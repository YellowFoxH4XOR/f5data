Description

Can not create Server SSL profile and see error:

01070313:3: Error reading key PEM file /partition/key_name.key for profile /partition/server_ssl_profile_name: error:0907B068:PEM routines:PEM_READ_BIO_PRIVATEKEY:bad password read
 

Environment

  • BIG-IP
  • any version
  • Server SSL profile
  • SSL key to be used requires password
     

Cause

If the key is generated with passphrase, then check if you are typing valid passphrase in the Server SSL profile.
 

Recommended Actions

Change "Basic" to "Advanced" for Configuration, and type valid password to Pass Phrase and Confirm Pass Phrase you set for the key.

None
