Topic

No data is sent or received over a failover cable.

A failover cable is used only to monitor the voltage level of the active BIG-IP system to assure that the peer unit is available. If the standby BIG-IP system detects a voltage level drop in the active computer, the system assumes failover status and becomes active within approximately 200 to 300 milliseconds.

The BIG-IP system also checks for voltage on this line when booting to determine whether it should start up as an active or a standby unit.

The sod process is the software daemon responsible for monitoring the line voltage on the failover cable.

Important: BIG-IP 9.4.5 through 9.4.8 are affected by an issue within the sod process in which the standby unit takes three to five seconds to become active after viewing the peer unit go offline or into standby mode. For more information, refer to K9468: The standby BIG-IP system is slow to go active during SOD-initiated failover.

Important: A failover cable is a special cable; a standard serial cable cannot be used as a failover cable. For more information about failover cable characteristics, refer to K1426: Pinouts for the failover cable used with BIG-IP platforms.
