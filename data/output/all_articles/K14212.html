Topic

This article applies to BIG-IP 11.x - 21.x. For information about other versions, refer to the following article:

  • K7119: Displaying BIOS version information for BIG-IP systems (9.x - 10.x)

You should consider using this procedure under the following condition:

  • To display the BIOS revision information

Description

The BIOS version information is located in the Platform section of the tmsh show sys hardware command output.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have access to the Traffic management shell (tmsh).

Procedures

Display BIOS version information

View the BIOS version information using the following procedure:

Impact of procedure: None.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Display system hardware information by typing the following command:

    show sys hardware

  3. You can find the BIOS version information in the Platform section of the command output. The platform section will appear similar to the following example:

    Platform
    Name BIG-IP 11050
    BIOS Revision OBJ-0352-01 - Build: 90014
    Base MAC 0:1:d7:c6:77:80
