Description

F5OS platform shows a different disk size in the output of show components component storage, when compared with the platform data sheet.

For example, output shows a 700GB disk, but the data sheet lists a 1TB disk.

Why is the disk smaller?

What is the expected size?

Environment

  • F5OS
  • rSeries r2k/r4k and r5k/r10k
  • VELOS
  • Storage size, SSD, Hard disk

Cause

This is expected. The disk is presented at a smaller smaller size by F5OS due to over-provisioning of the drive.

For more information, refer to the following Wikipedia page on write amplification:

  • https://en.wikipedia.org/wiki/Write_amplification#Over-provisioning

Recommended Actions

None

Additional Information

The disk size shown in the show components output may vary slightly between units manufactured at different times, but 700GB is the standard expected size for r5k, r10k, and VELOS blades. Likewise, the data sheet lists the r2k/r4k platforms as having 480GB drives, but the expected output of the show components command is 447GB.
