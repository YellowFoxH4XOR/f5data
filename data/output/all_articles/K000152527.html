Description

This procedure should be considered when sensitive data, such as IPs are required to be obfuscated from a packet capture for troubleshooting purposes.

Important: This article is intended to inform users of the availability of third-party tools that can be used to obfuscate or truncate data, particularly in situations where sensitive information cannot be shared with F5 Support. While providing such modified data is significantly more helpful than providing none at all, it is important to note that tools such as tcprewrite are not developed or maintained by F5. As these are external utilities, F5 assumes no responsibility for their use, reliability, or any impact they may have on your data or systems. 

Environment

  • This is a 3rd party application that may require installation on a Linux device on the customer's side (if it's not already installed).
  • Therefore access to a Linux device will be required to perform this PoA.

Recommended Actions

As mentioned above, the tcprewrite command may require installation on your Linux device. Below is an example of how to install it on an Ubuntu device:

# sudo apt install tcprewrite 

Once it is confirmed that the app is installed, perform the packet capture as requested and pull the .pcap file from the BIG-IP device (possibly using an app such as WinSCP). The first step is to trim the packet capture (where necessary) to only include the relevant conversation required for troubleshooting. Running the tcpdump by specifying the client IP address from where the issue will be reproduced (instead of using the VIP for example) can help limit such traffic and possibly not require trimming of the packet capture. This helps ensure that only the specific traffic that we are interested in is captured, and nothing else.

To obfuscate the data, the trimmed packet capture file must then be uploaded to the Linux device where tcprewrite is installed followed by the command below:

# tcprewrite --pnat=192.0.2.0/24:198.51.100.0/24 --pnat=10.0.0.1/32:172.16.0.1/32 --mtu=60 --mtu-trunc --infile=<original>.pcap --outfile=<obfuscated>.pcap

Feel free to modify the command accordingly. Below is an explanation of the example command shown above:

 

Command ParameterExplanation
--pnat=192.0.2.0/24:198.51.100.0/24IPs in the range 192.0.2.0/24 will be replaced/re-written by corresponding IPs from the range 198.51.100.0/24.
--pnat=10.0.0.1/32:172.16.0.1/32Specific IP 10.0.0.1 will be replaced/re-written by IP 172.16.0.1.
--mtu=60 --mtu-truncOnly the first 60 bytes of each packet will be displayed.
--infile=<original>.pcapThe original non-obfuscated file pulled from the BIG-IP device.
--outfile=<obfuscated>.pcapThe modified/re-written file with all the above changes.

Additional Information

If you wish to expand on or for more options/parameters for the tcprewrite command, visit the Ubuntu tcprewrite manual page here.
