Issue

Starting in BIG-IP 10.1.0, the bigpipe sshd allow command no longer modifies the /etc/hosts.allow file. The sshd process no longer requires entries in the /etc/hosts.allow file to allow SSH access, and so the bigpipe sshd allow command no longer adds entries to that file.

To view the sshd allow list, use the bigpipe sshd list command or view the sshd configuration in the /config/bigip_sys.conf file.

For example:

sshd {
allow "all"
}

F5 Product Development tracked this change as CR118383.
