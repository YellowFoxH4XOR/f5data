Known Issue

This is the result of a known issue. The FirePass attack notification feature sends a notification message to the administrator email account when the configured logon failure threshold has been reached.

Note: The logon failure threshold is configured in the Attack Notification and Prevention section on the Device Management : Security : User Access Security page. The administrator email account is configured on the Device Management : Configuration : Admin E-Mail page.

By default, FirePass selects the English language for the attack notification email. If you select the Choice of language in logon page check box on the Device Management : Customization page, and then select a different (non-English) language in the Default language menu on that page, the correct behavior is for FirePass to use the language you selected for the attack notification email. Instead, FirePass uses the language selected by the user who caused the logon failure. For example, if the user who generated the attack notification event selected Spanish on the user logon page, FirePass sends the attack notification message in Spanish, regardless of the default language specified on the Device Management : Customization page.

F5 Product Development is tracking this issue as ID 294118 ( formerly CR128297 ).
