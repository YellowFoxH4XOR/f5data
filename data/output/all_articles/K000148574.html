K000148574: How to create/modify Fast ACLs for Internet VIPs

Type
Support Solution
Published
2024-11-15
Updated
2025-06-11
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
  • F5 Distributed Cloud DNS Load Balancer
Source
https://my.f5.com/manage/s/article/K000148574

Description

  • After creating a Fast ACL there is no method to apply the new policy.
  • There is no option to apply Fast ACL to internet VIP by default.

Environment

  • F5®  Distributed Cloud
  • HTTP Load Balancer

Cause

  • Console Fast ACLs require Routed DDoS subscription

Answer/Recommended Actions

Currently, if you are not subscribed to Routed DDoS, Fast ACLs must be create/modified via the Distributed Cloud API. Please refer to our API documentation for further details: 

API Documentation - Fast ACL Reference

Additional Information

All F5 XC Load Balancers are protected against layer 3 and layer 4 DDoS attacks by default, this includes protocol attacks like TCP SYN floods and RST floods. Moreover, since the XC load balancers are part of a  full proxy architecture, these types of attacks are stopped before reaching your origin servers. 

 

We are working to ensure the Fast ACLs have the internet VIP option on the Console as well but it is not currently available (unless you are subscribed to Routed DDoS).
