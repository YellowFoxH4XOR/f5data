Description

This article explains the following messages are listed in /var/tmp/mcpd.out on the BIG-IP device.

Debug mcpd FipsUserMgr::write_encrypted_password (Line 678): Device does not contain NGFIPS/N3FIPS cards
Debug mcpd FipsUserMgr::write_encrypted_password (Line 678): Device does not contain NGFIPS/N3FIPS card

This article is related to C117 platforms which does not have FIPS.

We can reproduce the message when we add or remove serverssl, clientssl profile in the Virtual Server.

Environment

  • BIG-IP LTM 15.1.2
  • C117 Platforms (i2800) with no FIPS
  • Messages in /var/tmp/mcpd.out
  • Messages is re-produced when adding and removing serverssl and clientssl profile

Cause
None.

Recommended Actions

You can ignore these messages in the BIG-IP platform(C117) which does not support FIPS as stated in K05129174.
