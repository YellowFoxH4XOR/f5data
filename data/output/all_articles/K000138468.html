Description

The EXPIRY STATUS/DATE says locked or 1, or past day
 

Environment

  • F5OS-C
  • Velos
  • Adding new blade
  • RMA 
 

Cause

  • Bug ID 1505329
The partition's "root" account is expired/locked cause trouble for new blade to join the cluster.
NOTE: root account for partition is used for SSH and Console access to blade, also adding to the cluster. 
 

Recommended Actions

Enable root account from the partition CLI

config
system aaa authentication users user root config expiry-status enabled

NOTE: v1.5.x and before
system aaa authentication users user root config expiry-date -1

commit and-quit
