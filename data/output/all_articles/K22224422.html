K22224422: BIG-IP Backup Failure from BIG-IQ stuck as ''Backup In Progress''

2022-05-11
Updated

Applies to

Source

Description

  • When reviewing BIG-IQ from a failed backup notification email, I see the Backup File job with a status of "Backup In Progress" and it's showing a spinning.
  • Warning message similar to the following can be seen on /var/log/restjavad.0.log

    tar: config/.config.backup/WwMoU9: Cannot stat: No such file or directory
    tar: config/.config.backup/WwMoU9/bigip.conf: Cannot stat: No such file or directory
    tar: config/.config.backup/WwMoU9/bigip_user.conf: Cannot stat: No such file or directory
    tar: config/.config.backup/WwMoU9/partitions: Cannot stat: No such file or directory
    tar: config/.config.backup/WwMoU9/partitions/fcsd_parts_qim_qa: Cannot stat: No such file or directory
    |
    [WARN][08 Apr 2022 03:35:30 UTC][/cm/shared/event/alerts AlertCollectionWorker] There was a failure when creating a backup. Additional information: UCS backup with id 4cc3a9d3-524b-45bb-99fd-dfe3b6f37947, name Backup.ucs, and referer http://localhost:8100/shared/group-task failed: Saving active configuration...

Environment

  • BIG-IP
  • BIG-IQ CM
  • UCS

Cause

Seen behaviour is caused by a known issue tracked with the Bug ID 755197.

Recommended Actions

Perform the following procedure to delete the failed backup file

  1. On BIG-IQ Central Management run:

    tmsh restart /sys service postgres tokumond restjavad webd guiserver

  2. After the restart of restjavad daemon, the backup files stuck in "Backup In Progress" will result in "Backup Failed".
  3. Now, selecting the backup file will result in "Delete" button becoming active.  Thus, able to delete the backup file.
