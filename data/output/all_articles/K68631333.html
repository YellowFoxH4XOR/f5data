Known Issue

The Configuration utility may incorrectly display a local traffic policy rule condition when you view or modify a configured rule.

This issue occurs when all of the following conditions are met:

  • You have a local traffic policy with a policy rule configured on a BIG-IP system.
  • The rule condition is set to use a condition other than the equals option.
  • You attempt to view or modify the rule using the Configuration utility.
Impact

You can safely ignore this issue; it should not impact system performance.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the Configuration utility to view or edit a configured rule, the rule configuration is automatically populated to the respective field but the Condition field defaults to the equals option.
