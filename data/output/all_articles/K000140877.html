K000140877: Failed status on Catalog Key after using Automatic Activation Method

Support Solution
Published
2024-08-28
Updated
2025-10-28
Applies to

  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source

Description

You recently activated a Catalog key for the Flexible Consumption Program (FCP) on the BIG-IQ and used the Automatic Method. Afterwards, this CAT key displays a status of Failed and only some of its offerings are Active (green), whereas, the remaining ones Failed.

Environment

  • BIG-IQ

  • Flexible Consumption Program (FCP)

  • Catalog (CAT) key

Cause

Bug ID 1033457: Option to reactivate BIG-IP license on BIG-IQ is not available when exiting before confirming the EULA

The automatic activation or WebUI page likely timed out. One indicator of this issue is that no EULA is offered during the initial activation of the CAT key.

Recommended Actions

Prompt the BIG-IQ to reactivate this catalog key.

  1. On the BIG-IQ, navigate to Devices > License Management > Licenses
  2. Click on the name of the failed CAT key to load its properties page.
  3. Note the URL or address in the browser bar:
    • Example: https://<IP>/ui/devices/license-management/licenses/properties/Utility/<UUID>
  4. Replace the word "properties" with "reactivation":
    • Example: https://<IP>/ui/devices/license-management/licenses/reactivation/Utility/<UUID>
  5. This will reload the License activation page.
    Note: You may need to log back in and return to the CAT properties page.
    Important: This doesn't impact BIG-IPs licensed by this CAT, if any exist.
  6. Select Automatic then Reactivate in the lower right corner.

If the issue is still unresolved, refer to K000157113: Certificate at host activate.f5.com is not trusted as the certificate could be impacting this communication.

Additional Information

If the issue persists, please contact your Customer Success Manager and F5 Support.
