Description

  • RAID array member state is shown as 'undefined' in commands: tmsh show /sys raid
  • The actual raid status is up and operational
  • The software can not be upgraded as a result of this issue
Example:

show /sys raid

------------------------------------------------------------------------------
Sys::Raid::Bay
Bay  Shelf  Name  Serial Number          Array Member  Array Status

------------------------------------------------------------------------------
1    1      HD1   S3F4NXMM213456         yes           undefined
2    1      HD2   S3F4NXMM213478         yes           undefined

Environment

  • RAID supported BIG-IP platforms
  • Version 13.1.x
  • Array Status is undefined
  • Unable to install new software

Cause

ID 815425

Recommended Actions

Upgrade to a software version not impacted by this issue using one of the following methods:
  1. Boot into another volume and perform a software upgrade
  2. If there are no other volumes to boot in to, then perform a clean installation.  See article K13117 Section: Installing the software using an installation image saved on the system


Additional Information

[UU] indicates both of the disk in this raid are all up:
