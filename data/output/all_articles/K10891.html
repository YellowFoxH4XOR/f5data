K10891: The 'no wins' and 'no wins-server' CLI commands now accept optional arguments

Issue

For ARX 5.0.6 and earlier, the no wins and no wins-name commands do not require or accept arguments.

To remove the configured WINS server you must use the no wins command without specifying the WINS server IP address. If the WINS server IP address is specified in the no wins command, the command will fail. For example:

ARX1(gbl-gs-vs[ARX1-vip.arx.com~192.168.1.100])# no wins 192.168.1.202
                                                        ^
% ERROR: Invalid input detected at '^' marker

To remove the configured WINS name you must use the no wins-name command without specifying the WINS name. If the WINS name is specified in the no wins-name command, the command will fail. For example: 

ARX1(gbl-gs-vs[ARX1-vip.arx.com~192.168.1.100])# no wins-name wins.arx.com
                                                             ^
% ERROR: Invalid input detected at '^' marker

Not being able to specify the WINS Server IP address or the WINS Name was often found counter-intuitive and inconsistent with other CLI commands. As a result, F5 Networks Product Development received a request for enhancement to modify this behavior and allow the commands to accept the optional arguments.

Beginning with ARX 5.1.0 and later, the no wins and no wins-name commands still do not require the WINS Server IP address or the WINS Name to be specified. However, the commands will accept the optional WINS server IP address and WINS name arguments. 

To remove the configured WINS server you can use either of the following command formats:

no wins

no wins <WINS_Server_IP_address> 

To remove the configured WINS Name you can use either of the following command formats:

no wins-name

no wins-name <WINS_Name> 

F5 Product Development tracked this enhancement request as ARX ID 36368.
