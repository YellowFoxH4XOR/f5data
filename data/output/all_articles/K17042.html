Summary

FirePass does not support the Windows 10 operating system. F5 has no future plans to add support for future Windows operating systems to FirePass. F5 recommends that FirePass customers migrate to the BIG-IP APM system at their earliest convenience.

For more information, refer to K13366: End of Sale announcement for FirePass.

    Description

    FirePass does not currently support clients who are running the Windows 10 operating system.

    Impact

    The FirePass controller may not correctly detect clients running Windows 10. This behavior may cause the following issues:

    • The FirePass controller client operating system detection may not correctly detect the Windows 10 operating system.
    • The FirePass controller client-type detection may not correctly detect Internet Explorer 11.
    • The standalone BIG-IP Edge Client may not install correctly on devices running Windows 10.
