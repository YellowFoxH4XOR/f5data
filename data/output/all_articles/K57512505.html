Description

  • Attaching more than one log profile with local logging enabled like below produces a validation error
    security log profile profile1 {
        application {
            profile1 {
                filter {
                    request-type {
                        values { illegal }
                    }
                }
            }
        }
    }

    security log profile profile2 {
        application {
            profile2 {
                filter {
                    request-type {
                        values { all }
                    }
                }
            }
        }
    }
  • The fallowing message appears on the GUI
    Security log profiles '<profile_name>' and '<profile_name_2>' cannot be associated simultaneously with a virtual server '<vs_name>', since they both have local logging enabled.

Environment

  • Big-IP ASM
  • Virtual server with security log profile attached

Cause

Seen behavior is expected, only one logging profile with given type is supported

Recommended Actions

Change one of the profiles to log remotely

Additional Information

None
