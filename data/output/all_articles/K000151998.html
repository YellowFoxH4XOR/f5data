K000151998: How to verify if the device is licensed with FIPS?

Type
Support Solution
Published
2025-06-23
Updated
2025-07-31
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.6, 15.1.10
Source
https://my.f5.com/manage/s/article/K000151998

Description

You have a BIG-IP LTM device and wanted to verify if the device is licensed with FIPS, mainly to check if the software version for your device has reached its end of Technical Support.

Environment

  • LTM
  • FIPS

Cause

Device is running on either of the following software versions:

  • 15.1.10 that has reached its end of technical support (EoTS) on December 31, 2024. 
  • 16.1.6 that has reached its end of technical support (EoTS) on 31 July 2025.

However, if the device is licensed with FIPS, 15.1.10 EoTS has been extended to December 31, 2025.

For 16.1.6 EoTS, only iSeries and VIPRION, with FIPS Addon license has been extended to July 31, 2026.

Recommended Actions

To check if FIPS is licensed on your device, check if FIPS is listed in the Active Modules. Log in to your BIG-IP device, and do the following:

  • In the Configuration utility, navigate to System > License > Active Modules
  • From the command line, run this command, tmsh show sys license. 

If FIPS is not listed in the Active Modules, your device is not licensed with FIPS. 

Additional Information

Active modules

The features for modules listed in the Active Modules section are fully licensed and available for provisioning, configuration, and use.

Optional modules

The features for modules listed in the Optional Modules section (sometimes referred to as unlicensed modules) are available for licensing. The BIG-IP system may allow you to provision and configure objects for an optional (unlicensed) module feature; however, functionality for the optional module feature is inactive until the BIG-IP system is licensed for the module feature.
