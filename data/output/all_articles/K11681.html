Topic

Summary

This article discusses the behavior of the Diameter monitor and its support for the types of diameter commands.

Description

You can configure the BIG-IP Diameter monitor to monitor the status of a Diameter server. By default, the Diameter monitor uses the Capabilities-Exchange-Request (CER) and Capabilities-Exchange-Answer (CEA) commands to determine the status of the Diameter server. Specifically, it marks a Diameter server as up if the server passes all of the following checks:

  • The BIG-IP system is able to establish a TCP connection to the Diameter server.
  • The BIG-IP system sends a CER to the Diameter server, and receives a CEA in response.
  • The result code contained in the CEA is the expected result code (by default, 2001).

You can customize most of the parameters used by the Diameter monitor in the Configuration utility. However, you must modify the /usr/share/monitors/diameter.cer-cea file if you want the Diameter monitor to send additional Diameter commands or Attribute-Value-Pairs (AVPs), or accept a desired result code. To do so, perform the relevant procedures described in K14536: Customizing the BIG-IP Diameter monitor.
