Description

You are using a security policy with automatic or manual learning, and you would like to know if learning functionality will still work, even if there is no logging profile applied to the virtual server.

Environment

  • Security policy
  • Learning
  • Logging
  • Policy building

Cause

None

Recommended Actions

Learning suggestions will still be generated in the normal way. However, without logging you may lose some visibility of the request samples that are generating learning suggestions, so it can be harder to evaluate if a learning suggestion should be accepted or not when using manual learning. For this reason, it's recommended to use a logging profile if possible.

For more information about learning and policy building, refer to the following manual:
