K000160540: How to generate Diffie Hellman (DH) parameters for the ssl_dhparam directive and DHE ciphers

Description

Support for DHE ciphers may be required for client compatibility. NGINX Plus supports the use of DHE ciphers. Although more modern ECDHE ciphers exist, you may need to use DHE for better compatibility. This article will help you generate a file containing the Diffie Hellman (DH) parameters. And configure it in NGINX Plus.

Environment

  • NGINX Plus.
  • OpenSSL command-line tool.

Cause

  • None.

Answer/Recommended Actions

You can use the OpenSSL command-line tool to generate the Diffie Hellman (DH) parameters. This will take a few minutes for a 2048 bit key. This key size is both secure and quick.

For example:

openssl dhparam -out /etc/nginx/dhparam 2048

The next step is to configure the ssl_dhparam directive to enable the use of DHE ciphers.

For example:

http {
    ssl_dhparam /etc/nginx/dhparam;

    # ...
}

This directive can be specified as a global directive for all virtual servers inside the http context.

Additional Information

There is a more modern alternative to DHE ciphers: ECDHE. And you don't need to configure the ssl_dhparam directive to use them. However, sometimes you may need DHE ciphers.
