Topic

In BIG-IP versions 9.3.x through 9.4.x, you can use the snapshot utility to manage product images. For example, the snapshot utility can be used to create or restore the entire filesystem for a product image.

Starting in BIG-IP version 10.0.0, the snapshot utility was removed from the product.

In version 10.x you can use the UCS archive feature to export and import the configuration on the system.

Note: For more information, refer to K3499: Backing up and restoring BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator configuration files.

Additionally, in version 10.x you can use the cpcfg command to copy configurations between slots on the same unit.

Note: For more information about using the cpcfg command, refer to the Copying the Configuration chapter in the BIG-IP Systems: Getting Started Guide.
