K33551371: BIG-IQ VE support for additional virtual hard disks.

Applies to

Source

Description
BIG-IQ VE support for additional virtual hard disks.

Adding Additional virtual disk  and attaching it to logical group to resize  /var or /shared partitions can cause upgrade problems
 

Environment

  • BIG-IQ Centralized Management (Virtual Edition)
  • Increasing space for partitions
  • Adding additional Virtual disk to logical group

Cause
None

Recommended Actions

The use of additional virtual disks to BIG-IQ (VE) are not supported.
To increase virtual disk  size for BIG-IQ Virtual Edition please  modify size of main Virtual disk  not adding secondary Virtual Hard Drive

Additional Information

If adding Additional Virtual Hard Drive was done and space was assigned to partitions, please consider preparing new BIG-IQ VE and load UCS file
