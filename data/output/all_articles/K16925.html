Known Issue

User Datagram Protocol (UDP) traffic flows initiated from the server side may use the same port as an active client side flow.

This issue occurs when the following conditions are met:

  • The Datagram LB option is enabled for the UDP profile.
  • A secure network address translation (SNAT) is configured for outbound traffic.

Impact

Traffic is unevenly distributed across BIG-IP pool members.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H363163 on the Diagnostics > Identified > Medium screen.
  • Statistics indicate that traffic is unevenly distributed across pool members.
