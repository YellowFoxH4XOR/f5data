Known Issue

This is the result of a known issue. When closing a Java AppTunnel connection after opening multiple Java tunnel favorites, all open Java AppTunnels will stop responding. Once this behavior occurs, you must close the FirePass Client Connector window and reopen the Java application favorite to re-establish the connection.

F5 Networks Product Development is tracking this issue as ID 329912 and CR140538.

Workaround

No workaround currently exists for this issue.

Note:Java-based tunnels were introduced in FirePass version 6.0.3.
