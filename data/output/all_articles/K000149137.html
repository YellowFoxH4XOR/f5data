K000149137: BIG-IQ APM import fails with java.lang.IllegalStateException: /Common/RootNode refers to nonexistent object

Type
Support Solution
Published
2026-09-08
Updated
2026-09-08
Applies to
  • BIG-IQ
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000149137

Description

Importing APM configuration into BIG-IQ fails with the error similar to below:

 

Coordinator failed during working-config update, roll-back working-config started; reason: Worker http://localhost:8100/cm/adc-core/working-config/root-node failed validation with status 500: java.lang.IllegalStateException: /Common/RootNode refers to nonexistent object (https://localhost/mgmt/cm/adc-core/working-config/sys/file/ssl-cert/dd0ba02a-71ca-32e4-9a0e-de772cc890ae)

 

Environment

BIG-IQ 8.3.x.

Configuration contains autogenerated certificates seen with the below (note auto_jwk_ in the cert name):

 

restcurl /cm/access/current-config/apm/oauth/jwk-config/

{
...
  "cert": "/Common/auto_jwk_Azure_AD_Provider1_cert.crt",
...
}

 

Cause

ID910069 - auto-generated certificates are not supported by BIG-IQ.

 

Recommended Actions

Before importing make sure no auto-generated certificates are in use with Access ›› Federation : JSON Web Token : Key Configuration on the end BIG-IP.
