Known Issue

This is the result of a known issue. A Terminal Servers Favorite that is configured to open in a new window renders a truncated remote Desktop if the user's master group is configured to display terminal screen resolution using the Percentage of Screen Size setting with a value of roughly 90 percent or higher.

The Terminal Servers window will truncate the remote desktop if the following two conditions are met:

  • The percentage of the screen setting is roughly 90 percent or higher
  • The Terminal Servers Favorite is configured to open in a new window

This configuration can render the Terminal Servers connection unusable if, for example, the Windows Taskbar is included in the truncated portion of the Desktop.

You can configure the resolution of FirePass Terminal Servers Favorites to specific dimensions, or to take up a percentage of the screen. These settings are configured with the Select initial preference for the Terminal screen resolution drop-down menu, under the Screen resolution section of the Application Access: Terminal Servers: Master Group Settings page.

F5 Networks Product Development tracked this issue as CR74016 and it was fixed in version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Workaround

You can work around this issue and allow access to all parts of the desktop by selecting a fixed resolution size. Alternatively, you can avoid configuring the Terminal Servers Favorite to open in a new window.
