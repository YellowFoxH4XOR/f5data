K000160442: TACACS+ authentication may persist despite missing configuration in bigip.conf

Type
Support Solution
Published
2026-03-24
Updated
2026-03-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000160442

Description

On BIG-IP systems, TACACS+ authentication may continue to function even if the TACACS+ configuration is missing from both the GUI and the bigip.conf file. This occurs because the file /config/bigip/auth/pam.d/tacacs/system-auth, which is created when TACACS+ authentication is initially configured, can independently enable TACACS+ authentication.

Environment

  • Product: BIG-IP LTM
  • TACACS+ authentication
  • Configuration details:
    • TACACS+ settings missing from GUI and bigip.conf
    • TACACS+ configuration present in /config/bigip/auth/pam.d/tacacs/system-auth

Cause

If TACACS+ settings were removed manually from bigip.conf, but persisted in the system-auth file, the BIG-IP will still authenticate users via TACACS+.

Answer/Recommended Actions

  1. Disable remote authentication using the recommended GUI method to ensure all residual TACACS+ configuration is removed.
  2. Recreate TACACS+ authentication through the GUI to restore proper configuration and visibility.
  3. Reference F5 article K20276980: Remove TACACS+ remote authentication from BIGIP using GUI method for step-by-step instructions on removing TACACS+ remote authentication using the GUI.

Additional Information

  • Manual removal of TACACS+ configuration from bigip.conf does not fully disable authentication if the system-auth file remains configured.
  • Proper removal and reconfiguration through the GUI ensures all relevant files are updated and the system behaves as expected.
