K000139863: How to change/set the password of a user in F5OS-C via API

Type
Support Solution
Published
2024-06-01
Updated
2024-06-01
Applies to
  • F5OS
  • F5OS-C: 1.6.X, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000139863

Description

You would like to use the API to set or change the password of a user in F5OS-C partition.

Environment

  • F5OS-C partition 1.6
  • Setting/changing a user's password

Cause

None

Recommended Actions

Please refer to API documentation for data_openconfig_system_system_aaa_authentication_f5_system_aaa_users_f5_system_aaa_user_f5_system_aaa_user_username_f5_system_aaa_config_f5_system_aaa_set_password_post .

The example shows how to change the password for <user> to <new_password>.

$ curl -sku admin:<admin_password> -H "Content-Type: application/yang-data+json" -X POST -d '{ "f5-system-aaa:password": "<new_password>" }' https://<mgmt_IP>:8888/restconf/data/openconfig-system:system/aaa/authentication/f5-system-aaa:users/f5-system-aaa:user=<user>/f5-system-aaa:config/f5-system-aaa:set-password

{

 "f5-system-aaa:output": {

  "response": "Password successfully updated."

 }

}
