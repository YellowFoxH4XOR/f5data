Known Issue

During the SSL handshake, when the SSL record layer contains handshake data larger than 16384 (2^14) bytes, the BIG-IP system does not fragment the data.

This issue occurs when all of the following conditions are met:

  • The SSL record handshake data contains data larger than 16384 (2^14) bytes.

    This happens when you configure a large certificate or certificate chain for server or client authentication, at either the client or server SSL profile, respectively.

  • The client or server that is establishing an SSL handshake with the BIG-IP system checks and verifies the SSL record layer length.

In keeping with Internet Engineering Task Force (RFC 5246) and Internet Engineering Task Force (RFC 2246), the handshake data should be fragmented in chunks of 16384 (2^14) bytes.

Impact

When the BIG-IP system does not fragment the handshake data, the SSL record containing handshake data can exceed the maximum fragment size of 16384 bytes, causing the SSL handshake to fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When establishing an SSL connection, the BIG-IP system terminates SSL handshakes with a TCP reset from the client- or server-side.
  • In output similar to the following example, a packet capture of the affected traffic shows that the length of the Record layer of the Certificate Handshake protocol exceeds 16384 (2^14) bytes:

       TLSv1.2 Record Layer: Handshake Protocol: Certificate
            Content Type: Handshake (22)
            Version: TLS 1.2 (0x0303)
            Length: 16386

    In this example, the length of the record layer, 16386 bytes, exceeds 16384 (2^14) bytes.

  • Upon receiving a large certificate, the client or server terminates the SSL handshake with an error message similar to the following example in a packet capture:

       TLSv1.2 Record Layer: Alert (Level: Fatal, Description: Record Overflow)   

            Content Type: Alert (21)
            Version: TLS 1.2 (0x0303)
            Length: 2
            Alert Message
                Level: Fatal (2)
                Description: Record Overflow (22)
