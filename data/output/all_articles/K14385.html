Known Issue

The BIG-IP Configuration utility only accepts a limited subset of characters for an SSL profile passphrase.

This issue occurs when the following condition is met:

  • Using the BIG-IP Configuration utility, you attempt to set a passphrase for either a client or server SSL profile with any characters other than those described in the following table.
    CharacterDescription
    A-Z, a-zAll uppercase or lowercase alphabet characters
    0-9All numeric characters
    .Period
    *Asterisk
    /Slash
    -Hyphen
    :Colon
    _Underscore
    ?Question mark
    =Equal sign
    @At sign
    ,Comma
    &Ampersand

Impact

You cannot create an SSL profile.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to use an invalid character in an SSL passphrase, an error message similar to the following example appears in the BIG-IP Configuration utility:

    Bad Characters. Only the following special characters are allowed: period, asterisk, forward slash, dash, colon, underscore, question mark, equals, at sign, comma, ampersand and space (.*/-:_?=@,& )

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to set the password. To do so, perform the following procedure:

Setting an SSL profile passphrase using tmsh

  1. Create the profile in the BIG-IP Configuration utility using a password with supported characters.

    Note: If the profile already exists, skip this step.

  2. Log in to the BIG-IP command line as the root user.
  3. Log in to tmsh by typing the following command:

    tmsh

  4. Modify the existing SSL profile with the required password using the following command syntax:

    modify ltm profile <profile_type> <profile_name> cert <certificate_name>.crt key <key_name>.key passphrase <passphrase>

    In the previous syntax, note the following:
    • <profile_type> is either client-ssl or server-ssl.
    • <profile_name> is the name of the specific profile.
    • <certificate_name> is the name of the certificate being used.
    • <key_name> is the name of the key file.
    • <passphrase> is the passphrase of which you would like to change the password.

    For example:

    modify ltm profile client-ssl myclientssl cert f5test.crt key f5test.key passphrase test!!

  5. Save the change by typing the following command:

    save /sys config

    Note: For BIG-IP 10.0, type save config.
