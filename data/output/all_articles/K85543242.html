Issue

Old Behavior

In versions prior to BIG-IP 13.0.0 HF1, you can configure the Route Advertisement option for a virtual address to be either Enabled or Disabled only. 

New Behavior

Beginning in BIG-IP 13.0.0 HF1, F5 added more settings for the Route Advertisement option. In addition, the Enabled setting is deprecated and replaced by the Selective setting. The following table lists the new Route Advertisement options.

SettingDescription
AlwaysThe BIG-IP system always advertises the route for the virtual address, regardless of availability status. This requires an enabled virtual address.
EnabledThis is replaced by the Selective setting.
Disabled (default)The BIG-IP system does not advertise the route for the virtual address, regardless of the availability status.
SelectiveThe BIG-IP system advertises the route for the available virtual address based on the calculation method in Availability Calculation. This replaces the Enabled setting.
AnyThe BIG-IP system advertises the route for the virtual address when any virtual server is available.
AllThe BIG-IP system advertises the route for the virtual address when all virtual servers are available.

Impact

After an upgrade from versions prior to BIG-IP 13.0.0 HF1, if the setting was previously set to Enabled, you will encounter the following warning in the command line and the /var/log/ltm file:

v13 warning mcpd[5537]: 01071859:4: Warning generated : Virtual address /Common/192.0.2.0 setting route-advertisement 'enabled' is deprecated, use 'selective' instead.

Recommended Actions

Modifying the Route Advertisement setting to Selective

After an upgrade to BIG-IP 13.0.0 HF1 and later, with the Enable setting deprecated, F5 recommends that you modify the Enable setting to Selective. To do so, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Virtual Servers > Virtual Address List.
  3. Select the affected virtual address that is currently set to Enabled.
  4. For the Route Advertisement option, select Selective.
  5. Select Update.
