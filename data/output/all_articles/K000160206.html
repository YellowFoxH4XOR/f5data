K000160206: LX Workspace directory listing fail in GUI

Description

LX workspaces (iRulesLX) fail to load or list directories via the BIG-IP GUI. The workspace editor displays errors such as "Could not list directory: /var/ilx/workspaces/Common/<workspace name>/extensions"

Workspaces can be listed from the CLI but not from the GUI.

 

Environment

- Product: BIG-IP LTM

- Version: 17.5.1

- LX Workspaces and iRulesLX extensions

- Node.js version: 6.9.1

- Services involved: restjavad, restnoded

 

Cause

- Mismatched or incorrect version references in package.json files for workspace extensions (e.g., "f5-nodejs": "0.0.3" instead of "1.0.0")

- Incorrect file or directory ownership and permissions for node_modules directory within workspace extensions

drwxrwxr-x. 34 root sdm 4096 Aug 7 2025 node_modules

 

Recommended Actions

To resolve LX workspace directory listing failures in the BIG-IP GUI:

 

1. **Check and Correct package.json Version References**

- Navigate to the workspace extension directory

- Edit the `package.json` file and ensure the dependency version matches the actual installed version:

- Change `"f5-nodejs": "0.0.3"` to `"f5-nodejs": "1.0.0"` if the installed version is 1.0.0.

 

2. **Correct Directory Ownership and Permissions**

- Change ownership and permissions for the node_modules directory:

#chmod -R 755 node_modules

#chown -R root:root node_modules

3. **Restart Services**

- Restart relevant services to apply changes:

#bigstart restart restjavad restnoded

 

4. **Reload the Plugin**

- In the BIG-IP GUI, reload the plugin from the workspace:

- Local Traffic ›› iRules : LX Workspaces ›› [workspace name]

- Click "Reload from Workspace..."

 

5. **Verify Resolution**

- Confirm the workspace loads successfully in the GUI and the status symbol remains green.

 

Additional Information

- LX workspaces are not automatically synced between HA peers; only the iRulesLX plugin syncs.

- Workspace directory and file ownership should match expected values for proper GUI operation.

- Upgrading BIG-IP versions may require manual correction of workspace dependencies and permissions.
