Topic

The 3dpipe stats summary command displays the following information about the 3-DNS Controller:

FieldDescription
VersionSoftware version for the 3-DNS Controller.
Serial NumberSerial number for the 3-DNS Controller hardware platform.
Max Data SizeThe maximum amount of memory available to 3-DNS processes.
Start TimeThe time and date that the 3-DSN Controller was last booted or that the 3ndc restart command was run.
Current TimeThe current 3-DNS Controller system time.
Last ReloadThe time and date that the 3ndc reload command was last run. This will display NULL_TIME if the configuration has not been reloaded since the 3-DNS Controller was rebooted or the 3ndc restart command was run.
Total RequestsThe total number of DNS requests that have arrived at the 3-DNS Controller since the last reboot or since the last time that the 3dnc restart command was run.
Average Requests per SecondThe average number of DNS requests per second that has arrived at the 3-DNS Controller since the last reboot or since the last time that the 3dnc restart command was run.
Uptime in SecondsThe amount of time, in seconds, since the 3-DNS Controller was last rebooted or the 3ndc restart command was run.
