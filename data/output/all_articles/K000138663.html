K000138663: Getting "SSL certificate problem: unable to get local issuer certificate" error when installing or upgrading NGINX Plus

Type
Support Solution
Published
2024-02-21
Updated
2025-04-01
Applies to
  • NGINX Products
  • NGINX Plus
Source
https://my.f5.com/manage/s/article/K000138663

Description

  • You may encounter the below error when trying to install or upgrade NGINX Plus using Nexus Repository Manager.
    • "SSL certificate problem: unable to get local issuer certificate"

Environment

  • Nexus Repository Manager (NXRM)
  • NGINX Plus
  • Package Manager (yum, apt, ...etc)
  • Install
  • Upgrade

Cause

  • The SSL certificate installed on Nexus Repository Manager is not trusted by the underlying curl tool used by package manager.

Recommended Actions

  • Update repository file to access NGINX Plus repositories directly and bypass Nexus Repository Manager

Additional Information

  • To fix the SSL certificate issue on Nexus Repository Manager, please refer NXRM's documentation.
