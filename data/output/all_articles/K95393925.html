Known Issue

The Internet Message Access Protocol (IMAP) and Post Office Protocol 3 (POP3) monitors might fail if the mail server supports Generic Security Service Application Program Interface (GSSAPI) authentication.

This issue occurs when the following condition is met:

  • An IMAP and POP3 monitor is configured and the server returns GSSAPI as an available authentication mechanism.

Impact

The monitor fails and marks the server down, even when the server might be available.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The IMAP and POP3 monitors fail if the mail server supports GSSAPI authentication and mark the server down.

Workaround

To work around this issue, you can use one of the following options:

  • Turn off GSSAPI authentication on the mail server.
  • Use an alternate monitor type.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
