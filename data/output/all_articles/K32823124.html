Description

After performing an upgrade to BIG-IP version 15.x, DNSSEC key events are no longer being logged. 
 

Environment

  • BIG-IP DNS
  • DNSSEC
  • Logging
  • BIG-IP Version 15.x

Cause

This is the result of a known issue ID 1025285

Recommended Actions

  1. There is no fix for this bug. The recommendation is to upgrade to 16.1.x to resolve this issue.

Additional Information

As this impacts logging, this would also impact any configured alerts for DNSSEC Key events.
