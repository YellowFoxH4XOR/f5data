K000137706: BIG-IQ Configure Utility stuck with error "Waiting for BIG-IQ services to become available"

Type
Support Solution
Published
2023-12-15
Updated

Applies to

  • BIG-IQ Centralized Management: 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000137706

Description

BIG-IQ Configuration Utility stuck with error "Waiting for BIG-IQ services to become available", there are many reasons which could cause this symptom. Customer may have tried other workaround such as restart restjavad and other daemons, but it does not help.

Environment

  • BIG-IQ
  • Configuration Utility

Cause

If the management IP is configured with DHCP, customer should check whether the management IP is available in the base configuration. Management IP is mandatory for BIG-IQ, if there is no management IP configured, and user tries to login through another self IP, customer will see the error.
Customer can run below command to verify.

 # tmsh show cm device
---------------------------------------------------------------
CentMgmt::Device: bigiq1
---------------------------------------------------------------
Hostname                        bigiq1.example.com
Mgmt Ip                         127.0.0.1<===================
Configsync Ip                   ::
Mirroring IP                    ::
Mirroring Secondary IP          ::
Failover Multicast IP           ::
Failover Unicast IP(s)          -
Device HA State                 active
Device HA Load Capacity         0
Device Current Load Factor      1
Device Next Active Load Factor  0

Another symptom is restnoded daemon cannot be up.

# tmsh show sys service restnoded
restnoded down, waiting for restjavad

Recommended Actions

Login this device with ssh, and then run command config to bring the configure wizard , make sure it gets the management IP and save, then check with the same command above to confirm the management IP show as configured, then the issue should be fixed.
If the issue still persists after the above workaround, please open a support ticket for help.
