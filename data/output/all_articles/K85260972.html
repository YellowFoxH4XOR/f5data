Description

The fslogd process is continuously restarting, and the following error message is seen in /var/log/ltm:

  • err fslogd[<PID>]: Fatal error file_writer.c:sync_mapped_memory_and_unmap:442 msync failed errno[28] strerror[No space left on device]
  • err diskmonitor[<PID>]: 011d0004:3: Disk partition /var has only 0% free

The following error messages can be seen on /var/log/daemon.log

  • emerg logger: Re-starting fslogd
     

Environment

  • Big IP AFM/APM
     

Cause

  • No diskspace available at /var partition

 

Recommended Actions

  • Clear space within /var directory. For more information, refer to K14403: Maintaining disk space on the BIG-IP system
