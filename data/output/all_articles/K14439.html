Known Issue

The Enterprise Manager may fail to deploy a security policy or an IP address list to a managed device. This issue occurs when all of the following conditions are met:

  • The managed device is running BIG-IP ASM 11.3.0 or later
  • The Enterprise Manager user account used for deploying the security policy or IP address list does not exist on the managed device.

    For example, a myexampleadmin user account on the Enterprise Manager is used to deploy a security policy, but the managed device does not have this user account.

Impact

You cannot use the Enterprise Manager to deploy security policies or IP address lists to a BIG-IP ASM managed device.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you use an Enterprise Manager user account that does not exist on the managed device to attempt to deploy a security policy, the Enterprise Manager fails to deploy the security policy and reports an error message. For example:

    User <EM user account> does not exist, User <EM user account> does not exist
  • When you use an Enterprise Manager user account that does not exist on the managed device to attempt to deploy an IP address list, the Enterprise Manager Configuration utility fails to display the security policies on the selected managed device.

Workaround

There is no workaround for this issue. However, you may be able to mitigate this issue by ensuring the Enterprise Manager user account you used for deploying security policy or IP address list exists on the managed device. You need to copy the Enterprise Manager user account to the managed device. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the Enterprise Manager Configuration utility.
  2. Click Enterprise Management.
  3. Click Tasks.
  4. Click Task List.
  5. Click New Task.
  6. From the User Access section, select Copy User Access Configuration.
  7. Click Next.
  8. Select this Enterprise Manager as the Source Device.
  9. From the Configuration Data section, select Users.
  10. From the Device List section, select * All Devices.
  11. From the Devices section, select Compatible Devices.
  12. From the Compatible Devices section, select the managed device.

    Note: If the managed device is not listed under the Compatible Devices section, you must manually create the user account on the managed device.
  13. Click Next.
  14. From the Device Users section, select Add users not already present on device.
  15. Click Next.
  16. Click Start Task.
