Known Issue

Matching based on HTTP cookies may behave inconsistently when you use Local Traffic Policies.

This issue occurs when all of the following conditions are met:

  • You have a Local Traffic Policy associated with a virtual server.
  • The Local Traffic Policy is configured to perform an action based on matching HTTP cookies.

For example, if a request contains the HTTP cookie Cookie: user=xyz123, and the Local Traffic Policy is configured to not match cookies with the name/value pair user/xyz123, the policy may incorrectly match the request and perform the configured action.

Impact

The configured policy action may not be performed for requests that contain a matching HTTP cookie.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Local Traffic Policy fails to match requests that contain a matching cookie.
  • Local Traffic Policies that are configured to not match HTTP cookies, incorrectly match requests that contain a matching cookie.

Workaround

You may be able to work around this issue by using an iRule to match the HTTP cookies and perform the desired action. For more information about iRules, refer to the iRules Home at F5 Cloud Docs.
