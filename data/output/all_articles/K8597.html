User concurrent sessions limits

You can configure the number of concurrent sessions allowed for a single user account on the Device Management: Security: User Access Security page in the Concurrent logons section. If a user exceeds the user concurrent session limit, the user can continue to log on to the FirePass controller, but FirePass terminates the user’s earlier sessions.

Note: In a FirePass cluster configuration, this limit applies to each member of a cluster and not to the entire cluster. For example, if you set the user concurrent session limit to 2, the user can have two concurrent sessions on each member of the cluster.

For example, if you set the concurrent session limit to 2 concurrent sessions, and a user has two active FirePass sessions, FirePass terminates the first session if the user logs on a third time. If the user attempts to access the terminated session, FirePass redirects the browser to the logout page and reports an error message that appears similar to the following example:

Your session has expired.

Additionally, FirePass displays a message that appears similar to the following example on the Reports: System Logs page, where X is the user’s FirePass logon name:

User <X> exceeded the allowed number of concurrent logons

Users logged in to the webtop can view active concurrent sessions for their account by clicking the Tools link in the left navigational frame, and then clicking the View Current Sessions link.

Group concurrent session limits

You can configure the number of concurrent sessions allowed for a master group on the Users: Groups: Master Groups page. In the row of the master group you want to configure, click the number displayed in the Max concurrent sessions column. This step redirects you to the General tab, where you can enter the number of concurrent sessions under the Limit the number of concurrent sessions check box. After entering the number, click the Update button.

Note: In a FirePass cluster configuration, this limit applies to each member of a cluster and not to the entire cluster. For example, if you set the group concurrent session limit to 20, the master group can have 20 concurrent sessions on each member of the cluster.

If a user attempts to log on to the FirePass controller, and the group concurrent session limit is already reached, FirePass denies the logon attempt and reports an error message that appears similar to the following example:

The number of concurrent sessions exceeds the limit for this group!

Additionally, starting in FirePass version 5.5, FirePass displays a message that appears similar to the following example on the Reports: System Logs page, where groupname is the name of the master group, and # is the concurrent session limit configured for the master group:

The number of concurrent sessions exceeds the limit of <#> for group '<Groupname>'.

Licensed concurrent session limits

Your FirePass license determines the total number of concurrent user sessions supported by your FirePass controller. To view the total number of concurrent user sessions included in your FirePass license, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Maintenance: Activate License page.
  3. Click the Click here to view license details link.
  4. Next to Allowed Concurrent Connections is the maximum number of concurrent sessions your FirePass license supports.

If you require additional concurrent connection seats, contact your F5 Sales Representative.

Note: In a FirePass cluster configuration, every cluster member must have its own individual license that supports identical features and the same number of concurrent users, except for any failover-only members, which should have a failover-only license.

Note: The administrator account counts toward the total number of sessions used. However, the account will still be able to log on in the event that the concurrent session limit has been reached.

If a user attempts to log on to the FirePass controller, and the licensed concurrent session limit is already reached, FirePass denies the logon attempt and reports an error message that appears similar to the following example:

The number of concurrent sessions exceeds the licensed limit!

Additionally, starting in FirePass version 5.5, FirePass displays a message that appears similar to the following example on the Reports: System Logs page, where X is the number of licensed concurrent sessions:

The number of concurrent sessions has exceeded the maximum licensed limit of <X> seats.
