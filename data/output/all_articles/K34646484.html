K34646484: BIG-IP ASM request logs are not visible when the default route domain has a non-zero value

Type
Known Issue
Published
2018-02-27
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.1.0, 13.0.1, 13.0.0, 12.1.4
Source
https://my.f5.com/manage/s/article/K34646484

Known Issue

When you select a partition other than All [Read Only], no requests appear in the request log, but when you select All [Read Only], the requests appear.

This issue occurs when all of the following conditions are met:

  • You are viewing a partition other than All [Read Only].
  • The default route domain has a value other than 0 (zero).

Impact

You are unable to view the request log.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • No requests are logged in the BIG-IP ASM request log.
