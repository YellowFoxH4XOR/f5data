Topic

The RTSP profile Check Source option was added in BIG-IP LTM version 10.0.1, and is enabled by default.

When the Check Source option is enabled, the BIG-IP system performs the following tasks:

  • Determines the address from the source field in the Transport header
  • Sets up an ephemeral listener for RTP/RTCP traffic using the address determined from the source field
  • Rewrites the Transport header source field with the virtual server address before sending to the destination

When you upgrade to BIG-IP version 10.0.1, the Check Source option is enabled by default in the RTSP profile. If this setting is not appropriate for your environment, RTSP traffic may encounter communications disruption. If this occurs, disable the Check Source option in the RTSP profile associated with the affected virtual server.

When the Check Source option is disabled, the BIG-IP system sets up an ephemeral listener for RTP/RTCP traffic using the RTSP endpoint IP address and does not modify the Transport header source field before sending to the destination.
