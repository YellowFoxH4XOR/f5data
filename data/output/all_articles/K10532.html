K10532: The IP::addr iRule command fails to perform an IP address comparison

Known Issue

This is the result of a known issue. The IP::addr iRule command fails to perform an address-to-address comparison of IP address/subnet/supernet to IP address/subnet/supernet when the mask designation is specified following the IP address.

For example, the following IP::addr syntax will fail to perform an address-to-address comparison when used in an iRule:

[IP::addr [IP::remote_addr] equals "10.0.0.0/24"]

F5 Product Development tracked this issue as CR120845 and it was fixed in BIG-IP LTM 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You can work around this issue by moving the mask designation to follow the first address argument to the IP::addr command.

For example:

[IP::addr [IP::remote_addr]/24 equals "10.0.0.0"]
