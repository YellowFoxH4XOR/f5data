Known Issue

The TMM process may fail to start and produce a core file when modifying the provisioning for a BIG-IP system.

This issue occurs when the following condition is met:

  • When you are re-provisioning a BIG-IP system, the TMM process is unable to obtain the required memory allocated.
The BIG-IP system allocates system resources dynamically based on the modules that are provisioned, the levels each module is provisioned at, the platform type, and the available resources. This process requires TMM and other processes to be restarted. A rare timing condition may result in the TMM process being unable to obtain the allocated memory resources required to restart.

Impact

You must reboot the system for the re-provisioning to complete.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to restart properly following a provisioning change, and in the /var/log/ltm file, logs messages similar to the following example:
    • err mprov:<PID>:: 'Reserving huge memory failed (desired amount: 6295 pages [12590 MiB], allocated: 4248 pages [ 8496 MiB].'
    • err mprov:<PID>:: 'Resource reallocation could not be completed - A reboot is necessary for provisioning to complete.'
