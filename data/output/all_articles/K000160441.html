K000160441: Incorrect Geolocation detection for Public IPs on BIG-IP APM due to outdated Geoip database

Description

VPN connection failures occur when public IP addresses are incorrectly detected as being in the wrong geographic location on BIG-IP APM. This results in legitimate users being denied access based on geolocation policies. 

Environment

  • IP showing incorrect location
  • APM geolocation mismatch
  • Geoip database outdated
  • VPN access denied

Cause

The Geo-IP database on the BIG-IP APM device was outdated, resulting in incorrect mapping of public IP addresses to geographic locations.

Recommended Actions

  1. Update the Geo-IP database on the affected BIG-IP APM device to the latest available version.
    • Downloading and installing updates to the IP geolocation database
  2. After updating, verify that the device correctly detects the geographic location of the previously affected public IP addresses.
    • Looking up IP geolocation data using the geoip_lookup command
  3. Repeat the Geo-IP database update on all other BIG-IP APM devices in the environment to ensure consistent behavior.
  4. Consider scheduling regular updates for the Geo-IP database to prevent recurrence of similar issues.
  5. If the database is still inaccurate after installing the latest geolocation database update (either Edge or Pulse) and you have specific questions about the content of the geolocation data, contact F5 Support or Digital Element directly using the following email address: IP-Data@digitalelement.com
