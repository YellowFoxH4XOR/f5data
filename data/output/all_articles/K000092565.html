K000092565: APM SAML signature failing after upgrade to v15.1.7

Type
Support Solution
Published
2022-11-07
Updated
2023-03-30
Source
https://my.f5.com/manage/s/article/K000092565

Description

 

After install or upgrade to v15.1.7, SAML Authentication fails with Signature verification failed for SAML Authentication Request

The below logs are seen under /var/log/apm:
 

SAML SSO: Error verifying SAML message signature (with 1 certificate(s)) - RSA verification failed, check SP certificate
SAML SSO: Error(1) verifying detached signature
SAML SSO: Error(1) Signature verification failed for SAML Authentication Request
 

Environment


BIG-IP v15.1.7
BIG-IP APM as SAML IDP

Cause

Query string separate gets converted from either "?" to "%3F"  or "%2F" to "/" which is breaking SAML auth

Recommended Actions
 

Upgrade to v15.1.8.1
 

Additional Information

Bug ID1174873 MutiDomain SSO the location header query string separate gets converted from "?" to "%3F" breaking MultiDomain.
