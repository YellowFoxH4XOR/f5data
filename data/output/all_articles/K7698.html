Known Issue

This is a result of a known issue. When a self IP address is designated with a unit ID of 2 and a SNAT Automap is configured, the self IP is never used by SNAT Automap. This issue occurs if unit 2 is offline and unit 1 is handling traffic for both unit 1 and unit 2 for an active-active configuration. This issue can also occur if the floating self IP is designated with a unit ID of 2 and pair of BIG-IP LTM units are configured for active and standby. As a result, the SNAT Automap only uses the floating self IP address designated for unit 2, when unit 2 is active.

F5 Product Development is tracking this issue as ID 273841 (formerly CR80643).

Workaround

You can work around this issue by ensuring the unit ID assigned to the floating IP address is unit 1 for an active-standby configuration. Additionally, for an active-active configuration, additional floating self IP addresses assigned to unit ID 1 may be required. To change the unit ID assigned to the floating IP address, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Network >> Self IPs >> Self IP List.
  3. Click on the floating IP address.
  4. Select 1 from the Unit ID drop-down box.
  5. Click on the Update button to save the modifications.
