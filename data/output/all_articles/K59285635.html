Example 1:

To find the Tomcat version, type the following command:

rpm -qa | grep tomcat

The output from a BIG-IP system running BIG-IP 14.0.0 appears similar to the following example:

tomcat-7.0.76-1.0.0.2187.noarch

The numeric value after the first dash ( - ) indicates the Tomcat software version is 7.0.76.

Example 2:

To find the MariaDB version, type the following command:

mysqld -V

The output from a BIG-IP system running BIG-IP 14.0.0 appears similar to the following example:

mysqld  Ver 5.5.53-MariaDB for Linux on i686 (MySQL Community Server (GPL))

The MariaDB version is 5.5.53.
