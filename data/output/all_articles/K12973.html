Known Issue

If you attempt to open an Adobe Acrobat document (PDF) with Adobe Acrobat Reader X in an APM Protected Workspace, the PDF document fails to open.

This issue occurs when all of the following conditions are met:

  • The APM system is configured to use the Protected Workspace action in an access policy.
  • The user is accessing a PDF document.

Impact

Users are unable to access PDF documents.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users may receive an error message that appears similar to the following:

    To run Acrobat in the Protected Workspace, you must close it in the default desktop.
    If you do, all unsaved changes will be lost.
    Do you want to close Acrobat in the default desktop?

  • Users may receive an error message that appears similar to the following:

    There is a problem with Adobe Acrobat/Reader.
    If it is running, please exit and try again.

  • User's browser may appear to freeze.

Workaround

To work around this issue, you can remove the Protected Workspace action from the access policy. To do so, perform the following procedure:

Impact of workaround: Removing the Protected Workspace action will remove the protective services that PWS provides.

Removing Protected Workspace from BIG-IP APM Access Policy

  1. Log in to the BIG-IP Configuration utility.
  2. Click Access Policy.
    The Access Policy navigation panel expands.
  3. Click Access Profiles.
    The Access Profiles List opens in the right pane.
  4. Click Edit... next to the name of the access policy you want to edit.
    The Visual Policy Editor opens in a new window.
  5. Click the x on the upper right corner of the Protected Workspace action.
    The Item deletion confirmation dialog opens.
  6. Click the Connect previous node to Successful branch option.

    Note: The Successful keyword is a drop-down menu. Make sure that you select, from the drop-down menu, the proper branch that you want to connect to the previous node.

  7. Click the Delete button.
  8. Click Apply Access Policy in the upper left corner.
  9. Click the Close button.
