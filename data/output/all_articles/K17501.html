Known Issue

The devmgmtd process may leak file descriptors, restart, and then produce a core file.

This issue occurs when the following condition is met:

  • You attempt to add a device to a trust by specifying a host name instead of an IP address, where the host name is not valid.

Specifying an invalid host name, when adding a device to a trust, can cause the system to leak a large number of file descriptors. If sufficient file descriptors are not available, the devmgmtd process restarts and produces a core file.

Impact

Attempts to add an additional device to a trust domain fail to complete.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Attempts to add an additional device to a trust domain fail.
  • The devmgmtd process restarts and logs error messages similar to the following example:

    <error>[evConnection.cpp:152 tryConnect] fd: Too many open files</error>.

  • The devmgmtd process generates a core file in the /var/core directory.
