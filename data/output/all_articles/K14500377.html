Topic

You should consider using this procedure under the following condition:

  • You want to use F5 vendor-specific attributes (VSA) when configuring remote TACACS+ authentication in VELOS.

Description

The VELOS platform supports Vendor Specific Attributes, VSAs for use with TACACS+ remote authentication. The following lists the VELOS VSAs:

  • F5-VELOS-UID: A unique ID that defaults to 1001.
  • F5-VELOS-GID: Enter the following command on the system controller or chassis partition as appropriate to display a list of the different roles.

    show system aaa authentication roles

  • F5-VELOS-HOMEDIR: The home directory for the user. Set to /tmp to avoid sshd warning messages.
  • F5-VELOS-USERINFO: A user defined comment field. This can appear in log files such as /var/log/secure.

For more information about the VSAs and the full description of the different different user roles available in VELOS, refer to the User Management chapter of the VELOS Systems: Administration and Configuration manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to your VELOS system.
  • You have administrative access to the TACACS+ server.
  • The VELOS system management interface has network connectivity to the TACACS+ server.
  • You have TACACS+ installed and running on the TACACS+ server.

Procedures

  • Configure user accounts on the TACACS+ server
  • Configure VELOS to use remote TACACS+ authentication
  • Configure VELOS with the TACACS+ server details

Configure user accounts on the TACACS+ server

To use the VELOS VSAs, you must add the user and group accounts in the tac_plus.conf file. The example in this procedure creates the following remote TACACS+ users and groups. 

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to your TACACS+ server.
  2. Create the users ann, john, and bob on your TACACS+ server. In this example, you add users to the local /etc/passwd file.

    Note: On most Linux operating systems, OS, you can use the commands useradd to add users and passwd to set the passwords. For more information, refer to your specific OS documentation to create local users.

  3. Edit the TACACS+  default authentication attribute to use /etc/passwd in the tac_plus.conf file.

    Note: You can also define your own user database with TACACS+ instead of using /etc/passwd. Refer to the TACACS+ server to define your own user database.

    # Use /etc/passwd file to do authentication
    default authentication = file /etc/passwd

  4. Include the following configuration code example in the tac_plus.conf file in your TACACS+ server:

    user = ann {
        name = "Admin User"
        member = "admin_group"
    }
    user = john {
        name = "Operator User"
        member = "operator_group"
    }
    user = bob {
        name = "Partition1 User"
        member = "partition1_group"
    }
    group = admin_group {
        service = ppp protocol = ip {
            default attribute=permit
            F5-VELOS-UID=1001
            F5-VELOS-GID=9000
            F5-VELOS-HOMEDIR=/tmp
            F5-VELOS-USERINFO=velos_admin_user  #Comments
        }
    }
    group = operator_group {
        service = ppp protocol = ip {
            default attribute=permit
            F5-VELOS-UID=1002
            F5-VELOS-GID=9001
            F5-VELOS-HOMEDIR=/tmp
            F5-VELOS-USERINFO=operator_group_users  #Comments
        }
    }
    group = partition1_group {
        service = ppp protocol = ip {
            default attribute=permit
            F5-VELOS-UID=1003
            F5-VELOS-GID=9101
            F5-VELOS-HOMEDIR=/tmp
            F5-VELOS-USERINFO=partition1_group_users  #Comments
        }
    }

  5. Check the syntax of the tac_plus.conf file by entering the following command:

    Note: Depending on your TACACS+ installation, the command may vary. Refer to your TACACS+ and server documentation for more information.

    service tacacs_plus check

  6. Restart the TACACS+ server by entering the following command:

    Note: Depending on your TACACS+ installation, the command may vary. Refer to your TACACS+ and server documentation for more information.

    service tacacs_plus restart

Configure VELOS to use remote TACACS+ authentication.

Perform the following procedure on either the VELOS system controller or partition as appropriate to configure remote TACACS+ authentication.

Impact of procedure: The following procedure should not have a negative impact on your system.

Note: To perform this procedure on the CLI, refer to the User Management chapter of the VELOS Systems: Administration and Configuration manual.

For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

  1. Log in as administrator to the VELOS system controller webUI or partition webUI as appropriate.
  2. Go to USER MANAGEMENT > Auth Settings.
  3. Under Authentication Methods, for Enable, select TACACS.
  4. Select Save.
  5. Select Ok.

Configure VELOS with the TACACS+ server details.

Perform the following procedure on either the VELOS system controller or partition as appropriate to configure remote TACACS+ authentication.

Impact of procedure: The following procedure should not have a negative impact on your system.

Note: To perform this procedure on the CLI, refer to the User Management chapter of the VELOS Systems: Administration and Configuration manual.

For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

  1. Log in as administrator to the VELOS system controller webUI or partition webUI as appropriate.
  2. Go to USER MANAGEMENT > Server Groups.
  3. Select Add.
  4. For Name, give your group of TACACS+ servers a name.

    For example:

    tacacs-group

  5. For Provider Type, select TACACS.
  6. Select the name of your new server group.
  7. Select Add.
  8. For Server, enter your TACACS+ server IP address.
  9. For Secret, enter the secret configured in your TACACS+ server

    Note: You can locate the value of Secret in the tac_plus.conf file by referring to the key attribute.

  10. Leave the Source Address field empty
  11. Select Save & Close.

Troubleshooting

When troubleshooting, refer to the following log files on the VELOS system to review your login attempts:

  • /var/log/audit/audit.log
  • /var/log/messages
  • /var/log/secure
