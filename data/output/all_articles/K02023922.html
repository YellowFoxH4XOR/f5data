K02023922: After upgrading valid requests started to get blocked by attack signatures on authorization header

Type
Support Solution
Published
2022-11-08
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.X.X, 16.0.1, 16.0.0, 15.1.7, 15.1.6, 15.1.5, 17.0.0, 16.X.X, 16.1.2, 16.1.1, 16.1.0, 16.1.3, 17.0.X, 16.1.X, 16.0.X, 15.1.8
Source
https://my.f5.com/manage/s/article/K02023922

Description

  • Valid requests started to get blocked by attack signatures on authorization header scope
  • The following signature IDs could be triggered as false positive  (200018063, 200018064, 20000323)

Environment

  • ASM
  • Attack signature
  • JWT token
  • Authorization header

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1106937

Recommended Actions

At the time of creation of this article there is no fix available on stable releases but an EngHF with the fix can be provided. As a workaround you can disable attack signatures in question on authorization header

Additional Information

None
