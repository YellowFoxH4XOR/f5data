Known Issue

Note: This Solution only affects the BIG-IP LTM 8400 and 8800 platforms.

This is the result of a known issue. The XFP/SFP port may fail to register the XFP/SFP module if the module is removed and then reinstalled. As a result, the bcm56xxd process behaves as though the module is missing or the module information is incorrect, which causes bcm56xxd to set the media option for the XFP to none.

When the port belongs to a trunk, the lacpd process behaves as though the port's media speed option is set to 0 (zero), which makes the trunk port unusable.

F5 Networks Product Development tracked this issue as CR77947, and it was fixed in the BIG-IP LTM versions 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
