K85147845: ''General database error retrieving information'' alert on GUI when accessing ''Memory'' on Module Statistics

Source

Description

The BIG-IP's user interface does not access the memory statistics screen when navigating to Module Statistics >> Memory , presenting the message "General database error retrieving information".

Important: There are multiple reasons as to why you may see this database error when browsing the GUI. Unless this article fits your case exactly, it is recommended to start with General Database Error Retrieving Information in the BIG-IP Configuration Utility , which helps you discover the right article for you.

Environment

  • BIG-IP
  • AVR module provisioned

Cause

At the moment the cause is unknown.

Recommended Actions

There are two actions you can take to mitigate this issue:

1. Restarting the mcpd process

Impact of workaround: Traffic processing is temporarily interrupted during an mcpd restart and may trigger a failover if the device is the active member in the high-availability configuration. You should perform this procedure during a maintenance window.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:
    tmsh
  2. Restart the mcpd process by typing the following command:
    restart /sys service mcpd

2. Forcing the mcpd process to reload the configuration

  1. Instructions on how to forceload the mcpd process can be found in this article: K13030: Forcing the mcpd process to reload the BIG-IP configuration
