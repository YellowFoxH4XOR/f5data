Issue

Error Message

warning tmm[<pid>]: 01490547:4: Access Profile <name>: Per IP in-progress sessions limit (<#>) exceeded for <IP_address>

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process
  • <name> is the name and partition of the Access Profile
  • <#> is the configured limit for Max In Progress Sessions Per Client IP setting in the Access Profile. The default value is 128.
  • <IP_address> is the client IP address exceeding the limit

For example:

warning tmm3[13229]: 01490547:4: Access Profile /Common/access_example: Per IP in-progress sessions limit (128) exceeded for 10.10.10.10

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file
Description

This message occurs when the following condition is met:

  • The number of sessions in progress for a single client IP address exceeds the value configured for the Max In Progress Sessions Per Client IP setting in the access profile.

This can occur when clients reach the BIG-IP APM system through a device performing a source network address translation (SNAT). A single source IP address may be used by many different clients to access the BIG-IP APM system.

When this issue occurs, the client's browser may display a This site can't be reached or Page can't be reached message.

Impact

You are unable to establish the session with the BIG-IP APM system.

Recommended Actions

To work around this issue, depending on your environment, you can increase the value for the Max In Progress Sessions Per Client IP setting. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Profiles:

    13.0.0 and later

    Access > Profiles/Policies

    11.x - 12.x

    Access Policy > Access Profiles

  3. Click on the name of the access profile.
  4. In the Properties tab, under Settings, modify the value for the Max In Progress Sessions Per Client IP setting.
  5. Click Update
