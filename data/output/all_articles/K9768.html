K9768: The Toggle Scrollbar option does not appear in the Terminal Server favorite window when using Firefox

Topic

When a user launches a Microsoft Terminal Server or Citrix MetaFrame Browser Terminal Server favorite using Firefox, and the Terminal Server favorite is configured to open in a new browser window, the Toggle Scrollbar option does not appear in the upper right corner of the Terminal Server favorite window. This behavior occurs due to the way Firefox handles the document.body.scroll DOM event; it is not due to an issue with FirePass. Firefox automatically adds a scrollbar if the size of the terminal window is larger than the size of the browser window. 

Note: The Toggle Scrollbar option was introduced in FirePass version 6.0.2.
