Known Issue

This is the result of a known issue. The TMM process can crash if a BIG-IP LTM virtual server with ramcache enabled receives one of the following Cache-control header directives with an empty value:

  • max-age
  • max-stale
  • min-fresh

F5 Product Development tracked this issue as CR77684, and it was fixed in BIG-IP LTM 9.1.3, 9.3, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM release notes.
