Topic

The BIG-IP 8950 and 11050 platforms have multiple processing cores that support Clustered Multiprocessing (CMP). If you disable CMP globally on the BIG-IP 8950 or 11050 platforms by configuring the BIG-IP database key Provision.tmmCount setting to one (1), the Traffic Management Microkernel (TMM) crashes with the SIGSEGV signal. This issue occurs because the BIG-IP 8950 and 11050 platforms do not support disabling CMP globally.

Workaround

You can work around this limitation by disabling CMP for each virtual server. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Disable CMP on a virtual server by typing the following command:

    tmsh modify ltm virtual <virtual server name> cmp-enabled no

    For example:

    tmsh modify ltm virtual my_cmp_vs cmp-enabled no

  3. Repeat step 2 for the remaining virtual servers on which you would like to disable CMP.
  4. Save the changes by typing the following command:

    tmsh save sys config
