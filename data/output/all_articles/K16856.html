Known Issue

The BIG-IP 5200 series platform does not forward Bridge Protocol Data Units (BPDUs) when the spanning tree mode is set to Pass Through.

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP 5200 series platform.
  • You have configured the spanning tree protocol (STP) on the BIG-IP system.
  • The spanning tree mode option is set to Pass Through, which is the default value.
  • You have configured VLAN groups on the BIG-IP system.
  • The Bridge All Traffic VLAN group option is enabled. Disabled is the default value.

Impact

STP topology change information may not be communicated to all STP peers.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When inspecting packet captures, the BIG-IP system does not send any BPDU frames.
