K8685: Renaming HTTP classes and BIG-IP ASM web applications

Topic

The BIG-IP ASM system does not support renaming an HTTP class or the corresponding web application. When an HTTP class is created, a web application of the same name will be created automatically. Any attempt to rename an HTTP class or web application will prevent the two objects from communicating with each other. Additionally, attempting to rename the object will prevent that object from being associated or used by another class or application.

If you want to rename an HTTP class or web application, F5 Networks recommends that you create a new HTTP class and web application, then import the information from the desired web application to the newly created web application.

Note: Forensics (versions prior to 9.4.2) or Learning (versions 9.4.2 and later) data cannot be transferred to the new BIG-IP ASM web application. F5 Networks recommends that you create a final security policy (or policies if the end-goal is to split the BIG-IP ASM web application into multiple components) in the original BIG-IP ASM web application, then export and import it into the newly created BIG-IP ASM web application.

For information about creating a new security or HTTP class and web application, refer to the Essential Configuration Tasks section of the Configuration Guide for BIG-IP Application Security Management.

For information about exporting and importing security policies, refer to the Working with the Security Policy section of the Configuration Guide for BIG-IP Application Security Management.
