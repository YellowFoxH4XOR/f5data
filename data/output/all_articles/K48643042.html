Description

cpu and tmmCpu values reported by the Telemetry Streaming extension do not match the CPU graphs in the GUI. Typically, the values reported by Telemetry are lower.

Environment

  • Telemetry Streaming
  • CPU
  • Graphs

Cause

The values reported by telemetry represent the following:

cpu - One minute of average system usage, or utilization at the kernel level.

tmmCpu - One minute average of TMM usage.

GUI CPU utilization graphs show aggregated CPU usage and will not directly correlate with these Telemetry values. This is expected behaviour.

Recommended Actions

You may review current system usage at the command line with the following command:

show /sys cpu
