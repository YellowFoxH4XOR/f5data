K000137163: Error in CWC: Failed to publish the message. Fai led to open channel when trying to connect to RabbitMQ

Description

  • This issue can happen in either of the below scenarios:
    • Both pods, the one for RabbitMQ and the one for CWC, are restarted.
    • Or, when only the pod for RabbitMQ is restarted.
  • In the file f5-spk-cwc.log, you will see either or both of these errors:

Error publishing heartbeat message. Failed to open channel

or,

 Failed to publish the message. Failed to open channel

 

Environment

  • SPK 1.7.x or older versions
  • the pod for RabbitMQ is restarted
  • Race condition between RabbitMQ and CWC

Cause

In SPK v1.7.x and older, there is a race condition between RabbitMQ and CWC. RabbitMQ must start before CWC

 Recommended Actions

If the pod for RabbitMQ started later than CWC, restart CWC again. The goal is that RabbitMW must be running before CWC finish starting.

 

Additional Information

This race condition is fixed in v1.8.0
