Topic

The default administrative password is admin. To reset the FirePass administrative password to the default setting, perform the following procedure:

Note: Depending on your version of FirePass, you may see minor differences in the wording of these menu items or the inclusion of additional text screens. However, the basic sequence of this procedure remains the same.

  1. Connect a workstation to the serial port of the FirePass controller using a null-modem cable.

    Important: A null-modem cable is required for the serial connection. Other types of cables ,such as crossover or rollover cables, will not work.

  2. Configure a communications program, such as HyperTerminal or XTerm, using the following settings:
    • Baud rate: 19200
    • Data bits: 8
    • Parity: none
    • Stop bits: 1
    • Flow control: hardware
  3. Start the serial connection.

    The screen changes to show a logon prompt.

  4. At the logon prompt, type maintenance.
  5. Review the conditions and press Enter to continue.

    A screen of maintenance options opens.

  6. Select option 1: Reset FirePass settings and/or admin password.
  7. Select option 2: Reset admin password only.
  8. If you receive the following prompt:

    Reset FirePass admin password to default value? (default - no):

    Type yes, and then press Enter to continue.

  9. Select option 0: Return to main menu.
  10. Select option 0: Exit.
