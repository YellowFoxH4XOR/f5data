Issue

Description

A pool member IP address changed and the you must update a BIG-IP LTM pool to use the new IP address.

Environment

  • Server IP address changed
  • Pool with old IP address

Cause

None

Recommended Actions

If a pool member IP address changes, you must create a pool member using the new IP address and optionally delete the unwanted pool member and node.

If the node is a pool member in multiple pools, and you have to repeat the aforementioned configuration changes numerous times, you may want to automate the work using the script in K000137953: Automate updating IP address of BIG-IP poolmember.

Impact: None. Performing this procedure removes the node and pool member configuration which is no longer used.

  • Adding a pool member to the existing pool to reflect the new IP address
  • Removing the old pool member from the existing pool
  • Deleting the old node object

Adding a pool member to the existing pool to reflect the new IP address

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Pools > Pool List.
  3. Click the pool with the member you want to change.
  4. Click the Members tab.
  5. Click Add.
  6. Enter the configuration you want and click Finished.
    Note: When choose the New Address option, the system automatically adds the pool member and corresponding node object.

Removing the old pool member from the existing pool

  1. Navigate to Local Traffic > Pools > Pool List.
  2. Click the pool with the member you want to delete.
  3. Click the Members tab.
  4. Select the check box next to the pool member you want to delete.
  5. Click Remove.

Deleting the old node object

  1. Navigate to Local Traffic > Nodes.
  2. Select the check box next to the node with the previous IP address.
  3. Click Delete.

Additional Information

For more information about nodes and pools, refer to the help section within the node list and the pool list or the About Pools or About Nodes chapters of the BIG-IP Local Traffic Management: Basics manual.
