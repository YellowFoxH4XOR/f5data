Known Issue

This is a result of a known issue. A denial of service attack using reset (RST) packets on a BIG-IP 8400 or 8800 platform running version 9.4.1 causes the BIG-IP system to report a surge in new connections and throughput in the performance graphs.

This behavior should not occur since RST packets are dropped and not entered into the connection table; the surge should not be reported in new connections and throughput.

F5 Product Development tracked this issue as CR82834, and it was fixed in BIG-IP LTM 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, Hotfix-BIGIP-9.4.1-HF1 has been issued for BIG-IP LTM 9.4.1. You may download this hotfix or later versions of this hotfix from the F5 Downloads page.
