Known Issue

This is the result of a known issue. The hotfix uninstall script generates a message that contains incorrect instructions for legacy BIG-IP switch platforms. The hotfix uninstall script generates the following post message upon completion:

!NOTICE!
This hotfix may not be operational without a FULL
system restart. The "bigstart restart" and "reboot"
commands are NOT necessarily sufficient.
To accomplish this, use the following command:
"touch /.sccp_hard_reboot ; reboot". This will cleanly
shut down the host system, following which the sccp will
reboot. Once the sccp has finished booting, the host
will also boot back up.
This is described in SOL 5471.

The message incorrectly instructs you to run the touch /.sccp_hard_reboot ; reboot command to shut down the BIG-IP host subsystem and SCCP. The command should not be run on the following legacy BIG-IP switch platforms as they do not contain an SCCP:

  • BIG-IP 1000 (D39)
  • BIG-IP 2400 (D44)
  • BIG-IP 5100 and 5110 (D51)

F5 Product Development tracked this issue as CR60724 and it was fixed in versions 9.1.2 and 9.3.0. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, or Link Controller release notes.
