Issue

Error Message

notice sod[<PID>]: 010c008b:5: Unable to send to unreachable unicast address <IP_address> port <port_number>.

In this error message, note the following:

  • <PID> is the process ID for the sod process.
  • <IP_address> is the network failover unicast IP address.
  • <port_number> is the port number being used with the unicast IP address.

For example:

notice sod[8484]: 010c008b:5: Unable to send to unreachable unicast address 10.10.10.84 port 1026.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The sod process fails to find an available route to send network failover packets to the peer devices in the Device Service Cluster (DSC).

Impact

The devices in the DSC may take over the active role in the traffic group due to the lack of heartbeat packets received from peers.

Recommended Actions

If the change of failover status is unexpected, you should verify the network connectivity between the devices in the DSC, and review the network failover status and settings. For information about troubleshooting unexpected network failover, refer to K75975904: Troubleshooting network failover.
