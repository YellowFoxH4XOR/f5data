Known Issue

Secure renegotiation is set while data is not available, which may cause the Traffic Management Microkernel (TMM) to produce a core file in certain connections.

This issue occurs when the following condition is met:

  • The BIG-IP system is in the process of handling Secure Sockets Layer (SSL) secure renegotiation in certain connections.

Impact

Traffic is disrupted while the TMM process produces a core file and restarts. Systems configured as part of a high availability (HA) device group may fail over to a peer device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process generates a core file to the /shared/core directory.
  • Your BIG-IP system generates a SIGSEGV error message in the /var/log/tmm log file.
