Description
This error message gets logged when the ASM policy referenced does not exists. Most of the time, the partition name is not specified.

In an irule, a line below will produce this error:

  ASM::enable "myDefaultPolicy"

Error Message

Error Message:  01310012:6: ASM bad request: event code <event code> Request has an unknown HTTP selector: <ASM policy>
In this error message, note the following:
  • <event code> is the the event code:
              v12.x -  I3796
              v13.x -  I3948
              v14.x -  I4002
  • <ASM policy> is the name of the ASM policy.
For example:
 v12.x  -  01310012:6: ASM bad request: event code I3796 Request has an unknown HTTP selector: myDefaultPolicy
 v13.x  -  01310012:6: ASM bad request: event code I3948 Request has an unknown HTTP selector: myDefaultPolicy
 v14.x  -  01310012:6: ASM bad request: event code I4002 Request has an unknown HTTP selector: myDefaultPolicy

You may encounter this message in the following location:
  • The /var/log/asm file

Due to this error, connection will be reset.

Environment

  • BIG-IP ASM
  • iRule 
  • Missing Partition Name

Cause
Either the ASM policy does not exist or the partition name is not specified.

Recommended Actions

Verify if the referenced ASM policy exists. May need to include the partition name as shown below:

ASM::enable "/Common/myDefaultPolicy"
