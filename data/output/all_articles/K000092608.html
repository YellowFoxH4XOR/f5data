K000092608: Error reported (giants) on interface connected to BIG-IP

Type
Support Solution
Published
2022-11-12
Updated
2022-11-12
Source
https://my.f5.com/manage/s/article/K000092608

Description

You began seeing performance (throughput) issues and you have noticed that the next hop switch or router is reporting errors (giants) on the interface connected to BIG-IP. 
 

Sample snippet from Cisco switch:
3692782 unicast packets 6 multicast packets 0 broadcast packets
3692794 input packets 2639328491 bytes
1019750 jumbo packets 0 storm suppression bytes
0 runts 6 giants 0 CRC 0 no buffer      <<-----
 

Additionally, you may see logs same as below:
Oct 29 00:18:22 LTM1.example.com warning tmsh[20522]: 01420013:4: [api-status-warning] ltm/profile/tcp, properties : deprecated : hardware-syn-cookie

 

Environment

  • BIG-IP connected to a switch or a router
  • Hardware-syn-cookie enabled
     

Cause

The hardware-syn-cookie and software-syn-cookie protection options are no longer valid. You can use the syn-cookie-enable option for either hardware or software SYN cookie protection.

 

Recommended Actions

Hardware or software SYN cookie protection can be used in the TCP and FastL4 profiles. Based on the above logs, the error is for TCP.
 

Use the command below to find the TCP profile that has hardware-syn-cookie enabled.
tmsh -c 'cd /; list ltm profile tcp one-line recursive' 2>/dev/null | grep 'hardware-syn-cookie enabled'


Base on the output and upon further checking, this is one of the TCP profiles with hardware-syn-cookie enabled.
ltm profile tcp /Common/sample-tcp-wan {
fin-wait-timeout 5
hardware-syn-cookie enabled      <<-----
idle-timeout 300

Disable the hardware-syn-cookie for all affected profiles.
tmsh modify ltm profile tcp <profile_name> hardware-syn-cookie disabled
