K11254: The pre-logon sequence does not populate the session.ssl.cert.ou session variable with the client SSL certificate OU data

Known Issue

This is the result of a known issue. When you create a pre-logon sequence action of type Check client certificate, the session.ssl.cert.ou session variable is not populated from the client certificate. This behavior will cause a pre-logon check that attempts to perform a comparison of the session.ssl.cert.ou to fail. You can configure pre-logon sequences on the Users: Endpoint Security: Pre-Logon Sequence page.

Note: For FirePass version 6.0.3, this issue occurs after installing hotfix HF-603-5.1 or a later version of the cumulative hotfix.

Note: For information about configuring client certificate authentication refer to K8392: Configuring passwordless authentication using client certificates

F5 Product Development tracked this issue as ID 317717 (formerly CR137181) and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue has been fixed in cumulative hotfix HF-610-2, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about downloading software from F5, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

You can work around this issue by removing all references to the session.ssl.cert.ou session variable from your pre-logon sequences.
