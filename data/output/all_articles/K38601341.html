Topic

This article provides basic guidance for performing advanced customizations on your BIG-IP APM system when you are planning to upgrade.

Description

Using the advanced customization view in the Configuration utility allows you to edit webpage files directly to change the text, language, and appearance of the user interface.

  • When you make modifications using the advanced customization view, the files you modify may not receive the same upgrade as the default files. They may not contain potential new code releases or enhancements associated with the new BIG-IP version.
  • In some cases, the upgrade may make changes to modified files in order to support browser rendering changes with other updates in BIG-IP versions. For example, beginning in BIG-IP APM 14.0.0, resources appear as tiles on the webtop. To enable this new feature, BIG-IP APM advanced customization files apm_full.css, apm_mobile.css, and apm_edge.css are modified during the upgrade process to BIG-IP APM 14.0.0. This modification adds the required CSS elements needed by the new feature, and other files, such as logon.inc, decision_box.inc, confirm_box.inc, message_box.inc, oauth_authz.inc, are also updated to reflect internal changes pertaining to JavaScript implementation.
  • Customizations made by modifying specific files in the Unix file system through the command-line interface may not persist after an upgrade and are not recommended.
  • Images you specify through the advanced customization view are managed with the parent object and persist with the parent object through backup and upgrade procedures.

Recommendations

When planning for an upgrade, consider the following factors:

Note:

Advanced customization provides greater flexibility to the look and feel of webpages. However, the upgrade process cannot cater to all customizations since features or variables may be deprecated or changed. F5 recommends that you perform a backup first and test all customizations after the upgrade.

  • You should perform all customizations through advanced customization view in the Configuration utility.
  • You should use the Advanced Customization templates in DevCentral when customizing BIG-IP APM pages for users.
  • Because the files you modify through the advanced customization view do not receive the full upgrade, ensure that the new code releases or enhancements associated with the new BIG-IP version are not required.
  • If you require new code releases or enhancements in your customizations, you can manually upgrade each file by running the diff command to identify the new code before manually adding the files. Alternatively, if your customizations are minor, you can perform the upgrade and create a new access policy, which contains the latest updates. You can then add your customizations to the files in the new access policy.
