Known Issue

This is the result of a known issue. If an HTTP request contains only a partial command, BIG-IP fails to perform a header insert. This issue generally does not occur with normal traffic, but can occur if the client's system uses a Windows® Telnet client, because the Windows® Telnet client sends data character-by-character, rather than as a single request.

F5 Networks Product Development tracked this issue as CR40826 and CR41785, and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the BIG-IP version 4.6 software branch.
