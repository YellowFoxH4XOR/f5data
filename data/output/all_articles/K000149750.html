Description

Virtual server is with access policy for only authentication purpose: LTM+APM type. User has no issue with authentication.

However when user access to the site through inTune, client get message like:

To access to this size, it is required to use Microsoft Edge browser

iPhone is set MS Edge Browser as default browser.

BIG-IP is not configured to reject by the type of browser, and to return such error message.


When accessing MS Edge Browser on iPhone, there is no issue to access to the site.

 

Environment

  • BIG-IP APM
  • LTM+APM
  • iPhone
  • inTune

 

Cause

  • inTune use Safari to access to the portal
  • The portal has limitation for the type of browser.

 

Recommended Actions

You may be able to use OSA script to make sure access to this site is always done through MS Edge browser.

Also seek assistance for inTune side can be configured to use MS Edge Browser.

 

Additional Information

If you still have doubt on BIG-IP behavior, you can take tcpdump 

  • K31793632: Creating a decrypted tcpdump capture without using an iRule
  • DevCentral: Decrypting TLS traffic on BIG-IP

Or use iRule:

  • You will need to know the user agent of the MS Edge on iPhone (e.g. Search on Google "my user agent", then it provide you the user agent) then replace <User-Agent_string> to the user agent, also customize TYPE_YOUR_CUSTOM_TITLE and TYPE_YOUR_CUSTOM_MESSAGE to make sure the iRule is producing the error than the website.
when HTTP_REQUEST {
   if { [HTTP::header "User-Agent"] != "<User-Agent_string>" }{
      HTTP::respond 200 content {
         <html>
            <head>
               <title>TYPE_YOUR_CUSTOM_TITLE</title>
            </head>
         <body>
            TYPE_YOUR_CUSTOM_MESSAGE
         </body>
      </html>
   }
}
