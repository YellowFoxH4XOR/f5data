Description

In BIG-IP DNS Express setup where BIG-IP gets zone updates from more than one Primary DNS server, you may see below errors on the Secondary BIG-IP.  The generated messages are a result of DNS Express caching a newer Serial for a zone than the record located on the DNS server.

/var/log/ltm:
err zxfrd[7923]: 0153100c:3: Failed on receive of <x> bytes for transfer of zone <zone_name> (Orderly shutdown), 0 bytes were received.
err zxfrd[7923]: 01531018:3: Failed to transfer zone <zone_name> from <primary_dns_ip_address>, will attempt AXFR.
 
In later software versions eg. v15 you will see the following  message:
 
     err zxfrd[5340]: 0153102f:3: Timed out waiting for transfer data for zone <zone_name>


You may review traffic using a packet capture tool such as tcpdump and verify if the serial numbers in the response packets are different.

For example:
192.168.10.10 → 192.168.10.11  20920 53 DNS OUT s1/tmm1 : Standard query 0x031f IXFR support.f5.com SOA rootdns01.support.f5.com TSIG
192.168.10.11 → 192.168.10.10  53 20920 DNS IN  s1/tmm1 : Standard query response 0x031f IXFR support.f5.com SOA rootdns01.support.f5.com TSIG
192.168.10.10 → 192.168.10.12  20950 53 DNS OUT s1/tmm1 : Standard query 0x3335 IXFR support.f5.com SOA rootdns01.support.f5.com TSIG
192.168.10.12 → 192.168.10.10  53 20950 DNS IN  s1/tmm1 : Standard query response 0x3335 IXFR support.f5.com SOA rootdns01.support.f5.com TSIG

Use the follow command to verify the DNS Express cached Serial for the zone:

tmsh show ltm dns zone example.com | grep Serial

Environment
  • BIG-IP DNS Express
  • DNS Express cached serial is newer than on DNS server
Cause

DNS Express is unable to update a zone record with a numerically lower Serial than the one already cached.

Recommended Actions

Resolve any conflicts with Zone Serial if multiple DNS servers are used.

DNS express cache files can be removed, forcing zxfrd to pull the entire zone using an AXFR request. To do so, use the following commands, in sequence:

bigstart stop zxfrd
rm -rf /shared/zxfrd/*
bigstart start zxfrd

Note: DNS express will not be able to service DNS responses until the zone transfers have completed. For this reason, this procedure should be carried out on the standby device, if possible.

 

Additional Information

As per RFC1912, if a Secondary DNS server gets updates from multiple Primary DNS Servers, all Primary Servers should have same serial number.
