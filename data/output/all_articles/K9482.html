Issue

Starting in FirePass 6.0.3 with cumulative hotfix HF-603-1, the Prohibit routing table changes during Network Access connection setting now supports Linux clients. Previously, this setting only supported Windows clients.

The Prohibit routing table changes during Network Access connection check box is located under the Policy Checks tab on the Network Access : Resources page. Enabling this setting prevents modifications to the client's IP routing table while the Network Access connection is active.
 
F5 Product Development tracked this enhancement as CR106893 and it was included starting in cumulative hotfix HF-603-1 for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
