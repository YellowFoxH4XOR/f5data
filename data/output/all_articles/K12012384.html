Known Issue

Windows functionality within a Protected Workspace access session may be impacted.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an access policy that uses Windows Protected Workspace (PWS).
  • The Windows device used to establish access session has Norton Internet Security 22.x installed.

Impact

Windows functionality is impacted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Devices in a PWS access session are unable to launch the Internet Explorer and Firefox browsers.
  • Devices in a PWS access session are unable to use Microsoft OneDrive features.
