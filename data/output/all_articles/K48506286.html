Description
After setting the Sync type of Device Group datasync-global-dg   to Automatic, the change is reverted to Manual.

Environment

  • BIG-IP
  • ASM provisioned

Cause

By design.
datasync-global-dg  must be Manual, however the dialog doesn't prompt with a message and silently reverts the change.

Recommended Actions

  1. None. It is as designed.

Additional Information

Some older versions may have let it be set to Automatic. After an upgrade you may find this is silently corrected
