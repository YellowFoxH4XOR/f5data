You should consider using this procedure under the following conditions:

  • You need to identify the master directories.
  • You need to change the location of the master directories.

The master directory is the primary CIFS directory on the imported shares that the ARX system uses for the default file location and CIFS attribute data. You can change the directory after the ARX system has completed an import using a promote directory policy.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have administrative rights on the ARX system
  • Have multiple shares imported as one VIP on the ARX system

Procedures

Impact of procedure: None

Changing the master directory

 

To configure the ARX system to use a different share as the root backing share, perform the following procedure:

Impact of procedure: None

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. Enter global configuration mode by typing the following command:

    global

  4. Enter namespace configuration mode by using the following command syntax:

    namespace <namespace>

    For example:

    namespace ns1

  5. Enter volume configuration mode by using the following command syntax:

    volume <volume>

    For example:

    volume /vol1

    You are now in gbl-ns-vol mode.
  6. Configure a new filename fileset named policy-filename-fileset by typing the following command:

    filename-fileset promote-directories-fileset

  7. At the Create object 'promote-directories-fileset'? [yes/no] prompt, type the following:

    yes

    You are now in gbl-ns-vol-fs mode.
  8. Configure the fileset to ignore the naming case by typing the following command:

    name match * ignore-case

  9. Exit the fileset configuration mode by typing the following command:

    exit

  10. Configure a new fileset placement policy rule named promote-directory by typing the following command:

    place-rule promote-directory

  11. At the Create object 'promote-directories'? [yes/no] prompt, type the following:

    yes

    You are now in gbl-ns-vol-plc mode.
  12. Configure the promote-directories placement rule to use the fileset promote-directories-fileset as a source, matching directories only, and enabling directory promotion, by typing the following command:

     from fileset promote-directories-fileset match directories promote-directories

  13. Configure the promote-directories placement rule's target to be the new master directory share by using the following command syntax. Replace <share_name> with the name of the share you want to be the new master directories share:

    target share <share_name>

    For example:

    target share share2

  14. Configure the promote-root placement rule's report prefix to be promote-root by typing the following command:

    report promote-directories verbose

  15. Enable the promote-directories placement rule by typing the following command:

    enable

  16. Exit the placement rule configuration mode by typing the following command:

    exit

  17. Monitor the status of the promote-root placement rule by typing the following command:

    show policy

    When the promote-directories placement rule has completed, the output of the show policy command appears similar to the following example:

                                                             Status
    Namespace      Volume         Rule              Vol. Scan     Migration
    -------------  -------------  ----------------  ---------------------------
    ns1            /vol1          promote-directories      Complete      Complete

  18. Exit the gbl-ns-vol configuration mode and return to privileged mode by typing the following command:

    end
