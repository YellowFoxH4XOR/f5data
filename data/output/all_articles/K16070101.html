Description

In mid 2025, Apple announced that it will no longer be supporting the Intel architecture with its future MacOS releases, and that the recently released MacOS 26 (Tahoe) would be that last version to incorporate the Rosetta translation features to allow support of older Intel based products. APMClient since 7.2.6 has supported Apple Native ARM64 x86-64 devices.

On 15 October 2025 F5 released APMClient 7.2.6.1 with new feature updates for MacOS 26 and Windows Edge Client updates.
F5 recommends all APN VPN users upgrade to this release.
https://techdocs.f5.com/kb/en-us/products/big-ip_apm/releasenotes/related/relnote-edge-client-7-2-6-1.html
Legacy solutions based on MacOS can continue to use supported BIG-IP Edge Client, but future deployments are recommended to migrate to F5Access

On the MyF5 download pages you can access these by first selecting BIG-IP and then APM Client, APM EPSEC or BIG-IP as applicable.

Note that after upgrading any base BIG-IP release (like a QSN upgrade), the version for APMClient may need to be reset to 7.2.6.1 on your APM as changing the base release will reset to the original bundled version.

Environment

BIG-IP APM access deployments for VPN connectivity, the APMClient ISO releases contain components for:

  • Windows Edge Client
  • MacOS Edge Client
  • F5 Access for MacOS (7.2.6.1 this can also be directly downloaded on MyF5)
  • Web-browser helper apps (VPN.app and Endpoint Inspection.app)
  • Mobile Clients can be directly dowloaded from the appropriate App Store 

CauseF5 regularly updates the features and security of components.

Recommended Actions

During any software beta period, if you observe changes of F5 functionality, these should be reported in the first instance to Apple, Please also report them to F5 Support, so we can evaluate these issues with our testing.

Support requests can be opened for any current released OS platform (for example, not a beta version).
As soon as a new version is released, these versions are supported by F5; however, it is recommended that you wait for the results of F5 compatibility testing and perform local testing to confirm your particular use case is not affected.

F5 recommends performing tests on the most recent release, as new features are not updated in older releases. You should have test/development environments such that you can stage testing of vendor updates and upgrades without affecting your production networks. F5 testing may not cover specific customer deployment combinations.

F5 performs compatibility testing after the release of Major versions. For the official F5 support policy, refer to K22258530: APM Client software lifecycle support policy.
Once an OS platform release is no longer receiving security updates, the release is considered end of F5 support and will only receive configuration support.
