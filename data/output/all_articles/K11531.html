Known Issue

This is the result of a known issue. The BIG-IP APM web application rewriter does not support more than 8KB in the buffers. As a result, when a web application user accesses a website that contains more than 8KB of style or script tags in the HTML, the website may display duplicate or missing content.

F5 Product Development tracked this issue as CR132555 and was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP APM Release Notes.

Additionally, this issue has been fixed in cumulative hotfix BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
