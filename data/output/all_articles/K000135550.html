Description

When trying to open a category in Access >> Secure Web Gateway : URL Categories menu in the GUI, it keeps "loading from Database" and the category won't open. However, the category can be viewed from the TMSH.

There can also be accompanying issues, like some entries in the category are not working as expected.



Additionally, in at least one of the /var/log/tomcat/catalina.out log files, we can see the following Java error:


# java.lang.OutOfMemoryError: Java heap space


Environment

SWG

Tomcat provisioning set to "0" or a low amount

Cause

If the memory allocated to Tomcat is insufficient for the volume of requests it needs to handle or the complexity of the tasks, this error can occur.

Recommended Actions

Follow Error Message: java.lang.OutOfMemoryError (f5.com) in order to allocate more space for Tomcat. You can start with the recommended 50Mb and test - if this amount turns out to be insufficient, you can increase it further in steps, for example to 100, 250, and 500Mb.
