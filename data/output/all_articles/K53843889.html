Known Issue

The TMOS Shell (tmsh) may add resource pressure to the control plane when starting sessions.

This issue occurs when all of the following conditions are met:

  • Your system is running BIG-IP 13.1.0.8 or later.
  • Multiple users or remote processes connect to the BIG-IP system and start tmsh sessions.

Impact

The increase in resource use causes additional pressure on the control plane. As a result, you may experience delays when using tmsh or the Configuration utility. Extreme instances may cause one or more processes to terminate with a potentially disruptive effect. The risk of impact from this issue increases when a large number of automated tmsh sessions are created.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Responses from the Configuration utility or tmsh are slow or delayed.
  • Memory utilization on the BIG-IP system increases when users start tmsh sessions.
  • The BIG-IP system experiences out-of-memory conditions.

Workaround

To work around this issue, if you have administrative privileges and can use the bash, you can change the login shell to avoid invoking tmsh when it may not be needed. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the bash.
     
  2. Use the following syntax to change the login shell to use bash:

    tmsh modify /auth user <user_name> shell bash

    For example:

    tmsh modify /auth user test_user shell bash
