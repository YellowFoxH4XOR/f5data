Description

When you configure headercontent attack signature, you may find that the signature doesn't inspect the cookie header.

For example,

Attack Signature rule;
headercontent:"test"; nocase;

Send the request to VS that the above attack signature is applied.
# curl http://<VirtualServer> -H "Cookie: test"

In this case, this request is not detected as a violation by the above attack signature.
 

Environment

  • BIG-IP ASM
  • Create the attack signature using headercontent
  • Send violation request in Cookie header

Cause

It is by design.

Recommended Actions

If you would like to detect it, use content instead of headercontent.

For example, 
content:"test"; nocase;
