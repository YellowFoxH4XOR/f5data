K12070006: FQDN defined remote syslog server does not update IP address entry after DNS resolution expires or updates.

Description

When remote syslog configuration is set to use an FQDN hostname entry, it will not update to new ip address after DNS resolution TTL expires or resolves to different ip address.


Environment
  •     F5 BIG-IP
  •     Remote syslog configuration with FQDN hostname entry.
  •     DNS resolver

Cause

Syslog-ng  daemon, the same as all "syslogd" daemons in Unix/Linux environments is designed to do name resolution at "daemon instantiation" (when system starts or reboots) and will retain the initially resolved ip address despite DNS's TTL parameter or DNS resolving to any different ip address at a later time.

A DNS resolver is a function that might take an unknown amount of time (causing syslog to lose log messages during resolution or ip address update time); this might be particularly unacceptable for something like syslog process, which is an important part of security infrastructure.



Recommended Actions

None, article is informational, as this behavior is by Unix/Linux design
