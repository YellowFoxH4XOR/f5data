Known Issue

This is the result of a known issue. The pvad process uses the gettimeofday() function to perform status checks. Time changes or large time shifts may cause the pvad process to miss polling and status checks.

Note: This behavior only affects the pvad process; the BIG-IP system has been updated to use a monotonically increasing timer for system timer events. For more information, refer to K7712: The BIG-IP system now uses a monotonically increasing timer to calculate system timer events.

F5 Product Development tracked this issue as CR66036 and it was fixed in version 10.0.1. For information about upgrading, refer to the BIG-IP LTM, GTM, Link Controller, ASM, PSM, WebAccelerator, or WOM release notes.

This issue has been fixed in Hotfix-BIGIP-10.0.0-5460.0-HF1, which has been issued for BIG-IP version 10.0.0, for the BIG-IP 10 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
