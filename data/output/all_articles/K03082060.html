Description

Querying default geolocation database with "whereis <ip> latitude" or "whereis <ip> longitude" command provides only 0 in results

  • Using whereis command in cli looking for detailed information such as latitude or longitude for a given IP address
  • Results come back with a zero 0 instead of actual latitude or longitude

Environment

Querying default database for geolocation details on BIG-IP

  • Using only default geolocation database
  • Require more detailed information such as latitude or longitude

Cause

The default database provides geolocation data for IPv4 addresses at the Continent, Country, State, ISP, and Organization levels.  If you require geolocation data at the City-Level, contact your F5 Networks sales representative to purchase additional database files.

Recommended Actions

If more detailed information is required you will need to contact F5 Networks sales representative to acquire the additional database files.
