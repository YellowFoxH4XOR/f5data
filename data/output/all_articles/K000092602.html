K000092602: Default interval or duration used to calculate if the threshold has been crossed.

Type
Support Solution
Published
2022-11-26
Updated
2022-11-26
Source
https://my.f5.com/manage/s/article/K000092602

Description

  • SDC calculates the number of error answer from a peer over a specific period or the measuring interval. Between the measuring interval, it will tabulate the total busy error events and total requests to peer to find out the percent of error event and compare against the threshold set. If the percent error event crosses the threshold (RTT,Error Answer or Timeout) set, the peer will be flagged to be under overload protection and message prioritization starts approx. 1 sec later.
  • A peer in overload state calculates/updates its watermark at interval of 100msec.
  • The default interval is 100msec and it is not configurable from WebUI. It is also not advisable to tune this setting as optimization/profiling has been done to this interval already.

Environment

  • SDC 5.1
  • RTT, Error Answer or Timeout

Cause

By Design.

 Recommended Actions

None.
