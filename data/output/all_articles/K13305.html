Known Issue

Automatic license activation may fail on BIG-IP VE (which includes LTM, GTM, ASM, APM, and WOM) when configured to use temporary network settings.

This issue occurs when all of the following conditions are met:

  • The License activation method is set to Automatic
  • Outbound Interface is set to a value other than mgmt
  • Values are specified for Temporary Network Settings

You can still perform automatic license activation by using the management interface; only the switch interfaces are affected by this issue.

Impact

Automatic license activation may fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system displays error messages in the Configuration utility that appear similar to the following example:

    01070712:3 Caught configuration exception (0), Invalid primary key on route_static_entry object - path is empty. -framework/ForlderMgr.cpp, line 427.
