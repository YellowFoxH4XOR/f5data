Topic

The 3-DNS Controller can encrypt its iQuery communications with other F5 Networks devices, such as BIG-IPs and other 3-DNS Controllers. This 3-DNS Controller encryption feature provides secure iQuery communications over the Internet between datacenters without using 3rd party encryption devices.

To enable secure iQuery communications, you must perform the following procedures:

  • Generate and distribute a copy of an iQuery encryption key
  • Enable secure communication through encryption

Generating and distributing a copy of an iQuery encryption key

To generate and distribute an encryption key, select Generate and Copy iQuery Encryption Key from the 3dnsmaint menu.

Note: Starting in version 4.5, the 3dnsmaint menu contains fewer options than previous versions.

This option will generate a file called F5key.dat, and the key will be copied to the /etc/ directory on each F5 Networks device that is configured on the 3-DNS Controller with SSH access.

Enabling secure communication through encryption

  1. From the Configuration utility of the 3-DNS Controller, click System.
  2. From the System page, check the box next to Encryption Enabled.
  3. Click Update.

At this point the 3-DNS Controller will begin communicating with other F5 Networks devices with encrypted iQuery packets through a secured channel. A reboot is not required.
