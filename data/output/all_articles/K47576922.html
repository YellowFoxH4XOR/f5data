Known Issue

The Options List setting on the Client SSL profile may fail to reset.

This issue occurs when all of the following conditions are met:

  • You have modified the Options List setting on a customized Client SSL profile.
  • After the system committed the changes, you used the Traffic Management Shell (tmsh) to reset the Options List back to its inherited default value.
When you create a customized Client SSL profile, the Options List setting will inherit the values from the Parent Profile by default. The Options List setting provides a selection from a set of industry standard Secure Socket Layer (SSL) options and workarounds for handling SSL processing. After you create a Client SSL profile, you can use the tmsh utility to modify the Options List setting using the following command syntax:

tmsh modify ltm profile client-ssl <profile name> options <option list>

The affected software versions do not have the command option to reset the Option List setting back to the default inherited value.

Impact

You cannot use the tmsh utility to reset the Options List setting to its default inherited value.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You cannot use the tmsh utility to reset the Options List setting to its default inherited value.
