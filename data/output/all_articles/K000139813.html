K000139813: Is my device/unit connected to the F5 licensing server?

Type
Support Solution
Published
2024-06-05
Updated
2024-06-05
Source
https://my.f5.com/manage/s/article/K000139813

Description


These are the different ways to check if F5 unit/device is connected to the F5 licensing server

Environment

  • secure.f5.com
  • CLI/SSH


Cause

None

Recommended Actions

In CLI/SSH:
tmsh show /sys license

Note: This command will display licensing information for the BIG-IP system, including a list of active modules. If your system has a valid license and is connected to the licensing server, the output will show the active modules enabled on the system.
If your system license is not properly installed or if it is not properly connected to the licensing server, the output will indicate that the license cannot be loaded and basic system functionality may be lost.


sys license (f5.com)

license-server
	    Specifies the host name or IP address of the license server. The default value is 65.61.115.202 (activate.f5.com)
