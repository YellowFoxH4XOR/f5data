Known Issue

The IPC channel between the Traffic Management Microkernel (TMM) and the apmd process may become stuck.

This issue occurs when all of the following conditions are met:

  • A BIG-IP APM Virtual Private Network (VPN) virtual server is configured with an iRule that uses the ACCESS::POLICY evaluate command.
  • The BIG-IP APM system experiences high load conditions, and the ACCESS::POLICY evaluate command is evaluating large amounts of data for a high number of users.

Impact

Users cannot connect to BIG-IP APM VPN virtual servers.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You cannot connect to BIG-IP APM VPN virtual servers during high load conditions.
  • The debug tmm logs contain messages indicating BIG-IP APM policy failures.
  • The debug tmm logs contain an error message similar to the following example:

    notice acs_mpi_send/912: ACS: IPC send channel stuck!
