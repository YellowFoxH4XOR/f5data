Description

If your Radius Server is configured to do MFA, or prompt the User in any way, such as to select which device they are using for MFA, the Radius Server will send a Challenge Request to the BIG-IP, which will fail, if you are trying to login on the GUI.

If you are using the CLI, it will work as expected.

Environment

  • BIG-IP LTM 13.x and later using Radius Remote Authentication

Cause

The BIG-IP does not support Challenge Request for Radius Remote Authentication.

Recommended Actions

There is an RFE for this, so if you would like this functionality added to the BIG-IP, you need to submit a support case with F5, and ask to have your case assign to the following ID.

ID 1229025 RFE: System Radius Auth support for Challenge-Request
