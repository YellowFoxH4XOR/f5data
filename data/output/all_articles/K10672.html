Known Issue

This is the result of a known issue. BIG-IP GTM external monitors generate a debug log message whenever a read error is encountered. The BIG-IP GTM generates a read error after an external monitor times out and the system logs a debug error message to the /var/log/gtm file that appears similar to the following example:

big3d[11561]: 0133200c:3: ExtMonitor /usr/bin/monitors/sample_monitor read error Resource temporarily unavailable

Note: The message should only be written to the log file when the big3d process is configured to debug level.

F5 Product Development tracked this issue as CR124850 and it was fixed in BIG-IP GTM 10.1.0. For information about upgrading, refer to the BIG-IP GTM release notes.
