Known Issue

Local Traffic Policy may cause a TMM memory leak.

This issue occurs when all of the following conditions are met:

  • The Local Traffic Policy uses bracket expansion to execute particular iRule expressions, such as [HTTP::host] or [HTTP::uri].
  • A virtual server associated with the Local Traffic Policy processes traffic.

TMM will leak tcl (variable) memory for each request where a Local Traffic Policy action executes TCL code to do substitutions.

For example, TMM will leak if the Local Traffic Policy is configured to perform a redirect with an action similar to the following example:

actions {
1 {
http-reply
redirect
location https://[HTTP::host][HTTP::uri]
}
}

Impact

TMM memory may eventually be exhausted and may result in a system core. The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting. If the system is configured as part of a high-availability pair, the device may fail over.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H460036 on the Diagnostics > Identified > Medium|High screen.
  • TMM memory consumption steadily increases over time.

    You can monitor TMM memory usage using the tmstat command, or the following tmsh command:

    tmsh show sys memory

  • The sweeper may be triggered, as indicated by error messages in the /var/log/ltm file that appear similar to the following examples:

    tmm warning tmm[<PID>]: 011e0002:4: sweeper_update: aggressive mode activated. (166681/196096 pages)
    tmm warning tmm[<PID>]: 011e0002:4: sweeper_update: aggressive mode deactivated. (166680/196096 pages)

  • If configured as a high-availability pair, the BIG-IP system fails over to the standby system.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.

Workaround

To work around this issue, you can use an iRule to perform the required operation.

Impact of workaround: Using an iRule may have additional effects on traffic processing. Ensure that modifications are compatible with your environment.
