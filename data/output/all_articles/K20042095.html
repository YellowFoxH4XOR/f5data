Description

Export ASM event logs in HTML, PDF, CSV or JSON format.

Environment

  • ASM event logs

Cause

None

Recommended Actions

There are different alternatives to export ASM event logs:

GUI export: You can export a list of selected requests in HTML format via GUI.

Note: Event logs can only be exported in HTML format.

Note: A maximum of 100 requests can be exported.

  1. On GUI go to Security > Event Logs > Application > Requests
  2. If you want to export specific requests, select those requests from the list
  3. Click Export Requests
Remote logging: You can create a security logging profile for ASM on the Security ›› Event Logs: Logging Profiles ›› Create New Logging Profile... panel, enabling Remote Storage and specifying the Remote Storage Type as Remote. This lets you send CSV-formatted request logs to a remote log server. You need to assign this profile to each virtual server where you want to see the ASM event logs.

iControl REST API: If you are familiar with iControl REST API, you can query and endpoint to get its requests. However, the formatting of the JSON output would be outside the scope of support so it would require some effort on your part to turn it into the desired output.

Using the following endpoint /tm/asm/events/requests you can retrieve all the requests

Note: the maximum number of event logs allow to export is 500 requests.

restcurl /tm/asm/events/requests > /var/tmp/events.txt

In software version 13.x and above you export request logs endpoint does support exporting per policy.

For example, first locate the rest_uuid for my policy test-manual:

Using the following endpoint /tm/asm/events/requests and the restuuid, you are able to retrieve the events for this policy:

restcurl /tm/asm/events/requests\?\$expand=requestPolicyReference\&\$filter=requestPolicy/id%20eq%20'wPpYHtonjRgo653M_v2kug' > /var/tmp/policy_events.txt
