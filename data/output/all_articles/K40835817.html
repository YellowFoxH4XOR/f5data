Description

While using the BIG-IP BGP feature if you have enabled BGP graceful-restart and set graceful-time,
For example:
 router bgp xxx
 bgp router-id 192.168.1.1
 bgp log-neighbor-changes
 bgp graceful-restart restart-time 120 
 redistribute kernel

When you force the active BIG-IP offline, traffic continues to flow to the offline BIG-IP.

Environment

  • BGP
  • Graceful Restart
  • Force offline

Cause

This is working by design due to the BGP Graceful Restart Capability.

Recommended Actions

The BGP Graceful Restart Capability allows a BGP speaker to express its ability to preserve forwarding state during a BGP restart. When the option is enabled on a BIG-IP, it will announce capabilities to neighbor devices then when the BGP process stops or restarts, the neighbor devices continue to forward traffic to the BIG-IP during the graceful-restart time. You can disable the graceful-restart option or reduce the graceful-time to prevent the problem.

Refer to the following command sequence to disable the graceful-restart option or reduce the graceful-time:

Log in to tmos and type in each line of the following commands. 

imish
enable
conf t
router bgp xxx

no bgp graceful-restart OR 100 bgp graceful-restart restart-time

write
