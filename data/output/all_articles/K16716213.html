Known Issue

New DNS cache entries may retain previous Round Trip Time (RTT) values after previous cache entries are deleted.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured for DNS Service caching.
  • The BIG-IP system has cached a DNS nameserver.
  • A destination DNS nameserver, used for recursion for the particular resolution, becomes unavailable.
  • The BIG-IP system continues to receive DNS requests that require recursion by the unavailable DNS nameserver.
  • The DNS cache RTT value steadily increases until it reaches 120 seconds (120000 msec).
  • The destination DNS nameserver, used for recursion, becomes available.
  • You delete the DNS cached records of the DNS cache.
  • The BIG-IP system receives DNS requests that require recursion to the same DNS nameserver.

Impact

Affected DNS resolutions receive SERVFAIL responses.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing the DNS cache, you notice that the RTT value is set 120000 msec after the first recursion query for an entry.
  • Subsequent DNS requests are set with an RTT value of 120000 msec for the affected recursion queries.

Workaround

To work around this issue, you can change the nameserver-cache-count value of your DNS cache. To do so, perform the following procedure:

Impact of workaround: Changing the nameserver-cache-count value of the DNS cache will reinitialize the cache, removing all cached entries.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. To set the nameserver-cache-count value, use the following command syntax:

    modify /ltm dns cache resolver <dns cache name> nameserver-cache-count <numeric value>

    For example:

    modify /ltm dns cache resolver my_dns_cache nameserver-cache-count 16537

    Note: The nameserver-cache-count range is from 0 to 4294967295 DNS nameserver entries; the default setting is 16536.
  3. To exit the tmsh utility, type the following command:

    quit
