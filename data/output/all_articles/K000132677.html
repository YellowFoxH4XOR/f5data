K000132677: BIG-IQ scheduled backups failing

Type
Support Solution
Published
2023-02-21
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K000132677

Description

You are trying to set up a scheduled backup, but the backup is failing.
Error message:

\" Statistics collection error: agentInstaller failed: java.lang.IllegalStateException: getDeviceLicense for 172.16.1.1 failed: java.net.ProtocolException: status:401, body:<html...>. Please try again by clicking \"Save and Close,\" below. \"


You are still able to take backups locally on the BIG-IP but running the scheduled backups fails.

Environment

  • BIG-IQ
  • Managed BIG-IP's

Cause

 Not enough space in the /var partition

Recommended Actions

  ​​Free some space on the /var partition on the BIG-IP, by doing one or more of the following:
  • Delete unnecessary files from the /var partition (ISO files, TCP dumps, large UCS files etc...)
  • Move files from the /var to another partition (/shared, for example)
  • Increasing the partition size

Additional Information

None
