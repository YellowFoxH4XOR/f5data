Description

When the HSL log throughput is very high, the HSL log may stop and start intermittently.

When HSL log stop / start sending, there is no log printed.

Meanwhile, remote syslog to the same server is working as normal, only HSL log stop / start intermittently.

Environment

  • BIG-IP LTM
  • Virtual server
  • HSL logging

Cause

Throughput issue

Recommended Actions

Please configure the HSL logging destination, choose dedicated TMM interface and VLAN, make sure the bandwidth is enough.

Additional Information

None.
