Known Issue

 This is the result of a known issue. The Administrative Console may inaccurately report whether logging has been enabled. This issue appears to be limited to the HTTP Access Log.

Note: The HTTP Access Log can be configured on the Device Management: Maintenance: Logs: HTTP Access Logs page by selecting On or Off from the drop-down menu.

F5 Product Development tracked this issue as ID 269181 (formerly CR99193) and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes. 

This issue was fixed in cumulative hotfix HF-601-12 issued for FirePass version 6.0.1, and in cumulative hotfix HF-602-5 issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Important: After upgrading or installing the hotfix, you will need to reset HTTP logging using the following procedure.

Resetting the HTTP Access Log

Important: The following procedure requires restarting the services and will disconnect any connected users and prevent logon until all services have finished restarting.

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Device Management : Maintenance : Logs.
  3. From the HTTP Access Log drop-down menu, select Off.
  4. Navigate to Device Management : Restart Services.
  5. Click Restart Services.
  6. Navigate to the Device Management : Maintenance : Logs.
  7. From the HTTP Access Log dropdown menu, select On.
  8. Navigate to the Device Management : Restart Services.
  9. Click Restart Services.
