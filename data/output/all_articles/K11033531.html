Description

Disabling the EXPORT and DHE SSL ciphers Client SSL or Server SSL profiles
  • You need to ensure EXPORT and DHE ciphers are disabled
Environment
  • Client SSL Profile
  • Server SSL Profile

Cause

None

Recommended Actions

Add !DHE:!EXPORT to cipher string in the desired Client SSL or Server SSL profile.

For example:  !DHE:!EXPORT:DEFAULT

Additional Information

The EXPORT ciphers have not been enabled by default since version 10.2

The DHE ciphers were not enabled by default until 11.6 and are still enabled by default but current versions of Chrome and Firefox do not support them.

You can verify the ciphers in use with this command from the command line:

tmm --clientciphers '!DHE:!EXPORT:DEFAULT'
