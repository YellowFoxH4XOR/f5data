K000134544: LCD touchscreen seems to be stuck and it displays [Power on the System]

Type
Support Solution
Published
2023-05-10
Updated
2023-05-10
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000134544

Description

While the rSeries appliance is running, you noticed:

  • the LCD screen displays the option "Power on the system"
  • Upon clicking the action "Power on the system", nothing happens.

Environment

  • F5OS-A
  • rSeries
  • LCD touch screen

Cause

In the lcd-ui prior to v1.7.3 the 'Power On' option is always enabled, regardless of the system power state.

In 1.7.3 and later, the 'Power On' option will be disabled (unclickable) if system power is already on.

Recommended Actions

None

Additional Information

In any case, if using 'Power On' and the system is already powered-on, then nothing will happen. It won't disrupt the system or any tenants.
