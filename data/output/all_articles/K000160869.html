K000160869: Error 1603 and 1920 Installing Edge Client on Windows with SCCM

Type
Support Solution
Published
2026-04-20
Updated
2026-04-20
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160869

Description

SCCM can install Edge Client packages using the Windows installer package 'msiexec'. While Edge Client package may include the installation of services like 'F5 Networks Component Installer', upgrading to a new Edge Client release may trigger MSI errors 1920 and 1603. 

MSI Error 1603 is a generic "fatal error" occurred during installation indicating the overall process failed while Error 1920 is a more specific runtime error that occurs when a service fails to start. 

Environment

  • BIG-IP provisioned with APM.
  • APM deployed with a Network Access resource.
  • You are using SCCM to install or upgrade Edge Client packages on a Windows computer.

Cause

When MSI installer attempts to start a service that is already locked or running, system prevents the service from initializing correctly during the setup phase and may throw Error 1920 ("Service failed to start"). 

MSI (s) (C0:CC) [00:00:00:1]: Executing op: ActionStart(Name=InstallServices,Description=Installing new services,Template=Service: [2])
MSI (s) (C0:CC) [00:00:00:2]: Executing op: ServiceInstall(Name=F5 Networks Component Installer,DisplayName=F5 Networks Component Installer,ImagePath=C:\WINDOWS\SysWOW64\F5InstallerService.exe,ServiceType=272,StartType=2,ErrorControl=32769,,Dependencies=[~],,,Password=**********,Description=Installs and updates F5 client components on PCs without requiring administrative rights for user accounts.,,)
MSI (s) (C0:CC) [00:00:00:3]: Executing op: ActionStart(Name=StartServices,Description=Starting services,Template=Service: [1])
MSI (s) (C0:CC) [00:00:00:4]: Product: BIG-IP Edge Client -- Error 1920. Service 'F5 Networks Component Installer' (F5 Networks Component Installer) failed to start.  Verify that you have sufficient privileges to start system services.

If the installer cannot recover from this error, the entire process terminates with a generic "fatal error" 1603, indicating the overall process failed.

MSI (s) (C0:CC) [00:00:00:5]: Product: BIG-IP Edge Client -- Installation failed.
MSI (s) (C0:CC) [00:00:00:6]: Windows Installer installed the product. Product Name: BIG-IP Edge Client. Product Version: 72.25.1203.0525. Product Language: 1033. Manufacturer: F5, Inc.. Installation success or error status: 1603.

In Error 1603 when you try to install a Windows Installer package: A fatal error occurred during installation Microsoft alerts that you may receive Error 1603 if any one of the following four conditions is true. In this case the first condition is causing both errors.

  • Windows Installer is attempting to install an application that is already installed on your PC,
  • The folder that you are trying to install the Windows Installer package to is encrypted,
  • The drive that contains the folder that you are trying to install the Windows Installer package to is accessed as a substitute drive,
  • The SYSTEM account does not have Full Control permissions on the folder that you are trying to install the Windows Installer package to. You notice the error message because the Windows Installer service uses the SYSTEM account to install software

It is recommended first to uninstall current Edge Client version before installing a new one.

Answer/Recommended Actions

Before installing from SCCM, you can simulate the same process on a Windows computer:

  • Download and install on APM the new Edge Client ISO file from F5 Download page.
  • On APM, configure the connectivity profile, download a new Edge Client package enabling the services and features you want to install.
  • On Windows computer, create C:\tmp directory.
  • Uncompress BIGIPEdgeClient.exe file on that directory.
  • In order to simulate SCCM you need to run commands using the system account.  For this, download 'PsExec.exe' from Microsoft download page Sysinternals and save it in C:\tmp
  • Launch 'cmd' with administrator priviliges, navigate to 'C:\tmp' and run 'psexec -i -s cmd.exe'. 
  • A new window will come up. Run 'whoami' and check, if user is 'nt authority\system'.
  • Uninstall Edge Client using the GUID. Logs will be seen in C:\tmp directory:

msiexec /x "{6D4839CB-28B4-4070-8CA7-612CA92CA3D0}" /qn /norestart REBOOT=ReallySuppress MSIRMSHUTDOWN=2 MSIRESTARTMANAGERCONTROL=Disable /l*vx C:\TMP\f5_uninstall.log

  • Wait around 10 seconds
  • Install new Edge Client release with the services and components you need. You can read K13710 to setup ADDLOCAL.

msiexec /i f5fpclients.msi ADDLOCAL=BASE,VPN,InspectionHost,Standalone,API,SANDBOX,Win32SystemCheck,CLEANER,CERTCHECK,InstallerService,TUNNELSERVER,OesisInspector IGNORESSLSERVERCERTERRORS=0 ALLOWHTTPCONNECTIONS=0 CONNECTIONSOUND=0 EXTERNALBROWSERAUTH=0 REBOOT=ReallySuppress MSIRMSHUTDOWN=2 MSIRESTARTMANAGERCONTROL=Disable /qn /norestart /l*vx C:\tmp\f5_install.log

  • Find below a PS script that uninstalls & installs Edge Client packages. 

Important: This PS script is neither supported nor maintained by F5. It is a tool that may help you.

  • Run 'psexec -i -s powershell.exe -ExecutionPolicy Bypass' from cmd with admin rights.
  • Run the PS script from the new window inside C:\tmp:
    • Logs will be stored in "C:\Windows\Temp\F5_Deploy_Logs",
    • F5 services will be stopped and deleted,
    • Edge Client package will be removed using its GUID,
    • Edge Client will be installed reading features from XML file "_setup_configuration_.f5c" (you can also setup features locally populating $DAT,
    • Script will finish with the Exit Code.
=== START ===

# 1. Setup Logging
$LogDir = "C:\Windows\Temp\F5_Deploy_Logs"
if (!(Test-Path $LogDir)) { New-Item -Path $LogDir -ItemType Directory -Force }
$TimeStamp = Get-Date -Format "yyyyMMdd_HHmmss"
$LogFile   = "$LogDir\F5_Deployment_$TimeStamp.log"
$MSILog    = "$LogDir\F5_MSI_Install_$TimeStamp.log"
$UninstLog = "$LogDir\F5_MSI_Uninstall_$TimeStamp.log"

Start-Transcript -Path $LogFile -Append -IncludeInvocationHeader

Write-Output "--- F5 DEPLOYMENT START: $(Get-Date) ---"
Write-Output "Running as: $(whoami)"

# 2. Search F5 services
$f5Services = (Get-Service -DisplayName "F5*").DisplayName

# 3. Discover GUID using Windows Installer COM Object
Write-Output "[CHECK] Searching for F5 ProductCode via COM..."
try {
    $Installer = New-Object -ComObject WindowsInstaller.Installer
    $currentGuid = $Installer.ProductsEx("", "", 7) | ForEach-Object {
        [PSCustomObject]@{
            Name        = $_.InstallProperty("ProductName")
            ProductCode = $_.ProductCode()
        }
    } | Where-Object { 
        $_.Name -like "*F5 Networks Client Components*" -or 
        $_.Name -like "*BIG-IP Edge Client*" 
    } | Select-Object -ExpandProperty ProductCode -First 1
} catch {
    Write-Output "[ERROR] Failed to query COM object: $($_.Exception.Message)"
}

# 4. Stop and Delete Services (to prevent 1920/1603 errors)
foreach ($serviceName in $f5Services) {
    $svc = Get-Service -DisplayName $serviceName -ErrorAction SilentlyContinue
    if ($svc) {
        Write-Output "[CLEANUP] Stopping and deleting service: $serviceName"
        Stop-Service -DisplayName $serviceName -Force -ErrorAction SilentlyContinue
        Start-Process "sc.exe" -ArgumentList "delete `"$($svc.Name)`"" -Wait -WindowStyle Hidden
    }
}

# 5. Uninstall previous version if found
if ($currentGuid) {
    Write-Output "[UNINSTALL] Found GUID: $currentGuid. Running MSIEXEC /X..."
    $uninstArgs = "/x `"$currentGuid`" /qn /norestart REBOOT=ReallySuppress MSIRMSHUTDOWN=2 MSIRESTARTMANAGERCONTROL=Disable /l*vx `"$UninstLog`""
    $uninstProc = Start-Process "msiexec.exe" -ArgumentList $uninstArgs -Wait -PassThru
    Write-Output "[UNINSTALL] Finished with Exit Code: $($uninstProc.ExitCode)"
}

# 6. Delete Residual Folders (Clears locked DLLs)
$pathsToClean = @("${env:ProgramFiles(x86)}\F5 Networks", "C:\ProgramData\F5 Networks")
foreach ($path in $pathsToClean) {
    if (Test-Path $path) {
        Write-Output "[CLEANUP] Removing folder: $path"
        Remove-Item -Path $path -Recurse -Force -ErrorAction SilentlyContinue
    }
}

# 7. Wait for system to catch up
Write-Output "[WAIT] Pausing for 10 seconds to allow Service Control Manager to refresh..."
Start-Sleep -Seconds 10

# 8. Setting ADDLOCAL

# 8.1. Setting ADDLOCAL from XML file "_setup_configuration_.f5c"

[xml]$xmlContent = Get-Content -Path "_setup_configuration_.f5c"
$DATA = ($xmlContent.CLIENT_CONFIGURATOR.FEATURES.FEATURE) -join ","

# 8.2. Setting ADDLOCAL locally with the features you need.
#$DATA="BASE,VPN,InspectionHost,Standalone,API,SANDBOX,Win32SystemCheck,CLEANER,CERTCHECK,InstallerService,TUNNELSERVER,OesisInspector"

Write-Output "[INSTALL] Setting ADDLOCAL with services and features... $DATA"

# 9. Execute New Installation
Write-Output "[INSTALL] Installing new version from MSI..."

$installArgs = "/i `"f5fpclients.msi`" ADDLOCAL=$DATA IGNORESSLSERVERCERTERRORS=0 ALLOWHTTPCONNECTIONS=0 CONNECTIONSOUND=0 EXTERNALBROWSERAUTH=0 REBOOT=ReallySuppress MSIRMSHUTDOWN=2 MSIRESTARTMANAGERCONTROL=Disable /qn /norestart /l*vx `"$MSILog`""
$instProcess = Start-Process "msiexec.exe" -ArgumentList $installArgs -Wait -PassThru

Write-Output "[RESULT] Final Installation Exit Code: $($instProcess.ExitCode)"

Stop-Transcript
exit $instProcess.ExitCode

=== END ===
