Topic

You should consider using this procedure under the following condition:

  • You want to synchronize the BIG-IQ system clock with a network time protocol (NTP) server.

Description

You can configure the BIG-IQ system to synchronize its clock with an NTP server using the BIG-IQ user interface. To do so, perform one of the following procedures:

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have the IP address of a remote NTP server.
  • You have administrator access to the BIG-IQ system.

Procedures

  • BIG-IQ 5.2.0 and later
  • BIG-IQ 5.0.0 - 5.1.0
  • BIG-IQ 4.5.0 - 4.6.0

BIG-IQ 5.2.0 and later

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ user interface as the admin user.
  2. Click the System tab under BIG-IQ.
  3. Click THIS DEVICE.
  4. Click DNS & NTP.
  5. Click Edit.
  6. Under NTP Servers, add the NTP server IP addresses.
  7. Click Save.

BIG-IQ 5.0.0 - 5.1.0

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ user interface as the admin user.
  2. Click the System Management tab under BIG-IQ.
  3. Click Local Host Settings.
  4. Click DNS & NTP.
  5. Click Edit.
  6. Under NTP Servers, add the NTP server IP addresses.
  7. Click Save.

BIG-IQ 4.5.0 - 4.6.0

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system with the administrator user name and password.
  2. On the BIG-IQ Systems panel, click the gear icon next to the group name for which you want to define the DNS and NTP servers, and click Properties.
  3. Click Services.
  4. In the Time Servers box, type the IP addresses of your NTP servers.
  5. Click Save.
