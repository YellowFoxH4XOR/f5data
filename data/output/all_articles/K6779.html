Known Issue

This is the result of a known issue. It is possible to view or add a Layer 2 Static Forwarding Table entry from the Configuration utility. However, you cannot delete a Layer 2 Static Forwarding Table entry from the Configuration utility.

To view a list of Layer 2 static forwarding table entries, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Network.
  3. Click VLANs.
  4. Select the VLAN that you want to view.
  5. Click Layer 2 Static Forwarding Table from the top menu bar.

    The Layer 2 Static Forwarding Table list is displayed.

F5 Product Development tracked this issue as CR81956 and it was fixed in BIG-IP 9.4.2. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator Release Notes.

Workaround

You can work around this issue by deleting the Layer 2 Static Forwarding Table entry from the command line. To do so, type the following command:

b vlan <vlan name> fdb <MAC address> static delete
