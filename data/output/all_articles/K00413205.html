Topic

The BIG-IP system provides several protocol-based health monitors that use Tool Command Language (Tcl) scripting.

Description

Tcl monitors

The following system-supplied health monitors are commonly referred to as Tcl monitors:

  • FTP
  • IMAP
  • POP3
  • SMTP

These monitors rely on Tcl scripts (tclsh) to perform the functions for each of the protocol-based monitors. You can use the provided protocol-based monitor templates to create customized monitors for your particular environmental requirements.

The underlying Tcl scripts for the monitor templates are located in the /config/monitors/builtins (for BIG-IP 11.5.2 and later) or /config/bulitins (for BIG-IP 11.5.1 and earlier) file that is linked to the /usr/share/monitors file.

Tcl monitor scripts

The following monitor scripts are executed by tclsh, which calls the curl::transfer function to connect to the monitored destination server:

  • ftp_monitor 
  • imap_monitor 
  • pop3_monitor 
  • smtp_monitor 

These Tcl-based monitors have more protocol and session-based interaction with the destination server.
