Note: For more information, refer to K8802: Using SSL ciphers with BIG-IP Client SSL and Server SSL profiles.

The default clientssl and serverssl profiles support a different set of Secure Socket Layer (SSL) ciphers depending on the software version you are running.

The default clientssl profile in BIG-IP LTM 9.1 through 9.1.3 allows ciphers from both the native and compat SSL stacks. The following table lists the ciphers used in the default clientssl profile in BIG-IP 9.1.x:

Note: The default clientssl profile supports only the SSLv3 and TLSv1 cryptographic protocols.

Note: The default serverssl profile supports only the SSLv3 and TLSv1 cryptographic protocols.
