Description


When using Topology load balancing method the EDNS client subnet value is not being used.  Instead the source address of the requesting system is used and providing an undesired DNS record.

Environment

  • BIG-IP DNS
  • Topology records
  • EDNS
  • DNS Environment where EDNS functionality has been configured and deployed.  Typically configured on LDNS systems.

Cause

By default Topology load balancing will use the requesting systems IP address.  This is typically a LDNS system and not the actual client making the DNS request.

Recommended Actions

  • To configure at the Wide IP level - Note: Must be disabled globally for this to be controlled at the WideIP Level 
    Log into the Configuration Utility
    Navigate to DNS > GSLB > Wide IPs > Wide IP List
    Enable Prefer Client Subnet
    Click Update
     
  • To configure globally - Note: Will be enabled regardless of the setting at WideIP Level
    Log into the Configuration Utility
    Navigate to DNS > Settings > GSLB > Load Balancing
    Enable Prefer Client Subnet
    Click Update

Additional Information

None


With this configured, the system uses the edns0 client subnet option (if one exists) instead of the source address, when using topology load balancing. When disabled, or if the query does not contain a client subnet option, the system falls back to the source address. The default is disabled.
