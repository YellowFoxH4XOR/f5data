Known Issue

BIG-IP Analytics may report incorrect very high latency statistics.

This issue occurs when all of the following conditions are met:

  • You have configured a BIG-IP virtual server with an Analytics profile.
  • The server closes virtual server connections abnormally.
When a server closes a connection abnormally, BIG-IP Analytics may not receive all of the elements representing the full lifecycle of a transaction (request, request-done, response, response-done). As a result, BIG-IP Analytics may incorrectly interpret this as extremely high latency.

Impact

BIG-IP Analytics reports incorrect high latency statistics.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP Analytics reports incorrect high latency statistics.
