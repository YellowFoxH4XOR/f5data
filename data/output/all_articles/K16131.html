Known Issue

The Browser Workarounds option incorrectly identifies some modern browsers as needing compression workarounds.

This issue occurs when the following condition is met:

  • The Browser Workarounds option is enabled in the HTTP Compression profile.

The Browser Workarounds option was introduced to disable compression for some older legacy browsers that were not compatible with HTTP compression. However, the Browser Workarounds functionality erroneously matches with some modern browsers and disables compression.

Impact

HTTP compression is unexpectedly disabled for modern browsers.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • HTTP compression is not performed as expected when using modern browsers.

Workaround

To work around this issue, you can disable the Browser Workaround option in the HTTP profile. If legacy clients require compression workarounds, use an iRule that selectively disables compression depending on the User-Agent string.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window, with consideration to the possible impact on your specific environment.
