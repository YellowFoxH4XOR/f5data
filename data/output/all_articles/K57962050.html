Description

You can use the ZoneRunner™ utility to create and manage DNS zone files and configure the BIND instance on BIG-IP® DNS (formerly GTM). However, you cannot edit or delete an RR data that contains non-ASCII such as '*' through the Configuration Utility (GUI). 

Environment

  • BIG-IP DNS
  • ZoneRunner


Cause

This is a known issue currently tracked under ID 882509: ZoneRunner accepts non-ASCII RR data on input, fails on edit, delete.

Recommended Actions

Perform Workaround outlined in ID 882509:

1. Run 'rndc freeze' from the CLI bash.

    # rndc freeze

2. Edit the zone file to correct or remove the affected record, and (optionally) increase the SOA serial number by 1.

    example:
    # vi /var/named/config/namedb/db.external.mydomain.com

3. Save previously edited file

5. Run 'rndc thaw'.

    # rndc thaw
