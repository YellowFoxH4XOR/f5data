K17028193: Different FEPs are using same INTER COMMUNICATION port

Type
Support Solution
Published
2022-06-16
Updated
2023-02-21
Applies to
  • Traffix SDC: 5.X.X, 5.1.X, 5.0.X, 5.2.0, 5.2.X, 5.0.0, 5.1.0
Source
https://my.f5.com/manage/s/article/K17028193

Description

FEP fails to start up and the follwoing error message can be found in fep.log

  • FATAL [10641] Load balancer application was terminated with an exception. [main_23] [CpfApplication.init()] org.jboss.netty.channel.ChannelException: Failed to bind to: /172.16.15.11:4548

Environment

  • SDC Version 5.1
  • upgrade/migration
  • new fep were added

Cause

New FEP was not added properly due to unknown issue 

Recommended Actions

Workaround

  1. Stop EMSs services
  2. Stop SDCs services
  3. Delete fep folders from /data on SDCs and EMs
  4. start SDCs services
  5. re-add vip for the deleted fep in steps 3 on SDCs webui
  6. Start EMSs services

Additional Information

When FEP folder is wiped. SDCs staus is similar to fresh installed pertaining to the delete FEP. Users are expected to recreate the FEP on the webui.
