Environment

  • F5OS-C
  • Velos
  • Tenant Deployment failure

Cause

  • DIMM (Memory) has issue

Recommended Actions

Require to replace the blade.

Please generate partition qkview and run the below command on the problematic blade, and get the output.

dmidecode -t memory

Then please escalate the case to F5 Networks with those info.
