K12215: Deleting all views from ZoneRunner prevents the creation of a new view

Known Issue

This is the result of a known issue. Deleting all views within ZoneRunner prevents the creation of a new view. Attempting to create a new view results in the following error message:

Tag 'insert' can't insert page '/tmui/globallb/zfd/view/settings.jsp'. Check if it exists. Illegal initial capacity: -1

F5 Product Development is tracking this issue as ID 341115.

Workaround

To restore the default external view, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. From the ZoneRunner menu, select Named Configuration.
  3. Locate the listen-on port 53 section.

    For example:

    listen-on port 53 {
            127.0.0.1;
        };
  4. Add the following line:

    "zrd-acl-000-000";

    For example:

     listen-on port 53 {
            127.0.0.1;
            "zrd-acl-000-000";
        };
  5. Add the following information to the end of the configuration:

        acl "zrd-acl-000-000" {
            127.10.0.0;
        };

        view "external" {
            match-clients {
                "zrd-acl-000-000";
                any;
            };
        };
  6. Click the Update button.
  7. Log in to the command line.
  8. Restart the ZoneRunner daemon by typing the following command:

    bigstart restart zrd
  9. Log in to the Configuration utility.
  10. From the ZoneRunner menu, select View List.
    You should now have the default external view listed. You can now add new views.
