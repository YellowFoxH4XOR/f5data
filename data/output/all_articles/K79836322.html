K79836322: BIG-IQ may fail to import Large BIG-IP ASM configurations

Type
Support Solution
Published
2021-10-21
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • Public Cloud
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K79836322

Description

BIG-IQ fails on BIG-IP ASM service import of a managed device :

  • Import task never completes
  • No Error is listed in the Configuration Utility
  • In the tokumond logs, there is something similar to this:
Logs similar to these are found in tokumond logs:

2021-10-01_14:50:57.08603 [SEVERE] es: Error occured on post batchId:XXXXXXX >>>>>>
2021-10-01_14:50:57.08664 [SEVERE] es: _index:asm command:create status:400 _id:https://localhost/mgmt/cm/asm/tasks/declare-mgmt-authority/<UUID> error:{"type":"illegal_argument_exception","reason":"Limit of total fields [xxxx] in index [asm] has been exceeded"} see searchd log for complete error.

Environment

  • Managed Device ASM Service import 
  • BIG-IP ASM
  • BIG-IQ 8.0, 8.1

Cause

The total number of BIG-IP ASM index fields exceeds the max limit value (2000) that is currently default set.

Recommended Actions

Use the following workaround to resolve the issue

  1. On the command line, mount /usr in read/write mode:   mount -o remount,rw /usr
  2. Edit /usr/share/rest/tokumon/config/modules/asm.js
  3. Under "settings"."index", add the following: "mapping" : {"total_fields" : {"limit" : 5000}}

    Example:
     
    BEFOREAFTER
        settings: { "index":{"max_result_window":50000}}, // Use these to overwrite parts or all of ES_SETTINGS
         		    settings: { "index":{"max_result_window":50000}, "mapping":{ "total_fields":{ "limit":5000}}}, // Use these to overwrite parts or all of ES_SETTINGS
  4. In the command line, run  bigstart kill tokumond
