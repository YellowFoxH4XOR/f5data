K21770469: How to modify the ciphers used by the ssh client on Big-IP and Big-IQ

Type
Support Solution
Published
2021-10-20
Updated
2025-04-02
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K21770469

Description

If users receive the below error, you may need to update the ciphers in the ssh client:

no matching cipher found: client aes128-cbc,aes256-cbc server aes128-ctr,aes192-ctr,aes256-ctr

Environment

  • BIG-IP
  • BIG-IQ
  • SSH clients

Cause

No matching cipher found.

Recommended Actions
Note : These changes will not persist across upgrades.

  1. Open an SSH session to the bigIP.
  2. Run the following command to make a copy of the current SSH client configuration file:

       cp /config/ssh/ssh_config /config/ssh/ssh_config.bak
  3. Check the current configured ciphers by running the following command:

       cat /config/ssh/ssh_config

    The default ciphers section should look like this:

    ========================================
    Ciphers aes128-cbc,aes256-cbc
    MACs hmac-sha1,hmac-sha2-256,hmac-sha2-512
    ========================================
  4. Using a command line text editor such as 'nano' or 'vi', update the Ciphers in "/config/ssh/ssh_config" as shown below and save the change:

    The ciphers you choose needs to be the ones in the server list in the error message above.
    ***********
    Ciphers aes128-ctr,aes192-ctr,aes256-ctr,arcfour128,arcfour256,arcfour
    Macs hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com
    ***********
  5. Try to connect to the server, the connection should now work.
