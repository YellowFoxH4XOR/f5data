Cause

PSU may seems to report incorrect high input voltage even provided with supported voltage lines and shutdowns the main output

Recommended Actions

Before processing RMA, make sure to verify below to understand if the problem is with the PSU itself or if the customer's data center is providing AC input to the PSU that is well above specification.

  1. Replace affected PSU with a known-good PSU (using the same AC input cable as the failing PSU) and verify if replacement PSU is still showing same errors
  2. Try failing PSU with an alternate AC input cable (taken from another PSU that was working properly), and verify if failing PSU continues to report same AC input over-voltage errors
