Known Issue

An SSL handshake may fail when using large certificates.

This issue occurs when one of the following conditions is met:

  • The Client SSL profile is configured to request a client certificate for verification.

    • The SSL certificate size is large enough to exceed the default 32 KB SSL handshake buffer.
  • The Server SSL profile is configured with a back-end server that sends large SSL certificate files.

    • The SSL certificate size is large enough to exceed the default 32 KB SSL handshake buffer.

Impact

SSL connections may stall or close with an SSL handshake failure.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Client SSL connection fails.
  • In the /var/log/ltm file, you observe error messages that appear similar to the following example:

    err tmm1[17511]: 01230140:3: RST sent from 10.10.10.1:80 to 10.10.10.2:57521, [0x1b5adb9:2003] {peer} SSL error (handshake_failure(40))
    err tmm1[17511]: 01230140:3: RST sent from 10.10.10.3:47290 to 10.10.10.4:443, [0x1b5adb9:2003] SSL error (handshake_failure(40))

    err tmm3[13206]: 01230140:3: RST sent from 10.10.10.1:80 to 10.10.10.2:35317, [0x18dda11:1656] {peer} SSL error (record_overflow(22))
    err tmm3[13206]: 01230140:3: RST sent from 10.10.10.3:34290 to 10.10.10.4:443, [0x18dda11:1656] SSL error (record_overflow(22))
