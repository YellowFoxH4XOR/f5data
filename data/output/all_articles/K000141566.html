Description

Deleting Network adapters in the hypervisor might cause some connection issue after reboot.

Environment

VMWare

BIGIP VE

Cause

VMware with 4 network adapters.

Network adapter 1 00:00:5E:00:53:01 
Network adapter 2 00:00:5E:00:53:02
Network adapter 3 00:00:5E:00:53:03
Network adapter 4 00:00:5E:00:53:04

We can see then that the mapping is as follow:

Network adapter 1 = mgmt

Network adapter 2 = 1.1

Since interface 1.1 and interface 1.3 are not in use, you decided to do some cleanup and delete the unused network adapters. After some time, you decided to reboot the VE due to some maintenance window or upgrade, but after the reboot or upgrade you can see that your interface 1.2 is not coming up and the associated mac address for 1.2 is now in interface 1.1.

The reason for this is since the BIGIP VE can only detect 2 NICs configured to it, it will map those interfaces as per its sequence. 

Network adapter 1 = mgmt

Network adapter 3 = 1.1 

Recommended Actions

This is expected behavior so do not delete Network Adapters in the running VM even if those network adapters are not in use. If somehow you are in this issue, please add new network adapters to match your expected behavior.
