Topic

When attempting to activate or update the BIG-IP license using the Configuration utility, the update may fail and display the following error message:

An error has occurred while trying to process your request.

This issue can occur when activating or updating the BIG-IP license using the Configuration utility if the /var/tmp/bigip.license file exists.

When you use the Configuration utility to activate the license, the Configuration utility uses the /var/tmp/bigip.license file as a temporary storage location before copying the file to the /config/bigip.license file. If the /var/tmp/bigip.license file exists when attempting to activate or update the license, the Configuration utility does not have permissions to access the file, and the action fails.

You can resolve this issue by removing the temporary license file from the /var/tmp directory. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Remove the temporary license file from the /var/tmp directory by typing the following command:

    rm /var/tmp/bigip.license

  3. Re-activate the license from the Configuration utility.
