Description

When attempting to upgrade the BIG-IP system, you may encounter an error, similar to:

  • load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all " - failed. -- Loading schema version: 13.1.0.8 Loading schema version: 13.1.1.5 01071008:3: Provisioning failed with error 1 - 'Disk limit exceeded. 20338 MB are required to provision these modules, but only 16804 MB are available.' . Unexpected Error: Loading configuration process failed.

Environment

  • BIG-IP
  • Failed upgrade

Cause

The disk volume is full.

Recommended Actions

  • Delete an unused boot location, to free up space.
  • Delete any old image/iso files from /shared/images and /shared/hotfixes
    K14403: Maintaining disk space on the BIG-IP system

Additional Information

None
