Description

ASM failure with error message logged in /var/log/ts/asm_config_server.log:

F5::Cgc::Channel::send,,Failed to send a message, error:XXXXXXXXXX
F5::Cgc::Channel::new,,Could not open a cgc channel with channel_type 'publisher', is_listen '0'
F5::ASMConfig::Handler::send_to_relay,,Failed on sending mcp_asm_update to ASM_local_ASM_channels_ASM: Can't call method "send" on an undefined value at /usr/local/share/perl5/F5/ASMConfig/Handler.pm line 1846.

ASM policy changes may also not be synchronized, inconsistent between peers, or missing in the policy list.

Environment

  • After upgrade
  • Status: In Sync


Cause

Bug ID 912149
 

Recommended Actions

As per the bug tracker, the issue should be resolved automatically at the next sync attempt, which occurs within 5 minutes in response to failed manual or auto-sync operations.

In some cases, restarting the 'asm_config_server' process resolved the issue.

To restart 'asm_config_server' process, the following command should be run from the CLI:

pkill -f asm_config_server

Note: This should not be traffic impacting.
