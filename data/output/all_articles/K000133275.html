Description

HTTP compression is currently not supported by Istio and Aspenmesh. The compression can be enabled and configured only by manually configuring Envoy Sidecar configuration with the use of EnvoyFilters.

Istio community is tracking the progress for implementing compression in the following github issue:

https://github.com/istio/istio/issues/18443

The issue also contains EnvoyFilter examples to manually enable compression.

Environment

Aspenmesh 1.5.x - 1.14.x

Istio 1.x - 1.17.x

Cause

N/A

 

Recommended Actions

HTTP Compression can be enabled on Istio only by using EnvoyFilters and directly configuring sidecar proxy configuration.

Envoy community provides multiple network filters the user can use to configure HTTP compression. Gzip compression is one of the supported libraries.

For details about supported filters for a specific Envoy versions please look at Envoy documentation.
