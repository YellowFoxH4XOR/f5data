Procedure

There are multiple options to backup DNS config:

  1. Using API . You can list all zones with all data in a list. List API supports query parameters for fields. You find the exact parameters of the API by looking at developer mode and doing reload in browser. Console UI already uses this API to avoid roundtrips.
  2. Using Postman / script . This script leverages F5 Distributed Cloud API to get objects configuration using curl tool. It uses jq utility to format and process responses.
  3. Copy and save - JSON file .  (Easiest, you will have to grab the JSON from each instance)
  4. Using vesctl - How to download kubeconfig via API or vesctl

Describing option 3 for simplicity:

You can save Distributed Cloud configuration object in either JSON or YAML:

  1. Click on the three dots from your Distributed Cloud DNSLB object, select Edit.
  2. Select JSON and select the format your desire and copy the text as a yaml file. That the configuration you use to restore.

To Restore

  • When you add a new object (e.g. DNSLB), at the top, select JSON and clear the content to paste your backup content of the yaml.
  • Click "Save and Exit".
