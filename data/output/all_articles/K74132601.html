Known Issue

The BIG-IP DNS system (formerly known as BIG-IP GTM) does not save modifications to global server load balancing (GSLB) pool members.

This issue occurs when all of the following conditions are met:

  • You configure your BIG-IP DNS system with thousands of GSLB virtual servers or wide IP objects.
  • Using the Configuration utility, you modify the GSLB pool members of a GSLB pool in the Members > Manage page.
  • You save the GSLB pool modifications by clicking Finished.

Impact

The system does not save the configuration changes.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When viewing the GSLB pool members of the modified GSLB pool, the system does not retain the pool member modifications.

Workaround

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

To work around this issue, you can use the TMOS Shell (tmsh) to modify pool members of the GSLB pool.
