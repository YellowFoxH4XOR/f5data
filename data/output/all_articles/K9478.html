Topic

You should consider using this procedure under the following condition:

  • You want to determine the version of Always-On Management (AOM) firmware installed on a BIG-IP platform.

Description

The Always-On Management is a separate subsystem that provides lights-out management for the following BIG-IP platforms:

  • BIG-IP i2000, i4000, i5000, i7000, i10000, i11000, i15000, HRC-i2800, HRC-i5800, and HRC-i10800 iSeries platforms
  • BIG-IP 2000, 4000, 5000, 7000, 10000, and 12000 series platforms
  • BIG-IP 800, 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 platforms
  • VIPRION B2100, B2150, and B2250 blades

To determine your BIG-IP model and platform type, refer to the following articles:

  • K13144: Determining the BIG-IP model and platform type (11.x - 14.x)
  • K10635: Determining the BIG-IP model and platform type (9.x - 10.x)

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Always-On Management (AOM) Command Menu. For information, refer to K14594: Accessing the AOM Command Menu.

Procedures

  • Determining the AOM version installed on your platform for BIG-IP iSeries platforms, BIG-IP 2000, 4000, 5000, 7000, 10000, and 12000 series platforms, and VIPRION B2100, B2150, and B2250 blades
  • Determining the AOM version installed on your platform for BIG-IP 800, 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 platforms

Determining the AOM version installed on your platform for BIG-IP iSeries platforms, BIG-IP 2000, 4000, 5000, 7000, 10000, and 12000 series platforms, and VIPRION B2100, B2150, and B2250 blades

  1. Connect to the AOM Command menu.

    Note: For information about accessing the AOM Command menu, refer to K14594: Accessing the AOM Command Menu.

    For BIG-IP i2000, i4000, i5000, i7000, i10000, i11000, i15000, HRC-i2800, HRC-i5800, and HRC-i10800 iSeries platforms, the AOM Command Menu displays the following:

    AOM Command Menu:
    B --- Set console baud rate
    I --- Display platform information
    P --- Power on/off host subsystem
    R --- Reset host subsystem
    N --- Configure AOM network
    S --- Configure SSH Server
    A --- Reset AOM
    Q --- Quit menu and return to console

    For BIG-IP 2000, 4000, 5000, 7000, 10000, and 12000 series platforms, the AOM Command Menu displays the following:

    AOM Command Menu:
    B --- Set console baud rate
    I --- Display platform information
    P --- Power on/off host subsystem
    R --- Reset host subsystem
    N --- Configure AOM network
    S --- Configure SSH Server
    A --- Reset AOM
    H --- Host Console Capture Buffer
    E --- Error report
    Q --- Quit menu and return to console

    For VIPRION B2100, B2150, and B2250 blades, the AOM Command Menu displays the following:

    AOM Command Menu:
    B --- Set console baud rate
    C --- Capture blade console
    I --- Display platform information
    P --- Power on/off blade
    R --- Reset blade
    Q --- Quit menu and return to console

  2. Press I to display the platform information.

    The installed AOM firmware version is listed in under Firmware versions and appears similar to the following example:

    Firmware versions
    AOM Firmware Version (1) : 5.6.9 (Active)
    AOM Firmware Version (2) : 5.5.7
    AOM Bootloader Version : 3.2
    AOM Firmware Build Date : Apr 10 2018 14:11:34 PDT
    CPLD version : 0x55
    LCD Application Version : 2.02.082.00.0
    LCD Bootloader Version : 2.00.060.00.0

    Note: The AOM subsystem can store two images. If the AOM subsystem cannot be started using the currently active image, the subsystem uses the alternative image. When an upgrade of AOM firmware takes place, the most recently installed kernel is set as the default active kernel on its next restart. If a BIG-IP version is installed that includes an older AOM firmware version, the older AOM firmware version does not install.

Determining the AOM version installed on your platform for BIG-IP 800, 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 platforms

  1. Connect to the AOM Command Menu.

    Note: For information about accessing the AOM Command menu, refer to K14594: Accessing the AOM Command Menu.

    For the BIG-IP 800, 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 platforms, the AOM Command Menu displays the following:

    AOM Command Menu
    1 --- Connect to Host subsystem console
    2 --- Reboot Host subsystem (sends reboot command)
    3 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!)
    4 --- Reset AOM subsystem (issues hardware reset--USE WITH CARE!)
    5 --- Power off Host subsystem (issues hardware shutdown--USE WITH CARE!)
    B --- AOM baud rate configurator
    L --- AOM subsystem login
    N --- AOM network configurator
    P --- AOM platform information

  2. Press L to access the AOM subsystem login.
  3. At the AOM login prompt, enter the following username:

    root

  4. At the password prompt, enter the password for the root user.
  5. The AOM subsystem command line prompt appears similar to the following example:

    root@AOM2:~#

  6. To display the installed AOM versions, type the following command:

    flashver | grep -i kernel

    The AOM version information of the kernels installed on the subsystem appears similar to the following example:

    Kernel1 image: V10.1.10.2.0 Wed Sep 14 15:38:45 PDT 2011
    Kernel2 image: V10.1.17.388.0 Fri Nov 15 11:48:30 PDT 2013

    Note: The AOM subsystem can store two images. If the AOM subsystem cannot be started using the currently active image, the subsystem uses the alternative image. When an upgrade of AOM firmware takes place, the most recently installed kernel is set as the default active kernel on its next restart. If a BIG-IP version is installed that includes an older AOM firmware version, the older AOM firmware version does not install.

  7. To view the version number of the currently running AOM subsystem kernel, type the following command:

    cat /etc/aom_version

    The version number of the currently running kernel appears similar to the following example (AOM firmware version 10.1.17):

    Build 10.1.17.388.0 Fri Nov 15 11:48:30 PST 2013

  8. To exit AOM subsystem, type the following command:

    exit
