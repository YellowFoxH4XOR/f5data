Known Issue

You cannot upgrade directly from BIG-IP 10.x to 12.x when the BIG-IP GTM module is provisioned.

This issue occurs when the following conditions are met:

  • Your BIG-IP system has the BIG-IP GTM module provisioned, and one of the following is true:
     
    • You upgrade directly from BIG-IP 10.x to BIG-IP 12.x.
    • You attempt to load a BIG-IP 10.x user configuration set (UCS) on a BIG-IP system running BIG-IP 12.x.

Impact

The BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to install a BIG-IP 10.x UCS file on a BIG-IP 12.x system, the configuration does not load.
  • After attempting to load the UCS file, you notice an error message similar to the following example:

    ERROR: UCS version(v10.2.4) is less than v11.0.0 and GTM module config exists. Upgrade not supported to v12.0.0 or greater versions - exiting installation. See Solution SOL17158. Operation aborted. /var/tmp/configsync.spec: Error installing package Config install aborted. Unexpected Error: UCS loading process failed.

Resolution

Status

F5 Product Development has assigned ID 540956 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you must first upgrade from BIG-IP 10.x to BIG-IP 11.x. Then upgrade from BIG-IP 11.x to BIG-IP 12.x.

Note: F5 recommends that you upgrade to one of the most recent versions of BIG-IP 11.x software. For more information refer to K5903: BIG-IP software support policy.

Impact of workaround: Performing the suggested workaround causes the BIG-IP system to be unavailable for traffic processing while the device reboots into the new software partition.
