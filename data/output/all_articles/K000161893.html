K000161893: A cipher group must be configured when TLS 1.3 is enabled (validation failed for child profile)

Type
Support Solution
Published
2026-06-25
Updated
2026-06-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000161893

Description

Enabling TLS 1.3 on a parent client SSL profile in BIG-IP may result in configuration conflicts if child profiles do not meet required security criteria. Errors such as A cipher group must be configured when TLS 1.3 is enabled (validation failed for child profile) can occur. Modifying child profiles individually may not resolve the conflict if parent profile settings override changes. Using the default client SSL profile as a parent can trigger cascading warnings and conflicts across all child profiles.

Environment

  • BIG-IP LTM
  • Multiple client SSL profiles configured in a parent-child hierarchy
  • Default client SSL profile used as parent for other client SSL profiles
  • Child profiles may lack TLS 1.3 and secure cipher group settings

Cause

Hierarchical configuration of client SSL profiles causes child profiles to inherit settings from the parent profile. Enabling TLS 1.3 on the parent profile is blocked if child profiles do not have a secure cipher group configured, resulting in validation errors. The default client SSL profile is intentionally configured without TLS 1.3 and secure ciphers to support legacy systems, and modifying it can cause cascading conflicts.

Answer/Recommended Actions

  • Do not modify the default client SSL profile directly.
  • Create a new custom client SSL profile with TLS 1.3 and a secure cipher group enabled.
  • Use the new custom profile as the parent for all other client SSL profiles requiring modern security settings.
  • Override settings in child profiles as needed, ensuring the "Custom" option is checked for each parameter to be modified.
  • Do not assign the default client SSL profile directly to virtual servers; always use a custom profile.

Additional Information

The parent profile must always be specified when creating a new SSL profile; BIG-IP does not support parentless profiles.
