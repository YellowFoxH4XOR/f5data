K30376215: How to identify which DNS Controller pod is leader

Type
Support Solution
Published
2022-10-26
Updated
2022-12-13
Source
https://my.f5.com/manage/s/article/K30376215

Description

For Istio service entries that meet specific requirements, the DNS controller can reduce the DNS traffic between sidecar proxies and CoreDNS. When creating a DnsStaticEntry resource, the DNS controller creates or updates the managed ServiceEntry resource eliminating the need for each sidecar to query the CoreDNS for any IP address outside the mesh.


Environment

  • AM 1.11.8-am3


Cause

When deploying the DNS Controller, two pods are created as Active/Standby. Only one will be elected as the Leader. If that pod fails, the second pod will be elected to become leader.

oc get deploy dns-controller -n istio-system
NAME             READY   UP-TO-DATE   AVAILABLE   AGE
dns-controller   2/2     2            2           118m
 
oc get pods -l app.kubernetes.io/name=dns-controller -n istio-system
NAME                              READY   STATUS    RESTARTS   AGE
dns-controller-798fb4f7c7-n6kns   1/1     Running   0          119m
dns-controller-798fb4f7c7-svcgg   1/1     Running   0          119m



Recommended Actions

One way to distinguish the Leader pod is to check the logs to see who “successfully acquired lease.” 

oc logs dns-controller-798fb4f7c7-n6kns -n istio-system
… 
I0823 19:58:24.342310       1 leaderelection.go:248] attempting to acquire leader lease istio-system/703c7497.aspenmesh.io...
I0823 19:58:40.286499       1 leaderelection.go:258] successfully acquired lease istio-system/703c7497.aspenmesh.io


After deploying a DnsStaticEntry resource you will also see updates in the logs of the Leader.

2022-08-23T22:17:18.701Z            INFO      controllers/dnsstaticentry_controller.go:325       ServiceEntry NOT UP TO DATE, updating...{"host": "www.google.com", "requeueAfter": "2m0.999989093s"}
2022-08-23T22:19:19.723Z            INFO      controllers/dnsstaticentry_controller.go:319       ServiceEntry looks up to date                {"host": "www.google.com", "requeueAfter": "1m4.999999699s"}
