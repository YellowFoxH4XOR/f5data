Topic

This article applies to BIG-IP GTM  9.x through 10.x. For information about other versions, refer to the following article:

  • K14183: Configuring the BIG-IP GTM system to advertise the Listener address by way of BGP (11.x)

There may be occasions when you want to configure the GTM system to advertise the Listener address by way of the Border Gateway Protocol (BGP).

Note: The BIG-IP GTM system uses the Listener address to listen for DNS queries and identify the resolution requests for which it is responsible.

For example, if you plan to implement anycast DNS, and use BGP to distribute LDNS requests to the closest BIG-IP GTM system among a mesh of BIG-IP GTM systems sharing a Listener address, you need to advertise the BIG-IP GTM Listener address(es) by way of BGP.

Note: For more information about implementing anycast DNS, refer to RFC3258.

Advanced routing (BGP) configuration prerequisites

Before you can configure the BIG-IP GTM system to advertise the Listener address by way of BGP, the following advanced routing configuration elements must be in place:

  • The BIG-IP system must be licensed for the Advanced Routing Module (ARM), including BGP.
  • The BIG-IP system must be configured as a BGP peer with the upstream router(s).
  • The BGP configuration must be configured to redistribute kernel routes. For example, redistribute kernel.

BIG-IP GTM configuration requirements

In addition to the above advanced routing prerequisites, you must configure the following configuration elements on the BIG-IP GTM system:

  • Configuring a floating self IP address (to be used as the BIG-IP GTM Listener address)
  • Configuring the floating self-IP address as the Listener object
  • Enabling Router Advertisement for the BIG-IP GTM Listener object virtual address

Configuring a floating self IP address (to be used as the BIG-IP GTM Listener address)

In order for ZebOS to dynamically redistribute the Listener address, you must configure a floating self IP address. The floating address will be configured as the BIG-IP GTM Listener address. The steps to configure a floating self IP address are different depending on whether the system is a standalone or redundant pair device.

Configuring a floating self IP address on a redundant pair device

  1. Log in to the BIG-IP Configuration utility.
  2. Click Network.
  3. Click Self IPs.
  4. Click Create.
  5. Enter the appropriate self IP information.
  6. Select the Floating IP check box.
  7. Click Save.

Configuring a floating self IP address on a standalone device

Note: You must use the command line to configure a floating self IP address on a standalone device.

  1. Log in to the BIG-IP command line.
  2. Use the following command syntax to configure the floating self IP address:

    bigpipe self <ip_addr> { netmask <netmask> allow all floating enable vlan <vlan_name> unit 1 }

    For example, to create a floating self IP address of 10.0.0.1/8 on the VLAN named anycast, you would type the following command:

    bigpipe self 10.0.0.1 { netmask 255.0.0.0 allow all floating enable vlan anycast unit 1 }

Configuring the floating self-IP address as the Listener object

  1. Log in to the BIG-IP Configuration utility.
  2. Click Global Traffic.
  3. Click Listeners.
  4. Click Create.
  5. Select Advanced from the General Properties box.
  6. Enter the floating self IP address that you defined in the Destination box.
  7. Select either UDP or TCP from the Protocol drop-down menu.
  8. Click Save.

Enabling Router Advertisement for the GTM Listener object virtual address

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Virtual Servers.
  4. Click the Virtual Address List tab.
  5. Click the self IP / Listener address that you configured above.
  6. Select Always from the Advertise Route drop-down menu.
  7. Click the Route Advertisement box.
  8. Click Update.

Verifying that the BIG-IP system is advertising the route by way of BGP

To verify that the system is advertising / learning BGP routes, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. To access the VTY command line shell, type the following command.

    vtysh

  3. To enter enable mode, type the following command:

    enable

  4. To display BGP routes that the system is advertising / learning, enter the following command:

    show ip bgp

    For example, the following output indicates that the BIG-IP is advertising the 10.0.0.1 Listener address by way of BGP:

    #show ip bgp
