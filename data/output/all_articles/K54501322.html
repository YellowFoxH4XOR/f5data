Topic

This article applies to ASM cookies with the TS prefix. To modify Proactive Bot Defense cookies with the TSPD prefix, refer to the following article:

  • K72967239: Modifying the prefix of the ASM Proactive Bot Defense cookie name

You should consider using this procedure under the following condition:

  • You want to customize ASM cookie name formatting.

Description

The BIG-IP ASM system uses ASM cookie names to enforce security policies. The BIG-IP ASM system validates these cookies returned from clients to ensure that the cookies are not modified.

The format of ASM cookies vary depending on the following cookie types:

  • ASM Main cookie
  • ASM Feature and Frame cookies
  • ASM cookie name database variables

ASM Main cookie

The ASM Main cookie is constructed in three parts. For example, the following table displays the format of an ASM Main cookie named TS0113E842.

PrefixRevisionAffiliation
TS0113E842

ASM Feature and Frame cookies

ASM Feature and Frame cookies are constructed in four parts. For example, the following table displays the format of an ASM Feature or Frame cookie named TS0113E842028.

PrefixRevisionAffiliationSuffix
TS0113E842028

ASM cookie name database variables

Prior to 14.0.0, the ASM cookie string has a fixed format with the TS prefix. As a result, the cookie name is easily identifiable, and may be unsuitable if you are using a specific name convention for your application cookies. Beginning in BIG-IP ASM 14.0.0, you can modify the ASM cookie's prefix, revision, and suffix with the following system database variables:

  • asm.cookie_prefix
  • asm.cookie_revision_base
  • asm.cookie_suffix_base

Changing the ASM cookie format by modifying these system database variables applies to all TS cookies, including the ASM Main cookies and other ASM Feature cookies. For more information about BIG-IP ASM cookies, refer to K6850: Overview of ASM cookies.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the TMOS Shell (tmsh).

Procedures

To modify ASM cookie names, perform the following procedures:

  • Modifying the prefix
  • Modifying the revision base
  • Modifying the suffix base

Modifying the prefix

The ASM cookie prefix string has a default value of TS. To modify the prefix of the ASM cookie name, perform the following procedure:

Impact of procedure: Performing the following procedure causes a temporary traffic disruption while the Traffic Management Microkernel (TMM) process restarts. You should perform this procedure only during a scheduled maintenance period.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the prefix, use the following command syntax:

    modify /sys db asm.cookie_prefix value <new_prefix>

    For example, to use EXAMPLE as the prefix, type the following command:

    modify sys asm.cookie_prefix value EXAMPLE

  3. To verify the modified prefix, type the following command:

    list /sys db asm.cookie_prefix

  4. To restart the TMM process, type the following command:

    restart /sys service tmm

Modifying the revision base

The ASM cookie revision base is a two-digit hex value added to the cookie revision number. The default value of the revision base is 0. To modify the revision base of the ASM cookie name, perform the following procedure:

Impact of procedure: Performing the following procedure causes a temporary traffic disruption while the TMM process restarts. You should perform this procedure only during a scheduled maintenance period.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the revision base, use the following command syntax:

    modify /sys db asm.cookie_revision_base value <new_revision>

    For example, to use 4C as the revision base, type the following command:

    modify sys db asm.cookie_revision_base value 4C

  3. To verify the modified revision base, type the following command:

    list /sys db asm.cookie_revision_base

  4. To restart the TMM process, type the following command:

restart /sys service tmm

Modifying the suffix base

You can modify the suffix base of ASM Feature and Frame cookies. The ASM cookie suffix base is a three-digit decimal number added to the cookie suffix. The default value of suffix base is 0. To modify the suffix base of ASM cookie name, perform the following procedure:

Note: F5 does not recommend changing the ASM cookie suffix base without changing the prefix. An unchanged prefix with a modified suffix may overlap with the old cookie name and lead to confusion.

Impact of procedure: Performing the following procedure causes a temporary traffic disruption while the TMM process restarts. You should perform this procedure only during a scheduled maintenance period.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the suffix base, use the following command syntax:

    modify /sys db asm.cookie_suffix_base value <new_suffix>

    For example, to use 187 as the suffix base, type the following command:

    modify sys db asm.cookie_suffix_base value 187

  3. To verify the modified suffix base, type the following command:

    list /sys db asm.cookie_suffix_base

  4. To restart the TMM process, type the following command:

    restart /sys service tmm
