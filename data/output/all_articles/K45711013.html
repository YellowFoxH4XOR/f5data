Description

  • After running the bigip_add command on the BIG-IP DNS/GTM system, you find that the certificate for the BIG-IP LTM is still indicating as expired.

Environment

  • BIG-IP LTM with expired Device Certificate
  • BIG-IP GTM/DNS system, which has the BIG-IP LTM system configured as a DNS/GLSB Server.

Cause

It is necessary to first update or renew the BIG-IP LTM's expired Device Certificate with a valid one, before running the bigip_add command from the BIG-IP DNS/GTM system.

Recommended Actions

  1. Follow the procedure in K6353, to update the LTM's Device Certificate before running the bigip_add command from the BIG-IP DNS/GTM system.
