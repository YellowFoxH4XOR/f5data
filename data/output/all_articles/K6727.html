Known Issue

This is the result of a known issue. When BIG-IP LTM uses the Packet Velocity ASIC (PVA) with the FastL4 profile, the profile does not use the FastL4 idle timeout value. As a result, TCP connections are terminated well before the timeout value is specified.

F5 Product Development tracked this issue as CR70547, CR69773, CR69775, and CR62072 and it was fixed in BIG-IP LTM 9.1.3, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.
