K000147391: Is there an API interface available for f5cloudstatus.com?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-20
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147391

Description

  • You want to query the F5 Statuspage API to stay up-to-date on the latest changes and incidents.
  • You want to run a script that sends API calls to the F5 XC platform, avoiding sending requests while XC is under maintenance.
  • Query https://www.f5cloudstatus.com/ via API.

Environment

  • F5® Distributed Cloud Service
  • Alerts

Resolution/Answer

Yes, there is an API for f5cloudstatus.com :

  • F5 Distributed Cloud Status - API (f5cloudstatus.com)

Additional Information

Other possible options: 

  • Webhook
  • RSS subscription
