K15894469: Avoid UAC prompt for BIG-IP Edge client (F5EIHelper.exe) without disabling UAC in general.

Source

Description

Would like to avoid UAC prompt for Edge client (F5EIHelper.exe) without disabling UAC in general.

Environment

Relevant environmental factors specific to the topic

  • BIG-IP Edge client (F5EIHelper.exe)
  • User Account Control (UAC)

Cause

This works by design.

Recommended Actions

There is no simple way of bypassing UAC. It is recommended that the parts of the Client side application that require enhanced privilege, are provisioned by an administrator as part of the original device provisioning setup. Install the Component Installer package so that the system is capable of self update without requiring UAC. You should install the Component Installer as administrator.

  • BIG-IP Administrator: You can download the Component Installer component from the BIG-IP APM configuration utility. Select the F5 logo at the top left and locate the package in the Downloads section.
  • User: Please contact your IT department.

For more information on the Component Installer, refer to K11124534: Deployment options | BIG-IP Edge Client operations guide.
