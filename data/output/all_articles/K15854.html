Topic

When you have the BIG-IP and BIG-IP Virtual Edition (VE) systems, and you add the BIG-IP LTM module, the BIG-IP LTM system includes a free perpetual license for the BIG-IP APM Limited (formerly APM Lite) module.

Description

The BIG-IP APM Limited module includes the same feature set as a fully licensed BIG-IP APM module, with the following limitations:

  • You are restricted to 10 concurrent users and access sessions.
  • API Protection is not available
  • Hardware compression is disabled.
  • Software compression is limited to 50 Mbps.
  • Active Directory Federation Services and Proxy Integration Protocol (MS-ADFSPIP / ADFS-PIP ADFS) proxy functionality is not supported.
  • Authentication, Authorization and Auditing / Oracle Access Manager (AAA OAM) integration is not provided.
  • Secure Web Gateway (SWG) integration has the following limitations:
    • SWG forward proxy is restricted to 10 sessions.
    • Request and Response Analytics policy items are not supported.
    • The Category Lookup policy item is only supported for custom categories.

On the other hand, when you add a BIG-IP APM module license, you gain capabilities, including the following:

  • You can have from 100 through 60,000 concurrent users.
  • You can have from 5000 through 1,000,000 access sessions.
  • You can have from 500 through 50,000 SWG forward proxy sessions.
  • There is no limit for software compression.
  • API Protection is available

Note: Your capabilities and limits depend on your BIG-IP APM device type and module license options. For more information refer to: K15624537: The BIG-IP APM platform session capacity and  K13469: Determining the compression capability of your BIG-IP system (11.x - 13.x)
