  • K13896: Configuring a virtual server to use the same IP address as a self IP (11.x - 13.x)

Important: If you configure the Configuration utility and a virtual server to use the same self IP address, the virtual server takes precedence and processes connections to the address.

Configuring a virtual server and a self IP to use the same IP address on a redundant pair

When configuring a virtual server destination IP address and a self IP to use the same IP address on a redundant pair, F5 highly recommends that you use a floating self IP address. If you configure the system in this way, the system saves the virtual server configuration in the /config/bigip.conf file and synchronizes the configuration to the peer system during configuration synchronization (ConfigSync) operations. This configuration supports high availability by allowing the virtual server to float to the active unit upon failover.

Note: If you define the virtual server using a non-floating self IP address on a redundant pair, the system saves the virtual server to the /config/bigip_local.conf file, and the virtual server would not synchronize during ConfigSync operations. As a result, the virtual server would not float to the other unit when the unit becomes active.

Configuring a virtual server and a self IP to use the same IP address on a standalone system

When configuring a virtual server destination IP address and a self IP to use the same IP address on a standalone system, you must use a non-floating self IP address. Standalone BIG-IP systems do not have the option to define a floating self IP address.
