K000149667: Missing interface under VLAN section in tenant

Type
Support Solution
Published
2025-02-06
Updated
2025-03-19
Source
https://my.f5.com/manage/s/article/K000149667

Description

Once you create a VLAN, attach it to an interface, and launch a tenant, you observe that the assigned interface is missing in the tenant configuration under the VLAN section.

The bigip_base.conf file shows:

net vlan /Common/F5-VLAN-with-longer-name-than-expected {
    dag-adjustment none
    tag 100
}

instead of:

net vlan /Common/F5-VLAN-with-longer-name-than-expected{
    dag-adjustment none
    interfaces {
        1.1 {
            tagged
        }
    }
    tag 100
}

Environment

  • F5OS-A
  • VLAN
  • newly configured tenant

Cause

VLAN name with 31 characters or longer.

Recommended Actions

Use the procedure from K000135655 to shorten the VLAN name.

Additional Information

None
