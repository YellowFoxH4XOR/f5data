Description

Reactivating a license in a CCN BIG-IP device fails and similar errors are observed in the LTM log file:

mcpd[8826]: 01070608:0: License is not operational (expired or digital signature does not match contents).
2021 Apr 12 11:19:24 localhost mcpd[8826]: 01070608:0: License is not operational (expired or digital signature does not match contents).

Also, when using the Dossier option in the Secured Environment License Utility <https://secure.f5.com/ccn/programoverview.jsp>, an error shows up about including the MAC address.

Environment

  • Closed Circuit Networks - CCN site
  • BIG-IP
  • License Re-activation

Cause

The wrong MAC address may be being used when generating the license.

Recommended Actions

Use the correct MAC address, provided by the following command.

# tmsh show sys hardware

Example:
# tmsh show sys hardware

Platform
  Name  BIG-IP Virtual Edition
  BIOS Revision
  Base MAC       00:50:56:AA:BB:00
  Hypervisor     VMware Virtual Platform
  Cloud
