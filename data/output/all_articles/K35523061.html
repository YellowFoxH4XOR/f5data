Description

Traffic does not pass reliably through a virtual server when using a Venafi Certificate Manager.

You may see errors in the LTM log similar to this: "hud_ssl_handler:1208: alert(40) invalid profile unknown on VIP"
You may see errors in the LTM log similar to this: "reading: Unknown error."

Environment

  • Venafi or other centralized certificate manager
  • BIG-IP with SSL profiles

Cause
This is caused by frequent, sometimes even overlapping, certificate updates which result in a corrupt certificate on the BIG-IP.  

Recommended Actions

You should reduce the frequency of certificate updates so that updates do not overlap.  If a certificate does not change, such as a chain certificate, it should not be updated.
