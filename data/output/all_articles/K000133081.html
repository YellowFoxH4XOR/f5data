Description

You are unable to change the MTU for the BIG-IP management interface (eth0) using the tmsh utility and BIG-IP Configuration utility.

Environment

  • BIG-IP management network requiring non-default MTU

Cause

There is no TMOS command for changing BIG-IP management interface (eth0) MTU. The linux ip command can be used to configure the BIG-IP management interface (eth0) MTU, but it will not persist across reboots or upgrades.

Recommended Actions

You can run the following command in the BIG-IP command line to create a new entry in the user_alert.conf file so as to change the BIG-IP management interface (eth0) MTU setting on every boot:

tmsh run util bash -c '/sbin/ip link set eth0 mtu [new MTU]; echo \"alert set_mgmt_mtu \\\"Interface: mgmt is UP\\\" { exec command=\\\"/sbin/ip link set eth0 mtu [new MTU]\\\" } \" >> /config/user_alert.conf'

Additional Information

The RFE ID 623864 is filed to request for a tmsh command and/or BIG-IP Configuration utility setting to configure the BIG-IP management interface (eth0) MTU.
