Known Issue

Automatic installation of an antivirus EPSEC software package may trigger the mcpd process to produce a core file and restart.

This issue occurs when all of the following conditions are met:

  • You attempt to update the EPSEC software by uploading an EPSEC software package image using the Configuration utility.
  • You set the EPSEC upload Install Option to install the software package to a device group.
  • The EPSEC software package upload is terminated before the package upload completes.
  • A user attempts to establish an access session with an access profile in which the the access policy is configured with an agent that uses EPSEC software.

Impact

The BIG-IP APM system is not functional, and the mcpd process restarts continuously.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates an mcpd core file to the /shared/core directory, with a timestamp that correlates with the traffic interruption.
  • The BIG-IP system logs messages to the /var/log/audit file that appear similar to the following example:

Workaround

To work around this issue, you can re-upload the EPSEC software update to ensure that the file is completely uploaded prior to installing the update. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log on to the Configuration utility.
  2. Navigate to System > Software Management > Antivirus Check Updates.
  3. Select the Package Status tab.
  4. Click Upload Package.
  5. Click Browse.
  6. Select the EPSEC software update image from your local device.
  7. Select Install Option, Do not Install.
  8. Click Upload.
  9. After the upload has completed, select the EPSEC software image name.
  10. Click Install Package.
  11. Select the appropriate Install Option for your environment.
  12. Select the appropriate Device Group to install the EPSEC software update.
  13. Click Install.
