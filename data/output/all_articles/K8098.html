Issue

When logging on to the FirePass controller with the FirePass Windows Logon Integration component, users may receive an error message that appears similar to the following example:

Error 1327: Logon failure: user account restriction
Possible reasons are blank passwords not allowed, logon hour restrictions, or a policy restriction has been enforced

This error message occurs when one or more of the following conditions are met:

  • The client failed a pre-logon check.

    For example, the pre-logon sequence contains the Check Time inspector and the user attempted to access the FirePass controller outside of working hours.

  • The pre-logon sequence contains one or more inspectors that are not supported by the Windows Logon Integration component.

    For example, the Check Processes inspector is not supported by the Windows Logon Integration component. If the pre-logon sequence contains the Check Processes inspector, users cannot connect to the FirePass controller with the Windows Logon Integration component.

The FirePass Windows Logon Integration component allows users to establish a FirePass VPN connection when they log on to their Windows systems without modifying Microsoft GINA components. The connection appears as a dial-up connection on the Windows client system, and the Windows Logon Integration component provides support for logon scripts such as drive mappings. For more information about the Windows Logon Integration component, refer to the FirePass Controller Administrator Guide.

Workaround

If you need to support Windows Logon Integration, remove all pre-logon inspectors that are not supported by the Windows Logon Integration component. For more information about supported pre-logon inspectors, refer to K8097: Windows Logon Integration support for pre-logon inspectors.

You can configure pre-logon sequences on the Users: Endpoint Security: Pre-Logon Sequence page in the FirePass Administrative Console.
