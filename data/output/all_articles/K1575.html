Issue

After successfully copying the UCS file to the peer unit and running the bigpipe config sync all command, BIG-IP returns the following error:

FATALL executing /bin/sh /tmp/im.4526/script.post

BIG-IP supports synchronization only between controllers of the same version. To guarantee successful synchronization between controllers, you must be running the exact same version on both.

If you run bigpipe config sync on two BIG-IP Controllers with different version numbers, only the bigip.conf file copies to the peer, no installation or maintenance scripts are copied. This will cause an error when you run the bigpipe config sync all command.
