Known Issue

This is the result of a known issue. Creating a static route for a network that is directly connected to the BIG-IP system creates an invalid route entry in the routing table, and prevents the BIG-IP system from correctly routing traffic using the defined route.

F5 Product Development tracked this issue as CR90986 and CR92047 and it was fixed in BIG-IP LTM versions 9.4.4 and 9.6.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in hotfix BIGIP-9.4.3-14.3-HF3 issued for BIG-IP version 9.4.3. You may download this hotfix or a later version of this hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
