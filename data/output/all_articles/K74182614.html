Issue

Error Message

01070259:3: Requested member (<interface name>) is untagged on another VLAN

In this error message, note the following:

  • <interface name> is the name of the interface you are attempting to add to the Virtual Local Area Network (VLAN).

For example:

01070259:3: Requested member (test_trunk) is untagged on another VLAN

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • A VLAN is configured with an interface as an untagged member.
  • An additional VLAN is configured with the same interface as an untagged member, and the configuration fails with the above error message.

Impact

Attempts to configure the VLAN with the affected interface fails and the BIG-IP system logs the above error message.

Recommended Actions

To avoid this error, you must perform one of the following actions:

  • Remove the interface from the previously configured VLAN before adding it as an untagged member in the additional VLAN.
  • Add the interface to the additional VLAN as a tagged member.
