Description

When using SSLO to send decrypted FTPS (secure ftp) via external inspection device (ie: IPS, ICAP, virus scanner), only the control channel is sent for inspection.

Environment

  • BIG-IP configured via SSLO with listener for FTPS (normally port 990) with plain text inspection device and FTP profile.

Cause

Configuration error

Recommended Actions

The FTP profile requires "ftps-mode allow" in order for SSLO to read the FTP request specifying the port to use and open the appropriate pinholes for the traffic to pass. When using passive mode, this is the PASV command. 

In order for the decrypted data channel traffic to be sent to the inspection device, you will need to configure "inherit-parent-profile enabled".

The ftp profile should be

ltm profile ftp ftp-via-sslo {
    allow-active-mode disabled
    app-service none
    defaults-from ftp
    ftps-mode allow
    inherit-parent-profile enabled
}
