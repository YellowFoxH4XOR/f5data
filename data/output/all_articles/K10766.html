Known Issue

This is the result of a known issue. Dynamic routes are not propagated to TMM. The tmrouted process does not correctly parse the interface name in routing messages sent to TMM, and consequently corrupts the value in the VLAN field of corresponding MCP messages. This results in TMM ignoring route messages and not accepting dynamic routes. Dynamic routes are correctly propagated to Linux.

Note: The tmrouted process is the routing table management daemon, which updates the TMM routing table based on the kernel routing table. For more information, refer to K8035: Overview of BIG-IP daemons.

F5 Product Development is tracking this issue as CR132470.

This issue was fixed in BIGIP-9.4.8-379.3-HF1 issued for BIG-IP version 9.4.8. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
