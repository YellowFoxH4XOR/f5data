K8135: Configuring the BIG-IP version 4.5.x system to use an intermediate or chain certificate with the SSL proxy

Topic

In order to use the intermediate certificate with BIG-IP version 4.x, you must perform the following two procedures:
  • Obtaining the Intermediate CA Certificate
  • Installing the Intermediate CA Certificate on the BIG-IP system

Note: Intermediate certificates or chain certificates are obtained from the vendor of the certificate. For example, the Verisign intermediate certificate is available from the following website: http://www.verisign.com/support/verisign-intermediate-ca/index.html

The intermediate certificate or chain certificate must be in PEM format.


Obtaining the Intermediate CA Certificate
 
The most common Verisign intermediate certificates are as follows:
  • Secure Site certificate, which is available at the following website: http://www.verisign.com/support/verisign-intermediate-ca/secure-site-intermediate/index.html
  • Secure Site Pro certificate, which is available at the following website: http://www.verisign.com/support/verisign-intermediate-ca/secure-site-pro-intermediate/index.html

Installing the Intermediate CA Certificate on the BIG-IP system
  1. Copy the entire text of the Intermediate CA Certificate from the VeriSign website, including the -----BEGIN CERTIFICATE----- and -----END CERTIFICATE----- lines.
  2. Log in to the BIG-IP command line.
  3. Change directories to /config/bigconfig/ssl.crt by typing the following command:

    cd /config/bigconfig/ssl.crt

  4. Using a text editor, create a file called intermediate-ca.crt, and paste the contents of the CA Certificate into the intermediate-ca.crt file.

    Note: Make sure not to include any leading or trailing whitespace before the beginning and ending hyphens.

  5. To restart the proxyd process, type the following command:

    bigpipe load

Note: In a redundant system, the keys and certificates must be in place on both BIG-IP controllers.
