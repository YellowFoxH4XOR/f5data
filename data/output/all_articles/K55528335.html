Description

The subscriber that is connecting their PlayStation (PS) network through the BIG-IP CGNAT environment and showing the NAT type is 3 (strict) instead of type 2.
 

Environment

  • PlayStation NAT type 3 (strict)
  • BIG-IP CGNAT

Cause
The LSN pool configuration does not configure the inbound connection as "automatic". 
The LSN pool configuration does not configure the persistence as "Address Port".

Recommended Actions

Ensure your LSN pool configuration has the proper configuration.
 1. The inbound connection must set to "automatic".
 2. The persistence must set to "Address Port".

None
