Issue

Error Message

011b020b:3: Error '<reason>' scanning buffer '<buffer_number>' from file '<file_name>'

In this error message, note the following:

  • <reason> is the error message reason.
  • <buffer_number> is the buffer number. This field is typically empty.
  • <file_name> is the name of the file.

For example:

011b020b:3: Error 'Inappropriate ioctl for device' scanning buffer '' from file '/var/rrd/blade0cpu.info'

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A round-robin database (RRD) info file is not valid. 

The end of the RRD file should have a checksum hash that begins "#CRC " followed by a number. This line was not found.

Impact

Invalid info files prevent certain performance-related statistics from being presented accurately when you use the Configuration utility. 

Recommended Actions

To work around this issue, you can remove the invalid info and corresponding data files and restart statsd. To do so, perform the following procedure:

Impact of procedure: Some historical data may be missing from the BIG-IP system's performance graphs.

  1. Log in to the command line of the affected BIG-IP system.
  2. To remove the invalid info file, use the following command syntax:

    rm -rf <path to file>

    For example, to remove the info file named blade0cpu.info, type the following command:

    rm -rf /var/rrd/blade0cpu.info

  3. To remove the corresponding data file, type the following command:

    rm -rf /var/rrd/blade0cpu

  4. To restart the statsd process and rebuild the deleted files, type following command:

    tmsh restart sys service statsd
