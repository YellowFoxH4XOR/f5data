K000093007: BIG-IQ 8.2.0.1 DNS Generic Host gets wrong monitor assigned

Type
Support Solution
Published
2022-12-06
Updated
2022-12-06
Source
https://my.f5.com/manage/s/article/K000093007

Description

When discovering a BIG-IP device with DNS Generic host server object it automatically gets /Common/bigip monitor assigned to it in BIG-IQ configuration even if there is no monitor assigned to it on the BIG-IP device itself.

Environment

BIG-IQ discovering DNS Generic host from BIG-IP configuration.

Cause

ID1184425 DNS Server is assigned with bigip Health monitor even though the product is not bigip when importing.
