K07715212: Error during upgrade due to UCS failing to be created

Type
Support Solution
Published
2021-06-24
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K07715212

Description
During upgrade error message displayed due to UCS not being able to be created

  • [ERROR][Timestamp][/cm/shared/esmgmt/upgrade/regular/a71df215-70e5-4388-93e8-33c6522bf3b3/worker RegularClusterUpgradeProcessTaskWorker] Software installation failed for device 10.0.0.1 due to 'Device installation failed due to UCS backup failed 10.0.0.1 due to Device 10.0.0.1 is not active.'. Rolling back.

Environment

  • BIG-IQ

Cause

  • BIG-IQ localhost discovery is required before performing remote device discovery
  • [root@bigiq1:Active:Standalone] preUpgradeChecks # curl http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | /usr/bin/json-format

          "state": "VALIDATION_FAILED",   <<<<<<<----------- 
          "errors": "Unable to add device to cm-shared-all-big-iqs group. Device does not meet group validation requirements. \n Property name: productName Expected: BIG-IQ Received: ",
          "address": "10.0.0.1"
  • For example:

    [root@bigiq1:Active] config # curl http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | /usr/bin/json-format

    Should return:

      "items": [
        {

          "uuid": "8918277c-ca79-49d8-859e-bf7b5fdxxxxx",
    ...
          "deviceUri": "https://10.0.0.1:443",
          "machineId": "422031b5-a132-3a57-5754-aa49f88xxxxx",
          "state": "Active",
          "address": "10.0.0.1",


     

Recommended Actions

  1. Do local discovery first.
