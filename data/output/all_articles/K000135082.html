Description

You are getting this alerts/messages continuously.

011d0004:3: Disk partition /var/log (slot 5) has only 8% free

alertd[7151]: 01100048:0: Log disk usage still higher than 80% after logrotate and 24 times log deletion

This is the /var/log file system storage report output from the BIG-IP 

df -h /var/log

Filesystem Size Used Avail Use% Mounted on

/dev/mapper/vg--db--sdb-dat.log.1 6.9G 6.0G 601M 92% /var/log

Environment

  • LTM
  • Disk Space Issue

Cause

It is possible that the error messages are caused by the /var/log/btmp file; it is huge in size as it stores failed login attempts. It is a binary file which contains the data of the login attempts made on the BIG-IP. 

Recommended Actions

  1. You should copy /var/log/btmp file to some other Linux system for further investigation and to Identify account, IP address, timestamps of incoming connections
  2. To make some free space you may truncate btmp file on BIG-IP using the following command:

    >/var/log/btmp

    For example,

    [root@big-ip:Active:Standalone] config # ls -l /var/log/btmp
    -rw-------. 1 root utmp 804 Mar 31 06:17 /var/log/btmp
    [root@big-ip:Active:Standalone] config # >/var/log/btmp
    [root@big-ip:Active:Standalone] config # ls -l /var/log/btmp
    -rw-------. 1 root utmp 0 Mar 31 23:46 /var/log/btmp
