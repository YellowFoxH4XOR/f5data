This security advisory describes a TCP vulnerability.

Various vendors' TCP/IP implementations handle packets containing unusual flag combinations in different ways, which may lead to a violation of implicit or explicit security policies. For example, an attacker may be able to bypass network access policies by setting both the SYN and FIN flags within a TCP packet. This may make it possible for an attacker to establish connections with hosts which would otherwise be inaccessible, in violation of implied security policies. As a result, an attacker may be able to send data to hosts and services that they ordinarily cannot reach. A similar exploit is possible if the attacker sets both the SYN and RST flags within a TCP packet. The existence of this vulnerability in any particular network device is implementation-dependent.
