K14553345: MacOS EdgeClient Reports ''Error: Tunnel Server already launched''

Type
Support Solution
Published
2020-10-20
Updated
2023-01-31
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K14553345

Description
When MacOS users suddenly hibernate or 'sleep' the laptop,  It may  put the SVPN process in a 'stuck' state.  When this happens,  as the user restores the laptop, and attempts to re-connect to the VPN tunnel,  they may receive the following errors: 
 

edge.log 
2019-06-06, 8:36:06:103, 29190,9005399,edge, 2, /TunnelController.mm, 185, TunnelController, tunnelError(), Error code, Tunnel Server already launched
2019-06-06, 8:36:16:187, 29190,9005399,edge, 1, /SvpnHandler.cpp, 256, SvpnHandler::LaunchSvpn, (0xfffffffe) EXCEPTION - TunnelService, TunnelServer already launched, pid, <PID>

Environment

  • BIG-IP APM
  • MacOS Edge Client
  • users Hibernating / Sleeping the client machine suddenly or intermittently. 

Cause
SVPN process becoming stuck due to a incomplete disconnect process.

Recommended Actions

Use the following options:
  • This maybe due to ID 978945. Update/upgrade your APM Clients to 7.2.2 or later. For more information, refer to APM Client 7.2.2 release notes.
  • The svpn process creates and manages the VPN tunnel on MacOS clients. All causes of this error have not been determined, but F5 support has determined that this issue can occur in some cases where the MacOS system is abruptly put to sleep and/or hibernated, causing the svpn process to not be fully shut down.
  1. Exit the BIG-IP Edge Client.

    Note: You must quit the application by selecting the BIG-IP Edge Client in the menu bar and Quit BIG-IP Edge Client.

  2. From terminal on the MacOS kill the svpn process ID
    • sh-3.2# ps aux | grep svpn
      • root <PID> 0.0 0.0 4354076 8152 ?? S 8:34AM 0:00.12 /Library/Internet Plug-Ins/F5 SSL VPN Plugin.plugin/Contents/Helpers/svpn svpn
    • sh-3.2# sudo kill -9 <PID>
  • Reboot the MAC client.
