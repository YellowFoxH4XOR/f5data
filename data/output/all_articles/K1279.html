In the following configuration, the BIG-IP/3-DNS Controller is acting as a server for iControl communications. The configuration would appear as follows where traffic to the BIG-IP/3-DNS Controller is sent through an upstream NAT:

Note: The NAT device is sending the BIG-IP's address through the NAT, not the iControl client. In this example, the BIG-IP sees the iControl client's untranslated address.

To configure this, perform the following steps:

  1. From the BIG-IP/3-DNS Controller command line, type:

    config

  2. Type (I) to select the Initialize iControl Portal option.
  3. Verify that IIOP Port is 683, and press Enter.
  4. Verify FSSL Port is 684, and press Enter.
  5. When prompted for the IIOP Host entries, add the IP address for the upstream NAT.
  6. When prompted for the FSSL Host entries, add the IP address for the upstream NAT.
  7. Accept the default values for all other options.
  8. Exit the configuration menu.
  9. Reboot the controller.

Example network path scenario

If the NAT device has a translated address of 192.168.14.161 and BIG-IP has IP address of 20.20.20.1, both the IIOP Host and FSSL Host entries configured on BIG-IP would be as follows:

20.20.20.1, 192.168.14.161
