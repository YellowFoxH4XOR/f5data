Known Issue

Modifying a BIG-IP high availability (HA) redundant server object IP address may cause BIG-IP DNS monitoring to fail.

This issue occurs when all of the following conditions are& met:

  • Your BIG-IP DNS system is configured with a BIG-IP server object that is an HA redundant pair.
  • You modify the BIG-IP server object to move a configured IP address from the address list to the peer address list or when moving from the peer address list to the address list.

Impact

BIG-IP DNS monitoring of the BIG-IP pair reduces to monitoring only a single device of the HA pair.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the BIG-IP DNS system attempts to monitor only the standby device of the BIG-IP redundant pair, the BIG-IP standby device ignores the BIG-IP DNS probe request. The BIG-IP DNS system marks the BIG-IP redundant servers as down, in addition to all hosted virtual servers of the BIG-IP server HA pair.
  • When the BIG-IP DNS system attempts to monitor only the active device of the BIG-IP pair and the BIG-IP server HA pair experiences a failover event, the BIG-IP DNS system marks the BIG-IP redundant servers as down, in addition to all hosted virtual servers of the BIG-IP server HA pair.

Workaround

To work around this issue, you can delete the IP address that you moved from one address list to the other and add it back to the intended IP address list. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure may temporarily interrupt BIG-IP DNS monitoring of the BIG-IP server while the IP address is reconfigured.

  1. Log in to the Configuration utility of the affected BIG-IP DNS system.
  2. Navigate to DNS > GSLB > Servers.
  3. Click the name of the affected BIG-IP server configuration.
  4. For Address List or Peer Address List, click the IP address that previously changed IP address lists.
  5. Click Remove.
  6. Click Update.
  7. Type the deleted IP address in the intended IP address list (Address List or Peer Address List) Address text box. If required for your environment, enter the translation IP address in the Translation text box.
  8. Click Add.
  9. Click Update.
