K000163635: Administrator user is not able to create iFiles from specific source-paths

Type
Support Solution
Published
2026-10-09
Updated
2026-10-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163635

Description

Error when creating iFiles from source-path in /config, /root, /home, and other restricted directories.


# tmsh create sys file ifile testfile source-path file:/config/testfile.txt

Data Input Error: File location - (file:/config/testfile.txt) is not allowed.

 

Environment

- Data Input Error: File location - (file:/config/testfile.txt) is not allowed.

- the same operation succeeded on versions prior 17.5.1.6


 

Cause

Fix for ID2227441 introduced restrictions on ifile creation.

Specifically, these prefixes are not allowed when creating ifile objects:

"/etc"

"/root"

"/bin"

"/sbin"

"/usr"

"/boot"

"/lib"

"/lib64"

"/proc"

"/sys"

"/dev"

"/config"

"/shared/ssh"

"/var/db"

"/home"

 

 However, this restriction should not affect "UID 0" users (root and admin).


Answer/Recommended Actions

That's considered a bug, and new ID2351525 has been raised.
