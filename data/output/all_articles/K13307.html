Known Issue

When a backend web server sends an HTTP 100 Continue response to the BIG-IP APM system, the TMM process may core and restart.

This issue occurs when all of the following conditions are met:

  • The BIG-IP virtual server is configured with an access policy.
  • The backend server sends an HTTP 100 Continue status code.

Impact

The TMM process becomes unresponsive and traffic processing is temporarily interrupted.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The TMM process becomes unresponsive and produces a core file.
  • The BIG-IP system generates an SIGABRT fault and stack trace to the /var/log/tmm file.
