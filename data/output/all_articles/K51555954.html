Description

 AWS Telemetry stops working if the root shell login is disabled.

Environment

  • AWS Telemetry implemented
  • root access is disabled, for example running the command:

modify /sys db systemauth.disablerootlogin value true

Cause

The root account is required for Telemetry to work.

Recommended Actions

None
