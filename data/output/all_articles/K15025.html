Issue

This article applies to BIG-IP APM and BIG-IP Edge 11.x. For information about other versions, refer to the following article:

  • K11707: Error Message: failed in queryActiveDirectoryUser(): no matching user found with filter

Error Message

Session variable 'session.ad.<path/access policy name>_active_directory_query_ag.errmsg' set to 'no matching user found with filter (sAMAccountNam=<username>)'

In this error message, note the following:

  • <path/access policy name> is the name of the BIG-IP APM partition where the access policy resides, and the policy name of the affected access policy.
  • <username> is the name of the user who is attempting to establish a session with the access policy.

For example:

info apd[11703]: 01490007:6: 49cc2d28: Session variable 'session.ad./Common/Wizard_One_act_active_directory_query_ag.errmsg' set to 'no matching user found with filter (sAMAccountNam=bart)'

In this example, sAMAccountName is misspelled in the Search Filter field and is missing the last character e. No error message was generated at the time the Search Filter was configured. Users will be able to authenticate correctly with no error messages because authentication only inspects the user's credentials. However, any action that requires an Active Directory query will fail to run correctly.

If you view an error message that appears similar to the previous example, confirm that the search filter does not contain any typographical errors.

Message Location

You may encounter this message in the following location:

  • In the /var/log/apm directory

Additionally, users who attempt to access the affected access policy may receive the following logon error message:

Your session could not be established.
The session reference number: <Session-ID>
Access was denied by the access policy. This may be due to a failure to meet access policy requirements.
If you are an administrator, please go to Access Policy >> Reports : All Sessions page and look up the session reference number displayed above.

Note: The <Session-ID> example 598f901e is the session id variable assigned by the BIG-IP APM system to track individual sessions. The BIG-IP APM administrator can use this session id variable to troubleshoot issues with the session.

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP APM virtual server has an assigned access policy.
  • The access policy is configured with Active Directory or LDAP authentication.
  • The access policy is configured to query Active Directory or LDAP using an assigned variable.
  • The attribute is misspelled or is not a known value.

Impact

The access session fails to establish.

Recommended Actions

Review the AD Query configuration of the affected access policy search filter settings for syntax and variable use.
