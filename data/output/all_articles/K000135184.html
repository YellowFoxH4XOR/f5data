K000135184: Public Key authentication is failing after upgrade

Type
Support Solution
Published
2023-07-13
Updated
2026-09-25
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135184

Description

Public Key Authentication is failing with the following error message - Authentication refused: bad ownership or modes for file /home/x/.ssh/authorized_keys


Environment

SSH

Cause

Upgrade

RMA

Recommended Actions

Change owner to root using the full path to the directory mentioned in the error message. Example:


chown root /home/x/.ssh/authorized_keys

Additional Information
