K12386: Internet Explorer 7 or 8 blocks session cookies of web pages located inside an HTML frame

Topic

When using Internet Explorer 7 or 8 to access a web page that loads a secondary page inside an HTML frame and the secondary web page utilizes a session cookie, Internet Explorer security functions will block the cookie for the secondary page. This action may cause unexpected behaviors in the web page. The BIG-IP APM system relies on a session cookie to track the state of a browser session. If the BIG-IP APM session is iframeded in the frame of another web page, users will receive the following error message:

Your session could not be established

This behavior is caused by Internet Explorer.

Workaround

You can work around this issue by using one of the following three methods:

  • Using an alternate browser, such as Firefox or Safari.
  • Redesigning the host web page so that the affected web page is not located inside an HTML frame.
  • Enabling the Always allow session cookies option in Internet Explorer.

To enable the Always allow session cookies option in Internet Explorer, perform the following procedure:

  1. Open Internet Explorer.
  2. From the Tools drop-down menu, select Internet Options.
  3. Click the Privacy tab.
  4. Click Advanced.
  5. Select the Override Automatic Cookie Handling check box.
  6. Select the Always allow session cookies check box.
