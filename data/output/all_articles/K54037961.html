Description

  • BIG-IP device unexpected failover and reboot
  • Message similar to the following can be seen on /var/log/ltm

    crit tmm1[21360]: 01010025:2: Device error: hsbe2 hsb_lbb0 hde2_crc_errs count 212.
    warning overdog[7227]: 01140029:4: HA dataplane_inoperable_t tmm1 fails action is reboot.
    emerg overdog[7227]: 01140043:0: Ha feature dataplane_inoperable_t reboot requested.
    crit overdog[7227]: 01140102:2: Overdog daemon requests reboot.
    notice overdog[7227]: 01140104:5: Watchdog touch disabled.
    notice sod[8261]: 010c0044:5: Command:  go standby overdog.
    notice sod[8261]: 010c0052:5: Standby for traffic group traffic-group-1.
    notice sod[8261]: 010c0018:5: Standby

Environment

  • BIG-IP hardware devices
  • Reboot
  • Failover

Cause

Seen behavior is expected due to fix introduced for Bug ID 725791

Recommended Actions

These errors may indicate a hardware error in the HSB SRAM that impedes traffic through embedded Packet Velocity Acceleration (ePVA). To confirm if there is hardware issue we will recommend to Run an End User Diagnostics on the unit in question.

K7172: Overview of the End User Diagnostics software
