Description

  • When attempting to import a BIG-IP DNS Device into the BIG-IQ CM, it fails with the below error message.
  • Error message in Import:
    Failed copying from source to target: java.lang.IllegalArgumentException: failureRcode notimpl Invalid failureRcode - 'notimpl'. Valid values are [noerror, formerr, servfail, nxdomain, notimp, refused]

Environment

  • BIG-IP DNS wideip failure-rcode set to "notimpl"
  • Importing into BIG-IQ Centralized Manager

Cause

The is due to a known issue. Bug ID 851841
The BIG-IP uses the value for Not Implemented is "notimpl" while the BIG-IQ only accepts the value "notimp"
At this time, you cannot use the "Not Implemented" failure-rcode value if you want to import the BIG-IP DNS configuration into BIG-IQ.

Recommended Actions

In order to import the BIG-IP DNS device into BIG-IQ CM, follow the below Plan of Action.

  1. Set the rcode to something within the allow scope for BIG-IQ  [noerror, formerr, servfail, nxdomain, refused]
    Example:
    gtm wideip a /Common/mysite.com {
        aliases {
            mysite.alias.com
        }
        failure-rcode notimpl               <--------------------------------------needs to be [noerror, formerr, servfail, nxdomain, refused]
        failure-rcode-response enabled
        pools {
            /Common/mysite_pool {
                order 0
            }
        }
    }
     
  2. On the BIG-IP DNS device directly:
    tmsh modify gtm wideip a mysite.com failure-rcode noerror
    tmsh save sys config
     
  3. On the BIG-IQ CM, you will need to Re-Discover and Re-Import the BIG-IP DNS device, and it should be successful.
