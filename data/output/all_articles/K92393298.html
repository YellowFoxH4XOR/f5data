Policy Information

F5 is announcing the End of Life (EoL) of the F5 APIC static device package, effective October 28, 2016.

ProductVersion
Cisco APIC1.1 ( 1o), 1.1(2h)
BIG-IP11.4.1 and later

Old Behavior

F5 introduced the static device package so you could use it with Cisco APIC environments and integrate BIG-IP devices into the Cisco Application Centric Infrastructure (ACI).  

Alternatives

Using F5 iWorkflow, you can deploy the Service Graphs functionality that includes new and existing BIG-IP devices in the Cisco ACI. For additional information, refer to: K11198324: F5 iWorkflow compatibility matrix.

Product Support

F5 plans to end support for the F5 APIC static package, which applies to the following products:

VersionFeatureEnd of Technical Support (EoTS)End of Software Development (EoSD)
1.2.0F5 APIC static package31-Dec-2016  30-Sep-2016

Recommended Actions

F5 recommends that you deploy the dynamic device package in iWorkflow production environments.
