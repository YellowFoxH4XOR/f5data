K20900124: All RDP connections allowed using the same .rdp file from different computers

Type
Support Solution
Published
2022-08-10
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K20900124

Description

Copying .rpd file from one computer to another allow connection, when should be denied because it's not using the same APM session ID.
You might receive next error in the original computer:
"You have been disconnected because another connection was made to the remote computer"

Environment

  • RDP profile 

Cause
Bug ID 1033253

Recommended Actions

Restrict Single Client IP on Access Profile configuration.
  1. Go to Access ›› Profiles / Policies : Access Profiles (Per-Session Policies)
  2. Click the profile in question
  3. Look for "Restrict to Single Client IP" and click the checkbox


Additional Information
None
