Known Issue

Remote role groups may not save to the bigip.conf configuration file.

This issue occurs when the following condition is met:

  • You attempt to create a remote role group using the BIG-IP Configuration utility

Impact

Remote role groups may exist only in memory and will be deleted from the running configuration following a reboot or configuration reload.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The remote role group exists only in memory and may be viewed when running the following tmsh command:

    tmsh list auth remote-role
  • The remote role group does not appear in the bigip.conf configuration file when running the following command:

    cat /config/bigip.conf
  • If the BIG-IP configuration is reloaded or the BIG-IP system is rebooted, the remote role group will be deleted from the running configuration.

Workaround

To work around this issue, you can create a new remote role group using the Traffic Management Shell (tmsh). To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. To create a new remote role group, use the following tmsh syntax:

    modify auth remote-role role-info add { <group-name> { attribute <attribute-string> console <terminal-access> line-order <number> role <role-name> user-partition <partition-name-string> }

    For example, to create a new remote role group named example_role with the attribute for LDAP authentication, disabled console access, line order value of 1001 and granting the role of manager in all partitions to the remote users assigned to this role, use following syntax:

    modify auth remote-role role-info add { example_role { attribute memberOF=cn=BIG-IPmanagerGroup,cn=users,dc=mydept,dc=mycompany,dc=com console disabled line-order 1001 role manager user-partition all } }
  3. Save the configuration in tmsh by typing the following command:

    save sys config
  4. To exit tmsh, type quit and press Enter.
