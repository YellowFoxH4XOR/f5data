K54955814: How to create a DTLS Virtual Server for Network Access VPN

Description

Network Access VPN tunnels have the ability to allow DTLS connections, in some environments this can increase performance for VPN connections.

Environment

  • BIG-IP APM
  • Network Access VPN configured and working on a TLS Virtual Server.
  • Port 4433 Allowed in network for UDP DTLS connections

Cause

By default, VPN connections are established with TLS. These connection-oriented connections can in some environments be slower. DTLS can be enabled.

Recommended Actions

Enable DTLS on the Network Access profile:

  1. Login to the Configuration Utility
  2. Navigate to:

    Access  ››  Connectivity / VPN : Network Access (VPN) : Network Access Lists  ››  Click on your network resource you would like to enable DTLS on.

  3. Click on the Network Resource tab.
  4. From the drop down box Client Settings: Choose Advanced.
  5. Check the box for DTLS.
  6. Ensure the DTLS Port is set to 4433.
  7. Click Update

Create a DTLS Virtual Server:

  1. Login to the Configuration Utility
  2. Navigate to:

    Local Traffic  ››  Virtual Servers : Virtual Server List   ››  Click Create...

  3. Configure the DTLS Virtual Server with the following settings and leave the rest default
     
    ObjectValue
    NameDTLS_NA_VS
    Destination AddressSame IP Address as your TLS Virtual Server for Network Access
    Service Port4433
    ProtocolUDP
    SSL Profile (Client)Choose the same SSL Profile applied to your TLS Virtual Server
    Connectivity ProfileChoose the same Connectivity Profile as your TLS Virtual Server
  4. Click Finished

Ensure your Access Policies are Applied and connect. This configuration should allow you to connect your VPN tunnels on DTLS.
The TLS Virtual Server is required to establish the APM session and then it will switch to DTLS once the connection is established.

Additional Information

DTLS version 1.2 (DTLSv1.2) based on RFC6347 is now supported in BIG-IP version 16.0.0 in combination with APM Edge Client 7.2.1. By default, DTLSv1.2 is disabled in the SSL Profile. To enable it, perform the following procedure:
  1. navigate to Local Traffic > Profiles > SSL > Client SSL and select the appropriate profile.
  2. In the Options List, Select 'No DTLS v1.2' and click 'Disabled' then click 'Update' to save the changes.

For more information on BIG-IP APM support for DTLS 1.2, refer to K24074415: BIG-IP APM network access VPN support for DTLS 1.2.
