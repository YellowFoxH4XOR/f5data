Description

After applying a recent Live Signature Update, multiple false positives (blocking) may occur in BIG-IP ASM / Advanced WAF environments. This can result in legitimate Application traffic being blocked across multiple virtual servers and security policies.

Environment

  • BIG-IP ASM / Advanced WAF 
  • Multiple services use the same Attack Signature(s)
  • Live Attack Signature Updates applied

Cause

BIG-IP ASM / Advanced WAF manages Attack Signatures at the individual security policy level. There is no built-in method to globally disable specific attack signatures across all security policies in a single action. As a result, when a problematic signature is introduced or updated, it must be disabled manually in each affected Security Policy. 

Recommended Actions

To disable specific attack signatures that are causing false positives, you must perform this action at the individual security policy level. Disabling signatures can be done via the WebUI or programmatically using the iControl REST API.

Refer to the following Articles for step-by-step instructions:

K40449514: How to disable attack signature for the whole policy

K23231880: Enabling and disabling attack signatures using iControl REST

Tip: As a temporary workaround, you may revert to a previous signature version, but this is not recommended for long-term use as it may expose the environment to new threats.
