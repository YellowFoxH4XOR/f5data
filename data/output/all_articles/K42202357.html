Description
BIG-IP will generate an error when attempting to execute a name change with the wrong original hostname specified.

This error may be seen in the logs:

Mar 25 20:08:08 example.f5.com err mcpd[10702]: 01020036:3: The requested Re-Key (system device) was not found.

Environment

  • BIG-IP
  • Changing the hostname in the CLI

Cause
This error can occur as a result of incorrect command syntax.

Recommended Actions
The command syntax to change the device name of the BIG-IP from the CLI is:

tmsh mv cm device <old device name> <new device name>
