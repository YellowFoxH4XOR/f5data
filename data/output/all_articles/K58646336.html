Description

You are experiencing issues when trying to transfer files using active FTP. Active FTP is not working properly, while passive FTP is functioning as expected. The FTP process hangs at the 150 STOR stage for an extended period before ultimately resulting in the following error message:

FTP Response: 550 STOR failed: Client timed out during transfer.

Environment

  • Running on version 14.1.2.1 with an Engineering Hotfix applied
  • VLAN-group with transparent mode is being used
  • No SNAT configured

Cause

The issue is caused by the transparent VLAN-group preserving the MAC address of both the client and server during the TCP handshake. This is related to Bug ID 868209 , which states that transparent VLAN-group with standard virtual-server performs L2 forwarding instead of pool selection.

Recommended Actions

Contact F5 support to request an Engineering Hotfix specifically addressing this issue
