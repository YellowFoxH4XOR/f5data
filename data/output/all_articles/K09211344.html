Description

When trying to restart icrd service on older version of BIG-IP for e.g. 11.x or older in command line, it fails with below error output.

[root@BIG-IP:Active:Standalone] config # bigstart restart icrd
Couldn't find service: icrd
Couldn't find service: icrd

[root@BIG-IP:Active:Standalone] config # tmsh restart sys service icrd
Couldn't find service: icrd
Couldn't find service: icrd

Environment

BIG-IP 11.x or older 

Cause

In 12.x & later versions restjavad service controls icrd process, so there is no more icrd process. 

Recommended Actions

Instead of restarting icrd, restart restjavad using below command which controls icrd process:
Impact of workaround: Performing the following procedure should not have a negative impact on your system.

bigstart restart restjavad

OR

tmsh restart sys service restjavad
