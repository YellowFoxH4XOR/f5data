K000157275: Data Collection Device report 'Device is no longer in ES cluster' alert

Type
Support Solution
Published
2025-11-13
Updated
2025-11-13
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000157275

Description

In BIG-IQ version 8.4.0, users may encounter an alert stating "Device is no longer in ES cluster" for one or more Data Collection Devices (DCDs). This issue appears in the BIG-IQ GUI under the Data Collection Cluster tab, where the affected DCD displays a yellow triangle and the cluster health status indicates that "Alert logs are currently not being replicated to other devices.

Environment

  • Data Collection Devices
  • Data Collection Cluster

 

Cause

Unknown at time of publication

Recommended Actions

Remove the affected DCD from the BIG-IQ Central Manager (CM) using the GUI:

1.Navigate to the Data Collection Devices tab in the BIG-IQ GUI.

2.Select and remove the affected DCD from the cluster.

3. Verify connectivity between CM and DCD over port 9300 and 443

telnet <IP> 443

telnet <IP> 9300

4. Re-add Back the DCD to the BIG-IQ CM
