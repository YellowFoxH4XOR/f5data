Description

When enabled, login request without referer and forwarded header is permitted to continued to be processed.

 

# tmsh list sys db systemauth.permitloginwithoutheaders
sys db systemauth.permitloginwithoutheaders {
    value "disable"
}

 

Environment

・ BIG-IP LTM

 

Cause

Users cannot log on to the BIG-IP system's WebUI due to modify the HTTP request in such a way that the Referer and Host headers no longer tally with one another.

 

Recommended Actions

None
