K000149725: Understanding Management Interface Network Firewall Rules Event Logs

Support Solution
Published

2025-02-10
Applies to

Source

Description

You have configured management interface network firewall rules without any AFM module and enabled logging.

 

Each field represents a specific attribute of the logged event. Below is a breakdown of the fields:

 

Field Name

 Description                                                                

UUID

Universal Unique identifier (UUID) assigned to each specific event for tracking purposes.

management_ip_address

The IP address of the management interface where the event occurred.

bigip_hostname    

The hostname of the BIG-IP system generating the log entry.

context_type       

The type of context (e.g., "Management Port").

context_name       

The name associated with the context (e.g., "mgmt").

src_ip             

Source IP address involved in the event.

dest_ip            

Destination IP address involved in the event.

src_port          

Source port number used in communication.

dest_port         

Destination port number used in communication (e.g., 443 for HTTPS). 

vlan             

VLAN associated with this traffic; empty ("") if not applicable (e.g., mgmt).

protocol         

Protocol used for communication (e.g., TCP, UDP).   

route_domain     

Route domain associated with this traffic; empty ("") if not applicable. 

acl_rule_name      

Name of the Access Control List (ACL) rule that triggered this log entry. 

action           

Action taken by the firewall (e.g., Reject, Allow).  

drop_reason       

Reason for dropping packets, if applicable; empty ("") otherwise.     

 

The log format for management interface network firewall events is as follows:

 

"UUID","management_ip_address","bigip_hostname","context_type","context_name","src_ip","dest_ip","src_port","dest_port","vlan","protocol","route_domain","acl_rule_name","action","drop_reason"

 

Example of log:

 

23003137 "192.168.1.245","F5.lab.com","Management Port","192.168.1.245","192.168.1.29","192.168.1.245","53183","443","","TCP","","mgmt","","Reject","Policy"

 

Since this log is from the management, the fields "vlan" and "route domain" are left blank.

 

Environment

LTM

Management firewall

Cause

Management interface network firewall rules are from the AFM module and was made available to the LTM device even without the needed license. The format was taken from AFM and might report some parameters that will appear blank because it is using the management interface.
