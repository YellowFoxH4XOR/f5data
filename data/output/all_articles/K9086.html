Known Issue

This is the result of a known issue. When a client using iControl waits more than two seconds to send information after sending the initial HTTP headers of an iControl request, the socket used by the iControl portal is shut down, preventing communication with the server. As a result, the client receives a 500 Internal Server Error response page.

F5 Product Development tracked this issue as CR98530 and it was fixed in version 9.4.5 for the BIG-IP 9.4.x software branch. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, and WebAccelerator release notes.

This issue was fixed in cumulative Hotfix BIGIP-9.4.4-94.0-HF3 issued for BIG-IP version 9.4.4. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
