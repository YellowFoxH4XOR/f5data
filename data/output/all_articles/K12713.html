Known Issue

This is the result of a known issue. In the BIG-IP Configuration utility Virtual Server List, when you filter the list by Status, virtual servers may fail to display because of how the system paginates the list. For example, if the first 10 virtual servers (listed alphabetically) all show a status of Available, and you change the Virtual Server List filter to display only virtual servers showing a status of Offline, no virtual servers display. If instead only the first nine servers show a status of Available, and the tenth server shows a status of Offline, then when you set the filter to Offline, only that one Offline server displays.

F5 Product Development is tracking this issue as ID352644.

Workaround

You can work around this issue by changing the records.per.page variable. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Using the text editor of your choice, open the /etc/tomcat/systemsettings.properties file for editing.
  3. Locate the line that reads:

    records.per.page=10

  4. Increase the number in the above line to a value appropriate to your configuration.
  5. Save and exit the file.
  6. Reload the BIG-IP system configuration with the following command:

    bigpipe load

This procedure increases the number of objects that the system displays, per page, in the Virtual Server List. However, the Configuration utility still incorrectly counts the objects that do not match the filter. For example, if you change the records.per.page value to 15, and set the filter to Offline, and 10 virtual servers show a status of Active, then only the first five virtual servers showing a status of Offline display.
