Known Issue

Local web servers on client devices may not be accessible after you establish a network access session.

This issue occurs when all of the following conditions are met:

  • You use a MAC OS device to establish a network access session.
  • The network access profile specifies a Client Proxy Auto-Config (PAC) file that forwards all web traffic to the network tunnel.

Impact

Local web servers on client's devices are not accessible.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you establish a network access session on a MAC OS device, local web servers are not accessible.
