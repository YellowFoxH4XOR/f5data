Description

Existing attack signatures were placed into Staging after re-enabling Enable signature staging in the security policy's Learning & Blocking settings.

The attack signatures were previously in Enabled state with Enable signature staging disabled.

You believed that re-enabling this option would only apply to new signatures.

Environment

  • Security policy
  • Attack signatures

Cause

Re-enabling Enable signature staging places attack signatures into the enforcement state they were in when Enable signature staging was last enabled.

By default when a policy is created, Enable signature staging is enabled, and all signatures are in Staging. If Enable signature staging is disabled at this point, but later re-enabled after some time, the signatures will go into Staging. Similarly if the signatures were Enforced before initially disabling Enable signature staging, they will return to Enforced state after re-enabling the Enable signature staging option.

Recommended Actions

None. This is expected behaviour.
