Description

The BIG-IP system features allow the system to check for and update automatically the Intrusion Prevention System (IPS). 

Environment

  • AFM module
  • Intrusion Prevention System (IPS)

Cause

None

Answer/Recommended Actions

The minimum requirements to create the configuration: 

1/ Network requirements: K15000: Overview of the Automatic Update Check and Automatic Phone Home features (Connectivity requirements)

2/ License requirements: K66837555: Protocol inspection subscription license requirements

3/ Certificate requirement: K000157909: Certificate authority bundle update is required for BIG-IP AFM IPS signature update
