K11405977: No peer information for IPSec tunnel peer through Virtual Server

Type
Support Solution
Published
2022-06-09
Updated

Status

Applies to

  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K11405977

Description
IPSec tunnels will not establish if the Virtual Server protocol is configured incorrectly.

Environment

  • BIG-IP
  • CGNAT, LSN Pool may be configured as part of the IPSec tunnel setup
  • Virtual Server terminating IPSec tunnel traffic
  • Virtual Server protocol set to something other than '* All Protocols'

Cause
For a Virtual Server that is terminating IPSec tunnel traffic, the Virtual Server protocol should be set to '* All Protocols' to ensure that all traffic for the connection is directed to the Virtual Server.  With the protocol set to TCP, legitimate traffic such as ISAKMP (UDP) and ICMP will be ignored and the IPSec session will not be established.

Recommended Actions
The Virtual Server protocol should be set to '* All Protocols'

  1. In the BIG-IP GUI, select Local Traffic > Virtual Servers > Virtual Server List
  2. Under Configuration, change the Protocol dropdown to '* All Protocols'
  3. Click the Update button
