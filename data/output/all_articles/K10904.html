Known Issue

This is the result of a known issue. The BIG-IP LTM HTTPS monitor incorrectly reports that 1 byte of data was read and marks the node as UP when the server successfully completes an SSL handshake, accepts a request, but does not send any data in a response.

Note: This issue affects monitors configured without a Receive string.

F5 Product Development tracked this issue as ID 207411 (formerly CR120157) and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue was fixed in Hotfix-BIGIP-9.4.8-385.0-HF2 which was issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
