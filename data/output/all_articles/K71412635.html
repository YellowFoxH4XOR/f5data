K71412635: Edge Client - SmartCard authentication - PIN asked twice

Type

Published

Status
Legacy Content
Applies to

Source

Description 
After booting up the PC and launching Edge Client for the first time, PIN is requested twice : 1 time for "Downloading server settings" and 1 time for accessing the VPN.
If you disconnect and reconnect, the PIN is requested only once, as server settings have already been downloaded.

Environment

  • BIG-IP APM
  • Big-IP EDGE Client

Cause
This is the correct behaviour

Recommended Actions

None.

None.
