K000156519: What is the Maximum number of Static-Host (DNS-to-IP) entries an APM Network Access resource object support?

Support Solution
Published

Applies to

Source

Description

An APM Network Access (VPN) resource object can support a very large number of Static-Host DNS-to-IP entries. However, the number of those Static Host entries that a given client device and it's OS (Operating System) can support is dictated by the client software, not the BigIP. So while an administrator can add 1000 Static Host entries to their Network Access VPN resource object's configuration, a given client device may only be able to accept a limited number of them, due to the OS's built-in limitations. I other words, the limiting factor for the number of Static-Host entries that can be supported is dictated by the client OS's limitations, not the BigIP's limitations.


Environment

BIG-IP APM

Network Access Static-Hosts


Cause

Client OS's impose limits on the number of Static-Host entries they will accept from the Network Access. And those limits vary across OS manufacturers.


Recommended Actions

Check the given OS for it's limits on how many Static-Host entries it supports, as that will be the limiting factor, not the Network Access resource.
