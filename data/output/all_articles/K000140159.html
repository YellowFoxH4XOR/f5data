K000140159: "sender_https segfault at" error

Type
Support Solution
Published
2024-06-27
Updated
2024-06-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000140159

Description

  • Many "sender_https segfault at" error log entries detected on kern.log
  • Messages simialr to the following can be seen on /var/log/kern.log

    info kernel: SENDER_HTTPS[31719]: segfault at 7f08840000f8 ip 00007f08840000f8 sp 00007f088bcbe888 error 15
    info kernel: SENDER_HTTPS[32173]: segfault at 7fea90001ab0 ip 00007fea90001ab0 sp 00007fea95570888 error 15
    info kernel: SENDER_HTTPS[1033]: segfault at 7f473c000178 ip 00007f473c000178 sp 00007f4743df6888 error 15
    info kernel: SENDER_HTTPS[1634]: segfault at 7f5a000000f8 ip 00007f5a000000f8 sp 00007f5a070f7888 error 15
    info kernel: SENDER_HTTPS[2270]: segfault at 7efeb80000f8 ip 00007efeb80000f8 sp 00007efebd8ef888 error 15
  • Messages similar to the following can be seen on /var/log/avr/avrd.log

    EXTERNAL_MESSAGES|NOTICE|Jun 13 16:01:13.677|3374|lib/avrpublisher/infrastructure/avr_http_connection.cpp:0201| Start connecting to : 10.0.0.1:443
    EXTERNAL_MESSAGES|ERROR|Jun 13 16:01:13.680|3374|lib/avrpublisher/infrastructure/avr_http_connection.cpp:0226| Failed to establish connection: Connection reset by peer. HTTP Connection : 10.0.0.1:443

Environment

  • BIG-IP LTM and AVR provisioned
  • BIG-IQ DCD
  • BIG-IP is configured to send data to BIG-IQ DCD

Cause

Seen behaviour is caused by a know issue tracked with the Bug ID 1298225. 

Recommended Actions

To avoid this issue,  make sure the BIG-IP can connect to the BIG-IQ DCD.

None
