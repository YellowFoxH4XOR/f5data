Known Issue

The LCD panel may display an incorrect serial baud rate of 19200 following a reboot.

This issue occurs when all of the following conditions are met:

  • The baud rate is changed to a speed other than 19200
  • The device is rebooted

Impact

The LCD displays a baud rate of 19200, regardless of the actual baud rate set by the system. This issue is cosmetic only.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The system baud rate will be set to a speed other than 19200.

    You can verify the baud rate by typing the following command:

    bigpipe hardware baud rate

  • The LCD will incorrectly display the baud rate as 19200

Workaround

To work around this issue, you can reset the serial baud rate from the command line. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP command line.
  2. Check the current baud rate by typing the following command:

    bigpipe hardware baud rate

  3. Reset the same baud rate by typing the following command, where XXXX is the baud rate value returned in Step 2:

    bigpipe hardware baud rate <XXXX>

Once the baud rate has been reset, the LCD will display the updated value.

Note: This workaround is temporary. Following the next reboot, the LCD display will again display 19200, regardless of what the serial baud rate is set to.
