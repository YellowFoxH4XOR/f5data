Topic

An HTTP class profile allows you to classify traffic based on certain criteria and direct the traffic to a BIG-IP load balancing pool, or through other BIG-IP modules, such as the BIG-IP ASM or BIG-IP WebAccelerator.

When you define the HTTP class profile, you specify pattern string or regular expression filters for one or more of the following list of HTTP class variables:

  • Host names
  • URIs
  • Headers
  • Cookies

HTTP class pattern string filters are case-sensitive. For example, the following HTTP class profile contains a pattern string of www.askf5.com for the Hosts variable:

profile httpclass testclass {
defaults from httpclass
pool Pool-A
redirect none
hosts "www.askf5.com"
}

When a virtual server referencing the example HTTP class profile processes a request, the BIG-IP system sends all requests containing a lowercase www.askf5.com host header to Pool-A. The BIG-IP system drops any requests containing a host header of www.ASKF5.com or any other variation of uppercase letters.

You can configure a case-insensitive HTTP class variable by defining a regular expression for the variable. For example, to define a case-insensitive Host variable for the HTTP class, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles.
  3. Select HTTP Class from the Protocol menu.
  4. Click Create.
  5. Type a name for the profile.
  6. Select the check box next to Hosts.
  7. Select Match Only from the menu.
  8. In the Host field, enter the following:

    (?i)www.askf5.com

  9. From the Entry Type menu, select Regular Expression (regex).
  10. Click Add.
  11. Define an action for the HTTP class.
  12. Click Finished.
  13. Associate the HTTP class profile with the virtual server.

The HTTP class will now send all requests containing a case-insensitive host header of www.askf5.com to the defined resource.

Other variable traffic classifiers may be constructed in the HTTP class configuration. For example, case insensitivity can also be specified on a per-character basis by using a character class such as [aA] in the Host field.
