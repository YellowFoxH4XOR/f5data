Issue

Old Behavior

In versions prior to BIG-IP 10.2.2, the software uses hard-coded DNS server IP addresses to resolve the F5 license activation server host names.

New Behavior

Beginning in BIG-IP 10.2.2 and 11.0.0, BIG-IP software uses a script to resolve the F5 license activation server host names and does not rely on hard-coded DNS servers. The BIG-IP system will first attempt to access the root DNS servers to resolve the F5 license activation server host names. If the BIG-IP system is unable to access the root name servers, and is configured to resolve DNS host names, the system uses DNS servers defined in its /etc/resolv.conf file.

Impact

If the BIG-IP system does not have access to the root name servers and is not configured to resolve host names, the automatic license activation process may stall or time out.

Recommended Actions

For the BIG-IP system to resolve the F5 licensing server, the system must have Internet access to send DNS queries to the root name servers, or the system must be configured to resolve DNS host names.
