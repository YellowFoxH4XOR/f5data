Description

The DIAMETER specification limits any two DIAMETER nodes to a single connection. If multiple connections between the BIGIP and a diameter node is required, the BIGIP should use a unique origin-host name. To assist creation of unique diameter identity values, the following diametersession profile attributes support automatic insertion of system values into the generated AVP: origin-host, origin-realm, origin-host-rewrite, origin-realm-rewrite, dest-host-rewrite and dest-realm-rewrite.


Environment

  • MRF

Cause

None.


 Recommended Actions

Usage of any of the following macros within one of the above listed diameteresession attributes will be replaced with the system values defined in the table below.

For example:

Oirgin-Host: dra-$u.f5net.local, here in this case "$u" will be the TMM thread number.


Say for example if MRF creates connection towards Diameter Server, if the connection initiate from tmm/0 then the Origin-Host will be "dra-0.f5net.local"
