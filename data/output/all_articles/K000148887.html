Description

You want users of the access profile to be able to change their LDAP passwords with the BIG-IP APM access profile logon page 

Environment

  • BIG-IP APM
  • LDAP
  • Logon Page
  • Password Change

Cause

This is currently not supported.

RFE is tracked with ID 447098 [RFE] Provide a way for end user to change their LDAP password

Recommended Actions

There is no way to implement this currently. 

You can track the RFE ID mentioned above for updates, by contacting your F5 Account Manager.
