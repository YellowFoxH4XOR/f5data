Known Issue

BIG-IP Network Access Client Proxy settings may not be honored when you use Internet Explorer 11.

This issue occurs when all of the following conditions are met:

  • Client proxy settings are enabled in the BIG-IP Network Access configuration.
  • Proxy Auto-Configuration (PAC) files are specified with the file:// prefix.

Impact

Client traffic will not honor proxy settings.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use Internet Explorer 11, the proxy file is correctly created; however client traffic ignores the proxy settings.
  • Clients fail to connect to resources that must be accessed through the proxy.

Workaround

To work around this issue, you can enable the Client Proxy Uses HTTP for Proxy Autoconfig Script option in the Client Settings of the Network Access resource.
