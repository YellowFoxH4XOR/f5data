Description

  • You have deployed your Kubernetes cluster successfully and you want to leverage Nginx Ingress Controller
  • However, you want to modify/alter the ingress controller default listening port from 443/80 to a custom port 
  • Since, the required change is on the application, native Kubernetes objects like services cannot be used achieve the desired change but rather we need to build a new custom Docker image

 Environment

  • Nginx Ingress Controller
  • Docker
  • GIT
  • GNU Make
  • Kubernetes

 Cause

  • None

 Recommended Actions

  • We would need to make use of Docker, git and Make. So we need to install them first
  • We would then need to clone Ingress Controller repo, following article
  • Once the repo is cloned on to a local machine, navigate to directory ../internal/configs/version1/nginx-plus.ingress.tmpl to modify default listener
    • here, you would need to locate listener 443 and change it to 8443
    • you can do the same for port 80
  • If you are using Nginx plus, please make sure you have valid Nginx-repo-cert and key pair in directory /Kubernetes-ingress prior to building the image using Make,

Alternatively, you can customize NGINX Ingress Controller ports by performing the procedures described in Customizing NGINX Ingress Controller Ports.

 Additional Information

Optionally

  • You can push this newly minted image to a repository
  • And from there you can define your ingress controller image of the Kubernetes deployment
