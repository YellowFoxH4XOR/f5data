Issue

Error Message

01460007:6: semaphore <process> held

In this error message, note the following:

  • <process> is the process name.

For example:

01460007:6: semaphore mcpd.running(1) held

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • promptstatusd is currently verifying that a system process will start successfully.

Once promptstatusd verifies that a system process has started successfully, the system logs the following message to the /var/log/ltm file:

01460007:6: semaphore mcpd.running(1) released

Note: The promptstatusd process obtains and formats data displayed by the Advanced Shell (bash) and the Traffic Management Shell (tmsh).

Impact

There is no impact; this message is informational.

Recommended Actions

None
