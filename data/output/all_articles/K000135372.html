Description

Access to the F5OS-A device via SSH does not work. Additionally, when trying to power ON or reboot the device, the BIOS warning screen appears (without the user explicitly going into BIOS). Also, pressing ENTER causes the BIOS warning screen to reappear instantly.

Environment

  • rSeries device
  • You have no access via SSH
  • You do have access through console

Cause

This issue could be caused by either of:

  • Loose NVME disk module installation to the appliance
  • Empty or broken OS system files on the NVME disk
  • NVME disk hardware issue

Recommended Actions

  1. Remove the NVME disk and then re-install it if your NVME disk is removable

After re-install, then perform the following actions to try to save the BIOS changes to check wehther it improves. If not, proceed with the next step to perform clean installation.

    1. Disconnect the console cable from the device.
    2. Reboot the F5 device.
    3. Wait for about 10 minutes - to make sure the device reboots.
    4. Reconnect the console cable.
    5. Press Enter. The "Entering BIOS Setup" menu described before should appear.
    6. Choose "Continue" to enter BIOS.
    7. Press F4 to save BIOS settings.
    8. Reboot to go try to reach the system, if necessary.

 

  1. Reinstall the F5OS OS using an USB thumb drive

Re-install the F5OS could improve the second situation listed under the cause section effeciently, please follow the below guide for reinstalling the F5OS.

Manual Chapter : Install or Upgrade Software

Note: you may check the section "Clean installation using a USB flash drive"

 

  1. Under the situation that all above steps do not work, please:
    1. Collect steps you followed, share the console output or a recording of you performing these steps at step c below.
    2. Collect the hardware diagnostic data using K13428255: Get VELOS and rSeries hardware diagnostics when CLI access is not available,
    3. Open a case with F5 Support with the reference to this article. Upon case open, upload the data collected at 3.a and 3.b.
