Description

  • you attempt to access FPS alert from BIG-IQ dashboard, but it fails to display the alerts
  • BIG-IQ dashboard generates the below error on the GUI as well as in /var/log/restjavad.0.log file 
    •  reason":"maxConcurrentShardRequests must be >= 1"

The system returned an unexpected error (400 Bad Request). status:400, body:{"error":{"root_cause":[{"type":"illegal_argument_exception","reason":"maxConcurrentShardRequests must be >= 1"}],"type":"illegal_argument_exception","reason":"maxConcurrentShardRequests must be >= 1"},"status":400}"
 

Environment

  • BIG-IQ CM
  • BIG-IQ DCD
  • BIG-IP FPS

Cause

  • No dcd were associated with the CM

Recommended Actions

  • On the CM, check and verify BIG-IQ DCDs are present 
    • under System  >>  BIG-IQ Data Collection Devices 
  • If no DCD present, need to add  DCD/s to the cluster 
    • under System  >>  BIG-IQ Data Collection Devices  >>  Add
  • If present, need to check and verify the health of the DCDs
