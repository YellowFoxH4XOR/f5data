Known Issue

This is the result of a known issue. A BIG-IP WebAccelerator system under heavy load may return corrupt data for large responses. When this issue occurs, the BIG-IP system may log error messages to the /var/log/ file that appear similar to the following example:

[       PvHttpResponse.cxx:6294     evalContentLength ] Content length of response 5760066 exceeds available length of 5413632 bytes.

[       PvCacheManager.cxx:593           get_from_hds ] total [0x672fc3] freeMem [0xc91800]

F5 Product Development tracked this issue as CR136745, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
