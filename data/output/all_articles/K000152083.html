K000152083: How to make URI/path case insensitive?

Published

Description

You want to add URI/path and make it case insensitive, Lower Case 

Environment

  • F5® Distributed Cloud 
  • Distributed Cloud Web Application and API Protection (WAAP)
  • Route
  • Service Policy
  • Waf exclusion rule

Answer/Recommended Actions

  1. Route
    On the route use regex as example (?i)^/uat.*
    (?i) is case-insensitive flag and makes the rest of the regex ignore letter casing

  2. Waf exclusion rule
    Use the same regex as in Route

  3. Service Policy 
    When creating rule, go to HTTP path and select 'Lower Case'
