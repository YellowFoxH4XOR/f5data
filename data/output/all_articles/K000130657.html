K000130657: Logs are not registering on BIG-IQ

Type
Support Solution
Published
2023-01-27
Updated
2023-01-27
Source
https://my.f5.com/manage/s/article/K000130657

Description

We don’t see web security event/DOS application event logs in BIG-IQ even after we have increased the size of indexes in BIG-IQ DCD cluster. The cluster is in healthy state but we still see “statistics overflow protection detected” warning message.


Environment

BIG-IQ

BIG-IP ASM

Cause

Unknown

Recommended Actions

If customer is ok clearing all data from the DCDs, then follow the next steps:


Here are the steps to clear the DCD's: (NOTE: you will need to step through the setup utility on each DCD )


1) Clear all the DCD info from the BIGIQ CM, run this only on the BIGIQ CM


reset-data-collection-cluster -l


2) Check if old DCDs were removed using GUI. If they were removed then continue with #3


3) Clear all the data on DCD, run this only on DCDs:


clear-rest-storage -l


4) Complete the wizard setup in the DCDs


5) Add the DCDs to the BIGIQ CM
