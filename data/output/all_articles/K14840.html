Known Issue

A FIPS key mismatch occurs when you export keys from the Enterprise Manager system.

This issue occurs when all of the following conditions are met:

  • You use FIPS in a high-availability pair of 6900 or 8900 platforms.
  • You use Enterprise Manager to manage the platforms.
  • You use Enterprise Manager to export the keys to the platforms.

Impact

Traffic may be disrupted due to the FIPS key mismatch.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You see the message FIPS key handle mismatch in the output of the following commands:

    tmsh show sys crypto fips

    tmsh show sys crypto key

  • You see traffic interruptions for virtual servers that are configured to use the affected FIPS keys.

Workaround

There is no workaround for this issue. However, you can prevent this issue by removing the affected BIG-IP platforms from the Enterprise Manager control.
