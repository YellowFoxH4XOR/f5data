K000151594: BIG-IQ: Fails to Restore a BIG-IP UCS Backup Due to "Timed Out Waiting for Restore Task to Complete" error

Type
Support Solution
Published
2025-05-29
Updated
2025-05-29
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0
Source
https://my.f5.com/manage/s/article/K000151594

Description

You are attempting to create a UCS backup of a BIG-IP system using BIG-IQ. However, the task fails and displays a "Timed Out Waiting for Restore Task to Complete" error in the GUI. Additionally, you notice an error similar to the following in the restjavad.0.log file on the BIG-IP system.

PAM: Authentication failure for root from 127.0.0.1

Environment

You attempt to restore a UCS backup of a BIG-IP.

Cause

You need to have a SSH public key authentication on the BIG-IP system to the local host.

Recommended Actions

1. Login to the BIG-IP via ssh as a root user

2. Generate an SSH RSA key pair on the BIG-IP system by entering the following command

ssh-keygen -t rsa -b 4096 -f "$HOME/.ssh/id_rsa" -N '' command

3. Install this public key on the local system as an authorized key for the root user

ssh-copy-id root@localhost

 

You can refer to the following article for more detail how to configure SSH public key authentication.

K13454: Configuring SSH public key authentication on BIG-IP systems (11.x - 17.x)
