Known Issue

This is the result of a known issue. The LDAP Authentication Configuration profile requires an entry for the Remote LDAP Tree field. When you attempt to create an LDAP Authentication Configuration profile with an empty Remote LDAP Tree field, the profile creation will fail and display an error message similar to the following example:

 mcpd: "01070113:3: LDAP requires a base distinguished name."

The LDAP Authentication Configuration profile should accept a null entry for the Remote LDAP Tree field.

F5 Product Development tracked this issue as CR69129, CR68072, and CR68180, and it was fixed in BIG-IP LTM versions 9.1.3, 9.2.4, 9.3, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM release notes.
