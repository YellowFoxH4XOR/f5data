Description

Modify/add IP address on the LTM rule via tmsh 

Environment

  • LTM rule
  • tmsh

Cause

N/A

Recommended Actions

Following document explain how to modify LTM policies via tmsh:  F5 TMSH Reference > ltm policy

Example : Modify IP address of below rule 

(tmos)# list ltm policy Drafts/test_policy
ltm policy Drafts/test_policy {
  last-modified 2022-12-20:06:09:56
  requires { http tcp }
  rules {
    first_rule {
      conditions {
        0 {
          tcp
          address
          matches
          values { 141.202.53.16 }
        }
      }
    }
  }
  status draft
  strategy first-match
}


To modify this policy to add more IP address

1. (tmos)# modify ltm policy Drafts/test_policy rules modify { first_rule { ordinal 0 conditions modify { 0 { tcp address values { 10.10.10.10 10.10.10.11 10.10.10.12 } } } } }
2. (tmos)# list ltm policy Drafts/test_policy

ltm policy Drafts/test_policy {
  last-modified 2022-12-20:06:14:11
  requires { http tcp }
  rules {
    first_rule {
      conditions {
        0 {
          tcp
          address
          matches
          values { 10.10.10.10 10.10.10.11 10.10.10.12 }
        }
      }
    }
  }
  status draft
  strategy first-match
}

3. (tmos)# save sys config
