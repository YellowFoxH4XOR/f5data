Known Issue

When you select request log entries from within the Security > Event Logs > Application > Requests page of the Configuration utility, the system cannot display the selected entry and returns an error.

This issue occurs when the following condition is met:

  • You have selected the request log entry for XML format violations.

Impact

You are unable to view the request log entries.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system does not display the request log entries.
  • The system displays an error message similar to the following example:

    Request details are not available
