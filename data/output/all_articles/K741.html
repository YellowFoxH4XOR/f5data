Topic

This issue occurs because Passive (PASV) mode file transfers are incorrectly left in a TCP/IP TIME-WAIT state, which causes the FTP connection to appear as a hung connection. This problem is a known Microsoft Windows 2000 Server/Advanced Server FTP service bug.

For further details about this bug, refer to the following Microsoft knowledge base article:

Q257991: FTP Service May Not Time Out Inactive Sessions

Microsoft has released a Service Pack 1 that corrects the problem. You can download this service pack from the Microsoft web site at www.microsoft.com.
