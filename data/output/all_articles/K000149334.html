K000149334: New configuration "system security firewall config logging" in F5OS-A 1.8.0

Type
Support Solution
Published
2025-02-12
Updated
2025-02-12
Applies to

  • F5OS-A: 1.8.X, 1.8.0
Source

Description

This article describes new configuration in F5OS-A 1.8.0.

The newly added configuration is following.

system security firewall config logging [enabled|disabled]

Environment

F5OS-A 1.8.0

Cause

In F5OS-A 1.8.0, system security firewall config logging [enabled|disabled] configuration is added via Bug ID 1268433: Some firewall rules do not generate denial logs.

The configuration allows to enable or disable firewall logging. It is disabled by default.

Recommended Actions

If it is necessary to log firewall event, you may enable following.

# docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;system security firewall config logging enabled;commit and-quit'
