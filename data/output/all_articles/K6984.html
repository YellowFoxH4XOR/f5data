Known Issue

This is the result of a known issue. If a client retransmits a SYN packet, and the virtual server is using a FastHTTP profile, the virtual server retransmits the original SYN/ACK packet with a different sequence number. As a result, the connection will fail.

F5 Product Development tracked this issue as CR72575 and it was fixed in BIG-IP 9.1.3, 9.3.0, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM release notes.
