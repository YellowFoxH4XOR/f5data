Policy Information

F5 is announcing the End of Software Development (EoSD) for BIG-IP AAM for no earlier than April 1, 2020. For information about specific BIG-IP AAM SKUs, refer to K15719: End of Sale announcement for specific BIG-IP AAM SKUs.

This EoSD announcement affects the following F5 platforms:

  • BIG-IP hardware appliances
  • BIG-IP Virtual Edition (VE)
  • VIPRION platforms

The following specific products are affected by the BIG-IP AAM EoSD:

  • BIG-IP hardware appliances
  • BIG-IP AAM add-on module
  • BIG-IP iSeries platform
  • BIG-IP VE
  • VIPRION chassis and blades
  • Software availability
BIG-IP hardware appliances

The BIG-IP AAM software module is still available on the prior generation of BIG-IP appliances (BIG-IP 2000, 4000, 5000, 7000, 10000, and 12000 devices) and support will adhere to the same lifecycle timeline as these platforms. For more information, refer to K55590970: End of Sale announcement for BIG-IP 2000, 4000, 5000, 7000, and 10000 series appliances.

BIG-IP AAM add-on module

The End of Sale (EoS) date for the following BIG-IP AAM add-on module for BIG-IP is April 1, 2018.

SKU  SKU description
F5-ADD-BIG-AM BIG-IP Application Acceleration Manager Module (Max SSL, Max Compression)
BIG-IP iSeries platform

BIG-IP AAM is not available on the current or future BIG-IP iSeries hardware platforms (i2000, i4000, i5000, i7000, and i10000). These platforms are unaffected by this notification.

BIG-IP VE

BIG-IP AAM will be removed from Good, Better, Best (GBB) licensing for BIG-IP VEs with the V16 release. BIG-IP AAM (Better and Best licenses) is still available on prior releases but customers should check the lifecycle plan for the earlier releases. To find out more about this change, refer to K05392858: Advance End of Sale announcement for BIG-IP Virtual Edition V13 licenses.

Software availability

BIG-IP AAM software will no longer be available starting with BIG-IP 16.0.0, expected availability summer 2020. Any customer with existing platforms running BIG-IP AAM will need to remove any/all configuration associated with BIG-IP AAM and will no longer have access to the BIG-IP AAM functionality when upgrading. This includes the following functionality:

  • Content concatenation
  • Content inlining
  • Content minification
  • Content reordering
  • De-duplication / symmetrical acceleration
  • Disk caching
  • Image reduction
  • Intelligent browser referencing
  • iSessions (compressed TCP tunnels)
  • Multi-connect / domain sharding
  • PDF linearization
  • Small object cache
  • Smart cache

BIG-IP 16.0.0 will complete the End of Life of the BIG-IP AAM product.

Customers requiring tunnel support should use the BIG-IP IPsec tunnels in place of iSessions.
