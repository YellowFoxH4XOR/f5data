K000130559: Performance degradation after upgrading from BIG-IP 16.1.2.2 to 16.1.3.2

Type
Support Solution
Published
2023-01-11
Updated
2024-09-10
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000130559

Description

High CPU and memory usage from Java process seen on standby unit after the upgrade.

As a result, lots of OutOfMemoryError log may be produced in /var/log/restjavad.0.log

[SEVERE][32][1 Nov 2022 00:00:00 UTC][DieOnUncaughtErrorHandler] Restjavad exiting immediately due to an uncaught Error

[SEVERE][33][1 Nov 2022 00:00:00 UTC][DieOnUncaughtErrorHandler] Uncaught Error causing restjavad to exit. Thread id 24, 'Non-Blocking threadPool_4': java.lang.OutOfMemoryError: Java heap space

at java.util.Arrays.copyOfRange(Arrays.java:3664)

at java.lang.String.<init>(String.java:207)

 

In addition, /var/log/restjavad.0.log and /var/log/ltm may indicate some tasks are being run from standby device to active device and it's falling continuously. However, increasing java memory as per K9719 will not fix the issue.

The error below can also be observed in /var/log/restjavad.0.log which points to K58541720 but the fw rules configured on both active - standby devices appear to be identical

[WARNING][6388][17 Nov 2022 05:21:01 UTC][8100/tm/shared/bigip-failover-state BigipFailoverStateWorker] Failed to discover <peer device self IP>: java.lang.IllegalStateException: Could not connect to host <peer device self IP>. Please ensure there are no licensing, firewall, port lockdown or network connectivity issues. Error: Connection refused

Environment

  • BIG-IP
  • High CPU and memory usage from Java process
  • Configsync
  • Port Lockdown

Cause

Missing required ports on the allow list of self IPs

Recommended Actions

Allow port 443 and 1026(UDP) on the self IP or change the setting back to allow default.

Additional Information

K13946: Troubleshooting ConfigSync and device service clustering issues

Ports Device group members should be able to communicate over ports 443, 4353, 1026 (UDP), and 22 (recommended).
