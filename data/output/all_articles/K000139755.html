K000139755: Output ASM internal system variables via CLI using REST

Type
Support Solution
Published
2024-05-23
Updated
2024-05-23
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000139755

Description

Output ASM internal system variables via CLI using REST

Environment

  • ASM provisioned
  • You want to view the system variables listed at Security '' Options : Application Security : Advanced Configuration : System Variables but do it via CLI.

Cause

You can use REST API to query and format a tab separated table for all the ASM Internal System Variables that are listed in the GUI.

Recommended Actions

External to the BIGIP:
# curl -sku admin:admin https://localhost/mgmt/tm/asm/advanced-settings?\$select=name,value | jq -r '(["Internal_Parameter_Name","Value"] | (., map(length*"-"))), (.items[] | [.name, .value]) | @tsv' | column -t -o '|'

Via bash shell on BIGIP:
# restcurl -u admin:admin /mgmt/tm/asm/advanced-settings?\$select=name,value | jq -r '(["Internal_Parameter_Name","Value"] | (., map(length*"-"))), (.items[] | [.name, .value]) | @tsv' | column -t -o '|'
