Your BIG-IP system is not operational after restart and you are prompted with Reboot Reqired message at the Advanced Shell (bash) prompt.  Additionally, your BIG-IP system may not be passing traffic.

This issue occurs when the following condition is met:

  • You are running one of the affected versions.

Impact

The license is not operational and BIG-IP services will not run.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The following errorrs are logged in /var/log/ltm Reboot Required prompt may appear even after multiple restart attempts:

    mcpd[9528]: 01070608:0: License is not operational (expired or digital signature does not match contents).

    err mcpd[]: 01070710:3: Database error (13), Cannot update_indexes/checkpoint DB object, class:private_mac_addr_freelist status:13 - EdbCfgObj.cpp, line 127.

  • The bash prompt says Reboot Required.

Workaround

To work around this issue, you can restart the chmand process. To do so, perform the following procedure:

Impact of workaround: If the BIG-IP host is passing traffic, there may be a temporary interruption. F5 recommends that you perform this procedure during a maintenance window or when other hosts in a high-availability (HA) configuration are processing traffic.

  1. Ensure the mcpd process is running using the command bigstart status mcp in bash.
  2. Restart the chmand process using the command bigstart restart chmand.

For example:

# bigstart status mcpd

mcpd                  run (pid 16367) 3 days

# bigstart restart chmand
