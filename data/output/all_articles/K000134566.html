Description

The SSL certificate for Nginx Controller Web portal expired, this is APIGW certificate.

To verify date, click on the "Not secure" and find "Certificate Viewer" in the browser:
 

 

Environment

  • Nginx Controller

Cause

Certificate's validation date expired.

Recommended Actions

To solve expired APIGW (API Gateway) certificates we have two option:

  • For self-signed certificates need to run './update.sh' process
 cd $HOME/controller-installer
 ./update.sh
  • For 3rd Part signed certificate, i.e. customer’s own cert need to be used:
/opt/nginx-controller/helper.sh configtls <cert_file> <key_file>

 

OptionsDescription
cert_fileCertificate file path.
key_fileKey file path.
 

 

Additional Information

If during update.sh process receive "Failed to backup config database" error message at stage #8:

8. Extracting information from current controller...
Failed to backup config database. Please see the logs available at /opt/nginx-controller/postgres_data/backup

To overcome it, you need to edit ./update.sh and comment out the following lines by adding "#":

#    if ! dump_postgres "${install_path}${postgres_backup_location}" false; then
#        p[SSH] ERROR: Read from remote host 10.155.207.33: Operation timed outle at ${install_path}${postgres_backup_location} for details.\n"
#        exit 1
#   fi

Once done - run update script to take effect:

./update.sh
