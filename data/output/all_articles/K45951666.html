Description

After updating an SSL certificate in an iApp configuration, one of the virtual is deleted

Environment

  • BIG-IP version 15.1.2
  • App VMware (f5.vmware_view.v1.5.8 & f5.vmware_view.v1.5.9)
  • Virtual server for Blast is deleted after updating SSL certificate under:
iApps > <iApp related to this application> > Reconfigure > Go down the the certificate and key and select the new cert and key > Finish
 

Cause

Unknown

Recommended Actions

  1. Manually re-create the deleted Virtual Server

Additional Information

None
