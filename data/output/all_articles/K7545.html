The following table contains base operating system information for the Enterprise Manager system:

Note: Some versions may use components from multiple versions of the base operating system.

Enterprise Manager versionCustom built from operating system
3.0.0 - 3.1.1
CentOS 5.4 - 6.0, Linux Kernel 2.6.32 (64-bit kernel only)
2.0.0 - 2.3.0
CentOS 5.4, Linux Kernel 2.6 (64-bit capable platforms run a 64-bit kernel)

Important: In each case, F5 has modified the base host operating system and responds to all reported vulnerabilities for that base operating system. You must install only the patches that F5 supplies.
