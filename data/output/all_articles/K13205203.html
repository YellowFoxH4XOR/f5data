K13205203: BIG-IQ (Resolve Import Conflicts) operation message - ''Removed from device during deployment''

Type
Support Solution
Published
2021-04-27
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K13205203

Description

During a BIG-IQ managed device Discover / Import one may be presented with a Resolve Import Conflicts popup window with a Device Specific Objects listed as Removed from device during deployment seen under the Operation column. 

 

Environment

  • BIG-IQ Centralized Management
  • BIG-IP

Cause

The conflict object of reference once existed in BIG-IQ's configuration historically, later removed from BIG-IQ's configuration and now attempted to be re-introduced back into the BIG-IQ configuration during a managed BIG-IP device Discover / Import. 

Recommended Actions

Make a determination if the object of reference should be re-introduced back into BIG-IQ's configuration. If so, accept to resolve the conflict in order for the object to be re-imported back into BIG-IQ's configuration otherwise, manually remove the object from the managed device followed by a new device Discover / Import. For more information, refer to: K63557165: Discovering a BIG-IP device with a BIG-IQ system and importing the BIG-IP service configuration
