Known Issue

This is the result of a known issue. When attempting to clear an HTTP protocol compliance failed violation from the Learning -> Requests screen, the following error message is reported in the Configuration utility:

There seems to have been a slight problem with the BIG-IP® Application Security Manager database.
Please try again by pressing the refresh button in your browser.
We apologize for any inconvenience.

In addition, an error message that appears similar to the following example may be logged to the /var/log/secure file:

Database error in ASM: Invalid SQL: DELETE FROM LRN_DISABLE_VIOLATIONS WHERE code IN(HTTP_CHECK_CODE) AND account_id='7' mysql error: Unknown column 'HTTP_CHECK_CODE' in 'where clause' mysql error number: 1054 Date: Monday 05th 2009f October 2009 11:51:06 AM Script: /dms/policy/lrn_traffic.php Referer: <URL> , referer:<URL>

PHP Warning: mysql_fetch_array(): supplied argument is not a valid MySQL result resource in /var/ts/dms/common/classes/db_mysql.class.php on line 195, referer: <URL>

F5 Product Development tracked this issue as CR97232 and it was fixed in BIG-IP ASM 9.4.5. For information about upgrading, refer to the BIG-IP ASM Release Notes.
