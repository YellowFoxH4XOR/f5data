Description

  • Not able to receive clients source IP on next hop
  • Client source IP not preserved when connection reaches the server

Environment

  • Performance HTTP Virtual Server
  • SNAT disabled

Cause

Seen behavior is expected.

The Performance HTTP virtual server TCP behavior operates as follows: The BIG-IP system establishes server-side flows by opening TCP connections to the pool members.
When a client makes a connection to the Performance HTTP virtual server, if an existing server-side flow to the pool member is idle, the BIG-IP LTM system marks the connection as non-idle and sends a client request over the connection.

Recommended Actions

If client source IP needs to preserved you can consider using an Standard virtual server
K8082: Overview of TCP connection setup for BIG-IP LTM virtual server types
