Known Issue

This is the result of a known issue. Attempts to move a virtual address from one unit to another unit within an active-active configuration will fail.

For example, if you move a virtual server assigned to unit 2 to unit 1, the Configuration utility or command line will report the move was successful. However, the TMM process on unit 2 will behave as though the virtual server was never re-assigned.

F5 Product Development is tracking this issue as CR59365.

This issue has been fixed in Hotfix-BIGIP-9.3.1-HF5, which has been issued for BIG-IP 9.3.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
