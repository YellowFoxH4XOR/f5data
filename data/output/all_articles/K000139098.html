K000139098: Non Dual speed 10G SFP not coming up in slot 3.0

Type
Support Solution
Published
2024-03-29
Updated
2024-03-29
Applies to
  • BIG-IP
  • F5OS
  • F5OS-A: 1.7.0
Source
https://my.f5.com/manage/s/article/K000139098

Description

New non dual speed 10G SFP inserted into slot 3.0 not coming up.

Environment

F5OS v1.1.x

10G SFP (non dual speed)

Portgroup

 

Cause

Seeing the pre configured speed at SPEED_25GB is the cause when inserting a non dual speed SFP of 10GB for a particular slot.

 

Recommended Actions

Will need to reconfigure the portgroup mode:

appliance-1# config

Entering configuration mode terminal

appliance-1(config)# portgroups portgroup 3 config mode MODE_10GB

appliance-1(config-portgroup-3)# commit

The following warnings maybe seen:

'portgroups portgroup': Portgroup mode changes result in a reboot of the box.

Proceed? [yes,no] yes

Commit complete.

 

After reboot, you should see:

r5000-1# show interfaces interface 3.0 ethernet state port-speed

ethernet state port-speed SPEED_10GB

 

r5000-1# show interfaces interface summary

                                                 OPER LAG

NAME TYPE MTU ENABLED STATUS TYPE PORT SPEED

---------------------------------------------------------------------------

1.0 ethernetCsmacd 9600 true DOWN - SPEED_100GB

2.0 ethernetCsmacd 9600 true DOWN - SPEED_100GB

3.0 ethernetCsmacd 9600 true UP - SPEED_10GB <---------Now looks good
