Known Issue

The BIG-IP Configuration utility may fail to import an SSL certificate to a partition sub-folder.

This issue occurs when all of the following conditions are met:

  • You attempt to import an SSL certificate to a partition sub-folder.
  • Your SSL certificate name contains a forward slash (/) or a backslash (\). For example, you attempt to import an SSL certificate named /Test/Mypartition/mycertificate to the target partition /Test/Mypartion.

Impact

You are unable to import the SSL certificate.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP fails to import the SSL certificate to the partition sub-folder.
  • The Configuration utility displays an error message similar to the following example:

    Name cannot contain '/' nor '\'

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to import the SSL certificate if your certificate name contains a forward slash (/) or a backslash(\). To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Upload the SSL certificate file to the affected BIG-IP system. For more information, refer to K175: Transferring files to or from an F5 system.
  2. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  3. To import the SSL certificate, use the following command syntax:

    install /sys crypto cert <cert name> from-local-file <path/to/cert/file>

    For example, you can use the following command to import a certificate located in /shared/tmp/test.cert with a name /Test/Mypartition/mycertificate:

    install /sys crypto cert /Test/Mypartition/mycertificate from-local-file /shared/tmp/test.crt

  4. Save the change by typing the following command:

    save /sys config
