Known Issue

This is the result of a known issue. The BIG-IP GTM fails to auto-discover a virtual server on a BIG-IP version 4.x system if the virtual server's IP address is not on the same network as the self IP addresses of the BIG-IP 4.x system.

This behavior is a result of the BIG-IP GTM big3d agent ignoring all virtual servers that do not reside on the same network segment as the IP address(es).

F5 Product Development is tracking this issue as CR91127.

Workaround

To work around this issue and allow the big3d agent to include all virtual servers, add self IP addresses to the BIG-IP 4.x system that encompass the virtual server addresses configured.
