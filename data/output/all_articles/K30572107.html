K30572107: BIG-IQ DCD stops collecting stats when /var is 80% or greater with default settings

Type
Support Solution
Published
2021-07-22
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K30572107

Description
A BIG-IQ DCD (Data Collection Device) will stop collecting stats when /var is 80% or greater with default settings.

Environment

  • DCD
  • Stats collection is enabled for managed devices

Cause
With the default settings, DCD will stop collecting data when /var is 80% by design.

Recommended Actions

  1. Free up space in /var K14403: Maintaining disk space on the BIG-IP system
  2. Increase /var disk space K58621633: Extending disk space on a BIG-IQ Virtual Edition
    K30902515: Resizing the /var, /var/log, or /shared file system on a BIG-IQ Virtual Edition
  3. Alternativly, some have been able to get temporary relief by adjusting the settings in the retention policy to suit their environment and needs.
    In the BIG-IQ CM, navigate to System -> Big-IQ Data Collection -> Big-IQ Data Collection Cluster -> Statistics Data Collection -> Configure Retention

Additional Information
Manual Chapter : Configure Data Collection Devices

Section: Statistics retention policy overview

  • The DCDs do not collect new data until the available disk space complies with the Limit max storage to setting.
  • Statistical data not required to calculate the next higher time layer is removed (for example, you need 60 minutes of raw data to aggregate to the Hours level). Data is removed starting with the raw data container, then the hourly data container, then the daily time container. This process stops when storage consumption is below the Limit max storage to setting.
