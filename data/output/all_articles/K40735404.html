Known Issue

Multiple restorations of a user configuration set (UCS) file may alter virtual address configuration settings.

This issue occurs when all of the following conditions are met:

  • You restore a system configuration using a UCS file created on a BIG-IP 10.x system to a version listed in the Applies To box.
  • You verify the virtual address settings for the Address Resolution Protocol (ARP) and Internet Control Message Protocol (ICMP) Echo (enabled/disabled).
  • You again restore the same system configuration UCS file.

Impact

The virtual address ARP and ICMP Echo settings are different from the configured UCS restoration file settings.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system does not apply virtual address ARP and ICMP settings when you restore the UCS file more than once on an affected version.
  • Depending on the UCS file configuration settings, restored virtual addresses do not respond to ICMP requests as expected.
  • Depending on the UCS file configuration settings, restored virtual addresses do not generate/respond to ARP request as expected.

Resolution

Status

F5 Product Development has assigned ID 528295 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can delete all configured BIG-IP LTM virtual servers on 11.x/12.x systems prior to restoring the 10.x UCS file.

Impact of workaround: Virtual server access is unavailable until you restore the 10.x UCS file.
