Known Issue

DNS validating resolvers produce inconsistent results with DNS64 configurations.

This issue occurs when all of the following conditions are met:

  • You configure a DNS cache with the Resolver Type option set to Validating Resolver.
  • In the associated DNS profile, the DNS IPv6 to IPv4 option is enabled.
  • Your BIG-IP system processes AAAA queries.

Impact

The BIG-IP system may send SERVFAIL responses for valid AAAA queries.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A DNS validating resolver incorrectly validates DNS responses received from A queries made as a result of a front-end AAAA query received on a profile with DNS64 configured.
  • The BIG-IP system sends a SERVFAIL response to the client, unless the validating resolver cache has previously validated a front-end A query. In this scenario, where the A records already exist in the cache, the expected DNS64 AAAA records are synthesized.
