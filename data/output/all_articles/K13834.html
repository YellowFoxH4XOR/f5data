Known Issue

The default Secure Sockets Layer (SSL) handshake timeout for the Client SSL profile is set too high.

An SSL session begins with an exchange of messages called the SSL handshake. The handshake allows the server to authenticate itself to the client, and then allows the client and the server to exchange symmetric keys. In the affected versions, the BIG-IP default SSL timeout for the initial exchange to complete is 60 seconds.

Impact

BIG-IP systems with an SSL handshake timeout longer than 10 seconds may be more vulnerable to SSL handshake denial-of-service (DoS) attacks.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the event of an SSL handshake-based DoS attack, you notice higher-than-usual Traffic Management Microkernel (TMM) memory consumption and a slow response from the BIG-IP system.

Workaround

To work around this issue, you can reduce the SSL handshake timeout. The example below sets the timeout values to 10 seconds, which is the recommended default, but you can configure the setting as needed. To lower the SSL handshake timeout, perform one of the following procedures, depending on your software version.

Reducing the SSL handshake timeout

Impact of workaround: If you set too short of a timeout for your environment, the system may close the connection for slow clients.

BIG-IP 10.x/11.x

Note: In the following procedure, replace <profile> with the name of your Server or Client SSL profile.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To show the current Client and Server SSL handshake timeout, use the following command syntax:

    list ltm profile client-ssl <profile> handshake-timeout
    list ltm profile server-ssl <profile> handshake-timeout

  3. To modify the current Client and Server SSL handshake timeouts, use the following command syntax:

    modify ltm profile client-ssl <profile> handshake-timeout 10
    modify ltm profile server-ssl <profile> handshake-timeout 10

  4. Save the change by typing the following command:

    BIG-IP 10.1.0 and later:

    save /sys config

    BIG-IP 10.0.x:

    save config

BIG-IP 9.x

Note: In the following procedure, replace <profile> with the name of your server or client SSL profile.

  1. Log in to the BIG-IP command line as the root user.
  2. To check the current SSL handshake timeouts for the client and server, use the following command syntax:

    bigpipe profile <profile> list | grep handshake

    For example:

    bigpipe profile clientssl list | grep handshake
    bigpipe profile serverssl list | grep handshake

  3. To modify the current Server and Client SSL handshake timeouts, use the following command syntax:

    bigpipe profile clientssl <profile> handshake timeout 10
    bigpipe profile serverssl <profile> handshake timeout 10
