Known Issue

The Traffic Management Shell (tmsh) may not display the correct Virtual Server Score in BIG-IP DNS (formerly known as BIG-IP GTM) server object statistics. 

This issue occurs when the following condition is met:

  • You have configured a BIG-IP LTM virtual server with a non-zero VS Score value.

    Note: VS Score appears as gtm-score in both the configuration file and the tmsh utility output of the BIG-IP LTM system.

Impact

When using the tmsh utility, you cannot display the correct Virtual Server Score in the BIG-IP DNS server object statistics. You can safely ignore this issue; it does not affect any BIG-IP DNS load balancing methods.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the tmsh show gtm server <server object name> detail command, the Virtual Server Score displayed is 0 (zero) for a virtual server with a non-zero VS Score value.
