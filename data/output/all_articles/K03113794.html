K03113794: How display APM access sessions by IP Address or Username from the CLI

Description

This solution will explain how to display APM Access Sessions by client IP Address or Username.

Environment

  • Access Session
  • APM

Cause

You have a need to display access sessions per IP Address or Username.

Recommended Actions

Login to the APM CLI and display sessions by IP Address or Username.

  1.  Login to the APM Command Line.
  2.  Enter the tmos shell with the tmsh command.
  3.  User the following commands to display access sessions by client IP Address or username:
#show apm access client-ip <ip_addresss>

#show apm access username <username>

Example output of the above commands:

root@(apm)(cfg-sync Standalone)(Active)(/Common)(tmos)# show apm access client-ip 10.155.205.253
Total records returned: 1
apm access-info 7f8405b8 {
    logon-user f5user
}

root@(apm)(cfg-sync Standalone)(Active)(/Common)(tmos)# show apm access client-ip 10.155.205.253
Total records returned: 2
apm access-info 7f8405b8 {
    logon-user f5user
}
apm access-info cb43fa1b {
    logon-user f5user
}

root@(apm)(cfg-sync Standalone)(Active)(/Common)(tmos)# show apm access logon-user f5user
Total records returned: 2
apm access-info 7f8405b8 {
    client-ip 10.155.205.253
}
apm access-info 69f2b75b {
    client-ip 172.18.4.155
}

In the above examples the "apm access-info" is a unique APM Session ID.
