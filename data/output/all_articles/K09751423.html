Description

You want to set a boot loader password to secure the kernel command line to avoid possible intruder modifications with unauthorized console access.

Environment

  • Boot loader Password
  • Securing kernel command line
  • Console access

Cause

None

Recommended Actions

Important: Please note this procedure is not officially supported by F5. It has not been tested if the procedure survives an upgrade, or if it needs to be disabled and re-enabled before a major release upgrade. It is recommended to take precautions to safely store the password used, as it could be needed for troubleshooting.

To configure a boot loader password follow these steps:

Note: The BIG-IP will still boot without any manual user interaction, but will require authentication for any change to the kernel command line, besides when choosing one of the existing entries.

  1. From console, access the GRUB menu and press "c" for a command-line.
  2. You will see the grub command prompt: grub>
  3. Run this command, and when prompted, enter the password of your choosing: md5crypt

    For example:

    grub> md5crypt
    Password: Abc123!@
    Encrypted: $1$j4Aju0$8THCHPqn..DRBoGAW6efP/
     

  4. Copy the encrypted output on a separate text file safely
  5. Reboot the device normally
  6. From the command line, type the command: grub_open

    It will show full name and path of the grub.conf file similar to the following:

    /var/run/grub.conf.mdfy.11138

  7. Edit the grub.conf file shown before: vi /var/run/grub.conf.mdfy.11138
  8. Add the encrypted password copied on step 4, in the global section of the file, adding the line password --md5 similar to the example below:

     

    splashimage=(hd0,0)/img/splashimage.xpm.gz
    default=0
    timeout=8
    password --md5 $1$j4Aju0$8THCHPqn..DRBoGAW6efP/ → Paste encrypted password here

    title BIG-IP 14.1.2 Build 0.0.37 - drive vda.1
            root (hd0,0)
            kernel /boot/1/vmlinuz ro root=UUID=56f11167-6211-4946-acf3-a21f14b63393  console=ttyS0 console=tty0 panic=1 platform=Z100 default_cpu_order quiet
            initrd /boot/1/initrd
            # TIC_VS_PROJECT:
            # TIC_VS_PRODUCT: BIG-IP
            # TIC_VS_VERSION: 14.1.2
            # TIC_VS_BUILD: 0.0.37
            # TIC_VS_BASEBUILD: 0.0.37
            # TIC_VS_EDITION: Final
            # TIC_VS_PROJECT:

  9. Close the grub.conf file editing with: grub_close
  10. Reboot the device again

Additional Information

Note that if, at any point, you need to restart the BIG-IP system in single-user mode for troubleshooting purposes, you will need access to this password. In case of misplace of the boot loader password, you might need to perform a clean installation using the USB thumb drive option to recover access to the system.
