K000133045: Commands For Troubleshooting ELK(EMS)

Type
Support Solution
Published
2023-03-17
Updated
2024-10-25
Source

Description

  • This article present command elk curl commands use to obtain important information to trouble elk issue

 

 

Environment

  • SDC 5.1(EMS)
  • ELK

 

Cause

TDR stop generating and ELK need to be troubleshooted.

 

 Recommended Actions

Running the command below on EMS to collect essential data for ELK troubleshooting.

*note: do replace "ip" section below with actual EMS ip address.

 

curl -X GET "https://ip:9200/_cat/nodes?v" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cluster/health?pretty" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cat/allocation?v" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cat/allocation/explain?pretty" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cat/indices?v" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cat/shards?v" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cat/shards?h=index,shard,prirep,state,unassigned.reason" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cluster/allocation/explain?pretty" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cat/recovery?v" -H 'Content-Type: application/json' --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/fluentd.tdr/_ilm/explain?pretty" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_nodes/stats/breaker?pretty" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cat/nodes?v=true&h=name,node*,heap*" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cat/indices?h=health,status,index,id,pri,rep,docs.count,docs.deleted,store.size,creation.date.string&v" --key instance.key -k -u elastic:traffix
