Description

  • The main causes of high memory utilization on BIG-IQ CM

Environment

  • BIG-IQ CM

Cause

  • The highest percentage of memory use in BIG-IQ CM can be attributed restjavad process 
  • Core functionalities of restjavad on the BIG-IQ system is to provided REST APIs 
  • The other services with heavy system memory use is 'tokumx'. This process is responsible for managing bigiq system configuration database.
  • We also have 'elasticsearch' service optimizes and enables BIG-IQ's to process event and status messages sent from bigiq dcd logging node  

Recommended Actions

  • In short, memory use by restjavad, tokumx and elasticsearch, amounts for the majority of memory use in BIG-IQ. If system is experiencing memory resources pressure
    • consider increasing memory on virtual machine
    • consider reduce the number of managed bigIPs on the bigIQ,
    • consider upgrading to the latest BIG-IQ version
