Issue

Error Message

010e0004:4 MCPD query response exceeding <duration> seconds

In this error message, note the following:

  • <duration> is the amount of time.

For example:

010e0004:4: MCPD query response exceeding 30 seconds.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions are met:

  • The mcpd process is taking long to respond. 
  • The SNMP subagent is encountering long timeouts while communicating with mcpd.

Impact

SNMP requests fail.

Recommended Actions

You can retry the SNMP request to determine whether a temporary mcpd slowdown is occurring. You can also execute an unrelated TMOS Shell (tmsh) command to check whether slow response times are generally occurring. If the message persists over time, it may be necessary to restart the BIG-IP system.
