Source
https://my.f5.com/manage/s/article/K81125632

Description

You may see "No records to display" message when you filter ASM Event log by a specific signature ID only.
However, you may see some event logs when you filter it by signature ID and the other filters (ex. policy name/ virtual server name)

Environment

  • BIG-IP ASM
  • Security >> Event Log >> Application >> Requests
  • Only Signature ID is applied as a filter

Cause

It is by our design. 

Recommended Actions

In addition to signatureID, use some additional filters.

Additional Information

None
