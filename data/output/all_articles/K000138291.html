Description

You upload a renewed certificate with a BIG-IP Application Service 3 Extension (AS3) declaration; however, the configuration reverts to using the old certificate.

Environment
  • BIG-IP
  • AS3
Cause

If there is an overlooked error in the JSON, the entire AS3 declaration will fail and lead to unexpected results in other areas of the declaration such as renewing a certificate.

The error could be unrelated to the symptoms reported. For example, a datagroup that is referenced in an iRule in the AS3 declaration file is missing. An error similar to below can be seen in the /var/log/restnoded/restnoded.log depending on JSON declaration file content.

Thu, 18 Jan 2024 11:47:06 GMT - severe: [appsvcs] {"message":"Declaration failed: 01070151:3: Rule [/Common/Shared/irule-uat] error: Unable to find value_list (/Common/Shared/datagroup-uat) referenced at line 4: [class match -value -- $http_host starts_with /Common/Shared/datagroup-uat]","level":"error"}

Recommended Actions

Correct the AS3 JSON declaration file. In the previous example this means including the missing data group.
