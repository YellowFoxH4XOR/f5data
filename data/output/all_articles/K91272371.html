Description
New boot location named "HD1.0" does not show in Configuration Utility (System  ››  Software Management : Boot Locations).
Additionally, in Installed images the value for "Media" is blank (System  ››  Software Management : Image List).
On tmsh, the software volume media is "none".

# list sys software volume
sys software volume HD1.0 {
    basebuild 0.0.15
    build 0.0.15
    media none
    product BIG-IP
    status complete
    version 11.6.5
}

Environment

  • BIG-IP 11.6.4
  • Platform 2000

Cause
Boot location does not get configured properly when named HD1.0.

Recommended Actions

  1. Delete boot location HD1.0 from tmsh:

    tmsh delete sys software volume HD1.0

  2. Install software image creating a boot volume with a different name (HD1.x, where "x" is different than "0")

    For Example:
    tmsh install sys software image BIGIP-11.6.4-0.0.4.iso create-volume volume HD1.3 reboot

  3. Boot location and installed image should now show properly in the GUI.
