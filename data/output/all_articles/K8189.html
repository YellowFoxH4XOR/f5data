Known Issue

This is the result of a known issue. When a user enters Protected Workspace with a Microsoft Windows Vista client, icons that exist on the user's Windows Desktop may appear on the Desktop inside Protected Workspace. By allowing these icons to appear, the user may have access to an application that can create data outside Protected Workspace. Protected Workspace should only display a generic Desktop with icons for browsers, the Recycle Bin, and an option for exiting Protected Workspace.

F5 Product Development tracked this issue as CR88226 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Note: Support for Microsoft Windows Vista began in FirePass version 6.0.1. For more information, refer to K6843: FirePass support for Microsoft Windows Vista. Support for Protected Workspace with Microsoft Vista in version 6.0.1 requires a hotfix. For more information, refer to K7179: Protected Workspace does not support Microsoft Windows Vista clients in FirePass version 6.0.1.
