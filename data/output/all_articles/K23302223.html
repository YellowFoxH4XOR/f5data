Description

Analytic Reporting graphs do not work with the BIG-IP system when managed by the BIG-IQ system.

For example, if a Virtual Server is configured with an http analytics profile, when navigating to Statistics  --›  Analytics --> HTTP --> Overview no data shows up for that Virtual Server.

Environment

  • BIG-IQ 6.0.0 and later
  • BIG-IP modules LTM, ASM, AFM, AVR, and APM

Cause

This behavior is by design.

Recommended Actions

  1. Monitor statistics and reporting from the BIG-IQ system.

Additional Information

This statistics behavior is expected. A change in BIG-IQ 6.0.0 created this behavior. When you set up the BIG-IQ system to gather statistical data for BIG-IP systems, a configuration change occurs that the BIG-IQ pushes to the BIG-IP system in the global settings for analytics. This setting changes the 300 second aggregation time to 30 seconds. When this happens, by design, the BIG-IP system no longer aggregates data. When there is no aggregation, there is no data produced to provide charts or other tracking data on the BIG-IP system. You can only access it through the BIG-IQ system.

A BIG-IP system aggregates statistics only every five minutes (300 seconds). This is also by design. This is because each aggregation spikes the CPU for several seconds. Thus, when you change it to 30, by design, it stops aggregating the statistics to prevent the BIG-IP system from experiencing a constant CPU spike. Additionally, there is a very limited amount of space to store data on the BIG-IP system. The resources for a BIG-IP system are focused on protecting and running the traffic for a network, not statistics-gathering on a large scale.

The BIG-IQ system gathers statistics because it is designed to aggregate statistics every 30 seconds instead of every 300 seconds; thus it more quickly provides data than the BIG-IP system can. The BIG-IQ system also has far greater storage space. The BIG-IQ system also provides for the centralized management of the BIG-IP system, which is very helpful when in an environment where you have more than just a few BIG-IP systems.

Note: Due to the statistics no longer being aggregated locally on the BIG-IP, remote reporting to other devices no longer works because the BIG-IP system no longer has locally stored statistics to send to other remote devices. This applies to the statistics for all modules listed in this article.
