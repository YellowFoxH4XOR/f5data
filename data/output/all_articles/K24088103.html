Description

  • When trying to delete a certificate and key an error message stating they are associated with an HTTPS monitor is displayed.
  • Certificate and Key cannot be deleted from the GUI as no association of them to the HTTPS monitor is apparent.
  • The tmsh list ltm monitor <monitor name> command does show the certificate and key associated to the HTTPS monitor.

Environment

  • HTTPS monitor created under version 11.x-12.x
  • BIG IP upgraded to version 13.x- 15.x

Cause

On versions 11.x-12.x when a new HTTPS monitor was created when displaying the advanced configuration options there was a section where you could associate a certificate and a key. In 13.x- 15.x when creating and HTTPS monitor the advanced configuration will only allow a  Server SSL profile to be associated. Then HTTPS monitor could have been created in an older version and when the device was upgraded to a new version this configuration was inherited from the old version. This could cause the HTTPS monitor to be associated with a cert and key instead of being associated with the Server SSL profile. 

Recommended Actions

Using tmsh to disassociate the certificate and key from the HTTPS monitor.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To disassociate the certificate and key from the HTTPS monitor, use the following command syntax:

    modify ltm monitor https <https_monitor name> cert none key none
