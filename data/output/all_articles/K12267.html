Topic

BIG-IP software includes SYN cookie protection, which prevents the BIG-IP SYN queue from becoming full during a SYN flood attack. The SYN Check Activation Threshold setting indicates the number of new or untrusted TCP connection attempts that can be made before the BIG-IP system activates the SYN cookie authentication method for subsequent TCP connections.

Note: For information about BIG-IP SYN cookie protection, refer to K7847: Overview of BIG-IP SYN cookie protection (9.x - 11.2.x).

In BIG-IP 10.2.1 and later, autolasthop must be enabled in order to use hardware SYN cookie protection. For more information, refer to K16887: Autolasthop must be enabled for hardware SYN cookie protection to function.

In BIG-IP 9.0.0 through 9.3.x, SYN cookie protection is available for certain protocol profiles that support the SYN cookie protection attribute. SYN cookie protection is not enabled for self IP addresses.

In BIG-IP 9.4.0 and later, SYN cookie protection is available for certain protocol profiles that support the SYN cookie protection attribute. In addition, SYN cookie protection is enabled for all self IP addresses. It is not possible to disable SYN cookie protection for self IP addresses.

This feature was added as a result of CR68831.
