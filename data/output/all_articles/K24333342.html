Description

In the log file /var/log/restnoded/restnoded.log, get the log below:

severe: [SSLO] App Name: ssloGS_global App Type: null
severe: [SSLO] Device <management IP> is having hanging MCP objects and need cleanup
severe: [SSLO] Device <management IP> is having hanging MCP objects and need cleanup
severe: [SSLO] App config corrupted, please resolve before proceed

Environment

  • SSL Orchestrator
  • HA pair

Cause

Unknown yet

Recommended Actions

This "App config corrupted" message only for the configuration "ssloGS_global" in the restnoded logs can be ignored. However, if there is any warning in the Configuration Utility or other errors in the restnoded logs will need attention, please contact F5 support if you cannot resolve it.
