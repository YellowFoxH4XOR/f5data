K000132914: [F5OS-A] Tenant ISO image upload failed with "Size Mismatch" error

Source
https://my.f5.com/manage/s/article/K000132914

Description

Tenant ISO image is uploaded on GUI, and "Size Mismatch" error occurs.

Environment

  • F5OS-A
  • rSeries
  • Tenant ISO upload
  • GUI

Cause

  • User refreshed browser during uploading.

Recommended Actions

Do not refresh browser until upload is completed.

You can also use CLI to upload a tenant ISO file to /var/F5/system/IMAGES/ via SCP/SFTP.

Additional Information

To check why the tenant ISO upload is failing, you can check /var/F5/partition/log/platform.log using the following command: 
grep -a -i "image\-agent" /var/F5/partition/log/platform.log -n


For example:
File name uploaded:
     image-agent[10]: priority="Info" version=1.0 msgid=0x2005000000000001 msg="Image file added" FILE="BIGIP-15.1.8-0.0.7.ALL-F5OS.qcow2.zip.bundle".
  image-agent[10]: priority="Info" version=1.0 msgid=0x2002000000000012 msg="Image file transfer completed" IMAGE="BIGIP-15.1.8-0.0.7.ALL-F5OS.qcow2.zip.bundle.filepart".


Reason of upload failure:
     image-agent[10]: priority="Err" version=1.0 msgid=0x2002000000000010 msg="Could not verify image signature. Removed." IMAGE="BIGIP-15.1.8-0.0.7.ALL-F5OS.qcow2.zip.bundle.filepart" FAILURE="parse bundle".

Image is deleted:
     image-agent[10]: priority="Info" version=1.0 msgid=0x2005000000000002 msg="Image file removed" FILE="BIGIP-15.1.8-0.0.7.ALL-F5OS.qcow2.zip.bundle".
