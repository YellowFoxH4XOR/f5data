Description

Troubleshooting BIG-IQ or BIG-IP internal restjavad, restnoded, and icrd[_child]

Environment

  • BIG-IQ
    • Device Service Cluster (DSC)
    • Centralized Management
  • BIG-IP

Cause

None

Recommended Actions

Perform a packet capture: We know that in K23227510 the steps were provided to capture the restjavad and icrd traffic, however, in some versions the ports and awk may not save the correct port numbers into the variable and hence its important to first understand if the ports are correct or not before following that procedure.
In some version the ports and awk may not print the correct values. Please be aware of that.

For example:
For some version the "ss -nlpi" shows an extra column "Netid" this is causing the problem with printing ports using awk.

For Instance: In BIG-IP 14.1.2.3:
[root@LTM1.Example.com] var # ss -nlpi | more
Netid  State      Recv-Q Send-Q Local Address:Port               Peer Address:Port

In this case we need to use $5 to get the correct ports for icrd and java and also exclude the *
ports=$(ss -nlpi | awk '$0~"icrd"||$0~"java"{gsub(/([:f]?.+)?:/,"",$5);print $5}'  | grep -v "*")

[root@LTM1.Example.com] var # ss -nlpi | awk '$0~"icrd"||$0~"java"{gsub(/([:f]?.+)?:/,"",$5);print $5}' | grep -v "*"
50722
57973
54645
8100
8005
9832
8009


In BIG-IP  13.1.3:
[root@LTM1.Example.com] config # ss -nlpi | more
State      Recv-Q Send-Q        Local Address:Port          Peer Address:Port

Here we have missing Netid and hence need $4 to get the correct icrd and java ports.
ports=$(ss -nlpi | awk '$0~"icrd"||$0~"java"{gsub(/([:f]?.+)?:/,"",$4);print $4}')

[root@LTM1.Example.com] config # ss -nlpi | awk '$0~"icrd"||$0~"java"{gsub(/([:f]?.+)?:/,"",$4);print $4}'
1521
60451
8100
8005
8009

Its important to see if the ports and awk are saving the correct port for icrd and java else it may end up capturing nothing or garbage values.
