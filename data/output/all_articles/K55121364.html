Description

Request are blocked with the violation "Request length exceeds defined buffer size" when uploading more than 10 MB.

Environment

  • Blocked request
  • Buffer size
  • Violation
  • File Upload

Cause

By default, the buffer size is 10MB.

Recommended Actions

In order to avoid blocking legitimate requests, we can disable the violation by setting it as follow : 

"violations": [
           {
           "name": "VIOL_REQUEST_MAX_LENGTH",
           "alarm": true,
           "block": false                    
               }
           ]

For information about configuring the NGINX App Protect WAF security policy, refer to the following articles:

  • K69732105: Create NGINX App Protect WAF security policies
  • K14230463: Reduce false positive violations in NGINX App Protect WAF
