Topic

When the BIG-IP system activates the compression license enforcement, the system will induce NULL compression. NULL compression represents traffic that the BIG-IP system received, but did not compress because the compression license limit was exceeded.

The BIG-IP system uses the following indicators when the licensed compression limit has been exceeded:

  • The BIG-IP system logs the following message to the /var/log/ltm file:

    Compression license limit of <limit> Mbit/s exceeded today.

    The BIG-IP system will log this message once per day.
  • If SNMP traps are configured, the BIG-IP system sends an SNMP trap with the following Object ID:

    OID=.1.3.6.1.4.1.3375.2.4.0.35

    Note: If you require additional compression capability, contact your F5 Sales representative to purchase an additional license.
