Issue

ARX 2.7.x

In ARX 2.7.x, the clean_reports expect script deletes all reports with a status of INCOMPLETE, DONE, or FAILED.

To delete all reports, use the following command:

expect clean_reports

ARX 3.x

For ARX 3.x, the clean_reports expect script deletes all reports with a status of PARTIAL, INCOMPLETE, DONE, FAILED, or DISABLED. Additionally, optional arguments were introduced to allow reports to be deleted based on the type of report and the age of the report.

Command syntax:

expect clean_reports [type [age]]

To delete all reports, use the following command:

expect clean_reports

To delete reports of a specific type, use the following syntax:

expect clean_reports <type>

For example, remove Import reports by typing the following command:

expect clean_reports imp

To delete reports of a specific type and age, use the following command syntax:

expect clean_reports <type> <age>

For example, remove Import reports older than 90 days by typing the following command:

expect clean_reports imp 90days ago

Note: If the ago value is not specified after the number of days, the older than date is counted forward, resulting in a date in the future.

ARX 4.x and later

Beginning in ARX 4.0.0 and later, the clean_reports expect script deletes all reports with a status of PARTIAL, INCOMPLETE, DONE, or FAILED. An optional argument allows reports to be deleted based on the age of the report. However, the optional argument to remove a specific type of report was removed.

Command syntax:

expect clean_reports [age]

To delete all reports, use the following command:

expect clean_reports

To delete reports of a specific age, use the following syntax:

expect clean_reports <age>

For example, remove reports older than 90 days by typing the following command:

expect clean_reports 90 days ago

Note: If the ago value is not specified after the number of days, the older than date is counted forward, resulting in a date in the future.
