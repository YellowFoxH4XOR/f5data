Description

You can run confd command in admin mode for F5OS
But sometimes grepping information is required to narrow down output and need to run on bash mode.
How to run confd command in bash mode?

 

Environment

  • F5OS-A / F5OS-C
  • rSeries CLI
  • Velos Controler CLI
NOTE: Velos partition CLI: confd only: K65442484: Overview of access to the F5 VELOS system
 

Cause

  • n/a

Recommended Actions

Use the below syntax:
docker exec <CONTAINER_NAME> <COMMAND>

 

For example,  check system health and grep by unhealthy status component

On rSeries: 

docker exec system_manager /confd/scripts/f5_confd_run_cmd show system health | grep unhealthy -B 2
 

On Velos Controller CLI for controller confd:

docker exec vcc-confd /confd/scripts/f5_confd_run_cmd show system health |grep unhealthy -B 2
 

On Velos Controller CLI for the partition's confd:

exec partition<ID>_manager /confd/scripts/f5_confd_run_cmd show running-config | head -5

(1) You need to know which controller the partition services are running on and the partition ID.  

NOTE: It might not be the same as the controller

      you're logged into run in confd mode on Controller CLI, below command:

syscon-1-active# show partitions partition <partition_name>

                                                                             RUNNING
                      BLADE OS     SERVICE                  PARTITION        SERVICE      STATUS
NAME              ID  VERSION      VERSION      CONTROLLER  STATUS           VERSION      AGE
--------------------------------------------------------------------------------------------------
<partition_name>  2   1.6.1-19136  1.6.1-19136  1           running-standby  1.6.1-19136  14s
                                                2           running-active   1.6.1-19136  10s


(2) If the partition has different active controller than System Controller, you can SSH to the correct controller and run the command:
e.g.
 [root@controller-1(velos_lab.f5.com) ~]# ssh controller-2 docker exec partition2_manager /confd/scripts/f5_confd_run_cmd show running-config | head -5
