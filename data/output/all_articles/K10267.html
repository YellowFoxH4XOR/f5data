Topic

FirePass Network Access provides organizations the capability to deploy secure remote access to their users. Network Access can be used by virtually any IP application to extend the reach of the corporate network to the users present location, offering LAN-like access to resources. Microsoft provides a capability known as Outlook Anywhere for the Microsoft Office Outlook product. When Outlook Anywhere is configured and deployed with a publicly routable IP address, Microsoft Outlook is allowed to communicate with the internal Microsoft Exchange Server for remote users without first needing to establish a Network Access SSL VPN connection.

FirePass users may assume that once they disconnect Network Access, communication to corporate resources will cease; however, communication will continue through the Outlook Anywhere capability for organization who have deployed and configured Outlook Anywhere. To work around this issue, utilizing Network Access would provide a consistent approach to remote access management.
