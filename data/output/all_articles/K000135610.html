Description

You would use F5 as a reverse proxy to load-balance the SSH or RDP connections to the nodes, but there is a problem with establishing the connections of RDP and SSH to the target server.

Environment

  • BIG-IP
  • RDP
  • SSH

Cause

Misconfiguration in the virtual servers on ports 22 and 3389
 

Recommended Actions

Ensure that you have two simple virtual servers created on ports 22 and 3389 with tcp profiles and without the client and server SSL profiles.

Also please ensure that the virtual server type on port 22 is layer 4 set-up such as is a Performance Layer 4.
