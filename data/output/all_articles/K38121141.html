Known Issue

Multiple network time protocol (NTP) server or domain searches in the Dynamic Host Configuration Protocol (DHCP) lease can cause missing DNS and NTP configurations.

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP system with DHCP enabled for the management interface.
  • Multiple network time protocol (NTP) servers or domain searches are specified in the DHCP Client lease, stored in the /var/lib/dhclient/dhclient.leases file.

Impact

  • DNS and NTP servers are not configured in the Master Control Program Daemon (MCPD).
  • Name resolution can break.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/boot.log file, the BIG-IP system logs an error message similar to the following example:

    dhcp_config: save error: 01070911:3: The requested host (ntp-servers-ip) is invalid for servers in ntp (/Common/ntp).
