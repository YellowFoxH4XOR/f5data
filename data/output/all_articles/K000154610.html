K000154610: License Assignment Failed. Most likely a valid license already exists for device, revoke it before applying a new license *****

Type
Support Solution
Published
2025-09-04
Updated
2025-09-04
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000154610

Description

When attempting to assign or refresh a license for a F5 BIG-IP device using the BIG-IQ, the following error may be encountered when activating from CLI:

***** License Assignment Failed. Most likely a valid license already exists for device, revoke it before applying a new license *****

Environment

  • BIG-IQ
  • BIG-IP
  • License Reactivation

Cause

  • License missing from BIG-IQ when viewing System/License from GUI
  • Only option is to reactivate

Recommended Actions

Verify  that the BIG-IQ has an active license by viewing system/License with in the GUI,  if it is missing or blank  you will see the option to reactivate.

Reactivate License on BIG-IQ
