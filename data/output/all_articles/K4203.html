K4203: 3-DNS support for IPv6 requests

Topic

The 3-DNS daemon, 3dnsd, does not support AAAA and A6 record requests. When a DNS system does not support these request types, it should issue a NOERROR response. A NOERROR response prompts the client to resend the request as an A record request.

By default, 3-DNS will pass AAAA and A6 record requests to the named process, which issues the NOERROR response. The 3-DNS is unable to send the NOERROR response on certain systems, such as the BIG-IP Link Controller. As a result, the requests will fail.

Beginning with version 4.6.3 of 3-DNS, BIG-IP and BIG-IP Link Controller, the 3dnsd process intercepts AAAA and A6 record requests and sends the NOERROR response. This behavior allows IPv6 name resolution compatibility regardless of whether the named process is running.
