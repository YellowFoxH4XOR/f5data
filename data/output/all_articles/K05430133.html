Known Issue

BIG-IP systems not licensed for the BIG-IP LTM module may fail to create fully-qualified domain name (FQDN) ephemeral nodes.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is licensed only for non-BIG-IP LTM modules, for example, BIG-IP ASM or BIG-IP APM.
  • The configuration contains pool members or nodes that were defined using FQDN.

Impact

You are unable to use FQDN nodes or pool members in the BIG-IP configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/ltm file, you observe error messages similar to the following example:

    err mcpd[<pid>]: 01070356:3: Ratio load balancing feature not licensed.

  • When you create an FQDN pool member or node, the system does not create a corresponding ephemeral node. For example, if you create a node for AskF5.com on a system licensed for the BIG-IP LTM module, the system creates the following two configuration objects:
    • The FQDN node object:

      ltm node AskF5.com {
          fqdn {
              autopopulate enabled
              name AskF5.com
          }
          state fqdn-up
      }

    • The FQDN dynamically created ephemeral node object:

      ltm node AskF5.com-165.160.13.20 {
          address 165.160.13.20
          ephemeral true
          fqdn {
              name AskF5.com
          }
      }

    For BIG-IP systems that are not licensed for BIG-IP LTM, the system does not create the dynamically created ephemeral node.
