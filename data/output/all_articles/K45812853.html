Description

Using HTTP (Server)  profile with HTTP2 (Client) -the header on server side is corruped.

Environment

  • BIG-IP
  • HTTP2 profile configured on client-side
  • HTTP profile configured on server-side
  • Client is sending empty header field, it can be seen in a packet capture. i.e.:

    Client side:

    HyperText Transfer Protocol 2

            Header Block Fragment: 8241890ba15c2eae16c4bb3f8704b26298e862c2a12c770b149a82a127a8a86293f72d25…
            [Header Length: 1066]
            [Header Count: 24]

            Header: :authority: 192.168.2.3

Cause

The trigger for this behave is an empty header.
In the example above the  'x-forwarded-for' just before the 'apt_transaction_originator' that is being altered

This was found as Bug ID 988693.

Recommended Actions

Upgrade your BIG-IP to v13.1.X or later.
