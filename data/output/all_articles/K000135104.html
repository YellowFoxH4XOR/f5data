Description

During boot you can notice ACPI messages in /var/log/kern.log:

Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: RSDP 00000000000f6a10 00024 (v02 PTLTD )
Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: XSDT 00000000bfeefb94 0005C (v01 INTEL  440BX    06040000 VMW  01324272)
Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: FACP 00000000bfefee73 000F4 (v04 INTEL  440BX    06040000 PTL  000F4240)
Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: DSDT 00000000bfeefdfc 0F077 (v01 PTLTD  Custom   06040000 MSFT 03000001)
Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: FACS 00000000bfefffc0 00040
Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: BOOT 00000000bfeefdd4 00028 (v01 PTLTD  $SBFTBL$ 06040000  LTP 00000001)
Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: APIC 00000000bfeefd84 00050 (v01 PTLTD  ? APIC   06040000  LTP 00000000)
Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: MCFG 00000000bfeefd48 0003C (v01 PTLTD  $PCITBL$ 06040000  LTP 00000001)
Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: SRAT 00000000bfeefc90 000B8 (v02 VMWARE MEMPLUG  06040000 VMW  00000001)
Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: HPET 00000000bfeefc58 00038 (v01 VMWARE VMW HPET 06040000 VMW  00000001)
Oct 20 04:33:05 localhost warning kernel: kernel: [    0.000000] ACPI: WAET 00000000bfeefc30 00028 (v01 VMWARE VMW WAET 06040000 VMW  00000001)

Environment

  • Big-IP platform
     

Cause

ACPI stands for Advanced Configuration and Power Interface. It provides open standard interface between operating system and hardware to perform power management, auto configuration and status monitoring.

ACPI uses ACPI tables which contain information shared by BIOS/UEFI. These tables are put in memory and accessible to OS.

Above kernel log messages shows that kernel was reading/parsing ACPI tables during boot and their corresponding memory location. 4 letter acronym indicates which ACPI table was read, e.g.:
"RSDT": Root System Description Table (RSDT; 32-bit version of the XSDT)
"XSDT": Extended System Description Table (64 bit version of the RSDT)
"FACP": Fixed ACPI Description Table (FADT)
"DSDT": Differentiated System Description Table (DSDT)

Recommended Actions

Messages can be ignored. No action is required.
 

Additional Information

More information about ACPI tables is available in the ACPI specification: https://uefi.org/sites/default/files/resources/ACPI_Spec_6_5_Aug29.pdf
