Known Issue

The BIG-IP system may fail to use a self IP address from the same subnet as the pool member being monitored.

This issue occurs when all of the following conditions are met:

  • Self IP addresses are configured in two or more subnets for the same VLAN.
  • Self IP addresses are configured in two or more VLANs for the same route domain.
  • A resource pool contained two or more pool members from different IP subnets or route domains of the same VLAN.
  • The affected resource pool or the pool members were configured with at least one health monitor.

When the above conditions are met, the BIG-IP system uses the self IP address that was first configured for the VLAN, when the system initiates monitor connections to pool members. Any additional self IP addresses configured for the additional subnets or route domains for the same VLAN are not used.

Impact

The BIG-IP system incorrectly marks pool members down.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H379817 on the Diagnostics > Identified > Low screen.
  • The BIG-IP system may initiate monitor connections using a self IP address from the wrong subnet.
  • The BIG-IP system incorrectly marks pool members down.
