Remote Authentication Dial-in User Service (RADIUS) is a remote authentication service available on the BIG-IP system to authenticate users. The BIG-IP system implementation of RADIUS supports only the Password Authentication Protocol (PAP) authentication method.

If the remote RADIUS server is configured to use a different authentication protocol, authentication will fail.
