Description

The ICMP error limit can be like the good, the bad, and the ugly.

  • It can be expected traffic but hitting a limit on the BIG-IP.
  • It can be something in your network that without knowing it is DoSing the BIG-IP (such as someone running an internal test).
  • It can be an outside entity DoSing you.

Environment

  • The BIG-IP may be experiencing resource issues or icmp packets are not passing through.
  • This log entry is see in /var/log/ltm "01200015:4: Warning, ICMP error limit reached".

Recommended Actions

  • If the log entry is seen run this command... 
    tmctl icmp_stat
    The output should resemble....
# tmctl icmp_stat
tx rtx  rx forward drop err_cksum rxsummismatch err_len err_mem err_rtx
-- --- --- ------- ---- --------- ------------- ------- ------- -------
 0   0 384       0    0         0             0       0       0       0

err_proto err_opt err drop_limit drop_notactive drop_ttl drop_mcast drop_route
--------- ------- --- ---------- -------------- -------- ---------- ----------
        0       0   0          0              0        0    7501794          0

Note: The command output can be a elongated by running it this way... tmctl icmp_stat -w 200 This may be easier to read.
 
  • Bug ID 859717: ICMP-limit-related warning messages in /var/log/ltm was created to provide a breakdown of the heading, and K50145432: Warning "ICMP error limit reached" is logged, but BIG-IP doesn't send any ICMP error packets provides the whys and wherefores.
  • A Bugtracker is not made to be verbose but only to provide a brief outline and a workaround.
  • The bug added some counters that are not wellknown. What those counters indicate are...
HeadingMeaning
drop_limtICMP 4 & 6 error packet was not sent, rate-limited
drop_notactiveICMP 4 & 6 error packet was not sent, HA not active
drop_mcastICMP 4 & 6 error packet was not sent, mutlicast destination rfc1812#section-4.3.2.7
drop_routeICMP 4 & 6 error packet was not sent, route to destination missing
err_txICMP 4 & 6 error packet was sent
drop_ttlICMP4 error packet was not sent, TTL too low
drop_redirectICMP6 error packet was not sent, redirect rfc4443#section-2.4
drop_hlimICMP6 error packet was not sent, HLIM too low
drop_sourceICMP6 error packet was not sent, wrong packet source rfc4443#section-2.4
 

Additional Information

The stats can be reset by running this command...

tmsh reset-stats sys icmp-stat

Stats can also be seen by running...

tmsh show sys icmp-stat

For more help and option...

tmctl icmp_stat --help
