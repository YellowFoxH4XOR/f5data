Known Issue

Accessing the iControl representational state transfer (REST) application programming interface (API) immediately after a restart may cause the icrd_child process to restart and produce a core file.

This issue occurs when the following condition is met:

  • Following a restart of the BIG-IP system, you log in to the iControl REST API before all of the necessary services required by iControl REST are fully initialized.

Impact

The iControl REST API is temporarily not available for configuration queries or modifications while the process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The iControl REST API is temporarily not available.
  • Your BIG-IP system creates an icrd_child core file in the /shared/core directory.

Workaround

To work around this issue, allow the BIG-IP system to fully start before you access the iControl REST API.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
