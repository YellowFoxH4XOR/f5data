Issue

Error Message

notice sod[<PID>]: 010c007e:5: Not receiving status updates from peer device <device> (Disconnected)

In this error message, note the following:

  • <PID> is the process ID for the sod process.
  • <device> is the hostname of the peer device in the device group.

For example:

notice sod[9898]: 010c007e:5: Not receiving status updates from peer device /Common/LTM2.example.com (10.10.10.12) (Disconnected)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A peer device in the failover-sync group fails to receive failover packets for the duration of the network failover timer value.

Impact

The device in the message is marked offline by the device that is logging the message. The disconnected device is not eligible to become the next failover device until the system restores failover communication.

Recommended Actions

The state of the disconnected device should be verified. Communication problems with the peer device could be caused by issues on the network, hardware problems, or other environmental issues.
