Known Issue

This is the result of a known issue. After a temporary loss of connectivity from the ARX system to a filer, NFS exports may become inaccessible for some clients while remaining accessible for other clients. When this issue occurs, syslog will contain several messages that appear similar to the following example

NFS/TCP LOOKUP Error-Closed Connection: Internal (cleanup). XID 0x64e6721a

F5 Networks Product Development tracked this issue as ID 37512 and it was fixed in ARX version 5.1.5. For information about upgrading, refer to the ARX Release Notes.

Additionally, this issue has been fixed in a hotfix available for ARX versions 4.1.3 and 5.1.0. Customers affected by this issue should request the hotfix from F5 Networks Technical Support, referencing this Solution number and ID number.

Workaround

To recover from this condition, you must fail over the active ARX system.
