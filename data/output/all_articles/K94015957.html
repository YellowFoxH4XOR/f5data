Description

Recent versions of MacOS require that code should be Signed and Notarised and Apple Silicon devices will not run unsigned code.
 https://support.apple.com/en-au/guide/security/sec3ad8e6e53/web
 

Environment

SSL VPN deployments including

  • MacOS devices running F5 Edge Client for MacOS
  • MacOS devices running F5 Access for MacOS
  • MacOS devices using a browser and the 'F5 Endpoint Inspector.app'  and 'F5vpn.app' helper applications

Cause

The following commands can be used to check the installed versions and confirm the code signature on MacOS
   spctl -vva <path-to-application>
where the -vva requests a verbose security assessment response from the Apple policy subsystem 

Recommended Actions

Confirm each application is signed for example: 

This confirms the F5Access app is signed from the Apple Mac App Store 

% spctl -vva /Applications/F5Access.app 
/Applications/F5Access.app: accepted
source=Mac App Store
origin=Apple Mac OS Application Signing

This confirms the 'BIG-IP Edge Client' app is notarised by F5 as expected

% spctl -vva /Applications/BIG-IP\ Edge\ Client.app
/Applications/BIG-IP Edge Client.app: accepted
source=Notarized Developer ID
origin=Developer ID Application: F5 Networks, Inc. (57P38MF5GS)

This confirms the 'F5 VPN' app and is 'F5 Endpoint Inspector' app are notarised by F5 as expected.

% spctl -vva /Applications/F5\ Endpoint\ Inspector.app
/Applications/F5 Endpoint Inspector.app: accepted
source=Notarized Developer ID
origin=Developer ID Application: F5 Networks, Inc. (57P38MF5GS)

% spctl -vva /Applications/F5\ VPN.app                
/Applications/F5 VPN.app: accepted
source=Notarized Developer ID
origin=Developer ID Application: F5 Networks, Inc. (57P38MF5GS)

Here is another check of part of the Edge Client that shows that binary is signed by F5, but is not a full application.

% spctl -vva /Applications/BIG-IP\ Edge\ Client.app/Contents/Helpers/PolicyServer/Applications/BIG-IP Edge Client.app/Contents/Helpers/PolicyServer: rejected (the code is valid but does not seem to be an app)
origin=Developer ID Application: F5 Networks, Inc. (57P38MF5GS)

This is checking the third-party library that is provided by OPSWAT and installed by F5, as ecpected this is valid, but not a full application.

spctl -vva /Library/F5Networks/Inspectors/libwaresource.dylib
/Library/F5Networks/Inspectors/libwaresource.dylib: rejected (the code is valid but does not seem to be an app)
origin=Developer ID Application: OPSWAT, Inc. (ARQ7AT7Y5E)

Additional Information

In Micosoft Windows the Application structure and signing is completely different, but similar information can be checked using the "Client Troubleshooting Utility (aka CTU)".
