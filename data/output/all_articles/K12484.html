Known Issue

If specific products have been listed in the Antivirus ID section of the Antivirus action in the access policy or Endpoint Inspector Details, OPSWAT 3.4.19 and earlier are unable to detect the Japanese version of Trend Micro Virus Buster 2011 Cloud.

The antivirus checker uses software libraries from a software development kit (SDK) created by OPSWAT. OPSWAT provides a vendor-independent framework for endpoint security management.

F5 Product Development tracked this issue as ID 346604. OPSWAT has reported that this issue is fixed starting in OPSWAT 3.4.19.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about installing OPSWAT hotfixes on BIG-IP APM, refer to K10942: Installing OPSWAT hotfixes on BIG-IP APM systems.

For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.

For information about downloading and installing OPSWAT hotfixes on FirePass, refer to K6664: Obtaining and installing OPSWAT hotfixes.

Workaround

This issue can be addressed by accepting all antivirus software rather than inspecting the client machine for specified antivirus software. To do so, select Any for the Antivirus ID in the BIG-IP APM access policy or in the FirePass Endpoint Inspector Details.
