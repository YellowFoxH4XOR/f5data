Description
During routine iQuery SSL renegotiation, the iQuery connection will occasionally be reset with maybe one of below log:

err gtmd[<PID>]: 011ae0fa:3: iqmgmt_receive: SSL error: SSL read (5)

This usually takes no longer than one second. 

Environment

  • BIG-IP DNS
  • iQuery connection to other BIG-IP

Cause
ID 760471

Recommended Actions

  1. There is no workaround available.
  2. Refer to ID 760471 for the fixed version.
