Topic

Starting in version 3.2.3, proxyd for the BIG-IP system is compliant with x509 version 3 certificate and key pairs.

As of BIG-IP 4.0, when generating a self-signed certificate or a Certificate Signing Request (CSR) using the BIG-IP system, the certificate/request is automatically created in proxyd x509 version 3 format.
