Known Issue

Network access may fail for BIG-IP Edge Client users.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP Edge Client installation is configured with the following features:

    • Auto launch after Windows Logon
    • ?Enable always connected mode
  • Your BIG-IP APM network access profile is configured with the Location DNS List option.
  • A user's device network adapter is connected to a network where one of the DNS locations matches the DNS suffix set on the local network.

Impact

The user's device cannot connect to the network.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP Edge Client status displays "Disconnected - LAN detected." However, all network access is blocked.
  • When the user device network adapters are not connected to a network where one of the DNS locations matches the DNS suffix, the network is accessible.
