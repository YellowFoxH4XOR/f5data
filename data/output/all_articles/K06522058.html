K06522058: FAST template deployment failure due to Invalid Virtual Address

Type
Support Solution
Published
2021-08-30
Updated
2025-02-06
Applies to
  • F5 Automation and Orchestration
  • BIG-IP
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K06522058

Description

FAST deployment fails with the following error in /var/log/ltm:

err mcpd[XXXX]: 0107176c:3: Invalid Virtual Address, the IP address x.x.x.x already exists.

Environment

  • BIG-IP
  • FAST application deployment using AS3

Cause

Stale configuration of AS3 application stored in ltm data-groups but no longer deployed as an application on the BIG-IP.

Recommended Actions

  1. Retrieve the entire AS3 declaration stored on the BIG-IP
# curl -ksu admin:<your admin password> https://<your management IP>/mgmt/shared/appsvcs/declare > /var/tmp/as3.json
  1. Identify the partition/ tenant that has the conflicting IP address declared.
  2. Create a copy of /var/tmp/as3.json and delete the application with the conflicting IP address from the copy
  3. Use AS3 "POSTing to a specific tenant" to update the target tenant to bring it in sync with the deployments as per the related article.
