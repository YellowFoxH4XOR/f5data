Topic

The FirePass dynamic policy engine allows you to configure FirePass so that it will clean up (remove) information that is generated as part of a remote access session to a corporate network through the FirePass server. If you configure FirePass to use the cache cleanup feature, FirePass will remove cached information when the client uses the Logout button to close the FirePass session, or when the client closes the applicable browser windows to close the FirePass session.

The cache cleanup feature does not remove OPSWAT components and locked ActiveX components. ActiveX components are locked when the f5wininfo.exe utility is running or when ActiveX is loaded in the user's browser. The OPSWAT and ActiveX components that are not removed by the cache cleaner can be removed manually through the user's Control Panel.

Administration options

To view the cache cleanup options, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Click Users.
  3. Expand the Endpoint Security tree.
  4. Click on Post-Logon Actions.
  5. Select the Inject ActiveX/Plugin to to clean-up client browser web cache check box.

    The following policy options will display:

    Note: FirePass only allows you to configure these cache cleanup options on a global basis; you cannot configure them on a group-by-group basis.

    FirePass controller side cache clean up options Description
    Require cache cleanup ActiveX/Plugin to be loaded to allow attachment downloads in Mobile E-Mail and downloads via Web Applications.
    		Requires that web application and mobile email users have the cache cleaner control installed and running on the client workstation to allow attachment downloads and view non-HTML data.
    Require cache cleanup ActiveX/Plugin to be loaded to allow file downloads in Window files
    		Requires that the cache cleanup control be loaded and running on the client workstation to allow file downloads in Windows files. If not loaded, the client can only download zip files.
    Force FirePass 1000session termination if the browser or webtop is closed
    		Ends any session where the user closes the web browser or navigates outside of the webtop without logging out.
    Inherit caching policy settings from Portal Access Web Applications configuration.
    		The FirePass Controller uses the caching and compression settings configured at the Portal Access: Web Application: Caching and Compression screen to define the caching policy for the client Web browser.

    Important: The caching and compression policy is configured globally.


    Client-side cache cleanup options Description
    Uninstall FirePass controller client components
    		Removes all client controls when the user disconnects from the FirePass or closes their web browser.
    Uninstall FirePass 1000ActiveX components
    		Uninstalls ActiveX® components from the client at the end of the session.

    Note:     If you configure Network Access to remove ActiveX® components, the FirePass 1000 controller must reinstall them for each new Network Access session.
    Remove dial-up entries used by Network Access Client
    		Removes dial-up entries (network connection information) used by client at the end of each session.
    Empty Recycle Bin.Empties the remote systems recycle bin at the end of the session.
    Clean forms and passwords autocomplete data
    		Removes entries in Internet Explorer forms and passwords autocomplete database that were created or modified during user's session.

    Note    : If the user changes a field whose cached name is already present in the autocomplete file, the previously saved entry is also removed. This is due to an Internet Explorer cache design feature.
    Close Google Desktop Search
    		Closes the clients Google Desktop search.

Client installation

After login, FirePass immediately notifies the client that an ActiveX control is being installed. FirePass will enforce only the server-side security policies options if the user cannot install the ActiveX control (because they are using a non-Windows operating system, a browser that does not support ActiveX, or because their site security policy does not allows ActiveX controls).

Client activation

The cache cleanup routine remains active in the memory of client PC and is activated under the following conditions:

  • User logs off the FirePass server
  • User session times out
  • User closes the browser or browser crashes
  • The Force Session Timeout option is selected
  • A force re-authentication event occurs
  • User powers off the computer or the client's system is rebooted

Client execution

The cache cleanup feature removes and overwrites with zeros the following data from the client PC:

  • Cookies associated with the FirePass URL
  • History of FirePass URLs
  • URL auto-complete information
  • Browser cache during the time period of the remote access session
  • Temporary Internet files from default directory (from the time that the user logs into FirePass until the time that the cleanup control runs)

If the system was rebooted before the cache cleanup control executed, then the following data is removed from the client PC:

  • Cookies associated with the FirePass URL
  • History of FirePass URLs
  • Browser cache tied to FirePass URL
