Description

Upgrade process failed, with the following messages, under: /var/log/liveinstall.log:

Installing update to 15.1.2.1 fails. The message in /var/log/liveinstall.log:
info: mysqldump: Error: &#39;Disk full (/var/tmp/#sql_60e3_2); waiting for someone to free some space...&#39; when trying to dump tablespaces
info: mysqldump: Couldn&#39;t execute &#39;show fields from `parameter`&#39;: Disk full (/var/tmp/#sql_60e3_0); waiting for someone to free some space... (1021)
info: tar: /var/tmp/im18999/configsync-2.0-1-Linux-3.10.0862.14.4.7.8664.im: Wrote only 6144 of 10240 bytes
info: tar: Error is not recoverable: exiting now
info: Fatal: executing: tar --no-recursion -rf /var/tmp/im18999/configsync-2.0-1-Linux-3.10.0862.14.4.7.8664.im --no-unquote --files-from=/var/tmp/im.8769/Files
info: Operation aborted.
info: /var/tmp/configsync.spec: Error creating package

Error message broadcast on console:

011d0004:3: Disk partition /shared has only 1% free

Environment

  • /shared directory has no free disk space

Cause

During the upgrade process, the system use  /shared/ directory.
Without having enough disk space the upgrade process will fail. 

Recommended Actions

  1. Follow the article K15485103: Disk partition shared has only 1% free
  2. Check if there are old and unnecessary files: Qkview/UCS/images which can be deleted (or move those aside)

Additional Information

None.
