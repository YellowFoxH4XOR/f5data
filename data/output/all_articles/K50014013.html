Description

You can upload text files with custom signatures via Security > Protocol Security > Inspection List > Upload Signature. However the file upload fails if the uploaded text file contains Windows-style CRLF line feeds.

Environment

  • A custom signature file created with a text editor that uses Windows-style CRLF line feeds.

Cause

The text file uploaded will fail validation with a "Unable to upload file" message if its line feeds are provided by CR+LF (Carriage Return plus Line Feed), which is standard for Windows text editors like Notepad. The text file will pass validation if Linux-style LF (only) line feeds are used.

Recommended Actions

Use a text editor that does not use the CRLF sequence for newlines, such as the nano or vim text editor on the BIG-IP system. There are various ways of stripping CR characters from Windows-derived text files. There is no issue uploading a file so stripped from any client. The CRLF is introduced only by editing with common Windows text editors. You could create the file on the BIG-IP system using the nano or vim text editor, download it to your Windows workstation and then upload it to the BIG-IP system using the Configuration utility.
