Description

 

Customer is seeing error displayed on GUI when accessing the traffic-group page which prevents them from making any changes.

 

Environment

 

You are unable to open the Device Management > Overview and the Device Management > Traffic Groups page or make changes to traffic groups in the GUI.

 

Cause

You receive the following error in the configuration utility:

 

{"method"."GET","transformRequest".[null],"transformResponse":[null],"url"."/mgmt/tm/cm/traffic-group/~Common~traffic-group-1","params":{expandSubcollections":true},"headers":{:"Accept:."application/json, text/plain, */*"}}

 

Recommended Actions

 

Attempt to restart the following daemons from the CLI to see if the error is resolved:

 

Impact of Procedure: This command will make the configuration utility unavailable until the BIG-IP finishes restarting httpd/tomcat daemons. Restarting restjavad will limit REST API access to the device while the daemon restarts. You can refresh the configuration utility in the browser if it doesn't come back up within a couple minutes to regain access.

 

bigstart restart httpd tomcat restjavad

 

If this does not resolve the issue then complete the following procedure: Forcing the mcpd process to reload the BIG-IP configuration
