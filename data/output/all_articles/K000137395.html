Description

You would like to download the iControl.jar file from your BIG-IP device.

Environment

  • BIG-IP
  • iControl.jar file

Cause

None

Recommended Actions

The iControl.jar file is located on the BIG-IP in the /usr/share/java directory.

/usr/share/java/iControl.jar

You can copy the file from the BIG-IP device using the SCP (Secure Copy Protocol):

scp /usr/share/java/iControl.jar <user name>@<ip-addess of remote device>:<path on remote device>

Example scp command:
scp /usr/share/java/iControl.jar bob@10.0.0.10:/home/bob
