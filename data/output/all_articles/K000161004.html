Description

On F5OS appliances, system event logs may display messages indicating that an FPGA firmware "update" is occurring during every reboot. This can cause confusion, as the logs may be interpreted as evidence that a firmware upgrade is being performed each time the system restarts.

The event log entries typically state "Firmware update is running" or "Firmware update completed" for various FPGA components (e.g., atse 1, nso 0, asw 0). This terminology can lead to misunderstandings, with the belief that frequent firmware upgrades are taking place or that these updates are related to unexpected reboots.

Example log messages in event logs:

65550 appliance firmware-update-status EVENT NA "Firmware update completed for atse 1" ...

65550 appliance firmware-update-status EVENT NA "Firmware update is running for nso 0" ...

Similar entries are found in PEL logs, often using the abbreviation "FWU".

 

Example log messages in platform logs:

platform-mgr[13]: priority="Info" version=1.0 msgid=0x103000000000016 msg=
  Platform-mgr all system firmware components up to date, no update required.
platform-mgr[13]: priority="Info" version=1.0 msgid=0x103000000000017 msg=
  Platform-mgr system firmware update complete slot=1.

Note the first line contradicts the second line.

 

Environment

  • Product: F5OS
  • Version: 1.x
  • Affected components: FPGA (atse, nso, asw)
  • Event logs and PEL logs generated during appliance boot/reboot

Cause

Bug ID 2290273

Answer/Recommended Actions

  • The "Firmware update" messages in the event logs do not indicate that a firmware upgrade is being performed during every reboot.
  • These messages refer to the process of loading the existing .bin firmware image into the FPGA hardware at boot time, which is standard behaviour for field-programmable devices.
  • No action is required from administrators when these messages appear during normal boot or reboot cycles.
  • If you are concerned about unexpected reboots or suspect other issues, review additional system logs for unrelated hardware or software errors.
  • F5 is aware of the confusion caused by the current log wording and has filed Bug ID 2290273 to address this. A future update may revise the log messages to use "loading" instead of "updating" for clarity.

Additional Information

  • The process described in the logs is expected and does not indicate a problem with the appliance or its firmware.
  • The abbreviation "FWU" in PEL logs may also refer to this firmware loading process.
