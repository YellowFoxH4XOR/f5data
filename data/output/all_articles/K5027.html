K5027: Removing a 3-DNS Controller or BIG-IP Link Controller from a synchronization group

Topic

You can remove a 3-DNS Controller or Link Controller from a sync group through the command line or the Configuration utility.

Important: When removing an object from a sync group, the change should be made from the principal 3-DNS Controller.

Note: If a Link Controller is a member of a 3-DNS sync group, it was added to the 3-DNS configuration as a 3-DNS Controller. In the following procedures, 3-DNS Controllers and Link Controllers will be referenced as 3-DNS Controller.

Command line

To remove a 3-DNS Controller from a sync group through the command line, perform the following steps:

  1. Log in to the command line.
  2. Edit the /config/3dns/etc/wideip.conf file.
  3. Locate the section of the file that begins with sync_group {.

    Sync groups are listed in the following format:

        name   "<name>"
    3dns   "<member>"
    3dns   "<member>"
    3dns   ...

    Note: The first line indicates the principal 3-DNS Controller of the sync group. If you have a Link Controller in the sync group, the Link Controller can be only a receiver member; it can never be the principal member.

  4. Locate the name of the sync group that you wish to modify.
  5. Delete the 3dns line that specifies the 3-DNS Controller you wish to remove.
  6. Save the file and exit the editor.
  7. Apply the configuration change, by typing the following command:
        3ndc restart

Configuration utility

To remove a 3-DNS Controller from a sync group through the Configuration utility, perform the following steps:

  1. Log in to the Configuration utility.
  2. In the main navigation pane, select 3-DNS Sync.
  3. Locate the sync group that you wish to change.
  4. Locate the 3-DNS Controller that you wish to remove.
  5. In the Remove column, click the Remove button associated with the 3-DNS Controller you wish to remove.
  6. Click the OK button.
