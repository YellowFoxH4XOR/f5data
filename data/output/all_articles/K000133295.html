K000133295: Outlook Web Access (OWA) with APM Portal access - Modern or Legacy rewriting?

Type
Support Solution
Published
2023-03-31
Updated
2023-04-22
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000133295

Description

After deploying a fix for Modern Javascript rewriting support (BUG ID 957453 ) via an Engineering Hotfix or a software upgrade, users accessing Outlook Web Access (OWA) through Portal Access are reporting errors.

 

Environment

  • Portal Access
  • Outlook Web Access
  • Modern Javascript rewriting support (ID 957453) is implemented

 

Cause

Portal Access with Modern Javascript rewriting does not correctly rewrite the OWA web application

 

Recommended Actions

Edit the Rewrite Control List (RCL) to exclude the OWA web application host from Modern rewriting and use Legacy rewriting instead.

 

 

Additional Information

See K000130439 for additional information on how to implement RCL entries.
