Description
You may want to configure the BIG-IP system to only send audit logs to a remote syslog server, but not other system logs.

The structure of an audit log entry is as follows:

<time stamp> <host name> <level> <service[pid]> <message code> <user> <event>

For example,

May 18 13:11:32 bigip.local notice tmsh[20740]: 01420002:5: AUDIT - pid=20740 user=root folder=/ module=(tmos)# status=[Command OK] cmd_data=list cm device recursive

Environment

  • BIG-IP audit logs
  • Remote syslog

Cause
By default, the audit logs are logged to /var/log/audit. If you configure remote syslog servers using the steps in K13080: Configuring the BIG-IP system to log to a remote syslog server then all system log sources will be sent remotely.

Recommended Actions

  1. Log in to tmsh by typing the following command:
        tmsh
     
  2. To edit the syslog configuration type the following command:
        edit /sys syslog all-properties

        The syslog configuration opens in the vi text editor and appears similar to the following example:

        modify syslog {
            auth-priv-from notice
            auth-priv-to emerg
            cron-from warning
            cron-to emerg
            daemon-from notice
            daemon-to emerg
            description none
            include none
            iso-date disabled
            kern-from notice
            kern-to emerg
            mail-from notice
            mail-to emerg
            messages-from notice
            messages-to warning
            remote-servers none
            user-log-from notice
            user-log-to emerg
        }
     
  3.  Replace the include none line with the desired syslog filter. For example, to configure syslog-ng to log debug through emergency log level messages to UDP port 514 on destination hosts 192.168.1.1 and 192.168.1.2, use the following syntax:
    Note: It likely won't be necessary, but if you want to restrict the log level being sent, add the level parameter in the filter object. For examples refer to K13333: Filtering log messages sent to remote syslog servers.

        include "
            filter f_audit{
                match(AUDIT);
            };
            destination d_syslog_server {
                    udp(\"192.168.1.1\" port (514));
                    udp(\"192.168.1.2\" port (514));
            };
            log {
                    source(s_syslog_pipe);
                        filter(f_audit);
                        destination(d_syslog_server);
            };
            "
  4. Exit the text editor by typing the following key sequence:
        :wq!
     
  5. At the following prompt, type y to save the changes to the file:
        Save changes? (y/n/e)

        The tmsh utility prompt returns.

        Note: If the syslog filter contained syntax errors, the tmsh utility returns the following prompt:

        There were errors. Continue editing (y) or discard changes (n) (y/n)

        The BIG-IP system now sends syslog traffic to the remote server using the defined syslog filter.
     
  6. Save the configuration by typing the following command:
        save /sys config
