Known Issue

After a ConfigSync operation, custom media settings for all interfaces are lost on the BIG-IP system that receives the configuration changes. This issue occurs when all of the following conditions are met:

  • The peer BIG-IP system had configuration changes that were synchronized.
  • The BIG-IP system that receives the configuration changes has one or more interfaces that are configured with customized settings, such as State, Requested Media, Flow Control, and STP.

For example, a BIG-IP system has interface 2.1 configured with the following custom media settings:

net interface 2.1 {
mac-address 0:1:d7:e4:ea:c
media-max 1000T-FD
media-sfp 1000LX-FD
stp disabled
}

After a ConfigSync operation, this BIG-IP system that received the configuration changes now has interface 2.1, with the following configuration:

net interface 2.1 {
mac-address 0:1:d7:e4:ea:c
media-max 1000T-FD
}

Impact

Affected interfaces are unable to pass traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H372355 on the Diagnostics > Identified > High screen.
  • The BIG-IP system fails to pass traffic on affected VLANs.
  • The affected interface is reported as DOWN for its Availability in the Configuration utility.
  • The affected interface is reported as DOWN for its Status in the command line.
  • The affected interface has its configuration reverted to factory default. You can examine the interface configuration using the tmsh list /net interface <ifname> command. For example, you can examine the configuration of interface 2.1 by typing tmsh list /net interface 2.1 in the command line.
  • Messages that appear similar to the following example will be logged in the /var/log/ltm file of both member of the HA pair:

    01160011:6: Link 1/2.4 Actor Out of Sync
    01160012:6: Link 1/2.4 Partner Out of Sync

Workaround

For a BIG-IP system that has already encountered this issue, you can recover the BIG-IP system by reconfiguring the affected interface. To prevent the active unit from losing custom interface settings while passing traffic, avoid synchronizing to the active unit. If you must synchronize to the active system, affected interfaces will be unable to pass traffic until you re-apply custom interface settings on the active system. To reconfigure the affected interface, perform the following procedure:

Impact of workaround: Performing the procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Network > Interfaces > Interface List.
  3. Click the name of the affected interface.
  4. Configure the settings, as necessary.
  5. Click Update.
