Known Issue

This is the result of a known issue. In certain situations, the BIG-IP ASM stops enforcing attack signatures without providing any indication. This issue occurs after attack signatures are updated on a BIG-IP ASM system that contains multiple web applications, and each web application references a different set of attack signatures.

F5 Product Development tracked this issue as CR100160 and it was fixed in BIG-IP ASM 9.4.6. For information about upgrading, refer to the BIG-IP ASM Release Notes.

This issue has been fixed in Hotfix-BIG-IP-9.4.4-94.0-HF3, which has been issued for BIG-IP 9.4.4, and in Hotfix-BIG-IP-9.4.5-1086.1-HF2, which has been issued for 9.4.5. You may download these hotfixes or later versions of these hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.
