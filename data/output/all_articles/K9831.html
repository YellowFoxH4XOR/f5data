Known Issue

This is the result of a known issue. The bigpipe pva 0.0 command should display statistics for all traffic flowing through the PVA. However, when the bigpipe pva 0.0 command is performed from the command line, the counters all display 0 (zero).

For example:

# bigpipe pva 0.0
PVA traffic --
| client (cur, max, limit, tot) = (0, 0, 0, 0)
| client (pkts,bits) in = (0, 0), out = (0, 0)
| server (cur, max, limit, tot) = (0, 0, 0, 0)
| server (pkts,bits) in = (0, 0), out = (0, 0)
| assisted connections (curr, tot) = (0, 0)
| hardware SynCookies (generated, detected) = (0, 0)

F5 Networks Product Development tracked this issue as CR82189 and it was fixed in version 10.0.1. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, PSM, Link Controller, WebAccelerator, or WAN Optimization Module Release Notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.0.0-5460.0-HF1 issued for BIG-IP version 10.0.0, for the 10.x software branch. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
