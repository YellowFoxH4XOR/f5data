K000148247: IPv4 virtual address kernel routes disappear after changing icmp echo setting

Type
Support Solution
Published
2024-11-14
Updated
2026-08-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148247

Description

When making changes to virtual address using Terraform bigip_ltm_virtual_address module, virtual address mask  changes to /128 regardless of any modification apply to virtual address.

For example, changing the icmp-echo value from enabled to selective using Terraform, the mask value changed from 255.255.255.255 to ffff:ffff:ffff:ffff:ffff:ffff:ffff:ffff.

Environment

Terraform Provider BIG-IP v1.22.3

Cause

ID1677113

Recommended Actions

ID1677113 is fixed in Terraform Provider BIG-IP v1.22.5
