K000148922: superuser role require admin or Resource Admin role to run f5sh or ConfD CLI

Type
Support Solution
Published
2025-01-15
Updated
2025-11-12
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000148922

Description

The superuser is a new secondary role that allows existing users with access to ConfD to also get bash access. The feature is added in F5OS-A 1.8.0.
This document describes required roles to get access to Confd or f5sh.

Environment

F5OS-A 1.8.0

Cause

The definition of superuser role is following.

  • Sudo privileges and Bash access to the system(if enabled)

The superuser role does not have role to get access to Confd or f5sh.

The superuser can get ConfD or run f5sh without admin role or Resource Admin role, however, the superuser will not be able to read and edit configuration.

Recommended Actions

To get read and/or edit access to Confd or f5sh, add appropriate role to superuser as a secondary role.

The feature is available via CLI only in F5OS-A 1.8.0. GUI does not show superuser role as a secondary role.

To add superuser role to a user

1. Log into F5OS command line as root user.
2. Type f5sh, press Enter
3. Type config terminal, press Enter
4. Use the following command syntax to add superuser role to a user.

system aaa authentication roles role superuser config users [username]

Following example add superuser role to existing admin user named spuser.

appliance-1(config)# system aaa authentication roles role superuser config users spuser
appliance-1(config-role-superuser)# commit
Commit complete.

Relevant running configuration is following.

system aaa authentication users user spuser
 config username spuser
 config last-change 0
 config tally-count 0
 config role   admin
 config expiry-status enabled
