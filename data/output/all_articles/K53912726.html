Known Issue

The HTTP::cookie expires iRule command may fail to run.

This issue occurs when the following condition is met:

  • You set the cookie expiration time to 0 using the HTTP::cookie command in a server-side iRule. For example, the iRule uses HTTP::cookie expires 0 in an HTTP_RESPONSE server-side event.

Impact

On the client-side, the iRule command fails to set the expire time on the cookie

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the iRule HTTP::cookie expires command is invoked, messages similar to the following example are logged to the /var/log/ltm file:

    err tmm1[12345]: 01220001:3: TCL error: /Common/test-irule <HTTP_RESPONSE> - Illegal argument. Internal error - NULL argument (line 1)     invoked from within "HTTP::cookie expires <cookie-name> 0 absolute"

Workaround

To work around this issue, you can use iRule HTTP::cookie attribute command to set the cookie expiration value to 0. You may need to calculate the time-stamps for relative or absolute timestamps corresponding to zero. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Local Traffic > iRule > iRule List.
  3. Select the iRule you want to modify.
  4. To set the cookie expiration time to zero using the relative or absolute time-stamp, locate and replace the relevant HTTP::cookie command with the following command syntax:

    HTTP::cookie attribute <name> value "expires" <time-stamp>

    For example, the following iRule command is used to set absolute time-stamp for cookie1 expiration to zero:

    when HTTP_RESPONSE {
           if { [ info exists clear_alert_guid ] } {
                    HTTP::cookie insert name  test-cookie value "" path "/"
                    HTTP::cookie attribute cookie1 value "expires" "Thu, 01-Jan-1970 00:00:00 GMT"
                    unset clear_alert_guid
            }

    }

  5. Click Update.
