Known Issue

When an authentication, authorization, and accounting (AAA) server password or shared secret is created or modified through the Traffic Management Shell (tmsh) or an iApp template, the password is stored unencrypted.

Impact

Passwords are exposed as plain text in configuration files.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Listing the AAA server configuration in tmsh displays the password in plain text

    For example:

    tmsh list apm aaa

  • Passwords are viewable in plain text in the bigip.conf file

Workaround

To work around this issue, you can edit the affected AAA server password through the Configuration utility. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > AAA Servers.
  3. Click the name of the AAA server you want to edit.
  4. For Admin Password, enter the password.
  5. For Verify Admin Password, re-enter the password.
  6. Click Update.
