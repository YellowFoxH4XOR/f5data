K14491: The ARX system uses only proxy IP addresses configured on the senior device for ARX 1500 or 2500 platforms joined in a high availability pair

Topic

Summary

When you join the ARX 1500 or 2500 platforms into a high availability (HA) pair (redundancy), the ARX system uses only the proxy IP addresses configured on the senior device.

The senior system is determined during the initial rendezvous of an ARX HA pair. For more information, refer to K9391: Determining the senior system during the initial rendezvous of an ARX high availability pair.

Description

ARX systems require you to configure proxy IP addresses for communicating to managed filers and servers. When you join legacy platforms into an HA pair, the pair uses the combined proxy IP addresses for network communication.

When you join the ARX 1500 or 2500 platforms into a high availability pair, the proxy IP addresses configured on the senior device will be the only proxy IPs used.

For example:

  • To show all configured proxy IPs, you would enter the show ip proxy-addresses command:

    show ip proxy-addresses
  • ARX-1 has proxy IP addresses 192.168.25.31 and 192.168.25.32.

    For example:

    Proxy Address VLAN Mac Address Owner In Use By Proc
    --------------------  ----  ----------------- ------- ----------- ----
    192.168.25.31/24 25 00:0a:49:17:b1:80 ARX-1 ARX-1 1.1
    192.168.25.32/24 25 00:0a:49:17:b1:81 ARX-1 ARX-1 1.2
  • ARX-2 has proxy IP addresses 192.168.25.33 and 192.168.25.34.

    For example:

    Proxy Address VLAN Mac Address Owner In Use By Proc
    -------------------  ----  ----------------- ------- ----------- ----
    192.168.25.33/24 25 00:0a:49:17:a1:80 ARX-2 ARX-2 1.1
    192.168.25.34/24 25 00:0a:49:17:a1:81 ARX-2 ARX-2 1.2
  • When configured as standalone devices, the proxy IP addresses from ARX-1 and ARX-2 may be used for network communication.
  • When you join the ARX devices into an HA pair, ARX-1 will become the senior device, ARX-2 will become the secondary device, and both devices will combine the proxy IP addresses.

    For example:

    Proxy Address VLAN Mac Address Owner In Use By Proc
    -------------------  ----  ----------------- ------- ----------- ----
    192.168.25.31/24 74 00:0a:49:17:b1:80 ARX-1 ARX-1 1.2
    192.168.25.32/24 74 00:0a:49:17:b1:81 ARX-1 ARX-1 1.3
    192.168.25.33/24    00:0a:49:17:a1:80 ARX-2 ARX-1 1.2
    192.168.25.34/24    00:0a:49:17:a1:81 ARX-2 ARX-1 1.3
  • Once the rendezvous completes, the proxy IP addresses from ARX-1 (192.168.25.31 and 192.168.25.32) will be used. The proxy IP addresses from ARX-2 will still be part of the configuration and display in the show ip proxy-address command, but will no longer be used for network communication for the lifetime of the HA pair.
  • Changing the active system (ARX-1 or ARX-2) will not change the proxy IP addresses and the devices will continue to use the 192.168.25.31 and 192.168.25.32 IP addresses.
