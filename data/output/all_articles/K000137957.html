Description

Installing a BIG-IP iso to a volume results in "waiting for product image"


Environment

BIG-IP

Cause

Unknown

Recommended Actions

1. First, completely delete the volume you are trying to install the hotfix to and retry the installation cleanly (if you previously installed over the top of an existing volume). This can be done through the gui or the CLI - instructions at https://my.f5.com/manage/s/article/K33265170


2. If this does not resolve the issue the next step is to reload the binary mcpd database *NOTE* this will require a complete reboot of the machine in addition to a roughly ~15 minute time for the rebuild - instructions are at https://my.f5.com/manage/s/article/K13030
