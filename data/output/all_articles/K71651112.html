Description

After upgrade to 14.1.2, named daemon keeps restarting with the following message:

logger[31870]: Re-starting named

Rollback to the previous version is required.

Environment

  • LTM 14.1.2
  • Appliance

Cause

For some unknown reason, permission value for 'named.conf' file is incorrect after an upgrade. 

Recommended Actions

  • The named daemon restarts constantly which obstructs using the CLI
  • To workaround this you can use a one-line command that can be easily and quickly pasted into the CLI:

mv /var/named/config/named.conf /var/named/config/named_bak.conf; touch /var/named/config/named.conf; cp -n  /var/named/config/named_bak.conf /var/named/config/named.conf; bigstart stop named; bigstart start named
