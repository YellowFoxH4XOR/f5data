Description:

You wonder if you can mitigate CVE-2023-36884 & CVE-2023-38180 using asm signatures


Environment:

ASM or Advanced WAF


Cause:

None


Recommended Actions:

CVE-2023-36884 vulnerability involves crafting of Microsoft Office documents to execute the remote codes. Victim has to download and open a crafted document which is malicious file. BIG-IP is not an anti-virus system and cannot prevent against such attacks without icap integration.


CVE-2023-38180 is affecting Microsoft .NET & Visual Studio. The vulnerability allows for a denial-of-service attack. However because the details of the flaw have not been publicly disclosed (on 29th August 2023), it is not possible to provide a signature (or tell whether it can be prevent with existing signatures).
