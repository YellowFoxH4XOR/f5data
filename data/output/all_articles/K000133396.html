Description

  • You are not able to log into the BIG-IP system through an LDAP authentication

  • Username has a syntax like: "-user" (with dash or any other non-alphabetic character at the beginning)

  • Error messages can be found in /var/log/secure:

Jan 1 00:00:00 LTM1.example.com warning nslcd[4144]: [8b4567] <authc="-user"> request denied by validnames option

 

Environment

  • BIG-IP version 14.x or newer

Cause

Some special or non-alphabetic character are denied by nslcd username validation code, there is no workaround.

This behaviour was introduced in BIG-IP version 14.x when base operating system has been upgraded from CentOS 6.8 to 7.3.

 

 Recommended Actions

Change the username to start with alphabetic character.

 

Additional Information

None.
