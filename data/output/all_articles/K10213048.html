Known Issue

BIG-IP Edge Client may display grammatically incorrect text.

This issue occurs when all of the following conditions are met:

  • Your device uses French as the primary language.
  • Your device has BIG-IP Edge Client software installed.
  • You attempt to initiate an access session using BIG-IP Edge Client.

Impact

You can safely ignore this issue. The French language message text that BIG-IP Edge Client displays may be grammatically incorrect.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP Edge Client displays grammatically incorrect French for the auto-connect button.
  • BIG-IP Edge Client messages are displayed using a combination of French and English text.
