K66015050: Manual installation of Browser Challenges is stuck for several hours

Type
Support Solution
Published
2021-10-09
Updated
2023-02-21
Applies to
  • BIG-IP
  • Virtual Editions
  • BIG-IP ASM: 16.1.X, 16.0.X, 16.1.3, 16.1.2, 16.1.1, 16.X.X, 16.0.1, 16.0.0, 16.1.0
Source
https://my.f5.com/manage/s/article/K66015050

Description

Browser Challenges was downloaded from F5 downloads site and uploaded manually under System  ››  Software Management : Live Update

  • The install progress is in stuck state for a very long time (several hours).
  • There is no way to stop the progress.
  • This prevents us from re-installing (without a reboot).

Environment

  • BIG-IP ASM
  • Manual install of signatures

Cause

The cause is unknown at the time of article creation.

Recommended Actions
Perform the following workaround to stop the progress without a complete reboot.

  1. Reboot the tomcat daemon using the command below:
    # bigstart restart tomcat
     
  2. After the restart, re-upload the signatures and re-install them. It should be successful.
Note: Restarting tomcat will not affect the traffic, it will only affect Web GUI for minutes at the most.
