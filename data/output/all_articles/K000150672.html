K000150672: BIG-IP DNS (GTM) is not showing up when connected from other DNS devices

Description

A BIG-IP DNS (GTM) is showing offline on other DNS devices in the group. Meanwhile, another DNS device, which is the LTM pair, does show up.

Environment

The two DNS devices which are LTM HA pairs, are added as separate GSLB Server objects.

For example, if you have mybigip1 and mybigip2 as an LTM HA pair, this would look similar to the following in /config/bigip_gtm.conf file:

gtm server /Common/mybigip1 {
  datacenter /Common/my_dc
  devices {
    mybigip1{
      addresses {
        10.123.123.123 { }
--snip--
gtm server /Common/mybigip2 {
  datacenter /Common/my_dc
  devices {
    mybigip2{
      addresses {
        10.123.123.124 { }

Cause

By design, the mcpd daemon of the Standby LTM device would not give a response when being probed for the status of the Virtual Servers on that device. This in turn causes big3d to not respond to bigip monitor probe requests.

Recommended Actions

An LTM HA pair need to be added as one single GSLB Server object, with each Active and Standby as separate Device object under it.

It should look similar to the following in /config/bigip_gtm.conf file:

gtm server /Common/mybigip {
  datacenter /Common/my_dc
  devices {
    mybigip1{
      addresses {
        10.123.123.123 { }
--snip--
    mybigip2{
      addresses {
        10.123.123.124 { }
