Security Advisory Description

The BIG-IP system logs the device password in plaintext. This issue occurs when the following condition is met:

  • There are one or more syntax errors in the POST body of a REST token request.

Impact

Disclosure of the BIG-IP system's device password can lead to other exploits.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/restjavad.0.log file, the BIG-IP system logs the plaintext password in a message similar to the following example:

    [RestOperation] getBody could not deserialize to Json, input '{"username": "example_username", "password": "example_password", "loginProviderName: tmos"}'
