Known Issue

This is the result of a known issue. Network Associates' McAfee VirusScan 8.5 may not be detected by the Personal FireWalls/AntiVirus Checks feature, on the Policy Checks tab of the Network Access: Resources page. Detection fails if you specify an engine version in the Scan Engine Version field.

When VirusScan is not correctly detected, the Network Access client displays the following message:

Status: FirePass Security policy prevents Network Access connection from running on this PC. Please contact your system administrator.

VirusScan 8.5 uses a different set of registry key values with different data types from previous versions to store the anti-virus engine version. The 8.5 version uses the value name EngineVersionMajor, which is of type REG_DWORD (4-byte binary data), under the following key:

HKEY_LOCAL_MACHINE\SOFTWARE\McAfee\AVEngine

The older versions use the value name szEngineVer, which is of type REG_SZ (text string data), under the following key:

HKEY_LOCAL_MACHINE\SOFTWARE\Network Associates\TVD\Shared Components\VirusScan Engine\4.0.xx

Because of the change of type, any specification in the Scan Engine Version field causes the Network Access Policy Check to fail.

F5 Product Development tracked this issue as ID 279854 (formerly CR83053), and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in Cumulative Hotfix HF-552-11 issued for FirePass version 5.5.2 and Cumulative Hotfix HF-601-5 issued for FirePass version 6.0.1. You may download these hotfixes or later versions of the Cumulative Hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

To work around this issue, you can use Check system registry instead of the Personal FireWalls/AntiVirus Checks to detect the correct McAfee scan engine version. In the Check system registry field, enter the expression to check the value of the scan engine. For example, if your scan engine version for VirusScan 8.5 is 5200, you would enter the following to check that the version is equal to 5200 or greater:

"HKEY_LOCAL_MACHINE\SOFTWARE\McAfee\AVEngine"."EngineVersionMajor" >= "5200"

Note: Scan engine versions numbers do not map uniquely to software version numbers. For example, both VirusScan 8.0 and 8.5 can have the same scan engine number.

Note: In versions of FirePass software prior to 5.4, the Policy Checks tab is located on the Network Access: Group-based Settings page.
