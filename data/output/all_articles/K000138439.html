K000138439: F5OS-A 25G interface Set up with Cisco Nexus switch

Type
Support Solution
Published
2024-02-14
Updated
2025-06-17
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000138439

Description

You need to connect a F5OS-A 25G interface between F5OS-A device and Cisco Nexus Switch

Environment

  • F5OS-A
  • 25Gb F5OS-A interface
  • FEC

 

Cause

F5OS-A devices only support RS FEC IEEE on 25G interfaces

 

Recommended Actions

If you need to setup a link between a F5OS-A 25G interface of F5OS-A device and a Cisco Nexus Switch, you have to get configured the Cisco Nexus Switch interface with the FEC on IEEE mode otherwise the network interfaces (Link) will not come UP.
