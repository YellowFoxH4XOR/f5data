K000160909: Can non-default route domain be deleted without any impact

Description

You want to delete route domain that is no longer being used, in order to do that, you already deleted all the confugration objects that were assigned to this route domain.

Environment

  • BIG-IP

  • Route domains

Cause

You are concerned if deleting non-default route domain can have negative impact on traffic processing

Answer/Recommended Actions

If you deleted all the configuration objects assigned to specific route domain, there should be no negative impact.

BIG-IP would not allow you to delete route domain if some objects would still be present, you would receive an error similar to below ones:

01070635:3: The route-domain (/Common/test) is referenced by one or more self IPs.

0107097c:3: The specified route domain (1) is the default route domain for one or more partitions and cannot be deleted.

For additional safety, you can get UCS before removing route domain, which is generally good practice before applying any major changes.

If you would try deleting specific route domain, and it would fail, you should be able to track configuration objects that are not allowing you to delete it according to the error message
