Known Issue

This is the result of a known issue. On BIG-IP 8900 platforms, the following kernel messages will display on the console and log to the /var/log/kern.log file during system boot:

warning ********************************************************
warning * This system has more than 16 Gigabyte of memory.     *
warning * It is recommended that you read the release notes    *
warning * that accompany your copy of Red Hat Enterprise Linux *
warning * about the recommended kernel for such configurations *
warning ********************************************************

The warning message is benign and appears for systems with 16 gigabytes of RAM. Due to the way that the memory map is arranged, some of the RAM is addressed beyond the 16 gigabyte specification to make room for PCI devices. The kernel only looks at the physical memory addresses when it is determining whether to print its warning; when the kernel sees that some memory extends beyond 16 gigabytes, it prints the warning message.

F5 Product Development is tracking this issue as ID 334386 (formerly CR135521).
