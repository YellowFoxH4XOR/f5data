Description

After a failover, application connections are not working.

Environment

  • Failover

Cause

The switch connected to the BIG-IP is unable to cope with the amount of gratuitous ARPs issued by the BIG-IP system.

Recommended Actions

Verify the FDB on the switch to determine if the MAC addresses reflect those used by the active BIG-IP system.

If the switch is unable to cope with a high number of gratuitous ARP, consider use of the arp.gratuitousrate and arp.gratuitousburst database variables, which allow you to control the rate at which the BIG-IP issues gratuitous ARP.

Alternatively, consider using MAC masquerade, as this reduces the amount of unique MAC addresses that need to be learnt by a switch.

Refer to the below articles for more information:

  • K11985: Overview of the arp.gratuitousrate and arp.gratuitousburst database variables
  • K13502: Configuring MAC masquerade (11.x - 14.x)
