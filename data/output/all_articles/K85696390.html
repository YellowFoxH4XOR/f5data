Description

By default, the command "tmsh show running-config" displays configuration objects (Virtual Server, Monitors, Pool etc)  in the /Common partition only. To display objects in other partitions, you can use the commands in the Recommended Actions section.

Environment

  • BIG-IP with multiple partitions
  • For network admin task like grabbing the running-config and keeping change records 

Cause

  • Attempting to display configuration objects in a partition other than /Common

Recommended Actions

  • A manual command to show the running-config across all partitions could be achieved with the following command below:

    For example, you can use this command if your BIG-IP device configured with 6 partitions, but not for a different device with 3 partitions (especially if the partitions had a different name). Each BIG-IP device requires a unique command to show the configuration across all partitions.

    tmsh -c 'show running-config; cd /partition1; show running-config; cd /partition2; show running-config; cd /partition3; show running-config; cd /partition4; show running-config; cd /partition5; show running-config; cd /partition6; show running-config' > AllPartitions.out

 

  • To display running-configuration for all partitions including the /Common partition regardless of the names or number, you can use the following command:

    tmsh -q -c 'cd /;show running-config recursive'                        -- Output displays on the screen 

    tmsh -q -c 'cd /;show running-config recursive' > outputfile.txt       -- Output is redirected to a file
