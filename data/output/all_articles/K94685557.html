Known Issue

The PEM::session info $sub subscriber-id iRules command may fail to return a subscriber ID.

This issue occurs when all of the following conditions are met:

  • You are using a Remote Authentication Dial-in User Service (RADIUS) server.
  • The RADIUS discovery virtual server and the traffic listener virtual server are in different route domains.
  • You are using the PEM::session info $sub subscriber-id command to obtain a subscriber ID.

Impact

Querying the RADIUS server may fail or produce unexpected results.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The PEM::session info $sub subscriber-id command does not return the expected session info.
