K40224955: BIG-IQ isn't showing web application security events

Type
Support Solution
Published
2021-03-29
Updated
2023-10-16
Applies to
  • BIG-IQ
  • BIG-IP
  • BIG-IP ASM: 15.1.0
Source
https://my.f5.com/manage/s/article/K40224955

Description

  • BIG-IP is not sending events to BIG-IQ
  • No events are shown in Monitoring >> EVENTS >> Web Application Security >> Event Logs >> Events in the BIG-IQ
  • BIG-IQ shows the following message:
    List Empty
  • Security log profile configured on the BIG-IP pointing to BIG-IQ 
    For example:
security log profile /Common/example_remote_big-iq {
    application {
        /Common/example_remote_big-iq {
            filter {
                log-challenge-failure-requests {
                    values { disabled }
                }
                request-type {
                    values { all }
                }
            }
            local-storage disabled
            logger-type remote
            maximum-entry-length 64k
            remote-storage bigiq
            report-anomalies enabled
            report-challenge-failure-messages enabled
            servers {
                10.10.10.245:8514 { } <===================================== BIG-IQ DCD
            }
        }
    }
}

Environment

  • Web Application Security Event Logs
  • Remote Logging to BIG-IQ DCD

Cause

DCC on the BIG-IP wasn't adding the security log profile to the db, thus BIG-IP didn't know that it has to send event logs to the BIG-IQ.

Recommended Actions

  1. Check if the security log profile is added to the db with the following command: 
    # mysql -E -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "use DCC; select * from REMOTE_STORAGE_CONFIGURATION;"

  2. If it is not shown then restart dcc on the BIG-IP: 
    # pkill -f dcc

  3. Events should be seen in the BIG-IQ now.
