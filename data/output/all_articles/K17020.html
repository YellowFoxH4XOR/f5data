Known Issue

Under rare instances, the Traffic Management Microkernel (TMM) process may restart and produce a core file. This issue occurs when the following condition is met:

  • A connection flow is in an invalid TCP state.

Impact

The BIG-IP system temporarily fails to process traffic and fails over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H532742 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system generates a TMM core file to the /shared/core directory
  • The BIG-IP system generates a stack trace and panic string in the /var/log/tmm file similar to the following example:

    panic: Request for segment from middle of queue.

  • The BIG-IP system fails over to the standby system if configured as part of a high-availability system.
