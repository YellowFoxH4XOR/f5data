Description

If you encounter one or more of the following symptoms, you may have to verify if the website's certificate is trusted by SSL Orchestrator (SSLO) or Secure Web Gateway (SWG):
 

  1. Website is not accessible through SSLO/SWG
  2. Error logs in /var/log/ltm
    Dec 15 12:07:47 bigipsslo.loc warning tmm3[22184]: 01260006:4: Peer cert verify error: unable to get local issuer certificate (depth 1; cert /C=US/O=DigiCert Inc/CN=DigiCert TLS RSA SHA256 2020 CA1)
    Dec 15 12:07:47 bigipsslo.loc warning tmm3[22184]: 01260009:4: 10.2.154.10:443 -> 10.3.254.10:38834: Connection error: ssl_shim_vfycerterr:4447: alert(48) unable to get local issuer certificate

 

Environment

  • SSL Orchestrator

  • SWG
     

Cause

The certificate trust validation is done by SSLo/SWG . It might be using a ca-bundle not updated with intermediate/root CA used by the website having issue.

 

Recommended Actions

Use openssl cmd to verify the cert with ca-bundle configured in the ssl profile.

For that, first extract the cert pem file and then use openssl to verify against the ca-bundle configured.

#echo | openssl s_client -servername www.example.com -connect www.example.com:443 | sed -ne '/-BEGIN CERTIFICATE-/,/-END CERTIFICATE-/p' > example.pem

Verify if the site pem has been saved to file under example.pem. When you cat the pem file you should see the cert in PEM format.

Then verify it against the ca-bundle.

#openssl verify -CAfile /config/ssl/ssl.crt/ca-bundle.crt example.pem

Following error means the ca-bundle.crt doesn't have the intermediate/root CA in the ca-bundle.crt
 

[root@bigipsslo:Active:Standalone] ~ # openssl verify -CAfile /config/ssl/ssl.crt/ca-bundle.crt example.pem     
error 20 at 0 depth lookup:unable to get local issuer certificate


Proceed to update the ca-bundle and test again by the following K60612439: Manually updating the BIG-IP default CA certificate bundle file .


A successful testing will give a result like following:
 

#openssl verify -CAfile /config/ssl/ssl.crt/ca-bundle.crt example.pem            
example.pem: OK


 

Additional Information

SSL debug enabling will log the ssl errors in /var/log/ltm log file

#tmsh modify sys db log.ssl.level value debug
