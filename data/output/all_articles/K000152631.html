Description

When deploying BIG-IP and BIG-IQ VEs as a virtual machine on Proxmox 8.1.3, licensing may fail with the following error message:
Error 51133, F5 registration key is not compatible with the detected platform - This platform, "", cannot be activated …
This issue can occur during online, offline, or dossier-based licensing attempts.Environment

BIG-IP/BIG-IQ VE

Cause

Proxmox 8.1 and above changed the default QEMU SMBIOS entry point from version 2.x (32-bit) to version 3.0 (64-bit). The BIG-IP VE licensing process requires a VM to present a 32-bit SMBIOS entry point; if a 64-bit entry point is presented instead, the licensing process cannot detect the platform correctly and fails with error 51133.

Recommended Actions

To resolve this licensing issue:

  1. Shut down the BIG-IP VM in Proxmox.
  2. Edit the VM configuration file (typically located at /etc/pve/qemu-server/<VMID>.conf).Add).
  3. Add the following line to the configuration file: 
    args: -machine smbios-entry-point-type=32
  4. Save the file and restart the VM.
  5. Retry the licensing process.
