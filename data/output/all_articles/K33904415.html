Known Issue

The BIG-IP APM rewrite profile may incorrectly process the innerHTML property.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • You use the Google Chrome or Mozilla Firefox web browser.
  • The innerHTML property is invoked on a script or style tag.
For example:

var s=document.createElement("script");
var x="alerttest";
s.innerHTML=x;
document.head.appendChild(s);

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using the Chrome or Firefox web browsers, web applications malfunction or fail to render properly in browsers.
  • When you use portal access, requested pages that include the innerHTML property fail to display properly.
