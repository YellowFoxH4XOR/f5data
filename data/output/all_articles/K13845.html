Description

This article provides an overview of the supported upgrade path and related information to assist in planning for an upgrade to your BIG-IP software.

Important: This article is not a comprehensive guide to upgrading. For details about upgrading or updating BIG-IP software, refer to K84205182: Guide contents | BIG-IP update and upgrade guide.

Important: BIG-IP 15.1.x reached the EoL milestone on December 31, 2024. BIG-IP 16.1.x reached the End of Life (EoL) milestone on July 31, 2025. For more information, refer to K000139937: BIG-IP 15.1.x and 16.1.x reached End of Technical Support. For supported BIG-IP versions, refer to K5903: BIG-IP software support policy.

Recommended Actions

Choose the right release

Upgrade to a long-term stability release (x.1.0) whenever possible.

  • Long-term stability releases receive standard support for 5 years from the initial x.1.0 release date.
  • Major releases (x.0.0) only receive standard support for 15 months after their initial release.

If multiple long-term stability releases are available, select one that is 12 to 18 months past its initial release date to:

  • Reduce the number of maintenance actions needed earlier in the lifecycle.
  • Benefit from increased release maturity due to subsequent maintenance versions and hotfixes.

Refer to K9412: The BIG-IP release matrix for release date information.

Use an interim version, if needed

If the upgrade requires an interim version:

  • Ensure the interim version was released after the version you are upgrading from and before the version you are upgrading to.
    • For example, when upgrading from BIG-IP 11.6.5.3 to BIG-IP 14.1.4.6, use BIG-IP 12.1.6 as the interim version because it is between the two in release order.

Check release dates on F5 Downloads.

Important: Avoid upgrading to a version released earlier than your current version. Doing so may cause the configuration to fail to load because older versions lack the schema information required for newer configurations.

Check hardware and software support timelines

Review the End of Software Development (EoSD) dates for both your software release and hardware platform.

Confirm that the software release is compatible with your hardware using K9476: The F5 hardware/software compatibility matrix.

Stay current after upgrading

Apply subsequent hotfixes, maintenance versions, or point releases for your upgraded software as they become available.

  • Refer to K9502: BIG-IP hotfix and point release matrix to find the latest updates.

Be aware that F5 transitioned to a four-digit version format starting with BIG-IP 13.1.0.1 (released December 19, 2017):

  • For example, 13.1.0.1 replaces what used to be called 13.1.0 HF1.
  • Refer to K8986: F5 product support policies for definitions of major, minor, maintenance, and point releases.

Some security advisory status tables may still list both the old and new formats, depending on the affected BIG-IP versions.

Prepare your system

Verify the current health of your BIG-IP system by uploading a QKView diagnostic file to F5 iHealth.

Review the release information for the target version to identify known issues that could impact your configuration.

If you prefer not to carry forward your existing configuration, perform a clean installation instead.

Verify licensing and support

Ensure you have a valid F5 support contract before attempting to re-license the system after the upgrade.

Confirm compatibility

Check that the software release is fully compatible with your hardware platform. Refer to K9476: The F5 hardware/software compatibility matrix for guidance.

If you are upgrading a BIG-IP VE system, ensure the version you are upgrading to is within the permitted range for your product SKU. Refer to K42091606: Determine your BIG-IP VE SKU and permitted software version range.

Follow specific guidance for vCMP guests

If upgrading a vCMP guest running on VIPRION or BIG-IP appliance systems, follow the applicable upgrade instructions:

  • Use K14166297: Upgrade BIG-IP VIPRION systems (vCMP) for VIPRION systems.
  • Use K75476930: Upgrade BIG-IP appliance systems (vCMP) for appliance systems.
