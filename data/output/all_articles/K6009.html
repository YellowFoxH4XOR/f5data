If you need to provide a diagnostic dataset to F5 Technical Support and the web-based FirePass Administrative Console is inaccessible, you can use a serial connection to obtain a dataset from the FirePass Maintenance Console.

Note: The following steps assume that you are using the Microsoft Windows HyperTerminal program in order to connect to your Maintenance Console. If you use a terminal emulation program other than HyperTerminal, the Hyperterminal menu items referenced in Steps 10 through 11 may not be valid for your program. Consult the documentation for your terminal emulation program, if needed.

To obtain a dataset from the Maintenance Console, perform the following procedure:

  1. Connect a PC to the serial console port of the FirePass controller using a null-modem cable.

    Important: A null-modem cable is required for the serial connection. Other types of cables such as crossover or rollover cables will not work.

  2. Open a HyperTerminal session using the following settings:

    • Baud rate: 19200
    • Data bits: 8
    • Parity: none
    • Stop bits: 1
    • Flow control: hardware

    A login prompt displays.

  3. At the login prompt, type maintenance.

    A password is not required, by default.

    A conditions of use screen appears.

  4. Type y or press the Enter key to agree to the conditions.

    An options screen appears appears.

  5. If you are running FirePass version 6.x, Select 6 - Diagnostics by typing 6 and pressing the Enter key.

    If you are running FirePass version 5.x, Select 8 - Diagnostics by typing 8 and pressing the Enter key.

  6. Select 5 - F5 Support Diagnostic Tool by typing 5 and pressing the Enter key.

  7. Select 1 - Capture new dataset by typing 1 and pressing the Enter key.

    The option may also appear as Capture new dataset (replaces existing one) if a previous dataset has been captured through the Maintenance Console.

    The diagnostic programs will begin running. A progress bar indicates the percentage of the completed data collection.

  8. Once the diagnostics are complete, press the Enter key to return to the menu.

  9. Select 3 - Send existing dataset via Zmodem by typing 3 and pressing the Enter key.

    Depending on your Hyperterminal configuration, the Zmodem transfer may begin automatically. If not, proceed to step 10.

  10. From the Hyperterminal toolbar, select Transfer->Receive File.

    The Receive File dialog box appears.

  11. Select a location to save the file, and select Zmodem as the receiving protocol.

    The transfer should begin.

When complete, the dataset should be available at the location you selected in Step 11.
