K46987248: Cannot access the BIG-IP configuration utility because the tomcat process can't start

Description
Tomcat process may not start if the /var directory is 100% full.

  • You may see error such as: err diskmonitor[13331]: 011d0004:3: Disk partition /var (slot 3) has only 0% free
  • The configuration utility will fail to load


By checking hard disk space using below command, you will see the following: 

# df -h
Filesystem                            1K-blocks       Used          Available       Use%         Mounted on
/dev/mapper/vg--db--vda-set.2._var    3096336        3069004          0              100%          /var

Environment

  • BIGIP 
  • VCMP 
  • Var Directory 
  • Configuration utility

Cause
The /var directory is full.  

Recommended Actions

Impact of procedure: The Configuration utility is temporarily unavailable while the tomcat service restarts.
  1. Use the following command to check large files in /var directory and delete unnecessary files   e.g. ucs files etc...
    # find /var -xdev -type f -exec du {} \; | sort -rn | head -20
     
  2. Restart tomcat service by using this command
    # bigstart restart tomcat
