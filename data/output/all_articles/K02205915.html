Issue

Error Message

Unable to execute transaction because of: 01020036:3: The requested user role partition (admin Common) was not found.

Message Location

You may encounter this message in the following location:

  • The Visual Policy Editor (VPE) in the Configuration utility
Description

This message may occur when the following condition is met:

  • You attempt to edit the Subroutine settings of a per-request policy in the VPE.

Impact

The Subroutine settings of a per-request policy cannot be edited.

Recommended Actions

This is a known issue. For more information, and to determine if the issue is resolved, refer to Bug ID 726895.
