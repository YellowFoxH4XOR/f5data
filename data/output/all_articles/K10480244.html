Issue

Error Message

err pfmand[<PID>]: 01660004:3: <SR-IOV physical interface communication error message>

In this error message, note the following:

  • <PID> is the process ID for the pfmand process
  • <SR-IOV physical interface communication error message> is the error message specific to the SR-IOV interface experiencing the problem

For example:

err pfmand[5759]: 01660004:3: Copper interface in port:4.0 did not respond
err pfmand[5759]: 01660004:3: failed to read MARVELL_PHY_STATUS_REG port:4.0
err pfmand[5759]: 01660004:3: 4.0: failed to write 0x56 to register 0x11 to select pageAC rv:-1

err pfmand[7485]: 01660004:3: pflib_set_nic_media failed.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The pfmand device monitor has lost a connection to the mcpd process.

The pfmand daemon is responsible for tracking the state of SR-IOV physical functions on the BIG-IP 2000 and 4000 series platforms.

Impact

The pfmand process cannot run without a connection to the mcpd process. This will prevent BIG-IP system access to the SR-IOV interface.

Recommended Actions

None
