Known Issue

This is the result of a known issue. The Configuration utility intermittently fails to import a private key if the key is protected by a passphrase.

When this behavior occurs, a message that appears similar to the following example is reported in the Configuration utility:

Import failed: Certificate/Key Mismatch

F5 Product Development tracked this issue as CR91616 and it was fixed in BIG-IP LTM version 9.4.4. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

To work around this issue, F5 recommends that you manually copy a private key with a passphrase to the /config/ssl/ssl.key/ directory.

In the following example, SCP is used to copy a private key to the BIG-IP LTM:

scp myprivate.key root@<IP address>:/config/ssl/ssl.key/myprivate.key

Once you have manually copied a private key to the correct location, you can use the Configuration utility to manage the key and certificate. Once the certificate and key are available on the system, you can configure them for use with a clientssl or serverssl profile by selecting the certificate/key pair and specifying the passphrase for the key.
