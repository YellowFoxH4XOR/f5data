Known Issue

Password corruption may occur when importing or exporting access policies.

This issue occurs when all of the following conditions are met:

  • You import or export a BIG-IP APM access policy.
  • The import or export process is interrupted or fails to complete properly.
  • The configuration is saved or loaded using one of the following commands:
    • tmsh save /sys config
    • tmsh load /sys config

Impact

The encryption key used for the import and export process is not reset properly, causing password fields in the BIG-IP APM configuration to be corrupted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client authentication using the BIG-IP APM system fails.
  • The value for the security.configpassword database variable is incorrectly set to yIG11ZXJ0ZQcGF0cmlhIG9 following the import or export of an access policy.

Workaround

To work around this issue, you can restore the correct value for the security.configpassword database variable, which will trigger the mcpd process to correct the secure field values in the configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Advanced Shell (bash).
  2. To modify the value for the security.configpassword database variable, type the following command:

    tmsh modify /sys db security.configpassword value "<null>"
