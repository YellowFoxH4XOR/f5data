K45704034: zxfrd in restart loop after updating SOA records

Type
Knowledge
Published
2019-05-20
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP DNS: 14.1.0, 12.1.4
Source
https://my.f5.com/manage/s/article/K45704034

Issue

Description

  • Updates to SOA RR cause zxfrd to enter restart loop.
  • The following appears in /var/log/ltm:

    notice zxfrd[1887]: 01530007:5: /usr/bin/zxfrd started ===============================
    err zxfrd[1887]: 0153000c:3: Error writing scratch database(no error information available), serving database is unchanged. zxfrd will exit and restart.
    emerg logger: Re-starting zxfrd

Environment

  • BIG-IP DNS
  • SOA RRs

Cause

BUG ID 756094

Recommended Actions

As a partial workaround, the DNS express cache files can be removed, forcing zxfrd to pull the entire zone using an AXFR request.

  1. Log in to the BIG-IP DNS command line.
  2. Type the following commands in sequence:

    bigstart stop zxfrd
    rm /shared/zxfrd/*
    bigstart start zxfrd

Note: DNS express cannot service DNS responses until the zone transfers are complete. For this reason, this procedure should be carried out on the standby device, when possible.
