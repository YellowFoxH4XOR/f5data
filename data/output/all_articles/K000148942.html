Description

Enabling the "Enforce Device Lock" option in the APM VPN Connectivity Profile may prevent editing security settings on Android devices. This includes settings related to the screen lock, such as passwords or lock patterns.

Environment

  • An Android device with the F5 Access installed 
  • BIG-IP APM VPN connectivity profile with the "Enforce Device Lock" option enabled.

Cause

When the "Enforce Device Lock" option is enabled in the F5 APM VPN Connectivity Profile, it restricts the ability to modify security settings on the device. This behavior is expected and is designed to ensure that the device remains secure. Enforcing a device lock ensures that only authorized users can access the device and the VPN.

    Recommended Actions

    There is no workaround to bypass this restriction while the "Enforce Device Lock" option is enabled, as it is an expected behavior.
