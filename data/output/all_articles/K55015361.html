Description

  • Configuration not loading after software upgrade
  • Error message in /var/log/ltm: "... 010716f5:3: The number of active ASM policies exceeds the maximum number allowed (250)."

Environment

  • ASM provisioned
  • VE

Cause

Provisioning changed, leaving ASM with less asm-host memory than required to support 1024 ASM policies (otherwise it only supports 250 policies)
 

Recommended Actions

  • Increased VE memory in Hypervisor by 3GB (testing may be required to find the exact minimum value)
     

Additional Information

K6723: Number of Security policies supported by the BIG-IP ASM system


"The number of security policies supported by BIG-IP ASM are as follows:

    12.0.0 and later: Starting in 12.0.0, the system uses the following calculation to determine the number of supported security policies:
        The system obtains the system memory size by subtracting 750 MB from the provisioned host memory for the BIG-IP ASM system; this size cannot be less than 700 MB.
        If the obtained value is larger than 1.6 GB, the system supports up to 1,024 security policies; otherwise, the system supports up to 250 security policies.
"
