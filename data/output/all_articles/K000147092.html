K000147092: Why are there connections established with "OK" from countries I blocked via Service Policies?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-19
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Multi-Cloud Network Connect
Source
https://my.f5.com/manage/s/article/K000147092

Description

You created a Load Balancer and added service policies blocking countries or IPs and you see that the connection is flagged with "OK".

Environment

  • F5® Distributed Cloud
  • TCP Load Balancer
  • HTTP Load Balancer

Resolution/Answer

This is the expected behavior at the moment. There are no attacks going through, as the platform blocks the client if any data is transferred upstream to the Origin Server.

Additional Information

If you cannot see even the connection to be established with these IPs or countries, a workaround is to create a Fast ACL.
