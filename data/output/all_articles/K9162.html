Known Issue

This is the result of a known issue. When the BIG-IP ASM processes a server response containing a large number of headers, the system experiences resource exhaustion and possible core dumps. This issue occurs with responses containing 30 or more headers.

F5 Networks Product Development tracked this issue as CR105022 and it was fixed in BIG-IP version 9.4.6. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-9.4.4-HF3 issued for BIG-IP version 9.4.4, and in Hotfix-BIG-IP-9.4.5-HF2 issued for BIG-IP version 9.4.5. You may download these hotfixes or later versions of the hotfixes from the F5 Networks Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.
