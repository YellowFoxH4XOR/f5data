Known Issue

BIG-IP ASM may not apply cross-site request forgery (CSRF) protection to redirected URIs.

This issue occurs when all of the following conditions are met:

  • CSRF protection is enabled in the BIG-IP ASM security policy
  • A protected resource contains an HTTP 302 Redirect response

Although the CSRF engine processes the response page, the engine does not recognize the URI in the Location header as a link, and does not append the CSRT token.

Impact

BIG-IP ASM may generate false positive CSRF violations.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Requests for the resource listed in the HTTP 302 Redirect response Location header will not contain the CSRT token, which will generate false positive CSRF violations.
