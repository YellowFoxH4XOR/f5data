K000140365: Explain log message “This DB variable is not used on this platform.”

Type
Support Solution
Published
2024-07-18
Updated
2024-07-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000140365

Description

The log message This DB variable is not used on this platform. appears in /var/log/ltm.

Environment

  • BIG-IP
  • Non-Velos platform
  • LTM logs

Cause

This message is strictly informational. It is logged when the value of dag.userconfigipv6prefixlen is modified by a configuration load/change on a non-Velos platform. This DB variable is not used on a non-Velos platform and is ignored.

Recommended Action

None
