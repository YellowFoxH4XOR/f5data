K8218: Windows Mobile 5.0 and 6.0 clients cannot access hostnames that contain a period character

Topic

The FirePass Windows Mobile SSL VPN client is designed to work with the Windows Mobile Connection Manager. When you establish an SSL VPN connection to the FirePass controller using a Windows Mobile 5.0 or 6.0 device, the Connection Manager determines whether to route network traffic through the VPN (My Work Network) connection or through the Internet (My ISP) connection.

If the hostname you enter does not contain a period ( . ) character, the Connection Manager routes that traffic through the VPN connection.

For example:

http://intranet

If the hostname you enter contains a period character, the Connection Manager routes that traffic through the Internet connection.

For example:

http://intranet.siterequest.com

Note: The routing decision based on the period character is made by the Windows Mobile software and not by the FirePass SSL VPN client software.

If you want to connect to an intranet site that contains a period in its hostname, you must perform one of the following two actions:

  • Add the hostname of the intranet site to the Work URL Exceptions list in the Windows Mobile device.
  • If your intranet site can be reached by IP address, enter the IP address of the intranet site instead of the hostname to access the site through the VPN connection.

Note: For information about adding a hostname to the Work URL Exceptions list using a Windows Mobile 5.0 Pocket PC device, refer to http://www.microsoft.com/windowsmobile/help/pocketpc/connections.mspx.

Note: For information about adding a hostname to the Work URL Exceptions list using a Windows Mobile 5.0 Smartphone device, refer to http://www.microsoft.com/windowsmobile/help/smartphone/connections.mspx.

Note: For information about adding a hostname to the Work URL Exceptions list using a Windows Mobile 6.0 device, refer to your Microsoft Windows Mobile documentation.
