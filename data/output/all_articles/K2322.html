K2322: BIG-IP and 3-DNS systems may not allow any configuration changes and may report licensing or authorization errors

Topic

In some instances, BIG-IP and 3-DNS systems may not allow any configuration changes and may report the following errors in the /var/db/dmesg.boot file:

Authorization fails: Authorization code invalid.
Authorization fails: Authorization code invalid.
License ok but EULA not accepted

Additionally, when you run the sod command, you may receive the following error:

/config/bigip.conf: ''Load balancing is not available.'' in line ##''

This issue occurs because the BIG-IP system has not authorized the EULA (license agreement). To correct this issue, perform the following steps:

  1. Run the config command.
  2. When prompted, accept the license agreement.
  3. Exit the configuration menu.
  4. Run the sod command.

The BIG-IP system should now successfully authorize the license agreement, and you should be able to use the Configuration utility.
