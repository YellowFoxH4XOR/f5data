K31164044: The BIG-IP Edge Client download rundll32.exe file when attempt to connect

Type
Support Solution
Published
2021-10-28
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K31164044

Description

Starting in BIG-IP APM Edge Client 7.2.1.3 and later, rundll32.exe is used to create a new process which handles the login page and this is by design. As such, it is required on every login attempt and not only at installation time. This may trigger an alert on Firewall or security appliances as it detect a possible security breach.

This is expected behavior and there’s no way to directly launch a DLL file without downloading it as the rundll32.exe application is simply used to launch functionality stored in shared .dll files. This executable is a valid part of Windows, and normally shouldn’t be a threat.

Environment

  • The BIG-IP Edge Client 7.2.1.3 running on Windows operating system

Cause

This is the expected behavior as rundll32.exe is a common tool for using dll functionalities and required by edge client by design now.
