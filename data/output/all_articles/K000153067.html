K000153067: VELOS config-restore from backup fails with error: unknown namespace

Type
Support Solution
Published
2025-08-19
Updated
2025-08-19
Applies to
  • F5OS
  • F5OS-C: 1.8.0
Source
https://my.f5.com/manage/s/article/K000153067

Description

VELOS config-restore from backup failing, with an error similar to the following:

Error: response 'Failed.' confd_load: 642: maapi_load_config(sock, tid, flags, abspath(argv[0])) failed: external error (19): Error on line 2012: unknown namespace: http://f5.com/yang/system/components in components

The /var/log_controller/cc-confd log file also contains a message similar to:

(system f5-db:database cli admin admin -l name backupfile_01.xml): 'confd_load: 642: maapi_load_config(sock, tid, flags, abspath(argv[0])) failed: access denied (3): access denied'

Environment

  • F5OS-C 1.8.0
  • Upgrade from 1.6.x to 1.8.0
  • A system database config reset-default-config operation has been performed

Cause

  • Bug ID 1772433: Config restore fails after upgrade

When encountering this issue, the backup file will contain a config node for the none partition:

<partition>
  <name>none</name>
  <id>0</id>
  <uuid>00000000-0000-0000-0000-000000000000</uuid>
  <config>                              <---
    <enabled>false</enabled>            <---
  </config>                             <---
</partition>

Recommended Actions

Edit the backup file to remove the 3 lines for the none partition:

(Before)

<partition>
  <name>none</name>
  <id>0</id>
  <uuid>00000000-0000-0000-0000-000000000000</uuid>
  <config>                              <---
    <enabled>false</enabled>            <---
  </config>                             <---
</partition>

(After)

<partition>
  <name>none</name>
  <id>0</id>
  <uuid>00000000-0000-0000-0000-000000000000</uuid>
</partition>

Then try the backup-restore operation again.

If the restore still fails, there may be further issues to troubleshoot. Enable confd debug logging (K000092683), reproduce the problem, generate a qkview and open a case with F5 Support for further investigation.

Additional Information

Config restore can fail due to numerous reasons.
