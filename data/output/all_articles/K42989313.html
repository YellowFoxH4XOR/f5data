K42989313: BIG-IQ user is not permitted to create an application on this device via AS3

Type
Support Solution
Published
2021-09-16
Updated
2023-02-21
Applies to
  • F5 Automation and Orchestration
Source
https://my.f5.com/manage/s/article/K42989313

Description
Symptoms

  • BIG-IQ user not permitted to deploy an app on BIG-IP device using AS3.
  • The following error message is returned when deploying AS3 Declaration via BIG-IQ:

"results": [
    {
        "message": "Failed to get cm-bigip-allBigIpDevices device for hostname ltm1.test.org : 
        java.lang.IllegalArgumentException: User is not permitted to create an application on this device: 
        java.lang.IllegalArgumentException: User is not permitted to create an application on this device",
        "dryRun": false,
        "host": "localhost",
        "tenant": "test",
        "runTime": 1984,
        "code": 422
    }

Environment

  • Attempting to deploy AS3 template via BIG-IQ to BIG-IP
  • Deploying AS3 Declaration via BIG-IQ
  • AS3 user has "Administrator" privileges
  • BIG-IP LTM configuration has not been "Discovered" by BIG-IQ

Cause

In order for BIG-IQ to manage BIG-IP configuration (or deploy AS3 declaration), the LTM configuration for that BIG-IP device must first be "Discovered".

Recommended Actions

From BIG-IQ GUI menu "Devices >> BIG-IP DEVICES >> [select the BIG-IP] >> SERVICES >> LTM Configuration Discovery", click on the "Discover" button, (or attempt to "Re-discover").
