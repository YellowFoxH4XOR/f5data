Known Issue

A web page that contains the Microsoft AlphaImageLoader filter fails to properly render images.

This issue occurs when all of the following conditions are met:

  • FirePass is configured with a web portal
  • HTML data contains filter:progid:DXImageTransform.Microsoft.AlphaImageLoader(src=<image file>)

Impact

Web pages fail to properly render images.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Images that are rendered using the AlphaImageLoader filter are not displayed on the web page.
  • The web page source shows that the reverse proxy engine has not rewritten the AlphaImageLoader src property.
