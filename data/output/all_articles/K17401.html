Known Issue

The WhiteHat vulnerability assessment tool may not correctly integrate with BIG-IP ASM security policies.

This issue occurs when the following condition is met:

  • You configure the WhiteHat vulnerability assessment tool for an existing security policy.

Impact

Proper WhiteHat response headers are not added to traffic; therefore, rescans fail to report vulnerabilities found by WhiteHat as mitigated by the BIG-IP ASM system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Vulnerabilities reported by WhiteHat Sentinel are mitigated in the BIG-IP ASM system; however, mitigation results are not reported back to the WhiteHat portal.
