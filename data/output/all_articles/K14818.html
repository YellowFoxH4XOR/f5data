Topic

The BIG-IP system hourly generates new Diffie-Hellman (DH) parameters.

Description

Starting in BIG-IP 11.4.0, the generation of new DH parameters occurs hourly. The script that generates new DH parameters is called genkeys-1024, and it runs the first minute of every hour. When the script is running, the BIG-IP system may show a spike in CPU usage with a very short duration. This is an expected behavior. The script resides in the /etc/cron.hourly/ directory. Prior to BIG-IP 11.4.0, this script resides in the /etc/cron.monthly/ directory.

None
