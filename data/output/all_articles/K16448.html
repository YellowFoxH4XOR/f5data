Known Issue

The hostagentd process may leak memory over time. The hostagentd process runs on Virtual Clustered Multiprocessing (vCMP) hosts and receives various system and Traffic Management Microkernel (TMM) related statistics from vCMP guests.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is provisioned as a vCMP host (hypervisor).
  • You have configured and deployed vCMP guests.

Impact

In rare instances, the vCMP host may run out of memory and cause system instability on either the vCMP host or guest.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A vCMP host or guest shows signs of general instability.
  • The hostagentd process is 1 GB or larger in size, and continues to grow when you view the process by using the following command:

    ps aux | grep -E '/usr/bin/hostagentd|USER'
    USER PID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND
    root 23456 0.0 5.8 1.5G 910.4M ? S Jan01 00:18:44.71 /usr/bin/hostagentd

Workaround

To work around this issue, you can disable guest health statistic collection on the vCMP host. To do so, perform one of the following procedures:

Disabling statistic collection for the tmsh show vcmp health command

Impact of workaround: This procedure affects values returned by the tmsh show vcmp health stats command.

  1. Log in to the command line of the vCMP host. If the device is a VIPRION, ensure you are logged into the primary blade.
  2. To disable statistic collection, type the following command:

    tmsh modify vcmp guest all capabilities add { stats-isolated-mode }

    Note: If you need to revert the change made in this workaround, type the following command for this step:

    tmsh modify vcmp guest all capabilities delete { stats-isolated-mode }

  3. Save the changes by typing the following command:

    tmsh save sys config

  4. To restart the hostagentd process, type one of the following commands:
    • Standard BIG-IP appliance:

      bigstart restart hostagentd

    • VIPRION system:

      clsh bigstart restart hostagentd

Disabling the hostagentd process

Impact of workaround: This procedure affects health statistic collection, as well as the ability for guests to install from a host-provided ISO.

  1. Log in to the command line of the vCMP host. If the device is a VIPRION, ensure you are logged in to the primary blade.
  2. To disable the hostagentd process, type one of the following commands:
    • Standard BIG-IP appliance:

      bigstart stop hostagentd

    • VIPRION system:

      clsh bigstart stop hostagentd

  3. To exclude the hostagentd process from starting up after rebooting the system, type one of the following commands:
    • Standard BIG-IP appliance:

      bigstart disable hostagentd

    • VIPRION system:

      clsh bigstart disable hostagentd
