Known Issue

This is most likely the result of a known issue. If you attempt to add a Link Controller to an existing sync group, but do not first configure the sync group on the principal 3-DNS Controller, the 3dns_add script will fail to add the Link Controller. The 3dns_add script should refuse to run when a sync group has not been configured on the principal 3-DNS Controller.

The 3dns_add script will appear to work and will pull the remote configuration, but it will fail when it attempts to add the Link Controller to the existing sync group.

F5 Networks Product Development tracked this issue as CR27219 and CR41894.
