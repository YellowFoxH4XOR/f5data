K000139262: NTLM authentication sessions failing while using RDP gateway

Type
Support Solution
Published
2024-04-11
Updated
2024-04-11
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000139262

Description

You are having an issue with NTLM authentication. You are using RDP gateway with NTLM authentication in the APM profile. You can see users are connecting to BIG-IP APM but NTLM Authentication is failing.

Environment

  • BIG-IP APM
  • HA cluster
  • BIG-IP failover
  • NLAD daemon
  • ID 762401

Cause

This might be due to Bug ID 762401

Recommended Actions

The workaround for this issue as of now is to renew NTLM machine password or restart nlad daemon:

Impact of workaround: Only new connection while service is restarting will not be able to access service, but this is usually very quick and should not be notice by users. All other active sessions should not be interrupted

  • Click on Renew Machine password and NTLM should work properly.

OR

  • Run the following command to restart nlad:

#bigstart restart eca nlad
