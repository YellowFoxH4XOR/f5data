Description

F5 Insight for BIG-IP provides in-depth app telemetry, resource utilization data, key events, service statuses, network configurations, and health stats—all using lightweight software components. One feature option is to integrate with AI Data Fabric (AIDF) to automatically discover, identify, and categorize applications by type and workload. AI Data Fabric is an intelligence service that continuously enriches F5 products with contextual, cross-customer insights, so teams get better guidance, not just more data.

This requires sharing relevant information from your BIG-IP infrastructure with F5 Insights, and an LLM either internal to your organization, or externally.

Environment

  • F5 Insights - 1.0.0
  • AIDF deployment and data sharing

Cause

Informational

Answer/Recommended Actions

Here is a summary of the data shared with the AIDF envirronment and data categories that F5 Insights shares with a configured LLM.

  • Configuration metadata (names, IPs, ports)
  • Performance metrics and statistics (aggregated numbers)
  • Security event metadata (attack types, not payload)
  • Topology and relationship data

 

Data Categories Shared with LLM

1. Device & Infrastructure Data

Device Information: Device names, datacenter names, device status
Device Statistics: CPU usage, memory usage, connection counts, throughput metrics
Datacenter Info: Datacenter names

2. Virtual Server Data

Virtual Server Config: Virtual server names, IP addresses, ports, nodes, status (enabled/disabled)
Performance Metrics: Connection counts, request rates, throughput, response times
Policy Associations: Connection policies, iRules, profiles attached to virtual servers

3. Pool & Load Balancing Data

Pool Configuration: Pool names, load balancing methods, member lists
Pool Member Details: Member IP addresses, ports, status (up/down), priorities
Pool Statistics: Active connections, bytes in/out, current connections per member

4. Security & WAF Data

WAF Incidents: Attack types, severity levels, incident timestamps, violation details
WAF Event Summaries: Attack patterns, source IPs, violation categories, request URLs
Security Policies: WAF policy names and associations

5. Policy & Configuration Data

Connection Policies: Policy names, rules, match conditions
Network Topology: Relationships between virtual servers → pools → pool members
Configuration Details: iRules, profiles, SSL certificates (names, not private keys)

6. Geographic & Mapping Data

Location Information: Regional health information.
Geolocation Data: Geolocation data is inferred from the datacenter and device names. explicit device locations and information is not sent.

Data that is not shared with the LLM:

  • Private keys or certificates (only certificate names/metadata)
  • Passwords or authentication credentials
  • Actual payload data from traffic
  • Customer PII (unless it is contained in configuration names)
  • Decrypted SSL traffic contents

In summary, the LLM receives operational and configuration metadata about your BIG-IP infrastructure to provide insights and analytics, but will not receive sensitive authentication data, private keys, or actual traffic payloads.
