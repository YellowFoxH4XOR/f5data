K8025: Accessing the default logon page after accessing a customized landing URI

To access the FirePass default logon page after accessing a customized landing URI, close all browser windows and then re-open your browser. Enter the default logon URI to access the default logon page.

For example:

https://firepass.siterequest.com/my.logon.php3

Closing your browser clears the VHOST session cookie, which is set by the FirePass controller when you access a customized landing URI.

For example:

https://firepass.siterequest.com/partners/

The VHOST session cookie stores the landing URI you used to access the FirePass controller. After setting the cookie, FirePass redirects your browser to the default logon URI.

For example:

https://firepass.siterequest.com/my.logon.php3

Although your browser redirects from the customized landing URI to the default landing URI, the logon page customizes according to the landing URI information stored in the VHOST cookie. If you attempt to access the default logon page by entering the default logon URI within the same browser session, the page will continue to display the customized content. Closing your browser clears the VHOST session cookie, allowing you to access the default logon page by entering the default logon URI.

Note: You can configure customized landing URIs on the Device Management: Customization page under the URI-based Customization tab.
