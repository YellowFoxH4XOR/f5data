K000140798: Which Network Access tunnel will be connected when session assigned multiple network access resources?

Description

When the VPN client (Edge Client or F5 Access) access the APM virtual server and connect the VPN, maybe multiple Network Access resource will be assigned to the session, and the client will choose one Network Access resource and create the PPP tunnel.

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • Multiple Network Access
  • Edge Client or F5 Access on different OS

Cause

None

Recommended Actions

When multiple Network Access resources are assigned to the session, BIG-IP APM will sort the Network Access resource name by the ASCII order, choose the first network access tunnel resource.

If the client get the unexpected Network Access resource, the suggestion is, do not assign multiple Network Access resources to the session.

Additional Information

When the client is browser, it will show multiple Network Access resources on the webtop, and user can click the desired Network Access object, connect to the proper VPN tunnel.

If Auto-Launch option is enabled on one network access, it will be launched when the client is browser. But this option will not affect on the Edge Client and F5 Access.
