Description

On APM - Access Policy - Endpoint Security (Client Side) - Windows Process (or Windows File, etc.)

'Continuously check the result and end the session if it changes' feature behavior

 

The 'HELP' states that when this feature is enabled, the session will be terminated if the client does not respond for 5 minutes, but when you actually test it, if you terminate the process, the session will terminate after about 30 seconds to 1 minute.

 

Environment

BIG-IP APM

 

Cause

You are looking for information on the behavior of this feature.

 

Q: Doesn't the session end 5 minutes after the process ends?

A: Five minutes is the maximum time limit. The behavior is that the check will be performed within the 5 minutes and generally, the checks occur less than the maximum limit.

 

Q: At what frequency does it check whether the process is alive? N seconds or N minutes?

A: It checks within every 300 seconds.

 

Recommended Actions

No action needed.

For Information of the expected behavior only.
