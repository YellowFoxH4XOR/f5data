Topic

You should consider using this procedure under the following condition:

  • You want to use a custom logo image on the BIG-IP APM access profile login page for mobile devices.

Description

By performing the following procedure, you can update the logo image seen when accessed by mobile devices to fit the theme of the access profile. Consider the file size and the dimensions of the replacement logo image and how this impacts the presentation of the login page.

Note: The default F5 logo image size is 80 pixels x 80 pixels.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the BIG-IP APM system.
  • You verified that the BIG-IP APM system is configured with a functioning access profile.
  • You have a replacement logo image (JPG, JPEG, GIF, or PNG file) residing on the device that is administering the BIG-IP APM system.

Procedures

  • Uploading the custom image using the image browser
  • Selecting the custom image in the BIG-IP APM customization

Uploading the custom image using the image browser

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Profiles / Policies > Customization > General.

    Note: For BIG-IP 11.6.x - 12.x, navigate to Access Policy > Customization > General. For BIG-IP 11.5.x and earlier, navigate to Access Policy > Customization > Advanced.

  3. Click Image Browser.
  4. In the pop-up window, click on Add Image.
  5. Select your custom image to upload it to the BIG-IP APM system.
  6. Close the image browser.

Selecting the custom image in the BIG-IP APM customization

Impact of procedure: The original access profile login page no longer displays the default F5 logo.

  1. Log in to the Configuration utility.
  2. Navigate Access > Profiles / Policies > Customization > General.

    Note: For BIG-IP 11.6.x - 12.x, navigate to Access Policy > Customization > General. For BIG-IP 11.5.x and earlier, navigate to Access Policy > Customization > Advanced.

  3. Click Form Factor and click Full/Mobile Browser.
  4. Under Form Factor: Full/Mobile Browser, click the Branding tab.
  5. On the Branding tab, navigate to Customization Settings > Access Profiles > /Common > <access_profile_name> > Common > Page Header Settings.
  6. For Header left image (Mobile Devices size), click the file path of the image, then click the replace icon to the right of the path name.
  7. Click Replace, click your custom image, then click Change.
  8. Click Save.
  9. Click Apply Access Policy.
  10. Select the check box for the access policy you want to apply and click Apply.

    Note: For BIG-IP 11.x - 12.x, click Apply Access Policy.
