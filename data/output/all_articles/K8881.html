Known Issue

This is the result of a known issue. If a user attempts to enter Protected Workspace at the pre-logon sequence, and the Windows client system is running Utimaco Safeguard Enterprise, the client system appears to freeze for several minutes and then shuts down.

F5 Product Development tracked this issue as CR95430 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.
 
Additionally, this issue has been fixed in cumulative hotfix Hotfix HF-602-9 issued for FirePass 6.0.2, and cumulative hotfix HF-603-2.1 issued for FirePass 6.0.3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.
 
To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Workaround
 
You can work around this issue by preventing Windows clients running Utimaco Safeguard Enterprise software from entering Protected Workspace. To do so, perform the following procedure:
 
  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. Next to the name of the active pre-logon sequence, click the backup & edit link.

    The Pre-Logon Sequence Editor opens.
  4. Mouse over the line to the left of the Switch to PWS action.
  5. Click the plus icon.
  6. In the Change Sequence screen, select the Check Processes option button.
  7. Click Apply Changes.
  8. In the Edit Action screen, click the Windows process checker link.
  9. In the Processes to be absent field, enter the name of the Utimaco Safeguard Enterprise process.

    For example:

    SGNMaster.exe
  10. Click Update.

    If you do not want clients running Utimaco Safeguard Enterprise process to access the FirePass controller, this procedure is complete. Clients running Utimaco Safeguard Enterprise process will be directed to the Logon Denied page.

    If you want clients running Utimaco Safeguard Enterprise process to access the FirePass controller (without entering Protected Workspace), proceed to the next step.
  11. To the right of the fallback rule for the Check Processes action, click the Logon Denied Page box.

    The End Page Properties screen appears.
  12. In the End Page Properties screen, select Logon Allowed Page from the Type menu.
  13. Click Update.
