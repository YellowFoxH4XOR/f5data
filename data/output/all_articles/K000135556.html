Description

The below error message may pop up after saving the configuration, config sync, or upgrade.


IPsec policy (/partition/your-policy-name) referenced by traffic selector (/partition/your-traffic-selector-name) is not in Interface mode.

Environment

  • IPSec configuration
  • Configuration changes
  • Config sync
  • Software upgrade

Cause

Invalid configuration. An interface config links to a traffic selector and that selector is linked to an IPSec policy, which is in tunnel mode.

 Recommended Actions

  1. If you want interface mode, you are missing some tunnel config as well as needing to change the IPSec policy to mode "interface".
  2. If you want tunnel mode, delete the IPSec tunnel object. Tunnels in BIG-IP configuration actually set up interfaces, like VLANs. But an IPsec object in "tunnel" mode does not set up an interface.

Additional Information

None.
