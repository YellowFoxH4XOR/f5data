Description

  • When you encounter bug ID1103369 and one step in the procedure is to restart the process csyncd
  • Restarting the process should not have a traffic impact due to the csyncd process populates the software image table.
  • Additionally, on VIPRION systems, the csyncd process replicates portions of the file system between cluster members. 

 

Environment

  • Bug ID1103369
  • All platform

Cause

When you encountered bug ID1103369, one step in the procedure is to restart the process csyncd  

Recommended Actions

  • Restarting the process should not have a traffic impact due to the csyncd process populates the software image table. Additionally, on VIPRION systems, the csyncd process replicates portions of the file system between cluster members. 
    Important: Regarding ID1103369, please follow all actions of the workaround. Restarting the csyncd process is just one of the steps in the workaround. And the permanent fix is to upgrade the software.

    Impact of workaround: This should not have any traffic impact on the system.
  • For Appliance platform
    • bigstart restart csyncd
  • For Viprion platform
    • clsh "bigstart restart csyncd"
