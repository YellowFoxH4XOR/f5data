Topic

You should consider using this procedure under the following conditions:

  • You want to perform a graceful shut down of one or more blades in a VIPRION system.
  • You want to perform a graceful restart of one or more blades in a VIPRION system.

Description

In a VIPRION system, the reboot, halt, full_box_reboot, and shutdown commands only affect the blade on which the command is executed. To execute a shut down or restart on all available (green) blades in a VIPRION system, you can use the clsh command in conjunction with the shutdown command. For example, clsh shutdown -r now.

Note: If vCMP guests are running on a VIPRION host, the system does a graceful shutdown of the guests prior to the host shutdown.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command line access to the VIPRION system.

Procedures

  • Restarting all blades in a VIPRION system
  • Shutting down all blades in a VIPRION system
  • Restarting a specific blade in a VIPRION system
  • Shutting down a specific blade in a VIPRION system
  • Verifying the blade status

Restarting all blades in a VIPRION system

Impact of procedure: Service is interrupted during restart.

  1. Log in to the command line of the VIPRION system.
  2. To immediately restart all the blades, type the following command:

    clsh reboot

Shutting down all blades in a VIPRION system

Impact of procedure: Service is interrupted during shut down.

  1. Log in to the command line of the VIPRION system.
  2. To immediately shut down all the blades, type the following command:

    clsh shutdown -h now

Restarting a specific blade in a VIPRION system

Impact of procedure: The VIPRION blade is unavailable for traffic processing while the blade is restarting.

  1. Log in to the command line of the VIPRION system.
  2. To immediately restart a specific blade, use the following command syntax:

    clsh --slot=<slot number> <command>

  3. For example, to immediately restart only blade 2, type the following command:

    clsh --slot=2 "reboot" 

Shutting down a specific blade in a VIPRION system

Impact of procedure: The VIPRION blade is unavailable for traffic processing while the blade is shut down.

  1. Log in to the command line of the VIPRION system.
  2. To immediately shut down a specific blade, use the following command syntax:

    clsh --slot=<slot number> <command>

  3. For example, to immediately shut down only blade 2, type the following command:

    clsh --slot=2 "shutdown -h now"

Verifying the blade status

After you have shutdown one or more VIPRION blades, you can verify the blade status by performing the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the VIPRION system.
  2. Access the TMOS shell by entering the following command:

    tmsh

  3. To display the VIPRION blade status, enter the following command:

    show sys cluster all-properties

  4. The VIPRION blade status is displayed.
