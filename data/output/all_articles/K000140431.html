Description

BIG-IP is INOPERATIVE after a reboot, with mcpd restarting continuously.

A sequence of messages similar to the following is repeating in /var/log/ltm:

err mcpd[13780]: 01071245:3: Unable to open the configuration of the dns cache
err mcpd[13780]: 01070734:3: Configuration error: MCPProcessor::initializeDB (2):
err mcpd[13780]: 01070596:3: An unexpected failure has occurred, - sys/validation/DbVariable.cpp, line 3245, exiting...
info chmand[4236]: 012a0006:6: MCP connection lost.

Environment

  • mcpd
  • DNS cache

Cause

These symptoms indicate that /var/dnscached/config/named.conf, or the entire /var/dnscached directory, have gone missing or are inaccessible.

Here is how the directory structure should typically look on a 17.1.x BIG-IP:

Recommended Actions

Some of the files in /var/dnscached are unique, so cannot simply be copied from another BIG-IP system if they are missing.

If the entire /var/dnscached directory is missing, or you do not know how the file(s) were deleted, a clean install is recommended to resolve this issue.
