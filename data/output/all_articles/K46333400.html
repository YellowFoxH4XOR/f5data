K46333400: Cloud API failover is not working and encountered message ''Failover failed because Recovery operations are empty, advise reset via the API''

Type
Support Solution
Published
2021-04-29
Updated
2023-02-21
Applies to
  • Public Cloud
  • BIG-IP
  • BIG-IP LTM: 16.0.X, 16.1.0, 16.0.1, 16.0.0, 16.1.3, 16.X.X, 16.1.1, 16.1.2, 16.1.X
  • Microsoft Azure
Source
https://my.f5.com/manage/s/article/K46333400

Description

When trying to validate cloud failover extension via Postman, you get the following result:

POST /trigger = 500 Failover task failed

{

"taskState": "FAILED", "message": "Failover failed because Recovery operations are empty, advise reset via the API",
"timestamp": "YYYY-MM-DDTXX:XX:XX.XXXZ",
"instance": "bigip.local",

"failoverOperations": {
"addresses": null,
"routes": null
}

"code": 500

}

Environment

  • BIG-IP Azure
  • Cloud Failover Extension
  • Recently upgraded the BIG-IP instance

Cause

Recovery operations are empty

Recommended Actions

On both BIG-IP, reset the failover state by running this command from the command line:

curl --header "Content-Type: application/json" \
  --request POST \
  --data '{"resetStateFile": true}' \
  -u admin:admin http://localhost:8100/mgmt/shared/cloud-failover/reset
 

Additional Information

None
