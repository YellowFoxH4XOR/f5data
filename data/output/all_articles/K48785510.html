Description
After restoring the configuration from UCS, snmpget/snmpwalk times out even though tmsh list sys snmp shows the correct configuration. Restarting the snmpd service resolves the issue, and snmpget/snmpwalk starts working.

Environment

  • The BIG-IP configuration has been restored from UCS.
  • The sys snmp configuration is different before and after UCS restore.
  • The sys snmp configuration is correct.

Cause
The issue is due to ID 1059161, and snmpd does not load a new config during UCS restore.

Recommended Actions

  1. Refer to Bug ID 1059161: No response to SNMP GET request with an error message 'Timeout: No Response from <ip_address>.' after UCS restore for solution.
