Known Issue

This is the result of a known issue. The default Client SSL and Server SSL profiles include ciphers that utilize the MD5 message-digest algorithm. Weaknesses in the MD5 algorithm may allow for collisions in output. Therefore, it is possible for an attacker to generate cryptographic tokens or other data that may appear to be authentic.

F5 Product Development tracked this issue as CR126857 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Note: Beginning in version 10.2.0, ciphers utilizing the MD5 message-digest algorithm are removed from the default SSL profile cipher lists.

Workaround

You can work around this issue by disabling SSL ciphers that support MD5. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles.
  3. Select Client from the SSL drop-down menu (or select Server if you want to disable MD5 ciphers for a Server SSL profile).
  4. Click Create.
  5. Type a name for the profile.
  6. Select Advanced from the Configuration drop-down menu.
  7. Click the Custom box next to Ciphers.
  8. Add !MD5 to the end of the cipher string in the Ciphers box.

    For example, the following cipher string uses the default SSL ciphers for the profile, and disables ciphers using the MD5 hash algorithm:

    DEFAULT:!MD5
  9. Click Finished.
  10. Associate the new profile with the virtual server.
