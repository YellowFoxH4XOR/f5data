Description

GUI behaves correctly, until the Statistics Dashboard is accessed. GUI will fail if another GUI tab is open in the browser, or if any element
other than default information (last 5 min statistics) on the dashboard is accessed

Environment

  • Accessing the Configuration Utility Statistics Dashboard

Cause

This is Bug id 472645
The tomcat process restarts when the statistics dashboard is accessed
This is caused by too much data in /var/annotate
Catalina Log file shows:

# java.lang.OutOfMemoryError: Java heap space
# -XX:OnOutOfMemoryError="/usr/bin/restart_tomcat"
# Executing /bin/sh -c "/usr/bin/restart_tomcat"..

Recommended Actions

  1. Backup the contents of /var/annotate
    tar zcvf /shared/tmp/$HOSTNAME-annote.tar.gz /var/annotate/*
  2. Remove all the data in the path
    rm -Rf /var/annotate/*
  3. Restart the logstatd service:
    Note: The logstatd process parses log data for utilities, such as the BIG-IP dashboard and is also used in BIG-IP APM policy sync.
    Note: For more information on the steps and the impact of restarting logstatd, refer to K11439: Dashboard utility alerts generated by the system_check utility are not cleared when the event is resolved???????

    tmsh restart /sys service logstatd

  4. Verify the issue is fixed
  5. If needed increase the memory assigned to the tomcat process
    tmsh modify /sys db provision.tomcat.extramb value 250

Additional Information

Bug ID 472645: Memory issues when there is a lot of data in /var/annotate (annotations for dashboard)
