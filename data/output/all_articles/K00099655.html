Description

  • You build out a new BIG-IP and before changing the admin password via the GUI (mandatory during initial setup) you change the root password via the CLI.
  • When trying to access the GUI for the first time you will be asked to update the admin password but it will fail.
  • You will see an error message similar to...Authentication failed: Password expired. Update password via /mgmt/shared/authz/users

Environment

  • Updating the GUI password fails.

Cause

This has been identified as ID992241: Unable to change initial admin password from GUI after root password change

Recommended Actions

  1.  There are 2 ways to address this issue...
    1. Do not change the root password before trying to access the GUI for the first time. The root and admin passwords are required to be changed as part of the initial setup.
    2. If you have already changed the root password then via the CLI update the admin password. To do so follow these steps..
      1. Log into the CLI and obtain a tmsh prompt. 
        tmsh
      2. Then type this command:
        modify auth user admin password <password>
        Example: modify auth user admin password P@ssw0rd

Additional Information

There is no hotfix since the recommended action fixes the issue.
