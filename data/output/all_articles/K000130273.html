Description

  • IP Intelligence (IPI) Whitelist is not loaded into the DB
  • A whitelist feed list is not loaded and therefore does not function

Environment

  • ASM provisioned
  • AFM not provisioned
  • Trying to use IP Intelligence Feed Lists or IP Intelligence Whitelists

Cause

AFM must be provisioned to use IP Intelligence Feed Lists or IP Intelligence Whitelists.

Note: that statement only applies to AFM. IP Intelligence can also be used with just ASM and LTM. There are ways to allow IPs when IPI is used within those modules, but it is not as granular. To learn more refer to the note in K18751044: Allowlist/Whitelist for IP Intelligence

 Recommended Actions

Either provision AFM or do not use IP Intelligence Feed Lists or IP Intelligence Whitelists
