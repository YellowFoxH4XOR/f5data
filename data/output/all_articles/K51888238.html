Description
You have made changes to default profiles such as /Comman/clientssl, /Common/tcp, etc. F5 Support highly recommends against ever doing this for a number of reasons. The following is not an exhaustive list.

  • This can cause a failure to upgrade, see K74221031: Modifying the default SSL profile may cause upgrades to fail
  • Failure to sync, see K16237: Modifying a default profile may cause ConfigSync operations to fail

Environment

  • BIG-IP with modified default profiles.
    • ltm profile tcp /Common/tcp
    • ltm profile client-ssl /Common/clientssl
Cause
See the Related articles for various causes.
Recommended Actions

It is recommended to revert the modifications of the default profile back to the default settings.

You will retain the modifications made in the customized profile, and revert the default profile back to its default state.

Remove Customized Default Profile
Note: The following applies to the default clientssl profile, however this can be applied to any customized default profile.

  1. Make a copy of the current clientssl profile and name it something to the affect of 'clientsslCustomDefault', then load it into your configuration.

  2. Create a new custom profile that defaults from clientssl

    tmsh list ltm profile client-ssl one-line | grep 'ltm profile client-ssl clientssl {' | sed 's,ltm profile client-ssl clientssl ,ltm profile client-ssl clientsslCustomDefault ,g' > /var/tmp/clientsssCustomDefault.conf

    tmsh load sys config file /var/tmp/clientsssCustomDefault.conf merge

    tmsh save sys config

  3. Update all Virtual Servers that use ltm profile client-ssl /Common/clientssl
    Note: this will create a backup file named /config/bigip.conf.bak

    sed -i.bak 's,^        /Common/clientssl {$,        /Common/clientsslCustomDefault {,g' /config/bigip.conf

  4. Delete ltm profile client-ssl /Common/clientssl { from your configuration:

    1. Create a copy of your configuration sans default /Common/clientssl

      cp /config/bigip.conf /var/tmp/K51888238.bigip.conf

    2. Overwrite your current bigip.conf:

      awk 'BEGIN { FS = "\n" ; RS = "\n}\n" ; ORS = "\n}\n" }; !/^ltm profile client-ssl \/Common\/clientssl \{/ { print }' /var/tmp/K51888238.bigip.conf | sed ':a;N;$!ba;s,\n\n}$,,g' > /config/bigip.conf

    3. Verify and load:

      tmsh load sys config verify
      tmsh load sys config

Expected Result
  • ltm profile client-ssl clientssl is removed from bigip.conf, forcing it to fall-back to it's default configuration (held in /config/profile_base.conf)
  • New, custom client-ssl profile is created, clientsslCustomDefault
  • All virtual servers that were configured to use /Common/clientsssl will now use /Common/clientsslCustomDefault
Back-Out Procedure

Should anything go wrong, you have created a backup, /config/bigip.conf.bak:

  1. Copy and load /config/bigip.conf/bak

    cp /config/bigip.conf.bak /config/bigip.conf
    tmsh load sys config
    tmsh save sys config

Additional Information
As a best practice, it is highly recommended to never make any changes to default profiles. This has caused numerous failures that will likely never be documented; however to ensure a stable environment, ensure to follow F5 Best Practice recommendations.
