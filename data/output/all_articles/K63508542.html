Description

Configuration Utility stops responding for 20+ minutes after forcing configuration sync.
Resulting browser message: "Unable to Contact Big-IP device".
 

Environment

  • BIG-IP
  • Device service cluster (DSC) 
  • ConfigSync
  • GUI / Configuration Utility
     

Cause

Bug ID 796605

When forcing a configuration sync, the GUI stops responding and shows "Unable to contact BIG-IP" message which can last for 20+ minutes. This is caused by a 500 response being received after a 300 second timeout.

Example extraction for HTML Archive taken on client machine:

(Request-Line)    GET /tmui/service/resource/devmgmt_overview?_=1565896264 HTTP/1.1
(Status-Line)    HTTP/1.1 500 Internal Server Error
Receive        + 300.102    < 0.001            <--- Request timeout reached and HTTP sends 500 error message.

Multiple requests like this timing out can stack up to 20+ minutes of GUI inaccessibility.
 

Recommended Actions

The timeout value in the httpd config is set at 5 minutes by default. With repeated attempts to sync, this could lead to 20+ minutes waiting for a call to finally timeout. 
By decreasing the proxy timeout to 10 seconds, we can force a quicker 500 response which will limit the GUI inaccessibility.

Impact of procedure: This workaround can have a noticeable impact on AS3 restnoded behavior, the client can receive a 502 Proxy Error due to the ProxyTimeout value being too low. This low value can prematurely close the connection between httpd and restjavad causing the response from restnoded to restjavad, to be reset when passed on to httpd.

  1. Log in to BIG-IP Advanced shell (bash).
  2. Make a backup of /config/httpd/conf.d/proxy_ajp.conf
    cp /config/httpd/conf.d/proxy_ajp.conf /config/httpd/conf.d/proxy_ajp.conf.bk
     
  3. Edit /config/httpd/conf.d/proxy_ajp.conf with text editor
    e.g 
    vi /config/httpd/conf.d/proxy_ajp.conf

    Locate the following two "#ProxyPass" lines and add the line indicated by an arrow:

    #ProxyPass /tomcat/ ajp://localhost:8009/
    #ProxyPass /examples/ ajp://localhost:8009/jsp-examples/

    ProxyTimeout 10            #<----- Add this line
     
  4. Save and close the file.
     
  5. Restart httpd and tomcat.
    bigstart restart httpd tomcat
     
  6. Check if this workaround works.
IMPORTANT: this change will not replicated across blades in multi-bladed system. Please make a change for each blade.
Note: Perform the workaround on all members of the device group as this change will not be sync'd to the peer.
Note: this change will not be inherited when software upgrade is done.
Note: this change will not be saved in to ucs file, so after replacement of the unit/blade, you will need to follow above after/before UCS restoration.
