Description

Where do rSeries store it MIB files?

Note: If you are wanting to download the MIB files from your F5OS appliance:  Download MIB files from F5OS

Environment

  • F5OS-A
  • rSeries

 

Cause

You will see the MIB files after replacing *VERSION* with the F5OS-A version you're using under below directory:

/var/export/chassis/import/.mounts/iso/R5R10/*VERSION*/m3/usr/share/snmp/mibs/


For example, you can run below command to see the MIB files under version 1.1.1-8463

[root@appliance-1 mibs]# ll /var/export/chassis/import/.mounts/iso/R5R10/1.1.1-8463/m3/usr/share/snmp/mibs

/var/F5/system/mibs/mibs_f5os_appliance.tar.gz contains the following mibs:

  • mibs_f5os_appliance/F5-ALERT-DEF-MIB.txt
  • mibs_f5os_appliance/F5-COMMON-SMI-MIB.txt
  • mibs_f5os_appliance/F5-OS-LLDP-MIB.txt
  • mibs_f5os_appliance/F5-OS-PLATFORM-SMI-MIB.txt
  • mibs_f5os_appliance/F5-OS-SYSTEM-MIB.txt
  • mibs_f5os_appliance/F5-OS-TENANT-MIB.txt
  • mibs_f5os_appliance/F5-PLATFORM-STATS-MIB.txt
  • mibs_f5os_appliance/F5OS-APPLIANCE-ALERT-NOTIF-MIB.txt
