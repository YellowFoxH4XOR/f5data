Description

BIG-IP ASM/Advanced WAF system may not be able to send reports to remote SMTP server. You may observe errors similar to the following in /var/log/asm:

crit perl[<PID>]: 01310027:2: ASM subsystem error (run_scheduled_reports.pl,F5::AVReporter::Client::run_monpd_method): Monpd error: Internal error

Similar error logs may also be observed in log file /var/log/avr/monpd.log:

REPORTER|ERROR|... Error code 8 while running external process php /ts/dms/script/avrexport/avrmail.php /ts/dms/policy/upload_files/aet_monpd_avrexp_XVLEVr.xml
REPORTER|ERROR|... throwing exception to client error code is 1 error msg is Internal error

Environment

  • BIG-IP ASM/Advanced WAF
  • Scheduled reports
  • Manual reports

Cause

SMTP authentication failure between the BIG-IP ASM/Advanced WAF systems and the remote SMTP server.

Recommended Actions

Make sure the proper credentials are configured for SMTP authentication on the BIG-IP ASM/Advanced WAF systems.

  1. Log on to the Configuration utility.
  2. Go to System > Configuration > Device > SMTP. 
  3. Click the SMTP server configured.
  4. Check the "Use Authentication" box, and enter the proper username and credentials.
