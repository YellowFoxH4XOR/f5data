Known Issue

TMM may exit and produce a core file when the BIG-IP APM SWG performs URL categorization.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for SWG.
  • SWG is performing URL categorization on requests that have a large payload.

Impact

The BIG-IP APM system is unable to process traffic while the TMM process is unavailable.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are unable to access the BIG-IP APM system or may experience a traffic disruption.
  • The TMM process generates a core file to the /shared/core directory.
  • The BIG-IP system generates a SIGSEGV fault and stack trace in the /var/log/tmm file, similar to the following example:

    notice ** SIGSEGV **
    <snip>
    RIP=0x8a7ac9

  • Error messages similar to the following example are logged to the /var/log/apm file:

    err tmm3[<pid>]: 01790653:3: [S] 188.125.66.104:443 -> 172.29.74.12:2624: Hostname Parse Error in URL: https://<host>
