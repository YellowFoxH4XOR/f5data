Issue

Error Message

notice sod[<PID>]: 010c0049:5: Tmm ready - links up

In this error message, note the following:

  • <PID> is the process ID for the sod process.

For example:

notice sod[4784]: 010c0049:5: Tmm ready - links up

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The Traffic Management Microkernel (TMM) reaches a running state.

The sod process logs this message when the TMM is up and ready to accept traffic on the self IP addresses that the system frequently uses for failover addresses.

Impact

There is no impact; this message is a notification.

Recommended Actions

None
