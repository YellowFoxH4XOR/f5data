Known Issue

This is the result of a known issue. A BIG-IP LTM iRule can direct traffic to a pool member that is marked down. The LB::status iRule function, which was introduced in BIG-IP LTM 9.2, returns the status of a node address or a pool member. This function allows an iRule to check the status of a node address or pool member and handle the request according to the iRule requirements.

If a pool member is marked down from a monitor and the iRule is configured to direct traffic to a pool member that has a port specified, the LB_failed internal function is not invoked and the traffic is directed to the pool member that is marked down. The LB::Status iRule function allows the iRule to obtain the correct status of the pool member (in cases where the port is specified within the iRule) and handle the traffic accordingly.

F5 Product Development tracked this issue as CR64175 and it was fixed in BIG-IP LTM 9.1.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.
