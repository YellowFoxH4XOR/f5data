Known Issue

When you upgrade the BIG-IQ system, the upgrade carries forward the /var/config/rest/config/restjavad.properties.json file in the UCS archive, and the file from the ISO file does not deploy. This is by design so that the restjavad.properties.json file, which is intended for BIG-IQ administrators to use to optionally set customized values to override default behavior, is preserved after the upgrade. In previous BIG-IQ releases, some F5-defined default property values are inadvertently incorporated in the file that comes in the ISO. The result is that, after an upgrade, the file that the system carries forward does not contain the F5-defined properties, such as global, aws, or azure. You must edit these properties for certain F5-recommended customizations, as described in the following articles:

  • K54909607: BIG-IQ Centralized Management compatibility with F5 Application Services 3 Extension and F5 Declarative Onboarding
  • K97233143: Adding a new instance type for the AWS or Azure cloud environment on the BIG-IQ system

This issue occurs when all of the following conditions are met:

  • The restjavad.properties.json file is included in the UCS archive, which is the default behavior.
  • You upgrade the BIG-IQ system from BIG-IQ 5.1.0 or later to a version up to and including BIG-IQ 7.1.0.

Impact

The BIG-IQ system does not have the F5-defined default properties in the restjavad.properties.json file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you upgrade the BIG-IQ system, the restjavad.properties.json file is missing F5-defined default properties.

Workaround

To work around this issue, you can obtain a version of the restjavad.properties.json file from an ISO file that is appropriate to the version running on your BIG-IQ system. To do so, perform the following procedure:

Impact of procedure: This procedure overwrites the current restjavad.properties.json file and any custom settings are lost. You must re-add custom settings to the new file from the backup of the original you create.

  1. Download the same BIG-IQ ISO file as the version running on your BIG-IQ system from F5 Downloads. This file is likely already stored in your /shared/images directory. If so, you can skip to step 3.
  2. Use an SCP client to copy the ISO file to the /shared/images directory of the BIG-IQ system.
  3. Log in to the BIG-IQ command line and change the working directory to /shared/images:

    cd /shared/images

  4. Use the following one-liner syntax to extract the restjavad.properties.json file from the ISO file to the /shared/images directory. The command creates a var/config/rest/config sub directory structure within the /shared/images folder.

    isoinfo -i <ISO file name> -R -x /BIGIQ<version without dots>/i686/f5-rest-java-host-<version>-<build number>.i686.rpm | rpm2cpio - | cpio -idv ./var/config/rest/config/restjavad.properties.json

    For example:

    isoinfo -i BIG-IQ-7.0.0.1-0.0.6.iso -R -x /BIGIQ7001/i686/f5-rest-java-host-7.0.0.1-0.0.6.i686.rpm | rpm2cpio - | cpio -idv ./var/config/rest/config/restjavad.properties.json

    If the build number is not in the ISO file name, you can use the following syntax to obtain it:

    isoinfo -i <ISO file name> -R -x /BIGIQ<version without dots>/VERSION |egrep '^Build'

    For example:

    isoinfo -i 7.0.0.1.iso -R -x /BIGIQ7001/VERSION | egrep '^Build'

  5. Back up the original JSON file by entering the following command that uses brace expansion for the filename arguments:

    cp /var/config/rest/config/restjavad.properties.json{,.orig}

  6. Install the new JSON file by entering the following command:

    cp /shared/images/var/config/rest/config/restjavad.properties.json /var/config/rest/config/

    Enter y  to confirm the overwrite of the file.

  7. If necessary, re-add custom settings to the new file from the backup of the original you created in step 5.
  8. Optional: Remove the directories and files you extracted in the /shared/images folder:

    rm -r /shared/images/var/

    Enter y to confirm what rm is deleting, or, if you know you haven't made any typographical errors with the command, enter n and enter the command again with the addition of the -f option to suppress the confirmations.
