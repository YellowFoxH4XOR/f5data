Topic

This article applies to BIG-IP 10.x. For information about other versions, refer to the following article:

  • K16885: Controlling the BIG-IP ARP and ICMP echo response behavior for a virtual address

Disabling a virtual server prevents the virtual server from accepting new connections. A disabled virtual (even a deleted virtual) will continue to process existing connections, and the virtual address still advertises through Address Resolution Protocol (ARP).

To prevent BIG-IP LTM from advertising through ARP for a virtual address, you must disable ARP at the virtual address level. You can disable ARP for a virtual address through the Configuration utility, or the command line. To do so, perform one of the following procedures:

Using the Configuration utility to disable ARP for a virtual address

  1. From the Configuration utility, click Local Traffic.
  2. Navigate to Virtual Servers > Virtual Address List.
  3. Click the Virtual Address to be modified.
  4. Clear the ARP check box.
  5. Click Update.

Using the tmsh utility to disable ARP for a virtual address

  1. Log in to Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Disable ARP for the desired virtual server by typing the following command:

    modify ltm virtual-address <virtual_address> arp disable

    In the previous command, note the following:
    • <virtual_address> is the IP address of the virtual address in question.
  3. Save the change by typing the following command:

    BIG-IP 10.1.0 and later:

    save sys config

    BIG-IP 10.0.x:

    save config
