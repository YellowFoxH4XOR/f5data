Known Issue

You cannot use the tmctl -d blade command with a custom SNMP management information base (MIB).

This issue occurs when all of the following conditions are met:

  • You are using an SNMP custom MIB.
  • You have a custom script that calls the tmctl -d blade command, which gathers information for the custom SNMP MIB.

Impact

You are unable to configure a custom MIB to gather data using the tmctl -d blade command.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tmctl -d blade commands that you run in an SNMP custom MIB fail.

Resolution

Workaround

To work around this issue, instead of calling the tmctl -d blade, use the following command:

tmctl -d /var/tmstat/blade

Impact of workaround: Using the alternative command should not have a negative impact on your system.
