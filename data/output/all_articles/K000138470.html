Description

The small size of /shared directory might cause many issues. You might have issue in importing image to BIG-IP VE, when /shared size is too small. In the following example, /shared directory was only 477M , however the image size is typically 2G.

/dev/mapper/vg--db--vda-dat.share 477M 363M 85M 82% /shared

This article explains how you can increase the size of /shared directory.

Environment

  • BIG-IP VM
  • Not enough space in the directory /shared
  • Disk has enough free space to increase size of /shared directory

Cause

Not enough space in the directory /shared

Recommended Actions

Check the current directory size, in the following example /shared is 2048000KB or 2 GB.

# tmsh show sys disk directory

Directory Name         Current Size  New Size
--------------         ------------  --------
/config                2273280     
/shared                2048000   

You can change the /shared directory size:
# tmsh modify sys disk directory <directory name> new-size <new directory size in 1KB blocks>


For example, use following to increase the size of /shared directory to 15360000 1KB blocks (or roughly 15GB).
# tmsh modify sys disk directory /shared new-size 15360000


You can check new directory size using command.

# tmsh show sys disk directory
Directory Name         Current Size  New Size
--------------         ------------  --------
/config                2273280       
/shared                2048000       15360000


Please note that new size will take effect after the next reboot of the BIG-IP VM.

# tmsh show sys disk directory
Directory Name         Current Size  New Size
--------------         ------------  --------
/config                2273280       
/shared                15360000
