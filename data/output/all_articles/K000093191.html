K000093191: Renewing an SSL certificate in Configuration Utility but the "Renew" button is missing

Type
Support Solution
Published
2022-12-09
Updated
2023-01-03
Source
https://my.f5.com/manage/s/article/K000093191

Description

You are attempting to renew an SSL Certificate from CA using Configuration Utility but the "Renew" button is missing.

Environment

  • BIG-IP LTM
  • SSL Certificate & Key pair from CA
  • Configuration Utility

Cause

The Certificate and Key you are trying to renew are not associated with each other. This happens if you import them separately and provide your certificate with a different name than the key's name you are importing.

 Recommended Actions

  1. Import your SSL Certificate & Key pair providing the same name for both.
  2. The "Renew" option should now be available.
