Description

On GUI, L7 Dynamic Signatures status is Unready.

When the following CLI command to give output of the info.learning signal is run:

admd -s vs./Common/<name-of-virtual-server>HTTP_VS+/Common/<name-of-protection-profile>.info.learning

the output shows the signal values: [baseline_learning_confidence, learned_bins_count , good_table_size , good_table_confidence]

'baseline_learning_confidence' varying between 50 and 90%
'learned_bins_count' > 0
'good_table_size' > 4000
'good_table_confidence' equal to 100%

Environment

  • Unready for L7 Dynamic Signatures
  • Ready for L4 Dynamic Signatures 

Cause

Dynamic Signatures state 'Unready' is about L3/4 signatures, and not L7 ( bados ) signatures.
 

Recommended Actions

None.

Additional Information

For L3/4 dynamic signatures, baseline learning_confidence even being greater than zero is good enough. 

Learning should be [>0, X,X, 100] in order to be ready to create signatures under attack.

Furthermore, in the case of short attack or weak attack it's possible that dynamic signatures will not be created.

However, staging ( temporary ) signature are likely to be generated.
