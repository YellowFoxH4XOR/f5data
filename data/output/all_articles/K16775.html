Known Issue

The Traffic Management Microkernel (TMM) may restart when a Security Assertion Markup Language (SAML) single logout (SLO) request or response contains an invalid Issuer attribute.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured as either of the following:
    • SAML Identity Provider (IdP) with SLO
    • SAML service provider (SP) with SLO
  • Your BIG-IP APM system receives an SLO request or response that contains an Issuer attribute, for which there is no currently established session.

Impact

The BIG-IP APM system temporarily fails to process traffic while the tmm process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP APM system temporarily fails to process traffic while the tmm process restarts.
  • Your BIG-IP system generates a SIGSEGV fault and stack trace in the /var/log/tmm file.
  • TMM generates a core file to the /shared/core directory.

Workaround

There is no workaround for this issue; however, you can disable SAML SLO in your environment to prevent TMM from restarting.
