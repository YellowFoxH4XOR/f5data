Description

When an ASM security policy is applied to a virtual server that handles a large volume of HTTP requests with complex or large JSON payloads, such as an API gateway, ASM CPU usage may increase.

The ASM engine process's CPU usage, "bd", can be monitored using Linux commands such as "top" or "ps".

You can also review the asm_cpu_util_stats tmstat table for relative comparison across virtual servers over time.

tmctl asm_cpu_util_stats

Environment

  • BIG-IP AWAF/ASM
  • JSON content profile with Parse Parameters option enabled
  • Virtual server handling a large volume of HTTP requests with complex or large JSON payloads

Cause

Enabling Parse Parameters in the JSON content profile properties can increase CPU usage due to the additional processing overhead required to parse the JSON payload. This is especially noticeable when inbound HTTP requests contain complex or large JSON payloads.

This option is enabled by default for newly created JSON content profiles and in the default Default JSON profile.

Recommended Actions

Disable Parse Parameters if CPU performance is significantly affected.

Security ›› Application Security : Content Profiles : JSON Profiles ›› JSON Profile Properties

Additional Information

When the Parse Parameters option is enabled in a JSON content profile, JSON signatures, metacharacter checks, and sensitive data enforcement are performed in the parameter context.

This allows more granular enforcement control, such as:

  • Applying JSON signature exceptions to a specific JSON key
  • Using SSRF protection that performs DNS resolution for domain lookup to verify allowed URIs, which only works in the parameter context.

If your security posture requires features that are only available when Parse Parameters is enabled, please work with a sizing expert and F5 Support to determine appropriate CPU sizing recommendations.
