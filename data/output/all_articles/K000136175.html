Description

Updating the Internal Dev Portal Hostname within a Developer Portal configuration fails with the following error:

A given cluster name cannot be re-used in the same environment in a given runtime

Environment

NMS/ACM

Cause

The internal Dev Portal Hostname cannot be the same name as a hostname provided for a Developer Portal cluster.

Recommended Actions

Update the internal Dev Portal Hostname to something different than a hostname that was already provided for a Developer Portal cluster.

Additional Information

By default, the internal Dev Portal server is the hostname provided for the Developer Portal cluster, prefixed with acm.. For example: acm.dev-portal.io.

The internal Dev Portal Hostname must be resolvable from the NMS/ACM server.
