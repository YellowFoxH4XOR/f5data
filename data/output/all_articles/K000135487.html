Description

AWAF webhooks predefined variables

 

Environment

BIG IP ASM AWAF

Cause

N/A

Recommended Actions

The supported events and placeholders are:

 

Events:

 

  1. Apply Policy
  2. Apply Policy Failed
  3. Illegal Request
  4. Request Needing Examination
  5. Likely Malicious Request
  6. Incident Start
  7. Incident End

 

Placeholders:

 

  1. policy - name, enforcementMode
  2. request - clientIp, enforcementAction, method, url, rating, host, schema (http/https/ws/wss), id
  3. incident - incidentType, requestCount, incidentSeverity, durationInSeconds
  4. device - hostname, version
