Description

It is observed that the BIG-IP is not broadcasting OSPF Hello packets to its neighbors. This can be confirmed from tcpdump.

Environment

This issue occurs when all of the following conditions are met:

  • OSPF has already been enabled on all BIG-IP systems.
  • The BIG-IP systems are configured as OSPF peers.

Cause

Unknown at the time of publication.

Recommended Actions

To resolve the issue, you will need to restart the tmrouted service.

  1. Login to the BIG-IP command line.
  2. Type the following command
    bigstart restart tmrouted
