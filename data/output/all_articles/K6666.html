Known Issue

This is the result of a known issue. If BIG-IP ASM receives an HTTP request without a host header, the BIG-IP ASM bd process may crash.

F5 Product Development tracked this issue as CR69197 and CR69206 and it was fixed in BIG-IP ASM 9.2.4, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP ASM release notes.
