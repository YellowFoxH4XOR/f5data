K000140637: Adding secondary BIG-IQ HA returns "400 Bad Request. /dev/stdin is not a public key file"

Type
Support Solution
Published
2024-08-09
Updated
2026-05-21
Source
https://my.f5.com/manage/s/article/K000140637

Description

BIG-IQ fails to add Secondary BIG-IQ to cluster under System > BIG-IQ HA > Add Standby with "The system returned an unexpected error (400 Bad Request). /dev/stdin is not a public key file" in the WebUI after clicking Add:

 

The restjavad logs in /var/log/ directory shows similar error:

[INFO][09 Jul 2024 17:00:04 CEST][/shared/ssh-trust-setup SshTrustSetupWorker] /usr/bin/f5-ssh-fingerprint has failed with status code 255.

Stdout:

Stderr: /dev/stdin is not a public key file.

Environment

  • BIG-IQ Centralized Management 8.x
  • Configuring BIG-IQ HA
  • Modified sshd ciphers configuration

Cause

This error is due to sshd configuration missing ssh-rsa HostKeyAlgorithms on both BIG-IQ units which is required under the current design for BIG-IQ HA to function properly.  
HostKeyAlgorithms ssh-rsa is not only required for adding Standby BIG-IQ without the error but also required for BIG-IQ failover to work properly.

Recommended Actions

  • Check if HostKeyAlgorithms in sshd configuration has ssh-rsa included.

    # tmsh list sys sshd all-properties
  • If HostKeyAlgorithms doesn't include ssh-rsa, edit sshd configuration and modify the include statement to add ssh-rsa into HostKeyAlgorithms.

    For example;

    #tmsh

    # edit /sys sshd all-properties

    (once vi opens, go to the include statement and add ssh-rsa at the end of HostKeyAlgorithms)

     

      include "Ciphers aes128-ctr,aes192-ctr,aes256-ctr

      MACs hmac-sha2-256,hmac-sha2-512

      KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384,diffie-hellman-group-exchange-sha256

      HostKeyAlgorithms ecdsa-sha2-nistp256,ecdsa-sha2-nistp384,ecdsa-sha2-nistp521,ssh-ed25519,rsa-sha2-512,rsa-sha2-256,ssh-rsa"

     

    (Save changes in vi, then hit y for the prompt below)

    Save changes? (y/n/e) y

     

    # save sys config
