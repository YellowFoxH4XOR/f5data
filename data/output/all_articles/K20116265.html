Topic

This article breaks down the information presented in the Advanced Shell (bash) prompt for a user on a VIPRION platform.

Description

The Advanced Shell (bash) prompt on a VIPRION system provides the user with useful information regarding the state of the system. The following sections break down each of the areas based on the following example prompt:

[<user>@<hostname>:/<slot#>-<slot_status>-<slot_designation>:<failover_status>:<HA_status>]~#

In this example prompt, note the following:

  • <user> is the name of the logged in user.
  • <hostname> is the host name for the BIG-IP system.
  • <slot#> is the number for the current slot/blade you are logged in to.
  • <slot_status> denotes the current status for the slot, and will be one of the following:
    ColorStatus
    redOffline
    greenActive
    greyStandby
  • <slot_designation> denotes whether the slot is currently the primary slot (P) or secondary slot (S).
  • <failover_status> denotes the current failover status of the device, and will be one of the following:
    StatusDescription
    ActiveThe device is active.
    StandbyThe device is standby.
    OfflineThe device is offline.
    ForcedOfflineThe device is forced offline.
    UnknownThe failover status of the device is unknown.
    INOPERATIVENot working or taking effect.
    No LicenseLicensing needed.
    LICENSE EXPIREDReinstate license.
    REBOOT_REQUIREDReboot needed.
  • <HA_status> indicates whether the cluster member is used in a redundant system configuration for high availability (HA), and shows its current HA status.

    For example, the following prompt indicates that the root user is logged in to slot 1, the primary slot for the cluster, and that the slot is currently active:

    [root@V1.example.com:/S1-green-P:Active:Standalone]~#
