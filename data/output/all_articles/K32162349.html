Issue

Error Message

warning mcpd[<PID>]: 01070995:4: get_tmstat: tmstat_sample not ready. Statsd may not be running

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.

For example:

warning mcpd[6174]: 01070995:4: get_tmstat: tmstat_sample not ready. Statsd may not be running

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP system attempts a statistical query but fails to subscribe to the associated directory.

You typically see this message when the statsd process is not running or is not ready, or when the BIG-IP system is experiencing an out-of-memory condition.

Impact

The statistical query fails.

Recommended Actions

You should verify that the statsd process is running, and restart the process if it is not in the run state.  To do so, perform the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Verify that the statsd process is running by typing the following command:

    show /sys service statsd

    Output should appear similar to the following example:

    statsd       run (pid 7059) 4068 days

  3. If the statsd process is not in the run state, restart the statsd process by typing the following command:

    restart /sys service statsd
