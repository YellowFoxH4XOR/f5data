K000150589: Incompatibility of HTML Content Profiles with HTTP/2 and MRF Configuration

Type
Support Solution
Published
2025-03-27
Updated
2025-03-27
Status
Final
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000150589

Description:

 

HTML content profiles are incompatible when having MRF enabled in a Virtual Server. For example, if an iRule contains the HTML_TAG_MATCHED event, after enabling the MRF in the virtual server you might encounter the error: "Configuration error: Profile(s) found on <VS name> that are not allowed: Only (TCP Profile, UDP profile, QUIC Profile, ClientSSL profile, ServerSSL Profile, ...)"

 

Environment:

 

  • Product: BIG-IP
  • HTML Content Profile
  • HTTP/2Message Routing Framework (MRF)

 

Cause:

 

 HTTP/2 configurations using Message Routing Framework (MRF) are incompatible with the use of an HTML content profile, which is required for triggering events like HTML_TAG_MATCHED.

 

Example:

Scenario 1: HTTP/2 profile attached, HTML content profile attached (for HTML_TAG_MATCHED event) - Works fine.

Scenario 2: HTTP/2 profile attached, HTML content profile attached (for HTML_TAG_MATCHED event), when trying to enable MRF in the Virtual Server (VS) results in the following error:

Configuration error: Profiles(s) found on </Partition/VS_Name/ are not allowed: Only (TCP Profile, UDP Profile, QUIC Profile, ClientSSL Profile, ServerSSL Profile, HTTP Profile, HTTP2 Profile, HTTP3 Profile, HTTP Compression Profile, Application Visibility and Reporting Profile, DNS Profile, DOH Proxy Profile, profile statistics, Protection Profile, Bot Defense Profile, Bot Defense ASM profile, Web Security Profile, HTTP Router Profile, Web Accelerator Profile, Request Logging Profile, TDR Profile, ATI Profile, BD Profile, CSD Profile, AP and AI Profile) 

 

Recommended Actions:

 

Disable MRF if Possible:If MRF is not strictly required for your deployment, consider disabling it to allow compatibility with the HTML content profile and enable events like HTML_TAG_MATCHED.
