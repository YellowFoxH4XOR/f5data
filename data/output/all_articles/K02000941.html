K02000941: Portal Access stopped working with one web page

Type
Support Solution
Published
2020-04-17
Updated
2024-11-22
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 14.1.2
Source
https://my.f5.com/manage/s/article/K02000941

Description

When the user clicks on one of the icons on their PA application, the page is not loaded through Portal Access - they just get an empty webpage.

Environment
  • BIG-IP APM 14.1.2
  • Chrome
  • Portal Access
  • NetIQ Sentinel
Cause

This is a Chrome issue (non standard behavior at very specific conditions: namely inheritance of window properties from previous document in window).

Recommended Actions

Apply this iRule to the VS in use:

when REWRITE_REQUEST_DONE {
  if {
    [HTTP::path] ends_with "/com.novell.siem.proof.Main.nocache.js"
  } {

    # log "URI=([HTTP::path])"
    # Found the file we wanted to modify

    REWRITE::post_process 1
    set do_fix 1
  }
}

when REWRITE_RESPONSE_DONE {
  if {[info exists do_fix]} {
    unset do_fix

    set str { F5_Deflate_location( /*_5F##*/ a.contentWindow /*F5_*/ ) /*_5F#.location#*/  /*F5_*/ }
    set strlen [string length $str]

    set strt [string first $str [REWRITE::payload]]

    if {$strt > 0} {
      REWRITE::payload replace $strt  $strlen { /*_5F##*/ a.contentWindow.location }
    }
  }
}
