Description

Loading a configuration info BIG-IP Advanced Routing configuration shell for ZebOS (imish) can result in the last character of the final line of the configuration to be missing. This is most commonly observed with the Ansible bigip_imish_config module, but can also be seen using the imish -f <filename> function to load configuration from disk file.

Environment

  • BIG-IP
  • Advanced Routing enabled
  • Ansible (optional)

Cause

Bug ID 1018309

Recommended Actions

A workaround would be to add a sacrificial character to the end of your bigip_imish_configuration input for affected versions, so that the target appears correctly.

Additional Information

None at time of publication.
