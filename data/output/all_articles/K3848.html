Topic

Beginning in BIG-IP 9.0.0, the BIG-IP system does not include the RSH, Telnet, and FTP daemons.

The RSH, Telnet, and FTP daemons were included in previous versions of the BIG-IP system because several international export restrictions did not allow F5 to ship SSH with the BIG-IP system.

These export restrictions have since relaxed. F5 now ships SSH with the BIG-IP system to all countries, making the inclusion of the RSH, Telnet, and FTP daemons redundant.

In addition, F5 has discontinued shipping RSH, Telnet, and FTP daemons because they provide access to the system using protocols that are not secure, which may result in a security breach.
