Topic

HTTP profiles configured with explicit proxy mode are not compatible with connection mirroring.

Description

Enabling connection mirroring on a virtual server configured with an HTTP profile in explicit proxy mode is unsupported and can cause traffic disruptions. This also applies to any secondary virtual servers that listen on the tunnels used by the HTTP explicit proxy.

Recommendations

Ensure connection mirroring is not enabled for virtual servers using HTTP profiles in explicit proxy mode or on secondary virtual servers listening on the tunnels used by the HTTP explicit proxy.
