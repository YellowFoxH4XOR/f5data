Known Issue

Using the Traffic Management Shell (tmsh) to view configuration objects may fail.

This issue occurs when all of the following conditions are met:

  • You log in to the BIG-IP command line as root.
  • You run (or a script runs) one of the following tmsh global commands: 
    • list
    • list one-line
    • show running-config

Impact

The tmsh command fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to run the tmsh commands, the system displays an error similar to the following example:

    Unexpected Error: Can't display all items, can't get object count from mcpd
