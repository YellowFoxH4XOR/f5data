Topic

The Network Access Client proxy settings feature requires Microsoft Internet Explorer 5.0 or later on the client machine. FirePass does not currently support this feature for Mozilla Firefox or other browsers.

For FirePass version 5.2 and later, you can configure Client proxy settings under the Client Settings tab on the Network Access: Resources page. For FirePass version 5.0, you can configure Client proxy settings under the Client Settings tab on the Network Access: Group-based Settings page.

F5 Networks Product Development is tracking this enhancement request as CR86150.

Note: If a user connects to the FirePass controller using a browser other than Internet Explorer, and the browser is manually configured to use a proxy server, the browser will continue to route traffic to the proxy server even after the user establishes an SSL VPN connection. If the proxy server is not reachable through the SSL VPN tunnel, the user cannot view any web pages. If the proxy server is reachable through the SSL VPN tunnel, the user can view external (Internet) web pages but not internal web pages.
