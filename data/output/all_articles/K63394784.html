Description
How to manage ASM Bot Defense profiles using REST API

Environment

  • ASM provisioned
  • Bot Defense Profiles

Cause
N/A

Recommended Actions

All commands below are run locally on the BIGIP CLI using restcurl, they can all be run externally using the following syntax:

 # curl -s -k –user username:password -H “Content-Type: application/json” -X GET https://x.x.x.x/copy/path/from/restcurl/command
  • Replace your admin username and password
  • Replace x.x.x.x with your BIGIP’s IP address.

How to obtain a list of all Bot Defense profiles:

# restcurl -u admin:admin /mgmt/tm/security/bot-defense/profile?%24select=name,selfLink
    "bot-defense -- https://localhost/mgmt/tm/security/bot-defense/profile/~Common~bot-defense?ver=15.1.3.1"
    "bot-defense-device-id-generate-after-access -- https://localhost/mgmt/tm/security/bot-defense/profile/~Common~bot-defense-device-id-generate-after-access?ver=15.1.3.1"
    "bot-defense-device-id-generate-before-access -- https://localhost/mgmt/tm/security/bot-defense/profile/~Common~bot-defense-device-id-generate-before-access?ver=15.1.3.1"
    "bot-defense-device-id-none -- https://localhost/mgmt/tm/security/bot-defense/profile/~Common~bot-defense-device-id-none?ver=15.1.3.1"
    "bot-defense-upgraded-from-jha_dos_20191216 -- https://localhost/mgmt/tm/security/bot-defense/profile/~Common~bot-defense-upgraded-from-jha_dos_20191216?ver=15.1.3.1"
