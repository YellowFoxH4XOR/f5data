K000149622: Error "Memory is out of range", when attempting to allocate additional memory to F5OS tenant

Type
Support Solution
Published
2025-02-04
Updated
2025-02-04
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000149622

Description

I want to increase Tenants' memory, however, when I try the following error is produced:

 

Server Error(s)

/tenant/tenant{f5-itf}/config: Memory is out of range. Max allowed Memory Size: 24674MB

 

^ Hide Details

error-type : application

error-tag : malformed-message

error-path : /f5-tenants:tenants/tenant[name='f5-itf']/config

error-message : /tenants/tenant{f5-itf}/config: Memory is out of range.

Max allowed Memory Size: 24674MB

 

Environment

F5OS Partition

Tenant memory allocation

 

Cause

The error indicates the requested amount of memory exceeds the available amount of memory.

 

Recommended Actions

1) Check https://techdocs.f5.com/en-us/f5os-a-1-8-0/f5-rseries-systems-administration-configuration/title-tenant-management.html#tenant-overview to see how much total memory is available for tenants to use.

 

For example

R4600 allows for 48GiB (49152MiB) memory for Tenants to use.

 

 

 

2) Run "system_manager - /confd/scripts/f5_confd_run_cmd show tenants" to determine how much memory is currently allocated to each tenant. Pay attention to the state memory values.

 

For example:

 

system_manager - /confd/scripts/f5_confd_run_cmd show tenants

3) Subtract the amount of memory currently allocated to tenants from the total available for tenants, to determine the remaining memory available for tenants.

 

Tenant "f5-inside" state-memory + Tenant "f5-outside" state-memory:

24576MiB + 12288MiB = 36864MiB (36GiB) total used by tenants.

 

47104MiB - 36864MiB = 10240MiB (10GiB) remaining for Tenants
