Policy Information

F5 introduced the Cluster Log Consolidation feature in FirePass 6.0.0. This feature allows cluster logs to be consolidated on the master node in a FirePass cluster. Because of limited demand and limited use for this feature for an enterprise-scale cluster deployment, F5 no longer supports this feature in FirePass. As a result, F5 can focus on enterprise-class solutions that provide a higher value to our customers and partners.  F5 recommends that you use an external syslog server to consolidate logs for enterprise cluster deployments.

Product update

F5 announces plans to end support for the Cluster Log Consolidation feature in FirePass. This applies to all fully-licensed FirePass products:

Product support

For those customers using the Cluster Log Consolidation feature, F5 will continue to provide phone support in accordance to the customer's maintenance contracts. As of the End of Software Development (EoSD) date of June 15, 2007, F5 will not provide software fixes for any technical issues surrounding the Cluster Log Consolidation feature.

Questions

If you have questions about F5's decision to discontinue this feature, contact your local F5 representative or service department.
