Description

You want ot check via GUI the live connection table to analyse the traffic.

Environment

  • BIG-IP
  • Statistics in GUI

Cause

BIG-IP LTM version 17.5.1 does not include a native GUI feature to display a live, real-time system-wide connection table. The AVR module only provides historical data, and real-time connection visibility is limited to CLI access.

Recommended Actions

Use the CLI command to view real-time connection information:

tmsh show sys connection

For GUI-based or system-wide live connection table visibility, consider integrating with external monitoring solutions or third-party tools if required.

Monitor F5 release notes for future enhancements regarding GUI-based real-time connection monitoring.
