Known Issue

Under rare conditions, virtual servers that reference a Web Acceleration profile cause the Traffic Management Microkernel (TMM) to produce a core file.

This issue occurs when all of the following conditions are met:

  • The virtual server references a Web Acceleration profile.
  • The BIG-IP caching engine attempts and fails to match an ETag in the header field.

Impact

BIG-IP systems that are part of a high availability (HA) configuration fail over to a peer system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process produces a core file with a SIGABRT message.
  • A BIG-IP system in an HA configuration fails over to the peer system.
  • The BIG-IP system generates a TMM core file in the /var/core directory.
