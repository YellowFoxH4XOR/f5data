Issue

Starting in BIG-IP WebAccelerator 10.1.0, the pvac service's memory manager has been enhanced to improve performance and stability. Specifically, the pvac service's memory manager now releases cached objects from memory more efficiently to improve response times and prevent memory leaks.

Previously, in environments where the BIG-IP WebAccelerator had to assemble large, complicated documents with numerous links, delayed responses and timeouts could occur. Additionally, memory leaks could occur, potentially resulting in system instability.

F5 Product Development tracked this enhancement as ID 208587 (formerly CR122614).
