Topic

Starting in FirePass version 6.0.3, the FirePass controller supports DHCP Relay. DHCP client support on FirePass allows an external DHCP server to manage IP network access pools, per resource group. DHCP clients and DCHP relay agents exist in a DHCP-managed network. DHCP relay agents are commonly deployed in routers to relay broadcast DHCP client requests to a single or set of DHCP servers. When DHCP relay has been configured on your FirePass controller, it behaves the same as any other DHCP relay device. The FirePass controller requests an IP address from the DHCP server every time a Network Access connection is initiated by a FirePass user. After receiving a DHCP IP address from the DHCP server, FirePass assigns the IP address to the requesting Network Access connection.

Configuring your FirePass controller to use DHCP relay

To configure your FirePass controller to use DHCP relay, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Network Access : Resources.
  3. In the Configure IP Address Assignment section, select the Retrieve IP Address from designated DHCP Server (second priority) check box.
  4. In the Configure DHCP Server and Relay Agent Address section, populate the DHCP Server address field with the IP address of your DHCP server.
  5. Click the Update button.

FirePass is not able to create dynamic DNS records, just like any other DHCP relay device. The DHCP server manages dynamic DNS updates. If dynamic DNS is not working correctly, reference documentation from your DHCP server vendor.
