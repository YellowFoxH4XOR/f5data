Topic

You should consider using this procedure under the following condition:

  • You want to locate the registration key of your BIG-IP Virtual Edition (VE) system

Description

If you encounter an issue that requires F5 Support assistance, you must locate the base registration key of the BIG-IP VE system and provide the last seven digits to the F5 Support representative. To display the registration key, refer to the following procedures:

Note: For information about finding the serial number or registration key of your other F5 products, refer to K917: Finding the serial number or registration key of your F5 device. The serial number can also be found in the sales order details, and it starts with the letter Z.

Note: For instructions describing how to activate the license on a BIG-IP system refer to K7752: Licensing the BIG-IP system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have access to the TMOS shell (tmsh) or the Configuration utility.

Procedures

  • Displaying the registration key using the TMOS shell (tmsh)
  • Displaying the registration key using the Advanced Shell (bash)
  • Displaying the registration key using the Configuration utility
  • Obtaining the registration key for an unlicensed system

To watch a video demo of the Configuration utility procedure, go to  K000150135: Finding the serial number or registration key of your BIG-IP system. 

Displaying the registration key using the TMOS shell (tmsh)

To display the BIG-IP VE registration key from tmsh, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. To display the BIG-IP VE registration key, enter the following command:

    tmsh /show sys license

    The Sys::License section of the command output displays the registration key and appears similar to the following example:

    Sys::License
    Licensed Version                       15.1.0
    Registration key                       E1568-80187-36956-12679-8840999
    Licensed On                            2020/02/24
    License Start Date                     2020/02/23
    License End Date                       2020/03/26
    Service Check Date                     2020/02/24
    Platform ID                            Z100
    Daily Renewal Notification Days        5
    Daily Renewal Notification Start Date  2020/03/21
    Permitted Versions                     5.*.* - 18.*.*

Displaying the registration key using the Advanced shell (bash)

To display the BIG-IP VE registration key from the Advanced shell (bash), perform the following procedure:

  1. Log in to the command line.
  2. Enter the following command:

    grep Reg /config/bigip.license

    The command displays the registration key.

    For example:

    Registration Key :                 E1568-80187-36956-12679-8840999

Displaying the registration key using the Configuration utility

To display the BIG-IP VE registration key using the Configuration utility, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to System > License.
  3. Select Re-activate.
  4. After the license activation page loads, locate the Base Registration Key.

    For example,

    Base Registration Key E1568-80187-36956-12679-8840999
