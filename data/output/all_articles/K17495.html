Known Issue

Upgrade may fail with the No definition found for none error message.

This issue occurs when the following condition is met:

  • You modify the default Client Secure Sockets Layer (SSL) profile prior to the upgrade using a command that appears similar to the following example:

    tmsh modify ltm profile client-ssl clientssl defaults-from none

Impact

The upgrade fails after booting into the new release, during the configuration loading phase. This issue occurs because the script extracts the line defaults-from none and treats none as the parent profile.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You view messages in the /var/log/liveinstall.log file that appear similar to the following example:

    info: ERROR: No definition found for none
    info: Operation aborted.
    info: >----
    Terminal error: No definition found for none

  • The BIG-IP configuration fails to roll forward.

Workaround

To work around this issue, you can manually edit the /config/bigip.conf file, removing the defaults-from none line from the default Client SSL profile prior to upgrade. To do so, perform the following procedure:

Impact of workaround: Because the BIG-IP system failed to load the configuration, the system should be in INOPERATIVE mode at this stage. You will need to reboot the system to the original boot location, make the modification, and perform the upgrade again. Performing this procedure should not have any further impact on the BIG-IP system.

  1. From the pre-upgraded boot location, log in to the BIG-IP system command line.
  2. Create a backup copy of the /config/bigip.conf configuration file by typing the following command:

    cp /config/bigip.conf /var/tmp/bigip.conf.sol17495

  3. Using your preferred text editor, modify the /config/bigip.conf file, and locate the default ltm client-ssl profile.

    For example:

    ltm profile client-ssl /Common/clientssl {
    ...
    }

  4. Look for the line defaults-from none in that section, and remove only that line.
  5. Save the changes and exit the text editor.
  6. Reload the configuration by typing the following command:

    tmsh load /sys config

  7. Perform the BIG-IP system upgrade.
