Topic

This article applies to BIG-IP 10.x through 11.2.1. For information about other versions, refer to the following article:

  • K79544554: Configuring attack signatures for a parameter

    Description

    By default, all parameter-specific attack signatures that are enabled in the security policy are enforced on all user-input, alpha-numeric parameters. Parameter-specific attack signatures that are disabled in the security policy are disabled for the specific parameter.

    Under certain circumstances, you may want to change an attack signature state for a given parameter. For example, you may want to disable an attack signature for the parameter while leaving it enabled for the rest of the security policy. Conversely, you may want to enable an attack signature for a given parameter while leaving it disabled for the rest of the policy.

    To change the state of a specific attack signature for a specific parameter, perform the procedure applicable for your BIG-IP ASM version:

    BIG-IP ASM 11.1.0 through 11.2.1

    1. Log in to the Configuration utility.
    2. Navigate to Application Security > Security Policies.
    3. Click the relevant security policy.
    4. Click Parameters.
    5. From the Parameters List, click the relevant parameter.
    6. Click the Attack Signatures tab.
    7. In the Global Security Policy Settings box, select the attack signature for which you want to change the state, and then click the << button.

      The attack signature now appears as either Disabled or Enabled in the Overridden Security Policy Settings box.

    8. Click Update.
    9. Click Apply Policy.

    BIG-IP ASM 11.0.0 and earlier

    1. Log in to the Configuration utility.
    2. Navigate to Application Security > Web Applications.
    3. Click the relevant security policy.
    4. Click Parameters.
    5. From the Parameters List, click the relevant parameter.
    6. Click the Attack Signatures tab.
    7. In the Global Security Policy Settings box, select the attack signature for which you want to change the state, and then click the << button.

      The attack signature now appears as either Disabled or Enabled in the Overridden Security Policy Settings box.

    8. Click Update.
    9. Click Apply Policy.
