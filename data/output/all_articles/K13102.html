Known Issue

When you configure a Network Access tunnel to autolaunch an application, the application may fail to launch.

This issue occurs when all of the following conditions are met:

  • The user is running the Apple OS X operating system.
  • You have configured the FirePass network access tunnel to autolaunch an application.
  • The application that the system is going to launch contains spaces in the name.

    For example:

    Remote Desktop Connection.app

Impact

The application does not launch for the user.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Application fails to autolaunch
  • Client console logs show an error that appears similar to the following example:

    The files /Desktop and /Connection.app do not exist.
