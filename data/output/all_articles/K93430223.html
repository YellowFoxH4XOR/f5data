K93430223: High TMM memory usage and continuously increasing in persist subsystem

Type
Support Solution
Published
2020-04-03
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K93430223

Description

TMM memory is increasing very slowly over time, and most memory allocations appear in the persist TMM subsystem when reviewing the output of show /sys memory.

Environment

  • TMM Memory

Cause

One or more persistence profiles in use with timeout set to indefinite.

Recommended Actions

Re-configure persistence profiles to use an appropriate timeout value.

Additional Information

Bugs or incorrectly configured persistence may lead to memory issues in the persist subsystem. If there appears to be a leak in the TMM persist subsystem, and no persistence profile has timeout set to indefinite, open a service request with F5 support for further investigation.
