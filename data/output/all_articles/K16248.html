Known Issue

The Traffic Management Shell (tmsh) fails to display output and stops responding when you run the tmsh show sys connection all-properties command.

Impact

You cannot view the BIG-IP system's full connection table using the all-properties option, and tmsh stops responding until you abort using the Control + c keys.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are unable to view the full connection table results using the all-properties option.
  • The tmsh utility stops responding.
