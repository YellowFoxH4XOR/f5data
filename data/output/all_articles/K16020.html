Known Issue

File Transfer Protocol (FTP) connections may fail when handled by a secure network address translation (SNAT) listener instead of an FTP virtual server.

Impact

FTP data connections fail due to lack of IP address translation in the FTP PORT command.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • FTP data connections are failing.

Workaround

To work around this issue, you can create a Standard virtual server that uses an FTP profile.

Refer to the Load Balancing Passive Mode FTP Traffic chapter in the BIG-IP Local Traffic Manager: Implementations guide for your specific version.
