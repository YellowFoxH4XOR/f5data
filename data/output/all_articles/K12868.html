Known Issue

The BIG-IP ASM Charts Scheduler tool does not accept all of the valid non alpha-numeric characters in the local-part of an email address.

This issue occurs when the following conditions are met:

  • You attempt to add an email address containing one of the following characters in the local-part to the BIG-IP ASM Charts Scheduler:
    • Exclamation point ( ! )
    • Pound ( # )
    • Dollar ( $ )
    • Percent ( % )
    • Ampersand ( & )
    • Single quote ( ' )
    • Asterisk ( * )
    • Plus ( + )
    • Minus ( - )
    • Slash ( / )
    • Equal ( = )
    • Question mark ( ? )
    • Caret ( ^ )
    • Acute ( ` )
    • Left brace ( { )
    • Right brace ( } )
    • Vertical bar ( | )
    • Tilde ( ~ )

The local-part of an email address refers to the value preceding the at ( @ ) character. According to RFC5322 and RFC5321, the following non alpha-numeric characters should all be allowed if present in the local-part of an email address:

  • Exclamation point
  • Pound
  • Dollar
  • Percent
  • Ampersand
  • Single quote
  • Asterisk
  • Plus
  • Minus
  • Slash
  • Equal
  • Question mark
  • Carat
  • Underscore
  • Acute
  • Left brace
  • Right brace
  • Vertical bar
  • Tilde

Of these defined allowed non-alphanumeric characters, the BIG-IP ASM will only allow the underscore ( _ ) in the local-part of an email address.

Impact

Certain email addresses cannot receive reporting data from the BIG-IP ASM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When entering an email address into the Charts Scheduler tool, an error message similar to the following may display when you click Add:

    The E-Mail address that you have supplied is illegal.
  • When an email address has sucessfully been added to Send To (E-mails) list, an error message similar to the following may display when you click Create:

    Please enter a valid «E-Mail Address»

Workaround

To work around this issue, you can modify the email address in the BIG-IP ASM database. To do so, perform the following procedure:

Impact of workaround: None.

  1. Back up the BIG-IP ASM configuration by creating a UCS archive. For assistance creating a UCS archive, refer to SOL11318, linked in the Supplemental Information section below.
  2. In the Application Security menu of the Configuration utility, navigate to Reports > Charts > Charts Scheduler.
  3. Click Create.
  4. In the Schedule Title box, enter a name for your schedule.
  5. In the Send to (E-Mails) field, enter a valid email address that does not contain one of the problematic characters listed in this Solution.

    For example, if your email address is:

    my-name@host.com

    You would type the following:

    myname@host.com
  6. Click Create.
  7. Log in to the BIG-IP ASM command line.
  8. Log in to the MySQL database by typing the following command:

    # mysql -uroot -p`perl -I/ts/packages -MF5::GenUtils -e 'print get_mysql_password().qq{\n}'`
  9. From the mysql prompt, use the following command syntax, where <OLDEMAIL> is the email address you entered in Step 4, and <NEWEMAIL> is the correct email address:

    mysql> UPDATE DCC.REPORTING_SCHEDULE_EMAILS set email="<NEWEMAIL>" where email="<OLDEMAIL>";

    For example, to make the change with the examples provided in Step 4, you would use the folllowing command:

    mysql> UPDATE DCC.REPORTING_SCHEDULE_EMAILS set email="my-name@host.edu" where email="myname@host.com";
  10. To exit the MySQL prompt, type the following command:

    exit
