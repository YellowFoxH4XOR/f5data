Known Issue

This is the result of a known issue. When auto_lasthop is enabled, traffic from all self IP addresses will use last hop routing, rather than standard routing. Because of this, BIG-IP cannot ARP for the node addresses after the ARP entries expire.

F5 Networks Product Development tracked this issue as CR21228 and CR41772.

Workaround

You can work around this issue by disabling auto_lasthop on BIG-IP.

To disable auto_lasthop, perform the following steps:

  1. Log in to the command line.
  2. Type the following command:

    bigpipe global auto_lasthop disable

  3. Save the configuration, by typing the following command:

    bigpipe save
