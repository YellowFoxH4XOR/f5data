K000159841: VELOS partition unreachable via its management IP address after a controller reboot

Description

After a reboot of a VELOS system controller, a partition became unreachable via its management IP address.

Tenants continued to function normally and the partition appeared to be otherwise healthy.

Environment

  • F5OS-C 1.8.2
  • System controller restart

Cause

The rebooted controller experienced a restart of platform services shortly after startup, which resulted in an active/active.

When the active/active was resolved, the partition management interface in the partition containers was no longer up.

  • Bug ID 2188089: After Power Cycle testing on 1.8.2 EHF-3, observed partition mgmt interface stuck DOWN

Recommended Actions

Delete and re-create the partition management IP to restore management connectivity to the partition.

config# no partitions partition <name> config mgmt-ip
config# commit
config# partitions partition <name> config mgmt-ip <ipv4 | ipv6> address <ip address> prefix-length <length> gateway <gateway address>

Alternatively, disable and re-enable the partition.
