Description

How to find ASM policy name from BIGIQ error having REST_ID in error ?


Environment

  • BIGIQ
  • BIGIP ASM


Cause

BIGIQ errors gives ASM policy reference using REST ID and not name.


Recommended Actions

# restcurl -u admin:admin mgmt/tm/asm/policies/<Policy REST ID>'?$select=name'


 *Note: replace the "<Policy REST ID>" syntax above with the appropriate value from your error message

 *See example below:


For Example :

# restcurl -u admin:admin mgmt/tm/asm/policies/qB5caokejf-8DZiNe_1VKw'?$select=name'

{

 "kind": "tm:asm:policies:policystate",

 "selfLink": "https://localhost/mgmt/tm/asm/policies/qB5caokejf-8DZiNe_1VKw?$select\u003dname\u0026ver\u003d13.1.1",

 "name": "Test_Policy_1" <----- Policy Name

}
