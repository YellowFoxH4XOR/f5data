Known Issue

The ping license-server command may attempt to use an internal F5 license server that is not available outside of F5's internal network.

This issue occurs when the following condition is met:

  • The ping license-server command is used without specifying the optional base-reg-key <base_key> command option.

Impact

Connectivity to the F5 license server is not verified.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The ping license-server command will fail with the following error message:

         ping license-server % ERROR: LICENSE_SERVER_DNS_LOOKUP_FAILED (46334047):
         Could not look up IP address for license server 'authem.f5net.com'.

Workaround

Impact of workaround: None.

To work around this issue, you can specify the optional base-reg-key <base_key> command option when using the ping license-server command.

For example:

ping license-server base-reg-key ABCDE-FGHIJ-KLMNO-PQRST-UVWXYZA
