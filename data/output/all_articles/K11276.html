Topic

Each F5 platform contains a Lithium coin cell battery on the motherboard that is used to power non-volatile memory when the BIG-IP system is powered off. Some industries require the certification of Lithium batteries, and so the following documents provide certification details for the batteries used in BIG-IP hardware platforms.

CR2032 Lithium battery

The CR2032 battery is used starting in the BIG-IP 3900, 6900, and 8900 platforms. The following PDF file includes the certification of the CR2032 battery:

CR2032 Lithium battery certification

Note: The CR2032 battery is also used in Return Materials Authorization (RMA) of platforms earlier than the BIG-IP 3900, 6900, and 8900 platforms.

CR2450 Lithium battery

The CR2450 battery was used in BIG-IP platforms prior to the BIG-IP 3900, 6900, and 8900 platforms. However, the BIG-IP 1600 and 3600 platforms may also use the CR2450 battery. The following PDF file includes the certification of the CR2450 battery:

CR2450 Lithium battery certification

Note: For more information about the Lithium coin cell battery, refer to K2848: Batteries included in F5 hardware platforms.
