Description

When connecting to the GUI, objects are missing upon login, such as the sidebar.

Logs similar to the following may be found in /var/log/tomcat/catalina.out:

ERROR [ajp-bio-127.0.0.1-8009-exec-19] util.Syscall:call - Exception trying perform a system call.

Environment

  • GUI

Cause

Stalled UCS archive save is blocking syscalld from serving the sidebar and additional content to tomcat.

See K34264432 for another root cause.

Recommended Actions

  1. Review the output of the following command to determine if a UCS save is running:

    ps aux | grep ucs

    The following example shows a UCS save operation is running:

    USER         PID   PPID  %CPU  %MEM     VSZ     RSS TTY      STAT START   TIME        COMMAND
    root         665   6849   0.0   0.7  249.2M  154.9M ?        S    13:13   00:00:00.31 /usr/bin/tmsh save / sys ucs backup_daily_ucs
     

  2. Note the PID of the UCS save process

  3. Kill the stalled UCS save process with the kill command:

    kill -9 <pid>

Additional Information

syscalld manages system call functions and other system calls may also be blocked when this issue occurs.

A UCS save may get stalled under a variety of conditions, for example:

  • Low disk space
  • High resource utilization
  • Backup script disconnects prematurely
