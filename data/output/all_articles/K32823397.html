K32823397: BIG-IQ Hypervisor VMs require Dedicated CPU and Memory Resources

Type
Support Solution
Published
2020-07-22
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K32823397

Description
BIG-IQ Virtual Edition (VE) running on a Hypervisor as a Virtual Machine (VM) requires dedicated, not shared CPU and Memory resources for proper functionality. Usage of shared resource can manifest in many different operational issues of BIG-IQ with symptoms seemingly appearing at random.

Environment

  • Hypervisor Virtual Machine
  • BIG-IQ Virtual Edition

Cause
BIG-IQ has a number of processes that require adequate, timely CPU and Memory resources to function properly. A Hypervisor environment may assign specific physical resources to multiple Virtual Machines which can result in contest between those VMs for the same shared resource. An example effect is a delay between requested clock cycles for a process on a VM. If a BIG-IQ process encountered insufficient/slow resources it can degrade BIG-IQ performance.

Recommended Actions

  1. Ensure all new BIG-IQ VE VMs are configured for dedicated CPU and Memory resources.
  2. Review resource configuration of all existing BIG-IQ VE VMs. If any VMs have shared CPU and/or Memory, the resources should be changed to dedicated and then the change applied (potentially requiring VM restart).

Additional Information
Please consult your Hypervisor's documentation for specific configuration actions to execute.
