K000132444: Finding OID(s) for configured vlan, interface, or tunnel

Type
Support Solution
Published
2023-02-07
Updated
2023-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.7
Source
https://my.f5.com/manage/s/article/K000132444

Description

Customer looking for correct OID to look at tunnel stats

Environment

  • BIG-IP
  • SNMP monitor

Cause

None

Recommended Actions

  1. Login to the BIG-IP
  2. list interfaces and tunnels:
    snmpwalk -On -v 2c -c public 127.0.0.1 1.3.6.1.2.1.31.1.1.1.1
    .1.3.6.1.2.1.31.1.1.1.1.32 = STRING: mgmt
    .1.3.6.1.2.1.31.1.1.1.1.48 = STRING: 1.1
    .1.3.6.1.2.1.31.1.1.1.1.64 = STRING: 1.2
    .1.3.6.1.2.1.31.1.1.1.1.80 = STRING: 1.3
    .1.3.6.1.2.1.31.1.1.1.1.96 = STRING: 1.4
    .1.3.6.1.2.1.31.1.1.1.1.128 = STRING: /Common/http-tunnel
    .1.3.6.1.2.1.31.1.1.1.1.144 = STRING: /Common/socks-tunnel
    .1.3.6.1.2.1.31.1.1.1.1.192 = STRING: /Common/external_vlan
    .1.3.6.1.2.1.31.1.1.1.1.208 = STRING: /Common/internal_vlan
  3. grep for interface of choice (we will use the internal_vlan for this example):

    snmpwalk -On -v 2c -c public 127.0.0.1 1.3.6.1.2.1.31.1.1 | grep 208
    .1.3.6.1.2.1.31.1.1.1.1.208 = STRING: /Common/internal_vlan
