Known Issue

Traffic Management Microkernel (TMM) may become unstable or produce a core file and restart on a standby BIG-IP system when connection mirroring and Multipath TCP (MPTCP) are enabled.

This issue occurs when all of the following conditions are met:

  • At least two BIG-IP devices are configured in a sync-failover device group with a device that is standby for a traffic group.
  • A virtual server has connection mirroring configured.
  • A TCP profile where MPTCP is enabled is applied to the virtual server.

Impact

The device in the standby state for a traffic group will not be operational until TMM restarts. If the device was active for a different traffic group, that traffic group will fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system exhibits unusually high memory utilization before the TMM restarts.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • Messages similar to the following example are logged to the /var/log/tmm files:

    notice ** SIGSEGV **
