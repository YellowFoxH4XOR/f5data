Known Issue

Attempting to push BIG-IQ updates to BIG-IP APM devices may fail.

This issue occurs when all of the following conditions are met:

  • You are using a BIG-IQ system to manage your BIG-IP APM device.
  • The BIG-IP APM device is running one of the following hotfix releases:
        
    •  11.4.1 HF2     
    •  11.4.1 HF3
  • The BIG-IQ system attempts to push an update to the BIG-IP APM device.

Impact

Attempts to update the BIG-IP APM device fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the BIG-IQ representational state transfer (REST) update command, the system displays error messages similar to the following example:

    Uploading msgbusd-extras-<software version>.rpm to <BIG-IP APM ip address>...
    Installing msgbusd-extras-<software version>.rpm to <BIG-IP APM ip address>...
    Uploading f5-rest-java-host-<software version>.rpm to <BIG-IP APM ip address>...
    Installing f5-rest-java-host-<software version>.rpm to <BIG-IP APM ip address>...
    Can't open scim/run at /usr/lib/perl5/vendor_perl/5.8.8/daemon.pm line 448.
    Can't open scim/run at /usr/lib/perl5/vendor_perl/5.8.8/daemon.pm line 448.
    error: %preun(msgbusd-11.4.1-608.0.i686) scriptlet failed, exit status 2
    Installation to <BIG-IP APM ip address> failed!
