Description

The mysqld process fails to start up with errors like the following in /var/log/mysql.out:

 

Sep 31 01:01:59 waiting for mysql to set up permissions ...
Sep 31 01:02:01   generating password for root ...
Sep 31 01:02:01   setting root permissions...
ERROR 1045 (28000): Access denied for user 'root'@'localhost' (using password: YES)
Could not set password in MySQL
Sep 31 01:01:01     Error: could not set root password: password write failed
Sep 31 01:02:01     Unable to set up root password/permissions ...
Sep 31 01:02:04 waiting for mysql to set up permissions ...
Sep 31 01:02:06 Setting up MySQL permissions failedAug 13 16:08:06 Setting up MySQL database failed.Sep 31 01:02:09 waiting for mysql to set up permissions ...
Sep 31 01:02:14 waiting for mysql to set up permissions ...
Sep 31 01:02:19 waiting for mysql to set up permissions ...
Sep 31 01:02:24 waiting for mysql to set up permissions ...

 

This can happen when the MariaDB root password that is encrypted in the /var/db/mysqlpw file and the password for the root user used by mysqld are not the same.

Environment

A BIG-IP provisioned with any module that uses mysqld.  These include AVR, AFM, APM, ASM, and PEM.

Procedure

Reinitialize MariaDB by doing the following:

  1. bigstart stop mysql
  2. /usr/sbin/mysqld --user=mysql --skip-grant-tables &
  3. mysql -u root
    FLUSH PRIVILEGES;
    SET PASSWORD FOR 'root'@'localhost' = PASSWORD('xxx');
    SET PASSWORD FOR 'root'@'127.0.0.1' = PASSWORD('xxx');
    quit
  4. kill %%
  5. /usr/share/mysql/mysqlpw -n -p xxx
  6. touch /var/lib/mysql/INIT_DATABASE
  7. touch /var/lib/mysql/INIT_DATABASE_TABLES
  8. touch /var/lib/mysql/INIT_DATABASE_PERMISSIONS
  9. bigstart restart mysql

Note: The part with the 'xxx'  in Step 3 and 5 should be changed to your chosen password instead of copied and paste as the full command unchanged, as part of the re-initialiation of the mysql information—controlled by the presence/absence of the /var/lib/mysql/INIT_* files—the root password will change to something other than "xxx" 

 

The monpd process (if it should be running) may need to be restarted manually:

 

  1. bigstart restart monpd
