K000138539: Upgraded BIG-IP and found missing configuration

Type
Support Solution
Published
2024-02-20
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K000138539

Description

Perform an upgrade on the BIG-IP to new images (base/ENG Hotfix) and found missing configuration.
Example:

  • BIG-IP were upgraded from v16.x to v17.x
  • After the BIG-IP were upgraded, found some of the virtual server configured were missing

 

Environment

  • BIG-IP
  • 2 software volume
  • Missing configuration

Cause

  • BIG-IP has 2 software volume because of space constrains (example: HD1.1: "old" and HD1.2: "current")
  • The upgrade steps were done in a manner where first downgraded to the old software volume version which has old configuration
  • The upgrade were done on the old software volume version instead of the current new software volume version which has the latest configuration
  • Hence, during the upgrade the old configuration will be used
 

Recommended Actions

It is recommended to install the new image to the old software volume (example HD1.1:"old") instead of downgrading as a first steps.
