Known Issue

The Management.KeyCertificate.get_certificate_validator() function fails to throw a not-found exception when a given certificate does not exist.

This issue occurs when the following condition is met:

  • The iControl SOAP function get_certificate_validator() is called to get the certificate-validators' names of the given certificates.

Impact

The impact should be limited. The function returns empty strings [[]] for a non-existing certificate, so the user is unable to distinguish, from the output, whether the certificate is non-existing or has no certificate-validators configured.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The iControl SOAP call get_certificate_validator() is supposed to return the certificate-validators of the given certificates. When you input a non-existing certificate to the function, the system returns empty strings [[]] instead of presenting the exception for the non-existent certificate.
