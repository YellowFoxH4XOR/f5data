Description

You want to extract data from an HTTP packet and re-insert it as a header. This can be accomplished with an appropriately written iRule.

Environment

  • BIG-IP LTM
  • Standard Virtual Server
  • HTTP Profile

Cause

None

Recommended Actions

This iRule will require several things:
  1. The BIG-IP to be able to read the HTTP contents of the traffic. At minimum, this means the virtual server needs an HTTP profile with the addition of SSL profiles if the content is encrypted.
  2. Second, to pull data out of an HTTP payload, your iRule will need to use the HTTP::collect command. Note: See HTTP::collect and HTTP Payload Collection in Related Content
  3. Once your data is captured to a variable, you will then need to use that variable to insert a header into the response traffic. You do this using the HTTP::header command.  Note: See HTTP::header in Related Content
