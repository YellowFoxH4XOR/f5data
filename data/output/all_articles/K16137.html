Topic

Beginning in BIG-IP 11.2.0, dns is a reserved monitor name. This change may affect upgrades from a version of BIG-IP prior to 11.2.0 to a version later than BIG-IP 11.2.0 that contained a custom monitor called dns.

Description

Beginning in BIG-IP 11.2.0, there is a base monitor named dns for performing DNS monitoring, and so the dns monitor name is now reserved.

If you attempt to create a new monitor named dns in BIG-IP 11.2.0 or later, the BIG-IP system displays an error message similar to the following example:

01020066:3: The requested monitor template (/Common/dns) already exists in partition Common.

If you attempt to upgrade from a version of BIG-IP prior to 11.2.0, where dns was not a reserved monitor name, then after you upgrade, your configuration fails to load and displays an error messages similar to the following example:

01070035:3: Root monitor /Common/dns contains a non-null get_defaults_from string.

Recommendations

When planning an upgrade from BIG-IP versions prior to 11.2.0, you should consider the following factors:

dns is now a reserved monitor name, and you should rename it to a non-reserved name before you perform an upgrade.
