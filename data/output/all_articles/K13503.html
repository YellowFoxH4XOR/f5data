Known Issue

The snapshot consistency option is incorrectly enabled and cannot be disabled with the no snapshot consistency command.

This issue occurs when the following condition is met:

  • The ARX is configured to manage snapshots for a volume.

A snapshot is a complete, point-in-time copy of an ARX volume. The ARX volume coordinates snapshots at each of its back-end filers. You can use the snapshot consistency command to put up a VIP fence until the filers finish. Clients cannot access the volume’s virtual server(s) while the VIP fence is up, so the snapshots are guaranteed to be consistent. Most installations do not require strict snapshot consistency. The default setting for snapshot consistency is disabled.

Impact

Clients cannot access the volume's virtual servers while snapshots are being performed.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Clients are unable to access files through the ARX virtual servers while snapshots are in progress.
  • The ARX procdat log file will contain an error message indicating a VIP fence was raised. The error message appears similar to the following example:

    :SNAPD-0-DBG-MSG7::SnapshotOpCreate::raiseFenceAndPauseVols(): '1' vips to fence.

  • Snapshots may fail with snapshot consistency cannot be guaranteed error messages. The error message appears similar to the following example:

    :SNAPD-0-ERR-SNAP_CREATE_FAILED_MSGS:: Snapshot create failed message for namespace [ns01] volume [/vol1] snapshot rule [hourly] virtual snapshot [hourly0] message [Timed out while attempting to drain client traffic from VIP '10.10.10.25:445' for volume '/vol1'. Snapshot consistency cannot be guaranteed.].

Note: The procdat log file is included in an ARX system diagnostic information file. The procdat log file is located in the /acopia/var/log directory of the diagnostic information file. For information about creating an ARX system diagnostic information file, refer to K8294: Providing an ARX diagnostic information file to F5 Technical Support.
