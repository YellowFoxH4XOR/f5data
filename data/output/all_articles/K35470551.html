Known Issue

Importing or exporting an access policy configured to use the Machine Cert Auth agent may fail.

This issue occurs when all of the following conditions are met:

  • You have a Certificate Authority profile configured with a content revocation list (CRL).
  • You use the Machine Cert Auth agent in an access policy which is configured to use the Certificate Authority profile.
  • You export the access policy and then attempt to import it.

Impact

You cannot successfully import the access policy.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe messages similar to the following example in the /var/log/apm file:

    Import Error: 01070712:3: Failed: name (/Common/example.crl) cache path expected to be non empty. Unexpected Error: Validating configuration process failed.

  • You are unable to successfully import the access policy.

Workaround

To work around this issue, you can remove the Machine Cert Auth agent from the access policy before exporting it. You can then separately import the CRL and the access policy. You can then add the Machine Cert Auth agent back into the access policy.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
