Known Issue

If you modify a SNAT configuration, the configuration may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured with a SNAT that uses an IP address for the Translation type.
  • You attempt to modify the SNAT configuration changing the Translation type to SNAT Pool.

Impact

The SNAT modification produces an error, and the SNAT configuration is unchanged.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to modify a SNAT configuration using the Configuration utility, you may observe an error message similar to the following example:

    01070734:3: Configuration error: Snat Translation Address Name /<partition>/<translation ip address> encodes IP address <translation ip address> which differs from object IP address field ::

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to modify the SNAT configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Use the following command syntax to modify the SNAT configuration.

    modify /ltm snat <SNAT name> { snatpool /<partition>/<snat_pool name>}

  3. To save the configuration changes, type the following command.

    save /sys config

  4. To exit the tmsh utility, type the following command.

    quit
