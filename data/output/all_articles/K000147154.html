K000147154: Are there any special setup or configuration requirements for DNS Load Balancer Service?

Type
Support Solution
Published
2024-11-08
Updated
2025-12-07
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud DNS Load Balancer
Source

Description

If you want to use Distributed Cloud DNS services, you need to set up correctly your domain DNS/NS records. 

Environment

  • DNS Load Balancer Service
  • DNS nameserver 

Resolution/Answer

To use Distributed Cloud DNS, you need to set correct NS records on your domain as below:

Nameserver FQDNIPv4
ns1.f5clouddns.com107.162.234.197
ns2.f5clouddns.com107.162.176.221
