Description

On BIG-IP DNS, wide IP maybe marked down but it is able to perform DNS resolution. 

Sample config in bigip_gtm.conf:

gtm wideip a /Common/example.com {
    last-resort-pool a /Common/example_pool  #Status of the wide ip will be based on reachability of this pool if default pool is not configured.
    pool-lb-mode global-availability
} 

Environment

  • BIG-IP DNS
  • Wide IP
  • Default load balancing pool
  • Last resort pool

Cause

This is a cosmetic issue. Without default pool configured, wide IP status is reflecting on last resort pool instead. If last resort pool is not reachable, wide IP status will be marked down. However, it will still be able to resolve DNS traffic.

Recommended Actions

  1. Verify the reachability of the last resort pool. Make sure it is reachable from BIG-IP DNS.
  2. In GUI, consider removing last resort pool from wide IP if it's not in use.
