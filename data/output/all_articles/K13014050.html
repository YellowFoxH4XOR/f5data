Known Issue

The BIG-IP ASM Policy Builder may restart and produce a core file while processing a large extractions list.

This issue occurs when the following condition is met:

  • You configure thousands of URLs in a single extractions list by navigating to Security > Application Security > Parameters > Extractions.  

Impact

The BIG-IP ASM Policy Builder restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM Policy Builder restarts when processing thousands of URLs in the extractions list.
  • The BIG-IP system generates a pabnagd core file to the /shared/core directory.

Resolution

Status

F5 Product Development has assigned ID 421451 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can create multiple extractions lists with a smaller number of URLs instead of a single extractions list with a large number of URLs.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
