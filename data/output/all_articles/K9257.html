Known Issue

Note: The issue only applies to the BIG-IP ASM 4100 platform.

This is the result of a known issue. Configuring a forwarding virtual server, Forwarding IP, or Forwarding Layer 2 virtual server on a BIG-IP ASM 4100 platform causes the pvad process to continually restart.

The BIG-IP ASM 4100 does not have the FastL4 profile, which is necessary to support the forwarding virtual servers. As a result, the pvad process continually restarts, and the following two error messages are displayed:

  • Error message written to the console:

    LOGIN: Re-starting pvad

  • Error message written to the /var/log/ltm file:

    pvad[5733]: 01130003:6: Starting pvad
    pvad[5733]: 01130003:6: MCP connected!
    pvad[5733]: 01130003:6: Log level changed to: Informational
    pvad[5733]: 01130005:3: ../LogStream.cpp:89 - no obj w/key=fastL4 w/rel1 to obj w/key=testvip fastL4 - Expression 'relObj != Global::cfg.end()' failed in '../GraphBuilder.cpp', line: 301
    pvad[5764]: 01130003:6: Starting pvad
    tmm tmm[1498]: 01010007:3: Config error: virtual_server_profile bad profile

F5 Product Development tracked this issue as CR93742 and it was fixed in BIG-IP ASM 9.4.5. For information about upgrading, refer to the BIG-IP ASM release notes.
