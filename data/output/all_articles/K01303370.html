K01303370: Virtual address will change to traffic-group-1 when modifying Traffic-Matching-Criteria virtual server

Type
Support Solution
Published
2020-12-15
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.X.X, 16.1.X, 16.0.X, 15.1.X, 15.0.X, 16.1.0, 16.0.1, 16.0.0, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.X.X, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 16.1.3, 16.1.2, 16.1.1, 15.1.4
Source
https://my.f5.com/manage/s/article/K01303370

Description

For virtual servers associated with traffic-matching-criteria (TMC) and the virtual address does not belong to the default traffic-group-1, any modification of the virtual server will reset the virtual address to traffic-group-1.

Environment

  • BIG-IP LTM

  • Traffic-matching-criteria defined on system and is associated with a virtual server

  • Virtual address resides in another traffic-group instead of traffic-group-1

Cause

F5 Product Development filed ID748886 to track this issue.
Bug ID 748886: Virtual server stops passing traffic after modification

Recommended Actions

  • Remove address list or port-list from virtual server to avoid this issue.

None
