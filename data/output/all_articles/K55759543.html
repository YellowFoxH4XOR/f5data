Description
Statistics of  "Current Sessions" on gateway route pool member is incorrect

  • The stats show strange values such as, 18.4E
  • Stats are not cleared by reset-stats command.


For Example: 

 # tmsh show ltm pool gate members
---------------------------------------------------------------------------------------
Ltm::Pool: gate
---------------------------------------------------------------------------------------
Status
  Availability           : available
  State                  : enabled
  Reason                 : The pool is available
  Monitor                : gateway_icmp
   .....
  --------------------------------------------------------------
  | Ltm::Pool Member: 10.154.120.254:any
  --------------------------------------------------------------
  | Status
    .....
  |   Total Requests                                  -        1
  |   Current Sessions                                -    18.4E        <---------<< 
   .....

Environment

  •  BIG-IP V15.1.3.1
  • Gateway pool
  • HTTP explicit HTTP proxy VS

Cause
 This is a known issue with  ID 1042133.

Recommended Actions

To recover, restart TMM or reboot the system.

Impact: The BIG-IP system experiences a temporary traffic interruption as it recovers from the TMM restart, and devices configured as a high-availability (HA) pair may fail over.
