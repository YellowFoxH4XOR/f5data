K000159007: High MCPD CPU usage due to 'bigtop' command left running

Type
Support Solution
Published
2026-01-06
Updated
2026-01-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000159007

Description

BIG-IP system is observed to be slow, with high MCPD CPU usage.

Environment

  • MCPD
  • bigtop

Cause

The bigtop utility was left running on a system with a moderate-large configuration (for example, hundreds of virtual servers).

The bigtop utility sends many queries to MCPD and this can have significant CPU impact in some cases. In severe cases this might result in system slowdown or disconnections in the GUI.

Recommended Actions

Do not leave the bigtop command running for long periods. Short periods of bigtop use are fine.

You can verify if bigtop is running by reviewing output from the ps command:

ps aux | grep '[b]igtop'

It is possible for multiple instances of bigtop to run, which can exacerbate the problem.

You can kill off the bigtop process with the following command:

killall bigtop

Additional Information

There are numerous possible root causes of high MCPD CPU usage.
