Description

Sync group only fails after upgrading.

Error in LTM logs after initiating Policy Sync between devices: "01b70117:3: local_path (/tmp/psync_local_file) starts with invalid directory. Valid directories are /var/config/rest/, /var/tmp/, /shared/tmp/."
  • Policy sync group will not sync policies
  • APM access policy contains a custom image file

Environment

BIG-IP

  • APM configured, psync is APM policy sync related

Cause

APM access policy contains a custom image file which is not allowed to be created from /tmp local_path.
BugID 1108109

err mcpd[6405]: 01b70117:3: local_path (/tmp/psync_local_file) starts with invalid directory. Valid directories are /var/config/rest/, /var/tmp/, /shared/tmp/

Recommended Actions

Request EHF from support for BugID 1108109 to resolve policy sync failure which allows customization image file to be allowed to be created from /tmp local_path.
