Known Issue

Tab completion in the Traffic Management Shell (tmsh) may not list all transparent monitors.

This issue occurs when all of the following conditions are met:

  • You have created a custom transparent monitor.
  • The monitor type is not Gateway ICMP.
  • You attempt to use tab completion to display all of the available custom transparent monitors when creating or modifying a GTM link using the tmsh utility.

Impact

You must manually enter the name of a custom transparent monitor when creating or monitoring GTM link objects using the tmsh utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H425761 on the Diagnostics > Identified > Low screen.
  • When creating a GTM link using the tmsh utility, the system does not display the name of a custom transparent monitor when using tab completion.
  • When modifying a GTM link using the tmsh utility, the system does not display the name of a custom transparent monitor when using tab completion.

Resolution

Status

F5 Product Development has assigned ID 425108 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of the article. Workaround

You can work around this issue when associating the monitor with a GTM link using the tmsh utility. To do so, you can manually type the name of a custom transparent monitor.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
