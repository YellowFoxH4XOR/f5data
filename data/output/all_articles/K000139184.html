K000139184: Cloud Failover Extension (CFE) support moving IP prefixes in AWS

Description

Cloud Failover Extension (CFE) currently supports failing over /32 prefix only.

Customer Special Request (CSR), a F5 internal process was raised to request for this feature.

There is a public post about the supportability of moving IP prefixes in AWS, please refer Github page.

Note: This link takes you to a resource outside of MyF5, and the third party could remove the document without our knowledge.

Environment

  • BIG-IP VE in AWS
  • Cloud Failover Extension (CFE)

Cause

This is new feature

Recommended Actions

It is suggested to reach out to F5 account team to follow up for the Customer Special Request (CSR) status.

You may reference Jira ID: EC-104, or AUTOSDK-560 or find status update from the Github page mentioned in the description.
