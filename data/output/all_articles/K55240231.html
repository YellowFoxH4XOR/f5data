Description

After upgrade, the BIG-IP fails to boot to a new location.

It displays the error message in /var/log/ltm


info: Getting configuration from <boot_location> info: Copying configuration to <boot_locationn> info: Applying configuration to <boot_location>.
info: >++++ result:
info: /bin/touch: cannot touch `/service/mcpd/forceload': Permission denied
info: >----
error: status 256 returned by command: F5_INSTALL_MODE=install F5_INSTALL_SESSION_TYPE=hotfix chroot <mount point> /bin/touch /service/mcpd/forceload Creation of mcp db force-load flag failed;
Inappropriate ioctl for device umount: <mount point>: device is busy
umount: <mount point>: device is busy
umount: <mount point>: device is busy

Environment

  • BIG-IP
  • Upgrade software
  • 11.5.3 and 11.6.0 installed on two boot locations

Cause

Bug ID 524606: SElinux violations prevent cpcfg from touching /service/mcpd/forceload

Recommended Actions

  1. Roll back to the previous boot location.
  2. Delete the recently created boot location that experience the above error and re-install BIG-IP software again.
    Note: If unable to delete the issued boot location, reboot the BIG-IP. After reboot, checking the boot location again before re-installing BIG-IP software.
