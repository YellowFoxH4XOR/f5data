Description

DNS Express stops returning TXT records after enabling Rapid Response Mode in dns profile.

BIG-IP DNS stops responding to dns queries that worked previously.

Other records such as A records are working normally

 

Environment

  • BIG-IP DNS
  • DNS Express
  • Rapid Response Mode
  • rapid-response-last-action is drop

Cause

ID1382297

Recommended Actions

The issue only occurs when rapid-response-last-action is "allow".

Set to "drop" if possible to workaround the issue.

Additional Information

When rapid-response-last-action is allow, only records under 1632 bytes (including the current Authority and Additional records) are returned.
