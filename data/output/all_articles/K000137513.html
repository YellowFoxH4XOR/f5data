Description

After the upgrade, installing asm signature through REST API you are getting the below errors:

{
  "code": 500,
  "message": "Can not install. Update file was deleted from disk: asm-attack signatures",
  "referer": "x.x.x.x",
  "restOperationId": 627423,
  "kind": ":resterrorresponse"
}

 

Environment

ASM upgrade from v15.1.9+

 

Cause

In case of maintenace release version change e.g. from 15.1.x to 15.1.y all old signature files (available with image and newly updated if any) get deleted and new version files get copied on file system and files available from older version are shown in live update list but old signatures cannot be installed on new version. By clicking install only the new signature version compatible with new release only get installed.

 

Recommended Actions

Not all the updates files from the output of the endpoint are available, some of them have been deleted from the disk.

You need to double check "isFileAvailable = false" or "isFileAvailable = true" and only can install the files with "isFileAvailable = true".

 

For example:

   "id": "ff808081896dc6bd01896dc6d2a5002c",
   "filename": "ASM-AttackSignatures_20230705_155640.im",
   "md5": "84A554816C3CAB10E94855FFDB93E9DF",
