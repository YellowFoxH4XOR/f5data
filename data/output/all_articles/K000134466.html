Description

You are having problems creating a backup and the web UI is disconnected every few minutes.

You are prompted a 'Localdbmgr down' error in the UI or in the CLI console.

Additionally you might see error logs that indicates low disk space in the /var folder.

 

Apr 1 11:20:00 domain.example.com err diskmonitor[30927]: 00000000:0: Disk partition /var has only 0% free

 

Environment

  • BIG-IP

Cause

These symptoms may be due to the filling up with temporary files under /var.

 Recommended Actions

When this happens, observe the capacity of the /var partition (run the bash command: df -h) and remove any files that you do not need (It could be old qkview or UCS files).

You might also want to consider increasing the /var partition (K34126971).

To see how much disk space you can allocate, go to System > Disk Management on the BIG-IP (or run the bash command: vgs)

Then run the commands:

  1. bigstart restart mysql
  2. bigstart restart localdbmgr

 

...and the issue should be solved.

 

Note that this can cause traffic disruption and we suggest running this outside working hours or during a maintenance window.
