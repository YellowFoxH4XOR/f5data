K000135190: localdbmgr service is down due to disk partition / has only 0% free

Type
Support Solution
Published
2023-06-22
Updated
2023-06-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.4
Source
https://my.f5.com/manage/s/article/K000135190

Description

Unable to perform some task as device is throwing below error in CLI:

Disk partition / has only 0% free


Environment

localdbmgr, monpd and mysql services are down.


Cause

/tmp directory is filled with below files:

69 /tmp/jvm-8382/hs_error.log

69 /tmp/jvm-7910/hs_error.log


Recommended Actions

Remove above files from tmp directory using below commands:

rm -rf /tmp/hc_err_pid*

rm -rf /tmp/jvm-*


Additional Information

Run below command to check large files in the / and /tmp directory:


du -L --max-depth=1 -x / | sort -n

find /tmp -xdev -type f -exec du {} \; | sort -rn | head -20
