Description

In the /var/log/secure file you can see regular failing login attempts from the 'root' username:

Jan 18 17:30:40 slot6/youhostname123 err sshd[11289]: error: PAM: Authentication failure for root from 127.3.0.5

Jan 18 17:30:40 slot6/yourhostname123 err sshd[11289]: error: Received disconnect from 127.3.0.5 port 38206:3: com.jcraft.jsch.JSchException: Auth cancel [preauth]

Environment

- F5-VEL-LTM-CX410-AC, F101

Cause

Unknown at the time of this article creation.

Recommended Actions

To resolve this, you can delete that key pair (e.g. if it is not used), or add the public key to the authorized_keys file.

The easiest way to do that, from the primary slot (slot 5 at time of qkview):

cat /root/.ssh/id_rsa.pub >> /root/.ssh/authorized_keys

csyncd will then sync the changed file to the secondary slot(s).

The SSH between slots should then work again, and the auth failure messages should go away.
