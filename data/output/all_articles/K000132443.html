K000132443: Nginx APP Protect RFC Violations

Type
Support Solution
Published
2023-02-07
Updated
2023-02-07
Source
https://my.f5.com/manage/s/article/K000132443

Description

RFC violations passing in Nginx APP Protect

Environment

Nginx App Protect

Cause

RFC Violation

Recommended Actions

Update policy to enable for RFC violation protection

Additional Information

If using default policy "POLICY_TEMPLATE_NGINX_BASE" doesn't block "VIOL_EVASION" violations since this needs to be enabled on your policy.

 

Add to policy:

 

"blocking-settings" : {

"violations" : [

{

"alarm" : true,

"block" : true,

"description" : "Evasion technique detected",

"name" : "VIOL_EVASION"

}

]

},
