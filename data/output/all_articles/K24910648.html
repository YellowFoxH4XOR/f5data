Description

Where are the Proactive Bot Defense (PBD) logs stored on the BIG-IP system?

The PBD logs that display each HTTP request, along with its attributes, are available at the following location in the BIG-IP file system.

BIG-IP 14.x and later

  • /var/log/botd/botd.log
  • /var/log/dosl7/dosl7d.log

BIG-IP 13.x

  • /var/log/dosl7/dosl7d.log

You can use these logs to analyze any requests that PBD has blocked.

Note: The PBD logs in BIG-IP 13.x record limited information.

Environment

  • BIG-IP ASM 13.x and later
  • Proactive Bot Defense (PBD)

None

Additional Information

Other logging and reporting improvements were made to provide better monitoring of behavior and effectiveness of proactive bot defense, including:

  • A Bot Defense Logging profile to provide basic filtering capabilities in the Request Log and Remote Log.
  • Additional info and Blocking Page configuration in iRules.
  • Transaction outcome charts with filtering and drill-down capabilities.
  • Starting in version 14.1.x, the Bot Defense feature has a new statistical report in: Security >> Event Logs >> Bot Defense >> Bot Traffic. This report helps admin to understand the traffic volume in each different Bot Categories and Top Client IP addresses of Bot activities.

These allow you to:

  • Monitor the Proactive Bot Defense behavior and effectiveness.
  • Troubleshoot false-positive cases.
  • Drill-down on specific cases to better understand the behavior.

This monitoring and drill-down can provide answers regarding:

  • Which transactions are being blocked and why.
  • The violation root cause.
  • Trends in blocked versus non-blocked transactions.
  • The main source of blocked transactions, whether by IP address, country, application, or URL.
