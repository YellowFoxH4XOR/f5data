Description

CPU graphs may show short CPU spikes (up to 100%) on the Analysis Plane (the last odd-numbered CPU core) when AVR is in use (either provisioned, or enabled by provisioning of other modules such as ASM/AFM).

Environment

  • Blade
  • CPU Spike
  • CPU utilization
  • Analysis Plane
  • Data Plane

Cause

AVR Statistics aggregation running hourly. This is expected behavior.

Recommended Actions

None.
