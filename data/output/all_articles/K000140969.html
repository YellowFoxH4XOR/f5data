K000140969: Deploying SSLO fails due to error: 'To' or 'From' service address is not available

Type

Published

Updated

Description

When deploying SSLO on HA pair, you may get the following error

Deploying SSLO fails due to error: 'To' or 'From' service address is not available on <ip address>

Environment

  • SSLO

Cause

This error can occur in an SSLO HA setup when we configure a service. SSLO verifies whether the configured SSLO service's 'To Service' and 'From Service' settings are correct, typically checking if the self IP address is available on the remote peer. If the configured self IP is not a floating IP, this error will be generated.

 

Recommended Actions

Ensure that you are using a floating self IP address for the service configuration in SSLO HA setup .
