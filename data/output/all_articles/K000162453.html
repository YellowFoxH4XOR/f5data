K000162453: The file deletion log format was changed in F5OS v2.0.0

Type
Support Solution
Published
2026-07-26
Updated
2026-08-19
Applies to
  • F5OS Products
  • F5OS: 2.0.0
Source
https://my.f5.com/manage/s/article/K000162453

Description

F5OS-A v1.8.4 and v2.0.0 show the file deletion log message below, respectively.

2026-07-23T12:50:41.384746+08:00 R5900-HostA utils-agent[10]: priority="Notice" version=1.0 msgid=0x5e01000000000006 msg="utils-agent" AUDITLOG="File transfer AUDIT. Completed Delete file operation. localFile(configs/test_backup)".

2026-07-23T12:48:33.745450+08:00 R5900-HostB utils-agent[9]: priority="Notice" version=1.0 msgid=0x5e01000000000009 msg="file transfer audit" audit_log="Completed Delete file operation. localFile(configs/test_backup)".

F5OS 2.0.0 intentionally changed the platform audit log generated when deleting a backup file. Compared with F5OS-A 1.8.x, the delete event uses a different message ID, message text, audit field name, and event-message format. No functional impact was observed.

Environment

  • F5OS 2.0.0

Cause

The observed differences were caused by an intentional redesign of related audit-log messages as part of general logging improvements in F5OS 2.0.0. The backup-file deletion operation itself remained successful; only the audit log’s message ID, message text, field name, and formatting changed. F5 Product Engineering confirmed that this was not a bug fix, and no related Bug ID was identified.

Recommended Actions

Treat the F5OS 2.0.0 audit-log format as the expected format for backup-file deletion events.
