Description

Limitation of numbers of object for DNS

Environment

  • BIG-IP
  • DNS

Cause

None

Recommended Actions

It is depending on RAM and configuration. There is no definite limitation for number of objects, but depending on your config and traffic, it would reach to physical limit.

If you have numbers of object Management provision should be set midium or large accordingly like written in the online help:

Options include Small, Medium, and Large. Use Large for configurations containing more than 2000 objects, or more specifically, for any configuration that exceeds 1000 objects per 2 GB of installed memory. Changing the Management (MGMT) size after initial provisioning causes a reprovision operation.
