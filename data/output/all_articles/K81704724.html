Known Issue

Installing a user configuration set (UCS) archive file may fail.

This issue occurs when all of the following conditions are met:

  • The affected UCS archive file contains one or more invalid configuration files in a non-Common partition directory. The invalid configuration file names start with one of the following:

    • bigip.conf
    • bigip_base.conf
    • bigip_user.conf
    • bigip_gtm.conf

    For example, the UCS archive file that contains an invalid configuration file resides in the partition1 partition directory with a filename of bigip.conf.test:

    /config/partitions/partition1/bigip.conf.test

  • The affected UCS archive file is taken from a BIG-IP system running BIG-IP 11.3.0 or earlier.
  • You attempt to install this UCS archive file on an affected BIG-IP version listed in the Applies To box in the upper right corner of this article.

Impact

The UCS archive file fails to install. Additionally, if you are rolling forward an affected UCS archive file while performing an upgrade, the upgrade may fail with unexpected errors.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H621712 on the Diagnostics > Identified > High screen.
  • Installing a UCS archive file fails.
  • If you are performing an upgrade and use an affected UCS archive file to roll forward the configuration, the upgrade fails.
