Known Issue

This is the result of a known issue. The deflate compression filter does not correctly detect and handle incomplete HTTP transfers. This issue rarely occurs; however, it may result in system panic, and the report of the following log message in the /var/log/tmm file:

panic: ../modules/hudfilter/deflate/deflate.c:1166: Assertion "hudvariant type" failed.

F5 Product Development tracked this issue as CR80178 and it was fixed in BIG-IP LTM 9.3.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
