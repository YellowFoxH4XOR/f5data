Issue

Beginning with BIG-IP 10.1.0, the system no longer includes the Korn shell (/bin/ksh).

If you plan to upgrade to BIG-IP 10.1.0 or later, ensure that no Korn shell scripts will be rolled forward because they will not work after the upgrade. If you are currently using one or more Korn shell scripts, you must rewrite them to use the Bash shell before performing the upgrade. For example, this process applies to EAV monitors based on the Korn shell that you may have created.

Additionally, in BIG-IP versions prior to 10.1.0, the Korn shell is the default interpreter for the following bundled scripts:

/config/failover/active
/config/failover/standby

By default, these scripts are included in UCS archives. Therefore, if you upgrade to BIG-IP 10.1.0 or later, and roll forward an existing configuration, these scripts will not work after the upgrade. You should also modify these scripts to use the Bash shell before performing an upgrade to BIG-IP 10.1.0 or later.

Note: For more information about these scripts, refer to K6008: The BIG-IP system can be configured to execute commands or scripts upon failover.

Note: As these scripts are intended for customer use, by default, they do not specify any commands. If you have not previously customized these scripts, you can replace #!/bin/ksh with #!/bin/sh. However, if you have previously customized either or both scripts, you will have to verify that the commands you specified are valid Bash commands.
