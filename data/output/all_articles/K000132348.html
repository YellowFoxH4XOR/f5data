Description

AS3 declaration failure: mgmt shared service-discovery task update response=404 body

 

"results": [

{

"code": 422,

"message": "declaration failed",

"response": "POST http://admin:XXXXXX@localhost:8100/mgmt/shared/service-discovery/task mgmt shared service-discovery task update response=404 body={\"code\":404,\"message\":\"\",\"referer\":\"Unknown\",\"errorStack\":[]}",

"host": "localhost",

"tenant": "Sample_Tenant",

"runTime": 50

}

 

Environment

AS3

Service Discovery

Cause

f5-service-discovery is not installed.

 

Service Discovery will be used when an AS3 declaration contains pool members with an addressDiscovery type that is not "static":

 

e.g.

"test_consul_pool": {

"class": "Pool",

"monitors": [

"http"

],

"members": [{

"servicePort": 80,

"addressDiscovery": "consul",

"updateInterval": 5,

"uri": "http://<example.org:<Port>/<path>"

}]

}

 

- On the BigIP

# ls /var/config/rest/iapps

f5-appsvcs

 

This is showing Service Discovery is not installed. These should be a "f5-service-discovery" directory listed here as well.

 

Recommended Actions

Option 1

  1. Uninstall AS3 and Service Discovery (if listed)
    1. iApps  ››  Package Management LX
    2. Select f5-appsvcs and f5-service-discovery (if listed)
    3. click Uninstall
  2. Import AS3
    1. iApps  ››  Package Management LX
    2. click Import
    3. click Choose File
    4. select the AS3 RPM to Import
    5. click Upload
  3. Verify the installation was complete
  • iApps  ››  Package Management LX (verify f5-appsvcs and f5-service-discovery is listed)
    • on the bigIP: # ls /var/config/rest/iapps

f5-appsvcs f5-service-discovery

 

4. If Option 1 does not correct the issue, proceed to Option 2.

 

 

Option 2

1. # clear-rest-storage

Stopping restnoded

Stopping restjavad

Removing storage files

Removing index files

Starting restjavad

Starting restnoded

 

Note: This will not remove any deployed AS3 configuration, but AS3 and any other Package Management LX RPMs must be reinstalled.

 

2. Import AS3

  • iApps ›› Package Management LX
  1. click Import
    1. click Choose File
    2. select the AS3 RPM to Import
    3. click Upload

3. Verify the installation was complete

  • iApps ›› Package Management LX (verify f5-appsvcs and f5-service-discovery is listed)
    • on the bigIP:

# ls /var/config/rest/iapps

f5-appsvcs f5-service-discovery
