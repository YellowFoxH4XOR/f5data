Known Issue

This is the result of a known issue. A path probe throttling mechanism was not included in BIG-IP GTM versions prior to 9.3.1. For systems with a large number of Local Domain Name System (LDNS) clients, the number of path probes initiated when a BIG-IP GTM system is rebooted or restarted can overwhelm the capacity of the path probe queue. As a result, probes are dropped and path probe data is missing across the entire BIG-IP GTM synchronization group.

F5 Product Development tracked this issue as CR86554, and it was fixed in BIG-IP GTM 9.3.1 and 9.4.7. For information about upgrading, refer to the BIG-IP GTM Release Notes.
