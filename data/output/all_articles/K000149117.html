K000149117: Configuration Sync failed with an error "The ServerSSL Profile (/Common/shape-api-ssl) cannot be deleted because it is in use by a Security Offbox Service (/Common/f5-credential-stuffing-blackfish)".

Type
Support Solution
Published
2025-03-25
Updated
2025-03-25
Source
https://my.f5.com/manage/s/article/K000149117

Description

The configuration sync process is failing with an error "The ServerSSL Profile (/Common/shape-api-ssl) cannot be deleted because it is in use by a Security Offbox Service (/Common/f5-credential-stuffing-blackfish)".

Environment

BIG-IP LTM

Cause

The issue was caused by residual references in MCPD binary files related to removed or modified Shape/ASM configurations, leading to a mismatch between text and binary configurations and blocking synchronization due to unresolved dependencies.

Recommended Actions

Follow the below steps to resolve this error:

 

  • Check the configuration of the f5-credential-stuffing-blackfish cloud-services endpoint with the below command on both devices and see if the "shape-api-ssl" SSL profile is mapped to the "f5-credential-stuffing-blackfish" endpoint.

          #list /security cloud-services endpoint f5-credential-stuffing-blackfish

 

  • Set the SSL profile to None for "endpoint f5-credential-stuffing-blackfish" on both HA units with the below command if the "f5-credential-stuffing-blackfish" endpoint is mapped with SSL profile "shape-api-ssl" and save the configuration. 

            #modify /security cloud-services endpoint f5-credential-stuffing-blackfish ssl-profile none

           #save /sys config

 

  • Perform the sync operation. After the sync operation, verify the configuration of "shape-api-ssl" on both devices. You will notice that the SSL profile  "shape-api-ssl" is missing on the Standby unit. 
  • Perform the mcpd force load operation on the Standby device. After the standby device becomes UP, you will able to see the "shape-api-ssl profile on the standby unit. 

    Follow the instructions in the below article to perform the mcpd force load operation.  
    K13030: Forcing the mcpd process to reload the BIG-IP configuration

  • Map the "shape-api-ssl" profile to "f5-credential-stuffing-blackfish" on both devices with the below command, save the configuration and perform the sync operation.

            #modify /security cloud-services endpoint f5-credential-stuffing-blackfish ssl-profile shape-api-ssl

            #save /sys config
