Known Issue

This is the result of a known issue. The ARX system may experience poor NFS metadata performance during an import and during normal operations for a managed volume ARX VIP. The ARX system does not use all of its available memory to cache the metadata database, resulting in the NFS data cache becoming invalidated more frequently. This issue is a result of changes introduced in the Linux kernel 2.6, which is used by ARX versions 4.0 and later.

Note: ARX versions prior to 4.0 use the Linux kernel 2.4 and cache the metadata database using all the available memory on the ARX.

F5 Product Development tracked this issue as ARX ID 35311 and it was fixed in ARX version 5.0.5. For information about upgrading, refer to the ARX release notes.

Additionally, this issue has been fixed in a hotfix available for ARX version 5.0.1. To request this hotfix, contact F5 Technical Support and reference this Solution and ARX ID number.
