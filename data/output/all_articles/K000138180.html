Description

Default report (Overview -> active sessions) prints all sessions. 'Green' when access policy has been evaluated (allow) and 'blue' when it is being evaluated (in-progress) . 

You want to monitor only active sessions or in-progress sessions per user.

Environment

  • APM with access policies
  • Active sessions per user report

Cause

None

Recommended Actions

Create a custom report as below to print only active sessions (allow)

Create new report by  opening overview -> access reports -> customer reports -> create new report...

1. Report Name: ActiveSessions
2. Report Fields:
User->Login user name
User->Access policy result
Session->Session creation time
Session->Client IP
3. Report Constraints
"Policy ending output" is Allow (prompt false)
"Active" is Y (prompt false)
 
Create another report asking active sessions for an specific user.
Note: Replace "name" with the username of that user when this is prompted.
 
1. Report Name: ActiveSessionsPerUser
2. Report Fields:
User->Login user name
User->Access policy result
Session->Session creation time
Session->Client IP
3. Report Constraints
"Policy ending output" is Allow (promt false)
"Active" is Y (prompt false)
"Login user name" is name (prompt true)
