K000092889: [F5OS-A] unable to start tenant due to QAT plugin not loaded after upgraded to v1.2.x

Type
Support Solution
Published
2022-11-30
Updated
2023-04-28
Applies to
  • F5OS
  • rSeries Platforms
  • F5OS-A: 1.2.X, 1.2.0
Source
https://my.f5.com/manage/s/article/K000092889

Description

You should consider using these procedures under the following condition after an upgrade of F5OS-A or a re-installation of k3s:

  • Tenant will not start and is stuck in Pending status as shown below from Management CLI:
Appliance-1# show tenants
tenants tenant <tenant name>
 state name          <tenant name>
...
                         INSTANCE                                 READY
NODE  POD NAME           ID        PHASE    CREATION TIME         TIME   STATUS                                               MGMT MAC
-------------------------------------------------------------------------------------------------------------------------------------------------
1     <tenant name>-1  1         Pending  2022-07-21T10:27:01Z         0/1 nodes are available: 1 Insufficient f5.com/qat.  00:00:00:00:00:00

Environment

  • F5OS-A
  • upgrade to v1.2.x
  • Tenant

Cause

  • Bug ID 1137121

Recommended Actions

Perform one or the other workaround:
  • Reboot the appliance
or
  • Restart the qat-plugin process by running the following from Bash:
[root@appliance-1 ~]# pkill qat-plugin
