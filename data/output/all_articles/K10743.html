Known Issue

This is the result of a known issue. When modifying a virtual server's address in the Configuration utility, the original virtual address may not be deleted. This behavior may disrupt network communication, especially if the offending address was a network virtual addresses because the BIG-IP system will continue to respond to ARP and ICMP messages for those addresses.

F5 Product Development is tracking this issue as ID 331700 (formerly CR61110).

Workaround

You can work around this issue by manually removing the offending virtual address. To do so, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Browse to Local Traffic >> Virtual Servers >> Virtual Address List.
  3. Select the check box next to the address you want to remove and click the Delete button.
  4. Click Delete to confirm the deletion.
