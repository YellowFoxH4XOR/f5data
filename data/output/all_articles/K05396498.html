K05396498: Device status is Offline for long time after upgrade

Type
Support Solution
Published
2020-12-23
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.1.X, 13.1.4, 13.1.3, 13.1.1, 13.1.5, 13.1.0
Source
https://my.f5.com/manage/s/article/K05396498

Description
When upgrade the device with ASM provision, the device stay in offline status for long time, maybe last x hours, depending on number policy.  

Environment

  • ASM
  • Upgrade to the versions 13.1.0, 13.1.0.1, 13.1.0.2, 13.1.0.3, 13.1.0.4, 13.1.0.5, 13.1.0.6, 13.1.0.7, 13.1.0.8, 13.1.1, 13.1.1.1, 14.0.0, 14.0.0.1, 14.0.0.2, 14.0.0.3, 14.0.0.4
  • Condition mentioned in ID 737500:
    • Signature Staging is enabled.
    • Updated Signature Enforcement is set to 'Retain previous rule enforcement and place updated rule in staging'.
    • Signatures are enforced on a policy.
    • A new ASM Signature Update is installed, which modifies the matching rule for some enforced signatures.

Cause
Caused by ID 737500

Recommended Actions

  1. Reboot the device to previous volume by issuing switch boot command
    # switchboot -b <location>
    # Reboot
    For additional information refer K5658
  2. Upgrade device to later versions such as 13.1.1.2 , 14.1.0, 14.0.0.5, or higher.

Additional Information
None.
