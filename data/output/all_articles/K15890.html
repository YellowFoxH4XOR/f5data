Known Issue

Connections may stall on virtual servers that use OneConnect and SSL profiles.

This issue occurs when all of the following conditions are met:

  • Your virtual server uses the OneConnect profile.
  • Your virtual server uses server SSL profile with the Unclean Shutdown option disabled.
  • A pool member associated with your virtual server generates an SSL close_notify alert, but does not send a TCP FIN.

Impact

Connections fail to pass data and may be reset unexpectedly.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Connections may experience TCP RESETs and fail to pass data.

Workaround

To work around this issue, you can disable the OneConnect profile.
