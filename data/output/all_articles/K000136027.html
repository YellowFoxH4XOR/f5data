Description

BIG-IP may log message "01010028:3: No members available for pool" in /var/log/ltm. This may occur even when some pool members are available from a monitoring perspective.

 

Environment

LTM virtual server with a pool where all pool members have been session disabled administratively. 
No active connections or persistence records.

Cause

The messages are generated if all pool members are administratively session disabled and there are no active connections or persistence records for the virtual server. This is by design because the virtual server and pool will not be available for user connections. The messages will not be logged if active connections or persistence records exist.

Recommended Actions

None

Additional Information

All pool members administratively session disabled and there are no active connections or persistence records.

At least one pool member administratively forced offline.
