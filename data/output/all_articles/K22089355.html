Known Issue

The BIG-IP Edge Client may fail when establishing a network access session.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a network access profile.
  • The network settings and advanced client settings for Client Proxy Address and Client Proxy Port are not configured.
  • The access policy uses the variable assign agent to override the proxy configuration settings of the network access profile.
  • The variable assign values are incorrectly configured and do not include the specification for a static proxy host.
  • A user attempts to establish a network access session using the BIG-IP Edge Client.

Impact

The BIG-IP Edge Client may fail.

  • When you view the session variables using the sessiondump command, the access session config.connectivity_resource_network_access of the network access profile does not contain mappings for ProxyHost0 and ProxyPort0, and the session variables client_proxy_address and client_proxy_port.

Workaround

To work around this issue, you can correct the configuration by adding the proxy host configuration to the network access network settings, or by specifying the proxy host settings in the access policy variable assign configuration.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

For more information about configuring the network access profile, refer to the Configuring Network Access Resources chapter in the BIG-IP APM BIG-IP Access Policy Manager guide.

For more information about the sessiondump command, refer to the Visual Policy Editor Session Variables chapter in the BIG-IP APM BIG-IP Access Policy Manager guide.
