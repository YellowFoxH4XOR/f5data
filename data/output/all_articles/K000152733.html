Description

While trying to establish a VPN connection using the Windows Logon Integration, receive "Error 6: The Handle is Invalid".

Environment

BIG-IP ( APM Provisioned)

BIG-IP Edge Client (Build version: 7245, 7246)

 

Cause

Edge Client builds 7245 and 7246 introduced a regression where Windows Logon Integration fails with "Error 6: The handle is invalid."

The root cause is related to the handling of the Windows Secondary Logon Service (seclogon).

To enable the Windows "Secondary Logon" service for BIG-IP Edge Client with Windows Logon Integration, ensure the service is running and set to automatic startup. This is necessary because Edge Client uses a pre-logon VPN connection, and the "Secondary Logon" service is required for the local user account it creates during installation to log in. 

Recommended Actions

The fix requires the Secondary Logon Service to be running on the Windows Machine ( Client machine) and set to "Manual" or "Automatic" (not "Disabled").

Steps to enable the service:

  1. Open Services: Press the Windows key, type "services.msc", and press Enter.
  2. Locate Secondary Logon: Find the service named "Secondary Logon" in the list.

    

 

    3. Check Status: Verify that the "Status" column indicates "Running". If it's not running, right-click and select "Start".

      

 

    4. Check Startup Type: Verify that the "Startup Type" is not set to "Disabled". If it is, right-click, select "Properties", change the "Startup type" to "Automatic" (or "Automatic (Delayed Start)"), and then click "OK".

    

 

     5. Confirm: The "Secondary Logon" service should now be running and set to start automatically with Windows.
