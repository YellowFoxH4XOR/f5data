Summary

Support for clients and managed filers using the Server Message Block Protocol version 2 (SMB2) was added in ARX 6.4.0.

F5 Product Development tracked this Request for Enhancement (RFE) as ID 32654.

Description

For the ARX CIFS service to support SMB2, the following conditions must be met:

  • SMB2 must be enabled at the CIFS service. By default, SMB2 is enabled for every CIFS service. You can disable SMB2 on a service-by-service basis.
  • All filers associated with the CIFS service must support SMB2. You can use the show cifs-service filer-capabilities fqdn command syntax to locate all filers managed by the fully-qualified domain name (FQDN) service and probe them for SMB2 support.

Important: To enable SMB2 for a CIFS service, all shares in the namespace(s) that are being exported must be SMB2 capable, even if the volume with Server Message Block Protocol version 1 (SMB1)-only shares are not being exported.

Note: ARX 6.3.0 and lower do not support SMB2; clients and filers will be forced to use SMB1.

Recommendations

If SMB2 is needed within your environment, and you are using one of the supported platforms, you can upgrade to ARX 6.4.0 or later. To get the 6.4.0 release files, contact F5 Technical Support.
