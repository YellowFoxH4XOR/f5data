Obtaining and installing patches

A CA-2002-31 patch has been issued for BIG-IP and 3-DNS version 4.5.

To download and install the patch:

  1. Open the F5 Networks Downloads page in a browser.
  2. Navigate to the BIG-IP >> BIG-IP v4.x >> 4.5 section.
  3. Click CA-2002-31 and accept the End User Software license.
  4. Download the bind-8.3.4-1-BSD_OS-4.1.im file to the /var/tmp directory.
  5. Once the download is complete, type the following command to install the patch.

    im bind-8.3.4-1-BSD_OS-4.1.im
  6. To restart the name server, type the following command:

    ndc restart
  7. To verify that the upgrade has been properly installed, type the following command:

    named -v

    You should see server version 8.3.4. If you do not see this version number, contact F5 Networks Technical Support for assistance.
