K94165470: Transfer license from one physical device to another

Type
Support Solution
Published
2021-04-07
Updated
2025-04-02
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K94165470

Description

Base registration key is applied to a physical device that was not intended for. You want to transfer the license from one device to another.

Environment

  • Physical device
  • License
  • Base Registration Key

Cause

Base Registration Key is activated on the incorrect physical device.
or
Base Registration Key is already activated on the correct physical device but customer just want to move it to another device. 

Recommended Actions

If the Base Registration Key is activated on the incorrect physical device. Refer to K50621544: Applied license to incorrect device

If the Base Registration Key is already activated on the correct physical device but customer just want to move it to another device, F5 support is not able to do the license transfer. The Base Registration Key should remain on the correct physical device. This is due to each device having an assigned base registration key and the support contract information for the device being tied to the base registration key.

Contact F5 Sales or Account Manager if you have further questions about support contract.

Additional Information

None
