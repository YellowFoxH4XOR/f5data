Description

You have configured CPU pinning in OpenStack (such as a flavor with property hw:cpu_policy=dedicated), but the BIG-IP VE has poor performance.

Environment

  • BIG-IP VE
  • OpenStack / KVM
  • Red Hat Enterprise Linux as a host OS

Cause

Additional performance tuning may be required at the host OS kernel level.

 Recommended Actions

Some kernel parameters that changes the way specified CPUs behave are listed below. For details of the configuration, you may refer to instruction provided for your operating system.
  • isolcpus: A set of CPUs where the kernel's processes scheduler will not interact with. It allows to prevent kernel's process scheduling subsystem to move host processes onto CPU cores assigned to virtual machines, which could cause processes on hypervisor and a virtual machine to share a single CPU core.
  • nohz_full: Reduces frequency of kernel ticks on specified CPUs ('full' used for real-time applications).
  • rcu_nocbs: List of the CPUs in your system that should have their RCU callbacks offloaded to threads.
