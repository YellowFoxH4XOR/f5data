Description

  • What do I need to do to limit support access to my tenant?
  • What do I need to do to modify F5 Distributed Cloud support access to my tenant?
Note:

As part of Nov-1 release, feature Customer Tenant Access for Support Team was introduced.

The support team by default has read and write access to all namespaces on all customer tenants. You can now change the level of access of the support team to read-only access to all namespaces or read-and-write access to all namespaces or read-and-write access to selected namespaces.

 

Environment

  • F5®Distributed Cloud (SaaS)
  • F5 Distributed Cloud DDoS Managed Service
  • F5 Distributed Cloud WAF Managed Service
  • F5 Distributed Cloud Console (XC Console)

Procedure

How to modify F5 support read-write access

1. From the XC Console, navigate to Home > Administration > Tenant Settings > Tenant Overview

2. Go to Support Access

3. Click Manage Access

4. You can now either block the access or change the read-write access to read only mode or read-write with specific namespace.

 

Additional Information

Pause access

Checking Pause access will temporarily revoke support access to this tenant

 

Access Level

Choose what kind of access level support should have. The default access level choice is write access permission in all namespaces.

  • Read Only All: Allow read operations in all namespaces in this tenant.
  • Read Write All:  Allow read and write operations in all namespaces in this tenant.
  • Read Write with Specific Namespace: Allow read and write operations only in specific namespaces in this tenant.
