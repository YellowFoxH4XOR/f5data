K62136125: Unable to setup high availability (HA) configuration between two BIG-IQ systems due to SSH error

Type
Support Solution
Published
2020-11-04
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K62136125

Description

  • Customer is unable to setup HA BIG-IQ system
  • Getting error message when performing ssh between BIGIQ

    [root@BIGIQ1:Active:Standalone] config # ssh root@10.10.10.2
    no matching cipher found: client aes128-cbc,aes256-cbc server aes128-ctr,aes192-ctr,aes256-ctr

    [root@BIGIQ2:Active:Standalone] config #     ssh root@10.10.10.1
    ssh_exchange_identification: Connection closed by remote host

     

Environment

  • BIG-IQ
  • HA Setup

Cause

sshd setting has specific allow addresses and include option. See example below.

[root@BIGIQ1:Active:Standalone] config # tmsh list /sys sshd all-properties
sys sshd {
    allow { ALL }
    banner disabled
    banner-text none
    description none
    fips-cipher-version 0
    inactivity-timeout 0
    include "<list of ciphers>     <-----------
    Macs list of mac"              <-----------
    log-level info
    login enabled
    port 22
}
[root@BIGIQ1:Active:Standalone] config #


[root@BIGIQ2:Active:Standalone] config # tmsh list /sys sshd all-properties
sys sshd {
    allow { list of IP Addresses } <-----------
    banner disabled
    banner-text none
    description none
    fips-cipher-version 0
    inactivity-timeout 0
    include "Ciphers <list of ciphers>   <-----------
    Macs <list of mac>"                  <-----------
    log-level info
    login enabled
    port 22
}
[root@BIGIQ2:Active:Standalone] config #

Recommended Actions

 

  1. Revert this back to the default settings for now.

    For BIG-IQ1

    1. Login to CLI
    2. Enter tmsh
    # tmsh
    3. allow ALL
    # modify sys sshd allow replace-all-with { ALL }
    4. change include to none
    # modify sys sshd include none
    5. save config
    # save sys config


    For BIG-IQ2


    1. Login to CLI
    2. enter tmsh
    # tmsh
    3. change include to none
    # modify sys sshd include none
    4. save config
    # save sys config
     
  2. Now try to SSH again on each device and vice versa to confirm.
  3.  If SSH is working proceed to setup BIG-IQ HA
