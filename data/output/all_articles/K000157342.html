Description

After the upgrade, the MySQL service is down, and restarting it does not bring it back up.

 

# show /sys service localdbmgr

localdbmgr      down, waiting for mysql to release running semaphore

 

# show /sys service mysql

mysql         down, Failed to initialize MySQL

 

Environment

BIG-IP LTM

ASM is not Provisioned

Recommended Actions

To resolve this issue, here are the possible options:

 

Option #1: Move ibdata1, ib_logfile0, and ib_logfile1 to /shared, restart MySQL, and then load UCS if needed when the device is back online.

 

Commands:

# cd /var/lib/mysql/

# mv ibdata1 ib_logfile0 ib_logfile1 /shared/

# tmsh restart sys service mysql

# tmsh load sys ucs <file-name> no-license

 

Please note that the MySQL restart will result in an offline state until the database is up again.

 

Option #2: If Option #1 does not fix this, rollback to the previous version and reinstall the software.
