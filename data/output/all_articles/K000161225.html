K000161225: iRule modification issues after upgrade to 17.1.3.2

Type
Support Solution
Published
2026-05-12
Updated
2026-06-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000161225

Description

After upgrading to BIG-IP LTM version 17.1.3.2, the existing iRule detail page does not load.
The list of configured iRules is visible, but clicking on any iRule to view or edit its details results in a blank page as in example below:

Environment

  • BIG-IP LTM
  • Version: 17.1.3.2
  • Affected Feature: iRule management via the GUI

Cause

Bug ID 2290709

Answer/Recommended Actions

  • The Engineering Hotfix (EHF) for ID 2290709 ( Hotfix-BIGIP-17.1.3.2.0.39.32-ENG ) is now available for download on myF5. You will be require to login with valid login credentials before you can download the EHF.
  • As a temporary workaround, you may use CLI to view and manage your existing iRules.

Additional Information

None
