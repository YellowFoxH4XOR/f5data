Disabling ICMP

To disable Internet Control Message Protocol (ICMP) health checks, perform the following steps:

  1. To set the behavior in the bigd database, type the following command:

    bigpipe db set Common.Bigip.Bigd.NodePingOff = 1

  2. To save this change and reinitialize bigd, type the following command:

    bigstart reinit bigd

Enabling ICMP

To enable ICMP health checks, perform the following steps:

  1. To set the behavior in the bigd database, type one of the following commands:

    bigpipe db set Common.Bigip.Bigd.NodePingOff = 0

    or

    bigpipe db unset Common.Bigip.Bigd.NodePingOff

  2. To save this change and reinitialize bigd, type the following command:

    bigstart reinit bigd
