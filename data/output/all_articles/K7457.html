Topic

The Requests field, found in the Statistics section for virtual server, pool, and node object types of the BIG-IP LTM system, reports the number of requests based on protocol profile used.
  • If an L7 protocol profile such as HTTP or FTP was used, the Requests field reports the number of client-side HTTP or FTP requests made since the last reset.
  • If an L7 protocol profile was not used, the number of requests is equal to the number of connections (TCP/SCTP) or the number of client-side flows (all other IP protocols) since the last reset.
