K000157871: BIG-IP is not responding to SNMP get request

Type
Support Solution
Published
2025-11-23
Updated
2025-11-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 21.X.X, 17.X.X, 21.0.X, 21.0.0, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source

Description

Your monitoring system is marking the BIG-IP down because it is not responding to SNMP get request. Routes are all in place.

Environment

  • LTM

Cause

None

Recommended Actions

Restart snmpd. There is no service impact.

bigstart restart snmpd

None
