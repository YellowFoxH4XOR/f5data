K000137743: BIG-IP reset with "No local listener" message for servers's SYN_ACK

Type
Support Solution
Published
2023-11-30
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000137743

Description

In the server side connection, server reply with SYN_ACK, and BIGIP resets with No local listener.

 

Environment

  • BIG-IP
  • Standard virtual server
  • Reset cause: No local listener
 

Cause

  • routing config or config issue.


Recommended Actions

Take tcpdump with host backend server and port.

e.g.

tcpdump -ni0.0:nnn host and port -s0 -w /var/tmp/server.pcap

 

Check which vlan server's SYN_ACK is on.

You may see the different vlan from BIGIP's SYN packet.


If Asymmetric routing should be allowed, then follow:

  • K13558: Allowing asymmetrically routed connections across multiple VLANs (11.x - 16.x)
