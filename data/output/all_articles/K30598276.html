Known Issue

The qkview utility may fail to properly collect certain diagnostic files in the /var/lib/mysql folder.

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP system running an instance of MySQL as a result of provisioning certain BIG-IP modules, such as BIG-IP Analytics or BIG-IP ASM.
  • You run the qkview utility on the BIG-IP system to collect diagnostic information.

MySQL writes error messages to the /var/lib/mysql/mysqld.err file. When the qkview utility runs, the BIG-IP system collects the mysqld.err file from the /var/lib/mysql folder but fails to collect rotated files, such as mysqld.err.1, mysqld.err.2.gz, and so on. Additionally, the qkview utility does not truncate the /var/lib/mysql/mysqld.err file and consequently may damage the qkview output. For more information, refer to K63042400: The libtar utility may corrupt the qkview output.

Impact

The qkview output may omit some diagnostic files required by F5 Technical Support. Additionally, the existence of a /var/lib/mysql/mysqld.err file larger than 2 GB may damage qkview output.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice rotated mysqld.err files in the /var/lib/mysql folder of the BIG-IP system but none in the qkview output. In the following example, the command to list files in the /var/lib/mysql folder of the BIG-IP system results in output showing rotated files named mysqld.err.1 and mysqld.err.2.gz:

    ls -l /var/lib/mysql/mysqld.err*
    -rw-r-----. 1 mysql root 103741824 2017-08-29 21:59 mysqld.err
    -rw-r--r--. 1 mysql root 999 2017-08-29 22:01 mysqld.err.1
    -rw-r--r--. 1 mysql root 985 2017-08-29 03:48 mysqld.err.2.gz

    However, in the following example, based on the same system, the command to list qkview files collected from a qkview output file named bigip.qkview does not show the mysqld.err.1 and mysqld.err.2.gz files.

    tar -ztvf /var/tmp/bigip.qkview | grep mysqld.err
    -rw-r----- mysql/root 103741824 2017-08-29 21:59 var/lib/mysql/mysqld.err

  • You notice that the qkview utility collects a /var/lib/mysql/mysqld.err file that is not truncated as expected.

    Note: By default, the qkview utility truncates files larger than 5 MB. You can run the qkview utility with the -s0 option to increase the truncation limit to a maximum of 75 MB for any given log file.
