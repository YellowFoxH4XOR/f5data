Known Issue

Virtual Private Network (VPN) connection initiation to the BIG-IP APM system may fail unexpectedly.

This issue occurs when all of the following conditions are met:

  • Users attempt to establish VPN connections to the BIG-IP APM system using a browser or BIG-IP Edge Client for Windows, Mac, or Linux.
  • The VPN client components used for the connection are downloaded from a BIG-IP APM system that contains the code fix for ID 430962.

This issue is the result of a regression introduced by the software changes made to address ID 430962.

Impact

Some users are unable to establish VPN connections to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP Edge Client exits and generates an F5CORE*.dmp file to the client system when initiating VPN connections.
  • Client browsers freeze or restart when attempting to establish VPN connections to the BIG-IP APM system.
  • Browser crash reports reference the urxdialer.dll file.
  • You may see log messages similar to the following example in the Edge Client troubleshooting report:
