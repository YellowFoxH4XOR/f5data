Issue

Error Message

err logger: /usr/libexec/aws/aws-failover-tgactive.sh (<traffic group name>): Failed to describe network interfaces

In this error message, note the following:

  • <traffic group name> is the name of the affected traffic group that is unable to trigger failover

For example:

err logger: /usr/libexec/aws/aws-failover-tgactive.sh (traffic-group-1): Failed to describe network interfaces

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions are met:

  • The BIG-IP Virtual Edition (VE) system running on the Amazon Web Services (AWS) Elastic Compute Cloud (EC2) service is not configured with the appropriate route information for the AWS API to access the AWS resource.
  • The BIG-IP VE system running on the AWS EC2 cloud service is not configured with the appropriate AWS EC2 access key and secret key.
  • The AWS EC2 user account does not have the AWS Identity and Access Management (IAM) role permissions to use the DescribeNetworkInterfaces API action.

During the failover process, BIG-IP VE systems in a high-availability (HA) configuration use the AWS API with the assigned access key and secret key to access the AWS resource through the management network. Additionally, the AWS user account must have the necessary AWS IAM role permissions to use the DescribeNetworkInterfaces API action.

Impact

The BIG-IP VE system running on the AWS EC2 cloud service is unable to fail over to its peer system in an HA configuration.

Recommended Actions

You must rectify the error condition, depending on which one you have encountered:

  • If your system does not have the appropriate management route for the AWS API to access the AWS resource, you must configure the appropriate route for the management network to do so. For information about adding management routes, refer to K13284: Overview of management interface routing (11.x - 12.x).
  • If your system does not have the appropriate access key and secret key, you must obtain the necessary access key and secret key from the AWS EC2 management console and configure your system with them. For information about obtaining and configuring the access key and secret key, refer to K14827: Configuring failover for BIG-IP VE on Amazon EC2.
  • If your AWS user account does not have the appropriate access permissions to use the AssignPrivateIpAddresses and DescribeNetworkInterfaces API actions, you must grant your AWS user account the necessary permissions to use the affected API action. For information about granting permissions to an AWS user account, refer to the AWS Identity and Access Management documentation available on the AWS documentation site.
