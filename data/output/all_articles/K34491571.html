Issue

Error Message

tmm[<PID>]: 01230111:2: Interface <Interface.Number>: HSB DMA lockup on <Condition Message>

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process.
  • <Interface.Number> is the interface identifier that is reporting the problem.
  • <Condition Message> is the condition under which the failure occurred.

For example:

crit tmm14[16127]: 01230111:2: Interface 0.15: HSB DMA lockup on transmitter failure

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when any of the following conditions is met:

  • The HSB hardware experiences some lockup conditions under certain circumstances.
  • A Virtual Clustered Multiprocessing (vCMP) guest shuts down.

Impact

Traffic is interrupted and a failover may be triggered. The BIG-IP system may reboot to recover. A core file may also be generated because this condition usually leads to the TMM missing heartbeats, and so sod stops it. If this error message occurs during shutdown of a vCMP guest, then there is no impact.

Recommended Actions

If this situation occurs, F5 recommends that you capture a QKView file and open a ticket with F5 Support to look into the cause of the issue and prevent it from occurring again.

For vCMP environments, the affected vCMP guest may have experienced Bug ID 715061. F5 recommends that you review Bug ID 715061 for information about workarounds and/or fixes for the known issue.
