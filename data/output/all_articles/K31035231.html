K31035231: Allow BIG-IQ licensing when BIG-IP limits httpd to GET POST

Type
Support Solution
Published
2022-09-14
Updated
2025-04-03
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K31035231

Description
BIG-IQ is not able to license a BIG-IP that limits HTTPD methods

Environment

  • BIG-IP with "LimitExcept" in its httpd configuration
  • Licensing from BIG-IQ

Cause
BIG-IQ requires more methods via HTTPD than is allowed.

Recommended Actions

  1. Obtain the discovery address of the BIG-IQ.
  2. From a bash shell prompt on the BIG-IP, 
    1. cd /config
    2. vi bigip_base.conf
    3. locate the sys httpd configuration portion and the line with "deny from all"
    4. Press I to Insert and insert a new line directly below this line as follows:
      1. allow from <BIG-IQ IP as obtained in step 1 above>
    5. Save the file with :wq!
    6. tmsh load sys config
