Known Issue

The mcpd process may leak memory and produce a core file.

This issue occurs when all of the following conditions are met:

  • Your system uses a BIG-IP LTM pool that is configured with a health monitor.
  • The monitor logs a status change message.
  • The pool status is queried from the BIG-IP system using the Traffic Management Shell (tmsh), Configuration utility, or with SNMP.

Impact

Over time, system performance may degrade and the BIG-IP system may eventually become unresponsive or reboot due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H497319 on the Diagnostics > Identified > Medium | High page.
  • You notice a progressive increase in the amount of memory that the mcpd process uses.
  • The BIG-IP system unexpectedly fails over to another system in the device group.
  • The BIG-IP system generates an mcpd core file to the /shared/core directory.
