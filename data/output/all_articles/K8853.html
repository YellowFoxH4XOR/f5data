Known Issue

This is the result of a known issue. If you configure FirePass to use RADIUS authentication with an RSA SecurID server, authentication fails if the user’s token is in New Pin Mode and the user connects to the FirePass controller using Firefox 2.x.

F5 Networks Product Development tracked this issue as CR95695 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, this issue was fixed in Cumulative HF-602-4 issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
