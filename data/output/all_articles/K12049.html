Known Issue

This is the result of a known issue. The BIG-IP ASM correctly extracts dynamic parameter values that contain URL encoded characters; however, the BIG-IP ASM evaluates the values after they have been normalized, and attempts to compare the encoded parameter value against the normalized value. This behavior results in a mismatch error.

F5 Product Development tracked this issue as ID 339548 and it was fixed in BIG-IP ASM 10.2.2. For information about upgrading, refer to the BIG-IP ASM release notes.
