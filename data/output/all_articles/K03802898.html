Description

For virtual servers associated with traffic-matching-criteria (TMC),  adding or deleting iRules to/from VS deletes the associated virtual-address object and in-turn causes the virtual-server to stop accepting new  connections.

Environment

  • Traffic-matching-criteria with address list is defined and configured on a virtual server
  • An iRule is added to or deleted from this virtual-server

Cause
Releases that include fix for ID876805 are affected by this problem.

Recommended Actions

To work around this problem, Set 'auto-delete' to 'false' on the virtual-address settings
