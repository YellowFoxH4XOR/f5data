Description

Multiple messages similar to the following are being logged to /var/log/snmpd.log:
 

snmpd[XXXX]Connection from UDP/IPv6: [::ffff:x.x.x.x]:<PORT> REFUSED

Note:  XXXX will be the PID used by the snmpd process,  x.x.x.x is the IP address being REFUSED and <PORT> will be the random source port used by that IP.

Environment

  • F5 device managed by SNMP

Cause
The refused IP address was not allowed in list of Authorized SNMP management stations for this device.

Recommended Actions

  1. In case IP address suppose to be part of the Allow corresponding IP addresses allowed list, add it.
  2.  Use the following command line commands to clear the logs:
    tmsh stop sys service snmpd
    rm /var/log/snmpd.log
    tmsh start sys service snmpd
     
  3. Use the following commands to restart services:
    bigstart restart sflow_agent
    bigstart restart snmpd alertd nokiasnmpd
 

Additional Information
Configure access to the BIG-IP's SNMP agent from your remote systems

Before you start this task, you should gather the IP addresses or subnets of the remote systems that require access to the SNMP agent on this BIG-IP® system.

  1. On the Main tab, click System > SNMP > Agent > Configuration .
  2. In the Client Allow List area, for the Type setting, select either Host or Network, depending on whether the IP address you specify is a host system or a subnet.
    Note: By default, SNMP is enabled only for the BIG-IP system loopback interface (127.0.0.1).
  3. In the Address field, type either an IP address or network address from which the SNMP agent can accept requests.
  4. If you selected Network in step 2, type the netmask in the Mask field.
  5. Click Add.
  6. Click Update.
The BIG-IP system now contains a list of IP addresses from which SNMP requests are accepted.
