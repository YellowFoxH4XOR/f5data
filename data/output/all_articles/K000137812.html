Description

Deleting large files as part of housekeeping disk space maintenance caused impact to production traffic.

 

Environment

  • BIG-IP
  • Disk space maintenance
  • CPU High I/O wait
  • Traffic disruption

Cause

CPU High I/O wait across all CPU cores

Recommended Actions

Perform housekeeping disk maintenance activities during a maintenance window to minimise unexpected impact.

Using the rsync command instead of rm command can reduce the impact of disk activity.

For example, to remove all contents from /var/tmp/.config.tmp/ slowly with a bwlimit:

mkdir /var/tmp/empty-dir ; rsync --delete -a --progress --bwlimit=1000 /var/tmp/empty-dir/ /var/tmp/.config.tmp/

Additional Information

High I/O (Input/Output) wait, often referred to as "I/O wait," occurs when the CPU is idle, waiting for data to be read from or written to a storage device (such as a hard drive or SSD). In a system experiencing high I/O wait, the CPU spends a significant amount of time waiting for data to be fetched from or sent to storage, and during this time, it is not actively processing other tasks.

You may use the Linux tool "iostat" to monitor average CPU I/O wait.
