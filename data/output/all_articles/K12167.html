K12167: GPAnywhere policies are not included in a backup

Type
Knowledge
Published
2010-09-30
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 7.0.0, 6.1.0
Source
https://my.f5.com/manage/s/article/K12167

Topic

Currently, GPAnywhere policies are not included in the backup file when a backup is made of the FirePass configuration. After restoring from a FirePass backup, all GPAnywhere polices will be lost. Prior to restoring, note your GPAnywhere policies so you can manually replicate them after the restore is complete.

Note: For more information about GPAnywhere, refer to K9157: Overview of the Windows Group Policy inspector.

F5 Networks Product Development is tracking a request for enhancement (RFE) to include the GPAnywhere policies in the backup file as ID 341364
