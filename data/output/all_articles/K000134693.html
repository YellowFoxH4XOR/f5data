K000134693: Edge client uses IE11 or IE7 mini browser

Type
Support Solution
Published
2023-05-29
Updated
2023-05-31
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000134693

Description

On Dial-up option on the Azure AD authentication it says it is using IE7

Environment

  • BIG-IP
  • APM
  • Edge client mini browser

Cause

Why do you see the IE7 version.

Here is the explanation:

The Edge client has WLI (Windows Logon Integration) client that connects to the BIG-IP APM.

This WLI client, when built was using IE7 and the User-Agent was set to MSIE7. Even though the WLI client is now using IE11 the User-Agent was never changed (there is a request to fix this).

When the WLI client with the User-Agent MSIE7 connects to the BIG-IP APM (which in turn connects to Azure AD) the Azure AD interprets the User-Agent header as the version of the browser (which it is not).

 

The issue can be summarized:

The User-Agent set by the WLI client was never updated since it was created and used IE7.

Azure interprets (which is a misinterpretation) the User-Agent as the browser version.

 Recommended Actions

This can be safely ignored.
