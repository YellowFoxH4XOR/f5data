Topic

You should consider using this procedure under the following condition:

  • You want to evaluate potential hardware issues without booting the BIG-IP system into the End-User Diagnostics (EUD) software.

Description

Platform diagnostics were introduced in BIG-IP 11.4.0, and run a series of hardware diagnostics to quickly identify hardware failures on an F5 BIG-IP platform.

The platform diagnostic tests are only a subset of the tests available to the EUD software. However, the benefit is that you can perform the tests without actually booting the system into the EUD software. The following table briefly describes the available diagnostics tests:

NameTest
diskReports SMART data from hard drives
hwaccelExecutes diagnostics against SSL and Compression cards
miscValidates that PCI components are available to TMOS

Additionally, some of the platform diagnostic tests can be performed while the BIG-IP system is processing application traffic. However, some of the platform diagnostic tests can only be run while the BIG-IP system is not passing traffic and all daemons have been stopped.

Each platform diagnostic test will complete with a PASS, FAIL, or NOT RUN status message. The test will also create the /var/db/platform_check/platform_check.xml XML file, which contains test results.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command line access to the BIG-IP system.

Procedures

You can perform platform diagnostics using any of the following procedures:

Running a subset of platform diagnostics tests while the BIG-IP system is processing traffic
Running a full set of platform diagnostics tests while the BIG-IP system is not passing traffic and all processes have stopped
Running a specific platform diagnostics test from the Traffic Management Shell

Running a subset of platform diagnostics tests while the BIG-IP system is processing traffic

Note: If a test is not specified, the system will run all tests except the hardware acceleration tests.

Impact of procedure: Performing the following procedure will have no impact to your BIG-IP system.

  1. Log in to the BIG-IP command line.
  2. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  3. To run all platform diagnostic tests, type the following command:

    run util platform_check

    The command output appears similar to the following example:

    Disk Tests
      SMART (/dev/hda): NOT RUN
        Drive does not support SMART
      SMART (/dev/sda): PASS

    Hardware Acceleration Tests
      SSL (02:00.0): NOT RUN
       Test cannot run while the system is active, "bigstart stop" required.

    Miscellaneous Tests
      PCI: PASS

    Overall Platform Health: PASS - 2 tests not run

Running a full set of platform diagnostics tests while the BIG-IP system is not passing traffic and all processes have stopped

Note: The hardware acceleration test will not run if the BIG-IP system is active. You must first run the bigstart stop command, which will interrupt all traffic processing.

Impact of procedure: Performing the following procedure will have a significant impact on your BIG-IP system. You should run this procedure only on a system that is not actively processing traffic.

  1. Log in to the BIG-IP command line.
  2. To stop traffic processing, type the following command:

    bigstart stop

  3. Log in to the tmsh utility by typing the following command:

    tmsh

  4. To run all platform diagnostic tests, type the following command:

    run util platform_check

    The command output appears similar to the following example:

    Disk Tests
         SMART (/dev/sda): PASS
         SMART (/dev/sdb): PASS

       Hardware Acceleration Tests
         Compression (02:00.1): PASS
         Compression (02:00.2): PASS
         Compression (02:00.3): PASS
         Compression (02:00.4): PASS
         SSL (02:00.1): PASS
         SSL (02:00.2): PASS
         SSL (02:00.3): PASS
         SSL (02:00.4): PASS

       Miscellaneous Tests
         PCI: PASS

       Overall Platform Health: PASS

    Note: Some tests may not be available on certain BIG-IP platforms. If a test is not supported on a particular platform, the system will return a message that appears similar to the following example:

    No applicable tests found for this test suite

  5. To resume traffic processing, type the following command:

    bigstart start

Running a specific platform diagnostics test from the Traffic Management Shell

Note: The hardware acceleration test will not run if the BIG-IP system is active. You must first run the bigstart stop command, which will interrupt all traffic processing.

The specific tests available for the platform diagnostic utility include disk, hwaccel, and misc. To run a specific test, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To run a specific test, type the following command:

    run util platform_check <test>

    In this command, note the following:

    • <test> is the specific test you want to perform: disk, hwaccel, or misc

    For example:

    run util platform_check disk

    Disk Tests
        SMART (/dev/sda): PASS
        SMART (/dev/sdb): PASS
