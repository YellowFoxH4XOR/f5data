K3240: SNMP OIDs that can be queried for the same type of information that is provided by the bigpipe summary command

Type
Knowledge
Published
2006-02-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • BIG-IP 4.X: 4.6.4
Source
https://my.f5.com/manage/s/article/K3240

Topic

You can obtain values that are reported by the bigpipe summary command through SNMP, except for the following:

  • BIG-IP total # pkts
  • BIG-IP total # bits

Note: All of the SNMP object names listed in this Solution contain the prefix .iso.org.dod.internet.private.enterprises.f5.f5systems.loadbal.globals.globalStats; therefore, if the listed object name is .ExampleSnmpStat, the full path for that object would be: .iso.org.dod.internet.private.enterprises.f5.f5systems.loadbal.globals.globalStats.ExampleSnmpStat

The bigpipe summary commands that do match SNMP objects output are:

  • System uptime
  • Total number of connections
  • Total number of inbound packets
  • Total amount of inbound traffic
  • Total number of outbound packets
  • Total amount of outbound traffic
  • Total number of times no nodes in a virtual server were available
  • Total number of TCP packets denied
  • Total number of UDP packets denied
  • Total number of denied TCP packets addressed to a virtual server
  • Total number of denied UDP packets addressed to a virtual server
  • Total number of packets dropped because the BIG-IP had reached maximum connections
  • Total number of duplicate SYN SSL packets received by virtual servers
  • Total number of duplicate SYN packets received with a different destination
  • Total number of duplicate SYN packets received for a down node
  • Total number of packets dropped because a virtual server was in maintenance mode
  • Total number of packets dropped because a virtual server connection limit was met
  • Total number of packets dropped because a node connection limit was met
  • Total number of packets dropped because they were not SYN packets
  • Total number of packets dropped because they did not match a destination
  • Total number of fragments dropped because they did not contain a destination port
  • Total number of fragments dropped because they did not match an existing connection
  • Total number of packets dropped by the standby unit
  • Total number of TCP connections expired by BIG-IP
  • Total number of UDP connections expired by BIG-IP
  • Total number of SSL connections expired by BIG-IP
  • Total number of persistence records that have expired
  • Total number of BIG-IP memory errors
  • Number of installed CPUs
  • Current system multi-processor mode
  • Total system memory (RAM)
  • Amount of system memory (RAM) in use

System uptime

The bigpipe summary command reports BIG-IP uptime as BIG-IP total uptime.

To obtain this data through SNMP, poll for the following:

Object NameOID
.globalStatUptime3.6.1.4.1.3375.1.1.1.2.1

The value for this OID is provided in seconds.

Thebigpipe summary command reports the total number of connections since the last reboot as BIG-IP total # connections.

To obtain this data through SNMP, poll for the following:

Object NameOID
.globalStatTotalConn.1.3.6.1.4.1.3375.1.1.1.2.12
