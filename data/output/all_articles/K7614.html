Known Issue

This is the result of a known issue. The bigpipe shell command starts the bigpipe utility in its shell mode. When you use the list or show commands, the bigpipe shell utility causes a memory leak. For example, the following command will cause a memory leak in the bigpipe process when you run it in bigpipe shell mode:

bp>virtual show

F5 Product Development tracked this issue as CR79026 and it was fixed in version 9.4.2. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator Release Notes.
