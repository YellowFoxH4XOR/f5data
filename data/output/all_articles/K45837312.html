Description

This solution describes the conditions and resolution for the following OAuth error message.

  • OAuth authentication fails.
  • Symptoms
  • You observer the following log messages in /var/log/apm:
<bigip_hostname> err apmd[13980]: 01490290:3: /Common/<access_policy_name>:Common:<sessiond_ID>:/Common/rentalcopilotqa.cintas.com_policy_act_oauth_scope_ag: OAuth Scope: failed for jwt-provider-list '/Common/Azure_JWT_Provider' , error: Audience not found : Claim audience= https://<url> JWT_Config Audience=

In the above log message the Session ID refers for the unique APM Session ID:

K15387: Overview of BIG-IP APM session cookies
 

Environment

  • Access Policy Manager (APM)

  • OAuth Client/Resource Server

  • Java Web Token (JWT) configuration.

Cause

This issue occurs JSON Web Token configuration is missing the Audience or the configured Audience is incorrect.

Recommended Actions

Add or correct the Audience in the JSON Web Token configuration:

  1. Login to the Big-IP Admin GUI.
  2. Navigate to Access›Federation>JSON Web Token>Token Configuration.
  3. Click on the Token Configuration name.
  4. Enter the Audience name in the "Audience" field.
  5. Click "Add."
  6. Click "Save."
