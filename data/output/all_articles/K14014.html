Topic

You should consider using this procedure under the following condition:

  • You want to display a custom image on the BIG-IP APM login page.

Description

BIG-IP APM supports the ability to customize the login pages that are presented to users. This procedure explains how to display a custom image on the login page of an access policy. The following conditions apply:

  • The image is not scaled and displays in its original size.
  • GIF, JPG, PNG, and BMP image types are supported.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have an image file of the correct size and supported format.

Procedures

Adding an image to the login page in the visual policy editor

Note: Changes to an access policy affect all virtual servers configured with the access policy.

Impact of procedure: Large image files may impact login page load times.

  1. Log in to the Configuration utility.
  2. Go to Access Policy > Access Profiles > Access Profiles Lists.
  3. Select Edit to the right of the access profile name.
  4. Locate the Logon Page agent and select the name that you want to edit.
  5. For Customization, for Front Image, select Replace Image.
  6. From the image selector pop-up window, select Add New Picture.
  7. Select the image and select Update.
  8. SelectSave.
  9. Select Apply Access Policy.
Reverting the login page image to default in the visual policy editor

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Access Policy > Access Profiles > Access Profiles Lists.
  3. Select Edit to the right of the access profile name.
  4. Locate the Logon Page policy item and select the name that you want to edit.
  5. Under Customization, for Front Image, select Revert to Default.
  6. Select Save.
  7. Select Apply Access Policy.
