K000137341: HTTP or HTTPs monitors created or modified by WebGUI display the destination port incorrectly on CLI

Type
Support Solution
Published
2023-10-24
Updated
2023-11-16
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000137341

Description

If you create or modify an HTTP or HTTPS monitor in the WebGUI, the CLI displays the destination port incorrectly. This is cosmetic and has no operational impact.

 

list ltm monitor http GUI-HTTP-MON all-properties

ltm monitor http GUI-HTTP-MON {

  adaptive disabled

  adaptive-divergence-type relative

  adaptive-divergence-value 25

  adaptive-limit 200

  adaptive-sampling-timespan 300

  app-service none

  defaults-from http

  description none

  destination *.*

list ltm monitor http GUI-HTTP-MON all-properties | grep destination

  destination *.*

 

Environment

  • BIG-IP
  • WebGUI
  • HTTP/HTTPS monitors

 

Cause

Bug ID 926085: In WebUI node or port monitor test is not possible, but it works in TMSH

 

Recommended Actions

No action is required.
 

Additional Information

When the monitor is applied to a pool, you can use the command tmsh show ltm monitor HTTP <name>, and the destination will appear correctly with a colon.

tmsh show ltm monitor http GUI-HTTP-MON | grep Destination

Destination: 192.168.1.1:80
