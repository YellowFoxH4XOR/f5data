K81451045: BIG-IP AFM Network Firewall rule with geolocation not working after upgrade to v15.1.0 or higher

Source

Description

After software upgrade to v15.1.0 or higher, Network Firewall that uses geolocation is not working as expected.

Environment

  • Software upgrade to v15.1.0 or higher
  • Network Firewall rule with geolocation

Cause

There is a known bug that could cause this behavior:
Bug ID 1016309: When two policies with the same properties are configured with geo property, the geo for the second policy is ignored.

Recommended Actions

There is no workaround for this issue. Please contact F5 Support to confirm bug ID and request Engineering Hot Fix, if needed.
