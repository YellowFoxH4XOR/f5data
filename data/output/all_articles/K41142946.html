Description

You cannot connect to the BIG-IP using SSH. You get the following error:

Internal Fault: chaos in SSH 2 transport layer

There is normal GUI access.

The error shows up before putting the credentials in.

Environment

  • SSH using Putty

Cause

This is an external error related to the terminal being used (not F5 related).

Recommended Actions

Try connecting with a different terminal for SSH access. For example some known SSH clients are: SecureCRT, MremoteNG or MobaXterm.
