K10318605: Connections not working through new VIP

Type
Support Solution
Published
2022-02-24
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K10318605

Description

Created a new (VIP) Virtual Server on the F5 and application is not working as expected

  • Can ping the server IP and telnet the server IP and port from the F5
  • Application not working when going through the F5

Environment

  • Created new VIP on the F5
  • Created Pool and applied to the VIP. 
  • Monitor shows pool is marked as up
  • Tcpdump capture shows packets getting to the VIP and from the F5 to the server, but server is not responding

Recommended Actions

        Apply SNAT Automap to VIP to ensure traffic is returning from the server through the F5
           Source Address Translation > Automap

Additional Information

K7336: The SNAT Automap and self IP address selection
