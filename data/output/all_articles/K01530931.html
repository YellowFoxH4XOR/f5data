Description

When adding "0" ( zero ) in Allowed File Types, gives the following error:

"«File Type» is a required field."

Environment

  • Adding an integer as a file type

Cause

"0" is not considered File type, hence not allowed.

Recommended Actions

"0" ( zero ) may still be added, however, in its HTML URL encoding form.
  1. Browse to Security > Application Security > File Types > Allowed File Types
  2. Click "Create" button
  3. Add File type; Select "Explicit" and add: %30
  4. Save
  5. Apply Policy

Additional Information

To add a different integer, refer to HTML URL Encoding Reference
