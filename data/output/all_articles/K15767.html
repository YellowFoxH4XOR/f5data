Known Issue

The BIG-IP configuration may fail to load after you manually rename a virtual server.

This issue occurs when all of the following conditions are met:

  • You manually edit the /config/bigip.conf file to rename a virtual server.
  • The virtual server is configured with a pool that contains no members or has a pool which includes members and a monitor.
  • You attempt to reload the configuration using the Traffic Management Shell (tmsh).

Impact

The BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H486206 on the Diagnostics > Identified > Medium screen.
  • You receive an error message similar to the following example:

    01020056:3: Error computing object status for virtual_server (<old virtual server name>).
    Unexpected Error: Loading configuration process failed.

  • The BIG-IP configuration fails to load.

Workaround

To work around this issue, you can manually edit the /config/bigip.conf file and temporarily remove the pool association from the affected virtual server.

Impact of workaround: You should perform the following procedure during a maintenance window, as traffic may be temporarily disrupted while the edited configuration loads.

  1. Log in to the BIG-IP command line.
  2. Create a backup copy of the /config/bigip.conf file by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.sol15767

  3. Edit the /config/bigip.conf file using the text editor of your choice.
  4. Locate the stanza for the affected virtual server.

    For example:

    ltm virtual /Common/test_vs1 {
    destination /Common/10.10.10.10:80
    ip-protocol tcp
    mask 255.255.255.255
    pool /Common/test_pool
    profiles {
    /Common/tcp { }
    }
    source 0.0.0.0/0
    translate-address enabled
    translate-port enabled
    }

  5. Remove the line that includes the pool association.

    For example:

    ltm virtual /Common/test_vs1 {
    destination /Common/10.10.10.10:80
    ip-protocol tcp
    mask 255.255.255.255
    pool /Common/test_pool <---
    profiles {
    /Common/tcp { }
    }
    source 0.0.0.0/0
    translate-address enabled
    translate-port enabled
    }

  6. Save the changes and exit the text editor.
  7. Reload the configuration by running the following command:

    tmsh load sys config

  8. Once the configuration reloads, you can add the pool again using tmsh or the Configuration utility.
