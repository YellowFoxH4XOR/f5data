K9628: Switchboard failsafe may be triggered when loading a large number of VLANs

Topic

When loading a configuration with a large number of VLANs, the configuration my take a long time to load as the VLAN information is loaded on the switch hardware. For example, a configuration with more than 4000 VLANs assigned to only one interface may take more than 10 minutes to load on a BIG-IP LTM system running version 9.4.5, or more than six minutes to load on a BIG-IP LTM running version 9.4.6.

During this long load time, the switchboard failsafe mechanism may be triggered, resulting in a restart of the bcm56xxd process. This behavior occurs when the switch driver fails to process the switchboard heartbeat in a timely manner. This issue may occur more than once during loading of the configuration, and is due to the switch driver requiring a small amount of time to load each VLAN onto the interface.

To prevent the switchboard failsafe mechanism from triggering and restarting the bcm56xxd process during a large VLAN load, perform the following procedure:

  1. Log in to the command line.
  2. Disable the switchboard failsafe mechanism by typing the following command:

    bigipipe db Switchboard.Failsafe disable

    This command temporarily disables the failsafe mechanism, allowing the system to load all of the necessary VLANs.
  3. Monitor the CPU load of the bcm56xxd switch driver by typing the following command:

    ps -o%C%c | grep bcm

    Note: The bcm56xxd switch driver load may increase as high as 50 percent. This load will drop once all of the VLANs have been loaded.
  4. Once the switch driver no longer contains a high load, re-enable the switchboard failsafe mechanism by typing the following command:

    bigpipe db Switchboard.Failsafe enable

Note: For information about the maximum number of VLANs supported by platforms, refer to K3539: The maximum number of configurable VLANs

If the bcm56xxd process CPU load remains high after loading all VLANs, or if you encounter issues while loading a larger number of VLANs, contact F5 Support.
