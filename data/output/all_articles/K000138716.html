Description

Configured Cisco ISE as remote TACACS authentication for F5OS following: K000136131 : Configuring Cisco ISE for F5OS TACACS Remote Authenication

When logging in via ssh, client ip and protocol/port are logged in ISE.
However, when logging in via gui, both protocol/port and client ip are logged as "unknown".

This happens not only Cisco ISE, but also any TACACS authentication server with tac_plus
 

Environment

  • F5OS-A / F5OS-C
  • rSeries / Velos
  • Authentication server running tac_plus

 

Cause

  • Bug ID 1494205

 

Recommended Actions

  • No workaround.
