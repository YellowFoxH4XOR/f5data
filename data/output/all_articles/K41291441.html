Issue

Old Behavior

In versions that support device service clustering (DSC) prior to BIG-IP 11.6.0, you can configure a maximum of 15 floating traffic groups for a Sync-Failover device group.

New Behavior

Beginning in BIG-IP 11.6.0, you can configure a maximum of 127 floating traffic groups for a Sync-Failover device group.

Traffic groups allow you to define a group of related configuration objects that can float to another device in a Sync-Failover device group when a BIG-IP device becomes unavailable. Increasing the number of supported traffic groups provides more flexibility for segmenting failover objects and allows for more granular load management when traffic loads vary between traffic groups.

For example, a device with one or more active traffic groups may use more resources due to traffic spikes. By compartmentalizing configuration objects into more traffic groups, you can improve load distribution across the device group by failing specific traffic groups over to devices with more capacity.

F5 Product Development tracked this change as ID 429081.

Impact

You can now configure up to 127 floating traffic groups on a BIG-IP device that is a member of a Sync-Failover device group.
