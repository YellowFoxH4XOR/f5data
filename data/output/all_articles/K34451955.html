Topic

BIG-IP APM Portal Access support for Microsoft Silverlight.

Description

The BIG-IP APM Portal Access feature does not currently support Silverlight. If a user accesses a website with Silverlight objects, the Silverlight objects may fail to load properly.

Silverlight is a programmable web browser plug-in that enables features such as animation and high-definition video. For more information about Silverlight, refer to the Microsoft Silverlight page.
