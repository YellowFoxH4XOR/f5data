Description

Unable to view Virtual Server Statistics. Getting error "General database error retrieving information" when accessing the page

Important: There are multiple reasons as to why you may see this database error when browsing the GUI. Unless this article fits your case exactly, it is recommended to start with General Database Error Retrieving Information in the BIG-IP Configuration Utility , which helps you discover the right article for you.

Environment

BIG-IP LTM 16.x, 15.x

 

Cause

The message occurs when querying large statistics caused by bug ID758073.

 

Recommended Actions

Reset related statistics

tmsh reset-stats ltm virtual

 

Additional Information

Error in /var/log/tomcat/catalina.out

java.sql.SQLException: Wrong data type
