K33244273: HTTPS monitors might share one SSL profile

Support Solution
Published
2019-08-27
Updated

Applies to

Source

Description
When upgrading to version 13.1+, BIG-IP software will create a generic Secure Sockets Layer(SSL) server side profile based on the first monitor instance for use on all https monitor instances that use the same ssl cert/key combination.

  • https monitors have ssl profile attached

Environment

  • HTTPs monitors
  • New SSL Profile

Cause

Prior to BIG-IP 13.1, a single thread process (bigd) was used for https monitors, which does not support hardware acceleration of SSL and Transport Layer Security(TLS) Server Name Indication(SNI) which some HTTP2 servers implementations require. Post BIG-IP 13.1, monitoring is moved into Traffic Management Microkernel (TMM), allowing for hardware supported SSL and TLS SNI monitor processing. With TMM processing https monitors, these monitor instances now require a SSL server side profile attached, where in prior BIG-IP versions only a cert/key combination where required when doing SSL cert authentication. During upgrade, BIG-IP software will create a generic SSL profile based on the name of the first https monitor instance found and use that SSL profile for all https monitor that do not have SSL cert authentication required.

Recommended Actions

None

Additional Information

Example of https monitor configuration in version 12 and 13.1, notice the addition of ssl-profile in BIG-IP version 13.1.3 config.

  • BIG-IP 12.1.4.1 config

list ltm monitor https test-monitor-1
ltm monitor https test-monitor-1 {
    adaptive disabled
    cipherlist DEFAULT:+SHA:+3DES:+kEDH
    compatibility enabled
    defaults-from https
    destination *:*
    interval 5
    ip-dscp 0
    recv none
    recv-disable none
    send "GET /\r\n"
    time-until-up 0
    timeout 16
}

  • BIG-IP 13.1.3 config

list ltm monitor https test-monitor-1
ltm monitor https test-monitor-1 {
    adaptive disabled
    cipherlist DEFAULT
    compatibility enabled
    defaults-from https
    destination *:*
    interval 5
    ip-dscp 0
    recv none
    recv-disable none
    send "GET /\r\n"
    ssl-profile /Common/test-monitor-1_ssl_profile
    time-until-up 0
    timeout 16
}

list ltm profile server-ssl test-monitor-1_ssl_profile
ltm profile server-ssl test-monitor-1_ssl_profile {
    cert none
    cipher-group none
    ciphers DEFAULT
    defaults-from serverssl
    key none
    options { microsoft-sess-id-bug netscape-challenge-bug netscape-reuse-cipher-change-bug sslref2-reuse-cert-type-bug microsoft-big-sslv3-buffer msie-sslv2-rsa-padding ssleay-080-client-dh-bug tls-d5-bug tls-block-padding-bug dont-insert-empty-fragments }
    partition Common
}
