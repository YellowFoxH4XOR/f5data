Description

This article describes how to automate configuration backups on F5OS rSeries appliances and transfer the backup files to an SFTP server using cron jobs. The solution generates backup files with unique, timestamp-based filenames to prevent existing backups from being overwritten.

Environment

  • F5OS-A (rSeries Appliance)
  • Cron jobs configured on the F5OS host
  • SFTP Server

Cause

The F5OS ConfD CLI does not support direct shell command concatenation. Therefore, a shell script must be used to generate the backup, append a timestamp to the filename, transfer the file to an SFTP server, and remove the local copy after a successful transfer.

Recommended Actions

Prerequisites: SSH Key pair generation

Before configuring the cron job, generate an SSH key pair on the F5OS appliance to enable passwordless authentication with the SFTP server.

 

SSH Key Generation Steps

Step 1: Generate the SSH key pair on the F5OS appliance with the following command.

#ssh-keygen -t rsa -b 2048

  • Press Enter to accept the default file location.
  • Press Enter twice to skip passphrase creation.

 

Step 2: Verify that the SSH key files were created.

#ls -la /root/.ssh/

 

Step 3: Display the public key.

#cat /root/.ssh/id_rsa.pub

 

Step 4: Copy the contents of the public key and add it to the authorized_keys file on the SFTP server.

 

Create the Backup Script: Create a file named backup.sh and paste the following contents into the file.

Script:

#!/bin/bash
/usr/bin/f5sh 'config; system database config-backup name <Hostname> proceed yes'
D=$(date +%Y%m%d_%H%M%S)
mv /var/F5/system/configs/<Hostname> /var/F5/system/configs/<Hostname>_$D && echo "put /var/F5/system/configs/<Hostname>_$D" | /usr/bin/sftp <username>@<SFTP Server IP Address>:/path
rm /var/F5/system/configs/<Hostname>_$D

 

Note: Replace <Hostname> with the hostname of your F5OS rSeries appliance and <SFTP Server IP Address> with the actual SFTP server and provide the destination path

 

Example: echo "put /var/F5/system/configs/rSeriesappliance_$D" | /usr/bin/sftp root@10.1.1.2:/home/F5_Backup/

 

Make the script executable using following command:

  • #chmod u+x /root/backup.sh

 

Cron Job Configuration edit the crontab file:

Step 1:  crontab -e

Step 2:  Add the following entry to the crontab.

00 08 * * * /root/backup.sh

 

Note: In this example the cron job executes every day at 08:00 AM based on the timezone configured on the F5OS appliance. You can modify the cron entry based on your needs

 

Additional Information

  • If the backup file is not generated, verify the cron logs and ensure the backup command is correct and has the required permissions.
  • If the SFTP transfer fails, verify that SSH key-based authentication is configured correctly and that the SFTP destination path is valid.
