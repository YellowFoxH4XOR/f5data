K000152435: [F5OS] Configuring TACACS+ authentication for F5OS administrative users

Description

You can configure the TACACS+ protocol for authenticating F5OS administrative users. 

Environment

  • F5OS
  • TACACS+

Cause

NA

Recommended Actions

  • Configure TACACS+ authentication from the webUI
    1. Click on AUTHENTICATION & Access  >> Authentication Settings
    2. To enable an external authentication server, in Authentication Methods, select TACACS+ and save the configuration. The TACACS+ server must be configured for device authentication and reachable from the system.
    3. Click on AUTHENTICATION & Access  >> Server Groups, Add a new Server Group providing a name & type as TACACS+,  save the configuration.
    4. Add servers to the server group by going to AUTHENTICATION & Access  >> Server Groups, select the server group created in step 3, add the server providing IPv4, IPv6 Address or FQDN & port number(The default value is 49) for tacacs traffic and save the configuration. 
  • TACACS+ configuration from the CLI
    1. Log in to the command line interface (CLI) of the system controller or chassis partition using an account with admin access and Change to config mode using command 'config'.
    2. Enable the TACACS+ authentication method using command 'system aaa authentication config authentication-method TACACS_ALL' and save the configuration using 'commit'.
    3. Create a server group and add TACACS server to the server group and save the configuration using following commands.

system aaa server-groups server-group <group-name> config name <group-name> type TACACS
servers server <ip-address> config address <ip-address>
commit

TACACS+ authentication for users is configured on the system. When a user logs in, the system attempts to authenticate them against the configured authentication method. When the account has a match within any of the configured authentication methods, the user is authenticated and given access.

Additional Information

F5OS requires extra roles to be configured on the TACACS server (Group IDs and system authentication roles). Refer K000133763
