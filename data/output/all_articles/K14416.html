Known Issue

Directory permissions may change when you migrate files and directories.

This issue occurs when all of the following conditions are met:

  • You are migrating a parent directory of files that has a restrictive access control list (ACL). 
  • You are using the staged migration (Default) method.

Impact

The system removes the directory's ACL, and users may not have access to the directory.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A directory that previously had an ACL no longer has one.

Workaround

To work around this issue, you can change the migration method to Direct migration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter global configuration mode by typing the following command:

    global
  4. Enter namespace configuration mode using the following command syntax:

    namespace <namespace>

    Replace <namespace> with the name of your namespace.

    For example:

    namespace ns1
  5. Enter volume configuration mode using the following command syntax:

    volume <volume>

    Replace <volume> with the name of your volume.

    For example:

    volume /vol
  6. Change the migrate method using the following command syntax:

    policy migrate-method {direct | staged}

    Replace {direct | staged}  with the direct migration method.

    For example:

    policy migrate-method direct
  7. Exit placement rule configuration mode and return to privileged mode by typing the following command:

    end
