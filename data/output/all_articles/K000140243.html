Description

F5OS tenant self-ip is not accessible after deleting and re-creating the LAG on host

Environment

  • rSeries
  • F5OS
  • BIG-IP Tenant
  • LAG
  • Self-ip
  • VLAN

Cause

Seen behavior is caused by Bug ID1596313

Recommended Actions

There is no fix available at the time of creation of this article. As a workaround, you can perform the following to avoid triggering the issue:

  • Create the LAG and assign the interface and commit the changes
  • Modify the LAG and assign the vlan and commit the changes

If you have already encountered the issue, you may recover an affected tenant by re-deploying or rebooting it.
