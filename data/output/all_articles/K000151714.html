K000151714: UCS backup failed due to /var/ts/dms/policy/policy_versions

Description

UCS backup failed, returning an error similar to the following:

# tmsh save sys ucs test
Saving active configuration...
/var/ts/dms/policy/policy_versions/156/159.plc: (at /var/ts/dms/policy/policy_versions/156/159.plc) does not exist
Errors during file attribute collection
Operation aborted.
/var/tmp/configsync.spec: Error creating package

WARNING:There are error(s) during saving.
        Not everything was saved.
        Be very careful when using this saved file!

Error creating package
Error during config save.
Unexpected Error: UCS saving process failed.

Environment

  • BIG-IP ASM/AWAF
  • attempting to save a UCS file

Cause

ASM is frequently writing new policy versions to disk.

A maximum of 50 are retained in /var/ts/dms/policy/policy_versions/*/.

If a new version is saved after a UCS save begins, the old version will be rolled off and unavailable for inclusion in the UCS file, resulting in the error.

Recommended Actions

  • Retry attempting to save a UCS file
  • Reduce the frequency at which new policy versions are saved (e.g. reduce ASM learning).
  • If Policy Building Learning Mode is Automatic, set ASM policy's 'Auto-Apply Policy' setting to 'Scheduled', which should prevent so many policy versions from being saved.

Additional Information

/var/ts/dms/policy/policy_versions

The policy_versions directory is used to store historical versions of ASM security policies in binary format.
