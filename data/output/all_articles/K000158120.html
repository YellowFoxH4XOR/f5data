K000158120: No button for "test" on monitor

Type
Support Solution
Published
2025-12-22
Updated
2025-12-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000158120

Description

The "Test" button is missing from the GUI for all monitor objects under Local Traffic ›› Monitors ›› Test on BIG-IP LTM version 17.1.3, preventing users from testing monitors directly through the GUI. The Address field is visible and not grayed out, but there is no option to initiate a test.


Environment

BIG-IP LTM version 17.1.3

Multiple LTM device pairs affected

Accessing monitor configuration via the GUI


Cause

The issue is caused by a known product bug (Bug ID 2154089) in which the "Test" button is missing from the monitor configuration page in the GUI. This prevents users from testing monitors via the GUI, regardless of the monitor type or configuration.


Recommended Actions

Use the Traffic Management Shell (tmsh) to test monitors as a workaround, since the GUI functionality is unavailable. For more details, please follow:

K60677941: Verifying monitor configurations using the tmsh utility


Monitor F5 release notes and bug tracker for updates or fixes related to Bug ID 2154089.


Additional Information

Bug ID 2154089: "Test" button for monitor object is missing.
