Description

Impact of changing the admin/root password on the working HA/DSC setup.

Environment

  • BIG-IP LTM HA/DSC.
  • You want to modify the passwords for the root or admin users.
  • You want to reset a lost or forgotten root password.
  • You want to know the impact of the password change on the BIG-IP system.

Cause

None

Recommended Actions

  • Changing root/admin passwords won't have any negative impact on your BIG-IP traffic, device groups, or synchronization.
  • You need to change the root user and admin user passwords on one device and then sync to the device group. The passwords should be synchronized across devices.
  • Changing the passwords will not break the HA pair or trigger a failover.
     
  1. Before making any changes, F5 recommends having root CLI access and creating a UCS archive.
  2. You can change the root account and default admin account passwords from the System > Platform page of the Configuration utility.
  3. You can also change passwords from the CLI using the passwd command followed by the username. For example:

    passwd admin

None
