Description:

The Current Connections in virtual server's statistics shows a non-zero value. However there's no way to get corresponding detailed connection information.

Environment:
  • BIG-IP LTM
  • UDP profile with Datagram LB enabled
  • run command: tmsh show sys connection virtual-server <virtual_server_name> all-properties
Cause:

That's expected behavior, when Datagram LB is enabled in the UDP profile, we do not output information related to these connections via tmsh show sys connection commands. While this does not mean there is no connection table entries.

Recommended Actions:

None

Additional Information:

The Datagram LB option, which is disabled by default, specifies that the system load balances UDP traffic packet-by-packet and does not treat UDP packets from the same source and port as part of a connection.

Additionally, when Datagram LB option is enabled connections that were previously present are not subject to the new load balancing style until they are closed.  This can result in some cases for the appearance of uneven load balancing.  As an example, syslog connections can often be long lived and may not show behavior aligned to the new setting for some time (if ever) and may need to be deleted to behave as expected.  The command to remove those connections is tmsh delete sys connection virtual-server <virtual_server_name>
