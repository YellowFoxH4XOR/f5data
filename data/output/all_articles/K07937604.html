Description
The iRule class::match command may fail to match the appropriate datagroup due to hidden characters in the datagroup's configuration. These may be introduced through copy/paste errors or other ways, but the datagroup configuration will appear normal in the configuration utility.

Environment

  • BIG-IP LTM
  • iRules
  • class::match

Cause
Hidden characters in the datagroup configuration.

Recommended Actions

While the configuration utility doesn't show these characters, they are easy to see from the CLI. Use the following procedure to confirm their presence and remove them.
  1. From the tmsh shell, run the following command:
    tmsh list /ltm data-group <name>
  2. The results should look something like this:
    ltm data-group internal /Common/test_applications_dg {
        records {
            "/admin                      " {
                data pool_1
            }
            "/help                       " {
                data pool_1
            }
            /apps {
                data pool_2
            }
            /access {
                data pool_3
            }
        }
        type string
    }
     
  3. You can see that the first two entries are enclosed in quotations, and have several extra whitespace characters. These don't render in the GUI, but do cause the datagroup to fail to match what you would expect it to.
  4. To correct the problem, remove the affected entries from the datagroup and recreate them. Simply editing them from the configuration utility may not clear the hidden characters fully.
