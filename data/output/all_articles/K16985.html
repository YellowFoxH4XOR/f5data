Known Issue

The pkcs11d process is unable to initialize when Operator Card Set (OCS) protection is not enabled.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to use the Thales Hardware Security Module (HSM).
  • You have not created enabled Operator Card Set (OCS) on the Thales HSM.

Impact

SSL connections cannot be established to the virtual server that references SSL certificates and keys stored on the Thales HSM.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SSL connections are failing.
  • The pkcs11d process is unable to initialize.

Workaround

To work around this issue, you can enable Operator Card Set (OCS) following the BIG-IP Systems and Thales HSM: Implementations manual.
