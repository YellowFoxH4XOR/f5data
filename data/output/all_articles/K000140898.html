K000140898: Telemetry Streaming Data Modification declaration with 'includeData' property does not include root object name in output

Type
Support Solution
Published
2024-08-30
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000140898

Description

You would like to use Telemetry Streaming (TS) data modification 'includeData' property to output only data you specify. The output data did include specify locations, however the output data do not include the root object name.

Extracted section of TS declaration:

            "actions": [
            {
                "includeData": {},
                "locations": {
                    "system": {
                        ".*": true
                    },
                    "pools": true,
                    "sslCerts": true,
--snip--

 

Sample Output data:

Notice the root object name, system, is not included in the output.

[
  {
    "data": {
      "cpu": {
        "description": "cpu",
        "measurements": [
          {
            "tags": {
              "hostname": "bigipts.example.abc",
--snip--
              "facility": "southdc"
            },
            "value": 5

Environment

TS includeData property

Cause

Not applicable

Recommended Actions

To include the root object name, add telemetryEventCategory to includeData object TS declaration.

            "actions": [
            {
                "includeData": {},
                "locations": {
                    "telemetryEventCategory": true,
                    "system": {
                        ".*": true
                    },
                    "pools": true,
                    "sslCerts": true,
--snip--

Output data includes the root object:

[
    {
        "data": {
            "system_cpu": {
                "description": "system.cpu",
                "measurements": [
                    {
                        "tags": {
                            "hostname": "bigipts.example.abc",
--snip--
                            "facility": "southdc"
                        },
                        "value": 3
