Topic

In BIG-IP 9.0 through 10.0.1, the minimum TCP retransmission timeout is 1 second. Therefore, the shortest time between BIG-IP TCP retransmission segments is 1 second.

In BIG-IP 10.1.0, the minimum TCP retransmission timeout was changed to 300 milliseconds. This change was made as a result of CR121496, to improve performance over lossy, high bandwidth networks, such as Wi-Fi networks.

However, the 300 millisecond TCP retransmission timeout was found to be too aggressive in some circumstances. As a result, F5 Product Development adjusted the exponential back-off algorithm to allow for extra retransmission packets.

Note: For more information, refer to K11442: The new minimum TCP retransmission timeout may cause TCP connections to be prematurely terminated.

Note: The minimum TCP retransmission timeout is not a configurable option in the TCP profile.
