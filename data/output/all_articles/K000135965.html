K000135965: some pages in GUI fail to load after software upgrade to v17.1.0

Type
Support Solution
Published
2023-09-17
Updated
2026-01-13
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1, 17.1.2, 17.1.0
Source
https://my.f5.com/manage/s/article/K000135965

Description

After software upgrade, you may notice that some pages in GUI keep loading forever. 
For instance, System > Software Management > Live Update


Device Management > Overview

Security > Application Security > Policy Building > Learning and Blocking Settings also doesn't load.

No error messages seen in ltm log, restjavad.x.log, restjavad-audit.x.log and httpd_errors log.
No outofmemory logs observed in kern.log or restjavad.x.log.

Environment

  • BIG-IP
  • GUI pages

Cause

Unknown at the time of publication

Recommended Actions

Please run below command to fix the issue. 
# bigstart restart restjavad restnoded tomcat httpd

Impact: Running this command won't disrupt production traffic, so no Maintenance Window is needed. GUI will be temperarily unavailable until all daemons are up.

Additional Information

None
