Description

This article addresses the question of whether it is possible to log all SFTP commands issued by any user (including root) on BIG-IP systems and forward these logs to a remote syslog server.

Users may attempt to configure SFTP command logging similar to standard Linux systems by modifying the SFTP subsystem in the sshd_config file with logging parameters. However, on BIG-IP systems attempting to modify the SFTP subsystem results in the error: "01070920:3: Application error for confpp: do/config/ssh/sshd_config line 132: Subsystem 'sftp' already defined."

Environment

  • BIG-IP 
  • SFTP, Audit Logging, Remote Syslog

Cause

None

Answer/Recommended Actions

BIG-IP does not log individual SFTP commands or file operations performed during an SFTP session. The following limitations apply:

  • On BIG-IP systems, it is not possible to log all SFTP commands issued by users (including root) in the same way as on standard Linux systems by modifying the sshd_config file.
  • Audit logging is focused on system configuration changes and user access, not on detailed SFTP session activity.
  • While you can configure remote syslog to forward authentication and audit logs, these will not include a detailed record of SFTP commands executed by users.

Additional Information

Changes to the SFTP subsystem in sshd_config are not persistent across reboots.
