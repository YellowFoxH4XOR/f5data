Known Issue

When accessing a SharePoint 2007 or Outlook Web Access 2000 server that uses NT Lan Manager (NTLM) authentication and BIG-IP APM configured to use single sign-on (SSO), the authentication may fail with the following error message:

The page cannot be displayed

This issue occurs when the server HTTP connection closes, and the server establishes a new HTTP connection to request NTLM credentials.

F5 Product Development tracked this issue as ID 226375 (formerly CR141356) and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

In addition, this issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing a hotfix, refer to K10025: Managing BIG-IP product hotfixes (10.x).
