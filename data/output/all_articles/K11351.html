Known Issue

If an ARX system has a skew between the MAC index numbers and processor numbers in one or more ip proxy-address commands, the system will fail to form a pair after an upgrade. Using the count flag with the ip proxy-address command may generate proxy IP addresses with a mac/processor skew.

Impact

The ARX redundancy link will fail to join, leaving the ARX pair unable to failover.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Messages logged to the ARX syslog file appear similar to the following example:

    Resolution

    Status

    F5 Product Development has assigned ID 375161 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

    Type of Fix
    		Versions Fixed
    		Related Articles

    Workaround

    This issue can only be resolved by F5 Technical Support. You cannot work around this issue by reconfiguring the proxy IP addresses. When contacting F5 Technical Support, reference ARX ID 38057.
