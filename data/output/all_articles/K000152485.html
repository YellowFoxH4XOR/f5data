BIG-IQ 8.2.0BIG-IQ 7.x.0 or later
You can upgrade to BIG-IQ version 8.2.0 from the following BIG-IQ versions and deployments:
  • BIG-IQ versions 7.x and later without a data collection device cluster.
  • BIG-IQ versions 8.0.x and later, with a data collection device cluster.
    This upgrade path supports rolling upgrades.
  • BIG-IQ versions 7.x and later with a data collection device cluster.
    This upgrade path does not support rolling upgrades, and will result in a period of downtime where statistics are not collected.

    Recommended Actions

    When you plan an upgrade, you should consider the following factors:

    • Upgrade to supported software version. At the moment 8.4.0 and 8.3.0 are the current supported versions. For reference K15073: BIG-IQ software support policy.
    • Read the release notes of the BIG-IQ software version you plan to upgrade to.
    • Make sure that your BIG-IP and BIG-IQ software versions are compatible to each other. For reference K34133507: BIG-IQ Centralized Management compatibility matrix.

    Once the upgrade path is understood, you can follow K51342220: Upgrade the BIG-IQ and DCD cluster videos and procedures on how to perform BIG-IQ upgrade.
