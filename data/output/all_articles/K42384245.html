Description
010712de:3: Virtual Server (<virtual_server>) requires VDI profile (resource /<remote desktop resource>) for this assignment.
Unexpected Error: Validating configuration process failed.


For Example:
010712de:3: Virtual Server (/Common/vs) requires VDI profile (resource /Common/remotedestop_vmware_view) for this assignment.
Unexpected Error: Validating configuration process failed.

Environment

  • You may encounter this message in /var/log/ltm
  • This message occurs when all of the following conditions are met:
    • Virtual Server references an access profile that assigns a remote desktop resource
    • Upgrade from a version previous to 13.0.0 of BIG-IP

Cause
Configuration will fail to load after the upgrade event.  The configuration failure to load is is due to a change in validation checks. Starting in 13.0.0, MCP validation will throw an error when an access profile referencing a remote desktop resource is applied to a Virtual server that does not have a VDI profile applied.  This change was added with ID600966.

Recommended Actions

  1. Roll back to the previous release and modify the Virtual Server configuration to use a VDI Profile.
  2. Manually edit the configuration file to add a VDI Profile to the Virtual Server configuration.
    Note: Manually editing the configuration file is done at your own risk and is not supported by F5

Additional Information
In this error message, note the following:

  • <virtual_server> is the Virtual Server that is failing to load.
  • <remote desktop resource> is the remote desktop resource assigned in the Access Profile applied to the virtual server.
