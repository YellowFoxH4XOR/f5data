K000148642: Timezone is wrong

Type
Support Solution
Published
2024-11-20
Updated
2024-11-20
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.5
Source
https://my.f5.com/manage/s/article/K000148642

Description

 

Displayed incorrect Timezone | The Timezone displayed was incorrect with 1 hour difference in UTC. 

 

Environment

 

BIG-IP LTM v16.1.5

 

Cause

 

Unknown at the time of publication.

 

Recommended Actions

 

Perform one of the following actions:

 

-Refer to the section "Using the command line to set the time zone on the BIG-IP system" in the next article: "K9098: Setting the time zone on a BIG-IP system" and try to change the time zone to another one next to yours UTC and then change it again to the correct UTC and verify if this change keeps the correct time zone.

 

-Verify the NTP server following the procedures from this article: "K10240: Verifying NTP peer server communications"

 

Additional Information

 

K9098: Setting the time zone on a BIG-IP system
