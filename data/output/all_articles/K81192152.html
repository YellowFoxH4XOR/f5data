Description

When installing the F5Helpers programs - f5vpn_setup.exe and f5epi_setup.exe - in quiet mode, you are prompted with a popup window with the following error message:

Error creating process <<None>>. Reason:The system cannot find the file specified.

Environment

  • You're using BIGIP APM.
  • You are using or expect to use APM VPN;
  • You're deploying the F5Helpers programs on the client machines
  • You are to deploy those programs in quiet mode: f5XXX_setup. exe /Q
Cause

This error is due to the bug ID 903297.

Recommended Actions

We may need to extract the content of the f5xxx_setup.exe programs and to perform the installation with the procedure below:

  1. We first need to extract the content of the F5Helpers programs.

    • Example: f5vpn_setup.exe /Q /C /T:C:\Test (This will only extract the setup files in C:\Test)

  2. We can then deploy the programs this way: c:\Test\cabinstaller.exe /s (This will execute the setup in silent mode)

    Note: You may require Administrator privileges to execute this command on your client device.
