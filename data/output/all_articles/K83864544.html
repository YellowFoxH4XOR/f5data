K83864544: Recovering from the BIG-IQ or BIG-IQ Logging Node upgrade failures, when upgrading from 5.0.0 to 5.1.0

Topic

You should consider using this procedure under the following condition:

  • You have experienced one of the following issues after upgrading the BIG-IQ or BIG-IQ Logging Node from 5.0.0 to 5.1.0:
     
    • You experience data loss in the newly upgraded software volume.
    • You are unable to boot into the newly upgraded software volume.

Description

After you upgrade the BIG-IQ or BIG-IQ Logging Node from 5.0.0 to 5.1.0, the system may experience different upgrade issues due to the following reasons:

  • The BIG-IQ or BIG-IQ Logging Node system upgrade resulted in data loss because all of the required steps were not followed in the F5 BIG-IQ Centralized Management: Upgrading Logging Nodes to Version 5.1 guide. 

    Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  • The BIG-IQ Logging Node system is unable to boot into the newly installed 5.1.0 software volume, because a device failed during the upgrade.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have access to the advance shell, and have administrator role credentials on the BIG-IQ and the BIG-IQ Logging Node systems.

Procedures

To recover from the issues, perform the one of the following procedures:

  • Recover from data loss that you experienced after the upgrade
  • Recover from being unable to boot into the newly installed 5.1.0 version

Recover from data loss that you experienced after the upgrade

To recover from the data loss that you experienced after the upgrade, you can perform the upgrade again after cleaning up the faulty upgraded software volume. To do so, perform the following procedure on all BIG-IQ systems (including the HA peer) and BIG-IQ Logging Node systems. 

Impact of procedure: You have to reboot the system as part of this procedure. This is a recovery procedure and you should expect system access disruption.

  1. Log in to the advance shell of the affected BIG-IQ system as Administrator.  
  2. Reboot the system to the older software volume using the following command syntax:

    tmsh reboot system volume <Software_Volume_Name>

    For example, to switch the boot to software volume HD1.1, type the following command:

    tmsh reboot system volume HD1.1

     
  3. Delete the faulty software volume by using the following command syntax:

    tmsh delete system software volume <Software_Volume_Name>

    For example, to delete the software volume HD1.23, type the following command:

    tmsh delete system software volume HD1.23

     
  4. Repeat steps 2 and 3 for the other HA peer BIG-IQ system and the BIG-IQ Logging Node systems in your environment.  
  5. Upgrade the BIG-IQ systems (including the HA peer) and BIG-IQ Logging Node systems by following the procedures in the F5 BIG-IQ Centralized Management: Upgrading Logging Nodes to Version 5.1 guide.

    Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Recover from being unable to boot into the newly installed 5.1.0 version

To recover from being unable to boot into the newly installed 5.1.0, you can perform the upgrade again after cleaning up the faulty upgraded software volume and replacing the faulty Logging Node device. To do so, perform the following procedure on all BIG-IQ systems (including HA peer) and BIG-IQ Logging Node systems. 

Impact of procedure: You have to reboot the system as part of this procedure. This is a recovery procedure and you should expect system access disruption.

  1. Log in to the advance shell of the affected BIG-IQ system as Administrator.  
  2. Reboot the system to the older software volume using the following command syntax:

    tmsh reboot system volume <Software_Volume_Name>

    For example, to switch the boot to software volume HD1.1, type the following command:

    tmsh reboot system volume HD1.1

     
  3. Delete the faulty software volume by using the following command syntax:

    tmsh delete system software volume <Software_Volume_Name>

    For example, to delete the software volume HD1.23, type the following command:

    tmsh delete system software volume HD1.23

     
  4. Repeat step 2 and 3 on the other HA peer BIG-IQ system and the other BIG-IQ Logging Node systems in your environment.
  5. Log in to the BIG-IQ system as Administrator.
  6. To remove the faulty nodes and add the new ones, navigate to System Management > BIG-IQ LOGGING > Logging Nodes.
  7. Upgrade the BIG-IQ systems (including HA peer) and BIG-IQ Logging Node systems according to the procedures in the F5 BIG-IQ Centralized Management: Upgrading Logging Nodes to Version 5.1 guide.

    Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.
