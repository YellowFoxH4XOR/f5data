Description

Node is marked down even when it's responding normally to requests, causing the pool to be marked down.

  • The https monitor keeps marking the node down.
  • But the node responds well to the CURL requests without issues.
  • Packet capture shows "RST from BIG-IP internal Linux host"

Environment

  • BIG-IP LTM deployed on AWS cloud
  • Default https monitor is being used.

Cause

The cause of the issue is not clearly known at this time. It possibly could be due to incorrect TCP timestamps.

Recommended Actions

If the above conditions match, try enabling in-tmm monitors to see if that mitigates the issue.

  1. Login to tmsh and check if in-tmm is enabled. It's disabled by default.
    tmsh list sys db bigd.tmm
  2. If it's disabled, enable it by running command below.
    tmsh modify sys db bigd.tmm value enable
  3. Once it's enabled, the http monitor should mark the node/pool up.

    Note: For potential impact of enabling in-tmm monitoring, please refer article K85210713: Impact of enabling In-TMM monitoring
