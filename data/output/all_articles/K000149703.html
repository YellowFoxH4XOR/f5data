K000149703: HTTP/2 requests are displayed as HTTP/1.1 in ASM event logs

Type
Support Solution
Published
2025-02-07
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000149703

Description

When HTTP/2 traffic is processed by the BIG-IP Advanced WAF, the ASM event logs display the requests as HTTP/1.1 instead of HTTP/2. This behavior may cause confusion when reviewing logs for HTTP/2-enabled virtual servers.


Environment

  • HTTP/2
  • ASM event logs

Cause

This behavior is by design. When HTTP/2 traffic is intercepted by ASM, it is translated into HTTP/1.1 internally for easier parsing, inspection, and enforcement. The ASM event logs are generated based on this translated format (HTTP/1.1).


Recommended Actions

This translation from HTTP/2 to HTTP/1.1 in ASM event logs is expected and does not indicate a malfunction or misconfiguration.
