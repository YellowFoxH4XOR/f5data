Topic

The external BGP routing protocol (eBGP) requires unique Autonomous System Numbers (ASNs), which are assigned by the Internet Assigned Numbers Authority (IANA). Currently, the advanced routing module does not support 32-bit ASNs. As a result, if a router that supports 32-bit ASNs attempts to open a BGP connection with a BIG-IP system, the BIG-IP system sends the Unsupported Capability message (OPEN message error code 7) and the BGP peering fails.

ASNs were originally defined as 16-bit integers. RFC 4893 introduced 32-bit ASNs due to ASN exhaustion, and IANA began assigning them in 2007.

F5 Product Development tracked a request for enhancement (RFE) to add support for 32-bit ASNs as ID 222626 (formerly CR122196), which was included in BIG-IP 11.0.0.

For information about upgrading, refer to the BIG-IP release notes.
