Description

You would like to check the capability of your BIG-IP or evaluate the performance or resource utilization impact of an iRule which is used to block malicious user agent globally on the BIG-IP.

Environment

  • BIG-IP
  • iRule

Cause

None

Recommended Actions

The resource utilization impact of an iRule needs to be tested out in your environment and how it behaves on the BIG-IP. It all depends on the how the iRule is written and the traffic that is hitting the virtual server for BIG-IP to process using iRule. Generally iRule is slightly more resource intensive than inbuilt settings or profiles.

To evaluate or to understand the performance impact of your iRule, you can use "timing on" command in your iRule (Intermediate iRules: Evaluating Performance | DevCentral). You will need to test your new iRule and see how it performs. Once the evaluation is done, then you can remove the "timing on" command. There is video in it explaining what the command does and how to evaluate performance.

This Ten Steps to iRules Optimization | DevCentral document provides general guidelines on how to optimize the iRule and Intermediate iRules: Evaluating Performance | DevCentral provides how to evaluate the performance of the written iRule.
