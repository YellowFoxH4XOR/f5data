K82651085: ASM not sending logs to remote server

Type
Support Solution
Published
2022-03-08
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.1.3
Source
https://my.f5.com/manage/s/article/K82651085

Description

When a  BIG-IPASM security log profile is configured to send the logs to remote server and no logs being sent to the remote server. The BIG-IP local logging is working and there are no network connectivity issues between BIG-IP ASM device and remote server. However when viewing network level communication (tcpdump) there are zero packets captured and no logs sent by BIG-IP to the remote server. 

Environment

  • BIG-IP ASM
  • Logging profile
  • Splunk or Arcsight
     

Cause
Log profile is not getting updated in dcc database.

  2. If the profile data is not present in the output, which mean the profile is not updated in database and may need to restart the dcc process. 
    From the command line use the following command to kill dcc service:
     
    pkill -9 dcc
    Note: This command will not cause any traffic impact and daemon will restart itself within 60 seconds.
     
  3. Check to see that the dcc service has stopped with the following command:

    ps -ef | grep dcc
    Note: the dcc service should no longer be running. Once above commands are executed, Logging profile can be removed and then reattach to the virtual server.
