K12399: The BIG-IP Link Controller may display incorrect throughput statistics for link objects

Known Issue

This is the result of a known issue. One of the tasks of the bigip_link health monitor is to collect information about the throughput of the links. However, if the IP addresses of the links are used to create any pool other than the default gateway pool, the BIG-IP Link Controller may display incorrect information about the throughput of the links. This is because the bigip_link health monitor only accounts for the traffic handled by the pool members of the default gateway pool.

For example:

  • A BIG-IP Link Controller system is configured with the following three links:

    link1 192.168.1.254
    link2 192.168.2.254
    link3 192.168.3.254

  • The IP addresses of the links are used to create the default gateway pool:

    route default inet {
       pool default_gateway_pool
    }

    pool default_gateway_pool {
       monitor all gateway_icmp
       members
          192.168.1.254:any
          192.168.2.254:any
          192.168.3.254:any
    }

  • However, the IP address of one of the links is also used to create a more specific gateway pool, a pool that is only meant to handle a specific kind of traffic:

    pool http_traffic {
       monitor all gateway_icmp
       members
          192.168.3.254:any
    }

  • Based on the above configuration, the throughput information for link3 will be incorrect, as it will not account for the traffic handled by the http_traffic pool.

Correct behavior is for the bigip_link health monitor to obtain metrics from the node address of each link. This behavior would ensure that, if the IP address of one of the links is also used in a pool other than the default gateway pool, its traffic would be accounted for by the bigip_link health monitor.

Note: You can display information about the throughput of the links by navigating to Overview >> Statistics >> Link Traffic in the Configuration utility, and then selecting Links in the Statistics type drop-down menu.

Note: For detailed information about deploying the BIG-IP Link Controller system, refer to the BIG-IP Link Controller: Implementations manual (this resource was previously known as the BIG-IP Global Traffic Manager and Link Controller: Implementations manual).

F5 Product Development tracked this issue as ID 303500, ID 323756, ID 327112, and ID 220705 (formerly CR85292), and it was fixed in BIG-IP versions 9.3.1 and 10.0.0. For information about upgrading, refer to the BIG-IP Link Controller release notes.
