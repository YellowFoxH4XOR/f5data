Description

You attempt to send traffic locally from the BIG-IP to a configured virtual server however traffic is not hitting the VIP.
If using the curl command such as in the example below, you receive a Connection timed out error after a few minutes.

[bigip:Active:Standalone] config # curl -v -X GET http://10.82.52.84/abcd
Note: Unnecessary use of -X or --request, GET is already inferred.
*   Trying 10.82.52.84...
* connect to 10.82.52.84 port 80 failed: Connection timed out
* Failed to connect to 10.82.52.84 port 80: Connection timed out
* Closing connection 0
curl: (7) Failed to connect to 10.82.52.84 port 80: Connection timed out

Environment

BIG-IP LTM
Standard virtual server
Initiating traffic from the BIG-IP

Cause

There is no local self IP address configured on the same subnet as the virtual server address

Recommended Actions

Configure a self IP on the same subnet as the virtual server address.

Additional Information

None
