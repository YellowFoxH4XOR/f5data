K57282541: BIG-IQ CM shows error message ''INTERNAL_SERVER_ERROR: java.lang.NullPointerException''

Type
Support Solution
Published
2019-10-29
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K57282541

Description

When accessing the BIG-IQ CM dashboard, it will generate the below error message.

"INTERNAL_SERVER_ERROR: java.lang.NullPointerException"

The following error message are seen in var/log/appiq/queryservice.log

  • WARN c.f.a.c.c.F5_RESTController [XNIO-2 task-6] msg='INTERNAL_SERVER_ERROR: java.lang.NullPointerException', code=1002, restOperationId=9c8af4d3-6deb-4120-8d22-5e5340e1880e, errorStack=[]java.lang.NullPointerException: null

The following error message are seen in /var/log/appiq/queryservice-*.log

  • WARN c.f.a.q.m.BaseRangeToLayerSplitter [XNIO-2 task-8] No Bookkeeper available SimpleTimeRange{from=1570083900212, to=1570084200212}

Environment

  • BIG-IQ CM

Cause

The BIG-IQ system's bookkeeper index is not available.

You must recreate the bookkeeper.

Recommended Actions

You must remove and re-add all the managed devices to force re-create the "bookkeeper" index in the BIG-IQ system.
