Description

BIG-IP Policy Enforcement Manager (PEM) has two types of listeners

Data Plane

Data Plane Listeners are virtual servers where PEM subscriber traffic passes through. When you create a listener, Policy Enforcement Manager also creates virtual servers for each type of traffic (TCP, UDP, or both and IP), and a virtual server for HTTP traffic. The system sets up classification and assigns the appropriate policy enforcement profile to the virtual servers.

Control Plane

Control Plane Listeners are virtual servers that processes DHCP, RADIUS, and Diameter Endpoint traffic for PEM to discover and create subscribers sessions, request for authentication of DHCPv4 and DHCPv6 and discovered subscribers, and provision policies over Gx and online charging over Gy.

BIG-IP PEM Control and Data Plane Listeners are F5 virtual servers and are part of the BIG-IP data plane. For more information, refer to K44525501: Overview of BIG-IP data plane and control plane

Additional Information

Data Plane Listeners

Help for creating Data Plane Listeners can be found in the online help menu the in Configuration utility, by navigating to Policy Enforcement > Data Plane Listeners, then selecting the Help tab.

To create a Data Plane Listener, perform the following steps:

  • Log in to the Configuration utility of the PEM system.
  • Go to Policy Enforcement > Data Plane Listeners.

    This screen shows the properties of the virtual servers that the subscriber traffic passes through.

  • Select Add Group.

    Use this screen to add a group that creates a set of virtual servers for a specified destination, service port, and protocol.

    Select the Help tab for descriptions of each of the available fields.

Control Plane Listeners

Help for creating Control Plane Listeners can be found in the online help menu in the Configuration utility, by navigating to Subscriber Management > Control Plane Listeners, then selecting the Help tab.

To create a Control Plane Listener, perform the following steps:

  • Log in to the Configuration utility of the PEM system.
  • Go to Subscriber Management > Control Plane Listeners.

    On this screen, the PEM listener allows you to create and edit DHCP, RADIUS, and Diameter Endpoint virtual servers as needed. There are three main types of control plane configuration that can be made on this screen:

    • Subscriber Discovery Virtuals: Specifies the configuration of the virtual servers, that are used to discover and create subscribers sessions. This uses protocols like RADIUS, DHCPv4, and DHCPv6.
    • AAA Virtuals: Specifies the configuration of the virtual servers used to request for authentication of DHCPv4 and DHCPv6 discovered subscribers.
    • Policy Provisioning and Online Charging Virtuals: Specifies the virtual server used to provision policies over Gx and online charging over Gy.

    Select the Help tab for descriptions of each of the available fields.
