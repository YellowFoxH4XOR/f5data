Known Issue

Unrelated device group configuration folders may by synchronized across device groups.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration uses multiple device groups.
  • The device groups are configured with either of the following scenarios:

    • Two different device groups use the same folder or partition names.
    • A device has a local folder or partition with the same name as one of the folder names from a folder synchronized for the device groups.
  • You run a full sync to synchronize a device to the device group.

Impact

All device group folders are synchronized to all devices, regardless of device group association.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you list the system folders of the devices, you notice that all devices have the same folders from all device groups.
  • Device group members that use conflicting folder configurations are overwritten by the synchronizing member's configuration for the following objects:

    • Device group
    • Traffic group
    • iApp references
  • When you attempt to perform a synchronization by using the Configuration utility, an error message similar to the following example displays:

    Status Sync Failed
    Summary A validation error occurred while syncing to a remote device

    Details
    Sync error on <destination device fqdn>: Load failed from <source device fqdn> 01020036:3: The requested folder (/<folder name>) was not found.
    Recommended action: Review the error message and determine corrective action on the device
  • In the /var/log/ltm file, you observe log messages similar to the following example:

    err mcpd[<pid>]: 01020036:3: The requested folder (/windows) was not found.
    err mcpd[<pid>]: 01071488:3: Resuming log processing at this invocation; held 20 messages.
    err mcpd[<pid>]: 01071488:3: Remote transaction for device group /<partition>/<device group name> to commit id 10 4140734537641283915 /<partition>/<device group member> 0 failed with error 01020036:3: The requested folder (/<folder name>) was not found..
    err mcpd[<pid>]: 01071587:3: Commit ID message ignored, commit ID originator not specified
    notice mcpd[<pid>]: 01071038:5: Unit key hash from key header: <hash key>
    notice mcpd[<pid>]: 01071038:5: Unit key hash computed from read key: <hash key>

Workaround

To work around this issue, you can ensure that unique partition and folder names are used across all devices in all device groups.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
