K000148031: What domains need to be allowed for Bot Defense Standard?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000148031

What Happened?

You are wondering if there are certain domains that need to be allowed on your firewall rules for Bot Defense Standard when using a connector such as the BIG-IP iAPP connector.

 

Environment

  • F5® Distributed Cloud
  • Bot Defense Standard
  • Bot Defense Standard Connectors

 

Resolution/Answer

Please allow the following domains depending on your region:

 

For Web US region:

  • ibd-webus.fastcache.net
  • ibd-webus-usw2.fastcache.net
  • ibd-webus-use1.fastcache.net

For Mobile US region:

  • ibd-mobileus.fastcache.net
  • ibd-mobileus-usw2.fastcache.net
  • ibd-mobileus-use1.fastcache.net

For Web EMEA region:

  • ibd-webemea2.fastcache.net
  • ibd-webemea2-euw1.fastcache.net
  • ibd-webemea2-euc1.fastcache.net

For Mobile EMEA region:

  • ibd-mobileemea2.fastcache.net
  • ibd-mobileemea2-euw1.fastcache.net
  • ibd-mobileemea2-euc1.fastcache.net

For Web ASIA region:

  • ibd-webapac.fastcache.net
  • ibd-webapac-aps1.fastcache.net
  • ibd-webapac-aps2.fastcache.net

For Mobile ASIA region:

  • ibd-mobileapac.fastcache.net
  • ibd-mobileapac-aps1.fastcache.net
  • ibd-mobileapac-aps2.fastcache.net

 

Additional Information

IPs can also be allow listed by resolving these domains however allowing the IPs is not recommended as these could change in the future.
