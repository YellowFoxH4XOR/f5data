Description

When viewing monitor instances under: Local Traffic  ››  Monitors  ››  <monitor_name>, the results shows  incorrect pools if the same members are used in other pools. Ideally, it should only display assigned pool for the selected monitor instance.

Environment

  • BIG-IP
  • Monitoring

Cause

This is a known issue tracked under Bug ID 759258.

Recommended Actions

Use tmsh if you want to display pool to monitoring mapping:

# grep -E 'ltm pool | monitor' /config/bigip.conf
