Issue

Error Message

015d0000:5: Serializing new blob (<pktclass1|2>)

In this error message, note the following:

  • <pktclass1|2> is the compiled BIG-IP AFM firewall ruleset ID. The ID is either 1 or 2.

For example:

015d0000:5: Serializing new blob (pktclass2).
015d0000:5: Serialization completed after 10 seconds. Blob is 1000kB.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The /var/log/tmm file
Description

This message occurs when the following condition is met:

  • One of the following events occur:
    • You either create a new or modify an existing BIG-IP AFM security firewall ruleset.
    • Prior to 13.0.0, the availability status of a virtual server with an associated firewall policy changed.
  • The Packet Correlation Classification Daemon (pccd) detects and completes compiling the new firewall ruleset.

Beginning in 12.0.0, BIG-IP AFM maintains two compiled rulesets, called binary large objects (BLOB), in two different memory locations, pktclass1 and pktclass2. When you update or create a new firewall ruleset, the ruleset compiles using the non-active BLOB. Once the new firewall ruleset is compiled, the lock releases on the previous firewall ruleset and is placed on the new firewall ruleset. The Traffic Management Microkernel (TMM) is notified of the change and uses the new BLOB.

Impact

There is no impact; this message is informational only.
