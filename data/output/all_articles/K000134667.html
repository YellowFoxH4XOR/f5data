K000134667: Modify Audit Logging values for MCP, tmsh and GUI from the CLI

Type
Support Solution
Published
2023-05-18
Updated
2023-05-18
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000134667

Description

You can find the Audit Logging section for MCP, tmsh and GUI in the following configuration utility path:

System > Logs> Configuration > Options.

It may be required to modify these values directly from the CLI.

 

Environment

BIG-IP LTM

 

Cause

None

 

Recommended Actions

To modify the MCP value from the command line:
 

tmsh modify /sys db config.auditing value enable

tmsh save sys config

 

To modify the GUI value from the command line:

tmsh modify sys global-settings gui-audit enabled 

tmsh save sys config

 

​​​​​​​To modify the TMSH value from the command line:

 

tmsh modify cli global-settings audit enabled 

tmsh save sys config

 

Additional Information

None.
