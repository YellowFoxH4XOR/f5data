Description

You may see the bellowing log in /var/log/ltm, BIGIP may send encrypt alert and end the connection as well.
warning tmm[<PID>]: 01260009:4: Connection error: ssl_codec_parse:1546: record protocol version incorrect (47)
In this log message:
  • <PID> is the process id of tmm process

Environment

  • LTM
  • SSL profile configured

Cause

Alert 47 means illegal_parameter(A field in the handshake was out of range or inconsistent with other fields). SSL profile throws this alert when record protocol version does not match the following list:

  •  SSL_VID_SSL2 = 0x0002, /* Netscape's SSL version 2. */
  •  SSL_VID_SSL3 = 0x0300, /* Netscape's SSL version 3. */
  •  SSL_VID_TLS1_0 = 0x0301, /* RFC 2246 TLS version 1.0. */
  •  SSL_VID_TLS1_1 = 0x0302, /* RFC 4346 TLS version 1.1. */
  •  SSL_VID_TLS1_2 = 0x0303, /* RFC 5246 TLS version 1.2. */
  •  SSL_VID_DTLS1_0 = 0xfeff, /* RFC 4347 DTLS version 1.0. */
