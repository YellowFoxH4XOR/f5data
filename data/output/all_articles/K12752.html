Issue

The log message format for error messages generated by the Cavium Networks NITROX card (used by the BIG-IP system to accelerate SSL connections) has changed in BIG-IP 10.0.0.

In BIG-IP 10.x, the log messages have the following format, where X is replaced with the SSL acceleration card number:

01010025:2: Device error: cnX <error message>

In BIG-IP 9.x, the log messages have the following format, where X is replaced with the SSL acceleration card number:

01010025:2: Device failure: cnX <error message>

The error message portion of the log messages has not changed; the only change is that the text Device failure in BIG-IP 9.x reads Device error in BIG-IP 10.x.

If you have configured custom monitoring or SNMP traps based on the format of the log string, you will have to update the regular expressions you are using to trigger the events.
