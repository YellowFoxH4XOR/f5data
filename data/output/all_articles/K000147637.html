K000147637: How do I add arpa zones for secondary nameservers to enable address-to-name mapping?

Description

This article explains the process for adding arpa zones (such as in-addr.arpa) for secondary nameservers in F5 Distributed Cloud (XC) DNS to enable address-to-name mapping (reverse DNS).
It also addresses why you may receive the error:
Requested zone cannot have .arpa as the suffix. Please contact support to create your .arpa zone. Fix Error

Environment

  • F5® Distributed Cloud DNS Zones

Cause

Special validation is required for in-addr.arpa zones compared to regular domains. Only the rightful owner of the IP prefix can add arpa zones for secondary nameservers. If you are not the owner, you will receive an error and need to contact support.

Answer/Recommended Actions

  • If you are the rightful owner of the IP prefix, you can successfully add arpa zones for secondary nameservers.
  • If you are not the owner, you will receive the error above and must create a support case (How to contact F5® Distributed Cloud Support) to request creation of the .arpa zone.
