Description

BIG-IP logs IPv6 address conflict messages when ARP option is disabled for a virtual-address.

  • BIG-IP logs warning message in /var/log/ltm

  • Warning message:
    tmm[PID]: 01190004:4: address conflict detected for 2001:db8::32 (02:54:57:68:12:c31) on /Common/V-IPv6

Environment

  • BIG-IP with an IPv6 virtual address configured not to respond to "Neighbor Solicitations"
        ltm virtual-address 2001:db8::32 {
            address 2001:db8::32
            arp disabled
            icmp-echo disabled
            traffic-group traffic-group-1
        }

Cause

This behaviour is normal and expected when another device on the network attempts to use the same IPv6 address as configured on the virtual address. IPv6 has separate functions for detecting duplicate addresses, neighbor solicitation and neighbor advertisement.  IPv6 Neighbor Discovery (NDP) has a function "Unsolicited Neighbor Advertisement/Gratuitous Neighbor Advertisements" the equivalent of IPv4 ARP and is defined in RFC 4861/RFC9131. IPv6 Duplicate Address Detection also known as DAD is also a function of NDP which is defined in RFC 4861, RFC 4862 and RFC 4429.

BIG-IP on receiving "Unsolicited Neighbor Advertisement/Gratuitous Neighbor Advertisements" which matches a virtual-address will still perform DAD and log a message that duplicate usage of address has been detected even if configured not to respond to "Neighbor Solicitations". This is good since it will warn the network administrator of the possible problem of using duplicate addresses.

Recommended Actions

Identify the new device and ensure it does not use the BIG-IP virtual-address.

Additional Information

Dangers of disabling DAD: RFC 7527: 3.1.  Disable DAD on an Interface
