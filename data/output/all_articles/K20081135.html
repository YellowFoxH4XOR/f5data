Description

On the BIG-IP system, when you navigate to Statistics > Analytics and then select any category, such as HTTP, the page displays No data.

Environment

  • BIG-IP was previously managed by BIG-IQ
  • Analytics page shows 'No Data'

Cause

The BIG-IP system was removed from BIG-IQ management and the BIG-IP has an existing configuration to send the statistics to the BIG-IQ instead of locally storing the data.

Recommended Actions

  1. From the command line of the BIG-IP reset the analytics global-settings configuration back to default.

    tmsh modify analytics global-settings enable-bigiq-configuration disabled
    tmsh modify analytics global-settings use-offbox disabled
    tmsh modify analytics global-settings offbox-protocol none
    tmsh modify analytics global-settings offbox-tcp-addresses none
    tmsh modify analytics global-settings offbox-tcp-port 0
    tmsh modify analytics global-settings source-id none
    tmsh modify analytics global-settings ecm-port 0
    tmsh modify analytics global-settings avrd-interval 300

    Single line command example:
    tmsh modify analytics global-settings enable-bigiq-configuration disabled offbox-protocol none offbox-tcp-addresses none offbox-tcp-port 0 source-id none use-offbox disabled avrd-interval 300

    Example analytics global-settings before resetting to default:

    analytics global-settings {
    avrd-interval 30
    ecm-port 443
    enable-bigiq-configuration enabled
    offbox-protocol https
    offbox-tcp-addresses { 192.168.1.244 }
    offbox-tcp-port 443
    source-id e8fb6xxx-2xxx-4xxx-bxxx-1110c6c9dxxx_172.16.1.1
    use-offbox enabled
    }

    Example analytics global-settings after reset:

    analytics global-settings {
    avrd-interval 300
    ecm-port 0
    enable-bigiq-configuration disabled
    offbox-protocol none
    offbox-tcp-addresses none
    offbox-tcp-port 0
    source-id none
    }
     
  2. Clear REST related config on BIG-IP:
    clear-rest-storage -l
     
  3. Restart avrd:
    touch /var/avr/init_avrdb
    bigstart restart monpd
