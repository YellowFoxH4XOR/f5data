K000134620: The following signatures couldn't be verified because the public key is not available: NO_PUBKEY XXXXX

Description

  • When updating the Nginx repository via the command 'apt-get update', get the error message below:

The following signatures couldn't be verified because the public key is not available: NO_PUBKEY XXXXX

Environment

  • Nginx Plus
  • Debian or Ubuntu

Cause

The signing key file and/or folder is somehow corrupted or has a permission issue.

 Recommended Actions

  • Run the command below to see if the signing key is there and the file permission is 644. Use chmod command to change permission if needed:
#ll /usr/share/keyrings/nginx-archive-keyring.gpg

#chmod 644 /usr/share/keyrings/nginx-archive-keyring.gpg
  • Run the command below to see if the folder permission is 755. Use chmod command to change permission if needed: 
    #ls -ld /usr/share/keyrings

    #chmod 755 /usr/share/keyrings
  • Run the command below to confirm the same signing key path is included in the source file and add the path with your preferred editor if it's not presented:
#cat /etc/apt/sources.list.d/nginx-plus.list

deb [signed-by=/usr/share/keyrings/nginx-archive-keyring.gpg] https://pkgs.nginx.com/plus/ubuntu focal nginx-plus
