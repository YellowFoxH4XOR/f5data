Known Issue

The count for the locallb.stats.Misses(Unacheable) variable may be corrupted. This issue occurs when all of the following conditions are met:

  • The BIG-IP WebAccelerator system is processing multiple large responses that do not have a Content-Length header
  • The responses are larger than the configured Maximum Object Size in the WebAcceleration profile

The count for locallb.stats.Misses(Unacheable) tracks the number of uncacheable objects that were not cached by the BIG-IP WebAccelerator system. You can locate this statistic in the Configuration utility by performing the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to the location that applies to your version:

    • BIG-IP WebAccelerator 11.1.0:

      Statistics > Module Statistics > Local Traffic

    • BIG-IP WebAccelerator 11.0.0:

      Overview > Statistics > Local Traffic

  3. From the Statistics Type menu, select Profiles Summary.
  4. Click on the View link for the Web Acceleration profile type.

Impact

The Configuration utility reports an incorrect statistical value. However, this issue does not affect the BIG-IP WebAccelerator traffic processing capability.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H380479 on the Diagnostics > Identified > Low screen.
  • The count for locallb.stats.Misses(Unacheable) has an astronomical value decrementing past zero.

    For example:

    18446744073706194074
