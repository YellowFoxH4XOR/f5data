Description
"Insert-Via-Header" and 'Do Not Connect Back' must be enabled in MRF SIP session profile for Protocol Inspection.

Environment

  • BigIP V15.1.0 and  later versions.
  • AFM Protocol Inspections profile is attached to a MRF SIP Virtual Server

Cause
As an enhancement in V15.1,0. following two parameters in MRF SIP session profile must be true/enabled to work with Protocol Inspection.
* Insert-Via-Header
* Do-not-Connect-back.

Without these two parameters enabled, configuration will not be loaded. You will see error log as below in /var/log/ltm

01bf0006:3: Dependency failed between Protocol Inspection profile /Common/SIP_INSPECTION and the profile /Common/SIP_SESSION for the virtual /Common/MRF_SIP_VS, 'Do Not Connect Back' field must be enabled for /Common/SIP_SESSION


Please be noted,
1.) "insert-via-header" is true by default , while "Do-not-Connect-Back" is disabled by default.
2.) These checks are not required in older versions. For example,  the old configuration  "Do-not-Connect-Back"  disabled in SIP session profile and SIP protocol Inspection  works on v14.x,  while this configuration can not be loaded after upgrade to v16.1.x 

Recommended Actions

  1. Enable "insert-via-header"  and "Do-not-Connect-Back" in SIP session profile.
