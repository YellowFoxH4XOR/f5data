Description

ASM event logs for JSON requests containing sensitive parameters (e.g. password) are not masked.

Environment

  • Header-Based Content Profiles
  • Request Body Handling: Apply value and content signatures and detect threat campaigns
  • HTTPS wildcard allowed URL
  • ASM Security Policy

Cause

The "Request Body Handling" for the *json* header is configured to "Apply value and content signatures and detect threat campaigns" for HTTPS wildcard allowed URL.

Recommended Actions

Option 1:
Change the "Request Body Handling" for the *json* header of HTTPS wildcard allowed URL back to the default, which is JSON.

Option 2:
Add a specific allowed URL for the URL in question without modifying the default content profile configuration related to JSON.

Additional Information

Apply value and content signatures and detect threat campaigns: The system scans content for value and full-content attack signatures without attempting to parse it or extract parameters from it. This option provides basic security for protocols other than HTTP, XML, JSON, and GWT.

JSON: Content is expected to be in JSON format, and the system performs checks for JSON data in requests, based on the configuration of a JSON profile associated with this URL.
