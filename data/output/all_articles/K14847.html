Known Issue

Firefox may stop responding when accessing dynamically created pages through portal access.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured to provide portal access.
  • The portal access resource page is created dynamically using scripts.
  • Firefox is accessing the cookies for the portal resource for the first time.

Due to an internal bug within the Firefox browser, browsing portal resources through the BIG-IP APM system may halt or become unresponsive when cookies for the portal resource are accessed for the first time. This can occur, for example, when a portal resource is initially requested by a client through the BIG-IP APM system. A code change within the BIG-IP APM system provides a workaround for the Firefox issue.

Impact

Clients using Firefox may experience slowdowns or halts when browsing portal access resources.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H429471 on the Diagnostics > Identified > Low screen.
  • Browsing portal access resources using Firefox stalls intermittently or halts.
  • Clients are unable to access portal resources using Firefox.
