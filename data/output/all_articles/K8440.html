Topic

Adobe Authorware (formerly Macromedia Authorware) is an authoring tool for creating e-learning content and applications. You can access Authorware presentations through the FirePass Portal Access reverse-proxy engine, but issues may arise if the Authorware Web packaged pieces are not configured to support proxy servers.

For more information about configuring Authorware Web packaged pieces to support proxy servers, refer to the following website:

http://kb.adobe.com/selfservice/viewContent.do?externalId=tn_14748&sliceId=2

An alternate option is to configure an Application Tunnel or Network Access connection for access to Authorware presentations. The FirePass reverse-proxy engine does not rewrite Authorware content.

For additional information about Adobe Authorware, refer to the following website:

http://www.adobe.com/products/authorware/

For more information about configuring Application Tunnels and Network Access connections, refer to the FirePass Controller Administrator Guide.
