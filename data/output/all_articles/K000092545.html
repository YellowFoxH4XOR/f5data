K000092545: AFM IP Intelligence feedlist cannot block the IP

Type
Support Solution
Published
2023-03-20
Updated
2024-03-22
Source
https://my.f5.com/manage/s/article/K000092545

Description

You configured IP Intelligence with feedlist. It cannot block the IP in the list. Below error log is found in /var/log/dwbl/dwbld.log

 

dwbld| err|Oct 18 15:28:32.674|23226|CURLER|curler|(null)|CURL failed with error Couldn't connect to server

dwbld| err|Oct 18 15:33:32.693|23226|CURLER|curler|(null)|CURL failed with error Couldn't connect to server

dwbld| err|Oct 18 15:38:32.716|23226|CURLER|curler|(null)|CURL failed with error Couldn't connect to server

Environment

  • BIG-IP AFM
  • IP Intelligence

Cause

BIG-IP cannot reach the feedlist server through management route.

Recommended Actions

Check and fix the route to the feedlist server.

Additional Information

None.
