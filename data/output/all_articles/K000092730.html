K000092730: How to determine the Partition ID of the newly created Partition and the associated Kubernetes namespace

Type
Support Solution
Published
2022-11-27
Updated
2022-11-28
Source
https://my.f5.com/manage/s/article/K000092730

Description

You should consider using these procedures under the following condition:

  • You would like to find out what is the partition ID assigned to the Partition name.
  • You would like to know which Kubernetes namespace is associated with the Partition name.

Environment

  • F5OS
  • Management CLI

Cause

None

Recommended Actions

1. Access the management CLI and run the following command:
show partitions partition
2. From the output below, determine the Partition ID from the ID column: 
                                                                           RUNNING
                      BLADE OS    SERVICE                 PARTITION        SERVICE     STATUS
NAME              ID  VERSION     VERSION     CONTROLLER  STATUS           VERSION     AGE
-----------------------------------------------------------------------------------------------
NewPartition      2   1.5.0-8535  1.5.0-8535  1           running-active   1.5.0-8535  12d
                                              2           running-standby  1.5.0-8535  4d
default           1   1.5.0-8535  1.5.0-8535  1           running-active   1.5.0-8535  12d
                                              2           running-standby  1.5.0-8535  4d
none              0   -           -           1           disabled         -           -
                                              2           disabled         -           -
 3. The Partition ID from the output above will correspond to the Kubernetes namespace shown below:
[root@controller-2 ~]# kubectl get namespaces
