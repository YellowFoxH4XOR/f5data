Topic

FirePass support for certificates and certificate revocation lists (CRLs) is based on the OpenSSL library, which supports Version 1 and Version 2 CRLs. FirePass also supports Online Certificate Status Protocol.

You can configure Version 1 and Version 2 CRLs on the Device Management: Security: Certificates page in the Install Client Root Certificate and CRL section. Alternatively, beginning with FirePass version 5.2, you can configure a URL from which the CRL will periodically download in the Client CRL On-Line Updates section.

The Online Certificate Status Protocol (OCSP) enables applications to determine the revocation status of a certificate. OCSP provides more timely revocation information than is possible using CRLs, and may also be used to obtain additional status information. An OCSP client issues a status request to an OCSP responder and suspends acceptance of that certificate until the responder provides a response.

The FirePass controller supports OCSP validation of client certificates. You can configure OCSP on the Device Management: Security: Certificates page in the Client Certificate OCSP Configuration section.
