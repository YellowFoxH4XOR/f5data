Description

This article addresses whether an F5 BIG-IP LTM device can support both Private VLAN (PVLAN) and standard VLAN configurations running simultaneously on the same internal interface. The scenario involves an internal interface already configured with a PVLAN for specific servers/applications, with plans to add new servers/applications on a separate, standard VLAN (not PVLAN) - or vice-versa. Do note that a PVLAN is a Cisco proprietary technology and the BIG-IP will handle it as a normal VLAN.

Environment

  • Configuration:
    • Internal interface configured with a PVLAN for certain servers/applications
    • Planned addition of a standard VLAN (not PVLAN) for new servers/applications on the same interface
  • VLANs must be uniquely tagged and properly configured

Cause

None

Recommended Actions

  • Proceed with configuring the new standard VLAN alongside the existing PVLAN on the internal interface.
  • Ensure each VLAN is uniquely tagged.
  • Follow F5 best practices for VLAN setup and configuration.
  • Refer to official BIG-IP LTM documentation for detailed configuration steps and validation.

Additional Information

  • BIG-IP LTM supports multiple VLAN types (PVLAN and standard VLAN) on the same physical interface, provided each VLAN is uniquely tagged and properly configured.
  • No F5-documented restrictions or incompatibilities exist for this configuration on the specified platform and software version.
