Description

Configuration sync with peer is failing with error message "Gateway IP (x.x.x.x) cannot be same as a self IP".

When navigating to Device Management > Overview, the Sync Summary would should the following:
Sync Failed

A validation error occurred while syncing to a remote device

Sync error on ltm01.example.com: Load failed from /Common/ltm02.example.com 01070734:3: Configuration error: Gateway IP (192.168.0.200) cannot be same as a self IP

Recommended action: Review the error message and determine corrective action on the device

Environment
  • BIG-IP devices
  • HA pair
  • Config sync failed
  • The following error message is seen:
    Configuration error: Gateway IP (192.168.0.200) cannot be same as a self IP

Cause

There is a duplicate IP address on both HA pair devices where the same IP address is used as a self IP on one device and as a gateway IP on the other device.
For example ltm01 uses 192.168.0.200 as it's self IP address. However ltm02 uses 192.168.0.200 as it's gateway IP address.

Recommended Actions

  1. Assume the BIG-IP device which is using the IP address as it's gateway is device A and the BIG-IP using the same IP address as it's self IP is device B.
  2. Check if the IP address is a valid gateway IP address on device A. You will need to verify this with your network team.
  3. If the gateway IP address is valid, you will need to change the self IP on device B. Check with your network team available IP address. Follow article K15582.
  4. If the gateway IP address is not valid, delete or change the gateway IP address on device A.Follow article K50359390.
