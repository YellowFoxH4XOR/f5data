Description

About rule groups

Managed rule groups are collections of predefined, ready-to-use rules that AWS and AWS Marketplace sellers write and maintain. For more information, refer to AWS WAF managed rule groups.

Note: This article references general functions and procedures in AWS WAF, which is a third-party product. For detailed steps or additional assistance performing the following procedures, refer to the AWS WAF product documentation. F5 rule groups

The following F5 rule groups are currently available in AWS WAF:

  • F5 Rules for AWS WAF - Common Vulnerabilities and Exposures (CVE)
  • F5 Rules for AWS WAF - Web exploits OWASP Rules
  • F5 Rules for AWS WAF - Bot Protection Rules
  • F5 Rules for AWS WAF - API Security Rules

You can purchase F5 rule groups from either F5 Networks on the AWS Marketplace or the AWS WAF Management Console.

F5 rules are protected

The content of F5 rules is not visible and cannot be viewed.

Additionally, you cannot modify rules within a rule group.

Using rule groups

You can use multiple rule groups for each Web Access Control List (Web ACL), up to the AWS WAF limit.

Configuring rule groups

You configure rules with one of two Action values: Block or Count. When a rule group Action is set to Block, it blocks traffic, and when it is set to Count, the following behaviors occur:

  • Traffic is allowed to pass through AWS WAF, even when the traffic matches the conditions of a rule.
  • Traffic that matches the conditions of a rule group generate CloudWatch metrics, which you can use for troubleshooting.

Monitoring rule groups and rules

All rules and rule groups come with CloudWatch metrics that report the number of requests that matched a rule or rule group. When you use multiple rule groups, these metrics help discern which rules are being matched.

Updating rules

The system updates rules automatically, so they are always current. No interaction or intervention is required from the subscribed client. Additionally, the rules are updated approximately once per quarter.

Disabling and unsubscribing from F5 rule groups

To disable a rule group to which you subscribed, delete it from the WebACL that is associated with the resource or resources that receive the web traffic.

You can unsubscribe from AWS rule groups using the AWS Marketplace or the AWS WAF Management Console.

Note: If you do not unsubscribe from a rule group using the AWS Marketplace or the AWS WAF Management Console, you continue to be charged for the rule group.

Getting help

F5 Rules for AWS WAF are supported on DevCentral, F5’s extensive community of experts, developers, and users addressing technical issues related to F5 products. If you have questions or need assistance with any aspect of F5’s rulesets, submit a question with the tag F5 rules for AWS WAF. Response times may be up to two days.

Note: With full request logging, you can share information on a rule suspected of blocking a legitimate request by performing the following tasks:

  • Log the HTTP requests that were blocked and the name of the rules that matched them.
  • Make sure that the requests do not contain sensitive information; if they do, mask the sensitive data with ****.
  • Submit a question with the tag F5 rules for AWS WAF and attach the requests to it.

For infrastructure and WAF-related questions, contact AWS Support for AWS WAF-related assistance.
