Description

When attempting to modify or create a WideIP you will observe that the pool selection will not be available in the WEBUI. 

Environment

  • BIG-IP DNS
  • Have a very high number of GTM/DNS Pools configured on the device.

Cause

The cause of this issue is due to the following ID's ID654599 and ID899253. When you have a large number of pools configured on the device it will not display them in the WebUI.

Recommended Actions

Due to this issue if you would like to apply a pool to your WideIP or make a change it must be completed via TMSH. 
  1. To create a new WideIP you could use something like the following. 
    tmsh create gtm wideip a www.gslb.example.com { pools add { www.example.com_pool { order 0 } } }
  2. After this has been created you will need to save your configuration.
    tmsh save sys config gtm-only?
