Known Issue

Learning suggestions generated by CSRF Attack Detected violations are removed from the Traffic Learning report.

This issue occurs when all of the following conditions are met:

  • The blocking mask for the CSRF Attack Detected violation is set to Learn and/or Alarm
  • A request triggers the CSRF Attack Detected violation and logs the event on the Manual Policy Building : Traffic Learning screen

Impact

Violations that generate learning suggestions are not visible on the Traffic Learning screen.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • One to two minutes after a CSRF Attack Detection violation is logged, the violation will be removed from the Traffic Learning screen
