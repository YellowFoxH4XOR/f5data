Topic

In a BIG-IP WebAccelerator symmetric deployment, changes to the pvsystem.conf and globalfragment.xml files are not synchronized to the other BIG-IP WebAccelerators. The changes to these files must be performed on each BIG-IP WebAccelerator system in the deployment. This behavior is by design for current versions. However, F5 Product Development is considering a Request for Enhancement (RFE) to allow these files to be synchronized in a symmetric deployment.

F5 Product Development is tracking this RFE as ID 246713 (formerly CR100830).

Supplemental Information
