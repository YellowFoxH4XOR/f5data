Topic

You should consider using this procedure under the following conditions:

  • You are connecting with F5 Edge Client or Browser Helper Apps using MacOS or Linux.
  • You are connecting to a network access resource.
  • Some event or error requiring extended logging occurs.
Note: For BIG-IP 12.1.0 and later, the MacOS and Linux Environment variable default_log_level value is set to 63 and provides extended logging by default. While you can use this article to modify the value to settings other than 63, it should not be necessary to do so when you want extended logging.

Enabling Network Access debugging

Mac OS X and Linux users can configure the verbosity of system logs by editing the f5networks.conf file, which the system creates during BIG-IP Edge Client installation.

Note: The file is located in the ~/Library/F5Networks/ directory for older versions of the client.

The f5networks.conf file appears similar to the following example:

Notes:

  • For FirePass versions prior to 7.0.0, refer to K3367: Enabling FirePass Network Access debugging for Mac OS X and Linux.
  • If you are unable to locate the f5networks.conf file, you can manually create the file by adding the f5networks.conf example configuration displayed in this article to the appropriate, previously mentioned Mac OS or Linux directory.
  • System level administrative privileges may be required when you create or modify the f5networks.conf file, located in the MAC OS X directory /Users/<username>/Library/Logs/F5Networks or the Linux directory $HOME/.F5Networks/.

##########################################################################
# This file contain F5Networks client components settings
#
#
# BASIC 31 Value use to provide basic logs which include user friendly
# messages, warnings, and errors.
# Valid values are in the range 0 to 31, the highest setting is 31.
# EXTENDED 63 Set to provide extended log level.
# Valid values are in the range of 32 to 63, the highest setting is 63.
##########################################################################

# default log level for all f5 components
default_log_level=31

# svpn core log level. This setting is used to override the default log level
# set by default_log_level setting for svpn component
#svpn_log_level=31

# svpn NPAPI plugin log level. This setting is used to override the default log
# level set by default_log_level setting for svpn NPAPI plugin
#svpn_plugin_log_level=31

# endpoint security NPAPI plugin. This setting is used to override the default
# log level set by default_log_level setting for endpoint security NPAPI plugin
#eps_plugin_log_level=31

By changing the values of the log levels, you can set logging to be more or less verbose. Any value between 0 and 31 enables basic logging. Any value between 32 and 63 enables extended logging. If a user is experiencing issues with their Network Access connection, the default log level can be set between 32 and 63 to capture logs that may assist in troubleshooting the issue. If you only want to override the default log level for one of the available setting options (VPN core, VPN plugins, or endpoint security plugins), remove the pound sign ( # ) character from the beginning of the line in the file and set the log level for that option.

For example:

#eps_plugin_log_level=31

If you want to increase the logging only for the endpoint security plugin, you would change the line to appear as follows:

eps_plugin_log_level=63

Collecting and reviewing the debug logs for troubleshooting

The client system generates logs in two different locations (system-wide and user-specific). Assuming that the connecting user's machine has a standard installation, you can collect or review the logs in the following directories:

  • MacOS:
    • User log directory: ~/Library/Logs/F5Networks
      • edge.log
      • policyserver.log
      • epi.log
      • vpn.log
    • System log directory: /Library/Logs/F5Networks
      • svpn.log
      • svpn_proxy.log
  • Linux:
    • User log directory: ~/.F5Networks
      • epi.log
      • policyserver.log
      • vpn.log
    • System log directory: /var/log
      • svpn.log
      • svpn_proxy.log
