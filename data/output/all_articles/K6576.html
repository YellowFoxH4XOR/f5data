Topic

By default, the status of the BIG-IP ASM bd process cannot be polled using SNMP.

Workaround

To configure SNMP to allow polling for the status of the BIG-IP ASM bd process, perform the following procedure:

  1. Back up the /config/snmp/snmpd.conf file by typing the following command:

    cp /config/snmp/snmpd.conf /config/snmp/snmpd.conf.original

  2. Using a text editor, edit the /config/snmp/snmpd.conf file.
  3. Locate the process information that appears similar to the following lines:

    proc /bin/chmand 2 1
    proc /bin/mcpd 2 1
    proc /bin/tmm 2 1
    proc /usr/bin/bigd 2 1
    proc /usr/bin/bigdbd 2 1
    proc /usr/bin/sod 2 1
    proc /usr/sbin/httpd infinity 1

  4. Add the following line to the end of the process information, listed above:

    proc ./bd 2 1

  5. Save the changes.
  6. Restart the snmpd process by typing the following command:

    bigstart restart snmpd

You can now poll for BIG-IP ASM process status using SNMP OID .1.3.6.1.4.1.2021.2. and the description in the UCD-SNMP-MIB.txt file.
