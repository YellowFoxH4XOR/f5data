Description

When testing a new brute force configuration, you are unable to trigger the desired enforcement action, such as Alarm and CAPTCHA.

Environment

  • Login Page
  • Brute Force Protection

Cause

Configured Login Page URL is incorrect.

Recommended Actions

When configuring brute force protection, the configured Login Page must be the page that validates the username and password, not the page that provides the login form. In other words, whatever page is accessed when hitting Login or Submit.

The example below illustrates a typical HTTP exchange when logging in to an application.

Note: In this example, HTML Form based authentication is used.

Login form page is accessed:

Client                   Server
GET  /login.php -------->
               <-------- 200 OK

The code for the login form:

<form method="POST" action="/auth/sso">
  <input type="text" name="authusername" required>
  <input type="password" name="password" required>
  <button type="submit">Login</button>
</form>

Login credentials are sent to the server after hitting Login, in the body of the POST. A POST payload containing login parameters may look similar to:

authusername=devuser&password=**********&Login=Login

Upon validating the login details successfully, the server responds with a 302 redirection to the main application page:

Client                   Server
POST /auth/sso  --------> 
               <-------- 302 Found /index.php

From the above example, we know that the login page URL is /auth/sso, the Username parameter is authusername, and the Password parameter is password. With these details, the Login Page URL can be configured correctly.

Configure the additional options of the Login Page URL to enable brute force protection to work correctly. For instance, examine a failed login response and specify a string that should not appear in the response. If this string only appears in failed logins, this allows an unsuccessful login to be differentiated from a successful one and is sufficient for basic functional brute force attack prevention.
