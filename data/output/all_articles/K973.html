To delegate a subdomain from the authoritative DNS servers to a 3-DNS Controller, perform the following steps:

Important: For the following configuration to work, you must have a wip.domain.com zone, with a www.wip.domain.com wide IP, on the 3-DNS servers.

Note: In the following example, the domain is domain.com, and the subdomain to be delegated to the 3-DNS Controller is wip.domain.com.

  1. Add the nameserver records to the domain.com that delegates wip.domain.com to the 3-DNS servers that are authoritative for wip.domain.com, as follows:
    wip.domain.com.		IN	NS	3dns1.wip.domain.com.
wip.domain.com.		IN	NS	3dns2.wip.domain.com.
  2. If the name servers are inside the subdomain, add address records for them, as follows:
    3dns1.wip.domain.com.	IN	A	1.2.3.4
3dns2.wip.domain.com.	IN	A	1.2.4.5
  3. To send traffic for www.domain.com to the wide IP, www.wip.domain.com, add a CNAME delegation, as follows:

    www.domain.com. IN CNAME www.wip.domain.com.
