Description

How to keep a backup device of a BIG-IP in sync with its original.

Environment

  • A backup BIG-IP device is running.
  • All interfaces other than Management are disconnected on the backup device.
  • The backup device has a unique Management IP.

Cause

  • You wish to manually update the backup with the configuration of the source device so it can be brought into service quickly if desired.

Recommended Actions

  1. Generate a ucs archive on the source device and scp it to the backup.
  2. Restore the ucs on the backup device using tmsh with the no-licence and platform-migrate options.  This does not overwrite the Management IP.
