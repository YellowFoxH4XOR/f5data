Environment

  • BIG-IQ License Manager
  • Licensing BIG-IP fails

Cause

BIG-IP was probably cloned in the past

Cloning device cause BIG-IQ licensing issues as restID is not changing

Recommended Actions

Modify RESTID on BIG-IP device and relicense the box by  performing following actions in BIG-IP CLI:

1. List RESTID on BIG-IP:

cat /config/f5-rest-device-id

2. Remove RESTID from affected BIG-IP

rm -f /config/f5-rest-device-id

3. Restart restjavad

bigstart restart restjavad

4. Verify if we have different restIDs:

cat /config/f5-rest-device-id

5. Try to license device once again
