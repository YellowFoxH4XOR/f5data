Topic

This article provides examples of serial console output and serial console log file output, which you can use to identify potential hardware failures of BIG-IP iSeries platforms.

Description

When the BIG-IP system fails to boot to an operating system, the serial console output and log may appear in a specific pattern, depending on the possible cause, as shown in the following examples:

Memory failure

Serial console output is rolling B7 and B9. For example:

                                                                             B7

--- Press <ESC>( for AOM Command Menu.

Serial console log shows string containing B7 and B9.

For example:

19A1A3A3A3A3A3A3A7A9AAAAABACADAFB0B1AF19A1A3A3A3A3A3A3A7A9AAA7A7A7A7A8A9A9A9A9AAAAAEAFB0B1B4B2B3B6B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B8B9BAB7BF

CPU failure

Serial console output shows AF. For example:

                                                                             AF


--- Press <ESC>( for AOM Command Menu.

Serial console log shows string containing B7 and 49.

For example:

--- Press <ESC>( for AOM Command Menu.

1019F5A1A3A3A7A9A7A7A7A8A9A9A9AAAAAAAB6EAFB0B1B4B2B3B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B8B9B9BAB7BBBCBF33324F9A7868707991929394939494949494949494959697B2

SSD failure

Serial console output shows B4.

For example:

Version 2.19.1269. Copyright (C) 2019 American Megatrends, Inc.
F5 Platform: C117 OBJ-0614-xx BIOS (Build: 3.10.032.0) Date: 03/03/2019 


                                                                             B4

Serial console log shows string which begins with F519 and always ends in B4.

For example:

F519F6FCA1A3A3A7A9A7A7A7A8A9A9A9AAAAAAAEAFB0B1B4B2B3B6B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B8B9B9BAB7BBBCBF33324F619A627078F1F468799192949494949494949494949596919297B299989D9CB4B4B4B4B4B4B4

The B4 may also be accompanied by POST code AD or AE.

For example:

B4Press <c> to enter setup.Press <e> to launch F5 Disk Erase 
Utility.92929999A0A0A2A2A2A2ADF519F6FCA1A3A3A7A9A7A7A7A8A9A9A9AAAAAAAEAFB0B1B4B2B3B6B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B8B9B9BAB7BBBCBF33 POST code AD
