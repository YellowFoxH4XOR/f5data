Description

Unable to save changes to the backup schedules on the BIGIQ 


Environment

  • BIGIQ
  • Backup Schedules
  • Encrypted Backup

Cause

When modifying settings within an existing encrypted Backup Schedule in F5 BIG-IQ (located under Devices > BACK UP & RESTORE > Backup Schedules), you may observe that the Passphrase and Verify Passphrase fields visually display bullet masks (•••••••).


This visual masking can create the impression that the encryption passphrase is pre-filled and valid. However, modifying non-passphrase settings on this page will not enable the Save or Save & Close action, nor allow saving changes, until the passphrase is explicitly re-typed into both fields.



Answer/Recommended Actions

Rekey in the passwords on both fields to enable the save/save&close button.
