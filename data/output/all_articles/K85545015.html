Known Issue

Persist lookup across services may fail to return a matching record when multiple records exist.

This issue occurs when all of the following conditions are met:

  • A persistence profile that has Match Across Services configured is associated with the virtual server.
  • The persistence table contains multiple records that correspond to the same pool.

Impact

The BIG-IP system may route connections to an incorrect pool member.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system may incorrectly route returning connections to an incorrect pool member.
