Known Issue

This is the result of a known issue. The RADIUS health monitor process terminates too soon, and does not allow adequate time for a response from the RADIUS server. The RADIUS monitor process times out after 5 to 6 seconds. If the RADIUS server fails to respond within the 5 to 6 second period, the BIG-IP system marks the server down.

F5 Product Development tracked this issue as CR94796 and it was fixed in BIG-IP LTM version 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue has been fixed in Hotfix-BIG-IP-9.3.1-HF2, which has been issued for BIG-IP version 9.3.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
