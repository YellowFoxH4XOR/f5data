Known Issue

This is the result of a known issue. The SSL::enable iRule command can be used to re-enable SSL processing during the connection. When the SSL::enable[clientside] iRule command is called from the SERVER_DATA iRule event, TMM will crash when processing traffic for the virtual server. In addition, when the SSL::enable iRule command is used in any other iRule event, it fails to re-initialize SSL processing for the connection.

Note: The proper use of the SSL::enable command is protocol-dependent and not recommended in the majority of cases. To selectively enable SSL processing, you should instead use an SSL profile and then use the SSL::disable iRule command to selectively disable SSL processing.

F5 Networks Product Development tracked this issue as CR90693 and it was fixed in BIG-IP version 9.4.4 for the BIG-IP 9.4 software branch. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in HOTFIX-BIG-IP-9.3.1-HF2 issued for BIG-IP version 9.3.1. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
