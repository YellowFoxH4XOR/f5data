Known Issue

This is the result of a known issue. The Cmp.MaxQueuedMsgs BigDB variable represents the maximum number of CMP messages that the system will queue while waiting for room in the destination MPI channel. The default value for the Cmp.MaxQueuedMsgs BigDB variable is incorrectly set to 15000. The variable should be set to 150000.

F5 Product Development tracked this issue as CR137548 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

To work around this issue, you can manually set the Cmp.MaxQueuedMsgs BigDB variable to 150000. To do so, run the following command at the BIG-IP command line:

bigpipe db Cmp.MaxQueuedMsgs 150000
