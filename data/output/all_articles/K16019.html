Known Issue

VIPRION systems may experience excessive IP fragmentation when the Virtual Local Area Network (VLAN) name and path exceed 16 characters.

For example, if the external VLAN is created in the Common partition, the full path for the VLAN is /Common/external, which is a total of 16 characters.

VIPRION systems use the tmm_bp VLAN to exchange internal system information between primary and secondary blades. In affected versions, the Maximum Transmission Unit (MTU) for the tmm_bp VLAN is set to 1582. If the VLAN name and path exceed 16 characters, the packet size may exceed the 1582 unit limit, causing IP fragmentation for backplane messages. For example, if the external_01 VLAN is created in the Common partition, the full path for the VLAN is /Common/external_01, which is a total of 19 characters. This causes internal packets to be fragmented into two separate packets, with the second packet having a payload of 3 bytes.

Impact

Excessive fragmentation on the tmm_bp VLAN could lead to high CPU usage and, in some cases, packet loss.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Data transferred through a BIG-IP virtual server is corrupted.
