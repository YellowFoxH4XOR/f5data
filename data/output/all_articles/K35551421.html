Description

The following article will address support for CRLDP (Certificate Revocation List Distribution Point) with Machine Certificate Authentication.

  • CRLDP is not supported with Machine Certificate Authentication.

Environment

  • Access Policy Manager (APM)
  • Machine Certificate Auth object.
  • Virtual Policy Editor (VPE)
  • Certificate Authority profile.

Cause

CRLDP is not supported with Machine Certificate Authentication.

Recommended Actions

Upload the CRL from the CRLDP to the APM:

  1. Download the Certificate Revocation List from the CRLDP.
  2. Login to the Big-IP Configuration Utility.
  3. Navigate to System>Certificate Management>Traffic Certificate Managment>CRL files and select Import.
  4. Select Choose File.
  5. Select the CRL file and click Import.
Associate the CRL with the Certificate Authority:

       1. Login to the Big-IP configuration Utility.
       2. Navigate Local Traffic>Profiles>SSL>Certificate Authority.
       3, Select the Certificate Authority.
       4. In the CRL file field select the CRL file from the drop down.
       5. Click Update.
 

Additional Information

The CRLDP link in the Certificate will be ignored.
