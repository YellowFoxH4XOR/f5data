Topic

This article applies to BIG-IP 11.x through 16.x. For information about other versions, refer to the following article:

  • K7579: Adding trunked ports to a VLAN (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to add trunked ports to a VLAN using the TMOS Shell (tmsh).

Description

In certain situations, you may choose to add a trunk to a VLAN using tmsh, rather than the Configuration utility.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP system using tmsh.

Procedures

You can use tmsh to create a trunk and add it to a VLAN. To do so, perform the following procedure:

Creating a new trunk

Note: Interfaces can belong only to a single trunk or VLAN; you can add only currently unassigned interfaces to a new trunk.

Impact of procedure: F5 recommends testing any changes during a maintenance window, with consideration to the possible impact on your specific environment including network traffic.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To create a new trunk, use the following command syntax:

    create /net trunk <trunk_name> interfaces add { interface_number[s] }

    For example, the following command creates a trunk named my_trunk that contains interfaces 1.3 and 1.4:

    create /net trunk my_trunk interfaces add { 1.3 1.4 }

    Note: Interfaces on VIPRION blades are referenced by blade/interface_number. For example, 1/1.1 and 2/1.1 reference the 1.1 interfaces of blades 1 and 2.

    Note: To optimize bandwidth, F5 recommends that the number of links in the trunk be a power of 2 (for example, 2, 4, or 8). This is due to the frame-balancing algorithms that the system uses to map data streams to links. Regardless of the hashing algorithm, a trunk that has 2, 4, or 8 links prevents the possibility of skewing, which can adversely affect data throughput.

  3. Optional: To enable Link Aggregation Control Protocol (LACP) for the trunk, use the following command syntax:

    Note: LACP is not required, but it is recommended if supported by both endpoints.

    modify /net trunk <trunk_name> lacp enabled

    For example, the following command enables LACP on the already existing trunk named my_trunk:

    modify /net trunk my_trunk lacp enabled

  4. To display the trunk configuration, type the following command:

    list /net trunk my_trunk

    Output appears similar to the following example:

    net trunk my_trunk {
        cfg-mbr-count 2
        id 1
        interfaces {
            1.3
            1.4
        }
        lacp enabled
        mac-address 00:01:d7:92:9d:54
    }

  5. Add the trunk to a VLAN using one of the following methods:
     
    1. To add a trunk to a VLAN as untagged, use the following command syntax:

      modify /net vlan <vlan_name> interfaces add { <trunk_name> }

      For example, the following command adds the trunk my_trunk to VLAN my_VLAN as untagged:

      modify /net vlan my_VLAN interfaces add { my_trunk }

      Note: If you plan to assign a trunk to more than one VLAN, you must add the trunks to the VLANs as tagged.

    2. To add a trunk to a VLAN as tagged, use the following command syntax:

      modify /net vlan <vlan_name> interfaces add { <trunk_name> { tagged }}

      For example, the following command adds the trunk my_trunk to VLAN my_VLAN as tagged:

      modify /net vlan my_VLAN interfaces add { my_trunk { tagged }}

    Note: For information about creating VLANs, refer to K14961: Create and modify VLANs using the tmsh utility.

  6. To display the VLAN configuration, use the following command syntax:

    list /net vlan <vlan_name>

    When the trunk is a tagged resource, the output appears similar to the following example:

    list /net vlan my_VLAN

    net vlan my_VLAN {
        if-index 640
        interfaces {
            my_trunk {
                tagged
            }
        }
        tag 4050
    }

    When the trunk is an untagged resource, the output appears similar to the following example:

    list /net vlan my_VLAN

    net vlan my_VLAN {
        if-index 656
        interfaces {
            my_trunk { }
        }
        tag 4094
    }

  7. To save the configuration, type the following command:

    save /sys config

  8. To view the trunk traffic statistics, type the following command:

    show /net trunk my_trunk

    Output appears similar to the following example:

    --------------------------------------------------------------------
    Net::Trunk
    Name      Status  Bandw  Bits  Bits  Errs  Errs  Drops  Drops  Colli
                       Mbps    In   Out    In   Out     In    Out  sions
    --------------------------------------------------------------------
    my_trunk      up   2000  7.1G  5.1K     0     0   6.8M      0      0

    Note: The bandw Mbps column shows the aggregate speed of the trunk. Each interface in the trunk is 1000baseT full, which makes the trunk capacity 2000 Mbps.

  9. To view the VLAN traffic statistics, type the following command:

    show /net vlan my_VLAN

    Output appears similar to the following example:

    -------------------------------------
    Net::Vlan: my_VLAN
    -------------------------------------
    Interface Name      my_VLAN
    Mac Address (True)  00:01:d7:92:9d:43
    MTU                 1500
    Tag                 4094

      ----------------------------
      | Net::Vlan-Member: my_trunk

      | Tagged  no

         | Net::Trunk
         | Name      Status  Bandw   Bits  Bits  Errs  Errs  Drops  Drops  Colli
         |                    Mbps     In   Out    In   Out     In    Out  sions
         -----------------------------------------------------------------------
         | my_trunk      up   2000  37.2G  2.4M     0     0  31.8M      0      0

            ---------------------------------------------------------------
            | Net::Interface
            | Name  Status   Bits  Bits   Pkts  Pkts  Drops  Errs     Media
