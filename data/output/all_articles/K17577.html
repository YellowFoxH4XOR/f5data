Known Issue

Secure Sockets Layer (SSL) handshakes may fail when using ECDHE-ECDSA ciphers.

This issue occurs when all of the following conditions are met:

  • You configure an SSL profile with the following properties:
    • The ciphers list is limited to ECDHE-ECDSA ciphers.
    • An RSA cert/key pair is selected.
  • You associate the SSL profile with a virtual server.
  • An SSL client connects to the virtual server.

Impact

Client SSL connections fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client SSL connections fail.
  • In the /var/log/ltm file, you notice an error message similar to the following example:

    tmm[10652]: 01260000:2: Profile /Common/clientssl: no cipher suites selected

Workaround

To work around this issue, you can modify the SSL profile and replace the RSA cert/key pair with a valid ECDHE-ECDSA cert/key pair.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
