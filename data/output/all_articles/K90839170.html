Description

When reviewing Analytics data, some information may not be available, such as Client IP and URL.

Environment

  • AVR

Cause

Analytics profile in use is not collecting these entities.

Recommended Actions

Reconfigure the analytics profile to enable the collection of this data.

Additional Information

It's recommended to create and apply a custom Analytics profile, specifying the exact metrics and entities you wish to gather.

Important: Entities such as Client IP and URL are disabled in the default Analytics profile.
