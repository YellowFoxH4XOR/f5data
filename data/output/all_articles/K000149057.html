Description

When attempting to activate the 25 letters Base registration key for V5A or V5B BIG IP base registration key license the error 51096 or 51097 is displayed .

 

Environment

  • BIG_IP V5A/B 
  • License

 

Cause

The license could not be activated due to the product had gotten to the end technical support.

The link to activate 25 digit XXXXX-XXXXX-XXXXX-XXXXX-XXXXX Base registration key, is no longer available.

https://activate.f5.com

 

Recommended Actions

The product reached (EOT) end of technical support.
You cannot activate a license for a device that has reached EOT.

None.
