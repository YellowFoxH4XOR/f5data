K37524184: Wildcard Wide-IP's order of precedence

Type
Support Solution
Published
2019-12-10
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP GTM
  • BIG-IP DNS: 13.0.X, 14.1.0, 14.0.1, 14.0.0, 13.1.1, 13.1.0, 13.0.1, 13.0.0, 14.0.X, 12.1.3, 12.1.2, 12.1.1, 12.1.0, 12.1.4
Source

Description

  • When the BIG-IP DNS receives a DNS Query that matches more than one Wide-IP, the system will prefer a Wide-IP with a "?" character in the name than one with a "*" character.  
  • The "?" is more explicit than "*".

For example, if the BIG-IP DNS is configured with the following Wide-IPs:

 *.example.com
???.example.com
www.*.com

A DNS Query is received for "www.example.com", the BIG-IP DNS will select the "???.example.com" Wide-IP as it is the most explicit match.

Environment

  • BIG-IP DNS/GTM
  • Wide-IP configured

Cause

Bug ID 748177

Recommended Actions

Upgrade BIG-IP Software to a fixed version.  See ID748177.

Additional Information

However, if a DNS Query is received for "host.example.com", the "*.example.com" Wide-IP will be selected since the "???.example.com" Wide-IP will only be selected if the third-level domain of the DNS Query contains only three characters, one character per "?".

Additionally, the DNS Query is matched to the Wide-IP from Left to Right.  

For example, if the BIG-IP DNS is configured with the following Wide-IPs:

foo.*.example.com
*.host.example.com

A DNS Query is received for "foo.host.example.com" the BIG-IP DNS will select the "foo.*.example.com" Wide-IP as "foo" is more explicit than "*".
