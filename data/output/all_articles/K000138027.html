K000138027: Telemetry Streaming stops working after the BIG-IP version upgrade

Type
Support Solution
Published
2023-12-24
Updated
2026-03-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0, 17.5.X, 17.5.0, 17.1.2, 17.1.1, 16.1.4, 16.1.5, 17.1.X, 15.1.9, 15.1.10
Source
https://my.f5.com/manage/s/article/K000138027

Description

Telemetry Streaming stops working after the BIG-IP version upgrade

Error log pattern like the below shown in /var/log/restnoded/restnoded.log

Mon, 10 Nov 2023 17:00:00 GMT - warning: [telemetry] Unable to retrieve memory provisioning. Bad status code: 404 Not Found for http://localhost:8100/mgmt/tm/sys/db/restjavad.useextramb

 

Environment

  • Telemetry Streaming
  • BIG-IP with ID1153865 fixed (Version 15.1.9, 16.1.4 and 17.1.0)

 

Cause

The DB key 'restjavad.useextramb' is removed by ID1153865.
Telemetry Streaming bug ID1408277 was created to track this issue.

Recommended Actions

Telemetry version 1.35 and higher should fixe this issue, please consider upgrading to the latest version to solve it.

Under the situation that you are running a version that 1.35 and higher is not supported, you may consider the following workaround.

Create a file named db.txt with the following content.

[restjavad.useextramb]
default=false
type=enum
enum=|true|false|
realm=private_internal


Load the DB and restart restnoded by the following commands.

Impact of procedure: restnoded related services such as Telemetry and AS3 would be unavailable during the restart.

loaddb -local db.txt
bigstart restart restnoded
