Description

When you change or update a certificate via the GUI, all information in the Certificate Properties disappears.

Under General Properties the Certificate Subject(s) is also listed as blank.

However the certificate is working fine for production traffic.

Note: This can be seen on the GUI on: System > Certificate Management > Traffic Certificate Management > SSL Certificate List > Click on affected certificate.

Environment

  • Managing Traffic SSL certificates
  • GUI 

Cause

This could be caused by Bug ID 523985: Certificate bundle summary information does not propagate to device group peers.

Recommended Actions

Upgrade to a version where above ID is fixed. Workaround the issue on affected versions by re-importing the Certificates on the affected peer devices or use tmsh to view the certificate details:

tmsh list sys crypto cert <cert name>

None
