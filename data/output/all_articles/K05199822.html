K05199822: ASM constantly logging to Event Log even if Logging profile is disabled

Type
Support Solution
Published
2020-09-10
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.X.X, 15.1.X, 15.0.X, 14.1.X, 14.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 14.X.X, 15.0.1, 15.0.0, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 14.0.1, 14.0.0, 15.1.0
Source
https://my.f5.com/manage/s/article/K05199822

Description

ASM is constantly logging to local Event Log even if Security Log profile is removed out of Virtual-Server.

Environment

  • Multiple logging profiles are applied to Virtual Server
  • Virtual Server logging a lot of logs locally

Cause

Unknown.
 

Recommended Actions

As a workaround you can restart services related to ASM logging.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Below commands should be executed from BIG-IP bash shell.

1. Restart the asm_config_server:

 pkill -f asm_config_server

2. Restart asmlogd:

 pkill -f asmlogd
