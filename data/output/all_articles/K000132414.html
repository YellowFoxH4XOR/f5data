K000132414: API Connectivity Manager Unauthorized Error

Type
Support Solution
Published
2023-05-02
Updated
2023-05-02
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.0.0, 2.1.0, 2.0.1, 2.7.X, 2.6.X, 2.5.X, 2.4.X, 2.3.X, 2.2.X, 2.1.X, 2.0.X, 2.7.0, 2.6.0, 2.5.1, 2.5.0, 2.4.0, 2.3.1, 2.3.0, 2.2.0
Source
https://my.f5.com/manage/s/article/K000132414

Description

  • ACM stops working and the webGUI shows the error as

Unauthorized To view this page, make sure that you've licensed API Connectivity Manager and that you have the correct permissions to access this content.

 

 

Environment

  • Nginx Management Suit
  • API Connectivity Manager

Cause

This is identified as a known issue as 'Web interface reports no license found when a license is present (30647)' and fixed in version 2.8 .

 Recommended Actions

Upgrade the Nginx Instance Manager to version 2.8 

 

Additional Information

None.
