Topic

F5 products and services can mitigate the following types of attacks. Use the articles for each type of attack to quickly identify the features and mitigation strategies available for your product version, other versions of your F5 product/services, and other F5 products/services.

  • User Datagram Protocol (UDP) flood
  • Generic Routing Encapsulation (GRE) flood
  • TCP flood
  • Transport Layer Security (TLS)/SSL
  • HTTP
  • Application/layer 7 (L7)
  • Remote file inclusion
  • Illegal requests
  • GNU Bash
  • Denial-of-service (DoS)/distributed denial-of-service (DDoS)
  • Traffic from malicious IP addresses
  • Antivirus protection
