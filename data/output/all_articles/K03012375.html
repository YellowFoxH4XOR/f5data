Description

After load the configuration from a physical platform to a BIG-IP Virtual Edition (VE), some forwarding L2 and forwarding IP virtual servers may stop working.

Environment

  • BIG-IP Virtual Edition (VE) on VMware ESX or ESXi servers

Cause

Default security settings in the virtual switch's "Forged Transmits / Promiscuous Mode / MAC address changes"

Recommended Actions

You must set the virtual switch's "Forged Transmits, Promiscuous Mode and MAC address changes" settings to Accept. (These settings are disabled by default). For information about enabling Promiscuous Mode and Forged Transmits on the virtual switch, refer to the VMware knowledge base article listed in the Supplemental section or in the VMware documentation for your specific VMware version. F5 recommends that hypervisor administrators be very conservative with regard to interface usage after you enable promiscuous mode.
