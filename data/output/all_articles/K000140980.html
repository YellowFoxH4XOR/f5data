Description

Telemetry- 401 Unauthorized Error after changing password when trying to push declaration with curl

Environment

  • Telemetry Streaming
  • BIG-IP
  • Authentication error for curl requests

Cause

Special characters in password

Recommended Actions

Please ask customer to use single brackets like 'password' when defining password in curl

example:

curl -sk -u admin:'Ex@mp$le' https://10.0.0.1/mgmt/shared/telemetry/declare
