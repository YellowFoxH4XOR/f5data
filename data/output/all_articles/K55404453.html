K55404453: Client sessions getting mixed with other users' session

Type
Support Solution
Published
2022-03-25
Updated
2023-10-16
Applies to
  • BIG-IP
  • BIG-IP Platforms

  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K55404453

Description

Multiple user sessions are getting intermixed or in some cases duplicated

Environment

An virtual sever with a Netscaler or similar device "in front" of the Big-IP

  • The Netscaler device utilizes "multiplexing" to open a single connection to the Big-IP for multiple end user connections
  • The virtual server can be purely an LTM virtual server or a virtual server with an APM policy.

Cause

The "multiplexed" connections on the client side can inadvertently be sent to the wrong destination for that particular request.

Recommended Actions

Disable multiplexing on Netscaler - this is very likely to resolve this issue.  It may also be possible to employ an iRule to detach the server-side connection on the Big-IP and force a new load-balancing decision, or use some sort of persistence.
