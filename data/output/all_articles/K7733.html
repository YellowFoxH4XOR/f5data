Known Issue

This is the result of a known issue. If you installed cumulative hotfix HF-601-4 or HF-552-9 on a FirePass controller that shipped with FirePass software versions 6.0.1 or 5.5.2, you may experience one or more of the following issues:
  • Routing options configured in advanced mode no longer function
  • Network Address Port Translation (NAPT) in Network Access no longer functions
  • Packet filter rules no longer function

Important: Your FirePass controller is not affected if it did not ship with pre-installed FirePass versions 6.0.1 or 5.5.2.

F5 Product Development tracked this issue as CR83144 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-601-5 for the 6.0.1 software branch, and in cumulative hotfix HF-552-11 for the 5.5.2 software branch. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

If you do not want to install cumulative hotfix HF-601-5, HF-552-11, or later versions of the cumulative hotfixes, you can work around this issue by removing cumulative hotfix HF-601-4 or HF-552-9. To do so, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Current Settings.
  4. Next to FirePass Hot-Fixes, click HF-601-4 (or HF-552-9).
  5. Click Uninstall hot-fix.

    A pop-up window will appear to confirm the hotfix removal.
  6. Click OK.

FirePass services will restart after the hotfix is removed.
