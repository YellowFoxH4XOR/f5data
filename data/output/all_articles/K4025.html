K4025: Changes to the sshd.conf file are lost during upgrade

Topic

Whenever a new version of sshd is installed during an upgrade, the ssh configuration files are overwritten. This can cause problems if you have have modified the sshd configuration. To avoid this issue, make a backup copy of the /config/ssh/sshd_config file before running the upgrade.

Starting in versions 4.5.11 and 4.6.3, BIG-IP and 3-DNS will make a backup copy of the sshd configuration file when running an upgrade.
