Topic

When a node becomes unavailable, the BIG-IP LTM system will continue attempting to monitor the node. If the BIG-IP LTM system has an ARP entry for the node, the system will attempt to send monitor traffic to the node at the interval specified in the monitor configuration. However, because the node is no longer available, it does not acknowledge the SYN packet sent to the node. As a result, the TCP's exponential backoff algorithm will retransmit the SYN packet after a three second delay, and then retransmit the SYN packet after a 6 second delay. The retransmit of the SYN packet appears as though the BIG-IP LTM system is attempting to monitor the node at an interval less than specified in the monitor configuration.

When the ARP entry expires, the BIG-IP LTM system will send an ARP request for the node, and monitor traffic is not sent to the node.
