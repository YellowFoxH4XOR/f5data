Description

  • Unable to login to BIG-IP through SSH
  • SSH session is closed automatically

Environment

  • BIG-IP
  • Putty or other SSH clients

Cause

  • SSH sessions for the "admin" credentials are disabled by default, but you can configure the "admin" account for terminal access if desired. 

Recommended Actions

  • Use root credentials for BIG-IP SSH access
  • Configure admin credentials for terminal access
    • K52286304: BIG-IP system administrative accounts
Additional Information
  • Configure root account credentials in the Config Utility by navigating to System >> Platform
  • Under User Administration
    •  Root Account
    •  Ensure 'SSH Access' is enabled
