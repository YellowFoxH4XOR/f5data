Known Issue

This is the result of a known issue. Persistence will fail if the timeout value for the Source Address Affinity persistence profile is set to indefinite or greater than 2,147,483,647 seconds.

F5 Networks Product Development tracked this issue as CR47893 and it was fixed in BIG-IP LTM versions 9.1.1 and 9.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

If upgrading is not an immediate option, you can work around this issue by setting the timeout value between 1 and 2,147,483,647 seconds. To do so, perform the following procedure:

  1. From the Configuration utility, click Local Traffic.
  2. Click Profiles.
  3. Click the Persistence tab.
  4. Select the Source Address Affinity profile you want to modify.
  5. Enter a Timeout value between 1 and 2,147,483,647 on the Profile Configuration screen.
  6. Click Update.
