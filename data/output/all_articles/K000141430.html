Description

For BIG-IP Advanced Firewall Manager (AFM) systems protecting networks against Distributed Denial of Service (DDoS) attacks, DoS Auto Threshold sensitivity can be configured for system-wide thru Device Protection and per DoS Protection Profile. 

From the BIG-IP Configuration utility, navigate to:

For System Wide:

Security  ››  DoS Protection : Device Protection

per DoS Protection Profile:

Security  ››  DoS Protection : Protection Profiles .. select the specific profile

Options are Low, Medium, and High, and provide DoS thresholding from relaxed to very aggressive, and sets the default threshold floor and limits accordingly.

For Threshold Sensitivity, select Low, Medium, or High.

Low means the automatic threshold calculations are less sensitive to changes in traffic and CPU usage.

A lower setting causes the system to adjust the thresholds more slowly over time, but will also trigger fewer false positives.

If traffic rates are consistent over time, set this to Medium or High because even a small variation in generally consistent traffic could signal an attack.

If traffic patterns vary, set this to Low to get fewer false positives.

Environment

BIG-IP AFM DoS Protection Profile

BIG-IP AFM Device Protection

AFM DoS Attack Types Threshold Mode configured with Fully Automatic

 

Cause

Configure BIG-IP AFM DoS Protection profile or Device Protection to use Threshold Sensitivity

Under DDoS Attack and BIG-IP System CPU usage spikes as it processes DoS Attack Traffic 

Recommended Actions

Configure Threshold Sensitivity per your needs. Monitor traffic on your virtual servers and BIG-IP system CPU usage and decide to use Low, Medium or High.

A setting of High will be more sensitive to changes in BIG-IP System CPU usage and traffic. 

A setting of Medium is the default configuration. 

A setting of Low will be less sensitive to changes in BIG-IP System CPU usage and traffic. 

Threshold Sensitivity  can be configured from the BIG-IP Configuration utility by navigating to:

For System Wide:

Security ›› DoS Protection : Device Protection

per DoS Protection Profile:

Security ›› DoS Protection : Protection Profiles ›› <DoS Profile name>

 

Additional Information

When configuring the BIG-IP AFM Threshold Sensitivity, it provides a warning image and states that "Sensitivity is not applicable to HTTP". For more information on HTTP enabled DoS Protection configured with Automatic Threshold, refer to  K000138529: Understanding Automatic Threshold in BIG-IP ASM/Adv WAF DoS Protection profile
