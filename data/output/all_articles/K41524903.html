Description

After upgrading BIG-IP software to version 14.1 or higher External NTP monitor stops working and mark pool members down

Environment
  • BIG-IP
  • v14.1 and above
  • External monitor
  • ntpdate command
  • monitor interval is 5 seconds or less.
     

Cause

By default ntpdate requires four number of samples to be acquired from each server.
Prior to 14.1.0, there is no delay between the polls and the 4 ntp request/response packets are finished in less than 0.2 seconds.
From 14.1.0, there is a 2 second delay between each sample.
This means that the 4 polls takes 6 seconds to complete, which exceeds the default 5 second interval configured on the monitor.


Recommended Actions

One of the options below can fix the issue
  • Increase the monitor interval to more than 6 seconds
  • Configure ntpdate to send only a single probe.
    The "-p" option controls this. 
    Please update the script ntpdate command as similar to below:
    /usr/sbin/ntpdate -p 1 -q $node_ip > /dev/null 2>&1
