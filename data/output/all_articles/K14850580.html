Description
BIG-IQ Discovery of BIG-IP fails after BIG-IP upgrade  
Visible error in GUI:
Authentication Failure to host 10.0.0.1 . Please check the credentials provided.

Errors visible in /var/log/restjavad.0.log

[/cm/global/tasks/device-trust/17ac2b6d-e2c4-4c38-8d1c-2ab0a271e781/worker BigIPTrustTaskWorker] Failed to connect to 10.0.0.1, check credentials: Unauthorized(401)
[/cm/global/tasks/device-trust/17ac2b6d-e2c4-4c38-8d1c-2ab0a271e781/worker BigIPTrustTaskWorker] Failed to connect to 10.0.0.1, check credentials: Unauthorized(401)

Errors Visible in /var/log/httpd/httpd_errors

[client 10.0.0.10:59330] AUTHCACHE Error processing cookie 52CYHOBNKGSUZWLC74L5IUHF47 - Failed Read: User, referer: http://localhost:8100/cm/global/utility/bigip-device-check

Environment

  • BIG-IQ Centralized Management
  • BIG-IP Upgraded to 17.0.0, 16.1.2.2, 15.1.6, 15.1.5.1, 14.1.5, 14.1.4.6, 13.1.5
  • Intermittent REST authorization error  

Cause

Bug ID 1108181: iControl REST call with token fails with 401 Unauthorized

Recommended Actions

  1. Upgrade to one of version not affected  by ID1108181
  2. If none of listed versions is fine to upgrade to please open support ticket to address this

WORKAROUND
  • Perform device discovery few times as this issue occurs intermittently it should work after few tries
  • Restarting restjavad on BIG-IP may work in some cases:
    tmsh restart sys service restjavad 

Additional Information

K00979312: BIG-IQ - BIG-IP device status "This device is not available"
