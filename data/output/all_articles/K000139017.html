K000139017: SDC GUI shows Site EMS and doesn't show SDC Components

Type
Support Solution
Published
2024-12-17
Updated
2024-12-17
Applies to
  • Traffix SDC: 5.1.0
Source
https://my.f5.com/manage/s/article/K000139017

Description

  • During installation, the SDC GUI will look exactly like the EMS GUI and the EMS doesn't show the SDC components.

Environment

  • Installation
  • Lab

Cause

Deploying an incorrect topology file. The site names for both EMS and SDC should be unique.

Recommended Actions

Deploy a valid and correct topology file and make sure that the site names for both EMS and SDC should be unique.

Additional Information

None.
