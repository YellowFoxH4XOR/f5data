Known Issue

This is the result of a known issue. If you launch the Windows standalone VPN client from the command line, and use the /c command line argument to specify an F5 VPN configuration (.f5c) file, the VPN client ignores the /c command line argument. Instead of opening the session specified in the .f5c file, the VPN client presents the default Select FirePass controller prompt.

The /c command line argument is an optional parameter. The syntax to launch the Windows standalone VPN client from the command line is as follows:

"C:\Program Files\F5 VPN\f5fpc.exe" -start /c "path-to-f5c-file"

The path-to-f5c-file section is the full path to the .f5c file. For example, if your .f5c file is located at C:\MyProfile.f5c, you would enter the following:

"C:\Program Files\F5 VPN\f5fpc.exe" -start /c "C:\MyProfile.f5c"

Note: If your standalone VPN client is not installed in the default location of C:\Program Files\F5 VPN\ f5fpc.exe, enter the full path to f5fpc.exe as it is installed on your system.

 

F5 Networks Product Development tracked this issue as CR81683, and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-601-5 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads site.
