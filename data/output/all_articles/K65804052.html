Known Issue

The Traffic Management Microkernel (TMM) may generate a core file with an Assertion 'we always have room in either sw or hw ring' failed message.

This issue occurs when all of the following conditions are met:

  • The transmit ring for the associated network interface controller is nearly full.
  • The next packet sent for transmission is large enough to exceed the capacity of the transmit ring.

In rare conditions, the BIG-IP system may encounter an internal validation failure while processing packets for transmission. This behavior may lead to an assertion that causes TMM to exit and restart.

Impact

The BIG-IP system fails to process traffic while the TMM process restarts. If configured for high availability (HA), the system fails over to another device in the device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system generates a TMM core file to the /shared/core/ directory.
  • A panic string is generated to the /var/log/tmm file that appears similar to the following example:

    notice panic: ../dev/bcm570x/if_bge.c:4471: Assertion "we always have room in either sw or hw ring" failed.
    notice ** SIGFPE *

  • The BIG-IP system fails over to another device in the device group.
