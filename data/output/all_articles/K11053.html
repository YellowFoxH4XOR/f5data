Topic

Various locations on BIG-IP APM and FirePass allow you to configure specific actions to be taken based on the operating system to which the user connects. The BIG-IP APM inspects the session.client.platform and the FirePass controller inspects the session.os.platform variable to determine which operating system the user is running. The following table provides a list of the various operating system platforms and the variable settings for the operating system.

Note: F5 does not officially support all operating systems listed in the following table.
