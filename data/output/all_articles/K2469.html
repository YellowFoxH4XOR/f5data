Topic

Starting with 3-DNS version 4.5, the config command provides a feature that allows you to disable NameSurfer.

To disable NameSurfer, perform the following procedure:

  1. Log in to the command line.
  2. Type the following command:

    config

  3. Select Configure NameSurfer (type N and press Enter).
  4. Select Disable NameSurfer.
  5. Choose one of the following three options:
    • Keep all NameSurfer changes and remove .bk file extensions
    • Keep all NameSurfer changes and keep .bk file extensions
    • Re-use the pre-NameSurfer BIND zone files
  6. Press any key to continue.
  7. Verify the changes by checking the /etc/named.conf file and the /var/namedb directory.

    Note: For version 4.6.2 and later, zone files are saved in the /var/named/etc/namedb directory, and /var/named/etc/named.conf lists each zone record as master. 
    For prior versions, zone files are saved in the /var/namedb directory, and /etc/named.conf lists each zone record as master.
