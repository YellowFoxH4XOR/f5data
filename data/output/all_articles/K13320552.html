Description

When connecting to the BIG-IQ using a remote provider such as AD and posting a Declarative Onboarding declaration via REST API, the follow error is logged in /var/log/restnoded/restnoded.log:

info: [f5-declarative-onboarding: doUtil.js] Platform: BIG-IQ
finest: [f5-declarative-onboarding: restWorker.js] done w/ initial account setup
finest: [f5-declarative-onboarding: restWorker.js] Passing to TCW
info: [f5-declarative-onboarding: restWorker.js] TCW task failed: [RestOperationNetWorkerHandler]: bad response received: 400 - Get document for key: shared/authz/users/remoteuser returned nothing
severe: [f5-declarative-onboarding: configManager.js] Error getting current config: Cannot read property 'list' of undefined

The remoteuser is defined in the BIG-IQ with administrator role GUI: System Tab -> USER MANAGEMENT -> Users

When connecting to BIG-IQ using a local admin user DO is working as expected. Only remote users are impacted.

Environment

  • BIG-IQ v8 (DO v1.21)
  • BIG-IQ v7 (DO 1.16)
  • Post DO declaration via API using remote authentication

Cause

ID1047749
Issue 264
 

Recommended Actions

The DO package will be updated with a fix expected to be released in November 2021.

Declarative Onboarding Releases

Note: Check K54909607 for compatibility with BIG-IQ software before updating the DO package.
