K12127275: Unable to create Applications from BIG-IQ

Description

BIG-IQ was not able to deploy BIG-IP Application from it's Application Dashboard.

Steps to do this can be referred to this documentation.
Lab 6.1: HTTP Legacy Application Creation

The following error message will appear when the Application deployment fails.
Unable to post classic-app-service : Failed to create new role for the application due to an unexpected exception. java.lang.IllegalArgumentException: Item was not found: Get document for key: cm/adc-core/working-config/ltm/pool/88880000-ff11-3c3c-b123-11a11a11111a returned nothing.: Item was not found: Get document for key: cm/adc-core/working-config/ltm/pool/88880000-ff11-3c3c-b123-11a11a11111a returned nothing : Failed to create new role for the application due to an unexpected exception. java.lang.IllegalArgumentException: Item was not found: Get document for key: cm/adc-core/working-config/ltm/pool/88880000-ff11-3c3c-b123-11a11a11111a returned nothing.: Item was not found: Get document for key: cm/adc-core/working-config/ltm/pool/88880000-ff11-3c3c-b123-11a11a11111a returned nothing

Environment

Relevant environmental factors specific to the topic

  • BIG-IQ 7.1
  • Fails when creating Applications from the BIG-IQ
  • An error message will pop-up
  • Logs will show that the pool being deployed is in current-config state.

Cause

The latest BIG-IP configuration has not imported to the BIG-IQ.
This causes the missing pool to be in current-config state instead of working-config state.

The following message shows that the pool is NOT in working-config state:
Item was not found: Get document for key: cm/adc-core/working-config/ltm/pool/88880000-ff11-3c3c-b123-11a11a11111a

The following message in /var/log/restjavad logs will show it is in current-config state:
/cm/adc-core/current-config/ltm/pool/88880000-ff11-3c3c-b123-11a11a11111a

Recommended Actions

To resolve the issue, you will need to ensure that the BIG-IP is in current-config state by re-discover and re-import both the Active and Standby BIG-IP.

  1. Login to the BIG-IQ
  2. Navigate to Devices > BIG-IP DEVICES
  3. Click on the BIG-IP device
  4. Click SERVICES
  5. Under Local Traffic (LTM) click re-discover followed by re-import
  6. If solving conflicts pops up, choose BIG-IP
  7. Once you have done this for both BIG-IP, create the Application again.
