Known Issue

This is the result of a known issue. When a host sends an ARP request for a TMM-controlled IP address while the virtual servers are in transition as part of a failover, the ARP response is sent to TMM instead of back to the host. As a result, TMM crashes.

F5 Product Development tracked this issue as CR68243 and it was fixed in BIG-IP LTM version 9.3.0. For information about upgrading, refer to the BIG-IP LTM release notes.
