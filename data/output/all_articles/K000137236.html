Description

When you try to load or save a UCS file you get a tmsh error: 
tmsh save /sys ucs my.ucs
An error occurs: 
Syntax Error: "ucs" unexpected argument
 

Environment

  • BIG-IP
  • Attempting to load or save a ucs file from the command line
  • Logged in as a non-admin user

Cause

The privileges assigned to your user role are insufficient to save the ucs file.  For example, the 'operator' role cannot load or save UCS files.

Recommended Actions

Save and load UCS files while logged in as administrator.

Additional Information

Backing up and restoring BIG-IP configuration files with a UCS archive
