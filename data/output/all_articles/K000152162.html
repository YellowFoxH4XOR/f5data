K000152162: BIG-IP APM Syslog Filtering Limitation

Type
Support Solution
Published
2025-06-30
Updated
2025-06-30
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000152162

Description:

When configuring BIG-IP APM to forward logs to an external syslog server, attempts to filter and send only VPN user session start/end events may not work as intended. Even with syslog filters applied, a large volume of Access Control List (ACL)-related logs (for example, messages containing "reject ACL") are still sent to the syslog server. This can overwhelm the syslog infrastructure and obscure important session-related log entries.

Applies To:

  • Logging configuration:
    • Syslog filters tested with severity levels such as Emergency, Informational, Notice
    • Filter sources tested include: apmacl, accesscontrol, accessperrequest
  • External syslog server

Cause:

The current syslog filtering options on BIG-IP APM do not allow for granular exclusion of all ACL-related logs while including only VPN session start/end events. The available filter sources (accesscontrol, apmacl, etc.) include both session and ACL logs by design. Adjusting severity levels does not sufficiently limit the output to only desired events. This is a limitation of the product’s logging subsystem.

Recommendations:

  • Set the syslog filter source to accesscontrol or accessperrequest and use a severity level such as Notice or Informational to attempt reduction in log volume; however, some unwanted ACL logs will likely remain.
  • For precise filtering (e.g., sending only VPN session start/end events), configure additional message-based filtering on the external syslog server. For instance, set up rules on Syslog Server to discard messages containing specific patterns like "reject ACL".
  • Regularly monitor your syslog server’s performance and storage capacity to ensure critical logs are retained.
  • An enhancement request has been submitted for more advanced filtering capabilities within BIG-IP APM. Contact your F5 sales representative for updates or prioritization regarding this feature request.
