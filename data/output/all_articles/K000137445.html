Description

When trying to disable/enable http2 by using the nginx directive "http2 off"/"http2 on", the following error is seen when reloading nginx: 

"nginx: [emerg] unknown directive "http2"

 

Environment

Nginx-plus-R29

Cause

The directives "http2 off;" and "http2 on;" to enable/disable HTTP2 was released on the nginx R30 version.

Recommended Actions

The "http2" directive was introduced since R30:
 

server{
    http2 on;
    http2 off;
}

thats why it is sending the unknown directive "http2" error.
 

Before that, to enable http2 was by using the listen directive:

server{
    "listen 443 ssl http2;"
}

 

Additional Information

HTTP2 is not enable by default on Nginx, so you need to enable it by using the proper directive mentioned on this article
