Description

After performing initial setup for F5 rSeries can not ping gateway even though IPs is configured on Mgmt interface and it is up and mac is seen.


Environment

F5 rSeries

Velos

Initial configuration

Management-IP


Cause

N/A.


Recommended Actions

1.- Pinging other devices directly on the mgmt network (like the other appliance)

2.- Pinging the gateway.

3.- Pinging something beyond the gateway.

4.- Hopping on the other device and trying the same stuff.

5.- tcpdump while doing these tests.

6.- tcpdump -nni mgmt0-system 'icmp or arp'

7.- Double check the gateway and prefix-length is correct in 'show running-config system mgmt-ip'

8.- ip addr show dev mgmt0-system

9.- ip route show

10.- arp -an
