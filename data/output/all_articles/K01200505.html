Description

Each time a multiple CVE's are published, it becomes necessary to verify if BIG-IP's and running OS are affected by such and/or other CVEs.

Environment

  • BIG-IP

Cause

CVE's publication(s) might affect BIG-IP and/or running OS version.

Recommended Actions
 

  1.  Generate and upload a fresh QKView file from the specific BIG-IP unit you need to analyze.
  2.  Access the QKview file at F5's iHealth site and open the "Diagnostics" link in Menu at left.
  3.  There you will see all the issues and the recommended mitigations/workarounds or versions that contain the respective fix.
  4.  Verify the vulnerabilities, if affected, you need to be addressed and discuss the options with your network and applications security teams.
  5.  Go to AskF5 site (https://support.f5.com/csp/home) and verify the recommendations for each vulnerability if not listed in ihealth (QKview) diagnostics page.

A detailed overview with video is available here K27404821: Using F5 iHealth to diagnose vulnerabilities
