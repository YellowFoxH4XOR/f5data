Known Issue

The Traffic Management Microkernel (TMM) stops processing packets with rate shaping.

This issue occurs when all of the following conditions are met:

  • You configure your BIG-IP system for rate shaping.
  • The rate shaper receives a TCP Segmentation Offload (TSO) packet with a length that exceeds the ceiling you configured for the rate class.

Impact

The rate shaper does not process any subsequent flows from that TMM.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the system reaches the TCP connection timeout, it sends a TCP reset for the connection requests that the rate shaper handles.

Resolution

Workaround

To work around this issue in the following BIG-IP versions, you can modify a system database variable to allow the system to process TSO packets that exceed the rate class ceiling.

  • BIG-IP 12.x: 12.1.3.2 and higher
  • BIG-IP 13.x: 13.1.0.x

To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh).
  2. Type the following command to enable rateshaper.cmpdivide (which the system enables by default): 

    modify /sys db rateshaper.cmpdivide value enable

  3. Save your configuration change by typing the following command:

    save /sys config

  4. To exit tmsh, type the following command:

    quit
