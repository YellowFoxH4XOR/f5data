Topic

You should consider using this procedure under the following condition:

  • You want to enable DNS Denial of Service (DoS) protection on the BIG-IP AFM system.

Description

DNS DoS protection is a type of protocol security. DNS attack detection and prevention serves two functions:

  • To detect and automatically drop DNS packets that are malformed or contain errors.
  • To log unusual increases in DNS packets of any type, including packets that are malformed, packets that contain errors, or packets of any other type that appear to rapidly increase.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access the Configuration utility.
  • You have a properly configured DNS server to use as a pool member.
  • You have a virtual server and a pool configured to load balance DNS requests to your DNS server.

Procedures

  • Create a custom DoS profile
  • Create a custom DNS profile
  • Assign the DoS profile and DNS profile to your DNS virtual server

Create a custom DoS profile

The DoS profile is used to configure settings to identify DoS attack vectors. To configure a custom DoS profile on the BIG-IP AFM system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > DoS Protection > DoS Profiles.
  3. Click Create.
  4. Type a name for the profile.
  5. To enable options for DNS DoS Protection, check Protocol Security (DNS).
  6. Enable and set Thresholds and Rates, as appropriate, for your environment.
  7. To save your changes, click Finished.

Create a custom DNS profile

DNS security is enabled by way of the DNS profile, and required for DNS DoS Protection. To configure a custom DNS profile on the BIG-IP AFM system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Services > DNS.
  3. Click Create.
  4. Type a name for the profile.
  5. In the DNS Traffic section of the page, select the Custom box for DNS Security, and select Enabled from the menu.
  6. Modify any other settings as appropriate for your environment.
  7. To save your changes, click Finished.

Apply the DoS profile and DNS profile to your DNS virtual server

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Select your virtual server from the list.
  4. In the Configuration section, select Advanced from the menu.
  5. For DNS Profile, select the DNS Profile that you created.
  6. To save your changes, click Update.
  7. At the top of the Properties page of your DNS virtual server, navigate to Security > Policies.
  8. For DoS Protection Profile, select Enabled from the menu, then choose the DoS profile that you created.
  9. To save your changes, click Update.
