Description

When installing or updating the BIG-IP Edge Client for Windows, the installer does not create a desktop shortcut for the application. Only a Start Menu shortcut is created by default. Modifying the installation package or following standard deployment procedures does not result in a desktop shortcut being placed on the user's desktop.

Environment

Edge Client Windows application


Cause

The BIG-IP Edge Client installer is designed to create only a Start Menu shortcut during installation. There is no built-in option, registry setting, or supported configuration parameter to automatically create a desktop shortcut as part of the installation process. This behavior is consistent across all currently supported versions of the Edge Client.

Recommended Actions

  • If a desktop shortcut for BIG-IP Edge Client is required, it must be created manually by users after installation.
  • Alternatively, administrators can distribute the desktop shortcut using endpoint management tools such as MDM.
  • There is currently no supported method to modify the Edge Client installer to create a desktop shortcut automatically.
  • If automatic creation of a desktop shortcut is required for your environment, consider submitting a Request For Enhancement (RFE) to F5 Support for consideration in future product releases.
