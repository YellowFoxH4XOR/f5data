K89549422: Sophos VPN Client fails to connect via IPSEC ALG

Type
Support Solution
Published
2021-11-29
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K89549422

Description

Sophos IPsec clients cannot connect to Sophos Firewall when BIG-IP ipsecalg profile is in use on the Virtual Server.

Environment

  • Sophos IPsec client
  • ipsecalg profile

Cause

Seen behaviours is caused by an issue tracked with the Bug ID 1058645

Recommended Actions

At the moment of creation of this article there is no fix on the current releases but an EngHF with the fix can be provided. As a workaround you can create and assign the following iRule to the ipsecalg virtual serve:

 when SERVER_DATA {
    # Only execute on first server side packet of conflow.
    event disable

    if { [UDP::payload length] < 40 } { return; }
    binary scan [UDP::payload] x8x8cH2cx9x10S payload_type ver exch_type noti_type

    # Depending on throughput, the amount of logging here may be problematic
    #log local0. "payload_type : $payload_type"
    #log local0. "ver          : $ver"
    #log local0. "exch_type    : $exch_type"
    #log local0. "noti_type    : $noti_type"

    if { $payload_type == 11 && $ver == 10 && $exch_type == 5 && $noti_type == 1 } {
        log local0. "Closing ipsecalg connection"
        after 1 { reject }
    }
}
