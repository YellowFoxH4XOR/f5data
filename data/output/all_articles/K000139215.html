Description

This article provides additional context to set up Active/Standby BIG-IP DNS in a HA pair, following F5's guide Setting Up a BIG-IP DNS Redundant System Configuration. 

Environment

  • Two (or more) BIG-IP DNS devices
  • Active/Standby pair

Cause

You can configure BIG-IP DNS in a redundant system configuration, which is a set of two BIG-IP DNS systems: one operating as the active unit, the other operating as the standby unit.

Note: The basic configuration consists of only two BIG-IP DNS devices (active and standby), but the BIG-IP system now allows for a redundant system configuration to contain an arbitrary number of devices within a server.

Recommended Actions

  • For a new DNS device without any existing configuration, you will want to follow the Initial Configuration Guide. 

  • Once the initial device configuration is set up, follow the steps in the Setting up a BIG-IP DNS Redundant System Configuration guide.

  • Configure the DNS devices to be in a HA pair. When a DNS Listener is created, there is a LTM virtual server created to respond to DNS queries.

# Active DNS device
root@(localhost1)(cfg-sync In Sync)(Active)(/Common)(tmos)# list gtm listener
gtm listener 10.79.111.99 {
    address 10.79.111.99
    ip-protocol udp
    mask 255.255.255.255
    port domain
    profiles {
        dns { }
        udp_gtm_dns { }
    }
    translate-address disabled
    translate-port disabled
}
root@(localhost1)(cfg-sync In Sync)(Active)(/Common)(tmos)# list ltm virtual
ltm virtual 10.79.111.99 {
    creation-time 2024-03-20:11:22:30
    destination 10.79.111.99:domain
    ip-protocol udp
    last-modified-time 2024-03-20:11:22:30
    mask 255.255.255.255
    profiles {
        dns { }
        udp_gtm_dns { }
    }
    serverssl-use-sni disabled
    source 0.0.0.0/0
    translate-address disabled
    translate-port disabled
    vs-index 9
}

# Standby DNS device
root@(localhost2)(cfg-sync In Sync)(Standby)(/Common)(tmos)# list gtm listener
gtm listener 10.79.111.100 {
    address 10.79.111.100
    ip-protocol udp
    mask 255.255.255.255
    port domain
    profiles {
        dns { }
        udp_gtm_dns { }
    }

    creation-time 2024-03-20:12:25:50

Under the section "Defining a server and devices on the active BIG-IP system", it states:

"Using this procedure, create two servers on the active BIG-IP system, one that represents the active system and one that represents the standby system." 

To clarify, this type of deployment requires you to create 1 GTM server on what will be the Active DNS device. Then add the 2 self ip addresses (one each for the Active and Standby GTM) to the GTM server. As an example,

root@(localhost1)(cfg-sync In Sync)(Active)(/Common)(tmos)# list gtm server
gtm server localhost1 {
    addresses {
        10.79.111.99 {
            device-name localhost1
        }
        10.79.111.100 {
            device-name localhost2
        }
    }
    datacenter SEA
    devices {
        localhost3 {
            addresses {
                10.79.111.99 { }   <<< Active BIG-IP DNS self-ip (localhost1)
                10.79.111.100 { }  <<< Standby BIG-IP DNS self-ip (localhost2)
            }
        }
    }
    monitor bigip
    product bigip

In the final step "Running the gtm_add script", gtm_add will replace the bigip_gtm.conf file of the Standby BIG-IP DNS device with the Active device's bigip_gtm.conf file.
