Description

After an upgrade, the BIG-IP may remain in an Offline state, and fail to load the configuration with an "Invalid version Data Input Error".

Environment

  • BIG-IP that has been upgraded to a newer version
  • BIG-IP DNS or BIG-IP GTM module was at some point previously provisioned, resulting in an empty configuration file. The modules do not need to be provisioned at time of upgrade.
 

Cause

The issue is tracked as ID 837637. If at some point you provision a BIG-IP DNS or BIG-IP GTM module, it will create a small /config/bigip_gtm.conf file as the example below. This configuration file will remain even after you de-provision the modules.

#TMSH-VERSION: 13.1.1
gtm global-settings metrics {
    metrics-collection-protocols { icmp }
}
gtm global-settings metrics-exclusions {
    addresses none
}

If that configuration file remains unused, the version number listed may become orphaned and will not be accepted as a valid one in a later software version upgrade.

Recommended Actions

  1. Edit your /config/bigip_gtm.conf and change the version listed to the nearest supported version. Referring to the example in the above cause, 13.1.1.4 is advised recommendation instead of the problematic 13.1.1.
  2. Reload the config:
    tmsh load sys config gtm-only
Alternatively, if you do not have BIG-IP DNS or BIG-IP GTM modules enabled, and are not using the features, with an empty configuration file as above, it should be safe to delete the /config/bigip_gtm.conf file followed by a configuration reload.
 

Additional Information

You may find the following syslog entries in /var/log/ltm when attempting to load the BIG-IP configuration.

example.bigip.local notice mcpd[4709]: 01070424:5: Full configuration initialization phase triggered.
example.bigip.local emerg load_config_files[9886]: "/usr/bin/tmsh -n -g -a load sys config partitions all gtm-only" - failed. -- Data Input Error:(/config/bigip_gtm.conf at line: 0) Invalid version:13.1.1: Supported cli versions: 13.1.1.4 14.0.0 14.1.0 14.1.1 14.1.2 15.0.0 15.0.1 15.1.0 16.0.0
example.bigip.local  err mcpd[4709]: 01070678:3: Full gtm configuration load failed ( Original ).
