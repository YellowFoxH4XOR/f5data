Known Issue

The Traffic Management Microkernel (TMM) may leak memory when an HTTP profile is associated with a FastL4 virtual server.

This issue occurs when all of the following conditions are met:

  • You have associated an HTTP profile with a FastL4 virtual server.
  • New client connections, processed by the virtual server, begin using HTTP data and then switch to non-HTTP data.

Impact

TMM can become unstable and may produce a core file due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. **Fixed versions include the option to configure a FastL4 profile and Transparent type HTTP profile on the same virtual server. To prevent this issue, you must configure the Pipeline Action Enforcement setting in the http-transparent HTTP profile with Pass Through. This action allows the HTTP profile to operate in pass through mode and process the traffic without excessive memory consumption.

Workaround

To work around this issue, you can perform one of the following actions:

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  • If the HTTP profile is not required, you can remove the HTTP profile from the virtual server. 
  • If the HTTP profile is required, use a standard virtual server rather than a Performance (FastL4) virtual server.
  • To process connections that change from HTTP to non-HTTP, create an iRule that uses HTTP::disable after the first HTTP_REQUEST or HTTP_RESPONSE boundary can be identified. For more information about HTTP::disable, refer to HTTP::disable on F5 Cloud Docs.
