K000138046: Deprecated version alert from azure for virtual Machines running in up to date point release

Type
Support Solution
Published
2023-12-27
Updated
2023-12-27
Source
https://my.f5.com/manage/s/article/K000138046

Description

Azure alerts with the message "Virtual Machines in your subscription are running on images that have been scheduled for deprecation", while the instance runs on an updated/non-deprecated version(say 16.X/17.X).


Environment

  • Azure advisor alert for deprecated version
  • Instance running on latest point release
  • Originally Licensed version is not 15.X/16.X/17.X

Cause

These alerts are from Azure, not F5/BIGIP instances.

However, it reflects the fact that 13.X and 14.X are going end of the technical support (EOTS) cycle at the end of year 2023, and this draws on information such as the "Licensed Version".

When the deployment was created (using a deprecated image, say 13.X/14.X), the license data gets tagged with the initial version. Upgrades within the instance do not change this.


Recommended Actions

  1. Discuss the options to update the license with your F5 Account Team or F5 Sales.
  2. Get a UCS Backup, Release the existing license or obtain an allow-move from f5 support, Deploy a new instance from a non-deprecated version (say 16.X/17.X) using the old (or a new) license, and then restore the UCS on the new instance.
