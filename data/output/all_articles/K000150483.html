Description

You have route domain configured and you see the connection table is empty even after changing the partition.

Environment

BIG-IP

Cause

None

Recommended Actions

To view the connection table for particular route domain you need to mention the route domain using the following syntax:
<IP address>%<route domain>

For example you have virtual server in route domain 10. So if you want to view connection table for client IP 203.0.113.10 accessing virtual server 192.0.2.1 on port 443, you can use below command
tmsh show sys connection cs-client-addr 203.0.113.10%10 cs-server-addr 192.0.2.1%10 cs-server-port 443 

For more information on the filters please check K53851362: Displaying and deleting BIG-IP connection table entries from the command line
