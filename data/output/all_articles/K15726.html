Known Issue

The tmrouted process may restart when a non-default route domain is reconfigured.

This issue occurs when the following condition is met:

  • A non-default route domain with dynamic routing protocols enabled is deleted and then subsequently re-added.

Impact

Dynamic routing for all route domains is temporarily disrupted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H485161 on the Diagnostics > Identified > High screen.
  • The tmrouted process produces a core file in the /shared/core directory.
  • Messages are logged to the /var/log/daemon.log file that appear similar to the following example:

    emerg logger: Re-starting tmrouted
