Description

Customers may encounter PSU alarms on rSeries and VELOS devices, indicating potential issues with the power supply units. Reseating the PSU is a recommended first step to address these alarms.

Environment

  • F5 rSeries devices
  • F5 VELOS devices
  • PSU alarm or alarms visible

Cause

The PSU alarms can be triggered by PSUs that are not properly seated, which may occur due to vibrations, movement, heat, or initial improper installation. This can cause intermittent power issues, leading to alarms shown by the system.

Recommended Actions

Important: Please see the articles listed in Related Content for all safety precautions and images.

Important: This product is sensitive to electrostatic discharge (ESD). F5 recommends that you use proper ESD grounding procedures and equipment when you install or maintain the unit.
 

To reseat a PSU in an F5 rSeries or VELOS device, follow these steps, ensuring to take the same precautions as noted in the PSU replacement procedure that can be found in the Related Content section:

  • Procedure for rSeries
  • Procedure for VELOS

Reseating PSUs in rSeries Devices:

  1. Identify PSU Type and Part Number:
    • Check the label on your PSU to confirm the part number (e.g., PWR-0306-xx for 650W AC) and ensure you reseat the correct PSU as per your device's alarms. For reference: F5OS How to check if the Velos/rSeries is using AC / DC PSU? 
    • To check which PSU is showing alarms, run the following command
      show system alarms
    • To check details about that PSU, run the following command, replacing 'X' with the number of the PSU that is shown in Alarms
      show components component psu-X
  2. Prepare the System:
    • For single-supply systems, power off the device.
    • For dual-supply systems, ensure one PSU remains operational if you intend to hot swap.
  3. Disconnect Power:
    • For AC PSUs, unplug the power cord by releasing any locking tabs.
    • For DC and HVDC PSUs, ensure the circuit breaker for the mains power source is switched off.
  4. Reseat the PSU:
    • Squeeze the PSU's ejector latch and pull the handle toward you to remove the PSU from the chassis.
    • Wait at least 30 seconds before reseating the PSU to allow it to fully discharge.
    • Inspect the PSU's connector area and pins for damage.
    • Slide the PSU back into the slot, pushing it in until the ejector latch clicks into place.
    • Ensure the PSU is fully seated by gently pulling on it to confirm it does not move.
  5. Reconnect Power:
    • For AC PSUs, reinsert the power cord until it's fully seated.
    • For DC and HVDC PSUs, reapply power by switching the circuit breaker back on.
  6. Verify Operation:
    • If the system was fully powered down, power it on using the touchscreen LCD.
    • Clear any alert messages on the LCD touchscreen that may have resulted from reseating the PSU.
    • Check show system alarms to see if there is still an issue.

Reseating PSUs in VELOS Devices:

  1. Identify PSU Type and Part Number:
    • Confirm the PSU part number for your VELOS device. For 3000W AC/HVDC PSUs, the part number is PWR-0366-xx, and for 3000W DC PSUs, it's PWR-0367-xx. For reference: F5OS How to check if the Velos/rSeries is using AC / DC PSU?
    • To check which PSU is showing alarms, run the following command
      show system alarms
    • To check details about that PSU, run the following command, replacing 'X' with the number of the PSU that is shown in Alarms
      show components component psu-X
  2. Prepare the System:
    • Check for adequate number of redundant PSUs in the chassis.
    • For maintenance or in the event of a PSU failure, ensure working redundant supplies are installed before reseating.
  3. Disconnect Power:
    • For AC/HVDC PSUs, ensure the socket outlet is easily accessible and disconnect power.
    • For DC PSUs, switch off the DC mains power source's circuit breaker.
  4. Reseat the PSU:
    • Remove the LCD bezel if necessary.
    • Lift the orange latch lock and squeeze the blue ejector latch on the PSU, then pull the handle toward you.
    • Wait at least 30 seconds to allow the PSU to fully discharge.
    • Inspect the PSU, particularly the connector area and pins, for any signs of damage.
    • Slide the PSU back into the slot, open the ejector handle, and push the PSU in until the ejector engages the chassis.
    • Push the latch closed until it clicks and secure the orange latch lock.
    • Ensure the PSU is fully seated by gently pulling to confirm it does not come out.
  5. Reconnect Power:
    • For AC/HVDC PSUs, reapply input power from the mains power source.
    • For DC PSUs, reapply input power by switching the circuit breaker back on.
  6. Verify Operation:
    • If the system was fully powered down, power it on using the touchscreen LCD.
    • Use the LCD touchscreen to clear any alert messages that may have resulted from reseating the PSU.
    • Check show system alarms to see if there is still an issue.
