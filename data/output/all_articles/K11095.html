Known Issue

This is the result of a known issue. When the BIG-IP WebAccelerator receives a response from an OWS, if the response contains an Expires HTTP header with a date of January 1, 2021 or later, the Expires HTTP header is logged as invalid in the /var/log/wa/pvac.log file. The message is logged three times, and appears similar to the following example:

WA Debug: {69192624} Invalid Expires header received {Fri, 01 Jan 2021 00:00:00 GMT}, setting to {3987432725}
WA Debug: {69192624} Invalid Expires header received {Fri, 01 Jan 2021 00:00:00 GMT}, setting to {3987432725}
WA Debug: {76864432} Invalid Expires header received {Fri, 01 Jan 2021 00:00:00 GMT}, setting to {3987432726}

F5 Product Development tracked this issue as CR118314 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Workaround

To prevent these error messages, the Expires HTTP header should include a date of December 3l, 2020 or earlier.

Note: RFC2616 indicates the Expires date should not be more than one year in the future.
