Known Issue

The End User Diagnostics (EUD) utility may report that the power supply model number is missing for some platforms.

This issue occurs when the following conditions are met:

  • Your BIG-IP platform contains any of the following power supply unit (PSU) models:
    • PWR-0130 - BIG-IP 800, 1600, 3600, 3900, and Enterprise Manager 4000 platforms
    • PWR-0147 - BIG-IP 1600, 3600, 3900, 2000, 4x00, 5000, and 7000 platforms
    • PWR-0148 - BIG-IP 6900, 8900, 8950, and 110x0 platforms
    • PWR-0149 - BIG-IP 6900, 10xx0, 12xx0, and 110x0 platforms
    • PWR-0174 - C2400 AC chassis
    • PWR-0177 - C2400 DC chassis
    • PWR-0187 - BIG-IP 2000, 4x00 platforms
    • PWR-0199 - BIG-IP 10xx0, 12xx0 platforms
  • You run the EUD utility on your platform.
The power supplies displaying the message string are from units in which the EEPROM chip was updated in the fall of 2015 to reflect a vendor name change.

Impact

There is no impact to the functionality of the power supply or the BIG-IP appliance.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The EUD system report displays a message that appears similar to the following example:

    Power Supply 2: Present - No Model Number Found
