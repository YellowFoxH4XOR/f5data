Description

Creation of custom Strategy List Policy in Traffic Management User Interface(TMUI) that used the default operands for tcp will cause creation of object that does not pass validation.  TMOS Shell(TMSH) does not allow the same object to be created.
 
Error messages from validation of config

  • 010716f6:3: Strategy '/Common/test'; operand 'tcp' does not support selector 'all'.
 
Attempts to delete the object from TMUI fail with:
  • An error has occurred while trying to process your request.

Environment

  • LTM
  • Strategy List Policies
  • TMUI

Cause

The default operand of “tcp request address” is not a valid configuration causing validation failure and config load failure.  F5 is tracking this as Bug ID 864285.

Recommended Actions

  1. TMSH allows deletion of Strategy List object:
    tmsh delete ltm policy-strategy <object>
