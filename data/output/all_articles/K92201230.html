Known Issue

The BIG-IP ASM TS cookie name may contain NULL or raw byte characters.

This issue occurs when all of the following conditions are met:

  • You configure a virtual server with a BIG-IP ASM security policy.
  • A rare combination of the active security policy name and the cookie attributes sent by the server results in a computed TS cookie name with too few hexadecimal characters.

The BIG-IP ASM system performs a CRC calculation, which includes the security policy name and cookie attributes in the server's cookie. If, by chance, the CRC calculation result is less than six hexadecimal characters, the resulting TS cookie name may include a trailing NULL character.

Impact

The BIG-IP ASM system reports false positive modified domain cookie violations.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Traffic captures show the BIG-IP ASM system sending responses to the client containing Set-Cookie headers with invalid TS cookie names.
  • The BIG-IP ASM system reports modified cookie domain violations.

Workaround

To work around this issue, you can change the name of the security policy by exporting and re-importing the policy. To do so, perform the following procedure for your version:

Impact of workaround: Performing the following procedure changes the active security policy for the virtual server and you should perform the procedure during a maintenance window.

BIG-IP ASM 13.x

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Security Policies.
  3. Select the policy to rename.
  4. Select Export, then Export Policy.
  5. Select the arrow next to Create and select Import Policy.
  6. In the Imported Policy File box, click Select File.
  7. Choose the policy that was just exported, and click Open.
  8. In the Import Target box, select New Policy.
  9. In the Imported Policy Name box, enter the new name for the security policy.
  10. Click Import Policy.
  11. Navigate to Local Traffic > Virtual Servers.
  12. Click the name of the virtual server.
  13. Click the Security tab and select Policies.
  14. In the Application Security Policy box, select the name of the newly imported policy in the Policy menu.
  15. Click Update.

BIG-IP ASM 12.x

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Security Policies.
  3. Select the policy to rename, and click Export.
  4. Select the export method in the pop-up window, and click Export.
  5. Click Import.
  6. Click Choose File, and select the exported policy.
  7. Click Open.
  8. In the Import Target box, select Inactive Security Policies List.
  9. Click Import.

    The BIG-IP ASM system automatically renames the imported policy to avoid a conflict with the existing policy name.

  10. Navigate to Local Traffic > Virtual Servers.
  11. Click the name of the virtual server.
  12. Click the Security tab, and select Policies.
  13. In the Application Security Policy box, select the name of the newly imported policy in the Policy menu.
  14. Click Update.
