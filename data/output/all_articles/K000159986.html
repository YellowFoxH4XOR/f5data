Description

When attempting to add an F5OS-C (VELOS) controller device to BIG-IQ Centralized Management, a "400 Bad Request" error may occur. The error message typically appears as:

"The system returned an unexpected error (400 Bad Request). remoteSender:<IP_ADDRESS>, method:POST"

Environment

  • BIG-IQ Centralized Management
  • F5OS-C (VELOS)
  • F5OS-C controllers in high availability (HA) configuration

Cause

This issue typically occurs when trying to add an F5OS-C standby controller using its individual management IP address rather than the VELOS-C floating controller management IP address.

Answer/Recommended Actions

Use the VELOS-C controller Floating Management IP Address.

Additional Information

Always use the floating controller management IP address when adding F5OS-C controller devices to BIG-IQ. The floating IP automatically connects to the active controller, ensuring proper communication.
