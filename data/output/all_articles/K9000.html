Known Issue

This is the result of a known issue. A BIG-IP standby unit may leak connection flows for Layer 2 forwarded traffic if it receives traffic immediately prior to assuming standby mode. Once in standby mode, the BIG-IP system retains the connection flows as though they were configured with an infinite timeout value. As a result, this behavior may cause increased memory usage.

Note: If a redundant pair system is configured to mirror connections, the aggressive sweeper will remove the stale connection flows when the low memory water mark is reached.

F5 Networks Product Development tracked this issue as CR101659 and it was fixed in BIG-IP version 9.4.6.  For information about upgrading, refer to the BIG-IP LTM, ASM, or Link Controller Release Notes.

Additionally, this issue was fixed in Hotfix-BIGIP-9.4.4-94.0-HF3, issued for BIG-IP version 9.4.4, and in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP version 9.4.5. You may download these hotfixes or later versions of the hotfixes from the F5 Networks Downloads site.
