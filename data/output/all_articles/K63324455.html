K63324455: APM: NTLM Authentication fails with the error message: Fail (STATUS_NO_LOGON_SERVERS)

Type
Support Solution
Published
2019-10-29
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.X, 13.1.4, 13.1.3, 13.1.1, 13.1.5, 13.1.0
Source
https://my.f5.com/manage/s/article/K63324455

Description 

Users fail NTLM Authentication with the following error messages.

  • You observe messages similar to the following in /var/log/apm:

    <big-ip_hostname> warning eca[13847]: 01620002:4: [Common] <ip_address>:52486 Authentication with configuration (/Common/<ntlm_authentication_profile>) result: <username>@<domain> (<domain>: Fail (STATUS_NO_LOGON_SERVERS)
    <big-ip_hostname> err eca[13847]: 0162000e:3: Could not verify user (<domain>\<username>) credential (STATUS_NO_LOGON_SERVERS)
     
  • You observer the following error in the BIG-IP GUI when attempting to "Renew Machine Password":

    "Could not connect to domain domain controller of realm "<FQDN>" machine account update for "<machine account name>" failed: Preauthentication failed, principal name: <machine account name>@<FQDN>. Invalid user credentials. (-1765328360)"

Environment

  • BIG-IP APM
  • NTLM Authentication Configuration
  • NTLM Machine Account configuration
  • User fail NTLM authentication

Cause

Unknown at time of publication.

Recommended Actions

It is recommended to create a new NTLM Machine Account and replace the previous NTLM Machine Account in the NTLM Auth Configuration. Once this is done we also recommend you delete the previous NTLM Machine Account from both the APM and Active Directory.

Create and configure a new NTLM Machine Account

  1. Login to the Configuration Utility.
  2. Navigate to Access > Authentication > NTLM > Machine Account
  3. Click Create
  4. Enter the configuration information.
  5. Click Join
  6. Navigate to Access > Authentication > NTLM Auth Configuration
  7. Select the existing NTLM Configuration.
  8. Select the new NTLM Machine Account object.
  9. Click Finished

Delete the previous NTLM Machine Account

  1. Login to the Configuration Utility.
  2. Navigate to Access > Authentication > NTLM > Machine Account
  3. Select the previous NTLM Machine Account
  4. Click Delete.
