K000138560: [F5OS-C] Upgraded to 1.6.1, one of System Controllers is not accessible after upgrade

Type
Support Solution
Published
2024-02-09
Updated
2024-09-05
Source
https://my.f5.com/manage/s/article/K000138560

Description

After upgrade to prior to 1.6.2, lost connection to one of System Controller.
Active controller is accessible but does not show any status for standby System Controller

Can not SSH to standby System Controller.

Console access only, and can not log in as admin but root only.

/var/log/sw-mgmt.debug shows similar to the below log (1.X.X-XXXXX is F5OS-C's version)

ERROR: sw-mgmt: priority=error msgid=0x3501000000000153 msg=Unexpected error importing partition services 1.X.X-XXXXX: ('Connection aborted.', FileNotFoundError(2, 'No such file or directory'))

 

Environment

  • F5OS-C
  • Velos
  • Upgrade to prior to 1.6.2

 

Cause

  • Bug ID 1349257
  • K000137531 : VELOS system controller may become inoperative during rolling software upgrade

 

Recommended Actions

  • Apply workaround in K000137531 : VELOS system controller may become inoperative during rolling software upgrade
