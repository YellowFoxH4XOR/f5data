Topic

You can use the bigtop command to display a certain number of nodes or VIPs at a given time, but you cannot use bigtop to report for a single VIP or NAT.

There are, however, a few options that can help you display the information in a format that is more readable.

To help you view large configurations that normally would not fit on one screen, you can use the -scroll option. To do this, perform the following steps:

Note: If you are running BIG-IP version 4.0 through 4.2 PTF-03, refer to K1407: Known Issue: bigtop crashes and dumps core when used with the -scroll flag.

  1. From the command line, type the following command:

    bigtop -scroll

  2. Let the page refresh and display a few times (by default, it will refresh every 4 seconds), and then exit bigtop by pressing Ctrl-C.
  3. Use the scroll bar in the window to return to the snapshot of the pages previously displayed.

You can also use the following display options to make the information easier to read:

CommandFunction
bytesDisplay counts in bytes (default: bits).
pktsDisplay counts in packets (default: bits).
vips [value]Quantity of VIPs to print (default: all).
nodes [value]Quantity of Nodes to print (default: all).
oncePrint once and exit.
delay [value]Number of seconds between samples (default: 4).
scrollDisable full-screen (curses) mode.
nosortDisable sorting.
connSort by connection count (default: sort by byte count).
deltaSort by count since last sample (default: sort by total count).
helpDisplays help information, and various options.

For information about the bigtop command, refer to the bigtop utility man pages.
