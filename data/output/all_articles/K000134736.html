K000134736: NGINX App Protect Details, Metrics and Event Logs are not Populating

Type
Support Solution
Published
2023-05-23
Updated
2023-06-22
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.10.0
Source
https://my.f5.com/manage/s/article/K000134736

Description

In NGINX Instance Manager ui, NGINX App Protect is reporting "Not Found", App Protect Details are missing and Security Monitor (if enabled) Metrics and Event Logs are not populating.

Environment

NMS

Cause

The issue may be a result of missing configuration on NGINX Agent.
NMS v2.10.0+ introduced a change in behavior, via NGINX Agent v2.24.0+, where NGINX App Protect needs to be enabled as an extension on NGINX Agent.

Recommended Actions

Enable the NGINX App Protect extension on NGINX Agent:

  • On an NGINX Agent instance, follow documentation Configuring the NGINX Agent
  • Edit the NGINX Agent configuration file:   
    sudo vim /etc/nginx-agent/nginx-agent.conf
  • Add the following configuration settings:  
    # Enable NAP
extensions:
  - nginx-app-protect
    • NGINX Agent configuration settings can exist anywhere within the nginx-agent.conf file
  • Restart NGINX Agent:  
    sudo systemctl restart nginx-agent.service


Additional Information

Advanced Metrics and NAP Monitoring are also now extensions. Enable Advanced Metrics and NAP Monitoring by adding them as an NGINX Agent extension, the same way the NGINX App Protect extension is added. For example, to enable NGINX App Protect, Advanced Metrics and NAP Monitoring the NGINX Agent extension settings would be as follows:

# Enable NAP, Advanced Metrics and NAP Monitoring
extensions:
  - advanced-metrics
  - nginx-app-protect
  - nap-monitoring

Additionally, Advanced Metrics, NGINX App Protect and NAP Monitoring CLI flags have been removed: 

# CLI flags that have been removed
advanced-metrics-*
nginx-app-protect-*
nap-monitoring-*
