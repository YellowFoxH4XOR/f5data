Description

/Common/Sample_Access_Profile:Common:a1b2c3d4:/Common/azure_ad_oauth_act_oauth_client_ag: OAuth Client: failed for server '/Common/access_sample_azureAD_server' using 'authorization_code' grant type (client_id=1234abcd-1a2b-2b3c-3c4d-a1b2c3d4e5f6), error: Failed to perform curl: Failure when receiving data from the peer

Environment

  • BIG-IP APM
  • External OAuth  IDP

This can happen with any OAUTH2/OIDC  identity provider. Azure in the log above

Cause
Incorrect DNS Resolver configuration

Recommended Actions

  1. Increase the logging for the OAuth module to debug for verification of failed resolution
    Logging adjustment details can be found here:
    K24826763: Configuring the BIG-IP APM Logging Levels (12.x and newer)
  2. Verify you can complete a "dig" command from the BIG-IP to the OAUTH uri utilizing the configured DNS server(s) in the DNS resolver on the BIG-IP?
