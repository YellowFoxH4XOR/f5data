Known Issue

The TMM may leak memory when the BIG-IP system sends a compressed response and the connection is ended early.

This issue occurs when the following condition is met:

  • The BIG-IP AVR module is licensed and provisioned.

Impact

BIG-IP system memory usage increases over time, which may eventually cause a decrease in performance or a system reboot due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The tmsh show /sys memory command indicates that the allocated bytes for the deflate subsystem grows over time.
  • The BIG-IP performance graphs indicate high memory usage.
