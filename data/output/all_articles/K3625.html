Topic

This article applies to BIG-IP 4.5.x through 9.4.1. For information about other versions, refer to the following articles:

  • K13206: Configuring local hostname resolution for BIG-IP (11.x - 12.x)
  • K8439: Configuring local hostname resolution for BIG-IP (9.4.2 - 10.x)

You must enable name resolution in order to use DNS names at the command line and to use some optional configurations, such as email delivery.

BIG-IP and 3-DNS use two sources of information to resolve DNS names. First, they look in the local hosts file. If the answer is not found in that file, they attempt to use DNS to resolve the name.

Note: For information about configuring DNS name resolution, refer to K3624: Configuring BIG-IP to resolve DNS hostnames (4.5.x - 9.4.1).

Note: For information about configuring local hostname resolution for BIG-IP versions 9.4.2 and later, refer K8439: Configuring local hostname resolution for BIG-IP (9.4.2 - 10.x).

Configuring a local host file

To configure a local host file, perform the following procedure:

  1. Log in to the BIG-IP or 3-DNS command line.
  2. Using a text editor, edit the /etc/hosts file.
  3. In the following format, add a line for each host anywhere in the file:

    <IP Address> <Host Name>

    For example:

    10.90.101.81   hostone.askf5.com
10.90.101.82   hosttwo.askf5.com
10.90.101.83   hostthree.askf5.com

    Note: If the names or addresses for these servers change in the future, you must update the /etc/hosts file or local hostname resolution will stop working.

  4. Save the file and exit the editor. 

Testing local host name resolution

To test the local hostname resolution, use the following command syntax:

In this command syntax, note the following:

  • Replace <name> with the DNS name of a server on your network:

ping <name>

For example:

ping www.askf5.com

If the test is successful, you will receive a response that includes an IP address, similar to the following example:

PING www.askf5.com (10.90.100.21): 56 data bytes

If the test is not successful, you will receive a response that appears similar to the following example:

ping: unknown host www.askf5.com
