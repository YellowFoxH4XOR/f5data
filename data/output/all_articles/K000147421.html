Description

  • You want to know what a blank record is and its objective

Environment

  • F5® Distributed Cloud Primary DNS

Answer

  • A blank record (sometimes seen as the ‘@’ record) points your main domain to a server
  • You can also set subdomains to point to other IP addresses as well, if you run multiple webservers
  • Sometimes it's seen as the ‘@’ record
