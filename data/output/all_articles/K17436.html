Known Issue

In rare circumstances, the Traffic Management Microkernel (TMM) process may produce a core file while processing traffic through the bandwidth controller.

This issue occurs when all of the following conditions are met:

  • You associate a bandwidth controller profile with a virtual server.
  • There is no iRule with bandwidth controller features associated with the virtual server.
  • The virtual server is processing traffic.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting, and systems configured as part of a high availability (HA) group may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to the standby system if configured for HA.
  • The BIG-IP system generates TMM core files to the /shared/core directory, with a time stamp that correlates to the traffic interruption.
