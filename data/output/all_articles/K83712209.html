Issue

Error Message

err mcpd[<PID>]: 0107028a:3: The source address (<IP address>) for virtual server (<virtual_server_name>) must have a prefix length.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <IP address> is the IP address configured as the source failover address on the local system.
  • <virtual_server_name> is the name of the virtual server you are attempting to create or modify.

For example:

err mcpd[5505]: 0107028a:3: The source address (192.0.2.1) for virtual server (/Common/example_virtual_server) must have a prefix length.

Message Location

You may encounter this message in the following locations:

  •     The /var/log/ltm file
  •     The Configuration utility
  •     The TMOS Shell (tmsh)
Description

This message occurs when the following condition is met:

  • You specify a source address without a prefix length when creating or modifying a virtual server.

Impact

The virtual server is not created or modified and no changes are made to the system.

Recommended Actions

When you create or modify a virtual server, you must include a prefix after the address if a source address is required, The supported format is address/prefix, where the prefix length is in bits. For example, to select all IP addresses, an IPv4 address/prefix is 0.0.0.0/0, and an IPv6 address/prefix is ::/0. To specify a network, for example, an IPv4 address/prefix is 192.0.2.1/24, and an IPv6 address/prefix is 2001:DB8::/32.
