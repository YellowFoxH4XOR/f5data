Description

  • I want to configuring routes that match a header and point to a specific origin pool/server
  • How do I use headers in routes configuration in load balancers to send traffic to specific pools?

Environment

  • Distributed Cloud (SaaS)
  • F5® Distributed Cloud HTTP Load Balancer

Answer/Recommended Actions

To capture ability to match a route based on request header:

  1. Open Console
  2. Select Load Balancers
  3. Select Manage
  4. Select Load Balancers
  5. Select HTTP Load Balancers
  6. In Actions column select ... 
  7. Select Manage Configuration option
  8. In HTTP LB pop-up form select Edit Configuration
  9. In Routes section toggle Show Advanced Fields
  10. Select Configure link
    1.  
  11. Click + Add Item
  12. Select Type of Route drop-down menu
  13. Select Simple Route
  14. Select HTTP Method drop down menu option
  15. Select ANY
  16. Select Path Match drop-down menu
  17. Select Prefix
  18. Enter Prefix
  19. Headers:
    1. Click+ Add Item
    2. Enter Name in Header to Match box
    3. Select Value drop-down menu, select Exact
      1. Value options: 
      2. Exact > Enter exact in box.
      3. Regex > Enter regex in box.
      4. Presence > Check Presence box.
    4. Enter Exact header value to match exactly. (ex: abc)
    5. Select NOT of match box if needed
    6. Click Add Item
    7. Click + Add Item to add more headers
  20. Select Host Rewrite Method drop-down menu
  21. Select Automatic Host Rewrite
  22. Click Add Item button
  23. In Routes box click + Add Item to add more if needed
  24. In Routes box click Apply
  25. Click Save and Exit
