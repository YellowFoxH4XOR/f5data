Known Issue

When multiple iApps use the same virtual address, attempts to reconfigure one of the affected iApps will fail.

Impact

The affected iApp cannot be reconfigured.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H427317 on the Diagnostics > Identified > Low screen.
  • Attempting to reconfigure one or more of the affected iApps will fail. In addition, you may observe an error message using the following syntax:

    01070734:3: Configuration error: Unable to modify the traffic group for application (/Common/<App Name>.app/<App Name>) because it uses virtual address (/Common/<Virtual Address>) which is also used by application (/Common/<Other App Name>.app/<Other App Name>)

    For example:

    01070734:3: Configuration error: Unable to modify the traffic group for application (/Common/Sample2.app/Sample2) because it uses virtual address (/Common/192.168.1.0) which is also used by application (/Common/Sample1.app/Sample1)

Workaround

To work around this issue, you can disable inherited traffic group selection for the affected iApps. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to iApp > Application Services.
  3. Click the name of the affected iApp to be reconfigured.
  4. Select the Reconfigure tab.
  5. From the Template Selection menu, select Advanced.
  6. From the Traffic Group section, clear the Inherit traffic group from current partition / path check box.
  7. From the Traffic Group menu, select the desired traffic group.
  8. Make the other desired changes to the iApp.
  9. Click Finished.
