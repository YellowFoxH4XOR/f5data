Known Issue

A BIG-IP LTM virtual server may erroneously detect congestion in the network.

This issue occurs when all of the following conditions are met:

  • You configure a TCP profile to use the Woodside congestion control algorithm.
  • You associate the TCP profile with a virtual server.
  • The virtual server processes TCP connections with large congestion windows.

Impact

The affected virtual server experiences a decrease in TCP performance. Additionally, TMM may produce a core file and restart.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The affected virtual server experiences a decrease in TCP performance.
  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system fails over to another host in the device group.

Workaround

To work around this issue, you can configure the affected TCP profile to use a congestion control algorithm other than the Woodside congestion control algorithm.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
