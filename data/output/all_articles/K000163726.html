Security Advisory Description

The BIND resolver accepts validly-signed NSEC records where the "Next Domain Name" field points outside the signer's zone. This issue affects BIND 9 versions 9.11.0 through 9.18.50, 9.20.0 through 9.20.24, 9.21.0 through 9.21.23, 9.11.3-S1 through 9.18.50-S1, and 9.20.9-S1 through 9.20.24-S1. (CVE-2026-13321)

Impact

This vulnerability allows cross-zone cache poisoning when a BIND resolver accepts validly-signed NSEC records where the Next Domain Name field points outside the signer's zone. If an attacker controls or spoofs an authoritative DNSSEC-signed zone and serves crafted NSEC records spanning into victim zones, the resolver incorrectly accepts these records as valid, enabling authenticated denial-of-existence responses (AD=1) for domains in other zones. If your BIG-IP DNS system is enabled with recursion as described in K7055: Enabling DNS recursion in the named configuration on a BIG-IP DNS system, then it is exposed to this vulnerability.

Mitigation

To mitigate this issue, you can either disable recursion on your BIG-IP DNS system or disable the Use BIND Server on the BIG-IP option in the DNS profile. Note that disabling the Use BIND Server on the BIG-IP option in the DNS profile prevents the named process from being used for DNS resolution entirely, and as a result, eliminates the vulnerable code path.

To do so, perform either of the following procedures:

  • Disabling recursion on the BIG-IP DNS system
  • Disabling the Use BIND Server in the DNS profile

Disabling recursion on the BIG-IP DNS system

To disable recursion on your BIG-IP DNS system, perform the Restricting DNS recursion on the BIG-IP DNS system procedure described in K7055: Enabling DNS recursion in the named configuration on a BIG-IP DNS system.

Disabling the Use BIND Server in the DNS profile

To disable the Use BIND Server on BIG-IP option in the DNS profile, perform the following procedure:

Important: Disabling the BIND server can affect DNS configurations that use BIND as a fallback method (return to DNS) for resolution.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Services > DNS.
  3. Select the applicable DNS profile.
  4. For the Use BIND Server on BIG-IP option, select Disabled.
  5. Select Finished.
