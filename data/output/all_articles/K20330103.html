Topic

You should consider using this procedure under the following condition:

  • You need to edit a file stored on /usr file system.

Description

The BIG-IP /usr file system is mounted in read-only mode. While this configuration enhances overall system security, it can impact users who want to make modifications to files stored on the /usr file system. For example, K4422: Viewing and modifying the files that configured for inclusion in a UCS archive includes procedures that involve editing the /usr/libdata/configsync/cs.dat file.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You are assigned the Administrator or Resource Administrator user role.
  • You have Advanced Shell (bash) access to the BIG-IP system.

Procedures

Remounting the /usr file system

Impact of procedure: This procedure does not impact traffic; however, F5 recommends that you perform this procedure only during a maintenance window.

  1. Log in to the BIG-IP command line.
  2. To remount the /usr file system in read-write mode, type the following command:

    mount -o remount,rw /usr

  3. Edit the intended file stored on the /usr file system.
  4. To remount the /usr file system in read-only mode, type the following command:

    mount -o remount,ro /usr
