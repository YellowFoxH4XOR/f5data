Description

BIG-IP stays offline, checking the folloiwng command output, bd is marked as Fail.

tmsh show /sys ha-status all-properties

--------------------------------------------------------------------------------
Sys::HA Status
Feature               Key              Action                        Fail  Feature  Take  Client  Proc             Timeout
                                                                           Enabled  Act   Data                     (sec)
--------------------------------------------------------------------------------
...
proc-run              bd               go-offline-downlinks          yes   yes      yes   0       sod              10

But db log does not show the reason to fail to run.
 

Environment

  • BIG-IP
  • ASM
     

Cause

/var/lib/mysql partition is used up.
The following command shows

df -h

Filesystem                                        Size  Used Avail Use% Mounted on
...
/dev/mapper/vg--db--sda-app.ASWADB.set.2.mysqldb   12G   12G     0 100% /var/lib/mysql  
...
 

Recommended Actions

Check what is occupying the partition by running the following command
 
ls -alsR | grep -A1 '/var/lib/mysql/'
/var/lib/mysql/AVR:
total 10909900  <<<---------[!!]
--
/var/lib/mysql/DCC:
total 2280
--
/var/lib/mysql/PLC:
total 3800
--
/var/lib/mysql/PRX:

If the AVR is large, then rest AVR database following: K23735884: MySQL continuous restarting due to "/var/lib/mysql" partition 100% full.
