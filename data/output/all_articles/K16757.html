Description

The BIG-IP PEM system includes predefined classification signatures for many standard categories and applications. URL categorization provides the ability to enforce policies configured as part of the subscriber profile, based on the URL category type. URL categorization uses the Webroot database to perform URL filtering.

The full Webroot database contains more than 100 million entries, as the database is constantly being updated; however, the BIG-IP PEM system has a limited internal repository size of up to 20 million entries. For this reason, you may encounter a target URL that is uncategorized. This scenario occurs because the target URL is not present in the internal repository, and the BIG-IP PEM system did not match it to any category to perform the defined classification.

Recommendations

Starting in BIG-IP 11.6.0, you can create a custom URL database that can be leveraged for adding custom URLs and categories. To create a custom URL database with BIG-IP PEM 11.6.0, when using the PEM URL filtering function (where customization of the URL database is required), refer to the Creating Custom Classifications chapter of the BIG-IP Policy Enforcement Manager: Implementations guide.
