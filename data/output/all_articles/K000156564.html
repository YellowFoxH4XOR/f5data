Description

This article describes how to leverage Aspen Mesh's proxy logs to calculate valuable monitoring information, such as the percentage of dropped connections using Prometheus. The Prometheus query used in the example below calculates the percentage of stream connections that were terminated due to exceeding the allowed time, as defined by stream_idle_timeout configuration variable, by utilizing the SI response flag in the logs.
Note: For additional details and references to relevant documentation, please refer to Related Content 

Environment

  • Kubernetes
  • Aspen Mesh
  • Istio
  • Envoy
  • Prometheus

Cause

  • None

Recommended Actions

  •  Accessing Prometheus Web UI, the following query can be run:
( sum(irate(istio_requests_total{response_flags="SI"}[5m]) ) / 
sum(irate(istio_requests_total{response_flags!=""}[5m])) ) * 100

 

  • The above will give the percentage of dropped connections across the service mesh.

Figure: Graph displaying the percentage of timed out connections in Prometheus Web UI

Additional Information

  • Using Prometheus Query Language, you can monitor the timeout percentage for a specific workload pair.
( sum(irate(istio_requests_total{response_flags="SI",source_workload="client",destination_workload="server"}[5m]) ) / 
sum(irate(istio_requests_total{response_flags!="",source_workload="client",destination_workload="server"}[5m])) ) * 100
