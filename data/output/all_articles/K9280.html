Known Issue

This is a result of a known issue. When simultaneously changing the monitor interval and the monitor destination address of an existing application health monitor, the old monitor instance may not be completely removed from the probe list in memory. This may result in a segmentation fault of the gtmd process.

F5 Product Development tracked this issue as CR106287 and it was fixed in BIG-IP GTM 10.0.0. For information about upgrading, refer to the BIG-IP GTM Release Notes.

Workaround

Instead of modifying the existing monitor, create and apply a new monitor with the correct settings.
