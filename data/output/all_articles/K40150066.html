Topic

The serial number of your F5 VNF Manager solution can be retrieved from the VNF Manager Web UI.

Description

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your F5 VNF Manager is configured with a deployment.

Procedures

  • Displaying the serial number using the VNF Manager Web UI
  • Displaying the serial number using the vnfm cli utility

Displaying the serial number using the VNF Manager Web UI

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the VNF Manager Web UI.
  2. Navigate to Deployments.
  3. Locate the main Gi solution deployment and click either the OpenStack-F5-VNF-Service-Layer-xxxx or the vSphere-F5-VNF-Service-Layer-xxxx blueprint depending on the virtual infrastructure manager (VIM) platform deployed.
  4. Locate the Deployment Inputs section and retrieve the serial number from the ric_vnfm_serial field.

Displaying the serial number using the vnfm cli utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line interface.
  2. To retrieve the serial number, use the following command syntax:

    vnfm deployments inputs <main_deployment> | grep -A1 ric_vnfm_serial

    For example, to retrieve the serial number for the deployment GILAN_deploy_01, type the following command:

    vnfm deployments inputs GILAN_deploy_01 | grep -A1 ric_vnfm_serial
