K000135292: F5 SDC maintains the core file to reduce the disk space usage.

Type
Support Solution
Published
2024-07-02
Updated
2024-07-02
Applies to
  • Traffix SDC: 5.X.X, 5.2.X, 5.2.0, 5.1.X, 5.1.0, 5.0.X, 5.0.0
Source
https://my.f5.com/manage/s/article/K000135292

Description

Maintains the SDC's core file to reduce disk space usage.

  • The core file directory is /var/cores
  • The core file does not automatically remove, and the size might be bigger than 1 GB
  • To avoid the full disk space situation, please remove the old core files.

Environment

SDC

Cause

Maintains the SDC's core file to reduce disk space usage. To avoid the full disk space situation.

Recommended Actions

Recommend doing the house keeping once the core file completed troubleshooting with F5 support, you can safe to remove it.
