Description

Customers who purchase an NGINX product through AWS Marketplace must select NGINX Marketplace Cloud as the product module when opening a support case. 


                                                                                                             Figure : Select product ModuleNGINX Marketplace/Cloud

Environment

  • MyF5

Cause

None

Recommended Actions

When opening a support case for an NGINX product purchased through AWS Marketplace:

1. Sign in to the F5 support portal.

2. Create a new support case.

3. In Product Module field, select NGINX Marketplace Cloud

4. Provide detailed description of the issues.

5. Submit the case.
