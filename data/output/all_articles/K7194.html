K7194: The BIG-IP LTM system may drop server data buffered by the TCP::collect iRule command when the BIG-IP receives a FIN from the server

Known Issue

This is the result of a known issue. The TCP::collect iRule command allows the BIG-IP system to collect a specified amount of content data in its buffer. The collected data can then be parsed by the BIG-IP iRule engine. The BIG-IP LTM system may drop buffered content data collected by the TCP::collect iRule command when the BIG-IP receives a FIN response from the server. This behavior can cause file downloads to be aborted prematurely by the BIG-IP system.

F5 Networks Product Development tracked this issue as CR74924, and it was fixed in BIG-IP LTM versions 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
