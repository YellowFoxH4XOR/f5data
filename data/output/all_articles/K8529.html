Known Issue

This is the result of a known issue. SNMP queries for virtual server statistics only receive responses from virtual servers on the common partition. This issue occurs when virtual servers are created on partitions other than the common partition. When an SNMP query is performed to gather the statistics from the virtual servers, those virtual servers not on the common partition will return a result of 0 (zero).

This behavior results from the mcp process only returning the results for the virtual servers on the common partition, and not for the virtual servers on other partitions.

F5 Networks Product Development tracked this issue as CR80987 and it was fixed in BIG-IP LTM version 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
