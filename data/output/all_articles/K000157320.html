Description

 

PostgreSQL DB monitor may fail with an error similar to the following:

 

SQL Exception:

org.postgresql.util.PSQLException: FATAL: invalid value for parameter "TimeZone": "US/Pacific-New"

 

This occurs when BIG-IP 'sys ntp timezone' is set to America/Los_Angeles (default) and the DB monitor client instance picks up US/Pacific-New from the zoneinfo directory as it tries to find a TZ file with a match for the offset. When the monitor sends the TimeZone parameter in a PostgreSQL Startup message towards the database server, and the server does not support the deprecated time zone alias, the server rejects the connection and the error is thrown. DB monitor marks the pool member down.

 

Environment

  • BIG-IP
  • PostgreSQL DB monitor

 

Cause

 

Deprecated time zone alias being sent to a DB server that no longer support it. PD has raised ID2144029 for this.

 

Recommended Actions

 

1. Delete the file /etc/localtime:

  rm /etc/localtime

2. Create a symbolic link for the file pointing to the desired timezone as listed in /usr/share/zoneinfo.  If you have 'sys ntp timezone America/Los_Angeles', the command would be:

  ln -sf /usr/share/zoneinfo/America/Los_Angeles /etc/localtime

3. Restart bigd.

bigstart restart bigd
