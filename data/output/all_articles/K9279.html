The BIG-IP LTM system can act as an IPv4 to IPv6 gateway (and vice versa) by configuring a virtual server using one IP address version and pool members using the other version.

Note: To configure and use IPv6 addresses, the BIG-IP system must be licensed with the IPv6 Gateway Module. Beginning in BIG-IP 10.0.0, the IPv6 Gateway Module is automatically included and enabled (license status can be viewed within the Configuration utility by clicking System > License). BIG-IP versions prior to 10.0.0 require the IPv6 module license to be purchased. For information about purchasing the IPv6 Gateway Module, contact your F5 Sales Representative.

Note: Self IP addresses matching the pool members' IP address versions must also be configured on each VLAN. For more information about configuring IPv4 to IPv6 load balancing, refer to the BIG-IP Local Traffic Manager: Implementations guide. For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Connections that must be translated between IP address versions are automatically translated using the self IP address on the appropriate Virtual Local Area Network (VLAN) whose version matches that of the destination address. It is not necessary to create specific SNAT objects to enable this functionality, only to have self IP addresses of the appropriate version configured on each VLAN.

This automatic source address translation makes it possible to use one virtual server to load balance to a pool containing members using both address versions: Some members may use IPv4 addresses while others use IPv6 addresses. The BIG-IP system will load balance, as usual, to the pool members and translate to the appropriate address when necessary.

Without a SNAT address of the correct version explicitly configured, the following source address translation occurs:

  • Connections to an IPv4 virtual server that are forwarded to an IPv6 destination will be translated to the IPv6 self IP address of the destination VLAN.
  • Connections to an IPv6 virtual server that are forwarded to an IPv4 destination will be translated to the IPv4 self IP address of the destination VLAN.
  • Connections to a virtual server that are forwarded to a destination of the same IP version will not be translated.

Explicitly configured SNATs will override any automatic translation to the self IP.
