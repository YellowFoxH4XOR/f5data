Topic

RTT load balancing does not delay name resolution requests.

A 3-DNS Controllers wide IP is configured with a preferred, alternate, and fallback load balancing method. When the 3-DNS Controller receives a DNS request from a local DNS (LDNS), it first attempts to load balance the request using the preferred method.

If the preferred method is RTT, and the 3-DNS Controller has already probed the requesting LDNS, the 3-DNS Controller answers with the appropriate virtual server IP address. If the 3-DNS Controller has not probed the LDNS, it uses the alternate load balancing method and returns a virtual server IP address to the LDNS based on the alternate method. The 3-DNS Controller then initiates probing for that LDNS, and any subsequent requests are handled by the preferred method (in this case, RTT).
