K000163325: F5 Insight GUI Unreachable After Importing a Password-Protected Private Key

Type
Support Solution
Published
2026-09-15
Updated
2026-09-20
Applies to
  • BIG-IP
  • F5 Insight: 1.0.0, 1.1.0, 1.0.X, 1.X.X, 1.2.X, 1.2.2, 1.2.1, 1.2.0, 1.1.X, 1.1.1
Source
https://my.f5.com/manage/s/article/K000163325

Description

F5 Insight web UI may become unreachable after importing a certificate with a password-protected private key. The certificate import using f5insight-device-cert

utility can report success while displaying:

 

Warning: tls: failed to parse private key

 

Environment

  • F5 Insight
  • Device certificate managed with f5insight-device-cert
  • The private key being installed is protected with a passphrase.

 

Cause

The password-protected private key for F5 Insight is currently unsupported. PD has raised RFE ID2524393 for this.

 

Answer/Recommended Actions

Create a passwordless copy of the private key:

 

openssl rsa -in <password_protected_key_file> -out <passwordless_key_file>

 

Re-import the certificate chain and passwordless key:

 

sudo f5insight-device-cert import-cert \

--cert-file <certificate_chain_file> \

--cert-key <passwordless_key_file>

 

Additional Information

None.
