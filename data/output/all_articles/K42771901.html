Description

ASM Policy Builder is not learning Login Pages.

Environment

  • ASM policy configured with Learning enabled (Manual/Dynamic)
  • Login Pages are not learned

Cause

In order for ASM to learn login page:

  • Policy Building has to be configured correctly,
  • Response page should have 200 status,
  • Response page should contain "logout" string.

Recommended Actions

  1. Make sure your ASM policy is configured correctly to learn Login Pages automatically.
  2. If your application is responding differently, for example with status code 302, you have to configure Login Page manually.
Follow this guide to configure automatic/manual Login Page learning:
  • Manual Chapter: Creating Login Pages for Secure Application Access
