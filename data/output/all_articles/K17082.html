Known Issue

Virtual server connection rate limits may apply to clients that do not exceed the configured rate limit.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server to use Connection Rate Limit Mode.
  • The Connection Rate Limit Mode is set to Per Virtual Server and Source Address.
  • A specific client source IP address has reached the set connection rate limit.

Impact

New connections fail for clients that have not exceeded the virtual server connection rate limit.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • New connections fail for clients that have not exceeded the virtual server's configured connection rate limit.
