Topic

You should consider using this procedure under the following condition:

  • You want to upload files from your local workstation to a VELOS or rSeries system using the REST API.

Note: If you are looking for information on uploading files to the BIG-IP or BIG-IQ system using iControl REST, refer to the following articles:

  • K41763344: Using the iControl REST interface for file upload and download management
  • File Uploads of the F5 BIG-IQ API

Description

You can use the REST API to upload files (such as F5OS images or component packages, tenant images, F5OS configuration backup files) from your local workstation to a VELOS or rSeries system. The virtual path mapping for the different types of files on various systems are as follows:

Upload the following type of filesTo
VELOS chassis (F5OS-C)VELOS partition (F5OS-C)rSeries (F5OS-A)
F5OS-C/A images or component packagesimages/staging/Not applicableimages/staging/
BIG-IP tenant imagesNot applicableimages/images/tenant/
F5OS-C/A configuration backup filesconfigs/configs/configs/

 

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have administrative access to the management interface (REST API) of the VELOS or rSeries system.
  • If you have configured the Allowed IP Addresses feature on the VELOS system or the Allow List feature on the rSeries system, ensure that you have allowed your local workstation IP address to access port 8888 on the VELOS or rSeries system. For information on configuring these features, refer to K000138750: Configure the Allowed IP Addresses on the VELOS system or K000134482: Configure the Allow List on the F5 rSeries system.
  • Your local workstation should have the curl, grep, awk and tr utilities installed.
  • If you are planning to upload F5OS-C/A images or component packages or BIG-IP tenant images to the VELOS or rSeries system, you must download these files from MyF5 Downloads to your local workstation. For information on how to download from MyF5 Downloads, refer to K000090258: Download F5 products from MyF5. If you are planning to upload F5OS-C/A configuration backup files to the VELOS or rSeries system, you must have these files on your local workstation.

Procedures

  • Upload a file to the VELOS or rSeries system using REST API

Upload a file to the VELOS or rSeries system using REST API

To upload a file to the VELOS or rSeries system using REST API, you must get the authentication token from the system and use it to generate an upload-id before using the upload-id to upload the actual file to the system. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your local workstation with the curl, grep, awk and tr utilities installed
  2. Obtain the authentication token from the VELOS or rSeries system by entering the following command syntax:

    curl -fsSkI -u <username>:<password> -X GET "https://<mgmt IP>:8888/restconf" | grep -i 'x-auth-token' | awk -F: '{print $2}' | tr -d ' \r'

    Where

    • <username>:<password> is the username and password of the user with admin role on the VELOS chassis/partition or the rSeries system.
    • <mgmt IP> is the floating management IP address of the VELOS chassis, or the management IP address of the VELOS partition or the rSeries system.

    For example,

    curl -fsSkI -u admin:admin -X GET "https://192.168.86.35:8888/restconf" | grep -i 'x-auth-token' | awk -F: '{print $2}' | tr -d ' \r'

    You should observe an output similar to the following example:

    eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJTZXNzaW9uIElEIjoiYWRtaW4xNzEyMDI1MjI3IiwiYXV0aGluZm8iOiJhZG1pbiAxMDAwIDkwMDAgXC92YXJcL0Y1XC9zeXN0ZW0iLCJidWZmZXJ0aW1lbGltaXQiOiIzMDAiLCJleHAiOjE3MTIwMjYxMjcsImlhdCI6MTcxMjAyNTIyNywicmVuZXdsaW1pdCI6IjUiLCJ1c2VyaW5mbyI6ImFkbWluIDEwLjIwMS42MS4xNTkifQ.gtSe3L35FiAzCFKRGHZqo0Ksn_BikvPitjzuTtWEj5Q

  3. Initiate the file upload to the VELOS or rSeries system by entering the following command syntax:

    curl -k -L -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: <auth_token>" -X POST "https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/f5-file-upload-meta-data:upload/f5-file-upload-meta-data:start-upload" -d '{ "f5-file-upload-meta-data:file-path": "<destination_file_path>", "f5-file-upload-meta-data:name": "<filename>", "f5-file-upload-meta-data:size": <file_size> }'

    Where

    • <auth_token> is the authentication token you have obtained from the VELOS or rSeries system in the previous step.
    • <mgmt IP> is the floating management IP address of the VELOS chassis, or the management IP address of the VELOS partition or the rSeries system.
    • <destination_file_path> is the virtual path mapping on the VELOS chassis/partition or rSeries system you want to upload to. For more information, refer to the virtual path mapping table in the Description section on this article.
    • <filename> is the name of the file you want to upload to the VELOS chassis/partition or rSeries system.
    • <file_size> is the size of the file (in bytes) you want to upload to the VELOS chassis/partition or rSeries system.

    For example,

    curl -k -L -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJTZXNzaW9uIElEIjoiYWRtaW4xNzEyMDI1MjI3IiwiYXV0aGluZm8iOiJhZG1pbiAxMDAwIDkwMDAgXC92YXJcL0Y1XC9zeXN0ZW0iLCJidWZmZXJ0aW1lbGltaXQiOiIzMDAiLCJleHAiOjE3MTIwMjYxMjcsImlhdCI6MTcxMjAyNTIyNywicmVuZXdsaW1pdCI6IjUiLCJ1c2VyaW5mbyI6ImFkbWluIDEwLjIwMS42MS4xNTkifQ.gtSe3L35FiAzCFKRGHZqo0Ksn_BikvPitjzuTtWEj5Q" -X POST "https://192.168.86.35:8888/restconf/data/f5-utils-file-transfer:file/f5-file-upload-meta-data:upload/f5-file-upload-meta-data:start-upload" -d '{ "f5-file-upload-meta-data:file-path": "images/staging/", "f5-file-upload-meta-data:name": "optics-mgr-package-3.11.33.R5R10.img", "f5-file-upload-meta-data:size": 750080 }'

    You should observe an output similar to the following example:

    {
      "f5-file-upload-meta-data:output": {
        "upload-id": "UN9SmWAf"
      }
    }

  4. Start the file upload to the VELOS or rSeries system by entering the following command syntax:

    curl -k -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: <auth_token>" -H "File-Upload-Id: <upload_ID>" -X POST "https://<mgmt IP>:8888/restconf/data/openconfig-system:system/f5-image-upload:image/upload-image" --form "=@<filename>"

    Where

    • <auth_token> is the authentication token you have obtained from the VELOS or rSeries system in step 2.
    • <upload_ID> is the upload-id you have obtained from the VELOS or rSeries system in the previous step.
    • <mgmt IP> is the floating management IP address of the VELOS chassis, or the management IP address of the VELOS partition or the rSeries system.
    • <filename> is the name of the file you want to upload to the VELOS chassis/partition or rSeries system.

    For example,

    curl -k -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJTZXNzaW9uIElEIjoiYWRtaW4xNzEyMDI1MjI3IiwiYXV0aGluZm8iOiJhZG1pbiAxMDAwIDkwMDAgXC92YXJcL0Y1XC9zeXN0ZW0iLCJidWZmZXJ0aW1lbGltaXQiOiIzMDAiLCJleHAiOjE3MTIwMjYxMjcsImlhdCI6MTcxMjAyNTIyNywicmVuZXdsaW1pdCI6IjUiLCJ1c2VyaW5mbyI6ImFkbWluIDEwLjIwMS42MS4xNTkifQ.gtSe3L35FiAzCFKRGHZqo0Ksn_BikvPitjzuTtWEj5Q" -H "File-Upload-Id: UN9SmWAf" -X POST "https://192.168.86.35:8888/restconf/data/openconfig-system:system/f5-image-upload:image/upload-image" --form "=@optics-mgr-package-3.11.33.R5R10.img"

    When the upload is completed successfully, you should observe an output similar to the following example:

    { "result-tag": "uploaded-successfully" }

    If you are uploading a large file or expecting the upload speed to take some time, you can determine the status of the file upload by entering the following command syntax:

    Note: In order to avoid disrupting the file upload progress, you should use another terminal or another workstation to enter the following command syntax.

    curl -k -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: <auth_token>" -X GET "https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/f5-file-upload-meta-data:upload/f5-file-upload-meta-data:meta-data=<upload_ID>/f5-file-upload-meta-data:status"

    Where

    • <auth_token> is the authentication token you have obtained from the VELOS or rSeries system in step 2.
    • <mgmt IP> is the floating management IP address of the VELOS chassis, or the management IP address of the VELOS partition or the rSeries system.
    • <upload_ID> is the upload-id you have obtained from the VELOS or rSeries system in step 3.

    For example,

    curl -k -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJTZXNzaW9uIElEIjoiYWRtaW4xNzEyMDI1MjI3IiwiYXV0aGluZm8iOiJhZG1pbiAxMDAwIDkwMDAgXC92YXJcL0Y1XC9zeXN0ZW0iLCJidWZmZXJ0aW1lbGltaXQiOiIzMDAiLCJleHAiOjE3MTIwMjYxMjcsImlhdCI6MTcxMjAyNTIyNywicmVuZXdsaW1pdCI6IjUiLCJ1c2VyaW5mbyI6ImFkbWluIDEwLjIwMS42MS4xNTkifQ.gtSe3L35FiAzCFKRGHZqo0Ksn_BikvPitjzuTtWEj5Q" -X GET "https://192.168.86.35:8888/restconf/data/f5-utils-file-transfer:file/f5-file-upload-meta-data:upload/f5-file-upload-meta-data:meta-data=UN9SmWAf/f5-file-upload-meta-data:status"

    If the file upload is still in progress, you should observe an output similar to the following example:

    {
      "f5-file-upload-meta-data:status": "in-progress"
    }

    If the file upload has already completed, you should observe an output similar to the following example:

    {
      "ietf-restconf:errors": {
        "error": [
          {
            "error-type": "application",
            "error-tag": "invalid-value",
            "error-message": "uri keypath not found"
          }
        ]
      }
    }

  5. List the uploaded file in the destination file path by entering the following command syntax:

    curl -k -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: <auth_token>" -X POST "https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/list" -d '{ "path": "<destination_file_path>/<filename>" }'

    Where

    • <auth_token> is the authentication token you have obtained from the VELOS or rSeries system in step 2.
    • <mgmt IP> is the floating management IP address of the VELOS chassis, or the management IP address of the VELOS partition or the rSeries system.
    • <destination_file_path> is the virtual path mapping on the VELOS chassis/partition or rSeries system you have uploaded to in previous steps. For more information, refer to the virtual path mapping table in the Description section on this article.
    • <filename> is the name of the file you have uploaded to the VELOS chassis/partition or rSeries system.

    For example,

    curl -k -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJTZXNzaW9uIElEIjoiYWRtaW4xNzEyMDI1MjI3IiwiYXV0aGluZm8iOiJhZG1pbiAxMDAwIDkwMDAgXC92YXJcL0Y1XC9zeXN0ZW0iLCJidWZmZXJ0aW1lbGltaXQiOiIzMDAiLCJleHAiOjE3MTIwMjYxMjcsImlhdCI6MTcxMjAyNTIyNywicmVuZXdsaW1pdCI6IjUiLCJ1c2VyaW5mbyI6ImFkbWluIDEwLjIwMS42MS4xNTkifQ.gtSe3L35FiAzCFKRGHZqo0Ksn_BikvPitjzuTtWEj5Q" -X POST "https://192.168.86.35:8888/restconf/data/f5-utils-file-transfer:file/list" -d '{ "path": "images/staging/optics-mgr-package-3.11.33.R5R10.img" }'
