Topic

Except for the ARX 500 platform, ARX systems have two system disk drives. The two disk drives provide RAID Level 1 redundancy. These drives contain software images, reports, scripts, log files, and configuration files.

If one of the two system disk drives fails, you must manually rebuild the RAID configuration on the replacement drive.

Important: In the event of a hard drive failure, the replacement hard drive must meet specifications for each platform. When authorized by F5, you may replace a drive with a drive of larger capacity. The ARX system checks the drive geometry to ensure that the replaced drive meets or exceeds the specifications of the original remaining drive.

Note: If you replace a larger capacity drive with a lower capacity drive, the RAID rebuild process fails.

The model of the drives can be identified by the model number listed in the Disk Details section of the show chassis diskuse command output. The Disk Details section of the show chassis diskuse command displays output that appears similar to the following example:

 Disk Details:
 Disk       Size          State               Transfer Rate   Model
 --------   -----------   -----------------   -------------   -----------------
  Bay 1     68.36G        Online              320MB/sec       ST373455LC
  Bay 2     68.36G        Online              320MB/sec       ST373455LC

If an RMA replacement is required for a failed disk drive, you must provide F5 Technical Support the manufacturer and model number for the remaining drive.

Note: For information about removing and replacing a system drive, refer to the Removing and Replacing a Disk Drive section of the Hardware Installation Guide for your specific product.

After inserting the replacement drive, start the RAID rebuild process by performing the following procedure:

Note: If the ARX platform is part of a high-availability cluster, the ARX system should be the backup system when performing the RAID rebuild process.

  1. Log in to the ARX command line.
  2. Enable privileged mode by typing the following command:

    enable

  3. Start the RAID rebuild process by typing the following command syntax:

    raid rebuild <disk#>

    For example, to rebuild the RAID configuration for the disk in Bay 2, you would type the following command:

    raid rebuild disk2

  4. Display the RAID rebuild progress by typing the following command:

    show chassis diskuse

    The rebuild progress is displayed under the State column in the Disk Details section of the command output, which appears similar to the following example:

    Disk     Size        State             Transfer Rate Model
    -------- ----------- ----------------- ------------- -----------------
    Bay 1    68.50G     Online             320MB/sec     ATLAS10K5_73SCA
    Bay 2    68.50G     Rebuild 13 %       320MB/sec     ATLAS10K5_73SCA

    Note: The ARX RAID rebuild may take approximately 30 minutes.

  5. Verify that the RAID rebuild is complete by typing the following command:

    show chassis diskuse

    The RAID rebuild is complete when both drives are listed as Online under the State column in the Disk Details section of the command output, which appears similar to the following example:

    Disk     Size        State             Transfer Rate Model
    -------- ----------- ----------------- ------------- -----------------
    Bay 1    68.50G     Online             320MB/sec     ATLAS10K5_73SCA
    Bay 2    68.50G     Online             320MB/sec     ATLAS10K5_73SCA

Note: If the raid rebuild command fails, refer to K11523: Error Message: CLI-0-ERR-RAID_OPERATION_FAILED:: The raid rebuild command failed.
