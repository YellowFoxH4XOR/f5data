K54095560: Adding a BIG-IP device in BIG-IQ fails with 'unauthorized 401'

Type
Support Solution
Published
2021-12-29
Updated
2023-10-16
Applies to
  • BIG-IQ Platforms
  • BIG-IP
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K54095560

Description

When attempting to add a BIG-IP device in BIG-IQ using the BIG-IP admin user the error  'unauthorized 401'  is displayed in the Configuration utility (GUI).

An error similar to the following is logged to /var/log/restjavad.0.log at the time of the event:

Failed to connect to 10.10.10.10, check credentials: Unauthorized(401)

 

Environment

  • BIG-IP
  • BIG-IQ

 

Cause

Bug ID 1108181 or ID1146373

 

Recommended Actions

  1. Check whether username 'admin' is configured in BIG-IP device locally and able to login to the device.
  2. Check whether ports 443 and 22 are allowed from BIG-IQ to BIG-IP device and any firewall devices between the BIG-IP and BIG-IQ.
  3. Run the following commands from the command line of the BIG-IP device.

    clear-rest-storage
    bigstart restart restjavad

    Important: Do not run this command on devices that have SSLO provisioned and configured.
    Note:     During restart of restjavad service access to the Configuration utility will be temporarily interrupted.
     
  4. Add the BIG-IP device using 'admin' account in BIG-IQ.
    Note: Only use the admin account of the BIG-IP in BIG-IQ while adding BIG-IP device
