Policy Information

Summary

Common Criteria Certification for BIG-IP 11.5.1

Description

German Federal Office for Information Security (BSI) has certified BIG-IP ADC-AP 11.5.1 HF10 and ADF-Base 11.5.1 HF10 as Common Criteria EAL level 4+ certified. For more information about the Security Targets and related information, refer to the following BSI websites:

  • ADF-BASE: BSI-DSZ-CC-0856-2017
  • ADC-AP: BSI-DSZ-CC-0975-2018

Common Criteria is an international initiative to standardize security functionality and assurance measures. For more information about Common Criteria Certification, refer to the following Common Criteria website:

  • http://www.commoncriteriaportal.org

Note: This document, along with the Common Criteria Guidance Supplement, provides guidance on the secure installation and secure use of the Target of Evaluation (TOE) for the evaluated configuration. These documents provide clarifications and changes to the standard documentation and should be used as the guiding documents for the configuration and administration of the TOE in the Common Criteria evaluated configuration. Official product documentation should be referred to and followed only as directed within these guiding documents.

Installation

To install the BIG-IP system in accordance with the evaluation's expectations, refer to the following document in the document ISO:

  • Guidance Supplement: AGD_PRE and AGD_OPE

This document contains information to ensure that you have the correct software version of the BIG-IP system and describes how to configure that system to be Common Criteria-compliant.

Note that the installed system must include the engineering hotfix for CVE-2017-6164. Contact F5 Technical Support for access to that engineering hotfix: Hotfix-BIGIP-11.5.1.10.123.180-HF10-ENG.iso.

Product Documentation

The following ISO files contain the product and guidance documentation for the 11.5.1 Common Criteria evaluation:

  • CommonCriteriaDocumentation-11.5.1.iso – F5 Downloads
  • CommonCriteriaDocumentation-11.5.1.iso.sha256 – F5 Downloads

To verify the ISO file against the checksum, use the Linux sha256sum command with the –check option:

sha256sum –check CommonCriteriaDocumentation-11.5.1.iso.sha256
