K000139365: RHEL UBI8 docker image fails to install with error "This system is not registered with an entitlement server. You can use subscription-manager to register."

Description

  • RHEL UBI8 docker image fails to install with error "This system is not registered with an entitlement server. You can use subscription-manager to register."

Environment

  • RHEL being used for the BaseOS
  • Trying to deploy the Nginx docker RHEL UBI8 docker image

Cause

Red Hat Enterprise Linux restricts access to the repo codeready-builder-for-rhel-8-x86_64-rpms requiring an active RHEL subscription to access it.

Recommended Actions

  1. The customer's host is RHEL8 - if this is true then they need entitlement (a license) from RHEL before the RHEL UBI8 image will work due to a required repo being restricted by licensing.
  2. The customer's host OS is CentOS - if this is true then they can try the CentOS 7.4 Dockerfile example, NGINX App Protect WAF Administration Guide | NGINX Documentation.

Additional Information

Chapter 3. The CodeReady Linux Builder repository

"The CodeReady Linux Builder repository contains additional packages for use by developers. This repository is available with all Red Hat Enterprise Linux subscriptions....."
