Issue

When importing zones into NameSurfer, you may receive the following error:

No MIME boundry live found

This is error caused by the differences between Windows/DOS files and Unix files. It indicates that the end of the file was reached before finding an End line in MIME format. This causes NameSurfer to read the end of the file as the end of the data. The 3-DNS Controller is not reporting an actual failure.
