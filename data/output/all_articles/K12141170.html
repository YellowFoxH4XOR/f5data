Issue

Error Message

err tmm[<PID>]: 01230113:3: Unsupported media setting <Media/Duplex Setting> for interface <Interface Number>

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process.
  • <Media/Duplex Setting> is the current Media/Duplex setting  that does not match the physical interface supported media/duplex value.
  • <Interface Number> is the current interface that is reporting the mis-configured value.

For example:

err tmm[12113]: 01230113:3: Unsupported media setting 10000_T/full for interface 1.1

Message Location

You may encounter this message in the following locations:

  • The console
  • The /var/log/ltm file
  • The /var/log/tmm file

Description

This message occurs when the following condition is met:

  • A media setting for an interface such as speed or duplex does not match the type supported by the physical port.

Impact

The interface change does not occur. Normally, these settings are caught in configuration validation and F5 does not expect TMM to log them.

Recommended Actions

Check the configuration for the interface and select the interface from the available options.
