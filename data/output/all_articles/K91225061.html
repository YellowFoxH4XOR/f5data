K91225061: Management IP changes to 192.168.1.245, after loading a UCS with platform-migrate

Type
Support Solution
Published
2022-02-23
Updated
2023-02-08
Applies to
  • Virtual Editions
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K91225061
Description

Management IP may change to F5 default IP 192.168.1.245 when loading a UCS using 'platform-migrate'.

You may see log messages similar to the following:

<hostname> info install_ucs.pm[3374]: UCS installation success.
<hostname> info sod[7190]: 010c007b:6: Deleted unicast failover address <mgmt ip> port 1026 for device <hostname>.
<hostname> info sod[7190]: 010c007a:6: Added unicast failover address 192.168.1.245 port 1026 for device <hostname>.
<hostname> notice sod[7190]: 010c0078:5: Not listening for unicast failover packets on address <mgmt ip> port 1026.
<hostname> notice chmand[5304]: 012a0005:5: mgmtIpDel: deleting IP (<mgmt ip>/24), interface (mgmt)
<hostname> notice chmand[5304]: 012a0005:5: mgmtIpAdd: adding IP (192.168.1.245/24), interface (mgmt)


Environment

  • BIG-IP LTM VE
  • Version 14.1.2

Cause

At the time of loading the UCS, 'platform-migrate' option validates first if DHCP is enabled. If DHCP is enabled it will try to get a management IP via DHCP. When there is no DHCP offer, it defaults back to the F5 default IP, 192.168.1.245. This happens even if a static management IP is configured.

Recommended Actions

  1. Open the UCS file with a file archiver and edit the file /config/bigip_base.conf using a text editor.
  2. Locate the section sys global-settings and add mgmt-dhcp disabled to the settings.
sys global-settings {
    gui-setup disabled
    hostname bigip.local
    mgmt-dhcp disabled
}
  1. Save the changes and make sure the modified "bigip_base.conf" file of the UCS is updated.
  2. Load the updated UCS.
tmsh load sys ucs <filename> platform-migrate
Note: <filename> is the name of your modified UCS archive file.
