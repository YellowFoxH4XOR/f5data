Known Issue

This is the result of a known issue. The Configuration utility incorrectly reports that nodes that use a monitor rule are unchecked.

F5 Networks Product Development tracked this issue as CR34022 and CR41850.

Workaround

To work around this issue, use the bigpipe node command to view the current state of the nodes.
