Issue

Previously, the FirePass Windows standalone VPN client did not update its software components when the software on the FirePass controller was upgraded. After installing a hotfix or a new version of software on the FirePass controller, FirePass administrators needed to distribute the new version of the Windows standalone VPN client to users for manual installation.

Starting in FirePass 6.0.3, the Windows standalone VPN client automatically updates its software components when the software on the FirePass controller is upgraded.

Note: The optional DNS Relay Proxy client component is not automatically updated. For more information, refer to K9695: The DNS Relay Proxy client component is not automatically updated.

F5 Product Development tracked this enhancement as CR62912 and it was included in FirePass 6.0.3. For information about upgrading, refer to the FirePass Release Notes.
