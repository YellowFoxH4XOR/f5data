Topic

You should consider using this procedure under the following condition:

  • You want to install an OPSWAT Endpoint Security (EPSEC) update on a BIG-IP APM system.

Description

The BIG-IP APM Endpoint Security client-side checks use software libraries from a software development kit (SDK) created by OPSWAT, Inc. OPSWAT periodically issues new versions of the SDK libraries to support new security products and resolve bugs in the software. F5 distributes these updates in the form of an Endpoint Security (EPSEC) update ISO image file, such as epsec-1.0.0-]1000.0.iso. 

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have administrative access to the Configuration utility or the TMOS Shell (tmsh).

Important: Do not contact OPSWAT for support requests. OPSWAT works through vendors of security products to address issues with supported products or requests to add support for products. You should direct support requests to F5 for issues regarding the BIG-IP APM implementation of OPSWAT's SDK, and to the vendors of the security software for issues regarding their products' implementation of the SDK.

Procedures

  • Remove all old epsec packages from the system
  • Using the Configuration utility to install an OPSWAT EPSEC update
  • Using tmsh to install an OPSWAT EPSEC update

Remove all old epsec packages from the system

F5 recommends removing all previous epsec packages from the system. If you require them after removal, they are available for download at the F5 Downloads site. To remove a package, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to System > Software Management > Antivirus Check Updates.
  3. Select the name of the epsec package to remove.
  4. Select Delete.

    Note: In the System Package column, the epsec package currently in use has the value true and you cannot remove it. Delete is greyed out when you select the system package.

Using the Configuration utility to install an EPSEC update

To install an EPSEC update using the Configuration utility, perform the following procedure:

Note: Beginning in BIG-IP 14.1.0, EPSEC packages older than the pre-installed version cannot be installed.

Impact of procedure: Performing the following procedure should not have a negative impact on your system. However, the following procedure triggers a configuration synchronization (ConfigSync). To avoid an unexpected ConfigSync, you should perform a ConfigSync before performing the following procedure. For information, refer to K16119: Uploading an EPSEC OPSWAT ISO file may trigger a ConfigSync. Additionally, beginning in BIG-IP 12.1.0, you must perform the following procedure on an active system. For more information, refer to K03131331: The Upload Package and Install Package buttons for antivirus check EPSEC updates are disabled on standby systems.

  1. Download the EPSEC update ISO from the F5 Downloads site.

    Note: For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

  2. Log in to the Configuration utility.
  3. Go to System > Software Management > Antivirus Check Updates.
  4. Select Upload Package.
  5. Select Browse.
  6. Select the file you downloaded in step 1.
  7. For Install Option, select the appropriate installation option.

    Note: The Do not Install option uploads the EPSEC package without installing it.

  8. If you chose Install on Autosync enabled Device Group, for Device Group, select the device group.
  9. Select Upload.

    Note: The upload process may take a couple of minutes.

  10. After the software uploads, select OK.

The BIG-IP APM system is now running the updated EPSEC package. To confirm that the installation was successful, review the Installed Version field under the Device EPSEC Status tab.

Using tmsh to install an EPSEC update

Note: For BIG-IP 14.1.x, prior to attempting an install of a client side inspection package (EPSEC) from TMOS (tmsh), you must create the /Common/Install folder first.For more information refer to: K61214360: Error Message: 01070734:3: Configuration error: Invalid mcpd context, folder not found (/Common/EPSEC/Images).

To install an EPSEC Update using tmsh, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Download the EPSEC update ISO from the F5 Downloads site.

    Note: For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

  2. Copy the file you downloaded in step 1 to the BIG-IP /shared/apm/images folder.

    Note: Use a secure copy (SCP) utility to copy the file to the BIG-IP system.

  3. Log in to tmsh by entering the following command:

    tmsh

  4. Create a new package using the following command syntax:

    create /apm epsec epsec-package <package name> local-path <path/filename>

    In this command, note the following:

    • <package name> is the name the BIG-IP system uses to identify the package.

      Note: <package name> must start with epsec. When using the BIG-IP APM Configuration utility to install an EPSEC update, the system uses the file name as the package name.

    • <path/filename> is the path and name of the EPSEC file copied to the BIG-IP system in step 2.

    For example:

    create apm epsec epsec-package epsec-1.0.0-540.0.iso local-path /shared/apm/images/epsec-1.0.0-540.0.iso

  5. Install the new package you created in step 4 using the following command syntax:

    install /apm epsec epsec-package EPSEC/Upload/<package name>

    In this command, note the following:

    • <package name> is the name of the package you created in step 4.

    For example:

    install /apm epsec epsec-package EPSEC/Upload/epsec-1.0.0-540.0.iso

  6. You can validate the package installed by entering the following command:

    Note: It may take a few minutes for the following command to reflect that the package installation has completed.

    show /apm epsec software-status
