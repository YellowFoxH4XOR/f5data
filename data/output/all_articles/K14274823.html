Topic

This article discusses EPSEC OPSWAT software updates for BIG-IP versions that reach the End of Software Development (EoSD) phase of support.

Description

In accordance with the published F5 software life cycle policy, F5 no longer provides EPSEC OPSWAT updates for BIG-IP versions that have reached the EoSD phase. 

For more information, refer to K8986: F5 product support policies

Recommendations

Older software platforms may not detect newer versions of antivirus software correctly. F5 recommends that affected customers upgrade to a newer platform that is within the active software development phase of support.
