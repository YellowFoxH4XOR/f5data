Known Issue

This is the result of a known issue. The BIG-IP installer incorrectly permits a user to install version 9.x software on the 8950 (D107) or 11050 (E102) platforms. The installer allows the installation because it erroneously recognizes the platform code name that is written in the SMBIOS table.

Important: BIG-IP 9.x software does not support the BIG-IP 8950 or 11050 platforms, and installing 9.x software on the 8950 or 11050 platforms may result in a nonfunctional system.

F5 Product Development is tracking this issue as ID 225417 (formerly CR139347).
