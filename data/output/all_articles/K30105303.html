Description

 Tenant image corrupted - Update the tenant config with proper image...

On GUI of tenant details and command output of "show tenant", you will see the below status.


      INSTANCE                                                                                                                            CREATION  READY                                 MGMT
NODE  ID        PHASE                                                                   IMAGE NAME                                        TIME      TIME   STATUS                         MAC
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
1     1         Tenant image corrupted - Update the tenant config with proper image...  BIGIP-15.1.5-0.0.10.ALL-F5OS.qcow2.zip(1).bundle                   Retrying tenant deployment...  -

      INSTANCE                                                                                                                                    CREATION  READY                                                                               MGMT
NODE  ID        PHASE                                                                           IMAGE NAME                                        TIME      TIME   STATUS                                                                       MAC
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
1     1         Resource allocation failed - Blade is up but Partition services not responding  BIGIP-15.1.5-0.0.10.ALL-F5OS.qcow2.zip(1).bundle                   Tenant deployment will be processed when the partition services are running  -

Environment

  • Velos
  • rSeries
  • Tenant Deployment

Cause

  • Bug ID 1096885
Tenant image name has unsupported character.
e.g. brackets
 BIGIP-15.1.5-0.0.10.ALL-F5OS.qcow2.zip(1).bundle

Recommended Actions

rename the tenant image name with default one.
rSeries,
  1. Log in to CLI of appliance as root as we need to use bash.
    [root@appliance-1 ~]# cd /var/F5/system/IMAGES/
  2. Find the tenant image with ls command: [root@appliance-1 ~]# ls 
  3. Renane with mv command 
    e.g. 
    [root@appliance-1 ~]#  mv BIGIP-15.1.5-0.0.10.ALL-F5OS.qcow2.zip\(1\).bundle BIGIP-15.1.5-0.0.10.ALL-F5OS.qcow2.zip.bundle

Velos
  1. Log in to active controller CLI, and check which controller is active for the partition.
    syscon-2-active# show partitions   # <<<==== Controller side, controller 2 is active in this case (you can see the prompt it see "syscon-2-active")
                                                                                RUNNING
                           BLADE OS    SERVICE                 PARTITION        SERVICE     STATUS
    NAME               ID  VERSION     VERSION     CONTROLLER  STATUS           VERSION     AGE

    ------------------------------------------------------------------------------------------------
    MyPartition        1   1.3.1-5968  1.3.1-5968  1           running-active   1.3.1-5968  15d   # <<<------ In this partition, Controller 1 is active.
                                                   2           running-standby  1.3.1-5968  15d
    none               0   -           -           1           disabled         -           -
                                                   2           disabled         -           -
     
  2. Log in to CLI of Partition's running-active Controller (in above example controller 1 as the "partition status" says "running-active")\

    or Log in to CLI of floating IP as root and then ssh to Controller which is running-active status in the partition. 
    In the above case, controller 1 is in running-active status for MyPartition, so
    [root@Controller-2 ~]# ssh Controller-1
    [root@Controller-1 ~]#
     
  3. Check above output's ID column and use it in <ID> below
    [root@Controller-1 ~]# cd /var/F5/partition<ID>/IMAGES 

    in the above case, MyPartition has 1 in ID columns
    [root@Controller-1 ~]# cd /var/F5/partition1/IMAGES 
     
  4. Use mv command to rename the file
    e.g. 
    [root@Controller-1 ~]#  mv BIGIP-15.1.5-0.0.10.ALL-F5OS.qcow2.zip\(1\).bundle BIGIP-15.1.5-0.0.10.ALL-F5OS.qcow2.zip.bundle
     
  5. then run "ls" command and make sure the file name does not have any space nor brackets (e.g. "(",")" etc)
     
  6. Delete the tenants and recreate.
