Topic

By default, FirePass enables Network Access Port Translation (NAPT) for Network Accession connections. If you use NAPT, all packets forwarded to the LAN appear to have the FirePass controller interface as their source IP address. The advantage of NAPT is that it requires no changes to the LAN, whereas using virtual subnets requires routing changes on the corporate network.

Note: For more information about NAPT and virtual subnets, refer to K8112: Network-layer routing considerations when using Network Access.

Note: You can enable or disable NAPT on the Network Access > Global Settings page in the FirePass Administrative Console.

NAPT translates the source IP address of the client to the IP address of the FirePass controller. Additionally, if the client’s packet contains a source port that is already in use by another active connection, FirePass translates the source port to another source port not currently in use. NAPT does not translate all other TCP/IP headers, such as the destination IP address and destination port.
