Known Issue

Session variable values of access sessions may be truncated or missing.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an access profile that actively processes traffic.
  • A session variable of the access session exceeds1024 bytes.

Impact

The system does not correctly display the session variable in BIG-IP APM logs and reports.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view BIG-IP APM logs or reports, session variables that are greater than 1024 bytes are truncated.
  • When you view BIG-IP APM reports session variables that are greater than 4060 bytes, the system displays no session variable data.
