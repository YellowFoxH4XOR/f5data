Known Issue

If you attempt to initialize an access session using the command line utility f5fpc.exe, your attempt may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP Edge Client application software is installed on a device running the Windows operating system.
  • The BIG-IP Edge Client application is running in the disconnected state.
  • You attempt to establish an access session using the command line utility f5fpc.exe.

Impact

The f5fpc.exe command does not respond.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you run the f5fpc.exe command line utility, the idle or disconnected BIG-IP Edge Client application is brought forward, but the access session connection never initializes.
  • When the BIG-IP Edge Client application is not running, the f5fpc.exe command line utility successfully initializes an access session.

Workaround

To work around this issue, you can ensure that the BIG-IP Edge Client application is not running before you use the f5fpc.exe command line utility. 

Impact of workaround:  Performing the suggested workaround should not have a negative impact on your system.
