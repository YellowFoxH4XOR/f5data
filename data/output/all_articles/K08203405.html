Description

In BIG-IP 13.1.4 and BIG-IQ 8.0.0 a new configuration is introduced, sigkillDelaySeconds is the delay to wait before the system sends a SIGKILL to a icrd_child process if the process is not terminated after a SIGTERM was first issued. Under certain scenarios, you may want to change the default value of sigkillDelaySeconds from ‘0’ to a non zero value. To change the default value of sigkillDelaySeconds, you may follow below mentioned steps.

Environment

  • BIG-IP 13.1.4
  • BIG-IQ 8.0.0
  • icrd

Cause

None

Recommended Actions

Procedures

You must meet the following prerequisite[s] to use this procedure:

  • You have at least admin privileges.
  • BIG-IP version is 13.1.4 and above.
  • BIG-IQ version is 8.0.0 and above

Steps to follow:

  1. Login to BIG-IP or BIG-IQ command line.
  2. If you are in tmos mode then type below mentioned command to enter the bash shell.

    bash
    or
    run util bash

  3. Using a text editor of your choice, edit the /etc/icrd.conf file.
  4. In the "options" : { } section, modify the value of sigkillDelaySeconds to 3 as follows:"sigkillDelaySeconds" : 3

    Note: A 'safe' number for the delay may be 3 seconds, but you may change it as per your configuration requirement.

  5. Save and quit the file. Open  /etc/icrd.conf  one more time to verify the changes.
  6. Restart the restjavad service by typing the following command

    tmsh restart /sys service restjavad

Note: Restarting the restjavad process impacts the control plane and the system will not be able to process REST API requests.

Note: By default, a new user account with the Administrator role in the BIG-IQ system does not have access to bash or tmsh. For more information, refer to K16413: Enabling Advanced Shell or tmsh access for BIG-IQ user accounts.
