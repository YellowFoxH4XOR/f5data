Known Issue

BIG-IP APM Edge Client auto-update fails on macOS 15.0 (Sequoia).  The ~/Library/Logs/F5Networks/edge.log may indicate that the update is successful incorrectly. BIG-IP Edge Client version update process is not successful. The issue does not impact VPN.app and EPI.app updates.

This issue occurs when all of the following conditions are met:

  • The client device is running macOS 15.0.
  • You configure the BIG-IP Edge Client to auto-update when it connects to the BIG-IP APM.

Impact

BIG-IP Edge Client does not auto-update. This issue does not apply when you connect using the web browser client and endpoint inspection.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you launch BIG-IP Edge Client, the version is not updated as expected.

Fix Information

To fix this issue, you must install fixed versions on both the BIG-IP APM system as well as the BIG-IP Edge Client. For example, you must install either 17.5.0 or the Engineering hotfix containing the fix for your branch on your BIG-IP APM system, and you must also install APM Clients 7.2.5.1 or later. To do so, perform the following procedures based on your macOS version as appropriate:

  • macOS 14 and earlier
    1. Update both APM Client and BIG-IP APM system to versions listed in the Fixes introduced in column. For more information about upgrading the BIG-IP APM system and APM Client, refer to K84205182: Guide contents | BIG-IP update and upgrade guide and K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system.
    2. Configure BIG-IP APM to auto update BIG-IP Edge Clients. To do so, perform the procedure Configure Component Update in the connectivity profile of the virtual server in K81649656: Overview of APM Clients update on BIG-IP APM.

  • macOS 15 and later:
    1. Update both APM Client and BIG-IP APM system to versions listed in the Fixes introduced in column. For more information about upgrading the BIG-IP APM system and APM Client, refer to K84205182: Guide contents | BIG-IP update and upgrade guide and K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system.
    2. Uninstall and install BIG-IP Edge Client on the MAC client.*
      For more information on installing BIG-IP Edge Client, refer to the Deploy and install the required VPN software packages on VPN users’ client system procedure in K81649656: Overview of APM Clients update on BIG-IP APM.

      *On macOS 15, BIG-IP Edge Client auto updates work from only 7251 to future versions.
