K000152495: What does "Allowed Sources" Service Policy do?

Type
Support Solution
Published
2025-07-09
Updated
2025-07-09
Applies to

  • F5 Distributed Cloud WAF
Source

Description

  • What does "Allowed Sources" Service Policy do?
  • Does "Allowed Sources" Service Policy exempt a matched client from WAF?

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer
  • Service Policy
  • XC Console

Resolution/Answer

No, "Allowed Sources" Service Policy does not exempt a matched client from WAF. It exempts the client only from Service Policy blocking, not any other possible blocking, including WAF, malicious user mitigation, etc.


In other words, if a client IP matches an "Allowed Sources" Service Policy, then they will not get blocked by a service policy, but they could still get blocked by WAF, malicious user mitigation, etc. To prevent the client from getting blocked by these other services, create a trusted client rule on the LB and select Skip WAF, Skip Bot Defense, etc. as desired.
