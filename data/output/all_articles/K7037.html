Topic

You should use the BIG-IP Setup utility for initial setup configurations, and use the Configuration utility to make additional changes to the BIG-IP system configuration.

Note: The Basic Network Configuration section of the Setup utility creates an internal and an external default Virtual Local Area Network (VLAN). If your BIG-IP system has existing internal and external VLANs containing advanced configurations, and you plan to re-run the Setup utility, refer to K7038: Error Message: VLAN <vlan_name> has a configuration that is not supported by the Setup utility.

The Setup utility allows you to configure the following elements:

  • License properties
  • Module provisioning
  • Device certificate
  • Management interface settings such as the IP address, netmask, and default gateway
  • Host IP address
  • Time zone settings
  • User account settings, such as the root and administrative passwords
  • Support access
  • SSH access
  • Basic network configuration
  • High-availability settings

To run the Setup utility, perform the following procedure:

14.1.x and later

  1. Log in to the Configuration utility.
  2. Click the F5 logo in the upper-left corner of the page or click the About tab.
  3. Navigate to the Setup Utility section of the Welcome page or the About tab.
  4. Click Run the Setup Utility.
    For detailed Setup Utility prerequisites and steps refer to the Introduction to BIG-IP Initial Configuration chapter of the BIG-IP System: Initial Configuration manual (14.1.0 - 21.1.x).

Note: For information about performing initial setup for the BIG-IP system from the command line, refer to K13369: Performing a first-time configuration from the command line (11.x - 16.x).
