K000160521: Unintended Assignment of Common VLANs to Non-Common Route Domains via VLAN-Groups

Type

Published

Updated

Applies to

Description

When creating a VLAN-group in a non-Common partition and adding VLANs from the Common partition as members, the BIG-IP system allows these Common VLANs to be assigned to a route domain in the non-Common partition via the VLAN-group. 

This behavior bypasses the expected validation, which normally prevents direct assignment of Common VLANs to route domains in other partitions. 

As a result, Common VLANs can become associated with non-Common route domains, and may be difficult to remove through the GUI or CLI.

 

 

Environment

BIG-IP

VLAN Groups

Route Domain

 

 

Cause

The system enforces validation to prevent direct assignment of a VLAN from the Common partition to a route domain in a non-Common partition. 

However, when a VLAN-group is created in a non-Common partition and Common VLANs are added as members, this validation is not applied. 

This allows the configuration to proceed, resulting in Common VLANs being assigned to a non-Common route domain, which is not supported and may lead to configuration inconsistencies.

 

 

Recommended Actions

Avoid assigning Common VLANs to VLAN-groups in non-Common partitions if those VLAN-groups will be used in non-Common route domains.

 

If this configuration already exists:

  • Remove the VLAN-group from the route domain using the CLI (tmsh). This cannot be removed via the GUI.
  • manually remove the individual Common VLANs from the route domain. TMSH or GUI will work.

 

A fix for this issue is being tracked under ID2259001.

 

Additional Information

  • If you delete a VLAN-group from the system, the VLAN-group members remain assigned to the route domain. You must remove them individually.
  • Attempting to add a Common VLAN directly to a non-Common route domain will result in an error:

           General error: 01070726:3: Route domain /<Partition_Name>/<Route_Domain_name> can only reference (VLAN) /Common/<VLAN_Name> in the same partition or if the route domain is in the Common partition in statement [SET TRANSACTION END]
