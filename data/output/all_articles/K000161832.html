K000161832: Header Information missing in request/response log - x-volterra-truncated-hdr: true

Description

Logged requests sometimes have missing request headers.

Environment

XC Loadbalancer
XC Console logs
Logs forwarded to GLR destination - SIEM

Cause

Known limit on header length when headers size exceed 2KB for HTTP request and 1KB for HTTP response.

This is limiting information for logging and is setting flag: x-volterra-truncated-hdr: true

Answer/Recommended Actions

  • This is hard limit without workaround. Consider additional logging on origin server [backend application server].
  • x-volterra-truncated-hdr is set purely in the logs and is not passed in the request headers to upstream or response headers to the downstream client.
