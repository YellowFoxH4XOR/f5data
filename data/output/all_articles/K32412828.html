K32412828: APM cannot grant kerberos ticket to the user

Type
Support Solution
Published
2021-11-30
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.2
Source
https://my.f5.com/manage/s/article/K32412828

Description
Kerberos authentication has failed for the outlook clients and users that are impacted are not able to access the mail boxes
In the var/log/apm:
Kerberos: can't get S4U2Proxy ticket for server <SERVERNAME> - Message stream modified (-1765328343)
 

Environment

  • After a Windows Security Update
  • Kerberos

Cause
November security updates, released November 9, 2021 on your Domain Controllers (DC) running a Windows Server.

Authentication might fail on DCs with certain Kerberos delegation scenarios

Recommended Actions

Install updates on the DC's: Microsoft Update Catalog > Search results for "KB5008601"

Additional Information
None
