Issue

Error Message

warning mcpd[PID]: 010712e9:4: <db_variable> is not in BigDB.dat.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <db_variable> is the name of the database variable.

For example:

warning mcpd[9872]: 010712e9:4: log.pktclass.level is not in BigDB.dat.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You perform a software upgrade or clean install on the BIG-IP system.
  • You load the configuration on the system or synchronize the configuration to the system by performing a configuration synchronization (ConfigSync).
  • The configuration references a database variable that is no longer present in the software version currently running on the upgraded BIG-IP system.

Impact

This error message is usually benign. If the database variable was in use, you can contact F5 Technical Support to verify any potential impact.

To prevent system from generating the messages, you can force the mcpd process to reload the configuration. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure disrupts traffic processing and should be performed during a maintenance window.

Recommended Actions

To prevent system from generating the messages, you can force the mcpd process to reload the configuration.
If the error messages are seen following a ConfigSync from a peer device, then this procedure should be run on the device that initiated the ConfigSync.

To clear the messages, perform the following procedure:

Impact of procedure: Performing the following procedure disrupts traffic processing and should be performed during a maintenance window.

  1. Log in to the Advanced Shell (bash).
  2. Force the mcpd process to reload the configuration on restart by adding a file named forceload in the /service/mcpd/ directory by typing the following command:

    touch /service/mcpd/forceload

    On VIPRION systems, run the command on all blades by typing the following command:

    clsh touch /service/mcpd/forceload

  3. Stop services by typing the following command:

    bigstart stop

  4. Move the BigDB.dat file to the /shared/tmp/ directory by typing the following command:

    mv /config/BigDB.dat /shared/tmp

  5. Restart the system using the following command:

    reboot
