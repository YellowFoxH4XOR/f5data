Description

When APM is integrated with Endpoint Management system, we may need to list the UDID from MDM system, it might be required for troubleshooting.

Environment

  • BIG-IP APM
  • MDM
  • F5 Access
  • Endpoint

Cause

None

Recommended Actions

Please follow the steps below to list the device ID in the mysql database, they are from the MDM system.

  1. Please SSH to the BIG-IP, bash mode. It is better to login the root account.
  2. In bash mode, run the command below:

# /usr/libexec/mdmsyncmgr -c aw -o query -q "select * from mdm_device"

The command above will print the device id, for example:

# /usr/libexec/mdmsyncmgr -c aw w -o query -q "select * from mdm_device"
