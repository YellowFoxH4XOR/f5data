Issue

Error Message

info alertd[<PID>]: 01100049:6: logcheck Info: <message> <value>

In this error message, note the following:

  • <PID> is the process ID for the alertd process.
  • <message> is an informational message.
  • <value> is a numerical value associated with the message.

For example:

info alertd[7347]: 01100049:6: logcheck Info: /var/log disk avail 6661596

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The alertd process reports the amount of free disk space in the /var/log/ directory.
  • Old compressed log files are deleted from the BIG-IP system to increase the amount of free disk space.
  • The alertd process reports the current value for a database variable.

Impact

There is no impact. The messages are informational but could indicate a low amount of free disk space or the deletion of old compressed files.

Recommended Actions

If the message indicates that old compressed files are deleted from the BIG-IP system, or that a low amount of free disk space exists, consider deleting any unused or unnecessary files to free up disk space.
