K000140049: How to undeploy Access Guided Configuration that stuck with ''Undeploying'' state

Type
Support Solution
Published
2025-04-09
Updated
2025-04-09
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000140049

Description

User does not want to completely remove the configured application, but keep it on 'Not deployed' state. When user tries to undeploy the application Access Guided Configuration process might get stuck with ''Undeploying'' state.

 Environment

  • BIG-IP APM
  • Advanced Guided Configuration

 Cause

There might be undesired configuration objects in 'Unbinding' state present on the system.

 Recommended Actions

1) Obtain the blocks ID's and verify its state by running the command:

# restcurl -X GET /shared/iapp/blocks?$filter=name+eq+'<Guided_Configuration_application_name>' 

For example, when the config name is ACG-Exch16 the output can look as follows:

# restcurl -X GET /shared/iapp/blocks%3F%24filter%3Dname+eq+%27ACG-Exch16%27

"id": "68f222b3-4033-4335-94ef-8b7514f9ef25",
"name": "ACG-Exch16",
"state": "UNBINDING",

2) Set affected block ID's into 'Unbound' state using the command below:

restcurl -X PATCH -d '{"state" : "UNBOUND"}' /shared/iapp/blocks/<affected_block_ID>

3) Verify under Access  ››  Guided Configuration, whether the application has correctly changed its status to 'Not deployed'

 Additional Information

If the user wants to completely remove the application please follow the workaround described in Bug ID 723642: AGC creates configuration cannot be deployed, undeployed, or deleted.
