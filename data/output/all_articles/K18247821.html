Description

On a BIG-IP system configured with remote LDAP/Active Directory authentication, attempting to login to the Configuration Utility or to the command-line interface may proceed very slowly or fail.

log messages in /var/log/secure file has some of similar to the below: 
error reading from nslcd: Timer expired
error opening connection to nslcd: Connection refused
err nslcd[<PID>]: [e8944a] <authc="palabh"> ldap_result() timed out
info kernel: nslcd[<PID>]: segfault at 6d ip 00002b01d9d227b8 sp 00002b01dd04bf60 error 4 in libsasl2.so.3.0.0[2b01d9d17000+1c000]
notice systemd[<PID>]: nslcd.service: main process exited, code=killed, status=11/SEGV
notice systemd[<PID>]: Unit nslcd.service entered failed state.
warning systemd[<PID>]: nslcd.service failed.
 

Environment

  • BIG-IP
  • v14.1.0 - 14.1.2.2, 15.0.0-15.0.1
  • LDAP or Active Directory authentication for GUI/CLI
     

Cause

Bug ID 806093

Recommended Actions

Disable LDAP or Active Directory referrals.  For information about the workaround and/or fixed versions, refer to the Bug Tracker article Bug ID 806093

The Bug Tracker article provides a method for disabling LDAP or Active Directory referrals.

An alternative method for disabling LDAP or Active Directory referrals on versions up to 15.0.1.x,  is to run the following commands:

tmsh modify sys db systemauth.referrals value no && tmsh save sys config && tmsh load sys config


For information on disabling LDAP referrals on version 15.1.0 and later see AskF5 article:
K17311: Globally disable LDAP referrals for the BIG-IP system
