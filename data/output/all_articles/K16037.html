Known Issue

Suspended DNS_RESPONSE events are not resumed.

This issue occurs when all of the following conditions are met:

  • Your wide IP configuration references an iRule that uses the DNS_RESPONSE event.
  • The iRule uses a command that suspends the DNS_RESPONSE event. For more information regarding suspending commands, refer to K12962: Some iRule commands temporarily suspend iRule processing.

Impact

Some client Domain Name System (DNS) queries will fail to resolve.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Some client DNS queries fail to resolve.

Workaround

To work around this issue, you can avoid using iRule commands that suspend events in the DNS_RESPONSE event.
