Description

You want to be able to upload .pfx files completely using the rest API and be able to control the name of certificate after it is loaded and don't know how to do this.

 

Environment

Uploading a .pfx file to the BIG-IP and installing the certificate.

 

Cause

Vague documentation on how to upload and load a .pfx certificate file strictly using the Rest API.

 

Recommended Actions

Uploading the certificate file:

As referenced in this article: Using the iControl REST interface for file upload and download management 

@my_local_cert.pfx is the name of the certificate in the current working directory that will be uploaded.

Example: @my_updated_certificate.pfx

This will be uploaded to a temporary directory on the BIG-IP that we can later install from.

curl -o /dev/null -sku $user:$pwd POST https://10.155.103.196/mgmt/shared/file-transfer/uploads/uploaded.pfx -H 'Content-Type: application/octet-stream' -H 'Content-Range: 0-2818/2819' -H 'Connection: Close' --data-binary @my_local_cert.pfx

Example:

 curl -o /dev/null -sku admin:admin POST https://10.155.103.196/mgmt/shared/file-transfer/uploads/uploaded.pfx -H 'Content-Type: application/octet-stream' -H 'Content-Range: 0-2818/2819' -H 'Connection: Close' --data-binary @working_directory_local_file_to_upload.pfx

 
Response:
{"remainingByteCount":0,"usedChunks":{"0":2819},"totalByteCount":2819,"localFilePath":"/var/config/rest/downloads/uploaded.pfx","temporaryFilePath":"/var/config/rest/downloads/tmp/uploaded.pfx","generation":0,"lastUpdateMicros":1722492019909345}

 

Installing the certificate file:

[root@ltm-lab-bigip1:Standby:In Sync] tmp # curl -sku $user:$pwd -H "Content-Type: application/json" -X POST https://10.155.103.196/mgmt/tm/sys/crypto/pkcs12 -d '{"command":"install","name":"kevincerttest","consumer":"ltm","fromLocalFile":"/tmp/uploaded.pfx","passphrase":"Password_For_PFX_File"}'
