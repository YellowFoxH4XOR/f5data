K000151858: BIG-IP DNS big3d daemon consuming large amounts of CPU resources

Type
Support Solution
Published
2025-06-25
Updated
2025-06-25
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.1.4
Source
https://my.f5.com/manage/s/article/K000151858

Description

BIG-IP DNS systems with large number of HTTPS monitors with Server Name Indication (SNI) can cause big3d to consume additional CPU resources restricting the number of https monitors that a DNS system can support. 

 

Environment

  • BIG-IP DNS 
  • HTTPS Monitor using SNI

 

Cause

Large amouont of HTTPS monitors using SNI can cause big3d to consume additional CPU resources, because of big3d being forced to renegotiating the Transport Layer Security (TLS) with the pool member being monitored.  F5 has filed ID1953273 to address this issue.

 

Recommended Actions

Upgrade to a version that has ID1953273 fixed
