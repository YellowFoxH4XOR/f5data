Description

On VIPRION, when using GRUB menu you booted from a boot location other than the default set in BIG-IP, it will reboot back to the default boot location. 

Environment

  • VIPRION/VELOS

  • Guests running on VIPRION/VELOS 

Cause

Boot location is set in /shared/db/cluster.conf and clusterd picks the setting out and reboots automatically from the default boot location by design. This behavior applies to both multi-bladed or single bladed configuration, as long as it is a VIPRION/VELOS or a guest running within.

Recommended Actions

Follow K9296: Changing the default boot image location on VIPRION platforms
