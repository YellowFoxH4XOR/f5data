K9008: The BIG-IP WebAccelerator virtual server requests are translated to HTTP/1.0

Topic

Beginning in BIG-IP WebAccelerator version 9.4.2, the http-acceleration profile is used by default for virtual servers that are enabled for WebAccelerator. The http-acceleration profile uses the BIG-IP LTM RAM Cache. The BIG-IP LTM RAM Cache translates all HTTP requests to HTTP/1.0. Therefore, the origin web server must be configured to allow both HTTP/1.0 and HTTP/1.1 requests. Alternatively, you can use an HTTP profile that does not have LTM RAM Cache enabled, such as the default http profile or a custom http profile. However, this approach is not recommended as it will result in more requests being served from the less efficient Smart Cache.

Note: LTM RAM Cache is referred to as Hot Cache in BIG-IP WebAccelerator documentation.
