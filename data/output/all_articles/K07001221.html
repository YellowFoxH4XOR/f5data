Description

You can use this F5 supported iApp template to log messages from the BIG-IP system into specific cloud analytics solutions such as Azure OMS, AWS S3, and AWS Cloudwatch.

Support Matrix

For information about BIG-IP releases that support the various versions of this iApp template, refer to the following table.

f5.cloud_logger.v1.0.012.1.x - 14.x12.0.0 and earlier

To download and install the iApp template, perform the following procedures

  • Downloading the iApp template
  • Installing the iApp template

Downloading the iApp template

Important: You must download the file; do not copy and paste the contents.

  1. Go to the F5 Cloud iApps page on Github. 

    Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge

  2. Click Clone or Download.
  3. Click Download ZIP.

Installing the iApp template

  1. Unzip the zip file to a location accessible from your BIG-IP system.
  2. Log in to the Configuration utility.
  3. On the iApp tab, click Templates.
  4. Click Import.
  5. Select the Overwrite Existing Templates check box.
  6. Click Browse.
  7. Browse to the location where you save the iApp file.
  8. Select the template file that corresponds to the iApp versions you want to install, For example, the file for the January 2019 release of this iApp is named f5.cloud_logger.v1.0.0.tmpl.

    Note: Refer to the previously mentioned Support Matrix to select the must current supported template for you BIG-IP software version.

  9. Click Upload.

When the upload completes, the iApp is available for use.
