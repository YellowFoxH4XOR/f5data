Description

Local account can not be used when TACACS+ Authentication is enabled after RMA.
ssh login is not avaiable, GUI access is available.

Environment

  • F5OS 1.X.X
  • TACACS+ Authentication is configured

Cause

TACACS+ server secret is corrupted after primary key is configured.

Local user authentication fails, if remote TACACS+ servers is unavailable.

The issue is tracked by Bug ID 1635497

Recommended Actions

  • Reconfigure TACACS+ server secret.
  • Do not include space in the tacacs server group name.
    If the name contains a space in the tacacs server group name, Rename the tacacs server group name without a space.
    For example,
    "tacacs servers" to "tacacs_servers"
