K000138079: SNMP OID "F5-BIGIP-LOCAL-MIB::ltmVirtualServVaName" does not display a STRING value if the virtual server uses an address-list or a port-list.

Type
Support Solution
Published
2023-12-29
Updated
2024-02-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000138079

Description

You may encounter that SNMP OID of F5-BIGIP-LOCAL-MIB::ltmVirtualServVaName (1.3.6.1.4.1.3375.2.2.10.1.2.1.29) does not display a STRING value if the virtual server uses an address-list or a port-list.

Sample of Configuration:

ltm virtual VS_B {
    traffic-matching-criteria VS_B_VS_TMC_OBJ
}
ltm virtual VS_C {
    traffic-matching-criteria VS_C_VS_TMC_OBJ
}
ltm traffic-matching-criteria VS_B_VS_TMC_OBJ {
    destination-address-inline 0.0.0.0
    destination-address-list ADDRESS_LIST_A
    protocol tcp
    source-address-inline 0.0.0.0
}
ltm traffic-matching-criteria VS_C_VS_TMC_OBJ {
    destination-address-inline 10.105.45.189
    destination-port-list PORT_LIST_A
    protocol tcp
    source-address-inline 0.0.0.0
}
net address-list ADDRESS_LIST_A {
    addresses {
        1.2.3.4 { }
        5.6.7.8 { }
    }
}
net port-list PORT_LIST_A {
    ports {
        54321 { }
        italk { }
    }
}


The output when running the snmpwalk command:

config # snmpwalk -v 2c -c public localhost 1.3.6.1.4.1.3375.2.2.10.1.2.1.29
F5-BIGIP-LOCAL-MIB::ltmVirtualServVaName."/Common/VS_B" = STRING:
F5-BIGIP-LOCAL-MIB::ltmVirtualServVaName."/Common/VS_C" = STRING:

Environment

  • Virtual Server
  • address-list
  • port-list

Cause

This is expected behavior that SNMP OID of F5-BIGIP-LOCAL-MIB::ltmVirtualServVaName (1.3.6.1.4.1.3375.2.2.10.1.2.1.29) does not display a STRING value if the virtual server uses an address-list or a port-list.
