Description

Uploading file with an HTTP/2 profile takes ~3 times longer than HTTP/1.1.

For example, given that a client takes about 6.6 seconds to upload a 1 GB file via HTTP/1.1, it takes about 19.4 seconds via HTTP/2.

Environment

  • The virtual server has an HTTP/2 profile
  • The client sends a file by using POST.

Cause

This is a current limitation of the HTTP/2 profile.

Recommended Actions

  • You can increase the Receive Window in the HTTP/2 profile and test upload throughput with different values. The maximum value is 1024.

    ltm profile http2 my_http2 {
        app-service none
        defaults-from http2
        receive-window 128
    }

    The uploading file with an HTTP/2 profile may still take ~2 times more time than HTTP/1.1.
     
  • There is a Request For Enhancement (RFE) submitted to F5 Product Development to improve this performance in the future release.
