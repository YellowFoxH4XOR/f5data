K7952: Dynamic App Tunnels do not support the Microsoft Windows net use command

Topic

If you want to configure an Application Tunnel (App Tunnel) which runs the Microsoft Windows net use command, you need to configure a Static App Tunnel. Dynamic App Tunnels do not support the Microsoft Windows net use command.

Note: For information about configuring a Static App Tunnel with the net use command, refer to K9750: Configuring an Application Tunnel to map a network drive.

Dynamic App Tunnels were introduced in FirePass version 6.0.0, and they allow you to support applications which require dynamic IP addresses and ports. When you configure a Dynamic App Tunnel, you enter the path to an application on the client system instead of entering local and remote IP addresses and ports. When a user launches a Dynamic App Tunnel, all TCP/IP traffic from the specified application on the client system will be tunneled through the FirePass controller.

The Windows net use command communicates directly with the Windows kernel through a system call, instructing Windows to connect to or disconnect from a shared resource, such as a network drive. Once the system call has completed, net use closes. Since the net use command communicates through a direct system call instead of through TCP/IP, there is no network traffic for the Dynamic AppTunnel to intercept.

Note: For more information about the net use command, refer to Microsoft Windows documentation.

Note: For more information about configuring Static AppTunnels, refer to the FirePass Controller Administrator Guide.
