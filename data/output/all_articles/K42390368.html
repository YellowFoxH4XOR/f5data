Issue

Error Message

01070734:3: Configuration error: Invalid mcpd context, folder not found (<folder>)

In this error message, note the following:

  • <folder> is the path and folder name that was not created.

For example:

01070734:3: Configuration error: Invalid mcpd context, folder not found (/Common/tenant_1-app_2.app)

Message Location

You may encounter this message on the target device in the following location:

  • The /var/tmp/scriptd.out file

Description

This message occurs when the following condition is met:

  • You deploy any version of the Application Services Integration iApp on supported versions of BIG-IP and iWorkflow.

There is a known issue caused by race a condition in the TMOS control plane on the BIG-IP system. This issue occurs intermittently when deploying any version of the Application Services Integration iApp on supported versions of BIG-IP and iWorkflow.

Impact

When such a failure occurs and an application service object (ASO) remains in this state, subsequent creations of additional ASOs are likely to fail.

Recommended Actions

Redeploy the ASO that failed before deploying additional ASOs. You can use the deploy_iapp_bigip.py Python script on a Linux host. The Python script and iApp templates are available for download at the following locations:
