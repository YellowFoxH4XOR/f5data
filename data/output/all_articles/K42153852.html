Known Issue

The BIG-IP APM system may process HTML onsubmit event handlers incorrectly.

This issue occurs when all of the following conditions are met:

  • The resource is accessed using BIG-IP APM portal access
  • The resource contains an HTML onsubmit event handler
  • The original action is an absolute path to the target

Impact

The BIG-IP APM system may use an incorrect value of the action form attribute inside the onsubmit event handler, causing web applications to malfunction.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Web applications malfunction when accessed using portal access.
  • Users receive HTTP 404 Not Found responses when requesting portal access resources.
  • POST requests fail when using portal access.
