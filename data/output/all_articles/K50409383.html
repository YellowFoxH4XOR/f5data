Known Issue

Enabling CSRF (Cross-site request forgery) Protection may cause browser compatibility to fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM security policy processes server side content that includes a meta tag for browser compatibility.

    Example meta tag:

    <meta http-equiv="X-UA-Compatible" content="IE=8"/>
  • You enable CSRF Protection for the security policy.

Impact

Browser compatibility may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The CSRF protected content may not render correctly.
  • When viewing the HTTP level communication between the browser and the BIG-IP ASM virtual server, the BIG-IP ASM inserts the CSRF JavaScript after the first meta tag of the content sent.
