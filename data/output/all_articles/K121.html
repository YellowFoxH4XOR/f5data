Topic

All F5 products run a base operating system, and F5 responds to all reported vulnerabilities for that base operating system.

Important: F5 has modified the base operating systems for the products listed in the following table, except for F5 Traffix Signaling Delivery Controller (SDC). For SDC, F5 has pre-configured the base operating system to match the requirements and has added packages required to run SDC. Regardless, you must install only the patches that F5 supplies.
