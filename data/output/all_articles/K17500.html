Known Issue

Very large BIG-IP AFM firewall rule lists may result in excessive time to save or list the BIG-IP configuration.

This issue occurs when the following condition is met:

  • BIG-IP AFM firewall rule lists contain a very large number of rules (several thousand).

Impact

Saving or listing the BIG-IP AFM configuration may take an excessive amount of time (20 minutes or longer).

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Both the command line interface and the Configuration utility appear slow when you save or list the BIG-IP configuration.

Resolution

Workaround

You may be able to mitigate this issue by reviewing your BIG-IP AFM rule configuration and removing redundant rules. For example, instead of adding multiple rules for the same source and destination addresses, but different ports, you can create a port list and assign that to a single rule. For more information, refer to the About Firewall Rule Addresses and Ports section of the BIG-IP Network Firewall: Policies and implementations guide.

Impact of workaround: Ensure that any modifications that you make to firewall rules are compatible with your environment.
