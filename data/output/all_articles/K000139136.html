K000139136: BIGIP: how to check what agent invokes what code log message

Published

Source

Description

BIGIP administrator may want to get a grasp understanding about what agent triggers the particular code log message.

Environment

  • BIGIP

  • Logging code

Cause

None

Recommended Actions

BIGIP administrator may have a look at /run/bigip_error_maps.dat file using CLI. For example, if administrator wants to get more info about '01870023\|01490291' code logs, then he will see that the first code log is generated for access policy per-request logging agent and the second code log is for APM oAuth agent:

# cat /run/bigip_error_maps.dat | grep '01870023\|01490291'

1 LOG_NOTICE 01870023 BIGIP_ACCESSPERREQUEST_ACCESS2_LOGGING_AGENT "%s:%s:%.*s: %.*s"
1 LOG_NOTICE 01490291 BIGIP_ACCESSCONTROL_APDNOTICE_OAUTH_AGENT_SUCCESS "%s:%s:%s:%s: OAuth %s: succeeded for %s '%s'%s %s%s"
