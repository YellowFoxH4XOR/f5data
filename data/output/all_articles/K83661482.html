K83661482: Unable to access ''Live Update'' Page

Type
Support Solution
Published
2020-05-22
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.X, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 14.1.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 15.1.0, 15.1.8
Source
https://my.f5.com/manage/s/article/K83661482

Description
 

Live Update Configuration Utility page (System > Software Management > Live Update) is not accessible.
Page stuck with loading spinner. 
After few minutes of loading you might observe error similar to below:

"Could not communicate with the system. REST Framework is not available"
 

Environment

  • BIG-IP ASM 14.1.x, 15.x.x, 16.0.x
  • Live Update feature

Cause

ID893061

Recommended Actions

You can allocate more memory to tomcat by following procedure from below article:

K9719: Error Message: java.lang.OutOfMemoryError

 

Additional Information

Additionally similar symptoms might be observed in the logs:

  • /var/log/tomcat/catalina.out reports OutofMemory errors:

    # java.lang.OutOfMemoryError: Java heap space
    # -XX:OnOutOfMemoryError="/usr/bin/restart_tomcat"
    #   Executing /bin/sh -c "/usr/bin/restart_tomcat"... 
     
  • /var/log/restjavad.0.log displays "Connection refused" messages: 
    
[SEVERE][com.f5.rest.workers.liveupdate.LiveUpdateGenericWorker]  Exception:[java.net.ConnectException: Connection refused (Connection refused)
