Known Issue

This is the result of a known issue. A packet leak occurs when a VLAN failsafe is enabled on a disabled interface on the BIG-IP 540 (D35) platform. This ICMP packet leak results in increased memory consumption because the packets are not freed.

When this issue occurs, the following error message is reported in the /var/log/tmm file:

ifvnic packet_alloc() failure

F5 Product Development tracked this issue as CR90282 and it was fixed in version 9.4.4. For information about upgrading, refer to the BIG-IP LTM, GTM, or Link Controller release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.3-HF2 issued for BIG-IP version 9.4.3, and in HOTFIX-BIG-IP-9.3.1-HF2 issued for BIG-IP 9.3.1. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.

Workaround

You can work around this issue by disabling all instances of VLAN failsafe on disabled interfaces.
