Known Issue

When the BIG-IP system processes DNS requests by way of the cache resolver, the system discards chunked TCP responses.

This issue occurs when all of the following conditions are met:

  • The BIG-IP configuration contains a DNS cache resolver with the option to process the request using the TCP protocol.
  • The BIG-IP system processes the DNS query by way of the cache resolver to use the TCP protocol against an Internet name server.

Impact

The affected DNS response is discarded, and the query resolution fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The DNS cache resolver uses the TCP protocol to resolve a query, and the Internet name server does not include the complete reply in the first TCP segment.
  • The DNS cache resolver drops the chunked TCP responses, and the query resolution fails.
