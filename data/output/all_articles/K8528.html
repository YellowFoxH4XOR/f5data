Known Issue

Note:  BIG-IP WebAccelerator versions 9.4 and 9.4.1 are not affected by this issue.

This is the result of a known issue. Due to changes introduced in BIG-IP WebAccelerator version 9.4.2, the OneConnect feature is enabled in WebAccelerator-enabled virtual servers, even if a OneConnect profile has not been configured for the virtual server. Enabling OneConnect for the virtual server has significant impact if you want the Origin Web Servers (OWS) to log the actual Client IP Address for requests. 

For information about OneConnect behavior, refer to K7208: Overview of the OneConnect profile.

F5 Networks Product Development tracked this issue as CR92463 and it was fixed in BIG-IP WebAccelerator version 9.4.4. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.
