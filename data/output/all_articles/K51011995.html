Known Issue

The iControl REST daemon (icrd_child) may intermittently produce a core file during routine operations.

This issue occurs when the following condition is met:

  • After a set of REST APIs are served. For example, when a BIG-IP system is being discovered by a BIG-IQ system.

Impact

The iControl REST (icrd_child) daemon becomes unstable, and response times deteriorate.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system produces an icrd_child core file in the /var/core directory.
