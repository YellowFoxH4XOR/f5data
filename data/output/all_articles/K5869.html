K5869: BIG-IP may specify a source port of 0 when the use_incrementing_autoport internal variable is enabled

Known Issue

This is the result of a known issue. When the use_incrementing_autoport internal variable is enabled, BIG-IP selects source ports by using the next available port in numerical order.

Due to an off-by-one error, BIG-IP will cycle from port 65535 to port 0, before beginning again at port 1024. BIG-IP should never specify a source port of 0.

F5 Networks Product Development tracked this issue as CR57700 and CR57701, and it was fixed in BIG-IP version 4.5.14. For information about upgrading, refer to the BIG-IP Release Notes.
