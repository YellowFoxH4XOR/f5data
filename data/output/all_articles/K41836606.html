Description

After upgrading the BIG-IP if you have previously increased the size of the /var directory the upgrade process will automatically revert the size to the default value.

Note: Beginning in BIG-IP 16.0.0, the logical volume size for the /var partition increased by 50%. For more information, refer to K53259232: The /var partition size is increased by 50% in BIG-IP 16.0.0 and later.

In the following example the, /var size was extended before the upgrade to 20 GB.

Before upgrade:

tmsh show /sys disk directory

Directory Name         Current Size    New Size

--------------         ------------    --------
/config                   2273280         -
/shared                   20971520        -
/var                      20971520        -           <<<--------- 20 GB 
/var/log                  15728640        -
/appdata                  41943040        -


After upgrade, /var goes back to 3 GB:

tmsh show /sys disk directory

Directory Name         Current Size    New Size

--------------         ------------    --------
/config                  2273280         -
/shared                  20971520        -
/var                     3145728         -        <<<----------   3 GB        
/var/log                 15728640        -
/appdata                 41943040        -


Environment

  • /var disk space was extended before upgrade
  • upgrade performed


Cause

This behavior is expected. The /var was resized on a different volume set before upgrade. After device is upgraded to new volume, a new volume set will default size of /var to 3 GB.


Recommended Actions

In this scenario, you need to increase the size of /var again after upgrade is performed. 


Additional Information

None.
