Known Issue

This is the result of a known issue. Internet Explorer 8 (IE8) leaves a minimized window in the task bar when the Use Tray icon instead of Task bar entry when minimized option is selected from the Network Access: Resources: Customization tab.

You may safely ignore this issue. This issue does not occur in Internet Explorer prior to version 8. 

F5 Product Development is tracking this issue as ID 294092 (formerly CR121944-2) for FirePass version 7.0 and ID 317594 (formerly CR121944) for FirePass 6.1.0.

This issue was fixed in cumulative HF-610-2 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Additionally, a hotfix has been issued for FirePass version 6.0.3. Customers affected by this issue should contact F5 Technical Support, referencing this Solution number and the associated CR number, to request the hotfix.
