Issue

Error Message

01071bf7:3: Invalid URL format <URL> in CA-bundle manager <bundle manager object>. Check help page.

In this error message, note the following:

  • <URL> is the proxy server URL.
  • <bundle manager object> is the name of the bundle manager configuration object.

For example:

err mcpd[5627]: 01071bf7:3: Invalid URL format https://www.example-proxy.com in CA-bundle manager /Common/example_bundle. Check help page.

Message Location

You may encounter this message in the following locations:

  • /var/log/ltm
  • The TMOS shell (tmsh)
  • BIG-IP Configuration utility

Description

This message occurs when the following conditions is met:

  • A BIG-IP administrator attempts to configure a proxy server with an unsupported protocol within a bundle manager configuration object.

Only an HTTP proxy is supported.

Impact

The configuration issued through a tmsh command or the Configuration utility is rejected as invalid.

Recommended Actions

Omit the protocol scheme when configuring the Proxy Server setting. (You can use a FQDN or IP address). For example:

www.example-proxy.com

You can also optionally prepend http://.

For example:

http://www.example-proxy.com
