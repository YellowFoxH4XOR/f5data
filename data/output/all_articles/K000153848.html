K000153848: Unable to import APM profile, error "Log settings ... does not exist"

Type
Support Solution
Published
2025-08-28
Updated
2025-08-28
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000153848

Description

Import of an APM profile in Common partition fails if the exported profile was created in another partition.

Error message in /var/log/ltm:

 

... err mcpd[xxxx]: 01070734:3: Configuration error: Log settings /Common/xxxx associated with profile /Common/xxxx does not exist.

 

 

Environment

BIG-IP with APM

 

 

Cause

The Access Profile had a Logging Profile attached, which was created in another partition.

 

 

Recommended Actions

Create the logging profile in partition "/Common" before importing the Access Profile.
