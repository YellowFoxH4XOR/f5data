Description

The desired behavior is to set JWT authentication for all requests and disable it for certain requests. For example, all requests require JWT authentication except those that contain request uri /coffee and/or contain request method OPTIONS.

Environment

NGINX Ingress Controller (NIC)

JWT Authentication

VirtualServer resource

Policy resource

Recommended Actions

To achieve the desired behavior, implement a JWT Policy, at the server context level, with JWT authentication disabled and a valid JWK secret. The JWK secret will be inherited within the location context. Additionally, implement mappings within the http context that sets a variable used for the JWT auth directive. Implement the JWT auth directive within every location context.

  • Create a JWT Policy with realm set to "off"
apiVersion: k8s.nginx.org/v1
kind: Policy
metadata:
 name: jwt-policy
spec:
 jwt:
  realm: "off"
  secret: <jwk_secret_name>
  • Associate the JWT Policy to a VirtualServer resource
...
spec:
...
 policies:
 - name: jwt-policy
...
  • Configure the NIC ConfigMap with snippets that implements mappings for a JWT auth variable within the http context and the JWT auth directive in every location context
...
data:
 http-snippets: |
  map $request_uri $auth_jwt {
   ~*/coffee  "off";
   default   $options;
  }
  map $request_method $options {
   "OPTIONS"  "off";
   default   "Protected";
  }
 location-snippets: |
  auth_jwt $auth_jwt;
...

Additional Information

The filter for JWT auth exceptions can be changed or increased by editing the existing map directives and/or adding new ones. To add a mapping criteria, change the last map directive's default value to the variable of the new mapping criteria's variable. Then implement the default value of the new mapping criteria to that of what the last map directive's default value use to be.

For example, the following configuration will extend the JWT auth exceptions to include requests with a cafe header value of tea.

...
data:
 http-snippets: |
  map $request_uri $auth_jwt {
   ~*/coffee  "off";
   default   $options;
  }
  map $request_method $options {
   "OPTIONS"  "off";
   default   $cafe_header;
  }
  map $http_cafe $cafe_header {
   "tea"  "off";
   default   "Protected";
  }
 location-snippets: |
  auth_jwt $auth_jwt;
...
