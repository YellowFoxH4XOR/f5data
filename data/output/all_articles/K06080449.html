Description
You would like to disable the HTTP TRACE method of the BIG-IP Configuration Utility.

Example of the Configuration utility allowed HTTP methods:
HTTP/1.1 501 Not Implemented
Date: Tue, 03 Aug 2021 02:49:23 GMT
Server: Apache
X-Frame-Options: SAMEORIGIN
Strict-Transport-Security: max-age=16070400; includeSubDomains
Allow: OPTIONS,GET,HEAD,POST,TRACE

Environment

  •  BIG-IP
  •  Configuration utility


Cause
The TRACE method is allowed by default.
 

Recommended Actions

  1. Log into the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Modify the HTTPD configuration to not allow TRACE with the following command:

    modify /sys httpd include "TraceEnable off"

  3. Save the configuration change:

    save /sys config

  4. Restart the httpd service.

    restart /sys service httpd

Note: Access to the BIG-IP Configuration utility will temporarily be disrupted while the httpd service restarts.
