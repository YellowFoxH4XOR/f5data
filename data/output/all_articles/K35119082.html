Description

When the time drift exceeds 1000 seconds, ntpd will not automatically synchronize with the NTP server. In that case, the BIG-IP logs an error message to the /var/log/daemon.log similar to the following example:

err ntpd[12610]: time correction of <number> seconds exceeds sanity limit (1000); set clock manually to the correct UTC time.

 

Environment

  • You configured NTP servers on System > Configuration > Device > NTP.
  • The current time of the BIG-IP differs more than 1000 seconds.

 

Cause

None

 

Recommended Actions

You can restart ntpd to adjust the time drift which exceeds 1000 seconds.

# bigstart restart ntpd

 

Additional Information

None
