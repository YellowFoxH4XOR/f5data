Known Issue

When a virtual server is assigned an iRule that uses the HTTP::cookie decrypt iRule command to decrypt an encrypted cookie, and the encrypted cookie received is larger than the Maximum Segment Size (MSS), the TMM process cores and restarts.

This issue occurs when all of the following conditions are met:

  • The affected virtual server has an iRule that uses the HTTP::cookie decrypt iRule command to decrypt the encrypted cookie
  • The size of the encrypted cookie is larger than the MSS of the underlying TCP connection

If a cookie is larger than the MSS of the underlying TCP connection, it is sent across multiple TCP packets, which causes TMM to core. For example, if the MSS of the TCP connection is 64 bytes, and the cookie is 80 bytes, the cookie is sent across two TCP packets.

Note: The Encrypt Cookies feature of the HTTP profile is not affected by this issue.

Impact

The TMM process becomes unresponsive and traffic processing is temporarily interrupted.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The TMM process becomes unresponsive and produces a core file
  • The BIG-IP system generates an SIGSEGV fault and stack trace to the /var/log/tmm file

Workaround

To work around this issue, you can use the Encrypt Cookies feature of the HTTP profile to encrypt and decrypt cookies on the client side. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Services > HTTP.
  3. Click the name of the HTTP profile assigned to the affected virtual server.
  4. Select the Encrypt Cookies check box.
  5. Type the name of the cookie in the Encrypt Cookies text box.

    Note: If you want to specify more than one cookie for the BIG-IP system to encrypt, separate the cookie names with a space.

  6. Select the Cookie Encryption Passphrase check box.
  7. Type the passphrase for the cookie in the Cookie Encryption Passphrase text box.
  8. Confirm the passphrase for the cookie by typing it in the Confirm Cookie Encryption Passphrase text box.
  9. To save the modification, click the Update button.
