Description

Running tmsh load sys config verify shows this error:

01070734:3: Configuration error: in main mode with preshared key authentication, id-type can only be address. Unexpected Error: Validating configuration process failed.

Environment

BIG-IP

default profiles

Cause

Modifying this default profile shows this error in the /var/log/ltm. It says: 01070734:3: Configuration error: in main mode with preshared key authentication, id-type can only be address.

Unexpected Error: Validating configuration process failed.

Recommended Actions

As a best practice, it is highly recommended to never make any changes to default profiles. This has caused numerous failures that will likely never be documented; however to ensure a stable environment, ensure to follow F5 Best Practice recommendations.

Additional Information

To avoid this issue, create a custom profile using the default profile as the parent, and do not modify the default profiles.
