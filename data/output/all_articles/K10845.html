Topic

Many organizations have multiple forms of authentication, which may be due to authentication designed for full redundancy, or that some users need to authenticate against different authentication servers. When configuring your authentication method, some selections allow a secondary authentication.

The following table lists the FirePass authentication methods you can configure with a backup authentication method:

Authentication MethodBackup Method Available
Internal DatabaseActive Directory
RadiusActive Directory
LDAPActive Directory
Basic HTTP Using External ServerActive Directory
Initial signup on LDAP with Subsequent Strong Internal PasswordActive Directory
Windows DomainNone
Active DirectoryNone
HTTP Form basedNone
Client CertificateNone
RSA SecurIDActive Directory

To turn on on Active Directory as the backup method, perform the following procedure:

  1. From the FirePass Administrative Console, go to the Users: Global Settings page.
  2. In the Additional Domain Password section, select the Use extra domain password for single sign on option.
  3. Go to the Users: Groups: Master Groups page.
  4. Click the Create new group button.
  5. Create a new group using the primary method of authentication you want to use.
  6. Click on the Authentication tab.
  7. Select the Verify domain password against Active Directory server option.

    Note    : Configuration fields will appear after checking the option.
  8. Populate the Active Directory settings with the information for your domain.
  9. Click Save Settings.
