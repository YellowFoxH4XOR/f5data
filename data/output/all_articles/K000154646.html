Description

BIG-IQ systems may continuously generate backup files until disk space is depleted, even when no backup tasks are visible or configurable in the GUI in Devices> Backups > Backups Schedules

Environment

  • BIG-IQ 8.4
  • Empty backup schedule in GUI
  • Backup files are being created and stored automatically without cleaning it up

Cause

An orphaned backup schedule exists in the system database but is not visible or manageable via the BIG-IQ GUI. This hidden schedule continues to trigger backups, leading to disk space exhaustion.

 

Recommended Actions

  • Identify Orphaned Backup Schedules by running command on the BIG-IQ system to list all defined backup schedules (including those not shown in the GUI):

restcurl /shared/task-scheduler/scheduler/ | jq '.items[] | select(.taskBodyToRun.taskBody)' | jq '{id,name,timeToStartOn,daysOfTheWeekToRun}'

 

Review output for schedules matching the names of generated backups

 

Example:

 

[admin@labdevice:Active:Standalone] ~ # restcurl /shared/task-scheduler/sche duler/ | jq '.items[] | select(.taskBodyToRun.taskBody) ' | jq -r '{id,name,time ToStartOn,daysOfTheWeekToRun}'

{

"id": "63667574-21f3-3ccb-af6c-3e7ac9a8b09f",

"name": "Example-Backups",

"timeToStartOn": "2021-11-18T23:00:00-0800",

"daysOfTheWeekToRun": []

}

[admin@labdevice:Active:Standalone] ~ #

 

  • Remove Orphaned Backup Schedule delete the problematic schedule directly from the database using:

restcurl /shared/task-scheduler/scheduler/63667574-21f3-3ccb-af6c-3e7ac9a8b09f -X DELETE

NOTE Replace with correct schedule ID/path as identified above.

After removing the schedule, manually delete accumulated UCS backup files from the system to free up disk space.
