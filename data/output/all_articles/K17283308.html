Description

Applications can monitor or gather statistics from a BIG-IP by accessing the REST API on the BIG-IP. This article shows some of the commonly used REST endpoints for gathering statistics and also gives some example of how to request statistics from these endpoints using curl.

Environment

  • Use iControl REST API to query the status of the BIG-IP.
  • Use iControl REST API to query the statistics of particular BIG-IP Objects.

Cause

None

Recommended Actions

Prerequisites

  • Access to a client system with a third-party application that can send user-defined HTTPS POST requests to the BIG-IP system.
    Note: The procedures in this article use the client URL (cURL) utility.
  • Administrator access or have been granted access to iControl on the remote BIG-IP system on which you want to create or delete configuration objects.
  • IP address of the remote BIG-IP system is configured to allow port 443 access to the iControl REST API.

Procedures

  • Gathering Pool Statistics
  • Gathering Specific Pool Member Statistics
  • Gathering Virtual Server Statistics
  • Gathering Network VLAN Statistics
  • Gathering Network Interface Statistics
  • Gathering Specific Interface Statistics

Using cURL to query statistics from the BIG-IP LTM nodes and pools and member objects through the iControl Rest API

The following procedures provide examples of listing statistical objects using the iControl REST API on a remote BIG-IP system.
curl -k -u <username>:<password> https://<BIG-IP>/mgmt/tm/ltm/pool/~<partition>~<objectname>/stats

-k, --insecure        (TLS) By default, every SSL connection curl makes is verified to be secure. This option allows curl to proceed and operate even for server connections otherwise considered insecure.  Use this when the BigIP system does not have a signed certificate applied.
-u, --proxy-user    Specify the user name and password to use for proxy authentication.
          <username>:<password>   user credentials with iControl access.
<BIG-IP>                IP or hostname of the BIG-IP system.
<partition>             Partition the Object resides in.  Tilde’s are used instead of slashes for the Partition name.
<objectname>       The name of the object to query.
Note: See man page for curl for more information on how to use curl.

For Example: curl -k -u admin:admin https://mybigip.corp.local/mgmt/tm/ltm/pool/~Common~myPool/stats

The output is in JSON format. By default, cURL does not format the output from the command line.

Example of default curl output:

If you perform this command on the Standby BIG-IP you can pipe this output to json-format. Or use restcurl to print out the format properly.

For Example:

curl -ku admin:admin https://mybigip.corp.local/mgmt/tm/ltm/pool/~Common~test-ltm-pool/members/stats | json-format
restcurl -k -u admin:admin https://mybigip.corp.local/mgmt/tm/ltm/pool/~Common~test-ltm-pool/members/stats

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

Gathering Pool Statistics
curl -k -u <username>:<password> https://<BIG-IP>/mgmt/tm/ltm/pool/~<partition>~<poolname>/members/stats
 
Gathering Specific Pool Member Statistics
curl -k -u <username>:<password> https://<BIG-IP>/mgmt/tm/ltm/pool/~Common~bigiq/members/~<partition>~<NodeIP:Port>/stats

Gathering Virtual Server Statistics
curl -k -u <username>:<password> https://<BIG-IP>/mgmt/tm/ltm/virtual/~<partition>~<VirtualServer>/stats

Gathering Network VLAN Statistics
curl -k -u <username>:<password> https://<BIG-IP>/mgmt/tm/net/vlan/~<partition>~<VLANName>/stats | json-format

Gathering Network Interface Statistics
curl -k -u <username>:<password> https://<BIG-IP>/mgmt/tm/net/interface/stats | json-format
 
Gathering Specific Interface Statistics
curl -k -u <username>:<password> https://<BIG-IP>/mgmt/tm/net/interface/<interfaceNumber>/stats | json-format
