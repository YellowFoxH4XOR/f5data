Description

One or more private SSL keys may be missing or deleted by mistake from BIG-IP.  You may be able to recover the SSL key from the standby device if configured as a HA pair, however in the case where the private SSL keys are missing from both active and standby you can attempt to recover them from a UCS archive. 

Environment

  • BIG-IP
  • SSL private key missing

Cause

None

Recommended Actions

The private SSL key may be recovered from UCS. The SSL keys resides in the following location on the BIG-IP device:

/config/filestore/files_d/Common_d/certificate_key_d

However, the SSL keys reside in /var/tmp/filestore_temp/files_d/Common_d/certificate_key_d/ directory when they are included during the UCS creation.

The command to extract UCS in Linux OS:

Extrat UCS:
cd /shared/tmp
tar zvxf <ucs_name>.ucs

Copy the missing private SSL key from the extracted UCS /var/tmp/filestore_temp/files_d/Common_d/certificate_key_d to the device where it is needed.

If the SSL key is not found in the UCS, generate a new SSL key.

Additional Information

There is an option to include or exclude private keys in the UCS archive.
