Known Issue

This is the result of a known issue. On August 1, 2007, F5 Networks began shipping the BIG-IP 6400 platform with new AMD Opteron model 252 processors. For more information, refer to K8729: Differences in CPU performance on BIG-IP 6400 platforms.

If you install BIG-IP versions 9.4 through 9.4.1 on a 6400 platform with the new AMD processor, even though the unit will become active and the interfaces will come up, the BIG-IP system will not accept or pass any traffic.

When this issue occurs, the following error messages are logged to the /var/log/ltm file:

tmm[1477]: 01010025:2: Device failure: cn0: invalid core set
tmm[1477]: 01010025:2: Device failure: cn0: attach failure
tmm[1477]: 01010027:2: Unable to attach to PCI device 01:01.00

lacpd[8824]: 01160018:1: Internal link 0.1 is UNAVAILABLE.
lacpd[8824]: 01160018:1: Non working internal trunk member 0.1 triggers switchboard failsafe take action.
lacpd[8824]: 01160016:6: Interface 0.1, link admin status: enabled, link status: down, duplex mode: half, lacp operation state: down
lacpd[8824]: 01160013:1: Switchboard FailSafe take action is set
lacpd[8824]: 01160018:1: Internal link 0.2 is UNAVAILABLE.
lacpd[8824]: 01160018:1: Internal link 4.1 is UNAVAILABLE.
lacpd[8824]: 01160018:1: Internal link 4.2 is UNAVAILABLE.
sod[8866]: 01140040:5: Switchboard failsafe blocked for 128 seconds.
sod[8866]: 01140039:5: Switchboard failsafe no longer blocked.

To verify the processor model number running on your BIG-IP 6400 platform, type the following command:

cat /proc/cpuinfo | grep -i amd

If your platform is equipped with the new AMD processor, the command output should appear similar to the following example:

vendor_id : AuthenticAMD
model name : AMD Opteron(tm) Processor 252
vendor_id : AuthenticAMD
model name : AMD Opteron(tm) Processor 252

F5 Networks Product Development tracked this issue as CR92265 and it was fixed in BIG-IP version 9.4.2. For information about upgrading, refer to the BIG-IP LTM and ASM Release Notes.

Additionally, this issue was fixed in Hotfix-BIGIP-9.4.1-HF2 issued for BIG-IP version 9.4.1. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
