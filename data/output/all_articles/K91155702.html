K91155702: Boot Volumes show status ''Audited''

Type
Support Solution
Published
2022-10-18
Updated
2023-08-17
Applies to
  • VIPRION Platforms
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K91155702

Description

When checking the status of Software on Boot Locations, the status shows as audited.
When this occurs, additional volumes cannot be created or switched to.

# tmsh show sys software

-------------------------------------------------------------------
Sys::Software Status
Volume  Product   Version   Build  Active   Status  Allowed Version
-------------------------------------------------------------------
HD1.1    BIG-IP  15.1.5.1  0.0.14     yes  audited              yes

Note: if the volume is in 'failed to delete volumeset' state, please refer to K000135806
 

Environment

  • BIG-IP

Cause

This is caused by a flag-file specific to the lind service (responsible for software installation and volume creation tasks) being present on the system:

  /shared/noupgrade

Recommended Actions

Delete the file on the current volume (on all blades)
    # rm /shared/noupgrade
    or (on multi-blade VIPRION systems)
    # clsh rm /shared/noupgrade
    Verify that the status is no longer audited
    # tmsh show sys software

    --------------------------------------------------------------------
    Sys::Software Status
    Volume  Product   Version   Build  Active    Status  Allowed Version
    --------------------------------------------------------------------
    HD1.1    BIG-IP  15.1.5.1  0.0.14     yes  complete              yes

Additional Information

K48615077: BIG-IP daemons (15.x - 16.x)
