Description
Wide IP CNAME was not resolving to an IP address

Environment

  • BIG-IP DNS
  • DNS Profile options:
    • DNS Express: Enabled
    • Use BIND Server on BIG-IP: Disabled
    • Unhandled Query Actions: Allow
  • No Load Balanced Pool defined in DNS Listener
  • CNAME pool contains a CNAME that does not exist on the BIG-IP, ie defined on internal DNS

Cause
An additional A record is required for the BIG-IP to correctly resolve the IP address.  The DNS query cannot be handled by the BIG-IP, as there is no A record, or local BIND, configured and no DNS pool to forward the request to for resolution.  Once the Wide IP A record is created, the BIG-IP resolves the CNAME of the pool member using the DNS server(s) configured in its internal system DNS settings.  This issue has to do with how DNS queries are processed, as well as how Unmatched Queries are handled on the BIG-IP.

Recommended Actions
Create an additional A record to match the CNAME, or create a load-balanced pool on the listener as a forwarding destination for Unmatched Queries.

To create a new A record:

  1. Go to Global Traffic > wide IPs
  2. Select Create
  3. Enter the name that you want the BIG-IP system to resolve.
  4. Select the pools you want to use and select Add to add them to the Pool List.
  5. Select any additional options you want to enable for the wide IP.
  6. Select Finished

To create a new pool:

  1. On the Main tab, click on DNS > Delivery > Load Balancing > Pools > Pool List
  2. Select Create
  3. In the Name field, type a unique name for the pool.
  4. For the Health Monitors setting, from the Available list, select the custom DNS monitor you created and move the monitor to the Active list.
  5. Using the New Members setting, add each resource that you want to include in the pool:
    1. (Optional) In the Node Name field, type a name for the node portion of the pool member.
    2. In the Address field, type an IP address.
    3. In the Service Port field, type a port number, or select a service name from the list.
    4. (Optional) In the Priority field, type a priority number.
    5. Click Add.
  6. Select Finished.

 To attach the new pool to a DNS Listener:

  1. On the Main tab, click on DNS > Delivery > Listeners > Listener List
  2. Click on the link of the Listener in the Name field
  3. Click on the Load Balancing tab
  4. Select a pool from the Default Pool dropdown menu
  5. Select Update

Note: This pool is where the Unmatched Query Action will default to, if there is no Wide-IP entry for the DNS Query.
