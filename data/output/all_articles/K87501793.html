Known Issue

OneConnect may not function with some BIG-IP APM configurations.

This issue occurs when all of the following conditions are met:

  • Your configuration includes single sign-on (SSO).
  • SSO is configured as part of an access profile.
  • The access profile virtual server is configured to use a OneConnect profile.

Impact

Connections processed by the access profile do not use OneConnect connection pooling.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Destination resources have a higher number of TCP connections and a higher number of unused/idle TCP connections.
  • When viewing OneConnect profile summary statistics, the Total Reuses connection count does not increase when the SSO configured access profile processes connections.
