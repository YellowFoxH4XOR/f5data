Known Issue

When you use the back button on your browser to access a web resource, the resource may be unavailable.

This issue occurs when all of the following conditions are met:

  • Web scraping detection is enabled, and the blocking mask is set to Block
  • The security policy enforcement mode is set to Blocking
  • You attempt to use the back button on your browser to re-access a web page that is protected by web scraping detection

BIG-IP ASM injects JavaScript tokens into server responses to enable web scraping detection. Due to the modifications made to the server response, this issue may occur if a user returns to the page by reloading the browser's cache using the back button.

Impact

Web resources may be unavailable.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Error messages that appear similar to the following example may display:

    Warning: Page Has Expired
