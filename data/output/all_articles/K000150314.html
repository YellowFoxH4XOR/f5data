K000150314: PSU details not shown in F5OS rSeries unit

Type
Support Solution
Published
2025-03-11
Updated
2025-11-25
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000150314
Description

After installing/replacing a PSU, F5OS unit might not immediately display the new PSU's serial or part numbers.

Environment
  • F5OS-A
  • RMA
  • New PSU
Cause 

Certain discrete amount of time is required for new HW to be detected by F5OS.

Recommanded Actions

Allow some time for F5OS to detect and recognize new HW components.

If no details appear after 48 hrs. contact F5 customer support.

Example:

Recently installed PSU:

#############
MY_F5R5900_UNIT# show components component psu-*


components component psu-1
state serial-no XXXXXXXXXXXX
state part-no M1845
state empty false
psu-stats psu-current-in 0.937
psu-stats psu-current-out 11.625
psu-stats psu-voltage-in 228.0
psu-stats psu-voltage-out 12.218
psu-stats psu-temperature-1 33.0
psu-stats psu-temperature-2 42.0
psu-stats psu-temperature-3 43.0
psu-stats psu-fan-1-speed 9760


components component psu-2
state serial-no ""---------------------<<<<<<<<<<< No PSU serial number shown
state part-no ""  ---------------------<<<<<<<<<<< No PSU part number shown
state empty false
psu-stats psu-current-in 0.875
psu-stats psu-current-out 11.437
psu-stats psu-voltage-in 228.0
psu-stats psu-voltage-out 12.171
psu-stats psu-temperature-1 36.0
psu-stats psu-temperature-2 44.0
psu-stats psu-temperature-3 45.0
psu-stats psu-fan-1-speed 9728
############################

 

After 24 hrs:

#############
MY_F5R5900_UNIT# show components component psu-*
