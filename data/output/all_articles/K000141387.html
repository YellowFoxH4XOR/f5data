K000141387: BOT Profile in Transparent blocking request

Type
Support Solution
Published
2024-10-25
Updated
2024-10-25
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000141387

Description

When using BIG-IP Application Security Manager (ASM) with a BOT profile set to transparent mode, you may encounter a situation where Microservices are blocking requests. This happens even though the BOT profile itself is configured to not block traffic.

 

Environment

  • BIG-IP ASM
  • BOT Profile assigned
  • Microservices set to blocking

Cause

The Microservice settings will override the general settings of the BOT profile. This behavior is expected within the system. You can set the Microservice response to be different from the rest of the BOT profile. For example:

  • Security policy in Blocking mode with microservices in Transparent mode.
  • Security policy in Blocking mode with Blocking Settings overrides for microservices.
  • Security policy in Transparent mode with microservices in Blocking mode.

 

Recommended Actions

If blocking is not the intended behavior for your microservices, you should change the microservice setting to Profile Default. This will ensure that the general settings of the BOT profile are respected, and the requests will not be blocked.

  1. Navigate to the "Microservice Protection" setting in the BOT profile
  2. Select the matching configuration
  3. Set it to Profile Default 
  4. Click Update
  5. Click Save on BOT profile
