K000092432: Duplicate instances appear in the UI

Source

Description

Duplicate instances appear in the NGINX Instance Manager (NIM) ui.

 Environment

NIM

Two or more NGINX instances

 Cause

Unknown

 Recommended Actions

  1. Stop the agent on the instance  
    sudo systemctl stop nginx-agent
  2. Remove both instances appearing in the NIM ui
  3. Start the agent on the instance  
    sudo systemctl start nginx-agent
