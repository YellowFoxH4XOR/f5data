K6631: The gtmd process may crash if no peer IP address is configured when setting up redundant BIG-IP Link Controller systems

Known Issue

This is the result of a known issue. If a redundant BIG-IP Link Controller pair is initially set up with no peer IP addresses, and the Virtual Server Discovery One Time Discovery option is enabled, the gtmd process may crash.

BIG-IP Link Controller systems affected by this issue display the following error message:

Got bad result: 01070191:3: Server <peer_hostname> has no IP addresses

F5 Product Development tracked this issue as CR69152 and it was fixed in BIG-IP Link Controller versions 9.2.4 and 9.3.0. For information about upgrading, refer to the BIG-IP Link Controller release notes.
