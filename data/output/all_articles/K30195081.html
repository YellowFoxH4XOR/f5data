Description

All services are down

  • All VIP's and Pools are showing down
  • Interface showing inbound traffic but no outbound 
  • Packet captures show inbound SYN packets with no response

Environment

  • BIG-IP 1-nic configuration on Google cloud
  • All VIP's and Pools
  • No errors reporting and management working
  • Has sflow receivers configured and active

Cause

ID889209

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Disable Sflow receiver 
  2. Save configuration
  3. Reboot.

Additional Information

This issue only affects versions that have the fix for ID777269.
