K000157955: Message: 01070823:3: Read Access Denied: user ([username]) type (HPKE Key)

Type
Support Solution
Published
2025-11-25
Updated
2025-11-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.X, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000157955

Description

While running "show running-config" on TMSH, "01070823:3: Read Access Denied: user ([username]) type (HPKE Key)" error message may be thrown and user may fail to display current running configuration. Here are sample logs.

==> /var/log/ltm <==
Nov 25 09:10:40 bigip.local err mcpd[6366]: 01070823:3: Read Access Denied: user (myoperator) type (HPKE Key)

==> /var/log/audit <==
Nov 25 09:10:40 bigip.local notice -tmsh[25449]: 01420002:5: AUDIT - pid=25449 user=myoperator folder=/Common module=(tmos)# status=[Unexpected Error: Can't display all items, can't get object count from mcpd] cmd_data=show running-config

 

Environment

  • BIG-IP software version 17.5.0 or later.
  • User account role which does not have partition scope "All partitions". For example, Guest user role, Operator role, or Manager role.
  • Run "show running-config" or "list" TMSH command (or any other TMSH command which accesses to "/ltm dns hpke key|profile" object).

 

Cause

Bug ID 2152301.

 

Recommended Actions

Login with other user account with partition scope "All partitions", for instance, admin account.

 

Additional Information

These 4 user roles have partition scope "All partitions" and free from this problem.

  • Administrator
  • Resource Administrator
  • Auditor
  • Log Manager
