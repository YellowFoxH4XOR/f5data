Topic

This article applies to BIG-IP 11.x. For information about other versions, refer to the following article:

  • K8136: Missing default SSL certificate and key pair cause a bigpipe error (9.x - 10.x)

Summary

When the BIG-IP software is installed, the system generates a default Secure Sockets Layer (SSL) certificate and key pair, called default.crt and default.key. The system associates the certificate and key pair with the default SSL profiles.

The default SSL certificate and key pair are required for system operation and you should not delete them. The BIG-IP system checks the validity of the default certificate and key pair when the system is upgraded or the configuration is loaded. If the default.crt, and default.key files are missing or corrupt, the BIG-IP configuration may fail to load properly and generate an error message to the console and /var/log/ltm file that appears similar to one of the following examples.

Description

  • When the default.crt file is missing, the error message appears similar to the following example:

    01070313:3: Error reading cert PEM file /config/filestore/files_d/Common_d/certificate_d/:Common:default.crt_1 for profile /Common/clientssl: error:2006D080:BIO routines:BIO_new_file:no such file
    Unexpected Error: Loading configuration process failed.

  • When the default.crt file is corrupt, the error message appears similar to the following example:

    01070313:3: Error reading cert PEM file /config/filestore/files_d/Common_d/certificate_d/:Common:default.crt_1 for profile /Common/clientssl: error:0D07803A:asn1 encoding routines:ASN1_ITEM_EX_D2I:nested asn1 error
    Unexpected Error: Loading configuration process failed.

  • When the default.key file is missing, the error message appears similar to the following example:

    01070313:3: Error reading key PEM file /config/filestore/files_d/Common_d/certificate_key_d/:Common:default.key_1 for profile /Common/clientssl: error:2006D080:BIO routines:BIO_new_file:no such file
    Unexpected Error: Loading configuration process failed.

  • When the default.key file is corrupt, the error message appears similar to the following example:

    01070313:3: Error reading key PEM file /config/filestore/files_d/Common_d/certificate_key_d/:Common:default.key_1 for profile /Common/clientssl: error:0D07803A:asn1 encoding routines:ASN1_ITEM_EX_D2I:nested asn1 error
    Unexpected Error: Loading configuration process failed.

Recommendations

When experiencing issues with missing or corrupt default SSL certificates and key pairs on the BIG-IP system, you can regenerate them by referring to the procedures in K13579: Generating new default certificate and key pairs for BIG-IP SSL profiles.
