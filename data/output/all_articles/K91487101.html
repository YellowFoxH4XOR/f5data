Description:

After applying the following workaround based on K01235989: Understanding BIG-IP ASM large file upload behavior:

some or all policy may start blocking traffic due to "illegal method" violation on both GET and POST HTTP methods. 

 

Environment:

  • ASM Security Policy
  • Request buffer
  • GET/POST HTTP methods

 

Cause:

ID867373

 

Recommended Actions:

As described in the Work Around for ID867373, define the GET/POST methods as allowed in order to allow traffic to pass.

K12312: Overview of BIG-IP ASM Illegal Method violations

 

 

Additional Information:

Change in long_request_buffer_size followed by an ASM service restart can trigger ID867373.
