K18241930: Unable to import ASM policy from version 15.x to 16.x

Type
Support Solution
Published
2022-10-09
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP ASM: 16.1.X, 16.0.X, 16.1.3, 16.1.2, 16.1.1, 16.X.X, 16.0.1, 16.0.0, 16.1.0
Source
https://my.f5.com/manage/s/article/K18241930

Description

An ASM policy exported from a unit running version 15.x fails to be imported on an ASM unit running version 16.x, with the error message below:

Malformed XML: Failed to insert to PLC.PL_POLICY_NEGSIG_SETS (DBD::mysql::db do failed: Cannot add or update a child row: a foreign key constraint fails (`PLC`.`PL_POLICY_NEGSIG_SETS`, CONSTRAINT `PL_POLICY_NEGSIG_SETS_ibfk_2` FOREIGN KEY (`set_id`) REFERENCES `NEGSIG_SETS` (`set_id`) ON DELETE CASCADE))

Environment

  • BIG-IP ASM
  • Policy Export/Import

Cause
The policy contains Server-Side Request Forgery Signatures sets and these have been removed from version 16.x

Recommended Actions
You need to remove all Server-Side Request Forgery Signatures sets from your policy in version 15.x prior to  exporting the policy.

  1. Navigate to Security  ››  Application Security : Policy Building : Learning and Blocking Settings
  2. Select the relevant policy 
  3. Under 'Policy Building Settings' click on 'Attack Signatures', then click on 'Change'
  4. Uncheck all 'Server-Side Request Forgery Signatures' sets in the list of Attack Signature Sets
  5. Save the changes and then Apply Policy.
