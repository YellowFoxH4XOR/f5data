Description

Starting with the release of BIG-IP 14.1.0, Live Update provides a framework to manually install or configure automatic installation of updates to BIG-IP ASM components. Live update settings can be controlled by the BIG-IP's GUI, REST API, or TMSH.   

Environment

  • ASM
  • Your BIG-IP system is configured to automatically download component update files.
  • You manually upload component update files to your BIG-IP system.

Cause

TMSH is the desirable method to update the ASM's live update component files.

Recommended Actions

  • Checking and retrieving a component update file
  • Determining the latest version and availability of a BIG-IP ASM component update file and assigned installation ID
  • Installing a new component update file

Checking and retrieving a component update file

Use the following procedure to initiate the BIG-IP ASM system to check with F5 and retrieve a BIG-IP ASM update file when a file for the specified component type is available:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To have the BIG-IP ASM system check and retrieve a new component update file use the following syntax replacing <component update file type> with the appropriate value from the previous table:

tmsh modify mgmt tm live-update <component update file type> availability status check

Note: Component update file retrieval can take a few minutes depending on file size. Be sure to note the status returned for the action prior to attempting to install a component update file.

Example of checking and when available retrieving a component update file for ASM Attack Signatures:

tmsh modify mgmt tm live-update asm-attack-signatures availability status check
tmsh list mgmt tm live-update asm-attack-signatures availability
Example output:
mgmt tm live-update asm-attack-signatures availability {
    kind "tm:live-update:asm-attack-signatures:availabilitystate"
    lastCheckDateTime "2021-11-05T16:53:53Z"
    lastCheckUpdateFile "ASM-AttackSignatures_20210713_094523.im"
    selfLink "https://localhost/mgmt/tm/live-update/asm-attack-signatures/availability"
    status "update-file-retrieved"
}

Installing a new component update file

After you have determined the latest new BIG-IP ASM component component update file ID value, you can use the following TMSH command syntax to install the component update file.

Impact of procedure: Installing a component update file applies the component update to the active configuration. The component update is applied to request that matches the BIG-IP component of the related component update.

To install the identified component update file using TMSH command use the following syntax:
tmsh modify mgmt tm live-update <component update file type> installations <installations id> status INSTALL

Example locating a component update file for ASM Attack Signatures:

tmsh modify mgmt tm live-update asm-attack-signatures installations ff8080817cf0f74d017cf10566cc0002 status INSTALL

To query installation progress status, run this command:

tmsh list mgmt tm live-update asm-attack-signatures installations ff8080817cf0f74d017cf10566cc0002 status
Example output:
{
    status "install-in-progress"
}

When the system is done, you should see a new status by running the command again:

tmsh list mgmt tm live-update asm-attack-signatures installations ff8080817cf0f74d017cf10566cc0002 status
Example output:
{
    status "install-complete"
}
