Known Issue

The repeating Pkcs11 Initialization error message may appear in the /var/log/ltm file.

This issue occurs when all of the following conditions are met:

  • You are using a hardware security module (HSM), such as SafeNet.
  • You have initiated a reboot of the BIG-IP system.

The pkcs11d process requires other services, such as the Traffic Management Microkernel (TMM) and the Master Control Program Daemon (MCPD). Following a system reboot, the pkcs11d process attempts to start until those services are available.

Impact

The initialization error messages are misleading because the service is actually retrying. In some cases, this retrying may eventually lead to the pkcs11d process producing a core file. Until the service is successfully started, Secure Sockets Layer (SSL) connections cannot be established on virtual servers that are associated with an SSL profile that references the affected certificate/key pair that is stored on the HSM.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H541563 on the Diagnostics > Identified > High screen.
  • In the /var/log/ltm file, you observe repeated messages similar to the following example:

    err pkcs11d[1234]: 01680002:3: Pkcs11 Initialize error.

  • In the /var/log/daemon.log file, you observe messages similar to the following example:

    err pkcs11d[1234]: Nethsm: pkcs11_initialize C_GetSlotList error 0x00000000, number of slots 0

Workaround

To work around this issue, you can manually restart the pkcs11d process when TMM and MCPD are both ready. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To verify TMM and MCPD availability, type the following command:

    tail -f /var/log/ltm | grep -E "tmm | mcpd"

    You should see output similar to the following example, when those services are ready:/p>

    notice sod[21885]: 01140044:5: HA reports tmm ready.
    notice sod[21885]: 01140030:5: HA proc_running mcpd is now responding.

  3. To restart the pkcs11d process, type the following command:

    restart /sys service pkcs11d
