Description

A vulnerability where advanced JavaScript injection combined with HTTP parameter pollution can bypass Web Application Firewall protections, allowing XSS payloads to evade detection if repeated parameter names are not properly handled in security policies.

Environment

  • BIG-IP ASM/AWAF
  • Security policies with XSS protection enabled
  • ASM policy parameter objects with focus on "Illegal repeated parameter name" violation and "Allow Repeated Occurrences" option

Cause

Web Application Firewall protection is bypassed, allowing XSS payloads via JavaScript injection when HTTP parameter pollution is used and the "Illegal repeated parameter name" violation is not enabled or the "Allow Repeated Occurrences" option is misconfigured.

Answer/Recommended Actions

  1. Update ASM Attack Signatures to the latest available version to ensure coverage for advanced XSS and parameter pollution attacks. The new Improvement was already applied within the Attack Signature file "ASM-AttackSignatures_20250814_093551.im".
  2. Confirm the XSS Signature Set is included (especially Attack Signature ID "200101582") and enforced in ASM Security Policies.
  3. Enable the "Illegal repeated parameter name" violation in ASM policy to detect and block parameter pollution attempts.
  4. Disable the "Allow Repeated Occurrences" option for all relevant Parameter objects to prevent repeated parameter names in requests.
  5. Apply these settings to all security policies requiring XSS and parameter pollution protection.
  6. Test the policy with known XSS and parameter pollution payloads to verify mitigation.
