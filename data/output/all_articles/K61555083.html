Description

After renewing an SSL certificate, you may find that it fails to import to the BIG-IP system, with the following error:

01070317:3 key and certificate do not match

Environment

  • BIG-IP LTM
  • SSL Certificate, for Client SSL profile or Device Certificate

Cause

When it becomes time to renew an SSL certificate, it's important to first understand the difference between renewing a certificate, as opposed to signing an entirely new certificate. In either case, a new Certificate Signing Request (CSR) can be generated. The difference between a renewal and an entirely new certificate has to do with whether or not the original private key is reused.

A true renewal involves generating a CSR from the original private key. Each CSR that is generated from that private key will be identical.

In contrast, if you need an entirely new certificate, you must first generate a new private key. Your new CSR will be unique to this new private key.

In either case, the CSR is then provided to the Certificate Authority and a new signed certificate is returned. When it comes time to import the BIG-IP system with the updated certificate, you must ensure that the BIG-IP system has the appropriate Private Key for the certificate.

Recommended Actions

When importing the certificate and key to the BIG-IP system, ensure that the BIG-IP system has the appropriate Private Key for the certificate. Use the following section to determine that.

Additional Information

OpenSSL can be used to determine whether the private key and certificate are related.

Obtain the modulus for the SSL certificate

  • Syntax:

    openssl x509 -noout -text -modulus -in /config/filestore/files_d/<partition>_d/certificate_d/<name of the certificate>

  • Example:
    openssl x509 -noout -text -modulus -in /var/tmp/certificate.crt

Obtain the modulus for the SSL private key

  • Syntax:

    openssl <rsa|dsa|ec> -noout -modulus -in <path_to_key>/<key_name>

  • Example:
    openssl rsa -noout -modulus –in /var/tmp/privatekey.key

Compare the 'modulus' from these two commands. A matching certificate and private key will have the same modulus value.
