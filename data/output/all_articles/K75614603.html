Issue

Old Behavior

In versions prior to BIG-IP 11.4.0, not all Secure Sockets Layer (SSL) feature flags were included in all BIG-IP licenses.

New Behavior

Beginning in BIG-IP 11.4.0, SSL licensing was changed so that BIG-IP licenses include the following SSL feature flags:

  • perf_SSL_Mbps
  • perf_SSL_per_core
  • perf_SSL_Total_TPS
  • perf_SSL_cmp

Note: In BIG-IP 10.1.0, the perf_SSL_Mbps feature flag was changed from an integer to a boolean data type. As a result of this change, the perf_SSL_Mbps flag no longer indicates a measure of data transfer speed for SSL. The flag determines only whether SSL functionality is enabled on the system; any value (other than 0) enables SSL functionality. For example, there is no functional performance difference between the following two flags and both flags enable SSL on the system:

  • perf_SSL_Mbps : 2000
  • perf_SSL_Mbps : 1

Impact

BIG-IP licenses must contain all four SSL feature flags in 11.4.0 and later. Systems that do not have all SSL feature flags present may not have full SSL functionality.

Recommended Actions

  • If you are running BIG-IP 11.4.0 or later and you licensed the system anytime before June 23, 2015, you should verify that your license contains all four SSL feature flags. If your license does not contain all four SSL flags, you can obtain the necessary flags by renewing the BIG-IP license. To do so, run the tmsh install /sys license command.
