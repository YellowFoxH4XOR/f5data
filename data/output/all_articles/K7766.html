Known Issue

This is the result of a known issue. Whether in active or passive mode, the FTP monitor causes a memory leak each time it initiates a connection to the node it is monitoring. As a result, the TMM memory is exhausted until the connection reaper starts removing the connection entries when TMM memory' threshold has been reached.

F5 Product Development tracked this issue as CR81113, and it was fixed in BIG-IP LTM versions 9.3.1 and 9.4.2. For information about upgrading, refer to the LTM release notes.
