Topic

This article discusses the Digital Diagnostic Monitoring (DDM) feature on the F5 VELOS and rSeries systems. For information about DDM on a BIG-IP hardware products, refer to K83253027: Overview of the BIG-IP Digital Diagnostic Monitoring feature.

Description

The DDM feature provides real-time operating measurements for a pluggable optical transceiver, including the following:

  • Optical transmit output power
  • Optical received input power
  • Transceiver supply voltage

F5 referred to the following industry standards to implement this feature:

  • SFF-8636: Management Interface for Cabled Environments
  • SFF-8472: Diagnostic Monitoring Interface for Optical Transceivers

Both standards cover optical transceivers such as QSFP28, QSFP+, SFP, SFP+ and SFP28. For a list of F5 branded optical transceivers with DDM that are supported on the F5 VELOS and rSeries systems, refer to K6097: Specifications of the Fiber Gigabit Ethernet SFP, XFP, SFP+, QSFP+, and QSFP28 module ports on BIG-IP system platforms.

The VELOS and rSeries systems automatically run the DDM feature on every optical transceiver you insert into the VELOS and rSeries systems. You do not need to enable the feature, and the only way you can disabled it is by setting the DDM polling frequency to zero.

The default value for the DDM polling frequency 30 seconds. For information about configuring the DDM polling frequency, refer to the Configure the DDM polling frequency section of this article.

As the DDM feature runs on each transceiver, the system associates the information it obtains with port groups instead of interfaces. The system uses the fpgamgr process to periodically poll the measurements and any latched warnings or alarms the transceiver detects.

Procedures

  • View DDM output
    • View the DDM measurements for a specific portgroup
    • View a specific DDM measurement for all portgroups
  • Configure the DDM polling frequency

View DDM output

There are two ways to view DDM output: all measurements for a specific portgroup or all portgroups for a specific measurement type.

View the DDM measurements for a specific portgroup

  • As the VELOS partition or the rSeries administrator user, enter the following command syntax:

    show portgroups portgroup <portgroup> state ddm

    For example, to view the DDM measurements for portgroup 1/1, you enter the following command:

    show portgroups portgroup 1/1 state ddm

    The system returns output similar to the following example:

View a specific DDM measurement for all portgroups

  • As the VELOS partition or rSeries administrator user, enter the following command syntax :

    show portgroups portgroup state ddm <measurement type>

    Measurement type can be one of the following:

    • bias: Transceiver laser bias statistics in Amps
    • rx-pwr: Transceiver input power statistics in dBm
    • temp: Transceiver temperature statistics in degree Celsius
    • tx-pwr: Transceiver output power statistics in dBm
    • vcc: Transceiver internally measured supply voltage bias statistics in Volts

    For example, to view the optical output power for all portgroups, you enter the following command:

    show portgroups portgroup state ddm tx-pwr

    The system returns output similar to the following example:

Configure the DDM polling frequency

To configure the DDM polling frequency, perform the following procedure:

  1. As the VELOS partition administrator user, log in to the VELOS command line of the partition floating IP address. If you are doing this for the rSeries system, log in to the rSeries command line as the rSeries administrator user.
  2. To view the existing DDM polling frequency configuration, type the following command:

    show running-config portgroups portgroup config

    The system returns output similar to the following example:

    portgroups portgroup 1/1
     config mode MODE_100GB
     config ddm ddm-poll-frequency 30
    !
    portgroups portgroup 1/2
     config mode MODE_100GB
     config ddm ddm-poll-frequency 30
    !

  3. Enter the configuration mode terminal by entering the following command:

    config

  4. Set the DDM polling frequency in seconds by entering the following command syntax:

    portgroups portgroup <portgroup number> config ddm ddm-poll-frequency <seconds>

    For example, to set the DDM polling frequency of portgroup 4/1 to 0, which disables DDM for that portgroup, you enter the following command:

    portgroups portgroup 4/1 config ddm ddm-poll-frequency 0

  5. Save the change by entering the following command:

    commit

  6. Exit the configuration mode terminal by entering in the following command:

    exit

  7. If you have disabled DDM for a portgroup and you want to re-enable it, repeat steps 1 through 5 while replacing the polling frequency with an integer other than zero.

    F5 recommends setting the DDM polling frequency to the default value of 30 seconds.
