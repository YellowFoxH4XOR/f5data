To receive an email notification only when a snapshot operation fails (not when a snapshot operation starts or completes), perform the following procedure: 

  1. Log in to the ARX CLI.
     
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter configuration mode by typing the following command:

    config
  4. Specify the email role you want to configure by typing the following command, where [role name] is the name of the role you want to configure:

    email-event [role name] 

    For example:

    email-event tech-support
     
  5. Disable email notifications for all snapshot events by typing the following command:

    no group snapshot
     
  6. Enable email notifications for snapshot operation failures by typing the following command:

    group snapshot event snapshot-op-fail
