Description

Error using Azure Backup with Azure BIG-IQ VE in version 8.0.0.1  

Azure Backup posting the following error message: 
Azure Backup Agent is not at a supported level for Azure Backup.

Environment

  • Azure BIG-IQ VE version 8.0 and higher
  • Azure Backup Agent

Cause

Undetermined what has caused the error, but it's benign and can be ignored.

Recommended Actions

The backup still worked despite the error. If you see this error, try the backup anyway and it should finish.
