Known Issue

This is the result of a known issue. Due to an issue with the plugin filter polling mechanism, the BIG-IP ASM system may experience excessive CPU and TMM utilization when the Tx statistics counter exceeds a large threshold.

F5 Product Development tracked this issue as ID 331104 (formerly CR106011) and it was fixed in version 9.4.6. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-9.4.4-94.0-HF3, issued for BIG-IP version 9.4.4, and in Hotfix-BIGIP-9.4.5-HF2 issued for BIG-IP version 9.4.5. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
