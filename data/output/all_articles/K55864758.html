Description

When using LTM traffic policies, BIG-IP LTM will not allow two different policies to be configured on a Virtual Server with the same controls, the following error message will be logged:

err mcpd[XXX]: 010716fd:3: Virtual Server '/Common/example_virtual_server' cannot contain policies with conflicting controls.

Environment

  • BIG-IP LTM Virtual Servers
  • Multiple BIG-IP LTM Traffic Policies managing the same LTM policy controls.

Cause

The BIG-IP software does not allow, by design, two LTM Policies to manage the same LTM Policy Controls. The basic problem is that two policies could end up having conflicting rules, in which case the result is undefined.

Recommended Actions

Combine all the same Control actions into a single LTM Policy.

None.
