The ARX system only uses one interface to send SNMP trap notifications. The ARX system will send SNMP trap notifications to the SNMP server host(s) using either the out-of-band (OOB) management interface or the VLAN in-band interface.

However, when the ARX system is configured with SNMP server hosts on both the OOB interface and the VLAN in-band interface, SNMP trap notifications are only sent to the SNMP server host(s) on the OOB interface. If the OOB interface becomes unavailable, the ARX system will send SNMP trap notifications to the SNMP server host(s) on the VLAN in-band interface.

F5 Product Development is tracking a request for enhancement to have the ARX system send SNMP trap notifications using both interfaces as ID 35496.
