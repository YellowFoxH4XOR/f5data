Description

After applying ASM policy to Virtual Server, MS Outlook client doesn't work.

Environment

  • Virtual Server with ASM policy
  • Only Outlook client stops working, OWA is working correctly.

Cause

BIG-IP ASM does not support RPC and MAPI over HTTP.

Recommended Actions

Bypass the BIG-IP ASM system for connections that use RPC/MAPI over HTTP. Here are the articles that describes this procedure for RPC:
K40345000: Bypassing the BIG-IP ASM system for connections that use RPC over HTTP (12.1.0 and later)  - this applies to all later versions 14.x, 15.x and 16.x
K17411: Bypassing the BIG-IP ASM system for connections that use RPC over HTTP (11.4.0 - 12.0.0)

Additional Information

ASM does not support Content-Type application/vnd.ms-sync.wbxml which is used for requests send to  /Microsoft-Server-ActiveSync. Please follow this article to ignore those requests:
K31213731: BIG-IP ASM may block requests with content type application/vnd.ms-sync.wbxml
