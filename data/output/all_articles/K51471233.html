Description

You wish to refer the following ASM System Variables by using the iControl REST API.

 Security >> Options : Application Security : Advanced Configuration : System Variables

Environment

  • BIG-IP ASM

Cause

None

Recommended Actions

Using the endpoint /mgmt/tm/asm/advanced-settings with filter you can refer to specific System Variables.

restcurl -u "admin:<admin-user-pass>" /mgmt/tm/asm/advanced-settings/?\$filter=name+eq+<name of System Variables> 

For example:

# restcurl -u admin:admin /mgmt/tm/asm/advanced-settings/?\$filter=name+eq+long_request_mem_percentage
