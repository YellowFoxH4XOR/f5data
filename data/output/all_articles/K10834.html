Known Issue

This is the result of a known issue. When installing or reimaging a platform that uses the Always-On Management (AOM), using a serial console baud rate that does not match the baud rate set for the AOM results in an inoperable console. Any mismatch between the baud rates in the AOM system and the host system on the serial console port may result in garbage characters appearing on the serial console port. The baud rate for the AOM and the serial console port are set by default to 19200.

Note: The BIG-IP 1600, 3600, 3900, 6900, and 8900 platforms use AOM.

Note: The BIG-IP serial console baud rate is reset to the default value of 19200 during installation, but the AOM baud rate is not changed. As a result, if a system's serial port and AOM baud rates matched at a rate other than 19200 prior to installation or re-imaging, the installation process will create the mismatch described here.

F5 Product Development tracked this issue as ID 242226 (formerly CR133271) and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to BIG-IP LTM, ASM, GTM, PSM, WebAccelerator, Link Controller, APM, WOM, or Edge Gateway release notes.

Workaround

You can work around this issue by aligning the baud rates set for the BIG-IP serial console port and the AOM. To do so, perform the following procedures:

Determining the baud rate of the BIG-IP system's serial port

To determine the baud rate of the BIG-IP system's serial port, type the following command from the BIG-IP command line:

bigpipe hardware baud rate

Determining the baud rate for the AOM system

To determine the baud rate for the AOM system, perform the following procedure:

  1. Log in to the AOM by typing the following command:

    ssh aom

    Note: If the BIG-IP system is not operational, you will be unable to access the AOM using SSH, and must instead access the AOM using the serial console and refer to the procedure detailed in K9403: Overview of the Always-On Management (AOM) subsystem.

  2. Display the current baud rate by typing the following command:

    bootenv baudrate

Modifying the AOM baud rate

To modify the AOM baud rate, perform the following procedure:

  1. Log in to the AOM by typing the following command:

    ssh aom

    Note: If the BIG-IP system is not operational, you will be unable to access the AOM using SSH, and must instead access the AOM using the serial console and refer to the procedure detailed in K9403: Overview of the Always-On Management (AOM) subsystem.

  2. Change the AOM baud rate by typing the following command where <rate> is the baud rate configured for the BIG-IP serial port:

    bootenv baudrate=<rate>

  3. While logged in to the AOM, reboot the AOM by typing the following command:

    reboot

    Note: If you cannot access the command line, you can also reboot the AOM by disconnecting the power cables from the power supplies, waiting five seconds, and then reconnecting the cables. This method should be used only as a last resort, since the BIG-IP system will not be shut down cleanly.

Modifying the BIG-IP serial port baud rate

To modify the BIG-IP serial port baud rate, type the following command from the BIG-IP command line where <rate> is the baud rate to which the AOM is set:

bigpipe hardware baud rate <rate>

Note: If necessary, reset your terminal baud rate to match the new rate and reconnect.

Resetting the baud rate for both the Host and AOM serial ports using the LCD panel

If a change is made in baud rate to either the Host, AOM, or both, you can use the LCD panel to reset the baud rate for both serial ports. To do so, perform the following procedure:

Note: Using the LCD panel is the fastest and easiest method to reset both serial ports to the same baud rate. This method is useful if you are unable to access the system using the management port and the baud rate is mismatched, preventing serial access.

  1. From the LCD panel, display the menu options by pressing the X button.
  2. Use the arrow keys to highlight System.
  3. Press the Check button.
  4. Use the arrow keys to highlight Serial Speed.
  5. Press the Check button.
  6. Use the arrow keys to highlight the baud rate of the Host serial port and the AOM serial port. Available options are:

    9600
    19200 - Default
    57600
    115200

  7. Press the Check button.

    You will now be able to log in to the system utilizing the serial port and the baud rate that you selected in Step 6.
