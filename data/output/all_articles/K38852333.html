Description

Important: The BIG-IP Image Generator Tool has reached end of software development (EoSD) and is no longer supported with active updates. F5 will not provide software fixes (hotfixes) or consulting services for a version that has reached the EoSD milestone.

You want to deploy a BIG-IP to a public cloud environment with a built-in engineering hotfix, using a published F5 Cloud Template.

You have been provided an engineering hotfix (EHF) by F5 Support, and want to use Cloud Templates to deploy VE instances with the hotfix preinstalled.

Environment
Either:

  • BIG-IP version supported by the BIG-IP Image Generator Tool
  • Public Cloud environment supported by the BIG-IP Image Generator Tool
    • Alibaba
    • Amazon AWS
    • Microsoft Azure
    • Google Cloud Platform (GCE)
  • Bring Your Own License (BYOL) or BIG-IQ licensing

Or:

  • BIG-IP version currently available in AWS Marketplace
  • Any licensing type, including Pay-As-You-Go (PAYG)

Cause
You can use the F5 BIG-IP Image Generator Tool to create custom images for F5 BIG-IP VE which include engineering hotfixes for BYOL or BIG-IQ deployments, or create clones of AWS Marketplace images for any licensing type.

Recommended Actions
For BYOL or BIG-IQ licensed deployments, consider using the BIG-IP Image Generator Tool. This can be used with any supported release and produces a ready-to-use image in a single step.

  1. Follow the instructions published in the README for F5 BIG-IP Image Generator Tool.
  2. When deploying using an F5 Cloud Template, specify the custom image created in the previous step.

For PAYG images, you can create cloned images which will still be tied to your AWS Marketplace subscription. This also works with non-subscription (BYOL) images, but is more involved than the above process.

  1. Launch a standalone instance using AWS Marketplace or an F5 Cloud Template. 
    Important: for PAYG you MUST select the license level you plan to use. For BYOL you MUST select a 2 boot location image.
  2. Upload the base version and EHF to the system.
  3. Install the engineering hotfix to slot HD1.2. Review K84205182: BIG-IP update and upgrade guide for assistance with this process.
  4. Follow the steps from K44134742: Considerations when cloning a BIG-IP virtual edition instance to prepare for cloning. The instance you are working on is the "clone template".
  5. After shutting down the instance, create an AMI using the instance. Note the new AMI ID.
  6. When launching or updating an F5 Cloud Template, specify the new AMI ID.
