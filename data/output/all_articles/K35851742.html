K35851742: F5 SSL Orchestrator may change the source port when forward traffic to inline L2 Service

Description

F5 SSL Orchestrator may change the source port when forward traffic to inline L2 Service.
For example:

From the client to F5 SSL Orchestrator, the source port is 12345, the destination port is 443.
From the F5 SSL Orchestrator to the inline L2 Service, the source port is 23456, the destination port is 80.
From the inline L2 Service to the F5 SSL Orchestrator, the source port is 23456, the destination port is 80.
From the F5 SSL Orchestrator to the server, the source port is 12345, the destination port is 443.

Environment

  • F5 SSL Orchestrator
  • Topology
  • Inline L2 Service
  • Enable Port Remap

Cause

For the setting of "Enable Port Remap", we should enable it when the original destination port is different with the listening port on the inline L2 Service, F5 SSL Orchestrator change the destination port, due to the Clustered Multiprocessing (CMP) mechanism, the source port maybe changed, it is expected behavior.

Recommended Actions

.Change the source port / destination port should not impact the application, as it change back when send to the server.
You can disable "Enable Port Remap" if ncessary, and please make sure the inline L2 Service is able to handle the traffic with the original destination port.
