Environment

  • BIG-IP LTM

Cause

Your BIG-IP's Virtual Server or Servers are overloaded with high number or highly resources consuming connections, causing high usage of CPU.

Recommended Actions

2. As a temporary workaround you can disable most used VS on your BIG-IP:

  • On the Main tab, click Local Traffic --> Virtual Servers.
    The Virtual Server List screen displays a list of existing virtual servers.
     
  • On the menu bar, click Virtual Address List.
    This displays the list of virtual addresses.
     
  • In the Name column, locate the virtual address you want to disable.
     
  • Select the check box to the left of the virtual address name.
     
  • Click the Disable button.

3. To investigate source of high resource consuming traffic hitting Virtual Server, you can attempt to capture data using 'tcpdump' feature:

K411: Overview of packet tracing with the tcpdump utility

Additional Information

If problem remains after disabling most used Virtual Server or symptoms differs from presented output, please open Service Order by contacting F5 Networks Support.
