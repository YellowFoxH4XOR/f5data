Topic

You can configure the BIG-IP system to perform a boot from the network boot server using the command line, the Configuration utility, or the Switch Card Control Processor (SCCP).

SCCP-based platforms: 1500, 3400, 3410, 6400, 6800, 8400, 8800.

To perform a boot from a network boot server, perform one of the following procedures:

  • Configuring the BIG-IP system to perform a netboot using the command line (10.x - 11.1.0)
  • Configuring the BIG-IP system to perform a netboot using the Configuration utility (10.x - 11.1.0)
  • Configuring the BIG-IP system to perform a netboot using the SCCP

Note: To enable network boot on Always-On Management (AOM)-based platforms, refer to K9599: Configuring AOM-based BIG-IP platforms to boot from a network boot server.

Note: After the BIG-IP system has booted from the network once, it will reset itself to boot from its local hard drive for subsequent boots.

Configuring the BIG-IP system to perform a netboot using the command line (10.x - 11.1.0)

  1. Log in to the command line.
  2. To set the netreboot database variable, type the following command:

    tmsh modify sys db boot.netreboot value enable

  3. When you are ready to reboot the system, type the following command:

    reboot

Configuring the BIG-IP system to perform a netboot using the Configuration utility (10.x - 11.1.0)

  1. Log in to the Configuration utility.
  2. In the main navigation pane, click System.
  3. Click General Properties, or in BIG-IP 10.x, click Configuration.
  4. Select the Network Boot check box.
  5. To confirm that you want the system to be configured to boot from the network, click OK.
  6. Click Update.
  7. When you are ready to reboot, log in to the command line and reboot the system by typing the following command:

    reboot

Configuring the BIG-IP system to perform a netboot using the SCCP

  1. Log in to the command line.
  2. To connect to the SCCP using secure shell (SSH), type the following command:

    ssh sccp

  3. From the SCCP prompt, access the SCCP host console shell by typing the following command:

    hostconsh

  4. Display the SCCP menu by simultaneously pressing and holding the Shift, Esc, and 9 keys.
  5. From the SCCP menu, select option 4 --- Select Host subsystem boot mode: netboot from external server.
  6. From the SCCP menu, select option 7 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!).
  7. When prompted to confirm, type yes.
  8. From the SCCP menu, select option 1 --- Connect to Host subsystem console.

    The BIG-IP system now reboots from the SCCP and searches for a PXE server.
