K000147643: How do you account for the 'default' namespace, if you select "Select logs in specific namespace"?

Type
Support Solution
Published
2024-11-08
Updated
2025-12-01
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147643

Description

This article explains how to include the 'default' namespace when configuring the F5 Distributed Cloud Global Log Receiver to select logs from specific namespaces.
When configuring log streaming, users may want to ensure that logs from the 'default' namespace are included if they are only selecting specific namespaces.

Environment

  • F5 Distributed Cloud Global Log Receiver

Cause

None

Answer/Recommended Actions

  • The 'default' namespace is treated as any other namespace.
  • If you want to include logs from the 'default' namespace, you must explicitly add "default" to the list of specific namespaces when you select "Select logs in specific namespace".
