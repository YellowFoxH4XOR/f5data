K000135538: Illegal meta character shows incorrect hex values on BIGIQ event logs.

Type
Support Solution
Published
2023-07-19
Updated
2023-07-19
Source
https://my.f5.com/manage/s/article/K000135538

Description

Difference in hex value for meta characters like "&" in Event logs on BIGIP and BIGIQ side.


Environment

  • BIGIP with remote logging to BIGIQ
  • BIGIQ (any version)
  • Event logs Blocked with "Illegal meta character"


Cause

(Bug alias 1315301) Incorrect Metachar Data for Violation Details in BIG-IQ


Recommended Actions

None


Additional Information

  • This BUG is only related too " Illegal meta character in value" violation i.,e meta characters in parameter value
  • if there any meta characters on parameter name ("Illegal meta character in parameter name" ) this shows correct value i.e. .
