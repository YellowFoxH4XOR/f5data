K000139047: Cannot schedule license report with error "URI path not registered. Please verify URI is supported and wait for /available suffix to be responsive."

Support Solution
Published
2024-03-27

2024-03-27

  • BIG-IQ Centralized Management: 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000139047

Description

When click the button 'Schedule' in the License Reports, will get the following error message.

"URI path not registered. Please verify URI is supported and wait for /available suffix to be responsive."

Environment

  • BIG-IQ CM

Cause

The Licenses Report Scheduler is already running a task.

Recommended Actions

Need to delete the existing task then restart restjavad.

1. Get the existing task

#restcurl /shared/task-scheduler/scheduler | jq '.items[] | select(.name | contains("/cm/device/tasks/licensing/report-schedules")) | {selfLink}'

For Example:

#restcurl /shared/task-scheduler/scheduler | jq '.items[] | select(.name | contains("/cm/device/tasks/licensing/report-schedules")) | {selfLink}'

{

 "selfLink": "https://localhost/mgmt/shared/task-scheduler/scheduler/5eea7177-0ca7-3320-9ea2-9ba3023eb6b5"

}

2.Delete this task

#restcurl -X DELETE <selfLink>

For Example:

#restcurl -X DELETE /shared/task-scheduler/scheduler/5eea7177-0ca7-3320-9ea2-9ba3023eb6b5

3.Restart restjavad process

#bigstart restart restjavad
