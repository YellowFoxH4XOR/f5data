Description

The find_error.pl script is not triggering on the STRING, when using the logger command.

Example:

logger -p local0.info "STRING"

Environment

  • BIG-IP
  • find_error.pl script

Cause

In newer versions of BIG-IP, the logger command can not be used as a test trigger for the find_error.pl script

Recommended Actions

The find_error.pl script will trigger on the STRING (or token) specified.

See K6977: Using the find_error.pl script to capture tcpdump files on a BIG-IP system

Additional Information

To test the trigger function, you can use 'Tcpdump' as the STRING (or token) in the log file /var/log/ltm.
