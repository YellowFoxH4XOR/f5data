Issue

Error Message

crit tmm[<PID>]: 01010020:2: MCP Connection <action>, exiting

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <action> is either closed, aborted, or expired.

For example:

crit tmm[8397]: 01010020:2: MCP Connection closed, exiting

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The BIG-IP system experiences connectivity problems between the mcpd and tmm processes.
  • The mcpd process is not running.

Impact

As a result of losing connectivity with the mcpd process, the tmm process restarts and attempts to re-establish the connection. The BIG-IP system is unable to process traffic while the tmm process restarts, and a failover event occurs if the system is configured for high availability (HA).

Recommended Actions

  1. To ensure that the mcpd process is running, type the following command in the BIG-IP command line:

    tmsh show /sys service mcpd

  2. If the process in not in the run state, restart the process by typing the following command:

    tmsh restart /sys service mcpd

  3. If the message persists over time, you may have to reboot the BIG-IP system.
