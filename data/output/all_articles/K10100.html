Issue

Some back-end CIFS filers support case-sensitive file names, where file.txt and FILE.txt are stored as two different files. Other CIFS filers and file servers are case-insensitive. Therefore, the file names file.txt and FILE.txt refer to the same file.

By default, ARX does not enable case sensitivity for CIFS shares. If you attempt to import a CIFS share into a managed volume, and the back-end share contains duplicate files and directories when imported as case-insensitive, the import will fail with the following status message:
 
Error: Unresolvable case-blind name collision.
 
To determine which files and directories are causing the name collisions, open the share import report and locate the items marked with CC in the Type column.

For example:
Type      Path
-------- -------------------
[! F CC] /BLAH1.txt

You can prevent name collisions using several different methods. Before you reimport the share, perform one of the following four steps:
 
  • If there are only a few name collisions reported, you can manually rename the files and directories causing the collisions.
  • If you are adding the CIFS share using the ARX GUI, select the following two check boxes in the Add Share Wizard to automatically rename colliding files and directories on import:
    • Rename files with naming collisions on import
    • Rename directories with naming collisions on import
  • If you are adding the CIFS share using the ARX CLI, configure the share to automatically rename colliding files and directories on import. For specific steps, refer to the Configuring the share to automatically rename colliding files and directories on import section.
  • Configure the volume as case-sensitive for CIFS shares (not recommended). For specific steps, refer to the Configuring the volume as case-sensitive for CIFS shares section.
 
Configuring the share to automatically rename colliding files and directories on import
 
To configure the share to automatically rename colliding files and directories on import, perform the following procedure:
 
  1. Log in to the ARX CLI.
  2. Enable privileged mode by entering the following command:

    enable
     
  3. Enter global configuration mode by entering the following command:

    global
     
  4. Specify the volume you want to configure by entering the following command where [NameSpaceName] is the name of the namespace and [VolName] is the name of the volume:

    namespace [NameSpaceName] volume /[VolName]
     
  5. Specify the share you want to configure by entering the following command where [ShareName] is the name of the share:

    share [ShareName]
     
  6. Configure the share to rename colliding files at import by entering the following command:

    import rename-files
  7. Configure the share to rename colliding directories at import by entering the following command:

    Import rename-directories
 
 
Configuring the volume as case-sensitive for CIFS shares (not recommended)
 
Before configuring the volume as case-sensitive, ensure that both of the following conditions are met:

Important: If the following conditions are not met, do not perform the following procedure.
 
  • All back-end CIFS shares in the volume support case-sensitive names
  • All CIFS clients that will access the volume support case-sensitive names
 
To configure the volume as case-sensitive for CIFS shares, perform the following procedure:
 
  1. Log in to the ARX CLI.
  2. Enable privileged mode by entering the following command:

    enable
  3. Enter global configuration mode by entering the following command:

    global
  4. Specify the volume you want to configure by entering the following command where [NameSpaceName] is the name of the namespace and [VolName] is the name of the volume:

    namespace [NameSpaceName] volume /[VolName]
     
  5. Enable case-sensitive filenames for CIFS shares by entering the following command:

    cifs case-sensitive
