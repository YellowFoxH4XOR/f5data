Description

You would like to recovery or verify the exclusion list for the always connected mode in a BIG-IP APM connectivity profile for the edge client


Environment

BIG-IP APM

Cause

Expected behavior

Recommended Actions

The exclusion list can be recovered from a Windows client at the following registry location


HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\F5 Networks\RemoteAccess\AlwaysConnected\Exclusions
