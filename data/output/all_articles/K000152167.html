K000152167: BIG-IQ License Manager cannot license VE on KVM

Type
Support Solution
Published
2025-06-26
Updated
2025-09-30
Applies to
  • BIG-IQ
  • Virtual Editions
  • KVM
Source
https://my.f5.com/manage/s/article/K000152167

Description

BIG-IQ License Manager cannot license a VE on KVM.

The error "Not a valid F5 license" is presented.

Environment

  • BIG-IQ License Manager
  • BIG-IP VE deployed on KVM or Proxmox (KVM-based)

 

Cause

VE configuration in KVM environment missing 'args: -machine smbios-entry-point-type=32' line.

 

Recommended Actions

  1. shut down the VM
  2. edit '/etc/pve/qemu-server/<qmid>.conf' and add 'args: -machine smbios-entry-point-type=32' line.
  3. power up the VM then license

 

Additional Information

Proxmox UUID lost after changing machine type
