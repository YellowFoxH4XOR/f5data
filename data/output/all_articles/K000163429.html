K000163429: The certificate serial number is displayed in decimal on BIG-IP 21.1.

Support Solution
Published

Updated
2026-09-28
Applies to

Source

Description

The certificate serial number is displayed in decimal on BIG-IP 21.1.


 

Environment

BIG-IP 21.1.0.

A certificate is present on the system.

"tmsh list sys file ssl-cert <certificate>" displays the serial number.

BIG-IP 17.5 displays the same certificate serial number in hexadecimal format.


Example:

17.5.1.8

===================

root@(big-ip)(cfg-sync Standalone)(Active)(/Common)(tmos)# list sys file ssl-cert test serial-number

sys file ssl-cert test {

serial-number 3f:78:6e:f5:28:37:e1:f1

}


21.1.0.1

===================

root@(big-ip)(cfg-sync Standalone)(Active)(/Common)(tmos)# list sys file ssl-cert test serial-number

sys file ssl-cert test {

serial-number 4573527420815532529

}


Cause

Bug ID2503861: On 64-bit mcpd builds, certificate serial-number displays in decimal instead of hex.


 

Answer/Recommended Actions

Product Engineering confirmed that this is a cosmetic defect, not a functional certificate-processing issue. No configuration change is required. Continue operating the system normally and upgrade to a software release containing the Bug ID2503861 fix when available.
