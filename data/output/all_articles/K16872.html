Security Advisory Description

Unspecified vulnerability in the Java Runtime Environment (JRE) in IBM Java 5.0 before 5.0 SR16-FP3, 6 before 6 SR14, 6.0.1 before 6.0.1 SR6, and 7 before 7 SR5 allows remote attackers to affect availability via unknown vectors. (CVE-2013-4002)

Impact

The vulnerable software is on the system, however it is not exposed with any configuration. It is possible from a local shell that an attacker could take advantage of this vulnerability, but access level requires a privileged user. There are no known network access vectors for this issue.

Security Advisory Status

F5 Product Development has assigned ID 481806 (BIG-IP), ID 481806-1 (BIG-IQ), and ID 530276-1 (Enterprise Manager) to this vulnerability, and has evaluated the currently supported releases for potential vulnerability.
