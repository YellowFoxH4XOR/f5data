Known Issue

Description

The BIG-IP system may incorrectly report an interface as disabled.

This issue occurs when all of the following conditions are met:

  • An unconnected interface is administratively disabled from either the Configuration utility or the command line.
  • The configuration is saved using the bigpipe save or tmsh save sys config commands, and services are restarted using the bigstart restart command.
  • The interface is subsequently re-enabled.

The BIG-IP system continues to report the interface as disabled, instead of down.

Impact

You may not be able to distinguish a disconnected interface from an administratively-disabled interface.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • An unconnected and re-enabled interface is incorrectly listed as disabled, as demonstrated in the following examples:

    • In the Configuration utility, on the Network > Interfaces > Interfaces List screen:

      DISABLED 1.6

    • From the command line, in the output of the bigpipe interface command:

      1.6  DS  1000 FD      0      0    0    0      0      0    0

    • From the command line, in the output of the tmsh show net interface command:

      1.6   disable       0     0     0     0      0      0      0

Workaround

To work around this issue, you can perform one of the following procedures:

Connect and re-enable the interface

Impact of workaround: None

If the interface is connected to another device and detects link activity when it is enabled, the status is correctly reported as enabled.

  1. Connect the affected interface to another device using an appropriate cable.
  2. Log in to the BIG-IP command line.
  3. Enable the interface by using one of the following command syntax examples, where <X.X> is the number of the affected interface:

    bigpipe interface <X.X> enable

    tmsh modify net interface <X.X> enabled

Restart services and re-enable the interface

Impact of workaround: You must restart all services, resulting in a brief traffic interruption.

  1. Log in to the BIG-IP command line
  2. Save the configuration and restart services by entering either of the following commands:

    bigpipe save; bigstart restart

    tmsh save sys config ; bigstart restart

  3. Enable the interface by using one of the following command syntax examples, where <X.X> is the number of the affected interface

    bigpipe interface <X.X> enable

    tmsh modify net interface <X.X> enabled
