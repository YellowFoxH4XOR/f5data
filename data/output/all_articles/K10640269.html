Topic

You should consider using this procedure under the following condition:

  • You are using the kubectl utility to view the Kubernetes configuration for NGINX Controller.

Description

NGINX Controller uses the kube-system and the nginx-controller namespaces for the Kubernetes configuration; however, the majority of the NGINX Controller configuration is contained within the nginx-controller namespace. NGINX Controller does not set a default context for the kubectl utility, so, for each kubectl command you use, you must also specify the namespace using the -n option. To work around this limitation, you can set nginx-controller as the default namespace within the $HOME/.kube/config file.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have NGINX Controller 2.8 or later installed.
  • You have command-line access to the NGINX Controller system.

Procedures

Setting nginx-controller as the default namespace for the kubectl utility

The $HOME/.kube/config file is used to configure access to the Kubernetes cluster. You can edit the file directly, but, to avoid syntax errors, you should do so using the kubectl utility.

Impact of procedure: Configuration errors in the $HOME/.kube/config file can prevent kubectl utility access to the Kubernetes cluster. F5 recommends copying the current configuration file to a safe location prior to making any changes.

  1. Log in to the command line of the NGINX Controller system.
  2. Copy the existing $HOME/.kube/config file to a safe location.
  3. Set the default namespace to nginx-controller by entering the following command:

    kubectl config set-context --current --namespace=nginx-controller

  4. Confirm the change by entering the following command:

    kubectl config view --minify

    The output appears similar to the following example. Look for the namespace: nginx-controller line:

    apiVersion: v1
    clusters:
    - cluster:
        certificate-authority-data: DATA+OMITTED
        server: https://192.0.2.1:6443

    contexts:
    - context:
        cluster: NGINX-CONTROLLER
        namespace: nginx-controller
        user: kubernetes-admin
