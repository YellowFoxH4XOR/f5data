K03275122: Unable to access BIG-IP system via Configuration Utility and attempts to restore it fail. Blank grey page or 404 error is seen instead of login page

  • BIG-IP LTM: 13.X.X, 13.0.X, 12.1.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.0, 13.0.1, 13.0.0, 13.1.X, 12.1.5, 12.1.4, 12.1.3, 12.1.2, 12.1.1, 12.1.0, 12.1.6
Source
https://my.f5.com/manage/s/article/K03275122

Description
Configuration Utility inaccessible. A 404 error or blank grey page is returned when attempting to access the GUI. Attempts to restore service with commands similar to the following fail:
killall -9 httpd
tmsh restart sys service httpd tomcat

The following commands return results:
zgrep -i '%tmui' /var/log/audit*
zgrep -i '%tmui' /var/log/ltm*

Log entries similar to the following are seen in the results of these commands:
audit.1:Jul  6 01:23:45 bigip1 notice tmsh[12345]: 01420002:5: AUDIT - Cannot load user credentials for user "%tmui" Current session has been terminated.
ltm.1:Jul  6 01:23:45 bigip1 notice tmsh[12345]: 01420003:5: Cannot load user credentials for user "%tmui" Current session has been terminated.

Environment

  • BIG-IP system prior to version 14.1

Cause
Log entries similar to these are an indication of possible compromise

Recommended Actions

Follow the guidance given in K11438344: Considerations and guidance when you suspect a security compromise on a BIG-IP system
