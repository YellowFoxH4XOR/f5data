Known Issue

Viewing Stream Control Transmission Protocol (SCTP) profile statistics may cause an mcpd memory leak.

This issue occurs when the following conditions are met:

  • You associate an SCTP profile with a virtual server.
  • You use the Traffic Management Shell (tmsh) utility or the Configuration utility to display the SCTP profile statistics. To impact system performance, you would need to display the SCTP statistics thousands of times.

Impact

After an extended period of time, system performance may degrade, and the system may eventually become unresponsive or reboot due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The tmsh show sys memory command indicates that mcpd memory consumption steadily increases over time.
  • The BIG-IP system unexpectedly fails over to another system in the device group.
