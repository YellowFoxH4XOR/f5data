K000153088: Unable to access the web gui and there is no response from the api call's.

Type
Support Solution
Published
2025-08-20
Updated
2025-08-20
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000153088

Description

F5 users may experience unresponsiveness of the web GUI and API calls while CLI access remains available. Attempts to access the GUI or perform API operations result in timeouts or no response. System logs frequently show java.net.ConnectException: Connection refused errors in restjavad logs. Restarting httpd or restjavad services may temporarily restore access, but the issue can recur.

 

Environment

  • Typical configuration: Standard memory allocation for restjavad (384 MB) and tomcat (0 MB)
  • Extended system uptime (over 240 days) may increase likelihood of occurrence

 

Cause

A known bug (Bug ID991829) in restjavad can cause excessive "Connection Refused" errors and increased memory usage, leading to degraded performance of the web GUI and API—especially if the heap size is low or the system has been running for an extended period without a reboot.

Recommended Actions

  • Reboot the affected standby device to restore functionality
  • Increase memory allocation for restjavad and tomcat to mitigate symptoms
  • Upgrade to BIG-IP version 17.5.0 or later to permanently resolve the bug
  • Monitor system post-reboot for stability
  • Apply similar memory adjustments and reboot to peer device if needed

 

Additional Information

The bug does not consistently affect all devices, even with similar configurations and workloads

No official workaround exists; memory allocation increases may only alleviate symptoms

Issue was minimally impactful until recently; may be present but unnoticed on other devices

Case closure requested after successful reboot and monitoring period
