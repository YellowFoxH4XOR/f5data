Description

When deploying BIG-IP APM App Tunnels, administrators may require detailed information about the f5vpn_setup.exe client component. Common questions include:

  • Where does f5vpn_setup.exe need to be installed? 
  • Why is it required? 
  • Which files are installed and where? 
  • What system resources does it access (e.g., hosts file)? 
  • What documentation is available for App Tunnel client components? 

Environment

  • Product: BIG-IP Access Policy Manager (APM) 
  • Version: 17.x
  • Feature: App Tunnel (Application Tunnel) 
  • Client OS: Windows
  • Deployment: App Tunnel access via Webtop, using f5vpn_setup.exe as the client installer

Cause

The f5vpn_setup.exe is a prerequisite installer for App Tunnel client components. It is required to install and register the necessary files and services that enable App Tunnel functionality on the client system. 

Recommendations

Installation Location

f5vpn_setup.exe and its components are installed in %windir%\Downloaded Program Files.

Purpose

The installer provides the required elements to install and operate App Tunnel client components, enabling secure access to backend systems through BIG-IP APM.

Files Installed and Locations

The following files are typically installed in `%windir%\Downloaded Program Files`:

  • F5ElHelper.dll
  • F5ElHelper.exe
  • F5ElHelper64.dll
  • f5instd.exe
  • F5InstH.exe
  • F5InstP.dll
  • F5InstP64.dll
  • f5LogViewer.exe
  • f5tunsrv.inf
  • f5unistall.exe
  • f5vpn.exe
  • InstallerControl.dll
  • InstallerControl.inf
  • TunnelServer.exe
  • TunnelServerX.dll
  • uregsvr.exe
  • urSuperHost.dll
  • urxhost.dll
  • urxhost.inf
  • urxhostres.dll
  • urxshost.inf

 

System Access

The installer and App Tunnel components require access to:

  • %windir%\Downloaded Program Files - installation time to deploy components
  • %temp% directory - for writing to log files
  • %windir%\System32\drivers\etc\hosts - to modify the hosts file for tunnel operation
