Known Issue

This is the result of a known issue. The bigpipe config sync command reports the following error message when the BIG-IP ASM system is licensed, but the module is disabled:

Synchronizing Master Keys... Saving active configuration... unix dgram connect: Connection refused at /ts/packages/GenUtils.pm line 818 GenUtils::simple_syslog failed (no connection to syslog available at /ts/packages/GenUtils.pm line 818 ) at /ts/packages/GenUtils.pm line 825.

This error message occurs because the currently disabled BIG-IP ASM packages are prevented from writing to syslog.

F5 Product Development tracked this issue as ID 331467 (formerly CR113193), and it was fixed in BIG-IP 9.4.7. For information about upgrading, refer to the BIG-IP ASM release notes.

In addition, this issue was fixed in cumulative hotfix Hotfix-BIGIP-9.4.6-423.0-HF2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
