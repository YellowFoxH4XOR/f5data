Description

Guidance on exporting Firewall Rule configurations and Hit Count statistics from BIG-IP AFM, including details such as source IPs, destination IPs, IP protocol, and hit count. Also covers how to retrieve grouped IPs (Address-lists) referenced in Firewall Rules. Common issues include not finding CSV output files or not seeing expanded IPs for address lists in REST API output. 

Environment

  • BIG-IP AFM
  • Firewall Rules assigned to Contexts (Global, Virtual Server, Self IP)
  • Requirement to Export Rule configuration and/or Hit Count statistics
  • Use of REST API and TMSH command-line Interface
  • Address-lists (grouped IPs) referenced in Firewall Rules

Cause

This is a functional question about available methods to Export AFM Firewall Rules and Statistics. No technical issue or product defect is present. 

Answer/Recommended Actions

1. Export Rule Details via REST API:

# curl -s -k -u admin:<password> -H "Content-Type: application/json" -X GET "https://<management-IP>/mgmt/tm/security/firewall/rule-list?expandSubcollections=true" | jq -M

This command expands individual Rules, but does not inline the contents of referenced Address-lists.

 

2. Export Hit Count Statistics to CSV via REST API:
Change to your desired directory (e.g., 'cd /var/tmp') before running the commands:

# curl -s -k -u admin:<password> -H "Content-Type: application/json" -X GET "https://<management-IP>/mgmt/tm/security/firewall/rule-stat/stats" | jq -r '.entries | to_entries[] | .value.nestedStats.entries | [.action.description, .actualRule.description, .contextName.description, .contextType.description, .counter.value, .lastHitTimeFmt.description, .ruleListName.description, .ruleName.description, .ruleStatType.description, .useridValidation.description] | @csv' > rule_stats.csv

Add CSV header as needed:

# echo '"Action","Actual Rule","Context Name","Context Type","Counter","Last Hit Time","Rule List Name","Rule Name","Rule Stat Type","User ID Validation"' | cat - rule_stats.csv > output.csv

Check for the output files ('rule_stats.csv' and 'output.csv') in your chosen directory (e.g., '/var/tmp').

 

3. Export Rule Configuration and Statistics via TMSH:

# tmsh show running-config security firewall
# tmsh list security firewall rule-list
# tmsh show security firewall rule-stat
# tmsh show security firewall rule-stat field-fmt

 

4. Retrieve Grouped IPs (Address Lists) Referenced in Rules:
The REST API 'rule-list' output shows only the name/reference of address lists, not their contents. To retrieve all Address-lists and their member IPs:

# curl -s -k -u admin:<password> -H "Content-Type: application/json" -X GET "https://<management-IP>/mgmt/tm/security/firewall/address-list" | jq -M

To retrieve a specific Address-list by name:

# curl -s -k -u admin:<password> -H "Content-Type: application/json" -X GET "https://<management-IP>/mgmt/tm/security/firewall/address-list/~Common~my-address-list" | jq -M

Replace '/' with '~' in the partition path for the URL (e.g., '/Common/my-list' → '~Common~my-list').

 

5. For a Complete Export:
Combine the outputs from the REST API 'rule-list' and 'rule-stat' endpoints, and supplement with Address-list queries as needed.

Additional Information

  • When a Firewall Rule references an Address-list, the 'rule-list' API output will show only the Address-list name. To view the individual IPs, a separate API call to the Address-list endpoint is required.
  • This is expected behavior in the AFM data model; Address-lists are managed as separate objects.
  • CSV output files are created in the directory where the command is run. Ensure you have write permissions and check the correct directory for the files.
