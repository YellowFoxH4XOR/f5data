K15057236: Unable to form HA between BIG-IQ CM devices

Type
Support Solution
Published
2022-06-10
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K15057236

Description

  • Unable to form HA between BIG-IQ CM devices
  • Messages similar to the following are logged on /var/log/restjavad.0.log

    [/shared/ssh-trust-setup SshTrustSetupWorker] Setting up mutual SSH trust between 10.0.0.1 and 10.0.0.2.
    [/shared/ssh-trust-setup SshTrustSetupWorker] /usr/bin/f5-ssh-establish-mutual-ids has failed with status code 1. Stdout: Installed primary's public key on secondary using ssh-copy-id
    |
    /shared/ssh/root/known_hosts is not a valid known_hosts file.
    Not replacing existing known_hosts file because of errors

Environment

  • BIG-IQ CM
  • HA pair
  • SSH trust

Cause

The file /shared/ssh/root/known_hosts contains not known hosts entries.

Example:

ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABgQC8e89NhO4vJDULGwfRmEqVTUVF1NR4ZrkmuSb2e4FflRcLkwjf3TAtuxM8NTAAAAB3NzaC1yc2EAAAABIwAAAIEA0aSn3oISQrIhdZFia7jcW+Cw  <-- NOt known host entry
10.0.0.3 ssh-rsa ZZZZB3NzaC1yc2EAAAABIwAAAIEAzqE5dcLyOjzzOFtuhdGpvPgMh9XKaboGNkAOTNkw1cTDB8TqX7dPTBdZipWe+1LsiNQ04OeOY/uxUd04hWBnI+CYU3NV1Pgf+jUQyoeD5
10.0.0.4 ssh-rsa TTTTB3NzaC1yc2EAAAABIwAAAIEA5MQD07WitdYSYMIiZ0Bs0MC/4M9KHAEqp/AgjhMnjzit3vSsKDgj9B6uMnOG0mmK+oZ+fkHnOoNmhO1ADe+LOiuUCoy8p4MFXK7DoEm++
 

Recommended Actions

 Manually deleting the entries in question.

  1. Connect to CLI
  2. Edit /shared/ssh/root/known_hosts file and remove the entries in question
  3. Save the changes
