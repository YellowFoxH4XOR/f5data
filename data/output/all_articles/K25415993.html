Description
TMM Cores with core type ** SIGFPE ** and the panic string:

panic: ../kern/page_alloc.c:736: Assertion "vmem_hashlist_remove not found" failed.
when changing a virtual server port list to a port.

Environment

  • BIG-IP version 14, 15 or 16
  • using a port list on a virtual server

Cause
This is caused by 

Bug ID 1040361: TMM crashes during its startup when TMC destination port list attached/deleted to virtual server

Recommended Actions

Please see bugtracker for additional details and recommended actions.
