Security Advisory Description

JSON parser function does not protect against out-of-bounds memory accesses or writes. (CVE-2021-22973)

Impact

The Traffic Management Microkernel (TMM) may exit and restart while processing JSON payload with iRules LX commands, leading to a failover event.

Security Advisory Status
