Description

When trying to authenticate via serial console or ssh after we input the username root or admin we are not able to input the password and the console outputs "Login incorrec" (incorrectly spelled).

When trying to authenticate to the Configuration Utility the page displays "starting webserver".

Environment

Upgraded BIG-IP LTM from 12.1.2 to 13.1.5

Cause

In bigip.conf the radius-server object is missing from the configuration.  An example of a correct configuration:

auth radius /Common/system-auth {
    servers {
        /Common/system_auth_name1
    }
}
auth radius-server /Common/system_auth_name1 {
    secret $M$2W$LEDHmr6+HcRNwq6H07zt9w==
    server 10.0.0.1
}
auth source {
    fallback true
    type radius
}

Recommended Actions

  1. Boot back to the 12.1.2 volume
  2. Delete the 13.1.5 volume
  3. Change the authentication back to local
    1. Navigate in the Configuration Utility to System -> Users
    2. Click the Authentication tab near the top
    3. Click the Change button at the bottom of this page
    4. In the User Directory field set the dropdown box to Local
    5. Click the Finish button at the bottom of the page
  4. Perform the upgrade again to a new volume
