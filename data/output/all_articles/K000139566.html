Description

You have configured DNS profile with the DNS logging profile attached per K65762138: Configuring BIG-IP DNS to log dns queries and responses

However there is no DNS query log when DNS query arrives.

Environment

  • BIG-IP DNS

  • DNS logging

  • Rapid Response Mode is enable in the DNS profile

Cause

This is expected. When you enable the Rapid Response Mode for a DNS profile, only the GSLB and DNS Express features function in the DNS profile; other profile options including DNS logging does not work.

Recommended Actions

Disable the Rapid Response Mode if you need the DNS logging to take effect.
