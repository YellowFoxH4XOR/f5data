K7974: Microsoft Windows Vista clients cannot create or reply to emails in Microsoft Outlook Web Access

Applies to

  • FirePass: 6.0.2, 6.0.1
Source

Topic

Microsoft Window Vista clients may be unable to perform the following actions when they access Microsoft Outlook Web Access:

  • Compose or reply to an email message
     
  • Change settings in the Outlook Web Access Options folder
     
  • Create Outlook objects such as contacts, appointments, or notes

These issues are addressed by a Microsoft Exchange Server hotfix, and are unrelated to the FirePass controller. 

For more information about this issue, including download information for the Microsoft Exchange Server hotfix, refer to the following web site:

http://support.microsoft.com/default.aspx/kb/911829
