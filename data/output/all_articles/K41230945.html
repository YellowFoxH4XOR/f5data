Topic

You should consider using this procedure under the following condition:

  • You want to display the differences between two specified single configuration files (SCF) using the TMOS Shell (tmsh).

Description

The SCF feature allows you to define all BIG-IP configuration elements in a single, flat file, using tmsh. Using the SCF feature, you can create an SCF file from one BIG-IP system and use the file to configure additional BIG-IP systems. The SCF feature is useful when you want to configure a new BIG-IP system.

In some cases you may need to display the differences between SCF files. For example, you may need to compare two SCF files line by line and determine which file contains a new configuration element. To display the differences between SCF files you can use the tmsh sys config-diff command. The config-diff command displays the SCF output side-by-side and indicates configuration differences using the greater than sign (>).

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have access to tmsh.

Procedures

Displaying differences between SCF files

To display the differences between two specified SCF files, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by running the following command:

    tmsh

  2. Display the SCF files that are located on the system (in the default directory /var/local/scf/) by typing the following command:

    list /sys config file

    For example, the output may appear similar to the following example:

    SCF-1
    SCF-2
    SCF-3

  3. Display the differences between two specified SCF files by using the following syntax:

    show /sys config-diff <SCF_filename> <SCF_filename>

    For example, the following command output displays the differences between SCF-1 and SCF-2, and shows that the SCF-2 file includes configuration elements (a node and pool) that are not contained in the SCF-1 file:

    Note: The command output is truncated for brevity.
