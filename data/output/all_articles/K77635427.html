Issue

Error Message

notice big3d[<PID>]: 012b3007:5: SSL Context created using minimum TLS version <TLS_version>, SSL cipher list <cipher_list>.

In this error message, note the following:

  • <PID> is the process ID for the big3d process
  • <TLS_version> is the version of the Transport Layer Security (TLS) protocol
  • <cipher_list> is the list of ciphers that is set for the iQuery SSL Context

For example:

notice big3d[4633]: 012b3007:5: SSL Context created using minimum TLS version tlsv1, SSL cipher list 'AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA:!AES128:-SHA1:AES256-SHA'.

Message Location

You may encounter this message in the following location:

  • The /var/log/gtm file

Description

This message occurs when the following condition is met:

  • The big3d process creates SSL Context for iQuery connections as part of the normal start up sequence.

The big3d process provides metrics collection data on behalf of the BIG-IP DNS system using the iQuery protocol. This notice message is generated during the big3d process start up, and displays the current SSL Context set in the big3d.ssl.cipherlist and big3d.minimum.tls.version system variables.

Impact

There is no impact. You can safely ignore this error message.
