Topic

You should consider using this procedure under the following condition:

  • You want to customize a BIG-IP APM access policy error message that displays in a client browser.

Description

When a BIG-IP APM access policy error occurs, the messages presented to clients may use technical terms to describe the error. The technical terms in an error message are intended to help the administrator identify, troubleshoot, and resolve the error. However, if the default technical definition is not preferred, you can customize the message.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to perform advanced customization of access policies on the BIG-IP APM system.

Procedures

To watch a video demo of this procedure, go to Customizing BIG-IP APM access policy error messages.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Access > Profiles / Policies > Customization > General.

    Note: For BIG-IP 11.6.x through 12.x, go to Access Policy > Customization > General.

    For BIG-IP 11.5.x and earlier, navigate to Access Policy > Customization > Advanced.

  3. Under Form Factor: Full/Mobile Browser, select the Text tab.

    Note: For BIG-IP 11.5.x and earlier, click the Localization tab.

  4. In the folder tree, navigate to the object you want to modify.

    For example, navigate to Customization Settings > Access Profiles > <access_profile_name> > Error Messages.

  5. Select the category for the error message you want to customize. For example, General Errors.
  6. In the Language list, select the language of the error message you want to customize.
  7. In the Value column, locate the message you want to edit, select the message text, and enter your preferred message text.
  8. Select Save.
  9. Apply your access policy to implement the changes.
