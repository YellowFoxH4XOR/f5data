K000158771: Unable to Access OAuth Provider via GUI: "URI path not registered" Error

Type
Support Solution
Published
2025-12-30
Updated
2025-12-30
Source
https://my.f5.com/manage/s/article/K000158771

Description

While trying to view or access the OAuth provider's section, the following error is observed in system logs and/or the GUI:

URI path /tm/access/oidc/discover not registered. Please verify URI is supported and wait for /available suffix to be responsive.

Symptoms include:

  • The OAuth provider list does not display in the GUI.
  • Attempting to access a specific OAuth server from the list shows correct object information, but the error persists.
  • The "refresh state" field is not populated.

Issue may occur only on the active device; standby device operates normally. 

Environment

  • BIG-IP APM provisioned
  • One or more OAuth providers configured
  • Software upgrade

Cause

The REST API endpoint for OAuth provider discovery (/tm/access/oidc/discover) is not registered or available due to a malfunctioning restjavad process, which may occur after a software upgrade or if restjavad becomes stuck.

Recommended Actions

To resolve this issue, restart the REST Java and Node services:

  1. Log in to the BIG-IP command line interface (CLI).
  2. Execute the following command: 
    bigstart restart restjavad restnoded
    • This action does not impact production traffic.

Normally, all services are restarted during an upgrade; however, manual intervention may be required if restjavad remains stuck.
