Topic

In BIG-IP 9.0 through 10.0.1, you can create local user accounts on the BIG-IP system using the f5adduser command.

Note: The f5adduser command was removed from the product in BIG-IP 10.1.0. In BIG-IP 9.4 and later you can utilize the bigpipe user command. For more information about the bigpipe user command type bigpipe user help at the command line.

Important: On SCCP systems running version 9.4.2 or earlier, do not create a user account that begins with root, such as root123. Creating a user account on these systems that begins with root will erase the SCCP password and management connectivity will be lost. For more information, refer to K7745: The SCCP password file is deleted when you create a user account that begins with root.

Note: You can also create and manage BIG-IP system user accounts using the browser-based Configuration utility. For more information, refer to the BIG-IP Network and System Management Guide.

When you use the f5adduser command, the BIG-IP system adds a user account to the local /etc/passwd file. The command also creates an entry in the bigdb database that specifies the user role.

You can use the f5adduser command to perform the following tasks:

  • Create a local user account
  • Assign a user role
  • Assign a password, or specify that the account is to have no password
  • Grant secure shell (SSH) console access to the account
  • For version 9.4.x, specify a partition name for the account

You can create multiple user accounts with a single command-line sequence. In this case, all user accounts that you create are assigned the same user role. If a specified user account already exists, the command displays an error.

Note: For more information about user roles, refer to the BIG-IP Network and System Management Guide.

Note: You cannot delete user accounts using the f5adduser command. To delete one or more user accounts from the BIG-IP system, use the Configuration utility.

Syntax and Options

For the syntax and options for the f5adduser command, refer to the man page on the BIG-IP system by typing the following at the Linux command prompt:

man f5adduser
