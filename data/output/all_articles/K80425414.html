Description

The tcpdump shows internal loopback IPs associated with virtual server, _aaa_ha_udp_.

frame.number timestamp (UTC) f5ethtrailer.vip source IP destination IP
2    2022-11-01 17:31:34    _aaa_ha_udp_127.7.0.1:0    1.1.1.254    10.10.10.101
3    2022-11-01 17:31:39    _aaa_ha_udp_127.7.0.1:0    127.1.1.254    127.7.0.1    

Environment

  • Pool includes FQDN nodes
  • F5 eth trailers enabled on Wireshark (link below)
  • Big-IP packet capture filtered by port and included the p flag
    • tcpdump -vni 0.0:nnnp port 1812 -s0 -w /var/tmp/port1812.pcap 

Cause

It's a combination of factors. The pool uses FQDN nodes and the p flag on the tcpdump captures this internal traffic. Then the F5 ethtrailers in Wireshark show this internal virtual server as _aaa_ha_udp_ which is associated with internal loopback IPs.

Recommended Actions

None

Additional Information

Configure the F5 Wireshark Plugin
