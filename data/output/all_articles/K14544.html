Known Issue

The tcl_platform iRules variable is not in the static:: namespace.

This issue occurs when either one of the following conditions is met:

  • You upgrade your BIG-IP system to 11.4.0, and the system has a configuration containing an iRule referencing the static::tcl_platform variable.
  • After upgrading to BIG-IP 11.4.0, your system has a configuration that contains an iRule referencing the static::tcl_platform variable.

Impact

If the iRule referencing the static::tcl_platform variable causes any runtime TCL exception, traffic may be disrupted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • F5 iHealth lists Heuristic H425497 on the Diagnostics > Identified > Medium screen.
  • A runtime TCL exception disrupts traffic after an upgrade to BIG-IP 11.4.0.
  • The iRule referencing the static::tcl_platform variable returns with no value.

Workaround

To work around this issue, you can add a line of iRules code in the RULE_INIT event. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click the name of the affected iRule.
  4. In the Definition text box, insert the following code in the first line of the RULE_INIT event:

    upvar #0 tcl_platform static::tcl_platform

    For example:

    when RULE_INIT {
    # SOL14544 workaround
    upvar #0 tcl_platform static::tcl_platform

    # Original-RULE_INIT-Lines-of-Codes-Are-Below

    }
