Recommended Actions

The answer to this question is always changing as new software, security fixes, and bugs are addressed in the software.  However, with regards to ensuring that you'll get assistance when contacting F5 Support. F5 recommends that you upgrade your BIG-IP to the most recent maintenance and point release of software available:  K2200: Most recent versions of F5 software.

Important: BIG-IP 15.1.x will reach end of life (EoL) at the end of 2024, and BIG-IP 16.1.x will reach EoL seven months after 15.1.x. For additional information, refer to BIG-IP 15.1.x and 16.1.x are reaching End of Technical Support soon! and K5903: BIG-IP software support policy.

  • Review whether or not the version you are on is supported,
    • K5903: BIG-IP software support policy
  • Identify your BIG-IP platform,
    • K13144: Determining the BIG-IP model and platform type (11.x - 17.x)
  • Check if your platform supports the software version you are looking for,
    • K9476: The F5 hardware/software compatibility matrix
  • Overview of BIG-IP upgrade paths,
    • K13845: Overview of supported BIG-IP upgrade paths and an upgrade planning reference

Additional Information

1. Common upgrade issue while installing or rebooting from the boot location installed new version is lack of disk space, especially the BIG-IP APM is in use. EPSEC database can be large and it will be in ucs file to restore to the boot location installed new version. When ucs file is more than 1 GB, the config installation may fail.
  • K21175584: Removing unnecessary OPSWAT EPSEC packages from the BIG-IP APM system 

 

2. If you want to receive the most recent security fixes within the same major version, you can update to the latest point release.
  • K9412: The BIG-IP release matrix
