Known Issue

The Traffic Management Microkernel (TMM) process may exit and restart when the RADIUS::avp replace iRules command is executed.

This issue occurs when all of the following conditions are met:

  • A virtual server is configured with an iRule that executes a RADIUS::avp replace command with only two arguments.

    For example:

    RADIUS::avp replace 31 32

  • Traffic is processed through the virtual server, and the RADIUS::avp replace command is executed.

Impact

The BIG-IP system temporarily fails to process traffic, and may fail over if configured as part of a high availability (HA) system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H522391 on the Diagnostics > Identified > Medium screen.
  • Your BIG-IP system generates a TMM core file to the /shared/core directory.
  • Your BIG-IP system fails over to the standby system if configured as part of a HA system.
