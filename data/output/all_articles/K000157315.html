K000157315: General Database error when creating APM Kerberos SSO object

Type
Support Solution
Published
2025-11-06
Updated
2025-11-06
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000157315

Description

When creating a new Kerberos SSO object in BIG-IP APM, users may encounter a "General Database error" in the GUI. This error is generic and does not provide specific details, but it can persist even after increasing memory allocations for Tomcat and restjavad services.

Environment

  • Product: BIG-IP APM

Cause

The use of unsupported special characters in the Kerberos account password can cause a "General Database error" when creating a Kerberos SSO object in BIG-IP APM

Recommended Actions

  • Avoid using unsupported special characters in passwords for Kerberos SSO objects on BIG-IP APM.
  • If you receive a "General Database error" during Kerberos SSO object creation, review and modify the password to remove any unsupported characters.
