Issue

Error Message

notice mcpd[<PID>]: 01070407:5: Removed information for Publication <publisherID> and filterType <address>

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <publisherID> is the message publisher.
  • <address> is a pointer address for the filterType.

For example:

notice mcpd[8307]: 01070407:5: Removed information for Publication stpd8314 and filterType 0x40000000

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A BIG-IP system process removes itself as a message publisher for certain types of messages.

Certain BIG-IP system processes connect to the mcpd process and register as a publisher for system messages. These processes can also remove themselves as a publisher for certain messages while continuing to be a publisher for other types of messages.

Impact

You can safely ignore this issue; it should not impact system performance.

Recommended Actions

None
