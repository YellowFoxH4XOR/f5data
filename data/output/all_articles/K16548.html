Known Issue

The Traffic Management Microkernel (TMM) may produce a core file with the following error message:

panic: Invalid Tcl recursion!

This issue occurs when all of the following conditions are met:

  • The BIG-IP configuration contains the following:
     
    • A virtual server with an assigned SIP profile
    • An SIP iRule that uses the LB::prime command
  • Server-side congestion occurs due to a large amount of traffic.
  • Large queues of undelivered proxied messages exist.

Impact

In rare situations, the BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting, and systems configured as part of a high availability (HA) group may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to the standby system, if configured for HA.
  • The system logs error messages to the /var/log/tmm* files that appear similar to the following examples:

    notice panic: Invalid Tcl recursion!
    notice ** SIGFPE **

  • The system logs error messages to the /var/log/messages file that appear similar to the following example:

    notice logger: Started writing core file: /var/core/tmm.0.bld2384.0.core.gz for PID 13897
    notice logger: Finished writing 236194271 bytes for core file: /var/core/tmm.0.bld2384.0.core.gz for PID 13897

  • The BIG-IP system generates TMM core files to the /var/core directory with a time stamp that correlates to the traffic interruption. These files appear similar to the following example:

    -rw-r--r-- 1 root root 226M Apr 13 15:09 tmm.0.bld2384.0.core.gz
