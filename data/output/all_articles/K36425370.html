Description

Users are not able to access an SNI virtual server and the following message appears in the LTM logs.

01260009:4: Connection error: ssl_hs_rxhello:10066: name not available (112)

Environment

  • Virtual Server configured with SNI
  • SNI required enabled in the Client SSL profile

Cause

You have enabled SNI required in the default Client SSL profile, however, the client is not sending any server name in the Client Hello message
 

Recommended Actions???

  1. In the Configuration Utility go to Local Traffic  ››  Profiles : SSL : Client, disable the  Require Peer SNI support option, if this is not what you intended for your configuration

  2. Confirm that the client is sending the server name in the Client Hello message, otherwise, the connection will be RST
