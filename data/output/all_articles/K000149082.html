K000149082: SSL Certificate Signing Request for a wildcard certificate with Basic Constraints and/or Key Usage parameters fails

Type
Support Solution
Published
2024-12-20
Updated
2025-03-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.0.0, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.X.X, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 17.1.2, 17.1.0, 17.1.1
Source
https://my.f5.com/manage/s/article/K000149082

Description

An attempt to create a SSL Certificate Signing Request for a wildcard certificate with Basic Constraints and/or Key Usage parameters via the BIG-IP Configuration Utility fails and results in the following error messages.

 

Configuration Utility error:

/var/log/ltm error:

"01020036:3: The requested Certificate Signing Request File (/Common/EXAMPLE) was not found."

Environment

  • BIG-IP
  • Traffic Certificate Management
  • Creating a SSL Certificate Signing Request (CSR) for a wildcard certificate with Basic Constraints and/or Key Usage parameters

Cause

Bug ID 1600853

Recommended Actions

NOTE: ID 600853 is fixed in version v17.5. If possible, upgrade to that release, which also has numerous fixes for other IDs and vulnerabilities.

  1. Create the CSR using either TMSH or bash.
  2. Using TMSH:
    • Key-size & name (IE: EXAMPLE in EXAMPLE.key) can be changed to preferred values.
      create sys crypto key EXAMPLE.key key-size 2048
    • Create the EXAMPLE.csr to pair with EXAMPLE.key; change/add values to match what is required.
      create sys crypto csr EXAMPLE.csr key EXAMPLE.key country US state Washington city Seattle organization "F5, Inc." ou "Global Services" common-name *.gs.example.com email-address email@your-domain.com subject-alternative-name "DNS:*.gs.example.com,DNS:www.example.com" key-usage "nonRepudiation,keyAgreement,keyEncipherment,dataEncipherment,digitalSignature" basic-constraints "critical,CA:true"
  3. Using bash:
    • Key-size & name (IE: EXAMPLE in EXAMPLE.key) can be changed to preferred values.
      tmsh create sys crypto key EXAMPLE.key key-size 2048
    • Create the EXAMPLE.csr to pair with EXAMPLE.key; change/add values to match what is required.
      tmsh create sys crypto csr EXAMPLE.csr key EXAMPLE.key country US state Washington city Seattle organization "F5, Inc." ou "Global Services" common-name *.gs.example.com email-address email@your-domain.com subject-alternative-name "DNS:*.gs.example.com,DNS:www.example.com" key-usage "nonRepudiation,keyAgreement,keyEncipherment,dataEncipherment,digitalSignature" basic-constraints "critical,CA:true"
  4. Validation Step:
    • From the BIG-IP Configuration Utility, navigate to System > Certificate > Management > Traffic Certificate Management > SSL Certificate List > EXAMPLE > Certificate Signing Request
