Topic

You should consider using the procedures described in this article under the following conditions:

  • You no longer need the software version installed on a boot location and want to ensure the software is no longer used.
  • You want or need to delete an unused boot location to free up disk space on a system running low on disk space and experiencing issues, such as:
    • You are unable to provision modules that require additional disk space.
    • You are unable to perform upgrades.

Note the following considerations:

  • Boot locations do not affect the space available in the device filesystem as shown by running the df -h command or as logged by the diskmonitor system ( to /var/log/ltm)
  • When you delete a boot location, any data from that volume that was saved to the /shared partition will not be deleted by this procedure. If you want to delete that data, you must delete it separately.
  • When you delete a boot location volume that has an associated application volume, the associated application volume is also permanently deleted.  For information about application volumes, refer to K17477: Disk usage by the BIG-IP modules with application volumes. 

Important: Performing the procedures detailed in this article will permanently delete the specified boot location volume, and you cannot reverse the deletion. All data on the boot location volume is deleted and any statistical or configuration data stored in an application volume associated with the deleted volume is also permanently deleted.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have an administrator role or root user access to the BIG-IP system.
  • You have access to the Configuration utility or TMOS Shell (tmsh).

Procedures

You can delete a boot location using either the Configuration utility or tmsh. To do so, perform one of the following procedures:

  • Configuration utility

    To watch a video demo of this procedure, go to K000159058: Delete a boot location on the BIG-IP system using the Configuration utility.

  • tmsh

Impact of procedures: The following procedures will permanently delete all data on the deleted boot location volume and any statistical or configuration data stored in an application volume associated with the deleted volume. There is no impact to traffic.

Configuration utility

View current boot locations

  1. Log in to the Configuration utility.
  2. Go to  System > Software Management > Boot Locations.
  3. On the Boot Locations tab, confirm the boot location you intend to delete  Note that if the Status for a boot location is Active you cannot delete it. You can only delete boot location volumes listed as Inactive. Additionally, if you have only one boot location listed (for example HD1.1), you cannot delete that location without first creating and activating a new one.

Delete boot location

  1. Go to  System > Disk Management and select the name of the disk.  For example HD1. (Most devices only have HD1).
  2. On the Logical Disk tab, under Contained Software Volumes, select the check box for the boot location volume that you want to delete.
  3. Under the Contained Software Volumes section, select Delete and select Delete again to confirm.

    Note: If the selected volume also has an associated Contained Application Volume, this action will automatically delete that volume at the same time. 

tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. List the currently installed volumes by entering the following command:

    list /sys software volume

    The output of the command appears similar to the following example:

    sys software volume HD1.1 {
        basebuild 0.0.2187
        build 0.0.2187
        media {
            HD1.1 {
                media hd
                size default
            }
        }
        product BIG-IP
        status complete
        version 14.0.0
    }
    sys software volume HD1.2 {
        basebuild 0.0.1645
        build 0.0.1645
        media {
            HD1.2 {
                media hd
                size default
            }
        }
        product BIG-IP
        status complete
        version 13.0.0
    }

  3. Delete the unwanted software volume using the following command syntax:

    delete /sys software volume <volume>

    For example, to delete volume HD1.2, enter the following command:

    delete /sys software volume HD1.2

    Note: If the selected boot location volume has an associated contained application volume, the associated volume will also be deleted.

  4. View the status of the volume deletion by entering the following command:

    list /sys software volume status

    While the volume is being deleted, the volume status will appear as deleting volumeset, and the command output appears similar to the following example:

    sys software volume HD1.1 {
        status complete
    }
    sys software volume HD1.2 {
        status "deleting volumeset"
    }

Additional Information

Important: BIG-IP uses the Linux LVM volume management software. You can find additional information on the usage of disk space can by using the pvs, vgs, and lvs commands. A boot location volume is implemented as a set of LVM logical volumes. Do not make any changes to the system with these commands.
