Known Issue

In rare instances, running the show cifs-service client-activity command may cause the ARX CLI and GUI to become unresponsive. Additionally, users may experience dropped connections and performance degradation.

F5 Product Development tracked this issue as ID 25326 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.

Important: Until this issue is resolved, F5 does not recommend running the show cifs-service client-activity command.

Workaround

You can restore services by reloading the ARX system.
