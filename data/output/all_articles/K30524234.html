Issue

Old Behavior

In versions prior to BIG-IP 12.0.0, HTTPOnly and Secure attributes are not enabled or configurable for the HTTP Cookie Insert persistence profile.

New Behavior

Beginning in BIG-IP 12.0.0, HTTPOnly and Secure attributes are enabled by default for the HTTP Cookie Insert persistence profile. The Secure attribute setting only applies to SSL connections.

F5 Product Development tracked this change as ID 383925.

Impact

Having the HTTPOnly Attribute set by default might cause some of your applications to not work as expected. This option is not accessible through non-HTTP APIs, such as JavaScript; cookie persistence may fail in this situation.

Recommended Actions

If your applications do not work as expected after upgrading, return functionality to the previous behavior by setting the HTTPOnly attribute to Disabled.
