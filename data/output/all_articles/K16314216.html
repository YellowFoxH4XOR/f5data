Description

  • Error message when creating a Client SSL profile
  • 01070313:3: Error reading key PEM file /Common/<key_name>.key for profile /Common/<profile_name>: error:0907B00D:PEM routines:PEM_READ_BIO_PRIVATEKEY:ASN1 lib

Environment

  • Creating a client or server SSL profile

Cause

Passphrase is not defined or incorrectly entered when creating the SSL profile.

Recommended Actions

Confirm you have the correct passphrase using the instructions found in the article below:

Verifying SSL certificate and key pairs from the command line (11.x - 16.x)
