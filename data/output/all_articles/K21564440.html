Description

Remote authentication for BIG-IP configuration utility or CLI is configured, but BIG-IP initiate authentication traffic from it's self IP.
 

Environment

  • BIG-IP
  • any version
  • Remote authentication
     

Cause

BIG-IP have one default gateway on TMM and other on management ip.
TMM route has high priority, so requires to set management-route to remote authentication server.
 

Recommended Actions

add granular gateway with below command for the remote authentication server with follpowig command on CLI.
 
tmsh create sys management-route <name> network <destination network>/<netmask> gateway <management gateway>
<name>: the name you want to use to identify this route.
<destination network>/<netmask>: the IP address and netmask of the network you are routing to.
<management gateway>: the IP address of the router used to access the destination network.
