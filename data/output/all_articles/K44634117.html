Description

LLDP packets contains 'mac_address = 'None'' for vCMP guests

Environment

  • vCMP
  • Link layer discovery protocol
  • LTM

Cause

The virtualized nature of vCMP® guests abstracts many underlying hardware dependencies, which means that there is no direct relationship between guest interfaces and the physical interfaces assigned to VLANs on the vCMP host. Therefore the vCMP guest will not report a mac address via link layer discovery protocol.
