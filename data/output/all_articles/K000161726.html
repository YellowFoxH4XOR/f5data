K000161726: F5 Insight 1.1.1 updates DNS resolver cache metrics labeling in LTM DNS dashboards

Type
Support Solution
Published
2026-06-16
Updated
2026-06-16
Applies to
  • BIG-IP
  • F5 Insight: 1.1.1
Source
https://my.f5.com/manage/s/article/K000161726

Description

In F5 Insight for ADSP 1.1.0 and earlier, DNS resolver cache metrics such as cache hits, cache misses, and updates shown in the LTM DNS dashboards could be difficult to interpret because the metrics were labeled using internal cache component names rather than the DNS profile names that administrators configure (for example, /Common/dns or /Common/Mac).

F5 Insight 1.1.1 updates metric labeling so you now see recognizable DNS profile names in dashboards, improving correlation between performance metrics and configured DNS profiles.

Environment

  • F5 Insight for ADSP 1.1.1
  • BIG-IP LTM DNS (using DNS profiles and resolver cache)

Cause

The OpenTelemetry Collector previously emitted resolver cache metrics labeled with technical cache component identifiers, which did not map cleanly to custom DNS profile names.

Fix 

F5 Insight 1.1.1 updates the OpenTelemetry Collector to create a cache-to-profile lookup table during metrics collection. When resolver cache metrics are emitted, the collector now does the following:

  • Retrieves the DNS profile name using the BIG-IP API.
  • Maps the profile name to the associated cache component.
  • Labels resolver cache metrics with the DNS profile name, instead of the cache component name.

Recommended Actions

  • Upgrade to F5 Insight for ADSP 1.1.1 to receive the updated DNS resolver cache metric labeling.
  • After upgrading, review the LTM DNS dashboards and confirm the resolver cache metrics appear under the expected DNS profile names (for example, /Common/dns).

You can download F5 Insight for ADSP 1.1.1 on MyF5 Downloads. To see more release details, refer to the F5 Insight 1.1.1 Release Notes.
