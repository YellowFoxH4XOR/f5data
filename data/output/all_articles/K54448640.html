Known Issue

The dosl7d process may reach 100 percent CPU utilization.

This issue occurs when the following condition is met:

  • When the Traffic Management Microkernel (TMM) produces a core file and restarts, the dosl7d process also restarts and may consume 100 percent CPU utilization.
The dosl7d process provides Layer 7 (L7) denial-of-service (DoS) protection for the BIG-IP ASM system.

Impact

The BIG-IP system performance is degraded and L7 DoS protection may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system logs an error message to the /var/log/dosl7/dosl7d.log file that appears similar to the following example:

    DOSL7D_CONF|NOTICE|Oct 17 10:56:32.756|10104|dosl7d_conf.cpp:1999|Caught signal - disconnect from mcpd, exit conf thread
  • The BIG-IP system performance is degraded.
  • L7 DoS protection may fail.
