K000147468: How to Download LBs security configuration from XC portal

Type
Support Solution
Published
2024-11-08
Updated
2025-02-21
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147468

Description

  • You require a report or list of your load balancers (LBs) along with the associated security configurations.

Environment

  • WAF Managed Service
  • DDoS Managed Service
  • F5® Distributed Cloud

 

Resolution/Answer

1- Navigate to Web App & API Protection > Security Dashboard.

2- Select the associated namespace

3- Scroll down to the Application Delivery section.

4- Click on the gear icon, then select all the desired security objects.

5- Click the Download CSV button to download the report.
