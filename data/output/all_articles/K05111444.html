Issue

Error Message

warning mcpd[<pid>]: 01071859:4: Warning generated : /Common/<iRule_name>: warning: [The following errors were not caught before. Please correct the script in order to avoid future disruption. "invalid argument <html><body>Results</body></html>"24 74][HTTP::respond 200 <html><body>Results</body></html> "MatchResult" "match"]

In this error message, note the following:

  • <pid> is the unique process ID of the mcpd process running on your system.
  • <iRule_name> is the name of the iRule.

For example:

warning mcpd[1234]: 01071859:4: Warning generated : /Common/example_irule:2: warning: [The following errors were not caught before. Please correct the script in order to avoid future disruption. "invalid argument <html><body>Results</body></html>"24 74][HTTP::respond 200 <html><body>Results</body></html> "MatchResult" "match"]

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • Your iRule fails validation checks performed by the JET validation engine.

The BIG-IP system performs syntax validation through the JET validation engine, which checks iRule syntax more strictly. If your iRule fails JET validation, the system reverts to the old validation method and logs a message.

For example, the following iRule generates an error message after passing through the validator because it is missing the content option flag:

when HTTP_REQUEST {
HTTP::respond 200 <html><body>Results</body></html> "MatchResult" "match"
}

In this example iRule, you can add the "content" flag, which appears similar to the following:
when HTTP_REQUEST {
HTTP::respond 200 -content <html><body>Results</body></html> "MatchResult" "match"
}

Impact

If your iRule fails JET validation, a warning message is logged at the time of configuration load. Your BIG-IP system may fail to load the configuration if the syntax issue is not corrected.

Recommended Actions

To work around this issue, you must correct the syntax errors within the lines that are specified by the error message.
