K000138500: VPN KO if Proxy unavailable when already connected

Type
Support Solution
Published
2024-02-06
Updated
2024-02-20
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000138500

Description

The VPN connection breaks due to a proxy server losing connection.

Environment

Using a proxy server with APM VPN

Cause

Proxy went down

Recommended Actions

Make sure that proxy stays up as it is a part of the tunnel

Consider configuring a fallback device.

Additional Information

None
