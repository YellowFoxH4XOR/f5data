K30454517: ASM import error: ''an entry with this wildcardOrder already exists, please choose a distinct wildcardOrder''

Description

When trying to import ASM config into BIG-IQ getting error:
Coordinator failed during working-config update, roll-back working-config started; reason: Worker http://localhost:8100/cm/asm/working-config/policies/xxxxxxxxxx/urls failed validation with status 500: java.lang.IllegalArgumentException: an entry with this wildcardOrder already exists, please choose a distinct wildcardOrder

Environment

  • BIG-IQ
  • ASM service enable on managed device
  • Initial import of ASM config of a managed device

Cause

The BIG-IQ cannot handle different wildcard orders (HTTP/HTTPS) across different security policies on managed devices.

Recommended Actions

Make sure all URL Wildcard Order entries list HTTPS above HTTP (Security  ››  Application Security : URLs : Wildcards Order : HTTP URLs)
