Known Issue

A mobile device that accesses a Microsoft Exchange ActiveSync server through FirePass may establish multiple sessions on the FirePass controller. F5 Product Development has observed this issue on Apple iOS, Android, and Nokia devices, but the issue may occur with other mobile devices as well.

Impact

Users are unable to log in to the FirePass controller if the system reaches its licensed connection limit.

Symptoms

As a result of this issue, you may experience the following symptoms:

  • Multiple sessions for a user shows up in the Web Applications engine trace
  • Session reports show multiple entries with the same start time, user, and IP address

Workaround

You can mitigate this issue by defining a smaller timeout period for the group assigned to your ActiveSync configuration. By default the FirePass system sets a timeout period of 20 minutes; by setting the timeout to three minutes, you can ensure that the system frees connections more frequently. 

Impact of Workaround: If you change the global timeout or a group timeout for users, the system will close the users connections if they go three minutes without actively using the connection.

To configure session timeouts, refer to K3106: Configuring server-side session timeouts.
