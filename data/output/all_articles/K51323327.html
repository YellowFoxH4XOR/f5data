Issue

Error Message

bigip_1 warning mcpd[6879]: 01071af0:4: NTP not configured on device <IP_address> - within a trust

In this error message, note the following:

  • <IP_address> is the self IP address that is defined as the failover address for the local BIG-IP system.

For example:

bigip_1 warning mcpd[6879]: 01071af0:4: NTP not configured on device 10.3.1.4 - within a trust

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions is met:

  • You add a BIG-IP system with no defined network time protocol (NTP) server to a device group.
  • You remove the NTP server configuration from a BIG-IP system that is part of a device group.

Synchronized system clock time is required for all device group members. NTP is the recommended method to synchronize time on BIG-IP systems. If a BIG-IP system with no defined NTP server is added to a device group, the device group members may fail to synchronize their configuration, and the system in which no NTP server is configured logs the listed error message.

Impact

The system clock is out of sync with other device group members and configuration synchronization (ConfigSync) operations may fail.

Recommended Actions

You should configure each member of the device group to receive time from three NTP servers. For more information on configuring NTP servers for a BIG-IP system, refer to the following articles:

  • K3122: Using the BIG-IP Configuration utility to add an NTP server
  • K13380: Configuring the BIG-IP system to use an NTP server from the command line (11.x - 12.x)
