K000135844: Unable to post classic-app-service : Failed to Set Classic Config Set: Duplicate item. Key already exists

Type

Published
2023-08-14
Updated

Source

Description

An error may occur during the deployment of an application. (App_Name and machineId are examples in the following output):

Unable to post classic-app-service : Failed to Set Classic Config Set: Duplicate item. Key already exists: name : XXXX-APP-SIMULATOR-PLATFORM-INH, machineId : 47874e53-0818-53c8-9c49-da3ead8ea41a: Duplicate item. Key already exists: name : XXXX-APP-SIMULATOR-PLATFORM-INH, machineId : 47874e53-0818-53c8-9c49-da3ead8ea41a : Failed to Set Classic Config Set: Duplicate item. Key already exists: name : XXXX-APP-SIMULATOR-PLATFORM-INH, machineId : 47874e53-0818-53c8-9c49-da3ead8ea41a

Environment

BIG-IQ

Cause

This likely occurred due to a previous failed deployment or incomplete cleanup process, leaving behind residual configuration data that conflicts with subsequent attempts to create or deploy the same application.

Recommended Actions

  • Identify Duplicate Configuration Entries:

Use REST API commands via BIG-IQ CLI to locate and confirm duplicate entries:

  • List global applications: 
    restcurl /cm/global/global-apps/ > /var/tmp/global-apps
  • List classic configurations: 
    restcurl /cm/global/classic-configs/ > /var/tmp/classic-configs
  • Search for Duplicates:

Open the output files (global-apps and classic-configs) and search for entries related to XXXX-APP-SIMULATOR-PLATFORM-INH. Look for duplicate entries with matching names or machine IDs.

  • Remove Residual Configuration:

Once you identify the duplicate entry, delete it using its object ID:

restcurl /cm/global/classic-configs/<duplicated-entry-id> -X DELETE

  • Retry Application Creation:

After cleaning up duplicate entries, attempt creating the application again through BIG-IQ GUI.
