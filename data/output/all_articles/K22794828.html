K22794828: Edge Client Stuck at the Initialising Phase with IPV6

Type
Support Solution
Published
2021-03-01
Updated
2025-02-06
Applies to
  • BIG-IP APM: 13.X.X
Source
https://my.f5.com/manage/s/article/K22794828

Description

Edge Client is stuck in the initialising phase when tunnelling using IPV6.

CTU Report Error shows:

RAS error =734

Environment

  • Full Tunnelling used 
  • IPv6 used

Cause

This can be caused by a Third-party software that may redirect traffic, such as a "Proxy" or PACFILE.

Recommended Actions

Re-configure or remove the Proxy or PACFILE within the device or internal network.
