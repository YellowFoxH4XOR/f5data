K08415323: ''Challenge Failure Reason'' field in a request event log shows N/A.

Type
Support Solution
Published
2022-03-30
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • VIPRION Platforms
  • BIG-IP
  • BIG-IP ASM: 15.1.4
Source
https://my.f5.com/manage/s/article/K08415323

Description

"Challenge Failure Reason" field in a request event log shows N/A instead of "JavaScript is disabled in browser", when trying accessing login page with browser not supporting JavaScript.

Environment

  • BIG-IP ASM
  • 15.1.4
  • ASM security policy - Login Page configured

Cause

This is caused by BUG ID 1083513.
BD configuration for botdefense.disable_challenge_failure_reporting gets de-synced with mcpd

Recommended Actions

There are two ways of fixing the issue:

  1. Disable the key and re-enable, then save.

    tmsh modify sys db botdefense.disable_challenge_failure_reporting value disable
    tmsh modify sys db botdefense.disable_challenge_failure_reporting value enable
    tmsh save sys config
     
  2. Upgrade device to non-affected software version.
