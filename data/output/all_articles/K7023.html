Topic

If the Caps Lock feature is enabled, or a user enters their username in upper case through a BIG-IP console session, the BIG-IP system will assume that the client's terminal cannot use lowercase. As a result, the BIG-IP system adjusts the input and output to use uppercase. This behavior is expected.

Unix and Linux commands are case sensitive. Therefore, switching the console from uppercase to lowercase can prevent interaction with the BIG-IP system, and can prevent the running of commands.

You can reset the terminal to lowercase by typing the following command from the command line of the console session:

stty -iuclc -xcase -olcuc
