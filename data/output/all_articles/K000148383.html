K000148383: Negative SOA serial number shown in zxfrd logs during zone transfer

Description

You may observe the below log that shows a negative SOA serial number when the Zone transfer completes. However, DNS SOA serial number should never be negative.

0153102c:5: IXFR Transfer of zone example.com with SOA Serial -2147483647 from 192.168.1.2 succeeded.

Environment

  • DNS Express
  • Zone transfer for both IXFR and AXFR
  • Zone SOA Serial number larger than 2147483647(exclusive)
  • BIG-IP DNS versions v17.1.1.4, v16.1.5.1, v15.1.10.5 and before.

Cause

Bug ID 1711813, the logging used a signed integer format to record the message while the SOA serial number should be an unsigned integer.

Recommended Actions

This should be only cosmetic for logging. When you notice a negative SOA serial number, you may convert the number to a binary format and interpret it to an unsigned integer, in an unsigned integer it should reflect the correct serial number.

You can use the following command syntax to derive the decimal number for the negative value found in the logs,
echo "$Value" | awk '{ print $1 + 2^32 }'
where $Value is the variable containing the negative value.
