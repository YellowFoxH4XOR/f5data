K000091335: NGINX Plus R26 Requires PCRE2 Installed

Type
Support Solution
Published
2022-03-29
Updated
2025-04-02
Applies to
  • NGINX Products
  • NGINX Plus: R26
Source
https://my.f5.com/manage/s/article/K000091335

Description

Installing/updating NGINX Plus R26 via downloaded package may fail to install with an error similar to the following:

error: Failed dependencies:         libpcre2-8.so.0()(64bit) is needed by nginx-plus-26-1.el7.ngx.x86_64

Environment

  • NGINX Plus R26
  • RHEL or CentOS node

Cause

NGINX Plus R26 binary requires PCRE2 libraries to be installed.

Recommended Actions

Install PCRE2 before installing NGINX Plus R26. For example:

cd /tmp
sudo yumdownloader pcre2.x86_64
sudo yumdownloader nginx-plus.x86_64
sudo rpm -ivh pcre2-10.23-2.el7.x86_64.rpm
sudo rpm -Uvh ./nginx-plus-26-1.el7.ngx.x86_64.rpm

The above example commands assume you have the yumdownloader utility installed on your RHEL or CentOS node. The yumdownloader utility is part of the yum-utils package, which is not installed by default. Alternatively, you can use the yum utility to download and install the packages from the configured yum.repos.d on your RHEL or CentOS node. For example:

sudo yum install pcre2.x86_64
sudo yum install nginx-plus.x86_64

For information about how to configure the yum.repos.d on your RHEL or CentOS node, refer to the documentation from your RHEL or CentOS vendor.

Note: Most package managers such as yum will automatically detect and install dependencies.
