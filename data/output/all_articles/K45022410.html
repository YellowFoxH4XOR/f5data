Description

Some Virtual Servers stopped responding to client requests, although displaying green light and marked as available.

Notice the BIG-IP objects affected, are associated with a VLAN that has no Self-IP addresses configured.

When taking packet captures on the BIG-IP, no incoming traffic shows from upstream devices nor client connections.

Environment

  • OSPF Routing
  • Virtual Address with Route Advertisement set to Disabled

Cause

Route advertisement for the Virtual Addresses does not propagate to upstream devices when set to Disabled. The BIG-IP system does not advertise the route for the virtual address, regardless of the availability status.

Recommended Actions

Configure Route Health Injection for the affected virtual addresses so that the BIG-IP system advertises the availability of the address as a host route.

  1. Log in to the Configuration utility
  2. Go to Local Traffic > Virtual Servers > Virtual Address List
  3. Select the virtual address for which you want to enable route advertisement
  4. Under Configuration, select the following option for Route Advertisement: Selective
  5. Click Update.
  6. Repeat for all affected Virtual Addresses.

Note: With the Selective option, the BIG-IP system advertises the route for the virtual address only when it is available. For other options refer to: K52416313: Configuring Route Health Injection for use with OSPF.
