Known Issue

The BIG-IP APM rewrite process may incorrectly handle the action attribute of an HTML form.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The BIG-IP APM rewrite process handles a dynamic HTML form.
  • Other HTML forms, in the same page, contain an absolute action path attribute.

In the following example, the first form is dynamically created and the second form has an absolute form action attribute:

  <script type="text/javascript">
    jQuery#add-hardware-dialog').dialog({}); // empty defaults argument
  </script>

  <form action="/absolute/path" method="post">
    <button type="submit">Search (link is not rewritten after click)</button>
  </form>

The second form action attribute will not be properly rewritten via portal access, and the form is not submitted.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using portal access, HTML forms are not submitted.
  • When using portal access, requested pages fail to display.
  • Web applications malfunction or fail to render properly in browsers.
