Description

Secure Web Gateway has a limited license period. If the license expires without renewal, then services can be interrupted.
This document describes the creation of a custom SNMP OID that returns the number of days validity remaining on a Secure Web Gateway license.
This can be used to trigger alerts from an SNMP monitoring tool when this value is close to zero.

Environment

  • BIG-IP Secure Web Gateway implementation with time-limited license
  • SNMP

Cause

None

Recommended Actions

To configure a custom SNMP OID that returns the number of days validity remaining on a Secure Web Gateway license, perform the following procedure:

1. Log in with administrative privileges to the command line of the target device.
2. Using a text editor, create the following file

    /config/snmp/swglic_days_to_expiry.sh

3. Enter the following command syntax into the /config/snmp/swglic_days_to_expiry.sh file

#!/bin/sh
# return the number of days validity remaining on a Secure Web Gateway license
# return 0 if the license is expired
# return -1 if no SWG license is found

swg=$(tmsh show sys license | grep -i "secure web gateway")
if [[ $? -eq 0 ]]
then
  result=$(( ($( date +%s -d $( echo $swg | cut -f4 -d"|" )) - $(date +%s)) / 86400 ))
  if [[ $result -lt 0 ]]
  then
    result=0
  fi
else
  result=-1
fi
echo $result      

       
4. Save the changes.
5. To change the file permissions, type the following command:

    chmod 755 /config/snmp/swglic_days_to_expiry.sh

6. Using a text editor, create the following file:

    /config/snmp/custom_mib.tcl

7. Enter the following command syntax in the /config/snmp/custom_mib.tcl file:

Note: if you have existing custom mibs in the custom_mib.tcl file, you will need to change the OID number to suit

register_mib ".1" swglic_days_to_expiry GAUGE
    proc swglic_days_to_expiry {} {
        set status [catch { exec /bin/bash /config/snmp/swglic_days_to_expiry.sh } result]
        return $result
    }


8. Save the changes.
9. To restart the SNMP service, type the following command:

    tmsh restart /sys service snmpd

10. To verify that the workaround is functional, type the following command:

    snmpwalk -Os -c public -v 2c localhost .1.3.6.1.4.1.3375.2.100.1
  bigipTrafficMgmt.100.1.0 = STRING: "28"
