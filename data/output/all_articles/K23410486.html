Description

Windows 10 clients are getting detected as Windows 7.

For the APM session in question:
 - in the session variables list, the value of the session.client.platform is Win7
 - in the APM logs, the value of Platform is Win7
 
Below is a sample APM log showing the same:
 
Nov  30 18:59:56 bigip1 notice apmd[7376]: 01490261:5: /Common/test_AP:Common:85405777: Updating client info - Hostname: none Type: edge Version: none Platform: Win7 CPU: WOW64 UI Mode: Standalone Javascript Support: 1 ActiveX Support: 1 Plugin Support: 0 Model:  Platform Version:  Serial Number:  IMEI:

Environment

  • BIG-IP APM
  • Windows 10

Cause

The Windows 10 client is running in Compatibility mode

Recommended Actions

Turn off Compatibility mode for the affected Windows 10 clients

Note: The following link takes you to a resource outside of AskF5, and it is possible that the documents may have been removed without our knowledge
Make older apps or programs compatible with Windows 10
