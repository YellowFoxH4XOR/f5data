Known Issue

This is the result of a known issue. Under rare conditions, when an HTTPS server returns SSL read errors in response to HTTPS monitor traffic, the bigd process may leak SSL structures. When the server regularly returns SSL errors, the bigd process may eventually crash.

F5 Networks Product Development tracked this issue as CR117349 and it was fixed in BIG-IP versions 9.4.7, 10.0.1, and 10.2.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0, and in Hotfix-BIGIP-10.0.0-5514.0-HF2 for BIG-IP version 10.0.0. You may download these hotfixes or later versions of the hotfixes from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 Networks product hotfixes for BIG-IP version 10.x systems.
