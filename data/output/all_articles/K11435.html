K11435: BIG-IP WebAccelerator incorrectly removes quotes from Cache-Control headers

Known Issue

This is the result of a known issue. When parsing the OWS HTTP headers before sending the response to the client, the BIG-IP WebAccelerator incorrectly misinterprets double quote characters in the Cache-Control header as delimiters, and removes them. The double quote characters are used to group as a single header value multiple cache control field arguments that are separated by whitespace. When the BIG-IP WebAccelerator system removes the double quote characters, the browser receiving the response is unable to correctly process the Cache-Control header, and the browser may be unable to interact with the application as expected.

F5 Product Development is tracking this issue as ID 324288 (formerly CR139003).

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.1.0-3372.0-HF1, which has been issued for BIG-IP 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1 which has been issued for BIG-IP 10.2.0. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP 10.x systems.
