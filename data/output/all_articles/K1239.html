Important: Creating a new database will require that you reenter or re-import all zone information. Create a new NameSurfer zone database only if NameSurfer has corrupted data or will not start, and you have exhausted all other troubleshooting options.

To back up the existing zone database and create new one, perform the following steps:

  1. Log in to the command line.
  2. Change directories to the /usr/local/namesurfer directory by typing the following command:

    cd /usr/local/namesurfer/

  3. Stop existing NameSurfer processes by typing the following command:

    /usr/local/namesurfer/bin/stop

  4. Rename the existing database directory by typing the following command:

    mv db db.bak

  5. Restart the NameSurfer database by typing the following command:

    /usr/local/namesurfer/bin/dbinit

  6. Follow the prompts to enter the NameSurfer account information.
  7. Start NameSurfer by typing the following command:

    /usr/local/namesurfer/bin/namesurferd

NameSurfer should now be running with the new database.
