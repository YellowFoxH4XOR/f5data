Known Issue

The BIG-IP APM Configuration utility visual policy editor may not function for policies with long names.

This issue occurs when either of the following conditions are met:

  • You create a BIG-IP APM policy with a name that exceeds 70 characters.
  • You import a BIG-IP APM policy that contains policy name references that exceed 88 characters.

    Note: A policy name reference includes the partition name of the policy and any configuration file appended to the original policy name.

Impact

Users are unable to use the BIG-IP Configuration utility visual policy editor to open the BIG-IP APM policy.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H426895 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP APM Configuration utility editor freezes when attempting to open a policy for editing.

Workaround

To work around this issue, F5 recommends that you limit new policy names to 70 characters. When working with imported policies, ensure the policy file to be imported only contains policy name references that are no greater than 88 characters. To do so, perform the following procedure:

Impact of workaround: None.

Modifying the BIG-IP APM policy import file

  1. Using a plain text editor, open the policy configuration file intended for import.

    Note: Ensure that the text editor used to edit the file does not apply any additional formatting to the body of the file.
  2. Scan the file to identify policy name references with names that exceed 88 characters.
  3. Note the base name used for that policy.

    For example:

    /Common/<policy name>_suffix.

    Note: The policy name is referenced many times throughout the configuration file and may be appended with suffixes similar but not limited to the following list:

    _act_active_directory
    _act_active_directory_ag
    _act_logon_page
    _act_logon_page_ag
    _act_resource_assign
    _act_resource_assign_ag
    _end_allow
    _end_allow_ag
    _end_deny
    _end_deny_ag
    _ent
    _ent_in
    _eps
    _errormap
    _frameworkinstallation
    _general_ui
    _logout
    _ter_failure
    _ter_success

    The 88 character limit includes the appended text as well as the partition name that the policy resides in.

    Important: Do not modify the partition or appended suffix statements. Only modify the base policy name.
  4. Use the text editor find and replace feature to uniformly and globally replace the base policy name (excluding the partition name and appended suffixes). Use a replacement name that does not exceed 70 characters.
