Known Issue

BIG-IP APM virtual server fastL4 profile may not be available.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is licensed as a BIG-IP APM Standalone device.
  • You attempt to create or modify a virtual server to use the fastL4 profile with one of the following types:
    • Forwarding (Layer 2)
    • Forwarding (IP)
    • Performance (Layer 4)

Impact

You are unable to create or modify the configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use the Configuration utility and apply the configuration, the system displays an error similar to the following example:

    01020036:3: The requested profile (/Common/fastL4) was not found.
  • When you run the following Traffic Management Shell (tmsh) command, the ltm_proxy_fastl4 is not listed in the output.

    tmsh show /sys license detail
