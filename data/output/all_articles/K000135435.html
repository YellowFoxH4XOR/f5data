Description

Do F5 BIG-IP Application Services Templates (BIG-IP FAST) support the Access Policy Manager (APM) module

 

Environment

BIG-IP

Cause

Do F5 BIG-IP Application Services Templates (BIG-IP FAST) support the Access Policy Manager (APM) module

Recommended Actions

Per https://clouddocs.f5.com/products/extensions/f5-appsvcs-templates/latest/userguide/APM-guidance.html?highlight=apm none of the main F5 BIG-IP Application Services Templates (BIG-IP FAST) include support for the Access Policy Manager (APM) module.

 

We do have another utility called F5 BIG-IP Access Guided Configuration which does have templates for many common

SAML SaaS applications. Further information can be found at:

 

https://clouddocs.f5.com/products/agc/8.0/#
