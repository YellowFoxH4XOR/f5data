Description

Trying to import applications into iRules LX Workspace and you encounter errors similar to the one below: 
bigip.localhost.com err sdmd[1234]: 018e0018:3: pid[12345]  plugin[/Common/example.com.website] SyntaxError: Unexpected token function

Environment

  • BIG-IP with iRulesLX provisioned 
  • importing an application as a Workspace and deploying as a an LX Plugin

Cause

  • the Node.js version running on BIG-IP is 6.9.1
  • newer functions and features may not work as these require newer versions of Node.js

Recommended Actions

  • Since the Node.js version is not upgradable, you might have to use 'modules' that work with older versions of Node.js to meet your requirements
  • there is an option to use a 'transpiler' in order to convert your piece of code to the current version on BIG-IP

Important: Writing code, using modules and transpilers are outside of F5 Support's scope.

Additional Information

While there is an enhancement request to upgrade the Node.js version that ships with BIG-IP, there is no indication that this will be implemented any time soon.
