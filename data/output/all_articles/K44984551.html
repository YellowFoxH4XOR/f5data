Description
When trying to generate a report via Security > Overview > Application > Traffic, Some links and drop-down fields are not available for 'pressing/clicking' on AVR-GUI widgets pages
Options Device Group, Override time range to, and Security Policy are grayed out.
Additionally, the Export button is not executable, the cursor looks like if it was loading but can't execute the report export

Environment

  • ASM/AVR provisioned
  • Software version 15.1.2.1

Cause
The behavior is caused by a known issue tracked with the Bug ID 1009093 

Recommended Actions
You can do either of the following:

  1. Upgrade to a listed fixed release as noted in BugID 1009093 
  2. Perform the workaround explained in the Work Around section of the BUG-ID
