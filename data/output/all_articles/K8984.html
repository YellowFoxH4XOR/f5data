Known Issue

This is the result of a known issue. BIG-IP LTM reports a shared memory error message when attempting to configure or load a large number of VLANs (125 or more unique VLANs) with failsafe enabled. As a result, some VLANs are not loaded properly due to insufficient shared memory allocated within the high availability paging table.

An error message that appears similar to the following example is reported to the /var/log/ltm file:

01140003:3: Out of shmem, increment amount in /etc/ha_table/ha_table.conf.

F5 Product Development tracked this issue as CR98056 and it was fixed in BIG-IP LTM 9.4.6 and 9.6.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP 9.4.5, for the BIG-IP 9.4 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing BIG-IP product hotfixes (9.x).
