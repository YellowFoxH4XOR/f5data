K000157921: APM: None of the configured JWK keys match the received JWT header

Type
Support Solution
Published
2025-11-20
Updated
2025-11-20
Source
https://my.f5.com/manage/s/article/K000157921

Description

BIG-IP administrators may notice a message similar to the one below when APM is configured as an oAuth Client or an oAuth Resource Server:

Nov 10 13:13:57 bigip.apm err apmd[15118]: 01490290:3: /Common/StartAllow_ap::f82f7602./Common/f5_oauth_scope/YXhzMnN1YnNpZA==:/Common/f5_oauth_scope_act_oauth_scope_subsession_ag: OAuth Scope: failed for jwt-provider-list '<provider list>' , error: None of the configured JWK keys match the received JWT token, JWT Header: <token header>

The error itself may have several triggers. This article will list the various triggers for this error.

Environment

  • APM 
  • oAuth
  • JWT

Cause

Currently known causes 

  • https://my.f5.com/manage/s/article/K40154406 - JWK Key Missing
  • https://my.f5.com/manage/s/article/K000138169 - Issuer Mismatch
  • https://my.f5.com/manage/s/article/K000138170 - Audience Mismatch
  • https://my.f5.com/manage/s/article/K000151094 - Case Sensitive Key ID
  • https://my.f5.com/manage/s/article/K52449222 - Token Key Mismatch
  • https://my.f5.com/manage/s/article/K000157920 - Expired Token

Recommended Actions

Follow the procedures outlined in the articles

Additional Information

There may be other circumstances that could result in this error
