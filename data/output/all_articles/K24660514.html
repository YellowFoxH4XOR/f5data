K24660514: On post-15.x only last modified access policy can be saved successfully when clicking save button in advanced customization

Description

When going to Access  ››  Profiles / Policies : Customization : Advanced and customize any .css or .inc files in Advanced Customization Editor.
Make some dummy changes  e.g.
Logon page or message box, or decision box. e.g. add a dummy or empty line to change the file.
When you perform the change on multiple Access Profiles, then click "Save Draft" on the up-right corner, then click "Save" button on up-left corner.
In pre-15.x, the save operation will save all Access Profiles which have been modified.
However, in post-15.x, the save operation will only save the last modified Access Profiles, modification for other Access Profiles will be lost

Environment

  • BIG-IP APM
  • Access Profile

Cause

This is a behavior change since 15.x.

Recommended Actions

Once customizing Access Profile, save the change before moving on to the next Access Profile.

Additional Information

None.
