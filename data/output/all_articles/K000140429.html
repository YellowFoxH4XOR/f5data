Description

A re-install of K3s may be required to resolve certain issues relating to the Kubernetes cluster on rSeries appliances.

This article outlines the steps for re-installation.

Important: K3s re-installation should typically only be performed when recommended by F5 Support, or as recommended in F5 knowledge base articles to resolve a specific, known issue. Do not re-install the K3s cluster as an attempted fix for F5OS problems that have not yet been properly investigated and understood. Open a case with F5 Support if there is any doubt about the specific symptoms observed on your F5OS system.

Environment

  • rSeries
  • F5OS-A
  • K3s cluster

Cause

None

Recommended Actions

To re-install the K3s cluster, follow these steps:

Note: Re-installing the K3s cluster is service impacting. A maintenance window is recommended. The process takes approximately 15 minutes.

  1. Set tenants to Configured state. You can do this either using the webUI or the CLI.

    For webUI, go to TENANT MANAGEMENT > Tenant Deployments. Check the tenant and select Configure. Repeat these steps for the remaining tenants.

    For CLI, you can login as the root user to get into the F5OS command line and then su admin to get to the F5OS CLI prompt. Alternatively you can login as the admin user directly to the F5OS CLI prompt. Then enter config to get into the configuration mode terminal. Then run the following F5OS CLI command to set the tenant to Configured state:

    tenants tenant <tenant name> config running-state configured ; exit

    Repeat this command for the remaining tenants. To save the change and exit the configuration mode terminal, enter the following command:

    commit; exit

    You can use the following F5OS CLI command to monitor the status of the tenants:

    show tenants tenant state status

    When the command displays the tenants' status as Configured, proceed to the next step.

  2. Stop Appliance Orchestration Manager

    Note: You should be logged in to the F5OS command line as the root user to perform this step as well as all steps after this.

      systemctl stop appliance_orchestration_manager_container

  3. Uninstall k3s by running the following commands as the root user in the F5OS command line:

      k3s-uninstall.sh

      rm /var/omd/* /tmp/omd/tokens/* /tmp/omd/appliance-ansible-host

  4. Start Appliance Orchestration Manager again to trigger the k3s install by running the following commands as the root user in the F5OS command line:

      (touch /tmp/omd/skip; sleep 1m; rm -f /tmp/omd/skip)&

      systemctl start appliance_orchestration_manager_container

  5. Wait ~15 minutes for the install to complete.

    You can monitor the status with:

      tail -F /var/log/*-install.log

    Keep a lookout for log entries similar to the following example in /var/log/k3s-install.log file:

    Updating K3S Server with bind address
    k3s-config update is done, restarting the process

    The command will come to a complete stop with the last log entries similar to the above, which indicate that the k3s reinstall has completed.
    Press Ctrl-C to stop the "tail" command, and proceed to the next step to verify.

  6. Check that the pods are running:

      kubectl get pods --all-namespaces

    There should be ~16 pods in most cases.

Additional Information

This process is not applicable to the VELOS platform.
