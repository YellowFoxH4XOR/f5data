K01151510: Unable to load BIG-IP configuration due to configuration exception, Failed to find trash-path for ILX

Support Solution
Published
2021-05-28
Updated

Legacy Content
Applies to

  • BIG-IP LTM: 14.1.2
Source
https://my.f5.com/manage/s/article/K01151510
Description

Unable to load BIG-IP configuration after code upgrade. Below error messages appeared in /var/log/ltm:

01070712:3: Caught configuration exception (0), dev/validation/SDMAppProjectMgr.cpp:validate_checkpoint:819: Failed to find trash-path(/var/sdm/plugin_store/.trash/<ilx workspace>) for name(/Common/<ilx plugin>) rev(X)..

Environment

  • BIG-IP
  • ILX plugin

Cause
This is caused because the BIG-IP lost the path directory for a ILX configuration object after performing a BIG-IP code upgrade.

Recommended Actions
In order to fix this issue, the configuration object path directory needs to be re-created

  1. Login into the BIG-IP using  CLI.
  2. Restore the configuration object path directory by using below command
#mkdir /var/sdm/plugin_store/.trash/<ilx workspace>
  1. Verify BIG-IP configuration:
#tmsh load sys config verify
  1. Load BIG-IP configuration file:
#tmsh load sys config
