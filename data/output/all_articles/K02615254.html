K02615254: Pool monitors flapping - ICMP reply ignored by the BIG-IP

Type
Support Solution
Published
2022-08-03
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K02615254

Description

Health monitors are marked intermittently down, even when a packet capture shows the expected responses are received on time, the device score might change.

Environment

  • Health monitors are configured with a proper timeout value.
  • Logs are showing no response for the health monitor has been received.
  • Packet capture is showing expected node responses are arriving on time.

Cause

Unknown

Recommended Actions

  1. Restart BigD, using the following syntax.

    bigstart restart bigd

    To verify BigD is working again, use the command:

    bigstart status bigd
     
  2. If the issue persists after BigD restart, it might indicate an issue with a configuration file. Performing an mcpd force load is recommended in this case with the process described in article K13030.

Additional Information

K13030: Forcing the mcpd process to reload the BIG-IP configuration
