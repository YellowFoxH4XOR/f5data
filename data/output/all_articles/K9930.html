Known Issue

This is the result of a known issue. Some versions of the Cisco Content Services Switch (CSS) product use a different management information base (MIB) than previous versions. As a result, the object identifiers (OIDs) polled by the BIG-IP GTM system for the status of CSS systems may not be correct for some versions of CSS. When this behavior occurs, the BIG-IP GTM system may be unable to automatically discover affected CSS systems and to retrieve their current status.

Note: For more information about the CSS OIDs, refer to K6793: OIDs polled by BIG-IP GTM for third party server products.

F5 Networks Product Development is tracking this issue as CR48814.
