K000135846: APM rejecting clients with Cisco Webex

Type
Support Solution
Published
2023-08-29
Updated
2023-08-30
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000135846

Description

Applications on your client are being rejected even if they should pass the endpoint check.

Environment

  • Cisco Webex
  • APM
  • Endpoint check for P2P enabled

Cause

We have noticed that sometimes, applications that intuitively should not be affected by a endpoint check you have in place is in fact affected.
Eg. If you have an endpoint check denying File Sharing applications (like P2P), this might block unexpected applications, like Cisco Webex.
This is due to the applications (although not primarily File Sharing software itself) use P2P protocols for some of their features.
Hence blocking an application although it should not be affected.

 Recommended Actions

Reconsider what protocols you block and what software applications use them. The vendors and products detected as "Public-File_Sharing" can be checked on your APM or at the public "Support Charts" for the OESIS SDK used by the APM checks at  https://software.opswat.com/OESIS_V4/Win/docs/support_charts/support_charts.html

Additional Information

Cisco Webex, uses protocols (like P2P) although not a File Sharing software, it can be used to share files and as such is categorised as "Public File Sharing" by OPSWAT.
