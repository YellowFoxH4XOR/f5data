K000136172: How to get the cURL command equivalent for a Postman API call and viceversa?

Description

This article shows how to get the cURL equivalent command from a Postman call. Likewise, it shows you how to import a cURL command into a Postman API call.

Environment

  • Postman
  • cURL

Cause

None

Recommended Actions

Postman to cURL

  1. Open the request you want to convert to cURL command in Postman, then select the Code icon in the right sidebar.

    Note: If you do not see the right sidebar or the Code icon, you may need to upgrade to a recent version of Postman. For more information about the code snippet feature of Postman, refer to the Generate code snippets from API requests section of the Postman documentation. This link takes you to a resource outside of MyF5. The third party could remove the document without our knowledge.

  2. Select cURL if it's not already selected.

  3. Select the Copy snippet icon to copy the command snippet to your clipboard.

cURL to Postman

  1. Open Postman.
  2. Click the File menu and Import.

  3. Paste the cURL command in the text bar.

  4. The cURL command will be imported automatically as a new request.

Additional Information

It is common to use Postman and/or cURL as tools to send HTTP requests to F5 devices, for example, to BIG-IP and BIG-IQ. F5 may request that you provide the cURL command you are using, for troubleshooting purposes.
