Security Advisory Description

F5 has identified a possible SQL injection vulnerability for FirePass. FirePass may not perform adequate user input validation of particular fields. (CVE-2012-1777)

Impact

An unauthenticated attacker may be able to exploit the vulnerability via SQL injection.
