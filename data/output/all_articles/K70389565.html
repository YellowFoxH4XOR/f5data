K70389565: IMAPS virtual server with STARTTLS shows error message

Description

IMAPS virtual server with STARTTLS shows error message as below.
   
01b40003:3: Virtual Server /Common/imap_vip starttls-profile /Common/my_imap configuration error: SSL forward-proxy must be enabled 


Environment

  • LTM
  • IMAPS
  • STARTTLS 

Cause

Client---[IMAPS(STARTTLS)]---BIG-IP---[IMAP(No encryption)]---IMAP Server

If backend server connection does not use SSL encryption, BIG-IP requires SSL forward-proxy option enabled.


Recommended Actions

  1.  Apply server side SSL profile for IMAP server connection.

    SSL profile on server should enable SSL forward proxy  as well ONLY then no issue will appear, otherwise below config error will appear.

        01070734:3: Configuration error: SSL forward proxy feature state on clientssl profile(s) and/or serverssl profile(s) doesn't match on Virtual Server
     
  2.   You can NOT  enable SSL forwards proxy only on client side profile then if you have SSL forward proxy configure correctly no IMAP config issue appears.
