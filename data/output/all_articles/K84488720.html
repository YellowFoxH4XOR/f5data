K84488720: Update the Service Check Date for a BIG-IP VE licensed by a BIG-IQ

Support Solution
Published
2020-04-08
Updated
2026-06-10
Applies to

  • Virtual Editions
  • Public Cloud
  • Private Cloud
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0

Description

Similar to subscription or perpetual licenses, when planning to apply a hotfix or upgrade a BIG-IP, the service check date on the BIG-IP needs to be newer than the release date of the upgrade version.  BIG-IP VEs licensed from a catalog (CAT) license from the Flexible Consumptions Program (FCP) need to follow a two step process, update the Service check date for the CAT license then refresh the license for the BIG-IP.

Environment

  • BIG-IQ
  • BIG-IP Virtual Edition (VE)
  • Catalog (CAT) license offering
  • Flexible Consumption Program (FCP)

Cause

This license on the BIG-IP needs to be updated from BIG-IQ as the license offering is managed by a CAT key on the BIG-IQ.

Recommended Actions

  • Reactivate the catalog license on the BIG-IQ

  • Refresh the license on the BIG-IP

Note: Reactivating the catalog license on the BIG-IQ doesn't impact the BIG-IP VE or the BIG-IQ configuration.

Reactivate the Catalog License on the BIG-IQ

Note: The BIG-IP isn't impacted when the catalog key is reactivated on the BIG-IQ. 

  1. Log into BIG-IQ GUI
  2. Click on Devices at the top of the screen
  3. Expand License Management from the menu on the left and click on Licenses 
  4. Check the box to the left of the FCP Catalog license
  5. Click the Reactivate button and select either the Automatic or Manual reactivation steps listed in Additional Information below.
    Important: If the reactivate button is greyed out, all the license offerings in the CAT key need to be manually activated. Once they're all activated, the reactivate button will be available. If possible, choose the automatic method to avoid manually activating each license offering next time.
  6. After reactivating the CAT key, its Service Check Date should match today's date. If not, log onto MyF5 > Subscriptions > Subscription # FCP (active), copy the latest CAT key, then reference the following articles to activate it and its license offerings.
    • Manually Activate FCP CAT key and individual license offerings on BIG-IQ - Each license offering must be individually activated and the CAT status remains pending/yellow until all license offerings are activated.
    • Automatically activate FCP CAT key and all license offerings on BIG-IQ - All license offerings are activated and the CAT status is green/active.

Refresh the license on a reachable or unreachable BIG-IP

Reachable BIG-IP

  • If using existing CAT key:
    • Navigate to Devices > License Management > Licenses > CAT key > license offering the BIG-IP
    • Select the Offering Name assigned to BIG-IP
    • Select the check box for the Device Name
    • Click Refresh to update the license on BIG-IP
      Important: Traffic processing will be temporarily disrupted whilst the license is updated on BIG-IP.  This will trigger a failover event in HA cluster if the device is Active.
  • If using new CAT key (from step 6 above):
    • Navigate to Devices > License Management > Licenses > CAT key > license offering the BIG-IP
    • Select the Offering Name assigned to BIG-IP
    • Select the check box for the Device Name
    • Click Revoke to remove the expired the license from BIG-IP
      Important: Traffic processing will be temporarily disrupted whilst the license is updated on BIG-IP.  This will trigger a failover event in HA cluster if the device is Active.
    • Assign a an active license offering to the BIG-IP per License BIG-IP VE from BIG-IQ License Manager

    Unreachable BIG-IP

    If the BIG-IP is unreachable from the BIG-IQ, the reactivation process is slightly different.

      1. Revoke the current, unreachable BIG-IP license on the BIG-IQ
        • On the BIG-IQ, click the Devices tab
        • Navigate to License Management > Assignments
        • Select the unreachable BIG-IP in the list
        • Click the revoke button above. On the next screen, click the "Revoke" button in the lower right corner. On the Confirm Revoke pop-up window, click OK.
        • The license is now revoked. 
      2. Create a new unreachable license and apply the license to the unreachable BIG-IP per the following instructions
        • License a BIG-IP which is unreachable by BIG-IQ using FCP

    Additional Information

    Automatic Method (Internet connectivity required)

    1. Select Automatic
    2. Click on Activate to update all offerings. Note: This doesn't update the license on BIG-IP devices. The BIG-IP isn't impacted when the catalog key is reactivated on the BIG-IQ. 

    Manual Method (No internet connectivity required)

    1. Select Manual
    2. Click Generate Dossier
    3. Copy the dossier 
    4. Open activate.f5.com 
    5. Paste your dossier into the window
    6. Click on Next
    7. Agree to the terms and conditions
    8. Copy the new license file
    9. Paste license file into the BIG-IQ License text box
    10. Click Activate
    11. Repeat this step for each of the license offerings to complete the process. Note: This doesn't update the license on BIG-IP devices. The BIG-IP isn't impacted when the catalog key is reactivated on the BIG-IQ.
