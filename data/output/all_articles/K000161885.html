K000161885: F5 Distributed Cloud API Protection: Enforcement of OpenAPI "format: uuid" Keyword

Type
Support Solution
Published
2026-06-24
Updated
2026-06-24
Applies to

  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000161885

Description

F5 Distributed Cloud API Protection does not enforce the OpenAPI "format: uuid" keyword for schema validation. Type validation is enforced, but values that do not match the declared format (such as uuid) are allowed, even when blocking mode is enabled.

Environment

  • Product: F5 Distributed Cloud Web App & API Protection
  • Feature: API Protection / OpenAPI Validation
  • Configuration: API validation enabled in blocking mode, OpenAPI v3.0 schema property (type: string, format: uuid)

Cause

The OpenAPI "format: uuid" keyword is treated as a non-validating annotation in F5 Distributed Cloud API Protection. Enforcement of format keywords is not supported natively.

Answer/Recommended Actions

  • If native enforcement of format: uuid is required, submit a Request for Enhancement (RFE) to your F5 account team.

Additional Information

  • OpenAPI version supported: v3.0
  • According to OpenAPI Specification, support for format keywords is optional and varies across implementations.
  • Requests with invalid uuid values are classified as OpenAPIValidationSuccessful and allowed.
