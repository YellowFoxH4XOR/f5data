Description
After enabling Bot Defense on a BIG-IP ASM virtual server, you may get an error message in your browser when attempting to access the application.

  • Firefox error message: The page was reloaded, because the character encoding declaration of the HTML document was not found when prescanning the first 1024 bytes of the file. The encoding declaration needs to be moved to be within the first 1024 bytes of the file.

Environment

  • BIG-IP ASM
  • Proactive Bot Defense

Cause
The Bot Defense JavaScript injection is within the the <head> HTML tag and pushes the character encoding declaration beyond 1024 characters where the browser checks for it.

Recommended Actions
Configure injection point for ASM scripts to be after HTML body

Impact of procedure: This is a global setting and will affect all sites/pages processed by the ASM. You should verify the impact on your specific environment.

To configure the injection point for ASM scripts to run *after* client's script, using the following command:
  1. Log in to the BIG-IP command line.
  2. Set the JavaScript injection to happen after the HTML </body> tag
    tmsh modify sys db dosl7.parse_html_inject_tags value \"after,/body\"
