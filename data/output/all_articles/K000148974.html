K000148974: Error when running snmpwalk command "snmpwalk: Timeout (Sub-id not found: (top) -> sysSystemUptime)"

Type
Support Solution
Published
2024-12-31
Updated
2025-04-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148974

Description

The snmpd is not working properly. Report timeout when do local snmpwalk.

[root@big-ip:/S1-green-S::Active:In Sync] config # snmpwalk -v3 -u *** -l authPriv -a SHA -A '***' -x AES -X '***' localhost sysSystemUptime.0

snmpwalk: Timeout (Sub-id not found: (top) -> sysSystemUptime)

Environment

  • LTM
  • snmpd

Cause

The snmpd service is not working properly.

Recommended Actions

  • Restarting the snmpd service will help to aid this issue.
  • Verify the status
    • bigstart status snmpd
  • Restart service
    • bigstart restart snmpd
  • Verify the status again to ensure the service is running
    • bigstat status snmpd
