Known Issue

VIPRION systems may log false power down/up messages.

This issue occurs when all of the following conditions are met:

  • The VIPRION chassis is installed with at least one of the following blade types:
    • B4100 (A100)
    • B4200 (A107)
    • B4300 (A108)
    • B4340N (A110)
  • One or more blades have powered down and/or powered up

Impact

The BIG-IP system may erroneously log these error messages.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H985281 on the Diagnostics > Identified > Low screen.
  • You may observe the error messages logged to the /var/log/ltm file that appear similar to the following example:

    Dec  2 20:19:26 slot1/pred1 err clusterd[3524]: 013a0009:3: Blade 1: blade 2 powered DOWN.
    Dec  2 20:19:26 slot1/pred1 err clusterd[3524]: 013a0009:3: Blade 1: blade 3 powered DOWN.
    Dec  2 20:19:26 slot1/pred1 err clusterd[3524]: 013a0009:3: Blade 1: blade 4 powered DOWN.
    Dec  2 20:19:27 slot1/pred1 notice clusterd[3524]: 013a0010:5: Blade 1: blade 2 powered up.
    Dec  2 20:19:27 slot1/pred1 notice clusterd[3524]: 013a0010:5: Blade 1: blade 3 powered up.
    Dec  2 20:19:27 slot1/pred1 notice clusterd[3524]: 013a0010:5: Blade 1: blade 4 powered up.
    Dec  3 02:58:45 slot1/pred1 err clusterd[3524]: 013a0009:3: Blade 1: blade 2 powered DOWN.
    Dec  3 02:58:45 slot1/pred1 err clusterd[3524]: 013a0009:3: Blade 1: blade 3 powered DOWN.
    Dec  3 02:58:45 slot1/pred1 err clusterd[3524]: 013a0009:3: Blade 1: blade 4 powered DOWN.
    Dec  3 02:58:46 slot1/pred1 notice clusterd[3524]: 013a0010:5: Blade 1: blade 2 powered up.
    Dec  3 02:58:46 slot1/pred1 notice clusterd[3524]: 013a0010:5: Blade 1: blade 3 powered up.
    Dec  3 02:58:46 slot1/pred1 notice clusterd[3524]: 013a0010:5: Blade 1: blade 4 powered up.

    Note: These false logs entries can occur at any time, but are more likely to be generated when the system is under heavy load.

With the observed error reference from above, the following criteria indicates that the reboot messages were false:

  • The clusterd process may report that one or more blades powered down and then up within a 1 to 2-second time interval. For example, the following output indicates that blade 2 powered down at 20:19:26 and then powered up one second later:

    Dec  2 20:19:26 slot1/pred1 err clusterd[3524]: 013a0009:3: Blade 1: blade 2 powered DOWN.
    Dec  2 20:19:27 slot1/pred1 notice clusterd[3524]: 013a0010:5: Blade 1: blade 2 powered up.   
  • The clsh uptime command output does not correspond to the reboot times listed in the clusterd messages. For example, the false log entries may indicate that the blade recently rebooted, although the clsh uptime command output may not corroborate the reboot time listed in the message. The following clsh uptime command output indicates that both blades have an uptime of 74 days:

    === slot 2 addr 127.3.0.2 color green ===
    18:29:01 up 74 days, 15:47,  0 users,  load average: 2.56, 2.23, 1.86
    === slot 3 addr 127.3.0.3 color blue ===
    === slot 4 addr 127.3.0.4 color blue ===
    === slot 1 addr 127.3.0.1 color green ===
    18:29:02 up 74 days, 15:47,  1 user,  load average: 1.52, 1.85, 1.76   
  • The clusterd warnings appear in the log file when there is no other evidence of the blades going up or down. For example, when a VIPRION blade reboots, the system logs error messages to the /var/log/ltm file that appear similar to the following example:

    Nov 16 21:52:57 slot1/atl-lb01a notice clusterd[5015]: 013a0006:5: Goodbye from slot 2.
    Nov 16 21:52:57 slot1/atl-lb01a warning clusterd[5015]: 013a0013:4: Blade 1: blade 2 Down
    Nov 16 21:52:57 slot1/atl-lb01a notice clusterd[5015]: 013a0024:5: Blade 1: Changing primary from 2 to 0 (none)
    Nov 16 21:52:57 slot1/atl-lb01a err clusterd[5015]: 013a0004:3: Fatal error, cleaning up: St9exception
    Nov 16 21:52:57 slot1/atl-lb01a notice clusterd[5015]: 013a0006:5: Transition from state RUNNING to SHUTDOWN.
    Nov 16 21:52:57 slot1/atl-lb01a notice clusterd[5015]: 013a0015:5: Blade 1 quorum state increasing from RUNNING to SHUTDOWN.
    Nov 16 21:52:57 slot2/atl-lb01a info bcm56xxd[4179]: 012c0015:6: Link: 2/1.1 is DOWN
