Description

Unable to access webgui due to /var directory full.


Environment

  • /var disk full
  • WebGUI access

Cause

/var disk full


Recommended Actions

Depending on your environment, you can perform one or more of the following to resolve this issue.

  • Delete unused boot location volumes (Error Message: Disk full (volume group))
  • Reduce file retention period (K000133779: BIG-IQ disk partition is full)
  • Resize /var file system (K30902515: Resizing the /var, /var/log, or /shared file system on a BIG-IQ Virtual Edition)
