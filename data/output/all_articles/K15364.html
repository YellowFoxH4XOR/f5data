Known Issue

BIG-IP APM single sign-on (SSO) may fail for some NTLM-authenticated resources.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access profile uses an SSO configuration for NT Lan Manager (NTLM) authentication.
  • The destination access profile resource is a Microsoft Internet Information Services (IIS) 5.0 web server that requires NTLM authentication.
  • The destination resource sends a connection close header with an HTTP Error 401 - Unauthorized response.

Impact

Attempts to access the destination resource fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users accessing the destination resource through the BIG-IP APM access policy receive a TCP reset from the BIG-IP APM system.
  • Log messages similar to the following example appear in the /var/log/ltm file:

    err tmm[12922]: 01230140:3: RST sent from 10.20.1.30:80 to 15.0.0.109:1905, [0x1605cc4:2786] No server selected
  • When the WebSSO log is set to debug, messages similar to the following example appear in the /var/log/websso file:

    debug websso.1[12537]: 014d0001:7: SWALLOW THE RESPONSE
    debug websso.1[12537]: 014d0001:7: CREATING NEW REQUEST
    debug websso.1[12537]: 014d0001:7: ctx: 0x9a175e0, SERVER: TMEVT_SHUTDOWN_PEER
    debug websso.1[12537]: 014d0001:7: ctx: 0x99fe4a8, CLIENT: TMEVT_ABORT_PROXY
    debug websso.1[12537]: 014d0001:7: webssoContext destructor ...
    debug websso.1[12537]: 014d0001:7: webssoConfig destructor
