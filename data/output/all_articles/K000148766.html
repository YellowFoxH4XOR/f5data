Description

Unexpected unknown status on AS3 deployed application in 20.3.0 (same application deployed via earlier version of Next CM does not behave this way)

Environment

  • Next CM and Instance Version 20.3.0
  • AS3 Deployed Application

Cause

Unlicensed Instances in 20.3.0 do not behave like licensed instances and can have unpredictable results (including unknown application status)

Recommended Actions

Properly License the Next Instance
