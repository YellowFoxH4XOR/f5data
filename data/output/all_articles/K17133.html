Known Issue

The BIG-IQ Network Security object editor returns empty results when an IP address is used to filter results.

Important: This issue only affects BIG-IQ Security 4.4.0 HF2.

This issue occurs when all of the following conditions are met:

  • In the BIG-IQ Security system's Network Security Configuration utility, you navigate to the Security > Network Security > Object Editor page.
  • In the filter text field, you submit an IP address.

Impact

The Network Security object editor returns empty results when an IP address is used to filter results.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using an IP address to filter results, the Network Security object editor returns empty results.

Workaround

To work around this issue, you can escape the period characters in the IP address.

For example, when searching for 192.168.10.100, type 192\.168\.10\.100 to filter the results.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
