Known Issue

Secure Web Gateway (SWG) subscription licenses may display as evaluation licenses.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured and provisioned with a SWG subscription evaluation license.
  • You apply a production SWG subscription license to a BIG-IP APM device.
  • When you view the applied BIG-IP license details, the license key for the SWG subscription matches the production key ID.

Impact

SWG subscription expiration warnings persist.

Note: You can safely ignore the SWG subscription and evaluation expiration messages.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Resource Provisioning page displays a license status for SWG that appears similar to the following example:

    Evaluation expires after: <MMM, DD, YYYY>

  • When you are logged on to the command line of the affected device, the command line displays a prompt that appears similar to the following example:

    root@<hostname>:Eval:<device state>:<synchronization state><directory>>
