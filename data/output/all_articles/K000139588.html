Description

In an active-active configuration(also applies to a single bigip or active-standby), while remote logging for Dos and Bot Defense protection has been configured properly, remote logs are seen on the logging server only from one of the bigips.

No error logs can be seen in the unit that does not send the logs.

Environment

  • Dosl7 remote logging
  • Bot Defense remote logging

Cause

Unknown as no error messages can be found relevant to the behavior.

Recommended Actions

  1. Verify that the configuration of remote logging is based on K000136107.
  2. Restarting dosl7d might fix the issue.

# bigstart restart dosl7d
