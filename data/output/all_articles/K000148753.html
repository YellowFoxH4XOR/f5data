K000148753: GUI error ''Some fields below contain errors. Correct them before continuing'' while trying to change the Service Port of the Virtual Server

Description

Changing a Virtual Server's Service Port from Port to Port List gives you the below error in GUI.

"Some fields below contain errors. Correct them before continuing."

 

This error occurs when you deploy the Virtual Server using any iApps.


It is also unclear which fields are problematic and have to be corrected.

 

Environment

  • BIG-IP LTM running supported iApp template
  • Virtual Server created via iApp
  • Change Service Port from Port to Port list

Cause

Shared objects cannot be used on iApp Virtual Servers since this feature is not integrated into the iApp template.

 

Recommended Actions

In order to use the Port List, you need to create the Virtual Server manually instead of using iApps. 

 

Make sure that if your pool members are listening only on one port, change it to any to match the Port List.

 

Additional Information

iApp template is designed to use the "create virtual" command while shared objects are created by "create traffic-matching-criteria". This is the reason for the GUI error.
