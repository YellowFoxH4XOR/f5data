Description

While navigating to the menu Access ›› API Protection : Profile of the BIG-IP Configuration Utility, you get prompted with the following message:

No API Protection License: All requests will fail and no traffic will pass through

Environment

  • BIG-IP

  • Hardware ELA / FCP (Golden key)
  • APM

Cause

In some cases, prior to 16th October 2024,  the FCP Licenses did not contain API protection specific modules as listed below:

apm_logon_page_fraud_protection : enabled
apm_api_protection : enabled
api_protection_infra : enabled

Answer/Recommended Actions

If your license was activated on or before 16th October 20204, you will need to reactivate the license to add the additional functionality.

See Additional information below on how to reactivate.

Note: Reactivating the license is service impacting and is clearly detailed in the solution below.
