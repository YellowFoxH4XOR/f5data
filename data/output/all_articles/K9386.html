Topic

For security reasons you may be required to set the SNMP system contact settings, such as the Contact Information and Machine Location settings, to a null value. To set the SNMP system contact settings to a null value for BIG-IP 9.4.2 and later, you can use the bigpipe snmpd command.

For example, to set the Contact Information setting to a null value, perform the following procedure:

  1. Log in to the command line.
  2. To set the Contact Information setting to a null value, type the following command:

    bigpipe snmpd syscontact none
  3. To save the settings, type the following command:

    bigpipe save all

Note: In BIG-IP 9.0.0 through 9.4.1, there is not a supported method to set the SNMP system contact settings to a null value. To work around this issue, you can use the Configuration utility and enter two double-quote ( " " ) characters for the system contact setting, and then click Update.
