Description

This article describes the effects of disabling AVR on LTM policy/irule during runtime with ASM module.

One may notice inaccuracies or failure in detection of CSRF, BruteForce protection enabled, while AVR disabled in LTM. 

Environment

  • ASM
  • BOT Defense
  • DoSL7
  • Disabling AVR

Cause

  • AVR is responsible for determining if a URL is qualified for injection or not for these. This primarily is CSRF and Brute-Force protections. Disabling that will prevent bd from being able to know if a url can have JS injected.
  • AVR is used for TPS statistics and other numerical statistics management. DosL7 features that depend on TPS will lose the statistics from AVR when AVR is bypassed or disabled for that traffic.

Recommended Actions

Avoid disabling AVR module when having ASM functionalities enabled in the Virtual Server.
