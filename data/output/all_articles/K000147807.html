K000147807: How can I redirect to a maintenance page if none of the pools in the DNS XC Load Balancer are working?

Source

What Happened?

  • If I set up Primary and Secondary pool on a DNS loadbalancer and the domain is failing on both the pools while the same health check is enabled(on both the pools) - Is there a way that I can redirect it to a maintenance page of another domain to let users know that the website is down?

Environment

  • F5® Distributed Cloud (XC)
  • F5XC DNS Load Balancer

Resolution/Answer

There’s a “fallback pool” option when creating a DNSLB which we added recently exactly for the above use case. What you’ll do for that pool is:

  • Add the IP endpoint of the web server you want to answer with (Maintenance page)
  • Do NOT add health check for that pool (since this is a fallback pool, there’s no point in constantly doing health checks against its member)
  • Select that pool in the “fallback pool” section (see attached picture)

Additional Information

The Logic for DNS query matching:

  1. If the DNS query matches the LB rules for both the highest score pool and another pool:
    • a) The request will go to the highest score pool if it has healthy members.
    • b) If the highest score pool is unhealthy, the request will go to another pool, assuming it has healthy members.
  2. If the query matches just one pool, the request will go to it if it has healthy members. Else, The request will go to the fallback pool.
  3. If the query does not match any of the LB rules, it will go to the fallback pool.
  4. Redirecting to a different URL is beyond the scope of the DNS load balancer. It can only return a different IP address.
