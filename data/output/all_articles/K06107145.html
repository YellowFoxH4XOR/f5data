Description
You want to log the client's IP address with a Local Traffic Policy.

Environment

  • BIG-IP LTM policy
  • Client IP address

Cause
None

Recommended Actions

You can log the client's IP address by using TCL on the Local Traffic Policy Rule when conditions are matched.

  1. From the Configuration Utility, choose Local Traffic > Policies.
  2. Click Create button.
  3. Enter the name of the LTM Policy and click Create Policy button.
  4. Click Create button in the Rules section.
  5. Click + button in Do the following when the traffic is matched section.
  6. Select Log and enter tcl:[IP::client_addr] in the input box next to message. Alternatively, you can include additional information in the log string, for example: tcl:The client from [IP::client_addr] with source port [TCP::client_port] connected to [IP::server_addr]
  7. Select an event in the at ... time drop down menu.
  8. Hit Save.
