Known Issue

A dynamic bandwidth control policy fails to achieve the bandwidth specified by the Maximum Rate Per User value.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with a dynamic bandwidth control policy.

    Note: Bandwidth control policies are static by default; the Dynamic setting is disabled.

  • The dynamic bandwidth control policy has a category configured with a Max Category Rate that is a lower value relative to the Maximum Rate Per User value of the policy.
  • The virtual server processes an amount of non-TCP data that is 150 percent of the Maximum Rate Per User value.

When you configure a dynamic bandwidth control policy with a maximum category rate that is lower than the maximum rate per user, and the amount of non-TCP traffic going through the category is 150 percent of the Maximum Rate Per User value, the policy is activated and lowers the overall bandwidth.

Impact

The affected dynamic bandwidth control policy cannot achieve 100 percent of the Maximum Rate Per User value.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Non-TCP traffic to a virtual server that uses an affected bandwidth control policy configuration experiences lower throughput than expected (less than the Maximum Rate Per User value).

Workaround

To work around this issue, you can increase the Maximum Category Rate of the dynamic bandwidth control policy, and add an additional static policy to set the maximum rate expected from the dynamic bandwidth control policy.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.
