K7795: Increased timeout and retrieval attempts for Network Access PAC file download

Issue

Starting in FirePass 6.0.2, when you specify a proxy autoconfiguration (PAC) script for a Network Access connection, the FirePass Network Access client makes three attempts to retrieve the PAC script file. Additionally, the Network Access connecting timeout was increased from two minutes to three minutes to provide the Network Access client more time to retrieve the file.
 
Previously, the FirePass Network Access client would make only one attempt to retrieve the PAC script file and the Network Access connecting timeout was two minutes.
 
Note: Proxy autoconfiguration settings are configured on the Network Access > Resources page under the Client Settings tab.

F5 Product Development tracked this enhancement as CR81555 for the FirePass 6.0 software branch, and it is included starting in version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-601-5 has been issued for FirePass 6.0.1. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
