Description

After adding new GTM/DNS server to iQuery mesh, the system does not synchronize with the existing GTM/DNS servers, and repeatedly reports the error "cannot find my box" in /var/log/gtm

notice gtmd[12345]: 011a001c:5: SYNC bigip_gtm.conf from <DNS self IP> skipped. Reason: cannot find my box
notice gtmd[12345]: 011a001c:5: SYNC server.crt from <DNS self IP> skipped. Reason: cannot find my box

Environment

  •   GTM/DNS
  •   Adding Server to sync group

Cause

The new GTM/DNS server used "gtm_add" command to pull over the existing configuration. But, before doing gtm_add it is necessary to add the new server's IP address into the existing GTM/DNS configuration.

Recommended Actions

On the existing GTM/DNS system, add the new Server object and self-IP. Then, on the new Server, use gtm_add to pull the configuration over.
