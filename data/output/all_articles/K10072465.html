Description
Is it possible to have a remote user role with a more granulated, restricted access to ASM configuration items.

Environment

  • Remote AD authentication
  • ASM configured
  • Want to limit user to saving and exporting policies, but not able to make changes.

Cause
Our user roles are not customizable. You are limited to available user roles with pre-defined permissions

Recommended Actions

  1. There are no recommended actions at this time.
