Description

You see a lot SSL warning level logs and want to suppress them. For example LTM logs in your BIG-IP is filled with below types of log messages and due to this you loose track of other important logs.

In the below example. 203.0.113.5 is a client or source IP address trying to connect to 192.0.2.10 which is virtual server IP in the BIG-IP.

Aug 1 02:02:00 bigip1.local warning tmm5[11575]: 01260009:4: 203.0.113.5:12431 -> 192.0.2.10:443: Connection error: ssl_codec_rx:2293: alert(90) received alert 

Environment

  • BIG-IP LTM
  • SSL/TLS failure logs

Cause

SSL/TLS failures between remote device and BIG-IP virtual server. The issue differs from each SSL error code. For more details refer K29346112: Error Message: 01260009:4: Connection error: <ssl_function>:<function_id>: <error_reason> (<reason_code>).

Recommended Actions

If possible try to fix those SSL failures. If not, you could suppress the log message by changing the logging level. By default SSL log level is at warning. You can set the SSL log level to error using below command, so you will see SSL log level messages from error and above.

tmsh modify sys db log.ssl.level value error
