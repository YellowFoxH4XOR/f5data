Known Issue

The BIG-IP APM system may not rewrite certain server-side JavaScript code.

This issue occurs when all of the following conditions are met:

  • A user accesses a destination server that returns content written in JavaScript.
  • The server's JavaScript code is written using nonstandard syntax accepted by the Microsoft Internet Explorer browser.

    For example:

    <script>
    document.write(1);
    function f () {
    if (a){
    stmts1;
    };else{
    stmts2;
    }
    }
    </script>


    do {stmts};while(condition);
    try {stmt};catch(condition){};finally{};


    Important: The semicolon (;) preceding the "else", "while," and "catch" statements are examples that deviate from the accepted standard for JavaScript coding.

Impact

JavaScript-dependent content may not function as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Web page content that depends on the BIG-IP APM rewrite of JavaScript does not function.
  • JavaScript users cannot access links and web page applications.
