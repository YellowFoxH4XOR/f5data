Known Issue

BIG-IP APM access policies that use HTTP basic single sign-on (SSO) fail to export.

Impact

You cannot export the desired access policies.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Exporting through the Configuration utility hangs with the following message:

    Receiving configuration data from your device.

Resolution

Workaround

To work around this issue, you can remove the HTTP basic SSO from the access policy. To do so, perform the following procedure:

Impact of workaround: Disabling the SSO on a production system will force users to re-enter their password when accessing resources through BIG-IP APM. Additionally, the SSO will not be exported with the access policy; you will need to add the SSO back to the access policy after import.

  1. Log on to the Configuration utility.
  2. Click Access Policy.
  3. Click the name of the access policy to edit.
  4. If your BIG-IP version is 11.1.0 or later, click the SSO/Auth Domains tab.
  5. Select None from the SSO Configuration drop-down menu.
  6. Click the Update button.

Note: After exporting the access policy, re-enable the SSO by performing the previous procedure and selecting the original SSO configuration in Step 5.
