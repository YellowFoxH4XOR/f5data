Topic

This article discusses the purpose and use cases of the Ignore Persisted Weight option.

Description

The BIG-IP system provides several load balancing methods that can be used for load balancing traffic to pool members. However, when configured, persistence can interfere with some load balancing method calculations that the BIG-IP system uses to determine pool members' relative load.

The Ignore Persisted Weight option, introduced in BIG IP 11.0.0, specifies how the system handles persistent connections when calculating the relative load of a pool member and allows you to prevent the system from counting persisted connections as part of that load.

The Ignore Persisted Weight option is available for the following load balancing methods:

  • Ratio (member)
  • Ratio (node)
  • Observed (member)
  • Observed (node)
  • Predictive (member)
  • Predictive (node)

Two options are available:

  • Cleared (default): Specifies the system uses persisted connections to calculate the relative load of pool members when making load balancing decisions.
  • Selected: Specifies the system does not use persisted connections to calculate the relative load of pool members when making load balancing decisions.

Note: In BIG-IP 10.x.x and earlier, the system calculates all persistent connections as part of pool members' relative load.

  • Using the Configuration utility to configure the Ignore Persisted Weight option
  • Using the tmsh utility to configure the Ignore Persisted Weight option

Using the Configuration utility to configure the Ignore Persisted Weight option

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Pools and select the pool you want to update.
  3. Select the Members tab.
  4. In the Load Balancing Method list, select one of the following options:
    • Ratio (member)
    • Ratio (node)
    • Observed (member)
    • Observed (node)
    • Predictive (member)
    • Predictive (node)
  5. Select the Ignore Persisted Weight check box.
  6. Select Update.

Using the Traffic Management Shell (tmsh) to configure the Ignore Persisted Weight option

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To check the configuration of the pool you want to update, use the following command syntax:

    show /ltm pool <pool name> all-properties

    For example, the following command shows the pool configuration for MyPool:

    show /ltm pool MyPool all-properties

  3. Ensure that one of the following load balancing modes is listed:
    • Ratio-member
    • Ratio-node
    • Observed-member
    • Observed-node
    • Predictive-member
    • Predictive-node
  4. To enable Ignore Persisted Weight, use the following command syntax:

    modify /ltm pool <pool name> ignore-persisted-weight enabled

    For example, the following command enables Ignore Persisted Weight for MyPool:

    modify /ltm pool MyPool ignore-persisted-weight enabled

  5. To save the changes, type the following command:

    save sys config

Recommendations

If you are using long-lived persistent connections, F5 recommends that you leave the Ignore Persisted Weight option disabled to prevent overloading the pool members.
