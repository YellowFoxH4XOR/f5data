Issue

Error Message

warning eca[<PID>]: 0162000f:4: Received invalid type of NTLMSSP message

In this error message, note the following:

  • <PID> is the process ID for the eca process

For example:

warning eca[4585]: 0162000f:4: Received invalid type of NTLMSSP message

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file
Description

This message occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured to provide client-side NT Lan Manager (NTLM) authentication.
  • The client sends a message with an unexpected NTLM message type.

The NTLM implementation in BIG-IP APM expects to receive the NTLMSSP_NEGOTIATE NTLM message type (Type 1) when initially processing new authentication attempts. The BIG-IP APM system will then send an HTTP 401 response with an NTLMSSP_CHALLENGE (Type 2) to the client. The client can then follow the response with an NTLMSSP_AUTH message (Type 3) in response to the challenge.  

The system generates this error message if the client sends an NTLMSSP_CHALLENGE or NTLMSSP_AUTH type message when the BIG-IP APM system expects a NTLMSSP_NEGOTIATE type message.

Impact

The BIG-IP APM system resets the connection and the authentication attempt fails.

Recommended Actions

Inspect the client-side traffic to determine why the BIG-IP APM system is receiving unexpected messages. Check to ensure firewalls or proxies between the client and the BIG-IP APM system have not modified or blocked the messages.
