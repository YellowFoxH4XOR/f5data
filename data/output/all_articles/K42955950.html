Description
After repeated attempts to deploy an Azure BIG-IP LTM Virtual instance in Microsoft Azure,  you are unable to complete the deployment with an error: 

In the error, it includes,  "code": "DeploymentFailed",  and  \"code\": \"ResourceDeploymentFailure\

Environment

  • Microsoft Azure
  • BIG-IP LTM VE
  • BIGIP ARM deployment in Azure

Cause
When Multiple attempts to deploy occur, you may find failed partial configuration objects in the existing Stack, which results in a deployment failure when attempting another deployment.   Azure deployments do not overwrite existing objects. 

Recommended Actions

  • In order to make sure that resources from the old deployment were removed from any resource-group, you need to open https://resources.azure.com and navigate to "Subscriptions -> Subscription name -> Resource Group -> RG name -> Resources."  and review all the deployment objects from previous attempts.

Once you confirm that resources from old deployment have been removed, go ahead and initiate new deployment into the same resource-group.
