Known Issue

After you attempt to change the authentication, authorization, and accounting (AAA) Active Directory (AD) server administrator password, the BIG-IP APM system fails to remove the cached Kerberos tickets and incorrectly uses the cached tickets with old credentials for an AD query.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM system with an AAA AD server.
  • You configure the BIG-IP APM access policy with an AD query agent.
  • You attempt to change the AAA AD server administrator password that the AD query agent references and apply the access policy.
  • The cached Keberos ticket is invalid.

Impact

The BIG-IP APM system uses invalid cached Kerberos tickets and incorrectly processes an AD query for BIG-IP APM user logins.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • An AD query unexpectedly succeeds or fails.

Workaround

To work around this issue, you can manually delete the invalid Kerberos cache files (krb5cc_0 and krb5cc_1). To do so, perform the following procedure:

Impact of workaround: When you delete Kerberos cache files, Kerberos makes requests as users log in, which may result in a higher number of DNS and Kerberos requests in the network. F5 recommends that you perform this procedure during a scheduled maintenance window for the affected BIG-IP system.

  1. Log in to the command line of the affected system.
  2. Change directories to the AAA AD server's Kerberos directory by using the following command syntax:

    cd /var/run/apmd/krb5cc/<partition_name>/

    For example, you type the following command:

    cd /var/run/apmd/krb5cc/Common/

  3. To remove the invalid Kerberos cache files, use the following command syntax:

    Important: The rm -rf command runs a recursive deletion. Ensure that you have the proper directory and profile name before running this command.

    rm -rf ./<name of AAA AD server to delete>

    For example, you type the following command:

    rm -rf ./ad_server_name
