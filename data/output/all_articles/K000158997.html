Description

When configuring the AOM's IPv4 gateway on F5OS-A, the following warning message appears after committing the configuration:

--- WARNING ------------------------------------------------------
Running db may be inconsistent. Enter configuration mode and load a saved configuration.
------------------------------------------------------------------

This warning occurs when the AOM's IPv4 address and gateway are configured in different IP subnets. The warning persists even after loading a saved configuration if the subnet mismatch is not corrected.

Environment

  • F5OS-A
  • AOM IPv4 address and gateway configured in different IP subnets

Cause

The AOM's IPv4 address and gateway were configured in different IP subnets, causing a configuration database inconsistency. F5OS detects this subnet mismatch during the commit operation and generates the warning message to alert administrators of the configuration inconsistency. 

Recommended Actions

  1. Verify the current AOM configuration:

    show system aom

  2. Identify the AOM IPv4 address and its subnet mask (prefix-length)

  3. Configure the AOM IPv4 gateway to be within the same IP subnet as the AOM IPv4 address:

    config
system aom config ipv4 gateway <gateway_ip_in_same_subnet>
commit

  4. Verify the warning has been cleared and the configuration is consistent:show system aom

Note: Ensure proper subnet planning before configuring AOM settings, especially in production environments.

Additional Information

  • The warning does not prevent the configuration from being applied, but indicates a potential network connectivity issue
  • Loading a saved configuration without correcting the subnet mismatch will not permanently resolve the warning
  • Both the AOM IPv4 address and gateway must be within the same IP subnet for proper network connectivity and to avoid database inconsistency warnings
  • This issue can occur during initial AOM configuration or after F5OS upgrades when reconfiguring AOM settings
