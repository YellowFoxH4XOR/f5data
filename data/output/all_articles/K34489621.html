Description

  • Edge Client connection to APM Virtual Server does not start.
  • Downloading   /public/download/OesisInspector.cab  or   public/download/BIGIPComponentInstaller.msi from the APM Virtual Server via the internet results in a RST with no data transferred.
  • Nothing is logged.
  • The RST does not have a Cause Code

Environment

  •  APM with a network access resource configured.
  • This download is performed by the Edge Client to check for updates before starting a session.

Cause

System corruption. Hypervisor storage failures may do this.

Recommended Actions

  1. Reinstall to another boot slot. (no change to version)
  2. Update the Anti-Virus (EPSEC) and APM Client
  3. Remove old Anti-Virus updates.

Additional Information

Installing to a new boot location has the effect of applying the configuration to a fresh install.
