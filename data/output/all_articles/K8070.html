Known Issue

This is the result of a known issue. The event daemon uses iControl messaging to provide asynchronous event notification to subscribers, such as Enterprise Manager systems. When the eventd process receives a shutdown signal while a message notification is in progress, the eventd process can crash.

F5 Product Development tracked this issue as CR86980 and it was fixed in BIG-IP LTM 9.3.1 and 9.4.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
