Known Issue

The websso daemon experiences high CPU usage with Kerberos single sign-on (SSO) due to an implementation of the LRU Cache that is not scalable.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM access profile with Kerberos SSO.
  • A large number of users log in to the BIG-IP APM system using Kerberos SSO.

The maximum number of cached entries is currently set to 20,000. When this number is exceeded, the BIG-IP system destroys older entries using the LRU algorithm. The performance of the LRU Cache drops linearly as the number of cached Kerberos tickets increases, resulting in high CPU usage. For more information about Kerberos Credential Caching, refer to the Kerberos Single Sign-On Method chapter of the BIG-IP Access Policy Manager: Authentication and Single Sign-On manual.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Impact

The performance of the BIG-IP APM system handling HTTP requests decreases, and users experience increased latency when accessing applications.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The output from the top or ps commands shows high CPU usage for the websso daemon.
  • The BIG-IP APM virtual server configured with Kerberos SSO experiences decreased performance as more users log in.

Workaround

To work around this issue, you can reduce the number of cached Kerberos user tickets by lowering the default ticket lifetime from 600 minutes. For example, to modify the ticket lifetime to 120 minutes, perform one of the following procedures:

  • Lowering the default ticket lifetime (BIG-IP 13.x)
  • Lowering the default ticket lifetime (BIG-IP 11.x - 12.x)

Impact of workaround: When you reduce the ticket lifetime, the frequency of Kerberos ticket requests increases and may result in a higher number of DNS and Kerberos requests in the network. F5 recommends that you perform these procedures during a scheduled maintenance window for the affected BIG-IP system.

Lowering the default ticket lifetime (BIG-IP 13.x)

  1. Log in to the Configuration utility.
  2. Navigate to Access > Single Sign-On > Kerberos.
  3. Click the name of the affected Kerberos SSO object.
  4. Under SSO Method Configuration, in the Ticket Lifetime box, type 120.
  5. Click Update.

Lowering the default ticket lifetime (BIG-IP 11.x – 12.x)

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > SSO Configurations > Kerberos.
  3. Under SSO Method Configuration, in the Ticket Lifetime box, type 120.
  4. Click Update.
