K8556: The Configuration utility does not allow you use a custom profile as the parent for a new custom profile

Known Issue

This is the result of a known issue. When creating a new custom profile, the Configuration utility does not allow you to use another custom profile as its parent. The Configuration utility only displays the base parent profile.

For example, the following TCP profiles are configured by default:

  • tcp
  • tcp-lan-optimized
  • tcp-wan-optimized

The tcp-lan-optimized and tcp-wan-optimized profiles are custom profiles, which use the tcp profile as their parent.

If a user attempts to create a new custom TCP profile, the default TCP profile is the only available profile listed to inherit properties. The tcp-lan-optimized and tcp-wan-optimized profiles are not listed, even though they are valid custom profiles.

Note: This issue affects all profiles, not just TCP.

F5 Networks Product Development tracked this issue as CR95087 and it was fixed in BIG-IP LTM versions 9.4.5 and 9.6.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.4-73.1-HF1 issued for BIG-IP version 9.4.4 for the BIG-IP 9.4 software branch. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
