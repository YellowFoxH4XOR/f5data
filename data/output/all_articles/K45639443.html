Description

Active Directory user with Admin role can't access ASM Guide configuration

Environment

  • ASM provisioned
  • AWAF license
  • Remotely authenticated user

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 957337

Recommended Actions

You can do either of the following:

  • Upgrade to a software version where Bug ID 957337 is fixed
  • Use local admin credentials instead of the AD credentials

None
