In this video, AskF5 shows you how to create a firewall rule to restrict access to your BIG-IP system management interface using the Configuration utility and the TMOS Shell (tmsh). You'll also learn how to use the TMOS Shell delete network firewall rules.

This demo uses BIG-IP 16.0.

  • 00:00 Intro
  • 00:10 Use the Configuration utility to create a firewall rule to restrict management interface access
  • 02:07 Use the TMOS Shell to create a deny-all rule to reject traffic to management interface
  • 02:42 Use the TMOS Shell to delete a management port firewall rule

TMOS Shell rule syntax:

modify /security firewall management-ip-rules add { ‹rule-name› {
action [accept|drop|reject]
app-service ‹service›
description ‹description›
destination { [addresses|address-list|port-list|ports] add ‹destination› }
icmp [add|delete|modify|replace-all-with|none] [type|type:code]
ip-protocol ‹protocol›
log [no|yes]
place-after
place-before
rule-list
schedule
source { [addresses|address-list|port-list|ports] add { ‹source› }
status
uuid
} }
