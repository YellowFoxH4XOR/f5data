Description

When running the f5-system-scanner on a BIG-IP system, a mismatch is reported for the file /etc/security/opasswd or /etc/security/pwqualify.conf. The scanner output indicates a SHA512 hash mismatch. Example error message: MISMATCH etc/security/opasswd sha512 expected: <expected_hash> sha512 actual: <actual_hash>

Environment

  • Product: BIG-IP (All Modules)
  • File: /etc/security/opasswd or /etc/security/pwqualify.conf
  • Scanner tool: f5-system-scanner

Cause

Each flagged file must be reviewed to determine if the change is expected.

A common benign reason for /etc/security/opasswd or /etc/security/pwqualify.conf to be flagged as a mismatches can be if a BIG-IP device was ever configured with a local secure password policy. The scanner tool compares the file to a default reference and flags any deviation, even if the change is expected and benign.

 

Validate a Big-IP has configured a secure local password policy by reviewing your local devices /etc/security/opasswd or /etc/security/pwqualify.conf files, then compare them to the system defaults below. These files are automatically updated from the system default parameters to device customizable parameters whenever the following article is utilized: K15497: Configuring a secure password policy for the BIG-IP system

 

/etc/security/opasswd : The system default for this file is blank. When password history is enabled, this file contains encrypted old user passwords

 

/etc/security/pwqualify.conf

 

 

Answer/Recommended Actions

  • Each flagged file must be reviewed to determine if the change is expected.
  • The scanner highlights differences from the default configuration yet may not indicate a harmful or critical issue. 
  • A common difference in the /etc/security/opasswd or /etc/security/pwqualify.conf files can occur if the BIG-IP device was ever configured with a local secure password policy.
