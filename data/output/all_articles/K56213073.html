K56213073: SNMPv3 support for SHA2 and AES256 is not available on BIG-IQ

Type
Support Solution
Published
2022-02-15
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • Public Cloud
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K56213073

Description

This article covers the current status of SNMPv3 support for SHA2 and AES256 on BIG-IQ.

Environment

  • BIG-IQ 8.0.x or lower
  • Net-SNMP 5.7.2 or lower

Cause

BIG-IQ 7.x and 8.x or use Net-snmp 5.7.2 and SHA-256/AES-192 or AES-256 are only available in Net-snmp library 5.8.
Please refer to the following article for Net-snmp library version used on BIG-IQ: K15861: BIG-IQ third-party software matrix

Recommended Actions

  • Currently, there is no support for Net-snmp library v.5.8 on all the BIG-IQ versions.
  • This feature is being tracked as an RFE (Request for Enhancement) for a future version.
  • Requesting for Engineering hotfix (EHF) is not possible at this time.
