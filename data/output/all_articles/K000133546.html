K000133546: BIG-IP APM removes invalid DNS address space entries after upgrade to BIG-IP 16.0.0 or later

Type
Knowledge
Published
2023-04-18
Updated
2023-04-18
Applies to
  • BIG-IP
  • BIG-IP APM: 16.0.X, 16.1.X, 17.0.X, 17.1.X, 17.1.0, 17.0.0, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K000133546

Description

After an upgrade to BIG-IP 16.0.0 or later, you may observe the BIG-IP APM system removed entries you configured in the DNS address space field of a Network Access resource.

For example, at BIG-IP 15.1.x, before the upgrade, you configured the following entries for DNS address space:

  • site.example.com
  • *example.com
  • *.example.com
  • *.
  • 10.0.0.10
  • sales.*.example.com
  • .example.*com
  • *.*.f5.com
  • *.f5.*
After the upgrade at BIG-IP 16.1.0, you observe the system removed the invalid entries leaving the following 4 valid entries:
  • site.example.com (only exact match)
  • *example.com (matches example.com, dnsexample.com, dns.example.com, sales.dns.example.com)
  • *.example.com (matches sales.example.com, na.sales.example.com)
  • *. (matches all)

Note: The DNS address space field can be found on the Configuration utility at Access > Connectivity / VPN > Network Access (VPN) > <Name of Network Access resource>, select the Network Settings tab. This box only appears if you use split tunneling.

Select the Help tab on the left side of the Configuration utility for more information.

Environment

  • Upgrade to BIG-IP APM 16.0.0 or later.
  • Network Access resource

Cause

This is expected behaviour due to the fix described in ID 778321. Prior to BIG-IP APM 16.0.0, the system does not perform validation checks when you configure entries for DNS address space, allowing invalid entries to be saved.

Beginning in BIG-IP APM 16.0.0 that contains the fix for ID 778321, the system validates entries and removes invalid entries that you configured prior to the upgrade.

Recommended Actions

F5 recommends the following:

  • Do not enter invalid entries in the DNS Address Space and DNS Exclude Address Space of a network access resource.
  • Refer to the Description section of this article for valid and invalid examples.
  • Refer to the online help on the BIG-IP Configuration utility for more information. You can find the online help on the Help tab of the left panel.
