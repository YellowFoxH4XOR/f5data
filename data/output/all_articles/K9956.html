Known Issue

This is the result of a known issue. A SNAT translation address is a SNAT configuration object that specifies the IP address(es) that you want to map to origin IP address(es). Currently, a SNAT translation address is automatically deleted when the last reference to it is deleted. For example, a SNAT pool contains one or more SNAT translation addresses. When the only reference to a particular SNAT translation address is a SNAT pool, and the SNAT pool is deleted from the configuration, the SNAT translation address is also deleted. This is expected behavior as it prevents the system from silently accruing a collection of unused translation addresses.

However, when a SNAT translation address has non-default setting, such as a custom timeout value, the automatic deletion behavior causes the translation address to revert to default settings when the translation address is next used. For example, if you have a SNAT pool containing translation addresses with a custom timeout value, and you add additional SNAT translation addresses to the SNAT pool, the BIG-IP system first deletes all current SNAT pool members and then re-adds the members along with the new members. When the existing members are removed from the SNAT pool, the corresponding SNAT translation addresses are also deleted. As a result, the custom timeout value is deleted from the SNAT pool configuration.

F5 Networks Product Development is tracking this issue as CR119678.
