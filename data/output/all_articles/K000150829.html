Description

You want to manage MyF5 Self Service license keys from BIG-IQ, whether for automation purposes or ease of management. RegKey Pools on the BIG-IQ offer the flexibility to import, activate, and manage these BIG-IP Virtual Edition (VE) licenses.

Environment

  • BIG-IP Virtual Edition (VE)
  • BIG-IQ
  • New FCP Contract
  • MyF5 Customer Portal
  • MyF5 Self Service License Keys 

Cause

You have many license keys from MyF5 subscriptions that you'd like to manage from a central repository.

Recommended Actions

  1. From the MyF5 Customer Portal: Create necessary license keys
    • K000148592: Generate Self Service license keys in MyF5
  2. On the BIG-IQ, create a RegKey Pool
    • Big-IQ CM > Devices tab > License Management > Licenses > AddRegKey Pool
  3. Add the license keys from MyF5 and activate them.
    • K77706009: Activate a license key from RegKey Pool on BIG-IQ (automatic method)
    • K77706009: Activate a license key from RegKey Pool on BIG-IQ (manual method)
      Important: Once these keys are activated they report utilization, whether or not assigned to a BIG-IP VE.
  4. Either apply the license key to a BIG-IP VE directly or use existing automation processes to pull from the list and apply to a BIG-IP VE. 
    • K000150116: Assign a BIG-IP VE License from the RegKey Pool on BIG-IQ
      Important: Assigning a license key to a BIG-IP VE is traffic impacting as its services restart to process the new license.
