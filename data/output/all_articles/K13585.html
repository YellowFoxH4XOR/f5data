Known Issue

Description

When updating the interval time of a snapshot schedule, the ARX does not properly update the start time.

This occurs when the following condition is met:

  • The GUI is used to modify the snapshot schedule

Impact

The scheduled snapshots may not run when expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The snapshot schedule start time does not match the intended configured time

    Note: You can identify the configured schedules and schedule configuration by using the show policy schedule command.
  • The snapshot schedule runs at the time it was modified by a user instead of at the configured time. For example, if a user logs in at 12:35 p.m. and modifies the snapshot schedule to run at 2:30 p.m., the snapshot schedule will erroneously run at 12:35 p.m.

Workaround

To work around this issue, you can use the CLI to change the timing of a snapshot schedule. To do so, perform the following procedure:

Impact of workaround: None.

Changing the interval time of a snapshot schedule


















  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:
enable
  • Identify the schedule configuration by typing the following command:
show policy schedule Output will appear similar to the following example:   Schedule:         daily     Start Time:       Sat Mar 26 19:13:00 2012     Interval:         00:00,06:00,12:00,18:00 hours of the day     Status:           Running (runs in 02:24:25)     Previous:       Run Time:         Sat Mar 27 06:00:00 2010       End Time:         N/A     Next:       Run Time:         Sat Mar 27 12:00:00 2010       End Time:         N/A
  • Enter global configuration mode by typing the following command:

    global
  • Enter the schedule configuration mode by using the following command syntax, and replacing [schedule name] with the name of the schedule you want to edit:
schedule [schedule name] For example: bstnA(gbl)#schedule daily
  • To adjust the start time of the schedule, use the following command syntax:
start [mm/dd/yyyy:HH:MM[:00]] For example, the following command sets a start date for the daily schedule to November 12, 2004 at 11 p.m.: bstnA(gbl-schedule[daily])#start 11/12/2004:23:00
  • To adjust the interval time of the schedule, use the following command syntax:
every count {minutes | hours |days | weeks | months | quarters | years} For example, the following command sets the snapshot interval to run every six hours from the start time: bstnA(gbl-schedule[daily])#every 6 hours
  • Exit the gbl-schedule-daily configuration mode and return to privileged mode by typing the following command:

    end
