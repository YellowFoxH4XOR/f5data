Known Issue

The BIG-IP ASM system may stay offline after you restart or upgrade the system.

This issue occurs when the following condition is met:

  • You installed the ASM-SignatureFile_20160428_093545 attack signature update before you restarted or upgraded the BIG-IP system.

Impact

The BIG-IP system stays offline after you restart or upgrade the BIG-IP system and never recovers.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/ltm file, you observe error messages similar to the following example:

    err mcpd[1234]: 010719ad:3: Bad dos signature rule /Common/Neutrino Bot: Unquoted content: headercontent Unescaped quote in headercontent: 'Mozilla/5.0 (Windows NT 6.1 Invalid tag: WOW64 Tag found with no value: WOW64 Invalid tag: rv Content modifier on non-content tag: useragentonly Content modifier on non-content tag: nocase

Workaround

To work around this issue, you can install the more recent attack signature update, ASM-SignatureFile_20160516_144744. You can use the manual update mode instead of the scheduled update mode when you configure the Attack Signatures Update feature. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Download the ASM-SignatureFile_20160516_144744 Attack Signature Update from the F5 Downloads site.

    Note: For instructions for downloading software, refer to K167: Downloading software and firmware from F5.

  2. Log in to the Configuration utility.
  3. Navigate to Security > Security Updates > Application Security.
  4. For the Update Mode setting, click Manual.
  5. For the Delivery Mode setting, click Manual and browse to the downloaded Attack Signature Update file.
  6. To begin installation, click Install Updates.
  7. When the installation is complete, click Close on the Security Update Result summary window.
  8. Optional: Set your Update Mode and Delivery Mode configuration back to the previous configuration.
