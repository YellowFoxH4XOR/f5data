Description
Unable to perform config-sync from active F5 Big-IP to Standby unit. Below error messages appeared in GUI and /var/log/ltm  
 
Sync error on : Load failed from "Big-IP-hostname" 01070712:3: Caught configuration exception (0), failed in syscall link(/config/filestore/files_d/Common_d/certificate_key_d/:Common:f5_api_com.key_XXXX_X, /config/filestore/.trash_bin_d/.current_d/Common_d/certificate_key_d/:Common:f5_api_com.key_XXXX_X) errno=(No such file or directory).
 

Environment

  • BIG-IP active-standby HA pair
  • SSL certificate and key
 

Cause
This issue is caused when the f5_api_com.key has been removed from the /config/ssl/ssl.key repository. 
 

Recommended Actions

In the F5 Big-IP Standby device, a dummy file called "f5_api_com.key" needs to be crated with a symbolic link to the f5_api_com.key file
 
  1. Go to below directory.
               cd /config/ssl/ssl.key
 
  1. Create a dummy file for f5_api_com.key.
               touch f5_api_com.key
 
  1. Create below symbolic link:
               ln -s /config/ssl/ssl.key/f5_api_com.key /config/filestore/files_d/Common_d/certificate_key_d/:Common:f5_api_com.key_XXXX_X
 
  1. Once these files are created, the Big-IP config needs to be verified and reloaded in the Standby device following the below steps:
                  4.1.- Run: tmsh load sys config verify
                             This verify command should complete without any error
                  4.2.- Then config load needs to be issued
                                 tmsh load sys config
 
  1. Perform the config-sync from the active to the standby device, and this time it should complete without issues.
