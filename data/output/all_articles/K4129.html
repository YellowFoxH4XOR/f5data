K4129: Downloading or launching files may fail when connected to a site through FirePass

Topic



Specific client and server configurations can prevent web browsers from downloading or launching files when you are accessing a site through FirePass.

Client configuration

A client web browser that is configured with security settings set to high level may not allow you to download files when you are accessing a server using an encrypted SSL session. This will prevent you from downloading files when accessing a site through FirePass. To eliminate this problem, you must remove the web browser security restrictions.

To remove security restrictions for Microsoft Internet Explorer, access the Security Settings and disable the Do not save encrypted pages to disk option.

Refer to your web browser documentation for instructions about how to remove security restrictions for other web browsers.

Server configuration

The client web browser will not cache content when a server is configured to include the pragma: no-cache or pragma: no-store cache control. When you access a server with this configuration through FirePass, the client is able to download the content, but the web browser is not able to launch it because the content is not contained in the web browser's cache.

This behavior affects all Microsoft active file types, including Microsoft Office files. You may experience this behavior with other file types as well, such as PDF documents.

To eliminate this problem, you must configure the server to not send the cache control headers. Refer to your server documentation for specific instructions about how to change this configuration.

If you are unable to configure the server to not send the cache control headers, you can still access the file by saving it to your computer and manually launching the associated application.
