K000139945: SAML SP Connectors with same SP Entity ID

Type
Support Solution
Published
2024-06-07
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.3
Source
https://my.f5.com/manage/s/article/K000139945

Description

You want to configure two SP Connectors with the same Service Provider Entity ID which are involved in SLO. BIG-IP does not send LogoutRequest to SP2, when logout is initiated by SP1. SLO works conditionally, when logout is initiated from the same SP where SSO first took place.

Environment

  • BIG-IP APM
  • SAML IdP
  • SLO

Cause

This is due to Bug ID 1582765: SAML Single Logout should use 'SessionIndex' to disconnect SAML sessions

Recommended Actions

None. There is no fix currently available.

Additional Information

None
