K000157107: HTTP Load Balancer - Errors : HTTP2 protocol error while matcher.js is loading

Type
Support Solution
Published
2025-10-23
Updated
2025-10-23
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Apps
Source
https://my.f5.com/manage/s/article/K000157107

Description

This error happens when you have the following situation:

  • You are using BIG-IP in the chain of the request
  • You are using HTTP2

This is what the error looks like:

Environment

  • F5® Distributed Cloud HTTP Load Balancer
  • BIG-IP

Cause

HTTP2 is not fully supported. 

Recommended Actions

Disable HTTP2 on BIG-IP to fix the issue.
