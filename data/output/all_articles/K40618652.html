Description

There are continuous sync recovery log message in ASM log as below after manual sync.

info asm_config_server_rpc_handler_async.pl[<PID>]: Sending CMI sync file '/ts/var/sync/sync_<ID>_<ID>_full_update' to '/Common/<peer_hostname>'

Environment

  • ASM configuration sync

Cause
Bug ID 912149

Recommended Actions

on CLI on all units in the device group, run:

pkill -f asm_config_server
