K000133125: APM: EXCEPTION - ParseURL failed, /public/oauth_done.html

Type
Support Solution
Published
2023-04-01
Updated
2023-04-01
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000133125

Description

In CTU report, the BIGIP APM administrator may notice the below errors for oAuth-related session attempt:


2023-03-02, 2:38:04:332, 27744,27752,APPCTRL, 2, \m_strings.cpp, 594, ParseURL_WININET, InternetCrackUrl failed: 12006 (0x2ee6) 

2023-03-02, 2:38:04:332, 27744,27752,APPCTRL, 1, \Uri.h, 142, f5::CreateUri, EXCEPTION - ParseURL failed, /public/oauth_done.html <<< (!)

[...]

2023-03-02, 2:38:06:182, 27744,26048,APPCTRL, 1, OAuth2AuthorizationCodeFlow.cpp, 453, OAuth2AuthorizationCodeFlow::makeTokenRequest, Access Token is missing 

2023-03-02, 2:38:06:182, 27744,26048,APPCTRL, 1, OAuth2AuthorizationCodeFlow.cpp, 277, OAuth2AuthorizationCodeFlow::GetAuthorizationToken, makeTokenRequest failed

2023-03-02, 2:38:06:182, 27744,26048,APPCTRL, 1, oauth2.cpp, 224, OAuth2GetAccessToken, Failed to obtain authorization token


Environment

  • APM
  • EdgeClient app is configured as oAuth Client
  • ParseURL error in CTU report

Cause

The lack of Client Secret value in Edge Client connectivity package


Recommended Actions

Make sure that 'Client Secret (Public)' value is populated in 'Access ›› Connectivity / VPN : Connectivity : Profiles ›› <connectivity_profile_name> : Edit Profile : oAuth Settings'
