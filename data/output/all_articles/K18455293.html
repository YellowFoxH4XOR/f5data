Description

Trying to access a DKIM DNS TXT record in the configuration utility and Zone Runner throws the error:

RRSig Covers Unsupported Record Type<none>:1: text string too long

Environment

  • BIG-IP DNS.
  • DKIM DNS TXT record
    • Containing single string longer than 255 characters.

Cause

BIND TXT resource record are limited to have a maximum of 255 characters in a single string. See K30222115: Configuring DKIM DNS TXT resource records using the ZoneRunner utility for guidance on configuring a DKIM DNS TXT record in BIG-IP DNS.

Recommended Actions

  1. If you are deploying a 2048-bit or higher key size to generate your DKIM public key, break up the resulting public key into chunks of 255 characters or fewer before adding it to the TXT resource record:

    For example, consider the following public key generated using 2048-bit key size:
