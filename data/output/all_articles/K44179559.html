Description
Enabling the DB key avr.addrandomdelaybeforesnapshot may result in inaccurate statistics data on its managing BIG-IQ systems.

Environment

  • BIG-IQ
  • BIG-IP Managed By BIG-IQ

Cause
This DB key, avr.addrandomdelaybeforesnapshot, will cause the BIG-IIP system to delay sending statistics to BIG-IQ DCD Systems, which resulted in BIG-IQ systems reporting inaccurate data during the period where no BIG-IP system data is received.

Recommended Actions

To prevent BIG-IQ systems from reporting inaccurate data, make sure the DB key avr.addrandomdelaybeforesnapshot is left with its default value.
# tmsh modify /sys db avr.addrandomdelaybeforesnapshot value disable
