Topic

This article applies to BIG-IP 11.4.x - 15.x. For information about other versions, refer to the following article:

  • K11120: Changing the prefix used by the BIG-IP WebAccelerator system for Intelligent Browser Referencing (IBR) objects (10.x)

You should consider using this procedure under the following condition:

  • You want to change the IBR prefix for the BIG-IP AAM web application.

Description

The IBR prefix specifies a string that the BIG-IP AAM system prepends to a unique value for qualifying links or URLs embedded in your web pages. The default prefix used by the BIG-IP AAM for IBR-enabled objects is ;wa.

You should change the prefix only when necessary for sites that have issues with semicolons ( ; ) in URLs.

The IBR prefix should be three characters long. If the prefix is less than three characters, the client may receive HTTP 404 errors for IBR-enabled objects. If the prefix is longer than three characters, the prefix will be truncated to three characters. If you must change the prefix, ensure that you do not use a character from the following list:

  • carat ( ^ )
  • at symbol ( @ )
  • ampersand ( & )
  • colon ( : )
  • number sign ( # )
  • apostrophe ( ' )
  • quotation mark ( " )
  • less-than sign ( < )
  • greater-than sign ( > )   

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have access to the BIG-IP AAM Configuration utility.

Procedures

Customizing the default IBR prefix

To customize the default IBR prefix, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Acceleration > Web Application > Applications.
  3. Click the name of an application.
  4. From the General Options list, select Advanced.
  5. In the IBR Options area, modify the IBR prefix value as necessary.

    For example, to configure the BIG-IP AAM to use $wa as the IBR prefix, enter $wa.
     
  6. Click Save.
