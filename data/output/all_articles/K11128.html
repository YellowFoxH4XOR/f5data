K11128: An Internet Explorer 7 user's session may terminate when trying to reconnect to a OWA Portal Access Favorite

Type
Knowledge
Published
2010-03-29
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.1.0, 6.0.3, 6.0.2
Source
https://my.f5.com/manage/s/article/K11128

Topic

When a user who connects to the FirePass controller with Internet Explorer 7 log in and out of a web access OWA Portal Access Favorite that requires client certificate authentication, the user's FirePass session will be terminated when trying to reconnect to the OWA Portal Access Favorite. The following error message may be logged in Reports: System Logs:

Possible intrusion attempt detected against account <user's ID> from source IP address <user's IP Address> for URI=[/vdesk/intranets/*](Client certificate changed. )

The FirePass controller determines the client certificate has been changed and will terminate the user's session as a security measure.

The following procedure stops this behavior by disabling the authentication cache clearing functionality when the user logs out of the OWA Portal Access Favorite:

Note: This procedure only works if Compatibility Mode has not be enabled under the Web Applications Global Settings section found on the Global Settings tab of Portal Access: Web Applications: Content Processing page. If you require compatibility mode, please contact F5 Support for further assistance.

  1. From the Administrative Console, click Portal Access in the navigation menu.
  2. Click Content Processing.
  3. Click the Preprocessing Scripts tab.
  4. Click the add icon (i-bar) next to Add New Favorite, under the Web Applications content Processing Scripts section.
  5. In the Processing script name field, enter a name for the script.
     
    For example:

    OWA_ClearAuthCache
  6. In the URL match patterns field, enter the following text:

    */owa/auth/logoff.aspx?Cmd=logoff
  7. In the Content Type field, enter the following text:

    text/html
  8. Leave the Allow caching option clear.
  9. In the Sed processing field, enter the following text:

    s@F5_Invoke_execCommand(document,"ClearAuthenticationCache","false    ");@@
  10. In the Processing drop-down menu, select Post-process response data (after content patching).
  11. Click the Add New button.
