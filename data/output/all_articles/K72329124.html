Known Issue

The BIG-IP system may fail to evaluate all available hardware sensor thresholds for certain platforms.

This issue occurs when all of the following conditions are met:

  • You are running one of the following BIG-IP platforms:
    • BIG-IP 2000 series
    • BIG-IP 4000 series
    • BIG-IP 5000 series
    • BIG-IP 7000 series
    • BIG-IP 10000 series
    • BIG-IP 12000 series
    • VIPRION B2100 blades
    • VIPRION B2150 blades
    • VIPRION B2250 blades
  • The system_check script runs by way of either a cron job or manually.

    Note: The BIG-IP system runs the system_check script periodically to evaluate if any of the hardware sensors have breached the defined sensor limits, and to issue the corresponding alerts.

Impact

The BIG-IP system does not show the complete set of defined sensor limits. Only one entry is displayed for each sensor. As a result, the system_check script that relies on these defined sensor limits fails to evaluate the missing entries and does not issue the corresponding alerts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you run the system_check -d command, you notice that the BIG-IP system does not show the complete set of defined sensor limits. Only one entry is displayed for each sensor.

    For example, the Main board inlet IC temperature (inlet_ic_temp) sensor on a 4000 Series BIG-IP platform has two sensor limits configured. The expected output of the system_check command should look similar to the following example:

    system_check -d | grep -e Hyst -e inlet_ic_temp
    Key Sys Data Unit Sta Cur Tbl # Type Range Value Hyst Sev
    inlet_ic_temp 5 24 C 1 NORM I|D|S 3 0 2 45 2 CRIT
    inlet_ic_temp 5 24 C 1 NORM I|D|S 4 0 2 50 2 CRIT

    The sensor thresholds are set at 45 degree Celsius and 50 degree Celsius respectively.

    However, the affected BIG-IP system displays only the higher sensor threshold limit of 50 degree Celsius. This means that the BIG-IP system may not trigger an alert message when the sensor temperature reaches 45 degree Celsius. The output of the system_check command looks similar to the following example:

    system_check -d | grep -e Hyst -e inlet_ic_temp
    Key Sys Data Unit Sta Cur Tbl # Type Range Value Hyst Sev
    inlet_ic_temp 5 24 C 1 NORM I|D|S 4 0 2 50 2 CRIT
