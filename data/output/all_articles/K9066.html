Known Issue

This is the result of a known issue. IPv6 addresses require network interfaces to have an auto-configured link-local address (prefix fe80::/10), which is based on the MAC address of the interface. TMM correctly generates link-local self IP addresses for every VLAN on the BIG-IP system.

Currently, inbound traffic is not permitted to the IPv6 auto-generated link-local addresses. This behavior is required for certain dynamic routing protocols, such as OSPFv3, which uses link-local unicast addresses during database exchange.

F5 Product Development tracked this issue as CR98917.

This issued was fixed in Hotfix-BIG-IP-9.6.1-HF1 issued for BIG-IP version 9.6.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
