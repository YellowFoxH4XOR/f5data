Description

You can observe BIG-IP is not honoring HTTP Vary header with value Origin.
If the Vary header includes entries other than User-Agent or Accept-Encoding, the BIG-IP system ignores the headers.

Environment

  • BIG-IP

Cause

Behavior is related and documented under BUG ID 221995.

Recommended Actions

As detailed in K11009, BIG-IP ramcache will only support Vary: User-Agent or Vary: Accept-Encoding.
It does not support Vary: Origin header and unfortunately there are no plans to extend this support.

There is possible workaround, to design an iRule which could allow to cache mentioned requests.
Below iRule might be helpful in achieving this goal, but you may need to modify it according to your needs:

when HTTP_REQUEST {
    CACHE::userkey [HTTP::header value Origin]
}


More details you may find in below documentation:
