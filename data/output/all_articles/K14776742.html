Description
Not able to configure IPv6 dual stack management from GUI.

Example: Navigate to System > Configuration > Platform > Add in an IPv6 Config details
IP Address:  fc00:1:1:1:0:0:0:51
Network Mask: ffff:ffff:ffff:ffff:0:0:0:0
Management Route: fc00:1:1:1:0:0:0:1

Environment

  • Dual stack management IP
  • IPv4
  • IPv6
  • GUI
  • CLI

Cause
The issue is caused by known bug ID1038317 

Workaround
We have two options as listed below to resolve this issue.

1. Workaround the issue via CLI, steps attached as per KB article K15040 "Configuring the management IP address using tmsh(IPv6)".

# tmsh create /sys management-ip fc00:1:1:1:0:0:0:51/64
# tmsh create /sys management-route default-inet6 gateway fc00:1:1:1:0:0:0:1
# tmsh save /sys config partitions all

2. Perform upgrade to BIG-IP version 15.1.10.x or 16.1.1.x and above (F5 recommend to go for the latest stable release).

Additional Information

If you are upgrading from BIG-IP v15.1.6 or later in the v15.1.x branch to BIG-IP v16.1.2.2 or earlier in the v16.1.x branch, please take note there's a bug ID 1082717, the issue is when upgrading the BIG-IP from 15.1.6 to higher versions results in the error message "Can't load keyword definition (vlan.ipv6_prefix_len)" when loading the configuration.

This bug are fix in BIG-IP v16.1.3.x and above.
