K68751876: F5 Telemetry Streaming Declaration logging.

Published
2022-05-18

Applies to

Source

Description
F5 Telemetry Streaming versions 1.28 and later provides a log of declarations posted through iControl REST along with a log of the complete set of declarations as validated and loaded. This log will also display declarations that are posted and fail validation.

The history of JSON declarations posted to F5 Telemetry streaming is logged to this file:
 
/var/log/restnoded/telemetryDeclarationHistory

With this JSON log an administrator can see the current successfully loaded configuration as well as the declarations as they are posted the Telemetry Streaming Plugin. The last validated declaration will be equivalent to the current running configuration.

When Telemetry Streaming loads saved configuration the declaration history log will indicate the validated configuration was a loaded saved configuration.
 
               "metadata": {
                    "message": "Loading saved configuration"
                },
                "transactionID": "f9a6ad5a-29ca-4f5c-8b03-c773e7781256"
            }
        },
        "timestamp": "2022-03-31T20:43:49.499Z"
 
The declaration history will also display declarations that fail validation. In this case the declaration failure is logged with: "event": "validationFailed"

If a declaration fails validation the declaration as posted will be logged along with the error message. Here is an example of the error message with. "type": "GenericHTTP", posted instead of  "type": "Generic_HTTP",
This is logged after the failed declaration:

"errorMsg": "Error: Error: [{\"keyword\":\"enum\",\"dataPath\":\"/My_Consumer/type\",\"schemaPath\":\"#/allOf/0/then/properties/type/enum\",\"params\":{\"allowedValues\":[\"AWS_CloudWatch\",\"AWS_S3\",\"Azure_Log_Analytics\",\"Azure_Application_Insights\",\"DataDog\",\"default\",\"ElasticSearch\",\"Generic_HTTP\",\"Google_Cloud_Logging\",\"Google_Cloud_Monitoring\",\"Google_StackDriver\",\"Graphite\",\"Kafka\",\"OpenTelemetry_Exporter\",\"Splunk\",\"Statsd\",\"Sumo_Logic\",\"F5_Cloud\"]},\"message\":\"should be equal to one of the allowed values\"}]",

Environment
F5 Telemetery Streaming plug-in

Cause
This logging is a the default behavior for Telemetry Streaming in version 1.28 and later.

Recommended action
No addition action is required.
