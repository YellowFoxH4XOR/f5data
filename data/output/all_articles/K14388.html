Known Issue

Active Directory pass change fails if User Datagram Protocol (UDP) port 464 is blocked between the BIG-IP and Active Directory domain controller.

The BIG-IP APM system can detect an expired Active Directory password and prompt the user for a new password. The password change process uses UDP port 464. Active Directory can also use TCP port 464 for the password change process. A change in BIG-IP APM 11.2.1 prevents the BIG-IP APM from using TCP to request a password change from Active Directory.

Impact

Users are unable to change an expired Active Directory password, and are unable to log in to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H419939 on the Diagnostics > Identified > Low screen.
  • The user receives the following error message after attempting to change the password:

    The domain password change operation failed. Please try again.

Workaround

There is no workaround. However, you can ensure that UDP port 464 is not blocked between the BIG-IP system and the Active Directory domain controller.
