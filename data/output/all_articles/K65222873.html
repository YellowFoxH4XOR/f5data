K65222873: ctrl/AltGr key stroke causing typing issues on the edge client

Type
Support Solution
Published
2022-02-24
Updated

Status
Legacy Content
Applies to

  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K65222873

Description
On the latest version of the BIG-IP Edge Client 7197 and 7210 the user may be unable to type anything on the logon page

Environment

  • BIP-IP Edge Client
  • Windows 10

Cause
Bug: 942953 APM [apmclients] - Cannot type credentials into Win 10 EdgeClient window - v7197

Recommended Actions
You can workaround this problem by toggling the CTRL or AltGr key specific to your keyboard, to allow the users to type in the logon page.

Additional Information
You could also request a fixed version  of the BIG-IP Edge Client for BIG-IP APM by raising a support case with F5.
