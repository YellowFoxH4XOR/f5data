Known Issue

The BIG-IP system may log warning messages about an interface module ID schema mismatch.

This issue occurs when all of the following conditions are met:

  • The platform is a VIPRION B4200 (A107) blade.
  • The VIPRION blade is running an affected BIG-IP version.

Impact

This is an informational error message only and should not have a negative impact on the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H439698 on the Diagnostics > Identified > Low screen.
  • You observe an error message similar to the following example in the /var/log/ltm log file:

    err bcm56xxd: 012c0010:3: Error: interface 1/4.1 module id schema mismatch! (3 != 0)

    Note: You can safely ignore this log message.
