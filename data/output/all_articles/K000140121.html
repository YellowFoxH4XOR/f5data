K000140121: rSeries r2k/r4k return traffic (e.g. ICMP echo replies) not reaching the tenant

Type
Support Solution
Published
2024-06-25
Updated
2024-06-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.0, 15.1.2, 15.1.1, 15.1.X, 17.1.0, 15.1.10, 15.1.9, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3
Source
https://my.f5.com/manage/s/article/K000140121

Description

Return traffic (for example, ping responses) not reaching the BIG-IP tenant(s), but troubleshooting indicates the responses are being sent towards the appliance, and there appears to be no issue with the responses.

Environment

  • rSeries r2k or 4k
  • Tenant MAC Block Size greater than One (e.g. Large)
  • sys db vlan.macassignment set to unique
  • or VLAN groups in use

Cause

Bug ID 1289981: Tenants on r2000 and r4000 systems will not pass traffic through VLAN groups, or if ltm global-settings general share-single-mac changed from "vmw-compat"

Recommended Actions

Upgrade to a BIG-IP version where bug ID 1289981 is fixed (for example, the latest 17.1.x).

Additional Information

Traffic can appear to be dropped due to a variety of reasons. If your system does not meet the conditions listed in the Environment of this article, ID1289981 should not be applicable.
