Description

You need a way to block/drop traffic from a specific IP or a list of IP addresses. For example, during a suspected cyber attack, or simply to discard traffic from certain IP addresses.

Environment

  • BIG-IP
  • Virtual server

Cause

Not applicable.

Recommended Actions

You can create iRules similar to the following examples and apply them to virtual servers that need to block or drop traffic.

when FLOW_INIT {
  if { [IP::addr [IP::client_addr] equals (IPv4 Address%RouteDomain)] } {
    log local0. "Blocking [IP::client_addr]"
    drop
  }
}

Note: If the IPv4 Address being matched is in the default route domain, the route domain notation does not need to be included in the iRule syntax.

Examples

  1. Block an IP address in the default route domain:

    when FLOW_INIT {
      if { [IP::addr [IP::client_addr] equals 192.0.2.1] } {
        log local0. "Blocking [IP::client_addr]"
        drop
      }
    }

  2. Block an IP address in route domain 3000:

    when FLOW_INIT {
      if { [IP::addr [IP::client_addr] equals 192.0.2.1%3000] } {
        log local0. "Blocking [IP::client_addr]"
        drop
      }
    }

  3. When you have multiple IP addresses or a whole network range to drop traffic from, then it is recommended to use a data group created as Address type using the Configuration utility or type ip when using tmsh, then reference the data group with an iRule:

    Note: To create a data group using the Configuration utility, go to Local Traffic > Virtual Servers > iRules > Data Group List and select Create. For information on creating a data group using tmsh, use the tmsh command: tmsh help ltm data-group internal.

    Sample data group configuration viewed using the tmsh list ltm data-group internal BlockListIP_DataGroup command:

    ltm data-group internal BlockListIP_DataGroup {
      records {
        192.0.2.0/24 { }
      }
      type ip
    }

    Example iRule that uses the data group named BlockListIP_DataGroup

    when FLOW_INIT {
      if { [class match [IP::remote_addr] equals BlockListIP_DataGroup]} {
        log local0. "Attacker IP [IP::client_addr]"
        drop
      }
    }

  4. If you want to drop all traffic except a list of IP addresses or a network range, the following iRule example would drop connections that were not part of a data group named AllowListIP_DataGroup:

    when FLOW_INIT {
      if { (not [class match [IP::remote_addr] equals AllowListIP_DataGroup] )} {
        log local0. "Attacker IP [IP::client_addr]"
        drop
      }
    }

Note: The log lines in the iRule examples are optional and can be omitted or commented out.
