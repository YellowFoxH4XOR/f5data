Description
A learning suggestion may show that it was learned from a trusted source, even if no sample request contains a source IP address that is configured as a trusted IP address. This is possible even if no trusted sources are configured in the security policy's IP address list.

Environment

  • Example HTTP request source IP is not trusted by the BIG-IP ASM Policy Builder in Security  ››  Application Security : IP Addresses : IP Address Exceptions
  • BIG-IP ASM Security Policy has 'Learn from responses' enabled in Security  ››  Application Security : Policy Building : Learning and Blocking Settings, under Policy Building Process section

Cause
URLs, parameters and attributes of parameters can be learned from inspecting the traffic, both HTTP requests and responses. If the Policy Builder learns from responses, responses are counted as trusted sources and use the trusted traffic thresholds configured in the learning and blocking settings. Some learning suggestions can be created and reinforced from both violations and responses.
