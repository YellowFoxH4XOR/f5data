Description

An HTTP 403 is observed when accessing the BIG-IP GUI (Configuration utility). This could occur after an upgrade to version 17.1.x, but may also occur on 16.1.x.

Environment

  • BIG-IP LTM

Cause

Management provisioning on BIG-IP 17.x should be set to Large (500 MB) or more (1024 MB or 2048 MB) depending on the configuration and modules. The BIG-IP GUI uses tomcat; therefore:

  • If Management provisioning is increased to 1024, increase resources for tomcat to 128.
  • if Management provisioning is increased to 2048, increase resources for tomcat to 256.

Recommended Actions

Impact: When you reprovision Management, the BIG-IP system will temporarily go offline while daemons restart. This will cause a failover in a device group configuration.

Enter the following sequence of commands for 1024 MB extra Management memory:

  1. tmsh modify /sys db provision.extramb value 1024
  2. tmsh modify /sys db provision.tomcat.extramb value 128
  3. tmsh restart sys service tomcat restjavad

Enter the following sequence of commands for 2048 MB extra Management memory:

  1. tmsh modify /sys db provision.extramb value 2048
  2. tmsh modify /sys db provision.tomcat.extramb value 256
  3. tmsh restart sys service tomcat restjavad
