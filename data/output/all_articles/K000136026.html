Description:

You've observed following conditions on BIG-IP:

  • bd size is growing 
  • umu buffers are not released (can be confirmed in periodical prints in /var/log/ts/bd.log file)
  • there are ASM out of memory events in /var/log/asm file

Environment:

BIG-IP ASM or Advanced WAF


Cause:

Behavior observed might be a side effect of ID521713. If the amount of websecurity profiles is not equal to the policies amount overall in bigip.conf file and you can observe following logs in /var/log/ts/bd.log file:


"TMEVT_REQUEST: Request has no HTTP selector, empty web-security, action is bypass"


then ID521713 is likely a cause.


https://cdn.f5.com/product/bugtracker/ID521713.html


Error like "|TMEVT_REQUEST: Request has no HTTP selector, empty web-security, action is bypass" should force BD to close the connection, however, it's possible that BD couldn't release memory, e.g. it can happen with a combination of IRULES that are in progress during the transaction.


Recommended Actions:

Make sure all virtual servers are configured correctly.

Workaround from ID521713 should be helpful:


Run this command:

for vs in `tmsh list ltm virtual one-line | cut -f3 -d' '`; do tmsh modify ltm virtual ${vs} profiles delete { websecurity }; done
