Known Issue

Step-Up Certificates allow a client to initially connect to a server using a low complexity cipher and then renegotiate the session using a high complexity cipher. The BIG-IP system allows clients to renegotiate only Secure Socket Layer (SSL) sessions using the ciphers that were initially chosen for the connection. As a result, low-strength cipher connections to a virtual server using a Step-Up/Server Gated Cryptography certificate will fail after the initial key exchange.

F5 Product Development tracked this issue as CR48879 and CR53991 and it was fixed in BIG-IP LTM 9.1.1 and 9.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
