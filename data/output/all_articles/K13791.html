Known Issue

The Enterprise Manager system may incorrectly compare objects in pinned archives.

This issue occurs when all of the following conditions are met:

  • The Enterprise Manager system has a pinned archive stored for a managed device.
  • The managed device configuration is modified by the addition of a new configuration object, such that the names of the new objects fall alphabetically between two existing configuration objects.
  • A new pinned archive is created from the newer configuration containing the additional object mentioned previously.
  • The original pinned archive and the new pinned archive are compared.

Impact

Results of the Compare Archive task may be incorrect or misleading.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The results of a Compare Archive task may incorrectly compare a given object in one archive to a different object in the other archive, rather than the same object in both archives.

    For example the virtual servers in the first column are incorrectly compared to different objects in the second column. Vip01 is incorrectly compared to Vip02, resulting in the Compare Archive task incorrectly reporting a Comparison: Modified result for the Vip01 object:
