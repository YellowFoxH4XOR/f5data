Issue

Old Behavior

Prior to 11.2.0, the BIG-IP ASM system used Perl Compatible Regular Expressions (PCRE) as the sole regular expression library for attack signatures.

New Behavior

Beginning in BIG-IP ASM 11.2.0, the RE2 regular expression library is now supported, in addition to PCRE.

The RE2 library uses a fixed stack space, as opposed to PCRE's recursive stack, and thus does not suffer from catastrophic backtracking. In all cases where an existing attack signature supplied by F5 could be rewritten in RE2, it has been rewritten. Due to the differing feature sets available in RE2 and PCRE, some attack signatures must still use PCRE if they use a feature that is not replicated in RE2.

When upgrading to BIG-IP ASM 11.2.0 from a previous version, all applicable PCRE attack signatures are replaced with the RE2 versions as part of the upgrade process.

Impact

There are performance and stability enhancements to the BIG-IP ASM attack signature engine.

Recommended Actions

As RE2 does not suffer from the catastrophic backtracking problems of PCRE, you should write new user-defined attack signatures with RE2 regular expressions, and rewrite existing user-defined attack signatures using RE2, where possible.

You can test RE2 regular expressions in the Configuration utility by performing one of the following procedures:

BIG-IP ASM 11.3.0 and later

  1. Log in to the Configuration utility.
  2. Click Security.
  3. Click Options.
  4. Click Application Security.
  5. Click RegExp Validator.
  6. Change the RegExp Type option to RE2.
  7. Enter the regular expression and the test string into the RegExp and Test String boxes, respectively.
  8. Click Validate.

BIG-IP ASM 11.2.0 through 11.2.1

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Options.
  4. Click RegExp Validator.
  5. Change the RegExp Type option to RE2.
  6. Enter the regular expression and the test string into the RegExp and Test String boxes, respectively.
  7. Click Validate.
