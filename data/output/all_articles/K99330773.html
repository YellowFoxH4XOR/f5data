Description

The configuration file is not loading with the following error message:

01071769:3: Decryption of the field (secret) for object (/Common/system-auth) failed.

This error can be seen on /var/log/ltm logs or when running:

tmsh load sys config verify
tmsh load sys config

Environment

  • After UCS file load
  • After config load

Cause

The main issue is that the master key is not able to decrypt the password for /Common/system-auth.

The master key could have changed its value due to multiple reasons including:

Bug ID 514815: Configuration does not validate unused encrypted items.

Recommended Actions

To resolve this issue, please follow these steps:

  1. Save a backup of the the bigip.conf file with the following command:

    cp /config/bigip.conf /config/bigip.conf.backup.new

  2. With a text editor, edit the /config/bigip.conf file:

    vi /config/bigip.conf

  3. Find and delete the /Common/system-auth object referenced in the error above. You will need to delete the following lines, as on this example:

    auth tacacs /Common/system-auth {
        protocol ip
        secret ***scrubbed***  
        servers { 10.10.10.10 11.11.11.11 }
        service ppp
    }

  4. After deleting the /Common/system-auth object, save the changes to the bigip.conf file
  5. Run the following command to reload the configuration file:

    tmsh load sys config

Note: If this is unit is part of an HA pair, you can later run a Sync from the Active device to recover the system-auth configuration that has been deleted. The system-auth objects should sync normally.
