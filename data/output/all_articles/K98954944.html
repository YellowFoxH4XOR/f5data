Issue

Error Message

notice clusterd[<PID>]: 013a0019:5: <Cluster member transition to Availability State Yellow: Reason>

In this error message, note the following:

  • <PID> is the process ID for the clusterd process.
  • <Cluster member transition to Availability State Yellow: Reason> specifies the cluster member that transitioned state and the reason for the state transition.

For example:

notice clusterd[18912]: 013a0019:5: Blade 1 turned Yellow: TMM not ready
notice clusterd[5202]: 013a0019:5: Blade 2 turned Yellow: Quorum: waiting for lind
notice clusterd[5547]: 013a0019:5: Blade 1 turned Yellow: Quorum

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A cluster member has transitioned to clusterd availability state Yellow, indicating a transition to cluster state Quorum.

Impact

The cluster member is not available until it transitions to availability state Green. The cluster automatically tries to bring the cluster member up to availability state Green, running.

Recommended Actions

None
