Description

Configsync between BIG-IP cluster fails with an error message similar to the following: 

ASM feature not licensed.

Environment

  • BIG-IP HA 
  • BIG-IP ASM is not licensed
  • BIG-IP ASM is provisioned
  • Deprovisioning BIG-IP ASM does not solve the issue.

Cause

This occurs due to 'Protocol Security' option enabled in the ftp profile. The Protocol Security checkbox is displayed in the GUI with a BIG-IP AFM license.
This feature actually requires an BIG-IP ASM license. Without the BIG-IP ASM license, when a synchronization is attempted, it fails and system displays the error message.

Recommended Actions
 

To resolve the issue, comment out the 'protocol security' line under the ftp profile and perform the following steps:

  1. Log on to the BIG-IP command line.

  2. Create a backup copy of /config/bigip.conf.
    For example:
    cp /config/bigip.conf /config/bigip.conf.backup

  3. Using preferred text editor (example: vim, nano, pico), open the file /config/bigip.conf. 
    For example:
    vi /config/bigip.conf 

  4. Look for the line starting with 'ltm profile ftp'. Within the profile stanza search for 'security enabled'.
    ltm profile ftp /Common/<ftp_profile_name> {
    app-service none
    defaults-from /Common/ftp
    port 0
    security enabled
    }

  5. Prepend '#' in front of the line security enabled.
    For example:
    ltm profile ftp /Common/<ftp_profile_name> {
    app-service none
    defaults-from /Common/ftp
    port 0
    #security enabled
    }

  6. Save the bigip.conf file.
    For example when using "vi" or "vim":
    :wq!

  7. Verify that there are no errors by running:
    tmsh load sys config verify

  8. If no errors seen, load the configuration running command:
    tmsh load sys config

  9. Perform the Configsync.

Performing ConfigSync using the Configuration utility (BIG-IP 11.2.1 and later).
  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Overview.
  3. For Device Groups, select the name of the device group you want to synchronize.
  4. For Devices, select the name of the device from which you want to perform the synchronization action.
  5. For Sync Options, select the appropriate synchronization action.
  6. To synchronize from a device with an older configuration to a device, or devices, with a newer configuration, select Sync and Overwrite when prompted (BIG-IP 13.x and later) or enable Overwrite Configuration (BIG-IP 11.2.1 - 12.x).
  7. Select Sync.
