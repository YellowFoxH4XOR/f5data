Description

When accessing the BIG-IP Configuration Terminal (GUI), the following error message is shown.
500 Internal server error

When accessing /var/log/tomcat/catalina.out, java.lang.OutOfMemoryError is seen and tomcat is restarting multiple times.

Environment

  • BIG-IP
  • Error message 500 Internal server error when accessing the Configuration Terminal (GUI)
  • /var/log/tomcat/catalina.out shows java.lang.OutOfMemoryError error message
  • tomcat restarting multiple times

Cause

Tomcat daemon is running out of Java virtual memory.

Recommended Actions

Follow article K9719 to increase the maximum amount of Java virtual memory to the tomcat daemon.

Additional Information

None.
