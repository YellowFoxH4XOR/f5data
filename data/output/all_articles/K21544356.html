K21544356: RADIUS Authentication error Reject packet from host 127.7.0.4:1812;Error_Code=3

Type
Support Solution
Published
2022-11-30
Updated
2025-06-03
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.3
Source
https://my.f5.com/manage/s/article/K21544356

Description

  • User(s) cannot authenticate. 
  • var/log/apm logs errors similar to:

Action=authentication with;Object=USERNAME;Error_Message=Access-Reject packet from host 127.7.0.4:1812;Error_Code=3;
Module=RADIUS;Debug_Message=parseResponse(): Access-Reject packet from host 127.7.0.4:1812 (3)
Agent_Name=RADIUS;Function_Name=authenticateUser;
Logon_Attempt_Number=0;User_Name=USERNAME;Auth_Status=failed;

Environment

  • BIG-IP APM
  • RADIUS

Cause

  • During the execution of Access Policy for a user, the RADIUS server sends an "Access-Reject" response. The problem is with the Radius server denying access for this particular user.

Recommended Actions

The root cause needs to be investigated on the RADIUS server.
