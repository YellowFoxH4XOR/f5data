Description

What happens when your perpetual license expires?

Perpetual licenses (such as BIG-IP appliances or virtual editions) do not cause features to stop working simply due to expiry — since there is no expiration for the license itself. Unlike subscription licenses, which expire after a set duration and may require renewal to continue functioning.

However, must maintain updates and active support contracts to ensure optimal operation, access to new features, and protection from vulnerabilities.

There are a few key considerations to keep in mind regarding perpetual licenses and feature functionality:

Software Updates and Support Contracts

  • While the perpetual license itself doesn’t expire, access to software updates, patches, and technical support usually requires an active support contract. If the support agreement expires, it won’t have access to new features, security updates, or bug fixes, which may impact functionality over time.
  • Additionally, running outdated software without updates can expose the system to vulnerabilities or compatibility issues.

 

License Activation

  • F5 appliances and virtual editions require activation with a license key. If there’s an issue with license activation (example, if it was not properly provisioned or somehow invalidated), certain features may not work until the issue is resolved.
  • Losing or revoking the original license key could cause features to stop working.

 

Add-On Modules

  • If using additional F5 modules (example, Advanced WAF, DNS, SSL Orchestrator, and more), each module requires its own license. Some modules might have a subscription-based model rather than perpetual licensing. If a subscription-based module expires, the associated functionality will stop working.
  • Verify whether if the system is using additional subscription-based services tied to F5.
