Known Issue

WebSocket profile statistics may incorrectly report an unusually high number of current and maximum connections.

This issue occurs when the following condition is met:

  • You view the WebSocket profile statistics for current and maximum connections using the Configuration utility or the TMOS Shell (tmsh).

Impact

The incorrect statistics may cause confusion when troubleshooting WebSocket connections.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tmsh show /ltm profile websocket command shows an unusually high number of current and maximum connections, both of which exceed the total number of connections listed in the command output.

    For example:

    --------------------------------------------------------
    Ltm::WebSockets Profile: /Common/websocket
    --------------------------------------------------------
    Virtual Server Name                   N/A

    Resources                           Total     Current     Maximum
    Connections                      907977 18446744073709550827 18446744073709551615

    Note: The high connection count may be apparent during normal operation and also immediately after restarting the system.

Workaround

To work around this issue, you can reset the WebSocket profile statistics. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh by typing the following command:

    tmsh

  2. To reset the WebSocket statistics, type the following command:

    reset-stats /ltm profile websocket

  3. Verify that the statistics look accurate and the number of current and maximum connections do not greatly exceed the total number of connections listed in the command output. To view the statistics, type the following command:

    show /ltm profile websocket
