Description

LDAP authentication attempts on BIG-IP LTM may fail, resulting in login failures. System logs may show messages such as these in /var/log/secure:

May 15 16:53:39 apm1.hostname.com warning nslcd[17147]: [334873] <authc="user1"> CN=user1,OU=DORUsers,DC=prod,DC=domain,DC=com: lookup failed: Invalid credentials

May 15 16:55:43 apm1.hostname.com err nslcd[17147]: [b0dc51] <authc="user1"> ldap_result() timed out
May 15 16:55:55 apm1.hostname.com err httpd[15699]: pam_ldap(httpd:auth): error reading from nslcd: Timer expired

Environment

BIG-IP LTM

Cause

LDAP authentication failures can occur if LDAP referrals are enabled in the BIG-IP configuration. When referrals are enabled, the system may attempt to follow LDAP referrals returned by the Active Directory server, which can result in timeouts or invalid credential errors if the referred servers are unreachable or not properly configured.

Recommended Actions

To resolve LDAP authentication failures related to LDAP referrals, disable LDAP referrals in the BIG-IP configuration:

  1. Disable LDAP referrals:  
    # tmsh modify auth ldap system-auth referrals no
  2. Confirm the change:  
    # tmsh list auth ldap system-auth referrals
  3. The output should show referrals no.
  4. Save the configuration:  
    # tmsh save sys config
  5. Test LDAP authentication again to confirm successful login.
