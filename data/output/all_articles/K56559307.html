Known Issue

The BIG-IP AVR system may fill the /var disk volume to 100 percent capacity.

This issue occurs when all of the following conditions are met:

  • The BIG-IP AVR system is provisioned and collecting statistics.
  • The MySQL database becomes periodically unavailable, possibly due to lack of system resources.

Impact

The /var disk volume becomes full, causing system instability.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The /var/avr/loader directory is filled with files starting with the load_ prefix.
  • The system logs messages to the /var/log/ltm file that appear similar to the following example:

    err diskmonitor: 011d0004: Disk partition var has only 0% free

  • The df command line utility reports that the /var partition is at or near capacity, as shown in the following example:

    df -h /var

    Filesystem Size Used Avail Use% Mounted on
    /dev/mapper/vg--db--sda-set.1._var
    3.0G 3.0G 0 100% /var
