K9147: The Microsoft Terminal Services Client (mstsc.exe) does not auto-launch correctly on Windows Vista 64-bit clients

Type
Knowledge
Published
2008-09-16
Updated
2023-02-21
Status
Legacy Content
Applies to

  • FirePass: 6.0.2
Source

Topic

If you configure the Microsoft Terminal Services Client (mstsc.exe) application on the Network Access: Resources page under the Launch Application tab on the FirePass controller, and you specify an application parameter in the Parameters field, users running Windows Vista 64-bit clients may observe that mstsc.exe launches without the parameter you configured.

Similarly, if you configure the mstsc.exe application on the Network Access page under the Launch Application tab in the BIG-IP SAM Configuration utility, and you specify an application parameter in the Parameters field, users running Windows Vista 64-bit clients may observe that mstsc.exe launches without the parameter you configured.
 
For example, if you configured mstsc.exe as the application and /v:172.28.4.124 as the application parameter, mstsc.exe should launch and connect to the IP address 172.28.4.124. On Windows Vista 64-bit clients, mstsc.exe launches, but may prompt for a destination host instead of automatically connecting to 172.28.4.124.
 
This behavior occurs due to an issue with the 32-bit version of mstsc.exe, which was distributed with Windows Vista 64-bit systems. Users can install Service Pack 1 (SP1) on their Windows Vista 64-bit systems. SP1 installs the 64-bit version of mstsc.exe, which resolves this issue.
