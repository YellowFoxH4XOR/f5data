Description
You would like to know does BIGIP VE supports generation 2 Virtual Machine in Hyper-V or not.

Environment

  • BIGIP VE
  • Hyper-V

Cause
Currently, for all types of Hyper-V, BIGIP virtual machine support only generation 1.

Recommended Actions

Please use generation 1 during the creation of BIGIP virtual machine on Hyper-V.
