Topic

The F5 Return Material Authorization (RMA) process provides Advanced Exchange replacement units for defective hardware. When you receive your Advanced Exchange replacement unit, you must verify the BIG-IP software version and perform an upgrade as necessary.

Description

Due to supply-chain lead times, the Advanced Exchange replacement unit that you received or will receive may not have the same software version installed as the defective unit does. Before introducing the Advanced Exchange replacement unit into your environment, you must verify that the new unit has the correct BIG-IP software version installed and perform a software upgrade if necessary. When selecting an upgraded BIG-IP software version, take the following into consideration:

  • You should upgrade the software version on the Advanced Exchange replacement unit to the version that was installed on the defective unit and running in your environment when the hardware issue occurred, or to a later version of the software.
  • If you need to upgrade to a later BIG-IP version than that running on the defective unit, ensure that the new software version is compatible with your hardware platform and that it follows the supported BIG-IP upgrade paths, as well as other factors. For more information on selecting a BIG-IP software upgrade version, refer to K99014642: BIG-IP upgrade guide | Chapter 2: Choosing a BIG-IP upgrade version.
  • F5 is committed to providing stable and secure networks and recommends that you run the latest BIG-IP software version to ensure that you have the most current security patches. The software version on the Advanced Exchange replacement unit may be vulnerable to the latest security vulnerabilities, such as that described in K52145254: TMUI RCE vulnerability CVE-2020-5902.
  • If you have Expedited RMA Services and received an Imaging Kit (USB memory stick) from an Expedited RMA depot, you still need to update or apply patches.
