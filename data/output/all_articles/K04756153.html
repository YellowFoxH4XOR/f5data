Topic

You should consider using this procedure under the following conditions:

  • You want to verify the proper operation of your rSeries system by uploading a QKView file to F5 iHealth.
  • You want to provide a QKView file to F5 Support to aid in troubleshooting an issue with an rSeries system.

Description

You can use the qkview utility on rSeries systems to automatically collect configuration and diagnostic information from the system. The qkview utility provided in F5OS-A software captures diagnostic information from the rSeries system and associated containers. 

Note: The qkview utility on the rSeries system does not capture diagnostic data from tenant BIG-IP systems. To generate diagnostic data for a tenant BIG-IP or BIG-IQ system, log in to the tenant system and perform the relevant procedure in K12878: Generating diagnostic data using the qkview utility.

The qkview utility on the rSeries system generates machine-readable JavaScript Object Notation (JSON) diagnostic data and combines the data into a single compressed Tape ARchive (TAR) format file. The single TAR file is comprised of embedded TAR files containing the diagnostic data of individual containers running on the system, as well as diagnostic data from the rSeries system. You can upload this file, called a QKView file, to iHealth, or give it to F5 Support to help them troubleshoot any issues.

Note: F5 Support requires a QKView file in all cases in which remote access to the product is not available.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have administrative access to the rSeries system.
  • Have an F5 Support single sign-on (SSO) account to access the iHealth diagnostics server.

Procedures

  • Run the qkview utility from the webUI
  • Upload a QKView file to iHealth from the webUI
  • Run the qkview utility from the command line
  • Export the QKView diagnostic output from the command line
  • Upload a QKView file to iHealth from the command line

Run the qkview utility from the webUI

To run the qkview utility from the webUI of the rSeries system, perform the following procedure:

Impact of procedure: The qkview utility runs many commands when collecting information. This behavior may cause an additional performance burden on systems that are already under heavy load.

  1. Log in to the webUI on the rSeries system.
  2. Go to DIAGNOSTICS  > System Reports.
  3. Select Generate QKView at the top-right corner.
  4. Enter a name for Filename.
  5. Enter values for the Timeout Value, Max File Size, and Max Core Size options, or leave them at the defaults.
  6. To exclude any core files found on the system from the QKView file, select Exclude cores.
  7. To start the qkview utility, select Generate QKView.

    The System Reports page shows the status of the QKView file generation process.

Upload a QKView file to iHealth from the webUI

To upload a QKView file to iHealth from the webUI of the rSeries system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the webUI on the rSeries system.
  2. Go to DIAGNOSTICS > System Reports.
  3. Select the QKView file you want to upload.
  4. Select Upload to iHealth.
  5. Enter the iHealth login credentials, F5 Support Case Number, and a Description in the fields provided.
  6. Select Upload.

    The System Reports page shows the status of the QKView file upload process.

Run the qkview utility from the command line

To run the qkview utility from the command line of the rSeries system, perform the following procedure:

Impact of procedure: The qkview utility runs many commands when collecting information. This behavior may cause an additional performance burden on systems that are already under heavy load.

  1. Log in to the command line of the rSeries system as the admin user.
  2. Run the qkview utility by entering the following command:

    system diagnostics qkview capture

    Optionally, to specify a filename for the QKView file, add the filename option. For example, to specify the filename r10000_qkview.tar, enter the following command:

    system diagnostics qkview capture filename r10000_qkview.tar

  3. Check the progress of a running qkview by entering the following command:

    system diagnostics qkview status

    When completed, the output logs to the /var/shared/qkview/ directory.

Export the QKView diagnostic output from the command line

You can export the QKView diagnostic files from the rSeries system using the file utility from the command line. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the rSeries system as the admin user.
  2. Export a diagnostic file using the following syntax:

    file export protocol <https | scp | sftp> local-file diags/shared/qkview/<qkview_filename> remote-host <host_address> remote-file <path/to/remote_file> username <user>

    For example, to export the r10000_qkview.tar diagnostic file to the /tmp/ directory of the remote host at 10.10.10.100 using scp protocol, enter the following command:

    Note: To disable remote system identity verification, use the insecure option to the file command.

    file export protocol scp local-file diags/shared/qkview/r10000_qkview.tar remote-host 10.10.10.100 remote-file /tmp/r10000_qkview.tar username admin

  3. Check the status of the file transfer by entering the following command:

    file transfer-status

    When completed, the output displays similar to the following example:

    1    |Export file|SCP     |diags/shared/qkview/r10000_qkview.tar                         |10.10.10.100       |/tmp/r10000_qkview.tar                          |         Completed|

Upload a QKView file to iHealth from the command line

After you obtain the QKView diagnostic file, you can upload the file to iHealth to diagnose the health and proper operation of your rSeries system. First, if you have not already done so, you need to configure F5OS with your iHealth credentials. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the rSeries system as the admin user.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Enter your iHealth credentials by using the following command syntax:

    system diagnostics ihealth config username <email address> password

    For example:

    system diagnostics ihealth config username john@example.com password

    You observe output similar to the following, prompting for your password.

    (<AES encrypted string>): ******

  4. Enter your iHealth password.
  5. Commit the changes and exit the configuration mode terminal by entering the following command:

    commit and-quit

To upload the QKView diagnostic file to iHealth, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the rSeries system as the admin user.
  2. Upload a diagnostic file to iHealth using the following syntax:

    system diagnostics ihealth upload qkview-file <qkview_file> description <description> service-request-number <case_number>

    For example, to upload the r10000_qkview.tar file to iHealth specifying service request number c123456, enter the following command:

    system diagnostics ihealth upload qkview-file r10000_qkview.tar description r10000 service-request-number c123456

  3. Check the iHealth upload status by entering the following command:

    show system diagnostics ihealth upload-status

    Output appears similar to the following example:

    system diagnostics ihealth upload-status SAAyySXX
     service-request-number c123456
     status                 COMPLETE
     ihealth-link           https://ihealth.f5.com/qkview-analyzer/qv/12345678
     description            r10000
