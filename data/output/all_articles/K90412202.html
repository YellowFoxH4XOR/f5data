Security Advisory Description

The compress_bidder_init function in archive_read_support_filter_compress.c in libarchive before 3.2.0 allows remote attackers to cause a denial of service (crash) via a crafted tar file, which triggers an invalid left shift. (CVE-2015-8932)

Impact

This functionality is exposed only to authenticated administrators using the LineRate Manager GUI, CLI, or REST API, when performing a system restore with a backup file of the LineRate system that has been tampered. A successful attack may allow unauthorized modification of files.
