Source
https://my.f5.com/manage/s/article/K000150446

Description

You are unable to import an SSL certificate to the device and see an error in the GUI: "File upload failed, please check log file for details".

 

You see the following error message in /var/log/webui.log:

 

202X-0X-1X XX:XX:XX,XXX ERROR [ajp-bio-127.0.0.1-XXXX-exec-XXXX] web.WebRequestHandler:parseContents - Caught exception: Processing of multipart/form-data request failed. /shared/tmp/upload_XXXXXX.tmp (Permission denied)

 

Environment

BIG-IP

Configuration Utility (GUI)

Certificates

 

Cause

Incorrect permissions set for /shared/tmp directory.

 

Recommended Actions

Correct file permissions on /shared/tmp: 

chmod 777 /shared/tmp

Additional Information
