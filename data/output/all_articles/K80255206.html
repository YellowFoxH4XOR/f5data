Description

Suspicious Browser related violations triggered for Firefox Browsers.

The anomaly showed in the logs is as following:

"Invalid Browser Capabilities Suspected" 
 

Environment

  • Firefox Browser version 88.0 or newer
  • Bot Defense challenges and verification enabled

Cause

Product Engineering opened bug ID1029373.

Note: The bug ID is currently not available on BugTracker.

The aim of the bug ID is to update functions in the detection libraries that are used for browser identification.
 

Recommended Actions

Update the 'Browser Challenges' via LiveUpdate. 

Note: The fix is available in the Browser Challenges released on 11 July 2021.

None.
