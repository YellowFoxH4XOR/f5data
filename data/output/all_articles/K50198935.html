Description
The F5 BIG-IP goes into OFFLINE state unexpectedly.

Below are the symptoms you may encounter.

    Environment

    This issue occurs when all the following conditions are met.

    • You have provisioned BIG-IP APM.
    • You are running BIG-IP software 12.1.x or 14.0.x
    • sys db log.webapplications.level { value "Debug" }
     

    Cause

    The issue may be related to ID668343 which debug log messages from the rewrite plugin are erroneously marked as "notice".

    Recommended Actions

    Please follow the steps to resolve the issue.

    1. If you wish to save the rewrite logs, please copy them to another partition which has a larger space. It is suggested to move them to /shared/ . Please run the following command to execute this action.
      cp /var/log/rewrite /shared/
      cp /var/log/rewrite1 /shared/
      cp/ /var/log/rewrite1.1 /shared/
       
    2. You can proceed to delete the rewrite logs. Please run the following commands to execute this action
      rm /var/log/rewrite
      rm /var/log/rewrite1
      rm /var/log/rewrite1.1
       
    3. You will need to set the web application logging from debug to notice. Please execute the following command.
      # tmsh modify sys db log.webapplications.level value Notice
       
    4. Confirm that the web application logging value has been changed by executing the following command.
      # tmsh list sys db log.webapplications.level
      sys db log.webapplications.level {
          value "Notice"
      }
       
    5. Reboot the device and it will be in Active state.
