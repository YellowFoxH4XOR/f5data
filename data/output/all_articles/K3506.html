Topic

The PXE installation process is used to reload the system software on an F5 Networks platform or blade server that does not ship with an integrated CD-ROM drive. For more information about this process, refer to K1494: Reinstalling system software from a network boot server.

The BIG-IP PXE installation process requires specific hardware, including a Network Interface Card (NIC) and CD-ROM drive, as well as the various interconnecting parts between those components.

F5 Networks cannot guarantee that all hardware will work with the PXE installation process, given the complexity of desktops, laptops, and servers and the various combinations of hardware that exist.

Following is a list of network cards and platforms that F5 Networks has successfully used for the PXE installation process, as well as a list of known platforms that do not work with the PXE installation process.

Note: F5 Networks cannot guarantee that all revisions of the following hardware will function properly. F5 Networks does not endorse or support any hardware or platform that is not provided directly by F5 Networks.

Network Interface Cards

The following NICs are supported by the drivers on the PXE installation CD:

  • AMD PCnet-PCI Ethernet
  • SMC EtherPower 10 and 100 Mb/s Ether and other cards based on DEC 21040/21140 chips
  • DEC/Intel 21143-based boards
  • Intel EtherExpress Pro100B
  • Broadcom/3Com Gigabit Ethernet adapter
  • Packet Engines GNIC-II (Hamachi) - Gigabit Ethernet
  • SysKonnect SK-NET Gigabit Ethernet
  • Intel E1000 Gigabit Adapter
  • Alteon Tigon Gigabit Adapter
  • Adaptec Starfire
  • 3COM EtherLink XL 3C900/3C905 (boomerang) PCI Ethernet adaptors
  • TI Thunderlan-based Ethernet adapters (Compaq/Racore)

F5 Networks has successfully used the following NICs for the PXE installation process:

  • Intel EtherExpress Pro100B
  • Broadcom/3Com Gigabit Ethernet adapter
  • Intel E1000 Gigabit Adapter

Using a VMware virtual machine

You can also run the BIG-IP version 9.x PXE network boot server as a VMware virtual machine. For information about setting up a new virtual machine, refer to your product documentation. Ensure that you select Other 2.4x Linux (32-bit) as the guest operating system, and that you bridge the virtual NIC to the BIG-IP management network. Leave all other settings as default when creating the virtual machine. You can mount the BIG-IP ISO file directly on the virtual CD-ROM drive. After powering on the virtual machine, the BIG-IP version 9.x PXE network boot server correctly detects the virtual NIC and loads the appropriate driver for it.

Using a VMware virtual machine can be convenient for the following reasons:

  • It allows the use of a host with a possibly otherwise unsupported network adapter
  • It is not necessary to burn the ISO file to a CD
  • A single host can be used to run the virtual machine and at the same time connect to the console of the BIG-IP system
