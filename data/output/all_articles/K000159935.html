K000159935: Identifying client and server SSL Profiles associated with SSLO virtual servers

Description

When managing expired certificates and unused SSL profiles in a BIG-IP SSL Orchestrator (SSLO) deployment, administrators may need to determine whether the client and server SSL profiles are associated with SSLO virtual servers before safely deleting them. 

Environment

  • BIG-IP SSLO
  • SSL profiles (client and server)

Cause

None

Recommended Actions

Run the following TMOS shell (tmsh) command to display the client and server SSL profiles associated with SSLO virtual servers:

tmsh list ltm virtual recursive | egrep -i 'virtual sslo_|ssloT'

Output example:

ltm virtual sslo_<topology_name>.app/sslo_<topology_name>-t-4 {
        sslo_<topology_name>.app/ssloT_<topology_name>-cssl {
        sslo_<topology_name>.app/ssloT_<topology_name>-sssl {

Note:  <topology_name> will be replaced with your actual SSLO topology name.
