Issue



If a user exceeds the maximum number of concurrent logons in the FirePass controller, the following message appears on the Reports: System Logs page:

User X has exceeded the allowed number of concurrent logons

This error message indicates that the concurrent logon limit for the FirePass has been reached by the user X. Additional logins by that user will cause an earlier session belonging to that user to be terminated. The concurrent session limits for the FirePass master groups is displayed on the Device Management: Security: User Access Security page, under the Concurrent logons section.

You can view concurrent sessions by clicking on the Tools Webifyer, if it is displayed on the Webtop. Selecting View Current Sessions will list all actively logged in connections for your username. Additionally, you may choose to terminate any of the sessions, except the currently used session.
