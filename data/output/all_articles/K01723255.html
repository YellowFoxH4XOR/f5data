Description

The secondary blades on the chassis send syslog without hostname/FQDN.

Instead of the hostname it only send slotX.

Example:

On version 12.1.2 logs look like below:

slot4/VIP2400 emerg overdog[4056]: 01140043:0: Ha feature software_update reboot requested.
slot1/VIP2400 emerg overdog[4083]: 01140043:0: Ha feature software_update reboot requested.
slot2/VIP2400 emerg overdog[4084]: 01140043:0: Ha feature software_update reboot requested.
slot3/VIP2400 emerg overdog[4084]: 01140043:0: Ha feature software_update reboot requested.

After upgrading to version 15.1.3:

VIP2400.example.lab emerg overdog[4056]: 01140043:0: Ha feature software_update reboot requested
slot2 emerg overdog[4083]: 01140043:0: Ha feature software_update reboot requested.
slot4 emerg overdog[4084]: 01140043:0: Ha feature software_update reboot requested.
slot3 emerg overdog[4084]: 01140043:0: Ha feature software_update reboot requested.

Environment

  • VIPRION
  • After upgrade

Cause

Bug ID 992097: Incorrect hostname is seen in logging files

Recommended Actions

There is no workaround or fix at the time of publication of this article.

Please contact F5 support for an Engineering Hotfix, referencing this article.
