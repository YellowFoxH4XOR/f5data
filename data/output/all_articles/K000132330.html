K000132330: APM edge client may show different version to the installed version on APM

Type
Support Solution
Published
2023-02-14
Updated
2023-02-14
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000132330

Description

  • Edge Client version may show differences from the installed version on the APM it connects to. e.g. On BIG-IP APM the installed APM Edge Client package version is 7230, however, the installed Edge Client version on the client is 7221.

Environment

  • APM
  • Edge client

Cause

There are several APM gateway e.g. based on location/different countries
e.g. The customer may have shared a hosted-content of Edge Client 7221 using the sandbox feature from APM2.
When users access webtop of APM1 it will download the shared hosted content of Edge Client 7221 instead of the installed Edge Client package on APM1.
Resulting in different Edge Client versions between Client and APM.

 Recommended Actions

Customer needs to rebuild the Edge Client package file and then update the hosted-content file via sandbox
At the same time, make sure all APM gateways have the same version of Edge Client package.

Additional Information

If the user installed an older version of Edge Client, it can bring back some bugs.
