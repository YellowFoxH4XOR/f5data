Topic

The bigtop tool is a command line utility that displays real-time statistical information for BIG-IP LTM system objects such as virtual servers and nodes. For example, the following items are displayed when using the bigtop utility:
  • Current time
  • Network activity in bits, bytes, packets, or requests
  • Nodes available for virtual servers
  • Current state of nodes

The bigtop display is comprised of the following three sections:

  • BIG-IP
  • Virtual IP:port
  • Node IP:port

BIG-IP

The BIG-IP section displays the following information:

  • BIG-IP system hostname
  • High availability state: ACTIVE or STANDBY
  • System-wide connection information:
     
    • bits, bytes, packets, or requests in or out since last reboot
    • bits, bytes, packets, or requests in or out in previous four seconds

Virtual IP:port

The Virtual IP:port section displays the following information:

  • Virtual server IP:port or virtual server hostname:port
  • Virtual server connection information:
     
    • Bits, bytes, packets, or requests in or out since last reboot
    • Bits, bytes, packets, or requests in or out in previous four seconds
  • Node status:
    • number of nodes up for the virtual server

Node IP:port

The Node IP:port section displays the following information:

  • Node IP:port or virtual hostname:port
  • Node connection information:
     
    • Bits, bytes, packets, or requests in or out since last reboot
    • Bits, bytes, packets, or requests in or out in previous four seconds

  • Node state:

    The following table lists the node state and definition:

    Node StateDefinition
    UPNode / Node IP:port is UP
    DOWNNode IP:port is DOWN
    FORCED DOWNNode IP:port is forced offline
    ERRORThe IP:port is marked as DOWN by an iRule, which may, for example, use the LB::down command
    MULTIPLEThe node is a member of multiple pools, and the status of the node is different in two or more of the pools
    NODE DOWNNode is forced offline, or marked down by monitor
    UNCHECKEDThe node IP:port does not have a monitor assigned to it


Customizing the bigtop display

The bigtop utility accepts the following options to customize the display of information:

Note: For details, refer to the bigtop man page.

CommandFunction
-bytesDisplays counts in bytes (as opposed to bits)
-pktsDisplays counts in packets (as opposed to bits)
-reqsDisplays counts in requests (as opposed to connections)
-vips <n>Prints the designated number of virtual servers
-hPrints the bigtop help page
-nodes <n>Prints the designated number of nodes
-oncePrints once and exits
-delay <n>Designates the number of seconds between samples (the default is four)
-scrollDisables full-screen mode
-nosortDisables sorting
-connSorts by connection count (as opposed to byte count)
-deltaSorts by count since last sample (as opposed to total)
-nPrints the IP address and services in numeric format
-vnameDisplays virtual servers by name (as opposed to by IP address)
