K000161424: After Upgrade, DoS Profile Vector tcp-window-size threshold-mode Changes from Fully-Automatic to Manual

Type
Support Solution
Published
2026-05-26
Updated
2026-05-26
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000161424

Description

After upgrading BIG-IP from version 17.5.1.4 to 17.5.1.5, the threshold-mode fully-automatic configuration line for the DoS profile network attack vector tcp-window-size is missing from the bigip.conf file. The threshold mode for this vector reverts to "Manual" without user intervention, impacting DDoS detection and mitigation.

Environment

  • Product: BIG-IP AFM
  • Affected Version: 17.5.1.5 (upgraded from 17.5.1.4)
  • Platform: F5-BIG-LTM-R5900, C129
  • Feature: DoS protection profile with network attack vector tcp-window-size set to "Fully Automatic" (prior to upgrade)

Cause

This is a software defect tracked by Bug ID2297821.

Answer/Recommended Actions

After upgrading to BIG-IP 17.5.1.5, manually restore the threshold mode for the affected DoS attack vector:

  1. Log in to the BIG-IP GUI.
  2. Navigate to the affected DoS protection profile(s).
  3. Locate the tcp-window-size network attack vector where the threshold mode has reverted to "Manual."
  4. Change the threshold mode back to "Fully Automatic" for the vector.
  5. Click Commit Changes to apply the settings.

Additional Information

  • This behavior is a known software defect and is not the result of an intentional configuration change during the upgrade process.
  • The missing threshold-mode fully-automatic line in bigip.conf after upgrade is a side effect of the upgrade.
  • After manually committing the change back to "Fully Automatic," the bigip.conf will reflect the updated configuration for the vector, which can then be compared against pre-upgrade backups.
  • Bug ID2297821 has been raised with the Product Development team and a fix is planned for a future BIG-IP software release.
