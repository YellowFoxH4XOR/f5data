Summary

BIG-IP 12.0.0 includes a limited availability Early Access (EA) release of iRules LX.

Description

This new feature requires a license key to function and is restricted to invite-only customers. While you can provision iRules LX, and it appears to be configured without a license, the feature will not function.

Attempting to use iRules LX on a virtual server causes connections to fail, and in the /var/log/ltm log file, the system logs a TCL error message similar to the following example:

err tmm0[<pid>]: 01220001:3: TCL error: /Common/my_irule <HTTP_REQUEST> - Could not find ILX extension my_extension in path my_plugin (line 1) invoked from within "ILX::init my_plugin my_extension"

Note: F5 introduced the iRules LX feature in BIG-IP 12.1.0 for general availability; attempting to use unlicensed iRules LX still generates the error message.

Recommendations

You should not provision iRules LX without an EA license. All available EA licenses have been allocated to customers, and no additional licenses will be available.  Further information on new functionality in iRules LX will be available on DevCentral in due course, and full availability of iRules LX will be in a future BIG-IP release.
