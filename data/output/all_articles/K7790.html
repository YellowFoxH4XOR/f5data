Issue

Your Network Access Client may be in a partially installed state if you receive the following error message when you start a Network Access favorite:

Network Access client did not start (error code -3)

In this situation, you should uninstall the Network Access client components; the next time you start a Network Access favorite, you will be prompted to download and install the Network Access client. Alternatively, you may use the installation method that is appropriate for your organization to install the Network Access components.

To uninstall the Network Access client on Windows-based operating systems, open the Add or Remove Programs Control Panel and remove the F5 Networks VPN Client for Windows.

Note: To uninstall the Network Access client on Mac OS X operating systems, refer to K3826: Removing FirePass Network Access client components from Mac OS X. To uninstall the Network Access client on Linux operating systems, refer to K7791: Removing Network Access client components from Linux systems.
