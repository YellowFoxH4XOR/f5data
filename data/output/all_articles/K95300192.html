Description
Attempting to view DNS resource records in the GUI (Configuration utility) fails and gives the following error:

err zrd[PID]: 01150b21:3: RCODE returned from query: 'REFUSED'

  • Not able to display resource records information in the GUI.
  • Resource records are visible in the BIND config file.

Environment

  • Resource records configured in BIND
  • Viewing DNS resource records at DNS  ››  Zones : ZoneRunner : Resource Record List

Cause
BIND not able to feed resource record information to Configuration utility.

Recommended Actions
Modify BIND allow-transfer parameter to allow the feed of resource records.

Via Configuration utility:

  1. Browse to DNS  ››  Zones : ZoneRunner : Zone List  ››  Properties : <zone.name>
  2. Modify the allow-transfer section

    FROM
    allow-transfer {
       127.0.0.1;
    };

    TO
    allow-transfer {
       127.0.0.1;
       localhost;
     };
Via CLI:
  1. Open the /var/named/config/named.conf file with the text editor
  2. Add localhost to allow-transfer section:

    For example:
        zone "www.abc.com." {
            type master;
            file "db.www.abc.com.";
            allow-transfer {
                10.56.56.56;
                localhost;
            };
            allow-update {
                localhost;
            };
        };

Additional Information
If your BIND configuration contains multiple views. Ensure that only the last view contains the value "any;", in the match-class options statement. Views are consumed from the first-listed, to the last-listed (top-down), as configured in the named.conf file.
