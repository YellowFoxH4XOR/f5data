Description
what does "Transitions" column in the output of tmsh show cm failover-status represent ?

Environment

  • BIG-IP
  • HA
  • tmsh show cm failover-status
  • Transitions

Cause

  • n/a

Recommended Actions

Transactions represent how many times the interfaces in unicast settings detects peer 's status change.

For the below device the initial value for transitions was 1 for subnet 192.68.1.x. After rebooting peer device its value changed as explained below.

-----------------------------------------------------------------------------------------------------
CM::Failover Connections
Local Failover Address  Remote Device     Packets  Transitions  Received Last Packet  Status

-----------------------------------------------------------------------------------------------------
172.16.0.113:1026       LTM-A.rlab.local  3041     4            2019-Nov-23 21:53:51  Error   <<=== this subnet communication was already broken earlier so no change
192.168.1.113:1026      LTM-A.rlab.local  879562   1            2019-Nov-24 21:19:06  Ok 


so it should matches how many times /var/log/ltm logged similar to below logs, after BIG-IP started running/interface is added.
warning sod[<PID>]: 010c0083:4: No failover status messages received for 3.100 seconds, from device LTM-A.rlab.local (10.200.175.112) (unicast: -> 192.168.1.113).
 
NOTE: There is no way to reset the transition count, rather than restarting tmm.
