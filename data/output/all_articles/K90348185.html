Source

Description

The following messages are seen in the /var/log/asm:

crit g_server_rpc_handler.pl[XXXX]: XXXXXXXX:X: ASM subsystem error (asm_config_server.pl,(eval)): Couldn't pass call to async process - ignoring

Environment

  • BIG-IP ASM
  • Logs

Cause

Bug ID 885765

Note: After upgrading to a fixed version the error may still be logged, however and it can be safely ignored (cosmetic).

Recommended Actions

Upgrade to fixed version. Follow link to bug ID.
As a workaround you can perform the following:

  1. Log on the the command line of the affected system.
  2. Run the following commands
      cp /etc/ts/tools/asm_config_server.cfg /etc/ts/tools/asm_config_server.cfg.orig
      echo 'AsyncMaxMemorySize=300000000' >> /etc/ts/tools/asm_config_server.cfg
      diff /etc/ts/tools/asm_config_server.cfg.orig /etc/ts/tools/asm_config_server.cfg
      pkill -f asm_config_server
