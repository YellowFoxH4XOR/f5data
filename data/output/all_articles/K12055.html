Known Issue

This is the result of a known issue. When viewing a downloaded logon report, user names containing a backslash character (\) will display with the backslash character removed. For example, user\john will display on the report as userjohn.

Note: This issue only occurs when downloading the report; the user name will display correctly when viewed through the Administrative Console.

Additionally, if the user name contains a backslash character followed by a zero (\0) the user name will be truncated at the (\0). For example, user\01 will display on the report as user.

F5 Networks Product Development is tracking this issue as ID 337593.
