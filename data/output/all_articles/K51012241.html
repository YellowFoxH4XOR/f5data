K51012241: Configuration loading error media type is incompatible with other trunk members

Type
Support Solution
Published
2019-11-25
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.X.X, 13.X.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.0.1, 13.0.0, 13.1.0, 13.0.X
Source
https://my.f5.com/manage/s/article/K51012241

Description

Configuration fails to load, with an error similar to the following:

01070619:3: Interface 2.4 media type is incompatible with other trunk members Unexpected Error: Loading configuration process failed.

Environment

  • Trunk
  • Reload configuration, Upgrade or Re-licensing.

Cause

This problem can be caused by a range of issues, some are dependent on on the platform and software version used.

Recommended Actions

  1. Verify that F5 optical components are in use and that they are the proper type. F5 strictly prohibits the use of non-F5 components, and use of third party components may impede troubleshooting.

    • K8153: F5 support of third-party hardware components
  2. Verify that the media type and speed are the same across all interfaces in the trunk by reviewing the output of the tmsh list net interface command.

  3. A known issue can cause this problem, for more information, see the following article:

    • K01481294: The BIG-IP system may fail to add a network interface to an existing network trunk
  4. If this problem continues to occur after performing these troubleshooting steps, contact F5 Support for further assistance.
  5. To work around the immediate issue and load the configuration, you may remove the problematic interface from the trunk in the bigip_base.conf configuration file, then reload the configuration.
  • Log in via CLI.
  • Go to bash, on bash make sure you are located on config.
  • On config, look for the bigip_base.conf file and create a backup.
    Example:
    [In Sync] config # cp /config/bigip_base.conf /config/bigip_base.confK51012241  
  • Open /config/bigip_base.conf on a file editor and comment out or remove the target interface.
  • Repeat the step above for each interface that throws out the error.
     

For example, to remove interfaces 2.3 and 2.5 from the below trunk, remove this line:

net trunk ext_trunk {
    interfaces {
        2.3 <---------
        2.4
        2.5 <---------
    }
    lacp enabled
    lacp-timeout short
}

Save the file once the trunk configuration looks like this:

net trunk ext_trunk {
    interfaces {
        2.4
    }
    lacp enabled
    lacp-timeout short
}

Note: Links in a trunk should optimally be configured in powers of 2.

Then reload the configuration:

tmsh load sys config
