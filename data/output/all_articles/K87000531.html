Description

When trying to install linkcost.im patch, you've encountered the error below:

[root@bigip:Active:Standalone] config # im /var/tmp/linkcost.im
mount: /dev/loop1 is write-protected, mounting read-only
/usr/bin/upgrade_rpmdisk : Detected version 1.0, release 0.0.241
Freeing read locks for locker 0x45: 30261/1440206016
rpmdb: /shared/lib/rpm/Name: unexpected file type or format
error: cannot open Name index using db3 - Invalid argument (22)

Environment

  • BIG-IP DNS
  • BIG-IP Appliance / VIPRION
  • All BIG-IP versions

Cause

RPM database under /shared is corrupted. This is related to BUGID 767689

Recommended Actions

  1. Backup the current Packages file:
    # cp /shared/lib/rpm/Packages /shared/tmp/
  2. Remove all the files from the database directory
    # rm -f /shared/lib/rpm/*
  3. Initiate the database by using the old version RPM:
    # /opt/bin/rpm --dbpath /shared/lib/rpm --initdb
  4. Restore the Packages file (Press 'y' when promoted by 'cp: overwrite'):
    # cp /shared/tmp/Packages /shared/lib/rpm/Packages 
  5. Install the patch, type the following command:
    # im /var/tmp/linkcost.im

You should see no errors after performing the steps above

[root@bigip:Active:Standalone] config # im /var/tmp/linkcost.im
mount: /dev/loop1 is write-protected, mounting read-only
/usr/bin/upgrade_rpmdisk : Detected version 1.0, release 0.0.241
[root@bigip:Active:Standalone] config #
