Description

After performing a software upgrade and booting to the new volume, you might encounter an issue where the GUI is not responding. However, you are able to SSH to the BIG-IP. Additionally, the shell prompt may broadcast the below message repeatedly: 

logger[1234]: Re-starting named

Environment

  • BIG-IP
  • after upgrade

Cause

Corrupt install
Bug ID 759564: GUI not available after upgrade
 

Recommended Actions

  1. Boot back to the previous boot volume.
  2. Delete the boot volume containing the failed installation.
  3. Re-install the new version.

After following these steps, the GUI should be available and functional.

If the issue persists, try running the following commands in bash:

  • bigstart status httpd : This command should show the service as down, but it should normally be up.

  • bigstart restart httpd : This command may fail.
