Issue

Error Message

Boot device not found

Message Location

You may encounter this message in the following location:

  • The serial console

Description

This message occurs when any of the following conditions are met:

  • A BIG-IP device is unable to find a bootable partition on the HDD.
  • The HDD on a BIG-IP device is not functioning or not reachable.
  • Some other hardware failure is interrupting communication with the HDD.

Impact

The BIG-IP system is unable to start due to a corrupt, missing, or failed HDD partition. 

Recommended Actions

Install and run the End-User Diagnostics (EUD) utility to determine the state of the hard disks for your device. To do so, perform all of the following tasks:

  • Refer to the documentation for information about installing and running the EUD:  
    • For  BIG-IP 2000, 4000, 5000, 7000, 10000, 12000, and BIG-IQ 7000 Series: 
      • Field Testing BIG-IP and BIG-IQ Hardware
    • For iSeries platforms: 
      • Field Testing F5 Hardware: iSeries Platforms
  • Follow the Loading the EUD onto a USB flash drive procedure using the EUD manual that is appropriate to your device.
  • After running the EUD utility, contact F5 Technical Support and submit the resulting EUD output report.
