Description

The BIG-IP LTM (Local Traffic Manager) system supports CRL (Certificate Revocation List) files in both PEM (Privacy Enhanced Mail) and DER (Distinguished Encoding Rules) formats.
   
   1. PEM format is the most common format for CA (Certificate Authority) certificates and is stored with the .crt extension. It is a base64-encoded ASCII file that can contain multiple certificates and private keys within a single file.

   2. DER format is a binary file that typically has a: 
       • .der or .cer file extension for certificates,
       • .key file extension for keys.

Environment

  • BIG-IP all versions

Cause

None, this is informational article.

Recommended Actions

 When exporting an SSL certificate and key from a web server for use on a BIG-IP system, they need to be converted to PEM format if they are in DER format;
 The step-by-step procedure can be found in K04040195. 

Additional Information

It is important to note that the BIG-IP system must have sufficient memory available to allocate the CRL (PEM, DER) file into memory, and there are maximum file size limits for both PEM and DER formats depending on the version of BIG-IP being used.
