Issue

Error Message

info chmand[<PID>]: 012a0006:6: <LIBHAL reporting informational>

In this error message, note the following:

  • <PID> is the process ID for the chmand process.
  • <LIBHAL reporting informational> is an informational message describing a hardware event.

For example:

info chmand[8154]: 012a0006:6: Firmware is up to date in active slot

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The hardware monitoring in the BIG-IP system observed an informational event associated with hardware.

The message is commonly used when the BIG-IP system reports chassis and blade status that is related to disk media and sensor monitoring.

Impact

There is no impact. There are no actions to take based on these messages.

Recommended Actions

None
