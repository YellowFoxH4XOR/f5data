Known Issue

This is the result of a known issue. When a BIG-IP 3400 platform running version 10.2.x boots up, the following warning messages are logged to the /var/log/kern.log file and to the kernel ring buffer (dmesg):

ACPI Warning (dswload-0695): Type override - [DEB_] had invalid type (Integer) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [MLIB] had invalid type (Integer) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [IO__] had invalid type (Integer) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [DATA] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [SIO_] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [SB__] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [PM__] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [ICNT] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [ACPI] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [IORG] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [SB__] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [PM__] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [SIO_] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [PM__] had invalid type (String) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [BIOS] had invalid type (Integer) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [CMOS] had invalid type (Integer) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [KBC_] had invalid type (Integer) for Scope operator, changed to (Scope) [20060707]
ACPI Warning (dswload-0695): Type override - [OEM_] had invalid type (Integer) for Scope operator, changed to (Scope) [20060707]

These warning messages are the result of the BIOS settings used on the BIG-IP 3400 platform. They are benign and should be ignored.

F5 Product Development is tracking this issue as ID 341474.
