Known Issue

The Configuration utility may erroneously prevent a user assigned the Application Editor role from updating a node's description field.

This issue occurs when all of the following conditions are met:

  • You have an existing node on a BIG-IP system.
  • You are assigned the Application Editor role.
  • You use the Configuration utility to attempt to modify the node’s description field.

Impact

A user assigned the Application Editor role is not able to modify the description field of the node using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • As the Application Editor, you notice that the node description field is not editable.

Workaround

To work around this issue, you can modify the node description using the Traffic Management Shell (tmsh). To do so, perform the following procedure:

Note: To access the tmsh utility, the Terminal Access setting on your user Properties screen needs to be set to tmsh. For more information, refer to K12029: Accessing the Traffic Management Shell.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility.

    Note: If you have access to the tmsh utility, you enter it directly after you log in to the BIG-IP system.

  2. Modify the node description by typing the following command syntax:

    modify /ltm node <node_IP> description "<node_description>"

    For example:

    modify /ltm node 172.16.0.0 description "node_1"

  3. Save your changes by typing the following command:

    save /sys config

  4. To exit the tmsh utility, type quit and press Enter.
