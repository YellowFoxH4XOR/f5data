K000151224: Getting error connection reset on server

Type
Support Solution
Published
2025-06-12
Updated
2025-06-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000151224

Description

Unable to reach the application getting error message " This site can't be reached "

Environment

  • X-Frame-Options : SAMEORIGIN
  • [Expert Info (Warning) : Illegal characters found in header name]

Cause

If a request or response contains a malformed HTTP header (such as illegal characters, extra spaces, duplicate headers, or both Content-Length and Transfer-Encoding in the same response), the BIG-IP will reset the connection and log a "Malformed HTTP header error.

Recommended Actions

  1. Packet Capture Analysis

    • Use Wireshark to inspect HTTP headers for illegal characters, whitespace, or line folding.
    • Look for warnings like "Illegal characters found in header name".

        2.Correct Server/Application Behavior

    • The best practice is to fix the server or client to send RFC-compliant headers (no spaces before the colon, no illegal characters, no obs-fold, etc.).
