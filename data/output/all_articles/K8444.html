Topic

F5 highly recommends that you perform the following procedures prior to upgrading the software on a FirePass Controller:

  1. Thoroughly review the release notes for the version of FirePass software to which you are upgrading. Pay particular attention to the Known Issues section, and ensure that no known issues will disrupt operations in your environment. Additionally, follow any pre-upgrade procedures contained in the release notes and note any upgrade procedures.

    Important: Before deciding that you do not want to upgrade due to a known issue, proceed to Steps 2 and 3. A hotfix or workaround may have been provided after the release notes were published.
  2. Check the F5 Downloads site for available hotfixes for the version of FirePass software to which you are upgrading. Review the hotfix readme files to determine which hotfixes and cumulative hotfixes are relevant to your environment.
  3. Search the AskF5 Knowledge Base for known issues affecting the version to which you are upgrading. The known issues listed in the release notes are the known issues at the time of the product release. Known issues that are discovered after the product release are posted to AskF5. Additionally, AskF5 is frequently updated with hotfix information and workarounds for known issues.
  4. Ensure that your F5 support contract is active. An active support contract is required to perform a FirePass Online Update. Additionally, if you plan to perform a Local Update, an active support contract is required to download software from the F5 Downloads site.
  5. Develop a test plan for all applications and services accessed through the FirePass controller. Verify this test plan prior to the upgrade using your current FirePass software and configuration. Once the upgrade is complete, use the same test plan to verify that your applications and services are accessible through the new version of FirePass software.
  6. If you are upgrading a FirePass failover pair, review K4467: Upgrading a redundant pair of FirePass controllers.
  7. If you are upgrading from version 5.5.x of FirePass software to version 6.0.2, review K8249: Upgrade from 5.5.x to 6.0.2 fails to update configuration data.
  8. If you are upgrading to FirePass version 6.1.0, review K10923: Upgrading to FirePass version 6.1.0
  9. Schedule ample time to perform the upgrade. Upgrade times will vary depending on your environment, and whether you are upgrading a single FirePass controller or a FirePass failover pair or cluster. In addition to the upgrade itself, ensure that you factor in the time to create backups and snapshots, apply hotfixes before and after the upgrade (if applicable), perform your test plan after the upgrade, and troubleshoot potential issues. Additionally, if you plan to perform an Online Update, the speed of your Internet connection directly affects the amount of time required for your upgrade. If this is a concern, download the FirePass software from the F5 Downloads site prior to your upgrade window and use the Local Update feature to upgrade the FirePass controller.

    For more information about performing a Local Update, refer to the FirePass Controller Administrator Guide.
  10. Immediately prior to the upgrade, log on to the FirePass Administrative Console and create a configuration backup on the Device Management: Maintenance: Backup/Restore page. If you have multiple FirePass controllers, perform this step on each FirePass controller.

    Important: Even though members of FirePass failover pairs and clusters synchronize configurations, some settings are not synchronized.

    Note    : Backing up log messages is optional.

    For example, IP address information is unique to each FirePass controller and so this setting is not synchronized. For this reason, F5 highly recommends performing a backup of each FirePass controller prior to the upgrade.
  11. Immediately prior to the upgrade, create a snapshot of the FirePass controller. If you have multiple FirePass controllers, perform this step on each FirePass controller.

    For more information about creating a snapshot, refer to K3244: Backing up and restoring FirePass system software.

    Important    : You cannot currently downgrade FirePass software.The snapshot feature is the only feature that allows you to revert to a previous version of FirePass software.

    Note: The snapshot feature is available only on FirePass systems that are shipped with version 5.0.0 or later. You cannot use the snapshot feature on FirePass systems that you have upgraded from versions 3.x or 4.x.

    Note: You may want to temporarily increase the Global Inactivity Timeout setting to two or three hours, to ensure your session does not time out during the upgrade process. For more information, refer K3106: Configuring server-side session timeouts.
