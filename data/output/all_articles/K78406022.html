Description

You cannot disable FIPS mode using the Configuration utility or tmsh. 

Environment

  • BIG-IP.
  • PAYG Best Azure license.
  • FIPS 140.

Cause

PAYG BEST bundle has FIPS enabled by default and it is not possible to disable it.

Recommended Actions

In order to disable FIPS, you have to redeploy your machine and use a different license. Below are the options that do not include FIPS:

PAYG BETTER bundle doesn't include FIPS but only LTM,DNS, and AFM modules can be provisioned.
BYOL can be customized depending on the acquired license and your needs.
