K000133693: Some points about shutdown rSeries F5OS

Description

When you shutdown rSeries F5OS, as a best practice F5 would recommend the shutdown of the tenant(s) before shutdown F5OS.

Environment

F5OS

Cause

The host (F5OS) system can be shutdown without shutting down the tenant(s) first. However, a couple things to consider...

  1. If the shutdown is simply done via the host for the entire system then when it is started back up the tenant(s) will also come back up with it. In many instance this may or may not be desirable.
  2. If the entire system is brought up all at once there can be a strain on the resources. Versus bringing each component up one at a time.

Recommended Actions

  1. Shutdown the tenant(s) one at a time:
    1. K21121803: Shut down and restart a tenant on the VELOS and F5 rSeries systems
    2. K000136124: F5OS powers a tenant back on if tenant is shutdown from the tenant itself
  2. Shutdown the host
    1. Review the section titled 'Shut down the system' here...Platform Overview: F5 r2000/r4000 Series models
  3. For the restart reverse the actions:
    1. Boot up the host
    2. Bring up the tenant(s) one at a time.
