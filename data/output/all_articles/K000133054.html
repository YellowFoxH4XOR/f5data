K000133054: Too many very large memory bigd processes cause low memory issues

Type
Support Solution
Published
2023-03-17
Updated

Source

Description

Too many very large memory bigd processes cause low memory issues

 

Environment

BIG-IP
 

Cause

The number of bigd instances to start is determined by /etc/bigstart/scripts/bigd and is based on the number of CPU cores. On systems with a large amount of cores this could lead to too many instances of bigd that unecessarily consume too much memory.
 

Recommended Actions

The number of bigds that run can be set with the Bigd.NumProcs db variable (0 indicates to let the bigstart script figure it out).

 

Try reducing the number of bigds to a lower number:

 

# tmsh modify sys db bigd.numprocs value 4

 

# tmsh list sys db bigd.numprocs

 

sys db bigd.numprocs {

value "4"

}
