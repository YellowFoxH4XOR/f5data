Description

After upgrading to v14 and v15, it does not load config and console shows similar to below error message and freeze.

[  480.507756] "echo 0 > /proc/sys/kernel/hung_task_timeout_secs" disables this message.
[  480.554777] INFO: task tmm.0:13402 blocked for more than 120 seconds.
[  480.593322] "echo 0 > /proc/sys/kernel/hung_task_timeout_secs" disables this message.
[  600.629914] INFO: task kworker/1:0:14 blocked for more than 120 seconds.
 

/var/log/ltm log shows similar to below loading issue message:

01070712:3: Values (/<partition>/<analytics_child_profile>) specified for AVR traffic capture (/<partition>/<analytics_child_profile> /Common/capturing-for-Analytics-Default): foreign key index (profile_FK) do not point at an item that exists in the database.
 

Environment

  • BIG-IP
  • After upgrade to v14.*-v15.*
  • HTTP custom Analytics profile is created.
     

Cause

Unknown at the time of most recent publication
 

Recommended Actions

  1. Boot back from the original location.
  2. Delete the boot location installed v14.* or v15.*
  3. Remove HTTP custom Analytics profile from BIG-IP configuration.
    Note: If the HTTP custom Analytics profile is attached to virtual server, remove first from the virtual server, then remove it. 
  4. After removing it, save the config.
  5. Reinstall v14.* or v15.*
  6. Boot from the location you installed the new version.
