You would like to update a certificate, key or CA bundle for an existing ClientSSL configuration.
 

Environment

  • BIG-IP
  • SSL Offload

Cause 

Creation or update of a ClientSSL profile.
 

Recommended Actions

  • Importing SSL certificates, keys or CA bundles
  • Creating a ClientSSL profile
  • Updating a ClientSSL profile
  • Updating a CA bundle

 

How to import SSL certificates and keys

  1. Logon on the BIG-IP Configuration utility.
  2. Go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  3. Click Import.
  4. Select the Import Type from the pull-down menu (Key, Certificate, PKCS 12 (IIS) or Archive). 
  5. Enter a unique name for Certificate Name.
  6. Choose the Certificate Source (Upload File or Paste Text).
  7. For PKCS imports enter the PKCS password and select the PKCS import storage type for Key Security (Password or Normal).
  8. Click Import.

 

How to create ClientSSL profile

  1. Logon on the BIG-IP Configuration utility.
  2. Go to Local Traffic > Profiles > SSL > Client.
  3. Click Create.
  4. Enter a unique Name for the ClientSSL profile.
  5. Click the checkbox for Custom.
  6. In Certificate Key Chain click Add.
  7. For Certificate select the name given to your imported certificate from the pull-down menu.
  8. For Key select the name given to your imported key from the pull-down menu.
  9. For Chain select the name given to your imported certificate from the pull-down menu. If you did not import a CA bundle for the certificate and key, for most public signers select ca-bundle.crt.
  10. If you set a password on the imported certificate and key enter this in the Passphrase text box.
  11. Click Add.
  12. Leave all other configuration setting at their defaults unless you require specific settings.
  13. Click Finished.

 

How to update aspects of an existing ClientSSL profile

  1. Logon on the BIG-IP Configuration utility.
  2. Go to Local Traffic > Profiles > SSL > Client.
  3. Click on the name of the SSL profile that you want to edit.
  4. In Certificate Key Chain click the configured certificate, key and ca-bundle to highlight the configuration.
  5. Click Edit.
  6. For Certificate to replace the existing certificate select the name given to your newly imported certificate from the pull-down menu.
  7. For Key to replace the existing key select the name given to your newly imported key from the pull-down menu.
    Note: This is only required when the certificate is not based on the original key.
  8. For Chain to replace the existing CA bundle select the name given to your newly imported CA certificate bundle from the pull-down menu.
    Note: This is only required if the CA bundle has changed.
  9. If you set a password on the imported certificate and key enter this in the Passphrase text box.
  10. Click OK.
  11. Click Update.

Important: When updating a ClientSSL profile configured for an active virtual server the modifications will become immediate on the traffic being processed. If you do not want an immediate impact F5 recommends that you create a new ClientSSL profile with the desired configuration and modify the virtual server to use the new ClientSSL profile during a maintenance window.
 

How to update an existing CA bundle

  1. Log in to the Configuration utility.
  2. Go to System > Certificate Management > Traffic Certificate Management > Bundle Manager List.
  3. Click the Name of the CA bundle you wish to update.
  4. To update the CA bundle locate Include Bundles and select ca-bundle from the Available list.
  5. Click the << button to add (or the >> button to remove) the CA bundle to the Selected list.
  6. Select the checkbox for Update Now.
  7. Click Update.

Important: When updating the CA bundle configured as part of a ClientSSL profile for an active virtual server the modifications will become immediate on the traffic being processed. If you do not want an immediate impact F5 recommends that you create a new CA bundle with the desired configuration and modify the virtual server ClientSSL profile to use the new CA bundle during a maintenance window.
