Description
You may observe the below error in var/log/ltm:

err tpm-status[<PID>]: Unable to verify SIRR databases' integrity.
err tpm-status[<PID>]: System Integrity Status: Invalid

Environment

  • BIG-IP i10000 Series
  • TPM

Cause

Unknown at time of publication

Recommended Actions

You can investigate the issue by following K93302141 first, check below for a detailed list of commands:

  • tpm-status -a /var/log/pcr -v2
  • tmsh run sys integrity status-check
  • tmsh show /sys hardware | grep -i bios
  • tpm2_listpcrs -L 0xb:0,1,2
  • systemctl -l status f5-tboot

Collect the above command output from the affected systems and provide this information to F5 support, F5 support would help you to check the issue further. You may open a case with F5 by referring to: K2633: Instructions for submitting a support case to F5
