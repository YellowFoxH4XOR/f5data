Description

What is SNMP OID for Power Supply status to poll(for example, using snmpwalk/snmpget)?
Is there any way to get similar information to the information below?

# show components component psu-stats
       PSU      PSU      PSU      PSU      PSU          PSU          PSU          PSU
       CURRENT  CURRENT  VOLTAGE  VOLTAGE  TEMPERATURE  TEMPERATURE  TEMPERATURE  FAN 1
NAME   IN       OUT      IN       OUT      1            2            3            SPEED
-----------------------------------------------------------------------------------------
psu-1  1.187    20.625   206.5    12.046   39.0         41.0         44.0         12288
psu-2  1.234    21.0     205.5    12.031   38.0         41.0         43.0         12512

Cause

None

Recommended Actions

Since F5OS-A 1.8.0, the PSU snmpget/snmpwalk is possible by using the OID .1.3.6.1.4.1.12276.1.2.1.9.1(Mib human-readable string is F5-PLATFORM-STATS-MIB::platformPsuStatsTable). Below is an example output sent to one lab r2k device running 1.8.0.

snmpget -M ALL:/path/to/mibs_from_f5os_folder -m ALL -v2c -c <COMMUNITY_STRING> <IP MASKED OUT> F5-PLATFORM-STATS-MIB::platformPsuStatsTable

Note: the F5OS platforms does not have snmpget or snmpwalk command, you may need to execute this command on a third-party Linux System.

Example output of the above command:

F5-PLATFORM-STATS-MIB::psuName."platform"."psu-1" = STRING: psu-1
F5-PLATFORM-STATS-MIB::psuSerialNo."platform"."psu-1" = STRING: <SN MASKED OUT>
F5-PLATFORM-STATS-MIB::psuPartNo."platform"."psu-1" = STRING: PWR-0334-07
F5-PLATFORM-STATS-MIB::psuCurrentIn."platform"."psu-1" = INTEGER: .240 mA
F5-PLATFORM-STATS-MIB::psuCurrentOut."platform"."psu-1" = INTEGER: 3.800 mA
F5-PLATFORM-STATS-MIB::psuVoltageIn."platform"."psu-1" = INTEGER: 228.800 mV
F5-PLATFORM-STATS-MIB::psuVoltageOut."platform"."psu-1" = INTEGER: 12.060 mV
F5-PLATFORM-STATS-MIB::psuTemperature1."platform"."psu-1" = INTEGER: 27.0 °C
F5-PLATFORM-STATS-MIB::psuTemperature2."platform"."psu-1" = INTEGER: 21.0 °C
F5-PLATFORM-STATS-MIB::psuTemperature3."platform"."psu-1" = INTEGER: 29.0 °C
F5-PLATFORM-STATS-MIB::psuFan1Speed."platform"."psu-1" = INTEGER: 6000 RPM
F5-PLATFORM-STATS-MIB::psuPowerIn."platform"."psu-1" = INTEGER: 54.180 mW
F5-PLATFORM-STATS-MIB::psuPowerOut."platform"."psu-1" = INTEGER: 46.620 mW

 

In addition, you can also set up SNMPTrap psu-fault alert with the OID .1.3.6.1.4.1.12276.1.1.1.66305

Regarding more information on using SNMP and setting up SNMPTrap on F5OS-A, you may further read rSeries F5OS-A SNMP Monitoring and Alerting on F5 CloudDocs.

Additional Information

An RFI/RFE was recorded and tracked by ID 1239385 to enable the possibility of using snmpwalk/snmpget to query the F5OS PSU state, it is available since version 1.8.0.
