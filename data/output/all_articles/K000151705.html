Description

Information on how to review and license or reactivate a license for F5OS rSeries

Environment

  • F5OS rSeries
  • Licensing

Cause

Needing to check or relicense the device

Recommended Actions

Note: The steps for the initial licensing via the GUI are the same as the reactivating of the license, the only difference is the button changes from Activate to Reactivate.

To watch a video demo of these procedures using the F5OS-A webUI and Configuration utility, go to Activate or reactivate an F5 rSeries license using the F5OS webUI .

Log in and reactivate the license from the webUI with automatic method.

  1. Log into the webUI using the admin account
  2. Go to System Setting -> Licensing
  3. To reactivate the license, select Reactivate.
  4. Enter the base registration key and any add-on keys.
  5. Confirm Activation Method drop down is set to Automatic
  6. Select Reactivate.

Log in and reactive the license from the webUI with Manual method.

  1. Log into the webUI using the admin account
  2. Go to System Setting -> Licensing
  3. To reactivate the license select Reactivate.
  4. Enter the base registration key and any add-on keys
  5. For Confirm Activation Method, select Manual
  6. Select Get Dossier.
  7. Copy the dossier and connect to the F5 Product Licensing page at secure.f5.com.
  8. On the F5 Licensing Tools page, select Activate F5 product registration key.
  9. Paste the dossier into Enter Your Dossier and then select Next.

    The F5 Product Licensing page produces your license.

  10. Copy the license and paste it into License Text in the webUI.
  11. Select Reactivate

Log in and view the license from command line interface (CLI).

  1. Connect using SSH to the management IP address.
  2. Log in to the command line interface (CLI) of the system using an account with admin access.
    When you log in to the system, you are in user (operational) mode. 
  3. Enter show system licensing.

Log in and activate the license from command line interface (CLI).

  1. Connect using SSH to the management IP address.
  2. Log in to the command line interface (CLI) of the system controller using an account with admin access.
    When you log in to the system, you are in user (operational) mode. 
  3. Change to config mode
    config
  4. Apply the license to the device
    system licensing install registration-key <key> 

    The registration key is optional. If it is not included, the system uses the one that is already pre-installed. If no registration key is found, you receive an error.
    This example applies a specified base registration license to the system: 

     
    syscon-1-active(config)# system licensing install registration-key 
 I1234-12345-12345-12345-1234567
result License installed successfully.
  5. Apply any add-on keys.
    system licensing install add-on-keys <add-on-keys> 

    This example enables the additional features associated with the three specified add-on-keys, along with the entitlements of the base registration key:

    syscon-1-active(config)# system licensing install 
add-on-keys [1234567-1234567 2345678-2345678 3456789-3456789]
result License installed successfully.

    The system is licensed. The license and any add-on keys apply to the system and all installed BIG-IP tenants.  

Additional Information

If you want to verify the license the F5OS-A platform passed to your tenant, you may use the below command, this could be helpful for tenant-license-related troubleshooting:

kubectl get secret <tenant-name>-1-secrets -o json | jq '.data.LICENSE' -r | base64 -d

For example, if you have a tenant named test-tenant: 

kubectl get secret test-tenant-1-secrets -o json | jq '.data.LICENSE' -r | base64 -d
