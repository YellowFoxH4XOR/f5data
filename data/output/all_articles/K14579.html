Known Issue

When the BIG-IP system management interface is connected to a remote switch port with fixed media settings, the BIG-IP management interface may change to half duplex.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is an 800, 1600, 3600, 3900, 6900, 8900, 11000 or 11050 series platform.
  • Your BIG-IP system management interface is configured with fixed media settings for speed and duplex.
  • The remote switch port is configured with a fixed media setting for speed and duplex, and auto negotiation is disabled.

Impact

Users are unable to access the BIG-IP system through the management interface.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H426587 on the Diagnostics > Identified > Medium page.
  • If you access your BIG-IP system through the management interface, your connection fails.
  • If you access your BIG-IP system through the serial console, the management interface is set to half duplex.

    For example, to display the BIG-IP system management interface setting, type the following command:

    tmsh list /net interface mgmt media-active

    You may see output that appears similar to the following example, showing that the interface is set to half duplex:

    net interface mgmt {
    media-active 100TX-HD
    }

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you must modify the affected interface to first use auto-negotiation, and then reboot the system. After the reboot, you can change the interface to use your preferred fixed setting. To do so, perform the following procedure.

Modifying the BIG-IP system management port

Impact of workaround: You must reboot the BIG-IP system, so F5 recommends that you perform this procedure during a maintenance window. F5 recommends that you perform this procedure using serial console access to the BIG-IP system, as making changes to the management interface setting may cause you to lose connectivity. Make sure that you change the port setting to auto-negotiation on the affected remote switch port before proceeding with the following procedure to modify the BIG-IP system management port.

  1. Connect the serial console to the CONSOLE port of the BIG-IP system.
  2. To display the SCCP or AOM Command Menu, type the following key sequence:

    Esc (

  3. Press 1 to select 'Connect to the Host subsystem console'.
  4. Log in to the command line of the BIG-IP system.
  5. To set the management interface to use auto-negotiation, type the following command:

    tmsh modify /net interface mgmt media auto

  6. Save the changes by typing the following command:

    tmsh save /sys config

  7. Reboot the BIG-IP system by typing the following command:

    reboot

  8. When the BIG-IP system is back to an active state, change the media setting from auto to the desired fixed setting, using the following command syntax:

    tmsh modify /net interface mgmt media <Desired-Fixed-Media-Setting>

    For example, to fix the media setting to 100TX-FD, type the following command:

    tmsh modify /net interface mgmt media 100TX-FD

  9. Save the changes by typing the following command:

    tmsh save /sys config

  10. You may now verify the connectivity to the BIG-IP system management interface.
