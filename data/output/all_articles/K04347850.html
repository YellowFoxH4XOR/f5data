Known Issue

A newly configured BIG-IP server virtual server may remain in the down state.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP DNS system (formerly known as BIG-IP GTM) is configured with a BIG-IP server and Virtual Server Discovery is disabled.
  • You add a virtual server to the BIG-IP server configured with the following settings:
    • Address and/or Port Translation.
    • The virtual server name differs from the name used on the BIG-IP server device, or you do not specify a virtual server name.
  • You validate that the virtual server is available on the BIG-IP server device.

Impact

The BIG-IP DNS system marks the BIG-IP server virtual server as Unavailable (down).

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After adding the BIG-IP server virtual server to the BIG-IP DNS system, the system continually marks the virtual server as Unavailable (down), even though the virtual server status on the BIG-IP server is Available (up).
