Known Issue

The 'HTTP header exceeded maximum allowed size' error message may list the wrong profile name. Instead of logging the profile name associated with the virtual server, the BIG-IP system logs the profile name as http.

This issue occurs when all of the following conditions are met:

  • You apply a custom HTTP profile to a virtual server.
  • The combined header length in bytes in a client request exceeds the HTTP header size limit defined in the HTTP profile.

Note: For more information about the 'HTTP header exceeded maximum allowed size' error message, refer to K8482: Error Message: HTTP header exceeded maximum allowed size of <value>.

Impact

The BIG-IP system displays the wrong profile name in the log message. You can safely ignore this issue.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/ltm file, you observe a message similar to the following example:

    tmm1[5133]: 011f0005:3: HTTP header (<http_header_size> ) exceeded maximum allowed size of <http_header_size> (Client side: vip=http_192.168.1.1 profile=http pool=apache2)
