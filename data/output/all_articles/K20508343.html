Description

How to remove a server from the GSLB Server List in BIG-IP DNS

Environment

  • BIG-IP
  • DNS module configured
  • GSLB server configured under GSLB > Servers > Server List. For example a BIG-IP LTM system in your environment.

Cause

None

Recommended Actions

Note: Prior to removing a server from the GSLB Server List, you must manually remove the server object from prober pools if it belongs to any. Select Manage from the Members tab of the prober pool to complete the previous action. The BIG-IP system should automatically remove the virtual servers associated with the GSLB server from GSLB pools.

Using BIG-IP Configuration utility

  1. In the BIG-IP GUI, click on DNS > GSLB > Servers > Server List
  2. Click on the checkbox next to the server being removed.
  3. Click the Delete button.
  4. Click the Delete button on the confirmation page.
  5. If the BIG-IP DNS is in a sync group, verify the change synchronized to the other members.

Using tmsh utility

  1. Login to the tmsh utility by typing the following command:
    tmsh
  2. Remove the GSLB server from BIG-IP DNS by entering the following command syntax:

    delete gtm server <GSLB server name>

    For example,

    delete gtm server myserver.example.com

  3. Type q to exit the tmsh utility
  4. If the BIG-IP DNS is in a sync group, verify the change synchronized to the other members.
