Topic

Beginning with ARX version 5.0.0, Microsoft Windows 2008 Server has been qualified as a supported CIFS filer.

Beginning with ARX version 5.0.1, Microsoft Windows 2008 Server has been qualified as a supported Domain Controller.

Microsoft Windows 2008 Server has not been qualified by previous ARX versions as a supported CIFS filer or Domain Controller.

Microsoft Windows 2008 Server has not been qualified as a supported NFS filer in any ARX version.

Note: For information about products qualified for use with the ARX system, refer to K10909: F5 Data Solutions Compatibility Matrix.
