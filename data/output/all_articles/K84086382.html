Error Message

01071038:5: Unable to load master key from database. Empty master key attribute.

For example:

01071038:5: Unable to load master key from database. Empty master key attribute.
01071038:5: Secondaries couldn't load master key from the database.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • Your BIG-IP system configuration is reloading.
  • Your BIG-IP system's master key is either corrupt or is missing.

The Secure Vault feature provides security through the use of two cryptographic keys: the unit key and the master key. The unit key is securely stored in the BIG-IP system's (S)EEPROM hardware and is used to encrypt and decrypt the master key. The master key is stored on the BIG-IP file system and is used by the Master Control Program Daemon (MCPD) to encrypt and decrypt passphrases and passwords when loading BIG-IP system configuration files.

Impact

The BIG-IP configuration fails to load and traffic processing is impacted.

Recommended Actions

For information about the BIG-IP secure vault feature, including instructions on regenerating a new master key for your BIG-IP system, refer to the following article: K73034260: Overview of the BIG-IP system Secure Vault feature.
