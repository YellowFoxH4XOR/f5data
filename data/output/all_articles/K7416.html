Known Issue

This is the result of a known issue. When you use a FirePass Portal Access Web Application Favorite to view a web page using Internet Explorer 6 (IE6), you may receive a pop-up message similar to the following example:

A script on this page is causing Internet Explorer to run slowly. If it continues to run, your computer may become unresponsive. Do you want to abort the script?

Clicking on either the Yes or No buttons in the pop-up message will usually allow you to continue browsing your web application normally.

The warning occurs due to interaction between IE6's script time-out feature and the FirePass controller's cookie obfuscation feature. When the Obfuscate cleartext cookies check box is selected on the Global Settings tab of the Portal Access: Web Applications: Content Processing page, the FirePass controller will encrypt the content of cookies sent to the browser. The encrypted cookie will be handled with client-side Javascript, which is downloaded to the browser when a Portal Access Web Application Favorite is used. If a cookie contains a field with a large number of characters, the cookie-handling Javascript will consume enough time and resources to trigger the script time-out feature of IE6, and will produce the pop-up message.

F5 Networks Product Development tracked this issue as CR77855 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative hotfix HF-601-3 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can eliminate the pop-up message by turning off the cookie obfuscation feature, which is located on the Global Settings tab of the Portal Access: Web Applications: Content Processing page.
