Description
For example, an upgrade from 12.1.2 HF2 --> 13.1.1.4, error loading config post upgrade.  The configuration fails to load after upgrade to 13.x or above, due to AVR widgets for deleted partitions.  This results in an error:
01070734:3: Configuration error: Can’t associate classification overview selection (/ANOTHER_PARTITION/ABCXYZ) folder does not exist Unexpected Error: Loading configuration process failed.
 

Environment

  • Running a version prior to 13.x
    • Attempt to upgrade to 13.x or above
  • Create at least one additional administrative partition
  • Create an AVR widgets for object(s) in the new partition
  • Deleted the partition

Cause
In versions before 13.0, all AVR widget configuration data was stored in /config/bigip.conf, and when a partition was deleted, the AVR widgets for that partition still existed in the /config/bigip.conf file.  In version 13.0, more in-depth configuration verification was performed, which leads to the configuration not loading after an attempted upgrade to 13.0 or above.  AVR widget information is now stored in /config/<partition name>/bigip.conf.
 

Recommended Actions

Remove the AVR Widget using your editor of choice, edit the /config/bigip.conf file and remove all AVR widget entries that reference the deleted partition.
The number of entries will depend on the number of AVR widgets created prior to the partition deletion.
Note: Manually editing the configuration file is not supported by F5 Support.  However, this technique has been known to resolve this symptom before.

  1. From the command line backup the /config/bigip.conf file:

    # cp /config/bigip.conf /config/bigip.conf_avrfix


    Example of an AVR widget that references a partition named ANOTHER_PARTITION

    analytics gui-widget /ANOTHER_PARTITION/uwid5c90031d5a7ab {
        cent-report-destination-type self
        gui-pagecode avr
        metrics { avg_tps }
        module avr
        period 86400
        username admin
        view-by vip
        widget-type 3
    }
     
  2. Once the AVR widget(s) are removed from the /config/bigip.conf file, verify that the edited configuration will load successfully:

    # tmsh load sys config partitions all verify
     
  3. Assuming no errors (warnings are OK) are reported from step 2, load the edited configuration:

    # tmsh load sys config partitions all
     
  4. Restart the mcpd process. 

    # tmsh restart sys service mcpd
