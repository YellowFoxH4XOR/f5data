K000147493: How to block by IP or Geolocation

Description

  •  I need to block access for specific IP or Geolocation, what are the steps I need to follow?

Environment

  • F5® Distributed Cloud Console

Cause

You need to block traffic towards the LB using IP or Geolocation information.

Recommended Actions

To block by IP or Geolocation:

  1. For IP or Geolocation based blocking, navigate to Manage -> Service Policies
  2. Click Service Policies
  3. Click Add Service Policy at the top

4. Once you click the Add Service Policy option, form to create new service policy will appear.

5. Add Name for the service policy and select Any Server option for Server Selection

 

6. Scroll down to Rules section and select Denied Sources option for Select Policies Rules

7. Click on Configure for IPv4 Prefix List, form for IPv4 Prefix List will be appeared.

8. Add the IP you would like to block and click Apply

 

9. You will be taken back to the main form, scroll down and click Save and Exit

10. The Service Policy is now created

11. Navigate to your HTTP Load Balancer for which you would like to block IP and click on Manage Configuration

12. Click Edit Configuration

12. Scroll down to Security Configuration section

13. Select Apply Specified Service Policies under the Service Policies

14. Click Configure under Apply Specified Service Policies option

15. Form will appear where you can select from the existing service policy. Select the service policy created for IP block and click Apply Button

16. Scroll down and click Save and Exit

Now your load balancer will block the request for the IP specified in Service Policy

 

To block the specific Geolocation, just select the Country you would like to block under the Country List section instead of IPv4 Prefix List
