K85753565: No ''Full configuration has been loaded successfully'' message logged after restoring UCS

Description

In versions prior to 12.1.0, the message "Full configuration has been loaded successfully" appeared when loading UCS file by tmsh load sys ucs command.

Example;
# tmsh load sys ucs test.ucs
Saving active configuration...
Current configuration backed up to /var/local/ucs/cs_backup.ucs.
   ---snip---
Reloading License and configuration - this may take a few minutes...
Full configuration has been loaded successfully.      <-----!!!
/var/local/ucs/test.ucs is loaded.


However beginning in 12.1.0, the message "Full configuration has been loaded successfully" does no longer appear when loading UCS file by tmsh load sys ucs command.

Example;
# tmsh load sys ucs test.ucs
Replace all configuration on the system? (y/n) y
Saving active configuration...
   ---snip---
Reloading License and configuration - this may take a few minutes...
/var/local/ucs/test.ucs is loaded.
 

Environment

  • BIG-IP
  • Loading/Restoring UCS

Cause

None. It is behavior change.

Recommended Actions

None.

Additional Information

None.
