Known Issue

The BIG-IP PSM system may incorrectly perform response checks after a software upgrade to 11.3.0 or later. This issue occurs when the following condition is met:

  • Prior to the software upgrade, the Response Checks feature was configured on the BIG-IP PSM system to perform response checking.

Starting in 11.3.0, the Response Checks feature was removed from BIG-IP PSM and the relevant settings on the HTTP Security Profile Properties page were removed from the Configuration utility.

Impact

The BIG-IP PSM system incorrectly performs response checks, and there are no means to disable or configure the Response Checks feature.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After the software upgrade, the BIG-IP PSM system continues to send a blocking page to clients if it was configured to do so previously.
