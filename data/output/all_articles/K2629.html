Known Issue

BIG-IP does not save the absence of a monitor, only the presence or assignment of a monitor.

The default ICMP monitor is associated with all nodes as follows:

* monitor use icmp

You cannot disassociate a single node, or group of nodes, from the default ICMP monitor.

If you delete the monitor from the individual node, using the b node 192.168.33.205 monitor delete command, the new status of the node is not saved to the bigip.conf file; therefore, the next time you reload the bigip.conf file, the monitor will be reassociated with that node.

F5 Networks Product Development tracked this issue as CR15512, CR20414, and CR41947.
