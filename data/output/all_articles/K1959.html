K1959: Accessing FirePass by IP address rather than host name

Topic

When you initially configure FirePass web services, you are prompted to enter a name for the FirePass controller (in most cases, you should enter FirePass's fully qualified host name). When clients connect to FirePass and accept the SSL certificate, FirePass sends an HTML page that references the host name that you entered when you configured the web service. If you have not yet configured the host name for FirePass in DNS, the client cannot resolve the host name and the connection fails. (The same occurs with administrative access to FirePass.)

If you want to use a FirePass host name that you have not configured in DNS, you can work around this issue by using one of the following two options:

  • Use the IP address, instead of a name, when you configure the FirePass web services; this allows you to connect to the web services by IP address.
  • Enter the FirePass host name and IP address in the hosts file of each client computer; this allows you to connect to the web service without resolving the host name by DNS.
