Description

No sample requests shown for learning suggestions on the Traffic Learning page at Security > Application Security > Policy Building > Traffic Learning.

No samples found in requests list
 

Environment

  • Traffic Learning
  • Security Policy

Cause

Rate of local request logging is high, causing request samples to be rotated out quickly.

To confirm this is the issue, find the oldest entry in the event logs. If it is newer than the most recent request triggering the learning suggestion, then the relevant samples have already been rotated out.

In the screenshot example above, the suggestion's most recent request is 2021-02-09 12:18:43. The oldest event logs (not shown) are newer than this, so the samples are no longer available.

Local request storage is finite, and limited to 3 million rows in the MySQL PRX database, or 5GB request log data on disk (2GB for virtual editions). When either of these limits are hit, older logs are rotated out.

If log rotation happens a lot, you will observe frequent messages in /var/log/ts/asmlogd.log, similar to the following:

F5::RequestLog::delete_unused_protobuf_files,,Dropping protobuf file /var/asmdata1/request_log/0000001139
F5::RequestLog::delete_unused_protobuf_files,,Dropping partition p4700001

Recommended Actions

Reduce the rate of local logging if possible. Avoid logging all requests locally, and investigate if there is one particular application logging more than others - you may be able to modify the Alarm flags of the policy to avoid excessive logs.

Additional Information

There is a way to increase the local request log limits, but it is not recommended as it may result in performance issues.

Another common cause of this issue is bug ID 846181, described in K47074102. However, that bug is only applicable when there is a single request triggering the suggestion.
