Description

Log in to CLI as root works. When you try to go to Confd mode with the below command, you get error

su admin

Environment

  •  F5OS-A
  • Upgrade 
  • No access to Confd/GUI

 

Cause

  • many reasons, in this solution tells to how to recover from the status

 

Recommended Actions

1. Check what iso is available

echo 'list appliance_os' | nc -U /var/sw-mgmt.unix
echo 'list appliance_serv' | nc -U /var/sw-mgmt.unix

and confirm the <upgrded_version> in BOOT-MARKER log is exist 

    • example:
      1.8.0-16036
      1.8.0-17564 (this is EngHF available in F5 download site)

2. To boot from <upgrded_version>, run the following commands

echo 'switch appliance_os <upgrded_version>' | nc -U /var/sw-mgmt.unix
echo 'switch appliance_serv <upgrded_version> no_restart' | nc -U /var/sw-mgmt.unix
reboot

    • example

echo 'switch appliance_os 1.8.0-17564' | nc -U /var/sw-mgmt.unix
echo 'switch appliance_serv 1.8.0-17564 no_restart' | nc -U /var/sw-mgmt.unix
reboot


This should start from the version you wished properly. Below is the example of 1.8.0-16036
