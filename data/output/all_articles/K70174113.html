Known Issue

If you edit an iRule, the sod watchdog process may cause the Traffic Management Microkernel (TMM) process to no longer respond.

This issue occurs when all of the following conditions are met:

  • You have an iRule that numerous virtual servers use.
  • You edit an active iRule and save the changes.

Impact

Traffic that the affected TMM instance processes is interrupted while TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If configured, the BIG-IP system fails over to another device in the device group.
  • In the /var/log/ltm log file, you may observe error messages similar to the following example:

    crit tmm1[12053]: 01010020:2: MCP Connection aborted, exiting
    emerg logger: Re-starting tmm
    emerg logger: Re-starting tmm1
    emerg logger: Re-starting tmm2
    emerg logger: Re-starting tmm3
