Description

While creating a local user using configuration-utility, password is not prompted to set. The appliance is using remote authentication for all users' login.

Environment

  • BIG-IP LTM
  • Remote Authentication
  • Local user

Cause

By default, if you configure a remote authentication method, such as RADIUS or TACACS authentication for BIG-IP administrative users or for application traffic and the remote authentication server is unavailable to answer authentication requests, remote authenticated users cannot log in, even when their accounts are configured in the local authentication list. Only the default admin and root accounts can log in to the system

Recommended Actions

Enable the check box Fallback to Local.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
  1. Log in to the Configuration utility.
  2. Go to System > Users > Authentication.
  3. Select Change.
  4. Select the Fallback to Local check box
The system now prompts for a password when you create users locally.
