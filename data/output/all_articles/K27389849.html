K27389849: BIG-IP Edge Client hang when logout with SLO

Type
Support Solution
Published
2020-12-14
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K27389849

Description

On the windows client, when logout the BIG-IP Edge Client, the Edge window hang. Meanwhile, more symotoms like below:

  • In the log file /var/log/apm, see the log like below:

notice tmm2[<PID>]: 01490505:5: /Common/<Access policy>:Common:<Session ID>: PPP tunnel 0x56006028fd00 (ID: f0b5f2b9) closed.

notice tmm2[<PID>]: 01490502:5: /Common/<Access policy>:Common:<Session ID>: Session deleted due to user inactivity.

The session was deleted not due to the logout request, but due to the user inactivity, after PPP tunnel closed xx minutes later.

  • If the log level is debug, we can see the SLO debug log like below before the session deleted:

debug tmm1[<PID>]: 014d0501:7: /Common/<Access profile>:Common:<session id>:Client initiated SSO config received in metadata. Meta-data: SAML_SLO_SP_INIT=_<SLO string> <URL for the IDP> https://<hostname of SP> <URL for the SLO on the IDP> <URL for the SLO on the IDP>   /Common/<certificate file>   1 1

debug tmm1[<PID>]: 014d0501:7: /Common/<Access profile>:Common:<session id>:Signing algorithm type: (1)
debug tmm1[<PID>]: 014d0501:7: /Common/<Access profile>:Common:<session id>:SLO_ID: (39) _6f6dc6497aaeeee4b7bbc46ee4308d990d7b2f

Environment
  • BIG-IP APM
  • SAML Single Logout (SLO)
  • BIG-IP Edge Client on Windows

Cause

On the SP or IDP, the configurration for SLO request / response URL is wrong.

Recommended Actions

Refer to K70727133 / K67310544, configure the proper SLO request / response URL.

Additional Information

None.
