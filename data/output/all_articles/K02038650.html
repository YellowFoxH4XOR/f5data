Known Issue

The BIG-IP configuration fails to load after upgrading.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is licensed with BIG-IP DNS (formerly known as BIG-IP GTM).
  • You provision BIG-IP DNS and subsequently deprovision BIG-IP DNS.
  • After you deprovision BIG-IP DNS, you upgrade to later BIG-IP versions.

When you provision the BIG-IP DNS module, the BIG-IP system creates the bigip_gtm.conf configuration file. When you later deprovision BIG-IP DNS and upgrade to later versions, the remaining configuration file schema is not recognized by the later versions.

For example, your BIG-IP system runs 12.1.3.7 and the BIG-IP DNS module is provisioned. Next, you deprovision the BIG-IP DNS module and upgrade to 13.1.1.3. You then upgrade to 14.0.0.4, and the configuration fails to load because the 12.1.3.7 config schema is not recognized in 14.0.0.4.

Impact

The BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP Configuration fails to load after upgrade with an error message that appears similar to the following example:

    01420006:3: Can't find specified cli schema data for x.x.x.x

    Note: x.x.x.x denotes an earlier BIG-IP software version.

Workaround

You can work around this issue by recovering after you upgrade, or mitigating the issue before you upgrade. Perform one of the following two procedures:

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Recover after upgrading

  1. Log in to the BIG-IP command line.
  2. Rename the bigip_gtm.conf file by entering the following command:

    mv /config/bigip_gtm.conf /config/bigip_gtm.conf.837637

  3. Restart system services by entering the following command:

    tmsh restart /sys service all

Mitigate before upgrading

  1. Log in to the BIG-IP command line.
  2. Rename the bigip_gtm.conf by entering the following command:

    mv /config/bigip_gtm.conf /config/bigip_gtm.conf.837637

  3. Alternatively, if you no longer need the configuration, you can delete the file.
  4. Load the configuration by entering the following command:

    tmsh load sys config gtm-only
