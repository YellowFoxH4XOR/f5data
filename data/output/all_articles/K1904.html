K1904: Reasons why ECV and EAV SSL health monitors may not run properly when executed at the command line

Topic

The Secure Socket Layer (SSL) health monitor script does not inherit the RANDFILE variable from the main shell. As a result, the health monitor cannot generate the random numbers that are required in order to create an SSL session.

You can create external scripts that test SSL on the server using s_client, the OpenSSL test tool. This tool uses the shell variable RANDFILE to provide the random numbers required for SSL communication.

To resolve this issue, and properly set the variable for the external health monitor script, edit your external health check script and add the following line above the line that calls s_client:

export RANDFILE=/var/run/openssl_randfile
