K450: Preventing nodes from responding with redirects or links that contain HTTP references when the node is accessed through an SSL proxy

Topic

When you perform SSL termination on BIG-IP, BIG-IP sends plain-text HTTP requests to the nodes. Because the nodes do not receive HTTPS requests, they may respond with dynamically generated links that specify the HTTP protocol. When a client attempts to request an HTTP link from an SSL proxy, BIG-IP will reject the connection, because it is not encrypted.
