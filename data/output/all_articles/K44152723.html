K44152723: ASM Attack Signatures install faster on SSDs vs HDDs

Source

Description
ASM signature sets seem to install faster when run in v15.1 and v16.1 versus v13.1

Environment

  • ASM provisioned
  • ASM signature set upgrades

Cause

Signatures update are a heavy disk i/o operation. 
The disk spec will affect the amount of time it takes to be completed.
The heaviest part of this operation, database queries, depends on the disk.

Recommended Actions

For improvement during loading of Advanced WAF signature updates use the fastest, least latency, disks.

Additional Information

BIG-IP Next and NAP use the same signature update process as classic BIG-IP.
In Distributed Cloud WAF, ASU occur as an inherent upgrade of the newer version of the WAF product (no separate ASU).
