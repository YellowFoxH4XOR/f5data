Description

You are trying to create a virtual server of DHCP type, you have already set up a DHCP profile and the following error is being returned during the creation of the virtual server:

010718c4:3: DHCP virtual server can have at most one DHCP profile.

Environment

  • AVR is provisioned
  • Statistics profile is selected.

Cause

A Statistics profile cannot be used with a DHCP virtual server.

Recommended Actions

Remove the statistics profile from the respective virtual server configuration.

Additional Information

None
