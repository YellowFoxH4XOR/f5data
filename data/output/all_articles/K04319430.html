K04319430: Not able to access BIG-IP GUI (HTTP) when using BIG-IQ HA pair

Description

You are not able to access the BIG-IP GUI when the BIG-IP devices which are being managed by a BIG-IQ CM HA pair.

You have a scheduled BIG-IP UCS backups generation on the BIG-IQ.You are not able to access the BIG-IP at the same time as the UCS backup generation.

The BIG-IQ CM HA was recently was disconnected and both BIG-IQ are in Standalone state.

There is no issue accessing the BIG-IP device via SSH

Environment

  • BIG-IP managed by BIG-IQ is not accessible
  • BIG-IQ have a BIG-IP UCS backup generation scheduled
  • BIG-IP is not accessible at the time BIG-IQ is initiating the BIG-IP UCS backup
  • BIG-IQ CM HA has been disconnected and now they are in Standalone state
  • BIG-IP accessible via SSH.

Cause

Since the BIG-IQ HA has been disconnected and are now in Standalone state, both BIG-IQ are requesting to generate the UCS backup from the BIG-IP at the same time. This causes the BIG-IP to misbehave.

Recommended Actions

There are several ways to resolve the issue.

  1. Shutdown one of the BIG-IQ CM.
  2. Pairing the BIG-IQ systems for HA. Refer to K36398804.
  3. Remove the BIG-IP UCS backup schedule on one of the BIG-IQ device. Refer to Schedule BIG-IQ system's UCS file backups of Manual Chapter : BIG-IQ System File Management.
