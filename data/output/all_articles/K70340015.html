Known Issue

The BIG-IP system may ignore iControl calls to overwrite an existing Secure Sockets Layer (SSL) key or certificate.

This issue occurs when the following condition is met:

  • You attempt to overwrite an existing key or certificate on your BIG-IP system using one of the following iControl functions:
     
    • key_import_from_pem()
    • certificate_import_from_pem()
    • key_import_from_pem_v2()
    • certificate_import_from_pem_v2()

Impact

You are unable to overwrite the SSL certificate/key file objects using the specified iControl function.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H615855 on the Diagnostics > Identified > Medium screen.
  • The iControl functions fail to overwrite the SSL certificate/key objects.
  • The system logs error messages to the /var/log/daemon.log file that appear similar to the following example:

    err iControlPortal.cgi[9591]: Commit error 16908390 for file /config/ssl/ssl.key/<key_name>.key
    err iControlPortal.cgi[9591]: Commit error 16908390 for file /config/ssl/ssl.crt/<certificate_name>.crt

Workaround

To work around this issue, you can delete and import the certificate/key using the following iControl functions:

  • key_import_from_pem()
  • certificate_import_from_pem()
  • key_import_from_pem_v2()
  • certificate_import_from_pem_v2()
