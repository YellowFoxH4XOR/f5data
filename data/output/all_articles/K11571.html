Known Issue

When a user is connected to a Protected Workspace through Network Access, the Protected Workspace session keeps running even after the Network Access session has been terminated. Since the user is no longer restricted by the access control lists that can be configured in Network Access, they have the ability to send data from the Protected Workspace session to any resource that is connected to the internet.

F5 Product Development tracked this issue as CR136998 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
