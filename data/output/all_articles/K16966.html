Known Issue

Loading the BIG-IP AAM configuration may fail and cause the wocplugin process to restart and produce a core file.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured with AAM configuration objects (formerly referred to as WOM/WOC/WAM objects in 11.3.0 and earlier).
  • You perform a configuration load that attempts to modify the AAM configuration objects.

Note: This issue is result of race condition and is rarely encountered.

Impact

The configuration load fails and does not modify the configuration. Traffic processing may be temporarily disrupted while the wocplugin process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • An attempted configuration load may fail.
  • The wocplugin process may restart and produce a core file.
  • The BIG-IP AAM system may experience a temporary disruption to traffic processing.
