K000150872: SAML SSO authentication errors after upgrade to v17.5.0

Type
Support Solution
Published
2025-04-15
Updated
2025-06-05
Applies to

  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150872

Description

After upgrade from v15.1.10.4 to v17.5.0 and now SAML is not working, getting:

err tmm[2342]: 014d104d:3: /Common/apm_sso_DEBUG:Common:<strong>bace5d1a</strong>:SAML SSO: Authentication context match failed. IdP is not configured with SP requested authentication context

err tmm[2342]: 014d1092:3: /Common/apm_sso_DEBUG:Common:<strong>bace5d1a</strong>:SAML SSO: Error validating Authn Request Message. Status:urn:oasis:names:tc:SAML:2.0:status:NoAuthnContext


Environment

BIG-IP APM

SAML


Cause

Mismatch in the SP and IdP configuration, the IdP is using the unspecified authNContext. The SP is asking the IdP to use the PasswordProtectedTransport


Recommended Actions

Either you can set the SP to use unspecified or set the IdP to use PasswordProtectedTransport:


From unspecified

apm sso saml /Common/iDP-sso.com {

<<SNIPPET>>

auth-context-method urn:oasis:names:tc:SAML:2.0:ac:classes:unspecified

<<SNIPPET>>

to PasswordProtectedTransport

auth-context-method urn:oasis:names:tc:SAML:2.0:ac:classes:PasswordProtectedTransport
