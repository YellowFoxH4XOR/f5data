Known Issue

VMware View clients may stop responding when accessing remote desktop resources.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a VMware View remote desktop access profile that incorporates PC-over-IP (PCoIP).
  • A user initiates a connection request for a destination remote desktop using a VMware View client.
  • The user's authentication fails when authenticating to the VMware View Connection server.
  • The VMware View Connections server is running 5.3.

Impact

The VMware View client may stop responding.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to access the remote desktop resource, the VMware View client becomes unresponsive and requires a manual restart of the client.
  • After encountering the scenario and restarting the VMware View client, you may be able to access the intended remote desktop.
