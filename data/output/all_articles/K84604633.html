Description

After deploying an AS3 template on the BIG-IP where the request is invalid, an error will occur and the resulting error message is truncated.  The error message will be truncated if it is larger than 2048 characters.

Environment

  • iControl REST request
  • iControl REST response is greater than 2048 characters
  • AS3 Declaration
  • BIG-IP

Cause

ID853161: Restjavad has different behavior for error responses if the body is over 2k

Recommended Actions

There are a few things you can try to mitigate this issue:
  1. Use iControl REST asynchronous declarations
    OR
  2. Try to limit the size of the response body
 

Additional Information

AS3 API Reference

- Do not use ?show=full at the end of the URL to restrict the size of the response.
- If using ?show=full is necessary (or if this issue occurs with or without ?show=full), try the following workaround:
- POST the declaration to https://<BIG-IP mgmt IP>/mgmt/shared/appsvcs/declare?async=true?show=full
* this will POST the declaration asynchronously and keep the "full" option. If you are not using ?show=full, then just use ?async=true. The return response will be 202 Accepted and there will be a "selfLink" returned e.g. "selfLink": "https://localhost/mgmt/shared/appsvcs/task/<Task ID>"
- Issue a GET to the selfLink (changing localhost to the <BIG-IP mgmt IP>) e.g. GET https://<BIG-IP mgmt IP>/mgmt/shared/appsvcs/task/<Task ID>
- Check the output from the GET, and verify the Response section is not truncated.
