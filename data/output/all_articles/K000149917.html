Description

What is F5 Support for VMWare HW configuration change for BIG-IP VE?

Questions about impact to F5 support for the BIG-IP instance affected by this

Is there full support when they change the VMWare from 1 core per socket with 4 sockets to 4 cores per socket with 1 socket. 

For example, Changing the hardware processor cores from Cores per Socket 1 & 4 sockets vs 4 Cores per Socket 1 socket 

Environment

  • Changing VMWare HW Configuration for a BIG-IP VE instance
  • BIG-IP VE
  • VMware

Cause

Questions arising from changing the hardware configurations for a BIG-IP instance using VMWare.

Recommended Actions

You will have F5 Support access as long as you have a valid support contract for the VM installation.

You can verify those details here:  K32755669: How to verify support contract end date
