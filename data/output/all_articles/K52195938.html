Known Issue

In rare circumstances, the bigd process may produce a core file and restart.

This issue occurs when the following condition is met:

  • You use TCP Half Open monitors.

Impact

There is a temporary interruption to monitoring while bigd restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system logs a message to the /var/log/ltm log file that appears similar to the following example:

    notice sod[6504]: 01140029:5: HA daemon_heartbeat bigd fails action is restart.

  • You view a core file in the /shared/core directory with a timestamp that correlates with the bigd failure.
