Description

Access  ››  Authentication : Local User DB : Users
Adding a local user does not sync to the peer unit in Sync-Failover Group

Environment

  • BIG-IP APM
  • Access ›› Authentication : Local User DB : Users shows: Last HA Sync Time : not available

Cause

ID942965
ID932213

Recommended Actions

Restart the localdbmgr process on all BIG-IP's in the sync group and restore the local user database:
  1. Export local user database to CSV file from Active unit:
    Access  ››  Authentication : Local User DB : Users -> Export to CSV button
  2. Restart localdbmgr process on all BIG-IP's (Active unit last)
    bigstart restart localdbmgr
  3. Import CSV file from step 1 to restore local user database on Active unit
The local user database should sync to the peer units within 5 mins.
