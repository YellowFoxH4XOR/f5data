Known Issue

Attempts to send a new message, create a new contact, or create a new task in OWA2003 will fail

This issue occurs when the following condition is met:

  • FirePass portal access is configured to access an OWA2003 server.

Impact

Users are unable to send a new email message, create a new contact, or create a new task.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you click Send, you receive the following message:

    Are you sure you want to navigate away from this page?
