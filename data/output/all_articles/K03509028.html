Topic

After upgrading to an affected Windows 10 version, the Windows Credential Manager may stop caching BIG-IP Edge Client credentials and fail to reuse Windows logon credentials.

Description

After upgrading to Version 1903, Version 1709, Version 1703, or Version 1607, you may encounter the following symptoms:

  • BIG-IP Edge Client fails to reuse Windows logon credentials.
  • Credential Manager no longer caches the password for BIG-IP Edge Client.
  • The following registry keys are missing from the Windows registry:
    • HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\f5netprov
    • HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\f5netprov\NetworkProvider

This issue is caused by a Microsoft known issue. For more information, refer to Network provider settings are removed during an in-place upgrade to Windows 10.

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

Recommended Actions

To recover from this issue, F5 recommends uninstalling and re-installing BIG-IP Edge Client.

Alternatively, you can repair the Windows registry and re-add the required registry keys by re-installing the f5netprov64.dll file. To do so perform the following procedure:

Note: You must have Windows administrative permissions to modify the registry.

Impact of procedure: This workaround involves modifying the Windows Registry. Microsoft provides the following warning: Warning: Serious problems might occur if you modify the registry incorrectly by using Registry Editor or by using another method. These problems might require that you reinstall the operating system. Microsoft cannot guarantee that these problems can be solved. Modify the registry at your own risk.

  1. On the affected client system, open a Windows command prompt as an administrator.
  2. Navigate to \windows\syswow64 by typing the following command:

    cd \windows\syswow64

  3. Type the following command:

    regsvr32 f5netprov64.dll

  4. Log off of the active profile.
  5. Log on to the Windows client.
