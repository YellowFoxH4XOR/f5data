Description

Network interfaces down after upgrading F5OS-A from v1.7 to v1.8

Environment

Cause

Recommended Actions

- If network interfaces are down after upgrading to F5OS-A:

  1. Avoid cycling the 10G and 25G interfaces on the rSeries system until you have upgraded to a fixed F5OS-A version.

- If experiencing problems with 10G and 25G rSeries interfaces connecting to Nexus switches, reboot the rSeries system to recover the state.

  1. If interfaces are still down after the reboot, disable and re-enable the interfaces one at a time.
  2. Disable the interface on the rSeries system (not the Nexus switch), wait 30-40 seconds, then re-enable the interface.
  3. Repeat this process if needed until the interface connects again.
  4. If the issue persists, create a case with F5 Support.

- To disable and re-enable an interface on the rSeries system:

  1. Log in to the webUI of the rSeries system.
  2. Go to NETWORK SETTINGS > Interfaces.
  3. Select the 10G or 25G interface.
  4. For State, select Disabled, then Save & Close to disable the interface.
  5. To re-enable the interface, select it again, choose Enabled for State, and Save & Close to re-enable it.
