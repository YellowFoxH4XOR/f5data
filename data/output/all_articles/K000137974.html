K000137974: APM Logon Page Still Showing "Secure Logon for F5 Networks" Even If The Form Header Text Is Empty

Type
Support Solution
Published
2024-01-16
Updated
2024-01-16
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000137974

Description

  • You created a custom APM logon page and left the Form Header Text blank. After clicking the "Logon" button, the page briefly re-renders and shows "Secure Logon for F5 Networks"

Environment

  • APM Access Policy using a Custom Logon Page

Cause

  • This is caused by the blank Form Header Text

Recommended Actions

  • As a workaround, instead of leaving the Form Header Text blank, add a space (click the box and press the spacebar), save and apply the changes to the Access Policy.
