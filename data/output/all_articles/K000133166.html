K000133166: Only seeing 2 pods after installing Aspen Mesh 1.14.x

Published

Applies to

Source

Description

After installing Aspen Mesh 1.14.x only two pods are listed in the istio-system namespace.


Environment

Aspen Mesh 1.14.x
 

Cause

Starting with release 1.14.x, add-ons such Aspen Mesh alertmanager, Aspen Mesh dashboard, Aspen Mesh controlplane, event storage and metrics collector have been deprecated and will be removed in future releases.
 

Recommended Actions

You can install these add-ons, if you rely on these features and they’re still present in Aspen Mesh 1.14.5-am1 or later release archive file, after installing or upgrading Aspen Mesh.
For more information on how to install them please check the following link.
 

Additional Information

In releases 1.11.x and earlier, after a clean installation, add-ons such as AM alertmanager, AM dashboard, AM controlplane, event storage and metrics collector were installed automatically in the istio-system namespace.
