Description

If an iSeries platform is power-cycled while erasing a hard disk from the BIOS using the F5 Disk Erase utility, the drive will become locked.

Any interruption of the F5 Disk Erase Utility while it is running an erasure may result in this locked drive condition.

The BIOS will prompt for a hard drive password on subsequent boot-ups. An example below,
  
+----------P0:WDC WD1005XXX-123YYY-------------+
|                                                |
|                                                |
|      Enter User password:                      |
|                                                |
|                                                |
|                                                |
+------------------------------------------------+

Environment
  •  BIG-IP iSeries platforms.
Cause

This is expected behaviour if the security state is frozen pending power cycling the drive after a failed disk wipe.

Recommended Actions

To recover from the locked drive condition:
  1. Enter the password 'F5' at the BIOS prompt, or press Escape to escape from the password prompt.
  2. Re-run the F5 Disk Erase utility erasure process by pressing 'e' during BIOS boot up.
  3. Follow the appropriate prompts.
    Note: Be sure to let the Disk Erase process complete fully.
