Description

  • How to change the default 200 OK http response code from the ASM blocking page to 503

Environment

  • ASM response page

Cause

None

Recommended Actions

To change the default ASM response page you can perform the following:

  1. On GUI go to Security  >  Application Security > Policy > Response Pages

  2. Select the ASM security policy in question

  3. Click on Default

  4. On Response Type drop-down menu select Custom response

  5. Change to Response Headers to meet your requirement. For example:

    HTTP/1.1 503 OK
    Cache-Control: no-cache
    Pragma: no-cache
    Connection: close

  6. Click Save

  7. Click Apply Policy
