K000161360: Standby BIGIQ stuck in - Waiting for BIG-IQ services to become available after modifying sshd Ciphers on CM

Source

Description

The Standby BIG-IQ Central Manager (CM) was persistently stuck in a "Waiting for BIG-IQ services to become available..." state, After performing an HA reset, the BIG-IQ GUI returned a "400 Bad Request - /dev/stdin is not a public key file" error when attempting to rebuild the HA pair.

 

Environment

  • BIG-IQ HA
  • Standby GUI not starting
  • SSHD confguration changed

Cause

HA rebuild failure (secondary issue): After the HA reset resolved the GUI availability, BIG-IQ's hardcoded use of ssh-rsa for internal CM-to-CM SSH communication caused a "400 Bad Request - /dev/stdin is not a public key file" error when attempting to re-establish the HA pair. This is a known limitation with no current workaround or planned fix, tracked under Bug ID1623073.


Due to the fact that it ssh-rsa was removed cluster lost communication and Secondary device stopped being operational


Answer/Recommended Actions

  1. Perform HA reset on both BIg-IQ Devices ha-reset -f according to K53514505: How to Reset Secondary BIG-IQ Central
  2. Management Modify sshd configuration to enable ssh-rsa K000140637: Adding secondary BIG-IQ HA returns "400 Bad Request. /dev/stdin is not a public key file"
