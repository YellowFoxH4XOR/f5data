Issue

Error Message

chmand[<PID>]: 012a0049:5: Chassis power module 4 turned on

In this error message, note the following:

  • <PID> is the process ID for the chmand process.

For example:

chmand[8599]: 012a0049:5: Chassis power module 4 turned on

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file.

Description

This message occurs when the following condition is met:

  • The chassis power module 4 is turned on.

Impact

There is no impact. However, there may be an impact depending on the frequency of the error message, and whether the log file contains other error messages related to the power supply.

Recommended Actions

  • Check the /var/log/ltm file. If you determine that the system logs the message frequently, and the log file contains other error messages related to the power supply, refer to the following article:

    K52015891: Troubleshooting BIG-IP power supply issues
