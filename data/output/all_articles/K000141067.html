K000141067: After changing authentication from LDAP to RADIUS, the old LDAP configuration is still present in the bigip.conf file

Type
Support Solution
Published
2024-09-15
Updated
2024-09-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000141067

Description

After changing authentication from LDAP to RADIUS via the Configuration Utility, the previous LDAP configuration still exists in the bigip.conf file

# cat bigip.conf

auth ldap /Common/system-auth {
bind-dn "CN=svc_F5LDAP,OU=Service Accounts,OU=Administration,OU=User Accounts,DC=mysparq,DC=local"

 

Environment

  • BIG-IP LTM

  • Device Authentication

Cause

Unknown at the time of writing

Recommended Actions

Steps to remove the old LDAP auth configuration from disk.

  1. List the LDAP auth details
    # tmsh list auth ldap system-auth
    auth ldap system-auth {
bind-dn test
bind-pw <test-password>
search-base-dn ou=Users,dc=askf5,dc=pslab,dc=local
servers { x.x.x.x }
}
  2. Delete the LDAP auth
    # tmsh delete auth ldap all

  3. Check if the LDAP auth details are removed.
    # tmsh list auth LDAP system-auth
    01020036:3: The requested LDAP Authentication Configuration (/Common/system-auth) was not found
  4. Save the sys config.
    # tmsh save sys config

  5. Check the LDAP reference is removed from bigip.conf.
    # cat bigip.conf
