Known Issue

This is the result of a known issue. The asmqkview output file does not include the /ts/wsengine_conf directory, which contains files related to XML profiles configured on the BIG-IP ASM system.

Note: For more information, refer to K6824: Overview of the asmqkview script.

F5 Networks Product Development tracked this issue as CR105137 and it was fixed in BIG-IP ASM 9.4.6. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Workaround

You can work around this issue by manually adding the /ts/wsengine_conf directory to the asmqkview output file. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Run the asmqkview utility by typing the following command:

    asmqkview
  3. To create a temporary directory for the asm_snapshot file, use the following command syntax:

    mkdir /var/tmp/snapshot/ 
  4. To move the asm_snapshot file to the temporary directory, use the following command syntax, where <hostname> is the hostname of the system:

    mv /var/tmp/asm_snapshot.<hostname>.tar.gz /var/tmp/snapshot/
  5. To change directories to the temporary directory, use the following command syntax:

    cd /var/tmp/snapshot/
  6. To extract the asm_snapshot file into the temporary directory, use the following command syntax:

    tar -zxvf asm_snapshot.*
  7. To remove the snapshot file, use the following command syntax:

    rm -rf asm_snapshot.*
  8. To copy the /ts/wsengine_conf directory to the ts directory in the temporary folder, use the following command syntax:

    cp -rf /ts/wsengine_conf/ /var/tmp/snapshot/ts/
  9. To re-create and zip the asm_snapshot archive file, use the following command syntax:

    tar --ignore-failed-read * -Pzcvf asm_snapshot.tar.gz
