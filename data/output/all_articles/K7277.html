Known Issue

This is the result of a known issue. You can use an HTTP class to match specific criteria from an HTTP connection and direct the traffic to a load balancing pool through the Application Security Module (ASM), or through the WebAccelerator Module. For example, you can create an HTTP class to match specific HTTP headers for which the system routes to the appropriate pool or BIG-IP ASM security policy. The BIG-IP system fails to match some pattern string entries in the HTTP class header list.

F5 Product Development tracked this issue as CR76397, and it was fixed in versions 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP ASM, LTM, or WebAccelerator Release Notes.
