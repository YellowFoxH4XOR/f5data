K000141527: Message: DNS Sync Group Device Version Incompatibility

Source

Description

When you attempt to upgrade a BIG-IP DNS in a DNS Sync Group Device via the BIG-IQ, this message may pop up.

 

 

Environment

  • BIG-IQ
  • Upgrading BIG-IP DNS via BIG-IQ

 

Cause

A warning message to remind you that BIG-IP DNS synchronization group members must be running the same software version.

 

A BIG-IP DNS device should be running the same software version as other members in the synchronization group. BIG-IP DNS devices that are running different software versions will not be able to communicate and properly synchronize BIG-IP DNS configuration and zone files.

 

 

Recommended Actions

Make sure to upgrade all devices in a DNS Sync Group one after the other in a single maintenance window to avoid configuration sync issues and iQuery communication failures. You must follow K11661449: Overview of BIG-IP DNS system software upgrades to avoid service outages.

 

You may perform the software installation on devices in a DNS Sync Group at the same time but enable the 'Pause for reboot confirmation' option to allow you to manually boot devices in a DNS Sync Group one after the other.
