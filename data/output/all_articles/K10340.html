Known Issue

This is the result of a known issue. A user with the Operator role can disable or enable BIG-IP GTM pools; however, when attempting to disable or enable BIG-IP GTM pool members using the Configuration utility, an error message similar to the following example is displayed:

01070822:3: Access Denied: user (user_name) does not have modify access to object (pool_member)

F5 Product Development tracked this issue as CR111032 and it was fixed in BIG-IP GTM 10.0.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Note: Starting in 10.0.0, users with the Operator role can use the Configuration utility and the interactive command line to enable and disable pool members; however, the role does not permit using the bigpipe edit command to perform the same functions.
