K000159804: BIG-IP DNS synchronization fails when Synchronize checkbox is disabled

Type
Support Solution
Published
2026-01-28
Updated
2026-01-28
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.5.1
Source
https://my.f5.com/manage/s/article/K000159804

1. Description

BIG-IP DNS configuration changes made on one device in a sync group do not replicate to peer devices. When this occurs, DNS objects such as wide IPs, pools, virtual servers, and other GSLB configurations fail to synchronize across the GTM infrastructure, resulting in inconsistent configurations between sync group members.

Symptoms:

  • Configuration changes on one GTM device do not appear on peer devices
  • iQuery connections may show "Server Type: unknown" and "State: not-connected"
  • High reconnect counts (e.g., 294.8K) and significant bytes dropped in iQuery statistics
  • SSL handshake errors in logs: iqmgmt_ssl_connect: SSL error: SSL connect (1)
  • Stale or failed iQuery connection entries visible in tmsh show /gtm iquery output

2. Environment

  • BIG-IP DNS (GTM) version 11.x and later
  • Multi-device GTM sync group configuration
  • DNS synchronization setting disabled under DNS > Settings > GSLB > General
  • iQuery connections established between peer devices

3. Cause

The Synchronize checkbox is disabled (unchecked) under DNS > Settings > GSLB > General on one or more BIG-IP DNS devices in the sync group. When this setting is disabled, the device does not participate in configuration synchronization, preventing replication of DNS configuration changes between peer devices.

Even when iQuery connections are established and the sync group name matches across devices, configuration synchronization will not occur unless the Synchronize setting is explicitly enabled on all members of the sync group.

4. Answer/Recommended Actions

To resolve DNS synchronization issues, verify and enable the Synchronize setting on all devices:

  1. Log in to the Configuration utility on each BIG-IP DNS device in the sync group
  2. Navigate to DNS > Settings > GSLB > General (BIG-IP 11.5.0 and later) or System > Configuration > Global Traffic > General (BIG-IP 10.x - 11.4.1)
  3. Verify that the Synchronize checkbox is enabled
  4. If the checkbox is unchecked, enable it
  5. Verify the Group Name matches across all devices in the sync group
  6. Click Update to save the configuration
  7. Repeat steps 1-6 on all devices in the sync group
  8. Verify synchronization is working by making a test configuration change and confirming it replicates to peer devices

To verify synchronization status using TMSH:

tmsh show /gtm iquery

Confirm that all peer connections display:

  • Server Type: BIGIP-DNS
  • State: connected
  • Configuration Time: Recent timestamp indicating active synchronization

Alternative method using TMSH to enable synchronization:

tmsh modify /gtm global-settings general synchronization yes

tmsh save /sys config

If synchronization issues persist after enabling the setting:

  1. Restart iQuery daemons on all devices to clear stale connection entries:
  2. bigstart restart gtmd big3d
  3. Note: Service impact is minimal, but iQuery communication will briefly pause during restart.
  4. Verify iQuery status after restart:
  5. tmsh show /gtm iquery
  6. Check that GTM server objects are correctly configured with appropriate self IPs
  7. Confirm Port Lockdown on self IPs is set to "Allow Default" or includes port 4353
  8. Verify network connectivity and that TCP port 4353 is open and reachable between peer devices
  9. If issues continue, remove and re-add the affected GTM server object as described in K14044
  10. Verify certificate trust between devices and re-run certificate exchange if necessary:
  11. bigip_add <peer_DNS_IP_address>

5. Additional Information

The Synchronize setting must be enabled on all devices participating in a GTM sync group. This setting controls whether the device synchronizes its DNS configuration with other members of the sync group. When disabled, the device operates independently and does not share configuration changes with peers, even if:

  • iQuery connections are established
  • The sync group name matches
  • Network connectivity is functional

There are two distinct synchronization settings in BIG-IP DNS:

  • Synchronize: Controls synchronization of BIG-IP DNS configuration objects (wide IPs, pools, servers, virtual servers, data centers, monitors, etc.)
  • Synchronize DNS Zone Files: Controls synchronization of DNS zone files and named configuration (disabled by default)

Both settings are independent. The Synchronize checkbox must be enabled for DNS configuration synchronization to occur, regardless of the Synchronize DNS Zone Files setting.
