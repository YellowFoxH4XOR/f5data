K00829454: OAuth OpenID Connect Userinfo call does not return JSON

Type
Support Solution
Published
2021-06-22
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K00829454

Description

On calling the /userinfo  API, the result is a JWT and not JSON

Environment

  • BIG-IP APM
  • OAuth Authorization Server with OpenID Connect implementation

Cause

This is because the "UserInfo Primary Key" field in the OAuth Profile is set to a JWT key. This forces JWT output

Recommended Actions

  1.  In the OAuth Profile, set the"UserInfo Primary Key" to "none".

Additional Information

A link to an external content is provided by F5 as a convenience. This resource discusses UserInfo and what the response looks like.
