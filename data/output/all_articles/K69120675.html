Description

BIG-IP VE is a version of the BIG-IP system that runs as a virtual machine. In a VMware environment, a virtual machine has its own set of virtual hardware that determines the supported features that correspond to the available physical hardware. The virtual hardware features affect the virtual machine's configurable settings, such as the maximum number of CPUs, maximum memory configuration, and other characteristics typical of hardware. 

For the list of hardware features available with the various virtual hardware versions of a VMware virtual machine, refer to the following VMware knowledge base article: Hardware features available with virtual machine compatibility settings (2051652).

Upgrading VMware virtual hardware

You may choose to upgrade the underlying virtual hardware of a BIG-IP VE to a later VMware virtual hardware version (for example, from version 8 to version 11), after the initial deployment and provisioning. The virtual machine virtual hardware version upgrade is also dependent on the version of the VMware hypervisor. For example, you have the option to upgrade the virtual hardware version from version 7 or 9 to 11 if BIG-IP VE is hosted on a VMware ESXi 5.5 hypervisor. For more information, refer to the following VMware knowledge base article: ESXi/ESX hosts and compatible virtual machine hardware versions list (2007240).

Note: The previous link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

To perform the virtual machine virtual hardware version upgrade, refer to the procedure from the vendor's documentation. Although F5 supports upgrading the VMware virtual hardware, we do not support updating VMware Tools on BIG-IP VE. For more information, refer to K11744866: BIG-IP VE support for updating VMware Tools.

Note: The VM hardware virtual version upgrade process may require you to power off BIG-IP VE. F5 recommends that you perform this procedure during a maintenance window.
