K000135392: High swap memory usage after upgrade

Type
Support Solution
Published
2023-07-06
Updated
2026-03-24
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000135392

Description

After upgrade, swap memory usage is high

Swap usage is significantly higher than it used to be.

 

Environment

  • BIG-IP
  • Upgrade to 14.1.5.1, 15.1.7.0, 16.1.3.1, 17.0.0.1 or later versions
  • Value of sys db restjavad.useextramb: true.
  • Value of sys db provision.restjavad.extramb: 192 or lower than previous restjavad heap size.

Cause

  • Bug ID 1153865

Recommended Actions

  • Follow workaround of Bug ID 1153865

Additional Information

1. To check the db value run the below commands:

tmsh show sys db provision.restjavad.extram
 

sys db provision.restjavad.extramb {
   default-value "192"
   scf-config "true"
   value "192"
   value-range "integer min:192 max:8192"
}

tmsh show sys db restjavad.useextramb

sys db restjavad.useextramb {
   default-value "false"
   scf-config "true"
   value "true"
   value-range "false true"
}

 

Check what the most RSS usage by top, ps, pstree utility.
If it is java, then check the parent PID.
If the parent PID is runsv restjavad, this issue may be affecting.
