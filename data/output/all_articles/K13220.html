Known Issue

ISO files that contain parentheses in the file name will appear to import to the Configuration utility correctly, but will not appear in the Available Image list after the upload has completed. When importing an ISO file that contains parentheses in the file name, the file is uploaded to the /share/images directory on the BIG-IP system. However, the file will not appear in the Available Image list and cannot be installed.

This issue occurs when the following condition is met:

  • An ISO file containing parentheses in the file name is uploaded to the BIG-IP system

Impact

You are unable to install the ISO image after upload completes from the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The uploaded file name does not appear on the Software Management page. However, the uploaded file appears in the /shared/images directory
  • After the upload has completed without displaying any errors, the following message appears:

    The upload of image has completed.

  • The uploaded file name is not visible from the command line after running either of the following commands:

    bigpipe software images list

    tmsh list /sys

Workaround

To work around this issue, you can remove the parentheses from the file name prior to uploading it to the BIG-IP system. If the file has already been uploaded to the BIG-IP system, you can remove the parentheses from the command line. To do so, perform the following procedure:

Impact of workaround: None

  1. SSH to the BIG-IP system with root privileges.
  2. Change directories to the /shared/images directory.

    For example

    cd /shared/images

  3. Change the file name to not include parentheses.

    For example:

    mv Hotfix-BIGIP-11.0.0-8131.0-HF1\(1\).iso Hotfix-BIGIP-11.0.0-8131.0-HF1.iso

    Note: You will need to add a backslash ( \ ) character directly before any occurrence of parentheses in the file name.

  4. The file name will now appear on the Software Management page. You can proceed with the installation as you normally would.
