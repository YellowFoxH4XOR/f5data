Issue

When attempting to install FirePass hotfix HF-610-3, you may receive the following error message:

touch: /tmp/.captcha_image_gen_on_first_boot:Permission denied.

If you receive this error message, download and install FirePass hotfix HF-610-3-1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
