Known Issue

This is the result of a known issue. If the big3d process sends a non-conforming message to the Master Control Program Daemon (MCPD), it can result in a memory leak within MCPD service. As a result, the system reboots.

Note: This issue can occur if MCPD service receives only a partial message from the big3d process.

F5 Product Development tracked this issue as CR53530, and it was fixed in BIG-IP LTM version 9.1.3 and version 9.2.2. For information about upgrading, refer to the BIG-IP LTM release notes.
