Known Issue

The ARX system may not notify clients of quota changes on ARX-presented shares.

This issue occurs when the following condition is met:

  • Quotas are implemented on the filers presented by the ARX system.

The ARX system has the filer-side change-notify buffer set to one kilobyte. Any change-notify request that exceeds that amount results in a buffer overflow and is not transmitted to the client.  Instead, the ARX system transmits an empty notification.

Impact

Clients are not notified of quotas and space limitations until the client has reached its quota and additional space usage is rejected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Client space usage is rejected when space still appears to be available.
  • If you are using Wireshark, the following filter shows the empty notify messages:

smb.cmd == 0xa0 && smb.nt.function == 4 && smb.flags.response == 1 && smb.pc == 0

The wireshark filter provides a packet that appears similar to the following example:
