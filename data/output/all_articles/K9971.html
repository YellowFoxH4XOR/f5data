K9971: The Check OS pre-logon inspector does not detect the operating system correctly when the browser's User-Agent string exceeds 256 characters

Known Issue

This is the result of a known issue. If you enable the Check OS inspector in a pre-logon sequence, and the User-Agent string sent by the user’s browser exceeds 256 characters, operating system detection fails and the user is directed to the fallback action configured for the Check OS inspector.

User-Agent is an HTTP header field which contains a text string that identifies the browser. If JavaScript is enabled in your browser, you should be able to view the User-Agent string by entering the following text into the browser’s address bar:

javascript:alert(navigator.userAgent)

F5 Product Development tracked this issue as CR119119 and it was fixed in FirePass 6.1.0. For information about upgrading refer to the FirePass release notes.
 
Additionally, this issue has been fixed in cumulative hotfix HF-602-10, which has been issued for FirePass 6.0.2, and in cumulative hotfix HF-603-3, which has been issued for FirePass 6.0.3. You may download these hotfixes or later versions of these cumulative hotfixes from the F5 Downloads site.
