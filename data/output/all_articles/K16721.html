Known Issue

Under some configurations, the OneConnect profile may not reuse existing connections.

This issue occurs when one of the following conditions is met:

  • You have a OneConnect profile configured on a virtual server which is load balancing to another virtual server.
  • You have a virtual server configured with a OneConnect profile and an iRule which uses the node command.

Note: If the BIG-IP system is running 10.2.4, this issue only occurs if you are running HF8–HF10.

Impact

An increase in CPU and memory resources may impact the performance of the BIG-IP system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A packet capture reveals that OneConnect is not reusing previously opened connections and that previously opened connections remain idle until timeout.
  • The Traffic Management Microkernel (TMM) CPU and memory resources are limited.
