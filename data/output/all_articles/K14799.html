Topic

This article applies to BIG-IP DNS 11.x - 17.x. For information about other versions, refer to the following article:

  • K5662: Reconciling changes between the BIG-IP GTM Configuration utility and the wideip.conf file (9.x - 10.x)

You should consider using this procedure under the following conditions:

  • The BIG-IP DNS configuration in the Configuration utility does not accurately reflect the /config/bigip_gtm.conf configuration file.
  • The BIG-IP DNS configuration in the /config/bigip_gtm.conf file is the desired configuration.

Description

The BIG-IP DNS configuration in the Configuration utility represents the configuration communicated to the master configuration process service. The Configuration utility should reflect the global traffic manager daemon's (gtmd) current configuration. The mcpd process communicates all BIG-IP DNS configuration changes from the Configuration utility to gtmd, and then gtmd updates the /config/bigip_gtm.conf file.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command-line administrative access

Procedures

Reloading the BIG-IP DNS configuration to rectify the configuration discrepancies

If the configuration in the Configuration utility does not match the configuration in the /config/bigip_gtm.conf file, you can reconcile the changes by performing the following procedure from the command line of the affected BIG-IP DNS system:

Impact of procedure: The BIG-IP DNS system cannot respond to any wide IP queries until the gtmd process is started. For BIG-IP DNS synchronization group, configurations the configuration update is propagated across all of the devices in the configured synchronization group.

  1. From the affected BIG-IP DNS system, log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To load the /config/bigip_gtm.conf configuration, type the following command:

    load /sys config gtm-only

  3. To restart the BIG-IP DNS daemon, type the following command:

    restart /sys service gtmd
