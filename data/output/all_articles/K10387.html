Known Issue

This is the result of a known issue. When attempting to access the wide IP member properties page, the following error message displays:

An error has occurred while trying to process your request.

Note: To access the wide IP member properties page, click the wide IP, select the Members tab, and click the wide IP member.

This error message is benign. The system functions as expected.

F5 Product Development tracked this issue as CR123946 and it was fixed in BIG-IP Link Controller version 10.1.0. For information about upgrading, refer to the BIG-IP Link Controller release notes.

Workaround

If you need to modify the ratio of a wide IP member, you can work around this issue by deleting the wide IP member from the wide IP and and re-adding it with the modified ratio value.

Note: The ratio is the only configurable property for a wide IP member on a BIG-IP Link Controller system.

To delete and re-add the wide IP member, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to LinkController > Inbound wide IPs.
  3. Click the name of the wide IP you want to modify.
  4. Click the Members tab.
  5. Select the check box next to the member whose ratio you want to modify.
  6. To remove the member, click the Remove button.
  7. Click the Manage button.
  8. In the Virtual Server drop-down menu, select the same member you just deleted.
  9. Enter the ratio you want to assign to the member.
  10. Click Add.
  11. In the Member List dialog, use the Up and Down buttons to adjust the order of the pools as necessary.
  12. To save the configuration, click Update.
