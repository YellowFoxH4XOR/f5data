Description

Some or all of the VIPRION blades might show LICENSE INOPERATIVE even though their license is in working-condition.

Environment

  • VIPRION platform
  • Showing LICENSE INOPERATIVE in the CLI prompt for some or of all the blades

Cause

This is only a cosmetic issue, it can be fixed by killing the daemon related to showing this prompt (promptstatusd).

Recommended Actions

  1. First verify that the licenses are actually in working condition with the following command from tmsh:

    show /sys cluster

    In the column that shows "Licensed", it should be "True" for all of the cluster members in use.

  2. After verifying that the license is okay for all of the blades, login to the affected blade and run the following command on bash:

    top -cb | grep promptstatusd

    Note down the process ID number that is on the left column and on the same line as /bin/promptstatusd. It should look similar to:

    root@big:ModuleNotLicensed::Active:Standalone] config # top -cb | grep promptstatusd
    3195 root 20 0 111988 18488 14064 S 0.0 0.2 6:31.50 /bin/promptstatusd  → In this example 3195
    28291 root 20 0 114740 980 836 S 0.0 0.0 0:00.00 grep promptstatusd

  3. Issue the following command from bash:

    kill -1 <PID>

    For above example, it would be the following command:

    kill -1 3195

Repeat this process for all of the blades and the problem should clear out.

Note: This command is not traffic-impacting as long as the correct PID is killed.
