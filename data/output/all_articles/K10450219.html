K10450219: Live update installation of an ASM Attack Signature update may fail due to duplicate entry for '''echo'' execution attempt (2) (Header)'

Type
Support Solution
Published
2020-11-20
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.X, 14.1.4, 14.1.3, 14.1.2, 14.1.5, 14.1.0
Source
https://my.f5.com/manage/s/article/K10450219

Description

Live update installation of an ASM Attack Signature update may fail due to duplicate entry for '"echo" execution attempt (2) (Header)'
Following error may appear in /var/log/asm:

crit g_server_rpc_handler.pl[14097]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::Sigfile::Update::store_error_and_die): Failed on insert to PLC.NEGSIG_SIGNATURES (DBD::mysql::db do failed: Duplicate entry '"echo" execution attempt (2) (Header)' for key 'sig_name')

Environment

  • BIG-IP ASM
One of below signatures update:
  • ASM-AttackSignatures_20201109_104004.im
  • ASM-AttackSignatures_20201112_092538.im

Cause

In attack signature update ASM-AttackSignatures_20201109_104004.im signature with name '"echo" execution attempt (2) (Header)"' was incorrectly added causing attack signature installation failure.

This is being tracked as an ID:

  • ID964017

Recommended Actions

Issue has been fixed in subsequent signature update ASM-AttackSignatures_20201116_153945.im. by renaming the signature to '"echo" execution attempt (3) (Header)"'.
To resolve the issue install attack signature update ASM-AttackSignatures_20201116_153945.im or later.
