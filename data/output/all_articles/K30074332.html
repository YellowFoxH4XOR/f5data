Issue

Error Message

01071412:3: Cannot delete IP (<IP_address>) because it is used by the system config-sync setting

In this error message, note the following:

  • <IP_address> is the IP address.

For example:

01071412:3: Cannot delete IP (10.8.51.198) because it is used by the system config-sync setting

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
  • The command line interface (CLI)
Description

This message occurs when the following condition is met:

  • You attempt to delete a self IP address that is referenced in configuration synchronization (ConfigSync) settings.

Impact

You cannot delete the self IP address.

Recommended Actions

F5 recommends removing the self IP address from the ConfigSync setting before deleting the self IP address. 
 

  1. Log in to the BIG-IP Configuration  utility.
  2. Go to Device Management > Devices.
  3. Select the affected BIG-IP (Self). 
  4. From the Device Connectivity dropdown menu, select ConfigSync.
  5. Remove the IP address that you want to delete. (Select an alternative IP address or None, depending on your needs).
  6. Click Update.
  7. You should now be allowed to delete the affected IP address.
