Known Issue

When installing a geolocation database update, the BIG-IP GTM system may produce benign error messages.

This issue occurs when the following condition is met:

  • You install a geolocation database update to BIG-IP GTM 10.2.4 using the geoip_update_data command.

Impact

You can safely ignore the error message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H440718 on the Diagnostics > Identified > Low page.
  • You observe an error message similar to the following examples in the /var/log/ltm log file:

    013b0004:3: Invalid characters in /shared/GeoIP/F5GeoIPCity2.dat;4d3a1149: ignoring

    013b0004:3: Invalid characters in /shared/GeoIP/F5GeoIPISP.dat;4d3a114f: ignoring

    013b0004:3: Invalid characters in /shared/GeoIP/F5GeoIPOrg.dat;4d3a1155: ignoring
