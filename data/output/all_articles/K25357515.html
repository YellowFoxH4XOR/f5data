Known Issue

The Traffic Management Microkernel (TMM) may stop responding when the SSL Forward Proxy is enabled.

This issue occurs when all of the following conditions are met:

  • SSL Forward Proxy is enabled.
  • When the client SSL handshake is not ongoing, the system performs a server handshake.

Impact

The system disrupts traffic while TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • On a standalone BIG-IP system, the system disrupts all traffic handling while TMM restarts.
  • On a redundant BIG-IP system, when TMM restarts on the system that was previously active, the system fails over.
