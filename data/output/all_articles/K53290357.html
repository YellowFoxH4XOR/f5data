Description

When trying to add a BIG-IP device provisioned in Azure to a BIG-IP DNS syncgroup, the gtm_add, bigip_add or big3d_install command may fail when using the vmadmin user.
The command may fail with the following error(s) displayed from the CLI:

  • do_known_hosts: hostkeys_foreach failed: no such file or directory
  • failed to add the host to the list of known hosts (/home/vmadmin/.ssh/known_hosts).
  • Syntax Error: command history is only available in shell mode

Environment

  • BIG-IP
  • Azure
  • gtm_add, bigip_add or big3d_install command is run

Cause

When a BIG-IP is provisioned in Azure, the default 'root' account is removed and replaced with the admin account 'vmadmin'.
The settings on this account may impede the induction of a BIG-IP device into the iQuery mesh syncgroup.

Recommended Actions

To allow the induction of a BIG-IP device into a BIG-IP DNS iQuery syncgroup, the 'vmadmin' user account can be configured to use "Advanced Shell", allowing the account access to BASH:

  1. In the GUI of the target device, navigate to: System ›› Users ›› User List
  2. Click on the 'vmadmin' user.
  3. Set "Terminal Access" to 'Advanced shell'
  4. Click "Update".
  5. Re-run command from CLI.
