Known Issue

Some BIG-IP systems may log excessive bcm56xxd messages.

This issue occurs when the following condition is met:

  • You use a VIPRION B4300 blade, B2250 blade, or a 10000 series BIG-IP system.

Impact

None

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system logs messages similar to the following examples to the /var/log/ltm file, every two seconds:

    info bcm56xxd[<pid>]: 012c0016:6: _soc_xgs3_mem_dma: ING_SERVICE_COUNTER_TABLE_Y.ipipe0 failed(NAK)
    info bcm56xxd[<pid>]: 012c0016:6: _soc_xgs3_mem_dma: EGR_VINTF_COUNTER_TABLE_Y.epipe0 failed(NAK)
    info bcm56xxd[<pid>]: 012c0016:6: _soc_xgs3_mem_dma: EGR_SERVICE_COUNTER_TABLE_X.epipe0 failed(NAK)

Workaround

To work around this issue, you can restart the bcm56xxd process. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system stops processing traffic. You should perform this operation only during a maintenance window or when the system is in a standby state.

  1. Log in to the BIG-IP command line as the root user. If the device is a VIPRION, ensure you are logged in to the affected blade.
  2. To restart the bcm56xxd process, type the following command:

    bigstart restart bcm56xxd
