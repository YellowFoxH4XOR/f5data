Description

An Access Profile's "Profile Type" parameter can only be configured during initial creation of the Access Profile. Once created, the "Profile Type" parameter can no longer be changed. If such a "Profile Type" change is required, a new Access Profile must be created with the correct "Profile Type" configured from that start.

Environment

Relevant environmental factors:

  • BIG-IP with APM Provisioned and configured for use.

Cause

Most Profiles in BIG-IP contain a parameter or two that can only be configured at the time of the Profile's creation. And then cannot ever be changed. The Access Profile's "Profile Type" parameter is one such setting.

Recommended Actions

If there is a need to change an existing Access Profile's "Profile Type", a new Access Profile with the correct "Profile Type" must be created. And those settings that need to be retained must be manually replicated in the new Access Profile's config.
