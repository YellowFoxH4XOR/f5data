Known Issue

This is the result of a known issue. A link is a BIG-IP GTM or BIG-IP Link Controller object that defines a physical connection to the Internet. Link names must start with a letter and can contain any alphanumeric character. If you define a link name containing less than 16 characters on a BIG-IP GTM or BIG-IP Link Controller system, one or more of which is a non-alphanumeric character, graphing functionality may not work properly, and the statsd process generates error messages.

For example, if you define a link object containing a space such as, Datacenter 1, the BIG-IP GTM or BIG-IP Link Controller system generates error messages to the /var/log/ltm file that appear similar to the following example:

statsd[5601]: 011b010b:3: Datasource 'Datacenter 1ratein' in RRD '/var/rrd/gtmlinkDatacenter 1' references unknow variable 'Datacenter' in expression
statsd[5601]: 011b0401:3: Error processing expr for datasource 'Datacenter 1ratein'. No result found

This issue occurs because the statsd process has an RRD-imposed limit of 16 characters for link names.

However, if a link name has more than 16 characters, any combination of characters can be used; the BIG-IP GTM or BIG-IP Link Controller will convert the name into a unique 16 character hash.

For example, if you define a link object called AskF5 Data Center, the BIG-IP GTM or BIG-IP Link Controller creates a unique hash of 16 characters for the link name, and the system does not generate an error message.

F5 Product Development tracked this issue as ID 247113 (formerly CR109575) and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP GTM or Link Controller release notes.

Workaround

To work around this issue, use only alphanumeric characters when defining a link name.
