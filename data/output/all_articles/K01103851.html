Description

ConfigSync Fail when License Reactivation is performed on one of the Peers
Errors similar to below are seen:

sync failed : profile clientssl (wom-default-clientssl) missing
sync failed : client ssl profile (clientssl-insecure-compatible): certificate matching the cipher suites doesn't exist

Environment
  • Peer has an old bigip.license file (early 2017).
  • The newly signed dossier is from 2019.

Cause

Many items from the newest license have been removed from the older license.

Recommended Actions

When pushing out a new License Reactivation, the reactivation has to be done on each node in the cluster before syncing the devices against each other.
