K11118: Using Edge Side Includes Surrogate-Control headers to prevent the BIG-IP WebAccelerator from caching

Topic

A BIG-IP WebAccelerator policy can be configured to control caching based on matching information in an HTTP request header. However, the policy does not have cache control configuration options for HTTP response header information.

The OWS can insert cache control information into the HTTP response using Edge Side Includes (ESI) Surrogate-Control headers to control the BIG-IP WebAccelerator cache behavior.

For example, to specify that an object should not be cached, even when the policy specifies otherwise, the following header can be included in the response:

Surrogate-Control content="ESI/1.0",no-store

Note: For information about using ESI Surrogate-Control headers, refer to the Using ESI Surrogate-Control headers section of the Policy Management Guide for the BIG-IP WebAccelerator System.
