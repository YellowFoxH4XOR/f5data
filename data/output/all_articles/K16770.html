Topic

You should consider using this procedure under the following condition:

  • You want to configure the time zone on the LineRate system to match the other systems in your data center.

Description

In order to configure the time zone on a LineRate system, you must first locate an appropriate time zone name from the /usr/share/zoneinfo directory. Time zone names are generally organized in an area/location format. For example, Asia/Shanghai represents Shanghai, China. Some names, such as Coordinated Universal Time (UTC), do not include a location, only an area. Some names contain sub-locations.

For example:

America/Kentucky/Louisville

The absolute path to the time zone file is /usr/share/zoneinfo/, followed by the zone name.

For example:

/usr/share/zoneinfo/Asia/Shanghai

The Internet Assigned Numbers Authority (IANA) maintains and occasionally updates the official Time Zone Database (referred to as tz or zoneinfo). To ensure compatibility, you should only reference zoneinfo data obtained from the LineRate system for your LineRate configuration.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have command line access to the LineRate system.

Procedures

Setting the time zone on the LineRate system

Important: This procedure requires use of the FreeBSD command line through the LineRate bash CLI command. Note that F5 does not officially recommend configuring LineRate using FreeBSD commands.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the LineRate system CLI.
  2. Determine the appropriate time zone name from the /usr/share/zoneinfo directory by typing the following command:

    bash "ls -lR /usr/share/zoneinfo"

    Alternatively, you can paginate the results with the less utility.

    For example:

    bash "ls -lR /usr/share/zoneinfo | less"

    Note: To quit the less utility, type q.
  3. Create a backup copy of the current /etc/localtime file by typing the following command:

    bash "sudo mv /etc/localtime /etc/localtime.sol16770"
  4. Create a link to the desired time zone name using the following command syntax:

    bash "sudo ln -sf /usr/share/zoneinfo/<Area>/<Location> /etc/localtime"

    For example, to configure your time zone for Auckland, New Zealand, type the following command:

    bash "sudo ln -sf /usr/share/zoneinfo/Pacific/Auckland /etc/localtime"
  5. Confirm the change by typing the following command:

    bash "date"

    The date utility displays the current date and time, including the time zone. For example, the following output includes New Zealand Standard Time (NZST):

    Fri Jun 19 03:21:24 NZST 2015
