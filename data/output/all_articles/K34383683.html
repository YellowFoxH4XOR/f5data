Description

Outgoing traffic on a trunk is unbalanced across the interfaces but incoming packets may be balanced.

Case 1:

Interface 3/1.2 is faulty
Name Pkts In Pkts Out
2/1.1 9.6T12.2T
2/1.3 9.9T10.2T
3/1.12.5T2.6T
3/1.2 424.9G690.9G

Interfaces, (the SFP) can be defective without raising an alarm.
In this case we see that the incoming packets are also impacted

Case 2:

Interfaces are OK, Outgoing is unbalanced, Incoming is balanced
Name Pkts In Pkts Out
2/1.1 2.2G1.4G
2/1.3 2.1G2.9G
3/1.12.1G1.4G
3/1.2 2.1G2.9G



 

Environment

  • Viprion Blade
  • Trunks.

Cause
Case 1 is a faulty QSFP interface
Case 2 is the result of

https://cdn.f5.com/product/bugtracker/ID681935.html
This can impact 4 member trunks.
and 
https://cdn.f5.com/product/bugtracker/ID777993.html
The issue ID777993 seems like it is very specific, however the solution to this improved the balancing behaviour in other ways.

 

Recommended Actions
Case 1:

  1. Check the Interface is working correctly.
  2. Check the port on the Switch.
Case 2:
  1. Upgrade to Version 15.1.0 or later.

Additional Information

  • There is no workaround for Case 2.
