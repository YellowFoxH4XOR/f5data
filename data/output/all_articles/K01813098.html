Description

Adding peer device to device trust, GUI shows "This device is not found" error

Basic network connectivity troubleshooting shows no connection to peer device, ping fails with "time to live exceeded"

Local loop interface is shown as the default gateway:

      # ip route get 172.16.23.28
      172.16.23.28 via 127.1.1.253 dev tmm  src 127.1.1.254
          cache  mtu 9282 advmss 9242 hoplimit 64 

Environment

Peer device not in the same subnet

Cause

No route to peer device via mgmt (eth0)

Recommended Actions

Create a route via management for the Peer device: 

            tmsh create /sys management-route <name> network <destination network>/<netmask> gateway <management gateway>

             example:

            tmsh create /sys management-route route_to_peer network 172.16.23.28/255.255.255.255 gateway 172.16.13.1

The route should show management (eth0) now, for example:

      # ip route get 172.16.23.28
      172.16.23.28 dev eth0  src 172.16.23.30
          cache  mtu 1500 advmss 1460 hoplimit 64

Additional Information

K13284: Overview of management interface routing (11.x and later)
