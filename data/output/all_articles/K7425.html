K7425: SSL session renegotiation can cause a memory leak in the BIG-IP LTM SSL session cache

Known Issue

This is the result of a known issue. SSL session renegotiation allows a client and server to reuse previously negotiated SSL parameters. When a client attempts to locate an SSL session for renegotiation, the previous SSL session is not released by the BIG-IP LTM system. Eventually, the leaked SSL sessions accumulate, which causes system memory exhaustion.

F5 Product Development tracked this issue as CR76768 and it was fixed in BIG-IP LTM 9.1.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.
