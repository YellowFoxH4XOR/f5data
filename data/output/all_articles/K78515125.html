Known Issue

Running End-User Diagnostics (EUD) on an i2000 series or i4000 series platform may cause the interface LED lights to blink.

This issue occurs when the following condition is met:

  • You run EUD version EUD_SF 3.2.0.28.0 or earlier on an i2000 series or i4000 series platform.

    Note: You can determine the EUD version by typing the eud_info command from the command line.

The blinking LEDs are an unintended effect of the port being in test mode. The port LEDs may blink even if the interface is not connected.

Impact

There is no impact. The blinking interface LED lights do not indicate a failure, and you should not misinterpret them as interface traffic, or as a faulty LED.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • While you run the EUD on an i2000 series or i4000 series platform, the interface LED lights blink as if the system is passing traffic on the interfaces (even if the interface is not connected).

Resolution

Status

F5 Product Development has assigned ID 696843 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Type of fixFixes introduced inRelated articles

Point release/hotfixNoneNone

The latest available version of the End-User Diagnostic tool is available on the F5 Downloads site on the Platform / EUD product page, for your specific platform. For information about installing the EUD, refer to the Field Testing F5 Hardware: iSeries Platforms manual.

Note: In BIG-IP 13.0.0 and later, F5 no longer includes the EUD images in the base .iso image file. You must either install the latest EUD package from a BIG-IP-x.y.z.n.n.nnn-RECOVERY.iso image or download the EUD image of your specific platform from the Platform / EUD product page of the F5 Downloads site. For more information, refer to K03203114: Multiple BIG-IP iso images are available (13.x - 14.x).
