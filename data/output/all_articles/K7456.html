Known Issue

This is the result of a known issue. Different versions of the BIG-IP system use an inconsistent format to report the host and TMM memory for the b memory and b global stats commands. The different formats are listed and defined by version as follows:

 

BIG-IP 9.1.x

  • The b memory command reports the sum of the host and TMM memory in a multiple of 1024
  • The b global stats command reports the sum of the host and TMM memory in a multiple of 1000

For example:

# b memory
MEMORY STATISTICS --
Total = 2.147GB    Used = 211.0MB
# b global stats
GLOBAL STATISTICS --
Memory (total, used) = (2.000G, 200.9M)

 

BIG-IP 9.2.x and 9.3.x

  • The b memory command reports only TMM total and used memory in a multiple of 1000
  • The b global stats command reports two separate entries: TMM (Total and Used), and Host (Total and Used) in multiples of 1000

For example:

# b memory
MEMORY STATISTICS --
Total = 1.752GB    Used = 24.56MB
# b global stats
Memory (total, used) = TMM (1.752G, 24.56M), host (2.000G, 361.5M)

 

BIG-IP 9.4.x

  • The b memory command reports the sum of the host and TMM memory in a multiple of 1000
  • The b global stats command reports the same sum of the host and TMM memory as the b memory command reports under two fields: TMM and Host

For example:

# b memory
MEMORY STATISTICS --
|    Total = 2.000GB   Used = 367.4MB
# b global stats
GLOBAL STATISTICS --
+-> TMM traffic --
|   |     memory (total, used) = (2.000G, 367.4M)
+-> Host information --
|   |     CPU (total, active, multi-mode) = (2, 2, smp)
|   |     memory (total, used) = (2.000G, 367.4M)

 

F5 Product Development tracked this issue as CR77748, and it was fixed in BIG-IP version 9.4.1. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator release notes.

Note: Beginning in BIG-IP version 9.4.7 and 10.0.0, a change in behavior was introduced which makes the bigpipe memory show command display the total physical memory installed on the BIG-IP system. For more information, refer to K10099: Change in Behavior: The bigpipe memory show command now displays the total physical memory.
