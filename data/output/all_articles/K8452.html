Known Issue

This is the result of a known issue. If you configure Mobile E-Mail for a master group on the Portal Access: Mobile E-Mail page and select Use LDAP query for mail server, display, and logon information from the Logon Information menu, FirePass does not populate the display name for users in that master group.

For example:

"John Smith" j.smith@siterequest.com

FirePass sets the From field in outgoing emails without the display name, when users in that master group send emails through Mobile E-Mail, similar to the following example:

j.smith@siterequest.com

F5 Product Development tracked this issue as CR98343 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-602-9 issued for FirePass version 6.0.2, and cumulative hotfix HF-603-2 issued for FirePass version 6.0.3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

For a list of current hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

You can work around this issue by performing the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users : Groups : Master Groups page.
  3. Click the name of the master group you want to configure.
  4. Click the User Experience tab.
  5. Clear the Use global setting in Device Management: Customization check box.
  6. In the Order in full user name menu, select the option appropriate for your LDAP schema.

    For example:

    LastnameFirstname
