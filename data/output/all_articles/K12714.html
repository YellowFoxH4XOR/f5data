Known Issue

This is the result of a known issue. By default, the BIG-IP WebAccelerator system checks the hit logs every hour, rotates the log(s), and then restarts the pvac process if necessary. When the BIG-IP WebAccelerator system is experiencing high memory utilization, and the log rotation process and pvac process are struggling for critical memory resources, a race condition may occur during log rotation. As a result, the BIG-IP WebAccelerator pvac process will core.

F5 Product Development tracked this issue as ID 224021 (formerly CR133485), and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
