Known Issue

The SIP_REQUEST and SIP_REQUEST_SEND iRule events fail to trigger when Session Initiation Protocol (SIP) REFER, INFO, or UPDATE requests are received.

This issue occurs when all of the following conditions are met:

  • You have a virtual server that references a SIP profile.
  • The virtual server also references an iRule with SIP_REQUEST or SIP_REQUEST_SEND events.
  • The virtual server receives a SIP REFER, INFO, or UPDATE request.

Impact

SIP subscriber connections may fail due to iRule events not being triggered.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Subscriber connections are failing.
  • iRule events are not triggering as expected.
