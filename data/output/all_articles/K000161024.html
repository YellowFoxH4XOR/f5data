K000161024: Missing "REST API Security (Open API Spec)" Option in BIG-IP ASM Guided Configuration

Description

In BIG-IP ASM, the "REST API Security (Open API Spec)" option may be missing from the Guided Configuration interface. This can occur after system changes such as memory adjustments, RPM cloning, or device upgrades. Symptoms include the absence of the expected configuration option in the GUI, even though related packages appear present in the system directory. Manual installation or update of the Guided Configuration RPM may not resolve the issue if the package is not properly initialized.

Environment

  • Product: BIG-IP ASM
  • Version: 21.0.0
  • Feature: Guided Configuration for API Security Protection
  • Relevant package: f5-iappslx-waf-openapispec-api-protection

Cause

The f5-iappslx-waf-openapispec-api-protection package may be flagged as installed but is not properly initialized or triggered in the Guided Configuration GUI. This can result from compatibility issues between the Guided Configuration RPM and the BIG-IP ASM version, or from incomplete/broken package installation.

Recommended Actions

  1. Verify Package Presence
    • Confirm the f5-iappslx-waf-openapispec-api-protection package exists in /var/config/rest/iapps.
  2. Manual Reinstallation
    • Download the latest compatible Guided Configuration package from the F5 downloads portal, matching your BIG-IP ASM version.
    • Manually reinstall the Guided Configuration packages as described in K85454683: Manual Installation of Guided Configuration Packages.
  3. Full Guided Configuration Reset (If the Above Options Do Not Resolve the Issue)
    • If the version-check logic continues to block reinstallation, the cleanest path is a full factory reset of all Guided Configuration packages:
      • Navigate to iApps > Package Management LX
      • Select all f5-iappslx-access* and f5-iappslx-waf* packages and Uninstall them all
      • Do not manually reinstall anything at this stage
      • Navigate to Security > Guided Configuration
      • The system will automatically reinstall the factory default Guided Configuration version for your BIG-IP release, which should include all expected use case options.
