K71431684: Sync failure with AWS NTP server 169.254.x.x

Type
Support Solution
Published
2022-08-23
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K71431684

Description

Sync failure with AWS NTP server 169.254.x.x. Cannot add route for it and received, and you can see on GUI or CLI similar to below messages
Error Message: 01020062:3: IP Address 169.254.169.123 is invalid, link-local address not allowed.

Environment

  • BIG-IP / BIG-IQ
  • AWS
  • NTP
  • 169.254.x.x

Cause

  • K13098: Error Message: 01020062:3: IP Address 169.254.x.y is invalid, link-local address not allowed

Recommended Actions

  1. Log in to CLI
  2. Chenge config.allow.rfc3927 value to enable
    tmsh modify sys db config.allow.rfc3927 { value enable }
     
  3. Save config tmsh save sys config
    tmsh save sys config
     
  4. Verify config.allow.rfc3927 value is enable
    tmsh list sys db config.allow.rfc3927
    sys db config.allow.rfc3927 {
        value "enable"
    }
  5. Force sync with the NTP server: K78084428: How to force ntpd to sync to a specific NTP server
