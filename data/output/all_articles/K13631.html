Topic

This article applies to BIG-IP 11.x through 15.x. For information about other versions, refer to the following article:

  • K4481: Configuring the threshold values for CPU temperature and CPU fan speed (9.x - 10.x)

Purpose

You should consider using this procedure under the following condition:

  • You want to adjust the threshold value of the CPU temperature or CPU fan speed on the BIG-IP system.

Important: You should only change these values after careful consideration or at the recommendation of F5 Support.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access the TMOS Shell (tmsh).

Description

When the actual temperature of the CPU on the BIG-IP system rises above the configured threshold value for the platform.cpu.temperature.threshold database variable, the BIG-IP system logs a message similar to the following example to the /var/log/ltm file:

010d0001:0: Cpu 1: temperature (<actual temperature>) is too high.

When the actual speed of the CPU fan on the BIG-IP system falls below the configured threshold value for the platform.cpu.fanspeed.threshold database variable, the BIG-IP system logs a message similar to the following example to the /var/log/ltm file:

010d0002:0: Cpu 1: fan speed (<actual fan speed>) is too low.

The following table lists the range of values and the default value for both database variables:

Database variableDefault valueValue range
platform.cpu.temperature.threshold75 degrees Celsius0 to 65535 degrees Celsius inclusive
platform.cpu.fanspeed.threshold3000 RPM0 to 65535 RPM inclusive

The following is a list of hardware platforms that support modifying hardware thresholds using the database variables:

  • BIG-IP 800 appliance
  • BIG-IP 1600 appliance
  • BIG-IP 3600 appliance
  • BIG-IP 3900 appliance
  • BIG-IP 6400 appliance
  • BIG-IP 6800 appliance
  • BIG-IP 6900 appliance
  • BIG-IP 6900S appliance
  • BIG-IP 8400 appliance
  • BIG-IP 8800 appliance
  • BIG-IP 8900 appliance
  • BIG-IP 8950 appliance
  • BIG-IP 8950S appliance
  • BIG-IP 11000 appliance
  • BIG-IP 11050 appliance
  • VIPRION B4100 (PB100) blade
  • VIPRION B4200 (PB200) blade
  • VIPRION B4300 blade

Note: BIG-IP platforms not included in the previous list display the platform-specific threshold values in the Hi Limit(C) column from the Temperature Status output of the CLI command tmsh show sys hardware. You should leave the CPU temperature and CPU fan speed database threshold variables of the newer platforms at the default value of 0 (zero). Changing the values does not have any effect on the BIG-IP system.

Note: F5 does not support changing thresholds of CPU temperature or FAN speed on newer platforms not included in the previous list.

Procedures

You can control when the BIG-IP system logs the triggers for CPU temperature and CPU fan speed by configuring the threshold values for the CPU temperature or CPU fan speed for the BIG-IP system. To do so, perform the following procedures:

  • Displaying the existing configured threshold value for the CPU temperature and CPU fan speed
  • Configuring the threshold value for the CPU temperature and CPU fan speed

Displaying the existing configured threshold value for the CPU temperature and CPU fan speed

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To display the existing configured threshold value for the CPU temperature and CPU fan speed, enter the following command:

    list sys db platform.cpu.*

    The command output appears similar to the following example:

    sys db platform.cpu.fanspeed.threshold {
    value "7000"
    }
    sys db platform.cpu.temperature.threshold {
    value "35"
    }

Configuring the threshold value for the CPU temperature and CPU fan speed

Impact of procedure: Depending on the actual CPU temperature and CPU fan speed, as well as the configured threshold, the BIG-IP system may log the described messages inaccurately. You should always run the system_check -D command to determine the actual CPU temperature and CPU fan speed whenever possible.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To configure the threshold value for the CPU temperature, enter the following command:

    modify sys db platform.cpu.temperature.threshold value <desired value in degree Celsius>

    For example, type the following command to configure the CPU temperature threshold to 70 degrees Celsius:

    modify sys db platform.cpu.temperature.threshold value 70

  3. To configure the threshold value for the CPU fan speed, enter the following command:

    modify sys db platform.cpu.fanspeed.threshold value <desired value in RPM>

    For example, type the following command to configure the CPU fan speed threshold to 4000 RPM:

    modify sys db platform.cpu.fanspeed.threshold value 4000
