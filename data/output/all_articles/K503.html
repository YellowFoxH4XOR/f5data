Description

Simple Network Management Protocol (SNMP) software uses Management Information Base (MIB) files to translate the codes reported by the BIG-IP SNMP daemon into a user-friendly format. You need to install or compile the MIB files on your SNMP management station and configure them in accordance with your SNMP management station software documentation.

Note: For additional information regarding SNMP and working with the MIB files, refer to the Configuring SNMP chapter within the TMOS Management Guide for BIG-IP Systems.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Note: The Net-SNMP site is the official site for Net-SNMP and SNMP documentation. For additional SNMP tutorials, refer to the following link. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://www.net-snmp.org/

The BIG-IP system contains MIB files specific to F5 system information, and non-F5 specific information.

F5-specific MIB files

The F5-specific MIB files contain information that you can use for your remote management station to perform the following tasks:

  • Poll the SNMP agent for BIG-IP system-specific information (GetRequest)
  • Receive BIG-IP system-specific notifications (Trap)
  • Set BIG-IP system data (SetRequest)

The F5-BIGIP-APM-MIB.txt file is an enterprise MIB file that contains information that an SNMP manager system can use to help manage APM objects, such as access and connectivity statistics, pool statistics, and general APM information.

The F5-BIGIP-COMMON-MIB.txt file is an enterprise MIB file that contains information that an SNMP manager system can use to help manage information regarding common information, as well as the F5-specific SNMP traps. This MIB file specifies and defines objects for which all other BIG-IP MIB files reference.

The F5-BIGIP-SYSTEM-MIB.txt file is an enterprise MIB file that contains information that an SNMP manager system can use to help manage objects representing common BIG-IP system information, such as global statistic data, network information, and platform information.

The F5-BIGIP-LOCAL-MIB.txt file is an enterprise MIB file that contains information that an SNMP manager system can use to help manage local application traffic objects, such as virtual servers, pools, nodes, profiles, SNATs, health monitors, and iRules. You can reset statistics for any of these objects.

The F5-BIGIP-GLOBAL-MIB.txt file is an enterprise MIB file that contains information that an SNMP manager system can use to help manage global application traffic objects, such as wide IPs, virtual servers, pools, links, servers, and datacenters. You can reset statistics for any of these objects.

The F5-EM-MIB.txt file is an enterprise MIB that contains information that an SNMP manager system can access for the purpose of managing Enterprise Manager objects such as Device Lists, Device Groups, and Images available on the system. You can reset statistics for any of these objects.

The wa.mib file is an enterprise MIB file that contains information that an SNMP manager system can use to help manage WebAccelerator traffic objects, such as WebAccelerator specific statistic data, connection stats, or build information.

Note: For information about the WebAccelerator MIB file not linking to the BIG-IP SNMP configuration, refer to K8484: WebAccelerator MIB file is not loaded with other BIG-IP SNMP MIB files.

Downloading MIB files

The MIB files are located in the following locations on the BIG-IP system:

  • The /usr/share/snmp/mibs/ directory contains all of the MIB files, individually, in text format.
  • The WebAccelerator MIB file is located in the /usr/local/wa/mib directory, and is named wa.mib.
  • The /usr/local/www/docs/mibs/ directory contains compressed tar files of the F5-specific MIB files (mibs_f5.tar.gz) and non-F5 specific MIB files (mibs_netsnmp.tar.gz).

You can download the MIB tar files by performing the following procedure:

  1. Log in to the Configuration utility.
  2. Click the Main tab
  3. In the Downloads section, click Download F5 MIBs .
  4. Click Save.
  5. Select a location on your local system to save the file.
  6. Click Save.

    You may now uncompress and un-tar the saved tar file to your SNMP management station and install the MIB files in accordance with your SNMP management station software documentation.
