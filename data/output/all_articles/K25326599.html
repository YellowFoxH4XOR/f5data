Topic

You should consider using these procedures under the following conditions:

  • You are deploying a high availability (HA) BIG-IP Azure Resource Manager (ARM) template to Microsoft Azure and need to configure permissions for failover to work
  • You need to gather some of the values that are required when launching the BIG-IP ARM template.

Description

When you are deploying a BIG-IP ARM template for the first time, you may need to configure some permissions if you are using a template that will require representational state transfer (REST) calls to the Azure environment after a failover to move secondary IPs to the newly active BIG-IP system. Secondary IPs are usually used as the destination addresses for virtual servers. Before the setup process, it is a good idea to note some of the values you will need to supply to the BIG-IP ARM template at launch time. These names do not exactly match the names in the Azure portal:

  • TenantID: This is the Directory ID in the Azure portal
  • ClientID: This is in the registered app's Application ID in the Azure portal
  • Service Principal Secret: This is a key from the registered app that must be saved during the key creation process in the Azure portal

Prerequisites

Your Azure user account will need to have permissions that allow you to make changes in the procedures below.

Procedures

To gather the information required along with the other pre-requisite tasks before launching the BIG-IP ARM template, perform the following procedures:

  • Obtaining and noting down the TenantID
  • Creating an application in App registrations and noting the ClientID.
  • Creating the key for the app and noting the Service Principal Secret
  • Giving the app the contributor role

Obtaining and noting down the TenantID

You will need to fill in the value for TenantID when launching the BIG-IP ARM template. This value is equivalent to the Directory ID in the Azure portal.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Azure portal.
  2. Navigate to Azure Active Directory > Properties.
  3. Note down the Directory ID. This is your TenantID in the BIG-IP ARM template.

Creating an application in App registrations and noting the ClientID

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Azure portal.
  2. Navigate to Azure Active Directory > App registrations.
  3. Click + New registration.
  4. For Name, enter the name for your app.
  5. For Supported account types, select an appropriate account type.
  6. For Redirect URI (optional), click Web and enter a URL.

    For example:

    https://example.com/auth

  7. Click Register.
  8. Note down the Application ID. This is your ClientID in the BIG-IP ARM template.

Creating the key for the app and noting the Service Principal Secret

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Azure portal.
  2. Navigate to Azure Active Directory > App registrations.
  3. Click the name of the app you created in the previous step.
  4. Navigate to Certificates & secrets.
  5. Click + New client secret.
  6. For Description, provide a name for the key.
  7. For Expires, select the appropriate duration of the key.
  8. Click Add.
  9. Copy the key value and save it. You will not be able to retrieve this later. This will be the value used for Service Principal Secret in the BIG-IP ARM template.

Giving the app the contributor role

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Azure portal.
  2. Click All services.
  3. Click Subscriptions.
  4. Click the name of your subscription.
  5. Click Access control (IAM).
  6. Click +Add.
  7. Choose Contributor in the Role list.
  8. From the Assign access to list, click Azure AD user, group, or service principal.
  9. Under Select, enter the name of the app you created in the previous step.
  10. Click Save.
