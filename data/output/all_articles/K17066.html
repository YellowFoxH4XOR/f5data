Issue

Error Message

notice PEM: spm_psc_is_ip_address_valid: Session Address <IPv6-Address>; IPv6 prefix length of <Value-1> does not match the globally configured value of <Value-2>

In this error message, note the following:

  • <IPv6-Address> is the offending address in IPv6 address format.
  • <Value-1> is the IPv6 prefix length of the incoming RADIUS packet.
  • <Value-2> is the IPv6 prefix length configured on the BIG-IP system DB key tmm.pem.session.ipv6.prefix.len.

For example:

notice PEM: spm_psc_is_ip_address_valid: Session Address fdfe:11::%0; IPv6 prefix length of 64 does not match the globally configured value of 128

Message Location

You may encounter this message in the following location:

  • In the /var/log/tmm fie.

Note: When the system is loading the affected configuration, a related warning message is logged to the /var/log/ltm log file. The warning message may appear similar to the following example:

warning mcpd[7088]: 01071859:4: Warning generated : The default system IPv6 prefix length value of 128 may prevent PEM module from processing IPv6 subscriber traffic properly on virtual server (/Common/<VirtualServer_Name>). Use sys db variable tmm.pem.session.ipv6.prefix.len to adjust the IPv6 prefix length as deems necessary. Refer to PEM Deployment Guide for more information.

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP PEM system receives a RADIUS packet.
  • The BIG-IP system DB key tmm.pem.session.ipv6.prefix.len is configured to a value that does not match the IPv6 prefix that was received from the RADIUS packet.

The BIG-IP PEM system needs to create a subscriber that uses the IPv6 address if the prefix configured globally for the BIG-IP system by way of the DB key tmm.pem.session.ipv6.prefix.len is different from the prefix received on the RADIUS packet. When the two prefix lengths are different, the subscriber session cannot be created.

Impact

The PEM session cannot be created for the RADIUS packet connecting from the offending IPv6 address.

Recommended Actions

You can perform a tcpdump to capture the RADIUS packet to know what IPv6 prefix length is used, or alternatively, observe the value from the error message. Then modify the BIG-IP system DB key tmm.pem.session.ipv6.prefix.len to match the required value.

To change the DB key to the correct prefix length, use the following command syntax:

tmsh modify /sys db tmm.pem.session.ipv6.prefix.len value <Value>

For example:

tmsh modify /sys db tmm.pem.session.ipv6.prefix.len value 64
