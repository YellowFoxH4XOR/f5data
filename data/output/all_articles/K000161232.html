Description

You are using AFM IP Intelligence with custom feed lists and want to verify if an IP is getting blocked because it is in the shun list. Once verifying the IP is in the shun list, you want to release the IP.

Environment

  • IP Intelligence custom feed lists
  • BIG-IP AFM

Cause

You need to see or delete entries in the shun list.

Answer/Recommended Actions

1.) This command is used to check the IP Intelligence shun list for a specific IP address:
tmsh show security ip-intelligence info address <ip-address>  

--Example using IP address 192.168.1.1:
tmsh show security ip-intelligence info address 192.168.1.1

2.) The below command deletes an IP address from the IP intelligence shun list:
tmsh run security ip-intelligence category name <category_name> ip-ttl delete { x.x.x.x }

--Example using category name "cssp" and IP address 192.168.1.1:
tmsh run security ip-intelligence category name cssp ip-ttl delete { 192.168.1.1 }
