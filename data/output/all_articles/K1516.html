Topic

Starting in BIG-IP version 4.2, F5 Networks provides the following three unique plug-ins for Microsoft Windows nodes:

    You can view information about each .dll file by right-clicking on the file within Microsoft Windows and viewing the properties.

    RedirectFilter.dll

    File Version: 1.0.0.1
    Description: ISAPI Filter for Proxy Redirection
    Internal Name: ISAPI Filter for Proxy Redirection

    This .dll manages IIS server redirects and is used in conjunction with the SSL proxy to solve redirects and port translation issues. This .dll operates independently of BIG-IP so it will work with all versions of BIG-IP. You can download this .dll file from the following location:

    /usr/contrib/f5/redirect/redirectfilter.dll

    It is also available through the Configuration utility web page splash screen, under Additional Software Downloads.

    For more information about this plug-in, refer to K1607: Using an ISAPI filter on Microsoft IIS to rewrite URLs so that it creates redirects that match the protocol and port used by the BIG-IP virtual server or SSL proxy.

    F5isapi.dll

    File version: 1.0.0.1
    Description: F5 ISAPI Internet Server Extension Module
    Internal Name: F5 ISAPI Internet Server Extension Module

    This .dll is for Windows Management Interface (WMI) and it is used to gather NT or Windows 2000 server metrics.

    You can download this .dll file from the following location:

    /usr/contrib/f5/isapi/f5isapi.dll

    It is also available through the Configuration utility web page splash screen, under Additional Software Downloads.

    For more information on this plug-in, refer to K1352: Configuring dynamic ratio load balancing.

    f5realmon.dll

    File Version: 1.0.0.1
    Description: F5 ISAPI Internet Server Extension Module
    Internal Name: F5 ISAPI Internet Server Extension Module

    This .dll is used to health check a Real Media Server. You can download this .dll file from the following location:

    /usr/contrib/f5/rsplugin/f5realmon.dll

    It is also available through the Configuration utility web page splash screen, under Additional Software Downloads.
