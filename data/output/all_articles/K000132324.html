Description

You want to understand the log when manually disable or force offline a node using the Configuration utility (Local Traffic >> Nodes : Node List >> <Node Name> ).


Environment

  • Configuration utility
  • Audit log
  • LTM log
  • ConfigSync

 

Cause

None
 

Recommended Actions

You can find the related logs in /var/log/ltm and /var/log/audit. For example, you may want to disable or force offline node 192.168.1.1.

Note:  In an HA device group, you will find the same logs in /var/log/ltm on peer BIP-IP after ConfigSync, however, there is no relevant log in /var/log/audit on the peer BIG-IP.

  • When you disable a node                    

In /var/log/ltm:
mcpd[<pid>]: 01070641:5: Node /Common/192.168.1.1 address 192.168.1.1 session status forced disabled.
In /var/log/audit:  
Note: The "node_address_monitor_state 3 node_address_new_session_enable 1"means the node is manually Disabled.
notice mcpd[<pid>]: 01070417:5: AUDIT - client tmui, user admin - transaction #3227609-3 - object 0 - modify { node_address { node_address_name        "/Common/192.168.1.1"node_address_monitor_state 3 node_address_new_session_enable 1 node_address_update_status 1 } } [Status=Command OK]

  •  When you force offline a node
In /var/log/ltm:
notice mcpd[<pid>]: 01070640:5: Node /Common/192.168.1.1 address 192.168.1.1 monitor status forced down.
In /var/log/audit:
Note: The "node_address_monitor_state 20 node_address_new_session_enable 1" means the node is manually Forced Offline
notice mcpd[<pid>]: 01070417:5: AUDIT - client tmui, user admin - transaction #3234931-3 - object 0 - modify { node_address { node_address_name        "/Common/192.168.1.1" node_address_monitor_state 20 node_address_new_session_enable 1 node_address_update_status 1 } } [Status=Command OK]
  • When you enable a node from Disabled or Forced Offline
In /var/ltm:
notice mcpd[<pid>]: 01070728:5: Node /Common/192.168.1.1 address 192.168.1.1 monitor status up.
In /var/audit:
Note: The "node_address_monitor_state 3 node_address_new_session_enable 2" means the node is manually Enabled
notice mcpd[<pid>]: 01070417:5: AUDIT - client tmui, user admin - transaction #3241504-3 - object 0 - modify { node_address { node_address_name        "/Common/192.168.1.1" node_address_monitor_state 3 node_address_new_session_enable 2 node_address_update_status 1 } } [Status=Command OK]
