Description

You create a pool and pool members at the BIG-IP Configuration utility, then click the Finished button, and you find: 

  • The pool creation completes.
  • The pool member creation failed.
  • You check the /var/log/audit file, but can't find any log about pool members. 

Environment

  • BIG-IP GUI or Configuration utility
  • Pool or pool members' creation

Cause

Unknown.

Recommended Actions

We suggest using appropriate browsers to access the BIG-IP Configuration utility to avoid any potential HTML and JavaScript compatibility problems. Different versions of the BIG-IP Configuration utility support different browser versions, you need to query BIGIP-IP Release Notes to check.

For example, The BIG-IP version 13.1.1 Configuration utility supports these browsers and versions by looking up Release Notes : BIG-IP 13.1.1 New and Installation on F5 Tech Docs:

  1. Mozilla Firefox v40, or later.
  2. Google Chrome v44, or later.
  3. Microsoft Edge browser v42.17134, or later.

In addition, if the problem happens again, you can collect more data and contact the F5 Support Engineer to further analysis.

  1. Collect the HTTP Archive (HAR) file using a browser. For more information, refer to  K10370211: Generate an HTTP Archive using a browser.
  2. Use follow the command below to capture the Configuration utility traffic at BIG-IP CLI.

tcpdump -s0 -nni 0.0:nnn -vvv -w /var/tmp/GUI_capture.pacp "port 8100 or (host <client_PC_IP> and port 443)"

Note: For more detail about the tcpdump command, please refer to K411: Overview of packet tracing with the tcpdump utility
