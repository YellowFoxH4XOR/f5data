Description

Custom HTTP monitor created with default send string and no specific receive string. In this case, the pool member associated with the monitor will show UP. 
When accessing the virtual server, connection getting rejected with HTTP response: (HTTP) 503 Service Unavailable. 

Environment

  • Standard virtual server
  • HTTP profile with default send string and no receive string 

Cause

This is expected behavior as HTTP monitor  with default send string and no receive string  will just make a normal http connection on defined port and will be successful if the TCP connectivity is successful.
With the default send string the monitor will be UP if port connectivity is there.

Recommended Actions

  1. Configure the send string in the http monitor with correct send and receive string which can collect correct response from the server if service on the server is not UP
    K2167: Constructing HTTP requests for use with the HTTP or HTTPS application health monitor https://my.f5.com/manage/s/article/K2167
