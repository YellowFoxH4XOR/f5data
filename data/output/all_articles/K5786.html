Known Issue

This is the result of a known issue. RFC 3279 requires that certificates should follow any Algorithm Identifier string with a NULL parameter value. The self-signed certificates generated on the BIG-IP system do not include the NULL parameter value. As a result, clients that strictly follow RFC 3279 may not accept a self-signed certificate generated by the BIG-IP system.

The only client that is known to be affected by this issue is Oracle Enterprise Manager.

F5 Product Development tracked this issue as CR52590 and CR61979 and it was fixed in BIG-IP 9.2.2. For information about upgrading, refer to the BIG-IP LTM or ASM release notes.
