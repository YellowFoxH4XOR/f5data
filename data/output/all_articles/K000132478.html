K000132478: BIG-IQ fails to discover BIG-IP AFM containing thousands of rule lists

Type
Support Solution
Published
2023-02-09
Updated
2023-02-09
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.0
Source
https://my.f5.com/manage/s/article/K000132478

Description

When BIG-IQ is adding or discovering a BIG-IP AFM that contains a large number of rule lists (ie. 8k+), it takes the BIG-IP AFM significant amount of time to process the request from within its TMSH library resulting in BIG-IQ timing out the discovery task.

 

The symptoms include BIG-IQ throwing an error similar to the following from restjavad log:

 

[/cm/firewall/tasks/discover-config/<TASK_ID>/worker FirewallDiscoveryTaskWorker] Error querying 'Rule List' from path '/mgmt/tm/security/firewall/rule-list' on device <BIGIP_DEVICE_NAME> (<BIGIP_DEVICE_IP), network communication failed due to protocol error : java.net.ProtocolException: status:400, body:{"code":400,"message":"remoteSender:<BIGIQ_IP_ADDR>, method:GET ","referer":"<BIGIQ_IP_ADDR>","restOperationId":600925,"kind":":resterrorresponse"}

 

From the BIG-IP, the following can be seen from the restjavad log corresponding to the request coming from the BIG-IQ:

 

[8100/mgmt ForwarderPassThroughWorker] URI:http://localhost:8100/mgmt/tm/security/firewall/rule-list?ver=15.1.7&em_server_ip=18.13.191.58&em_server_auth_token=<TOKEN_STRING>, Referrer:<BIGIQ_IP_ADDR>, Method:GET, Exception:java.util.con

current.TimeoutException: remoteSender:<BIGIQ_IP_ADDR>, method:GET

 

Increasing the timers for icrd/restjavad/restnoded on the BIG-IP even to maximum value of 600 may not help.

 

Both tmsh and iControl REST commands when executed from the BIG-IP AFM to retrieve the rule lists take significant amount of time (ie. about 10 minutes) to complete.

 

# time tmsh list security firewall rule-list > /tmp/tmsh.output.txt

# time restcurl -u admin /tm/security/firewall/rule-list > /tmp/restcurl.test.json

 

This is due to how the TMSH library processes the response prior to sending it over to the client. F5 is tracking this BIG-IP AFM issue as BZ ID1215161. At the time of writing, fix is only available via EHF.

 

Environment

  • BIG-IQ discovering a BIG-IP device
  • BIG-IP AFM with thousands of rule lists

 

Cause

ID1215161

 

Recommended Actions

Install an EHF containing fix for ID1215161.

 

Additional Information

None.
