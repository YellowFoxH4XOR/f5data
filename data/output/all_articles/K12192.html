Known Issue

This is the result of a known issue. If a user deletes an email while using mobile email on their mobile device, and the user then presses the back button, other emails may also be deleted. For example, if a user deletes email A and then presses the back button after the mail list redisplays, email B may be inadvertently deleted.

This behavior occurs because the back button takes the user back to the last action that was completed, rather than to the previous email.

F5 Product Development is tracking this issue as ID 341365.

This issue has been fixed in cumulative hotfix HF-610-6.1 for FirePass version 6.1.0 and cumulative hotfix HF-70-4.1 for FirePass version 7.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by requesting that the user completes an action other than deleting an email prior to pressing the back button. For example, if the user reloads the web page before pressing the back button, emails will not be deleted.
