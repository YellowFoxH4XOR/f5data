To load balance multiple services to your servers, create a virtual server for each service that you want to load balance.

Nodes are identified by IP address and port, and one node can be configured to answer requests for multiple virtual servers. You can create multiple virtual servers using the same virtual IP address and different ports, or you can use unique IP addresses and ports.

For example, assume you have two services where one (service A) is hosted on 10.10.10.1:80 and 10.10.10.2:80, and the other (service B) is hosted on 10.10.10.3:8080 and 10.10.10.4:8080.

To configure load balancing for service A, perform the following steps:

  1. Create a pool containing the nodes 10.10.10.1:80 and 10.10.10.2:80.
  2. Create a virtual server with the IP address routable to port 80.
  3. Associate the virtual server to the pool for service A.

To configure load balancing for service B, perform the following steps:

  1. Create a pool containing the nodes 10.10.10.3:8080 and 10.10.10.4:8080.
  2. Create a virtual server with the IP address routable to port 8080.
  3. Associate the virtual server to the pool for service B.

For more information about virtual servers and pools, and how to configure them, refer to the BIG-IP manuals.
