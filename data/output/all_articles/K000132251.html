Description

Recommended way to store a single global value that is valid for all iRules on the device

Environment

  • BIG-IP LTM
  • iRule
  • Global variable

Cause

None

Recommended Actions

If you need to share data that the iRule will never modify across CMP-enabled virtual servers, you can use a static global variable. A static global variable stores data globally to the entire BIG-IP system and is set within each TMM instance each time the iRule is started.

To define the a static global variable you just need to create one irule with the global variable (No need to assign it to any VS). Example:

Rule Name: Static_global_variable

Syntax:

when RULE_INIT {
# Change to "1" to enable debugging log statements
set static::debug 0
}

Then any iRule running on a virtual server on the entire BIG-IP system can read the static global variable. Example:

Rule Name: Logger

Syntax:

when HTTP_REQUEST {
if { $static::debug != 0 } {
log local0. "Got HTTP request: [HTTP::host] ; [HTTP::uri]"
}
}

On above example the most efficient way to change the debug option to 1 on a live BIG-IP system is to modify the ""Static_global_variable iRule using the Configuration utility and save the changes. The changes are then propagated to each TMM instance.
