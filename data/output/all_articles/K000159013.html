K000159013: NGINX Plus License Renewal Notice: "Renewed license does not match the original"

Description

In R34 and later, the NGINX Plus license is updated automatically when the subscription renews, provided reporting is configured. Cloud-side enhancements to this process were added in R35.

After renewing an NGINX Plus subscription, if the license.jwt file is manually replaced, the following notice appears in the NGINX error log:

[notice] renewed license does not match the original one; using original license 

This occurs when manually updating the license.jwt file after renewal. Users may be concerned about whether further action is required to ensure uninterrupted service.

Environment

  • Product: NGINX Plus
  • Version: R34 and later
  • License types: NGINX Plus, NGINX One
  • Configuration: Manual replacement of /etc/nginx/license.jwt after subscription renewal
  • Recent actions: Subscription renewal and manual update of license.jwt

Recommended Actions

  • No action is required for continued operation; you may safely ignore this notice.
  • To suppress the notice:
    • Restore the original license.jwt file if a backup exists.
    • If no backup is available, continue using your current setup.
  • After expiration, entitlement endpoint will reflect renewed subscription details automatically.

Additional Information

  • The log entry is at "notice" level and does not indicate any functional issue.
  • Both old and new JWTs are valid for entitlement checks; only currently active subscriptions are shown by the entitlement endpoint.
  • Service will remain operational as long as a valid renewed subscription exists.
