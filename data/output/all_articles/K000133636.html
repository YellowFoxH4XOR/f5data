Description

In the asm traffic learning, the suggestion details, suggestion has been made to add a matched parameter and specifies the parameter name, however, in the sample request section, the parameter does not exist.

Environment

  • Learning is enabled in ASM Policy

 

Cause

The suggestion is due to "Learn from Response" enabled in Learning and Blocking Settings, which learns parameters from HTTP Response Content from server.

 

Recommended Actions

If it is not required to learn entities, such as parameters from responses, disable Learn from Response from Learning and Blocking Settings.

None.
