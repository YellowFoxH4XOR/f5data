Known Issue

The Service Message Block (SMB) monitor may mark monitored objects in the down state.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with an SMB monitor.
  • The SMB monitor is applied to Samba objects that only accept plain text or lanman authentication types.
  • You upgrade from a BIG-IP version prior to 12.1.2 to a listed release.

Impact

The SMB monitor marks monitored objects in the Unavailable (down) state.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You verify that the monitored Samba object is available.
  • When viewing the network level traffic of the SMB monitor, the monitor attempts to authenticate using NTLMv2 with monitored objects.

Workaround

To work around this issue, you can modify the system smb.conf global settings. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log on to the command line of the affected BIG-IP system.
  2. Using a text editor, open the /etc/samba/smb.conf file.
  3. Locate the [global] reference line.
  4. Add the following stanza after the [global] reference line:

    client ntlmv2 auth = No
    client lanman auth = Yes
    client plaintext auth = Yes

  5. Save the configuration changes to the /etc/samba/smb.conf file.
