K5149: BIG-IP disables ARP for any configured automap SNAT when ARP is disabled on a wildcard virtual server

Known Issue

This is the result of a known issue. If you disable ARP for a wildcard virtual server, BIG-IP also disables ARP for any configured SNAT automap. To avoid this problem, do not disable ARP for wildcard virtual servers, since wildcard virtual servers do not normally respond to ARP requests.

F5 Networks Product Development tracked this issue as CR46706.
