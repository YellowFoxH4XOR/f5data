Description

Use CLI to create user with Read-Only TMSH access

 

Environment

BIG-IP

Administration

 

Cause

Not Applicable

 

Recommended Actions

To create a user with Read Only access, assign the user with the "Auditor" role. An auditor is unable to make any changes to the F5, but has read access to all partitions.

The Auditor role can be given TMSH access, but not access to the Advanced Shell. you can use the following cli/bash command to create the user, assign them the Auditor role, and allow them access to TMSH:

tmsh create auth user <insert user name here> { partition-access add { all-partitions { role auditor } } password <insert password here> shell tmsh }

Make sure to remove the < and > carrots when entering a username and password as in the following example:

tmsh create auth user audit_user { partition-access add { all-partitions { role auditor } } password cde3MKO)sw2 shell tmsh }

Note: The Auditor role allows the user to reset their own password.
