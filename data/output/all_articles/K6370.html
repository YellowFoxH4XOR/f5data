Topic

The BIG-IP Management Information Base (MIB) provides OIDs that supply the bytes sent into and out of virtual servers. Four OIDs are provided in the MIB; two for the input counter and two for the output counter. The standard counters are VirtualServerOctetsIn and VirtualServerOctetsOut. The standard counters provide 32 bits of data (a maximum decimal value of 2,147,483,648).

In addition to the standard counters, the OIDs VirtualServerOctetsInHi32 and VirtualServerOctetsOutHi32 are provided. The VirtualServerOctetsInHi32 OIDs supply an addition 32 bits of data, which allow for a total of 64 bits (a maximum decimal value of 9,223,372,036,854,775,807) if you query both OIDs.

When the standard counter reaches the maximum value, it returns to 0 (zero) and begins counting again. If you pass more traffic than can be tracked by a 32 bit value (more than 2,147,483,648 bytes) during your SNMP polling period, you should also query the VirtualServerOctetsInHi32 OID.
