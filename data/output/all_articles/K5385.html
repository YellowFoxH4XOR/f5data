K5385: Changes made in the Configuration utility are discarded when synchronization begins

Source

Known Issue

This is the result of a known issue. If you are working in the Configuration utility when another member of the synchronization group initiates synchronization, the Configuration utility displays a notification message and does not allow you to continue making changes. When this occurs, you will lose any changes you have made to the configuration.

F5 Networks Product Development tracked this issue as CR24081.

Workaround

You can work around this issue by waiting for at least one minute and then clicking the back button in your web browser, if you are making extensive changes. 3-DNS will allow you to continue making configuration changes once synchronization is complete.
