Description

You have created a custom BIG-IP Edge Client installer specifically without the DNS Relay Proxy Service included. However, upon installation of the said package on the endpoint client, you notice that the DNS Relay Proxy was is still getting installed.

 

Environment

BIG-IP Edge Client

DNS Relay Proxy service

 

Cause

The Machine Tunnel Service component was selected when creating the custom Edge Client installer.

 

Recommended Actions

Do not include the Machine Tunnel Service component in your custom Edge Client package

 

Additional Information

None
