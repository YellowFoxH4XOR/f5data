Issue

Error Message

notice sod[<PID>]: 01140045:5: HA reports tmm NOT ready

In this error message, note the following:

  • <PID> is the process ID for the sod process

For example:

notice sod[5685]: 01140045:5: HA reports tmm NOT ready

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The tmm process starts or restarts, during the period from startup until when the Traffic Management Microkernel (TMM) completes initialization.

Impact

The BIG-IP system is unable to process traffic until TMM is ready.

Recommended Actions

None
