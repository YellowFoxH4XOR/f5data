Known Issue

This is the result of a known issue. In some cases, users may be unable to stop the Policy Builder utility once it is started. This issue may prevent users from running another concurrent instance of the Policy Builder for a different web application. This issue may occur when a user deletes a security policy while the Policy Builder utility is running.

When this issue occurs, error messages that appear similar to the following example may be logged to the /var/log/ts/policy_builder/pb-<##>.log file, where <##> is the security policy ID number:

ERROR 2010-05-05 22:01:11 [pb.BuilderConfig]: Policy <##> does not exist
FATAL 2010-05-05 22:01:11 [pb.BuilderConfig]: Failed to load configuration

F5 Product Development is tracking this issue as ID 329807.

Workaround

Important: If you are experiencing this issue and are unable to stop the Policy Builder utility, contact F5 Technical Support for assistance in stopping the utility.

To prevent this issue from occurring, stop any Policy Builder instance that is running the security policy before deleting the policy by performing one of the following two procedures:

Stopping the Policy Builder prior to deleting the policy for BIG-IP ASM 10.2.0

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Automatic Policy Building.
  4. In the editing context area, ensure that the edited web application and security policy are those for which you want to stop automatic policy building.
  5. For Automatically Build Policy, clear the Enabled check box.
  6. To save the change, click Save.
  7. On the menu bar, click Status.

    The automatic policy building state displays Disabled, and the system stops the Policy Builder.

Stopping the Policy Builder prior to deleting the policy for BIG-IP ASM 10.0.1 through 10.1.0

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Automatic.
  4. In the editing context area, ensure that the edited web application and security policy are those that you want to update.
  5. On the menu bar, click Status.
  6. Below the Policy Builder status area, click Stop.
