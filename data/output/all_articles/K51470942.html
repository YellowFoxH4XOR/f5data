Known Issue

The man page for the show sys connection command in TMOS Shell (tmsh) incorrectly defines the attribute returned by the command. The man pages state that the command returns the age of a connection, which is its minimum idle time. However, the command actually returns the idle time of a connection.

This issue occurs when the following condition is met:

  • You consult the man page for the definition of the show sys connection command in tmsh.

Impact

The man page provides incorrect information.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The value returned by the show sys connection command is unexpected, because you expect the minimum idle time, as stated on the man page, but the idle time displays instead.
