Description

The BIG-IP Enterprise Manager and BIG-IP APM systems both use the local1 syslog facility to send local messages to the /var/log/em and /var/log/apm files. When the system locally logs BIG-IP APM events with iRules or logger utility, if the message is not properly configured, the system may log the message in /var/log/em instead of /var/log/apm.

Cause

Not applicable

Recommended Actions

  1. The BIG-IP system uses the standard UNIX logging utility, syslog-ng, to locally deliver system messages to log files. In BIG-IP systems, syslog-ng uses facility local1 to describe system messages that are specific to the Enterprise Manager and BIG-IP APM systems. When you attempt to log iRule events to the /var/log/apm file, the command should match the filter (facility and regular expression) specified in /etc/syslog-ng/syslog-ng.conf:

    # APM log                                       /var/log/apm
    filter f_apm {
       facility(local1) and match(": 0149[0-9a-fA-F]{4}:");
    };
    filter f_aperreq {
       facility(local1) and match(": 0187[0-9a-fA-F]{4}:");
    };
    filter f_sso {
       facility(local1) and match(": 014[dD][0-9a-fA-F]{4}:");
    };
    filter f_eca {
       facility(local1) and match(": 0162[0-9a-fA-F]{4}:");
    };
    filter f_urldb {
       facility(local1) and match(": 0176[0-9a-fA-F]{4}:");
    };
    filter f_urldbmgrd {
       facility(local1) and match(": 0177[0-9a-fA-F]{4}:");
    };
    filter f_swg {
       facility(local1) and match(": 0179[0-9a-fA-F]{4}:");
    };

  2. For example, the following iRule code logs to the /var/log/apm file:

    when  ACCESS_SESSION_STARTED  {
        log local1.error "APM: 0149FFFF:F: Received a new session from browser: [ACCESS::session data get "session.user.agent"]"
    }

    However, the following iRule code instead logs to the /var/log/em file:

    when  ACCESS_SESSION_STARTED  {
        log local1.error "APM: Received a new session from browser: [ACCESS::session data get "session.user.agent"]"
    }

  3. Similarly for logger utility:
root@bigip.local::Active:Standalone] config # logger -p local1.error "APM: 0149FFFF:F: F5 case XXXXX APM logs"
[root@bigip.local::Active:Standalone] config # grep 'F5 case XXXXX APM logs' /var/log/apm
Sep 2 13:15:55 bigip.local err root[8888]: APM: 0149FFFF:F: F5 case XXXXX APM logs
[root@bigip.local::Active:Standalone] config #

[root@bigip.local::Active:Standalone] config # logger -p local1.error "APM: F5 case XXXXX EM logs" 
[root@bigip.local::Active:Standalone] config # grep 'F5 case XXXXX EM logs' /var/log/em
Sep 2 13:16:16 bigip.local err root[8992]: APM: F5 case XXXXX EM logs
[root@bigip.local::Active:Standalone] config #
