Known Issue

The Dynamic Host Configuration Protocol (DHCP) Relay virtual server configuration may fail to load after upgrading.

This issue occurs when all of the following conditions are met:

  • The configuration contains at least one DHCP Relay virtual server before the upgrade.
  • You upgrade the BIG-IP system from 11.x to 11.6.0.

Impact

You cannot load the configuration after the upgrade.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you attempt to load the affected BIG-IP configuration, you encounter an error message that appears similar to the following example:

    01070095:3: Virtual server /Common/MYdhcprelay lists incompatible profiles.
    Unexpected Error: Loading configuration process failed.

  • The BIG-IP configuration does not load.

Workaround

To work around this issue, you can manually replace the affected DHCP Relay virtual server(s) profiles in the /config/bigip.conf file. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Before editing the /config/bigip.conf file, perform a backup of the existing copy by typing the following command:

    cp -a /config/bigip.conf /config/bigip.conf_SOL16726_backup

  3. Using your preferred text editor, edit the /config/bigip.conf file.
  4. Locate the affected DHCP Relay virtual server configuration where the profiles {...} braces are located.
  5. Replace the profile entry using udp{} with either dhcpv4{} or dhcpv6{}, depending on whether your DHCP Relay configuration is IPv4-based or IPv6-based, respectively.

    For example, before editing, the profiles {...} braces that were configured with udp{} may appear similar to the following example:

    ltm virtual MYdhcprelay {
    description "DHCP relay"
    ...
    profiles {
    udp { }
    }
    ...
    }

    After editing, the profiles {...} braces using the IPv4-based DHCP dhcpv4{} profile may appear similar to the following example:

    ltm virtual MYdhcprelay {
    description "DHCP relay"
    ...
    profiles {
    dhcpv4 { }
    }
    ...
    }

  6. If you have more than one affected DHCP Relay virtual server, repeat Step 4 and Step 5.
  7. When you have finished editing the /config/bigip.conf file, save the changes and exit the text editor.
  8. Manually load the configuration by typing the following command:

    tmsh load sys config

  9. You can delete the /config/bigip.conf_SOL16726_backup file backup copy when the configuration loads correctly. To delete the backup copy, type the following command:

    rm /config/bigip.conf_SOL16726_backup
