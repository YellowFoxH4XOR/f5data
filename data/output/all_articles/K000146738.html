What Happened?

  • I want to apply the exact configurations for an App Firewall (also known as WAF policy) to another namespace. What are the steps I need to take?
  • Is it possible to clone an App Firewall to a different namespace?

Environment

  • F5® Distributed Cloud (XC)
  • Web App & API Protection

Resolution/Answer

To clone an App Firewall to a different namespace:

  1. Navigate to your tenant in Distributed Cloud using the following URL: <tenant-name>.console.ves.volterra.io (replace <tenant-name> with your tenant name)
  2. Navigate to Web App & API Protection
  3. Ensure that you are within the appropriate namespace
  4. On the left hand side of the page, click App Firewall nested under Manage
  5. Locate the App Firewall that you'd like to clone
  6. Click the triple-dots icon on the right side of the page that corresponds to that App Firewall
  7. Click Clone Object
  8. In the Name field nested under Metadata, type the desired name of your new App Firewall
    1. If you'd like to modify any technical settings of the App Firewall, now would be a suitable time to do it. 
  9. At the top left of the page, click the JSON tab next to Documentation and Form
  10. Change the namespace value to the desired namespace. For example:
    1. BEFORE: "namespace": "something"
    2. AFTER: "namespace": "somethingdifferent"
  11. At the bottom right, click Save and Exit
  12. Navigate to the other namespace that received your cloned App Firewall
  13. On the left hand side of the page, click App Firewall nested under Manage
  14. You can see your newly cloned App Firewall in the list
