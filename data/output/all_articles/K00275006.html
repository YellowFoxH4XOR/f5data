Description

When installing BIG-IP Edge Client and F5 Access at the same time on Mac with x86 CPU.
When connecting to VPN with BIG-IP Edge Client, it is recognized as an x86 CPU.
When connecting to VPN with F5 Access, it is sometimes recognized as an ARM CPU.

Environment

  • BIG-IP APM
  • MacOS(x86 CPU)
  • F5 Access

Cause

The client code does not include the use case of CPU type on MacOS with F5 Access.
We do include the pattern in the iPhone use case.

Recommended Actions

  • When using F5 Access on MacOS, avoid checking CPU type.
  • Or use only Edge Client on MacOS.
