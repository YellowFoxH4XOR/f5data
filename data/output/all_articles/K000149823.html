Description

When you want to add allow all IPs in ACL, it is possible to set prefix-length zero.

Environment

F5OS-A 1.8.0 R2800

Cause

It is possible to specify prefix length zero for the ACL via CLI, but GUI does not allow zero.

Recommended Actions

You can use CLI.

Following example allows access to port 161 from all IP addresses.

# system allowed-ips allowed-ip snmp config ipv4 address 0.0.0.0 prefix-length 0 port 161
