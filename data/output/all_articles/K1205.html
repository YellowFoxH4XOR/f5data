Issue

The NameSurfer log file is named namesurfer.log and it is located in the /var/log directory.

To view the NameSurfer log files, perform the following steps:

  1. View new additions to the NameSurfer log, by typing the following command:

    tail -f /var/log/namesurfer.log &

    The tail command will run in the background.

  2. Press the Enter key to return to the command prompt.
  3. Start NameSurfer. For instructions, refer to K1092: Restarting the NameSurfer process from the command line.
  4. Bring the tail command back into the foreground, by typing the following command:

    fg

    Any zone errors that occurred during startup should display on the screen and point to errors in specific files.

For information about isolating the files that are causing the errors, refer to K1237: Isolating NameSurfer problems by removing zone files.
