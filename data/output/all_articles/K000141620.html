Description

  • You installed NGINX Instance Manager (NIM) successfully. 
  • Following NGINX published documents, you understand you can import certificate type PEM and PKCS12
  • Your have a certificate based on PKCS12 format
  • When attempted to import the certificate, you encounter the below error on the GUI and NIM log

- on NMS log

    Oct 9 11:03:54 nms <DPM>[1102]: 2024-10-09T11:03:54.075+0100 ERROR 277355fb-9051-4737-83ce-6efd6f9e46f4 
        errors/http.go:76 http failure with code '134089': the certificate data is not base64 encoded

- and on the UI we have

    An internal error occurred while parsing the certificate(s). Contact the system administrator to check the error log for more details...

Environment

  • NGINX Instance Manager
  • PKCS12 formated Certificates
  • Certificate management 

Cause

  • pkcs file is a Binary and NIM only works with base64 encoded certificate

Recommended Actions

  • Encode certificate to base64 following command ---
              cat <path/certificate file name>.pkcs12 | base64 > <path/certificate file name>.pkcs12
