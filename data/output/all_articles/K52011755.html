Issue

Error Message

01070340:3: <object> (<object_name>) is referenced by one or more rules

In this error message, note the following:

  • <object> is the type of object referenced by the rule.
  • <object_name> is the name of the object.

For example:

01070340:3: pool (/Common/pool_http) is referenced by one or more rules

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You attempt to delete a configuration object when it is actively referenced in an iRule.

    For example, an active iRule containing the following code will prevent the BIG-IP system from deleting the pool named pool_http:

    if { [HTTP::uri starts_with "/example" } {
       pool /Common/pool_http
    }

Impact

You cannot delete the object until you remove the reference in the iRule.

Recommended Actions

You can search existing iRules for pool references from the BIG-IP command line using the following Advanced Shell (bash) script.

  1. Log in to the command line of the BIG-IP system.
  2. Using a text editor (vi or pico), open the new file find_rules_pools.
  3. Place the following text in the file:

    #!/bin/bash
    #Identify all partitions
    PARTITIONS=$(tmsh list /auth partition | awk '$0 ~ /auth partition/ {print $3}')
    for PARTITION in ${PARTITIONS}
    do
      #gather list of iRules
      RULES=$(tmsh -c "cd /${PARTITION};list /ltm rule" | awk '$0 ~ /^ltm rule/ && !/^ltm rule _sys/ {print $3}')
      for RULE in ${RULES}
      do
        #check each iRule for a configured pool reference
        POOL=$(tmsh -c "cd /${PARTITION};list /ltm rule ${RULE}" | awk '$1 == "pool" {printf($2" ")}')
        # verify that a pool name was found and map iRule name to pool name
        test -n "${POOL}" 2>&1 && {
          echo  "Rule: /${PARTITION}/${RULE} - references - pool(s): ${PARTITION}/${POOL}"
        }
      done
    done

  4. Save the file.
  5. To execute the bash script, enter the following command:

    bash ./find_rules_pools

    Output appears similar to the following:

    Rule: /Common/pool_select - references - pool(s): /Common/a_pool b_pool
    Rule: /Example/http_resources - references - pool(s): /Example/stream_pool
