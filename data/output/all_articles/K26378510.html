Description
When upgrading from 12.0.x or lower to 12.1.x or later you receive the following error: 01070396:3: Virtual server x.x.x.x uses fallback persistence when no other persistence has been declared.
Unexpected Error: Validating configuration process failed.

Environment

  • BIG-IP
  • Upgrade from 12.0.x or lower to 12.1.x or later
  • You have a Virtual Server (VS) with an SSL persistence and a TCP profile with verified-accept enabled
Example: 
ltm virtual vs {
    destination 10.1.11.101:443
    fallback-persistence source_addr
    ip-protocol tcp
    mask 255.255.255.255
    persist {
        ssl { 
            default yes
        }
    }
    
ltm profile tcp /Common/<profileName> {
    app-service none
    defaults-from /Common/tcp-legacy
    syn-cookie-enable enabled
    verified-accept enabled 
}

Cause

Behavior change in 12.1.x or later
Related to Bug ID501339

The default TCP profile has Local Traffic  ››  Profiles : Protocol : TCP : Connection Setup : Verified Accept disabled by default.

Note: F5 recommends that you do not modify the default profiles. The default profile types contain a recommended baseline from which an implementation starts; if you change the default profile values, the baseline settings may be difficult to recover. 
 K14488: Working with profiles

To check the default TCP profile: 
# tmsh list ltm profile tcp tcp | grep -i verified-accept
   verified-accept disabled
   
If you have modified the default TCP profile to enable verified-accept then you may encounter this change in behavior.

Example: 
# tmsh list ltm profile tcp <profileName>
ltm profile tcp <profileName> {
    app-service none
    defaults-from tcp
    fast-open disabled
    verified-accept enabled <--- shows enabled (default is disabled)
}

Recommended Actions

Related

  1. If you want to use TCP verify accept, you cannot use SSL persistence.
  2. If you want to use SSL persistence, you must use a TCP profile with verify accept disabled.

Additional Information
Release Notes : BIG-IP 12.1.0 New and Installation

Behavior changes in 12.1.0

501339    "The system now prevents configuring a virtual server to use a SSL persistence profile together with a TCP profile that has Verify Accepted enabled. The Verify Accepted setting is not compatible with SSL persistence but some previous releases did not prevent this configuration. During the upgrade process, the SSL persistence profile will be removed from any virtual server that also uses a TCP profile that has Verify Accepted enabled."
