Topic

This article applies to BIG-IP APM 10.1.0 through 11.3.0. For information about other versions, refer to the following articles:

  • K48955220: Installing an OPSWAT Endpoint Security update on BIG-IP APM systems (11.4.x and later)
  • K6664: Obtaining and installing OPSWAT hotfixes for FirePass

The BIG-IP APM antivirus and firewall client-side checks use software libraries from a software development kit (SDK) created by OPSWAT, Inc. OPSWAT periodically issues new versions of the SDK libraries to support new security products and resolve bugs in the software. F5 distributes these updates in the form of an Endpoint Security (EPSEC) update ISO image file, such as epsec-1.0.0-420.0.iso.

Important: Do not contact OPSWAT for support requests. OPSWAT works through vendors of security products to address issues with supported products or requests to add support for products. You should direct support requests to F5 for issues regarding the APM controller's implementation of OPSWAT's SDK, and to the vendors of the security software for issues regarding their products' implementation of the SDK.

To install an OPSWAT hotfix on a BIG-IP APM system, perform one of the following procedures:

  • Using the Configuration utility to install an OPSWAT hotfix (BIG-IP APM 11.2.1 through 11.3.0)
  • Using the Configuration utility to install an OPSWAT hotfix (BIG-IP APM 10.2.0 through 11.2.0)
  • Using the Traffic Management Shell to install an OPSWAT hotfix (BIG-IP APM 11.2.0 through 11.3.0)
  • Using the command line to install an OPSWAT hotfix (BIG-IP APM 10.1.0 through 11.1.0)

Using the Configuration utility to install an OPSWAT hotfix (BIG-IP APM 11.2.1 through 11.3.0)

  1. Download the OPSWAT hotfix from the F5 Downloads site.

    Note: For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

  2. Log in to the Configuration utility.
  3. Navigate to System > Software Management.
  4. Click Antivirus Check Updates.
  5. Click Upload Package.
  6. Click Browse.
  7. Select the file you downloaded in step 1.
  8. From the Install Option menu, select the appropriate installation option.

    Note: The Do not Install option uploads the EPSEC package without installing it.

  9. If you selected the Install on Autosync enabled Device Group option, select the device group from the Device Group menu.
  10. Click Upload.
  11. After the software uploads, click OK.

    Note: The upload process may take a couple of minutes.

BIG-IP APM is now running the OPSWAT package. To confirm that the installation was successful, review the Installed Version field under the Device EPSEC Status tab.

Using the Configuration utility to install an OPSWAT hotfix (BIG-IP APM 10.2.0 through 11.2.0)

  1. Download the OPSWAT hotfix from the F5 Downloads site.

    Note: For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

  2. Log in to the Configuration utility.
  3. Navigate to System > Software Management.
  4. Click Antivirus Check Updates.
  5. Click Import.
  6. Click Browse.
  7. Select the file you downloaded in step 1.
  8. Click Import.
  9. After the software uploads, click OK.

    Note: The upload process may take a couple of minutes.

  10. From the System > Software Management > Antivirus Check Updates screen, click the software image that you just uploaded.

    For example:

    epsec-1.0.0-1.0.iso

  11. Click Install.

BIG-IP APM is now running the OPSWAT package. To confirm that the installation was successful, review the Version field under Installed Image located on the Antivirus Check Updates screen. The new OPSWAT SDK libraries take effect immediately, and a reboot is not required.

Using the Traffic Management Shell to install an OPSWAT hotfix (BIG-IP APM 11.2.0 through 11.3.0)

  1. Download the OPSWAT hotfix from the F5 Downloads site.

    Note: For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

  2. Copy the file you downloaded in step 1 to the BIG-IP /shared/apm/images folder.

    Note: Use a SCP utility to copy the file to the BIG-IP system.

  3. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  4. Create a new package using the following command syntax:

    create /apm epsec epsec-package <package name> local-path <path/filename>
    Where <package name> is the name the BIG-IP will use to identify the package
    <path/filename> is the path and name of the EPSEC file copied to the BIG-IP in step 2.

    For example:

    create apm epsec epsec-package epsec-1.0.0-420.0.iso local-path /shared/apm/images/epsec-1.0.0-420.0.iso

    Note: When using the BIG-IP APM Configuration utility, the system uses the file name as the package name, by default. You may rename the package.

  5. Install the new package using the following command syntax, where <package name> is the name of the package you created in step 4:

    install /apm epsec epsec-package EPSEC/Images/<package name>

    For example:

    install /apm epsec epsec-package EPSEC/Images/epsec-1.0.0-420.0.iso

  6. You can validate the package installed by typing in the following command.

    Note: It may take a few minutes for the following command to reflect that the package installation has completed.

    show /apm epsec software-status

Using the command line to install an OPSWAT hotfix (BIG-IP APM 10.1.0 through 11.1.0)

  1. Download the OPSWAT hotfix from the F5 Downloads site.

    Note: For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

  2. Copy the hotfix file to the /shared/apm/images directory on the target BIG-IP system. For example, to use scp on the system where the file is located, type the following command:

    scp </local/path/to/file> root@<bigip_management_ip>:/shared/apm/images/<hotfix-name>

    Note: In the example command, replace the /local/path/to/file section with the full path to the file on the local system, the bigip_management_ip section with the management IP address of the BIG-IP system, and the hotfix-name section with the name of the hotfix file you downloaded.

  3. On the BIG-IP system, install the hotfix by typing the following command:

    epsec install <hotfix-name>

    Note: In the example command, replace the hotfix-name section with the name of the hotfix file.

  4. Verify the installation by typing the following command:

    epsec list

    The hotfix package you just installed should be listed.

The new OPSWAT SDK libraries take effect immediately. A reboot is not required.
