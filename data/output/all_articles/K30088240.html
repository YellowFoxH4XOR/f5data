Description

Attempts to reactivate a license on the Activate F5 Product page, is resulting with the following error message:

51080: Invalid Base Registration Key - Unknown Key

Environment

  • Licensing
  • BIG-IP
  • Base Registration Key

Cause

The key passed in the dossier cannot be found in the database. Like Error 51083, this can be caused by a invalid key value. In this message, the license server cannot match the value to any known key.

Recommended Actions

Confirm that the base registration key is correct by following any of the steps below:

•  Display the registration key from the command line:

    Using the TMOS shell (tmsh)

  1. Log in to the BIG-IP command line.
  2. To display the registration key, enter the following command:

    # tmsh show sys license

    The Sys::License section of the command output appears similar to the following example:

    Sys::License
    Licensed Version 11.0.0
    Registration key X1234-12345-12345-12345-1234567
    Licensed On 2016/02/07
    License Start Date 2016/02/06
    License End Date 2016/09/17
    Service Check Date 2016/08/18
    Platform ID D106
    Appliance Serial Number F5-ABCD-0112

•  Search the /config/bigip.license file

  1. Log in to the command line.
  2. Enter the following command:

    # grep Reg /config/bigip.license

    The command prints the registration key.

    For example:
    Registration Key: X1234-12345-12345-12345-1234567

•  Display the registration key in the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > License.
  3. Select Re-activate.
  4. After the license activation page loads, locate the Base Registration Key.
