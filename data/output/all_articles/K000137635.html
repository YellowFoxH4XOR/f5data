K000137635: Telemetry path /mgmt/tm/security/dos/profile/stats failing after upgrade to 15.1.9

Type
Support Solution
Published
2023-11-21
Updated
2023-11-21
Applies to
  • BIG-IP
  • BIG-IP AFM: 15.1.9
Source
https://my.f5.com/manage/s/article/K000137635

Description

1. After upgrading to software version 15.1.9 , the Telemetry Streaming path /mgmt/tm/security/dos/profile/stats is failing.

2. You observe a log message similar to below in the /var/log/restnoded/restnoded.log file
severe: [telemetry.ITRes_Namespace::customEndpointsSystem::customPoller_ITRes] Error on attempt to load data from endpoint 'dosProfileStats[/mgmt/tm/security/dos/profile/stats]': Error: Bad status code: 500 Server Error for http://localhost:8100/mgmt/tm/security/dos/profile/stats

3. Using tmsh to view the dos profile stats returns the error below 
     A null pointer was passed into a function.

 

Environment

BIG-IP AFM
Telemetry Streaming
Dos profile with Network Families enabled 

Cause

ID1251105

Recommended Actions

Upgrade to a software version where ID1251105 is fixed.
In case a software upgrade is not possible, disable the Network Families in your dos profiles.

Additional Information

None
