K000158827: [F5OS] Unable to modify LDAP configuration using webUI. Receiving error message "object is not writable: /oc-sys:system/oc-sys:aaa/oc-sys:authentication/f5-aaa-ldap:ldap/f5-aaa-ldap:state"

Type
Support Solution
Published
2025-12-18
Updated
2026-08-19
Applies to
  • F5OS Products
  • F5OS-A: 1.8.3
  • F5OS-C: 1.8.1, 1.8.2
Source
https://my.f5.com/manage/s/article/K000158827

Description

You are unable to modify LDAP configuration via webUI.

Certain changes result in object is not writable server error.While making modifications to LDAP configuration from webUI, you will get a pop-up window with the message object is not writable:/oc-sys:system/oc-sys:aaa/oc-sys:authentication/f5-aaa-ldap:ldap/f5-aaa-ldap:state.

Once the issue occur this pop-up will appear everytime you make any changes to LDAP from webUI, however the changes from CLI will work without any issue.

Environment

  • F5OS
  • Software Version: 1.8.x
  • Changing LDAP configuration from webUI

Cause

This issue is tracked under Bug ID 2044517.

Recommended Actions

Use CLI to modify LDAP configuration as a workaround, until a fix for Bug ID 2044517 is available. For information about using CLI to configure LDAP, refer to the following guides:

  • F5OS-C 1.8.x

    The LDAP/AD configuration from the CLI sub-section in the Authentication & Access chapter of the VELOS systems: Administration and Configuration guide.

  • F5OS-A 1.8.x

    The LDAP/AD configuration from the CLI sub-section in the Authentication & Access chapter of the F5 rSeries Systems: Administration and Configuration guide.
