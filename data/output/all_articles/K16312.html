Known Issue

The BIG-IP system may fail to appropriately respond to SMTPS commands. This issue occurs when all of the following conditions are met:

  • A virtual server is associated with an SMTPS profile that is configured with Require for the STARTTLS Activation Mode setting.

    Note: By default, the STARTTLS Activation Mode setting is set to Require in an SMTPS profile.

  • The following series of events take place after the STARTTLS handshake on the client side:

    • The BIG-IP system sends an RSET command to the SMTP server.
    • The BIG-IP system receives a command (such as HELO or EHLO) from the SMTP client.
    • The BIG-IP system then receives the RSET response from the SMTP server.

Impact

SMTPS communication terminates unexpectedly on the BIG-IP system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A packet capture on the affected traffic shows that the responses from the BIG-IP system do not match the requested commands from the SMTP client.
  • A packet capture on the affected traffic shows that the BIG-IP system responds with a 530 Must issue a STARTTLS command first after the STARTTLS handshake has already been completed and the series of events described in the Description section has taken place.
