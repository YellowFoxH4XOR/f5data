Topic

BIG-IP ASM supports importing and exporting security policies using the Configuration utility. For example, you can export a security policy from one BIG-IP ASM system and import that same policy to another BIG-IP ASM system running the same or later software version.

Description

When preparing to export or import a security policy from one BIG-IP ASM system to another, you should be aware of the following information:

  • You can import a security policy that was previously exported from the same or different BIG-IP ASM system.
  • You can import a security policy that was previously exported from the same or earlier software version. For example, you can export a security policy from a system running BIG-IP 11.2.1, and import the policy to a system running BIG-IP 12.0.0.
  • F5 does not support importing a security policy that was exported from a later software version. For example, it is not supported to attempt to export a security policy from a system running BIG-IP 12.0.0 and attempt to import that policy to a system running BIG-IP 11.2.1.
  • You can export a security policy as a binary archive file, as a readable XML or JSON file.
  • When you import a security policy, you can import it as an inactive security policy or so that it replaces an existing security policy. If you replace an existing policy, the replaced policy is automatically archived with the inactive security policies.

Exporting a security policy

To export a security policy and save it in a file, perform the following procedure for your version:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IP 16.0.0 and later

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Security Policies > Policies List.
  3. Select the policy you want to export.
  4. Select Export and then select the appropriate export format options.
    • To save the security policy as an XML file, select XML Format.
    • To save the security policy as an XML file with a reduced file size, select XML Format (Compact).
    • To save the security policy as a policy archive file (PLC file), select Binary Format.
    • (BIG-IP 16.1.0 and later) To save the security policy as an JSON file, select JSON format.
  5. Save the exported file on your computer.

BIG-IP 13.0.0 through 15.1.x

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Security Policies > Policies List.
  3. In the select the security policy that you want to export, then select Export.
  4. Select the appropriate export formatting options, and then select Export Policy.
  5. Save the exported file your computer.

BIG-IP ASM 11.3.0 through 12.1.x

  1. Go to Security > Application Security > Security Policies > Active Policies.
  2. For Active Security Policies, select the security policy that you want to export, and then select Export.
  3. For Select Export Method, select the appropriate formatting option, and then select Export.
  4. Save the exported file your computer.

BIG-IP ASM 11.1.0 through 11.2.1

  1. Go to Application Security > Security Policies > Policies List > Active Policies.
  2. For Active Security Policies, select the security policy that you want to export, and then select Export.
  3. For Select Export Method, select the appropriate formatting option, and then select Export.
  4. Save the exported file your computer.

BIG-IP ASM 11.0.0

  1. Go to Application Security > Policies List.
  2. For Security Policies, select the security policy that you want to export, then select Export to export the policy file in binary format or Export as XML to export the policy file in an XML format.
  3. Save the exported file your computer.

Importing a security policy

To import a security policy to a BIG-IP ASM system, perform the following procedure for your version:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IP ASM 15.0.0 through 16.x

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Security Policies > Policies List.
  3. Select the three dots next to Create and then select Import Policy.
  4. Use File Upload to browse to the location on your computer where you saved a previously exported security policy file, select the file, and select Open.
  5. Optionally change the imported policy name and add a description.
  6. For Import Target, select the import option you want to use. If you are replacing a policy, for Replaced Policy, select the name of the policy you want to replace.
  7. Select Import.

BIG-IP ASM 13.0.0 through 14.1.x

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Security Policies > Policies List.
  3. Select Import Policy.
  4. Select Select File and use File Upload to browse to the location on your computer where you saved a previously exported security policy file, select the file, and select Open.
  5. Optionally change the imported policy name and add a description.
  6. For Import Target, select the import option you want to use. If you are replacing a policy, for Replaced Policy, select the name of the policy you want to replace.
  7. Select Import Policy.

BIG-IP ASM 11.3.0 through 12.1.x

  1. Go to Security > Application Security > Security Policies > Active Policies.
  2. Select Import.
  3. For Choose File, select Browse and use the File Upload dialog box to browse to the location on your computer where you saved a previously exported security policy file, select the file, and select Open.
  4. For Import Target, select how to import the security policy. To create a new policy, select Inactive Security Policies List. To replace a current policy, select Replaced Policy and select the name of the policy you want to replace.
  5. Select Import.
  6. If you are saving a new policy, after the policy imports, select OK to go to Inactive Policies, where you can activate it. If you are replacing an existing policy, the imported file replaces the policy and you remain on the Import Security Policy page until you navigate away.

BIG-IP ASM 11.1.0 through 11.2.1

  1. Go to Application Security > Security Policies > Policies List > Active Policies.
  2. Select Import.
  3. For Choose File, select Browse and use the File Upload dialog box to browse to the location on your computer where you saved a previously exported security policy file, select the file, and select Open.
  4. For Import Target , select how to import the security policy. To create a new policy, select Inactive Security Policies List. To replace a current policy, select HTTP Class (Replaced Policy) and select the name of the policy you want to replace.
  5. Select the Enabled check box to associate existing statistics, logs data, and learning suggestions to the imported policy.
  6. Select Import.
  7. If you are saving a new policy, after the policy imports, select OK to go to the Inactive Security Policies list where you can activate it. If you are replacing an active policy, select OK to go to the Active Security Policies list.

BIG-IP ASM 11.0.0

  1. Go to Application Security > Policies List.
  2. Select Import.
  3. For Choose File, select Browse and use File Upload to browse to the location on your computer where you saved a previously exported security policy file, select the file, and select Open.
  4. For the Import .
  5. Select OK to return to the Policies List page.

Recommendations

When importing or exporting security policies, consider the following factors:

  • Use an exported security policy as a baseline policy. For example, you may want to export a security policy protecting one web application to use it as a baseline policy for another similar web application.
  • Use an exported policy to back up security policy information. For example, you may want to export a security policy to archive it on a remote system before upgrading the system software to create a backup copy, replace an existing policy, or to merge with another security policy.
  • Make sure to use the same version of ASM Signatures (preferably the newest) on both systems.
