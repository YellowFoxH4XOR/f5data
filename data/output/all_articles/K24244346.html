K24244346: Error Message:0107147c:3: iFile file ''ifile_name'' is too large. Maximum size is 32MB.

2023-04-06

Applies to

Source
https://my.f5.com/manage/s/article/K24244346

Description

You are encountering an error message when attempting to upload an iFile, indicating that the file is too large. The maximum size for an iFile is 32MB. The error message can be found in /var/log/ltm:

"0107147c:3: iFile file "<ifile_name>" is too large. Maximum size is 32MB."

Environment

  • Using the Big-IP Configuration utility
  • Importing a file as an iFile

Cause

The iFile you are trying to upload exceeds the maximum content size limit of 32MB.

Recommended Actions

  1. Review the iFile size and modify it to fit within the 32MB limitation.
  2. Import the iFile for use with the BIG-IP system:
a. Log in to the Configuration utility.
b. Navigate to System > File Management > iFile List.
c. Click Import.
d. Click Choose file.
e. Locate the iFile on your local device.
f. Click Open.
g. For Name, type a name for the iFile.
h. Click Import.
