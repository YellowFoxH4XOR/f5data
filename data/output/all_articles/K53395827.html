Topic

F5 has partnered with Appdome, a third-party vendor providing automated integration of mobile applications with the F5 Anti-Bot Mobile Application SDK.

Description

F5 Anti-Bot Mobile Application SDK extends advanced web application firewall (WAF)/BIG-IP ASM protection to work within native mobile applications.

To use this enhanced capability, you must integrate the F5 Anti-Bot Mobile Application SDK with your applications.

For more information, refer to Integrate Apps with F5 Anti-Bot Mobile SDK.
