K000150793: How to verify License Usage Reporting for NGINX Ingress Controller Deployment

Type
Support Solution
Published
2025-04-10
Updated
2025-04-10
Applies to
  • NGINX Products
  • NGINX Ingress Controller: 4.X.X, 4.0.X, 4.0.0
Source
https://my.f5.com/manage/s/article/K000150793

Description

  • You upgrade Nginx Ingress Controller to version "4.0.1". 
  • To comply with recent change in R33 mad facilitate usage reporting requirement, you created the necessary configMap.
  • But, after the upgrade, you were unable to find any kind of reference to usage reporting on Nginx One. 
  • You want to know how you can verify usage reporting to NGINX One

Environment

  • NGINX Ingress Controller
  • Upgrade
  • NGINX Plus R33 +
  • Licensing
  • Usage Reporting

Cause

  • You want to know how you can verify usage reporting to NGINX One
  • By default NGINX Ingress Controller log level is set at "notice" level. However, usage report log is recorded at a higher log level, that is "info"

Recommended Actions

  • It is possible to see Usage reporting from within NGINX Ingress Controller Pod log by increasing the log level to "info"
  • to do so,
    • modify/set the log level to info, using "nginx-config" configMap and directive "error-log-level"
      • kubectl edit cm -n nginx-ingress nginx-ingress
      • set the log level to info as shown below
                    apiVersion: v1
                    data:
                      error-log-level: info
