K000160729: Understanding BIG-IP AFM DoS Logs with "Attack ID = 0" and Missing Source/Destination IPs

Description

BIG-IP AFM DoS logs may show traffic drops for single packets with "Attack ID = 0" and missing source/destination IP information. These events are not visible in the BIG-IP DoS Dashboard and may cause confusion for monitoring logs. This typically occurs when the Mitigation threshold is set equal to or lower than the Detection threshold in the DoS profile, resulting in packet drops before an official Attack is declared.  

Environment

  • BIG-IP AFM
  • DoS profile with Detection and Mitigation thresholds in unexpected manner

Cause

This behavior is due to AFM DoS vector configuration where the Mitigation threshold is set equal to or lower than the Detection threshold. AFM drops packets before an official Attack is declared, resulting in logs with "Attack ID = 0" and missing source/destination IPs.

As a side note, BIG-IQ aggregates Attack data, and events with "Attack ID = 0" are part of normal operation when the detection threshold is not crossed.

Answer/Recommended Actions

  • Adjust DoS profile configuration so the Detection threshold is set lower than the Mitigation threshold to ensure attacks are properly detected and assigned an 'Attack ID', before Mitigation occurs.
  • Apply Analytics profile to relevant Virtual Server object in BIG-IP to enable more granular event logging and visibility either in BIG-IP or BIG-IQ.
  • In case of sending DDoS events to BIG-IQ, review DoS events from the BIG-IQ DDoS Dashboard (Network Analysis) for accurate Attack information.
  • Inform your Internal monitoring teams that events with "Attack ID = 0" are expected when Mitigation occurs before Detection, and these do not indicate unmitigated Attacks.

Additional Information

  • BIG-IP AFM divides the configured Thresholds for DoS profiles by the number of TMMs, so per-TMM thresholds may trigger events earlier than expected.
  • Attack IDs are generated after statistics sampling (typically every minute), and events with "Attack ID = 0" are expected when thresholds are not met or when drops occur before attack declaration.
  • BIG-IQ aggregates attack data, and granular details may require Analytics profile configuration.
