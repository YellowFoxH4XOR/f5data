Issue

If the MySQL system account is missing, the BIG-IP Application Security Module (ASM) may fail to start the MySQL service and the following message will be logged in the /var/lib/mysql/asm.<domain>.err log file:

[ERROR] Fatal error: Can't change to run as user 'mysql' ; Please check that the user exists!

When this occurs, most BIG-IP ASM functions will not work properly.

To resolve this issue, you can add the MySQL system account by performing the following procedure:

  1. Log in to the command line.
  2. Add the MySQL system account by typing the following command:

    /usr/libdata/ucs_convert/06000001_mysql_user

  3. Start the MySQL service by typing the following command:

    bigstart start mysql

The MySQL service should now start and the error message should no longer occur.
