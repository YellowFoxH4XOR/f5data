K000141239: Enabling monpd debugging

Type
Support Solution
Published
2024-09-30
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP Analytics
Source

Description

In rare instances, F5 Support may ask to enable additional debugging level for the monpd daemon.

Environment

AVR, or at least one of the modules that leverages AVR (including AFM, ASM, APM, and PEM), is provisioned.

Procedure

Enabling monpd debugging

Impact of procedure: The extra logging can cause some additional load (particularly I/O load) on the unit.

 

  1. Make a backup of the monpd logging file:

cp /etc/avr/monpd/monpd_logger.cfg /etc/avr/monpd/monpd_logger.cfg.bak

 

  1. Edit the /etc/avr/monpd/monpd_logger.cfg file 
    • Change these settings:

GENERAL                INFO
DB                     INFO
REPORTER               INFO

    •  To these:

GENERAL                DEBUG
DB                     DEBUG
REPORTER               DEBUG

  1. Return to the CLI and force AVR to reload its configuration files using these commands:

tmsh modify sys db md.dologging value 0
tmsh modify sys db md.dologging value 1

 

Note: This does not require a monpd restart.  Additional messages will be logged to the /var/log/avr/monpd.log file.

Disabling monpd debugging

  • To restore the previous monpd logging configuration:

cp /etc/avr/monpd/monpd_logger.cfg.bak /etc/avr/monpd/monpd_logger.cfg
tmsh modify sys db md.dologging value 0
tmsh modify sys db md.dologging value 1

 

Note: This does not require a monpd restart.
