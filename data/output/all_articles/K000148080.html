K000148080: Why are the IPs of malicious users flagged as High not being blocked?

Source

What Happened?

You want to block the users that are flagged as High risk in the security dashboard, on "malicious Users" tab.

 

Environment

  • Malicious Users
  • F5® Distributed Cloud Console

Resolution/Answer

In order to block the IP address(es) that are flagged as High risk you have to configure:

  1. The "User Identifier" (Under the configuration of the selected Load Balancer > Common Security Controls > User Identifier) as "Client IP address".
  2. The "Malicious User Detection" (Under the configuration of the selected Load Balancer > Common Security Controls > Malicious User Detection) Enabled .
  3. The "Challenge type" (Under the configuration of the selected Load Balancer > Common Security Controls > Challenge type) enabled in one of the 3 options
    1. JavaScript challenge (common)
    2. Captcha challenge (common)
    3. Policy-based challenge

Once enabled, the IP addresses that get the tag as High Risk will be blocked for 20 minutes (the so-called Cooling Off Period).
