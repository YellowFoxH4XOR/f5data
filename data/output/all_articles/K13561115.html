Description

CPU Temperature related values are not supported for iSeries platfroms and Herculon platforms so that following db keys are not supported

  • sys db platform.cpu.temperature.threshold
  • sys db platform.cpu.fanspeed.threshold

NOTE: You should leave the CPU temperature and CPU fan speed database threshold variables of those platforms at the default value of 0 (zero). Changing the values will not have any effect on the BIG-IP  and Herculon systems.

Also, CPU Temperature OID is not supported.
