K000148818: /config/gtm/server.crt cert is truncated after performing bigip_add

Type
Support Solution
Published
2024-12-03
Updated
2026-06-07
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.1.3
Source
https://my.f5.com/manage/s/article/K000148818

Description

Server.crt file become truncated after bigip_add is perform.

  • The number of certificates in server.crt reduces.
  • IQUERY between GTM and remote BIG-IP System maybe broken if CA certs are truncated

Environment

  • GTM
  • BIG-IP system

Cause

bigip_add does not process certs(/config/gtm/server.crt) with CRLF (/r/n) and omit copying while creating temp file. Those certs get deleted without any error or warning. The bugid is ID1756389. 

Recommended Actions

  1.  Please open SR to request hotfix for ID1756389.
  2. or alternative, please ensure CRLF is remove from server.crt

Additional Information

For example,
