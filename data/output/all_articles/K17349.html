Known Issue

The ZebOS Network Services Module (NSM) process may use 100 percent CPU and stop responding.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system to use ZebOS Border Gateway Protocol (BGP) routing.
  • The BGP configuration contains a recursive next-hop.

Impact

ZebOS imish becomes unresponsive to commands, and the NSM process may fail to update routes.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The NSM process is at or near 100 percent, as seen from the output of the top command line utility.

    For example:

    PID USER      PR  NI  VIRT  RES  SHR S %CPU %MEM    TIME+  COMMAND
    12345 root      20   0 14652 3264 1980 R 92.4  0.0   0:11.17 nsm

  • Within minutes of manually restarting the tmrouted process, the problem returns.
