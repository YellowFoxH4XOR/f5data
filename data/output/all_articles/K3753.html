Note: This article applies only to platforms with a switch card control processor (SCCP). To determine if a specific hardware platform has an SCCP, refer to K9476: The F5 hardware/software compatibility matrix. If your platform has an AOM subsystem, refer to K9608: Configuring AOM network access (800, 1600, 3600, 6900, 89XX, 11000, 11050 series platforms).

Configuring the SCCP IP address using the serial console

To configure the switch card control processor (SCCP) from the serial console so that it can be accessed over the network, perform the following procedure:

  1. Access SCCP by following the Accessing SCCP from the console instructions specified in K3454: Overview of the SCCP.
  2. Type N to select the SCCP network configurator option.

    Note: The N option is not displayed when you are connected through SSH; it is available only when you access it through the console.
  3. Enter the requested configuration information, as prompted. The SCCP IP address must be different than the BIG-IP management address, but they must be on the same IP subnet.

    For example:

    SCCP Linux Management Network Configurator

    Use DHCP? n
    Host name (optional): test.askf5.com
    IP address (required): 10.90.101.21
    Network mask (required): 255.255.255.0
    Broadcast IP address (optional): 10.90.101.255
    Default gateway IP address (optional): 10.90.101.1
    Nameserver IP address (optional): 10.90.105.50
    Nameserver IP address (optional):
  4. Test the SCCP login by opening an SSH session to the IP address that you configured. Access SCCP using the management port and the same login credentials that you use for the BIG-IP root account.

Configuring the SCCP IP address using SSH

To configure the switch card control processor (SCCP) using SSH so that it can be accessed over the network, perform the following procedure:

  1. Log in to the command line using the root account.
  2. Login in to the SCCP by typing the following command:

    ssh sccp
  3. To begin configuring the SCCP IP address, type the following command:

    netconfig
  4. Enter the requested configuration information, as prompted. The SCCP IP address must be different than the BIG-IP management address, but they must be on the same IP subnet.

    For example:

    SCCP Linux Management Network Configurator

    Use DHCP? n
    Host name (optional): test.askf5.com
    IP address (required): 10.90.101.21
    Network mask (required): 255.255.255.0
    Broadcast IP address (optional): 10.90.101.255
    Default gateway IP address (optional): 10.90.101.1
    Nameserver IP address (optional): 10.90.105.50
    Nameserver IP address (optional):
  5. To make the changes effective, type the following command:

    /etc/rc.network

    Note: You may receive an error message indicating SIOCADDRT: File exists. This error message is benign and can be ignored.
  6. Test the SCCP login by opening an SSH session to the IP address that you configured. Access SCCP using the management port and the same login credentials that you use for the BIG-IP root account.
