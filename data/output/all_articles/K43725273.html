K43725273: The BIG-IQ system has HTTP basic authentication disabled by default

Issue

Old Behavior

In versions prior to BIG-IQ Centralized Management 5.1.0, the system uses HTTP basic authentication, by default.

By default, the BIG-IQ system uses HTTP basic authentication for HTTP/HTTPS requests to the representational state transfer (REST) framework.

New Behavior

Beginning in BIG-IQ Centralized Management 5.1.0, the system has HTTP basic authentication disabled, by default.

With this change, the BIG-IQ system has, by default, disabled basic authentication for HTTP/HTTPS requests to the REST framework. This is a security enhancement.

F5 Product Development tracked this change as ID 598057.

Impact

  • When sending REST requests using HTTP basic authentication to a BIG-IQ device that runs 5.1.0 or later, you will receive an HTTP Error 401.
  • When you upgrade the BIG-IQ system to 5.1.0 or later, the system will have HTTP basic authentication disabled.

Recommended Actions

To continue to use the BIG-IQ system with basic HTTP authentication disabled, the peer systems can send REST requests by using the BIG-IQ system authentication token. For more information about the BIG-IQ authentication token, refer to K04452074: Overview of using the BIG-IQ system authentication token.

Alternatively, you can re-enable the HTTP basic authentication. However, this would potentially expose the BIG-IQ system to security issues related to HTTP basic authentication.

Enabling HTTP basic authentication

Impact of recommended actions: This procedure will potentially expose the system to security issues related to HTTP basic authentication, and F5 recommends that you carefully assess the security of your environment before you enable HTTP basic authentication.

  1. Log in to the Advanced Shell (bash) as Administrator.
  2. Type the following command:

    set-basic-auth on

Impact of recommended actions: After you disable HTTP basic authentication, a peer device can no longer use HTTP basic authentication to send REST requests to this device.

  1. Log in to bash as Administrator.
  2. Type the following command:

    set-basic-auth off
