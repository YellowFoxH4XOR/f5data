Issue

When linearization is enabled for PDF files, the BIG-IP WebAccelerator may report the following warning messages to the /var/log/wa/pvac.log file (in 9.4.x) or the /var/log/user.log file (in 10.0.x):

Warning: stream operator not terminated by valid EOL.

This warning message comes from Ghostscript, which is used to perform PDF linearization. The message is benign, and indicates the OWS is serving poorly formed PDF files. 

You may be able to resolve this issue by disabling PDF linearization or suppressing the messages. For more information about disabling PDF linearization, refer to K9408: Enabling and disabling PDF linearization on the BIG-IP WebAccelerator. If you want to suppress the messages in version 10.x., refer to K10534: Filtering BIG-IP WebAccelerator pvac log messages. You can suppress the messages in version 9.4.x by editing the syslog-ng template using the procedure detailed in K10218: Filtering BIG-IP WebAccelerator pvac log messages; however, this option is not recommended, and should be used as a last resort when PDF linearization cannot be disabled.
