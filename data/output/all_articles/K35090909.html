Description
How to check virtual servers in different partition from command line? 

For a /Common partition, following command works.
 # tmsh list ltm virtual

Environment

  • List configuration items
  • Command Line
  • Partition

Cause
None

Recommended Actions

  • Add partition name after the command:
    # tmsh list ltm virtual /partition/* 
    Note * is required for this command.

    For example, if there is a RD10 partition, the command will be:
    # tmsh list ltm virtual /RD10/*
  • Alternatively, to view virtual servers in any partition replace the partition name with *
    # tmsh list ltm virtual "/*/*" 
    Note: the double quotes are required for this command when entered from the BIG-IP command line. They are not necessary when entering the command from the tmsh command line.

    For example, to view all virtual servers in any partition, the command will be:
    # tmsh list ltm virtual "/*/*"
  • In the case for virtual server resources deployed through an iApp, add the partition and iApp names after the command:
    # tmsh list ltm virtual /partition/iApp/* 
    Note * is required for this command.

    For example, if there is a RD10 partition and myiAppname iApp, command will be:
    # tmsh list ltm virtual /RD10/myiAppname/*
  • Alternatively, to view virtual server resources deployed through an iApp in any partition replace the partition, iApp, and virtual server name with *
    # tmsh list ltm virtual "/*/*/*" 
    Note: the double quotes are required for this command when entered from the BIG-IP command line. They are not necessary when entering the command from the tmsh command line.

    For example, to view resources deployed through an iApp in any partition, the command will be:
    # tmsh list ltm virtual "/*/*/*"
