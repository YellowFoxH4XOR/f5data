Description

  • I want to know how I can find support tickets in the F5® Distributed Cloud (XC) Console

Environment

  • F5® Distributed Cloud (XC) Console

Answer/Recommended Actions

To find support tickets in the F5® Distributed Cloud (XC) Console:

  1. Access your XC Console
  2. Go to Home -> Administration -> Support
  3. In the left sidebar click on Requests
  4. A list with all your support tickets opened via XC Console will appear
