Known Issue

BIG-IP VE systems may experience packet drops for traffic traversing a tagged VLAN.

This issue occurs when the following conditions are met:

  • The BIG-IP VE image is running on an ESX platform.
  • The ESX platform contains particular network hardware. For example, this issue is known to occur with systems using the Broadcom BCM57800 or BCM57810 NICs.

Impact

Packet drops during a high volume of data transfer.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The 'rxbadsum' counts increase as the affect traffic is ignored by TMM.

    For example, the tmctl profile_bigproto_stat command indicates that the 'rxbadsum' counts are increasing over time.

  • The BIG-IP VE is experiencing packet drops.

Workaround

To work around this issue, you can disable LRO/GRO on the hypervisor system. To do so, perform the following procedure:

Impact of workaround: Disabling LRO/GRO on the hypervisor may increase the CPU overhead for TCP/IP network operations and affect the performance of guests running on the system.

  1. Log in to the ESX/ESXi shell on the hypervisor host.
  2. Run the following shell commands:

    esxcli system settings advanced set -o /Net/Vmxnet2HwLRO -i 0
    esxcli system settings advanced set -o /Net/Vmxnet3HwLRO -i 0
    esxcli system settings advanced set -o /Net/Vmxnet2SwLRO -i 0
    esxcli system settings advanced set -o /Net/Vmxnet3SwLRO -i 0
    esxcli system settings advanced set -o /Net/VmxnetSwLROSL -i 0

  3. Reboot the hypervisor host.
