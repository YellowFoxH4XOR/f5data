K15433801: Web Acceleration caching profile is not caching information

Type
Support Solution
Published
2020-02-07
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.0
Source
https://my.f5.com/manage/s/article/K15433801

Description

Web Acceleration may fail to cache information if ASM is also in use and policy builder learning suggestions. 

Environment

  • Virtual server has a Web Acceleration profile
  • Virtual server has an ASM or advanced WAF security policy
  • Security policy is using the Automatic Policy Builder or has learning enabled.

Cause

When the Security Policy is in an unstable state, caching is disabled to prevent caching of incorrect or undesired information.

Recommended Actions

  1. No action is required.  Caching will be re-enabled when policy builder finishes.
  2. Caching can be re-enabled by deactivating policy builder or by disabling learning.

None
