Known Issue

The active BIG-IP system may reset mirrored connections unexpectedly.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP system as a high availability (HA) pair.
  • You use an iRule to determine the load-balanced destination.
  • You enable connection mirroring for the virtual server.
  • The mirrored connection on the standby unit times out due to a connection state mismatch with the active unit connection table.

Impact

The active BIG-IP system resets the established connection.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When analyzing a network level capture of the connection reset, the active BIG-IP virtual server sends a reset with the HA Expire flow reset cause.

    For example:
