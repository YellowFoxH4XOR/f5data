K000151515: VIP Traffic Not Forwarding to Backend Pool Members on Different VLAN/Route Domain

Description

Traffic sent to a BIG-IP LTM Virtual IP (VIP) is not forwarded to backend pool members when the VIP and pool members are on different VLANs or subnets. This occurs even though firewall rules allow connectivity between the relevant networks, and SNAT is configured. Traffic reaches the VIP but does not reach the intended pool members

Environment

  • Product: BIG-IP LTM
  • Route domains in use to avoid overlapping network IP address spaces
  • Strict Isolation enabled on route domains

Cause

Strict Isolation was enabled on one or more route domains. When Strict Isolation is active, it prevents traffic from crossing route domain boundaries, which blocks forwarding of VIP traffic to pool members located in different route domains.

Recommended Actions

  • To permit cross-route domain traffic, disable Strict Isolation on both source and destination route domains.
