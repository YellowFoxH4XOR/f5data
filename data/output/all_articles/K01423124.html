Known Issue

The BIG-IP APM Configuration utility may become unresponsive.

This issue occurs when one of the following conditions is met:

  • You use the BIG-IP APM Configuration utility to delete user account(s) from the local user database.
  • You use the BIG-IP APM Configuration utility to create or modify the BIG-IP APM configuration.

Impact

The Configuration utility becomes unresponsive and/or may display a warning message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After making configuration modifications using the BIG-IP APM Configuration utility, a warning message that appears similar to the following example displays:

    This BIG-IP system has encountered a configuration problem that may prevent the Configuration utility from functioning properly.

    To prevent adverse effects on the system, F5 recommends that you restrict your use of the Configuration utility to critical tasks only until the issue is resolved. Attempting to modify your configuration in this state with the Configuration utility may overwrite your configuration.

  • You are unable to access the BIG-IP APM Configuration utility.
  • The system logs an error message to the /var/log/tomcat/catalina.out file at the time of the occurrence:

    ERROR [TP-Processor<numeric value>] util.SystemSettings:getStartPageName - Unable to retrieve UI Start Screen value from BigDB.

Workaround

To work around this issue, you can restart the tomcat service or reboot the affected device. To do so, perform the following procedure:

Impact of workaround: The BIG-IP APM Configuration utility will be unavailable while the tomcat service restarts.

  1. Log in to the Traffic Management Shell (tmsh).
  2. To restart the tomcat service, type the following command:

    restart /sys service tomcat

  3. To exit the tmsh utility, type the following command:

    quit
