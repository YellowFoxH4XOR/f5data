Topic

This article covers the compatibility of the BIG-IQ 4.0.0-4.5.0 and BIG-IQ Cloud and Orchestration 1.0.0 products with BIG-IP releases.

For BIG-IQ Centralized Management 4.6.0 and later, refer to K34133507: BIG-IQ Centralized Management compatibility matrix.

For the considerations on the upgrade compatibility of BIG-IQ or iWorkflow product offerings, refer to K21232150: Considerations for upgrading BIG-IQ or F5 iWorkflow.

Description

The BIG-IQ products support several modules, and provide central management for the BIG-IP system.

Beginning in BIG-IQ 4.5.0, the BIG-IQ Security product separated BIG-IP supported versions into the Network Security module and Web Application Security module.

For more information about the BIG-IQ system supporting the upgrade of legacy BIG-IP devices, refer to K16239: BIG-IQ supports the upgrade of legacy BIG-IP devices running 10.2.0 or later.

As of November 2015, the BIG-IQ product line is divided into two products: BIG-IQ Cloud and Orchestration and BIG-IQ Centralized Management. For more information, refer to K05211126: Introducing new BIG-IQ Cloud and BIG-IQ Centralized Management product offerings.

For a summary of expected limitations and new compatible features between the BIG-IQ and BIG-IP releases, refer to the following sections:

  • BIG-IQ Cloud and Orchestration
  • BIG-IQ ADC
  • BIG-IQ Cloud
  • BIG-IQ Device
  • BIG-IQ Security
