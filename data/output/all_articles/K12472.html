Known Issue

This is the result of a known issue. When you configure the Encrypt Cookies field of an HTTP profile with a cookie name that includes a period character ( . ) and you click the Create or Update button, the Configuration utility will return the following error message:

Bad Characters. Only the following special characters are allowed: dash and underscore (-_). Multiple arguments should be separated by spaces

As a result, the HTTP profile will not be created or updated. A few examples of cookie names that contain a period character include the following:

my.cookie

encrypt.cookie

my.http.cookie

F5 Product Development tracked this issue as ID 345053, and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

You can work around this issue by creating or modifying the HTTP profile in question through the BIG-IP command line. To do so, perform the following procedures:

Creating a new HTTP profile

  1. Log in to the BIG-IP command line using a privileged account, such as root.
  2. To create a new HTTP profile, type the following command that applies to your version:

    • BIG-IP version 10.x

      tmsh create ltm profile http <http profile name> encrypt-cookies add {<cookie name>} encrypt-cookie-secret <passphrase>

      For example, to create the v10-myencryptcookie-http HTTP profile to encrypt the my.cookie cookie using passphrase testing123, you would type the following command:

      tmsh create ltm profile http v10-myencryptcookie-http encrypt-cookies add {my.cookie} encrypt-cookie-secret testing123

    • BIG-IP versions 9.4.0 through 9.4.8

      bigpipe profile http <http profile name> {encrypt cookies <cookie name> cookie secret <passphrase>}

      For example, to create the myencryptcookie-http HTTP profile to encrypt the my.cookie cookie using passphrase testing123, you would type the following command:

      bigpipe profile http myencryptcookie-http {encrypt cookies my.cookie cookie secret testing123}

  3. To save the configuration, type the following command that applies to your version:

    • BIG-IP versions 10.1.0 and later

      tmsh save sys config

    • BIG-IP version 10.0.x

      tmsh save config

    • BIG-IP versions 9.4.0 through 9.4.8

      bigpipe save all

Modifying an existing HTTP profile

  1. Log in to the BIG-IP command line using a privileged account, such as root.
  2. To modify an existing HTTP profile, type the following command that applies to your version:
    • BIG-IP version 10.x

      tmsh modify ltm profile http <http profile name> encrypt-cookies replace-all-with {<cookie name>} encrypt-cookie-secret <passphrase>

      For example, to modify the v10-mycookie-http HTTP profile to encrypt the my.newcookie cookie using passphrase abc123, you would type the following command:

      tmsh modify ltm profile http v10-mycookie-http encrypt-cookies replace-all-with {my.newcookie} encrypt-cookie-secret abc123

    • BIG-IP versions 9.4.0 through 9.4.8

      bigpipe profile http <http profile name> {encrypt cookies <cookie name> cookie secret <passphrase>}

      For example, to modify the mycookie-http HTTP profile to encrypt the my.newcookie cookie using passphrase abc123, you would type the following command:

      bigpipe profile http mycookie-http {encrypt cookies my.newcookie cookie secret abc123}

  3. To save the configuration, type the following command that applies to your version:

    • BIG-IP versions 10.1.0 and later

      tmsh save sys config

    • BIG-IP version 10.0.x

      tmsh save config

    • BIG-IP versions 9.4.0 through 9.4.8

      bigpipe save all
