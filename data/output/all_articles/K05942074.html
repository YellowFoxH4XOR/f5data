Description

Applying HSTS enabled option in HTTP profile without client SSL profile to Virtual Server and save the config or load config, Configuration Utility (GUI) or /var/log/ltm log shows below message.
Upgrading from a previous version to version 12.1.5 can cause this error.

Environment

  • BIG-IP v12.1.5 and later
  • Create or modify an HTTP profile with HTTP Strict Transport Security (HSTS) option enabled
  • Create or modify a virtual server without client ssl profile and try to apply to the newly created HTTP profile or modify existing HTTP profile to enalbe HTTP strict Transport Security (HSTS) and save the config.

Cause

HTTP profile HSTS option by nature requires SSL profile. So, the Virtual Server must support SSL if HSTS option is used in the HTTP profile applied.

Recommended Actions

Either way, based on business need

  • Add client ssl profile
  • Disable HSTS option in the http profile if the virtual server does not support SSL.

Additional Information

Not Applicable.
