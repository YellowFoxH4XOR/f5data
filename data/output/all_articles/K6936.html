Known Issue

This is the result of a known issue. Remote Shell (RSH) is a command line program that allows you to execute shell commands as another user, and on another computer, across a network.

Note: RSH is disabled by default on the BIG-IP and 3-DNS systems.

If RSH (port 514) is enabled and then later disabled, ports 512 (login) and 513 (exec) are still active and listening.

When the RSH ports are scanned, a reset should be sent. This behavior, however, does not occur. Instead, the daemon accepts the connection rather than sending a reset. The daemon then issues a FIN a second after the connection as been accepted and established, because ports 512 and 513 are still active and listening.

F5 Networks Product Development is tracking this issue as CR72647 and it is scheduled to be fixed in a future version. To monitor the status of this CR, refer to the BIG-IP, 3-DNS, or Link Controller Release Notes.

Workaround

To work around this issue, you can disable the RSH from the command line and restart the system daemons, by performing the following procedure:

  1. Disable RSH by typing the config command from the command line and selecting U.
  2. Select Disable access via RSH.
  3. Select Q to exit the Configuration utility.
  4. Change directories to the /etc/ directory by typing the following command:

    cd /etc/

  5. Using a text editor, edit the inetd.conf file.
  6. Locate the following lines:
    login   stream  tcp     nowait  root    /usr/libexec/tcpd       rlogind -a
exec    stream  tcp     nowait  root    /usr/libexec/tcpd       rexecd
  7. Comment out the lines above, as follows:
    #login   stream  tcp     nowait  root    /usr/libexec/tcpd       rlogind -a
#exec    stream  tcp     nowait  root    /usr/libexec/tcpd       rexecd
  8. Save the changes to the inetd.conf file.
  9. Restart the system daemons, by typing the following command:

    bigstart restart

Note: This procedure will cause an active unit to failover to the partner unit. F5 Networks recommends that this procedure be performed during a maintenance window.
