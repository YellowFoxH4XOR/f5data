K9508: Signatures that are in a staging state are always run against incoming requests

Topic

BIG-IP ASM signatures that are in a staging state are always run against incoming requests, regardless of whether another policy configuration is defined that would exclude all or a portion of the signature from being run.

For example, if a parameter level signature is defined as Disabled against a specific parameter, the signature will still be run against the disabled parameter if the signature is currently in a staging state.

Once the signature leaves the staging state, or if staging has been disabled, the signature will behave as specified in the policy. Therefore, if the signature is enabled globally, it will be run against all requests except those for which the specific parameter has been disabled. If it encounters the specific parameter for which the policy has been configured to ignore (Disabled), no violation will be reported, which will prevent false positives.

This behavior is by design and is intended to give an accurate count of the number of times a signature in staging would be triggered when receiving the specific parameter it is searching for, regardless of any other policy configuration.
