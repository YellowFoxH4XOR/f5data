Description

Blade 0 hardware sensor critical alarm alerts observed, but show sys hardware command shows PSUs as Up

  • show /sys alert
    ----------------------------------------------------------------------------
    Sys::LCDAlerts
    Slot          Timestamp  Priority         Id                      Description
    ----------------------------------------------------------------------------
    0     02/02/22 21:47:34  critical  0x12a0013  Blade 0 hardware sensor critical alarm: Power Supply 2 GPIO status(FND850): Bad (FDIP)
  • show /sys hardware
Sys::Hardware
Chassis Power Supply Status
  Index  Status           Current
  1      up               DC
  2      up               DC
  • Log messages observed in /var/log/ltm showing a Bad status, immediately followed by a Good status on the PSU:

    /var/log/ltm:
    crit chmand[17816]: 012a0013:2: Blade 0 hardware sensor critical alarm: Power Supply 2 GPIO status(FND850): Bad (FDIP)
    notice chmand[17816]: 012a0016:5: Blade 0 hardware sensor notice: Power Supply 2 GPIO status(FND850): Good

Environment

  • BIG-IP 10000 Series platform (D112/D113)
  • The system has one or more PWR-0149 / FND850 DC PSUs installed

Cause

This issue is cosmetic in nature and not indicative of a problem with the PSU. 

Recommended Actions

To confirm that the error you receive is cosmetic only, and to verify the Chassis Power Supply Status for each installed PSU is 'up,' you can view the output of the following command:
 tmsh show sys hardware 

If the PSU is showing as Up, the condition causing the alert message has been cleared.  To clear the alert message on the BIG-IP, please refer to K11094: Clearing the LCD and the Alarm LED remotely

If the issue persists you should contact F5 Support to request an RMA of the PSU, as the replacement FRUs contain new firmware, which eliminates these messages.

Additional Information

  • K33736814: BIG-IP 10000 series platforms may generate PSU error messages indicating high current or high voltage readings
