K000137114: Health Monitor not coming up without configuring Username & Password

Published

Status

Applies to

Source

Description

HTTPs health monitor is failing without domain credential.

Other HTTPs monitors for same pool member working for other directory is working without domain credential.

 

Environment

  • BIG-IP
  • HTTPs monitor

Cause

  • Backend server's requirement. (BIG-IP has no function to request backend server for authentication.)

Some directory checked by the monitor requires credentials.
 

Recommended Actions

  • Request backend server engineer to have monitor specific account and password.
     

Additional Information

  • K2167 : Constructing HTTP requests for use with the HTTP or HTTPS application health monitor
