K000149087: Create a valid string of Ciphers, KexAlgorithms, and MACs to use as part of the SSHD configuration.

Applies to

Source

Description

This article explains how to modify the SSH daemon configuration on the F5 BIG-IP system, specifically focusing on constructing a configuration string for the sshd service using ssh -Q query commands.  This is helpful when administrators want to efficiently customize parameters such as encryption ciphers, message authentication codes (MACs), and key exchange algorithms.

Environment

  • F5 BIG-IP LTM 
  • SSH Client
  • Ciphers, MACs and KexAlgorithms

Cause

None. Informational only.

Recommended Actions

  1. Retrieve the existing SSH daemon configuration using the following command:
    list /sys sshd all-properties
  2. On a Linux / Windows machine with a SSH client, run the ssh -Q command to identify available options for Ciphers, MACs, and KexAlgorithms. Example:
     
    ssh -Q cipher
ssh -Q mac
ssh -Q kex
    This in an output example:
    > ssh -Q ciphers
    3des-cbc
    aes128-cbc
    aes192-cbc
    aes256-cbc
    aes128-ctr
    aes192-ctr
    aes256-ctr
    aes128-gcm@openssh.com
    aes256-gcm@openssh.com
    chacha20-poly1305@openssh.com
  3. Based on the query results, build a string specifying the desired parameters. For instance:
    include "Ciphers 3des-cbc,aes128-cbc,aes192-cbc,aes256-cbc,aes128-ctr,aes192-ctr,aes256-ctr,aes128-gcm@openssh.com
MACs hmac-sha2-256,hmac-sha2-512,hmac-md5,hmac-md5-96,umac-64@openssh.com,umac-128@openssh.com,hmac-sha2-256-etm@openssh.com
KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384,ecdh-sha2-nistp521,curve25519-sha256,curve25519-sha256@libssh.org"
  4. From tmsh, use the following command to edit the SSH daemon configuration. This will open ta Vi text editor. Locate and modify the "include" parameter to use the new string.
     
    edit /sys sshd all-properties
  5. Finally, save changes:
    save sys config

The result of these changes should look something similar to the below:
# list sys sshd all-properties
sys sshd {
    allow { ALL }
    banner disabled
    banner-text none
    description none
    fips-cipher-version 0
    inactivity-timeout 0
    include "Ciphers 3des-cbc,aes128-cbc,aes192-cbc,aes256-cbc,aes128-ctr,aes192-ctr,aes256-ctr,aes128-gcm@openssh.com
    MACs hmac-sha2-256,hmac-sha2-512,hmac-md5,hmac-md5-96,umac-64@openssh.com,umac-128@openssh.com,hmac-sha2-256-etm@openssh.com
    KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384,ecdh-sha2-nistp521,curve25519-sha256,curve25519-sha256@libssh.org"
    log-level info
    login enabled
    port 22
}


Note: To revert back to the default values, use the below command:
tmsh modify /sys sshd include none

Additional Information

The include statement is the line in the TMOS sys sshd configuration where you can include a list of specific encryption ciphers, KEX algorithms, or MAC algorithms into the /config/ssh/sshd_config configuration file. The keywords Ciphers, KexAlgorithms, and MACs are used with the include statement when you specify a list of desired ciphers, KEX algorithms, or MACs. These override pre-existing keywords in the /config/ssh/sshd_config configuration file.

Note: F5 does not support editing the /config/ssh/sshd_config file directly. This is an auto-generated file.
