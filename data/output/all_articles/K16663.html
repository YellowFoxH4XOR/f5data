Issue

Error Message

01070734:3: Configuration error: In Virtual Server (<vs name>) HTTP is configured as a Transparent Proxy, and thus is incompatible with any other filter other than PEM.

In this error message, note the following:

  • <vs name> is the name of the affected virtual server.

For example:

01070734:3: Configuration error: In Virtual Server (/Common/web-virtual) HTTP is configured as a Transparent Proxy, and thus is incompatible with any other filter other than PEM.

Message Location

You may encounter this message in the following locations:

  • The Configuration utility
  • The /var/log/ltm file
  • The Traffic Management Shell (tmsh)

Description

This message occurs when one of the following conditions is met:

  • You initially associate a virtual server with an HTTP profile that is configured with Transparent proxy mode. Then, you associate the same virtual server with another profile (such as Analytics, Adapt, or Statistics).
  • You initially associate a virtual server with an HTTP profile that is configured with either Reverse (by default) or Explicit proxy mode, as well as other profiles (such as Analytics, Adapt, or Statistics). Then, you change the proxy mode of the HTTP profile to Transparent.

When an HTTP profile is configured with Transparent proxy mode, the BIG-IP system does not validate HTTP content and allows invalid HTTP traffic to be forwarded to the backend server (instead of dropping the connection). As a result, other profiles that require HTTP content validation or inspection cannot function with an HTTP profile that is configured with Transparent proxy mode.

The HTTP Transparent proxy mode is typically used in certain BIG-IP PEM scenarios which may allow HTTP traffic from non-browser clients to be forwarded to the backend server.

Impact

Users cannot associate a virtual server with an HTTP profile that is configured with Transparent proxy mode and other profiles (such as Client SSL, Server SSL, OneConnect, and HTTP security, Analytics, Adapt, or Statistics); this behavior is by design.
