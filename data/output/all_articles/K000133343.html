K000133343: FQDN nodes incompatible with non-default Route Domains

Type
Support Solution
Published
2023-04-03
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000133343

Description

Creating a FQDN node in a non-default/zero route domain is currently unsupported.
FQDN nodes are not currently compatible with non-default route domains. When attempted to add the '%<RD-id>' at the end of FQDN in the 'address' tab, you will get a mcpd error message like this in GUI: "0107189a:3: Invalid FQDN: myfqdnnode.f5.org%10"
 

Environment

  • BIG-IP system (all versions)
  • FQDN Node
  • Route Domains

Cause

There is an existing RFE (request for enhancement) ID for this feature created previously upon requests from customers over past few years however it has not yet been implemented by F5 Product Development team.

 

ID522465 RFE: Route domain support for FQDN nodes

 

 Recommended Actions

If you would like to benefit from implementation of this feature in future software releases, please feel free to create a service request with support team requesting to link your account and ticket to this ID.
