Issue

Error Message

err get_dossier[<PID>]: 01170020:3: Option -<opt> requires an argument.

In this error message, note the following:

  • <PID> is the process ID for the get_dossier daemon.
  • <opt> is the option specified when using the get_dossier utility.

For example:

err get_dossier[12019]: 01170020:3: Option -k requires an argument.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file.

Description

This message occurs when the following condition is met:

  • You specify an option for the get_dossier utility that requires an argument but omit the argument.

If you specify an option that requires an argument when executing the get_dossier utility, but omit the required argument, the BIG-IP system logs this message and reports a list of supported arguments on the command line.

For example:

usage: get_dossier -b "basekey1,basekey2,..." -a "actkey1,actkey2,..." -i "inactkey1,inactkey2,..." -f "certificate-request-file" [-c] [-u] [ -k <kernel_version> ] [ -v "<product> <version> <build>"]

Impact

The get_dossier utility fails to generate the dossier.

Recommended Actions

Review the usage details provided on the command line and include the required arguments for the options. For more information about using the get_dossier utility, refer to K2595: Activating and installing a license file from the command line.
