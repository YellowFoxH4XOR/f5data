Source
https://my.f5.com/manage/s/article/K09220134

Description
The following error message occurs after adding and publishing a line in the LTM policy to disable bot-defense to all rules of the policy:

010716d9:3: Virtual server <virtual server name> requires a profile of type bot defense for ltm policy <LTM policy name>

Environment

  • BIG-IP ASM
  • Bot-defense profile
  • LTM policy

Cause
A bot defense profile must be assigned to the virtual server name.

Recommended Actions
Assign a bot defense profile to the virtual server name before publishing LTM policy, the default "bot-defense" will do just fine.

Additional Information
None
