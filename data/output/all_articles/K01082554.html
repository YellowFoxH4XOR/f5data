Description

F5 Hourly Pre-Licensed Images on Cloud environment may throw license validation error if you try to move the license. Especially if the image is rolled back to the lower version. 
An error message similar to below is logged.

01180002:3: License validation error 298.
01180010:3: [license processing][error]: license verification failed 
01180010:3: [license processing][error]: failed processing license management data

Environment

  • License is inoperative
  • Cannot reactivate the license 
  • Cloud environment

Cause

This is due to images that are pre-licensed and associated with a specific site, the license cannot be moved and the license becomes unstable and reactivation fails.  

Recommended Actions

To work around the issue, spin up a new pre-licensed instance. 

Additional Information

None.
