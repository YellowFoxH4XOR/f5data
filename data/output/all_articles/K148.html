Topic

Some features require specifying a date and time using UNIX time (seconds since 1970-01-01 00:00:00 UTC, which is otherwise known as the start of the current Unix epoch). To convert the current time into UNIX time, perform one of the following two procedures:

  • Using the date command
  • Using the perl command

Using the date command

To convert the current time into UNIX time using the date command, type the following command from the command line:

date +%s

For example, if you run the command on Tuesday, August 31 at 10:37:54 PDT 2010, a string similar to the following is displayed, indicating the number of seconds that have elapsed since the start of the current epoch:

1283276274

Using the perl command

To convert the current time into UNIX time using the perl command, type the following command from the command line:

perl -e 'print time . "\n"'

For example, if you run the command on Tue Aug 31 10:37:54 PDT 2010, a string similar to the following is displayed, indicating the number of seconds which have elapsed since the start of the current epoch:

1283276274

Converting an arbitrary date and time into UNIX time

To convert an arbitrary date and time into UNIX time, type the following command from the command line where <STRING> is the date to be converted:

date -d <STRING> +%s

For example, to convert January 01, 00:00:00 EST 2011 into UNIX time, you would type the following command from the command line:

date -d "Jan 01 00:00:00 EST 2011" +%s

A string similar to the following is displayed, indicating the number of seconds that have elapsed since the start of the current epoch:

1293858000

Other valid date strings include the following:

sunday (or any other day of the week)
next-week
next-month
next-year
last-sunday (or any other day of the week)
last-week
last-month
last-year

Converting a Unix time string to a date and time

To check your conversion, you can convert a UNIX time string back into a date and time. To do so, type the following command from the command line where <STRING> is the Unix time string to be converted:

date -d @<STRING>

For example, to convert the UNIX time string 1293858000 to a date and time, you would type the following command from the command line:

date -d @1293858000

A date string similar to the following is displayed:

Fri Dec 31 21:00:00 PST 2010
