K000158167: Local Traffic Policy Editor: Pool and/or Virtual Server selection dropdown is grayed out/empty after upgrade to 17.1.3 or 17.5.1.3

Type
Support Solution
Published
2025-12-30
Updated
2026-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1, 17.1.3
Source
https://my.f5.com/manage/s/article/K000158167

Description

When attempting to create a Local Traffic Policy in the BIG-IP GUI, the "Forward traffic to pool" action dropdown may appear grayed out or empty, preventing selection of any pool. This issue occurs even when pools are present and healthy in the relevant partition. Users may observe that the dropdown does not populate with available pools, making it impossible to complete policy configuration via the GUI.

Environment

  • BIG-IP LTM
  • LTM Policy list

Cause

The issue is caused by a Bug ID 2078797, that is encountered in versions 17.1.3, 17.5.1.2 or 17.5.1.3. This issue prevents the Local Traffic Policy Editor from populating the selection dropdowns for certain configuration items such as pools and virtual servers.

Recommended Actions

Bug ID 2078797 is fixed in v17.1.3.1, 17.5.1.4 and v21.0.0.

Additional Information

Bug ID 2078797: LTM Policy actions fail to render in configuration utility (web UI)
