K73542261: How to tell if an upgrade to BIG-IQ version 7.x has successfully completed

Type
Support Solution
Published
2021-08-31
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K73542261

Description

This article will show how to confirm when a BIG-IQ upgrade from 5.4.x or 6.x to 7.x has successfully completed. User is unable to conclude the following after an upgrade:

  • When to login to WebUI and complete the setup
  • When the upgrade has completed

Environment

  • Upgrading from BIG-IQ 5.4.x - 6.x to 7.x

Cause

  • Part of Upgrade to 7.x is converting the TokuMX data to the new Postgress database. This process must complete before a user can log into the WebUI.

Recommended Actions

Users can monitor the bootstrap.out log  for a "BOOTSTRAP SUCCESSFUL" message. The upgrade process has completed when you observe "BOOTSTRAP SUCCESSFUL" message is displayed in the bootstrap log file.

For example:

             tail -f /var/log/bootstrap/bootstrap.out  |grep "BOOTSTRAP SUCCESSFUL"
