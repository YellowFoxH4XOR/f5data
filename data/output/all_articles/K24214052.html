Known Issue

NGINX Controller 2.0.0 installation fails when the host operating system (OS) locale is not UTF-8.

This issue occurs when the following condition is met:

  • You attempt to install NGINX Controller 2.0.0 on a system where the locale is a character encoding type other than UTF-8.

Impact

Installation appears to complete successfully, but the NGINX Controller system is unusable.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Log messages appear in the /var/log/nginx-controller/nginx-controller-install.log file, similar to the following example:

    database initialization failed.

    UnicodeDecodeError: 'utf-8' codec can't decode byte 0xf2 in position 0: invalid continuation byte

Workaround

To work around this issue, you can set your host locale to UTF-8. To do so, refer to the vendor documentation for the Linux distribution that you are using.

To view the current system locale configuration, use the localectl command. For example:

$ localectl
   System Locale: LANG=en_US.UTF-8
       VC Keymap: n/a
      X11 Layout: us
       X11 Model: pc105
