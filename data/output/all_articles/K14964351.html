K14964351: Draft policies may not show in Configuration Utility if REST interface is offline

Type
Support Solution
Published
2019-09-10
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K14964351

Description

BIG-IP Configuration Utility (GUI) won't refresh draft policies in cases where the REST functionality has been interrupted

Environment

  • BIG-IP
  • LTM Policies

Cause

The REST interface is inaccessible.  When the REST interface is not accessible there will be an error like the following in the restjavad-audit.log file:
[ForwarderPassThroughWorker] {"user":"tmos/admin","method":"DELETE","uri":"http://localhost:8100/mgmt/tm/ltm/policy/~Common~Drafts~example_policy/rules/example_rule","status":404,"from":"10.10.10.10"}

Recommended Actions

  1. Restart the httpd and tomcat daemons
    This can be completed from the command line with the following syntax:
    bigstart restart httpd tomcat
