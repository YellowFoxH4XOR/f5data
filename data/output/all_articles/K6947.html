Known Issue

This is the result of a known issue. If you use Internet Explorer 7 (IE7) to log in to FirePass, and you are placed into Protected Workspace (PWS) by a Pre-Logon Sequence, a warning message appears in your browser, which stops the PWS logon sequence. You must respond to the message before you can enter PWS and log in to the FirePass.

PWS, which is configured in a Pre-Logon Sequence, creates an environment within the client computer where information created during the FirePass session is protected from accidentally being left or leaked. Normally, users who load the FirePass login page and meet the criteria for the Pre-Logon Sequence are requested to enter PWS. Users then log in to FirePass inside the PWS environment created on the client computer.

If you use IE7 to log in to FirePass, and a Pre-Logon Sequence prompts you to enter PWS, the sequence will subsequently stop and you will see a warning message that appears similar to the following example reported in IE7:

To help protect your security, Internet Explorer has restricted this webpage from running scripts or ActiveX controls that could access your computer. Click here for options...

To continue into PWS, you must click on the warning and select Allow Blocked Content... from the drop-down menu. A pop-up window with a message that appears similar to the following example will appear:

Allowing active content such as script and ActiveX controls can be useful, but active content might also harm your computer. Are you sure you want to let this file run active content?

Click the Yes button in the pop-up window to continue to the FirePass login page inside PWS.

Note: These warning messages appear regardless of your IE7 security settings.

Note: For information about FirePass support for IE7, refer to K6740: Support for Internet Explorer 7.

F5 Product Development tracked this issue as CR72475 and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, Cumulative Hotfix HF-552-4 has been issued for FirePass version 5.5.2 and Cumulative Hotfix HF-600-9 has been issued for FirePass version 6.0.0. You may download these hotfixes or later versions of the Cumulative Hotfixes from the F5 Downloads page.
