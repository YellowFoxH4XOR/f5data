Known Issue

Form-based client-initiated single sign-on (SSO) may fail to process strings with special characters.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for form-based client-initiated SSO.
  • The application form includes a Form Parameter Name field that contains special characters.

Impact

Application forms are not successfully submitted, causing SSO to fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users cannot authenticate with the BIG-IP APM system by using form-based client-initiated SSO.
  • An error message that appears similar to the following example displays in the browser error console:

    TypeError: __f5form.<portion_of_the_form_parameter_name> is undefined
