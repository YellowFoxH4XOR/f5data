Topic

F5 recommends reinstalling the BIG-IP system software when converting redundant pair units. Due to the large number of settings that must be changed using both the Configuration utility and the command line when you convert a unit from active-standby to active-active, or from active-active to active-standby, F5 recommends starting with a clean installation of the BIG-IP software. Reloading and reconfiguring both units is generally an easier and more reliable process than converting from one redundant mode to another.

For more information about reinstalling BIG-IP system software, refer to the BIG-IP LTM release notes.

Note: For more information, refer to K7247: The Application Security Module does not currently support an active-active configuration.
