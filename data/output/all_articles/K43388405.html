Description

'SSL::collect ' statement in iRule and an LTM policy with an action of Set Variable on request triggers an RST and traffic to fail.

  • Traffic RSTs
  • iRule execution error as the RST cause in F5 Ethernet Trailers of a packet capture
  • The following log can be seen in /var/log/ltm:
    01220001:3: TCL error: no connection established SSL::collect needs an established connection! (line 1)     invoked from within "SSL::collect"

Environment

  • BIG-IP 12.x and 11.6.x
  • iRules
  • LTM Policies

Cause

Bug ID865341

Recommended Actions

    Do not configure a virtual server with both of the following:
    • An iRule with an "SSL::collect" statement
    • An LTM policy with an action of "Set Variable on request"
