Topic

If your BIG-IP GTM system's DNS configuration contains non-master type zones, such as forwarding zones, you must also enable DNS recursion in the named configuration on the BIG-IP GTM system.

By default, DNS recursion is disabled in the named configuration. To enable DNS recursion on the BIG-IP GTM system, refer to K7055: Enabling DNS recursion in the named configuration on a BIG-IP GTM system.
