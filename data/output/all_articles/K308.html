Issue

There are a number of possible reasons for packet loss. Use the following troubleshooting methods to help determine the cause:

  • Some switches and hubs that auto-negotiate (auto) can cause problems interfacing with BIG-IP Network Interface Cards (NICs), which can cause packet loss. To avoid this, connect the BIG-IP to a hub or switch that has the speed and duplex setting hard coded, and then set the BIG-IP NICs to the same setting.
  • Use a cable-testing device to check for faulty cabling.
  • Verify that you are using CAT5 Ethernet cabling.
  • Check the BIG-IP configuration and system resources. For example, if BIG-IP is configured with several IP filters and/or health monitors, some packet loss can occur as BIG-IP evaluates these complex rules. Consider streamlining the IP filters or reducing the complexity of the strings used for node checking.
  • A chattering device or too much traffic on a hub can cause collisions and excessive collisions cause dropped packets. To check the number of collisions, type the following command and look at the last column labeled, Coll:

    • For BIG-IP versions 4.0 through 4.6.4, type:

      netstat -nis

    • For BIG-IP versions 1.8.3 through 3.3.1 PTF-06, type:

      netstat -ni

If you are still experiencing excessive packet loss after using these troubleshooting methods, contact F5 Networks support.
