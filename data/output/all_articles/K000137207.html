Description

You may have the requirement to configure remote syslog servers for the F5OS-A platform(rSeries) so that you can forward the logs on the F5OS to your remote syslog servers.

This article discusses how to send the logs on the F5OS Host OS level to the remote logs servers, if you need to send logs in the tenants, you may refer to the article below:
K13080: Configuring the BIG-IP system to log to a remote syslog server (11.x - 17.x)

You may also refer to the article below to configure remote log servers for your VELOS system:
K04801882: Configuring the VELOS system to log to a remote syslog server

Environment

  • F5OS-A 1.4.0 and later
  • Remote Syslog servers

Cause

None, this is informational

Recommended Actions

To configure a remote syslog server, you can choose GUI or CLI. At the time this solution was written, some of the options were only available via CLI.

To configure a remote syslog destination, you can follow the steps:
NOTE: At the time the article is published, You may not be able to see all the logs unless you use CLI to configure selectors or host log forwarding.
Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your F5OS GUI
  2. Click SYSTEM SETTINGS > Log Settings
  3. Under Remote Log Servers, click Add
  4. Filling the form with your configuration details and then click Save or Save & Close

 

To configure a remote syslog destination using CLI, you can follow:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your CLI, you will need to log in to the confd terminal
  2. Enter configuration mode by typing the command
config
  1. You can use a command like the one below to configure the remote servers, you may need to configure the selectors as per your requirement.
system logging remote-servers remote-server <remote-server-ip-address> 
selectors selector LOCAL0 <LOG-SEVIRITY-LEVEL>

For example,

system logging remote-servers remote-server 192.168.1.3
selectors selector LOCAL0 INFORMATIONAL
  1. Commit the changes by
commit

 

Additional considerations:
To forward audit logs, you may follow the article below to add corresponding selectors:

K000135458: Missing audit logs on remote logging server - rSeries system

To forward all the system host logs, you will also need to configure it to forward host logs in this way(only CLI):

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

NOTE: Due to Bug ID 1588093: Forwarding host log files to remote targets, for versions prior to F5OS-C 1.8.0 or F5OS-A 1.8.0, you should avoid having /var/log/messages or messages as a host-logs files entry to forward the file lines to a remote destination to avoid exhausting disk space. 

  1. Log in to your CLI, you will need to log in to the confd terminal
  2. Enter configuration mode by typing the command
config
  1. You can use a command like the one below to enable forwarding host logs:
system logging host-logs config remote-forwarding enabled
  1. Commit the changes by
commit

For what logs are forwarded, you may further read the below article, in short, it should forward all messages from the kernel, daemon, user, syslog, cron, authpriv, and local0 facilities to the remote server. 

K000137345: F5OS remote syslog with host-logs enabled
