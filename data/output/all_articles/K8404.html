K8404: Error Message: The certificate's CN name does not match the passed value

Issue

When a user launches a Network Access connection or an Application Tunnel, FirePass may report an error message that appears similar to the following example:

The certificate's CN name does not match the passed value.

This issue occurs when the Common Name (CN) field in the FirePass SSL certificate does not match the hostname the user entered to access the FirePass controller. For example, this issue would occur in the following situations:

  • The user entered a fully qualified domain name (FQDN) to access the FirePass controller, for example firepass001.siterequest.com, but the certificate CN field does not contain an FQDN, for example firepass001.
  • The user entered a hostname alias to access the FirePass controller, for example firepass.siterequest.com, but the certificate CN field contains the actual hostname of the FirePass controller, for example fp001.seattle.siterequest.com.
  • The user entered an IP address to access the FirePass controller, but the certificate CN field contains a hostname.

When this error message occurs, users can click the Yes button to trust the certificate and proceed. If you want to prevent users from receiving this error message, ensure that users connect to the FirePass controller using the hostname contained in the CN field of the FirePass SSL certificate.

Note: To verify which SSL certificate is associated with each web service, view the Certificate column under the Web Services tab on the Device Management: Configuration: Network Configuration page. You can view details of installed certificates by clicking the Configure SSL Certificates link on the Device Management: Configuration: Network Configuration page under the Web Services tab.
