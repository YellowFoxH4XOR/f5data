Topic

The BIG-IP ASM system enforces proper HTTP requests by verifying that requests containing a query string or POST data are allowed by the security policy. If the BIG-IP ASM processes a request containing an illegal query string or POST data, the following violation will be logged to the /var/log/asm file and to the Reporting screen in the Configuration utility:

Illegal Query String or POST Data

Note: The Illegal Query String or POST Data violation can occur only for a flow.
