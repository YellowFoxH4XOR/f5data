Topic

This article provides guidance on extra memory allocation for the restjavad process in Automation Toolchain when your BIG-IP system experiences issues with the restjavad process.

Description

If your BIG-IP system experiences degraded performance and uses a relatively high amount of CPU, you may be experiencing an issue with the restjavad process. Such issues are caused by the underlying BIG-IP framework and not an issue with Automation Toolchain. For more information, review the following documents:

  • Application Services 3 (AS3)
  • Declarative Onboarding (DO)
  • Telemetry Streaming (TS)

The restjavad process may become unstable if the amount of memory required by the process exceeds the value allocated for its use. The memory required by the restjavad process may grow significantly in system configurations with either a high volume of device statistics collection or a with relatively large number of BIG-IP LTM objects managed by the REST framework. The overall system performance degrades during continuous restart of the restjavad process due to high CPU usage.

Recommendations

Increase the memory allocated for the restjavad process according to the information in the following table.

ATC componentRecommended extra memory allocationCommandsReference
AS3
  • 256 MB if only using AS3
  • 512 MB if using additional iControl LX Extensions
Enter the following commands as appropriate to allocate the extra memory:
Note: Features that are handled by the restjavad daemon are disrupted during the restart.
  • tmsh modify sys db restjavad.useextramb value true
  • tmsh modify sys db provision.extramb value <256 or 512 or 2048>
  • tmsh restart sys service restjavad
In versions 15.1.9, 16.1.4, and 17.1.0 and later in each respective branch, restjavad.useextramb has been removed. Previously since restjavad memory allocation was a percentage of provision.extramb plus 384, the equivalent commands to increase the memory allocated for restjavad are the following:
  • tmsh modify sys db provision.extramb value <204 or  410 or 1638>
  • tmsh modify sys db provision.restjavad.extramb value <588 or 794 or 2022>
  • tmsh restart sys service restjavad
For more information about restjavad memory provisioning in different BIG-IP versions, refer to K000137363: Overview of restjavad memory provisioning on BIG-IP and use of restjavad.useextramb, provision.extramb and provision.restjavad.extramb .		AS3 Clouddocs Reference
