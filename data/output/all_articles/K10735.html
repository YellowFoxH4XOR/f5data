Topic

F5 is announcing that the End of Software Development (EoSD) for BIG-IP version 9.x is effective March 31, 2011 in accordance with the guidelines contained within K8986: F5 product support policies and K5903: BIG-IP software support policy.

As of March 31, 2011, F5 will no longer provide security updates, software fixes (hotfixes), or consulting services for BIG-IP version 9.x. Additionally, service contracts enter the Extended Support phase beginning with the EoSD in accordance with the guidelines contained within K4309: BIG-IP Platform Lifecycle Support Policy.

Important: The End of Software Development (EoSD) for BIG-IP version 9.4.6 through 9.4.7 has been extended to December 31, 2011. Additionally, the EoSD for BIG-IP version 9.4.8 has been extended to August 31, 2012.

During the Extended Support phase, F5 will offer only configuration support and RMA services. Defect correction will not be provided. F5 may offer a customer access to certain software updates, which may include security or stability related software releases.

All configuration support for BIG-IP version 9.x during the Extended Support phase is considered reasonable effort, which is limited to technical phone support and hardware support.

Note: Reasonable effort is confined to system configuration support. No response time targets, guarantees, or SLAs shall apply. No escalations to Engineering Services or Product Development will be utilized. RMA support is included, as long as the platform has not exceeded its End of Technical Support (EoTS) or End of RMA (EoRMA) support date.

Customers should view the corresponding software release notes to determine if a particular software release is suitable for their platform or software version. Access or compatibility of these software updates are not guaranteed and will be made under F5's reasonable effort support guidelines.

Additionally, if a platform is not compatible with the latest General Sustaining (GS) software release, the platform may be restricted from operating that version through the F5 software licensing process.

The effective End of Technical Support (EoTS) date is March 31, 2012 for the BIG-IP version 9.x software, completing its End of Life (EoL) cycle.

Important: The End of Technical Support (EoTS) for BIG-IP version 9.4.6 through 9.4.7 has been extended to December 31, 2012. Additionally, the EoTS for BIG-IP version 9.4.8 has been extended to August 31, 2013.

Note: Some platforms running BIG-IP version 9.x software are capable of upgrading to the BIG-IP version 10.x software. For information, refer to the BIG-IP 10.x release notes.

For more information about this announcement, contact your local F5 Partner Busine ss Manager or Inside Sales Representative.
