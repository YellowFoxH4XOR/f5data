Known Issue

The qkview utility stops responding.

This issue occurs when the following conditions are met:

  • You run the qkview utility from the command line.
  • The qkview utility executes a command that stops responding.
  • You press Ctrl+C to exit the qkview utility.

Impact

The qkview utility does not retain the data it gathered prior to exiting.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you press Ctrl+C to exit the qkview utility, the utility loses the data it gathered.

Workaround

To work around this issue, you can run the qkview utility with the -v flag, and then, before you exit the qkview utility, you can manually save the data the utility obtains before it becomes unresponsive. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP device.
  2. Start the qkview utility using the following command:

    qkview -v

    Note: The -v flag shows the process that the qkview utility initiates, which is running when the utility becomes unresponsive.

  3. Log in to another session on the affected BIG-IP device from the command line.
  4. When the qkview utility becomes unresponsive, use the following commands to copy the existing QKView data files:

    cp /tmp/qkview_run.dat /var/tmp/qkview_run_backup.dat
    cp /tmp/qkview_err.dat /var/tmp/qkview_err_backup.dat

  5. Note the command that the qkview utility is attempting to run when it becomes unresponsive.
  6. Save the qkview_run_backup.dat and qkview_err_backup.dat files to a location that is off of the device.
  7. In the original login session, which is running the qkview utility, type the following command to terminate the utility:

    Ctrl+C
