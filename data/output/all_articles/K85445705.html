Description

The BIG-IP CLI displays a similar error message when creating/adding a new pool member to an existing pool via TMSH:

01070224:3: Pool Member on Pool /Common/<pool_name> of type A must contain a valid Virtual Server name because it is a terminal member.

Environment

  • BIG-IP DNS
  • BIG-IP GTM
  • Existing pool
  • TMSH

Cause

Faulty syntax order:

tmsh create gtm pool a <pool-name> members add { <server_object_name>:<virtual_server_name> { member-order 0 } alternate-mode global-availability load-balancing-mode topology }

NOTE: This fails. The system displays the following message:

01070224:3: Pool Member on Pool /Common/<pool-name> of type A must contain a valid Virtual Server name because it is a terminal member.

Recommended Actions

  1. Log in to the command line of a BIG-IP system to create a new object.
  2. Run:

    tmsh create gtm pool a <pool-name> members add { <server_object_name>:<virtual_server_name> { member-order 0 } } alternate-mode global-availability load-balancing-mode topology

NOTE: Moving the last curly bracket "}" from topology to before "alternate-mode". This syntax order succeeds.
