K78154381: Not able to login to our BIG-IP after resetting management UI certificate

Type
Support Solution
Published
2021-04-14
Updated
2023-02-21
Applies to
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K78154381

Description

After importing the certificate used for management UI, the device is no longer accessible.

  • Management IP can't be accessed via browser.
  • SSH access still works.

Environment

Recently changed certificate used by management UI.

  • HTTPD doesn't start and if we try to manually restart, an error message is shown indicating that the key and certificate do not match.
  • BIG-IP LTM

Cause

This can happen if an incorrect certificate is replaced.

Recommended Actions

First generate a new self signed certificate from bash. Once that's active, restart httpd and the GUI should come back up.

  1. Use the command below to generate a new self signed certificate for management:
    openssl req -x509 -nodes -newkey rsa:2048 -keyout /config/httpd/conf/ssl.key/server.key -out /config/httpd/conf/ssl.crt/server.crt -days 3650
     
  2. Once the above command has been executed successfully, restart httpd using command below:
    bigstart restart httpd

Once the above steps are followed, the GUI should be accessible via browser.
