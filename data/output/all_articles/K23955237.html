K23955237: Velos Cluster shows 'Openshift cluster is NOT ready.' and KubeVirt pods show 'ImagePullBackOff'

2023-10-17
Applies to

Source
https://my.f5.com/manage/s/article/K23955237

Description

Running v1.3.0 F5OS and after a reboot, the system controllers shows '2 Controller(s) are NOT ready, Openshift cluster is NOT ready.' (when showing the cluster status with show cluster) for example:

# show cluster
                             TIME                                         
NAME          STATUS         CREATED  ROLES  CPU  PODS  MEMORY  HUGEPAGES 
---------------------------------------------------------------------------
blade-1       Not Available  -        -      0    0     -       -         
blade-2       Not Available  -        -      0    0     -       -         
controller-1  Not Available  -        -      -    -     -       -         
controller-2  Not Available  -        -      -    -     -       -           

cluster orchestration-manager cluster-initialized true
cluster orchestration-manager cluster-ready false
cluster orchestration-manager active-node controller-2.chassis.local
cluster orchestration-manager etcd-ha-initialized true
cluster orchestration-manager etcd-ha-running true

cluster cluster-status summary-status "2 Controller(s) are NOT ready, Openshift cluster is NOT ready."
INDEX  STATUS     

This can also show after an upgrade from 1.2.1 to 1.3.0  of the System Controllers.

The KubeVirt  pods fail to upgrade and produce that can be seen with command 'oc get pods -n kubevirt' and similar to:

status ImagePullBackOff or status ErrImagePull  

The partition is working, and can be accesses by management interface, but the tenants cannot be deployed.

Environment

  • Velos System Controllers Cluster 1.3.0

Cause

Bug ID 1071693: KubeVirt pods might fail when upgrading from VELOS v1.2.1 to v1.3.0

Recommended Actions

Rebuild the Openshift cluster and apply a fix for Kubevirt with the following steps:

  1. Fix the Kubevirt:

    cp /usr/share/omd/kubevirt/omd-kubevirt-velos-install.sh /tmp

    cd /tmp

    vi omd-kubevirt-velos-install.sh

  2. Add these lines at line 99 and save the file:

    else
       echo "Using registry port of $official_port for kubevirt install"
       echo "Update registry port in kubevirt yml files"
       sed -i -e "s@:[0-9][0-9][0-9][0-9]/@:$official_port/@" $WORKDIR/kubevirt-velos.yaml
     

  3. In one window:

    oc delete -f /usr/share/omd/kubevirt/kubevirt-velos.yaml

  4. In another window:

    /tmp/omd-kubevirt-velos-install.sh /usr/share/omd/kubevirt/
