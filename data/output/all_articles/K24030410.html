Description
You get an error similar to the following when you run a F5 SDK python script after the version upgrade to v14.0.0 and later.
0107074b:3: Unable to change data group (<data-group name>) type.  Must remove existing entries first.

Environment

  • You are using F5 SDK (Python).
  • You are trying to update a data-group.
  • You didn't get the error when you were using v13.x.x.

Cause
This is the result of the change by ID 742170.
ID 742170: REST PUT command fails for data-group internal

Recommended Actions

You need to use update(type="string") instead of update() to update the data group

e.g.

#!/usr/bin/env python3
from f5.bigip import ManagementRoot

mgmt = ManagementRoot("192.168.1.10", "admin", "admin")

dg = mgmt.tm.ltm.data_group.internals.internal.load(name='<data-group name>', partition='Common')
dg.records = ["192.168.2.10/32", "192.158.2.11/32"]
print(dg.records)
dg.update(type="string")
