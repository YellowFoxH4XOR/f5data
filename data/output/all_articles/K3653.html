Topic

This article applies to 9.x. For information about other versions, refer to the following article:

  • K6869: Reserved words that should not be used in BIG-IP configurations (10.x - 13.x)

The following list represents words that should not be used in BIG-IP system configurations. F5 recommends you refrain from using any of the following words when you name a network object.

Important: Using any of the words in the following list may result in errors and other issues.

General

  • admin (This exclusion applies to any word that contains the word admin, such as aadmina.)
  • all
  • any
  • delete
  • disable
  • enable
  • help
  • list
  • min
  • none
  • show
  • streaming

Custom name

Acceptable characters are as follows:

  • letters ( A to Z in upper and lower case )
  • digits ( 0 through 9 )
  • hyphen ( - )
  • period ( . )
  • underscore ( _ )

The object name must start with a letter or underscore.

In addition, VLAN group names may contain only letters (alphabetic characters A to Z in upper and lower case).

BIG-IP ASM

The following words should not be used in BIG-IP ASM configurations:

Under the Parameter section:

  • UNNAMED

Under the Object Type section:

  • no_ext
