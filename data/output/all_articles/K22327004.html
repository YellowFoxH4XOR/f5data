Description

  • You are attempting to send OTP password via email.
  • APM logs messages similar to:
/Common/Policy_name:Common:sessionID: Email Agent: Message sent failed

/Common/Policy_name:Common:sessionID: Email Module: Send message failed. curl_easy_perform() returned with error : 'Resolving timed out after 10521 milliseconds'

/Common/Policy_name:Common:sessionID: Session variable 'session.email./Common/otp_by_email_ag.errmsg' set to 'message send failed. Resolving timed out after 10521 milliseconds'

Environment

  • APM
 

Cause

DNS resolution fails, Email Agent cannot resolve the hostname of the SMTP server. 
 

Recommended Actions

  • Check the DNS settings and connectivity: System > Configuration > Device > DNS
  • Verify/correct SMTP hostname in: System > Configuration > Device > SMTP
    or
  • Replace the hostname with the server IP
