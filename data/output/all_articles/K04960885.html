K04960885: LTM device got failed over suddenly

Applies to

  • BIG-IP LTM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K04960885

Description

  • LTM device got failed over suddenly.
  • tmm restarts.
  • tmm core file is generated.
  • A sharp usage increase of tmm memory can be seen on units performance graphs.
  • Messages similar to the following can be seen on /var/log/tmm

     notice panic: unable to realloc 1983658 bytes
     notice TMM clock is 0 seconds from system time
     notice ticks since last clock update: 234
     notice ticks since start of poll: 233
     notice ePVA firmware snoop vers(0x2:0x1), features: 0x1d6ea5f3bdedff, attached:no, pde:8.
     notice ePVA: disable ePVA per request.
     notice hsb7: pde dma stopped
     notice TMM version: pgo_use x86_64 padc TMM Version 14.1.2.8.0.0.7
     notice ---------------------- Crash dump - Start ----------------------

Environment

  • LTM
  • log4j mitigation iRule version previous to 2.6 in use

Cause

tmm memory is exhausted due to log4j mitigation iRule version 2.5 or below.

Recommended Actions

Please use the latest log4j mitigation iRule version available on K59329043 which reduces the memory footprint.
