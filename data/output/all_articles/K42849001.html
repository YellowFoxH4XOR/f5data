K42849001: No Learning Suggestions with two ASM policies are applied via Local Traffic Policy to a single Virtual Server

Type
Support Solution
Published
2020-06-19
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K42849001

Description

When more than one ASM policy is applied to a single Virtual Server via Local Traffic Policy, no traffic learning is generated.

Environment

  • LTM Policy directs traffic to ASM policy based on host header
  • No Traffic learning for assigned ASM policies
  • Traffic learning is generated when ASM policy is assigned directly to the Virtual Server

Cause

This is caused by the Bug ID 913137

Recommended Actions

There are two workaround available to resolve the issue.
  • In the 'policy building process' setting of the learning and blocking, uncheck the option 'Learn only from non-bot traffic'

    --or--
     
  • Three Virtual Servers can be used; first virtual server with iRule redirects traffic to the other two Virtual Servers where required ASM policies are assigned.
