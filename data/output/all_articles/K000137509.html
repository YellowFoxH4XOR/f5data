Description

You would like to disable the use of basic authentication for administrative access to your F5OS system.

Environment

  • F5OS-A

Cause

None

Recommended Actions

After disabling basic authentication any attempt to access an API endpoint other than the root /api URI using basic auth will fail. Only when a token is issued to the client, can that client make changes via the webUI or the API.

Disabling basic authentication with the webUI
  1. Logon to the F5OS webUI.
  2. Go to USER MANAGEMENT > Authentication Settings.
  3. For the Basic Authentication pull-down menu select Disabled.
  4. Click Save.
