Known Issue

This is the result of a known issue. After installing Microsoft patch KB955759, Dynamic App Tunnels and Protected Workspace fail to launch for users connecting with Internet Explorer. The issue that the patch addresses occurs in Windows 2000 SP4, Windows XP SP2 and SP3, and Windows XP Professional x64 SP2. The KB955759 patch does not affect Windows Vista users. Installing the patch disables the client machine's ability to call a specific dll, which is needed for Protected Workspace and Dynamic App Tunnels to work correctly.

F5-supported Firefox and Mozilla browsers are not affected by this issue.

F5 Product Development tracked this issue as CR133875 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in cumulative HF-610-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by either removing the KB955759 patch and rebooting the client machine, or using a supported Firefox or Mozilla browser.

Note: To remove an installed patch, reference your Microsoft documentation.
