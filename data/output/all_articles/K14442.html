Known Issue

If a Server Principal Name (SPN) is updated on a filer, the ARX system may continue to use the previous SPN.

When existing CIFS connections using the old SPN are available for reuse, the ARX may reuse the connection and cause a connection failure.

Impact

Clients may not be authenticated and the ARX managed data will be unavailable.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Clients may not be authenticated
  • ARX managed data will be unavailable
  • Messages will be logged in the ARX sylog. For example:

    VCIFS-3-WARN-FILERLOGONFAIL:: Logon failure for user Admin@EX.EXAMPLE.COM at filer 10.10.10.100 (STATUS_MORE_PROCESSING_REQUIRED).

Workaround

To work around this issue, you can fail over to the peer ARX system. To do so, perform the following procedure:

Impact of workaround: ARX services will be unavailable while the failover completes.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Reboot and fail over by typing the following command:

    reload
  4. Confirm the reload request when prompted.
