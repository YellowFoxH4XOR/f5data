K12451: The Microsoft Terminal Services static application tunnel port changes if remote desktop is enabled on a Microsoft Windows client

Topic

If a FirePass Microsoft Terminal Services static application tunnel is configured to use the default port of 3389 and the Windows client system has remote desktop enabled using the same default port, when a Windows user launches the Microsoft Terminal Services static application, the user will receive the following warning message:

WARNING! The local TCP port number used by the App Tunnel adapter for the application you are trying to connect to has changed due to the conflicts with another application on your local system, that uses the same port. To continue, do one of these things:
temporarily shutdown the conflicting program, and then restart the App Tunnel
reconfigure the App Tunnels client application to connect to the alternate port shown
reconfigure the conflicting application to use a different TCP port

In addition, FirePass will assign a different port to the local loopback interface, which may cause the session to fail.

This issue occurs because the local remote desktop service and the static application tunnel's local loopback interface attempt to use the same port. 

Workaround

You can work around this behavior by configuring the static application tunnel to use an alternate port.

Note: For more information about configuring Microsoft Terminal Services application tunnels, refer to K8640: Configuring Windows Terminal Server favorites.
