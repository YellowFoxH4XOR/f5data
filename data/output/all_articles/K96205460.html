Description

How to rename the GSLB server on the BIG-IP DNS?

Environment

  • BIG-IP DNS
  • GSLB server
  • Rename server name

Cause

None

Recommended Actions

  1. Determine the  new name for GSLB server.
    For example: Current GSLB server name is "xxx" and we need to change server name to "yyy".

  2. Login into  BIG-IP DNS  using SSH 

  3. Perform the  back up of current configurations by using below command
    # cp /config/bigip_gtm.conf /var/tmp/bigip_gtm.conf.b4serverRename

  4. Update the GSLB server name and all references to old name in the config file
    sed -i s'|xxx|yyy|' /config/bigip_gtm.conf
    Note: In this example the old server name  is "xxx" and the new server name is "yyy"

  5. Apply the change by using the below command
    tmsh load sys config gtm-only

  6. Verify the new name is reflected for the GSLB server in the BIG-IP GUI.

If required  to rollback the GSLB Server name  from "yyy" to "xxx"  again  then follow below steps.

  1. Revert the configuration by using below command
    cp /var/tmp/bigip_gtm.conf.b4serverRename /config/bigip_gtm.conf

  2. Apply the change:
    # tmsh load sys config gtm-only
