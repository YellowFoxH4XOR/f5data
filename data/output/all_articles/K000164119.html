K000164119: GUI HA Group configuration rejects trunk weight value that is not multiple of 5.

Type
Support Solution
Published
2026-11-18
Updated
2026-11-18
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3, 21.1.X, 21.1.0, 17.5.1
Source
https://my.f5.com/manage/s/article/K000164119

Description

While trying to configure ha-group with trunk object on GUI, an error "The Weight must be an integer in the range of 10 and 100." may be displayed even though the specified weight value is within the range of 10 and 100. When this error is displayed, user cannot add trunk object to HA Group.

Figure: GUI error screen

 

This error occurs when trunk weight value is not multiple of 5.

 

Environment

  • Configuring HA Group with trunk objects on GUI.
  • Try to set trunk weight value of the HA Group other than multiple of 5. For example, 11, 26, 34, 77, 91, 99... all results in the error. Issue does not occur if weight value is multiple of 5 such as 10, 15, 50, 90, 95, 100...etc.
  • Software version 17.1.3 or later, 17.5.1.1 or later, 21.1.0 or later.

 

Cause

Bug ID2727501.

 

Answer/Recommended Actions

Use TMSH to configure ha-group with trunk that has weight value other than multiple of 5.

root@(bigip2)(cfg-sync In Sync)(Active)(/Common)(tmos)# create sys ha-group my_hagroup trunks replace-all-with { ext_trunk { minimum-threshold 1 weight 99 } }
root@(bigip2)(cfg-sync In Sync)(Active)(/Common)(tmos)# list sys ha-group my_hagroup
sys ha-group my_hagroup {
    trunks {
        ext_trunk {
            minimum-threshold 1
            percent-up 100
            weight 99
        }
    }
}
root@(bigip2)(cfg-sync In Sync)(Active)(/Common)(tmos)#
