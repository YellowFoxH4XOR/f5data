Description

How to verify or view the sshd configuration? The sshd configuration is stored in /config/ssh/sshd_config

Environment

BIG-IP

Cause

Informational

Recommended Actions

Note: F5 does not support editing the /config/ssh/sshd_config file directly.


To view the sshd configuration:

  # cat /config/ssh/sshd_config
