Known Issue

In rare situations, the BIG-IP system fails to start.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is starting from a shut-down state.
  • Your system platform is one the following:
    • BIG-IP iSeries: i4600, i4800, i10600, i10800, i2600, i2800, i7600, i7800, i5600, i5800, i15600, i15800, i12600, i12800
    • BIG-IP HERCULON: i2800, i5800, i10800, i11600, i11800, i11800-DS, i5820-DF, i7820-DF

Impact

The BIG-IP system fails to start and remains inoperative.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system does not start.
  • During system start, the following error displays on the serial console screen:

    Dataplane INOPERABLE - only 1 HSBes found on this platform.

Workaround

To work around this issue, you can power cycle the BIG-IP system. 

Impact of workaround: Because the BIG-IP system has not yet started or begun passing traffic, the suggested workaround should have no negative impact.

You can power cycle the BIG-IP system directly or using the Always-On Management (AOM) subsystem.  For information on accessing the AOM subsystem and power cycling refer to K9403:Overview of the AOM subsystem and K14594: Accessing the AOM Command Menu.
