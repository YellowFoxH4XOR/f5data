Topic

Using the BIG-IP APM system, you can configure selective logging in an access policy. The system can capture individual session variables in the log file, which the system can use in many ways. By configuring logging in the access policy, you can control when the system captures information and adds it to the log file. The placement of the logging option in the access policy is crucial. You must configure the logging option directly after the action that gathers the information you want to capture. For example, if you want to capture session variable information, you must place the logging option after the session variable has been assigned. In addition, if you want to capture information regarding logon credentials, you must place the logging option directly after the Authentication action.

Configuring session variable logging in an access policy

To log a session variable value in an access policy, perform the following procedure:

  1. Go to Access > Profiles / Policies > Access Profiles (Per-Session Policies).

    Note: If your access policy is a Per-request policy, go to Access > Profiles / Policies > Per-Request Policies.

  2. For the policy you want to edit, select Edit.
  3. To add an action, select + at the location you want to log the session variable.
  4. Under General Purpose, select Logging.
  5. Click Add Item.
  6. In the Log Message box, type a log message and the session variable to log in the /var/log/apm file. For example, enter the following text for either a Per-session or Per-request policy:

    Note: For Per-session policies, you have additional functionality to select Add new entry and select your session variable.

    Login action: %{session.logon.last.username} has logged in.
    Login action=%{perflow.username} has logged in.

    You observe a log entry similar to the following in the /var/log/apm file when the user John logs in:

    Jun 21 10:23:59 apm.example.com notice apmd[8296]: 01490143:5: /Common/examplePolicy:Common:e1211821: Logging Agent: Login action: John has logged in.

  7. Select Save.
  8. Select Apply Access Policy.
