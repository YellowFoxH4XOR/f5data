Known Issue

This is the result of a known issue. The SSL::modssl_sessionid_headers iRule command returns a list of fields that the BIG-IP LTM adds to the HTTP headers to emulate ModSSL behavior. An iRule that calls the SSL::modssl_sessionid_headers command causes a Tcl memory leak.

F5 Product Development tracked this issue as CR63907, CR63910, 63911, and CR68269, and it was fixed in BIG-IP LTM versions 9.1.3, 9.2.4, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM release notes.
