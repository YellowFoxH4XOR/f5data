Known Issue

Description

If a user accesses a Portal Access favorite that uses Extensible Stylesheet Language (XSL), the website may fail to load, or render incomplete. This issue occurs because the reverse proxy engine in FirePass does not properly recognize the XSL format and will not render any include statements.

This issue occurs when the following condition is met:

  • A Portal Access favorite uses XSL

Impact

XSL content does not render properly through Portal Access.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The resulting website may be missing information
  • The resulting website may fail to load
  • User may receive JavaScript errors from their browser

Workaround

To work around this issue, you can create a content processing sed script and configure the global caching settings. To do so, perform the following procedure:

Creating a content processing sed script

  1. Log in to the FirePass Administrative Console.
  2. Click Portal Access.
  3. Click Content Processing.
  4. Click Add New Favorite.
  5. In the Processing script name text box, type a name for your script.

    For example:

    XSL_Processing
  6. In the URL match patterns text box, type the following:

    *://*.xsl*
  7. In the Content Type text box, type:

    xml
  8. Select the Allow caching check box.
  9. In the Sed processing script text box, type the following:

    s@<head>@<HEAD><script>parent.F5_scriptIncludes_new1(window);</script>@i
  10. From the Processing drop-down menu, select Pre-process response data.
  11. Click the Add New button.

Configuring global caching settings

  1. Log in to the FirePass Administrative Console.
  2. Click Portal Access.
  3. Click Caching and Compression.
  4. Clear the Enable Dynamic Cache on FirePass check box.
  5. Click the Clear Cache button.
  6. In the Web Applications Global Settings section, add the following URL pattern to the text box:

    *://*.xsl*
  7. Click the Update button.
  8. Click on the service restart link.
  9. Click the Restart button.
