Known Issue

Lightweight Directory Access Protocol (LDAP) authentication configuration does not warn when SSL is configured with a client certificate but no matching key.

This issue occurs when all of the following conditions are met:

  • You configure LDAP authentication for administrative access that uses SSL.
  • You specify an SSL client certificate but do not specify a matching SSL key.

Impact

LDAP authentication fails and the BIG-IP system logs no warning messages.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Authentication attempts fail.
  • The system does not log messages indicating that authentication failures occurred.
  • Packet captures between the BIG-IP system and the LDAP server show the BIG-IP system sending FIN after the TCP handshake.

Workaround

None. To prevent this behavior from occurring, you must configure a matching SSL key for the SSL client certificate.
