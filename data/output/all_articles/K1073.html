Topic

If you configure BIG-IP to create debugging log files or create custom log files with syslog, F5 Networks recommends that you store the log files in the /var/log directory. The /var/log directory contains existing log files and also has the most filesystem space available on BIG-IP or 3-DNS Controllers.
