Known Issue

The BIG-IP system may incorrectly send multiple TCP retransmissions.

This issue occurs when all of the following conditions are met:

  • The network environment (upstream or downstream) is configured with a Maximum Transmission Unit (MTU) size that is less than 1500 bytes.
  • A virtual server is associated with a customized TCP profile that has the Initial Congestion Window Size set to a value greater than one.
  • A file transfer is then performed over this virtual server, and a response with an improperly large TCP maximum segment size (MSS) is received.

When the BIG-IP system receives a TCP packet that has an improperly large MSS, the BIG-IP system is supposed to respond with an ICMP Fragmentation Needed (Type 3 Code 4) message due to the MSS exceeding the discovered path maximum transmission unit (PMTU). When this issue occurs, the BIG-IP system resends the entire connection queue with the new MSS, in addition to the Internet Control Message Protocol (ICMP) messages.

Impact

File transfers require a longer period of time, due to large amounts of duplicate retransmissions.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • From viewing a tcpdump capture, you observe that your BIG-IP system sends large amounts of duplicate TCP retransmissions, and then receives large amounts of duplicate TCP ACK packets.
