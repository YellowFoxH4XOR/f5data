Description

When attempting to import an SSL certificate or private key via GUI (Configuration utility), it fails with below error:
01070712:3: Certificate/Key has unknown format or security type (/Common/<file name>). 

Environment

  • Importing certificate or key file on BIG-IP. 

Cause

The certificate is failed to be validated due to incorrect format. This occurs when trying to add a certificate file as key file or vice versa on BIG-IP. 

Recommended Actions

  • Ensure the certificate or Key file is formatted correctly. 
    A certificate in PEM format should include the BEGIN CERTIFICATE and END CERTIFICATE lines and contain no white space, extra line breaks, or additional characters.
    Similarly, a private key file should include the BEGIN PRIVATE KEY and END PRIVATE KEY lines and contain no white space, extra line breaks, or additional characters.
     
  • ??To view the certificate you can open the certificate in any notepad editor (for example, Notepad++). Text file should appear similar to the following example:
         
    For Certificate file: 
              -----BEGIN CERTIFICATE-----
                     [encoded data]
              -----END CERTIFICATE-----
   
           For Private key file: 
              -----BEGIN PRIVATE KEY-----
                     [encoded data]
              -----END PRIVATE KEY-----
