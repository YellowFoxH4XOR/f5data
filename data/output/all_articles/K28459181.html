Description

Unable to create or update DataSafe profile after upgrade.

Message appears:

{{::'asm.message.Loading...' | localize}}

 


Save button is obscured:
 

Environment

  • DataSafe profile
  • After upgrade to 15.1.2.1

Cause

Bug ID 998085: BIG-IP DataSafe GUI does not save changes

Recommended Actions

Bug ID 998085 is fixed in version 15.1.3 onwards. Upgrade to a fixed version.

As an immediate workaround, you may use tmsh to configure the profile.

  • security anti-fraud profile - BIG-IP TMSH Manual
