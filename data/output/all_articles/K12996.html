K12996: The Mac OS X version 10.4 native client requires the server NetBIOS name to be registered in WINS for NTLMv2 authentication for a CIFS service using constrained delegation

Topic

The Mac OS X version 10.4 native client has a unique netlogon authentication behavior. The native client does not use the server name included in the protocol negotiation server field of the NTLMv2 response. Alternately, the native client performs an NB name lookup to acquire the server NetBIOS name. As a result of this behavior, if the native client is authenticating with an NTLMv2-only CIFS service configured to use constrained delegation, the ARX virtual server must register its NetBIOS name with a WINS server.

To configure the ARX virtual server to register its default NB name with a WINS server, you can use the wins command. The default NetBIOS name for a virtual server is the first component of the global server's FQDN. For example, if the global server's FQDN is fs1.mycompany.com, the default NetBIOS name for the virtual server would be FS1. Additionally, you may use the wins-name and wins-alias commands to register a specific and/or alternate server name(s) for the virtual server.

Note: For information about the wins, wins-name, and wins-alias commands, refer to the ARX CLI Reference Guide.
