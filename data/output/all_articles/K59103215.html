Description

The dashboard is blank on all nodes in an Azure autoscale sync group.

  • The dashboard in blank
  • The dashboard returns the error: "Unrecoverable Communications Error: Please close this window and log in via the BIG-IP Configuration Utility"
  • There are no errors in the logs

Environment

This occurs under the following conditions:

  • The management port uses a non-standard port (not 443).

Cause

As customers migrate to the cloud, port 443 is used to encrypt the virtual server so they must change the management port, typically to 8443, in order to manage the device.  This is tracked as Bug ID 565755.

Recommended Actions

Upgrade to a version that no longer uses flash to display the dashboard.  This currently includes 14.0.x and 14.1.x.

Change the Management Port
  • To change the Management Port, run the following command:

    tmsh modify sys httpd ssl-port 8443

  • To change the Management Port back to 443, run the following command:

    tmsh modify sys httpd ssl-port 443

Access Performance data via the command line:

  • tmsh show sys performance
  • tmsh show sys performance throughput
  • tmsh show sys performance throughput default
  • tmsh show sys performance throughput raw
  • tmsh show sys performance throughput meg
  • tmsh show sys performance throughput gig
  • tmsh show sys performance throughput historical
  • tmsh show sys performance throughput detail
  • tmsh show sys cpu all
