K000150295: Packets lost on UDP

Type
Support Solution
Published
2025-03-07
Updated
2025-03-12
Applies to
  • NGINX Products
  • NGINX Plus: R33
Source
https://my.f5.com/manage/s/article/K000150295

Description

When there is high UDP load and the kernel buffer is full, incoming packets are silently dropped.


Environment

Nginx Plus


Cause

UPD packet loss during high load


Recommended Actions

rcvbuf=size paramater for listen directive must be added.


For example:

server {

listen 12345 udp rcvbuf=512k;

proxy_pass backend:12345;

...

}


Additional Information

Check and increase system UDP buffer limits.
