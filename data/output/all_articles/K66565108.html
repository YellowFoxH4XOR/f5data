Description

When attempting to create an iRule that uses the DNS_RESPONSE event, you receive an error similar to the one below:
...error: [unknown event (DNS_RESPONSE)]...

Environment

  • BIG-IP GTM or DNS
  • iRule with DNS_RESPONSE event

Cause

DNS_RESPONSE is an LTM only event iRules using this event must be created in the Local Traffic section of the Configuration Utility

Recommended Actions

Create iRule as a Local Traffic configuration object

Additional Information

None
