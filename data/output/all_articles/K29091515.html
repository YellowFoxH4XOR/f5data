Description

Newly discovered Keys in the provider profile under OAuth Client / Resource Server : Provider are not synced to standby device.

Environment

  • Oauth configured as OAuth Client / Resource Server : Provider
  • HA Device group set to manual sync
  • Active device discovers new keys after the discovery
Cause

1. When the Active device discovers the keys, the same are stored in bigip.conf file, and the config/keys sync needs to follow the traditional method of sync to standby device. The Gossip sync is only for the task and not to sync mcp objects.
2. If the device fail overs without syncing first, the newly elected Active device may not have the latest keys and the OAUTH authentication may fail until next discovery.

Recommended Actions

  1. Configure auto sync on the device group.  K14624: Configuring the Automatic Sync feature to save the configuration on the remote devices
  2. Manually Sync the configuration whenever the device shows "Changes Pending"
