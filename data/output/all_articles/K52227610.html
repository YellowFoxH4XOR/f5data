Description

Unable to create a new ASM policy. 

  • Getting "an error occurred [object Object]" message.
  • ASM policy creating fails.

Environment

  • BIG-IP ASM
  • Trying to create a new ASM policy

Cause

This happens if some of the GUI related daemons are not running properly.

Recommended Actions

Restart the following daemons to fix the issue.

  1. From CLI (bash) restart 4 daemons using command below:
    # bigstart restart httpd
    # bigstart restart tomcat
    # bigstart restart restjavad
    # bigstart restart restnoded

    Note: There should not be any impact on traffic due to restarting the above daemons. The GUI may become inaccessible for a short period of time.
