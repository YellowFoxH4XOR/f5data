Topic

Large amounts of traffic from specific sources, such as site scans from individuals, can clutter the Forensics log and make the log difficult to use while maintaining a policy.

To filter and remove information from specific sources, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Application Security > Web Applications.
  3. Select the name of your configured Web Application.
  4. Select Forensics.
  5. From the Filter list, select Custom.
  6. Select the down arrow button next to the Filter list.
  7. Select the IP option button in the IP box, and enter the source IP address that you want to filter.

    Leave all other fields at their default settings, unless you want to apply additional filtering.

  8. Select the Go button next to the filter field.

    Selecting the Go button applies the filter and filters out only the source IP specified.

  9. Click Clear All.

    Clicking Clear All clears all entries that apply to the filter.

Note: Any entries not matching the filter will not be removed from the system.

In BIG-IP ASM 9.2.x the following confirmation prompt syntax appears:

This action will delete all entries related to requests in Learning that were selected in filter! Are you sure you want to delete these requests?

In BIG-IP ASM 9.4 the following confirmation prompt syntax appears:

This action will delete all entries that were selected in filter! Are you sure you want to delete these requests?

The entries in Traffic Learning in BIG-IP ASM 9.4 are not affected by clearing the Forensics log.
