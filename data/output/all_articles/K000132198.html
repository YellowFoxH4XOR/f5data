Description

Monitor of a FQDN pool went down and reports a similar /var/log/ltm like the following:

 

 Error 01070712: <hostname> mcpd[<PID>] Caught configuration exception (0), Invalid monitor rule instance identifier: <#>.

 

This may also result in some monitors stuck in "checking" state.

 

 

Environment

  • BIG-IP LTM
  • versions: 17.0.0, 16.1.3, 16.1.2.2, 16.1.2.1, 15.1.8, 15.1.7, 15.1.6, 15.1.5.1, 14.1.5, 14.1.4.6, 14.1.4.5, 13.1.5
  • FQDN nodes exist on the configuration

 

Cause

  • Bug ID 1111473

 

Recommended Actions

  • Force the mcpd process to reload the BIG-IP configuration. Refer to: K13030: Forcing the mcpd process to reload the BIG-IP configuration.
  • If  you are still having the issue, contact F5 Support
