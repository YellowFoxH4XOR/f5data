Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K13502: Configuring MAC masquerade (11.x - 15.x)

You should consider using this procedure under the following conditions:

  • You want to minimize ARP communications or dropped packets as a result of a failover event.
  • You want to improve reliability and failover speed in lossy networks.
  • You want to improve interoperability with switches that are slow to respond to gratuitous ARP requests.

Description

To optimize the flow of traffic upon failover of a redundant BIG-IP pair, you can configure a feature known as MAC masquerading. MAC masquerading takes advantage of a shared media access control (MAC) address. Upon failover, the shared MAC address(es) float to the newly-active BIG-IP system along with the shared IP addresses.

Note: The BIG-IP system will use the MAC masquerade MAC address when sending a gratuitous ARP request during a failover event.

Note: MAC masquerade does not affect health monitor traffic. The BIG-IP systems will continue to use the original MAC address when performing health checks.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have a redundant BIG-IP pair, and they must not be in active-active mode.
  • The attached switch is able to accommodate the MAC address moving from one port to another port.

Procedures

Assigning MAC masquerade address to a VLAN

Impact of procedure: When you activate MAC masquerading on a VLAN, it can temporarily disrupt traffic on that VLAN while the surrounding network devices learn the new hardware address association. F5 strongly recommends that you perform the procedure below during a scheduled maintenance window.

  1. Log in to the Configuration utility on the active or standby system.
  2. Choose a locally unique MAC address for each L2 network connection that requires MAC masquerading, by following the procedure in K3523: Choosing a unique MAC address for MAC masquerade.
  3. Log in to the Configuration utility.
  4. Click Network.
  5. Click VLANs.
  6. Click the VLAN for which you want to configure MAC masquerading.
  7. In the Configuration section, select Advanced from the menu.
  8. In the MAC Masquerade box, type the MAC address you selected in step 1 for the L2 network corresponding to this VLAN.

    Note: For each VLAN, the same locally unique MAC masquerade address must be configured on both members of the redundant pair.

  9. Click Update.
  10. For each additional VLAN requiring MAC masquerading, repeat steps 1 through 8.
  11. Repeat steps 2 through 8 on the other BIG-IP system in the redundant pair.

    Note: MAC masquerading is not synchronized between BIG-IP systems. You must perform this procedure on both the active and the standby system in a redundant pair.
