Description

Poor TCP performance with Windows 2019 pool members.

Environment

  • Standard TCP virtual server (VS)
  • Windows 2019 server pool member(s)
  • TCP profile serverside with "delayed-acks" enabled.

Cause

Windows 2019 server default setting is to expect an acknowledgement (ack) for each packet. Most F5 tcp profiles use delayed-ack setting. The result is that the server
waits for an acknowledgement for each data packet sent. The BIG-IP delays briefly before sending the ack resulting in slower performance.
 

Recommended Actions

Configure or select a TCP profile with "delayed-acks disabled" and assign to the VS serverside.
 

Additional Information

  • A number of F5 supplied tcp profiles have "delayed-acks" enabled. 
  • From observation, the Windows 2019 server delay before retransmission is typically 0.04s.
