Description

Changed value of Maximum Rate and Maximum Rate Per User on a dynamic Bandwidth Controllers (BWC) policy; however connection speed does not have any effect.
The virtual server stops responding.


Environment

  • BIG-IP
  • Virtual Server
  • Dynamic Bandwidth Controllers (BWC) Policy
  • Connection speed
     

Cause

  • Bug ID 886649
    NOTE: Although the workaround stated in the Bug ID does work, a less drastic way to workaround this, is to remove the iRule from the Virtual Server, delete the BWC Policy, recreate it, and add the iRule back to the VS.
     

Recommended Actions

Upgrade to fixed version

 

Additional Information

  • K02742920: Bandwidth Control does not seem to take affect on Virtual server
