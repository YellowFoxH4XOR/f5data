K15624: The BIG-IP system may fail to forward traffic through an ip6ip4 tunnel when the MTU is set to non-default values

Known Issue

The BIG-IP system may fail to forward traffic through an ip6ip4 tunnel.

This issue occurs when the following condition is met:

  • The affected ip6ip4 tunnel is configured with a non-default maximum transmission unit (MTU) size.

The default MTU size for an ip6ip4 tunnel is zero (0). The ip6ip4 tunnel is typically used to transport IPv6 packets over an IPv4 network and confirms to IP Encapsulation, described in RFC 4213: Basic Transition Mechanisms for IPv6 Hosts and Routers.

Impact

Traffic through the ip6ip4 tunnel is disrupted.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • No traffic flows through the ip6ip4 tunnel.
  • When you attempt to send an IPv6 ping packet through the ip6ip4 tunnel, the ping command returns an error similar to the following example:

    Destination unreachable: No route

Workaround

There is no work around for this issue. However, you can prevent this issue from occurring by ensuring that the MTU size for the ip6ip4 tunnel is left at its default value of zero (0). To recover from this issue, you can manually set the MTU size for the ip6ip4 tunnel back to its default value. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system may temporarily fail to process traffic and failover if configured as part of a high-availability system.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Tunnels > Tunnel List.
  3. Click the name of the affected ip6ip4 tunnel.
  4. Enter the numeral zero (0) for the MTU setting.
  5. To save the change, click Update.
  6. Navigate to System > Configuration > Device > General.
  7. To restart the system, click Reboot.
