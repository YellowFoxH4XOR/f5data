K12423401: Unexpected aggressive sweeper messages seen in the logs

Description
The BIG-IP may hold onto UDP connections too long, causing TCP Memory Pressure and Aggressive Sweeper messages to be seen in the LTM logs.

Environment

  • BIG-IP with DNS provisioned
  • Unexpected traffic increase seen
  • UDP DNS listener configured with default /Common/udp profile

Cause
Aggressive sweeper mode may be activated by events or conditions that increase memory utilization, including but not limited to the following:

  • Denial-of-service (DoS) attacks
  • RAM Cache memory allocation
  • Memory leaks/issues
  • High number of connections (more than the what the box is designed to handle)
Due to the longer idle timeout value configured on the /Common/udp profile, the BIG-IP may not close connections quickly enough on a DNS Listener Virtual Server, which is taking high volumes of traffic.

Recommended Actions
For UDP DNS Listener Virtual Servers, the udp_gtm_dns UDP profile should be used, as it has a lower timeout value of 5 seconds.
