Topic

Summary

Proxy Secure Sockets Layer (SSL) does not support session resumption using Transport Layer Security (TLS) session tickets.

Description

When you configure a BIG-IP virtual server to use Proxy SSL, established SSL connections will reset (TCP RST) if a TLS session ticket is used to resume the session.

If the BIG-IP system has Reset Cause Logging enabled, the reset cause is SSL Session Not Cached. For more information, refer to K13223: Configuring the BIG-IP system to log TCP RST packets.

Recommendations

When attempting to use TLS session tickets with Proxy SSL, you should either disable TLS session tickets on the client or disable the Proxy SSL feature on the BIG-IP system.
