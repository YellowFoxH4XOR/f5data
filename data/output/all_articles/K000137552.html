Description

When monitor object has specific alias port number, monitor test command may fail and return "Syntax Error: invalid monitor destination" error.

ltm monitor http /Common/http-with-alias-port-mon {
    adaptive disabled
    defaults-from /Common/http
    destination *:8080        <=== !!! 8080 == custom alias port is configured
    interval 5
    ip-dscp 0
    recv 200
    recv-disable none
    send "GET / HTTP/1.0\r\n\r\n"
    time-until-up 0
    timeout 16
}

[root@bigip:Active:Standalone] config # tmsh run ltm monitor http http-with-alias-port-mon destination 1.1.1.1:8080
Syntax Error: invalid monitor destination "1.1.1.1:8080"
[root@bigip:Active:Standalone] config # echo $?
1
[root@bigip:Active:Standalone] config #

 

Environment

All the following conditions are matched:
 

  • Monitor object has specific alias port number.
  • Monitor test command is executed with destination parameter "ip:port" format.
 

Cause

When monitor object has specific alias port number, port number in the destination parameter can be omitted.

 

Recommended Actions

To successfully run monitor test command for monitor object which has alias port number, omit alias port number in the destination parameter of "run ltm monitor" monitor test command. 

[root@bigip:Active:Standalone] config # tmsh run ltm monitor http http-with-alias-port-mon destination 1.1.1.1
[root@bigip:Active:Standalone] config # echo $?
0
[root@bigip:Active:Standalone] config # tmsh show ltm monitor http http-with-alias-port-mon test-result
