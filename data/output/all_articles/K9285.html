Known Issue

This is the result of a known issue. Starting in version 9.4.5, BIG-IP PSM can be integrated with the BIG-IP LTM. After applying an HTTP security profile with an alarm-only configuration to a virtual server, new and existing connections to the virtual server may be blocked. When this behavior occurs, the blocking response page is not returned to the client system, and the following error messages are logged to the /var/log/asm file:

ASM configuration error: event code T658 Failed to update configuration table
ASM configuration error: event code T1111 Failed to update configuration table

This issue may be caused by an intermittent communication issue between the BIG-IP control plane and the data plane.

F5 Networks Product Development tracked this issue as CR107808 and it was fixed in versions 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, or PSM Release Notes.

Workaround

To work around this issue, restart the BIG-IP ASM bd process by typing the following command:

bigstart restart asm
