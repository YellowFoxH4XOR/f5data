Known Issue

A standby BIG-IP system configured with Virtual Local Area Network (VLAN) fail-safe may leak memory.

This issue occurs when all of the following conditions are met:

  • You enable VLAN fail-safe on a standby BIG-IP unit.
  • The fail-safe action is configured as failover.
  • The standby BIG-IP unit detects a loss of traffic on the affected VLAN and attempts to generate Internet Control Message Protocol (ICMP) traffic.

Impact

The BIG-IP system experiences decreased performance and instability.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system experiences decreased performance and instability.
  • The amount of memory allocated for and used by the source address translation subsystem will increase over time.

    To inspect the memory usage for the source address translation subsystem, you can use the following Traffic Management Shell (tmsh) command:

    tmsh show /sys memory | egrep 'Max\ Alloc|source\ addr'

    The command output appears similar to the following example:

    SubSystem Alloc (bytes) Max Alloc (bytes) Object Size
    source address translation (var 4628466880 4628466880 4628466880

    Repeating the command will show an increase over time.

  • You notice error messages in the /var/log/ltm file that appear similar to the following example:

    warning tmm[12345]: 011e0003:4: Aggressive mode sweeper: 100 Connections killed

  • The BIG-IP system may generate a TMM core file to the /shared/core directory.
