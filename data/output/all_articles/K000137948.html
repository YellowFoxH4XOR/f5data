K000137948: BIG-IP Next changing IP Address or Default Gateway

Published
2023-12-18

Legacy Content
Applies to

Source

Problem:

During installation of BIG-IP Next setup, you are asked for the IP Address and Default Gateway of the host. The values typed into the setup script are incorrect and need to be changed. 

Analysis:

You find that the initial values typed into the setup script are incorrect and need to be changed. 

Resolution:

For Central Manager -

First, edit the file /run/systemd/network/10-netplan-ens192.network on the Central Manager host and change the values.
Then, restart the network service. 
sudo vi /run/systemd/network/10-netplan-ens192.network

sudo service systemd-networkd restart


For Virtual Edition - 

First, edit the file /run/systemd/network/10-netplan-ens160.network on the Virtual Edition host and change the values.
Then, restart the network service. 
sudo vi /run/systemd/network/10-netplan-ens160.network

sudo service systemd-networkd restart
