Known Issue

This is the result of a known issue. When restoring a backup, certain fields in the LDAP Mapping Method will not be restored if changes have been made to those fields since the time of the backup.

Configuration of LDAP as a mapping method is done on the Users: Groups: Dynamic Group Mapping page, under the Group mapping methods tab in version 6.0.0 and later, and the Request configuration tab in versions prior to 6.0.0. If you backup your FirePass configuration, the Search Base DN and Attributes to map group fields on the Group mapping methods tab cannot be restored to the values in the backup if you make changes to these values after the creation of the backup. Instead, when you perform the restore operation using the backup file, the existing values will remain.

F5 Product Development tracked this issue as CR64875 and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

Workaround

You can restore field values by deleting the LDAP mapping method, and performing a restore. To do so, perform the following procedure:

Important: If you intend to use this Workaround, be certain that the needed values are on the backup you want to restore. Alternatively, F5 recommends performing a backup of the current configuration, just before restoring from an older backup. If the older backup does not have the desired values, then you can restore the backup you just created.

  1. Log in to the FirePass Administrative Console.
  2. Click Users.
  3. Click Groups.
  4. Click Dynamic Group Mapping.
  5. Click the Group Mapping Methods tab (version 6.0.0 or later), or the Mapping Methods tab (versions prior to 6.0.0).
  6. Click the Delete link next to LDAP (user object).
