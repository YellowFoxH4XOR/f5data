Known Issue

Description

The ARX system may stall during an import of a new share.

This issue occurs when the following conditions are met:

  • A previous share import failed
  • A user removed the failed share configuration, and did not re-import it

If an import fails, the ARX system stores the share information in a queue. If a user removes the share before the issue is resolved, the ARX system does not take into account the stored queue information in the share removal process. The task that is left in the queue will prevent imports of lower priority shares from importing.

Impact

The ARX system will stall during import of a new share.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The ARX system will stall during import of a new share.
  • An error message logged to the ARX syslog appears similar to the following example:

Storage Import Scan for volume '/voltest' share [test_share] priority '300' waiting for higher priority share [(ID 41)] priority '90'.

Workaround

To work around this issue, you can enable the import sync-attributes option when importing a new share. To do so, perform the following procedure:

Impact of workaround: Attributes on the importing directories may be modified.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enable global mode by typing the following command:

    global
  4. Enable the namespace configuration mode using the following command syntax:

    namespace [namespace name]

    For example:

    namespace test
  5. Enable the volume configuration mode using the following command syntax:

    volume [volume name]

    For example:

    volume voltest
  6. Enable the share configuration mode using the following command syntax:

    share[share name]

    For example:

    share sharetest
  7. To enable the sync attritubes feature, enter the following command:

    import sync-attributes
  8. Exit the channel configuration mode and return to privileged mode by typing the following command:

    end
