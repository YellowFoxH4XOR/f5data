Description

Attempting to load the config will yield a warning message similar to the one below:

/Common/example_iRule:3: warning: [The following errors were not caught before. Please correct the script in order to avoid future disruption. "invalid 'content'; expected:-version"151 287]

Environment

  • BIG-IP
  • iRule

Cause

  • iRule's content tab spacing
  • Below is an example: 
ltm rule /Common/example_iRule {
when HTTP_REQUEST {
if { not [class match [IP::remote_addr] equals whitelist_example] || [class match [IP::remote_addr] equals whitelist_example2] } {
HTTP::respond 200 content "<HTML><p align=\&#8221;center\&#8221;> System maintenance is required
</body></html>" \       "Content-type" "text/html" "pragma" "no-cache" "retry-after" "600"                 
  } else { #go to default pool }
}
}

Recommended Actions

  1. Reviewing respective iRule's content.
  2. Replace the suspicious tab spacing with a general spacing.
           Example line: 
  
          </body></html>" \       "Content-type"
           
           Replace with:
  
          </body></html>" \ "Content-type"
