Description

While testing the command execution attack "cmd=uname+ -a" is not being detected as an attack by the BIG-IP ASM.

Environment

  • BIG-IP ASM
  • Security policy
  • Attack Signatures
  • Unix/Linux server

Cause

The correct attack signature set is not assigned to the security policy.

Recommended Actions

  1. Log on to the BIG-IP ASM Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Expand Attack Signatures.
  4. Click on "Change".
    Note: A pop-up window will appear.
  5. Add the attack signature set Unix/Linux Signatures (High/Medium Accuracy).
  6. Click Save.
  7. Click Apply Policy.
     
Additional Information

You can test that is being blocked using a curl command like this:

# curl -i -v -k -A 'curl/7.64.0' -H 'X-Forwarded-For: 192.168.20.20' -X POST -d "cmd=uname+ -a" https://<virtual server>/
