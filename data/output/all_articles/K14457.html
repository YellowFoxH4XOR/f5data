Example 1:

To find the Tomcat version, type the following command:

rpm -qa | grep tomcat

The output from a BIG-IP system running BIG-IP 11.5.0 appears similar to the following example:

tomcat-6.0.37-1.0.0.221

The numeric value after the first dash ( - ) indicates the Tomcat software version is 6.0.37.

Example 2:

To find the MySQL version, type the following command:

mysqld -V

The output from a BIG-IP system running BIG-IP 11.5.0 appears similar to the following example:

mysqld Ver 5.1.71-enterprise-commercial-advanced for pc-linux-gnu on i686 (Source distribution)

The MySQL version is 5.1.71.
