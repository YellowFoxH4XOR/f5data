K000091349: When connecting to the internal VIP, everything was working as expected, however, when connecting through the DMZ, the connection is failing with "ERR_EMPTY_RESPONSE"

Description

When connecting to the internal VIP, working as expected, however, when connecting through the DMZ, connection fails with "ERR_EMPTY_RESPONSE"

 

 Environment

  • Layered Virtual
  • DMZ
  • BIG-IP 15.1.2

 

 Cause

The internal virtual server is encrypted on the frontend and is a pool member for the DMZ virtual. The DMZ virtual has no server side SSL profile applied, however, leading to a failure in TLS communication between the Internal VIP and the DMZ virtual.

 

 Recommended Actions

Add a serverssl profile to the DMZ virtual server to enable TLS communication

 

 Additional Information

K14806: Overview of the Server SSL profile (11.x - 16.x)
