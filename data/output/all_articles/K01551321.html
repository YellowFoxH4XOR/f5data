Description

  • Trying to enable OCSP stapling
  • Message "Status monitoring is not enabled or Status is not yet available" (grey square) in certificate's Monitoring Properties
  • Counter for " Validity Errors" in OCSP object stats page (section "Response Validation Errors") increases every time customer clicks on "Update Status Monitor" on the certificate page

Environment

  • BIG-IP LTM
  • Traffic Certificate Management
  • status-age value in OCSP configuration was changed from default "0"
    sys crypto cert-validator ocsp /Common/ocsp_config {
        dns-resolver /Common/dns_resolver
        route-domain /Common/0
        sign-hash sha1
        status-age 300            < this was changed from default "0"
        strict-resp-cert-check disabled
    }

Cause

Changed Status Age setting in OCSP configuration.

Recommended Actions

  • Leave Status Age at default "0" seconds or match it to the interval the OCSP server gives in its response/update.

Additional Information

The example below shows an OCSP response with the update interval details:

                        certStatus: good (0)
                  good
              thisUpdate: 2019-03-17 06:00:00 (UTC)
              nextUpdate: 2019-03-24 06:00:00 (UTC)

Note: The above lines will show that that OCSP server updates every 7 days (604800 seconds).
