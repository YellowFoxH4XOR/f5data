Topic

You should consider using this procedure under the following condition:

  • You want to translate management information base (MIB) object identifier (OID) names between numeric and textual forms.

Description

You can use the snmptranslate command to translate MIB OID names between numeric and textual forms. To do so, perform the following procedures.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have command line access to the BIG-IP system.

Procedures

  • Finding an SNMP OID numeric value when the string name is known
  • Determining the MIB file to which a variable belongs
  • Printing all of the object OID pairs in a particular MIB file

Finding an SNMP OID numeric value when the string name is known

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To find an SNMP OID numeric value when the string name is known, use the following command syntax:

    snmptranslate -On <MIB NAME>::<Object Name>

    For example:

    snmptranslate -On F5-BIGIP-LOCAL-MIB::ltmVirtualServStatCsMeanConnDur

    The following value is returned:

    .1.3.6.1.4.1.3375.2.2.10.2.3.1.4

    Note: It is important that you use the name of the MIB without the .txt extension, otherwise an error will occur.

Determining the MIB file to which a variable belongs

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To determine the MIB file to which a variable belongs, use the following command syntax:

    snmptranslate -IR <Object Name>

    For example:

    snmptranslate -IR ltmVirtualServStatCsMeanConnDur

    The following value is returned:

    F5-BIGIP-LOCAL-MIB::ltmVirtualServStatCsMeanConnDur

    The previous output indicates that the F5-BIGIP-LOCAL-MIB is the MIB file that contains the object ltmVirtualServStatCsMeanConnDur.

Printing all of the object OID pairs in a particular MIB file

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To print out all of the object OID pairs in a particular MIB file, use the following command syntax:

    snmptranslate -On -Tz -m <path to MIB file>

    For example:

    snmptranslate -On -Tz -m /usr/share/snmp/mibs/F5-BIGIP-COMMON-MIB.txt

    The following values are returned:

    "org"                   "1.3"
    "dod"                   "1.3.6"
    "internet"                      "1.3.6.1"
    "directory"                     "1.3.6.1.1"
    "mgmt"                  "1.3.6.1.2"
    "mib-2"                 "1.3.6.1.2.1"
    "transmission"                  "1.3.6.1.2.1.10"
    "experimental"                  "1.3.6.1.3"
    "private"                       "1.3.6.1.4"
    "enterprises"                   "1.3.6.1.4.1"
    "f5"                    "1.3.6.1.4.1.3375"

    Note: The output from the previous command is truncated for clarity.
