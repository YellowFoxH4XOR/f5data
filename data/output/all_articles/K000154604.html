K000154604: How to create VLANs and self-IPs for F5OS tenants?

Type

Published

Source

Description

You are looking for a procedure on how to correctly create VLANs and self-IPs for an F5OS tenant.

Environment

  • VLANs
  • Self-IPs
  • F5OS
  • tenant

Cause

All VLANs must be created and assigned to interfaces at the F5OS host level before attaching them to tenants. Only then can self-IPs be configured within the tenant.

Recommended Actions

  1. Create VLANs at the F5OS host level.
  2. Assign those VLANs to the appropriate LAG or physical interfaces on the F5OS host.
  3. Attach VLANs to tenants on the F5OS host. 
  4. Configure self-IPs within the tenant. 

Additional Information

Always configure VLANs at the F5OS host level, not inside the tenants.
