Known Issue

Network Access sessions may have an incomplete proxy.pac file.

This issue occurs when all of the following conditions are met:

  • Your Network Access profile specifies a Client Proxy Autoconfig Script URL for the proxy.pac file.
  • You establish an access session with the Network Access profile.
  • The referenced proxy.pac file download is larger than 65535 bytes.

Impact

The user does not receive the full proxy.pac file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Some network resources specified in the proxy.pac file may not be accessible.
  • When comparing the proxy.pac file sizes of the original and network access downloaded files, the downloaded file is truncated at 65535 bytes.
  • The user device may not receive the proxy.pac file.

Workaround

To work around this issue, you can minimize the size of the original proxy.pac file to under 65535 bytes.
