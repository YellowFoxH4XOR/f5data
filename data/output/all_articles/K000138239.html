K000138239: BIG-IP LDAP remote authentication fails

Description:

BIG-IP LDAP remote authentication fails with "Login Failed" error. The username/password provided are valid. The system configurations are verified correct. 

Environment:

  • Failed authentication
  • LDAP Server
  • UID
  • samAccountName

Cause:

On BIG-IP version 15.1.5.1 while searching for the user, the default filter used is the uid instead of samAccountName. If the uid entry is not present, the authentication will fail even though the username/passwords provided are correct.

Example :  

Recommended Action:

Set the uid as username on LDAP server under User >Properties>Attribute Editor on AD server. 


Additional Information :

None.
