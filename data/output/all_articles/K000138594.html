Description

There are limitation for named object .

When the object name is too long, it might cause unknown results.

In this case the Trunk name which too long, called:

 

"FiberUplink-LocEU-2.41-to-a03109u48-1-17-LocEU-8.1.2-to-a5510e0........"

 

The length of the Trank's name is too long - it needs to be shorter.

Environment

  • BIG IP
  • BCM56XXD Core

Cause

The length of the Trunk name is too long

Recommended Actions

To overcome this you will need to:

Step #1:   Create new Trunk with empty members with name length less than 63 characters and with constraints mentioned above.

Step #2:  Go to the Trunk you wish to modify, and remove all members (Make sure you write it aside before removing)

Step #3:  Go to the new Trunk created in Step #1 and add the members (removed in Step #3).

Important:

- Make sure this will be done in a Maintenance Window

- Do it first on Standby (once done failover and do the same on the old Active BIG IP)

- Could be Traffic impact during the procedure (i.e.: while failover to Standby)

Additional Information

Names have the following constraints:

- Must start with an alphabetic character (Aa-Zz).

- Cannot exceed 63 characters in length.

- May contain alpha-numeric characters, periods (.), hyphens (-), and underscores (_).

- Must be unique among VLANs / Trunks.
