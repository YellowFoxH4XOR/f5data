Known Issue

When you attempt to open the window to the maximum size, the BIG-IP system closes the connection.

This issue occurs when all of the following conditions are met:

  • You have configured the HTTP2 profile on a virtual server.
  • A client sends a WINDOW_UPDATE frame to increment the window value to its maximum.

Impact

The BIG-IP system treats the window size overflow as a protocol violation, shuts the connection down, and does not serve the request.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system closes client connections whenever you attempt to use the maximum window size.
