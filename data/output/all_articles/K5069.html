Known Issue

There are several reasons this can occur, one of which is a known issue. When you perform a large SNMP exchange of data on BIG-IP, such as an SNMP walk, the SNMP daemon may hang or crash due to lack of buffer space.

F5 Product Development tracked this issue as CR49695 and CR49696 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the 4.6 software branch.

Workaround

If this issue occurs, and upgrading is not an immediate option, you can resolve it by restarting the SNMP daemon.

To restart the SNMP daemon, type the following command:

bigstart restart snmpd
