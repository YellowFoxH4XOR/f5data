Known Issue

The SNMP Link monitor type may be unavailable for selection when creating/updating links.

This issue occurs when all of the following conditions are met:

  • Your system is licensed and provisioned for the BIG-IP GTM or Link Controller modules.
  • You attempt to create or update a link using the Configuration utility or the Traffic Management Shell (tmsh).

Impact

The system default link monitor for SNMP (snmp_link) is not listed.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to assign a monitor to a link, using the Configuration utility, the snmp_link system default monitor is not available.
  • When you attempt to assign a monitor to a link, using the tmsh utility, the tab complete function does not list the snmp_link system default monitor.
  • When you attempt to assign a monitor to a link, using the tmsh utility, you can manually specify the snmp_link monitor even though it is not listed.

Workaround

To work around this issue, you can use the tmsh utility and manually input the snmp_link monitor name. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. When you attempt to create a new link, specify the SNMP link monitor by typing the snmp_link default monitor name.

    For example, syntax should appear similar to the following:

    create /gtm link <link name> datacenter <datacenter name> monitor snmp_link router-addresses add { router ip address } uplink-address <local self ip address>

  3. Save the configuration changes by typing the following command:

    save /sys config gtm-only
