Topic

Beginning December 5, 2016, F5 reclassified six of the previous document types into two new document types on AskF5.com. 

Description

The new document types are listed on the AskF5.com search results page, on the left pane of the AskF5 tab, in the Filter results by document type section. The document types that appear in the section correspond to what you have typed in the search box, so all document types will not always appear.

The new document types and the previous document types that the new document types replace are listed in the following table.
