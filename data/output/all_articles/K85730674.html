Description

Unable to access MGMT Interface after reboot in Google Cloud Platform (GCP) environment

  • Before rebooting, the routing table shows there is the auto-generated default route for MGMT interface:
    netstat -nr
    Kernel IP routing table
    Destination     Gateway         Genmask         Flags   MSS Window  irtt Iface
    0.0.0.0         192.168.44.1    0.0.0.0         UG        0 0          0 external
    0.0.0.0         192.168.33.1    0.0.0.0         UG        0 0          0 mgmt    <<<<<<
     
  • After rebooting, the BIG-IP no longer has the default route for MGMT interface:
    netstat -nr
    Kernel IP routing table
    Destination     Gateway         Genmask         Flags   MSS Window  irtt Iface
    0.0.0.0         192.168.44.1    0.0.0.0         UG        0 0          0 external

Environment

  • Either Standalone or HA deployment
  • Used template to deploy BIG-IP in GCP
  • 2-NIC or 3-NIC template
  • Rebooting BIG-IP

Cause

The default route for the MGMT interface is not present after a reboot

Recommended Actions

We can fix this issue by the following ways:

Note: First run netstat -nr to verify if existing routes are present. 
  1. Connect to BIG-IP via console
  2. Manually re-create all management configurations. To do so, run the following commands to delete any existing management configuration and recreate them using the following command syntaxes:

    Note: In a 2 NIC and 3 NIC github template deployment, you may be able to retrieve the following configuration values from /config/cloud/gce/interface.config. This file is generated by the start up script when the VM instance was first created. 

  3. Open /config/cloud/gce/interface.config and copy the appropriate values for {MGMTADDRESS}, {MGMTGATEWAY}, {MGMTMASK}, {MGMTNETWORK} into the placeholders below.

tmsh modify sys global-settings mgmt-dhcp disabled
tmsh delete sys management-route all
tmsh delete sys management-ip all
tmsh create sys management-ip ${MGMTADDRESS}/32
tmsh create sys management-route mgmt_gw network ${MGMTGATEWAY}/32 type interface
tmsh create sys management-route mgmt_net network ${MGMTNETWORK}/${MGMTMASK} gateway ${MGMTGATEWAY}
tmsh create sys management-route default gateway ${MGMTGATEWAY}
tmsh save sys config

Additional Information

If the above steps do not fix the issue, verify that the management interface is configured for eth1:

tmsh list sys db provision.managementeth

For 2 NIC and 3 NIC deployments, you may need to configure management swap to eth1 with the following command syntaxes:
  1. tmsh stop stop sys service tmm
  2. tmsh modify sys db provision.managementeth value eth1
  3. reboot
