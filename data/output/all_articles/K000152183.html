Description

  • What is a DNS Flood Attack?
  • Is F5 Distributed Cloud able to protect against DNS Flood Attack?

Environment

  • F5 Distributed Cloud DDoS
  • Routed DDoS protection

Answer/Recommended Actions

  • Also called a DNS Query flood, a DNS flood is one of the most common vectors used in DDoS attacks today.
  • An attacker sends a large number of spoofed DNS request packets to a target DNS server. A small number of hosts can generate thousands of requests per second, and with spoofing, these requests appear to originate from hundreds or even thousands of different source IPs.
  • This makes it difficult for the target server to differentiate between legitimate DNS requests and malicious requests. In attempting to serve all requests, the server exhausts its resources, resulting in denial of service to legitimate users.
  • Large DNS Query floods can also saturate a customer's ISP links.
  • F5 Distributed Cloud can protect against DNS Flood attacks using several available countermeasures.
