When the BIG-IP system uses tunnels, the Traffic Management Microkernel (TMM) may lose its connection to the mcpd process, exit, and then restart, causing a traffic disruption or degraded performance.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system uses one of the following versions:
    • 17.1.0 or 17.1.0.1
    • 16.1.3.4
    • 15.1.8.2
    • 14.1.5.4
  • An IPsec, Generic Routing Encapsulation (GRE), or IPIP tunnel is in use.

Impact

TMM may disconnect unexpectedly from other BIG-IP system processes; for example, the tmrouted process. Additionally, TMM may suddenly fail to match traffic for existing virtual server connections against a connection flow, which can result in traffic stalling and timing out.

Note: In a default configuration, the system does not generate a core file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • At the time of restart, a message similar to the following example is logged to the /var/log/ltm file:

    crit tmm6[19243]: 01010020:2: MCP Connection expired, exiting
