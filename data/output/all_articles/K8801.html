Issue

If two power supplies are installed, and one of the power supplies fails or is not plugged in (leaving only one available power supply), an error message is logged to the /var/log/ltm file and to the console. The error message will appear similar to the following example:

system_check[4753]: 010d0006:0: Chassis power supply <X> is not supplying power (status: 0): make sure it is plugged in.

where <X> refers to the power supply number.

Any temporary power interruption (for example, a power cord that is briefly unplugged) may generate the error message even though the PSU may currently be on. The error message may also be generated if a PSU is slow to come up to full power at system startup.

Verify for each affected PSU that the power cable is plugged in securely, that there is energy flowing from the upstream power source, and that the PSU power switch is in the On position. If the errors persist, contact F5 Technical Support for assistance in reviewing and resolving the errors.

Note: For detailed information about locating, diagnosing, and replacing the power supply, refer to the Platform Guide for your chassis hardware model.

To stop the BIG-IP system from logging the error message, and to allow uninterrupted console access display, you can temporarily disable the BIG-IP system from monitoring the power supplies. To do so, type the following commands:

Versions 10.x

  • To disable power supply monitoring, type the following commands:

    tmsh modify sys db platform.powersupplymonitor value disable

    tmsh save sys config

  • To enable power supply monitoring, type the following commands:

    tmsh modify sys db platform.powersupplymonitor value enable

    tmsh save sys config

Version 9.x

  • To disable power supply monitoring, type the following command:

    bigpipe db Platform.PowerSupplyMonitor disable
     
  • To enable power supply monitoring, type the following command:

    bigpipe db Platform.PowerSupplyMonitor enable

Note: F5 does not support operating the BIG-IP 8800 platform on a single 460W power supply. Dual 460W power supplies or a single 475W power supply are required for normal operation. If the error message appears as the result of a failed 460W power supply, you should replace the power supply as soon as possible. For more information, refer to K8001: Power supply change notice.

Note: F5 does not support operating the BIG-IP WebAccelerator 4500 platform on a single power supply. Both power supplies are required for normal operation. If the error message appears as the result of a failed power supply, you should replace the power supply as soon as possible.
