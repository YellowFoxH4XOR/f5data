Topic

You should consider using this procedure under the following conditions:

  • You want to perform a reset or forced shutdown of a single blade in a VIPRION system.
  • You have attempted and failed to perform a graceful restart or shutdown of the blade as described in K11333: Using the clsh command to restart or shut down one or more blades in a VIPRION system.

Note: The power off function is a forced shut down. The reset function is an abrupt shutdown and restart operation that may result in loss of data in unsaved running memory.

Description

On a VIPRION system, you can use the bladectl command to execute a power off or a reset operation for a single blade in the chassis. You can perform the power off or the reset operation on the blade on which you execute the command or specify a different blade on which you execute the command.

For example, you can log in to blade1 on the VIPRION system and power off blade2 using the bladectl command. You can then perform required maintenance on blade2 and run the bladectl command on blade1 to power on blade2.

Note: The bladectl -r or bladectl -p 0 command forcefully restarts or shuts down a blade without a graceful shut down of the BIG-IP system. This may have an adverse effect on the system and should only be done as a last resort after you have attempted the procedures detailed in K11333: Using the clsh command to restart or shut down one or more blades in a VIPRION system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command line access to the VIPRION system.

Procedures

Resetting a single blade in a VIPRION system

To reset a single blade in a VIPRION system, perform the following procedure:

Impact of procedure: The VIPRION blade is unavailable for traffic processing while the blade is resetting.

  1. Log in to the command line of the VIPRION blade.
  2. To verify the slot number of the blade to which you are connected, type the following command:

    bladectl -g slot

    The command output can help you determine the blade number to specify in the bladectl command. For example, if you want to reset blade2, you may want to log in to and run the command on blade1.

  3. To reset the blade, use the following command syntax:

    bladectl -b <blade#> -r

    For example, if you are logged in to blade1 and want to reset blade2, type the following command:

    bladectl -b 2 -r

Powering off and powering on a single VIPRION blade

Impact of procedure: The VIPRION blade is unavailable for traffic processing while the blade is powering off and powering on.

  1. Log in to the command line of the VIPRION blade.
  2. To verify the slot number of the blade to which you are connected, type the following command:

    bladectl -g slot

    The command output can help you determine the blade number to specify in the bladectl command. For example, if you want to power off and power on blade2, you may want to log in to and run the command on blade1.

  3. To power off the blade, use the following command syntax:

    bladectl -b <blade#> -p 0

    For example, if you are logged in to blade1 and want to power off blade2, type the following command:

    bladectl -b 2 -p 0

  4. To power on the blade, use the following command syntax:

    bladectl -b <blade#> -p 1

    For example, if you are logged in to blade1 and want to power on blade2, type the following command:

    bladectl -b 2 -p 1
