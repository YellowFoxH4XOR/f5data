Topic

The mkdisk utility can be used to create a bootable USB thumb drive to install BIG-IP version 10.0.0 or later onto other systems.

Note: For more information, refer to the Creating a Bootable USB Thumb Drive chapter in the BIG-IP Systems: Getting Started Guide.

When BIG-IP version 10.0.0 or later is installed, an installation image is copied to the /shared/images directory. The installation image in this directory does not contain the mkdisk utility and is only used for local installation of the software onto another slot.

In order to create a bootable USB thumb drive to install the BIG-IP software, you must obtain the ISO installation image for BIG-IP version 10.0.0 or later from the F5 Downloads site, and extract the mkdisk utility from the ISO image.
