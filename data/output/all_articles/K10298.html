Known Issue

This is the result of a known issue. The NVRAM battery status may be inaccurately reported on the ARX 4000 platform. As a result, repeated NVRAM battery faults and temperature alerts will be logged to syslog, similar to the following example:

:CHASS-0-3-MSG3:: kwaiBatteryMonitor: Bad KWAI battery temperature reading: temp=15366 C.
:L2SW_LVL7-0-5-MSG5:: SNMP TRAP: nvramBatteryFail (419) : Nvram battery  :: fault/temperature
...
:L2SW_LVL7-0-5-MSG5:: SNMP TRAP: nvramBatteryStatus (420) : Nvram battery :: Battery is OK.
...
:CHASS-0-3-MSG3:: kwaiBatteryMonitor: Bad KWAI battery temperature reading: temp=15365 C.
:L2SW_LVL7-0-5-MSG5:: SNMP TRAP: nvramBatteryFail (419) : Nvram battery  :: fault/temperature

Note: This behavior is a reporting issue; it does not impact system performance.

F5 Product Development tracked this issue as ARX ID 35115 and it was fixed in ARX version 5.0.5. For information about upgrading, refer to the ARX release notes.
