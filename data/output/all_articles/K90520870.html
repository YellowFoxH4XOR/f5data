Description

BigIP configuration may fail to load after upgrading software from 14.1.4 to 15.1.3

Environment

  • Upgrading BigIP to version 15.1.3

Cause

This is due to a certain buggy condition that produces this error message logged to /var/log/ltm

01070260:3: Can't change shell for username myusername (couldn't read from `/etc/passwd.lock': Failed to open file '/etc/passwd.lock': Permission denied) Error: failed to reset strict operations; disconnecting from mcpd. Will reconnect on next command. Data Input Error: 01070734:3: Configuration error: Current folder /Partition1 has been removed. Exit session. 
 

Recommended Actions

  1.  Reboot into working 14.x volume.
  2.  Delete broken 15.x volume and reinstall 15.1.3. software creating new volume.
  3.  Boot into new 15.x volume copying config from source volume.
  4.  If issue persists then execute the following commands in new 15.x volume:

            # cd /etc 
            # mv passwd.lock passwd.lock.bkup
            # chmod 644 passwd
            # tmsh load sys config partitions all
