Description

BIG-IP DNS is configured to distribute dns answers between pool members across different data centers and need to check if WideIP load balancing is working as expected.

Environment

  • BIG-IP DNS
  • WideIP
  • Load balancing between Pool members on different DC's

Cause

None

Recommended Actions

Reset the statistics for the pool members in question and monitor the Pool stats to assess if it's working as expected.

If statistics are showing even distribution, then the imbalance of traffic is likely caused by an external factor to BIG-IP DNS.

Additional Information

Command: reset-stats
