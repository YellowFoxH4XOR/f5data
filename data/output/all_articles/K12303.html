Known Issue

This is the result of a known issue. When using BIG-IP APM web applications to access Microsoft Office documents that are located on a Microsoft SharePoint 2010 server, the documents will be opened in a read-only mode.

This error occurs because of a change in the way SharePoint 2010 requests authentication information.

F5 Product Development is tracking this issue as ID 336646 for FirePass.

F5 Product Development tracked this issue as ID 336992 for BIG-IP APM and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

In addition, this issue has been fixed in cumulative Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
