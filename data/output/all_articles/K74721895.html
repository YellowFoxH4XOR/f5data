Description

  • Error message observed in /var/log/tmm

    err tmm2[12285]: 01010227:3: DNSSEC: For DNSSEC key /Common/dns_sec_key, master key failed to decrypt private key:

Environment

  • BIG-IP DNS
  • DNSsec

Cause

DNSsec key failed to be decrypt with master key, it happens when restoring DNS ucs with DNSsec configuration for single device.
If the error shows on some device of DNS sync group, it means the DNSsec key generated on other device failed to decrypted on this device, which indicates the DNS sync group is running with different master key.
Master key must be same to make sure DNSsec work properly in a DNS sync goup,

Follow the solution link below to fix:
K13542: Restoring DNSSEC or password protected configuration data to a BIG-IP GTM or BIG-IP DNS RMA unit
