K9882: Symantec Client Security and Symantec EndPoint Protection may falsely detect the urvpn.exe file as Suspicious.Farfli

Type
Knowledge

Updated

Applies to

  • FirePass: 6.0.3
Source

Topic

The urvpn.exe file is a FirePass client component used with the Network Access feature. If a client system has Symantec Client Security or Symantec EndPoint Protection installed, the Symantec product may falsely detect urvpn.exe as having a Suspicious.Farfli threat. This behavior is due to an issue with the Symantec detection mechanism, and not an issue with the FirePass client component.

In February of 2009, Symantec issued a virus database update that corrects this behavior. Users affected by this issue should download the latest virus definitions for their Symantec products.

Note: For more information about Suspicious.Farfli, refer to the following location:

http://www.symantec.com/en/th/enterprise/security_response/writeup.jsp?docid=2008-103115-5014-99.
