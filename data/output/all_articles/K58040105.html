K58040105: Native RDP resources can't be launched from APM Webtop with Mac RDP 10.6.0 - 10.6.2 client

Type
Support Solution
Published
2021-04-21
Updated
2023-10-16
Applies to
  • BIG-IP Platforms
Source
https://my.f5.com/manage/s/article/K58040105
Description

Mac RDP client 10.6.x shows credentials prompt when SSO-enabled native RDP resource is launched from the APM Webtop.
If the user enters credentials manually, the RDP client will display an error message:

An error occurred while communicating with the Remote Desktop Gateway. If this keeps happening, contact your network administrator for assistance.

In /var/log/apm, you may see an error similar to this:

err vdi[<pid>]: 019cffff:3: /Common/<profile_name>:Common:<sessionid>: {2c7.C} An exception is thrown (TMEVT_INGRESS): handshake: short read

Environment

  • Mac RDP client is v10.6.0 - v10.6.2 (e.g., 10.6.1)
  • Native RDP
  • SSO is enabled on the RDP Resource
Cause

Microsoft resolved bug:
"In this release we fixed a bug that was causing the client to return a 0x507 error code."

Per the app store version release notes:
Mac App Store - Microsoft Remote Desktop

Recommended Actions

Upgrade to the current latest version (10.6.3 at the time of writing)

Workaround:

Stay on app version 10.5.x

None
