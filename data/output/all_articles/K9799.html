Known Issue

This is the result of a known issue. The region.user file contains a customized collection of topology regions used for BIG-IP GTM topology load balancing. The mcpd process uses an inefficient method for deleting unmarked BIG-IP GTM region items. As a result, a large region.user file takes several minutes to reload when performing an operation that affects multiple lines in the region.user file, such as changing the netmask in several thousand region item CIDR masks. This issue may cause an mcpd process heartbeat timeout event.

F5 Product Development tracked this issue as CR117588 and it was fixed in BIG-IP GTM 9.4.7. For information about upgrading, refer to the BIG-IP GTM Release Notes.
