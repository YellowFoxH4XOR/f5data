Known Issue

Operator-level users are unable to perform top-level views of the BIG-IP system configuration.

This issue occurs when all of the following conditions are met:

  • You log in to the BIG-IP system TMSH shell (tmsh) with Operator-level authorization.
  • You attempt to perform a top-level view, or full listing, of the BIG-IP system configuration using the show or list command.

Impact

Operator-level users are unable to perform top-level views of the BIG-IP system configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You receive the following error when attempting to perform a top-level view of the BIG-IP system configuration using the show or list command:

    (tmos)# list
    Unexpected Error: Can't display all items, can't get object count from mcpd

Workaround

To work around this issue, you can perform top-level views by configuration object type. For example, to view all of the BIG-IP system pools, type the following command:

tmsh list ltm pool

Impact of workaround: Performing the recommended workaround should not have a negative impact on your system.

Note: Refer to the Traffic Management Shell (tmsh) Reference Guide for a full list of tmsh commands. For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.
