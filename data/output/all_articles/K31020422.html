Description

When running a port scan from an external host, it appeared that the BIG-IP system was responding on TCP ports which were not open by any virtual server.

Environment

  • BIG-IP LTM
  • BIG-IP Virtual Addresses and Virtual Servers
  • No specific TMOS version.

Cause

A device in front of the BIG-IP system was responsible for sending SYN/ACK responses to the client.

Recommended Actions

  1. Use tools, such as tcpdump and netstat, to verify whether or not the BIG-IP system is sending the responses. Both of these are available from the BIG-IP command line.

Additional Information

None
