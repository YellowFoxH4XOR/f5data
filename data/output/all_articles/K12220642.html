Description

You may observe AVR processes running on the system even though the AVR module is not explicitly provisioned.

Environment

  • BIG-IP AVR
  • One or more of the following modules is provisioned: AFM, ASM, APM

Cause

AVR is a BIG-IP module that tracks, analyzes, and visualizes application-layer performance, client traffic, and network latency in real time.

AVR includes several daemons that collect, normalize, and aggregate performance and application data. It also maintains a database where traffic and performance statistics are stored.

Certain BIG-IP modules implicitly use AVR for statistics collection and reporting, including ASM, AFM, and APM. Therefore, AVR-related processes may run even when AVR is not explicitly provisioned.

Answer/Recommended Actions

This is expected behavior.

Administrators should monitor system resource usage and consider AVR activity as a possible factor when investigating abnormal system behavior.
