Known Issue

You may be unable to access Citrix Storefront browser-based resources.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured in integration mode with Citrix StoreFront.
  • The BIG-IP APM system is configured for Citrix StoreFront authentication pass through.
  • Access session users attempt to access browser-based Citrix StoreFront resources.

Impact

You are unable to access the Citrix StoreFront resources.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to access the Citrix StoreFront browser based resource, you may observe an error message similar to the following example:

    'Can not complete the request', press 'OK'/

  • When you view HTTP headers that the BIG-IP APM system sent to the Citrix StoreFront server, you observe multiple instances of the following header:

    X-Citrix-Via-Vip:<header value>

Workaround

To work around this issue, you can use an iRule to remove the duplicate HTTP headers. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. In the new iRule Name box, type a name for the iRule.
  5. In the Definition box, enter the following text:

    when HTTP_REQUEST {
       if { [HTTP::header count "X-Citrix-Via-Vip"] >= 2 } {
            HTTP::header remove "X-Citrix-Via-Vip"
            HTTP::header insert "X-Citrix-Via-Vip" "10.10.10.10"
        }
    }

  6. Click Finished.
  7. Navigate to Local Traffic > Virtual Servers.
  8. Click the name of the affected BIG-IP APM virtual server.
  9. Click the Resources tab.
  10. In the iRules section, click Manage.
  11. From the Available column, select the iRule you previously created.
  12. Click the << button to move the iRule to the Enabled column.
  13. Click Finished.
