Known Issue

This is the result of a known issue. When you access a Portal Access Windows File Favorite with a Mozilla-based web browser, such as FireFox, you can save the file by clicking the Download and save locally link. If you click that link to save a ZIP archive and compression is enabled in the FirePass controller, the downloaded ZIP archive may become corrupted.

To determine whether compression is enabled, log in to the FirePass Administrative Console and navigate to the Portal Access: Web Applications: Caching and Compression page. Compression is enabled if the Enable Compression. Saves bandwidth, at the expense of server resources. check box is selected.

F5 Networks Product Development tracked this issue as CR80273 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.
 

Additionally, this issue was fixed in the Cumulative Hotfix 601-4 for FirePass version 6.0.1. You may download this hotfix or a later version of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about how to obtain a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
