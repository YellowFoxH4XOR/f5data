Known Issue

The Force to Standby button in the Configuration utility may be deactivated.

This issue occurs when all of the following conditions are met:

  • You have configured multiple traffic groups.
  • You select the Select All check box on the Device Management > Traffic Groups page.

Impact

You cannot activate all traffic groups to force to standby simultaneously using the Force to Standby button.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Force to Standby button is greyed out and deactivated when using the Select All check box.

Resolution

Status

F5 Product Development has assigned ID 528971 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Release11.6.1K2200: Most recent versions of F5 software
Hotfix12.0.0 HF1K9502: BIG-IP hotfix matrix

Workaround

There is no work around this issue. However, instead of using the Select All check box, you can select each traffic group individually to activate the Force to Standby button.
