Security Advisory Description

This issue occurs when all of the following conditions are met:

  • You configure Ping Identity Services in the BIG-IP APM system for user authentication and authorization.
  • You are running a BIG-IP APM version using the Ping Access SDK that is vulnerable.

Impact

This vulnerability can lead to user impersonation and authorization bypass.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Users have access to internal resources for which they are not authorized.
