Description

While checking thorough Configuration Utility under System -> Software Management, you observe Boot Locations, Image List and Hotfix List information are missing. However, device was found to be functioning properly performing all the intended functions. 

Environment

  • BIG-IP
  • Configuration Utility / GUI

Cause

Multiple possible causes exist and it require further analysis to know the root cause. Some of the possible causes can be:

  • Multiple system level files were removed
  • Corrupted Operating System

Recommended Action

  • Take a current Configuration Backup and store it at a place for easy later retrieval.
  • Login to CLI and reboot the device, post reboot verify the if the missing boot locations and image list details are available.
  • If reboot doesn't fix the issue then follow the below steps:
    • Reboot the system from any other known latest working partition and perform the fresh installation of required version in a new partition. 
    • Upgrade/Update the system with new partition.
    • If no other boot partition exists, then build the device with minimal configuration and restore it with backup configuration. 

Additional Information

In case you still need further support, open a service request by contacting to F5 contact support and upload a fresh qkview file describing the GUI problem in detail.
