K000138359: Add split_clients_module in nginx and test functionality

Applies to

  • NGINX Plus: R27
Source

Description

You want to add the split_clients_module in your configuration and need a use case to test functionality.

Environment

Nginx Plus

Cause

New installation of nginx / new implementation of the module.

Recommended Actions

By default, the split_clients_module comes pre-built in nginx so there are no additional steps to start using the module.
The best way to test the functionality is with a sample use case, you can use the following example:
 

http {
...
    split_clients "$request_id" $upstream {
                   50%               myapp-5511;
                   50%               myapp-5522;
                   *                  "";
    }
    upstream myapp-5511 {
        server 127.0.0.1:5511;
    }
    upstream myapp-5522 {
        server 127.0.0.1:5522;
    }
    server {
..
      location / {
          proxy_pass http://$upstream/;
...
      }
      }

 

Additional Information

After adding the split_clients block and restarting the nginx service, you should be able to confirm it is working as expected, splitting the traffic evenly:
 

➜  nginx curl http://127.0.0.1:443/ --insecure -v | grep "nginx 55"
<p><em>Thank you for using nginx 5511.</em></p>

➜  nginx curl http://127.0.0.1:443/ --insecure -v | grep "nginx 55"
<p><em>Thank you for using nginx 5522.</em></p>

➜  nginx curl http://127.0.0.1:443/ --insecure -v | grep "nginx 55"
<p><em>Thank you for using nginx 5511.</em></p>
