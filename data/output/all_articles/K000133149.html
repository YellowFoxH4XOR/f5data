K000133149: [F5OS] cannot see F5OS image/iso after uploading

Type
Support Solution
Published
2023-03-23
Updated
2023-03-23
Source
https://my.f5.com/manage/s/article/K000133149

Description

After you upload an F5OS iso or image to /var/import/staging/ and /var/export/chassis/import/iso/ directory, you're not able to see the image when you run the command from the confd: 'show system image'


Environment

  • F5OS-A
  • Uploading iso to directory (/var/import/staging/ and /var/export/chassis/import/iso/)
  • ISO has the correct image name (For ex. F5OS-A-1.3.2-13054.R2R4.iso)

Cause

Not known as of this writing


 Recommended Actions

  1. Validate if the ISO name is correct, for example: F5OS-A-1.3.2-13054.R2R4.iso
    1. Please take note that a filename like F5OS-A-1.3.2-13054.R2R4(1).iso is considered not valid
  2. Verify md5sum result:
    1. Upload the md5 sum file to the same directory
    2. Run the command: md5sum --check F5OS-A-1.3.2-13054.R2R4.iso.md5
  3. If Step 2 result is OK, reboot the appliance
  4. After reboot it should list the iso:

appliance-1# show system image
