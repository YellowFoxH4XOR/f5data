Description

After upgrading an active/standby HA pair, when navigating to Access  ››  Guided Configuration page on the standby unit, the page does not load and the "The requested URL was not found on this server" error is displayed, instead.

On the active unit, AGC still loads fine.

Environment

  • BIG-IP APM HA pair with Access Guided Configuration (AGC)

Cause

the f5-iappslx-access-framework version was found to be different on the HA units, for some reason:
 active (working) = 1.4.1
 standby (not working) = 1.1.0

To check the installed f5-iappslx-access-framework version, navigate to iApps  ››  Package Management LX

Alternatively, you can also check in /var/tmp/storage_text_dump.txt. In the below sample logs, the installed f5-iappslx-access-framework version is 1.4.1

Recommended Actions

1. on the active unit (working): navigate to iApps  ››  Package Management LX. select "f5-iappslx-access-framework" and then click 'Export'

NOTE: you'll get a message similar to the following after the export. Take note of this location as we will be downloading this rpm file shortly.

Rpm files written:
/var/config/rest/iapps/RPMS/f5-iappslx-access-framework-1.4.1-0.0.1204.noarch.rpm

2. use winscp (or any similar tool) to download the rpm file from the above-mentioned directory, and save it on your PC

3. on the standby unit (not working): navigate to iApps  ››  Package Management LX. uninstall "f5-iappslx-access-framework". once it has been successfully uninstalled, proceed to import the "f5-iappslx-access-framework-1.4.1-0.0.1204.noarch.rpm" file we downloaded earlier from the active unit.

4. check to see if this fixes the issue on the Access Guided Configuration page on the standby unit.

5. If the error is encountered on standalone device or unable to export  iApps "f5-iappslx-access-framework" from working device, follow below procedure
 
  • Navigate to https://my.f5.com/manage/s/downloads. Choose BIG-IP and then choose 'Guided configuration'. Download the Access and Advanced WAF Guided Configuration .
  • Unpack the archive
  • In the list of files, you should see a file with a name similar as the following:
         f5-iappslx-access-framework-**.rpm
  • In BIG-IP Configuration Utility navigate to "iApps ›› Package Management LX"
  • Uninstall f5-iappslx-access-framework
  • Import f5-iappslx-access-framework-**.rpm file from step 4. New package will be installed.
  • Verify the error is gone when going to  Access > Guided Configuration
