Description

You are using the F5 Access application to connect to VPN from an Android device and you notice that the connection is not established or even it is unexpectedly closed.

Environment

  • Always on VPN is not automatically connecting on the device start-up
  • F5 Access App
  • BIG-IP 15.0.0 and later.
  • Android

Cause

This issue can be caused by multiple independent factors. To get more insights into the problem, please follow the Recommended Actions below.

Recommended Actions

​​Please provide the following data from both BIG-IP APM and Android Client with the following steps.
  1. Close and delete any previous VPN sessions established between the BIG-IP and the client.
  2. Enable Debug Level Logging for the Access Policy.
a. Navigate to Access  ››  Overview : Event Logs : Settings.
b. Create a new logging provider, check the Enable Access System Logs box.
c. In the Access System Logs tab, set the logging level for Access Policy to "Debug".
d. In the Access Profiles tab, select the affected profile (move to the right).
 
     3. Connect to the BIG-IP APM CLI and modify the tcpdump db keys via CLI:
tmsh modify sys db tcpdump.sslprovider value enable
tmsh modify sys db tm.rstcause.log value enable
tmsh modify sys db tm.rstcause.pkt value enable
tmsh modify sys db log.ssl.level value Debug
 
     4. Start a packet capture on the BIG-IP with the following command and replace x.x.x.x with the public IP which is assigned to the client:
tcpdump -vv -nni 0.0:nnnp --f5 ssl -s0 -w /var/tmp/${HOSTNAME}_$(date +%d_%b_%H_%M_%S).pcap host x.x.x.x

     5. Reproduce the problem from the affected device and start the VPN connection.
     6. Take note of the APM Session ID associated with the failed attempt. To find the Session ID in BIG-IP, navigate to: Access  ››  Overview  ››  Access Reports and search for the Client IP.
     7. Stop the packet capture with CTRL-C.
     8. Collect logs from the BIG-IP:
tar zcvf /var/tmp/${HOSTNAME}_$(date +%d_%b_%H_%M_%S).tar.gz /var/log/*
     9. Collect the VPN logs from the client. Please refer to 'F5 Access Android' section in K00819308: Gathering F5 VPN client logs.
    10. Generate a qkview file from the BIG-IP CLI:
         qkview -s0 -f /var/tmp/"$HOSTNAME"_"$(date +%H-%M-%S-%d-%m-%y)".qkview
    11. Please upload all files to the case using:  K000090853: Exchange files with F5 Support using MyF5
