Description

How caching works in NGINX as a Service for Azure (NGINXaaS)?

Environment

  • NGINXaaS
  • Cache

Cause

Active-Active configuration

Recommended Actions

NGINXaaS is deployed in an active-active configuration with multiple instances. When the cache is filled on one instance it might still be empty on another. At times the VMs are replaced that can also clear the cache.
 

Additional Information

The Pragma:no-cache header is added by clients to bypass all intermediary caches and go straight to the origin server for the requested content. NGINX does not honor the Pragma header by default, but you can configure the feature with the following proxy_cache_bypass directive.
