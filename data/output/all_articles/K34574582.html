K34574582: GTM Ratio load balancing not responding as expected

Type
Support Solution
Published
2021-05-11
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP GTM
Source
https://my.f5.com/manage/s/article/K34574582

Description

  • Changes to GTM Ratio load balancing pool ratios are not quickly reflected in the load balancing result
  • GTM answers with pool members with Ratio set to 0

Environment

  • Ratio load balancing selected and 1 or more of the following
    • Recent changes to ratio values
    • max-answers-returned configured to a value greater then 1
    • Configuring Ratio value to 0 instead of disabling the pool member

Cause

GTM does not reference the configured wideip pool ratios for every query.  GTM maintains an internal 'ratio counter' for each pool member and that counter is set to the pool members configured ratio when the pool member is created.  For every Ratio load balance decision, the GTM will return the pool member with the highest ratio counter and will also decrement the ratio counter by 1.  If there are no available pool members with non-zero ration counters then all the ratio counters are reset back to the configured values for the pool.
If the combined ratios are high and incoming query volume is low, a significant delay can exist between updating a pool members ratio and seeing a change in the load balancing results.

If max-answers-returned is set to a value greater then 1 there also exists a case where pool members with ratio configured to 0 may be returned as an answer to the query.  If there are available pool members with ratio counter greater then 0, but not a sufficient number to satisfy the configured max-answers-returned, then GTM will round-robin among available pool members that have a ratio counter 0 if necessary to satisfy the configured max-answers-returned.
 

Recommended Actions

  1.  Reduce configured Ratios to lowest possible for desired effect.
      Example use ratios 3:2:1 instead of 30:20:10
  2. Disable pool members instead of setting ratio to 0

Additional Information

Configure GTM Decision Logging to show how the response is picked.
