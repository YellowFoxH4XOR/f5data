To add a mail server to your DNS, add an MX record to the zone records with an A record pointing to that address, as in the following example:

domain.com.      IN SOA  3dns.domain.com.    postmaster.domain.com. (
            1	  ; Serial example as YYYYMMDDHH
            3600    ; Refresh
            900     ; Retry
            3600000 ; Expire
            30 )    ; Minimum (actually default ttl)
; Domain DNS servers
domain.com.            IN NS          3dns.domain.com.
              	     

; Mail servers
domain.com.         IN MX 10    mailserver.domain.com.

; Name to Address mapping

mailserver.domain.com.  IN A           192.168.101.202

In this example, mail resolving to domain.com goes to the mail server named mailserver.

The metric 10, after the letters MX, is the preference value for that server. The default value is either 5 or 10. A lower preference value means that server gets higher priority. If you are running sites using several mail servers, you may want to assign different servers a higher or lower preference value based on pertinent factors.
