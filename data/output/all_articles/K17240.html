Issue

Error Message

error: status 256 returned by command: F5_INSTALL_MODE=install F5_INSTALL_SESSION_TYPE=hotfix chroot <mount point> /usr/local/bin/im -force /var/local/ucs/config.ucs
info: >++++ result:
info: Extracting manifest: /var/local/ucs/config.ucs
info: /: Not enough free space
info: <required size> bytes required
info: <available size> bytes available
info: /var/local/ucs/config.ucs: Not enough free disk space to install!
info: Operation aborted.

In this error message, note the following:

  • <mount point> refers to a temporary location mounted on the BIG-IP system while running the cpcfg utility.
  • <required size> refers to the size of the user configuration set (UCS) file created from the source slot.
  • <available size> refers to the size of the target slot.

For example:

error: status 256 returned by command: F5_INSTALL_MODE=install F5_INSTALL_SESSION_TYPE=hotfix chroot /mnt/tm_install/12714.vmlZsA /usr/local/bin/im -force /var/local/ucs/config.ucs
info: >++++ result:
info: Extracting manifest: /var/local/ucs/config.ucs
info: /: Not enough free space
info: 216061952 bytes required
info: 167553024 bytes available
info: /var/local/ucs/config.ucs: Not enough free disk space to install!
info: Operation aborted.

Message Location

You may encounter this message in the following location:

  • The SSH session console output

Description

This issue occurs when all of the following conditions are met:

  • You attempt to apply a copy of BIG-IP configurations to another software slot by using the cpcfg utility.
  • The version of the target software slot is the same as, or newer than, the source slot version.
  • The target software slot does not have sufficient disk space to accommodate the size of the configuration from the source software slot.

Impact

The cpcfg utility is unable to copy BIG-IP configurations to the designated target software slot.

Recommended Actions

You can free disk space by performing one or more of the following:
  • Remove non-critical maintenance files from the source software slot, per K14403: Maintaining disk space on the BIG-IP system (11.x - 14.x).
  • Delete unnecessary boot locations to free up disk space. For more information, refer to K33265170: Deleting a boot location volume to free up disk space.
