Description

You want to verify the backend server with protocol TLS 1.3 but cannot use the curl command on BIG-IP to verify.

Environment

  • BIG-IP
  • curl version 7.47.1

Cause

The curl software version on BIG-IP does not support protocol TLS 1.3.

According to the curl SSL Ciphers documentation page, support for TLS 1.3 cipher suites was added to curl in 7.61.0+:

Setting TLS 1.3 cipher suites is supported by curl with OpenSSL (1.1.1+, curl 7.61.0+), LibreSSL (3.4.1+, curl 8.3.0+), wolfSSL (curl 8.10.0+) and mbedTLS (3.6.0+, curl 8.10.0+).

Note: This link takes you to a resource outside of MyF5. The third party could remove the document without our knowledge.

Recommended Actions

Use an alternate system to test the TLS 1.3 protocol of your backend systems.
