Topic

You should perform the following procedure when using a web server for user authentication.

Description

The BIG-IP APM system can use a web server to authenticate users by prompting the users for their credentials and passing them on to the web server configured for AAA authentication.

Prerequisites

You must meet the following prerequisite to perform this procedure:

  • The web server is configured to use HTTP basic/NT Lan Manager (NTLM) authentication.

    Note: For instructions about configuring your web server, refer to your web server's vendor documentation.

Procedures

Configuring HTTP form-based authentication

The following procedure provides an example of configuring a BIG-IP APM system to send user credentials to a web server that is using HTTP basic/NTLM authentication.

To configure HTTP basic authentication, perform the following three procedures:

  • Create the HTTP AAA server
  • Create the access profile
  • Apply the access profile to your virtual server

Impact of procedure: None

Create the HTTP AAA server

  1. On the navigation pane, expand Access Policy, AAA servers and click HTTP.(Beginning in version 13.0.0, select Access > Authentication > HTTP)
  2. Click Create.
  3. Type a name for your server.
  4. From the Authentication Type field, select Basic/NTLM.
  5. From the Start URI field, type the complete URL that returns the logon form.
    Make sure to include the protocol (HTTP or HTTPS, server, and port).
  6. Click Finished.

Create the Access Profile

  1. On the navigation pane, expand Access Policy, and click Access Profiles.
  2. Click Create.
  3. Enter a name for your access profile.
  4. Click Finished.
  5. Click the Edit link for the access profile you just created.
  6. Click the (+) after the Start box.
  7. Under General Properties, select Logon Page.
  8. Click Add Item.
  9. Review the prepopulated fields for the logon page and make any necessary changes.
  10. Click Save.
  11. Click the (+) after the Logon Page action.
  12. Under Authentication, select HTTP Auth.
  13. Click Add Item.
  14. Select the AAA server you created from the drop-down menu.
  15. Click Save.
  16. Click the ending action box of the Successful branch (it will be set to Deny, by default).
  17. Select Allow.
  18. Click Save.
  19. Click Close.
  20. Select the access profile you just created.
  21. Click Apply Access Policy.

Apply the access profile to your virtual server

  1. On the navigation pane, expand Local Traffic and click Virtual Servers.
  2. Click the virtual server for which you want to use HTTP authentication.
  3. Under Access Policy, select your newly-created access profile from the drop-down menu.
  4. Click Update.
