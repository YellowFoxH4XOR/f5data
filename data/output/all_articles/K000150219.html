K000150219: Disabling USB port on iSeries devices

Type
Support Solution
Published
2025-03-07
Updated
2025-03-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150219

Description

You are looking for way to disable USB port for iSeries device.

Environment

  • iSeries device

Cause

Disabling USB port might be considered due to security concerns.

Answer/Recommended Actions

There is no supported way to disable the front panel USB port on the iSeries platform. While it is possible to disable USB ports at the "device level" is in the system BIOS, as disabling the wrong port could render the system inoperable, this is not recommended or supported by F5 Support.

Additional Information

USB port is disabled by default on rSeries devices.
