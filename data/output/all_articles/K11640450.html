K11640450: BIG-IQ may have logrotate alerts in /var/log/messages

Type
Support Solution
Published
2021-11-03
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K11640450

Description

Alert logs are found in /var/log/messages.

  • BIG-IQ appears to operate correctly, however, these alerts are found in the logs
  • Logs may appear similar to: 
 example.com notice logrotate[2638]: ALERT exited abnormally with [1]

Environment

Relevant environmental factors specific to the topic

  • Normal BIG-IQ configuration
  • BIG-IQ CM 8.x

Cause

Leftover script for logrotate is not finding ASM logs in BIG-IQ.  Those logs should not be there by default.

Recommended Actions

To eliminate these errors:

1. Using a text editor of your choice, edit the file /etc/cron.d/asm_logrotate.cron and comment out the command by placing a # at the beginning of the line:

# */5 * * * * root nice -n 19 ionice -c 3 /usr/share/ts/bin/asm_logrotate

Additional Information

Bug ID 1005029: Unneeded script on BIG-IQ generates error messages when run by cron
