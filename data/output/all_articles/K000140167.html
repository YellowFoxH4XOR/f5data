K000140167: [F5OS-A] "Signature Verification Failed" after uploading image to the F5OS appliance

Source

Description

While Importing an ISO file you were prompted: Signature Verification Failed

Environment

rSeries

Cause

The internal hardware clock is set to a date outside the signature validity

You can verify this by checking the logs, run:

zgrep -i 'signature verification'

or

hwclock --show

The logs will be suggesting that the image was trying to be verified 2008 or some other 'old' date.

Recommended Actions

If the hardware clock is wrong then reset the hardware clock by running:

hwclock --systohc

... and then run "hwclock --show" to verify it was changed

Once the clock is correct, try to re-import the ISO file (make sure the old files were deleted before importing it again)

 

If the hardware clock is correct, then try

  • K13140103: [F5OS] Software status with Signature verification failed
