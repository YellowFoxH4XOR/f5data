Description

  • BIG-IP configured as http2 full proxy (ie: http2 on both client and server sides) fails to correctly transfer grpc (google rpc) traffic.
  • Http2 connection is reset by BIG-IP.

Environment

Relevant environmental factors specific to the topic

  • Http2 full proxy - http2 on both client and server sides with httprouter configured.
  • When the payload arrives from the pool member, BIG-IP sends RST_STREAM INTERNAL_ERROR (2) clientside and RST_STREAM PROTOCOL_ERROR (1) serverside.

Cause

Grpc uses trailers in its http2 flow. BIG-IP internal http framework doesn't handle trailers correctly.

Defect 751055 has been created for this issue.

Recommended Actions

Upgrade to the latest version of 16.1 or 17.1

Additional Information


Grpc traffic is typically identified by the following http2 headers:

  • user-agent: grpc-dotnet/1.2.3.0
  • content-type: application/grpc
