Known Issue

When the BIG-IP system removes an HTTP cookie from the HTTP header data, it will leave the trailing semicolon ( ; ) and whitespace on the current cookie. As a result, unexpected behavior may occur on systems that use this cookie data, such as the PingFederate Internet Identity server.

For example:

Cookie: user=joe; logon=yes
HTTP::cookie remove "logon"
Resulting cookie Cookie: user:joe;

F5 Product Development tracked this issue as ID 341217 and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM and Edge Gateway release notes.
