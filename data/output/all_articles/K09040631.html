Description

While creating an F5 SSL Orchestrator configuration that makes usage of iCAP service, you receive the following error message:

Jan  1 12:00:00 sslo.company.com err mcpd[11090]: 0107003a:3: Pool member node (/Common/10.10.10.10) and existing node (/Common/icap-node) cannot use the same IP Address (10.10.10.10).

Environment

  • F5 SSL Orchestrator

Cause

When a node is assigned to a pool that and is also referenced as a pool member the ICAP server will have the same destination as this node generating a conflict.

Recommended Actions

  1.  Detach the node from the pool(s)
  2.  Delete the node
  3.  Add a new node to the pool: just using IP:PORT, but with no name
  4.  Configure the ICAP server in SSLO to use IP:PORT
