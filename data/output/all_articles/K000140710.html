K000140710: AWAF introduces 25s latency when <any_text>://<any_text> is present in request URI

Type
Support Solution
Published
2024-08-14
Updated
2024-08-14
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.X.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000140710

Description

The security policy can introduce significant delays of up to 25 seconds for specific requests. This is observed in requests where "://" is used as part of the URI.

Example:

example.com?p=<any_value>://<any _value>

Environment

  • AWAF
  • URL

Cause

This is caused by ASM misinterpreting Other parameter data types as URI types, even though it is not a URI type. This leads to dns-lookup attempts which results in the noticed delay. This behavior is tracked by bug ID1317873.

Recommended Actions

Follow the workaround for bug ID1317873.
