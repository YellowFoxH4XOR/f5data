K25612004: Error: ''Unable to decrypt item due to No master key found''

Type
Support Solution
Published
2021-03-23
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K25612004

Description

When trying to reset BIG-IQ to factory default using "clear-rest-storage" command, the following error is seen from CLI:
 
Unable to decrypt item due to No master key found

As a result, services start to fail.

Environment

  • BIG-IQ
  • bash

Cause

unknown

Recommended Actions

Append the -d option to include the reset of the BIG-IQ system level configuration to default.

#clear-rest-storage -d

Additional Information

none
