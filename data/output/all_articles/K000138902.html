Description

When adding a BIG-IP Next instance to Central Manager, an error occurs:

Instance 10.155.74.72 could not be added. Reason: DEVICE-0206: BIG-IP Next instance discovery error: Failed to add management user in 10.155.74.72, error: user 'admin' already exists.

Environment

Relevant environmental factors specific to the topic

  • BIG-IP Next Central Manager
  • Adding an existing BIG-IP Next instance

Cause

In the Add Instance screen in which you are configuring the new username and password to manage the instance from BIG-IP Next Central Manager, you are attempting to add the user 'admin'.  This can occur if you accidentally type 'admin' or if you have a password manager that substitutes the default of 'admin-cm' with 'admin'.

Recommended Actions

  1.  Change the username back to admin-cm and try again
