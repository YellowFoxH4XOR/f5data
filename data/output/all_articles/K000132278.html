Description

"nexthop" irule command expected behaviour with auto-lasthop disabled.

Environment

iRule used to route traffic using the command "nexthop".

Cause

"nexthop" iRule command works as expected even if "AUTO LASTHOP" is disabled globally or on a given virtual server. This is expected behaviour by design.

Note: If "AUTO LASTHOP" is disabled then the system MUST be configured with relevant routing entries or lasthop pools for the server responses to be routed back to the client.

Recommended Actions

None
