K7973: The 'failed to convert character blocking' flag is disabled after upgrading the BIG-IP ASM from version 9.2.x to 9.3

Known Issue

This is the result of a known issue. Upgrading the BIG-IP ASM from version 9.2.x to 9.3.x disables the failed to convert character blocking flag in the blocking mask of the security policy. For example, if the BIG-IP ASM system is running version 9.2.x, and the failed to convert character blocking flag is enabled in the security policy, the character flag is disabled after upgrading the BIG-IP ASM system to version 9.3.x. The setting will remain disabled if the system is later upgraded from BIG-IP ASM 9.3.x to 9.4.x. This issue does not occur if you upgrade directly from BIG-IP ASM 9.2.x to 9.4.x.

F5 Product Development tracked this issue as CR80543 and it was fixed in version 9.4.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can work around this issue by enabling the failed to convert character blocking flag in the security policy. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Web Applications.
  4. Click the active security policy for which you want to enable the failed to convert character blocking flag.
  5. Choose Settings from the Blocking drop-down menu.
  6. Under the Input Violations section, select the Block check box for the failed to convert character violation.
  7. Click Save.
