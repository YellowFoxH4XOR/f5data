Issue

If you have a FirePass controller equipped with a Cavium CN1005 SSL accelerator card, you may receive the following error message on the Reports: System Logs page:
kernel   Condition code based error = 40000002

This error message indicates that an error occurred after a decryption operation, such as an incorrect pad or length of a variable in a data structure. This error message is unlikely to indicate a security issue; decryption failures usually result in the termination of cryptographic operations.

The full sequence of syslog error messages would be similar to the following example: 

kernel   Condition code based error = 40000002   
kernel   Condition code = 0200000000000000

These error messages are from the Nitrox Linux kernel driver. If the frequency of these error messages is low, they can be safely ignored. However, if the frequency is high, you may be experiencing an issue with the Cavium driver software.
