Known Issue

Using a localhost address (or a host name that resolves to a localhost address) as a remote syslog destination can cause recursive log messages.

Impact

The BIG-IP system recursively logs messages until the system runs out of disk space.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H501266 on the Diagnostics > Identified > Low screen.
  • You notice recursive log entries that appear similar to the following example:

    notice syslog-ng[29592]: syslog-ng starting up; version='2.1.4'
    notice notice syslog-ng[29592]: syslog-ng starting up; version='2.1.4'
    notice notice notice syslog-ng[29592]: syslog-ng starting up; version='2.1.4'
    notice notice notice notice syslog-ng[29592]: syslog-ng starting up; version='2.1.4'
    notice notice notice notice notice syslog-ng[29592]: syslog-ng starting up; version='2.1.4'
    notice notice notice notice notice notice syslog-ng[29592]: syslog-ng starting up; version='2.1.4'
    notice notice notice notice notice notice notice syslog-ng[29592]: syslog-ng starting up; version='2.1.4'
    notice notice notice notice notice notice notice notice syslog-ng[29592]: syslog-ng starting up; version='2.1.4'
  • The BIG-IP system recursively logs messages until the system runs out of disk space. As a result, you notice log messages similar to the following example:

    notice syslog-ng[18909]: Suspending write operation because of an I/O error; fd='25', time_reopen='60'
    notice syslog-ng[18909]: Suspending write operation because of an I/O error; fd='26', time_reopen='60'

Workaround

To work around this issue, you should avoid specifying a localhost address or host name that resolves to a localhost address. You should instead use a self IP address to specify a local address as a remote syslog destination. For more information, refer to K13080: Configuring the BIG-IP system to log to a remote syslog server (11.x).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
