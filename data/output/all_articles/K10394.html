Topic

Purpose

You should consider using this procedure under the following conditions:

  • You want to change the default file size of the BIG-IP WebAccelerator access log.
  • You want to add an automatic daily log rotation for your BIG-IP WebAccelerator access logs.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have familiarity with using a Linux text editor.

Description

By default, the BIG-IP WebAccelerator access log file rotates as soon as it reaches 10MB in size, and is checked hourly, at one minute past the hour. To increase the default log file size of 10MB, or to force a log rotation each day, regardless of whether the maximum log size has been reached, perform the following two procedures. You can perform these procedures individually or together.

Procedures

Increasing the default log file size

Impact of procedure: None.

  1. If you are running 10.1.0 or later, remount the /usr filesystem as read-write, by typing the following command:

    mount -o remount,rw /usr

  2. Using a text editor, edit the following file:

    /usr/share/defaults/config/templates/warotate.tmpl

  3. Locate the following section:

    /var/log/wa/access/*.log /var/log/wa/pvacLog_8081 {
    size=10M
    sharedscripts

  4. Edit the size=10M to be the maximum size of log file that you require, in megabytes (for example, size=250M). There may be multiple lines with size=10M in this file; edit only the one line as shown in the example for Step 3.
  5. Using a text editor, edit the following file:

    /var/run/config/logrotate.d/wa

  6. Repeat the editing procedure outlined in Step 2.
  7. If you are running version 10.1.0 or later, remount the /usr filesystem as read-only, by typing the following command:

    mount -o remount,ro /usr

Forcing a log rotation each day using the bigpipe command

Impact of procedure: None.

  1. To force a log rotation, type the following command from the BIG-IP command line:

    bigpipe logrotate wa include daily

  2. Save the configuration by typing the following command:

    bigpipe save

  3. To reverse this configuration, type the following command:

    bigpipe logrotate wa include none

  4. Save the configuration by typing the following command:

    bigpipe save

Note: Daily log rotation is triggered at 4:02 a.m. On busy hosts, the access log size may be greater than the one which has been configured; log file sizes are checked hourly.
