Topic

You should consider using these procedures under the following conditions:

  • You want to verify if a user has shell access on the F5 iWorkflow system.
  • You want to enable user access to the Advanced Shell (bash) or the TMOS Shell (tmsh) on the iWorkflow system.

Description

By default, a user account with the administrator role that is not predefined in the iWorkflow system does not have access to the bash shell or tmsh. To allow this user access, perform the following procedures.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have bash shell or tmsh access to the iWorkflow system with administrator credentials or root user access.
  • You have created new user accounts on the iWorkflow system.
  • The users you want to grant access to bash shell or tmsh have administrator credentials.

Procedures

Verifying a user's shell access

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh of the iWorkflow system by typing the following command:

    tmsh

  2. To display the authentication setting on the user, use the following command syntax:

    list /auth user <USERID>

    For example:

    list /auth user myuser99

    The output may appear similar to the following example:

    auth user myuser99 {
        description "myuser99"
        encrypted-password $6$jOAlwEUz$uoQdkti9eOicatGdbNOBpUakdKx41AwSF9Eka1ynXbxl9QPrQWbwndGe5W76no4SK3qEyih4nrw1n2RbujALfM/
        partition Common
        partition-access {
            all-partitions {
                role admin
            }
        }
        shell none
    }

    This output shows that the user myuser99 has an administrative role, and has no shell access configured.

    When the user has shell access, the output on the shell entry displays as follows:

    • shell tmsh - The user has shell access to tmsh.
    • shell bash - The user has bash shell access.

Enabling a user's shell access

To enable a user to have access to the bash shell or tmsh, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh of the iWorkflow system by typing the following command:

    tmsh

  2. To enable the user to have access to tmsh, use the following command syntax:

    modify /auth user <UserID> shell tmsh

    To enable the user to have access to the bash shell, use the following command syntax:

    modify /auth user <UserID> shell bash

    For example, to enable the user adm_emp2 access to tmsh, type the following command:

    modify /auth user adm_emp2 shell tmsh

  3. Save your changes by typing the following command:

    save /sys config

  4. To exit tmsh utility, type quit and press Enter.
