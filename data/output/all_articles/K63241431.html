Description

Endpoint inspection on the Client machine takes more than 2 mins to complete. During this time the screen is frozen and the access policy execution moves forward only after the endpoint inspection is complete.

Environment

  • APM Access Policy
  • AV check endpoint inspection
  • Windows Client machine
  • Using Edge Client

Cause

The Backwards Compatibility Service of the Antivirus software affects the behavior of f5fpclientW.exe. In many cases, monitoring F5-related component(s) may cause slowness in processing the VPE (such as: client inspection, changing the network configuration for establishing the NA, etc.).

Recommended Actions

To troubleshoot issues like this, please perform the following:
  • Enable debug logging on the Access Policy
  • Run CTU (Client Troubleshooting Utility) on the Client machine
  • Run OPSWAT OESIS tool
  • Run Procmon to identify the service that is affecting the f5fpclientW.exe

      Additional Information

      Overview of Procmon tool
      Procmon (Process Monitor) tool helps you to identify the processes running at the time of Endpoint inspection. You can download the tool and run it when you have initiated a new Access Policy session with debug logging enabled.
