Topic

Session (cookie) hijacking is an exploit in which an attacker gains unauthorized access to information in a computer system or web application by exploiting a computer session. The attacker hijacks cookies from a user session and attempts to use the cookies for authentication.

Description

The Session Hijacking feature mitigates session hijacking attacks by using JavaScript to obtain a unique device ID to represent the client device. The system encrypts and stores the device ID in the ASM cookie, which remains with the client for the duration of the HTTP session.

The Session Hijacking feature works as follows:

  1. The client attempts to log in to the web application.
  2. The BIG-IP ASM system uses JavaScript to gather information about the client and create a unique device ID.
  3. The BIG-IP ASM system embeds the device ID in an ASM cookie and returns the response to the client.
  4. For subsequent HTTP requests in the session, the BIG-IP ASM system issues a challenge to test the validity of the device ID.
  5. If the device ID or message key changes during the session or the session times out, the system considers the request to be an attack and, depending on the blocking settings, issues the following violation to the event logs:

    ASM cookie hijacking
