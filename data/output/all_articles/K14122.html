Known Issue

Description

The BIG-IP ASM system may fail to highlight a request. This issue occurs when all of the following conditions are met:

  • A security policy is enabled with signature staging.
  • The Logging Profile is configured to Log illegal requests for the security policy.
  • The request matches an attack signature.

When an attack signature is in staging, and a request matches the attack signature, the system reports the request in the Traffic Learning page. However, the system fails to highlight the matching portion of the request with a red bracket.

Impact

You may not be able to identify why a request matches an attack signature.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you click the View details link in the attack signature violation details on the Learning page, the system reports the request without highlighting the matching portion.
