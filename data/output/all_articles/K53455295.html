Description

On clustered vCMP systems, the device status is showing as Forced Offline on the Network Map (Local Traffic  ››  Network Map), even though the device itself is active.

Environment

  • vCMP systems running 14.1.0 and later version

Cause

Bug ID 787885

Recommended Actions

The device's correct status can be viewed from TMUI or by running the tmsh show sys cluster command.
