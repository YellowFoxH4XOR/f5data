Description

DNS resolution fails during DNS registration when Windows workstations have both IPv4 and IPv6 active configs
When clients are configured with IPv4 and IPv6 IP addresses AND when they enable the feature to discard secured dynamic updates (dynamicUpdatePacketFilter0 is set to 2) from non-VPN adapters, DNS resolution is timing out around the times where DNS registration happens

 

Environment

apmclients-7.2.4

Network Access with IPv4/IPv6 used on client and discard non-VPN adapter registration enabled

 

Cause

BugID 1494301
DNS resolution timeout happens for 45-60 seconds when DNS registration is triggered with Dynamic DNS packet filtering enabled.

 

Recommended Actions

On the windows workstation disable the Register this connection's addresses in DNS checkbox under Advanced TCP/IP setting
