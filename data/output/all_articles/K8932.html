Topic

FirePass version 6.0.2 is the first version of FirePass software to certify Microsoft Outlook Web Access (OWA) 2007 as a certified application for the Portal Access Web Applications feature. If you are running an earlier version of FirePass software, some features of OWA 2007 may not work properly through Portal Access.
