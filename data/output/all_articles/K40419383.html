Known Issue

Mac Client Package may intermittently fail to download from the Configuration utility.

This issue occurs when the following condition is met:

  • You attempt to download a Customize Mac Client Package from the Configuration utility.

Impact

You are unable to download a Customize Mac Client Package.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Downloading a Customize Mac Client Package intermittently fails.
  • When you attempt to download a Customize Mac Client Package from the Configuration utility, the system displays error messages similar to the following example:

    HTTP Status 500 - java.lang.OutOfMemoryError: Java heap space
    type Exception reportmessage java.lang.OutOfMemoryError: Java heap space
    description The server encountered an internal error that prevented it from fulfilling this request.
    exception
