Description

After deploying a Gateway with Hostname value starting with udp or tcp, and no other Hostnames defined, results in desired configuration not being deployed and the following message on the Gateway configuration page: 

Configured: {"type": "error", "Message": "no deployment provided"}

Additionally the following dpm logs may occur: 

<timestamp> [INFO] ADC-<id>   placement/placement.go:254      failed: no deployment provided
<timestamp> [WARN] ADC-<id>   placement/placement.go:239      no deployment provided
<timestamp> [WARN] dpm       orchestration/manager.go:295     error msg: no deployment provided
<timestamp> [INFO] placement    placement/status.go:178       acked (error=true): ADC-<id>:[acked created: <timestamp> {init:89.839µs resolving:89.158µs resolved:55.940334ms elapsed:56.119331ms}] (no deployment provided)

Environment

NGINX Controller / ADC

Cause

Gateway Hostname feature is not designed to implement server block configuration with TCP/UDP listeners.

Recommended Actions

Define stream configuration at the Component / URI level
