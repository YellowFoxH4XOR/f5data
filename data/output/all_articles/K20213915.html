Description

Accessing a BIG-IP VE Configuration Utility (GUI) and SSH via the management interface is slow when using Cisco ACI.

Environment

  • BIG-IP VE v12.1.x
  • Cisco ACI

Cause

Auto Last Hop feature is enabled on the management interface by default and this feature is not compatible with Cisco ACI.

Recommended Actions

Follow the steps below to resolve the issue.
  1. Disable the Auto Last Hop by referring to article K52592992.
  2. If default route has not been configure, refer to article K15040 to configure it.
