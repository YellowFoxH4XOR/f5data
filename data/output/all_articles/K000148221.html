Description

I see traffic volumes on my DDoS Dashboard even when I'm not sending any traffic through F5. Why does this happen?

Answer/Recommended Actions

Notice in the screenshot above that all of the traffic shown is Incoming (pre-scrubbing) and there is no visible traffic on the Incoming (post-scrubbing) data series.

  • F5 XC uses data collection tools to monitor traffic both before any scrubbing action occurs and after. These two flow collection areas represent the pre-scrubbing and post-scrubbing data series in the graph.

  • The pre-scrubbing data collection is processed on ALL traffic passing through F5 XC for all customers. This means that pre-scrubbing flow data will be shown on the timeline when either the source or destination of the traffic matches the customer's configured prefixes in the F5 Console.

  • This does not indicate that traffic is being processed by F5 XC to mitigate and return to the specific customer. It indicates that other customers on the F5 network have traffic flows that interact with this customer's prefixes.

  • This is considered normal behavior and is indicative of the visibility that F5 XC provides to all users of the DDoS Protection service.

Note that there is both Incoming (pre-scrubbing) traffic and Incoming (post-scrubbing) traffic shown on the data series.

  • The Incoming (post-scrubbing) traffic is collected via data collection tools after mitigation actions, firewall rules and other protections have occurred and this traffic will be passed along (post-scrubbing) to the customer via GRE or whatever configured method is selected for clean traffic delivery. 

Additional Information

  • The Clean Traffic calculated for customer billing purposes does not include the Incoming (pre-scrubbing) traffic volumes.
