Description
You may want to configure the BIG-IP system to only send a module log (e.g: LTM, ASM, etc.) to a remote syslog server but no other module logs.

Environment

  • BIG-IP version 11.x or higher

Cause
By default, the BIG-IP sends all module logs to the remote syslog server.

Recommended Actions

  1. BIG-IP uses the syslog facility for each module. You can refer to this article which module uses which facility. For example, ASM uses local3.

    K15934495: Configuring the level of information that syslog-ng sends to log files (12.x - 15.x)

  2. To edit the syslog configuration type the following commands.
    [root@LTM1.example.com] config # tmsh
    root@(LTM1.example.com)(cfg-sync Standalone)(Active)(/Common)(tmos)# edit /sys syslog all-properties

  3. Replace the include none line with the desired syslog filter. For example, to configure syslog-ng to send ASM logs only to UDP port 514 on destination hosts 192.168.1.2, use the following syntax.

    include "
        destination d_remote_loghost {
            udp(\"192.168.1.2\" port(514));
        };
        log {
            source(s_syslog_pipe);
            filter(f_local3);
            destination(d_remote_loghost);
        };
    "
    Note: Filter (f_local3) filter handels ASM messages

  4. Exit the vi editor by typing :wq and then type y to save the change.

    Save changes? (y/n/e) y
    root@(bigip)(cfg-sync Standalone)(Active)(/Common)(tmos)#

  5. You can use the following logger command to confirm that the remote syslog server only receives the ASM log.

    [root@LTM1.example.com] config # logger -p local0.notice "LTM log"
    [root@LTM1.Example.com] config # logger -p local3.notice "ASM log"

    On remote syslog server logs will be noticed similar to the below example. 
    bigip.local notice root[30707]: ASM log

    K11127: Testing SNMP traps on the BIG-IP system (9.4.x - 15.x)
