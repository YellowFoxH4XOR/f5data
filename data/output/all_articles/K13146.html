Known Issue

When you clear non-volatile RAM (NVRAM) using the clear nvr command, an internal timing issue may result in the metalog daemon (mltdaemon) writing a core file.

This issue occurs when all of the following conditions are met:

  • You issue the clear nvr command.
  • The metalog daemon (mltdaemon) shuts down before responding to the SIGTERM thread.

The clear nvr command halts the ARX system after clearing the NVRAM, and the metalog daemon occasionally shuts down before responding to the SIGTERM thread.

Note: The clear nvr command should be run only on a switch that has been completely unconfigured and removed from the network.

Impact

None, as the system was halting.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The syslog file contains an error message that appears similar to the following example:

    :CORE-0-DBG-MSG7:: mtlDaemon[2189]: [E:0] Writing core file.

  • The metalog daemon core file is written.
