Security Advisory Description

The upload functionality in BIG-IP Advanced WAF and ASM allows an authenticated user to upload files to the BIG-IP system using a call to an undisclosed iControl REST endpoint. (CVE-2021-23001)

Impact

An authenticated malicious user can upload malicious files to use in future attacks, or simply upload large files to fill the BIG-IP system's disk space.
