Known Issue

Both BIG-IP systems monitor both gateway fail-safe pools regardless of their association.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP systems in a high availability (HA) configuration.
  • You configure the gateway fail-safe feature on the BIG-IP peer systems.
  • You synchronize the configuration between the peer BIG-IP systems.

Note: Only the BIG-IP system associated with the gateway pool should monitor the pool. HA peer BIG-IP systems that are not associated with a gateway pool should not monitor the pool, and the status should be blue or unknown. For more information, refer to K75303031: Configuring gateway fail-safe using the Configuration utility (13.x).

Impact

Both BIG-IP systems monitor both gateway fail-safe pools regardless of their association.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The gateway pool status is not blue or unknown on peer BIG-IP systems not associated with the gateway pool.
  • BIG-IP systems that are not associated with the gateway pool send monitor probes to the gateway pool members.

Workaround

To work around this issue, you can reload the BIG-IP system configuration using the TMOS Shell (tmsh). To do so, perform the following procedure:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To reload the BIG-IP configuration, type the following command:

    tmsh load sys config
