K000152414: F5OS tenants must be moved to 'provisioned' or 'configured' state when downgrading

Type
Support Solution
Published
2025-07-04
Updated
2025-07-04
Applies to
  • F5OS
  • F5OS-A: 1.7.0, 1.8.0
  • F5OS-C: 1.8.1, 1.8.0, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000152414

Description

Before you downgrade an F5OS-C partition or F5OS-A appliance software from a version 1.6.0 or later to versions earlier than 1.6.0, you must move all tenants to the Configured or Provisioned state first. If there are running tenants at the time the downgrade is attempted, the downgrade will be blocked.

Environment

Refer to the following for each supported F5OS versions that the issue may occur:

  • Downgrade from F5OS-C 1.6.0 or later
    to
    F5OS-C 1.5.x or earlier
    Note: F5OS-C 1.5.x and earlier reached End of Technical Support. For supported F5OS versions, refer to K21501912: Software lifecycle policy for F5OS. Therefore, you should not be attempting this downgrade.

  • Downgrade from F5OS-A 1.7.0 or later
    to
    F5OS-A 1.5.x
    Note: F5OS-A 1.7.0 reached End of Technical Support. For supported F5OS versions, refer to K21501912: Software lifecycle policy for F5OS. For example, you may observe the issue when downgrading from F5OS-A 1.8.0 to F5OS-A 1.5.3

Cause

You attempt to perform a software downgrade

  • F5OS-C
  • F5OS-A

Recommendations Actions

You must move all F5OS Tenants to the Configured or Provisioned state first for the downgrade to succeed.

Additional Information

For more information on downgrading F5OS-A software, refer to the manual for the version you are running. For example, refer to the Downgrade Software manual chapter.
