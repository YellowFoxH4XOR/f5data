K000152563: "Navigation to the webpage was canceled" error during BIG-IP APM browser-based VPN login

Type
Support Solution
Published
2025-11-07
Updated
2025-11-07
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000152563

Description

The error message "Navigation to the webpage was canceled" may appear when attempting to establish a VPN connection using browser-based access through BIG-IP APM.

The error persists even after closing the VPN helper pop-up and retrying from the Webtop, and only logging out and logging back in temporarily resolves it.

Logs and a .pcap file may contain entries such as F5RST: Machine Hash is not Valid

Environment

  • Access method: Browser-based VPN access (Webtop Network Access)

  • Endpoint checks implemented in the Access Policy
  • Windows client systems with multiple or dynamic network adapters (e.g., Wi-Fi Direct, Bluetooth, virtual adapters)

Cause

The Machine Hash incorporates several system parameters, including hostname, serial number, and network adapter information.

If the number or state of network adapters changes between endpoint inspection and VPN agent checks—such as dynamic creation/removal of adapters like "Microsoft Wi-Fi Direct Virtual Adapter" or toggling Bluetooth—the Machine Hash becomes invalid. 

This results in a session reset and display of the error message. The issue is specific to browser-based VPN access. Edge Client handles Machine Hash validation differently and is not affected.

This behavior has been documented and recorded as bug ID 1972437.

Recommended Actions

  • use Edge Client for VPN access if possible -  this method does not trigger the issue
  • minimize network adapter changes - disable unnecessary or virtual network adapters (such as Wi-Fi Direct or Bluetooth) before starting a browser-based VPN session. Avoid toggling network adapters or connecting/disconnecting devices during login.
