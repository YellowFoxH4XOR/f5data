Description

When attempting a deployment from the Guided Configuration, users may receive an the error message similar to the following:

Config processor is not available: java.util.concurrent.TimeoutException: Unavailable: http://localhost:8100/mgmt/shared/iapp/processors/saml-sp

Environment

  • BIG-IP APM
  • Guided Configuration

Cause

This error can occur when there is a lack of management resources on the Big-IP to use for Guided Configuration deployments.
 

Recommended Actions

  1. Guided Configuration deployments can utilize more resources, so regardless of how many modules you have provisioned, it is recommended to set "Management Provisioning to Large." However, following the below steps will overwrite this change, making the Management Provisioning drop down show "Custom." This is known and expected. Do not change it back to Large after making the below changes.

    K26427018: Overview of Management provisioning

  2. Run the following commands on the Big-IP to allocate additional memory to management, tomcat, and restjavad:

    # tmsh modify sys db provision.extramb value 2048
    # tmsh modify sys db provision.tomcat.extramb value 512
    # tmsh modify sys db provision.restjavad.extramb value 2048
    # bigstart restart restjavad && sleep 20 && bigstart restart restnoded

Note: There may be a traffic disruption as HA failover might occur while the services restart, so it is recommended to perform these actions in a maintenance window

Note: These changes do not sync to peer devices. You may need to make the same changes on the peer as well.
