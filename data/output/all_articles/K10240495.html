Description

You want to add a hyperlink footer on a BIG-IP APM access profile logon page.

Environment

  • Access policy

  • Login Page

Cause

None

Recommended Actions

  1. Log in to the Configuration utility.

  2. Navigate to the Quick Start/Basic page:
  • 13.0.0 and later: Access > Profiles / Policies > Customization > Quick Start/Basic
  • 11.x - 12.x: Access Policy > Customization > Quick Start/Basic

  1. Under Access Profiles, in the Available Profiles list, click the access profile that you want to add a hyperlink on Footer Text.

  2. In the Select Language list, click the language preference of the access profile.
    Note: To add a hyperlink on Footer Settings for all languages, click All Languages.

  3. To add the hyperlink to the Footer Settings, edit the Footer Text in HTML syntax below:

    <a href="hyperlink" target="_blank">display name of the hyperlink</a>

    For example,  you want to add the https://www.example.com hyperlink to the Footer Text, you can use the content below:

    This product is licensed from Example Company. © 1999-2020 <a href="https://www.example.com" target="_blank">Example Company</a>. All rights reserved.

  4. To save the new config, click Save.

  5. To preview the new clickable hyperlink, click Preview.

For more information about the customization of the BIG-IP APM system, refer to the manuals in the Additional Information section.
