Description
After modifying or moving certain files the BIG-IP may fail a FIPS integrity check, even when FIPS is not licensed on the device.

Environment

  • BIG-IP
  • BIG-IP is running in Common Criteria mode

Cause
Common Criteria mode (initiated by running ccmode, and verified by checking the security.commoncriteria db key) will cause the BIG-IP to run the FIPS integrity check on boot.

To check if this key enabled, run: tmsh list sys db security.commoncriteria value
If the system returns true, the BIG-IP is running in Common Criteria mode

Recommended Actions

Resolve the issues leading to boot failure and reboot
Note:  Reverting security.commoncriteria to false will not undo the relevant changes on the BIG-IP.  There is no supported way to unwind Common Criteria mode short of rebuilding the BIG-IP.

Additional Information
For recovery assistance refer: K25205233: BIG-IP System halted while booting. Halt at boot after FIPS Integrity Check Result FAIL 
Information on BIG-IP Common Criteria certification can be found here: https://www.f5.com/company/certifications
