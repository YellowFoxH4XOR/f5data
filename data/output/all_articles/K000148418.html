Description

When using Ansible to manage F5OS, you can use F5OS modules:

https://clouddocs.f5.com/products/orchestration/ansible/devel/f5os/F5OS-index.html

You can also "ansible.builtin.uri" to take advantage of F5OS RESTCONF API support.  This document is an example about using "ansible.builtin.uri" method to work with F5OS.

Environment

  • F5OS
  • Ansible
  • RESTCONF API

Recommended Actions

    Step1: Obtain authentication token

    ~/playbook/F5OS$ cat auth_token.ansible.yaml
    ---
    - name: Obtain authentication token
      ansible.builtin.uri:
              url: "https://10.10.10.12:8888/restconf/data/openconfig-system:system/aaa"
              method: GET
              headers:
                Content-Type: application/yang-data+json
                X-Auth-Token: rctoken
                Authorization: "Basic {{ 'admin:admin' | b64encode }}"
              validate_certs: false
              status_code: 200
      register: auth_response

    - name: Set token fact
      ansible.builtin.set_fact:
              token: "{{ auth_response.x_auth_token }}"

    10.10.10.12 is IP address of F5OS controller or F5 partition, depending on the API endpoint.

    Step2: A  task  using auth_token

    ~/playbook/F5OS$ cat primary-key.yaml
    ---
    - name: Retrieve Primary Key Hash
      hosts: localhost
      gather_facts: false

      tasks:
        - name: Get token
          include_tasks: auth_token.ansible.yaml

        - name: Get primary key hash
          ansible.builtin.uri:
                  url: "https://10.10.10.12:8888/restconf/data/openconfig-system:system/aaa/f5-primary-key:primary-key/f5-primary-key:state/f5-primary-key:hash"
                  method: GET
                  headers:
                    Content-Type: application/yang-data+json
                    X-Auth-Token: "{{ token }}"
                  validate_certs: false
                  status_code:
                  - 200
          register: primary_key

    Additional Information

    When disabling Basic Authentication the endpoint for token retrieval must the raw base path. For port 443 then /api is the raw base path and for restapi port 8888 /restconf is the raw base path.
