Description

Nginx Plus instances must be compatible with the Nginx Controller software version. In case when there is an incompatible versions, we will need to downgrade Nginx Plus instances version,  to make sure it compatible as it shared in the RN document .

Environment

  • Nginx Plus
  • Incompatible software version

Cause

Since incompatible software versions between the Nginx Plus instances and the Nginx Controller, downgrade procedure should be implemented.

Recommended Actions

  1. Go to MyF5 Customer Portal  and download correct Nginx Plus software version
Example snapshot:
  1. Upload the downloaded files to Nginx Plus server
  2. On Nginx Plus server make a backup for configuration file /etc/nginx/nginx.conf
cp /etc/nginx/nginx.conf /etc/nginx/nginx.conf<DATE>
  1. Uninstall Nginx Plus agent use the following steps:
sudo service nginx stop
sudo apt-get remove -y nginx-plus
sudo apt autoremove -y
  1. Install downloaded Nginx Plus software package:
sudo apt-get install -y -f ./nginx-plus_<version>-focal_amd64.deb --allow-downgrades
  1. Go to Nginx Controller and add again this Nginx Plus agent as an instance:
Example snapshot:


Note: take curl command from the GUI and run on the Nginx Plus server.
 

curl -sS -L https://<nginx plus></install/controller-agent> install.sh && API_KEY='xxxxxxx' sh ./install.sh
