K11030299: BIG-IP LTM VE 13.1.1 SNMP traps sent by the F5 for offline VS during ''load sys config verify''

Type
Support Solution
Published
2021-12-17
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM: 13.1.1, 13.1.1
Source
https://my.f5.com/manage/s/article/K11030299

Description
SNMP traps for Offline Virtual Server will be sent when execute "tmsh load sys config verify"

Environment

  • BIG-IP LTM
  • SNMP

Cause
By design.

Recommended Actions

  • Verify that Virtual Server is offline,

# tmsh show ltm virtual testing_vs | grep Availability
  Availability     : offline
  • Run the below command,

# tmsh load sys config verify

  • Tcpdump below showing that snmp trap sent out by F5 for offline Virtual Server,
