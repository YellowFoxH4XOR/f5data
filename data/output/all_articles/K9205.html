Topic

To restore configuration data to a FirePass RMA unit, perform one of the following procedures:

  • Restoring configuration data to an RMA standalone controller or primary cluster node
  • Restoring configuration data to an RMA standby controller in a failover pair
  • Restoring configuration data to an RMA secondary cluster node

Restoring configuration data to an RMA standalone controller or primary cluster node

To restore configuration data to an RMA standalone controller or to an RMA primary cluster node, perform the following procedure:

Important: In order to restore from a backup file, the RMA unit must have the same hardware, license options, version of FirePass software, and hotfixes as the unit from which the backup file was created. For more information, refer to K3339: Restoring backup files on a different FirePass unit than they originated on.

  1. Log in to the FirePass Administrative Console of the RMA unit.

    Note: For information about establishing basic network connectivity to the FirePass controller, refer to the FirePass Controller Getting Started Guide.

  2. Navigate to the Device Management : Maintenance : Activate License page.
  3. In the Base Registration Key field, enter the registration key from the previous unit and click the Update button.
  4. Optionally, if additional Module Registration Keys were installed on the previous unit, enter the registration keys, one at time, into the Module Registration Keys field and click the Add button.
  5. Use the Automatic or Manual registration method to license the RMA unit.

    Note: For more information about the Automatic or Manual registrations methods, click the Help link at the top right of the Device Management : Maintenance : Activate License page.

    Important: If you cannot successfully license the RMA unit, contact F5 Technical Support.

  6. Navigate to the Device Management : Current Settings page.
  7. In the FirePass Version row, verify the version of software installed on the RMA unit, and proceed with one of the following options:
    • If the version of FirePass software installed on the RMA unit matches the version of software installed on the previous unit, proceed to Step 8.
    • If the version of FirePass software installed on the RMA unit is older than the version of software installed on the previous unit, download the correct version of FirePass software from the F5 Downloads site and then upload the software to the RMA unit on the Device Management : Maintenance : Local Update page.
    • If the version of FirePass software installed on the RMA unit is newer than the version of software installed on the previous unit, contact F5 Technical Support. FirePass does not currently support downgrading to a previous version of FirePass software.

      Note: For more information, refer to K2847: Downgrading to a previous FirePass software version.

  8. Navigate to the Device Management : Maintenance : Local Update page.
  9. Install all hotfixes that were installed on the previous unit when the backup file was created.

    Note: For more information, refer to K3430: Installing FirePass hotfixes.

    Important: Do not install any hotfixes that were not installed on the previous unit. For example, if Cumulative Hotfix HF-602-2 was the only hotfix installed on the previous unit, do not install Cumulative Hotfix HF-602-5 on the RMA unit.

  10. Navigate to the Device Management : Maintenance : Backup/Restore page.
  11. In the Restore FirePass controller configuration from a previous backup field, enter the full path to the backup file or use the Browse button to navigate to the file.
  12. Click the Restore your saved configuration link.
  13. Select the Restore Networking Configuration check box.
  14. Select the Restore Users and Groups Settings check box.
  15. Click the Restore button.
  16. Click the Restart FirePass Controller link.
  17. Click the Restart button.
  18. After the RMA unit restarts, manually configure the settings which were not restored from the backup file.

    Note: Complete the following steps if the FirePass controller is running version 6.0.3 or later.
  19. Navigate to the Device Management : Configuration : Network Configuration.
  20. Click the DNS tab.
  21. Click Clear DNS cache button.

Note: For more information about these settings, refer to K8114: Certain configuration settings are not restored from a backup file

Restoring configuration data to an RMA standby controller in a failover pair

To restore configuration data to an RMA standby controller in a high availability configuration, perform the following procedure:

  1. Log in to the FirePass Administrative Console of the active controller.
  2. Navigate to the Device Management : Current Settings page.
  3. Note the version of FirePass software listed in the FirePass Version row.
  4. Note the installed hotfixes listed in the FirePass Hot-Fixes row.
  5. Navigate to the Device Management : Configuration : Clustering and Failover page.
  6. In the Failover (High-Availability) Configuration section, note the Failover Pair Member setting. If the Failover Pair Member setting is set to First, you will configure this setting to Second on the RMA unit. If the Failover Pair Member setting is set to Second, you will configure this setting to First on the RMA unit.
  7. Note the text in the Failover ID field. You will enter the same text in the Failover ID field on the RMA unit.
  8. Log in to the FirePass Administrative Console of the RMA unit.

    Note: For information about establishing basic network connectivity to the FirePass controller, refer to the FirePass Controller Getting Started Guide.

  9. Navigate to the Device Management : Maintenance : Activate License page.
  10. In the Base Registration Key field, enter the registration key from the previous unit and click the Update button.
  11. Optionally, if additional Module Registration Keys were installed on the previous unit, enter the registration keys, one at time, into the Module Registration Keys field and click the Add button.
  12. Use the Automatic or Manual registration method to license the RMA unit.

    Note: For more information about the Automatic and Manual registrations methods, click the Help link at the top right of the Device Management : Maintenance : Activate License page.

    Important: If you cannot successfully license the RMA unit, contact F5 Technical Support.

  13. Navigate to the Device Management : Current Settings page.
  14. In the FirePass Version row, verify the version of software installed on the RMA unit, and proceed with one of the following options:
    • If the version of FirePass software installed on the RMA unit matches the version of software installed on the active controller, proceed to Step 15.
    • If the version of FirePass software installed on the RMA unit is older than the version of software installed on the active controller, download the correct version of FirePass software from the F5 Downloads site and then upload the software to the RMA unit on the Device Management : Maintenance : Local Update page.
    • If the version of FirePass software installed on the RMA unit is newer than the version of software installed on the active controller, contact F5 Technical Support. FirePass does not currently support downgrading to a previous version of FirePass software.

      Note: For more information, refer to K2847: Downgrading to a previous FirePass software version.

  15. Navigate to the Device Management : Maintenance : Local Update page.
  16. Install all hotfixes that are installed on the active controller.

    Note: For more information, refer to K3430: Installing FirePass hotfixes.

  17. Follow the steps outlined in the Configuring the standby FirePass controller section of the FirePass Controller Administrator Guide to configure the RMA unit as a standby controller.

    Important: Use the information you obtained in Steps 6 and 7 when configuring the settings on the Device Management : Configuration : Clustering and Failover page on the RMA unit.

  18. After the RMA unit successfully synchronizes with the active controller, configure the settings on the RMA unit that are not synchronized.

    Note: Complete the following steps if the FirePass controller is running version 6.0.3 or later.
  19. Navigate to the Device Management : Configuration : Network Configuration.
  20. Click the DNS tab.
  21. Click Clear DNS cache button.

Note: For more information, refer to K7419: Configuration parameters that are not synchronized between members of a failover pair.

Restoring configuration data to an RMA secondary cluster node

To restore configuration data to an RMA secondary cluster node, perform the following procedure:

  1. Log in to the FirePass Administrative Console of the primary cluster node.
  2. Navigate to the Device Management : Current Settings page.
  3. Note the version of FirePass software listed in the FirePass Version row.
  4. Note the installed hotfixes listed in the FirePass Hot-Fixes row.
  5. Navigate to the Device Management : Configuration : Clustering and Failover page.
  6. Note the information in the Total Number of Cluster Nodes, Cluster ID, Synchronization Interval, and Cluster/Failover Global ID fields. You will need these settings when configuring the Device Management : Configuration : Clustering and Failover page on the RMA unit.
  7. Log in to the FirePass Administrative Console of the RMA unit.

    Note: For information about establishing basic network connectivity to the FirePass controller, refer to the FirePass Controller Getting Started Guide.

  8. Navigate to the Device Management : Maintenance : Activate License page.
  9. In the Base Registration Key field, enter the registration key from the previous unit and click the Update button.
  10. Optionally, if additional Module Registration Keys were installed on the previous unit, enter the registration keys, one at time, into the Module Registration Keys field and click the Add button.
  11. Use the Automatic or Manual registration method to license the RMA unit.

    Note: For more information about the Automatic or Manual registrations methods, click the Help link at the top right of the Device Management : Maintenance : Activate License page.

    Important: If you cannot successfully license the RMA unit, contact F5 Technical Support.

  12. Navigate to the Device Management : Current Settings page.
  13. In the FirePass Version row, verify the version of software installed on the RMA unit, and proceed with one of the following options:
    • If the version of FirePass software installed on the RMA unit matches the version of software installed on the primary cluster node, proceed to Step 14.
    • If the version of FirePass software installed on the RMA unit is older than the version of software installed on the primary cluster node, download the correct version of FirePass software from the F5 Downloads site and then upload the software to the RMA unit on the Device Management : Maintenance : Local Update page.
    • If the version of FirePass software installed on the RMA unit is newer than the version of software installed on the primary cluster node, contact F5 Technical Support. FirePass does not currently support downgrading to a previous version of FirePass software.

      Note: For more information, refer to K2847: Downgrading to a previous FirePass software version.

  14. Navigate to the Device Management : Maintenance : Local Update page.
  15. Install all hotfixes that are installed on the primary cluster node.

    Note: For more information, refer to K3430: Installing FirePass hotfixes.

  16. Follow the steps outlined in the Configuring FirePass controller clusters section of the FirePass Controller Administrator Guide to configure the RMA unit as a secondary cluster node.

    Important: Use the information you obtained in Step 6 when configuring the settings on the Device Management : Configuration : Clustering and Failover page on the RMA unit.

  17. After the RMA unit successfully synchronizes with the primary cluster node, configure the settings on the RMA unit which are not synchronized.
    Note: Complete the following steps if the FirePass controller is running version 6.0.3 or later
  18. Navigate to the Device Management : Configuration : Network Configuration.
  19. Click the DNS tab.
  20. Click Clear DNS cache button.

Note: For more information, refer to K8816: Configuration parameters that are not synchronized between members of a cluster.
