Known Issue

The BIG-IP ASM bd process may exit and produce a core file when processing File Transfer Protocol (FTP) or SMTP traffic.

This issue occurs when all of the following conditions are met:

  • Protocol Security is enabled for the FTP or SMTP profile.
  • A logging profile that is configured with remote logging is enabled for the virtual server.

Impact

The BIG-IP ASM system fails to process traffic while the bd process restarts. A failover may occur if the BIG-IP ASM system is part of a high-availability (HA) group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system temporarily fails to pass traffic.
  • The BIG-IP ASM system writes a core file to the /var/core directory.
  • The system logs error messages in the /var/log/ts/bd.log file that appear similar to the following example:

    REG_EXP|ERR |<date>|<pid>|RegexpParamParser.cpp:0113|Exception caught while creating PCRE for regexp_str (?<=WebResource.axd?d=).+?(?=&)
