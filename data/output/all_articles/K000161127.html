K000161127: BIG-IP APM SSL VPN – DNS Resolution Failure on ARM-Based Windows 11 Laptops

Type
Support Solution
Published
2026-05-05
Updated
2026-05-05
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000161127

Description

DNS resolution fails for users on ARM-based Windows 11 laptops when connected to BIG-IP APM SSL VPN using the BIG-IP Edge Client. The VPN tunnel establishes successfully and network connectivity (e.g., ICMP/ping) to internal resources works, but DNS queries to the on-premises DNS servers configured in the VPN profile time out. The issue is isolated to ARM-based hardware and does not affect Intel-based machines with the same configuration. Removing the GlobalProtect VPN client from the affected ARM device restores DNS resolution through the BIG-IP VPN.

Environment

  • BIG-IP APM version 17.5.1
  • BIG-IP Edge Client version 7353 (ARM64-compatible)
  • Windows 11 ARM-based laptops managed via Microsoft Intune
  • Split tunnel VPN configuration
  • On-premises DNS servers assigned in VPN profile
  • GlobalProtect VPN client version 6.2.8 installed on ARM device
  • Netskope client present

Cause

Conflict between GlobalProtect VPN client and BIG-IP Edge Client DNS Relay Proxy service on ARM-based Windows 11 devices. Launching GlobalProtect interferes with DNS interception, preventing DNS queries from reaching the on-premises DNS servers via the BIG-IP VPN.

Answer/Recommended Actions

  1. Remove the GlobalProtect VPN client from ARM-based Windows 11 devices to restore DNS resolution through the BIG-IP APM SSL VPN.
  2. If both VPN clients are required, consider isolating their usage or testing for compatibility on ARM platforms.
  3. If DNS issues persist, verify:
    • The DNS Address Space field is populated in the Network Access resource (Access > Connectivity/VPN > Network Access Lists > Network Settings > Client Settings: Advanced).
    • The DNS Relay Proxy log (C:\Windows\Temp\FltRedirSrv.txt) on the client for evidence of DNS interception.
    • No other endpoint security or DNS interception software is interfering.

       Test DNS resolution with other third-party security clients (e.g., Netskope) temporarily disabled to rule out additional conflicts.

Additional Information

  • On Intel-based machines, BIG-IP Edge Client and GlobalProtect may coexist without issue, indicating an ARM-specific conflict.
  • The DNS Relay Proxy service is required for split-tunnel DNS functionality; disabling or removing it may impact DNS resolution in split-tunnel configurations.
