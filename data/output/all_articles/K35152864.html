Known Issue

Multiple Dynamic Host Configuration Protocol (DHCP) relay does not work.

This issue occurs when the following condition is met:

  • The DHCP virtual server is configured with a dhcpv4_fwd profile.

Impact

The virtual server drops the DHCP packets.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If the BIG-IP system is behind another DHCP relay, the system drops the packets rather than sending them to the server.

Resolution

Status

F5 Product Development has assigned ID 516307 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, F5 recommends the following changes:

Impact of workaround: Performing the following recommendations should not have a negative impact on your system.

  • Configure a unicast IP address for the BIG-IP DHCPv4 listener destination address field.
  • Configure the same IP address as the DHCP server IP address on the DHCP relay agent.
