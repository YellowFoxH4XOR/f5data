K000161279: EPSEC Updates Fail in Windows Clients with Edge Client 7262 or Earlier

Description

After upgrading the EPSEC package to version 1988 or later on the BIG-IP APM system, client endpoints running Edge Client version 7262 or earlier on Windows systems fail to install EPSEC updates.

When this occurs, Edge Client may repeatedly attempt to download and install the EPSEC package but fail signature validation.

Error messages similar to the following examples may be seen in logs:

CertFindCertificateInStore() failed, - (0x80092004) Cannot find object or property.

no valid signature found, C:\Windows\Downloaded Program Files\f5OesisInspectorCom4.dll

Environment

  • EPSEC package version 1988 or later (OESIS 4.3.5626.0 and above) is installed on the BIG-IP APM system.
  • Windows client systems are running Edge Client version 7262 or earlier.

Cause

Starting with EPSEC version 1988, F5 changed the signing certificate for the EPSEC package from Entrust to Sectigo. Edge Client version 7262 and earlier do not include the Sectigo certificate in the F5FirePassRoot certificate store on Windows endpoints. As a result, signature validation fails when installing the EPSEC package, causing update failures.

Recommended Actions

As a workaround for endpoints running Edge Client 7262 or earlier, you can manually install the Sectigo signing certificate into the Windows certificate store located at Local Computer > Certificates > F5FirePassRoot. After installation, reconnect with Edge Client and verify that EPSEC updates install successfully.

Note: To obtain the Sectigo signing certificate, you can open a support case and reference this article (K000161279). Specify the request is for the new code signing certificate required for EPSEC 1988 and later on Windows clients.

For a permanent solution, upgrade Edge Client to version 7270 or later. Edge Client 7270 includes the Sectigo certificate in the F5FirePassRoot store by default.

Note: Edge Client 7270 requires a fresh installation on Windows clients. For more information, refer to K000160684: APM Client 7.2.7 requires fresh installation of BIG-IP Edge Client on Windows.
