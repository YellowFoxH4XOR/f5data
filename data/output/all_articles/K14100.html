Known Issue

After installing BIG-IP 10.2.2 HF2 or HF3 on a system configured for remote authentication, authentication fails when using remote user credentials.

This issue occurs when the following condition is met:

  • The BIG-IP system was upgraded from a slot running on 10.2.2 Final Edition or 10.2.2 HF1.

After installing 10.2.2 HF2 or HF3, the system begins using local authentication and authenticates only users applying local credentials.


Impact

Users applying remote user credentials are not able to log in to the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H379818 on the Diagnostics > Identified > High screen.
  • The BIG-IP system configuration appears to be configured to use remote authentication.
  • Users applying remote user credentials are not able to log in to the BIG-IP system.
  • Only users applying local authentication credentials are able to access the BIG-IP system.

Workaround

To work around this issue, you can reapply the remote authentication setting. To do so, perform the following procedure:

Impact of workaround: None. However, the BIG-IP system is required to have a valid locally=authenticated administrator account to perform this procedure.

  1. Log in to the BIG-IP Configuration utility using a local account with the Administrator role.
  2. Navigate to System > Users: User List > Authentication.
  3. Set the authentication back to local by clicking Change, changing the value of User Directory to Local, and clicking Finished.
  4. Apply the desired remote authentication setting by clicking Change, configuring the desired remote authentication setting, and saving the changes by clicking Finished.
