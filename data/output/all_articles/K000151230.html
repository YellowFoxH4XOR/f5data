K000151230: VELOS shows "Receiver power low warning" after upgrade

Type
Support Solution
Published
2025-05-08
Updated
2025-07-24
Applies to
  • F5OS
  • F5OS-C: 1.8.0
Source
https://my.f5.com/manage/s/article/K000151230

Description

After upgrading your VELOS system to F5OS-C 1.8.0, the system starts to report alarms on "Receiver power low warning".

# show system alarms

ID   RESOURCE    SEVERITY TEXT                  TIME CREATED            

-----------------------------------------------------------------------------------------------------------

262401 Portgroup 4/2 WARNING  Lanes: 2,4 Receiver power low warning 2025-02-20 20:02:31.773028542 UTC  

262401 Portgroup 3/2 WARNING  Lanes: 2,4 Receiver power low warning 2025-02-20 20:02:43.647407931 UTC

No alarm exists before upgrade. You also verify on the switch that the relevant transceivers have sufficient transmit power.

Environment

  • VELOS
  • After upgrade to F5OS-C 1.8.0
  • "Receiver power low warning" alarm

Cause

  • Bug ID 1624057

Recommended Actions

  1. Upgrade to F5OS-C 1.8.0 EHF-1 or any version with a fix for ID1624057 .
  2. If the alarm is still present after installing the fixed version, clear the system alarm and verify if any new alarm is reported. 

Additional Information

Use the command from K000150155 to assist you to clear the alarm.
