Cause

This is a known issue tracked under ID 580500: /etc/logrotate.d/sysstat's sadf fails to read /var/log/sa6 or fails to write to /var/log/sa6, disk space is not reclaimed.

Recommended Actions

Perform workaround for ID 580500:

1. Edit /etc/logrotate.d/sysstat Add "exit 0" after sadf line

Example:

/var/log/sa6/sa {
    compress
    missingok
    notifempty
    create
    prerotate
        /usr/bin/sadf -x /var/log/sa6/sa -- -A > /var/log/sa6/saxml
    exit 0 # F5 temp fix for ID 580500
    endscript
}

2. You can then manually backup then delete files under /var/log/sa6 to reclaim space

For permanent solution, upgrade to the version that ID 580500 is confirmed fixed. The bug is fixed since version 13.0.0 / 12.1.2.
