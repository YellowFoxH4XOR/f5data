Known Issue

This is the result of a known issue. If you specify a value for the IP ToS to Client setting when configuring a pool, the BIG-IP system sets the Type of Service (ToS) value to 0 (zero) instead of the value you configured when passing traffic to clients.

Note: This issue does not affect the IP ToS to Server setting.

ToS values, also referred to as Differentiated Services Code Point (DSCP) values, are used in Quality of Service (QoS) configurations to give specific traffic priority on the network. The BIG-IP system does not use the ToS value specified in the IP ToS to Client setting, which may result in priority traffic receiving a low priority on the network. In QoS network configurations, this behavior may prevent upstream and downstream devices from routing traffic properly.

Note: A similar issue exists for ToS values set by the server. For more information, refer to K8838: The TCP profile removes ToS values set by the server when passing traffic to a client.

F5 Product Development is tracking this issue as ID 224095 (Formerly CR133962).

Workaround

You can work around this issue by changing the IP ToS setting to Pass Through mode in the TCP profile associated with the virtual server. To do so, perform the following procedure:

Note: For the BIG-IP 9.3 software branch, this workaround is valid for BIG-IP version 9.3.1 with Hotfix-BIG-IP-9.3.1-HF3 or later. For the BIG-IP 9.4 software branch, this workaround is valid for BIG-IP versions 9.4.2 or later.

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. From the Protocol menu, select TCP.
  5. Select the TCP profile you want to modify.

    Note: F5 recommends that only custom TCP profiles be modified, and not the default or base TCP profile.

  6. To the right of the IP ToS setting, select the Custom check box.
  7. If you are running BIG-IP 10.x, select Pass Through from the IP ToS menu.

    If you are running BIG-IP 9.x, enter 65535 in the IP ToS field.
  8. Click Update.
