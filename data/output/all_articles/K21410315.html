Description

When using a BIG-IQ to re-activate a BIG-IP device license,  the re-activation fails, and logs an error message in the BIG-IP /var/log/ltm:
emerg mcpd[<PID>]: 01180006:3: Software version not covered by service agreement service check date <service_check_date> version date <version_date>

In this error message, note the following:

  • <PID > is the process ID for the mcpd process

Environment

  • BIG-IQ License Manager
  • BIG-IP with license managed by BIG-IQ

Cause

The Utility pool license on the BIG-IQ has not been refreshed recently enough and the check dates are not current. 

Recommended Actions

Re-activate the Utility pool license and its offerings before you attempt to refresh the licenses currently assigned to BIG-IPs.
  • Manual Chapter : License Management
