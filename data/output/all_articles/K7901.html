Known Issue

This is the result of a known issue. Creating multiple NATs with the same origin address will cause TMM to crash continually until the NATs are removed. TMM crashes when it attempts to associate the second NAT with the same origin address, even though the translation addresses reside on separate VLANs.

F5 Product Development tracked this issue as CR83624 and it was fixed in BIG-IP 9.4.2. For information about upgrading, refer to the BIG-IP LTM or Link Controller Release Notes.

Note: In BIG-IP 9.4.2 and later, the BIG-IP system does not allow a user to create multiple NATs with the same origin address.
