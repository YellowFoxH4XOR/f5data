Known Issue

The BIG-IP Configuration utility Resource Provisioning page displays Cannot find disk information after upgrading from 10.0.1 to 11.3.0.

Impact

Unable to modify the provisioning configuration using the BIG-IP Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms

  • BIG-IP iHealth lists Heuristic H419783 on the Diagnostics > Identified > Low screen.
  • The System > Resource Provisioning page of the BIG-IP Configuration utility displays the following error message:

    Cannot find disk information

Resolution

Status

F5 Product Development has assigned ID 419639 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the top right corner of the article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can modify the provisioning configuration using tmsh. For more information, refer to the provision command in the Traffic Management Shell (tmsh) Reference Guide.

Impact of workaround: A reboot is required. Perform this change during a maintenance window. This workaround allows you to modify the provisioning configuration, but it does not restore usability to the System > Resource Provisioning page of the Configuration utility.

To prevent this issue or to restore usability to the System > Resource Provisioning page, you can perform a stepped upgrade (for example, upgrading from 10.0.1 to 10.1.0 and then upgrading from 10.1.0 to 11.3.0). For information about upgrading, refer to the BIG-IP release note for the version you are upgrading to.

Impact of workaround: Requires additional upgrade installation. This should be performed during a maintenance window.
