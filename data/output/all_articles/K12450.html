Version 1.0.1 of the BIG-IP Edge Portal application was released on December 19, 2010 and is available through the Apple App Store. Version 1.0.1 of the BIG-IP Edge Portal application contains the following changes and fixes:

ID NumberSolution NumberDescription
344758None Request for Enhancement. BIG-IP Edge Portal now supports landscape orientation on all screens for the iPad.
344629None Request for Enhancement. BIG-IP Edge Portal now honors the credentials caching policy defined in the Connectivity Profile (on Access Policy Manager) and in the BIG-IP Edge Client settings (on FirePass).
344482None Request for Enhancement. BIG-IP Edge Portal now supplies its version number in the user agent string. For example: "EdgePortal/1.0.1"
344415None Request for Enhancement. BIG-IP Edge Portal now provides better handling of a denied logon on both FirePass and Access Policy Manager
343646None BIG-IP Edge Portal - The Done button in certain circumstances can become unresponsive. For example, the Done button on the Settings screen will appear as disabled when a session is expired.
343456None The session id is now removed and not displayed in the application log file for enhanced security.
343359None Under certain circumstances, a terminated session can cause improper operation and fails to display a session termination message.
343355None The invalid URL error message now provides a more descriptive explanation of the failure.
343255None There may be times when you will not be able to hide the overlay view of the keyboard.
342248None The logon failed button label text is now more descriptive.

Customers running the BIG-IP Edge Portal Version 1.0 should upgrade as soon as possible.

You can download the F5 BIG-IP Edge Portal application from the Apple iTunes App store, at the following location:

itunes.apple.com/us/app/f5-big-ip-edge-portal/id399900369

Note: You can report issues related to the BIG-IP Edge Portal application by clicking the Report a Problem button on the Settings page.

For more information about the BIG-IP Edge Portal application refer to K12328: Overview of the BIG-IP Edge Portal application for Apple iPhone, iPad, and iPod touch.
