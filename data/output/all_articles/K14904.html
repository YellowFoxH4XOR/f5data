Known Issue

Adding or modifying BIG-IP APM access profile Endpoint Security software checks may fail.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM system with administrative partitions.
  • A user created with the Manager role in a non-default administrative partition attempts to add or modify the Endpoint Security software check agents for an access profile.

Impact

Adding or modifying access profile software checks fails.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Adding or modifying access profile Endpoint Security software checks using the Configuration utility visual policy editor produces an error message similar to the following example.

    Server request for 'addItemDialogout' is failed: Request status=500

  • Adding or modifying access profile Endpoint Security software checks using Traffic Management Shell (tmsh) produces an error message similar to the following example.

    Access Denied: user <user name> does not have create access to object (agent_endpoint_check_software_item)
