Known Issue

Some Traffic Management Shell (tmsh) message routing commands may fail to execute for non-administrative users, even though non-administrative users have tmsh access to all partitions.

This issue occurs when all of the following conditions are met:

  • You are logged in as a user without administrative privileges.
  • You attempt to run the following tmsh commands:

    • list /ltm message-routing
    • show /ltm message-routing

Impact

You are unable to view message routing information using the tmsh utility as a non-administrative user.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system may display an error message that appears similar to the following example:

    Unexpected Error: Can't display all items, can't get object count from mcpd.

Workaround

To work around this issue, you can log in as an administrative user to run the list /ltm message-routing and tmsh show /ltm message-routing tmsh commands.

Impact of workaround: Performing this workaround should not have a negative impact on your system.
