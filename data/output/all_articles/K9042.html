Issue

In WebAccelerator 9.4.x, if the origin web server (OWS) takes longer than 30 seconds to render an HTTP request from the BIG-IP WebAccelerator, the BIG-IP WebAccelerator times out the connection and log an error message to the /var/log/wa/pvac.log file that appears similar to the following example:

WA ERROR: PvAsyncFetcherHttpData::taskDone(), sts != E_OK, Error: Server timed out.

Note: BIG-IP WebAccelerator 9.4.5-HF2 introduced a new expandedAsyncErrors option to the /config/wa/pvsystem.conf file. The expandedAsyncErrors option can help identity the requests that are timing out. For information about enabling the expandedAsyncErrors option, refer to K8991: BIG-IP WebAccelerator logging enhancement to help identify a faulty request and response.

By default, the BIG-IP WebAccelerator times out requests if it does not receive a response within 30 seconds. If additional time is required, you can modify the Read/Write Timeout value for the BIG-IP internal pool destination host. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click WebAccelerator.
  3. Click Applications.
  4. Click Destination Hosts.
  5. Click BIG-IP Internal Pool.
  6. Modify the Read/Write Timeout setting to the desired value.

    Note: The Read/Write Timeout value for the BIG-IP Internal Pool should not exceed the OWS idle timeout value.

  7. Click Save.

Note: The BIG-IP WebAccelerator system's Read/Write Timeout was removed in version 10.0.0 with the move to the plugin architecture.
