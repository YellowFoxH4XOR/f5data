01070707:7: The state mirroring address, statemirror.ipaddr, ipv6 may not be on the same network as the management port.

 

Environment

  • VIPRION
  • BIG-IP
  • Local mirror address set up with IPv6

 

Cause

This is caused by Bug ID 1032001.

None
