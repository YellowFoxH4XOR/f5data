Description

VIP with iRule is processing TLS1.2 and TLS1.3 traffic

The iRule processing TLS1.2 traffic is forwarding HTTP requests as expected

The same iRule processing TLS1.3 traffic is not forwarding HTTP requests as expected

 

Environment

  • BIG-IP
  • iRule with SSL Renegotiation
  • TLS1.3

 

Cause

SSL::renegotiate <----- deprecated in TLS 1.3

 

Recommended Actions

Additional iRule logic is needed to account for this condition, where SSL::renegotiate does not apply to TLS 1.3 traffic.

K10251520: BIG-IP support for TLS 1.3

 

Additional Information

The Transport Layer Security (TLS) Protocol Version 1.3 -  (page 28)

Because TLS 1.3 forbids renegotiation, if a server has negotiated TLS 1.3 and receives a ClientHello at any other time, it MUST terminate the connection with an "unexpected_message" alert.
