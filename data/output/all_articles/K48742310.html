K48742310: System shows offline state after an upgrade

Type
Support Solution
Published
2022-02-25
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K48742310

Description

After a software upgrade, the system is in offline state.

Environment

  • Software upgrade

Cause

Generally it is normal for a BIG-IP system to appear in offline state after recently booting. It can take some time for the system to initialize, especially after an upgrade.

Recommended Actions

Wait some time after the upgrade to allow the system to come into an online state.

If the system stays in an offline state, begin troubleshooting by reviewing the output of the HA table:

  • K20060182: Overview of the HA table

None
