Description

You are planning to upgrade to version 13 or above and the config might not load because of BUG ID 699249.

Environment

  • Bug after upgrade to v13 or above
  • Config doesn't load
  • You upgrade to a version affected by Bug ID 699249: The config may not load after upgrade if syslog-ng syntax is not valid
    from a non-affected version

Cause

In v13.0.0, the syslog-ng version changed from 2.1.4 to 3.8.1. Syslog-ng 'include' options may contain syntax which is correct in 2.1.4 syslog, but is not correct in 3.8.1. TMOS does not parse the 'include' option, or translate it from older versions to newer, or any other modification. It blindly copies it into the configuration file.

Recommended Actions

You need to either remove all 'include' options and leave 'include' blank (include ""), or modify include options and filters according to the new Syslog-ng 3 syntax. Please refer to the following Syslog page for this syntax: Syslog-ng Open Source Edition 3.16 - Administration Guide.

Note: This config can be modified on the /config/bigip_base.conf file or equivalent tmsh commands.

Additional Information

You also need to be aware of this other BUG ID related to syslog: Bug ID 711248: After upgrade to 13.1.0 or later, mcpd fails to start due to syslog config parsing error.
