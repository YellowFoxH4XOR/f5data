Known Issue

This is the result of a known issue. Connections processed by the BIG-IP ASM or WebAccelerator on the client source port are not passed on the same source port to the web server. As a result, the client source port information is not passed to the back-end virtual server. The BIG-IP ASM or WebAccelerator then selects a new source port when sending the connection to the web server.

Important: Although this behavior does not introduce failures, it does prevent the ability to provide a transparent connection.

F5 Product Development is tracking this issue as CR74286.
