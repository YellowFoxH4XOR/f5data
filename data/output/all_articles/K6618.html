Known Issue

This is the result of a known issue. When PVA-enabled virtual servers receive a large number of connections while load balancing to servers that are down, an LBDB exception error is logged to the /var/log/ltm file.

F5 Product Development tracked this issue as CR59463, CR65861, and CR68002, and it was fixed in BIG-IP LTM version 9.2.4. For information about upgrading, refer to the BIG-IP LTM release notes.
