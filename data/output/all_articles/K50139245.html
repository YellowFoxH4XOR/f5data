Known Issue

BIG-IP log message entries may not include the hostname.

This issue occurs when the following condition is met:

  • The BIG-IP system is configured to send log messages to a syslog server.

Impact

The system cannot parse the log messages based on the hostname.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Log message entries do not include the hostname, as shown in the following example:

    Jan 21 15:41:00 local/sccp notice sbmand[8185]: 012a0005:5: Stopping sbmand
