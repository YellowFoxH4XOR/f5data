K000161210: Peer cert verify error: certificate has expired (depth 1; cert /CN=b000d0e-00b4-0000-00b0000a00d0e000)

Description

Traffic logs on BIG-IP LTM display repeated messages such as example below or similar:

Peer cert verify error: certificate has expired (depth 1; cert /CN=b1000e0d-44f4-3000-72b4000a5d8e701)

Attempts to locate the certificate using standard commands tmsh list sys crypto cert one-line | grep <CN> and run /sys crypto check-cert do not return results. The certificate is not found in the usual MCPD-managed certificate listings.

Environment

  • LTM
  • Device trust certificate

Cause

The error is caused by an expired device trust certificate used for HA communication between BIG-IP units. This certificate is not managed via standard MCPD certificate commands and must be renewed through the Device Management interface.

Answer/Recommended Actions

  1. Validate Device Trust Certificate Status:
    Navigate to Device Management > Device Trust > Local domain on both BIG-IP units to check the certificate status.
  2. Renew Device Trust Certificate:
    Schedule a service window for certificate renewal.
    Follow the procedure outlined in K47052252: Procedure to renew Device Trust Certificates on BIG-IP system to renew the device trust certificate.
  3. Verify Resolution:
    After renewal, monitor logs to ensure certificate expiration errors are resolved.
