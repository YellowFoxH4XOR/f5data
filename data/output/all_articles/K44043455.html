Known Issue

BIG-IP APM portal access rewritten iframe JavaScript content may not function correctly.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a portal access profile.
  • Content rewritten by BIG-IP APM contains HTML iframe(s) that reference JavaScript code in the SRC.

    For example:

      <script>
        var s="javascript:'<script>alert(document.write)</scr"+"ipt>'";
        var ifr=document.createElement("iframe");
        a.appendChild(ifr);
        ifr.setAttribute("src",s)
      </script>

Impact

The rewritten iframe content does not function correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Expected content does not appear in the user's browser.
  • Applications dependent on the rewritten iframe content do not function.
  • The user's browser JavaScript console displays an exception error that appears similar to the following example:

    F5_Invoke_write is not defined
