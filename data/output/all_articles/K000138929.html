Description

After OAuth with DUO is configured, users observe an authentication failure, with APM logs reporting an error similar to:

OAuth Client: authorization_code is required to get access_token for server '/Common/duo_server'

 

Environment

  • BIG-IP APM
  • MFA
  • OAuth with DUO

 

Cause

  • bad config

 

Recommended Actions

Ensure to follow this document

  • APM Configuration to Support Duo MFA using iRule

NOTE: Ensure the request parameters configured in the auth-redirect-request and a token-request configurations are configured exactly as documented. 

The most common mistakes are with these parameters:

  • client_id parameter with type client-id
  • response_type parameter with type response-type
  • grant_type parameter with type grant-type
  • redirect_uri parameter with type redirect-uri
