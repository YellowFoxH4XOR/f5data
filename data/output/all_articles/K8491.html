Known Issue

This is the result of a known issue. If a Windows client launches a Network Access connection, and the client device performs a DHCP renewal while the Network Access connection is active, the DNS servers provided by FirePass are overwritten or preempted by the DNS servers provided by the DHCP server. When this issue occurs, the user may be unable to access resources across the Network Access connection due to the client device’s inability to perform DNS resolution using the DNS servers provided by FirePass.

F5 Product Development tracked this issue as CR89225 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-601-10 has been issued for FirePass version 6.0.1 and cumulative hotfix HF-602-1 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

Note: The Cumulative Hotfixes listed above add the Enforce DNS search order check box to the Network Access: Resources page under the DNS tab.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

Users can work around this issue by disconnecting and reconnecting the Network Access connection.
