Known Issue

The system may improperly assign Active Directory (AD)/Lightweight Directory Access Protocol (LDAP) group resources when you use AD/LDAP Group Resource Assign.

This issue occurs when all of the following conditions are met:

  • You have the AD Group Resource Assign or LDAP Group Resource Assign policy item configured in your access policy.
  • Branch rules in the AD/LDAP Group Resource Assign item are configured to query for group membership.
  • The matching AD/LDAP attributes returned by the AD/LDAP server contain lower case names or values.

For example, take the following rule expression:

expr { [mcget {session.ad.last.attr.memberOf}] contains \"cn=Example,\" } 

If the previous rule expression is configured in an AD Group Resource Assign policy item using the VPE, and the AD server returns the following output, the BIG-IP APM system would fail to match the Example group because cn is not upper case:

cn=Example,ou=Groups,dc=example,dc=com

Impact

The BIG-IP APM system is unable to match the group and incorrectly assigns resources to the user.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When connecting to the BIG-IP APM system, users are assigned the wrong group resources.
  • The AD/LDAP Group Resource Assign functionality is impaired following an upgrade.
