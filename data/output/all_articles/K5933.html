Known Issue

Upgrading the BIG-IP ASM to a new version can cause the system to stop responding during the upgrade process and take as long as 45 minutes to complete. This delay is due to the upgrade process requiring a UCS backup prior to making the update.

The UCS backup file for the BIG-IP ASM system contains all the statistics and attacks recorded, as well as all the detailed forensics information for all web applications. When a BIG-IP ASM 9.x system is upgraded, the installation package updates the necessary system files, and then installs all configuration information in the /config.ucs file. Since the statistics and forensic information can be quite large, the installation process can take up to 45 minutes. This behavior is by design.

You can shorten the amount of time it takes for an upgrade to complete by clearing the statistics and forensic information from the BIG-IP ASM database before creating the /config.ucs file.

F5 Product Development tracked this issue as CR67386 and CR54580, and it was fixed in BIG-IP ASM 9.3.0 and 9.4.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Note: The upgrade process should be performed during a maintenance window to prevent any disruption to client access.

Important: The following procedures will delete all BIG-IP ASM related events, attacks, and forensic information from the ASM database. This does not harm your system, but all historical information will be lost.

Clearing the events and attacks for all web applications

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Expand the Application Security menu and select Web Applications.
  3. Select Statistics.
  4. Set the filter to Not Filtered.
  5. To clear the events, click Clear.
  6. Click the Attacks tab.
  7. Set the filter to Not Filtered.
  8. To delete the attacks, click Delete.

Clearing the events from the Forensics section for each Web Application

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Expand the Application Security menu and select Web Applications.
  3. Select the first Web Application.
  4. Click the Forensics tab.
  5. Set the filter to Custom.
  6. Select All for each filter.
  7. To list all events, click Go.
  8. To clear all events, click Clear All.
  9. Repeat steps 1 through 8 for each Web Application.

After the above procedures have been completed, you can create the config.ucs file and continue the upgrade.
