Topic

The iSeries and rSeries platforms use three different AC power supply units (PSUs) that should only be installed in their supported platforms.

  • i2000/i4000 and r2000/r4000 series: General Electric (GE) or ABB AC power supply (F5 part number PWR-0334-xx, GE or ABB model number CSAC0250BZ, GE or ABB part number 150047488).
  • i5000/i7000/i10000/i11000 and r5000 series: Murata AC power supply (F5 part number PWR-0306-xx, Murata Model M1845).
  • r10000/r12000 series: Murata AC power supply (F5 part number PWR-0388-xx, Murata Model MW2100).

Description

IMPORTANT: The size and shape of the three AC power supplies are the same, so any of them will physically fit into the different i2000/i4000/i5000/i7000/i10000/i11000/r2000/r4000/r5000/r10000/r12000 platforms. You need to verify the correct power supply designed for your specific iSeries or rSeries platform model prior to its installation into the device.

The iSeries and rSeries platforms use three different AC power supply units (PSUs) that should only be installed in their supported platform.

  • The i2000/i4000 and r2000/r4000 series platforms use a General Electric (GE) or ABB AC power supply (F5 part number PWR-0334-xx, GE or ABB model number CSAC0250BZ, GE or ABB part number 150047488).  This CUSTOMER P/N can be seen on the label when removed from the device.

    You can visually identify the GE or ABB AC power supply without removal from the device by the black horizontal (--) pull handle and hexagon shaped perforations near the power cord connection.

     

  • The i5000/i7000/i10000/i11000 and r5000 series platforms use a Murata AC power supply (F5 part number PWR-0306-xx, Murata Model M1845). This CUSTOMER P/N can be seen on the label when removed from the device.

    You can visually identify this Murata AC power supply without removal from the device by the black vertical (|) pull handle and rectangle shaped perforations near the power cord connection. 

     

  • The r10000/r12000 series platform use a Murata AC power supply (F5 part number PWR-0388-xx, Murata Model MW2100). This CUSTOMER P/N can be seen on the label when removed from the device.

    You can visually identify this Murata AC power supply without removal from the device by the cream vertical (|) pull handle and rectangle shaped perforations in the black front near the power cord connection.

     

    This AC power supply will initially have a tag attached to the cream vertical (|) pull handle reminding the end user to check for the correct installation into their appliance. 

     

If you install the wrong PSU model in an iSeries or rSeries platform, the system will report errors, alert conditions, and fail the End-User Diagnostics (EUD) tests (with an iSeries appliance).

For example, if you install the Murata PWR-0306-xx/M1845 PSU into an i2000/i4000 series platform, or install the GE or ABB PWR-0334-xx/150047488 PSU into an i5000/i7000/i10000/i11000 series platform, you may encounter any of the following symptoms:

  • The LCD panel displays a critical alert for one or more of the following:
    • Platform FRU data corrupted or missing.
    • Status config mismatch.
    • PSU unidentified.
  • The tmsh show sys alert lcd command reports errors that appear similar to the following example:

    --------------------------------------------------------------------
    Sys::LCDAlerts
    Slot          Timestamp  Priority         Id    Description
    --------------------------------------------------------------------------------
    0     02/06/18 15:05:29  critical  0x12a0043    PSU2 Status PSU unidentified
    0     02/06/18 15:05:28  critical  0x12a0043    PSU2 Status config mismatch
    0     02/06/18 15:05:15  critical  0x12a0025    Platform FRU data corrupted or missing
    0     02/06/18 15:05:14      info  0x12a0045    PSU2 Status present

  • The tmsh show sys hardware command reports a power supply status of down and NA (not available) that appears similar to the following example:

    Appliance Power Supply Status
      Index  Status  Current
      1      up      AC
      2      down    NA

  • The /var/log/sel file contains messages that appear similar to the following example:

    INF BMC  Power Supply #1d Present 6f [00 ff ff]
    INF BMC  Power Supply #1d Config Mismatch 6f [08 ff ff]
    INF BMC  Power Supply #1d Unidentified 6f [0a ff ff]

  • With iSeries appliances, EUD tests fail and report the following unknown error messages when trying to read PSU status or PSU model information:
    • ERROR: Unknown error occurred when trying to read PSU status.
    • ERROR: Unknown error occurred when trying to read PSU model information.

Recommended Actions

Prior to installing an AC power supply into an iSeries or rSeries appliance, check that you use only the power supply designed for your specific platform model. 

If you are unsure if you have the correct power supply installed, check the CUSTOMER P/N and visual attributes as listed above for the specific iSeries or rSeries appliance.  If unable to physically check these, then check for error logs, alerts or diagnostics as seen in the examples shown above.

If you have redundant power supplies, check that both power supplies are the same correct CUSTOMER P/N and visually check the power supplies installed with the pictures in this article.  Also check that both installed power supplies look identical to each other. If both are not visually the same, there is an incorrect power supply installed.
