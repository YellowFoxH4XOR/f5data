Description

It is possible to create more than 2 radius server following in CLI, however, GUI shows system_auth_name1 and system_auth_name2 only, system_auth_name3 and system_auth_name4 is not shown.

auth radius /Common/system-auth {
  servers {
    /Common/system_auth_name1
    /Common/system_auth_name2
    /Common/system_auth_name3
    /Common/system_auth_name4
  }
}

auth radius-server system_auth_name1 {
  secret testing123
  server 10.10.10.10
}
auth radius-server system_auth_name2 {
  secret testing123
  server 20.20.20.20
}
auth radius-server system_auth_name3 {
  secret testing123
  server 30.30.30.30
}
auth radius-server system_auth_name4 {
  secret testing123
  server 40.40.40.40
}

Environment

BIG-IP All version

Cause

tmsh allow to add more than 2 radius servers, however, GUI allow 2 servers, primary server and secondary server, and the auth radius-server name is hard-coded as system_auth_name1 and system_auth_name2.

The inconsistency between tmsh and GUI is tracked by  Bug ID 2186953.

Recommended Actions

Do not add more than 2 servers.

Use the name system_auth_name1 for primary server, and system_auth_name2 for secondary server.
