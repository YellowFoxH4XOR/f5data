Description

You have BIG-IP Virtual Edition (VE) licenses designated as "V18" (for example, F5-BIG-LTM-VE-V18) and notice that BIG-IP software versioning jumped from 17.x directly to 21.x, skipping versions 18, 19, and 20. You want to know if your V18 license allows you to upgrade to BIG-IP 21.x or later software versions.

V18 licenses only support up to BIG-IP 17.5.x so V18 doesn't support BIG-IP 21.x and later per K15643: BIG-IP VE Version Plus license offerings.

Cause

The confusion arises from the difference between the license SKU designation and the software version ceiling. The "V18" in the license SKU refers to the license generation, not the software version. Additionally, F5's software versioning jumped from 17.x to 21.x (skipping 18, 19, 20) due to a change in naming methodology, which coincidentally matches the V18 license designation but is unrelated.

Understanding V18 license designation

  • The "V18" in your license SKU (F5-BIG-xxx-xxx-V18) refers to the license generation/SKU version, not the maximum software version you can run
  • V18 licenses were designed to support software releases up to and including the last maintenance release of BIG-IP 17.5.x
  • The V18 license SKU was created before F5 changed its software versioning methodology
  • There are no BIG-IP v18.x, v19.x, or v20.x software versions
  • The next major version after 17.x is 21.x

Recommended Actions

Important: V18 licenses do NOT support v21.x. V18 licenses support BIG-IP TMOS 12.1.0 through 17.5.x only.

  1. Supported software versions by License SKU
    • V18 licenses support BIG-IP software up to 17.5.x only
    • BIG-IP VE V18 licenses do NOT support v21.x or later
    • BIG-IP VE V18 licenses support BIG-IP TMOS software versions 12.1.0 through 17.5.x only.

Figure: BIG-IP VE Version Plus license offerings (Article K15643)

 

  1. If you want to continue using your V18 licenses 
    • Continue using BIG-IP v17.x software
      • BIG-IP 17.5.x: End of Technical Support (EoTS) on January 1, 2029
      • BIG-IP 17.1.x: End of Technical Support (EoTS) on March 31, 2027
    • Plan for license refresh before your current licenses expire
      • Evaluate V23 license options when approaching renewal time
      • V23 licenses offer extended lifecycle and enhanced security features (improved API security, enhanced DNS capabilities)
    • Do NOT attempt to install v21.x software with V18 license
      • Installation may appear successful but will not be supported
      • Your support maintenance contract cannot be renewed in this scenario
  1. If you want to use BIG-IP v21.x or later
    • Contact your F5 Account Manager to discuss upgrading to V23 Virtual Edition licenses
    • V23 licenses support BIG-IP TMOS 17.1.x through 23.x, including v21.x
