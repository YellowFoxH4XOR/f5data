K000146506: BD restart loop due to insufficient XML engine memory to load related XML/JSON configuration

Type
Support Solution
Published
2024-10-23
Updated
2024-10-23
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000146506

Description

Adding large or many XML schemas may cause the XML processing engine to run out of memory.  If this condition is reached, the BIG-IP ASM system will fail to start.

Environment

ASM

Cause

BD isn't able to start due to insufficient XML engine memory to load related XML/JSON configuration.

Recommended Actions

Allocate the max allowed memory to variable total_xml_memory, using this command:mysql -uroot -p`perl -I/ts/packages -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` -e "update DCC.INTERNAL_CONFIG_ITEMS set current_value = 1073741824 where field_name = 'total_xml_memory';"

If it doesn't help as the system needs more memory, run one of the following options:

  • Restore the unit from any good old UCS file, and then sync most recent configuration from the active unit.
  • Follow K6992 to reset ASM database to a default configuration, and then sync most recent configuration from the active unit.
