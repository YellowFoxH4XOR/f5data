Description

After an upgrade or a configuration load, the configuration fails to load with an error similar to:

01420001:2: MCP call 'mcpmsg_set_string_item(m_msg, CID2TAG(cid), val.c_str())' failed with error: 16908375, 01020057:3: The string with more than 65535 characters cannot be stored in a message. : msg++/SchemaObjToMsg.cpp, line 152

At least one LTM monitor in the configuration has a description containing a backslash (\).

Environment

  • LTM Monitors with descriptions
  • After config load or after upgrade

Cause

Bug ID 653930: Monitor with description containing backslash may fail to load.

Recommended Actions

  1. Open the configuration file bigip.conf with a text editor, and go to the line indicated in the error above. Just above that line you should find the monitors with the offending characters (\). Similar to:

    ltm monitor http /Common/http_monitor {
        defaults-from /Common/http
        description "Monitor to check if page has a \\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\

  2. Remove the \ from the description and save the changes
  3. Load the configuration again with tmsh load sys config until the error is no longer present

Additional Information

More information about this ID can be found on: K69713140: A monitor with a backslash character (\) in the description may fail to load.
