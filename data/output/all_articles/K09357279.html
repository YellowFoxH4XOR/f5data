Description

When adding Microsoft Intune as an Endpoint Management System and APM failed contacting Intune with logs showing connectivity error:

notice mdmsyncmgr[1234]: 019dffff:5: (null)::00000000: {} /Common/Microsoft_Intune: Scheduling for 60 seconds, start updating at 2019-Mar-23 21:33:17
err mdmsyncmgr[1234]: 019dffff:3: (null)::00000000: {} /Common/Microsoft_Intune: Error during updating device details: Connectivity error (End of file)

Environment

  • BIG-IP APM
  • Intune Endpoint Management System

Cause

There are generally three causes for this type of failure:

  • DNS resolution
  • Connectivity
  • Invalid Credentials

Recommended Actions

  • Verify functional DNS Resolution. This often time requires a DNS resolver.  Details for configuring a DNS Resolver can be found in:
    Manual Chapter : LTM SSL Forward Proxy and SWG
  • Verify connectivity to the Microsoft Azure Intune environment (e.g. login.microsoftonline.com:443), including ensuring that there are no firewalls blocking traffic.
  • Verify that the device has connectivity out on Route Domain 0. See K20465715: BIG-IP APM route domain limitations
  • Verify that the correct credentials are included in the configuration (Tenant Id field, Client Id, Client Secret)
