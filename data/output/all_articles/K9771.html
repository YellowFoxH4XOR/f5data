Beginning January 2009, F5 began using a new 150 GB Western Digital hard drive for the ARX 1000 platform. The previous 74 GB Western Digital drives will no longer be used in manufacturing.

Note: This change is strictly due to an availability issue with the 74 GB drives; it is not due to an engineering change on the ARX 1000 platform.

As of April 4, 2009, if a 74 GB drive fails in an ARX 1000 chassis, it will be replaced by a 150 GB drive. As previously indicated, this change is due to hard drive availability and not an engineering requirement.

If an ARX 1000 system with 74 GB drives experiences a single drive failure, the failed 74 GB drive can be replaced with a 150 GB drive. Both drives do not need to be replaced. The ARX 1000 system will function normally and the RAID rebuild process will be successfull if the remaining drive is 74 GB and the new drive is a 150 GB.

Important: If a new 150 GB drive fails, it must be replaced with a 150 GB drive. If a 150 GB drive is replaced with a 74 GB drive, the RAID rebuild process will fail.

If an entire ARX 1000 chassis needs to be replaced, and the original chassis had a 150 GB drive, it may be replaced with an ARX 1000 system that has a pair of 74 GB drives. An ARX 1000 system with 74 GB drives can form a redundant (high availability) pair with an ARX 1000 system with 150 GB drives.

The size of the drive is listed in the Disk Details section of the show chassis diskuse command output.

The Disk Details section of the show chassis diskuse command output for an ARX 1000 system with the 74 GB drives will appear similar to the following example:

 Disk Details:
 Disk       Size          State               Transfer Rate   Model
 --------   -----------   -----------------   -------------   -----------------
  Bay 1     69.24G        Online              1.5Gb/sec       WD740ADFD-00NLR1
  Bay 2     69.24G        Online              1.5Gb/sec       WD740ADFD-00NLR1

The Disk Details section of the show chassis diskuse command output for an ARX 1000 system with the new 150 GB drives will appear similar to the following example:

 Disk Details:
 Disk       Size          State               Transfer Rate   Model
 --------   -----------   -----------------   -------------   -----------------
  Bay 1     139.73G       Online              1.5Gb/sec       WD1500HLFS-01G6U
  Bay 2     139.73G       Online              1.5Gb/sec       WD1500HLFS-01G6U
