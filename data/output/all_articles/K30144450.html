Description

Access session variables are missing or being truncated when written to /var/log/apm

Environment

  • Access session logs
  • Session Variables
  • policy_path session variable

Cause

BUG ID 1095909

APM Session variables that are large, for instance

  • policy_path
  • configVariableCatalogSessionKey

 get truncated in local syslog (/var/log/apm) which has a default size limit of 1024 bytes.
 

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Configure High-Speed logging on BIGIP rather than using local syslog
  2. Turn off policy trace logging under System > Logs > Configuration > Options > Policy Trace - Disabled
