Description

Enabling session tracking for application sessions without a predefined login URL provides a strategic advantage in swiftly identifying the origin of attacks by associating them with specific sessions or IP addresses. This proactive stance enhances security by offering insights into potential threats.

However, it's crucial to acknowledge a potential drawback in this configuration: the absence of session tracking for authenticated users. This loophole introduces a security concern as malicious sessions can exploit the lack of username metadata tracking, allowing them to operate undetected.

Environment

  • Session Awareness is enabled.
  • Login URLs are defined.
  • Application Username option is set to None.

Cause

When the Application Username option is configured as None, the enforcer operates in a mode where it refrains from monitoring and recording application sessions and associated usernames for login requests.

Recommended Actions

To guarantee full session awareness capabilities, ensure to define all login pages and set the option Application Username to Use All Login Pages.
