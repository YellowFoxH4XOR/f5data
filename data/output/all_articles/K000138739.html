K000138739: Internet traffic going though the VPN even when it's excluded

Type
Support Solution
Published
2024-02-27
Updated
2024-02-27
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000138739

Description

When using split tunneling to allow certain IP addresses to go through the BIG-IP, but not internet traffic, the BIG-IP is still receiving internet traffic, which causes internet connections to fail.


Environment

BIG-IP APM

Network Access resource

Split Tunneling

Dynamic LAN Address Space as default "Default All"


Cause

Dynamic LAN Address Space is pulling that internet traffic


Recommended Actions

Remove "Default All" from Dynamic LAN Address Space in the Network Access resource


Additional Information

None
