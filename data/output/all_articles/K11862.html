Known Issue

Starting in BIG-IP APM and Edge Gateway 10.2.0 with Hotfix-BIGIP-10.2.0-1755.1-HF1 installed, users can remove the VPN client from their Windows system by using the Add/Remove Programs utility. This functionality will work for both 32-bit and 64-bit Windows operating systems. Prior to version 10.2.0 with Hotfix-BIGIP-10.2.0-1755.1-HF1 installed, users must manually uninstall the client components.

F5 Product Development is tracking this request for enhancement as ID 294225 (formerly CR134304) and it was fixed in BIG-IP APM 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

This feature enhancement was introduced in Hotfix-BIGIP-10.2.0-1755.1-HF1 for BIG-IP 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
