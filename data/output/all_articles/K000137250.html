Environment

Ansible --check option

Cause

--check option is Ansible "check mode" verifying if playbook is fine. That means that some (not all!) modules will report what they would have changed if the playbook had been executed for real (with no--check). It allows to see what’s going to happen and to check inner logic of the playbook.Its not checking BIg-IP configuration.


In other words --check does not verify REST responses. It just verifies commands modules input of parameters, type of data etc.

Recommended Actions

Works as designed. Please do not use check for verifying BIG-IP configuration.
