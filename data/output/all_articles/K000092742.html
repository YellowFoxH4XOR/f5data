K000092742: Configuring the log levels for the asm_config_server process (12.x and later)

Type
Support Solution
Published
2022-11-28
Updated
2022-11-28
Source
https://my.f5.com/manage/s/article/K000092742

Description

You should consider using this procedure under the following condition:

  • You need to change the log levels for the asm_config_server process for certain situations, such as troubleshooting BIG-IP ASM ConfigSync issues.

Environment

  • ASM (or Advanced WAF) is provisioned

Cause

Additional debugging should only be done under the guidance of F5 Support.

Recommended Actions

Enabling verbose logging for the asm_config_server process

You can turn on more verbose logging by changing the log levels for the db variables from info to trace.  To do so, perform the following procedure:

Impact of procedure: An overloaded BIG-IP system may experience performance degradation if the logging intensity is high.

  1. Log in to the BIG-IP command line.
  2. Change the log level from info to trace for the db variables:
tmsh modify sys db log.asm.asmconfig.level value trace
tmsh modify sys db log.asm.asmconfigevent.level value trace
tmsh modify sys db log.asm.asmconfigverbose.level value trace  (13.1.0 or later)

Note: The asm_config_server process should pick up these changes automatically.

Disabling verbose logging for the asm_config_server process

You can turn off more verbose logging by changing the log levels for the db variables from trace to info.  To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Change the log level from trace to info for the db variables:
tmsh modify sys db log.asm.asmconfig.level value info
tmsh modify sys db log.asm.asmconfigevent.level value info
tmsh modify sys db log.asm.asmconfigverbose.level value info  (13.1.0 or later)

Note: The asm_config_server process should pick up these changes automatically.

Additional Information

None.
