Known Issue

The VIPRION B4100 (PB100) blade will fail to create a trunk with two 10GB XPF interfaces.

This issue occurs when one of the following conditions is met:

  • You install a configuration from a previous version that contains a trunk with two 10GB XPF interfaces.
  • You attempt to create a trunk with two 10GB XPF interfaces using the Traffic Management Shell (tmsh).
  • You attempt to install either a user configuration set (UCS) or a single configuration file (SCF) with a trunk containing two 10GB XPF interfaces.

Impact

The BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The configuration is missing after an upgrade.
  • An error similar to the following example is produced when trying to create a trunk containing two XPF 10GB interfaces using the tmsh utility:

    01070619:3: Interface 2/1.2 media type is incompatible with other trunk members

  • You observe an error message similar to the following example after attempting to load a UCS or SCF with a two XPF 10GB interface trunk:

    01070619:3: Interface 1/1.2 media type is incompatible with other trunk members
    Unexpected Error: Loading configuration process failed.
