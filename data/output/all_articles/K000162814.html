K000162814: BIG-IP TMUI Hotfix Installation Fails with “Version Incompatibility” During Upgrade

Type
Support Solution
Published
2026-08-06
Updated
2026-08-06
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000162814

Description

A hotfix installation through the BIG-IP Configuration utility (TMUI) fails validation when the hotfix targets a software version different from the currently active boot volume.

The following TMUI error may appear:

Hotfix test failed due to version incompatibility

Environment

  • BIG-IP LTM (21.1.x)
  • Hotfix installation through TMUI
  • The hotfix is being installed to a different boot volume
  • The currently active boot volume runs a different software version from the hotfix target version

Cause

The TMUI installation workflow invokes dry-run validation against the currently active BIG-IP volume instead of validating the hotfix against the software version in the destination boot volume. The resulting version mismatch blocks the installation.

This issue is being tracked as Defect ID 2449609

Recommended Actions

Use tmsh to install the hotfix directly to the intended boot volume instead of using the TMUI installation workflow.

  1. Verify that the required software and hotfix images are available on the BIG-IP system.
  2. Identify the intended destination boot volume.
  3. Install the hotfix from the command line:
    tmsh install sys software hotfix <hotfix-image> volume <destination-volume>
  4. Monitor the installation and verify that the hotfix is installed on the intended boot volume.
    watch tmsh show sys software status
  5. Boot the system from the updated volume according to the standard BIG-IP software upgrade procedure.

Additional Information

  • The issue is specific to the TMUI dry-run validation workflow.
