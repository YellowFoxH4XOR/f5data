Purpose

You should consider using this procedure under the following conditions:

  • Users are accessing the BIG-IP APM system through the Microsoft Windows operating system and the Mozilla Firefox browser.
  • When the browser attempts to initiate a session with the BIG-IP APM system, the required browser plug-in fails to download.

Note: F5 official support of the Firefox browser stops after the Firefox version 34 release.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You should be familiar with the Firefox browser configuration, including advanced settings such as about:config.

Description

When using the Firefox browser for network access sessions or application access tunnels, the BIG-IP APM system requires Firefox to download and install a plug-in that establishes the access tunnel to the BIG-IP APM system. However, the Firefox browser code updates may disable access to the local user plug-in folder, which causes the download, installation, and plug-in download to fail.

This condition may occur under the following conditions:

  • The BIG-IP APM system is configured with a Network Access or Application Access Tunnel profile.
  • The user is connecting to the BIG-IP APM profiles through the Windows operating system and the Firefox browser.
  • The user receives an error message similar to the following example when the browser attempts to download the required BIG-IP APM Firefox plug-in:

    Firefox prevented this site <hostname or ip address> from asking you to install software on your computer.

  • The user receives an error message similar to the following example after clicking the Firefox Allow button:

    The add-on could not be downloaded because of a connection failure on <hostname or ip address>.

Procedures

Installing the Firefox plug-in after the BIG-IP APM browser plug-in fails to download

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. In the Firefox failed connection window, in the Download and install the software manually (second section) of the failed download window, click Click here to download and save a compressed file to download the urhostplg.zip file to the local system.
  2. Extract the zipped archive file to a local temporary directory.
  3. In the local temporary directory, locate the subdirectory named Plugins that you extracted from the compressed archive in the previous step.

    The extracted Plugins directory includes the following files:

    • ics.exe
    • NPuroamHost.dll
  4. Copy the files from the local Plugins directory to the Firefox Plugins directory.

    The destination Firefox directory path for Windows is:

    C:\Program Files (x86)\Mozilla Firefox\Plugins

    Note: If the Firefox directory does not already contain the subdirectory Plugins, copy the entire Plugins directory from the extraction location to the Firefox directory to create the Plugins directory.

  5. Open a new tab in the Firefox browser.
  6. In the browser's address bar, type about:config.
  7. If necessary, confirm the Firefox warning about making changes to the browser configuration.
  8. In the Search box, search for the Preference Name plugins.load_appdir_plugins.
  9. To the right of the plug-ins Preference Name load_appdir_plugins, change the value from false to true.
  10. Close all instances of the Firefox browser, and then start a new instance.
  11. Log in to the BIG-IP APM system to establish a new session.

    Note: The Firefox browser may display the following message for several seconds before initializing the network access tunnel:

    Downloading required files....
