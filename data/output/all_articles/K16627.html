Known Issue

The BIG-IP system may not update virtual address state changes.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration uses a virtual address with route advertisement enabled.
  • You have enabled a routing protocol (for example, BGP) on the BIG-IP system that is licensed with advance routing.
  • State changes occur to the pool resource associated to the affected virtual address. For example, if the pool resource becomes unavailable and then resumes after some time.

Impact

The BIG-IP system does not update the route advertisement with the latest change, and the routing databases that are not updated may cause connection failures to the available services.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to update the route advertisement with the latest state change of the affected virtual address.
  • You notice that when the affected virtual address status changes from available to unavailable, the system updates the route advertisement as expected (for example, the affected route is removed). However, when the virtual address status changes from unavailable to available, the system does not propagate the route advertisement update to all the subscribers.
