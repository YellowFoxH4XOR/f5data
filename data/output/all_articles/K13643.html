Known Issue

Client authentication may fail when the BIG-IP APM access policy is configured to use Kerberos single sign-on (SSO) and Active Directory Domain Controller (DC) configured as a Read-Only Domain Controller (RODC).

Starting in Windows Server 2008, Microsoft introduced the concept of the RODC. RODCs are additional domain controllers for a domain that hosts complete, read-only copies of the partitions of the Active Directory database and a read-only copy of the SYSVOL folder contents.

Impact

Users are unable to access resources through the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users are unable to access resources through the BIG-IP APM system.
  • The domain controller returns the Kerberos error KRB5KRB_AP_ERR_BAD_INTEGRITY in the Kerberos TCP response packet.

    For Example:

    90.027002 10.184.2.240 10.104.71.69 KRB5259TGS-REQ
    100.028376 10.104.71.69 10.184.2.240 TCP88kerberos > 52149 [ACK] Seq=1 Ack=1620 Win=131584 Len=0 TSval=225726965 TSecr=3980591478
    110.028609 10.104.71.69 10.184.2.240 KRB5179KRB Error: KRB5KRB_AP_ERR_BAD_INTEGRITY

Workaround

You can work around this issue by ensuring that the Kerberos SSO configuration is sending Kerberos requests to a read-write domain controller.
