Description

When Remote - LDAP is used for sys authentication, the login process takes long time but not fail. Capture traffic between BIG-IP and the remote LDAP server(s), no packet drop or other outstanding problem.

Environment

  • BIG-IP 
  • Remote LDAP server(s)

Cause

The most possible reason is the search scope is too large, comparing with the bind-dn. One example is below, which takes long time to login:
 
 auth ldap system-auth {
       bind-dn CN=Account_Name,CN=Users,DC=Domain_Name,DC=com
       bind-pw ********
       login-attribute samaccountname
       port ldaps
       search-base-dn DC=Domain_Name,DC=com   ---> the search scope is too large comparing with the bind-dn
       servers { IP_Server }
       ssl enabled
   }

After updating the search-base-dn to below, then the sys auth is much faster:

search-base-dn CN=Users,DC=Domain_Name,DC=com

Recommended Actions

  1. Please check the bind-dn and the search-base-dn, and narrow the search-base-dn scope based on the tree of the bind-dn.
