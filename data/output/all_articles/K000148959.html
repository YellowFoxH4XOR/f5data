K000148959: Unable to access website served with NGINX Plus using IP Address

Description

This article outlines the troubleshooting steps user experience from accessing the website using IP Address, while direct access via FQDN worked flawlessly.

  • When bypassing Azure App Gateway (directly accessing NGINX), the website was accessible using both IP and FQDN.
  • Internal users could access the website using both IP and FQDN, but external users can only access using FQDN.
  • Azure App Gateway returned an error indicating an incorrect or mismatched certificate configured on the backend server.
  • Root and intermediate certificates were not visible from the App Gateway.

 

Environment

  • NGINX Plus 
  • Azure App Gateway 
  • Akamai CDN

 

Cause

The fullchain certificate configured on the backend server (NGINX Plus) was invalid or incomplete. Specifically, the fullchain certificate:

  • Did not include the root certificate.
  • Was missing the intermediate certificate required for proper chain validation.

This caused Azure App Gateway to fail its SSL handshake, leading to the observed error.

 

Recommended Actions

The issue was resolved by generating a new, complete fullchain certificate that included:

  1. The server certificate.
  2. The intermediate certificate(s).
  3. The root certificate.

 

Additional Information

Regularly Verify Certificate Chain Completeness:

  • Before deploying certificates, validate the fullchain for completeness and correctness.
