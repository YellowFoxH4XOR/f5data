Known Issue

When you use the Traffic Management Shell (tmsh) to perform a task on certificates, the tab key may not function as you expect.

This issue occurs when all of the following conditions are met:

  • You use the tmsh utility to perform a task on a certificate (for example, list, show or install).
  • You use the tab key in such a way so the system displays available certificates or a specific certificate filename without you having to type out the filename in full.

Impact

As a result, using the tab completion function in the tmsh utility, you cannot select the certificate filename that you want.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you press the tab key in the tmsh utility, the tab completion function fails to display the available certificates on the BIG-IP system.

    The tmsh command and output may appear similar to the following example:

    list sys crypto cert <tab>

    Options:
    all |

    The expected output of the previous command should appear similar to the following example:

    Options:
    all |
    Properties:
    app-service {
    Configuration Items:
    ca-bundle.crt default.crt f5-irule.crt

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can manually type out the filename of the certificate that you want in the tmsh utility, without using the tab key.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
