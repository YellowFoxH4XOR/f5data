Known Issue

The BIG-IP Edge Client may unexpectedly disconnect from a network access session.

This issue occurs when a subset of the following condition is met:

  • You have an established network access session using the BIG-IP Edge Client and:
    • you manually initiate a connection on your local device to the access session tunnel server local loop back listener. For example, 127.0.0.1:44444.
    • the local device software attempts to probe the access session tunnel server local loop back listener.

Impact

The network access session disconnects.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice that the BIG-IP Edge Client network access session repeatedly disconnects and reconnects over the life of the session.
  • Connection state sensitive resources, such as RDP, Lync, or video streaming clients, unexpectedly stop responding.
