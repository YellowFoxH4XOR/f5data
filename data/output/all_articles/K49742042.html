Description

The BIG-IP system stores local user accounts (including user names, passwords, and user roles) in a local user-account database.

When a user logs into the BIG-IP system using one of these locally-stored accounts, the BIG-IP system checks the account to determine the user role assigned to that user account for each partition to which the user has access.

  • For example, you want to create a local user account that at least can generate QKView file to provide to F5 Support to aid in troubleshooting an issue 

Environment

  • BIG-IP
  • Local User Account 

Cause

None 

Recommended Actions

To perform this task, you must have the Administrator or User Manager user role assigned to your user account.
Note: If the user role assigned to your account is User Manager, you can only create a user account in the partitions to which you have access.

  • Configuration utility
  • tmsh shell

Configuration utility

To watch a video demo of this procedure, go to  Create a local user account on a BIG-IP system using the Configuration utility.

  1. Log in to the BIG-IP Configuration utility.
  2. Go to System > Users.
  3. From the Partition list in the upper-right corner of the page, set the current partition to the partition in which you want the user account to reside.
  4. Select Create.

    If the Create button is unavailable, you do not have permission to create a local user account. You must have the Administrator or User Manager role assigned to your user account in order to create a local user account.

  5. Provide the User Name.
  6. For Password, for New, enter a password for the user account.
  7. For Confirm, enter the password again.
  8. For Partition Access, for Role, select a user role.

    Note: Generating the QKView is only available for accounts with the Administrator or Resource Administrator user role.

  9. For Partition, select a partition name.
  10. Select Add

    A user role pertaining to a partition displays.

  11. If you want to allow user access to the command line interface, for Terminal Access, select a level of access.

    Note: The Advanced shell is only available for accounts with the Administrator or Resource Administrator user role.

  12. Select Finished.

tmsh shell

  1. Log in to tmsh by entering the following command:
    tmsh
  2. Optional: To set the current partition to the partition in which you want the user account to reside, enter the following:
    cd /<partition_name>
    For example:
    cd /example_part
  3. To create a new user, use the following command syntax:
    create /auth user <admin-user> partition-access add { <partition names> { role <role> } } prompt-for-password

    Note: <admin-user> is the name of the new administrative user account you want to create.

    For example, to create a user with the admin role with bash access, enter the following command:

    create /auth user newadmin partition-access add { all-partitions { role admin } } prompt-for-password shell bash

  4. At the password prompt, enter a password for this user.

Additional Information

When a local user with multiple roles logs in to the system, the system applies the most powerful of those roles to the user and sets the current partition to the partition associated with that role. This role remains in effect until the user changes the current partition or the user logs off the system.

For more details, refer to User roles.
