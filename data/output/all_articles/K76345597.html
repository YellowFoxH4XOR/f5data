Description
After upgrading the BIG-IP unit to software version 14.1.4.4, a webpage error of ERR_CONNECTION_RESET is received when accessing the APM Logon page.

This occurs when the database key "ipv6.enabled" is set to false.

Note: The "ipv6.enable" database key simply opens up the address space of the client to ipv6. 

Environment

  • BIG-IP APM
  • BIG-IP software version 14.1.4.4

Cause
This is due to ID 1044121.

Recommended Actions

There are two workarounds that can be either applied:

    Workaround 1
    1. Set the db sys "ipv6.enabled" to true; the procedure is in the following article:
    K15056: Disabling IPv6 on a BIG-IP system

      Workaround 2
      1. Set "listen [ip_addr tmm6] 8080" value of "_tmm_apm_portal_cache_vip" in /usr/lib/tmm/tmm_base.tcl from tmm6 to tmm as highligthed below.

        proxy TCP {
            listen [ip_addr tmm6] 8080 {   
                proto $ipproto(tcp)
                tap enable tmm0
                name "_tmm_apm_portal_cache_vip"
            }
            profile clientside /Common/apm-enduser-if-cache
            profile _tmm_apm_portal_http
            profile _tmm_apm_portal_tcp
            clientside TCP HTTP RAMCACHE
            serverside TCP HTTP
            use pool _tmm_firepass_renderer_pool
        }

        Note, in order to modify /usr/lib/tmm/tmm_base.tcl, first, make a file backup of this by running the following CLI command (bash shell):
            cp /usr/lib/tmm/tmm_base.tcl /usr/lib/tmm/tmm_base.tcl.backup

        Then set /usr to read-write by following the article below:

        K20330103: Mounting the /usr file system in read-write mode

        Afterward, revert the said file to read-only.
         
      2. Restart all BIG-IP services
      bigstart restart
