Description

When running tmsh command show sys service all it does not list all services i.e. httpd 

Environment

  • BIG-IP

Cause

  • It is by design, the tmsh will not list all items available for "sys service" component when you run tmsh show sys service all.

Recommended Actions

Add the service name to the bigstart process as it describe in the following article:
  • K4080: Adding and removing services included in the 'bigstart' process

Additional Information

You can add a service to Default group like httpd into bigstart  if needed, then it will be included in tmsh show sys service all like it shown below: 
# bigstart add --default httpd
# bigstart status | grep -i httpd
httpd (pid 4145) is running...
httpd_apm down, Not provisioned

# tmsh show sys service all | egrep http
httpd (pid 4145) is running...
httpd_apm down, Not provisioned
Note: For more information about bigstart, refer to the bigstart man page.
