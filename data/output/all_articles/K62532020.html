Known Issue

You are unable to load a configuration that has a Client SSL profile error.

This issue occurs when all of the following conditions are met:

  • The system is loading the configuration.
  • The configuration contains a Client SSL profile that has an RSA cert-key-chain whose key is the default (/Common/default.key), but the chain is non-empty or the cert is different from /Common/default.crt.

    For example:

        cert-key-chain {
            rsa {
                cert /Common/default.crt   <==== default cert
                chain /Common/chainCA.crt  <==== non-empty
                key /Common/default.key    <==== default key
            }
        }

Impact

You are unable to load the configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system fails to load the configuration and displays an error message similar to the following example:

    Client SSL profile cannot contain more than one set of same certificate/key type

Workaround

To work around this issue, you can remove or modify the problematic Client SSL profile from the bigip.conf configuration file (/config/bigip.conf or /config/partitions/<name>/bigip.conf, depending on the partition that the profile resides in), and then reload the configuration. To do so, perform the following procedure:

Impact of workaround: Syntax errors in the bigip.conf file can prevent the configuration from loading. Use care when editing configuration files on the BIG-IP system.

  1. Log in to the BIG-IP command line.
  2. To back up the bigip.conf file, type the following command:

    cp /config/bigip.conf /config/bigip.conf.K62532020

    If you are using a non-default partition, then backup the bigip.conf file using the following command syntax:

    cp /config/partitions/<partition name>/bigip.conf /config/partitions/<partition name>/bigip.conf.K62532020

    For example, if the partition name is myPartition, type the following command:

    cp /config/partitions/myPartition/bigip.conf /config/partitions/myPartition/bigip.conf.K62532020

  3. Edit the bigip.conf file using either the vi or pico text editor.
  4. Locate the affected Client SSL profile in the bigip.conf file. The first line of the Client SSL configuration section appears similar to the following example:

    ltm profile client-ssl /Common/myClientSSL {

    If the Client SSL profile is in a non-default partition, the first line of the Client SSL configuration section appears similar to the following example:

    ltm profile client-ssl /myPartition/myClientSSL {

  5. Locate the cert-key-chain section of the affected client SSL configuration and replace cert and key sections named default with the name of your actual cert and key pair. For example, if your actual cert and key pair are named mySite.crt and mySite.key, locate the following section:

        cert-key-chain {
            rsa {
                cert /Common/default.crt
                chain /Common/chainCA.crt
                key /Common/default.key
            }
        }

    And replace default with mySite:

        cert-key-chain {
            rsa {
                cert /Common/mySite.crt
                chain /Common/chainCA.crt
                key /Common/mySite.key
            }
        }

  6. Save your changes exit from the text editor.
  7. Load the configuration by typing the following command:

    tmsh load sys config

Note: You may choose to remove the entire section of the affected Client SSL profile from the bigip.conf file, but you will then need to be sure to remove that profile from any virtual servers which reference the profile, and then you will need to recreate this portion of your configuration after successfully loading the configuration.
