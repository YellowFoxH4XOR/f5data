Topic

To measure CPU utilization on the BIG-IP system, you can use the cpu bigip command. Traditional Unix utilities such as top, vmstat, and SNMP monitoring do not report all of the information necessary to measure CPU utilization on the BIG-IP system. As a result, you should not use the traditional Unix utilities for measuring CPU utilization on the BIG-IP system.

The cpu bigip command reports CPU utilization based on BIG-IP-specific instrumentation in the kernel. The kernel uses the high-resolution timer to measure the number of CPU cycles that are spent in each of the major code sections, and then the kernel averages the information over time.

The major code sections are as follows:

  • Idle (Idle)
  • Unix user space (Unix)
  • BIG-IP processing (BIGIP)
  • Network processing (NET)
  • Network device drivers (DV_NET)
  • Interrupts (INT)

To use the cpu bigip command, log in to the command line and type the following command:

cpu bigip

BIG-IP will display information similar to the following example:

             Idle   Unix   BIGIP   NET   DV_NET   INT
Current:      100%     0%     0%     0%     0%     0%
10-Sec Avg:   100%     0%     0%     0%     0%     0%
1-Min Avg:     99%     1%     0%     0%     0%     0%
5-Min Avg:     99%     0%     0%     0%     0%     0%
15-Min Avg:    94%     0%     0%     0%     0%     0%
Max BIGIP:      0%     0%     0%     0%     0%     0%
Max NET:        1%     1%     0%     3%     0%    26%
Max DV_NET:     0%     0%     0%     0%     0%     0%

The column and row definitions are as follows:

Idle

The CPU idle time. CPU idle time is the amount of processor time that is available for additional work. The higher the number, the higher the remaining capacity of the BIG-IP system.

Unix

The amount of CPU time dedicated to user space processes. User space processes are all processes other than the kernel.

BIGIP

The amount of CPU time used by the main traffic processing functions in the kernel.

NET

The amount of CPU time used by basic networking. This includes ARP. During an ARP storm or SYN flood, this value will increase significantly.

DV_NET

The amount of CPU time used by the network drivers. If this value significantly increases, it may indicate that a large number of illegal packets are being discarded by the network drivers.

INT

The amount of CPU time used for interrupt handling. If this value significantly increases, it may indicate a hardware problem.

ANIP

The amount of time the ANIP processor uses to receive and dispatch network traffic. Traffic using fastpath is also included. This column only appears on dual processor systems running in ANIP mode.

Note: The values listed in the Max BIGIP, Max NET, and Max DV_NET rows represent the values of Idle, Unix, BIGIP, NET, DV_NET, and INT when BIGIP, NET, and DV_NET were at their peak.

Max BIGIP

The Max BIGIP row lists the maximum values reached for each column, when the BIGIP column reached its peak. When BIGIP reached its highest value, the value for Idle, Unix, NET, DV_NET, and INT at that time will be listed in the Max BIGIP row. These values may be different than when NET or DV_NET reached thier highest values.

Max NET

The Max NET row lists the maximum values reached for each column, when the NET column reached its peak. When NET reached its highest value, the value for Idle, Unix, BIGIP, DV_NET, and INT at that time will be listed in the Max NET row. These values may be different than when BIGIP or DV_NET reached thier highest values.

Max DV_NET

The Max DV_NET row lists the maximum values reached for each column, when the DV_NET column reached its peak. When DV_NET reached its highest value, the value for Idle, Unix, BIGIP, NET and INT at that time will be listed in the Max DV_NET row. These values may be different than when BIGIP or NET reached their highest values.
