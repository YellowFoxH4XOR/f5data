Description

The client cannot access the resource in the APM access profile.
Error messages in the log /var/log/apm:
notice tmm[<PID>]: 01490517:5: /Common/<Access profile>:Common:<session id>: User-Agent header is absent or empty

Environment

  • BIG-IP APM
  • Virtual Server
  • Access profile
  • APM client, like VMware Horizon View Client

Cause

When the client send the HTTP request to the APM, the HTTP request did not contain the HTTP header "User-Agent", or the value is empty.

 Recommended Actions

  1. Investigate the client for this issue, fix it, maybe reinstall it, or upgrade it. 

Additional Information

On the client, run the curl command will trigger the log:

curl -kv https://<IP/FQDN of VPN virtual server>/ -H "User-Agent:"
