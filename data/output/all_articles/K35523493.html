Description

  • Error Message: "Config File Install Error on Device" displayed on big-IQ alert pannel with 15 minutes interval.
  • The alert is related with error message below on Big-IQ in /var/log/restjavad

[WARN][26 Aug 2020 12:46:58 HKT][/cm/asm/tasks/threat-campaigns/push-threat-campaigns/9ccb5b37-53e9-457d-9285-10d85aeaf5ce/worker PushThreatCampaignFilesTaskWorker] failed pushing config file to device https://localhost/mgmt/shared/resolver/device-groups/cm-asm-allAsmDevices/devices/7e32b195-191a-49f2-bc0c-1a5481eb810d, error message: status:400, body:{"code":200,"referer":"http://localhost:8100/cm/asm/tasks/threat-campaigns/push-threat-campaigns/9ccb5b37-53e9-457d-9285-10d85aeaf5ce/worker", "restOperationId": 195439042,"kind":":resterrorresponse"}. Task will continue

Environment

Relevant environmental factors specific to the topic

  • BIG-IQ Centralized Management

  • BIG-IP ASM 

  • Signature 

Cause

BIG-IP ASM  signature autoupdate failure
Recommended Actions

Refer the solution below for fix 

K21061529: Cannot upload ASM signature file after applying patch set 14.1.x

If just want to cease the alert without trying the above fix solution, please follow the below workaround

  1. login BIG-IQ Configuration Utility, at the top of the screen, click Monitoring.

  2. On the left, click ALERTS & NOTIFICATIONS.

  3. At the top of the screen, click the Settings button.

  4. Uncheck "Config File Install Error", then the alerts will be ceased

  5. Click the Save & Close button.
