K53074081: BIG-IQ CM tasks with AFM firewall rule update fails. ConfigSync status unexpectedly shows Changes Pending state after a previous task completes

Source

Description
You may observe intermittent BIG-IP AFM network firewall policy update failures. Subsequent BIG-IQ Centralized Management tasks with BIG-IP AFM firewall rule updates fail when ConfigSync status unexpectedly shows Changes Pending state after a previous BIG-IQ task completes. A pccd core file is generated. You may notice that after syncing the device group and trying the BIG-IQ job, it succeeds as expected.

Environment

  • BIG-IQ Centralized Management
  • BIG-IP AFM version 13.1.x or 14.x
  • Device group uses manual synchronization for HA pair

Cause
Bug ID 761345: Additional config-sync may be required after blob compilation on a HA setup in manual config-sync mode

Recommended Actions

  • Upgrade to a version which is listed as fixed in the BugTracker article.
  • To work around this issue, you can enable automatic synchronization on the sync-failover device group
