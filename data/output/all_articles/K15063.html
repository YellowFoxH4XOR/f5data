Known Issue

The Wide IP properties page of the BIG-IP Link Controller Configuration utility is missing input controls to enable/disable the Wide IP, and to enable/disable the IPv6 NoError Response setting for the Wide IP.

Impact

  • The Wide IP properties page, in the BIG-IP Link Controller Configuration utility, does not allow users to enable or disable a Wide IP, or to enable or disable the IPv6 NoError Response setting.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Wide IP properties page does not display check boxes to enable or disable the Wide IP.
  • The Wide IP properties page does not display check boxes to enable or disable the IPv6 NoError Response setting.

Workaround

To work around this issue, you can enable or disable the Wide IP from the Input Wide IPs List page or by using the Traffic Management Shell (tmsh), and you can enable or disable the IPv6 NoError Response setting by using the tmsh utility. To do so, perform the following procedures as needed:

Using the Configuration utility to enable or disable the Wide IP

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Link Controller Configuration utility.
  2. Navigate to Link Controller > Inbound Wide IPs.
  3. Select the check box for the Wide IP to be enabled or disabled.
  4. Click the Enable or Disable button.

Using the tmsh utility to enable or disable the Wide IP

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Enable or disable a Wide IP using the following tmsh command syntax:

    modify gtm wideip <wideip_name> <enabled/disabled>

    Where <wideip_name> is the name of the Wide IP you want to enable or disable.
    Where <enabled/disabled> is enabled or disabled.
  3. Save the change by typing the following command:

    save /sys config

Using the tmsh utility to enable or disable the IPv6 NoError Response setting

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Enable or disable the IPv6 NoError Response setting for a Wide IP using the following tmsh command syntax:

    modify gtm wideip <wideip_name> ipv6-no-error-response <enabled/disabled>

    Where <wideip_name> is the name of the Wide IP you want to modify.
    Where <enabled/disabled> is enabled or disabled.
  3. Save the change by typing the following command:

    save /sys config
