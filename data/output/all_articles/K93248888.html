Description

Config Sync showing Changes Pending after License Reactivation

Environment

  • BIG-IP

Cause

During license reactivation, traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. Config Sync status will move to Changes Pending if the device is a part of an HA pair and Manual Sync is configured in a Device Group. This Changes Pending state appears because the BIG-IP reloads the configuration during license reactivation

Recommended Actions

  1. After completion of license reactivation on both the devices in HA pair, manually sync the config between devices.

Additional Information
Please ensure that both devices in HA pair are In-Sync before License reactivation. If not, then ensure to Sync the last working active device to another one.
