Description

A long TLS transfer through a Virtual Server terminates with a RST. When examining the SSL traffic with a traffic capture on the client side shows the RST with the cause of "SSL Peer renegotiate timeout exceeded" and no SSL renegotiation is seen in the capture.
 

Environment

  • Standard Virtual Server
  • ClientSSL
  • ServerSSL
  • TLS 1

Cause
The BIGIP server side ignores the "Hello Requests" and forwards them to the client, and does not track the forwarded "Hello Requests".
 

Recommended Actions

Modify the ServerSSL profile to use TLS 1.2
