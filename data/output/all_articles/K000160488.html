K000160488: Enforcer errors: Protobuf message exceeds max defined size

Type
Support Solution
Published
2026-03-27
Updated
2026-03-27
Applies to
  • NGINX Products
  • F5 WAF for NGINX
Source
https://my.f5.com/manage/s/article/K000160488

Description

When using Docker to set up F5 NGINX App Protect (NAP), you may occasionally encounter the following error message when running "sudo docker logs <NAP_container_name>"

{
  "completed_successfully": false,
  "event": "configuration_load_failure",
  "error_message": "Enforcer errors: Protobuf message exceeds max defined size. Size: 1701016623, Table: CONFIG_TYPE_MANIFEST.\nfailed to read dynamic data from file"
} 

Environment

F5 WAF for NGINX
Docker

Cause

There is a mismatch between policy.json and compiled_policy.tgz.

Recommended Actions

Ensure that policy.json and compiled_policy.tgz are located in the same directory and are matching. 

 

Additional Information

None.
