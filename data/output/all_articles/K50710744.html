Known Issue

Using the Traffic Management shell (tmsh) to load the configuration from the terminal or from a file fails when an object references an external file.

This issue occurs when the following condition is met:

  • You run the command load /sys config <merge> from-terminal or tmsh load /sys config <merge> file <file_name> to load a configuration with an object that references a file external to the configuration.

    Note: You can use from-terminal only within the tmsh shell.

The BIG-IP system uses the system file object within the configuration to reference external files. External monitors, iFiles, SSL certificates, and data groups are examples of external files that can be referenced in the configuration.

Impact

Users cannot use tmsh to load configuration objects that reference external files.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H611564 on the Diagnostics > Identified > Medium screen.
  • When you load the configuration, you receive an error message similar to the following example:

    01070712:3: Failed: name (/Common/external_file_example) cache path expected to be non empty.

Workaround

To work around this issue, you can use the create global tmsh command or, when performing a migration, manually add configuration stanzas to the system configuration files to create system file objects. To do so, perform one of the following procedures:

Use the create global tmsh command to create system file objects

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Copy the external file to the BIG-IP system. For more information, refer to K175: Transferring files to or from an F5 system.
  3. To create the system file object that references the file you used in step 2, use the following command syntax:

    create sys file <file_type> <object_name> source-path file:///<path/to/file>

    For example:

    create sys file external-monitor example source-path file:///config/example-file

  4. If necessary, repeat steps 2 and 3 for additional system file objects.
  5. Save the configuration change by typing the following command:

    tmsh save sys config

  6. To exit the tmsh utility, type q and press Enter.

Manually edit the system configuration to create system file objects

Important: F5 recommends that you perform this workaround only if you have encountered the issue when migrating a configuration to another system and the external files have already been installed into the filestore of the target system.

Impact of workaround: Performing a configuration reload on an active device group member may cause a service disruption of the device. F5 recommends that you perform this procedure during a scheduled maintenance period.

  1. Log in to the BIG-IP command line.
  2. Determine if you need to edit /config/bigip.conf or /config/bigip_base.conf based on the source system's configuration.
  3. Before you edit the /config/bigip.conf or /config/bigip_base.conf file, perform a backup of the existing copy by using the following command syntax:

    cp -a /config/<bigip.conf or bigip_base.conf> /config/<bigip.conf or bigip_base.conf>_sol50710744_backup

    For example:

    cp -a /config/bigip.conf /config/bigip.conf_sol50710744_backup

  4. Using your preferred text editor, load the /config/bigip.conf or /config/bigip_base.conf file for editing.
  5. Copy the system file object stanza from the source system to the target system's configuration file you have opened to edit. The object stanza will appear similar to the following example: 
    
sys file ssl-key /Common/example.key {
    cache-path /config/filestore/files_d/Common_d/certificate_key_d/:Common:example.key_75317_1
    revision 1
}
  6. If necessary, repeat step 5 for additional system file objects.
  7. When you have finished editing the /config/bigip.conf or /config/bigip_base.conf file, save the changes and exit the text editor.
  8. Manually load the configuration by typing the following command:

    tmsh load sys config
