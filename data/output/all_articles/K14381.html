Topic

Summary

Beginning in BIG-IP 11.4.0, HTTP Class iRule events and commands are no longer available.

Description

With the introduction of the Local Traffic Policies feature in BIG-IP 11.4.0, the HTTP Class iRule events and commands have been replaced. If you plan to upgrade to BIG-IP 11.4.0, and your configuration contains an iRule that uses an HTTP Class iRule event or command, refer to the Recommendations section.

If you attempt to upgrade to BIG-IP 11.4.0, or restore an earlier user configuration set (UCS) on an 11.4.0 system, the operation fails with an error message that appears similar to the following example:

HTTP Class iRule events and commands are no longer available

Recommendations

Before you upgrade to BIG-IP 11.4.0, perform the following tasks:

  • Determine if your iRule uses HTTP Class events or commands.
  • Save the iRules to a safe location.
  • Delete the affected iRules from the pre-11.4.0 configuration.
  • Perform the upgrade to BIG-IP 11.4.0.
  • Modify the iRules using the following table.

Note: Changing the design of an iRule may have additional effects on traffic processing. Ensure any modification is compatible with your environment.

Events

BIG-IP 11.3.0 and earlier versions
BIG-IP 11.4.0
when HTTP_CLASS_SELECTED {
    …
}		when HTTP_REQUEST {
     if {[llength [POLICY::names matched]] > 0} {
         …
     }
}
when HTTP_CLASS_FAILED {
    …
}		when HTTP_REQUEST {
     if {[llength [POLICY::names matched]] == 0} {
         …
     }
}

Commands

BIG-IP 11.3.0 and earlier versions
BIG-IP 11.4.0
do_something_with [HTTP::class]
foreach policy [POLICY::names matched] {
    do_something_with [POLICY::rules matched $policy]
}
HTTP::class select <name>
No equivalent.
HTTP::class enable/disableNo equivalent.
HTTP::class wa/asm
No equivalent.
PROFILE::httpclass <setting_name>No equivalent.
