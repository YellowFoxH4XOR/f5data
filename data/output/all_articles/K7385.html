Known Issue

This is the result of a known issue. Connections to an RTSP virtual server causes a memory leak in the connflow cache subsystem. The connflow cache subsystem represents traffic flow contained in the Flow table. One indication of a memory leak is the amount of memory that the connflow cache uses continues to grow. To view the connflow cache, use the b memory command.

F5 Networks Product Development tracked this issue as CR77437 and it was fixed in BIG-IP LTM versions 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
