Description

Beginning in 11.0.0, the value of Maximum Header Count is now set to a default value of 64. The minimum and maximum values are 16 and 4096. 
If the application server requires header size larger than 64 headers, you may notice an error message similar to 

011f0011:3: HTTP header count exceeded the maximum allowed count of 64 
 

Environment

  • HTTP Profiles 
  • HTTP Headers


Cause

If the header count exceeds the header limit, the connection is reset.  


Recommended Actions

You may perform the following procedure if the applications require header count greater than 64, you can increase the Maximum Header Count in the HTTP profile. 

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to Local Traffic > Profiles > Services > HTTP.
  3. Select the HTTP profile that handles your affected traffic.
  4. Change the Maximum Header Count to a higher value, such as 128.
  5. Click Update.

All new connections now use the new configuration.
 

Additional Information

Maximum Header Count adds the ability to restrict the total number of headers and potentially helps to mitigate attack attempts that send extremely large headers to exhaust memory resources on HTTP servers.
