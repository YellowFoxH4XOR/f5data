K000136200: The F5 Units will not sync, after SSLO modifications

Type
Support Solution
Published
2023-09-14
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136200

Description

Recent changes to SSLO topology caused BIG-IP HA sync to break.

Environment

  • BIG-IP SSLO v16.1.3
  • SSLO Topology
  • Firewall Rule

Cause

There was a conflicting Virtual server in the bigip_base.conf holding on to a firewall rule that still referenced a virtual server by name that was originally from an SSLO topology.

Recommended Actions

Delete the offending Firewall rule in the bigip_base.conf that was referencing the virtual server that was removed via the SSLO topology.
