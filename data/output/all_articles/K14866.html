Known Issue

When the BIG-IP system uses a Request Adapt or Response Adapt profile, Traffic Management Microkernel (TMM) memory usage may steadily increase over time.

This issue occurs when all of the following conditions are met:

  • You associate the Request Adapt or Response Adapt profiles with a virtual server.
  • The Request Adapt or Response Adapt profile is not associated with an internal virtual server.

Impact

TMM memory usage continuously increases over time, and causes the BIG-IP system to reboot.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice a progressive increase in TMM memory usage.
  • Memory exhaustion causes the system to fail over to another system in the device group.

Resolution

Status

F5 Product Development has assigned ID 430091 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, do not associate a Response Adapt or Request Adapt profile to a virtual server unless you have associated a corresponding internal server with the profile.
