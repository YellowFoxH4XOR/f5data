K45203048: How to configure an iRule that uses UTF-8 character encoding to log messages

Type
Knowledge
Published
2017-09-27
Updated
2025-04-03
Applies to
  • BIG-IP
  • BIG-IP LTM
Source

Topic

You should consider using this procedure under the following condition:

  • You want the iRule log command to use UTF-8 character encoding when generating log messages.

Description

The iRule log command supports UTF-8 character encoding, which allows you to log messages with characters from numerous languages. To avoid iRule validation issues and a limitation with the Configuration utility, F5 recommends that the log command reference the UTF-8 characters using a data group.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have access to the BIG-IP Configuration utility.
  • Use a text editor that supports UTF-8 character encoding to create an external data group file.

Procedures

Create a data group with an external file

In this procedure you create an External File type data group and import a file with UTF-8 character encoding, which the data group will reference.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. On your workstation, create a file formatted for use as a data group with the UTF-8 characters you want in the iRule log command. The contents may look similar to the following example:

    "example1" := "?????",

  2. Log in to the BIG-IP Configuration utility.
  3. Navigate to Local Traffic > iRules > Data Group List.
  4. Click Create.
  5. In the Name box, type a name for the data group.
  6. From the Type menu, select (External File).

    A Records section appears below.

  7. In the Records section for File Name, click Import.

    This automatically directs you to the System > File Management > Import screen.

  8. For File Name, click Choose File.
  9. Select the file you created in step 1.
  10. Next to Name, ensure that Create New is selected (for BIG-IP 13.x and later) and type a name for the data group file in the adjoining box.
  11. From the File Contents menu select String.
  12. If necessary, update the Key / Value Pair Separator box to match the separator you used in the external file.
  13. Ensure that the data group name you entered in step 5 is pre-populated in the Data Group Name box.
  14. Click Import.

    The procedure should result in a new data group and data group file.

Create an iRule that logs messages in UTF-8 character encoding

Using the log command, create an iRule that references the data group.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Local Traffic > iRules
  3. Click Create.
  4. In the Name box, type a name for the iRule.
  5. In the Definition box, enter an iRule that references the data group that you created in the previous procedure to log messages.

    For example, the following iRule references the first line in the data group, utf8_example:

    when HTTP_REQUEST {
            log local0. "Here are some example UTF-8 characters: [class element -value 0 utf8_example]"
    }

    The example iRule would log the following:

    info tmm2[16792]: Rule /Common/utf8_example_rule <HTTP_REQUEST>: Here are some example UTF-8 characters: ?????

  6. Click Finished.
  7. Apply the iRule to one or more virtual servers.
