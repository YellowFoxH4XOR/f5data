K9811: BIG-IP ASM may not mark all of the Illegal MetaCharacters within the Learning page

Topic

When BIG-IP ASM receives a request that triggers the Illegal MetaCharacter in Parameter Value violation, BIG-IP ASM places a red bracket on the Policy Builder/Traffic Learning page of the illegal metacharacter which triggered the violation.

If the illegal metacharacter is within a large request, BIG-IP ASM may not mark the illegal metacharacter on the Policy Builder/Traffic Learning page; this is expected behavior due to parameter display limits within the Configuration utility.

The Configuration utility parameter display limits are as follows:

Note: The parameter display limits are not configurable.

  • 255 bytes for displaying parameter name
  • 1024 byets for diplaying parameter value

If the illegal metacharacter is not within the limits, it may not be highlighted on the Policy Builder/Traffic Learning page.

Note: The metacharacters will display properly if MetaCharacter is selected in the View by menu.
