Description

When loading a UCS archive on a VCMP guest where the default management gateway is defined, if the UCS archive has a default management gateway defined, but with a different name, the UCS archive load will fail with the error message:

 

May 20 14:05:45 slot1/vcmpguest.localhost err mcpd[7207]: 01070734:3: Configuration error: invalid Management Route, the dest/netmask pair 0.0.0.0/0.0.0.0 already exists for /Common/default

Environment

  • VCMP guest
  • Current configuration contains a default gateway management IP
  • UCS archive has a default management gateway configured, but with a different name.

Cause

ID1596493

Recommended Actions

To work around this issue, one of next options:

  1. Delete the existing default management route, then recreate it using the same name as specified in the UCS archive, then run 'tmsh load sys config'.
  2. Create the guest with no default management route from the GUI
