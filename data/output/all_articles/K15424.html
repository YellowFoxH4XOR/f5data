Known Issue

Uploading files larger than 64 KB may fail using BIG-IP APM portal access.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is providing portal access to web applications
  • Users attempt to upload a file larger than 64 KB to a portal access resource

Uploading files larger than 64 KB to web applications may occasionally fail when using BIG-IP APM portal access. This issue may include, but is not limited to, sending emails with attachments when using Outlook Web Access (OWA) or uploading files to SharePoint. Network latency affecting responses to DNS queries may increase the frequency of the issue.

Impact

Users are unable to upload files to portal access resources using the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Web applications accessed with BIG-IP APM portal access stall when uploading files
  • The system generates messages to the /var/log/apm file that appear similar to the following example:

    tmm1 err tmm1[14614]: 01490514:3: 00000000: Access encountered error: ERR_NOT_SUPPORTED. File: ../modules/hudfilter/access/access.c, Function: hud_access_process_ingress, Line: 2097

Workaround

You may be able to mitigate this issue by configuring the DNS Cache feature in the BIG-IP system. To do so, follow the instructions in the BIG-IP DNS Cache: Implementations guide for your version.
