Environment

  • BIG-IP
  • SRX1500 (Juniper) device

Cause

The configurations on the end point is not identical to the BIG-IP's settings.  The BIG-IP is configured to use IKE version2 while the other IKE peer is configured to version1:

net ipsec ike-peer /Common/Customer_ORACLE_Peer_Prim {
    description "HUB to Oracle IKE Peer"
    my-id-type address
    my-id-value 10.0.0.82
    peers-id-type address
    peers-id-value 172.16.0.60
    phase1-auth-method pre-shared-key
    phase1-encrypt-algorithm aes256
    phase1-hash-algorithm sha256
    phase1-perfect-forward-secrecy modp1536
    preshared-key-encrypted $M$Z4$ZB08wF08+tR3b5uR1DdnxHl5jmo/UcIE++dGUwfTmLQ=
    prf sha256
    remote-address 172.16.0.60
    traffic-selector { /Common/Customer_ORACLE_GW_INTEG /Common/Customer_ORACLE_GW_INTEG_1 /Common/Customer_ORACLE_GW_INTEG_2 /Common/Customer_ORACLE_GW_INTEG_4 /Common/Customer_ORACLE_GW_INTEG_5 /Common/Customer_ORACLE_GW_INTEG_6 }
    version { v2 }      <<<< IKE version 2
}

Recommended Actions

Correct the IKE version to be identical on both IKE ends
  1. To correct IKE version on Bigip:
On GUI:
  1. Click on Network  ››  IPsec : IKE Peers  ›› <IKE Peer settings>
  2. General Properties ›› Version and update with the correct IKE version
