Issue

Error Message

err iControlPortal.cgi<PID>: icontrol_portal:Error waiting for MCP

In this error message, note the following:

  • <PID> is the process ID for iControlPortal.cgi process.

For example:

err iControlPortal.cgi[28332]: icontrol_portal:Error waiting for MCP

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The iControl portal is unable to establish a connection to the MCP process due to high CPU utilization.

Impact

You are unable to access BIG-IP iControl portal.

Recommended Actions

There is no workaround. However, you can run bigstart restart command if you are having issues accessing iControl portal on the BIG-IP-managed device. To do so, perform the following procedure:

Impact of procedure: The bigstart restart command temporarily interrupts traffic processing. If the system is configured as part of a HA pair, the device may fail over. F5 recommends that you perform this procedure during a scheduled maintenance window.
  1. Log in to the BIG-IP command line
  2. To restart all BIG-IP services, type the following command:

    bigstart restart
