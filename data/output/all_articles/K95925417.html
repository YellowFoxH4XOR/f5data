Impact

You cannot establish VPN access to the BIG-IP APM system.

    Recommended Actions

    When troubleshooting BIG-IP Edge Client connection issues, you should consider the following factors:

    • Examine the client side logs on the user interface together with the appropriate server-side log files. For more information about the location of the client log files, refer to K00819308: Gathering F5 VPN client logs.
    • As a BIG-IP APM administrator, you should use the APM session ID obtained from the client side to analyze the /var/log/apm file on the BIG-IP system.
