Known Issue

The BIG-IP ASM bd process may produce a core file when the XML processing engine attempts to allocate additional memory.

This issue occurs when the following condition is met:

  • The XML processing engine attempts to use more memory than the amount that has been allocated to the engine.

Impact

The BIG-IP ASM bd process restarts, and BIG-IP ASM fails to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system logs messages to the /var/log/bd.log file that appear similar to the following example:

    BD_XML|ERR |Apr 09 12:14:11.680|10624|xml_validation.cpp:0241|Cannot allocate 6439 more bytes for XML parser. current memory size 471859194 (in bytes)

  • The system writes a core file to the /var/core directory.
