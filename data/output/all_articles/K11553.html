Known Issue

This is the result of a known issue. When a BIG-IP WebAccelerator-enabled virtual server to which an NTLM profile has been applied receives a request for a PDF file, the PDF file cannot be displayed in the browser. The pvac process initially responds to the request with an HTTP response status code 206 (Partial Content) and the first piece of the multipart message body, then later sends an HTTP response status code 503 (Service Unavailable). If the browser receives the 503 status response before the final part has been received, the browser cannot render the requested file, and may hang. 

F5 Product Development tracked this issue as CR137600 and it was fixed in version 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
