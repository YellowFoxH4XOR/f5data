Description

While activating a license key or an Add-on key on the BIG-IP device, you may observe an error if there is an issue. Typically, the error will include a resulting error code, and/or related text indicating the problem encountered when activating the key.

Environment

  • BIG-IP
  • License Key or Add-on key

Cause

None

Recommended Actions

You may want to refer to the following table for specific license-related error codes and the individual error code-linked articles for more information.

Related article(s)

50063

Invalid length of the Dossier

This dossier cannot be decrypted. The Dossier length must be evenly divisible by 512. The most common cause of this error is the dossier being incorrectly cut-and-pasted into the manual license page.

K000149836: Error 50063 This dossier cannot be decrypted. The Dossier length must be evenly divisible by 512

51071

Invalid Dossier

The dossier is blank.

K44130001: Error: 51071 - Invalid Dossier

51072

Invalid Dossier - Registration Key sent instead of a Dossier

A valid dossier contains only hexadecimal characters; A-F and 0-9. What appears to be sent in is a String , not the expected dossier. The dossier that entered was not actually the dossier but a text string containing the Base Registration Key.

K000150256: 51072 Invalid Dossier - Registration key sent instead of a Dossier

51074

Invalid Dossier - Contains non-Hexadecimal characters

A valid dossier contains only hexadecimal characters; A-F and 0-9. This dossier contains non-hexadecimal characters, please double check your dossier for a typo or cut and paste type error. Historically, we have seen email, notes requesting licenses, Auth3 files, V5A licenses, private keys, public keys, and the HTML source to the manual activation page.

K70385521: Licensing Error 51074: Invalid Dossier - Contains non-Hexadecimal characters

51075

Invalid Dossier - Unable to decrypt

The inbound dossier cannot be decrypted by the F5 Licensing server. Please double check your dossier. The dossier cannot be decrypted using the F5 private key. This would indicate that either the dossier was produced using a non-F5 public key, or the dossier is corrupt.

K98832408: Licensing Error Message: 51075: Invalid Dossier - Unable to decrypt

51076

Multiple Active Base Keys present in the Dossier

More than one base registration key is contained in the Dossier. There should be only one registration key per activation request. Depending on your BIG-IP version, entering the base registration key in the incorrect field, for example the Add-On Registration Key field, may result in this error.

K10547: Attempting to activate a license by using an incorrect registration key generates a licensing error

51078

Incompatible Products and Add-ons

Keys are not valid for this Product Name Platform Module The detected platform is not in the same product family as either the Base Registration Key or Add-ons found in the dossier. A BIG-IP base or add-on key can only be used on a BIG-IP platform.
  • K000092895: Licensing Error: Error 51078, Incompatible Products and Add-ons - Keys are not valid for this BIG-IQ platform : XXXXXXX-YYYYYYY(BIG-IP) When reactivating BIG-IP FCP license via the BIG-IP command line
  • K56534070: Error Message: Unable to grant license key: Error 51078 License error Incompatible Products and Add-on keys

51079

Invalid Base Registration Key - Retired status

Activation attempt against retired keys The Base Registration Key(s) in the dossier are of a "retired" status and cannot be used for activating a license. A "retired" key has been intentionally disabled by F5 Networks.

K18795805: Licensing Error 51079: Invalid Base Registration Key - Retired status

51080

Invalid Base Registration Key - Unknown Key

The key passed in the dossier cannot be found in the database. Like Error 51083, this is usually this is caused by a mistyped key value, but in this case the license server cannot match the value to any known key.
  • K30088240: Error Message: 51080: Invalid Base Registration Key - Unknown Key
  • K95506031: License server has returned an exception. Fault code: 51080

51081

Previous Activation Dossier cannot be decrypted

When a reactivation request is processed against a license that is set to active, the original dossier that was activated against is used internally to check for locking issues. If this stored dossier cannot be decrypted, this error is raised. This error should only happen if an attempt by the client of a CCN (closed circuit network) produced license happens. CCN systems should not be re-licensed through this process. If this is not a CCN appliance, this can be resolved simply by doing an "Allow Move" on the Registration Key to let the dossier get reset to a decryptable valid one.

K80571722: Error 51081: Previous Activation Dossier cannot be decrypted - The stored dossier cannot be decrypted

51085

Invalid Base Registration Key - No Base Registration Key in the Dossier

No valid base registraion key is found in the dossier. The dossier contains naught but Add-On keys. For a license to be processed, a valid Base Registration Key is required. An Add-On key for BIG-IP is of the pattern: ABCDEFGH-IJKLMNO. A Base Registration Key for BIG-IP is of the pattern: ABCDE-FGHIJ-KLMNO-PQRST-UVWXYZA.

K37052031: Error Message: 51085: Invalid Base Registration Key - No Base Registration Key in the Dossier

51086

Add-on Module Key is not a valid option for the Base Registration Key

Product "Product Name" does not allow the Add-On modules to be included. The Add-on module does not appear as a valid option in the Bill of Materials for the product, and thus cannot be added to the license.
  • K11546573: Error Message: Error 51086, Add-on Module Key is not a valid option for the Base Registration Key
  • K72285347: Unable to provision Add-On key to BIG-IQ under FCP license with error: Unable to grant license key: Error 51086, Add-on Module Key is not a valid option for the Base Registration Key
  • K000136950: FCP Hardware, when activating additional add-on license keys "Unable to grant license key: Error 51086, Add-on Module Key is not a valid option for the Base Registration Key"
  • K11615481: Guideline on purchasing Add-on licenses when the initial Base Registration Key has been upgraded to a higher throughput
  • K33012223: SDN Services feature is enabled by default on iSeries and rSeries platform

51087

Add-on Module Key - Module is explicitly Excluded for this Base Registration Key

Module explicitly excluded from the platform. One of the Add-on modules is incompatible with either the base key or another Add-on. The conflicting module must be removed from the active module list.

K000148460: Error 51087: Add-on Module Key Module is explicitly Excluded for this Base Registration Key

51088

System time differs from the F5 License Server by greater than 24 hours

The timestamp of the dossier, which is based of the F5 Appliance's system clock, should be within 24 hours of F5 License Server Time . The F5 Appliance's system clock is off by X hours. The internal time stamp in the dossier differs from the time on the license server (NIST GMT +8) by more than 24 hours. F5 Networks requires that the system clock of the customer's appliance being activated be set correctly before licensing it. Do not change the system time after licensing the appliance! Please refer to the proper product documentation to read further on this matter.

K000138224: Error 51088: System time differs from the F5 License Server by greater than 24 hours

51091

The system platform is either unrecognized or is not a valid version for the identified platform
  • The product name contained in the dossier, is not in the list of supported F5 products. The detected product name is not supported.
  • The product's version contained in the dossier cannot be located This means that the "version" tag in the dossier is either incorrectly formatted or missing. The correct format for the "version" should be "product" "version" "build".
  • This product version, is not supported for this platform. The license server has correctly identified the platform and version, but the platform has not been released for the version of the detected software.
  • This dossier is reporting an invalid system identifier value. This may be due to an incompatibility with the hardware and the software.
  • The license server was not able to determine the appliance's platform from the dossier.

K80704621: Error 51091: The system platform is either unrecognized or is not a valid version for the identified platform - The license server was not able to determine the appliance's platform from the dossier.

51092

This license has already been activated on a different unit. Please contact technical support for assistance

The locking data in the dossier does not match the system configuration that was detected at time of activation. Either a new component has been added or removed, or the registration key is being used to reactivate a different appliance.

K36582218: Error 51092: This license has already been activated on a different unit

51093

Minimum locking information is missing from the Dossier

The dossier does not contain the minimum set of locking data in which to produce a license. This generally means that either the dossier is missing sections, or the F5 product cannot read the system configuration of the hardware it is being installed on.

K000139313: Error 51093, Minimum locking information is missing from the Dossier

51109

No active Base Modules found

No active Base Modules found. The inbound dossier need to have at least one base add-on module (not to be confused with the base product registration key) set to active. A base module is a module that defines a product, like LTM, as opposed to SSL. Any module can be deactivated, but there must be at least one base module set to active.

K55534720: Error code: 51109 There are no active Base Modules There must be at least one active Base Add-On

51113

Non-Eval Add-on trying to be licensed on an Eval Base License

Time-limited keys incompatibility. A non-time limited add-on module key cannot be used on a time limited license key. Evaluation base products cannot use a non-evaluation add-on key because an add-on key is locked to the parent base registration key. As a result, when the time runs out on the evaluation system, the paid permanent add-on key can no longer be used.

K08474582: Error 51113: Non-Eval Add-on trying to be licensed on an Eval Base License

51133

Invalid Registration Key for the Platform Detected

The F5 Registration key provided is not compatible with the platform detected. The detected platform cannot be activated with this registration key.

51134

F5 registration key is not compatible with the detected version - This software version, "y.y.y" cannot be activated with this registration key "xxxxxxx-xxxxxxx"

The F5 registration key provided is not compatible with the version detected. This usually happens when you attempt to activate a BIG-IP version that is later than what you are licensed for.

K63265242: Error Message: 51134, F5 registration key is not compatible with the detected version - This software version, ''y.y.y'' cannot be activated with this registration key ''xxxxxxx-xxxxxxx''

51136

F5 registration key is not compatible with the detected version

The F5 registration key provided is not compatible with the version detected. Certain licenses are version locked in such a way that they can only be used on a specific version, or between version X and version Y. If you receive this error, the device is running a version that is not compatible with the license.

K38252110: Error 51136, F5 registration key is not compatible with the detected version

51138

This dossier cannot be decrypted.

This dossier cannot be decrypted. The Dossier length must be evenly divisible by 512. The inbound dossier length is 13200, when divided by 512 this leaves a remainder of 4. 

K43451231: Unable to grant license key: Error 51138

51139

A valid dossier contains only hexadecimal characters; A-F and 0-9

A valid dossier contains only hexadecimal characters; A-F and 0-9. What appears to be sent in is a F5 Registration Key, not the expected dossier.

K000141177: Unable to grant license key: Error 51139
