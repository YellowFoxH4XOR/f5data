K7674: Disabling WebAccelerator compression to allow iRules to alter HTTP data

Topic

You must disable compression for the WebAccelerator system if you want to allow BIG-IP LTM iRules to alter HTTP data.

To disable compression on the WebAccelerator system, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click WebAccelerator.
  3. Click Policies.

    A new WebAccelerator configuration window opens.

    Note: You cannot edit predefined policies. If the accelerated application uses a predefined policy, you must first copy the policy to create a custom policy, then associate the custom policy with the application.
  4. Click the Edit link for the policy that is being accelerated.

    A new WebAccelerator Policy Editor window opens.
  5. Click the Assembly tab.
  6. On the navigation tree, click Site.
  7. From the Content Assembly Options section, clear the Compress contents check box.
  8. Click Save.
  9. Click the Publish link.
  10. Click Publish.
  11. Click the Close Editor link.

    The WebAccelerator Policy Editor window closes.
  12. From the WebAccelerator configuration window, click Invalidate Content.
  13. Select the check box for the desired application.
  14. Click Invalidate.

Accelerated data will no longer be compressed, and the iRules will be able to alter the HTTP data as required.
