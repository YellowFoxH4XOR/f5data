Known Issue

This is the result of a known issue. When a user accesses a Web Application Tunnel favorite, pressing the backspace key or an arrow key on the keyboard may cause the keystroke to be sent twice to the browser. This issue occurs when the Locked Browser option is enabled for the Web Application Tunnel.

F5 Product Development tracked this issue as CR118184 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally this issue has been fixed in cumulative hotfix HF-603-2.1, which has been issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround
 
You can work around this issue by clearing the Locked Browser check box in the Web Application Tunnel configuration. However, clearing this check box will enable full browser functionality for the Web Application Tunnel.
 
Note: Web Application Tunnels are configured on the Application Access > App Tunnels > Resources page under the Web Application Tunnels tab. For more information about the Locked Browser option, refer to the FirePass Controller Administrator Guide.
