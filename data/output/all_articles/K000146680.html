Description

  • You want to disable an origin server during a maintenance with minimal traffic disruption

Environment

  • F5 Distributed Cloud HTTP Load Balancer

Cause

None

Answer/Recommended Actions

F5 Distributed Cloud provides a way to select specific origin servers in an origin pool to forward traffic to using a  label selector and the Origin Server Subset feature. This is useful in case we need to disable an Origin Server for maintenance.

 

Create Labels and configure Origin Server subset

  • Create a Known Key and assign two values that reflect the Origin Server status (e.g. Enabled, Disabled or Online, Offline):
    • Home > Shared Configuration > Manage > Labels > Known Keys > Add Known Key.
  •  

    • This is the Known Key created:

These are the associated Known Labels: Home > Shared Configuration > Manage > Labels > Known Labels

  • Edit the Origin Pool configuration and from the Origin Servers sections, edit each Origin Server:

Click on Show Advanced Fields and in the Origin Server Labels section, click on Add Label to add the created Know Key with the desired value to the Origin Server:

After the labels are added, the configuration should look like this:

In this example, both Origin Servers will receive traffic.

  • Click Configure in the Other Settings section to enable Subset Load Balancing in the Origin Pool:

Click on Configure and add the created key name:

Apply the configuration and then Save and Exit.

  • From the Load Balancer configuration go to the Origins section:

Edit the Origin Pool configuration, click on Show Advanced Fields and then click on Add Label in the Origin Servers Subsets section:

Select the value that will be used to indicate the Origin Servers that will process traffic, in this example, Enabled:

The Origins section should look like this:

This means that the Load Balancer will forward traffic only to the Origin Servers with label value Enabled.

 

Disable an Origin Server

To disable an Origin Server for maintenance we need to change the label value.

  1. Edit the Origin Pool configuration and modify the Origin Server value:
  2. In this example, by selecting Disabled, the Origin Server will not process traffic.
  3. After the maintenance is completed, the label can be changed back to Enabled.

Additional Information

  • Origin server subset rules provide the ability to create match conditions on incoming source traffic to the HTTP load balancer using country, ASN, regional edge (RE), IP address, or client label selectors for subset selection of destination (origin servers).
