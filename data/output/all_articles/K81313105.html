Description
When a virtual server is configured with a HTTP/2 profile and has the Web Acceleration option HTTP MRF Router enabled, WebSocket traffic is not processed and produces an error similar to the following in /var/log/ltm:

Error bigip.f5.com mcpd[5774]: 01070734:3: Configuration error: Profile(s) found on /<partition>/<virtual server name> that are not allowed: Only (TCP Profile, ClientSSL Profile, ServerSSL Profile, HTTP Profile, HTTP2 Profile, HTTP Compression Profile, HTTP Router Profile)

Environment

  • Websocket traffic
  • HTTP/2 profile 
  • HTTP MRF Router enabled 

Cause
The HTTP/2 full proxy architecture does not support WebSockets.

Recommended Actions

Disable the virtual server Acceleration option HTTP MRF Router of the virtual server configuration.
  1. Go to Local Traffic  ››  Virtual Servers ›› Virtual Server List
  2. Select the affected virtual server
  3. Locate the Acceleration configuration section
  4. Uncheck HTTP MRF Router
  5. Click Update
