K000135121: Misleading error log messages in SAML flow

Type
Support Solution
Published
2023-09-29
Updated
2023-10-02
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000135121

Description


From v17.1.x, during a successful SAML Authentication, some unrelated error log messages are seen under /var/log/apm.
For example, even if SAML Artifact is not configured, you may see the below message:

Failed to retrieve SAMLArtifact_b64 for SAML Agent
 

Environment

  • BIG-IP APM
  • SAML SP
     

Cause

The message is being logged for both SAML POST and Artifact conditions.
 

Recommended Actions


This log message can be ignored.
 

Additional Information

None
