Known Issue

Querying the IP intelligence database fails.

This issue occurs when all of the following conditions are met:

  • You BIG-IP system IP Address Intelligence Service (IPI Subscription) is licensed and enabled.
  • The IPI Subscription service does not initialize correctly.
  • The IPI Subscription service attempts to download an updated IP intelligence database.

Impact

The IPI Subscription service is unable to query the IP intelligence database.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing Security > Reporting > Application > Charts, no data displays for View By: " IP Address intelligence " or " Client Country"
  • When viewing the IPI Subscription /var/iprep/iprepd.log file, the system logs repeating error messages that appear similar to the following example:

    iprepd|ERR|<MM DD HH:MM:SS:s>|<pid>|Wrong est entries - don't merge more IPs!

  • When viewing the /var/log/ltm file, the system logs messages that appear similar to the following example:

    err iprepd[<pid>]: 015c0004:3: Failed memory allocation in vMergeLists!
    err iprepd[<pid>]: 015c0004:3: Wrong est entries - don't merge more IPs!
    err iprepd[<pid>]: 015c0004:3: vSetThreatListSize: Failed to allocate Threat List memory!
    err iprepd[<pid>]: 015c0004:3: Per-invocation log rate exceeded; throttling.
    err iprepd[<pid>]: 015c0004:3: Resuming log processing at this invocation; held <numeric value> messages.

Workaround

To work around this issue, you can restart the IPI Subscription service. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will temporarily stop the IPI Subscription services when the process is restarting.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the IPI Subscription service, type the following command:

    restart /sys service iprepd

  3. Exit tmsh by typing the following command:

    quit
