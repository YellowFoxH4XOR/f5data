K000132162: Certificate based client authentication between BIG-IP and Portal Access resource

Type
Support Solution
Published
2023-04-28
Updated
2023-04-28
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000132162

Description

You'd like to setup the BIG-IP APM to use X.509 client certificate authentication to the Portal Access resource.


Environment

  • BIG-IP APM
  • Portal Access resource requires client certificate authentication.


Cause

None


Recommended Actions

  1. First, import a client certificate (and key) to the BIG-IP (follow K14620 for further details)
    System ›› Certificate Management : Traffic Certificate Management : SSL Certificate List 
     
  2. Then you can set up a new Server SSL profile (follow K14806 for further details) as so:
        Configuration: Advanced
        Certificate: <select the client certificate added in step #1>
        Key: <select a key matching the client certificate>
        Server Name: <FQDN of the backend server>*
        Default SSL Profile for SNI: Enabled

        *substitute Server Name to the expected SNI name of the backend server (if no value is specified, the system uses the CN value from the certificate configured)This is the name that the system sends to the back-end server as the SNI extension. Wildcard "*" can be used.
     
  3. Lastly, make sure to add that Server SSL profile to the Virtual Server bearing the APM policy with desired Portal Access resource assigned.
