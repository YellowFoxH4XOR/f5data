Known Issue

DNS lookup may fail on Windows systems while a VPN connection is established

This issue occurs when all of the following conditions are met:

  • You install APM Clients 7.1.9 on your BIG-IP APM system.
  • You enable Integrated IP filtering engine in the Network Access configuration.
  • The DNS Exclude Address Space list in the Network Access configuration includes an entry with a wildcard.
  • You establish a VPN connection using a Windows client system running the 7.1.9 client.

Impact

You are unable to resolve DNS names matching the wildcard entry in the DNS Exclude Address Space list.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • DNS resolution fails when connected to the VPN
  • Clients are unable to resolve DNS names that match the wildcard entries configured in the DNS Exclude Address Space list

Workaround

To work around this issue, you can disable Integrated IP filtering engine in the Network Access configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure disables the Integrated IP filtering engine feature for VPN connections using this Network Access configuration.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to Access > Connectivity / VPN > Network Access (VPN).
  3. Select the name of the Network Access configuration.
  4. Select the Network Settings tab.
  5. Under Client Settings, for Client Side Security, clear the Integrated IP filtering engine check box.
  6. Select Update.
