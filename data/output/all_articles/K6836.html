Note: This Solution applies to only BIG-IP platforms that contain a Switch Card Control Processor (SCCP). The BIG-IP platforms affected include the 1500, 3400, 4100, 6400, 6800, 8400, and 8800 platforms. For more information about the SCCP, refer to K3454: Overview of the SCCP.

Note: This Solution applies to only BIG-IP 9.1.2, 9.1.3, 9.2.4 and later. For information about rebooting the SCCP on all other BIG-IP versions, refer to K5471: Rebooting the SCCP.

The SCCP is a separate subsystem that controls the F5 switch hardware. You may have to reboot the SCCP if, for example, you install a hotfix that updates the SCCP firmware package.

Rebooting the SCCP

F5 recommends that you perform a clean shutdown of the host system, and then concurrently reboot the SCCP and host system, by performing the following procedure:

  1. Log in to the BIG-IP command line.
  2. Reboot the host system and SCCP by typing the following command:

    full_box_reboot
