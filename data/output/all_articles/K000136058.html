Description

While trying to delete connections that are using route domains, the connection will not be deleted if the route domain is not specified.

Environment

  • BIG IP LTM

Cause

If route domain is not specific in the command, the command will affect route domain 0, it will not affect connections using other route domains.

Recommended Actions

Specify the route domain in the delete sys connection command.

For example, the below command will not delete connections if route domain %1 was specified for connection

tmsh delete /sys connection cs-client-addr 10.10.10.10

Instead you need to use the following command:

tmsh delete /sys connection cs-client-addr 10.10.10.10%1
