K01401131: Maintain snatpool persistence

Description

The BIG-IP system currently does not provide a feature to configure on the Configuration Utility or the tmsh (TMOS) shell, persistence for the snatpool selection to maintain application source IP consistency across a session.

Environment
  • BIG-IP Snatpool 
  • Persistence


Cause

We do not have a way to maintain SNAT persistence.

Recommended Actions

To enable snat pool persistence in the virtual server, an iRule can be used. For more information, refer to the following Devcentral links:

https://devcentral.f5.com/s/articles/persisting-snat-addresses-in-link-controller-deployments-26916
https://devcentral.f5.com/s/feed/0D51T00006i7P93SAE
https://devcentral.f5.com/s/articles/exchange2010-snat-pool-persistence
https://devcentral.f5.com/s/articles/snat-pool-persistence

Note: The iRules may require modification according to the environment of each application running.
