K000137705: Error: In Virtual server (/Common/virtual_server) an http2 profile with enforce-tls-requirements enabled is incompatible with client ssl profile '/Common/clientssl_profile'; cipher ECDHE-RSA-AES128-GCM-SHA256 must be available

Type
Support Solution
Published
2023-11-28
Updated
2023-11-28
Source
https://my.f5.com/manage/s/article/K000137705

Description

The system is offline due to a configuration issue after the upgrade to 14.1.5.6. The error is:

In Virtual server (/Common/virtual_server) an http2 profile with enforce-tls-requirements enabled is incompatible with client ssl profile '/Common/clientssl_profile'; cipher ECDHE-RSA-AES128-GCM-SHA256 must be available

Environment

  • Virtual server with HTTP/2 profile
  • Software upgrade

Cause

https://cdn.f5.com/product/bugtracker/ID1341093.html

Recommended Actions

Add the missing cipher ECDHE-RSA-AES128-GCM-SHA256 to the cipher rule from /Common/clientssl_profile and remove the "no-tlsv1.2" option from the profile.

Additional Information

None.
