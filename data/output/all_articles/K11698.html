Known Issue

This is the result of a known issue. In rare instances, the Traffic Management Microkernel (TMM) may stop responding while processing traffic by an FTP virtual server.

Note: Although the following error message is not always logged when this issue occurs, its presence in the /var/log/ltm file indicates that TMM has stopped responding and dumped core due to this issue.

notice panic: ../modules/hudfilter/ftp/ftp.c:400: Assertion "new data." failed.

F5 Product Development tracked this issue as ID 247854, ID 243214, ID 315213, ID 243329, and ID 315226 (formerly CR136003 and CR136323), and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
