Issue

Error Message

01071488:3: Remote transaction for device group <device_group> to commit id <commit_id> <remote_host> failed with error <error>.

In this error message, note the following:

  • <device_group> is the name of the device group.
  • <commit_id> is the commit ID.
  • <remote_host> is the remote host.
  • <error> is a supplemental error message.

For example:

01071488:3: Remote transaction for device group /Common/device_group to commit id 3 6085773701354286521 /Common/bigip.example.com 0 failed with error 01020036:3: The requested parent profile (/Common/source_addr) was not found.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • Configuration validation fails on a peer device during a ConfigSync operation.

Impact

The ConfigSync operation fails on the peer device and the system does not apply the changes.

Recommended Actions

This message indicates the system is not properly configured and can include another error message with more specific details about the problem.  You should correct any configuration problems before attempting another ConfigSync operation.
