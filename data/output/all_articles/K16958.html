Known Issue

Network access sessions may incorrectly alter network interface metrics.

This issue occurs when all of the following conditions are met:

  • You establish a network access session from a multi-home device that runs the Windows operating system.
  • You terminate your network access session.

Impact

Device routing interface metrics are not restored correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After establishing and then subsequently terminating a network access session, your Windows device does not route traffic to the expected interface.
  • When viewing the Windows device network table, before and after establishing a network access session, you notice that the network interface metrics are different.

Workaround

To work around this issue, you can disable and re-enable the network interface of the affected device.
