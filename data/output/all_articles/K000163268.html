Description

As part of the September 2026 SaaS release, support for both single-hop and multi-hop Bidirectional Forwarding Detection (BFD) configurations is being introduced for eBGP neighbors.
Customers who currently use BFD with existing BGP peer configurations should review this change carefully, as a one-time configuration update is required before upgrading Customer Edge (CE) software to ensure uninterrupted BFD operation.

Environment

  • F5® Distributed Cloud
  • F5 Distributed Cloud Customer Edge

Answer/Recommended Actions

This change applies only to customers who have BFD enabled in their BGP peer configuration prior to the September 2026 SaaS release.

To maintain existing single-hop BFD functionality after upgrading Customer Edge (CE) software, these customers must set eBGP Multihop to Disabled before upgrading to the September 2026 release software.

If the CE software is upgraded without first disabling eBGP Multihop, the BFD session will not become active after the upgrade.

Beginning with the September 2026 SaaS release, BFD supports both single-hop and multi-hop configurations for eBGP neighbors.

Required action: Customers with BFD already enabled in their BGP peer configuration must set eBGP Multihop to Disabled before upgrading their CE software to the September 2026 release, to ensure uninterrupted BFD operation.

Steps to disable BFD

1. Navigate to Multi-Cloud Network Connect > Networking > BGP Peers & Policies.

2. Find your BGP peer object and select … > Manage Configuration > Edit Configuration.

3. In the Peers section, select the pencil icon for your peer configuration.

4. From the eBGP Multihop list, select Disabled.

5. Select Apply to save the new configuration.

6. Select Save BGP Peers.
