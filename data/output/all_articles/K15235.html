Known Issue

The tmsh show /net route-domain command displays extra information, such as Virtual Local Area Network (VLAN) and interface statistics.

Impact

The route-domain command option incorrectly displays extra information; however, this issue is only cosmetic and does not affect the functionality of the configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The route-domain command option incorrectly displays VLAN and interface information, similar to the following example:

    # tmsh show /net route-domain
    --------------------
    Net::Route Domain: 0
    --------------------
      ---------------------------------------
      | Net::Vlan: ea-internal
      ---------------------------------------
      | Interface Name      ea-internal
      | Mac Address (True)  00:23:e9:31:6c:c3
      | MTU                 1500
      | Tag                 2102
        --------------------------
         | Net::Vlan-Member: ktrunk
         --------------------------
         | Tagged  yes
            ----------------------------------------------------------------------
            | Net::Trunk
            | Name    Status  Bandw   Bits   Bits  Errs  Errs  Drops  Drops  Colli
            |                  Mbps     In    Out    In   Out     In    Out  sions
            ----------------------------------------------------------------------
            | ktrunk      up   1000  32.4K  32.7K     0     0     50      0      0

               ---------------------------------------------------------------
               | Net::Interface
               | Name  Status   Bits   Bits  Pkts  Pkts  Drops  Errs     Media
               |                  In    Out    In   Out
               ---------------------------------------------------------------
               | 1.16      up  32.4K  32.7K    50    32     50     0  1000T-FD
               | 1.16      up  32.4K  32.7K    50    32     50     0  1000T-FD
