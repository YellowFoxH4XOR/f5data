Topic

SPF is a new anti-spam measure currently under development, which reduces mail address forgery and assists in identifying worms, spam, and viruses.

An SPF record is a TXT entry in the DNS for each domain used to verify the authenticity of a message.

Note: The proper format of an SPF TXT record is beyond the scope of this solution. For more information about SPF, refer to the following:

http://spf.pobox.com
http://spftools.infinitepenguins.com/
http://www.libspf.org/

Adding an SPF record to the DNS domain

To add an SPF TXT record to a domain name using the NameSurfer user interface, perform the following steps:

  1. Log in to the 3-DNS Controller's Configuration utility.
  2. From the left navigation, click NameSurfer.
  3. Type your username and password.

    The Zone index page displays, listing the domains that NameSurfer is maintaining.

  4. Click the domain name to which you want to add the SPF TXT record.

    The Zone <domain.com> page displays, listing all the names in the specified domain, starting with the domain name itself.

  5. Click the domain name.

    The Zone root page displays the SOA, NS and other records for the <domain.com> name.

  6. From the left navigation, click Add RR.

    The Add resource record page displays.

  7. From the Record type menu, select TXT.
  8. Click OK.
  9. The Zone root page for the domain displays with a Comment (TXT) field added at the bottom.
  10. Enter the properly formatted SPF information in the Comment (TXT) field.
  11. Click OK.

Testing the SPF record

To test the SPF record, perform the following steps:

  1. From the left navigation, click Back to zone page.
  2. From the left navigation, click DNS master file.

    The content of the entire domain, including the added TXT record, should be displayed. For example:

    $ORIGIN domain.com.
domain.com.         86400    IN      SOA    dns1. hostmaster.dns1. ( 
                             2004090206 28800 7200 604800 86400 ) 
                             NS      dns1
                             TXT     "v=spf1 mx ptr -all"
  3. To verify that the server is responding with correct information, type the following command:

    dig @<address of 3-DNS server> domain.com txt

    If configured correctly, the output should include the following:

    ;; ANSWER SECTION:
domain.com.               1D IN TXT       "v=spf1 mx ptr -all"
