Important: The behavior described in this Solution applies to the BIG-IP 1500 or 3400 platform that has 1GB of memory installed.

If you want to retain a BIG-IP 9.4.x installation when upgrading to BIG-IP 10.2.0, you must use the partitions disk-formatting scheme using the image2disk utility with the --format=partitions option to install 10.2.0 to another slot. However, when you attempt this on a BIG-IP 1500 or 3400 platform that has 1 GB of memory installed, this installation operation fails with errors that appear similar to the following:

Note: The errors are truncated in this example.

info: Creating log filesystem.

mkfs.ext3 invoked oom-killer: gfp_mask=0x200d0, order=0, oomkilladj=0

---sniped---

Out of memory: Killed process 9257 (mkfs.ext3).

Note: Due to a separate known issue, you may encounter a Terminal error message when you convert the disk formatting scheme to logical volume management (LVM) while upgrading the BIG-IP 1500 or 3400 (which has 1GB of memory installed) to 10.2.0. For more information, refer to K11396: Error Message: Terminal error: System memory of 1 GiB is insufficient for 'format=volumes' with this product image; 1.5 GiB is required.

If you have not yet proceeded with the upgrade to BIG-IP 10.2.0, you can perform an interim upgrade to 10.1.0, followed by an upgrade to 10.2.0. To do so, perform the following procedures:

  • Backing up 9.4.x configuration
  • Performing an interim upgrade to BIG-IP 10.1.0
  • Performing an upgrade to BIG-IP 10.2.0
  • Installing BIG-IP 9.4.x
  • Restoring the UCS archive

If you have already attempted to upgrade to BIG-IP 10.2.0, and the upgrade failed, you can remedy the situation by performing a clean installation of BIG-IP 10.2.0. To do so, perform the following procedures:

  • Performing a clean installation of BIG-IP 10.2.0
  • Installing BIG-IP 9.4.x

Backing up 9.4.x configuration

Back up the existing configuration on the 9.4.x slot and store the UCS archive file off the box. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to System > Archives > Archive List.
  3. Click Create button.
  4. Type the name of the UCS archive you want in the File Name box.
  5. Click Finished button.
  6. When the UCS archive is back up successfully, click OK to exit the status page.
  7. Click the name of the UCS archive.
  8. To download the UCS archive on your local PC, click the Download: <UCS archive filename> button.

Performing an interim upgrade to BIG-IP 10.1.0

To perform an interim upgrade to BIG-IP 10.1.0, perform the procedures described in the Upgrading from 9.3.x or 9.4.x section in the Performing the Installation chapter of the BIG-IP Systems: Getting Started Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Performing an upgrade to BIG-IP 10.2.0

When you have completed the interim upgrade to BIG-IP 10.1.0, perform the upgrade to BIG-IP 10.2.0 to another slot by using the Software Volume Management (SVM). To do so, perform the procedures described in the Upgrading from 9.6.x, or from earlier versions of 10.x section in the Performing the Installation chapter of the BIG-IP Systems: Getting Started Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Installing BIG-IP 9.4.x

When you have completed the upgrade to BIG-IP 10.2.0, you must download the BIG-IP 9.4.x installation image and install the BIG-IP 9.4.x on a different partition from the 10.2.0 upgrade. You can use any of the standard 9.4.x installation methods to install any version of the 9.4.x release that the platform supports. For example, you can use the following command syntax to install the BIG-IP 9.4.8 software:

im /var/tmp/local-install-9.4.8.355.0.im

Note: Due to a known issue with the BIG-IP 9.4.x installer, the GRUB entry for Maintenance Operating System (MOS) is removed. For more information, refer to K11774: The GRUB entry for MOS is removed during an installation of BIG-IP version 9.x

Note: For BIG-IP 9.4.x installation information, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM or EDGE Gateway release notes.

Restoring the UCS archive

When you have completed the BIG-IP 9.4.x installation, you can upload the UCS archive file and restore the configuration on the BIG-IP 9.4.x slot. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to System > Archives > Archive List.
  3. Click Upload.
  4. Click Browse.
  5. Select the UCS archive file that you have downloaded earlier.
  6. Click OK.
  7. Click Upload.
  8. Click the name of the UCS archive file that was uploaded to the BIG-IP system.
  9. To restore the configuration to the BIG-IP system, click Restore.

Performing a clean installation of BIG-IP 10.2.0

To perform a clean installation of BIG-IP 10.2.0, perform the procedures described in K10819: Performing a clean installation of BIG-IP 10.x or Enterprise Manager 2.x.
