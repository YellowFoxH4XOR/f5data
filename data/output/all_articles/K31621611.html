Known Issue

Open Shortest Path First (OSPF) adjacencies may fail to form when a Maximum Transmission Unit (MTU) mismatch exists between the Traffic Management Microkernel (TMM) and the BIG-IP Advanced Routing Module (ARM).

This issue occurs when all of the following conditions are met:

  • TMM caches a route metric with an MTU size that is smaller than the interface's configured MTU size.

    Note: This behavior may be the result of TMM receiving an ICMP Fragmentation Needed message from an upstream router.

  • BIG-IP ARM runs an OSPF instance on the interface and uses the interface's configured MTU size.

Impact

OSPF adjacency formations fail to form.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the show ip ospf neighbor command, you view that neighbors are stuck in the Exchange state.

Workaround

There is no workaround for this issue. To resolve this issue, you can restart TMM. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will halt all traffic processing. You should perform this procedure only during a scheduled maintenance period.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To restart TMM, type the following command:

    restart sys service tmm

  3. To exit the tmsh utility, type the following command.

    quit
