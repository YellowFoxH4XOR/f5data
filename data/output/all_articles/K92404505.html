K92404505: Unsuccessful UCS archive creation can fill the /shared partition

Type
Knowledge
Published
2019-06-03
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K92404505

Issue

Description

Recurrent unsuccessful UCS archive creation can fill the /shared partition.

As a result of this issue, you may encounter one or more of the following symptoms:

  • Files cannot be saved to the /shared partition
  • Error messages logged to the /var/log/ltm file:

    err diskmonitor: 011d0004:3: Disk partition /shared has only <free_space> free

    In this error message, note the following:

    • <free_space> is the percentage of free disk space remaining.

Environment

  • UCS archive files are created using an external script

Cause

There are many large configsync*.im files left behind in /shared/tmp after UCS archive creation fails.

Recommended Actions

Perform the following procedures to resolve this issue:

  • Verifying the presence of configsync*.im files
  • Investigating the behavior of the external script
  • Deleting the configsync*.im files

Verifying the presence of configsync*.im files

Verify if configsync*im files are consuming space under the /shared partition with the following find command:

find /shared/tmp -name *.im -exec ls -lh {} \;

Investigating the behavior of the external script

Investigate the behavior of the external script to determine why the failure is occurring and fix the issue.

Deleting the configsync*.im files

Delete the directories and files left behind by the unsuccessful UCS creation with the following rm command:

rm -rf /shared/tmp/im*/

Important: Performing this step without fixing the issue with the external script eventually leads to a full /shared partition again.

Additional Information

During UCS creation, temporary directories and *.im files are created under the /shared/tmp/ directory, similar to the following:

337480 /shared/tmp/im17039/configsync-2.0-1-Linux-2.6.32431.56.1.6.5.8664.im
310192 /shared/tmp/im10306/configsync-2.0-1-Linux-2.6.32431.56.1.6.5.8664.im
298632 /shared/tmp/im6318/configsync-2.0-1-Linux-2.6.32358.61.1.6.5.8664.im
282904 /shared/tmp/im9133/configsync-2.0-1-Linux-2.6.32431.56.1.6.5.8664.im
272096 /shared/tmp/im943/configsync-2.0-1-Linux-2.6.32358.61.1.6.5.8664.im
267820 /shared/tmp/im27374/configsync-2.0-1-Linux-2.6.32431.56.1.6.5.8664.im
260136 /shared/tmp/im23614/configsync-2.0-1-Linux-2.6.32358.61.1.6.5.8664.im

Note: Despite configsync appearing in the file name, ConfigSync operations do not create these files.

These files are normally deleted after a UCS archive is successfully created under /var/local/ucs. In cases where you use an external script for connecting and creating UCS archives, this can be unsuccessful. For example, if the script disconnects before the UCS save operation completes, the temporary files can then be left behind. Over time, if the script continues to run, many of these directories and *.im files can fill the /shared partition.
