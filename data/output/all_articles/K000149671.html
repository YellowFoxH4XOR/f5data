Description

I have some Fast ACL rules configured and I do not see any logs in the GUI console even if I get some hits on those rules:

 

 

  Environment

  • F5® Distributed Cloud
  • Fast ACLs

Cause

None

Answer/Recommended Actions

Logging of fast ACLs is only supported for auto DDOS, so the configured DDOS rules will not be logged.
