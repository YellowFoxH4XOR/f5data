K000140866: Edge Client on MacOS getting "Software update is available. Do you want to download this update?" while Component Update is set to No

Type
Support Solution
Published
2025-05-07
Updated
2026-03-02
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000140866

Description

After upgrading TMOS version on the BIG-IP APM device , the existing Edge Client on MacOS receives a confusing prompt "Software update 72xx.xxxx.xxx.x is available. Do you want to download this update?" even though the Component Update is set to No in the connectivity profile and you have no intention to upgrade the APM client version via auto update.

This is because the Endpoint Inspection Helper (mac_f5epi.pkg) which is a separate download and tied to the APM client installed on the BIG-IP APM server side needs to be updated on the client upon server upgrade if the upgraded server ships with a newer APM client version than the existing client version running on Mac and also if your APM policy includes the Endpoint Inspection actions.  

Here is an example of the prompt.  The version number appearing in the prompt is the APM version that is installed on the server:

 

 

Even though the pop-up message shows the newer APM client version, this prompt is NOT for updating the actual APM/Edge Client version. This is for updating the Endpoint Inspection Helper package (mac_f5epi.pkg)

 

Environment

  • BIG-IP APM Edge Client on Mac
  • Upgraded BIG-IP TMOS version which ships with a newer APM client image (see the table in K13757: BIG-IP Edge Client version matrix)
  • Existing APM Edge Client installed on Mac is older than the APM client image/version installed on the upgraded BIG-IP APM unit
  • Component Update is set to No in the connectivity profile (no auto client update)
  • Your APM policy includes Endpoint Inspection action on the client (such as Antivirus check, Device cert check, etc)

Cause

This is filed as Bug ID 1295133. There is currently no public facing information about this bug. 

 

Recommended Actions

  1.  Simply have the Mac user click OK in this prompt, which downloads mac_f5epi.pkg on the fly (from https://<virtual_server>/public/download/mac_f5epi.pkg) and update the EPI package.
  2.  If you would like to prevent from Mac users receiving this confusing pop-up upon server upgrade, download the new mac_f5epi.pkg from the BIG-IP while the newer APM image installed, then work with your IT team to push the new mac_f5epi.pkg to Mac users before upgrading the server. The new mac_f5epi.pkg from a newer APM image still works with older APM clients.
