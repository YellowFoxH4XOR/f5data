Description

Public Key Authentication failure for remote users with error:

crit sshd: fatal: Access denied for user <user-id> by APM account configuration [preauth]


Environment

  • Remote authentication configured
  • Local profile for Remote users configured
  • Public Key Authentication

Cause

Remotely authenticated users cannot use Public Key Authentication despite having a local profile.


Recommended Actions

  1. Create a local account or modify the existing local profile
  2. Modify shell to bash for this user with the following tmsh command - tmsh modify auth user <username> shell bash
  3. Generate key in the /home/<username> in BIGIP or any remote system - ssh-keygen -t rsa
  4. Copy the public key to BIG-IP - scp .ssh/id_rsa.pub <username>@<BIG-IP IP>:/home/<username>
  5. Generate authorized_keys in the BIG-IP - cd /home/<username>; mkdir .ssh; cat id_rsa.pub >.ssh/authorized_keys
  6. Test this function ssh -i /home/<username>/id_rsa <username>@<BIG-IP IP>
  7. In addition to this, enable the fallback option on remote authentication.


Additional Information

If the locally built <username> also appears on the remote authentication server, local public key authentication overrides and the user will always be locally authenticated using public key authentication. The user in question wouldn't be authenticated against the remote authentication server.
