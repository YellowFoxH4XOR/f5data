Known Issue

The DNS monitor may fail to mark an object down when an Internet Control Message Protocol (ICMP) error message is received.

This issue occurs when all of the following conditions are met:

  • The DNS monitor receives an ICMP error message other than the port unreachable message.
  • The DNS monitor does not have a receive string configured.

When the DNS monitor receives an ICMP port unreachable error message, the monitored object is marked down regardless of whether the monitor is configured with a receive string. However, if any other type of ICMP error message is received, such as an ICMP host unreachable - admin prohibited message, the monitored object is only marked down if the monitor is configured with a receive string.

Impact

The DNS monitor may fail to mark down an unavailable object.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Unavailable objects that are monitored by a DNS monitor remain marked up.

Workaround

To work around this issue, you can configure the DNS monitor with a receive string. Alternatively, you can monitor the affected objects with a different monitor type (such as an ICMP monitor).

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
