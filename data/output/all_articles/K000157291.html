K000157291: Unable to perform Winscp to F5 BIGIP with error message "Host is not communicating for more than 15 seconds"

Type
Support Solution
Published
2025-11-05
Updated

Applies to

  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000157291

Description

Attempts to transfer files to a BIG-IP using WinSCP or SCP fail with the error "Host is not communicating for more than 15 seconds. still waiting." CLI SCP attempts return "path not allowed" and related errors. SSH access is successful, and the issue is isolated to file transfer operations.

Environment

  • BIG-IP  
  • Advance shell

Cause

The root cause is the user account not having "Advanced shell" (bash) access, which is required for SCP/SFTP file transfers on BIG-IP  due to security enhancements. Without bash shell access, SCP/WinSCP operations are blocked, resulting in the observed errors.

Recommended Actions

Change the affected user account's shell to "Advanced shell" (bash) using the following command:

tmsh modify /auth user <username> shell bash

tmsh save /sys config

Ensure that file transfers use absolute paths within directories allowed by the SCP whitelist.
