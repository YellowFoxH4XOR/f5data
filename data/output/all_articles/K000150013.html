K000150013: A Trusted IP Address is Not Populating Learning Suggestions

Type
Support Solution
Published
2025-02-27
Updated
2025-02-27
Source
https://my.f5.com/manage/s/article/K000150013

Description

Learning suggestions for building policies from trusted IP addresses are not being populated in BIG-IP Advanced WAF. Despite traffic being generated from trusted IPs, no learning suggestions or alarms are observed. Logs indicate that the traffic is being flagged as bot-like and excluded from learning due to specific policy settings.

The debug logs may look like this:

  1. policy |DEBUG |Feb 26 01:36:24.093|008545|Policy.cpp:216|user-agent <XXXXXXXX/1.0 CFNetwork/1111.111.111 Darwin/11.1.1> is not a browser

Environment

  • Product: BIG-IP Advanced WAF
  • Version: 16.1.2

Cause

The User-Agent string in requests sent from trusted IPs was identified as non-standard browser traffic by the ASM (Application Security Manager). This caused the system to classify it as bot-like traffic, which is excluded from generating learning suggestions due to the "Learn only from non-bot traffic" setting being enabled.

Recommended Actions

  • Disable "Learn only from non-bot traffic":

            Navigate to your ASM policy settings and disable this option temporarily or permanently based on your organization's requirements. Disabling this setting will allow learning suggestions to be generated for all types of traffic, including those flagged as bot-like.

  • Verify User-Agent Strings:

            Ensure that requests originating from trusted IPs use standard browser User-Agent strings if possible. If using mobile applications or custom clients, confirm their User-Agent strings align with expected formats recognized by ASM.
