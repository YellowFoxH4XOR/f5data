Known Issue

This is the result of a known issue. Safari 4.0 users may receive the following error message when attempting to launch a Java AppTunnel Favorite:

Java 1.4.2 or above is required for Java Application Tunnel

The error message may appear regardless of the Java version installed on the user's Mac OS X. This issue appears more frequently if there is a delay in the user response to the confirmation request that appears after a Java AppTunnel is launched. If the user waits more than approximately 5 seconds, the FirePass controller will erroneously view the Java applet as not loaded. As a result, the user receives the above error message.

F5 Product Development tracked this issue as ID 296480 (formerly CR124449) and was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in cumulative hotfix HF-603-3, which has been issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
