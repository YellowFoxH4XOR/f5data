Description

ASM event logs are not preserved during an outage of communication with an external remote logging server.

Environment

  • BIG-IP ASM
  • Remote Logging of ASM Events

Cause

None, this is by design.

Recommended Actions

This is expected behaviour for BIG-IP ASM. When the remote syslog server is unavailable, ASM does not buffer or cache logs for later delivery. Any logs generated during the outage are not retained for forwarding once the connection is restored.

If strict log retention is required, 

  • Consider architecting your external syslog infrastructure for high availability to make sure you have at least one server available at a given time (one or more remote logging servers configured as a pool).
  • You can enable local logging as a backup, so logs are at least stored on the BIG-IP itself. However, make sure you only log important Illegal requests, as logging all the requests will significantly reduce the BIG-IP performance. You can further use iControl REST APIs to pull these locally logged event logs periodically from BIG-IP referring to the API endpoints from https://my.f5.com/manage/s/article/K000149677 

Additional Information

We already have an RFE in place for this functionality.
