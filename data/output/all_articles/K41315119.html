Known Issue

The BIG-IP APM rewrite process may exit and produce a core file when processing responses with multibyte encoding.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with portal access.
  • The BIG-IP APM rewrite process responds with multibyte encoding other than UTF-8.
  • In the response content, the network packet payload ends with an incomplete or invalid sequence.

Impact

The BIG-IP APM rewrite process is unresponsive and temporarily stops processing traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a rewrite process core file to the /var/core directory that appears similar to the following example:

    /var/core/rewrite.2.bld637.0.core.gz

  • The BIG-IP APM rewrite process is unresponsive and temporarily stops processing traffic.
