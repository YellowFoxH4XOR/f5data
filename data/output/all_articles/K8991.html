The message that is logged when the BIG-IP WebAccelerator encounters an issue parsing the server response has been enhanced to facilitate troubleshooting. The log message now contains information about the request and the response, such as the URI and the response status. In previous versions, the message logged does not contain information identifying the source of the logged message.

Note: In BIG-IP WebAccelerator 9.4.8, the expandedAsyncErrors feature no longer logs the URI or headers to the pvac.log file. The URI will appear in the hit logs, if enabled.

F5 Product Development tracked a request for this enhancement as CR93393 and it was added in BIG-IP WebAccelerator 9.4.6. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

In addition, the enhancement was added in Hotfix-BIG-IP-9.4.5-HF2 for BIG-IP 9.4.5. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

Enabling enhanced logging

In BIG-IP Hotfix-BIG-IP-9.4.5-HF2 and BIG-IP WebAccelerator version 9.4.6 through 9.4.8, you can enable enhanced logging by editing the setting in the /config/wa/pvsystem.conf. To enable the enhanced logging, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa
  3. Open the pvsystem.conf file in a text editor.
  4. Change the expandedAsyncErrors entry from false to true.

    For example:

    <expandedAsyncErrors>true</expandedAsyncErrors>
  5. Save the pvsystem.conf file.
  6. Stop the BIG-IP WebAccelerator pvac process by typing the following command:

    bigstart stop pvac
  7. Start the BIG-IP WebAccelerator pvac process by typing the following command:

    bigstart start pvac

Note: After enabling the enhanced logging, some irrelevant garbled data may be included in the pvac.log file. For information, refer to K9888: The pvac.log file may contain garbled log messages. 

Note: The expandedAsyncErrors setting was removed in BIG-IP WebAccelerator 10.1.0.
