K12401: Error Message: 04050203:5: |EM_ALERT_00000000| Calculated storage capacity is below 5 days

Issue

The Enterprise Manager system provides information about the amount of space available for the storage of statistics, the amount of space currently in use for statistics data, and the estimated number of days of storage based on the current data collection volume. By default, the Enterprise Manager system allocates a small portion of disk space for statistics storage. Depending on the number of devices managed and their respective configurations, this space may not be sufficient to store the amount of data that is estimated for collection over the next five calendar days. When this occurs, the Enterprise Manager system logs messages to the /var/log/em file that appear similar to the following example:

local/em notice emalertd[9222]: 04050203:5: |EM_ALERT_00000000| Calculated storage capacity is below 5 days (currently at 0 days)

To increase the amount of disk space available for statistics data storage, perform the following procedure:

  1. Log in to the Configuration utility on the Enterprise Manager system.
  2. Navigate to the Data Storage page using one of the following paths:

    Enterprise Manager 3.0.0 and later

    Statistics > Managed Devices > Options > Data Storage


    Enterprise Manager 2.3.0

    Enterprise Management > Options > Statistics > Data Storage


    Enterprise Manager 2.2.0 and earlier

    Enterprise Management > Statistics > Options > Data Storage
  3. Review the available statistics storage space, statistic storage currently in use, and the estimated statistic storage space with the current settings.
  4. To determine the allocation of resources that best suits your performance needs, select a value from the Allocated Statistic Storage Space list.
  5. Click Recalculate.

    The system recalculates statistic storage based on the change, without saving the configuration.

  6. When you are satisfied with the allocation of statistic storage, click Save Changes to commit the configuration changes.
