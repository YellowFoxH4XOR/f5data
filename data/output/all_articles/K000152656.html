K000152656: Unable to import BIG-IP 17.5.x .tar.bundle on F5OS appliance - "Failed to verify image signature. Removed."

Type
Support Solution
Published
2025-07-21
Updated
2025-07-21
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.3, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000152656

Description

Failed to import the BIG-IP 17.5.x .tar.bundle on F5OS-A 1.5.x.

The /var/F5/system/log/platform.log file contains an entry similar to the following from the image-agent process:

image-agent[9]: priority="Err" version=1.0 msgid=0x2002000000000010 msg="Failed to verify image signature. Removed." IMAGE="BIGIP-17.5.1-0.0.7.ALL-F5OS.tar.bundle" FAILURE="signature".

Environment

  • F5OS-A 1.5.x
  • BIG-IP image import

Cause

The .tar.bundle files are not supported in F5OS-A 1.5.x. These files can be imported from F5OS-A 1.8.0.

Recommended Actions

Use the .qcow2.zip.bundle on F5OS-A 1.5.x. This file is available from the same location on the MyF5 Downloads site.
