Known Issue

BIG-IP CGNAT may experience a memory leak.

This issue occurs when either one of the following conditions is met:

  • You have a Large Scale NAT (LSN) pool configured with Hairpin Mode set to Enabled.
  • You have set the Inbound connection handling to Automatic.

Impact

Over time, system performance may degrade, and the system may eventually become unresponsive or reboot due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system unexpectedly fails over to another system in the device group.
  • The tmsh show sys memory command shows high memory utilization for the CMP memory subsystem.

Workaround

To work around this issue, you can avoid using Hairpin Mode, or not set Inbound connection handling to Automatic.
