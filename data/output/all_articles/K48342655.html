Known Issue

The BIG-IP system may fail to disassociate and delete a profile within the same batch transaction.

This issue occurs when all of the following conditions are met:

  • You have a local traffic profile (for example, an HTTP profile) associated to a virtual server.
  • You attempt to disassociate the profile with the virtual server and delete it within a transaction.

    For example, the following tmsh command sequence attempts to disassociate an HTTP profile named test-profile from a virtual server named test-vs followed by deleting the test-profile within the same transaction.

    (tmos)# create cli transaction
    (tmos)# modify ltm virtual test-vs profiles delete { test-profile }
    (tmos)# delete ltm profile http test-profile
    (tmos)# submit cli transaction

Impact

The BIG-IP system will fail to process the transaction. As a result, the local traffic profile remains in the BIG-IP configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Removing the local traffic profile from the BIG-IP configuration fails with an error message that appears similar to the following example:

    01020036:3: The requested virtual server profile (/Common/test-vs test-profile) was not found.

Workaround

To work around this issue, you can perform the disassociation and deletion of the local traffic profile in separate transactions. For more information about tmsh batch transactions, refer to the Creating a batch mode transaction section of the Traffic Management Shell (tmsh) Reference Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
