Issue

Description

  • When establishing BIG-IP APM network access, the captive portal only displays a blank page for certain users on certain machines at certain times.

Environment

  • BIG-IP APM 13.x using Captive Portal
  • The BIG-IP Edge Client package installed on the client device has Always Connected Mode enabled

Cause

ID749925 Edge Client captive portal authentication page is not fetched and a blank window is shown instead.

Recommended Actions

This is resolved by upgrading the APM Clients package to a version 7.1.7.1 or later.
After downloading the latest APM Clients package from APM Clients Download Page, perform the procedure below:

  1. Log in to the Configuration Utility
  2. Navigate to System > Software Management > APM Clients > Import.
  3. On the New Image page, click Choose File browse to the ISO file you downloaded, and then click Import.
  4. After the upload of image has completed message displays, click OK.
  5. On the next page, in the list of client images uploaded to the system, select the check box for the BIG-IP APM client image you just uploaded, and then click Install.
  6. On the Software Image page, click Install.
  7. Installed Image indicates the currently active image that is delivered to users.
  8. Updates can be delivered to the BIG-IP Edge Client on users' device using the following methods:
    • Setting the Component Update to Yes in the appropriate connectivity profile.
    • Downloading the BIG-IP Edge Client package from the BIG-IP APM and delivering it to each client device for install.

Additional Information

You can configure the Always Connected Mode feature of the BIG-IP Edge Client using the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Access >  Connectivity / VPN > Connectivity > Profiles.
  3. Click the appropriate connectivity profile.
  4. Click Customize Package.
  5. Click BIG-IP Edge Client on the left panel.
  6. Select or clear the Enable Always Connected Mode check box to enable or disable the feature.
