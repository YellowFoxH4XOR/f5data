Description

The FIPS 140 Compliance Module is active in the license and you will see the following log message when the license with this feature has been activated:

/var/log/ltm

FIPS 140 Compliance license changing OpenSSL FIPS flag from (-1) to (1). Reboot is required for changes to take full effect.

Environment

  • BIG-IP
  • Active FIPS 140-2, ELA module (Also known as FIPS Compliance or Full box FIPS)
  • License Activation

Cause

FIPS 140-2, ELA is active on your BIG-IP license.  The system requires a reboot to activate the feature.

Recommended Actions

Before rebooting the system, ensure that the FIPS Integrity Check does not FAIL, otherwise the system will not be able to boot up.

Use the custom script provided in K41999483 to see if the Integrity Check will PASS or FAIL.
