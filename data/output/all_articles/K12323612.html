Known Issue

BIG-IP ASM processing of chunked requests may trigger security violations.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM security policy is configured to trigger a security violation based on the HTTP Allowed File Type Properties > Request Length or POST Data Length settings.
  • Content processed by the BIG-IP ASM security policy is HTTP chunked.
  • The chunked request length is greater than half of the configured maximum allowed file type Request Length or POST Data Length.

Impact

The chunked content triggers a Request Length violation.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The chunked content triggers a false positive Request Length or POST Data Length violation, and may be blocked based on policy settings.

Workaround

To work around this issue, you can increase the allowed file type Request Length property to a value that is greater than double the size of the offending chunked content. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure allows the system to pass larger requests through to the application server.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > File Types > Allowed File Types.
  3. In the Current edited policy box, enter the affected security policy.
  4. Click the affected file type.
  5. In the Request Length box, type a bytes value that is at least two times the total bytes size of the chunked content that triggered the violation.
  6. In the POST Data Length box, type a bytes value that is at least two times the total bytes size of the chunked content that triggered the violation.
  7. Click Update.
  8. Click Apply Policy.
