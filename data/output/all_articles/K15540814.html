Description

SIP Invite with "media-service=treatment" doesn't get forwarded

Environment

  • SIP Invite
  • media-service type treatment

Cause

At first, It may look like BIG-IP is not forwarding SIP invite with media-service=treatment.
However, if you look closely on a packet level, you would see a garbled or incomplete header which BIG-IP is unable to parse causing it to drop:

Recommended Actions

The SIP application in question has to be fixed, in order to send well-formatted valid headers to BIG-IP.
