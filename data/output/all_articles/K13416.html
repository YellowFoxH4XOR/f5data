Known Issue

Polling the SNMP OID sysObjectID.0 (.1.3.6.1.2.1.1.2.0) returns an incorrect value of org (.1.3).

This issue occurs when the following condition is met:

  • SNMP is being polled for the sysObjectID.0 OID (.1.3.6.1.2.1.1.2.0).

The sysObjectID OID returns the OID for the OS of the system being managed. The FirePass controller should return .1.3.6.1.4.1.8072.3.2.10 (Linux), which is the base OS for the FirePass controller.

Impact

You are unable to determine the OS of the device.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • SNMP returns org (.1.3) when the sysObjectID.0 OID is polled.
