K000156659: How to Upload SSL/TLS Certificates to Distributed Cloud

Applies to

Source

Description

  • I need to upload a SSL/TLS certificate to my F5 Distributed Cloud Tenant so that I may utilize it with my Load Balancers

Environment

  • F5 Distributed Cloud (XC)

Cause

 

Answer/Recommended Actions

  • Select the Web App & API Protection Tile in the Distributed Cloud Console
  • Switch to the Namespace you wish to store the SSL/TLS Certificate in
  • Expand Manage menu on the left-hand side of the window, go to Certificate Management, and select TLS Certificates
  • Select the Add TLS Certificate button
  • Enter the desired name for this certificate
  • Click the Import from File button
  • Click the Upload File button
  • You'll be prompted to select the PEM or PKCS12-encoded certificate file (Allowed extensions: crt, cer, pem, pkcs12, p12 or pfx)
  • Click the Upload File button under Key
  • You'll be prompted to select the PEM encoded private key file (Allowed extensions: key or pem)
  • Press the Import Button
  • If your certificate doesn't contain the Intermediate/Root CA Certificates, you'll need to choose your Intermediate Certificate Chain from the  Intermediate Certificate Chain dropdown.
    • If you have an existing  Intermediate Certificate Chain that is valid for this certificate, select it from the list
    • If you need to create a new  Intermediate Certificate Chain:
      • From the drop-down menu, Select Add Item
      • Enter the desired name for this Intermediate Certificate Chain
      • You can either paste in the contents of your Intermediate Certificate Chain or upload the Intermediate Certificate Chain using the Upload File Button
      • Once configured, press the Add Intermediate Certificate Chain in the lower right of the window
  • Click the Add TLS Certificate button in the lower right of the window
