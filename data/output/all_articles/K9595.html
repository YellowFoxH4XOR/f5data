Topic

Creating a wide IP or wide IP alias using a first-level domain name will cause ZoneRunner to create a top-level domain (TLD) entry in the BIND database. This behavior may cause a site outage because the BIG-IP DNS system is not authoritative for the top-level domain. Similarly, creating a wide IP using a second-level domain name may cause ZoneRunner to create a parent domain for which the BIG-IP DNS system is not authoritative. This behavior may cause resolution issues for other subdomains of that parent.

For example, if you create a wide IP called myf5.com and the myf5.com zone does not exist, ZoneRunner will automatically create a .com top-level domain zone entry.

When a resource record is added to that zone, such as a CNAME, and that record is queried, the Authority section displays .com as the authoritative domain. Queries to BIG-IP DNS system for sub-domains of the created parent may return authoritative NXDOMAIN responses.

Important: Top level domains are the last part of an internet domain name, which include the group of letters following the last period ( . ) character of any domain name. These domains are controlled and maintained by DNS root zone servers. The root zone servers do not resolve addresses for these domain names; they only provide NS records associated with the subdomains that are affiliated with top-level domains.

For example:

dig @172.16.65.11 www.myf5.com

; <<>> DiG 9.4.2-P2 <<>> @172.16.65.11 www.myf5.com
; (1 server found)
;; global options: printcmd
;; Got answer:
;; ->>HEADER<<- opcode: QUERY, status: NXDOMAIN, id: 20012
;; flags: qr aa rd ra; QUERY: 1, ANSWER: 1, AUTHORITY: 1, ADDITIONAL: 0

;; QUESTION SECTION:
;www.myf5.com. IN A

;; ANSWER SECTION:
www.myf5.com. 30 IN CNAME www1.myf5.com.

;; AUTHORITY SECTION:
com. 60 IN SOA ns1.myf5.com. hostmaster.ns1.myf5.com. 5 10800 3600 604800 60

;; Query time: 2 msec
;; SERVER: 172.16.65.11#53(172.16.65.11)
;; WHEN: Wed Jan 14 08:13:49 2009
;; MSG SIZE rcvd: 120

This behavior may cause an outage or recursion issues.

Workaround

To create a wide IP that does not contain a host name and to prevent the BIG-IP DNS system from creating a top-level domain zone record, perform one of the following options, using the Configuration utility:

  • Creating a zone record using ZoneRunner, then creating the wide IP (BIG-IP 11.5.0 and later)
  • Creating a zone record using ZoneRunner, then creating the wide IP (BIG-IP 11.4.1 and earlier)
  • Creating the wide IP specifying a host name, then adding the subdomain you want to resolve to the Alias list (BIG-IP 11.5.0 and later)
  • Creating the wide IP specifying a host name, then adding the subdomain you want to resolve to the Alias list (BIG-IP 11.4.1 and earlier)

Note: If you have already created the wide IP or wide IP alias, and a top-level domain zone record was created, delete both the wide IP or wide IP alias and the zone record.

Creating a zone record using ZoneRunner, then creating the wide IP (BIG-IP 11.5.0 and later)

To create a zone record using ZoneRunner and the wide IP, perform the following two procedures:

Creating a zone record using ZoneRunner

  1. Go to DNS > Zones > ZoneRunner.
  2. Select Zone List.
  3. Select Create.
  4. For View Name, select an appropriate option.

    Note: Unless you have multiple views configured, the default view is external.

  5. Enter the Zone Name.

    For example:

    myf5.com

  6. Enter the SOA Record and NS record information and any other options you want to allow.
  7. Select Finished.

Creating the wide IP

  1. Go to DNS > GSLB > Wide IPs.
  2. Select Create.
  3. Enter the name that you want the BIG-IP system to resolve.

    For example:

    myf5.com

  4. Select the pools you want to use and select Add to add them to the Pool List.
  5. Select any additional options you want to enable for the wide IP.
  6. Select Finished.
  7. Test the configuration by performing a lookup and resolving the name.

Creating a zone record using ZoneRunner, then creating the wide IP (BIG-IP 11.4.1 and earlier)

To create a zone record using ZoneRunner and the wide IP, perform the following two procedures:

Creating a zone record using ZoneRunner

  1. Go to Global Traffic > ZoneRunner > Zone List.
  2. Select Create.
  3. For View Name, select the appropriate option.

    Note: Unless you have multiple views configured, the default view is external.

  4. Enter the Zone Name.

    For example:

    myf5.com

  5. Enter the SOA record and NS record information, and any other options you want to allow.
  6. Select Finished.

Creating the wide IP

  1. Go to Global Traffic > wide IPs.
  2. Select Create.
  3. Enter the name that you want the BIG-IP system to resolve.

    For example:

    myf5.com

  4. Select the pools you want to use and select Add to add them to the Pool List.
  5. Select any additional options you want to enable for the wide IP.
  6. Select Finished.
  7. Test the configuration by performing a lookup and resolving the name.

Creating the wide IP specifying a host name, then adding the subdomain you want to resolve to the Alias list (BIG-IP 11.5.0 and later)

To create the wide IP and add the subdomain you want to resolve to the Alias list, perform the following procedure:

  1. Go to DNS > GSLB > Wide IPs.
  2. Select Create.
  3. For General Properties, select Advanced.
  4. Enter the name, including the host name, that you want the BIG-IP system to resolve.

    For example:

    www.myf5.com

  5. For Alias, enter the subdomain portion that you want to associate with the entry that you previously created.

    For example:

    myf5.com

  6. To add the alias to the Alias List, select Add.
  7. Select the pools you want to use, and select Add to add them to the Pool List.
  8. Select any additional options you want to enable for the wide IP.
  9. Select Finished.
  10. Test the configuration by performing a lookup and resolving both names.

Creating the wide IP specifying a host name, then adding the subdomain you want to resolve to the Alias list (BIG-IP 11.4.1 and earlier)

  1. Go to Global Traffic > wide IPs.
  2. Select Create.
  3. Set the view to Advanced.
  4. Enter the name, including the host name, that you want the BIG-IP system to resolve.

    For example:

    www.myf5.com

  5. For Alias, enter the subdomain portion that you want to associate with the entry that you previously created.

    For example:

    myf5.com

  6. To add the alias to the Alias List, select Add.
  7. Select the pools you want to use, and select Add to add them to the Pool List.
  8. Select any additional options you want to enable for the wide IP.
  9. Select Finished.
  10. Test the configuration by performing a lookup and resolving both names.
