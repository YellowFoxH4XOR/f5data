Description

The value following the "state part-no" field shown below displays manufacturing number instead of part number:

r5000-1# show components component psu-1
components component psu-1
 state serial-no S9XX51XX5XX
 state part-no M1845
 state empty false
 psu-stats psu-current-in 1.89
 psu-stats psu-current-out 29.437
 psu-stats psu-voltage-in 203.0
 psu-stats psu-voltage-out 11.984
 psu-stats psu-temperature-1 40.0
 psu-stats psu-temperature-2 51.0
 psu-stats psu-temperature-3 58.0
 psu-stats psu-fan-1-speed 9376
