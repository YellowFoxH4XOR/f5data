K8039: Certain Decision Box options may not appear in the pre-logon sequence

Known Issue

This is the result of a known issue. If you configure a Decision Box in your pre-logon sequence, and that Decision Box contains numerous options or options with lengthy descriptions, some of the latter options may not be displayed to users during the pre-logon sequence.

An example Decision Box configuration is as follows:

  • Option 1
    Sentence one.
    Sentence two.
    Sentence three.
    Sentence four.
  • Option 2
    Sentence one.
    Sentence two.
    Sentence three.
    Sentence four.
  • Option 3
    Sentence one.
    Sentence two.
    Sentence three.
    Sentence four.
  • Option 4
    Sentence one.
    Sentence two.
    Sentence three.
    Sentence four.
  • Option 5
    Sentence one.
    Sentence two.
    Sentence three.
    Sentence four.
  • Option 6
    Sentence one.
    Sentence two.
    Sentence three.
    Sentence four.

With the above Decision Box configuration, FirePass may only display the following options to users during the pre-logon sequence: 

  • Option 1
    Sentence one.
    Sentence two.
    Sentence three.
    Sentence four.
  • Option 2
    Sentence one.
    Sentence two.
    Sentence three.
    Sentence four.
  • Option 3
    Sentence one.
    Sentence two.
    Sentence three.
    Sentence four.
  • Option 4
    Sentence one.
    Sentence two.
    Sentence three.
    Sentence four.

F5 Networks Product Development is tracking this issue as CR83557.

Workaround

You can reduce the probability of this issue by performing any combination of the following options:

  • Limit the number of options for each Decision Box, and group options together if possible.

    For example, the following Decision Box configuration may cause options 1 through 3 to result in the Logon Allowed page, and options 4 through 6 to result in the Logon Denied page:
     
    • Option 1
    • Option 2
    • Option 3
    • Option 4
    • Option 5
    • Option 6

    Alternatively, the following Decision Box configuration would cause all options to result in a Logon Allowed page:
     
    • Option 1, Option 2, or Option 3.
    • Option 4, Option 5, or Option 6.

  • Avoid the use of carriage returns in option descriptions.

    For example, the following Decision Box configuration uses multiple carriage returns:
     
    • Option 1
      Sentence one.
      Sentence two.
      Sentence three.
      Sentence four.

    Alternatively, you could enter the same information with limited carriage returns, as in the following example:
     
    • Option 1. Sentence one. Sentence two. Sentence three. Sentence four.
  • Keep option descriptions as brief as possible.
