Description

/var/log/ltm in vCMP host may log similar to below messages:

012c0012:6: FFP (v)DAG installed for guest4 (cmp state 0x0)

This tells the guest is disconnected from the host. Nothing wrong in the host blade. 

in /var/log/tmm* log you should also see similar to below logs, since guest is linked to host blade TMMs:

notice wlite NITROX (p|lv): Consumer unregistered, ping == 0xffff
notice wlite NITROX (p|lv): Consumer unregistered, ping == 0xffff
notice wlite NITROX (p|lv): Consumer unregistered, ping == 0xffff
notice wlite NITROX (p|lv): Consumer unregistered, ping == 0xffff
notice wlite NITROX (p|lv): Successful registration for wlite vcmp type NITROX consumer 0 for guest: 0x23, type: NITROX (key: 0xf7402300)
notice wlite NITROX (p|lv): Successful registration for wlite vcmp type NITROX consumer 1 for guest: 0x23, type: NITROX (key: 0xf7402300)
notice wlite NITROX (p|lv): Successful registration for wlite vcmp type NITROX consumer 2 for guest: 0x23, type: NITROX (key: 0xf7402300)
notice wlite NITROX (p|lv): Successful registration for wlite vcmp type NITROX consumer 3 for guest: 0x23, type: NITROX (key: 0xf7402300)
 

Environment

  • BIG-IP
  • v12.* and later
  • Viprion
     

Cause

The guest was rebooted.
 

Recommended Actions

Check why guest was rebooted.
 

Additional Information

About detail of CMP state, please refer to: K39829934: What is CMP state?
