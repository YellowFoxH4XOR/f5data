Description

HP physicals server have ilo interface which monitoring the hardware equipment.
The iLO4 have 50 sensors which monitoring temperature on different HW components.

The graphical view all sensors via iLO4 WebUI interface [Interfaces ->System Information: Temprature tab]:



Note: The sensor 49-Sys Exhaust and 50-Sys Exhaust indicate the temperature for the chassis and can be used as a reference temperature for the room.
 

Environment

  • Traffix/SDC - HPE hardware
  • iLO 4 interface

Cause

In the HPE hardware infrastructure, you may export values of the temperature sensors.
How to export values of the temperature sensors, out of  the HPE hardware infrastructure?
Which sensors can by use as a  reference temperature for room?                                          

Recommended Actions

The access to the iLO4 sensors can be done via:
  • ssh session to iLO console
  • ipmitool tool run from any linux server
  • iLO4 WebUI interface - only graphical view

  1. The access to the iLO4 sensors via ssh access to the ilo console

  1. Access to the iLO4 sensors via "ipmitool" tool.

The best way to collect the sensor information for further usage is using "ipmitool" installed on the EMS or SDC server or on the external linux server in network with access to the ilo4 console.
The example below is for CentOS7 server.
 
to install "ipmitool" run the command: 
# yum install ipmitool
Then run the command:
# ipmitool -I lanplus -H <iLO ip address> -U <username> -P <password> sensor
On output receive list of all temperature sensors:
e.g
