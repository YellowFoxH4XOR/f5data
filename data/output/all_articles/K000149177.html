Description

What is the procedure when one of System Controller is down and can not boot?

 

Environment

  • F5OS-C
  • Velos
  • Possible hardware failure in Controller

 

Cause

  • general question

 

Recommended Actions

1. While Standby System Controller is not accessible, we recommend not to make any config change in configuration in the Controller and the Partitions, but it is OK to make a config change in tenants. And take backup following the solution below:

K50135154: Back up and restore the F5OS-C configuration on a VELOS system
IMPORTANT: You may not be able to change passphrase and salf phrase when System Controller is standalone. Set this when both System Controllers are working.

 

2. Gather qkview from the Active System Controller, and escalate the case to F5 Support.

We will distinguish software issue and hardware issue. We may need to do remote session to see the accessibility from the Active Controller to Standby Controller.

 

Case-1) Software side of issue, we will fix or provide workaround.

Case-2) Hardware side of issue, we will initiate RMA process.

K000133249: Replacing VELOS system controller after a Return Materials Authorization
NOTE: inserting replacement System controller trigger installing the same version software, and sync the configuration.
