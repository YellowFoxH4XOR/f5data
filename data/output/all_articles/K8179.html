K8179: Importing BIG-IP WebAccelerator version 9.x policies into WebAccelerator version 5.x

Topic

You can import a BIG-IP WebAccelerator version 9.x policy into a WebAccelerator version 5.x system. However, you must first manually edit the database version entry in the policy.

Policy files exported from a BIG-IP WebAccelerator version 9.x system will contain the following database version entry:

<policyGlobals databaseVersion='9.0'>

If you are going to import the policy to a WebAccelerator version 5.x system, you must manually edit the policy file's database version entry to appear as follows:

<policyGlobals databaseVersion='5.0'>

Note: A BIG-IP WebAccelerator version 9.x system can import a WebAccelerator version 5.x policy without editing the database version entry. However, WebAccelerator version 5.x policies with a path entry greater than 256 characters will fail to import to some versions of the BIG-IP WebAccelerator version 9.x.  For more information, refer to K8176: WebAccelerator policy import fails if the policy contains a node with a path greater than 256 characters.
