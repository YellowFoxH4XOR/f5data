K000141269: CAT license status shows "Processing"

Type
Support Solution
Published
2024-09-30
Updated
2025-04-03
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000141269

Description

You need to unassign a CAT license, but its status is "Processing" via the Subscriptions page on My.F5.com Customer Portal.

Environment

  • Catalog (CAT) license keys
  • Flexible Consumption Plan (FCP)
  • My.F5.com Customer Portal Subscriptions
  • BIG-IQ License Manager or Centralized Manager

Cause

Unknown at this point.

Recommended Actions

Contact F5 support to request an allow move on this license.

  1. Open a case via the F5 Customer Portal
    • Logon on to my.f5.com > Support > Create a Case
  2. Request an allow move on the CAT license key, XXXX-XXXX-XXXX-XXXX-ABCDEFG.

After the allow move is complete, the status will read "Ready to Activate" and you can activate this CAT key on the BIG-IQ.

Additional Information

None
