Topic

This article applies to BIG-IP Link Controller version 11.x. For information about other versions, refer to the following article:

  • K12087: Configuring the BIG-IP Link Controller to shorten the time taken to detect a status change in a virtual server (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You require the BIG-IP Link Controller to shorten the time taken to detect a status change in a virtual server.

Description

The BIG-IP Link Controller monitors the availability and performance of multiple ISP connections to intelligently manage incoming and outgoing traffic flows. The BIG-IP Link Controller accomplishes this functionality through selected LTM system and GTM system features over iQuery communication.

To establish an iQuery connection between the two components, the BIG-IP Link Controller automatically assigns a bigip monitor with default settings to itself.  The bigip monitor tells the GTM system side of the BIG-IP Link Controller to connect to its LTM system side and periodically poll its configuration, including the current availability of objects, such as virtual servers.

By default, the bigip monitor has an interval of 30 seconds. Depending on when the next configuration update is due, the GTM side of the BIG-IP Link Controller may take up to 30 seconds to detect a status change in a virtual server. During this time, a wide IP may direct traffic to a virtual server that is currently marked as down by the LTM side of the BIG-IP Link Controller.

You can shorten this process by creating a custom bigip monitor with a shorter interval and assign it to the BIG-IP Link Controller.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have administrative access to the Configuration utility
  • Have administrative access to the Traffic Management Shell (tmsh) utility

Procedures

  • Configuring a custom bigip monitor with a shorter interval
  • Assigning a custom bigip monitor to the BIG-IP Link Controller

Configuring a custom bigip monitor with a shorter interval

To create a custom bigip monitor with a shorter interval, perform the following procedure:

Impact of procedure: None

  1. Log in to the Configuration utility.
  2. Navigate to Link Controller >> Monitors >> Monitor List.
  3. Click the Create button.
  4. In the Name box, type a name for the custom bigip monitor.
  5. From the Type drop-down menu, select BIG-IP.
  6. Enter the desired values for Interval and Timeout.

    Important: F5 recommends that you set an interval of at least 3 seconds. Additionally, the timeout value should be three times the interval value.

  7. Click the Finish button.

Assigning a custom bigip monitor to the BIG-IP Link Controller

You must use the tmsh utility to assign a custom bigip monitor to the BIG-IP Link Controller, as the Configuration utility does not provide an interface for this task. To do so, perform the following procedure:

Impact of procedure: Assigning a custom monitor with shorter interval and timeout may increase load on the BIG-IP Link Controller. depending on the number of objects configured.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.

  2. Assign a custom bigip monitor to the BIG-IP Link Controller by entering the following command:

    modify /gtm server <Link Controller name> monitor <custom monitor name>

    For example, you would enter the following command to assign the custom monitor my_bigip_monitor to BIG-IP Link Controller bigipve5.f5.com:

    modify /gtm server bigipve5.f5.com monitor my_bigip_monitor

  3. Save the change by typing the following command:

    save sys config
