Environment

BIG-IP APM

Access - Federation >> OAth Client / Resource Server : Provider


Cause

Recommended Actions

Firewall rules for connectivity, firewall rules outside BIG-IP were needed for a federation setup using Microsoft Entra.

Analyzed logs from your Firewall and check the IPs needed to allow the discovery task.
