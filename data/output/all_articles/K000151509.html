Description

Whe using the BIG-IP Configuration Utility (GUI), the Local Traffic > Virtual Servers page takes a long time to load or does not load at all. However, other pages (for example, those under the System or Network menu) work just fine.

Environment

  • BIG-IP
  • Configuration Utility (GUI)
  • The "Display Host Names When Possible" setting is enabled (by default, it is disabled)
  • The configured DNS servers are unresponsive or unreachable

Cause

When "Display Host Names When Possible" is enabled, BIG-IP uses the configured DNS servers to display host names on the "Virtual Servers" page. If the DNS servers are unresponsive or unreachable, the DNS resolution process will take a long time to time out or complete. This causes the page to appear unresponsive.

Recommended Actions

  1. Verify if the "Display Host Names When Possible" setting is enabled

    To check in Configuration Utility (GUI), navigate to System > Preferences and check if "Display Host Names When Possible" is enabled/selected.

    To check in tmsh (if value is "true"):

    (tmos)# list sys db ui.system.preferences.displayhostnameswhenpossible all-properties

    sys db ui.system.preferences.displayhostnameswhenpossible {

      default-value "false"

      scf-config "false"

      value "true"   <===

      value-range "false true"

    }

    If the setting is disabled/false, the unresponsiveness is due to a different reason and needs to be further investigated.

  2. If the setting is enabled/true, try disabling it and see if the situation improves.

    To make the change in Configuration Utility (GUI), navigate to System > Preferences.

    To make the change in tmsh:

    (tmos)# modify sys db ui.system.preferences.displayhostnameswhenpossible value false

    After making the change, check if the "Virtual Servers" page displays well.
