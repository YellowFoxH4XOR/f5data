K000138933: [F5OS-C] VELOS connectivity issues after generating a partition Qkview in versions prior to 1.6.4

Type
Support Solution
Published
2024-03-15
Updated
2025-11-17
Applies to
  • F5OS
  • VELOS Platforms
  • F5OS-C: 1.6.4, 1.6.X, 1.6.1, 1.6.0, 1.6.2
Source
https://my.f5.com/manage/s/article/K000138933

Description

If a partition qkview is generated, a number of issues can subsequently occur if blades in the partition have not been rebooted:

  • Tenant connectivity is broken.
  • Incorrect link status reported in F5OS.
  • Interface link state changes not reflected in LAG state.

 

Environment

  • F5OS-C (for VELOS)
  • F5OS-C version is prior to 1.6.4.
  • A partition qkview is generated
  • The blade has not been rebooted since the partition qkview was generated

 

Cause

The following is tracked by Bug ID 1559525.

If a partition qkview is generated, a number of issues can subsequently occur if blades in the partition have not been rebooted:

- If both system controllers are rebooted, backplane connectivity between the blades will fail, resulting in a complete loss of tenant connectivity. The system controllers do not need to be rebooted simultaneously. There will be repeated messages in the partition velos.log showing VQF IMM and EMM watchdogs from all blades in the partition:

Impact

  • F5OS software will report incorrect link status for external interfaces if links change state.
  • The system may continue to treat interfaces configured as members of a LAG as being up even after the interface goes down, resulting in traffic failures.
  • Interfaces that were down at the point a partition Qkview was generated may fail to pass traffic properly even if the link comes up. Traffic will appear in a packet capture, but the system will not transmit egress traffic out the interface.

 

Recommended Actions

You can apply either of the following workarounds.

  • This issue is fixed in version F5OS-C 1.6.4.
  • Follow the workaround in Bug ID 1559525.
  • An Engineering Hotfix (EHF) is available on MyF5 Downloads at https://my.f5.com/manage/s/downloads?productFamily=F5OS&productLine=F5OS_for_VELOS&version=1.6.2&container=1.6.2-EHF. The EHF has fixes that prevent ID 1559525 and ID 1576241 from occurring.
