K12395: A maximum of 30 snapshot rules should be associated with a single schedule

Topic

Configuring an excessive number of snapshot rules to use a single schedule may result in delays, which prevents the creation of the snapshots. To ensure that you gather complete snapshots, do not schedule more than 30 snapshot rules on a single schedule. If you schedule more than 30 snapshots of managed volumes, you must offset the scheduled start times. For example, to schedule snapshots for 72 managed volumes, you should schedule three sets of 24 managed volumes to perform at :00, :20, and :40 of the hour.

F5 Product Development is tracking a Request for Enhancement (RFE) as ID 339306 to improve the scalability for the maximum number of snapshot rules associated with a single schedule.

Note: Some earlier versions of the ARX software have a maximum number of 16 snapshot rules for a single schedule. For information, refer to K9421: Configuring snapshots for more than 16 managed volumes using the same schedule may result in an incomplete snapshot.
