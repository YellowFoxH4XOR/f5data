Description

You must provision vCMP before loading UCS files containing deployed or provisioned vCMP guest instances.

If the BIG-IP system does not have vCMP provisioned, the system is not able to start the vCMP guest instance correctly when loading a UCS saved configuration that contains vCMP guest instances that are in the Provisioned or Deployed state.

For example, a UCS configuration file contains three vCMP guest instances with three different states: Deployed, Provisioned, and Configured. This UCS file was created from a BIG-IP system that was licensed and provisioned with the vCMP module. When this UCS file is applied to a BIG-IP system that is licensed with vCMP, but it has not been provisioned, the system will load the UCS without error. The system will load the three vCMP guest instances as Configured; however, they will not be operational.

Recommendations

Before you load a vCMP-related UCS configuration file, you should ensure that the BIG-IP system is licensed and already provisioned with the vCMP module.

If the UCS file is already loaded, and the vCMP guest instances were already in the Configured state, you can change the state of the affected vCMP guest instances using either the Configuration utility or the Traffic Management Shell (tmsh) utility. To do so, perform one of the following two procedures:

Changing the state of the vCMP guest using the BIG-IP Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to vCMP > Guest List.
  3. To change the state, select the box next to the affected vCMP guest name.
  4. For the selected vCMP guest, select either the Provision or Deploy option.

Changing the state of the vCMP guest using the tmsh utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility.
  2. Change the state of the affected vCMP guest as follows:
    • To provision the desired vCMP guest, use the following command syntax:

      modify /vcmp guest <Name> state provisioned

    • To deploy the desired vCMP guest, use the following command syntax:

      modify /vcmp guest <Name> state deployed

  3. Save configuration by typing the following command:

    save /sys config

  4. Exit the tmsh utility by typing quit.
