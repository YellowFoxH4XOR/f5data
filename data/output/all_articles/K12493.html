Known Issue

When you attempt to use the Configuration utility to update the Start of Authority (SOA) resource record of a BIND zone where the serial number is 2147483647 or greater, the Configuration utility returns an error message that appears similar to the following example:

01150410:3: Error from res_nupdate: No such file or directory.

In addition, ZoneRunner logs this error message to the /var/log/gtm file.

As a result of this issue, you are not able to update the SOA resource record of the affected BIND zone from the Configuration utility. This issue occurs because the BIND implementations included in the BIG-IP system incorrectly evaluate the serial number field as a signed 32 bit integer. RFC1035 defines the serial number field as an unsigned 32 bit integer.

For more information about support for ZoneRunner and BIND, refer to K7176: F5 support for ZoneRunner, BIND, and the named process.

F5 Product Development tracked this issue as ID 344691, and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Resolution

Workaround

You can work around this issue by using the command line to modify the SOA resource record serial number field to be less than 2147483647. To edit the zone file from command line, follow the instructions described in K7032: Freezing zone files to allow manual update to ZoneRunner-managed zone files.
