Topic

The remote logging profile allows an administrator to configure the BIG-IP AFM system to direct log information for IPS events to a syslog server. The following table lists the Storage Format fields and descriptions.

 

Description

You can configure remote logging on the BIG-IP AFM to log detailed IPS events locally or remotely.  The BIG-IP AFM system reports details about events based on the built-in fields created for IPS, when there is not information for a field then you will just see empty quotation marks.  For example you could see a log like below if local syslog is configured (/var/log/ltm):

Note that there are not field names in the above sample, just the values. However, if we log remotely we will be able to see field names in the IPS logs. The following table lists the field names and their meaning that the system uses for remote logging when reporting BIG-IP AFM IPS events.

support_idA unique identifier for http security illegal transaction.

source_portThe source port of the event to which the signature/compliance matched.
dest_ipThe destination IP address of the event to which the signature/compliance matched.
dest_portThe destination port of the event to which the signature/compliance matched.

dest_geoThe packet destination location of the event to which the signature/compliance matched.
