Description

An iApp was deployed, but the objects are created in route domain 0.

Environment

  • iApp
  • Route domains

Cause

Expected behavior.

Recommended Actions

Delete and re-deploy the iApp while specifying the required route domain ID for virtual server and pool member objects, for example 10.10.10.50%2 for route domain 2.

Additional Information

The route domain notation must be used when deploying iApps even when there is a default route domain for the partition.
