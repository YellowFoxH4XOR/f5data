K71435341: iRule not detecting domain with URI::host

Description

iRule utility 'URI::host' parses the host in the following URI as  'example.com\test.com' instead of 'example.com'
 
http://example.com\test.com/?query='
 

Environment

  • iRule
  • BIG-IP v 12.1.2
  • URI::host utility

Cause

The BIG-IP is adhering to the RFC 3986 regarding the use of hierarchical identifiers:

  "The generic syntax uses the slash ("/"), question mark ("?"), and
   number sign ("#") characters to delimit components that are
   significant to the generic parser's hierarchical interpretation of an
   identifier."

Thus the BIG-IP reads the '\'  as an invalid delimiter and ignores it.
