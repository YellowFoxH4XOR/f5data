Known Issue

Harmless error messages are logged when the BIG-IP VIPRION system's management IP address is selected as the Failover Unicast Address.

This issue occurs when all of the following conditions are met:

  • You have multiple VIPRION systems in a high availability (HA) configuration.
  • The BIG-IP systems are configured to use network failover.
  • The BIG-IP system's management IP address, also referred to as the cluster IP address, is selected as the Failover Unicast Address.

Impact

There is no impact. You can safely ignore the specific error message; it should not impact the configured functionality.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/ltm file, you observe error messages similar to the following example:

    err sod[3456]: 010c003b:3: bind fails on recv_sock_fd addr 192.168.10.100 port 1026 error Cannot assign requested address.

Workaround

There is no workaround. To prevent the error message, you can configure the BIG-IP system to use a Failover Multicast Address. To do so, refer to K13915: Configuring network failover for redundant VIPRION systems (11.x).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
