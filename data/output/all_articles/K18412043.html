Description

Following errors  messages are noted under var/log/messages.

notice syslog-ng[15662]: Configuration reload request received, reloading configuration;
warning pendsect[31898]: skipping drive -- Model: ST1000NM0008-2F2100   
warning pendsect[31898]: No known drives detected for pending sector check. Exiting

Environment

  • BIG-IP LTM
  • Cron job
  • Pendsect script

Cause

Hard disk drive model in the system is not listed in /etc/pendsect/drives.xml. Hence during the internal cron job check errors are logged  under /var/log/messages.

Recommended Actions

There is no impact to the system with these logs.

If you want to suppress this message, you can  disable 'pendsect' from cron job by moving out, so that the error messages will be suppressed.

  1. Login to BIGIP using SSH
     
  2.  Navigate to /etc/cron.daily 
    # cd /etc/cron.daily
     
  3. Create new directory called  suppress
    # mkdir suppress
     
  4. Move the pendsect cron job to suppres
    # mv pendsect suppress
     

Additional Information
IMPORTANT: Running this workaround on a BIG-IP running in FIPS or Common Criteria mode will cause the BIG-IP to fail its integrity check on boot.  This will prevent the BIG-IP from booting until the system is reverted.  See: K25205233: BIG-IP System halted while booting. Halt at boot after FIPS Integrity Check Result FAIL
