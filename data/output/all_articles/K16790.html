Known Issue

The Traffic Management Microkernel (TMM) process may produce a core file when the BIG-IP PEM system receives a RADIUS message that has multiple IP addresses and no subscriber ID.

This issue occurs when all of the following conditions are met:

  • The BIG-IP PEM system receives the RADIUS start or stop message, which contains multiple IP addresses.
  • The related RADIUS message does not contain a subscriber ID.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting, and systems configured as part of a high availability (HA) group may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group if configured for HA.
  • The BIG-IP system generates TMM core files to the /var/core directory.
