Description

Unexpected silent reboot occurred and there is no log which indicate the cause, but below messages after reboot and no other Latched Event logged in /var/log/ltm.

warning chmand[<pid>]: 012a0004:4: Host Watchdog timeout count: 1
info chmand[<pid>]: 012a0006:6: Latched Event:0x5: LOP was reset by itself event
info chmand[<pid>]: 012a0006:6: Latched Event:0x7: Host was reset by platform reset event

Environment

  • The BIG-IP platform uses the LBH lights-out management system. The BIG-IP systems that have this functionality include the following platforms:
    • BIG-IP 2000 series
    • BIG-IP 4000 series
    • BIG-IP 5000 series
    • BIG-IP 7000 series
    • BIG-IP 10000 series
    • VIPRION B2250
  • BIG-IP 11.2.1 or later.

Cause

This symptom can appear with various causes, for example software defects, hardware issue, etc.

Further troubleshooting is required to identify the root cause.

The Host Console Capture Buffer (HCCB) allows capturing of the console output to /var/log/ltm.

Recommended Actions

Enable the Host Console Capture Buffer (HCCB) feature following the below procedures.

Important: Do not enable the Host Console Capture Buffer (HCCB) unless requested to do so by an F5 Technical Support representative. You should enable the HCCB only when troubleshooting issues, such as a silent reboot, kernel panic, or other situations when you require the host console output before a host reset. 

Note: Root user access is required.

  • Enabling the HCCB
  • Disabling the HCCB
  • Viewing the HCCB buffer

 

    Enabling the HCCB

    Note: Performing the following procedure should not have a negative impact on your system.

    1. Log in to the AOM and access the AOM menu system.
    2. At the AOM menu prompt, press the "Esc" key, then press "h", and then press "Enter".

      The system displays a message similar to the following:

      Are you sure you want to enable the host console capture buffer? (y/n)

    3. To enable the HCCB, press y.

      The HCCB is enabled, and a new menu option in the AOM menu displays:

      H --- Host Console Capture Buffer

      When you select this menu option H, the current status of the HCCB displays, similar to one of the following two examples:

      The host console capture buffer is actively capturing.
      The host console capture buffer is not actively capturing.

      The following menu options to show or disable the HCCB also display:

      S --- Show host console capture buffer
      D --- Disable host console capture buffer

    Important: If you enabled the HCCB, and it continues to display The host console is not actively capturing message, repeat this procedure.

    Note: After you enable HCCB and restart the system, the buffer is copied to the /var/log/ltm file.

     

      Disabling the HCCB

      Note: Performing the following procedure should not have a negative impact on your system.

      1. Connect to the AOM menu system.
      2. To enter the HCCB menu options, press H.
      3. To disable the host console capture buffer, press D.

        The system displays a message similar to the following:

        Are you sure you want to disable the host console capture buffer? (y/n)

      4. To disable the HCCB, press y and then press Enter.

       

        Viewing the HCCB buffer

        Note: Performing the following procedure should not have a negative impact on your system.

        1. Connect to the AOM menu system.
        2. To enter the HCCB menu options, press H.
        3. To show the contents of the HCCB buffer, press S.

          Additional Information

          The HCCB feature is a 4096-byte circular buffer located in the Always-On Management (AOM)/lights-out processor (LOP) backplane microcontroller (BuC) Hybrid (LBH) that captures host serial console output and places its contents into the /var/log file after a system reboot. This tool is useful for troubleshooting silent reboots and kernel panics.

          When enabled, the HCCB logs the last 4096 bytes of host console data to a buffer within the AOM. This buffer is impervious to host resets and reboots. When the AOM detects a host reset, the system freezes the HCCB buffer and immediately stops logging data to prevent system startup information from overwriting the contents of the buffer. After the system successfully reboots, the following behavior occurs, depending on your version:

          • BIG-IP 11.3.0 and later
            • The chmand process dumps the HCCB host console buffer output to the /var/log/ltm file, which is prefixed with messages that appear similar to the following example:

              May 9 05:53:31 localhost notice chmand[7365]: 012a0005:5: AOM CONSOLE - host is UP
              May 9 05:53:31 localhost notice chmand[7365]: 012a0005:5: AOM CONSOLE - logging capture from host DOWN event
              May 9 05:53:31 localhost notice chmand[7365]: 012a0005:5: AOM CONSOLE +-----------------------------------------------------

            • The system clears the HCCB buffer.
            • The HCCB buffer resumes logging console data.
          • BIG-IP 11.2.1
            • The system does not dump data to the /var/log/ltm file; you must view the buffer manually. For instructions about performing this task, refer to the Viewing the HCCB buffer section.
            • The HCCB buffer remains frozen and does not log further data until you manually disable and re-enable it. For instructions about how to perform these tasks, refer to the Enabling the HCCB and Disabling the HCCB sections.
