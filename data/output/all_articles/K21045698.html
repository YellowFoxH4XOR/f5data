K21045698: Config-Sync fails with default cert/key error

Type
Support Solution
Published
2022-07-13
Updated
2023-02-21
Applies to
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K21045698

Description

Config-Sync fails with SSL error.

  • When trying to initiate a Config-Sync, it does not complete.
  • Config-Sync fails
  • Error message similar to: 
    Sync error on yourdevice.com: Load failed from /Common/yourdevice2.com 01071a78:3: IKEv2 peer (/Common/anonymous): Error reading my-cert-key-file file (/Common/default.key) - error:0D07207B:asn1 encoding routines:ASN1_get_object:header too long.

Environment

Relevant environmental factors specific to the topic

  • Performing normal Config-Sync
  • Device Groups----->Failover Device Group----> Config-Sync
  • BIG-IP LTM

Cause

The default certificate/key is altered or corrupted.

Recommended Actions

Workaround:

  1. K13579: Generating new default certificate and key pairs for BIG-IP SSL profiles

Additional Information
