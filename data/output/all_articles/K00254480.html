Known Issue

A Client SSL profile's current connection statistics counters may be incorrectly incremented.

This issue occurs when all of the following conditions are met:

  • You have a virtual server configured with a Client SSL profile.
  • The virtual server has active connections.
  • You reset the virtual server's statistics.

When you reset the statistics for a Secure Sockets Layer (SSL) virtual server with active connections, the Client SSL profile's current connections counters are re-incremented for the active connections (which were already counted).

Impact

The BIG-IP system presents invalid statistics values for the Client SSL profile.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After resetting a virtual server's statistics, the Client SSL profile's current connection statistics values are double the actual number of current connections.
