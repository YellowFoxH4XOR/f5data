Known Issue

BIG-IP GTM virtual server auto-discovery may unexpectedly add self IP addresses.

This issue occurs when all of the following conditions are met:

  • You enable Virtual Server Discovery on the BIG-IP LTM server object of your BIG-IP GTM configuration.
  • Your BIG-IP LTM configuration contains a default gateway pool.

In certain configurations, the BIG-IP LTM system may contain self IP addresses that are not relevant to the BIG-IP GTM or LTM load balancing configuration, and may not be reachable by the BIG-IP GTM system. Under these conditions, if the BIG-IP GTM system auto-discovers the self IP addresses, unpredictable behavior may occur between the systems.

Impact

The BIG-IP GTM system intermittently marks the BIG-IP LTM server object down.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP LTM server object is unexpectedly marked down.
  • The BIG-IP LTM server object contains self IP addresses that were not intended for inclusion in the BIG-IP GTM configuration.
