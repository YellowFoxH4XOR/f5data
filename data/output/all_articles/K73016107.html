Description

You wish to check easily if BADOS feature is enabled because there are many DoS profiles.

Environment

  • BIG-IP ASM

  • DoS profile

Cause

None

Recommended Actions

You may check if BADOS feature is enabled for each DoS profiles attached to Virtual Servers as follows.

 tmctl adm_stats -s context_name,bados_enabled

For example:

 # tmctl adm_stats -s context_name,bados_enabled
 context_name                    bados_enabled
 ------------------------------- -------------
 /Common/vs-http-1+/Common/dos-1             1
 /Common/vs-http-2+/Common/dos-2             0

If there is no traffic, bados_enabled flag may not be updated.
