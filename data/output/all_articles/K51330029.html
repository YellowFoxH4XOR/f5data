Description

Access Guided Configurations (AGC) may fail with the following error.

  • Access Guided Configuration deployment fails.
  • You observe the following error message in the Admin GUI, "Error: <bigip_management_ip_address> not discovered in any device-group."

Environment

  • BIG-IP Access Policy Manager (APM).
  • Access Guided Configuration.

Cause

The root cause of this issue is unknown at the time of publication.

Recommended Actions

Delete the Application LX deployment that is causing this error:

  1. Login to the BIG-IP Admin GUI.
  2. Navigate the Application>Services>Applications LX.
  3. Select the check box next the Application LX configuration.
  4. Click the Delete button.
