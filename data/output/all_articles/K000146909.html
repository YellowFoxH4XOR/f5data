K000146909: TLS versions on older versions of Windows

Type
Support Solution
Published
2024-11-08
Updated
2025-02-18
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Apps
  • F5 Distributed Cloud Multi-Cloud App Connect
Source
https://my.f5.com/manage/s/article/K000146909

Description

Users may complain that their website visitors can't access a website after a migration to F5® Distributed Cloud Services, and end up with the following error message:

This page can't be displayed

Turn on TLS 1.0, TLS 1.1 and TLS 1.2 in Advanced settings and try connecting to https://www.{} again. If this error persists, it is possible that this site uses an unsupported protocol or cipher suite such as RC4, which is not considered secure. Please contact your site administrator.

 

Environment

  • F5® Distributed Cloud Services load-balancer

Cause 

  • The operating system is out of date, and doesn't support current encryption standards

Resolution

Distributed Cloud Services will not support SSL versions 3.0 or 2.0. These have been deprecated in 2015 and 2011 respectively, and vulnerabilities keep being found in these versions of the protocol. At the time this article is written:

  • TLS 1.3 is the current norm, and has become the default in Windows in August 2020
  • Distributed Cloud Services load-balancers can still be configured to accept TLS 1.0, TLS 1.1 and TLS 1.2
  • The TLS settings can be changed in the load-balancer configuration, see image below
  • Ciphers suites can be changed/extended to accept wider suits and cover more client corner cases
