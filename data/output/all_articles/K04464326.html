Issue

Error Message

notice chmand[PID]: 012a0048:5: Chassis power module 3 turned on.

In this error message, note the following:

  • <PID> is the process ID for the chmand process.

For example:

notice chmand[8834]: 012a0048:5: Chassis power module 3 turned on.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • Power supply 3 is powered on.

Impact

There is no impact. You can safely ignore this error message.

Recommended Actions

None
