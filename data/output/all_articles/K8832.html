Known Issue

This is the result of a known issue. When the BIG-IP processes a request or response that contains an empty cookie value, and the virtual server references an iRule that attempts to set the cookie, the TMM process may crash.

F5 Product Development tracked this issue as CR93910 and it was fixed in BIG-IP LTM 9.4.5. For information about upgrading, refer to the BIG-IP LTM Release Notes.
