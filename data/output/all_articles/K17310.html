Known Issue

Secure Web Gateway (SWG) reports may omit older historical data.  

This issue occurs when the following conditions are met:

  • Your BIG-IP SWG system receives requests that are infrequent or idle for long periods of time.
  • You attempt to view reports from the Configuration utility by navigating to Access Policy > Secure Web Gateway > Overview.

If requests to the BIG-IP SWG system are very infrequent, or idle for long periods of time, the collected data over time may not be aggregated for reporting. This issue prevents historical data from displaying properly in the Access Policy > Secure Web Gateway > Overview section of the Configuration utility.

Impact

Reporting data in the BIG-IP SWG Configuration utility is incomplete.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When examining detailed SWG statistics, you notice that data for Last Day and Last Week is missing.
  • After a user session is created on a previously idle BIG-IP SWG system, the missing data reappears.
