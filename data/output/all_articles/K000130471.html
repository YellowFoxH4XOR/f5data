This topic is divided into four articles. This article covers BIG-IP 11.6.0 HF5. The other three articles cover the following hotfixes:

  • BIG-IP 11.6.0 HF6
  • BIG-IP 11.6.0 HF4
  • BIG-IP 11.6.0 HF3, H2, H1

F5 has recently discovered and corrected a number of issues that affect customers running ARX 6.3.0. F5 recommends that all customers currently running ARX 6.3.0 install the latest cumulative rollup hotfix available.

The following table lists the rollup hotfixes available for ARX 6.3.0. Each hotfix lists the ID number and description for the issues fixed by the hotfix:

Note: These rollup hotfixes are cumulative; each hotfix contains the fixes included in the previous hotfixes.
