Description

Observing below error when attempting to install NGINX Controller Agent

admin@nginx-plus:~$ curl -k -sS -L https://<IP address of Controller>/install/controller-agent > install.sh && \
> sudo API_KEY='604f97591xxxxxxxb9e57b4f7' sh ./install.sh -i instance_nginx # [ this is  the instance_name ]

 --- NGINX Controller Agent package installer ---

 *overriding instance_name value from command line: sg104 ...
  1. Checking admin user ... root, ok.
  2. Preparing environment for NGINX Controller Agent ... Installing agent to run as root
  3. Checking API key ... using 604f97591xxxxxxxb9e57b4f7
  4. Checking if uuid should be stored in the config ... False
  5. Checking OS compatibility ...ubuntu-20  ubuntu detected.
  6. Checking connectivity to the NGINX Controller ... failed to connect to the NGINX Controller

curl: (60) SSL certificate problem: self signed certificate
More details here: https://curl.haxx.se/docs/sslcerts.html

curl failed to verify the legitimacy of the server and therefore could not
establish a secure connection to it. To learn more about this situation and
how to fix it, please visit the web page mentioned above.
 If NGINX Controller instance is using certificate signed by private Certificate Authority, provide --ca-bundle flag.
 To skip NGINX Controller certificate verification, use --insecure flag(not recommended).
 exiting.

 Environment

  • NGINX Controller
  • NGINX Plus

 Cause

NGINX Controller certificate is expired. You can verify in few ways eg:

  • via browser when browsing to NGINX Controller hostname or IP address
  • running command "openssl s_client -connect <NGINX Controller Hostname or IP address>:port

 Recommended Actions

  • Generate new SSL certificate and key
  • Upload to NGINX Controller
  • Run command "/opt/nginx-controller/helper.sh configtls <new SSL cert> <new SSL key>"
  • Once command run successfully, confirm that the SSL cert has been renewed.
  • Proceed to install NGINX Controller Agent on NGINX Plus

 Additional Information

  • Renewing NGINX Controller certificate can take up to 2 minutes. During this time, NGINX controller is inaccessible via GUI
