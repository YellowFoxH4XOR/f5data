Known Issue

This is the result of a known issue. When you use the Network Access Setup Wizard for Remote Access, the Web Applications Setup Wizard for Remote Access, or Web Application Access Management for Local Traffic Virtual Servers, an error message is logged to the /var/log/ltm file that appears similar to the following example:

The child access profile (<Policy name>) must have a valid access policy.

This error message is logged as soon as you enter a name for the policy and click the Next button. This error message should not be generated and can be safely ignored.

F5 Product Development is tracking this issue as ID 306971 (formerly CR127350).
