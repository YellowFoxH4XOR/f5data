Known Issue

TMM may crash if the Proxy SSL feature experiences a memory exhaustion condition.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is licensed to use the Proxy SSL feature.
  • The BIG-IP system experiences a memory exhaustion condition while using the Proxy SSL feature.

Impact

TMM may crash and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H424882 on the Diagnostics > Identified > High screen.
  • TMM crashes and produces a core file.
