Description

When a WIP type A is created via Configuration utility (GUI) the A record may not show up on DNS  ››  Zones : ZoneRunner : Resource Record List.

Environment

  • Configuration utility (GUI).
  • BIG-IP DNS/GTM.
  • WIP.
  • Resource Record List.
  • ZoneRunner.

Cause

  • The WIP does not have a pool member assigned.

Recommended Actions

If the Wide IP does not have a pool member, perform the following option 1. 

Creating the wide IP (Option1)

  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Wide IPs > Wide IP List.
  3. Click Create.
  4. Under General Properties, for Name, type the fully qualified subdomain that is delegated to the BIG-IP DNS system.
  5. For Type, click the DNS query type that the wide IP uses to respond.
  6. Under Pools, for Load Balancing Method click Global Availability.
  7. For Pool List, click the primary pool in the Pool list and click Add. Then, click the secondary pool and click Add. Repeat this step for any additional pools, if necessary.
  8. Click Finished.
If the Wide IP has a pool member and you still see the issue, perform the following option 2:
 
Remove and re-add the pool again (Option 2).
  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Wide IPs > Wide IP List.
  3. Select the Wide IP.
  4. Select the tab Pools.
  5. Select the check box of the pool.
  6. Click Delete
  7. Click Manage
  8. For Pool List, click the primary pool in the Pool list and click Add. Then, click the secondary pool and click Add. Repeat this step for any additional pools, if necessary.
  9. Click Finished.
