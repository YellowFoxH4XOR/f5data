Topic

When running the Policy Builder in Advanced configuration mode, you can specify trusted IP addresses, which are IP addresses that the Policy Builder considers safe.

If you are using the Policy Builder to build the security policy, you should be aware of the differences between running the Policy Builder using trusted IP traffic and non-trusted IP traffic.

Running the Policy Builder using trusted IP traffic

When running the Policy Builder using only trusted IP traffic, the BIG-IP ASM will not sample responses for the trusted IP traffic. As a result, the Policy Builder does not create any dynamic parameters.

Running the Policy Builder using trusted and non-trusted IP traffic

When running the Policy Builder using trusted IP traffic and non-trusted IP traffic, and violations are generated by the non-trusted IP traffic, the BIG-IP ASM system samples responses originating from requests made by both trusted IP traffic and non-trusted traffic.

Note: Dynamic parameters are only created when the BIG-IP ASM system samples responses.
