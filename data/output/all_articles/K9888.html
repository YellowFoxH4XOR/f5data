Known Issue

In BIG-IP WebAccelerator version 9.4.x and 10.0.x, debug logging can be enabled with the expandedAsyncErrors setting in the pvsystem.conf file. When debug logging is enabled, the pvac process may not compute the end of the request headers properly. As a result, the pvac.log file may contain garbled data. This garbled data is random buffer data and can be ignored; it is not relevant for identifying the issue.

Note: The expandedAsyncErrors setting was removed in BIG-IP WebAccelerator version 10.1.0. BIG-IP WebAccelerator version 10.1.0 and higher are not affected by this issue. For information about the expandedAsyncErrors setting, refer to K8991: BIG-IP WebAccelerator logging enhancement to help identify a faulty request and response.

F5 Product Development tracked this issue as CR118630 and it was fixed in BIG-IP 9.4.8. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue was fixed in BIGIP-10.0.1-378.0-HF3 issued for BIG-IP 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
