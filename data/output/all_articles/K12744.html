Known Issue

This is the result of a known issue. If an Apple iOS Edge Client attempts to connect to a FirePass device that does not use a pre-logon sequence, the user may receive the following error message:

Authentication Failed. Unable to obtain authentication token.

The user is unable to authenticate. This error occurs because the Apple iOS Edge Client expects to receive a client version token from FirePass, but FirePass does not send one unless the system uses a pre-logon sequence.

F5 Product Development tracked this issue as ID 349222 and it was fixed in the Apple iOS Edge Client version 1.0.1.

You can download the latest BIG-IP Edge Client for Apple iOS from the following link.

http://itunes.apple.com/us/app/f5-big-ip-edge-client/id411062210

Workaround

You can work around the issue by activating an empty pre-logon sequence. To do so, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users : Endpoint Security : Pre-Logon Sequence screen.
  3. In the New Sequence: section, type a name for the new sequence in the Create new sequence field.
    For Example:

    Apple iOS empty pre-logon sequence

  4. From the Based on: drop down menu, select either template: empty or sequence: empty.
  5. Click the Create button.
  6. Click the edit link for the pre-logon sequence you just created.
    The Pre-Logon Sequence Editor opens.
  7. Optional: By default, the only action is Logon Allowed Page. You may add other actions to the pre-logon sequence from this screen.
  8. After you have finished reviewing the pre-logon sequence, click the Back to Console link located in the upper right corner.
  9. Select the pre-logon sequence you created.
  10. Click the Apply button.
