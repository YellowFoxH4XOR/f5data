Description


This article helps you disable the ICMP redirect messages. ICMP Redirect Messages are network control messages used to convey routing information within a network. When a router receives a packet that should have been sent through a more optimal route, it forwards the packet to the correct path and informs the sender of the better route via an ICMP Redirect Message. Disabling these messages can enhance security by preventing potential manipulation of network routing. To disable ICMP Redirect Messages, one can adjust specific kernel parameters directly within the Linux operating system.
 

Environment

  • BIG-IP system
 

Cause


By default, ICMP Redirect Messages are typically enabled on the BIG-IP systems, which are based on the Linux operating system. To view the current configuration settings for ICMP Redirect Messages on BIG-IP, you can use the sysctl command along with the specific kernel parameter. For instance, to check the status of ICMP Redirect Messages acceptance, you can run the command sysctl net.ipv4.conf.all.accept_redirects. This command queries the BIG-IP system for the current setting of this parameter.
 

Recommended Actions


To disable the aforementioned ICMP Redirect Messages on a BIG-IP system, you can follow the steps below:

1. Log in to the BIG-IP as 'root' user.
2. Run the following commands:

sysctl -w net.ipv4.conf.all.accept_redirects=0
sysctl -w net.ipv4.conf.default.accept_redirects=0
sysctl -w net.ipv4.conf.all.secure_redirects=0
sysctl -w net.ipv4.conf.default.secure_redirects=0
 

These commands will modify the BIG-IP system settings to disallow the processing of ICMP Redirect Messages, enhancing the security and stability of the network configuration. However, it is essential to approach these changes with caution, as there may be devices within your network that rely on ICMP Redirect Messages.
 

Additional Information


For more additional information regarding ICMP redirect messages please check RFC 792.
