K13077: The CSRF protection feature does not apply to iframe elements or framesets

Topic

The BIG-IP ASM system cross-site request forgery (CSRF) feature allows you to protect against CSRF attacks by injecting a JavaScript token into the response pages for certain URLs. You can specify URLs for CSRF protection either explicitly or as wildcards, as shown in the following examples:

  • Explicit URL:

    /myauctionsite/checkout.php

  • Wildcard URL:

    /myauctionsite/*

If a URL specified in the CSRF policy matches a link found in an HTTP response, but the link resides in an embed element or a frameset, the CSRF token will not be applied to the link. For example, the following link within an embed element matches both of the URLs shown previously, but does not have the CSRT token injected:

<embed id="auctionframe" src="/myauction/checkout.php?ACTION=BEGIN" title="" width="444" height="352" name="main" frameborder="0" scrolling="no" marginheight="0"> </embed>

This is expected behavior.
