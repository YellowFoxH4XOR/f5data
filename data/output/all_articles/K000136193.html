K000136193: FQDN Node / Ephemeral pool member pointing to old IP address

Type
Support Solution
Published
2023-09-13
Updated
2023-09-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136193

Description

  • FQDN Node / Ephemeral pool member is marked down.
  • ​​​​​The node IP(s) indicate that they are still referring to the old entries.

Environment

  • BIG-IP LTM
  • Using FQDN nodes or Ephemeral pool members
  • Recently the IPs for the FQDN were changed.

Cause

This happens due to a known bug ID870309

 Recommended Actions

There are two workarounds for this bug. Anyone can be followed. But a dynconfd restart is recommended.

1. Restart the dynconfd daemon using command below: 
# bigstart restart dynconfd
(OR)
 
2. Remove the FQDN pool member, then re-add the FQDN pool member back to the pool
 
Note: Restart of dynconfd temporarily interrupts queries for FQDN name resolution and updates (deletion/creation) of ephemeral nodes/pool members in response to FQDN resolution changes. This should have no impact to traffic.
