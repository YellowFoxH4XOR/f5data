Topic

You should consider using this procedure under the following condition:

  • You want to display Border Gateway Protocol (BGP) and TCP connection information for BGP neighbor sessions.

Description

Using the TMOS Shell (tmsh), you can display BGP and TCP connection information for neighbor sessions. The BGP connection information includes detailed neighbor attribute information, capability, path, and prefix information. The TCP connection information includes statistics related to BGP neighbor session establishment and maintenance.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to tmsh.

Procedures

Displaying BGP and TCP connection information for neighbor sessions

To display BGP and TCP connection information for BGP neighbor sessions, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Access the IMI Shell (imish) by using the following syntax:

    run /util imish -r <route_domain>

    For example, the following command accesses imish for route domain 0, the default route domain:

    run /util imish -r 0

  3. Access Enable mode by entering the following command:

    enable

  4. Display BGP and TCP connection information for neighbor sessions by entering the following command:

    show ip bgp neighbors

Definitions of significant fields in the BGP and TCP connection information for neighbor sessions output
BGP fieldDescription
BGP neighborAutonomous system (AS) number and IP address of the BGP neighbor.
BGP versionBGP version used to establish and maintain the session with the BGP neighbor.
BGP stateIndicates the operational status of the BGP neighbor. The system may report the following states: Idle, Connect, Active, OpenSent, OpenConfirm, Established.
Neighbor capabilitiesIndicates the BGP capabilities advertised and received from the neighbor. When neighbor capabilities are used, a BGP neighbor sends an OPEN message to its BGP peer which may include optional parameters, called Capabilities.
ReceivedTotal number of BGP messages received.
SentNumber of BGP messages sent.
Route Refresh requestThe status of the route refresh requests between BGP neighbors.
Minimum timeThe number of seconds between BGP advertisement transmissions.
Address familyThe BGP address family refers to the type of traffic which BGP can carry, such as IPv4 or IPv6. The For address family field includes the following sub-fields:
  • BGP table version: The version number of the routing table. The routing table number increments when the table changes.
  • AF-dependant capabilities: BGP capabilities that are specific to a particular address family.
Community attribute sentIndicates that send-community-ebgp is configured on the specified address family for this neighbor.
Connections establishedNumber of times the system established a TCP and BGP connection with the neighbor.
Graceful Restart statusIndicates BGP Graceful Restart status and whether Graceful Restart is enabled or disabled for an individual neighbor.
Local hostIP address and BGP port number of the local system.
Foreign hostThe neighbor IP address and BGP port number.
NexthopIPv4 address of the nexthop.
Nexthop globalIPv6 address of the nexthop.
BGP connectionThe status of the BGP session between BGP speakers.
