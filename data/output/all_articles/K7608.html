Topic

In BIG-IP LTM 9.1.x, 9.2.x, 9.3.0, 9.4.0, and 9.4.1, only one partition scheme may be used, which is referred to as the Legacy partition scheme. In BIG-IP 9.3.1 and 9.4.2 through 9.4.8, F5 implemented the Standard partition scheme in order to provide for expansion of the /shared partition for use among multiple boot images running the these versions.

Note: The Standard partition scheme was deprecated as of BIG-IP 10.0.0, when the Logical Volume Management (LVM) scheme was introduced. However, BIG-IP 10.0.x supports the Standard partition scheme. For information about partition scheme options when upgrading to BIG-IP 10.0.x, refer to the release notes for BIG-IP 10.0.x, and the BIG-IP Systems: Getting Started Guide.

Note: BIG-IP 10.1.x software does not support the Legacy partition scheme.

When you upgrade from a BIG-IP version using the Legacy partition scheme (9.1.x, 9.2.x, 9.3.0, 9.4.0, and 9.4.1) to a version that supports the Standard partition scheme (9.3.1 and 9.4.2 through 9.4.8) you may have the option to retain the default Legacy partition scheme or to reformat the drive(s) using the Standard partition scheme. When upgrading a BIG-IP system to one of these versions, you may be presented with the option to reformat the disk using the Standard partition scheme if any of the following conditions is true:

  • You are upgrading a system in which all the slots are empty
  • Your are upgrading all of the system slots
  • You are upgrading a system where the upgrade removes all older versions from other slots

When any of these conditions is true, the installation dialog presents the following prompt:

Do you wish to reformat your disk(s)?

Choosing Yes results in the disk(s) being formatted using the Standard partition scheme. Choosing No results in the disk(s) retaining the Legacy partition scheme.

Important: Reformatting the disk(s) using the Standard partition scheme erases all of the existing files in the/shareddirectory.

Important: Installing an older version of the BIG-IP software which requires the Legacy partition scheme (BIG-IP versions 9.1.x, 9.2.x, 9.3.0, 9.4.0, and 9.4.1) on a system previously formatted with the Standard partition scheme erases all the existing files on the disk(s). Additionally, if you have a BIG-IP system which uses the Standard partition scheme, and you want to install a previous version of the software that requires the Legacy partition scheme, you must use the USB thumb drive or PXE boot installation method to install the previous version. For information about the USB thumb drive and PXE boot installation methods, refer to the BIG-IP LTM release notes.
