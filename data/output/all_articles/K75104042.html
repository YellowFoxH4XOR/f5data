Topic

You can use this F5-supported iApp template to configure the BIG-IP system to act as a forward proxy, decrypting outbound HTTPS traffic so it can be inspected by a security device, which then forwards the traffic to the BIG-IP system for re-encryption and delivery to the destination.

Note: SSL Intercept is a new name for the Air Gap Egress inspection template; release candidate versions of this iApp template were named f5.ssl_airgap_egress.

Description

The SSL Intercept iApp template simplifies deployment and maintenance of the article. To use the Secure Sockets Layer (SSL) category bypass feature available in the iApp template, you must be using BIG-IP 11.5.0 or later versions and have an active URL Filtering subscription.

For instructions about using this template and configuring your BIG-IP system, refer to the Configuring F5 for SSL Intercept deployment guide.

To download and install the iApp template, perform the following procedures:

  • Downloading the iApp template
  • Installing the iApp template

Downloading the iApp template

Important: You must download the file; do not copy and paste the contents.

  1. Go to the F5 Downloads site.
  2. From the Downloads Overview page, click Find a Download.
  3. From the Product Line column, click iApp-Templates.

    The Select a Product Version and Container page displays.

  4. In the Name column, click iApp-Templates.

    A Software Terms and Conditions page displays.

  5. Read the End User Software License Agreement and either accept the license by clicking I Accept, or cancel the process by clicking Cancel.

    If you accept the End User Software License Agreement, the Select a Download page appears, which shows a table with the file name, product description, and file size details.

    Note: After you accept the End User Software License Agreement, the system will not present the agreement again for subsequent downloads that you perform during the same browser session.

  6. From the Filename column of the table, select the file named iapps-x.x.x.x.x.zip.

    For example, the file for the May 2017 iApp release is named iapps-1.0.0.455.0.zip.

  7. F5 supports the FTP, HTTP, and HTTPS protocols for downloading files from F5. Select one of the three supported protocols listed by clicking the Down Arrow.

    A pop-up window appears, prompting you to either open or save the file.

    Note: Some browsers save the file to a default location. You can review your specific browser's documentation to change the default location of where you want to save files.

  8. Select the option to save the file.

Installing the iApp template

  1. Unzip the zip file to a location accessible from your BIG-IP system.
  2. Log in to the Configuration utility.
  3. From the iApp tab, click Templates.
  4. Click Import.
  5. Select the Overwrite Existing Templates check box.
  6. Click Browse.
  7. Browse to the location where you saved the iApp file.
  8. Select the template file that corresponds to the iApp version you want to install.

    For example, the file for the May 2017 release of this iApp is named f5.ssl_intercept.v1.0.1.tmpl.

    Note: Refer to the previously-listed Support Matrix to select the most current supported template for your BIG-IP software version.

  9. Click Upload.

When the upload completes, the iApp is available for use.
