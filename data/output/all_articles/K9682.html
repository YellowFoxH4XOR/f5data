Topic

The ARX 6000 platform requires two system disk drives for operation. The two disk drives provide RAID Level 1 redundancy. These drives contain software images, reports, scripts, log files, and configuration files.

The ARX 6000 platforms were shipped with two different hard disk models. The Maxtor drive model ATLAS10K5_73SCA, and the Seagate drive model SEAGATE ST373455LC.

The model of the drives can be identified by the model number listed in the Disk Details section of the show chassis diskuse command output. The Disk Details section of the show chassis diskuse command output displays similar to the following example:

 Disk Details:
 Disk       Size          State               Transfer Rate   Model
 --------   -----------   -----------------   -------------   -----------------
  Bay 1     68.36G        Online              320MB/sec       ST373455LC
  Bay 2     68.36G        Online              320MB/sec       ST373455LC

Important: In the event of a hard drive failure, the replacement hard drive must be the same model as the existing drive. The ARX system checks the drive geometry to ensure that the replaced drive is the same type and model as the original remaining drive.

If an RMA replacement is required for a failed disk drive, you must provide F5 Networks Support the manufacturer and model number for the remaining drive.

To cross-reference the drive model number to an F5 Networks or IBM part number, refer to the following table:
