Known Issue

This is the result of a known issue. When using the FirePass web proxy, binary content such as files, images, video, and other sources may be corrupted as the FirePass controller inserts additional data into the file. This issue occurs because the FirePass controller proxy engine attempts to write data to redirect content through the FirePass controller.

F5 Product Development tracked this issue as ID 294420 (formerly CR139045-1) and it was fixed in FirePass controller 7.0.0. For information about upgrading, refer to the FirePass release notes. 

Additionally, this issue has been fixed in cumulative HF-610-3-1 issued for FirePass 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.
