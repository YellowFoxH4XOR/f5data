K000132966: Unexpected "Changes Pending" status while viewing Analytics

Type
Support Solution
Published
2023-03-14
Updated
2023-03-14
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000132966

Description

  • While monitoring the analytics for Big-IPs within a high availability sync group, the sync status unexpected updates to "Changes Pending"
  • No changes were made on the Big-IPs

Environment

  • AVR is provisioned

Cause

Opening custom page in Statistics > Analytics > Custom Page automatically created a set of default objects. A banner reports "A set of default widgets was created for the current page".

 Recommended Actions

  1. Sync these changes to the other Big-IPs in the HA sync group.

Additional Information

The audit logs show logs that the user account that opened the custom page created several widgets.

/var/log/audit
AUDIT - client Unknown, user admin - transaction #163537-2 - object 0 - create_if { classification_overview_selection { classification_overview_selection_widget_id "/Common/uwid640f434c4e2e3" 


These logs align with the seven options presented on this page.

  • Blank Widget at the top of the screen
  • Top Virtual Servers by Avg TPS
  • Top URLs
  • Top Pool members by Avg TPS
  • Top client subnets by Avg TPS
  • Top response codes by day
  • Top Countries by day
