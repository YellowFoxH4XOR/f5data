K7730: Certain HTTP headers are ignored when the Ignore no-cache Request Headers or the Ignore no-cache Response Headers options are enabled

Topic

Certain HTTP headers are ignored when the Ignore no-cache Request Headers or Ignore no-cache Response Headers options are enabled in the Lifetime section of a policy. The following HTTP headers are ignored in the HTTP request:
Pragma: no-cache
Cache-Control: no-cache
Cache-Control: no-store
Cache-Control: max-age=0

The following HTTP headers are ignored in the HTTP response:

Pragma: no-cache
Cache-Control: no-cache
Cache-Control: no-store
Cache-Control: max-age=0
Cache-Control: s-maxage=0
Cache-Control: private

Important: An issue exists where the WebAccelerator system will not ignore the Cache-Control: max-age=0 HTTP header, and will proxy the request to the origin web server (OWS). For information about the WebAccelerator system acknowledging the Cache-Control: max-age=0 HTTP header, refer to K7731: WebAccelerator acknowledges the Cache-Control: max-age=0 HTTP header when it should be ignored.

When the Ignore no-cache Request Headers or the Ignore no-cache Response Headers options are enabled in the Lifetime section of a policy, caching is controlled using the following lifetime directive settings:

Note: The lifetime directives are listed by order of priority; therefore if multiple values are present, the WebAccelerator system uses the highest priority value.

Directive settingDescription
No CacheDirects the WebAccelerator system to not cache the content.
OWSDirects the WebAccelerator system to use the OWS lifetime settings.
Min ageSets the minimum time that the content can be stored by the browser.

Note: The default system-wide minimum age configured in the pvsystem.conf file is two seconds. If this policy setting is set to less than two seconds, the system-wide minimum age will be used instead. If a minimum age of less than two seconds is required, you must manually configure the system-wide minimum age setting in the pvsystem.conf file.

Maximum AgeSets the maximum time the WebAccelerator system can store content before revalidating content with OWS.

Note: The default system-wide maximum age configured in the pvsystem.conf file is 24 hours. If this policy setting is set to greater than 24 hours the system-wide maximum age will be used instead. If a maximum age of greater than 24 hours is required, you must manually configure the system-wide maximum age setting in the pvsystem.conf file.

Stand-in PeriodDirects the WebAccelerator system how long to continue serving content from cache when content has expired and the OWS is not responding. After the stand-in period has expired, the WebAccelerator system will return a standard HTTP 404 response page, with a page not found error message.

Note: This setting only applies to content that has been previously cached by the WebAccelerator system.

HTTP Lifetime HeuristicSets the age for content lifetime.

The content expiration for the Lifetime Heuristic is calculated by the following formula: ((current time - last modified time ) * (Heuristic value)) + (current time) = content expiration.

Note: The LAST_MODIFIED HTTP Response header is used for the last modified time value.

For example:
Current time: 11 a.m.
Last modified time: 9 a.m.
Heuristic value: 50%

((11- 9 = 2) * (50%)) + (11) = 12

Content expiration = 12 p.m.
