Description

  • I am getting an error "503- Service unavailable" while using the HTTP load balancer with managed k8s.

Environment

  • F5® Distributed Cloud Console  
  • HTTP load balancer with managed k8s

Cause

When a k8s service refers to a pod which has host networking enabled, the k8s endpoint will use the nodeIP as the endpoint IP. It is not supported for an origin server to be referred to the node IP if it is of type k8s service

Answer/Recommended Actions

To resolve the issue it is suggested to use IP address of Origin Server on given Sites in the origin pool configuration and it would be directly forwarded to the pod rather than via the service as shown in below screenshot:
