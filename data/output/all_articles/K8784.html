Note: Some 5.1.x versions of the ARX Secure Agent software have been removed from the F5 Downloads site. For more information, refer to K11388: Multiple issues with the ARX Secure Agent software version 5.1.x.

Beginning with ARX version 5.2.0 the ARX Secure Agent software, formerly known as the Acopia Secure Agent software, is no longer bundled within the ARX software.

Note: For information, refer to K12394: The ARX Secure Agent software is no longer bundled with the ARX software. You must download the ARX Secure Agent software from the F5 Downloads site. For information about how to download software, refer to K167: Downloading software from F5.

For previous ARX versions, the ARX Secure Agent software may be obtained directly from the ARX system's software directory. The ARX CLI provides copy commands to transfer a file to or from the ARX using the ftp, scp, smtp, or tftp protocols. To copy the ARX Secure Agent software from the ARX system's software directory, perform the following procedure:

  1. Log in to the ARX CLI.
  2. Type the following command:

    show software

    The output should appear similar to the following example:

    Important: ARX software 3.2.1 and higher contain both 32-bit and 64-bit versions of the ARX Secure Agent software. Be sure to select the appropriate software for your Windows Domain Controller. If the file name does not specify 32-bit or 64-bit, then it is 32-bit. The 32-bit ARX Secure Agent is not compatible with 64-bit Windows. 

  3. Note the filename of the ARX Secure Agent software.
  4. Enable privileged mode by typing the following command:

    enable

  5. Copy the software to the target with the appropriate copy software command. 

    For example, the following copy ftp command uses the username user and password password for an FTP server running at 10.0.0.1:

    AskF5ARX# copy software SecureAgentSoftware-32bit.zip 

ftp://user:password@10.0.0.1//tmp/SecureAgentSoftware-32bit.zip

% INFO: The copy command completed successfully.

AskF5ARX#

    Note: For more information and syntax about the copy ftp, copy scp, copy smtp, and copy tftp commands, refer to the ARX CLI Reference Guide.

Note: For information about installing and configuring the ARX Secure Agent software after successfully retrieving it from the ARX software directory, refer to the ARX Secure Agent Installation Guide.
