Issue

Old Behavior

In BIG-IP versions prior to 9.4.7, the system does not require a TMM restart when performing a Federal Information Processing Standards (FIPS) card initialization.

FIPS card initialization can be performed using the following command:

fipsutil -f init

New Behavior

Beginning in BIG-IP 9.4.7, 10.1.x, and later, the system has an updated FIPS driver. After initializing the FIPS card, you must restart the TMM process.

F5 Product Development tracked this change as ID 291442 (formerly CR118391).

Impact

Restarting TMM will disrupt services on the BIG-IP system. F5 recommends that you restart TMM during a maintenance window.

Recommended Actions

After the FIPS card has been initialized, F5 recommends that you restart the TMM processes. To do so, type the following command:

bigstart restart tmm
