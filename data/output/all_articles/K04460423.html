Known Issue

BIG-IP configurations fail to load after you upgrade from 10.x to 12.x.

This issue occurs when all of the following conditions are met:

  • Your configuration contains a configuration object port defined using the service name nat-stun-port.
  • You upgrade from BIG-IP 10.x to 12.x.

This issue is due to changes in the /etc/services file port map name change for port 3478.

Port 3478 service name mapping of the /etc/services file for BIG-IP versions prior to 12.0.0:

# service-name  port/protocol            [aliases ...]     [# comment]

nat-stun-port   3478/tcp                   # Simple Traversal of UDP Through NAT (STUN) port
nat-stun-port   3478/udp                   # Simple Traversal of UDP Through NAT (STUN) port

Port 3478 service name mapping of the /etc/services file for BIG-IP 12.0.0 and later:

# service-name        port/protocol      [aliases ...]             [# comment]

stun            3478/tcp       turn            # Session Traversal Utilities for NAT (STUN) port, TURN over TCP
stun            3478/udp       turn            # Session Traversal Utilities for NAT (STUN) port, TURN over UDP

Impact

The configuration fails to load.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H601682 on the Diagnostics > Identified > High screen.
  • When attempting to load the configuration, the system displays an error message regarding nat-stun-port that appears similar to the following example:

    BIGpipe parsing error (/config/bigpipe/bigip.conf Line 9):
    012e0022:3: The requested value (<ip address>:nat-stun-port {) is invalid (show | <pool member list> | none) [add | delete]) for 'members' in 'pool'

Workaround

To work around this issue, you can manually edit the /config/bigpipe/bigip.conf file, replacing nat-stun-port with the numeric equivalent of 3478. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the recently upgraded BIG-IP system.
  2. To make a backup copy of the /config/bigpipe/bigip.conf file, type the following command:

    cp /config/bigpipe/bigip.conf /config/bigpipe/bigip.conf.599245

  3. Using a text editor, open the /config/bigpipe/bigip.conf file.
  4. Locate all instances of nat-stun-port and replace with the port number 3478.
  5. Save the file modifications.
  6. To load the modified configuration, type the following command:

    /usr/libexec/bigpipe daol

  7. After a successful load of the /config/bigpipe/bigip.conf file, save the configuration by typing the following command:

    tmsh save /sys config

  8. To load the newly saved configuration, type the following command:

    tmsh load /sys config
