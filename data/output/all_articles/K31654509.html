K31654509: BIG-IQ Stats collection agent package fails after upgrade

Type
Support Solution
Published
2022-07-26
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K31654509

Description

Stats collection stops working after upgrading BIG-IQ or BIG-IP device

Environment

  • BIG-IQ/BIG-IP upgrade
  • Stats collection stops working

Cause

Managed devices must be re-discovered after upgrade

Recommended Actions

Following the upgrade, you must re-discover and re-import all managed devices and services to ensure new data is collected.

Additional Information

Manual Chapter : Upgrading to BIG-IQ Version 8.1.0
