Known Issue

This is the result of a known issue. When a user attempts to launch a Network Access connection from the webtop using Firefox 2.x, a blank pop-up window appears and the Network Access connection fails to establish. This issue occurs when the user performs one of the two following actions prior to logon:

  • The user selects the Switch to French link on the logon page
  • The user selects French in the Default Language menu on the logon page, and then selects the Translate UI check box on the logon page

The Switch to French link appears on the logon page if the Default Language menu is set to French and the Choice of Language in logon page check box is not selected in the Advanced Customization section of the Device Management: Customization page. The Default Language menu appears if the Choice of language in logon page check box is selected in the Advanced Customization section of the Device Management: Customization page.
 
F5 Networks Product Development tracked this issue as CR96357 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.
 
Additionally, this issue was fixed in Cumulative Hotfix HF-602-5 issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Workaround
 
Users can work around this issue by not selecting the Switch to French link or the Translate UI check box on the logon page.
