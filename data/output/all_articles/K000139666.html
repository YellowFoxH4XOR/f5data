K000139666: VELOS partition's Images Volume Size available space shows lower value than expected from viewing usage of /var/F5/partition1/IMAGES filesystem

Type
Support Solution
Published
2024-05-17
Updated
2024-05-17
Applies to
  • F5OS
  • F5OS-C: 1.6.X, 1.5.X, 1.6.2, 1.6.1, 1.6.0, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000139666

Description

When viewing available space for a VELOS partition's Images Volume Size from the controller GUI, the available space does not match the output of df -h /var/F5/partition1/IMAGES. The GUI indicates there is less available disk space than expected.

Note: This article assumes a partition ID of 1 (matching the default partition).

Environment

  • VELOS partition
  • Chassis Partitions page in GUI

Cause

The GUI and df output are viewed from the active controller, but the Images Volume Size in the GUI displays available disk space on the controller for which the partition is currently running-active, which might be the other controller, and might have different disk utilisation.

Recommended Actions

Determine which controller is active for a partition by reviewing the output of show partitions.

Connect to the command line of that controller and review the contents of the filesystem:

df -h /var/F5/partition1/IMAGES

find /var/F5/partition1/IMAGES -ls

Space used by the files should be in line with what the GUI displays on the active controller.

The most likely cause for a discrepancy between the controllers would be previous failed image uploads, which might remain behind in /var/F5/partition1/IMAGES/.tmp. Those can be safely deleted.
