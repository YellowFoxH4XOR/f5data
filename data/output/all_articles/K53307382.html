Known Issue

The BIG-IP APM access profile virtual server connection request may receive a TCP reset.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is deployed on an appliance or BIG-IP Virtual Edition (BIG-IP VE).
  • The traffic group associated with the access profile virtual server address of your BIG-IP APM system is configured to use a MAC masquerade address.
  • The virtual server of your access profile is configured with Source Port > Preserve Strict.

Impact

The virtual server connections fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Virtual server connections sporadically receive a TCP reset.
  • When you remove the use of the MAC masquerade address or set the virtual server Source Port setting to Preserve or Change, you no longer see the issue.

Workaround

To work around this issue, you can remove the use of MAC Masquerade, or set the virtual server Source Port setting to Preserve or Change.

Impact of workaround: Removing the use of MAC masquerade address causes network traffic to use the BIG-IP system MAC addresses instead of the singular MAC address that is specified for the traffic group. Changing the Source Port setting of the virtual server may allow the BIG-IP system to modify the source port of the request while the system is processing the modification.
