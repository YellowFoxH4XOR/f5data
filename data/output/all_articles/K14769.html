Known Issue

Description

BIG-IP APM application tunnels may fail to load.

This issue occurs when all of the following conditions are met:

  • You have an access policy that is configured with an application access application tunnel.
  • The application tunnel configuration has an argument string that contains the ampersand character (&).

    For example:

    http://10.10.1.100/login.do?sso=aaa&userid=Bob

  • You attempt to launch an application tunnel from a device that runs the Mac OS X operating system.

Impact

The application tunnel fails to launch.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H428436 on the Diagnostics > Identified > Medium screen.
  • When a user initiates an application tunnel, the application tunnel does not launch.
  • Users with Network Access profiles that allow access to the application tunnel destination can access the resource directly.
