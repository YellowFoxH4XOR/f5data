Issue

Error Message

info get_dossier[<PID>]: 01170019:6: Detected Registration Key-Less dossier generation for CSP.

In this error message, note the following:

  • <PID> is the process ID for the get_dossier utility

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file.

Description

This message occurs when the following condition is met:

  • The BIG-IP system is licensed with an hourly billing license in a cloud environment supported by BIG-IP Virtual Edition (VE).

Impact

There is no impact. You can safely ignore this error message.

Recommended Actions

None
