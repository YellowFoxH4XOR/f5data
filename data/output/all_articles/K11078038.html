K11078038: BIG-IQ Fails to Discover Device after BIG-IP Upgrading

Type
Support Solution
Published
2020-11-02
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IQ
  • BIG-IQ Centralized Management: 6.0.1
Source
https://my.f5.com/manage/s/article/K11078038

DescriptionYou cannot make changes to the Managed BIG-IP device.

Environment

  • Managed BIG-IP Device has been Upgraded

Cause

Bug ID 718796

Recommended Actions

Observe the current status of /mgmt/tm/sys/provision:

  1. SSH to log into the Advanced Shell (bash) prompt of the BIG-IP

  2. Run the following command:

    curl -sku admin:a https://localhost/mgmt/tm/sys/provision | jq -r .
    Note: The response should be a JSON Formatted list of provisioned system modules.

If you observe the following, then proceed to Restart restjavad on BIG-IP and check /mgmt/tm/sys/provision again

{
    "code": 400,
    "message": "Could not allocate base64 BIO.",
    "errorStack": [],
    "apiError": 1
}

Restart restjavad on BIG-IP and check /mgmt/tm/sys/provision again:

  1. SSH to log into the Advanced Shell (bash) prompt of the BIG-IP

  2. Run the following commands:

    tmsh restart sys service restjavad
    Note: Perform this action on the BIG-IP.
    Note: The restjavad daemon provides control-plane access to the BIG-IP using an http REST api.

  3. Check the status of restjavad:
    tmsh show /sys service restjavad

  4. Run the following command to ensure /mgmt/tm/sys/provision has come back up:
    curl -sku admin:a https://localhost/mgmt/tm/sys/provision | jq -r .
