Description

For scripting or automation purposes, how can a SSL certificate serial number be retrieved from the Big-IP SSL certificate list ?

Environment

  • Big-IP 11.x or higher
  • User has tmsh cli login access

Cause

The below tmsh command will retrieve just the serial number from a ssl certificate

# tmsh list sys file ssl-cert <CERTIFICATE NAME> serial-number

So assuming the name of the cert was test then you could run the below command:

# tmsh list sys file ssl-cert test.crt serial-number
sys file ssl-cert test.crt {
    serial-number 313591236
}
