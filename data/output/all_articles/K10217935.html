Description

You need to mask a JSON or XML parameter such as password value in event logs.

Environment

  • Parameter
  • JSON/XML content profile
  • BIG-IP ASM Security Policy

Recommended Actions

  1. Log in to Configuration utility. 
  2. Navigate to Security > Application Security > URLs > Allowed URLs > Allowed HTTP URLs and make sure you are modifying the intended ASM security policy.
  3. Click the URL where the JSON/XML is requested.
  4. Under the URL Properties, set the Allowed URL Properties to Advance.
  5. Click the Header-Based Content Profiles tab.
  6. Make sure that a request header name Content-Type for JSON or XML has an entry and associated with a profile name.
  7. If there is no entry, add using the details below:
    Request Header Name:  Content-Type
    Request Header Value:  *json* (for JSON) or *xml* (for XML)
    Request Body Handling:  JSON or XML 
     
  8. Click Add and make sure that the entry is in the correct order and the profile name is associated.
  9. Select the URL Parameters tab and select Create.
  10. Type the Parameter Name, for example (password). 
  11. For Mask Value in Logs, select the Enabled check box.
  12. Click Create to save changes.
