Topic

During the initial rendezvous of an ARX high availability (HA) pair, the global configuration is synchronized between the senior system to the peer system. The senior ARX system is elected using the following selection criteria:

  • If only one of the ARX systems being paired has a global configuration, the ARX system with the global configuration will be the senior (active) system.
  • If neither of the ARX systems being paired has a global configuration, the ARX system with the numerically lower rendezvous IP address will be the senior (active) system.
  • If both of the ARX systems being paired have a global configuration, the rendezvous will fail.

Supplemental Information

  • For information about configuring an ARX high availability pair, refer to the Configuring Redundancy section of the ARX CLI Network-Management Guide.
