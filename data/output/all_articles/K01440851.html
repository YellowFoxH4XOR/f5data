Topic

You should consider using this procedure under the following conditions:

  • You have enabled the Data Transfer Service (DTS) on the BIG-IQ system.
  • You want to recover from the error state and re-enable DTS after a high availability (HA) auto failover event.

Important: The DTS feature is not currently supported in the BIG-IQ HA configuration and fails during the device state transition in an auto failover event. F5 recommends that you enable DTS only on standalone BIG-IQ devices.

Description

The DTS feature enables the BIG-IQ system to feed application data of the managed BIG-IP devices to the F5 Beacon service. When BIG-IQ HA auto failover is enabled, the standby BIG-IQ system becomes standalone and continues to manage your BIG-IP devices after a failover event. However, DTS will not be recovered until the service is manually initiated again on the newly activated standalone BIG-IQ device. The following procedure describes re-enabling DTS when a BIG-IQ HA auto failover occurs.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have administrative access to the BIG-IQ system.

Procedures

Re-enable DTS

You can re-initiate and re-enable DTS from the BIG-IQ command line. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Verify that the required DTS configuration JSON file is prepared and uploaded to the currently-active standalone BIG-IQ device. To prepare the DTS configuration file, make sure the following fields are properly updated and match the information on the currently-active standalone BIG-IQ device:

    Field nameField value
    biqHost"BIG-IQ IP Address"
    biqUserName"BIG-IQ username"
    biqPassword"BIG-IQ password"
    biqServerCertificate"BIG-IQ server certificate"

    Note: For more information about preparing the configuration JSON file, refer to Set up the Beacon DTS Configuration file.

  2. Log in to the BIG-IQ command line.
  3. To initiate Docker Swarm for DTS, enter the following command:

    data-transfer-service init

  4. To enable DTS, use the following command syntax:

    data-transfer-service start <path_to_config_json_file>

    For example, to enable DTS with the config.json file located in the /var/tmp directory, enter the following command:

    data-transfer-service start /var/tmp/config.json
