Description
Unable to establish a VPN connection from the iPhone, always disconnecting immediately after connecting. 
 

Environment

  • VPN tunnel
  • iOS 12+
  • Proxy in use

Cause
From iOS version 12, apple has implemented stricter security policy, and requires that a proxy pac file be downloaded from an https source and not a http source.
If the network access configuration applies a proxy pac file to be downloaded over a http connection, the pac file will be rejected by the iPhone and this can cause the VPN to immediately disconenct.

 

Recommended Actions

There are 2 possible solutions to workaround this issue.

From the Network Access resource network settings, either: 
  1. Enable the checkbox for "Ignore Client Proxy Autoconfig Script Download Failure"
     
  2. Change the "Client Proxy Autoconfig Script" location to provide the file over https instead of http
