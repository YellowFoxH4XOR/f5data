Known Issue

A VMware View HTML5 client may fail to establish a session with the destination resource.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured for VMware View (PCoIP) Remote Desktop Application Access for VMware Horizon View 7.
  • Users establish an access session using a Google Chrome or Safari browser.
  • Users attempt to launch the VMware View HTML5 client for Horizon 7 from a configured BIG-IP APM webtop resource.

Impact

Users cannot access the VMware resource.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to launch the VMware View HTML5 client for Horizon 7, the system displays a blank page.
  • When using the native VMware Horizon View client, users can access the VMware desktop resource.

Workaround

To work around this issue, you can create and apply an iRule to the affected access profile virtual server to enable access for VMware View HTML5 clients. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of the affected BIG-IP APM device.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. In the new iRule Name box, type a name for the iRule.
  5. In the Definition box, enter the following text:

    when HTTP_REQUEST {
       if { [HTTP::header "Origin"] ne "" } {
          HTTP::header remove "Origin"
       }
    }

  6. Click Finished.
  7. Navigate to Local Traffic > Virtual Servers.
  8. Select the affected virtual server.
  9. Click Resources.
  10. In the iRules section, click Manage.
  11. From the Available column, select the new iRule.
  12. Click << to move the iRule to the Enabled column.
  13. Click Finished.
