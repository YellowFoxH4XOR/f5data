K000138253: Audit logs are not getting stored locally

Type
Support Solution
Published
2024-01-16
Updated
2024-01-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.7
Source
https://my.f5.com/manage/s/article/K000138253

Description

Changes made on the BIG-IP system are not stored locally in audit log file - /var/log/audit

Environment

  • BIGIP LTM
  • TMSH/MCP/GUI  options are enabled under audit logging at following page System ›› Logs : Configuration : Options

Cause

Log filter configuration under System ›› Logs : Configuration : Log Filters will make BIG-IP to send logs to remote server only and doesn't keep copy

For example :

With below configuration all logs with level info or above will be sent remotely (and *only* remotely, no local copy is kept).

sys log-config filter /Common/logfilter {
level info
publisher /Common/logPublisher
}

Recommended Actions

Remove log filter config under System ›› Logs : Configuration : Log Filters
