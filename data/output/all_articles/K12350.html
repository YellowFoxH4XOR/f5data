Topic

This article applies to BIG-IP 9.x through 10.x. For more information about other versions, refer to the following article:

  • K61172462: Enabling or Disabling the Spanning Tree Protocol for a trunk (11.x - 14.x)

You should consider using this procedure under the following condition:

  • Your network design requires disabling or re-enabling the Spanning Tree Protocol (STP).

    Note: STP is enabled by default on all BIG-IP interfaces and should remain enabled unless there is a specific reason to disable the protocol.

Description

The BIG-IP system supports STP, Rapid Spanning Tree Protocol (RSTP), and Multiple Spanning Tree Protocol (MSTP), which prevent bridge loops by blocking redundant network paths.

Note: STP is not supported on BIG-IP Virtual Edition (VE).

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the command line.

Procedures

Impact of procedure: STP is enabled by default on all BIG-IP interfaces to help prevent bridge loops. F5 recommends testing any changes in an appropriate environment.

  1. Log in to the BIG-IP command line.
  2. To disable or enable spanning tree for a trunk object, use the following command syntax:

    bigpipe trunk <trunk_name> stp <disabled or enabled>

    For example, to disable spanning tree for a trunk named test-trunk, type the following command:

    bigpipe trunk test-trunk stp disabled

  3. Save the configuration by typing the following command:

    bigpipe save all
