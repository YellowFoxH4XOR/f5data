Known Issue

When viewing device group information, the BIG-IP system may incorrectly display a previous BIG-IP version installed on other devices.

This issue occurs when all of the following conditions are met:

  • You have upgraded one or more devices in a device group to a newer BIG-IP version.
  • You attempt to view the BIG-IP versions of the other devices in the device group using one of the following methods:
    • The Configuration utility Device Management > Devices menu
    • The tmsh list cm device command

Impact

None. This issue is cosmetic and does not affect BIG-IP system performance.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system displays previous BIG-IP versions rather than the upgraded version.

Workaround

To work around this issue, you can make a change to the device Description field that triggers the device to advertise the correct version. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility for each device in turn.
  2. Navigate to Device Management > Devices.
  3. Click the (Self) device name.
  4. In the Description field, enter some text.

    For example:

    K16544

  5. Click Update.
