K15088: BIG-IP PEM listener virtual servers use a new Any IP (ipother) profile

Type

Published
2014-03-19
Updated

Status

Applies to

Source

Issue

Old Behavior

In versions prior to BIG-IP PEM 11.5.0, when a user creates a PEM listener, the BIG-IP system automatically creates a Forwarding IP virtual server that uses a FastL4 profile. The Forwarding IP virtual server can only classify and apply actions to network traffic that is based on TCP and UDP protocols. The Forwarding IP virtual server simply forwards any other IP protocols, such as ICMP or ESP.

For example, when a user creates a new PEM listener in BIG-IP 11.4.x, the automatically generated Forwarding IP virtual server configuration may appear similar to the following example:

ltm virtual pem11-4_Forwarding_IP {
    description "Used by listener pem11-4"
    destination 0.0.0.0:any
    ip-forward
    mask 255.255.255.255
    profiles {
        fastL4 { }
    }
    source 0.0.0.0/0
    translate-address disabled
    translate-port disabled
    vlans {
        internal
    }
    vlans-enabled
    vs-index 17
}

New Behavior

Beginning in BIG-IP PEM 11.5.0, when a user creates a PEM listener, the ANY IP virtual server uses a new profile called Any IP (ipother). This allows the PEM listener to manage and classify network traffic for several non-TCP/non-UDP protocols, such as IPsec, GRE, IPinIP, ICMP, and SCTP.

For example, when a user creates a new PEM listener in BIG-IP 11.5.0, the configuration of the ANY IP virtual server that is automatically generated using the ipother profile may appear similar to the following example:

ltm virtual pem11-5_ANY_IP {
    description "Used by listener pem11-5"
    destination 0.0.0.0:any
    mask 255.255.255.255
    profiles {
        classification {
            context clientside
        }
        ipother { }
        pem11-5_pem_profile {
            context clientside
        }
    }
    source 0.0.0.0/0
    translate-address disabled
    translate-port disabled
    vlans {
        internal
    }
    vlans-enabled
    vs-index 21
}

Impact

When upgrading to BIG-IP 11.5.0 or later, the BIG-IP system will not automatically apply the configuration of any PEM listener's virtual server to use the ipother profile.

Recommended Actions

After you upgrade to 11.5.0 or later, F5 recommends that you manually configure any Forwarding IP virtual servers created prior to 11.5.0 to use the ipother profile. For more information, refer to K15089: Modifying a PEM listener virtual server to use the Any IP profile.
