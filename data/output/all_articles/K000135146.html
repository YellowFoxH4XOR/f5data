K000135146: WebStatMgr return the error "Unexpected error occurs, Error: Fault 6: SOAP-ENV:Client [[no subcode]]" due to wrong handling of the request type by the process.

Type
Support Solution
Published
2023-06-25
Updated
2024-10-01
Status
Legacy Content
Applies to
  • Traffix SDC: 5.1.0
Source
https://my.f5.com/manage/s/article/K000135146

Description

  • SOAP client request attempted not from SDC nmsagent to Tripo WebStatMgr may cause WebStatMgr to return the following error "Unexpected error occurs, Error: Fault 6: SOAP-ENV:Client [[no subcode]]" due to wrong handling of the request type by the process.

Environment

  • Traffix SDC 5.1
  • Tripo
  • WebStatMgr

Cause

SDC-2299

 Recommended Actions

  1. Allow only SDC nmsagent to connect to WebStatMgr at port TCP:5555.
  2. Alternatively, upgrade to 5.2 CF5 or higher.

Additional Information

None.
