Description

Config Sync fails after upgrade of one of HA pair units to v16.1.2.2 or later version.
GUI shows similar to below message:

Sync Failed

A validation error occurred while syncing to a remote device

Sync error on <host_name>: Load failed from /Common/<device_name> 01070712:3: Caught configuration exception (0), Values (/Common/f5-cc-stip) specified for Cipher Group Rule (/Common/f5-cc-stip 0 /Common/f5-cc-stip): foreign key index (cipher_group_FK) do not point at an item that exists in the database..

Recommended action: Review the error message and determine corrective action on the device

/var/log/ltm has the similar to the below log

err mcpd[<PID>]: 01070712:3: Caught configuration exception (0), Values (/Common/f5-cc-stip) specified for Cipher Group Rule (/Common/f5-cc-stip 0 /Common/f5-cc-stip): foreign key index (cipher_group_FK) do not point at an item that exists in the database..
 

Environment

  • BIG-IP v16.1.2.2 or above
  • HA-Pair
  • Config sync
  • One unit of HA pair upgraded

Cause

From 16.1.2.2 new cipher group rule object called f5-cc-stip is added to support FIPS 140-3 Approved Ciphers which is not available in older version.
IMPORTANT : To have successful config sync, it is always recommended to have same version: K13946: Troubleshooting ConfigSync and device service clustering issues

Recommended Action

Upgrade both BIG-IP hosts to the same version.
NOTE: Sync should be expected to work after the upgrade (bear in mind that 'newly updated unit' will have the latest commit ID).
