Known Issue

This is the result of a known issue. Starting in BIG-IP version 9.4.4, you can configure the SMTP security profile for the BIG-IP ASM system and BIG-IP PSM. When you configure the SMTP security profile, the system provides security checks for SMTP traffic. However, the SMTP profile erroneously appears on BIG-IP systems that are not licensed for the BIG-IP ASM system or BIG-IP PSM.

For example, if you log in to a BIG-IP version 9.4.5 system that is not licensed for either the BIG-IP ASM system or BIG-IP PSM, the SMTP profile is visible in the Configuration utility under Local Traffic > Profiles > Services > SMTP. The SMTP profile provides no functionality and if you associate the profile with a virtual server, you may experience traffic disruption.

Note: To prevent disruption of traffic, do not associate an SMTP profile with a virtual server unless the system is licensed for either the BIG-IP ASM system or BIG-IP PSM.

F5 Networks Product Development is tracking this issue as CR111101.
