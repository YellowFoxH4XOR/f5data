K56662504: BIG-IQ logs incompatible indices mapping

Source

Description
You are unable to add Access service to a BIG-IQ DCD Node and observe the following error message:

Wait for indices failed-status:404, body:{"error":{"root_cause":[{"type":"type_missing_exception","reason":"type[[app-classification]] missing","index_uuid":"_na_","index":"_all"}],"type":"type_missing_exception","reason":"type[[app-classification]] missing","index_uuid":"_na_","index":"_all"},"status":404}

Environment

  • BIG-IQ Centralized Manager (CM)
  • BIG-IQ Device Service Cluster (DCD)
  • Adding DCD's interface for Access service (port 9997)

Cause
Unknown at time of Publication.

Recommended Actions

To resolve need to remove all Access related indices from ElasticSearch
Note: Removing and clearing DCD cluster is fast and ensures no other issues will not linger
  1. In the CM, remove DCD from the GUI.
  2. In the CM, run reset-data-collection-cluster
  3. In the DCD, run clear-rest-storage
  4. In the DCD, complete the initial config utility.
  5. In the CM, add the DCD again

Additional Information

The error message seen is due to incompatible indices mapping.
You may encounter this error message on BIGIQ 6.0.x when someone is trying to add DCD's interface for Access service (port 9997), it won’t work. DCD would log this type of messages noted above.
