K55135543: BIG-IQ Failing upgrade with error: Device installation failed due to Unable to complete software installation for 10.1.1.17 due to timeout

Type
Support Solution
Published
2021-04-07
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
Source
https://my.f5.com/manage/s/article/K55135543

Description
BIG-IQ Upgrade Failing for one DCD device  with error:

[ERROR][25 Mar 2021 12:04:52 MSK][/cm/shared/esmgmt/upgrade/regular/4f6f15dd-0be5-478d-9b5f-a765501184b6/worker RegularClusterUpgradeProcessTaskWorker] Software installation failed for device 10.1.1.17 due to 'Device installation failed due to Unable to complete software installation for 10.1.1.17 due to timeout'. Rolling back.

Affected BIG-IQ DCD node shows

show /sys software

--------------------------------------------------------
Sys::Software Status
Volume  Product  Version   Build  Active  Status

--------------------------------------------------------
HD1.1    BIG-IQ    6.1.0 0.0.1224      no  failed (archive checksum error)  <<<!!!!

Environment

  • BIG-IQ CM and DCD cluster
  • Software upgrade
  • Failing Iso transfer

Cause

Failing iso transfer

Recommended Actions

  1. Manually upload image to affected BIG-IQ DCD node via GUI (System>Software Installations> Images)
  2. Start over installation process according to  Upgrade procedure

Additional Information

None.
