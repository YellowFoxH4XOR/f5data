Description

AWAF is not possible to install Bot Defense Signature Updates:

You see an error while updating Botdefense Signatures in LiveUpdates Page as follow:

Installation Error: Fail handle payload files

In /var/log/tomcat/live_update_upload.log, you see similar logs like below:

apply_bot_signatures|INFO|Feb 07 07:04:22.912|31224|F5::Dos::BotSignatures::load_from_xml,,Cannot send updated objects to mcp: 01b90017:3: Bot signature /botdefense-policy/Bytespider: When the field 'rule' is populated, 'url' and 'user-agent' must be empty.
 01b90017:3: Bot signature /botdefense-policy/Bytespider: When the field 'rule' is populated, 'url' and 'user-agent' must be empty.
apply_bot_signatures|ERR|Feb 07 07:04:22.934|31224|F5::LiveUpdate::PayloadHandler::clean_fail,,Fail load update files: Can't use an undefined value as an ARRAY reference at /usr/local/share/perl5/F5/LiveUpdate/PayloadHandler/BotSignatures.pm line 32.

Environment

  • ASM LiveUpdates
  • Bot Defense

Cause

There is an custom-built Bot Signature named the same as a Bot Signature from F5.

Recommended Actions

Remove and avoid custom-built bot signatures that named the same as Bot Signatures from F5.
