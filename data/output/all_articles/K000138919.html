K000138919: "tmsh load sys config file <file> replace" command throws an error when modifying monitor's default-from setting

Type
Support Solution
Published
2024-03-14
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000138919

Description

The tmsh load sys config file <filename> merge command allows you to modify monitor default-from but the tmsh load sys config file <filename> replace command does not allow that allows you to modify monitor default-from setting and instead returns 01070685:3: Cannot modify the monitor type (defaults from) for monitor /<partition>/<monitor-name> error message

Environment

  • Modifying monitor's defaults-from setting using the tmsh load sys config file <filename> replace command

Cause

Product Engineering is tracking this as a product defect @ ID1562429.

Recommended Actions

A workaround is to utilize tmsh load sys config file <filename> merge command for tasks that require changing the monitor's defaults-from setting.

Additional Information

None.
