K000140935: Installing evaluation VE license forces all VIPs down

Type
Support Solution
Published
2024-09-03
Updated
2024-09-03
Source
https://my.f5.com/manage/s/article/K000140935

Description

  • BIG-IP shows as disconnected after installing new evaluation license.
  • The new license includes an increase in core count.
  • ntlmconnpool is restarting continuously.
  • /var/log/ltm logs may show: Can't connect to CMI peer <peer_ip_address>, TMM outbound listener not yet created messages

 

Environment

  • BIG-IP VE
  • Upgrading license
  • New license includes an increase in VE cores vs the previous license

 

Cause

This is a known issue tracked under Bug ID 870349. This occurs when there's a license update and that the new license changes the number of TMMs available.

 

Recommended Actions

After new, higher core count license is installed reboot the system.
