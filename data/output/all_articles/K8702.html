Known Issue

This is the result of a known issue. When using a FirePass Portal Access favorite to access Citrix published resources, the resources may fail to launch. Depending on the version of Citrix you are running, you may receive one of the following Citrix error messages:

  • An error has occurred while connecting to the requested resource
  • The requested string could not be found

This failure occurs if both of the following conditions are met:

  • The FirePass URL is in the Trusted Sites list of Internet Explorer
  • The user accesses the Citrix resource with the ActiveX control-based Citrix Web Client

This issue does not affect the Citrix Java ICA client or fat clients such as Citrix Program Neighborhood. This issue affects all versions of the Portal Access Web Application engine.

F5 Product Development tracked this issue as ID 269389 (Formerly CR92264) and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Note: For more information, refer to K8444: The FirePass pre-upgrade checklist.

Workaround

Users can work around this issue by performing one of the following two actions:

Removing the FirePass controller's URL from the list of Trusted Sites zone in Internet Explorer

Removing the URL from the Trusted Sites zone may cause the FirePass controller to become unreachable, depending on the configuration of your Internet Explorer and your organization's security policy. For information about configuring the Trusted Sites zone, refer to your Microsoft Internet Explorer documentation.

Configuring a content processing script on the FirePass controller

  1. Log in to the FirePass Administrative Console.
  2. Click Portal Access in the navigation menu.
  3. Click Content Processing.
  4. Click the Preprocessing Scripts tab.
  5. Click the add icon (i-bar) to Add new Favorite, under the Web Applications content Processing Scripts section.
  6. In the Processing script name field, enter a name for the script
    For example:
    Citrix Script
  7. In the URL match patterns field, enter the following text:
    */default.aspx*
  8. In the Content Type field, enter the following text:
    text/html
  9. Leave the Allow caching option cleared.
  10. In the Sed processing field, enter the following text:
    s@launcher.aspx@launch.ica@g
  11. In the Processing drop down menu, select Pre-process response data (before content patching).
  12. Click the Add New button.
