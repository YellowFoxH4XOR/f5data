Description

When a violation occurs in a WAF policy and the traffic is blocked and you want to investigate this, you need to look up the Support ID of the violation.

 

Environment

  • Silverline Portal
  • Silverline WAF

 

Answer/Recommended Actions

To search for related WAF Violation by using Support ID:

1. Navigate to Monitor & Analyze > WAF Violation Summary.

2.  Click on Filter,

3. Select Field > Support ID

4. Select the operator is

5. Paste the Support ID

6. Click Add

7. See How to Read WAF Violation Logs in WAF Violation Summary for how to interpret.

 

Additional Information

The support ID is used to uniquely identify the request that caused the violation 

  • Search for the Support ID for details on violation
  • Include Support ID when contacting the SOC
