Description
After FIPS 140-2 license is installed on BIG-IP FIPS-certified hardware devices, the system halts while booting upon performing the FIPS integrity check.

Environment

  • BIG-IP v15.1.0.4
  • EHF for ID 925989
  • FIPS 140-2  (FIPS full-box license)

Cause
Bug ID 925989: Certain BIG-IP appliances with HSMs cannot upgrade to v15.1.0.4

Recommended Actions
Try to boot into a different volume, if are able to boot there you can install a new instance of 15.1.0.4 with EHF 925989 in a new boot location then you can boot in the new v15.1.0.4.
