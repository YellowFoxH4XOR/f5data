Description

You want to know an SNMP trap in the event of a system reboot.

Environment

  • rSeries F5OS-A
  • SNMP

Recommended Actions

The rSeries F5OS-A will send the SNMP trap with OID .1.3.6.1.4.1.12276.1.1.1.327681 (reboot) when the system reboots. This OID was introduced in F5OS-A version 1.6.0. If you are using F5OS-A version 1.5.x or earlier, you will need to upgrade to version 1.6.0 or later.
