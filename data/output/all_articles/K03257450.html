Description

You have created a rule in network firewall configuration that doesn't appear to be affecting traffic as you expect

Environment

  • BIG-IP AFM
  • Network Firewall rules

Cause

Rules are processed in the order they are listed. If any combination of rules in a single context affect a single traffic flow, the first rule in the rule list will be executed first.

Recommended Actions

  1. Reviewed rule list for the context you are working with
  2. Re-order the rules so that the desired correct rule is executed first
