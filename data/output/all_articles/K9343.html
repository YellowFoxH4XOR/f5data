K9343: Web Application Tunnels and Dynamic Application Tunnels cannot connect to a remote host if the hostname resolves to a 12-digit IP address

Known Issue

If you configure a Web Application Tunnel, and the hostname in the URL resolves in DNS to an IP address containing 12 digits, the Web Application Tunnel fails to connect to the remote web server. This issue does not occur if you configure an IP address instead of a hostname in the URL field. For example, if you configure http://192.168.123.123/index.html in the URL field, the Web Application Tunnel will connect to the remote web server even though the IP address contains 12 digits.

Similarly, if a user launches a Dynamic Application Tunnel and attempts to connect to a hostname that resolves in DNS to an IP address containing 12 digits, the Dynamic Application Tunnel fails to connect to the remote host. This issue does not occur if the user enters a 12-digit IP address instead of a hostname.
 
 
Important: This issue only occurs in FirePass version 6.0.2 after installing cumulative hotfix HF-602-6, HF-602-7.1, or HF-602-7.2.
 
F5 Networks Product Development tracked this issue as CR109849 and it was fixed in FirePass version 6.1.0. For information about upgrading refer to the FirePass Release Notes.
 
Additionally this issue has been fixed in cumulative hotfix HF-602-8 issued for FirePass version 6.0.2, and cumulative hotfix HF-603-1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
 
To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Workaround
 
You can work around this issue by performing one of the following two actions:
  • Web Application Tunnels

    Configure the IP address instead of the hostname in the Web Application URL field, if the website is accessible by its IP address.
  • Dynamic Application Tunnels

    Connect to the IP address of the remote system instead of the hostname.
