Description

All of the active BIG-IP's FQDN based pool members are offline with the reason being DNS server being unavailable. The standby BIG-IP's FQDN based pool members are still online.

 

Environment

- FQDN ephemeral node or pool members are offline with the reason: The DNS server(s) are unavailable

- dynconfd using port 4791 for outgoing DNS requests

- BIG-IP is VE running on hypervisor such as VMWare

- Packet captures show outgoing DNS requests sourced from UDP port 4791, but no answers are seen in the capture

 

Cause

Certain hypervisor interface configurations, such as some in VMware environments, may silently drop UDP packets destined for port 4791. For more information see: https://knowledge.broadcom.com/external/article/396622/udp-packet-destined-for-vm-over-port-479.html

Note: This link takes you to a resource outside of MyF5, and the third party could remove the document without our knowledge.

 

Recommended Actions

Administrators should review and adjust hypervisor settings to ensure proper packet handling and consult vendor documentation for troubleshooting guidance.
