Known Issue

This is the result of a known issue. The BIG-IP GTM system may return some servers in the first position more often than others with the same score, under the following conditions:

  • The Maximum Addresses Returned setting for a pool is set to a value greater than 1.
  • A dynamic load balancing method is configured.
  • Multiple pool members tie for the top score.

F5 Product Development tracked this issue as CR106062 and it was fixed in BIG-IP GTM 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Workaround

To work around this issue, set the value of the Maximum Addresses Returned setting to 1.
