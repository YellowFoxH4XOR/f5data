K000135728: Expired certificate alert in GUI even though there are no expired certificates

Type
Support Solution
Published
2023-08-03
Updated
2023-08-03
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135728

Description

There is a red alert in GUI indicating there are expired or close to expire certificates on the system. But when clicking on the alert or running tmsh check-cert command there are no certificates.


Environment

  • Certificates expiration alert

Cause

False positive/cosmetic.


Recommended Actions

If there are indeed no certificates in all partitions, consider restart the alert:


# tmsh modify sys global-settings gui-expired-cert-alert disabled

# tmsh save sys config


# tmsh modify sys global-settings gui-expired-cert-alert enabled

# tmsh save sys config


Additional Information

tmsh check-cert command comes from https://my.f5.com/manage/s/article/K14318.
