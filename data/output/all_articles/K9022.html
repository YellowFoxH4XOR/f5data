K9022: Entering a backslash character in the Domain admin name field causes Active Directory authentication to fail

Known Issue

This is the result of a known issue. If you configure a master group with Active Directory (AD) authentication, and enter a backslash character ( \ )in the Domain admin name field under the Authentication tab for that master group, FirePass adds an additional backslash character for each backslash character you enter.

For example, if you enter the following in the Domain admin name field:
 
SOMEDOMAIN\administrator
 
FirePass saves the entry as:
 
SOMEDOMAIN\\administrator
 
This causes FirePass to contact the AD server with incorrect administrator credentials, causing AD authentication to fail for that master group.
 
Additionally, if you configure dynamic group mapping with an AD mapping method, and enter a backslash character in the Domain admin name field in the AD mapping method configuration, FirePass adds an additional backslash character for each backslash character you enter. This causes FirePass to contact the AD server with incorrect administrator credentials, causing the AD mapping method to fail.
 
F5 Product Development tracked this issue as CR101342 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.
 
Additionally, cumulative hotfix HF-602-6 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Workaround
 
If the domain administrator account belongs to the same domain you configured in the AD Domain name field, you do not need to specify the domain in the Domain admin name field. For example, enter administrator instead of SOMEDOMAIN\administrator in the Domain admin name field
