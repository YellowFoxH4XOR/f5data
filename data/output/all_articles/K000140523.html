Description

Bruteforce was set with failed login attempts as number N: We expected on the N+1th attempt failed login users should get captcha response page.

But sometimes captcha page only shown on the N+2th attempt, or even larger number of attempts.

Environment

  • Brute Force Protection is enabled in ASM Policy.

Cause

On every 10s we have an aggregation process for the username count brute_force_object_collect_process.

Take this as an example, we have set 3 failed logins allowed: 

There were 3 failed logins between aggregation phases (brute_force_object_collect_process).Previous threshold was at 1/3, when it was updated it became 4/3 at the end of the aggregation phase:

    BRUTE_FORCE_ENFORCER|DEBUG |Jul 04 09:11:01.380|26853|brute_force.c:0482|brute_force_enforce_source_threshold: username action none failed logins/threshold 1/3   <=== Previous Aggregation, we have 1 attempt
    BRUTE_FORCE_ENFORCER|INFO  |Jul 04 09:11:02.284|26854|brute_force.c:1246|brute_force_object_collect_process                                        
    BRUTE_FORCE_ENFORCER|DEBUG |Jul 04 09:11:02.420|26853|brute_force.c:2075|brute_force_source_count_failed_logins: username counted failed login
    BRUTE_FORCE_ENFORCER|DEBUG |Jul 04 09:11:04.170|26850|brute_force.c:2075|brute_force_source_count_failed_logins: username counted failed login
    BRUTE_FORCE_ENFORCER|DEBUG |Jul 04 09:11:05.751|26850|brute_force.c:2075|brute_force_source_count_failed_logins: username counted failed login <=== 4th attempt: We are not yet having login count aggregated.

    BRUTE_FORCE_ENFORCER|INFO |Jul 04 09:11:13.340|26854|brute_force.c:1246|brute_force_object_collect_process  <=== Now Aggregated
    BRUTE_FORCE_ENFORCER|DEBUG |Jul 04 09:11:13.340|26854|brute_force.c:0482|brute_force_enforce_source_threshold: username action captcha failed logins/threshold 4/3 

Another aggregation phase continued, and new failed login went to 5/3.

    BRUTE_FORCE_ENFORCER|DEBUG |Jul 04 09:11:15.262|26850|brute_force.c:2075|brute_force_source_count_failed_logins: username counted failed login <=== 5th attempt: Start to see block page
