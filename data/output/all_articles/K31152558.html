Description

Software installation failed on vCMP guest and lind restart.
Also the similar to below log and the command output are observed:

/var/log/daemon.log

logger: Re-starting lind


/var/log/ltm

err lind[<pid>]: 013c0004:3: unmount failed Invalid argument
notice mcpd[<pid>]: 01070410:5: Removed subscription with subscriber id lind
err lind[<pid>]: 013c0004:3: Fatal error: block id new probe failed - device file:/dev/cdrom
info lind[<pid>]: 0114002b:6: HA software_update lind enabled.
 

tmsh show sys software

--------------------------------------------------------------
Sys::Software Status
Volume  Slot  Product   Version  Build  Active          Status
--------------------------------------------------------------
HD1.1      1     none      none   none      no  upgrade needed <--- where installation was attempted
HD1.1      2     none      none   none      no  upgrade needed <--- where installation was attempted
HD1.2      1   BIG-IP  13.1.1.2  0.0.4     yes         audited
HD1.2      2   BIG-IP  13.1.1.2  0.0.4     yes         audited


Environment

  • vCMP guest
  • Software installation failure
     

Cause

Permissions to ISO image on the vCMP Host don't allow to install the software on vCMP Guest.

-rwx------. 2 root   webusers 2253223936 Apr 29 12:49 BIGIP-14.1.0.3-0.0.6.iso


Recommended Actions: Change permissions to:

-rw-r--r--. 2 root   webusers 2253223936 Apr 29 12:49 BIGIP-14.1.0.3-0.0.6.iso

 

Recommended Actions

  1. Log in to CLI on HOST with administrater or more level user.
     
  2. Run the following command on HOST:
    clsh chmod 644 /shared/images/<problematic_iso_file_name>
     
  3. Log in to CLI on Guest with administrator or above level user.
     
  4. Restart lind on Guest:
    tmsh restart sys service lind
