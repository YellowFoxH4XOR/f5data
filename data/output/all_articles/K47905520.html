Issue

Error Message

err scriptd[<PID>]: 014f0017:3: Perpetual handler (<handler name>) exited with failure

In this error message, note the following:

  • <PID> is the process ID of scriptd.
  • <handler name> is the name of the iCall perpetual handler

For example:

err scriptd[6765]: 014f0017:3: Perpetual handler (/Common/my_handler) exited with failure

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • An iCall perpetual handler object is deleted or the scriptd process is terminated.

Impact

The iCall perpetual handler does not process events or initiate scripts until restarted.

Recommended Actions

If you encounter this error message, restart the perpetual handler using the TMOS shell (tmsh). To do so, perform the following procedure:

Impact of workaround: Since the perpetual handler is not running, restarting it should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Use the following command syntax, where <name> is the affected handler name:

    restart /sys icall handler perpetual <name>

    For example:

    restart sys icall handler perpetual my_handler

  3. To exit tmsh, type the following command:

    q
