Description

The mysql daemon is continuously restarting and the /var/lib/mysql partition is 100% full, which it what's causing mysql to be restarted continuously.

Environment

Relevant environmental factors:

  • BigIP with AVR and ASM or APM Provisioned, which utilize the mySQL DB. 
  • BigIP's /var/lib/mysql partition 100% full

Cause

When the /var/lib/mysql partition is 100% full, the mysql daemon cannot be started successfully. Thus, space must be freed in order to allow mysql to start and run successfully. 
or
K36942191: Advanced WAF and BIG-IP ASM MySQL database vulnerability CVE-2021-23053

Recommended Actions

To free disk space in the /var/lib/mysql partition, perform the procedure below:

  1. Stop the monpd daemon:

    tmsh stop /sys service monpd

  2. Delete all files from the below location:

    rm -f /var/lib/mysql/AVR/*

  3. Create the below file to re-initiate AVR:

    touch /var/avr/init_avrdb

  4. Restart mysql and monpd:

    tmsh restart /sys service mysql
    tmsh restart /sys service monpd
