Known Issue

BIG-IP DNS (formerly known as BIG-IP GTM) and BIG-IP LTM systems use hard-coded AES/3DES ciphers for the iQuery protocol used to communicate securely. These ciphers are no longer considered secure.

This issue occurs when the following condition is met:

  • Your BIG-IP systems use iQuery (TCP/4353) to communicate.

Impact

There is no impact to the BIG-IP system; iQuery will continue to function.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Network security scans may flag these services as not secure.

Workaround

To work around this issue, you can set up firewall access for TCP port 4353 if iQuery communication is not needed, or you can restrict access to only trusted hosts.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
