Description

When creating a new SNMPv3 agent on the GUI on System > SNMP > Agent > Access (v3), and selecting MD5 for the Authentication field, you get an error similar to the following:

Exception caught in Management::urn:iControl:Management/SNMPConfiguration::set_create_user()
Exception: Common::OperationFailed
primary_error_code : 17238275 (0x01070903)
secondary_error_code : 0
error_string : 01070903:3: Constraint 'no auth protocol requires that there be no auth password' failed for '/Common/<Agent_Name>'

You can also find the following log on /var/log/ltm:

err mcpd[<PID>]: 01070903:3: Constraint 'no auth protocol requires that there be no auth password' failed for '/Common/<Agent_Name>'

Environment

  • On version 15.1.0.4
  • SNMPv3 Agent
  • GUI

Cause

A new ID has been filed to track this issue: Bug-ID 929821: GUI unable to create SNMP v3 user if MD5.

Recommended Actions

To workaround the issue on affected versions, you can create the user using tmsh command line as explained on: K15731024: How to create a SNMPv3 user via TMOS.

Alternatively, you can create the user on the GUI using SHA Authentication, and then modify the authentication to MD5 on tmsh with:

modify sys snmp users modify { <Agent_Name> { auth-protocol md5 } }
