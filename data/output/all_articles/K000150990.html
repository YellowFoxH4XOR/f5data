Description

This article describes the steps to create a BIG-IP health monitor for an Oracle database server.

 

Environment

  • Product: BIG-IP Local Traffic Manager (LTM)
  • Health monitor type: Oracle monitor
  • Oracle Database

Cause

None

Recommended Actions

In the BIG-IP GUI/Configuration utility:

  1. On the main window, expand Local Traffic, and then click Monitors.
  2. Click the Create button.
  3. In the Name box, type a name, e.g., oracle_monitor
  4. From the Type list, select Oracle.
  5. From the Configuration list, select Advanced.
  6. In the Interval box, specify the value that you used for your Oracle TCP.CONNECT_TIMEOUT setting, e.g., 10. If you did not specify a value for the Oracle setting, leave the Interval value as the default.
  7. In the Timeout box, type a timeout that is 3 times the value of the interval +1, e.g., 31.
  8. In the Send String box, type the SQL query you want to perform at regular intervals for monitoring, e.g.:
    SELECT status FROM v$instance
  9. In the Receive String box, type the response you expect to get back from your SQL query, e.g., OPEN
  10. In the User Name box, specify the user you created specifically for monitoring, e.g., bigip.
  11. In the Password box, type the associated password.
  12. In the Connection String box, type the valid Oracle Net connection string you want to use to connect to your database; this is a free-form field.
    The variables %node_ip% and %node_port% in the Connection String are dynamically substituted with the IP address and Port number of the Oracle Database instance to which the monitor is connecting.
    Example:
    (DESCRIPTION=(ADDRESS=(PROTOCOL=tcp)(HOST=%node_ip%)(PORT=%node_port%))(CONNECT_DATA=(SERVICE_NAME=primary))(SERVER=dedicated))
    Where SERVICE_NAME=primary specifies which Database service you want to health check.
  13. The Receive Row and Receive Column boxes allow you to handle a SQL query that returns multiple results. If you know what you are looking for is in a specific spot in a multi-line, multi-column result, this is where you would define it, e.g., 1 for both boxes.
  14. Click the Finished button. The new monitor is added to the Monitor list.

Additional Information

To verify that the input query is correct and to see its corresponding output,  in the Oracle DB server, run the desired Oracle select query command. Once verified, use the same query command and DB information, e.g., server/table details in the Oracle Health Monitor being created.
