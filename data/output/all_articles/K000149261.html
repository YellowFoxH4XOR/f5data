Description

You want to check if your HTTP/3 traffic can be secured with BIG-IP ASM based implementations (Attack Signature checks, Violations, Compliance,...). 

Environment

  • BIG-IP ASM
  • HTTP/3 traffic

Cause

None

Recommended Actions

HTTP/3 is not currently supported on BIG-IP ASM. However, RFEs (Requests for Enhancement) have been raised, and support for HTTP/3 is planned for a future release.

You can implement HTTP/3 with LTM, but the following limitations apply (at time of publishing this article):

  • There is no HTTP/3 full-proxy (client side and server side) support; therefore, you cannot use HTTP/3 on the server side.
  • There is no HTTP/2 support on the server side.
  • Only HTTP/1.1 is supported on the server side (RFE has been raised for this as well.)
