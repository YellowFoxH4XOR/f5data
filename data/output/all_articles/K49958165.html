Description

With ASM/Advanced WAF provisioned, SMTP security profile is available for SMTP profile only. SMTPS profile is not supported.

Environment

  • BIG-IP System

  • ASM or Advanced WAF provisioned

  • SMTP security profile

Cause

This is by current design.

Recommended Actions

With the current design, SMTPS profile is not supported for SMTP security profile. You may contact your F5 Sales to request new RFE for this.
