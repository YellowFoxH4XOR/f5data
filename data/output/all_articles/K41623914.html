Description

While working projects over Microsoft Sharepoint through APM PortalAccess, you may get prompted with an error message when saving changes.
Typical error message:
The project has been updated in another session and the current data may no longer be valid.
Refresh the page to see the most current data for the project.

Environment

  • You're using BIGIP APM
  • The application is delivered to users through the PortalAccess technology
  • The application in use is: Microsoft Project Server.

Cause

The difficulty may be due to the BIGIP Analytics profile being attached to the Virtual Server.
Here is what it looks like in the GUI:

Here is how it looks like in the /config/bigip.conf file: 

ltm virtual /Common/main_VS {
    [...]
    profiles {
        /Common/analytics { } <--------- [The Analytics profile]
      [...]
    }
[...]
}

Recommended Actions

Suggest detaching the BIG-IP Analytics profile from the Virtual Server.
