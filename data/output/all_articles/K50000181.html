Issue

Description

  • After an upgrade or restart of the device, the Configuration utility does not restart.
  • The configuration fails to load.
  • When running the command tmsh load sys config verify command, the BIG-IP generates an error message similar to the following:

    01070734:3: Configuration error: Can't associate (/Common/iAPP_folderName.app/iAPP_name_443-Test_wan-optimized-compression) with folder (/Common/iAPP_folderName.app) folder does not exist.
    Unexpected Error: Loading configuration process failed.

Environment

  • iApps

Cause

A profile is referenced by an iApp that no longer exists but is still referenced in the BIG-IP configuration file.

Recommended Actions

You can resolve this by noting the section of the affected BIG-IP configuration file and manually editing the configuration file to remove the profile reference. To do so, perform the following procedure:

Impact of workaround: You should perform the following procedure during a maintenance window, as traffic may be temporarily disrupted while the edited configuration loads.

  1. Log in to the BIG-IP command line.
  2. Make a backup copy of the affected configuration file by using the following syntax:

    cp -p /config/<bigip_configuration_file> /config/<bigip_configuration_file>.bak

    For example,

    cp -p /config/bigip.conf /config/bigip.conf.bak

  3. Edit the BIG-IP configuration file using a text editor of your choice. For example, vi /config/bigip.conf.
  4. Remove the profile reference from configuration file.
  5. Save the changes and exit the text editor.
  6. Load the configuration from the modified configuration file by typing the following command:

    tmsh load sys config
