K000135014: Unable to view network summary after 16.1.3.2 software update

Type
Support Solution
Published
2025-03-07
Updated
2026-07-17
Status
Legacy Content
Applies to

  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135014

Description

After upgrading from 13.1.3.6 to 16.1.3.2, the network map summary of all objects isn't available.

Environment

  • BIG-IP
  • Upgrade from 13.1.x to 16.1.3.2

Cause

The summary information was moved to a different location. 

Recommended Actions

Access this new location to view the summary.

On the BIG-IP, navigate to Statistics > Module Statistics > Local Traffic > Statistics Type [drop down menu] : Status Summary

Additional Information

None
