Known Issue

The SSL::sessionid iRules command may return incorrect values.

This issue occurs when all of the following conditions are met:

  • You configure an iRule with the SSL::sessionid command to retrieve the session ID.
  • The iRule is associated with a virtual server that processes Secure Sockets Layer (SSL) traffic.

Impact

The value returned by the SSL:sessionid iRules command does not match the SSL session ID presented by the client.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The SSL session ID returned by the SSL::sessionid iRules command contains random values or is invalid.
  • iRules using the SSL::sessionid command fail to function properly.
