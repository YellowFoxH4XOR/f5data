Description

You applied the workaround mentioned in Bug ID 1298029, but you found that the value(4194304) was changed back to the default(32768) when you rebooted the box.

Environment

  • BIG-IP LTM
  • BIG-IP DNS
  • Database monitor

Cause

Bug ID 1298029: DB_monitor may end the wrong processes

Recommended Actions

If you want to make the value permanent after the box reboot, then you may run the below command, add the following line to your /etc/sysctl.conf file, and then run the "sysctl -p" command to apply the changes:
# echo kernel.pid_max = 4194304 >> /etc/sysctl.conf && sysctl -p

Instead of applying the bug workaround mentioned in the recommended actions, you can upgrade the software to version v17.1.1 or above with the bug fixes.

Note: You can follow the above steps to change it to the permanent value, but you should also need to periodically clean up with PID files in the command of find /var/run/ -iname \*SQL__* -mtime +1 -exec rm -vf '{}' ';'
