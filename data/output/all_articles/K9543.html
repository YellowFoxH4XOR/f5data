Known Issue

This is the result of a known issue. If you configure a FirePass web service to request a client certificate, FirePass requests the certificate at user logon. However, if the user launches a Network Access connection or an Application Access resource (such as an Application Tunnel or Terminal Server favorite), and the user’s master group requires a client certificate for logon, FirePass may incorrectly request the client certificate one or more times before launching the resource.

F5 Networks Product Development tracked this issue as CR70987 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

This issue has been fixed in cumulative hotfix HF-603-2.1, which has been issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
