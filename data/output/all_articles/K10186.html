Topic

Previously, OPSWAT hotfixes used the versioning schema 2.5.x. For example, OPSWAT 2.5.18. These version numbers are determined by OPSWAT, Inc., and not F5 Networks. OPSWAT, Inc. has recently changed its versioning schema from 2.5.x to 3.4.x; newer OPSWAT hotfixes on the F5 Networks Downloads site will reflect this change. Customers should not be concerned with the versioning change, since the same features and functionality will be present in the 3.4.x OPSWAT hotfixes. 

Note: For more information about OPSWAT hotfixes, refer to K6664: Obtaining and installing OPSWAT hotfixes.
