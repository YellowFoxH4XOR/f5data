Known Issue

This is the result of a known issue. Setting the priority on pool members affects member ratio and node ratio load balancing even if the Priority Group Activation setting is disabled. The BIG-IP system incorrectly honors the priority setting when determining the ratio value for the pool member or the node, which results in an incorrect overall ratio.

F5 Product Development tracked this issue as ID 324872 (formerly CR99587). This issue does not affect BIG-IP 10.1.0 and later versions.

Workaround

You can work around this issue by removing priorities from pool members if the Priority Group Activation setting is disabled.
