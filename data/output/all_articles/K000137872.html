Description

This article intends to explain the meaning of message:

 

Feb 4 00:10:50 zebos-1 OSPF[29739]: OSPF : Received self originated Router LSA with router ID 1.1.1.1 in area 0.0.0.0 on interface Internal Current Router LSA Sequence no : 0x80000021, Received Router LSA sequence no : 0x80000021

 

Environment

BIG-IP

OSPF enabled (on the BIG-IP device)

 

Cause

This message was introduced with the fix for ID965457. It is benign and it simply indicates that an LSA which the BIG-IP generated has been flooded back.

It is typical for OSPF routers, when receiving a new LSA, to install it and then flood it back to the network. It is entirely possible (and benign) to receive a self-originated LSA via another router due to the flooding process.

 

Recommended Actions

This is benign, so no action needed. It is just an informational message.

 

Additional Information

To provide some context, before the fix for ID965457 a message regarding 'Detected router with duplicate router ID' was seen when a self-generated LSA was flooded back to us. This was obviously a false-positive. So in order to differentiate a true duplicate router-id detection with the scenario where the BIG-IP generates an LSA and it is flooded back to itself (benign) the above log message 'Received self originated Router LSA <...>' was created.
