Description

You may find the following error log at /var/log/ltm, you want to know why the BIG-IP generates the message.

err tmm1[<pid>]: 01010276:3: Crypto codec error: sw_crypto RSA private decrypt error OpenSSL error:04065072:rsa routines:RSA_EAY_PRIVATE_DECRYPT:padding check failed

Environment

  • BIG-IP LTM
  • Client SSL profile
  • RSA 

Cause

The log usually indicates an incorrectly formatted SSL record.

The situation occurs when a client sends an invalid value to the virtual server during an SSL handshake(padding check failed). When this happens, the connection will abort. Sometimes, it may happen when an attacker probes the network for a security vulnerability in SSL negotiation.

Recommended Actions

Normally, you can safely ignore this log. 

If you find the BIG-IP generates the message when normal users visit an HTTPS virtual server, you can contact F5 Support for further analysis.

Additional Information

None.
