K000137632: Problem accessing BIG-IQ GUI for specific user. User automatically logged out

Support Solution
Published
2023-11-21

2023-11-21
Applies to

  • BIG-IQ Centralized Management: 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000137632

Description

After loging in to BIG-IQ CM GUI page is not loading for one user. Some redirections are spotted when loading default page and user is logged out. No specific errors visible in BIG-IQ logs

 

Environment

  • BIG-IQ CM
  • Gui login issue for specific user
  • RBAC configured

Cause

Possibly wrong link opened by default caused problems with opening BIG-IQ GUI

Recommended Actions

Try to open specific link to BIG-IQ comfiguration objects before logging in

 

1. Open page before login https://<BIGIQ-IP>/ui/configuration/ltm/virtual-servers

Note replace <BIGIQ-IP> with proper IQ ip address

2. Enter login credentials

Additional Information

After logging to big-iq system is opening latest opened tab of BIG-IQ
