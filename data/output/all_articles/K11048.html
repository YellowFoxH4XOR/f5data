Known Issue

This is the result of a known issue. The BIG-IP 6900 platform fiber ports (interfaces 2.1 and 2.2) may not negotiate interface pause settings properly with Cisco switches. When the Flow Control is set to Pause None, and the requested media is set to auto, the Cisco switch may detect that pause frames are still enabled on the BIG-IP system. This can cause LACP trunks to fail as the Cisco side will see flow control being enabled.

F5 Networks Product Development is tracking this issue as CR134482.

Workaround

To work around this issue, you can set the fiber link to 1000BaseSX Full. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Network.
  3. Click Interfaces.
  4. Click the fiber port that is not negotiating properly with the Cisco switch.
  5. From the SFP Requested Media drop-down menu, select 1000BaseSX Full.
  6. Click Update.
