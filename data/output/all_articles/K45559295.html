Description

The BIG-IQ can import BIG-IP ASM security alerts and proceed to forward them to the F5 SOA (monitor.f5.com). These security alerts will be forwarded from the BIG-IQ DCD.

This article addresses why the security alerts are not be sent or intermittently sent from the BIG-IQ DCD to the F5 SOA when there is a proxy server between them.

The /var/log/restjavad logs will have entries similar to this which shows alerts are not forwarded:

Environment

  • BIG-IQ
  • BIG-IP ASM security alerts
  • F5 SOA (monitor.f5.com)
  • BIG-IQ DCD intermittently or always not sending the security alerts to the F5 SOA
  • There is a proxy server between the BIG-IQ DCD and F5 SOA.

Cause

The proxy server is dropping/denying the BIG-IQ DCD from sending the security alerts to the F5 SOA.

Recommended Actions

Contact the proxy server administrator and allow all traffic between the BIG-IQ DCD and F5 SOA (monitor.f5.com).
