Topic

You should consider using this procedure under the following condition:

  • You want to display the management IP address for your BIG-IQ system.

To configure the management IP address of the BIG-IQ system, refer to K99418679: Modifying the discovery address or management address of the BIG-IQ system.

Description

Prerequisites

You must meet at least one of the following prerequisites to use these procedures:

  • You have administrative privileges in the BIG-IQ user interface.
  • You have command line access to your BIG-IQ system.
  • You have physical access to the LCD panel on your BIG-IQ system.

The management port on a BIG-IQ system provides administrative access to the system and you can also use the management port for discovery and for communication with BIG-IP systems and data collection devices. You can display the management IP address for the BIG-IQ system using the user interface, the command line, or the LCD panel.

Procedures

Displaying the management IP address using the BIG-IQ user interface, command line, or LCD panel

You can display the currently-configured management IP address if you have administrative access or physical access to the BIG-IP system. To do so, perform one of the following procedures:

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

Displaying the management IP address using the BIG-IQ user interface

  1. Log in to the BIG-IQ user interface.
  2. Go to System > THIS DEVICE > General Properties.

    The configured management IP address appears in the Management Address row.

    The address the BIG-IQ system uses for discovery and peer communications is displayed in the Discovery Address row.

Displaying the management IP address using tmsh 

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To display the configured management IP address, type the following command:

    list /sys management-ip

    The output appears similar to the following example:

    sys management-ip 192.168.1.245/24 {
    description configured-statically
    }

  3. To display the management route, type the following command:

    list /sys management-route

    The output appears similar to the following example:

    sys management-route default {
    description configured-statically
    gateway 192.168.1.254
    network default
    }

Displaying the management IP address using the LCD panel

  1. To enter Menu mode for the LCD, press X.
  2. Use the arrow keys to navigate to System, and press Check.
  3. Navigate to Management, press Check.
  4. Use the arrow keys to select Address Type, Mgmt IP, Prefix Length, or Mgmt Gateway, and press Check to display the item.
