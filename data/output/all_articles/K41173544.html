Description

The file "mcp_module.xml" consumes a lot of disk space in /shared/tmp/. 
Similar output as below may show when using the following command:

# lsof -ws | grep -i 'size\|deleted'
qkview    24422      root    6w      REG              253,1        2661       8260 /shared/tmp/index.xml (deleted)
qkview    24422      root    7w      REG              253,1           0       8261 /shared/tmp/meta.xml (deleted)
qkview    24422      root    9w      REG              253,1        3633       8264 /shared/tmp/manifest.xml (deleted)
qkview    24422      root   10w      REG              253,1 42189090816       8265 /shared/tmp/mcp_module.xml (deleted)  <----!!

Disk /shared reports a high utilization or 0% free.

Environment

  • BIG-IP
  • Disk /shared

Cause

Not applicable when this article is published.

Recommended Actions

The "/shared/tmp/mcp_module.xml" is related to generating qkview. Manually kill the qkview process using the command:
# pkill qkview

None
