Description

This article describes how to determine which TLS ciphers and protocols are negotiable by the BIG-IP Configuration utility.

Environment

  • BIG-IP Configuration utility

Cause

None

Recommended Actions

Determine which protocols and ciphers are currently negotiable by the httpd daemon.

  1. Log in to the Advanced Shell (bash) of the BIG-IP system.
  2. Display the current ssl-ciphersuite and ssl-protocol by typing the following command:

    tmsh list /sys httpd { ssl-ciphersuite ssl-protocol }

    Output appears similar to the following:

    sys httpd {
        ssl-ciphersuite ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256
        ssl-protocol "all -SSLv2 -SSLv3 -TLSv1"
    }

  3. To show a list of all TLS protocols and ciphers that are available for use with the Configuration utility, type the following command:

    openssl ciphers -v

Additional Information

The httpd service uses two tmsh options to determine which SSL ciphers and protocols are negotiable. These options directly correlate with standard Apache directives as indicated in the following table:

OptionDescriptionRelated Apache Directive
sys httpd ssl-ciphersuiteRestricts the ciphers the httpd process negotiates.SSLCipherSuite
sys httpd ssl-protocolRestricts the protocols the httpd process negotiates.SSLProtocol

Note: The previous links take you to resources outside of AskF5, and it is possible that the documents may be removed without our knowledge.

While the ssl-ciphersuite option may specify a protocol version, it is not required. With the omission of the protocol version in the ssl-ciphersuite string, the system falls back to the protocols defined in ssl-protocol.

In the following example, TLSv1.1+ECDHE-RSA-AES256-SHA is a valid string but is ignored because ssl-protocol is restricted to only negotiate TLSv1.2:

sys httpd {
    ssl-ciphersuite TLSv1.1+ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES256-GCM-SHA384
    ssl-protocol TLSv1.2
}

Note: The previous configuration results in only TLSv1.2+ECDHE-RSA-AES256-GCM-SHA384 being negotiable.

To use the sys httpd ssl-protocol command to improve Configuration utility security, refer to K22426638: Use only TLS 1.2 on BIG-IP GUI (management interface).
