K000092442: 'error: /bin/haloptns unexpected error -- 768' log messages generated on A110 and D112 platforms

Type
Support Solution
Published
2022-10-12
Updated
2022-10-12
Source
https://my.f5.com/manage/s/article/K000092442

Description

'error: /bin/haloptns unexpected error -- 768' message is logged by system commands, including some startup scripts and the software installation process.

Running /bin/haloptns manually displays this output:
'Expected 32 bit OPTN field, found field "" instead.'

Environment

  • Any one of the following platforms
    • VIPRION B4340N (NEBS) blades
    • 10350v-F (FIPS)
    • 10150s-N (NEBS) platforms
  • RAID is not in use
  • Certain commands are executed that run /bin/haloptns

Cause

The /bin/haloptns command returns an error and this can be logged into log files.

Recommended Actions

This error message is benign and can be safely ignored.
