Description

You may find the current connections value is different between the command tmsh show ltm snat-translation and command tmsh show sys connection, they are multiples of the relationship. For example, the tmsh show ltm snat-translation connection value is double tmsh show sys connection.
#tmsh show sys connection ss-client-addr 10.10.227.30
Sys::Connections
172.16.227.6:58340  10.10.227.51:3389  10.10.227.30:28499  10.10.227.51:3389  tcp  125  (tmm: 7)  none  none
Total records returned: 1    <====

#tmsh show ltm snat-translation 10.10.227.30
---------------------------------
Ltm::SNAT Translation: 10.10.227.30
---------------------------------
Traffic                ServerSide
  Bits In                    1.7K
  Bits Out                   1.0K
  Packets In                    4
  Packets Out                   3
  Current Connections           2    <====
  Maximum Connections           3
  Total Connections             3

Environment

  • SNAT translation
  • SNAT pool
  • Current connection

Cause

When the same SNAT translation IP is in multiple SNAT pools, MCPD process will query the stats of SNAT translation as same times as the numbers of SNAT pools, so the value is double/triple/quadruple of show sys connection, even if the SNAT pool is not used.

 Recommended Actions

  • Avoid adding the same IP address to more than one SNAT pool.
  • When you use the same IP address on different SNAT pool, please use the command tmsh show sys connection query the current connections, the command's output is correct.
