K000139066: Add newly created vlan in the vcmp guest using TMSH

Type
Support Solution
Published
2024-03-28
Updated
2024-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000139066

Description

VLANs are created and associated to the vCMP guests from the vCMP Host . If the VLAN is not associated to the vCMP Guest, the vCMP guest will not be able to use the VLAN.

Environment

  • BIG-IP vCMP

Cause

This is an expected behaviour. If the newly created VLAN is not added in the VLAN allowed list of the vCMP Guest the traffic will not flow through to the vCMP Guest.

Recommended Actions

1. Check if the new created VLAN on the vCMP Host is added in the VLAN allowed list of the guest unit. Run the below given command on the vCMP host and replace the <Guest name> with the actually name of the guest unit.

       tmsh list vcmp guest <Guest name> all-properties

2. Add the newly created VLAN to the VCMP Guest VLAN allowed list using the below given command, change the <New VLAN> with the actually name of the vlan to be added.

       tmsh modify vcmp guest <Guest name> vlans add { <New VLAN>}
