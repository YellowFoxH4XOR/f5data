K12476: The BIG-IP GTM configuration may fail to load when the parent of a child monitor is also a child monitor

Known Issue

Note: The issue described in this article does not affect BIG-IP GTM 11.0.0 or later.

This is the result of a known issue. If you create a child monitor that references another child monitor as its parent, the gtmd process may write out an invalid wideip.conf file. As a result, all BIG-IP GTM systems in the sync group will fail to load the new configuration.

If the gtmparse -l or gtmload command is run at this stage, one of the following two error messages will be returned and logged to the /var/log/gtm file:

  • BIG-IP 9.x

    ERROR, recvMCPreply: Got bad result: 01070043:3: Monitor <name> parent not found
  • BIG-IP 10.x

    ERROR, recvMCPreply: Got bad result: 01070032:3: No argument list found for monitor <name>

This issue occurs because the gtmd process does not always write monitor definitions to the wideip.conf file in the correct order. Specifically, this issue occurs when the child monitor definition is incorrectly written above its parent monitor definition.

F5 Product Development is tracking this issue as ID 337664.

Resolution

Workaround

You can work around this issue by editing the wideip.conf file and manually re-ordering the monitor definitions. To do so, perform the following procedure:

  1. Log in to the BIG-IP system command line.
  2. Change the working directory to the /config/gtm/ directory by typing the following command:

    cd /config/gtm/
  3. Create a backup of the wideip.conf file by typing the following command:

    cp wideip.conf wideip.conf.sol12476
  4. Using a text editor, open the wideip.conf file.
  5. Locate the following section:

    // *** Monitor Definitions (X) ***

    Note: The above line will include a number enclosed in parentheses. The number indicates how many monitor definitions are present in your wideip.conf file.
  6. Within this section, locate the definitions of the affected child and parent monitors.
  7. Move the definition of the parent monitor above that of the child monitor.
  8. Save the file and exit the text editor.
  9. Verify that the BIG-IP GTM configuration is now correctly loading by typing the gtmparse -l command.

    Note: The updated wideip.conf file will be automatically synchronized to all other sync group members.
