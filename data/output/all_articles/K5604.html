mod_access in Apache 1.3 before 1.3.30, when running big-endian 64-bit platforms, does not properly parse Allow/Deny rules using IP addresses without a netmask, which could allow remote attackers to bypass intended access restrictions. (CVE-2003-0993)

None of the F5 products listed in the Applies To box are affected by this Apache mod_access module vulnerability.
