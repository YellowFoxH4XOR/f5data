K000090259: Metrics not working

Type
Support Solution
Published
2021-08-27
Updated
2026-07-30
Source
https://my.f5.com/manage/s/article/K000090259

Description

  • You want to view Metrics by navigating to Infrastructure/instance  but the Controller does not or is unable to display statistical information
  • When running kubectl describe command for clickhouse pod, following kubectl describe pod clickhouse-0, you note the pod status is in 'Running' but failed to reach 'Ready' state
  • You would also see in the 'Events' section of the above output a message similar to, 'Container clickhouse failed liveness probe, will be restarted'

Environment

  • Nginx Controller
  • Clickhouse works

Cause

  • High CPU and RAM usage on the worker NODE where Clickhouse pod resides

Recommended Actions

  • Reboot the worker node where Clickhouse pod resides
  • If rebooting the node does not solve, then please try moving Clickhouse Pod to a different Node

Additional Information

  • Described above, the output from your environment may look like as below

# kubectl describe pod clickhouse-0

...

...
