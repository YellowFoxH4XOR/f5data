Description

Export access session reports from inactive software volumes

  • Navigating to Access  ››  Overview: Access Reports
  • Unable to find access sessions that were available before upgrade
  • No results when you generate session reports for the time period before the upgrade

Environment

  • APM was upgraded
  • Missing access sessions

Cause

Access sessions prior to upgrade cannot be accessed on newly activated software volume.

Recommended Actions

To generate a report of sessions that were initiated before the upgrade, you need to switch to the previous volume.
The current active volume would have sessions that were initiated after the upgrade.

[admin@bigip1:Active:In Sync] ~ # switchboot -l

Current boot image:
    HD1.2 - title BIG-IP 14.1.4.1 Build 0.0.4
Default boot image:
    HD1.2 - title BIG-IP 14.1.4.1 Build 0.0.4
Available boot image(s):
    HD1.1 - title BIG-IP 14.1.2.8 Build 0.0.7
    HD1.2 - title BIG-IP 14.1.4.1 Build 0.0.4


[admin@bigip1:Active:In Sync] ~ # switchboot HD1.1
[admin@bigip1:Active:In Sync] ~ # reboot

After switching to the previous volume, Access  ››  Overview: Access Reports shows the missing sessions
