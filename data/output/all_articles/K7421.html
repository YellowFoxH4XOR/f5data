K7421: Language customizations are not synchronized in a failover pair and a cluster

Known Issue

This is the result of a known issue. The following FirePass language settings are not synchronized from the active controller to the standby controller in a failover pair, and from the cluster primary to the secondaries in a cluster:
  • Default character set
  • Default language
  • Default order for full user name

Note: Language customization settings are available under the Advanced Customization section of the Global Customization tab, on the Device Management: Customization page.

F5 Networks Product Development tracked this issue as CR74284 and it is fixed in version 6.0.1 of FirePass software. For information about upgrading, refer to the FirePass Release Notes.

Workaround

You can work around this issue by configuring the language settings separately on each FirePass controller.

Important: F5 Networks recommends that you do not change the settings on the standby unit.
