Description

Error 51093, Minimum locking information is missing from the Dossier.

Environment

  • BIG-IP Standard series

Cause

  • Dossier file is missing the minimum amount of information to process a license.

Recommended Actions

Error 51093 indicates that information is missing from the dossier file.  This generally occurs when there is an issue on the BIG-IP such as mismatched software/hardware versions.  

    the most common cause is the software version installed on the hardware is not supported.  Another potential cause is the F5 product cannot read the system configuration of the hardware it's installed on. 

    1.  Make sure your device is running software listed in the F5 hardware/software compatibility matrix  and matches your hardware.
      1. If you are running unsupported software:
        1. upgrade to new hardware that supports the current version of software on the device and migrate the configuration to that new hardware.
        2. revert to a volume that contains a supported version of software for your platform.  Downgrading BIG-IP Software. Note:  Configuration data cannot be downgraded.

    If the recommended actions do not fix this issue,  Please open a support case at https://my.f5.com for additional assistance.
