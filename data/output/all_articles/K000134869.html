This article provides information about supported upgrade paths for F5OS software.

Description

The following table indicates the supported upgrade paths for F5OS, F5OS-A, and F5OS-C software and shows the software versions you can upgrade from when upgrading to another F5OS software version.

Version you are upgrading toVersions you can directly upgrade fromAdditional information
F5OS 2.0.x
  • F5OS-A 1.5.x or later (r2000, r4000, r5000, and r10000 series)
  • F5OS-A 1.8.x (r12000-DS series)
  • F5OS-C 1.6.x or later (VELOS CX410 chassis)
  • F5OS-C 1.8.1 or later (VELOS CX1610 chassis)
  • F5OS-C 1.8.2 or later (VELOS CX410 or CX1610 chassis with FIPS license)
When you plan for an upgrade to F5OS 2.0.x on an F5 rSeries or VELOS system, F5 recommends that you reference the following prerequisites and related information:
  • The F5OS version you can upgrade from depends on the hardware platform you are running as shown in the Versions you can directly upgrade from column.
  • For installation instructions and information about upgrading to F5OS software, refer to the following documentation:
    • The release note for the F5OS version to which you want to upgrade
    • The F5 rSeries Systems: Software Installation and Upgrade guide at techdocs.f5.com
    • The VELOS Systems: Software Installation and Upgrade guide at techdocs.f5.com
F5OS-A 1.x.xF5OS-A 1.x.xWhen you plan for an upgrade to F5OS-A 1.x.x on an F5 rSeries system, F5 recommends that you reference the following prerequisites and related information:
  • You can upgrade to any F5OS-A 1.x.x version from another F5OS-A 1.x.x version.
  • For installation instructions and information about upgrading to F5OS-A software, refer to the following documentation:
    • The release note for the F5OS-A version to which you want to upgrade
    • The F5 rSeries Systems: Software Installation and Upgrade guide at techdocs.f5.com
F5OS-C 1.x.xF5OS-C 1.x.xWhen you plan for an upgrade to F5OS-C 1.x.x on a VELOS system, F5 recommends that you reference the following prerequisites and related information:
  • You must be running F5OS-C 1.1.4 or later to upgrade directly to F5OS-C 1.2.1 or later. If your VELOS system is running F5OS-C software version 1.1.3 or earlier, you must first upgrade to F5OS-C 1.1.4 before you can install F5OS-C 1.2.1 or later.
  • For installation instructions and information about upgrading to F5OS-C software, refer to the following documentation:
    • The release note for the F5OS-C version to which you want to upgrade
    • The VELOS Systems: Software Installation and Upgrade guide at techdocs.f5.com

Recommendations

When planning to upgrade F5OS software, you should consider the following factors:

  • When possible, upgrade to a Long-Term Stability Release for the following reasons:
    • The Standard Support phase for the Long-Term Stability Release continues for three years past the customer ship date.
    • The Standard Support phase for the Short-Term Stability Release is six months or three months after the next STS release, whichever is longer.
  • Take note of the End of Software Development dates for the software release and for your hardware platform.
  • Verify that you have a current F5 Support contract before attempting to re-license the system.
  • Read the Release Notes for Fixes and Known Issues for the target version to identify known issues with your configuration.
  • If you prefer to reconfigure your F5 rSeries or VELOS system without rolling forward a current configuration, F5 recommends that you perform a clean installation.
  • Regularly verify the proper operation of your F5 rSeries or VELOS system by uploading a QKView diagnostic file to F5 iHealth.
  • Check for the latest F5OS version that is compatible with your F5 rSeries or VELOS system. For more information, refer to K86001294: F5OS hardware/software support matrix.
