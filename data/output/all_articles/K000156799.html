K000156799: Network Access compression may cause issues with VPN tunnel traffic on APM Client v7260 and higher

Type
Support Solution
Published
2025-10-03
Updated
2025-10-03
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000156799

Description

VPN connections using APM Client v7260 may experience performance or connectivity issues, if Network Access compression is enabled.

Environment

Big-IP APM Edge Client v7260+

Cause

Network Access compression is deprecated and not recommended for use, starting in APM Client v7260

Recommended Actions

Ensure GZIP Compression on the Network Access profile used for VPN connections, is disabled.

The Network Access compression setting is found in the GUI under:

Access ›› Connectivity / VPN : Network Access (VPN) : Network Access Lists -> select your Network Access profile

Under 'General Settings' you can check the 'Compression' setting and verify or change it so it is set to 'No Compression' (instead of GZIP Compression).

Click Update.

 

Additional Information

Release Notes : APM Client 7.2.6

Note: Effective with this release, Network Access compression is deprecated across all VPN clients. Updated clients will ignore the compression setting during VPN sessions.
