Description
When connecting to a BIGIP APM Webtop, users are prompted by their browser with the following error message:
XML Processing Error: Tag Mismatched. Expected: </custom_img_path>.

Environment

  • You're using BIGIP APM;
  • Once the AccessPolicy is completed, users are assigned a webtop and resources

Cause
This is likely due to some internal resources being somehow corrupted.

Recommended Actions

We'd need to force the BIGIP APM to "Apply Access Policy", to the affected AccessProfile.
There are many ways to trigger such action;  the key element is to get the "Apply Access Policy" button appearing on the top left of the Configuration Utility page.
Here are a couple of examples:
  • open the properties of the AccessProfile, and implement and change (click Update) you immediately revert (click Update again);
  • open the "SSO / Auth Domain" tab, and implement and change (click Update) you immediately revert (click Update again);
  • open the VPE / AccessPolicy, and implement any harmless change (some text being displayed to the users, some "Empty" or "Logging" agent, ...
Please click the "Apply Access Policy" button once available; before users can initiate fresh new sessions.
