Description

  • Very High CPU on Active and Standby devices
  • top shows high CPU for apmd, oathd, localdbmbr
  • Possibly High CPU for dosl7d, mpcd, avrd
  • No processing of BIG-IP APM traffic.

Environment

  • BIG-IP APM provisioned
  • 1000+ Virtual Servers
  • Version 13 prior to 13.1.0.6  or
  • Version 14 prior to 14.1.0.8

Cause

Issue with the internal process startup.

Recommended Actions

  1. Upgrade. There is no workaround.
  2. If using Version 13, upgrade to the latest  release. The issue is   Bug ID 703171: High CPU usage for apmd, localdbmgr and oauth processes
  3. If using Version 14, upgrade to 14.1.0.8 or later or 15.1.X. The issue is Bug ID 706782: Inefficient APM processing in large configurations.

Additional Information

  • The high CPU can cause the GUI to have "internal errors"
  • BIG-IP APM processing is stalled, impacting traffic that needs BIG-IP APM.
  • It can occur after a config sync when the configuration reaches a critical level.
