Known Issue

This is the result of a known issue. The FirePass reverse-proxy engine does not properly assign an empty parent window to a target tag. As a result, if a user accesses a web page that contains frames through a FirePass web portal, the web page may fail to render properly. For example, the frame information may be altered or removed and the first frame loaded will encompass the entire window.

F5 Product Development is tracking this issue as ID 329888 (formerly CR139382).

This issue has been fixed in cumulative hotfix HF-70-1 issued for FirePass version 7.0.0 and in HF-610-4 for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
