Description

After attempting to deploy a new BIG-IP Next tenant using the rSeries or VELOS provider via BIG-IP Next Central Manager, a critical alert is displayed and Central Manager removes the instance.

The critical alert reads "BIG-IP Next <IP> has an unknown or unusable device certificate; explicit trust is not possible. Error: EOF

Environment

  • BIG-IP Next Central manager
  • Using Central Manager to create a tenant using the provider.

Cause

The important part of the error message is "Error: EOF". The certificate was not returned, and this could mean that Central Manager cannot reach the management IP address of the newly created BIG-IP Next instance.

Recommended Actions

The newly created BIG-IP Next instance is removed from Central Manager's inventory but the tenant probably remains on the rSeries or VELOS system. You can try to ping the management IP address of the tenant from Central Manager to confirm that this is the issue.

If this is the issue, you can delete the BIG-IP Next tenant from the rSeries or VELOS system, and then use Central Manager to re-create the instance, this time using a management IP address that is reachable by Central Manager.
