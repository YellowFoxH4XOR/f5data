Description

Management IP address is not working on Azure v5 series BIG-IP VE instances

Environment

  • BIG-IP
  • Azure
  • v5 Azure Instance

Cause

v5 series instances types are not supported on BIG-IP versions prior to 17.1.2

Recommended Actions

Create new 17.1.2 instances and migrate configuration across to them.
