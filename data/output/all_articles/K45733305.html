Description

In /var/log/apm   you see

Session deleted due to admin initiated termination


Environment: 

  • BIG-IP APM (any version)


Cause

There are four possibilities

  1. Enforcing of Maximum number of concurrent sessions for the given user: K18390492: Security | BIG-IP APM operations guide
  2. Session was deleted by an irule: ACCESS::session
  3. Session was deleted on the UI
  4. Session was deleted by the sessiondump utility. 



Recommended Actions

ACCESS::session remove

Above command is executed in iRule, this log message will appear.
However there is no requirement to specify a sessionID. Using the irule in this form will cause unpredictable session removals, not just related to the Virtual Server to which it is applied.

We recommend to use: 

ACCESS::session remove -sid [HTTP::cookie MRHSession]
