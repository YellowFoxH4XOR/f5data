Description

How can I rename an existing Load Balancer (LB) in my F5 Distributed Cloud environment?

Environment

  • F5® Distributed Cloud (XC) Console

Answer/Recommended Actions

Renaming a Load Balancer in the F5 Distributed Cloud Console is possible, but due to strict domain enforcement, there is no direct "rename" function. Instead, you must clone the existing LB configuration with the new name and delete the old one. This ensures that domain constraints are respected and avoids conflicts. 

Important Notes before proceeding: 

If you are using a C-Name for your Load Balancer this will change when the new LB is created and you will need to adjust DNS accordingly. 
If you are using the auto certificate feature that may take a short amount of time to generate a new certificate.
If you are using static IPs for DNS or your own SSL/TLS certificate that should stay exactly the same. 

 

**Steps to Rename a Load Balancer:**

1. Backup Your Configuration:
   - Open your current Load Balancer’s configuration.
   - Copy its JSON definition for backup purposes. This is important in case your session times out or you need to restore settings.

2. Prepare Your Workspace:
   - Open two browser tabs:
     - Tab 1: The List of load balancers displaying the LB you wish to rename.
     - Tab 2: An exact copy showing the same information.

3. Clone and Rename:
   - In Tab 1, locate your target LB.
   - Click the three dots next to it and select “Clone.”
   - Change the name field to your desired new LB name.

4. Delete Old LB Before Saving New One:
   - In Tab 2, click on the same three dots and click delete the original LB.
   - Once deleted, return to Tab 1 and save your cloned (renamed) LB configuration.

> **Note:** You cannot save the renamed LB before deleting the original due to strict domain enforcement rules within F5 Distributed Cloud.

5. Restore from Backup if Needed:
   If you encounter issues during this process (e.g., session timeout), use your saved JSON backup to recreate either version of your LB as needed.

6. Support Assistance:
   If you require help during this process, contact F5 Support for guidance or request a walkthrough call.

Additional Information

- Always ensure backups are taken before making changes.
- Domain enforcement prevents duplicate names; deletion of the old resource is mandatory prior to saving under a new name.
