Known Issue

The zless command may fail to run on the BIG-IP system. This issue occurs when all of the following conditions are met:
  • You have assigned the tmsh shell as the default shell.
  • You log in and enter the run util bash command.
  • You attempt to view compressed files (for example, the /var/log/ltm.1.gz file) using the zless command.

The zless command allows viewing of compressed files by combining the functions of the Linux gzip and less utilities.

Impact

You are unable to view compressed files using the zless command.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The zless command fails and reports an error that appears similar to the following example:

    Syntax Error: unexpected argument "gzip"

Resolution

Status

Workaround

To work around this issue, you can use the zmore command, which has similar functionality to the zless command.
