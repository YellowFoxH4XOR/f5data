Description

When loading the BIG-IP configuration  (tmsh load sys config) you encounter an error similar to the following:

01071dc9:3: BIG-IP doesn't support using a '#' in the TACACS secret.

 

    Environment

    • BIG-IP
    • After upgrade to 14.x or later
    • TACACS

    Cause

    TACACS authentication password contains the "#" sign.

    Recommended Actions

    To avoid config loading issues F5 suggest following steps:

    1. Verify bigip.conf configuration file located in /config directory.
      Note: You may use any Linux text editor such like VIM, or download bigip_base.conf file directly from BIG-IP to your workstation.
       
    2. Modify TACACS related values that new TACACS secret won't use '#' sign in its password: 

      Important: This section output contains example configuration. Setup within your environment can be different and you should stick up to yours system config. 
      auth remote-user {

    default-role admin
    remote-console-access tmsh

}
auth source {
    type tacacs
}
auth tacacs /Common/system-auth {
    debug enabled
    protocol ip
    secret ***scrubbed***        <<<----    Change to plain-text password which would not contain '#' sign in it, eg. test123
    servers { 192.0.2.2 192.0.2.10 }
    service ppp
}


       

    3. Save configuration changes in bigip.conf file on F5 system, and try to load modified configuration using below command:
      tmsh load sys config

    Additional Information

    If problem remains after modifying TACACS config according to article suggestions, please open Service Order by contacting F5 Networks Support.
