Known Issue

This is the result of a known issue. The Expires string is cached and updatable by multiple users of the same document. In some cases, the string may be set in more than one thread, resulting in a memory leak.  In other cases, the string may be referenced before it has been created. When this occurs, the pvac process crashes.

F5 Product Development tracked this issue as CR136591, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
