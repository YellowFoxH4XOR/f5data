Description

GUI  System > BIG-IQ HA tab shows 'localhost' and no version information for primary device in cluster

ha_reset <discovery selfip> does not fix this issue 

restcurl command shows VALIDATION_FAILED status
restcurl /shared/resolver/device-groups/cm-shared-all-big-iqs/devices/

            "state": "VALIDATION_FAILED",
            "errors": "Unable to add device to cm-shared-all-big-iqs group. Device does not meet group validation requirements. \n Property name: productName Expected: BIG-IQ Received: ",
            "address": "172.168.1.25",
            "httpsPort": 443.0,
            "hostname": "localhost",
            "version": "",
            "product": "",
            "edition": "",
            "build": "",

Environment

  • BIG-IQ Centralized Management
  • BIG-IQ HA configuration

Cause

Issue related to localhost discovery process which is failing.

Recommended Actions

To fix this issue please refer to article for fixing localhost discovery:

K14593: BIG-IQ localhost discovery is required before performing remote device discovery
