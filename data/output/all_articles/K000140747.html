Description

After installing the EHF for ID1060393, the system continues to experience high CPU usage, indicating that the issue may not be fully resolved. Further investigation is required to identify any additional factors contributing to the elevated CPU load.

Environment

ASM

Recommended Actions

To fix this, install the latest BrowserChallenge and wait 48h till it is applied, then sync to the peer.

for a quicker fix during a maintenance window, have the standby in forced offline. Install the latest BrowswerChallenge on the active unit, and apply it immediately below ( involve tmm restart ). Then bring up the standby and sync from active to standby:

touch /etc/datasync/regenerate_all

bigstart restart tmm
