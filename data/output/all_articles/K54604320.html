Known Issue

The bigd process may restart when a DNS response does not match the expected value.

This issue occurs when the following condition is met:

  • The system is monitoring DNS servers or using a fully-qualified domain name (FQDN).

Impact

The bigd process will potentially produce a core file and restart; this situation may cause an endless restart loop if the DNS monitor instance is configured.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The bigd process restarts when a response returned from a DNS request does not match the expected value.
