Known Issue

The iControl Management.Zone.get_zone() method returns zone options in an invalid format for use with the Management.Zone.set_zone_option() method.

Impact

The DNS zone configuration is not properly formatted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system outputs an error message that appears similar to the following example:

    0115080c:3: Invalid zone option syntax

  • The Management.Zone.set_zone_option() method returns an exception error message that appears similar to the following example:

    Exception calling "set_zone_option" with "1" argument(s): "Exception caught in Management::urn:iControl:Management/Zone
    ::set_zone_option()
    Exception: Common::OperationFailed

Resolution

Status

F5 Product Development has assigned ID 520640 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can use the ZoneRunner utility in the Configuration utility to create the DNS zone.
