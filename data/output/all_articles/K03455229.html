Description

By default, Zebos advertises the route for the entire subnet, and selects the lowest self-IP as the route destination to advertise the subnet. The Traffic group configuration doesn't match the tag specified in the route-map and dynamic routing advertises the lowest self-ip as route destination.

When using Active/Active configurations, route-maps must be created for each traffic group to ensure that the IP addresses within each traffic group are grouped together and then advertise the appropriate floating self-IP for that route-map this requires significant manual configuration when virtual addresses are added, or when a virtual address is shifted between traffic groups for load-management purposes.

Environment

  • Dynamic routing
  • Active-Active HA environment

Cause

This works as designed. However, there is a design limitation if running BIG-IP in Active-Active HA configuration.

Recommended Actions

You can use the following workaround to advertise the specific subnets in the Traffic group:

  1. Create route-map
  2. Create prefix-list for matching subnets set per Traffic groups
  3. Redistribute kernel routes to BGP with route-map configuration.
There is a Request For Enhancement (RFE) submitted to F5 Product Development which allows dynamic routing to advertise routes based on route-map tag.
