K20234241: No learning suggestions for file types more than 7 characters

Type
Support Solution
Published
2021-09-29
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP ASM: 15.1.2
Source
https://my.f5.com/manage/s/article/K20234241

Description
There is a new file type examined by ASM but there is no learning suggestion for that new file type.

Environment

  • BIGIP ASM
  • Learning suggestions

Cause
File type more than 7 characters.

Recommended Actions

It is by design that learning suggestion will not show file type with more than 7 characters.
You could consider to manually update the file type in the ASM policy. 

Additional Information
None
