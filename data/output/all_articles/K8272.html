Known Issue

This is the result of a known issue. If your configuration logs a user out of the FirePass controller when the user logs out of a Microsoft SharePoint or Outlook Web Access 2007 Portal Access favorite, the user's session will be retained in the FirePass controller's session table. The session will be visible on the Reports: Sessions page of the Administrative Console.

When a user's session is not cleared from the FirePass session table, any limits to the number of user logons (either master group-based limits or global limits) could be reached without the actual number of users being serviced. The uncleared sessions may consume some or all of the allowed number of concurrent logons for each user, or may consume some or all of the total users allowed by the license, or both, depending on your configuration. This resource consumption could prevent users from accessing the FirePass controller. Each user can create as many leftover session table entries as the user's master group limits or global limits permit.

This issue does not affect FirePass controllers that are configured to use the new version of the Web Applications engine introduced in version 6.0.2.

This issue affects FirePass controllers that are configured to use the Compatibility Mode 2 setting of the Web Applications engine. The Compatibility Mode 2 setting is configured on the Portal Access: Web Applications: Content Processing page, by selecting the Compatibility Mode (enable legacy versions of Web Applications engine) check box, then selecting the Compatibility Mode 2 (Version 5.4 through 6.01 default engine) button.

Note: Support for Microsoft SharePoint 2007 or Microsoft Outlook Web Access 2007 requires FirePass software version 6.0.2 or later. Refer to K7268: FirePass support for Outlook Web Access 2007 and SharePoint 2007 for more information.

F5 Networks Product Development tracked this issue as CR90313 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-1 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

To clear leftover user sessions, an administrator can kill the sessions using the Kill links in the Current sessions table on the Reports: Sessions page.

To prevent the user sessions from being left in the session table when the user is logged off from the application and the FirePass controller, use the newest version of the Web Application engine. To configure your FirePass controller to use the newest version of the Web Application engine, clear the Compatibility Mode (enable legacy versions of Web Applications engine) check box on the Portal Access: Web Applications: Content Processing page. This setting requires a service restart to take effect.
