Description

Active health checks proactively send synthetic requests to a configured URI on the upstream server at scheduled intervals to assess its health. This module is available part of Nginx Plus subscription. 

Passive health checks, on the other hand, monitor live client traffic and mark servers as unhealthy if errors (timeouts, 5xx responses, etc.) occur. 

If you have active health checks configured, disabling passive health checks is recommended to prevent false positives from transient failures in real traffic, reducing unnecessary noise in health status changes.

 

Environment

Nginx Plus

 

Recommended Actions

To disable passive health checks in Nginx, update the upstream block by adding the max_fails=0 parameter to each server directive. 

Modify your Nginx configuration file as shown in the example below:

upstream backend {
    zone backend 64k;
    server 127.0.0.1:80 max_fails=0;
    server 127.0.0.2:80 max_fails=0;
    ...
}

After updating the configuration, test and reload Nginx with the following commands:

sudo nginx -t && sudo service nginx reload

This ensures the configuration is valid and the changes are applied.

Additional Information

For more details on health checks, refer to the Nginx Admin Guide.
