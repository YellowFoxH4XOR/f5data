Topic

This article discusses the logging format for BIG-IP ASM remote logging profiles that are configured to log to ArcSight or Reporting Server remote storage types.

Description

You can configure a remote logging profile for a BIG-IP ASM system to log to one of the following types of remote storage:

  • Reporting Server
  • ArcSight

When you configure either of these storage types, the BIG-IP ASM system sends remote logs to the configured destination using the following pre-defined format:
