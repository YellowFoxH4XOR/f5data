Description

FQDN Nodes maybe reporting as DOWN and repeated monitor "UP" log messages in /var/log/ltm in the following format maybe encountered:


notice mcpd[PID#]: 01070727:5: Pool /Common/example_pool member /Common/_auto_192.168.1.10:443 monitor status up. [ /Common/example_TCP_Monitor: up ] [ was unchecked for 0hr:0min:0sec ]


Environment

FQDN Nodes are configured.


Cause

This can be caused when the FQDN IP Address is updated at the same rate as the TTL of the FQDN.

The BIGIP is not likely the cause of this issue.


Recommended Actions

Compare TTL value of FQDN and rate IP Address is changing.

Contact Service/Cloud Provider or Administrator of remote IP Address(es) affected.


Additional Information

None
