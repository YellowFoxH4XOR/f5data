K12586415: ASM events logs stopped logging on BIG-IQ

Type
Support Solution
Published
2020-03-17
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K12586415

Description

  • No new ASM event logs can be seen on BIG-IQ GUI on Monitoring > EVENTS > Web Application Security > Event Logs > Events
  • On the ElasticSearch aliases table the alias "asmindex" is associated with index name "asmindex_writer"

Environment

  • BIG-IQ CM
  • BIG-IQ DCD
  • ASM event logs

Cause

  • Seen behavior is caused by a known issue tracked with the Bug ID 812725

Recommended Actions

To confirm if the BIG-IQ device is affected by ID 812725 perform the following steps:

  1. Connect to BIG-IQ CLI
  2. Check the ElasticSearch aliases

    curl -s localhost:9200/_cat/aliases?

  3. If the output is similar to the one below it confirms that ID 812725 is in play 
    alias          index                 filter routing.index routing.search
asmindex       asmindex_writer       -      -             -
To workaround the issue perform the following procedure:
  1. On BIG-IQ CM GUI Navigate to System > BIG-IQ DATA COLLECTION > BIG-IQ Data Collection Devices
  2. Click on the DCD device and go to Services
  3. Deactivate all services one by one
  4. Connect to BIG-IQ CM CLI
  5. Delete the ASM index

    curl -sX DELETE localhost:9200/asmindex*

  6. On BIG-IQ CM GUI Navigate to System > BIG-IQ DATA COLLECTION > BIG-IQ Data Collection Devices
  7. Click on the DCD device and go to Services
  8. Activate all needed services one by one
