Description

SNMPv3 requests timeout, giving the impression that there is extreme slowness in the responses

Environment

  • SNMPv3 configured
  • An SNMPv3 small max message size received while processing large SNMPv1 and SNMPv2c requests.
Cause

If the SNMP server receives an SNMPv3 request with a small max message size then, it applies that check to all requests. This can cause SNMPv1 and SNMPv2c requests to time out if they are too long or if their responses are too long, for example, large get bulk requests.

Recommended Actions

  • this issue is being tracked as Bug ID 810381
  • as a workaround, you can avoid sending SNMPv3 requests to the BIG-IP
