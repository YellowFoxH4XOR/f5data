Description

You want to move one or more objects from one Route Domain to another. For example, you want to move all configuration objects from a route domain named, RD10, to route domain 0, the default route domain.

Environment

  • BIG-IP
  • Route Domains

Cause

None

Recommended Actions

You may consider either of consider two options:

  • Delete and Replace
    • This is the recommended option and involves removing the configuration objects from one route domain and manually re-creating the objects in the desired route domain. For example, the more reliable method is to delete the objects from the user-defined route domain and recreate them using route domain 0, the default route domain.
  • Config file editing
    • This option involves editing the BIG-IP configuration files. If you are confident in your command line skills, you can perform a find and replace to remove the route domain flags. This option may be time saving, but can potentially result in an unloadable configuration if done incorrectly. The way to do this safely is to work with a copy of the configuration files and attempt to load the modified files on the standby device. You can use the tmsh load sys verify file <my_file> command to validate the specified configuration in the file to determine whether they are valid to replace the running configuration; the running configuration will not be changed.
