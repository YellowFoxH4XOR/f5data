Description

Error about last-resort-pool can not be empty, when using Ansible to perform a wide-ip configuration. Error can be similar to this message:

  • \"code\":400,\"message\":\"\\\\\"last-resort-pool\\\\\" requires a value\",\"errorStack\":[],\"apiError\"

Environment

  • BIGIP DNS
  • Recently upgrade to 14.1.4 or above FW
  • Using Ansible to configure a wide-ip

Cause

Behavior seen is caused due to BugID: 1011285

Recommended Actions

You can use either of the following, depending on what you want to do:

  1. To create a new wide IP object, remove the empty 'lastResortPool' property from the JSON body.
  2. To remove the last-resort-pool from an already existing wide IP, define the property as follows instead: "lastResortPool":"none"

Additional Information

Bug ID 1011285: The iControl REST API no longer accepts an empty 'lastResortPool' property for wide IP objects
