Known Issue

This is the result of a known issue. The VIPRION MIB contains only the chassis serial number and the serial number of the current primary blade. It is not possible to retrieve the serial numbers for the secondary blades in a VIPRION chassis using SNMP.

F5 Product Development tracked this issue as ID 248031 (formerly CR142036), and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, or PSM release notes.
