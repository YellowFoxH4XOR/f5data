Description

How to identify IPI subscription using "tmsh show sys iprep-status" command and interpret below output. 

  •  tmsh show sys iprep-status

    -----------------------------------------------------------------------
    Sys::IP Reputation Database Status
    -----------------------------------------------------------------------
    Last time the server was contacted for updates      05/24/2021 02:35:32
    Last time an update was received                    05/24/2021 02:35:34
    Total number of IP Addresses in the database                    3966844
    Number of IP Addresses received in the last update                   94

Environment

  • IPI
  • Brightcloud

Cause

If there is no updates available on bright cloud server and does not have new records or new base file: 
Time stamp for fields namely, "Last time the server was contacted for updates" and "Last time an update was received" are not change 
 

  •  tmsh show sys iprep-status

    -----------------------------------------------------------------------
    Sys::IP Reputation Database Status
    -----------------------------------------------------------------------
    Last time the server was contacted for updates      05/24/2021 02:35:32
    Last time an update was received                    05/24/2021 02:35:34
    Total number of IP Addresses in the database                    3966844
    Number of IP Addresses received in the last update                   94

    Note: Last time the server was contacted for updates & Last time an received timestamp remains the same for a prolong period of time.
     
  • /var/log/iprepd/iprepd.log will show that there is no update available and old time stamp is 5/7/2021 12:30 AM.

iprepd|INFO|May 06 17:37:25.485|16584|vThreatDataMonitor: check for newer data since 1.5028 upd 67 build 5/7/2021 12:30 AM
iprepd|INFO|May 06 17:37:27.390|16584|   0 IPs loaded in 1.91 secs
iprepd|INFO|May 06 17:37:27.390|16584|   No update available, managing 3873307 Threats

  • when there is a update, the time stamp will be updated. For example, the new time stamp to show up using "tmsh command" will be  5/7/2021 12:35 AM
iprepd|INFO|May 06 17:42:27.804|16584|vThreatDataMonitor: check for newer data since 1.5028 upd 67 build 5/7/2021 12:30 AM
iprepd|INFO|May 06 17:42:29.630|16584|   update found: maj 1 min 5028 upd 68 date 5/7/2021 12:35 AM max est entries 145
iprepd|INFO|May 06 17:42:29.655|16584|   86 IPs loaded in 1.85 secs
iprepd|INFO|May 06 17:42:29.655|16584|   Rev 1.5028 upd 68 build 5/7/2021 12:35 AM...
iprepd|INFO|May 06 17:42:29.706|16584|vMergeLists : nAdded 64 nChanged 22

Recommended Actions

There is no action required, this is an expected behaviour.
