Topic

In BIG-IP LTM, you can configure a Source Address Affinity profile in conjunction with a Proxy Address Data Group to map AOL client connections to the same pool member. For information about using source address affinity for AOL persistence connections, refer to K7004: Using source address affinity for AOL persistence connections.

When using a Source Address Affinity persistence profile to map AOL client connections to the same pool member, the BIG-IP LTM persistence table displays a single IP address to represent all AOL proxy connections. The BIG-IP LTM system will treat AOL client connections as originating from the following AOL proxy IP address: 64.12.96.0.
