Description

You want to change the elliptic curve cryptography (ECC) curves to offer to pool members in Server SSL profile such as not offering P384.

Environment

  • Server SSL profile
  • Cipher Group
  • Cipher Rule 

Cause

None

Recommended Actions

By default, the Server SSL profile provides ECC curves in the following order of preference for TLS connections to pool members:

  • P256
  • X25519
  • P384

To change the default order of preference, or to prevent the system from offering one or more ECC curves, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Local Traffic > Ciphers : Rules > <cipher rule name> and type the ECC curve you want in the DH Groups field. For example, if you do not want to offer P384 for better TPS performance, type: P256:X25519
  3. If you want  to change the order of the ECC curves, go to Local Traffic > Ciphers : Groups > <cipher group name> in GUI and select among the selection, such as Speed or Strength. Here are the order of the ECC curves offered by the selection.
Default
  • P256
  • X25519
  • P384
Speed
  • X25519
  • P256
  • P384
Strength
  • P384
  • P256
  • X25519
