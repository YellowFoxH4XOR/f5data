Known Issue

VMware View HTML5 client users may be unable to access BIG-IP APM resources.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system uses an access profile for accessing a VMware View resource.
  • The BIG-IP APM virtual server resides in a non-default route domain.
  • Users attempt to access the VMware View resource using the HTML5 client.

Impact

Attempts to access the BIG-IP APM resources fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to connect to the VMware View resource, users receive an error message similar to the following:

    The connection to the server was reset while the page was loading.
  • When analyzing the network packet flow of the user request, the initiating request sent to the virtual server (that is configured in a non-default route domain) is sent by the BIG-IP APM system to the VMware View resource. However, when the VMware View resource responds, the BIG-IP APM system routes the response packets to the default route domain and the connection fails.
