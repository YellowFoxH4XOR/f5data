K14734711: Unable to login to BIG-IQ via SSH using Putty client tool with an error message ''Putty Fatal Error ;''

Type
Support Solution
Published
2022-02-16
Updated
2025-04-02
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K14734711

Description

  • Logging in via SSH into BIG-IQ using putty client tool is failing with the Putty Fatal Error messages below:
login as: admin
Keyboard-interactive authentication
Access denied

Putty Fatal Error ;
Disconnected: No supported authentication methods available (server sent: publickey,keyboard-interactive,hostbased)
  • The root account can log into BIG-IQ via SSH.
  • Customer wants other user accounts to log onto BIG-IQ via SSH. 
     

Environment

  • SSH
  • BIG-IQ 
  • Putty client tool
     

Cause

The default is that only root account is accessed to BIG-IQ via SSH.
 

Recommended Actions

  1. Log in to the workstation command line or BIG-IQ Advanced Shell (bash).

    For example, please check the current user account configuration and then, enter the following commands:
    # tmsh list auth user all
    # tmsh modify auth user <user_account_name> shell bash
    # tmsh save sys config
    # tmsh list auth user <user_account_name> 
     
  2. Check whether the <user_account_name> can log into BIG-IQ VE 8.1.0 via SSH without the error message successfully.
     

Note: User accounts (to be granted shell access) must be locally defined.
