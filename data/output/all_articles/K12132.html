Known Issue

This is the result of a known issue. The BIG-IP system does not execute startup commands or scripts in the /config/startup file during system startup. The /config/startup file is called by /etc/rc.local and allows the BIG-IP system to execute startup commands or scripts when configured.

Note: For more information about the use of the /config/startup file, refer to K11948: Configuring the BIG-IP system to execute commands or scripts upon system startup.

F5 Product Development tracked this issue as ID 211919 (formerly CR128756) and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WAN Optimization Release Notes.
