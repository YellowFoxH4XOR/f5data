Description

You may also see the below message displayed on the Configuration Utility (GUI).

"The configuration has not yet loaded. If this message persists, it may indicate a configuration problem."

You see the following error  in /var/log/ltm when attempting to load the configuration on your BIG-IP:

ltm.example.com emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all " - failed. -- 01070712:3: Failed: name (/<Partition>/<Filename>) Cache path (/config/filestore/files_d/<Partition>_d/ifile_d/:<Partition>:<Filename>_<revision number>) does not exist and there is no copy in trash-bin to restore from. Error: failed to reset strict operations; disconnecting from mcpd.  Will reconnect on next command. Data Input Error: 01070734:3: Configuration error: Current folder /<Partition> has been removed. Exit session.

Environment

  • BIG-IP
  • Configuration not loading

Cause

A reference to a delete iFile is present in the configuration. When the system attempts to load the configuration, but doesn't find the iFile referenced in the configuration, you will see the error above.

Recommended Actions

Remove iFile reference from configuration and reload it.

  1. Make a copy of bigip_base.conf.
    cp bigip_base.conf bigip_base.conf.backup
  2. Using the error message as a reference, (/<Partition>/<Filename>), open the bigip_base.conf file in the partition referenced in nano or vi.
  3. Using your the editor's find function, locate the iFile object that references the filename.
  4. Delete or comment out the object
    Example, if the object that is causing the issue is as below:
    cm cert /Common/dtca-bundle.crt {
       cache-path /config/filestore/files_d/Common_d/trust_certificate_d/:Common:dtca-bundle.crt_11111_3
       checksum SHA1:1111:222fe00000cece222ll11lll1777700000001111
       revision 3
    }

    You can comment it out and it will look like this:
    #cm cert /Common/dtca-bundle.crt {
    #   cache-path /config/filestore/files_d/Common_d/trust_certificate_d/:Common:dtca-bundle.crt_11111_3
    #   checksum SHA1:1111:222fe00000cece222ll11lll1777700000001111
    #   revision 3
    #}
  5. Save your edit
  6. Run the following command to check if there are no other issues: 'tmsh load /sys config verify'
  7. If no errors are reported, load config using: 'tmsh load /sys config'.
