Description

 

Declarative Onboarding reboots device when a new Device Certificate/Key is defined.

Declarative Onboarding reboots device when subsequent declarations are deployed with missing Device Certificate/Key definition (triggering roll back procedure).

 

Environment

 

  • BIG-IP
  • Declarative Onboarding
  • DeviceCertificate

 

Cause

AUTOTOOL-3579

The BIG-IP system is rebooted when submitting a declaration with change in Device Certificate/Key

 

Recommended Actions

 

This is expected to be fixed in a future release - Declarative Onboarding v1.47.0

Check release notes when available.

https://github.com/F5Networks/f5-declarative-onboarding

 

Additional Information

If the Device Certificate/Key is not defined in subsequent DO deployments, they will roll back to previously configured cert/key.

If this behaviour is not desired, you may use the Skip Device Certificate check, to avoid triggering the roll back process:

https://clouddocs.f5.com/products/extensions/f5-declarative-onboarding/latest/schema-reference.html#devicecertificate

"deviceCertificate": {
"class": "DeviceCertificate",
"skipDeviceCertificates": true,
}
