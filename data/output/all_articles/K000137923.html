Description

You manually edited /var/run/config/snmpd.conf in order to monitor disk space usage on a filesystem/folder (this configuration option is not present in the Web GUI).  Subsequent changes were made to the BIG-IP configuration using the web gui and the manual edits to the file were lost.

Environment

  • BIG-IP
  • SNMP
  • snmpd.conf
  • CLI
  • GUI

Cause

Configuration manually added and not saved via tmsh, is overwritten by any configuration added via the Web GUI.

Recommended Actions

As you cannot use the Web GUI to make this change, you can effect the change using tmsh commands and by then saving the configuration.

To permanently add the filesystem/directory entry that you wish to monitor, you can do the following.

1. check to see what the existing snmp disk-monitors configuration looks like, by running the following:

tmsh list /sys snmp

Note: In an unedited snmpd.conf file you should only see the 2 default disk monitors for paths '/' and '/var'

...

disk-monitors {
root {
minspace 2000
path /
}

var {
minspace 10000
path /var
}
}

...

2. Add your desired configuration entry using this command syntax:

tmsh modify sys snmp disk-monitors add { <label> { minspace path }}

Note: <label> is an arbitrary text label, it can be any text you wish, but keep it short and meaningful. In this example we will use label 'varlog'.

for example:

tmsh modify sys snmp disk-monitors add { varlog { minspace 10000 path /var/log }}

3. Look at the configuration again and note that your monitor is added and should persist across changes to SNMP settings performed via the Web GUI:

tmsh list /sys snmp

...

disk-monitors {
root {
minspace 2000
path /
}

var {
minspace 10000
path /var

}

varlog {
minspace 100000  # your added configuration
path /var/log
}

...

4. save the configuration:

tmsh save /sys config

Additional Information

If you need to delete the entry that you created above, the command would be:

tmsh modify sys snmp disk-monitors delete { varlog }
