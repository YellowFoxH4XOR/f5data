Description

Starting in version 14, you have the option to specify what status codes will reuse connections from OneConnect. The default value is "200 206".

Environment

  • BIG-IP LTM v14.x and later
  • OneConnect Profile
  • HTTP Profile

Cause

This is a Feature Enhancement.

The HTTP status code in the server response must match one of the status codes in the OneConnect Status Reuse property. Otherwise, OneConnect will not reuse server-side connections.

Recommended Actions

To observe or change this feature:

  • In the Web Configuration Utility (GUI):
    Local Traffic > Profiles > Services > HTTP > <profile_name> > Settings > OneConnect Status Reuse

  • Traffic Management OS (TMOS) Shell:

tmsh list ltm profile http http oneconnect-status-reuse

root@(localhost)(cfg-sync In Sync)(Active)(/Common)(tmos)# list ltm profile http http oneconnect-status-reuse oneconnect-transformations
ltm profile http http {
  oneconnect-status-reuse "200 206"     <<<< default http profile value
  oneconnect-transformations enabled     <<<< default value is enabled
}
  • Create a custom http profile to confirm to make any changes to the "oneconnect-status-reuse" value. Additionally, "oneconnect-transformations" must be enabled for OneConnect to manage server-side connections.
  • Create a custom one-connect profile to confirm "Total Reuses" column increments. 
# "New" counter increases, when OneConnect feature does not manage additional server-side connections 
root@(localhost)(cfg-sync In Sync)(Active)(/Common)(tmos)# show ltm profile one-connect oneconnect_test
