Known Issue

The BIG-IP system may occasionally fail to identify and replace string matches specified in a Stream profile or iRule.

This issue occurs when one of the following conditions are met:

  • A virtual server uses a Stream profile that is configured to replace a source string with a smaller target string.
  • A virtual server uses an iRule STREAM command that is configured to replace a source string with a smaller target string.

Note: The greater the size differential between the source and target strings, the greater the chance that a match will be missed.

Impact

Application layer traffic is not managed appropriately.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • On rare occasions, a stream match and replace function does not occur.
