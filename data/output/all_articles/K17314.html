Known Issue

The BIG-IP system may unexpectedly terminate Session Initiation Protocol (SIP) connections when the server fails to send a response to the client.

This issue occurs when all of the following conditions are met:

  • The virtual server is configured with a SIP and a message-based load balancing (MBLB) profile.
  • You are consolidating back-end server-side connections using one of the following methods:
     
    • You configure a virtual server to use a OneConnect profile.
    • You configure an iRule to use the lb::src_tag and lb::dst_tag commands and associate the iRule with the virtual server.

Impact

The client connections to the server are terminated.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The server-side connection is reset and the BIG-IP system logs error messages to the /var/log/tmm file that appear similar to the following example:

     err tmm[1234]: 01230140:3: RST sent from 192.168.1.1:6782 to 192.168.1.2:44181, [0x12e0260:1503] MBLB internal error (Not connected)
