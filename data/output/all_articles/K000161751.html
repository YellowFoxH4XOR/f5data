K000161751: How to increase the core dump size limit for NGINX App Protect (NAP) in Kubernetes

Description

When NGINX App Protect (NAP) crashes within a Kubernetes (k8s) environment, the generated core dump may be truncated, preventing complete crash analysis and root cause investigation.

  • Core dump files are truncated or incomplete
  • Core dump file size appears capped at approximately 2 GB
  • Crash analysis / debugging cannot proceed due to an incomplete core dump

Environment

  • NGINX App Protect (NAP) running in a Kubernetes (k8s) environment
  • Host using systemd-coredump for core dump handling
  • Default core dump size limit (e.g., 2 GB) configured on the host

Cause

By default, systemd-coredump enforces size limits on core dumps via the ProcessSizeMax and ExternalSizeMax parameters. When a NAP process consumes more memory than this default limit, the resulting core dump is truncated, leaving an incomplete file that is unsuitable for full crash analysis.

 

Answer/Recommended Actions

Increase the core dump size limit to 8 GB by following these steps:

1. Confirm there is sufficient storage space (greater than 8 GB)

df -h /var/lib/systemd/coredump/

2. Increase the core dump size limit

mkdir -p /etc/systemd/coredump.conf.d/
cat > /etc/systemd/coredump.conf.d/large-core.conf <<'EOF'
[Coredump]
ProcessSizeMax=8G
ExternalSizeMax=8G
EOF
systemctl daemon-reload

3. Verify the configuration takes effect

systemd-analyze cat-config systemd/coredump.conf

The output should reflect the updated ProcessSizeMax=8G and ExternalSizeMax=8G values.

 

Additional Information

  • Ensure the storage location (/var/lib/systemd/coredump/) has adequate free space before increasing the limit, as larger core dumps will consume more disk space.
  • The 8G value can be adjusted based on the expected process memory size and available storage.
  • These settings apply at the host/node level. In a Kubernetes environment, this configuration must be applied to the underlying worker node(s) where the NAP pods are scheduled.
