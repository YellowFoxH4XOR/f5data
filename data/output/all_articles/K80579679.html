Description

You may experience issues with LDAP communication between the BIG-IP and your domain controller due to an increase in the cipher strength required on your Active Directory (AD) controller. Symptoms may include:

  • Failure of remote authentication for administrative users on the BIG-IP
  • LDAP monitors may start to fail
  • The ldapsearch command may fail with errors such as: 
    • ldap_start_tls: Connect error (-11), additional info: TLS error -5961:TCP connection reset by peer
    • ldap_sasl_bind(SIMPLE): Can't contact LDAP server (-1)
    • ldap_bind: Strong(er) authentication required (8)

Environment

  • LDAPS communication between BIG-IP and authentication server

Cause

The issue arises when the BIG-IP is using a lower cipher strength than required by the authentication server.

Recommended Actions

Use the following command to specify stronger ciphers for LDAP remote authentication: 
tmsh modify auth ldap system-auth ssl-ciphers <value>

For more information on ciphers supported on the BIG-IP platform see the following knowledge article:
K13163: SSL ciphers supported on BIG-IP platforms (11.x - 13.x)


To increase the cipher strength of LDAPS monitors and the ldapsearch command:

On the BIG-IP system, openldap is used. To increase the cipher strength the BIG-IP uses:

modify the openldap configuration file: 
/etc/openldap/ldap.conf

Add the following entry to the file: 
TLS_CIPHER_SUITE
Your config file should then look similar to the example below, with the appropriate cipher suite inserted: 
#
# LDAP Defaults
#
# See ldap.conf(5) for details
# This file should be world readable but not world writable.
#BASE   dc=example,dc=com
#URI    ldap://ldap.example.com ldap://ldap-master.example.com:666
#SIZELIMIT      12
#TIMELIMIT      15
#DEREF          never
TLS_REQCERT     never
TLS_CACERTDIR   /etc/openldap/certs
TLS_CIPHER_SUITE <INSERT CIPHER SUITE HERE>


TLS_CIPHER_SUITE configures the accepted ciphers and their preference order. You can use the command

openssl ciphers -v ALL

to obtain a verbose list of available cipher specifications. Specifiers like HIGH, MEDIUM, LOW, EXPORT, and EXPORT40, along with TLSv1, SSLv3, and SSLv2, may be useful.
