K000148205: How to set up a maintenance page in case of an outage

Type
Support Solution
Published
2024-11-08
Updated
2025-12-31
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source

Description

You need to configure a maintenance page because of an outage to your site and you want to customize it.

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer

Cause

None

Recommended Actions

To set-up a maintenance page:

  1. Go to HTTP Load Balancer in Advanced Configuration -> Configure (under the More Options label) -> Configure Custom Error Response Options 
  2. Click Configure (below label Custom Error Responses). 
  3. Select from the left menu or scroll down to the Advanced Configuration section and perform the configuration:

  • To cover all 3XX, 4XX, and 5XX errors, create 3 items with values 3, 4, and 5 respectively (or any specific error code between 300-599)

    

4. Click Apply to add the advanced configuration to the load balancer.

Additional Information

Custom error responses configured through this method will override default error pages for the specified HTTP status codes. This configuration applies only to the specific HTTP Load Balancer where it is configured and takes effect immediately upon application.
