Known Issue

Downloads through BIG-IP APM Network Access tunnels may experience performance degradation.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM system to provide network access using Datagram Transport Layer Security (DTLS).
  • Multiple DTLS records are contained within a single User Datagram Protocol (UDP) response packet.

Impact

Degraded performance and packet loss occur when downloading content through Network Access tunnels.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Downloads through Network Access tunnels experience excessive packet loss or IP fragmentation between the client and the BIG-IP APM system.
  • Download throughput is noticeably reduced when using Network Access tunnels.
