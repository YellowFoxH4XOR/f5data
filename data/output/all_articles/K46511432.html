Description

After upgrading the BIG-IP software, Standard Virtual Server will have a connection issue where there is no retransmission.

This Virtual Server is using BWC (Bandwidth Controller). When BWC is removed, issue will not happen.

The BIG-IP software version which are impacted are:

  • 15.1.0.1
  • 15.1.0
  • 15.0.1.1
  • 14.1.2.3
  • 14.1.2.1
Environment
  • BIG-IP
  • Running on BIG-IP software 15.1.0.1, 15.1.0, 15.0.1.1, 14.1.2.3, 14.1.2.1
  • Only happens on Standard Virtual Server
  • Only happens when BWC (Bandwidth Controller) is used on the Virtual Server

Cause

This issue is related to bug ID 891477.

Recommended Actions

As per the bug description, you will need to upgrade you BIG-IP software to resolve the issue. The issue is fixed in:

  • 16.0.0
  • 15.1.0.5
  • 15.0.1.4
  • 14.1.2.7


Bug ID891477 is also fixed is later software versions than the ones mentioned above.

There are 2 workarounds to resolve the issue which are:

  1. Change from a Standard Virtual Server to a Fast L4 Virtual Server
  2. Remove the BWC (Bandwidth Controller) on the Virtual Server
