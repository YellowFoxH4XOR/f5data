Source
https://my.f5.com/manage/s/article/K33843354

Description

Failover working intermittently, these errors are present:

/var/log/restnoded/restnoded1.log:

Thu, 03 Feb 2022 15:47:31 GMT - finest: [f5-cloud-failover] Function error, retrying: You are not authorized to perform this operation. Retries left: 0
Thu, 03 Feb 2022 15:47:31 GMT - finest: [f5-cloud-failover] Function error, retrying: You are not authorized to perform this operation. Retries left: 0
Thu, 03 Feb 2022 15:47:35 GMT - fine: [f5-cloud-failover] No subnets found! Please check for ec2:DescribeSubnets permission.
Thu, 03 Feb 2022 15:47:35 GMT - fine: [f5-cloud-failover] Discover address operations found Elastic IPs: {}

Environment

  • BIG-IP 
  • AWS Cloud
  • CFE extension

Cause

Unknown.

Recommended Actions

Change your stanza in AWS IAM policy from:

"Action": [
        "s3:ListBucket",
        "s3:GetBucketLocation",
        "s3:GetBucketTagging"

to:

            "Action": [
                "ec2:CreateRoute",
                "ec2:ReplaceRoute"
            ],
            "Resource": "arn:aws:ec2:eu-west-1:427136436016:route-table/rtb-0abc9ba7dc12a1234",
            "Effect": "Allow"
        },

 

Additional Information

None.
