Issue

Old Behavior

In versions prior to BIG-IP 11.5.0, you can configure the Automatic Sync feature to save the configuration to file by setting the save-on-auto-sync option to true for the Root trust domain only. This option is a system-wide option and will cause all device groups enabled with the Automatic Sync feature to save the running configuration on the peer devices during automatic synchronization.

New Behavior

Beginning in BIG-IP 11.5.0, you can now configure the Automatic Sync feature to save the configuration to file per device group by setting the save-on-auto-sync option to true for your desired device group. This new behavior provides customers more granular control over which device groups should have their running configuration saved to file during the automatic synchronization.

F5 Product Development tracked this change as ID 427154.

Impact

If you have set the save-on-auto-sync option to true for the Root trust domain on versions prior to BIG-IP 11.5.0 and you upgraded to BIG-IP 11.5.0 and later, all device groups enabled with the Automatic Sync feature will have their save-on-auto-sync option set to true after the upgrade.
