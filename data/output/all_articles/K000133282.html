K000133282: Errors after upgrading the Access Guided Configuration (AGC) tool to version 8 or 9

Type
Support Solution
Published
2024-03-06
Updated
2024-03-25
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.2
Source
https://my.f5.com/manage/s/article/K000133282

Description

Upgrading  the Guided Configuration (AGC) to version 8.0 or 9.0  will show 3 errors related to certificates.

There is no mentioning of these errors in the AGC release notes which you can also download from the F5 Download site as indicated below.

This is an image of how these errors show up:

Environment

BigIP AFM and/or ASM/AWAF

Version 14.x to 17.x

 

Cause 

Unknown

 

Recommended Action 

After the upgrade of AGC has finished as shown in the above image, please click the blue "Continue" button.

These errors are "cosmetic" and do not affect AGC.

As a general recommendation please upgrade to the latest AGC version which is currently version 10.0 build 0.0.1636 

After upgrading to AGC version 10.0 the 3 errors mentioned in this article are no longer displayed.

At the moment this article was created the upgrade file which should be imported into the AGC upgrade process is the following:

f5-iappslx-agc-usecase-pack-10.0-0.0.1636.tar.gz

 

Additional Information

Detailed information or bugs related directly to AGC can be found in the AGC release notes which can be found in the

F5 General Download site at:  https://my.f5.com/manage/s/downloads  following these steps:

  1. Sign-in with your email and password or create new F5 download account
  2. Accept End User License Agreement
  3. Select Product family as "BigIP"
  4. Select Product Line as "Guided Configuration" and Product Line Version as the latest, currently version "10.0"
  5. Select "relnote-guided-config-10-0.html" for the AGC Release Notes or "f5-iappslx-agc-usecase-pack-10.0-0.0.1636.tar.gz" upgrade image.
  6. Under "Download Locations" select the location nearest to you and then click "Download"
  7. Save the file on your local computer in a directory you can easily remember.
