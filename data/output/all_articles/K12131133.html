Description

When navigating to Device Management >> Overview in your Active unit, the Standby unit is showing as Offline. However, the config is still able to sync and Failover works when the Active unit goes offline.

Environment

  • BIG-IP
  • vCMP
  • Issue appears after a recent device trust rebuilt due to a MGMT IP change

Cause

When executing the tmsh command show cm failover-status the following output appears in each device:

-------------------------------------------
CM::Failover Status
-------------------------------------------
Color    green
Status   ACTIVE
Summary  1/1 active
Details
         active for /Common/traffic-group-1

---------------------------------------------------------------------------------------------------------
CM::Failover Connections
Local Failover Address  Remote Device                  Packets  Transitions  Received Last Packet  Status
---------------------------------------------------------------------------------------------------------
HA.IP:1026              Standby-unit                   0        1            -                     Error
MGMT.IP:1026            Standby-unit                   0        1            -                     Error



--------------------
CM::Failover Status
--------------------
Color    gray
Status   STANDBY
Summary  1/1 standby
Details

---------------------------------------------------------------------------------------------------------
CM::Failover Connections
Local Failover Address  Remote Device                  Packets  Transitions  Received Last Packet  Status
---------------------------------------------------------------------------------------------------------
HA.IP:1026              Active-unit                    654545   3            2022-Aug-15 01:01:01  Ok

OLD.mgmt.IP:1026        Active-unit                    0        1            -                     Error

As you can see, the status in the Active unit show both HA IP and MGMT IP interfaces in "Error" state, while in the Standby unit, the HA IP interface shows as "OK", but the MGMT IP interface show in "Error" state, but most important, you still see the old MGMT IP in the list, although, it is not present anywhere in the configuration anymore.

When doing a tcpdump to capture network failover packets on both the MGMT IPs and the HA vlan, you can see the failover packets going back and forth between those interfaces in port 1026. However, when inspecting such packets, the HA messages from the Standby unit still has an incorrect management address embedded in it's HA message which is presumably why it is ignored.

    Recommended Actions

    In order for the Standby unit to embed the correct MGMT IP in the HA messages, you will need to restart the "sod" process.

    1. Log in to the system's bash:
      bash
    2. Restart the "sod" process with the following command:
      bigstart restart sod

    After restarting the sod process, HA messages will be accepted in the Active unit and the output of the tmsh command "show cm failover-status" will show all interfaces in "OK" status.
