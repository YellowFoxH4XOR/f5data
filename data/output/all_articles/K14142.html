Known Issue

When you delete the wide IP configuration, the gtmd wildcard wide IP may mismatch or TMM may core.

This issue occurs when all of the following conditions are met:

  • The client sends a DNS request for a wide IP alias.
  • The wide IP configuration was deleted, or it was previously deleted and re-created.

Impact

The BIG-IP system may temporarily fail to process traffic, as it recovers from TMM restart. If configured as a high availability pair, the device may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM may restart and generate a core file in the /shared/core directory.
  • The system may return an incorrect DNS response to the LDNS if the BIG-IP GTM configuration contains a wildcard wide IP alias. For example, www.my*.net is a wildcard wide IP alias.
