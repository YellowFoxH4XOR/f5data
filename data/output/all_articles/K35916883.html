K35916883: GSLB log search in the Configuration Utility may list Dec 31, 1969 as a start date

Type
Support Solution
Published
2021-10-21
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP DNS: 14.1.2
Source
https://my.f5.com/manage/s/article/K35916883

Description

BIG-IP DNS GSLB logs are showing year of 1969 and cannot select any other year

  • You attempt to search the GSLB logs in System > Logs : GSLB
  • No logs are shown
  • The only start time available is Epoch time, Dec 31, 1969

Environment

  • Using the Configuration Utility to search logs
  • BIG-IP DNS

Cause

The Epoch time, December 31st, 1969 is displayed when there are no GLSB logs.

Recommended Actions To check that the GSLB module is logging as it should, run a logger command and then search the logs again:

logger -p local2.3 \"This is a new log message\" 

Log search should now show something similar to:

Sep 23 14:57:30 example.com err root[13486]: "This is a new log message"
