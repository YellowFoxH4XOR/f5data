Known Issue

In rare instances, the BIG-IP WebAccelerator system excessively logs an error message to the /var/log/wa/pvac.log file that appears similar to the following example:

[ PvCacheManager.cxx:509 pv_crHeader_good_version_code ] -->hds:wrong_version_code count='445' expected='5' actual='572551022'

This error is due to the BIG-IP WebAccelerator system's inability to successfully write an object to a cache file.

This issue may occur when any of the following conditions are met:

  • The BIG-IP WebAccelerator system is under heavy load with high iowait and memory usage.
  • The BIG-IP WebAccelerator system is processing very large files, greater than 10mb in size.

Impact

Over time, the /var/log/wa/pvac.log file may become excessively large.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The /var/log/wa/pvac.log file may grow very rapidly with the previously-mentioned error message.

Workaround

To work around this issue, you need to clear the PVAC cache.  To do so, perform the following procedure:

Impact of workaround: All cached data will be deleted and will need to be re-cached.  The BIG-IP WebAccelerator system will be temporarily unavailable while the system deletes the cache files.  This may last several seconds.

  1. Log in to the BIG-IP command line interface.
  2. Run the following command:

    wa_clear_cache
