Description

Bot Signatures file is loaded in the live update page. But when trying to install following errors are noted in the GUI

Installation error: Fail handle payload files

Following logs are noted in "/var/log/tomcat/liveupdate.log"

live_update_upload <DATE> <TIME>  Info apply_bot_signatures[15690] F5::Dos::BotSignatures::load_from_xml,,Cannot send updated objects to mcp: 01070265:3: The Bot Defense Signature (<BOT_SIGNATURE_NAME>) cannot be deleted because it is in use by a Bot Defense Profile Signature Override (<BOT_DEFENSE_PROFILE_NAME> <BOT_SIGNATURE_NAME>).

01070265:3: The Bot Defense Signature (<BOT_SIGNATURE_NAME>) cannot be deleted because it is in use by a Bot Defense Profile Signature Override (<BOT_DEFENSE_PROFILE_NAME> <BOT_SIGNATURE_NAME>).

Environment

  • BIG-IP ASM / AWAF Module (BIG-IP 15.1.8.1)
  • Bot defense profile with configured bot signatures exception rule(s)
  • Updating BIG-IP ASM bot signatures by using either the "Automatic" or "Manual" update.
  • You already checked the article K01145451 or K04590402, but it did not match with your scenario

Cause

F5 provides bot signature updates by adding or removing different bot signatures to provide less false-positive. In some cases, you may have already configured one or some bot signatures exception under your bot defense profile. If F5 has recently removed at least one of those bot signatures which are under the exception section of your bot defense profile, BIG-IP
ASM / AWAF is not able to remove those signatures. As a result the bot signatures Installation fails since those are "in use" state,

Recommended Actions

Based on /var/log/tomcat/liveupdate.log, find the bot defense profile object's name in which the desired bot signature is in use. Next, you should remove all the needed bot signatures from them, and then try to Install the new Bot signatures file.
For example, based on the below log noted under "/var/log/tomcat/liveupdate.log", we have to remove the bot signature exception "/Common/bew" under the bot defense profile "/Common/sample_bot_profile", before Installing the new bot signatures.

live_update_upload ;<DATE> <TIME> Info apply_bot_signatures[15690] F5::Dos::BotSignatures::load_from_xml,,Cannot send updated objects to mcp: 01070265:3: The Bot Defense Signature (/Common/bew) cannot be deleted because it is in use by a Bot Defense Profile Signature Override (/Common/sample_Bot_profile /Common/bew).

After finding the name of your desired bot defense profile and name of bot signature in the liveupdate logs, follow the below steps to remove the needed Bot signature exception rule(s).
Impact of workaround: After removing the exception, since there is no exception for the overriden Bot signature, you may need to create your desired bot signature exception, after installing the new Bot Signatures update file.

  1. Go to below menu on GUI:
    Security  ››  Bot Defense : Bot Defense Profiles
  2. Click on your desired Bot defense profile
  3. Go to the "Bot Mitigation Settings" section, and then go to the "Mitigation Settings Exceptions" section at the bottom of page
  4. Find all the Bot signature exception rules which should be removed, and then try to remove them one-by-one, by clicking on the "Remove" button for each exception rule
  5. After removing all the needed Bot signature exception rule(s), try to install the Bot Signatures again under the below Menu on GUI, and check for the result
    System  ››  Software Management : Live Update  ›› Bot Signatures
