Known Issue

TMM may produce a core file on a BIG-IP PEM system when a Gx connection is disconnected and reestablished.

This issue occurs when the following condition is met:

  • Your Gx connection is disconnected and subsequently reestablished while performing subscriber provisioning.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting. If the BIG-IP system is configured a part of a high-availability (HA) group, a device failover may occur.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to the standby system if the system is configured for HA.
  • The BIG-IP system generates TMM core files to the /shared/core directory.
  • You observe messages in the /var/log/ltm log file that appear similar to the following example:

    notice sod[7056]: 01140045:5: HA reports tmm NOT ready.
