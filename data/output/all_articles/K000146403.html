Description

Irule generated IPfix records have natEvent set to zero

Environment

  • BIG-IP generating and populating IPfix records to IPfix logging server

Cause

This is working as designed.

All elements of the irule template must be assigned values within the irule.

Answer/Recommended Actions

The irule author must generate the logic to determine the required natEvent settings required and assign value.

set static::http_rule1_tmplt [IPFIX::template create "flowStartMilliseconds \
    sourceIPv4Address \
    sourceIPv6Address \
    destinationIPv4Address \
    destinationIPv6Address \
...
    natEvent \
    flowEndMilliseconds"]

<code>

if { <logic> } {
    IPFIX::msg set $rule1_msg1 natEvent 100
...

 

Additional Information

BIG-IP does not preset or populate any of the element values in the irule template automatically. All  element values must be assigned.
