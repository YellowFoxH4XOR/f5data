K2796: Creating a rule to perform a case-insensitive search of URI string

Topic

Starting in version 4.6.1, the BIG-IP system provides you with the ability to search a string for specific content, regardless of its case.

To use this feature, enclose the rule in a tolower function. This will instruct the rule to look for the string, regardless of case.

For example, if you configure a rule to use the tolower function to search for the lowercase string literal, jpg, it will return the following values:

JPG
JpG
jpg

For this example, you would configure the rule as follows:

rule WhateverCase {
if (tolower(http_uri) ends_with "jpg") {
use pool web
}
else {
use pool web1
}
}
