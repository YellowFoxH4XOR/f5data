A UCS archive is a compressed file that contains all the configuration files that are typically required to restore your current configuration to a new system. These files are:
  • All BIG-IP/3-DNS specific configuration files
  • BIG-IP/3-DNS product licenses
  • User accounts and password information
  • DNS zone files and NameSurfer configuration
  • SSL certificates and keys

A UCS archive is created each time you boot BIG-IP or 3-DNS. The compressed file is stored in gzipped tar format (which you can manipulate with the tar -z command), in the default /usr/local/ucs UCS path. The name of the archive is last_boot.ucs and it is suffixed by a number. The highest suffix number is the oldest archive.

Important: In addition to user accounts, passwords, and critical system files, the UCS archive contains the SSL private keys that are used with your SSL proxies. You must store backup UCS archives in an environment that is as secure as where you store your private keys.

Note: For more information about the specific files that are contained in a UCS archive and instructions about how to modify those files, refer to K4420: Viewing and modifying the files that are configured for inclusion in a UCS archive.

Creating a UCS archive

BIG-IP creates a UCS archive automatically, but you can also create a UCS archive at any time, using the following command syntax:

bigpipe config save <filename>

Replace <filename> with the name you want to give the archive. The default path is /usr/local/ucs. To save the UCS archive to a specific location, include the desired path.

Restoring a configuration from a UCS archive

To restore a configuration that is contained in a UCS archive, use the following command syntax:

bigpipe config install <filename>

Replace <filename> with the name of the archive. If the file is not contained in the default path or the directory from which you are working, you must also specify the path.

For more information about backing up and restoring configurations using a UCS archive, refer to K3135: Backing up and restoring BIG-IP or 3-DNS configuration files.

Viewing the UCS archive content

To view the files that are saved in a UCS archive, use the following command syntax:

tar -ztf <filename>

Replace <filename> with the name of the UCS archive.

This will provide a list of all the files included in UCS the archive.

Extracting files from the UCS archive

You can extract the files from a UCS archive without overwriting your existing configuration, by using one of the following processes:

  • Extract all UCS archive files
  • Extract a single UCS archive file

Extract all UCS archive files

To extract all files from a UCS archive, perform the following steps:

  1. Create a new directory within the /var/tmp directory, using the following command syntax:

    mkdir /var/tmp/<directory>

    Replace <directory> with a name of your choice.

  2. Copy the UCS archive into the new directory, using the following command syntax:

    cp <filename> /var/tmp/<directory>/

    Replace <filename> with the name of the UCS archive from which you want to extract files and <directory> with the name of the directory that you created in step 1.

  3. Change directories to the new directory, using the following command syntax:

    cd /var/tmp/<directory>

    Replace <directory> with the name of the directory that you created in step 1.

  4. Extract the files from the UCS archive, using the following command syntax:

    tar -zxf <filename>

    Replace <filename> with the name of the UCS archive.

    This command will extract the files and put them in the current directory. It will create subdirectories to match the directories in which the configuration files are normally stored. For example, it will create a config directory for the files that are normally contained in the /config directory.

Extract a single UCS archive file

To extract a single file from a UCS archive, perform the following steps:

  1. Create a new directory within the /var/tmp directory, using the following command syntax:

    mkdir /var/tmp/<directory>

    Replace <directory> with a name of your choice.

  2. Copy the UCS archive into the new directory, using the following command syntax:

    cp <filename> /var/tmp/<directory>/

    Replace <filename> with the name of the UCS archive from which you want to extract files and <directory> with the name of the directory that you created in step 1.

  3. Change directories to the new directory, using the following command syntax:

    cd /var/tmp/<directory>

    Replace <directory> with the name of the directory that you created in step 1.

  4. Extract the desired file from the UCS archive, using the following command syntax:

    tar -zxf <filename> <file-to-extract>

    Replace:

    • <filename> with the name of the UCS archive
    • <file-to-extract> with the relative path and name of the file that you want to extract from the UCS archive

    For example, to retrieve the bigip.conf file, you must specify the config directory, but not the root directory.

    For example:

    tar -zxf myconfig.ucs config/bigip.conf

    This command will extract the files and put them in the current directory. It will create a subdirectory to match the directory in which the configuration file is normally stored. For example, if you extract config/bigip.conf, it will create a config directory.

Viewing the contents of a file contained in a UCS archive

To view a single file from a UCS archive on a terminal screen (standard output), perform the following steps:

  1. Change directories to the directory that contains the UCS archive, using the following command syntax:

    cd <directory>

    Replace <directory> with the name of the directory that contains the UCS archive.

  2. Display the desired file in standard output from the UCS archive, using the following command syntax:

    Note: The third character in the flags list is a capital letter O.

    tar -zxOf <filename> <file-to-view>

Replace:

  • <filename> with the name of the UCS archive
  • <file-to-view> with the relative path and name of the file that you want to extract from the UCS archive

For example, to view the bigip.conf file, you must specify the config directory, but not the root directory.

For example:

tar -zxOf myconfig.ucs config/bigip.conf

Note: It is possible to use wildcards, for example config/bigip.*, to display multiple files from an archive.

Warning: Some files contained in a UCS archive are binary files which will not display correctly to standard output.
