Description

BIG-IP SSL Orchestrator supports decrypting and inspecting websocket and secure websocket traffic that does not flow through inline HTTP and ICAP services.

Environment

  • Client or server applications using websocket and secure websocket to support real time updates.
  • Secure websocket traffic needs to be intercepted for SSL visibility.
  • Websocket and secure websocket traffic that does not flow through inline HTTP and ICAP services.

Cause

None

Recommended Actions

BIG-IP SSL Orchestrator with websocket profile

BIG-IP has a websocket profile that allows filtering and auditing of websocket traffic. This websockdet profile is not necessary for BIG-IP SSL Orchestrator decryption and inspection. BIG-IP SSL Orchestrator treats websocket as plain TCP traffic. Use the following recommendations:

  • BIG-IP SSL Orchestrator does not send websocket traffic through HTTP or ICAP security services. To inspect websocket traffic, use L2 or L3 inline security services.
  • BIG-IP does not allow a websocket profile to be used on the same virtual server as an access profile. Because BIG-IP SSL Orchestrator uses an access profile, the BIG-IP SSL Orchestrator virtual server may not use a websocket profile. To use a websocket profile with BIG-IP SSL Orchestrator, you may configure a separate virtual server to use it using the deployment design pattern described in SSL Orchestrator Advanced Use Cases: Inbound Authentication.
