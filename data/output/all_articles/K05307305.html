Description

Backup UCS may fail via Configuration Utility.  You may see the following errors during backup A UCS

Operation Status
Saving active configuration...
Syntax Error: A port number or service name is missing for "/Common/<IP>:<port>:<port>". Please specify a port number or service name using the syntax "/Common/<IP>:<port>:<port>.".

Environment

  • BIG-IP
  • Node name with the colon ( : ) character example:  10.10.1.11:80
  • Backup a UCS via Configuration Utility

Cause

Node name contains (:) colon character.

Recommended Actions

The workaround is:

First rename the node to not contain a colon in it, then you can save UCS file without error.

None
