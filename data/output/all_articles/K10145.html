Known Issue

In a FirePass high availability pair configuration, the RSA SecureID server configuration synchronizes from the active node to the standby node. When creating an RSA SecureID configuration on the active node, the RSA SecureID configuration is synchronized to the standby node as expected. However, when removing the RSA SecureID configuration on the active node, the RSA SecureID configuration is not removed from the standby node.

F5 Product Development is tracking this issue as ID 327656 (formerly CR119989) for FirePass version 7.0.0 and as ID 317590 (formerly CR119989-1) for FirePass version 6.1.0.

This issue was fixed in cumulative HF-610-3-1 issued for FirePass version 6.1.0 and in cumulative HF-70-1 for FirePass version 7.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

To manually remove the configuration, perform the following procedure:

  1. Remove the RSA SecureID server configuration on the active node.
  2. Navigate to the Failover: Settings page.
  3. Perform a full synchronization by clicking the Force Full Sync link.

Note: For more information about configuring the RSA SecureID Server, refer to K8438: Configuring RSA SecurID Authentication on a FirePass failover pair.
