Topic

To enable Nokia® NetActTM Traps, perform the following steps:

  1. From the navigation pane of the BIG-IP Configuration utility, click System Admin.
  2. Click the SNMP Administration tab.

    You should see the SNMP Admin screen.

  3. To allow access to the BIG-IP system SNMP agent, check the Enable box.
  4. To allow access to the BIG-IP system NOKIA SNMP agent, check the Enable Nokia SNMP Traps box.
  5. Configure the Client Access and System Information as if you were setting up a normal SNMP configuration (for specific instructions, refer to the BIG-IP manual).
  6. In the Trap Configuration section, type the NetAct Manager's IP address in the trap Sink box.
  7. Click the Add (>>) button to add the trap sink to the Current List.
  8. When you are done, click the Apply button.

  9. If you are not upgrading from a previous version of BIG-IP, skip to step 10.

    If you are upgrading from a previous version of BIG-IP, use the command line utility to replace the /etc/snmptrap.conf file with /etc/snmptrap.conf.example file, as follows.

    Note: F5 Networks recommends that you back up the original snmptrap.conf file to snmptrap.conf.ORG before you overwrite it.

    cp /etc/snmptrap.conf.example /etc/snmptrap.conf

    Important: If you manually edited the original snmptrap.conf file (added new traps or removed old ones), you must to make the same edits in the new file. The new syntax is described within the file.

  10. In the /etc/syslog.conf file, enable the applicable facilities. These facilities allow log messages from various sources to be routed to specific files or message handling applications. The F5 Networks software uses the following facilities:
    local0.*
local1.*
local2.*
auth.*
kern.*

    The syslog utility sends messages to the /var/run/trapper log file, which BIG-IP continuously monitors for new input.

    Using a text editor, such as vi or pico, open the /etc/syslog.conf file and locate the lines near the bottom of the file that contain information similar to the following:

    #/local0.* /var/run/trapper

    Remove the number (#) symbol from each of the facilities for which you want traps. The edited text should appear as follows:

    /local0.* /var/run/trapper

  11. After you complete the configuration changes, reboot the BIG-IP system.

    The Nokia® NetActTM traps should now display in NetActTM Manager.
