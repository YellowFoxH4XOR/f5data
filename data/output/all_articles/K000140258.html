Description

With APM API protection profile for checking Oauth Scope with the internal Token Validation Mode, how to allow a specific URL to bypass API protection profile by iRule?

 

Environment

  • BIG-IP APM
  • API protection profile
  • iRule

 

Cause

  • iRule: ACCESS Please note: ACCESS iRule commands are not supported in API Protection use cases.
  • API protection access policy supports Request Classification Agent(RCA) for this purpose.

 

Recommended Actions

You can update your per-request access policy to include:

  • API Auth agent to check and branch based on the authorization header including a bearer token
  • RCA agent to check and branch based on the API request including the path.
