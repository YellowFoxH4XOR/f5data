Known Issue

The iRule HTTP::cookie insert command erroneously adds an unnecessary trailing semi-colon (;) character.

This issue occurs when the following condition is met:

  • You have an iRule that uses the HTTP::cookie insert command to insert a cookie into an HTTP response page.

Impact

You can safely ignore this issue; it should not impact system performance.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using the HTTP::cookie insert command in an iRule, you notice a trailing semi-colon character.

    For example:

    when HTTP_RESPONSE {
        HTTP::cookie insert name "ABC" value "123"
    }

    This iRule produces a header in the HTTP response with an unnecessary trailing semi-colon which appears similar to the following example:

    Set-Cookie: ABC=123;

Workaround

To work around this issue, you can use the iRules HTTP::header replace command after the HTTP::cookie insert command to remove the trailing semi-colon character. To do so, perform the following procedure:

Impact of workaround: F5 recommends testing iRules modifications during a scheduled maintenance window to ensure compatibility with your environment.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click the Name of the affected iRule.
  4. In the iRule's Definition text, find the HTTP::cookie insert name command syntax which erroneously inserts the trailing semi-colon.

    For example:

    when HTTP_RESPONSE {
        HTTP::cookie insert name "ABC" value "123"
    }

  5. Modify the iRule Definition text to add the HTTP::header replace command.

    For example:

    when HTTP_RESPONSE {
        HTTP::cookie insert name "ABC" value "123"
        HTTP::header replace Set-Cookie [substr [HTTP::header Set-Cookie] 0 [expr [string length [HTTP::header Set-Cookie]]-1]]
    }

  6. Click Update.
