K29625923: BIG-IQ DCD service check date showing old date after activation

Type
Support Solution
Published
2021-06-04
Updated
2025-02-08
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K29625923

Description

After re-activating the license on BIG-IQ DCD, the Service Check date in the new license is not current.  This is usually an indication that the Registration Key is no longer entitled to support (support has expired).

However since BIG-IQ v7 you no longer need a registration key for License Manager or BIG-IQ DCD (as a virtual edition).

Environment

  • BIG-IQ DCD Virtual Edition
  • Support Expired for Registration Key

Cause

Support Expired for Registration Key

Recommended Actions

For License Manager or BIG-IQ DCD (as a virtual edition):

Select 'Skip License' from System -> Licensing -> Reactivate License

Additional Information

A license is required to manage BIG-IP from BIG-IQ or to install BIG-IQ DCD on 7000 Series hardware.  Contact your F5 representative to renew your support contract.
