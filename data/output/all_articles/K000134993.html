Description

You want to gather all URLs that were requested on a specific virtual server from the last 7 days from analytics module AVR.

You have more URLs than 1000 to display

Environment

BIG-IP AVR

Cause

The configuration utility and the CLI are restricted to displaying a specific amount of URLs, 100 URLs for the Configuration utility and 1000 for the CLI.

Recommended Actions

The avr.stats.reportrownumberlimit db key can be used to raise the limit to display 1000 or more URLs in CLI

Impact of workaround: There was no testing done when increasing the query max value and we can't predict any implication of using a higher limit value.

Steps to increase value:

  1. Log in to the CLI
  2. tmsh
  3. mod sys db avr.stats.reportrownumberlimit 10000

Use following command to display a 10000 URLs for specific virtual server from the last 7 days:

show analytics http report view-by url drilldown {{ entity virtual values { /NameOfVirtualServer }}} limit 10000 range now-7d
