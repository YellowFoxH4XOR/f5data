Known Issue

This is the result of a known issue. The description of the Insert Certificate function in the BIG-IP online help is incorrect.

When you enable the Insert Certificate function, BIG-IP inserts HTTP headers into the node-side connection. The HTTP headers contain information from the client certificate that are presented to BIG-IP by the client. This process allows you to maintain a client certificate authentication model once you have off-loaded SSL processing to the BIG-IP.

F5 Networks Product Development tracked this issue as CR47142.
