Issue

Error Message

notice mcpd[<PID>]: 010713ba:5: Propose change to default gateway (<Gateway IP>).

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <Gateway IP> is the IP address for the chosen gateway.

For example:

notice mcpd[5723]: 010713ba:5: Propose change to default gateway (192.0.2.1).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • A Virtual Clustered Multiprocessing (vCMP) guest starts.
  • A user on the vCMP hypervisor changes the management gateway of the vCMP guest.

Impact

None. The message is informational.

Recommended Actions

None
