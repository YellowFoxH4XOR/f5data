K000160754: APM LocalDB user created via BIG-IP APM GUI disappears after approximately one hour

Description

When a LocalDB user is created via the BIG-IP APM GUI, the user account may disappear after about one hour if no further action is taken. The user is not persisted in the backend database (MySQL) and the  GUI.

Symptoms:

  • LocalDB user is created via GUI and appears in the user list.
  • After about one hour, the user account disappears without any manual deletion.
  • No corresponding "Updated DB" or deletion logs are found in /var/log/apm or audit logs.

Environment

  • BIG-IP APM
  • Create LocalDB users from GUI

Cause

The F5 PD team is tracking the issue from an internal bug: ID2266037.

Answer/Recommended Actions

To prevent LocalDB users from disappearing after creation via the GUI, follow these steps:

  1. After creating a LocalDB user via the GUI, then refresh the LocalDB Users page or search for the newly created user.
    • This action forces the APM to synchronize the user information from memcache to the backend MySQL database.
    • Once synchronized, the user will persist and will not disappear after an hour.
  2. Verification:
    • After adding a user and refreshing the page, verify the user exists in the GUI.

Additional Information

  • The problem has been fixed, so you may request the EHF from F5 technical support.
