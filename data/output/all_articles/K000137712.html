K000137712: Edge Client does not properly Disconnect when using SSO/SAML Entra-ID Authentication

Description

BIG-IP Edge Client hangs after attempting to disconnect. It does not proper Disconnect when using SSO/SAML Entra-ID (Azure AD) Authentication

 

Environment

  • Big-IP Edge Client
  • SAML/SSO
  • Entra ID (Azure AD)

 

Cause

F5 networks has opened a few tickets with Microsoft to handle this scenario.

 

Recommended Actions

Workaround for this issue is below

 

It uses a domain hint (whr) in the HTTP_RESPONSE_RELEASE event. You need to replace "example.com" with the domain of that account.
Microsoft site: Entra-ID Domain hints (This link may be removed by Misrosoft)

# START
when CLIENT_ACCEPTED {
    ACCESS::restrict_irule_events disable
}

when HTTP_RESPONSE_RELEASE {
   # this is to help with multiple identities on the logon by filtering based on domain
   if { [HTTP::status] == 302 && [HTTP::header exists Location] && [HTTP::header value Location] starts_with "https://login.microsoftonline.com" } {
      set loc [HTTP::header value Location]
      if { $loc contains "/saml2?SAMLRequest=" } {
         # add whr to filter identity during login phase
         set add "&whr=example.com"
         set newloc $loc$add
         HTTP::header replace Location $newloc
      }
   }
}
# END
