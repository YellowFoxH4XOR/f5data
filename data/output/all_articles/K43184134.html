Known Issue

DoSL7 detection may cause cross-origin HTTP requests to fail.

This issue occurs when all of the following conditions are met:

  • You have enabled a security policy feature that includes challenge scripts, such as the following:
    • Web Scraping
    • Brute Force protection
    • Proactive bot defense
    • DOSL7 protection
  • A user browses to a resource that makes a cross-origin HTTP request.

A cross-origin request (CORS) is a feature that enables one website to access the resources of another website using JavaScript within the browser.

Impact

Web pages intermittently fail to load completely.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Web pages intermittently fail to load completely.
