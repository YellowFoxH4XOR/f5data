Description:

HTTP/2 requests may get unexpected failures, this article describes one scenario.

Environment:
  • BIG-IP LTM
  • virtual server with HTTP/2 profile configured
Cause:

In RFC 7540:
  • Section 5.1.2 Stream Concurrency:
A peer can limit the number of concurrently active streams using the SETTINGS_MAX_CONCURRENT_STREAMS parameter within a SETTINGS frame.
Endpoints MUST NOT exceed the limit set by their peer.  An endpoint that receives a HEADERS frame that causes its advertised concurrent stream limit to be exceeded MUST treat this as a stream error of type PROTOCOL_ERROR or REFUSED_STREAM.
  • Section 5.4.2 Stream Error Handling:
An endpoint that detects a stream error sends a RST_STREAM frame that contains the stream identifier of the stream where the error occurred. The RST_STREAM frame includes an error code that indicates the type of error.

The BIG-IP system will send such a RST_STREAM FRAME which indicates REFUSED_STREAM Error when concurrent active streams exceeds the corresponding setting in HTTP/2 profile.

HyperText Transfer Protocol 2
    Stream: RST_STREAM, Stream ID: 21, Length 4
        Length: 4
        Type: RST_STREAM (3)
        Flags: 0x00
        0... .... .... .... .... .... .... .... = Reserved: 0x0
        .000 0000 0000 0000 0000 0000 0001 0101 = Stream Identifier: 21
        Error: REFUSED_STREAM (7)

Recommended Actions:

In RFC 7540:
  • Section 6.5.2 Defined SETTINGS Parameters:
SETTINGS_MAX_CONCURRENT_STREAMS (0x3): ... It is recommended that this value be no smaller than 100, so as to not unnecessarily limit parallelism.
So you can change the value of Concurrent Streams Per Connection in http/2 profile. Default value of this options is 10.

To modify this setting, you can follow these steps:

Please Note: It's not recommended to modify the system default profile directly, you'd better create a customized profile and use default one as parent profile and then modify the settings you need.
  1. Login to the GUI
  2. Navigate to Local Traffic >> Profiles >> Services >> HTTP/2
  3. Click the name of the http/2 profile you want to modify
  4. Rewrite the value of Concurrent Streams Per Connection to what you need.
  5. Click Update.

You can also use TMUI to change the setting by following these steps:
  1. Login to the CLI
  2. Run the following command to modify setting:
tmsh modify ltm profile http2 <http_profile_name> concurrent-streams-per-connection <desired_value>
  1. Run the following command to save configuration:
tmsh save sys config partitions all

Additional Information:

HTTP2 profile statistics will also do some help when troubleshooting such an issue.
By typing the following command you will see the goaway reasons.

tmsh show /ltm profile http2 <http2_profile_name>
 
It's recommended to run it several times, so that we can see the delta of each item.

For example:
GoAway Reasons

If you find Max Streams Exceeded is keeping increase, that indicates a higher value of Concurrent Streams Per Connection in http/2 profile is required.
