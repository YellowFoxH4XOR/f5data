Topic

Network Access resource variable attributes are logged in the Session Reports in XML format. The XML presents as <tag>tagdata</tag>.

For example, a lease pool that was created with the name GuestUsers will similar to the following example:

<leasepool_name>GuestUsers</leasepool_name>

Note: For more information about using the XML format with Network Access resources, refer to the Configuration Guide for BIG-IP Access Policy Manager.
