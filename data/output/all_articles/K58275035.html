Known Issue

The syncookie syn cache may increment when processing User Datagram Protocol (UDP) traffic.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP platform has an embedded Packet Velocity Acceleration (ePVA) chip.

    For more information, refer to K12837: Overview of the ePVA feature.

  • You configure a virtual server with a FastL4 profile that is set with the Packet Velocity ASIC (PVA) Offload Dynamic option enabled.
  • The FastL4 profile is configured with the Hardware SYN Cookie Protection or Software SYN Cookie Protection option enabled.
  • The virtual server processes both TCP and UDP traffic.

Impact

This issue may cause the BIG-IP virtual server syncookie threshold to unexpectedly exceed its limit, causing the system to skew virtual server syncookie statistics.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the system exceeds the syncookie threshold, you may observe, in the /var/log/ltm file, messages that appear similar to the following example:

    warning tmm5[<pid>]: 01010038:4: Syncookie threshold 16384 exceeded, virtual = <virtual server ip address:<virtual server port>

  • When you view virtual server statistics, the SYN Cookie Current SYN Cache value is disproportionately high in relation to processed TCP traffic.
