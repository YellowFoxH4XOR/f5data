Topic

You should consider using this procedure under the following condition:

  • You want to change the baud rate of the VELOS system controller serial console port.

Description

The VELOS system comprises of the chassis, system controllers and blades. The blades do not have a physical serial console port and their console can only be accessed via the system controllers' AOM menu. Each system controller has a physical serial console port and the default baud rate is 19200. F5 recommends that you set the baud rate on the connecting serial terminal to match the VELOS system controller serial console port baud rate, rather than modify the VELOS serial port configuration. However, if you cannot modify the connecting serial terminal settings, you can set the serial console baud rate on a VELOS system by performing the procedure in this article.

At the point of publishing, the serial console port baud rate can be changed using the following method:

  • The VELOS system controller AOM command menu

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have physical access to the VELOS system controller's serial console port.

Procedures

  • Setting the baud rate of the VELOS system controller serial console port using the AOM command menu

Setting the baud rate of the VELOS system controller serial console port using the AOM command menu

Impact of procedure: Setting the baud rate of the VELOS serial console port that is different from the connecting serial terminal may result in garbled console output. Ensure you have set the baud rate of the VELOS serial console port and the connecting serial terminal to match each other.

  1. Connect to the serial console port of the active system controller of the VELOS system using a serial terminal and a null modem cable.

    Note: The Active LED is illuminated in solid green on the system controller which indicates that it is the currently active controller.

  2. Access the AOM command menu by simultaneously pressing the ESC+SHIFT+9 keys. The system displays a command menu similar to the following:

    Active console               : system controller 1
    Physically connected console : system controller 1 serial port
     
    AOM Command Menu:
    B --- Set baud rate
    C --- Capture blade console
    CC -- Capture system controller console
    I --- Display chassis information
    P --- Power on/off blade
    PC -- Power on/off system controller
    R --- Reset blade CPU
    RC -- Reset system controller CPU
    U --- Front panel USB port
    Q --- Quit menu and return to console
     
    Enter Command:

  3. Press B to select the Set baud rate option from the AOM menu. The system displays a list of baud rate options for you to select; similar to the following example:

    Set console baud rate:
     
    1 -- 9600
    2 -- 19200 *
    3 -- 38400
    4 -- 57600
    5 -- 115200
     
    Select baud rate:

  4. Press the number representing your selection. The system prompts the following:

    Baud rate being set to 19200. Be sure to change the serial device baud rate to 19200 and press <Enter>, or garbled characters may appear.

    Press ENTER/RETURN to continue.

  5. At this time, the current console connection via the connecting serial terminal drops. You have to change the baud rate on your serial terminal to match the newly configured baud rate.
  6. Re-establish the serial connection to the controller.
  7. To exit the AOM command menu, press Q.
