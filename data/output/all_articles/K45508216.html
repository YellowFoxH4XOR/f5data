Topic

You should consider using this procedure under the following condition:

  • You want to view a list of iControl REST API endpoints and resources on the BIG-IP system from your browser

Description

The iControl REST API provides a table of contents page that you can access from a browser. This page lists all iControl REST collections and endpoints you can work with.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have administrative access to the BIG-IP system.

Procedures

Displaying the iControl REST table of contents

This procedure describes how to access the iControl REST table of contents with a browser.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open a browser on your workstation.
  2. Type the following URI in the browser. Replace <IP> with the BIG-IP management IP address:
    • BIG-IP 12.x and later:

      https://<IP>/mgmt/toc

    • BIGIP 11.x:

      https://<IP>/mgmt/shared/presentation/toc.html

  3. Enter your credentials to log in. The table of contents page appears.
  4. The table of contents contains a list of collections that are presented as links. You can select a link in the list to navigate down the hierarchy. For example, selecting ltm takes you to a list of the LTM module collections, and selecting /mgmt/tm/ltm/node displays a list of node resources.

    Note: /mgmt/tm is omitted from the URIs in the top-level table of contents page.

  5. Optionally, when you view the list of resources, if a resource has statistics data, you can select the Statistics button to display the data for the configuration objects.

    Important: When you view the list of resources, although you can add, delete, or edit configuration objects, F5 recommends that you use the BIG-IP Configuration utility to perform these tasks, because the system automatically saves the changes to the configuration files on disk and the utility requires a confirmation when you delete an object, preventing you from inadvertently deleting an object.
