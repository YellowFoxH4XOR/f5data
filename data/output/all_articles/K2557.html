Known Issue

All of the configuration files for the 3-DNS Controller are synchronized as normal in version 4.5; however, there is no mechanism (beyond rsync) to synchronize specific files between the 3-DNS Controllers. The functionality to edit the sync_list.mandatory list, or to use the edit copy list button in the Configuration utility, was removed in version 4.5.

Note: rsync is an open source utility that provides fast incremental file transfer. For more information about rsync, refer to http://samba.anu.edu.au/rsync/.

F5 Networks Product Development tracked this problem as CR27618. This functionality will not be restored in the 3-DNS version 4 software branch.
