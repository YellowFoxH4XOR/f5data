K000151207: Retrieve BIG-IP resource usage and performance metrics for monitoring or integration purposes via rest API.

Type
Support Solution
Published
2025-05-07
Updated
2025-05-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000151207

Description

BIG-IP systems support the collection of resource usage metrics including CPU, memory, disk, and network interface statistics—via the iControl REST API. These endpoints enable real-time monitoring and integration with external tools for system performance management.

Environment

Standard BIG-IP deployment with iControl REST API access enabled.

Cause

None

Recommended Actions

To collect resource usage data from BIG-IP using the iControl REST API, use the following endpoints:

  • System Performance Metrics:

    GET https://<BIG-IP-mgmt-ip>/mgmt/tm/sys/performance/system

  • CPU Usage:

    GET https://<BIG-IP-mgmt-ip>/mgmt/tm/sys/cpu

  • Memory Usage:

    GET https://<BIG-IP-mgmt-ip>/mgmt/tm/sys/memory

  • Disk Usage:

    GET https://<BIG-IP-mgmt-ip>/mgmt/tm/sys/disk

  • Network Traffic Statistics:

    GET https://<BIG-IP-mgmt-ip>/mgmt/tm/net/interface/stats

Additional Information

Discovering Available Endpoints:

The iControl REST API provides a table of contents page listing all available collections and endpoints. Access this in your browser at:

https://<BIG-IP-mgmt-ip>/mgmt/toc

For further details, refer to F5 article K45508216: Displaying the iControl REST table of contents.
