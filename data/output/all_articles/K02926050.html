Description

There are scenarios when BIG-IP Administrator needs the exact APM Client (System Default) or OPSWAT EPSEC (System Package) base iso images which are running on BIG-IP device.

For example as described in K11643, in order to generate OPSWAT OESIS report, the BIG-IP administrator requires EPSEC iso image which matches the one installed (and running) on BIG-IP device.  
As EPSEC iso images are cumulative, it's possible the situation when on BIG-IP the running image version is older (lower) than the available on F5 Downloads 
(for example the running image on BIG-IP is epsec-1.0.0-928.0.iso, while on F5 Downloads epsec-1.0.0-1058.0.iso is the latest available).

Environment

  • APM Client image
  • EPSEC image

Cause

None

Recommended Actions

  1. The base iso images (for APM Client and OPSWAT EPSEC) can be found in /usr/apm/images/ folder on BIG-IP. For example for TMOS 15.1.3, the base images are:

    [root@apm.local::Active:Standalone] config # ls -l /usr/apm/images/

    total 457956
    -rw-r--r--. 1 root root 308836352 Apr  8  2021 apmclients-7198.2021.121.659-5212.0.iso
    -rw-r--r--. 1 root root 160106496 Apr  8  2021 epsec-1.0.0-928.0.iso

    This read only folder is part of the volume set and is changed when choosing a volume to boot from

  2. The non-base iso images can be found in /shared/apm/images/. For example:

    [root@apm.local::Active:Standalone] config # ls -l /shared/apm/images

    total 558628
    -rw-r--r--. 1 tomcat tomcat 310079488 Jun 12  2020 apmclients-7195.2020.605.1243-5212.0.iso
    -rwxr-xr-x. 1 root   root   261386240 Aug 30 00:07 epsec-1.0.0-1025.0.iso

    This volume in in common shared storage and is read/write for updating the images.
