K000159814: Warning message in BIG-IQ "Certificate /Common/f5-ca-bundle.crt is missing a certificate file"

Description

  • When you are trying to deploy configuration from BIG-IQ to BIG-IP, you see below error message:
    Certificate /Common/f5-ca-bundle.crt is missing a certificate file
  • The warning message is not affecting your deployment. Whatever configuration you wanted to deploy is successfully onto the BIG-IP.

Environment

  • BIG-IQ
  • Managed BIG-IPs

Cause

  • BIG-IQ did not have the f5-ca-bundle certificate. It just had meta data. The actual certificate was missing.
  • f5-ca-bundle.crt is in Unmanaged state.

Answer/Recommended Actions

Make the f5-ca-bundle.crt in Managed state. Follow this SSL Certificates document.

Import f5-ca-bundle certificate from BIG-IP to BIG-IQ.

  1. Login into your BIG-IP
  2. Go to System > Certificate Management > SSL Certificate List. Click on f5-ca-bundle.
  3. Click on Export
  4. Either copy paste the certificate content in the BIG-IQ or download the certificate.
  5. In your BIG-IQ, go to Configuration > Certificate Management > Certificates & Keys and click on f5-ca-bundle.
  6. You will see certificate state as Unmanaged. Click on it import the certificate from the BIG-IP.
  7. Click Save and close.

You ignore importing key because there is no key for f5-ca-bundle.crt.

Additional Information

If you see "Device Error" when deploying configuration from BIG-IQ to BIG-IP, try to re-discover and re-import the BIG-IP.
