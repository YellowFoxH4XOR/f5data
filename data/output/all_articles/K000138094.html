Description

Access Denied Warning dialog pops up


Number of Errors: 4

You are not authorized for: masterkeyworkerstate

Details:

GET to /mgmt/cm/shared/secure-storage/masterkey is unauthorized.

You are not authorized for: standalone-check

Details:

GET to /mgmt/shared/standalone-check is unauthorized.

You are not authorized

Details:

GET to /mgmt/tm/sys/software/volume is unauthorized.

You are not authorized for: loginuimessageworkerstate

Details:

GET to /mgmt/shared/login-ui-message is unauthorized.


Environment

  • BIGIQ
  • Viewer-only roles assigned Users (for ex., Local Traffic & Network Viewer)


Cause

When you access any section of the UI that requires more than read access, you should see access denied warnings instead of errors.


Recommended Actions

Use user accounts with more than just read permissions.
