K28542451: After changing the management-ip address, the BIG-IP system may continue to use the old address

Type
Support Solution
Published
2022-02-25
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.0.1, 13.1.4, 13.1.3, 13.1.1, 13.1.0, 14.0.0, 13.0.0, 13.0.1
Source
https://my.f5.com/manage/s/article/K28542451

Description

When changing the management-ip address and/or gateway

  • After the management-ip address is changed, the BIG-IP system continues to use the old management-ip address
  • Device keeps responding to the old address
  • You might see the following error in /var/log/ltm: -- warning chmand[6584]: 012a0004:4: mcp_admin_ip_remove, delMgmtAddr() catch exception: Network Socket: Open Error [No such device], possibly nonexistent.

Environment

  • Changing the management-ip address using any of the methods, GUI, CONFIG, or tmsh
  • F5 BIGIP
  • Known Affected Versions: Refer to the Bug ID listed in the following section.

Cause

Bug ID 627506: Unable to change management-ip address.

Recommended Actions

  1. Make the changes and save them.
  2. Reboot the device.
  3. When the device returns, it should have the new management-ip address

Additional Information

None.
