Description

You should consider using these procedures under the following condition:

  • You would like to find out where the API paths are mapped to on the F5OS filesystem.

Environment

  • F5OS-A
  • F5OS-C
  • Management CLI
  • REST API

Cause

None
 

Recommended Actions
