K51446212: How to generate FCP usage report using an API call

Type
Support Solution
Published
2021-01-30
Updated
2024-04-02
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K51446212

Description
You want to create the FCP usage reports but do not have access to the GUI or the BIG-IQ does not have access to the Internet.
You want to add the reporting task to your existing automation tools.

Environment

  • BIG-IQ
  • FCP

Cause
It is not possible for you to automate utility billing and you don't have easy access to the GUI.

Recommended Actions

In this example we use Postman to send and receive API calls to the BIG-IQ and create, review and download the utility Billing report.
We assume postman is set up with basic authentication and the BIG-IQ has basic auth enabled.
We will make a note of all of the FCP CAT, license base registrations keys.

  1. Log into BIG-IQ as root and type set-basic-auth on to enable basic auth (set-basic-auth off will disable it after your testing).
  2. Set postman to "Post" in the address bar type https:// then the IP or hostname of your BIG-IQ followed by the following address /mgmt/cm/device/tasks/licensing/utility-billing-reports
    Example: https://10.1.2.3/mgmt/cm/device/tasks/licensing/utility-billing-reports.
  3. In the body create the following "raw" "JSON" replacing the "regkey" (highlighted in the example below) with your ELA Load license base registration key.
    {
        "regKey": "    XXXXX-XXXXX-XXX-XXXXX-XXXXX",
        "submissionMethod": "Manual"
    }
  4. Click on send.
  5. Review the response in Postman "body" and copy the contents of "id" highlighted in the example below.
    {
      "product": "big-iq",
      "version": "7.1.0.0.0.1511",
      "reportType": "pool usage",
      "poolType": "CLPv2",
      "regkey": "XXXXX-XXXXX-XXX-XXXXX-XXXXX",
      "poolRegkey": "YYYYY-YYYYY-YYYYY-YYYYY-YYYYYYY",
      "poolName": "Load-18",
      "periodStarted": "2021-01-29T17:55:44Z",
      "periodEnded": "2021-01-29T17:58:43Z",
      "records": [
        {
          "id": "    85474f5f-aadb-43db-8c64-bf0108ce37b3",
          "address": "10.2.3.4",
          "hostname": "bigip1.local",
          "type": "UNMANAGED",
          "sku": "F5-BIG-MSP-LTM-AWF3G-LIC-DEV",
          "uom": "yearly",
          "chargebackTag": "Example",
          "granted": "2021-01-07T18:59:02Z"
        }
      ]
    }
  6. To view the status of the billing report, change Postman to "Get" and in the address bar type https:// then the IP or hostname of the BIG-IQ followed by the following address /mgmt/cm/device/tasks/licensing/utility-billing-reports/<id>
    Example: https://10.1.2.3/mgmt/cm/device/tasks/licensing/utility-billing-reports/85474f5f-aadb-43db-8c64-bf0108ce37b3
  7. Click on send
  8. Review the response in Postman "body" and copy the contends of "reportUri" just the file name .json highlighted in the example below.
    {
        "id": "85474f5f-aadb-43db-8c64-bf0108ce37b3",
        "kind": "cm:device:tasks:licensing:utility-billing-reports:billingreporttaskitemstate",
        "name": "XXXXX-XXXXX-XXX-XXXXX-XXXXX starting 2021-01-29T17:58:43Z",
        "regKey": "XXXXX-XXXXX-XXX-XXXXX-XXXXX",
        "status": "FINISHED",
        "selfLink": "https://localhost/mgmt/cm/device/tasks/licensing/utility-billing-reports/1026df1b-001d-4183-b923-d08fe099f8d0",
        "username": "admin",
        "reportUri": "https://localhost/mgmt/cm/device/licensing/license-reports-download/    9eb22c8a-1046-486f-9d86-f2563a1fa6b2.json",
        "generation": 2,
        "userReference": {
            "link": "https://localhost/mgmt/shared/authz/users/admin"
        },
        "ownerMachineId": "XXXXX-XXXXX-XXX-XXXXX-XXXXX",
        "lastUpdateMicros": 1612029116024015,
        "submissionMethod": "Manual",
        "reportEndDateTime": "2021-01-30T17:51:54Z",
        "identityReferences": [
            {
                "link": "https://localhost/mgmt/shared/authz/users/admin"
            }
        ],
        "reportStartDateTime": "2021-01-29T17:58:43Z"
    }
  9. To download the Utility Billing Report send a "Get" to https:// IP address or hostname of BIG-IQ followed by the following address /mgmt/cm/device/licensing/license-reports-download/<report>
    Example: https://10.1.2.3/mgmt/cm/device/licensing/license-reports-download/9eb22c8a-1046-486f-9d86-f2563a1fa6b2.json
  10. Review the output of the json file and save it as "filename.json" (note lower case)
  11. send the file via email to vesubscriptions@f5.com
