K15752149: WAF Signature updates failing to deploy from BIG-IQ

Type
Support Solution
Published
2022-04-05
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K15752149

Description

WAF Signature updates fails to deploy from BIG-IQ and you found the following error in /var/log/restjavad.log 

[/cm/asm/tasks/signatures/update-signatures/5abcf90a-d2d3-4235-a355-18ce08df4f72/worker UpdateSignatureFilesTaskWorker] external adapter failed in fetching product version 15.1.3.; reason: timeout error while trying to connect to external config files server https://callhome.f5.com/soa/softwareupdate/. please make sure the server is available

Environment

  • BIG-IQ 
  • BIG-IP ASM
  • WAF Signatures

Cause

No communication between the BIG-IQ and https://callhome.f5.com/
i.e.
[root@BIG-IQ1-ltm01:Active:Standalone] scripts # curl -vlk https://callhome.f5.com
* Rebuilt URL to: https://callhome.f5.com/
* Trying 104.218.110.134...
* connect to 104.218.110.134 port 443 failed: Connection refused
* Failed to connect to callhome.f5.com port 443: Connection refused
* Closing connection 0 
curl: (7) Failed to connect to callhome.f5.com port 443: Connection refused
[root@BIG-IQ1-ltm01:Active:Standalone] scripts #

Recommended Actions

  1. From the CM bash run the following command:

    [root@BIG-IQ-8A:Active:Standalone] config # curl -vlk https://callhome.f5.com

  2. We expect to get HTTP/1.1 200 OK if you get something different then you should check your FireWall or anything that might be blocking the connection.
