Description
Although there have been engineering hotfixes on top of 13.1.x branch which contain fix of ID886273 / ID1000973, the customer may still experience TMM restart with SIGABRT signal.

The following error could be seen in /var/log/tmm:

<13> Sep 18 20:46:40 F5-HOSTNAME notice ** SIGABRT **

There will also a tmm core file generated in /var/core/. An example of the core file is as below:
/var/core:
total 65228
     8 drwxrwxrwt  2 root        root                   4096 Sep 19 00:46 2021 .
     8 drwxr-xr-x 34 root        root                   4096 Sep 19 07:19 2021 ..
 65212 -rw-r--r--  1 root        root               66701161 Sep 19 00:46 2021 tmm.bld0.0.4.core.gz

Environment

  • BIG-IP 13.1.x
  • Engineering Hotfix resolving ID1000973
  • SIGABRT seen in /var/log/tmm
  • tmm core file generated in /var/core

Cause
Due to failure in updating vmlinuz properly when the engineering hotfixes are being installed, problematic Linux kernel may still be in use by which the same symptom may still occur. This issue only affects engineering hotfix installation.

Recommended Actions

  1. Customers may upgrade to BIG-IP 13.1.4.1 or later to fix this issue. Since BIG-IP 13.1.4.1 and later releases include the fix code of ID1000973 and doesn't need any engineering hotfix, they aren't affected.
