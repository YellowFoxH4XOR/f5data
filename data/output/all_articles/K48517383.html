Description

IPSec and GRE tunnel traffic can be disrupted by the default AFM Device DOS Profile.

  • Messages similar to the following can be observed in /var/log/ltm
01010252:3: A Enforced Device DOS attack start was detected for vector IP uncommon proto, Attack ID 1234567890.
 

Environment

  • BIG-IP AFM
  • IPSec or GRE tunnels configured and in use

Cause

  • when Advanced Firewall Manager (AFM) module is provisioned on a BIG-IP, a Device DOS Profile is created and is automatically applied
  • a category in this Device DOS Profile is IP Uncommon Protocols, which limits the number of packets arriving at the device
  • this includes ESP packets for IPSec, and GRE encapsulation.
  • reaching this threshold disrupts IPSec tunnels causing them to flap and significantly limit IPSec and GRE tunnel throughput.

 

Recommended Actions

To mitigate this behavior, ESP and/or GRE should be moved to the Available column. Alternatively,  the configured thresholds can be increased.


 

Additional Information

This also applies to other IP Uncommon Protocols that may be in use.
