Description

  • Trying to import ASM policy into BIGIQ fails with the following error:
Import policy error : manual signature set CVE-2019-2725 must contain at least 1 signature reference

Environment

  • BIG-IQ
  • ASM Security policy

Cause

  • Imported ASM security policy contains signature set CVE-2019-2725
  • Attack signatures IDs 200004754, 200004755 and 200004756 are not present in BIG-IQ.

Recommended Actions

To have above IDs in the BIG-IQ you have to discover and import a BIG-IP ASM device running the latest ASU

  1. Discover and import any ASM device with updated attack signature into BIG-IQ
  2. Then import policy in question
