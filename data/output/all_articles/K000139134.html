K000139134: APM: oAuth Discovery may not work if Start button is not clicked in GUI

Type
Support Solution
Published
2024-06-11
Updated
2026-01-27
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000139134

Description

BIGIP APM administrator may notice that oAuth Discovery functionality is not working.

Environment

  • APM

  • oAuth Discovery

Cause

The Start button is not clicked in GUI under 'Access ›› Federation : OAuth Client / Resource Server : Provider' 

Answer/Recommended Actions

Make sure that the Start button is clicked under 'Discovery Task' column for oAuth provider in-question and the status is 'STARTED' under 'Task Status' column.

Additional Information

None
