Known Issue

iControl representational state transfer (REST) may fail to delete certain objects that require you to specify additional parameters when using the DELETE command.

This issue occurs when one of the following conditions is met:

  • You attempt to delete the cached entries in the DNS cache on the BIG-IP system using the following iControl REST DELETE command syntax:

    curl -sk -u <username>:<password> -H "Content-Type: application/json" -X DELETE https://<BIG-IP IP address>/mgmt/tm/ltm/dns/cache/records/rrset?options=cache,<cache-name>

    For example:

    curl -sk -u admin:admin -H "Content-Type: application/json" -X DELETE https://192.168.1.254/mgmt/tm/ltm/dns/cache/records/rrset?options=cache,myexamplecache

  • You attempt to delete cached Online Certificate Status Protocol (OCSP) responses on the BIG-IP system using the following iControl REST DELETE command syntax:

    curl -sk -u <username>:<password> -H "Content-Type: application/json" -X DELETE https://<BIG-IP IP address>/mgmt/tm/ltm/clientssl/ocsp-stapling-responses?options=clientssl-profile,<profile name>,virtual,<virtual name>

    For example:

    curl -sk -u admin:admin -H "Content-Type: application/json" -X DELETE https://192.168.1.254/mgmt/tm/ltm/clientssl/ocsp-stapling-responses?options=clientssl-profile,myexampleclientssl,virtual,myexamplevirtual

Impact

You are unable to delete certain objects on the BIG-IP system using the iControl REST DELETE command.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The iControl REST DELETE command receives an error response that appears similar to the following example:

    {"code":400,"message":"Query parameter options is invalid.","errorStack":[]}

Workaround

To work around this issue, you can delete objects using the Traffic Management Shell (tmsh) utility. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility.
  2. Depending on the object you are attempting to delete, perform either of the following:
    • If you are attempting to delete cached entries in the DNS cache, use the following command syntax:

      delete ltm dns cache records rrset type <record-type> cache <cache-name>

      For example, to delete all A records cached in the DNS cache myexampleDNScache, type the following command:

      delete ltm dns cache records rrset type A cache myexampleDNScache

    • If you are attempting to delete cached OCSP responses on the BIG-IP system, use the following command syntax:

      delete ltm clientssl ocsp-stapling-responses clientssl-profile <profile name> virtual <virtual>

      For example, to delete all OCSP responses cached in the myexampleclientssl profile associated to the myexamplevirtual virtual server, type the following command:

      delete ltm clientssl ocsp-stapling-responses clientssl-profile myexampleclientssl virtual myexamplevirtual
