Description

Upon booting into a RAID volume containing a newly installed instance of BIG-IP system software which is an Engineering Hotfix, the following messages may appear on console access:
The boot is stuck on this log and not able to boot up properly. 

"A start job is running for dev-disk-by...fb.device (28mins 52/s no limit)"

Environment

  • BIG-IP
  • When upgrading to version 15 hotfix version 
  • A hardware platform is configured to use RAID for redundancy

Cause

Bug ID 1049085

Recommended Actions

To fix the issue, perform the following steps:

  1. To leave the stuck console log, you can access the AOM command Menu by holding the 'Esc' key while simultaneously pressing the ' ( ' key:
    Esc (
  2. To reboot the device, set the R command and then the Q command:

    The AOM Command Menu:
    B - Set console baud rate
    I - Display platform information
    P - Power on/off host subsystem
    R - Reset host subsystem
    N - Configure AOM network
    S -  Configure SSH Server
    A -  Reset AOM
    Q - Quit menu and return to console
     
  3. At the Grub Menu, select the previous version to boot when displaying boot image selection. 
  4. Once it has successfully booted up, delete the newly-installed boot location (where the new hotfix version was installed).
  5. Try to install the plain base version first on which the hotfix is based instead of installing the hotfix directly.

    <For example>
    Base version: BIGIP-15.1.2.1-0.0.10.iso
    Hotfix version: Hotfix-BIGIP-15.1.2.1.0.375.10-ENG.iso
     
  6. Boot the new base version without installing the hotfix. 
  7. When the boot is done, then install the hotfix a normal way.
