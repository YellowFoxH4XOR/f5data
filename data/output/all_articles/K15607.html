Known Issue

A large data flow returning to a BIG-IP system from an Internet Content Adaptation Protocol (ICAP) server may be fully received by the BIG-IP system, but is not completely sent to the HTTP server.

This issue occurs when all of the following conditions are met:

  • Your system experiences one of the following situations:

    • A request adaptation, such as a POST request, with ICAP returning a large data stream destined for an HTTP server
    • A response adaptation, such as a GET response, with ICAP returning a large data stream destined for the HTTP client
  • The HTTP server or client is slower than the ICAP server sending the data.
  • An ICAP profile is associated with an internal virtual server.

Impact

HTTP connections may stop responding, time out, and truncate data.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Large POST requests are truncated
  • Large GET responses appear to stop responding
