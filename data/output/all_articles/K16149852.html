Description

Method to check the pool membership information through Command line of BIGIP.

Environment

  • BIGIP-LTM
  • Pool membership
  • Node

Cause

NA.

Recommended Actions

Command syntax from Advanced shell prompt to get the pool membership details:
tmsh -c 'cd /; list ltm pool recursive one-line' | grep <String Pattern> | awk '{print $3}'

<String Pattern> refers to any other form of string that can uniquely identify what you are looking for, e.g. an IP Address prefix.

For example, to locate the pool objects that uses the node IP address prefix with "10.2.2", use the following command:
tmsh -c 'cd /; list ltm pool recursive one-line' | grep 10.2.2 | awk '{print $3}'

Example of the output from the above command with 2 related pool nodes from 2 different partitions are displayed:
demo/HTTP-a
Common/HTTPS-x

Note: Change the tmsh folder path to highest level using "cd /;" is to capture all objects in all partitions. If you only have objects in /Common partitions, you can remove "cd /;" in the command. By default, tmsh command is only scoped on objects in the the default partition "Common" unless specified or redirected.
