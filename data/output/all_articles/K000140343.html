Description

When creating and configuring BIG-IP tenants on rSeries / F5OS-A:

  • What is the default Virtual Disk Size?
  • What is the minimum Virtual Disk Size?
  • What is the maximum Virtual Disk Size?

Environment

  • rSeries
  • BIG-IP tenant creation
  • Virtual Disks

Cause

None

Recommended Actions

Default and minimum virtual disk size varies by BIG-IP tenant image type:

ImageDefault/minimum
T122 GB
T250 GB
T4142 GB
ALL77/86/88 GB1

1The minimum virtual disk size is 77 GB for BIG-IP 15.1.x tenant image, 86 GB for BIG-IP 17.1.x, BIG-IP 17.5.x, BIG-IP 21.0.x tenant image, and 88 GB for BIG-IP 21.1.x tenant image.

Maximum virtual disk size varies by rSeries model:

ModelMaximum
r2x00297GB
r4x00297GB
r5x00434GB
r10x00434GB
r12x00931GB

Additional Information

It is possible to create multiple tenants whose combined virtual disk size exceeds overall storage space on the appliance. The virtual disk files are sparse, so will not actually consume disk space on the underlying physical disk until that space is used within the tenant(s).
