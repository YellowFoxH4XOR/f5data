Environment

  • BigIP I2X00

Cause

The lcdui watchdog is a feature in the LCD firmware meant to recover from a hang of the LCDUI. It requires that the LCDUI JavaScript periodically "kicks" the lcdui watchdog by calling a JavaScript function that is handled by the browser.
If it is not kicked for a period of time, the browser determines that the user interface must be hung and restarts the UI. This issue could also be related to  ID679061 and ID671741 .

Recommended Actions

  1. Shutdown the BIG-IP system by halt command.
  2. Disconnect power cable. then connect power cable again. 
  3. Boot the BIG-IP system.
