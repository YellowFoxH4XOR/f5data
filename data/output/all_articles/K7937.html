Topic

When attempting to access the logon page of the FirePass controller, you may receive an error message that appears similar to the following example:

SSL ciphersuite EXP1024-RC4-SHA not permitted. Please see your system admin.

If you receive this error message, your browser is configured to use SSL ciphers that are weaker than allowed by the FirePass controller's configuration. 

Note: Allowed ciphers are configured in the SSL Cipher Security and SSL Protocol Versions sections on the Device Management: Security: User Access Security page.

Normally, this error message occurs when the browser version is out of date, or when the browser is export strength, such as a browser that is required by U.S. export law to use only reduced-strength ciphers. Consult the documentation from your browser's manufacturer to determine whether you can upgrade to resolve this issue.

Alternatively, your browser may have the capability to use the high-strength ciphers required by the FirePass controller, but the browser has been configured to use only low-strength ciphers. Consult the documentation from your browser's manufacturer to determine how to configure the needed ciphers.
