K00150531: Support for encrypted volume on BIG-IP and BIG-IQ VE instances within the AWS environment

Type
Knowledge
Published
2019-01-28
Updated
2025-02-06
Applies to
  • Public Cloud
  • BIG-IP
  • BIG-IQ
  • Amazon Web Services
Source
https://my.f5.com/manage/s/article/K00150531

Issue

Old Behavior

In versions prior to BIG-IP Virtual Edition (VE) 12.1.3.2, 13.1.0.2, and 14.0.0, and BIG-IQ VE 5.3.0, instances running within the Amazon Web Services (AWS) environment do not support encrypted volume.

New Behavior

Beginning in BIG-IP 12.1.3.2, 13.1.0.2, and 14.0.0, and BIG-IQ VE 5.3.0, instances running within the AWS environment support encrypted volume.

F5 Product Development tracked this change as ID 471237.

Impact

BIG-IP VE and BIG-IQ VE instances now work with an encrypted disk in AWS.

Recommended Actions

None
