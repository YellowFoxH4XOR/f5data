Description

Unable to discover the BIG-IP ASM configurations in the BIG-IQ CM.

Following errors are noted in the GUI
'Missing/empty parameter: name' was returned : java.lang.IllegalArgumentException: Missing/empty parameter: name

Also following errors are noted in the in /var/log/restjavad.0.log
restjavad.0.log:[ERROR][05 Aug 2021 14:31:52 SGT][/cm/asm/tasks/discover-config/ba99ba41-cd80-4bef-8b30-af4e42bd870f/worker AsmDiscoveryTaskWorker] Error querying 'ASM Policy - Filetype' from path '/mgmt/tm/asm/policies/qCytdHsSLR0x0sfAJvyP6A/filetypes' on device ASM.example.com (10.0.80.43), message 'Missing/empty parameter: name' was returned : java.lang.IllegalArgumentException: Missing/empty parameter: name

Environment

  • BIG-IP ASM
  • BIG-IQ Centralized Management (CM)
  • Discovering the ASM configurations in BIG-IQ Centralized Management

Cause

 None

Recommended Actions

  1. Find out the rest_uuid  from the logs recorded in the  /var/log/restjavad.0.log. 
    For example, in below logs rest_uuid  is qCytdHsSLR0x0sfAJvyP6A

    restjavad.0.log:[ERROR][05 Aug 2021 14:31:52 SGT][/cm/asm/tasks/discover-config/ba99ba41-cd80-4bef-8b30-af4e42bd870f/worker AsmDiscoveryTaskWorker] Error querying 'ASM Policy - Filetype' from path '/mgmt/tm/asm/policies/qCytdHsSLR0x0sfAJvyP6A/filetypes' on device F5ASM.training.com (10.0.80.43), message 'Missing/empty parameter: name' was returned : java.lang.IllegalArgumentException: Missing/empty parameter: name
  2.  Enter below command from SSH. Identify the virtual server and rest_uuid association.

    [root@ASM.example.com:Active:Standalone] config # mysql -uasm -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "select name, id, rest_uuid from PLC.PL_POLICIES"

    +---------------+----+------------------------+
    | name          | id | rest_uuid              |
    +---------------+----+------------------------+
    | /Common/Test  |  1 | qCytdHsSLR0x0sfAJvyP6A |
    | /Common/Test1 |  2 | 6k9DBocL3keTcKGFNPJvow |
    +---------------+----+------------------------+
     
  3. Edit the ASM policy after identifying from virtual server.
  4. Navigate to Security  ››  Application Security : File Types : Allowed File Types and choose ASM policy identified from step 2.There should be filetype with the empty value
  5. Create the wild card file type before deleting the filetype with empty value.
  6. Remove  the empty file type and save the configuration.
  7. Proceed to rediscover the ASM configuration in BIG-IQ
