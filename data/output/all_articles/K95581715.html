K95581715: LTM policy for a redirect doesn't work having a special character in the URI

Applies to

Source
https://my.f5.com/manage/s/article/K95581715

Description

When creating an LTM policy for a redirect, if the destination URI contains a special character the policy/rule will not be created. For instance, a redirect to /home/#/ will show the following message:

  • 01071748:3: Policy '/Common/redirect-specchar', rule 'char'; invalid path, value '/home/#/'.

Environment

  • LTM policy for a redirect
  • The redirect contains a special character in the URI

Cause

The BIG-IP requires the proper URL encoding of the special character to process the URI correctly.

Recommended Actions

Replace the special character with the percent-encoding value of the special character. For instance, for /home/#/ the correct URI would be /home/%23/
