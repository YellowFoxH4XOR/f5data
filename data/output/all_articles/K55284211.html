K55284211: SNMP /32 allow mask does not work in the BIG-IQ system GUI

Type
Support Solution
Published
2020-12-18
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K55284211

Description

SNMP allow list in the BIG-IQ GUI with a /32 mask in CIDR format will cause polling to fail. For example, SNMP polling fails for a mask of (1.2.3.4/255.255.255.255).

Environment

  • Configuring SNMP allow lists in the BIG-IQ GUI with a /32 mask in CIDR format.

Cause

This issue is caused by the BUGID 643645

Recommended Actions

  • When configuring BIG-IQ SNMP agent, enter the host portion of the subnet and then the mask.
  • Delete any previously created SNMP allowed address on the BIG-IQ and create another using tmsh with mask 255.255.255.255 and see that SNMP polling now works.
