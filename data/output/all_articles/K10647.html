Topic

The following Windows file servers have been certified for use with ARX snapshots:

  • Windows Server 2003
  • Windows Server 2008

The ARX system manages snapshots on these file servers through Windows Remote Management (WinRM). WinRM is included with Windows Server 2008; however, you must install WinRM on a Windows Server 2003 system. The ARX system requires the Windows server to use WinRM version 1.1 or later.

Important: For information about an issue in which ARX-managed snapshots fail with WinRM version 2.0, refer to K10859: ARX-managed snapshots will fail for a Windows server running Windows Remote Management (WinRM) version 2.0.

Note: For information about WinRM, refer to http://msdn.microsoft.com/en-us/library/aa384426(VS.85).aspx.

Important: When installing WinRM on a Windows Server 2003 system, F5 Networks recommends downloading the most current WinRM version available. The version of WinRM included on the Windows Server 2003 install media is out of date and does not correctly set up the ports for Microsoft Volume Shadow Copy Service (VSS) use by the ARX.

If the version of WinRM on the Windows Server 2003 install media is used, the server will respond with an HTTP Status: 400 (Bad Request) response and the ARX system's attempt to create a VSS snapshot will fail with error messages that appear similar to the following example:

: The HTTP request was rejected by the server. HTTP Status: 400.
