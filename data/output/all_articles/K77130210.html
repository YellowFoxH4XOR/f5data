Description

The cli preference setting, which allows for configuring tmsh preferences, is a per-user setting and is configurable for either local or remotely authenticated users on the BIG-IP system.

Environment

  • User with working login to BIG-IP system
  • User having tmsh access
  • BIG-IP versions: 11.x - 16.x

Cause

The cli preference setting is a per-user setting and not a system-wide setting. If any setting such as display-threshold, pager etc are modified by a user via tmsh, those changes will only be saved for that user and it will be reflected within /config/bigip_user.conf file.

Recommended Actions

If the cli preference settings have to be modified to a certain standard value for all users with CLI access to the BIG-IP system, then the recommendation is to ensure that each user makes the changes manually by logging into the system and modifying respective setting to desirable values.

Additional Information

After modifying cli preference setting through tmsh, a configuration disparity is detected in memory and that will result in devices going out of sync, because the devices in the group will exchange MCP messages and it'll show the device on which the change was made has now got an updated commit ID value and is eligible to sync that config to devices in the group.

Whenever you issue a sync, it is the disk configuration files (bigip.conf, bigip_user.conf, bigip_base.conf etc.) that gets synced to devices in the group, so it is imperative to issue a tmsh save sys config partitions all command before issuing the Config Sync operation.
