 Recommended Actions

DDoS Dynamic Signatures - Definitions of the parameters


IP Hdr Size. Size of IP Header Length from 20 to 60 bytes in 8 groups.

IP Flags. Flags to control fragmentation Don't Fragment (DF) and More Fragments (MF):

  • Fragmented
  • Fragmented + DF
  • Unfragmented
  • Unfragmented + DF

IP Proto. Select IPv4 or IPv6 protocol from below:

  • TCP
  • UDP
  • ICMP
  • IGMP

IP ToS/TC. The options are 64 groups with 4 values from 0-3 to 252-255 matching the type of service ToS, is the second byte of the IPv4header.

IP Pkt Size. This 16-bit field defines the entire packet size in bytes, including header and data. The minimum size is 20 bytes (header without data) and the maximum is 65,535 bytes.

IP TTL/HL. Time to live (TTL)

SrcIP. Source IP address

SrcPort. Source port number between 0 to 65535

SrcIP Upper. Decimal value of source IP bits 24 to 34 XOR bits 16 to 23 ie. 10.20.30.40 => 10 XOR 20 => 30

SrcIP Middle. Decimal value of source IP bits 8 to 15 of source IP address ie. 10.20.30.40 => 30

SrcIP Lower. Decimal value of low order 8 bits of source IP address ie. 10.20.30.40 => 40

 

DstIP. Destination IP address

DstIP Upper. Decimal value of destination IP bits 24 to 34 XOR bits 16 to 23 ie. 20.20.100.200 => 20 XOR 20 => 0

DstIP Middle. Decimal value of destination bits 8 to 15 of source IP address ie. 20.20.100.200 => 100

DstIP Lower. Decimal value of low order 8 bits of destination IP address ie. 20.20.100.200 => 200

 

DstPort. Destination port number between 0 to 65535

TCP Flags. Every flag is a bit in the TCP header:

  •    FIN: Last packet from sender
  •    SYN: Synchronize sequence numbers
  •    RST: Reset the connection
  •    PSH: Push function
  •    ACK: Indicates that the Acknowledgment field is significant
  •    URG: Indicates that the Urgent pointer field is significant

TCP HdrLen. TCP header size field or it's also called offset, the field contains 4 bits, then, it's possible 16 possible values, the maximum is 60 bytes.

ICMPv4 Type/Code. ICMP Options for ICMP protocol operated in IPv4, descriptions can be found here https://en.wikipedia.org/wiki/Internet_Control_Message_Protocol#Control_messages

ICMPv6 Type/Code. ICMP Options for ICMP protocol operated in IPV6, descriptions can be found here https://en.wikipedia.org/wiki/ICMPv6#Types

 

SrcPort Upper and SrcPort Lower have the range from 0 to 255. This is 8 bits, 256 is 2^8. A port number can be from 0 to 65535, 65536 is 2^16. Then, it's the same as the concatenation of two strings of 2^8. For example, the port is 40000:

 

Port 40000 = 1001110001000000 = 10011100 + 01000000 = 156 + 64

 

SrcPort Upper. In above example, SrcPort Upper is 156

SrcPort Lower. In above example, SrcPort Lower is 64

 

The same applies for DstPort Upper and DstPort Lower. Then another example will be:

 

Port 50000 = 1100001101010000 = 11000011 + 01010000 = 195 + 80

 

DstPort Upper. In above example, DstPort Upper is 195

DstPort Lower. In above example, DstPort Lower is 80
