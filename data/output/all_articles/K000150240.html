Description

Is it possible for F5 to collect user credentials during authentication and directly pass them to Azure AD, bypassing the Azure AD login page?

Environment

  • BIG-IP APM
  • Microsoft Entra ID (Azure Active Directory)

Cause

Azure AD Login Flow Requirement.

Recommended Actions

BIG-IP APM cannot pass user credentials directly to Azure AD without going through its login flow. The authentication process involves Azure AD login flow to ensure secure and proper validation of user credentials.

Additional Information

Microsoft implements this restriction to ensure compliance with OAuth 2.0 and OpenID Connect protocols for secure authentication. Visit Microsoft's website for information.
