Topic

The BIG-IP APM system provides a local user database for access policy authentication that allows you to create multiple local user database instances, which enables on-box access authentication, segments users, and maintains individual user information.

Description

The BIG-IP APM local user database consists of the following two components:

  • Local database instance: Each database instance contains a database of user data and database instance configuration, such as lockout interval, lockout thresholds, and a partition path system. You can configure multiple local database instances on a BIG-IP system, but each must have a unique name.

  • Local user data: The local user data contains user information, such as username, passwords, email, group membership, and the local user database instance they belong to. 

When you upgrade the BIG-IP system, it backs up and restores both components automatically for you. However, when you manually generate and restore a user configuration set (UCS) archive, the system includes both components, but restores only the local database instance. The following table summarizes both scenarios.

ScenarioLocal database instanceLocal user data
Manual UCS archive generation and restore
Database instance is saved in the UCS file and restored    
 		User data is saved in the UCS file but not restored 
BIG-IP system upgradeUser data is saved in the UCS file and restored 

Recommendations

To maintain full functionality, you must back up and restore the local database instance and the local user data separately. To do so, perform the following two procedures:

Backing up the local database instance

You can generate and restore a UCS archive file. For more information, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.

Backing up the local user data

To back up and restore local user data, you can use one of the following two methods:

  • Export and import user data in a CSV file using the Configuration utility
  • Back up and restore the local user database using the ldbutil command line utility

For more information about both methods, refer to K59100837: Backing up and restoring user data in the BIG-IP APM local user database.
