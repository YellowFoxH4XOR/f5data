Topic

When using the BIG-IP APM system, you can enter URIs that various websites may use to terminate sessions in the access profile configuration. The access profile monitors the URIs accessed  and it simultaneously terminates the BIG-IP APM session to the website as the session to the website ends. This behavior occurs if the system encounters a URI defined in step 4 of the following procedure:

Configuring the Logout URI Include option in an access profile

  1. Log in to the Configuration utility.
  2. Navigate to Access > Profiles / Policies

    Note: For BIG-IP 12.x and earlier, navigate to Access Policy > Access Profiles.

  3. Click the name of the access profile you want to configure.
  4. For Configurations, enter the URI for the web resources the user may access that terminates the session. For example, /logout.htm, /auth/signout.aspx.

    Important: The URI entered must be an exact match. No wildcards are supported. URL parameters are also not supported.

  5. Click Add.
  6. Repeat steps 4 and 5 until you have entered all of the URIs you want the access profile to monitor.
  7. Click Update.
  8. Click Apply Access Policy.
  9. To apply the change, click Apply Access Policy on the resulting page.

This option does not work for sessions to resources in which the permission is gained by using an access policy resource assignment, such as web applications or Network Access.
