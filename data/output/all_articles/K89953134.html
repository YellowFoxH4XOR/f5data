K89953134: Failover for Virtual servers are not working, when MAC masquerade is in use.

Type
Support Solution
Published
2022-05-18
Updated
2023-02-21
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K89953134

Description

When failover, connection to VIP fails when MAC masquerade is set. (failover itself works.)

Environment

  • F5OS
  • v1.x
  • Failover
  • MAC masquerade
  • vlan is shared by multiple tenants.

Cause

  • Bug ID 1072209 (F5OS)
  • Bug ID 1084873 (BIG-IP)


Using MAC masquerading on a traffic group will result in packet drops for any vlan that is shared by more than one tenant.
If a tenant's vlans are not shared with any other tenants, then MAC masquerading may be used. 
 

Recommended Actions

Disable MAC masquerading 
or 
Do not share vlan among tenants
