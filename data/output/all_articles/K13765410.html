Topic

If you upgrade a BIG-IP partition to BIG-IP 13.1.0 or later and then downgrade the partition to a version earlier than BIG-IP 13.1.0, you may be required to reactivate the license.

Description

Due to changes in licensing behavior in BIG-IP 13.1.0, if you attempt to downgrade a partition from version BIG-IP 13.1.0 and later to a version earlier than BIG-IP 13.1.0, you may encounter one or more of the following symptoms:

  • When you run the failover_status command at the command line, the system returns a message similar to the following:

    ModuleNotLicensed:LICENSE INOPERATIVE:Standalone] config # failover_status
    LicenseInoperative

  • An error message similar to the following example appears in the /var/log/ltm file:

    localhost emerg mcpd[5682]: 01070608:0: License is not operational (expired or digital signature does not match contents).

This behavior is expected and is a result of changes in licensing behavior. When the new licensing feature is present and you attempt to boot a previous version, the BIG-IP system fails to initialize due to license validation failure. This behavior occurs any time you use a license for BIG-IP 13.1.0 or later with a software version earlier than BIG-IP 13.1.0. For example, if you downgrade a BIG-IP 13.1.0 partition to BIG-IP 12.1.2 and then attempt to boot to the BIG-IP 12.1.2 partition. This behavior does not occur when rebooting to a previously installed volume with an earlier version than BIG-IP 13.1.0 or when installing from a USB thumb drive and reactivating the license in a version earlier than BIG-IP 13.1.0.

This behavior applies to the following platforms and their variants (NEBS, FIPS):

  • iSeries i2x00, i4x00, i5x00, i7x00, i10x00, i11x00
  • Herculon HRC-i2800, HRC-i5800, HRC-i10800
  • 2x00, 4x00, 5x00, 7x00, 10x00, 12x00

Recommendations

You can mitigate this behavior by relicensing your system to the software version from which you previously downgraded. This removes the new licensing item present in the license.

Impact of procedure: Your system will not be operational until you reactivate the license.
