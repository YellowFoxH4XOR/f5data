K33099205: AS3 module stops functioning after software upgrade

Type
Support Solution
Published
2020-06-25
Updated
2023-02-21
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K33099205

Description
Upgrading BIG-IP may cause AS3 to stop functioning. 

Environment

  • BIG-IP
  • AS3
  • iApps

Cause
AS3 module may be removed during OS upgrade. 

Recommended Actions

  1. Uninstall AS3 and the Service Discovery package(s) from the BIG-IP Configuration utility.
  2. Run the following command from the command line before AS3 can be installed: touch /var/config/rest/iapps/enable.
  3. Install AS3
    • Click "iApps ›› Package Management LX" tab
    • Import f5-appsvcs.rpm (Download from https://github.com/F5Networks/f5-appsvcs-extension)
    • Upload it
  4. Confirm AS3 installed by sending a GET to the endpoint.

    Example : 
    [root@LTM1.example.com] config # curl -sk -u admin:admin -H "Content-Type: application/json" -X GET https://<IP address of Host>/mgmt/shared/appsvcs/info
    {"version":"3.14.0","release":"4","schemaCurrent":"3.14.0","schemaMinimum":"3.0.0"}
