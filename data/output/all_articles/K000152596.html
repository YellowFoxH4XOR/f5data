K000152596: Flood vector only works when working together with Sweep vector

Type
Support Solution
Published
2025-07-18
Updated
2025-09-30
Source
https://my.f5.com/manage/s/article/K000152596

Description

When configuring Endpoint Flood vector while Endpoint Sweep vector is disabled we notice that stats are 0 for Flood vector.

 

Environment

  • BIG-IP AFM provisioned.
  • DoS profile attached to a virtual server.
  • Endpoint Sweep vector disabled and Endpoint Flood vector enabled.

 

Symptoms

When we configure the Endpoint Flood vector and a flood attack reaches the AFM exceeding the Endpoint Flood configured threshold, we will notice that the attack is not detected by this vector and in fact no stats are increased for it.

In order to confirm if we are matching this issue we need first to confirm the configuration for the involved vectors:

tmsh list security dos device-config dos-device-config dos-device-vector { flood sweep } | grep state
            state mitigate
            state disabled

Then we need to confirm that stats are not increasing for the Endpoint Flood vector and attack is not detected:

tmsh sho security dos device-config dos-device-config | grep -A48 'Flood attack'

 

Recommended actions

If we need to work with Endpoint Flood vector then we recommend to activate both Endpoint vectors, Sweep and Flood. In case it is mandatory to not using Sweep vector then enable it and set a very high values so it is never matched.
