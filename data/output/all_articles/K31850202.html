Description

OCSP Stapling is currently not supported for Configuration Utility and DNS iQuery protocol.

Environment

  • BIG-IP LTM (WebUI)
  • BIG-IP DNS (iQuery)

Cause

Not applicable

Recommended Actions

For BIG-IP DNS 16.x and later iQuery communication, consider configuring CRL verification. For more information, refer to K38753397: Configure a CA-signed device certificate and CRL verification for iQuery communication.
