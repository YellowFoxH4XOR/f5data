K000136036: [F5OS] BIG-IP tenant assigns MAC address of 0:0:0:0:0:0 to all trunks

Type
Support Solution
Published
2023-08-30
Updated
2023-08-30
Source
https://my.f5.com/manage/s/article/K000136036

Description

Upon reviewing the configuration of a trunk interface in the GUI of a BigIP tenant, you may notice that the MAC address assigned is showing only zeros. (0:0:0:0:0:0)
 

Environment

  • F5OS-A
  • rSeries 5000/10000
  • v1.5.0


Cause

On r5000 platforms and r10000, you only see tenants inside the guest for use in HA groups (for score-based failover). The tenant does not otherwise know (or rely on) VLAN<>TRUNK association information. As consequence, It doesn't assign a MAC address as it is not needed.


Recommended Actions

This is the current behavior at the moment of this publication.
