K000135241: How to upload qkview files to F5 support cases using the iHealth API

Type
Support Solution
Published
2023-06-30
Updated
2026-08-13
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000135241

Overview:

  • A Client Access Key is needed. This is a base64 encoded value for Client ID and Client Secret.  This will be created once you generate a Client ID and Client Secret using the following procedure:
    K000130498: Generating new iHealth API credentials using iHealth API token service
    Note: The Client Access Key will last for 180 days.
  • The Client Access Key is used to generate a bearer token which is needed for uploading qkview files via the iHealth API.
    Note: The bearer token lasts for 30 min.
  • Run a curl command that contains the bearer token, support case number, and local qkview file location to be uploaded.

The following is the Client Credentials window once the procedure in K000130498 is completed. Along with the Client ID, Client Secret, copy the Request to obtain the Bearer access token which is your Client Access Key. This key can be used to generate a new bearer tokens for 180 days.

 

 

Procedure:

You should now have your Client Access Key which would look similar to the following within a curl command:

  2. To use the iHealth API to upload the qkview, create a curl command from a system with internet access and also has the qkview file on it using the following syntax:
    curl -v -H "Authorization: Bearer <Bearer_Token>" -H "Accept:  application/vnd.f5.ihealth.api" --user-agent "MyGreatiHealthClient" -o - -F qkview=@"<full path to local file>" "https://ihealth2-api.f5.com/qkview-analyzer/api/qkviews?visible_in_gui=true&f5_support_case=<case number>"
