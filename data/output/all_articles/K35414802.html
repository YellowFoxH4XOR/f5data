Issue

Error Message

01070734:3: Configuration error: The maximum number of configured FQDNs in the system must not exceed 1024

Message Location

You may encounter this message in the following locations:

  • The BIG-IP Configuration utility
  • The var/log/ltm file
  • The TMOS Shell (tmsh)

Description

This message occurs when the following condition is met:

  • You attempt to configure a fully qualified domain name (FQDN) entry that exceeds the maximum supported limit of 1024 for the IPI (IP Intelligence) category.

The BIG-IP AFM supports 1024 FQDN when FQDNs are mapped to IPI categories.

Impact

The system rejects the new FQDN entry that exceeds the configured maximum limit.

Recommended Actions

None
