Known Issue

Attempts to access Citrix HTML5 resources may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM virtual server is configured to reference a Citrix HTML5 resource.
  • The virtual server is also configured with an iRule for HTTP.

Impact

Attempts to access the Citrix resource fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Messages similar to the following example are logged to the /var/log/apm file:

    err tmm[3887]: 01220001:3: TCL error: /<partition>/<profile name> <HTTP_REQUEST> - Prerequisite operation not in progress (line 20) invoked from within "HTTP::path"
    err tmm[3887]: 01230140:3: RST sent from <virtual server ip address:port to <user ip address:port>, [0x1c581ee:1288] iRule execution error

  • When you attempt to access the Citrix resource virtual server, you receive a TCP reset from the virtual server.

Resolution

Workaround

To work around this issue, you can modify the iRule to use priority 1. For more information, refer to the iRules priority iRules command page on F5 Cloud Docs.
