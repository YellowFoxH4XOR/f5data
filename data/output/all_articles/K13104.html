Known Issue

Copying a report file from the ARX may fail with an error message.

This issue occurs when all of the following conditions are met:

  • The report was initially viewed via the ARX Manager GUI
  • The report is being copied via the ARX CLI copy command
  • The report is being copied to a remote destination via FTP or SMTP (e-mail)

Initially viewing the report using the ARX Manager GUI causes incorrect permissions to be set on the internal directories in the logging partition. When this occurs, the directory is inaccessible to the CLI process making the subsequent request.

Impact

Unable to copy a report file off of the ARX via the CLI.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The copy command will fail with an error message that appears similar to the following example:

    % ERROR: XML_CHUNKER_FAILED (40960108): XML chunker failed: 256
  • The file is not copied.

Workaround

To work around this issue, you can copy the report file from the ARX using the ARX Manager GUI. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the ARX Manager GUI.
  2. Click Reports in the left navigation menu.
  3. Select the check box next to the desired report file.
  4. Click the Download button.
  5. Navigate and save the file to the desired location.
