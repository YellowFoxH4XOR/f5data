Known Issue

rSeries 2000/4000 system Non-volatile Memory Express (NVMe) solid-state drive (SSD) may fail to initialize after multiple reboots. The system also fails to boot after restarting the device without completely turning it off (warm reboot). Power-cycling will clear that instance of the issue.

This issue occurs when all of the following conditions are met:

  • The NVME SSD installed in the system is a 480GB Micron NVME SSD, model 7450_MTFDKBA480TFR . For example, the model:  Micron_7450_MTFDKBA480TFR

Impact

The system is unresponsive, and services are not available.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe the following messages in the System Event Logs (SEL) located at /var/log/platform/sel:
    MCA Error-Reporting Registers Capture. Bank: 6 Core: 0 STATUS Register: 0x0419 Value: 0xb980000000000e0b
    MCA Error-Reporting Registers Capture. Bank: 6 Core: 0  MISC Register: 0x041b Value: 0x0000000000180000

Workaround

To work around this issue, you can disable ASPM (Active State Power Management) and L1 Substate in the system BIOS, preventing the drive from entering low power mode. To do so, perform the following procedure:

This workaround is permanent and reboots or system behavior will not affect it. If however the BIOS CMOS data is manually reset to defaults, you must reapply the procedure.

Impact of workaround: Performing the following procedure should not have a negative impact on your system. Your system does not incur risk or performance penalty.

  1. Power up the system.
  2. Select the C key on the keyboard repeatedly as the system begins to boot.
  3. After the BIOS setup screen appears, select Platform Configuration.
     
  4. Select PCH-IO Configuration and select ENTER.
    Note: There may be a delay of up to several seconds before the screen changes. Do not repeat your keystrokes quickly.
  5. Select PCI Express Configuration and select ENTER.
     
  6. From the PCI Express Configuration menu, select PCI Express Root Port 1 and select ENTER.
     
  7. To disable ASPM, select ASPM and then select Disabled.
     
  8. To disable L1 Substate, select L1 Substate and then select Disabled
     
  9. Verify that you disabled ASPM and L1 Substate.
     
  10. Save and exit the BIOS using one of the methods as appropriate:
    • If you see F4: Save and Exit in the menu as follows, select the F4 key and select Yes.
       
    • Otherwise, 
      • Select ESC slowly several times until prompted to Save and Exit.
      • Select Save and Exit.
  11. After the system reboots, power it down and then restart it.
