Description

You encounter the following deployment error in SSLO guided configuration UI when deploying an SSL Orchestrator topology.

Deployment error
[OrchestratorConfigProcessor] Deployment failed for Error: Operation to the configProcessor timed out after waiting 30 seconds. Please increase the timeout or contact the iApp writer for further instructions.

You applied a workaround of ID922069 however the problem isn't resolved.
 

In /var/log/restjavad.0.log file, you would see a similar error message is logged and it's regarding the size of the file /var/named/config/named.conf.

[WARNING][8021][14 May 2023 02:45:28 UTC][8100/shared/iapp/update-named-conf DNSServiceHelperWorker] Error: file /var/named/config/named.conf size unreasonable 28

The /var/named/config/named.conf is a BIND configuration file(detail refer to K6963). For some reason, the unit may have a non-default configuration named.conf or a corrupted file.

For example /var/named/config/named.conf has this content: 

# cat /var/named/config/named.conf
options {
forwarders {};
};

Environment

SSLO version v7.x
named.conf BIND configuration file
 

Cause

a broken named.conf file or incorrect configuration in named.conf
 

Recommended Actions

To work around the issue, reverting named.conf back to a default value or correcting the configuration in named.conf.
It's advised to check with the customer why making a custom named.conf, because incorrectly editing the DNS configuration files on a BIG-IP DNS system can cause issues, such as the ZoneRunner utility or BIND failing to start properly.
