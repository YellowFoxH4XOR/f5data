K000134844: Solarwinds reporting wrong high memory

Type
Support Solution
Published
2023-05-30
Updated
2023-05-30
Source
https://my.f5.com/manage/s/article/K000134844

Description

Solarwinds reporting unusually high memory consumption, despite normal memory levels observed in the system.

Environment

Big-ip
Solarwinds

Cause

This issue lies in Solarwinds' monitoring methodology. Solarwinds utilizes SNMP (Simple Network Management Protocol) to gather information, but in this case, it is not using F5's official OIDs (Object Identifiers). As a result, the information obtained by Solarwinds becomes meaningless. F5 recommends using only the F5-supplied MIBs (Management Information Bases) for accurate monitoring. 

Recommended Actions

To resolve this issue, it is essential to configure Solarwinds to monitor the supported F5 OIDs. These supported OIDs can be found in the MIB files located on your Big-ip device under /usr/share/snmp/mibs/. If the specific OID you are looking for does not exist in the MIB files, it indicates that the OID itself does not exist.

Additional Information

For an easy way to search for the OID numeric value from a known variable string, refer to F5's knowledge base article K6854: Finding the OID numeric value from a known variable string
