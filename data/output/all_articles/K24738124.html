Description 

Users are unable to Remote Desktop from macOS after the Microsoft RDP Client is Upgraded.

The RDP stops responding and no error messages are displayed.


Environment

  • RDP Client Upgraded to version 10.6.0 ( 1872 )


Cause

There is a known issue with Microsoft Remote Desktop Version 10.6.0 (1872).


Recommended Actions

Upgrade to Microsoft Remote Desktop version 10.6.1 or above.  


Additional Information

None.
