Description

From version 13.1, in iControl REST, the maximum of 100 authentication tokens per user is imposed. When the 101-th token is requested, you will get the following warning message in /var/log/restjavad.x.log

user <name> has reached maximum active login tokens

where <name> is the name of the user.
 

Environment

  • BIG-IP
  • v13.1.x and later
  • iControl REST
     

Cause
This limitation applies to all the users irrespective of the role (including administrator) except the default admin. There is no limitation for version 13.0.x and older.

The error may disappear after some time, because the lifespan of a token is 20 min (1200s) by default. A token purged by timeout will make a room for another token.

 

Recommended Actions

To avoid this limitation, you may want to consider:
  • Set the lifespan shorter.
  • Reuse the same token. Often a user creates a token for each single query. Refactor the code so that all the query/sessions use the same token.
  • Explicitly remove the token after it is used.

You can check the active tokens by running the below commands on CLI
 
tmsh list mgmt shared authz tokens 
curl -sku <admin>:<pass> https://<host>/mgmt/shared/authz/tokens
