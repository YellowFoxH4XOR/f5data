Known Issue

This is the result of a known issue. When multiple proxy users are configured, the ability to add a description is beneficial for administration; however, there is no method for adding a description for a proxy user.

F5 Product Development tracked this issue as ARX ID 33814 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX release notes.

Note: Beginning in ARX version 5.1.0, a Description field was added for the Edit CIFS Proxy User page in the ARX Manager GUI, and a new description mode specific command was added as an option for the CLI proxy-user command. For information about the CLI proxy-user command, refer to the ARX CLI Reference Guide.
