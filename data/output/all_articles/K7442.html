Topic



The loopback interface (lo) is an option in the drop-down menus for routing rules and routing tables, when the Advanced Mode view is displayed on the Routing tab of the Device Management: Configuration: Network Configuration page. When adding a rule, or a route to a routing table, the Interface drop-down menu lists all the physical interfaces for the hardware platform, as well as the loopback interface.

Currently, selecting the loopback interface has no effect on routing rules. Selecting the loopback interface in a routing table entry will generate an error message similar to the following example:

Configuration Errors Occured:

Failed to Add Route to 0.0.0.0/0 via 192.168.0.254 in table my_table

As a result, the target network will become inaccessible.

F5 Networks Product Development is tracking this request for enhancement as CR79299 and it is scheduled to be included in future versions of FirePass software. To monitor the status of this CR, refer to the FirePass Release Notes.

Workaround

F5 Networks currently recommends that you not use lo as an interface for routing rules or routing tables.
