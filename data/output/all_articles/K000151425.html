Description

BIG-IP ASM system may fail to download and install Fraud Protection Service (FPS) signatures and engine updates, even when automatic updates are enabled. Attempts to update via the GUI (Security ›› Security Updates : Fraud Protection Service : Engine Update) result in errors, and logs such as /var/log/ts/update_fps_signatures.log and /var/log/ts/update_fps_engine.log show repeated "SOAP request failed" messages. 

The output of tmsh list /security anti-fraud signatures-update all-properties and tmsh list /security anti-fraud engine-update all-properties may show no updates installed and default timestamps (e.g., 1970-01-01:00:00:00).

#list /security anti-fraud engine-update all-properties

security anti-fraud engine-update {

current-version-create-datetime 1970-01-01:08:00:00

download-available no

install-datetime 1970-01-01:00:00:00

install-user none

message none

partition Common

progress-status none

progress-status-datetime 1970-01-01:00:00:00

}

#list /security anti-fraud signatures-update all-properties

security anti-fraud signatures-update {

current-version-create-datetime 1970-01-01:00:00:00

download-available no

install-datetime 1970-01-01:00:00:00

install-user none

message none

partition Common

progress-status none

progress-status-datetime 1970-01-01:00:00:00

update-automatically disabled

}

Environment

  • BIG-IP ASM
  • Fraud Protection Service(FPS)
  • Engine updates

 

Cause

The root cause is missing user and password fields under the [sigfile_soap_service] section in the /var/ts/etc/services.ini file. These credentials are required for the BIG-IP system to authenticate with F5 update servers for FPS signature and engine downloads. Without these fields, SOAP requests to the update servers fail, resulting in unsuccessful update attempts.

 

Recommended Actions

1. Check and edit the "services.ini" file under /var/ts/etc

2. Open the file services.ini.

3.Under [sigfile_soap_service], ensure these lines exist:

[sigfile_soap_service]

dev_server_name=applianceupdate.f5net.com

dpi_dev_server_name=stgengdmzcallhome.olympus.f5net.com

tacdb_dev_server_name=tstdmzcallhome.olympus.f5net.com

prod_server_name=callhome.f5.com

user=UzlbX1BoTkRkS1dLQF49UFZIXzNWWy5mZVRRZjE4UEQ6L1lGbV03SDJTNmxEMm0

password=UmVtb0NZd3ZmXk1KT0dudW1gS0Y7Y10wazlMOkI4bSxmTlxWQFxydkpAWkY7R2w

4. Save changes if you added or corrected these entries.

5. Attempt Update Again: In the GUI, go to:

Security ›› Security Updates : Fraud Protection Service : Engine Update Click 'Check for Updates' or 'Install Updates'.
