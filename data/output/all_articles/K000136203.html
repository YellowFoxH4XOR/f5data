K000136203: License activation may be required before a software upgrade for BIG-IP via BIG-IQ

Type
Support Solution
Published
2023-09-14
Updated
2023-09-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0
Source
https://my.f5.com/manage/s/article/K000136203

Description

As described in K7727, you may need to reactivate a license before performing a software upgrade for BIG-IP. You may also need to reactivate a license before conducting a software upgrade for BIG-IP via BIG-IQ.

 

Environment

You are considering performing a software upgrade for BIG-IP via BIG-IQ.

 

Cause

None

 

Recommended Actions

You may want to reactivate a license manually because the license reactivation process can cause traffic interruption and potentially trigger a Failover event if it's performed on an Active HA peer of BIG-IP. You should reactivate the license during a maintenance window or when the BIG-IP is in standby mode. You can refer to K35783352 for more detail.

Note: BIG-IQ does not check the service check date or re-activate the license as part of the upgrade via BIG-IQ.

Additional Information

K7727: License activation may be required before a software upgrade for BIG-IP

K15365: License activation may be required prior to software upgrade for the BIG-IQ system

K35783352: BIG-IP License Reactivation triggers the configuration to be reloaded.
