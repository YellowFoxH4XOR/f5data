Known Issue

Important: The behavior described in this Solution is caused by an issue with the Symantec Confidence Online Server ActiveX control, and not an issue with the FirePass controller.

If you configure FirePass to check for a client certificate, and the Far-End Security Integration pre-logon inspector is configured to integrate with the Symantec (formerly WholeSecurity) Confidence Online Server, the certificate check fails.

When the Far-End Security Integration pre-logon inspector is configured in a pre-logon sequence, the browser on the client system downloads the Confidence Online Server ActiveX control when the user accesses the pre-logon sequence. The Confidence Online Server ActiveX control is run by the Far-End Security Integration inspector each time the user accesses the pre-logon sequence. The Confidence Online Server ActiveX control does not properly handle certificate events in the SSL negotiation. If FirePass requests or requires a client certificate during the logon process, the check for the Confidence Online Server fails. When this issue occurs, users receive a pop-up window with an error message similar to the following example:


Server Connection Failed

The server returned an error.

Please contact the Help Desk

FirePass then directs the users to the logon denied page.

The FirePass controller integrates with the Symantec Confidence Online Server, which provides policy-based management for endpoint systems. A FirePass pre-logon sequence that is configured to use the Confidence Online Server collects information about the host endpoint system, which is then reported to the Confidence Online Server. In turn, the FirePass controller receives a pass or failure notification from the Confidence Online Server, depending on whether the host meets the policy specified by the Confidence Online Server. For more information about configuring the Far-End Security Integration inspector, refer to the Integrating the FirePass and WholeSecurity Confidence Online Server deployment guide.

Client certificate checking can be configured in a pre-logon sequence or by selecting the Request client certificate during logon check box on the Device Management: Security: Certificates page.

Note: Starting in FirePass version 6.0.2, client certificate checks are configured on individual web services. For more information, refer to K8138: Change in Behavior: Request client certificate feature is now configured through individual web services.
