Known Issue

This is the result of a known issue. When the Enterprise Manager or F5 Monitoring Pack monitors a device, the big3d process generates debug error messages that appear similar to the following example:

big3d[1995]: 012b8002:3: Error processing notification message: Failed to convert object to XML
big3d[1995]: 012b8003:3: Class: 848, MCPD to XML: Tag was skipped by MCPtoXML
big3d[1995]: 012b8002:3: Error processing notification message: Failed to convert object to XML
big3d[1995]: 012b8003:3: Class: 848, MCPD to XML: Tag was skipped by MCPtoXML

Note: These error messages are benign, and can be safely ignored.

F5 Product Development tracked this issue as CR121371 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-342.0-HF1 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
