Description

BIG-IP intermittently closes the connection with TCP RST with reason 'No pool member available', when there are no monitors assigned to the pool.

 

Environment

  • BIG-IP LTM
  • iApp deployment with unmonitored pool

Cause

ID1397073

Recommended Actions

Modify iApp to always have a monitor on a pool

Additional Information

It should be noted that iApps are being deprecated in favour of FAST, therefore it would be advised to migrate away from the use of iApps to use FAST instead.
