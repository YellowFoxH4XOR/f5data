Topic

You should consider using this procedure under the following condition:

  • You want to configure high-availability failover for BIG-IP Virtual Edition (VE) on Amazon Elastic Compute Cloud (EC2).

Description

Device Service Clustering (DSC) provides the framework for high-availability features, such as failover and configuration synchronization (ConfigSync) for BIG-IP device groups. To configure DSC and active-standby failover for BIG-IP VE on Amazon EC2, you must perform the following procedures:

  • Supplying the Access Key ID for failover
  • Obtaining the Access key and Secret key from the EC2 Management Console
  • Configuring the Access key and Secret key on the BIG-IP VE system
  • Configuring DSC and active-standby failover

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have completed the necessary steps to deploy the redundant BIG-IP VE on Amazon EC2, including the following:
    • Created a key pair
    • Created a virtual private cloud with subnet, security group, and routing
    • Launched the new Amazon Machine Image (AMI)
    • Associated an elastic IP for management
    • Attached additional network interfaces as needed
  • You have completed the initial BIG-IP configuration on both systems, including installing the license and configuring Virtual Local Area Networks (VLAN) and self IPs.

Procedures

Supplying the access key ID for failover

When configuring DSC and active-standby failover for BIG-IP VE on Amazon EC2 you must supply the access key and secret key for both members of the active-standby pair. Doing so allows your Amazon Web Services account to accept the F5 API calls that facilitate the failover process.

Note: When a BIG-IP hardware appliance fails over, the newly active unit sends out gratuitous Address Resolution Protocol (ARP) requests for all floating and virtual addresses in order to update the ARP cache of devices on the network. This practice ensures that all traffic is transitioned to the newly-active unit as quickly as possible. Amazon EC2 does not use gratuitous ARP, and instead provides API calls that facilitate the failover process.

To supply the access key and secret key for both members of the active-standby pair so that your Amazon Web Services account accepts the F5 API calls that facilitate the failover process, perform the following two procedures:

Obtaining the Access key and Secret key from the EC2 Management Console

To obtain the access key and secret key from the EC2 Management Console, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Amazon Web Services (AWS) Management Console.
  2. From the Services menu, select IAM.
  3. In the Navigation pane, under Details, select Users.
  4. Click Create New Users.
  5. Type a user name.
  6. Select Generate an access key for each user and then click Create.
  7. Click Download Credentials.
  8. An access key ID and a Secret Access Key pair are downloaded to your PC as credential.xlsx.

    Important: AWS downloads these credentials only once, so keep track of where they are stored.

Configuring the Access key and Secret key on the BIG-IP VE system

To configure the access key and secret key on the BIG-IP VE system, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the active BIG-IP system.
  2. Click System.
  3. Click Configuration.
  4. Click AWS.
  5. Under Global Settings, paste the access key ID that you previously copied to the Access Key field.
  6. Paste the secret key ID that you previously copied to the Secret Key field.
  7. Click Update.
  8. Repeat the previous steps, but this time paste the credentials into the Global Settings page for the standby BIG-IP device.

Configuring DSC and active-standby failover

In BIG-IP 11.x, a device group is a collection of BIG-IP devices that are configured to securely synchronize their BIG-IP configuration data and fail over when needed. To configure the systems for DSC and active-standby failover, perform the following tasks:

  • Configure the ConfigSync and Failover IP addresses.
  • Add a device to the local trust domain.
  • Create a device group.
  • Modify the default traffic group on one instance to define the failover method.
  • Perform a ConfigSync operation.
