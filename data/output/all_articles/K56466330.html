Known Issue

When you configure virtual servers with HTTP/2, the Traffic Management Microkernel (TMM) process leaks memory.

This issue occurs when the following condition is met:

  • You have a virtual server configured with HTTP/2.

Impact

The memory leak may eventually trigger the aggressive sweeper and a potential crash, resulting in a failover.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system logs error messages in the /var/log/ltm file that appear similar to the following example:

    warning tmm[12345]: 011e0003:4: Aggressive mode sweeper: 100 Connections killed

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.
