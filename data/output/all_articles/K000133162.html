Description

BIG-IP DNS stopped responding to particular DNS queries.

 

gtm logs show Pool going offline:

 

 alert gtmd[20741]: 011a1005:1: SNMP_TRAP: Pool example_pool state change green --> red (No enabled pool members available)

 

The pool member configuration for the gtm server object (BIG-IP) has disappeared.

 

Environment

  • BIG-IP DNS
  • Pool down
  • Pool member config is missing

Cause

virtual-server-discovery is enabled for gtm server object (BIG-IP)

Working as configured

Recommended Actions

Use virtual-server-discovery Enabled (No Delete) if the virtual server should never be deleted from the BIG-IP DNS configuration.

Additional Information

K13994: Configuring virtual server and link auto-discovery (11.x - 16.x)
