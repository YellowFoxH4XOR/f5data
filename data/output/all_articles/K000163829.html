In this video, AskF5 shows you how to configure the BIG-IP system to send high-speed logs through the management interface using the Configuration utility.

00:00 Intro and prerequisites
00:16 Create a log destination
00:54 Create a log publisher
01:16 Optionally configure iRule for connection logging
01:49 Associate connection logging iRule with a virtual server

iRules syntax

when CLIENT_ACCEPTED {
  set my_hsl [HSL::open -publisher /<partition>/<log publisher>]
}
when HTTP_REQUEST {
  HSL::send $my_hsl "Request: [HTTP::host][HTTP::uri]"
  log local0.info "Request: [HTTP::host][HTTP::uri]"
}
when CLIENT_CLOSED {
  unset my_hsl
}

Note: Replace <partition> and <log publisher> with the partition location and log publisher configuration name created in the previous procedure.

This demo uses BIG-IP 21.1.x
