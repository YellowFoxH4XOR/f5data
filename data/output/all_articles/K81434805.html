K81434805: BIG-IP ASM resets a request when ip is whitelisted

Source
https://my.f5.com/manage/s/article/K81434805

Description

BIG-IP ASM resets connections When an IP is whitelisted. The packet capture shows the following reset cause:

rst_cause="[0x26f6e6c:927] Internal error (ASM requested abort (plugin abort error))"

Environment

  • The request exceeds long_request_buffer_size (10000000 bytes by default)
  • "Request length exceeds defined buffer size" is set to BLOCK
  • The source IP is set to never block in IP exception list

Cause

Bug ID 865897

Recommended Actions

You may turn on session tracking on the same ASM policy as a workaround. The other options in session tracking can be disabled.
