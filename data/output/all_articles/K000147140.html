K000147140: HTTP LB Stuck in Provisioning Status with Automatic Certificate enabled

Type
Support Solution
Published
2024-11-08
Updated
2025-02-19
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147140

Description

  • New load balancer created
  • Stuck in Provisioning status
  • Certificate Renewal Status: Pre Domain Challenge Pending
  • Allow HTTP Load Balancer Managed Records in DNS Zone configuration is not checked

 

Environment

  • F5® Distributed Cloud
  • Multi-Cloud App Connect
  • HTTP Load Balancers
  • HTTPS with Automatic Certificate

Cause

DNS CNAME mismatch

Answer/Recommended Actions

Review the _acme-challenge.example.com CNAME record value provided in the load balancer configuration matches the one set in your DNS records.

 

You can check the value of the CNAME record using dig:

➜ ~ dig _acme-challenge.example.com -t CNAME +short
xxxxxxxxxxxxxxxxxx.autocerts.ves.volterra.io

 

The CNAME record value needs to match entirely otherwise Pre Domain Challenge Pending message will be shown.

 

Additional Information

Checking Allow HTTP Load Balancer Managed Records in DNS Zone configuration option in a manage DNS Zone by F5® Distributed Cloud will create CNAME challenge records automatically.
