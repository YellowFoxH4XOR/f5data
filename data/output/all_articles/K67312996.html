K67312996: LTM is not provisioned after upgrade

Type
Support Solution
Published
2021-10-10
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K67312996

Description

After upgrading the device the LTM module is not showing as provisioned in Configuration Utility.  The following symptoms and events may also be observed.

  • The output of the command tmsh list /sys provision all-properties shows the LTM module as provisioned. 
  • In configuration utility the LTM module is showing as not provisioned.
  • The output of the command tmsh load /sys config verify  does not show any error. 
  • In /var/log/ltm you see similar error messages as follows:
    err mprov:3099:[3099]: 'No modules have memory! Changing to initial boot configuration.'
    info mprov:3099:[3099]: 'Provisioning attempt was not successful: State change at /usr/bin/mprov.pl line 834.
    info mprov:3099:[3099]: 'Forcing Host to 1564 MiB and allocating 14360 for later use by modules.'

Environment

  • BIG-IP LTM
  • You upgrade the device

Cause

Unknown

Recommended Actions

Follow the procedure of the article K13030: Forcing the mcpd process to reload the BIG-IP configuration
