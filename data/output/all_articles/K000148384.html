K000148384: Running "tmsh load sys config file /config/bigip.conf verify" shows an error while "tmsh load sys config verify" doesn't show any error

Type
Support Solution
Published
2024-11-05
Updated
2024-11-05
Source
https://my.f5.com/manage/s/article/K000148384

Description

When running the command "tmsh load sys config file /config/bigip.conf verify", you will notice some errors (ex. missing folder, route not directly connected to interface, etc)

  • Example error message:

01070734:3: Configuration error: Can't associate APM Log Configuration (/Common/sslo_Explicit_Proxy.app/sslo_Explicit_Proxy-log-setting) folder does not exist

Unexpected Error: Validating configuration process failed.

However, when running the command "tmsh load sys config verify" on the same device, you will notice that there are no errors.


Environment

  • BIG-IP

Cause

This is expected behavior. When you run the command "tmsh load sys config file /config/bigip.conf verify", you are asking to confirm the configuration objects against no other file than itself. Since some configuration objects are in other files like bigip_base.conf, it can't locate these objects and will throw out the error message.


Recommended Actions

To verify the configuration, you must use the command "tmsh load sys config verify".
