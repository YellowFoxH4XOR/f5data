K33065391: Security policy history page missing in BIG-IP version 16

Type
Support Solution
Published
2020-07-13
Updated
2024-03-02
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.X.X, 16.1.X, 16.0.X, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K33065391

Description

You are unable to locate the History page for security policies under Security >> Application Security when using version 16.

Environment

  • Security policy
  • BIG-IP version 16

Cause

The policy history page at this location no longer exists from version 16.

Recommended Actions

There is a new way to see policy history in version 16.

Security >> Application Security >> Policies List >> <Policy>  >> In the General Policy Settings click the date link next to Version.

This opens the Policy Version History.

None
