K75002500: BIG-IP analytics statistics for a virtual server is mismatching

Description

There is a bit of a discrepancy between various different graphs looking for bandwidth utilization for a particular virtual server from BIG-IP analytics page. TCP-Analytics profile is attached to the virtual server to monitor TCP statistics. The statistics are not matching with the Virtual server statistics and BIG-IP analytics with regards to the client-side and server-side bits.

Environment

BIG-IP LTM
TCP-Analytics profile
AVR
BIG-IP Analytics

Cause
Unknown at time of publication

Recommended Actions

Please follow the below workaround to see if that changes the behavior by disabling TCP Segmentation Offload (TSO) and Large Receive Offload (LRO).

Impact of workaround: Disabling TSO/LRO can result in a slight performance impact, a few percentage increase in CPU utilization. Other than that, they shouldn't notice any other side effects.

1.Log in to tmsh by typing the following command:
#tmsh

2. To disable TSO functionality, use the following command syntax:
#tmsh modify sys db tm.tcpsegmentationoffload value disable 

3. To disable LRO functionality, use the following command syntax:
#tmsh modify sys db tm.tcplargereceiveoffload value disable

4. Save the configuration.
#tmsh save sys config
