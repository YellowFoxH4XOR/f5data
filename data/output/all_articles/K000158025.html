Description

In order to synchronize APM OAuth profiles configurations to a peer device, you must use a sync-failover device group.

A sync-only device group is not supported.


Environment

Big-IP APM High Availability


Cause

Sync-Only device groups are specifically designed to propagate configuration changes only (including APM objects such as policies, profiles, etc.) across devices, without managing the runtime state.

OAuth synchronization, which involves dynamic key state, relies on gossip workers rather than being handled directly by a device group sync and does not apply to sync-only device groups, as they do not synchronize dynamic key state.


Recommended Actions

Only use a sync-failover group for synchronizing APM OAuth profiles
