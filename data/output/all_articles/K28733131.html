Description

BIG-IP GTM/DNS was upgraded. After upgrade the zrd remains down.

  • zrd down can be seen in CLI.
  • If zrd is restarted, it fails to start with "zrd down, waiting for named to release running semaphore"
  • Even a restart of the device doesn't bring zrd up.

Environment

  • Before upgrade, the device was put in forced offline.
  • BIG-IP GTM/DNS provisioned.

Cause

This can happen when the device is in forced offline state.

Recommended Actions

Release the device from forced offline state and the zrd should start running automatically.

In GUI, navigate to Device Management  ››  Devices, click on "Release Offline"
(OR)
From CLI, run:
tmsh run sys failover online

Additional Information

None.
