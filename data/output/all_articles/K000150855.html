K000150855: BIG-IP tenants on VELOS show high CPU, TMM does not fully start

Type
Support Solution
Published
2025-04-14
Updated
2025-05-20
Applies to
  • F5OS
  • F5OS-C: 1.8.0
Source
https://my.f5.com/manage/s/article/K000150855

Description

BIG-IP Tenants on VELOS show high CPU, but do not fully start.

Log messages similar to the following appear in /var/log/tmm repeatedly:

<13> Mar 31 06:57:28 slot1/bigip1.example.com notice SDAG CDP ERROR: Error - SDAGLIB context request expired
<13> Mar 31 06:57:28 slot1/bigip1.example.com notice SDAG CDP INFO: Selected DAG state from PG 0 for CMP state 01 with clock 20090589
<13> Mar 31 06:57:28 slot1/bigip1.example.com notice SDAG CDP INFO: Sent DAG context request, status 0

Environment

  • BIG-IP tenant on VELOS
  • F5OS-C v1.8.0
    • this has been observed on F5OS-C v1.8.0 but may occur on other versions

Cause

Bug ID 1922489.

Recommended Actions

Reboot the blade using the following command from the F5OS partition:

cluster reboot node <blade>

Additional Information

TMM fails to start due to a confd hang on the F5OS partition, which causes dagd to fail to respond to TMM.
