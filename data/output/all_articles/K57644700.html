Description

On your BIG-IP GTM, when importing a certificate to the Trusted Device Certificate, you are getting the following error message:
Import Failed: OpenSSL error: error:0D0680A8:asn1 encoding routines:ASN1_CHECK_TLEN:wrong tag

To import the certificate to the Trusted Device Certificate, navigate to System > Device Certificate > Trusted Device Certificates.

This certificate was exported from another GTM device.

Environment

  • BIG-IP GTM
  • Importing another GTM's certificate to the Trusted Device Certificate

Cause

The imported device certificate Issuer is a Certificate Authority instead of Self.

Recommended Actions

You will need to Renew the device certificate and have the Issuer be from Self before exporting it to the peer GTM device.

For the steps below GTM-01 is the BIG-IP GTM device which is renewing its device certificate and GTM-02 is importing the device certificate from GTM-01.

  1. Login to the BIG-IP GTM Configuration Terminal of GTM-01.
  2. Navigate to System > Device Certificate.
  3. Click Renew.
  4. Under Issuer, select Self.
  5. Fill in the other details on this page.
  6. Click Finished.
  7. You will need to re-login GTM-01 Configuration Terminal.
  8. Navigate to System > Device Certificate.
  9. Click Export.
  10. Click Download server.csr.
  11. Login to the BIG-IP GTM Configuration Terminal of GTM-02 to import the new certificate.
  12. Navigate to System > Device Certificate > Trusted Device Certificates.
  13. Click Import.
  14. In Import Method change to Replace.
  15. Select Upload File.
  16. Click Browse and choose select server.csr.
  17. Click Import.
The certificate should be imported correctly now.
