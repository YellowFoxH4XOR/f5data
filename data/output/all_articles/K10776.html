Known Issue

This is the result of a known issue. The CIFS service may be incorrectly displayed as Disabled on the ARX Manager: Virtual Service Details page. This issue occurs when a single virtual service exports both CIFS and NFS volumes from different namespaces. 

Note: This is a display issue; the CIFS service is actually enabled. You can use the show virtual service command to verify the actual status of the CIFS service. For information about the show virtual service command, refer to the ARX CLI Reference Guide.

F5 Product Development tracked this issue as ARX ID 36568 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX release notes.
