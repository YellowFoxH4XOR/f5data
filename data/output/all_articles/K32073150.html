Description

When using a new SFP, some error counts appear on the interface statistics.

For example:

tmsh show net interface 4/1.0
----------------------------------------------------------------
Net::Interface
Name   Status  Bits  Bits  Pkts  Pkts  Drops  Errs         Media
                 In   Out    In   Out
----------------------------------------------------------------
4/1.0      up    64     0     0     0      0     1  100000SR4-FD

Environment

  • BIG-IP
  • Replacing an old SFP

Cause

We suspect that this is related to old version for f5optics.

Recommended Actions

Use 'tmsh list net interface 4/1.0 | grep vendor-revision' to compare the version of the old and new SFP. If they are different, please go to downloads.f5.com to get the latest version for f5optics.

Additional Information

None.
