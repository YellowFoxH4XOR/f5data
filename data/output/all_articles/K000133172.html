K000133172: DNS Malformed is not detected by the protection profile of AFM(VS)

Type
Support Solution
Published
2023-03-24
Updated
2023-05-04
Applies to
  • BIG-IP
  • BIG-IP AFM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000133172

Description

  • DNS Malformed vector not detected on VS DOS.

Environment

  • AFM


Cause

By Design DNS Malformed Vector only works on via Device Dos.


 Recommended Actions

  1. If DNS Malformed Vector is require, please enable Vector on Device DOS.

Additional Information

Bugid 1273225 indicate this and DNS Malformed Vector will be removed from VS Dos Profile.
