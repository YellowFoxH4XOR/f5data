Topic

Beginning with version 4.2, BIG-IP and 3-DNS store the SysIP value in a bigdb variable. This value of the variable overwrites the snmpd.conf configuration.

If you change the SysIP value in the snmpd.conf file, you must also change the SysIP bigdb variable to make the change permanent.

To change the SysIP bigdb variable, perform the following steps:

  1. Log in to the command line.
  2. Change the value using the following command syntax:

    bigpipe db set Local.Bigip.Snmpd.SysIp = "<IP address>"

The 3-DNS or BIG-IP systems will now permanently retain the IP address that you specified for SysIP.
