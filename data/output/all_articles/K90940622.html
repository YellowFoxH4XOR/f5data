Description 

Unable to configure DoS logging under  "Configuration >> Security >> Shared Security  >> DoS Protection >> Device DoS configuration". The option is grayed-out.

Environment

  • DoS logging profile
  • Application Security

Cause

Works as designed . Device DoS Configurations is a menu for AFM module.

Recommended Actions

In order to configure DoS profile logging for ASM:

  2. Create a Publisher
