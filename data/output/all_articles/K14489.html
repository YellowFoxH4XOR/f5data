Known Issue

The Enterprise Manager system may fail to completely discover a managed BIG-IP device.

This issue occurs when the following conditions are met:

  • The managed BIG-IP device contains comments in an iRule.
  • The iRule comments span multiple lines using a line continuation character (\).

Impact

The Enterprise Manager system may fail to discover all objects configured on the managed device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H424108 on the Diagnostics > Identified > Medium screen.
  • The Enterprise Manager system fails to discover all objects configured on the affected managed device.
  • Some of the configuration objects for the discovered device are not visible on the Enterprise Manager system.
  • The Enterprise Manager system logs error messages similar to the following example to the /var/log/ltm file:

    err emdeviced[8352]: 04010568:3: Error found on device 192.168.10.11 (UID: 8): get change control info: iControl error: 'iControl::OperationFailed - primary code:2(0x2) secondary code: 0(0x0) string: Shell interface returned unexpected number of instances [2] for the following arguments [/Common [ltm.rule] [/Common/repro] [list] [ltm.rule] [/Common/test1] [list] [ltm.rule] [/Common/test2] [list] '

  • The Enterprise Manager system marks the affected device status as impaired.

Resolution

Status

F5 Product Development has assigned ID 420776 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

To work around this issue, you can modify the iRules on the managed device so they do not use comments containing line continuation characters.
