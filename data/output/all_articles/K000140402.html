Description

Remote RDP user fails to connect to the leasepool IP address of an F5 VPN client.

  • RDP initially succeeds but fails after the Edge client resets due to new user logging in.
  • Edge client will reset it's connection after the remote user authenticates, causing RDP to fail and disconnect.

Environment

  • Windows to Windows clients using RDP
  • APM VPN/Network access client w/leasepool IP assigned.
  • Microsoft RAS and Fast User Switching

 

Cause

This is a Microsoft issue, not F5.
