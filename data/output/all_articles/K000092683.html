Description

You should consider using these procedures under the following condition:

  • The system management CLI is behaving in an unexpected manner

Environment

  • F5OS-A (rSeries appliance)
  • F5OS-C (VELOS chassis)
  • System management CLI

Cause

None

Recommended Actions

The following procedures executed in the F5OS Bash environment will enable debug logs for the ConfD process.

  • F5OS-A (rSeries appliance)
    • F5OS-A 1.4.0 and above
    • F5OS-A 1.3.2 and below
  • F5OS-C (VELOS) Chassis
    • F5OS-C 1.6.0 and above
    • F5OS-C 1.5.1 and below
  • F5OS-C (VELOS) Partition
    • F5OS-C 1.6.0 and above
    • F5OS-C 1.5.1 and below

F5OS-A (rSeries appliance):

F5OS-A 1.4.0 and above:

Debug logs for ConfD are configured from a root shell on the appliance.  The changes persist across a system restart, so once debugging is complete, set the log level back to 'info'.

  1. SSH as root to the rSeries appliance management IP address to access the Bash shell.
  2. Change the log level by running one of the following commands:
    • To enable debug logs: docker exec system_manager confd_cmd -c 'mset /confdConfig/logs/developerLogLevel trace'
    • To disable debug logs: docker exec system_manager confd_cmd -c 'mset /confdConfig/logs/developerLogLevel info'
  3. The debug logs will be written to /var/F5/system/log/devel.log.

F5OS-A 1.3.2 and below:

  1. SSH as root to the rSeries appliance management IP address to access the Bash Shell.
  2. Using an appropriate text editing tool, edit the ConfD configuration file in the following location: /var/F5/system/cdb/confd.conf 
    <developerLogLevel>trace</developerLogLevel>
  3. Add the following lines to the ConfD configuration file after the line </developerLog>:
  4. Reload the configuration in the ConfD process by running the following command: docker exec system_manager confd --reload
  5. The debug logs will be written to /var/F5/system/log/devel.log.

To disable debug logs:

  1. Edit /var/F5/system/cdb/confd.conf and remove the previously-added <developerLogLevel>trace</developerLogLevel> section
  2. Reload he configuration in the ConfD process by running the following command: docker exec system_manager confd --reload

For F5OS-C (VELOS) Chassis:

F5OS-C 1.6.0 and above:

Debug logs for ConfD are configured from a root shell on the system.  The changes persist across a system restart, so once debugging is complete, set the log level back to 'info'.

  1. SSH as root to the VELOS controller floating management IP address to access the Bash Shell.
  2. Change the log level by running one of the following commands:
    • To enable debug logs: docker exec vcc-confd confd_cmd -c 'mset /confdConfig/logs/developerLogLevel trace'
    • To disable debug logs: docker exec vcc-confd confd_cmd -c 'mset /confdConfig/logs/developerLogLevel info'
  3. The debug logs will be written to /var/confd/log/devel.log.
  4. Repeat the above steps to debug the ConfD process on the standby Controller if needed.

F5OS-C 1.5.x and below:

  1. SSH as root to the VELOS controller floating management IP address to access the Bash Shell.
  2. Access the vcc-confd docker container with an interactive bash shell by running the following from Bash: docker exec -it vcc-confd bash
  3. Using an appropriate text editing tool, edit the ConfD configuration file in the following location: /usr/etc/confd/confd.conf.
  4. Add the following lines to the ConfD configuration file after the line </developerLog>: 
    <developerLogLevel>trace</developerLogLevel>
  5. Reload the configuration in the ConfD process by running the following command within the vcc-confd container: vcc-confd --reload
  6. The debug logs will be written to /var/confd/log/devel.log.
  7. Repeat the above steps to debug the ConfD process on the standby Controller if needed.

For F5OS-C Partition:

F5OS-C 1.6.0 and above:

Debug logs for ConfD are configured from a root shell on the system.  The changes persist across a system restart, so once debugging is complete, set the log level back to 'info'.

  1. Determine on which system controller the partition is active.
  2. SSH as root to the VELOS controller (not partition) management IP address on which the partition is active to access the Bash Shell.
  3. Change the log level by running one of the following commands, replacing X with the partition ID
    • To enable debug logs: docker exec partitionX_cli confd_cmd -c 'mset /confdConfig/logs/developerLogLevel trace'
    • To disable debug logs: docker exec partitionX_cli confd_cmd -c 'mset /confdConfig/logs/developerLogLevel info'
  4. The debug logs will be written to /var/F5/partitionX/log/devel.log, where X represents the Partition ID.

F5OS-C 1.5.x and below:

  1. Determine on which system controller the partition is active.
  2. SSH as root to the VELOS controller (not partition) management IP address on which the partition is active to access the Bash Shell.
  3. Using an appropriate text editing tool, edit the ConfD configuration file in the following location: /var/F5/partitionX/cdb/confd.conf, where X stands for the Partition ID.
  4. Add the following lines to the ConfD configuration file after the line </developerLog>: 
    <developerLogLevel>trace</developerLogLevel>
  5. Reload the configuration in the ConfD process by running the following command, where X stands for the Partition ID. docker exec partitionX_manager confd --reload
  6. The debug logs will be written to /var/F5/partitionX/log/devel.log, where X represents the Partition ID.
