K000161523: VELOS System Controller becomes unreachable via HTTPS/SSH due to dockerd crash

Type
Support Solution
Published
2026-06-02
Updated
2026-06-02
Applies to
  • F5OS
  • F5OS-C: 1.8.2
Source
https://my.f5.com/manage/s/article/K000161523

Description

A VELOS system controller becomes unreachable via HTTPS and SSH unexpectedly.

  • System controller is not pingable and SSH/HTTPS access is lost
  • show cluster output shows the controller as unable to be pinged:

    Can NOT ping controller-2.chassis.local

  • A dockerd SIGABRT crash is recorded in show system events:

    core-dump EVENT NA "Core dumped on controller-2. process=dockerd-current, location=/var/shared/core/host/core.host.dockerd-current.<pid>.<timestamp>.core.gz"

  • show system redundancy-details on the active controller shows the peer controller as missing or unhealthy

Environment

  • VELOS system controller
  • dockerd

Cause

Bug ID 2306641

Answer/Recommended Actions

Reboot the affected system controller. This may need to be done via the AOM menu.
