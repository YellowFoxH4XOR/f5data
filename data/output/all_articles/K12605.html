Known Issue

This is the result of a known issue. When a host from the same network as the ARX out-of-band (OOB) management network pings the ARX system's in-band (IB) management IP address, the ping response will be from an internal 169.254.x.x network IP address if the OOB management interface is enabled.

F5 Product Development is tracking this issue as ID 347196.

Workaround

The ARX will respond with the correct IP address if you disable the OOB management interface. To do so, perform the following procedure:

  1. Log in to the ARX command line.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter the configuration mode by typing the following command:

    config
  4. Enter the management interface configuration mode by typing the following command:

    interface mgmt
  5. Disable the OOB management interface by typing the following command:

    shutdown

    Note    : To re-enable the OOB management interface, use the no shutdown command.
  6. Exit the management interface configuration mode and return to privileged mode by typing the following command:

    end
