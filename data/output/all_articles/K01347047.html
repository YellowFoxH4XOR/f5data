K01347047: Restrict on IP address using ''IP Subnet Match'' agent in APM policy

Type
Support Solution
Published
2022-04-19
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM: 15.1.6, 15.1.2, 15.1.1, 15.0.1, 15.0.0, 15.1.8, 15.1.7, 15.1.5, 15.1.4, 15.1.3, 15.0.X, 15.1.0, 15.X.X, 15.1.X
Source
https://my.f5.com/manage/s/article/K01347047

Description
There is a need to use "IP Subnet Match" agent to restrict individual hosts' IP addresses, instead of the whole network.

Environment

  • IP Subnet Match
  • APM Access Policy

Cause
None

Recommended Actions

Normally, in "IP subnet match" the expression needs to be filled with a network and the prefix, for example x.x.0.0/16. To use it as individual host, use x.x.x.x/32.
For example 10.1.2.5/32
