Issue

For an active-active configuration to function properly, network failover must be enabled. If network failover is not enabled on an active-active pair, the BIG-IP systems remain in the offline state and log an error message that appears similar to the following example to the /var/log/ltm file:

Mar 25 07:48:19 local/B8800-R19-S30 notice sod[1910]: 01140029:5: HA config_not_received sod fails action is go offline.

Note: For information about network failover, refer to K2397: Comparison of serial failover and network failover features.
