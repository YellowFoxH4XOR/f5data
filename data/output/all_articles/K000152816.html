K000152816: Upload a BIG-IP ISO file to BIG-IQ using iControl REST API

Type
Knowledge
Published
2025-08-26
Updated
2025-08-26
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000152816

Topic

You want to upload a BIG-IP ISO file to a BIG-IQ system using iControl REST API.

Description

You can use the iControl REST API interface on the BIG-IQ system to upload a BIG-IP ISO file. Due to the large file size of a BIG-IP ISO file (typically 2GB or more), you may not be able to upload the file with a simple curl command. You may have to split the file into multiple chunks of acceptable size to the BIG-IQ system and upload these chunks one at a time. To automate this process, you can use the following bash script from MyF5 Github repository to perform the upload to a BIG-IQ system:

uploadbigipisotobigiq.sh

Prerequisites

  • Administrative access (admin user) to the BIG-IQ REST API.
  • You should have the following utilities installed on the Linux workstation you want to run this bash script:
    • curl
    • jq
    • printf
    • stat
    • dd
    • md5sum
  • You have downloaded the BIG-IP ISO file to the Linux workstation and it must reside in the same directory as the bash script.

Procedures

  1. Log in to your Linux workstation. The workstation must have internet connectivity.
  2. Change to an existing directory or create a directory where you want the project directory to be stored.
  3. Copy the K000152816 project to your workstation using one of the following methods:
    • Clone the K000152816 repository to your workstation by entering the following command:

      git clone https://github.com/askf5/K000152816.git

    • Download the bash script using the following command:

      curl -s https://raw.githubusercontent.com/askf5/K000152816/refs/heads/main/uploadbigipisotobigiq.sh -O

  4. If you downloaded the bash script using the curl command method, skip to the next step. If you cloned the K000152816 repository to your workstation, change to the project directory downloaded on your workstation by entering the following command:

    cd K000152816

  5. Modify the file permissions of the bash script by entering the following command:

    chmod 744 ./uploadbigipisotobigiq.sh

  6. Enter the following command syntax to run the bash script. You will be prompted for the BIG-IQ admin password:

    ./uploadbigipisotobigiq.sh <BIG-IQ management IP address> <BIG-IP ISO filename>

    For example,

    ./uploadbigipisotobigiq.sh 192.168.61.185 BIGIP-17.1.2.2-0.0.12.iso

    The bash script should immediately prompt you for the BIG-IQ admin password before proceeding to upload the BIG-IP ISO file. During the upload process, the bash script should indicate its progress in percentage form. For example, 56.9 percent remaining...

    When the bash script completes the upload, it should display an output similar to the following:

    0.0 percent remaining...done.
    Calculating md5sum for BIGIP-17.1.2.2-0.0.12.iso to compare to uploaded file:
    c312a748e842e59e540f0f04e81d401f BIGIP-17.1.2.2-0.0.12.iso

  7. When the bash script completes the upload successfully, you can login to your BIG-IQ device and go to Devices > SOFTWARE MANAGEMENT > Software Images to verify. Alternatively, you can use the other bash script listbigipimagesonbigiq.sh to display the list of BIG-IP ISO files on the BIG-IQ. If you used the git clone method in step 3, this bash script should be in the K000152816 directory. If you used the curl command method in step 3, you can download this bash script using the following command:

    curl -s https://raw.githubusercontent.com/askf5/K000152816/refs/heads/main/listbigipimagesonbigiq.sh -O

    Enter the following command syntax to run the listbigipimagesonbigiq.sh bash script. You will be prompted for the BIG-IQ admin password:

    ./listbigipimagesonbigiq.sh <BIG-IQ management IP address>

    For example,

    ./listbigipimagesonbigiq.sh 192.168.61.185
