Topic

The BIG-IP APM system does not currently support configuring Kerberos authentication and Kerberos single sign-on (SSO) in the same deployment.

The BIG-IP APM system does not prevent you from configuring Kerberos authentication and Kerberos SSO together. However, such configurations might lead to authentication and performance issues. For example, if BIG-IP APM Secure Web Gateway (SWG) Forward Proxy with Kerberos SSO is configured with Kerberos Auth in the same deployment, end-user clients are unable to access resources.
