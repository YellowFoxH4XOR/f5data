Description

When inspecting the content of BIG-IP /var/core folder, I noticed core files for processes like "tail" or "tailf".

This event is also logged under /var/log/messages and /var/log/user.log.

Environment

  • BIGIP
  • Console and/or SSH access

Cause

The issue occurred because the BIG-IP administrator manually triggered a "SIGQUIT" signal by pressing "Ctrl-\" while running the "tail" or "tailf" command.

Recommended Actions

To avoid this issue, do not press `Ctrl-\` while running commands like `tailf`, as it sends a `SIGQUIT` signal to terminate the process and generate a core dump.
