Issue

Error Message

info sod[<PID>]: 010c0082:6: Sorted Load-Aware failover <status>.

In this error message, note the following:

  • <PID> is the process ID of the sod process.
  • <status> is the internal Sorted Load-Aware failover algorithm status.

For example:

info sod[8484]: 010c0082:6: Sorted Load-Aware failover disabled.
info sod[8484]: 010c0082:6: Sorted Load-Aware failover enabled.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The sod process changes the utilization status of the internal sorting algorithm for Load-Aware failover.

Note: The Sorted Load-Aware failover algorithm is an internal, not-configurable feature that enhances the sod process to determine the next active device during a failover event.

Impact

The Load-Aware failover mechanism may be less efficient when the internal Sorted Load-Aware algorithm is disabled.

Recommended Actions

None
