Topic

Dropped packets listed in the Egress column of the show statistics global server command output indicate TCP retransmissions were required for the ARX virtual server; they do not indicate a failure on the ARX system.

The show statistics global server command output appears similar to the following example:

Global Server:         test1.domain.com
Virtual Server Ip:     10.10.10.1
-------------------------------------------------------------
                                 Ingress               Egress
-------------------------------------------------------------

Octets                            728238              3778750
Unicast Packets                     5404                 6802
Non Unicast Packets                    0                    0
Dropped Packets                        0                   73
