K000130360: ASM policy changes synchronize but not applied

Type
Support Solution
Published
2022-12-27
Updated
2022-12-27
Source
https://my.f5.com/manage/s/article/K000130360

Description

When doing a change in an ASM policy and applying it, it syncs but in all other devices in the ASM device group the change is not applied, just replicated. Manual application is needed.


Environment

ASM policy

ASM auto-sync

Change and policy application

Cause

Unknown at the time of the publication

Recommended Actions

NOTE: Order is very important


1. Apply change in all BIG-IPs in the group if they are still showing non applied changes

2. Restart asm_config_server in all BIG-IPs with the next command:

# pkill -f asm_config_server


3. Do a change for testing and apply it

4. Verify in the other BIG-IPs


Additional Information

None
