Known Issue

This is the result of a known issue. When the BIG-IP ASM system is provisioned on a BIG-IP LTM system but the BIG-IP WebAccelerator is not, the following error message is occasionally logged to the Local Traffic log (/var/log/ltm):

err iControlPortal.cgi: WebAccelerator::Applications:Problem connecting to port 12015, check webAccelerator is provisioned

The message indicates that a BIG-IP ASM iControl call to the BIG-IP WebAccelerator failed, since the BIG-IP WebAccelerator is not provisioned or running.

Note: If the BIG-IP WebAccelerator has been provisioned and you encounter this error, contact F5 Technical Support.

F5 Product Development tracked this issue as ID 241642 (formerly CR130727) and it was fixed in BIG-IP ASM version 10.2.0. For information about upgrading, refer to the BIG-IP ASM release notes.
