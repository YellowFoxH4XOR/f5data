Description

On running installation script for ntrust netHSM, customer may see:

/bin/nethsm-thales-rfs-install.sh: line 231: /opt/nfast/cknfastrc: No such file or directory

Environment

BIG-IP

ntrust netHSM

Cause

Missing critical directories

Recommended Actions

Verify that the /opt directory exists. If it exists, please refer to K85380383: Troubleshooting Thales/nCipher/Entrust netHSM

If this directory does not exist, please perform a clean install of your BIG-IP software.

Additional Information

This directory is created by default and contains a variety of important, but ultimately non-critical, files and directories. As such, your BIG-IP may boot and seem to work as intended without this directory, but certain features, such as the thales install script, will fail in non-intuitive ways.
