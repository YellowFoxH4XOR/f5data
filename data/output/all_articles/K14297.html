Known Issue

The BIG-IP system will not force a user to re-authenticate to the Configuration utility on a peer system after changing the user's password.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured as a member of a high availability (HA) pair or device group
  • A ConfigSync is performed after changing the user's password

When a user changes the Configuration utility password on the local system, the BIG-IP system automatically logs the user out immediately and redirects the user to the login page for re-authentication using the new password. However, a user logged into the Configuration utility on a peer system will not be logged out and forced to re-authenticate.

Impact

Depending on the organization's security policy, this behavior may not be desirable for audit compliance.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • A user who has logged into the Configuration utility on a BIG-IP system will not be automatically logged out for re-authentication when the user password is changed on a peer system and synchronized between the HA pair.
