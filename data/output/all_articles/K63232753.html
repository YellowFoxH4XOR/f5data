Description

  • Provisioning TAM on an ix600 device fails with error messages
  • Error message: Re-starting nest
  • Error messages similar to the following are logged at /var/log/tam/nest.start
Feb 25 10:38:21 I7800-R20-S34 [2020-02-25 10:38:21,223 WARNING] Hornet fpga neither configured nor loaded
Feb 25 10:38:21 I7800-R20-S34 [2020-02-25 10:38:21,224   ERROR] Num NDE (0) != required NDE (4)
Feb 25 10:38:21 I7800-R20-S34 10:38:21 WARNING: nest running without strict numa affinity. This may decrease performance
Feb 25 10:38:21 I7800-R20-S34 10:38:21 Restricting nest to 8 cpus in BIGIP_CPUMASK_NEST=00000ff0
Feb 25 10:38:21 I7800-R20-S34 10:38:21 INFO: Running '/etc/bigstart/scripts/nest.start --log-files /var/run/nest_%d.pipe --num-threads 4 --config-map /dev/mprov/tam_2mb/hornet_nest_config_map --stats-map /dev/mprov/tam_2mb/hornet_nest_stats_map --ring-dir /dev/mprov/tam_2mb --table-dir /dev/mprov/tam --table-size 2 -- --numa-node none'
Feb 25 10:38:21 I7800-R20-S34 [2020-02-25 10:38:21,657   ERROR] Not enough active NDEs (0) to start 4 threads

Environment

  • TAM (Traffic Acceleration Manager) provisioned
  • You are using one of the following hardware platforms:
    • BIG-IP i5600 Series
    • BIG-IP i7600 Series
    • BIG-IP i10600 Series
    • VIPRION B4450 blade

Cause

TAM (Traffic Acceleration Manager) requires the turboflex profile turboflex-ultrafast-layer4 be enabled, this profile is only available on the ix800 performance license.

Recommended Actions
Impact: Modifying module provisioning will restart services and temporarily impact traffic.

Deprovision TAM:

  1. Navigate to System  ››  Resource Provisioning
  2. Uncheck the box beside TAM
  3. Select Submit

Additional Information
Note: Contact sales to upgrade to the performance ix800 license, ix600 and ix800 use the same hardware.
