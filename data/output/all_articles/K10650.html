Known Issue

This is the result of a known issue. When rebooting the 3900 platform using the LCD screen, the status LED remains solid green throughout the entire reboot process.

When rebooting the system using the Always-On Management (AOM), or using the reboot command from the command line, the Status LED correctly turns solid amber then solid green after system initialization.

F5 Product Development is tracking this issue as CR125025.
