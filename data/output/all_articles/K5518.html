Backing up the FirePass configuration
  1. To back up the FirePass configuration, perform the following procedure:
  2. Log in to the Administrative Console.
  3. In the main navigation pane, select Device Management.
  4. In the upper navigation pane, select Maintenance.
  5. In the sub-menu, select Backup/Restore.
  6. Click the Create backup of your current configuration link.

    Note: If you wish to back up log files in addition to configuration files, click the Create backup of your current configuration and log messages link instead.

    Important: A backup operation which includes the log messages can impact the FirePass controller's performance, especially if the Application Logs and the Logon Logs have several entries. F5 Networks recommends that you perform this kind of backup operation when the controller is least used or idle.
  7. Your browser will prompt you to save the file.
  8. Choose a location to save the file.


If FirePass is configured in a redundant pair or a cluster, repeat this procedure for each unit.

Restoring the FirePass configuration to a single unit

Important: The FirePass version and installed hotfixes must be the same as they were when the backup was created.

To restore the FirePass configuration to a single unit, perform the following procedure:

  1. Log in to the Administrative Console.
  2. In the main navigation pane, select Device Management.
  3. In the upper navigation pane, select Maintenance.
  4. In the sub-menu, select Backup/Restore.
  5. In the text box under the heading Restore FirePass controller configuration from a previous backup, enter the name of the backup file, or locate the backup file by clicking the Browse button.
  6. Click the Restore your saved configuration link.
  7. Review the configuration to ensure it is correct.
  8. If you wish to restore the Networking configuration, select the Restore Networking Configuration check box.
  9. If you wish to restore the User and Group settings, select the Restore Users and Groups Settings check box.
  10. Click the Restore button.
  11. Click the Restart FirePass Controller link.

Restoring the FirePass configuration to a redundant pair

Important: The FirePass version and installed hotfixes must be the same as they were when the backup was created.

Important: Remote restoration of a FirePass redundant pair is not supported. The FirePass controllers must be powered on and off during the procedure to prevent synchronization while the configuration is restored.

This procedure will restore configuration to units in a redundant pair with minimal down time. You must briefly shut down both controllers simultaneously to prevent the standby from synchronizing the old configuration to the active unit after it reboots.

  1. Open two browser windows.
  2. Log in to the Administrative Console of the active unit in the first browser window.
  3. Log in to the Administrative Console of the standby unit in the second browser window.
  4. On the standby unit, in the main navigation pane, select Device Management.
  5. On the standby unit, in the upper navigation pane, select Maintenance.
  6. On the standby unit, in the sub-menu, select Restart Services.
  7. On the standby unit, click the Shutdown Controller link.
  8. On the standby unit, click the Shutdown button.
  9. On the active unit, in the main navigation pane, select Device Management.
  10. On the active unit, in the upper navigation pane, select Maintenance.
  11. On the active unit, in the sub-menu, select Backup/Restore.
  12. On the active unit, in the text box under the heading Restore FirePass controller configuration from a previous backup, enter the name of the backup file, or locate the backup file by clicking the Browse button.
  13. On the active unit, click the Restore your saved configuration link.
  14. On the active unit, review the configuration to ensure it is correct.
  15. On the active unit, if you want to restore the Networking configuration, select the Restore Networking Configuration check box.
  16. On the active unit, if you want to restore the User and Group settings, select the Restore Users and Groups Settings check box.
  17. On the active unit, click the Restore button.
  18. On the active unit, click the Restart FirePass Controller link.
  19. After the active unit reboots, turn on the standby unit.

When the standby unit starts, it will automatically synchronize the configuration from the active unit. If you do not need to restore log files, the restoration is complete.

If you need to restore log files, perform the steps in Restoring the FirePass configuration to a single unit procedure for the standby unit.
