Known Issue

User Datagram Protocol (UDP) Session Initiation Protocol (SIP) packets may be dropped.

This issue occurs when all of the following conditions are met:

  • The SIP and UDP profiles are enabled on a virtual server.
  • The UDP Idle Timeout setting is set to Immediate.
  • In the UDP profile, the Datagram Load Balancing setting is enabled.
  • In the virtual server configuration, the Source Port setting is set to Preserve Strict.

Impact

SIP traffic may experience retransmissions and delays.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SIP traffic retransmissions occur due to dropped packets.
