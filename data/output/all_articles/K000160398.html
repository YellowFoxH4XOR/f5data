K000160398: Modifying management IP or gateway IP of the tenant via F5OS will not be reflected

Description

From F5OS host management, modifying the IP address of management or gateway of the tenant will not be reflected.

Once F5OS host deployed a tenant and shut down the tenant to configure. F5OS should be able to modify the IP address of management or gateway.

However after rebooting the tenant, the modified IP address is not reflected in the tenant while F5OS management screen shows the modified IP address.

 

Environment

F5OS 1.5 , 1.6 , 1.7 , 1.8

 

Cause

ID 1331829

 

Recommended Actions

There is a workaround procedure to avoid the symptom.

  • from F5OS host, modify the status of the tenant to "Configure".
  • modify the tenant's management-IP or modify the gateway IP
  • modify the status of tenant to "Deployed", boot and run the tenant.
  • at BIG-IP tenant, manually save the config(#tmsh save sys config).
  • Reboot the tenant, and will show the new modified management IP or gateway IP.
