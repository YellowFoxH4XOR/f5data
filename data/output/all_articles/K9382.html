Known Issue

This is the result of a known issue. The Windows logon integration dialer cannot connect when DHCP is configured for the Network Access resource, and gzip compression is enabled for the Network Access connection. For example, when the client attempts to connect, the following error message is displayed:

Error 721. The remote computer did not respond.

The issue does not appear if connecting to a standalone FirePass device or if using the webtop. This issue does appear with both Windows XP and Windows Vista clients. In addition, this issue has been consistently noted when using clusters and failover pairs.

F5 Networks Product Development tracked this issue as CR109282 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

This issue was fixed in cumulative HF-603-1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
