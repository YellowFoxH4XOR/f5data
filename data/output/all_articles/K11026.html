K11026: Time stamps for attack signatures in staging are retained when exporting a UCS archive file

Issue

Beginning in BIG-IP ASM 10.2.0, the system retains time stamps for attack signatures in staging when it creates a UCS archive. In BIG-IP ASM versions prior to 10.2.0, if you save a UCS archive from a BIG-IP ASM system with attack signatures in staging, and then install the UCS file on a BIG-IP ASM system, the Policy Attack Signature screen in the Configuration utility does not display the date information indicating how long the signature(s) have been in the staging process.

F5 Product Development tracked this request for enhancement as ID 241803 (formerly CR131917).
