Description

After carrying out a Configuration migration from one BIG-IP system to another, some configuration may appear to be missing.

Environment

  • BIG-IP configuration has been migrated from another BIG-IP
  • Configuration showing as "In-Sync"

Cause

  • BIG-IP System Preferences "Records Per Screen" not set to default values on source BIG-IP Hardware
  • Missing configuration hidden on other pages (Page 1 of X)

Recommended Actions

  1. Navigate to System >> Preferences
  2. Set "Records Per Screen" to an appropriate number (eg 1000)
  3. Click Update

Additional Information
None
