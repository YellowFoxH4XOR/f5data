Known Issue

BIG-IP Edge Client cannot establish a Virtual Private Network (VPN) on macOS High Sierra 10.13.1 due to iBridge interface restrictions.

This issue occurs when all of the following conditions are met:

  • The Traffic Options setting in the Network Access configuration is set to Force all traffic through tunnel.
  • The Allow Local Subnet setting in the Network Access configuration is not enabled.
  • The client is running macOS High Sierra 10.13.1 on a system with an iBridge interface (for example, a Touch Bar).

    Note: You can locate the iBridge interface in the Network utility under the Info tab.

Impact

BIG-IP Edge Client cannot establish a network access session and enters a reconnection loop.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • macOS users cannot establish a network access session with the BIG-IP APM system using F5 Access or browser helper apps.
  • Error: VPN Disconnected messages display when the client attempts to establish a network access session.

Workaround

To work around this issue, enable the Allow Local Subnet setting in the Network Access configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure allows local access to any host or subnet in routes that you specified in the client routing table.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Connectivity / VPN > Network Access (VPN).
  3. Click the name of the network access configuration.
  4. At the top of the page, click the Network Settings tab.
  5. Under Client Settings, in the Allow Local Subnet section, select Enable.
  6. Click Update.
  7. Click Apply Access Policy.
  8. To apply the change, click Apply.
