Description

In the event where a Slow Transaction Attack is triggered by ASM for certain requests due the implementation and the requests being very slow a workaround can be configured to bypass the ASM protection mechanism for the relevant requests.

err perl[23918]: 01310001:3: event code I952 Slow transactions attack detected - policy_name: (/Common/lab_policy), number of dropped slow transactions: (1)

Environment

  • ASM
  • Slow requests
  • Slow Transaction Attack

Cause

The request sent to bigip takes too long to complete. This can be due to specific implementation.

Recommended Actions

To avoid triggering the protection mechanism for a specific request, two things should be configured:

  1. An Allowed URL should be configured with a Header-Based Content Profile with action "Do nothing".
  2. Disable from the Learning and Blocking settings of the security the "Request length exceeds defined buffer size". The flag on alarm can remain if required.
