Topic

Purpose

You should consider using this procedure under the following condition:

  • You want to allow files larger than 32MB to be uploaded by way of a FirePass Windows file web portal.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • The FirePass controller must be configured with a Windows files web portal.

Description

By default, to protect back-end systems from potential buffer overflow issues, the FirePass Windows file web portal limits the size of uploaded files to 32MB.

If the size of an uploaded file exceeds the maximum allowed size, the upload fails and the user receives the following message:

Security exception: maximum size of the request is exceeded

Increasing the Restrict maximum upload size

The maximum upload file size can be configured for a size of 32MB to 1024MB. You should set this value to the smallest size that is acceptable for your environment.

Impact of procedure: Setting a large maximum file size increases exposure to a buffer overflow attack on the back-end server that is being accessed. Changing this value requires a restart of the FirePass controller.

  1. Log in to the FirePass Administrative Console.
  2. Click Portal Access.
  3. Click Content Inspection.
  4. Click the Buffer overflow tab.
  5. Enter the maximum file size in the Restrict maximum upload size (32-1024 MB) field.
  6. Click Update.
  7. Click (Requires restart.)
  8. Click Restart.
