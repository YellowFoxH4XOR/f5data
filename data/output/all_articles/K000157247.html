Description

The BIG-IP LTM device was unable to perform REST API calls with the BIGIP report, resulting in repeated "Failed to index" errors and device group synchronization failures. The issue manifested as REST/gossip synchronization errors in the restjavad logs, preventing proper device group communication and management operations.

 

Environment

BIG-IP LTM, version 17.1.2

Platform: F5-BIG-LTM-I7800, C118

 

Cause

The root cause was stale or corrupted state information maintained by the IControlRoleMigrationWorker within the REST Framework, which led to persistent REST/gossip synchronization failures and "Failed to index" errors. Deleting this state and restarting the restjavad process restored normal REST API and device group operations.

 

Recommended Actions

Delete the state maintained by IControlRoleMigrationWorker:

restcurl -X DELETE "shared/storage?key=shared/authz/icontrol-role-migrator"

Restart the restjavad service:

bigstart restart restjavad or tmsh restart /sys service restjavad

Monitor device group synchronization and REST API functionality after performing these steps.
