K000132510: Removing self-IP of device configured under GTM server

Type
Support Solution
Published
2023-05-26
Updated
2023-05-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000132510

Description

This article describes how to remove an IP address of a device configured under the gtm server.

Environment

  • BIG-IP
  • DNS module provisioned
  • DNS synchronization group configured

Cause

N/A

 Recommended Action

  1. Disable the synchronization checkbox from all DNS devices in the group (DNS > Settings > GSLB > General)
  2. If link-discovery was enabled, it is necessary to disable it as well, before deleting the affected self IP.
a) In the Configuration utility (GUI) go to DNS > GSLB > Servers > Server List.
b) Select the BIG-IP server definition for which you want to disable link auto-discovery.
c) Select Links.
d) Link Discovery, select Disabled
 
      3. Delete the affected self IP address from one device (DNS-A)
a) In the GUI go to DNS > GSLB > Servers > Server List and select gtm server 
b) Select the device you want to modify
c) Remove the IP address from the Address List
     
      4. Log in to the CLI of the other two DNS devices (DNS-B and DNS-C) and run gtm_add in order to synchronize the configuration:
     
gtm_add <IP_of_device_A>
 
      5. You will not need to enable synchronization from the GUI as gtm_add will enable it by default.​​​​​​​
