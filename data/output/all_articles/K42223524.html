Known Issue

The Configuration utility does not display memory utilization of the BIG-IP ASM bd process.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured with a security policy that is actively processing an HTTP and/or XML request.
  • You want to view the memory utilization for the BIG-IP ASM bd process using the Configuration utility.

Impact

There is no method to display the BIG-IP ASM bd process memory utilization.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When troubleshooting memory utilization, you are unable to determine the amount of memory the BIG-IP ASM bd process is utilizing.
  • You are unable to monitor memory utilization of the BIG-IP ASM db process.

Workaround

To work around this issue, you can view memory utilization of the BIG-IP ASM bd process in the /var/log/ts/bd.log file. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP ASM command line.
  2. To view log messages regarding memory utilization, type the following command: 

    grep -i "UMU: total" /var/log/ts/bd.log

    For example:

    grep -i "UMU: total" /var/log/ts/bd.log

    UMU: total   106 (  0M) VM (1639M) RSS (164M) SWAP (  0M) trans  0
    UMU: total   106 (  0M) VM (1639M) RSS (163M) SWAP (  0M) trans  0
    UMU: total     5 (  0M) VM (1612M) RSS (163M) SWAP (  0M) trans  0

    Note: If your security policy is not configured for XML, the following steps are not required.

  3. To view memory consumption specifically related to parsing of XML content, modify the /etc/ts/bd/logger.cfg file to enable debug logging.

    Important: In rare cases, the additional resource demands of debug logging may cause poor performance or a system failure if the BIG-IP system is at high resource utilization before you enable debug logging.

  4. Using a text editor, open the /etc/ts/bd/logger.cfg file.
  5. Add the following three lines to the bottom of the file:

    MODULE=BD_XML;
    LOG_LEVEL=TS_INFO | TS_DEBUG;
    FILE = 2;

  6. Save the file modifications.
  7. To load the /etc/ts/bd/logger.cfg configuration, type the following command:

    /usr/share/ts/bin/set_active.pl --update_logger_cfg

  8. After the  logger configuration has loaded, you can view memory consumption using the command in step 2.
  9. To disable debug logging for XML parsing (recommended), open the /etc/ts/bd/logger.cfg file with a text editor.
  10. Remove the three lines that you previously added to the bottom of the file:

    MODULE=BD_XML;
    LOG_LEVEL=TS_INFO | TS_DEBUG;
    FILE = 2;

  11. To load the logger.cfg configuration, type the following command:

    /usr/share/ts/bin/set_active.pl --update_logger_cfg
