K000133280: F5 VE device in Azure loses default route after reboot

Support Solution
Published
2023-03-31

2023-03-31

Source
https://my.f5.com/manage/s/article/K000133280

Description

After rebooting Azure single NIC VE, the default route via the TMM is no longer present in the routing table

Environment

  • Azure Single NIC setup
  • Reboot
  • Default static route on the same network as the self IP

Cause

sys db key provision.1nicautoconfig when enabled, prevents the static route from being installed on to the TMM route table

Recommended Actions

When the Azure VE with Single NIC is configured and you would like to create a default route on the same network as the Self IP then you will need to disable the following DB key which is enabled by default
 

sys db provision.1nicautoconfig {
    default-value "enable"
    scf-config "true"
    value "enable"
    value-range "disable enable"
}

To disable this option run the below command:

 tmsh modify sys db provision.1nicautoconfig value disable
 tmsh save sys config
