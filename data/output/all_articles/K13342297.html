K13342297: The bigip_add/gtm_add commands fail with remote role accounts

Type
Support Solution
Published
2022-01-14
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP GTM
  • BIG-IP DNS: 14.1.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.X.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K13342297

Description

When running bigip_add / gtm_add by a remotely authenticated admin user, you may see the following output in the CLI.

[remote.user@bigip_01:Active:Changes Pending] ~ # bigip_add 10.0.0.10
Retrieving remote and installing local BIG-IP's SSL certs ...
Use of uninitialized value $dir in concatenation (.) or string at /usr/local/bin/gtm_env.pm line 82.
Enter remote.user password for 10.0.0.10 if prompted
Use of uninitialized value $dir in concatenation (.) or string at /usr/local/bin/gtm_env.pm line 82.
do_known_hosts: hostkeys_foreach failed: No such file or directory
The authenticity of host '10.0.0.10 (10.0.0.10)' can't be established.
Are you sure you want to continue connecting (yes/no)? yes
Failed to add the host to the list of known hosts (/.ssh/known_hosts).

Environment

  • BIG-IP DNS
  • Remote Auth
  • CLI
  • bigip_add / gtm_add

Cause

ID1038809

Recommended Actions

  1. Use a local account for the bigip_add / gtm_add commands

Additional Information

None
