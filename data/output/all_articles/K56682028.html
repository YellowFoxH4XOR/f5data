Description
Initialization of new network interfaces in AWS after Single NIC deployment.

Environment

  • BIG-IP Cloud
  • AWS
  • Single NIC deployment
  • Additional Network Interface

Cause
None

Recommended Actions

  • Prior to configuring the BIG-IP VE instance you will need to disable the Single-NIC mode of the default AWS instance, which shares management and data-plane on a single interface.
    Note: This will split the Management on to a single dedicated interface and data-plane traffic on to the second.
  1. Log on to the command line of the BIG-IP VE instance.
  2. Set a database variable so that the number of NICs will be recognized on reboot:

    setdb provision.1nic enable
     
  3. Shutdown the BIG-IP VE instance with the following command:

    shutdown -h now
     
  4. Add a third interface for your second tenant as covered in Amazon Web Services: Three-NIC BIG-IP VE.
    Note: When the BIG-IP VE instance is up and running, multiple NICs will be recognized and you can begin configuring BIG-IP VE.
     
  5. After configuring the AWS EC2 instance with the additional network interface re-start the BIG-IP VE instance.
