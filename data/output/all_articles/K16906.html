Issue

Error Message

Cannot edit the device-group for root or /Common folders; it is set by the BIG-IP to ensure failover functions correctly

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Traffic Management Shell (tmsh) when running the modify sys folder command

Description

This message occurs when the following condition is met:

  • You attempt to manually configure the device group for the root (/) and Common (/Common) folders by using tmsh.

Impact

None; this error message is informational to alert that the device group for the root (/) and Common (/Common) folders cannot be manually set.

Recommended Actions

For additional guidance about creating and managing device groups, refer to the following resources:

  • The Working with Device Groups chapter of the BIG-IP Device Service Clustering: Administration guide
  • The Working with Folders chapter of the BIG-IP Device Service Clustering: Administration guide

    Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

  • K13649: Creating a device group using the Configuration utility (11.x - 12.x)
  • K13639: Configuring a device group using tmsh
