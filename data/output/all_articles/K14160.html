Known Issue

Using the set-sync-leader Traffic Management Shell (tmsh) command option for a device group will delete configured packet filter exemptions.

This issue occurs when all of the following conditions are met:

  • Two or more devices are configured in a device group.
  • A packet filter exemption is configured.
  • The set-sync-leader command option is run on a device group member.

    For example:

    tmsh modify cm device-group <Device-Group-Name> devices modify { <Device-Name> { set-sync-leader } }

Note: Setting sync-leader can only be performed using the tmsh utility.

Impact

Packet filter exemptions will not be applied to remote device group members.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Packet filter exemptions will not be applied to remote device group members.
  • The tmsh list net packet-filter-trusted command will indicate there are no configured packet filter exemptions for the remote device group members.
  • The Configuration utility for the remote device group members will indicate there are no packet filter exemptions configured.

Workaround

To work around this issue, you can reload the configuration at the sync-leader device and perform a ConfigSync to the device group. To do so, perform the following procedure:

Impact of workaround: Reloading of configuration at the sync-leader is required. If it is an active unit, this procedure may cause traffic interruption.

  1. Log in to the Traffic Management Shell (tmsh) of the BIG-IP system that you have set as the sync-leader, by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. Re-load the configuration using the command as follows:

    load sys config
  3. Continuing on the sync-leader device, synchronize the configuration to the device group by using the following command syntax:

    run cm config-sync to-group <Device-Group-Name>

    For example:

    run cm config-sync to-group ExampleDG
  4. To exit the tmsh utility, type the following command:

    quit
