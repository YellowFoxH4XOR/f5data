K000140093: Getting "426 - low_version" error at the Ingress Gateway istio-proxy access logs

Type
Support Solution
Published
2024-09-24
Updated
2024-09-24
Applies to
  • Aspen Mesh: 1.14, 1.11
Source
https://my.f5.com/manage/s/article/K000140093

Description

When there is a request using HTTP/1.0 at the Ingress Gateway level, the flow isn't working, and on the access logs, we are seeing the following error:

[2024-09-18T17:33:39.089Z] "GET / HTTP/1.0" 426 - low_version - "-" 0 0 0 - "-" "curl/7.68.0" "-" "10.125.1.200" "-" - - 10.244.1.49:8080 10.125.1.2:35314 - -

Environment

  • Aspen Mesh 1.14.X 1.11.X
  • Istio Ingress Gateway

Cause

HTTP/1.0 is an old protocol for legacy applications, so it is disabled by default at the outbound HTTP listeners for the Ingress Gateway.

Recommended Actions

To enable the use of HTTP 1.0 at the Ingress Gateway level, please follow this steps:

  1. Edit your IngressGateway override values and  add the following items:
    gateways:
      istio-ingressgateway:
        env:
          ISTIO_META_HTTP10: "1"
  2. Go to your AspenMesh folder and do a helm upgrade on your ingress gateway with the new override values file:
    helm upgrade istio-ingress manifests/charts/gateways/istio-ingress \
        --namespace <ingressNamespaceName> \
        --values aspen-mesh-igw-override-values.yaml

 

Additional Information

After upgrading your Ingress Gateway, you can successfully do HTTP 1.0 requests:
