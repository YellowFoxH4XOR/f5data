K000135227: SAML Single Logout fails on Chrome and Edge

Description

 

SAML Single Logout (SLO) fails on Chrome and Edge browsers. With Firefox, it works fine.
 

Environment

 
  • BG-IP APM
  • SAML SP
  • CrossSite environment between SAML SP and SAML IDP
 

Cause

During SAML Single Logout, the Chrome browser does not send the APM MRHSession cookie with the POST SLO request.
This is because the APM MRHSession cookie does not have the SameSite attribute set. So the Chrome browser treats it as Lax and does not send the APM MRHSession cookie in the case of cross site requests.

 

 

Recommended Actions

  1. In the BIG-IP Admin GUI, under Access >> Profiles / Policies : Access Profiles (Per-Session Policies), enable the "samesite-cookie" and set it to "None" for the specific SAML Access Profile
  2. Apply the Access Policy
This will allow the Chrome browser to send the APM MRHSession cookie with the POST SLO request for cross sites.
