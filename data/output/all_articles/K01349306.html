Known Issue

In a single-admin NGINX Controller system, the only admin account can self-assign a non-admin role, leaving the system without an administrative account.

This issue occurs when all of the following conditions are met:

  • The NGINX Controller system has only one admin account.
  • The admin user attempts to assign a non-admin role to the account.

Impact

The only admin account is demoted to a non-admin role on the NGINX Controller system. As a result, no users can run tasks that require admin permission, including account management. The self-demoting action is irreversible.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the demoted account attempts to run admin-level tasks, the user interface displays an error message similar to the following example:

    API Error (403): unauthorized

Resolution

Workaround

To recover from this issue, you can restore the affected NGINX Controller system with the Controller database that was saved prior to the admin account demotion. For more information about backing up and restoring the NGINX Controller system, refer to Back Up & Restore.
