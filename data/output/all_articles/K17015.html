Known Issue

An error may occur when you attempt to create a Virtual Clustered Multiprocessing (vCMP) guest on a VIPRION system, if slot 1 has no blade installed.

This issue occurs when all of the following conditions are met:

  • You have a VIPRION system with no blade installed in slot 1.
  • You have the vCMP module provisioned.
  • You attempt to create a vCMP guest by using the Traffic Management Shell (tmsh) without setting the cores-per-slot attribute option.

Impact

Attempts to create a vCMP guest fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to create a new vCMP guest, the system displays an error message similar to the following example:

    010716a5:3: Unable to find default core count for guest on this hardware. Please use restricted slots.

Workaround

To work around this issue, when creating a new vCMP guest, you can set the cores-per-slot option. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. From the vCMP host, log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To create a new guest by using the cores-per-slot option, use the following command syntax:

    create vcmp guest <guest name> state <configured | provisioned | deployed> cores-per-slot <number>

    For example, to create a new vCMP guest named test_guest with 2 cores per slot, type the following command:

    create vcmp guest test_guest state configured cores-per-slot 2

  3. To save the configuration, type the following command:

    save sys config

  4. To exit the tmsh utility, type the following command:

    quit
