Known Issue

The BIG-IP APM Custom Report may not display assigned values.

This issue occurs when all of the following conditions are met:

  • You create a BIG-IP APM Custom Report containing the user report field Assigned IP.
  • You run the custom report.

Impact

The custom report field for Assigned IP does not show the IP address assigned to user sessions.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you run the custom report, the Assigned IP value for all sessions is IPv4.
  • When you run the built-in reports All Sessions or Current Sessions, the Assigned IP box shows the assigned IP address.

Resolution

Status

Workaround

To work around this issue, you can run the BIG-IP APM built-in reports All Sessions or Current Sessions to view the session assigned IP addresses.
