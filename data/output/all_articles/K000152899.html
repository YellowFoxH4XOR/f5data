Description

Running the tmsh load sys config verify command on BIG-IP LTM systems with large or complex configurations can cause the control plane (MCPD) to become temporarily unresponsive. During this period, management-plane statistics such as CPU and memory may be unavailable, and MCPD query response times may exceed 30, 60, or 90 seconds. This can disrupt iQuery communications between LTM and GTM devices, resulting in GTMs losing visibility to the affected LTM pair. Other management functions such as SNMP queries and health monitoring may also be impacted.

 

Environment

  • BIG-IP LTM
  • Execution of tmsh load sys config verify on systems with large/complex configurations

 

Cause

The tmsh load sys config verify command is resource-intensive when run against large or complex configurations. It can temporarily overload the control plane (MCPD), causing delays in processing other management-plane requests—including iQuery responses—leading to loss of GTM visibility.

 

Recommended Actions

The following should be considered and not in any specific order.

  • Schedule configuration verification (tmsh load sys config verify) during maintenance windows or periods of low activity.
  • Monitor system resource usage during these operations to assess impact.
  • For very large or complex configurations, consider breaking up tasks or reviewing system sizing.
  • Avoid running multiple resource-intensive management commands simultaneously.
