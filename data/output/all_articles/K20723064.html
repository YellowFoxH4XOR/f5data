K20723064: Error while transforming Virtual Server

Type
Support Solution
Published
2022-03-18
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K20723064

Description

While adding an LTM to the BIG-IQ, the device is added and shows in the devices tab, however, during configuration import, it gives us the following error:
Error while transforming Virtual Server, message 'java.lang.IllegalStateException: Full path /Common/host has no matches.' was returned

Environment

  • BIG-IQ 7.x or 8.x 
  • BIG-IP
  • Host persistence profile configured on the BIG-IP

Cause
Bug ID937761 Import of BIG-IP with host persistence profile fails

Recommended Actions

Remove the Host Persistence Profile on the BIG-IP from use, and then import the configuration again

Additional Information
None
