Description
An error message logged constantly under /var/log/ltm:
err mcpd[PID]: 0107167d:3: Data publisher not found or not implemented when processing request (unknown request), tag (177).
err mcpd[PID]: 0107167d:3: Data publisher not found or not implemented when processing request (unknown request), tag (139).

Environment

  • BIG-IP Logs
  • SNMP

Cause
This error messages are logged when an SNMP server is polling an OID from BIG-IP devices that returns an uninitialized or disabled value.

Recommended Actions

  1. Locate the OID that might be returning the uninitialized value:
    Run this command from the BIG-IP command line:
    snmpwalk -v 2c -c public localhost bigipSystem | grep 'uninitialized'
    You should get an output similar to the one below, meaning the OID called: "sysDot1dbaseStatType.0", is the one returning an uninitialized value:
    F5-BIGIP-SYSTEM-MIB::sysDot1dbaseStatType.0 = INTEGER: uninitialized(0)

  2. Locate the OID that might be returning the disabled value:
    Run this command from the BIG-IP command line:
    snmpwalk -v 2c -c public localhost bigipSystem | grep 'disable'
    You should get an output similar to the one below, meaning the OID called: "sysStpBridgeStatMode.0", is the one returning a disabled value:
    F5-BIGIP-SYSTEM-MIB::sysStpBridgeStatMode.0 = INTEGER: disable(0)

  3. Configure your SNMP server to stop / avoid polling OIDs located on steps 1 and 2. This will stop the "Data Publisher" errors from being logged to /var/log/ltm.

Additional Information
Running this command, will also help you reproduce the log on /var/log/ltm, as soon as this is executed:

  1. To reproduce log: 0107167d:3: Data publisher not found or not implemented when processing request (unknown request), tag (177).
    > snmpget -v2c -cpublic localhost F5-BIGIP-SYSTEM-MIB::sysDot1dbaseStatType.0 F5-BIGIP-SYSTEM-MIB::sysDot1dbaseStatType.0 = INTEGER: uninitialized(0)
  2. To reproduce log: 0107167d:3: Data publisher not found or not implemented when processing request (unknown request), tag (139).
    > snmpget -v2c -cpublic localhost F5-BIGIP-SYSTEM-MIB::sysStpBridgeStatMode.0
    F5-BIGIP-SYSTEM-MIB::sysStpBridgeStatMode.0 = INTEGER: disable(0)
