K000136002: Script route-api.py unable to work due to OAM-DB

Type
Support Solution
Published
2023-08-29
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.0
Source
https://my.f5.com/manage/s/article/K000136002

Description

  • Script route-api.py is used to add routes to the SDC system.
  • It communicates to the Cassandra OAM-DB when the script is run.
  • You will see script output error like :

[2023-08-14 22:24:39,998] WARNING - [control connection] Error connecting to <OAM-DB_IP>: Traceback (most recent call last):

File "cluster.py", line 2535, in cassandra.cluster.ControlConnection._reconnect_internal (cassandra/cluster.c:39255)

File "cluster.py", line 2557, in cassandra.cluster.ControlConnection._try_connect (cassandra/cluster.c:39710)

File "cluster.py", line 1107, in cassandra.cluster.Cluster.connection_factory (cassandra/cluster.c:13658)

File "connection.py", line 321, in cassandra.connection.Connection.factory (cassandra/connection.c:5069)

File "/usr/lib64/python2.6/site-packages/cassandra/io/libevreactor.py", line 260, in __init__ self._connect_socket()

File "connection.py", line 360, in cassandra.connection.Connection._connect_socket (cassandra/connection.c:6050) error: [Errno 99] Tried connecting to [('<OAM-DB_IP>', 9042)]. Last error: Cannot assign requested address

 

Environment

  • SDC 5.x
  • Route api script
  • OAM-DB

Cause

If the node where the route-api.py script is run experiences issues connecting to OAM-DB and/or OAM-DB is not fully functional the script will fail.

 Recommended Actions

1. Run the command below to get the process IDs of Cassandra for OAM-DB node 1. 

#ps aux | grep CassandraDaemon -i --color

2. Kill the process by the command below.

#kill -9 <PID-of-CassandraOAMDB>

3. Check if monit has automatically restarted Cassandra. It should have a new PID.

#ps aux | grep CassandraDaemon -i --color

4. If the same PID go back to step 1. If the monit didn't start Cassandra perform the command below. 

#monit start <OAM-DB-Name>

5. Once the OAM-DB PID is new and running perform the same steps to node 2. 

6. Once both OAM-DB nodes have new OAM-DB PIDs then please try to check if you can perform the route-api.py script now.
