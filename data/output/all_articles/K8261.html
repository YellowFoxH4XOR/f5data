Topic

This article applies to BIG-IP 9.x through 11.1.0. For information about other versions, refer to the following article:

  • K13802: Enabling dynamic routing protocols for a route domain

If your BIG-IP system is licensed for the ZebOS set of advanced routing modules (ARM), you must enable the appropriate routing protocol before you can use the ZebOS VTY shell to add entries into the ZebOS.conf file. If you attempt to access the VTY command line shell (by typing vtysh or imish) prior to enabling a routing protocol, the system displays an error message that appears similar to one of the following examples:

  • BIG-IP 11.0.0 - 11.1.0

    % Can't set FD_CLOEXEC to IMI socket: Bad file descriptor

  • BIG-IP 9.4.4 - 10.x

    % Connection is closed!

  • BIG-IP 9.0.0 - 9.4.3

    Cannot connect to nsm. Exiting...

When you enable an advanced routing protocol, the BIG-IP system creates a default ZebOS.conf file in the /config directory.

To enable a routing protocol at the BIG-IP system prompt, type the zebos command and specify a routing module using the following syntax:

zebos enable [bgp | isis | ospf | ospf6 | rip | ripng]
