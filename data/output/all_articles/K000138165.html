Description

  • Unable to discover/import ASM to BIG-IQ CM
  • During ASM discovery in BIG-IQ, you may encounter the following error message:
           Error querying 'ASM Signature' from path '/mgmt/tm/asm/signatures' on device <hostname> (IP address), network communication failed due to protocol error.

Environment

  • Big-IQ ASM discovery
  • Big-IP ASM

Cause

  • When trying to discover all the ASM attack signatures, sometimes the BIG-IP REST framework can't provide a valid response back due to the large number of objects. Instead, the BIG-IP will respond with a 400 error.
  • Very large ASM configurations.

Recommended Actions

On BIG-IP:

Using text editor open file /etc/bigstart/scripts/restjavad and include next line below "JVM_OPTIONS=" -Xss384k":

JVM_OPTIONS+=" -Dorg.eclipse.jetty.server.HttpChannelState.DEFAULT_TIMEOUT=180000"

Example:
 

# JVM: limit the default stack size per thread.
# Tough trade-off: keep small enough to play game with TMM's strict memory footprint requirements.
# Keep large enough to fit some of the more stack-expensive JVM networking APIs (e.g. lookupAllHostAddr())
JVM_OPTIONS="-Xss384k"

JVM_OPTIONS+=" -Dorg.eclipse.jetty.server.HttpChannelState.DEFAULT_TIMEOUT=180000"

# Print out to the console all final JVM options, useful for debugging
# Look in /var/tmp/restjavad.out


Set restjavad timeout to 180s at db values:
 

tmsh modify sys db icrd.timeout restjavad.timeout restnoded.timeout value 180
 

Restart service, and try to import the config again:
 

bigstart restart restjavad
