Description

Unable to locate the SSL certificate which is triggering these warnings in /var/log/ltm:

Unable to get certificate for peer cert issuer /CN=Example Root CA

Peer cert verify error: unable to get issuer certificate (depth 1; cert /DC=com/DC=example/DC=exampleDC/CN=Example ICA)

 

Environment

  • BIG-IP LTM
  • Certificate warnings

Cause

Bug ID 1125381

Recommended Actions

Use the following bash commands to identify ca-file certificates used in client and server ssl profiles:

tmsh list ltm profile client-ssl | grep ca-file | sort | uniq

tmsh list ltm profile server-ssl | grep ca-file | sort | uniq

Review each certificate and ensure the CA cert is included in each one to prevent the warning log messages.
