K000147800: How to skip Threat Mesh

Applies to

  • F5 Distributed Cloud
Source

Description

  • I want to disable Threat Mesh during a scan or pen-testing session.
  • I need to exclude specific IP addresses from being blocked by Threat Mesh.
  • I want to exclude specific IP addresses from being blocked by Threat Mesh

Environment

  • F5® Distributed Cloud Threat Mesh

Cause

None

Answer/Recommended Actions

  • Skip Threat Mesh action in Trusted Client Rules

Cause

  • Use Trusted Client Rules in case of False Positive.​

Additional Information

If you are using Web Application Scanning (WAS) within the F5 Distributed Cloud environment, be aware that:

  • WAS may use known IP addresses, which can be safely added to Trusted Client Rules.
  • It is recommended to disable Threat Mesh while running scans to prevent unnecessary blocking.
