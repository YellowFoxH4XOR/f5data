Known Issue

This is the result of a known issue. When you view the Local DNS Statistics page in the Configuration utility, 3-DNS divides the results into multiple pages. The page count is always off by one. As a result, there is always one page beyond what appears to be the last page.

For example, if there are ten pages of results, the second to last page will report that it is page 10/10, when it is actually page 9. If you click the page forward arrow, you will receive a different page that also reports itself as page 10/10, and is the actual last page.

F5 Networks Product Development tracked this issue as CR18258.
