Topic

The following error indicates that an SSL proxy connection timed out before it received a response from a node:

connect() to server failed: errno = 60

This message most frequently occurs when the node that the target virtual server selected is not available, so the SSL proxy connection times out. This error can also occur if the node is slow to respond or if there is packet loss caused by a short timeout value.

The default timeout for connections to the SSL proxy is 30 seconds. To increase the SSL proxy timeout setting, type the following command:

sysctl -w net.inet.tcp.conntimeo=<seconds>

For example, to set the SSL proxy timeout at 60 seconds, you would type:

sysctl -w net.inet.tcp.conntimeo=60
