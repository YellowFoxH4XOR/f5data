Description

  • Configured SCTP Virtual server as IP Forwarding for SCTP Multi-Homing, not getting to destination servers.

Environment

  • IP Forward Virtual Server
  • Wildcard port set

Cause

The Destination IP set for the VIP is not including port number.
Default SCTP port is 3868.

Recommended Actions

Make sure when you set the Virtual Server for SCTP, it will include the Port number used for SCTP connection.
Set port number 3868 to the Virtual Server's destination port.

None.
