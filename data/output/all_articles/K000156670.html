Description

API authentication to BIG-IP LTM using iControl REST may intermittently fail with HTTP 400 "Bad Request" errors. Typical log entries include:

  • [I][113836][29 Aug 2025 09:12:19 UTC][ForwarderPassThroughWorker] {"user":"local/null","method":"POST","uri":"http://localhost:8100/mgmt/shared/authn/login","status":400,"from":"xx.xx.xx.xx"}

Environment

  • BIG-IP LTM
  • iControl REST
  • API Calls

Cause

There may be a few possible causes of this issue:

  • Insufficient memory allocated to management and REST-related daemons, resulting in degraded performance and API failures.
  • Exhaustion of available login tokens for the default admin user (see Bug ID 959057, 1853721, and K44237337).
  • Stale or corrupted REST storage or token database preventing new authentications.

Recommended Actions

There are a few workarounds to perform depending on what is suspected.

  1.  If token exhaustion is suspected, delete all current tokens:
    restcurl -X DELETE /shared/authz/tokens
  2. Increase Management and REST Daemon Memory, along with timeout values. Run the following commands during a maintenance window, preferably on the standby device first:
    tmsh modify sys db provision.extramb value 2000
    tmsh modify sys db provision.restjavad.extramb value 1000 
    tmsh modify sys db provision.tomcat.extramb value 300
    tmsh modify sys db restnoded.timeout value 600
    tmsh modify sys db restjavad.timeout value 600
    tmsh modify sys db icrd.timeout value 600
    bigstart restart restjavad && sleep 20 && bigstart restart restnoded
    tmsh save sys config
    Note: The above commands should be done during a maintenance window after the box is set to standby to minimise disruption (if done while box is active, it can cause HA failover action).
  3. Clear REST Storage
    If increasing memory does not resolve the issue, clear the REST storage:
    clear-rest-storage
    Expected output:
    Stopping restnoded
    Stopping restjavad
    Removing storage files
    Removing index files
    Starting restjavad
    Starting restnoded
    Note: This should impact only the control plane; traffic should not be affected.
  4. Delete Current Login Tokens
    If token exhaustion is suspected, delete all current tokens:
    restcurl -X DELETE /shared/authz/tokens
