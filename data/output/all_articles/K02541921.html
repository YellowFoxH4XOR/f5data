Issue

Error Message

notice sod[<PID>]: 010c005a:5: Dropping a failover packet that is too small

In this error message, note the following:

  • <PID> is the process ID for the sod process.

For example:

notice sod[3678]: 010c005a:5: Dropping a failover packet that is too small

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The sod process receives a message on one of its failover listening addresses that is not big enough to be a valid failover packet.

Impact

The BIG-IP system drops the packet. Occasional occurrences of this message are benign unless seen in conjunction with other system issues.

Recommended Actions

If the BIG-IP system ceases to receive failover messages from another device in a Sync-Failover group, the presence of this log message may indicate an issue with the sod process on the other device. Restarting the sod process on the other BIG-IP system may resolve the issue. If restarting the sod process does not resolve the issue, you can contact F5 Support. To restart the sod process, perform the following procedure:

Impact of procedure: Restarting the sod process causes all active traffic groups to fail over to another device in the device group.

  1. Log in to the command line of the other BIG-IP system in the device group.
  2. Check the status of the sod process by entering the following command:

    bigstart status sod

  3. If the status is not run, or if no failover messages are sent, restart the sod process by entering the following command:

    bigstart restart sod
