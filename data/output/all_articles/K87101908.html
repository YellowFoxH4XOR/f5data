K87101908: Multi Connection per Peer not triggered when connecting to 2 different FEPs

Type
Support Solution
Published
2022-08-25
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.X, 5.1.0
Source
https://my.f5.com/manage/s/article/K87101908

Description

  • Multiple Connections per Peer feature is designed for multi connections from a client peer using the same origin-host name to connect to the same FEP.
  • Peers making connections to 2 different FEPs will not trigger the Multiple Connections per Peer feature and no suffix SN_<index#> appended by SDC.

Environment

  • SDC 5.x
  • Multiple Connections per Peer feature
  • peer.setMultiConnections

Cause

By design

Recommended Actions

None

Additional Information

Configuring Multiple Connections per Peer feature is described in the Signalling Deliver Controller User Guide 5.1 section 3.3.1.4
