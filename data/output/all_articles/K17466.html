Known Issue

The BIG-IP APM system may improperly process HTML anchors without linking URLs.

This issue occurs when all of the following conditions are met:

  • The resource is requested using BIG-IP APM portal access.
  • The HTML anchor ( <a> ) in the server response does not have an html attribute.
  • The resource is accessed using a web browser other than Microsoft Internet Explorer.

Impact

The BIG-IP APM system incorrectly inserts a non-empty html value which may cause the web application to malfunction.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Web application components relying on the value of the html attribute do not function properly.
  • Portal access users experience decreased resource functionality.
