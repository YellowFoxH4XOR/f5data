Known Issue

This is the result of a known issue. The BIG-IP system may report incorrect CPU temperatures and fan speeds. When this issue occurs, the system reports log messages indicating that the CPU is too hot and the fan speed is either nonexistent or too low. The error messages are logged to the /var/log/ltm file and appear similar to the following example:

010d0001:0: Cpu 1: temperature (255) is too high.
010d0002:2: Cpu 1: fan speed (-2147483648) is too low.
010d0004:0: Chassis 2: temperature (255) is too high.
010d0003:3: Cpu 1: fan speed (1323): no signal being received.
010d0001:0: Cpu 1: temperature (255) is too high.
010d0002:2: Cpu 1: fan speed (-2147483648) is too low.

You can identify the spurious error messages that result from this issue by the reported values within each message. For temperature, if the reported value is 255, the error is a result of this issue and you can safely ignore the message. For fan speed, if the reported value is -2147483648, or if the error indicates that no signal is being received, the errors are a result of this issue and you can safely ignore the message.

F5 Product Development tracked this issue as ID 333222 (formerly CR79150-1), ID 308069 (formerly CR79150-2), and ID 213423 (formerly CR79150-3) and it was fixed in BIG-IP versions 9.4.8 and 10.1.0. For information about upgrading, refer to the BIG-IP LTM, GTM, or Link Controller release notes.

This issue still exists as ID 335346 (formerly CR79150) for the BIG-IP version 9.1.x software branch.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-9.3.1-40.2-HF1, which has been issued for BIG-IP version 9.3.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
