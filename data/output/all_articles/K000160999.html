K000160999: BIG-IP Edge Client behavior when switching between non-local network and local network with auto connect configured

Type
Support Solution
Published
2026-04-30
Updated
2026-04-30
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000160999

Description

This article addresses auto connect to different VPN servers behavior for the BIG-IP Edge Client when users switch between non-local network and local network.

    Environment

    Edge Client with auto connect configured.

    Issue

    When switching between non-local network and local network, user is seeking Edge Client to disconnect from currently connected VPN server, and automatically connect to different VPN server, if local network is detected.

    Example:
    User is in network 'example.non-local' and is auto connected to VPN server, because network 'example.non-local' is not configured as local network.
    Next, user is switching network to 'example.local' which is configured as local network, and expect Edge Client to automatically reconnect with different VPN server.

    This behavior cannot be configured.

    Cause

    None.

    Recommended Actions

    Edge Client cannot automatically switch to a different VPN profile or server when switching from non-local network to configured local network. This is not currently supported.
