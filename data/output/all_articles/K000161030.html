K000161030: How to disable HTTP TRACE in the F5OS GUI

Type
Support Solution
Published
2026-04-29
Updated
2026-04-29
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000161030

Description

Disable the HTTP TRACE method for F5OS GUI (F5OS refers to both F5OS-A, F5OS-C and the unified F5OS ).

Environment

  • F5OS-A
  • F5OS-C

Cause

None

Answer/Recommended Actions

By default the TRACE method is disabled in the F5OS GUI. Depending on the F5OS version, the GUI may return either

  •  405 Method Not Allowed, or
  • 403 Forbidden

Additional Information

None
