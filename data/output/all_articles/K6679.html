F5 Networks previously licensed the following modules as add-ons to the base FirePass license:

Part numberModule name in license fileFeature name
F5-ADD-FP-APPFP Application ConnectorApplication Access App Tunnels
F5-ADD-FP-TERMFP Terminal Server AdapterApplication Access Terminal Servers
F5-ADD-FP-OPSWATFP Anti-Virus/FireWall InspectorEndpoint Security Inspector

If you have a valid service contract, you can upgrade to version 6.0.0 or a later version of FirePass software in order to use these modules, even if these modules were not previously licensed. The new modules must be activated by re-licensing the FirePass controller.

Important: FirePass 600 hardware platforms are not eligible for upgrade to version 6.0.0 of FirePass software. Contact your local sales representative for details on programs for upgrading to a platform that supports version 6.0.0 and later versions of FirePass software.

You can re-license the FirePass controller by performing the following procedure:

  1. Logon to the FirePass Administrative Console.

  2. Navigate to the Device Management: Maintenance: Activate License page.

  3. Under the Registration Method section, select either the Automatic or Manual option button.

    Note: The the Automatic option is preferable for a FirePass controller with outbound access to the Internet on port 443/TCP. Consult the online help from the Device Management: Maintenance: Activate License page for additional information.

Perform one of the following two procedures, depending on which Registration Method you selected.

Automatically register and install the license

To automatically register the license, perform the following steps:

  1. Click the Request License button.

  2. Accept the End User License Agreement.

  3. Provide your business email address and contact details at the prompts.

    Your new license file displays.

  4. Activate and install the license by clicking the Continue button.

    This process may take several seconds.

Manually register and install the license

To manually register the license, perform the following steps:

  1. Click the Request License button.

  2. Copy the full contents of the Product Dossier field.

  3. Below the Product Dossier box, click the Click here to access F5 Licensing Server link.

    The Activate F5 License screen appears in a new browser window.

  4. Enter the dossier you obtained in Step 2 into the Enter your dossier field.

  5. Click the Activate button.

  6. Accept the End User License Agreement.

  7. Provide your business email address at the prompt.

    Your new license file displays.

  8. Copy the full contents of the License File field.

  9. Return to the FirePass Administrative Console.

    The Activate License screen should still be displayed.

  10. Enter the license you obtained in Step 7 into the License File field.

  11. Click the Install License button.

  12. Click the Continue button to activate and install your license.

Once you have obtained and installed your new license, you may verify that the features are now active by clicking on the Click here to view license details link on the Device Management: Maintenance: Activate License page. Check that the following features are in the Enabled state:

  • Application Tunnels
  • Terminal Services
  • Anti-Virus/Firewall End-Point Security
