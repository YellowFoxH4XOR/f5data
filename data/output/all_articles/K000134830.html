K000134830: This device cannot be added as a Data Collection Device until the self-ip is configured

Type
Support Solution
Published
2023-06-13
Updated
2023-06-13
Source

Description

You would like to add DCD to the Cluster but the following error is showing up:

Error: Unable to add Data Collection Device <IP-ADDRESS> to logging cluster with error 'updateNode: unable to configure transport self-ip: java.lang.IllegalStateException: unable to get self-ip name from address 192.168.1.245. This device cannot be added as a Data Collection Device until the self-ip is configured'

The IP address of 192.168.1.245 belongs to the Initial F5 config, if something was misconfigured in the Setup Utility, you can observe that IP address at the bottom of the /var/config/rest/elasticsearch/config/elasticsearch.yml file. In the properly configured cluster, this file should contain all management IP addresses of the devices already attached to the cluster.
 

Environment

  • BIQ IQ CM
  • BIG IQ DCD

 Recommended Actions

Verify the /var/config/rest/elasticsearch/config/elasticsearch.yml on both devices - CM and DCD: 
tail /var/config/rest/elasticsearch/config/elasticsearch.yml
Depending on the output, please execute the following procedure on devices with 192.168.1.245 visible in elasticsearch.yml.
  1. In BIG IQ GUI click System > This Device > General Properties > Return to Setup
  2. Select Continue to enter setup mode.
  3. Once the BIG-IQ user interface is available, log back in as the administrative user and you should now be redirected to the setup wizard.
  4. Select Next to advance.
  5. You may have to select Discard Changes to proceed.
  6. Once you are on the Password step, you must re-configure the Admin and Root passwords. Use the current passwords for this step.
  7. Continue selecting Next to advance to the Networking step.
  8. When on the Networking step, select a new option for Discovery Address.
  9. Select Next until you reach the final step, then select Launch.
  10. Verify if the IP address changed in elasticsearch.yml file
tail /var/config/rest/elasticsearch/config/elasticsearch.yml

If the IP address is now correct you should be able to successfully add DCD to the CM
