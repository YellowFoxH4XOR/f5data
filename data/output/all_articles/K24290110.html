Description

You want to remove a child security policy from a parent security policy.
This might be necessary if you want your child security policy to stop receiving changes from the parent security policy.


Environment

  • ASM (Application Security Manager)
  • Advanced WAF (Web Application Firewall)


Cause

You wish to remove a child security policy from a parent security policy, so it no longer inherits changes from the parent policy.


Recommended Actions

Please note that the steps for versions 13.1.X and 14.1.X are different from those for 15.1.X and 16.1.X.

For versions 13.1.X and 14.1.X:

  1. Navigate to Security ›› Application Security : Security Policies : Policies List.
  2. Select the child security policy you want to modify.
  3. Click on the Inheritance Settings tab at the top of the child policy settings.
  4. In the Parent Policy dropdown menu, change the selection to "None" and save your changes.

For versions 15.1.X and 16.1.X:

  1. Navigate to Security ›› Application Security : Security Policies : Policies List.
  2. Select the child security policy you want to modify.
  3. Click on the Inheritance Settings tab on the left-hand side of the child policy settings.
  4. In the Parent Policy dropdown menu at the top, change the selection to "None" and click "Save" at the top.
