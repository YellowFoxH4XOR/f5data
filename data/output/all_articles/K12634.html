Topic

Clients that use Forefront Client Security software as their antivirus software may fail a pre-logon inspection that looks for the age of the signature database. This issue occurs if the user does not have read permissions to the directory that holds the signature database. Because the user's permissions do not allow access to the signature database, OPSWAT is unable to inspect the age of the database and terminates the logon attempt. You can resolve this issue by granting the user read access to the applicable directory.

Note: For more information about locating the appropriate directory on your user's system, refer to Microsoft KB article 953524: How to deploy Forefront Client Security definitions by using a file-copy procedure. This link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

The FirePass and BIG-IP APM Windows antivirus checker uses software libraries from a software development kit created by OPSWAT. OPSWAT provides a vendor-independent framework for endpoint security management. OPSWAT is aware of the issue described in this Solution and reports that this issue is expected behavior.
