Description
When trying to access your site, users get a BIG-IP ASM blocking page which instructs them to turn on JavaScript. The support ID is generated but the ID is not logged as a request in Security  ››  Event Logs : Application : Requests in the Configuration Utility. Therefore the support ID can not be used to view additional violation information.

Example blocking page returned when the browser cannot process JavaScript:

Please enable JavaScript to view the page content.
Your support ID is: 01234567891011121314

Environment

  • BIG-IP ASM
  • Security Policy has enabled features which require JavaScript

Cause
By design, these support IDs are not logged to the event logs since the request has not been processed by ASM and no violation has occurred.

Recommended Actions
It is recommended that the user enable JavaScript for their browser client and disable any plug-ins which disable JavaScript.

Additional Information
ASM features within an ASM Security Policy that utilize requests to /TSbd/* URL include:
* Web Scraping Bot Detection
* AJAX Blocking Page
* CSRF Protection
* Single-Page Application
* Client-Side mitigation of Web Scraping Session Opening
* Client-Side mitigation of Brute Force
* Session Tracking (by Device ID)
