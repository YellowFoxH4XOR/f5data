Known Issue

A virtual server may stop accepting traffic after the server type is changed to Performance HTTP.

This issue occurs when the following condition is met:

  • You change an existing Standard virtual server to a Performance HTTP virtual server.

Impact

The virtual server fails to pass traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Clients that attempt to connect to the virtual server are timing out.

Workaround

To work around this issue, you can change the virtual server type to FastL4, and then change the virtual server type to Performance HTTP. To do so, perform the following procedure:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Server > Virtual Server List.
  3. Select the virtual server.
  4. From the General Properties section, in the Type menu, select Performance (Layer 4).
  5. At the bottom of the screen, click Update.
  6. From the General Properties section, in the Type menu, select HTTP (Layer 4).
  7. At the bottom of the screen, click Update.
