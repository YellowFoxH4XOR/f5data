Description
Failover not working in Azure Cloud with Cloud Failover Extension (CFE) 

Environment

  • BIG-IP v15.1.x
  • Azure Cloud
  • Azure HA via-api template 7.4.0.0
  • Cloud Failover Extension (CFE)

Cause
Resource group and the existing virtual network resource group has not been assigned at least a Contributor role.

Recommended Actions

  1. As per deployment manual, The user-assigned managed identity must be granted the Contributor role to both the deployment resource group and the existing virtual network resource group prior to deployment.

Additional Information
For more Prerequisites information please see, Deploying the BIG-IP VE in Azure - HA Cluster (Active/Standby) Prerequisites
