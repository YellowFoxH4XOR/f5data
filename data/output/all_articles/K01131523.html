Description


This article describes how to remove a managed device from the BIG-IQ configuration using the command line on BIG-IQ (using restcurl) or an external device (using curl).

Environment

  • BIG-IQ
  • Remove managed device using CLI

Cause

None


Recommended Actions


Procedure to remove a device using the BIG-IQ REST API. You use iControl REST to first remove the discovered services and then you remove the device. 

External Device: Set variables in the local environment required to run the command:

IP=<IP_TARGET_BIGIQ>
USERNAME=<USER_NAME>
PASSWORD=<PASSWORD>

Example:

IP=192.0.2.50
USERNAME=admin
PASSWORD=ExAmP1EpAsSwOrD

Important: When finished with the procedure below, unset the variables with the syntax: unset <variable name>. Additionally, remove the PASSWORD variable command from the history by running the command history to get the line number then use the following syntax: history -d <line number>.

  1. Get auth token and save in a variable:

    TOKEN=$(curl -sk -H "Content-Type: application/json" https://${IP}/mgmt/shared/authn/login -X POST -d '{"username": "'$USERNAME'","password":"'$PASSWORD'","loginProviderName": "tmos"}' | jq '.token.token' | tr -d '"')

  2. List all devices and find UUID for the device you want to remove:

    External Device: curl -sk -H "X-F5-Auth-Token: ${TOKEN}" https://${IP}/mgmt/cm/system/machineid-resolver | jq '.items[] | {uuid,hostname,version,product,managementAddress,selfLink}'
    Primary BIG-IQ CLI: restcurl /cm/system/machineid-resolver | jq '.items[] | {uuid,hostname,version,product,managementAddress,selfLink}'

  3. Find the UUID from step 2 and save it in a variable:

    UUID=<uuid>

    Example:

    UUID=caf1981c-db31-4e66-bb11-e8cb7b005fbb

  4. Save POST data to a variable that will be used to make the request to remove all Services:

    POST_BODY=$( echo '{"moduleList":[{"module":"adc_core"},{"module":"access"},{"module":"asm"},{"module":"fps"},{"module":"firewall"},{"module":"security_shared"},{"module":"dns"}],"deviceReference":{"link":"https://localhost/mgmt/cm/system/machineid-resolver/'$UUID'"},"createChildTasks":true,"name":"remove_all_services_'${UUID}'"}')

  5. Make a request to remove all Services for the device:

    External Device: curl -sk -H "Content-Type: application/json" -H "X-F5-Auth-Token: ${TOKEN}" https://${IP}/mgmt/cm/global/tasks/device-remove-mgmt-authority -X POST -d $POST_BODY | jq .
    Primary BIG-IQ CLI: restcurl /cm/global/tasks/device-remove-mgmt-authority -X POST -d $POST_BODY | jq .

  6. Query the selfLink endpoint (from the output of the previous step) periodically to track the task status. Replace <TASK_ID> with the id in the output from step 5.

    External Device: curl -sk -H "Content-Type: application/json" -H "X-F5-Auth-Token: ${TOKEN}" https://${IP}/mgmt/cm/global/tasks/device-remove-mgmt-authority/<TASK_ID> | jq .
    Primary BIG-IQ CLI: restcurl /cm/global/tasks/device-remove-mgmt-authority/<TASK_ID> | jq .

    Proceed to removing the device when the task status field is set to FINISHED, otherwise see Additional Information section.

  7. Save POST data to a variable that will be used to make the request to remove the device:

    POST_BODY=$(echo '{"deviceReference":{"link":"https://localhost/mgmt/cm/system/machineid-resolver/'$UUID'"},"name":"device-remove-'${UUID}'"}')

  8. Make POST request to remove the device from BIG-IQ:
    Important: If the BIG-IP license is managed by BIG-IQ, then proceeding with this step will also remove the license on BIG-IP which will halt traffic processing. Proceed only if BIG-IP is no longer processing traffic.

    External Device: curl -sk -H "Content-Type: application/json" -H "X-F5-Auth-Token: ${TOKEN}" https://${IP}/mgmt/cm/global/tasks/device-remove-trust -X POST -d $POST_BODY | jq .
    Primary BIG-IQ CLI: restcurl /cm/global/tasks/device-remove-trust -X POST -d $POST_BODY | jq .

Additional Information

If the task status returns FAILED, then review the errorMessage to identify the problem.

The following is a common errorMessage returned if you deploy AS3 via BIG-IQ:

"errorMessage": "Device in use by application 'example.com'"

Before you can remove the services for this managed BIG-IP, you must first remove the applications associated with this device.
Identify the name of the applications in the BIG-IQ GUI > Applications tab > APPLICATIONS then follow the steps outlined in the following article to remove the applications before trying again to remove the services.

K42012148: Failed to delete BIG-IQ applications in Configuration Utility
