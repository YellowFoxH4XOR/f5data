Known Issue

rsync messages may flood the datasyncd.log file in clustered systems.

This issue occurs when all of the following conditions are met:

  • One of the blades in the cluster is either down, powered off, disabled, or not populated.
  • You perform one of the following actions:
    • You provision either the BIG-IP ASM or Fraud Protection Service (FPS) module.
    • You power on a blade that has been powered off for a day or longer.
    • You add the cluster to a trust domain.
    • You install either an ASM or FPS update file.

Impact

The impact is cosmetic and does not affect traffic. The messages temporarily log to the datasyncd.log file every few seconds.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Messages flood the /var/log/datasync/datasyncd.log file that appear similar to the following example:

    rsync: failed to connect to 127.3.0.3: No route to host (113)
