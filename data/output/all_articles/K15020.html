Known Issue

Role-based access to the system logs may reset after the BIG-IP system reboots.

This issue occurs when all of the following conditions are met:

  • You have selected Allow in the Log Access settings for non-administrative users on the System > Logs > Configuration > Options screen of the Configuration utility.
  • Your BIG-IP system reboots.

Impact

Authorized users cannot access logs from the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth  lists Heuristic H438682 on the Diagnostics > Identified > Medium|High  screen.
  • After your BIG-IP system reboots, authorized non-administrator users are not be able to view system logs in the Configuration utility.
  • After your BIG-IP system reboots, the log access setting on the System > Logs > Configuration > Options screen of the Configuration utility resets to Deny.
  • After your BIG-IP system reboots, corresponding UI.logaccess.* db key options revert to the default value of disabled.
