Topic

F5 provides End-User Diagnostics (EUD) software for all supported FirePass hardware platforms. The EUD feature is implemented as a boot option. Once booted in EUD mode, the FirePass controller provides a menu of tools for testing hardware components. The release notes for current EUD software for all hardware platforms can be found under the Related Documentation section the FirePass documentation for your FirePass version.

New versions of EUD software may be released to support a new hardware platform, to add a new feature to the EUD, or to provide fixes for known issues. New EUD features may apply to all hardware platforms or be specific to the features of a particular hardware platform. Similarly, fixes for known issues may apply to all hardware platforms or be specific to a particular hardware platform.

For the FirePass controller, EUD software is distributed as hotfixes. Hotfixes are created for each version of FirePass software that requires the hotfix. Choose the EUD hotfix that matches your version of FirePass software. The F5 Downloads site requires you to select a version of FirePass software, and then displays hotfixes for only that version. The appropriate EUD hotfixes for your version of FirePass controller will display. For more information, refer to K7960: Obtaining and installing the latest version of End-User Diagnostics.

Because of the size of the EUD software, the EUD hotfixes for the FirePass controller are specific to the hardware platform as well. Check the Description column of the hotfix listings to determine which hardware platform an EUD hotfix supports.

It is possible that new EUD software will be released, but the new EUD software may have no new features or fixes that are applicable to one or more existing FirePass hardware platforms. If no advantage would be gained by installing the new EUD software, F5 may not create a hotfix for those FirePass hardware platforms. If the FirePass section of the F5 Downloads site does not contain an EUD hotfix for your FirePass platform, you can refer to the release notes for the EUD hotfix to determine whether any new features or fixed issues apply to your hardware platform.
