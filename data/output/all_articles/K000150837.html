K000150837: Unexpected failover while modifying vlans on F5OS LAG interface assigned to tenants

Type
Support Solution
Published
2025-04-12
Updated
2025-04-12
Applies to
  • F5OS
  • F5OS-A: 1.5.2
Source
https://my.f5.com/manage/s/article/K000150837

Description

Unexpected failover on tenant hosted on F5OS-A.

Tenant configured with HA-group scoring and monitoring TRUNK interfaces.

On F5OS - Host unit, at the same time as failover, there are modifications to vlans assigned to LAG interface as below.

#interfaces interface TRUNK_INTERFACE

#no aggregation switched-vlan config trunk-vlans [ VLAN1 VLAN2 ... ...]

 

Environment

  • F5OS-A
  • Tenant failover
  • Config change via CLI 

Cause

From the CLI if one execute below command, it is interpreted as no aggregation switched-vlan config trunk-vlans.

#no aggregation switched-vlan config trunk-vlans [ vlan1 vlan2 ... ]

Therefore, above command will remove all vlans from the trunk.

Recommended Actions

From the CLI, either incrementally add or remove a single vlan, or replace with a full list.

For example:

You can add a vlan using:

#aggregation switched-vlan config trunk-vlans VLAN1

You can remove a vlan using:

#no aggregation switched-vlan config trunk-vlans VLAN1

You can replace the vlans using:

#aggregation switched-vlan config trunk-vlans [ VLAN1 VLAN2 ]
