Known Issue

Traffic Management Microkernel (TMM) may produce a core file with the Assertion rt_entry ref valid failed error message.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ARM system is deployed on the BIG-IP system.
  • Routes are dynamically added to and removed from the BIG-IP routing table.

Impact

If the BIG-IP system is a member in a redundant configuration, traffic fails over to the standby BIG-IP system. If BIG-IP system is not part of a redundant pair, traffic is interrupted until TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process restarts and produces a core file in the /shared/core directory.
  • The BIG-IP system temporarily fails to process traffic while TMM restarts.
  • The BIG-IP system fails over to another device in the device group.
  • Messages similar to the following example are logged to the /var/log/tmm files:

    panic: ../netinet/route.c:1772: Assertion "rt_entry ref valid" failed.
