Description

  • When adding numerous objects (> 3000) to a Resource Group within BIG-IQ v7.0, the system can time out with a 413 Error upon saving.
     

Environment

  • BIG-IQ Central Manager v7.0
  • Creating or Modifying a Resource Group with over 3000 objects

Cause

The request to add over 3000 items can exceed the client maximum body size within the webd.conf file.

Recommended Actions

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Backup a copy of webd.conf 
     # cp /etc/webd/webd.conf /etc/webd/webd.conf.mybackup
  2. Edit /etc/webd/webd.conf
  3. Under http context, search for "client_max_body_size 10M;" and increase the size from 10M to 20M.
  4. Save and close webd.conf
  5. Restart webd 
    # bigstart restart webd
  6. Verify if issue persists.

Additional Information

If the issue does persist, you can modify the client_max_body_size by increments of 10M, up to 128M.  
If you are still seeing the issue persist after modifying the value to 128M, and restarting webd, please open a case with F5 Network Support.
