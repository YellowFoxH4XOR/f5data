K5391: It is not possible to successfully upgrade 3-DNS from the Mindterm SSH terminal

Known Issue

This is the result of a known issue. The MindTerm SSH Console is shut down before the upgrade process completes. As a result, it is not possible to perform an upgrade using the MindTerm SSH Console.

3-DNS does not provide any warning when you attempt to upgrade the system through the MindTerm SSH Console.

F5 Networks Product Development tracked this issue as CR18436.
