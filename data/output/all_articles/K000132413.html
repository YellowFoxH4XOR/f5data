Description

"Daily Renewal Notification" will tell you that your license is about to expire.

For example, following license End Date is 2023/03/05 and "Daily Renewal Notification" is 5 days (=2023/03/01).
When the data is changed to 2023/03/01, then BIG-IP notifies "the license expires in XX days".
 

[root@bigip:Active:Standalone] config # tmsh show sys license | grep -A 5 "End Date"
License End Date                       2023/03/05
Service Check Date                     2023/02/02
Platform ID                            Z100
Daily Renewal Notification Days        5
Daily Renewal Notification Start Date  2023/03/01
 
[root@bigip:Active:Standalone] config #
[root@bigip:Active:Standalone] config # date
Fri Feb  3 16:18:04 JST 2023
[root@bigip:Active:Standalone] config #
[root@bigip:Active:Standalone] config # date -s "20230301"
Wed Mar  1 00:00:00 JST 2023
[root@bigip:Active:Standalone] config #
[root@bigip:Active:Standalone] config # tmsh show sys license | grep -A 5 "End Date"
License End Date                       2023/03/05
Service Check Date                     2023/02/02
Platform ID                            Z100
Daily Renewal Notification Days        5
Daily Renewal Notification Start Date  2023/03/01
License Notification                   Product license expires on 2023-03-06 (in 4 days).
[root@bigip:Active:Standalone] config #

2023 Mar  1 00:00:20 bigip mcpd[5408]: 01071db9:0: Product license expires on 2023-03-06 (in 4 days).
 
[root@bigip:LICENSE EXPIRES IN 4 DAYS:Active:Standalone] config #

It is by our design.
