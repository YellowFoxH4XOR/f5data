K11762: Changing LCP Keep-Alive packet frequency to prevent DTLS tunnel failures

Topic

When using a Datagram Transport Layer Security (DTLS) Network Access tunnel, some client firewalls may time out the User Datagram Protocol (UDP) traffic flow.  This happens more frequently if there are dropped UDP packets. Link Control Protocol (LCP) sends Keep-Alive packets through the tunnel to prevent firewalls from seeing the session as being dead and terminating the connection. The LCP Keep-Alive packets are sent every 15 seconds by default in BIG-IP APM 10.x, and every 30 seconds by default in BIG-IP APM 11.x.  However, some firewalls might have a lower threshold than 15 seconds. To change the interval between Keep-Alive packets to 10 seconds, perform one of the following procedures, depending on your version:

Note: When determining how frequently to send Keep-Alive packets, try to use the longest interval of time between packets as possible. The shorter the interval is between the packets, the more traffic is sent. While this might not be a concern in all environments, F5 recommends that you minimize the number of packets sent. This configuration affects all DTLS Network Access users and may have an exponential impact.

  • Changing the LCP Keep-Alive interval in BIG-IP APM v11 using the Configuration utility
  • Changing the LCP Keep-Alive interval in BIG-IP APM v11 using the tmsh utility
  • Changing the LCP Keep-Alive interval in BIG-IP APM v10 using the bigpipe utility

Changing the LCP Keep-Alive interval in BIG-IP APM v11 using the Configuration utility

To change the LCP Keep-Alive interval to 10 seconds using the Configuration utility, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Navigate to Network > Tunnels > Profiles > PPP.
  3. Click ppp.
  4. In the LCP Echo Interval box, enter the value 10.
  5. To save the change, click Update.

Changing the LCP Keep-Alive interval in BIG-IP APM v11 using the tmsh utility

To change the LCP Keep-Alive interval to 10 seconds using the tmsh utility, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Modify the lcp-echo-interval to 10 by typing the following command:

    modify net tunnels ppp ppp lcp-echo-interval 10

  3. Save the change by typing the following command:

    save /sys config

Changing the LCP Keep-Alive interval in BIG-IP APM v10 using the bigpipe utility

The bigpipe utility must be used to change the LCP Keep-Alive interval in BIG-IP APM 10.x.  To change the LCP Keep-Alive interval to 10 seconds using the bigpipe utility, perform the following procedure:

Impact of procedure: This procedure requires that you restart the TMM process.  Traffic will be temporarily disrupted while the TMM process restarts.

  1. Log in to the command line.
  2. Type the following command:

    b profile ppp ppp lcp echo interval 10

  3. To save this configuration, type the following command:

    b save

  4. For the change to take effect, type the following command:

    bigstart restart tmm
