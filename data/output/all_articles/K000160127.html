K000160127: Unable to create UCS with error "Data Input Error: Invalid partition ID request, partition does not exist ([All])"

Type
Support Solution
Published
2026-02-24
Updated
2026-02-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000160127

Description

  • Users with resource admin role are unable to create UCS files.
  • When creating a UCS file, an error occurs:

    Data Input Error: Invalid partition ID request, partition does not exist ([All])
    Error during config save.
    Unexpected Error: UCS saving process failed.

Environment

  • Creating a UCS file
  • User with admin role
  • BIG-IP
  • Software Version: 16.1.5.2, 16.1.6, 16.1.6.1, 17.1.2.1, 17.1.2.2, 17.1.3, 17.1.3.1, 17.5.0, 17.5.1, 17.5.1.2, 17.5.1.3, 17.5.1.4

Cause

Bug ID 1854353

Answer/Recommended Actions

  • Workaround: Other admin type roles are able to save the UCS file.
  • At the time of creation of this article there is no fix available on public release, but an EHF with the fix can be provided.

Additional Information

None
