Issue

Error Message

0107131f:3: Could not allocate vCMP guest (<name>) because <reason>.

In this error message, note the following:

  • <name> is the name of the Virtual Clustered Multiprocessing (vCMP) guest instance.
  • <reason> is the reason for the core allocation failure.

For example:

0107131f:3: Could not allocate vCMP guest (example_guest) because fragmented resources
0107131f:3: Could not allocate vCMP guest (example_guest) because insufficient CPU cores

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following conditions are met:

  • You are attempting to deploy a vCMP guest instance.
  • You observe one of the following conditions:
    • There are not enough cores available.
    • There are not enough cores available on a single CPU socket1.
    • There are not enough contiguous hyperthreads available2.

1vCMP hosts with multiple socket CPUs must be able to allocate the number of Cores Per Guest, or Cores Per Slot for VIPRION systems, within a single CPU socket.
2vCMP hosts using hyperthreading must be able to allocate the number of Cores Per Guest, or Cores Per Slot for VIPRION systems, using contiguous hyperthreads.

Impact

You cannot deploy the vCMP guest with the current number of cores.

Recommended Actions

To resolve fragmented resource errors, refer to K41022663: Resolving vCMP fragmented resource errors.
