Description

This article provides a simple step-by-step procedure for updating or upgrading the BIG-IP system in a classic high-availability (HA) pair.

Use this procedure when you:

  • Need simple steps to update or upgrade a classic BIG-IP HA pair in an Active/Standby configuration without a lot of additional background documentation.

Note: In most cases, use the BIG-IP update and upgrade guide when performing updates or upgrades. The guide includes important details, such as how to choose an update or upgrade version, how to prepare your BIG-IP system, and how to perform an update or upgrade for your specific BIG-IP platform. For more information, refer to K84205182: Guide contents | BIG-IP update and upgrade guide.

Environment

  • Classic BIG-IP HA pair in an Active/Standby configuration

Recommended actions

Upgrade steps

  1. Disable Auto Sync if configured

    Note: The standby BIG-IP system may load an outdated configuration from disk and push it to the device group. For more information, refer to K000157180: License reactivation or upgrade on standby BIG-IP may trigger loading of old configuration .

    1. In the Configuration utility, go to Device Management > Device Groups, select the device group, and set Sync Type to Manual.
    2. On both BIG-IP systems, save the configuration to disk from the command line using the following command:

      tmsh save sys config

      or perform a ConfigSync between device group systems.

       

  2. Reactivate the license on both systems

    Note: Because this action can impact traffic, perform it during a maintenance window on a standby BIG-IP system. For more information, refer to K7752: Licensing the BIG-IP system .

    1. On the standby BIG-IP system, in the Configuration utility, go to System > License.
    2. Select Re-activate.
    3. Follow the wizard to reactivate the license. F5 recommends that you manually copy and paste both the dossier and the license.
    4. Force the active BIG-IP system to standby and repeat steps a – c on the former active system to reactivate its license.

  3. Upload the software ISO files and perform basic validation

    1. Download the required ISO file from F5 Downloads (my.f5.com/manage/s/downloads).

      Starting with BIG-IP 12.1.3 and 13.1.0, F5 switched to releasing hotfixes integrated with the base install.

      A hotfix ISO file includes all files needed to perform the update or upgrade. There is no need to download the base image ISO file if you already have a copy. Both the base version ISO and any engineering hotfix (EHF) ISO files must reside in the /shared/images directory on the BIG-IP system to complete the installation.

      Hotfixes are cumulative, so you only need to download the latest hotfix ISO file.

      The hotfix number is the last number in the software version: 0.0.0.x. For example, BIG-IP 13.1.0 with hotfix 2 is listed as 13.1.0.2 on the F5 Downloads page.

    2. Upload the ISO file to both BIG-IP systems:

      In the Configuration utility, go to System > Software Management > Image List.

    3. Create a UCS archive backup on both BIG-IP systems. For more information, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive .

    Note: From the command line, run the following command on both BIG-IP systems before the update or upgrade and again after the update or upgrade to verify the configuration: tmsh load sys config verify. Warnings are usually acceptable and often indicate changes between software versions. Investigate and resolve any errors before and after the update or upgrade.

  4. Update or upgrade the standby BIG-IP system

    1. Place the standby BIG-IP system in Force Offline mode.
    2. In the Configuration utility, go to System > Software Management > Image List.
    3. Select the ISO file to install and select Install.
    4. When prompted, select an available boot location from the list, or specify a new volume name. The system appends the name you specify to the storage device name to create the new volume.

      Example: If you select HD1 and enter 2 as the volume name, the system creates a new volume called HD1.2 and installs the image to that volume.

    5. Select Install to start the installation.
    6. Wait for the installation to complete.

  5. Restart the standby BIG-IP system

    1. In the Configuration utility, go to System > Software Management > Boot Locations.
    2. Open the boot volume where you installed the update or upgrade.
    3. Select Activate to restart to the new volume.
    4. A restart can take 15 minutes or longer depending on the hardware platform and configuration. If the system has not come back up after about 30 minutes, contact F5 Support for assistance.

    Note: During this phase, device status may show Disconnected. This is expected when the BIG-IP systems in the device group are running different software versions. The HA pair can still fail over successfully to allow you to update or upgrade the peer BIG-IP system.

    Note: You might see an Install Configuration option. You do not need to select this option because the configuration is copied automatically when you install the software. For more information, see K64400324: Should I use Install Configuration when activating a new Boot Location? .

  6. Verify the configuration on the standby BIG-IP system

    1. Log in to the upgraded standby BIG-IP system and verify that the configuration loaded correctly.
    2. Change the system from Force Offline (if still set) to its normal state. It should return to the Standby state.

  7. Fail over from the active to the standby BIG-IP system

    1. On the active BIG-IP system, in the Configuration utility, go to Device Management > Devices > <device name>.
    2. Scroll down and select Force to Standby.
    3. Verify that the former standby BIG-IP system (now active) is passing traffic.

  8. Update or upgrade the former active BIG-IP system

    1. On the former active (now standby) BIG-IP system, repeat steps 3, 4, and 5.

  9. Perform a ConfigSync

    1. On the BIG-IP system that has the latest, correct configuration, in the Configuration utility, go to Device Management > Overview.
    2. Perform a ConfigSync from that BIG-IP system to the device group.
    3. After both BIG-IP systems show that they are in sync, re-enable any automatic sync settings on both systems.

Additional information

If you encounter issues during this procedure, refer to K84554955: Overview of BIG-IP system software upgrades .
