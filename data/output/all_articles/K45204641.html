K45204641: LTM Authentication profile accepts empty certificate from client

Type
Support Solution
Published
2021-11-02
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K45204641

Description
The LTM Authentication profile ignores an empty Certificate message from a client.

LTM Authentication profiles allow requests to pass when the client does not provide a certificate.

Environment

  • BIG-IP LTM
  • Virtual server with:
    • Authentication profile
    • Client SSL profile with Client Certificate set to "ignore" or "request"

Cause
The Authentication profile does not force client certificate authentication at the SSL level, and so ignores requests where no client certificate is provided.

Recommended Actions
Impact of recommended actions: clients without a valid client SSL certificate will not be able to connect.

  1. Configure the client SSL profile to require a client certificate.

Additional Information
Client certificate authentication is controlled by the client SSL profile. The Authentication profile is only used to validate the certificate against a secondary source
