Description

Recent articles about WAF bypass using JSON-based SQL injection were published. BIG-IP ASM / Adv WAF Attack Signatures for JSON-based SQL Injection were released in March 2022 through Attack Signature update files.

 

Environment

BIG-IP ASM / Adv WAF licensed

BIG-IP ASM / Adv WAF Security Policy configured

Low Accuracy or SQL Injection Attack Signature Set applied to BIG-IP ASM / Adv WAF Security Policy
Update: Latest Attack Signature Update files have reclassified and improved these attack signatures. These are now in the Medium Accuracy Attack Signature sets. Please assign appropriate Attack Signature sets to your BIG-IP ASM / Adv WAF Security Policy.

 

Cause

JSON-based SQL injection formatted strings in HTTP request

 

Recommended Actions

The BIG-IP ASM / Adv WAF Attack Signatures for JSON-based SQL Injection were released through an Attack Signature update back in March 2022.

 

ASM-SignatureFile_20220315_113554.im

ASM-AttackSignatures_20220315_113554.im

 

Update to the latest Attack Signature Update file and apply the Low Accuracy or SQL Injection Attack Signature Set to your BIG-IP ASM / Adv WAF Security Policy to include the JSON-based SQL Injection attack signatures.

Update: Latest Attack Signature Update files have reclassified and improved these attack signatures. These are now in the Medium Accuracy Attack Signature sets. Please assign appropriate Attack Signature sets to your BIG-IP ASM / Adv WAF Security Policy.
