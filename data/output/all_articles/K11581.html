Known Issue

This is the result of a known issue. The BIG-IP system has specific requirements for combinations of profile types when defining a virtual server. For example, a virtual server that references a Client SSL profile also requires a TCP profile before it will process traffic. In addition, if a virtual server configuration contains a profile that requires another profile type, and the administrator does not explicitly define that profile, the BIG-IP system automatically adds the required profile to the virtual server definition. However, when defining a virtual server that references a Client SSL profile from the command line, the BIG-IP system fails to automatically add a TCP profile to the virtual server definition. If the BIG-IP administrator does not specifically include the TCP profile in the bigpipe or tmsh syntax, the BIG-IP system does not add the TCP profile and connections to the virtual server will fail.

For example, the following bigpipe command creates a Client SSL virtual server called vs_test:

bigpipe virtual vs_test { snat automap pool pool_test destination 10.10.0.1:443 ip protocol tcp profiles clientssl }

The command syntax does not specify a TCP profile for the virtual server; however, the BIG-IP system should recognize that a TCP profile is required and automatically add the profile to the configuration, resulting in the following virtual server definition:

virtual vs_test {
snat automap
pool pool_test
destination 10.10.0.1:https
ip protocol tcp
profiles
clientssl
tcp
}

If you run the above command in BIG-IP 10.1.0 and 10.2.0, the BIG-IP system fails to automatically add the TCP profile to the virtual server, resulting in the following virtual server definition:

virtual vs_test {
snat automap
pool pool_test
destination 10.10.0.1:https
ip protocol tcp
profiles
clientssl
}

F5 Product Development is tracking this issue as ID 226411 (formerly CR141434).

Resolution

You can work around this issue by modifying the virtual server and adding the TCP profile to the configuration.

For example, the following bigpipe command syntax modifies the Client SSL virtual server by adding the TCP profile:

bigpipe virtual <virtual_server> { profiles tcp add }
