Description

  • Unable to import ASM device to BIG-IQ
  • The following error message can be seen on BIG-IQ CM GUI

    Failed to copy configuration to working-config; reason: Failed copying from source subcollections to target subcollections: %s: java.lang.IllegalArgumentException: The dynamic signature mitigation (manual-multiplier) must be [none, low, medium, high].

Environment

  • BIG-IP ASM
  • BIG-IQ CM
  • Discover/import configuration

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 906853

Recommended Actions

Perform the workaround provided on Bug ID 906853 link

Additional Information

None.
