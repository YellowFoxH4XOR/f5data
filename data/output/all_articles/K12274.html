Known Issue

This is the result of a known issue. The find host command may display incorrect path information for shares in a presentation volume that have multiple attach points to managed volumes.

Note: For information about the find command, refer to the ARX CLI Reference Guide.

F5 Product Development tracked this issue as ID 339676 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.

This issue was fixed in hotfix versions 5.0.6 HF15 (build 11783) and 5.1.7 HF2 (build 12061). Customers affected by this issue can request these hotfixes or a later version of the hotfixes from F5 Technical Support by referencing ID 339676 and this Solution.
