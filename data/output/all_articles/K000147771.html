K000147771: How to set up a custom error page on F5® Distributed Cloud Services

Description

To keep the look and feel of your website, you can set up a custom error page that F5® Distributed Cloud Services will display when your origin server is unavailable.

Environment

  • F5® Distributed Cloud load-balancer

Procedure

  1. Access F5® Distributed Cloud Console
  2. Go to the Multi-Cloud App Connect or Web App & API Protection Workspace tab. 
  3. Select the proper namespace, then find the section Manage > Load Balancers > HTTP Load Balancers.
  4. Select the Load Balancer, click the Actions button, and select Manage Configuration > Edit Configuration.
  5. Scroll down to the Other Settings and navigate to More Options and click Configure.
  6. Scroll down again until you find the Configure Error Response Options
  7. Click Configure, and then Add Item.
  8. Each Custom Error Reponse contains the following elements to configure:
    1. Error Code: Enter the expected HTTP Status Codes with a value between 300 and 599 (classes 3xx, 4xx, and 5xx) with one of the following formats:
      1. Status Code Classes: Values 3, 4, and 5 as representing a complete code class, respectively. For example, value 4 covers the class 4xx or all 400-499 error codes, and value 5 represents the class 5xx or all 500-599 error codes.
      2. Specific Status Code: You can also specify an exact error code like, for example, 404 or 503.
        Note: Consider that a specific response code takes preference when both the response code and response code class match for a request.
    2. Error Response Body: A string representing the error response to be used for each error code, it can be added in either of the following formats:
      1. ASCII: Use the ASCII option when you are pasting ordinary text or raw HTML.
      2. Base64: Use the Base64 option only when the content has already been Base64 encoded. Pasting ordinary HTML in this field can cause unexpected issues.
        Note: Each error page needs an HTML body between 0 and 48kB long, pasting something longer won't allow you to save the setting.
  9. Repeat steps 7 and 8 as needed.
  10. Select Apply, Apply and then Save HTTP Load Balancer.

Note: You can add {{request_id}} placeholder in the custom blocking page to include the request identifier.
