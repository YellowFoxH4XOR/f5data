K000138896: [F5OS] Maximum number of configurable administrative partitions inside tenant.

Type
Support Solution
Published
2024-03-13
Updated
2024-03-13
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000138896

Description

Customer would like to know the maximum number of administrative partitions which is allowed to be configured for each F5OS tenant.

Environment

  • F5OS tenant with any software version
  • Administrative partitions

Cause

Customer is concerned about the number of configurable administrative partitions for each F5OS tenant.

Recommended Actions

On tenant level, it acks the same as traditional TMOS which does not have a fixed maximum number of administrative partitions.

Additional Information

None.
