Topic

You should consider using this procedure under the following condition:

  • You want to add legitimate host names to a security policy.

Description

You can configure a security policy to allow legitimate host names. Doing so can help protect your application from common host header attacks, such as web cache poisoning, routing-based SSRF and other server-side vulnerabilities. You can configure the policy to alarm or block requests that do not contain the defined host names.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have access to the Configuration utility.
  • You have defined a list of host names or IP addresses that are used to access the web application.

Procedures

Add legitimate host names to a security policy

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

Versions 17.x and later

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Policies List.
  3. Select the name of the security policy.
  4. Go to HTTP Message Protection > Headers.
  5. In the Host Name box, enter a domain name or IP address.
  6. Select Include Sub-domains if you want to include all sub-domains of the specified host name.
  7. Select Save.
  8. Select Apply Policy to put the changes into effect.
  9. To change the blocking settings for illegal host name violations, go to Security > Application Security > Policy Building > Learning and Blocking Settings > Headers, and set the value for Illegal host name.

Versions 13.x - 16.x

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Headers > Host Names.
  3. In the Current edited security policy list, select the name of the policy you want to modify.
  4. Select Create.
  5. In the Host Name box, enter a domain name or IP address.
  6. For Include Sub-domains, select the Enabled check box if you want to include all sub-domains of the specified host name.
  7. Select Create.
  8. Select Apply Policy to put the changes into effect.
  9. To change the blocking settings for illegal host name violations, go to Security > Application Security > Policy Building > Learning and Blocking Settings > Headers, and set the value for Illegal host name.
