K000141237: The management interface status on a Tenant does not match with the F5OS

Type
Support Solution
Published
2024-09-29
Updated
2025-09-30
Source

Description

When MGMT interface is down due to some reason, F5OS shows the MGMT status correctly as "DOWN" while tenant still shows it as "UP"

Environment

  • F5OS-A
  • MGMT port is down

Cause

This is an expected behavior.

The tenant MGMT port is defined using CNI plugin type macvlan, which is a bridged virtual interface.

Since it's just a virtual interface, it is expected to stay UP when the physical interface MGMT on F5OS goes down.
