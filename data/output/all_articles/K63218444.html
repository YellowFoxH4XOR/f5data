Description

Request with illegal parameter is marked by ASM as legal when the parameter in question configured in staging.

Environment

  • ASM
  • Allowed parameter
  • Staging

Cause

Staging is used so that you can learn the violation. While the parameter is in staging all parameter violations won't actually be blocked. Instead they will be marked as "Violations Found for Staged Entities" and will be considered "legal" requests. Once you remove staging for the parameter then any parameter violations for that parameter will be considered "illegal".

Recommended Actions

 If you want the violation to be considered illegal but not get blocked then you will have to remove staging and change the violation itself to not block.
