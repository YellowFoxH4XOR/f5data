K000161806: F5OS-A rSeries: uploaded images persist after "system database reset-to-default" factory reset

Type
Knowledge
Published
2026-06-19
Updated
2026-06-19
Applies to
  • F5OS
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000161806

Description

When executing the system database reset-to-default command on an F5OS-A rSeries appliance, uploaded F5OS host images and tenant bundle images (.tar.bundle) are not removed from the system. The appliance continues to boot from the previously active F5OS image rather than reverting to the original factory-installed image. This behavior may be unexpected, as the reset procedure name implies a full return to factory state.

Environment

  • F5OS-A on rSeries platform
  • Reset method: system database reset-to-default
  • Uploaded F5OS host images and tenant bundle images (.tar.bundle) present prior to reset

Cause

The system database reset-to-default command resets only system configurations and settings (ConfD configuration data). It does not perform a full filesystem wipe and therefore does not remove uploaded image files stored on the system.

Answer/Recommended Actions

Reset methods and their impact on uploaded images:

  • system database reset-to-default:
    • Clears system configuration and settings only.
    • Does not remove uploaded F5OS host images or tenant bundle images.
    • The appliance will continue to boot from the previously active image.
    • Use this method when a configuration reset is needed but image files should be preserved.
  • Partial reset (rm -f /var/F5/system/cdb/*.cdb):
    • Deletes only the ConfD configuration data stores.
    • Tenant virtual disks and uploaded image files in /var/F5/system/IMAGES/ are not removed.
    • Note: This is not a supported reset method.
  • Clean installation of F5OS-A:
    • Wipes all user-uploaded content, including all images.
    • Use this method when a completely clean environment is required.
    • Refer to the official F5OS-A installation and upgrade documentation for procedure details.

Before performing any reset, ensure the following prerequisites are completed:

  1. Back up the F5OS configuration:

    appliance-1(config)# system database config-backup name <backup-filename>

    Export the backup file to a remote location.
  2. Set the primary key to a known value:

    appliance-1(config)# system aaa primary-key set passphrase

  3. Back up each tenant's BIG-IP configuration using a UCS archive from within each tenant.
  4. Save all tenant bundle images to an external location if they may be needed after a clean installation.
  5. Record your license Registration Key and any add-on keys, as the license file is not included in the ConfD backup.

Additional Information

  • The system database reset-to-default procedure does not revert the F5OS version to the original factory-installed version. It only clears system settings and configurations. Uploaded images (both F5OS host images and tenant bundle images) remain intact after this operation.
  • For F5OS-A 1.8.3 and newer, use the .tar.bundle format for tenant images. The .qcow2.zip.bundle format is deprecated.
  • F5OS configuration backups record the initial deployment image, not the currently running tenant version. If tenants were upgraded after initial deployment, the image reference in the backup may need to be manually updated before restoring.
