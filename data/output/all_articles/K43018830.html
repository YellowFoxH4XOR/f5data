K43018830: GUI disconnects when accessing ZoneRunner menu

Type

Published

Applies to

Source

Description
When the ZoneRunner menu is opened with a large number of config objects (observed with 5,000 zones with a total of 5,000,000 records), the GUI disconnects for several minutes and services may restart.

This is only observed with a very large number of DNS records.

Environment

  • BIG-IP DNS provisioned
  • ZoneRunner accessed
  • Very large number of DNS records configured in BIND

Cause
ZoneRunner is not designed or optimized as a management tool for large-scale DNS deployments.

Recommended Actions
F5 recommends the following if BIG-IP is to be used as an authoritative DNS server:

  • Use purpose-made DNS management software appropriate for your environment to configure a primary authoritative DNS server 
  • Configure BIG-IP as a secondary DNS server using DNS Express, which offers better scalability and performance than BIND on BIG-IP
