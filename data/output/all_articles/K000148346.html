Description

Unbound HTTP::collect may stall connections.

  • Stalled connection may stay in connection table until idle timeout or client terminates connection

Environment

  • iRule using HTTP::collect without specifying the length of data to be collected
  • HTTP request data is very small
  • iRule attached to a virtual server with an attached HTTP profile

Cause

HTTP::collect without specifying request data length will wait until maximum allowable length of data which can be collected. The maximum length varies depending on BIG-IP version as stated in article K13387

Recommended Actions

Ensure to set the length of request data to be collected. For requests with very small amounts of data use the request's Content-Length header value.

Additional Information

Using the request's Content-Length header value. Should be used with caution as this suits requests which are not very large.

when HTTP_REQUEST { HTTP::collect [HTTP::header value Content-Length] }
