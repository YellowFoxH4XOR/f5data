Description
With a significant increase in the number of remote workers (for example COVID-19), you may find yourself seeing an increase in the number of SSL VPN connections as well as CPU usage.  This article covers techniques from the F5 Sales and Support organizations to help mitigate this issue.

Environment

  • BIG-IP APM
    • Network Access (SSLVPN)
  • High CPU load

Cause
Significant increases in the number of remote workers that are leveraging the SSL VPN component of APM resulting in higher than normal resource use.

Recommended Actions

The following techniques have been known to help optimize the resources used by VPN connections:

  1. Disabling Compression in Network Access profile AND Connectivity profile.
    K19681382: How to disable compression in BIG-IP APM Network Access
    K12524516: APM Network Access (VPN) compression causes CPU usage higher

  2. Make sure TLS Ciphers are hardware accelerated: 
    K13213: SSL algorithms that are hardware accelerated (11.x - 14.x)

  3. Optimize / Reduce ACLs as much as possible

  4. Ensure your use of Lease pools and SNAT have enough IPs for your increased concurrent users.  When using SNAT make sure you have no more than 10 users per SNAT IP address (ratio of 10:1): K63118490 : Overview of BIG-IP APM Network Access Lease Pools

  5. Disable Connection Mirroring on Virtual Server(s)

  6. Limit the number of connections per user.  K23402746: Limiting the number of connections an APM user can make to an Access policy

  7. Enabling Split Tunneling
    Warning: This is not recommended for security reasons, but in such situation where there is a significant spike in remote users (such as COVID-19), this can help reduce load significantly.

    1. You can see non-business related traffic like streaming or social media Web traffic passing through the tunnel

    2. You can either include or exclude addresses spaces

      1. Included internal network like *.<yourdomain>.com

      2. Exclude SaaS apps (such as Office 365)

  8. Enabling Traffic Shaping for upload traffic on Network Access Client

    1. Manual Chapter : Shaping Traffic on the Network Access Client

    2. Windows only

  9. Enabling Bandwidth Controller

    1. Manual Chapter : Managing Traffic with Bandwidth Controllers
      This is an easy and effective however, this has not been tested thoroughly with v14 or v15.

    2. We typically would recommend 1Mbps per user. However, be careful, as Zoom Video has been known to consume 2Mbps per user.

  10. Scale out - transform an active/passive APM cluster into a active - active standalone solution.

    1. Active / Active not supported on APM

    2. Separate the cluster in 2 standalone devices
