Description

The diskmonitor utility is not logging disk space errors in /var/log/ltm.

Expected log messages are not seen, for example:

err diskmonitor[21018]: 011d0004:3: Disk partition /var/lib/mysql has only 3% free

Using the logger command also does not produce a log message in /var/log/ltm.

The journalctl command does not work as expected:

Error was encountered while opening journal files: Input/output error

Environment

  • Logging
  • Disk space

Cause

The systemd-journald process is in a problematic state.

Recommended Actions

Restart systemd-journald:

systemctl restart systemd-journald

Note: There is no impact to traffic, but logging will be briefly interrupted.

Additional Information

From version 14 onwards, the systemd-journald process listens to the /dev/log socket, and feeds log messages to syslog-ng, which ultimately writes them to /var/log/ltm. It is likely that other logs will also go missing if systemd-journald is not working properly, not just those originating from diskmonitor.
