K92845549: Upgrade image on one-slot cloud instances fails to register on Big IP after upload

Description

This article specifically covers the situation in which one is attempting to upgrade a one-slot instance in the public cloud - but, upon upload of image, it simply does not show up as available:

  • When uploading through the web UI, the image simply does not appear on the list.
  • When using sftp to upload to /shared/images, the image may arrive - but it will not show as available.
  • Any attempt to upgrade simply receives a response that states the attempt to upgrade is impossible. 
Environment
  • Big IP VE in public cloud (e.g., AWS, Azure, etc.) for any version

Cause

This is expected behavior.  In any cloud environment that provides them, the one-slot instances cannot be upgraded directly.  In such instances, the overall disk space is significantly reduced and cannot be increased.  
 

Recommended Actions

The only thing you can do to upgrade is to move off of the old instance. 
  1. Create a new instance; ensure it is on the same version as the current instance, and do not use a one-slot instance; license as need be.  
  2. Create a UCS file on the old instance, and download - see K13132 for related instructions.
  3. When it is ready, upload the UCS file to the new instance and install it. 
  4. Cut over to the new instance.


Additional Information

For best results, use a one-slot instance only in conditions where you are fully certain that you will not need to upgrade - for example, a test environment.  These are best used for testing, especially such where you need to worry about affecting production traffic in some way.  Never use a one-slot instance for production.
