Issue

Old Behavior

In versions prior to BIG-IP GTM 11.4.0, the bigip_add and gtm_add scripts cannot accept a username. Therefore, you cannot use them to add devices in Appliance mode. This issue occurs because root user access to the Advanced Shell (bash) is disabled for systems licensed for Appliance mode.

The bigip_add script is an interactive script that logs in to the bash shell of a remote BIG-IP LTM system and exchanges SSL device certificates between the systems.

The gtm_add script is an interactive script that logs in to the bash shell of a remote BIG-IP GTM system and exchanges SSL device certificates between the systems. The script integrates a new BIG-IP GTM system into an existing synchronization group that has one or more remote BIG-IP GTM systems.

New Behavior

Beginning in BIG-IP GTM 11.4.0, the bigip_add and gtm_add scripts accept a username when connecting to BIG-IP LTM and BIG-IP GTM systems, which enables the scripts to add devices in Appliance mode. You can run the scripts from the command line or from the Traffic Management Shell (tmsh).

F5 Product Development tracked this change as ID 342508.

Adding a BIG-IP LTM system running in Appliance mode to a BIG-IP GTM system

  1. Log in to tmsh by typing the following command:

    tmsh

  2. From tmsh of the BIG-IP GTM system, use the following command syntax:

    run gtm bigip_add -a <username>@<ip_addr>

    In this command, note the following:

    • <username> is a user on the remote BIG-IP LTM system with the resource administrator or administrator role with tmsh access enabled.
    • <ip_addr> is the IP address of the BIG-IP GTM system that you want to add.

Adding a new BIG-IP GTM system to an existing BIG-IP GTM system running in Appliance mode

  1. Log in to tmsh utility by typing the following command:

    tmsh

  2. From tmsh of the local BIG-IP GTM system, use the following command syntax:

    run gtm gtm_add -a <username>@<ip_addr>

    In this command, note the following:

    • <username> is a user on the remote BIG-IP GTM device with the resource administrator or administrator role and with tmsh access enabled.
    • <ip_addr> is the IP address of the BIG-IP GTM system that you want to join.
