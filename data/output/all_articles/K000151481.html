Description

In some cases if possible you may need to remove the ASM policy from virtual server for troubleshooting purpose to ruleout ASM policy related issue

Environment

ASM

Cause

N/A

Recommended Actions

To remove the ASM policy go to Local Traffic  ››  Virtual Servers : Virtual Server List

 

Set the Application Security Policy to Disabled and Click update .

After disabling the policy, test the application to ensure it is working as expected.

Once testing is complete, re-associate the ASM policy:

  • Set the Application Security Policy option to Enabled.
  • Select the appropriate security policy from the list.
  • Click Update to apply the changes.
