Description

The "Add" button, to add Central Manager High Availability (CM HA) instances, does not appear in "CM Setup" for Central Manager.

Environment

BIG-IP Central Manager from version 20.2.0

Cause

Once the CM cluster is installed, Central Manager cannot join an HA cluster or or add members.

Recommended Actions

The "Add" button only exists if the Central Manager (CM) Setup is being run for the first time. There are two phases to setting up CM. First the IP address, NTP and DNS server must be configured. This can be done by DHCP or manually via the setup script. The second phase is the actual "CM Setup" when the Kubernetes cluster is setup.

In other words, the "CM Setup" is manually initiated after basic IP addressing has been done.

For static IP addressing, the console "setup" script is used to configure this on Central Manager. The administrator must say no, after the first phase (IP, NTP, DNS) is done:

Would you like to start the BIG-IP Next Central Manager application installation (Y/n) [Y]: n

If the CM has been issued an IP address via DHCP, no interaction is required with the console or "setup" script. The administrator can login directly to the CM web UI and access the "CM Setup".

All three CMs need to be in exactly the same state. Ready with IP, NTP and DNS setup, but have not had the CM application installation part performed.

Important! Doing anything outside of setting up the IP addressing may invalidate the availability of the CM Setup button. This includes generating a qkview.
