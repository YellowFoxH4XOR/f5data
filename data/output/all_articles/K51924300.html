Description
BIG-IP Device reboots without core file and the following messages are recorded in /var/log/ltm:

<Date> <hostname> info chmand[7953]: 012a0006:6: MCP initial connection not ready.
<Date> <hostname> info chmand[7953]: 012a0006:6: Latched Event:0x7: Host was reset by platform reset event
<Date> <hostname> info chmand[7953]: 012a0006:6: Latched Event:0xf: Host was power cycled by the PCH power down event
<Date> <hostname> info chmand[7953]: 012a0006:6: Latched Event:0x26: Main board +12V voltage event
<Date> <hostname> info promptstatusd[3317]: 01460007:6: semaphore chmand.running(1) released

Environment

  • BIG-IP
  • Reboot 
  • No core file
  • Error Messsage : Latched Event:0xf: Host was power cycled by the PCH power down event

Cause
Messages indicate that the device was shut down via the LCD panel or there was a power disruption.

Recommended Actions

  1. Run End User Diagnostics test K7172: Overview of the End User Diagnostics software
  2. Verify power source is good.

None
