Known Issue

This is the result of a known issue. The standby member of a BIG-IP redundant pair configured to use the Open Shortest Path First (OSPF) feature of the BIG-IP Advanced Routing Module may incorrectly advertise redistributed routes. When the system or the tmrouted process is restarted, the ZebOS OSPF router loads its configuration and broadcasts OSPF v2 link external LSAs, advertising its redistributed routes, even if it is the standby BIG-IP system. This causes neighboring OSPF routers to see the standby BIG-IP system as a valid nexthop to the redistributed routes. If Equal Cost Multipath (ECMP) routing is configured on the other OSPF routers, traffic may then be directed to the standby BIG-IP system, which drops the traffic.

Note: Only routers with the maximum-paths configured to more than 1 (one) will be affected.

Note: Route Health Injection (RHI) routes are not affected, as the standby units do not advertise them.

F5 Product Development tracked this issue as CR111105 and it was fixed in BIG-IP 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, PSM, or WebAccelerator Release Notes.

Additionally, this issue has been fixed in Hotfix-BIG-IP-9.4.5-HF2, which was issued for BIG-IP 9.4.5 and in Hotfix-BIGIP-v9.6.1-HF2, which was issued for BIG-IP 9.6.1. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix and point release matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about managing F5 product hotfixes, refer to K6845: Managing BIG-IP product hotfixes (9.x).

Workaround

You can work around this issue permanently by ensuring the BIG-IP system's OSPF neighbors are configured with ECMP OSPF routing disabled and maximum-paths set to a maximum of 1.

You can work around this issue temporarily by manually failing over the BIG-IP pair, which forces the standby unit to broadcast another LSA update for the same entry with Maxage, flushing out the spurious entry from the neighboring routers.
