Description

Experiencing the "Error has occurred" message in BIG-IP DNS V14.1.4.5

Environment

  • BIG-IP DNS V14.1.4.5
  • catalina.log contains messages similar to following
                 web.FormHandler:doAllowedCharactersCheck - error occurred while parsing value /tmui/globallb/wideip/pools.jsp
  • Run the following steps to reproduce it :
  1. Create GTM POOL, "A"
  2. Add a member to the pool.
  3. Click Manage, try to add a member to the pool.
  4. Results in "An error has occurred while trying to process your request."

Cause

The device has hit a known issue: Bug ID 741862: DNS GUI may generate error or display names with special characters incorrectly.

Recommended Actions

One of the following actions will address this issue.

  1. Make required changes via TMSH
  2. Upgrade to the fixed software version of ID741862

Additional Information

To be more explicit, the conditions should be:

  • The DNS object name may be displayed incorrectly if it contains a special character such as: # &

       OR

  • An error can occur on BIG-IP versions prior to 15.0.0 that contain the fix for ID1045421 (such as Engineering Hotfixes on versions 14.1.x or 13.1.x with a fix for ID1045421), and especially, 14.1.4.5 is affected, which has fixed ID1045421, but not fixed ID741862.
