K000151948: Failure to add a remark in an AS3 declaration to an existing pool member

Published

Source

Description

 
When attempting to add or update a `remark` (or `description`) field for an existing pool member using an AS3 (Application Services 3 Extension) declaration, the operation fails with a 422 error. The error message includes:
01020066:3: The requested Pool Member (<pool member details>) already exists in partition <partition name>.
This issue occurs even though adding a remark at the pool level is successful; the problem is specific to pool members.

Environment

  • Product: BIG-IP LTM

  • Version: 17.1.2
  • AS3 schemaVersion: 3.54.0-6 (and earlier/later as tested)
  • Configuration: Attempting to use the `remark` or `description` field within the `members` array of a Pool object in an AS3 declaration.

Cause

AS3 does not currently support adding or updating the `remark` (or `description`) field for individual pool members. When a declaration attempts to modify this field for an existing pool member, AS3 interprets this as an attempt to create a duplicate pool member, resulting in a 422 error and the message that the pool member already exists.

Recommended Actions

  • Current Limitation: Adding or updating the `remark` or `description` field for pool members via AS3 is not supported in the affected versions.
    • You can add a `remark` or `description` at the pool level, which is supported and does not trigger the error.
    • If you need to annotate individual pool members, consider using alternative documentation or tracking methods outside of AS3 until this feature is supported.
  • Resolution Plan:
    • This issue is tracked under internal ID: 1962105 / AUTOTOOL-4718.
    • A fix is planned for a future AS3 release (tentatively August 2025). Monitor release notes for updates on this feature.
