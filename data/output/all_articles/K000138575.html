Description

The BGP best route selected for the network xx.xx.xx.xx/xx is selected with Metric xx instead of Metric 0
 

Environment

  • BGP

Cause

Configuration is required to apply RFC1771.

Recommended Actions

To change this behavior, one needs to tell the BIG-IP do perform path selection per RFC1771 (or in other words, to start using MED). This is done via below commands:
 

 imish
 en
 conf t
 bgp rfc1771-path-select
 wr
 end
 

Note: Bear in mind this won't apply to existing routes (routes already learned and in the routing table). It will only apply to new routes being learned after the new config is applied.
