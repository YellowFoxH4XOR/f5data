Known Issue

The Traffic Management Microkernel (TMM) process may exit and produce a core file during shutdown.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured as a Virtual Clustered Multiprocessing (vCMP) guest.
  • The BIG-IP versions on the hypervisor and the guest are different.

Impact

There is no impact to traffic processing. The TMM process restarts after the shutdown.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system logs an error message to the /var/log/tmm file that appears similar to the following example:

    notice ** SIGSEGV **
    <snip>
    notice RIP=0x41e629
