Topic

You should consider using this procedure under the following condition:

  • You want to use telnet to manually test mail server transactions and view the SMTP server response.

Description

When crafting an iRule or health check for an SNMP server, it can be useful to manually test email transactions and view the SMTP server responses from the mail server. One way to analyze the SMTP information exchanged for various mail server transactions is to use telnet to connect to a mail server and send a test email.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You must have command line access to the BIG-IP system.
  • The BIG-IP system must be able to access a functioning SMTP mail server.

Procedures

Establishing a connection and viewing SMTP responses

To use telnet to connect to an SMTP server and send a test email, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: The following procedure has you perform the minimum options required to send a test SMTP email message. Refer to the Supplemental section for additional SMTP commands available while you have a telnet session established to the SMTP server. Additionally, you can use the HELP SMTP command to view details about SMTP command options.

  1. Log in to the BIG-IP command line.
  2. Establish a telnet session to the mail server on the appropriate port using the following command syntax:

    telnet <mail_server> <port>

    In this command, note the following:
    • <mail_server> is replaced by the host name or IP address of the mail server
    • <port> is the port the mail server is listening on (the default for SMTP is port 25)

    For example, to connect to a mail server named mail.askf5.com on port 25, you would type the following command:

    telnet mail.askf5.com 25

    The mail server should respond with its SMTP header and response code information that appears similar to the following example:

    # telnet mail.askf5.com 25
    Trying 10.90.100.60...
    Connected to mail.askf5.com.
    Escape character is '^]'.
    220-
  3. Specify your user name using the following command syntax:

    HELO <name>

    For example, to connect as a user named test, type the following command:

    HELO test

    The output should appear similar to the following example:

    250 mail.askf5.com Hello askf5.askf5.com [10.90.100.60]
  4. Specify the email address to be used as the sender of the test email, using the following command syntax:

    MAIL FROM:<sender>

    For example, to send a test email from user test@askf5.com, type the following command:

    MAIL FROM:test@askf5.com

    The output should appear similar to the following example:

    250 <test@askf5.com> is syntactically correct
  5. Specify the email address to be used as the recipient of the test email, using the following command syntax:

    RCPT TO:<recipient>

    For example, to send a test email to user recipient@askf5.com, type the following command:

    RCPT TO:recipient@askf5.com

    The output should appear similar to the following example:

    250 <recipient@askf5.com>... Recipient ok
  6. To enter text to be used as the message body, enter DATA mode by typing the following command:

    DATA

    The output should appear similar to the following example:

    354 Enter mail, end with "." on a line by itself.
  7. Enter the desired message body text, and exit DATA mode and send the test email by placing a period ( . ) on a line by itself.

    For example, to enter a message body of test, test and then exit and send the test email, type the following:

    test, test
    .

    You should receive the following message, indicating that the mail server has accepted the test email message:

    250 Message accepted for delivery

    Note: This message does not guarantee that the mail will be delivered successfully.

  8. To close the connection with the SMTP mail server, type the following command:

    QUIT

    You should receive a message similar to the following example:

    221 mail.askf5.com closing connection Connection closed by foreign host.
