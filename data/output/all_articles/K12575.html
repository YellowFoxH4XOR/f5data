Known Issue

When a user launches a Citrix XenApp application through the BIG-IP APM system, the application may experience significant delays in starting.

The Citrix XenApp client is unable to resolve the IP address of the Citrix XenApp server through the BIG-IP APM proxy.

Note: For more information about configuring the BIG-IP APM for use with Citrix XenApp, refer to the Deploying BIG-IP Access Policy Manager with Citrix XenApp guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

F5 Product Development tracked this issue as ID 340928 and was fixed in BIG-IP 10.2.2. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP APM 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
