K4143: Recovering the BIG-IP LTM if the upgrade to version 9.x fails and the BIG-IP LTM no longer boots successfully

Topic

In rare cases, the upgrade to BIG-IP LTM version 9.x can fail and leave the BIG-IP LTM in an inoperable state. If this occurs, perform the following procedure to recover the system:

Important: If the BIG-IP LTM boots, but does not successfully convert and load the 4.x configuration, refer to K4145: Recovering the configuration if the one-time conversion utility (OTCU) does not properly convert it.

  1. Perform a clean installation by performing the procedure provided in the BIG-IP LTM release notes.
  2. After you install the software, load the backup .ucs file.

    Note: For more information about copying files to BIG-IP, refer to K175: Transferring files to or from an F5 system.

  3. Copy the .ucs file to the / directory and name it otcu.ucs by using the following command syntax:

    cp <filename>.ucs /otcu.ucs

    Replace <filename> with the name of your backup .ucs file.

  4. Run the one-time conversion utility (OTCU) by performing the procedure provided in the BIG-IP LTM release notes.

Your system should now be running BIG-IP LTM version 9.x with a properly converted configuration.
