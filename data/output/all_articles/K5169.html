Known Issue

This is most likely the result of a known issue. If your SSL proxy is configured to use a remote target server, rather than a target virtual server configured on the BIG-IP, 3-DNS will mark the SSL proxy with a blue sphere, indicating that the status of the SSL proxy is unknown. The SSL proxy is marked unknown even if a health check is configured for the remote target server.

F5 Networks Product Development tracked this issue as CR30139.
