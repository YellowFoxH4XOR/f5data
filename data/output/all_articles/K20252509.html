Description

vCMP stays in INOPERATIVE state and keeps (loop) rebooting.
An error message similar to the following is displayed:
clusterd[32085]: 013a0006:5: Waiting for lind to send software status info.
01810004:3: inotify_add_watch (/var/tmstat/cluster) (2, No such file or directory)
/usr/bin/overdog  ==> /usr/bin/bigstart restart

Environment

  • vCMP Guest
  • HA

Recommended Actions

  1. Rebuild the vCMP guest and restore the guest configuration from a UCS archive.
  2. Once restored synchronize the configuration from its peer.
