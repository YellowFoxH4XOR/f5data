Environment

  • BIG-IQ CM
  • Device not starting after upgrade or restart
  • tokumond restart loop
  • Managend APM devices

Cause

Huge number of events in dma dowloads task cause memory issue during indexation

Recommended Actions

The workaround to overcome the issue is to skip table by adding into blacklist /usr/share/rest/tokumon/config/black-list-tables.js

  1. Mount /usr in read write mode:
    • mount -o remount,rw /usr
  2. Modify /usr/share/rest/tokumon/config/black-list-tables.js using text editor
    • vi /usr/share/rest/tokumon/config/black-list-tables.js
  3. Add highlighted text to list of excluded tables

"use strict";
//more tables are blacklisted based on url pattern found in kindtablename. These are a subset
exports.BLACK_LIST_TABLES = [
"counter_table",
"asm_wc_policies_signatures",
"system_authn_providers_ldap_users_ui_preferences",
"system_authn_providers_radius_users_ui_preferences",
"system_authn_providers_tacplus_users_ui_preferences",
"shared_authz_users_ui_preferences",
"tasks_dma_download_files"
];

Note: Remember to  add "," in the line above  tasks_dma_download_files

Note: The following change will not survive an upgrade. If you upgrade the device you will need to perform them again.
