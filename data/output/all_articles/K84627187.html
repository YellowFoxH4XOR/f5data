Description

  • The Portal Access Home Tab is showing even though it is disabled in Portal Access Resource Item

Environment

  • BIG-IP with APM provisioned
  • Portal Access resource configured
  • Optional: Portal Access Webtop

Cause

Portal Access can be provided by either using a Portal Access resource published on a full Webtop or via a Webtop of type "Portal Access".
In the case of a "Portal Access" Webtop, the Portal Access Start URI is configured in the Webtop properties. Optionally a Portal Access resource can also be assigned to the user in addition to the "Portal Access" Webtop. This allows for Portal Access Resource Items to be configured to control properties such  as SSO and Home Tab. The "Destination", "Paths", "Scheme" and "Port" values in the Portal Access Resource Items has to match the requests in order for the properties to be applied.

Recommended Actions

  1. If the Portal Access Home Tab behavior is not what is expected please check that the user has a Portal Access resource assigned and the settings in the Portal Access Resource Items match the request URL.
