Known Issue

The maximum allowable length for an HTTP header string is 253 characters. The following error indicates that you have exceeded this limit.

Error 331903

F5 Networks Product Development tracked this error message issue as CR29801, CR33223, CR41848, and CR41942. Starting in BIG-IP version 4.6.3, the following, more descriptive, error is provided:

Error 336097 -- HTTP Header to Insert cannot exceed 253 characters.

The error message was not changed for the 4.5 software branch.
