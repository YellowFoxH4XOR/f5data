K52753876: iRule isn't always triggerred when the Connection Rate Limit is reached

Description
The iRule isn't always triggered when the Connection Rate Limit is reached. The BIG-IP sometimes sends TCP RST.

Environment

  • You are using Connection Rate Limit.
  • An iRule is attached to the virtual server.
  • The Connection Rate Limit is reached.
  • The BIG-IP sometimes sends TCP RST, and the iRule is triggered at other times.

Cause
The expected behavior is that the BIG-IP sends TCP RST when the Connection Rate Limit is reached. However, because of a current limitation, the BIG-IP sometimes triggers the iRule.

Recommended Actions

You may be able to use Connection Limit instead of Connection Rate Limit. In that case, the BIG-IP always triggers the iRule when the Connection Limit is reached.
