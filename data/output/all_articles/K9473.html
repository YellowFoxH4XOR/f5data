K9473: Active Directory authentication and dynamic group mapping may fail if nested groups are enabled and the user's primary group contains a space character

Known Issue

This is the result of a known issue. If you configure Active Directory authentication for a master group and enable nested groups, authentication may fail even if the user belongs to the required Active Directory group through nested groups. Similarly, if you configure the Active Directory dynamic group mapping method and enable nested groups, mapping may fail even if the user belongs to the required Active Directory group through nested groups.

This issue occurs if both of the following two conditions are met:

  • The user’s primary group in Active Directory contains a space character (for example, Domain Users)
  • The group that the user must belong to is nested through the user’s primary group

Note: FirePass support for nested groups was introduced in FirePass version 6.0.3. For more information, refer to K9472: Change in Behavior: Active Directory authentication and dynamic group mapping now support nested groups.

F5 Product Development tracked this issue as CR109030 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads page.
