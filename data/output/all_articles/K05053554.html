Description

This article explains the steps to enable debug logging for Safenet Luna HSM client in BIG-IP. This Software Client installed in BIG-IP is used to communicate with Network HSM device to perform routine cert/key operations which includes generating of key, saving the key, downloading the key during SSL negotiations and more.


Environment

  • PKCS.
  • Safenet Luna Network HSM.
  • Safenet Luna Client.
  • Cert/Key
  • SSL

Cause

Enabling Luna Client debug logging displays the internal communication status and error codes generated during BIG-IP and Network HSM communication which can help to isolate the problem. F5 support can request to enable client debug logging during troubleshooting issues related to Network HSM. 

Specific BIG-IP versions support specific Safenet HSM Appliance Software version, Firmware Version and Luna Client version as per the compatibility matrix.
https://techdocs.f5.com/kb/en-us/products/big-ip_ltm/manuals/product/f5-safenet-hsm-version-interoperability-matrix.html

Recommended Actions

     

    Steps to Enable Logging:

         Following  steps involves restarting  service 'pkcs11d' which can impact access to externally stored SSL keys and SSL negotiations when service is restarting.
    1. Make a copy of the Safenet client library under a different name:
        # cp /usr/lunasa/lib/libCryptoki2_64.so /usr/lunasa/lib/libCryptoki2_64.so.real
    2. Edit /etc/Chrystoki.conf and add this section:
       CkLog2 = {
                 LibUNIX64=/usr/lunasa/lib/libCryptoki2_64.so.real;
                 Enabled=1;
                 File=/var/log/cklog.log;
                 Error=/var/log/cklog-error.log;
                 NewFormat=1;
                 LoggingMask=ALL_FUNC;
                }
    3. Replace /usr/lunasa/lib/libCryptoki2_64.so with a symlink to libcklog2.so.
         # ln -sf /usr/lunasa/lib/libcklog2.so /usr/lunasa/lib/libCryptoki2_64.so
    4. Restart pkcs11d
         # bigstart restart pkcs11d
       
    5. Verify that you see contents in /var/log/cklog.log

      22:39:37 30468-1975617856:STRTLogin {Sesn=17 User=1 PIN="********" }

      22:39:37 30468-1971407168:FINILogin CKR_OK(140ms) {}

        Steps to Disable Logging:
      • Replace /usr/lunasa/lib/libCryptoki2_64.so with the original (actual) library:
          # rm -f /usr/lunasa/lib/libCryptoki2_64.so
         # cp /usr/lunasa/lib/libCryptoki2_64.so.real /usr/lunasa/lib/libCryptoki2_64.so
      • Restart pkcs11d
          # bigstart restart pkcs11d
      You need to disable debug logging before upgrading BIG-IP software.

      Additional Information

      It may also be useful to enable pkcs11d debug logging to see additional info from pkcs11d when troubleshooting network HSM issues:

                  # tmsh modify sys db log.pkcs11d.level value debug
