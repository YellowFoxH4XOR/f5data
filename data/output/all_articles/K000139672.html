Description

What is the BIG-IQ default user "f5-dtuser" used for?

Environment

  • BIG-IQ
  • Default User "f5-dtuser"

Cause

None

Recommended Actions

The BIG-IQ user "f5-dtuser" account are F5 default account:

  • it is a trusted user account and has access over all APIs that related to managed BIG-IP devices and BIG-IQ DCDs.
  • this user's User Groups (if applicable) and Roles cannot be edited
  • there will be no option to disable local user from the BIG-IP via GUI
  • this user is not removable as it is a system user
  • you may proceed to change the password of "f5-dtuser" on all of the BIG-IQ and DCD as this will not affect the communication via API between BIG-IQ CM and DCD
