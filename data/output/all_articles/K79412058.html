Description
A BIG-IP configuration that contains a trunk with interfaces of different media (SFP and SFP+ interfaces) fails to load after an upgrade on a BIG-IP 2000/4000 series platform.

  • After upgrading, the configuration fails to load with error message that appears similar to the following example:
    Loading system configuration...
      /defaults/asm_base.conf
    ...
      /usr/share/monitors/base_monitors.conf
    Loading configuration...
    Loading schema version: 12.1.3.4
      /config/bigip_base.conf
      /config/bigip_user.conf
      /config/bigip.conf
    Loading schema version: 12.1.3.5
    01070619:3: Interface 5.0 media type is incompatible with other trunk members
  • Unable to create a trunk containing both SFP and SFP+ interfaces

Environment

  • BIG-IP 2000/4000 series platform
  • Trunk configured with both SFP and SFP+ interfaces 
  • Upgrade from 12.1.3.4 or earlier to 12.1.3.5 or later

Cause
BUG ID 622453 introduced a Change-In-Behavior and trunks with mixed media (SFP and SFP+) interfaces are no longer allowed for the BIG-IP 2000/4000 series platforms. For more information, refer to K98266045: BIG-IP 2000/4000 series platforms no longer allow trunks configured with a combination of SFP and SFP+ interfaces.

Recommended Actions

  • For an existing configuration that fails to load, re-configure the trunk to use only interfaces of the same media. You can do this using either of the following methods:
    • Boot to the previous boot location (12.1.3.4 or earlier), modify the trunk configuration to only contain interfaces of the same media before booting to the new boot location (12.1.3.5 or later) and rolling the configuration forward.
    • Manually modify the /config/bigip_base.conf file to reconfigure the trunk to only use interfaces of the same media, and reload the configuration.
  • When configuring a trunk on a BIG-IP 2000/4000 series platform, ensure all of the interfaces are the same media.
