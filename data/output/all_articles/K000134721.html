K000134721: [F5RST: Flow expired (sweeper) (idle timeout)] for some connections

Type
Support Solution
Published
2023-06-09
Updated
2023-06-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000134721

Description

After successful TCP and TLS handshakes on the client side, connections are closed by the virtual server due to time out. 

Environment

  • BIG-IP LTM
  • Standard virtual server
  • HTTP profile

Cause

A virtual server configured with an HTTP profile is expecting an HTTP request from the client.

If HTTP data are not received during the specified idle timeout, BIG-IP closes the connection with TCP Reset [F5RST: Flow expired (sweeper) (idle timeout)] .

 

Recommended Actions

Do not use an HTTP profile if you would like the virtual server to process different types of traffic.

 

Additional Information

None.
