Known Issue

The BIG-IP system may not properly retransmit some Secure Sockets Layer (SSL) packets or may continuously retransmit Datagram Transport Layer Security (DTLS) finished messages.

This issue occurs when the following condition is met:

  • The virtual server references a client SSL profile or server SSL profile.
  • The SSL session or DTLS session includes packet retransmissions.

Impact

Clients may not be able to establish DTLS sessions with the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You perform packet captures which indicate that the BIG-IP system is not retransmitting SSL packets correctly or is continuously retransmitting DTLS finished messages.
