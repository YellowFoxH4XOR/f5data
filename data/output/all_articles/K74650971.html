Description

Trying to understand what does cause the following message error:

010b0bad:1: TAMD: too many (>60) fails during last 1 sec.

Environment

  •  BIG-IP LTM
  • Using OCSP configuration, OCSP profiles.

Cause

The message error could be related to issues reaching the OCSP server.

This has been observed to occur when Tenable scanning tool has been used by security teams.

Recommended Actions

  1. Verify the logging or alarms on the OCSP Server.
  2. If you are using OCSP profiles on the BIG-IP, this command will show you if you are having errors:

tmsh show ltm auth profile
