Error Message

Aborted: node is in readonly mode

Message Location

You may encounter this message in the following location:

  • VELOS command-line interface (CLI)

Description

This message occurs when the following condition is met:

  • You attempt to enter the configuration mode terminal by entering the config command in the VELOS CLI.

The VELOS system allows only configuration changes on the active controller. You can only run commands that are read-only on the standby controller. For more information about high availability (HA) for the VELOS system, refer to K19204400: Overview of the VELOS system architecture: High availability.

Impact

There is no impact. You can safely ignore this error message.

Recommended Actions

If you want to perform configuration changes on the VELOS system controller, you must log in to the active controller using the floating management IP address.
