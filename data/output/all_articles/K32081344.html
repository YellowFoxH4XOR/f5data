Description

The BIG-IP system fail to install a software image, point release or hotfix with a " failed (archive checksum error) " error message.

Environment

You are installing an imported software image, point release, or hotfix on the BIG-IP system.

Cause

It failed to pass the MD5 integrity check due to image file being corrupted or when the entire ISO image is not copied properly.

Recommended Actions 

You can delete the failed software image and .md5 checksum, re-download it and perform the installation again. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

It is recommended to delete the .ISO image and the .md5 checksum, re-download from https://downloads.f5.com/esd/index.jsp, and proceed with reinstallation.

  1. You must delete the affected volume that has the failed installation.
  2. Delete the  .ISO image and the .md5 checksum in question.
  3. From the F5 downloads site, re-download the ISO image and the matching MD5 checksum file and copy those files to the /shared/images directory on the BIG-IP system.
    • For information about verifying the software image using the MD5 checksum, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.
  4. Once the checksums are validated, perform a new installation again.
Note: If the installation fails to restart after the ISO is re-uploaded to the device, you can run this command from the CLI to clear the stuck liveinstall process:
bigstart restart lind
