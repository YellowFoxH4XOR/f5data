Known Issue

Note: The SSL::handshake iRule command is used to halt or resume SSL activity. Generally, this is useful for suspending SSL activity while authentication is in progress. For example, it is possible to hold the SSL handshake until the revocation status of an X.509 digital certificate is obtained from an OCSP server.

This is the result of a known issue. If an iRule invokes the SSL::handshake hold command from within a CLIENTSSL_CLIENTCERT event for a connection which has resumed a previously established SSL session, the iRule will not actually hold either the handshake or the client data. As a result, TMM will process subsequent iRule events (for example HTTP_REQUEST), which TMM would have held if the connection had not resumed a previously established SSL session.

F5 Product Development is tracking this issue as ID 226827 and ID 248037 (formerly CR142223).
