K000160633: BIG-IP FTP login failed with error 530 incorrect credentials

Support Solution
Published
2026-04-13
Updated
2026-04-30
Applies to

Source

Description

After establishing a successful connection from a BIG-IP device to the FTP server, the login attempt failed with a 530 login or password incorrect.

Sample output,

[root@Test-LB:Active:Standalone] config $ ftp x.x.x.x

Connected to x.x.x.x (x.x.x.x).

Name (x.x.x.x:root): <Username>

331 Please specify the password.

Password:

530 Login or password incorrect!

Login failed.

Environment

  • FTP/SFTP server
  • Remote storage server
  • File transfer from BIG-IP

Cause

The FTP server accepts the connection and prompts for a username. After the username is provided, it returns a 331 response requesting for the password. Once the password is entered, the server rejects the login attempt with a 530 error response.

The "Login failed" response observed in this scenario is coming from the remote server and does not indicate a defect in the BIG-IP.

Recommended Actions

  1. Verify the credentials by confirming that the username and password for the remote server are correct.
  2. If the credentials are verified as valid, take the tcpdump on BIG-IP to ensure we are passing the same credentials details to the remote server

    If the traffic takes a non-management interface, use this command: #tcpdump -ni 0.0:nnn host <Remote_server_ip> -w /var/tmp/Issue.pcap
    If the traffic takes the management interface, use this command: #tcpdump -nni mgmt host <Remote_server _p> -w /var/tmp/issue.pcap
