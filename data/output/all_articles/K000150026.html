K000150026: Error "The following list of images referenced from the deployment template are not found" during BIG-IP deployment on Azure

Type
Support Solution
Published
2025-02-27
Updated
2026-01-06
Applies to
  • BIG-IP
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K000150026

Description

When you try to deploy a BIG-IP in Azure using a template, you may see a Azure console error similar to:

{"code":"InvalidTemplateDeployment","details":[{"code":"InvalidParameter","target":"imageReference","message":"The following list of images referenced from the deployment template are not found: Publisher: f5-networks, Offer: f5-big-ip-best, Sku: f5-big-best-plus-hourly-1gbps, Version: 16.1.303000. Please refer to https://docs.microsoft.com/en-us/azure/virtual-machines/windows/cli-ps-findimage for instructions on finding available images."}],"message":"The template deployment 'Microsoft.Template-20250226050919' is not valid according to the validation procedure. The tracking id is 'c5871b09-6039-44c2-a321-e3784a13851d'. See inner errors for details."}

Environment

  • Azure cloud environment
  • BIG-IP VE
  • ARM template deployment

Cause

This happens when the image referenced in the template is not available in the Azure marketplace.

Recommended Actions

Use an image that it is available in the Azure marketplace. To validate the list of available images. You can run the following command on the Azure Portal console:

az vm image list --publisher f5-networks --offer <F5_offer> --sku <F5_SKU> --all --output table

Replace  <F5_offer> with F5 offer. Example f5-big-ip-best 

Replace <F5_SKU> with F5 SKU. Example f5-big-best-plus-hourly-1gbps
