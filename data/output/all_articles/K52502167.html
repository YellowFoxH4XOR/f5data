Topic

You should consider using this procedure under the following condition:

  • You have configured the BIG-IP system to store all logging information remotely, and you want to reduce the amount of logging data stored locally on the BIG-IP system.

Description

By default, the BIG-IP APM system writes access policy information to the /var/log/apm file while users have active sessions. To reduce the amount of data the system writes to the /var/log/apm file, you can disable local access policy logging using the Configuration utility or the TMOS Shell (tmsh). To do so, perform one of the following procedures as needed:

Prerequisites

You must meet one of the following prerequisites to use this procedure:

  • You have Advanced Shell (bash) or tmsh access to the BIG-IP system.
  • You have administrative access to the Configuration utility.

Procedures

  • Using tmsh to disable or enable access system logging in BIG-IP APM 12.x and later
  • Using the Configuration utility to disable or enable access system logging in BIG-IP APM 12.x and later
  • Using tmsh to disable or enable access policy session logging in BIG-IP APM 11.x
  • Using the Configuration utility to disable or enable access policy session logging in BIG-IP APM 11.x

Using tmsh to disable or enable access system logging in BIG-IP APM 12.x and later

Beginning in BIG-IP APM 12.0.0, access system logging can be disabled or enabled separately for each access profile using tmsh. To do so, perform the following procedure:

Impact of procedure: Disabling access system logging will reduce the quantity of log information stored on the BIG-IP system. Additionally, disabling access system logging may increase troubleshooting difficulty due to the reduced logging data collected by the QKView. Enabling access system logging will increase the quantity of log information stored on the BIG-IP system.

Note: Disabling access system logging for a log setting configuration disables logging for the following components for all associated access profiles: Access Policy, Per-Request Policy, ACL, single sign-on (SSO), Secure Web Gateway, and ECA.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To disable or enable access system logging for a log setting configuration, use the following syntax:

    Note: Using system database keys to control logging in BIG-IP APM 12.0.0 and later is deprecated. Setting the log.access.syslog database key to disable in BIG-IP APM 12.0.0 and later will not disable access system logging.

    modify apm log-setting <name> access modify { <object_name> { enabled <true | false> } }

    For example, to disable access system logging for the log-setting configuration named custom-log-setting, type the following command:

    modify apm log-setting custom-log-setting access modify { custom-log-setting_access { enabled false } }

Using the Configuration utility to disable or enable access system logging in BIG-IP APM 12.x and later

Beginning in BIG-IP APM 12.0.0, access system logging can be disabled or enabled separately for each access profile using the Configuration utility. To do so, perform the following procedure:

Impact of procedure: Disabling access system logging will reduce the quantity of log information stored on the BIG-IP system. Additionally, disabling access system logging may increase troubleshooting difficulty due to the reduced logging data collected by the QKView. Enabling access system logging will increase the quantity of log information stored on the BIG-IP system.

Note: Disabling access system logging for a log setting configuration disables logging for the following components for all associated access profiles: Access Policy, Per-Request Policy, ACL, SSO, Secure Web Gateway, and ECA.

  1. Log in to the Configuration utility.
  2. Navigate to the log settings page:

    13.x and later

    Access > Overview > Event Logs > Settings

    12.x

    Access Policy > Event Logs > Log Settings
  3. Select the log settings configuration to modify and click Edit.
  4. In the General Information window, deselect the check box for Enable Access System Logs
  5. Click OK

Using tmsh to disable or enable access policy session logging in BIG-IP APM 11.x

To disable or enable access policy session logging BIG-IP APM 11.x using tmsh, perform the following procedure:

Impact of procedure: Disabling access policy session logging will reduce the quantity of log information stored on the BIG-IP system. Additionally, disabling access policy session logging may increase troubleshooting difficulty due to the reduced logging data collected by the QKView. Enabling access policy session logging will increase the quantity of log information stored on the BIG-IP system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the log.access.syslog database key, use the following command syntax:

    modify sys db log.access.syslog value <enable | disable>

    For example, to disable local access policy logging, type the following command:

    modify sys db log.access.syslog value disable

Using the Configuration utility to disable or enable access policy session logging in BIG-IP APM 11.x

To disable or enable access policy session logging in BIG-IP APM 11.x using the Configuration utility, perform the following procedure:

Impact of procedure: Disabling access policy session logging will reduce the quantity of log information stored on the BIG-IP system. Additionally, disabling access policy session logging may increase troubleshooting difficulty due to the reduced logging data collected by the QKView. Enabling access policy session logging will increase the quantity of log information stored on the BIG-IP system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Reports > Preferences.
  3. If the Enabled check box for Write To APM Log File is selected, clear the check box to disable access session logging. If the Enabled check box is not selected, select the check box to enable access session logging.
  4. Click Update.
