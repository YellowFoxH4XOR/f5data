Known Issue

DNS Express log messages do not indicate the reason for failed DNS queries.

This issue occurs when all of the following conditions are met:

  • You have configured a DNS Express zone on the BIG-IP system.
  • DNS Express receives a DNS query for a resource record that is not in the zone.

Impact

Error messages do not offer enough information to effectively troubleshoot failed DNS queries.

Symptoms

As a result of this issue, you may encounter one or more of the following symptom:

  • BIG-IP iHealth lists Heuristic H516715 on the Diagnostics > Identified > Low screen.
  • The system logs error messages in the /var/log/ltm file that appear similar to the following example: 

    err tmm1[12345]: 01010225:3: Failure to query dns-express db (Okay).
