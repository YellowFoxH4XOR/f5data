K000130608: TFTP virtual server doesn't send the response back to the client

Type
Support Solution
Published
2023-05-30
Updated
2023-05-30
Status
Final
Source
https://my.f5.com/manage/s/article/K000130608

Description

TFTP acts like an active FTP and uses a second data session on an ephemeral port. When the sever picks a new source port the connection may fail.

You may see a connection timeout or the session may appear to be frozen.

Environment

BIG-IP (13.x - 17.x)

Cause

TFTP uses a callback-type function to handle file transfers. As such, a standard UDP virtual server IP on port 69 will not work with TFTP.

Recommended Actions

In order for Virtual Server to handle the callback function, the TFTP UDP profile must be enabled.
 
See steps below: 
  1. Log in to the configuration utility.
  2. Navigate to the Local Traffic > Virtual Servers 
  3. Click on <name-of-your-virtual-server>
  4. Change the Configuration from Basic to Advanced 
  5. Scroll down until you see TFTP profile 
  6. Change the profile from NONE to TFTP  
  7. Click Update
