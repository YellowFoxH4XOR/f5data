Description

vCMP guest GUI is not loading correctly after a major release upgrade. For example, the vCMP guest was running BIG-IP v13.x and was upgraded to vCMP v14.x/v15.x.

There is no error message seen on the vCMP guest GUI.

Some of the GUI object are not loading correctly or are not responsive.

Check on /proc/meminfo shows that available memory is low.

cat /proc/meminfo

MemTotal                      3569352 kB
MemFree                         47772 kB
MemAvailable                    95308 kB    <- 95MB

Environment

This issue occurs when all of the following conditions are met:

  • vCMP guest upgraded to a major release such as from BIG-IP v13.x to BIG-IP v14.x and above
  • GUI does not load correctly all the time
  • There is no error message when the GUI does not load
  • No issue with httpd and tomcat service
  • No issues with the production traffic
  • vCMP guest has less than 8 GB memory
  • vCMP has very low Available memory as seen from /proc/meminfo

Cause

vCMP guest does not have enough available memory to render the GUI correctly.
When the BIG-IP is upgraded to a major release, it will require more memory to function as the major release will provide more features than the previous release.

Recommended Actions

  1. You will need to increase the amount of cores to the vCMP guest. This would increase the amount of memory.
  2. Provision the vCMP guest to have at least 8 GB of memory.
  3. To increase the cores refer to: Manual Chapter : CPU Core Upgrade for Deployed Guests
