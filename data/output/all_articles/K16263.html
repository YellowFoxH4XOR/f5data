Known Issue

The BIG-IP system does not retain data group file edits.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system references an external data group file.
  • The external data group file exceeds approximately 1488900 bytes in size.
  • You update the contents of the data group using the Configuration utility.

Impact

The data group file does not update.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using the Configuration utility to update a large external data group file, the BIG-IP system does not retain the modifications and or display an error message indicating that the file was not updated.
  • The data group file update information is not available for use with other BIG-IP functions.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to modify the data group. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Edit the external data group file using the following command syntax.

    edit /sys file data-group <datagroup file name>

    Note: This command will launch a vi editor within the tmsh utility.

  3. Using vi editor commands, modify the contents of the data group file.
  4. Save the modifications using the following vi command syntax.

    esc :wq!

  5. To save your changes, type y at the prompt:

    Save changes? (y/n/e)

  6. To exit the tmsh utility, type q.
