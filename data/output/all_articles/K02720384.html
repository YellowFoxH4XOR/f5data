Description

After upgrade on an Active-Active configuration, with BIG-IPs on a traffic-group with +2 HA members, two of the BIG-IPs were advertising the next hop address as the floating address from the inactive/wrong traffi- group.

Environment

  • After upgrade
  • BIG-IPs in Active-Active configuration
  • BGP routing

Cause

Bug ID 760950: Incorrect advertised next-hop in BGP for a traffic group in Active-Active deployment.

Note: This ID is a regression of Bug ID 566507. 

Recommended Actions

To workaround this issue on the affected versions, you can follow the workaround on: K55285671: The BGP may advertise the wrong nexthop floating self IP address.
