Topic

An explicit forward proxy virtual server that uses BIG-IP Analytics requires you to disable the Analytics profile when forwarding SSL traffic.

Description

Starting in BIG-IP 11.5.0, you can configure the BIG-IP system to handle HTTP proxy requests and function as an explicit forward proxy gateway that can forward traffic (for example, SSL traffic) to another virtual server (for example, SSL forward proxy) through a local tunnel.

When you associate an Analytics profile with an explicit forward proxy virtual server, the explicit forward proxy virtual server will not be able to forward SSL traffic to an SSL forward proxy virtual server using a tunnel. Additionally, the explicit forward proxy virtual server will abort the affected client proxy connection. This behavior is expected because the explicit forward proxy virtual server is not associated with an SSL profile and the BIG-IP Analytics system is unable to perform application statistics collection on SSL encrypted traffic. To allow this explicit forward proxy virtual server to forward SSL traffic, you must disable the Analytics profile in the HTTP_PROXY_REQUEST event using an iRule when SSL traffic is detected.

Recommendations

When you plan to use BIG-IP Analytics on the explicit forward proxy virtual server that forwards SSL traffic, you must incorporate an iRule snippet to the explicit forward proxy virtual server configuration.

For example:

when HTTP_PROXY_REQUEST {
if { [HTTP::method] eq "CONNECT" } {
AVR::disable
}
}
