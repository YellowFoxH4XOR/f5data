Topic

Edit the AS3 declaration to add VLAN names, WAF and access policies, multiple SSL profiles, and certificate names to deploy the application service with the supported changes.

Once you Migrate as Draft the application services, go to My Application Services and select the respective application service to edit the AS3 declaration.

Note: When you make any changes to the AS3 declaration, they are automatically saved. Ensure you update the correct changes.

Adding VLAN names in the AS3 declaration

To learn how to create a VLAN, see step no 19.2 in How to: Create a BIG-IP Next instance in a VMware vSphere environment from Central Manager.

  • To add VLAN name, open the Common_virtual_vlan AS3 declaration:
    • In the allowVlans property, add the created VLAN name in the bigip tag.

      Sample AS3 Declaration:

      "tenant61570d921b644": {
           "Common_virtual_vlan": (
                "Common_virtual_vlan": {
                      "allowVlans": [
                            {
                                 "bigip": "vlan_name"
                             }
         ]

Adding WAF and Access policy in the AS3 declaration

To create WAF policy, see Import, Export, Clone, Revert, or Delete a WAF policy.

  • To update the WAF policy name for the unsupported WAF policies, open the common_virtual_multi_waf AS3 declaration:
    • In the policyWAF property, add the WAF policy name in the cm tag.

      Sample AS3 Declaration:

      "Common_virtual_multi_waf": {
           "Common_virtual_multi_waf": (
                "class": "Service_HTTP",
                "persistenceMethods": [],
                "policyWAF": {
                     "cm": "waf_policy_name"
                }

To create an Access policy, see Create an Access policy.

To update the Access policy names, check for policyIAM and policyPerRequestAccess properties in the declaration and update the respective policy names.

Update multiple SSL profiles in the AS3 declaration

To update multiple SSL profiles in the AS3 declaration, open the Common_virtual_multi_ssl AS3 declaration:

  • To add the SSL client side profile name, check the required objects in the AS3 declaration and update in the serverTLS tag.

    For example, search for TLSserver class in the declaration and update with required profile name in the serverTLS tag.

    Note: You can refer only one profile name in the declaration.

    Sample AS3 Declaration:

    "Common_virtual_multi_ssl": {
         "Common_virtual_multi_ssl": {
              "class": "Service_TCP",
                   "persistenceMethods": [],
                   "profileTCP": {
                        "use": "/tenantc3d2758c11a68/Common_virtual_multi_ssl/tcp_default_v14"
                   },
                  "serverTLS": "SSL_client_side_profile_name"
                  "snat":"none",
                  "virtualAddresses": [
                       "10.10.10.21"
                   ],
                   "virtualPort": 443
         }

Adding Certificate name in the AS3 declaration

To add a certificate to CM, see Create a new self-signed certificate and key.

  • To add the certificate name for unsupported certificates application services, open the Common_virtual_unsupported_cert AS3 declaration:
    • In the "certificate property, add the certificate name in the cm tag.
    • In the "privateKey property, add the certificate name in the cm tag.

      Note: Keep the extensions like .crt and .pem the same, and update only the certificate names.

      Sample AS3 Declaration:

      "class": "Application",
      "dsa_51T": {
           "certificate": (
                "cm": "certificate_name.crt"
           },
           "class": "Certificate",
           "privateKey"： {
           "cm": "certificate_name.pem"
            }
        }
