K54299700: AS3 fails with checking cli script status timed out

Type
Support Solution
Published
2022-03-25
Updated
2023-02-21
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K54299700

Description

"Checking cli script status timed out" error returned when deploying a large AS3 declaration.

Example:

[{"code":422,"message":"declaration failed","response":"connection to http://admin:XXXXXX@localhost:8100/mgmt/tm/task/cli/script/1644237601034313 checking cli script status timed out","host":"localhost","tenant":"Common","runTime":257363},{"code":422,"message":"declaration failed","response":"connection to http://admin:XXXXXX@localhost:8100/mgmt/tm/task/cli/script/1644237861517075 checking cli script status timed out","host":"localhost","tenant":"Common","runTime":260588}],

Environment

  • Large AS3 declaration
  • Multiple WAF policies
  • Telemetry Streaming

Cause

ID1086905
GitHub Issue 581

Recommended Actions

The following workarounds can be used to avoid the timeout condition:
  1. Temporarily disable the Telemetry Streaming pull request (or reduce the frequency)
  2. Copy the WAF Policies XML files to the BIG-IP and update the AS3 declaration to reflect that change

Additional Information

Follow guidance for AS3 Best Practice
