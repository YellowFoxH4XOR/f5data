K000149649: Can Bot Defense JavaScript (JS) be inserted on JSON responses?

Published

Updated
2025-02-05
Applies to

  • F5 Distributed Cloud Bot Defense
Source

Description

I'm using Custom JavaScript Insertion Rules and there's a JSON response page I would like to insert Bot Defense JavaScript on to gather telemetry from it.

Can Bot Defense JavaScript (JS) be inserted on JSON responses?

Environment

  • F5® Distributed Cloud
  • Bot Defense

 

Cause

JS cannot be executed on JSON

 

Recommended Actions

Bot Defense JavaScript (JS) cannot be inserted on JSON responses (Content-Type: application/json).

Insert the JS on the page that requests this JSON and not on the JSON endpoint itself or if possible, insert the JS in all pages.
