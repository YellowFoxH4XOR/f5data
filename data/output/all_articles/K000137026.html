Description

Issue with disabling system logs being sent to Microsoft Sentinel from BIG-IP LTM VE deployed in Azure. Telemetry Streaming was causing logs to flood the remote log server. 

 

Environment

Product: BIG-IP LTM VE
Version: 16.X or 17.X
Cloud Provider: Azure
Configuration: Telemetry Streaming enabled, logs being sent to Microsoft Sentinel.

Cause

Logs from the BIG-IP system were being forwarded to the remote log server (Microsoft Sentinel) due to the Telemetry Streaming configuration. The logging profiles and telemetry virtual server settings were not fully disabling the log forwarding. 

Recommended Actions

  1. Disabling Request Logging Profile and Telemetry Virtual Server:

    • Ensure that the Request Logging Profile is set to 'None' for the virtual server.
    • Disable the Telemetry Virtual Server.

  2. Modifying Telemetry Declaration:

    • Use the excludeData property to prevent system logs from being sent to the Sentinel consumer.
    • Example Declaration:
      { "class": "Telemetry", "controls": { "class": "Controls", "logLevel": "info", "debug": true }, "My_System": { "class": "Telemetry_System", "trace": "<path_to_trace>", "systemPoller": { "interval": 60, "actions": [ { "excludeData": {}, "locations": { "system": true } } ] } }, "My_Listener": { "class": "Telemetry_Listener", "port": 6514 }, "My_Consumer": { "class": "Telemetry_Consumer", "type": "Azure_Log_Analytics", "workspaceId": "<workspaceId>", "passphrase": { "cipherText": "<cipherText>" }, "useManagedIdentity": false, "region": "<Region where LogAnalytics workspace resides>" } }

  3. Complete Removal of Telemetry Configuration:

    • If disabling logs via above "excludeData" declaration changes does not work, you can remove the telemetry configuration by making a POST request with an empty declaration:

      { "class": "Telemetry" }

    • Sample command for POST request: 

      curl -X POST http://<big-ip-address>/mgmt/shared/telemetry/declare -H "Content-Type: application/json" -d '{ "class": "Telemetry" }'

                      Note : the above POST request would remove the entire telemetry configuration.
