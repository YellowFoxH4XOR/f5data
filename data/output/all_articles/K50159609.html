Description

  • You have upgraded to version 14.1 or later
  • ConfigSync fails and 'tmsh show /cm sync-status' returns an output similar to:
A validation error occurred while syncing to a remote device.
Sync error on Bigip1 Load failed from /Common/Bigip2 01070712:3: Caught configuration exception (0),
  • /var/log/ltm does not record any specific config sync errors.

Environment

  • Big-IP on High-Availability

Cause

The ConfigSync channel uses a VLAN MTU that is not supported by a network device between the HA pair. Prior to version 14.1, the DCS and CMI channel always used a TCP MSS of 1448, however, this has now changed to use what the VLAN MTU setting is. This is further described in K32233102.


Recommended Actions

 Review the HA VLAN configuration to ensure that the MTU setting is set to 1500 on the HA pair, and all devices in between should be able to pass 1500 MTU.

Additional Information

  • A traffic capture will show TLS handshake failure
  • /var/log/ltm  may  log similar to

SSL Handshake failed for TCP 192.168.1.12:49680 -> 192.168.1.13:4353   (4353 is the Config Sync destination port)
