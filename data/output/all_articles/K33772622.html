Description

When trying to deploy config using AS3, the following error message is seen:
 
"code":408,"message":"Request exceeded iControl LX timeout"}

Environment

  • BIG-IP
  • AS3

Cause

The error is displayed because the referenced data file either does not exist or is empty. For example, when sending AS3 JSON via POST:

curl -X POST -H "Content-Type: application/json" -d @deployment.json http://localhost:8105/shared/appsvcs/declare

deployment.json is missing or just a blank file.

Recommended Actions

Make sure the data file exists and has content.
