Topic

Note: This Solution only applies to BIG-IP platforms that contain a Switch Card Control Processor (SCCP). The BIG-IP platforms affected include the 1500, 3400, 4100, 6400, 6800, 8400, and 8800 platforms. For more information about the SCCP, refer to K3454: Overview of the SCCP.

Note: This Solution only applies to BIG-IP 9.0.0 through 9.1.1 and 9.2.0 through 9.2.3. For information about rebooting the SCCP on all other BIG-IP versions, refer to K6836: Rebooting the SCCP.

The SCCP is a separate subsystem that controls the F5 switch hardware. It may become necessary to reboot the SCCP if, for example, the installation of a hotfix updates the SCCP firmware package.

Rebooting the SCCP

F5 recommends you perform a clean shutdown of the host system, and then concurrently reboot the SCCP and host system, by performing the following procedure:

  1. Log in to the BIG-IP command line.
  2. Create the /.sccp_hard_reboot file, by typing the following command:

    touch /.sccp_hard_reboot
  3. Reboot the host system and the SCCP by typing the following command:

    reboot

Note: The /.sccp_hard_reboot file will no longer exist after the system reboots.
