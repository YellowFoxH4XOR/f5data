Known Issue

Management traffic to a self IP address may fail if SYN cookie protection is activated.

This issue occurs when following conditions are met:

  • SYN cookie protection is enabled
  • You have configured a self IP address to process management traffic

Impact

You may experience poor response times or page timeouts for management traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Increased page load times and/or timeouts when accessing the Configuration utility

Workaround

To work around this issue, you can perform your management tasks using the BIG-IP management interface.

If using the management interface is not possible, you can perform the following procedure to create a virtual server on the self IP address with an iRule, which redirects traffic with the TCP profile. This procedure will stop SYN cookie protection on the virtual server.

Impact of workaround: You must perform a reload of the BIG-IP configuration during a maintenance window.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click iRules.
  4. Create an iRule named gui_helper with the following code, where <self ip> is the IP address of your self IP:

    when CLIENT_ACCEPTED {
    node <self ip>
    }
  5. Click Local Traffic.
  6. Click Virtual Servers.
  7. Create a virtual server with the same IP address as your self IP, and the same self IP address you used in Step 1 on port 443/https.
  8. Associate the gui_helper iRule with this virtual server
  9. Reload your configuration by typing the following command from the command line:

    tmsh load /sys config
