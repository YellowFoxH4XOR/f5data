K44325268: BIG-IQ may fail to import LTM configurations with 1000's of Virtual Servers with ''network communication failed due to protocol error''

Type
Support Solution
Published
2021-10-21
Updated
2025-04-02
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K44325268

Description

BIG-IQ CM fails on module Discovery and Import of device.

Environment

  • BIG-IP device with a large amount of Virtual Servers, numbering into the 1000's
  • Attempt to discover (LTM, AFM, etc) module on an imported BIG-IP device
  • Discovery Fails

    Error getting resource provisioning from /mgmt/tm/sys/provision on example.net (x.x.x.x), network communication failed due to protocol error

Cause

The module discovery is surpassing the hard-coded timeout and BIG-IQ responds with an error.

Recommended Actions

  1. On BIG-IQ, create a backup of restjavad.properties.json.
    cp /var/config/rest/config/restjavad.properties.json /var/tmp/restjavad.properties.json.org

  2. Edit /var/config/rest/config/restjavad.properties.json, by first searching for "global" and insert in the following into the "discovery" section. (Use any text editor such as VI, or NANO)
    "icrPageSize": {
      "tm:ltm:virtual:virtualstate": 250
    }

    To better visualize, following is the snippet of the restjavad.properties.json before and after the change:

    ************
    ** BEFORE **
    ************
    [...]
        "global" :
        {
            "discovery" :
            {
            },
            "deployment" :
            {
            },
            "remove":
            {
            }
        },
    [...]

    ***********
    ** AFTER **
    ***********
    [...]
        "global" :
        {
            "discovery" :
            {
             "icrPageSize": {
                    "tm:ltm:virtual:virtualstate": 250
             }
            },
            "deployment" :
            {
            },
            "remove":
            {
            }
        },
    [...]

  3. Restart restjavad and try discovering LTM service again.
    Note: The discovery and import will take a longer time.
     bigstart restart restjavad
