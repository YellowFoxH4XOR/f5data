K12204: A BIG-IP system with a Load Balancer Limited license fails provisioning initialization during system startup

Known Issue

This is the result of a known issue. When you upgrade a BIG-IP system licensed with a Load Balancer Limited (LBL) license from version 9.x to version 10.x, the BIG-IP system will fail provisioning initialization during system startup. As a result, the BIG-IP system will not be able to load configurations. Therefore, the BIG-IP system will not be able to process traffic until this issue is cleared. When this issue occurs, you may observe the following error message on the command line:

01071009:3: No provisioned objects found.

F5 Product Development tracked this issue as ID 242212 (formerly CR133252) and ID 247784 (formerly CR133252-1), and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You can work around this issue by editing the /config/bigip_sys.conf file to include the provisioning stanza. To do so, perform the following procedure:

  1. Connect to the serial console of the BIG-IP system and log in to the command line with a privileged account, such as root.
  2. Back up the /config/bigip_sys.conf file by making a copy.

    For example:

    cp -p /config/bigip_sys.conf /config/bigip_sys.conf.sol12204
  3. Using a text editor, add the following stanza to the beginning of the /config/bigip_sys.conf file:

    provision ltm {
    level nominal
    }

  4. Save the file as /config/bigip_sys.conf.
  5. Exit the text editor.
  6. Reload the configuration to enable your changes by typing the following command:

    bigpipe load
