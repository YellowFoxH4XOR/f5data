Description

Beginning BIG-IP v17, BIG-IP ASM / Adv WAF OWASP Top 10 2021 Security Policy Compliance check feature now has the updated list of web application security risks

Environment

BIG-IP ASM Adv WAF provisioned
BIG-IP ASM Adv WAF Security Policy configured

Cause

You would like to check if BIG-IP ASM / Adv WAF has the updated OWASP Top 10 2021 web application security risks checks

Recommended Actions

In the Configuration Utility, go to Security  ››  Overview : OWASP Compliance, select a Security Policy you would like to check compliance to OWASP Top 10 2021 list.

A1 Broken Access Control
A2 Cryptographic Failures
A3 Injection
A4 Insecure Design
A5 Security Misconfiguration
A6 Vulnerable and Outdated Components
A7 Identification and Authentication Failures
A8 Software and Data Integrity Failures
A9 Security Logging and Monitoring Failures
A10 Server-Side Request Forgery (SSRF)

Additional Information

A4 Insecure Design, A8 Software and Data Integrity Failures and A10 Server-Side Request Forgery (SSRF) are new to OWASP Top 10 2021 list.
