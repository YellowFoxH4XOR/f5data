Important: FirePass does not support downgrading the software currently running on your FirePass controller to a previous version of FirePass software. The Local Update and Online Update features in the FirePass Administrative Console do not support software downgrades. Downgrading to a previous version of FirePass software may leave your FirePass controller inoperable.

FirePass does not support downgrading to a previous version of FirePass software. However, FirePass supports the use of the snapshot feature to restore FirePass controllers to a previous version or configuration. The snapshot feature was introduced in version 5.0.0 of FirePass software and is available on FirePass controllers that shipped with version 5.0.0 or later.

The snapshot feature creates an image of the current FirePass software and configuration, and stores the image on the hard drive of the FirePass controller. You can use this image to replace the current configuration with the stored configuration, and safely restore your FirePass controller to a previous version.

Note: For additional information about the snapshot feature, refer to K3244: Backing up and restoring FirePass system software.

Contact F5 Technical Support if you have attempted to downgrade to a previous version of FirePass and it has left your FirePass controller inoperable.
