Known Issue

Description

The BIG-IP Edge Client may fail to process traffic when switched from Transport Layer Security (TLS) to Datagram Transport Layer Security (DTLS).

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM configuration uses a network access profile with DTLS enabled.
  • The network access tunnel is established using TLS and later switches to DTLS.

Impact

The BIG-IP Edge Client locally closes the tunnel session and is unable to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP Edge Client stops processing network access tunnel traffic.
  • The BIG-IP Edge Client stops responding, and the status changes from Connected to either Waiting to connect or Downloading server settings.
