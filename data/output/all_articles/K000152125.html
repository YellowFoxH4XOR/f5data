K000152125: n3fipsutil Utility Referenced in K000135566 Fails to Import All FIPS Keys

Type
Support Solution
Published
2025-06-25
Updated
2025-06-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000152125

Description

You want to disable Cavium Nitrox III FIPS HSM key export and are following the procedure outlined in K000135566. However, you discover that the command in step 11 of "Apply the Fix" fails to import all FIPS keys.

/var/tmp/n3fipsutil -importKeys /var/tmp/fipsexport [-n <partition_name>]

Environment

  • You want to apply the FIPS HSM change introduced by ID 1023341 while preserving all stored information by following the procedure detailed in K000135566.

Cause

n3fipsutil utility fails to import FIPS keys with '.' in the name. F5 tracks the issue as ID 1854633.

 

Recommended Actions

Please open a support case with F5.

Additional Information

None
