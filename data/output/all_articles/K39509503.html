Description

You wish to create a specific response to the DNS Resource Record type 65 (HTTPS) request using an iRule.

Environment

  • BIG-IP
  • DNS virtual server
  • DNS requests for Type 65 (HTTPS) Resource Record

Cause

DNS type 65 (HTTPS) Resource Record is a proposed standard that has already been implemented in some operating systems. However, BIG-IP DNS support for this Resource Record is limited to enabling the Oblivious DNS over HTTPS (ODoH) Target service discovery. For more information, refer to K83416050: BIG-IP support for DNS Resource Record type 65 (SVCB HTTPS).

Recommended Actions

  1. An iRule created in the DNS / Delivery / iRule, you can see the DNS::question type of an HTTPS request as 65. You can then insert the following iRule to handle the HTTPS type requests.
when DNS_REQUEST {
  log local0. "\[DNS::question name\]: [DNS::question name], \[DNS::question type\]: [DNS::question type]"
  if {[DNS::question type] == 65} {
    log local0. "returning NOERROR"
    DNS::header rcode NOERROR
    DNS::return
  }
}

Note: You cannot set DNS::answer to type 65 as this will cause an iRule error until suitable support has been added to BIG-IP.


Additional Information

For DNSSEC zones NOERROR response must contain SOA record matching the zone name in the DNS query. 
In the following example there are 2 zones: "example.com" and "example2.com".  Queries for DNS Type 65 in all other zones will receive responses with NOERROR and with no authority section which cannot be signed with DNSSEC.

when DNS_REQUEST {
    log local0. "\[DNS::question name\]: [DNS::question name], \[DNS::question type\]: [DNS::question type]"
    if {[DNS::question type] == 65} {
        if {[DNS::question name] ends_with "example.com"} {
            DNS::header rcode NOERROR
            set authority [DNS::rr "example.com.    60  IN  SOA ns.example.com. hostmaster.example.com. 1001 10800 3600 604800 60"]
            DNS::authority insert $authority
            DNS::return
        }
        elseif {[DNS::question name] ends_with "example2.com"} {
            DNS::header rcode NOERROR
            set authority [DNS::rr "example2.com.   60  IN  SOA ns.example2.com.  hostmaster.example2.com.  1001 10800 3600 604800 60"]
            DNS::authority insert $authority
            DNS::return
        }
        else {
            DNS::header rcode NOERROR
            DNS::return
        }
    }
}
