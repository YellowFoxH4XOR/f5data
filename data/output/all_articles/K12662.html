Known Issue

This is the result of a known issue. When the log level of the BIG-IP APM SSO logs is set to Info, the Session ID does not appear in the log messages. The expected behavior is that the log messages include the Session ID information.

F5 Product Development tracked this issue as ID 337949.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP APM version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

If you set the log level to Debug, the Session ID appears. You should set the log level to Debug only during active troubleshooting as the Debug setting can quickly generate a large number of messages.

To change the log level for APM SSO, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Expand the System section.
  3. Click Logs.
  4. Click the Options tab.
  5. In the Access Policy Logging section, change the SSO drop-down menu to the log level you want.
  6. Click Update.

Important: When you have completed troubleshooting, repeat this procedure to revert to a lower log level.
