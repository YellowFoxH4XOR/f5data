Known Issue

Important: This issue applies only to BIG-IP 6900 and 8900 platforms running BIG-IP version 10.1.0 and attempting to run EUD version 12.5 or earlier. In addition, this issue only occurs on platforms using the volume format with RAID enabled. Systems running the partition format will not utilize the RAID file system or systems that are using volume partition but are not configured to use the RAID file system.

This is the result of a known issue. Running EUD version 12.5 or earlier on a BIG-IP 6900 or 8900 platform running BIG-IP version 10.1.0 will result in corruption of the RAID file system and prevent the system from booting correctly after the EUD has run.

Note: For more information about changes made to EUD version 12.6, refer to K10897: The EUD utility no longer stores the test report log in the /shared/log directory.

F5 Product Development tracked this issue as ID 201406 (formerly ITEM 1445) and it was fixed in EUD version 12.6. For information about upgrading, refer to the EUD release notes.
