Description

Starting with BIG-IP version 12.0 iControl® REST no longer requires that you grant permissions on iControl REST resources for individual user accounts. Users automatically has access to REST resources, but the user must acquire a token for authentication and include that token in all REST requests.
Note: For users that lack administrator privileges, the user must request a token that can be used to authenticate the user making REST API requests.
 

Environment

  • BIG-IP
  • Administrator user role

Cause

Administrator Privilege No Longer Required.

Recommended Actions

Here's an example on how to delete/revoke a user REST API token:

  • To start off, obtain all generated auth tokens:
    curl -sk -u admin:passed -X GET "https://x.x.x.x/mgmt/shared/authz/tokens?%24select=token,userName" | sed 's/,/\'$'\n/g' | egrep -w "userName|token"
    Note: Update the above command replacing <admin>:<password> with the correct user credentials and replace x.x.x.x with the IP/Hostname of the BIG-IP .

    The output should be similar to:

    {"items":[{"token":"N2THHXUEYSA5L236LAQEU5BHX3"
    "userName":"user_1"}
    {"token":"WNB4KOLH23RFLUG75CXTR2W72N"
    "userName":"user_2"}]
  • There's no revoke command. however, to delete the given token to the userName user_1, use the HTTP DELETE method as shown below:
    curl -sk -u <admin>:<password> -X DELETE "https://x.x.x.x/mgmt/shared/authz/tokens/N2THHXUEYSA5L236LAQEU5BHX3"
    Note: Update the above command replacing <admin>:<password> with the correct user credentials and replace x.x.x.x with the IP/Hostname of the BIG-IP .
