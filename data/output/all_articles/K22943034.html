Description

In a BIG-IQ you are trying to add a TCP analytics profile to a FastL4 virtual server via the application deployment. However, you get a warning message like the following one:

Verification error: Virtual Server named <virtual-server name> has failed with error message: Performance L4 server attached 2 profiles: one is fastL4 and the other must be Http profile for Virtual server

Environment

  • BIG-IQ
  • Application deployment 
  • Fast L4 virtual server
  • Analytics profile

Cause
This warning message is a cosmetic issue. The warning should not be there. The deployment is performed successfully.

Recommended Actions

No action, the warning message is benign. The deployment should be successful

None
