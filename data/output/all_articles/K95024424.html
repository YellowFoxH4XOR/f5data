K95024424: After migration to vCMP Guest, services on one Virtual Server stopped working

Type
Support Solution
Published
2022-04-12
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K95024424

Description

Migrated from an Appliance to a vCMP Guest and a flow that has Virtual Server targeting another Virtual Server via irule,  packets are not forwarded by 2nd Virtual Server to Pool Member.

Environment

Migrated from Appliance to vCMP Guest.
Configuration has a Virtual Server targeting another Virtual Server via irule.

Cause

The second Virtual Server has Mirroring enabled but there is no Mirroring IP setup on for the vCMP Guest.

Recommended Actions

  1. Remove Mirroring from the second Virtual Server.
  2. Or, setup Mirroring IP for the vCMP Guest

Additional Information

None at this time of publication.
