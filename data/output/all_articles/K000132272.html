K000132272: BIG-IQ Backup schedule time configuration incorrect after Daylight Saving Time (DST) event

Type
Support Solution
Published
2023-01-26
Updated
2024-07-03
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.1.X, 8.0.X, 8.1.X, 8.2.X, 8.3.X, 8.3.0, 8.2.0, 8.1.0, 8.0.0, 7.1.0
Source
https://my.f5.com/manage/s/article/K000132272

Description

  • BIG-IQ Backup Scheduling changes due to daylight saving. The next start time no longer matches the initial start time when the backup schedule was created.

Environment

  • BIG-IQ
  • UCS

 

Cause

Bug ID 1070385

 

Recommended Actions

Modify backup start date

 

From GUI:

 

1. Go to Backup Schedule and select backup schedule name

2. Change the start date to a more recent date

 

To modify all backup start time at the same time:

 

1. Create a file with the backup ID list:

 

# restcurl /shared/task-scheduler/scheduler/ | jq '.items[] | select(.taskBodyToRun.taskBody) ' | jq -r .id > /var/tmp/id_list

 

2. Perform the actual update against the timeToStartOn using the ids listed. For instance, to change start date on Jan 25, 2023 to 11:30 AM:

 

# cat /var/tmp/id_list | while read line ; do restcurl /shared/task-scheduler/scheduler/$line -X PATCH -d '{"timeToStartOn": "2023-01-25T11:30:00+0000"}' ; done

 

 

3. Confirm changes.
