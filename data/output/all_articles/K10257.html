K10257: The System Health page displays temperature readings for multiple boards

Topic

On some FirePass platforms, the Device Management: Monitoring: System Health page displays temperature readings for multiple boards.

For example:

CPU 1 Temperature 51 C OK
CPU 2 Temperature 45 C OK
Board 1 Temperature 60 C OK
Board 2 Temperature 41 C OK
 
The term board refers to a temperature sensor, not to a separate motherboard. Therefore, when several boards are reported, there are multiple temperature sensors and not multiple motherboards.
