K6630: BIG-IP incorrectly changes the client IP address to the BIG-IP self IP address for connections that use the _ASM_Bypass rule

Known Issue

This is the result of a known issue. When the _ASM_Bypass rule is enabled, requests to virtual servers bypass BIG-IP ASM, and are routed according to the virtual server configuration. When the _ASM_Bypass rule is enabled and no secure network address translation (SNAT) is configured for virtual server connections, the source IP address of the request is incorrectly translated to the BIG-IP system's self IP address.

F5 Product Development tracked this issue as CR69312 and it was fixed in BIG-IP ASM 9.2.4. For information about upgrading, refer to the BIG-IP ASM release notes.
