Topic

The following procedure configures a pre-logon sequence that sends users with a valid client certificate to the standard logon page, while sending all other users to a Logon Denied screen. You may customize the Logon Denied screen with instructions or additional information, or choose any other set of actions for users who do not have a valid client certificate installed.

Detecting client certificates in a pre-logon sequence

  1. Log in to the FirePass Administrative Console.

  2. Click Users.

  3. Click Endpoint Security.

  4. Click Pre-Logon Sequence.

  5. Under the New Sequence section, enter a name for this pre-logon sequence next to Create new sequence.

    For example:

    Client Certificate Detection

  6. In the Based on drop-down menu, select template: Empty.

  7. Click the Create button.

    The sequence you created now appears in the Select Sequence to Use section at the top of the page.

  8. Click edit next to the pre-logon sequence that you created.

    The Pre-Logon Sequence Editor opens.

  9. Mouse over the Go action.

  10. Click the + link.

  11. In the Change sequence drop-down menu, select Insert action.

  12. In the Using drop-down menu, select One from the list.

  13. Click the Check client certificate button.

  14. Click the Apply changes button at the bottom of the page.

    The Check client certificate inspector now appears in your pre-logon sequence.

    To the right of yes is a Logon Allowed Page box. This means that users with a valid client certificate will be directed to a logon page.

  15. To the right of fallback is a Logon Denied Page box. Click on Logon Denied Page.

    The End Page Properties panel opens.

  16. Leave Type set to Logon Denied Page.

  17. Under Message for user (FirePass versions 5.5 and later) or Message for failed logons (FirePass version 5.4.2), enter the message that will appear to users who do not have a valid client certificate installed.

    For example:

    A valid client certificate is required to access this system. Please contact your FirePass administrator for assistance.

  18. Click the Update button at the bottom of the page.

  19. Click the Back to Console link at the top right corner of the page.

    The Pre-Logon Sequence main page appears.

  20. Under the Select Sequence to Use section, click the button to the left of the pre-logon sequence you just created.

  21. Click the Apply button. Your new pre-logon sequence is now activated.

For information about self-signed client certificates, refer to K7478: Creating and requiring self-signed client certificates.
