Known Issue

Important: This article applies to Windows Vista clients. For Windows 7 clients, refer to K10876: The Components Troubleshooting Utility may report errors or crash on Windows 7 clients.

This is the result of a known issue. If you select Remove Components from the Tools menu in the FirePass Components Troubleshooting Utility (CTU), and the client system is running Windows Vista, the CTU may report an error message that appears similar to the following example:

Control is locked. Please, try to remove components after restart the system!

This error message is erroneous and can be safely ignored. The CTU is a client utility introduced in FirePass version 6.0.2.

Note: For more information about the CTU, refer to K9133: Overview of the FirePass Components Troubleshooting Utility.

F5 Product Development tracked this issue as CR103870 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Important: After installing cumulative hotfix HF-603-1, you must distribute the new version of the CTU to client systems. For more information about downloading the CTU from the FirePass Administrative Console, refer to K9133: Overview of the FirePass Components Troubleshooting Utility.
