Known Issue

If you enable mirroring on a Session Initiation Protocol (SIP) or diameter router profile, it affects the per-client connection mode operation.

This issue occurs when the following condition is met:

  • You enable connection mirroring in the siprouter and diameterrouter profiles.

Impact

In the siprouter and diameterrouter profiles, if you enable mirroring, it incorrectly enables the internal ignore_peer_port flag. This causes the router to not consider the remote port of the client-side connection when determining which of an outgoing per-client connection it can use for forwarding messages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the mirror flag is enabled in the siprouter and diameterrouter profiles, any client connection from the same IP address can use the outgoing per-client create connection.
