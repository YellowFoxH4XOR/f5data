Description

  • How can I configure an HTTP Load Balancer (LB), so everyone sees the proxy IPs instead of the client's real IP address?
  • You want to configure an HTTP Load Balancer to show the proxy IP instead of the Real IP address.

Environment

  • F5® Distributed Cloud HTTP Load Balancer (LB)

Answer/Recommended Actions

F5 HTTP LB by default adds the x-forwarded-for header to notify the real client IP address to the origin server.

You can hide the real IP address and expose the Proxy IP address, as follows:

  • When configuring the HTTP LB, remove the x-forwarded-for header before sending the request to the origin server.
  • This option can be found in the HTTP Load Balancer configuration under More Options > Header Options
