Description

AS3: Switching monitorType from https to http breaks configuration

 

Environment

BIG-IP LTM

AS3

 

Cause

After switching monitorType from https to http in an AS3 declaration the Tenant's bigip.conf file contains the string "user-defined CIPHERLIST DEFAULT"

 

e.g.

/config/partitions/AS3-TENANT/bigip.conf

 

ltm monitor http /AS3-TENANT/app1/monitor1 {

adaptive disabled

adaptive-limit 1000

adaptive-sampling-timespan 180

defaults-from /Common/http

destination *:*

interval 5

ip-dscp 0

recv HTTP/1.

recv-disable none

send "HEAD / HTTP/1.0\r\n\r\n"

time-until-up 0

timeout 16

user-defined CIPHERLIST DEFAULT <<<<< ---------- This is added

}

 

Error seen when loading the sys config:

# tmsh load sys config verify

Syntax Error:(/config/partitions/AS3-TENANT/bigip.conf at line: 52) "user-defined" unknown property

 

Recommended Actions

Workarounds

1.

  • Delete the HTTPS monitor via AS3
  • Update the AS3 declaration with the new HTTP monitorType

2.

  • Change the name for the new HTTP monitor

 

Fix

This issue is fixed in AS3 v3.54.1.
