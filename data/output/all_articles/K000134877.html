K000134877: [F5OS] Error: Storage size(77) must be greater than or equal to 82

Type
Support Solution
Published
2023-06-06
Updated
2024-06-25
Source
https://my.f5.com/manage/s/article/K000134877

Description

When using ansible to deploy tenants in an F5OS-capable device or restore F5OS configuration backup, the deployment returns this error in /var/F5/system/log/devel.log :

fatal: <<hostname>>: FAILED! => {"changed": false, "msg": "{'ietf-restconf:errors': {'error': [{'error-type': 'application', 'error-tag': 'malformed-message', 'error-path': \"/f5-tenants:tenants/tenant[name='<<tenant name>>']\", 'error-message': '/tenants/tenant{test}/config: Storage size(77) must be greater than or equal to 82G\\n'}]}}"}

 

Environment

  • Deployment via ansible
  • F5OS Tenant
  • Restore F5OS configuration backup

Cause

This might be caused by BugID 1204845

 Recommended Actions

Please, upgrade the F5OS software to v1.4.0 or later, where the Storage tag has been added:

 "f5-tenants:config": {
    ....
    "storage": {
      "size": 142
    },
   ....
}

If the current F5OS is already v1.4.0 or later, please modify size of the tenant to 82 and retry previous task :

 <tenant>
   <name><tenant name></name>
---snip---
    <type>BIG-IP</type>
---snip---
    <storage>
     <size>77</size>                                       <---- change to 82
---snip---
  </tenant>

 

Additional Information

None.
