Known Issue

This is the result of a known issue. When a Mac OS X client connects to Network Access using the Safari browser, and the browser is left idle, a disconnect may occur within 10 to 15 minutes. When the Safari browser does not send traffic, the FirePass controller determines the client is no longer connected and terminates the session.

F5 Product Development tracked this issue as CR122046 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-4 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

For a list of the latest hotfixes, refer to K10322: FirePass hotfix matrix.
