Known Issue

The subject line of an alert notification email message may contain a truncated log message.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration uses an alert event in the alert.conf file that includes both the lcdwarn and email actions.
  • The lcdwarn action occurs before the email action.

When the lcdwarn action occurs before the email action in an alert.conf file, processing of the lcdwarn action causes the log message used for the subject line of the subsequent email message to be truncated.

Impact

The subject line of email message alerts may contain incomplete information.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H474724 on the Diagnostics > Identified > Low screen.
  • The email message sent for an alert condition contains a truncated log message.

Workaround

To work around this issue, you can edit the /etc/alertd/alert.conf file to ensure that the lcdwarn action occurs after the email action. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Change to the /etc/alertd directory by typing the following command:

    cd /etc/alertd
  3. Create a backup copy of the alert.conf file by typing the following command:

    cp alert.conf alert.conf.sol15506
  4. Modify the permissions on the alert.conf file to include write access by typing the following command:

    chmod 644 /etc/alertd/alert.conf
  5. Using a text editor, edit the alert.conf file to ensure the affected alerts perform the email action before the lcdwarn action.
  6. Save and then exit the file.
  7. Restore the permissions on the alert.conf file by typing the following command:

    chmod 444 /etc/alertd/alert.conf
  8. Restart the alertd process by typing the following command:

    bigstart restart alertd
