Issue

Error Message

01070069:3: Subscription not found in mcpd for subscriber Id <process>

In this error message, note the following:

  • <process> is the process ending a subscription to the Master Control Program Daemon (mcpd).

For example:

01070069:3: Subscription not found in mcpd for subscriber Id BIGD_Subscriber

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The BIG-IP systems is shutting down or restarting and a system process is removing a subscription to mcpd that was never used.

Impact

There is no impact. This message is informational.

Recommended Actions

None
