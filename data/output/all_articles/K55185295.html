Issue

Old Behavior

In versions prior to BIG-IP 12.0.0, systems licensed for the BIG-IP Advanced Routing Module (BIG-IP ARM) and configured to use Border Gateway Protocol (BGP) have a practical limitation of about 50,000-100,000 route entries.

New Behavior

Beginning in BIG-IP 12.0.0, the BIG-IP system supports up to 1 million route entries for IPv4 and IPv6 traffic.

F5 Product Development tracked this change as ID 467730.

Impact

Systems licensed for BIG-IP ARM and configured to use BGP can now more easily be deployed as edge router systems.

Recommended Actions

None
