K000149428: Creating custom ciphers group with support for TLS1.3 protocol: "A cipher group must be configured when TLS 1.3 is enabled".

Type
Support Solution
Published
2025-02-10
Updated
2025-02-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149428

Description

Simply enabling TLS1.3 protocol in the Client SSL profile does NOT work due to the following error:

01b40001:3: A cipher group must be configured when TLS 1.3 is enabled (validation failed for profile /Common/tls13_custom).

 

Adding TLS1.3 ciphers to the 'cipher' string does NOT work either. SSL-Checker reports no TLS1.3 in the supported ciphers list.

'TLS13-AES128-GCM-SHA256:TLS13-AES256-GCM-SHA384:TLS13-CHACHA20-POLY1305-SHA256:DEFAULT'

 

Environment

BigIP 17.1.1.4

 

Cause

You need to enhance TLS security on Virtual server by adding support for TLS1.3 ciphers.

Recommended Actions

You need to create two new cipher rules.

You can enable TLS1.3 protocol via either WebUI or CLI.

A) Using the WebUI

Log in to the BIG-IP system Web GUI  and select:

Local Traffic  ››  Ciphers : Rules...Create

1) New TLS1.3 ciphers:

Rule name: TLS13_Ciphers:

Cipher Suites: TLSv1_3

DH Groups: DEFAULT

Signature Algorithms: DEFAULT

2) Existing custom cipher string:

Rule name: TLS12_Ciphers:

Cipher Suites: 'ECDHE:DHE:!low:!SSLv3:!tlsv1:!DHE-RSA-DES-CBC3-SHA:!ECDHE-RSA-DES-CBC3-SHA'

DH Groups: DEFAULT

Signature Algorithms: DEFAULT

B) Using the CLI

Log in to tmsh by entering the following command:

tmsh

create ltm cipher rule TLS13_Ciphers2 { cipher TLSv1_3 dh-groups DEFAULT signature-algorithms DEFAULT }

create ltm cipher rule TLS12_Ciphers2 { cipher ECDHE:DHE:!low:!SSLv3:!tlsv1:!DHE-RSA-DES-CBC3-SHA:!ECDHE-RSA-DES-CBC3-SHA dh-groups DEFAULT signature-algorithms DEFAULT }

3) Create new 'TLS12_TLS13_Protocols' cipher Group combining the above cipher rules.

A) Using the WebUI

Log in to the BIG-IP system Web GUI  and select:

Local Traffic  ››  Ciphers : Groups  ››  New Cipher Group...

 

B) Using the CLI

Log in to tmsh by entering the following command:

tmsh

create ltm cipher group TLS12_TLS13_Ciphers allow add { TLS12_Ciphers2 TLS13_Ciphers2 }

 

4) Now you can create Client SSL profile and assign newly created cipher group to it.

A) Using the WebUI

Log in to the BIG-IP system Web GUI  and select:

Local Traffic  ››  Profiles : SSL : Client  ››  New Client SSL Profile...

Enable the "Cipher Group" option and select the new cipher group from the drop-down menu

 

B) Using the CLI

Log in to tmsh by entering the following command:

tmsh

create client-ssl TLS12_TLS13_ssl_profile { cipher-group TLS12_TLS13_Ciphers }
