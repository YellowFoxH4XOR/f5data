Description

Procedure to debug LTM policy (Centralized Policy Matching (CPM) policy) rules to ensure configured policy rule conditions and actions are being triggered.

Environment

  • BIG-IP
  • v11.4 and later
  • LTM (CPM) Policy
     

Cause

By design
 

Recommended Actions

Complete the following steps:

  1. Place TMM in debug mode using command below

    Important: This will cause a disruption in services if performed on an Active BIG-IP

    ln -sf /usr/bin/tmm.debug /etc/alternatives/tmm
    bigstart restart tmm

  2. Enable LTM (CPM) policy tracing using db key below

    tmsh modify sys db tmm.policy.tracelevel value <value>

    Note: 
    • Setting value to 1 traces found operands and actions executed
    • Setting value to 2 produces more verbose output including state-machine transitions

    For example:

  3. Reset the db key once the operand conditions and actions are verified

    tmsh modify sys db tmm.policy.tracelevel reset-to-default

  4. Create a new symbolic link that points back to the default TMM by typing the following command

    ln -sf /usr/bin/tmm.default /etc/alternatives/tmm

  5. Restart TMM by typing the following command

    Important: This will cause a disruption in services if performed on an Active BIG-IP

    bigstart restart
