K14850353: Big-IQ returns message similar to ''code'':500,''message'':''Connection refused'' when running a job on the Big-IP

Type
Support Solution
Published
2026-08-14
Updated
2026-08-14
Source
https://my.f5.com/manage/s/article/K14850353

Description
When attempting to run a job on the Big-IQ against a Big-IP, it returns an error similar to

[INFO][21 Sep 2020 07:39:57 AEST][/cm/shared/stats-mgmt/device-monitor-task/6ebcde9a-52fc-43a7-9173-cdcdb3541bca/worker DeviceMonitorTaskWorker] getRegisteredSourceInfo failed for device <IP ADDRESS>: java.net.ProtocolException: status:500, body:{"code":500,"message":"Connection refused","referer":"http://localhost:8100/cm/shared/stats-mgmt/dcd-forwarder","restOperationId":1440499680,"errorStack":[],"kind":":resterrorresponse"}

Environment

  • A Big-IQ managing one or more Big-IPs

Cause
This is caused by restjavad failing to properly bind to the listener port on the Big-IP
 

Recommended Actions

Restart restjavad on the Big-IP
