K35251042: Kerberos authentication fails with KRB5KDC_ERR_C_PRINCIPAL_UNKNOWN

Type
Support Solution
Published
2024-04-27
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K35251042

Description

Kerberos authentication fails with the following Windows Kerberos server message:

 KRB5KDC_ERR_C_PRINCIPAL_UNKNOWN

Environment

  • Kerberos SSO delegation account is in UPN format
  • Principal Type NT-ENTERPRISE-PRINCIPAL

Cause


Kerberos SSO delegation account is in UPN format and does not match exactly the sAMaccountname found in ADSIEdit or ldapsearch.


Recommended Actions

Verify the sAMaccountname on the delegation account, either in ADSIEdit or ldapsearch and try using this as the delegation account name in the Kerberos SSO profile exactly the way it is on the Windows server.
