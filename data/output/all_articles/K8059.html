Policy Information

Important: F5 has announced the End of Sale (EoS) for the BIG-IP ASM / Traffic Shield 4100 platform. For information refer to K9572: End of Sale for the BIG-IP ASM / Traffic Shield 4100 platform.

F5 has announed the End of Sale (EoS) for the BIG-IP ASM 4100 lower base memory SKU, effective August 1, 2009. Maximum memory is needed for customers to take full advantage of the 4100 and higher platform capabilities.

To simplify the ordering process and reduce possible confusion, F5 is providing advance notification of its intent to EoS base memory platform SKUs. The following SKUs will be moved to EoS status and be replaced in accordance to the information contained in the following table:

Lower Base Memory End of Sale Summary

Part NumberDescriptionReplacement SKU
F5-BIG-ASM-4100-RSBIG-IP Appliance: Application Security Manager 4100 ROHSF5-BIG-ASM-4100-4G-R

Transition Plan

  • Product support for existing customers:

F5 continues to actively support the lower base memory SKUs and maintains generous lifecycle policies that allow customers to enjoy many years of both support and new software releases. Full details of the policies and support timelines are available on AskF5.

  • New sales and current prospects:

Prospects who want to purchase the BIG-IP ASM 4100 products can purchase maximum memory configurations of these platforms using the replacement SKUs referenced in the Lower Base Memory End of Sale Summary table.

For more information about this Solution, contact your local F5 Channel Sales Manager or Inside Sales Representative.
