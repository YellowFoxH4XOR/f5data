Description

Regarding Web Application Security signature file processing, such as importing, downloading, installing (pushing to devices), and deleting signature files in the BIG-IQ for managed BIG IP

 

Environment

-BIG-IQ Central Management

-Managed BIG-IP

-Web Application Security signature file processing, such as importing, downloading, installing (pushing to devices), and deleting signature files in the BIG-IQ for managed BIG IP

Cause

None

Recommended Actions

With regard to the download of application security attack signature updates:

-if there is both tmm and mgmt route to callhome.f5.com, BIG-IQ will use the self IP that has a route going to callhome.f5.com to download the attack signature updates.
-if there is only the mgmt route then BIG-IQ will use the mgmt IP to callhome.f5.com to download the attack signature updates regardless of the discovery IP for the managed BIG-IP.

With regard to the installation of application security attack signature updates:

-BIG-IQ will install the application security attack signature via the Discovery IP
