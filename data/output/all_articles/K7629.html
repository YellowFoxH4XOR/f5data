Known Issue

This is the result of a known issue. If you stream HTTP data and have compression enabled on a virtual server, compression of the HTTP content can fail due to the HTTP data becoming stuck in the compression buffers queue. This behavior may cause the BIG-IP system to pass the uncompressed information to the client, or prevent the BIG-IP system from sending any data to the client. As a result, the connection will time out.

F5 Product Development tracked this issue as ID 264228, ID 282731, ID 296602, and ID 314636 (formerly CR62467 and CR62558), and it was fixed in BIG-IP versions 9.3.0 and 9.4.5. For information about upgrading, refer to the BIG-IP LTM, ASM, or WebAccelerator release notes.

Note: This issue was fixed by adding a new setting to the HTTP profile. If you are affected by this issue, you can enable this setting from within an iRule. For more information, refer to K12503: Compressing HTTP streaming applications.
