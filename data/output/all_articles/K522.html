Configuring media speed

By default, BIG-IP and 3-DNS network interfaces are configured to auto-negotiate the media speed setting. Since all Ethernet devices do not implement auto-negotiation in the same way, this can cause a failure when attempting to negotiate the correct link speed.

To avoid this issue, F5 Networks recommends that you manually configure the media speed setting for all 10Mbps, 100Mbps, and 10/100Mbps interfaces.

Important: Fiber and copper gigabit interfaces use a different auto-negotiation mechanism and should be left at the auto setting.

Media speed setting options

The options for the media speed setting on BIG-IP and 3-DNS Controllers equipped with 10Mbps, 100Mbps, and 10/100 Mbps interfaces are:

  • 10base
  • 100baseTX
  • auto

Viewing the existing media speed setting

To view the existing media speed setting for the interface, type the following command:

bigpipe interface <interface> media show

For example:

bigpipe interface 1.1 media show

The output should appear similar to the following example:

1.1     100baseTX (100baseTX)

If the output matches your desired media speed, you do not need to manually configure the speed.

Manually configuring the media speed setting

To manually configure the media speed setting for each interface, perform the following steps:

Important: F5 Networks recommends that you connect to the console port when you make any changes to the media setting. If you make an error while changing this setting, it is likely that you will interrupt service and not be able to connect to the controller through the affected interface.

  1. To reset the media speed, type the following command:

    bigpipe interface <interface> media <speed>

    For example:

    bigpipe interface 1.1 media 100baseTX

    Confirm that the system is working properly with the new settings.

  2. To save the new setting, type the following command:

    bigpipe base save

  3. Confirm the saved settings by viewing the interfaces section of the /config/bigip_base.conf file. The configuration should appear similar to the following example:

    # interfaces
    interface 1.1 media 100baseTX

The system is now configured to use the new media speed settings upon reboot.

Configuring media duplex settings

By default, BIG-IP and 3-DNS network interfaces are configured to auto-negotiate the duplex setting. Since all Ethernet devices do not implement auto-negotiation in the same way, this can cause a failure when attempting to negotiate the correct link speed.

To avoid this issue, F5 Networks recommends that you manually configure the duplex setting on all 100Base-TX interfaces.

Important: Fiber and copper gigabit interfaces use a different auto-negotiation mechanism and should be left at the auto setting.

Duplex setting options

The options for the duplex setting for BIG-IP and 3-DNS systems equipped with 100Base-TX interfaces are full and half.

Note: 10Base-T, 100Base-T4, and FDDI interfaces do not have duplex settings.

Viewing the existing duplex setting

To view the existing duplex setting for the interface, type the following command:

bigpipe interface <interface> duplex show

For example:

bigpipe interface 1.1 duplex show

The output should appear similar to the following example:

1.1   half (half)

If the output matches your desired duplex setting, you do not need to manually configure it.

Manually configuring the duplex setting

Important: F5 Networks recommends that you connect to the console port when you make any changes to the media setting. If you make an error while changing this setting, it is likely that you will interrupt service and be unable to connect to the controller through the affected interface.

To manually configure the duplex setting for each interface, perform the following steps:

  1. To reset the duplex setting, type the following command:

    bigpipe interface <interface> duplex <setting>

    For example:

    bigpipe interface 1.1 duplex half

    Confirm that the system is working properly with the new settings.

  2. To save the new setting, type the following command:

    bigpipe base save

  3. Confirm that the changes are saved by viewing the interfaces section of the /config/bigip_base.conf file. It should appear similar to the following example:
    # interfaces
interface 1.1 media 100baseTX
interface 1.1 duplex half

The system is now configured to use the new duplex settings upon reboot.
