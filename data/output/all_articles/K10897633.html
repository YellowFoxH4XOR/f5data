Issue

Error Message

Error Message: notice tmrouted[<PID>]: 01910300:5: HA daemon heartbeat disabled. Last value is <counter>.

In this error message, note the following:

  • <PID> is the process ID of the tmrouted process.
  • <counter> is a counter for the total number of heartbeat periods (9s) that the tmrouted process is registered with the HA system.

For example:

Error Message: notice tmrouted[8725]: 01910300:5: HA daemon heartbeat disabled. Last value is 30104.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You remove all dynamic routing protocols from a route domain so that no dynamic routing protocol is enabled on the BIG-IP system.

You can add or remove dynamic routing protocols to a route domain at the affected route domain when you navigate to Network > Route Domains in the Configuration utility.

Impact

No dynamic routing protocol is enabled on the BIG-IP system.

Recommended Actions

This message is a notification that the tmrouted HA process heartbeat is disabled so that no dynamic routing protocols are enabled on the BIG-IP system.
