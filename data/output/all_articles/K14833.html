Known Issue

Connections that use dynamic Equal Cost Multipath (ECMP) routing may not be mirrored correctly.

This issue occurs when all of the following conditions are met:

  • There are multiple nexthop/routes between the BIG-IP system and server/pool member through the OSPF ECMP routing environment.
  • You have configured the high-availability (HA) pair to use dynamic routing with ECMP.
  • You have configured connection mirroring on the affected virtual server, and it uses an ECMP route.

The system does not correctly mirror connections that rely on ECMP routes to the pool members that are multiple hops from the standby BIG-IP system.

Impact

The affected connections fail if a failover event occurs.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The standby BIG-IP system's connection table does not contain entries for the affected connections.
  • Affected connections fail if a failover event occurs.
