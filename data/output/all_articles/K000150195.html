K000150195: OID for CPU and Fan/PSU status on F5 rSeries appliance

Type
Support Solution
Published
2025-06-03
Updated
2026-02-06
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000150195

Description

  • OID for CPU , Fan and PSU status on F5 rSeries appliance.

Environment

  • F5OS - Appliance
  • SNMP
  • MIB/OID

Cause

Monitoring hardware health (CPU, Fan, PSU) on F5 rSeries appliances requires the correct SNMP OIDs, which may vary depending on the F5OS-A version. Some OIDs for PSU status are only available in F5OS-A 1.8.0 and later.

Recommended Actions

1. PSU (Power Supply Unit) Status

  • MIB Table: F5-PLATFORM-STATS-MIB::platformPsuStatsTable
  • OID Example: .1.3.6.1.4.1.12276.1.2.1.9.1
  • How to Query:Use SNMP tools (like snmpget/snmpwalk) from a third-party system: 
  • snmpget -M ALL:/path/to/mibs_from_f5os_folder -m ALL -v2c -c <COMMUNITY_STRING> <F5OS_IP> F5-PLATFORM-STATS-MIB::platformPsuStatsTable

2. Fan Status (within PSU)

  • MIB Table: F5-PLATFORM-STATS-MIB::platformPsuStatsTable
  • OID Example: .1.3.6.1.4.1.12276.1.2.1.9.1.1.11

3. CPU Status

  • MIB Table: F5-PLATFORM-STATS-MIB::cpuProcessorStatsTable
  • OID Example: .1.3.6.1.4.1.12276.1.2.1.1.1

 

  • MIB Table: F5-PLATFORM-STATS-MIB::cpuUtilizationStatsTable
  • OID Example: .1.3.6.1.4.1.12276.1.2.1.1.2

 

Additional Information

  • These OIDs and MIBs are supported on F5OS-A 1.8.0 and later. If you are running an earlier version, some OIDs may not be available or may behave differently.
  • F5OS does not have native SNMP commands (like snmpwalk or snmpget) on the appliance itself. You must use a third-party SNMP tool from a management workstation or server.
  • For human-readable OID descriptions, download and import the F5 MIB files into your SNMP manager.
