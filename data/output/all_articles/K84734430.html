Description
Unable to configure SNMPv3 profile combination of SHA1 + AES 256
01070903:3: Constraint ' SHA-2 auth protocol is required with longer AES keys' failed for '/Common/user'

Environment

  • BIG-IP 
  • SNMPv3 profile

Cause
The related error message was added as a part of  Bug ID 867249
SHA-1 and AES-192/192C/256/256C were never supported for a long time. SHA-1 is considered insecure since 2005. 

Recommended Actions

  1. Consider configuring SNMPv3 profile using SHA2 for longer AES keys.  For more Information refer to K82498430
