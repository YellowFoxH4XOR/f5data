Description

Article covers question How to generate BIG-IQ report showing the number of F5 Guests and their VIPs & Pools at all

 

Environment

BIG-IQ CM

Report for Virtual Servers Pools and Nodes

Cause

Feature not implemented and tracked under ID629961

Recommended Actions

As a workaround use curl to obtain information directly from rest database

Example:

PASS='admin' ; set-basic-auth on; curl -sk

https://localhost/mgmt/cm/adc-core/working-config/ltm/virtual

-u admin:$PASS | jq -r '.items[] | {name,destinationAddress, destinationPort, deviceName: .deviceReference.name, poolReference: .poolReference.name} | join(", ") ' ; set-basic-auth off 

Note Remember to change PASS='admin' to admin password configured on BIG-IQ device
