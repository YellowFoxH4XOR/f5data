Known Issue

This is the result of a known issue. The FirePass %session.av.summary.monitor% session variable is initialized when the Windows antivirus checker is triggered during a pre-logon sequence. If you enable the Session Variable dynamic group mapping method, and configure an entry in the master group or resource group mapping table using the %session.av.summary.monitor% session variable, FirePass does not perform group mapping based on that entry.

F5 Product Development is tracking this issue as CR129813.
