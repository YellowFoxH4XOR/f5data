K34141619: Unable to discover BIG-IP ''Failed to update (post or patch) device-group cm-bigip-allDevices keys on device''

Description

BIG-IP config discover produces error "Failed to update (post or patch) device-group cm-bigip-allDevices keys on device".


Environment

  • BIG-IP discover

Cause

Httpd has blocked methods on BIG-IP. 
BIG-IQ it's regularly using GET, POST, PUT, DELETE and PATCH methods.

Recommended Actions

  1. Check BIG-IP httpd config

    # tmsh list sys httpd

    Example output:  
    sys httpd {
...
    include "FileETag MTime Size
    <Location />                               
        <LimitExcept GET POST>                 <<  httpd allows only GET and POST methods 
            order deny,allow
            deny from all
        </LimitExcept>
    </Location>"
    ssl-ciphersuite TLSv1.2+ECDHE-RSA-AES256-GCM-SHA384:TLSv1.2+ECDHE-RSA-AES128-GCM-SHA256:TLSv1.2+ECDHE-ECDSA-AES128-SHA256:TLSv1.2+ECDHE-ECDSA-AES128-GCM-SHA256:TLSv1.2+ECDHE-ECDSA-AES256-GCM-SHA384
    ssl-protocol TLSv1.2
}

  2.  Edit httpd config to allow more methods or remove <Location /> section with limitation

Additional Information
