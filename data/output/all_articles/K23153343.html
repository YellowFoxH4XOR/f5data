Description

Unable to locate bfd echo option after upgrade.

BIGIP-LTM [0](config)#bfd ?
  gtsm           bfd gtsm protection
  multihop-peer  Multihop BFD session
  notification   bfd notifications
  slow-timer     Set BFD slow-timer Interval

Environment

  • BIG-IP v13.x or later 

Cause

BFD echo functionality is not supported on BIGIP, BFD echo option is removed starting from v13. This is tracked with ID625758. 

Recommended Actions

This is an expected behavior.

Additional Information

None.
