Description

This article explains how to configure F5 WAF for NGINX (NGINX App Protect) to restrict access to only specific file types. By default, NAP policies may include a wildcard entry that allows all file types, and file type violations are set to alarm mode rather than blocking mode.

Key topics covered:

  • How NGINX App Protect inspects and enforces file type restrictions
  • Configuring the policy to allow only designated file types
  • Enabling blocking mode for file type violations

Environment

  • F5 WAF for NGINX (NGINX App Protect)
  • NAP policy configuration with filetypes section
  • VIOL_FILETYPE violation setting

Cause

None

Recommended Actions

To configure NGINX App Protect to allow only specific file types:

  1. Modify the filetypes section in the NAP policy configuration:
    • Add only the desired file type(s) to the filetypes section
    • Remove the wildcard entry from the policy configuration
    • Refer to: https://docs.nginx.com/waf/policies/filetypes/ 
      {
    "policy": {
        "name": "policy1",
        "template": { "name": "POLICY_TEMPLATE_NGINX_BASE" },
        "applicationLanguage": "utf-8",
        "enforcementMode": "blocking",
        "blocking-settings": {
            "violations": [
                {
                    "name": "VIOL_FILETYPE",
                    "alarm": true,
                    "block": true
                }
            ]
        },
        "filetypes": [
            {
                "name": "*",
                "type": "wildcard",
                "allowed": true,
                "checkPostDataLength": false,
                "postDataLength": 4096,
                "checkRequestLength": false,
                "requestLength": 8192,
                "checkUrlLength": true,
                "urlLength": 2048,
                "checkQueryStringLength": true,
                "queryStringLength": 2048,
                "responseCheck": false
            },
            {
                "name": "bat",
                "allowed": false
            }
        ]
    }
}
  2. Set VIOL_FILETYPE to blocking mode:
    • By default, VIOL_FILETYPE is set to alarm mode
    • Change the violation setting to blocking mode to enforce file type restrictions
    • Refer to: https://docs.nginx.com/waf/policies/violations/
  3. Verify the configuration:
    • Test that requests with allowed file types are permitted
    • Confirm that requests with disallowed file types are blocked

Additional Information

NGINX App Protect inspects file types based on the file extension present in the request URL.

/exampleurl/test.pdf?parameters

The file type enforcement mechanism relies on:

  • The filetypes list defined in the NAP policy configuration
  • The VIOL_FILETYPE violation setting (alarm vs. blocking mode)

The following file types are disallowed by default: https://docs.nginx.com/waf/policies/disallowed-extensions/
