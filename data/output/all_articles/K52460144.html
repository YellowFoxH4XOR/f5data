Description

An application is a container that houses multiple application services in the BIG-IQ user interface. An Application Service Name(ASN) refers to the name given to the application service during the AS3 deployment.  This article describes how to view the corresponding ASN information in the BIG-IP GUI.
  • In the BIG-IP GUI, the ASN will be shown as the Path value for objects related to the Application Service.
  • In the following example, "Sales" is the Partition name and "web443" is the ASN:

    Partition / Path : Sales/web443

 

Environment

  • BIG-IQ deploying ASN to BIG-IPs using AS3
