Known Issue

Secure Sockets Layer (SSL) forward proxy bypass may fail to release memory used for ssl_hs instances.

This issue occurs when all of the following conditions are met:

  • The leak can be triggered by iRules, where a duplicate forward proxy lookup is initiated and interferes with the initial asynchronous lookup.
  • You have configured SSL Forward Proxy with SSL Forward Proxy Bypass enabled.

Impact

The Traffic Management Microkernel (TMM) produces a core file after the system runs out of memory, which impacts availability.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • TMM leaks memory used for ssl_hs instances when the system uses SSL Forward Proxy when SSL Forward Proxy Bypass is enabled.
