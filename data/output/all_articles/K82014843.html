Description

Running Bitsight, Qualys SSL Labs, or other SSL scanners against a BIG-IP virtual server reports DH 1024 bits WEAK.

Environment

BIG-IP SSL virtual server configured with Diffie-Hellman (DHE) 1024-bit cipher enabled.

Cause

The DHE 1024-bit cipher is considered to be a weak cipher by Qualys and other SSL scanning tools.

Recommended Actions

To increase the security of DHE ciphers, the BIG-IP rotates the 1024-bit keys, which makes them more secure than static 2048-bit keys. The BIG-IP also provides more secure ciphers such as ECDHE. Consider the following options:

  1. Beginning in BIG-IP 16.1.3 and 17.0.0, the BIG-IP system supports DHE keys larger than 1024 bits. For more information, refer to K79342815: BIG-IP support for RFC7919 Negotiated Finite Field Diffie-Hellman Ephemeral (FFDHE).
  2. If your environment can function without DHE ciphers, disable DHE ciphers and use ECDHE ciphers.
  3. For information on configuring SSL ciphers, refer to the following:
    • K01770517: Configuring the cipher strength for SSL profiles (14.x - 15.x)
    • K17370: Configuring the cipher strength for SSL profiles (12.x - 13.x)
    • K13171: Configuring the cipher strength for SSL profiles (11.x)
    • K8802: Using SSL ciphers with BIG-IP Client SSL and Server SSL profiles

Additional Information

The move to 2048-bit keys is 5 times the mathematical processing of 1024-bit keys (80% reduction in DHE SSL throughput).

There are additional reasons to consider not using DHE ciphers:

  • Older browsers such as IE6 and Java clients do not support 2048-bit DH parameters.
  • The TLS protocol does not provide any method for negotiating the DH parameter-length to ensure compatibility.
  • Modern versions of Chrome, Safari, and Firefox do not support DHE by default.
