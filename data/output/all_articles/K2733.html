K2733: BIG-IP SSL proxy support for SSL-encrypted FTP

Topic

FTPS has been superseded by SSH-based FTP (SFTP) clients, which are a sub-protocol for SSH2 and secure copy (SCP) based clients. BIG-IP's SSL proxy does not currently support FTPS (or FTP over SSL) and BIG-IP does not currently contain special-protocol level support for SFTP/SCP.

BIG-IP is, however, able to load balance SFTP/SCP at the TCP level, because, unlike FTP, SFTP/SCP does not transmit IP:Port information inside of the protocol thereby requiring no special handling from a load balancing perspective.
