K000138901: Rename the RDP launcher filename

Applies to

  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000138901

Description

You would like to rename the RDP launcher filename to something more appropriate for your needs

Environment

  • BIGIP
  • APM
  • Remote Desktop launcher

 

Cause

n/a

Recommended Actions

An iRule would be required to change the name of the launcher file.
Create the iRule below and apply the iRule to the Virtual Server.


## The RDP launcher URI uses the path /f5vdi/rdp/launch
## The icon name displayed on the WebTop is used as the filename in the URI
## This iRule puts the RDP icon name into the variable $rdpreq
 
when HTTP_REQUEST {
    set rdpreq ""
    if { ([HTTP::path] starts_with "/f5vdi/rdp/launch” ) } {
        set file [split [HTTP::path] "/"]
        set ix [llength $file]
        set rdpreq "[lindex $file [expr {$ix - 1}]]" 
    }
}
 
 
## The locally saved launcher filename is defined in the response header Content-Disposition (as filename=launchXXXXXXXX.rdp)
## so before sending the response to the client, modify the Content-Disposition header to replace
## the "launch" in the default filename with whatever is in $rdpreq as defined in the HTTP_REQUEST
 
when HTTP_RESPONSE_RELEASE {
    if { $rdpreq ne ""} {
        if {[HTTP::header exists "Content-Disposition"] } {
            set rdpname [HTTP::header value "Content-Disposition"]
            set newrdpname [string map [list "launch" $rdpreq ] $rdpname]
            HTTP::header remove Content-Disposition
            HTTP::header insert Content-Disposition $newrdpname
        }
        set rdpreq ""
    }
}
