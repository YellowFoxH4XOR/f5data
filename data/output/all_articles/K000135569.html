Description

The module “Intrusion Prevention System, VE-3G” went missing after doing a license upgrade from v13.0.0 to 16.1.3.

In v13.0.0 the module was showing under Active Module. After moving to v16.1.3, it was showing under Optional Module.

Environment

  • LTM VE
  • v16.1.3
  • Module "Intrusion Prevention System, VE-3G"

Cause

This has nothing to do with version upgrade. The module was accidentally included in the software Bill Of Materials (BOM) in error. The feature will automatically disappear from a license when this license was reactivated.

 Recommended Actions

Since the module is not active in the first place, customer will need to purchase an addon license for Intrusion Prevention System (IPS) if they need this feature. Please reach Sales/Accounts team to purchase.
