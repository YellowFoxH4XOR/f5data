Known Issue

The BIG-IP Edge Client traffic control service may unexpectedly terminate.

This issue occurs when all of the following conditions are met:

  • The BIG-IP Edge Client traffic control service component is installed on a Windows 64-bit operating system as part of a BIG-IP Edge Client installation.
  • The Windows 64-bit operating system is version 7 or later.

Impact

The BIG-IP Edge Client traffic control service fails to function.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you start the BIG-IP Edge Client traffic control service (F5TrafficSrv), within seconds the service terminates and does not automatically restart.
  • When you attempt to restart the BIG-IP Edge Client traffic control service, within seconds the service terminates.

Workaround

There is no work around for this issue. User devices will need to update the BIG-IP Edge Client traffic control components (typically automatic) when connecting to an access policy on a BIG-IP APM system running a fixed version.
