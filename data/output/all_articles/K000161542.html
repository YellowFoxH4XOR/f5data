Description

In BIG-IP AWAF/ASM, filtering Security ›› Event Logs : Application : Requests using only the Request Contains text filter may return no results even though matching events exist. The same text search may succeed when combined with additional indexed filters (for example, source IP, destination IP, policy name, or a narrower time range), especially in high-volume logging environments.

Environment

  • BIG-IP AWAF/ASM
  • High-volume ASM security event logging
  • GUI event log search using Request Contains (text/substring search against request content)
  • Request content stored in protobuf files under /var/asmdata1/request_log`` and event metadata in PRX (MySQL) database

Cause

The Request Contains filter is a non-indexed, two-stage search:

  1. The GUI backend first queries the PRX database and retrieves up to 100,000 candidate events (based on sort order and any other indexed filters).
  2. It then performs a text search against request content stored in protobuf files for only those retrieved events.

If the searched string is not present within that initial 100,000-event set, the GUI returns no results, even if matching logs exist outside that window. Applying additional indexed filters reduces the initial PRX result set, increasing the likelihood that matches fall within the first 100,000 events.

Recommended Actions

  • Do not rely on Request Contains as the only filter in high-volume environments. Combine it with additional indexed filters such as:
    • Source IP / destination IP
    • Policy name
    • A narrowly defined time range
  • Reduce the initial result set before applying Request Contains (more filters and tighter time windows improve consistency).
  • Be aware of the 100,000-event limitation when performing GUI text searches on request content.

Additional Information

  • This is a design/scalability limitation of how GUI search is performed when request content is not indexed (protobuf-based storage).
  • If GUI results appear inconsistent (works only when additional filters are used), it typically indicates the search term exists outside the first 100,000 events returned by the initial PRX query.
