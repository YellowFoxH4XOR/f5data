Known Issue

The BIG-IP system may report CPU and chassis temperatures incorrectly when the operating temperature of the device is less than 0 degrees Celsius.

The system may read temperature values from the ADM1026 controller as unsigned integers. The signed integer range that the ADM1026 controller reports spans the values -128 to +128. When the system reads these values as unsigned integers, the range spans the values 0 to +255. This issue affects the following platforms:

  • BIG-IP 1500
  • BIG-IP 3400
  • BIG-IP 6400
  • BIG-IP 6800

Impact

Operating temperatures below 0 degrees Celsius are reported incorrectly.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • CPU and chassis temperatures may be falsely reported as above 128 degrees Celsius
  • The system may write log messages similar to the following examples to the /var/log/ltm file:

    010d0001:0: Cpu 1: temperature (254) is too high
    010d0001:0: Cpu 2: temperature (255) is too high
    010d0004:0: Chassis 102: temperature (255) is too high
