Description

When attempting to configure Link Aggregation Control Protocol (LACP) on trunk interfaces in BIG-IQ VE, the configuration fails with the following error message:

01070687:3: Link Aggregation Control Protocol (LACP) is not supported on this platform.

This issue occurs when trying to enable LACP on a trunk interface using TMSH commands. Users may encounter this when attempting to establish cross-connections between BIG-IQ Central Manager (CM) systems using LACP trunking or configurations similar to Cisco Virtual Port Channel (vPC).

Environment

  • Product: BIG-IQ
  • Version: All versions
  • Platform: F5-BIQ-VE (BIG-IQ Virtual Edition)
  • Configuration: Attempting to configure LACP on trunk interfaces
  • Command used: modify net trunk <trunk_name> lacp enabled

Cause

LACP is not supported on the BIG-IQ VE platform. This is a platform limitation. BIG-IQ interfaces are designed for management, discovery, cluster, and listener functions, and do not support LACP trunking configurations that are available on BIG-IP systems.

Recommended Actions

For BIG-IQ High Availability Configuration:

  1. Use the BIG-IQ GUI to establish HA between two BIG-IQ systems:
    • Log in to the primary BIG-IQ system
    • Navigate to System > BIG-IQ HA
    • Select Add Standby and provide the required details for the secondary BIG-IQ
    • Ensure both systems are on the same version, have synchronized clocks, and can communicate over their management interfaces (eth0)
  2. The HA cross-connection for BIG-IQ is established through the HA pairing process in the GUI, not by configuring LACP or trunks.

For Network Redundancy:

  • If network redundancy for the management interface is required, implement this at the network or hypervisor level, not within BIG-IQ itself.

Note: While basic trunk creation is possible using TMSH (e.g., create net trunk T1 interfaces add { 1.1 1.2 }) , enabling LACP on these trunks is not supported on BIG-IQ VE.

Addition​al Information

  • BIG-IQ does not support LACP trunk configuration in the same way as BIG-IP systems.
  • The interfaces on BIG-IQ are designed for management, discovery, cluster, and listener functions, not for application traffic or LACP trunking.
  • LACP configuration with Virtual Port Channel (vPC) is not supported on BIG-IQ VE.
