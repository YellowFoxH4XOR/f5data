Known Issue

This is the result of a known issue. Internal link flaps cause a switchboard failsafe to occur on the BIG-IP 8800 platform. When this occurs, the following message is logged to the /var/log/ltm file:

bcm56xxd[291]: 012c0012:6: Tx Aborted. Link(s) down. unit=4, tx_ports=7d3ff970bcm56xxd[291]: 012c0012:6: Tx Aborted. Link(s) down. unit=4, tx_ports=7d3ff970bcm56xxd[291]: 012c0010:3: Trouble with packet send request from LACPD on unit 4, port 1tmm2[2628]: 01230002:4: Interface 0.5: link is downtmm2[2628]: 01230002:4: Interface 0.6: link is down

F5 Product Development tracked this issue as CR80142 and it was fixed in BIG-IP 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
