Description

After deleting a virtual server or network objects and try to re-create it, the device won't be able to load the configuration and you may start seeing the following error message: 

/var/log/ltm
01070710:3: Database error (0), ERROR: duplicate key value violates unique constraint "<object_name>" DETAIL: Key (name)=(/<partition>/<tunnel_name>) already exists.

In this error message, note the following:

<object_name> - The name of the configuration object
<partition> - The name of the partition the tunnel configuration object
<tunnel_name> - The name of the tunnel object

For example:

01070710:3: Database error (0), ERROR: duplicate key value violates unique constraint "tunnel_pkey" DETAIL: Key (name)=(/Common/http-tunnel) already exists.

Environment

  • BIG-IP
  • Virtual Server
  • Network objects
  • Mcpd binary database

Cause

This message occurs when the following conditions are met:

  • The mcpd binary database has been removed
  • The configuration is loaded by manual command or reboot of the device

Recommended Actions

  1. In order to load the configuration, you will need to use the 'bigstart reload' command then load the configuration on the device 
  • Reloading the 'bigstart' application via the TMSH Shell.
  • Log in to the command line interface on the device
  • Run the 'bigstart restart' command
  • Load the configuration using the 'tmsh load sys config' command
  1. Alternatively, perform an mcpd forceload.
  • touch /service/mcpd/forceload
  • reboot
