Topic

You should consider using these procedures under the following conditions:

  • The BIG-IP ASM system generates an Access From Malicious IP Address violation.
  • The BIG-IP system does not return the expected results when running the iprep_lookup command.
  • You believe that the connection is legitimate and the IP address is incorrectly classified as malicious.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • IP Intelligence Services is configured and enabled.
  • You have administrative access to the BIG-IP system.

Description

The IP Address Intelligence feature allows the BIG-IP system to automatically block client requests that originate from IP addresses that have been denylisted by the Webroot IP Reputation subscription service. If you believe an IP address is incorrectly classified as malicious, perform the procedures below to investigate and possibly request a change to the status of the IP.

Procedures

  • Verifying that the IP reputation database is current
  • Verifying the IP reputation
  • Submitting an IP reputation change request

Verifying that the IP reputation database is current

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To verify that the BIG-IP system has the most current copy of the IP reputation database installed, perform the following procedure:

  1. Log in to the BIG-IP system command line.
  2. To verify that the IP reputation database is configured to automatically update, enter the following command:

    tmsh list sys db iprep.autoupdate

    If the command returns the following string, proceed to step 3:

    value "disable"

    If the command returns the following string, proceed to step 4:

    value "enable"

  3. To enable automatic updates, enter the following command:

    tmsh modify sys db iprep.autoupdate value enable

  4. To determine how recently the database was updated, enter the following command:

    tmsh show sys iprep-status

    The command returns a status that appears similar to the following example:

    Last time the server was contacted for updates  09/14/2012 23:59:21
    Last time an update was received  09/14/2012 23:55:19
       

    The default interval for contacting the server for updates is every five minutes.

    Note: If the TMOS Shell (tmsh) shows that the sys iprep-status command does not return any output, your device may not be correctly licensed for the IP reputation subscription module. For more information, refer to the Supplemental Information section.

  5. If you must force the BIG-IP ASM system to contact the server and check for an updated database in a shorter time interval (one minute), enter the following command:

    tmsh modify sys db iprep.intervalmin value 1

  6. After the system contacts the server and receives any available updates, restore the refresh rate to the default value (five minutes) by entering the following command:

    tmsh modify sys db iprep.intervalmin value 5

  7. Starting in BIG-IP 15.1.4 for the BIG-IP 15.1.x branch, you can force the BIG-IP ASM system to contact the server using IPv4 or IPv6. By default, the system automatically detects which IP protocol to use. You can change the IP protocol by entering the following command syntax:

    tmsh modify sys db iprep.protocol value <auto-detect | ipv4 | ipv6>

    For example, to force the BIG-IP ASM to contact the server using IPv4 protocol only, enter the following command:

    tmsh modify sys db iprep.protocol value ipv4

Verifying the IP reputation

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To verify the classification of the IP address once you have the most current database, perform the following procedure:

  1. Log in to the BIG-IP system command line.
  2. To check the IP address against the malicious IP address database, use the following command syntax:

    iprep_lookup <X.X.X.X>

    Note: <X.X.X.X> is the IP address you want to verify.

    The command returns the categories for which the IP has been flagged in the database, similar to the following example:

    iprep threats list for ip = 182.161.114.36 is:
     
    bit 0 - Spam Sources
    bit 2 - Web Attacks
    bit 4 - Scanners
     

Submitting an IP reputation change request

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To submit an IP reputation change request, complete the form located at the following location:

http://www.brightcloud.com/tools/change-request.php

Note: F5 does not maintain the IP reputation database, and F5 Support cannot assist with any information about the IP reputation change request after you have submitted it.
