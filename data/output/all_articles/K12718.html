Topic

The BIG-IP ASM system does not support UTF-8 Byte Order Mark (BOM) in the middle of an XML stream in versions 9.2 - 10.2.1. The BIG-IP ASM XML processor will respect the BOM if it appears at the beginning of an XML stream, as defined in section 4.3.3 of the W3C XML specification; however, if the BOM appears elsewhere in the XML stream, the BIG-IP ASM will treat it as an unsupported character. When this occurs, a violation that appears similar to the following example will be logged to the /var/log/asm file:

Malformed XML data

F5 Product Development is tracking a Request for Enhancement (RFE) to support BOM characters in the middle of an XML stream as ID 349410, and the feature was addressed in BIG-IP ASM version 10.2.2.

This RFE has been addressed in cumulative hotfix Hotfix-BIGIP-10.2.1-496.0-HF2, which has been issued for BIG-IP ASM version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
