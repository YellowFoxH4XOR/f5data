Description

While troubleshooting a network issue you have taken a packet trace and observed the BIG-IP sending a TCP reset after receiving a SYN/ACK. Similar to the following example:

192.168.115.15 → 192.168.115.17 TCP 5162 → 25 [SYN]
192.168.115.17 → 192.168.115.15 TCP 25 → 5162 [SYN, ACK]
192.168.115.15 → 192.168.115.17 TCP 5162 → 25 [RST]

Environment

  • Packet trace
  • TCP

Cause

This is the expected behaviour of a TCP half-open monitor.

Recommended Actions

Verify if the pool member or node in question is monitored by a TCP half-open monitor.

Additional Information

You may also be able to determine if this is monitor activity by reviewing the interval at which the BIG-IP sends a TCP SYN in the packet trace. The default monitor interval is 5 seconds.
