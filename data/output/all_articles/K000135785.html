Overview

This policy applies to the following software products:

  • BIG-IP Next for F5 Systems, which you deploy on F5 hardware systems running on the F5OS operating system from F5
  • BIG-IP Next Virtual Edition (VE), which you deploy into virtualized compute environments using a virtual appliance
  • BIG-IP Next Central Manager, which you deploy into virtualized compute environments using a virtual appliance

For information about the BIG-IP software support policy, see K5903: BIG-IP software support policy.

Note: The F5 software support policy described in this article does not apply to the F5 BIG-IP Edge Client and F5 BIG-IP Edge Portal application software delivered through the Apple App Store or Android Market. F5 supports only the latest versions of these client applications.

This policy defines the following:

  • Key milestones —Stages of the BIG-IP Next software lifecycle from initial release through retirement
  • Versioning schema—Product notation system that denotes new functionality, updates, and/or bug fixes after the product Introduction milestone
  • Release type—Part of the versioning schema, notation that indicates the longevity of technical support offered

This policy brings together the key implications for product support based on the milestones, product version, and release type.

BIG-IP Next Standard Support phase and software lifecycle milestones

The Standard Support phase for BIG-IP Next software includes the following product support:

  • New functionality
  • Updates
  • Bug fixes
  • Security fixes
  • Technical support

The Standard Support phase for BIG-IP Next software products begins with the Introduction date and ends with the End of Software Development (EoSD) date. BIG-IP Next software products have the following product lifecycle milestones, which have direct implications for the support the software products receive.

Table 1 BIG-IP Next software lifecycle milestone definitions
MilestoneDefinition
IntroductionThe date of release of the BIG-IP Next software product to customers. The Introduction date is when a product is ready for sale and F5 makes it commercially available. The milestones indicate that a product satisfies the functionality, quality, and supportability requirements to be offered to target customers (not purpose built or specific to one customer). After the Introduction date, F5 can quote a product and you can purchase it for deployment and use.

F5 uses Introduction date interchangeably with a few other terms, such as General Availability (GA) date, and it is when product access is available to any customer.

In some cases, F5 allows a limited number of customers to access a product release before moving to general market availability. This phase is called Limited Availability (LA).
End of Software Development (EoSD)The date F5 declares the end of development and bug fixes for the product, which includes fixes to security vulnerabilities. EoSD generally occurs from one to three years after the Introduction date, based on the type of release and the version of the product.
End of Technical Support (EoTS)The date when F5 no longer offers technical support or consulting services for the specific release of a software product. This usually coincides with EoSD.

BIG-IP Next software version schema

F5 ties the Standard Support phase timeline to versions of BIG-IP Next software products.

The BIG-IP Next product release version schema consists of the product name followed by a simplified three-digit structure, representing the level of change and the support duration.

Figure 1 BIG-IP Next software version schema

With BIG-IP Next, F5 has an annual Long Term Support (LTS) release model that is interspersed with multiple minor releases, known as Short Term Support (STS) releases.

Definitions for the BIG-IP Next version schema are in the following table.

Table 2 BIG-IP Next software version schema definitions
Release typeVersion schemaDefinition
Major releaseBIG-IP-Next-xIncludes significant changes in behavior, added functionality, significant increases in performance, new hardware support, and/or significant architectural changes.
Minor releaseBIG-IP-Next-x.xIncludes added functionality, increase in performance, new hardware support, and addresses product defects.
Patch releaseBIG-IP-Next-x.x.x
  • Is a full release.
  • Addresses product defects, including the hardening and refining of existing features and security fixes, and may contain minor functional improvements and new hardware support.
  • Does not introduce a change in existing default behavior.
  • Included in Major versions they are associated with, you do not need to reactivate a license when updating to a Patch release.
  • Includes multiple fixes for significant software defects discovered since a Minor release.
  • Receives the same level of testing as a Minor release.
  • Is available from MyF5 Downloads.
F5 periodically provides Patch releases for:
  • Major releases within their Standard Support phase.
  • The latest Minor release of each Long-Term Support (LTS) release.
Short Term Support (STS) releaseBIG-IP-Next-x.x.x
  • EoSD and EoTS generally occur six months from the release or three months from the next STS release, whichever is longer.
  • Usually occurs on a quarterly basis and includes backwards compatible feature additions, enhancements, and bug fixes.
  • Enables F5 to respond to new feature requirements more rapidly.
  • Enables customers who upgrade more frequently to get the latest features sooner.
Long Term Support (LTS) releaseBIG-IP-Next-x.x.x-LTS
  • EoSD and EoTS generally occur three years after Introduction.
  • Usually released on an annual basis.
  • Has an explicit LTS moniker suffixed to the version.
  • Has a Patch version number incremented, based on the scope and extent of change.

Important: Software development support activities within the Standard Support phase (from Introduction to EoSD), such as bug fixes, occur only on the latest Patch release. F5 recommends that you deploy and adopt the latest Patch release of any version.

Note: For more information about specific releases, such as release date and supported platforms, refer to K9412: The BIG-IP release matrix.

BIG-IP Next software supported by this policy

There are no longer any BIG-IP Next software versions supported under this policy because BIG-IP Next has been discontinued. For more information, refer to K000152956: BIG-IP strategic update: Modernizing BIG-IP TMOS and discontinuing BIG-IP Next.
