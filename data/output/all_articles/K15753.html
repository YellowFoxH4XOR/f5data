Known Issue

Using the Configuration utility to modify the port lockdown feature's values, from Allow All to Allow Default, may result in an error.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system applies to any versions between 11.4.1 HF2 and 11.5.1 HF5.
  • From Network > Self IPs, you have changed the setting in the port lockdown feature from Allow All to Allow Default.
  • After changing the setting, the port lockdown feature remains configured as Allow All.
  • You attempt to change port lockdown from Allow All to Allow Default a second time, and then click Update.

Impact

You are unable to modify port lockdown using the Configuration utility, and the setting remains configured as Allow All.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your second attempt to update the setting from Allow All to Allow Default may cause an error message in the Configuration utility that appears similar to the following example:

    01020066:3: The requested self port (/Common/v172_10.10.172.100 256 0) already exists in partition Common.
  • The MCP daemon may generate an error message in the /var/log/ltm file that appears similar to the following example:

    01020066:3: The requested self port (/Common/v172_10.10.172.100 256 0) already exists in partition Common.
  • After you observe the error message, if you refresh the setting of the affected self IP using the Network > Self IPs Configuration utility menu, you observe that port lockdown remains configured as Allow All.

Workaround

To work around this issue using the Configuration utility, you can set the Port Lockdown setting to Allow None first, then set it to Allow Default. To do so, perform the following procedure:

Impact of workaround: The following procedure restricts available ports for the self IP and may interrupt existing connections to the self IP.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Self IPs
  3. Click the name of the self IP to modify.
  4. In the Port Lockdown menu, select Allow None.
  5. Click Update.
  6. In the Port Lockdown menu, select Allow Default.
  7. Click Update.
