Description

You want to view and/or search attack signatures for specific security policies on BIG-IP ASM

  • List and search through attack signatures on BIG-IP ASM

Environment

  • BIG-IP with ASM module provisioned.
  • One or more Security Policies configured.
  • You have access to the Configuration Utility with correct role set to view and modify security policies.

Cause

The below steps describe some of the methods used to list and search attack signatures using the configuration utility in BIG-IP ASM/Adv. WAF versions 13.x - 16.x. 

Recommended Actions

BIG-IP ASM version 16.x:
Option #1
1.) Navigate to Security --> Options --> Application Security --> Attack Signatures --> Attack Signatures List
2.) Click the filter icon to search attack signatures via name, ID, attack type or other search criteria.
Option #2
1.) Navigate to Security -> Application Security -> Security Policies -> Policies List
2.) Click on desired security policy.
3.) Click "Attack Signatures" to view attack signatures associated with the chosen security policy. 
4.) Click the filter icon to search attack signatures via name, ID, attack type or other search criteria. 

BIG-IP ASM version 15.x:
Option #1
1.) Navigate to Security --> Options --> Application Security --> Attack Signatures --> Attack Signatures List
2.) Click "Show Filter Details" to search attack signatures using specific search criteria, like Containing String, Signature ID, Signature Type, Signature Scope, etc...
Option #2
1.) Navigate to Security -> Application Security -> Security Policies -> Policies List
2.) Click on desired security policy.
3.) Click "Attack Signatures" to view attack signatures associated with the chosen security policy. 
4.) Click the filter icon to search attack signatures via name, ID, attack type or other search criteria. 

BIG-IP ASM version 13.x - 14.x:
Option #1
*Note: make sure to be in the desired security policy before making changes.
1.) Navigate to Security --> Application Security --> Attack Signatures
2.) Click "Show Filter Details" to search attack signatures using specific search criteria, like Containing String, Signature ID, Signature Type, Signature Scope, etc...
Option #2:
1.) Navigate to Security --> Options --> Application Security --> Attack Signatures --> Attack Signatures List
2.) Click "Show Filter Details" to search attack signatures using specific search criteria, like Containing String, Signature ID, Signature Type, Signature Scope, etc...

Additional Information

For information on displaying attack signatures using the CLI or iControl REST see article K11680: Displaying attack signature sets on BIG-IP ASM systems.
