K000132974: Verification of CRL file signatures which can't be verified using the CA file in SSL profile can raise TMM CPU usage

Type
Support Solution
Published
2023-03-14
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000132974

Description

 

Verification of CRL file signatures which can't be verified using the supplied CA file can drive higher TMM CPU usage on Big-IP.

 

 

Environment

 

BIG-IP, SSL profile, CRL file in use.

 

 

Cause

 

When a CRL file is attached to an SSL profile, the CRL file signature is verified using the CA file when the CRL file is loaded by SSL. If the signature cannot be verified, then an attempt is made during each SSL handshake to verify CRL. This is quite expensive as regards TMM CPU, and can be a driver of high TMM CPU usage on Big-IP.

 

 

Recommended Actions

 

Ensure that all CRL file signatures can be verified using the CA file when loading a CRL file in an SSL profile.

 

 

Additional Information

 

Further to this, if the CRL file has a bundle of multiple separate CRL files, then each one must be independently verified. If even one fails, then they are all are perceived to fail by TMM.
