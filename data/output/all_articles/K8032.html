K8032: URLs that contain query parameters defined within a WSDL file are not applied to the policy when imported

Topic

When a Web Services Description Language (WSDL) file is imported or uploaded to the BIG-IP ASM system, an option is available to add the URL of the service as an allowed object to the policy. If the URL of the service within the WSDL file includes a query parameter, the BIG-IP ASM system does not automatically add the parameter to the policy. This behavior is by design.

F5 Product Development is tracking a Request For Enhancement (RFE) for this behavior as ID 309869 (formerly CR86334).

Workaround

To work around this behavior, you can manually apply the parameter portion of the URL to the policy. To view or add parameters to the policy, perform the following procedure:

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Select Learning.
  3. Select Violations.
  4. Select Illegal parameter from the Input Violations section of Traffic Learning.
  5. Review the parameters you want to allow, and click Accept.
