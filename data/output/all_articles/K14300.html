Summary

The ARX system policies may fail when they encounter filenames that use a mixture of half-width and full-width Katakana characters.

Description

When the ARX system converts the half-width and full-width Katakana characters for use in filename comparison, if the policy ignore-case€� option is selected, the ARX system is unable to match these characters correctly when the evaluated file or directory name uses a mixture of full-width and half-width characters.

Recommendations

When attempting to run a policy against a file or directory that may use a mixture of half-width and full-width Katakana characters, the fileset should match the required name of the requested targets, as closely as possible. In the event of possible mixed full-width and half-width Katakana names, F5 recommends that you use a filename fileset that specifies all full-width or all-width half characters. In addition, ensure that you do not select the ignore-case option. 

When creating a new place-rule, the tentative option allows you to estimate the exact behavior of the created fileset.

The following is an example policy without the ignore-case option:

policy-filename-fileset
path exact //
name match *
recurse
tentative
exit
