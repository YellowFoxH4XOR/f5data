Description

After upgrading from v14.0.x or earlier version to v14.1.x and later version, BIG-IP mark nodes/pools down when they are associated with external monitors.

Environment

  • BIG-IP
  • External Monitors
  • HTTPS
  • Curl used in the script
  • Recv string '200 OK'

Cause

  • The backend server supports HTTP/1.1 and HTTP/2.
  • From v14.1.x, curl utility is compliled with nghttp2.

Recommended Actions

  • change recv string to '200' only.

Additional Information

External monitors based on curl uses ALPN during TLS handshake to negotiate upper layer protocol.
You can check with similar to the below command how the backend server response, when both protocol is supported.

curl -vk --resolve my.example.com:443:192.0.2.50 https://my.example.com/test
* Added my.example.com:443:192.0.2.50. to DNS cache
*   Trying 192.0.3.61...
* Connected to my.example.com (192.0.3.61) port 443 (#0)
* ALPN, offering h2
* ALPN, offering http/1.1
