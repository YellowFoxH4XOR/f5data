Known Issue

Description

SSL Renegotiation may fail on BIG-IP VE and BIG-IP 2000/4000 series platforms.

This issue occurs when all of the following conditions are met:

  • The Proxy SSL feature is enabled for the Client SSL and Server SSL profiles.
  • The SSL client or server attempts to renegotiate an existing SSL connection.

Impact

Users are unable to use SSL renegotiation in conjunction with the BIG-IP Proxy SSL feature.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H427617 on the Diagnostics > Identified > Medium screen.
  • Client certificate authentication fails.
  • The SSL client connection resets.
  • If the TMM log level is set to Informational, you observe messages similar to the following examples in the /var/log/ltm file:

    SSL Handshake failed for TCP from 10.10.1.10:57113 to 10.10.2.10:443
    SSL Handshake failed for TCP from 10.10.1.10:57113 to 10.10.2.10:443
    SSL Handshake failed for TCP from 10.10.1.10:57113 to 10.10.2.10:443
