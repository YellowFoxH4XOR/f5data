K000133610: Unable to pull istio-cni image in kube-system namespace

Type
Support Solution
Published
2023-04-21
Updated
2023-07-18
Applies to
  • Aspen Mesh: 1.14
Source
https://my.f5.com/manage/s/article/K000133610

Description

Unable to pull istio-cni image with error code "Failed to pull image "quay.io/aspenmesh/carrier-grade-releases:install-cni-1.14.6-am1": rpc error: code = Unknown desc = reading manifest install-cni-1.14.6-am1 in quay.io/aspenmesh/carrier-grade-releases: unauthorized: access to the requested resource is not authorized".

 

Environment

Aspen Mesh 1.14.x

 

Cause

Image pull secret name for istio-cni got changed in version 1.14.x to aspen-mesh-cni-pull-secret

 

Recommended Actions

Make sure there's a secret named aspen-mesh-cni-pull-secret in the kube-system namespace when installing istio-cni. In past releases this secret was named aspen-mesh-pull-secret. The contents of the secret are the same therefore you can copy the secret and change the name if needed.

Likewise, you can install Aspen Mesh and istio-cni from scratch following this guide .
 

Additional Information

A Kubernetes cluster uses the Secret of kubernetes.io/dockerconfigjson type to authenticate with a container registry to pull a private image.
