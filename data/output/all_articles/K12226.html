Known Issue

This is the result of a known issue. The EUD may incorrectly report the Mezzanine Xaui test as FAILED.

This issue is a rare occurrence that is only reported on the BIG-IP 6900 and BIG-IP 8900 platforms, and may only be reported after several iterations of EUD checks are performed.

The EUD failed reports appear similar to the following example:

Note: The test may also report other components as FAILED, as displayed in the example test.

********** Mezzanine Xaui Test Started**********
 
Test Begin: Mezzanine Xaui Test
This test takes approximately one minute
Test Complete: Mezzanine Xaui Test: FAILED

******************* TEST SUMMARY *****************
21 Mezzanine Xaui Test: FAILED

Test Complete: AOM I2C Test: FAILED

Test Complete: Host I2C Test: PASSED
Test Complete: I2C Test: FAILED


Test Complete: Host I2C Test: PASSED
Test Complete: I2C Test: FAILED

To check if the test status reported is incorrect, run the Mezzanine Xaui test again. If the test status reports PASSED, nothing is wrong with the Xaui port on the system.

If the EUD consistently reports a FAILED status after multiple consecutive tests, there may be an issue with the system. For more information, contact F5 Technical Support.

The cause of the false test status is due to the EUD test not taking into account the voltage range the port is allowed to utilize. The EUD test looks for one specific value returned. If that value is not seen, the results are reported as FAILED.

F5 Product Development is tracking this issue as ID 342407.
