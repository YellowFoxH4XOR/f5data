K11760: Loading a configuration on a BIG-IP WebAccelerator enabled system may cause the system to reprovision the size of the /wam partition

Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator specifies a minimum of 4GB and a maximum of 12GB for the /wam disk partition. Each time a configuration is loaded using the bigpipe load command, the system runs the provisioning process and may erroneously reprovision the /wam partition. As a result, the BIG-IP WebAccelerator system performance may be negatively affected.

F5 Networks Product Development is tracking this issue as CR141663 and ID 238533.
