Known Issue

A child health monitor incorrectly inherits the parent health monitor's password.

This issue occurs when the following condition is met:

  • You create a child health monitor that inherits from a parent health monitor with a password configured.

Impact

Health monitoring can fail if the monitored pool member doesn't accept the inherited password during authentication.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • A health monitor fails for an available pool member.
  • A heath monitor shows an unintended password in the configuration.

Workaround

To work around this issue, create a parent monitor which contains no password and then apply passwords to the child monitors only.
