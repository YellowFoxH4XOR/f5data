Known Issue

The BIG-IP system may drop packets when the TCP profile's Selective NACK option is enabled and TCP SYN cookie protection is active.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration has a virtual server that references a TCP profile with the Selective NACK option enabled.

    Note: This option is disabled by default.

  • The virtual server's TCP SYN cookie threshold has been reached, and TCP SYN cookie protection is active.
  • The BIG-IP system receives a client SYN packet without the Selective NACK option.

Impact

The BIG-IP system experiences additional network congestion and possible connection failures.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client connections are slower, and may fail through certain virtual servers.
  • When viewing packet captures, you notice that additional TCP retransmissions are causing network congestion.

Workaround

To work around this issue, you can disable the Selective NACK option in the TCP profile. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > TCP.
  3. Click the name of the TCP profile with Selective NACK enabled.
  4. From the Loss Detection and Recovery section, clear the Selective NACK check box.
  5. Click Update.
