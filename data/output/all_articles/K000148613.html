Description

The F5 ASM module is sending large request logs to the SIEM server. Due to a recent configuration change on the server, these logs are being truncated or displaying anomalies, which impacts log interpretation and monitoring systems.

Environment

  • F5 Application Security Manager (ASM)
  • Log Truncation and maximum-entry-length setting

Cause

The maximum-entry-length was reduced from 64k to 2k to address temporary display issues on the remote server. This change is leading to:

  1. Log truncation for events exceeding 2k.
  2. Missing or incomplete log entries, affecting local devices and the SIEM system.

Recommended Actions

  1. Temporary Fix: Restore maximum-entry-length to 64k to ensure complete logs are sent. Apply log filtering to manage size if server display issues persist.
  2. Long-Term Solutions:
    • Optimize logging configuration to capture essential data.
    • Work with the SIEM vendor to handle larger logs or parse truncated entries.
  3. Monitor log integrity and completeness after any configuration changes.

Additional Information

  • Increasing maximum-entry-length to 64k resolves truncation but may still require adjustments for the SIEM.
  • Engage with F5 Support if issues persist after configuration updates.
  • The observed behavior is standard for logging systems and not specific to F5 devices.
