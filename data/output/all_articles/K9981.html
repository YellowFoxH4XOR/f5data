Known Issue

This is the result of a known issue. The BIG-IP ASM logging profile uses comma separated string fields for the Reporting Server Storage Type; however, the Logging Profile Storage Type should use a key=value format.

F5 Networks Product Development tracked this issue as CR115082 and it was fixed in BIG-IP ASM version 10.0.1. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, this issue was fixed in BIGIP-10.0.0-5514.0-HF2 for BIG-IP version 10.0.0. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes on systems with a logical volume management (LVM) disk-formatting scheme, refer to K10025: Managing F5 Networks product hotfixes for BIG-IP version 10.x systems. For information about installing version 10.x hotfixes on systems with a partitioned disk-formatting scheme, refer to K9819: Installing a BIG-IP version 10.x hotfix on a partitioned system.
