K000135943: Process monpd not running

Type
Support Solution
Published
2023-08-23
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.0
  • BIG-IP AFM: 13.1.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.0
  • BIG-IP ASM: 13.1.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.0
Source
https://my.f5.com/manage/s/article/K000135943

Description

  • monpd down (unable to start)
  • System logs messages on /var/log/daemon file indicating that the monpd process keeps on restarting
     emerg logger: Re-starting monpd

Environment

  • LTM and AFM or ASM provisioned
  • AVR not provisioned

Cause

/appdata has 0% free space

Recommended Actions

Clear and reset the AVR database:

Impact: Clearing AVR database will remove all existing statistics data.

1. Stop the monpd daemon:

tmsh stop /sys service monpd

2. Delete all files from the below location:

rm -f /var/lib/mysql/AVR/*

3. Create the below file to re-initiate AVR:

touch /var/avr/init_avrdb

4. Restart mysql and monpd:

tmsh restart /sys service mysql

tmsh restart /sys service monpd

Additional Information

None
