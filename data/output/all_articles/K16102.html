Known Issue

Running qkview from the primary blade on a VIPRION system that has more than one blade installed does not produce qkview output for secondary blades.

This issue occurs when all of the following conditions are met:

  • You are running a VIPRION system with more than one blade installed.
  • You are attempting to run the qkview diagnostic and require output from each blade.

Impact

No qkview files are produced for any secondary blades.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Running the qkview command only produces one output file for the primary blade.

Workaround

To work around this issue, you can run the qkview command on each individual blade.

Impact of Workaround: Performing this workaround should not have a negative impact on your system.
