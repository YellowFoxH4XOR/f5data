Description

iQuery failure after failover of a network device such as a Firewall between the GTM and LTM

Error message when running iqdump command:

SSL error:14090086:SSL routines:SSL3_GET_SERVER_CERTIFICATE:certificate verify failed

 

Environment

  • BIG-IP DNS
  • iQuery connection failure

Cause

The iQuery connection can continue to use the old device certificate until big3d or gtmd has been restarted, or network connectivity breaks the connection (such as failover of a network device) in which case the TLS connection will need to be established again. If the new certificate is not trusted then the connection will fail.

Recommended Actions

See K9467: Error Message: SSL routines: SSL3_GET_SERVER_CERTIFICATE:certificate verify failed
