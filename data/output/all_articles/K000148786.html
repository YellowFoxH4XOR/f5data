Description

When deploying web applications using Modern mode inside Rewrite Control List (as per K000130439), it will tell the BIG-IP to provide cache-fm-Modern.js file to browsers for rewriting purposes.

From time to time, applications content may not be rewritten properly, requiring fixes that will be provided by F5 support in the form of an updated version of the default cache-fm-Modern.js file.

This article aims to provide the most recent version of that file, including the most interesting fixes that would benefit all applications, instead of having to wait for a more recent release of BIG-IP to include them.

If you're running into some rewrite issues for a given web application in Modern mode, we suggest trying the cache-fm-Modern.js file version from this article prior to opening an F5 support case.

Environment

  • Portal Access
  • Application is failing even though it is configured with Modern mode in the rewrite profile attached to the Virtual Server

Cause

  • Applications may be running into known rewrite issues

Recommended Actions

In order to use the latest version of the cache-fm-Modern.js file, the below procedure will create an iFile and then an iRule that will make use of it when attached to the Virtual Server used to access the Web Application via Portal Access:

  1. Download the following file:
    Latest-cache-fm-Modern.txt
  2. Import the downloaded file as an iFile on the BIG-IP:
    1. System --> FileManagement --> iFile List --> Import
    2. In File Name, browse to retrieved "Latest-cache-fm-Modern.txt" file
    3. Under Name, use:  file-cachefm
  3. Create an iRule "iFile" object that uses the above Imported "iFile" object, and which is referenced by the above iRule:
    1. Local Traffic --> IRules --> iFile List --> Create
    2. Name:  LatestModernCachefm
    3. File Name:  file-cachefm
  4. Create the below iRule, and attach it to the VS:

# This iRule is from MyF5 article K000148786 when CLIENT_ACCEPTED { ACCESS::restrict_irule_events disable } when HTTP_REQUEST { if { [HTTP::has_responded] } { return } if { [HTTP::path] ends_with "cache-fm-Modern.js" } { HTTP::respond 200 content [ifile get LatestModernCachefm] "Content-Type" "application/javascript" "Cache-Control" "max-age=3600" return } }

Note: this cache-fm-Modern.js file was derived from version 17.5.1.5 and is backward compatible with previous version.  This file has additional fixes included. 
Note: It is recommended to upgrade to the latest APM version to see if the issue is resolved before applying this iRule/iFile.
