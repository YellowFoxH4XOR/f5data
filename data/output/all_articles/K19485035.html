Issue

Error Message

err bcm56xxd[<PID>]: 012c0011:3: <BCM56XXD SDK error>

In this error message, note the following:

  • <PID> is the process ID.
  • <BCM56XXD SDK error> is the message describing the problem encountered by the bcm56xxd process.

For example:

err bcm56xxd[6560]: 012c0011:3: SDK error Entry not found bs_trunk.cpp(2309)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The Broadcom SDK library encounters an error condition when executing a command from the bcm56xxd process on the BIG-IP system.

While this message rarely occurs, it typically indicates a critical error that prevents proper configuration of the Broadcom switch.

Impact

The error may negatively impact traffic processing and statistics reporting on the BIG-IP system.

Recommended Actions

  • You may be able to work around this issue by restarting the bcm56xxd process using the bigstart restart bcm56xxd command or by rebooting the BIG-IP system.
  • If traffic is still affected after restarting the bcm56xxd process or rebooting the unit, you should run the End-User Diagnostics (EUD) utility and provide the diagnostic report to F5 Technical Support.
