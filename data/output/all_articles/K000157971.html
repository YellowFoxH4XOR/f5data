Topic

This article discusses the end of technical support for BIG-IP APM network access, VPN on 32-bit Linux client operating systems (OS) beginning from APM Clients 7.2.7. This includes

  • BIG-IP Edge Client on Linux, f5fpc
  • BIG-IP APM network access, VPN via browser on 32-bit Linux OS

For more information, refer to APM Client 7.2.7 release notes.

Description

After evaluating industry trends and decisions made across the Linux OS distribution landscape F5 announced the discontinuation of 32-bit Linux support sometime back in the APM Edge Client Compatibility matrix. In APM Clients 7.2.7, F5 will remove the 32-bit binaries from client ISO images.

This impacts the following client downloads from the BIG-IP Configuration utility (Go to Access > Connectivity / VPN > Connectivity > Client Downloads):

  • BIG-IP Edge Client components
    • Command Line Client for Linux ( linux_f5cli.armhf.deb )
    • Command Line Client for Linux ( linux_f5cli.x86_64.deb )
    • Command Line Client for Linux ( linux_f5cli.x86_64.rpm )
  • Browser components for Linux
    • F5 Endpoint Inspector for Linux ( linux_f5epi.x86_64.deb )
    • F5 Endpoint Inspector for Linux ( linux_f5epi.x86_64.rpm )
    • F5 VPN for Linux ( linux_f5vpn.x86_64.deb )
    • F5 VPN for Linux ( linux_f5vpn.x86_64.rpm )

Recommendation

To ensure uninterrupted service and compatibility, F5 recommends you plan and implement in advance the transition of all 32-bit Linux clients in your environment to 64-bit clients.
