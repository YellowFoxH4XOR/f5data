Known Issue

This is the result of a known issue. If you have enabled the Display Host Names When Possible option, the BIG-IP system Configuration utility may fail to display the Route Domain ID of those objects that reside in non-default route domains. For example, the 10.0.0.10%20 virtual server will be displayed as 10.0.0.10 only.

You can safely ignore this issue, as it does not affect traffic.

Note: When enabled, the Display Host Names When Possible option specifies that if the IP address has an associated host name, the system displays host names rather than IP addresses. The default is disabled. This option is located in the Configuration utility under System > Preferences.

F5 Product Development tracked this issue as ID 223443 and ID 247710 (formerly CR129786) and it was fixed in BIG-IP LTM 11.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Note: For more information about route domains, refer to the TMOS Management Guide for BIG-IP Systems and BIG-IP LTM Implementations guides.
