Description

I have an HTTP Load Balancer with 2 Origin Pools and I want to distribute the load between them on a different ratio than the standard one

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Cause

  • None

Answer/Recommended Actions

To configure the load ratio of your Load Balancer:

Example: You have to configure a route match with two origin pools with a weight of 6 and 4 (you can select the weights) respectively. The values refer to the ratio the system uses to determine the proportion of traffic that is distributed to each pool. Another example is when you set the weight to 0, it disables the pool.

1. Got to HTTP Load Balancer configuration > Routes > Add Item

2. Under Route Type select Simple Route

3. Go to Origin Pools

4. Click Add Item

7. Under Select Origin Pool Method select Origin Pool

8. Under Origin Pool select your Origin Pool

9. Under Weight add the weight you want to give your Origin Pool

10. Under Priority choose the priority

 

 

Additional Information

You can also consider using some of the predefined algorithms from the load balancer section:

  1. Round_Robin
  2. Least_Request
  3. Ring_Hash
  4. Random
  5. Load Balancer Override.
