Issue

Error Message

01100042:3: Failed with MCPD at: <error> (<error_code>)

In this error message, note the following:

  • <PID> is the process ID for the alertd process
  • <error> is a message describing the communication error
  • <error_code> is an internal error code

For example:

err alertd[3194]: 01100042:3: Failed with MCPD at: MCP msg receive (16908291)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The alertd process has encountered an inter-process communication error with the mcpd process.

Impact

Non-repeating Socket read messages are likely caused by temporary congestion and should not have a long-term impact.  

The following messages indicate the alertd process failed to initialize properly, which may prevent the BIG-IP system from generating alerts and their associated SNMP traps:

  • Connect
  • Subscribe
  • MCP msg receive
  • Socket/pipe select
  • Socket error event
  • syslog pipe error event
  • errdefs socket error event

Recommended Actions

Check to ensure the alertd and mcpd processes are in the run state by executing the bigstart status alertd mcpd command from the BIG-IP system command line. If either process is not in the run state or the error messages persist over time, restart the process using the bigstart restart alertd or bigstart restart mcpd command.
