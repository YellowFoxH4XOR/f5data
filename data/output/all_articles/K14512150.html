Description

When performing an upgrade on a VELOS chassis, both the Controllers and the Partitions can be upgraded. However, should the Controllers be upgraded first or the Partitions?

Environment

  • VELOS
  • F5OS-C

Cause

Not applicable

Recommended Actions

F5 recommends using Bundled upgrade, which includes both the base OS and service components, in the following order:

  1. Controller
  2. Partition

For more information about the base OS and service components of the software image, refer to K62132391: Display the F5OS-C software version on the VELOS system
