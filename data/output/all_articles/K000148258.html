K000148258: After upgrading vCMP Host and vCMP Guest, Host still shows that Guest is running on the software version before the upgrade.

Type
Support Solution
Published
2024-12-03
Updated
2024-12-03
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000148258

Description

Wrong (old/pre upgrade) vCMP Guest version number seen on vCMP Host after the vCMP Guest upgrade.

Environment

BIG-IP vCMP HOST/GUEST

Cause

unknown

Recommended Actions

Workaround:

  • on vCMP Host, take the affected vCMP Guest to 'Configured' state, and check the output from:

           show /vcmp health software

 

  • change the state back to 'Deployed', and check again the output from:

           show /vcmp health software

 

  • log into the Host GUI and verify the vCMP Guest status have been corrected.
