K2566: Reasons why a rule that matches IP addresses in a class may not work properly

Topic

When you define classes for checking HTTP headers, you must use a string class type.

The host header can contain a name or an IP address, but that IP address is only an ASCII representation. The IP address should still be treated as a string, or the iRule will not work.

You can configure the IP address string through the Configuration utility or the command line.

Configuration utility

To configure the IP address string using the Configuration utility, perform the following steps:

  1. From the navigation pane, click Rules.
  2. Click the Classes tab at the top of the screen.
  3. Click Add.
  4. Type class name for the rule in the Class Name box.
  5. From the Class Type menu, select Strings.
  6. Finish configuring the rule as normal.

Command line

To configure the IP address string through the command line:

  1. Use the following command syntax (note the required quotes around the fields):

    class good_class {
    "10.0.0.1"
    "10.0.0.2"
    "10.0.0.3"
}
  2. Save the string class in the bigip.conf file.

Note: For additional information, refer to the iRules chapter in the BIG-IP Reference Guide.
