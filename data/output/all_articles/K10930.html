Topic

Starting in FirePass versions 6.0.3 and 6.1.0, if Active Directory is the primary authentication method for a master group, users in that master group can change their Active Directory passwords from the FirePass webtop. To do so, users can perform the following procedure:

Important: Updating the Active Directory password from the FirePass webtop does not update the Windows cached credentials on the client system. If the client system is joined to a domain, the user may want to update the cached credentials by performing the procedure provided in K11195: The Windows cached credentials are not updated when the Active Directory password is changed.

Note: If Active Directory is configured as the secondary (backup) authentication method, this procedure cannot be used to change the Active Directory password.

  1. Logon to the FirePass webtop.
  2. In the right navigational pane, click Tools.
  3. Click Account Details.
  4. Select the Change Password link.
  5. In the Current Password field, enter the current Active Directory password.
  6. In the New password and Confirm new password fields, enter the new Active Directory password.
  7. Click the Update button

If the password update was successful, FirePass displays the following message:

Password changed successfully

Troubleshooting the "Password reset failed" error message

A user will receive the Password reset failed error message if one or more of the following conditions have been met:

  • The user does not have sufficient Active Directory privileges to change the password
  • The user entered the wrong password in the Current password field
  • The hostname configured in the Kerberos server name field does not match the Full computer name configured on the Active Directory server

    Note: The Kerberos server name field is located on the Users : Groups : Master Groups page under the Authentication tab.

Disabling the Active Directory password change feature

By default, users are able to access the Account Details tool on the webtop. To disable this feature, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users : Groups : Master Groups page.
  3. Select the name of the master group you want to configure.
  4. Select the User Experience tab.
  5. In the Account Details row, select the Don't Use option button.
  6. Click the Update button.

The Account Details tool no longer appears under the webtop Tools menu for users in that master group.
