Environment

  • vCMP Host
  • mysql
  • Upgrade
  • localdbmgr

Cause

The database volume that mysql uses can not be created due to insufficient disk space and this prevents monpd from starting.
This issue can occur after an upgrade or after a reboot when disk space is low.

Recommended Actions

1. Delete any unused volume partitions from the system, first list all available images with the "tmsh show /sys software" command:

tmsh show /sys software
--------------------------------------------------------
Sys::Software Status
Volume Slot Product Version Build Active Status
--------------------------------------------------------
HD1.1 2 BIG-IP 14.1.4 0.0.11 yes complete
HD1.2 2 BIG-IP 14.1.2.6 0.0.2 no complete


2. To delete the unused volume use the command "delete /sys software volume <volume>". For instance, to delete volume HD1.2, the command is "delete /sys software volume HD1.2"

3. After deleting the unused volumes run the command "bigstart restart localdbmgr". In the event that the command is ineffective, please reboot the chassis by running the "clsh reboot" command.
