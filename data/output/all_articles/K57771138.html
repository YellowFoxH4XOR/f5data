Topic

You should consider using this procedure under the following condition:

  • You want to modify or create a BIG-IP configuration using the BIG-IQ user interface.

Description

BIG-IQ Centralized Management provides a central point of control for monitoring and configuring BIG-IP physical and virtual devices.

This article will cover the basic steps to create or modify a BIG-IP configuration, and to deploy the BIG-IP configuration from the BIG-IQ system to the destination BIG-IP device.

Prerequisites

You must meet at least one of the following prerequisites to use these procedures:

  • You have administrator access credentials for the BIG-IQ system.
  • The BIG-IQ system discovers and manages the destination BIG-IP device.

Procedures

  • Modifying a BIG-IP configuration object
  • Creating a new configuration deployment 
  • Deploying a new configuration or configuration object modifications

Modifying a BIG-IP configuration object

To modify a BIG-IP system configuration object, perform the following procedure:

Impact of procedure: Performing the following procedure should have a negative impact on your system.

  1. Log in to the BIG-IQ user interface.
  2. Click the Configuration tab.
  3. In the Local traffic section, select the configuration object that you want to modify. For example, when selecting the configuration object, Virtual Servers, a list of all configured virtual servers for the managed BIG-IP device will display.
  4. Modify the desired properties of the configuration object.
  5. Click Save.
  6. To deploy the configuration modification, perform the Deploying a new configuration or configuration object modifications procedure.

Creating a new configuration deployment          

To create a BIG-IP system configuration object, perform the following procedure:

Impact of procedure: Performing the following procedure should have a negative impact on your system.

  1. Log in to the BIG-IQ user interface.
  2. Click the Deployment tab.
  3. Select the Local Traffic and Network deployment option.

    The right pane will display the option to create a new Evaluation deployment.

  4. Under Evaluation, click Create.
  5. Under General Properties, enter a name for the deployment in the Name text box.
  6. (Optional) Provide a description of the deployment in the Description box.
  7. From the list of BIG-IP devices, select the appropriate BIG-IP device name and move it to the right.
  8. Click Save.
  9. To deploy the configuration modification, perform the Deploying a new configuration or configuration object modifications procedure.

Deploying a new configuration or configuration object modifications

To deploy a new or modified BIG-IP system configuration object, perform the following procedure:

Impact of procedure: Performing the following procedure may have a negative impact on your system if the created or modified configuration objects conflict with the expected behavior for your deployment environment.

  1. Log in to the BIG-IQ user interface.
  2. Select the check box next to the newly created deployment.
  3. To deploy the object, select the Deploy tab.
  4. A dialog box prompts for confirmation. To deploy the configuration changes, click Deploy.

    Once the deployment is complete, the user interface displays the Deployment complete status.
