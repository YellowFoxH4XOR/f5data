Known Issue

The BIG-IP PSM Statistics page should count the total number of FTP requests sent over a connection. Instead, the BIG-IP PSM system counts transactions based on TCP connections instead of FTP requests. For example, an FTP session consisting of 10 FTP commands sent over a single TCP connection is counted as one transaction on the Statistics page instead of 10.

F5 Product Development is tracking this issue as ID 309710 (formerly CR111889).
