K07347450: Default LDAP monitor not working due to missing filter

Type
Support Solution
Published
2022-10-25
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 16.1.X, 16.0.X, 16.1.0, 16.0.1, 16.0.0, 16.X.X, 16.1.2, 16.1.1, 16.1.3
Source
https://my.f5.com/manage/s/article/K07347450

Description

Certain LDAP servers may respond to search requests sent by a default LDAP monitor with an unsolicited notification error similar to the following: ExtendedResp(0) decoding attrs error.
This unsolicited notification is not a response to any LDAPMessage received by the server. It is used to signal an extraordinary condition in the server or in the connection between the client and the server. The notification is of an advisory nature, and the server will not expect any response to be returned from the client.

Environment

  • BIG-IP LTM
  • LDAP monitor

Cause

Even though the K17472 article specifies the filter configuration setting is not required, certain LDAP servers require the filter setting to be able to respond to search queries sent by the monitor.

Recommended Actions

Insert a presence filter in the LDAP monitor settings that will match any entry that contains one or more cn values.

Example: cn=*

Additional Information

None.
