Known Issue

This is the result of a known issue. BIG-IP will report the following message in the /var/log/bigip file if you have VLAN mirroring configured:

/config/bigip_base.conf: "Probe control features are not available"

This problem is cosmetic and does not have an affect on system performance.

F5 Networks Product Development tracked this issue as CR29744 and CR41792.
