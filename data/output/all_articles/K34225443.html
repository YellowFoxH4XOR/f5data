Description

  • Building APM Policy
  • Virtual Policy Editor (VPE) Message Box object only supports click to continue
  • When creating an APM Policy, there is no obvious way to display a message with a timeout

Environment

  • APM VPE

Cause

This is the default behaviour of a VPE Message Box object

Recommended Actions

If the policy is using "Standard"  Customization, then:

The VPE Message Box object accepts HTML as its message content. JavaScript content can be used to add a message timeout.

  1. Navigate to and open the Visual Policy Editor for the Access Policy.
  2. Select the Branch & location on that Branch where the message box is to be added, and click the "+" (plus) button to insert a new object in that location.
  3. From the pop-up window, click the General Purpose tab, select the Message Box object and click the Add Item button.
  4. In the Message Box's Properties page, add the Message content:
About to start next action
<script>
var checkExist = setInterval(function() {
    if (document.body.contains(document.getElementById("interaction_table_header"))) {
       clearInterval(checkExist); SubmitResult(1); return 1;
    }
}, 5000); // check every 5000ms
</script>
  1. Click the Save button to add the Message Box to the Access Policy.
  2. Then click the Apply Access Policy link at the top of the Visual Policy Editor to put the new version of the Access Policy into use.

The Access Policy will display "About to start next action", and after 5000 millseconds continue to the next object in the VPE policy.
The message text and timeout can be modified to suit.

 

If the policy is is using "Modern" Customization, then script cannot be added to the message box.

Instead go into advanced customization menu and drill down to the message box you want to interact with and add this code in the "user-message.js" file.


var checkExist = setInterval(function() {
if (document.body.contains(document.getElementById("continue"))) {
clearInterval(checkExist);

document.getElementById("continue").click();
}
}, 5000); // check every 5000ms

Then "Save Draft", then "Save" and finally apply the access policy.

 

With Modern Customization its possible to hide the button.

Add this code in the "user-message.css" file.

.apmui-button-submit {
    background-color: #1D9CD3;
    color: #FFFFFF;
    visibility: hidden;
}
