K000150382: Unable to create CSR under Authentication & Access > TLS Configuration with a SAN other than "none"

Type
Support Solution
Published
2025-03-13
Updated
2025-03-13
Applies to
  • F5OS
  • F5OS-C: 1.8.X, 1.8.0
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000150382

Description

"Unable to create CSR. See error log for details.", when attempting to create a CSR with a SAN value other than 'none'.

Unable to create CSR for the self-signed certificate. See error log for details.
error-type : application
error-tag : malformed-message
error-path : /openconfig-system:system/aaa/f5-openconfig-aaa-tls:tls/create-self-signed-cert
error-message : Unable to create CSR for the self-signed certificate. See error log for details.

 

/var/log/system/platform.log shows:

2025-03-10T23:20:37.166975+00:00 lab-r5900-R85-S35 authd[8]: priority="Err" version=1.0 msgid=0x7b01000000000069 msg="OpenSSL X509V3_EXT_add_nconf failed to load extension ." name="www.mysite.com".

2025-03-10T23:20:37.167066+00:00 lab-r5900-R85-S35 authd[8]: priority="Err" version=1.0 msgid=0x3901000000000124 msg="Unable to create a certificate signing request(CSR).".

Environment

F5OS 1.8.0

Cause

Incorrect syntax

Recommended Actions

Use the following syntax, including "URI:https://"

URI:https://something.mysite.com

Additional Information

None
