Description

01070095:3: Virtual server /Common/<virtual server> lists incompatible profiles

Environment

  • iRules Language Extensions (iRulesLX)
  • Virtual Server associated with the following profiles:
    • iRulesLX Profile
    • An incompatible profile. Example: ASM Security Policy, APM Access Policy

Cause

  • You associate an iRulesLX profile to a virtual server that is already associated with another profile that is incompatible with the iRulesLX profile. Example: ASM security policies or APM access policies.

Recommended Actions

  • iRulesLX profiles cannot be applied to a virtual server with an incompatible profile such as ASM security policy or APM profile.
  • Enter the tmsh help ltm profile ilx command to view the list of profiles that are compatible with iLX profiles. Currently, compatible profiles include clientssl, http, http-compression, serverssl, stream, tcp and web-acceleration.

Additional Information

An ILX profile is used to associate an ILX Plugin (see ilx plugin) with a virtual server. When a client connects to a virtual server the data from the client and server will be routed to the ILX plugin allowing the plugin to inspect and manage traffic.
