Description

When viewing BIG-IP APM license details on a BIG-IP APM standby device of a HA pair, the license details vary when viewing BIG-IP APM license details through the Configuration utility and when viewing through the tmsh utility. The Configuration utility displays the expected BIG-IP APM license information, however when viewing through tmsh utility all license values show as 0 (zero).

Example output from the tmsh utility:

tmsh show apm license
--------------------------------------------
Global Access License Details:
--------------------------------------------
total access sessions: 0
current active sessions: 0
current established sessions: 0
access sessions threshold percent: 0
total connectivity sessions: 0
current connectivity sessions: 0
connectivity sessions threshold percent: 0
total swg sessions: 0
current swg sessions: 0
swg sessions threshold percent: 0
total swg limited sessions: 0
current swg limited sessions: 0
swg limited sessions threshold percent: 0

Environment

  • BIG-IP APM
  • HA
  • Standby device
  • tmsh

Cause

Unknown at time of publication.

Recommended Actions

Reboot the device is a temporary workaround.
A reload the configuration or restart services may address the issue as a temporary workaround.
