Topic

A remote file inclusion attack is designed to cause a web application to retrieve and include a remote file through the manipulation of server-side parsed user input.  Potential consequences of this range from sensitive information disclosure and Cross Site Scripting (XSS), through to Remote Code Execution (RCE) if the file retrieved file is executed within the context of the running application.

Such attacks are usually specific to the language or framework that the web application is written in.

Description

BIG-IP ASM can mitigate Remote File Inclusion attacks with the Attack Signatures feature or with defined meta-characters. This procedure lists the steps needed to mitigate such attacks using BIG-IP ASM Attack Signatures.

The following procedure outlines how to assign, enable, and configure the relevant attack signature set in blocking mode so that Remote File Inclusion attacks can be mitigated. The final step is the mitigation verification where you can see the Remote File Inclusion attack being blocked.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • BIG-IP ASM is licensed and provisioned on your system.
  • A security policy is assigned to the virtual server.
  • A BIG-IP ASM logging profile is configured to log illegal requests.
  • Parameter of type wildcard is defined.

Procedures

You can use the following procedures in the order in which they appear to configure an attack signature to mitigate RFI attacks.

Impact of procedure:  Adding attack signatures to a security policy can generate false positives. In these cases, false positives should be removed using Learning and Blocking Settings.

Adding the Remote File Inclusion signatures

  1. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  2. For General Settings, click Advanced.
  3. Expand Attack Signatures.
  4. Click Change. 
  5. For Select Policy Attack Signature Sets, select the Remote File Include Signatures check box and click Change.
  6. Verify that the signature set has Learn, Alarm, and Block check boxes selected.
  7. Click Save.
  8. Click Apply Policy.

Enabling and enforcing Remote File Inclusion signatures

  1. Clear the Enable Signature Staging check box.
  2. Click Save, then click Apply Policy.

Switching to blocking

  1. Under General Settings, for Enforcement Mode, click Blocking.
  2. Click Save.
  3. Click Apply Policy.

Verifying that Remote File Inclusion is being blocked

  1. Navigate Security > Event logs > Application > Requests.
  2. Open the filter and click the IP / Username / URL tab.
  3. Under Violation click Attack Signature Detected, then click Apply Filter.
  4. The blocked request is listed in the request log.
  5. The Attack Type name in the request log is shown as Remote File Inclusion.
