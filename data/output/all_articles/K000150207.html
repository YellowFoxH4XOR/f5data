Description

When attempting to license a Local Traffic Manager (LTM) standalone license on BIG-IQ, either through the automatic or manual method, you may encounter the following error message: Error 51133, F5 registration key is not compatible with the detected platform - This platform, "BIG-IQ Pool", cannot be activated with this registration key "XXXXXXX-XXXXXXX"

Environment

  • Big-IQ 
  • LTM Standalone license

Cause

This error occurs because the licensing is being made outside the specified offering key using automatically or manually outside the offering key.

Recommended Actions

  1. Create a license Key Pool:
    1. Access your BIG-IQ system.
    2. Navigate to the license management section.
    3. Create a new license key pool specifically for standalone LTM licenses.
  2. Add Standalone License Keys:
    1. Add the standalone license keys to the created pool one by one.
    2. Ensure each key is valid and corresponds to the intended use.
  3. Assign a License Key from the Pool:
    1. Once the keys are added to the pool, select the appropriate key you wish to assign to your BIG-IP device.
    2. Use the drop-down list to choose the key from the pool.

  4. If BIG-IP is Unmanaged:

    1. If the BIG-IP device you are licensing is not managed through BIG-IQ (i.e., it does not appear in the drop-down list), select the "unmanaged" option.

    2. Provide the BIG-IQ with the management IP address and the correct administrative credentials of the BIG-IP device.

Additional Information

Refer to the official F5 documentation for more detailed instructions on creating and managing license key pools in BIG-IQ.
