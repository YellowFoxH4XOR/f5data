K12520: The BIG-IP WebAccelerator does not recognize Microsoft Silverlight file extensions and MIME types

Topic

The BIG-IP WebAccelerator system does not recognize by default the following file extensions and MIME types, which are used by Microsoft Silverlight applications:

  • .xap   application/x-silverlight-app
  • .xaml  application/xaml+xml
  • .xbap  application/x-ms-xbap

When using the standard globalfragment.xml file and bundled WebAccelerator policies, Microsoft Silverlight objects will match the Unclassified node. This node is set to Always proxy, which means the BIG-IP WebAccelerator will always send requests for Microsoft Silverlight objects to the origin web servers, rather than serving them from cache.

Additionally, beginning in BIG-IP version 9.4.5-HF2, the BIG-IP WebAccelerator sets the Cache Control: no-cache header when responding to requests that matched the Unclassified node. This causes clients not to cache Microsoft Silverlight objects, and may also prevent the application from functioning properly on some browsers.

F5 Product Development is considering a request for enhancement (RFE) to have the Microsoft Silverlight file extensions and MIME types added by default to an appropriate object type. F5 Product Development is tracking this RFE as ID 348151.

A suitable object type for Microsoft Silverlight files is Audio/Video Media. You can manually add the appropriate file extensions and MIME types to the Audio/Video Media object type by performing one of the following procedures:

BIG-IP versions 10.2.x

Note: Although the following procedure also applies to BIG-IP versions 10.0.0 through 10.1.0, these versions cannot use this procedure because of an issue affecting the BIG-IP system Configuration utility. For more information, refer to K11230: The Configuration utility fails to save an object type when one of its MIME-types contains a plus sign.

  1. Log in to the BIG-IP WebAccelerator Configuration utility.
  2. Navigate to Configuration >> Policies >> Object Types.
  3. Select the Audio/Video Media predefined object type.
  4. Add the following to the Extensions list:

    xap
    xaml
    xbap
  5. Add the following to the MIME-types list:

    application/x-silverlight-app
    application/xaml+xml
    application/x-ms-xbap
  6. Click Save.

BIG-IP version 9.4.0 through 10.1.0

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa
  3. Back up the original globalfragment.xml file by typing the following command:

    cp globalfragment.xml globalfragment.xml.sol12520
  4. Open the globalfragment.xml file in a text editor.
  5. Locate the media objType entry.
  6. Edit the ext= section of the media objType object, adding the following to the list of extensions:

    xap
    xaml
    xbap
  7. Edit the mimeType section of the media objType object, adding the following to the list of MIME types:

    application/x-silverlight-app
    application/xaml+xml
    application/x-ms-xbap
  8. Save the globalfragment.xml file.
  9. Restart the pvac daemon by typing the following command:

    Important: Restarting the pvac daemon will briefly disrupt connections and should be scheduled accordingly.

    bigstart restart pvac
