Description

Connection reset with cause code "No server selected"

Environment

  • BIG-IP with virtual server (VS) configured without a pool attached but with translate-address and/or translate-port enabled

  • Most likely seen in virtual-wire environment with DDOS (but not exclusively)

Cause

If translate-address and/or translate-port is enabled, then a pool must be assigned.

This might be the result of a copy and paste error during migrations (eg: i-series to r-series)

Recommended Action

Unless a pool is required, disable both translate-address and translate-port under the VS

Additional Information

DDOS with virtual-wire configurations are often transparent in that the traffic is processed by a VS but the source/destination address/port 4-tuple is unchanged.
