Known Issue

Restoring the BIG-IP configuration to factory default settings may change the Terminal Access setting for the admin user to tmsh.

The tmsh load sys config default command resets the Terminal Access for the admin user to tmsh.

This issue occurs when all of the following conditions are met:

  • You restore the BIG-IP configuration to factory default settings, using the tmsh load /sys config default command.
  • Terminal Access for the admin user is set to Disabled (None) or Advanced Shell (bash).

Impact

The admin user may have unintended Terminal Access settings.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After running the tmsh load /sys config default command, you notice that the admin user has unintended tmsh shell access.
  • You notice that the admin users Terminal Access setting changes after you run the tmsh load /sys config default command.

Workaround

To work around this issue, you can reset the Terminal Access settings for the admin user to the desired access level. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Resetting the Terminal Access for the admin user

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Reset the Terminal Access to the desired level by using the following command syntax:

    modify /auth user admin shell [bash|none|tmsh]

    For example, if the desired Terminal Access level is None, run the following command:

    modify /auth user admin shell none

  3. Save the change by typing the following command:

    BIG-IP 10.1.0 and later:

    save /sys config

    BIG-IP 10.0.x:

    save config
