K000133465: IP address searching not working on GUI for Virtual Server & Network Map

Type
Support Solution
Published
2023-07-12
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000133465

Description

When a virtual server is configured with source address list and the destination is configured as host IP address (destination IP address), for example 192.168.1.1/32, virtual server is not searchable with destination IP address in GUI, when you try to search from Virtual Server list or Network Map.

Note: Virtual server using source or destination address list automatically creates traffic-matching-criteria (TMC) object

Environment

  • Source address list
  • Traffic-matching-criteria

Cause

This is by design.

Recommended Actions

Workaround is search by virtual server name

Additional Information

None
