Known Issue

This is the result of a known issue. When a non-default static route is configured for the management network, a GATEWAY entry is created in the /etc/sysconfig/network file. The GATEWAY entry results with a default route entry in the main routing table during startup. Non-default static routes configured on the management network should not be entered as a default gateway. These default routes may also interfere with default routes learned dynamically when working with dynamic routing protocols.

F5 Product Development tracked this issue as CR55546 and CR83141 and it was fixed in BIG-IP versions 9.3.0 and 9.4.2. For information about upgrading, refer to the LTM, GTM, ASM, Link Controller, or WebAccelerator release notes.

Workaround

You can work around this issue by manually removing the GATEWAY entry from the /etc/sysconfig/network file for BIG-IP versions 9.0.0 through 9.2.5, and versions 9.4.0 through 9.4.1. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Change directories to the /etc/sysconfig directory by typing the following command:

    cd /etc/sysconfig

  3. Back up the network file, by typing the following command:

    cp network network.sol7814

  4. Open the network file using a file editor.
  5. Change the GATEWAY entry to the following line:

    GATEWAY=none

  6. Save the /etc/sysconfig/network file.
  7. Reboot the BIG-IP system by typing the following command:

    reboot
