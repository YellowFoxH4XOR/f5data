Known Issue

This is the result of a known issue. In rare cases, the TMM process can crash when TMM is placed in strict mode and tcpdump runs on a VLAN.

Important: Placing TMM in strict mode should only be done when instructed by F5 Technical Support for the purposes of troubleshooting.

F5 Product Development tracked this issue as CR68410, and it was fixed in BIG-IP LTM version 9.3.0 and 9.4.0. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, or Link Controller release notes.
