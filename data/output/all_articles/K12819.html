Topic

Note: For information about ARX shadow volumes, refer to the Shadowing a Volume section of the ARX CLI Storage Management Guide.

When configuring the ARX to manage replication of data to a shadow volume, the shadow-copy rule's target shadow volume can be empty or pre-populated with some or all of the specified source files. Therefore, it is possible to use a replication method other than the ARX shadow-copy function to perform the initial data replication.

Important: When using an alternative replication method to pre-populate a target volume, that replication must be disabled before specifying the target volume as a shadow volume and enabling the shadow-copy rule. Once a shadow volume is enabled, only the ARX shadow-copy process should replicate files to it.

When the shadow-copy rule is enabled, the first shadow-copy operation is to perform a tree walk and to add or replace any files that are not present or differ from the source volume. After the initial shadow-copy operation, the ARX will then remove any extraneous files on the target shadow volume that are not on the source volume.
