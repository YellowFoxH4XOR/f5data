Known Issue

This is the result of a known issue. When FirePass is configured to copy backups to a remote SCP or FTP server, the copy fails if the time it takes to generate the backup is greater than five minutes. This issue occurs because the backup exceeds the five-minute HTTP session timeout.

F5 Product Development is tracking this issue as CR141363.

Workaround

You can work around this issue by modifying the logging parameters to reduce the amount of data being backed up. To do so, perform the following procedures to determine which combination works best in your environment:

Enabling partial backup

  1. Log in to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Backup/Restore.
  4. Select the Partial Backup check box.

Note: The steps in this procedure do not back up the application logs and logon detail logs.

Changing the amount of time to retain logs

  1. Log in to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Logs.
  4. Select the amount of time to retain logs from the Keep logs for drop-down box. 

Lowering the log file size limit

  1. Log in to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Logs.
  4. Enter a size for the log files in the A purge of logs will be forced when the size of any log file exceeds this limit text box.

Note: For more information about configuring FirePass logging options, refer to the FirePass Controller Administrator Guide.
