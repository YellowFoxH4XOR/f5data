Known Issue

The BIG-IP system fails to validate custom syslog configurations. This issue occurs when the following condition is met:

  • You add an invalid custom syslog configuration using the tmsh modify sys syslog include <syslog config syntax> command.

    For example, the BIG-IP system will fail to validate the syslog command syntax in the following command:

    tmsh modify /sys syslog include "invalid syslog command syntax"

Impact

The syslog-ng process may fail to start and result in logging failure.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you attempt to restart the syslog-ng process, it fails to start and reports the following error message:

    Starting syslog-ng: syntax error at 864
    [FAILED]
  • The BIG-IP system may fail to log any messages in the log files.

Workaround

If you have already encountered the issue, you can remove the errant custom syslog configuration. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Remove the errant custom syslog configuration by typing the following command:

    modify /sys syslog include none

  3. Save the change by typing the following command:

    save /sys config
