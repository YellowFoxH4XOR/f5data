K000149644: Velos chassis LLDP not seen on Switch

Type
Support Solution
Published
2025-02-10
Updated
2025-02-10
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.6.X, 1.8.X, 1.3.X, 1.8.0, 1.6.2, 1.6.1, 1.6.0, 1.5.1, 1.5.0, 1.3.2, 1.3.1, 1.3.0
Source
https://my.f5.com/manage/s/article/K000149644

Description

  • Velos not sending LLDP frames
  • LLDP information is not being learnt on the Network switch
  • LLDP frames from switch are reaching the Velos device

Environment

  • Velos
  • F5OS-C
  • LLDP
  • OpenShift cluster was manually rebuilt.

Cause

The cluster rebuild triggered Bug ID1138085. When OpenShift is reinstalled on a VELOS system (that is, by running 'touch /var/omd/CLUSTER_REINSTALL'), partition services that run as Kubernetes pods are not re-deployed after the installation finishes.

This caused the lldpd pod to stop running.

Recommended Actions

Workaround: Disable and re-enable the partition(s).

None
