Description

You are unable to get iControl REST Table Of Contents. You may see following error after you entered user name and password.

( {"code":400,"message":"URI path /mgmt/logmein.html not registered. Please verify URI is supported and wait for /available suffix to be responsive.","referer":"https://10.1.1.1/mgmt/toc","restOperationId":45299775,"kind":":resterrorresponse"} )

Environment

BIG-IP 15.1.x and later

Cause

REST API endpoints in /mgmt/toc are not mapped to correct URL's internally.

Recommended Actions

To get iControl REST Table Of Contents,
Access to following URL directly.

https://<BIG-IP IP address>/restui/default/toc.html

Additional Information

In BIG-IP version v17.x, there is an additional issue. It is possible to get the Table Of Contents, however, object browser pages does not show any object data. This is tracked by Bug ID 2153421: iControl REST /mgmt/toc endpoint and object browser pages are not functioning on BIG-IP v17.x
