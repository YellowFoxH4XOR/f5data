K1446: Reasons why configuration changes may be lost when you run configsync

Topic

When you run the bigpipe config sync command, it transfers all the appropriate files to the peer BIG-IP and initiates the b load command.

If you made configuration changes and do not run the b save and b base save commands, you will lose those changes after you run the bigpipe config sync command, causing your configuration to revert back to the configuration that you had the last time you ran the b load command.

It is important to run the b save command every time you make configuration changes to BIG-IP. The b base save command is required less often, as it applies only to base configuration changes such as trunk port configuration. BIG-IP provides a reminder to save your base configuration every time you run the b save command.

For example:

ip2:/config# b save
/config/bigip.conf was renamed to /config/bigip.conf.bak (6 lines).
The main configuration was saved to /config/bigip.conf (9 lines).
The base configuration can be saved with the bigpipe base save command.

Note: Any changes that you make to the configuration through the Configuration utility are automatically saved and do not require you to run the b save or b base save commands.
