Topic

Due to some issues that may arise from upgrading to FirePass version 6.1.0, F5 strongly recommends that you upgrade using the Online Update feature rather than the Local Update feature.

Note: This issue has been fixed starting in FirePass version 7.0.0.

Upgrading to version 6.1.0 may fail if a master group name contains a period character ( . ) and the master group was configured for an intranet webtop. This issue may occur even if the master group was deleted from the FirePass controller. A pop-up box will display the following error message:

Installation failed with status: Error: (number-string) bad argument type: 17\n\n\n\n\n\nRELOAD. Please contact F5 technical support.

This failure may prevent the FirePass web services from running, causing a service outage for end-users and preventing FirePass administrators from accessing the Administrative Console. If you receive the error message, or if the FirePass controller becomes inaccessible after attempting to upgrade to version 6.1.0, refer to K10922: Recovering from a failed upgrade to FirePass version 6.1.0.

Important: For Online Update to work correctly, the FirePass controller that you are upgrading must have a stable connection to the internet from the default gateway, and must have DNS configured and working properly.

Steps that need to be completed prior to upgrading

  1. Create a snapshot of your current configuration.

    Note: For more information, refer to K3244: Backing up and restoring FirePass system software.
  2. Navigate to Device Management : Maintenance : Backup/Restore.
  3. Click Create backup of your current configuration.
  4. When prompted, save a local copy of the backup.

    Note: This step may take several minutes
  5. Navigate to Device Management : Security : Timeouts.
  6. Temporarily change the Global inactivity timeout option to a large value, such as 8 hours, so that the upgrade process does not time out while downloading the image.
  7. Disable all pop-up blockers in your web browser so that any generated error messages during the upgrade process are displayed.

    Note: For more information, refer to the documentation provided by your browser software vendor.
  8. Navigate to Device Management : Maintenance : User Session Lockout.
  9. In the User Session Lockout area, select the Lockout new user sessions option to prevent any new FirePass controller users from logging on.
  10. In the Kill Current Sessions section, click the Kill all sessions (except this one) link to log off all current FirePass controller users.

Upgrading using Online Update

  1. Navigate to Device Management : Maintenance : Online Update.
  2. Click the Upgrade button next to Version 6.1.0 release.

    Note: The upgrade may take several minutes to complete; once completed, the controller automatically reboots.
  3. After the controller reboots, reconnect to FirePass and log on to the Administrative Console.
  4. Navigate to Device Management : Maintenance : User Session Lockout.
  5. Clear the Lockout new user sessions check box to allow users to log on to the FirePass controller again.
  6. Navigate to Device Management : Security : Timeouts.
  7. Change the Global inactivity timeout option to its previous value.

Important: If you are unable to use the Online Update process, you will need to download two hotfixes as well as the 6.1.0 release files. For more information, refer to the following Upgrading using Local update section.

Upgrading using Local Update

  1. From the F5 Downloads site, download the following files:

    • HF-133602-1 for your current FirePass version
    • HF-133285-1 for FirePass version 6.1.0

      Note: HF-133285-1 is included in cumulative hotfix HF-610-1. Rather than installing the individual hotfix, you may want to consider installing the cumulative hotfix to resolve this issue.
    • The 6.1.0 release files (release readme file, the release, and MD5 file for release)
       
    Note: For more information, refer to K167: Downloading software from F5.

    Important: Failure to install the two hotfixes in the following order may create a failure state that will require you to revert back to the latest snapshot taken of the FirePass controller.
  2. Install the pre-upgrade HF-133602-1.

    Note: For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
  3. Install the FP-6.10-20091009.tar.gz.enc release file.
  4. After the FirePass controller has rebooted, install HF-133285-1.
