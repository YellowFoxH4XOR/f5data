Description

  • Speaking of the BIG-IQ product, are there any differences between Azure and VMware deployments? For example, do we have some features that are not available on Azure (In this case, which kind of features)? 
  • The configuration on VMware is compatible with the ones on Azure? 
  • How can we migrate the license?

Environment

  •  BIG-IQ
  • Azure
  • VMware

Cause

  • None

Recommended Actions

  • None

Additional Information

  • All BIG-IQ features should be available in both Azure and VMware
  • Difference between Azure and VMware BIG-IQ deployment can be found in  https://github.com/f5devcentral/f5-big-iq-trial-quick-start/
  • BIG-IQ configuration could be imported from VMware to azure, but no documentation to migrate such configuration and therefore it needs to be tested in your test environment
  • Migrating license from current VMware environment to Azure, best to reach out to your Account Manager
