Description

After renewing a certificate, getting NET::ERR_CERTIFICATE_TRANSPARENCY_REQUIRED error in Chrome.

  • Other browsers like Chrome, Opera, IE work fine with the same certificate.
  • Chrome v96 and Edge v96 or later show this error message.

Environment

  • BIG-IP LTM
  • A new traffic certificate was installed

Cause

This can happen if the Certificate Authority (CA) issuing the certificate hasn't followed certificate didn't publish the certificate issuance log properly. Newer versions of Chrome (and browsers based of Chromium) have started blocking certificates which do not have Certificate Transparency log.

Recommended Actions

This is not an issue on BIG-IP. To resolve this, reach out to the CA and request them to add this existing certificate to CT or get a new certificate issued which is compliant with Google's Certificate Transparency.

If CA doesn't comply, get a new certificate from a different CA.

More details about Certificate Transparency project:
https://certificate.transparency.dev/

To check if a certificate has been added to the CT log, search for the domain name in the link below:
https://transparencyreport.google.com/https/certificates?hl=en
