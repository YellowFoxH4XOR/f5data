Known Issue

After installing the Windows Mobile client on the Samsung Omnia II i920 device, the user is unable to manually configure the client. In addition, the F5 icon does not display in the top bar, and the Windows Mobile client does not launch.

F5 Product Development tracked this issue as ID 243084 (formerly CR135613) and it was fixed in BIG-IP APM 10.2.0 and FirePass 7.0.0. For information about upgrading, refer to the BIG-IP APM or FirePass release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0, and in cumulative hotfix HF-610-2, which has been issued for FirePass 6.1.0. You may download these cumulative hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.
