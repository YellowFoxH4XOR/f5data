K51795958: BIG-IQ ASM discovery and import fails with Error message: Error querying 'ASM Signature' from path '/mgmt/tm/asm/signatures' on device <hostname> (IP address), network communication failed due to protocol error.

Applies to

Source

Description

  • Unable to discover/import ASM to BIG-IQ CM
  • During ASM discovery in BIG-IQ, you may encounter one of the following error messages:


    Error querying 'ASM Signature' from path '/mgmt/tm/asm/signatures' on device <hostname> (IP address), network communication failed due to protocol error.

    Error querying 'ASM Policy - Signature' from path '/mgmt/tm/asm/policies/<ID>/signatures' on device [target asm hostname] (<ip_addr>), network communication failed due to protocol error

Environment

  • Big-IQ ASM discovery
  • Big-IP ASM

Cause

When trying to discover all the ASM attack signatures, sometimes the BIG-IP REST framework can't provide a valid response back due to the large number of objects. Instead, the BIG-IP will respond with a 400 error.

Recommended Actions

Reduce the "batch size" an in BIG-IQ to allow the discovery process to complete successfully:

  1. Connect to BIG-IQ CM CLI
  2. Reduce the batch size

    restcurl /cm/asm/preferences/discovery-batch-size -X PATCH -d {value:4}
