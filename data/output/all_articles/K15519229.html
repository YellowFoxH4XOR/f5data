Description

  • On GUI, with the Yellow banner:  Error getting auth token from login provider, cannot click any other features, for example, "in Sync" or "Active" links, results in "Loading" being stuck here forever.
  • Impact: BIG-IP system components that rely on REST Workers such as: OpenID Connect key rotation discovery, portions of the Configuration utility (GUI), and Guided Configuration (AGC and WGC) fail to function properly.

Environment

  • The BIG-IP may report the error under the following conditions: 
    • After logging into the Management GUI, that is when the yellow banner with error: "Error getting auth token from login provider " is immediately seen.

    • After new local user added and default admin user disabled

  • Configuration objects and settings:  WebUI: Management GUI
  • Products and features:  REST

Cause

The cause may be related to the following bug ID(s).

  • Bug ID 717174: WebUI shows error: Error getting auth token from login provider
  • Bug ID 723798: Non-default Administrator unable to access all GUI pages after disabling default admin

Recommended Actions

Restarting the BIG-IP REST daemons restjavad and restnoded will usually correct the problem.

To do so, connect to the SSH console and issue the following command:

Impact of procedure: Restarting the restjavad and restnoded will temporarily impact the BIG-IP control plane components that rely on the services of these two processes such as REST API and Configuration utility. BIG-IP data plane is not impacted during the restart of these two processes. 

tmsh restart sys service restjavad restnoded

If the above command does not resolve the issue, restart restjavad and restnoded separately with these commands:

bigstart restart restjavad
bigstart restart restnoded

If the above commands didn't work, you may want to try increasing restjavad heap memory. That normally means increasing the value of sys db provision.extramb as well, which is service affecting so likely will require a maintenance window.

It's worth ruling out common restjavad issues first, one such being ID 1826505.

If you wish to know more about increasing  restjavad memory the following article may be useful:

K000133258: Provisioning restjavad memory with provision.restjavad.extramb

 

Additional Information

After rebooting the unit, the error:  Yellow banner:  "Error getting auth token from login provider" may be seen again.
