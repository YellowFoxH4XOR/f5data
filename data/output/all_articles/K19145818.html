Description:
A Portal Application displays a blank panel.


Environment:

  • APM
  • Portal rewrite resource.
  • sys db apm.xframeoptions  is set to  "same_ori"


Cause:

  • The translated resource has a header "X-Frame-Options DENY"
  • The "sys db apm.xframeoptions"  DB key is not intended for portal rewrite and has no effect. It changes appropriate headers in user interface pages in Access Policy.
  • Portal Rewrite does not have support for the "Referer" header. This causes the perceived origin of iframes to be different.



Recommended Actions:

Create and apply an irule to the portal virtual server.
In this example, the portal resource is https://10.2.8.40
This is hex encoded to  68747470733A2F2F31302E322E382E3430



when HTTP_REQUEST {
 if { [HTTP::has_responded] } { return }
  if { [HTTP::header exists REFERER] and not ( [HTTP::header REFERER] contains "/f5-w-" ) } {
    set referer [HTTP::header REFERER]
    HTTP::header replace REFERER "${referer}f5-w-68747470733a2f2f31302e322e382e3430$$/"
  }
}
