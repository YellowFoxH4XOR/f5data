K000157288: The default setting for "Prohibit routing table changes during Network Access connection" changed to "enabled"

Issue

The default setting for the Prohibit routing table changes during Network Access connection feature changed from disabled to enabled.

Old Behavior

In BIG-IP APM versions prior to 17.5.1, 17.1.3, 16.1.6.1, and 15.1.10.8, the default setting for the Prohibit routing table changes during Network Access connection feature is disabled. This setting is disabled by default when creating new Network Access resources in these versions. 

New Behavior

Beginning in BIG-IP APM versions 17.5.1, 17.1.3, 16.1.6.1, and 15.1.10.8, the default setting for the Prohibit routing table changes during Network Access connection feature changed from disabled to enabled. This change was introduced as a security mitigation for the CVE-2024-3661 TunnelVision vulnerability.

After upgrading to these versions, this setting will be enabled by default on both new and existing Network Access resources. Existing Network Access resources with Prohibit routing table changes during Network Access connection set to disabled are automatically set to enabled when upgrading to these versions. 

Recommended Actions

Before upgrading to a version with the new behavior, review your current configuration for dependencies on the previous default setting (disabled).

After upgrading to a version with the new behavior, verify that user connectivity is not impacted by the new default setting (enabled).

F5 recommends enabling the Prohibit routing table changes during Network Access connection feature, as enabling it mitigates the issue described in CVE-2024-3661. To enable this feature, refer to the mitigation section in K000139553: VPN TunnelVision vulnerability CVE-2024-3661.

Always consult the release notes for your target upgrade version regarding security-related behavior changes.
