Description
:Java based client JNLP (1.7.0) cannot be opened through APM

Environment

  • LTM+APM
  • Java based pool
  • User-Agent is shown as : JNLP/1.7.0 javaws/11.51.2.16 (<internal>) Java/1.8.0_5
  • User-agent as FirstSpirit 5.2.190910.78562

Cause
APM does't pass cookies to the java based Resource.

Recommended Actions
- Persistance cookie Enabled

- irule 
when HTTP_REQUEST {

   if { ([HTTP::uri] starts_with "/jnlp/") || ([HTTP::uri] starts_with "/servlet/") } {
         log local0. "***** [HTTP::method] [HTTP::uri] doing ACCESS::disable"
         ACCESS::disable
         return
   }
}
