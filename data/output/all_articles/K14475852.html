K14475852: avrd daemon on BIG-IP restarts and generate a core file when the BIG-IQ connection is down

Type
Support Solution
Published
2021-11-19
Updated

Applies to

  • BIG-IP Platforms
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K14475852

Description

When a BIG-IP is configured to work with BIG-IQ but it can not connect due to network problems, the avrd daemon restarts itself every 10 minutes. During such restarts, a core is sometimes generated.

Environment

  • BIG-IP AVR (Application Visibility and Reporting) provisioned or configuration stored
  • BIG-IP is registered on BIG-IQ
  • There is a network connectivity issue for some reasons between BIG-IP and BIG-IQ

Cause

Bug ID 922105

Recommended Actions

Perform either of the recommended actions to fix the issue: 
  •  Disable BIG-IP to connect BIG-IQ manually by running the command:
    tmsh modify analytics global-settings use-offbox disabled
    (or)
  • Upgrade to the fixed version from Bug ID 922105 to resolve the issue. You can refer this article (K84554955) for overview of BIG-IP system software upgrades.
