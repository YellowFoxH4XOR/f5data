Description

The cmp state is a hex value seen in /var/log/ltm and /var/log/tmm that represents the number of blades/slots that are active or inactive in a multi-slot cluster, such as VIPRION, vCMP guest, and VELOS tenant. 
Searching for cmp state in the logs can help determine which blade may have an issue in a clustered environment.

CMP state change log messages are usually seen when a blade is added or removed from the cluster. You may see messages in logs referring to cmp state changes, such as:

Immediately transitioning dissaggregator to state 0x7
cmp state: 0x7
cmp transition complete, transitioning dissaggregator to state 0x7

TMM may repeatedly log a message like the one below when the number of available slots differs between two clusters in HA.

01340004:3: HA Connection detected different cmp_state: local cmp_state 7, remote cmp_state 1. Connection will be retried.


You can use the following information to determine which slot the hex value is referencing in a multi-slot cluster system: 

Step 1:  Convert the hex value into binary and compare that number to the blade order.  The binary values represent the following: 

  • 1 = blade is available and in the cluster
  • 0 = blade is not available and not in the cluster 

Step 2: Apply the binary value to the blade order below.

Blade Order:  (i.e. B8 = blade 8,  B1 = blade 1) 
                B8  B7  B6  B5  B4  B3  B2  B1 

Examples

Example 1:  cmp state = 0xAF

  1. Take the cmp state value in hex and convert to binary.
     AF in binary = 10101111 

  2. Write the binary value under the Blade Order.

    Blade Order:        B8  B7  B6  B5  B4  B3  B2  B1 
    Binary Value:        1   0   1   0   1   1   1   1


    Results:  A cmp state of 0xAF means that blades/slots 8, 6, 4, 3, 2, and 1 are available, and blades/slots 7 and 5 are not. 

Example 2:  cmp state =  0xD5

  1. Take the cmp state value in hex and convert to binary. 
     D5 in binary = 11010101 

  2. Write the binary value under the Blade Order.
    Blade Order:        B8  B7  B6  B5  B4  B3  B2  B1 
    Binary Value:        1   1   0   1   0   1   0   1

    Results: A cmp state of 0xD5 means that blades/slots 8,7,5,3,1 are available and blades/slots 6,4,2 are not.

Example 3:  cmp state = 0x0D

  1. Take the cmp state value in hex and convert to binary. 
     D in binary = 00001101

  2. Write the binary value under the Blade Order.
    Blade Order:        B8  B7  B6  B5  B4  B3  B2  B1
    Binary Value:        0   0   0   0   1   1   0   1

    Results: A cmp state of 0x0D means that blades/slots 4, 3, and 1 are available and blades/slots 8, 7, 6, 5, and 2 are not.

Environment

  • You have a multi-slot cluster system, such as VIPRION, vCMP guest, and VELOS tenant.
