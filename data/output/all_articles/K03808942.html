Known Issue

The BIG-IP ASM system blocks HTTP requests with more than 1,000 chunks.

This issue occurs when the following condition is met:

  • Your BIG-IP ASM system processes an HTTP request that contains more than 1,000 chunks.

Impact

The BIG-IP ASM system blocks valid HTTP requests.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP ASM system logs messages in the ASM Event Logs Requests report that appear similar to the following example:

    Unparsable request content Chunks number exceeds request chunks limit: 1000.

  • Your BIG-IP ASM system blocks valid HTTP requests that contain more than 1,000 chunks.
