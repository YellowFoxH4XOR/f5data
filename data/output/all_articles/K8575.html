K8575: BIG-IP GTM can crash while parsing LDNS records with non-existent virtual server references

Known Issue

This is the result of a known issue. If a Local Domain Name System (LDNS) record refers to an object that does not exist, the BIG-IP GTM system can crash while parsing the LDNS record. F5 recommends that you do not delete objects unless you are sure that they are not referenced by any LDNS records.

F5 Product Development tracked this issue as CR68883 and it was fixed in BIG-IP GTM 9.3.0 and 9.4.0. For information about upgrading, refer to the BIG-IP GTM Release Notes.
