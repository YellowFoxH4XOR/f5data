Known Issue

The Configuration utility may display software modules that are incompatible and cannot be provisioned on a VIPRION.

This issue occurs when the following condition is met:

  • A VIPRION chassis has two or more blades

Impact

None. You can safely ignore this issue.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Software modules that are not compatible with the VIPRION platform will be displayed in the Configuration utility under the System > Resource Provisioning menu.

    For example, the modules shown in the Configuration utility may appear similar to the following list, which contains some modules that cannot be provisioned on the VIPRION:

    Global Traffic (GTM)
    Link Controller (LC)
    Protocol Security (PSM)
    Application Security (ASM)
    WebAccelerator (WAM)
    WAN Optimization (WOM)
    Access Policy (APM)

  • The list of modules in the Configuration utility will not match the list of provisionable modules displayed from the command line.

    The output of the bigpipe command shown in the workaround below will correctly show the modules that can be provisioned on this platform, for example:

    PROVISION
    Key CPU % Memory (MB) Host Mem (MB) Disk (MB)
    asm   0             0             0         0
    ltm   1             0             0         0
    psm   1             0           602         0

Workaround

To work around this issue, you can view the available modules from the command line. To do so, perform the following procedure:

Impact of workaround: None.

Viewing available modules using TMSH

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.

  2. Enter the following command:

    show sys provision

Viewing available modules using bigpipe

  1. Log in to the BIG-IP command line.
  2. Enter the following command:

    bigpipe provision
