K000156789: TLS version supported by rSeries Management IP

Type
Support Solution
Published
2025-10-03
Updated
2026-01-28
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.7.X, 1.5.X, 1.8.0, 1.7.0, 1.5.3, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000156789

Description

Vulnerability Scan reports mentions the use of TLS1.0 for the rSeries Management IP and suggested to disable it to mitigate the risks.

Environment

  • F5-BIG-LTM-R4800, C131
  • Security Scan report

Cause

By design, F5OS-A used TLSv1.2 for Management communications and SSLv2, SSLv3, TLSv1 and TLSv1.1 are disabled.

Hence the Vulnerability stating disabling weaker SSL/TLS version can be ignored as false.

 

Recommended Actions

  • There is no public facing command or process ( as of now) to configure or edit the SSL/TLS version for F5OS-A.
  • We can check the SSL/TLS version supported by F5OS-A using the below Docker command.

      docker exec http-server grep -r SSLProtocol /etc/httpd/conf.d
