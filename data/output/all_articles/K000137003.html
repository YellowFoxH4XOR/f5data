K000137003: Adv WAF highlights incorrect key word for attack signature 200020003

Type
Support Solution
Published
2023-09-27
Updated
2025-10-27
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000137003

Description

  • Adv WAF highlights incorrect keyword for attack signature 200020003 in the event logs.
  • Attack signature "Signature ID 200020003 - Jetty FileBasedSessionStore Session Stealing" looks for the presence of \"JSESSIONID=node\" within the request header.


Environment

  • Advanced WAF
  • Security policy
  • Signature ID 200020003
  • Long signature match


Cause

  • BUG 1039633

 Recommended Actions

  • No Action required.
  • Attack signature "Signature ID 200020003 - Jetty FileBasedSessionStore Session Stealing" looks for the presence of \"JSESSIONID=node\" within the request header and highlights it. Due to Bug 1039633, Adv waf highlights incorrect keywords as the trigger.

None
