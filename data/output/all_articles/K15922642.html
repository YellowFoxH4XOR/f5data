Description
As part of App tunnel configurations, there are 2 settings, local-ip and local-port-range. These settings are not shown and cannot be configured from the Configuration Utility. However, these settings can be seen on tmsh. For example:

list apm resource app-tunnel <app tunnel name>

apm resource app-tunnel my_apptunnel {
    apps {
        item {
            host none
            ip 10.64.181.67
            local-ip any6
            local-port-range none
            order 1
            path none
            port-range 1024-1030
        }
    }
    customization-group my_apptunnel_resource_app_tunnel_customization
    type app-tunnel
}

  • local-ip field accepts loopback IP addresses which are configured and used for the F5 Application Tunnel on client machine. If the specified loopback IP address is in use on the client, then it will randomly pick the next loopback address as needed.

  • local-port-range field expects single port or port range. Number of ports in local-port-range should match number of ports in port-range, otherwise MCP validation fails. Local ports supported: 1024- 65535. If local-port-range is specified, then it's used as a starting local port even if it is under 1024.

Environment

  • BIP-IP APM
  • App tunnel

Cause
These two fields are configurable via tmsh only.

Recommended Actions

If need to configure these settings, use the following commands from tmsh:

  • For local-ip:

modify apm resource app-tunnel my_apptunnel { apps modify { item { local-ip 127.10.1.1 } } }

  • For local-port-range:

modify apm resource app-tunnel my_apptunnel { apps modify { item { local-port-range 1024-1030 } } }

This will be result for previous example commands:

list apm resource app-tunnel <app tunnel name>

apm resource app-tunnel my_apptunnel {
    apps {
        item {
            host none
            ip 10.64.181.67
            local-ip 127.10.1.1
            local-port-range 1024-1030
            order 1
            path none
            port-range 1024-1030
        }
    }
    customization-group my_apptunnel_resource_app_tunnel_customization
    type app-tunnel
}
