Known Issue

The RAID status may report alarming message of undefined disk when only one solid-state drive (SSD) is populated.

This issue occurs when all of the following conditions are met:

  • The hardware platform includes any of the following:

    • BIG-IP 7000 series with SSD
    • BIG-IP 10000 series with SSD
    • BIG-IP 12000 series with SSD
  • Only one SSD hard disk is populated into the affected platform.
  • The BIG-IP system is running on the affected versions.

Impact

This issue is cosmetic; the SSD hard disk functions correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H496676 on the Diagnostics > Identified > Low screen.
  • You observe the RAID status message on the LCD panel. The message may appear similar to the following example:

    RAID Status
    Bay1: Undefined
    SN1:AZ01234567890123
    Bay2: No disk.

  • You observe the RAID status message when checking the system raid status using the Traffic Management Shell (tmsh) utility. The message may appear similar to the following example:

    [root@bigip:Active:Standalone] config # tmsh show sys raid
    ----------------------------------------------------------------
    Sys::Raid::Bay
    Bay Shelf Name Serial Number Array Member Array Status
    ----------------------------------------------------------------
    1 1 HD1 AZ0123456789012345 no undefined
    2 - - - - -
    ------------------------------------------------------------------------
    Sys::Raid::Disk
    Name Serial Number Array Member Array Status Model
    ------------------------------------------------------------------------
    HD1 AZ0123456789012345 no undefined ATA INTEL SSDSC2BA80
