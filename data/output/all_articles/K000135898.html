Description

When you create the CNAME type WideIP on BIG-IP DNS, you find the BIND database doesn't have the CNAME record for the WideIP.

Environment

  • CNAME record
  • WideIP alias

Cause

This behavior is intentional and by design. When adding a CNAME record under the WideIP alias list, ZoneRunner will automatically create the corresponding record in the BIND. ZoneRunner does not create a CNAME record in the BIND database based on the CNAME type WideIP. This design decision is due to a restriction in BIND. BIND only allows a single CNAME record for a specific domain name with the default setting, while a single A type WideIP can have multiple associated CNAME type WideIPs. As a result, ZoneRunner cannot programmatically determine which specific CNAME record should be placed in the BIND database.

 Recommended Actions

If you want ZoneRunner to automatically populate that CNAME record into the BIND database, please use the WideIP alias option.
