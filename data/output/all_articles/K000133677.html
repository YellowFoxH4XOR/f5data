K000133677: Audit logs not being sent to HSL

Type
Support Solution
Published
2025-04-04
Updated
2025-04-04
Source
https://my.f5.com/manage/s/article/K000133677

Description

  • You have configured HSL in the BIG-IP and you are able to see logs there, but the audit logs are not being sent to the external server
  • No error messages.

Environment

  • HSL configured
  • Audit logs

Cause

The audit messages are sent directly to syslog-ng using standard syslog() function, so they cannot be captured by HSL.
HSL operates on the data-plane level in TMM and does not collect messages from syslog.
 

Recommended Actions

The option here is that you use remote syslog instead.
