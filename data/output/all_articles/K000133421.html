Description

Environment

  • Address-list
  • Port-list

Cause

All the endpoints listed below are part of Precursory APIs:

  • /cm/firewall/working-config/address-lists
  • /cm/firewall/current-config/address-lists
  •  
  • /cm/firewall/working-config/port-lists
  • /cm/firewall/current-config/port-lists
  •  
  • /cm/firewall/working-config/firewalls/*/rules
  • /cm/firewall/current-config/firewalls/*/rules
  •  
  • /cm/firewall/working-config/rule-lists
  • /cm/firewall/working-config/rule-lists/*/rules

 Recommended Actions

These precursory APIs are not yet supported by F5, but may become official, public, supported BIG-IQ APIs in the future. No additional documentation about these APIs are available at this time as they are likely to change. Their REST endpoints are listed here because a precursory API may be necessary to automate some important BIG-IQ workflows. Any undocumented BIG-IQ APIs not listed in existing documentation are private and should not be used.
