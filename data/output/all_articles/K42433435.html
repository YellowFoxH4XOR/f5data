Description
A virtual server remains up / green when all pool members in the attached default pool are marked down / red.

Environment

  • Virtual server with default pool
  • iRule applied to VIP uses the pool command to select another pool

Cause
This is expected behavior. When a pool is referenced in an iRule and it has available pool members, the virtual server where it is applied will remain available even if the default pool is unavailable. Please see K73440174: How referenced pools in iRules affect VIP status

Recommended Actions
The virtual server can be manually disabled if you do not wish for it to be available
