K25501808: After BIG-IP upgrade, legacy applications in BIG-IQ do not show data

Type
Support Solution
Published
2022-03-08
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K25501808

Description
After an upgrade of BIG-IP, legacy applications created in BIG-IQ no longer shows data.

Environment

  • BIG-IQ
  • BIG-IP upgrade

Cause
The BIG-IP configuration file /var/config/rest/downloads/app_mapping.json is not carried forward in the upgrade process.

Recommended Actions

Recreate one of the legacy applications on the BIG-IQ.
For more information refer to: K02142132: Requirements and recommendations for creating a BIG-IQ application service with existing device configurations
Note: After recreating the legacy application the file app_mapping.json reappears on the BIG-IP with all the legacy applications / tags.
