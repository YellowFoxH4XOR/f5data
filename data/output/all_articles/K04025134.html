Known Issue

The BIG-IP AFM system bypasses rules when traffic is internally forwarded to a redirected virtual server.

This issue occurs when the following condition is met:

  • Incoming traffic matches a virtual server and then the system internally redirects the traffic to another virtual server either by way of an iRule or a BIG-IP LTM local traffic policy.

Impact

This issue has the effect of potentially negating firewall protections for the traffic that the system redirects to a different virtual server (application), if that virtual server contains an enabled BIG-IP AFM policy.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP AFM system bypasses rules when traffic is internally forwarded to a redirected virtual server.
