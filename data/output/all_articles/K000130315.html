K000130315: Policy Sync is not supported between members belonging to the same Sync-Failover device group.

Type
Support Solution
Published
2022-12-22
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.1
Source
https://my.f5.com/manage/s/article/K000130315

Description

Policy Sync is not supported between members belonging to the same Sync-Failover device group.

All APM Policies must be synchronized using Config Sync among members belonging to the same Sync-Failover device group.

 

Environment

BIG-IP APM

Sync Failover device group

 

Cause

Policy Sync is a function that synchronizes APM Policy individually.

The purpose of Policy Sync is to reuse the APM Policy in the Sync-Only device group.

 

On the other hand,All APM policies must be synchronized between devices belonging to Sync-Failover device group using Config Sync.

It is not support to use Policy Sync to synchronize individual APM Policy among devices belonging to a Sync-Failover device group.

 

Recommended Actions

Members belonging to the same Sync-Failover device group must be synchronized by Config Sync.

 

Additional Information

None.
