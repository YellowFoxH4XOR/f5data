Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K14212: Displaying BIOS version information for BIG-IP systems (11.x)

BIOS version information displays differently depending on the BIG-IP software you are running.

BIG-IP 9.4.0 through 10.2.4

Beginning in BIG-IP 9.4.0, you can display the BIOS revision information using the bigpipe platform command. In BIG-IP 9.4.0 through 10.2.4, display the BIOS revision information by performing the following procedure:

  1. Log in to the BIG-IP command line.
  2. To display the BIG-IP plaform information, including BIOS revision, type the following command:

    bigpipe platform

    The command output appears similar to the following example:

    PLATFORM INFORMATION --
    | Type: D68
    | Chassis serial: bip069724s Level 200 part: 200-0161-03 REV A
    | Switch board serial: PCA0084MF356 part: PCA-0084-02 REV A
    | Host board serial: TY5AP1110269 part: MOB-0018-01 REV A
    | Annunciator board serial: 909911 part: OEM-0029-03 REV A
    | BIOS Rev: AMIBIOS(C)2003 American Megatrends, Inc. BIOS Date:
    12/02/04 11:04:20 Ver: 08.00.10 TYAN High-End Dual AMD Opteron
    BIOS vF5-7 OBJ-0092-00 REV. H
    | base MAC 00:01:D7:30:D7:C0
    |
    | CPU 1 - temp 36degC fan speed 6750rpm
    | CPU 2 - temp 44degC fan speed 6750rpm
    |
    | CHASSIS TEMPERATURE
    | (101) 30degC
    |
    | CHASSIS FAN
    | (101) active (102) active (103) active (104) active
    | (105) active (106) active
    |
    | POWER SUPPLY
    | (101) active (102) missing

    In this example, the BIOS version is 08.00.10, REV. H

BIG-IP 9.0.0 through 9.3.0

BIG-IP 1500 platform

You can display the BIOS version and revision information by performing the following procedure:

  1. Log in to the BIG-IP command line.
  2. Type the following command:

    dd bs=65k count=10 skip=15 </dev/mem|strings|grep -e BIOS -e REV

    The command output appears similar to the following example:

    Phoenix - AwardBIOS v6.00PG
    IBM COMPATIBLE 486 BIOS COPYRIGHT Phoenix Technologies, Ltd
    Phoenix - AwardBIOS v6.00PG
    odTYAN Tomcat I7210 S5112 02092006 OBJ-0084-01 REV. J
    10+0 records in
    10+0 records out

    In this example, the BIOS version is v6.00, REV. J.

BIG-IP 3400, 6400, 6800, 8400, 8800 platforms

The BIOS version and revision information can be displayed by performing the following procedure:

  1. Log in to the BIG-IP system command line.
  2. Type the following command:

    dd bs=65k count=10 skip=15 </dev/mem|strings|grep BIOS

    The command output appears similar to the following example:

    89:American Megatrends, Inc. EPP BIOS 00.32
    AMIBIOS 080010
    AMIBIOS(C)2003 American Megatrends, Inc.
    BIOS Date: 12/02/04 11:04:20 Ver: 08.00.10
    TYAN High-End Dual AMD Opteron BIOS vF5-7 OBJ-0092-00 REV. H
    10+0 records in
    10+0 records out

    In this example, the BIOS version is 08.00.10, REV. H.
