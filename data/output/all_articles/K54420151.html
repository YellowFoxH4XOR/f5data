K54420151: RULE_INIT event crash TMM when an illegal command is added

Source

Description
When an illegal command is added to a RULE_INIT event TMM restarts and a core file is generated.
Note: An illegal command is any command that is not used to initialize a global variable.

Environment

  • BIG-IP LTM
  • iRules
  • Illegal commands

Cause
Invoking illegal command on RULE_INIT iRule causes TMM to restart.

Recommended Actions

  1. RULE_INIT has to be used only to initialize global variables
  2. Remove illegal commands from the RULE_INIT event.
