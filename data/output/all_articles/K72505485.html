Description

Unable to upgrade from 13.x. or 15.x

The Configuration Utility (GUI) shows a banner with the following error message:

This device is not operational because the loaded configuration contained errors or unlicensed objects. Please adjust the configuration and/or the license, and re-license the device.

Environment

  • BIG-IP Virtual Edition
  • Following upgrade from 13.x or 15.x

Cause

Some license SKUs are limited to 13.x or 15.x. The list of limited license SKUs can be found in K15667 in Related Content.

Recommended Actions

If your license SKU is listed in K15667, you must upgrade the license to a Version Plus perpetual license, move to Subscription license, or ELA.

None
