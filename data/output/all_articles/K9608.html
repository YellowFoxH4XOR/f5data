Topic

This article applies to the BIG-IP 800, 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 series platforms. For information about other versions, refer to the following articles:

  • K11400446: Configuring AOM network access (i2000, i4000, i5000, i7000, and i10000 series platforms)
  • K14595: Configuring AOM network access (2000, 4000, 5000, 7000, and 10000 series platforms)

Always-On Management (AOM) is a separate subsystem that provides lights-out management for the BIG-IP system. You can configure AOM so that it can be accessed over the network by performing one of the following two methods:

  • Configuring the AOM IP address using the serial console
  • Configuring the AOM IP address using SSH

Note: The AOM IP address and the BIG-IP management address may result in the neighboring switch to which the management port is connected registering two IP addresses and MAC addresses. This behavior may result in switches that are enabled with port security identifying them as unauthorized devices.

You can back out of the configuration by performing one of the following two methods:

  • Removing the AOM IP address using the serial console
  • Removing the AOM IP address using SSH

Configuring the AOM IP address using the serial console

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Access AOM by following the instructions specified in K14594: Accessing the AOM Command Menu.
  2. Type N to select the AOM network configurator option.

    Note: The N option is available only when accessed through the serial console; it is not available through secure shell (SSH).

  3. Enter the requested configuration information, as prompted.

    Important: The AOM IP address must be different than the BIG-IP management address, but must be on the same IP subnet.

    For example:

          AOM Linux Management Network Configurator

          Use DHCP? n
          Host name (optional):                  test.askf5.com
          IP address (required):                 10.90.101.21
          Network mask (required):               255.255.255.0
          Broadcast IP address (optional):       10.90.101.255
          Default gateway IP address (optional): 10.90.101.1
          Nameserver IP address (optional):      10.90.105.50
          Nameserver IP address (optional):

  4. Test the AOM login by opening an SSH session to the IP address that you configured.

    Note: Access AOM using the management port and the same login credentials that you use for the BIG-IP root account.

Configuring the AOM IP address using SSH

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: The option to configure the AOM IP address using SSH is only available for the BIG-IP 1600, 3600, 3900, 6900, 8900, 8950, 11000, 11050 and the Enterprise Manager 4000 platforms. Newer platforms only support configuring an AOM IP address using the serial console.

  1. Log in to the command line using the root account.
  2. To log in to the AOM subsystem, type the following command:

    ssh aom

  3. To run the AOM network configurator, type the following command:

    netconfig

  4. Enter the requested configuration information, as prompted.

    Important: The AOM IP address must be different than the BIG-IP management address, but must be on the same IP subnet.

    For example:

          AOM Linux Management Network Configurator

          Use DHCP? n
          Host name (optional):                  test.askf5.com
          IP address (required):                 10.90.101.21
          Network mask (required):               255.255.255.0
          Broadcast IP address (optional):       10.90.101.255
          Default gateway IP address (optional): 10.90.101.1
          Nameserver IP address (optional):      10.90.105.50
          Nameserver IP address (optional):

  5. Test the AOM login by opening an SSH session to the IP address that you configured.

    Note: Access AOM using the management port and the same login credentials that you use for the BIG-IP root account.

Removing the AOM IP address using the serial console

Impact of procedure: The AOM subsystem will not be accessible from the network after performing the procedure.

  1. Access AOM by following the instructions specified in K9403: Overview of the AOM subsystem.
  2. Type N to select the AOM network configurator option.

    Note: The N option is available only when accessed through the serial console; it is not available through SSH.

  3. Enter the requested configuration information as prompted.

    For example:

        AOM Linux Management Network Configurator

          Use DHCP? n
          Host name (optional):                  
          IP address (required):                 0.0.0.0

    Note: The removal of the AOM IP address will take effect immediately after performing the steps described in this section.

Removing the AOM IP address using SSH

Impact of procedure: The AOM subsystem will not be accessible from the network after performing this procedure.

  1. Log in to the command line.
  2. To log in to the AOM subsystem, type the following command:

    ssh aom

  3. To run the AOM network configurator, type the following command:

    netconfig

  4. Enter the requested configuration information as prompted.

    For example:

      AOM Linux Management Network Configurator

          Use DHCP? n
          Host name (optional):                  
          IP address (required):                 0.0.0.0

    Note: The removal of the AOM IP address will take effect immediately after performing the steps described in this section.
