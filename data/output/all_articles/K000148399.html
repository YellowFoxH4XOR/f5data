Description

Due to Bug ID 778225, vCMP guests may not have the f5_api_com key and certificate installed when licensed by the vCMP host. This issue prevents the update of protocol inspection settings directly on the vCMP guests. As a workaround, you can use BIG-IQ to perform the protocol inspection updates on your vCMP guests.

Environment

  • BIG-IQ
  • BIG-IP AFM
  • Protocol Inspecion
  • vCMP 

Cause

None

Recommended Actions

To work around this issue, you can use BIG-IQ to perform the protocol inspection updates. Article K000138301: Updating the BIG-IP AFM protocol inspection signatures using the BIG-IQ system outlines the detailed steps to perform this action

Note: This procedure can be used by any vCMP guests, not exclusively those affected by Bug ID 778225. The intention of this article is to address a customer scenario where they can work around the issue caused by the bug by using BIG-IQ
