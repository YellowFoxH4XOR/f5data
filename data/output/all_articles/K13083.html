Topic

The Configuration utility supports basic syslog configurations, such as defining module (such as LTM, GTM, and ASM) and audit log levels. To adjust system log levels such as cron, kern, or messages you must use the tmsh syslog command. If you want to perform more extensive syslog customizations, you use the tmsh modify sys syslog include command. For an example of how to use the include option, refer to K13333: Filtering log messages sent to remote syslog servers (11.x - 17.x).

Note: For a list of configurable syslog settings, refer to the F5 TMSH Reference on F5 Cloud Docs.

Adjusting system log levels with tmsh syslog commands

  • To list the current syslog configuration, enter the following command at the tmsh prompt:

    list /sys syslog all-properties

  • To list the lowest level of a specific facility's messages to include in logs, enter the following command at the tmsh prompt :

    list /sys syslog <facility>-from
    For example:
    list /sys syslog cron-from

  • To list the highest level of a specific facility's messages to include in logs, enter the following command at the tmsh prompt:

    list /sys syslog <facility>-to
    For example:
    list /sys syslog cron-to

  • To modify the lowest level of a specific facility's messages to include in logs, enter the following command at the tmsh prompt :

    modify /sys syslog <facility>-from <severity level>
    For example:
    modify /sys syslog cron-from debug

  • To modify the highest level of a specific facility's messages to include in logs, enter the following command at the tmsh prompt:

    modify /sys syslog <facility>-to <severity level>
    For example:
    modify /sys syslog cron-to alert

  • Changes made with the tmsh syslog commands must be saved in order to persist after a configuration reload. To save changes, enter the following command:

    save /sys config

  • To display the syslog help page, enter the following command:

    help /sys syslog

    Note: To quit the help page, enter q.

Adding a remote syslog server with tmsh syslog commands
Note: This can also be performed with the Configuration utility

  • To configure the IP address of a remote server to which syslog sends messages, use the following tmsh syntax:

    modify /sys syslog remote-servers add {<server name> {host <server IP address> remote-port <port number>}}

    For example:

    modify /sys syslog remote-servers add {server{host 192.168.1.1 remote-port 514}}

  • To configure the local IP address which the syslog binds to for sending logs to the remote server, use the following tmsh syntax:

    modify /sys syslog remote-servers modify { <name> { local-ip <IP address> }}

    For example:

    modify /sys syslog remote-servers modify { server { local-ip 192.168.68.42 }}

  • Changes made with the tmsh syslog commands must be saved in order to persist after a configuration reload. To save changes, enter the following command:

    save /sys config
