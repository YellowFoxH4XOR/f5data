K000162422: BIG-IQ Remote Backup Fails with UcsBackupRestoreTaskWorker: verify: false

Type
Support Solution
Published
2026-07-23
Updated
2026-07-23
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.0
Source
https://my.f5.com/manage/s/article/K000162422

Description

BIG-IQ Centralized Management remote UCS backup archiving fails while establishing an SSH connection to the remote backup server.

The BIG-IQ restjavad log may contain messages similar to:

[ERROR][XX Jul 2026 12:XX:XX PDT][/cm/system/backup-restore/XXX-XXX-XXX/worker UcsBackupRestoreTaskWorker] to archive backup while making ssh connection to XXX.XXX.XXX.XXX verify: false

The remote SSH server may also log:

com.jcraft.jsch.JSchException: verify: false

Environment

  • BIG-IQ
  • Remote backup or UCS archive operation
  • Remote SSH server configured with HostKeyAlgorithms ecdsa-sha2-nistp521

Cause

The BIG-IQ Centralized Management backup process does not support the remote SSH server's ecdsa-sha2-nistp521 host-key algorithm. The SSH library used by the backup process terminates the connection and reports:

... UcsBackupRestoreTaskWorker] to archive backup while making ssh connection to XXX.XXX.XXX.XXX verify: false

The remote SSH server must offer a supported host-key algorithm, such as ecdsa-sha2-nistp256 or ssh-rsa.

Answer/Recommended Actions

Configure the SSH daemon to use supported host-key algorithms:

HostKeyAlgorithms ecdsa-sha2-nistp256,ssh-rsa

Additional Information

ecdsa-sha2-nistp521 is not supported for HostKeyAlgorithms either. F5 tracks this as ID 1701809.
