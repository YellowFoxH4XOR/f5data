Known Issue

Descriptions are missing for the ltmNodeAddrMonitorState and ltmNodeAddrMonitorStatus Simple Network Protocol (SNMP) object identifier (OID) values.

This issue occurs when all of the following conditions are met:

  • You perform snmpwalk for the ltmNodeAddrMonitorState and/or ltmNodeAddrMonitorStatus SNMP OIDs.
  • The nodes are configured to display their fully qualified domain name (FQDN).

Impact

The integer values ranging from 25 to 29 are not documented for the ltmNodeAddrMonitorState and ltmNodeAddrMonitorStatus SNMP OIDS.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The ltmNodeAddrMonitorState and ltmNodeAddrMonitorStatus SNMP OIDS may return integer values ranging from 26 to 29, for which descriptions are not provided in the F5-BIG-IP-LOCAL-MIB file.

Resolution

Status

F5 Product Development has assigned ID 670443 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

The issue is cosmetic and does not affect operation or traffic; it is a documentation issue within the MIB file.

The integer values and associated meanings for 26 to 29 for both ltmNodeAddrMonitorState and ltmNodeAddrMonitorStatus include the following:  
     
fqdnChecking(26)    "Node address service checking is enabled, but result is not available yet"
fqdnDown(27)        "The DNS server(s) are unavailable"
fqdnUp(28)          "The DNS server(s) are available"
fqdnUpNoAddress(29) "No records returned"
