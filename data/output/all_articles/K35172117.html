Description

A WideIP configured with multiple Pools continue responding to DNS queries referencing pool member(s) that are down.

Environment

  • BIG-IP DNS
  • WideIP
  • Multiple pools configured

Cause

The Fallback option for the Pool is configured as "Return to DNS" by default.

Recommended Actions

Set the Fallback option for all Pools to "None".
