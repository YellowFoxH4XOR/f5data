Known Issue

This is the result of a known issue. A Mac OS X user may be unable to connect to Network Access if both the Ethernet and wireless adapters are enabled and connected to the same network. If the user attempts to launch Network Access under these conditions, the Network Access window will appear and then quickly exit. This error occurs because the routing table contains duplicate routes, which causes Network Access to exit. 

F5 Product Development tracked this issue as ID 317913 (formerly CR129143) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in cumulative hotfix HF-610-4, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
