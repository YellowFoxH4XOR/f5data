When configuring a new email role in ARX, you must decide which events should trigger email notifications. To view a full list of email events along with their default severities, use the show email-severity all command.

Note: You can use the email-severity [event-name] level command to change the default severity of an email event.

Configuring an email role that only receives critical severity notifications

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter configuration mode by typing the following command:

    config
  4. Create a new email role by typing the following command, where [role name] is the name of the role you want to configure:

    email-event [role name] 

    For example:

    email-event critical
  5. Configure the email address that will receive the notifications by typing the following command:

    mail-to [email address]

    For example:

    mail-to alerts@example.com
  6. Add the critical severity events by typing the following commands:

    Note: The command group network event gateway-offline was introduced in ARX version 4.0.1. If you are running an previous version of ARX, you will receive a configuration error if you enter that command.

    group chassis event bounce-limit
    group chassis event disk-control-failure 
    group chassis event disk-failure
    group chassis event fan-failure
    group chassis event module-failure
    group chassis event nvram-battery-failure 
    group chassis event nvram-ecc-error
    group chassis event power-failure
    group chassis event temperature-failure 
    group chassis event warm-start
    group metadata event free-space-threshold
    group metadata event offline  
    group network event gateway-offline

  7. Enable the email role by typing the following command:

    enable

ARX is now configured to email critical event notifications to the email address you specified.
