K7770: The View as plain text feature for Windows Files supports only English character sets

Type
Knowledge
Published
2007-08-20
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.0.1, 6.0.0
Source
https://my.f5.com/manage/s/article/K7770

Topic

The View as plain text feature for Windows Files can be used to display files that are encoded in English character sets. This feature cannot be used to display files that are encoded in other character sets such as Japanese, Korean, or Chinese character sets.

Workaround

You can work around this issue using the Load into browser feature instead.
