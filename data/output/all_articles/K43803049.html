Description

You recently created a new HSM Security World and get the following error when attempting to reinstalling the client on BIG-IP by running the nethsm-thales-install.sh script:

...
RFS syncing complete.
Setting Thales HSM for use with 'fipskey.nethsm' ...
Setting hsm to [Thales]
ckinfo: C_Initialize failed rv = 00000006 (CKR_FUNCTION_FAILED)
ERROR: Install procedures did not succeed - 'ckinfo' failed. Unexpected error.

ERROR: Install failed.  Attempting to clean-up ...


 

Environment

  • Thales HSM
  • BIG-IP
  • New HSM Security World

Cause

ckinfo failed to initialize.

Recommended Actions

If you have recently changed to a new HSM Security World, then it is likely that RFS still contains key files from the old Security World which should be removed from the system.  Use the following procedure to identify old key files.

Run nfkmcheck to identify warning messages.

Example:

nfkmcheck: warning: Key pkcs11 uaf652df13c11206cbb0a5345eeee5c8d02670ed34 kmdata BlobKA KM found
ad6ce8f31a0834405f8ea4bc88c9575791d1cad7 expected f1345eaae97bcd344513483c6e877a8a7d169ef0

nfkmcheck: warning: Key pkcs11 uaf652df13c11206cbb0a5345eeee5c8d02670ed34 kmdata BlobRecoveryKA blob format found 8 expected 9

The key files identified do not belong to the current HSM Security World and should be removed from the /opt/nfast/kmdata/local/ directory on RFS.

Additional Information

Refer to Manual and netHSM installation documentation and ensure valid Module and Security World files are stored on RFS
