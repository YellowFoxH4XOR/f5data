Description

vCMP guest is INOPERATIVE after a reboot, and continuously logging the following message to /var/log/ltm:

warning clusterd[<PID>]: 012a0004:4: halGetChassisAllSlots: error 1

The output of show sys mcp-state shows the following:

-------------------------------------
Sys::mcpd State:
-------------------------------------
Running Phase                   none
Last Configuration Load Status  none
End Platform ID Received        true
Cluster Quorum Reached          false

Attempting to load a UCS file produces the following error:

Unexpected Error: Saving and loading a UCS is only allowed on the primary slot.

Environment

  • vCMP
  • After reboot

Cause

vCMP host is in a forced offline state.

Recommended Actions

Release the vCMP host from the forced offline state:

tmsh run sys failover online

Additional Information

There is typically no good reason to force offline a vCMP host.
