K4438: The BIG-IP may not use a renewed SSL certificate

Applies to

  • BIG-IP 4.X: 4.6.4

Topic

If a new SSL certificate has the same name as the previous certificate, the BIG-IP system does not require that you add the new SSL certificate to existing SSL proxies. Existing SSL proxies will continue to use the previous SSL certificate, as it is already loaded into memory. Therefore, if the SSL certificate has expired, the BIG-IP system will continue to use the expired certificate.

To prompt the existing SSL proxies to use the new certificate, you must restart the proxyd process. You can restart the proxyd process by reloading the configuration or restarting the BIG-IP system.

To reduce the impact on existing traffic, F5 Networks recommends that you restart the proxyd process manually. To do so, type the following command:

proxyd
