Topic

This article describes the CPU behavior for the BIG-IP iSeries i850 platform when attempting to validate system capacity based on CPU utilization.

Description

This behavior applies to the following platform:

  • BIG-IP i850

Behavior

Unlike previous platforms, the BIG-IP i850 may report between 50 to 70 percent CPU utilization when at full capacity. This is expected behavior due to the design of the BIG-IP i850, which displays in both the Configuration utility and the top command output. The specific number is workload-dependent. You should not use this number as an indicator of system capacity for sizing or performance purposes. 

Recommendation

To determine the actual capacity under a specific workload, refer to the BIG-IP reported statistics and compare them to published capabilities on the BIG-IP System Hardware Datasheet.
