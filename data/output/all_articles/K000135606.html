Description

How to export Virtual Server status to a .csv file.

Environment

  • BIG-IP command line
  • Familiarity with command line text editors such as vi or nano

Cause

You should use this procedure when you need to export the Virtual Server's status across the configured partition of a BIG-IP system info to a .csv file.

Recommended Actions

  1. Log in to the BIG-IP command line as the root user.
  2. Change the working directory to /tmp by entering the following command:

    cd /tmp

  3. Use a text editor such as vi or nano to create a script.
  4. Paste the following script in the text editor:

    #!/bin/bash

    echo \"VS name\",\"Destination\",\"Availability\",\"State\",\"Reason\",\"CMP\",\"CMP Mode\"
    VIRTUALS=$(tmsh -q -c "cd / ; list /ltm virtual  recursive" | grep "ltm virtual" | awk -F' ' '{print "/"$3}')
    for VS in $VIRTUALS;
    do
        echo -n \"$VS\",
        DEST=$(tmsh show ltm virtual $VS | grep Destination | cut -d: -f2,3)
        echo -n \"$DEST\",
        AVAIL=$(tmsh show ltm virtual $VS | grep Availability | cut -d: -f2)
        echo -n \"$AVAIL\",
        STATE=$(tmsh show ltm virtual $VS | grep State | cut -d: -f2)
        echo -n \"$STATE\",
        REASON=$(tmsh show ltm virtual $VS | grep Reason | cut -d: -f2)
        echo -n \"$REASON\",
        CMP=$(tmsh show ltm virtual $VS | grep "CMP              :" | cut -d: -f2)
        echo -n \"$CMP\",
        MODE=$(tmsh show ltm virtual $VS | grep "CMP Mode" | cut -d: -f2)
        echo -n \"$MODE\"
        echo
    done

  5. Save the changes. If you are using nano, press Ctrl+x and type Y to save the changes and exit the editor. If you are using vi, enter the key sequence :wq! to save the changes and exit the editor.
  6. Change the permissions of the script file by entering the following command:

    chmod a+x <script filename>

  7. You can verify the script file is saved correctly by using the cat command:

    cat <script filename>

  8. Execute the script and wait till it completes:

    ./<script filename>

  9. You should observe an output similar to the following example:

    "VS name","Destination","Availability","State","Reason","CMP","CMP Mode"
    "/Common/http-vs"," 192.168.155.51:80"," available "," enabled "," The virtual server is available"," enabled "," all-cpus "
    "/Common/https-vs"," 192.168.155.51:443"," available "," enabled "," The virtual server is available"," enabled "," all-cpus "

  10. Copy and paste the output into a text file and save it with file extension .csv on your local workstation. You can then use your Excel spreadsheet or any application that supports Comma Separated Values (CSV) format to open the .csv file.

Additional Information

F5 Support does not provide support for the script provided in this article. Please be aware that if you need to modify the script to gather some other information, you should modify the script as needed to suit your requirements. (This is beyond F5 Support scope)
