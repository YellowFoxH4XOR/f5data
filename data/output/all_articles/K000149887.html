K000149887: Provisioning AFM breaks BFD by blocking egressing BFD traffic.

Type
Support Solution
Published
2025-02-20
Updated
2025-02-20
Source
https://my.f5.com/manage/s/article/K000149887

Description

Provisioning AFM blocks egressing BFD traffic.

Environment

BigIP AFM 17.1.1

Cause

'peer-group' aci is blocking egressing BFD traffic.

Recommended Actions

Delete the peer-group aci and add the failover & remote-as config to the neighbor statement by executing the following commands:

tmsh modify net routing bgp bgp-rd0-to-aci neighbor modify { 192.168.0.1  { peer-group none enabled true fall-over bfd remote-as 64886}}

tmsh modify net routing bgp bgp-rd0-to-aci neighbor modify { 192.168.0.2 { peer-group none enabled true fall-over bfd remote-as 64886}}

tmsh modify net routing bgp bgp-rd0-to-aci peer-group delete { aci }

tmsh save sys config

Additional Information

The final version of /config/bigip_routing.conf is:

#TMSH-VERSION: 17.1.1.3

net routing bgp /Common/bgp-rd0-to-aci {
 address-family {
 ipv4 {
 redistribute {
 kernel { }
 }
 }
 ipv6 { }
 }
 local-as 64888
 neighbor {
 192.168.0.1 {
 address-family {
 ipv4 { }
 ipv6 {
 activate disabled
 }
 }
 fall-over bfd
 remote-as 64886
 }
 192.168.0.2 {
 address-family {
 ipv4 { }
 ipv6 {
 activate disabled
 }
 }
 fall-over bfd
 remote-as 64886
 }
 }
 profile /Common/bgp-rd0-to-aci
 route-domain /Common/0
}
net routing route-map /Common/rm-kernel {
 route-domain /Common/0
}
net routing profile bgp /Common/bgp-rd0-to-aci {
 app-service none
 max-paths {
 ebgp 2
 }
}
