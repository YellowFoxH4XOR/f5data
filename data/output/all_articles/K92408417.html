K92408417: TCL error after removing BIG-IP from BIG-IQ

Type
Support Solution
Published
2020-10-29
Updated
2025-02-07
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K92408417

Description

After removing BIG-IP from BIG-IQ, you see the following TCL error logs in /var/log/ltm

Script (/Common/bigiq-analytics-send_stats) generated this Tcl error: (script did not successfully complete: (could not read "/shared/tmp/bigiq-analytics-stats_0": no such file or directory

Environment

  • BIG-IQ
  • BIG-IP, recently removed from BIG-IQ
  • BIG-IQ Analytics iApp deployed on BIG-IP

Cause

Errors are generated by BIG-IQ Analytics iApp no longer having data to send to BIG-IQ

Recommended Actions

  1. Review BIG-IP's currently deployed iApps
  2. Delete BIG-IQ Analytics iApp

Additional Information

None
