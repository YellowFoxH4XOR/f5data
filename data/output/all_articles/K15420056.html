K15420056: How to manually license FCP in BIG-IQ

Type
Support Solution
Published
2019-12-16
Updated
2026-04-22
Applies to
  • Virtual Editions
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 6.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K15420056

Description
You need to activate Flexible Consumption Program (FCP) Catalog Base Registration Key (BRK) on BIG-IQ device.

Your BIG-IQ does not have Internet access.

You must ensure ALL license offerings are activated even if you are not intending to use them

Environment

  • BIG-IQ 
  • FCP
  • Catalog Base Registration Key (BRK)

Cause
None

Recommended Actions

Important: Please ensure to copy each dossier and each created license file only once per license offering (see additional information below)

Download the Catalog Base Registration Key (BRK)

  1. Logon to MyF5 > Subscriptions > Subscription ID (active) 
  2. Copy the Catalog Base Registration Key (BRK)

Note: Please contact your Customer Success Manager if this subscription isn't available via my.f5.com. 

Activate Catalog Catalog Base Registration Key (BRK) in BIG-IQ

  1. Log into BIG-IQ 
  2. Select devices tab
  3. Expand License Management on the left pane and choose licenses
  4. Click Add License (not Add RegKey Pool)
  5. Enter valid license name and Catalog Base Registration Key (BRK)
  6. Select Manual within the Activation Method
  7. Generate the dossier 
  8. Click the link to access the F5 licensing portal.
  9. Paste the dossier into the Enter Your Dossier box, and then click Next
  10. In the  End User License agreement box, review and click on Agree and click Next
  11. Copy the license and paste it into the License box on the BIG-IQ device.
  12. Click on Activate in the right hand corner of the screen.
  13. Observe the license status which is currently Pending. 

Activate ALL individual license offerings

  1. Click on the License Name to expand its license offerings
  2. Select the relevant offering name
  3. Copy dossier from Device Dossier box. 
  4. Click the link to access the F5 licensing portal.
  5. Paste the dossier into the Enter Your Dossier box, and then click Next
  6. Copy the license and paste it into License text on BIG-IQ
  7. Click on Activate in the bottom right of the screen.

Repeat this for ALL of the FCP license offerings, even if you are not planning to use them.

Note: The status will show as Pending with a yellow triangle until all offerings are activated, Please ensure to activate ALL of the offerings.

Once CAT key and All of  its license offerings are activated on the BIG-IQ, you can begin assigning licenses to managed or unmanaged BIG-IP VE devices per K02061834: How to license BIG-IP from BIG-IQ License Manager using FCP .

Additional Information
It is important to ensure that you activate ALL of the license offerings at this stage, even if you are not intending to use all of them.

In the future should you need to upgrade or apply a hot-fix, you could face license re-activation is greyed out issue, meaning all offerings were not activated at this time.
