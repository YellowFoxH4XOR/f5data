Description

Can Classic BIG-IP VE be deployed on Azure Gen 2 Virtual Machines?

Environment

BIG-IP VE

Cause

Classic BIG-IP VE is not supported on Azure Gen 2 VM.

Recommended Actions

Classic BIG-IP VE is supported as presented in the following articles:

  • F5 BIG-IP Virtual Edition in Microsoft Azure
  • Deploy F5 BIG-IP Virtual Edition VM in Azure

For current support options regarding Azure Gen 2 Virtual Machines, please contact F5 Support to discuss available alternatives and workarounds.
