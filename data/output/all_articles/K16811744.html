Description
Apply Policy fails due to policy corruption in PLC database from a previously enforced signature resulting in an error in var/log/ts/asm_config_server.log
asm_config_server.pl|CRIT|Apr 17 03:27:57.694|22261|F5::Sigfile::Update::store_error_and_die,,Failed to insert to DCC.ACCOUNT_NEGSIG_SIGNATURE_PROPERTIES (DBD::mysql::db do failed: Duplicate entry '11452915924510514816' for key 'PRIMARY' at /usr/local/share/perl5/F5/BatchInsert.pm line 219.
)

Environment

  • BIG-IP 13.x versions
    • ASM provisioned and in use

Cause
Corruption in PLC database from a previously enforced signature. Bug ID 759360

STEPS TO REPRODUCE:

  1. Create a new policy.
  2. Associate "All Signatures" with policy.
  3. Enforce all signatures from ""
  4. Apply policy.
  5. Update ASM signatures (ASU) with at least one updated signature.
  6. Export policy as XML.
  7. Update ASM signatures (ASU) with a more recent .im than in Step #5.
  8. Import XML policy from Step #6.
  9. Apply newly imported policy
    At this point you'll experience the aforementioned error in the logs.

Recommended Actions

  1. As a workaround, run the following SQL
    UPDATE PLC.PL_POLICY_NEGSIG_SIGNATURES SET previous_enforced_rule_md5 = '' WHERE previous_enforced_rule = '' and previous_enforced_rule_md5 != ''

    Example:
    #mysql -uroot -p`perl -I/ts/packages -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw`  -e "UPDATE PLC.PL_POLICY_NEGSIG_SIGNATURES SET previous_enforced_rule_md5 = '' WHERE previous_enforced_rule = '' and previous_enforced_rule_md5 != ''"

  2. Apply the policy
