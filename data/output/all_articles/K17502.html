Known Issue

The BIG-IP system bypasses packet filters for certain Internet Control Message Protocol (ICMP) echo requests.

This issue occurs when all of the following conditions are met:

  • A packet filter rule is configured to block ICMP request traffic to a virtual address.
  • The BIG-IP system receives an ICMP packet that was fragmented before it reached the BIG-IP system.

Impact

ICMP traffic is not blocked, despite the existence of a packet-filter rule.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system appears to intermittently respond to ICMP echo requests, even though a packet filter is configured to block that traffic.
