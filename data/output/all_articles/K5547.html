Topic

The standard BIG-IP system serial port tty00 configuration is used for console access, while the serial port tty01 is used for hardware failover.

The BIG-IP system software allows you to configure the tty00 serial port for hard-wired failover; however, serial port tty00 is not functional for hard-wired failover on all platforms.

Use of tty00 for hard-wired failover functionality is only supported on the following platforms:

  • BIG-IP 520 and 540 (D35)
  • BIG-IP 1000 (D39)
  • BIG-IP 2400 (D44)
  • BIG-IP 5100 and 5110 (D51)
