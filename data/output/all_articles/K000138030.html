Description

  • There are certain logs that tells you when a config manager was able to push a config successfully.
  • These logs are present in /opt/traffix/sdc5.1_XX_X/logs/config_mgr/config_mgr.log and /var/log/rsyslog/<Nodename>.<CMprocess>.main.log
  • This is what a successful EMS config push to SDC looks like : Note that the logs was taken from SDC 1 which is SDC01. Peer SDC SDC02. "from: NodeInfo" tells us where the config change/update is coming from.
