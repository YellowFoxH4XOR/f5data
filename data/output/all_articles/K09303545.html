K09303545: New devices don't get update from ''Stats last collection data'' on BIG-IQ CM GUI

Type
Support Solution
Published
2021-08-18
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K09303545

Description

  • New discovered/imported BIG-IP devices on BIG-IQ doens't get the "Stats last collection data" column updated
  • Column "stats last collection data" shows Jan 01, 1970 01:00:00(CET).

Environment

  • BIG-IQ CM
  • BIG-IQ DCD
  • BIG-IP with AVR provisioned
  • BIG-IP statistical data

Cause

Analytics data is sent from BIG-IP device to BIG-IQ DCD. If the BIG-IP device cannot reach the BIG-IQ DCDs on port 443 the "Stats last collection data" column will show "Jan 01, 1970 01:00:00(CET)"

Recommended Actions

You need to ensure network communication between BIG-IP devices and BIG-IQ DCDs on port 443.

Additional Information

None.
