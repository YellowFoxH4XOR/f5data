Known Issue

If you import an access profile that is configured with an active directory AAA pool, the import may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is running any of the following software versions:

    BIG-IP 11.3.0 HF3 - BIG-IP 11.3.0 HF5

  • You export an access profile where the AAA active directory configuration uses a pool of active directory servers.
  • You import the previously-mentioned exported access profile onto a BIG-IP APM system that did not create the export file.

Impact

The system fails to import the access profile.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H426303 on the Diagnostics > Identified > Low screen.
  • Importing the access profile export file produces an error message similar to the following example:

    Import Error: 01020036:3: The requested pool (<path>/<active directory pool name>) was not found. Unexpected Error: Validating configuration process failed.

  • The system does not import the access profile.

Workaround

To work around this issue, before importing the access profile, you can modify its active directory AAA configuration. To do so, perform one of the following procedures:

Impact of workaround: Modifying an active policy's AAA configuration may impact the available resources for AAA.

Modifying the Access Policy AAA active directory configuration for export

You can modify the active directory AAA access profile configuration before the export, removing the active directory server's pool reference. After the export is complete, you can revert the active directory AAA modifications, placing the access profile back to the original state.

  1. Click Access Policy.
  2. Click AAA Servers.
  3. Click Active Directory.
  4. Under Active Directory Servers, select the name of the AAA configuration that is associated with the access profile to be exported.
  5. Modify the Server Connection from Use Pool to Direct.
  6. Enter a single IP address as the Domain Controller.
  7. Click Update.
  8. Click Access Policy.
  9. Click Access Profiles.
  10. Click the Export link to the right of the access profile name.
  11. Save the export file to your local device.
  12. Click Access Policy.
  13. Click AAA Servers.
  14. Click Active Directory.
  15. Under Active Directory Servers, select the name of the AAA configuration that is associated with the access profile previously modified for exporting.
  16. Modify the Server Connection from Direct to Use Pool.
  17. For Domain Controllers add the IP address and Hostname of each desired active directory server to the pool.
  18. Click Update.

Modifying an exported access profile configuration file prior to importing

You can manually modify an exported access profile, removing the active directory AAA pool reference. Once you modify the access profile export file, you can then import it on a destination BIG-IP APM system.

  1. Using a plain text editor (vi, pico, notepad) open the saved export access profile file <original access profile name>_profile.conf.
  2. Within the exported access_profile.conf file, locate the section starting with Access Control / Aaa Active Directory Server.

    For example:

    #F5[Access Control / Aaa Active Directory Server]
    #F5[Original Name:/Common/<active directory servers pool name>, Type:s]
    #F5[$target_partition$]
    apm aaa active-directory /@partition/@name-<active directory configuration pool name> {
    admin-encrypted-password "xxxxxxxxxx"
    admin-name administrator
    domain active_directory_pool
    domain-controllers {
    <active directory server hostname> {
    ip <active directory server ip address>
    }
    <active directory server hostname> {
    ip <active directory server ip active address>
    }
    }
    pool Common/<active directory servers pool name>
    }

  3. You need to modify three items within this section before successfully importing the access profile: domain, domain-controllers, and pool.

    domain

    Change the domain line from referencing the pool of active directory servers to the actual domain name for the configuration.

    For example:

    Replace domain <active directory configuration pool name> with the domain name of the domain that is configured on the active directory server.


    domain-controllers

    Remove the domain-controllers section and replace it with a single line noting the active directory domain.

    For example, locate the following section:

    domain-controllers {
    <active directory server hostname> {
    ip <active directory server ip address>
    }
    <active directory server hostname> {
    ip <active directory server ip address>
    }
    }

    Replace the previous section with the following single line statement:

    domain-controller <active directory sever ip address>


    pool

    Remove the pool reference, replacing it with the use-pool disabled statement.

    For example:

    Replace pool Common/<active directory servers pool name> with use-pool disabled.

    The following exported access profile aaa section is configured with a pool of active directory servers:

    apm aaa active-directory /@partition/@name-active_directory_pool {
    admin-encrypted-password "xxxxxxxxxx"
    admin-name administrator
    domain active_directory_Pool
    domain-controllers {
    dc-1.mydomain.net {
    ip 172.16.2.40
    }
    dc-2.mydomain.net {
    ip 172.16.2.42
    }
    }
    pool Common/<active_directory_poo>l
    }

    The following modified, exported access profile reactive directory is ready for import.

    apm aaa active-directory /@partition/@name-active_directory_pool {
    admin-encrypted-password "xxxxxxxxxx"
    admin-name administrator
    domain mydomain.net
    domain-controller 172.16.2.42
    use-pool disabled
    }

  4. Save the changes and exit the text editor.
  5. You can now import the modified export file.
