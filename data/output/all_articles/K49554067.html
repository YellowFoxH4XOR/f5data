Known Issue

When you attempt to use a dotted group name in a request string, the icrd_child process produces a core file.

This issue occurs when the following condition is met:

  • You use the iControl REST API to request virtual server statistics, using a string that contains the dotted group name.

    For example, you use a group name containing a period, such as:

    abc.123

Impact

The icrd_child process consumes excessive CPU resources and grows rapidly, resulting in exhausted CPU resources; the process eventually produces a core file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe that the icrd_child process consumes excessive CPU resources every time you request virtual server statistics.
  • Your BIG-IP system creates an icrd_child core file in the /shared/core directory.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to clear the virtual server statistics. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To reset the virtual server statistics, use the following command syntax:

    reset-stats /ltm virtual <virtual_server_name>

    For example, type the following command:

    reset-stats /ltm virtual test-virtual
