Description

Observing large amount of connections in show /sys connection output with Idle Timeout value of 4294967295.

Environment

  • BIG-IP LTM
  • Connection table

Cause

The connections in question use indefinite idle timeout.

This is most likely to occur when a global SNAT uses a SNAT translation address with indefinite idle timeout, which is the default.

Recommended Actions

Review the configuration to determine if there are any objects with indefinite idle timeout and adjust session timeouts as appropriate.

Refer to the following article for more information:

  • K7606: Overview of BIG-IP idle session timeouts

Additional Information

In some cases the configuration in question may have already been deleted. However, this won't affect existing connections. If those connections were not closed (gracefully or forcefully) then they must be deleted from the connection table.

If you cannot find any objects in the configuration matching the suspected SNAT translation address, you can review the configuration patch files to determine if the address has already been deleted.
