Known Issue

A BIG-IP APM access policy Firewall check action fails to detect the McAfee Personal Firewall installed on the Japanese version of Windows.

This issue occurs when all of the following conditions are met:

  • The client operating system is a Japanese version of Windows.
  • McAfee Personal Firewall is installed.
  • A BIG-IP APM access policy is configured with the Firewall check action.

The BIG-IP APM system uses the OPSWAT OESIS Framework to inspect a client system for antivirus and firewall products. This inspection of the client system allows the BIG-IP APM system to validate that the client system accessing the BIG-IP meet a minimum set of requirements before allowing access.

Impact

Users are unable to access resources through the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • User receives an error message that appears similar to the following example:

    The session reference number: <sessionid>
    Access was denied by the access policy. This may be due to a failure to meet access policy requirements.

    In this error message, note the following:

    - <sessionid> is the user's sessionid

    For example:

    The session reference number: 60ed22e3
    Access was denied by the access policy. This may be due to a failure to meet access policy requirements.

  • The session information that the system logs in Access Policy >> Reports >> Session Details for the <sessionid> shows a message that appears similar to the following example:

    Following rule 'fallback' from item 'Firewall Check' to ending 'Deny'
