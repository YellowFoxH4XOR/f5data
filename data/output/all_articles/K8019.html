Known Issue

This is the result of a known issue. The HTML text area wrap attribute (the <textarea> HTML tag) is set to wrap=on for the text input boxes in the Configuration utility. The HTML text area wrap behavior varies between different browsers and versions. When the text within a text area wraps, certain browsers will interpret the line wrap as a virtual new line. As a result, the browser will incorrectly send an actual new line instead of sending a single line.

When creating an HTTP monitor in the Configuration utility, if the text in the Send String or Receive String field wraps, and the browser interprets the line wrap as an actual new line, the monitor creation will fail.

F5 Product Development tracked this issue as CR85147 and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator Release Notes.

Workaround

You can work around this issue by performing one of the following tasks:

  • Resize the browser window so that the Send String and Receive String fields are large enough to prevent the text from wrapping.
  • Use a browser that interprets wrap=on as a virtual line wrap rather than a new line.
  • Create the monitor from the command line.
