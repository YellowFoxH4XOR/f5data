K97429209: EMS cannot sync configuration data to remote SDC

Type
Support Solution
Published
2022-07-01
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.X, 5.1.0
Source
https://my.f5.com/manage/s/article/K97429209

Description

You are trying to deploy a multiple SDC sites managed by central EMS site and notice EMS cannot synchronize configuration data to a remote SDC site. Multi-site configuration management is performed by EMS Configuration Manager (CM) distributing configuration changes to SDC site CM. When synchronization issue occurs, EMS/SDC CM config_mgr.log will start logging:

WARN  [11222] first failure. could not reach endpoint: NodeInfo{nodeId=my-remote-sdc_traffix_config_mgr-config1, nodeAddress=https://10.1.2.11:61617, siteId=my-remote-sdc, nodeType=CACHE_MANAGER, isManager=false, isProxy=false, NodeVersion=5.1, sdcVersion=Version{version='5.1', build='1'}}. failed to distribute: DistributedEvent
WARN  [1111] could not reach endpoint NodeInfo{nodeId=my-remote-sdc_traffix_config_mgr-config1, nodeAddress=https://10.1.2.11:61617, siteId=my-remote-sdc, nodeType=CACHE_MANAGER, isManager=false, isProxy=false, NodeVersion=5.1, sdcVersion=Version{version='5.1', build='1'}}. failed to distribute: DistributedEvent

Asymmetric routing network path has been setup between the EMS and SDC CM communication.

Environment

  • Multiple SDC sites managed by central EMS site
  • EMS CM configuration sync failure to SDC site
  • Asymmetric routing

Cause

CM uses TLS secured communication with other components including CM to CM. It is preferred that the EMS and SDC CM communication traverse symmetry network path for stable connectivity such that configuration changes may be distributed successfully.

Recommended Actions

It is advisable to setup symmetry network path between EMS and SDC CM communication for stable connectivity and to minimize synchronize issue that may occur in asymmetry setup.

Additional Information

Asymmetric network path refers to the different entry and exit paths to a network; traffic enters a network through route A and exits the network through route B. Comparatively, Symmetric network path refers to the same entry and exit path to a network; traffic enters a network through route A and exits the network through route A.
