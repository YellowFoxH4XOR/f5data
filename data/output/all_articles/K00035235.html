Description

The /var/log/ltm folder is showing several logs like the following:

01420012:5: Cannot access configuration at /config/api_settings/log_resource_property.conf . Using defaults from /defaults/api_settings/log_resource_property.conf
01420012:5: Cannot access configuration at /config/api_settings/availability.conf . Using defaults from /defaults/api_settings/availability.conf
01420012:5: Cannot access configuration at /config/api_settings/log_resource.conf . Using defaults from /defaults/api_settings/log_resource.conf

Environment

  • BIG-IP LTM
  • api_settings folder

Cause

There are missing or corrupt files in the /config/api_settings/ folder

Recommended Actions

Replace the missing or corrupt files with the ones in the /defaults/api_settings/ folder:

  1. Log into the device cli
  2. Execute the following command: 
    cp -p /defaults/api_settings/* /config/api_settings/
The correct files should appear under the /config/api_settings/ folder.
