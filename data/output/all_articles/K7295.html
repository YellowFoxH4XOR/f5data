Known Issue

This is the result of a known issue. When using Portal Access Windows Files Favorites to download a ZIP archive using the file cart, the .zip extension may not be appended to the downloaded file, depending on the configuration of the operating system used to connect to the FirePass controller.

A Windows File Favorite allows you to add files to a file cart, and then download all the files in the file cart as a ZIP archive to a local drive, with the filename cart.zip.

Depending on the configuration of the operating system, the file may be downloaded without the .zip extension, which may prevent the file from being automatically handled by the correct application. However, the file is still a valid ZIP archive.

F5 Product Development tracked this issue as CR76301 and it was fixed in FirePass version 6.0.2.  For information about upgrading, refer to the FirePass release notes.

Workaround

If the file is downloaded without the .zip extension, manually add the .zip extension to the filename.
