Known Issue

The Configuration utility fails to display Stream Control Transmission Protocol (SCTP) profile settings for non-admin users.

This issue occurs when all of the following conditions are met:

  • You log in to the Configuration utility as a user assigned a non-admin role, such as the Manager role.
  • In the Configuration utility, you navigate to Local Traffic > Profiles > Protocol > SCTP and select the SCTP profile to view its settings.

Impact

Non-admin users cannot view SCTP profile settings.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A non-admin user cannot view SCTP profile settings.
  • In the /var/log/ltm file, you notice an error message that appears similar to the following example:

    mcpd[<PID>]: 01070823:3: Read Access Denied: user (<user>) type (Virtual Address profile SCTP)

  • The Configuration utility displays an error message that appears similar to the following example:

    General database error retrieving information.

Resolution

Status

Workaround

There is no workaround for this issue. To view SCTP profile settings, you must log in to the Configuration utility with a user account granted the Administrator role.

Impact of action: Performing the suggested action should not have a negative impact on your system.
