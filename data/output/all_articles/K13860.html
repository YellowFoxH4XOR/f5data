Issue

Error Message

tmm warning tmm[7213]: 01260017:4: Connection attempt to insecure SSL server (see RFC5746) aborted: <server_ip>:<dest_port>

In this error message, note the following:

  • <server_ip>:<dest_port> is the IP address and destination port of a back-end SSL server

For example:

tmm warning tmm[7213]: 01260017:4: Connection attempt to insecure SSL server (see RFC5746) aborted: 10.12.23.28:443

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The client initiates a connection to a virtual server configured with a Server SSL profile.
  • The Server SSL profile Secure Renegotiate setting is set to Require or Require Strict.
  • The back-end SSL server lacks support for the Transport Layer Security (TLS) renegotiation indication extension described in RFC5746.

Impact

The initial SSL handshake from the BIG-IP system to an unpatched SSL server fails.

Recommended Actions

F5 recommends that you upgrade the back-end SSL server to a version that includes support for RFC5746.

Note: If upgrading the back-end SSL server is not an option, you can set the Secure Renegotiation setting in the Server SSL profile to Request, which will allow the back-end SSL server to continue to renegotiate insecurely.
