K48898528: BIG-IQ: internal_server_error: the query time boundaries for device default are not found

Type
Support Solution
Published
2022-09-12
Updated
2025-04-02
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K48898528

Description

Getting error: 

INTERNAL_SERVER_ERROR: The query time boundaries for device default are not found. This is likely because the device is not registered for statistics collection. Please check the Agent Manager logs

Environment

Relevant environmental factors specific to the topic

  • BIG-IQ v8.x
  • Viewing statistics
  • Cluster Health issue

Cause

ES cluster in a bad state which was causing a problem with monitor graphs showing error

Recommended Actions

  1. To restore the cluster and big-iq functionality the following procedure has to be performed:
    Note: this results in statistic loss

    a. run below on the DCDs and CM (first dcd nodes, then CM)
    # reset-data-collection-cluster

    b. to verify if cluster is in green state again

    # curl -s localhost:9200/_cluster/health?pretty

    Note: If you have two CMs in ha you have to break the cluster before proceeding with above steps.
     
  2. If the cluster status is green again you can add back both DCD nodes and re-enabled statistic collection for your BIG-IP devices.

Additional Information

None.
