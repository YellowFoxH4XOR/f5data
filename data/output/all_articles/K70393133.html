Description

Config sync fails when a virtual server having a Universal persistence profile that uses an iRule and the same iRule is configured in the Virtual server

Environment

  • BIG-IP
  • Virtual Server with Universal persistence

Cause
 

Configuration synchronization fails when the same configuration object reference more than once.

Universal persistence profile uses iRules, If that same iRule is applied in the virtual server configuration it triggers an error message as below:

01070585:3:Virtual server (/partition/vs_name) cannot reference rule (/partition/rule_name) more than once (check persistence, auth and rules).
 

Recommended Actions

1. Remove the iRule from the Virtual Server.

The persistence profile will invoke the iRule internally hence it does need to be configured on the virtual server.
