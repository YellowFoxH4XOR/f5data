F5 NGINX is announcing the End of Sale (EoS) for the existing NGINX Controller API-Manager, NGINX Controller API-Manager with Security, and NGINX Management Suite API Connectivity Manager, effective January 1,2024. This applies to all SKUs containing NGX-CTRL-APIM or NGX-CTRL-APIS. End of Software Development (EoSD) and End of Technical Support (EoTS) are effective September 30, 2025.
