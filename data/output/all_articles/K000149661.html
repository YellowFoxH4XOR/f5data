Description

I would like to know what the default configuration for F5®Distributed Cloud WAF is.

 

Environment

  • Web App & API Protection
  • Web Application Firewall
  •  F5®Distributed Cloud (XC)

Cause

Before customizing a WAF policy, it is helpful to know the default configuration.

 

Answer/Recommended Actions

Security Policy Settings

  • All attack types, high and medium accuracy signatures, automatic Attack Signatures tuning, Threat Campaigns and all violations will be enabled.

HTTP Response Status Codes

  • All response codes are allowed.

Sensitive Parameter Masking

  • Values of query parameters "card", "pass", "pwd", and "password" will be masked.

Blocking Response Page

  • The system returns the system-supplied response page in HTML.

 

Additional Information
