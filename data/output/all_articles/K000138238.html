K000138238: when will DNS cache will caches use TCP

Type
Support Solution
Published
2024-01-16
Updated
2024-01-16
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.1.1
Source
https://my.f5.com/manage/s/article/K000138238

Description

Article describe when DNS uses TCP to send dns request to root hint


Environment


  • GTM/DNS
  • DNS Cache configured with use both UDP and TCP under "DNS Resolver" section


Cause

This Article share the behaviour of DNS Caches. Regardless of protocol(TCP/UDP) use by client for DNS query, DNS Cache will always attempt to use UDP to query root hint and will use TCP if response will above 1500 MTU or if it get TC bit from external resolver.



Recommended Actions

N.A


Additional Information

If environment only allow DNS cache to send DNS query over TCP to external resolver/root hint, please update DNS Cache to use only TCP.
