Issue

Description

SAML Authentication fails with the error message, RSA verification failed, check SP certificatele

  • SAML Authentication or Single Sign-On fails.
  • The following log messages are observed in /var/log/apm:
<big-ip_hostname> debug tmm[14081]: 014d0002:7: <session_id>: SSOv2 Detached signature algorithm: http://www.w3.org/2001/04/xmldsig-more#rsa-sha256
<big-ip_hostname> err tmm[14081]: 014d0002:3: <session_id>: SSOv2 Error verifying SAML message signature - RSA verification failed, check SP certificate
<big-ip_hostname> err tmm[14081]: 014d0002:3: <session_id>: SSOv2 Error(22) verifying detached signature
<big-ip_hostname> err tmm[14081]: 014d0002:3: <session_id>: SSOv2 Error(22) Signature verification failed for SAML Authentication Request
<big-ip_hostname> err tmm[14081]: 014d0002:3: <session_id>: SSOv2 Error validating Authn Request Message. Status: urn:oasis:names:tc:SAML:2.0:status:Requester
<big-ip_hostname> debug tmm[14081]: 014d0002:7: <session_id>: SSOv2 Size of SAML response: 591

In the above log message the SessionID is the unique APM session identifier:
K15387: Overview of BIG-IP APM session cookies

Environment

Relevant environmental factors specific to the topic

  • Access Policy Manager (APM)
  • APM configured as Service Provider (SP) or Identity Provider (IdP)
  • SP Connector is configured to require a encrypted Assertion

Cause

The certificate selected in the SP Connector Security Settings, Assertion must be encrypted,  does not match the certificate that signed the Assertion (configured in the SP).

Recommended Actions

Verify the correct certificate is selected in the APM SP Connector:

1. Login to the Big-IP configuration utility.
2. Navigate to Access>Federation>SAML Identity Provider>External SP Connectors.
3. Select the SP Connector and click Edit.
4. Go to Security Settings.
5. Under the "Assertion must be encrypted" configuration verify the correct "Encryption Certificate" is selected.
