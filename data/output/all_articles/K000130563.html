Description

Base license missing after reactivation with another add-on license

Example: LTM base, reactivated with ASM add-on. After license reactivation, only left with ASM add-on
 

Environment

  • Base Registration Key
  • Add-on Module

Cause

The product's active base module, which appears as add-on (xxxxxxx-xxxxx) in the add-on module section is being removed during license activation.

 

Recommended Actions

Reactivate the license by adding back the product's active base module in add-on module section of the license

None
