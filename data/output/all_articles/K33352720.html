Description

The BIG-IP APM Client Troubleshooting Utility (CTU) is a Windows client application. It's also known as F5 Report. Administrators can download the CTU as a single file, 'f5wininfo.exe', from the BIG-IP system and distribute it to clients for the purpose of collecting diagnostic data and troubleshooting client issues.

When the report is generated, APM admins in the beginning of report can see the lines similar to:

F5 Report
Version:7213,2021,527,649

and may mistakenly think that the Version value shows the APM Client (aka EdgeClient app) version installed on the testing machine, but it's not. It shows the version of 'f5wininfo.exe' utility only.

Environment

  • APM
  • CTU
  • F5 Report
  • f5wininfo.exe
  • APM Client
  • EdgeClient app

Cause

F5 Report Version log lines don't tell what APM Client is installed on the testing machine, but tell what CTU (f5wininfo.exe) version was used to generate the report. 

Imagine the following situation: 
a) you have BIG-IP with APM Client 7213 installed; 
b) APM administrator downloads 'f5wininfo.exe' from BIG-IP (it will be 7213 version), uploads it to the testing machine, then runs the report and you will see in the CTU report the log lines similar to 'F5 Report Version 7213'; 
c) then APM Client is upgraded to 7124 on BIG-IP, the user on the testing machine connects to vpn and the APM Client related components are updated toward 7124;
d) APM Administrator doesn't download the new 'f5wininfo.exe' version after that for troubleshooting purposes on the testing machine and just re-uses previously uploaded 'f5wininfo.exe' (from step b)) and in newly generated CTU report the administrator will still see the log lines 'F5 Report Version 7123' while in reality all vpn APM Client components are already updated to 7124. As the result, the EdgeClient app version is 7214 and the log lines from CTU report are 'F5 Report Version 7123'.

Recommended Actions

  1. Download the latest 'f5wininfo.exe' (CTU) utility from BIG-IP relevant to the installed APM Client. This way the F5 Report Version value will match with the apm client installed on BIG-IP and accordingly with the APM Client (aka EdgeClient app) components installed on the end windows machines.
