K000137354: SSL Handshake Error alert in the BIG-IQ: "Certificate at host example.net is not trusted"

Description

You have receive SSL Handshake Error messages from BIG-IQs:

Certificate at host example.net is not trusted. Please verify the host is correct, and set up SSL Certificate Verification settings for the server certificate or one of its trust chain certificates.

 

Environment

  • BIG-IQ
  • BIG-IP

Cause

  • Certificate at host example.net is not trusted. Please verify the host is correct, and set up SSL Certificate Verification settings for the server certificate or one of its trust chain certificates.
  • Problem is due BIG-IQ usage data collection which is enabled by default.

Recommended Actions

You can disable usage data collection by logging in to the BIG-IQ user interface, navigating to the System > USAGE DATA page, and clearing the I agree to F5’s collection and use of Usage Data check box. This would stop the BIG-IQ system from sending usage data; as a result, the BIG-IQ system should not be reporting this error message.
