Known Issue

The Configuration utility iRules editor may experience an error in literal strings within switch statements.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility iRules editor to create or modify an iRule.
  • The iRule definition contains a switch statement including a literal string defined by braces ({ }). For example:

    when HTTP_PROXY_REQUEST {
    switch -glob -- [string tolower [URI::host [HTTP::uri]]] {
    localhost* -
    {string value} -
    127.0.0.1 {
    discard
    return
    }
    }
    }

  • You click Update to save the iRule.

Impact

The Configuration utility iRules editor displays a parse error and the BIG-IP system does not update the iRule.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to update the iRule, the Configuration utility iRules editor displays an error message similar to the following:

    Some fields below contain errors. Correct them before continuing.
    01070151:3: Rule [/<partition>/<irule name>] error: /<partition>/<irule name>:1: error: [parse error: missing close-brace][{

Workaround

To work around this issue, you can replace the braces at either end of the literal string with quotation marks (").

For example:

when HTTP_PROXY_REQUEST {
switch -glob -- [string tolower [URI::host [HTTP::uri]]] {
localhost* -
"string value" -
127.0.0.1 {
discard
return
}
}
}

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
