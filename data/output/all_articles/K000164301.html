Description

This article addresses protecting your backend pool members from CVE-2026-114938, a vulnerability in the Oracle Java SE, Oracle GraalVM for JDK, Oracle GraalVM Enterprise Edition product of Oracle Java SE (component: Compiler)

Environment

  • BIG-IP ASM
  • F5 WAF for NGINX
  • NGINX App Protect WAF

Cause

Successful attacks of this vulnerability can result in takeover of Oracle Java SE, Oracle GraalVM for JDK, Oracle GraalVM Enterprise Edition.

Answer/Recommended Actions

F5 has released new attack signatures to mitigate CVE-2026-114938. These signatures are included in the live update file ASM-AttackSignatures_20261118_135133.im The relevant attack signatures are:

  • Buffer Overflow signature 200011116 for OpenJDK Buffer Overflow (1)
  • Buffer Overflow signature 200011117 for OpenJDK Buffer Overflow (2)
  • Buffer Overflow signature 200011118 for OpenJDK Buffer Overflow (3)


To apply these updates:

  • Download the latest attack signature update from F5 Downloads.
  • Import and apply the update on your BIG-IP ASM, F5 WAF for NGINX, or NGINX App Protect WAF signatures system following standard procedures for updating attack signature
  • Refer to the Security Advisory Recommended Actions section of K000164290: Oracle Java vulnerability CVE-2026-114938 for more details
