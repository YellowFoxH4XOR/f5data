Topic

This article provides an overview of the F5 Access for Windows 10. F5 Access secures enterprise application and file access from your Windows 10 and Windows 10 Mobile device using SSL VPN technologies, as a part of an enterprise deployment of F5 BIG-IP APM. For information about which features are available for other BIG-IP APM client applications, refer to K23653432: BIG-IP APM client feature matrix.

Description

Description

Starting with Windows 10 Desktop and Mobile, the VPN client for the BIG-IP system will be available in the Windows Store. The name of the application (formerly Inbox VPN) changed to F5 Access. F5 Access secures enterprise applications and file access from your Windows 10 and Windows 10 Mobile device using SSL VPN technologies, as a part of an enterprise deployment of F5 BIG-IP APM. For more information, refer to the F5 Access for Windows 10 release notes and the Configuration Notes: F5 Access for Windows 10 and Windows 10 Mobile. The following lists the environment for F5 Access for Windows 10:

  • Client Operating System: Windows 10
  • App: F5 Access client
  • BIG-IP system: BIG-IP APM 13.0.0 or later or at least the following versions in its software branch: 11.5.7, 11.6.3, 12.1.3.

VPN tunnel setup process

The following diagram provides a brief explanation of the VPN tunnel setup process. The tunnel setup consists of a series of exchanges between the F5 Access client and the BIG-IP APM system.

  • Tunnel Management (setup/teardown): The properties assigned to the user session are passed to the Windows 10 Universal Platform VPN framework, and are then used to create the tunnel. Tunnel negotiation and configuration (LCP/IPCP/IPCPv6) are all handled by the framework. In addition, the tunnel Keep-Alive mechanism is LCP, which is also handled by the framework.
  • Tunnel Framing: F5 FastPPP and HDLC are both supported framing methods. However, F5 FastPPP is enabled by default.
  • Session Management: The F5 Access plugin establishes a session with the BIG-IP APM system and handles the authentication. The network access resource is assigned to the user session and a list of properties are sent to the client in XML format.
  • DNS Management: The DNS properties are passed to the framework and managed and enforced by the Microsoft Name Resolution Policy Table (NRPT).
  • Proxy Management: The Proxy properties are passed to the framework.

Recommended Actions

If you have issues connecting using the F5 Access client, you can perform the following:

  • Attempt to connect using a different client from the same device. BIG-IP APM provides secure remote access to system resources using a number of clients including the BIG-IP Edge Client, popular browsers, command line interface client and so on. For more information, refer to K98269316: BIG-IP APM operations guide | Chapter 4: BIG-IP Edge Client.
