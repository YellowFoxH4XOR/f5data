Description

The /shared/tmp directory is getting filled with rpm-tmp files and is consuming excessive disk space.

Environment

  • iApps LX/iControl LX extension is installed (For example, AS3 or Telemetry Streaming)
  • The following alert appears:

    Disk partition /shared has only 30% free.

  • There are a lot of rpm-tmp* files in /shared/tmp directory.
  • You observe the following logs in /var/log/restjavad.<number>.log:

    Failed to execute the build command 'rpmbuild -bb --define '_tmppath /shared/tmp' --define 'main /var/config/rest/iapps/f5-service-discovery' --define '_topdir /var/config/rest/node/tmp' '/var/config/rest/node/tmp/7424d6d7-3ba6-4f8c-8c08-6518ddd4463d.spec'',
    Threw:com.f5.rest.workers.shell.CommandExecuteException: Command execution process killed

Cause

ID985329

Recommended Actions

  1. Remove the unwanted rpm-tmp* files from the /shared/tmp directory with the following command:
    rm -rvf /shared/tmp/rpm-tmp*
    Note: These files may reappear.

  2. The fix of another ID 929213 introduced a new database key iapplxrpm.timeout (default 60 seconds, max 600), which allows the RPM build timeout value to be increased. Increase the timeout to something longer (e.x. 300).
    tmsh modify sys db iapplxrpm.timeout value <value>
    tmsh restart sys service restjavad
    Impact of workaround: Increasing the db key and restarting restjavad should not be traffic impacting.
