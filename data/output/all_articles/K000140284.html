Description

After attempting to upgrade a BIG-IP Next instance of HA pair from Central Manager, the BIG-IP Next system is not upgraded and a critical alert is added to the Alerts list. The alert reads "DEVICE-00055: Upgrade reported failure". The BIG-IP Next instance is not upgraded but remains healthy while running the software version you were upgrading from.

Environment

  • BIG-IP Next Central Manager managing one or more BIG-IP Next instances

  • Upgrade

Cause

The contents of the signature file (.sig) do not match the sha512 signature of the BIG-IP Next image you uploaded.

Recommended Actions

When the sha512 signature file does not match, it can be for one of two reasons -

  1. The wrong .sig file was uploaded. Verify that you uploaded the correct signature file. It should have the same file name and build number as the BIG-IP Next image.
  2. An incomplete or corrupt BIG-IP Next upgrade image was uploaded.

For either of these potential issues, download the md5 file and compare the contents of the md5 file with the output of the command md5 <filename>.
