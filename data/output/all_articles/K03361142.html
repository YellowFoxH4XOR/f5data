K03361142: Refresh WhiteHat Site Names returns error 404 Not Found

Type
Support Solution
Published
2022-08-18
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K03361142

Description

When navigating  to Security ›› Application Security : Vulnerability Assessments : Settings, WhiteHat Sentinel (US Server) is populated,. After entering the  API key and select the button that says "Refresh WhiteHat Site Names List" it throws  the following three messages in a GUI popup window:

"Could not get list of site names. Failed to get site names 404 Not Found".

Environment

  • Big-IP ASM

Cause

This issue falls under Bug alias 961465 scanner WhiteHat: Site names cannot be retrieved from WhiteHat servers and is due to WhiteHat updating their API changing their URL path required to get the site names. Our code has the old path hard coded so when our software makes the outbound request WhiteHat returns a 404 Not Found.

Recommended Actions

You can manually define your site name or URI by simply typing it in under "WhiteHat Site Name" setting:

For example:
WhiteHat Site Name: "Specifies the name, or URI, of the web site for which you want to view the WhiteHat Sentinel verified vulnerabilities report. You may type in the box, or select from the list."
