K000092733: How to determine the status of the REST API

Type
Support Solution
Published
2022-11-28
Updated
2022-11-29
Source
https://my.f5.com/manage/s/article/K000092733

Description

You should consider using these procedures under the following condition:

  • You would like to determine the status of the F5OS REST API .

Environment

  • F5OS
  • REST API
  • Client capable of sending REST calls, i.e. Curl

Cause

None

Recommended Actions

1. Using Curl as an example, run the following command:
$ curl -sku <administrator account>:< password > -H "Content-Type: application/yang-data+json" https://<F5OS management IP>:8888/restconf/ | jq .
2. The response from the F5OS REST API will be similar to the following: 
{
  "ietf-restconf:restconf": {
    "data": {},
    "operations": {},
    "yang-library-version": "2019-01-04"
  }
}
