Known Issue

This is the result of a known issue. The BIG-IP LTM hotfix script does not account for the extra disk space needed during iControl-based hotfix installations. Since an iControl-based hotfix installation uses extra diskspace, it is possible that there is adequate disk space on a BIG-IP system to perform a manual hotfix installation, but not to perform an iControl-based hotfix installation. The Enterprise Manager uses iControl to communicate with and perform hotfix installations on managed devices such as BIG-IP systems.

F5 Product Development tracked this issue as CR76353 and it was fixed in BIG-IP LTM version 9.4.1. For information about upgrading, refer to the BIG-IP LTM release notes.
