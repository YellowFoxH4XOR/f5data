Known Issue

Local traffic policy statistics may display incorrect values.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP virtual servers with a local traffic policy.
  • The virtual servers actively process traffic.
  • Using the Configuration utility, you view the local traffic policy statistics by navigating to Statistics > Module Statistics > Local Traffic > Policies.

Impact

The local traffic policy statistics page displays only zero values for all listed statistics.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you view the local traffic policy statistics with the Traffic Management Shell (tmsh), the statistics are numerated correctly.

Workaround

To work around this issue, you can use the tmsh utility to view BIG-IP LTM traffic policy statistics. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To view BIG-IP LTM traffic policy statistics for all configured policies, type the following command:

    tmsh show /ltm policy

  3. To view statistics for a single BIG-IP LTM traffic policy, use the following command syntax:

    tmsh show /ltm policy <ltm policy name>

    In this command, note the following:

    • <ltm policy name> is the name of your BIG-IP LTM policy
  4. Exit the tmsh utility by typing the following command:

    quit
