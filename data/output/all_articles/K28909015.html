Description

After increasing disk space for VCMP Guest, Software installation process fails and  displays error similar to following in /var/log/liveinstall.log:

error: tm_install::Process::Process_full_install -- predicted size for BIGIP14123 is 12315728 and vg has 11862016 remaining.
Terminal error: Disk full (volume group). See SOL#10636

Environment

  • VCMP Guest version 14.1.x
  • Upgrade Process
  • Software installation
  • Increased disk size for VCMP Guest

Cause

Bug ID 744730

Recommended Actions

Workaround:

  • Reboot VCMP Guest
Fix:
  • Upgrade VCMP Guest system to version 15.x
 

Additional Information
None
