Description

While trying to generate a fresh qkview from GUI - the process fails with "error uploading to iHealth," or "Error generating QKView snapshot".

The /var/log/audit contains an error similar to the following:
notice mcpd[5460]: 01070417:5: AUDIT - client Unknown, user Unknown - transaction #18622-4 - object 0 - modify { diags_ihealth_request { diags_ihealth_request_error 13 } } [Status=Command OK]


Environment

  • BIG-IP LTM
  • QKview 
  • Configuration Utility (GUI)
     

Cause

The issue is due to a bug tracked as ID967373 


Recommended Actions

Use either one of the following commands on CLI to generate a QKview file.
#qkview -s0 
#nice -n 19 qkview -s0
