Description

When rebooting an rSeries system F5OS-A, the K3s cluster may not respond to complete the installation process causing tenant deployments to fail.  The cluster may remain in an unusable state, preventing tenants from starting.

Tenants fail to start and report error messages that appear similar to the following example:

Tenant deployment failed - Server is not responding


After the reboot process, tenants fail to start and report error messages that appear similar to the following example:

Tenant deployment failed - Server is not responding

The following show cluster cluster-status summary-status CLI command output shows the K3s cluster is ready in this scenario ::

show cluster cluster-status summary-status

cluster cluster-status summary-status  "K3S cluster is initialized and ready for use."

The /var/log/messages file contains certificate error messages that appear similar to the following examples

appliance-1 k3s: level=info msg="Cluster-Http-Server http: TLS handshake error from 100.65.6.61:39194: remote error: tls: bad certificate"
appliance-1 k3s: level=info msg="Cluster-Http-Server http: TLS handshake error from 100.65.6.61:39196: remote error: tls: bad certificate"
appliance-1 k3s: E1028 16:15:15.701917   12674 remote_runtime.go:116] "RunPodSandbox from runtime service failed" err="rpc error: code = Unknown desc = failed to setup network for sandbox \"b4d984d3f514011cc0ffd136b98102e5bd66db2687c5e0791fdf68efb7f018fc\": Multus: [kube-system/klipper-lb-7l47n]: error getting pod: Get \"https://[100.75.0.1]:443/api/v1/namespaces/kube-system/pods/klipper-lb-7l47n?timeout=1m0s\": x509: certificate signed by unknown authority"

Environment

F5OS-A device
Tenants are  not coming up after restart

Cause

K3s cluster may not respond to complete the installation process causing tenant deployments to fail


Recommended Actions

To resolve this issue, you must re-install K3s and rebuild the cluster, which will take approximately 10-15 minutes to complete.

Refer to K000140429 for instructions on re-installing the K3s cluster:

  • K000140429: Re-installing the K3s cluster on F5OS-A rSeries appliances
