Description:

After you activate an add-on license key for a device, you cannot activate the same add-on license key on another device. To move an add-on license key from one device to a different device, you must contact F5 Support to retire the existing add-on key and receive a new key.

Note:

  • F5 Support can retire Add-on keys only within two weeks of initial activation. After two weeks of activating an Add-on key, if you must move the Add-on key to another device, contact your F5 Account manager to do so. 
  • If multiple add-on keys of the same SKU (example: the duplicated add-on didn't increase the throughput/feature of the base license) have been activated, an exception will be given, and the request can still be processed. 
  • If the mis-applied add-ons are subscription add-ons, all add-on keys (with the same function) tied to the unit must be removed, not just the extra(s).

Environment:

Product: F5OS - Appliance

Cause

This issue occurs when multiple add-on keys are mistakenly activated on the same base appliance during initial licensing. Once activated, these add-on keys become permanently associated with that specific base key and cannot be reassigned to another device.

Recommended Actions

Retire the Incorrect Add-on Key:

  • Submit a request to F5 support to retire the incorrectly assigned add-on key.

Reactivate License on Affected Appliance:

  • After retirement is confirmed, log in to the appliance and reactivate its license so that the retired key is removed from its license file.

Request New Add-on Key Generation:

  • Please contact F5 to notify us once the key is removed .A new key will be generated and emailed to you .

Install New Add-on Key:

  • Apply the newly generated add-on key to the correct appliance and verify restoration.
