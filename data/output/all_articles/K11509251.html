Issue

Error Message

notice tmm[<PID>]: 01010240:5: Syncookie HW mode activated, server = <IP>:<port>, HSB modld = 1

In this error message, note the following:

  • <PID> is the process ID for the tmm process
  • <IP> is the virtual IP address on the BIG-IP system receiving the SYN flood
  • <port> is the port number of the virtual server

For example:

notice tmm[15245]: 01010240:5: Syncookie HW mode activated, server = 10.10.10.10:443, HSB modld = 1

notice tmm[15245]: 01010240:5: Syncookie HW mode exited, server = 10.10.10.10:443, HSB modld = 1

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP platform is equipped with a high speed bus (HSBe2) chip that can perform hardware SYN cookie protection.
  • SYN cookie protection is enabled on the BIG-IP system.
  • One of the SYN cookie thresholds is reached on the BIG-IP system.

The SYN cookie feature on the BIG-IP system protects against SYN flood attacks and allows established connections to process normally during attacks. BIG-IP systems equipped with an HSBe2 chip can perform SYN cookie protection in hardware and generate this message when hardware SYN cookie protection is activated.

Impact

This message is informational and indicates hardware SYN cookie protection is activated. This message does not indicate an operational error. 

Recommended Actions

None
