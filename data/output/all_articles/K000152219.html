K000152219: Meaning of /var/log/sel: 'INF BMC System Event #ff - 6f [05 00 ff]' log message

Description

This article attempts to explain the following log message in /var/log/sel, which may occur during normal operation of the device :

02e0 04/18/23 07:27:48 INF BMC System Event #ff - 6f [05 00 ff]

02e1 04/18/23 07:27:53 INF BMC System Event #ff - 6f [05 80 ff]

 

Environment

BIG-IP LTM

 

Cause

In the above messages from /var/log/sel, the hex code "05 00 ff" corresponds to "time sync needed/initiated" and the hex code "05 80 ff" corresponds to "time sync completed".

These 2 messages in themselves just seek to inform the administrator that an internal time sync between the host and the BMC was initiated and/or completed on the Big-IP.

These messages can generally be ignored, unless they are positively associated with a problem (in which case, the internal time sync may be triggering the problem).

 

Recommended Actions

None.
