Description

Firefox gives error when using OCSP Stapling through BIG-IP

  • Firefox displays the following error: "MOZILLA_PKIX_ERROR_OCSP_RESPONSE_FOR_CERT_MISSING"
  • OCSP Stapling fails only through Firefox

Environment

  • OCSP Stapling through proxy connection
  • BIG-IP from 11.X to 15.X
  • Firefox Browser
  • Default OCSP Profile Hash SHA256

Cause

Mozilla Firefox browser fails to properly use SHA256 hash for OCSP Stapling profile when using in a proxy connection. For additional information please refer to Mozilla's bug article:
Stapled OCSP response with SHA256 used in CertID causes MOZILLA_PKIX_ERROR_OCSP_RESPONSE_FOR_CERT_MISSING
 

Recommended Actions

At this time there is only a workaround for this issue as Mozilla is still working on this. Work around is to configure the OCSP Profile to use SHA1 Hash Algorithm.

  1. You can either modify the existing OCSP profile to use SHA1 Hash Algorithm under Request Signing. Or you can create a new OCSP profile and apply that to the client ssl profile utilized. This can be found in the following:
    • System  ››  Certificate Management : Traffic Certificate Management : OCSP  ›› <Then Select the affected profile or Create a new profile>
       
  2. Once this has been edited/created and applied to the client ssl profile, please test after clearing cookie and cache or testing in a private browsing window.
