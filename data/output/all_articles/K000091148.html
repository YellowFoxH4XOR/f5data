K000091148: Instructions to Renew Nginx Instance Manager v1 License

Type
Support Solution
Published
2022-10-10
Updated
2026-07-20
Source
https://my.f5.com/manage/s/article/K000091148

Description

You want to renew your NIM(Nginx Instance Manager) v1 license.

Environment

  • NIM(Nginx Instance Manager) v1
  • License Renew

Cause

None

Recommended Actions

  1. Backup your old license file by below command

    cp /etc/nginx-manager/nginx-manager-free-trial.lic /etc/nginx-manager/nginx-manager-free-trial.lic.bak

  2. Upload your new license file and override the original one located at /etc/nginx-manager/nginx-manager-free-trial.lic

  3. restart your service by the command below

    sudo systemctl restart nginx-manager.service

Note: restarting the service will reload the license and might impact your traffic.
