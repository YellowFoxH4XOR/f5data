Issue

Error Message

01531018:3: Failed to transfer zone <zone_name> from <ip_address>, will attempt <transfer_method>

In this error message, note the following:

  • <zone_name> is the name of the zone file attempting to be transferred.
  • <ip_address> is the IP address of the remote master DNS nameserver.
  • <transfer_method> is either Authoritative Transfer (AXFR) or incremental zone transfer (IXFR).

For example:

01531018:3: Failed to transfer zone test.example.org from 192.168.10.100, will attempt AXFR.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • DNS Express cannot perform a zone transfer from a master DNS nameserver.

Impact

If this is the initial zone transfer, DNS Express does not host the zone. If the zone was successfully transferred previously, DNS Express does not receive updates to the zone. If the zone transfer continues to fail, and the zone expiration time is exceeded, DNS Express stops hosting the zone until the next successful transfer.

Recommended Actions

This message is typically logged in conjunction with more specific error messages that offer additional information about the failure. The BIG-IP system continues to attempt to transfer the zone.

Possible causes for the issue may be:
  • An incorrect configuration on the BIG-IP system, such as the wrong master DNS nameserver IP address.
  • A network configuration that prevents the BIG-IP system from reaching the master DNS nameserver.
  • A configuration issue on the master DNS nameserver, such as an incorrect firewall access list (ACL).
