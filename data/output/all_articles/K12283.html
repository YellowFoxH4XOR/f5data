Known Issue

This is the result of a known issue. A virtual server configured with BIG-IP WebAccelerator receives pipelined HTTP requests and the BIG-IP system shuts down the server-side connection after the origin web server (OWS) sends notification to close the connection upon responding to the first request. As a result, the BIG-IP system will log error messages that appear similar the following example to the /var/log/tmm file and abort the client connection:

HUDCTL_SHUTDOWN -> PROXY_SHUTDOWN in ESTABLISHED_PROXY
HUDEVT_REQUEST -> REQUEST in SHUTDOWN_PROXY

F5 Product Development tracked this issue as ID 241515 (formerly CR128437), ID 315103 (formerly CR128437-1), and ID 330140 (formerly CR128437-2), and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 issued for BIG-IP WebAccelerator 10.1.0, and Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP WebAccelerator 10.0.1. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP 10.x systems.
