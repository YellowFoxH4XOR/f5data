K8188: The TMM process will crash when an iRule uses the LB::reselect command after the HTTP::Response command in an LB_FAILED event

Known Issue

When an iRule uses the LB::reselect command after the HTTP::Respond command in an LB_FAILED event, the TMM process will crash.

F5 Product Development tracked this issue as ID 246376 (formerly CR84102) and it was fixed in BIG-IP versions 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.
