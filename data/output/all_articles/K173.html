To verify that your BIG-IP or 3-DNS is able to send email, perform the following steps:

  1. Log in to the command line.
  2. Send a test email through the log2mail program, by typing the following command:

    echo '<subject>' |log2mail <recipient>

    For example:

    echo 'This is a test mail' |log2mail admin@askf5.com

If BIG-IP is properly configured to send email, the recipient will receive the test email.
