Topic

FirePass does not currently support RSA SecurID pin code updates on a Webdav customized logon page.  

F5 Product Development is tracking a Request for Enhancement (RFE) to support RSA SecurID pin code updates on a Webdav customized logon page as ID 238089. This fix has been added in FirePass 7.0.0 HF-70-5.

Supplemental Information

  • FirePass does provide support for RSA SecurID pin code entry as part of the standard logon process. For more information, refer to K11054: Configuring RSA SecurID Authentication using RSA Authentication Manager version 7.1.0.
