Topic

To configure the named process on 3-DNS to listen on a specific IP address, perform the following steps:

  1. Using a text editor, such as vi or pico, open the /etc/named.conf file.
  2. Add a listen-on substatement to the options section of the file.

    For example:

    Important: The substatement must include the 127.0.0.1 address as shown in the following example.

    listen-on {<ip_address>; 127.0.0.1; };

    In this example, <ip_address> is the IP address on which you want named to answer DNS queries. In the following example, this address is 192.168.17.248.

Sample configuration file

Following is an example configuration file for named (from BIND 8.1 or later) installed on /etc/named.conf.

options {

        directory '/config/3dns/namedb';
        check-names master warn;                /* default. */
        listen-on { 192.168.17.248; 127.0.0.1; };

};
