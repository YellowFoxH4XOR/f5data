K54502271: BGP default route not advertised to peer via default-originate command

Type
Support Solution
Published
2021-12-16
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K54502271

Description
After BGP peer open a new session with BIG-IP in the middle of the existing session and the session is dropped,
BIG-IP will not send default route NLRI to the peer upon new session establishment.

Default route is missing on a BGP peer.

Environment

  • Zebos
  • BGP
  • default-originate

Cause
This is documented as known issue ID1067617

Recommended Actions

You may consider to soft reset BGP by using one of the command below
  • clear bgp *
  • clear bgp neighbour

Otherwise, you may consider to contact F5 Support to request for an Engineering Hotfix if you are being affected by this known issue.
