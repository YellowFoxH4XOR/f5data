Description

  • I get the error: HTTP 404 route_not_found.

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Answer/Recommended Actions

The error message suggests that our proxy is unable to find a proper route for the incoming request. In our proxy configuration, routes are used to define how incoming HTTP requests are forwarded to different back-end services.

This error is indicating that on the downstream (Client -> XC), there was no route-match for the request.

Cause

Here is a list of possible causes:

  • Mismatch in the "Host" header. When creating Routes on the HTTP Load Balancer you may not have correctly written the name of the host.
    • HTTP Load Balancer > Routes > Simple Route
