Description

Identity Providers may use modern web standards to render their web pages like login pages. 

You may experiencing rendering issues, like JS errors, accessing external web pages with Customer Dialer (Windows Logon Integration)

The use of the default browser is not supported with Customer Dialer. ID2216537 was filed to support it.

Check first with F5 Support team if ID2216537 is fixed, otherwise you can follow this procedure. 

Environment

  • BIG-IP provisioned with APM and deployed to use Network Access
  • You login to Windows desktop with Customer Dialer

Cause

Embedded browser within the Edge Client is built using the Microsoft WebBrowser Control that is powered by the Trident engine. Because this technology is based on IE, it may have limitations with modern websites.

Recommended Actions

FEATURE_BROWSER_EMULATION registry key allows changing the emulation mode of the Trident engine 

Value (Hex) Value (Decimal)  Resulting Emulation Mode2af8        11000            IE11 Standards mode (requires !DOCTYPE)2af9        11001            IE11 Edge mode (ignores !DOCTYPE and forces standards)

With the IE11 emulation mode, the 'Trident' engine (via mshtml.dll) uses 'jscript9.dll' instead of 'jscript.dll', supporting "modern" JavaScript features (ES5/ES6 basics) instead of Legacy JScript (ES3/ES5 Partial)     

By default Edge Client forces the 'IE11 Standards' mode but you can force manually the 'IE11 Edge' mode if a web page fails.

Considering:

  • Edge Client launches the Web Logon interface (DllWebLogonEntryPoint) using Windows 'rundll32.exe'
  • Edge Client reads FEATURE_BROWSER_EMULATION registry key from the HKEY_CURRENT_USER (HKCU) Hive
  • Custom Dialer is executed with the 'f5 Pre-Logon User' account 

You need to create key value 'rundll32.exe' with '11001' in key 'FEATURE_BROWSER_EMULATION' in the f5 Pre-Logon User's HKCU Hive

From your Windows desktop, 

  • open regedit.exe.
  • Select the HKEY_USERS node.
  • From the menu, Click File > Load Hive.
  • Browse to the NTUSER.DAT file for the f5 Pre-Logon User "C:\Users\f5 Pre-Logon User\NTUSER.DAT".
  • When prompted for a name, choose a temporary identifier, such as F5_USER_HIVE.
  • Add the registry subkeys needed to obtain key "HKEY_USERS\F5_USER_HIVE\SOFTWARE\Microsoft\Internet
  • Explorer\Main\FeatureControl\FEATURE_BROWSER_EMULATION"
  • Add in key FEATURE_BROWSER_EMULATION the rundll32.exe value (Name: rundll32.exe, Type: DWORD, Value: 11001)
  • Select the temporary node (F5_USER_HIVE) under HKEY_USER
  • From the menu, click File > Unload Hive.

It is also recommended to add the same rundll32.exe value in these registry Hives.

HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Microsoft\Internet Explorer\Main\FeatureControl\FEATURE_BROWSER_EMULATION HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Internet Explorer\Main\FeatureControl\FEATURE_BROWSER_EMULATION 

After that, run a new test.
If you see this error in 'C:\Users\f5 Pre-Logon User\AppData\Local\Temp\logterminal.txt', will mean something went wrong because Edge Client could not find key value 'rundll32.exe'.

GetRegistryAsDWORDA() error opening key SOFTWARE\Microsoft\Internet Explorer\Main\FeatureControl\FEATURE_BROWSER_EMULATION error=2

WebBrowser Control is influenced by several machine-specific factors. So if it continues failing with 'IE11 Edge mode', you can check

  • Internet Explorer Security Zones
  • Compatibility View Settings
  • Advanced Internet Options
  • Group Policy Objects (GPO)
  • Windows Updates and DLL Versions 

If problem continues, probably that external web page is using modern web standards not supported by 'IE11 Edge mode'.
