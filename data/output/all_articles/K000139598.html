K000139598: "system snmp" configuration produces an error

Type
Support Solution
Published
2024-05-14
Updated
2024-05-14
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000139598

Description

In F5OS-C 1.5.0 and 1.5.1, when trying to enter configurations containing "system snmp", an error is produced.

syscon-1-active(config)# system snmp targets target v2c-target config community public security-model v2c ipv4 address 10.255.0.144 port 162

Error: failed to create path - application communication failure

syscon-1-active(config)#

Environment

  • F5OS-C 1.5.0, 1.5.1
  • Configuring SNMP with "system snmp"

Cause

This is expected behavior. "system snmp" is only available starting 1.6.0.

Recommended Actions

Upgrade to F5OS-C 1.6.0 or later. Latest LTS version recommended.

Additional Information

In 1.5.0, https://clouddocs.f5.com/api/velos-api/F5OS-C-1.5.0-cli.html - "system snmp" commands were not advertised in the CLI manual.

In 1.6.0, https://clouddocs.f5.com/api/velos-api/F5OS-C-1.6.0-cli.html - "system snmp" commands are available.
