Description

A DNS query is answered by an internal DNS server instead of BIG-IP GTM/DNS.

Environment

  • BIG-IP GTM/DNS
  • Unhandled query action is enabled in DNS profile

Cause

BIG-IP GTM/DNS is not configured to respond to the DNS query and will therefore be categorised as an "Unhandled query"
 

Recommended Actions

Understand how BIG-IP GTM/DNS processes queries and modify the configuration as appropriate. For more details, depending on the product type refer to the following manuals:

  • For BIG-IP DNS, refer to the BIG-IP DNS: Implementations manual.
  • For BIG-IP GTM, refer to the BIG-IP Global Traffic Manager: Implementations manual.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

The process goes as follows:
DNS query arrives on BIG-IP DNS Listener and considers:

  1. Name is in a Wide-IP?
    • Yes > Intelligent Resolution
    • No > proceed to next step
  2. Name is in a DNS Express zone?
    • Yes > Accelerated Resolution
    • No > proceed to next step
  3. Name is in a DNS Cache?
    • Yes > Accelerated Resolution
    • No > proceed to next step
  4. Resolving Cache Defined? 
    • Yes > DNS lookup and cache response
    • No > proceed to next step
  5. Listener has a pool?
    • Yes > Load balance query and cache response
    • No > proceed to next step
  6. DNS profile allows local BIND?
    • Yes > Local BIND resolution and cache response
    • No > proceed to next step
  7. Listener is not a self-IP?
    • Yes > Forward to server with listener's IP address; cache response if through BIG-IP.
