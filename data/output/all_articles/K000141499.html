Description

Create the SSLO Existing Application topology, add the Inline HTTP Service in the Service Chain, apply the topology to the existed virtual server, but SSLO bypass the Inline HTTP Service.

If add the L3 Inline Service, SSLO will forward the request to the L3 Inline Service.

Environment

  • BIG-IP LTM with SSLO addon
  • Virtual server
  • Client SSL profile
  • Existing Application Topology
  • Inline HTTP Service

Cause

In the virtual server, HTTP profile is not applied, so BIG-IP will not clarify the traffic is HTTP protocol, cause the Inline HTTP Service was bypassed.

Recommended Actions

Configure the virtual server, apply HTTP profile.

Additional Information

None.
