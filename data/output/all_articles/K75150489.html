Description

You are not able to reactivate the BIG-IQ license with the following error message.

The system returned an unexpected error (400 Bad Request). License content is invalid or expired

This happens during Automatic and Manual activation method.

This is an BIG-IQ evaluation license.

Environment

  • BIG-IQ
  • Not able to reactivate license
  • Evaluation license

Cause

You are not able to reactivate an BIG-IQ Evaluation license.

Recommended Actions

  1. Contact your F5 Sales representative to acquire a production/permanent BIG-IQ license.
  2. Replace the evaluation license with the new license on the BIG-IQ.

Additional Information

To confirm that you are using an evaluation license, open /config/bigip.license from the BIG-IQ and view the Service Status. It should state a message similar to the one below:

As of xxxx-xx-xx there is no active service contract. This may inhibit your ability to upgrade your software.
