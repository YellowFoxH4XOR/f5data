Description

Encountering syntax error when running command to produce pre master secret key log file with tshark on Windows.


Command:

"c:\Program Files\Wireshark"\tshark.exe -r c:\path\to\capture\thedata.pcap -Y "f5ethtrailer.tls.keylog" -T fields -e f5ethtrailer.tls.keylog >> c:\path\to\output\file.pms


Error:

Unexpected token '\tshark.exe' in expression or statement.

+ CategoryInfo : ParserError: (:) [], ParentContainsErrorRecordException

+ FullyQualifiedErrorId : UnexpectedToken


Environment

Windows


Cause

Executing command in wrong terminal window.


Recommended Actions

Run command in CMD prompt instead of Powershell.


Additional Information

Creating a decrypted tcpdump capture without using an iRule (f5.com)
