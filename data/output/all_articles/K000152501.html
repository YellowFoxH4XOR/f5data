K000152501: After deploying BIG-IP Virtual Edition (VE), getting error "Cannot find disk information." on GUI

Type
Support Solution
Published
2025-07-09
Updated
2025-07-09
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000152501

Description

After deploying BIG-IP Virtual Edition (VE), you are getting error "Cannot find disk information." on GUI during setup or in the resource provisioning screen. Additionally, attempts to create or manage objects via the GUI may fail, while some CLI operations (such as changing the hostname) may still succeed.

Environment

  • BIG-IP LTM Virtual Edition (VE)
  • Multiple virtual disks (HD1, HD2, etc.)

Cause

The BIG-IP VE software was installed on a secondary disk (HD2) instead of the primary disk (HD1). Only the primary disk (HD1) is supported for software volume installations. You can use the following commands to verify the logical disks created and disk used for software installation.

tmsh list /sys disk all-properties
tmsh list /sys software
tmsh show /sys software

Recommended Actions

  • Ensure that the primary disk (HD1) is correctly sized and available before installation.
  • Perform a fresh installation of BIG-IP VE on the primary disk (HD1).
  • If the system has already been installed on a secondary disk (HD2), configure the boot marker to boot from HD1, or redeploy the VE ensuring the installation targets HD1.

Additional Information

Refer to F5 Knowledge Article K14952 for guidance on extending disk space on BIG-IP VE and best practices for disk provisioning.
