Issue

Error Message

notice chmand[<PID>]: 012a0016:5: Blade <number> hardware sensor notice: <message>

In this error message, note the following:

  • <PID> is the process ID for the chmand process.
  • <number> is the number of the blade experiencing the condition.
  • <message> is a message describing the condition.

For example:

notice chmand[6367]: 012a0016:5: Blade 1 hardware sensor notice: Power supply 1 GPIO status: Good

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The LCD panel

Description

This message occurs when the following condition is met:

  • One of the hardware sensors in the BIG-IP system indicates the presence or absence of a notable condition.

For example, the BIG-IP system generates this message when sensors detect temperature levels are too high or return to normal, fan speeds are too low or return to normal, or the loss or return of power to the system.

Impact

This messages indicates that a hardware sensor reported a condition of note that could potentially indicate a loss of power or a malfunctioning hardware component.  

Recommended Actions

This message is typically accompanied by several other log messages that specify the exact nature of the condition.  For more details about the condition in the message, review the /var/log/ltm file for related messages.
