K000141038: Unable to access tenant virtual console via virtctl - "Can't connect to websocket (500): websocket: bad handshake"

Type
Support Solution
Published
2024-09-11
Updated
2024-09-11
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000141038

Description

Unable to access tenant virtual console with virtctl console on rSeries:

[root@appliance-1(R4600) ~]# virtctl console tenant01-1
Can't connect to websocket (500): websocket: bad handshake

Environment

  • F5OS-A
  • Tenant virtual console

Cause

This problem can occur if there is a lingering kubectl process on your system that precedes the date of the most recent K3s re-installation.

Recommended Actions

Review the process list to determine if there are any lingering kubectl processes present:

ps aux | grep '[k]ubectl'

Killing off the process should restore virtctl console functionality:

killall kubectl
