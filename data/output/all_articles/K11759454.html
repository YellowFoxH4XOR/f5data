Known Issue

BIG-IP APM local user database imported fields from a CSV file may not display.

This issue occurs when all of the following conditions are met:

  • Using the BIG-IP APM Configuration utility, you import a new local user database from a CSV file.
  • The CSV user information import successfully completes.

Impact

The imported user database fields do not display.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After importing a new local user database from a CSV file, the user database fields do not display.
  • Executing a browser refresh of the local user database page displays the imported fields.

Resolution

Status

F5 Product Development has assigned ID 475506 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can display the imported fields by executing a browser refresh of the local user database page.

Impact of workaround:  Performing the suggested workaround should not have a negative impact on your system.
