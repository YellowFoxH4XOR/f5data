Known Issue

This is the result of a known issue. In earlier versions, 3-DNS associated an IP address with each wide IP. This was known as the Wide IP Key. User access to this internal function was not necessary, and was removed from the product in version 4.5. The network map still displays this internal information, which you can safely disregard.

F5 Networks Product Development tracked this issue as CR24750 and CR24752.
