K15274516: Deploying WAF Policy to BIG-IP VS, BIG-IQ Shows Error: ''This virtual server does not support ASM policies.''

Description

Attempting to attach a security (WAF) policy to a virtual server from the BIG-IQ produces an error message similar to the following:

This virtual server does not support ASM policies.

Environment

  • BIG-IQ to BIG-IP ASM
  • WAF Policies 
  • BIG-IP Virtual Servers

Cause

  • The BIG-IP where the WAF is being applied does not have a HTTP profile attached.
  • The BIG-IQ needs to the most recent BIG-IP config imported after the HTTP profile is attached to the Virtual Server.

Recommended Actions

Please follow the below steps to ensure the BIG-IQ properly sees the HTTP Profile n 

  1. On the BIG-IQ:
          Configuration --> Local traffic --> Virtual Servers : VIP
          Does the virtual server reflect that an http profile is present?
          Note: A HTTP profile is needed to apply a WAF Policy.
     
  2. If no HTTP Profile is shown:
    1. Confirm it is missing/attached on the Virtual Server on the BIG-IP.
       
  3. If the BIG-IP shows an HTTP profile, and the BIG-IQ doesn't, you will need to Re-Discover and Re-Import
    Re-Discover and Re-Import LTM and ASM in the BIG-IQ.
           Devices --> BIG-IP devices
              Click on the BIG-IP in question, click on the Services tab --> Re-Discover LTM, then Re-Import... repeat for ASM.
     
  4. After confirming the virtual server is showing a HTTP profile from the BIG-IQ, attempt to attach the WAF Policy to the Virtual Server.
