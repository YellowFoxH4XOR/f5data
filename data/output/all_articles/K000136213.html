K000136213: RADIUS Accounting STOP Request does not include "Framed-IP-Address"

Type
Support Solution
Published
2023-11-24
Updated
2023-11-24
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136213

Description

When BIG-IP APM Network Access VPN tunnel is disconnected, the "RADIUS Accounting-Request (STOP)" does not include the "Framed-IP-Address"

Environment

  • BIG-IP APM
  • Network Access Resource configured with IPv4 and IPv6
  • Radius Accounting object in the Visual Policy Editor

Cause

Since the Network Access resource is configured with IPv4 and IPv6, the session variable "session.assigned.clientip" is assigned the IPv6 address.
This results in not being able to validate the IPv4 address and the "Framed-IP-Address" is not included in the "RADIUS Accounting-Request (STOP)".

Recommended Actions

Please contact F5 Support for an Engineering Hotfix to be provided.
