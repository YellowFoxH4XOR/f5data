Description

You have set the limit of the connection on node but you have observing the following logs in the /var/ltm even if the nodes didn't reach the limit set:

 

Tue Jan 2 16:40:15 ICT 2024 warning example.com tmm3[26155] 01200016 Warning, node IP 10.10.10.30 has reached its connection limit.

Tue Jan 2 16:40:14 ICT 2024 warning example.com tmm3[26155] 01200016 Warning, node IP 10.10.10.20 has reached its connection limit.

 

Environment

  • BIG-IP
  • Node

Cause

None

Recommended Actions

This is expected behavior.


The BIG-IP system divides the configured connection limit by the number of Traffic Management Microkernels (TMMs) that are running on the system and forces the calculated limit to round down to the nearest whole number, per TMM. If the connection limit is not evenly divisible by the number of running TMMs, the remainder ( % ) is distributed, one per TMM, to the lower ordered TMMs. For example, when an object is configured with a connection limit of 10 on a CMP system with four running TMMs, the BIG-IP system divides the configured limit of 10 by four TMMs and calculates a connection limit of two per TMM. The remaining (10 % 4) two connections are then distributed to the lower ordered TMMs resulting in a calculated connection limit of three for tmm0 and tmm1.
