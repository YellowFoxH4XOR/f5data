Source

Description

Prior to 14.1.4.2 version, wide ip persistence records are removed when deleting the GSLB pool.
 

Environment

  • BIG-IP DNS
  • GSLB Pool
  • Persistence records

Cause

Unknown at time of publication.

Recommended Actions

Upgrade the BIG-IP DNS device to version 14.1.4.2 to resolve this issue.

None
