K000150586: How to post multiple URLs to a ASM Security Policy at once with the API

2025-04-24
Applies to

  • BIG-IP ASM: 17.1.1
Source

Description

You want to add multiple URLs to the ASM Security Policy whitelist at once

Environment

BIG-IP ASM 17.1.1

REST API

Cause

The API expects a single JSON object per request. Sending an array directly causes a parsing error because the API cannot process multiple objects in a single request. 

Recommended Actions

Use POSTMAN Collection Runner to feed data
