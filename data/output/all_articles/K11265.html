Known Issue

This is the result of a known issue. The BIG-IP ASM system may not correctly apply Data Guard to chunked HTTP responses when the HTTP profile Response Chunking option is set to Preserve.

The BIG-IP ASM system requires unchunked content in order to examine and block sensitive data using Data Guard. The Preserve option ignores the BIG-IP ASM system request for unchunked data and sends the original chunked data. The BIG-IP ASM system is unable to examine the content; as a result, sensitive data that Data Guard is configured to mask is allowed to pass.

F5 Product Development is tracking this issue as CR134141.

Workaround

To work around this issue, F5 recommends you use any of the following Response Chunking options: Selective (default), Unchunk, or Rechunk.
