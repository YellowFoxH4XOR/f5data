Description

Installation of the Falcon CrowdStrike Sensor on a BIG-IP system fails with an error indicating insufficient disk space on the root (/) partition:
falcon-sensor-7.34.0-18708.el7.x86_64 needs 82MB on the / filesystem

 

Environment

  • BIG-IP LTM
  • Falcon CrowdStrike Sensor (RPM package)

 

Cause

Insufficient free space on the root (/) partition, caused by unnecessary restjavad-audit log files stored in a non-standard directory.

 

Recommended Actions

  1. Identify large or unnecessary files on the root (/) partition:
    • find / -xdev -type f -exec du {} \; | sort -rn | head -20
    • du -xh / --max-depth=1
  2. Locate and review files under unexpected directories (e.g., restjavad-audit logs in a non-standard var_log directory). If you are unsure compare the content of / directory with different BIG IP or raise the ticket to F5 Support.
  3. Delete unnecessary files, such as old or redundant log files, to free up space on the root partition.
  4. Re-attempt the Falcon CrowdStrike Sensor installation.
