Issue

Old Behavior

In versions prior to BIG-IP 11.x, you must change the certificate chain traversal depth (Certificate Depth) setting from the default setting of 0 (zero) so the system can use Secure Sockets Layer (SSL) certificates that are signed by third-party Certificate Authorities (CA) to authenticate iQuery communication between BIG-IP systems.

You can modify the Certificate Depth setting by using both Big3d.CertificateDepth database variables, from the System > Configuration > Global Traffic > General screen in the Configuration utility.

New Behavior

Beginning in BIG-IP 11.x, both Certificate Depth settings have been deprecated. The Certificate Depth setting is now hard-coded to 9 (max).

F5 Product Development tracked this change as ID 346752.

Impact

You no longer need to modify the Certificate Depth setting in order to use SSL certificates that are signed by third-party CAs to authenticate iQuery communication between BIG-IP systems.
