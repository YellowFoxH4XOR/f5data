Description

When you try to run "fsck -y" or "fsck -A -y" on BIG-IP version 12.x and later, you will see the error "e2fsck: Cannot continue, aborting."

e2fsck: Cannot continue, aborting.


Environment

  • BIG-IP version 12.x and later
  • Run "fsck -y" or "fsck -A -y"


Cause

"fsck -y" command is not available on BIG-IP version 12.x and later.


Recommended Actions

Firstly enter into MOS according to K14245, then you can run the following command on BIG-IP version 12.x and later, instead of "fsck -y".
For example:

e2fsck -yf /dev/mapper/vg--db--sda-dat.share.1


Additional Information

None.
