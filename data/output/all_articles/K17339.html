Known Issue

The Traffic Management Microkernel (TMM) may restart when multiple Point-to-Point Tunneling Protocol (PPTP) calls arrive from the same client.

This issue occurs when all of the following conditions are met:

  • You have a virtual server with an associated PPTP ALG profile.
  • You have licensed and configured the carrier-grade network address translation (CGNAT) module.
  • A remote client initiates multiple PPTP calls to the virtual server.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.
