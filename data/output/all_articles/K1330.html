Topic

Note: This articles describes a date-specific issue, triggered by a date that is now in the past. This information is still included because date-specific issues may still be triggered if you set the system clock to a previous date.

Almost all Unix-based operating systems calculate the current date and time based on the number of seconds that have elapsed since midnight on January 1, 1970 (the beginning of the "Unix epoch").

At 1:46:40 a.m. on September 9, 2001, the number of elapsed seconds since the epoch rolled from 999,999,999 to 1,000,000,000. The main significance of this number is that it contains 10 digits instead of nine.

POSIX-compliant operating systems use a 32-bit unsigned integer, which can store a value up to 4,294,967,296. Such operating systems, including those used in all F5 products, are not affected by this change.
