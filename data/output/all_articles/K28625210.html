Known Issue

The BIG-IP AAM system may not correctly forward the POST body to backend servers.

This issue occurs when all of the following conditions are met:

  • You have the BIG-IP AAM module licensed and provisioned on the BIG-IP system.
  • The matched node in the acceleration policy is configured to cache POST requests.

By default, acceleration policies in the BIG-IP AAM system allow for caching content for POST requests. When processing a POST request, the BIG-IP AAM system may be able to forward only the HTTP request headers to the origin web server. As a result, the origin web server may treat this as a bad request and respond with an error.

Impact

The HTTP request fails, causing application functionality to break or degrade.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The origin web server responds with a 400 Bad Request HTTP status code.
  • Applications or widgets break when accessed through the BIG-IP AAM system.

Workaround

To work around this issue, you can bypass the BIG-IP AAM system for these requests or configure the acceleration policy to proxy the requests. For more information about bypassing the BIG-IP AAM system, refer to K52245924: Bypassing the BIG-IP WebAccelerator or BIG-IP AAM or BIG-IP HTTP cache with an iRule in 11.x through 12.x. To configure the acceleration policy to proxy the request, perform the following procedure:

Impact of workaround: Bypassing the BIG-IP AAM system for certain requests may affect application functionality. You should perform and test the following workaround before applying the change to production traffic.

  1. Log in to the Configuration utility.
  2. Navigate to Acceleration > Web Application > Policies.
  3. Click the name of the policy to edit.
  4. Expand the Policy Tree and select the node to modify.
  5. From the Matching Rules menu, select Acceleration Rules.
  6. Click the Proxying tab.
  7. In the Proxy Rules section, select Method from the Add Parameter menu, and click Add.
  8. Check the POST box and click Save.
  9. To publish the change, click Publish, and then Publish Now.
