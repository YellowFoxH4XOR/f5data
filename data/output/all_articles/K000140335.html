Description

In BIG-IQ CM, under Devices > BIG-IP Devices Page, many BIG-IP devices have services eg. ASM enabled, but they are not visible when filtering with services containing as ASM.

For example, before filtering:

After filtering:

Environment

  • BIG-IP device managed by BIG-IQ CM.

  • BIG-IP has ASM service enabled.

Cause

Only successful ASM imported devices are shown in the filtered list.

Recommended Actions

Make sure you have imported ASM/SSM configuration of those related BIG-IP devices successfully.

Additional Information

You can use the following command in the BIG-IQ CM CLI interface to check which devices has ASM configuration imported successfully:

restcurl /cm/system/machineid-resolver | jq -r '.items[] | select(.properties."cm-asm-allAsmDevices".imported==true)' | jq -r '.hostname'
