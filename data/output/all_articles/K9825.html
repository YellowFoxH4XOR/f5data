Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 10.0.0. F5 recommends that all customers currently running 10.0.0 install Hotfix-BIGIP-10.0.0-5460.0-HF1, or a later version of the cumulative hotfix rollup, as soon as possible.

The following CRs are fixed in Hotfix-BIGIP-10.0.0-5460.0-HF1 for BIG-IP 10.0.0:

CR
ArticleDescription
CR66036 K9828The pvad process uses the gettimeofday() function for status checks
CR82189 K9831The bigpipe pva 0.0 command does not display traffic statistics
CR84034 K9830Idle tmzd process consumes a large amount of CPU time
CR101304 K9833Mirrored connection table entries may be lost if a blade bounces
CR113258 K9832FastHTTP may prematurely close connections when the other side closes
CR116464 K9834The tcpdump command outputs extraneous data when specifying the maximum snaplen (-s0) option
CR116540 K9842The BIG-IP system does not properly fragment egress packets when using a FastL4 profile
CR116570 K9843Slow client connections may be aborted when transferring large documents
CR116873 K9846Some Configuration utility Help tabs display errant heading information
CR117228 K9847Attempting to install a version 10.x hotfix using the 'im' command displays a cryptic error message

The hotfix is available for download at the F5 Downloads site. For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For a list of the latest hotfixes for each BIG-IP software branch, refer to K9502: BIG-IP hotfix matrix.
