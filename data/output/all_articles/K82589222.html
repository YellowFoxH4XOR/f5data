Description

You want to upload the iFile to a new BIG-IP but you don't have the local file. You already have this file in the existing BIG-IP.

Environment

  • BIG-IP
  • iFile

Cause

None.

Recommended Actions

  1. Login to the BIG-IP CLI which has iFile.
  2. Run this command to check the iFlie, it will list all of the iFile in the BIG-IP.

    # tmsh list sys file ifile all-properties

    The result should show similar to the following:

    sys file ifile f5_logo {
        checksum SHA1:<value>
        create-time <timestamp>
        created-by admin
        last-update-time <timestamp>
        mode 33188
        partition common
        revision 1
        size 5111
        updated-by admin
    }
  3. Use editor to locate the iFile that you want to upload in bigip.conf.

    # vi /config/bigip.conf

    type "/" to search for the iFile, in this example we are looking for f5_logo.

    The result should show similar to the following:

    sys file ifile /Common/f5_logo {
        cache-path /config/filestore/files_d/Common_d/ifile_d/:Common:f5_logo_59304_1
        revision 1
    }

    Now we know the path of this file is /config/filestore/files_d/Common_d/ifile_d/.

    Note: If your file is not in the common partition, you need to access the partition by executing this command:

    # cd partitions/<name_of_the_partitions>
     
  4. Use WinSCP or SFTP software to download the file to your local PC.
  5. Once the download is completed, rename the file and change the file extension on your local PC.

    For the example:
    :Common:f5_logo_59304_1  --> f5_logo
     
  6. Login to the new BIG-IP GUI, import the iFile from your local PC (Web UI -> System -> File Management -> iFile List).

Additional Information

None.
