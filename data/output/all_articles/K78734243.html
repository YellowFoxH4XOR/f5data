Description

You want to restore or clear the BIG-IP iControl REST framework after being managed by BIG-IQ.

Environment

  • BIG-IP devices
  • HA Pair
  • iControl REST Framework
  • Command line access
  • Root access

Cause

BIG-IP device not successfully removed from BIG-IQ.

Recommended Actions

Important: If you are running SSL Orchestrator (SSLO), clearing REST storage will erase the SSLO configuration. To re-create it, ensure you've documented your configuration prior to clearing REST storage and created a UCS backup. Clearing REST storage will also permanently erase all Access Guided Configuration, Advanced WAF Guided Configuration, and iAppLX REST and FAST templates on the BIG-IP. Additionally, it will remove the AS3 package. For more information refer to K67220984: Clear-rest-storage. What does it do?

The clear-rest-storage script completely clears the stored state for the iControl REST framework. The script stops restjavad and restnoded, deletes the /var/config/rest/index and /var/config/rest/storage directories, removes the Application Services 3 (AS3) package, deletes the SSL Orchestrator (SSLO) configuration and then restarts those services.
The -l option deletes the restjavad log files as well as the stored state.
The -d option resets the BIG-IP configuration to default by running tmsh load sys config default in addition to deleting the stored state.

Ensure that your BIG-IP system is not currently being managed by a high availability (HA) peer BIG-IQ system.

Impact of workaround: Performing the following procedure will permanently erase all Access Guided Configuration, Advanced WAF Guided Configuration, SSLO configuration, and iAppLX REST and FAST templates on the BIG-IP. The only way to restore the configuration is from a UCS file. Additionally, it will remove the AS3 package from the BIG-IP.

  1. Log in to the BIG-IP system's Advanced Shell (bash).
  2. To restore your BIG-IP REST framework to default, enter the following command:
    clear-rest-storage 
    Note: You don't need to reboot the device or restart any services after running the previous command.
