Known Issue

The Traffic Management Microkernel (TMM) may produce a core file and temporarily stop responding when you associate a Policy Enforcement Manager (PEM) enforcement policy with a virtual server.

This issue occurs when the following conditions are met:

  • Your BIG-IP system is provisioned with the PEM module.
  • The policy rule contains category parameters and no application parameters.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H438544 on the Diagnostics > Identified > Medium screen.
  • An error message similar to the following example logs to the /var/log/daemon file:

    emerg logger: Re-starting tmm
  • TMM produces a core file and temporarily fails to process traffic.

Workaround

To work around this issue, you can modify the policy rule so that it contains category parameters and application parameters.

To recover from this issue, you can remove the policy from the affected virtual server when TMM restarts. You can then reload the configuration.
