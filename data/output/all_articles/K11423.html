Known Issue

This is the result of a known issue. When upgrading to FirePass version 6.1.0 or 7.0.0 with the DNS-Cache option enabled on the FirePass system, the system may begin to generate a large number of repeated DNS requests. In addition you may see multiple instances of the following error message in your system logs:

Kernel.Warning    F5-Primary    kernel: NET: 109

In some instances after upgrading FirePass, the DNS cache process may send an abnormally high number of repeated DNS requests to the DNS server configured in FirePass. This may cause the FirePass system, attached network, or DNS server to become overwhelmed.

FirePass implements a DNS cache to speed resolution of DNS requests that originate from FirePass for Portal Access or other types of traffic that originate or are proxied by FirePass by locally caching DNS information.

F5 Networks Product Development is tracking this issue as CR140469.

Workaround

To disable the DNS caching process, turn off DNS cache and finalize the network configuration. The change in performance should be minimal in most cases.

Alternatively, if the DNS server configured for FirePass is remote, has high latency, or processes a high volume of request traffic, F5 Networks recommends that you set up a DNS server that performs caching on the same network as the FirePass system and configure FirePass to utilize this DNS server for resolution.

Note: For more information about configuring DNS and DNS caching refer to the FirePass Controller Administrator Guide.
