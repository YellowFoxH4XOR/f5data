K000147818: How to enable Syslog/Storage (NetApp)/Multi-NIC/GPU features on managed kubernetes

Type
Support Solution
Published
2024-11-08
Updated
2025-02-23
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147818

Description

  • You configured a fleet to enable GPU/Syslog/Storage(NetApp) on a pk8s (managed kubernetes) site, but it did not work
  • How to enable those features on managed k8s sites?
    • *Here managed k8s site equals to pk8s site, F5® Distributed Cloud App Stack site

Environment

  • F5® Distributed Cloud Console and managed k8s Customer Edge (CE) site

Answer/Recommended Actions

  • The fleet will not work for the F5® Distributed Cloud App Stack site, it will be overwritten by the system
  • All features supported on Distributed Cloud App Stack site are available on either of the following
    • Distributed Cloud App Stack site
    • K8s Cluster
  • Multi-NIC config is imbedded in the "Certified Hardware", check it from the following UI
    • {Tenant_URL}/web/namespaces/system/manage/site_management/certified_hardware
