Known Issue

When a record in the parent zone has a name that contains the child zone name followed by a hyphen (-), the child zone does not load correctly.

This issue occurs when the following condition is met:

  • The parent zone has a record with a name that contains the child zone name followed by a hyphen.

    For example, consider a case in which the parent zone is myzone.com and the child zone is example.myzone.com. In myzone.com, there is the following record: example-record.myzone.com.

Impact

DNS cannot resolve records correctly.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A DNS request returns no record from the parent zone with Start of Authority (SOA), even though dnsxdump shows that the record exists.
