Known Issue

This is the result of a known issue. The Redirect URL blocking response option does not allow you to include the <%TS.request.ID()%> support ID notation when configuring custom URL redirects. As a result, you cannot configure custom response headers to include the support ID.

F5 Product Development tracked this issue as ID 204563 (formerly CR107507), and it was fixed in BIG-IP ASM 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.
