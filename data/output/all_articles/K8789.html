Known Issue

Note: This Solution only applies to the BIG-IP WebAccelerator 4500 platform.

This is the result of a known issue. The interface statistics for the sysInterfaceStat SNMP object ID (OID) are not reported for the 1.1 and 1.2 interfaces of the BIG-IP WebAccelerator 4500 platform. Only the SNMP OIDs of the management interface are reported.

To view the sysInterfaceStat SNMP OIDs, type the following command:

Note: The following command uses the default SNMP community string of public. If you have configured a custom SNMP community string, replace public with your SNMP community string.

snmpwalk -c public localhost sysInterfaceStat

F5 Networks Product Development is tracking this issue as CR98445.

 

Workaround

The interface statistics for non-managemement interfaces of the 4500 platform are reported via the standard (RFC 1213) network management MIB.  To view the available SNMP OIDs, type the following command:

snmpwalk -c public localhost if
