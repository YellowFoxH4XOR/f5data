K000092686: Outh2.0 - TCP Reset after sending a POST request to token endpoint

Type
Support Solution
Published
2022-12-07
Updated
2022-12-07
Source
https://my.f5.com/manage/s/article/K000092686

Description

You are you receiving a TCP reset when making a request to a token endpoint.

 

Environment

  • You are using BIG-IP APM as an OAuth Client, as per K14391041
  • You are configuring a custom parameter: response_mode = "form_post"

 

Cause

This is a known issue, 'response_mode=form_post'  is not supported.
This has been logged a s request for improvement with the ID 1189745

 Recommended Actions

Remove the custom parameter.
