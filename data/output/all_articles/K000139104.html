K000139104: How to add IP address Exception in WAF Policy on BIG-IP Next using BIG-IP Next CM

Type
Support Solution
Published
2024-07-23
Updated
2024-07-23
Source

Description :

Under certain scenarios you may want to while list an IP address in WAF policy. Once done WAF policy will not enforce the checks on that IP address.

 

Environment :

  • BIG-IP Next ver 20.1.1
  • BIG-Ip Next WAF 20.1.1
  • BIG-IP Next CM 20.1.1
  • IP Address whitelist

 

Cause:

How not to enforce WAF policy checks on an IP address.

 

Recommended Actions:

To add the IP address in the exception list please follow the steps mentioned below.

  1. Login to BIG-IP Next CM
  2. Click on “Manage Security Policies”
  3. Click on policies under WAF section
  4. Click on the policy to which you would like to add the IP address exception.
  5. Look for “IP Address Exceptions” and click on it.
  6. Click on create, add the IP address and its subnet
  7. Under Blocking mode select “Never Block”
  8. If you still want to monitor the activity of IP added to the exception you may keep the setting “Exclude Log Traffic from IP Address” disabled but if you don’t want to monitor the IP address, enable this setting.
  9. Click on save and Deploy the policy.

 

Additional Information:

  1. You should know the IP address which you would like to add in the exception.
  2. You should have access to BIG-IP Next CM and privileges to make the changes.
  3. You should know the WAF policy name to which IP address exception is needed.
