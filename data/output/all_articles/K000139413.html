Description

Connnectivity Error on MDM Airwatch object.
The monitors are up on fqdn pool when enabled.
When the monitor is detached and just do force update on the object, no traffic leaving the device and the following log is in /var/log/apm;

err mdmsyncmgr[<PID>]: 019dffff:3: (null)::00000000: {} /Common/myendpoint-mgmt-system : Error during updating device details: Connectivity error (Connection reset by peer)

The object is configured:

apm aaa endpoint-management-system /Common/myendpoint-mgmt-system {
   fqdn my.fqdn.com
   mdm-token ***scrubbed***
   password ***scrubbed***
   pool /Common/myendpoint-mgmt-system-fqdn-pool
   serverssl-profile /Common/myserver_ssl
   type airwatch
   username big-ip-user
}

ltm pool /Common/myendpoint-mgmt-system-fqdn-pool {
   members {
      /Common/my.fqdn.com:443 {
         fqdn {
            autopopulate enabled
            name my.fqdn.com
         }
      }
   }
   monitor /Common/tcp
}

 

Environment

  • BIG-IP APM
