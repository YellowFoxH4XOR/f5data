Known Issue

This is the result of a known issue. Editing a server object within the BIG-IP GTM configuration utility incorrectly adds prober 0.0.0.0 to the server object configuration. As a result, a warning message appears at the command line whenever the configuration is loaded using the gtmload command or parsed using the gtmparse command. The warning message appears similar to the following example:

gtmparse: Initializing ...
/usr/bin/monitors/builtins/gtm_base_monitors.conf: SUCCESS
/usr/local/gtm/include/base_region.ISP: SUCCESS
/config/gtm/region.user: SUCCESS
/config/gtm/region.ACL: SUCCESS
/config/gtm/topology.inc: SUCCESS
Validation Warning in prober_def: Prober 0.0.0.0 not previously declared.
/config/gtm/wideip.conf: SUCCESS
gtmparse: SUCCESS

Note: The warning message is informational only and does not prevent the configuration from loading.

F5 Product Development tracked this issue as CR67973, CR61970, and CR61692 and it was fixed in BIG-IP GTM 9.3 and 9.4. For information about upgrading, refer to the BIG-IP GTM Release Notes.
