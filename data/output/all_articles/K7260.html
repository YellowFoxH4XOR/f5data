Known Issue

This is the result of a known issue. In BIG-IP LTM versions prior to 9.4, HTTP RAM Cache performance is degraded when Nagle's Algorithm is enabled in the TCP profile. The Nagle's Algorithm option causes cached responses to be copied to memory, which causes a significant performance impact on cached responses that are larger than 1 MB.

F5 Networks Product Development tracked this issue as CR57440 and it was fixed in BIG-IP LTM versions 9.3 and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

You can work around this issue by disabling the Nagle's Algorithm option in the TCP profile. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. From the Protocol drop-down menu, choose TCP.
  5. Click the TCP profile that is associated with the RAM cache virtual server.
  6. Uncheck the Nagle's Algorithm check box.
  7. Click Update.
