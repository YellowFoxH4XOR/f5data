Description:

This article addresses common challenges associated with high disk space usage in Linux environments. It provides practical troubleshooting steps to identify the root causes of disk space issues and discusses tools and techniques useful for diagnosing and resolving them. Additionally, the article emphasizes the importance of maintaining filesystem health to avoid issues caused by excessive logging, log rotation failures, and general high disk usage.

Environment:

  • Linux-based systems
  • Systems with large log files, multiple partitions, or applications generating heavy disk I/O
  • Environments with disk space constraints or frequent storage-related incidents

 

Cause:

High disk space usage can be caused by a variety of factors, including but not limited to:

  • Excessive log file generation
  • Uncleaned temporary files
  • Large or unnecessary files occupying disk space
  • Log rotation not functioning properly
  • Unmonitored growth of application data
  • Lack of disk quotas or file system limits

 

Recommended Actions:

To troubleshoot and resolve high disk space usage issues, follow these steps:

 

1. Analyze Storage Devices, Partitions, and File Systems:

Understanding the layout of storage devices and the partitions in your system is crucial. Use the following commands to gather essential information:

  • lsblk: Lists all block devices, their sizes, and mount points.

    lsblk
    Example Output:
    NAME                         MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
    sda                            8:0    0  81G  0 disk
    |-sda1                         8:1    0 200M  0 part
    |-sda2                         8:2    0  16M  0 part
    `-sda3                         8:3    0 80.8G 0 part
       |-vg--db--vda-dat.log       253:3  0    3G  0 lvm /var/log

  • fdisk -l: Displays partition tables and disk information.
    fdisk -l

  • parted -l: Shows detailed information about disk model, size, partition table, and filesystem type.
    parted -l

 

2. Analyze Disk Space Usage with df and du:

The df and du commands are essential for analyzing disk space utilization at the filesystem and directory level:

  • df -kh: Reports filesystem disk space usage in human-readable format (size, used space, available space, and usage percentage).

    df -kh
    Example Output:
    Filesystem                  Size  Used Avail Use% Mounted on
    /dev/mapper/vg-root          20G  5.0G   15G  25% /
    /dev/mapper/vg-var           10G  9.5G  500M  95% /var

  • du -sh /path/to/directory: Analyzes the space used by files and directories, showing the largest consumers of disk space.
    du -sh /var/*

    Example Output:
    1.1G /var/log
    500M /var/cache

3. Monitor File System Objects and Metadata:

To understand the size and behavior of specific files or directories, use stat to view metadata.

  • stat /path/to/file: Shows file size, inode, access/modification times, and other metadata.

    stat /var/log/messages
    Example Output:
    File:     '/var/log/messages'
    Size: 2165        Blocks: 8        IO Block: 4096 regular file

  • find /path -type f -size +1G: Locates files larger than 1GB to identify large files.
    find /var -    type f -size +1G

4. Investigate Mounted File Systems:

Ensure that the correct mount points are utilized and that they are not inadvertently consuming disk space.

  • df -T: Reports on mounted file systems and their types.

    df -T
    Example Output:
    Filesystem                    Type  1K-blocks    Used Available Use% Mounted on
    /dev/mapper/vg-root            ext4  20971520  5242880 15728640  25% /

5. Clear Log Files and Temporary Files:

Log files and temporary files often consume large amounts of disk space.

  • Clear large log files:
    > /var/log/messages

  • Remove unnecessary files in /tmp:
    rm -rf /tmp/*

6. Use lsof to Identify Open Files:

Sometimes deleted files can still be using disk space. Use lsof to find open files and processes using them.

  • lsof +L1: Lists open files that have been deleted but are still using disk space.
    lsof +L1

7. Set Up Disk Quotas:

Implement filesystem quotas to limit disk usage by individual users or groups.

  • Enable disk quotas on the system and assign appropriate limits to prevent a single user or application from consuming excessive disk space.

 

Additional Information:

  • Regular monitoring of disk usage is recommended using tools like df, du, and system log analysis.
  • Automate log rotation with tools like logrotate to ensure that logs do not grow uncontrollably.
  • Clean up temporary and cache directories periodically to avoid disk space issues.
