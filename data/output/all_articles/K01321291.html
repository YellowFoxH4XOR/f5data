Description

The latest supported iApps and Deployment guides do not list support for the most recent BIG-IP versions 14.x or 15.x:

Environment

Article K13422 lists a number of supported iApps and their associated deployment guides for example:

  • Microsoft SharePoint 2016 iApp template
  • Microsoft Exchange 2016 Mailbox servers iApp template
  • Microsoft Active Directory Federation Services iApp template

Cause

These iApps and deployment guides although fully supported are no longer specifically updated and validated with each new release, and as a result these guides will not be updated to reflect that latest released BIG-IP version.

Recommended Actions

These iApps can be used on current releases, and any issues should be reported to support as usual. 
Note that some of the older iApps are unsupported because Microsoft no longer supports that product.
