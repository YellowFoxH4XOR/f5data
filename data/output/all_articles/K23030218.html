K23030218: BIG-IQ restjavad restarting continuously

Type
Support Solution
Published
2021-12-09
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K23030218

Description

  • Restjavad process is restarting in a loop
  • The following error messages can be seen on /var/log/restjavad.0.log

    Failed getting isMaster status: Error: com.zaxxer.hikari.pool.HikariPool$PoolInitializationException: Failed to initialize pool: FATAL: role "bigiq" does not exist
    com.zaxxer.hikari.pool.HikariPool$PoolInitializationException: Failed to initialize pool: FATAL: role "bigiq" does not exist

Environment

  • BIG-IQ CM configured in HA
  • Secondary BIG-IQ CM is affected

Cause

 The restjavad process in not able to start due to missing required data.

Recommended Actions

Rebuild the Secondary device to factory defaults and add it again from Primary BIG-IQ CM.

  1. In secondary device run:

    /usr/bin/ha_set_firewall <primary_discovery_IP> <secondary_discovery_IP>

  2. Complete the initial setup in the Secondary.
  3. Reset the Primary device to standalone

    /usr/bin/ha_reset -f <self_discovery_IP>

  4. Re-add the secondary device to the primary device using GUI procedure.

Additional Information

None.
