Description

  • You have multiple NGINX instances on version R33 or above in a disconnected, air gaped environment
  • With NGINX Plus instances associated with a valid JSON Web Token (JWT) license, you set up NGINX Instance Manager (NIM) for usage reporting. 
  • With the above, however, you’ll need to download the usage report from NGINX Instance Manager and submit it to F5 from a location with internet access.

 

  • You want to know how often you would need to generate and submit usage reporting from NIM to F5’s licensing endpoint in a disconnected, air gaped environment

Environment

  • NGINX Plus
  • NGINX Instance Manager
  • Usage Reporting
  • JSON Web Token
  • Subscription
  • Disconnected Environment

Cause

  • Starting with NGINX Plus R33, all NGINX Plus instances are required to validate subscription by generating usage reports to F5’s licensing endpoint

Recommended Actions

  • In a disconnected, air-gaped environment usage report should and must take place on a monthly basis, that is, a usage report must be submited ONCE every month.
  • You can generate and submit usage report in a disconnected environment following our document "Report usage data to F5 (disconnected)"

Additional Information

  • If you postponed initial usage report using directive "enforce_initial_report", then you have a maximum of 180-day reporting grace period, during which NGINX Plus operates normally. If usage reporting has NOT established after 180 days, then NGINX Plus will stop processing traffic.
  • If associated NGINX Plus JWT license expires, you have a total of 90 days to replace expired license before NGINX stops processing traffic.
