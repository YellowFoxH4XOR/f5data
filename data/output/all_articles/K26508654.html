Issue

Error Message

01530007:5: /usr/bin/zxfrd started ===============================

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The DNS Express zone transfer daemon (zxfrd) has successfully initialized.

Impact

The zxfrd process is ready to perform zone transfers.

Recommended Actions

This message is generated when the zxfrd process initializes. Repeated appearances of this message may indicate the zxfrd process is restarting in a loop. Review the logs for related messages that may help determine the cause.
