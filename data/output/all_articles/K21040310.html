Source

Description

  • Triggered ASM Behavioral DoS blocks legitimate client traffic
  • False positive
  • The following messages can be seen on /var/log/dosl7/dosl7d.log

    DOSL7D_ARB|NOTICE|Jun 18 06:30:51.309|13622|dosl7d_anomaly_engine.cpp:5574|>>>>>>>>> ARBITRATOR:  ADM ATTACK START  on vs /Common/example_vs profile /Common/example_dos_profile attack id 3910178016 <<<<<<<<<
    |
    DOSL7D_ARB|NOTICE|Jun 18 08:16:20.844|13622|dosl7d_anomaly_engine.cpp:4035|>>>>>>>>> ARBITRATOR: END ATTACK on vs /Common/example_vs profile /Common/example_dos_profile reason: ATTACK_END_CONF_CHANGE attack id 3910178016 <<<<<<<<<

Environment

  • ASM
  • DoS profile
  • Products and features

Cause

Seen behavior is caused by a known issue tracked with the bug ID 922597

Recommended Actions

Modify the default sensitivity value from 50 to 500

  1. Connect to CLI
  2. Change the sensitivity value to 500

    tmsh modify sys db adm.health.sensitivity value 500
