Topic

After you update the APM Clients version on your BIG-IP APM system, to update your fleet of client systems running BIG-IP Edge Client on Windows, you use the F5 Component Installer Service to update your clients automatically when they connect to the BIG-IP APM virtual server. For more information on how this works, refer to K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows, macOS, and Linux CLI.

For APM Clients 7.2.7 release, you cannot use this feature. To update BIG-IP Edge Client on Windows clients to BIG-IP Edge Client 7270, you must perform a fresh installation.

Description

In October 2025, F5 rotated the cryptographic certificates and keys used to sign software update packages. As a result, the verification logic within the BIG-IP APM Installer Service (auto-updater) has been updated to recognize and validate packages signed with the new certificates and keys. For more information, refer to K000157975: BIG-IP APM VPN client update signing certificate and key rotation, October 2025.

As a result, after you update your BIG-IP APM system to APM Clients 7.2.7, in order to update the BIG-IP Edge Client on Windows clients, you must uninstall the existing BIG-IP Edge Client first then perform a fresh installation. Using the component update feature configured in the connectivity profile of the BIG-IP APM virtual server fails due to changes in signer certificates and Certificate Authority (CA) in APM Clients 7.2.7 release.

This applies under the following conditions:

  • APM Clients 7.2.7 on BIG-IP APM
  • Update to BIG-IP Edge Client 7270 on Windows clients. 
  • You use the F5 Component Installer Service to update the client side.

This does not apply to:

  • Updates on BIG-IP Edge Client for Mac and other platforms or clients.
  • You install updates directly using MSI files or deployment tools such as SCCM, Intune, or other enterprise software distribution platforms.

Recommendation

To ensure smooth functionality when you update to APM Clients 7.2.7, F5 recommends you perform one of the following procedures:

  • deploy and install the Component Installer Service component on all your Windows systems first for auto update to work. To do so, refer to K000161357: BIG-IP Edge Client on Windows auto upgrade to 7270 fails.
  • uninstall any older versions of BIG-IP Edge Client on Windows systems and perform a fresh installation of BIG-IP Edge Client 7270.
