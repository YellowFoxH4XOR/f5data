Description

After rebooting (or power-cycle) BIG-IP on Cloud platform (AWS, Azure etc.), you may face the license error;
01070608:0: License is not operational (expired or digital signature does not match contents).

You may find similar errors;

/var/log/ltm
err chmand[5825]: Curl request to metadata service failed with error(XX): 'Failed binding local connection end'
err chmand[5825]: Curl request to metadata service failed with error(XX): 'Failed binding local connection end'
err chmand[5825]: 012a0003:3: Unexpected empty product code in the dossier. : File dossier/VirtDossierSvc.cpp Line 163
err mcpd[5010]: 01070266:3: Dossier error: 1E
emerg mcpd[5010]: 01070608:0: License is not operational (expired or digital signature does not match contents).

In addition to above errors, you may see "endpoint" error in /var/log/waagent.log and/or /var/log/boot.log.
Note: The error messages is varied, depending on Cloud platform.

Here are examples of Azure;
/var/log/waagent.log
INFO Protocol endpoint not found: WireProtocol, [ProtocolError] [Wireserver Exception] [HttpError] [HTTP Failed] GET http://<IP_Address>/?comp=versions -- IOError [Errno 101] Network is unreachable -- 6 attempts made
INFO Protocol endpoint not found: MetadataProtocol, [ProtocolError] [HttpError] [HTTP Failed] GET http://<IP_Address>/Microsoft.Compute/identity?api-version=2015-05-01-preview -- IOError [Errno 101] Network is unreachable -- 6 attempts made
 

Environment

  • BIG-IP on Cloud platform (ex. AWS, Azure)
  • After reboot or power-cycle
  • PAYG

Cause

It might be due to temporary failure of "endpoint" (Ex. AWS, Azure).

Recommended Actions

Reboot BIG-IP

Additional Information

None.
