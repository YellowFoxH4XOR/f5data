Known Issue

This is the result of a known issue. The source address affinity persistence timeout is reset to default value during an upgrade to BIG-IP LTM version 9.4.2 or 9.4.3. For example, if you are running a version of BIG-IP LTM prior to version 9.4.2, and the configuration contains a source address affinity persistence profile with a custom timeout value, the timeout value will reset to the default value of 180 seconds during an upgrade to BIG-IP LTM version 9.4.2 or 9.4.3.

F5 Product Development tracked this issue as CR87329 and it was fixed in BIG-IP LTM version 9.4.4. For information about upgrading, refer to the BIG-IP LTM release notes.
