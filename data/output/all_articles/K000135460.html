K000135460: FTP data session fails

Type
Support Solution
Published
2023-07-12
Updated
2023-07-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000135460

Description

FTP data channel is unexpectedly terminated with a reset from BIG-IP.

Environment

  • BIG-IP LTM
  • FTP profile
  • BIG-IP platform with the embedded Packet Velocity Acceleration (ePVA) chip

Cause

Seen behaviour is cased by a known issue tracked with the Bug ID 883593 .

Recommended Actions

Upgrade to a software version where the issue is fixed. As a workaround you can make modifications to the FTP profile by performing one of the following procedures:

 

  • Set the Data Port to 0

  • Enable 'inherit-parent-profile' option in the FTP profile.

Set the Data Port to 0

Impact of action: None

  1. Go to Local Traffic Management > Profiles > Services > FTP.

  2. To create a custom FTP profile, select Create.

  3. For Name, enter a name for this new FTP profile.

  4. Under Settings, select the Custom box.

  5. For Data Port, type 0.

  6. To save the new custom FTP profile, select Finished.

  7. Associate this FTP profile with your virtual server.

Enable 'inherit-parent-profile' option in the FTP profile.

Impact of action: Enabling Inherit Parent Profile allows the FTP data channel to inherit the TCP profile used by the control channel. When the setting is disabled (default setting), the data channel uses FastL4 only. Enabling Inherit Parent Profile and consequently not using FastL4 may cause a slight performance impact.

  1. Go to Local Traffic Management > Profiles > Services > FTP.

  2. To create a custom FTP profile, select Create.

  3. For Name, enter a name for this new FTP profile.

  4. Under Settings, select the Custom box.

  5. Select the Inherit Parent Profile box.

  6. To save the new custom FTP profile, select Finished.

  7. Associate this FTP profile with your virtual server.
