K42351432: Issues when trying to disable Strict Updates from an iApp (using the GUI), and/or when trying to edit any configuration object on that iApp using the GUI

Type
Support Solution
Published
2021-02-12
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 16.1.X, 16.0.X, 16.1.0, 16.0.1, 16.0.0, 16.X.X, 16.1.2, 16.1.1, 16.1.3
Source
https://my.f5.com/manage/s/article/K42351432

Description

Error(s) messages seen on the GUI when trying to disable Strict Updates from an iApp (using the GUI). 
When trying to disable Strict Updates (trough GUI) or modify and object from an iApp, it might be possible you see some messages like the following:

"The requested URL /iapps/<iapp-template-name>/index.html was not found on this server"

For example:

"The requested URL /iapps/f5-iappslx-access-saml-sp/index.html was not found on this server"

Environment

  • Having Virtual Servers created using an iApp
  • BIG-IP Configuration Utility

Cause
Undetermined
 

Recommended Actions

If GUI is showing error mentioned above, as a workaround disable the Strict Updates vi a CLI, you can do it with a command like this:
#modify sys application service <iApp-name.app>/<Virtual-server-name> strict-updates disabled
