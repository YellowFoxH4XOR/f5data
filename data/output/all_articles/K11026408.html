Topic

The BIG-IP configuration supports only 7-bit ASCII characters in object names, descriptions, and text boxes.

Description

The BIG-IP configuration supports only 7-bit ASCII characters. This applies to object names and all free-form boxes, such as the Description box.

There are limited exceptions, such as the BIG-IP ASM configuration, which has a configurable character set on a per-policy basis and defaults to UTF-8.

Effects

As a result of this limitation, you may notice the following:

  • The TMOS Shell (tmsh) command line accepts only 7-bit ASCII characters.
  • Using non-ASCII characters through other interfaces produces unexpected behavior.
  • Using a character encoding other than UTF-8 causes iControl REST requests to fail.

Recommendations

You should avoid using non-ASCII characters in the BIG-IP configuration, except where explicitly allowed.
