K72528513: Packet inspector 1 throwing errors connecting to 20 GCB (Gigamon)

Source

Description

You see the following error when looking at the Packet Inspector (pcapper) logs:

{"level":"error","ts":1661533580.8139024,"caller":"cmd/serve.go:175","msg":"failed to get Analysis service version","error":"Get \"https://gcb-http-service.chrxnclhvzwcgcb-y-gi-x-000.svc.cluster.local:9443/v1/version\": failed to verify client certificate: x509: certificate signed by unknown authority"


Environment

  • Aspen Mesh: 1.11.x
  • Packet Inspector
  • Citadel


Cause

Mismatched Intermediate Cert. The chain had a different Intermediate Cert than the one issued to the Gigamon.
 

Recommended Actions

  1. Verify the chain for the citadel CA Cert secret using the following command:

    oc get secret -n istio-system istio.istio-citadel-service-account  -o json | jq -r '.data."cert-chain.pem"'| base64 -d

  2. Check if the chain had a different Intermediate Cert than the one issued to the Gigamon. If so, correct the chain with the right certificate by following this documentation for provisioning external certs.

  3. Restart GCB, Packet Inspector secrets, and pods. Check if everything came back to running state with no error.
     

Additional Information

Pcapper pods in istio-system namespace do not have a sidecar, so it is the Citadel configured in our cluster responsible to issuing them certificates. The documentation which should be followed to create secret CA Cert for provisioning external certs:

Provisioning Existing Certificate Authority (CA) Certificates in Aspen Mesh
