Description

The following log messages are found in /var/log/onboard.log after running onboard.js script with valid parameters:

debug: [pid: 10880] [lib/ipc.js] Sending signal ONBOARD_DONE
info: [pid: 10880] [lib/util.js] ERROR signaled from other script. Exiting

Environment

  • BIG-IP
  • BIG-IQ
  • f5-cloud-libs onboard.js

Cause

A prior "Onboard failed" event left a "signal" in /tmp/f5-cloud-libs-signals/ but it hasn't been cleared

Recommended Actions

Manually clear the "signal" by deleting the files in /tmp/f5-cloud-libs-signals/
