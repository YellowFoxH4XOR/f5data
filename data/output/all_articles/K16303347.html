Description

How to add a BIG-IP ASM security policy to a virtual server using the command line (tmsh).

Environment

  • BIG-IP ASM
  • Local Traffic Policy
  • Security policy
  • Virtual server 

Cause
None

Recommended Actions
BIG-IP ASM security policies are not applied like normal LTM profiles, they are connected to the virtual server via a Local Traffic Policy.

  1. Enter the TMSH shell from the BIG-IP command line:

    tmsh
     
  2. Create a Local Traffic Policy:
    create /ltm policy /Common/Drafts/<local traffic policy_name> requires add { http tcp } controls add { asm } strategy first-match rules add { default { actions add { 1 { asm enable policy <asm security policy name> }}}}
    Note: Replace <local traffic policy name> with the name of the BIG-IP Local Traffic Policy, replace <asm security policy name> with the name of your BIG-IP ASM security policy. 
     
  3. Publish the draft Local Traffic Policy:
    publish /ltm policy /Common/Drafts/<policy_name>
    Note: Replace <local traffic policy name> with the name of the BIG-IP Local Traffic Policy. 
     
  4. Apply the published Local Traffic Policy to the virtual server
    modify ltm virtual <virtual_name> profiles add { http websecurity } policies add { <local traffic policy name> }
    Note: Replace <local traffic policy name> with the name of the BIG-IP Local Traffic Policy. 
Note: If you apply an ASM policy via TMSH (or a customer Local Traffic Policy) using the Configuration utility (gui) at Local Traffic  > Virtual Servers > Virtual Server List  ››  <virtual server name>  > Security > Application Security Policy you may see "Manual Configuration (Advanced)"
