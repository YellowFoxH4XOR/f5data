Description

  • The F5 Distributed Cloud (XC) Retention Policy dictates the retention period for each log type 
  • Logs are retrievable via F5 Distributed Cloud (XC) systems within the retention period.

Environment

  • F5 Distributed Cloud (XC)
  • Logging

 

Log Retention Policy

Available in F5® Distributed Cloud Console on-demand:

  • Audit Logs: The retention period is 30 days.
  • Security Events: The retention period is 30 days.
  • Request Logs (AKA Access logs): The retention period is 7 days.
  • DNS Logs: The retention period is 30 days.

For example, say a request was sent 10 days in the past and generated a support ID / req_id from a security event.  The access log record will no longer be available, but the security event will.

Additional Information

  • If you are unable to locate a req_id / Support ID displayed by the Default Error Pages, bear in mind that access logs may be sampled at high request volumes which can result in some individual records being unavailable.
    • Note: security events with meaningful detections are not sampled.
  • You can use Global Log Receiver to send logs to your SIEM using the instructions here
  • You can enable streaming of logs by using the instructions here
  • You can collect access logs, security events, or audit logs by using tools here
  • Once you ingest logs into your own SIEM or other system, you can retain them for as long as you like.
