Description
When using 4096-bit public key + certificate with the client SSL profile, BIG-IP EdgeClient may report the VPN connection is established over the protocol "TLS1.2 (2048-bit)".

Environment

  • BIG-IP APM
  • Edge Client

Cause
This is due to bugID 1102793.

Recommended Actions

None: this is cosmetic issue.

Additional Information
You can display the current VPN connections information with:

  • ??????open the Edge Client "Main" window
  • click the "View Details ..." button
  • locate the parameter "Protocol Version"
