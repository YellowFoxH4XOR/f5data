Issue

You may receive the following error on your BIG-IP 2400:

CPU too hot

The heat sensor in early models of the BIG-IP 2400 is inaccurate and software fixes have proven unable to solve the problem. Starting in BIG-IP version 4.5.11, this check is disabled by default.

To resolve this issue, upgrade to the most recent version of BIG-IP. For information about upgrading, refer to the BIG-IP Release Notes.

Workaround

If upgrading is not an immediate option, you can work around this issue by disabling the system_check script.

To disable the system_check script, perform the following steps:

  1. Using a text editor, such as vi or pico, edit the /etc/crontab file.
  2. Locate the following line:

    */2 * * * * root /usr/local/bin/system_check -q

  3. Disable this line, by adding the # character at the beginning of the line.

    For example:

    #*/2 * * * *    root /usr/local/bin/system_check -q
  4. Save the file and exit.

The heat sensor check is now disabled and the inaccurate error message will no longer occur.
