Known Issue

This is the result of a known issue. Data Guard custom patterns are user-defined PCRE regular expressions that the BIG-IP PSM system uses to match sensitive data sent by the origin web server (OWS). Certain Data Guard custom patterns may cause BIG-IP PSM to dump core files when the regular expression matches a particular traffic pattern. This issue is not limited to a specific list of regular expressions statements, but occurs under the combination of particular traffic patterns and regular expression statements.

This issue only affects BIG-IP PSM; it does not affect BIG-IP ASM.

F5 Product Development is tracking this issue as ID 225527 (formerly CR139602).

This issue was fixed in BIG-IP 11.0.0, Hotfix-BIGIP-9.4.8-407.0-HF4 issued for BIG-IP 9.4.8, and Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for 10.2.0. You may download these BIG-IP versions or hotfix versions from the F5 Downloads site.
