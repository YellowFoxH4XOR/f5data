K000156527: Impact of Azure Disk Type Change on F5® Distributed Cloud Customer Edge (CE) Node Operation

Description

Changing the Azure disk type from Standard HDD to any SSD for F5® Distributed Cloud Customer Edge (CE) nodes does not require redeployment of the CE node. No errors or operational issues are expected when the disk type is upgraded in-place, provided the recommended procedure is followed.

Environment

  • Product: F5® Distributed Cloud Customer Edge (CE)
  • Platform: Microsoft Azure Virtual Machines
  • Configuration: CE nodes deployed on Azure VMs using Standard HDD disks, with planned upgrade to any SSD disks

Cause

Microsoft is retiring Standard HDD disks in Azure, necessitating an upgrade to any SSD disks for continued support and operation.

Recommended Actions

  • The disk type of an Azure VM can be changed from Standard HDD to any SSD in-place, without redeploying the F5 Distributed Cloud CE node.
  • To avoid any issues, ensure the VM is powered off before converting the disk type.
    • You may start with the non-active node if you are running a three node cluster.
    • Check the Connectivity panel under Home > Multi-Cloud Network Connect > Overview > Infrastructure > Sites
    • The Connectivity panel shows the initiating nodes.
      • The node not present under initiating node is the non-active node.

  • Use the Azure portal or CLI to change the disk type following official documentation: Change the type of an individual managed disk
    Note: This link takes you to a resource outside of MyF5, and the third party could remove the document without our knowledge.
  • After conversion, power the VM back on. The CE node will continue to operate normally.
