K000134470: Database config-restore failed

Type
Support Solution
Published
2023-05-04
Updated
2023-05-05
Source
https://my.f5.com/manage/s/article/K000134470

Description

When loading a backup archive on an rSeries system, in certain instances a "Database config-restore failed" error may be observed. In some cases this can be due to attempting to load an archive from a later version of F5OS on an earlier version.

 

Environment

  • F5OS
  • Versions 1.x
  • Working with backup archives

 

Cause

Archives taken from a later version won't load on an earlier version.

 

Recommended Actions

Update the system you're on to a version equal to or later than the version off the system the archive was generated on.
