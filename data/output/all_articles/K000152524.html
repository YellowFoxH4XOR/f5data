Description

You are using OIDC policy in your NGINX Ingress Controller deployment, and want to add extra URL arguments to the authorization endpoint(IDP).

Environment

  • NGINX Ingress Controller
  • OIDC

Cause

By default, the OIDC policy YAML file is defined as below, and it does not natively support dynamic parameter. 

apiVersion: k8s.nginx.org/v1
kind: Policy
metadata:
  name: oidc-policy
spec:
  oidc:
    clientID: nginx-plus
    clientSecret: oidc-secret
    authEndpoint: https://keycloak.example.com/realms/master/protocol/openid-connect/auth
    tokenEndpoint: http://keycloak.default.svc.cluster.local:8080/realms/master/protocol/openid-connect/token
    jwksURI: http://keycloak.default.svc.cluster.local:8080/realms/master/protocol/openid-connect/certs
    endSessionEndpoint: https://keycloak.example.com/realms/master/protocol/openid-connect/logout
    scope: openid+profile+email
    accessTokenEnable: true

Recommended Actions

1.Define a map block in the ConfigMap, nginx-config, via the http-snippets to get the dynamic parameter. In the example below, NGINX will check the $arg_dummy value from the request (/example?dummy=hello-world) , and pass it to $oidc_dynamic_arg.

apiVersion: v1
kind: ConfigMap
metadata:
  name: nginx-config
  namespace: nginx-ingress
data:
  http-snippets: |
    map $arg_dummy $oidc_dynamic_arg {
      "" "";
      default "extra_arg=$arg_dummy";
    }

2. Use the authExtrArgs field to set the extra dynamic parameter, $oidc_dynamic_arg

apiVersion: k8s.nginx.org/v1
kind: Policy
metadata:
  name: oidc-policy
spec:
  oidc:
    clientID: nginx-plus
    clientSecret: oidc-secret
    authEndpoint: https://keycloak.example.com/realms/master/protocol/openid-connect/auth
    tokenEndpoint: http://keycloak.default.svc.cluster.local:8080/realms/master/protocol/openid-connect/token
    jwksURI: http://keycloak.default.svc.cluster.local:8080/realms/master/protocol/openid-connect/certs
    endSessionEndpoint: https://keycloak.example.com/realms/master/protocol/openid-connect/logout
    scope: openid+profile+email
    accessTokenEnable: true
    authExtraArgs: [$oidc_dynamic_arg]     <<==== Add this line
