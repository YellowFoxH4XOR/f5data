    Description

    To preserve a client's IP address for DNS traffic on an F5 device, you can utilize the "EDNS Client Subnet (ECS)" feature within the BIG-IP DNS module, which allows the F5 to inject the client's source IP information into the DNS request, effectively forwarding the original client IP address to the backend DNS server; this is achieved by configuring the appropriate settings on the Wide IP or globally within the F5 configuration. 

    Environment

    F5 DNS GTM

    3rd Party DNS/DDOS Application

     

    Cause

    Need to preserve client IP with F5 DNS:

    • EDNS-Client-Subnet:
      • This is the standard mechanism used to send the client's subnet information within a DNS query, enabling the backend server to identify the client's origin. 
    • Wide IP configuration:
      • You can configure the ECS option at the Wide IP level, allowing specific domain names to benefit from client IP preservation. 
    • Global configuration:
      • Alternatively, you can set up ECS globally on the F5 BIG-IP DNS system to apply the client IP preservation across all DNS requests. 

    Answer/Recommended Actions

    1. Access the F5 BIG-IP configuration interface. 
    2. Navigate to the DNS settings within the relevant Wide IP or global configuration section. 
    3. Enable the "Prefer Client Subnet" option 
    4. Enable the "Insert Source Address Into Client Subnet" option

    Additional Information

    • Backend DNS server compatibility:
      • Ensure your backend DNS servers are configured to interpret and utilize the ECS information included in the DNS query. 
    • Security implications:
      • Be mindful of potential privacy concerns when forwarding client IP addresses, especially if you are handling sensitive data.
