Known Issue

This is the result of a known issue. If a user running Windows Mobile 5.0 or 6.0 manually establishes a Network Access connection, then uses an application that is not integrated into the Windows Connection Manager, the application is unable to use the Network Access tunnel. Network traffic generated by the application is not sent through the F5 SSL VPN adapter.

F5 Networks Product Development tracked this issue as CR91980 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-2 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
