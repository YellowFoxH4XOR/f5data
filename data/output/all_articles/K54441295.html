Description

A Vulnerability Scanner may return this result for a BIG-IP DNS Listener:
The remote DNS server answers to any request. It is possible to query the name servers (NS) of the root zone ('.') and get an answer that is bigger than the original request. By spoofing the source IP address, a remote attacker can leverage this 'amplification' to launch a denial-of-service attack against a third-party host using the remote DNS server.

Owasp Category Security Misconfiguration

Impact
The remote DNS server could be used in a distributed denial of service attack.

Risk
Rating High

Recommendation
Restrict access to your DNS server from public network or reconfigure it to reject such queries.

Environment

DNS recursion already disabled on the BIG-IP as per K7055: Enabling DNS recursion in the named configuration on a BIG-IP DNS system unless its enabled manually.
DNS or AFM module licensed and provisioned

Cause

Vulnerability Scanner result
 

Recommended Actions

Per https://www.cisa.gov/uscert/ncas/alerts/TA13-088A, a Domain Name Server (DNS) amplification attack is a popular form of distributed denial of service (DDoS) that relies on the use of publically accessible open DNS servers to overwhelm a victim system with DNS response traffic. It documents mitigation for DNS Amplification attacks. Review the suggestions and apply as needed.

Implement AFM DNS DoS attack type vectors to prevent excessive queries being sent to the BIG-IP listener or DNS VIP

Implement AFM DNS DoS attack type vectors to prevent excessive queries being sent to the BIG-IP listener or DNS VIP - example, the ANY type query can return more information in dns responses and used in dns amplification attacks
see https://my.f5.com/manage/s/article/K49869231#link_08_03

Restrict access to your BIG-IP DNS listener from public network where possible.

Restrict access to your BIG-IP DNS listener from public network where possible. If BIG-IP AFM is provisioned,  create network firewall rules to limit access to the DNS listener.

The "ANY" type query can be filtered using a DNS Security Profile configuration.
