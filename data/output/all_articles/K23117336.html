Issue

Old Behavior

In versions prior to BIG-IP 14.1.0, the prompt on the maintenance operating system (MOS) displays as follows:

bash (try 'info') / >

New Behavior

Beginning in BIG-IP 14.1.0, the MOS prompt displays as follows:

switch_root:/#

F5 Product Development tracked this change as ID 710222.
