Description

If you require to allow a specific host name in the http request, you can refer to the below procedure.

Environment

  • BIG-IP Advanced WAF

Cause

Illegal host name violation is raised when "Host" header doesn't contain an host that related to host name list (Application Security : Header > Host Names)

Recommended Actions

The actions or steps required to address the topic covered in the description.

       1. Confirm if either or both of Alarm and Block of Illegal host name are checked below.   

Security >> Application Security : Policy Building : Learning and Blocking Settings

Headers > Illegal host name    

       2. Create host name list to be allowed.

Security >> Application Security : Headers : Host Names

Click Create and specify below.

Host Name

Type the host name that is used to access the web application. 

You can type either a domain name or an IP address.

Include Sub-domains

When a domain name is used in the above, check this box if you also want to use all sub-domains of the specified host name to access the web application.
