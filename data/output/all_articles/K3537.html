Topic

Note: Prior to BIG-IP version 4.0, VLAN failsafe was called interface failsafe.

Note: For information about BIG-IP version 9.x, refer to K7066: Overview of VLAN failsafe.

For information about BIG-IP versions 10.x - 11.x, refer to K13297: Overview of VLAN failsafe (10.x - 11.x).

The VLAN failsafe timeout is the length of time that BIG-IP will continue to run without detecting traffic on a VLAN before it reboots and fails over.

When BIG-IP has not detected traffic for half of the configured failsafe timeout, it will attempt to generate traffic on the network by sending an ARP message to all hosts in its ARP cache for that VLAN. If BIG-IP detects an answer to this ARP, it will reset the VLAN failsafe timer. If it receives no response, it will continue to send an ARP to the target every second. If the timer reaches 0 (zero) and BIG-IP has not received a response, BIG-IP will reboot and fail over.

Timeout values

The timeout values for the VLAN failsafe are as follows:

Value typeTime in seconds
Minimum10
Maximum4,294,967,295
Default30

F5 Networks recommends that you leave the VLAN failsafe timeout at the default of 30 seconds for most networks; however, you can change the value depending on the equipment to which BIG-IP is attached. You can determine the best value for your network by experimenting with your hub or switch configuration and establishing a threshold value where normal events, such as spanning tree convergence, do not cause VLAN failsafe to trigger.

Following are two examples of different timeout value requirements:

Cisco 6500 switch

In the standard out-of-the-box configuration of the Cisco 6500 switch, it takes approximately 32 seconds for the 100MB Ethernet port to become stable and return traffic to the BIG-IP; therefore, the 30-second default for the VLAN failsafe timeout will cause the BIG-IP to continuously reboot, since the switch is blocking the traffic for longer than the timeout.

F5 Networks recommends that you set the VLAN failsafe timeout to a value greater than 32 seconds.

Extreme Summit-24 switch

For the Extreme Summit-24 switch with Spanning Tree disabled, the settle time can be as low as 6 seconds; therefore, you can reasonably set the VLAN failsafe timeout to 10 seconds (the minimum time allowed). This provides just enough time for BIG-IP to receive the ARP reply and reset the timer.


Configuring VLAN failsafe

To arm VLAN failsafe, type the following command:

bigpipe vlan <vlan> failsafe arm

To set the timeout value, type the following command:

bigpipe vlan <vlan> timeout <timeout>

To disarm VLAN failsafe, type the following command:

bigpipe vlan <vlan> failsafe disarm
