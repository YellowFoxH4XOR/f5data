K31130851: CNAME Pool with AWS NLB member is not resolving intermittently

Description
DIG commands executed against 'localhost' can be forwarded to System DNS resolvers

Environment

  • BIG-IP with DNS provisioned
  • CNAME DNS objects in a WideIP CNAME pool
  • DIG command executed against localhost
  • No DNS LB pool, or local BIND db, defined

Cause
If the BIG-IP has no way to resolve a CNAME in a WideIP pool, it will forward out the request to the DNS servers configured in System > Configuration > Device > DNS.  Resolution failures can then point to an issue with the DNS server where the BIG-IP is forwarding the request.

Recommended Actions
If the intention is to test the DNS resolution capabilities of the BIG-IP DNS listener, DIG commands should be run against the BIG-IP DNS listener, not localhost.
