Description

Always Connected Mode refers to an installation option of BIG-IP Edge Client that allows an Administrator to define the connection behavior of the Edge Client. The purpose is to prevent a user or application from accessing the Internet or other networks until a Network Access connection is established. Additionally, the user is prevented from manually disconnecting Network Access. This is implemented through the use of the F5 Networks Traffic Control Service and the F5 Networks Stonewall Service.

Environment

Always Connected Mode uses Network Location Awareness to determine when a client should attempt to start a Network Access connection.

  • DNS Suffix(es) are specified in the connectivity profile/Location DNS List and checked against the DNS Suffix specified on the network adapter of the client. If the DNS Suffix matches, the client does not attempt to establish a Network Access connection.
  • Domain Controller reachability tests are performed to determine if a client is connected to the enterprise LAN, if a Domain Controller is accessible, the client does not attempt to establish a Network Access connection.

Traffic Control options when Network Access is disconnected

Beginning in version 12.1.0; three options are available to specify what traffic is allowed when Network Access is disconnected.

  • Allow

    In this mode, all traffic is allowed. This allows unrestricted access to any network before the client connects and after it disconnects. When the DNS Suffix of an enabled network adapter is updated to match the Location Specific DNS, the Edge Client will begin Network Access connection.

  • Allow-Only-In-Enterprise-LAN

    In this mode, when the client is connected to the Enterprise LAN, all traffic is allowed. When the client is NOT connected to the Enterprise LAN, only the following traffic is allowed: traffic on the local loopback, inbound traffic, DHCP, and DNS requests. Additionally, if the Edge Client is running, traffic to the Virtual Server IP and captive portal probes are allowed.

  • Block

    In this mode, only the following traffic is allowed: traffic on the local loopback, inbound traffic, DHCP and DNS requests. Additionally, if the Edge Client is running, traffic to the Virtual Server IP and captive portal probes are allowed.

Detailed information about what traffic is allowed in what configurations is available in K43906425: Overview of BIG-IP Edge Client Always Connected mode.

Beginning in version 13.0, the Exclusions List option is available. Addresses added to the exclusions list will allow requests to these hosts in any Traffic Flow configuration. The list is limited to 10 entries and may include IPv4 addresses or FQDNs, with or without a port specification. Adding a host to the exclusion list is necessary when 3rd party authentication is used (ex. SAML, or Duo Auth)

Configuration of Always Connected Mode

  • To configure Always Connected Mode, go to the connectivity profile applied to the Virtual Server where Network Access connections are made. 
    Access  ››  Connectivity / VPN : Connectivity : Profiles. Select the profile and choose Customize Package.
  • On the Available Components page, ensure that the Traffic Control Service is selected along with any other services required for your deployment.
  • On the BIG-IP Edge Client page, select the Enable Always connected mode check box.
  • From the Traffic flow when VPN is disconnected list, select an option.
  • Add addresses to the Exclusions list if required.

Additional Information

  • During installation, the DNS Suffixes and the Traffic Control options selected are written to the following profile files:
C:\ProgramData\F5 Networks\Secure Access Client\config.f5c,
C:\Program Files (x86)\F5 VPN\config.f5c
  • The install time file will include configured exclusions:
<STONEWALL_EXCLUSIONS>
<ITEM>www.example.com</ITEM>
</STONEWALL_EXCLUSIONS>
  • The profile-based files will include definitions for Always Connected Mode and Traffic Blocking options. 
<ALWAYS_CONNECTED_MODE>YES</ALWAYS_CONNECTED_MODE>
<DISCONNECTED_VPN_TRAFFIC_OPTION>0</DISCONNECTED_VPN_TRAFFIC_OPTION>
<DISCONNECTED_VPN_TRAFFIC_OPTION> has 3 options that correspond to the option selected for 'Traffic flow when VPN is disconnected'
0 – Block
1 –Allow
2 – Allow only in Enterprise LAN
  • The following Registry Keys are written:

Regsitry Key (32 bit): HKLM\Software\F5 Networks\RemoteAccess\AlwaysConnected\NLAConfiguration 
Registry Key (64 bit): HKLM\Software\Wow6432Node\F5 Networks\RemoteAccess\AlwaysConnected\NLAConfiguration
Name: DNSSuffixes  Type: REG_SZ Value: <comma delimited suffixes> e.g. suffix1,suffix2,suffix3, based on suffixes from config.f5c
Name: DisconnectedVPNOption Type: REG_DWORD Value:< 0 or 1 or 2> based on the traffic option from config.f5c

  • Edge client connects to the APM Virtual Server and downloads the configuration with a request to /pre/config.php?version=2.0. Suffixes from the downloaded configuration are merged with the original profile files and stored as a per user profile here: %APPDATA%\F5 Networks\VPN\client.f5c
  • Network Location Awareness reads the DNS suffixes from the user specific profile %APPDATA%\F5 Networks\VPN\client.f5c first and then from C:\Program Files (x86)\F5 VPN\config.f5c. If the dns suffix of the local adapter matches a suffix in the profile, the Edge Client does not attempt to connect. Network Location Awareness repeats this check each time a network event occurs. 
  • Network Location Awareness checks for Domain accessibility by sending an SRV request to _ldap._tcp.dc._msdcs.<suffix>, for each suffix configured in Location DNS. If a valid record is received for any configured suffix, the Edge Client does not attempt to connect to Network Access.
  • The F5 Networks Stonewall Service updates the registry keys with the DNS suffixes that are merged into %APPDATA%\F5 Networks\VPN\client.f5c
