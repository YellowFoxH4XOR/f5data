K000160900: Review Attack Signatures in NGINX App Protect or WAF for NGINX

Type

Published
2026-04-20

Source

Description

Review the attack signatures in your NGINX App Protect/WAF for NGINX system.

Environment

  • NGINX App Protect/WAF for NGINX
  • Attack signatures  

Cause

None

Answer/Recommended Actions

On your NGINX App Protect system, you can use the built-in tool to generate a report of all attack signatures present:

nginx-plus-waf:~# /opt/app_protect/bin/get-signatures -o /var/tmp/signature-report.json --fields=name,signatureId,accuracy
{"filename":"/var/tmp/signature-report.json","completed_successfully":true,"file_size":863369}

Then check with a editor or use a similar command: 

nginx-plus-waf:~# cat /var/tmp/signature-report.json | jq . 
{
  "revisionDatetime": "2025-09-17T14:03:48Z",
  "signatures": [
    {
      "name": "Unicode Fullwidth ASCII variant",
      "signatureId": 299999999,
      "accuracy": "low"
    },
    {
      "accuracy": "low",

To see which signature sets are enabled or disabled in your current policy, you can export the full policy:

nginx-plus-waf:~# /opt/app_protect/bin/convert-policy -i /etc/app_protect/conf/test.json -o full_export-default-policy.json --full-export
{"filename":"/root/full_export-default-policy.json","completed_successfully":true,"file_size":145850,"warnings":[],"error_message":[]}

Then check the policy configuration, 

nginx-plus-waf:~# cat full_export-default-policy.json | head
{
   "policy" : {
      "applicationLanguage" : "utf-8",
      "blocking-settings" : {
         "evasions" : [
            {
               "description" : "Semicolon path parameters",
               "enabled" : false,
               "learn" : true
            },
...
