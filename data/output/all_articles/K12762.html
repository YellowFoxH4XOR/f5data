Known Issue

This is the result of a known issue. The BIG-IP APM Configuration utility enforces strict validation checking on a BIG-IP APM AAA HTTP configuration and allows only certain special characters. The following table lists the special characters that the BIG-IP system allows for an AAA HTTP configuration.

Character NameCharacter Symbol
Period.
asterisk*
slash/
dash-
colon:
underscore_
question mark?
equal=
at@
comma,
space' '

If you attempt to use the BIG-IP Configuration utility to create an AAA HTTP configuration that contains a special character that is not listed in the table, you receive an error message that appears similar to the following example when saving the configuration:

Bad Characters. Only the following special characters are allowed: period, asterisk, forward slash, dash, colon, underscore, question mark, equals, at sign, comma, ampersand and space (.*/-:_?=@,& )

Workaround

You can work around this issue by using the BIG-IP command line to create the AAA HTTP configuration. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Create the AAA HTTP configuration by using the following command syntax:

    Note: Not all parameters are required.

    bigpipe aaa http server <aaa http name> '{ start uri "<uri path>" form method (post | get) form action "<action to perform>" form username "<form parameter for user name>" form password "<form parameter for password>" form params "<hidden form parameters/values>" follow redirect <number of redirects to follow> success match type (uri | cookie | string) success match value "<Successful Logon Detection Match Value>" }'

    For example:

    bigpipe aaa http server httpauthserver '{ start uri "http://www.siterequest.com/logon" form method post form action "./logon.js" form username "logonuser" form password "logonpassword" form params "SMAGENTNAME $SM$K36+A%2bHwBxZja%3d" success match type string success match value "Logon Successful"}' <enter>

Note: You can use the BIG-IP Configuration utility to view the AAA HTTP server configuration, but you will be unable to update the configuration.

Note: For more information about the BIG-IP command line, refer to the Bigpipe Utility Reference Guide for your version of the BIG-IP system.
