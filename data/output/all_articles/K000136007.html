K000136007: BIG-IP APM Endpoint Check not detecting antivirus

Type
Support Solution
Published
2023-08-29
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000136007

Description

You have created Access Policy with Endpoint Check to check Antivirus installed on the client, but the check is failing. You may see similar exceptions in Client Troubleshooting Utility report:


POLICY_SERVER, 1, , 365, CClientSession::CreateAgentCheck, EXCEPTION caught: CClientSession::CreateAgentCheck - EXCEPTION
POLICY_SERVER, 1, , 0, , CClientSession::ExecuteCheck - Failed to create new agent (id:"/Common/example_av_check_ag_2", guid:"***", data:"type=av&collect=2&count=1&check_list_type=required&vendor_id1=0&id1=0&version1=&platform1=0&state1=1&db_version1=&db_age1=0&last_scan1=0&engine_version1=")
EPCHECK, 2, \Process.h, 154, f5::system::getProcessNameByID, OpenProcess() failed (PID, error), 4, 5 (0x5) Access is denied.

Environment

  • BIG-IP APM with configured Access Policy using Endpoint Inspection (version 13.1 onwards)
  • Client using Edge Client or Browser helper applications on Microsoft Windows (version 7.1.5 onwards)
  • Inspector Service (an optional Component install) is not running

Cause

Some AV products have started to require Privilege escalation to Check Last Scan date and other state information. On Microsoft Windows this is done by an optional component "Inspector Service" that may not be installed or running. 

Recommended Actions

Check that "Inspector Service" is installed and running

You can check Client Troubleshooting Utility report under section F5 Network Access Diagnostic  > SERVICES
F5 Inspector Service Not installed
or under section Components Information
Inspector Service    f5InspectorService.exe    - not found

Alternatively you can check on Windows:

Type "services" in the windows search bar to launch the services GUI
Once the "Services(Local)" are displayed, scroll down and check the ones starting with F5
Check that "F5 Networks Inspector Service" is shown as running (f5InspectorService.exe).
If it is shown but not running, you should try to restart the service.
If it is not shown, re-install the Edge Client (with 'run as administrator') with following services selected in the customized windows client package:
  • Inspector Service (that would help with detecting AV/FW,.. that requires admin privileges)
  • Component Installer Service (that would help updating & installing the below client side components for users without admin rights)
  • Endpoint Security
     

Additional Information

Inspector Service
This component installs and registers a Windows service that supports OPSWAT Endpoint inspection with escalated privilege (Administrator).
