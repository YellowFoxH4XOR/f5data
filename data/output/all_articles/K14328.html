Topic

You should consider using this procedure under the following condition:

  • You need to test the validity of the Enterprise Manager software license

Description

You can verify the license in Enterprise Manager 3.x using the tmsh command, and in Enterprise Manager 1.8.0 through 2.3.0 using the bigpipe command.

If you determine an Enterprise Manager license is expired, or not valid, you may be required to reactivate the license. For more information about licensing the Enterprise Manager system, refer to K14327: Licensing the Enterprise Manager system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Enterprise Manager command line

Procedures

Verifying the license in Enterprise Manager 3.x

Impact of procedure: None.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. Display the licensing information for the Enterprise Manager system by typing the following command:

    show /sys license

    If the Enterprise Manager is properly licensed with a valid license, licensing information and a list of active modules will display. For example:

    Sys::License
    Licensed Version    3.0.0
    Registration key    N445-677997-164001-640162-0925025
    Licensed On         2012/08/28
    License Start Date  2012/08/27
    License End Date    2013/04/11
    Service Check Date  2013/03/12
    Platform ID         Z100

    Active Modules
      Enterprise Manager VE - DEV (D500672-5478408)
        ADD STATS REPORTING
        ADD 8 DEVICES
        EM, ADD MAX DEVICES

    If the Enterprise Manager is not properly licensed with a valid license, the system will not function. In addition, a message similar to the following will display:

    Can't load license, may not be operational

Verifying the license in Enterprise Manager 1.8.0 through 2.3.0

Impact of procedure: None.

  1. Log in to the Enterprise Manager command line.
  2. Display the licensing information for the Enterprise manager system by typing the following command:

    bigpipe version

    If the Enterprise Manager is properly licensed with a valid license, licensing information and a list of enabled features modules will display. For example:

    Note:     The Enabled Features section of the command output has been truncated for clarity.

    Kernel:
    Linux 2.4.21-1.8.0.868.0smp
    Package:
    EM Version 1.8.0 868.0
    Final Edition

    Enabled Features:
    EM Certificate Management
    EM Configuration Archiving
    EM Device Auditing
    EM Device Inventory
    EM Device Performance Monitor
    EM Software Installer
    EM License Management
    EM Log File Management
    EM Network Object Management
    EM Managed Devices unlimited
    Enterprise Manager
    BIG-IP Monitor
    EAV Monitor
    FTP Monitor
    HTTP Monitor
    HTTPS Monitor
    ICMP Monitor
    IMAP Monitor
    LDAP Monitor
    LDAP Over SSL Monitor
    SNMP Link Monitors

    If the Enterprise Manager is not properly licensed with a valid license, the system will not function. In addition, the command output will not display any enabled features. For example:

    Kernel:
    Linux 2.4.21-1.8.0.868.0smp
    Package:
    EM Version 1.8.0 868.0
    Final Edition

    Enabled Features:
