K000149732: Time out error launching Advanced Settings from APM Policy Sync configuration

Type
Support Solution
Published
2025-04-16
Updated
2025-04-16
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000149732

Description

You are setting APM Policy Sync on APM using WebUI and when you try to open Advanced Settings a popup comes up with error "Request timed out. Status text communication failure" after a while.

Restarting tomcat fixes it during a period of time.

Environment

  • BIGIP provisioned with APM

 

Cause

tomcat running out of resources

 

Recommended Actions

 

Increase memory assigned to tomcat.

 

If tmm is not using all of its memory, you can assign memory from tmm to tomcat.

You can check memory constumption by tmm running "tmsh show sys memory" or selecting Graphs (Memory used) in a qkview

 

To remove 1GB of memory from tmm

Impact: This command requires tmm restart causing production traffic interruption and requires maintenance window to apply

tmsh modify sys db provision.extramb value 1024

To assign 1GB of memory to tomcat

tmsh modify sys db provision.tomcat.extramb value 1024

tmsh save sys config

tmsh restart /sys service tomcat
