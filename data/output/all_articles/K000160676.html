Description

The DoS Dashboard stopped displaying attack data. While DoS attack events are visible in Security ›› Event Logs : DoS : Application Events, the dashboard itself appears empty and does not show recent attack statistics. Log messages in dosl7d.log confirm attacks are detected, but avrd.log shows warnings such as:

Received event about attack [ID] while VIP [name] no longer exist (probably deleted). Will mark/already marked this attack as ended

Trying to update statistics on attack ID [ID] but such attack is not present in our map. Throwing away this update

Environment

  • BIG-IP ASM
  • DoS Dashboard doesn't display recent attack's data

Cause

The issue is related to an internal mapping problem between attack events and virtual servers within the AVR service.

Answer/Recommended Actions

To resolve the issue of the DoS Dashboard not displaying attack data:

  1. Schedule a maintenance window, as the following action will restart a service (recommended for production environments).
  2. Restart the AVR daemon by running:
    bigstart restart avrd
  3. Wait 1–2 minutes for the service to restart.
  4. Verify the service status:
    bigstart status avrd
  5. After the restart, check if the DoS Dashboard is now displaying attack data (you will have to wait until the next attack is triggered).

Additional Information

Restarting the avrd service typically does not impact traffic processing, but caution is advised in production.
