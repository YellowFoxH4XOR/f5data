Known Issue

BIG-IP Virtual Edition (VE) fails to log “bandwidth utilization exceeded” error messages.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP VE instance is licensed with throughput limitations.
  • The system processes traffic that exceeds the licensed throughput limit.

Impact

After the licensed throughput limit is reached, BIG-IP VE fails to log alert messages.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP VE instance does not log “bandwidth utilization exceeded” messages to the /var/log/ltm file after traffic exceeds the licensed throughput limit.
  • When you run the tmsh list sys db log.alertbwthreshold command, you notice that the log.alertbwthreshold system database variable is set to 0. The output appears similar to the following example:

    tmsh list sys db log.alertbwthreshold
    sys db log.alertbwthreshold {
        value "0"
    }

Resolution

Workaround

To work around this issue, you can set the log.alertbwthreshold database variable to a value other than 0. To do so, refer to K15377: Configuring the BIG-IP VE system to log a notification when the throughput rate exceeds a configured threshold.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
