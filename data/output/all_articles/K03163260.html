Known Issue

The Traffic Management Microkernel (TMM) process exits and produces a core file when using a TCP profile with Verified Accept enabled.

This issue occurs when all of the following conditions are met:

  • The TCP profile is configured with Verified Accept enabled.
  • Hardware SYN cookie protection is enabled in the TCP profile.
  • The OneConnect profile is configured on the virtual server.
  • The BIG-IP system has reached the SYN Check Activation Threshold.

Impact

The BIG-IP system temporarily fails to process traffic while the TMM process restarts. If the BIG-IP system is configured for high availability (HA), the system fails over to a peer system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to another host in the device group.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system temporarily fails to process traffic.

Workaround

To work around this issue, you can disable the Verified Accept option in the TCP profile.

Impact of workaround: With the Verified Accept option disabled, the BIG-IP system always accepts the client connection before communication on the server side.
