Topic

You should consider using this procedure under the following condition:

  • You want to create a customized Catalog template on the BIG-IQ Cloud system with a non-default load balancing method, for any of the following types of BIG-IP iApp templates:

    • f5.http
    • f5.microsoft_sharepoint_2010
    • f5.micrsoft_iis

Description

When a BIG-IP iApp application template is being used in the BIG-IQ Catalog template, the system sets the load balancing method to Least Connections Member, by default. If you want to specify a preferred load balancing method, you can create a new BIG-IQ Cloud Catalog template when using any of the following BIG-IP iApp templates:

  • f5.http
  • f5.microsoft_sharepoint_2010
  • f5.microsoft_iis templates

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have already configured the BIG-IQ Cloud system to manage at least one BIG-IP device.
  • You are the Administrator of the BIG-IQ Cloud system.

Procedures

To specify a desired load balancing method when creating a new Catalog template on the BIG-IQ Cloud system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system using the Administrator role.
  2. Click the plus (+) symbol next to Catalog.
  3. In the Name box, type a name for the new Catalog template.
  4. In the Cloud Connector box, select the connector where the managed BIG-IP system is located.

    Optionally, you can leave the default setting, *Tenant Selectable*, to allow the Cloud Tenant user to select this option when configuring a new Application.

  5. From the long list of items in the Application Type box, select one of the following three types of applications:
    • f5.http
    • f5.microsoft_sharepoint_2010
    • f5.microsoft_iss
  6. Click the triangle symbol next to Advanced Properties to expand additional configurable items.
  7. From the list of questions in the expanded, configurable items, locate the following question:

    Note: If you use Ctrl + F, the search function on the browser, you can more easily find the questions you are looking for.

    Which configuration mode do you want to use?

    Select Yes for every instance of this question.

    Note:  This answer maps to an internal parameter, where the Yes answer, in this case, makes sense.

  8. From the list of questions in the expanded, configurable items, locate the following question:

    Do you want to restrict client traffic to specific VLANs?

    Replace the current value by typing all; do this for every instance of this question.

    Note:  This answer maps to an internal parameter, where the all answer, in this case, makes sense.

  9. From the list of questions in the expanded, configurable items, locate the following question:

    Which load balancing method do you want to use?

    Reference the previous table, and enter the load balancing method that you would like to use; do this for every instance of this question.
  10. To create the new template, click Save.

The Cloud Tenant user may now use the new Catalog template to create new Applications, using the chosen load balancing method configured in step 9.
