Description

When you created a DHCP Virtual Server in the default route domain and then modifying this VIP and changing it to a different route domain it won't trigger any error but if you load the configuration or reactivate the license the configuration won't load and /var/log/ltm will show:


 01020060:3: IP Address 255.255.255.255 is invalid, must not be all ones.


Environment

BIG-IP LTM

DHCP Virtual Server

Route Domain


Cause

ID1441549


Recommended Actions

The only workaround for the issue is simple locate the stray virtual-address and delete it .

If you want to prevent this to happen then create a DHCP Virtual Server with the route domain that you want to use and do NOT modify it.
