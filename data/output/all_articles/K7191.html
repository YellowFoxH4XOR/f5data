Known Issue

This is the result of a known issue. Using the ssldump command on the BIG-IP LTM system will not decrypt application data using FIPS-imported private keys.

F5 Product Development tracked this issue as CR65894, CR65569, and CR65893 and it was fixed in BIG-IP LTM 9.1.3, 9.3, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
