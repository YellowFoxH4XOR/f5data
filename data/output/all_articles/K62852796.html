Known Issue

An MCP error may erroneously appear in the /var/log/tmm file when the Traffic Management Microkernel (TMM) restarts.

This issue occurs when the following condition is met:

  • TMM restarts unexpectedly and creates a core file in the /var/core directory.

Impact

An MCP error message is logged erroneously and does not indicate any issue with MCP.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H581147 on the Diagnostics > Identified > Low screen
  • After an unexpected TMM restart, an error message similar to the following example appears in the /var/log/tmm file:

    notice mcp error: 0x1020003 at ../mcp/db_net.c:553
