K000139387: When SSLo/SWG forward proxy handles HTTPS connections, the client receives 503 responses or error messages.

Type
Support Solution
Published
2024-04-24
Updated
2024-04-24
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator
Source
https://my.f5.com/manage/s/article/K000139387

Description

When either BIG-IP SSLo or SWG is configured as forward proxy, users may fail to connect to HTTPS destinations: the browser may display various error messages.

Connections to HTTP destination may work fine, though.

Environment

  • BIG-IP SSLo or BIG-IP SWG
  • Forward proxy configuration
  • Route Domain

Cause

This may have its root with the misconfiguration of the "HTTP Tunnel" object.

Recommended Actions

  1. Navigate the Configuration Utility to Local Traffic ›› Virtual Servers : Virtual Server List
  2. Click the name of the Virtual Server users (or client machines) connect to
  3. Scroll down and take note the name of the parameter "HTTP Profile (Client)"
  4. Navigate the Configuration Utility to Local Traffic ›› Profiles : Services : HTTP
  5. Click the name of the HTTP Profile object as noted from step #3
  6. Scroll down to "Explicit Proxy"
  7. Update the parameter "Route Domain" to match the Route Domain the Virtual Servers are sitting in
  8. Click Update
