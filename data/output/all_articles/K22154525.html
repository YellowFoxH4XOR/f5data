Description

The vCMP HOST system logs the following hostagentd and vcmpd messages in /var/log/ltm every minute after guest upgrade:

Example:
err hostagentd[16938]: 01820004:3: Couldn't convert json to expected datastructure (http://127.3.0.1:23035/mgmt/vmchannel/host-hotfixes
warning vcmpd[16968]: 01510005:4: Failed to update guest stats from JSON file.
warning vcmpd[7776]: 01510005:4: Failed to update guest stats from JSON file.

Environment

  • BIG-IP
  • vCMP provisioned
  • vCMP guest upgrade

Cause

Bug ID 713183: Malformed JSON files may be present on vCMP host

Recommended Actions

These messages can be ignored/filtered as there is no functional impact to the guests or to the host

Additional Information

None
