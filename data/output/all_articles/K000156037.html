Description

You would like to rotate your custom log files.

Environment

  • Product: F5 BIG-IP LTM
  • Version: 11.x – 17.x (example provided for 17.1.2)
  • Platform: BIG-IP VE
  • Feature: Logrotate

Cause

Custom log files generated by third-party tools are not managed by the default BIG-IP logrotate configuration. This omission can lead to the accumulation of large or numerous log files, consuming disk space over time.

 

Recommended Actions

To add a custom log file to the BIG-IP logrotate process:

  1. Log in to TMOS Shell (tmsh):
    tmsh
  2. Edit the logrotate configuration:
    edit /sys log-rotate all-properties
    This opens the configuration in vi editor.
  3. Modify include line:
    - Enter insert mode by pressing 
    i
    - Replace any existing 
    include none 
    line with:

    include "/var/log/one.log {
  nocompress
  missingok
  notifempty
  sharedscripts
  postrotate
  endscript
  rotate 2
}"
    - Ensure /var/log/one.log` matches your actual custom logfile path and filename.
  4. Save and exit vi editor:  
    Press Esc, type :wq, then press Enter.
  5. Test manual rotation:  
    Run:
    logrotate -f` /etc/logrotate.conf
  6. This forces an immediate rotation based on your updated config.

Important: Set the `rotate <count>` value appropriately to avoid excessive disk usage.
- Only the specified file will be rotated; rotated files ending with a number (such as .1) are ignored by this configuration.
- Always verify that you have entered the correct full path and filename for your custom logfile before saving changes.
