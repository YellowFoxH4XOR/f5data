Known Issue

When using the Japanese or Chinese language localization in a Protected Workspace, the BIG-IP APM system should display an informative message to the user. However, the BIG-IP APM will generate an error message in the users browser that appears similar to the following example:

Error occurs when executing scripts on this page
Line 249
Column 127
The string is not finish with null
Code 0
Do you want to continue with this script?

If you Yes, the same error message redisplays.

F5 Product Development tracked this issue as ID 243620 (formerly CR137288) and it was fixed in BIG-IP 10.2.0. However, this issue was reintroduced in BIG-IP APM 10.2.1. This issue has been fixed in cumulative Hotfix-BIGIP-10.2.2-969.0-HF4, which has been issued for BIG-IP APM 10.2.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site. For information about upgrading, refer to the BIG-IP APM release notes.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

To work around this issue, you can change the Protected Workspace messages to the standard ASCII character set. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Access Profiles. The Access Profiles list displays in the right pane.
  4. Click the name of the profile to change. The access profile properties displays in the right pane.
  5. Click the Customization tab.
  6. Select eps from the Customization Type dropdown menu.
  7. Select the language set you want to use from the Language drop down menu. e.g. select ja for Japanese.
  8. Click Find Customization.
  9. Click the Windows Protected Workspace action message text box.
  10. Type the ASCII text you want displayed for this message in the text box.
  11. Click the Windows Protected Workspace logon: short message text box.
  12. Type the ASCII text you want displayed for this message in the text box.
  13. Click the Windows Protected Workspace continuing: extended message text box.
  14. Type the ASCII text you want displayed for this message in the text box.
  15. Click the Windows Protected Workspace continue link text box.
  16. Type the ASCII text you want displayed for this message in the text box.
  17. Click the Windows Protected Workspace started: close browser message text box.
  18. Type the ASCII text you want displayed for this message in the text box.
  19. Click Update.
  20. Click Apply Access Policy highlighted by the yellow indicator bar in the upper left corner of the window.
  21. Click Apply Access Policy.
