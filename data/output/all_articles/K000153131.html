K000153131: Response from the DNS server times out when running dig query from the CLI

Source

Description

DNS fails on single NIC deployment VEs


Environment

VE with single NIC


Cause

Due to the way that single NIC deployments function, all traffic save DHCP/SSH and traffic bound for the TMUI (TCP Port 8443 by default) must be handled by TMM. This means that DNS requests may not work as intended.


Recommended Actions

If you need DNS resolution to work normally add a second NIC to your VE.
