Known Issue

This is the result of a known issue. If you configure Active Directory dynamic group mapping, group mapping may fail if the users’s sAMAccountName attribute does not match the username portion of the user’s userPrincipalName (UPN) attribute. For example, if the user’s sAMAccountName attribute is set to johnsmith and the user’s userPrincipalName attribute is set to jsmith@example.com, Active Directory group mapping may fail.

Note: For more information about the sAMAccountName and userPrincipalName Active Directory attributes, refer to http://msdn.microsoft.com/en-us/library/ms677605%28VS.85%29.aspx.

Workaround

For certain Active Directory schemas, you can work around this issue by enabling or disabling the Forest mode option in the Active Directory group mapping method. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users : Groups : Dynamic Group Mapping page.
  3. Select the Group mapping methods tab.
  4. Next to the Active Directory mapping method, click the Configure link.
  5. If the Forest Mode check box is cleared, select the Forest Mode check box.
    If the Forest Mode check box is selected, clear the Forest Mode check box.
  6. Click the Update button.
