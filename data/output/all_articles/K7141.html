Known Issue

This is the result of a known issue. A virtual server using the FastHTTP profile will drop SYN packets with the Explicit Congestion Notification (ECN) or the Congestion Window Reduced (CWR) flag set.

F5 Product Development tracked this issue as CR65348, CR65346, and CR66194, and it was fixed in BIG-IP LTM 9.1.3, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
