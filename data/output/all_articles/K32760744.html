Security Advisory Description

valid.c in libxml2 before 2.9.13 has a use-after-free of ID and IDREF attributes. (CVE-2022-23308)

Impact

The security impact of xmlGetID() returning a pointer to freed memory depends on the application and mostly results in denial-of-service (DoS). The typical use case of calling xmlGetID() on an unmodified document is not affected.

Mitigation

To mitigate this vulnerability, do not process any untrusted XML documents in any form. The following list includes, but is not limited to, some examples of XML processing on the BIG-IP system:

  • BIG-IP (all modules) and BIG-IQ
    • Extended Application Verification (EAV) monitors parsing XML
    • iRules XML commands
    • iApps application programming language (APL)
    • QKview
    • XML content-based routing

      For more information, refer to the Routing Based on XML Content chapter of the BIG-IP Local Traffic Manager: Implementations manual.

      Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching MyF5 and finding product documentation.

  • BIG-IP ASM / Advanced WAF virtual servers referencing a security policy with any of the following:
    • XML profiles with imported XML schema files

      Note: XML profiles without imported schema files are not affected by this vulnerability.

    • Dynamic content value (DCV) parameters with extractions

      Note: You can mitigate the risk to DCV parameters by using another parameter type, where possible, or disabling these parameters.
