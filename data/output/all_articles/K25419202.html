K25419202: BIGIP send a log ''WARNING: Default value changed for the prefix() option of systemd-journal source in syslog-ng 3.8; old_value=‘’, new_value=‘.journald.’'' to syslog server

  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP DNS: 15.1.0
Source
https://my.f5.com/manage/s/article/K25419202

Description
when log rotation occurred on BIG-IP, the log appeared like below on /var/log/ltm:

notice syslog-ng[3033]: Configuration reload request received, reloading configuration

And BIG-IP sends a log below log to the remote Syslog server. 

warning syslog-ng[3033]: WARNING: Default value changed for the prefix() option of systemd-journal source in syslog-ng 3.8; old_value=‘’, new_value=‘.journald.’


Environment

  • BIG-IP
  • Remote Syslog configured

Cause

This message occurs when all of the following conditions are met:

  • Remote syslog configured on BIGIP
  • When log rotated, syslog-ng also automatically restarted or manually restart syslog-ng

Recommended Actions

  • No impact, you can safely ignore this log.
