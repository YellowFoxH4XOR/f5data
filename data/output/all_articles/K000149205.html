Description

Attempting to convert a remote certificate to a managed certificate using the certs API endpoint fails. The following error code and message is returned:

{
 "code": 134031,
 "message": "Error adding the certificate: a certificate with serial number already exists under different name. Use a unique certificate, then try again."
}

Environment

NGINX Instance Manager (NIM)

Cause

NIM does not allow multiple certificate objects, remote or managed, with the same certificate.

Recommended Actions

Convert the remote certificate to a managed certificate using a new/unique certificate.
