K000139858: APM returns TCP RST from 127.0.0.1:10001 to the client when my.policy requested

Type
Support Solution
Published
2025-05-29
Updated
2025-05-29
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000139858

Description

When a client visits a virtual server with an APM access policy, and requests /my.policy, there is an unexpected reset from an internal APM virtual server (127.0.0.1 port 10001). This ip:port correlates with the apmd daemon, which listens on that ip:port. Client gets Page Not Displayed when visiting an APM virtual. Packet capture reveals reset sent from a loopback address on TCP port 10001.

Environment

BIG-IP APM configured on a Virtual Server

Cause

apmd listener is not running for unknown reason.

 

Recommended Actions

Restart apmd daemon with one of the following commands:

tmsh restart sys service apmd

bigstart restart apmd
