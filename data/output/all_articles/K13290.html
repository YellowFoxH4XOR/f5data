Known Issue

Description

BIG-IP WebAccelerator 11.1.0 and 11.1.0 HF1 may exhibit system instability.

This issue occurs when the following conditions are met:

  • The BIG-IP WebAccelerator module is provisioned.
  • The BIG-IP system is running 11.1.0 or 11.1.0 HF1.

The trace evidence created by this issue is not specific enough to allow further troubleshooting. Customers running affected versions in production applications should upgrade immediately.

Impact

The BIG-IP Web Accelerator system may intermittently fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H378292 on the Diagnostics > Identified > Low screen.
  • The BIG-IP system may intermittently fail to process traffic.
  • The BIG-IP system may restart, which may result in failover if the system is deployed in a high-availability configuration.
  • The TMM process may dump its core, creating files that are named similarly to the following example in the /var/core/ directory:

    tmm.1.bld1922.0.core.gz

  • The TMM process may log a panic message and stack trace similar to the following examples in the /var/log/tmm file:

F5 Product Development has assigned ID 372046, 371863, 372065, 372582, and 372191 to this issue, and has confirmed that these issues exist in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

There is no workaround for this issue. Customers running BIG-IP 11.1.0 or BIG-IP 11.1.0 HF1 in production applications should apply HF2 as soon as possible to avoid outages.
