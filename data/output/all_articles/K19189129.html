Known Issue

A distributed application configuration may cause a configuration load failure.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP DNS system with a wide IP name that contains the wildcard asterisk ( * ) character.

    For example:

    *.f5.com

  • Using the Configuration utility, you create a distributed application that includes the wildcard wide IP as a member.
  • You load the DNS configuration.

Impact

The configuration fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to load the DNS configuration, the configuration fails with an error message that appears similar to the following example:

    Syntax Error: the "create" command does not accept wildcard configuration identifiers

  • When you use the Traffic Management Shell (tmsh) to create a distributed application that includes the wildcard wide IP, the distributed application creation fails with an error message that appears similar to the following example:

    Syntax Error: the "create" command does not accept wildcard configuration identifiers
