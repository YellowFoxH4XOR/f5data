Description

Command to export ASM Event Logs from BIG-IQ using api call

Environment

  • BIG-IQ CM
  • BIG-IP ASM
  • Rest API
  • ASM event logs

Cause

None

Recommended Actions

You can export up to 1800 (Default limit) events using the following command:

curl https://localhost/mgmt/cm/shared/es/logiq/asmindex/_search -X POST -d '{ "from":0, "size":1800,"sort":{ "date_time":"desc"}}' -k -u admin:admin | jq .
