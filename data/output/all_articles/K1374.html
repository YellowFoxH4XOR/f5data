Topic

By default, all accounts that you create on BIG-IP with command line access are assigned UID 0. This UID is required to run all of BIG-IP's command line utilities. This means that if you have more than one user with command line access, you will have more than one account with UID 0 and when you run the whoami command, BIG-IP may display the wrong username.

This issue has no impact on the operation of the BIG-IP Controller, but you may notice this issue when you enable the support account on your BIG-IP, because the users support and root share the same UID. The usernames that are displayed do not affect the operation of BIG-IP in any way. The UID number is the important number, not the name that is displayed along with that number. The name that is displayed when you run the whoami or ls -l command (or anything using the getnamebyid() function) is based on the order in which a username is listed in the password file. In BIG-IP versions 1.8.3 through 3.3.1, the first username listed is the name shown for a given UID. Starting in BIG-IP version 4.0, it is the last username listed with the same UID. In BIG-IP versions 1.8.3 through 3.3.1, root appears first in the password file, and support appears later, but because the behavior for UID-to-name lookup has changed, the name displayed depends on the BIG-IP version you are running.

Starting in BIG-IP version 4.5, you can provide command line access to a user account through the Configuration utility and these accounts are authenticated through BIG-IP's internal LDAP database, or through external authentication authorities.

When accessing the command line, these Configuration utility accounts are associated with UID 0, but they do not have corresponding entries in the /etc/passwd file, because they are not authenticated locally. You cannot force whoami to display a specific username for these accounts; they will always display as root. If you want to see the specific user you are logged in as, use the who am i command. (Note the spaces between the words in the command).

Changing the order of the username displayed in the /etc/passwd file

If you would like to change the order in which the accounts display in the BIG-IP /etc/passwd file, perform the following steps.

  1. From the command line, type the following command to open the password database editor:

    vipw

  2. Use the following keys (This is a vi copy/paste function.):

    dd
SHIFT+G
p
:x
Enter

    You should now see a line root appear at the bottom of the file. If you do not, or if you typed an incorrect character, escape from vi with the following keys and begin again with step 2:

    :q!
Enter

The root user entry is now moved to the bottom of the passwd file, so it is associated with UID 0 when multiple users exist with UID 0.
