Known Issue

BIG-IP APM virtual server configurations may trigger memory leaks.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM virtual server is configured with an iRule.
  • The iRule utilizes the STREAM::expression command.
  • Traffic processed by the virtual server matches the iRules event for the STREAM::expression command.

Impact

A small amount of memory is allocated and not returned to the system. Extreme memory utilization may trigger the Traffic Management Microkernel (TMM) process to produce a core file and temporarily stop processing traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The memory consumption of the TMM process steadily increases over time.
  • When configured as a high availability (HA) pair, your BIG-IP will system fail over to a peer system.
  • Your BIG-IP system generates a TMM core file to the /shared/core directory.
