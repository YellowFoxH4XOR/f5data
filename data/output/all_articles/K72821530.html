Description
Keep getting below messages from kern.log

page allocation failure: order:2, mode:0x104020

Normally, stack trace follows after the above messages.

Environment

  • BIGIP
  • kern.log

Cause
This is documented as known issue ID854493 which is related to failure of memory allocation.

Recommended Actions

Software upgrade to one of the below software version
  • v16.0.0 or above
  • v15.1.0.2 or above
  • v14.1.2.8 or above
