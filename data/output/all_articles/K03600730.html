Description

When trying to export an APM access policy through the GUI an error page is displayed containing the message "Internal Server Error"

Error messages are also logged in /var/log/httpd/httpd_errors similar to the following message:

err httpd[29585]: [proxy_ajp:error] [pid 29585] (70007)The timeout specified has expired: [client 192.168.0.1:61020] AH00878: read response failed from 127.0.0.1:8009 (localhost), referer: https://10.0.0.1/tmui/Control/jspmap/tmui/accessctrl/profiles/list.jsp?Filter=*

Environment

  • BIG-IP APM
  • Exporting an APM access policy through the web GUI

Cause

Bug ID 942729

Recommended Actions

You can workaround this issue by exporting the access policy using the CLI command ng_export.

  1.   SSH to the BIG-IP
  2.   Run the command "ng_export -t access_policy <policy_name> <filename>"
  3.   For example ng_export -t access_policy testpolicy testpolicy
  4.   This file will be output as /shared/tmp/policy-testpolicy.conf.tar.gz

If the export still fails you can also try increasing the object capacity of the ng_export script using the following procedure.

1) Mount the file system from ro to rw :
    mount /usr -o remount,rw
2) Edit the ng_export script:
    vi /usr/bin/ng_export
3) Find and update
    const MAX_SELECT_COUNT = 50;
    to
    const MAX_SELECT_COUNT = 1000;           (Change 50 to 1000)
4) Save the file, and remount the /usr volume as Read only
    mount /usr -o remount,ro
