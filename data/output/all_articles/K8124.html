To check the health of the FirePass database, navigate to the Device Management: Monitoring: System Health page in the FirePass Administrative Console. In the Storage section, you should see a status similar to the following example:

Database Integrity         no errors          OK

If FirePass reports database errors, or if the Database Integrity status is not OK, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Device Management: Maintenance: Backup/Restore page.
  3. Click the Create backup of your current configuration link or the Create backup of your current configuration and log messages link, and download the backup file locally when prompted by your browser.
  4. Log in to the FirePass Maintenance Console.

    Note: For instructions on accessing the Maintenance Console, refer to K9286: Accessing the FirePass Maintenence Console.
  5. Using the arrow keys, navigate to option 8: Check/Repair FirePass database (FirePass versions 6.0.0 and later) or to option 9a: Check/Repair FirePass database (FirePass versions 5.0 through 5.5.2) and press Enter.
  6. When the check/repair operation is complete, press Enter to return to the main menu.
  7. Select option 0: Exit to exit the FirePass Maintenance Console.
  8. Log in to the FirePass Administrative Console.
  9. Navigate to the Device Management: Monitoring: System Health page.
  10. In the Storage section, you should see a status similar to the following example:

    Database Integrity         no errors          OK

  11. If database errors are still reported, or if the database integrity status is not OK, contact F5 Technical Support.

    Note: For more information about opening a case with F5 Technical Support, refer to K4274: Information required when opening a support case for FirePass.
