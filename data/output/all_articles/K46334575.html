Topic

BIG-IP Virtual Edition (VE) software is available on the following public cloud vendor marketplaces:

  • Amazon AWS Marketplace
  • Microsoft Azure Marketplace
  • Google Cloud Platform Cloud Launcher

However, each vendor independently determines which versions of BIG-IP VE software they make available.

Description

Amazon AWS Marketplace

When Amazon AWS Marketplace selects a BIG-IP VE image, they default to the latest available version from the most recent F5 major branch.

For example:

Latest Version    13.0.0.2.0.1671

Additionally, they provide an Other available versions link to display the other available software versions. When you click the Other available versions link, what versions you see depends on whether you are a new or an existing customer:

  • New Customers

    If you are a new customer, only the latest versions available from the other major branches are displayed.

    For example, the list may appear similar to the following example:

    • 11.5.4.2.0.291
    • 11.6.1.2.0.238
    • 12.1.2.1.0.271

Note: When F5 releases a new version for a branch, Amazon replaces the previous version with the new version so only the latest version of each branch is available.

  • Existing Customers

    If you are an existing customer, in addition to the latest versions that are available to new customers, you will have available any versions that you have previously launched.

    For example, the list may appear similar to the following example:

    • 11.5.4.2.0.291
    • 12.0.0.1.14.628
    • 11.6.1.2.0.238
    • 12.1.2.1.0.271
    • 11.6.0.8.0.482
    • 11.6.0.6.204.442

When you select a version to launch, if you select a version that you have previously installed, but it is no longer the latest version for that software branch, you will see the following warning:

"! Then vendor has depreciated this versions ?"

The help text for this warning message reads:

"A depreciated version is no longer offered to new customers and will no longer be supported by the vendor after a certain date. Users are strongly encouraged to upgrade to newer versions of the software."

This is a generic message that Amazon AWS Marketplace uses to indicate that you are selecting a version of software that might not be supported by a vendor.  This message does not apply to F5 products and versions. F5 will continue to support the BIG-IP VE versions in accordance with the BIG-IP software support policy. For information, refer to K5903: BIG-IP software support policy.

Microsoft Azure Marketplace 

When you deploy a BIG-IP VE image directly from the Microsoft Azure Marketplace, they use the latest version from the most recent major software branch.

For example:

13.0.0.2.10.1671

To deploy alternate BIG-IP versions, you are directed to use an Azure Resource Manager (ARM) template, available on the F5 Networks GitHub site.

When you use an ARM template from the F5 GitHub site to deploy a BIG-IP VE image on Microsoft Azure, the Big IP Version menu of the deployment template allows you to choose from the latest version for each major software branch.

For example:

  • 13.0.021 - 13.0.0 HF2 Build 2.10.1671
  • 12.1.24  - 12.1.2 HF1 Build 1.34.271
  • latest   - This will select the latest BIG-IP version available

Google Cloud Platform Cloud Launcher

When you launch a BIG-IP VE image from the Google Cloud Platform Cloud Launcher, they use the latest version from the most recent major software branch.

For example:

13.0.0.2.3.1671

You can also deploy BIG-IP VE images using Google Deployment Manager (GDM) templates available on the F5 Networks GitHub site.

The imageName box of the GDM template is where you specify the BIG-IP image (version) that you want to deploy.

Note: Currently, 13.0.0.2.3.1671 is the only version supported on the Google Cloud Platform.
