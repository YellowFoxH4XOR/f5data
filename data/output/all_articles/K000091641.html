K000091641: Unable to generate UCS archive

Type
Support Solution
Published
2022-10-14
Updated
2023-06-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000091641

Description

  • UCS archive generation never gets completed via BIG-IP GUI and CLI.
  • There is no error, but the task never finishes.

Environment

  • BIG-IP
  • Incomplete UCS archive
  • GUI
  • CLI

Cause

Tried generating the UCS multiple times, some processes are stuck and that's why the task never ends.

Recommended Actions

Kill the processes that are stuck in the box. Follow the below steps:
Impact of the procedure:  Performing the following procedure should not have a negative impact on your system

  1. Log in to the BIG-IP affected and run the below command from bash: 
ps aux | grep -i 'save sys ucs'
  2.  Command above will display the list of the running or stuck processes for saving a UCS file.

  3. Identify the process ID.

  4. Kill the process IDs, by running the following command: 
kill -9 XXXX
Note: Replace XXXX with the ID of the process. Run the same command for every process listed.

  5. Once finished, run again the command listed on step number 1 to make sure that those processes were removed correctly.

  6. After that, create the UCS archive either via GUI or CLI.
