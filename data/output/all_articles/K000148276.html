Description

Requests are blocked due to Evasion technique detected. You identify these as false positives and need to disable them for specific URLs.   

Environment

  • BIG-IP
  • ASM
  • Evasion technique violation

Cause

Expected behaviour. 

Recommended Actions

You can create a URL as a Microservice and disable evasion techniques by following these steps:

  1. Log in to the BIG-IP system Configuration Utility.
  2. Navigate to Security > Application Security > Security Policies > Policies List.
  3. Select the desired policy and go to HTTP Message Protection > Microservices.
  4. Click on Create and enter the Hostname and URL (either explicit or wildcard values).
  5. Select the enforcement mode, choose Policy Default to inherit the policy-defined mode.
  6. Click the arrow next to Evasion technique detected and Override the specific violation type(s) to disable.
  7. Uncheck Enable and click on Add. 

Additional Information

Microservices can only be defined for URL-type of entities.
