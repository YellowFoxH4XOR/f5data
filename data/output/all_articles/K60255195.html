Description  DNS

By navigating to the DNS top charts in the BIG-IQ centralize manager the category "Aggregated" is displayed as value in the summary of top source IPs and Domain names.

Monitoring > Dashboards > DNS > Top Charts

Environment

  • BIG-IQ Centralize Manager.
  • BIG-IP DNS managed/monitored by BIG-IQ.

Cause 

The 'Aggregated' reporting category is considered an expected behavior since it contains data elements which have been aggregated since AVR had determined that it cannot keep it long term in order to collapse down statistics effectively. This is because AVR has a limited number of database rows for storing data. When the number of database rows approaches it's limit, similar entries will be Aggregated into a single row.

When data is displayed in the chart, AVR is showing the top 10 entries according to the requested filter. It is often that when there is “Aggregated” data, it is showing up in the top 10, just because it holds data from many actual entities so the sum of its hitcount is usually high, while the explicit entities are having much less total hitcount.
