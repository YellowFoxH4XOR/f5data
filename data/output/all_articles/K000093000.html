K000093000: Determine the Partition's active System Controller from Management CLI

Type
Support Solution
Published
2022-12-06
Updated
2023-07-18
Source
https://my.f5.com/manage/s/article/K000093000

Description

You should consider using these procedures under the following condition:

  • You would like to find out what is the active System Controller for the Partition.

Environment

  • F5OS-C
  • Management CLI
  • F5OS-C Partition

Cause

None

Recommended Actions

1. From the Management CLI run the following command:
    syscon-2-active# show partitions partition
                                                                           RUNNING
                      BLADE OS    SERVICE                 PARTITION        SERVICE     STATUS
NAME              ID  VERSION     VERSION     CONTROLLER  STATUS           VERSION     AGE
-----------------------------------------------------------------------------------------------
TestPartition     2   1.5.0-8535  1.5.0-8535  1           running-active   1.5.0-8535  21d
                                              2           running-standby  1.5.0-8535  13d
default           1   1.5.0-8535  1.5.0-8535  2           running-active   1.5.0-8535  13d
                                              1           running-standby  1.5.0-8535  21d
none              0   -           -           1           disabled         -           -
                                              2           disabled         -           -
2. The above output shows that System Controller 1 is the active Controller for the Partition "TestPartition" while System Controller 2 is the active Controller for the Partition "default".
