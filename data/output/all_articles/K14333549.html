Description

BIG-IP goes offline with tmm core, similar to the below message in /var/log/tmm:

notice panic: ../dev/ndal/iq.c:620: Assertion "Descriptor is valid" failed.
notice ** SIGFPE **
 

Environment

  • BIG-IP
  • v13.1.x and above
  • KVM hypervisor
  • virtio drive in use.
     

Cause

Bug ID 1079769
 

Recommended Actions

Cause can be different from Bug ID 1079769.
If you encounter this issue, please gather qkview and the tmm core file, and raise a case to F5 Support.
