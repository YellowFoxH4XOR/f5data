Known Issue

This is the result of a known issue. When a Citrix terminal server favorite has a Java client enabled and the screen resolution is set to Full Screen, users may receive a blank page when they attempt to launch the terminal server favorite. This issue was first introduced in FirePass version 6.0.3 with cumulative hotfix HF-603-5 installed.

F5 Product Development tracked this issue as ID 317635 (formerly CR130361).

This issue was fixed in cumulative hotfix HF-610-1 issued for FirePass version 6.1.0 and in cumulative hotfix HF-70-2 for FirePass version 7.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by defining a fixed screen size that is not the full screen setting.

You can define the screen size either in the favorite settings for the individual terminal server or the terminal server Master Group settings.

Configuring a global master group setting for screen size

  1. Navigate to Application Access : Terminal Servers : Master Group Settings.
  2. Select the screen resolution you want to use from the Select initial preference for the Terminal screen resolution: drop-down menu.
  3. Optional: You can define a custom screen resolution by selecting the following options:
    • Selecting custom from the Select initial preference for the Terminal screen resolution: drop-down menu
    • Entering a width in the Width: text box
    • Entering a height in the Height: text box

Configuring screen size for a terminal server favorite

  1. Navigate to Application Access : Terminal Servers : Resources.
  2. Click the name of the terminal server favorite you want to edit.

    The favorite will expand to show the detail.
  3. Select the screen resolution you want to use from the Screen resolution: drop-down menu.
  4. Optional: You can define a custom screen resolution by selecting the following options:
    • Selecting custom from the Screen resolution: drop-down menu
    • Enter a width in the Width: text box
    • Enter a height in the Height: text box
  5. Click the Update button.
