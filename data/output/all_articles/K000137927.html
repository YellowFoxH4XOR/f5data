Description

DNS provisioned unit started keep generating core. with same RIP ID in the /var/log/tmmx logs:

 

** SIGSEGV **
...
notice RIP: 0x0000000001c2d1dd EFLAGS: 0x0000000000013282 <<<---- this RIP ID is only for 15.1.5.1 and differs version to version (different to each EngHF version).
...

 

There is no other specific message nor action made before.

 

Environment

  • BID-IP
  • v15.1.5 and later
  • DNS in use
  • TMM core
 

Cause

  • Bug ID 1106865

NOTE: The Bug Tracker says "after the gtm_add command is run" but this issue may be triggered after topology updates as well.

NOTE: This issue may affect only one blade even though there is multiple blade in use.

 

Recommended Actions

Contact F5 Support to confirm the issue with qkview and the tmm core.

We can provide EngHF for this issue.
