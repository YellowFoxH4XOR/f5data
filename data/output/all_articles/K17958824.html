K17958824: Configuration error. Webtop configuration is required error message

Type
Support Solution
Published
2020-01-13
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP APM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K17958824

Description

users are getting an error message similar to the following, when logging in to the APM:

Configuration error. Webtop configuration is required. Webtop configuration is not necessary for App Tunnel Control, or a Portal Access connection with minimal patching configured. Please contact your system administrator for assistance.

Environment

  • BIG-IP APM

Cause
a Resource Assign agent is being used in the Access Policy VPE. By design, the Resource Assign agent does not assign a webtop. It only assigns the following connectivity resources to a session:

  • Network Access
  • Portal Access
  • App Tunnel
  • Remote Destop
  • SAML

Recommended Actions

If your deployment requires that you assign one of the above-mentioned connectivity resources to a session, consider using the Advanced Resource Assign agent (instead of Resource Assign). With the Advanced Resource Assign agent, you now have the ability to assign a webtop resource directly to a session.
