K22192167: After upgrading, CLI shows Disallowed version

Type

Published
2022-05-20
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IP
Source

Description

After upgrading the software, CLI shows Disallowed version

  • The device doesn't load the config and stops traffic processing.
  • GUI also shows a message indicating that the current version is disallowed for this license.

Environment

  • BIG-IP VE
  • License reactivation before the upgrade was successful and the service check data was updated.

Cause

This happens if the license is from BIG-IP VE Version Plus license SKU. This SKUs allow perpetual usage but are limited to a certain range of BIG-IP versions.

Recommended Actions

Verify if the license is limited to certain BIG-IP versions by following the steps below.

  1. Check the license file to see if it's limited to specific versions.
    cat /config/bigip.license | grep -i "Exclusive_version"
  2. If the output of the command has a list of BIG-IP versions stated in Exclusive_version, then it can be only upgraded to those versions.
  3. If the device is upgraded to a version that is not in the list of Exclusive_version (aka, allowed version range) it will not load config and cease traffic processing.
  4. If the device needs to be upgraded to protect against CVEs, upgrade to the latest release in the allowed software version.

Additional Information

This type of license is explained in K15643: BIG-IP VE Version Plus license offerings
If a newer version of BIG-IP is required, reach out to the F5 accounts team for further options.
