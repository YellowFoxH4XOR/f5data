Known Issue

This is the result of a known issue. You can configure the Dynamic Sessions in URL setting to remove session information from the URL.

When configuring a custom Dynamic Session in URL pattern where the regular expression consists of one or more commas enclosed in parentheses, the BIG-IP ASM system generates an error message, and the pattern does not remove matched strings from the URL.

For example, if you configure a custom pattern Dynamic Session in URL containing a regular expression pattern of (?:test{2,3}), the pattern does not remove matched strings from the URL, and the following error message is logged to the /var/log/asm file after you click the Update button:

01310012:6: ASM configuration error: event code D133 Illegal RegExp (?:test{2 in table wrong regexp in dyn sess

F5 Product Development is tracking this issue as CR113787.

This issue has been fixed in Hotfix-BIGIP-9.3.1-HF5, which has been issued for BIG-IP 9.3.1, for the BIG-IP 9.3 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
