Known Issue

Requests that are originally chunked are returned unchunked to the client.

This issue occurs when all of the following conditions are met:

  • BIG-IP ASM and BIG-IP Analytics (AVR) are enabled on a virtual server with a denial-of-service (DoS) profile.
  • The pool member is sending chunked responses.

Impact

Responses from the origin web server (OWS) may be corrupted.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Browser clients receive unchunked data, which may appear as garbled ASCII text.
