Known Issue

BIG-IP configurations that contain a non-default Secure Sockets Layer (SSL) profile may fail to load after upgrading to 11.x - 12.0.0.

This issue occurs when all of the following conditions are met:

  • You upgrade from BIG-IP 10.x to 12.0.0, or attempt to load a BIG-IP 10.x user configuration set (UCS) on a BIG-IP 11.x - 12.0.0 system.
  • The BIG-IP 10.x configuration contains a non-default SSL profile with the cache-size option set to one of the following values:

    • A value greater than 262,144 if upgrading to BIG-IP 11.0.0 - 11.4.1
    • A value greater than 4,194,304 if upgrading to BIG-IP 11.5.0 - 12.0.0

Impact

The configuration fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After upgrading from BIG-IP 10.x to 11.x - 12.0.0, the configuration fails to load.
  • When you attempt to install a BIG-IP 10.x UCS file on a BIG-IP 11.x - 12.0.0 system, the configuration fails to load.
  • The Configuration utility displays an error message similar to the following example:

    The configuration has not yet loaded. If this message persists, it may indicate a configuration problem.

  • You notice an error message similar to the following example in the /var/log/ltm file:

    • If upgrading to BIG-IP 11.0.0 - 11.4.1:

      01071313:3: The requested cache size value (4294967295) is out of range for client SSL profile (/Common/my_large_cache); should be in range from 0 to 262144.

    • If upgrading to BIG-IP 11.5.0 - 12.0.0:

      01071313:3: The requested cache size value (4294967295) is out of range for client SSL profile (/Common/my_large_cache); should be in range from 0 to 4194304.

Workaround

To work around this issue, you can boot back to the BIG-IP 10.x slot and then modify the cache-size option in the non-default SSL profiles to a range that is supported on the BIG-IP version you are upgrading to. For upgrading to BIG-IP 11.0.0 through 11.4.1, values should be 262,144 or lower. For upgrading to BIG-IP 11.5.0 - 12.0.0, values should be 4,194,304 or lower.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
