Known Issue

The qkview utility may store information in the wrong format.

This issue occurs when all of the following conditions are met:

  • You create a new monitor.
  • You run the qkview utility.

Impact

Occasionally, some information stored for the new monitor is in the incorrect format.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When creating a new monitor, some information is stored in the wrong format.
