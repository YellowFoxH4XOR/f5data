Description

Your BIG-IP iSeries platform reboots unexpectedly and log messages similar to the following are logged to /var/log/sel:

00bc 02/07/21 16:04:29 INF <voltage> Power Event
00bd 02/07/21 16:04:33 INF System Reboot Type: Memory Init Reboot
00be 02/07/21 16:04:35 INF Host Reset Event

Note: <voltage> represents the measured voltage event, examples: +5V, +3.2V.

Alternatively you may see log messages similar to the following:

0024 12/31/99 16:00:25 INF Power-on Reset Event
0025 | 12/31/99 16:00:37 | INF | BMC  | Power Supply | PSU1 Status  | Input Lost 
0026 | 12/31/99 16:01:30 | INF | BMC  | Power Supply | PSU1 Status  | Input Lost 
0027 12/31/99 16:13:13 INF Host Power Cycle Even

Environment

  • iSeries

Cause
DIMM may experience unexpected changes in voltage triggering a reboot.
 

Recommended Actions

Open a support case with F5 Support and provide the following:

  1. Generate a device End-User Diagnostic report selecting the option A Run All (Non-Interactive) Tests.
  2. Generate a QKview diagnostic file.
    For more information refer to: K12878: Generating diagnostic data using the qkview utility

Additional Information
Continue to monitor device for future reoccurrence.
