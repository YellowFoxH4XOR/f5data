Description

CVE-2026-33937 is a critical Remote Code Execution (RCE) vulnerability affecting Handlebars versions 4.0.0 through 4.7.8. The issue occurs when Handlebars.compile() accepts unsanitized Abstract Syntax Tree (AST) objects, specifically allowing the "value" field of NumberLiteral nodes to contain arbitrary JavaScript code. This lack of input validation enables attackers to inject and execute malicious JavaScript, potentially compromising server security. This article describes mitigation steps using BIG-IP ASM until a dedicated signature is released.

Environment

  • Product: BIG-IP ASM / Advanced WAF
  • Application context: Web servers protected by ASM, running Handlebars (versions ≤ 4.7.8)
  • Vulnerability context: Handlebars.compile() accepting crafted AST objects

Cause

CVE-2026-33937

Answer/Recommended Actions

To mitigate CVE-2026-33937 on BIG-IP ASM until a dedicated signature is released, follow these steps:

1. Ensure that existing ASM signatures for Node.js and JavaScript code injection should be enabled to provide a more broad and generic coverage. The available signatures part of these frameworks should provide coverage for many different scenarios.

2. Strengthen security by taking following measures:

  • Enable Parse Parameters setting within JSON profile associated with the URL.
  • Enable 'Block' setting for for "Parameter value does not comply with regular expression" violation.
  • Create an explicit parameter named "value" with a positive regex match enforcing numeric-only input. A regular expression such as the following should work:

                      ^[ \t][+-]?(?:\d+(?:.\d+)?|.\d+)(?:[eE][+-]?\d+)?[ \t]$).

Note: While the parameter name "value" is always used in this vulnerability, it is quite generic and may also be present elsewhere within the application. Applying a global rule to "value" could result in false positives. For more precise protection, consider creating this as a URL-level parameter object to minimize false positives.

 

  • Save the changes with 'Apply Policy' operation.
