K60973447: Dos event logs show as ''Rate Limiting'' when mitigation action is set to ''Block All''

Type
Support Solution
Published
2021-01-28
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.0.X, 13.1.X, 13.0.X, 14.0.1, 14.0.0, 13.1.5, 13.X.X, 13.1.3, 13.1.1, 13.1.0, 13.0.1, 13.0.0, 13.1.4
Source
https://my.f5.com/manage/s/article/K60973447

Description

You observe that dos application events show the mitigation action as "Source IP-Based Rate Limiting" when the actual action is set to "Request Blocking: Block All".  

Environment

  • BIG-IP ASM
  • Local/Remote Logging Profiles

Cause

This is Bug ID 683095, which is fixed in 14.1.x.

Recommended Actions

If you are able to validate that you are affected by Bug ID 683095, please upgrade to 14.1.x or later.

None
