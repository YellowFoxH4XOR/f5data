K000132458: Understanding the Dynamic Signature status for L7 Protection Profiles

Type
Support Solution
Published
2023-02-08
Updated
2023-02-08
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.2
Source
https://my.f5.com/manage/s/article/K000132458

Description

  • When navigating to Security ›› DoS Protection : Protection Profiles in the GUI you observe a status other then Ready for Dynamic Signatures

Environment

  • ASM provisioned
  • AFM not provisioned
  • DoS profile with Behavioral DoS configured and applied to a Virtual Server

Cause

Dynamic Signatures are only generated when traffic is considered an Attack defined by the conditions in the DoS profile.

Unless a recent DoS attack has occurred that triggered Dynamic Signatures this status will remain unready.


 Recommended Actions

No Action is required.


Additional Information

You can view dynamic signatures at Security ›› DoS Protection:Signatures, click on the Dynamic box.

When the associated logging profile is configured properly you can view DoS event logs at Security ›› Event Logs ›› DoS ›› Application Events.

Note: The admd command is often used in relation to DoS and DoS attacks, the percentage score is the learning confidence, a measure of how confident the Protection Profile is in differentiating between baseline and attack traffic. A 100% confidence score does not mean that the Dynamic Signature status should be in a Ready state.
