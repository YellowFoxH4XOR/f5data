Cause

This is caused by Chromium DNS hijacking detection. This behavior is known to Chromium based browsers, MS Edge and other browsers.
Random DNS queries are generated by the browser, however since F5FltSrv.exe process forwards DNS resolution traffic, it may appear as the source of it in some network scanners, EDR equipment etc.

Recommended Actions

It is currently not possible to disable the feature.

F5 does not recommend stopping or restarting F5FltSrv.exe or any other processes individually. Use available controls on the BIG-IP Edge Client application to restart the application if needed.
