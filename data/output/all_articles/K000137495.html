K000137495: Root user cannot log in using ssh. Appliance mode has different values in the config and the running-config components.

Type
Support Solution
Published
2023-11-07
Updated
2023-11-07
Applies to
  • F5OS
  • F5OS-C: 1.3.X, 1.3.2, 1.3.1, 1.3.0
Source
https://my.f5.com/manage/s/article/K000137495

Description

While trying to log in using ssh the username and passwords are rejected.

Suspect that appliance-mode is enabled.

When running the show system appliance-mode, using the admin user, the screen shows:

system appliance-mode state enabled

you try over and over to change it to disabled, but it doesn't stick.

When committing the changes, there is no error, only this message % No modifications to commit.

When running show running-config system appliance-mode, you notice that the value is reported as disabled.

system appliance-mode state disabled


Environment

  • F5OS Configuration console
  • difference with running-config
  • Appliance-mode

Cause

Undetermined at the time of publication.

Recommended Actions

Using the admin user, toggle the appliance mode from enabled and disabled.

syscon-2-active# config

syscon-2-active (config) # system appliance-mode config enabled

syscon-2-active# commit and-quit

syscon-2-active# config

syscon-2-active (config) # system appliance-mode config disabled

syscon-2-active# commit and-quit

The value should now be the same in both configurations,

Note: You may need to wait around 5 minutes to be able to log in using the root user.
