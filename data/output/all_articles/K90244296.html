Issue

Error Message

notice mcpd[<PID>]: 0107102d:5: Cannot load master key file. Updating to a new master key.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.

For example:

notice mcpd[7880]: 0107102d:5: Cannot load master key file. Updating to a new master key.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You attempt to load the BIG-IP configuration.
  • The master encryption key used by the BIG-IP system for passphrase encryption is missing or corrupt.

Impact

You are unable to load previous configurations that contain attributes that were encrypted using the old master encryption key.

Recommended Actions

If you know the original unencrypted passphrases, you can restore a UCS archive with a new master key. For more information, refer to K9420: Installing UCS files containing encrypted passwords or passphrases.
