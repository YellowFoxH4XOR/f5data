Description
When sending a declaration that directly calls for a parent TCP profile, under /var/log/restnoded/restnoded.log, this entry shows: 

warning: [appsvcs] {"status":422,"message":"declaration is invalid","errors":["<TCP profile>: should NOT have additional properties"],"level":"warning"}

The declaration includes this line:

"parentProfile": {

"bigip":"<TCP profile>"}
 

Environment

  • AS3 Declaration
  • TCP Parent Template

Cause
Currently, TCP profile does not have parentProfile Property.

There was a design decision made that AS3 would not support parent profiles since this could cause confusion and conflicts with regard to the source of truth. When using AS3, the declaration should be the source of truth for the BIG-IP state. A parent profile represents state outside of this source of truth, and could change the state without applying a new declaration.

Recommended Actions
If you want to create multiple profiles with similar properties in AS3, F5 recommends using templating with tools like F5 Application Services Templates, Mustache, or Jinja.

Some profiles were added to AS3 before this decision was made that expose configuration of the parent profile. We do not recommend using any parent profile settings from these older profiles.

Additional Information
See the  entry "Why doesn’t AS3 support setting a parent profile in all profiles?" at: https://clouddocs.f5.com/products/extensions/f5-appsvcs-extension/latest/userguide/faq.html
