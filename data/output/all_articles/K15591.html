Known Issue

The Traffic Management Microkernel (TMM) may produce a core file if an iRule fails prior to completion.

This issue occurs when all of the following conditions are met:

  • You have an iRule associated with a virtual server.
  • The iRule experiences an error prior to completion.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system sends a SIGFPE signal to TMM, resulting in a stack trace in the /var/log/tmm log file, and a core file in the /shared/core directory.
  • The BIG-IP system fails over to another host in the device group.
