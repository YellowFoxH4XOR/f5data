Description

Running certain commands via vconsole that return large dataset in it's output can result in the following error message observed on the console and within /var/log/kern.log file:

err kernel: serial8250: too much work for irq4

Environment

  • Accessing a vCMP guest via vconsole
  • Issuing a command that fetches large output, such as "tmsh show sys license detail"
  • Observing err kernel: serial8250: too much work for irq4 error message on vconsole and subsequently within /var/log/kern.log

Cause

The observed error messages on vconsole when running commands such as tmsh show sys license detail or others that display a large output is due to a known bug at ID381023. These errors can be ignored, as there is no impact on the system.

Recommended Actions

It isn't recommended to use the console for heavy usage, where a large command output needs to be displayed.
