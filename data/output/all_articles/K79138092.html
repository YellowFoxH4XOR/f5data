Environment

  • BIG-IP
  • version 15.1.3
  • Device Service Clusters

Cause
Causes is still unknown at the time this article's publication

Recommended Actions

You may take either of below steps:

  1. Restart all of the BIG-IP services that received wrong SNI certificate.
    In Bash: 
    # bigstart restart
     
  2. If that is not working, then try rebooting the BIG-IP (standby) system
  3. If reboot does not resolves the issue, please collect QKVIEW file and tcpdump file for F5 Support to investigate further.
