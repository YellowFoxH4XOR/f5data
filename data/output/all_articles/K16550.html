Known Issue

Uninitialized fields in an OCSP or CRLPD access policy object may cause the apd process to restart.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured to use an Online Certificate Status Protocol (OCSP) Responder or CRLPD type AAA server.
  • The BIG-IP APM system encounters initialized fields within the OCSP or CRLPD module.

Impact

The BIG-IP APM system may temporarily fail to process traffic while the apd process restarts, and may fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a Traffic Management Microkernel (TMM) core file to the /shared/core directory.
  • The BIG-IP system fails over to the standby system if it is configured as part of a high-availability system.
  • The BIG-IP APM system temporarily becomes unavailable for new connections.
