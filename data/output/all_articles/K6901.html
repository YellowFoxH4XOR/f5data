Known Issue

This is the result of a known issue. Under certain conditions, the BIG-IP LTM aborts some client-side HTTP compressed data transfers just after the server response is complete. This issue may occur under the following conditions:

  • The client sends an HTTP Connection: close header
  • The compressed response size exceeds the compress buffer size in the HTTP profile

F5 Product Development tracked this issue as CR56880 and it was fixed in BIG-IP LTM version 9.1.3. For information about upgrading, refer to the BIG-IP LTM release notes.
