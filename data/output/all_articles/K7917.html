Known Issue

This is the result of a known issue. The AMD 8131 PCI-X device is a point-to-point link on the BIG-IP system board that provides high speed data transfer for chip-to-chip and board-to-board links. Under high traffic load, the AMD 8131 PCI-X device can cause the AHA compression card to intermittently lock up. As a result, TMM may crash.

When this issue occurs, you will see the following error messages logged to the /var/log/tmm file:

aha: restarting.
aha: restarting.

F5 Product Development tracked this issue as CR47138 and it was fixed in BIG-IP LTM versions 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.
