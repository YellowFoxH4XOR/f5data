Known Issue

This is the result of a known issue. When a BIG-IP LTM system under high load attempts to expire a slow server connection flow that has already been removed, the Traffic Management Microkernel (TMM) may core.

F5 Product Development tracked this issue as CR107461 and it was fixed in BIG-IP LTM 9.4.7. For information about upgrading, refer to the BIG-IP LTM Release Notes.

This issue has been fixed in BIGIP-9.6.1-839.0-HF3, which has been issued for BIG-IP 9.6.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
