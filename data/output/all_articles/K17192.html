Summary

BIG-IP Fraud Protection Service (FPS) module licenses must be reactivated after an upgrade to BIG-IP 12.0.0.

Description

After an upgrade to BIG-IP 12.0.0, you may observe that when your system loads the BIG-IP FPS configuration, the Configuration utility displays all BIG-IP FPS Anti-Fraud profiles (as well as their configured functions) with a note similar to the following example:

Note: Malware Detection is not licensed. You can only see, but not configure, this setting.

This note appears because all BIG-IP FPS module licenses are invalidated, and all previously-licensed BIG-IP FPS modules cease to process any traffic. This behavior is by design.

Recommendations

Prior to upgrading your BIG-IP FPS system to BIG-IP 12.0.0, you must contact the F5 representative in your area to request new license keys for your previously-licensed BIG-IP FPS modules. After you obtain the necessary license keys, you can proceed to upgrade to BIG-IP 12.0.0 and activate your BIG-IP FPS modules with the new license keys on the upgraded slot. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Activate the BIG-IP FPS module licenses by using the following command syntaxes, relevant to your BIG-IP FPS module licenses:

    modify sys db license.antifraud.malwaredetection value <malware detection license key>
    modify sys db license.antifraud.phishingdetection value <phishing detection license key>
    modify sys db license.antifraud.automatictransactiondetection value <automatic transaction detection license key>
    modify sys db license.antifraud.applicationencryption value <application encryption license key>
    modify sys db license.antifraud.mobilesafe value <MobileSafe license key>

    Your previously-licensed BIG-IP FPS modules should now function as expected, and you can configure their respective settings.
