Issue

Old Behavior

Prior to BIG-IP VE 11.3.0, the BIG-IP Virtual Edition (VE) architecture supported upgrading a currently running VE to a new version using a variety of hypervisor products.

New Behavior

Beginning in BIG-IP VE 11.3.0, the architecture has changed and includes features such as Clustered Multiprocessing (CMP) and higher performance NICs with lower hypervisor overhead. As a result, upgrading from BIG-IP VE 11.2.x to 11.3.x is supported on the VMware hypervisors. Upgrading to 11.3.x is not supported on other hypervisors.

F5 Product Development tracked this change as ID 391795.

Impact

Non-VMware hypervisors products no longer support upgrading BIG-IP VE from 11.2.x to 11.3.x or later versions. If you are using a non-VMware hypervisor, refer to the following Recommended Actions section.

Recommended Actions

If you are using an alternate hypervisor product, you must create a new BIG-IP VE instance, install the software version 11.3.0 (or later), and restore a user configuration set (UCS) file on the new VE. For more information, refer to the Updating a BIG-IP VE Virtual Machine section of the BIG-IP Virtual Edition Setup Guide for the appropriate hypervisor product you are using.
