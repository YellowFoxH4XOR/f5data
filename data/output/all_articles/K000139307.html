Description

The NGINX Plus subscription is about to expire, but a new NGINX Plus FCP is beginning.

Environment

  • NGINX Plus

  • Flexible Consumption Plan (FCP)

Cause

To retain active support and access the software repository for updates, for any server running NGINX Plus, the certificate and key need to be replaced with the one included in the FCP.

Recommended Actions

Download the certificate and key from the MyF5 Customer Portal and replace the existing certificate and keys on the NGINX Plus servers.

Note: This procedure doesn't impact traffic, but F5 recommends performing this work during a maintenance window.

  1. Logon to my.f5.com
  2. Open Subscriptions
  3. Click the FCP associated with NGINX
  4. Download the NGINX Plus certificate and key
  5. Follow these instructions, Installing NGINX Plus, to replace the certificate and key

Additional Information

To open support cases for these NGINX Plus servers, use the Subscription ID associated with FCP for NGINX from the MyF5 Customer Portal.
