K11674: The Application or Network tunnel webtop session may expire without a warning message

Topic

When opening an Application or Network tunnel through the webtop and subsequently closing the main webtop session while leaving the tunnel status window open, FirePass does not display a warning when the session times out. When the session times out and you attempt to pass network traffic through the connection, you receive the following error message:

404
Error:FirePass server could not handle the request
Reason:Invalid session id

At this point you are prompted with the option to continue or quit:

  • Clicking the Continue button repeats the error message, and the tunnel status window remains open.
  • Clicking the Abort button closes the tunnel status window and terminates the network connection.

In addition, attempting to establish a new webtop session without closing the current tunnel status window results in the following error message:

WARNING! The local TCP port number used by the App Tunnel adapter for the application you are trying to connect to has changed due to the conflicts with another application on your local system, that uses the same port. To continue, do one of these things:
temporarily shut down the conflicting program, and then restart the App Tunnel
reconfigure the App Tunnels client application to connect to the alternate port shown
reconfigure the conflicting application to use a different TCP port

Note: Network traffic passing through the tunnel connection keeps the tunnel active. The tunnel does not time out until no network traffic has passed through the connection for the timeout period.
