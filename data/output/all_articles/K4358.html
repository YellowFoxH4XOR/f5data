Known Issue

This is the result of a known issue. The only supported media negotiation setting for the management port interface is auto-negotiate. Any switch port to which the management port is connected should also be configured for auto-negotiation.

The bigpipe interface mgmt media 100baseTX full command should force the speed and duplex settings on the management interface. However, the interface continues to behave as though it is set to auto-negotiate.

This issue only affects the following hardware platforms:

1500 (C36)
3400 (C62)
3410 (C100)
4100 (D46)
6400 (D63)
6800 (D68)
8400 (D84)
8800 (D88)

F5 Product Development tracked this issue as CR46765 and it was fixed in BIG-IP 9.2.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Note: For information about a similar issue affecting versions 9.4.5 and 9.4.6, refer to K9150: The interface media setting is lost upon a system reboot or an mcpd process restart.
