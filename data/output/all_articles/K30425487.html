K30425487: Unable to sync devices. Getting ''Not all devices synced'' message

Type
Support Solution
Published
2021-12-27
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K30425487

Description

BIG-IP devices repeatedly show "Not all devices synced".

  • Unable to sync configuration.
  • In CLI can intermittently see "peer time out of sync".
  • "Not all devices synced" shown in GUI.

Environment

  • BIG-IP LTM with HA configured.
  • NTP server is configured and BIG-IP is communicating with the NTP servers.

Cause

This can happen if one of the NTP server is giving incorrect time to the BIG-IP intermittently.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Make sure the BIG-IP can access the NTP server. Command to check is below:
    ntpq -np
  2. After checking the output, remove the first NTP server from the list on all peer devices and then perform a time sync on all peers. Command below:
    ntpd -q
  3. Once they are in sync, perform a config sync.
  4. If a normal sync doesn't work, perform a force sync. Refer K63470472 for steps to perform force sync via CLI.
