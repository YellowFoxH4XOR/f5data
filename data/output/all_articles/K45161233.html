Description

What is the difference between outbound-smtp and smtp-server in bigip_base.conf?

sys outbound-smtp {
    from-line-override disabled
    mailhub 192.168.1.50:25
}

sys smtp-server /Common/smtp_ltm {
    from-address f5.smtp@ltm1.com
    local-host-name f5.ltm1.com
    smtp-server-host-name smtp.ltm1.com
}

Environment

  • SMTP

Cause

None

Recommended Actions

smtp-server is used by the AVR, ASM and APM modules to deliver generated reports and is configurable in the GUI under System >> Configuration >> Device >> SMTP.

outbound-smtp mailhub is used by the system's ssmtp utility to deliver locally generated emails such as for custom alerts, and can only be configured using tmsh with the modify sys outbound-smtp mailhub command.

Additional Information

Refer to the following article for more information about configuring the system to deliver locally generated email messages:

  • K13180: Configuring the BIG-IP system to deliver locally generated email messages (11.x - 15.x)
