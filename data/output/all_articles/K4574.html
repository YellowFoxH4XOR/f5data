K4574: BIG-IP and 3-DNS do not prevent installation on platforms that are no longer supported

Type
Known Issue
Published
2010-03-01
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • 3-DNS: 4.6.4
  • BIG-IP 4.X: 4.6.4
Source
https://my.f5.com/manage/s/article/K4574

Known Issue

BIG-IP and 3-DNS do not check the platform type during the upgrade installation process. As a result, it is possible to install new versions of software on unsupported older platforms.

Before you install a BIG-IP or 3-DNS upgrade, read the Release Notes to verify that your platform is supported for the new software version.
