Description

You are unable to import software image into BIG-IP. SCP is blocked in your environment so image file cannot be transferred through any file transfer application eg. WinSCP. 

The connection to BIG-IP gets lost after clicking the "import" button under:
Software Management > Image list.

Environment

  • BIG-IP
  • BIG-IQ

Cause

None

Recommended Actions

If your BIG-IP is managed by BIG-IQ, as an alternative solution you can copy the ISO image from the BIG-IQ to BIG-IP and you will able to see the software image in your BIG-IP device. So, you will need to first import the ISO image to your BIG-IQ and then copy the image to managed BIG-IP device.

  1. To import ISO in BIG-IQ, go to Devices > SOFTWARE MANAGEMENT > Software Images. Click on Upload, and upload the software image.
  2. Once the ISO image is uploaded go to SOFTWARE MANAGEMENT > Software Installations. Click the Managed Device Install.

Only check box "Pause after the software image has been copied to devices ". So that only software image is being copied and nothing else. Run the task. Once completed you should see the software image in the BIG-IP GUI and CLI (/shared/images).
