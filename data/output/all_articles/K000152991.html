K000152991: Media type of data interface on tenant doesn't match rSeries 2k/4k

Type
Support Solution
Published
2025-08-13
Updated
2025-08-13
Source
https://my.f5.com/manage/s/article/K000152991

Description

The article talks about a difference in displaying media type of data interface between rSeries 2k/4k and tenant. For example:

On F5OS, the media type of interface 6.0 is reported as 10GBASE-SR:

R4600-R85-S9# show portgroups portgroup 6
portgroups portgroup 6
state vendor-name "F5 NETWORKS INC."
state vendor-oui 009065
state vendor-partnum "OPT-0016 "
state vendor-revision A0
state vendor-serialnum "ATK0DR6 "
state media 10GBASE-SR
state optic-state QUALIFIED

On tenant, interface 1.6 media type is reported as 10000T-FD:

root@(localhost)(cfg-sync Standalone)(REACTIVATE LICENSE)(/Common)(tmos)# show net interface 1.6
-----------------------------------------------------------------
Net::Interface
Name Status Bits Bits Pkts Pkts Drops Errs Media
In Out In Out
-----------------------------------------------------------------
1.6 up 749.5M 10.3K 999.6K 15 0 0 10000T-FD


Under a list of available values for 'media' parameter, you can find 10000SR-FD there:

root@(localhost)(cfg-sync Standalone)(REACTIVATE LICENSE)(/Common)(tmos)# modify net interface 1.6 media 10000
Values:
100000-FD 100000AR4-FD 100000CR4-FD 100000LR4-FD 100000SR4-FD 10000ER-FD 10000LR-FD 10000SFPCU-FD 10000SR-FD 10000T-FD

Environment

- r2k/r4k
- F5OS interface media type 10GBASE-SR while on tenant it's 10000T-FD

Cause

This is cosmetic. ID2014429 is to track the change.

Recommended Actions

Cosmetic issue, no impact.

Additional Information

None.
