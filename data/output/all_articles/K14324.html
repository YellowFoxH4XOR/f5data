Topic

This article applies to BIG-IP 11.x -12.x. For information about other versions, refer to the following article:

  • K11431: Using F5 vendor-specific attributes with RADIUS authentication (10.x)

You should consider using this procedure under the following condition:

  • You want to use F5 vendor-specific attributes (VSA) when configuring remote RADIUS authentication.

Description

BIG-IP supports F5 VSAs for use with RADIUS authentication. To use these attributes, you must perform the following three procedures:

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You must configure the BIG-IP system to use remote RADIUS authentication. For information about configuring remote user authentication, refer to the BIG-IP TMOS: Implementations manual.

    Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

  • You must have administrative access to your BIG-IP system.
  • You must have administrative access to the RADIUS server.

Procedures

  • Adding the F5 dictionary file to the RADIUS server
  • Configuring user accounts on the RADIUS server
  • Configuring the remote role group on the BIG-IP system

Configuring user accounts on the RADIUS server

On the RADIUS server, configure the user accounts that will have access to the BIG-IP system.

Impact of procedure: The following procedure should not have a negative impact on your system.

The following example was taken from a server running FreeRADIUS:

Note: The following configuration is an example. Configurations should be customized for the appropriate environment.

jsmith Cleartext-Password := "test" Service-Type = Framed-User, Framed-Protocol = PPP, Framed-Routing = Broadcast-Listen, Framed-Filter-Id = "std.ppp", Framed-MTU = 1500, Framed-Compression = Van-Jacobsen-TCP-IP, F5-LTM-User-Role = 100, F5-LTM-User-Info-1 = mgmt, F5-LTM-User-Partition = Common, F5-LTM-User-Shell = tmsh

Important: The F5-LTM-User-Role attribute must be set to one of the integers defined in the RADIUS dictionary file. For example, use the value 0 for administrator and the value 400 for operator.

Ensure that the RADIUS server is returning the attributes correctly.

For example, the previous configuration was verified by running the radtest command on the RADIUS server:

Configuring the remote role group on the BIG-IP system

On the BIG-IP system, configure a remote role group to use the attributes provided by the RADIUS server using one of the following procedures:

Impact of procedure: The following procedure should not have a negative impact on your system.

TMOS Shell

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To create a new remote role group, use the following tmsh syntax:

    modify auth remote-role role-info add { <group-name> { attribute <attribute-string> console <terminal-access> line-order <number> role <role-name> user-partition <partition-name-string> }

    For a detailed description of the remote-role tmsh command, refer to the Traffic Management Shell (tmsh) Reference Guide.

    Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

    For example, to create a new remote role group named mgmt_group with an F5 attribute of F5-LTM-User-Info-1=mgmt that uses F5-specific variables provided by the RADIUS server to assign console, role, and user partition permissions, you would enter the following command:

    modify auth remote-role role-info add { mgmt_group { attribute "F5-LTM-User-Info-1=mgmt" console %F5-LTM-User-Shell line-order 1001 role %F5-LTM-User-Role user-partition %F5-LTM-User-Partition } }

  3. Save the configuration by typing the following command:

    save sys config

  4. To exit tmsh, type quit and press Enter.

Configuration utility

Impact of procedure: The following procedure should not have a negative impact on your system.

Note: The examples used in this procedure create the same remote role group as the tmsh procedure above.

  1. Log in to the Configuration utility.
  2. Navigate to System > Users > Remote Role Groups.
  3. Click Create.
  4. For Group Name, type the name you want for the remote role group. For example: mgmt_group.
  5. For Line Order, type the line number you want. For example: 1001.
  6. For Attribute String, type the F5 attribute you want. For example: F5-LTM-User-Info-1=mgmt.
  7. For Assigned Role, click Other.
  8. For Assigned Role, type the role F5 variable you want. For example: %F5-LTM-User-Role.
  9. For Partition Access, click Other.
  10. For Partition Access, type the partition F5 variable you want. For example: %F5-LTM-User-Partition.
  11. For Terminal Access, click  Other and type the terminal access F5 variable you want. For example: %F5-LTM-User-Shell.
  12. Click Finished.

RADIUS Authentication example

The following example from a packet capture shows a RADIUS protocol decode of a successful Access-Accept response to a Access-Request transmission for the example user jsmith. The vendor-specific attributes are shown in bold and the decimal representations of the on-the-wire data are in parentheses. The RADIUS dictionary file defines attributes such as F5-LTM-User-Role as 1 and F5-LTM-User-Info-1 as 12 and it defines the acceptable format for values such as an integer of 100 for F5-LTM-User-Role or an ASCII string, such as mgmt for F5-LTM-User-Info-1.

The following configuration stanza shows the remote role group configuration that results from the examples shown earlier in this section:

auth remote-role {
    role-info {
        mgmt_group {
            attribute F5-LTM-User-Info-1=mgmt
            console %F5-LTM-User-Shell
            line-order 1001
            role %F5-LTM-User-Role
            user-partition %F5-LTM-User-Partition
        }
    }
}

Based on the Access-Accept response and the remote role configuration, you would assign the user jsmith the following access to the BIG-IP system:

  • The remote role group mgmt_group, since the value mgmt is returned for the attribute F5-LTM-User-Info-1.
  • tmsh, since the value tmsh is returned for the attribute F5-LTM-User-Shell.
  • The role of Manager, since the value 100 is returned for the attribute F5-LTM-User-Role.
  • The Common partition, since the value Common is returned for the attribute F5-LTM-User-Partition.
