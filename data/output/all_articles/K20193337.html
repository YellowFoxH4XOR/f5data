Cause
This error can occur if a "passphrase" is defined in the AS3 declaration, but the "privateKey" is not encrypted.

e.g.
                "webcert1": {
                    "class": "Certificate",
                    "remark": "replace these with real certificates and keys",
                    "certificate": "-----BEGIN CERTIFICATE-----

                                        <certificate>

                                        -----END CERTIFICATE-----",
                    "chainCA": "-----BEGIN CERTIFICATE-----

                                       <chainCA>

                                       -----END CERTIFICATE-----",
                    "privateKey": "-----BEGIN PRIVATE KEY-----

                                         <unencrypted privateKey>

                                         -----END PRIVATE KEY-----",
                    "passphrase": {
                        "ciphertext": "ZjVmNQ==",
                        "protected": "eyJhbGciOiJkaXIiLCJlbmMiOiJub25lIn0"
                    }
                   
Recommended Actions
Remove the "passphrase" definition in the AS3 declaration if using an unencrypted privateKey.
