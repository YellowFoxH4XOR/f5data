K01551143: Disable Certificate expired alert on GUI

Type
Support Solution
Published
2022-12-27
Updated
2024-11-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.0
Source
https://my.f5.com/manage/s/article/K01551143

Description

With BIG-IP version 15.1 onwards, If your BIG-IP device is using an expired certificate, you will now see a warning banner in the GUI.
 

Environment

BIG-IP version 15.1
Expired certificate is still in use.
 

Cause

This is a result of change in Bug ID 707276


Recommended Actions

In case you would like to disable this warning, you can run below command :

tmsh modify sys global-settings gui-expired-cert-alert disabled

To enable the warning back , run below command:
tmsh modify sys global-settings gui-expired-cert-alert enabled

To check the current setting , use below command:
tmsh list sys global-settings gui-expired-cert-alert 

Example:
[root@bipip:Active:Standalone] config # tmsh list sys global-settings gui-expired-cert-alert
sys global-settings {
    gui-expired-cert-alert enabled
}
[root@bigip:Active:Standalone] config #
