Description

 

  • Syslog server's IP:Port is removed from remote syslog servers settings, but still there might be some active tcp/udp connections from BIG-IP to the removed syslog server(s).
  • Below logs are noted in the /var/log/ltm or /var/log/messages.

       <DATE & TIME> <HOSTNMAE> notice syslog-ng[3222]: Syslog connection                established; fd='60',server='AF_INET(10.10.10.10:52345)',                        local='AF_INET(0.0.0.0:0)'

  • Checking the "netstat" command output shows something like sample, below:

            # netstat -an | grep 52345 

        udp 0 0 10.10.10.10:42254 <Syslog-Server- IP>:52345 ESTABLISHED
 

  • Based on K53851362  to remove the unwanted active connections from BIG-IP to the removed syslog servers, but still connections appear again automatically, after a while:

         # tmsh delete /sys connection cs-client-addr <BIG-IP-Source-IP> cs-server-addr 10.10.10.10 cs-server-port 52345
 

 

Environment

  • BIG-IP LTM
  • Remote syslog servers

 

Cause

The "syslog-ng" service still trying to establish connections to the removed syslog servers. So, It needs to be restarted after applying the changes to the server list. 

 

Recommended Actions

Restart the "syslog-ng" service to terminate all the unwanted connections. After restarting this service, only the correct connections will be established, based on the current configured syslog servers. 

Impact: Running the command below should not have any negative impact on your traffic. 
 

# bigstart restart syslog-ng
