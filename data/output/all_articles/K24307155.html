Known Issue

The SafeNet HSM installation script fails if the HSM partition password contains special characters (! # { } ').

This issue occurs when all of the following conditions are met:

  • You use the nethsm-safenet-install.sh script to install the SafeNet HSM client software.
  • The SafeNet HSM partition password includes special characters (! # { } ').

Impact

The SafeNet HSM software is not installed or configured on the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The SafeNet HSM installation script fails with a syntax error similar to the following example:

    ...
    Verifying the HSM connection ...
    Please enter the HSM partition password: *****************
    Opening the session with the SafeNet HSM partition ...
    Successfully set SafeNet HSM for use with 'fipskey.nethsm'.
    Registering SafeNet HSM in the BIG-IP config ...

    ***** Syntax Error: command history is only available in shell mode *****
    ERROR: Unable to set SafeNet as the external-hsm on BIG-IP.

Workaround

To work around this issue, you should ensure that the SafeNet HSM partition password includes no special characters (! # { } '). For information about changing the SafeNet HSM partition password, refer to K16350062: Changing the SafeNet HSM partition password.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
