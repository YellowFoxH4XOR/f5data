Description

  • How Notify works with Secondary DNS 

Environment

  • F5® Distributed Cloud DNS (XC DNS) Secondary Zones
  • Zone Transfers
  • DNS Notify

Answer

DNS Notify is a mechanism for a Primary DNS nameserver to inform secondaries that a zone update is available.

When an XC Secondary Zone entity receives a dns-notify request from a configured Primary, an acknowledgement response is immediately returned confirming receipt of the notify message.  Subsequently, F5's DNS system initiates a zone transfer (AXFR) that updates records of the DNS Secondary Zone.  This is an asynchronous asynchronous process; the returned acknowledgement does not indicate completion of the zone transfer process, rather that the update process has commenced.

The final result of the dns-notify process is an update via AXFR for all records in F5's DNS system pertaining to the zone name provided in the request. F5's DNS system will not send any external notifications that the zone update process has completed. The best way to verify successful completion of the zone transfer is to query F5 nameservers (ns1.f5clouddns.com, ns2.f5clouddns.com) for a zone record just added in the external primary nameserver.  For instance:

dig @ns1.f5clouddns.com newrecord.example.com

In typical operational conditions, the entire process should take less than 5 seconds after F5 DNS's initial receipt of the dns-notify request.
