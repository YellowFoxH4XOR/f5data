K000092601: Condition for flushing the netty write queue

Type
Support Solution
Published
2022-11-26
Updated
2022-11-26
Source
https://my.f5.com/manage/s/article/K000092601

Description

  • When the overall number of bytes in netty socket write queue/buffer exceeds a predefined limit (1048576) OR a single message in the queue is stuck for longer than 50 ms, then the FEP discards all messages in the queue. This is being triggered in the netty level.
  • The limit (1048576) and delay (50 ms) are set via variables in the java class.

Environment

  • SDC 5.1

Cause

By design.

 Recommended Actions

None.

Additional Information

Upon testing in the F5 labs flush of the buffer occurs when message is stuck longer than the timeout defined. The buffer does not need to reach full buffer size to trigger a flush.
