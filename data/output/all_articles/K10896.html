K10896: The Japanese and Traditional Chinese versions of the FirePass online help list the wrong default value for Txqueuelen

Topic

In the Japanese and Traditional Chinese versions of the FirePass online help, the Device Management : Configuration : Network Configuration : Interfaces page incorrectly states that the default value of the Txqueuelen configuration option is 100. The actual default value of the Txqueuelen option is 1000.
