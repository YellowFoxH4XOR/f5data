Known Issue

The Trusted Platform Module (TPM) system integrity check may return an invalid status.

This issue occurs when all of the following conditions are met:

  • You upgrade a system running either BIG-IP 11.x, 12.x, or 13.0.x (including their point releases) to BIG-IP 14.1.0.
  • You then perform an initial boot into the upgraded BIG-IP 14.1.0 slot.

Impact

The BIG-IP system reports an invalid TPM status upon the first boot of the upgraded BIG-IP 14.1.0 slot.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • While the system boots to BIG-IP 14.1.0 for the first time, you observe an error message that appears similar to the following example:

    tpm-status-check[5380]: System Integrity Status: Invalid

Resolution

Workaround

To work around this issue, you can perform another reboot to the BIG-IP 14.1.0 volume after the system has completed booting to the BIG-IP 14.1.0 for the first time. To do so, perform the following procedure:

Impact of workaround: The system will not be available while performing another reboot. F5 recommends that you perform this procedure during an appropriate maintenance window.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Determine the volume of the recently installed BIG-IP 14.1.0 slot by typing the following command:

    show sys software

    The command output appears similar to the following example:

    ----------------------------------------------------
    Sys::Software Status
    Volume  Product   Version    Build  Active    Status
    ----------------------------------------------------
    HD1.1    BIG-IP  12.1.3.5   0.0.10     yes  complete
    HD1.2    BIG-IP    14.1.0  0.0.116      no  complete
    HD1.3      none      none     none      no  complete

  3. Reboot the system using the following command syntax:

    reboot volume <volume of BIG-IP 14.1.0>

    For example, if the BIG-IP 14.1.0 resides in HD1.2 on your system, type the following command:

    reboot volume HD1.2

  4. Wait for the system to complete rebooting. The BIG-IP system should now report a valid TPM system integrity status.
