K29239022: Reusing a BIG-IQ license on a different BIG-IQ system

Type
Support Solution
Published
2021-08-27
Updated
2025-04-01
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K29239022

Description
You want to revoke an existing BIG-IQ Virtual Edition (VE) license and re-assign the license to a different BIG-IQ VE system.

Environment

  • BIG-IQ Virtual Edition

Cause
None.

Recommended Actions

Contact F5 Technical Support and request for Allow-Move.

Note: After the Allow-Move process, please wait fifteen (15) minutes before attempting to activate the license again. 
 
Activate the license using the manual activation method
Impact of procedure: Performing the following procedure should not have a negative impact on your system.
  1. Log in to the BIG-IQ system as Administrator.
  2. If you connect to the user interface and your BIG-IQ system is not licensed yet, you are prompted to license the system.
In the Base Registration Key box, enter the base registration key.
  1. In the Add-On Registration Key List box, certain systems may require you to enter add-on registration keys for additional modules.
  2. Select Manual.
  3. Select Get Dossier.
  4. Copy the dossier and connect to the F5 Product Licensing page at the following address: https://secure.f5.com
  1. On the F5 Product Licensing page, in the row that lists BIG-IQ, select Activate License.
  2. Paste the dossier into the Enter your dossier box and select Next.
  3. Copy the license returned by the F5 Product Licensing page and paste it into the License box in the BIG-IQ system.
  4. Select Activate License.
For BIG-IQ 5.0.0 and later, if the license contains both BIG-IQ Central Management and Logging Node features, the system opens the License Feature Selection menu; select your required feature and select OK.
Note: If your license contains both Central Management and Logging Node features, the BIG-IQ system will require you to choose one of those features when you select Next. To change this selection after you have completed the BIG-IQ system setup, refer to K15886: Restoring the BIG-IQ system to factory default settings.

Additional Information
