Known Issue

A Client SSL profile that defaults from wom-default-clientssl or clientssl-insecure-compatible in a BIG-IP configuration may cause a BIG-IP system upgrade or user configuration set (UCS) load to fail.

This issue occurs when any of the following conditions are met:

  • You attempt to upgrade a BIG-IP system to 11.5.0 or 11.5.1 from an earlier version, with a configuration that has a Client SSL profile that defaults from wom-default-clientssl or clientssl-insecure-compatible.
  • You attempt to load a BIG-IP 11.4.1 or earlier UCS file with a configuration that has a Client SSL profile that defaults from wom-default-clientssl or clientssl-insecure-compatible, on BIG-IP 11.5.0 or 11.5.1.

This issue occurs because the /Common/wom-default-clientssl and /Common/clientssl-insecure-compatible profiles are not properly defined in an upgrade conversion script on the affected versions. When the upgrade script attempts to process a configuration that contains a Client SSL profile that defaults from either profile, the upgrade will enter an infinite recursion loop looking for the missing profile definitions, and the upgrade or UCS load will fail.

Impact

The BIG-IP system upgrade or UCS load fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your attempts to upgrade the BIG-IP system or load a UCS fail.
  • After loading a UCS file or upgrading from a configuration with a Client SSL profile that defaults from wom-default-clientssl or clientssl-insecure-compatible on BIG-IP 11.5.0 or 11.5.1, the Configuration utility displays an error message similar to the following example:

    "UCS application failed; unknown cause."

Workaround

To work around this issue, you can boot back to the previous BIG-IP 11.4.1 or earlier version and modify the affected Client SSL profiles to default from the clientssl profile before upgrading or saving a UCS file.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
