Known Issue

This is the result of a known issue. The Configuration utility CPU graph may incorrectly indicate 100 percent CPU utilization, or higher than normal CPU utilization on BIG-IP ASM systems.

Note: On BIG-IP ASM supported platforms, the Linux kernel schedules the BIG-IP ASM  bd process and other Linux-based processes using the lower-numbered CPU. Therefore, the CPU0 graph indicates the BIG-IP ASM CPU utilization. For more information about BIG-IP ASM CPU utilization, refer to K8191: Overview of the CPU Utilization performance graphs on BIG-IP ASM.

F5 Product Development is tracking this issue as ID 283322 (formerly CR97855).
