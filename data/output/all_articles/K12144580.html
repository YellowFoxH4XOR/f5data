Known Issue

Network Access Client Proxy Settings selection may not be honored after multiple reconnections.

This issue occurs when all of the following conditions are met:

  • In the network access resource configuration, the Client Proxy Settings check box is selected.
  • When using network access through BIG-IP Edge Client, you connect and disconnect several times (approximately 10 times).

Impact

Client traffic does not honor proxy settings.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The built-in PAC file server in BIG-IP Edge Client does not start, resulting in the proxy settings not being honored.
  • Client traffic does not honor proxy settings.

Workaround

To work around this issue, you can restart BIG-IP Edge Client.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
