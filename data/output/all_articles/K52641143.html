Description

F5 products have a lot of built-in sets of features that help to detect and prevent several types of DOS, Credential Stuffing, Brute Force .. etc attacks. the recommendation in this article is useful when it's desired to throttle requests to a specific URI based on the number of transactions per custom detection period time by using an iRule.

Environment

  • BIG-IP
  • A virtual server with an HTTP profile.

Cause

To mitigate an ongoing attack until a long term solution using one of the built-in features is configured/tuned based on the application in question needs.

Recommended Actions

Note. Update below iRule to the target URI in question, and tune the lockout parameters as well as block response page content.

when RULE_INIT {
        # to set lockout period to a static value, make min_lockout and max_lockout the same.
        set static::min_lockout 60
        set static::max_lockout 18000
        set static::attempts_per_period 5
        set static::logging 1
        set static::state_table "bruteforce-exp-backoff-state"
}
when HTTP_REQUEST {
        set session_id [IP::client_addr]

        if { [class match $session_id equals private_net] } {
           return
        }
        if { ([HTTP::method] eq "POST" || [HTTP::method] eq "GET") && [HTTP::uri] contains "SignIn"} {
                set prev_attempts [table lookup -subtable $static::state_table $session_id]
                if { $prev_attempts eq "" } { set prev_attempts 0 }
                if { $static::min_lockout eq $static::max_lockout} {
                  set new_lockout $static::min_lockout
                } else {
                  set new_lockout [expr {1 << ($prev_attempts - 1)}]
                  if { $new_lockout > $static::max_lockout } {
                    set new_lockout $static::max_lockout
                  } elseif { $new_lockout < $static::min_lockout } {
                    set new_lockout $static::min_lockout
                  }
                }
                table incr -subtable $static::state_table $session_id
                table timeout -subtable $static::state_table $session_id $new_lockout
                if { $static::logging > 0 } {
                log local0. "POST request (#[expr {$prev_attempts + 1}]) from $session_id received during lockout period, updating lockout to ${new_lockout} sec"
                }
                if { $prev_attempts > $static::attempts_per_period } {
                  set response "<html><head><title></title></head><body><center><h1>SESSION ERROR</h1>"
                  HTTP::respond 200 content $response
                  if { $static::logging > 0 } {
                  log local0. "IP $session_id is BLOCKED with $prev_attempts attempts and will be blocked for $new_lockout seconds"
                  }
                }
        }
}
