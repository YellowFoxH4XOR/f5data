Known Issue

Deleting objects using a Traffic Management Shell (tmsh) batch mode transaction may fail.

This issue occurs when the following condition is met:

  • You attempt to delete a pool member and the corresponding node using a tmsh batch mode transaction.

Impact

The transaction fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tmsh transaction displays an error message similar to the following example:

    01070110:3: Node address '/<partition>/<ip address>' is referenced by a member of pool '/<partition>/<pool name>'.

Resolution

Workaround

To work around this issue, you can accomplish this task by performing two separate transactions--first delete the pool, then delete the corresponding node.
