Description

On non-primary clustered blades in a BIG-IP chassis environment, stpd may repeatedly log "hal sendMessage failed" in /var/log/ltm: 
root@bigipa:/S2-green-P:Active:Standalone] config # tail -f /var/log/ltm
Feb 16 00:26:40 slot1/bigipa err stpd[19630]: 01280015:3: HAL sendMessage failed
Feb 16 00:26:40 slot3/bigipa err stpd[22450]: 01280015:3: HAL sendMessage failed
Feb 16 00:26:40 slot3/bigipa err stpd[22450]: 01280015:3: HAL sendMessage failed
Feb 16 00:26:40 slot3/bigipa err stpd[22450]: 01280015:3: HAL sendMessage failed
Feb 16 00:26:42 slot1/bigipa err stpd[19630]: 01280015:3: HAL sendMessage failed
...

Environment

  • VIPRION platforms
  • BIG-IP version 11.x, 12.x
  • Two or more blades clustered in a chassis with STP enabled on one or more ports.

Cause

Bug ID 713947: stpd repeatedly logs "hal sendMessage failed"

Recommended Actions

There are no workaround except to ignore log messages, and it has no ill effect on the system besides log spam.
You can upgrade to a version where ID 713947 is fixed.  

Additional Information

None.
