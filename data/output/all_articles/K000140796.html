Description

When trying to renew/replace the BIG-IP device certificate with their internal CA signed certificate and key prompted with error "Import Failed: Key management library returned bad status: -99,Key is password protected." as per screenshot example attached below.

Figure: Device Certificate Import Failed Error Message 

 

Environment

  • BIG-IP
  • Device Certificate Renew/Replacement
  • CA signed certificate
  • CA key RSA encrypted
  • WebUI or Configuration Utility
  • CLI

Cause

The CA key were password protected "key content similar as below"

-----BEGIN RSA PRIVATE KEY-----
Proc-Type: 4,ENCRYPTED
DEK-Info: AES-256-CBC,FFF9C7C95FC92ECB86E7575516CE641F

GC7/9UR...
-----END RSA PRIVATE KEY-----

Recommended Actions

1. Decrypt the CA key which has RSA protected with below OpenSSL command and enter the pass phrase when prompted

openssl rsa -in "rsa_ecrypted_key" -out rsa_decrypted.key
Enter pass phrase for server_rsa_ecrypted_key: *****

2. Then, may proceed to import the CA signed certificate with rsa_decrypted.key file "decrypted key content similar as below"
-----BEGIN RSA PRIVATE KEY-----
MIIEog....
-----END RSA PRIVATE KEY-----
