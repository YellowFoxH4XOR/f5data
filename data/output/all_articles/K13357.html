Known Issue

The persist uie iRules command may reset connections with an incorrect reset cause.

This issue occurs when the following condition is met:

  • An iRule calls the persist uie command with an empty string

For example, in the following iRule, an empty string is passed to persist uie, which will cause this issue to occur:

when HTTP_REQUEST {
persist uie ""
}

Impact

Affected virtual servers will close connections with a TCP reset.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Affected virtual servers will close connections with a TCP reset cause of Unknown Reason and logs an error message.
  • If TCP RST logging is enabled, the reset will cause the system to write error messages to the /var/log/ltm file that appear similar to the following example:

    01230140:3: RST sent from 10.11.20.20:80 to 10.11.20.187:43610, Unknown reason
