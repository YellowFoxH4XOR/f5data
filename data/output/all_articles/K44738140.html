Known Issue

The merged process may produce a core file and restart due to a timing issue in which the process may fail processing a table row with incomplete keys defined.

This issue occurs when the following condition is met:

  • The merged process attempts to process incomplete or missing data.

    Note: This issue may be more prevalent on vCMP hosts.

Impact

There is a gap of several seconds in available statistics during the time when the system produces a core file and the merged process automatically restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The merged process produces a core file in the /var/core directory.
  • You notice errors similar to the following in the /var/log/ltm log file:

    Dec 30 18:21:31 slot1/HOSTNAME notice logger: Started writing core file: /var/core/merged.bld2.0.276.core.gz for PID 7024
    Dec 30 18:21:32 slot1/HOSTNAME notice logger: Finished writing 8474648 bytes for core file: /var/core/merged.bld2.0.276.core.gz for PID 7024
