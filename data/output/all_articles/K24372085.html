    01071488:3: Remote transaction for device group /Common/DG_NAME to commit id 6731 7030922323602857589 /Common/DG_NAME.com 0 failed with error
    01070726:3: ClientSSL CertKeyChain Entry /PARTITION_A/RSA_CERTname.com-2021-10-20_SectigoRSAExtendedValidationSecureServerCA-2020 in partition Common cannot reference Certificate File /PARTITION_A/RSA_CERTname.crt in partition PARTITION_A.

Environment

  • Profile modify by tmsh commands

Cause

Bug ID 890321

Recommended Actions

Use the GUI to modify SSL profiles in this manner.
