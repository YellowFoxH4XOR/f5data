Description

You should consider using these procedures under the following condition: 

  • You would like to clean install the system controller in your VELOS chassis using the internal PXE server.

Environment

  • F5OS-C
  • Clean install
  • System Controller
  • VELOS
  • PXE

Cause

None 

Recommended Actions

1. SSH to the system controller you want to do the clean install, under bash enter efibootmgr:

[root@controller-1 ~]# efibootmgr
BootCurrent: 0003
Timeout: 3 seconds
BootOrder: 0003,0002,0004,0001
Boot0001* UEFI: PXE IP4 Broadcom NetXtreme Gigabit Ethernet (BCM5720)   # <--- Note
Boot0002* UEFI: KingstonDataTraveler 3.0PMAP
Boot0003* UEFI: SAMSUNG MZ1L2960HCJR-00A07, Partition 1
Boot0004* UEFI: KingstonDataTraveler 3.0PMAP, Partition 2

2. Determine the boot index of the internal network NIC, discarding the leading zeros and select it as the first boot device, enter efibootmgr --bootnext 1:

[root@controller-1 ~]# efibootmgr --bootnext 1
BootNext: 0001                                                          # <--- Note
BootCurrent: 0003
Timeout: 3 seconds
BootOrder: 0003,0002,0004,0001
Boot0001* UEFI: PXE IP4 Broadcom NetXtreme Gigabit Ethernet (BCM5720)
Boot0002* UEFI: KingstonDataTraveler 3.0PMAP
Boot0003* UEFI: SAMSUNG MZ1L2960HCJR-00A07, Partition 1
Boot0004* UEFI: KingstonDataTraveler 3.0PMAP, Partition 2

3. Proceed to reboot the system controller, enter reboot:
Note: You will lose connection to the controller on reboot. Open a second SSH session to the other system controller to view the progress. This should automatically install software to match the active system controller and reboot. After the install completes and the controller boots into F5OS-C software, the active system controller will bring it into the cluster. This process may take about 1 hour. Do not reboot the active system controller during this process. 

[root@controller-1 ~]# reboot
packet_write_wait: Connection to 100.65.x.x port 22: Broken pipe

4. On a second SSH session connected to the active system controller, enter the following command in confd to monitor the progress until the affected system controller joins the cluster and reaches the ready status.

syscon-2-active# show cluster | repeat

On bash, you can also follow the progress with the following command:

[root@controller-2:Active ~]# tail -f /var/log/openshift.log

5. Steps 1–3 provide an example of how to perform a clean installation on System Controller 1. If you want to perform a clean installation on System Controller 2, you need to follow the same steps. 

Additional Information

In certain situations, you may wish to fail over the current active controller, then PXE boot it.

When failing over an active system controller prior to PXE booting it, it is recommended to wait at least 10 minutes to ensure the newly active controller is stable, before PXE booting the newly standby controller. In addition, review the output of show cluster and the contents of /var/log/openshift.log to ensure the OpenShift cluster remains healthy.
