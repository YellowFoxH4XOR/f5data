Description

By default CGNAT logs use quotes as delimiters between fields. You would like to send CGNAT logs in CSV format (use comma as delimiter)

 

Environment

  • BIG-IP CGNAT
  • LSN pool
  • CGNAT logging

 

Cause

log.lsn.comma db variable is set to 'disable' (by default)

 

Recommended Actions

If you would like to configure CSV format for CGNAT logs, set log.lsn.comma db variable to enable

 

1. Log in to the tmsh utility by typing the following command:
tmsh

2. To change a database variable log.lsn.comma to enable, use following command syntax:
modify /sys db log.lsn.comma value enable

 

Before DB key change:

 

"LSN_DELETE""<client_ipv4_address>%<client_rtdomid>:<client_port>""<protocol>""<lsn_address>%<egress_rtdomid >:<lsn_port>""<start>""<duration>"


 After log.lsn.comma set to enable

 

LSN_DELETE,<client_ipv4_address>,<client_rtdomid>,<client_port>,<protocol>,<lsn_address>,<egress_rtdomid>,<lsn_port>,<start>,<duration>
