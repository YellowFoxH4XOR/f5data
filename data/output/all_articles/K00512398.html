Additional Information

The option use-from-dns-profile is under dos profile and protocol-dns. This is only visible on the tmos command and not on the GUI.

It has two values that is "yes" and "no". To make a change on a dos profile with protocol-dns enabled you can run the command:

tmsh modify security dos profile <name of dos profile> protocol-dns modify { <name of dos profile> { use-from-dns-profile <yes or no>  } }

In version 16.x the value is by default "yes" however in version 15.x it is "no".

This command  is used for overriding the configuration from original dns security profile. The impact depends on the configuration based on the below table for DNS security for virtual:
