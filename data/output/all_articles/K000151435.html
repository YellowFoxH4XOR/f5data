K000151435: AS3 installed but not working

Support Solution

Applies to

  • BIG-IP LTM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000151435

Description

After installing the AS3 RPM, the URI query to /mgmt/shared/appsvcs/info returns HTTP 400

Environment

  • AS3 RPM

Cause

Querying the REST API /mgmt/shared/appsvcs/info should return information about the AS3 installation, such as:

{ "version": "3.8.0", "release": "2", "schemaCurrent": "3.8.0", "schemaMinimum": "3.0.0" }

If this does not result and an HTTP 404 error returns instead, then AS3 did not install or is not running properly.

Recommended Actions

  1.  Check messages in /var/log/restnoded/restnoded.log
    1. If you see

severe: [appsvcs] {"message":"Failed to complete startup. SyntaxError: Unexpected token a in JSON at position 6\n at JSON.parse (<anonymous>)\n at outputToObject (/var/config/rest/iapps/f5-appsvcs/node_modules/@f5devcentral/atg-storage/src/storageDataGroup.js:162:17)\n

 then see article K000092654

  1. If you do not see anything useful in /var/log/restnoded/restnoded.log, then verify that restjavad and restnoded are running: bigstart restart restjavad restnoded

  2. If both services are running, but AS3 still is not responding as expected, uninstall and re-install the AS3 rpm.
