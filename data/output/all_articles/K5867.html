Topic

The BIG-IP LTM provides the following protocol options when you configure a forwarding virtual server.
  • All Protocols
  • ICMP (OSI Layer 3)
  • TCP (OSI Layer 4)
  • UDP (OSI Layer 4)
  • Other Value 1

The Other option allows you to specify an IP protocol (in its numerical form) other than TCP or UDP.

The default design of the BIG-IP LTM virtual server only allows traffic or protocols for which the virtual server is configured. The BIG-IP LTM blocks and drops all other traffic or protocols not specified by the virtual server.

For example:

  • You can configure a BIG-IP LTM virtual server to only allow ICMP traffic by specifying IP protocol number 1.
  • You can configure a BIG-IP LTM virtual server to only allow GRE traffic by specifying IP protocol number 47.

To configure a basic ICMP-only forwarding virtual server, perform the following procedure:

  1. Log on to the BIG-IP LTM Configuration utility.
  2. Select Local Traffic.
  3. Select Virtual Servers.
  4. Click Create.
  5. Name the virtual server.
    For example:
    icmp-only-fw-vs

  6. Under Destination, select the Network radio button.
  7. Type 0.0.0.0 for the Destination Address.
  8. Type 0.0.0.0 for the Destination Mask.
  9. Enter 0 or select "All Ports" from the Service Port drop-down menu.
  10. Under Type, select Forwarding (IP).
  11. Under Protocol, select Other.
  12. Enter 1 for the protocol value.

    Note: The value of 1 entered in this Step indicates a value of ICMP only.

    Note: A list of IP protocols and their corresponding numbers is available from the command line. The protocols are listed in the /etc/protocols text file, which you can open and read using a text editor.
  13. Click Finished.
