Known Issue

Low memory situations during Secure Sockets Layer (SSL) egress handling may cause the Traffic Management Microkernel (TMM) to produce a core file.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system has a small amount of available TMM memory.
  • The system is processing SSL requests through an SSL profile.

Impact

If the BIG-IP system is a member of a redundant configuration, traffic fails over to the standby system. If the BIG-IP system is not a member of a redundant pair, traffic is interrupted until the TMM process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system temporarily fails to pass traffic.
