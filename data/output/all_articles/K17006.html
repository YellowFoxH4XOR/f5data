Known Issue

The Traffic Management Microkernel (TMM) may restart when you configure the virtual server ip-protocol option and associated protocol profile to use different protocols.

This issue occurs when all of the following conditions are met:

  • You use the Traffic Management Shell (tmsh) to configure a virtual server in one of the following ways:

    • You set the virtual server ip-protocol option to udp and the profile to tcp.
    • You set the virtual server ip-protocol option to any and the profile to tcp.
    • You set the virtual server ip-protocol option to tcp and the profile to udp.
  • The virtual server processes a new client connection.

Impact

TMM may restart and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system fails to process traffic for a brief period of time.
  • Your BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.

Workaround

There is no workaround. To avoid this issue, ensure that you configure the virtual server ip-protocol option and the associated protocol profile to use the same protocol.
