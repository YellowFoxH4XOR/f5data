Description

Not getting output for all TMM Cores when monitoring TMM Dropped Packets via SNMP

Environment

  • F5OS
  • LTM
  • SNMP

Cause

The OID to get all TMM CPU Dropped Packets is 1.3.6.1.4.1.3375.2.1.8.2.3.1.33 (sysTmmStatDroppedPackets)

Recommended Actions

Update the correct OID - 1.3.6.1.4.1.3375.2.1.8.2.3.1.33

Sample output:

snmpwalk -v 2c -c public 10.10.10.10 1.3.6.1.4.1.3375.2.1.8.2.3.1.33
