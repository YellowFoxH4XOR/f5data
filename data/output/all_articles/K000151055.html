Description

This article describe the change in GSLB Pool member icon when disabled.

  • GSLB Pool member icon is black diamond instead of black circle.

Environment

  • DNS/GTM
  • GSLB Pool member
  • GSLB Pool

Cause

DOC ID 1930941: Document the icon change and behaviour.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1.  This is a change in icon from version 16.1.5 and version 17.1.2

Additional Information

Disabled GSLB pool members are no longer monitored, which is why a black diamond surface instead of a black circle.
