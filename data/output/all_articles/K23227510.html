Description

Troubleshooting BIG-IQ or BIG-IP internal restjavad, restnoded, and icrd[_child]

Environment

  • BIG-IQ
    • Device Service Cluster (DSC)
    • Centralized Management
  • BIG-IP

Cause

None

Recommended Actions

Perform a packet capture

Impact of this procedure: There should not be a negative impact as a result of performing this procedure.

  1. SSH to log into the bash prompt of the BIG-IP or BIG-IQ system.
  2. Execute the following commands in sequence:

    Note: You may also save this as a shell script or simply copy/paste the entire script below

    #!/usr/bin/env bash
# Set the environment variables
source /etc/bashrc

# Set the name of the output file
output="/shared/tmp/$(getHostName).$(getPromptStatus | sed 's/[ :/]/_/g').$(date +%F.%H%M%S).v$(awk '$1=="Build:"{b=$2}$1=="Version:"{v=$2}END{print v "_HF-" b}' /VERSION).pcap"

# Discover the ephemeral ports for all icrd and java processes.
ports=$(ss -nlpi | awk '$0~"icrd"||$0~"java"{gsub(/([:f]?.+)?:/,"",$5);if($5!="*"){print $5}}')

# Output the tshark syntax to parse this capture. Non-default http ports will be used, so we use the -d flag to 'decode as' http.
echo -e '\nUse the following syntax to decode the random ports as http:\n\ttshark -r '${output} $(echo ${ports} | xargs printf "-d tcp.port==%s,http ") -2 -R http"\n"

# Convert our ports to BPF consumable syntax
ports=$(echo ${ports}|xargs printf "%s or ") && ports=${ports%????}

# Start our packet capture
tcpdump -s0 -i lo "port ($ports)" -w ${output} -v

  3. Parse the capture on the command line with tshark using the syntax output in step 2.

    For Example, I want to search for all POST messages in packet capture /shared/tmp/bigip.Active.2019-03-19.094646.v6.1.0_HF-0.5.1224.pcap:

    tshark -r /shared/tmp/bigip.Active.2019-03-19.094646.v6.1.0_HF-0.5.1224.pcap -d tcp.port==1514,http -d tcp.port==9200,http -d tcp.port==8081,http -d tcp.port==2514,http -d tcp.port==8018,http -d tcp.port==8020,http -d tcp.port==9300,http -d tcp.port==9081,http -d tcp.port==9210,http -d tcp.port==9310,http -d tcp.port==8514,http -d tcp.port==8100,http -d tcp.port==33928,http -2 -R http.request.method==POST

  4. Alternatively, you may download the capture and view it with Wireshark or your favorite packet parser.

Additional Information
