Topic

You should consider using this procedure under the following condition:

  • You want to change the SSL protocols or ciphers allowed for a managed BIG-IP device's Configuration utility using BIG-IQ.

    Note: The BIG-IQ does not have any method to list the existing allowed SSL protocols or ciphers of a managed BIG-IP device's Configuration utility. You may have to use other methods to list the existing allowed SSL protocols or ciphers of a BIG-IP device's Configuration utility by referring to the other articles described below.

For other methods of managing the SSL protocols and ciphers allowed by BIG-IP Configuration utility, refer to the following:

  • K02321234: Managing the SSL protocols and ciphers allowed by Configuration utility
  • K000140730: Managing the SSL protocols and ciphers allowed by Configuration utility using iControl REST

Description

SSL protocols and ciphers allowed by a BIG-IP device's Configuration utility are configured independently of local traffic objects, such as SSL profiles.

The default protocol and ciphers vary from version to version. You can change the SSL protocols and ciphers to meet your requirements if needed.

If the BIG-IP device is managed by a BIG-IQ, you can use the BIG-IQ Onboarding feature to configure the SSL protocols and ciphers of the managed BIG-IP device Configuration utility.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your BIG-IP device is licensed, provisioned, and configured with a management IP address.
  • Your BIG-IP device is managed by a BIG-IQ system.
  • You have administrative access the BIG-IQ webUI.

Procedures

To configure the SSL protocols and ciphers of the managed BIG-IP device Configuration utility using the BIG-IQ Onboarding feature, perform the following procedure:

Impact of procedure: Clients that do not support the specified SSL protocols and/or ciphers are not able to access the managed BIG-IP device's Configuration utility.

  1. Log in to the BIG-IQ webUI as the admin user.
  2. Go to Devices > BIG-IP ONBOARDING.
  3. Select Onboard. The BIG-IQ webUI displays a Create Onboard Declaration page.
  4. Select New for the Configurations setting.
  5. Type in a name for the task in the Task Name setting, for example, onboard-httpd-ssl-settings.
  6. Type in the management IP address of the managed BIG-IP device you want to change in the Target Host setting.
  7. Type in the listening port of the managed BIG-IP device you want to change in the Target Port setting. By default, this should be port 443.
  8. Type in the password of the admin user of the managed BIG-IP device you want to change in the Target Passphrase setting.
  9. Under the Onboard Classes column, locate and check httpd. The Create Onboard Declaration page displays an additional section for httpd.
  10. Add or remove the SSL ciphers you want from the list of the Ssl Ciphersuite setting as needed.
  11. Add or remove the SSL protocols you want in the Ssl Protocol setting as needed.

    Note: Acceptable values include SSLv2, SSLv3, TLSv1, TLSv1.1, TLSv1.2, ALL, or None.

  12. Select Onboard to effect the change on the managed BIG-IP device. The BIG-IQ webUI returns you to the BIG-IP Onboarding page and you can monitor the status of the task in the Status column. If the task completes successfully, the task will be reported as Onboard Finished in its Status column.
