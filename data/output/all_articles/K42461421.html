Description

You wish to refer ASM event for specific Support ID by using REST API.

Environment

  • BIG-IP ASM

Cause

None

Recommended Actions

Using the endpoint /tm/asm/events/requests with filter you can refer to specific request.

 restcurl /tm/asm/events/requests/?\$filter=id+eq+<Support ID>

# restcurl /tm/asm/events/requests/?\$filter=id+eq+10898971038247288919
