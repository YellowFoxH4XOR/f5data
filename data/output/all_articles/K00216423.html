Known Issue

BIG-IP LTM monitors may prevent configurations from loading after an upgrade when using backslash (\) characters in the recv setting.

This issue occurs when all of the following conditions are met:

  • You have configured one or more BIG-IP LTM monitors to use multiple backslash characters. For example:

    recv "\\* OK"

  • You upgrade the system from BIG-IP 11.5.0 through 11.6.3 to BIG-IP 12.0.0 through 13.0.0.

Note: This issue affects only BIG-IP LTM monitors. It does not affect BIG-IP GTM or BIG-IP DNS monitors.

Impact

The BIG-IP configuration fails to load after an upgrade.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system does not process traffic after an upgrade.
  • In the /var/log/ltm file, you observe messages similar to the following example:

    01070753:3: Monitor /Common/example_http recv parameter contains an invalid regular expression (Invalid preceding regular expression).
    Unexpected Error: Validating configuration process failed.

Workaround

To work around this issue, you can edit the /config/bigip.conf file to add missing backslash characters to the BIG-IP LTM monitor configuration. To do so, perform the following procedure:

Impact of workaround: This workaround is a temporary fix that enables the configuration to load. The issue will persist on the next configuration reload using the tmsh command.

  1. Log in to the Advanced Shell (bash).

  2. Using a preferred editor, open the bigip.conf file and add any missing backslash characters.

    In the following example, the recv setting should have two backslash characters:

    ltm monitor http /Common/example_http {
        adaptive disabled
        defaults-from /Common/http
        destination *:*
        interval 5
        ip-dscp 0
        recv "\* OK"
        recv-disable none
        send "GET /\r\n"
    }

    The corrected BIG-IP LTM monitor configuration should appear similar to the following example:

    ltm monitor http /Common/example_http {
        adaptive disabled
        defaults-from /Common/http
        destination *:*
        interval 5
        ip-dscp 0
        recv "\\* OK"
        recv-disable none
        send "GET /\r\n"
    }

  3. Save the changes and exit the file.
  4. Reload the configuration by typing the following command:

    tmsh load sys config
