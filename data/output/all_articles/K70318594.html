Description

After upgrade to 15.0.0 or later releases, you can see messages similar to the following messages in /var/log/asm:
May 19 17:49:55 bigip err perl[11111]: 01310001:3: event code I4556 Cookie building failed
or
May 19 17:49:55 bigip err perl[11111]: 01310001:3: event code I4537 Cookie building failed

You can also observe the following messages within /var/log/ts/bd.log:
BEM|ERR   |May 19 17:49:55.800|0983|response_header_accumulator.c:0200|Error: CookieMgrBuildCookie failed. ans 1 job 2957561040
IO_PLUGIN|ERR   |May 19 17:49:55.800|0983|io_plugin.c:3320|TMEVT_RESPONSE: Cannot build a ts cookie.

Environment

  • BIG-IP ASM provisioned
  • ASM policy is associated to the virtual server processing traffic
  • Upgrade to 15.0.0 or later release

Cause

For some requests, the response can arrive truncated or not arrive at all. Depending on files this affected, this behavior can cause the application intended to be protected to fail. This is a known issue and being tracked as ID910253.

Recommended Actions

Please refer to ID910253 linked below for steps to work around this issue
