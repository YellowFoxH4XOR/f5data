Description

You get the following error when publishing ltm policy with asm control and no default rue.

err mcpd[xxxxx]: 0107172c:3: Policy '/Common/policy_name'; a policy controlling 'asm' must have a default rule.

Environment

  • ASM, Advance WAF

Cause

There is a missing condition for traffic that doesn't match previous condition

Recommended Actions

When creating LTM policy controlling the ASM policy, we need to create a default rule that manages the condition if no other condition matches.

Create a default rule with no condition but only action by selecting either asm disable or enable based on your requirement.

To create a default rule using GUI perform following

1. Go to Local Traffic  ››  Policies : Policy List  ››  < Policy name >
2.  Under Rules click - 'create' 
3.  In new screen, provide the name - 'default'
4. Under Match all of the following conditions - Leave as it is 
5  Under Do the following when the traffic is matched - select Enable/Disable ASM at 'request' time.

Note : Pay attention while selecting at what point of time this event to trigger. For instance, if your first condition is at 'request' then selecting 'client accepted' in default rule make all the traffic to match default rule based on the strategy - execute first matching rule.
