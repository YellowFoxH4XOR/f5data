K53713752: When Setting up LDAPS in BIG-IQ, Test Authentication Fails with error: Certificates do not conform to algorithm constraints

Description
When you set up an LDAP or Active Directory authentication provider that uses the LDAPS protocol on TCP port 636, the test authentication fails with the error: 
Unable to connect to the authentication server. java.security.cert.certificateexception: Certificates do not conform to algorithm constraints

Environment

  • BIG-IQ 7.1.X Centralized Management
  • LDAPS Configured
  • "validateServerCertificate" : false
  • Algorithm in use by a certificate is RSA-PSS 
    For Example:
    As seen below, it has 2 Certificates: first certificate is the server certificate, the second is the signing Certificate Authority (the error has something to do with the "algorithmIdentifier")

Cause
There is no current support for server certificate signed by RSA-PSS algorithm for AD/LDAP authentication for BIG-IQ. The openjdk 1.8.0_212 on BIG-IQ does not support server certificate signed by RSA-PSS algorithm. The support was added to 1.8.0_252 version.

Recommended Actions

Use StartTLS (with server certificate validation enabled) instead of LDAPS as it is the recommended and most secure method.
