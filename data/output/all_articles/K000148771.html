K000148771: Error 51096 - A V5A BIG-IP license request cannot be processed by this V5B license server. Please use https://activate.f5.com

Type
Support Solution
Published
2024-12-05
Updated
2024-12-05
Status
Final
Source
https://my.f5.com/manage/s/article/K000148771

Description

Getting error when trying to activate Base registration key, This Error show up on license service when  try to activate the 25 letters Base registration key for V5A BIG IP.

Environment

Licensing BIG IP V5A and older versions.

Cause

The license could not be activated due to the product had gotten to the end technical support. The link to activate 25 digit XXXXX-XXXXX-XXXXX-XXXXX-XXXXX Base registration key, is no longer available.

https://activate.f5.com

Recommended Actions

The product had gotten to the end of technical support, And not possible to be activated anymore. 

Additional Information

None.
