Source

Description

  • The fslogd process is continuously restarting
  • The following error messages can be seen on /var/log/ltm

    err fslogd[18142]: Fatal error file_writer.c:truncate_file:350 ftruncate failed errno[22] strerror[Invalid argument]
    err fslogd[21410]: Fatal error file_writer.c:truncate_file:350 ftruncate failed errno[22] strerror[Invalid argument]
    err fslogd[21556]: Fatal error file_writer.c:truncate_file:350 ftruncate failed errno[22] strerror[Invalid argument]

  • The following error messages can be seen on /var/log/daemon.log

    emerg logger: Re-starting fslogd
    emerg logger: Re-starting fslogd
    emerg logger: Re-starting fslogd

Environment

AFM

Cause

Stuck fslogd process

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Stop fslogd

    bigstart stop fslogd

  2. Make a tarball of /var/fslog

    tar czvf /var/tmp/fslogd.tgz /var/fslog/

  3. Move all the temp log files from tmp/ to pending/

    mv /var/fslog/tmp/*.log /var/fslog/pending/

  4. Start fslogd

    bigstart start fslogd
