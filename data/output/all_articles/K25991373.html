Known Issue

BIG-IP Edge Client may fail to establish an access session.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an access policy that uses the Endpoint Security Server-Side Client Type agent to allow only the client type of Edge Client.
  • The access policy does not display a message box when the detected client type is other than the Edge Client for the Full or Mobile Browser branch.
  • The BIG-IP Edge Client fails to authenticate.

Impact

As a BIG-IP Edge Client user, you are unable to open a new session to authenticate.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After the BIG-IP Edge Client fails to authenticate, the system displays a message similar to the following example :

    Your session could not be established.

    <session id>

    Access was denied by the access policy. This may be due to a failure to meet access policy requirements.

    If you are an administrator, please go to Access Policy >> Reports : All Sessions page and look up the session reference number displayed above.

    To open a new session, please click here.
    Cancel

  • When the BIG-IP Edge Client presents the previously described message, if you click To open a new session, please click here, you immediately return to the Access Denied page. To create a new access session, you must first click Cancel.
  • When you view the BIG-IP APM event logs for the failed access session attempts initiated after the authentication failure, you notice that the BIG-IP APM system detects the client type of Full or Mobile Browser for the access session.

Workaround

To work around this issue, you can modify the access policy by adding a message box to the Full or Mobile Browser branch. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Access Policy > Access Profiles.
  3. To open the visual policy editor, find the affected access profile and click Edit .
  4. In the Full or Mobile Browser branch, click +.
  5. Click General Purpose.
  6. Select Message Box.
  7. Click Add Item.
  8. (Optional) Modify the Message text.
  9. Click Save.
  10. Click Apply Access Policy in the top left corner of the editor.
