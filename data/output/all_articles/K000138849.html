Description

After changing an application template to either add or remove the SNAT and/or SNAT Automap profile and re-deploying the changes to BIG-IP Next instances, the changes to SNAT do not take effect on the BIG-IP Next instances.

Environment

  • BIG-IP Next
  • Managed by Central Manager
  • An application is already successfully deployed to one or more BIG-IP Next instances
  • You make a chance to the application to add or remove SNAT and redeploy

Cause

The SNAT setting does not get changed on BIG-IP Next instances that are already running the application.  This is being tracked by ID 1134225.

Recommended Actions

Un-deploy the application from all BIG-IP Next instances, and then re-deploy the application to all BIG-IP Next instances once the change to SNAT has been made.
