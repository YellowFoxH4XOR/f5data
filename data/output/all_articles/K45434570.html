Known Issue

The BIG-IP ASM system device group full sync may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured as part of a device group that has Full Sync configured.
  • The /var hard drive partition becomes fully utilized.

Impact

The device group full sync fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to run a full sync to the configured device group, the /var/log/ts/asm_config_server.log log file on the initiating device contains error messages similar to the following example:

    <BIG-IP ASM hostname> crit g_server.pl[9349]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::SyncHandler::sync_send_ucs): Could not save configuration to send full sync to /Common/F5-CF-Primary.oami.europa.eu: DBD::mysql::db do failed: File '/ts/var/sync/ts_db.save_dir_9349.cstmp/ts_db.data.DCC.ACCOUNT_SESSION_AWARENESS_SETTINGS.cstmp' already exists at /usr/lib/perl5/site_perl/F5/ConfigSync.pm line 337.

  • When you attempt to run a full sync to the configured device group, the /var/log/ts/asm_config_server.log log file on the device group members contains error message similar to the following example:

    <BIG-IP ASM hostname> crit g_server.pl[9419]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::spawn_relay_handler): Sync recovery state timed out. State may be inconsistent with other peers

Workaround

To work around this issue, you can clear the contents of the /ts/var/sync directory. To do so, perform one of the following procedures:

  • Correcting BIG-IP ASM synchronization 11.6.0 and later
  • Correcting BIG-IP ASM synchronization 11.5.4 - 11.3.0

Impact of workaround: Performing the following procedure should not have a negative impact on your system

Correcting BIG-IP ASM synchronization 11.6.0 and later

  1. Log in to the command line of the affected device.
  2. Change directories to /ts/var/sync by typing the following command:

    cd /ts/var/sync

  3. Delete the contents of the /ts/var/sync directory by typing the following command:

    rm -f /ts/var/sync/*

  4. Restart the asm_config_server.pl process by typing the following command:

    pkill -f asm_config_server

  5. Check that the asm_config_server.pl process has restarted by typing the following command:

    ps ax | grep asm_config_server.pl

  6. Repeat steps 1 through 5 on all peer devices.
  7. Initiate a device group full sync from the primary BIG-IP ASM device.

Correcting BIG-IP ASM synchronization 11.5.4 - 11.3.0

  1. Log in to the command line of the affected device.
  2. Delete the contents of the /ts/var/sync directory by typing the following command:

    rm -f /ts/var/sync/*

  3. Restart the asm_config_server.pl process by typing the following command:

    /usr/share/ts/bin/kill_asm_config_server.pl

  4. Check that the asm_config_server.pl process has restarted by typing the following command:

    ps ax | grep asm_config_server.pl

  5. Repeat steps 1 through 5 on all peer devices.
  6. Initiate a device group full sync from the primary BIG-IP ASM device.
