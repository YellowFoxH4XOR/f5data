Description

When expand more links on BIG-IP Link Controller system, you must add the new link to the existing GTM server objects. When you have "virtual-server-discovery enabled" on an existing GTM server object, the self-IP will be automatically removed after you add it.

This article guide you how to add the new self IP on a "virtual-server-discovery enabled" BIG-IP Link Controller system.

Environment

  • BIG-IP Link Controller
  • GTM server
  • Self IP
  • Virtual server auto-discovery enable

Cause

This is expected, if BIG-IP Link Controller have "virtual-server-discovery enabled" configuration, it will check the gateway route pool, if the self IP subnet is not there, system will remove the added self IP from GTM server object.

Recommended Actions

To add a new self-IP to GTM server object, you will only need to add the new link gateway IP address to the configured default route gateway pool. The BIG-IP Link Controller will automatically add the new self-IP to GTM server object since virtual-server-discovery enabled.
