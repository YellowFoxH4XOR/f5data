K000140407: Pool member status - Unknown (Enabled) - Pool member does not have service checking enabled

Type
Support Solution
Published
2024-08-27
Updated
2024-08-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000140407

Description

Pool member status is stucked as Unknown (blue square). When you go to the Pool member, it shows the status as Unknown (Enabled) - Pool member does not have service checking enabled.

 

tmsh list ltm pool <pool name> members

 

  --------------------------------------------------------------
  | Ltm::Pool Member: 10.10.10.1:80       
  --------------------------------------------------------------
  | Status                                 
  |   Availability   : unknown             
  |   State          : enabled             
  |   Reason         : Pool member does not have service checking enabled
  |   Monitor        : none                
  |   Monitor Status : unchecked           
  |   Session Status : enabled             
  |   Pool Name      : Pool_http           
  |   IP Address     : 10.10.10.1 

 

 Upon checking the configuration, you can see that there is a specific monitor pointing to the pool member with issue.

 

ltm pool /Common/Pool_http {
    members {
        /Common/10.10.10.1:80 {
            address 10.10.10.1
            monitor /Common/none
        }
        /Common/10.10.10.2:80 {
            address 10.10.10.2
        }
    }
    monitor /Common/http
}

 

Environment

BIGIP LTM

Cause

The monitor for that pool member in question is set to None.

Recommended Actions

Remove the None health monitor to that specific Pool member.

 

1. Login to BIGIP GUI.
2. Navigate to Local Traffic --> Pools.
3. Select the pool with the problem.
4. Click on Members.
5. Click on the pool member with the problem.
6. Under Configuration, select Advanced.
7. Under Health Monitors, Select Inherit from Pool.
8. Click on Update.

The monitor on the pool level should start monitoring the pool member, and should update the device after a few seconds (depending on the interval of the monitor)
