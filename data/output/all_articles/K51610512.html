Description

I would like to capture traffic which is destined for my vCMP Guest, at the vCMP Host system.

Environment

vCMP Host with one or more vCMP Guests

Cause

Under normal troubleshooting (i.e. tmm level), tcpdump on the vCMP Host will collect traffic which is destined for the vCMP Host itself (either broadcast or direct traffic).  It will not capture traffic destined for the vCMP Guest.

Recommended Actions

The correct place to capture traffic related to the vCMP Guest is on the vCMP Guest system itself.
In certain instances it may be necessary to determine if traffic destined for the Guest is reaching the Host (to be passed to the Guest) or to determine if the Host is properly passing traffic on to the Guest.  In these instances the interface level packet captures at the Host can be used to examine that traffic.

Note: if the vCMP guest is hosted by a VIPRION platform vCMP host, be aware of the limitations given in K49375773: tcpdump limitations on BIG-IP VIPRION systems
