Known Issue

The following APM Clients issues result in additional certificate prompts to the user on BIG-IP Edge Client for Windows when you use client certificates with APM Clients 7.2.1.2 installed.

  • ID 1008213: When you configure an On-Demand Cert Auth policy agent in the access policy, BIG-IP Edge Client for Windows may present the user with a certificate selection prompt even when only a single valid certificate is installed on the client.
  • ID 1008209: When using Security Assertion Markup Language (SAML) Identify Provider, BIG-IP Edge Client for Windows may present the user with a certificate selection prompt even when only a single valid certificate is installed on the client.
  • ID 1007549: When using SAML authentication, BIG-IP Edge Client for Windows may present the user with an additional certificate selection prompt upon logout.

Expect the certificate dialog prompt to appear only when there are several user certificates installed.

The issues occur when the conditions listed in the following table are met.

Known issueTriggering conditions
ID 1008213
  • You configure On-Demand Cert Auth in the access policy.
  • The client device has a single user certificate installed.
ID 1008209
  • You configure SAML authentication.
  • The Identity Provider (IdP) requests a user's certificate.
  • The client device has a single user certificate installed.
ID 1007549
  • Scenario 1:
    • You configure SAML authentication with a Single Logout option.
    • The IdP requests a user's certificate.
    • The client device has a single user certificate installed.
    • The IdP address is not in the Trusted Server List of the client device.
  • Scenario 2:
    • You configure SAML authentication with a Single Logout option.
    • The IdP requests a user's certificate.
    • The client device has two or more user certificates installed.

Impact

There is an additional certificate prompt for affected BIG-IP APM configurations.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • During the BIG-IP APM access policy evaluation, BIG-IP Edge Client for Windows shows an additional certificate selection prompt to the user instead of automatically selecting the certificate.

Resolution

Status
