K000134716: Manually editing the BIG-IP Edge Client for Windows and Mac OS client.f5c file is not supported

Type
Support Solution
Published
2023-07-26
Updated
2026-05-07
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000134716

Description

The BIG-IP Edge Client for Windows and Mac OS client.f5c file can be edited manually for configuration changes as documented in K02344525: Overview of the BIG-IP Edge Client server list behavior.

Beginning in BIG-IP Edge Client for Windows and Mac OS, APM Clients 7.2.4.3, editing the BIG-IP Edge Client client.f5c is not supported.

Environment

  • BIG-IP Edge Client on Windows and Mac OS
  • BIG-IP Edge Client client.f5c file editing

Cause

Upgrade to BIG-IP Edge Client for Windows and Mac OS, APM Clients 7.2.4.3. For more information, review K23159056: Upgrade the BIG-IP Edge Client | BIG-IP update and upgrade guide.
If your APM deployment includes Endpoint Inspection, please note
K000134990: Upgrading to BIG-IP 17.1.0.2, 16.1.3.5 or 14.1.5.5 breaks MacOS 13.3 Endpoint Inspection for VPN again

Recommended Actions

Beginning in BIG-IP Edge Client for Windows and Mac OS, APM Clients 7.2.4.3, BIG-IP Edge Client added integrity checking on the client.f5c file to prevent loading added configurations through manual editing of the file. However, with administrator access on the Windows or MacOS end user system, you can still manage the BIG-IP Edge Client configuration on the client by making manual changes to the config.f5c file instead of client.f5c. To do so, when your perform BIG-IP APM system is running APM Client 7.2.4.3, perform one of the following procedures as appropriate for the operating system on the client system:

  • Edit config.f5c on Windows
  • Edit config.f5c on MacOS

Prerequisite

  • Administrator role access to BIG-IP APM system
  • Administrative access on an end user system to modify the config.f5c file

Edit config.f5c on Windows

  1. Login to the client system
  2. Close the BIG-IP Edge Client application.
  3. Delete the client.f5c and client.f5c.sig file under C:\Users\<username>\AppData\Roaming\F5 Networks\VPN folder as appropriate.
  4. Using a non-formatting text editor, modify the config.f5c file under C:\ProgramData\F5 Networks\Secure Access Client folder
  5. If the config.f5c file does not exist in C:\ProgramData\F5 Networks\Secure Access Client folder, modify the config.f5c file under C:\Program Files (x86)\F5 VPN folder
  6. Start the BIG-IP Edge Client application.

Edit config.f5c on MacOS

  1. Login to the client system
  2. Close the BIG-IP Edge Client application.
  3. Delete the client.f5c and client.f5c.sig file under /Users/<username>/Library/F5Networks folder
  4. Using a non-formatting text editor, modify the config.f5c file under the /Library/Application Support/F5Networks folder as appropriate.
  5. Start the BIG-IP Edge Client application.

Additional information

When a remote Windows or macOS user launches BIG-IP Edge Client on a client device and initiates a network access session, the client device downloads and initializes the BIG-IP Edge Client installer based on the Component Update settings of the connectivity profile of the BIG-IP APM virtual server. For example, when you add a server in the Server list field in the BIG-IP APM connectivity profile, it also updates the client.f5c or client_tmp.f5c server entries in BIG-IP Edge client configuration on the Windows and MacOS clients. For more information on this behavior, refer to K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows, macOS, and Linux CLI.
