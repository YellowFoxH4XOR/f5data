Known Issue

This is the result of a known issue. BIG-IP version 9.1.1 software has introduced a new baud rate scheme that is not compatible with the baud rate scheme in the Switch Card Control Processor (SCCP) version installed with version 9.1.1. Due to this incompatibility, complex procedures are required for setting the serial console baud rate on a BIG-IP system that is running version 9.1.1.

Note: This incompatibility applies to version 9.2 ONLY if version 9.1.1 has been previously installed (or if version 9.1.1 is currently installed on a different slot), and if no version later than 9.1.1 (for the 9.1 branch) and 9.2.0 (for the 9.2 branch) has been installed.

F5 Product Development tracked this issue as CR59186 and CR59156. This issue has been resolved in BIG-IP version 9.1.2 for the version 9.1 software branch and in BIG-IP version 9.2.2 for the version 9.2 software branch.

Important: Because the SCCP is common for all version slots, for systems that support installing multiple version slots, installation of the BIG-IP version 9.1.2 or later of the 9.1 branch, or version 9.2.2 or later of the 9.2 branch to any slot will update the SCCP to the proper version.

F5 Product Development recommends upgrading to version 9.1.2 or 9.2.2 or later so that you may adjust the baud rate using the procedure outlined in solution K9156: Setting the baud rate of the serial console port.

If upgrading is not an immediate option, the following procedures are required to set the serial console baud rate for BIG-IP version 9.1.1:

  • Set the serial console baud rate using the LCD panel.
  • Set the serial console baud rate in the inittab and grub.conf files.
  • Set the serial console baud rate in the SCCP u-boot environment variable.

Setting the serial console baud rate using the LCD panel

Important: For systems with multiple version slots installed, all version slots must use the same baud rate.

To set the desired baud rate using the LCD panel, perform the following steps:

  1. On the LCD panel, press the X key to enter the menu.
  2. Using the down arrow key, select System.
  3. Select the check box for the LCD panel.
  4. Using the down arrow key, select Serial Speed.
  5. Select the check box for the LCD panel.
  6. Using the down arrow key, select the desired baud speed.
  7. Select the check box for the LCD panel.
  8. Press the X key on the LCD panel.

Setting the serial console baud rate in the inittab and grub.conf files

Important: For systems with multiple version slots installed, all version slots must use the same baud rate.

Set the desired baud rate in the inittab and grub.conf files by performing the following steps:

  1. Log in to the command line.
  2. Change directories to the /etc directory by typing the following command:

    cd /etc

  3. Using a text editor, such as vi or pico, edit the inittab file.
  4. Edit the baud rate following the ttyS0 entry in the following line at the end of the file:

    co:2345:respawn:/sbin/agetty -L ttyS0 19200 vt100

  5. Save the inittab file and exit the editor.
  6. Change directories to the /mnt directory by typing the following command:

    cd /mnt

  7. Mount the /dev/hda2 file system by typing the following command:

    mount /dev/hda2 /mnt/tmp

  8. Change directories to the /mnt/tmp/grub directory by typing the following command:

    cd /mnt/tmp/grub

  9. Using a text editor, such as vi or pico, edit the grub.conf file.
  10. Edit the speed setting to the desired baud rate. The output should appear similar to the following, where 19200 is the baud rate:

    serial --unit=0 --speed=19200

  11. Edit the ttyS0 value to the desired baud rate for all of the available version slots. The output should appear similar to the following, where 19200 is the baud rate:

    title BIG-IP 9.1.1 Build 54.6 - drive hda.1
    kernel (hd0,4)/boot/vmlinuz ro root=/dev/hda5 console=ttyS0,19200 panic=1 mem=224M platform=C62 quiet

  12. Save the grub.conf file and exit the editor.
  13. Change directories to the /mnt directory by typing the following command:

    cd /mnt

  14. Unmount the /dev/hda2 file system by typing the following command:

    umount /mnt/tmp

  15. Stop the BIG-IP processes by typing the following command:

    halt

  16. After the system has halted, power down the BIG-IP system.

Setting the serial console baud rate in the SCCP u-boot environment variable

Set the desired baud rate in the SCCP u-boot environment by performing the following steps:

  1. Connect the client terminal to the BIG-IP console port.
  2. Configure the client terminal settings to the baud rate that was used prior to upgrade.
  3. Power up the BIG-IP system from a powered-off state.
  4. At the press any key to stop Autoboot prompt, stop the boot.

    The system will return a => prompt.

  5. View the current environment baud rate value by typing the following command:

    printenv

  6. Set the desired baud rate environment value by typing the following command:

    setenv baudrate <rate>

    Replace <rate> with the desired baud rate.

    The system will return the following prompt to change your terminal setting to the new baud rate, where <rate> will be the new baud rate you have selected:

    ## Switch baudrate to <rate> bps

  7. Configure the client terminal settings to the desired baud rate, and press the Enter key.
  8. Save the baud rate environment value by typing the following command:

    saveenv

  9. Restart the BIG-IP system by typing the following command:

    reset

    Important: Some client terminal applications will need to be closed and restarted at this point in the procedure. If you experience garbled console output as the system boots using the new baud rate, close and then restart your client terminal application.

    Important: After the system reboots, for systems with multiple version slots, you will need to boot to each slot and perform the 'Setting the serial console baud rate' procedure using the LCD panel and Steps 3, 4, and 5 of the Setting the serial console baud rate in the inittab and grub.conf files procedure.
