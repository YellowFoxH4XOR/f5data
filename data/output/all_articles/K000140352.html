Description

Customer configure the DNS resolver, but cannot find the way to display the cached DNS records, delete the cached DNS records.

Environment

  • BIG-IP
  • DNS resolver

Cause

None

Recommended Actions

Refer to K12140128: Overview of the DNS resolver:

Unlike the BIG-IP DNS cache feature, the DNS resolver does not have a method or utility to perform the following tasks:

  • Query an entry or entries in the cache
  • Determine the number of entries in the cache
  • Remove an individual entry from the cache
  • Note: All entries in the cache are removed when TMM restarts.

If this feature is required, please contact F5 support and raise the feature request.

Additional Information

None.
