Description

You tried to add new AVR Widget on the GUI > Statistics > Analytics > HTTP > Custom page.

The Add Widget button is not active (does not show a hyperlink), you are not able to add any widget nor create a new customer view.

It works as normal on version 14.x.

Environment

  • AVR provisioned
  • GUI

Cause

Bug ID 1009093: GUI widgets pages are not functioning correctly

Recommended Actions

There are no fixed versions for this ID at the time of publication of this article.

Apply the workaround on the BUG tracker link. Alternatively you can request an Engineering HotFix for this ID with F5 Support.
