Description

If you have any issues running the FCP usage script, this document will help you troubleshoot and resolve the most common issues.

Inventory refresh completed [FAILED]

Environment

  • BIG-IQ 8.4.0

  • FCP

Cause

The FCP usage script runs on the BIG-IQ and requires all managed devices to be available to ensure accurate collection of data.

If a BIG-IP device is unavailable (offline, certificates expired, suddenly fire-walled, DNS or network issues) the FCP usage script will fail.

Answer/Recommended Actions

There is a list of unavailable BIG-IP devices in the bigIQCollect.out file (part of the TGZ output).

Lab box example:

========== UNAVAILABLE DEVICE CHECK ==========
Hostname: big-ip-14-1-4-3.example.com
Address: 10.155.255.43
Machine ID: 54208c9e-d27e-40c2-9346-5d1b9594ad7f
==============================================

For each failed device, check network and certificate issues and if the device is no longer needed, remove it from the BIG-IQ managed devices.
