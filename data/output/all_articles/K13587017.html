Issue

Error Message

notice mcpd[<PID>]: 01070807:5: Monitor /<partition>/<name> instance <IP>:<port> has been <state>

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <partition> is the name of the partition where the monitor resides
  • <name> is the name of the monitor instance
  • <IP> is the name or IP address of the monitor instance
  • <state> is either enabled or disabled

For example:

notice mcpd[6402]: 01070807:5: Monitor /Common/monitor_http instance 10.10.10.10:80 has been enabled

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You configure a pool or pool member with a monitor.
  • An administrator changes the monitor instance state to enabled or disabled.

Impact

There is no impact; this message is a notification of the state of the monitor instance.

Recommended Actions

If the message indicates the monitor instance is disabled, you can enable it using the Traffic Management Shell (tmsh). To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Enable or disable the monitor instance using the following command syntax:

    tmsh modify ltm pool <name> members modify { <member_name> { state <user-up | user-down> } }

    For example, to enable the monitor instance pool_member, type the following command:

    tmsh modify ltm pool pool_http members modify { pool_member:80 { state user-up } }
