Description

When adding a DNS query to Active in Query type filter and then remove it from the filter it continues to be blocked.

Environment

BIG-IP with DNS and AFM modules provisioned
DNS Security Profile is used for defining which DNS query types are accepted by the device

Cause

Bug ID1101653.

Recommended Actions

There is an available workaround as well:

1. Move 'query' from Available to Active in Header Opcode Exclusion, click Update
2. Move 'query' back from Active to Available in Header Opcode Exclusion, click Update
3. Filter will stop blocking allowed query types

None.
