Known Issue

Using the Traffic Management Shell (tmsh) to create a data group record with an empty string data value with tmsh may generate an invalid string value.

This issue occurs when all of the following conditions are met:

  • You create or modify a data group using the tmsh utility.
  • Your data group uses the String type.
  • You create or modify a record where the String data value is empty.

Impact

You save the empty string data value as the word none.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing a data group using the tmsh utility with the all-properties flag, the empty string data value is set with the word none.

    For example:

    A data group (dg-test) is created with the following tmsh command syntax:

    tmsh create /ltm data-group internal dg-test type string records add { k1 {} k2 { data nada } }

    The newly created data group configuration displays with the following tmsh command syntax:

    list /ltm data-group internal dg-test

    ltm data-group internal dg {
        records {
            k1 { }
            k2 {
                data nada
            }
        }
        type string
    }

    The newly created data group configuration displays with the following tmsh command syntax that includes the all-properties flag:

    list /ltm data-group internal dg-test all-properties

    ltm data-group internal dg {
        app-service none
        description none
        partition Common
        records {
            k1 {
                data none
            }
            k2 {
                data nada
            }
        }
        type string
    }

    Note: The string data value for the data group record k1 is set to none.

  • Configurations that depend on empty data group data values may not function as expected.

Workaround

To work around this issue, you can use the Configuration utility to create or modify the data group.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
