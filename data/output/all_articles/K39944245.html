Known Issue

Attempting to load a configuration that references an encrypted Secure Sockets Layer (SSL) key file may fail if the first line of the SSL key file is blank. 

This issue may occur when an affected configuration is present on a system running BIG-IP 11.3.0 or earlier, and you upgrade to BIG-IP 11.4.0 through 12.1.1. If this issue occurs during an upgrade, the system will not load the configuration under the new software version, and will remain inoperative.

This issue occurs when all of the following conditions are met:

  • The first line of an SSL key file is blank.
  • The BIG-IP system attempts to load a configuration that references this SSL key file.

Impact

The BIG-IP system remains in an inoperative state and does not pass traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP configuration fails to load.
  • You view an error message in the /var/log/ltm file that appears similar to the following example:

    01070711:3: basic_string::compare

Workaround

To work around this issue, you can remove the newlines at the beginning of the affected SSL key files.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
