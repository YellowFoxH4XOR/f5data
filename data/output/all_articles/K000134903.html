K000134903: Caution when manually activating FCP licenses and correct use of dossier and license output.

Type
Support Solution
Published
2023-06-02
Updated
2026-08-06
Source
https://my.f5.com/manage/s/article/K000134903

Description

When manually licensing FCP (Cat) licenses, it is important that you copy and paste the correct dossier to the F5 Activate server and even more so to ensure that you do not use the same output license in the wrong license sku offering.
Each sku offering has its own unique dossier, this should be activated in Activate F5 web portal and the license file which is created should be copied only to that sku.

Environment

  • BIG-IQ
  • FCP-Cat licenses
  • BIG-IP

Cause

You are able to paste the same license file (generated by activate f5) into all of the SKU offerings.
This will create base license output for the CAT or Load regardless to which offering you try and assign to a Big-IP.

 Recommended Actions

  1. Please follow detailed steps in K15420056 (see additional information link below)
