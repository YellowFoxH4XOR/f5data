Description

 

You see the message in GUI - Device Management > Traffic Groups:

The traffic group configuration on this device does not match with other devices. Sync the configuration between devices.

An issue occurs even if devices in HA cluster are In Sync status.

 

Environment

 

  • BIG-IP
  • HA cluster
  • In sync status
  • Message suggesting that synchronization is needed
  • ConfigSync does not resolve the issue

 

Cause

 

Traffic Groups CRC inconsistency due to wrong value in database.

 

Recommended Actions

 

1 - Review /var/log/sodlog looking for config_crc and its values

 i.e.:

Traffic Group: /Common/traffic-group-1 tg_load 1 state stby

--- Start Peers & Mates ---

10.10.10.1

slot 0     seq 9193359 no_chg_sec 0 alive yes next_active false

           tg_load 1 na_load 0 tg_score 6614 ha_order 2 state act

           config_crc 0xcf75f99d substate No_subst

           cmd no_cmd target_cmd no_cmd target_ip ::

           dev_cap 0 dev_load 1 ha_score -1

       Recv from (cnt): 10.10.10.2 (51001222) 192.168.20.1 (51020911) 

10.10.10.2

slot 0     seq 51048060 no_chg_sec 0 alive no next_active true

           tg_load 0 na_load 1 tg_score 6630 ha_order 1 state stby

           config_crc 0x6afa2f00 substate No_subst

           cmd no_cmd target_cmd no_cmd target_ip ::

           dev_cap 0 dev_load 1 ha_score -1

       Recv from (cnt): self (51048060) 

 

2 - Log in to CLI and execute a command on all devices from cluster:

 

tmsh list /sys db failover.crcvalues value

 

Output from a command will be one of below:

Correct:

 

sys db failover.crcvalues {

   value "agree"

 

Not correct:

 

sys db failover.crcvalues {

   value "disagree"

 

When you notice value "disagree" on any device, please proceed with point 3

 

3 - From CLI level, please execute a command - on all machines with the wrong value:

 

tmsh modify sys db failover.crcvalues value agree

 

Impact of this procedure: It should not have any negative impact for traffic processing. 

 

4 - Perform a Full ConfigSync – push the config to the group.

For more information about ConfigSync, refer to K13920: Performing a ConfigSync using the Configuration utility.

Additional Information

Please always remember to backup configuration to UCS file before applying any changes in configuration. Please refer to article K4423: Overview of UCS archives
