Issue

Error Message

warning mcpd[<PID>]: 01071323:4: Vlan (/Common/<vlan_name>:<tag>) is configured, but NOT on hypervisor allowed list.

  • <PID> is the process ID
  • <vlan_name> is the name of the vlan
  • <tag> is the vlan tag assigned to the vlan

For example:

Jul 14 08:38:31 BIG-IP-01 warning mcpd[7147]: 01071323:4: Vlan (/Common/vlan33:33) is configured, but NOT on hypervisor allowed list.

Message Location

You may encounter this message in the following locations:

  • /var/log/ltm file on the vCMP Guest.
Description

This message may occur when all of the following conditions are met:

  • You have a vCMP system.
  • You configured a vlan directly on the vCMP Guest
  • The VLAN is not configured on the host or it is not assigned to this guest

Impact

Communication through that vlan may fail.

Recommended Actions

In vCMP Deployments, VLANs and interfaces are configured on the vCMP host (hypervisor) system. The configured VLANs are then available for selection on the vCMP guest system as needed. F5 recommends creating all needed vlans on vCMP Host and then assigning them to respective Guests.
