K3392: Resetting the status of virtual servers that were marked gray after running the 3-DNS auto-discovery process

Topic

Running the 3-DNS Controller's auto-discovery process may result in multiple routers or incorrect routers associated with BIG-IPs.

If the wrong router is associated with a BIG-IP, all of the virtual servers that are configured on that BIG-IP will be marked gray.

Note: For more information, refer to K2325: Reasons why 3-DNS may display objects with an unusable (gray) status indicator.

To fix this issue, you must perform the following two procedures:

  • Disabling autodiscovery and link discovery to prevent 3-DNS from discovering the router(s)
  • Removing the discovered router(s) from the wideip.conf file to allow the virtual server to be properly reported

Disabling autodiscovery and link discovery to prevent 3DNS from discovering the router(s)

  1. From the 3-DNS Controller Configuration utility, click Servers.
  2. Click BIG-IP.
  3. Click the affected BIG-IP.
  4. Clear the autodiscovery check box.
  5. Clear the link discovery check box.

Removing the discovered router(s) from the wideip.conf file to allow the virtual server to be properly reported

  1. Log in to the command line.
  2. Using a text editor, edit the /config/3dns/etc/wideip.conf file.
  3. Locate the Routers section.
  4. Delete the IP address for each incorrect router.
  5. Save and exit the file.
  6. To restart 3-DNS with the new /config/3dns/etc/wideip.conf file, type the following command:

    3ndc restart

You may need to perform this process again if you upgrade or reinstall the 3-DNS Controller software.
