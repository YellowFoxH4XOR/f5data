Topic

You should consider using this procedure under any of the following conditions:

  • You want to install the BIG-IP software or hotfix to a specific slot because previous installation attempts using the Configuration utility or TMOS Shell (tmsh) failed.
  • You want to reinstall a specific slot because you cannot fix file system errors with the fsck utility.

    If other slots encounter similar issues that you cannot fix with the fsck utility, you should consider reinstalling the BIG-IP system using the procedures describe in K13117: Performing a clean installation of BIG-IP 11.x - 14.x or Enterprise Manager 3.x.

Description

The Maintenance Operating System (MOS) is an additional boot location that is automatically created when you install the BIG-IP system. MOS is used mainly for maintenance purposes and for performing an installation using local media for scenarios described in the Topic section. For a list of maintenance tasks that you can perform in the MOS environment, refer to K14245: Overview of the recovery tasks performed from the MOS (11.x - 14.x).

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access the serial console.
  • You have a copy of the desired BIG-IP software or hotfix that resides on the local file system.
  • You have a copy of the BIG-IP user configuration set (UCS) archive file residing on another remote system.

Procedures

Using MOS to perform a local installation

You can perform an installation using local media while booted in the MOS environment. To do so, perform the following procedure:

Impact of procedure: The BIG-IP system does not process traffic while booted into the MOS environment. F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Log in to the BIG-IP command line.
  2. Verify the MD5 checksum of the desired BIG-IP software or hotfix that resides on the local file system (/shared/images directory).

    For information about verifying the MD5 checksum, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.

  3. To determine the device name listed in the /dev/mapper/ path for the file system where the software or hotfix resides, use the following command syntax:

    df -h | grep <filesystem name>

    For example, for software or a hotfix that resides in the /shared/images directory, type the following command:

    df -h | grep share

    In addition, the /dev/mapper/ path for the /shared file system is /dev/mapper/vg--db--sda-dat.share.1:

    /dev/mapper/vg--db--sda-dat.share.1 24G 1.3G 22G 6% /shared

  4. Access the BIG-IP serial console using a client terminal console and log in as root.
  5. To reboot the BIG-IP system into the MOS environment, type the following command:

    mosreboot

  6. After the system boots into the MOS environment, create a temporary directory with the name /mos_install by typing the following command:

    mkdir /mos_install

  7. To mount the device that hosts the file system determined in step 3 to the temporary /mos_install directory, use the following command syntax:

    mount <device name> /mos_install

    Using the example in step 3, you would type the following command:

    mount /dev/mapper/vg--db--sda-dat.share.1 /mos_install

  8. To copy the software or hotfix image to the /tmp directory, use the following command syntax:

    cp /mos_install/<path to image> /tmp

    For example:

    cp /mos_install/images/BIGIP-11.2.1.797.0.iso /tmp

  9. When the software or hotfix image copy is complete, unmount the /mos_install directory by typing the following command:

    umount /mos_install

  10. To change the current working directory to the /tmp directory, type the following command:

    cd /tmp

  11. To initiate the installation, use the following command syntax:

    image2disk <--hotfix> --nosaveconfig --instslot=<slot> <software.iso>

    For example, to install BIGIP-11.2.1.797.0.iso to the HD1.2 slot, you would type the following command:

    image2disk --nosaveconfig --instslot=HD1.2 BIGIP-11.2.1.797.0.iso

    For a hotfix installation example, to install Hotfix-BIGIP-11.1.0-2027.0-HF2.iso to the HD1.1 slot, you would type the following command:

    image2disk --hotfix --nosaveconfig --instslot=HD1.1 Hotfix-BIGIP-11.1.0-2027.0-HF2.iso

  12. When the installation is complete, reboot the system by typing the following command:

    reboot

  13. When the system is up and running, use the Configuration utility to configure the system with a management IP address by typing the following command:

    config

  14. Follow the on-screen instructions to complete the configuration and proceed to use the Configuration utility to perform the first-time configuration. Alternatively, you can perform a first-time configuration for the system using the procedures described in K13369: Performing a first-time configuration from the command line (11.x - 14.x)
  15. Optional: If required, you can upload and restore the BIG-IP UCS archive file to the BIG-IP system. For more information, refer to K175: Transferring files to or from an F5 system and K13132: Backing up and restoring BIG-IP configuration files (11.x - 13.x).
