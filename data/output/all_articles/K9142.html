The Load Status feature allows external devices to monitor the session statistics and load on a FirePass controller in a secure manner. You can configure the security settings for the load statistics page by performing the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Monitoring: Load Status Access Security page.

    Note: In a FirePass failover pair (high availability) configuration, the Load Status Access Security page is only available on the active controller. In a FirePass cluster configuration, the Load Status Access Security page is only available on the primary cluster node.
  3. In the New Password and Confirm New Password fields, enter the password that will be used to access the load statistics page.

    Note: The logon name is set to gtmuser and cannot be changed.

    Alternately, select the Do not use password for Load Status query check box to bypass password protection.
  4. Click the Update button.
  5. Optionally, in the Load Status Access Security section of the page, enter the IP addresses that are allowed to access the load statistics page. By default, all IP addresses are allowed to access the load statistics page.
  6. Click the Apply button.

To view the FirePass controller load statistics, type the following URL in your browser, replacing <FirePasshostname> with the hostname or IP address of the FirePass controller:

https://<FirePassHostname>/load_status.php

A page similar to the following example appears:

Session Usage: 1 / 100
Session Usage Percentage: 1%
1-Min Load Average: 0.07
Size of the biggest Database table: 12k

You must manually refresh the browser page to update the statistics. All statistics are reported in real time, with the exception of Session Usage. The Session Usage statistic is updated every 60 seconds.

Note: The load_status.php page is accessible only from Web Services configured with User Logon access. They are not accessible from Admin only Web Services.

In a high availability configuration, the security settings for the load statistics page are configured on the active controller in the failover pair. The Device Management: Monitoring: Load Status Access Security page is not available on the standby controller. In a cluster configuration, the security settings for the load statistics page are configured on the primary cluster node. The Device Management: Monitoring: Load Status Access Security page is not available on the secondary cluster nodes.

The Load Status feature was introduced in FirePass version 6.0.1; it is frequently used in conjunction with a BIG-IP GTM deployment.

Note: For information about deploying a FirePass controller with a BIG-IP GTM system, refer to the Deploying The FirePass Controller with the Big-IP GTM System Deployment Guide.

Note: For more information about the Load Status feature, refer to the FirePass Controller Administrator Guide.
