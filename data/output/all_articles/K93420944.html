Description

Find the users which are currently logged into the BIG-IP and kill a specific SSH or console management connection.

Environment

  • SSH or console management connections

Cause

None

Recommended Actions

Follow the steps from the example below in order to kill a management connection:

  1. Identify your connection. You need to verify your terminal ID, in order not to kill you current session:

     

    [root@BIGIP-A:Active:In Sync] config # tty
    /dev/pts/0

  2. Identify the management connection you want to kill:

     

    span class="example2">[root@BIGIP-A:Active:In Sync] config # w
    10:56:55 up 2 days, 11:15,  3 users,  load average: 10.12, 10.11, 9.61
    USER     TTY      FROM           LOGIN@       IDLE   JCPU   PCPU WHAT
    root     tty1                    10:44        12:15  0.01s   0.01s -bash
    root     pts/0    10.6.12.18     10:27        7.00s  0.20s   0.17s -bash
    root     pts/2    10.7.14.21     10:56        5.00s  0.01s   0.01s -bas

    Note: In the current example three management connections have been made on the device. A console connection ( tty1 ) and two SSH connections ( pts/0 and pts/2 ). pts/2 is the SSH management connection which we will terminate.

  3. Get the process id of the connection:

     

    [root@BIGIP-A:Active:In Sync] config # ps -f | grep 'pts/2' | grep -viE 'grep'
    root     17048  3843  0 10:56 ?        Ss    0:00 sshd: root@pts/2
    root     17131 17048  0 10:56 pts/2    Ss    0:00 -bash
    root     28982 17131  0 11:15 pts/2    Sl+   0:00 tmsh

    Note: On this example, The process ID of the SSH connection on pts/2 pseudo terminal is 17048.

  4. Kill the SSH management connection under process ID 17048:
           kill -9 17048

    

Additional Information

The output of the commands which were used in the previous example will vary from device to device. There's more than one way to kill a process in Linux. 

For example: To kill the pseudo-terminal itself, run the below command. This will kill all the process being run on the pseudo-terminal

# pkill -9 -t pts/2

You should replace the required values of the commands accordingly before proceeding with this procedure.
