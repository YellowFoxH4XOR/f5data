Description

Deployed a BIG-IP tenant on rSeries using the ALL image.

Now trying to install a new image or hotfix, but there is only one HD1.1 boot location.

How do we fix this issue?

Environment

  • F5OS tenant
  • Upgrading

Cause

This is expected. A single boot location (HD1.1) exists by default in BIG-IP tenants. Additional boot locations can be created in most cases.

Recommended Actions

The ALL image can accommodate two boot locations if created at the default storage-size.

To create a second boot location, enter 2 in the GUI when installing the software to a target boot location. This would create HD1.2 and install the selected software on to it.

Alternatively, use the create-volume option from the command line:

install sys sof <image|hotfix> <ISO> create-volume volume HD1.x

Additional Information

To create further boot locations, you can add additional storage space to the tenant from F5OS.

You can confirm this space is available in the tenant by reviewing the output of the vgs command.
