Known Issue

This is the result of a known issue. In order to upload a Citrix client to the FirePass controller, the Citrix client must be named wficac.cab or wficat.cab. This filename restriction is incompatible with newer versions of the Citrix client, which may be named wfica.cab or icaweb.cab.

F5 Product Development tracked this issue as CR76593 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix 600-13 has been issued for FirePass version 6.0.0 and cumulative hotfix 601-1 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around the issue by configuring an alternate download location for the Citrix client on the Application Access : Terminal Servers : Global Settings page. To do so, perform the following procedure:

  1. On the Application Access : Terminal Servers : Global Settings page, click the Citrix web-site button.
  2. Enter a URL in the URL field.

    For example:

    http://download2.citrix.com/FILES/en/products/CPSICAClientsMulti/icaweb.cab

  3. Click Update.

Users would then download the Citrix client from the Citrix web site instead of from the FirePass controller.

For more information about configuring an alternate download location for the Citrix client, refer to K5891: Downloading and installing the Citrix client.
