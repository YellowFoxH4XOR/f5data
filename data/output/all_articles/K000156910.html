K000156910: Modifying VLAN on a Terraform managed F5OS Tenant removes other tenant managed by Terraform.

Type
Support Solution
Published
2025-12-18
Updated
2025-12-18
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000156910

Description

You can observe that Terraform managed F5OS tenant got removed, after modifying VLAN on 2nd Tenant via Terraform Provider.

Environment

  • F5OS Tenants managed via Terraform Provider
  • Modifying VLAN

Cause

BUG INFRAANO-2010

More details can be found on F5Networks GitHub:
bug: Modifying VLAN on a TF-managed tenant deletes other manually created tenants

Recommended Actions

Problem is fixed in Terraform Provider version 1.9.0.

Make sure that you're using the latest release of Terraform provider.

Additional Information

None
