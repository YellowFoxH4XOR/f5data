Known Issue

This is the result of a known issue. The BIG-IP ASM reporting server encloses part of the <key>=<value> section of the URI with double quotes ( "" ) when sending requests to a remote logging server. This behavior causes parsing issues when the value itself contains double quotes.

For example, the BIG-IP ASM reporting server encloses the requested query string a="<SCRIPT>" with double quotes when sent to the remote logging server:

a=""<SCRIPT>""

This behavior causes issues when the remote logging server regards the double quotes as delimiters, and not as part of the value.

F5 Product Development tracked this issue as CR120614 and it was fixed in BIG-IP ASM version 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
