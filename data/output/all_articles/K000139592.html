Security Advisory Description

An issue was discovered in libxml2 before 2.10.4. When hashing empty dict strings in a crafted XML document, xmlDictComputeFastKey in dict.c can produce non-deterministic values, leading to various logic and memory errors, such as a double free. This behavior occurs because there is an attempt to use the first byte of an empty string, and any value is possible (not solely the '\0' value). (CVE-2023-29469)

Impact

This vulnerability allows a remote, unauthenticated attacker to cause memory corruption that can lead to a denial-of-service (DoS) on the affected F5 products. There is control plane and data plane exposure.

Mitigation

BIG-IP

To mitigate this vulnerability, you should accept or use XML files from only trusted sources. This applies to XML Content Based Routing, the wap monitor, external monitors, and AAM image optimization.

To learn more about the vulnerable BIG-IP components to help understand how to implement the mitigation, refer to the following:
