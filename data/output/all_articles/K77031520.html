Description

Unexpectedly unit rebooted and failover is initiated.
When you check /var/log/ltm, there is no indication why it is rebooted.
But in /var/log/sel has further information, similar to the below:

MM/DD/YY hh:mm:ss INF BMC  Power Supply #1c Input Lost 6f [03 ff ff]
MM/DD/YY hh:mm:ss INF BMC  Power Supply #1d Input Active ef [03 ff ff]

And Console Output would have

Bay power fault detected, retries=0
Bay power fault detected, retries=1
Bay power fault detected, retries=2
Fault clear attempts failed. Please power cycle to retry. 

Environment

  • BIG-IP iSeries any version
  • Power Supply issue
  • Unexpected reboot
     

Cause

Power Supply did not receive power source or Power Supply is faulty.
 

Recommended Actions

  1. Check the following command output

    tmsh show sys hardware

    And check Power Supply Status like below:

    Chassis Power Supply Status
    Index  Status           Current
      1      up               AC
      2      up               AC
     
  2. If the Current status is showing "down", then take qkview and raise support case to F5 Support.
