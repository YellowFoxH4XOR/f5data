Known Issue

The BIG-IP system experiences higher than expected CPU usage when you use DNS cache.

This issue occurs when all of the following conditions are met:

  • You configure DNS cache with any of the three available types: Resolver, Validated Resolver, or Transparent.
  • You are using DNS cache on a VIPRION system with at least two or more blades.

Impact

The BIG-IP system experiences higher than expected CPU usage.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the BIG-IP system uses DNS cache, the CPU usage is higher than expected.
