Issue

The global Secure Sockets Layer (SSL) session cache size setting limits the total number of cached SSL sessions among all SSL profiles. For BIG-IP 11.4.1 and earlier, the global SSL session cache size setting is not configurable.

Note: Beginning in BIG-IP 11.5.0, the global SSL cache size limit becomes a configurable setting and can be configured between 262,144 sessions and 4,194,304 sessions. For more information, refer to K16303: The BIG-IP global SSL session cache can be increased to 4,194,304 sessions.

Old Behavior

In versions prior to BIG-IP 9.1.3, 9.4.7, and 10.1.0 the BIG-IP global SSL session cache is limited to 32k (32,768) sessions.

When the BIG-IP system processes a high number of SSL transactions per second, the 32k global SSL session cache size may not provide an adequate number of stored SSL sessions.

New Behavior

Beginning in BIG-IP 9.1.3, 9.4.7, and 10.1.0, the global SSL session cache size was increased to 256k (262144) sessions per Traffic Management Microkernel (TMM). For example, a system with eight cores running eight TMM processes support 8 * 256k = 2048k (2097152) sessions globally.

Additionally, the global SSL session cache is increased in Hotfix-BIG-IP-9.3.1-HF-2 issued for BIG-IP LTM 9.3.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

F5 Product Development tracked this change as ID 213370 (formerly CR34771).

Impact

When the BIG-IP system processes a high number of SSL transactions per second, the increased 256k per TMM global SSL session cache size is more likely to provide an adequate number of stored SSL sessions.

Note: The global SSL session cache is shared among all SSL profiles actively in use by virtual servers. The total number of stored sessions between all SSL profiles cannot exceed 262,144. When the global cache limit is reached, the oldest SSL session entry (regardless of profile association) is evicted and replaced with the new session ID. For information about configuring SSL cache settings for the SSL profiles, refer to K6767: Overview of the BIG-IP SSL session cache profile settings.

Note: The BIG-IP configuration validator allows you to configure the SSL session cache size for a single profile with a value in excess of the maximum global cache size. For more information, refer to K11213: SSL profile session cache size setting can be configured larger than global session cache size.

Note: When the capacity of the SSL Session cache is exhausted, the SSL::sessionid iRule command returns a string of 64 zeroes. This behavior may lead to collisions and unintentional session sharing when using the SSL::sessionid command for persistence. For more information, refer to the SSL::sessionid command documentation on DevCentral. A separate DevCentral login is required to access this content.
