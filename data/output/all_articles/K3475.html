Topic

The BIG-IP system may not respond to requests for a self IP address.

Description

To enhance system security, a BIG-IP self IP address does not respond to requests arriving on a Virtual Local Area Network (VLAN) on which you do not have the self IP address configured.

However, the BIG-IP self IP address may respond to requests if any of the following conditions are met:

  • The request arrives on the VLAN on which the self IP address is configured.
  • The request arrives on the VLAN on which a virtual server is configured, using the same IP address as a configured self IP address.

    Note: By default, the BIG-IP system enables all VLANs when you create a virtual server.

The following example shows a configuration in which the self IP addresses and a virtual server are enabled on the external VLAN:

self 10.10.65.65 {
netmask 255.255.255.0
vlan internal
}
self 172.16.66.66 {
netmask 255.255.255.0
vlan external
}
virtual http_vip {
pool http_pool
destination 10.10.65.65:http
ip protocol tcp
vlans external enable
}
virtual http_vip {
pool http_pool
destination 172.16.66.100:http
ip protocol tcp
vlans external enable
}

Note: In a high-availability (HA) environment, it may appear as though the standby unit erroneously responds to Internet Control Message Protocol (ICMP) ping packets that arrive on the wrong VLAN. For example, if a ping arrives on VLAN 100 with a destination of a self IP configured on the standby system in VLAN 200, you would not expect the standby system to respond to the packet because the ping arrived on the wrong VLAN. However, if a wildcard forwarding virtual server is listening on VLAN 100, it forwards the packet to its destination (in this case, to the standby unit on VLAN 200) just as it would any other IP packet. The standby unit receives the packet and then responds to it because it arrived on the correct VLAN.

The following table shows the results you can expect from the previously described configuration when you send ICMP requests to the self IP addresses from various network locations, relative to the BIG-IP system.

OriginDestinationResult
10.10.65.x (or forwarded by router on internal VLAN)172.16.66.66BIG-IP system ignores request
10.10.65.x (or forwarded by router on internal VLAN)10.10.65.65BIG-IP system responds
172.16.66.x (or forwarded by router on external VLAN)172.16.66.66BIG-IP system responds
172.16.66.x (or forwarded by router on external VLAN)10.10.65.65BIG-IP system responds
