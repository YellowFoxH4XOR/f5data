Known Issue

The BIG-IP system may report an error when creating a virtual server.

This issue occurs when the following condition is met:

  • You choose the following settings when creating a new virtual server:
    • In the Type list, you select Stateless
    • In the Protocol list, you select a protocol other than UDP

This is expected behavior, as the stateless virtual server applies to User Datagram Protocol (UDP) traffic only.

Impact

Users are unable to create a stateless virtual server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to create a stateless virtual server, you receive an error message similar to the following example:

    0107147b:3: Illegal to have a stateless virtual server attached to a TCP profile

Workaround

To work around this issue, you can choose UDP as the protocol for the stateless virtual server.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
