Description

  • A virtual server is configured with an ASM policy and a Bot defense profile
  • Local and remote logging are configured for both ASM and Bot defense events
  • Bot defense and ASM event logs can be seen locally on the device
  • Only ASM event logs are being received on the Splunk server and no Bot Defense logs.
  • The  same Splunk server is used for both ASM and Bot defense and is reachable using the Management route.

 

Environment

BIG-IP ASM
Bot Defense
Remote logging

Cause

Bot Defense uses High speed logging ( HSL) and this has been configured to use a tmm interface although the splunk server is reachable via the management interface.

Note: You can follow the steps in K86480148 to determine the interface that the BIG-IP system uses to reach the remote syslog server

Recommended Actions

To resolve the issue, you can configure High Speed Logging for Bot Defense via the management Interface or you can change routing for your Splunk server to use a tmm interface instead of the management Interface. 

The complete steps for configuring High Speed Logging (HSL) for Bot Defense are available in K09439152 .
To configure High Speed Logging via the management Interface, you need to use option (b) at step '2'

  2. Go to System ›› Logs : Configuration : Log Destinations and create one of these two types of Destinations depending on whether you want to use TMM or management for the traffic.
   b. To use the management interface (only one IP can be used in this method)
      Enter IP and port of logging server.
      Select Protocol.
      Click Finished.
