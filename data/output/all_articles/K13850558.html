Description

When you enabled Rapid Response in DNS profile, BIG-IP DNS may not respond to queries which do not match Wide IP or DNS Express Zone, even though we have a record matching that query in the ZoneRunner zone.

For example:
ltm profile dns /Common/DNS-Test-profile {
    app-service none
    avr-dnsstat-sample-rate 1
    cache none
    defaults-from /Common/dns
    dns64 disabled
    dns-security none
    enable-cache no
    enable-dns-express yes
    enable-dns-firewall no
    enable-dnssec no
    enable-gtm yes
    enable-hardware-query-validation no
    enable-hardware-response-cache no
    enable-logging yes
    enable-rapid-response yes
    log-profile /Common/logging-DNS-queries
    process-rd yes
    process-xfr no
    rapid-response-last-action drop
    unhandled-query-action allow
    use-local-bind yes
}

Environment

  • BIG-IP DNS with those records configured in the ZoneRunner zone
  • Those records do not exist in wide IP or DNS Express
  • Rapid Response mode is enabled

Cause

With the Rapid Response Mode enabled, only the GSLB and DNS Express features function in the DNS profile. Meanwhile, other configured DNS features, such as BIND, don't take effect. This means that BIG-IP can provide a response only if the query matches wide IP or DNS Express Zone. The BIG-IP will not provide response from BIND.

Recommended Actions

  1. Set the "rapid-response-last-action" to "allow". This will make the querys that are unmatched GSLB and DNS express to use the BIND.

Note: This action might lower the DoS protection.

For example:

ltm profile dns /Common/DNS-Test-profile {
    app-service none
    avr-dnsstat-sample-rate 1
    cache none
    defaults-from /Common/dns
    dns64 disabled
    dns-security none
    enable-cache no
    enable-dns-express yes
    enable-dns-firewall no
    enable-dnssec no
    enable-gtm yes
    enable-hardware-query-validation no
    enable-hardware-response-cache no
    enable-logging yes
    enable-rapid-response yes
    log-profile /Common/logging-DNS-queries
    process-rd yes
    process-xfr no
    rapid-response-last-action allow  
    unhandled-query-action allow
    use-local-bind yes
}

  1. If you really don't want to use BIND, you can config the affected zones/records into GSLB or DNS express.

To configure zones/records in GSLB, you may refer to About wide IPs.

To configure zones/records in DNS express, you may refer to Configuring DNS Express.
