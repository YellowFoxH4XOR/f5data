Description

Using remote authentication you cannot access the advanced shell (bash).

Environment

  • Remote authentication (e.g. TACACS, RADIUS, etc.)
  • Remote user without the 'Administrator' role

Cause

By default, BIG-IP allows only remote users with Administrator role to access bash. Other remote user roles cannot be given direct access to advanced shell as they do not have an account defined in the /etc/passwd file, so a custom shell cannot be defined. As a result, the shell for all non-admin remote user roles defaults to tmsh. 

    Recommended Actions

    To access bash with a remotely authenticated user you can run the following command:

    run /util bash

    Additional Information

    If you additionally get the following error:

    Syntax Error: "bash" unexpected argument

    It means your user doesn't have the 'Administrator' user role, you can change the role of remotely authenticated users by following these next steps:

    1. Login to the configuration utility (web ui) using an Administrator account
    2. In the upper-right corner of the screen, confirm that the Partition list is set to the partition in which the user account that you want to modify resides
    3. On the Main tab, click System > Users > Remote Role Groups
    4. Select the Remote Role Group you want to edit
    5. Set the 'Assigned Role' to Administrator
    6. Make sure the terminal access is set to 'tmsh'
