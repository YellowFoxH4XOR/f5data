Known Issue

This is the result of a known issue. In BIG-IP ASM versions 10.2.0 and 10.2.1, enabling CSRF protection may cause HTML anchors to function incorrectly. An anchor element that does not have a valid URL value for the href attribute may not function due to the CSRF feature adding the CSRT token to anchors. 

For example an HTML page may contain the following JavaScript code to submit a form:

<a href="#" onclick="document.forms['my_form'].submit">SUBMIT</a>

When a user navigates to the page containing the anchor above with a link that appears similar to the following example, the BIG-IP ASM CSRF feature will insert the CSRT token, as detailed in K11930: The CSRF protection feature inserts the CSRT parameter into URIs embedded in response pages:

http://www.domain.tld/page.php?a=10

As a result, the feature rewrites the anchor in the response to appear as follows:

<a href="http://www.domain.tld/page.php?a=10&csrt=123325443646#" onclick="document.forms['my_form'].submit">SUBMIT</a>

When the user clicks this link, they will be redirected back to page.php, rather than submitting the form as expected.

This behavior is only known to occur when the end user is accessing the page with Microsoft Internet Explorer.

F5 Product Development tracked this issue as ID 347853 and it was fixed in BIG-IP ASM 10.2.2. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP 10.x systems.

For information about downloading software from F5, refer to K167: Downloading software from F5.

Workaround

You can work around the issue by ensuring the HTML document contains the following doctype declaration:

<!DOCTYPE html PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd">

Note: For general information about the CSRF prevention feature, refer to the Manually Configuring Security Policies chapter of the Configuration Guide for BIG-IP Application Security Manager and K11903: BIG-IP ASM violation: CSRF Attack detected.
