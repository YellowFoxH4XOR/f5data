K000151036: Unable to authenticate AD group members to F5OS using LDAP

Type
Support Solution
Published
2025-06-20
Updated
2025-06-20
Source
https://my.f5.com/manage/s/article/K000151036

Description

Members of the AD group are unable to authenticate to F5OS. The group has a gidNumber assigned, but no gidNumbers are directly assigned to users who are members of the group.

Environment

  • remote user authentication
  • LDAP
  • F5OS before 1.8.0

Cause

Using group membership for role assignment is only available starting in F5OS 1.8.0. However, even on 1.8.0, role assignment based on group membership is broken for TLS/SSL LDAP connections due to ID1660961.

Recommended Actions

Add in the required uidNumber / gidNumber attributes to each user that requires access to F5OS.

Additional Information

None.
