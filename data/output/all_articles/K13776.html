Topic

The IP address intelligence feature allows you to block requests that originate from black-listed IP addresses, which are updated by a subscription service. The subscription period ends without notification.

Description

When a given subscription period ends, the IP address intelligence service no longer receives updates from the subscription service, and the IP address database becomes outdated. There are no symptoms that the subscription service is no longer updating the data. In addition, the IP intelligence feature continues to function, but with outdated data.

Recommendations

You can manually inspect the expiration date for the subscription service by performing either of the following procedures:

Using the Configuration utility to inspect the expiration date

  1. Log in to the Configuration utility.
  2. Go to System > License.
  3. Under Active Modules, locate the entry for IP Intelligence.

    Note: Licenses generated prior to Aug 8, 2017 refer to this module as IPI Subscription.

  4. The expiration date is listed beneath the IP Intelligence (or IPI Subscription) entry.

    For example:

    Subscription expires after Dec 30, 2019

Using the command line to inspect the expiration date

  1. Log in to the command line.
  2. Type the following command:

    grep trust /config/bigip.license

  3. The system returns an IP intelligence license key value that appears similar to the following example:

    20191230_subscr_trusted_ip : 290345338

    The first entry in the line is the expiration date in the following format: YYYYMMDD
