K000149721: Changed the variable http url length but Configuration Utility continues to tell me to restart ASM

Type
Support Solution
Published
2025-02-09
Updated
2025-02-09
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149721

Description

You attempted to change asm variable ecard_max_http_req_uri_len, but even after restarting ASM the continue to see:

"Note: You must perform a 'tmsh restart sys service asm' for this change to take effect! If you are using a device group you must perform 'tmsh restart sys service asm' on all members of the device group for this change to take effect!"

Environment

  • ASM
  • internal database variable 'ecard_max_http_req_uri_len'

Cause

The warning note regarding restarting ASM is not dynamic and will always remain

Recommended Actions

ensure that you have actually restarted asm by checking the /var/log/ltm for a line like:

Feb 8 16:08:12 BIGIP1.example.com root[11001]: -bash ==> /bin/bigstart restart asm

Additional Information

None
