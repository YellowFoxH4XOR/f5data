Known Issue

The iprepd process may leak memory when using a forward proxy server.

This issue occurs when all of the following conditions are met:

  • The IP address intelligence service is enabled.
  • The BIG-IP ASM system is configured to connect to the internet using a forward proxy server.

    Note: For more information about configuring a forward proxy server, refer to the Overview: Enabling IP address intelligence chapter of the BIG-IP Local Traffic Manager: Implementations guide.

    Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  • The proxy host prevents a successful Secure Sockets Layer (SSL) handshake with the IP reputation database server.

    Note: This issue is similar to K17498: The iprepd or merged processes may leak memory under certain conditions. While the conditions are slightly different, the root cause for both issues is connectivity to the IP reputation database server.

Impact

A slow memory leak occurs, which may eventually affect other services and overall system performance.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP ASM logs messages to the /var/log/ltm file that appear similar to the following example:

    err iprepd[1234]: 015c0004:3: Ssl error # 2
    err iprepd[1234]: 015c0004:3: SendReceive returns error -1 (recv error)

  • BIG-IP ASM is not able to connect to the IP reputation database server using the tmsh show /sys iprep-status command:

    -----------------------------------------------------------------------
    Sys::IP Reputation Database Status
    -----------------------------------------------------------------------
    Last time the server was contacted for updates 10/24/2015 06:55:18
    Last time an update was received N/A
    Total number of IP Addresses in the database 0
    Number of IP Addresses received in the last update 0

Workaround

To work around this issue, you will need to either determine the cause of the SSL handshake issues at the proxy host, or disable the IP address intelligence service.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
