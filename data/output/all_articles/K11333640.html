Description

You are using Remote Authentication as main method of authentication with Fallback to Local enabled.

You still want the other locally created users to work at all times, (other than admin and root). For this, you have created them using tmsh/GUI and then added them manually to this file: /config/bigip/auth/localusers ( this file is read only )

These local users randomly disappear within a few days from /config/bigip/auth/localusers.

Environment

  • Using Remote Authentication
  • Unit Rebooted

Cause

The file /config/bigip/auth/localusers is auto-generated and should not be manually edited. After a system reboot it is expected that this configuration will be lost.

Recommended Actions

None. This is expected behaviour, when the system has Remote Authentication enabled, it will only fallback to local users, if this option is enabled, and if the Remote Authentication servers are unreachable. The only local users that will always be available are admin and root.

Note: You can workaround this, to allow local and remote users to work at all times, by creating a startup script to add the local users to /config/bigip/auth/localusers on every reboot. However, this is not officially developed or supported by F5.

Additional Information

When opening the file /config/bigip/auth/localusers with a text editor, you can see this warning message:

# THIS IS AN AUTO-GENERATED FILE - DO NOT EDIT!!!
#
# Use the tmsh shell utility to make changes to the system configuration.
# For more information, see tmsh -a help auth user.
root
admin
