Known Issue

The BIG-IP APM session ends when the access profile Maximum Session Timeout is set to 0 (zero).

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policies are configured to use the Maximum Session Timeout value of 0 (zero).
  • The BIG-IP APM user access sessions exceed 604,799 seconds (seven days).

    Note: The Configuration utility Help tab states the use of 0 means no limit.

Impact

The BIG-IP APM session ends.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP APM session ends after 604,800 seconds, regardless of session traffic.
  • The BIG-IP APM system requires users to re-login to the BIG-IP APM access profile after seven days.

Workaround

To work around this issue, you can set the Maximum Session Timeout value higher than 604,800 seconds. To do so, perform the following procedure:

Impact of workaround: User access sessions will timeout at the value set for the Maximum Session Timeout of the access profile.

Using the Configuring utility to set the Maximum Session Timeout value for an access profile

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Access Policy > Access Profiles.
  3. Locate the affected profile that has been previously defined with the Maximum Sessions Timeout value of 0.
  4. Modify the setting to a value higher than 604,800 seconds based on the requirements of your environment.
  5. Click Update.
  6. Navigate to Access Policy.
  7. Select the check box for the modified access policy (the Status flag should be yellow).
  8. Click Apply Access Policy.

Using the Traffic Management Shell to set the Maximum Session Timeout value for an access profile

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To modify the Maximum Session Timeout for an access profile, use the following command syntax:

    modify apm profile access <access profile name> max-session-timeout <maximum value in seconds>

  3. To apply the access profile change to the active access policy, use the following command syntax:

    modify apm profile access <access profile name> generation-action increment

  4. To save the change, type the following command:

    save /sys config
