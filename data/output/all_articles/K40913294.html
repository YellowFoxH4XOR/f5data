Description
For BIG-IP versions prior to 14.x, when you try to open the Statistics > Dashboard in the GUI. A new window is opened for the Dashboard.

  • The Dashboard utility is not being displayed. 
  • You get an error: "This content requires the Adobe Flash Player. Get Flash'."
    • After you click 'Get Flash' it redirects to 'Adobe Flash Player End of Life' page.
    • Alternatively you will get 'We couldn't download' or 'Adobe Flash Player is out of date' message after new window URL https://<MgmtIpAdress>/tmui/dashboard/F5Dashboard.html opens. In both cases, you can not download or update since Adobe Flash Player is EOL.


Environment

  •  BIG-IP Versions prior to 14.x.
  • GUI > Statistics > Dashboard
  • Adobe Flash Player
     

Cause

Dashboard requires Adobe Flash Player for BIG-IP Versions less than 14.x,

However,  Adobe no longer supports Flash Player and blocked Flash content from running in Flash Player. As a result, the Dashboard utility is no longer available. It will be redirected to 'Adobe Flash Player End of Life' page.

Recommended Actions

Upgrade to BIG-IP 14.x or later.  Starting in BIG-IP 14.0.0, the BIG-IP Dashboard no longer uses Flash technology, and has been replaced with a more modern HTML5 GUI which does not use Flash technology.    Bug ID 534474: Dependency on Adobe Flash removed from the BIG IP Dashboard
