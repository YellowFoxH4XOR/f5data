Issue

Error Message

012b3103:3: CRL file <file name> contains no CRLs, or an invalid CRL. Remote iQuery connections may be rejected

In this error message, note the following:

  • <file name> is the name of the Certificate Revocation List (CRL) file on the BIG-IP system used for iQuery connections.

For example:

012b3103:3: CRL file /config/revoked_certs.crl contains no CRLs, or an invalid CRL. Remote iQuery connections may be rejected.

Message Location

You may encounter this message in the following location:

  • The /var/log/gtm file

Description

This message occurs when the following condition is met:

  • The /config/revoked_certs.crl file is invalid or contains no CRLs.

Starting in BIG-IP 16.x, you can configure the system to check for revoked SSL certificates for components that use the iQuery communication mechanism, such as BIG-IP DNS synchronization. To enable the feature, you must install a valid PEM-encoded CRL to the BIG-IP system and name the file /config/revoked_certs.crl.

Impact

The BIG-IP system may reject remote iQuery connections, and features that use iQuery, such as BIG-IP DNS synchronization, may fail to function properly.

Recommended Actions

To work around this issue, you can upload a valid PEM-encoded CRL to the /config directory on the BIG-IP system and name the file as follows: revoked_certs.crl.
