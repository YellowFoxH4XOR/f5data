Known Issue

BIG-IP APM Security Assertion Markup Language (SAML) Identity Provider (IdP) assertions may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured as a SAML IdP.
  • The BIG-IP APM system sends a SAML assertion to a service provider (SP) that is not a BIG-IP APM endpoint.
  • The SAML SP system clock is running behind the time value of the BIG-IP APM IdP system clock.
  • The SAML SP implementation does not allow tolerance for clock skew.

Impact

BIG-IP APM SAML IdP assertions fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When comparing the clock skews of the IdP and SP, the SP skew is behind that of the IdP.
  • The BIG-IP APM system is unable to send a successful assertion to the SP.
  • When comparing the IdP SAML assertion "NotBefore" time, to the actual time of the SAML SP, the assertion time is ahead of the SP system time.

Workaround

To work around this issue, you can ensure that the IdP and SP time values match.
