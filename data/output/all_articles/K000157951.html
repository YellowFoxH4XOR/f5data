K000157951: TMM may crash using virtaul server with udp protocol

Type
Support Solution
Published
2025-11-24
Updated
2025-11-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000157951

Description

Virtual server that forwards User Datagram Protocol(UDP) traffic to pool members in down state may cause Traffic Management Microkernel(TMM) to crash.

Environment

  • LTM

Cause

UDP pool has service on action down setting to reject and one or more pool members where down. TMM core also leaves behind a core file in /var/core directory.  Product Engineering has identified bug 2151885 as the cause of this issue.

Recommended Actions

As a workaround, update pool service on action down setting to default of none.
