K42051301: Removing F5 APM plugin components from Firefox on Linux systems

Type
Support Solution
Published
2020-12-15
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP APM: 16.0.0, 17.X.X, 16.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1
Source
https://my.f5.com/manage/s/article/K42051301

Description

Removing Network Access plugin components or Endpoint Inspector component in the Firefox from Linux systems.

Environment

  • BIG-IP APM
  • Network Access (F5 VPN)
  • Endpoint Inspector
  • Firefox in Linux

Cause

None

Recommended Actions

For Ubuntu system (install the deb package), run the command below:

sudo apt list | grep ^f5                <<< list the installed F5 VPN software.
sudo apt remove f5epi        <<< Remove the Inspector component if existed.
sudo apt remove f5vpn        <<< Remove the Network Access component if existed

For Fedora system (install the rpm package), run the command below:

rpm -qa |grep ^f5        <<< list the installed F5 VPN software.
sudo rpm -e f5epi        <<< Remove the Inspector component if existed.
sudo rpm -e f5vpn        <<< Remove the Network Access component if existed
