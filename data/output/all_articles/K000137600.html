K000137600: F5 Terraform/AS3/REST API services are not working after V17 upgrade

Type
Support Solution
Published
2023-11-15
Updated
2023-11-15
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000137600

Description

After upgrading to v17.1.0.1+, the F5 Terraform plugin no longer connects as expected

Environment

BIG-IP LTM + FIPS 140-3 Compliance

Cause

 
Bug ID 1252093: BIG-IP OpenSSL now supports Extended Master Secret

FIPS 140-3 Compliance requires all HTTP Clients connecting to the BIG-IP to support TLS Extended Master Secret

F5Networks / terraform-provider-bigip v1.20.0 uses GOLANG v1.19 which does not support TLS Extended Master Secret
See EOF Error with BigIP v17.10.1 running FIPS #817
This should be resolved in the next release of the terraform-bigip-provider
 

Workaround

  1. GOLANG v1.23+ supports TLS Extended Master Secret, so you can manually compile you own version of this to work with terraform-provider-bigip
  2. If you don't need FIPS 140-3 Compliance, you can obtain a replacement BIG-IP License that does not include FIPS Compliance. Before 17.1.0.1, FIPS was only 140-2 Compliant, which did not require TLS Extended Master Secret, but it is not possible implement FIPS 140-2 Compliance on 17.1.0.1+
