K40359761: Virtual server stopped working after upgrade to 15.1.5.1.

Type
Support Solution
Published
2022-05-17
Updated

Applies to

  • BIG-IP APM: 14.1.4, 13.1.5, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.1, 16.0.0, 15.1.6, 15.1.5, 15.1.4, 14.1.5
Source

Description

After an upgrade, the BIG-IP virtual server is no longer working.

  • Your web browser may display ERR_CONNECTION_RESET.
  • The TCP RST packet, as found a tcpdump shows, "Cause: Route domain not reachable (strict mode)"

Environment

  • BIG-IP APM
  • The virtual server's address is configured with a Route Domain other than zero (0).

Cause

Bug ID 1010597: Traffic disruption when virtual server is assigned to a non-default route domain

Recommended Actions

Workaround:
  1. Log in to the Configuration utility.
  2. Go to Network > Route Domains > affected route domain.
  3. In the section Parent Name select '0 (Partition Default Route Domain)'.
  4. Select Update.
