Topic

You should consider using the following procedures under the following conditions:

  • You want to create a pre-login message banner that appears before the user logs in using an SSH session.
  • You want to create a post-login message banner after the user logs in using SSH or a serial console.

Description

The pre-login message banner sends a message to remote users who attempt to log in to the system using SSH. The pre-login message banner is useful for enforcing security policy--for example, to inform remote users that all activities are logged.

The post-login message banner appears after a user successfully authenticates to the Advanced shell (bash) access on the system, either through SSH or serial console. This message banner is useful to inform users about the system--for example, informing users of an upcoming scheduled maintenance.

Prerequisites

You must meet the following applicable prerequisites to use these procedures:

  • You have administrator access to the TMOS Shell (tmsh)
  • You have administrator access to the Configuration utility.
  • You have advance shell access with Administrator credential.
  • You are familiar with a Linux text editor.

Procedures

Perform the procedure that meets your need and environment:

  • Add a pre-login message banner using the Configuration utility

    To watch a video demo of this procedure, go to  Configure a pre-login banner message for SSH login using the BIG-IP Configuration utility.

  • Add a pre-login message banner from a file using tmsh 
  • Add a pre-login single-line message banner using tmsh 
  • Add a post-login message banner

Add a pre-login message banner using the Configuration utility 

To add a pre-login message banner that will send the message to the remote user who attempts to log in using SSH, perform the following procedure:

Impact of procedure: The pre-login message banner may not take effect in the Configuration utility if you previously configured a banner using tmsh. To avoid conflicts, you should remove any banner configuration that was configured using tmsh.

  1. Log in to the Configuration utility.
  2. Go to System > Configuration > Device
  3. Select SSHD.
  4. Enter the pre-login message banner in the text box and enable appropriate options.
  5. To enable this banner message, select the Show The Security Banner On The Login Screen check box.

    To disable this message banner, clear the Show The Security Banner On The Login Screen check box.

  6. Select Update.

Add a pre-login message banner with a file using tmsh

To use tmsh to add a pre-login message banner from a file that will send the message to the remote user who attempts to log in using SSH, perform the following procedure:

Impact of procedure: These changes may not be present after an upgrade or re-installation. Therefore, F5 does not officially recommend these changes. However, if the changes are required due to a security policy, ensure that the changes are verified after any upgrades. In addition, these changes may not propagate to HA peers and you must perform this procedure to all devices in the device group if required.

  1. Log in to the BIG-IP command line.
  2. Using a text editor, open the /config/ssh/ssh_banner file. If it does not exist, create the file.

    Note: Alternatively, you can create the message banner using a different filename. If you use a different filename, the matching filename has to be applied to Step 5.

  3. Enter the content for the pre-login message banner.
  4. Save the file and exit the editor.
  5. To add pre-login message banner using a file, use the following command syntax:

    tmsh modify /sys sshd include "<enter_value>"

    For example:

    tmsh modify /sys sshd include "Banner /config/ssh/ssh_banner"

    Note: If you have specified a different filename in Step 2, you have to use the matching filename in this step.

    To disable this message banner, type the following command:

    tmsh modify /sys sshd include none

  6. To save the changes, type the following command:

    tmsh save /sys config

Add a pre-login single-line message banner using tmsh

To use tmsh to add a pre-login single-line message banner that will send the message to the remote user who attempts to log in using SSH, perform the following procedure:

Impact of procedure: These changes may not be present after an upgrade or re-installation. Therefore, F5 does not officially recommend these changes. However, if the changes are required due to a security policy, ensure that the changes are verified after any upgrades. In addition, these changes may not propagate to HA peers and you must perform this procedure to all devices in the device group if required.

  1. To enable and enter the single-line message banner text, use the following command syntax:

    tmsh modify /sys sshd banner enabled banner-text "<Banner-Text>"

    For example, to enable the pre-login message banner text and use "NOTICE: This is for authorized users only." as the single-line text, type the following command:

    tmsh modify /sys sshd banner enabled banner-text "NOTICE: This is for authorized users only."

    To disable this message banner, type the following command:

    tmsh modify /sys sshd banner disabled banner-text none

  2. To save the changes, type the following command:

    tmsh save /sys config

Add a post-login message banner

To create a post-login message banner that displays after a user successfully authenticates to the system using SSH or a serial console, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: Customizations to the /etc/motd file are not saved in the UCS archive. To ensure that customized files are saved when you create a UCS archive, refer to K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive.

  1. Log in to the BIG-IP command line.
  2. Using a text editor, open the /etc/motd file. If the file does not exist, create the file.
  3. Enter the post-login message banner content.
  4. Save the file and exit the text editor.

To disable this message banner, you can remove the content of the /etc/motd file by entering the following command:

cat /dev/null > /etc/motd
