Issue

Error Message

0153100e:3: Transfer of zone <zone_name> failed with rcode (<rcode>)

In this error message, note the following:

  • <zone_name> is the zone file transferred by DNS Express.
  • <rcode> is the DNS response code.

For example:

0153100e:3: Transfer of zone example.org failed with rcode (SERVFAIL)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • DNS Express was unable to perform a zone transfer from a master DNS name server.

Impact

If this is the initial zone transfer, DNS Express will not host the zone. If the zone was successfully transferred previously, DNS Express will not receive updates to the zone. If the zone transfer continues to fail and the zone exceeds the expiration time, DNS Express will stop hosting the zone until the next successful transfer.

Recommended Actions

  • The master DNS name server provides the rcode in the error message, which you can use to investigate why the master DNS name server was not able to successfully transfer the zone.
  • The BIG-IP system continues to attempt to transfer the zone. Once the issue on the master DNS name server is resolved, DNS Express will be able to transfer and host the zone.
