K000148269: Module "ngx_http_js_module" is Already Loaded

Type
Support Solution
Published
2024-10-26
Updated
2024-10-26
Applies to
  • NGINX Products
  • NGINX Ingress Controller: 3.7.0
Source
https://my.f5.com/manage/s/article/K000148269

Description

  • You have NGINX Ingress Controller, image version pre 3.7.0, deployed and running 
  • You have installed and enabled "ngx_http_js_module" using "main-snippets" as shown below using nginx-config configMap
              data:
                main-snippets: |
                   load_module modules/ngx_http_js_module.so;
  • You proceeded to upgrade your deployment to image version 3.7.0
  • After the upgrade, the pod failed to reach full running state
  • When viewed using kubectl logs, the pod records the below error 
        NGINX Ingress Controller Version=3.7.0 Commit=035006849bde69c12c08f7ed18a3a9c6bf7551a2 Date=2024-09-27T10:19:33Z DirtyState=false Arch=linux/amd64 Go=go1.23.1
        I20241025 15:53:35.608338       1 flags.go:315] Starting with flags: ["-nginx-plus" "-nginx-configmaps=nginx-ingress/nginx-config" "-report-ingress-status" "-external-service=nginx-ingress" "-enable-tls-passthrough" "-enable-custom-resources" "-external-service" "-enable-external-dns" "-enable-snippets"]
        I20241025 15:53:35.613678       1 main.go:297] Kubernetes version: 1.30.2
        I20241025 15:53:35.618440       1 main.go:444] Using nginx version: nginx/1.25.5 (nginx-plus-r32-p1)
        2024/10/25 15:53:35 [emerg] 14#14: module "ngx_http_js_module" is already loaded in /etc/nginx/nginx.conf:12

Environment

  • NGINX Plus Ingress Controller
  • ngx_http_js_module
  • Upgrade

Cause

  • As per NGINX release note and specification, the default image 3.7.0, now includes "NGINX Plus JavaScript and OpenTracing modules"

Recommended Actions

  • The recommendation, as of version 3.7.0 is to remove any additional declaration of ngx_http_js_module.so module using nginx configMap manifest
