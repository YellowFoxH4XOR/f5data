Issue



The following error message may be reported on the Reports: System Logs page, or output to the syslog file of your syslog server (if configured):

GarbageCollection[?????]: apache server is not running. start it

This message indicates the httpd processes on the FirePass controller are not running. This message can appear when the Web Services are restarted, or during failover in a high availability (HA) failover pair configuration. During these events, this message can be ignored. If these messages persist and occur frequently, and you notice issues connecting to your FirePass controller, contact F5 Networks Technical Support.

Note: The syslog level and severity for this message is Local1.Info.
