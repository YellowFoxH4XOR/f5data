Description

Attempt to upload qkview to ihealth, but you get either:

  • a 500 error from the server
  • the file uploads but then no extraction, normalizing, etc; it does not show up in the list of qkviews.

Environment

  • ihealth.f5.com
  • BIG-IP

Cause

corrupt .qkview file

Recommended Actions

  1. ensure that your qkview is intact:
    tar tvfz qkviewfilename.qkview
     
  2. The file is corrupt if this results in an error, such as:
    gzip: stdin: unexpected end of file
    tar: Unexpected EOF in archive
    tar: Error is not recoverable: exiting now
     
  3. You may need to retransfer the file from the device it was generated on or generate a new qkview and reupload it.
