Source
https://my.f5.com/manage/s/article/K000149034

Description

You are unable to import "F5OS Image" or "Tenant Image" under Software Management via GUI.

"Loading data..." and a blue rotating circle is displayed, indefinitely.

Environment

  • rSeries
  • Firefox 
  • Software Management
  • F5OS Image
  • Tenant Image

Cause

You are using outdated version of Firefox or another browser

Recommended Actions

Update Firefox or another browser to the latest version.

Additional Information
