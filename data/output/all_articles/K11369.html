Topic

FirePass administrators may want to grant full access to the FirePass controller using only a RADIUS authenticated account. This configuration ensures that corporate standards, such as password complexity, password age, and auditing, are strictly enforced. To create an account with administrator privileges on the FirePass controller, perform the following four procedures:

  • Create a master group
  • Create an administrator account
  • Grant the administrator full access
  • Disable the default administrator account

Create the master group

  1. Log on to the FirePass Administrative Console.
  2. Navigate to Users: Groups: Master Groups.
  3. Click the Create new group button.
  4. Enter a name for the group in the New group name field.
  5. Ensure that the Local option is selected in the Users in group drop-down menu.
  6. Select RADIUS from the Authentication method drop-down menu.
  7. Click the Create button.

Create the administrator account

  1. Navigate to Users: User Management.
  2. In the Create user accounts by drop-down menu, select the individual entry option.
  3. Click the Go button.
  4. Select the master group you created in the previous procedure from the drop-down menu located on the right panel of the screen.
  5. Click the Change button.
  6. Populate the fields in the New user section.

Grant the administrator account full access

  1. Navigate to Device Management: Security: Administrative Realms.
  2. Click the Edit link under Full Access.
  3. Enter the name of the Administrator account you created in the previous procedure.
  4. Click the Add button.

Disable the default administrator account

  1. Navigate to Device Management: Security: Admin Name and Password.
  2. Select the Disable Admin (Superuser) Account check box.
