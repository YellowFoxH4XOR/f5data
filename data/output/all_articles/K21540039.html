Issue

Error Message

err mcpd[<PID>]: 010713b1:3: Cannot delete IP (<IP address>) because it is used by the system state-mirroring (<mirror_address_object>) setting.

In this error message, note the following:

  • <PID> is the process ID of the mcpd process.
  • <IP address> is the IP address you are attempting to delete.
  • <mirror_address_object> is the local mirror address using the IP address you are attempting to delete and is either Primary Mirror Address or Secondary Mirror Address.

For example:

err mcpd[7006]: 010713b1:3: Cannot delete IP (192.0.2.2) because it is used by the system state-mirroring (Primary Mirror Address) setting.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
  • The TMOS Shell (tmsh)
Description

This message occurs when the following condition is met:

  • You are attempting to delete a self IP address that the system references in its mirroring settings.

Impact

The system does not delete the self IP address, nor does it make changes to the system.

Recommended Actions

This behavior is intentional and prevents unexpected routing conditions. However, if you find that the self IP address should be deleted, you can remove it from the system mirroring settings, and then delete it. To do so, perform the following procedure:

Impact of workaround: The impact of the suggested workaround depends on your specific environment. F5 recommends you perform these changes during a maintenance window and consider the possible impact on your environment.

BIG-IP 13.0.0 and later

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Devices.
  3. Click the device name.
  4. Click the Mirroring tab.
  5. In the Primary Local Mirror Address or Secondary Local Mirror Address list, click None or another IP address.
  6. Click Update.

BIG-IP 11.x - 12.x

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Devices.
  3. Click the device name.
  4. Point to the Device Connectivity tab, and then click Mirroring.
  5. In the Primary Local Mirror Address or Secondary Local Mirror Address list, click None or another IP address.
  6. Click Update.

You can now delete the self IP address.
