Description

In some scenarios it may be necessary to export your client certificate and key to a PFX file to be able to import it into F5 Access for iOS to allow On-Demand Certificate Authentication with APM.

Environment

  • BIG-IP APM
  • F5 Access for iOS
  • On-Demand Certificate Authentication

Cause

None

Recommended Actions

Manually export your Certificate and Key PFX file and import it into F5 Access:
Note: The private key must be set to exportable for this to work correctly or you will get an error "Export-PfxCertificate : Cannot export non-exportable private key."

  1. Open Powershell on your client machine as an Administrator
     
  2. Locate your client certificate on your PC using tab to complete
    Cert:\LocalMachine\my\06BC30EFEEA9B23E64CF20A5A4903A7E73D57D3A
     
  3. You will need to set your user password in a variable for the export script to execute correctly:
    Replace abc123!@ with your user password
    $mypwd = ConvertTo-SecureString -String "abc123!@" -Force -AsPlainText
     
  4. Using the Cert:\ location above, update the following script to export the PFX file to your local root directory.
    Get-ChildItem -Path Cert:\LocalMachine\my\06BC30EFEEA9B23E64CF20A5A4903A7E73D57D3A | Export-PfxCertificate -FilePath C:\mypfx.pfx -Password $mypwd
     
  5. When exporting it will prompt to set a password for importing.
     
  6. Emailing yourself the PFX file is the easiest way to transfer to the iOS device
     
  7. When opening the PFX file, you can choose which app to open it with, Choose F5 Access

     
     
  8. This will prompt for the password that you created on step 5.
