Known Issue

You cannot add high availability (HA) BIG-IP APM systems running BIG-IP 12.1.1 to BIG-IQ Access Groups.

This issue occurs when the following conditions are met:

  • You are using the BIG-IQ system to manage remote BIG-IP APM systems running BIG-IP 12.1.1.
  • The BIG-IP APM systems are in an HA configuration.
  • You attempt to add one of the BIG-IP APM systems to a BIG-IQ Access Group.

Impact

You cannot add HA BIG-IP APM systems to a BIG-IQ Access Group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice the following error when you attempt to add a BIG-IP APM system to an Access Group:

    Failed to download file (null). java.lang.IllegalArgumentException: REMOTE_SOURCE_FILE requires remoteFilePath
