K000140753: Cannot execute 'su - admin' command

Type
Support Solution
Published
2025-04-08
Updated
2025-04-08
Applies to
  • F5OS
  • F5OS-A: 1.5.2
Source
https://my.f5.com/manage/s/article/K000140753

Description

'su - admin' command is unavailable after clean install.

Environment

F5OS

Cause

The problem could be corrected by using a USB flash memory stick, installing the software, and then waiting a while before logging in.

Recommended Actions

execute the 'su - admin' command after several minutes (It could be around 10 minutes).
