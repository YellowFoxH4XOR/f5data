K000135174: AS3 declaration returns 500 error

Type
Support Solution
Published
2023-06-22
Updated
2023-06-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source

Description

AS3 declaration fails on save config.

The following error message could be presented on failure:

{

"code": 500,

"declarationFullId": "Declaration",

"message": "failed to save BIG-IP config (GET http://admin:XXXXXX@localhost:8100/mgmt/tm/task/sys/config/1684303066956177 checking config save status response=500 body={\"code\":500,\"message\":\"Connection refused\",\"referer\":\"Unknown\",\"restOperationId\":8001964,\"kind\":\":resterrorresponse\"})"

 

Environment

  • AS3 v3.35.0.
  • Previous AS3 versions do not affected.

 

Cause

ID1302033

 

Recommended Actions

Upgrade to a version with the fix.
