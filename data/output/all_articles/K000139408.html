Description

BIG-IP Next Central Manager does not honor the NTP configuration provided by DHCP or Cloud-Init

Environment

Relevant environmental factors specific to the topic

  • Central Manager
  • NTP configuration provided by DHCP
  • NTP configuration provided by cloud-init

Cause

BIG-IP Next Central Manager currently provides a default NTP configuration located in /etc/chrony/sources.d/central-manager.sources. 

This default configuration file contains the following entries:

pool ntp.ubuntu.com iburst maxsources 4

pool 0.ubuntu.pool.ntp.org iburst maxsources 1

pool 1.ubuntu.pool.ntp.org iburst maxsources 1

pool 2.ubuntu.pool.ntp.org iburst maxsources 2

 

When the BIG-IP Next Central Manager receives NTP IPs from either DHCP or cloud-init, the default NTP configuration is not overridden and continues to be used by the chrony service.

The effect of this behavior is that Central Manager HA clusters members may fail to join the cluster due to divergent system time. 

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1.  It is recommended that BIG-IP Next Central Manager be allowed to connect to NTP servers on the public internet until this issue is resolved in a future product version.
