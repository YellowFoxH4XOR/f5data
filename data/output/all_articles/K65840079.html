Description 

iquery unable to connect to reused BIG-IP LTM devices with the following error message:

011ae0fa:3: iqmgmt_ssl_connect: SSL error: SSL connect (5)

iqdump shows:

New (NONE), Cipher is (NONE)

Environment

  • DNS device trying to add reused LTM devices v12.1.5.2

Cause 
Not confirmed but suspect old data in BIG-IP LTM devices prevented DNS iquery from connecting to them. 

Recommended Actions

  1. Confirm customer is in root on DNS device
     
  2. If reusing BIG-IP LTM devices and running bigip_add command get:
    ERROR: Can't read remote cert via /usr/bin/ssh
     
  3. Forceload mcpd to reload the flatfile configuration and reboot the BIG-IP LTM.
    Once device comes back run bigip_add again and verify iquery connection
