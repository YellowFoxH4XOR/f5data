Description

 

In the /var/log/ltm file or syslog server you may see a log entry with -c as the process name instead of tmm1, tmm2, etc.

-c[10801]: Rule /Common/vapi_irule_OPS-207447_version1 <HTTP_REQUEST>: 14:12:08 | Client IP: 192.168.0.1 | HTTP Request Method: POST | HOSTNAME: lt1m.hostname.com| URL: /services/ad_asset_store/382926 | Response Code: 429 | Cookie:

 

tmm1[10801]: Rule /Common/vapi_irule_OPS-207447_version1 <HTTP_REQUEST>: 14:12:08 | Client IP: 192.168.0.1 | HTTP Request Method: POST | HOSTNAME: ltm1.hostname.com| URL: /services/ad_asset_store/382926 | Response Code: 429 | Cookie:

 

 

Environment

BIG-IP LTM

 

Cause

This is a known issue caused by Bug ID 1057305: On deployments that use DPDK, "-c" may be logged as the TMM process/thread name.
