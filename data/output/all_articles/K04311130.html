Known Issue

The IP::stats iRule command truncates output to a 32-bit integer.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system processes more than 2,147,483,647 bytes or 2,147,483,647 packets over a connection.
  • The affected connection triggers an iRule with the IP::stats command.

The IP::stats iRule command is incorrectly limited to a 32-bit integer. As a result, the command reports a negative value when 2 gigabytes (GB) or 2 billion packets are exceeded over a connection that the command is used to gather statistics from.

Impact

iRules that reference the IP::stats command may not function as expected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The IP::stats iRule command returns data that reports a negative number instead of the actual value.
