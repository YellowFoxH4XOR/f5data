Description

You can observe on your BIG-IP system that failover connection is down. By issuing command "tmsh show cm failover-status" you can see Error status for this connection, like in example below:
------------------------------------------------------------------------------------------------
CM::Failover Connections
Local Failover Address  Remote Device         Packets  Transitions  Received Last Packet  Status
------------------------------------------------------------------------------------------------
192.0.2.21:1026         LTM.example.local     0        6            -                     Error

Warning(s):
Not receiving any failover updates from LTM.example.local.

Environment

  • BIG-IP HA
  • Self IP Port Lockdown set to Allow None

Cause

Configuring Allow None at affected Self IP for Port Lockdown setting.

Recommended Actions

Modify mentioned Port Lockdown value on affected Self IP to Allow Default or Allow Custom specifying UDP port 1026 to allow communication.

Additional Information

None
