Known Issue

Exporting Event Logs Requests reports may not function.

This issue occurs when all of the following conditions are met:

  • You filter the BIG-IP ASM Event Logs Requests report by Severity.
  • You select Binary export of all requests defined by filter as your Export Method.

Impact

Attempting to export BIG-IP ASM Events Logs Requests reports may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt the export, the system displays an error message similar to the following example:

    Error after running Requests events export script; Error: Export proxy log failed: DBD::mysql::st execute failed: Unknown column 'A.severity_id' in 'where clause' at /usr/lib/perl5/site_perl/F5/ExportProxyLog.pm line 107
  • When not filtering the BIG-IP ASM Events Logs Requests by Severity, the export is successful.
