Known Issue

In the bash command line prompt, the BIG-IP system may display an incorrect username for users with privileged roles.

This issue occurs when all of the following conditions are met:

  • You are running one of the following BIG-IP software versions:
    • BIG-IP 11.6.1 HF1 and HF2
    • BIG-IP 11.5.4 through 11.5.4 HF2
  • You create a user with bash command line access and admin or resource-admin roles.

Impact

The affected user may observe that the command line interface is displaying the root user instead of the login username.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H590272 on the Diagnostics > Identified > Low screen.
  • Your BIG-IP system displays users incorrectly in the bash command line.

    For example, in the following example, the user test appears as root when logging in as test:

    login as: test
    Using keyboard-interactive authentication.
    Password:
    Last login: Wed Oct 8 02:31:44 2014 from 192.168.12.206
    [root@2000-1:Active:Standalone] ~ #
    [root@2000-1:Active:Standalone] ~ # tmsh
    test@(2000-1)(cfg-sync Standalone)(Active)(/Common)(tmos)#
