Known Issue

Using ZoneRunner to create DNS zones from file may fail.

This issue occurs when all of the following conditions are met:

  • You attempt to create a new zone by using Load from File of an external zone file with ZoneRunner.
  • The zone file contains two or more consecutive lines of the following line types, or any consecutive combination thereof.

    • $TTL ( default expiration time variable )  
    • blank lines
    • Zone file text comment lines, (;) lines that start with a semicolon.

      Example problematic zone file:

      $ORIGIN example.com.
      $TTL 900  
      example.com.        IN SOA    dns1.example.com. admin.example.com. (
                      2009083957 ; serial
                      900        ; refresh (15 minutes)
                      600        ; retry (10 minutes)
                      259200     ; expire (3 days)
                      900        ; minimum (15 minutes)
                      )


                             NS    dns1.example.com.
                             NS    dns2.example.com.
                              A       5.6.7.8    
      $TTL 797 ; time out of 797 seconds
      glb1            A       1.2.3.4
      glb2            A       1.2.3.5


      This zone file contains multiple (2) empty lines between the closing ")" of the SOA section and the first NS name server statement.

Impact

ZoneRunner does not create the new zone.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Creating a new DNS zone fails when you use the Configuration utility. The ZoneRunner option fails with an error similar to the following example:

    ERR MSG: 01150213:3: Zone '<dns zone>' in file '<zone file to import>' contains errors: zone <dns zone>/IN: has no NS records. zone <dns zone>/IN: not loaded due to errors.

Workaround

To work around this issue, you can prepare the zone file for use with ZoneRunner. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Preparing the zone file for use with ZoneRunner

  1. Using a text editor, open the intended zone file.
  2. Specify the domain in the line following any $ directive lines.
  3. Remove any consecutive blank lines.
  4. Remove any consecutive comment lines (;).
  5. Save the file changes.

    The file is ready for ZoneRunner to create a new DNS zone.

Alternatively, to manually update ZoneRunner managed zone files, you can follow the procedure outlined in K7032: Freezing zone files to allow manual update to ZoneRunner-managed zone files.
