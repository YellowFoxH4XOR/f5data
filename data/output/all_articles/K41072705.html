Issue

Error Message

01010241:5: Syncookie HW mode exited, server = <ip_address>:<port>, HSB modId = <ID> from HSB

In this error message, note the following:

  • <ip_address>:<port> is the destination address and service port combination of the virtual server that has entered or exited Syncookie HW mode.
  • <ID> is the numeric identifier of the High-Speed Bridge (HSB) device that has entered or exited Syncookie HW mode.

For example:

01010241:5: Syncookie HW mode exited, server = 192.168.10.100:80, HSB modId = 1 from HSB

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • The BIG-IP SYN cookie feature had entered or exited protection mode for one or more virtual servers

Note: For more information about the BIG-IP SYN cookie feature, refer to K14813: Detecting and mitigating DoS/DDoS attacks (11.4.x - 14.x).

Impact

There is no impact; this message is informational only.

Recommended Actions

None
