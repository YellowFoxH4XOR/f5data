Known Issue

The TMM process may exit and produce a core file. This issue occurs when all of the following conditions are met:

  • A BIG-IP ASM virtual server is processing an existing connection.
  • A BIG-IP PSM-only license was upgraded to a BIG-IP ASM and PSM license during a license re-activation that occurred on the BIG-IP system.

The BIG-IP ASM and PSM services are reinitialized during the licensing change event. Subsequent requests received on the existing connection may reference data that has been freed during the re-initialization. As a result, the TMM process exits and produces a core file.

Impact

The BIG-IP system may temporarily fail to process traffic and fail over if it is configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system fails over to the standby system if it is configured as part of a high-availability system.
