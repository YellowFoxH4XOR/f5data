K000153030: APM - When attempting to export SAML Metadata you observe the error "File(s) access/permission or signing key mismatch error. See log file."

Description

This solution while described the conditions that will cause this error message.

  • Synopsis of issue, question, or intent
  • Exporting SAML Metadata files
  • The following error message is seen in the Admin GUI:

File(s) access/permission or signing key mismatch error. See log file.


Environment

Relevant environmental factors specific to the topic

  • APM
  • SAML
  • Metadata

Cause

  1. The user logged into the Admin GUI attempting to generate/download does not have Administrator permissions.
  2. On the download screen you have selected to Sign the Metadata, but have select the incorrect Certificate/Key pair.
  3. An error has occurred internally and process for generating the Metadata has failing and it is not available for download.

Please note for cause number 3 you may observe this error message in the webui.log file:


SamMetadataDownloader: Syscall returned error; Syntax Error: "apm" unexpected argument


Recommended Actions

Verify the user has the Administrator Role:

  1.  Login to the Admin GUI
  2. Navigate to System>Users>User List.
  3. Verify the user has the Administrator Role.

Verify you have selected the correct Certificate and Key:

  1. Login the the Admin GUI
  2. Navigate the Access>Federation>SAML Service Provider>Local SP.
  3. Select the SP Connector.
  4. Click on Export Metadata.
  5. For Sign Metadata select Yes from the drop down.
  6. Make sure to verify/select the correct Certificate and Key.

Perform an mcpd reload of the configuration:


K13030: Forcing the mcpd process to reload the BIG-IP configuration


Additional Information

When you click the button it builds a tmsh command string and then executes it then provides it for download.
