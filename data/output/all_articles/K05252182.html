Description

  • The Origin header transmitted by the client is a key to differentiate client requests.
  • The response is different (header Access-Control-Allow-Origin different) according to the value of the Origin header.
  • The web servers therefore indicate to the F5 cache, via the Vary header, that the cache data is different depending on the value of the Origin header.

Environment

  • CORS (Cross-origin_resource_sharing)
  • RAMcache
  • BIG-IP

Cause

  • CORS (Cross-origin_resource_sharing) will not work with RAMcache 
  • ID 221995
    • According to ID 221995, RAMcache ignores Vary header entries that are not exactly User-Agent or Accept-Encoding

Recommended Actions

  • None, by design

Additional Information

  • The 'Vary' header, on the BIG-IP, can only be used for specific request headers and it only honors User-Agent and Accept-Encoding,
  • K11009: The HTTP cache will honor Vary headers containing only User-Agent or Accept-Encoding entries
