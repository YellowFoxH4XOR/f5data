Description

Occasionally when using the f5 master key utility to rekey a new device you may receive the error

Decryption of the field (secret) for object (/Common/sctp) failed

Environment

  • BIG-IP without a loaded configuration.
  • You attempt to rekey the master key

Cause

A default profile (/Common/sctp) has an encrypted field that is already tied to the master key that comes with the device, so rekeying the master key fails.


Recommended Actions

Reset the device's configuration back to factory default settings as described in article K13127.
Then, loading UCS to recover the configurations by following K13127: Restoring the BIG-IP configuration to factory default settings (11.x - 17.x)
