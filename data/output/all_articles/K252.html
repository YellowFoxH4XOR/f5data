K252: Dell 2650 server appliances are licensed for 2 CPUs, but dual CPU configurations are not allowed

Known Issue

This is the result of a known issue. The license incorrectly allows for two CPUs on a Dell 2650 server appliance. This server appliance model comes with a single CPU.

Do not add an additional CPU to Dell server appliances, even if the license indicates multiple CPUs are supported. If you add an additional CPU, the BIG-IP will fail to boot.

F5 Networks Product Development tracked this issue as CR29393 and CR41791.
