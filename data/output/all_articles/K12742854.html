Description

Missing Server side graph or analytics data for a deployed Application Service

Environment

  • BIG-IQ is running 7.1.0
  • BIGIP is running 13.x.x
  • Create an application service configuration using existing device configurations
  • The BIG-IQ has a data collection device (DCD) cluster configured.
  • Statistics collection is enabled for each managed BIG-IP device.

Cause

  1. The Virtual Server in question of a managed BIG-IP's was configured with default HTTP and TCP analytics profile.
  2. Default HTTP and TCP analytics profile does not include statistics collection for server side connection.

Recommended Actions

  1. Login to the GUI of the managed BIG-IP in question
  2. Create a custom HTTP and TCP Analytics profile with both client side and  server side collection then associate it to the Virtual Server you want to collect statistics from.
