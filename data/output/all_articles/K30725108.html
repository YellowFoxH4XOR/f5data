Description

The BIG-IP responds with a "No server selected" to a connection even if pool members are available.

Environment

  • BIG-IP
  • Virtual Server with Service Profile configured
  • Pool members available

Cause

Bug ID 1021837

Recommended Actions

Delete the VS and re-create it without the service profile.
