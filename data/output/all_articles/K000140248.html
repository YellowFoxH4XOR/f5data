Description

Connection to backend server on TLS1.3 not working when the pool member webserver requires SNI (Server Name Indicator), an error is seen in a packet capture between the BIG-IP and pool member after the CLIENT HELLO is sent in the TLS handshake.

TLS 1.3 is enabled on clientssl and serverssl profiles used on the virtual server.

Environment

  • BIG-IP
  • TLS 1.3
  • SNI

Cause

A backend pool member webserver requires SNI, but none is being sent in the CLIENT HELLO inside the TLS handshake.

Recommended Actions

Configure an SNI header in the serverssl profile, or configure the backend webserver to not require SNI.
