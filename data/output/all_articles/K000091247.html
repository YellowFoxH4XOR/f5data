K000091247: Logs not showing up at configured syslog compatible SIEM tool

Type
Support Solution
Published
2022-02-08
Updated
2023-07-18
Applies to
  • BIG-IP
  • BIG-IP FPS: 15.1.2
Source
https://my.f5.com/manage/s/article/K000091247

Description

Logs not showing up at configured syslog server. Syslog configured on the BIG-IP per K13080: Configuring the BIG-IP system to log to a remote syslog server (11.x - 16.x)


 Environment

BIG-IP

syslog log server/syslog compatible SIEMS service (eg: Chronicle)

 Cause

Firewall blocking UDP on the configured port between the BIG-IP and the SIEMS device/instance


 Recommended Actions

  1. Confirm that BIG-IP is sending the logs on the IP:PORT configured. This can be done using a simple tcpdump such as:
    1. tcpdump -ni 0.0 host <hostip_of_SIEM_device> and port <port_of_SIEM_device>
    2. where <hostip_of_SIEM_device> is replaced with the actual SIEM device/instance that is configured in the remote syslog settings of the BIG-IP and <port_of_SIEM_device> is replaced with the actual SIEM device/instance port that is configured in the remote syslog settings of the BIG-IP
  2. If the logs are being sent on the wire by the BIG-IP then ensure that specified port and ip address are open on any firewall between the BIG-IP and the SIEM device.
