Known Issue

The BIG-IP ASM system incorrectly sends the client-side integrity defense JavaScript for certain objects. This issue occurs when all of the following conditions are met:

  • The enforcement mode for the affected security policy is set to blocking.
  • On the Anomaly Detection > DoS Attack Prevention page, the affected security policy is configured with one or both of the following options:
    • Source IP-Based Client Side Integrity Defense
    • URL-Based Client Side Integrity Defense
  • The BIG-IP ASM system receives a client request for non-qualified objects, such as GIF or JPEG files.

The client-side integrity defense feature ensures that an HTTP request originates from a valid client browser, rather than a bot. The feature is one of the steps used in denial-of-service (DoS) prevention on the BIG-IP ASM system.

Impact

The client browser fails to properly render web pages.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Images on a web page may fail to display
  • A packet capture on the affected traffic shows the system responding to a client request for an image file with JavaScript codes instead of the actual image file
