Topic

Firmware updates may be included with an updated release version. However, firmware updates are not automatically installed when the updated release is loaded.

Note: The ARX 1500 and 2500 platforms do not support firmware upgrades at this time. The show firmware and firmware upgrade commands are not available on these platforms.

You can first determine if an upgrade is available and perform an upgrade accordingly, by performing the following two procedures:

  • Viewing the current running firmware versions and determining if an upgrade is available
  • Upgrading the firmware

Viewing the current running firmware versions and determining if an upgrade is available

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Display the currently running firmware versions and upgrade availability status by typing the following command:

    show firmware upgrade verbose
  4. If a firmware upgrade is available, Upgrade available displays in the Status column similar to the following example:

    Show Firmware Update Verbose
    ----------------------------

    Slot  Firmware     Running         Current         Status
    --------------------------------------------------------------------

    1    Bootstrap     2.03.000.09144  2.03.000.09144  Up to date
    1    Firetruck     17              17              Up to date
    1    Diag          3.00.000.10538  3.01.000.10731  Upgrade available
    1    BootLoader    3.00.000.10538  3.01.000.10731  Upgrade available
    1    Hunchback     1               1               Up to date
    1    NSM Boot      3.00.000.10538  4.00.001.11127  Upgrade available
    1    NSM Diag      3.00.000.10538  4.00.001.11127  Upgrade available
    1    NSM BootLdr   3.00.000.10538  4.00.001.11127  Upgrade available
    1    NSM Boot      3.00.000.10538  4.00.001.11127  Upgrade available
    1    NSM Diag      3.00.000.10538  4.00.001.11127  Upgrade available
    1    NSM BootLdr   3.00.000.10538  4.00.001.11127  Upgrade available

Upgrading the ARX firmware

Important: If the ARX system is configured in a redundant configuration, the firmware upgrade must be performed on the backup ARX.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Upgrade the firmware on all slots by typing the following command:

    firmware upgrade all

    Note: To upgrade the firmware on a specific slot on an ARX 6000 system, specify the slot using the firmware upgrade <slot#> command.

    A confirmation prompt will display similar to the following example:

    Confirmation of this command commences a firmware upgrade on the entire chassis. During the upgrade process, the chassis reboots automatically to complete the upgrade process. Proceed? [yes/no]
     
  4. At the confirmation prompt, type the following:

    yes

    Note: The ARX system may reboot multiple times. However, the chassis does not reset until the firmware upgrade has completed on all slots. The firmware upgrade may take approximately 10 to 20 minutes.
  5. Verify that the ARX system has completed the firmware upgrade process by typing the following command:

    show version

    If the firmware upgrade process is still performing, the ModuleState will be displayed as FW Upgrade, similar to the following example:

      Slot  Admin     ModuleType     ModuleState        FW Upgrade
      ----  -------   ------------   ----------------   ----------
        1   Enabled   ACM            FW Upgrade         Disabled

    When the firmware upgrade process completes, the ModuleState will be displayed as Online, similar to the following example:

      Slot  Admin     ModuleType     ModuleState        FW Upgrade
      ----  -------   ------------   ----------------   ----------
        1   Enabled   ACM            Online             Disabled

  6. When the firmware upgrade process has completed, repeat the procedure on the peer ARX system.

    Important: The peer ARX will require a failover to become the backup ARX system. The failover should be performed during a scheduled maintenance window.
