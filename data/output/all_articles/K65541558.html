Description

When trying to remove a certificate from the configuration utility, but it isn't removed.

Environment

  • BIG-IP
  • Certificates
  • CLI

Cause

Bug ID 876809

Recommended Actions

  1. Log in to the TMOS shell by typing the following command:
    tmsh
  2. Remove the cert from the CLI using backslash to escape the wildcard character, for example:
    delete sys crypto cert \*.example.crt
  3. Remove the associated key using a backslash to escape the wildcard character, for example:
    delete sys crypto key \*.example.crt
  4. Save the configuration with the following command:
    save sys config
  5. Confirm the cert and key were removed with command:
    list sys crypto

Additional Information

K13209: BIG-IP configuration object names must begin with an alphabetic character
