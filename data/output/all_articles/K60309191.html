K60309191: Unable to see AFM logs from Centralized Manager monitoring menu

Description

User is unable to view Network Security events (AFM) in the BIG-IQ Centralized Manager (CM)

Environment

  • BIG-IP and BIG-IQ cluster manually configured to receive Network Security events as described in the manual:
  • Network Security (AFM) service is enabled on the CM, and BIG-IPs send the events to the DCDs
  • The following objects will be present on the BIG-IP
    • The Log Publisher that writes to the High-Speed Log Destination

      sys log-config publisher afm-remote-logging-publisher {
          destinations {
              afm-remote-logging-destination-remote-hslog { }
          }
       
    • The High-Speed Log Destination that points to the AFM remote logging pool consisting of DCD(s) on port 8018

      sys log-config destination remote-high-speed-log afm-remote-logging-destination-remote-hslog {
          pool-name afm-remote-logging-pool_bigip1.local
          }

Cause

Manual configuration makes it quite easy to miss the step of configuring a 'Splunk-type' Log Destination on the source BIG-IP.
To improve, we have ID 1109217 to desplay error message when user set wrong config.
 

Recommended Actions

  • Configure a  Splunk-type Log Destination that forwards to the existing High-Speed Log Destination afm-remote-logging-destination-remote-hslog:

sys log-config destination splunk afm-remote-logging-destination-splunk {
    forward-to afm-remote-logging-destination-remote-hslog
}

  • Reconfigure the existing Log Publisher afm-remote-logging-publisher to use the Splunk-type log Destination instead of the High-Speed Log Destination:
sys log-config publisher afm-remote-logging-publisher {
    destinations {
        afm-remote-logging-destination-splunk { }
    }
}

Additional Information

Deploying AFM logging on BIG-IP using the BIG-IQ deployment method is preferred.
