K54523584: BIG-IQ CM tokumond service constantly restarting

Type
Support Solution
Published
2022-04-08
Updated
2025-04-02
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K54523584

Description

BIG-IQ CM GUI is not accessible and showing "Waiting for BIG-IQ services to become available".
From command line, tokumond service is restarting continuously.

Environment

  • BIG-IQ CM GUI
  • Tokumond service restarting

Cause

None.

Recommended Actions

  1. Temporary stop tokumond service
    bigstart stop tokumond
  2. In CLI, run
    /usr/share/rest/tokumon/clean.sh
  3. Start tokumond service
    bigstart start tokumond
Tokumond service stop restarting continuously and GUI is accessible.

Additional Information

None.
