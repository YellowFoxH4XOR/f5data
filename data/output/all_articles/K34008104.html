K34008104: ActiveX popup asking for admin right BIG-IP APM

Type
Support Solution
Published
2022-03-24
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.4
Source
https://my.f5.com/manage/s/article/K34008104

Description
Users are getting prompted to install BIG-IP Edge Client components. 

Environment

  • BIG-IP APM
  • BIG-IP Edge Client

Cause
Installer Service was installed using user privileges only.

Recommended Actions

  1. make sure that all BIG-IP Edge Client components are installed with admin rights.
  2. make sure that there are no objects causing issues with the Installer Service (eg no GPO in place)

Additional Information
