Description

How to deploy BIG-IP from BIG-IQ using Declarative onboarding with license provided from BIG-IQ

This article describe steps which should be done to deploy BIG-IP licensed by BIG-IQ (License Offering) with Declarative Onboarding using curl or restcurl.

Environment

  • BIQ-IQ CM
  • Declarative Onboarding
  • Licensing from BIG-IQ

Cause

N/A

 

Recommended Actions

Process of deploying BIG-IP from BIG-IQ using DO :

1. Login to BIG-IQ  CM SSH

2.Verify if DO is installed on big-iq by executing: restcurl -u admin:a /mgmt/shared/declarative-onboarding/info

3. Create file with DO declaration based on informations provided in DO manuals

Example of declaration which can be used to deploy BIG-IP with LTM and ASM provisioned  licensed with Utility license  provided by BIG-IQ:

            "failImportOnConflict": false,
            "conflictPolicy": "USE_BIGIQ",
            "deviceConflictPolicy": "USE_BIGIP",
            "versionedConflictPolicy": "KEEP_VERSION"

4.  Push the declaration to IP of BIG-IQ  using postman or curl or directly on BIG-IQ  : restcurl -u admin:a  -X POST /mgmt/shared/declarative-onboarding/ -d "@/shared/tmp/DO.json"

Note: DO.json is file created with declaration. remember to use path if file  is not in the same directory as you currently are.

5. Verify Deployment status  in GUI of BIG-IQ Devices > Devices Onboarding> Task
