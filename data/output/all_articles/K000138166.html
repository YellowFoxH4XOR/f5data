K000138166: BIG-IP SSLO GUI Configuration unavailable. Error: "The requested URL was not found on this server" when accessing SSLO configuration tab in the GUI.

Type
Support Solution
Published
2024-01-09
Updated
2024-01-09
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator
Source
https://my.f5.com/manage/s/article/K000138166

Description

As you navigate the Configuration Utility to "SSL Orchestrator / Configuration", you are prompted with the message:

Error: "The requested URL was not found on this server" when accessing SSLO configuration tab in the GUI.

Environment

BIGIP SSLO module active and configured SSLO objects.

Cause

Root cause is still being investigated.

Recommended Actions

  1. Take an UCS archive of the unit
  2. Navigate to "iApps ›› Package Management LX"
  3. Take note of the version for the package "f5-iappslx-ssl-orchestrator"
  4. Go to F5 download pages - Family: Security, Product: SSL Orchestrator - and select the version currently in use: do please download the .rpm file
  5. Navigate to "iApps ›› Application Services : Applications LX"
  6. Select the app "f5-ssl-orchestrator-dg-data" and click "Delete"
  7. Navigate to "iApps ›› Package Management LX" and select the item "f5-iappslx-ssl-orchestrator"
  8. Click "uninstall"
  9. Click "Import .." (top right of the page) and import the .rpm file we just downloaded.
