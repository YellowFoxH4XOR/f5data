Known Issue

You cannot use the Configuration utility to configure the Generic Alert setting on the Client SSL profile or Server SSL profile.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility to enable Proxy SSL in the Client SSL profile or Server SSL profile.
  • You attempt to use the Configuration utility to enable the Generic Alert in the Client SSL profile or Server SSL profile.

Impact

The Generic Alert setting is no longer visible in the Client SSL profile or the Server SSL profile after you enable Proxy SSL.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice that the Generic Alert setting is not visible in the Configuration utility after you enable Proxy SSL in the Client SSL profile or Server SSL profile.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to modify the Generic Alert setting in the Client SSL profile or Client SSL profile. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Use the following command syntax to enable or disable the Generic Alert setting:

    tmsh modify ltm profile <client-ssl|server-ssl> <profile_name> generic-alert <enabled|disabled>

    For example, to enable the Generic Alert setting in a Client SSL profile called exampleclientprofile, type the following command:

    tmsh modify ltm profile client-ssl exampleclientprofile generic-alert enabled

  3. To save the changes, type the following command:

    tmsh save /sys config
