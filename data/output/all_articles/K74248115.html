Description

After disabling and enabling one of the pool members, no traffic is forwarded to that pool member.

From the Statistics section in the GUI we don't see any traffic on re-enabled pool member.

Environment

  • Wide IP load balancing
  • Persistence enabled

Cause

Persistence configured on Wide IP:

gtm wideip a /Common/example.com {
    persistence enabled        
    pools {
        /Common/example_pool {
            order 0
        }
      }
}

Recommended Actions

Since it's not possible to clear persistence table on DNS system, you will have to disable persistence and re-enable it again - that will clear the table.

This has to be done every time pool member goes down for whatever reason.

Note: If you are running version affected by bug ID977625, do not enable persistence right after disabling. Wait for at least 10 seconds before enabling.

Additional Information

This can also happen when pool member was marked DOWN/UP by monitor.
