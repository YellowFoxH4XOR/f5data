K000156885: The Policy Action page does not function properly after upgrading to v17.1.3 or v17.5.1.x.

Type
Support Solution
Published
2025-10-10
Updated
2025-11-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3, 17.5.1
Source
https://my.f5.com/manage/s/article/K000156885

Description

After upgrading to v17.5.1.x, the Policy Actions page under LTM does not render actions properly, leading to incomplete or missing elements.

Symptoms include missing pool selection and improperly rendered action rules, such as the following when viewing the LTM policy configuration:

{{vm.getCapitalizedLabel(vm.action.action)}} {{vm.getSuffix(vm.action.action)}} {{vm.getLabel(vm.action.target)}} at {{vm.getLabel(vm.action.event)}}

Also, an error similar to the following is displayed when attempting to configure a Rule in the LTM Policy:

transaction failed:010716e0:3: Policy '/Common/Drafts/Example_LTM_Policy', rule 'Example_LTM_Policy_Rule'; target 'forward' action 'select' is missing required parameter 'pool'.

Environment

  • Using LTM policy
  • Upgraded to 17.1.3 or v17.5.1.x

Cause

ID 2078797

Recommended Actions

The latest EHF in myF5 downloads page has the fix for Bug ID 2078797.

  • Hotfix-BIGIP-17.1.3.0.210.11-ENG.iso
  • Hotfix-BIGIP-17.5.1.3.0.192.19-ENG.iso
