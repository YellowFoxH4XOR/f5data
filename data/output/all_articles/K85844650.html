K85844650: BIG-IP device is not allowing GUI access for administrators resulting in certificate revocation message

Type
Support Solution
Published
2020-09-04
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K85844650

Description
- Administrators are getting certificate revoked error when accessing BIG-IP GUI.
- This is not impacting application traffic

Browsers had more and more problems and failures connecting to the BIG-IP.
Older versions of Internet Explorer (IE) are able to connect.
Fails with current versions of FireFox and Chrome


Server test from SSLlabs returns "Assessment failed: Required directive missing: max-age"

Err shows in wireshark as "certificate unknown (46)"

Some internet searching came up with :
---
https://tools.ietf.org/html/rfc6797#section-5
6.1.1.  The max-age Directive

   The REQUIRED "max-age" directive specifies the number of seconds,
   after the reception of the STS header field, during which the UA
   regards the host (from whom the message was received) as a Known HSTS
   Host.
NOTE:  A max-age value of zero (i.e., "max-age=0") signals the UA to
          cease regarding the host as a Known HSTS Host
---
 

Environment

  • BIG-IP LTM VE 
  • Device certificate from a third party Certificate Authority.
     

Cause
CA provided device SSL certifcate does not meet current browser standards.

Recommended Actions

  1.  Work with Certificate Authority (CA) to get a certificate that includes the max-age directive and passes the test at SSLlabs.

Additional Information
