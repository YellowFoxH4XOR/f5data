Topic

Reinstalling the BIG-IP software

The BIG-IP software may be reinstalled using various methods depending on your version.

For detailed instructions about performing a clean installation of BIG-IP software, refer to the following articles:

  • K13117: Performing a clean installation of BIG-IP 11.x - 14.x
  • K10819: Performing a clean installation of BIG-IP 10.x or Enterprise Manager 2.x

Reinstalling configuration data from a backup

Once the software installation process has finished and the system has rebooted, you can configure the system from scratch, or you can install a previously-saved user configuration set (UCS) configuration archive containing a BIG-IP configuration you want to restore.

For instructions about restoring BIG-IP 11.x configuration files, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.

For instructions about restoring BIG-IP 10.x configuration files, refer to K11318: Backing up and restoring BIG-IP configuration files (10.x).

For instructions about restoring BIG-IP 9.x configuration files, refer to K3499: Backing up and restoring BIG-IP 9.x configuration files.
