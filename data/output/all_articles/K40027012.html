Description

The BIG-IP system creates swap usage space during software installation on disk. A high and increasing swap usage may indicate a system under memory pressure. However, high but stable swap usage may not be an issue. Swap area could be filled with data from a previously active process. Because paging data to and from disk is an expensive process, the operating system may leave the swap area filled but is able to claim the area back for use at any time.

    Environment

    BIG-IP

    Cause

    Various

    Recommended Actions

    F5 recommends monitoring the swap value and its usage trend together with the following commands:

    • tmsh show sys memory
    • vmstat 1 5

      Monitor the swap out (so) value. A constantly high swap out value could indicate memory thrashing.

    • cat /proc/meminfo

      Monitor the MemAvailable value. A constant decreasing trend in MemAvailable value could indicate a memory leak.

    • free

    To monitor which process is using swap, you can use the top command.

    1. Log in to Advanced shell (bash).
    2. Type the following command to enter the top utility:

      top

    3. Press f to edit the columns display.
    4. Press down to navigate down to the SWAP = Swapped Size (KiB) row.

      Note: For BIG-IP versions prior to 14.1, press P to select SWAP, and verify that an asterisk now appears next to it. SWAP is now added as a column. Proceed to step 9 below.

    5. Press right to select it for move.
    6. Press up to move SWAP = Swapped Size (KiB) just directly above the COMMAND = Command Name/Line row.
    7. Press Enter to commit.
    8. Press space to add SWAP = Swapped Size (KiB) as a column to the top output. You may observe an additional * next to SWAP similar to the following example:

      * SWAP    = Swapped Size (KiB)
      * COMMAND = Command Name/Line

    9. Press Esc to exit edit mode.
    10. Press shift+w to save the changes to the ~/.toprc file. You may observe a momentary message similar to the following:

      Wrote configuration to '/root/.toprc'

      The next time you start top, the swap column is displayed according to the settings in .toprc.

    11. You can then optionally use a script to run and save the output of the top command over a period of time. For example:

      for i in {1..y} ; do top -bcn 1 >> /var/tmp/top_output.txt ; sleep x; done;

      y: number of times to run the top command
      x: interval in seconds of each run

      For example, the following command runs the top -bcn 1 command every 60 seconds for 10 times.

      for i in {1..10} ; do top -bcn 1 >> /var/tmp/top_output.txt ; sleep 60; done;
