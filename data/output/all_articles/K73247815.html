Description

In Configuration Utility, when accessing Security :: Network Firewall :: Active Rules, the active rules count is stuck at 0 (zero).

Environment

  • BIG-IP AFM Global Context Active Rules

Cause

ID988005 

Recommended Actions

1. Upgrade to a Fixed version or above:
16.1.0, 16.0.1.2, 15.1.4, 14.1.4.2

OR

2. Use workaround as per ID988005 

In order to follow workaround per ID988005 and disable firewall inline editor:

Uncheck the box for "Inline Rule Editor" under Security > Options > Network Firewall settings.
