Topic

You should consider using this procedure under any of the following conditions:

  • You have a BIG-IP APM system deployed in a two-armed topology between the Internet router and an internal router.
  • You want all network access traffic to transit through the internal router.
  • You have corporate servers that reside in different subnets and VLANs accessible via the internal router.

Description

The BIG-IP APM Network Access feature provides secure access to corporate applications and data using a standard web browser or the BIG-IP Edge Client. If you want to transit all network access traffic through an internal router, you should direct all BIG-IP APM egress traffic to the internal router in a two-armed deployment similar to the topology shown in the following figure:

To configure the BIG-IP APM network access in a two-armed deployment, you can create an internal virtual server to intercept and process only network access VPN traffic and configure the internal router as a member of a pool attached to the virtual server.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the BIG-IP APM system.
  • You have configured your BIG-IP APM system with a functioning Network Access profile.

Procedures

Creating a layered virtual server to intercept network access traffic

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Virtual Servers.
  3. Select Create.
  4. Specify the Name.
  5. Specify the Destination Address/Mask. For example, for the previously shown topology, you can enter 172.16.20.0/24 to match all traffic in the LAN subnet.
  6. Specify the Service Port. For example, you can select * All Ports to match all type of traffic ports.
  7. Specify the Protocol. For example, you can select * All Protocols to match all protocols.
  8. For VLAN and Tunnels Traffic, enable traffic on the connectivity profile used for your network access.
  9. Optional: For Source Address Translation, specify a SNAT if your network environment requires it.
  10. For Default Pool, select + to create a new pool.
  11. Specify the Name for the pool.
  12. Add the internal router as a New Member. For example, for the previously shown topology, you can enter 10.10.20.1:0.
  13. Select Finished to save the pool member.
  14. Select Finished to save the new virtual server.
