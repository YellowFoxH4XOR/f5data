K000092758: F5OS-A 1.3.1 clean install results in Tenant stucked in 'Allocating resources to tenant is in progress'

Type
Support Solution
Published
2022-11-29
Updated
2022-11-29
Source
https://my.f5.com/manage/s/article/K000092758

Description

F5OS-A 1.3.1 clean installation may result in the following symptoms:

  • Tenant is stucked in 'Allocating resources to tenant is in progress' after clean installation.
  • Pod with name preceding with "helper-job-<tenant name>" in ImagePullBackOff state.

Environment

  • F5OS
  • Management CLI

Cause

ID1187189

Recommended Actions

1. Determine if the installation ISO has been successfully imported after the clean install by running the following command from Management CLI:
appliance-1# show system image
2. If the output from step 1 shows the following, you will need to import the F5OS-A 1.3.1 ISO image. Refer to K93807441 on the steps needed to import the ISO image. 
% No entries found.
3. Reboot the appliance.
