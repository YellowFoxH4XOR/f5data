Issue

Error Message

01010001:5: default <cpu> vadc TMM Version <number> starting

In this error message, note the following:

  • <cpu> is central processing unit (CPU) architecture.
  • <number> is the BIG-IP system software version number.

For example:

01010001:5: pgo_use x86_64 padc TMM Version 12.0.0.0.0.606 starting

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A Traffic Management Microkernel (TMM) instance is in the process of starting.

Impact

There is no impact; this message is informational.

Recommended Actions

None
