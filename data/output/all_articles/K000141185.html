Description

When using F5 Edge Client to connect to VPN, there is a feature to reuse Windows logon credentials.

After upgrading Windows OS to Windows 11, 24H2 version, this feature does not work.

When a user hits this issue (unable to reuse the Windows Logon Credentials), the Edge Client CTU Report will have similar log entries:

Environment

When using APM Edge Client  on Windows 11, version 24H2 and above.

Cause

Starting in Windows 11, version 24H2, the inclusion of password payload in MPR notifications is set to disabled by default through group policy in NPLogonNotify and NPPasswordChangeNotify APIs. The APIs will be removed in a future release.

The primary reason for disabling this feature is to enhance security. When enabled, these APIs allow the caller to retrieve a user's password, presenting potential risks for password exposure and harvesting by malicious users. 

Recommended Actions

The first workaround is, configure the windows OS, enable MPR notifications, allow the user's password is included in the content of MPR notifications sent by winlogon in the system.

Open the Registry Editor, under Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System, create the DWORD EnableMPRNotifications, the value is 1.
And create / modify the DWORD EnableMPR, the value is 1.

Then exit the Edge client, test it again, reboot the OS if necessary.

 

The second workaround is, change the configuration, disable this feature in the APM client.

To prevent this you need to change the Connectivity profile Settings. On the APM server, go to:

Access  ››  Connectivity / VPN : Connectivity : Profiles

And select your profile. 

  • Click Edit Profile at bottom of page.
  • Click on "Desktop Client Settings"  
  • Untick "Reuse Windows Logon Credentials"
  • Click Ok

Then "Customise Package" at bottom of page and ensure that the "User Logon Credentials Access Service" is unticked.

Once you have a customized Edge Client, you can download the  Edge Client exe, copy it to the device. Uninstall the old Edge Client and install the new.

Note that unticking "Reuse Windows Logon Credentials" will cause it to not be downloaded to the client automatically in the future.

However it does not remove it if it has already been installed. Thus you must uninstall the existing Edge Client to remove it.

The key part of this, is not that your users use this facility, but if the component is installed.

Additional Information

This will not be fixed in the near future since we depend on Microsoft to provide an alternate solution.
