Topic

This article applies to BIG-IP 11.x and later as well as BIG-IQ. For information about other versions, refer to the following article:

  • K5465: Managing static routes (9.x - 10.x)

You should consider using this procedure under the following conditions:

  • You want to add static routes on a BIG-IP or BIG-IQ system.
  • You want to delete static routes on a BIG-IP or BIG-IQ system.

Description

You can add or delete static routes on a BIG-IP or BIG-IQ system for destinations that are not located on a directly connected network. You can add or delete static routes using either the Configuration utility (BIG-IP only) or the TMOS Shell (tmsh). When you add a static route, the system saves it in the /config/bigip.conf file, which it synchronizes between devices in the same device group during a configuration synchronization (ConfigSync).

The following table provides a brief description of each resource type that you can use for the static route:

Configuration utility optiontmsh utility optionDescription
Use GatewaygwThis option is for a network IP address that is the next hop for the route destination. This address must be on a directly connected network of the BIG-IP system.
Use PoolpoolThis option is for a pool of gateways that you want to load balance. You must create the pool before you add a static route to use it.
Use VLAN/tunnelinterfaceThis option is for a route destination that you connect directly to the BIG-IP system. Destination hosts residing on the Virtual Local Area Network (VLAN) typically respond to the Address Resolution Protocol (ARP) request that the BIG-IP system sends, thus providing the BIG-IP system with the destination host MAC address.
RejectblackholeThis option is for dropping all traffic destined for the route destination.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have the IP addresses of the gateways for the route destination.
  • The BIG-IP or BIG-IQ system must have a self IP address on the same subnet as any static route gateway that you create.
  • You have access to the Configuration utility (BIG-IP only) or tmsh.

Adding static routes using the Configuration utility (BIG-IP only)

To add a static route on a BIG-IP system using the Configuration utility, perform the following procedure:

Impact of procedure: Ensure that the static route you want to add does not create an asymmetric route situation on the BIG-IP system.

  1. Log in to Configuration utility.
  2. Go to Network > Routes.
  3. Select Add.
  4. Enter a name for the static route.
  5. Enter the destination.

    For example:

    10.10.22.0

  6. Enter the netmask.

    For example:

    255.255.255.0

  7. Select one of the following resources:
    • Use Gateway
    • Use Pool
    • Use VLAN/Tunnel
    • Reject
  8. Perform the following task for the resource you selected:
    • If you selected Use Gateway, perform the following:
      1. For Gateway Address select IP Address or IPv6 Link-Local Address from the drop-down list.
      2. Enter the IP address in the adjacent field.
      3. If you selected IPv6 Link-Local Address, select the appropriate VLAN or tunnel from the drop-down list in the VLAN / Tunnel section.
    • If you selected Use Pool, select the appropriate pool from the drop-down list.
    • If you selected Use VLAN/Tunnel, select the appropriate VLAN or tunnel from the drop-down list in the VLAN / Tunnel section.
  9. Select Finished.

Adding static routes using tmsh

To add a static route on the BIG-IP and BIG-IQ systems using tmsh, perform the following procedure:

Impact of procedure: Ensure that the static route you want to add does not create an asymmetric route situation on the BIG-IP system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To create a static route, use the following command syntax:

    create /net route <route destination/mask> <gw|pool|interface|blackhole> <IP address|pool name|VLAN/Tunnel name>

    Examples:

    To create a static route to the 10.10.22.0/24 network using gateway 30.30.30.158, you enter the following command:

    create /net route 10.10.22.0/24 gw 30.30.30.158

    To create a static route to a single destination host 10.10.99.111 using the gateway 30.99.99.254, you enter the following command:

    create /net route 10.10.99.111/32 gw 30.99.99.254

  3. To verify the route, type the following command:

    list /net route

    Using the previous command, the output appears similar to the following examples:

    net route 10.10.22.0/24 {
    gw 30.30.30.158
    network 10.10.22.0/24
    }

    net route 10.10.99.111/32 {
    gw 30.99.99.254
    network 10.10.99.111/32
    }

    Note: You must directly connect the static route gateway through an interface of the device.

  4. Save the changes by typing the following command:

    save /sys config

Deleting static routes using the Configuration utility (BIG-IP only)

To delete a static route from a BIG-IP system using the Configuration utility, perform the following procedure:

Impact of procedure: Ensure that deleting the static route does not result in a route destination unreachable situation for the pool members on the BIG-IP system.

  1. Log in to Configuration utility.
  2. Go to Network > Routes > Route List.
  3. Check the static route you want to delete.
  4. Select Delete.
  5. To confirm deletion, select Delete.

Deleting static routes using tmsh

To delete a static route from a BIG-IP or BIG-IQ system using tmsh, perform the following procedure:

Impact of procedure: Ensure that deleting the static route does not result in a route destination unreachable situation for the pool members on the BIG-IP system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To delete a static route, use the following command syntax:

    delete /net route <static route name>

    For example, to delete the 10.10.22.0/24 route name, enter the following command:

    delete /net route 10.10.22.0/24

  3. Save the changes by typing the following command:

    save /sys config
