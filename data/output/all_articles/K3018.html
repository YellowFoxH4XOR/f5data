Topic

This Solution assumes that you have not previously attempted this configuration. If you have previously attempted to configure BIG-IP for use with the Cisco FastEthernet, you must clear any existing trunk configuration, using the following command syntax:

bigpipe trunk <interface> delete

Replace <interface> with the controlling interface of the trunk you previously created.

Configuring a Cisco Fast EtherChannel trunk to BIG-IP

To configure a Cisco Fast EtherChannel trunk to BIG-IP using the 802.3ad protocol, complete the following procedures.

On BIG-IP

Perform the following steps on the BIG-IP system:

  1. Physically connect the first BIG-IP interface included in the BIG-IP trunk to the first Cisco interface included in the Cisco channel definition.
  2. On BIG-IP, verify that the media settings for each interface included in the trunk are correct and specifically set, rather than set to auto-negotiate.

    Note: For information about configuring media settings on BIG-IP, refer to the bigpipe interface man page.

  3. If you make any changes to interface media settings on BIG-IP, save the changes by typing following command:

    bigpipe base save

  4. Create the trunk, using the following command syntax:

    bigpipe trunk <maininterface> define <interface> <interface> ...

    Replace:

    • <maininterface> with the controlling interface for the trunk
    • <interface> with each interface that you want to include in the trunk

    Note: For more information about configuring a trunk, refer to K2190: Configuring a BIG-IP trunk port from the command line.

On the Cisco device

Perform the following steps on the Cisco device:

  1. Verify that the media settings for each interface included in the trunk are correct and specifically set, rather than set to auto-negotiate.
  2. Disable the ports included in the Cisco channel definition.
  3. Disable LACP on each of the ports that will be included in the channel. This will cause the Cisco device to use the 802.3ad protocol.

    Important: There is no support for dynamic aggregation protocols such as LACP/PAGP on BIG-IP. Because of this, you must disable LACP on each port on the Cisco device that will be connected to BIG-IP. If you do not disable LACP on the included ports, If you do not disable LACP for these ports, the trunk will come up for about 1-2 minutes and you will receive a broadcast storm, traffic flood, or messages on the Cisco switch about overflowing buffers. For more information, refer to the following Cisco knowledge base article:

    http://www.cisco.com/en/US/tech/tk389/tk213/technologies_configuration_example09186a0080094470.shtml

  4. Add the ports to the channel definition.
  5. Enable the ports included in the channel.

The trunk between the BIG-IP and the Cisco device is now configured.
