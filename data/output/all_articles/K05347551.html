Description

If after making changes to the settings for e.g. for the db proxy.host, you want to reset it to default and enter <null> as the value, you will see an error message in /var/log/asm similar to:

Jan  1 12:00:00 slotX/,<BIGIP_HOSTNAME> crit g_server_rpc_handler.pl[XXXXX]: XXXXXXXX:X: ASM subsystem error (asm_config_server.pl,F5::Sigfile::AutoDownload::call_soap_server): SOAP request failed: 500 Can't connect to callhome.f5.com:443 (Bad hostname '<null>')

The default settings for db keys proxy.host, proxy.port, proxy.password, proxy.username is <null>. For e.g. for the proxy.host:

sys db proxy.host {
    default-value "<null>"
    scf-config "false"
    value "<null>"
    value-range "string"


Environment

  • Reset the db proxy.host value to default '<null>'
  • Attack Signatures Update unsuccessful

Cause

This is caused by the string '<null>'.
 

Recommended Actions

To reset the db proxy.host to default, use the value 'reset-to-default'.
  1. Log in to the BIG-IP command line via SSH or console
  2. Enter the command to reset the db proxy.host to default:
    tmsh modify sys db proxy.host reset-to-default
  3. Save the configuration:
    tmsh save /sys config
