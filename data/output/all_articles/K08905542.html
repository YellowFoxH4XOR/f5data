Known Issue

When the BIG-IP system receives a Datagram Transport Layer Security (DTLS) cookie that is 32 bytes in length, the system issues an incorrect alert.

This issue occurs when the following condition is met:

  • The BIG-IP system that is configured with a Server SSL profile and DTLS communicates with another BIG-IP system that uses a Client SSL profile and DTLS, and receives a DTLS cookie that is 32 bytes in length.

Impact

The DTLS with a 32 byte cookie fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the Server SSL profile using DTLS receives a cookie with a length of 32 bytes, then in the /var/log/ltm/ log file, the system reports a fatal alert similar to the following example:

    warning tmm[10961]: 01260009:4: Connection error: ssl_hs_rx_hellovfyreq:5103: Invalid dtls cookie len (47)
