Description

Use this article if you want to confirm that the BIG-IP devices in the same HA device-group have the configuration sync

Environment

  • Two or more devices in the same HA device-group

Recommended Actions

 The ConfigSync is a high-availability feature that synchronizes configuration changes from one BIG-IP device to other devices in a device group. So by validating sync status of the devices in the device group is way to confirm that the devices share the same LTM configuration, you can do so by following the below steps,
  1. Log in to the Configuration utility.
  2. Go to Device Management > Overview.
  3. For Device Groups, confirm that all the groups show the below message and there are not changes pending
Expected output if the devices are in sync :

"In Sync

All devices are in sync. There are no changes pending."
  1. If there are changes pending, you can sync the config by selecting the Device-Group in question,
  2. For Devices, select the appropriate device.
  3. Select the synchronization operation.
  4. Select Sync.

To validate the sync status in the CLI you can use the below procedure:
  1. Access to the tmos shell and run the below command

# show cm sync-status

  1. Read the command output to confirm the sync status
  2. The expected output is Color Green and Status In Sync
Expected output if the devices are in sync :

(tmos)# show cm sync-status

----------------------------------------------------------------------------------
CM::Sync Status
----------------------------------------------------------------------------------
Color    green
Status   In Sync       
Mode     high-availability
Summary  All devices in the device group are in sync
Details
         bigip-A.local: connected
         HADeviceGroup (In Sync): All devices in the device group are in sync
         device_trust_group (In Sync): All devices in the device group are in sync
