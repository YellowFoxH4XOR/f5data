Description

When you push the config from Active to Standby, the config syncs as expected, but shortly after, the Standby goes Out-Of-Sync

Environment

ASM is provisioned

Cause

This is caused by Bug ID 1085661 ASM Policy Encoding Stored in MCP incorrectly in upper case. 
asm policy /Common/dev_ASM {
    active
    encoding UTF-8
}
asm policy /Common/prod_ASM {
    active
    encoding utf-8
}
We can see here, that the Policy dev_ASM has the encoding stored as uppercase.

Recommended Actions

To workaround this issue, we just need to change the encoding back to lowercase. 
# tmsh modify asm policy dev_ASM encoding utf-8
# tmsh save sys config
Now if you push the config to the Standby, it will remain In-Sync

Note: Please be aware of Article K62762609, as some entities may need to be reconfigured, if you change the actual encoding to a different encoding. If you only change the case of the encoding, as we have done here, then K62762609 does not apply. It maybe a good idea to Export you policy first, so you can re-import it as different name, so you can compare the settings.
