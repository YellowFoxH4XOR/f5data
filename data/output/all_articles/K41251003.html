Description

When using an external monitor it will appear to not run at all but when looking over the script will appear that there are no errors in it.
When enabling monitor debugging you may see the following error in the log:

(spawn_external_pinger): EAV execve: No such file or directory

Environment

  • External monitor

Cause
This error is caused by the extra line feed character added when saving a file on a Windows machine and then importing it onto a Linux box.  Windows uses a carriage return and a linefeed while Linux doesn't need the extra line feed character.

Recommended Actions

You can verify that the extra character is there by loading the file up in vi and using the -b option, for example:
vi -b /config/filestore/files_d/Common_d/external_monitor_d/<name of your external monitor program file>

At the end of every line you should see a ^M

In order to resolve it, run the following command that will do an in place edit and remove the extra character from each line:
sed -i 's/\r$//' /config/filestore/files_d/Common_d/external_monitor_d/<name of your external monitor program file>

None.
