Description

After performing an upgrade, virtual server with nPath routing stops working.

Environment

  • BIG-IP
  • Upgrade from prior versions to 13.1.5 or later, 14.1.4.4 or later, 15.1.4.1 or later, or 16.1.0 or later
  • nPath routing (Direct Server Return)
  • virtual server with fastl4 profile
  • fastl4 profile with loose-close disabled

Cause

In versions where CVE-2022-23029 is fixed, loose-close enabled on a fastl4 profile is strictly required for nPath deployments.

Recommended Actions

  1. Verify the loose-close option of your fastl4 profile.

    # tmsh list /ltm profile <profile_name> loose-close

    Example:
    # tmsh list /ltm profile fastL4_nPath loose-close
    ltm profile fastl4 /Common/fastL4_nPath {
        loose-close disabled
    }
     
  2. If loose-close is disabled, enable it or create a new profile and enable it.

    # tmsh modify /ltm profile <profile_name> loose-close enabled
    # save /sys config partitions all
     

Additional Information

For all requirements of nPath routing, refer to K11116: Configuring nPath routing.
