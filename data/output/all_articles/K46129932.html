K46129932: How to verify Advance Routing Module is provisioned

Type
Support Solution
Published
2020-04-28
Updated
2023-02-21
Applies to
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K46129932

Description

This article applies if you are trying to
  • Verify if Advance Routing Module is provisioned or
  • Encountered error message when trying to enable a dynamic routing protocol for a route domain
Dynamic routing is not enabled in route domain <route domain ID>

Environment

  • BIG-IP

Cause

None.

Recommended Actions

To verify if Advance Routing Module is provisioned

  1. In TMSH,
  2. Run command: 
    tmsh show /sys license | grep "Routing Bundle"
For F5 ELA license
  • Standalone F5 BIG-IP VE Modules does not support Advance Routing Module. 
  • F5 ELA BIG-IP VE Better or Best Bundle license is required for Advance Routing Module. 

Please contact your Sales representative for assistance to obtain Advance Routing Module.

Additional Information

None.
