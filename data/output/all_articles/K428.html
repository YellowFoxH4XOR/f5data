Known Issue

This is the result of a known issue. The Configuration utility does not accurately report the unit ID of the local self IP address for the second unit in an active-active pair. BIG-IP incorrectly displays the self IP address that is assigned to the first unit, to the second unit.

This issue is cosmetic; BIG-IP will not use the first unit's self IP address for the second unit.

F5 Networks Product Development is tracking this issue as CR27639 and CR41827.
