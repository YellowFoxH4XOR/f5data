Description

The log message below will be logged but not in the timing described in K11633: Error Message: syslog-ng[PID]: Configuration reload request received, reloading configuration

notice syslog-ng[PID]: Configuration reload request received, reloading configuration

Environment

  • BIG-IP v12.x and later

Cause

With this change in behavior: K70264550: The BIG-IP system uses anacron to manage scheduled jobs for daily, weekly, and monthly tasks, the BIG-IP system uses anacron to manage scheduled jobs for daily, weekly, and monthly periodic tasks. anacron executes these daily, weekly, and monthly jobs at random intervals between the hours of 03:00 and 22:00, with a random delay of up to 45 minutes, plus an additional delay of 5 minutes for daily jobs, 25 minutes for weekly jobs, and 45 minutes for monthly jobs. This fit the scenario the seen in the logs.

The BIG-IP system still uses cron to process hourly scheduled jobs. The scripts in the /etc/cron.hourly directory are processed by cron on the first minute of every hour.
anacron executes scripts in the following directories:

  • /etc/cron.daily
  • /etc/cron.weekly
  • /etc/cron.monthly
