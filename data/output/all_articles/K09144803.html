Description

The datasync-global-dg Device Group is found to be in a Not all Devices Synced state on a daily basis.

This requires a manual sync to bring the group back in sync.

Environment

  • datasync-global-dg

Cause

Bug ID 932497

Recommended Actions

Upgrade to a version where Bug ID 932497 is fixed.

F5 Support may also be able to provide an Engineering Hotfix with the fix for this bug included.

Additional Information

This happens when nsyncd is sending multiple modifications to the datasync_global_dg device group in a row, and therefore causing the datasync module to skip force sync for the device group since it must wait 30 seconds between syncs.

This may happen shortly after a Live Update check is done.
