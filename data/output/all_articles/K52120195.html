K52120195: Enabling TLS 1.3 on F5 SSL Orchestrator for inbound topology deployment

Type
Knowledge
Published
2019-07-12
Updated
2023-02-21
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator: 15.0.X, 15.0.0
Source
https://my.f5.com/manage/s/article/K52120195

Issue

Description

Starting in F5 SSL Orchestrator 15.0.0-6.0, the F5 SSL Orchestrator supports configuring TLS 1.3 for inbound topology deployment from the SSL Orchestrator Configuration menu. 

TLS 1.3 is supported on Client SSL and Server SSL profiles. By default, it is disabled on both profiles.  

Environment

  • F5 SSL Orchestrator 15.0.0-6.x.
  • Inbound topology deployment

Note: SSL Orchestrator 6.x needs BIG-IP 15.0.0 and later. It does not run in versions earlier than BIG-IP 15.0.0.

Cause

None

Recommended Actions

Depending on whether you want to turn it on for client side or server side, you can modify the respective Client SSL and/or Server SSL profile(s). To do so, perform the following procedure:

Impact of procedure: Performing this procedure requires you to re-deploy the deployment which may temporarily result in traffic disruption until the deployment is successfully completed.

  1. Log in to the Configuration utility.
  2. Navigate to SSL Orchestrator > Configuration > Configure > Topologies.
  3. Click the inbound topology deployment that you want to modify.
  4. In the SSL Orchestrator configuration, click SSL Configuration.
  5. Click Show Advanced Setting.
  6. In Disabled Options, click TLSv1.3 and move it to the Enabled Options.
  7. For Cipher, click the appropriate group. For example, the f5-default cipher group contains the necessary TLS 1.3 ciphers as shown as follows:
    # tmsh show ltm cipher group f5-default | tr ':' '\n' | grep TLS13
    TLS13-AES128-GCM-SHA256/TLS1.3
    TLS13-AES256-GCM-SHA384/TLS1.3
  8. Repeat the steps 6 and 7 for Server-side SSL.
  9. Click Save & Next.
  10. Click Summary from the SSL Orchestrator configuration workflow and review the changes.
  11. Click Deploy.
