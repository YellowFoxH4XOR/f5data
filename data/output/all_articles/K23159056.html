Introduction

Use this chapter to upgrade the BIG-IP Edge Client on the BIG-IP APM system.

BIG-IP Edge Client is a native, platform-specific application for desktop operating systems which provides endpoint inspection and SSL VPN connectivity to the BIG-IP APM system. BIG-IP Edge Client is included with all BIG-IP APM software versions and can be upgraded when newer BIG-IP Edge Client versions become available.

In BIG-IP APM 13.1.0 and later, BIG-IP Edge Client is available as a separate package, and you can upgrade BIG-IP Edge Client independently from BIG-IP software. In versions prior to BIG-IP APM 13.1.0, you must upgrade the BIG-IP APM system software to upgrade the BIG-IP Edge Client version.

After you upgrade BIG-IP Edge Client, you can customize and download a new BIG-IP Edge Client package from the BIG-IP APM system and distribute it to end users, or provide end users direct access to download the BIG-IP Edge Client package. Any new client packages that you generate from the BIG-IP APM system contain the new client version.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You are running BIG-IP APM 11.6.x or later.
  • You have administrative access to the BIG-IP APM system.
  • You have access to and credentials for F5 Downloads.

Upgrade the BIG-IP Edge Client on BIG-IP APM 13.1.0 and later

BIG-IP APM 13.1.0 and later allow you to upgrade the active BIG-IP Edge Client version on the BIG-IP APM system without upgrading the BIG-IP APM system software. You can download the APM Clients package as an image from F5 Downloads and install it on your BIG-IP APM system, while remaining on your current BIG-IP APM software version.

You can update the APM Clients package within the same major branch or later. F5 does not support downgrading the APM Clients software and doing so may cause the automatic Component Update to fail on client systems. For examples of supported target APM Clients versions, refer to the following table.

Table 22.1 Examples of supported target APM Clients versions
Examples of APM Clients version before upgradeSupported target upgrade version
7.2.17.2.1.1 or later
7.1.9.77.1.9.8, 7.2.1.1 or later
7.1.8.17.1.8.5, 7.1.9.8, 7.2.1.1 or later

F5 bundles the BIG-IP Edge Client with every version of BIG-IP software. When you upgrade the BIG-IP system, the version of APM Clients that you receive with your new software automatically becomes the active APM Clients version.

If you previously upgraded the BIG-IP Edge Client version on your BIG-IP system, and then you upgrade your BIG-IP system to a version of BIG-IP software that contains an older version of BIG-IP Edge Client than your current version, you may downgrade your BIG-IP Edge Client version.

Consider the following example. BIG-IP APM 15.1.1 ships with BIG-IP Edge Client 7.1.8.3. You decide to independently upgrade your BIG-IP Edge Client version to 7.2.1. Later, you upgrade your system to BIG-IP APM 15.1.2, which contains BIG-IP Edge Client 7.1.8.4. Therefore, your new BIG-IP APM software actually downgrades the active BIG-IP Edge Client version to 7.1.8.4.

To avoid this problem, before you upgrade your BIG-IP system, compare the currently active APM Clients version on your system with the BIG-IP Edge Client version that comes with the BIG-IP software you want to upgrade to. For more information about BIG-IP and APM Clients versions, refer to K13757: BIG-IP Edge Client version matrix.

Notes:

  • In a high availability (HA) environment, you must update each BIG-IP system with the new client version.
  • In a multi-blade cluster environment on a chassis system, the system automatically replicates the client to the peers.

Download BIG-IP APM Clients

Impact of procedure: Downloading BIG-IP APM Clients consumes approximately 300 megabytes (MB) of bandwidth and disk space.

  1. Go to F5 Downloads.

    Note: To access this page, you must have an F5 account and log in.

  2. On the Downloads Overview page, select Find a Download.
  3. Under BIG-IP, select APM Clients.
  4. In the product version list, select the version you want.
  5. Under Name, select APM_Clients.
  6. Select I Accept.
  7. Under Filename, select the ISO file.
  8. Select your region, and then complete the steps to download the file.

    Notes:

    • You have the option to use the included MD5 utility to validate the checksum. For more information, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.
    • If you enabled automatic image verification on your BIG-IP system, you must also download the SIG file that corresponds to the APM Clients ISO file you are downloading. For information, refer to K24341140: Verifying BIG-IP and BIG-IQ software images using SIG and PEM files and K15225: Enabling signature verification for BIG-IP and BIG-IQ ISO image files.

Upload the ISO file to the BIG-IP APM system

Impact of procedure: This procedure consumes approximately 300 MB on your BIG-IP system.

  1. Log in to the Configuration utility.
  2. Go to System > Software Management > APM Clients > Import.
  3. Browse to the ISO file you downloaded, and then select Import.
  4. After The upload of image has completed message displays, select OK.

    The uploaded image displays in System > Software Management > APM Clients.

Install the APM Clients image on the BIG-IP APM system

Install using the Configuration utility

Impact of procedure: This procedure installs a new active APM Clients package on your BIG-IP system.

  1. Log in to the Configuration utility.
  2. Go to System > Software Management > APM Clients.
  3. Under Software Images, select the check box for the APM Clients image you just uploaded, and then select Install.
  4. Select Install again.

    Under Installed Image, you can see the currently active image that the system is delivering to users, similar to the following example:

    Version
    apmclients-7190.2020.225.642-5164.0.iso

    Under Software Images, you can see the available images and the default image, similar to the following example:

    Software ImageSystem DefaultImage SizeLast Modified
    apmclients-7185.2021.111.757-4818.0.isoYes311 MBThu Feb 11 18:01:14 2021
    apmclients-7190.2020.225.642-5164.0.isoNo308 MBThu Feb 11 18:22:15 2021

    Note: The System Default indicates the version included with your version of the BIG-IP APM system, not the currently active version. You can upload images older than the System Default, but you cannot install them.

Install using tmsh

Impact of procedure: This procedure installs a new active APM Clients package on your BIG-IP system.

  1. Log in to the BIG-IP APM Advanced Shell (bash).
  2. List the available APM Clients images on the system by typing the following command:

    tmsh  list /apm client image

    The system displays output similar to the following example:

    apm client image apmclients-7185.2021.111.757-4818.0.iso {
        checksum 34008582b479a258aa6f0459d0f1564c
        config-source base
        file-size "311 MB"
        last-modified "Thu Feb 11 18:01:13 2021"
    }
    apm client image apmclients-7190.2020.225.642-5164.0.iso {
        checksum 746b0712d5e8ea2158ec5cb2c7418433
        config-source user
        file-size "308 MB"
        last-modified "Thu Feb 11 18:22:15 2021"
    }

  3. If you haven't done so already, upload the APM Clients image to the BIG-IP APM system by following the steps in the Upload the ISO file to the BIG-IP system section.

    Note: You can also use a utility such as Secure Copy (SCP) protocol to copy the file directly to the /shared/apm/images directory on the BIG-IP APM system, rather than using the Configuration utility.

  4. Enter the following command syntax to install a new BIG-IP APM Clients image on the system, in which you substitute the APM Clients ISO image name for <apmclients-version.iso>:

    tmsh install /apm client image <apmclients-version.iso>

  5. Enter the following command to list the currently active BIG-IP APM client image on the system:

    tmsh list /sys db apm.client.version

    The system displays output similar to the following example:

    sys db apm.client.version {
        value "apmclients-7190.2020.225.642-5164.0.iso"
    }

Upgrade the BIG-IP Edge Client on versions prior to BIG-IP APM 13.1.0

The BIG-IP Edge Client application that comes with versions prior to BIG-IP APM 13.1.0 cannot be upgraded independently from the BIG-IP APM system software. To upgrade the BIG-IP Edge Client in versions prior to BIG-IP APM 13.1.0, you must upgrade the BIG-IP APM system software.

To upgrade the BIG-IP APM system software, refer to the applicable chapters for your system in K84205182: BIG-IP update and upgrade guide.

For more information about BIG-IP Edge Client versions, refer to K13757: BIG-IP Edge Client version matrix.

Download the BIG-IP Edge Client package from the BIG-IP APM system

You can configure a custom BIG-IP Edge Client package that you can download and distribute to users. There are several ways to distribute the BIG-IP Edge Client package to users, including allowing users to download the package directly from the BIG-IP APM system.

Administrators can use the BIG-IP APM Configuration utility to download BIG-IP Edge Client installer packages for Windows and macOS systems. You use the command line to download the BIG-IP Client for Linux. For more information about downloading the BIG-IP Edge Client for administrators, refer to K44328534: BIG-IP administrator instructions for downloading BIG-IP Edge Client for Windows and Mac OS X, and Linux clients.

Administrators can also provide end users with access to download the BIG-IP Edge Client. For example, administrators can upload the BIG-IP Edge Client installation files as Hosted Content in the BIG-IP APM system, and then share the content using direct download links or by creating a webtop download link. For more information about end user access to BIG-IP Edge Client downloads, refer to K05816648: Enabling end user access to download the BIG-IP Edge Client for BIG-IP APM.

Update the BIG-IP Edge Client application on client systems

By default, when a user who has a Windows or macOS system and the BIG-IP Edge Client installed initiates a network access session to a BIG-IP APM system with an upgraded BIG-IP Edge Client, the system automatically updates the user’s BIG-IP Edge Client application before completing the VPN connection. During this process, the BIG-IP Edge Client retrieves the Component Update setting from the connection profile and compares the client component versions on the BIG-IP APM system with the client component versions currently installed on the client system. If higher versions are available, the BIG-IP Edge Client downloads those component versions and updates the application on the client system based on the update setting.

You can determine the currently installed BIG-IP Edge Client version by checking the client systems. To check the BIG-IP Edge Client version installed on a Windows, macOS, or Linux client system, refer to K13757: BIG-IP Edge Client version matrix.

The automatic upgrade behavior is configured with the Component Update setting in the connectivity profile. When set it to yes (default), the BIG-IP APM system checks the currently installed version of the BIG-IP Edge Client on the client system and updates the related components as needed.

Note: The automatic update behavior does not apply to the Linux Client f5fpc client. When using web browsers, BIG-IP APM 13.0.0 and later use VPN helper components, which it updates regardless of the Component Update setting. For more information, refer to K15326: Browser plug-in support for BIG-IP APM features and browser remediation options.

To configure the Component Update feature on the BIG-IP APM system, perform the following procedure:

Impact: When you change the Component Update feature in the connectivity profile, you must install a new BIG-IP Edge Client package that includes the change on the client system for the change to take effect.

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN.

    Note: For BIG-IP 12.x and earlier, go to Access Policy > Secure Connectivity.

  3. Select the connectivity profile that is associated to your network access virtual server, and the select Edit Profile.
  4. Select Win/Mac Edge Client.
  5. In the Component Update list, select yes, no, or prompt.

    A description for each setting is in the following table.

    Component Update SettingDescription
    yesThe BIG-IP Edge Client automatically attempts an upgrade when connecting to the BIG-IP APM system. This is the default setting.
    noThe BIG-IP Edge Client does not automatically attempt an upgrade when connecting to the BIG-IP APM system.
    promptThe BIG-IP Edge Client prompts the end user before attempting an upgrade when connecting to the BIG-IP APM system.

    Note: Even if the Component Update setting in the Connectivity profile is set to No, the system automatically updates some components, including Windows ActiveX components such as Host Control, InspectionHost, Machine Certificate Checker, and SuperHost.

  6. Select OK.
