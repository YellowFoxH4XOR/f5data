K000150186: Is it possible to renew the VELOS OpenShift certificates manually without completely re-installing the cluster?

Source

Description

Is it possible to renew the OpenShift certificates without doing a full cluster re-install via touch /var/omd/CLUSTER_REINSTALL?

Environment

  • VELOS cluster
  • OpenShift certificates

Cause

None

Recommended Actions

There is no supported method to manually renew all of the OpenShift certificates for the cluster, without doing a full cluster re-install.

A full cluster re-install takes up to 90 minutes and renews all of the certificates for a validity period of 10 years.

None
