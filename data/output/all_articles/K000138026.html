Description

All of the API endpoints can be found in https://<bigip-mgmt-ip>/mgmt/tm/

However, under some circumstance, you need to find more granular information of the BIG-IP from a certain API calls.

For example: to retrieve license information, you can use this endpoint: https://localhost/mgmt/tm/sys/license

but the JSON response does not include the details you need.

In such cases, you can use the tmsh or bash API endpoint instead


Environment

BIG-IP

Restful API


Cause

None


Recommended Actions

Use the /util/bash endpoint to execute tmsh commands:


# curl -sku admin:password -X POST -H "Content-Type: application/json" https://localhost/mgmt/tm/util/bash -d "{\"command\":\"run\", \"utilCmdArgs\": \"-c 'tmsh show sys license detail'\"}" | sed 's/\\n/\n/g'
