K000160479: Cannot see version 17.5.1 in the dropdown from the option to discover the version automatically

Type
Support Solution
Published
2026-03-26
Updated
2026-03-26
Applies to
  • F5OS
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000160479

Description

During migration of a BIG-IP configuration from an iSeries system to an rSeries tenant using the F5 BIG-IP Journeys utility, the “Discover version automatically” (target version) dropdown may not show newer BIG-IP versions, and the migration may fail when the destination tenant software version is not compatible with the source UCS/TMOS version.

Environment

  • Source platform: iSeries
  • Target platform: rSeries (BIG-IP tenant on F5OS)
  • Tool: F5 BIG-IP Journeys utility
  • Symptom: Target BIG-IP version missing from the Journeys “Discover version automatically” dropdown

Cause

  • The Journeys tool’s embedded/pre-defined version list may not include the required BIG-IP software version.
  • Incompatible version alignment between the source UCS/TMOS and the destination BIG-IP tenant can prevent migration.

Recommended Actions

  1. Verify Journeys is updated to a current release.
  2. Ensure the destination BIG-IP tenant software version is compatible with the source UCS/TMOS version before migrating; if needed, provision a tenant on a compatible version and retry.
  3. If the desired BIG-IP version is missing from the Journeys dropdown, select the closest available target version to complete the migration, then upgrade the tenant afterward to the desired version.
  4. If migration fails, re-check version compatibility between source and destination and retry after correcting the tenant version.
