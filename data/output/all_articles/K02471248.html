Known Issue

BIG-IP system installations or upgrades do not complete because the user configuration set (UCS) save operation stalls when the system attempts to back up the BIG-IP Analytics database.

This issue occurs when all of the following conditions are met:

  • You attempt to install or upgrade BIG-IP system software into an available slot.
  • The BIG-IP Analytics module is provisioned.
  • The /var/db/mysqlpw file containing the MySQL database password file does not exist.

Impact

The installation or upgrade process does not complete.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP install or upgrade process stalls at zero percent (0%) completion.
