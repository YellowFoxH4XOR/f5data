Known Issue

This is the result of a known issue. FirePass 1200 hardware platforms may report a system fan running at over 20,000 RPM on the Device Management: Monitoring: System Health page. The message will appear similar to the following example:
 
System Fan Speed 4218 RPM OK
System Fan 2 Speed 21093 RPM OK

The reported number is high by a factor of two. The actual fan speed is half of the displayed value when the value is in excess of 20,000 RPM. The other fan speed is reported correctly.

F5 Product Development tracked this issue as CR68473 and CR68717 and it was fixed in FirePass version 5.5.2 for the FirePass 5.x software branch and in version 6.0.1 for the FirePass 6.x software branch. For information about upgrading, refer to the FirePass release notes.
