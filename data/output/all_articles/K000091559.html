K000091559: "No NGINX Controller License Found" on NGINX Controller 3.22.2

Type
Support Solution
Published
2022-05-11
Updated
2026-08-27
Source
https://my.f5.com/manage/s/article/K000091559

Description

On or after May 10, NGINX Controller may show unlicensed with the following error message:

No NGINX Controller License Found. Please add one immediately through your sales channel.

All module tabs in Controller's UI are not showing, except for Platform tab.

When trying to add a license the following error displays:

Error processing the request: the license file has an invalid signature. Check if the license file is for NGINX Controller, then try again. If the problem persists, contact NGINX Support.

Environment

  • NGINX Controller version 3.22.2
  • License/subscription is valid and not expired

Cause

Bug ID ID34050. There is a bundled cert within one of the pods that expired on May 10th.

Recommended Actions

Confirm the issue by checking platform-mgr logs.

kubectl logs $(kubectl get po | grep platform-mgr | sed 's/ .\*//')

If this error is showing you are hitting Bug ID ID34050.

4578 error: Signature could not be verified: pkcs7: failed to verify certificate chain: x509: certificate has expired or is not yet valid

To resolve the issue implement a connected license (Association Token) if available obtained from your MyF5 Portal. See License Types in the NGINX Controller documentation for more information.

If licensing your NGINX Controller with an Association Token is not an option then implement the following steps to resolve the issue:

  1. Contact F5/NGINX support to request the patch fix-license-k8s-3.22.tar to resolve this issue.
  2. Copy fix-license-k8s-3.22.tar file to each Controller host.
  3. Untar the file
    tar xf fix-license-k8s-3.22.tar
  4. Run the replace-docker-files.sh script on each Controller node
  5. Once the script has been run on each node, restart the platform-mgr pod
    kubectl delete pod -l app=platform-mgr

At this time, the license should be restored and Controller's UI should be working as usual.

If you do not see the license at this time, please reload your old license.
