Known Issue

This is the result of a known issue. Using the wizard to create an access policy in a partition other than the Common partition may fail after clicking the Next button on the Review screen. After clicking the Next button, you may get an error message that appears similar to the following example:

Access Policy is not created. See Log File.

In addition, the /var/log/ltm file may have a corresponding error message that appears similar to the following example:

A Resource Assign Agent (non-common-partition) may only reference connectivity resource network access (policy_name_na_res) that is in the same partition or the common partition.

Some of the objects that were configured by the wizard may still be created in the Common partition.

Workaround

You can avoid this issue by manually creating the access policy (instead of using the wizard), or by using the Common partition.
