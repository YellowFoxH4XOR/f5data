Known Issue

This is the result of a known issue. The BIG-IP ASM WSDL conversion is unable to handle methods with the same name in different namespaces.

If different WSDLs contain the same method name for multiple definitions in different namespaces, BIG-IP ASM will only display one method containing the name.

F5 Product Development tracked this issue as CR125165 and it was fixed in BIG-IP ASM version 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in BIGIP-10.0.1-378.0-HF3 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
