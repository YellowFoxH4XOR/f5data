Known Issue

Apple iOS devices using the BIG-IP Edge Client fail to authenticate when using 2 factor authentication.

This issue occurs when all of the following conditions are met:

  • FirePass is configured to request a client certificate and use the CN attribute of the client certificate as the logon username.
  • The user is accessing FirePass with the BIG-IP Edge Client for Apple iOS version 1.0.2.

Impact

Users using the BIG-IP Edge Client for iOS version 1.0.2 are unable to access network resources through FirePass.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • User receives the following error message:

    Authentication Failed. Please check your credentials or configuration.

  • A failed logon attempt is logged in the Reports : Logons report.
  • The output from a Device Management : Maintenance : Troubleshooting : Network packet dump shows the value of the POST /my.activation.php3 password field populated with the same value as the username field.

    For example:

    &vhost=standard&username=user01&password=user01&state=&mrhlogonform=1&translform=1

Workaround

To work around this issue, you can disable the certificate CN to username mapping in the FirePass controller and populate the username in the Apple iOS device. To do so, perform the following procedure:

Impact of workaround: Disabling the certificate username mapping is a global setting and will affect all clients using the certificate username mapping.

Disabling the 'Use the certificate common name (CN) for logon username' option

  1. Log in to the FirePass administrator console.
  2. Navigate to Device Management : Security : Certificates.
  3. Select Do not use certificate field for logon username from the Request client certificate during logon drop-down menu.
  4. Click the Update button.

Populating the BIG-IP Edge Client username

  1. Open the BIG-IP Edge Client app on the Apple iOS device.
  2. Click Settings.
  3. Click the > button next to the configuration you want to update.
  4. Enter the user name to use for logon in the Username field.
