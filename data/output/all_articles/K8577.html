K8577: FirePass does not send RADIUS accounting stop requests if the shared secret contains only numeric characters

Known Issue

This is the result of a known issue. If you enable RADIUS accounting on the FirePass controller, and the RADIUS shared secret contains only numeric characters, FirePass does not send a RADIUS accounting stop request when a user logs out.

Additionally, in versions prior to FirePass version 5.4.2, FirePass does not send a RADIUS accounting start request at user logon if the RADIUS shared secret contains only numeric characters.

Important: If you are running version 5.5.2 of FirePass software, you must install Cumulative Hotfix-HF-552-11 or a later version of the cumulative hotfix to resolve a similar issue with RADIUS accounting stop requests. For more information, refer to K7539: FirePass does not send RADIUS accounting stop requests.

RADIUS accounting is configured on the Device Management: Maintenance: Accounting page in the FirePass Administrative Console.

F5 Networks Product Development is tracking this issue as CR52636.

Workaround

You can work around this issue by adding alpha characters to your RADIUS shared secret.

For example:

1234

When you add the abc alpha characters to your RADIUS shared secret, it will appear similar to the following example:

abc1234

To change your RADIUS shared secret, perform the following procedure:

  1. On the RADIUS server, change the shared secret configured for your FirePass controller to a shared secret that contains at least one alpha character. For more information about performing this step, refer to your RADIUS software documentation.
  2. Log on to the FirePass controller.
  3. Navigate to the Device Management: Maintenance: Accounting page.
  4. Select the Change Shared Secret check box.
  5. In the Shared Secret field, enter the new RADIUS shared secret you configured on the RADIUS server in Step 1.
  6. In the Confirm Shared Secret field, enter the new RADIUS shared secret you configured on the RADIUS server in Step 1.
  7. If the Use a secondary RADIUS server check box is selected, repeat Step 5 and Step 6 in the Secondary RADIUS server section of the page.
  8. Click the Save Settings button.

Note: FirePass sends a RADIUS accounting stop request at the next minute interval, not immediately after user logout. For example, if a user logs out at 12:36:31, FirePass sends the RADIUS accounting stop request at 12:37:00.
