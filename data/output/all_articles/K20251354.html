Known Issue

When a Virtual Clustered Multiprocessing (vCMP) guest runs BIG-IP 13.x or 14.x, while the host runs an older version of the BIG-IP system, the vCMP host logs additional warning messages.

This issue occurs when all of the following conditions are met:

  • You have a vCMP host running one of the following BIG-IP versions:
    • 12.1.x
    • 11.6.x
  • You deploy a vCMP guest or upgrade an existing vCMP guest to BIG-IP 13.x or 14.x.

Impact

The vCMP host logs additional warning messages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Every five seconds, the vCMP host logs a message to the /var/log/ltm file that appears similar to the following example:

    warning vcmpd[<PID>]: 01510005:4: Failed to find value for enum::cli_id (ha_feature_t::provisioning-failed).

Workaround

To work around this issue, you can suppress warning messages related to the vcmpd process from appearing in the /var/log/ltm file of the vCMP host. To do so, perform the following procedure:

Impact of workaround: You suppress all warning messages on the vCMP host that are related to the vcmpd process.

  1. Log in to the TMOS Shell (tmsh) of the vCMP host by typing the following command:

    tmsh

  2. To suppress the vcmpd warning messages, type the following command:

    create /sys log-config filter <filter_name> message-id 01510005 publisher none

    For example, to suppress warning messages using a filter named stop_vcmpd_warn_log, type the following command:

    create /sys log-config filter stop_vcmpd_warn_log message-id 01510005 publisher none

  3. Save the configuration by typing the following command:

    save /sys config
