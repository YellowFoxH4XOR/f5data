K000147950: Is Alert sent by SMS charged?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-22
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147950

Description

If you set up the SMS alert receiver, but you are concerned about whether it is charged.

 

Environment

  • F5® Distributed Cloud (SaaS)
  • F5® Distributed Alert

 

Resolution/Answer

No, this service is not charged, we bear the cost of sending out the sms and don't charge the customer for it.
