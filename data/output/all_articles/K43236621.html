K43236621: Manually define the days before certification expired

Source

Description

By default, we can see expiration of SSL certificates alert within 30 days.
We can create a daily crontab to alert the system administrator before more than 30 days.

Environment

  • With SSL certification in configuration

Cause

None

Recommended Actions

Please save following script in BIGIP crontab and run it as daily crontab:

#!/bin/bash
tmsh run /sys crypto check-cert ignore-large-cert-bundles enabled verbose enabled > /var/tmp/list.txt
cur=$(date +%s)
while read line; do
  temp1=$(echo ${line} | awk -F '|' '{print $1}')
  certdate=$(date +%s --date="$temp1")
  expiredin=$((($certdate - $cur)/86400))
  if [[ $expiredin -lt 90 ]]; then
    certname=$(echo ${line} | awk -F '|' '{print $3}')
    logger -p local0.warning ${certname}" will expired in "$expiredin" days"  ## please modify this line to what actions needed
  fi
done < /var/tmp/list.txt
rm -f /var/tmp/list.txt

it should be like this in 'crontab -l' (which will be run at 2:00AM every day)

0 2 * * * /etc/cert_check.sh
