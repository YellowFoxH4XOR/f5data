K82314400: Enable Debugging on webd Process

Description

This article discusses how to enable debugging for webd process on BIG-IQ systems to provide more detailed troubleshooting information.

Environment

  • There is a BIG-IQ system present which needs to have further troubleshooting on webd process.
  • There is command line access to the BIG-IQ system.

Cause

None

Recommended Actions

Enable debugging on webd process

  1. Backup the webd configuration file

    cp /etc/webd/webd.conf /etc/webd/webd.conf.bak

  2. Type the following command

    vi /etc/webd/webd.conf

  3. Locate the following line:

    error_log /var/log/webd/errors.log notice;

  4. Modify the above line to:

    error_log /var/log/webd/errors.log debug;

  5. Save the file by typing the following:

    :wq!

  6. Restart webd

    tmsh restart /sys service webd
