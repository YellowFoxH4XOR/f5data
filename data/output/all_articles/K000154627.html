K000154627: Ways to download NGINX Plus Image from Command Line for RHEL/Ubuntu Distribution

Type

Published

2025-09-06
Applies to

  • NGINX Plus: R34
Source

Description

  • You are attempting but unable to download NGINX Plus image from MyF5 downloads portal 
  • You want to know an alternative way to download NGINX image 

Environment

  • Product: NGINX Plus
  • Platform: RHEL  (CentOS)
  • Download method: F5 downloads portal (web interface) / Commnad line
  • Ubuntu
  • Rocky Linux

Cause

  • None

Recommended Actions

Workaround for RHEL/CentOS systems:

  1. Ensure you have the nginx-repo certificate/key pair in /etc/ssl/nginx`.
  2. Update your system repositories:
    sudo yum update
  3. List available NGINX Plus versions:
    sudo yum --showduplicates list nginx-plus
  4. Clean yum cache:
    sudo yum clean all
  5. Download the required NGINX Plus package without installing:
    sudo yum install --downloadonly --downloaddir=<directory> nginx-plus-<version>
    Replace <directory> with your desired download location and <version> with the specific package version (e.g., nginx-plus-34-3.el9.x86_64).

Workaround for Ubuntu systems:

  1. Update package lists:
    sudo apt update
  2. List available NGINX Plus versions:
    sudo apt-cache madison nginx-plus
  3. Clean apt cache:
    sudo apt clean
  4. Download the required package without installing:
    sudo apt install --download-only nginx-plus=<version>
    Example:

sudo apt install --download-only nginx-plus=34-3~noble

  1. The downloaded package will be located in /var/cache/apt/archives/`.

Note: Downloading NGINX Plus RPM packages for RHEL/CentOS must be performed on a compatible Redhat-based system; macOS is not supported for this operation. Note: If using a system without internet access, transfer the downloaded package using tools such as WinSCP.
