Issue

Error Message

010714a0:5: Sync of device group <name> to commit id <ID> <hostname> from device <hostname> complete

In this error message, note the following:

  • <name> is the name of the Device Group
  • <ID> is transaction commit ID number
  • <hostname> is the hostname of the local BIG-IP system
  • <hostname> is the hostname of the remote BIG-IP system

For example:

010714a0:5: Sync of device group /Common/Example_group to commit id 10 1234567891012345678 /Common/BIGIP1 from device /Common/BIGIP2 complete

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You have two or more BIG-IP systems in a high availability (HA) configuration.
  • The local BIG-IP system has successfully received a configuration synchronization (ConfigSync) update from a peer BIG-IP system.

Impact

None. The message is informational.

Recommended Actions

None
