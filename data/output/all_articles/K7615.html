Topic

The BIG-IP Edge Client provides an Application Programming Interface (API) for use by third party applications. This API allows you to create customized SSL VPN clients or to provide seamless SSL VPN support to your existing in-house applications. Using this API, applications can access FirePass controller Network Access, Application Tunnels, and Terminal Server Connector favorites.

To create applications using the BIG-IP Edge Client API, download the BIG-IP Edge Client SDK from F5 DevCentral. A separate DevCentral login is required to access this content; you will be redirected to authenticate or register (if necessary).

Important:The FirePass Client API does not currently support non-Windows clients. For a list of supported Windows platforms, refer to the Supported Platforms section of the BIG-IP Edge Client SDK documentation. Additionally, Windows Mobile devices are not supported. However, the Microsoft Connection Manager API may be used for Windows Mobile 5 and 6 devices. For more information, refer to K10187: FirePass Client API support for Windows Mobile devices.

You must also distribute the FirePass Client COM API control with your application client.

Obtaining the FirePass Client COM API control

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Client Downloads: Windows (x86) page.
  3. Click the Customize Package tab.
  4. Select the FirePass Client COM API check box.
  5. Select the other components you want to distribute with this package. For example, Base Controls, Network Access, and Application Tunnels.
  6. Click the Update button.
  7. Click the Download tab.
  8. Click the Download customized package link.
  9. When prompted by your browser, download the customized package.
