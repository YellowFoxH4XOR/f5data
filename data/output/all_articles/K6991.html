Known Issue

This is the result of a known issue. Connections to BIG-IP ASM-enabled virtual servers are first processed by TMM, and then sent to the BIG-IP ASM module using a non-routable loopback IP address. If you enable SNAT automap on the BIG-IP ASM-enabled virtual server, TMM will process the connections and then send them to the BIG-IP ASM module using the system's floating self IP address instead of the non-routable loopback address.

F5 Product Development tracked this issue as CR73437 and it was fixed in BIG-IP 9.3.0 and 9.4.2. For information about upgrading, refer to the BIG-IP ASM release notes.
