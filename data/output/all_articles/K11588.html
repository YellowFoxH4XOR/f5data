Known Issue

This is the result of a known issue. When a OneConnect profile is associated with a BIG-IP WebAccelerator-enabled virtual server that is processing Edge Side Includes (ESI), TMM will immediately crash when the virtual server receives an ESI-eligible request.

F5 Product Development tracked this issue as CR137276, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

Workaround

You can work around this issue by removing the OneConnect profile from the virtual server.
