Description
When creating a new HA Pair, both BIG-IP devices show an Active failover state

Environment

  • Multiple BIG-IP devices configured for HA Failover
  • ConfigSync, Failover Network, and Mirroring setting are correctly defined
  • Device group is created and populated with all HA peers

Cause
The Group type of the device group is set to Sync-Only

Recommended Actions

  1. Delete the existing device group
    1. Login to the BIG-IP UI
    2. Click on Device Management > Device Groups
    3. Click the checkbox next to the device group
    4. Select Delete
  2. Recreate the device group as a Sync-Failover group
    1. Login to the BIG-IP UI
    2. Click on Device Management > Device Groups
    3. Select Create
    4. Enter the device group name in the Name field
    5. Change the Group Type dropdown to Sync-Failover
    6. In the Configuration section, select the appropriate the Members entries from Available and move them to Selected using the << button
    7. Select Finished
  3. Sync the changes to the HA Peer
    1. Navigate to Device Management > Overview
    2. For Device Groups, select the name of the device group you want to synchronize.
    3. For Devices, select the name of the device from which you want to perform the synchronization action.
    4. For Sync Options, select the appropriate synchronization action.
    5. Select Sync.
