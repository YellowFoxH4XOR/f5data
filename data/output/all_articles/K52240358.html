Issue

Error Message

emerg mcpd[<PID>]: 0107070e:0: Software version not covered by service agreement.  Reactivate license before continuing.

In this error message, note the following:

  • <PID > is the process ID for the mcpd process

For example:

emerg mcpd[7581]: 0107070e:0: Software version not covered by service agreement. Reactivate license before continuing.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The service check date in the license is older than the software version release date.
  • The license on the BIG-IP system is expired.

The BIG-IP system compares the license check date to the service check date in the license file when the system initializes. The license check date is a static date built in to the software for BIG-IP and Enterprise Manager systems. For more information on the service check date and license check date, refer to K7727: License activation may be required before a software upgrade for the BIG-IP or Enterprise Manager system. This error occurs most commonly after you perform a software upgrade or load a user configuration set (UCS) archive on the system.

Impact

The BIG-IP system is inoperative in this state and fails to process traffic.

Recommended Actions

  • Before you attempt to perform a software upgrade on a BIG-IP system, re-activate the license in order to update the service check date. 

    For more information, refer to K7727: License activation may be required before a software upgrade for the BIG-IP or Enterprise Manager system.

  • You can try to work around this issue by re-licensing the BIG-IP system.

    For more information about licensing the BIG-IP system, refer to K7752: Licensing the BIG-IP system.
