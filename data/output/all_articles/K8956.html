Known Issue

This is the result of a known issue. Some internal referencing in the PVAC memory manager is faulty.

F5 Product Development tracked this issue as CR98151 and it was fixed in BIG-IP WebAccelerator version 9.4.6. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2 issued for BIG-IP version 9.4.5. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.
