K13740: Enterprise Manager suspends statistics processing during a ConfigSync task

Topic

When a configuration synchronization task is run for a high availability Enterprise Manager pair, the active Enterprise Manager system temporarily suspends the processing of the statistics collected from the managed devices.

Description

When an Enterprise Manager unit is configured as part of a high availability system, the standby Enterprise Manager serves as a warm backup for the active unit. The configuration data that are synced between the high availability pair includes device, alert, archive, certificate, and software repository information. Additionally, the statistics data collected from managed devices can also be synced between the high availability pair if you enable the Include Statistics Data or Include Local Statistics Data option on the ConfigSync page in the Configuration utility. This option is usually enabled by default.

When the Enterprise Manager high availability pair performs a configuration synchronization task to synchronize configuration between the pair, the active Enterprise Manager suspends the processing of the statistics collected from the managed devices if the Include Statistics Data or Include Local Statistics Data option is enabled. During this period, the Configuration utility fails to display the statistics of the managed devices and reports the following error message when you attempt to view the statistics:

Error trying to access the database

After the configuration synchronization task is completed, the Configuration utility will proceed to display the statistics of the managed devices when you attempt to view them. This behavior is by design.

Note: When you attempt to run a configuration synchronization task from the standby Enterprise Manager, the standby Enterprise Manager proceeds to run the task and reports a message similar to the following example on the task:

Synchronize From Peer

During a ConfigSync operation on an Enterprise Manager system, the Enterprise Manager database that normally reports status information may not be available, so the system does not automatically report status. If you manually refresh the screen, you may receive an error. When the database is available, you will not receive an error upon refresh.
