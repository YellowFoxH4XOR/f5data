K000157064: The "Standalone" status indicator is missing from the GUI next to the F5 logo

Type
Support Solution
Published
2025-10-30
Updated
2025-10-30
Source
https://my.f5.com/manage/s/article/K000157064

Description

After migrating to F5OS, the GUI may fail to display the "Standalone" status indicator next to the F5 logo. The Local Trust Domain page may not load, and the device group trust may be missing from the Device Management overview. Attempts to configure high availability (HA) between devices can fail with an error similar to:

install_authority_trust: Exception caught in Management::urn:iControl:Management/Trust::install_authority_trust()Exception: Common::OperationFailed primary_error_code : 16908289 (0x01020001) secondary_error_code : 0 error_string : Trust daemon returned an error: 01070712:3: Values (/Common/device_trust_group) specified for device group device (/Common/device_trust_group /Common/<name_of_device_group): foreign key index (devicegroup_fk) do not point at an item that exists in the database.

Environment

  • Device trust and device group configuration are present
  • High Availability (HA) configuration attempted
  • Post migration

Cause

Corrupted or incomplete device trust and device group configuration after migration. This results in missing GUI elements and prevents successful HA setup due to invalid or missing database references for device groups.

Recommended Actions

  1. Delete all trust domains using: tmsh delete cm trust-domain all
  2. Restart services using: bigstart restart
  3. Rebuild the HA trust and device group configuration from scratch.
  4. Verify that the Local Trust Domain page loads and that correct status indicators (such as "Standalone") appear in the GUI.
  5. Confirm successful HA configuration and synchronization between devices.
