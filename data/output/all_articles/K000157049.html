Description

Please consider the recommendation in this article if the system post upgrade shows symptoms of security policies fails to load and there are logs indicates space starvation issue.

Environment

  • Adv. WAF

Cause

Starting with BIG-IP 17.x, the system uses a manifest generation process to maintain its configuration. This process relies on available space in the /var directory, so it’s important to monitor and minimize its usage. 

Recommended Actions

Perform the following steps to stabilize your system and proceed with a more reliable configuration upgrade:

  1. Roll back the upgrade to restore the system to a stable state.
  2. Follow the instructions in K04428546 to increase disk provisioning for the /var directory before performing the upgrade.
  3. Ensure that Install Configuration is set to Yes before activating the new boot location.
  4. After the reboot, verify that the /var disk space is sufficient and confirm that the configuration has loaded successfully.

Additional Information

Verify that the ASM configuration has fully loaded before activating the device. To confirm this, search for the following log entry in /var/log/ts/asm_config_server.log:

load_complete,,populating completed successfully

After locating this entry, review any error messages that appear after it. You can use the command below to assist with the verification:

zgrep -A 50 "load_complete,,populating completed successfully" /var/log/ts/asm_config_server.* | grep -i error
