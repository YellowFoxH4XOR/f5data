Description

You can use the F5 ASM Anti-Bot Mobile Application SDK to detect traffic coming from mobile applications and determine, which requests to allow and block to your application. The ASM Anti-Bot Mobile Application SDK allows you to test mobile clients for human activity rather than responding to mobile application traffic with JavaScript-based challenges.

The following table covers ASM Anti-Bot Mobile SDK support for the Android and IOS operating systems.

Mobile OSSupported versionsAPILanguage

Note: There is no dependency between the SDK version and ASM version.
