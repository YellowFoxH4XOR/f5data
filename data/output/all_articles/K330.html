Topic

Time to live (TTL) variables control how long information is saved in cache to answer new queries without contacting an authoritative server. Each Wide IP has a TTL setting assigned; the default is 30 seconds. You can change this through the Configuration utility or the wideip.conf file. In the following example, the wide IP TTL limit is 10 seconds.

Example wide IP TTL configuration file:

wideip {
 address           192.168.25.220
 port              80 // http
 ttl               10
 name              'www.lb.test.com' // num_requests 0
 ecv { protocol none }
 pool {
 name           'US'
 ratio          1
 last_resort    no
 limit { /* none */ }
 preferred      leastconn
 alternate      ret2DNS
 }

Note: Some DNS servers and clients do not accept extremely low TTL values. To address this issue, you can use the 3-DNS Controller's LDNS Round Robin feature. Refer to the 3-DNS Controller Administrator Guide for more information about this feature.

Values

The following two values affect the TTL variables:

  • Minimum
  • Object limits

Minimum

The Minimum value is located in the SOA section of the zone file and applies to all resource records (RR) in the zone file; however, each RR can override the zone file's Minimum value.

For example, if you do not want resolvers (clients that access nameservers) to cache the previous answer issued for a domain name, you would set the Minimum to a low value.

In the following zone file example, the Minimum is set to 30 seconds for every entry and the domain name, www.wip.domain.com, is overridden so it will never be saved in a DNS cache. This results in a new query each time, allowing the 3-DNS Controller to provide the best answer to each query.

Example zone file configuration

wip.domain.com. IN SOA
3dns.newyork.domain.com.postmaster.domain.com.
 (
 199806291430 ;
 900 ; Retry
 3600000 ; Expire
 30 ) ; Minimum (default ttl for entire file)
 www.wip.domain.com 0 IN A 192.168.101.60

Object limits

Each 3-DNS Controller object has an associated TTL. When an object's TTL has expired, the 3-DNS Controller stops using a dynamic load balancing method and reverts to a static method.

Example static configuration:

globals {
 bigip_ttl 60
 host_ttl 120
 vs_ttl 120
 path_ttl 320
 }
