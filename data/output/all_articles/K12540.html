K12540: Deleting a route domain that is the default route domain for an administrative partition

Topic

A route domain that has been configured as the default route domain for an administrative partition cannot be deleted. Deleting this route domain would leave the administrative partition without a default route domain. In the Configuration utility, the check box to specify the route domain for deletion is unavailable. If you attempt to delete the route domain from the command line, the system will return an error message that appears similar to the following example:

0107097c:3: The specified route domain (2) is the default route domain for one or more partitions (test2) and cannot be deleted.

This behavior is expected.

Deleting the route domain

To delete the route domain, you first have to set the administrative partition to use a different route domain, such as route domain 0, as the default. To do so, perform the following procedure:

  1. Log in to the BIG-IP system Configuration utility as the admin user.
  2. Ensure that the relevant administrative partition is selected (the one whose default route domain is the route domain that you want to delete).
  3. Navigate to Network >> Route Domains.
  4. Click the route domain that you want to be the new partition default route domain.
  5. Under Partition Default Route Domain, select Make this route domain the Partition Default Route Domain.
  6. Click Update.

    You can now delete the former partition default route domain.
