Description

You are looking for a way to limit the Maximum number of connections to a Virtual Server over time, as per Source IP Address of each Client.

Environment

  • Virtual Server which terminates the connections on F5
  • Using an iRule Script to count and limit the Maximum number of connections from specific Source-IP over time
  • LTM

Cause

In some scenarios, you may want to limit the number of Maximum Established connections from any specific Source-IP over time to manage both the F5 and Server resources, and prevent from many Established Connections per Client's IP.

Please note that there is another useful Article "K45530602" which can be helpful for limiting the number of concurrent connections to a Virtual Server as per-second basis under the "Connection Rate Limit" settings of a Virtual Server. But that could not be helpful if you want to count and limit the total number of connections from any Source-IP, over time.

Recommended Actions

There are two sample iRule scripts for this purpose, and you can use either of the below scripts.

In below iRule samples, the total Maximum number of Established Connections from any Source-IP was considered as "10", but you can simply modify the script based on your demand.

 

iRule Sample (1):

# Limit each client IP address to 10 concurrent connections
when CLIENT_ACCEPTED {
   # Check if the subtable has over 10 entries
   if { [table keys -subtable connlimit:[IP::client_addr] -count] >= 10 } {
      reject
   } else {
      # Add the client IP:port to the client IP-specific subtable
      table set -subtable connlimit:[IP::client_addr] [TCP::client_port] "" indef
   }
}

when CLIENT_CLOSED {
   # When the client connection is closed, remove the table entry
   table delete -subtable connlimit:[IP::client_addr] [TCP::client_port]
}

 

iRule Sample (2):

when CLIENT_ACCEPTED {
    # Define the maximum allowed concurrent connections per IP
    set max_connections 10
    
    # Count the number of current connections from this source IP
    set current_connections [table lookup [IP::client_addr]]
    
    # Check if the current connections exceed the defined limit
    if { $current_connections >= $max_connections } {
        # Exceeding the limit, reject the connection
        reject
    } else {
        # Increment the connection count
        table set -subtable connections [IP::client_addr] [expr {$current_connections + 1}] indef
    }
}

when CLIENT_CLOSED {
    # Decrement the connection count when the connection closes
    set current_connections [table lookup [IP::client_addr]]
    if { $current_connections > 0 } {
        table set -subtable connections [IP::client_addr] [expr {$current_connections - 1}] indef
    }
}
