Description

Starting 13.0.0, the following warning message may be logged on BIG-IP after receiving a full config-sync from an HA peer:
warning mcpd[<pid>]: 0107185a:4: Warning generated, for version <current_version> or greater : Please use threshold-sensitivity. auto-threshold-sensitivity is being deprecated
 
Environment
  •  A full config-sync is initiated
  •  BIG-IP is on version 13.0.0 or above.


Cause

Note: During full config-sync, the receiving BIG-IP validates the configuration and can print this advisory message.This configuration exists whether AFM is provisioned or not. Provisioning AFM is not a prerequisite for this warning to be logged.

This log refers to the following setting in AFM being deprecated:
security dos device-config dos-device-config auto-threshold-sensitivity [value is: integer between 1 - 100(default is 50)]


Starting 13.0.0, this has been replaced with the following AFM setting:
security dos device-config dos-device-config threshold-sensitivity [value is one of: low, medium(default) or high]


Recommended Actions

This message is advisory only and can be safely ignored.
