K000158930: F5OS host pcap on R5000/R10000 platform shows a frame which should egress onto the network, but frame is not actually sent out onto the network

Type
Support Solution
Published
2025-12-29
Updated
2025-12-29
Applies to
  • F5OS
  • rSeries Platforms
  • F5OS-A: 1.8.X, 1.8.3, 1.8.0
  • rSeries 5000
  • rSeries 10000
Source
https://my.f5.com/manage/s/article/K000158930

Description

Sometimes, a  frame shown in an F5OS host pcap taken on an R5000 or R10000 platform might not actually make it out onto the wire.

Environment

F5OS on R5000/R10000 platforms


Cause

This can occur because the layer 2 logic on these platforms is performed after the pcap entry is taken, so it means that a frame can appear in a pcap which seems to be an egress frame which should be sent out on the network, but in practice that frame might not be actually sent out on the network by the F5OS host due to being filtered/blocked by some of its layer 2 tables.

 

Recommended Actions

None.


Additional Information

This is unfortunately due to where the pcap capturing hook sits on the F5OS device, and the only sure way to confirm for sure as to what has actually been sent out onto the network (ie. onto the wire) is by taking a capture on the switchport (or other device) connected directly to the relevant interface of the F5OS host.
