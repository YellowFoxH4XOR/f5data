Description

When trying to deploy SSLO RPM 7.5 next error appears:

[orchestrator config processor] deployment failed for error: [haawareicrdeploy processor] error: transaction failed:invalid property value "type":"ending-abort"

Environment

  • BIG-IP SSLO
  • Using a version prior to 15.1.1
  • RPM 7.5

Cause

SSL Orchestrator 7.5 does not work with BIG-IP versions prior to 15.1.1. SSL Orchestrator 7.5 must use BIG-IP 15.1.1.However, the download link for the BIG-IP 15.1.1 RPM download is named f5-iappslx-ssl-orchestrator-15.1.0-7.5.2.noarch.rpm. Use the Release: 15.1.0 link under Downloads from the 15.1.0 page to locate the RPM. 

Recommended Actions


Run the default RPM of your version or upgrade the system to version 15.1.1 or higher.

Additional Information

None.
