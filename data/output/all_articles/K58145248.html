Description

Many IP addresses resolve to the same F5 MAC address on upstream devices.

Environment

  • VLAN

Cause

This is normal behavior. The IPs all relate to listeners or SNAT translation addresses that reside in the same VLAN on the BIG-IP.

Recommended Actions

To validate which MAC address belongs to a particular BIG-IP VLAN, use the following command:

show /net vlan <vlan name>

This example output indicates that the MAC address 00:00:5e:00:53:81 is used in the EXT_VLAN VLAN.

show /net vlan EXT_VLAN
-------------------------------
Net::Vlan: /Common/EXT_VLAN
-------------------------------
Interface Name      EXT_VLAN
Mac Address (True)  0:0:5e:0:53:81
MTU                 1500
Tag                 500

Note: The OUI 00:00:5e is not an F5 OUI, but an example OUI as defined in RFC 7042 section 2.1.2.
