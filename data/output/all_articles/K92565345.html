Description

When the DB key provision.extramb is modified or the Management provisioning level is changed, TMM will restart automatically for the change to take effect and if HA is configured and the device is active, a failover may occur.
Configuration Utility may show "The system must be rebooted for some changes to take effect.", and the CLI prompt may show "REBOOT REQUIRED" if you reset the value to default (0).
 

  • Messages similar to the following are observed in /var/log/audit:

user root - transaction #16738795-2 - object 0 - modify { db_variable { db_variable_name "provision.extramb" db_variable_value "500" } } [Status=Command OK]
 

  • Messages similar to the following are observed in /var/log/ltm:

info mprov:394:: '/usr/bin/bigstart stop avrd monpd mysql tmipsecd tmm tomcat vxland'
warning sod[8995]: 01140029:4: HA proc_running tmm fails action is go offline and down links.
info mprov:394:: '/usr/bin/bigstart start avrd monpd mysql tmipsecd tmm tomcat vxland'
warning sod[8995]: 01140029:4: HA daemon_heartbeat tmm fails action is go offline down links and restart.
 

Environment

  • BIG-IP
  • any version
  • Updating DB key provision.extramb
    or
  • Updating Provision
     

Cause

  • You modified DB key provision.extramb using tmsh, or
  • You changed the Management provisioning level using Configuration Utility
     

Recommended Actions

It is recommended to modify DB key provision.extramb or change the management provisioning level during a maintenance window as traffic disruption may occur.
