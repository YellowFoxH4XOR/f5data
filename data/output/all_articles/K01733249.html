Description

The APMClient iso is a package that is installed on your APM, controls the the behavior of active VPN APM sessions, and provides most of the APM clients that can be downloaded (or updated) directly from the APM. This iso covers protocol helpers that use f5epi: and f5vpn: links to extend Web Browsers, as well as native VPN Clients. It does not include VPN clients that are distributed directly via the appropriate APP store.

See below for the list of applicable release notes.

A version of APMClient is pre-installed (as bundled) with each BIG-IP upgrade but can be separately upgraded by updating the apmclients iso file as described in K52547540, So this means the decision as to what client side version to use needs to be made explicitly. Clients Devices will upgrade automatically if enabled (see K15302 below) on first connection. However, once you upgrade BIG-IP versions is not possible to downgrade the apmclient version below the system bundled version.
If you were already running a newer version of apmclient in an APM, and upgrade to a newer BIG-IP version, you may inadvertently downgrade the installed apmclient version.

Recommended Actions

F5 generally recommends upgrading to the newest version available after reviewing the release notes and suitable testing to confirm and ensure the best end user experience.
Using the latest feature release (ie version 7.2.6.2 or 7.2.7.2) may contain changes that require updating the Access Policy for correct operation.
The release notes for apmclients are mostly not cumulative the release note for each version may contains the new feature documentation and should be reviewed. Each BIG-IP release manual contains documents that may only be applicable to features of that specific version.

Environment

  • supported BIG-IP APM 17.1.x and above (for details see K5903: BIG-IP software support policy)
  • APM Access Policy deployed
  • Ongoing Endpoint Device OS releases and upgrades
  • Ongoing CVE releases

Cause

With reference to K22258530: APM Client Support policy states, "F5 provides software fixes in the current latest major released version and one version prior".

  • Starting in early 2021, version 7.1.8.x was no longer being updated (version 7.1.8.5 did include the March 2021 CVE fixes).
  • Starting in early 2022, version 7.1.9.x is no longer being updated.
  • Since July 2025, with version 16.1 version 7.2.4.x are no longer supported
  • Since early 2026 the latest supported releases (and BIG-IP 21.x) have contained apmclients 7.2.6.3x

    You should always check any previous BIG-IP maintenance versions upgrade, as it may require additional manual upgrade to the latest apmclients, epsec, or Guided Configuration. Previous examples were
  • upgrade from an earlier version to BIG-IP 15.1.2.1 and your system Edge Client will be reset to 7.1.8.4, you must upgrade to 7.1.8.5 or browser initiated VPN will fail.
  • upgrades to 13.1.3.6, 14.1.4, 15.1.3, and 16.0.1.1 will reset your system Edge Client to 7.2.5.x
    forcing a major macOS VPN GUI client change that cannot be reversed
  • Upgrades to 17.1.3, 17.5.1, 21.0.0 or 21.1.0 will reset your system Edge Client to 7.2.6.x
    and my require clients be re-installed individually.

Additional Information

If you are using recent OS versions like Apple macOS Sequoia, or Windows 11 then the best experience is always with the latest version of both apmclients and the latest OPSWAT oesis EPSEC (especially if you are using Endpoint Inspection features).

The release notes for apmclients are mostly not cumulative and the first release note for each version contains the new feature documentation.
Check all the "known issues" in the intermediate versions, and if they are relevant, check if they are fixed in a subsequent release.
