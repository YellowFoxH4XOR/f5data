Description

"REST framework is not available" is displayed when viewing some elements of the Configuration Utility

Environment

  • BIG-IP
  • Configuration Utility

Cause

None

Recommended Actions

Clear rest storage to allow restjavad to restart

  1. From bash run:
    clear-rest-storage
    bigstart restart restjavad
    NOTE: Avoid using clear-rest-storage on BIG-IP SSLO  as its removing configuration from systems.
  2. Access Configuration Utility and verify access is restored

Additional Information

If you observe this similar message on the Configuration Utility on System > Software Management > Live Update, refer to K83661482: Unable to access "Live Update" Page for more information.
