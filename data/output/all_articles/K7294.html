Known Issue

This is the result of a known issue. If you create either a Certificate Signing Request (CSR) for an SSL server certificate or a self-signed SSL server certificate and include an apostrophe character in certain fields, the apostrophe character will be stored as a backslash character.

From the Device Management : Security : Certificates page, when you create a CSR for an SSL server certificate or create a self-signed SSL server certificate, you will be prompted to fill in values for the certificate fields. The following fields will accept an apostrophe character, but will store it as a backslash character:

  • State (S)
  • City (L)
  • Company (O)
  • Organizational Unit (OU)

When you display the certificate in the FirePass controller Web UI, you will see either a backslash or a double-backslash, depending on the page in the Web UI that is displayed.

Note: Self-signed client root CA certificates are not affected by this issue.

F5 Product Development tracked this issue as CR75134 and it was fixed in version 6.0.2.  For information about upgrading, refer to the FirePass Release Notes.
