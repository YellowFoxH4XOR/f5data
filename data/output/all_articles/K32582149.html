Topic

Upgrading the BIG-IP Edge Client software may require a secondary user agreement acceptance.

Description

This issue occurs when all of the following conditions are met:

  • Your iOS device has a BIG-IP Edge Client software installation prior to 2.0.6.
  • You upgrade, or an MDM system upgrades, the BIG-IP Edge Client version to 2.0.6.
  • You launch BIG-IP Edge Client directly or as a per-app VPN.

Impact

The BIG-IP Edge Client application will not attempt to establish a session until you enable the user agreement.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you launch BIG-IP Edge Client as part of a per-app VPN configuration, the session does not initiate.
  • The user device home screen has a BIG-IP Edge Client icon that did not display prior to the upgrade.
  • When launching the BIG-IP Edge Client directly, the user is prompted to enable the user agreement.

Workaround

To work around this issue, you can launch BIG-IP Edge Client directly by tapping the BIG-IP Edge Client icon and selecting Enable when presented with the user agreement.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
