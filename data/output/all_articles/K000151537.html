Description

The BIG-IP device has been upgraded and the configuration cannot be loaded. The device may get stuck during boot. The following error appears when executing the 'tmsh load sys config' command:

01b90023:3: Bot defense profile (/Common/<profile>) signature category override not supported for (/Common/<category>) which belongs to (/Common/<class>) class. 

Unexpected Error: Validating configuration process failed.

Environment

  • BIG-IP
  • VE
  • Bot-defense profile

Cause

It is due to ID1933061.

Basically when you configure mitigation setting exception on bot-defense profile you can do it for the following bot class: Trusted Bot, Untrusted Bot, Suspicious Browser, Malicious Bot.

You should not do that for the following class: Unknown, Browser, Mobile Application.

Recommended Actions

In order to fix this problem you would need to manually edit bigip.conf file and delete mitigation setting exception for /Common/<category> category on affected bot defense profiles.

Example part of the configuration that needs to be removed:

 

signature-category-overrides {

/Common/<category> {

action alarm

}

}

 

After deletion, save the bigip.conf file and try to load the configuration once again.
