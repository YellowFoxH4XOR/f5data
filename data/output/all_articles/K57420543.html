Topic

You should consider using this procedure under the following condition:

  • You want to configure cookie tampering protection for your BIG-IP ASM security policy.

Description

Cookies are supposed to be sent back to the server unchanged, but attackers may be able to modify the value of a cookie before sending them back to the server. To prevent this, you may want the security policy to alert you to changes to specific cookies, such as session-related cookies that are set by the web application, and block those requests. If so, you can add enforced cookies to the policy. An enforced cookie is one that must not be modified or it generates the Modified domain cookie violation.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You must have access to the Configuration utility.
  • You have compiled a list of cookies that must not be modified.

Procedures

  • Configure cookie tampering protection
  • Enable the modified domain cookie violation

Configure cookie tampering protection

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Headers > Cookies List.
  3. For Current edited policy, select the name of the policy you want to modify.
  4. Select Create.
  5. For Cookie Name select Explicit if the system should identify the cookie by a specific name or Wildcard if you want to specify cookies using wildcard characters (for example *f5.com), then enter either the name of the cookie or the wildcard pattern string, respectively.
  6. For Cookie Type, select Enforced.
  7. Leave the Perform Staging check box selected if you want the security policy to evaluate traffic before enforcing the cookie.
  8. If you want the system to add the HttpOnly attribute to the response header of the domain cookie, select the Insert HttpOnly attribute check box.
  9. If you want the system to add the secure attribute to the response header of the domain cookie, select the Insert Secure attribute check box.
  10. Select Create.
  11. Select Apply Policy.

Enable the modified domain cookie violation

When you enable the modified domain cookie violation, the system checks that the web application cookies within the request have not been altered, and the system checks that the request includes a web application cookie defined in the security policy. To enable the modified domain cookie violation, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. For Current edited policy, select the name of the policy you want to modify.
  4. For Policy Building Settings, expand Cookies.
  5. For the Modified domain cookies violation, select the Learn, Alarm, and Block check boxes as appropriate.
  6. Select Save.
  7. Select Apply Policy.
