K000163419: 40G port on BX110 VELOS blade stuck DOWN after a reboot or upgrade with OPT-0036

Type
Support Solution
Published
2026-09-25
Updated
2026-09-25
Applies to
  • F5OS Products
  • F5OS-C: 1.8.2
Source
https://my.f5.com/manage/s/article/K000163419

Description

A 40G port is stuck DOWN after a reboot or upgrade to F5OS-C 1.8.2.

default-2# show interfaces interface 2/1.0
interfaces interface 2/1.0
 state type              ethernetCsmacd
 state mtu               9600
 state enabled            true
 state oper-status        DOWN
...

Remote switch side reports its port as UP.

Both rx and tx power are normal, with no warnings or alarms.

Environment

  • BX110 blade
  • 40G port
  • System already has the fix for ID2151753

Cause

  • Bug ID 2326397: BX110 ports configured for 40G can fail to link with OPT-0036 optics

Recommended Actions

Reboot the affected blade a second time.

Additional Information

Issue occurs rarely. No fix is available at the time of this article's publication.
