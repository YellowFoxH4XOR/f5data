K000092900: Interfaces will not come up after changing mode on F5OS appliance

Type
Support Solution
Published
2022-11-30
Updated
2023-12-07
Source
https://my.f5.com/manage/s/article/K000092900

Description

Interfaces will not come up after changing mode on F5OS appliance


Environment

F5OS

Cause

Changing the port group mode impacts the view of physical interfaces published by the system. The previous interfaces that corresponded to the previous port group mode are deleted, and new ones are created. All configuration associated with the deleted interfaces is also lost.

Recommended Actions

Reboot the appliance to reload the new configuration
