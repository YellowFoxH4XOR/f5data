K000147039: Why my Customer Edge (CE) is unable to connect to closest Regional Edge (RE)?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147039

Description

  • Customer edge (CE) is not connecting to the closest Regional Edge (RE)
  • You did not specify coordinates during the registration process and observe the latency is very high

Environment

  • F5® Distributed Cloud Console 
  • Customer Edge
  • SMSv1

Cause

When registering an SMSv1 CE, the system will by default select the closest REs from longitude and latitude, not necessarily the closest network path.

Answer/Recommended Actions

  • Regional Edge is selected after you registered CE on Distributed Cloud Console.
  • The system will find the closest RE from CE's longitude and latitude you entered during the registration process.
  • Once CE is registered, at this time we don't support changing the connected RE.
  • CE will not select new REs without a rebuild.
  • You cannot force a re-selection, you have to build a new CE.
  • You can start the registration from scratch
