Description

F5 Support may ask you to produce a core file on the BIG-IP system to establish the state of TMM or another process during an event. You can send signals, such as SIGABRT and SIGSEGV, to processes on the BIG-IP system using the kill command from the command line. Forcing the BIG-IP system to produce a core file interrupts service and may cause a failover or instability. You should perform this task only when asked to do so by F5 Support.

Environment

  • BIG-IP
  • Version 12+
  • Administrative access to the BIG-IP command line

Cause

None

Recommended Actions

To provide diagnostic core file to F5 Support, perform the following actions:

  1. Core files are compressed memory spaces of daemons, ensure you have adequate an amount of disk space:
    • K14403: Maintaining disk space on the BIG-IP system
       
  2. Generate the requested diagnostic core file:
    • TMM diagnostic core:
      • K15569543: Producing a TMM diagnostic core file
    • BD diagnostic core:
      • K53105268: Producing a diagnostic core file of the BD daemon
    • Other daemon diagnostic core:
      • K65944711: Producing a BIG-IP daemon diagnostic core file
         
  3. Generate an md5sum for the collected diagnostic core file:
    • K41022796: Generation of md5sum for transmission to f5 support
       
  4. Upload requested files to F5 support:
    • K000090853: Exchange files with F5 Support

Additional Information

        md5sum file should also be provided when uploading a core file to F5.
