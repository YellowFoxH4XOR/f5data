K000135780: VELOS shows software and partition install status as "none"

Type
Support Solution
Published
2023-08-08
Updated
2023-08-08
Applies to
  • F5OS
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000135780

Description

Output of show system image and show partitions install lists INSTALL STATUS as none.

# show system image
                     SERVICE      ISO      INSTALL
NUMBER  OS VERSION   VERSION      VERSION  STATUS
----------------------------------------------------
1       1.5.1-14085  1.5.1-14085  -        none      <-- Note
2       1.5.1-14085  1.5.1-14085  -        none

# show partitions install
         INSTALL     INSTALL
         BLADE OS    SERVICE  INSTALL  INSTALLING
NAME     VERSION     VERSION  STATUS   CONTROLLER
---------------------------------------------------
default  -           -        none     -
none     -           -        none     -

Is this expected?

Environment

  • VELOS
  • CLI output

Cause

This is expected after a clean install, or after upgrading from a version prior to 1.2.0.

The INSTALL STATUS should list success after upgrading from later versions.

Recommended Actions

None
