K41531725: Enable AWS ENA Driver on BIG-IP LTM

Type
Support Solution
Published
2019-11-28
Updated
2023-02-21
Applies to
  • Public Cloud
  • BIG-IP
  • Amazon Web Services
  • BIG-IP LTM: 13.1.0, 13.1.1, 13.1.3, 13.1.4, 13.1.5, 13.1.X
Source
https://my.f5.com/manage/s/article/K41531725

Description

When you make an upgrade, there's a chance the ENA driver might get disabled so your AWS instance may lose connection.

Environment

  • Upgrade just being done where ENA driver was available

Cause

The is caused after the ENA driver has been disabled after an upgrade.

Recommended Actions

To verify if your device has the ENA driver enabled run the following command from your CLI:

ethtool -i eth0 driver: ena

Here we can see that the ENA is in fact enabled:
 

version: 1.5.0g
firmware-version:
expansion-rom-version:
bus-info: 0000:00:05.0
supports-statistics: yes
supports-test: no
supports-eeprom-access: no
supports-register-dump: no
supports-priv-flags: no

In case you don't see it enabled, you can proceed with the following instructions to enable it:

  1.  Access to your BIG-IPs CLI
  2.  From the config prompt, enter the following commands:
    aws ec2 modify-instance-attribute --instance-id instance_id --ena-support
    tmsh save /sys config
After this, you should be able to see the ENA driver using the ethtool command.
