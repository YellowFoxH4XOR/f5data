Description
After making a change to a policy /Common/Test which is in used by a virtual server /Red/Redhttp in another partition, sync failed with below error message:

Sync Failed
A validation error occurred while syncing to a remote device
Sync error on bigip-2: Load failed from /Common/bigip-1 01070712:3: Caught configuration exception (0), Values (/Common/Drafts/Test testrule) specified for policy action (/Common/Drafts/Test testrule 0): foreign key index (rule_FK) do not point at an item that exists in the database..

Environment

  • BIG-IP HA pair
  • Did a change to the policy /Common/Test on active device
  • The policy is in used by a virtual server /Red/Redhttp in another partition 
  • Sync failed

Cause
We have a known issue could happen when changing the policy,
Bug ID 742838: A draft policy of an existing published policy cannot be modified if it is in /Common and an used by a virtual server in a different partition

For certain circumstance, change could be published and saved to the configuration file of both devices but causing sync issue.

Recommended Actions

  1. Reload configuration on bigip-2
    # tmsh load sys config verify
    # tmsh load sys config

  2. Re-sync HA pair

Additional Information

In order to prevent known issue ID 742838, create a clone of published policy and modify it then swap the policy, instead of modifying the original draft
