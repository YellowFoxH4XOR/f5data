Issue

Error Message

notice mcpd[<PID>]: 01071434:5: No CMI peer devices configured

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.

For example:

notice mcpd[9272]: 01071434:5: No CMI peer devices configured

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all the following conditions are met:

  • The BIG-IP system is a member of a trust domain with other devices.
  • The BIG-IP system does not have ConfigSync IP addresses configured.

Impact

The BIG-IP system is unable to synchronize the configuration with device trust peers.

Recommended Actions

When you view this message, consider the following:

  • You may be able to resolve this issue by configuring a ConfigSync IP address for the affected BIG-IP system. To do so, perform the following procedure:

    Impact of procedure: Performing the following procedure should not have a negative impact on your system.

    1. Log in to the BIG-IP Configuration utility.
    2. Navigate to Device Management > Devices.
    3. Click the name of the affected device.
    4. Hover over Device Connectivity and click ConfigSync.
    5. For Local Address, click an IP address. 
    6. Click Update.
  • If you view this message on multiple devices in the trust domain, you may need to reset the device trust for all devices in the trust domain and configure the ConfigSync IP addresses for each device individually, before attempting to add the devices back to the trust domain. For more information about resetting the device trust, refer to K13946: Troubleshooting ConfigSync and device service clustering issues (11.x - 14.x).
