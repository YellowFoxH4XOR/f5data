K000151340: Lost access to BIG-IP Web GUI

Type
Support Solution
Published
2026-09-08
Updated
2026-09-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000151340

Description

The BIG-IP Web GUI is inaccessible because excessive control-plane CPU utilization is caused by the syslog-ng process.

Environment

  • BIG-IP LTM version 17.1.1
  • High CPU utilization isolated to the control plane
  • Syslog is configured
  • AVR is provisioned

Cause

High control-plane CPU utilization from the syslogd process (/var/run/syslogd.pid) prevented normal GUI management access. This can be identified by using the top and ps aux commands from bash.

 

Recommended Actions

1. From Bash, restart the affected analytics and logging services:

bigstart restart avrd syslog-ng

2. Restart httpd and tomcat after the preceding services have been restarted:

bigstart restart httpd tomcat

3. Monitor control-plane CPU utilization and GUI availability.

4. Verify that system logging and BIG-IP Analytics functionality resume after the service restarts.
