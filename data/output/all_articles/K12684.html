Known Issue

This is the result of a known issue. The diskmonitor utility may report inaccurate disk usage statistics for secondary VIPRION blades.

The diskmonitor utility runs periodically on BIG-IP systems to monitor disk usage. The diskmonitor utility executes BigDB db variables on the system to track information such as disk utilization and disk usage limits. When the diskmonitor utility runs on a VIPRION system and attempts to collect a BigDB db variable from a secondary blade, the system may return inaccurate values. For example, after the diskmonitor utility runs on a VIPRION system, the utility may report that a partition on a secondary blade exceeded the allowed growth limit, even though disk usage on the partition did not change. When this occurs, an error message that appears similar to the following example may be logged to the /var/log/ltm file:

Disk partition shared exceeded growth limit 5%

F5 Product Development tracked this issue as ID 345956 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
