K3461: Reasons why the product code may display as ''indeterminate'' when reported by the bigpipe -v command

Topic

Normal output for the bigpipe -v should appear similar to the following:

Kernel:
BIG-IP Kernel 4.6.2 Build117
Package:
BIG-IP Version 4.6.2 Build117-a
Global Edition
Product Code:
BIG-IP

The product code will display as indeterminate if you have not accepted the End User License Agreement (EULA).

To correct this issue, perform the following steps:

  1. Run the Setup utility, by typing the following command:

    config

  2. View the EULA and accept the terms.
  3. Update the running configuration, by typing the following command:

    bigstart restart

  4. Type the following command to view the product code:

    bigpipe -v

    The product code should now display correctly.
