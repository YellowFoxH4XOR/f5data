Known Issue

Description

Android Edge Portal app users receive a 'session expired' message and the session immediately terminates after they log in to a FirePass controller that is configured to require a client certificate. This is a result of the Android OS browser not properly handling client certificate requests.

This issue occurs when all of the following conditions are met:

  • FirePass is configured to require a client certificate
  • User is using the Android Edge Portal app
  • The Android Edge Portal app is configured with a client certificate

Impact

Android Edge Portal users are unable to view resources through FirePass.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • User receives a 'Session expired' message on the Android device
  • Session immediately terminates after the user logs in
  • FirePass logs an error that appears similar to the following example in the system log:

    [<user name>@<controller name>] Possible intrusion attempt detected against account <user name> from source IP address <client IP address> for URI=[/vdesk/intranets/provision.php3?address=<URL>](Client certificate changed.)

    In this error message, note the following:

    • <user name> is the users login name
    • <controller name> is the name of the FirePass controller
    • <client ip address> is the IP address of the client device
    • <URL> is the URL of the FirePass controller
    For example:

    [test@fp1] Possible intrusion attempt detected against account test from source IP address 192.168.1.1 for URI=[/vdesk/intranets/provision.php3?address=http%3A%2F%2Ffp1.siterequest.com%2F] (Client certificate changed.)

Workaround

To work around this issue, you can disable the Require client certificate for user logon option in the Master Group. To do so, perform the following procedure:

Impact of workaround: Disabling the Require client certificate for user logon option bypasses two-factor authentication, thus eliminating the requirement for the client to present a valid certificate.

  1. Log in to the FirePass Administrative Console.
  2. Click Users.
  3. Click Groups.
  4. Click the name of the Master Group you want to edit.
  5. Click the Authentication tab.
  6. Clear the Require client certificate for user logon checkbox.
  7. Click the Update button.
