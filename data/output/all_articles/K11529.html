Known Issue

This is the result of a known issue. When a shadow copy rule has been configured with the no prune-target command to disable target pruning, the Prune Target check box will remain selected on the Edit Shadow Copy Rule page in the ARX GUI.

This is a cosmetic display issue in the ARX GUI. Target pruning will be disabled when no prune-target is listed in the shadow copy rule configuration. To view the shadow copy rule, use the show global-config command.

Important: Target pruning will be disabled when no prune-target is listed in the shadow copy rule configuration. However, when editing the shadow copy rule using the ARX GUI, to avoid re-enabling target pruning, you must clear the Prune Target check box before clicking the OK button to save your changes.

F5 Product Development tracked this issue as ID 38454 and it was fixed in ARX 5.2.0. For information about upgrading, refer to the ARX release notes.

Additionally, this issue was fixed in ARX 5.1.5 hotfix 2. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
