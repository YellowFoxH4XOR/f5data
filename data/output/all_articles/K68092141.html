Known Issue

The BIG-IP system may log benign correctable_error_received error messages.

This issue occurs when the following condition is met:

  • Your BIG-IP system is running a listed software version on a Herculon iSeries platform.

Impact

The BIG-IP system logs benign error messages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system logs error messages to the /var/log/sel file that appear similar to the following example:

    MAJ CPU 0 PCI/DMI Error B:D:F 0x1a: corerrsts: replay_num_rollover_status
    MAJ CPU 0 PCI/DMI Error B:D:F 0x1a: rperrsts: correctable_error_received

Resolution

Status

F5 Product Development has assigned ID 611352 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article.
