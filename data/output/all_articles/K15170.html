Topic

You should consider using this procedure under the following condition:

  • You want the BIG-IP PEM system to display the classification statistics on the Configuration utility Statistics page.

Description

Beginning in BIG-IP PEM 11.4.0, BIG-IP PEM classification statistic analytics is disabled by default. You can access the BIG-IP PEM classification statistics from the Configuration utility menu item Statistics > Classification, and view either the Overview page or the Statistics page.

By default, the Configuration utility's Statistics page does not have all the statistical information for the BIG-IP PEM classification statistics. If you navigate from the Configuration utility to Statistics > Classification, the page may not display the expected classification statistics.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have appropriate credentials to access to the Traffic Management Shell (tmsh).

Procedures

Enabling the BIG-IP PEM classification statistic analytics

Impact of procedure: Enabling the tmm.gpa.ce.events database key has a negative impact on the system's memory and performance up to 20 percent. Therefore, F5 recommends disabling the database key when you have finished exporting or inspecting the required statistical reporting.

  1. Log in to the Traffic Management Shell (tmsh).
  2. To display the current setting of the tmm.gpa.ce.events database key, type the following command:

    list /sys db tmm.gpa.ce.events

    Note: By default, the value of this database key is set to false.

  3. To enable the BIG-IP PEM classification statistic analytics, type the following command:

    modify /sys db tmm.gpa.ce.events value true

    After enabling the system database key, you may need to wait up to 20 minutes with appropriate traffic generated for the BIG-IP PEM classification statistics to display.

  4. To save the changes, type the following command:

    save /sys config

  5. To exit the tmsh utility, type quit and press Enter.

Disabling the BIG-IP PEM classification statistic analytics

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh).
  2. To disable the BIG-IP PEM classification statistic analytics, type the following command:

    modify /sys db tmm.gpa.ce.events value false

  3. To save the changes, type the following command:

    save /sys config

  4. To exit the tmsh utility, type quit and press Enter.
