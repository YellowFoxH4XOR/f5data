Description

Deletion of a GTM link can orphan objects dependent on that link.

  • GTM link is decommissioned and deleted via the GUI.
  • When the device is rebooted or configuration is reloaded, the device goes inoperative.
  • Log message is noted in /var/log/ltm  
    foreign key index (explicit_link_FK) do not point at an item that exists in the database.

Environment

  • GTM link assigned as an explicit link on a virtual server
  • GTM link is deleted, however the explicit link on the virtual server still points to a now non-existent link.
  • DNS module 

Cause

This is a known issue.

Recommended Actions

To avoid this issue:

      1. Go in to DNS  ››  GSLB : Servers : Server List  ››  Virtual Servers
      2. Set the assigned link back to "auto"
      3. Delete the link as normal
