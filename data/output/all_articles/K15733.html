Topic

Summary

The Response Chunking setting values, other than Selective in the HTTP profile, are incompatible with the BIG-IP WebAccelerator and BIG-IP AAM systems.

Description

Description

Note: BIG-IP WebAccelerator and BIG-IP WOM were combined to create BIG-IP AAM in BIG-IP 11.4.0.

When you configure a virtual server with BIG-IP WebAccelerator (BIG-IP 11.0.0 - 11.3.0) or BIG-IP AAM (BIG-IP 11.4.0 and later) enabled, the Response Chunking setting in the associated HTTP profile should be configured as Selective. The Preserve, Unchunk, and Rechunk values are provided with the BIG-IP LTM system but are incompatible when configured with the BIG-IP WebAccelerator and BIG-IP AAM systems. Using values other than Selective in conjunction with BIG-IP WebAccelerator or BIG-IP AAM results in an invalid configuration.

Configuring the Preserve, Unchunk, or Rechunk values for the Response Chunking setting can cause the BIG-IP WebAccelerator and BIG-IP AAM systems to incorrectly increase the HTTP Content-Length for objects served from cache. As a result, browsers receive responses to requests but stall when attempting to load the objects.

Recommendations

When configuring the BIG-IP WebAccelerator or BIG-IP AAM systems, verify that associated HTTP profiles are configured with Selective for the Response Chunking setting.
