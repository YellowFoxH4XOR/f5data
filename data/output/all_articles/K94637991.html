K94637991: MSSQL health monitor marking a resource down

Description

  • MSSQL health monitor marking a resource down
  • tcpdumps show monitor instances not sent at configured interval

Environment

  • MSSQL health monitor
  • Configured monitor interval shorter than the period required for the resource to respond

Cause

MSSQL monitor has a daemon (DBDaemon) that is between bigd and and the monitored resource.  There are several points between the connection/query process that can be subject to various timeouts.  When such a timeout occurs, it can hang the DBDaemon longer than the configured monitor interval and overrun the next scheduled interval. When a MSSQL monitor instance overruns the next scheduled interval it will block firing a new instance in that next interval.  If the MSSQL monitor is configured for shorter than default intervals this increases the risk of a single probe attempt can consuming the entire configured timeout.

Recommended Actions

Configure MSSQL monitors for a minimum interval/timeout of 30/91.
