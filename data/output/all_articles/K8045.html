Known Issue

This is the result of a known issue. The ZoneRunner utility incorrectly reports the RDATA information for the IN-ADDR.ARPA domain pointer (PTR) records within the zone.

Viewing records within a zone

To view the records within a zone, perform the following procedure:

  1. Log in to the BIG-IP GTM Configuration utility.
  2. Navigate to Global Traffic > ZoneRunner.
  3. Select the name of the IN-ADDR.ARPA zone you want to view from the Zone Name drop-down menu from the Resource Record List page.
  4. Select Search.
  5. Select the reverse DNS entry of which you want to view the properties.

The following example displays how the Configuration utility incorrectly displays the information of the reverse DNS entry properties.

Example entry:

dns.test.net

The ZoneRunner Configuration utility should display reverse DNS entries with the following RDATA information:

  • Zone Name: 3.44.10.10.in-addr.arpa
  • TTL: 30
  • Type: PTR
  • Domain: dns.test.net

The ZoneRunner Configuration utility instead displays the revers DNS entry, as follows:

  • Zone Name: 3.44.10.10.in-addr.arpa.
  • TTL: 30
  • Type: PTR
  • Domain: 3.44.10.10.in-addr.arpa.

If the Update button is accidently selected, it will overwrite the PTR entry with the incorrect information which could adversely affect how the BIG-IP GTM system handles requests for the reverse DNS entry.

F5 Product Development tracked this issue as CR85072 and it was fixed in BIG-IP GTM 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM release notes.
