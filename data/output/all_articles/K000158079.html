Description

Cannot delete local user. Delete button grayed out in GUI; CLI fails:

01070821:3: User Restriction Error: The user may not be deleted


Environment

- unable to delete local user

- GUI: Delete button grayed out - no option to delete

- CLI: failed with error:

01070821:3: User Restriction Error: The user may not be deleted.


Cause

User was configured as the Primary Admin User, preventing deletion until reassignment.


(tmos)# delete auth user test-user

01070821:3: User Restriction Error: The user (test-user) may not be deleted.

(tmos)# list sys db systemauth.primaryadminuser

sys db systemauth.primaryadminuser {

  value "test-user"

}


Recommended Actions

Change the Primary Admin User to a different account and then delete the intended user.


(tmos)# modify sys db systemauth.primaryadminuser value admin

(tmos)# delete auth user test-user

(tmos)#

K15632: Disabling the admin and root accounts using the Configuration utility or tmsh
