Topic

You should consider using these procedures under the following condition:

  • You want to manage the BIG-IP system from the command line using the TMOS Shell (tmsh).

Description

The BIG-IP system includes the TMOS Shell (tmsh) that can be used to manage the system from the command line. You can enter tmsh to configure the BIG-IP system and view statistics and performance data.

Prerequisites

You must meet one of the following prerequisites to use these procedures:

  • You have a workstation with an SSH client and network access to the BIG-IP management IP address.
  • You have a workstation with a serial terminal connection to the BIG-IP system.

BIG-IP user accounts can either be configured to enter tmsh a number of different ways, or they can be denied access to tmsh altogether.

  • Terminal access options
  • Configure terminal access
  • Access tmsh
  • Exit tmsh

Terminal access options

When configuring a user account for the BIG-IP system, there are three terminal access options. The available options vary depending on the specific user role and the BIG-IP version. For example, the following roles are available for the administrator role:

  • Disabled (none)

    Specifies no shell access.

  • Advanced shell (bash)

    Provides an unrestricted system prompt.

  • TMOS Shell (tmsh)

    Provides access to tmsh.

Procedures

Configure terminal access

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to System > Users > User List.
  3. Under User Name, select the appropriate user.
  4. Under Account properties, select the appropriate Terminal Access option.
  5. Select Update.

Access tmsh

Users can enter tmsh in two ways:

  • If you are granted Advanced Shell (bash) access, you must enter tmsh in to the command line after logging in to the BIG-IP system.
  • If you are granted tmsh access, you enter tmsh directly when logging in to the BIG-IP system.

After logging in to the command line, the BIG-IP system prompt indicates the terminal access types as follows:

  • Advanced shell - The command line prompt ends with a single # character.
  • tmsh - The command line prompt ends with (tmos)#.

Exit tmsh

You can exit tmsh by entering quit. Two different results may occur, depending on the user's terminal access type:

  • If you are granted bash access, you will be returned to bash.
  • If you are granted tmsh access, you will be logged out of the BIG-IP system.
