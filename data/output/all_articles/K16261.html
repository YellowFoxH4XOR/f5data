Known Issue

A memory leak in the Intel Gigabit Virtual Function (igbvf) network driver may cause the Traffic Management Microkernel (TMM) to restart and produce a core file.

This issue occurs when the following condition is met:

  • The system processes jumbo frames.

When processing jumbo frames, xfrags are leaked if a partial jumbo frame is received.

Note: The BIG-IP 2000 and 4000 series platforms use the igbvf network driver.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system may temporarily fail to pass traffic.
