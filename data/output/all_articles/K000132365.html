Description

Unable to view the ASM policy while logging as Guest role in the BIG-IP ASM device

Environment

Logging into BIG-IP ASM device as the guest role 
ASM policy is not displayed after login as guest role

Cause

Bug ID 718796

Recommended Actions

1) Delete the state maintained by IControlRoleMigrationWorker and let it rerun by restarting restjavad process:

# restcurl -X DELETE "shared/storage?key=shared/authz/icontrol-role-migrator"

2) Restart services

# bigstart restart restjavad *or* tmsh restart /sys service restjavad

3) Now, when you create a new user, the permissions should start in a healthy state

If the issue is not resolved, follow the additional step mentioned in the  Bug ID 718796
