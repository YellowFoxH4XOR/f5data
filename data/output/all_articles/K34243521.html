Description

F5 Ansible Module bigip_gtm_pool,  when fallback_ip is configured as 0.0.0.0, the playbook always reports 'changed' status, which triggers Ansible handler if it is configured in this task.

Example of affected configuration:

- name: Create GTM pools

  bigip_gtm_pool:

    provider: f5

    name: my_pool

    type: a

    fallback_ip: 0.0.0.0    <<<<<<

    members: my_server

    state: absent

  delegate_to: localhost

  notify: my_handler
 

Environment

  • BIG-IP GTM Pool
  • BIG-IP Ansible Module
  • fallback_ip

Cause
It is a known issue with F5 Ansible Version 1

Recommended Actions

Use other IP address as fallback_ip in F5 Ansible Module bigip_gtm_pool
Or
Disable the Ansible handler in the same playbook
