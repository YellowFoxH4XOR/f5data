Topic

When a local DNS server (LDNS) makes a DNS request to the BIG-IP GTM system for a wide IP address, the BIG-IP GTM system responds to the request and determines if it has an existing entry for the LDNS server stored in its cache. If the BIG-IP GTM system does not have an existing entry for the LDNS server stored in its cache, the system creates one. The BIG-IP GTM system then probes the LDNS server and gathers the link and path metrics used for load balancing.

You can search for LDNS link and path entries stored in the BIG-IP GTM system's cache by navigating to the Global Traffic statistics page and selecting the appropriate statistics type. However, to avoid overloading the system, the system searches and displays only the most recent 1000 entries.

To view all of the entries stored in the BIG-IP GTM system's cache, you can use the zless or zcat commands to view the contents of the /config/gtm/ldns.gz file.
