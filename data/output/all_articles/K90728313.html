Topic

You can configure your BIG-IP ASM security policy to block requests and trigger a violation when users attempt to upload binary executable content to the web application.

Description

A malicious user may attempt to upload binary executable content to the web application. For example, after successfully uploading executable content to the web server, an attacker may attempt to run the program to gain remote access to the server or spread malware to other application users.

You can configure your BIG-IP ASM security policy to disallow parameters containing binary executable content. You can do so by creating a user-input parameter, with the data type set to file upload, and then opt to disallow uploading executable files. After the policy option is enabled, the BIG-IP ASM system checks whether the file upload content is a binary executable file format.

If a client sends an HTTP request containing binary executable content, the system considers the request to be an attack and, depending on the blocking settings, issues the following violation to the event logs:

Disallowed file upload content detected
