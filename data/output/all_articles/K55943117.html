Description

F5 iHealth does not accept the QKview file for upload when an F5 Support Case number is provided, or when attempting to upload using a link such as: https://ihealth.f5.com/qkview-analyzer/upload?case=required&case_id=<case_number>

The web browser displays the following message:  The case number could not be associated with this qkview

Environment

  • iHealth
  • QKview
  • Any browser

Cause

  • The account used to log in to F5 iHealth is not linked to the serial number associated with the F5 Support Case
  • You may also receive this error if you are trying to upload a QKView to a case for which you are not listed as the Customer Contact for the case

Answer/Recommended Actions

If you would like to upload QKViews directly to iHealth, only the current primary Case Contact on a case can upload a QKView via iHealth.

The issue can be resolved by using any one of the following options:

  1. Chat with Support to request linking your email ID to the account associated with the serial number. Once access is granted, you may proceed with the upload.
    Note: You must log in to MyF5 then click the speech bubble in the lower right to use chat

    Or

  2. Upload the QKView file to the F5 iHealth upload link: https://ihealth.f5.com/qkview-analyzer/upload
         a) Description field : <case number>
         b) F5 Support Case : <leave it blank>
    Once uploaded, request the case owner to confirm the upload in the case.
    Note: If the QKView file is uploaded this way, it may not remain explicitly linked to the SR. If the case remains open for an extended period, the system may expire and remove the file before the SR is closed. Refer to iHealth Home for details.

    Or

  3. Upload it to the support case via https://securefiles.f5.com. If you are not the primary contact of the case, contact F5 Support to request an invitation sent for you to upload or get the primary case contact to sent you the invitation.
    Note: the QKView uploaded this way will remain available until the SR gets closed, but its details will be visible only to F5 Support engineers.

    Or

  4. Contact F5 Support to temporarily change the case's primary Customer Contact to the person who is trying to upload the QKView, and once uploaded, revert the Customer Contact back to the original owner.
