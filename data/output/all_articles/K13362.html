Beginning in BIG-IP 10.0.0, the BIG-IP GTM system adds support for the Domain Name System Security Extensions (DNSSEC). The BIG-IP GTM system supports the following hash algorithms for DNSSEC keys:

BIG-IP GTM 11.1.0 and later

In BIG-IP GTM 11.1.0 and later, DNSSEC supports the following SHA hash algorithms:

  • RSA/SHA-256
  • RSA/SHA-512
  • RSA/SHA1

BIG-IP GTM 10.x through 11.0.0

In BIG-IP GTM 10.x through 11.0.0, DNSSEC supports the following SHA hash algorithms:

  • RSA/SHA1

In BIG-IP 11.5.0 and later, you can create DNSSEC keys using the Configuration utility by navigating to DNS > Delivery > Keys > DNSSEC Key List > Create. For BIG-IP 11.4.1 and earlier, you can create DNSSEC keys using the Configuration utility by navigating to Global Traffic > DNSSEC Key List > Create.
