Description

  • You currently have Engineering Hotfix (EHF) for a set of BUG IDs.
  • You plan to upgrade your BIG-IP.
  • You want to know if the EHF is included in the version you plan to upgrade to.

Environment

  • BIG-IP
  • Upgrade
  • EHF

Cause

None

Recommended Actions

Check the release notes of the version you plan to upgrade. The release note will list all the BUG IDs which are cumulatively fixed in that branch.

  1. Go to Product Manuals and Release Notes | MyF5
  2. Choose the version you want to upgrade to.
  3. Click on the "Fixes and Known Issues" section.
  4. Search on the page for the BUG ID if it is fixed.

If you do not see the BUG ID listed as fixed, then you will need a new EHF. Please contact F5 support for new EHF.
