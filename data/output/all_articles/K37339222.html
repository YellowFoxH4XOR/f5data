Known Issue

BIG-IP APM access policy endpoint security client-side antivirus check for ESET Endpoint Antivirus may fail and prevent user access.

This issue occurs when all of the following conditions are met:

  • You have BIG-IP APM installed with the Endpoint Security (EPSEC) package version 1.0.0–410.0.
  • You have an access policy configured with an endpoint security client-side agent to check for antivirus software.
  • Users attempt to establish access sessions to the BIG-IP APM system from devices running ESET Endpoint Antivirus version 6.3.2016.0 software.

Impact

The BIG-IP APM system denies access to users.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP APM system denies access to users when they attempt to log in and displays an error message similar to the following example:

    Your session could not be established.
    The session reference number: <session id number>
    Access was denied by the access policy. This may be due to a failure to meet access policy requirements.

  • Users can successfully log in to the BIG-IP APM system when you remove the endpoint security client-side antivirus check agent from the access policy.
  • The BIG-IP APM system logs messages similar to the following examples to the /var/log/apm directory:

    notice apd[<pid>]: 01490113:5: <sessionid>: session.check_software.last.av.item_3.db_time is 1453939200

    notice apd[<pid>]: 01490113:5: <sessionid>: session.check_software.last.av.item_3.db_version is 12940 (20160128)

Resolution

Status

F5 Product Development has assigned ID 572006 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Workaround

To work around this issue, you can install an updated EPSEC package for version 1.0.0–420.0 or later. For more information about installing EPSEC packages, refer to K10942: Installing OPSWAT hotfixes on BIG-IP APM systems (10.x - 11.3.0).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
