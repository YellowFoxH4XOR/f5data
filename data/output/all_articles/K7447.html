Known Issue

This is the result of a known issue. The BIG-IP system will persistently advertise a serverside TCP window size of 0, causing the HTTP connection to stall, if all of the following conditions are met:

  • A virtual server which is configured to use an HTTP profile with OneConnect enabled receives a request.
  • BIG-IP sends the request to a pool member using a OneConnect serverside flow.
  • The client resets the clientside connection while part of the server response remains in the BIG-IP LTM TCP proxy buffer.
  • The existing serverside flow is re-used to request a new object whose size exceeds the most recent TCP window size advertised by the BIG-IP system on the serverside flow.

When this occurs, the server cannot send the remainder of the response. The connection is eventually reset when the service timeout expires.

Note: For more information about another issue with OneConnect, which may prevent clients from retrieving HTTP objects that require NTLM authentication, refer to K5050: OneConnect may prevent NTLM authentication from succeeding.

F5 Product Development tracked this issue as CR77060 and it was fixed in BIG-IP LTM 9.1.3 and 9.4. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in hotfix BIGIP-9.3.1-HF4, which has been issued for BIG-IP 9.3.1, for the BIG-IP 9.3 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.

Workaround

To work around this issue, disable the OneConnect profile for the virtual server. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Select the appropriate virtual server.
  4. From the OneConnect Profile menu, select None.
  5. Click Update.
