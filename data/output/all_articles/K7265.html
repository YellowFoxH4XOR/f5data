Topic

The bigtop utility can be slow to respond when displaying information if the /etc/resolv.conf file is configured with nameservers that are unreachable or not responding. This delay is caused by the bigtop utility attempting to look up each virtual server and member in order to display the FQDN of each object.

Note: By default, the bigtop utility does not perform a DNS resolution unless the /etc/resolv.conf file is configured.

To prevent this delay from occurring, ensure that the nameservers are reachable if they are configured in the /etc/resolv.conf file and that each member and virtual server address resolves to a name.

If you do not have a nameserver configured, or want to prevent name lookup by the bigtop utility, the following switch can be used with bigtop to prevent name resolution:

bigtop -n
