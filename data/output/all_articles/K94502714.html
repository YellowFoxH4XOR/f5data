Known Issue

Importing an access profile containing a resource object with a long name may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an access profile.
  • The access profile contains a resource object with a name that contains more than 80 characters.
  • You export the access profile.
  • You attempt to import the access profile.

Impact

The access profile fails to import.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to import the access profile, the system displays an error message that appears similar to the following example:

    Import Error: /shared/tmp/import/<import id>/access_profile.conf doesn't exist

  • When you attempt to manually extract the export archive using the Linux tar command, the system displays repeating error messages that appear similar to the following example:

    tar: Archive contains `00' where numeric uid_t value expected
    tar: Archive contains `00' where numeric gid_t value expected
    tar: Archive contains `00' where numeric uid_t value expected
