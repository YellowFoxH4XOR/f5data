Description

CloudHSM client service could not be found after upgrading BIG-IP


Environment

BIG-IP

Cause

This is expected behavior, installed software like CloudHSM in the /opt directory will not survive an upgrade

Recommended Actions

You will need to re-install and re-configure CloudHSM after every upgrade

Additional Information
