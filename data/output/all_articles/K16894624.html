Description

The datasync-device-<devicename>-dg device group is essential for BIG-IP ASM, Advanced WAF, and BIG-IP FPS systems to function properly in the same trust domain as another BIG-IP provisioned with that particular module. In other words ASM with ASM, AdvWAF with AdvWAF, and FPS with FPS. 

Environment

Beginning in BIG-IP 11.6.0, the datasync-device-<devicename>-dg device group is automatically created on systems in any of the following scenarios:

  • You provision the BIG-IP ASM, AdvWAF, or BIG-IP FPS system on a new BIG-IP 11.6.0 installation.
  • You upgraded BIG-IP ASM or BIG-IP FPS systems from previous versions to BIG-IP ASM or BIG-IP FPS 11.6.0 (or later).
  • You added a BIG-IP 11.6.0 (or later) system to a trust domain that has another device with the datasync-global-dg device group.
  • You upgraded to BIG-IP 11.6.0 (or later), a BIG-IP system that belongs to a trust domain that has another device with the datasync-global-dg device group.

Each device in the device_trust_group will create a new device group named datasync-device-<devicename>-dg, where <devicename> is the Fully Qualified Domain Name of the device.

The datasync-device-<devicename-dg device groups are used to sync stats related to the Datasync framework, such as the number of versions of obfuscated JavaScript available on each device. This is (for example) required to ensure devices don't use obfuscated JavaScript versions which are not available on other devices, especially when using active-active deployment.

Each device-group includes objects which are only written by a single device, and read by all the others. This is to prevent conflicts.

Cause

When ASM is provisioned, a device-group is created for each device in the trust-domain. These device-groups are created and synced automatically, and hidden from the GUI, as they are only handled internally. For example, if you have 5 devices in the trust domain, you will have 5 of those device groups including all five devices in it.

The datasync-device-<devicename>-dg device-group is automatically created for each device in the device_trust_group device group.

Example:

With two devices provisioned for ASM and in a device_trust_group, the following configuration will be observed:

cm device-group device_trust_group {
    auto-sync enabled
    devices {
        bigip1.example.com { }
        bigip2.example.com { }
    }
    network-failover disabled
}
cm device-group datasync-global-dg {
    devices {
        bigip1.example.com { }
        bigip2.example.com { }
    }
    full-load-on-sync true
    network-failover disabled
}
cm device-group datasync-device-bigip1.example.com-dg {
    auto-sync enabled
    devices {
        bigip1.example.com { }
        bigip2.example.com { }
    }
    full-load-on-sync true
    network-failover disabled
}
cm device-group datasync-device-bigip2.example.com-dg {
    auto-sync enabled
    devices {
        bigip1.example.com { }
        bigip2.example.com { }
    }
    full-load-on-sync true
    network-failover disabled
}
