Issue

Error Message

err csyncd[<PID>]: 013b0004:3: Fatal error: event queue overflow

In this error message, note the following:

  • <PID> is the process ID for the csyncd service

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • iControl requests are received faster than the csyncd service can dequeue the event notifications queue.

Impact

This error message is considered benign because the csyncd service will recover automatically by restarting.

Recommended Actions

None
