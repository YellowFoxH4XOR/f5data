K000091845: Nginx IC crashes with nginx-ingress-helm-operator; Error: flag provided but not defined: -enable-external-dns

Type
Support Solution
Published
2022-08-03
Updated
2023-12-21
Applies to
  • NGINX Products
  • NGINX Ingress Controller: 3.X.X, 3.4.X, 3.4.0, 3.3.X, 3.3.1, 3.3.0, 3.2.X, 3.2.1, 3.2.0, 3.1.X, 3.1.1, 3.1.0, 3.0.X, 3.0.2, 3.0.1, 3.0.0
Source
https://my.f5.com/manage/s/article/K000091845

Description

  • You have admin access to OpenShift UserInterface [UI]
  • You have successfully installed available Nginx Operator of OperatorHub on the OpenShift
  • You have also built your own Ingress Controller image or have an intention to use an existing image
  • And, when attempting to install the ingress using this image, you were unable to complete the instillation of the Ingress controller, resulting in the ingress pod erroring out with CrashLoopBackOff 

 Environment

  • RedHat OpenShift
  • Nginx ingress controller

 Cause

  • Controller and operator version mismatch

 Recommended Actions

  • When installing Nginx Ingress controller in Red Hat using Nginx Operator, the ingress version must corresponds to the correct operator as stated here

 Additional Information

  • None
