Topic

By default, the BIG-IP GTM system is designed to operate as the primary DNS server and answer all requests. This was formerly referred to, in 3-DNS, as DNS node mode.

You can also configure the system to forward or route DNS traffic through the BIG-IP GTM system. In this configuration, the gtmd process answers all requests for wide IPs and transparently relays all other DNS requests to another DNS server. This was formerly referred to, in 3-DNS, as DNS bridge mode.

Configuring the BIG-IP GTM system to forward or route traffic through the BIG-IP GTM system (Formerly DNS bridge mode)

You achieve bridging functionality with the BIG-IP GTM system depending on how you configure the listeners. If the listener address points to a DNS server that exists on the same subnet, the BIG-IP GTM system acts as a bridge.

To configure the BIG-IP GTM system to behave as a bridge, complete the following configuration tasks:

  • Place the BIG-IP GTM system between the existing DNS server and the Internet. For example, connect the BIG-IP GTM system to your Internet connection, and connect the DNS server to an Ethernet port on the BIG-IP GTM system.
  • Configure the listener address on the BIG-IP GTM system. For example, if the BIG-IP GTM self IP address is 172.16.1.1, and the DNS server IP address is 172.16.1.2, define the listener address as 172.16.1.2.

Defining the listener address

  1. Log in to the Configuration utility.
  2. Navigate to Global Traffic > Listeners.
  3. Click Create.
  4. In the Destination box, type the IP address on which the BIG-IP GTM system listens for network traffic. For the above example, the IP address you add is 172.16.1.2.
  5. From the VLAN Traffic list, select All VLANs.
  6. Click Finished.

With this configuration in place, the BIG-IP GTM system receives all DNS queries. If the query is for a wide IP address, the BIG-IP GTM system load balances the request. If the traffic has a destination IP address of 172.16.1.2, the BIG-IP GTM system bridges the query to the DNS server for resolution.

Note: Defining a VLAN group or other special network configuration is not required to configure the BIG-IP GTM system in bridge mode.
