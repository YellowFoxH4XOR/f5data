K000160411: Interface 1.4 Down on BIG-IP LTM i7800 – No UDLD Response, Link Loss

Type
Support Solution
Published
2026-03-20
Updated
2026-03-20
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160411

Description

BIG-IP interface went down while using Cisco UDLD


 

Environment

BIG-IP

Cisco UDLD


 

Cause

UDLD is a Cisco proprietary link status detection protocol and is not supported on the BIG-IP.


 

Answer/Recommended Actions

Do not use UDLD on BIG-IP


 

Additional Information

None
