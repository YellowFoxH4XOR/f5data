Known Issue

The EUD Verify Host I2C test may fail and indicate a false positive hardware failure.

This issue occurs when all of the following conditions are met:

  • The system is running EUD 2.3.0 or earlier.
  • The Verify Host I2C test is performed on one of the following platforms:
    • BIG-IP 2000s/2200s
    • BIG-IP 4000s/4200v
    • BIG-IP 5000s/5200v
    • BIG-IP 7000s/7200v
  • The platform shipped after 08/23/2013.

On 08/23/2013, F5 began shipping platforms with revised Dual In-Line Memory Modules (DIMMs). These DIMMs contain a serial presence detect (SPD) register that contains information such as the version of the memory module. The Verify Host I2C test incorrectly interprets the version information for the revised DIMMs as a failure.

Impact

You can disregard the false positive EUD test failure.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H428629 on the Diagnostics > Identified > Medium screen.
  • When running the EUD diagnostics suite, if a user runs the Verify Host I2C test, the test fails with error messages similar to the following example:

    ERROR: Could not read DIMM A1 register 1, expected 0x10 or 0x11, got 0x13
    ERROR: Could not read DIMM B1 register 1, expected 0x10 or 0x11, got 0x13
    Test Complete: Verify Host I2C: FAILED
