Topic

This article applies to BIG-IP 9.x - 10.x. For information about other versions, refer to the following article:

  • K13180: Configuring the BIG-IP system to deliver locally-generated email messages (11.x - 13.x )

You can configure the BIG-IP system to deliver locally generated email messages using DNS by performing the following three procedures:

  • Configuring DNS resolution
  • Verifying DNS resolution
  • Configuring email delivery

Note: For information about configuring the BIG-IP system to deliver locally generated email messages without using DNS, refer to K7365: Configuring the BIG-IP system to deliver locally generated email messages without using DNS.

Configuring DNS resolution

To configure DNS resolution (assuming you did not do that during the initial setup of the BIG-IP system,) perform the following procedure:

  1. Log in to the Configuration utility.
  2. From the Main tab, click System.
  3. Click Configuration or General Properties, depending on the version of BIG-IP software you are running.
  4. Expand the Device menu at the top of the screen.
  5. Click DNS.
  6. Add the IP address of your DNS servers to the DNS Lookup Server List field.
  7. Click Update.

Verifying DNS resolution

  1. Log in to the command line.
  2. To verify DNS resolution for the domain to which you will be sending email, type the following command:

    dig <domain> mx

    For example:

    dig askf5.com mx

    You should receive a response that appears similar to the following example, indicating that the BIG-IP system is able to resolve the mail exchanger:

    ; <<>> DiG 9.6.1-P3 <<>> askf5.com mx
    ;; global options: +cmd
    ;; Got answer:
    ;; ->>HEADER<<- opcode: QUERY, status: NOERROR, id: 10020
    ;; flags: qr rd ra; QUERY: 1, ANSWER: 2, AUTHORITY: 0, ADDITIONAL: 2

    ;; QUESTION SECTION:
    ;askf5.com. IN MX

    ;; ANSWER SECTION:
    askf5.com. 86370 IN MX 10 mail.f5.com.
    askf5.com. 86370 IN MX 20 mail2.f5.com.

    ;; ADDITIONAL SECTION:
    mail.f5.com. 3570 IN A 65.197.145.96
    mail.f5.com. 3570 IN A 207.155.204.96

    ;; Query time: 0 msec
    ;; SERVER: 192.168.160.180#53(192.168.160.180)
    ;; WHEN: Wed Dec 15 15:11:02 2010
    ;; MSG SIZE rcvd: 105

Configuring email delivery

Note: The following procedure does not set a relayhost in the Postfix configuration file, which implies that the BIG-IP system will directly route mail to the destination. In addition, you must configure the BIG-IP system with a gateway to the Internet, and allow outgoing TCP connections on port 25. If you want to specify a relayhost, or modify any other parameter of the Postfix configuration, edit the /etc/postfix/main.cf file.

Note: The /etc/postfix/main.cf file is not configured for inclusion in UCS archives; therefore, any modifications you make to the file will not survive a software upgrade and will not be synchronized between redundant BIG-IP systems. For more information about UCS archives, refer to K4423: Overview of UCS archives. For more information about the specific files that are contained in a UCS archive and instructions about how to include additional files, refer to K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive.

  1. Log in to the command line.
  2. By default, the postfix service does not automatically start when the BIG-IP system boots. To determine whether the postfix service is currently running, type the following command:

    bigstart status postfix

  3. If the postfix service is not running, start it by typing the following command:

    bigstart start postfix

    If the postfix service is running and you have made modifications to the /etc/postfix/main.cf file, restart the service by typing the following command:

    bigstart restart postfix

  4. If you want the postfix service to automatically start every time the BIG-IP system boots, type the following command:

    bigstart add postfix

    Note: Although the postfix service is set up to automatically start, it is not configured for inclusion in user configuration set (UCS) archives. Therefore, if the UCS archive is restored on another BIG-IP system, this step needs to be re-run on the BIG-IP system in order for the postfix service to start automatically. For more information, refer to K9208: Service startup information is not saved in a UCS archive file. For more information about including additional files in a UCS archive, refer to K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive.

  5. To send a test email, type the following command:

    echo test | mail <your email address>

  6. To view the mail queue, type the following command:

    mailq

  7. To force delivery of any messages in the deferred mail queue, type the following command:

    postfix flush

  8. Using a text editor, open the /etc/aliases file or the /etc/postfix/aliases file, depending on the version of BIG-IP software you are running.

    Note: Only one of the files listed above will be present on the BIG-IP system.

  9. Change the root alias mapping to the email account to which you want the root's mail to be sent. Additionally, remove the number sign character (#) from the beginning of the line, if present.

    For example:

    root: helpdesk@askf5.com

  10. Save and exit the file.
  11. To update the Postfix aliases database, type the following command:

    newaliases

  12. To send a test email, type the following command:

    echo "this is a test" | mail root

    If configured properly, the email will be delivered to the alias address that you specified in the Postfix aliases file.
