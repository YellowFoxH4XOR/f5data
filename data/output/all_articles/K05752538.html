Description

Security > Application security > Policy building > traffic learning logs shows "No records to display" for the policy in Manual learning mode. 
 

Environment

  • Security policy with learning mode: Manual
  • BIG-IP ASM
     

Cause
Unknown
 

Recommended Actions

To avoid any synchronization issue of data, force the mcpd process to reload the configuration. 
Impact of procedure: BIG-IP system traffic processing is interrupted while the system restarts.

See the procedure in K13030: Forcing the mcpd process to reload the BIG-IP configuration for guidance on forcing MCPD to reload the configuration.
