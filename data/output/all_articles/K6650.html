Known Issue

This is the result of a known issue. If you create a link with two or more self IP addresses defined, and then run the gtmparse command from the command line, the system saves only one self IP address for the link to the wideip.conf file.

F5 Product Development tracked this issue as CR69124 and it was fixed in BIG-IP GTM 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP GTM release notes.
