K56566318: Configuring OSPF Priority

Type
Support Solution
Published
2022-06-24
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K56566318

Description

Using Open Shortest Path First (OSPF) command syntax, neighbor A.B.C.D priority, ZebOS Integrated Management Interface (IMI) shell may return this message:

A.B.C.D Specify the interface IP address of the neighbor.

(config-router)#neighbor 10.33.3.3 priority 100
% Neighbor command is allowed only on NBMA and point-to-multipoint networks
Environment
  • ZebOS OSPF

Cause

  • OSPF area does not have either a NBMA or point-to-multipoint network type

Recommended Actions

To change OSPF priority for network type broadcast, please use command syntax, ip ospf priority.

(config-if)#ip ospf priority 0

None
