Topic

You should consider using this procedure under the following conditions:

  • You are planning to upgrade or update your BIG-IP system and want to get information about BIG-IP images available on AWS marketplace.
  • You want to get the attributes (name, AMI image ID, description, and so on) of a BIG-IP AWS image.

Description

When planning to update your BIG-IP system, you want to know the BIG-IP versions available that you can choose from in the AWS marketplace and the relevant information about each BIG-IP image.

Prerequisites

You must meet either one of the following prerequisites to use this procedure:

  • You have access to AWS console and AWS Cloudshell.
  • You have your own client system.
    • You have the AWS Command Line Interface (CLI) version 2 tool installed on your client system.
    • You have run aws configure to configure the tool on your client system.

Note: These links take you to resources outside of AskF5, and it is possible that the documents may be removed without our knowledge.

Procedures

The following procedures provide examples of using the AWS CLI tool to perform the following:

  • Display the list of available BIG-IP images in AWS Marketplace
  • Display the full information of a BIG-IP image with the AMI ID

Display the list of available BIG-IP images in AWS Marketplace

The following section provides examples of using the filter and query switches of the AWS CLI tool:

To display a list of the descriptions of all BIG-IP 16.x images by F5 in AWS Marketplace, use the following command syntax:

aws ec2 describe-images --region <region> --owners <owner ID> --filters Name=description,Values='*BIGIP-16*' --query "Images[*].[Description]"

For example:

aws ec2 describe-images --region us-east-1 --owners '679593333241' --filters Name=description,Values='*BIGIP-16*' --query "Images[*].[Description]"

To display the Description, CreationDate and AMI ID of all BIG-IP PAYG* WAF * 200Mbps images, use the following command syntax:

aws ec2 describe-images --region <region> --owners <owner ID> --filters Name=description,Values='*PAYG* WAF * 200Mbps*' --query "Images[*].[Description, CreationDate, ImageId]"

For example:

aws ec2 describe-images --region us-east-1 --owners '679593333241' --filters Name=description,Values='*PAYG* WAF * 200Mbps*' --query "Images[*].[Description, CreationDate, ImageId]"

Display the full information of a BIG-IP image with the AMI ID

When you have the image ID or AMI ID of the BIG-IP image, you can display its full information using the following command syntax:

aws ec2 describe-images --region <region> --image-ids <AMI ID>

For example:

aws ec2 describe-images --region us-east-1 --image-ids ami-056444b3c407ffcea
