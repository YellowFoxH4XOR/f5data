K25254159: General Database Error when creating AD authentication profile

Published

Status
Legacy Content
Applies to

  • BIG-IP APM: 16.0.1
Source

Description

When creating or updating a BIG-IP APM Active Directory authentication profile a "General Database" error is displayed.

Environment

  • BIG-IP APM
  • Configuration Utility (GUI)
  • The authentication profile password uses the non-alphanumeric character "&" as the last character of the password. 

Cause
 

Recommended Actions

When setting the Active Directory authentication profile password avoid the use the "&" as the last character of the password.
