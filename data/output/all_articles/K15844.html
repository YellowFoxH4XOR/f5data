Known Issue

vCMP guests may detect another vCMP guest's backplane broadcast traffic.

This issue occurs when the following condition is met:

  • You are running on one of the following VIPRION blades:

    • B4300 (A108)
    • B4340 (A110)
    • B4350 (A110)
  • A vCMP guest is assigned interface 0.39.

Impact

None. Traffic processing is not affected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You may view messages in the vCMP guest's /var/log/ltm file that appear similar to the following example:

    warning tmm[<pid>]: 01190004:4: address conflict detected for 127.20.1.1 (02:01:23:45:00:18) on VLAN 4095'

Workaround

To work around this issue, you can redeploy the vCMP guest using interface 0.39 to a different blade or a different set of interfaces.

Impact of workaround: The vCMP guest may be unavailable temporarily. You should perform this workaround during a maintenance window.
