Known Issue

Use of the Variable Assign agent may cause clientless authentication to fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access policy is configured for clientless authentication.
  • A Variable Assign agent is configured as part of the access policy prior to the logon page agent placement.

Impact

Users are unable to authenticate.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the system attempts to access the access profile, the access policy's credential request begins to loop.
  • Removing or moving the Variable Assign agent allows authentication to function normally.
