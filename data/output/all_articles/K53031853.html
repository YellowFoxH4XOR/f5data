K53031853: Disable account ''admin'' cause BIG-IQ daemon setupd keep restarting

Type
Support Solution
Published
2021-11-17
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K53031853

Description

When disable or delete or change the "admin" user account on BIG-IQ, after device reboot, BIG-IQ will fail to load service. The daemon setupd will keep restarting, logs in /var/log/setupd.out like below:

2021-10-10T10:10:10-01:00 BIG-IQ notice boot_marker : ---===[ MD1.1 - BIG-IQ 8.1.0.2 Build 0.0.36 <MD1.1> ]===---
Spawning [icrd_child -S] (pid: 15947)...
Failed to get icrd_child port
Spawning [icrd_child -S] (pid: 18443)...
Failed to get icrd_child port
Spawning [icrd_child -S] (pid: 22276)...
Failed to get icrd_child port

Environment

  • BIG-IQ
  • Deleted, Disabled, or Changed "admin" user account

Cause

This is expected. BIG-IQ requires the "admin" user account. Disabling, Deleting, or Changing the "admin" user account is not supported on BIG-IQ.

Recommended Actions

Revert back the default user account "admin".

  1. Login to BIG-IQ tmsh.

  2. Revert back the default user account "admin":

#modify sys db systemauth.primaryadminuser value admin

#save sys config

  1. Restart restjavad service:

#restart sys service restjavad
