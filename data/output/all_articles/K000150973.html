Description

Certain requests can show the following error when seen in the console output of the browser.

"This attempt to set a cookie via Set-Cookie header was blocked because its Domain attribute was invalid with regards to the current host url."

This behavior can occur when a cookie set by ASM has the wrong value in the "Domain" attribute of the cookie.

Environment

  • ASM cookie

Cause

A request can reach ASM where the "Host" value is not defined in the "Host Names" of the security policy. In this case, the "Domain" attribute of the cookie set by ASM can have a different value. This mismatch can cause the violation.

Recommended Actions

Define a "Host Name" for the relevant request and in case where the Host value can change due to multiple subdomains enable the "Include Sub-domains" option.
