Topic

Step-up/SGC certificates, such as Verisign's Global Certificate, allow users with a low complexity encryption browser (40- or 56-bit) to access a site that only allows high complexity encrypted connections.

Standard certificates consist of two parts:

  • Public certificate
  • Private key

Step-up/SGC certificates consist of three parts:

  • Public certificate
  • Private key
  • CA certificate

Installing a Step-up/SGC

To install a Step-up/SGC certificate, obtain the necessary CA certificate from your certificate vendor, and perform the following steps:

  1. Upload the CA certificate to BIG-IP.

    For more information about transferring files to the BIG-IP, refer to K175: Transferring files to or from an F5 Networks system.

  2. Log in to the command line.
  3. Change the file name of the CA certificate you uploaded to intermediate-ca.crt file, by typing the following command:

    mv <file> intermediate-ca.crt

    Replace <file> with the full path and filename of the file you uploaded.

  4. Move the CA certificate into the /config/bigconfig/ssl.crt/ directory, by typing the following command:

    mv intermediate-ca.crt /config/bigconfig/ssl.crt/

  5. Restart proxyd, by typing the following command:

    proxyd

Note: BIG-IP will only recognize one CA certificate for use with Step-up/SGC certificates. As such, you should use Step-up/SGC certificates from only one vendor.

When it is required, BIG-IP will use the CA certificate automatically.
