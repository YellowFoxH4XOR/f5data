K000149586: How to display NGINX Dashboard status values from the Command line

Description

  • You have deployed and configured NGINX to proxy traffic to/from upstream</p><p>You wish to access HTTP upstream statistics dispalyed in NGINX Dashboard from the command line. 

Environment

  • NGINX Plus
  • REST API Call
  • Command Line
  • Dashboard
  • jq

Cause

  • None

Recommended Actions

  • To display different statistic values from the command line
    • First, you would need to configure a server block and its "location /api" to expose and extract such information
      • SSH into the host system where NGINX installed
      • vi /etc/nginx/nginx.conf file
  • From within the HTTP Block, insert a server block as shown below
                server {
                listen 127.0.0.1;

                          location /api {
                            api write=on;
                            allow 127.0.0.1;
                            deny all;
                          }
                }

with the above set, you can send REST API call

  • For example and focusing on upstream,
    • you can list the status of all configured upstreams following
    • command "curl http : //127.0.0.1/api/9/http/upstreams | jq",
    • provided server block is configured with 127.0.0.1 "listen" address, as per step one.
    • you can simply list the statistics of a particular upstream by appending the name of the upstream to the above curl command

  • send a REST Request
    • curl http : //127.0.0.1/api/9/http/upstreams/ibackend | jq
