Known Issue

If you log off the BIG-IP APM session during an established Citrix remote desktop session, the Citrix resource may become unreachable in a subsequent BIG-IP APM session.

This issue occurs when all of the following conditions are met:

  • You use Internet Explorer 8 in non-compatibility mode when you access the BIG-IP APM system.
  • Users have established a Citrix session through a BIG-IP APM remote desktop access profile.
  • Users terminate their BIG-IP APM Citrix remote desktop session by logging off from the BIG-IP APM system.
  • Users establish a new BIG-IP APM access session, and attempt to initialize a remote desktop to the destination Citrix resource.

Impact

Users are unable to connect to the destination Citrix resource.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to access Citrix using a remote desktop session, you may observe an error message similar to the following example:

    The network connection to your application was interrupted. Try to access your application later, or contact your help desk.
