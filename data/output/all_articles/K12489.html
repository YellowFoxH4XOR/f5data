Topic

When a redundant pair of ARX systems initially form a high availability (HA) pair, all of the Application Control Modules (ACM) and Network Services Module (NSM) processors are reported as up on the active and backup systems. However, once either system of the HA pair has been rebooted, only the 1.1 ACM (SCM on the ARX 6000) is reported as up while all other ACMs and/or NSMs are reported in standby mode. This is expected behavior and does not indicate a failure.

The show processors command on a backup ARX system will display the state of the ACM and NSM processors.

The show processors command output on an ARX 500 system will appear similar to the following example:

Proc Module State   Up      Time      Total Kb  Free Kb  CPU1M   CPU5M
----------------------------------------------------------------------
1.1  ACM    Up      0 days, 17:12:05  12225456  11700152  1      0
1.2  ACM    Standby 0 days, 17:08:30  2714622   2154371   0      0
