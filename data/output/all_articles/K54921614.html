Known Issue

The Always-On Management (AOM) firmware may not update during an upgrade.

This issue occurs when all of the following conditions are met:

  • You upgrade the BIG-IP software on a platform with an AOM subsystem to a version that includes a newer version of the AOM firmware than is currently running.
  • The AOM software aomcltd process is actively running when you perform the upgrade.

Impact

The latest available AOM firmware version does not install.

Symptoms

As a result of this issue, you may encounter the following symptom:
  • After upgrading to a BIG-IP version that includes a newer AOM firmware version, the system is still running an older AOM firmware version.
