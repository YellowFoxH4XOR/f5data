Known Issue

This is the result of a known issue. ICMP traffic does not honor the Connection.VlanKeyed db variable when disabled.

When VLAN-keyed connections are disabled, connection flows are allowed to match any VLANs. Therefore, a connection can be matched to an existing flow and updated, regardless of the VLAN the packet was received on.

ICMP type 3 code 4 Destination Unreachable and Do Not Fragment packets are not updated when VLAN-keyed connections are disabled. The BIG-IP LTM does not update the path MTU if the VLAN the packet was received on does not match the connection flow VLAN specified in the system.

This behavior may result in connection delays while path MTU fails until the packets are sent without the Do Not Fragment bit set.

F5 Networks Product Development is tracking this issue as CR99380.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.1-HF3 issued for BIG-IP LTM version 9.3.1, for the BIG-IP 9.3 software branch. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
