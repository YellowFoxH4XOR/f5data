Issue

If a virtual server has been created that uses Single Sign-on (SSO), but SSO Credential Mapping has not been configured in the access policy, you may receive an error message in your APM logs that appears similar to the following example:

err websso.0[16871]: 014d0028:3: /Common/deckers_webtop_pl:Common:c768f54e: Master Decyrpt failed for ckDecrypt: Ciphertext does not begin with master key prefix

If you see this error message, SSO will not be functional for the virtual server. For more information, refer to the Configuring access policy profile section of K11312: Creating network access with single-sign on capabilities.

Starting in BIG-IP 10.2.0 and in BIG-IP 10.1.0 with cumulative hotfix BIGIP-10.1.0-3372.0-HF1 installed, the error messages relating to SSO credential mapping have changed. For more information, refer to K11577: Error messages for SSO credential mapping issues are now more descriptive.
