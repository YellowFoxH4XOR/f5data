Topic

You can use this F5-supported iApp template to deploy Microsoft Active Directory Federation Services (AD FS) with BIG-IP LTM and BIG-IP APM modules. The BIG-IP LTM system provides high availability, performance, and scalability for both AD FS and AD FS proxy servers. Additionally, you can deploy the BIG-IP APM system to secure AD FS traffic without the need for AD FS proxy servers.

The iApp template and associated deployment guide contain three ways you can configure the BIG-IP system for Microsoft AD FS deployments:

  • Using the BIG-IP LTM system to load balance AD FS servers
  • Using the BIG-IP LTM system to load balance AD FS proxy servers
  • Using the BIG-IP APM system to secure AD FS traffic without the need for proxy servers

For instructions about using this template and configuring your Microsoft AD FS environment, refer to the Deploying F5 with Microsoft Active Directory Federation Services deployment manual.

Downloading the deployment guide

To download the deployment guide associated with the Microsoft Active Directory Federation Services iApp template, perform the following procedure:

  1. Navigate to the Deployment Guides page on F5.com.
  2. Scroll down the page and click Microsoft Active Directory Federation Services (BIG-IP v11, - v13: LTM, APM).

    Note: You can also use Filter by: or Search Deployment Guides to find the file.

  3. Click Download Deployment Guide.
  4. Click the download icon and save the document to your computer.

Downloading the iApp template

Important: You must download the file. Do not copy and paste the contents.

  1. Navigate to the F5 Downloads site.

    Note: If you are not already logged in to the F5.com site, you are required to log in using your F5 support account to access the F5 Downloads site. If you don't have a support account, click Register for an F5 Support Account on the F5 Login page to sign up for one.

  2. From the Downloads Overview page, click Find a Download.

    The Select a Product Line page opens.

  3. In the BIG-IP area, click iApp-Templates.

    The Select a Product Version and Container for IAPP TEMPLATES page opens.

  4. Click iApp-Templates.

    The Software Terms and Conditions page opens.

  5. Read the End User Software License and either accept the license by clicking I Accept or cancel the process by clicking Cancel.

    If you click I Accept, the Select a Download page opens. It shows a table with the file names, product descriptions, and file sizes for the available downloads.

    Note: After you accept the End User Software License , the system does not present the agreement again for subsequent downloads that you perform during the same browser session.

  6. From the Filename column of the table, click the file named iapps-x.x.x.x.x.zip. For example, iapps-1.0.0.405.0.zip.

    The Download Locations page opens.

  7. Click the download location closest to you.

    A pop-up window appears, prompting you to save the file.

    Note: Some browsers save the file to a default location. You can review your specific browser's documentation to change the default location of where you want to save files.

  8. Click Save.

Installing the iApp template

  1. Extract the ZIP file contents to a location accessible to your BIG-IP system.
  2. Log in to the Configuration utility.
  3. Navigate to iApp > Templates.
  4. Click Import.
  5. Select the Overwrite Existing Templates check box.
  6. Click Choose File.
  7. Browse to the location where you saved the ZIP file contents and navigate to the Microsoft > ADFS folder.
  8. Double-click the template file that corresponds to the iApp version you want to install. For example, f5.microsoft_adfs.v1.0.0.

    Note: Refer to the version information in the previously listed Support Matrix table to select the most currently supported template for your BIG-IP software version.

  9. Click Upload.

When the upload completes, the iApp is available for use.
