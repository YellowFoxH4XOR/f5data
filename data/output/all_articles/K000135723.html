Description

  • Configure the AD authentication and AD query for same AD server, AD authentication success, but AD Query failed, the error log printed for the session, in /var/log/apm:
err apmd[<PID>]: 01490107:3: /Common/<Access policy name>:Common:<session id>: AD module: query with '(sAMAccountName=<username>)' failed: Local error, SASL(-1): generic failure: GSSAPI Error: Unspecified GSS failure.  Minor code may provide more information (Message stream modified)  (-2)
  • Click "Update" in the page of the "Group" tab under Access  ››  Authentication  ››  <AD Server>, cannot update the groups.

Environment

  • BIG-IP APM
  • Virtual Server
  • Access Policy
  • AD Query

Cause

It may be an AD server issue.

Recommended Actions

  • Search for the error. For example, The kerberos client received a KRB_AP_ERR_MODIFIED error from the server, may helpful for the issue.
  • Check the event logs on the AD server and resolve any errors.
  • Use the adtest command line utility to test AD query and authentication. For more information, refer to K11308: Overview of the adtest tool.
  • Use the tcpdump utility to take a packet capture.
  • Configure different AD server and different account (enough permission), and then apply the Access Policy.
