K000137298: ASM attack signature does not run on enforced cookies

Type
Support Solution
Published
2023-10-19
Updated
2026-01-09
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.4
Source
https://my.f5.com/manage/s/article/K000137298

Description

  • ASM attack signatures does not run on enforced cookies

Environment

  • BIG-IP ASM
  • ASM attack signature
  • Enforced cookies

Cause

  • You can apply attack signatures only to allowed cookies, because enforced cookies are set by the server, and therefore, are considered to be secure.

Recommended Actions

  • It is the expected behaviour that ASM attack signature does not run on enforced cookies

Additional Information

  • You can configure the cookie name under allowed cookies in order to check the cookie value by ASM attack signatures.
