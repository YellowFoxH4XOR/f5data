Topic

You should consider using this procedure under the following condition:

  • You want to display the attack signatures on a BIG-IP Advanced WAF/ASM system using either command line (CLI) or iControl REST.

For information on displaying attack signatures on a BIG-IP Advanced WAF system using the Configuration utility, refer to K41207833: Displaying the Attack Signature List and/or Attack Signature Sets in the Configuration Utility (GUI) .

Description

You can use the CLI and/or iControl REST to display a list of existing attack signatures on a BIG-IP Advanced WAF/ASM system. This can be useful when you want to review the attack signatures differences between two systems if any, for example production and QA. Using the CLI and/or iControl REST, you can filter the list of existing attack signatures you want to display with the following properties:

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP Advanced WAF/ASM Configuration utility in order to use iControl REST.
  • You have root user access to the BIG-IP Advanced WAF/ASM command line in order to query the database for attack signatures.
  • Performing the iControl REST procedure requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems but can also be installed on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure from a BIG-IP system.

Procedures

  • Displaying attack signatures on a BIG-IP Advanced WAF/ASM system using CLI
  • Displaying attack signatures on a BIG-IP Advanced WAF/ASM systems using iControl REST

Displaying attack signatures on a BIG-IP Advanced WAF/ASM system using CLI

To display attack signatures on a BIG-IP Advanced WAF/ASM system using CLI, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Advanced Shell (bash) as the root user.
  2. Run a query using the following command syntax:

    mysql -uasm -p`perl -I/ts/packages -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` PLC -e "select <property1>, <property2>, … from PLC.NEGSIG_SIGNATURES;"

    For example, you would run the following query to list the ID and name of all attack signatures on the BIG-IP Advanced WAF system:

    mysql -uasm -p`perl -I/ts/packages -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` PLC -e "select sig_id, sig_name from PLC.NEGSIG_SIGNATURES;"

Displaying attack signatures on a BIG-IP Advanced WAF/ASM systems using iControl REST

To display attack signatures on a BIG-IP Advanced WAF/ASM system using iControl REST, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to display the list of existing attack signatures on the BIG-IP Advanced WAF/ASM system:

    curl -sku <username>:<password> -H "Content-Type: application/json" -X GET https://<management IP>/mgmt/tm/asm/signatures[$select expression] | jq [-M . | jq filter expression]

    Replace:

    • <username>:<password> with the credentials that has administrative access to the BIG-IP Configuration utility.
    • <management IP> with the BIG-IP management IP address or localhost if you are running the command from the BIG-IP CLI.

    For example, you would run the following command from the BIG-IP CLI to list the ID and name of all attack signatures on the BIG-IP Advanced WAF/ASM system:

    curl -sku admin:admin -X GET https://localhost/mgmt/tm/asm/signatures | jq '.items[]|.signatureId,.name'

    This example uses jq filter expression to limit the output to display only the signature ID and name:

  3. If you want to filter the list of attack signatures, you can use the following command syntax:

    curl -sku <username>:<password> -H "Content-Type: application/json" -X GET https://localhost/mgmt/tm/asm/signatures?\$filter=<property1>+eq+<property1 value>+and+<property2>+eq+<property2 value>…\&\$select=<propertyA>,<propertyB>,<propertyC>… | jq -M .

    For example, you would run the following query to display the ID and name of attack signature ID 200009188:

    curl -sku admin:admin -H "Content-Type: application/json" -X GET https://localhost/mgmt/tm/asm/signatures?\$filter=signatureId+eq+200009188\&\$select=signatureId,name | jq -M .
