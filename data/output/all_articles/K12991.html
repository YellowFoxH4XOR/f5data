Known Issue

Description

When a user uploads Office 2010 documents to a SharePoint 2007 server through a reverse proxy configuration, the FirePass controller may corrupt the files during the rewrite process.

This issue occurs when all of the following conditions are met:

  • Client uses Office 2010.
  • Client edits an existing document or saves a new document to a SharePoint 2007 server.
  • Client is connecting to the SharePoint server through a FirePass reverse proxy configuration.

Impact

Users will be unable to successfully upload new documents or save changes to existing documents.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Office 2010 reports an error that appears similar to the following example when a user attempts to open the new or updated document:

    The file cannot be opened because there are problems with the content

  • The corrupt file will be 5 to 8 bytes in length, regardless of the size of the original document
