K85408400: Renew IP intelligence licenses combines the remaining time from the old license

Type
Support Solution
Published
2024-08-14
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K85408400

Description
When your planning to renew IP Intelligence license earlier from the expiration date of IPI subscription.

For example:
Subscription Expiration Date: December 1, 2021 
Plan date for renewal: November 30, 2021.

Environment

  • Renewing IP Intelligence License
  • Time Limited Module
  • Subscription License

Cause
None

Recommended Actions

When subscription licenses such as IP Intelligence renewed it will combine the old and new IPI license file. The license server will add the remaining days or extend the existing date of validity.

Based on the above example, if you are planning to renew your IPI license for 1 year, the IPI subscription will expire on December 1, 2022. 

If you require further assistance, please contact F5 Network Support Center.

Additional Information
Removing the old add-on key is not necessary for subscription license. It won't have any effect on the license to include the (old and new add-on key) as they are imprinted in the license file anyway.
