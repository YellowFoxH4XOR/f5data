K000148778: [F5OS-A] Error - "system software upgrade compatibility check failed"- when trying to upgrade

Type
Support Solution
Published
2024-11-28
Updated
2024-12-04
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000148778

Description

You uploaded new F5OS-A ISO image using a file name with special characters

For example : F5OS-A-1.5.1-12283.R5R10(1).iso

Then upload was not successful so you deleted the ISO image.

Then you re-uploaded new ISO image with correct file name second time .

For example : F5OS-A-1.5.1-12283.R5R10.iso

But when trying to upgrade the software you're getting following error on GUI 

error-type: application
error-tag: malformed-message
error-path: /openconfig-system:system/f5-system-image:image/set-version
error-message: System software upgrade compatibility check failed.

You are also seeing following similar log in /var/log/sw-util.log with base ISO image details everytime you perform upgrade.

For example : when upgrade from 1.5.1 to 1.5.2 the base image is 1.5.0

Directory /var/docker/config/appliance/1.5.0-5781 does not exist. 

Environment

  • F5OS-A
  • ISO installation 
  • Upgrade

Cause

When a failed ISO image is deleted, it also removes the files related to the base service causing upgrade to fail

Recommended Actions

Rebooting the unit should resolve the issue 

Additional Information

None
