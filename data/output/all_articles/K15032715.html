Description

Enabling Policy Property 'Differentiate between HTTP/WS and HTTPS/WSS URLs' started blocking traffic.

Environment

  • Policy Property 'Differentiate between HTTP/WS and HTTPS/WSS URLs' enabled
  • HTTPS Requests blocked
  • Violations: Illegal URL
Cause

In the Allowed URL list, there are no HTTPS URLs configured in the Allowed URL list.

Recommended Actions

To manually create Allowed URLs, please refer to the article K29418033: Configuring allowed or disallowed URL lists
