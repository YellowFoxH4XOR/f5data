Description

The NGINX controller have the possibility enable collecting access and error logs for each App Component. The default location for those access and error log is /var/log/nginx/ on Nginx Plus instance. 

There is possibility to redirect access and error logs for each App Component to dedicated files or subfolders.

Environment

  • Nginx Controller 3.22.5
  • Nginx Plus R27

Cause

Need to redirect logs for App Components to dedicated files or subfolder.

Recommended Actions

The solution for redirecting access.log and error log files for App Component to dedicated subfolder.

Before applying this configuration you will need to create subfolder "test" in /var/log/nginx/ on Nginx Plus instance.

ssh <nginx-plus IP>
sudo su -
cd /var/log/nginx/
mkdir test
chown nginx:adm test

From Nginx Controller GUI go the App Component -> Snippets -> URI Snippets add the following two lines:

access_log /var/log/nginx/test/access.log controller_recommended_log_format;
error_log /var/log/nginx/test/error.log;

For "Applicable URI" choose "Select All".

Next "Submit" profile and reload nginx service:

nginx -s reload

example snapshot:

 

Note: There is the possibility to use dedicated filenames e.g. test_access.log and test_error.log instead of default names (access.log and error.log)

Additional Information

Example nginx.conf file on Nginx Plus instance with dedicate access.log and error.log in "test" subfolder".

 Note: If you don't want keep additionally logs in default access.log and error.log you need to comments manually line like in example below:

server {
                server_name 10.171.207.61;
                listen 80 reuseport;
                status_zone server_c729c99b-b77f-35ad-be5c-6d622aa7376a;
                set $f5_gateway test_gw;
                f5_metrics_marker gateway $f5_gateway;
                set $f5_environment test_env;
                f5_metrics_marker environment $f5_environment;
                location / {
            #            access_log /var/log/nginx/access.log controller_recommended_log_format;  <<< commented manually 
                        set $f5_app test;
                        f5_metrics_marker app $f5_app;
                        set $f5_component test_app;
                        f5_metrics_marker component $f5_component;
                        proxy_set_header X-Forwarded-For $remote_addr;
                        proxy_set_header Host $host;
                        proxy_set_header Connection '';
                        proxy_http_version 1.1;
                        access_log /var/log/nginx/test/access.log controller_recommended_log_format; <<< added from GUI
                        error_log /var/log/nginx/test/error.log; ; <<< added from GUI
                        proxy_pass http://webservers_http_5dc74f75-381f-455b-ae32-4076fe848d9c;
                }
        }
