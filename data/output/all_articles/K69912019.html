Known Issue

The Configuration utility may stop responding when viewing the Pool Statistics page.

This issue occurs when all of the following conditions are met:

  • You have configured a large number of pools (about 2,200 or more) on your BIG-IP system.
  • You attempt to view the pool statistics from the BIG-IP Configuration > Statistics > Module Statistics > Local Traffic page.

Impact

The tomcat service restarts automatically as a result of running out of memory resources, and the Configuration utility is inaccessible while the tomcat service restarts.

Symptoms

As a result of this issue, you may encounter all of the following symptoms:

  • The Configuration utility does not display the Pool Statistics page.
  • The tomcat service restarts automatically.
  • You observe log messages in the /var/log/tomcat/catalina.out file that appear similar to the following example:

    # java.lang.OutOfMemoryError: Java heap space                                                
    # -XX:OnOutOfMemoryError="/usr/bin/restart_tomcat"
    #   Executing /bin/sh -c "/usr/bin/restart_tomcat"...

Resolution

Status

F5 Product Development has assigned ID 655484 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can allocate additional memory to the tomcat service. To do so, refer to K9719: Error Message: java.lang.OutOfMemoryError.

Impact of workaround: Allocating additional memory to the tomcat service may impact the performance and stability of the BIG-IP system. F5 recommends that you test any such changes during a maintenance window with consideration to the possible impact on your specific environment.
