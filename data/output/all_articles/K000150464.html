Description

This article provides step-by-step instructions on how to delete a profile (such as an analytics or logging profile) attached to a Virtual Server on F5 BIG-IP, using the command line interface (CLI). This is a common requirement when modifying Virtual Server configurations to ensure they meet updated business or technical requirements.

Environment

  • Product: F5 BIG-IP
  • Affected Components: Virtual Server, Profiles (e.g., Analytics, Logging, etc.)
  • Software Version: Applicable to TMOS-supported versions.

Cause

Profiles, such as analytics or logging profiles, may need to be removed from a Virtual Server due to:

  • Changes to monitoring requirements.
  • Optimization of traffic handling.
  • Replacement of profiles with updated configurations.

Recommended Actions

Follow these steps to delete a profile from a Virtual Server in the CLI:

1. View the Current Configuration (Optional)
Verify the existing profiles attached to the Virtual Server. Run the following command to list the current configuration:

tmsh list ltm virtual <virtual_server_name>

2. Remove the Profile
Use the modify command to update the Virtual Server configuration and remove the specified profile using the following sintax:

tmsh modify ltm virtual <virtual_server_name> profiles delete { profile_name }

For example:

tmsh modify ltm virtual <test-VS> profiles delete { tcp-analytics }

3. Verify the Change
Check the updated configuration to ensure the profile is no longer attached to the Virtual Server:

tmsh list ltm virtual <virtual_server_name>

Confirm that the profile has been successfully deleted.

4. Save the Configuration
Save the updated configuration to ensure the changes persist after a reboot:

tmsh save sys config

Note: It is a good idea to verify the changes after performing modifications to avoid unexpected behavior. Removing critical profiles may affect traffic handling or visibility.
