Known Issue

This is the result of a known issue. It is not possible to update any SOA resource records using the ZoneRunner utility. Some fields, such as the TTL, allow a value to be entered in the field, but the Update button required to save the changes does not appear on the screen.

F5 Product Development tracked this issue as ID 224276 (formerly CR135158) and it was fixed in BIG-IP GTM 11.0.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.4-771.0-HF6, which was issued for BIG-IP GTM 10.2.4. You can download this hotfix, or later versions of the cumulative hotfix, from the F5 Downloads site.

For information about installing a hotfix for BIG-IP 10.x systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

You can work around this issue by manually editing the zone file as detailed in K7032: Freezing zone files to allow manual update to ZoneRunner-managed zone files.
