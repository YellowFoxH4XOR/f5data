Known Issue

The BIG-IP system may experience performance degradation when a forwarding virtual server processes Generic Routing Encapsulation (GRE) tunnel traffic.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration includes one or more IP forwarding virtual servers.
  • You have one or more IP forwarding virtual servers processing a large amount of GRE tunnel traffic.

The lack of a port number in the GRE packet header causes a single Traffic Management Microkernel (TMM) to process all GRE tunnel traffic.

Impact

Remote clients experience delayed or stalled connections.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Remote clients experience delayed or stalled connections.
