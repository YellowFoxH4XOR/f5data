K23315436: How do I remove a GTM or DNS from a GTM/DNS sync group

Description

How to safely remove BIGIP device from GTM/DNS Sync Group

  • Recommended step to removing DNS/GTM system for troubleshooting or decommissioning.

Environment

  • DNS/GTM is already an established member of a device sync group

Cause

None

Recommended Actions

The following procedure will safely remove the DNS/GTM from the Sync Group:

  1. Go to the devices you would like to remove from the sync group, uncheck the Sync and the Synchronize DNS Zone Files
    • DNS > Settings > GSLB and Uncheck:
      • Synchronize
      • Synchronize DNS zone files
  2. Rename the Group Name to something else for added assurance
  3. Click Update
  4. On an existing member of the GTM/DNS sync group, remove server objects in DNS > GSLB > Servers > Server List referencing the device you removed. Refer to K20508343: Removing a server entry in GTM/DNS for instructions.
  5. On an existing member of the GTM/DNS sync group, delete the removed device's trusted device certs from device group members. You can find the certificates in the GUI by navigating to the following pages:
    • System > Certificate Management > Device Certificate Management > Device Trust Certificates
    • DNS > GSLB > Servers > Trusted Server Certificates
  6. Verify the changes synchronized to the other members.
  7. If necessary, you can also delete unwanted DNS zones using ZoneRunner on an existing member of the GTM/DNS sync group. Go to the DNS > Zones > ZoneRunner > Zone List page, select the zone, and select Delete. This deletes all resource records in the zone and if Synchronize DNS Zone Files is checked deletes the zones on all sync group members. If so, verify the changes synchronized.
