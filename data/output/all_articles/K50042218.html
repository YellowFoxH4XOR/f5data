Known Issue

Tab completion in the Traffic Management Shell (tmsh) may not function properly when you attempt to delete a profile.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a custom TCP or HTTP profile.
  • You attempt to use tab completion in the tmsh utility when deleting the profile.

    For example:

    modify /ltm virtual BZ_VS profiles delete { <press the tab key>
    modify /ltm virtual BZ_VS profiles delete { htt<press the tab key>
    modify /ltm virtual BZ362164_VS profiles delete { tc<press the tab key>

Impact

Tab completion in the tmsh utility does not function properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you press the tab key to autocomplete a profile type name, the profile name does not autocomplete.
  • You are required to fully type out the profile type name of the tmsh command.
