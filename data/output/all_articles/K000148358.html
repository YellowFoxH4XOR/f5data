K000148358: RDP Resource can be run from a different computer

Type
Support Solution
Published
2024-11-15
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000148358

Description

When an RDG profile is configured and assigned in VPE, then a .rdp file can be transferred through zoom/email, and an unauthorised client machine can launch an RDP session to a back-end resource server in an APM session.

Environment

  • RDP Resource 
  • RDG-RAP as Access Profile
  • RDG Policy Assign in VPE

Cause

By design

Recommended Actions

Enable "restrict to single client ip" on the Access Profile.

When Restrict to Single Client IP option is enabled, a user should only be allowed to launch the resource from the client that initiated the request.

Additional Information

In a case where you have another device in between the client and Big-ip, which is acting on behalf of the client, therefore big-ip only sees that as one IP.

If it's two different devices but big-ip sees one client IP, then it will allow access, if the IPs are different, it will restrict access.

 

You can check the client IP that the big-ip is seeing by navigating:

Access > Overview > Active sessions
