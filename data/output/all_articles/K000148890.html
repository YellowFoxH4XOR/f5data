Topic

This article describes the PPP tunnel error stats for BIG-IP APM Network Access VPN sessions.

Description

The BIG-IP APM system provides PPP tunnel error stats for TLS/DTLS during Network Access VPN connections. The PPP tunnel messages are logged each time a PPP tunnel is disconnected, regardless of the reason for the disconnection. The stats should be used in combination with additional data and troubleshooting methods. It should be taken into consideration that a small number of errors can be reported and still not be an indication that there is a problem, due to the nature of the protocols used for VPN.

Recommendations

When troubleshooting Network Access VPN connections, it is possible to review the PPP error messages in the APM logs to help diagnose problems related to the PPP tunnel. Additional troubleshooting should be including using methods described in K00231525: VPN for business continuity | Chapter 8: Troubleshoot the Network Access VPN tunnel.
