Description

Logs similiar like next is shown even when the alerting certificate has already been removed. 
 

warning tmsh[27506]: 01420008:4: Certificate 'CN=<Certificate_CN>,OU=<Certificate_OU>,O=<Certificate_o>,C=<Certificate_C>' in file /Common/ca-bundle.crt will expire on Mar 20 18:05:38 2022 GMT

Environment

  • Warnings for certificate that has already been deleted are still appering in the logs. 

Cause

Unknown

Recommended Actions

To resolve this issue, please proceed with mcpd forceload reboot following article K13030: Forcing the mcpd process to reload the BIG-IP configuration.

Note: The mcpd forceload reboot is a traffic-impacting process and mainteance window is recomended before proceeding.
