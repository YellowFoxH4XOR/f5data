Description
Unable to perform a config sync after renaming a virtual server name using the tmsh mv command.

  • Configuration cannot be loaded
  • Error message is presented in /var/log/ltm

    /usr/bin/tmsh -n -g load sys config partitions all " - failed. -- 010719a2:3: PostgreSQL database error: ERROR: duplicate key value violates unique constraint "virtual_server_pkey" DETAIL: Key (name)=('/partition/virtual_server_name') already exists. Unexpected Error: Loading configuration process failed.

Environment

  • Use 'tmsh mv' to change a virtual server name
  • After changing name you attempt to load the configuration

Cause
The tmsh mv command fails to update the PostgreSQL database with the new object name. This is caused by a known issue ID678397.

Recommended Actions

Remove the affected virtual server key from the PostgreSQL database and re-load configuration files again to let the database create a new key.
  1. Log in to the BIG-IP command line
  2. Connect to the PostgreSQL database as user postgres, by typing the following command:
    psql -U postgres
  3. Connect to the traffic management table, by typing the following command:
    \c tmdb
  4. Delete the affected virtual server entry using the following command syntax:

    delete from virtual_server where name='/partition/virtual_server_name';

    Replace  '/partition/virtual_server_name' with the original (old) virtual server name.

    For example, if you had changed a virtual server named /Common/testvs1  to /Common/testvs2, you would use the following command:

    delete from virtual_server where name='/Common/testvs1';
     
  5. Remove the database links for the virtual server and keys, by typing the following commands:

    alter table virtual_server drop constraint virtual_server_pkey ;
    alter table virtual_server drop constraint virtual_server_addr_name_key ;
     
  6. Exit the PostgreSQL database by typing the following command:

    \q
     
  7. Load the configuration by typing the following command:

    tmsh load sys config
 

Additional Information
Rather than using the tmsh mv command to change the name of a configuration object, you should use any of the followoing methods:

  • Using 'tmsh modify' commands
  • Running 'tmsh delete/create' commands
  • Editing the configuration in the GUI
  • Executing REST API calls
