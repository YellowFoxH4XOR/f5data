Description

The browser debugger (Developer Tool) shows the F5 BIG-IP management login page with HTTP header:
Pragma: no-cache, no-cache

The Pragma header shows that there are two no-cache instead on one.

This article explains further on this HTTP header on the BIG-IP management.

Environment
  • BIG-IP management interface
  • BIG-IP GUI login page
  • HTTP header Pragma: no-cache, no-cache

Cause

This is an expected HTTP header when accessing the BIG-IP management (login page).

This is not a vulnerability.

There is no workaround to remove both no-cache as it is required by the BIG-IP management.

Recommended Actions

None.

Additional Information

None.
