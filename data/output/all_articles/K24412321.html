Known Issue

The BIG-IP system may erroneously allow duplicate media access control (MAC) masquerade addresses in traffic group configurations.

This issue occurs when all of the following conditions are met:

  • You have multiple traffic groups configured in a device service clustering (DSC) trust domain.
  • You use the same MAC masquerade address on two or more traffic groups in the DSC.

The BIG-IP system should not allow you to configure a traffic group with a MAC masquerade address that is already in use by another traffic group.

Impact

The BIG-IP system may not correctly process network requests.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you configure a traffic group with a MAC masquerade address already in use by another traffic group in the DSC, the BIG-IP system does not correctly process network requests.
  • After you upgrade to BIG-IP 12.1.0 and start the BIG-IP system, you observe warning messages in the /var/log/ltm file that appear similar to the following example:

    warning mcpd[6407]: 01071859:4: Warning generated : Misconfigured traffic-group (/Common/traffic-group-1): Masquerade MAC address 02:01:D7:01:02:03 used by multiple traffic-groups.

Note: If you upgrade the BIG-IP system to 12.1.0 without removing the duplicate MAC masquerade address from the configuration, you may observe the symptoms listed in the Symptoms section.

Workaround

To work around this issue, you can configure a unique MAC masquerade address for each traffic group. For more information, refer to K13502: Configuring MAC masquerade (11.x - 14.x).

Impact of workaround: Configuring a MAC masquerade address for a traffic group can temporarily disrupt traffic on the associated VLAN while the surrounding network devices learn the new hardware address association. F5 strongly recommends that you perform this procedure during a scheduled maintenance window.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To define a MAC masquerade address for a traffic group, use the following command syntax:

    modify /cm traffic-group <traffic_group> mac <mac_address>

    For example, to configure a MAC masquerade address of 02:01:D7:01:02:03 for a traffic group called traffic-group1, type the following command:

    modify /cm traffic-group traffic-group1 mac 02:01:D7:01:02:03

    Note: For more information about selecting an appropriate MAC masquerade address, refer to SOL3523: Choosing a unique MAC address for MAC masquerade.

  3. Save the change by typing the following command:

    save /sys config
