Description

In order to perform changes in Learning and Blocking configuration for multiple policies, administrators can use REST API.

Environment

  • BIG-IP ASM
  • Learning and Blocking settings

Cause

Modifying multiple policies using GUI can be time consuming and can lead to potential mistakes.

Recommended Actions

The best way to perform changes on multiple policies is to use REST. Here is an example procedure for single policy to modify Modified Domain Cookie(s) blocking setting:

  1. List ASM policies and corresponding links:

    curl -u admin:password -ks "https://localhost/mgmt/tm/asm/policies" | jq '.items[].name,.items[].selfLink'

    Example output:

    "test_update_policy"
    "https://localhost/mgmt/tm/asm/policies/8jdXTExRZzyptZTlhK8d7Q?ver=13.1.0"

    8jdXTExRZzyptZTlhK8d7Q is policy ID for REST calls.

  2. Verify current policy settings for Modified Domain Cookie:

    curl -u admin:password -ks "https://localhost/mgmt/tm/asm/policies/8jdXTExRZzyptZTlhK8d7Q/blocking-settings/violations/z_18CsCKd0IJ9t5aRzkPRw?ver=13.1.0" | jq .

    Note: You can check other settings using:

    curl -u admin:password -ks ""https://localhost/mgmt/tm/asm/policies/8jdXTExRZzyptZTlhK8d7Q/blocking-settings/violations"" | jq .

  3. Use policy link to disable Modified Domain Cookie blocking:

    curl -k -u admin:password -H "Content-Type: application/json" -X PATCH "https://localhost/mgmt/tm/asm/policies/8jdXTExRZzyptZTlhK8d7Q/blocking-settings/violations/z_18CsCKd0IJ9t5aRzkPRw?ver=13.1.0" -d '{"block": "false"}'

    Note: To enable blocking:

    curl -k -u admin:password -H "Content-Type: application/json" -X PATCH "https://localhost/mgmt/tm/asm/policies/8jdXTExRZzyptZTlhK8d7Q/blocking-settings/violations/z_18CsCKd0IJ9t5aRzkPRw?ver=13.1.0" -d '{"block": "true"}'

  4. Verify the change:

    curl -u admin:password -ks "https://localhost/mgmt/tm/asm/policies/8jdXTExRZzyptZTlhK8d7Q/blocking-settings/violations/z_18CsCKd0IJ9t5aRzkPRw?ver=13.1.0" | jq .

  5. Apply Policy using this command:

    curl -k -u admin:password -X POST "https://localhost/mgmt/tm/asm/tasks/apply-policy" -d '{"policyReference": {"link": "https://localhost/mgmt/tm/asm/policies/8jdXTExRZzyptZTlhK8d7Q"}}'
