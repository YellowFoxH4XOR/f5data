F5 Technical Support generally requires a packet trace when assisting you in troubleshooting a network traffic issue. This Solution provides instructions about using the tcpdump utility to capture a packet trace while you reproduce the issue. If you capture this information before you open a case with F5 Technical Support, it often speeds resolution.

Gathering a tcpdump packet trace

You can gather a tcpdump packet trace by performing the following procedure:

  1. Log in to the command line.
     
  2. Determine which VLANs are involved in the network traffic issue.

    If traffic passes in and out of only one VLAN, run tcpdump only on that VLAN. If traffic passes into and out of separate VLANs, run tcpdump on both VLANs.

  3. Run tcpdump on each VLAN, using the following command syntax:

    tcpdump -i <vlan> -Xs 1600 -w /var/tmp/<case>.<vlan>.dmp &

    Replace <vlan> in both locations with the name of the VLAN.

    Replace <case> with the F5 Technical Support case number. The case number helps F5 Technical Support to ensure that the information is associated with the right case. If you have not yet opened a case with F5 Technical Support, replace <case> with the serial number of the BIG-IP system.

    Repeat this step for each VLAN that you are troubleshooting.

  4. Run tcpdump on the loopback interface, using the following command syntax:

    tcpdump -i lo0 -Xs 1600 -w /var/tmp/<case>.loopback.dmp &

  5. Close any open browsers on the system.

    Important: F5 Technical Support will analyze the browser session from start to finish. If the browser is not closed first, it may already have entered a problematic state and F5 Technical Support will not be able to determine the cause.

  6. Reproduce the issue.
     
  7. After you have reproduced the issue, close all of the tcpdump sessions, as follows:

    1. When you ran each tcpdump command, you placed the process in the background. To return the process to the foreground, type the following command:

      fg

      The original command will display on the screen.

    2. Press CTRL-C to close the session.
       
    3. Repeat these steps for each tcpdump session that you opened.

The packet traces are complete. The files are located in the /var/tmp directory.

Preparing and submitting tcpdump packet trace files

To prepare and submit the tcpdump packet traces, perform the following steps:

  1. Compress each of the packet trace files, using the following command syntax:

    gzip <file>

    Replace <file> with the name of the tcpdump file you created.

    The gzip command will automatically append a .gz extension.

  2. Create a UCS configuration archive, using the following command syntax:

    bigpipe config support save /var/tmp/<case>

    Replace <case> with your F5 case number. If you have not yet opened a case with F5 Technical Support, replace <case> with the serial number of the BIG-IP system.

    This command will create a UCS archive named <case>.ucs in the /var/tmp directory.

  3. Upload the UCS archive to dropbox.f5.com using FTP.

    For instructions about sending files to F5 Technical Support refer to K2486: Providing files to F5 Technical Support.

  4. Contact F5 Technical Support and inform them that you have uploaded the trace information.
