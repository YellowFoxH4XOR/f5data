K000140689: High BD CPU When Enabling Classify Request Content of Learned HTTP URLs

Type
Support Solution
Published
2024-08-12
Updated
2024-08-12
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000140689

Description

High CPU mostly by ASM's daemon BD.


Environment

ASM

Cause

Most of the accepted suggestion to add URLs has request body handling set to [Apply value and content signature] due to misconfiguration in URL's Learning and Blocking Settings as it's configured to have [Classify Request Content of Learned HTTP URLs] option enabled which isn't recommended.

Recommended Actions

The seeing CPU is due to policies configuration being in a non-healthy state. Please disable Classify Request Content of Learned HTTP URLs.
