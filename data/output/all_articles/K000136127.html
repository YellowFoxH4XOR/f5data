Description

  • Specific monitor ports are not available by default in the node monitor, this is only possible in pool members.

Environment

  • LTM

Cause

It is necessary to monitor nodes in a specific port, not just in a general way as with ICMP

 

 Recommended Actions

  1. Create a new monitor in Local Traffic ›› Monitors
  2. Select type as TCP
  3. Change the Alias Service Port with the port it is necessary
  4. Now it should be possible to select the new monitor in the node monitor settings.
