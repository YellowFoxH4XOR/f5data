Known Issue

The Network Access Setup Wizard may create an access policy with an empty Antivirus action.

This issue occurs when the following conditions are met:

  • The Network Access policy has been created using the Network Access Setup Wizard.
  • The Client Side Checks check box was set to enabled (Enable Antivirus Check in Access Policy) in the Wizard when creating the policy.

Impact

Clients are unable to access the virtual server logon page.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Client access to a virtual server associated with the affected access policy will fail during the Antivirus check and present a "Your session is finished" notification.
  • The virtual server logon page is not displayed.

Workaround

To work around this issue, you can use the VPE editor to configure the access policy with the desired Antivirus checks. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Access Profiles.
  3. Locate the affected access policy.
  4. In the Access Policy column, select Edit to open the VPE editor.
  5. Click Antivirus Software Check.
  6. Click Add new entry.
  7. Select the appropriate Platform and Vendor ID for the policy.

    Note: Using the default settings of Any enables the most wide ranging Antivirus software checks.

  8. Set the State to Enabled.
  9. Click Save.
  10. Click the Apply Policy notification in the upper left corner of the Configuration utility.
