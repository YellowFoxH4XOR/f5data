Description

The following messages are observed within /var/log/ts/bd.log on several occasions:

IO_PLUGIN|NOTICE|Jun 08 23:02:21.428|15991|io_plugin.c:0988|Invoke Plugin tm_soft_reset.
IO_PLUGIN|NOTICE|Jun 08 23:02:21.428|15990|io_plugin.c:0629|In io_plugin_config_update profile_name=/Common/pluginasm
IO_PLUGIN|NOTICE|Jun 08 23:02:21.429|15991|io_plugin.c:0629|In io_plugin_config_update profile_name=/Common/pluginasm

Environment

  • ASM provisioned
  • Security policy changes are issued

Cause

The messages reported within /var/log/ts/bd.log are logged when certain configuration changes are made and the ASM plugin configuration needs to be adjusted. This information can be correlated within /var/log/asm where it would show changes being pushed to a security policy (thereby a new version got created) and the new version of the policy was set to being active.

Recommended Actions

A high occurrence of these messages within bd.log file would indicate lots of configuration changes, but the messages are considered to be benign in nature.
