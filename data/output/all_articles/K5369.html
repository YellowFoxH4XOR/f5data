K5369: The Configuration utility does not allow the use of the Enter key to commit content in the Wide IP Alias name field

Source

Known Issue

This is the result of a known issue. In the Configuration utility, if you type information in the Edit Wide IP screen and then press the Enter key, 3-DNS discards the content you entered. In other screens, 3-DNS will allow you to submit information by pressing the Enter key.

F5 Networks Product Development tracked this issue as CR18887.

Workaround

To avoid this issue, click the Add button in the Edit Wide IP screen, rather than pressing the Enter key.
