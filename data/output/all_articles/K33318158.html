Known Issue

When generic hosts are associated with different data centers but the same monitors, server status flapping occurs.

This issue occurs when all of the following conditions are met:

  • You create two generic hosts and associate them with different data centers.
  • The two hosts are not directly accessible by way of DNS (that is, they have internal network access only).
  • You have configured a monitor to monitor both hosts, and the monitor contains the same name, but uses a different configured alias IP/Port.

Impact

The server status flaps from red to green, and back to red.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you navigate to DNS > GSLB > Server, the status flaps from red to green to red.

Workaround

To work around this issue, you can check the Transparent option for the affected monitors you have configured.
