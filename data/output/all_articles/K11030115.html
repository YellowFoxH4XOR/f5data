K11030115: agetty[<PID>]: /dev/tty0 ttyS0: No such file or directory logged in /var/log/secure every 10 seconds

Description

An agetty error message is output to the /var/log/secure log file every 10 seconds:
agetty[<process_id>]: /dev/tty0 ttyS0: No such file or directory.

Environment

  • BIG-IQ 
  • /var/log/secure log file filling up with agetty error messages
  • Multiple consoles configured in grub.conf

Cause

Multiple consoles configured in grub.conf.

Example: 
....
title BIG-IQ 8.0.0.1 Build 0.0.41 - drive vda.1
    root (hd0,0)
    kernel /boot/1/vmlinuz ro root=UUID=abc123dd-5ab6-456e-f7e8-9a987b0f65b4 console=tty0  console=ttyS0 panic=1 platform=Z100 default_cpu_order quiet   ---->>>
    initrd /boot/1/initrd
    # TIC_VS_PROJECT:
    # TIC_VS_PRODUCT: BIG-IQ
    # TIC_VS_VERSION: 8.0.0.1
    # TIC_VS_BUILD: 0.0.41
    # TIC_VS_BASEBUILD: 0.0.41
    # TIC_VS_EDITION: Point
    # TIC_VS_PROJECT:
...

Recommended Actions

  1. First remount /usr as read/write
    mount -o remount,rw /usr
     
  2. Use an editor or download to modify the getty unit file located at /usr/lib/systemd/system/getty@.service
     
  3. Find the following line in the file:
    ConditionPathExists=/dev/tty0
     
  4. Add the following line after it:
    ConditionPathExists=/dev/%I
     
  5. Save the edited file or upload it back to the original location on BIG-IQ
     
  6. Remount /usr as read-only
    mount -o remount,ro /usr
     
  7. Reload systemd to take the modification into effect
    systemctl daemon-reload
