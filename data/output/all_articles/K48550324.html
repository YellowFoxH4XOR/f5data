Known Issue

'Host Mem Usage' and 'TMM Mem Usage' statistics are not included in exported CSV files.

This issue occurs when the following condition is met:

  • You export the Memory Usage statistics in the Statistics > Dashboard > History > Overview section of the Configuration utility, to a CSV file.

Impact

Exported CSV files do not contain Host Mem Usage and TMM Mem Usage columns.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Exported CSV files are missing derived statistical information for memory usage.

Resolution

Workaround

To work around this issue, you can include the raw statistics in the exported data and manually calculate the host memory usage and Traffic Management Microkernel (TMM) memory usage. When you select the Include Raw data check box before saving the CSV file, the 'Total RAM,' 'Free RAM,' 'Total TMM Memory,' and 'TMM Memory Used' statistics are included in the exported data. To calculate the missing statistics, use the following formulas:

  • TMM Mem Usage = ( TMM Memory Used x 100 ) / Total TMM Memory
  • Host Mem Usage = 100 - ( ( Free RAM x 100 ) / Total RAM )
