K000091642: Configuring Custom Syslog Format for NGINX Instance Managed by NGINX Instance Manager

Type
Support Solution
Published
2022-06-29
Updated
2022-07-06
Source

Description

  • Configuring custom log format for NGINX instance
  • Example of warning log observed in NGINX instance /var/log/nginx-agent/agent.log
    • time="2022-06-17T00:16:18Z" level=warning msg="NGINX Access log syslog:server=1.1.1.1 is not readable or is disabled. Please make it readable and enabled in order for NGINX metrics to be collected."
    • time="2022-06-17T00:19:53Z" level=error msg="NGINX Access log /var/log/nginx/access.log's log_format has to be the exact format as the default comes from the installation."

 Environment

  • NGINX Instance Manager 2.1.0 and 2.2.0
  • NGINX Plus R25 and R26

 Cause

  • Custom log format will prohibit NGINX Instance Manager from doing metric collection

 Recommended Actions

  • Split the access_log to two:
    • access_log that will be written to local file (NGINX Instance Manager will collect metric from this access_log)
    • syslog
Configuration Example

log_format syslog '"$time_local" client=$remote_addr '

'url=$scheme://$host$request_uri '

'method=$request_method request="$request" '

'length=$request_length '

'status=$status bytes_sent=$bytes_sent '

'referer=$http_referer '

'ups_status=$upstream_status '

'request_time=$request_time '

'ups_response_time=$upstream_response_time '

'ups_connect_time=$upstream_connect_time '

'ups_header_time=$upstream_header_time '

'ups_http_location=$upstream_http_location '

'upstream_http_location=$upstream_http_location '

'server_name=$server_name '

'$upstream_cache_status '

'host = $host '

'ancient_browser = $ancient_browser '

'request_uri = $request_uri '

'$status $body_bytes_sent '

'remote_user = $remote_user';

log_format ori_format '$remote_addr - $remote_user [$time_local] "$request" '

'$status $body_bytes_sent "$http_referer" '

'"$http_user_agent" "$http_x_forwarded_for"';

access_log syslog:server=1.1.1.1 syslog;

access_log /var/log/nginx/access.log ori_format;
