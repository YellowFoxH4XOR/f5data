K25966754: How to delete interfaces on VIPRION device for a slot which is empty

Description

Under certain circumstances, you may see interfaces on VIPRION device for a slot which is empty.

For example, slot 1 is empty, but interface 1/1.1 is shown in GUI or tmsh output.

Environment

  • VIPRION
  • Interfaces shown for an empty slot

Cause

It is possible that the blade was removed from the slot or moved between slots. The interface configuration (with original slot number) may still be present in config files.

Recommended Actions

  1. Take a UCS backup of this device before making any changes and ensure you have downloaded it on your local machine 
     
  2. Ensure the Slot is empty by running " tmsh show sys cluster properties"

    ----------------------------------------------------------------------
    Sys::Cluster: default
    ----------------------------------------------------------------------
    Address                 10.10.10.1/24
    Availability            available
    State                   enabled
    Reason                  Cluster Enabled
    Primary Slot ID         3
    Primary Selection Time  04/06/2022 22:37:35

      -----------------------------------------------------------------------------------------------
      | Sys::Cluster Members
      | ID  Address     Availability  State    Licensed  HA       Clusterd  Reason
      -----------------------------------------------------------------------------------------------
        1   10.10.10.1  unknown       enabled  false     unknown  shutdown  Slot powered off or empty  <-- empty slot!
        2   10.10.10.2  unknown       enabled  false     unknown  shutdown  Slot powered off or empty
        3   10.10.10.3  available     enabled  true      active   running   Run
        4   10.10.10.4  unknown       enabled  false     unknown  shutdown  Slot powered off or empty

     
  3. Check bigip_base.conf to see if it still has interface configuration related to empty slot. In bash mode , run "vi /config/bigip_base.conf"
    Note : Slot 1 interfaces would be named like 1/1.X

    Use vi or any preferred editor to remove the whole interface config as below and save the file

    net interface 1/1.1 {
      disabled
      lldp-admin txrx
      lldp-tlvmap 114552
    }
     
  4. Verify configuration load is working:
    # tmsh load sys config verify
     
  5. If step 4 works, load the configuration:
    # tmsh load sys config
     
  6. If you still see interfaces, perform mcpd forceload using below commands (in bash):
    # clsh touch /service/mcpd/forceload
    # clsh reboot
