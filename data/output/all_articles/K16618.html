Topic

This article discusses the limitations when you enable the DNS Rapid-Response feature on a BIG-IP system.

Description

When you enable the DNS Rapid-Response feature on a BIG-IP system, the following list of limitations apply:

  • Virtual server with iRules

    When you enable the DNS Rapid-Response feature in a DNS profile and associate it with a virtual server that has an iRule to process DNS traffic, the BIG-IP system may not execute the iRule. In addition, the BIG-IP system logs a warning message in the /var/log/ltm file that appears similar to the following examples:

    010718a5:4: The DNS profile /Common/exampleDNSprofile, with DNS DNS Acceleration (DNS in HW and/or DNS Rapid-Response Mode) Enabled, may cause incompatibilities with rules enabled on Virtual Server /Common/example-dns-vs: /Common/example-dns-irule.

    010718a5:4: The DNS profile /Common/exampleDNSRapidRespProf, with DNS Rapid Response Enabled, may cause incompatibilities with rules enabled on Virtual Server /Common/exampleDNSRapidRespListener: /Common/exampleDNSRapidRespiRule.

  • DNS denial-of-service (DoS) profile

    When you enable the DNS Rapid-Response feature on a virtual server that has a DNS DoS profile associated, the DNS queries may be answered or dropped before the DNS DoS has a chance to execute.

  • All other DNS profile options

    When you enable the DNS Rapid-Response feature in a DNS profile, all other configured DNS profile options, such as DNS Cache, DNSSEC, DNS IPv6 to IPv4, will not execute when a DNS query matches. In addition, the BIG-IP system logs a warning message in the /var/log/ltm file that appears similar to the following example:

    The DNS profile /Common/exampleDNSRapidRespProf has DNS Rapid Response Enabled, results in the following features having no effect on DNS processing: DNS Cache/Resolver.

  • Prior to BIG-IP 13.1.0 - BIG-IP platforms without the High-Speed Bridge (HSB)

    In BIG-IP versions before 13.1.0, you may be able to enable and configure the DNS Rapid-Response feature, but the feature is not supported on BIG-IP platforms that do not have the HSB (for example BIG-IP Virtual Edition). In BIG-IP 13.1.0 and later, support for DNS Rapid-Response is introduced to all platforms (regardless of their HSB equipment). You can determine if your BIG-IP platform has the HSB by entering the following command at the command line:

    lspci | grep -i 'F5 Networks'

    If your BIG-IP platform has the HSB, the previous command will return output that appears similar to the following example:

    03:00.0 Ethernet controller: F5 Networks Inc. Device 0003

    If your BIG-IP platform does not have the HSB, the previous command will not return output.

These limitations are designed to enhance performance for the DNS Rapid-Response feature.
