Known Issue

BIG-IP APM access policy Active Directory (AD) or Lightweight Directory Access Protocol (LDAP) queries may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an access policy that queries attributes from AD or LDAP.
  • A query result returned from AD or LDAP is in binary format. For example, the binary attribute could contain printable ASCII characters, followed by 0x00, and then printable characters again, as follows:

    binary attribute 0x3100323334 1\0234')

    Based on the format of the binary data, the BIG-IP APM system incorrectly interprets the attribute as printable data causing the query to fail.

Impact

Some user accounts in AD or LDAP may not be able to log in to the BIG-IP APM access profile.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H432777 on the Diagnostics > Identified > Low|Medium screen.
  • Clients who access the BIG-IP APM access policy receive an error message similar to the following example after they enter credentials:

    The session reference number: <session id value>
    Access was denied by the access policy. This may be due to a failure to meet access policy requirements.

  • One or more of the access policy session variable query results does not match the value set in AD or LDAP for the user.
