Description

Upgrading a vCMP Guest to 13.1.3.6 (and other affected versions), the device crashes and leaves a tmm core file.

You can find similar logs on /var/log/tmm:

notice panic: ../kern/daglib.c:1800: Assertion "Hash type successfully set" failed.
notice ** SIGFPE **

Device keeps crashing continuously with same Assertion log, if left on upgraded version.

Environment

  • Tmm core SIGFPE signal
  • During and after upgrading

Cause

Bug ID 1001541: TMM crash (SIGFPE) when starting on a VCMP guest.

Recommended Actions

Upgrade the vCMP Host to a fixed version.

None
