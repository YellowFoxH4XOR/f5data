K000148775: Successful Upgrade to NGINX Plus R33 but Receiving "invalid license token" errors

Type
Support Solution
Published
2024-11-28
Updated
2025-04-01
Applies to
  • NGINX Products
  • NGINX Plus
  • NGINX Gateway Fabric
  • NGINX Ingress Controller
  • NGINX Instance Manager
Source
https://my.f5.com/manage/s/article/K000148775

Description

  • You want to upgrade NGINX Plus to version R33
  • You create required file "license.jwt" under directory " /etc/nginx/ "
  • You update "license.jwt" file with Nginx JWT token, obtained from MyF5 Customer Portal
  • The upgrade to R33 succeeds but when validating Nginx Configuration or service, you encountered error message "nginx: [error] invalid license token"
  • You encountered this error despite you have a valid subscription 

Environment

  • NGINX Plus {R33}
  • Upgrade
  • JWT Token

Cause

  • The issue might be related to how the JWT payload was written into the license.jwt file.
  • It is possible that trailing chars (spaces or newline) were accidentally added to the end of the file during its creation.

Recommended Actions

  • You can validate applied JWT token and you can do so using sites like https://jwt.io/
  • When validating a license (assuming the signature is valid), you should look or check the following claims

JWT Token Payload

                     {
                      "sub": "FNI-97xxxxxe-xxxx-xxxx-xxxx-51xxxxxxc058",
                      "iat": 172xxxx928,
                      "iss": "F5 Inc.",
                      "aud": "urn:f5:teem",
                      "jti": "8axxxx0-xxxx-xxxx-xxxx-e9xxxxx65",
                      "f5_order_type": "paid",
                      "f5_sat": 1783900800
                     }
  • These claims, "iss", "aud", and "f5_sat" MUST be present and have the specified values.
  • "f5_sat" is analogous to exp and represents a unix timestamp indicating until when the license is considered valid.
  • You can convert "f5_sat": 1783900800 to a human format as follows:
                    date -d @1783900800
                    Mon 13 Jul 01:00:00 BST 2026

Additional Information

  • The claims f5_order_type and f5_order_subtype are important but doesn't affect token validation errors.
  • It’s important to ensure that license.jwt does not contain trailing spaces or newline characters. You can check this using command xxd: and license.jwt file created above
                    $ xxd license1.jwt
                    ...
                    000002a0: 495a 3563 4b43 7a50 7a61 5946 5041 4277  IZ5cKCzPzaYFPABw
                    000002b0: 200a 0a  

In the above example,
        - 20 represents space 
        - 0a represents newline.
