Known Issue

This is the result of a known issue. The BIG-IP ZebOS implementation does not currently support IPv6 with the dynamic routing modules offered.

F5 Product Development tracked this issue as CR54805 and it was fixed in BIG-IP version 9.4.4. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator Release Notes.
