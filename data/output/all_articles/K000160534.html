K000160534: Default value of "alertd.lcdwarn" became disable after ucs restore

Type
Support Solution
Published
2026-03-31
Updated
2026-04-14
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000160534

Description

After restoring a UCS file on a BIG-IP LTM tenant, you may notice that the default value of the BigDB variable "alertd.lcdwarn" changed from "enable" to "disable." 

Environment

  • LTM
  • UCS
  • alertd.lcdwarn

Cause

The change in the default value of "alertd.lcdwarn" after UCS restore is expected behavior.

UCS restore temporarily sets certain db variable defaults, which are corrected after a full system reboot.

Additionally, on rSeries tenants, the alertd.lcdwarn variable is not functionally relevant, as the tenant does not interact with the physical LCD panel.

Answer/Recommended Actions

No action required; the observed behavior is expected and benign.
