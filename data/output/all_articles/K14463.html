Known Issue

A virtual server may not be marked unavailable (red) when the virtual server's default pool status is marked unavailable.

This issue occurs when both of the following conditions are met:

  • The pool status transitions to red.
  • The virtual server status is yellow, because it has exceeded either a connection limit or rate limit.

The virtual server's status will remain yellow until the connection limit or rate limit are no longer exceeded.

Impact

Connections may be sent to a virtual server with no available pool members. If route advertisement is enabled for the virtual address corresponding to the virtual server, a route could be advertised for virtual servers that are unable to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H423467 on the Diagnostics > Identified > Medium screen.
  • A virtual server's default pool status is red, but the virtual server's status is yellow.
