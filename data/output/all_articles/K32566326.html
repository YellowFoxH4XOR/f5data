Description

When using tmsh command, getting an error message such as :

[root@BIG-IP01:INOPERATIVE:In Sync] config # tmsh show sys mcp-state
exception: (Can't chmod temp dir (/var/system/tmp/tmsh), Read-only file system) (framework/TempDir.cpp, line 112), exiting...

Environment

  • BIG-IP VE
  • ESX Hypervisor
  • Device is in INOPERATIVE state

Cause

There is a virtualization communication issue between the ESX Hypervisor and the BIGIP VE. File System may corrupt causing TMOS files to be missing.

Recommended Actions

Impact of procedure: Rebooting the BIG-IP system in a standalone configuration will interrupt traffic processing. If the system is configured as part of a high-availability (HA) pair, the device may fail over. F5 recommends that you perform this procedure during a maintenance window.

  1. Schedule a file system check in the BIG-IP the next reboot of the system by creating a blank file
    # touch /forcefsck

    During the next reboot, the /forcefsck file causes the system to perform a file system check.
     
  2. Power off the BIG-IP device
    # poweroff
     
  3. Power on the BIG-IP from the Hypervisor.

Additional Information

None.
