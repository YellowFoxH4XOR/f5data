Known Issue

This is the result of a known issue. When performing a software upgrade of FirePass controller version 5.5.x to 6.0.2, some configuration data may not be converted from the format used in 5.5.x to the newer 6.x format. The symptoms of this issue include missing configuration data in text fields of the Administrative Console, or incorrect functioning of features that are new or changed in FirePass version 6.0.2.

For example, the upgrade process performs a conversion of Accessibility Scope patterns in version 5.5.x into Access Control Lists (ACLs) in version 6.x. This failure can result in an upgraded system with missing ACLs for master groups with Portal Access Web Application favorites. The Accessibility Scope patterns (5.5.x) and ACLs (6.x) are found on the Portal Access: Web Applications: Master Group Settings page.

F5 Networks Product Development tracked this issue as CR92078 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-552-11 has been issued for FirePass version 5.5.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

If you are running version 5.5.2 of FirePass software, you can work around this issue by installing Cumulative Hotifix HF-552-11 or later versions of the Cumulative Hotfix before upgrading to version 6.0.2 of FirePass software.

If you are running versions 5.5 or 5.5.1 of FirePass software, you can work around this issue by upgrading to version 5.5.2 of FirePass software, installing Cumulative Hotfix HF-552-11 or or later versions of the Cumulative Hotfix, and then upgrading to version 6.0.2 of FirePass software.
