F5 Platforms

The following F5 platforms are supported:

Note: For information about installing BIG-IP or 3-DNS version 4.6.3 or version 4.6.4 on an F5 platform, refer to the BIG-IP or 3-DNS release notes.

  • Switch Appliances: 1000 (D39), 2000 (D45), 2400 (D44), 5000 (D50), 5100 (D51)
  • BIG-IP 2U Server Appliances: 520 (D35), 540 (D35)

Third Party Platforms

Note: For information about installing BIG-IP version 4.6.3 or version 4.6.4 on a third-party platform, refer to the Third Party Platform Release Notes.

The following Dell platforms are supported:

  • Server Appliances: 2650, 2850
  • Blade Servers: 1655MC

The following HP platforms are supported:

Blade Servers: BL20p G2, BL30p
