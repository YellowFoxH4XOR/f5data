Issue

In BIG-IP versions prior to 9.4.0, the bigpipe platform command does not display the BIOS revision as part of the platform information.

Beginning in 9.4.0, the output from the bigpipe platform command includes the BIOS revision, as shown in the following example:

Note: In this example, the BIOS version is 08.00.10, REV. H.

# bigpipe platform
PLATFORM INFORMATION --
| Type: D63
| Chassis serial: bip062530s Level 200 part: 200-0146-02 REV A
| Switch board serial: PCA0049MCFCE part: PCA-0049-04 REV C
| Host board serial: TY4V64610514 part: MOB-0018-01 REV A
| Annunciator board serial: 123456 part: OEM-0029-02 REV A
| BIOS Rev: AMIBIOS(C)2003 American Megatrends, Inc.
BIOS Date: 12/02/04 11:04:20 Ver: 08.00.10 TYAN High-End Dual AMD Opteron
BIOS vF5-7 OBJ-0092-00 REV. H
| base MAC 00:01:D7:1E:91:40
|
| CPU 1 - temp 44degC fan speed 4500rpm
| CPU 2 - temp 44degC fan speed 4411rpm
|
| CHASSIS TEMPERATURE
| (101) 33degC
|
| CHASSIS FAN
| (101) active (102) active (103) active (104) active
| (105) active (106) active
|
| POWER SUPPLY
| (101) missing (102) missing

Note: For information about displaying BIOS version information for BIG-IP 9.0.0 though 9.4.0, refer to K7119: Displaying BIOS version information for BIG-IP switch appliances.

F5 Product Development tracked this request as CR67589 and CR69099, and it was fixed in BIG-IP 9.1.3 and 9.3.0. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, or Link Controller release notes.
