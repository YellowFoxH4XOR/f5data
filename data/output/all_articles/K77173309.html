Known Issue

The BIG-IP PEM does not send high-speed logging (HSL) information when operating in passive mode.

This issue occurs when all of the following conditions are met:

  • You have provisioned the BIG-IP PEM module.
  • Your configuration includes a virtual server with an associated HTTP and PEM classification profile. 
  • The BIG-IP PEM system receives network traffic on a Switch Port Analyzer (SPAN) port.
  • You have configured the BIG-IP system to send log information to a remote HSL server. 

Impact

Remote HSL servers do not receive logging information from the BIG-IP PEM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice the remote HSL server is not receiving log information from the BIG-IP PEM system.
  • You notice the remote HSL server receives log information when the BIG-IP PEM system is not configured to use a SPAN port.
