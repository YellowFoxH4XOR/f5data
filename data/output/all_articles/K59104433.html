Description

In the SSLO HA deployment, import the new certificate / key, and then configure the topology with the new certificate / key, when deploy, will get this error:

Deployment error
[OrchestratorConfigProcessor] Deployment failed for Error. [HAAwareICRDeployProcessor] Error: transaction failed: 01070277:3: The requested key (/Common/<key_name>) was not found.

Environment

  • SSLO HA
  • New certificate / key
  • Topology

Cause

BIG-IP will not sync the new certificate / key to the standby device automatically, but the SSLO will sync the topology to standby device when deploying.

Recommended Actions

After import the certificate / key, sync the configuration manually, then create the new topology with the new certificate / key.

  1. Import the certificate / key on the active device. For the details, please refer to K14620: Manage SSL certificates for BIG-IP systems using the Configuration utility or K15462: Managing SSL certificates for BIG-IP systems using tmsh.
  2. Sync the configuration from active device to standby device manually. For the details, please refer to K13920: Performing a ConfigSync using the Configuration utility or K14856: Performing a ConfigSync using tmsh.
  3. Configure the topolgy with new certificate / key.
