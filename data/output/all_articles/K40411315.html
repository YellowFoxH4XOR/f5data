Description

Device A, B and C belong to the same Sync-Only device group. When creating a new object on device A, devices B and C do not sync this configuration.

Devices B and C do not show a Changes Pending message acknowledging the recent changes.

This happens with objects created on partition /Common and on other partitions.

Environment

  • Sync-Only device group with auto-sync enabled

Cause

Sync-only device group does not sync objects created on the /Common partition.

Sync-only device group needs to be associated to a specific folder or partition, other than /Common.

Recommended Actions

Objects created on the /Common partition can only be synchronized between devices belonging to a Failover-Sync device group.

For objects created on other partitions to sync, associate the Sync-Only device group to a partition other than /Common. To do this:

  1. Navigate to System > Users
  2. Click the Partition List menu
  3. Click Create (or click a partition name to modify an existing partition)
  4. Enter the name for the partition
  5. In the Redundant Device Group Configuration section, clear the Inherit device group from root folder check box, and then select the Sync-Only device group from the Device Group menu
  6. Click Update
