Known Issue

The wom_verify_config command may not recognize iSession profiles created in non-default administrative partitions.

This issue occurs when all of the following conditions are met:

  • You create an iSession profile, either manually or using the f5.replication iApp, and associate it with a virtual server.
  • The iSession profile resides in a sub-partition of the /Common partition.

If you create an iSession profile in a partition such as /Common/example.com.app, the wom_verify_config command is unable to locate the iSession profile and reports the associated virtual server as not optimized. This issue can occur when using the f5.replication iApp to deploy configurations on the BIG-IP AAM system.

Impact

The wom_verify_config command reports the incorrect optimization status for virtual servers.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Output from the wom_verify_config command shows virtual servers are not optimized, even though they are configured with iSession profiles.
