Topic

A session ID is a string of data that identifies a user to a web server. The session ID string is often dynamic, and can be contained in a cookie or URL. If the BIG-IP ASM security policy is protecting a web application that uses dynamic session IDs in the URL, the BIG-IP ASM may not identify the web object name correctly, and the request will be blocked by the security policy.

For example:

http://www.f5.com/account.jsp;jsessionid=12345?username=admin&password=test

The example URL contains the following information:

  • The account.jsp;jsessionid=12345 string
  • The account.jsp string, which is defined in the BIG-IP ASM security policy as an object type
  • The jsessionid=12345 string, which is dynamic and represents the user's session ID information

When the BIG-IP ASMsystem receives a request, it evaluates the requested URL, reviews the object type and name, and determines whether the requested object type appears in the security policy. If the requested object is allowed in the security policy, the BIG-IP ASM system routes the request to the pool. If the BIG-IP ASM system is protecting a web application that uses dynamic session IDs in the URL, the session ID string may be mistaken as a part of the web object name, and the request will generate a nonexistent object violation.

Configuring the BIG-IP ASM system to identify the object type

You can configure the BIG-IP ASM system to parse the URL and distinguish the object type from the session ID. The BIG-IP ASM system distinguishes the object type by performing a length check on the originally requested URL so that it can properly identify the object type without the session ID attached, and properly evaluate the object type for compliance against the security policy. To configure the BIG-IP ASM system to identify the object type, perform the following procedure that applies to your version of BIG-IP:

Configuring the BIG-IP ASM system to identify the object type in version 9.x

  1. Identify the dynamic session ID format used by your web application, and create a regular expression that depicts its name and value.

    For example:

    http://www.f5.com/account.jsp;jsessionid=12345?username=admin&password=test

    In the example URL, account.jsp is the object type and jsessionid=12345 is the session ID.

    You can use the following regular expression to enable the BIG-IP ASM system to identify that the session ID string is not part of the object type:

    ;jsessionid=.{5}

  2. Log in to the Configuration utility.
  3. Click Application Security.
  4. Click Web Applications.
  5. Click the web application name that you want to configure.
  6. Select Custom Pattern from the Use Dynamic Session in URL drop-down menu.
  7. In the Value box, type the regular expression value that will represent the dynamic session ID.

    Note: For details on defining dynamic values with regular expressions, refer to the Supplemental Information section
  8. Click Update.

Configuring the BIG-IP ASM system to identify the object type in version 10.x

  1. Identify the dynamic session ID format used by your web application, and create a regular expression that depicts its name and value.

    For example:

    http://www.f5.com/account.jsp;jsessionid=12345?username=admin&password=test

    In the example URL, account.jsp is the object type and jsessionid=12345 is the session ID.

    You can use the following regular expression to enable the BIG-IP ASM to identify that the session ID string is not part of the object type:

    ;jsessionid=.{5}

  2. Log in to the Configuration utility.
  3. Click Application Security.
  4. Click Web Applications.
  5. Click the web application name that you want to configure.
  6. Click Policy.
  7. Select Advanced from the Configuration drop-down menu.
  8. Select Custom Pattern from the Use Dynamic Session in URL drop-down menu.
  9. In the Value box, type the regular expression value that will represent the dynamic session ID.

    Note: For information about defining dynamic values with regular expressions, refer to the PCRE - Perl Compatible Regular Expressions website.
  10. Click Save.
