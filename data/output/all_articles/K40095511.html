Description

Your device starts experiencing high CPU loads after you enable AFM Protocol Inspection on a number of virtual servers

Environment

  • BIG-IP AFM and LTM

Cause

AFM Protocol Inspection is CPU intensive and should be used sparingly

Recommended Actions

Review the security requirements for your applications and limit use of this feature to virtual servers that require this level of traffic scrutiny
