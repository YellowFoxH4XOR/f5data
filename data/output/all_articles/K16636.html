Known Issue

Multiple root certificates that use the same 'subject' and 'issuer' names, but different serial numbers, may cause the Traffic Management Microkernel (TMM) to produce a core file.

This issue occurs when the following conditions are met:

  • The Certificate Authority (CA) file contains multiple root certificates using the same 'subject' and 'issuer' names.
  • The Secure Sockets Layer (SSL) profile references the CA file.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM produces a core file and temporarily fails to process traffic.
  • The BIG-IP system generates a stack trace and panic string, in the /var/log/tmm file, that appears similar to the following example:

    panic: ../kern/page_alloc.c:109: Assertion "maximum pages" failed

Workaround

To work around this issue, you can avoid using two certificates with the same 'subject' and 'issuer' names in the CA file.
