K7204: SSL server certificate configuration required for failover pairs

Topic

To enable SSL encryption, each FirePass controller in a High Availability (HA) failover pair requires an SSL server certificate and the corresponding private key. Both FirePass controllers in a failover pair should use the same SSL server certificate and private key. This configuration is possible because only one FirePass controller is active at a time, and because the hostname of the FirePass controller used in the FirePass URL, which is the value in the certificate's Common Name (CN) field, is always the same regardless of which controller is active.

The SSL server certificate is not synchronized from the active controller to the standby controller. If you're using an SSL server certificate issued by an external certificate authority (CA), install the certificate on both the active and standby controllers. If you're using a self-signed SSL sertificate, generate a self-signed certificate on the active controller and then install the certificate on the standby controller using the procedure below.
 

Note: Only SSL server certificates are not synchronized in the failover pair. Client Root certificates are automatically synchronized.

  1. Logon to the Administrative Console of the active FirePass controller.
  2. Navigate to the Device Management: Security: Certificates page.
  3. In the Renew/Replace SSL Server Certificate section, click the Self-Sign link.
  4. Enter the appropriate information in each field, including an encryption password for the private key. Be sure to retain the password in a secure location for future use.
  5. Click the Generate Certificate button.

    The certificate information is transmitted, along with options to download and to save the certificate and the private key.

  6. Download the certificate and private key using the link provided.
  7. When prompted by your browser, save the file cert.zip to a secure location.
  8. On the SSL Server Certificate page, click the Save button to save the certificate and private key in the FirePass keystore.
  9. Click the Finalize tab.
  10. Click the Finalize Changes button to finalize the configuration.
  11. On the client system, extract the following two files from the cert.zip file you downloaded in Step 7.
    • newcert.crt
    • newcert.key
  12. Open both files using a text editor such as Notepad.
  13. Logon to the Administrative Console of the standby FirePass controller.
  14. Navigate to the Device Management: Security: Certificates page.
  15. In the Renew/Replace SSL Server Certificate section, click the Install link.
  16. Copy and paste the certificate and private key displayed in the text editor into the corresponding fields.
  17. Type the password for the private key in the Enter password here box, then click Go!.
  18. Click the Save button to save your changes.
  19. Click the Finalize tab.
  20. Click the Finalize Changes button to finalize the configuration.
     

Once the procedure is complete, configure an SSL web service on the active FirePass controller using the SSL server certificate you just installed.

Note: For more information about configuring web services, refer to the FirePass Controller Administrator Guide.
