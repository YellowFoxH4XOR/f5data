K000130578: VPN does not connect when using layered Virtual Server

Description

When trying to use a layered virtual server in with and http profile in front of an APM virtual server that includes a network access resource, connection to the VPN fails

 

Environment

  • Layered Virtual server with http profile
  • APM virtual server with network access

Cause

In order to properly handle VPN traffic, connectivity profile should be assigned to the layered Virtual Server with http profile. But it is not possible to assign the profile without APM policy.

Recommended Actions

Add next irule to the layered virtual server to disable the http profile when vpn traffic comes in

when HTTP_REQUEST {
set http_disable 0
     if { [HTTP::uri] starts_with "/isession" or [HTTP::uri] starts_with "/myvpn" } {
         set http_disable 1
     }
}


when HTTP_REQUEST_SEND {
     if { $http_disable != 0 } {
         HTTP::disable
     }
}
