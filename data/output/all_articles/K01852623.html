Description

After upgrade from version 15.1.4.1 to 16.1.3.1 configuration does not load and ltm logs show this error messages:

  • err httpd[12340]: 01180006:3: Software version not covered by service agreement service check date 20200513  version date 20210611.
  • err mcpd[7059]: 01070582:3: Monitor rules are not licensed: /Common/Monitor_https and /Common/icmp.

Environment

  • BIG-IP upgrade
  • License re-activation

Cause

This happens when you do not re-activate the license before the upgrade.

Recommended Actions

  1. If possible re-activate the license from the newer version
    or
  2. Rollback to the previous version and re-activate the license and now you can boot into the new version.

Additional Information

K7727: License activation may be required before a software upgrade for BIG-IP
