Description

Configuring an HTTPS monitor for a server that sends a NTLM authentication request. The credentials work to access the server through a browser, however the monitor fails to mark the pool member UP.

Environment

  • In-tmm monitor is enabled (bigd.tmm db key enabled)
  • Monitor configured for NTLM authentication

Cause

Bug ID 723194: In-TMM monitor supports only basic authentication

Recommended Actions

Disable in-tmm monitoring for this monitor to work:

tmsh modify sys db bigd.tmm value disable

Additional Information

If you can capture un-encrypted traffic for the monitor, you will be able to see a 401 Unauthorized NTLM authentication error and the BIG-IP resetting the connection.
