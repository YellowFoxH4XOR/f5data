Known Issue

If a user attempts to modify a macro for a BIG-IP APM visual policy editor, the BIG-IP APM system does not display the Apply Access Policy notification, as expected.

This issue occurs when all of the following conditions are met:

  • A BIG-IP APM policy visual policy editor has an associated macro.
  • A user edits the macro associated with the visual policy editor.

Impact

The BIG-IP APM system does not apply the policy changes to the visual policy editor macro.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H426044 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP APM system does not enforce the intended visual policy editor policy modifications.

Workaround

To work around this issue, you must manually apply the policy changes after editing a visual policy editor macro. To do so, perform the following procedure:

Impact of workaround: None

Applying a BIG-IP APM policy change

  1. Log in to the BIG-IP Configuration utility.
  2. Click Access Policy.
  3. Click Access Profiles.
  4. Click Access Profiles List.
  5. Select the check box to the left of the policy that was previously edited.
  6. Click Apply Access Policy.
