K000163388: LDAP Authentication Fails with “Bad Search Filter” After BIG-IP Upgrade

Type
Support Solution
Published
2026-09-23
Updated
2026-09-23
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163388

Description

BIG-IP APM LDAP authentication fails with a Bad search filter error with LDAP.

Example log message:

LDAP Module: Failed to make ldap_search in 'OU=Users,DC=example,DC=com' with filter 'sAMAccountName=john_smith' and scope '2'. Bad search filter

Environment

  • LDAP authentication or LDAP query configuration
  • Upgraded to 17.5.1.9

Cause

The LDAP search filter uses invalid syntax without enclosing parentheses. Releases with stricter LDAP syntax and RFC compliance validation reject the filter.

Answer/Recommended Actions

Update each filter to use valid LDAP filter syntax.

Change:

sAMAccountName=%{session.logon.last.username}

To:

(sAMAccountName=%{session.logon.last.username})

Save and apply the access policy configuration.
