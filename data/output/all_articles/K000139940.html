K000139940: Apply/Re-use the base registration key on another Appliance

Type
Support Solution
Published
2024-06-12
Updated
2024-06-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000139940

Description

Cannot re-use or apply the base registration key of an Appliance on another Appliance/Hardware

Environment

  • Appliance
  • Base Registration key
  • Reactivate License

Cause

Want to test the base registration key on another spare appliance to confirm if the issue is on the key or on the Appliance.

Recommended Actions


Base Registration keys are tied to the Appliance and cannot be moved to another Appliance unless through the RMA process.

Will see the error 51092 when attempting to re-activate the license on another device. 

Approach your F5 Account Manager or Sales Representative to request for an EVAL/Trial key to activate on the spare appliance to perform the test. 

Note: Remember to reactivate the Appliance with the assigned base registration key after the test and before the EVAL expires

Additional Information

None
