Known Issue

This is the result of a known issue. The management (mgmt) port for the following platforms shows a status of up when the management cable is not connected:

  • BIG-IP 1600 (C102)
  • BIG-IP 3600 (C103)
  • BIG-IP 6900 (D104)
  • BIG-IP 8900 (D106)

For example, if you connect an Ethernet cable to the mgmt port, the bigpipe interface command indicates the port is up. If you then remove the cable from the mgmt port, the bigpipe interface command output continues to indicate the interface status as up.

F5 Product Development tracked this issue as CR101418 and it was fixed in BIG-IP versions 9.4.8 and 10.1.0. For information about upgrading, refer to the BIG-IP LTM, GTM, Link Controller, ASM, PSM, WebAccelerator, or WOM release notes.
