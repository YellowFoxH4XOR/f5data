Description

If you need to maintain self IP connectivity on a VIPRION system or vCMP guest on a VIPRION hypervisor, you can use the Minimum Blades Up setting to intentionally trigger a failsafe condition, instead of forcing the device offline.

Environment

  • BIG IP Viprion or vCMP
  • High Availability
  • Multi Blade system

Cause

When using Force Offline for VIPRION platforms, connections to self IP addresses are terminated when Force Offline is enabled. ConfigSync and some HA connectivity may fail if not configured according to recommended practice. If the administrator is managing the device using self-IP, that may also terminate the connection when Force Offline is set.

Recommended Actions

To avoid using Force Offline, you should use the setting Minimum Blades Up option, as described below:

Setting Minimum Blades Up on VIPRION systems or vCMP guests

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Set Minimum Blades Up to a number that is greater than the total number of blades in the chassis. For example, in a VIPRION chassis with four blades, set Minimum Blades Up to 5, by typing the following command:

    modify /sys cluster default min-up-members 5
     
  3. Enable the Minimum Blades Up setting by typing the following command:

    modify /sys cluster default min-up-members-enabled yes

  4. To revert, perform steps 1 through 3, then for Minimum Blades Up in step 2, enter a value lower than the number of current available blades. The VIPRION system should change to Standby mode if you recently added it to a device group or Active if it is a standalone system.
