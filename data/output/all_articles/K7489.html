Known Issue

This is the result of a known issue. In rare conditions, virtual server connections using hardware compression can experience data corruption. This occurs when the deflate compression filter corrupts data in the compression stream.

F5 Product Development tracked this issue as CR76670 and it was fixed in versions 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
