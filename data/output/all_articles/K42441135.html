Description

When filtering by URLs, the client IP addresses that visited this url are missing.

When filtering client IP address, all URLs that this client IP visited are missing as well. 

Environment

  • BIG-IP LTM
  • AVR module is provisioned
  • HTTP analytics profile is attached to Virtual Servers

Cause

This is by design. AVR module only keep tracks of all URLs.

Recommended Actions

None
