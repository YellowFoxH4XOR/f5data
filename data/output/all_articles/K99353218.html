Description

ConfigSync fails between devices on Sync-Failover group.

Receiving unit shows Awaiting Initial Sync when listed with tmsh show /cm sync-status.

You can see similar, continuous logs on the receiving unit:

notice mcpd[<PID>]: 01070418:5: connection 0x63f11048 (user %cmi-mcpd-peer-<Peer IP address>) was closed with active requests

notice mcpd[<PID>]: 0107143c:5: Connection to CMI peer <Peer IP address> has been removed

When syncing from the GUI, the Standby unit does not reflect the expected sync logs for the Sync-Failover device-group right after an attempted sync.

When forcing a sync from tmsh, you can see logs similar to the following example, for the default device_trust_group, however, no logs reflect for the Sync-Failover device-group:

notice mcpd[<PID>]: 010714a0:5: Sync of device group /Common/device_trust_group to commit id 80915 6823227695593119286 /Common/Standby_Peer_Name 80915 from device /Common/Active_Peer_Name complete.

Environment

  • ConfigSync in HA pair
  • No logs registered after Sync

Cause

The BIG-IP might be discarding some frames when connecting to the CMI peer, and therefore not allowing Sync, if configured for Jumbo Frames (or a high MTU value) on the HA VLAN.

Recommended Actions

  1. Check if the MTU for the HA VLAN (or any VLAN used for ConfigSync), is configured for Jumbo Frames. On the GUI, navigate to Network > VLANs > VLAN List, click on the relevant HA VLAN and check if the configured MTU is 9198.
  2. Change the MTU of the HA VLAN to a lower value, for example 1500.
  3. Try the sync again.

Additional Information

Typical Ethernet v2 frames are limited to 1518 bytes (1522 bytes if Virtual Local Area Network (VLAN) tagging is used) resulting in a maximum transmission unit (MTU) of 1500 bytes. Jumbo frames refer to Ethernet frames that can reach 9000 bytes in size, thus allowing a payload (MTU) greater than 1500 bytes. Although many variations exist, most manufacturers have adopted 9000 bytes as the conventional jumbo frame size. Only gigabit Ethernet networking devices have the ability to support jumbo frames.
