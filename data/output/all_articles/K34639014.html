Description

Set the secure flag for Antifraud cookies (Websafe/Datasafe)

Environment

  • HTTPS Virtual Server
  • Antifraud Profile Assigned
Cause

Antifraud cookies are not marked as secure by default.

Recommended Actions

The following iRule is an example of how to secure all cookies on a Virtual Server:

when HTTP_RESPONSE_RELEASE {
    foreach x [HTTP::cookie names] {
            HTTP::cookie secure $x enable
    }
}
