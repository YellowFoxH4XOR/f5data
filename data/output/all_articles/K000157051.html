K000157051: F5 WAF Signature update configuration is missing after upgrade to version 17.1.3 or 17.5.1.3.

Type
Support Solution
Published
2025-10-17
Updated
2026-08-18
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000157051

Description

After upgrading F5 BIG-IP Advanced WAF appliances to 17.1.3 or 17.5.1.3, the ASM attack signatures are missing. The liveupdate logs contain the following logs:

var/log/tomcat/liveupdate.log_truncated
----------------------------------------------------------
2025-10-17 10:27:12 ERROR Transaction:52 -
java.lang.IndexOutOfBoundsException

 

 

Scheduled AWAF (Application Web Application Firewall) signature update configuration is removed. Attempts to reconfigure the automated signature update fail with an error, as shown in the attached error screenshot.

 

Environment

  • ASM attack signatures

Cause

Bug ID2152445

Recommended Actions

To restore the functionality of live updates, restart the tomcat service.

# bigstart restart tomcat

Note! The above action will not have a negative impact on traffic.

Additional Information

If the workaround doesn't solve the issue, we recommend upgrading software to the fixed version.
