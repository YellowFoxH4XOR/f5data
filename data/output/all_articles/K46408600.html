Description

"Redirect Trunk failed: SDK error Invalid port" messages logged on the VCMP host.

Environment

On platforms that include 40GbE interface ports, they can be configured as a single 40GbE port (bundled) or as four 10GbE SFP+ ports (unbundled). Anytime the bundle status is adjusted, the bcm56xxd process will restart. 

  • If the operation done on the active box, it will failover.
  • If the operation is done on a vcmp host, all active vmcp guests will failover.

Cause

    The bcm56xxd daemon controls the Broadcom 56xx switch chips which all interfaces use to process traffic. Therefore, all network traffic is interrupted while the bcm56xxd process restarts. This restart is by design, but there are warnings via the WebUI and command line:

    From the CLI: tmsh modify net interface 2.0 bundle disabled

    Are you sure? Y/N (changing the interface bundling will restart bcm56xxd and impact traffic)

    On the WebUI: Network > interface > interface Bundles

    Changing this setting will impact traffic after you click "Update"

    Recommended Actions

    Perform these bundle updates during a maintenance window and/or on the standby device.

    1. If this device is in a high availability (HA) pair, update the standby device then manually failover afterwards.
    2. If this is a VCMP host, set all the vcmp guests to standby. Then failover over these guests to perform the same updates on the other VCMP host.

    Additional Information

    You may also see the following log messages in /var/log/ltm:

    • Activating bundled interface
    • Scheduling a delayed bcm56xxd daemon restart in 5 sec
    • Restarting bcm56xxd to setup new bundling configuration
