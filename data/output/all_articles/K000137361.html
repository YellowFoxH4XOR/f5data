K000137361: Your BIG-IQ license does not permit device discovery and management

Type
Support Solution
Published
2023-10-25
Updated
2023-10-25
Source
https://my.f5.com/manage/s/article/K000137361

Description

Attempting to add a remote BIG-IP to the list of managed devices on BIG-IQ fails.

  • The BIG-IQ reports "Your BIG-IQ license does not permit device discovery and management"

Environment

The BIG-IQ successfully manages licenses for these same BIG-IP Virtual Edition (VE).

Cause

The BIG-IQ is configured as a License Manager which only allows deploying or revoking licenses, not managing devices.

Recommended Actions

Update the device license on the BIG-IQ to Central Management so can manage remote devices.

  1. Check the BIG-IQ's license
    • System > Licensing > Licensed Module
    • If it reads License Manager and this BIG-IQ needs to manage remote BIG-IP VEs, then this license needs to be corrected to support Central Management..
  2. To update the license, please contact a customer success manager via customersuccess@f5.com.
