Issue

If you see errors similar to the following in the /var/log/bigip file, the error indicates that the SSL persistence is configured on an HTTP pool.
Jul 3 15:50:13 my_bigip kernel: ssl: get_ssl_id: invalid packet 
from 205.229.151.150:24850 to 127.0.0.16:80

Jul 3 15:50:13 common09091a06y kernel: ssl: get_server_id: invalid packet 
from 205.229.151.150:24850 to 127.0.0.16:80

For example, your SSL configuration may look similar to the following:

   pool secure {
   lb_method observed_member
   persist_mode ssl
   member 10.78.5.247:http ratio 1 priority 1
   member 10.78.5.244:http ratio 1 priority 1
}

To resolve this issue and eliminate the error, you can do one of the following:

  • Disable SSL persistence
  • Switch to insert cookie mode

Disabling SSL persistence

The following procedures describe how to disable SSL persistence from the Configuration utility and from the command line.

From the Configuration utility

To disable SSL persistence from the Configuration utility, perform the following steps:

  1. Click Pools.

  2. Click the specific Pool with the configuration issue. (In the previous example, that would be the Pool secure.)

  3. Click the Persistence tab.

  4. Select None.

From the command line

To disable SSL persistence from the command line, type:

bigpipe pool secure modify { persist_mode none }

Switching to cookie insert mode

The following procedures describe how to switch to insert cookie mode from the Configuration utility and from the command line.

From the Configuration utility

To switch to insert cookie mode from the Configuration utility, perform the following steps:

  1. Click Pools.

  2. Click the specific Pool with the configuration issue. (In the previous example, that would be the Pool secure.)

  3. Click the Persistence tab.

  4. Select Cookie insert.

From the command line

To switch to insert cookie mode from the command line, type:

bigpipe pool secure modify { persist_mode cookie cookie_mode insert }

For additional information about persistence, refer to the BIG-IP Reference Guide.
