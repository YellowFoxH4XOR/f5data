K49995710: You added RADIUS type Auth Provider in BIG-IQ GUI, but you are unable to set non-default RADIUS authentication time out

Type
Support Solution
Published
2022-11-15
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K49995710

Description

  • You have added radius type Auth Provider to Big-IQ GUI, but you are unable to set non-default Radius authentication time out
  • There is no option to set authentication time out in GUI
  • When you are trying to set authentication time out in CLI via TMSH context you get an error: 
#tmsh modify auth radius-server all timeout 40
Update not applied, no configuration items found

#tmsh list auth radius-server
(no output)

Environment

  • BIG-IQ 
  • Radius type Auth Provider configured in BIG-IQ GUI
  • Setting non-default Radius authentication time out

Cause

You cannot use TMSH to confiugre RADIUS authentication for GUI. 
TMSH radius configuration is for CLI authentication purpose only.

You also cannot configure RADIUS authentication timeout for GUI using GUI because there is no option for that.
However you can reconfigure Radius settings for GUI using API call.

Recommended Actions

To reconfigure Radius time out for GUI please do the following:

Configure desired value of timeout by typing a command:

# restcurl -X PATCH /cm/system/authn/providers/radius/<item ID> -d '{"timeoutMillis":"<timeout value>"}'

For example:

# restcurl -X PATCH /cm/system/authn/providers/radius/4ad795c2-6e8c-47fb-b5a3-9070c769bff5 -d '{"timeoutMillis":"20000"}'
