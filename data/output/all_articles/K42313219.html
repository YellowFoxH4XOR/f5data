Topic

You should consider using this procedure under the following condition:

  • You want to configure a post-login advisory banner for the BIG-IP system.

Description

You can configure the BIG-IP system to display a post-login advisory banner in the Configuration utility. When configured, the advisory banner is displayed on both the top and bottom of the Configuration utility page and can be used for important administrative messages.

For example, you may want to configure advisory banners to clearly identify BIG-IP systems that you manage in the following environments:

  • A test environment where you test your BIG-IP upgrade procedures
  • A QA environment where you simulate production traffic against the upgraded system
  • A production environment where the systems process production traffic

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrator access to the TMOS Shell (tmsh)
  • You have administrator access to the Configuration utility.

Procedures

Configure an advisory banner for the BIG-IP system using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to System > Preferences.
  3. For Security Settings, select Advanced.
  4. Select Show Advisory Banner.
  5. For Advisory Color, select a color.
  6. For Advisory Text, enter the text to show in the advisory banner.
  7. Select Update.

Configure an advisory banner for the BIG-IP system using the TMOS shell

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS shell (tmsh).
  2. To enable the advisory banner, enter the following command:

    modify /sys db ui.advisory.enabled value true

  3. To set a color for the advisory banner, use the following syntax:

    modify /sys db ui.advisory.color value <blue/green/orange/red/yellow>

    For example, to set the advisory banner to orange, enter the following command:

    modify /sys db ui.advisory.color value orange
     
  4. To configure the advisory banner text, use the following syntax:

    modify /sys db ui.advisory.text value <'advisory banner text'>

    For example, to configure the advisory banner text to read, QA ENVIRONMENT, enter the following command:

    modify /sys db ui.advisory.text value 'QA ENVIRONMENT'

  5. To save the configuration, enter the following command:

    save /sys config
