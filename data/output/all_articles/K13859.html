Topic

You should consider using this procedure under the following condition:

  • You want to disable BIG-IP Client Side Performance Monitoring (CSPM) injection for specific HTTP transactions.

Description

The CSPM feature injects JavaScript into HTTP responses to allow the BIG-IP Analytics module to track the Page Load Time metric. This feature is supported by only certain browsers, but by default the JavaScript is injected without regard to whether the client browser type supports the feature. Using iRules, you can specify the conditions under which CSPM injection should be disabled.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have experience writing and designing iRules.
  • You have experience viewing raw HTTP request data.

Procedures

Disabling CSPM injection with iRules

You can disable CSPM injection with the AVR::disable_cspm_injection iRules command. For example, to disable CSPM injection based on a user-agent value, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > Create.
  3. Type a name for the iRule.
  4. In the iRule definition box, enter a rule similar to the following example:

    when AVR_CSPM_INJECTION {
    if { [HTTP::header "User-Agent"] starts_with "my-user-agent" } {
    AVR::disable_cspm_injection             
        }
    }

    In the previous example, note that my-user-agent represents the specific user-agent value you want to match.

    Note: You must determine the specific User-Agent values that you want to match on by inspecting the HTTP sessions in your specific environment. This can be done with third-party tools such as tcpdump, HTTPwatch, Fiddler, etc.  For more details on inspecting HTTP requests, refer to the documentation for your chosen utility.

  5. Click Finished.
  6. Navigate to Local Traffic > Virtual Servers.
  7. In the Virtual Servers List, locate the affected virtual server and click the Edit link under the Resources column.
  8. For iRules, click Manage.
  9. In the Available column, locate the iRule you created in step 3, and click it.
  10. Assign the iRule to the virtual server by clicking <<.
  11. Click Finish.

The previous procedure demonstrates an example of using AVR::disable_cspm_injection based on the User-Agent string in an HTTP Request. However, this command may be used in the HTTP_RESPONSE event as well. You may also want to disable CSPM injection based on other factors beside the User-Agent string. The following example code structure demonstrates this logic:

when HTTP_RESPONSE {
        if { <condition> } {
            AVR::disable_cspm_injection
            }
    }

In the previous example, note that <condition> represents a condition you determine.
