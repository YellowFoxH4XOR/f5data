Known Issue

The BIG-IP ASM system may fail to import Simple Object Access Protocol (SOAP) methods from a WSDL file.

This issue occurs when the following condition is met:

  • The SOAP method name in the WSDL file contains a non-alphanumeric character.

Impact

The system does not import SOAP methods with non-alphanumeric characters to the BIG-IP ASM XML profile.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you upload a WSDL file to the XML profile, the system does not import SOAP methods with non-alphanumeric characters.
