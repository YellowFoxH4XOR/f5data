Description
 

Monitors are using the management interface to test the pool members when they should be using the tmm interfaces.

The networks routes exist in the routing table.

Environment
 

  • Monitoring pool members
  • Management interface
  • Self IP address


Cause
 

There is an existing self IP that has a network mask, like /30, and you are using the broadcast IP from this range as a gateway in your BIG-IP. This is why there are routes in the routing table are not being used as expected.
 

Recommended Actions


To correct this issue you can try the following options:

  1. Correct the IP address that you are using as a gateway in your BIG-IP.
  2. Change the network mask on your self IP to another range, so that the current gateway's IP address is not a reserved IP like broadcast.
