K5384: 3-DNS will not create a new wide IP or allow a pool to be added to a wide IP if Global Availability load balancing is specified

Known Issue

This is the result of a known issue. If you use the Configuration utility to create a new wide IP, or add a pool to an existing wide IP, and you select Global Availability for the load balancing mode, the virtual servers in the pool are not added to the configuration. As a result, the wide IP cannot load balance to those virtual servers.

F5 Networks Product Development tracked this issue as CR43540 and CR44654.

Workaround

To work around this issue, create the wide IP at the command line or create the wide IP with the Configuration utility by initially specifying a load balancing mode other than Global Availability. You will then want to edit the wide IP to change the load balancing mode to Global Availability.
