Topic

FirePass provides two ways to obtain CPU utilization information: a graphical display from the FirePass Administrative Console, and data collected through the Simple Network Management Protocol (SNMP). An SNMP-based network monitoring tool obtains data by polling FirePass SNMP objects which contain CPU utilization data. Each SNMP object has a unique Object ID (OID). The network monitoring tool is configured with the OIDs of the objects so that it can poll for the objects data.

You can view FirePass CPU utilization on the CPU Usage graph by performing the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Monitoring.
  4. Click System Load.

The following parameters are listed in the legend of the CPU Usage graph:

  • User
  • System
  • Nice (FirePass version 5.5.1 and earlier)
  • Idle

The data for the graph are derived from values in kernel data structures, then graphed in 20-second increments.

You may obtain similar information using SNMP. The objects for CPU utilization are the standard objects found in the Net-SNMP MIB (formerly known as the UC Davis UCD-SNMP MIB). Two kinds of objects are available: raw and percentage.

Raw measures CPU usage through an integer counter. The integer counter is sampled periodically, and the difference in the counter between the sample times is proportional to the CPU usage during that time period. The percentage of CPU utilized is the difference in the counter divided by the total CPU usage during the time period and multiplied by 100.

Percentage provides a direct integer quantity of CPU utilization. It is calculated using the same method as raw measures.

Note: Percentage objects are being phased out from the Net-SNMP-MIB and may not be available in future releases of FirePass software.
