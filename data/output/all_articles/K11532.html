Known Issue

When Mac OS X users are connected to Network Access, they may not not be able to resolve DNS queries sporadically. Programs that use the DNS settings in their system configuration will be unable to successfully query names, but if the user performs a DNS query using Dig or NSLookup, the query will work. This issue may occur at any time after connecting to Network Access.

F5 Product Development tracked this issue as CR132557 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes.

This issue was fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
