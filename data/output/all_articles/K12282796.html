Description

Unable to perform a configsync. Configsync fails with the following error in /var/log/ltm file: 
01b9000f:3: This platform doesn't support DoS hardware capability, which is needed to disable this sys db variable.

Environment

  • Sync group with different device types that do and do not support DoS hardware compatibility.
    Such as:
    • Device group with BIG-IP VE and Appliance
    • Device group with BIG-IP Appliance that is DoS hardware compatible (BIG-IP 2000) and is not DoS hardware compatible (BIG-IP ix600)
       
  • The dos.forceswdos DB key on the device that supports DoS hardware compatability:
sys db dos.forceswdos {
    default-value "false"
    scf-config "true"
    value "false"
    value-range "false true"
}
 
  • The dos.forceswdos DB key on the device that does not support DoS hardware compatability:
sys db dos.forceswdos {
    default-value "false"
    scf-config "true"
    value "true"  
    value-range "false true"
}
 
  • Migrating using a USC file with the configuration from a DOS HW compatible device to a non-DOS HW compatible device for example ix600 platforms.
  • Migrating using a Device Group Synchronization from a DOS HW compatible device to a new BIG IP No compatible DoS Hardware Platform.

Cause

The BIG-IP system generates this message on the destination device if the DoS Hardware Compatibility feature can not be enabled (the dos.forceswdos DB Key set to False). This happens on platforms that are license-limited to prevent this. Such as Rate-limited/license-restricted i-series appliances, namely the ix600 platforms.

Recommended Actions

To work around this issue you can disable DoS hardware compatibility on the device that supports DoS hardware compatibility:

  1. Connect to the Source Device (that supports DoS hardware compatibility. (The device you want to sync the configuration from)
  2. Log in to the command line.
  3. Set the dos.forceswdos DB Key to true
    tmsh modify sys db dos.forceswdos value true
  4. Synchronize the configuration or create the UCS file to perform your migration.
