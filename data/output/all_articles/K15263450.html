Description

The directory /var/named/config/namedb is filling up with query.log files.

Environment

  • BIG-IP GTM
  • BIG-IP DNS
  • Logging

Cause


Query logging was enabled at the BIND level via Zone Runner or by manually editing the named.conf file.

logging {
 channel logfile {
 syslog daemon;
 severity error;
 print-category yes;
 print-severity yes;
 print-time yes;
 };
 channel named_query {      
 file "query.log" versions 10 size 200m;
 severity info;
 print-time yes;
 };
 category default {

Recommended Actions

  • You can disable BIND query logging with the command rndc querylog but note it will become enabled on a reboot or restart of the BIND service.
    # rndc querylog off
  • Alternatively, you can remove the Channel named_query section from the named.conf configuration file.
