Known Issue

This is the result of a known issue. The Configuration utility does not automatically delete the temporary session files it uses to manage each user's session while they are logged in. As a result, over time the /shared/tmp directory will be littered with unnecessary files.

When a user successfully logs in to the Configuration utility, it creates two temporary session files in the /shared/tmp directory that appear similar to the following files:

/shared/tmp/sess_4l8ee0nmk7rcduepbr2jeev5d0
/shared/tmp/sess_mrj8bc6tgrjak3pci9pvs6ngl4

These files should be deleted after they age past 24 hours.

F5 Product Development tracked this issue as ID 224913 (formerly CR 138068), and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

In addition, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1755.1-HF1, which has been issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

You can work around this issue by manually deleting session files that are more than 24 hours old. To do so, type the following commands at the BIG-IP command line:

Note: If BIG-IP has ASM enabled, you should only delete session files that are more than 24 hours old. If ASM is not enabled, you can safely delete the session files any time.

  • To display all of the session files in the /shared/tmp/ directory that are more than 24 hours old, type the following command:

    find /shared/tmp -type f -name "sess_*" -mtime +1 -print
  • To display and delete all of the session files in the /shared/tmp/ directory that are more than 24 hours old, type the following command:

    find /shared/tmp -type f -name "sess_*" -mtime +1 -print -delete
