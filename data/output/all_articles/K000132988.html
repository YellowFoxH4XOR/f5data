K000132988: Quay.io image pull secret location for Aspen Mesh 1.14.x

Type
Support Solution
Published
2023-03-15
Updated
2023-07-18
Applies to
  • Aspen Mesh: 1.14
Source
https://my.f5.com/manage/s/article/K000132988

Description

Kubernetes needs a secret resource to pull the Aspen Mesh images from the quay.io public image registry. The secret resource is included in the Aspen Mesh installation files.

➜  aspenmesh-carrier-grade-1.14.6-am1 ls -ltr manifests/charts/istio-control/istio-discovery/templates/ | grep pull
-rw-r--r-- 1 root root   501 Feb 21 18:12 pullsecret.yaml
➜  aspenmesh-carrier-grade-1.14.6-am1

apiVersion: v1
kind: Secret
metadata:
  name: aspen-mesh-pull-secret
  namespace: {{ .Release.Namespace }}
data:
  # aspenmesh+carrier_grade_release_pull
  .dockerconfigjson: <omitted>
type: kubernetes.io/dockerconfigjson
 

Environment

  • Aspen Mesh: 1.14.x

Cause

In version 1.11.8.x and earlier the secret resource path was manifests/charts/base/templates/pullsecret.yaml
With the release of 1.14.x the path has changed to manifests/charts/istio-control/istio-discovery/templates/pullsecret.yaml
 

Recommended Actions

Edit the script from:

$TOOLS_DIR/../manifests/charts/base/templates/pullsecret.yaml

To:

$TOOLS_DIR/../manifests/charts/istio-control/istio-discovery/templates/pullsecret.yaml


Additional Information

This change has a special impact on customers storing AM images in private registries and automated scripts.
The PD team doesn't have any plans to change the installation charts in the near future.
