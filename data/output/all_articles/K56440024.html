Description

Cannot sync.  Getting Sync error: 01070920:3: Application error for confpp: SysExe: fork error

At the time of ConfigSync: 

Log:   tailf /var/log/ltm shows log messages of:

MCPD query response exceeding 30 seconds.
MCPD query response exceeding 60 seconds.
Application error for confpp: SysExe: fork error
Remote transaction for device group /Common/SYNC-FAILOVER to commit id 8884 6972602581530736086 /Common/xxxxxxxx 0 failed with error 010709

Environment

  • BIG-IP version 12.x
  • Using GUI to sync: GUI:  Device management > Overview > Sync   or   Click "Changes Pending" top left 

Cause

Lack of resource on VE

Recommended Actions

Either of the following have been known to alleviate the error and allow ConfigSync to work:

  • Increase Management Resource Provisioning:   System > Resource Provisioning > Management:   Change to Medium or Large
  • Increase VE guest RAM on the Hypervisor to 8 GB or more
