K53936462: BIG-IQ login will timeout in a ELB AWS environment

Type
Support Solution
Published
2021-03-07
Updated
2023-02-21
Applies to
  • Public Cloud
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X, 6.X.X, 8.X.X
  • Amazon Web Services
Source
https://my.f5.com/manage/s/article/K53936462

Description

You are accessing the BIG-IQ via a DNS lookup that resolves between AWS Elastic Load Balancing (ELB) devices. There are at least 2 ELB devices being used.

After login into the BIG-IQ, the login session will timeout after 1 to 10 minutes randomly.

This issue happens during GUI access to the BIG-IQ.
 

Environment
  • BIG-IQ Cloud
  • Accessing the BIG-IQ GUI and it will timout after 1 to 10 minutes randomly.
  • Accessing BIG-IQ via a DNS lookup that resolves to a AWS Elastic Load Balancing (ELB)
  • At least 2 ELB devices
  • DNS will resolve between the 2 ELB

Cause

BIG-IQ uses a token authentication to authenticate users based on source IP. You can read further on BIG-IQ system authentication token here K04452074.

When accessing the BIG-IQ via a DNS lookup in the AWS ELB environment, it will resolve to any of the ELB IP addresses and BIG-IQ will create an authentication token base on this IP address. After sometime navigating the BIG-IQ, a new DNS request will resolve to the other ELB and source IP on the BIG-IQ will change. This will invalidate the current authentication token because it now sees another source IP address and eventually will timeout.
 

Recommended Actions

When accessing the BIG-IQ GUI ensure that the source IP address (in this case the ELB) does not change.

The options to resolve this is done externally from the BIG-IQ system itself. Here are some options to consider:

  1. DNS sticky session which will maintain using a specific ELB when accessing the BIG-IQ.
  2. Communicate directly to a ELB without using DNS resolution.

Additional Information

REST API logs from the BIG-IQ will show a 401 Unauthorized error message stating the authentication token is not valid for the new IP address. This error message can be seen in the /var/log/restjavad.0.log file.
