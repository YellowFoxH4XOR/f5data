Description

This article provides the procedure for updating the iRules in virtual server configured through iApps Application Services without disabling the iApps' Strict Updates.

Environment

  • BIG-IP
  • iApps
  • iRules

Cause

None

Recommended Actions

Impact of procedure: Running this procedure should not have a negative impact on the traffic and follow the below procedure to configure iRules under iApps.
  1. In the BIG-IP Configuration Utility/GUI, Select iApps template in iApps  ››  Application Services:Applications and click on the desired Application Service.
  2. Go to the Reconfigure tab.
  3. Select Template Selection : Advanced.
  4. Under Template Options : Which configuration mode do you want to use? Select - Advanced - Configure advanced options.
  5. Now Scroll down the webpage and you will get an option to configure Vlans, VS properties, Server Offload, Application Health, Local Traffic Policies, iRules, Statistics and Logging.
  6. Under iRules section, in the field - Do you want to add any custom iRules to this configuration? -> Select already configured iRule from  /Common partition or from the list and click the Add << button to move it to the selected list.
  7. Click the Finished button.
     

Additional Information
iRule configured to Virtual server under local traffic works in a similar way, but some clients prefer to maintain uniformity.

Strict Updates

When you are working in the Application Services properties screen, and select the Advanced view, the Strict Updates field is shown. The Strict Updates option is enabled by default and protects against accidental changes to an iApp's configuration, such as virtual servers, pool, and iRules. F5 recommends that you leave the Strict Updates setting enabled and make any changes to the iApp's configuration by modifying the template.
