Known Issue

The mcpd process may fail to release file descriptors when email notifications are enabled in an Analytics profile.

This issue occurs when all of the following conditions are met:

  • The system is licensed and provisioned for the Analytics module.
  • Email notifications are enabled in an Analytics profile.
  • An email notification is sent.

The mcpd process will consume a file descriptor for each Analytics email notification sent. Once all available file descriptors have been exhausted, the mcpd process will stop responding and may core.

Impact

The mcpd process will not process configuration updates, and mcpd may eventually core and restart causing a temporarily service interruption.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The number of open file descriptors in use by the mcpd process increases over time. The output of the following command will increase each time an Analytics email notification is sent:

    lsof -p `pidof mcpd` | wc -l
  • The mcpd process CPU utilization increases over time, and eventually consumes more than 90 percent CPU utilization.
  • When available file descriptors have been exhausted, you are unable to access the BIG-IP Configuration utility.
  • When available file descriptors have been exhausted, you are unable to access the Traffic Management Shell (tmsh) utility and/or tmsh commands may fail to complete.
  • The mcpd process may core and restart causing a temporarily service interruption.

Workaround

To work around this issue, you can disable email notifications in the Analytics profile. To do so, perform the following procedure:

Impact of workaround: Analytics alert email notifications will not be sent.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. Click Analytics.
  5. Click on the affected Analytics profile.
  6. Clear the E-mail notification type check box.
  7. Click Update.

Recovery

To recover from this issue, you must restart the mcpd process. To do so, perform the following procedure:

Impact of workaround: The BIG-IP host becomes temporarily inoperative, all BIG-IP processes restart, and all connections are lost. As a result, F5 recommends that you perform the following procedure during a maintenance window.

  1. Log in to the BIG-IP command line.
  2. Restart the mcpd process by typing the following command:

    bigstart restart mcpd
