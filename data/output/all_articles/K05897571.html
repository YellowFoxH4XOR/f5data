Description

This article is provide guidance on how to connect to Microsoft Remote Desktop [RDP] resources from an Apple Mac OSX machines, through BIG-IP APM.

Environment

  • You're using BIG-IP APM to authenticate users and to control access to the RDP resources
  • You're using the "Native RDP" objects, to make the BIG-IP APM the "RD Gateway"
  • You're using Apple Mac OSX client machines.
Cause

Since BigIP v13.0, APM can play the roles of "RD Gateway" or "RD Gateway and RDWeb" (please see the resource below to get to know more about this technology).
To connect to any RD Host through BIG-IP APM, a RD Client software is needed, on all client machines.

Recommended Actions

Please download, deploy and install RDP Client software, such as:
  • Microsoft Remote Desktop 10
Additional Information

Microsoft Docs: Remote Desktop Services architecture
