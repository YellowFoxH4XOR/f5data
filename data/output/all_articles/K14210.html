Issue

This article applies to BIG-IP 11.3.0 through 11.5.1, and 11.6.0 through 11.6.0 HF4. For information about other versions, refer to the following article:

  • K95553400: vCMP guests with more than 4 GB and less than 8 GB RAM can now provision more than two modules

Old Behavior

In versions prior to BIG-IP 11.3.0, you are able to provision three or more modules on a Virtual Clustered Multiprocessing (vCMP) guest with less than 6.5 GB of memory.

New Behavior

In BIG-IP 11.3.0 through 11.5.1, and 11.6.0 through 11.6.0 HF4, vCMP guests with less than 6.5 GB of memory support provisioning for a maximum of two software modules.

This change is due to the increased memory footprint of the BIG-IP software beginning in BIG-IP 11.3.0, and the resources available on the vCMP guests. This constraint applies to any combination of three or more modules. In BIG-IP 11.3.0, F5 does not support the following provisioning examples:

  • All of the items in the Triple Product Combos and Quad Product Combos sections of the BIG-IP software and platform support matrix.
  • The addition of the BIG-IP Analytics module to any two module combination, such as LTM/ASM or LTM/GTM.
  • The BIG-IP Edge Gateway product, which consists of BIG-IP APM, WebAccelerator, and WOM.

Note: With the introduction of the Good-Better-Best licensing options, the vCMP guest provisioning limitations do not change. While more than two modules may be licensed on the device, they cannot be provisioned. For additional information on F5’s new licensing options, refer to: http://www.f5.com/pdf/licensing/good-better-best-licensing-overview.pdf.

For information about the amount of memory allocated to each vCMP guest for vCMP-capable platforms, refer to K14218: vCMP guest memory/CPU core allocation matrix.

Impact

Installation failure

If a vCMP guest with less than 6.5 GB of memory already has three or more modules provisioned, the installation process fails if you attempt to upgrade to an affected version. For example, if you attempt to upgrade to 11.3.0 you notice the following symptoms when the installation process fails:

  • The BIG-IP Configuration utility System > Software Management > Installed Images page displays an error message that appears similar to the following example:

    failed (Physical memory (XXXX MiB) insufficient for desired modules. See Solution #13988.)

  • The tmsh show sys software command displays a message that appears similar to the following example:

    ----------------------------------------------------------------------------------------------
    Sys::Software Status
    Volume Product Version Build Active Status
    ----------------------------------------------------------------------------------------------
    MD1.2 BIG-IP 11.3.0 2702.0.13 no failed (Physical memory insufficient for desired modules. See Solution #13988.)

  • Error messages in the /var/log/liveinstall.log file appear similar to the following example:

    info: WARNING: There were one or more errors detected during installation.
    info: Check the error messages and take the proper actions if needed.
    info: ERROR: UCS installation failed.
    info: Operation aborted.

Recommended Actions

To install BIG-IP 11.3.0 through 11.5.1, or 11.6.0 through 11.6.0 HF4 to a vCMP guest with less than 6.5 GB of memory, you must ensure that the device is provisioned with two or fewer modules. If three or more modules are provisioned, you must remove provisioning from some modules.

Removing provisioning from a module

  1. Log in to the Configuration utility.
  2. Click System.
  3. Locate the Resource Provisioning menu.
  4. In the Resource Provisioning (Licensed Modules) list, remove provisioning from an active module by selecting None (Disabled) in the menu next to that module.
  5. Click Update.
  6. Click OK.

When the BIG-IP system has the correct number of modules, you can proceed with any upgrade operations. If an upgrade has previously failed with the error messages detailed earlier in this article, you can proceed to reinstall the desired version from the System > Software Management > Image List screen.
