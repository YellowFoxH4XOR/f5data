Description

When using the revoke /sys license add-on-keys command, the entire license is revoked.

Environment

  • License
  • BIG-IP VE

Cause

The add-on-keys option should not be available with revoke /sys license, this option is only applicable to install /sys license.

Recommended Actions

Do not use revoke /sys license with the add-on-keys option.

Additional Information

Addon keys are tied to the base registration key once used, and may not be revoked individually by using the add-on-keys option.
