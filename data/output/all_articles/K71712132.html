Security Advisory Description

Stored Cross Site Scripting vulnerability in the undisclosed page of a BIG-IQ system. The attack can be stored by users granted the Device Manager and Administrator roles. (CVE-2019-6653)

Impact

The attacker can exploit this vulnerability to access the sensitive data (for example, account credentials) of the BIG-IQ systems.

Security Advisory Status

F5 Product Development has assigned ID 746458 (BIG-IQ) to this vulnerability.
