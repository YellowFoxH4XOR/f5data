K000134604: Configure NTLM on NGINX Plus

Source

Description

  • Load balancing Microsoft Exchange Servers

Environment

  • NGINX Plus
  • Windows New Technology LAN Manager (NTLM)
  • Microsoft Exchange Servers

Cause

None

Recommended Actions

Please refer to the example below for a complete configuration:

http {
    upstream exchange {
        zone exchange 64k;
        ntlm;
        server exchange1.example.com;
        server exchange2.example.com;
    }
    
    server {
        listen              443 ssl;
        ssl_certificate     /etc/nginx/ssl/company.com.crt;
        ssl_certificate_key /etc/nginx/ssl/company.com.key;
        ssl_protocols       TLSv1 TLSv1.1 TLSv1.2;
       
        location / {
            proxy_pass         https://exchange;
            proxy_http_version 1.1;
            proxy_set_header   Connection "";
        }
    }
}
