Description

  • How to create an OpenAPI security policy using a Swagger file

Environment

  • Advanced WAF provisioned

Cause
None.

Recommended Actions
1.  On the Main tab, click Security > Application Security > Security Policies > Policies List.
2.  The Policies List screen opens.
3.  Click Create New Policy.
4.  You only see this button when no policy is selected.
5.  Enter a unique policy name.
6.  Make sure the Policy Type is Security.
7.  For the Policy Template select API Security.
8.  The OpenAPI (Swagger) File field is now visible.
9.  Click Upload File to navigate to your swagger file and upload it.
10. Click Save to create the OpenAPI Security policy.

Additional Information

The API security template is only available when licensed for Advanced WAF.
