K000137907: Commands to see Ciphers and Protocols used in a particular STRING

Type
Support Solution
Published
2023-12-20
Updated
2023-12-20
Source
https://my.f5.com/manage/s/article/K000137907

Description

You want to validate what CIPHERS and PROTOCOLS are being used in a particular STRING
 

Environment

  • BIG-IP
  • Client or Server SSL profiles 
  • Virtual Server

Cause

Informational. 
 

Recommended Actions

1. The following commands list the cipher suites (e.g. DEFAULT) configured in the SSL profile (i.e. clientSSL or serverSSL)
tmm --clientciphers DEFAULT
tmm --serverciphers DEFAULT                  
tmm --clientciphers ALL:EXPORT:SSLv2:SSLv3:NULL

2. The following commands list the cipher suites that use the protocols (i.e. TLS v1.2, or TLS v1.3)
tmsh run util clientssl-ciphers TLSv1_3
tmsh run util clientssl-ciphers TLSv1_2

3. The output is the list of the ciphers that use those protocols.    
    ID  SUITE                                BITS  PROT    CIPHER            MAC     KEYX
 0:  4865  TLS13-AES128-GCM-SHA256           128  TLS1.3  AES-GCM            NULL      *         
 1:  4866  TLS13-AES256-GCM-SHA384           256  TLS1.3  AES-GCM            NULL      *         
 2:  4867  TLS13-CHACHA20-POLY1305-SHA256    256  TLS1.3  CHACHA20-POLY1305  NULL      *       

4. To test if a specific Cipher String is being blocked or not. 
# openssl s_client -cipher '<Cipher_String>' -connect <VIP_IP_Address>:443

5.- To view the encryption algorithms used for a given cipher suite and the TLS protocols it is available in, you can use either of the tmm --clientciphers <cipher suite> or tmm --serverciphers <cipher suite> commands. If you want to display the values along with the hex value (Wireshark displays the hex value) then you can append the tmm --clientxxxx commands with |  awk '{printf "0x%X\t",$2,$0} {print $0}'.

For example: 
[root@IP:Active:Standalone] config # tmm --clientciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES256-SHA384:ECDHE-ECDSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-RSA-AES128-SHA256:@STRENGTH' | awk '{printf "0x%X\t",$2,$0} {print $0}'
