Description

  • Your BIG-IP logs contain iRule SSL cipher decrypt messages and you would like to stop logging SSL decrypt information

Environment

  • BIG IP
  • Decrypt iRule

Cause

Keeping the Decrypt iRule while no justification (Research or investigation) will cause extra use with BIG IP resources and disk space.

 Recommended Actions

  1. Log on to the BIG-IP Configuration Utility (GUI) 
  2. Go to Local Traffic > Virtual Server List 
  3. From iRule list you will find the iRule 
  4. Click the name of the affected virtual server
  5. Click the Resources tab
  6. To remove the iRule click >> to move the iRule to the Available list
  7. Click Finished
