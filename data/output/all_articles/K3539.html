K3539: The maximum number of configurable VLANs

Topic

The maximum number of configurable VLANs on all currently supported BIG-IP is 4094.

If you have already configured the maximum number of VLANs that your BIG-IP allows, and you attempt to configure one more VLAN, the BIG-IP system returns an error message that appears similar to the following example:

VLAN operation error:
01070085:3: Cannot create VLAN example_vlan, maximum limit reached

Note: Due to a known issue, VLAN limits are enforced incorrectly. For more information, refer to K10732: The mcpd process incorrectly limits the number of VLANs.

Important: The BIG-IP system may take a long time to load a configuration that features many VLANs. For more information, refer to K9628: Switchboard failsafe may be triggered when loading a large number of VLANs.
