Known Issue

This is the result of a known issue. The Charts Scheduler, which is a BIG-IP ASM chart reporting tool, may not include the PDF attachment when sending chart reports through email.

This issue may occur if there is no data to report, or if there is an issue creating the PDF file.

Note: For more information about the Charts Scheduler, refer to the Configuration Guide for BIG-IP Application Security Manager.

F5 Networks Product Development tracked this issue as CR134221 and it was fixed in BIG-IP ASM 10.2.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, this issue has been fixed in BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
