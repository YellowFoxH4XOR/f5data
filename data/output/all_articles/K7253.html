Known Issue

This is the result of a known issue. A virtual server configured with a redirect iRule and universal persistence profile results in a memory leak in the TCL object containing the UIE persistence key. The memory leak occurs with HTTP requests that elicit the following actions by the BIG-IP LTM system:

  • redirect
  • respond
  • ramcache
  • drop/reject

F5 Product Development is tracking this issue as CR76145, and it was fixed in BIG-IP LTM 9.1.3, 9.3, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
