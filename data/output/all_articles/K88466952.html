Description

Feb 11 10:44:56 BIG-IP-01 err iprepd[16924]: 015c0004:3: Ssl error # 6
Feb 11 10:44:56 BIG-IP-01 err iprepd[16924]: 015c0004:3: ConnectSocket fails (probably DNS not configured)
Feb 11 10:50:12 BIG-IP-01 err iprepd[16924]: 015c0004:3: Ssl error # 2
Feb 11 10:50:12 BIG-IP-01 err iprepd[16924]: 015c0004:3: SendReceive returns error -1 (recv error)
Feb 11 11:07:24 BIG-IP-01 err iprepd[16924]: 015c0004:3: Ssl error # 6
Feb 11 11:07:24 BIG-IP-01 err iprepd[16924]: 015c0004:3: no IP found for host vector2.brightcloud.com

Environment

  • BIG-IP 
  • IP Intelligence

Cause

Following article K03011490, we have determined this is a problem on the brightcloud server side.
