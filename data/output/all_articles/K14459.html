Topic

This article details the remote log server destination limitation in BIG-IP 11.6.5 and earlier when you configure the high-speed logging (HSL) feature on the BIG-IP system. This article does not apply to BIG-IP 12.0.0 and later which allows HSL logs to be sent out of both the management interface and TMM interfaces.

Description

The HSL feature is introduced in the BIG-IP system as follows:

  • The Log Publishers feature (BIG-IP 11.3.0)
  • Various logging profiles and logging profiles for BIG-IP ASM, BIG-IP AFM, and BIG-IP PSM (BIG-IP 11.0.0)
  • HSL::open and HSL::send iRule commands (BIG-IP 10.1.0)

Because HSL dispatches logs through the Traffic Management Microkernel (TMM) process, the BIG-IP system sends the high-speed logs to remote log servers that reside in networks reachable through the TMM interfaces only in 11.6.5 and earlier. Starting in BIG-IP 12.0.0, you can configure the BIG-IP system to send high-speed logs to remote log servers that reside in networks that are reachable through the management port.

Recommendations

If running BIG-IP 11.6.5 and earlier, when you configure the high-speed log-related logging profiles or use the HSL::* iRule commands, you should consider the following F5 recommendations:

  • To send logs through HSL, ensure that the BIG-IP system can reach the remote log servers through the TMM interfaces.
  • To send logs through the BIG-IP management interface, consider configuring the BIG-IP system to use the syslog mechanism.
