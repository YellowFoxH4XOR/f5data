Recommended Actions

For detailed steps on this configuration, please refer to the Configuring Remote High-Speed Logging of DoS Protection Events chapter of the External Monitoring of BIG-IP Systems: Implementations manual, for your specific version.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Additional Information

The BIG IP 13.0 system includes a new log option for reporting on bots. After the option is enabled, results display on the ASM Reporting page.

Important:  The Recommended Actions must be completed before attempting the procedure below for Remote Publisher.

Logging and viewing reports on bot violations

  1. Go to Security > Event Logs > Logging Profiles.
  2. Select Create to create a new logging profile.
  3. In Profile Name, enter a name for the profile.
  4. Select Bot Defense.
  5. Select Local Publisher, or select the Remote Publisher, or both, depending on your application environment.
  6. Select the type of violations you want to log in your application environment.

    For example, select either Log Illegal Requests and/or Log Challenged Requests.

    Note: In BIG-IP 14.1.0 and later, you can log violations based on how the system classifies them—such as Malicious Bot—and the mitigation action it performs —such as TCP Reset.

  7. Select Finished to save the profile.
  8. After the system creates the logging profile, assign it to the virtual server.
