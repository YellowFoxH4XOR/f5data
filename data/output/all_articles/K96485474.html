Description

You are unable to detect brute force attack in configuration similar to the following.

 Security ›› Application Security : Sessions and Logins : Login Pages List
  Login URL : [HTTPS] */login*
 
 Security ›› Application Security : URLs : Allowed URLs : Allowed HTTP URLs
 Allowed URL : [HTTPS] /test/login
 Allowed URL : [HTTPS] */login*

 
 URL of Test Attack Request : /test/login  

You assume the Login URL */login* is used to detect a brute force attack.

Environment

  • BIG-IP ASM
  • Brute Force Attack Prevention

Cause

This is by design.
The request will be detected by Allowed URL : [HTTPS] /test/login, which is not associated to Login URL : [HTTPS] */login*.

Recommended Actions

Configure another explicit Login Page for the request as follows.

 Security ›› Application Security : Sessions and Logins : Login Pages List
  Login URL : [HTTPS] /test/login

None
