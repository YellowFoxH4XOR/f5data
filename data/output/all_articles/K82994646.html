Description
A prompt error message of "Unable to verify SSL certificate presented by the server. The certificate's CN name does not match the passed value." is received when connecting to the APM Network Access/VPN site.

This simply implies the certificate's CN name should match the HTTP Host value of the APM Network Access/VPN site's URL.

Even the small trailing dot in the HTTP URL Host can cause this error. 

For example, this issue occurs if the certificate's CN has a value of "CN=*.myapmvpn.com" and the HTTP Host of the APM Network Access/VPN URL site has a value of https://pub.myapmvpn.com." Notice the trailing dot in this URL.

Environment

  • BIG-IP APM
  • Network Access/VPN

Cause
None

Recommended Actions

  1. Verify the BIG-IP client SSL certificate's CN value

         a. Using the OpenSSL
               
                  In the BIG-IP command-line (bash shell), run the following command: 

                  i. Find the cache-path of the client SSL Certificate
                            tmsh list sys file ssl-cert `tmsh list ltm profile client-ssl [partition/profilename] | grep '^    cert ' | awk -F " " '{print $2}'` -hidden | grep cache-path

                            e.g. 
                            tmsh list sys file ssl-cert `tmsh list ltm profile client-ssl /Common/myapmvpn | grep '^    cert ' | awk -F " " '{print $2}'` -hidden | grep cache-path

                  i. Run openssl using the cache-path output above: 
                            openssl x509 -text -noout -subject -in /config/filestore/files_d/Common_d/certificate_d\:[partition]\:[certificatefile] | grep 'Subject:'
                         
                            e.g. 
                            openssl x509 -text -noout -subject -in /config/filestore/files_d/Common_d/certificate_d\:Common\:myapmvpn.crt_217334_1 | grep 'Subject:'    

                            The output would be like this, note the CN value:
                            Subject: C=US, ST=Washington, L=Seattle, O=myOrg, CN=*.myapmvpn.com
      
         b. Using a Web Browser

                        i.    Launch a web browser e.g. Chrome

                        ii.   Access the APM Network Access/VPN site's URL

                        iii.  Click on the padlock in the web browser's Address bar

                        iv.  Click on the 'Connection is secure' item

                        v.   Click on the 'Certificate is valid' item 

                        vi.  Go to the Details tab

                        vii. Scroll and find the Subject field and verify its value
                  
  2. Verify the HTTP Host of the APM Network Access/VPN site's URL in the CTU report  is matching with the certificate's CN value above

         a. Generate the CTU report, see K12444: Overview of the Client Troubleshooting Utility for Windows

         b. Search for the APM Network Access/VPN URL
                        If using a Linux command-line, you can use the following command:

                        grep 'HostCtrl information.*url' f5Report.html

                        The output would be like this, note the trailing dot in the URL HTTP Host: 
                        2022-09-19,11:01:30:609, 10408,1076,HOST, 48, , 177, CHostCtrl::Load properties, HostCtrl information: property #0, name="ur_ui_url", value="https://pub.myapmvpn./vdesk/webtop_resource_inner.eui".
