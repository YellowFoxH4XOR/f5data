Microsoft Azure Government is a physically and network isolated instance of Microsoft Azure designed to support U.S. government organizations.

You can view the F5 End User License Agreement (EULA) specific to Azure Government customers here: F5 End User License Agreement.

Important: Read this document before installing or operating this product.

To review F5's EULA for other environments, refer to K12902: End User License Agreement Change Notice.
