K000162105: Distributed Cloud App Firewall Custom Blocking Response Page Size Limitation

Description

When configuring a Custom Blocking Response Page in F5 Distributed Cloud App Firewall, an error may occur if the response body exceeds a certain size. The UI indicates a maximum length of 4096 bytes, but this limit applies to the base64-encoded response body, not the original plain-text content.


Environment

 F5 Distributed Cloud Console

 Web App & API Protection > App Firewall

 Blocking Response Page > Blocking Response Page Body


Cause

The 4096-byte maximum applies to the response body after base64 encoding. Base64 encoding increases the payload size, so the practical plain-text limit is about 3070 bytes.


Answer/Recommended Actions

 Keep the plain-text response body below approximately 3070 bytes when configuring a Custom Blocking Response Page.
