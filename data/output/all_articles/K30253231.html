K30253231: Configuration file /usr/lib/systemd/system/devmgmtd.service is marked executable. Please remove executable permission bits. Proceeding anyway.

Type
Support Solution
Published
2020-10-16
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K30253231

Description

When booting or performing a ConfigSync, observing in /var/log/dmesg one or more messages similar to the following examples:

warning kernel: [xx]: systemd-sysv-generator[xxxx]: Configuration file /usr/lib/systemd/system/availability_log.service is marked executable. Please remove executable permission bits. Proceeding anyway.
warning kernel: [xx]: systemd-sysv-generator[xxxx]: Configuration file /usr/lib/systemd/system/bcm56xxd.service is marked executable. Please remove executable permission bits. Proceeding anyway.
warning kernel: [xx]: systemd-sysv-generator[xxxx]: Configuration file /usr/lib/systemd/system/devmgmtd.service is marked executable. Please remove executable permission bits. Proceeding anyway.
warning kernel: [xx]: systemd-sysv-generator[xxxx]: Configuration file /usr/lib/systemd/system/fw_update.service is marked executable. Please remove executable permission bits. Proceeding anyway.
warning kernel: [xx]: systemd-sysv-generator[xxxx]: Configuration file /usr/lib/systemd/system/pfmand.service is marked executable. Please remove executable permission bits. Proceeding anyway.

Environment

  • BIG-IP startup
  • Performing a ConfigSync

Cause

Files in question have unnecessary executable permissions:

Example:
ls -l /usr/lib/systemd/system/devmgmtd.service
-rwxr-xr-x. 1 root root 986 Oct 18  2019 /usr/lib/systemd/system/devmgmtd.service

Bug ID 1231149 tracks this issue.

Recommended Actions

There is no impact to functionality.

If you want to stop the message, remove executable permissions on the file(s):

  1. mount -o rw,remount /usr
  2. chmod 644 /usr/lib/systemd/system/devmgmtd.service
  3. mount -o ro,remount /usr

Additional Information

These messages can be safely ignored.
