Known Issue

This is the result of a known issue. The BIG-IP ASM security policy templates contain predefined configurations to address the security needs of a specific web application. The OWA Exchange 2007 Template does not include password as a sensitive parameter by default.

F5 Product Development tracked this issue as CR127599, and it was fixed in BIG-IP ASM version 10.1.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Workaround

If you ran the Deployment Wizard or the Security Policy Setup Wizard and selected the OWA Exchange 2007 (http) security policy, you can add password as a sensitive parameter by performing the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Click the Main tab in the Application Security screen.
  3. Click Web Applications.
  4. Click the OWA 2007 security policy.
  5. Click Parameters.
  6. Click the Sensitive Parameters menu.
  7. Click Create.
  8. Type password in the Parameter box.
  9. Click Create.
