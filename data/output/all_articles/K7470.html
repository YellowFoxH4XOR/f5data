When configuring a changeset in Enterprise Manager, the only class paths that are available from the Add Path menu are for objects that have already been configured.

Creating a new changeset

When creating a new changeset using Device as the source option, the only class paths available for selection from the Add Path menu are class paths for objects that have been configured on the selected device.

For example, if the selected device does not have any virtual servers configured, the class path Local Traffic/Virtual Server class path will not be available from the Add Path menu.

Modifying an existing changeset

When modifying an existing changeset, or creating a new changeset using Text as the source option, the only class paths available for selection from the Add Path menu are class paths for objects that have been configured on at least one of the devices configured on the Enterprise Manager system.

For example, if none of the devices configured on the Enterprise Manager have any virtual servers configured, the class path Local Traffic/Virtual Server will not be available from the Add Path drop-down menu.

F5 Networks Product Development tracking this feature enhancement request as CR78819 and it was added in BIG-IP version 9.4.1.

Note: While this issue affects the behavior of the Enterprise Manager system, the change was made on the BIG-IP system to modify the information the BIG-IP system reports to the Enterprise Manager. All versions of Enterprise Manager may be affected by this issue when managing devices running BIG-IP version 9.4.0 or version 9.3.1.
