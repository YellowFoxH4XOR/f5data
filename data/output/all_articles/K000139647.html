K000139647: F5OS "Can NOT ping appliance-1.chassis.local (100.65.60.1)." and "Can now ping appliance-1.chassis.local (100.65.60.1)."

Updated
2024-05-16
Applies to

  • F5OS-A
Source

Description

We may find the messages in /var/F5/system/log/platform.log


2024-05-09T06:52:27.734712+09:00 appliance-1 appliance-orchestration-manager[7]: priority="Info" version=1.0 msgid=0x6701000000000004 msg="INFO." details="Can NOT ping appliance-1.chassis.local (100.65.60.1).".

2024-05-09T06:52:57.740807+09:00 appliance-1 appliance-orchestration-manager[7]: priority="Info" version=1.0 msgid=0x6701000000000004 msg="INFO." details="Can now ping appliance-1.chassis.local (100.65.60.1).".



Environment

  • F5OS-A

Cause

The IP address 100.65.60.1 is the gateway IP associated with the appliancenet docker bridge network.

Appliance orchestration manager sends a ping to this IP address to determine system availability approximately every ~30 seconds.


If the ping fails (e.g., no response within 1s), "Can NOT ping appliance-1.chassis.local (100.65.60.1)" is logged.

The next time the ping succeeds, "Can now ping appliance-1.chassis.local (100.65.60.1)" is logged.


Recommended Actions

If the next ping succeeds (ex. "Can now ping appliance-1.chassis.local (100.65.60.1)" is logged after 30 seconds), we can safely ignore it.
