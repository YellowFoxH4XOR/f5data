  • F5OS-C: 1.5.X, 1.3.X, 1.2.X, 1.1.X, 1.5.1, 1.5.0, 1.3.2, 1.3.1, 1.3.0, 1.2.2, 1.2.1, 1.2.0, 1.1.4, 1.1.3, 1.1.2, 1.1.1, 1.1.0
Source

Description

There is only one Controller inserted, then images are not displayed in "Chassis Partitions" and "Controller Management" on GUI.

 

Environment

  • Velos
  • Controller

 

Cause

  • Bug ID 1195361 (cosmetic)

Recommended Actions

You can safely ignore.

When one of system controller is unhealthy status or not inserted, this message appear and cause of confusion. 

2 healthy System Controllers are inserted, then this message will be disappeared.
