Topic

To provide an ARX system diagnostic information file to F5Technical Support, perform one of the following procedures:

  • Creating an ARX system diagnostic information file and saving the file to a management system's local disk using the ARX Manager GUI, and manually providing the file to F5 Technical Support
  • Creating an ARX system diagnostic information file and uploading the file to the F5 Support FTP server from the ARX command line

Creating an ARX system diagnostic information file and saving the file to a management system's local disk using the ARX Manager GUI, and manually providing the file to F5 Technical Support

  1. Log in to the ARX Manager GUI using the Crypto Officer credentials.
  2. Click Maintenance.
  3. Click Collect Diag Info.
  4. Enter an identifiable filename in the Filename field.

    Note: F5 Technical Support requests that you name the file with the ARX hostname, date, and description or case number.

    For example:

    ARXname_01222008_c123456.tgz

  5. In the Destination field, ensure that Local Disk is selected.
  6. Click OK.

    Important: The newly-created diagnostic information file will not display until completion of the collection, which may take several minutes.

  7. In the left navigation menu, click Maintenance to refresh the diagnostic file list.
  8. Select the check box for the diagnostic information file.
  9. Click Download.
  10. Click Save.
  11. Navigate to the desired location to save the file.
  12. Click Save.
  13. Transfer the saved diagnostic information file to F5 Technical Support using your desired method.

Creating an ARX system diagnostic information file and uploading the file to the F5 Support FTP server from the ARX command line

  1. Log in to the ARX command line.
  2. The command prompt displays, appearing similar to the following example:

    ARXname>

  3. Enable privileged mode for the ARX by typing the following command:

    enable

    The privileged mode command prompt displays, appearing similar to the following example:

    ARXname#

  4. Create a configuration and diagnostics file and upload the file to the F5 Support FTP server by using the following command syntax:

    collect diag-info ftp://<ftpid>:<ftppassword>@arxftp.f5.com/<File_Name>.tgz

    Replace <ftpid> with the username you were issued for accessing the FTP server.

    Note: This is not the username used for accessing AskF5 or downloads resources.

    Replace <ftppassword> with the password used for accessing the FTP server.

    Note: This is not the password used for accessing AskF5 or downloads resources.

    Replace <File_Name> with the desired file name for your diagnostics file.

    Note: F5 Technical Support requests that you name the file with the ARX hostname, date, and description or case number.

    For example:

    collect diag-info ftp://johndoe:secret@arxftp.f5.com/ARXname_01222008_c123456.tgz

    The Collect diagnostic information? [yes/no] prompt displays.
  5. Type yes.

    Status messages similar to the following display until the command completes:

    Note: The diagnostics information file is actually transferred, even though the status messages indicate 0 megabytes transferred.

    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: The copy command completed successfully.

  6. Inform F5 Technical Support that the ARX diagnostic information file has been uploaded to the FTP server.
