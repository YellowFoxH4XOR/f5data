K000091336: Cluster FQDN change does not change Azure AD Auth Provider redirect uri fqdn

Type
Support Solution
Published
2022-03-29
Updated
2022-03-29
Source
https://my.f5.com/manage/s/article/K000091336

Description

Changing the NGINX Controller Cluster FQDN does not change the fqdn in the Azure AD Auth Provider redirect uri.

 Environment

NGINX Controller

Azure AD Auth Provider

 Cause

This issue is being tracked internally as ID IND-33292

 Recommended Actions

Change the fqdn value implemented by the Azure AD Auth Provider redirect uri from the NGINX Controller command line

1. Delete the Azure AD Auth Provider object
2. Patch platform-mgr with desired fqdn for redirect uri: 
kubectl patch cm $(kubectl get cm | grep platform-mgr | sed ‘s/ .*//‘) -p ‘{“data”:{“CTR_FQDN”:“(desired_fqdn)”}}’
3. Create the Azure AD Auth Provider object

Note: If the platform-mgr pod is deleted any time after this then the fqdn of the redirect uri will revert to its original value (at this point repeat steps above to reinstate desired configuration)
