Known Issue

This is the result of a known issue. Virtual snapshots may time out if multiple managed volumes are snapshot on the same schedule, and the corresponding physical volumes are on a Windows filer. Because a Windows filer requires snapshots to perform one at a time, the ARX system must snapshot each physical volume sequentially. The time required to complete these serial physical snapshots may exceed the time configured for the managed volume snapshot. As a result, the snapshot will fail with the following error message:

:WMI-0-ERR-WMI_TIMED_OUT_FAULT:: The request timed out on the server. Reason: (null) HTTP Status: 500

F5 Product Development tracked this issue as ARX ID 36573 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX release notes.

Additionally, this issue was fixed in hotfix HF3 for ARX version 5.0.5.
