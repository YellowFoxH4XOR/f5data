Issue

Old Behavior

In versions prior to 11.1.0, the BIG-IP system supports the neighbor discovery for IPv6 by configuring the radvd process and the /etc/radvd.conf file.

New Behavior

Beginning in BIG-IP 11.1.0, neighbor discovery for IPv6 functionality is integrated into TMM and must be configured using the tmsh utility; the radvd process and the /etc/radvd.conf configuration file were removed from TMOS.

F5 Product Development tracked this change as ID 227306.

Impact

If your BIG-IP system contains radvd configuration and you upgrade to version 11.1.0, you must use the tmsh utility to configure neighbor discovery for IPv6 functionality.

Recommended Actions

Configure IPv6 router advertisement functionality using the tmsh utility.
