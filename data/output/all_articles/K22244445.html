Description
This article explains how to enable debug logging for the restjavad process on a BIG-IP/BIG-IQ. By default, restjavad only rotates the log file when it reaches 1MB. This is sometimes insufficient specially when debug is enabled.

Environment

  • BIG-IP/BIG-IQ

Cause
None.

Recommended Actions

Setting to debug
To enable debug for all the workers, and increase the size of files to 10MB (from 1MB default) and retain 30 files, apply the following changes:

  1. Backup the current restjavad logging configuration saved to file named /etc/restjavad.log.conf.bak
    cp -b /etc/restjavad.log.conf{,.bak}
  2. Create a debug version of restjavad.log.conf and save to file /etc/restjavad.log.conf.debug:
    Note: The following is a single command.
    cat /etc/restjavad.log.conf.bak | sed -e 's/level=INFO/level=FINEST/g' \
        -e 's/FileHandler.limit=.*/FileHandler.limit=10000000/g' \
        -e 's/FileHandler.count=.*/FileHandler.count=30/g' \
        -e 's/rootLogger=INFO/rootLogger=FINEST/g' \
        -e 's/ForwarderPassThroughWorker=INFO/ForwarderPassThroughWorker=FINEST/g' \
        -e 's/MaxFileSize=.*/MaxFileSize=10MB/g' \
        -e 's/MaxBackupIndex=.*/MaxBackupIndex=30/g' > /etc/restjavad.log.conf.debug
  3. Overwrite the default restjavad.log.conf with the debug version:
    cp -vf /etc/restjavad.log.conf.debug /etc/restjavad.log.conf
  4. Restart restjavad:
    bigstart restart restjavad

Setting logging to default
You can restore the default configuration by copying back the original file

  1. Restore the defaults stored in restjavad.log.conf.bak it back to restjavad.log.conf:
    cp -vf /etc/restjavad.log.conf.bak /etc/restjavad.log.conf
  2. Restart restjavad:
    bigstart restart restjavad
