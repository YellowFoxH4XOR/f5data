Known Issue

This is the result of a known issue. When navigating in the BIG-IP WebAccelerator Configuration utility, a large number of messages that appear similar to the following example may be logged to the /var/log/httpd/httpd_errors file:

err httpd[9961]: [error] [client <ip_address>] File does not exist: /usr/local/www/xui/skin, referer: https://<ip_address>/waui/list_policies.do

Note: The referer page included in the error message may be one of several BIG-IP WebAccelerator Configuration utility pages; it is not specific to the issue. 

This issue is benign for most web browsers and does not affect Configuration utility performance.

Note: This issue may cause Internet Explorer version 6 (IE6) sessions to hang when browsing BIG-IP WebAccelerator Configuration utility pages. This behavior occurs because IE6 may attempt to send a large burst of SYN packets to the BIG-IP WebAccelerator management address. As a result, the BIG-IP WebAccelerator web server exceeds the httpd MaxClients setting. For more information, refer to K9588: Error Message: httpd: [error] server reached MaxClients setting.

F5 Product Development tracked this issue as CR124968 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
