Description

  • You want to install or upgrade NGINX Ingress Controller using JWT token
  • JWT token usually is provided to customer along and at a time of renewing or activating new subscription.
  • JWT token, also helps automate Nginx image pull process.
  • You are using default NGINX image from F5 Container registry private-registry.nginx. com 

Environment

  • NGINX Ingress Controller
  • JWT token
  • Kubernetes cluster
  • instillation/Upgrade

Cause

  • Steps to follow when pulling NGINX Plus image using JWT token in Kubernetes cluster

Recommended Actions

  • Create Docker Config Secret
    • Create a Kubernetes docker-registry secret in target namespace where NGINX Ingress Controller installed
      • docker-username = none for password (as the password is not used). The name of the docker server is private-registry.nginx.com.
      • docker-password = JWT token
      • docker-server = private-registry.nginx.com

Syntax

kubectl create secret docker-registry <name-of-secret> --docker-server=private-registry.nginx.com --docker-username=<JWT Token> --docker-password=none [-n nginx-ingress]

Example

kubectl create secret docker-registry myexample --docker-server=private-registry.nginx.com --docker-username=eyzIzQ1NTMyM30.ct__-dot8XRq.......IYM --docker-password=none -n nginx-ingress
    • Make sure that you copied all character as it is provided in nginx-repo.jwt file
    • Make sure not to introduce white space or any additional character
  • Associate Secret with nginx-ingress serviceAccount 
    • With the above secrete created, associate the secret with nginx-ingress serviceAccount that you would have created with the controller

Example

apiVersion: v1
imagePullSecrets:
- name: myexample 
kind: ServiceAccount
metadata:
  name: nginx-ingress
  namespace: nginx-ingress
  • Update NGINX Ingress Controller deployment manifest
    • With secret associated with serviceAccount, modify NIC deployment manifest to point to F5 Container Registry to automate image pull process

Example

    • to pull Nginx Ingress image 3.5.0, point to private-registry.nginx.com/nginx-ic/nginx-plus-ingress:3.5.0
            apiVersion: apps/v1
            kind: Deployment
            metadata:
              name: nginx-ingress
              namespace: nginx-ingress
            spec:
              replicas: 1
              selector:
                matchLabels:
                  app: nginx-ingress
              template:
                metadata:
                  labels:
                    app: nginx-ingress
                    app.kubernetes.io/name: nginx-ingress
                spec:
                  serviceAccountName: nginx-ingress
                  automountServiceAccountToken: true
                  securityContext:
                    seccompProfile:
                      type: RuntimeDefault
                  containers:
                  - image: private-registry.nginx. com/nginx-ic/nginx-plus-ingress:3.5.0
                    imagePullPolicy: IfNotPresent
                    name: nginx-plus-ingress
