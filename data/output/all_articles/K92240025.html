K92240025: AD Authentication to GUI fails after upgrading

Type
Support Solution
Published
2023-03-22
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K92240025

Description

AD auth is failing on the BIG-IP, AD server is up and available, reachable from other devices on the same subnet.
BIG-IP appears to be following LDAP referrals to servers that are unreachable.

The description of the LDAP packet may look similar to the following:

... | searchResRef(2)  | searchResRef(2)  | searchResRef(2)  | searchResDone(2) success  [1 result]

This may indicate the BIG-IP is chasing LDAP referrals.


Environment

  • Active Directory Authentication
  • After upgrade to BIG-IP version 14.x and later


Cause

It's not possible to disable referrals in version 14.x and later


Recommended Actions

Please contact F5 Support for an Engineering Hot Fix to resolve this issue.
