Issue

Error Message

bigd[<PID>]: 01060145:5: Pool <pool_name> member <member_name> monitor status <status>. [ <monitor_name> ] [ <prior_status> ]

In this error message, note the following:

  • <PID> is the process ID for the bigd process.
  • <pool_name> is the partition and name of the pool.
  • <member_name> is the partition and name of the pool member.
  • <status> is the reported status of the pool member.
  • <monitor_name> is the partition, name, and new status of the monitor that triggered the status change.
  • <prior_status> is the last known status of the pool member.

For example:

bigd[22609]: 01060145:5: Pool /Common/pool_http member /Common/10.10.10.10 monitor status up. [ /Common/http: UP ] [ was checking for 0hr:1min:16sec ]

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You configure a health monitor the check the availability of a fully-qualified domain name (FQDN) pool member.
  • The BIG-IP system detects a change in the availability status for the pool member.

Possible pool member statuses for this message include the following:

  • checking
  • disabled
  • down
  • down; waiting manual resume
  • forced down
  • forced up
  • irule down
  • unchecked

Impact

This message is informational and indicates the new status of the pool member. Unexpected changes to a pool member's availability state may indicate a configuration issue or lack of resource availability.

Recommended Actions

If the system reports an unexpected down status, verify the pool member configuration, the configuration of associated pool member monitors, and the resource availability to ensure pool member availability.
