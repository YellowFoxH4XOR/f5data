K18013613: Configuration load failure: 010717e6:3: EC key contains unsupported curve

Support Solution

Legacy Content
Applies to

Source
https://my.f5.com/manage/s/article/K18013613

Description

Reloaded the configuration or rebooted, and the configuration failed to load, with the error:

010717e6:3: EC key contains unsupported curve.
Unexpected Error: Loading configuration process failed.

Environment

  • Configuration reload

Cause

This error message indicates the system attempted to load an SSL object with an unsupported ECC curve.

This would most likely be seen after importing or updating a certificate bundle that contains a certificate (public key) with an unsupported ECC curve. In particular, certificates with secp521r1 curve are completely unsupported on 11.6.x, with limited support on later versions.

Recommended Actions

Refer to the following article for more information on supported elliptic curves:

  • K12982: BIG-IP support for elliptic curve cryptography

To resolve the configuration load failure, remove the certificate in question from the certificate bundle file, starting from Certificate: and ending with -----END CERTIFICATE-----, then reload the configuration:

tmsh load sys config

Additional Information

Example of a certificate with secp521r1 / P-521 curve:

Certificate:
<..>
    Signature Algorithm: ecdsa-with-SHA512
        <..>
        Subject Public Key Info:
            Public Key Algorithm: id-ecPublicKey
                <..>
                ASN1 OID: secp521r1     <---
                NIST CURVE: P-521       <---
            <..>
-----BEGIN CERTIFICATE-----
<..>
-----END CERTIFICATE-----
