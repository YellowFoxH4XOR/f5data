Known Issue

The DNS FPGA hardware-accelerated cache may drop DNS queries that contain EDNS OPT records.

This issue occurs when all of the following conditions are met:

  • The BIG-IP DNS system is configured for FPGA hardware-accelerated DNS caching.

    Note: At the time of publishing, the VIPRION B2250 blade is the only platform that supports hardware-accelerated DNS caching.

  • A DNS query is sent to the BIG-IP DNS system for a record that is stored in the hardware-accelerated DNS cache.
  • The DNS query includes an EDNS OPT record with an unknown version, or other values that the hardware-accelerated cache cannot process.

Impact

The DNS request is not processed.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The DNS request sent to the BIG-IP DNS system may time out.
  • The DNS request for a record that is not stored in the FPGA hardware-accelerated DNS cache is processed.
