Topic

When Internet Explorer 6 (IE6) browser clients access a web page through the WebAccelerator, the client may cache pages or objects even if the HTTP response headers direct the client not to cache. As a result, some web pages or objects may not display or update properly. This issue occurs because IE6 reads compressed data as cached, even if the cache-control setting specifies a different value.

For information about the IE6 browser not adhering to the cache-control setting for compressed content, refer to the following two Microsoft KB articles:

  • Microsoft KB article 327286

    http://support.microsoft.com/kb/327286/
  • Microsoft KB article 328498

    http://support.microsoft.com/kb/328498/

Note: This issue does not affect Internet Explorer 7 or Firefox clients.

Workaround

To prevent the IE6 browser from inappropriately caching content, you can edit the WebAccelerator acceleration policy to disable content compression for the affected object types when IE6 is the client. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click WebAccelerator.
  3. Click Policies.

    A new policies configuration page opens.

    Note: You cannot edit pre-defined acceleration policies. If you are using a pre-defined acceleration policy, you must copy the policy and edit the new user-defined acceleration policy.
  4. Select the user-defined acceleration policy to edit.
  5. Find the node ID for the affected objects by matching the A field in the X-PvInfo header of the HTTP request affected by this issue.
  6. To find the node ID, hover the mouse over each node of the Policy Tree until the desired node ID is found.

    Note: For information about the X-PvInfo header information, refer to the Viewing X-PvInfo response headers section of the Using HTTP Headers chapter in the BIG-IP WebAccelerator Policy Management Guide.
     
  7. Select the node by clicking on the node in the Policy Tree.
  8. Click the Copy button at the top of the Policy Tree.
  9. Type a name in the Name field for the new node.
  10. Click the Copy button.

    The new node will appear in the Policy Tree.
  11. Select the new node in the Policy Tree.

    The Matching Rules for the node are displayed.
  12. Move the new node above the original node in the Policy Tree, by clicking the up arrow button.
  13. Select User Agent from the Add Parameter drop-down menu.
  14. Click the Add button.
  15. Select the check box next to the Value matches drop-down menu.
  16. Click the down arrow next to Enter a regular expression.
  17. Select Internet Explorer 6.0.
  18. Click the Save button.
  19. Select Acceleration Rules from the Matching Rules drop-down menu.
  20. Select the Assembly menu tab.
  21. Clear the Enable Content Compression check box.
  22. Click the Save button.
  23. Click the Publish Now button.

Note: If you had to copy a pre-defined acceleration policy and create a new user-defined acceleration policy, you must also associate the new user-defined policy with your WebAccelerator Application.
