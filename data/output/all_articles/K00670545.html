K00670545: BIGIQ CM cannot create One-connect profiles on Managed Devices

Type
Support Solution
Published
2021-04-08
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ
  • BIG-IQ Platforms
  • BIG-IQ Centralized Management: 7.1.X, 7.X.X, 6.X.X, 8.0.X, 7.0.X, 7.0.0
Source
https://my.f5.com/manage/s/article/K00670545

Description

It is not possible to create a OneConnect profile with a BIG-IQ
  • OneConnect profiles can be imported from managed devices
  • An imported OneConnect profile can be cloned and deployed
  • OneConnect profile cannot be modified after being imported

Environment

  • BIG-IQ CM Configuration Utility 

    Cause

    A feature request is currently in the process to add this feature to BIG-IQ. An update will be made to this article when a feature request ID is available.  

    Recommended Actions

    One-connect profiles can only be created locally on managed BIG-IPs and then imported into BIG-IQ

    1. Create a new OneConnect profile locally on a managed BIG-IP
    2. Re-import the Local Traffic (LTM) server for the managed BIG-IP

    Additional Information

    • Currently supported profiles:
      • Client SSL
      • HTTP
      • PCP
      • Server SSL
      • TCP
      • UDP
      • HTTP Analytics
      • TCP Analytics
      • Persistence Universal
      • Persistence Cookie
      • Persistence Source Address
      • Persistence Hash
      • Persistence SSL
