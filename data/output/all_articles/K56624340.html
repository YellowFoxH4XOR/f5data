Description

You need to allow specified traffic from cloud.
For example,  you want to allow Azure Monitor traffic.

Environment

  • BIG-IP ASM 

  • Bot profile

Cause
None

Recommended Actions
The actions or steps required to fix issue.

  1. Follow the official manual Manual Chapter : Writing Custom Bot Signatures

  2. You need to set the mitigation action to item except None.

Additional Information

It is a bit confusing, and you may think "mitigation action None" means ASM will do nothing to trusted bots, and allows the request to pass.
But please do not apply mitigation action "None" to allow passing custom trusted bots. 
Reason:
The behavior of the following bot classes with mitigation action "None" is : 
With a Trusted / Untrusted bot, all signatures of this class are disabled and are not executed.
With a Suspicious browser / Malicious bot, all signatures and anomalies of this class are disabled and not executed.
With an Unknown class, no action is performed.

If you want to allow traffic from custom Bots without logging the requests, you can consider using and iRule like:
 

when BOTDEFENSE_ACTION {
  if (user agent equals CustomBot)
    BOTDEFENSE::action allow
}
