Known Issue

This is the result of a known issue. If a Windows Vista client enters Protected Workspace, and the client system is using the Microsoft Office Input Method Editor (Japanese) 2007, Kanji selections do not appear in Microsoft Office Input Method Editor (IME) 2007.

F5 Networks Product Development tracked this issue as CR89943 and it was fixed in FirePass version 6.1.0. For information about upgrading refer to the FirePass Release Notes.

Additionally, this issue has been fixed in cumulative HF-602-10, which has been issued for FirePass version 6.0.2, and HF-603-3, which has been issued for FirePass version 6.0.3. You may download this hotfix or a later version of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by directing Windows Vista clients to the logon page instead of requiring Protected Workspace.

Note: For information, refer to K7177: Detecting Microsoft Windows Vista clients in a pre-logon sequence.
