Description

Deploying BIG-IP VE in google cloud platform results in the error:

Authentication failed: Password expired. Update password via /mgmt/shared/authz/users.

Environment

  • Google Cloud Platform
  • New VE deployment on GCP
  • Deploying 16.1.2.2 or later

Cause

For scripts using rest api calls this means first posting to /mgmt/tm/auth/user to create a user. This user immediately expires due to the change in behavior as per the ID1036285.
This causes the authentication failure error.

Recommended Actions

Creating a new user via a script, you should add another statement to modify the user password.

For example:
  echo "--- START CREATE BIGIP USER ---"
  tmsh create auth user bigipuser partition-access add { all-partitions { role admin } } password xxxxxx shell bash
  tmsh modify auth user bigipuser password xxxxxx
  tmsh save sys config
  echo "--- DONE CREATE BIGIP USER ---"
