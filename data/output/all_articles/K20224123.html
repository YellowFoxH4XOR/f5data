Description

When doing Config Sync, you get an error message similar to the following:

01070712:3: Caught configuration exception (0), Invalid monitor rule instance identifier: <...>

Environment

  • BIG-IP
  • FQDN pool
  • Monitor

Cause

Bug ID 1017513 - fqdn pool full config sync issue when changing or removing the monitor attached

Recommended Actions

You need to find the FQDN Pool that has a different monitor configuration on Active and Standby.

Then change the Monitor on the Standby to be the same as the Active, and then push the Sync from the Active with the Overwrite option.

If you are not sure which FQDN Pool it is, you can upload the qkviews from the Active and Standby BIG-IP's, and use the compare function in iHealth. Click on the Pool, and this will list the Pools that have different configs for Active and Standby.

Additional Information

  • K12878: Generating diagnostic data using the qkview utility
