Topic

You should consider using this procedure under the following conditions:

  • You want to disable the admin or root user accounts for administrative or security purposes.
  • You want to create new administrative accounts for the Configuration utility or for command line access.

IMPORTANT: When you disable the admin account on vCMP systems, vCMP guest information does not get updated on the vCMP host. As a result, commands such as tmsh show vcmp health does not work. For more information on this known issue, refer to ID 694765 and K44041985: REST API calls fail: Cannot load user credentials for user "admin" Current session has been terminated.

IMPORTANT: When you disable the admin account on a BIG-IP system, REST-API will be unable to perform some actions that require use of the account. For more details, refer to Bug ID 563144.

Description

Beginning in BIG-IP 11.6.0, it is possible to disable and replace the admin and root accounts with alternative logins using the Configuration utility or TMOS Shell (tmsh).

You can do one or both of the following:

  • Watch the following videos for a demonstration of the procedures in this article, which you can perform using either the Configuration utility or tmsh and the command line.
  • Follow the written steps in the Procedures section.

To watch a video demo of this procedure, go to Change users and access for the BIG-IP root and admin accounts using the Configuration utility or Change users and access for the BIG-IP root and admin accounts using tmsh and the command line.

Prerequisites

You must meet one the following prerequisites to use this procedure:

  • You must have administrative access to the Configuration utility.
  • You must have administrative access to tmsh.

Procedures

To disable and create new login accounts using the Configuration utility or tmsh, perform the following procedures:

Disabling and creating new login accounts using the Configuration utility

  • Disabling the admin account
  • Creating an alternative root login account
  • Disabling the root shell login account

Disabling and creating new login accounts using tmsh

  • Disabling the admin account
  • Creating an alternative root login account
  • Disabling the root shell login account

Disabling and creating new login accounts using the Configuration utility

To disable and create new login accounts, perform the following three procedures:

Note: While it is possible to fully disable shell login access to the BIG-IP system, you must have at least one administrative user for the Configuration utility.

Disabling the admin account

Before you disable the admin login, you must also create a new administrative user account. To accomplish both tasks, perform the following procedure:

Impact of procedure: You will no longer be able to use the admin user login for administrative purposes. BIG-IP features that rely on the admin user account, such as some REST API's, do not function properly.

  1. Log in to the Configuration utility as the administrative user.
  2. Go to System > Users > User List.
  3. To create a new user, select Create...
  4. Enter a username, password, and user role of Administrator.
  5. Select Add.
  6. Select Finished.
  7. Go to System > Platform.
  8. Under the Admin Account section, select the Disable default admin, use alternate box.

    Note: If you have not created an alternate administrative account, this option will not appear.

  9. From the menu that appears, select the newly created administrator role user account.
  10. Enter the new password for the selected user.
  11. Select Update.

Creating an alternative root login account

To create an alternative root login account, perform the following procedure:

Impact of procedure: Newly created users will have full administrative privileges to the BIG-IP host.

  1. Go to System > Users.
  2. To create a new user, select Create.
  3. Enter a username, password, and user role of Administrator.
  4. Select Add.
  5. Under Terminal Access, select Advanced Shell.
  6. Select Finished.

Disabling the root shell login account

To disable the root shell login account, perform the following procedure:

Impact of procedure: You will no longer be able to use the root login for administrative purposes.

  1. Log in to the Configuration utility as the administrative user.
  2. Go to System > Platform.
  3. Under Root Account, select the Disable login box.
  4. Select Update.

Disabling and creating new login accounts using tmsh

To disable and create new login accounts, perform the following three procedures:

Disabling the admin account

Before you disable the admin login, you must also create a new administrative user account. To accomplish both tasks, perform the following procedure:

Impact of procedure: You will no longer be able to use the admin login for administrative purposes. BIG-IP features that rely on the admin user account, such as some REST API's, do not function properly.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To create a new user with the admin role, type the following command:

    create /auth user <admin-user> partition-access add { all-partitions { role admin } } prompt-for-password

    Note: <admin-user> is the name of the new administrative user account you want to create.

    For example:

    create /auth user newadmin partition-access add { all-partitions { role admin } } prompt-for-password

  3. At the password prompt, enter a password for this user.
  4. To disable the admin account and assign an alternate user as the administrative user, type the following command:

    modify /sys db systemauth.primaryadminuser value <user>

    Note: <user> is the name of the user.

    For example:

    modify sys db systemauth.primaryadminuser value newadmin

    Note: Executing this command will immediately disconnect all administrative users currently connected to the Configuration utility.

Creating an alternative root login account

To create an alternative root login account, perform the following procedure:

Impact of procedure: Newly created users will have full administrative privileges to the BIG-IP host.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To disable the root user, type the following command:

    create /auth user <username> shell bash partition-access add { all-partitions { role admin } } prompt-for-password

    Note: <username> is the name of the new root user account you want to create

    For example:

    create /auth user newrootuser shell bash partition-access add { all-partitions { role admin } } prompt-for-password

  3. At the prompt, enter a new password for this root user.

Disabling the root shell login account

To disable the root shell login account, perform the following procedure:

Impact of procedure: You will no longer be able to use the root login for administrative purposes. See Supplemental Information for steps on re-enabling root access in a recovery scenario.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To disable the root user, type the following command:

    modify /sys db systemauth.disablerootlogin value true
