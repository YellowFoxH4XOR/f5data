K73615315: Purchased VPN license is not applied on APM

Type
Support Solution
Published
2019-12-13
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 12.1.0
Source
https://my.f5.com/manage/s/article/K73615315

Description

  • You apply any APM add-on license like "F5-ADD-BIG-VE-VPN-50"
  • You see that license is applied but total access sessions number is still 10

Environment

  • APM
  • Licensing

Cause

  • APM Base is not licensed on the device. You are using APM Lite license, which is some kind of trial
  • Any APM add-on key doesn't work with only APM lite

Recommended Actions

  • Contact your F5 Account Manager to acquire an "APM Base" add-on for your device's current license

Additional Information

In tmsh show sys license command output you can see that:

  • "APM-VE, 50 VPN Users (XXXXXX-XXXXXX)" add-on is activated
  • "APM, Base" is located under Optional Modules, which means that it is not licensed
