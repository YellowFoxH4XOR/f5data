Description

Message that /var/lib/mysql is running out of disk space:

011d0004:3: Disk partition /var/lib/mysql (slot 1) has only 4% free.

  • df -h command shows /var/lib/mysql is at 100% disk usage
  • BIG-IP HA pair shows status Offline

Environment

  • BIG-IP
  • AVR module provisioned
  • ASM module provisioned 

Cause

BIG-IP Analytics (AVR) statistical data for BIG-IP ASM grows to consume available disk space, causing traffic disruptions and system instability.

Recommended Actions

Impact: Removes all collected AVR statistics from the BIG-IP system and resets the AVR statistics database.

  1. Stop the monpd process by typing the following command:

    #tmsh stop /sys service monpd

  2.  Remove the AVR files by typing the following command:

    rm -rf /var/lib/mysql/AVR

  3. Create the /var/avr/init_avrdb file by typing the following command:

    touch /var/avr/init_avrdb

  4. Restart the monpd process by typing the following command:

    #tmsh restart /sys service monpd
