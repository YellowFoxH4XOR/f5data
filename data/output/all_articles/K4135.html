K4135: Configuring BIG-IP to fail over if the SSL accelerator hardware fails

Topic

BIG-IP LTM 9.0.0 through 9.2.0 support failover when integrated SSL processing chips fail. By default, this feature is enabled.

Note: SSL hardware failover is not supported in versions later than BIG-IP 9.2.0.

When disabled, the BIG-IP LTM will not fail over and will process SSL sessions using only the main CPU. This reduces performance for most sites.

You can enable or disable support for SSL proxy failover using the configuration utility or the command line.

Configuration utility

To enable or disable the SSL proxy failover using the Configuration utility, perform the following procedures:

Enabling SSL proxy failover

  1. From the Main tab of the Configuration utility, click System.
  2. From the menu, click High Availability.
  3. To enable SSL proxy failover, check the SSL Accelerator Failure box Under System Trigger Properties.
  4. Click Update.

Disabling SSL proxy failover

  1. From the Main tab of the Configuration utility, click System.
  2. From the menu, click High Availability.
  3. To disable SSL proxy failover, uncheck the SSL Accelerator Failure box Under System Trigger Properties.
  4. Click Update.

Command line

To enable or disable the SSL proxy failover using the command line, perform the following procedures:

Enabling SSL proxy failover

  1. From the command line, type the following command:

    bigpipe db Failover.Sslhardware enable

  2. Specify the type of action to occur upon failure, by typing the following command:

    bigpipe db Failover.Sslhardware.Action <action>

    To failover, type:

    bigpipe db Failover.Sslhardware.Action failover

    To reboot, type:

    bigpipe db Failover.Sslhardware.Action reboot

Disabling SSL proxy failover

From the command line, type the following command:

bigpipe db Failover.Sslhardware disable
