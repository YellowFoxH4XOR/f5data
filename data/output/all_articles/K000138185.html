Description

In some scenarios your users will need to select a domain from the login page or have one statically set for them to populate the session.logon.last.domain session variable for use in the Access Policy.

Environment

  • BIG-IP APM
  • Domain session variables

Cause

By default, the BIG-IP does not have a domain select on the login page.

Recommended Actions

Modify the login page in the Visual Policy Editor to include the domain selection

  1.  Login to the BIG-IP WebUI
  2. Navigate to Access --> Profiles / Policies
  3. Click on the Edit... in the Per-Session Policy column of the policy you want to modify
  4. Click on Logon Page
  5. In the middle - there will be rows 1 and 2 for username and password
  6. In Row 3 - Type: select Post Variable Name: domain Session Variable Name: domain
  7. Click on the field in the Values Column - click Add Option
  1. Add each of the Domains and the label to be shown for the name
  2. Update the Logon Page Input Field #3 so the label says Domain

When the user lands on the Login Page they will have the option to choose their domain that will populate the session.logon.last.domain session variable

Statically Assign Domain to Login Page

The only change that will need to be done on the login page is to have a Single Domain and choose "Read Only" Yes

Notice in the following APMSUPPORT is grayed out but selected
