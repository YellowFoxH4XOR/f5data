Description

This script will collects existing virtual server name and its associated details including pool names and i-Rules and save it to a CSV File.

CSV file is a comma-separated values file is a delimited text file that uses a comma to separate values. Each line of the file is a data record. Each record consists of one or more fields, separated by commas. The use of the comma as a field separator is the source of the name for this file format.

Environment

  • TMSH
  • BIG-IP LTM
  • Virtual Server

Cause

None

Recommended Actions

Follow the steps below to create script in CLI.

  1. Create a script named "virtual-details"
    tmsh create cli script virtual-details
     
  2. Switch to TMOS: type "tmsh"
     
  3. Use the "edit" command as it will open a vi editor to allow edits/creation.
    (tmos)# edit cli script virtual-details

    Contents will look like this:
    modify script virtual-details {
    proc script::run {} {
    puts "Virtual Server,Destination,Pool-Name,Profiles,Rules"
    set partition [ lindex $tmsh::argv 6 ]
    tmsh::cd \/$partition
    foreach { obj } [tmsh::get_config ltm virtual recursive all-properties] {
    set profiles [tmsh::get_field_value $obj "profiles"]
    set remprof [regsub -all {\n} [regsub -all " context" [join $profiles "\n"] "context"] " "]
    set profilelist [regsub -all "profiles " $remprof ""]
    puts "[tmsh::get_name $obj],[tmsh::get_field_value $obj "destination"],[tmsh::get_field_value $obj "pool"],$profilelist,[tmsh::get_field_value $obj "rules"]"
    }
    }
    }
     
  4. Save it.
  5. Run the script:
    tmsh run cli script virtual-details > /var/tmp/virtual-details.csv

Note:
  • There is no impact when creating and running the script.
  • F5 Support does not design or configure scripts. If you are in need of any assistance configuring a customized script to best work for your environment, F5 Professional Services and/or DevCentral can assist.
