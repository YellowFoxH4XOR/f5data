Topic

This article applies to BIG-IP 9.x - 10.x. For information about other versions, refer to the following article:

K14129: Viewing the dynamic ratio weight of a node (11.x - 12.x)

The dynamic ratio weight of a node is used to determine load balancing decisions when a dynamic ratio load balancing algorithm is employed.

You can view the dynamic ratio weight of a node from the command line by typing the command appropriate for your version:

  • BIG-IP 10.x

    bigpipe node all dynamic ratio show

  • BIG-IP 9.x

    bigpipe node dynamic ratio show

The output appears similar to the following example:

NODE 192.168.65.254 - Dynamic Ratio: 1

NODE 10.10.65.101 - Dynamic Ratio: 1

NODE 10.10.65.100 - Dynamic Ratio: 1

You can also view detailed statistics, which are used to calculate the dynamic ratio weighting. To view this information, you must enable monitor logging for SNMP DCA and SNMP DCA Base monitors.

For more information, refer to K6529: Enabling and disabling monitor logging for SNMP DCA and SNMP DCA Base monitors (9.x - 10.x).
