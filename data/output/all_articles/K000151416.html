Description

You may see log below during boot up process at the kernel logs:

WRITE SAME failed. Manually zeroing.

Environment

  • LTM
  • kern.log
  • Reboot or boot up

Cause

This log indicates that the Linux kernel experimentally tried to issue a "WRITE SAME" SCSI command to speed up zeroing data and the block layer rejected it during OS booting up phase, it finally falls back to manully zeroing for disk initilalization. Basically WRITE SAME writes the same block of data (in this case 0x00, all zero) to X number of sectors instead of issuing the commands individually (which is what it said it's falling back to doing). 

Recommended Actions

None, this message is from Linux kernel and actually informational.
