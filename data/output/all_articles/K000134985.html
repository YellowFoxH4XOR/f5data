Description

You want the BIG-IP system to send traps for the following bandwidth log:

 

Bandwidth utilization is <number of Mbps> Mbps, exceeded <%> of Licensed <number of Mbps> Mbps

 

Environment

  • BIG-IP LTM
  • SNMP

Cause

None.

 

 Recommended Actions

1. Log in to the command line.

 

2. To back up your /config/user_alert.conf file, type the following command:

# cp /config/user_alert.conf /config/user_alert.conf.SOL3727

 

3. Edit the /config/user_alert.conf file.

Add the following new SNMP trap to the file:

 

alert BIGIP_TMM_TMMERR_LICENSE_LIMIT "Bandwidth utilization is %d Mbps, exceeded %d%% of Licensed %d Mbps" {

  snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.<XXX>"

}


Note: Replace XXX with a number not used previously by your user_alert.conf file.
 

4. Save the file and exit.

 

5. Test with logger to see if you receive the SNMP trap with the following command:

 

# logger -p local0.notice "01010045:5: Bandwidth utilization is 1070 Mbps, exceeded 75% of Licensed 1000 Mbps"
