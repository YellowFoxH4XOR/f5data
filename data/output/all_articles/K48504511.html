Description

Getting an error when accessing "log-config" F5 API end-points with the guest role user. 

API Error:   {'code': 400, 'message': '"management-port" unexpected argument', 'errorStack': [], 'apiError': 26214401}

Problematic API URIs:
         mgmt/tm/sys/log-config/destination/management-port
         mgmt/tm/sys/log-config/destination/splunk
         mgmt/tm/sys/log-config/publisher
         mgmt/tm/sys/log-config/destination/management-port


The same config is accessible when logged into GUI as a guest user.

Environment

  • iControl REST API
  • Guest Role
  • /mgmt/tm/sys/log-config
  • BIG-IP

Cause

It is by design. "log-config" has access control in tmsh.

- create/delete/modify only allowed for roles: admin and resource-admin.
- list is only allowed for roles: admin, resource-admin and auditor.
 

Recommended Actions

The guest role user has no access to tmsh, you may elevate the user role to auditor

See manual chapter for your software version for additional steps:

Manual Chapter : User Roles - v12
