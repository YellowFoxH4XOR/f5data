Description

When you try to configure a domain in wideip that contains over 63 characters, the below error prompt.

0107019a:3: Wide IP or alias (abbcccddasdfasdfasdfasdfasdfasdfasdfasdfasdfasdfasdfasdfaaaaaaab.com of type A) entered is not a fully qualified domain name or contains invalid characters. Additional character support can be enabled by modifying the Domain Name Check settings. 

Environment

  • BIG-IP DNS
  • Wide IP
  • domain-name-check

Cause

The BIG-IP DNS wideip doesn't allow the charaters in domain over 63 by default.

Recommended Actions

To configure the wideip domain with the charaters over 63, you can follow the command to set the setting domain-name-check to none value.

#tmsh modify gtm global-settings general domain-name-check none
#tmsh save sys config gtm-only

Additional Information

The default value for domain-name-check is allow-underscore, however, beginning in BIG-IP 12.1.0, the BIG-IP DNS system allows the use of underscore characters in wide IP names, by default. Thus the underscore characters always are allowed even you changed the value for domain-name-check to non.
