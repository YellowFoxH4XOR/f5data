Description
When trying to export a SSL certificate's key, you may be met with a disabled "Export" button in the configuration utility GUI.
If a FIPS140-2 license is active on the BIG-IP, exporting SSL certificate keys is disabled, and this is the expected behavior.

Environment

  • BIG-IP VE
  • FIPS140-2 license applied

Cause
When a FIPS140-2 license is in use on a VE instance, exporting certificate keys from the BIG-IP is not allowed.

  1. You can check to see if you have a FIPS140-2 license in use by running:
    • # tmsh show sys license | grep FIPS
      • FIPS 140-2, i4X00/i5X00/i7X00/i10X00/i11X00/i15X00
         
  2. You can also check if FIPS140-2 is enabled by checking the security.fips140.compliance db key:
    • ?????????????????????# tmsh list sys db security.fips140.compliance 
      • ???????sys db security.fips140.compliance {
            default-value "false"
            scf-config "true"
            value "true"     <<<-- FIPS security is enabled
            value-range "false true"
        }

Recommended Actions

  1. The only way to disable FIPS140-2 is to obtain a license without the FIPS140-2 feature, and relicense the BIG-IP with the new license key.
    Note: Relicensing a BIG-IP does require downtime while the device restarts services after applying a new license.

    Additional Information
    Please see article, K91841023: Overview of the FIPS 140-2 Level 1 Compliant Mode license for BIG-IP VE, for more information.
