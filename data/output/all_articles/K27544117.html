Known Issue

The BIG-IP Edge Client Network Location Awareness (NLA) uses case-sensitive DNS suffixes.

This issue occurs when the following condition is met:

  • DNS suffixes configured on the BIG-IP system have a different case than DNS suffixes coming from the network to the BIG-IP Edge Client.

Impact

NLA fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP Edge Client establishes a network access connection instead of a direct connection to the local network.

Resolution
