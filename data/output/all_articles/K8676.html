Known Issue

This is the result of a known issue. The HTTP::header values <name> iRule command returns value(s) of the HTTP header named <name>. If multiple headers contain the same name, the HTTP::header values command returns the values all of the headers separated by a colon ( : ) character.

The HTTP::header values iRule command removes the colon characters from the header values it returns. The actual header values are unchanged.

F5 Product Development tracked this issue as CR98328 and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP LTM or ASM  release notes.

This issue still exists in the BIG-IP version 9.4.x software branch.
