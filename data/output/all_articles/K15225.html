Topic

You should consider using this procedure under the following condition:

  • You would like to enable or disable the BIG-IP or BIG-IQ software ISO file signature checking feature.

Description

Beginning in BIG-IP 11.5.0 and BIG-IQ 4.4.0, every BIG-IP and BIG-IQ software ISO image released will be accompanied by an authenticity signature (SIG) file. The SIG file enables the system to verify the ISO file authenticity before the software installation. The SIG file must be located in the /shared/images directory.

The feature is controlled by the liveinstall.checksig database key. By default, this feature is disabled.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Traffic Management Shell (tmsh).
  • You have uploaded the software and signature files to the /shared/images directory of the BIG-IP or BIG-IQ platforms or Virtual Clustered Multiprocessing (vCMP) guests.

    Note: For vCMP guests hosted on a hypervisor running version 11.6.0 and later, the image verification may not work as expected. For more information, refer to K33135278: The vCMP guest may fail to perform a BIG-IP software installation when the image verification database variable is enabled.

Procedures

Enable signature verification for BIG-IP or BIG-IQ ISO image files

Note: After you enable the liveinstall.checksig database key, to complete the installation, ensure that each installation ISO file has its accompanying signature file.

Impact of procedure: Without the correct signature file, the software installation process will fail.

  1. Log in to the tmsh utility by entering the following command:

    tmsh

  2. To enable signature checking, enter the following command:

    modify /sys db liveinstall.checksig value "enable"

  3. To save the configuration, enter the following command:

    save /sys config

  4. To exit the tmsh utility, enter the following command:

    quit

Disable signature verification for BIG-IP or BIG-IQ ISO image files

Impact of procedure: The BIG-IP or BIG-IQ ISO image file authenticity will not be checked before you install the software.

  1. Log in to the tmsh utility by entering the following command:

    tmsh

  2. To disable signature checking, enter the following command:

    modify /sys db liveinstall.checksig value "disable"

  3. To save the configuration, enter the following command:

    save /sys config

  4. To exit the tmsh utility, enter the following command:

    quit
