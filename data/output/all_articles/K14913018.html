Issue

Error Message

01470000:3: iSession: Connection error: <function>:<line_number>: <cause>:<tmm_error>

In this error message, note the following:

  • <function> is the function being executed.
  • <line_number> is the line number of the code.
  • <cause> is the cause of the error.
  • <tmm_error> is the Traffic Management Microkernel (TMM) error text.

For example:

01470000:3: iSession: Connection error: isession_handle_evt:6680: isession_handle_evt: bad transition:7

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • A fatal error occurs on an iSession tunnel. These errors can include deduplication and compression codec errors, memory management errors, and iSession protocol errors.

Impact

User tunnels are disconnected and must be re-established by the client. Control connections for symmetric data deduplication and the WAN optimization control module (wocd) are automatically re-established after a fatal connection error.

Recommended Actions

Transient errors on data deduplication control connections are common when a deduplication endpoint is initializing. If iSession connection errors persist, you should verify network connectivity between the endpoints of the iSession tunnel.
