Known Issue

The IPsec tunnel may erroneously establish on a misconfigured responder remote IP address.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured as an IPsec tunnel endpoint.
  • The responder side ipsec-policy is configured with an incorrect remote IP address.

Impact

The IPsec tunnel negotiation succeeds, however, data traffic fails to pass through the tunnel.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Internet Key Exchange (IKE) IPsec security associations (SAs) successfully establish.
  • You create the IPsec tunnel, however, data traffic fails to pass through the tunnel.
  • A tcpdump capture of the affected traffic shows Internet Control Message Protocol (ICMP) error messages similar to the following example:

    IP (tos 0x0, ttl 255, id 28642, offset 0, flags [DF], proto: ICMP (1), length: 56) 172.16.40.1 > 172.16.50.1: ICMP 172.16.40.1 protocol 50 unreachable, length 36
