Description

The dwbld (Data Watch Blacklist Daemon), autodosd, and autodiscd daemon logs cannot be forwarded to remote syslog servers using High-Speed Logging (HSL) or traditional syslog configuration on BIG-IP systems.

 

  • dwbld logs do not appear on remote syslog server despite HSL configuration
  • HSL configuration for dwbld, autodosd, or autodiscd appears successful but no logs are transmitted
  • Feed List integration logs (managed by dwbld) cannot be monitored remotely for operational alerting
  • These daemons may appear as selectable options in the HSL filter source list, but log forwarding does not function

Environment

  • BIG-IP AFM (Application Firewall Module)
  • All BIG-IP versions including 15.x, 17.x, and later
  • High-Speed Logging (HSL) configured for remote syslog
  • Feed List integration enabled
  • Remote logging or High-Speed Logging configured

Cause

By design limitation. The logging mechanism used for dwbld, autodosd, and autodiscd daemons does not support export via High-Speed Logging or traditional syslog. The information contained in these logs is primarily intended to assist F5 Product Engineering with troubleshooting and is not considered necessary for daily BIG-IP administration.

Answer/Recommended Actions

Access logs locally on BIG-IP:

The dwbld, autodosd, and autodiscd logs can be accessed locally on the BIG-IP system at the following locations:

  • dwbld logs: /var/log/dwbl/dwbld.log
  • autodosd logs:
  • autodosd logs: /shared/tmp/autodosd.out
  • autodiscd logs:
  • autodiscd logs: /shared/tmp/autodiscd.out

Alternative monitoring approaches:

If remote monitoring of these logs is required for your environment:

  • Configure custom SNMP traps for specific events (see K3727: Configuring custom SNMP traps)
  • Implement external log collection scripts that read local log files and forward them to your monitoring system

Request enhancement:

If remote logging of specific dwbld log messages is business-critical:

  • Contact your F5 account team to initiate a Customer Special Request (CSR) process
  • Reference Bug ID 2208769 which tracks the enhancement request for enabling remote logging of dwbld messages
