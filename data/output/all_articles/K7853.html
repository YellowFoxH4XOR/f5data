Known Issue

This is the result of a known issue. A Certificate Revocation List Distribution Point (CRLDP) authentication module can be used on the BIG-IP LTM to authenticate client traffic using the CRLDP protocol. The purpose of a CRLDP authentication module is to manage the revocation of client SSL certificates on a network. Currently, it is not possible to disable CRL signature verification on the BIG-IP LTM.

F5 Product Development tracked this issue as CR75624, and it was fixed in BIG-IP LTM 9.4.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Disabling CRL signature checking

In BIG-IP LTM 9.4.1, you can disable CRL signature checking by performing the following procedure:

  1. Log in to the BIG-IP LTM command line.
  2. To create the new database key, type the following command:

    bigdb_create tamd.crldp.nosignature

  3. To enable the nosignature key that will disable CRL signature verification for the system, type the following command:

    bigpipe db tamd.crldp.nosignature enable

Note: You can resume CRL signature checking by typing the following command:

bigpipe db tamd.crldp.nosignature disable
