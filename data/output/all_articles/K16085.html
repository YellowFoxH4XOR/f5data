Known Issue

Using the BIG-IP APM VMware View remote desktop may cause the Traffic Management Microkernel (TMM) to exit and restart.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM system with VMware View remote desktop application access.
  • Users attempt to start a remote desktop session through the BIG-IP APM system.

Impact

The BIG-IP APM system may incur memory corruption, which could eventually deplete the TMM memory, causing the TMM to exit and restart.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP APM system fails over to the standby system if configured for high availability (HA).
  • The BIG-IP APM system generates TMM core files to the /shared/core directory.
  • A stack trace is generated to the /var/log/tmm* files.
  • A message is generated to the /var/log/tmm* files that appears similar to the following example:

    notice panic: umem_btfree_validate: redzone err (obj = 0x570009b1b210, redzone = 0x1122334455000000, diff = 0x 667788)
