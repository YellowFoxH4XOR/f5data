K000136932: Unable to access MyF5 using Multi-factor authentication (MFA)

Type
Support Solution
Published
2023-09-21
Updated
2024-01-26
Applies to
  • Support Portal
Source
https://my.f5.com/manage/s/article/K000136932

Description

Some MyF5 users with MFA having intermittent access issues.

You may experience the following symptoms:

  • Blank page
  • Error message:

    There was an unsupported response from server
    Try to reset the password or visit the Login Help page for more information

Environment

  • multifactor authentication (MFA)
  • MyF5

Cause

Unknown at the time of publishing

Recommended Actions

Review the following scenarios to troubleshoot MyF5 access problems.

Scenario 1: Browser displays an old or outdated page

Solution: Clear the cache. If you see an old page, clear the cache to refresh the page. To do so, refer to the instructions for your browser:

  • Firefox: https://support.mozilla.org/en-US/kb/how-clear-firefox-cache
  • Chrome https://support.google.com/accounts/answer/32050
  • Edge: https://support.microsoft.com/en-us/microsoft-edge/delete-cookies-in-microsoft-edge-63947406-40ac-c3b8-57b9-2a946a29ae09
  • Internet Explorer: https://support.microsoft.com/en-us/topic/view-and-delete-your-browsing-history-in-internet-explorer-098ffe52-5ac9-a449-c296-c735c32c8678

Note: These links take you to resources outside of MyF5. The third parties could remove the documents without our knowledge.

Scenario 2: You can't log in to a specific browser

Solution: Use Incognito mode or uninstall browser plugins

If login issues persist, try opening the browser in Incognito mode. This action disables plugins that might be causing the issue. If this method works, clear the cache again. If the problem persists, you should uninstall browser plugins. To use Incognito mode, refer to the instructions for your browser:

  • Firefox: https://support.mozilla.org/en-US/kb/private-browsing-use-firefox-without-history#w_how-do-i-open-a-new-private-window
  • Chrome: https://support.google.com/chrome/answer/95464
  • Edge: https://support.microsoft.com/en-us/microsoft-edge/browse-inprivate-in-microsoft-edge-cd2c9a48-0bc4-b98e-5e46-ac40c84e27e2#
  • Internet Explorer: https://support.microsoft.com/en-us/microsoft-edge/browse-inprivate-in-microsoft-edge-e6f47704-340c-7d4f-b00d-d0cf35aa1fcc

Note: These links take you to resources outside of MyF5. The third parties could remove the documents without our knowledge.

If the previous steps do not resolve the issue, please contact F5 Support for further assistance.
