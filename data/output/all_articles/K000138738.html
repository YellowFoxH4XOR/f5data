Description

Windows 10 changes announced in October 10, 2023—KB5031356 (OS Builds 19044.3570 and 19045.3570) and November 14, 2023—KB5032189 (OS Builds 19044.3693 and 19045.3693) may cause limited F5 VPN connectivity.

Edge Client establishes the VPN tunnel successfully, connection looks stable, but no traffic goes through the VPN. After some time, the problem may resolve itself and web traffic works normally. 

 Environment

  • BIG-IP
  • VPN
  • Windows 10
  • Edge Client

 Cause

This is known Microsoft issue.

 Recommended Actions

Open a ticket to Microsoft Support and request Microsoft Software Installer file, which modifies registry key as a workaround.

 Additional Information

Final solution is still in experimental state and should be included in an official update package around the middle of this year by Microsoft.
