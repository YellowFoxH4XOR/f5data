Description

This article describes how to remove a Standby BIG-IQ and reset to factory defaults. After the recommended actions the BIG-IQ will be fully reset but will retain the management interface network setup and the license.

Environment

  • BIG-IQ CM
  • BIG-IQ DCD
  • BIG-IQ HA Cluster
  • Command-Line access

Cause
None

Recommended Actions

  1. On Primary CM1 needs to set as standalone:

    ha_reset -f  <Discovery IP>

  2. Reset Secondary BIG-IQ Central Management

    ha_reset -f  <Discovery IP>
    clear-rest-storage -d -l

    Note: -d option will reset Big-IQ master key as well 
  3. Complete the setup wizard after logging into the GUI
