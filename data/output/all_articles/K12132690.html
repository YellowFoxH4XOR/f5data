K12132690: SSLO - gossipworker starts on box even before SSLO is configured

Type
Support Solution
Published
2023-03-31
Updated
2023-03-31
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator: 14.1.X, 14.1.4, 14.1.2, 14.1.0
Source
https://my.f5.com/manage/s/article/K12132690

Description

An admin may see error messages from gossipworker or similar SSL Orchestrator (SSLO) related items in restjavad.0.log even before sslo is "activated" (by browsing to the SSLO menu in admin GUI) on the box, typically after the HA pair is configured.


Environment

  • SSLO
  • HA Configured


Cause

These messages are not indicative of any problem before SSLO is configured.
 

Recommended Actions

The admin can proceed to set up SSLO as per the usual process at this point.

Additional Information
