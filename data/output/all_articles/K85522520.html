Known Issue

The Traffic Management Shell (tmsh) show virtual detail command may produce an error.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM system with an access profile that references an application access exchange profile.
  • You configure the access policy of the virtual server with the access profile.
  • You use the following tmsh command to view the statistic details of the virtual server.

    show /ltm virtual <virtual server name> detail

Impact

The tmsh command produces an error and the virtual server details do not render.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When executing the tmsh command, the system displays an error message that appears similar to the following example:

    01020036:3: The requested profile exchange: virtual server object (/<path>/<exchange access profile name>:/<path>/<virtual server name>) was not found.
