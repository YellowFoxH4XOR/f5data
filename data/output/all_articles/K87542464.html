Description
When trying to add or change a GTM pool parameter the GUI returns 'No Access'

Environment

  • DNS (previously known as GTM)
  • Trying to add or change a GTM pool parameter the GUI returns 'No Access'

Cause
Bug ID1062513 (GUI returns 'no access' error when modify a GTM pool parameters)
Note: At this time there is no public facing documentation at this time.

Recommended Actions
Follow either of the workarounds stated below:

  1. Use TMSH commands to make a change to the GTM pool
    (OR)
  2. Click "Update" a second time (twice) to commit the change successfully
