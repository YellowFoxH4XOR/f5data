Issue

Error Message

info mcpd[<PID>]: 01071528:6: Device group '<name>' inconsistent, <message>.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <name> is the partition and name of the affected device group
  • <message> is a message providing additional information about the sync failure

For example:

info mcpd[5852]: 01071528:6: Device group '/Common/failover_device_group' inconsistent, Sync status may not be consistent.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You configure BIG-IP systems in a Sync-Failover device group
  • One of the BIG-IP systems in the device group fails to complete a ConfigSync operation

This message indicates the configuration failed to fully synchronize to the device group peer, which affects the sync status for the device group. You can check the sync status using the tmsh show /cm sync-status command. When the configuration is synchronized, output should appear similar to the following example:

--------------------------------------------------------------------------------
CM::Sync Status
--------------------------------------------------------------------------------
Color    green
Status   In Sync
Mode     high-availability
Summary  All devices in the device group are in sync
Details
         ltm1.example.com: connected
         sync_failover_group (In Sync): All devices in the device group are in sync
 

Impact

The configuration is no longer synchronized between device group members, which may cause unexpected behavior or a traffic disruption if a failover occurs.

Recommended Actions

For the ConfigSync process to function properly, device service clustering must be setup correctly and the communication channel used for ConfigSync must be functional. To troubleshoot ConfigSync, refer to K13946: Troubleshooting ConfigSync and device service clustering issues (11.x - 12.x).
