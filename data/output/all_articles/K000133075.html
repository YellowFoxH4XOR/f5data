K000133075: Scheduled backup error message due to license validation failure

Type
Support Solution
Published
2023-03-20
Updated
2023-08-05
Source
https://my.f5.com/manage/s/article/K000133075

Description

  • You are trying to create a scheduled backup, but it fails with the following error message:

[WARN][10 Jan 2000 01:00:00 CET][/shared/group-task DeviceGroupTaskCollectionWorker] Failed to start task on Hostname.example.com: java.lang.IllegalArgumentException: License validation failed. 93 devices were added and the current license limit is 0

 

in: /var/log/restjavad.log folder

 

Environment

  • BIG-IQ CM
  • BIG-IP

Cause

The license you have does not allow scheduled backups.

You can check your license by running the following command in TMSH "show /sys license detail". The "License Manager" license only allows your BIG-IQ to manage the licenses on the BIG-IP devices.

 

Example: show /sys license detail

Sys::License
Licensed Version 8.1.0
Registration Key xxxxx-xxxxxx-xxx-xxxxxxx-xxxxxxx
Licensed on 02/02/2022
Service Check Date 02/02/2022
Platform ID Z100
Active Modules
BIQ, VE, License Manager

 

 Recommended Actions

Upgrade your license
