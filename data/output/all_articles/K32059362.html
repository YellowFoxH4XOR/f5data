K32059362: Multiple reverse DNS requests are seen for 2.2.4.127.in-addr.arpa

Description
Multiple reverse DNS queries for the record 2.2.4.127.in-addr.arpa to the configured DNS server are seen when traffic is captured on BIG-IP like below with a response indicating that no such name was found.  
Standard query 0x3895 PTR 2.2.4.127.in-addr.arpa
Standard query response 0x3895 No such name PTR 2.2.4.127.in-addr.arpa SOA example.com

Error messages like below are seen in /var/log/restjavad-audit.0.log.  

[I][1348658][05 Jan 2022 11:24:10 UTC][ForwarderPassThroughWorker] {"user":"local/f5hubblelcdadmin","method":"GET","uri":"http://localhost:8100/mgmt/tm/sys/failover",
"status":400,"from":"127.4.2.2"}

These might be seen as well in /var/log/touchscreen_lcd log files.

Jan  5 15:39:33:Oct 19 17:14:26 127.4.2.2 err lcdui[1236]: URL: http://127.4.2.1/mgmt/tm/sys/failover, result: 'Error downloading http://127.4.2.1/mgmt/tm/sys/failover - server replied: Bad Request' (299), HTTP method 2, status 400

Environment

  • iSeries 4000
  • Shuttle family
  • Reverse lookups for 127.4.2.2

Cause
The LCD screen on shuttle platforms has the IP address 127.4.2.2 and can periodically send logs to Syslog-ng on the BIG-IP with this source address. The syslog-ng is configured to use DNS to resolve the hostname based on the source IP address for incoming messages, so the BIG-IP does a reverse lookup for 127.4.2.2 whenever a log message is received from the touchscreen.  This address is not resolvable and logs messages in /var/log/touchscreen_lcd appear with 127.4.2.2 as their hostname.

This is addressed in bug ID1026813. 

Recommended Actions
To work around the issue, add an entry for the LCD hostname.

Procedures 

Command-Line:

  1. Log in to BIG-IP CLI.
  2. Add an entry for the LCD to /etc/hosts by modifying the 'remote-host' global settings, by running the following tmsh command:
    #tmsh modify sys global-settings remote-host add { lcd { addr 127.4.2.2 hostname lcd } } 
    #tmsh save sys config

Configuration-Utility:

  1. Log in to the Configuration utility. 
  2. Navigate to System --> Configuration -->Device -->Hosts
  3. Add an entry for the 'lcd'  as hostname and the IP address as 127.4.2.2. 
  4. Update.
