K000160562: F5 VELOS Chassis | Stale LOP Alert Handler Errors

Type
Support Solution
Published

Updated
2026-04-07
Applies to

Source
https://my.f5.com/manage/s/article/K000160562

Description

LOP (Local Operator Panel) alert handler errors appear on an F5 VELOS Chassis blade. The errors are characterized by stale LOP alarms that persist after the upgrade, impacting system monitoring and alerting.
You can noticed the "LOP USB error" from command "show system health" from controller.

blade/services/diag-agent/alert-manager - alert-manager:lop:alert-handler:analog Diag-agent is able to initialize the analog LOP alert handler unhealthy error LOP Analog Alert Handler initialization error

Environment

  • F5OS software version: 1.8.2
  • Recent action: Firmware upgrade performed prior to issue

Cause

The stale LOP alarms persisting on the system, resulting in transient alert handler errors. Restarting the diag-agent docker container on the affected blade clears the stale alarms and restores normal alert handling.

Answer/Recommended Actions

  1. Restart the diag-agent docker container on the affected blade:
    ssh blade-<blade_number> 
docker container restart diag-agent

    Important: Restarting diag-agent should not have a negative impact, however, F5 always recommend to perform any activities during the maintenance window

  2. Monitor the system to confirm that LOP errors are cleared and normal alerting is restored.
  3. If similar issues occur please contact F5-Support.

Additional Information

None.
