Topic

Beginning in NGINX Plus R24, released on April 27, 2021, the NGINX Plus software repository format has changed. Before upgrading from previous NGINX Plus versions or installing new NGINX modules on an existing system, you must first remove any previous NGINX Plus repository configuration on your host system.

Note: This article does not apply to new installations of NGINX Plus R24. When performing a new installation of NGINX Plus R24, refer to the Installing NGINX Plus instructions in the Admin Guide.

Description

Prior to NGINX Plus R24, there was a single software repository configured at plus-pkgs.nginx.com. Beginning in version R24, the software repository you use depends on the products tied to your subscription.

Procedures

Depending on your host system's operating system, use one of the following procedures to reconfigure the software repository. After this procedure is complete, follow the Upgrading NGINX Plus instructions in the Admin Guide to upgrade your system.

  • Alpine Linux
  • Amazon Linux
  • Amazon Linux 2
  • CentOS 7/Oracle Linux 7/RHEL 7
  • CentOS 8/Oracle Linux 8/RHEL 8
  • Debian
  • Ubuntu
  • SLES 12
  • SLES 15

Alpine Linux

Impact of procedure: Syntax errors in the following commands will prevent your system package manager from connecting to the software repositories.

  1. Log in to the command line of the NGINX host system using administrative privileges.
  2. Update the main NGINX Plus repository configuration by entering the following command:

    printf "https://pkgs.nginx.com/plus/alpine/v`egrep -o '^[0-9]+\.[0-9]+' /etc/alpine-release`/main\n" | sudo tee -a /etc/apk/repositories

  3. For systems with an NGINX App Protect subscription, update the App Protect repository configuration by entering the following command:

    printf "https://pkgs.nginx.com/app-protect/alpine/v`egrep -o '^[0-9]+\.[0-9]+' /etc/alpine-release`/main\n" | sudo tee -a /etc/apk/repositories

  4. For systems with an NGINX ModSecurity subscription, update the ModSecurity repository configuration by entering the following command:

    printf "https://pkgs.nginx.com/modsecurity/alpine/v`egrep -o '^[0-9]+\.[0-9]+' /etc/alpine-release`/main\n" | sudo tee -a /etc/apk/repositories

  5. Update the package manager cache information by entering the following command:

    sudo apk update

Amazon Linux

Impact of procedure: Syntax errors in the following commands will prevent your system package manager from connecting to the software repositories.

  1. Log in to the command line of the NGINX host system using administrative privileges.
  2. Update the main NGINX Plus repository configuration by entering the following command:

    sudo wget -P /etc/yum.repos.d https://cs.nginx.com/static/files/nginx-plus-amazon.repo

  3. For systems with an NGINX ModSecurity subscription, update the ModSecurity repository configuration by entering the following command:

    sudo wget -P /etc/yum.repos.d https://cs.nginx.com/static/files/modsecurity-amazon.repo

  4. Clean up package manager cache information by entering the following command:

    sudo yum clean all

Debian

Impact of procedure: Syntax errors in the following commands will prevent your system package manager from connecting to the software repositories.

  1. Log in to the command line of the NGINX host system using administrative privileges.
  2. Download the 90pkgs-nginx file and save it to the /etc/apt/apt.conf.d directory by entering the following command:

    sudo wget -P /etc/apt/apt.conf.d https://cs.nginx.com/static/files/90pkgs-nginx

  3. Update the main NGINX Plus repository configuration by entering the following command:

    printf "deb https://pkgs.nginx.com/plus/debian `lsb_release -cs` nginx-plus\n" | sudo tee /etc/apt/sources.list.d/nginx-plus.list

  4. For systems with an NGINX App Protect subscription, update the App Protect repository configuration by entering the following two commands:
    1. printf "deb https://pkgs.nginx.com/app-protect/debian `lsb_release -cs` nginx-plus\n" | sudo tee /etc/apt/sources.list.d/nginx-app-protect.list
    2. printf "deb https://pkgs.nginx.com/app-protect-security-updates/debian `lsb_release -cs` nginx-plus\n" | sudo tee -a /etc/apt/sources.list.d/nginx-app-protect.list
  5. For systems with an NGINX ModSecurity subscription, update the ModSecurity repository configuration by entering the following command:

    printf "deb https://pkgs.nginx.com/modsecurity/debian `lsb_release -cs` nginx-plus\n" | sudo tee /etc/apt/sources.list.d/nginx-modsecurity.list

  6. Update the package manager cache by entering the following command:

    sudo apt update

SLES 12

Impact of procedure: Syntax errors in the following commands will prevent your system package manager from connecting to the software repositories.

  1. Log in to the command line of the NGINX host system using administrative privileges.
  2. Remove previously configured repositories by entering the following command:

    sudo zypper rr nginx-plus

  3. Add the new NGINX Plus repository by entering the following command:

    sudo zypper ar -G -t yum -c 'https://pkgs.nginx.com/plus/sles/12?ssl_clientcert=/etc/ssl/nginx/nginx-repo-bundle.crt&ssl_verify=peer' nginx-plus

  4. For systems with an NGINX ModSecurity subscription, update the ModSecurity repository configuration by entering the following command:

    sudo zypper ar -G -t yum -c 'https://pkgs.nginx.com/modsecurity/sles/12?ssl_clientcert=/etc/ssl/nginx/nginx-repo-bundle.crt&ssl_verify=peer' nginx-modsecurity
