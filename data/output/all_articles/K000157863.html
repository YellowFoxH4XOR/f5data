Description

Unable to access the BIG-IP LTM web GUI after updating the device certificate. CLI access remained functional. The issue was traced to an incorrectly loaded device certificate, which disrupted GUI authentication.

 

Environment

Updating BIG-IP Device certificates incorrectly or with wrong certificates

 

Cause

The root cause was an incorrectly loaded device certificate, which prevented GUI authentication. Replacing the certificate with the correct one restored GUI access.

 

Recommended Actions

Overwrite the incorrect device certificate (server.crt) and key (server.key) files with the correct content using CLI commands. You can edit the files in place, or remove these files and copy the correct ones onto the system naming them server.crt and server.key in the proper locations.

These are the locations.

/config/httpd/conf/ssl.crt/server.crt
/config/httpd/conf/ssl.key/server.key

After overwriting these files, restart httpd service:

tmsh restart sys service httpd

Verify GUI access after certificate replacement.

Ensure future certificate updates use the correct certificate file and follow documented procedures to prevent authentication issues.
