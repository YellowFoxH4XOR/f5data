K000148804: BIG-IQ schedule remote backup failing for BIG-IP

Type
Support Solution
Published
2024-12-03
Updated
2025-02-07
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000148804

Description

You are trying to set up a scheduled backup, but the backup is failing.


You see below error message in BIG-IP :


/var/log/restjavad.0.log


mv: error writing '/var/local/ucs/schedule-LTMs-DMZ-Layer2_$hostname_20241117003000.ucs': No space left on device


mv: failed to extend '/var/local/ucs/schedule-LTMs-DMZ-Layer2_$hostname_20241117003000.ucs': No space left on device



Environment

  • BIG-IQ
  • Managed BIG-IP's


Cause

Not enough disk space in the /var partition



Recommended Actions

Free some space in /var partition on the BIG-IP :

  •  Delete ucs backup archive 
  • Extend disk space for /var partition

Additional Information

None
