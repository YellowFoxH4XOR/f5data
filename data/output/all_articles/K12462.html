Topic

This article provides an overview of the F5 Access for iOS application for the Apple iPhone, iPad, and iPod touch. The F5 Access for iOS application devices provides full Virtual Private Network (VPN) access to servers behind BIG-IP APM devices.

For information about which features are available for other BIG-IP APM client applications, refer to K23653432: BIG-IP APM client feature matrix.

Description

F5 Access is a lightweight app available from the Apple App Store for download and install. It is used to establish VPN access to the BIG-IP APM.

F5 Access for iOS application features

The F5 Access for iOS application features include:

  • Localized user interface for English, French, German, Spanish, Japanese, Korean, Simplified Chinese, and Traditional Chinese
  • N-factor authentication support (at least two input fields, such as password and passcode)
  • Username/password, client certificate, and RSA SecurID support
  • Multiple input field support
  • Credential caching support
  • Split tunneling support
  • Support for checking information from client devices
  • Support for automatic launch of applications on client devices
  • Support for roaming between 3G and WiFi networks
  • Support for private-side internal proxy servers
  • Support for SAML 2.0 features in BIG-IP APM
  • Landing URI support
  • Logging support to report issues
  • Support for IPv6 servers and tunnels with devices running iOS 5 and higher
  • Per-App VPN support for iOS devices running version 7 and higher
  • Detection of jailbroken devices

    Note: The feature that detects jailbroken devices is only available on BIG-IP APM systems running BIG-IP 11.3.0 and later.

This application is a lightweight client for iOS access to the BIG-IP APM controller. You can download the F5 Access for iOS application from the Apple iTunes App store from the following locations:

  • F5 Access 3.x.x
  • F5 Access Legacy

F5 Access log files
The F5 Access app logs information in the following files:

  • ~/Library/Group\ Containers/*group.com.f5.access.macos/Application.log
  • ~/Library/Group\ Containers/*group.com.f5.access.macos/PacketTunnel.log

The Application.log file logs information related to configuration management, prompts for login credentials, and VPN state monitoring. The PacketTunnel.log file logs information related to VPN traffic tunneling and BIG-IP APM authentication.

Removing F5 Access from iOS

  1. Tap and hold on the F5 Access icon until it begins to jiggle.
  2. Tap (X) in the upper left corner.
  3. When prompted to delete the app and its data, tap Delete.
