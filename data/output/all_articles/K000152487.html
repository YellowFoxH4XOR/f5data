Description

BIG-IP Virtual Edition (VE) deployment on Azure Local (formerly known as Azure Stack HCI) is officially supported by F5.

Environment

  • Product: BIG-IP Virtual Edition (VE)
  • Platform: Azure Local (also known as Azure Stack HCI), based on Hyper-V

Cause

BIG-IP VE has been qualified by F5 on Azure Local (Azure Stack HCI).

Recommended Actions

Azure Stack HCI (Azure Local) supports BIG-IP Virtual Edition Version 17.5.x, 17.1.2.x, 17.1.1.x and 17.1.0.x. Refer to the Hyper-V setup guide Microsoft Hyper-V: BIG-IP Virtual Edition Setup for deployment best practices.
