Description

Configuring SNMPv3 trap destinations via CLI on rSeries.

Environment

F5OS-A

Cause

NA

Recommended Actions

If you are going to use SNMPv3, you should set up a SNMP user first. You can use the following command:

system snmp users user <user-name>
config authentication-protocol <authentication-protocol> authentication-password
config privacy-protocol <privacy-protocol> privacy-password
system snmp targets target <target-name> config ipv4 address <ip-address> port <port-number>
commit

Additional Information

F5OS-A accepts a maximum of 32 character in target-name.
