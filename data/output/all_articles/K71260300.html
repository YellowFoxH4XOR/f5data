K71260300: Cannot choose the Release Offline option

Type
Support Solution
Published
2022-03-03
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K71260300

Description
A BIG-IP device is manually set to offline, and after performing all the desired changes, you try to release it from offline using the following procedure.

  • Go to Device Management > Devices.
  • Select the local device (Self).
  • Attempt to click the Release Offline button.
However, the Release Offline button is grayed out and unavailable.

Environment

  • BIG-IP manually set to offline
  • Release offline

Cause
When you are NOT located on the partition Common, you cannot perform the release offline operation. This is by design. 

Recommended Actions

  1. Make sure that you are located under the partition Common
  • On the top-right corner, locate the drop-down box that is labeled Partition. Then, switch it to Common.
  1. If the Partition drop-down box is grayed out and it Does Not read Common.
  • Navigate to a different screen. For instance, in the left-hand side panel, select Local Traffic, then Virtual Servers. The Partition drop-down box now becomes available.
  1. Try to release the Offline again. This time the button will be available.
