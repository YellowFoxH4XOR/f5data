Description

The update_bigip.sh script fails to upgrade REST framework on destination BIG-IP

Environment

  • BIG-IQ 5.4
  • Multi-blade VIPRION or vCMP system running BIG-IP 11.5.x or 11.6.x
  • Upgrade REST framework when discovering the multi-blade VIPRION or vCMP system
Cause

The IP address specified for the update_bigip.sh script was the cluster management IP of the destination BIG-IP system

Recommended Actions

When using the update_bigip.sh script, specify the cluster member IP as a parameter.
