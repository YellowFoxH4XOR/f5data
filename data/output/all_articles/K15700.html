Topic

Changing the BIG-IP host name does not update the device name when the device is a member of a Device Service Clustering (DSC) device group.

Description

When you change the host name of a standalone BIG-IP system, both the host name and the device name are updated. However, if the system is a member of a device group, the device name is not automatically updated because it would affect the device trust established between device group members.

Note: Starting in BIG-IP 13.0.0, changing the host name of a standalone BIG-IP system no longer updates the device name automatically. This is an expected behavior.

Recommendations

While it does not affect the BIG-IP system's functionality to have the host name and device name not match, you may want to see the new host name in all configuration instances.

When changing the host name for a member (or members) of a device group, if you want the device name to match the new host name, you must perform all of the following procedures:

For more information refer to K26057357: Changing the BIG-IP system hostname.

  • Resetting the device trust across all devices
  • Changing the device name
  • Re-adding the devices to the device group
  • Performing a ConfigSync (optional)

Resetting device trust across all devices

To change the device name, you must first remove the device from the device group by resetting the device trust for the device. To reset the device trust across all devices, perform the following procedure on all devices in the device group.

Impact of procedure: F5 recommends that you perform this procedure during a maintenance window. This procedure causes the current device to lose connectivity with all other BIG-IP devices. Depending on the device group and traffic group configuration, the connectivity loss may result in an unintentional Active-Active condition that causes a traffic disruption. For appliance platforms only (non-VIPRION platforms), you can prevent a standby device from going active by setting the standby device in the device group to Force Offline before performing the procedure. Standby devices that were set to Force Offline should be set to Release Offline after performing the procedure.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Device Trust > Local Domain.
  3. Click Reset Device Trust.
  4. For Certificate Signing Authority, click Generate New Self-Signed Authority.
  5. Click Update.
  6. Click OK.
  7. Repeat this procedure for each device in the device group.

Changing the device name

After you have reset the device trust across all devices in the device group, you can update the device name for each device that needs to be changed. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Navigate to Device Management > Devices.
  2. Click the (Self) device name. (This should be the only device listed.)
  3. Click Change Device Name.
  4. For New Name, type the new device name.
  5. For Certificate Signing Authority, click Generate new self-signed authority.
  6. Click Update.
  7. Repeat this procedure for each device in the device group.

Re-adding the devices to the device group

After you update the device name for all devices that you need to change, you can re-add the devices to the device group. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Navigate to Device Management > Device Trust > Local Domain.
  2. Click the Device Trust Members tab.

    Note: For BIG-IP 11.0.0 through 11.1.0, scroll to Peer Authority Devices or Subordinate Non-Authority Devices.

  3. Click Add.
  4. For Device Type, click the appropriate device type.
  5. Fill in Device IP Address, Administrator Username, and Administrator Password for the remote BIG-IP device and click Retrieve Device Information.

    Note: For BIG-IP 11.0.0 through 11.1.0, click Next.

  6. Verify that the certificate and the remote device name are correct, and then click Finished.

    Note: In BIG-IP 11.0.0 through 11.1.0, click Next and advance through the remaining pages.)

  7. Navigate to Device Management > Device Groups.
  8. Click the device group to which you want to add the new member.
  9. For Members, move the new member from the Available list to the Includes list.

    Note: For BIG-IP 11.0.0 through 11.1.0, click Add.

  10. Click Update.

    Note: For BIG-IP 11.0.0 through 11.1.0, select the check box for the new member, and then click Add.

Performing a ConfigSync (optional)

Perform a ConfigSync operation to ensure that the device trust across members of the device group is functioning properly. To do so, perform the following procedure:

  1. Navigate to Device Management > Overview.
  2. Under Device Groups, click the name of the device group you want to synchronize.
  3. Under Devices, click the appropriate device.
  4. For Sync Options, click the appropriate synchronization operation.
  5. Click Sync.
