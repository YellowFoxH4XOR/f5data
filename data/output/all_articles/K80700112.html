Description
After an Attack Signature Update (ASU), you may notice that some existing signatures were removed from the system and no longer exist in security policies. When using the Configuration Utility to view the readme in Security  ››  Security Updates : Application Security, you see the following list of deleted signatures:

Deleted Non-browser client signature 200021001 for Automated client access "snoopy"
Deleted Non-browser client signature 200021067 for Automated client access "disco"
Deleted Non-browser client signature 200021069 for Automated client access "wget"
Deleted Non-browser client signature 200021070 for Automated client access "libwww"
Deleted Non-browser client signature 200021072 for Automated client access "pavuk"
Deleted Non-browser client signature 200021075 for Automated client access "curl"
Deleted Non-browser client signature 200021078 for Automated client access "netants"
Deleted Non-browser client signature 200021092 for Automated client access "perl" (corrected)
Deleted Non-browser client signature 200021093 for Automated client access (Jakarta)
Deleted Non-browser client signature 200021094 for Automated client access (Java)
Deleted Non-browser client signature 200021095 for Automated client access (GT::WWW)
Deleted Non-browser client signature 200021096 for Automated client access (HTTP::Lite)
Deleted Non-browser client signature 200021097 for Automated client access (PECL::HTTP)
Deleted Non-browser client signature 200021098 for Automated client access (PHP/)
Deleted Non-browser client signature 200021100 for Automated client access (URI::Fetch)
Deleted Non-browser client signature 200021101 for Automated client access (urllib)
Deleted Non-browser client signature 200021102 for Automated client access (http client)
Deleted Non-browser client signature 200021103 for Automated client access (Zend_Http_Client)
Deleted Non-browser client signature 200021134 for Automated client access "Microsoft Office Protocol Discovery"
Deleted Non-browser client signature 200021135 for Automated client access "Microsoft Office Existence Discovery"
Deleted Non-browser client signature 200021136 for Automated client access "Microsoft-WebDAV-MiniRedir"
Deleted Non-browser client signature 200021137 for Automated client access "ms-office"
Deleted Non-browser client signature 200021140 for Automated client access (WordPress)

Environment

  • BIG-IP ASM v12+
  • Attack Signature Update was recently performed

Cause
Signatures which were only intended to be included for BIG-IP version 11.x were mistakenly included in ASM-SignatureFile_20200130_174340 ASU. They have been removed in ASM-SignatureFile_20200303_160717 ASU.

Recommended Actions
None. There is no risk in disabling these signatures in a security policy on BIG-IP ASM versions 12 and later.

Additional Information
None.
