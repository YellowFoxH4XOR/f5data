K41576970: LACP enabled trunk interface remains inoperative (DOWN) on BIG-IP 5200 (C109)

Type
Support Solution
Published
2023-03-20
Updated
2025-02-04
Applies to
  • BIG-IP Platforms
Source
https://my.f5.com/manage/s/article/K41576970

Description

  •  LACP enabled trunks remains inoperative (DOWN) on BIG-IP 5200 platform (C109).
  • Logical interfaces aggregated in trunk interfaces remains in UP/connected state.

Environment

  • BigIP is configured with trunk interface with lacp enabled protocol.

  • Following error messages are being reported to /var/log/ltm
    Apr 20 03:09:06 Hostname err lacpd[7085]: 01290003:3: HalmsgTerminalImpl_::sendMessage() Unable to send to any BCM56XXD address
    Apr 20 03:09:06 Hostname err lacpd[7085]: 01160005:3: HalMsgHandler.cpp:125 - HAL send PDU request failed
    Apr 20 03:09:09 Hostname err lldpd[6730]: 01290003:3: HalmsgTerminalImpl_::sendMessage() Unable to send to any BCM56XXD address
    Apr 20 03:09:09 Hostname err lldpd[6730]: 01570004:3: HAL send PDU request failed

Cause

bcm56xxd receives LACP frames on the wire from upstream device but doesn't "report" them to lacpd via the open unix domain socket.

Recommended Actions

Run following command to restart processes:

bigstart restart bcm56xxd lldpd lacpd

Impact of procedure: This will cause all interfaces to be restarted which could be traffic impacting.

Additional Information

This is result of known issue: ID1009337 (bcm56xxd to lacpd communication failure over unix domain socket).
