Issue

Error Message

011f0012:3: HTTP profile option <name> incompatible with proxy_type.  Using default instead.

In this error message, note the following:

  • <name> is the name of the incompatible setting in the HTTP profile

For example:

011f0012:3: HTTP profile option passthrough.oversize_server_header incompatible with proxy_type.  Using default instead.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You configure a virtual server with an HTTP profile
  • The HTTP profile is configured with non-default values for settings that incompatible with the configured proxy mode.

You can configure an HTTP profile to use Reverse, Explicit, and Transparent proxy modes. Some profile options are only available when using certain proxy modes and are incompatible with other proxy modes. The system generates this message when you attempt to apply an HTTP profile configured with settings that are incompatible with the current proxy mode. For example, enforcement settings with non-default values are configured and the proxy mode is not set to Transparent.

Impact

The BIG-IP system uses the default value for the incompatible HTTP profile setting, rather than the configured value.

Recommended Actions

To mitigate this issue, you can modify the incompatible setting to its default value or a value that is compatible with the proxy mode, or you can modify the proxy mode for the profile.

For more information about HTTP profile settings, refer to the Services Profiles chapter of the BIG-IP Local Traffic Management: Profiles Reference guide.
