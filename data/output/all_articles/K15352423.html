Known Issue

If you configure a virtual server to use a rewrite profile, the virtual server may fail to process Layer 3 (L3) traffic.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP system with Virtual Clustered Multiprocessing (vCMP) guests.
  • You allocate a vCMP guest with 10 CPU cores.
  • You configure a virtual server on the vCMP guest with a rewrite profile.
  • Users attempt to connect to the virtual server.

Impact

Users cannot connect to the virtual server.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/ltm file, you observe error messages similar to the following examples:

    crit tmm1[<pid>]: 01000025:2: Device error: mpi failed to allocate shared memory
    err tmm1[<pid>]: 01480043:3: Failed to build plugin profile for /<partition>/rewriteplugin
    err tmm1[<pid>]: 01480002:3: Can't initialize plugin configuration
    crit tmm1[<pid>]: 01000203:2: Proxy failed to attach plugin rule
    err tmm1[<pid>]: 01000008:3: Proxy initialization failed for /<partition>/<virtual server name>

  • In the /var/log/tmm file, you observe repetitive messages similar to the following example:

    notice <tmm number>: share_mem: shmget(0x138509, 657664, 0x3b6): Invalid argument

  • When you analyze the network-level communications of the affected virtual server, you notice that user requests do not receive L3 network responses.
  • When you remove the rewrite profile from the affected virtual server's configuration, you observe network-level communication and notice that the virtual server now responds to L3 network requests.

Workaround

To work around this issue, you can modify the vCMP guest so that it has a different number of allocated CPU cores (six or eight rather than 10, for example).

For instruction on how to change the core allocation, refer to the Initial vCMP Configuration Tasks chapter of the BIG-IP LTM vCMP for Appliance Models: Administration guide

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

In some environments, you can use a custom rewrite profile based on the URI Translation rewrite mode parent profile. For more information regarding rewrite profiles, refer to the following documents:

  • K93017176: Overview of the Standard virtual server
  • The Configuring the BIG-IP System as a Reverse Proxy Server chapter of the BIG-IP Local Traffic Manager Implementations manual
  • The Configuring Rewrite Profiles for Portal Access chapter of the BIG-IP Access Policy Manager Portal Access manual

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Impact of workaround: Modifying the vCMP guest's allocated CPU count may reduce its processing capacity.
