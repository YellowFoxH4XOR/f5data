K93005195: The OCSP Responder option is removed from the Machine Cert Auth policy item

Issue

The Online Certificate Status Protocol (OCSP Responder) option is removed from the Machine Cert Auth policy item in the BIG-IP APM visual policy editor. A Certificate Type option is added to the OCSP Auth policy item to provide the ability to verify the revocation status for machine certificates and user certificates.

Old Behavior

In versions prior to BIG-IP APM 12.0.0, when you configure OCSP validation for a machine certificate, you configure an OCSP Responder with the URL that the system uses to contact the OCSP service. You also associate the OCSP Responder to the Machine Certificate Auth check in the visual policy editor.

New Behavior

Beginning in BIG-IP APM 12.0.0, the OCSP Responder setting is removed from the Machine Cert Auth check object. You can now configure OCSP validation for a machine certificate using the Certificate Type option in the OCSP Auth policy item.

F5 Product Development tracked this change as ID 382390.

Impact

When upgrading from versions earlier than BIG-IP 12.0.0, the OCSP Responder option is missing from the Machine Cert Auth policy item. OCSP validation for machine certificates fails.

Recommended Actions

  1. Log in to the BIG-IP APM Configuration utility.
  2. Navigate to Access Policy > Access Profiles.
  3. Find the name of the access profile you want to edit and click Edit to open the visual policy editor for that profile.
  4. Click the + symbol and then click the Endpoint Security (Client-Side) tab.
  5. Click Machine Cert Auth and then click Add Item.
  6. Under Machine Cert Checker, for Save Certificate in a session variable, click Enabled, and then click Save.

    The visual policy editor displays the Machine Cert Auth policy item with three branches: Successful, Found, and fallback.

  7. On either the Successful or Found branch, click the + symbol.
  8. Click the Authentication tab, click OCSP Auth, and then click Add Item.
  9. On the Properties tab, for Certificate Type, click Machine and then click Save.
  10. Click Close to close the visual policy editor.
  11. Select the checkbox for the access profile you edited and then click Apply Access Policy.
