Topic

This article applies to BIG-IP version 10.x. For information about other versions, refer to the following articles:

  • K13369: Performing a first-time configuration from the command line (11x - 12.x)
  • K4802: Performing a first-time configuration for BIG-IP from the command line (9.x)

Important: This article contains numerous steps, which must be performed correctly. If you make an error while following the instructions in this article, you may cause issues that are not immediately apparent. F5 recommends that you use this article only when it is not possible to perform a first-time configuration from the Configuration utility.

Important: In writing this article, F5 assumes that you have already installed the desired version of BIG-IP software on your system. For information about installing or upgrading the BIG-IP software, refer to the release notes for the version you want to install.

Performing a first-time configuration from the command line

To perform a first-time configuration from the command line, perform the following two procedures:

  • Licensing the BIG-IP system
  • Completing a basic configuration

Licensing the BIG-IP system

  1. Connect a serial terminal to the console port.
  2. Log in as root with the default password, default.
  3. Create a dossier, using the following command syntax, replacing <regkey> with your registration key:

    get_dossier -b "<regkey>"

    Note: The registration key is printed on a paper certificate that was included in the box with the BIG-IP system.

    The dossier is displayed.
  4. Highlight and copy the dossier, starting with the section that begins on the line after the command you issued, and ending just before the next command prompt.
  5. Open a web browser and connect to the following URL:

    http://activate.f5.com
  6. Click Activate License.
  7. Follow the instructions to submit your dossier.

    Your product license is displayed.
  8. Highlight and copy the entire license.
  9. Return to the BIG-IP command line.
  10. Using a vi text editor, open the /config/bigip.license file by typing the following command:

    vi /config/bigip.license

  11. Enable the vi insert mode by pressing the i key.
  12. Paste the license file that you copied in Step 8.
  13. Press the Esc key to exit vi insert mode.
  14. Save the file and exit vi by typing the following command and pressing Enter:

    :wq

  15. Restart the BIG-IP system services by typing the following command:

    bigstart restart

The command prompt will change from INOPERATIVE to Active. The BIG-IP system is now licensed.

Completing a basic configuration

To complete a basic configuration for the BIG-IP system from the command line, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Type the following command from the command line:

    config

  3. When prompted, enter the IP address that you will use to access the BIG-IP management port.
  4. When prompted, enter the netmask for the IP address that you entered in Step 2.
  5. If you want to access the BIG-IP system from the network, enter a management route. Unless you have reason to do otherwise, accept the default setting.
  6. To assign a hostname, replacing <hostname> with the fully-qualified hostname for the BIG-IP system, use the following command syntax:

    bigpipe system hostname <hostname>

    For example:

    bigpipe system hostname askbig9n1.askf5.com

  7. Type one of the following two commands, depending on the configuration of your BIG-IP system:
    • If the BIG-IP system is a member of a redundant pair, type the following command:

      bigpipe db Failover.IsRedundant true

    • If the BIG-IP system is not a member of a redundant pair, type the following command:

      bigpipe db Failover.IsRedundant false

  8. Set the BIG-IP unit ID, depending on the configuration of your BIG-IP system:
    • If the BIG-IP system that you are configuring is a standalone unit or the first unit in a redundant pair, type the following command:

      bigpipe db Failover.UnitID 1

    • If the BIG-IP system that you are configuring is the second unit in a redundant pair, type the following command:

      bigpipe db Failover.UnitID 2

  9. Change directories to the /usr/share/zoneinfo directory by typing the following command:

    cd /usr/share/zoneinfo

  10. List the files in the directory by typing the following command:

    ls

    A number of directories that match geographical regions are displayed.
  11. Find the geographical region in which the BIG-IP system you are configuring is installed.
  12. Change directories to the directory for the geographical region you selected, using the following command syntax, replacing <directory> with the region you selected in Step 11:

    cd <directory>

    For example:

    cd America

  13. List the files in the directory by typing the following command:

    ls

    A number of time zone files that match states and cities are displayed.
  14. Find the closest match to the time zone in which the BIG-IP system you are configuring is installed.
  15. Set the time zone by typing the following command syntax, replacing <directory> with the region you chose in Step 11 and replacing <timezone> with the location that you selected in Step 14:

    bigpipe ntp timezone <directory>/<timezone>

    For example:

    bigpipe ntp timezone America/Los_Angeles

  16. Set the root password by typing the following command:

    tmsh modify auth password root

  17. Set the administrative password by typing the following command:

    tmsh modify auth password admin

  18. Set the db key that indicates that the setup has run by typing the following command:

    bigpipe db Setup.Run false

  19. Type the following command to save the configuration:

    bigpipe save all

  20. Restart all BIG-IP services by typing the following command:

    bigstart restart

You have finished the basic configuration for the BIG-IP system. You can continue configuring the BIG-IP system using the Configuration utility or the command line.

Note: If your BIG-IP system contains multiple modules, you must provision the appropriate resources to each module using the Configuration utility, or the bigpipe provision command. Refer to the BIG-IP Getting Started Guide, or the bigpipe man page for more details.
