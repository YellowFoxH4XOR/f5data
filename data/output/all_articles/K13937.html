Known Issue

You may not be able to modify or re-activate a security policy that was originally created on BIG-IP ASM 11.0.0 after you upgrade to a later version.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM security policy is created by a BIG-IP 11.0.0 iApp Application Service.
  • The BIG-IP ASM system is upgraded to version 11.1.0 or later.

When the above conditions are met, the symptoms of this issue occur when you click the Apply Policy button, or when the iApp configures the policy to be inactive, and subsequently reconfigures it to be active.

Impact

The system might not save the changes to the security policy.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The system might display, in the Configuration utility, error messages that appear similar to the following example:

    Security Policy for /Common/asm1.bigip.com.app/asm1.bigip.com_httpclass was created using the application templates system. Use the application templates system to change the Security Policy

  • The system might write to the /var/log/asm file, error messages that appear similar to the following example:

    01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::handle_error): Code: 303, Error message = Security Policy for /Common/asm1.bigip.com.app/asm1.bigip.com_httpclass was created using the application templates system. Use the application templates system to change the Security Policy.

Workaround

To work around this issue, you can rename the BIG-IP ASM security policy. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the Configuration utility.
  2. Navigate to Application Security > Policy.
  3. Select the affected policy from the Current edited policy menu.
  4. In the Security Policy Name box, the current policy name is in the following format:

    <name>_asm_policy

    Modify the Security Policy Name value to use the following format, keeping the <name> value the same:

    <name>_httpclass

    For example:

    The configuration contains the following Security Policy Name:

    my.domain.com.app_asm_policy

    You would re-enter the Security Policy Name as:

    my.domain.com.app_httpclass

  5. Click Save.
  6. Click Apply Policy.
