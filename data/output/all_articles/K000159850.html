Description

BIG-IP Application Security Manager (ASM) logging profiles can be configured to log full user traffic payloads, including request and response bodies, to external log servers. This article explains how to Exclude request body payload data from logs sent to SIEM systems, as well as Format selection considerations for this scenario.

Environment

  • BIG-IP ASM / AWAF
  • ASM logging profile configured for remote storage
  • External log server (Splunk, QRadar, ArcSight, or other SIEM solutions)

Cause

ASM logging profiles require specific format selections and field configurations to control whether request and/or response body data is included in logs sent to external servers. The default configuration and format selection determine which payload elements are captured and forwarded. 

Answer/Recommended Actions

To Exclude Request Body (Payload) Data from Remote Logs:

  1. Navigate to Security > Event Logs > Logging Profiles
  2. Select your logging profile
  3. Under Application Security, set Configuration to Advanced
  4. For Storage Format, select Comma-separated Values
  5. In the field selection panel:
    • Keep the 'request' field in the Available Items (right panel)
    • Do NOT move it to the Selected Items (left panel)
  6. Only select the fields you want to include in logs (excluding request body data)
  7. Save the configuration

Note: To Exclude the HTTP Response Body to be sent to the Remote log collector(s), you can simply consider the same procedure for the other field name as "response" in Step-5 of the above workaround. You can also Exclude both Request Body and Response Body, at the same time.

Additional Information

If your logging profile is using a Storage Format other than Comma-separated Values, it may be possible to limit the request body by setting a value for the Maximum Request Size setting. However this method may not exclude the request body entirely. The best method is to use the Comma-separated Values storage format; ensure the request field is in the Available items list and out of the Selected items list.
