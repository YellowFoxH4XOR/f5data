Known Issue

The BIG-IP ASM system may fail to apply configuration changes to the security policy.

This issue occurs when the following condition is met:

  • Your BIG-IP ASM system cannot locate the policy configuration item to update. For example, this issue may occur when the configuration item to be updated was previously deleted and then later re-added.

Impact

The update fails and the configuration entity is not added.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H607681 on the Diagnostics > Identified > Medium screen.
  • Your BIG-IP ASM system logs a configuration failure to the /var/log/ts/bd.log file that appears similar to the following example:

    err perl[4739]: 01310011:3: ASM configuration error: event code T865 Failed to update configuration table CONFIG_TYPE_ACCOUNT_WILDCARD_POLICY_COOKIES, record 0, status 10
