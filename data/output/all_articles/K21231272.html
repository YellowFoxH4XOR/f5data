K21231272: Installing ISO image file on vCMP guest may fail

Type
Support Solution
Published
2022-03-03
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.X.X, 15.X.X, 15.1.0, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.0.1, 15.0.0, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 14.1.X, 15.1.X, 15.0.X
Source
https://my.f5.com/manage/s/article/K21231272

Description
Unable to upgrade vCMP guest

  1. Software installation fails with checksum error even though MD5 sum is correct.
    Running tmsh show sys software shows output similar to below 
    ---------------------------------------------------------------------------------------
Sys::Software Status
Volume  Slot  Product   Version  Build  Active                                   Status
---------------------------------------------------------------------------------------
HD1.1      3   BIG-IP  14.1.2.5  0.0.3     yes                                 complete
HD1.2      3     none      none   none      no  failed (archive read or checksum error)
  2. In /var/log/liveinstall.log following error messages can be observed 
    error: Cannot translate repository name. It is not a directory, ISO file, nor URL.
Terminal error: Failure testing installer update status in /shared/images/<image_name>.
  3.  In /var/log/ltm following error messages generated by lind process can be observed 
    013c0004:3: ImageIsValid insert failed
013c0005:4: Could not validate checksum for image: <image_name>
Environment
  • vCMP guest upgrade
  • VCMP Host running affected software version. Please refer to Bug ID 927909 for more details
  • Attempt to upgrade vCMP guest from image residing on the host,

Cause

Unable to use block-device-image option (where the actual images reside on the host) due to Bug ID 927909

Recommended Actions

To workaround the issue, copy the the upgrade BIG-IP image to the vCMP guest locally, through the guest's IP address. For more information on uploading the file to the guest, refer to K175: Transferring files to or from an F5 system???????.
