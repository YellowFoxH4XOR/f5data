K000141296: [APM] Portal Access resource slowness and delay

Type
Support Solution
Published
2024-10-01
Updated
2024-10-01
Source
https://my.f5.com/manage/s/article/K000141296

Description

BIGIP APM administrator may notice slowness and delay for Portal Access resources.

Environment

  • APM
  • Portal Access
  • Slowness
  • Delay

Cause

Make sure that system db variable  'log.webapplications.level' has default value 'Notice'

Recommended Actions

To verify that 'sys db log.webapplications.level' has default value 'Notice':

# tmsh list sys db log.webapplications.level
sys db log.webapplications.level {
    value "Notice" <---- (!)
}
