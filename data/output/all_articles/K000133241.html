K000133241: Backups over Ansible (module: bigip_ucs_fetch) are not being encrypted

Type
Support Solution
Published
2023-03-29
Updated
2023-03-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000133241

Description

UCS file is not encrypted when using Ansible bigip_ucs_fetch module and specify encryption_password parameter

Environment

BIG-IP

Ansible bigip_ucs_fetch module

Cause

Software bug in bigip_ucs_fetch module

Recommended Actions

To pick up the fix, customer needs to download the daily build 'f5networks-f5_modules-devel.tar.gz' from

https://github.com/F5Networks/f5-ansible/tree/devel/ansible_collections/f5networks/f5_modules

and then follow "Install from the daily build file" section to install it.
 

Note: Do not follow "Install from GitHub" instructions at this point.

None
