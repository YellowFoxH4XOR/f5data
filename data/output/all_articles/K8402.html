Issue

The BIG-IP LTM system may log an error message to the /var/log/ltm file that appears similar to the following example:

tmm tmm[1015]: 01010025:2: Device failure: cn0: Address/Attribute phase

This is a rare PCI error indicating a serious failure of the signal integrity of the system bus. The chip's bus wires may be damaged or broken. If your BIG-IP system logs the example error message, you should run the End-User Diagnostics (EUD) utility and provide the diagnostic report to F5 Technical Support.

For information about the EUD, refer to K7172: Overview of the End User Diagnostics software.
