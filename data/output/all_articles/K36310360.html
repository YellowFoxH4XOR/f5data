Description

You have configured SNMPv3 on the BIG-IP and the SNMP manager is not able to retrieve device specific information, such as uptime and interfaces information, while information from other OIDs can be retrieved successfully.

Environment

  • SNMPv3
  • BIG-IP

Cause

A specific OID value other than .1 is configured on the SNMP Access (v3) record.  A value of .1 will allow access to all the OIDs on the device, and any other specific value will restrict access to this specific OID or OID tree only.

For Example:

A value of .1.3.6.1.4.1.3375 will permit access only to the following OID tree F5-BIGIP-COMMON-MIB::f5. As a result of that, the system uptime information with the following OID, won't be able to be retrieved:

.1.3.6.1.2.1.1.3.0
DISMAN-EVENT-MIB::sysUpTimeInstance

Recommended Actions

You can modify the OID value on the GUI, by navigating to: System > SNMP > Agent > Access (v3), select the record in question, and then modify the OID value to .1.
