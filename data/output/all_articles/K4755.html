Topic

By default, the BIG-IP system does not propagate frames addressed to a multicast or broadcast Layer 2 destination across the child VLANs in a VLAN group.

Some types of redundant systems send well-formed requests from unicast source MAC/unicast source IP address, but include a multicast or broadcast MAC address in the payload, expecting the response to be sent to the MAC address in the payload. If the request must traverse a BIG-IP VLAN group to reach the destination, the BIG-IP system will forward the request across the VLAN group with its source MAC address intact, but will ignore the response sent to the specified multicast/broadcast destination MAC address.

F5 Product Development tracked a feature request to support propagation of multicast and broadcast frames across VLAN groups as CR47032 and it was added in BIG-IP 9.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway Release Notes.

Beginning with BIG-IP 9.1.0, you can configure the BIG-IP system to flood frames addressed to multicast or broadcast destination MAC addresses across the child VLANs of a VLAN group. To set the AllowMulticastL2DestinationTraffic database variable, type the following command:

bigpipe db TM.AllowMulticastL2DestinationTraffic enable

The BIG-IP system will now propagate multicast and broadcast frames across all interfaces in a VLAN group.
