Known Issue

This is most likely the result of a known issue. If you use the Configuration utility to add a link and then refresh the Links page, you receive the following error.

An error has occurred in the Configuration utility. 
You may need to restart one or more daemons, or the system, to resolve this error. 
Contact support for more information.
Error Info:
Error creating link.com.f5.tdns.jcapi.exception.OperationFailed: 
IDL:ITCMGlobalLB/OperationFailed:1.0
Error Details:
No Stack trace available.

This error occurs because the Configuration utility attempts to resend the command that added the link when you refresh the page.

This problem is cosmetic. You can continue to use the Configuration utility without further errors.

F5 Networks Product Development tracked this issue as CR40319 and CR41860.
