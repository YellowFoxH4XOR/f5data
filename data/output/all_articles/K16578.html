Known Issue

Attempting to delete an HTTP iApp may fail.

This issue occurs when the following conditions are met:

  • You have enabled the Automatic Sync feature for the device group.
  • You made configuration changes to the HTTP iApp prior to attempting to delete it.

Impact

  • You cannot delete the iApp.
  • Configuration synchronization (ConfigSync) operations fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to delete the affected HTTP iApp, your BIG-IP system logs error messages to the /var/log/ltm file that appear similar to the following example:

    mcpd[6629]: 01070265:3: The HTTP Profile (/Common/<profile_name>) cannot be deleted because it is in use by a sflow http data source (16).
    mcpd[6629]: 01071488:3: Remote transaction for device group /Common/HA_Group to commit id 679 607087129064800123 /Common/<device> 0 failed with error 01070265:3: The HTTP Profile (/Common/<profile_name>) cannot be deleted because it is in use by a sflow http data source (16)..

  • ConfigSync operations fail.

Workaround

To work around this issue, you can disable the Automatic Sync feature for the device group and force the mcpd process to reload the BIG-IP configuration. To do so, perform the following procedure:

Impact of procedure: Forcing the mcpd process to reload the BIG-IP configuration requires you to reboot the BIG-IP system. You should perform this procedure during a maintenance window. In addition, you will need to manually synchronize the configuration after disabling the Auto Sync feature.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Device Groups.
  3. Click the name of the affected device group.
  4. Clear the Automatic Sync check box.
  5. Click Update.
  6. To force the mcpd process to reload, refer to K13030: Forcing the mcpd process to reload the BIG-IP configuration.
