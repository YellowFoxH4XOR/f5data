Known Issue

Installation of BIG-IP system software may fail when performed from a USB CD-ROM drive. The BIG-IP system may detect certain USB CD-ROM drives as device /dev/sda (a mass storage device), rather than /dev/sr0 (a removable CD-ROM). When this behavior occurs, the BIG-IP system attempts to install the software to the USB CD-ROM drive, which fails. As a result, the BIG-IP system reports the following error message:

Disk Errors on Sector 0

Once the installation has failed, the BIG-IP system will no longer boot.

F5 Product Development tracked this issue as CR60731 and CR61843 and it was fixed in BIG-IP 9.4 and 9.3. For information about upgrading, refer to the BIG-IP ASM, GTM, LTM, and Link Controller Release Notes.

Workaround

To work around this issue, perform the installation from a network boot server instead.

You may also attempt to reinstall the software from a different USB CD-ROM drive, as most USB CD-ROM drives are detected properly by the BIG-IP system.

Note: For more information, refer to K3525: Configuring BIG-IP LTM, GTM, or ASM to boot from a network boot server.
