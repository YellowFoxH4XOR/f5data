K3804: Reasons why dependent virtual servers disabled when the virtual server on which they are dependent is disabled

Topic

3-DNS was not originally designed to disable all virtual servers associated by dependency when one of the virtual servers is disabled, because it could cause incomplete sessions when traffic is sent to a virtual server that has a disabled co-dependent virtual server.

Starting in 3-DNS version 4.5.11 and version 4.6.3, all virtual servers that are associated by a dependency are disabled if any one of the virtual servers is disabled.

Important: Although this new design allows you to disable all virtual servers associated by dependency, using this feature can prevent existing sessions, that are on the co-dependent servers, from completing.

In versions prior to versions 4.5.11 and 4.6.3, you must manually disable each virtual server associated by a dependency.
