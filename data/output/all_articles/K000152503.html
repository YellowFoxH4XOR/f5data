K000152503: F5 rSeries 'SFP28 (25G)' Optics Do Not Operate at 10G in '4x25GbE' Port Group Profile

Description

On F5 rSeries platforms running F5OS-A, configuring SFP28 ports with the 4x25GbE port group profile does not allow a 25G SFP28 transceiver (such as F5 OPT-0053-01) to operate at 10G speed. When connecting these ports to switches that only support 10G (e.g., Cisco Catalyst 2960), the link remains down even if the switch port is set to 10G and Forward Error Correction (FEC) is disabled. The system supports operation of 10G SFP+ modules (e.g., F5 OPT-0016-00) at 10G in this profile, but not single-rate 25G SFP28 modules at 10G.

Environment

  • F5 rSeries Appliances: e.g., r2000, r4000
  • SFP28 ports configured in 4x25GbE port group mode
  • Using F5-branded SFP28 25G transceivers (OPT-0053-01)
  • Peer network device supports only 10G on corresponding ports
  • FEC disabled on both sides

Cause

The OPT-0053-01 SFP28 module is a single-rate optic designed exclusively for 25Gbps operation and does not support fallback or dual-rate functionality for use at lower speeds such as 10Gbps. The 4x25GbE port group profile enforces all member ports to operate at 25Gbps; individual port speed override is not supported within this mode. While the hardware allows backward compatibility with true SFP+ (10G) modules, it cannot force a single-rate SFP28 module to run at a lower speed.

Recommended Actions

  • For operation at 10Gbps on any SFP port, install an F5-branded and supported 10G SFP+ module (e.g., OPT-0016 series).
  • If using a single-rate 25G SFP28 module (OPT-0053), ensure that the connected peer device also supports and negotiates a link at 25Gbps.
  • To run all four fiber ports at 10Gbps, change the port group profile to 8x10GbE. In this mode, 10Gbps transceivers (e.g. OPT-0016-xx) must be used. If you attempt to use OPT-0053 in this mode, the 10Gbps link may run but F5 does not support this combination.
  • For mixed-speed requirements, you can use 4x10GbE+2x25GbE profile which provides only 2x25GbE as Optic Interfaces, and 4x10GbE as Copper Interfaces.
  • Always use only officially supported and branded optics per the latest hardware compatibility lists from F5.

Note: Changing the port group profile requires a system reboot and will remove previous interface configurations for those ports.
