Issue

Old Behavior

Previously, the route domains feature was only compatible with IPv4 addresses.

In order to append the route domain identifier to an IPv4 address the BIG-IP translated all IPv4 addresses to IPv6 addresses for internal processing, and the route domain ID was then encoded into the unused bits of the larger IPv6 address. While this design allowed a 32-bit IPv4 address and a route domain ID to be encapsulated together, there is insufficient space to include a route domain ID with a 128-bit IPv6 address.

New Behavior

Beginning in BIG-IP 11.1.0, the route domain ID is no longer encapsulated within an IPv6 address, allowing route domains to be used with both IPv4 and IPv6 addresses.

F5 Product Development tracked this change as ID 339935.

Impact

Route domains support IPv4 and IPv6 addresses.
