K95921851: How to enable custom login banner for BIG-IQ GUI login screen using CLI

Type
Support Solution
Published
2021-07-17
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K95921851

Description

You would like to enable the "Show on Login Screen" for Custom Login Message and specify a message to be displayed on the BIG-IQ login page from the Command Line Interface. From BIG-IQ UI, this is the equivalent feature found under  System > This Device > General Properties > Edit > Custom Login Message. 
 

Environment

  • BIG-IQ CM
  • Enable the "Show on Login Screen" feature via CLI
  • Specify a message to be displayed on the BIG-IQ login page via CLI
     

Cause

None

Recommended Actions

  1. Log in to the command line of the BIG-IQ system.
  2. Determine the value set for the "message" and "isEnabled" variable under /mgmt/shared/login-ui-message using the iControl REST command:
    # restcurl /shared/login-ui-message

    Output appears similar to the following example:
    {
      "message": "Welcome to BIG-IQ.\n\nLog in with your username and password.",
      "isEnabled": false,
      "generation": 7,
      "lastUpdateMicros": 1626523917842392,
      "kind": "shared:login-ui-message:loginuimessageworkerstate",
      "selfLink": "https://localhost/mgmt/shared/login-ui-message"
    }
  3. Modify the value of the "message" and "isEnabled" variable as needed by using the following iControl REST command syntax:
    # restcurl /shared/login-ui-message -d '{"isEnabled": true, "message": "<desired message>"}' -X PATCH

    Example: 
    # restcurl /shared/login-ui-message -d '{"isEnabled": true, "message": "Welcome to BIG-IQ.\n\nLog in with your username and password.\n\nThis is a test message."}' -X PATCH
    {
      "message": "Welcome to BIG-IQ.\n\nLog in with your username and password.\n\nThis is a test message.",
      "isEnabled": true,
      "generation": 9,
      "lastUpdateMicros": 1627791898035342,
      "kind": "shared:login-ui-message:loginuimessageworkerstate",
      "selfLink": "https://localhost/mgmt/shared/login-ui-message"
    }
     
  4. Logout from BIG-IQ's GUI and re-login to verify the custom login message.
