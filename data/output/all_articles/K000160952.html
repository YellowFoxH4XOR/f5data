K000160952: What API Group is Required for Uploading Certificates via XC API?

Description

  • What API Group is Required for Uploading Certificates via XC API?
  • If want to submit a request like POST https://<tenant-domain>.console.ves.volterra.io/api/config/namespaces/<namespace-name>/certificates, then what API Group is required?

Environment

  • F5® Distributed Cloud Console
  • XC API

Resolution/Answer

You need to create a role with the "ves-io-proxy-write" API group and then assign it to a user in the pertinent namespace.

 

  1. Navigate to administration tile in XC console. 
  2. Click on roles. 
  3. Add a role.
  4. Add "ves-io-proxy-write" API Group to the role.
  5. Save it.
  6. Click on users. 
  7. Add a user or edit a user of interest.
  8. Click assign roles and namespaces. 
  9. Add the role you just created.
  10. That user can now upload certificates via XC API.
