Known Issue

BIG-IP LTM policies with more than one IP address in a TCP address match may fail.

This issue occurs when the following condition is met:

  • A BIG-IP LTM policy rule with a tcp match address statement attempts to match against more than one IP address.

Impact

The system might not take the action that is configured with the match.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A BIG-IP LTM policy using a rule that attempts to match based on a list of IP addresses may fail if more than one IP address is used.

Workaround

To work around this issue, you can use one of the two available options:

  • Option 1: Use a subnet instead of single IP addresses.
  • Option 2 (BIG-IP 13.0.0 only): Use a datagroup with the list of IP addresses to match.

For more information, refer to the BIG-IP Local Traffic Management: Getting Started with Policies guide.
