Topic

When the BIG-IP system runs End User Diagnostic (EUD) 2.6.0, the eud_log utility may indicate that no EUD log was found.

Description

The eud_log utility searches for an EUD-written file containing diagnostic information and copies it to the /var/log/eud.log file. After running diagnostic tests on a BIG-IP system with EUD 2.6.0, the eud_log utility may generate an error message similar to the following:

info: No EUD log found in /var/tmp.  Searching boot volume
info: No eud.log found on sda.dat.boot

Although the messages indicate that no EUD log exists, the impact is cosmetic because the eud.log file is already written to the /var/log/ directory.

Recommendations

Later versions of the EUD do not experience this issue. When troubleshooting a potential hardware problem, F5 recommends that you download and install the latest version of the EUD for your platform before you run system diagnostics.
