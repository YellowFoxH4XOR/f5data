Description

Configuration does not load after upgrading to 15.x or 16.x.

  • Log messages in /var/log/ltm after booting into Version 15.x or 16.x:

      err mcpd[<pid>]: 010716e0:3: Policy '/Common/Drafts/sample_local_traffic-policy', rule 'sample-rule'; target 'forward' action 'select' is missing required parameter 'pool'.
      err tmsh[<pid>]: 01420006:3: Loading configuration process failed.
      emerg load_config_files[<pid>]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- Loading schema version: 14.0.0
      err mcpd[<pid>]: 01070425:3: Full configuration load failed.

Environment

  • BIG-IP 14.x
  • Upgrading to BIG-IP 15.x or 16.x
  • Draft Local traffic policy is present containing a rule for forwarding that does not select a pool.
    ltm policy /Common/Drafts/sample_local_traffic-policy {
        controls { forwarding }
        requires { http }
        rules {
            sample-rule {
                actions {
                    0 {
                        forward
                        select
                    }
                }
                conditions {
                    0 {
                        http-uri
                        path
                        starts-with
                        values { /sample-rule }
                    }
                }
            }
        }
        strategy /Common/best-match
    }

Cause

Change in behavior

In Version 15.x and 16.x, policies (including draft policies) that use the forward action must select a specific pool to which traffic will be forwarded.
 

Recommended Actions

Perform one of the following procedures:

  1. On 14.x, remove the draft Local Traffic Policy named 'sample_local_traffic-policy'
  2. Remove the 15.x or 16.x volume
  3. Reinstall  15.x or 16.x (with the fixed configuration).
or
  1. On 14.x, edit draft Local Traffic Policy named 'sample_local_traffic-policy' on 14.x to include a specific pool to which traffic will be forwarded.
Example:

ltm policy /Common/Drafts/sample_local_traffic-policy {
    controls { forwarding }
    requires { http }
    rules {
        sample-rule {
            actions {
                0 {
                    forward
                    select
                    pool /Common/Sample_pool <--- pool added here
                    
                }
            }
            conditions {
                0 {
                    http-uri
                    path
                    starts-with
                    values { /sample-rule }
                }
            }
        }
    }
    strategy /Common/best-match
}
  1. Remove the  15.x or 16.x volume
  2. Reinstall 15.x or 16.x (with the fixed configuration).
