Description

After upgrade to 14.1.x /var/log/messages log is filled with asterisks:

Jan 01 01:01:01 localhost **********************************************
Jan 01 01:01:01 localhost **********************************************
Jan 01 01:01:01 localhost **********************************************

Message reoccurs every few minutes.

Environment

  • BIG-IP LTM
  • In most cases issue occurs after upgrade from v13.x to v14.1.x (or other affected versions)

Cause

Bug ID 849085: Lines with only asterisks filling message and user.log file.

Recommended Actions

This issue is only cosmetic. For a full solution, you can upgrade to a version where this ID is fixed.

You can workaround the issue on affected versions with any of the possible workarounds suggested on the BUG tracker link, or, with this procedure:

Edit /defaults/config/template/syslog.tmpl file:

  1. Log in to the command line.
  2. Mount /usr as read-write:

    mount -o rw,remount /usr

  3. Change directory:<

    cd /defaults/config/template

  4. Create backup of that file:

    cp syslog.tmpl /shared/tmp

  5. Edit syslog.tmpl to add the indicated line, and save the file:

    # This is used to apply the template to local messages
    destination d_syslog_pipe {
       pipe("/var/run/syslog.pipe" perm(0600) template(t_commontmpl));
    };
    source s_syslog_pipe {
       pipe("/var/run/syslog.pipe" perm(0600) flags(expect-hostname));
    };
    filter f_no_multi_line {
        not (message('\n') or message('\r'));
    };
    log {
       source(local);
       filter(f_no_multi_line);     #<<<<<<<<<<< add this line
       destination(d_syslog_pipe);
    };

  6. Make this change in syslog configuration:

    tmsh modify sys syslog include "# test"

    tmsh modify sys syslog include none
