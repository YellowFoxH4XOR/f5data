K45744553: F5 transparent cache does not differentiate queries with/without RD bit

Type
Support Solution
Published
2025-06-18
Updated
2025-07-07
Applies to
  • BIG-IP
  • BIG-IP GTM: 11.6.1
  • BIG-IP DNS: 12.1.2, 12.1.1, 12.1.0, 12.0.0, 13.0.0
Source
https://my.f5.com/manage/s/article/K45744553

Description

F5 dns transparent cache does not differentiate queries regardless of RD bit.
For example, when a client queries A records for domain 'www.test.com' with 'norec' set, F5 transparent cache will cache the A records and NS records.
After a while, when A records for 'www.test.com' expires and NS records still exists, for following queries, F5 will respond NS records direclty without A response.

Environment

  • Transparent cache is used
  • DNS transparent cache that receives a non-recursive query whose result is stored in the cache.

 

Cause

None

Recommended Actions

The fixed releases include 11.6.3 12.1.3 and 13.0.1.
Before upgrading to fixed release, you can workaround this issue by applying following iRule:

when DNS_REQUEST {
   if { ([DNS::header rd] == 0 ) || ([DNS::header cd] == 1 )} {
    DNS::disable cache
   }
}
