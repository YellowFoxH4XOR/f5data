Known Issue

The OAM Software Development Kit (SDK) on the BIG-IP APM system may generate an exception when a WebSSO session is connecting to an OAM server and an error occurs, or the OAM server the BIG-IP APM system delivers an unexpected response. As a result, the WebSSO session may dump core.

F5 Product Development tracked this issue as ID 324381 (formerly CR141990-1) and ID 226693 (formerly CR141990) and it has been fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

This issue has been fixed in Hotfix-BIGIP-10.2.0-1755.1-HF1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about installing version 10.x hotfixes, refer to K10025: Managing BIG-IP product hotfixes (10.x).

To view the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
