Known Issue

Printer and keyboard redirection for Remote Desktop sessions may not function.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an RDP Application Access Remote Desktop access profile.
  • The Access to Local Resources Remote Desktop RDP setting is configured with Printers and/or Special Keyboard Commands enabled.
  • Users connecting to the Remote Desktop access profile are running the Windows 7 or 8 operating system.

Impact

Users cannot access remote printers and special keyboard commands.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users cannot use local printers remotely.
  • Special keyboard command redirection does not function.

Workaround

To work around this issue, you can configure the Access to Local Resources Remote Desktop RDP setting with the In Full Screen Only option. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Navigate to Access Policy > Application Access > Remote Desktops.
  3. Click the name of the affected access profile.
  4. In the Access to Local Resources section, set the Special Keyboard Commands setting to In Fullscreen Only.
  5. Click Finished.
  6. In the upper-left corner of the Configuration utility, click Apply Access Policy.
