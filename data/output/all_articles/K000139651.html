Description

Concerns regarding the Windows security update KB5036892 and its potential impact on VPN connections, specifically relating to the F5 VPN / APM functionality. This is based on 3rd party articles and communications from Microsoft, such as Microsoft says April Windows updates break VPN connections (bleepingcomputer.com)

Note: This link points to a 3rd party website. The owner can remove or change this link without our knowledge.

Environment

  • F5 VPN 
  • Windows security update KB5036892

Cause

Recent reports have indicated that the Windows security updates released in April 2024, including KB5036892, have led to VPN connection failures on various Windows client and server platforms. 

Recommended Actions

Although the general advisory from Microsoft suggests possible VPN disruptions, the SSLVPN technology used by F5 VPN seems to remain unaffected. This affects Microsoft's own built-in client: VPN connection types - Windows Security | Microsoft Learn
