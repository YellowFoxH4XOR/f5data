Description

You unexpectedly deleted /boot and /home directories and wanted to restore them.

Environment

BIG-IP

Cause

None

Recommended Actions

 Use any available partition on the unit and re-install the software which you require and boot into partition and restore with last known good UCS file.

 or

A new volume can be installed from current boot location only when below variables are set to disabled.
 

# tmsh modify /sys db liveinstall.moveconfig value disable

# tmsh modify /sys db liveinstall.saveconfig value disable

Note : Disabling above variables will not copy software config to new boot location so a known good UCS files should be used to restore the config after booting into newly created volume

Refer to below guide for details on liveinstall variable

K13438 : Controlling configuration import when performing software installations
