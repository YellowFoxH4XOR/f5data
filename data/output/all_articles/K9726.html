Topic

You can use different type of actions and rules to create a pre-login sequence policy. To create a pre-logon sequence that will look for a specific file by name on a Mac OS X, perform the following procedures:

Important: Prior to performing the following procedures you must copy or create a file in a test directory. For example, you could create a file named stamp 1 in the /test directory.

  • Creating a new pre-logon security file check
  • Adding a Mac OS X file checker action
  • Editing the inspector and setting the details to look for the file name
  • Activating the sequence

Creating a new pre-logon security file check

  1. Navigate to the New Sequence section of the Device Management: Users: Endpoint Security: Pre-Logon Sequence page.
  2. In the Create new sequence field, enter a new sequence name.

    For example:

    myfilecheck1
  3. In the Based on drop-down menu, select the template Empty option.
  4. Click Create.

Adding a Mac OS X file checker action

  1. Navigate to the Device Management: Users: Endpoint Security: Pre-Logon Sequence: Select Sequence to Use section.
  2. Next to the name of the pre-logon sequence you just created, click the Edit link.
  3. Hover your mouse over the line between Sequence Start and Logon Allowed Page.

    A plus sign (+) will appear.
  4. Click the plus sign.

    FirePass will open a Change Sequence panel on the right side of the browser
  5. Under Predefined actions, select Check Files (Max OS X).
  6. Click Apply Changes.

Editing the inspector and setting the details to look for the file name

  1. Navigate to the Device Management: Users: Endpoint Security: Pre-Logon Sequence: Select Sequence to Use section.
  2. Next to the name of the pre-logon sequence you just created, click the Edit link.
  3. Click the Check Files (Max OS X) action.
  4. Under Action details, add a brief description in the Description field.

    For example:

    Check for stamp1 file
  5. In the Inspector section, click Max OS X file checker.
  6. Populate the File name* field with the name of the file.

    For example:

    /test/stamp1.rtf

    Note    : Make sure you include the file extension. It needs to have the full name and the full path to the file to work properly.
  7. Leave all other fields blank
  8. Click Update.
  9. In the upper right corner, click on Back to Console.

Activating the sequence

  1. Navigate to the Device Management: Users: Endpoint Security: Pre-Logon Sequence: Select Sequence to Use section.
  2. Select the name of the pre-logon sequence.
  3. Click Apply.

    After attempting to log in, you should see the following message prior to receiving the login page:

    Checking files ...

You can perform a more detailed file inspection, and can list up to three files in any one inspector. The following table provides a brief overview of the different variables you can use for inspection: 

VariableFunction
File nameThis variable represents the full name of the file to check for.
MD5This variable represents the file MD5 check sum.
File sizeThis variable represents the size of the file, in bytes.
Last modifiedThis variable represents the file's last modification date and time.

Note: Enter the date and time in UTC format (YYYY.MM.DD HH:MM:SS)
File versionThis variable represents the version of the file.
CNThis variable represents the CN value from a certificate.
