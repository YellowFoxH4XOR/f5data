Topic

You should consider using this procedure under the following condition:

  • You want to display BIG-IP ASM learning suggestions for a given attack signature.

Description

As a BIG-IP administrator, you can display the policy builder learning suggestions and modify the policy suggestions as needed. You can also display learning suggestions for a particular attack signature. Doing so is useful if you want to review the request details that triggered a specific attack signature and decide how to proceed with the learning suggestion. For example, after reviewing the request details you can choose to accept, delete, ignore or export the learning suggestions.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP system is licensed for the Application Security (ASM) module.
  • You have administrative access to the BIG-IP Configuration utility.

Procedures

Display learning suggestions for a given attack signature

To display BIG-IP ASM learning suggestions for a given attack signature, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the Configuration utility.
  2. Go to Security > Application Security > Policy Building > Traffic Learning.
  3. Select the name of the security policy from the Select or search a policy in the list... menu.
  4. Select Open Filter.
  5. Select Advanced Filter.
  6. In Matched Attack Signature, type the name or category of the attack signature.
    For example, Directory Traversal attempt "../" (URI) (%2e%2e)
  7. Select Apply.
  8. The learning suggestion matching the signature name appears under Suggestions.
  9. Select the relevant suggestion and review the requests that triggered the learning suggestion.
  10. Select the appropriate action for the learning suggestion as needed, such as Accept, Delete, Ignore or Export.
