Issue

Error Message

01070821:3: User Restriction Error: Advanced shell not available in Appliance Mode

Message Location

You may encounter this message in the following location:

  • The System > Users > <username> > <username> Preferences screen in the Configuration utility

    For example:

    System > Users > MyUsername > MyUsername Preferences

Description

This message occurs when both of the following conditions are met:

  • The BIG-IP system is running in Appliance Mode.
  • You attempt to modify the Terminal Access setting for a given user to Advanced Shell.

When a BIG-IP system is running in Appliance Mode, the Advanced Shell option (access to the bash shell) is disabled for all users.

Impact

Users will not be granted the Advanced Shell level of Terminal Access.

Recommended Actions

None
