Known Issue

A Citrix client may not be able retrieve the Citrix config.xml file when accessing a Citrix system through the BIG-IP APM system.

This issue occurs when the following condition is met:

  • The Citrix client and the BIG-IP APM Citrix configuration have different URIs configured to retrieve the Citrix configuration file.

The Citrix client stores the URI for the Citrix configuration file (config.xml) locally on the client's system when the account is first created. When a Citrix profile is created on the BIG-IP APM system, the BIG-IP system uses the default path of /Citrix/PNAgent/config.xml for the Citrix configuration file.

Impact

Users are unable to access Citrix resources through the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • An error message is logged in the /var/log/ltm file. The error message appears similar to the following example:

    tmm err tmm[12111]: 01220001:3: TCL error: /Common/_sys_APM_Citrix <ACCESS_SESSION_STARTED> - can't read "tmm_apm_citrix_username": no such variable while executing "sha1
  • The client may receive the following error message:

    Your apps are not available at this time. Please try again
    in a few minutes or contact your help desk with this
    information: Cannot contact <profile name>.

Workaround

To work around this issue, you can create a data group on the BIG-IP system that matches the URI of the BIG-IP system to the client configuration path. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click iRules.
  4. Click the Data Group List tab.
  5. Click Create.

    Note: If you have previously created the data group, click the group name to edit the group.
  6. In the Name field, enter the following text:

    APM_Citrix_ConfigXML
  7. From the Type menu, select String.
  8. In the String text box, enter the fully-qualified domain name (FQDN) of the virtual server to which the Citrix clients connect.

    For example:

    citrix.example.com
  9. In the Value text box enter the path to the Citrix config.xml file that matches your Citrix configuration.

    For example:

    /citrix/pnagent/store/config.xml
  10. Click Add.
  11. Click Finished.
