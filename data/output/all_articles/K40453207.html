Known Issue

The BIG-IP system may fail to load configurations containing BIG-IP LTM policies.

This issue occurs when all of the following conditions are met:

  • Your virtual server is associated with a BIG-IP LTM policy.
  • Your BIG-IP configuration contains both a published and a draft copy of the policy.

    The bigip.conf configuration file may appear similar to the following example:

    ltm policy /Common/another {
        draft-copy /Common/Drafts/another
         ...
    }
    ltm policy /Common/Drafts/another {
         ...
        published-copy /Common/another
         ...
    }

  • Your BIG-IP system contains at least one non-default partition other than the default /Common partition.
  • One of the following events occurred on your BIG-IP system:
    • Your BIG-IP system attempts to perform loading of the BIG-IP configuration after a software upgrade.
    • Your BIG-IP system attempts to perform loading of the BIG-IP configuration from the text configuration files after performing the procedure in K13030: Forcing the mcpd process to reload the BIG-IP configuration.

Impact

The BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system is unable to load the configuration.
  • When you attempt to load the configuration using the TMOS Shell (tmsh), you observe an error message similar to the following example:

    01070726:3: Policy /Common/Drafts/[policy_name] in partition Common cannot reference policy reference /Common/Drafts/[policy_name] /Common/[virtual_server name] in partition [partition]

Workaround

To work around this issue, you can manually edit the bigip.conf file and remove the draft policy before loading the configuration. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you perform the following procedure during a scheduled maintenance window.

  1. Log in to the command line of the affected BIG-IP system.
  2. To create a backup copy of the /config/bigip.conf file, enter the following command:

    cp /config/bigip.conf /config/bigip.conf_example

  3. Using a text editor, open the /config/bigip.conf file.
  4. Locate the BIG-IP LTM draft policy.
  5. Remove the draft policy from the configuration file.
  6. Save the configuration changes to the /config/bigip.conf file.
  7. To load the configuration, enter the following command:

    tmsh load /sys config
