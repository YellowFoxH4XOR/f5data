Known Issue

This is the result of a known issue. The method for accounting for the CPU utilization of non-TMM processes in statsd is incorrect in BIG-IP 9.3.x and 9.4.x. As a result, certain processes may appear to use larger amounts of CPU cycles. For example, if you view the CPU usage graph in the Configuration utility, you may observe CPU spikes on a regular basis, while the top utility does not show spikes.

F5 Product Development is tracking this issue as CR102761 and CR99560.

Note: BIG-IP 9.6.0 and later versions are not affected by this issue. These versions use a different CPU utilization accounting method for non-TMM processes.

Workaround

You can verify whether the CPU utilization displayed in the CPU graph is accurate by viewing the top command output.
