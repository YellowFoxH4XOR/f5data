Description

When diagnosing BIG-IP DNS configuration or Zone sync issues, the following error message maybe observed in /var/log/gtm:

012b2009:7: Skipped xml broadcast to: <address>:<port> reason: not connected to same local address

Environment

The following conditions (all) can trigger the error message to be observed in /var/log/gtm:

  • big3d debug logging enabled (db key log.big3d.level=debug)

Cause

When a big3d agent receives a monitor probe request from a connected gtmd, it runs the requested monitor, and then "broadcasts" (iterates through all connected gtmds) the monitor probe reply to each gtmd device that is connected via iQuery.  In some deployments, a gtmd may be connected with multiple connections to different self IPs to same big3d, and when sending a probe reply, big3d skips over any iQuery connections that are connected to a self IP other than the one where the monitor probe request was received. This behaviour ensures that each connected gtmd only recieves one copy of the monitor probe reply.

This message will be seen in the debug logs any time big3d skips over an iQuery connection, which will happen any time a gtmd is connected to more than one self IP on the same big3d device. The message can be safely ignored.

Recommended Actions

The messages are for debug purposes, and are benign.
