Topic

Support for the Windows 8.1 operating system and Internet Explorer 11 is available for several BIG-IP APM versions.

Note: Depending on your BIG-IP APM version, support for Windows 8.1 and Internet Explorer 11 may require a hotfix.

Description

Starting in 11.5.0, the BIG-IP APM system supports the Windows 8.1 operating system and Internet Explorer 11. For 11.2.0 through 11.4.x, BIG-IP APM systems with installed hotfixes can also support the Windows 8.1 operating system and Internet Explorer 11.

For a list of operating systems and browsers that the BIG-IP APM system supports, refer to K14047: Supported operating systems and web browsers for the BIG-IP APM system. 

    Impact

    For other versions, the BIG-IP APM system may not correctly detect clients that run Windows 8.1 and Internet Explorer 11. This can cause the following issues:

    • BIG-IP APM client operating system detection may not correctly detect the Windows 8.1 operating system.
    • BIG-IP APM client type detection may not correctly detect Internet Explorer 11.
    • You cannot upgrade the Windows 8.1 installed BIG-IP APM components.
    • The standalone BIG-IP Edge Client system may not install correctly on devices that run Windows 8.1.
