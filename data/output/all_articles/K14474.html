Known Issue

You may experience a memory leak when using the BIG-IP High Speed Logging (HSL) feature.

This issue occurs when the following conditions are met:

  • Your BIG-IP system uses HSL.
  • The connection to the remote logging host fails.

For each failed HSL connection, the BIG-IP system may leak 128 bytes of Traffic Management Microkernel (TMM) memory.

Impact

The BIG-IP system may exhaust available memory and fail over to another system in the device group.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H423653 on the Diagnostics > Identified > Low screen.
  • The BIG-IP system becomes unresponsive or fails over to another system in the device group.
  • TMM may crash and generate a core file in the /shared/core directory.
  • The TMM memory utilization graph may constantly grow.

Resolution

Status

F5 Product Development has assigned ID 423153 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can resolve the underlying reasons for the connection failures to the remote logging host, or temporarily disable HSL.
