Known Issue

The BIG-IP Server SSL profile may reject Secure Sockets Layer (SSL) server certificates used for server authentication.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system uses a virtual server associated with a Server SSL profile.
  • The Untrusted Certificate Response Control option in the Server SSL profile is set to ignore.
  • The SSL server uses a self-signed or untrusted SSL certificate for server authentication.

Setting the Untrusted Certificate Response Control option to ignore specifies that the system should ignore untrusted certificates and allow connections. However, the BIG-IP system may still reject self-signed or untrusted SSL certificates from the server during server authentication.

Impact

The BIG-IP system drops SSL connections.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system rejects self-signed or untrusted SSL certificates from the server when performing server authentication, even though the Untrusted Certificate Response Control option is set to ignore.
