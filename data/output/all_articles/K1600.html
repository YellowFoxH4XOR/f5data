Issue

When you try to create a virtual server from the command line, or from the Configuration utility, you may receive the following error:

Error 300 — The requested virtual IP and netmask addresses are incompatible

This error indicates that you specified a subnet mask for a normal virtual server. You can use a subnet mask only when creating network virtual servers.
