Known Issue

Description

The BIG IP APM rewrite process may incorrectly handle dynamically created script tags.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The web application dynamically creates script tags.
  • The web application uses the text property on a dynamically created script tag.
  • Client-side traffic is generated using a browser other than Internet Explorer.

In the following example, the script element e is dynamically created with its property text assigned an href attribute:

e = document.createElement('script');  document.body.appendChild(e);
e.text = 'document.write("<a href=http://www.us>click me</a>")'

The system may not properly rewrite the value of the text property, leading to application error.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use portal access, requested pages fail to display.
  • When you use portal access, actions on web applications fail to run.
  • Web applications malfunction or fail to render properly in browsers other than Internet Explorer.
