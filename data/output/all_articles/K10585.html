Known Issue

This is the result of a known issue. If you select a specific issuer in the Required client certificate issuer menu for a master group, that setting will continue to take effect even if you replace the client root certificate on the FirePass controller. When viewing the master group configuration after replacing the client root certificate, the Required client certificate issuer menu will contain the default value of Any issuer, even though the master group is still configured to require the old issuer.

When this issue occurs, users are unable to log on to the FirePass controller until the Required client certificate issuer menu is updated with the new issuer.

Note: This issue does not occur if you selected Any issuer in the Required client certificate issuer menu prior to replacing the client root certificate.

Note: The Required client certificate issuer menu is located on the Users: Groups: Master Groups page under the Authentication tab.

F5 Product Development tracked this issue as CR116825 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative HF-603-5 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

You can work around this issue by selecting the new issuer in the Required client certificate issuer field. To do so, perform the following procedure:

Note: FirePass cannot perform client certificate authentication without a client root certificate. If you have not installed a new client root certificate on the FirePass controller, perform that task before performing the following procedure. In addition, client certificates issued by the old issuer will no longer be valid.

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Master Groups page.
  3. In the Master Group menu, select the name of the master group you want to configure.
  4. Click the Authentication tab.
  5. In the Required client certificate issuer menu, select the name of the new client root certificate issuer.
  6. Click the Update button.
