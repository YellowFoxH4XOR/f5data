Known Issue

MCP does not recognize the Notify Status to Virtual Address option when using the Selective setting of ICMP echo.

This issue occurs when all of the following conditions are met:

  • The virtual server is configured with the Notify Status to Virtual Address option (default).
  • The ICMP echo setting for the virtual server address is configured to use Selective.

Impact

The previous setting will continue to take effect until an unrelated change is made to the virtual address, at which point the new setting will take effect.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When selecting  Notify Status to Virtual Address on a virtual server and using the Selective setting of ICMP echo for a corresponding virtual address, MCP does not recognize that this setting changed and does not modify the ICMP echo settings of the virtual address accordingly. 

Resolution

Status

F5 Product Development has assigned ID 671261 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Workaround

After changing the Notify Status to Virtual Address option on a virtual server where the Selective setting of ICMP echo is used for the corresponding virtual address, make another change to the virtual address to initiate the new setting to take effect.
