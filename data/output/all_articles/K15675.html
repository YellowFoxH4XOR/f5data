Issue

Error Message

err tmm[PID#]: 01490514:3: 00000000: Access encountered error: ERR_ARG. File: ../modules/hudfilter/access/access_session.c, Function: access_session_handle_pool, Line: <XXXX>

In this error message, note the following:

  • PID# is the process ID number of the reporting Traffic Management Microkernel (TMM) process.
  • <XXXX> is the line number of access_session.c code that processed the event.

For example:

virtual-siteone err tmm[8140]: 01490514:3: 00000000: Access encountered error: ERR_ARG. File: ../modules/hudfilter/access/access_session.c, Function: access_session_handle_pool, Line: 3534

Message Location

You may encounter this message in the following location:

  • In the /var/log/apm file

Description

This message occurs when the following condition is met:

  • There are no available members of the virtual server-associated pool.

    For example, either the health monitors marked down the configured destination pool members, or pool members have been administratively disabled, leaving the pool with no available members to send the request.

Impact

BIG-IP APM 11.4.0 and later

  • The BIG-IP APM virtual server sends the client the following web page response:

    "You do not have permission to access this page.
    Requested pool is not available now.
    Click here to retry
    Click here to logout"

  • The system logs an error message similar to the following example to /var/log/apm:

    <virtual server name> err tmm[22303]: 01490514:3: 00000000: Access encountered error: ERR_ARG. File: ../modules/hudfilter/access/access_session.c, Function: access_session_handle_pool, Line: <XXXX>

BIG-IP APM prior to 11.4.0

  • The virtual server sends a connection reset to the requesting IP address.
  • The system logs an error message similar to the following example to /var/log/apm:

    <virtual server name> err tmm[8140]: 01490514:3: 00000000: Access encountered error: ERR_ARG. File: ../modules/hudfilter/access/access_session.c, Function: access_session_handle_pool, Line: <XXXX>

Recommended Actions

None
