Topic

This article describes a hardware limitation on the following platforms that may prevent the system from preserving the source port for certain configurations.

  • BIG-IP Virtual Edition
  • BIG-IP 2000/4000 series
  • BIG-IP tenants on rSeries 2000/4000

Description

The BIG-IP Virtual Edition/2000/4000 series and tenants on rSeries 2000/4000 platforms use a Clustered Multiprocessing (CMP) hash algorithm that is different from other BIG-IP platforms.These platforms use a Receive Side Scaling (RSS) algorithm for CMP hash functions. The RSS algorithm allows systems to dis-aggregate client flows based on the source IP address, destination IP address, and TCP/UDP source and destination ports. However, for some virtual server configurations, the RSS algorithm does not preserve the source port even when the source port setting is set to Preserve. This is known to affect the following configurations:

  • Virtual servers with Address Translation enabled (This is a typical configuration, except for forwarding virtual servers.)
  • Virtual servers with Source Address Translation enabled
  • SNATs
  • NATs

Note: If you must preserve the source port, you can configure virtual servers or SNATs to use the Preserve Strict option instead of the Preserve option. However, this configuration may result in a significant performance impact to your BIG-IP system traffic.
