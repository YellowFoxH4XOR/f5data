Known Issue

Attempts to create a user configuration set (UCS) archive on a BIG-IP system may fail.

This issue occurs when the following condition is met:

  • You attempt to create a UCS archive using the representational state transfer (REST) interface for iControl.

Impact

The UCS archive is not created.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Upon issuing the request to create a UCS archive, the process fails with an error message similar to the following example:

    {"code":500,"message":"UCS saving process failed.","errorStack":[]}

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) or the Configuration utility to create a UCS archive.
