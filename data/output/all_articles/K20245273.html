Known Issue

The BIG-IP system may load an invalid virtual server configuration when the NT LAN Manager (NTLM) profile is used.

This issue occurs when all of the following conditions are met:

  • The system uses a virtual server with an NTLM profile.
  • The virtual server does not have the HTTP profile applied.
  • You load the BIG-IP configuration.

Impact

Virtual servers cannot be contacted due to invalid configurations.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H573036 on the Diagnostics > Identified > High page.
  • In the /var/log/ltm log file, you observe an error message similar to the following example:

    err tmm4[18797]: 01010007:3: Config error: virtual_server_profile no suitable hudchain
    err tmm4[18797]: 01010007:3: Config error: add virtual server profile error

  • Affected virtual servers fail to load and cannot be contacted.

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can apply the HTTP profile to the affected virtual server.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
