Known Issue

The BIG-IP system may report an error message when you attempt to add a device to the device trust.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility to attempt to add a peer device to the device trust.
  • The IP address of the peer device is not reachable.

Impact

You are unable to add a peer device to a device trust.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Configuration utility displays an error message similar to the following example:

    java.ioException: Could not read response from server: ParseError at [row, col]:[1,238] Message: The processing instruction target matching "[xX[mM][L]" is not allowed

  • You are unable to add a peer device to the device trust.
  • The error message, being too generic, may prolong troubleshooting on HA failures.

Workaround

To work around this issue, you can verify that the peer device is reachable before adding the device to the device trust.
