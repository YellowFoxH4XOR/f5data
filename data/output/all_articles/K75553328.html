Known Issue

You are unable to delete a symmetric optimization local endpoint using the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You have the BIG-IP AAM or BIG-IP WOM module licensed and provisioned on the BIG-IP system.
  • You create a local endpoint and associated iSession listener (virtual server) using the Configuration utility.
  • You delete the iSession listener (virtual server) and then attempt to delete the local endpoint using the Configuration utility.

When you attempt to delete the local endpoint using the Configuration utility, the BIG-IP system also attempts to delete the associated iSession listener or virtual server.  If you delete the iSession listener using the Local Traffic > Virtual Servers page or the Acceleration > Symmetric Optimization > Local Endpoint > iSession Listeners page, and then attempt to delete the local endpoint, the delete operation fails with an error message indicating the virtual server was not found.

Impact

The delete operation fails and you are unable to delete the local endpoint.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to delete a local endpoint using the Configuration utility, you might observe messages similar to the following example:

    01020036:3: The requested Virtual Server (/Common/isession-virtual) was not found.

  • Administrators are unable to delete the local endpoint using the Configuration utility.

Workaround

To work around this issue, you can delete the local endpoint using the Traffic Management Shell (tmsh). To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Delete the local point by typing the following command:

    delete /wom local-endpoint

  3. Save the change by typing the following command:

    save /sys config

  4. Exit the tmsh utility by typing the following command:

    quit
