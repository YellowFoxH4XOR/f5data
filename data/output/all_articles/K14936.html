Known Issue

Server certificate verification may fail with the BIG-IP Edge Client command line for Linux.

This issue occurs when all of the following conditions are met:

  • You are using the Linux version of the BIG-IP Edge Client to connect to the BIG-IP APM system.
  • The Secure Sockets Layer (SSL) certificate in use has more than 10 entries in the Subject Alternative Name field.

When you establish a Virtual Private Network (VPN) connection, the BIG-IP Edge Client command line for Linux attempts to verify the server's SSL certificate. The certificate verification mechanism limits the number of entries allowed in the Subject Alternative Name to 10. If a certificate contains more than 10 entries, certificate verification fails to prevent network access.

Impact

Users who use the BIG-IP Edge Client command line for Linux are unable to establish network access to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP Edge Client command line for Linux fails to establish VPN connections to the BIG-IP APM system.
  • You may observe the following error messages from the f5fpc --info command:

    Connection Status: logon failed

Workaround

To work around this issue, you can disable certificate verification using the -x option to the f5fpc command. To do so, perform the following procedure:

Impact of workaround: This procedure specifies that the trusted CA certificate is not verified for trust at all and is not recommended under normal conditions.

  1. Log in to the client system and open a command shell.
  2. To establish a VPN connection to the BIG-IP APM system, type the following command:

    f5fpc -s -x -t <[https://]hostname[:port]>

    For example:

    f5fpc -s -x -t https://apm1.example.com
