Description

After downgrade from 15.1.2.1 to 13.1.3.6 GUI access is not available and page displays the following message:

Starting web server

Environment

  • BIG-IP
  • syslog

Cause

The syslog configuration from the new version is not backward compatible.

 

Recommended Actions

From the command line remove the syslog configuration after booting to 15.1.2.1 and reconfigure using the following:

  • K13333: Filtering log messages sent to remote syslog servers (11.x - 15.x)
  • K000135645: Configuring the local IP address that syslog binds to in a HA environment
  • K13080: Configuring the BIG-IP system to log to a remote syslog server (11.x - 17.x)
  • K26457459: Syslog messages are sent with incorrect source IP
