Description

When the user attempts to upload a file to the site, Attack Signatures are triggered.

Environment

  • Request contains header Content-Types "multipart/form-data"
  • URL where the file is upload is configured
  • Parameters are configured with Data Type: File Upload
  • Requests is still not allowed

Cause

In most cases the configurations described in the section Environment should work, and arbitrary file uploads should be allowed.

However, there are some cases where additional configuration such as disabling Attack Signature on the Parameter.
 

Recommended Actions

This only applies to File Upload Parameters.
  1. Identify the parameter
  2. Browse to the Parameter
  3. Disable the Attack Signature
Note: This selectively disables the Attack Signature on the Parameter level, however, not the URLs.
