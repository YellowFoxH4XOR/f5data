Description

Unable to generate Qkview file with error on command line:

 

Another qkview is running.

You can't run multiple instances of qkview at once.

 

 Environment

  • BIG-IP LTM VE
  • qkview

 Cause

/var/tmp folder missing

 Recommended Actions

Re-create the /var/tmp symbolic link:

ln -s ../shared/tmp /var/.
