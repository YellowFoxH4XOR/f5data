Description

After upgrading the BIG-IP software version to 15.x or higher, the configuration may fail to load.

The configuration fails to load with the error message found in /var/log/ltm:
Bot Defense Profile (profile name) Micro Service (micro service name) must contain at least one url

Environment

  • BIG-IP ASM
  • Software upgrade to version 15.x or later
  • Bot defense profile configured with a Micro Service

Cause

In software versions before 15.x, a Micro Service in a Bot Defense Profile can be created without a "Protected URL" defined.
Version 15.x or later requires at least one Protected URL defined.
If there was no Protected URL defined in versions before 15.x, the configuration will fail to load after upgrade to version 15.x or higher due to the missing URL.

Recommended Actions

Workaround 1: Rectify issue from previous version
  1. Rollback to the previous active Boot Location
  2. Open the configuration of the Bot Defense Profile advised in the error message
  3. Add a URL or wildcard (*) into the Micro Service Protected URL field.
  4. If configured, confirm other Bot Defense Profile configurations and correct where required.
  5. Activate the previously installed boot location with the Install Configuration option set to 'Yes'.
Workaround 2: Rectify issue while in the new version
  1. Remove the 'micro-services' stanza from /config/bigip.conf file using a text editor like 'vi' to edit /config/bigip.conf
  2. Reload the configuration with 'tmsh load sys config'
  3. Once the configuration has loaded, recreate the Micro Service in the affected Bot Defense Profile
