K6593: VLAN Failsafe can be configured to reset its timer on reception of any frame

Issue

By default, when the BIG-IP LTM system receives unsolicited traffic, such as bridge protocol data unit (BPDU) messages, the VLAN failsafe timer does not reset. Only traffic that reaches TMM, such as ARP and IPV6 neighbor discovery responses, resets the VLAN failsafe timer.

Beginning with BIG-IP LTM 9.2.4 for the BIG-IP 9.2.0 software branch, and 9.4.0 for the BIG-IP 9.4.0 software branch, you can change the default behavior by typing the following command:

bigpipe db Failover.VlanFailsafe.ResetTimerOnAnyFrame true

The bigpipe db Failover.VlanFailsafe.ResetTimerOnAnyFrame true command resets the timer after the VLAN receives any frame, which is equivalent to BIG-IP 4.x behavior.

Important: For information about the Failover.VlanFailsafe.ResetTimerOnAnyFrame db setting, refer to K7093: Outbound monitor traffic can cause the BIG-IP LTM system to incorrectly reset the VLAN failsafe timer, preventing failover from occurring.

F5 Product Development tracked this feature request as CR64239, CR66174, and CR66175.
