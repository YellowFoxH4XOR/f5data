K10498: The BIG-IP WebAccelerator may log a cryptic error message when /cdserver is not mounted during a USB CD-ROM installation

Topic

The BIG-IP system supports software installations using a USB CD-ROM drive on certain platforms.

Note: For more information refer to K9589: Installing BIG-IP software from a USB CD-ROM drive.

Note: Due to constant changes in the performance and configuration of USB CD-ROM drives, F5 cannot guarantee the success of all drives; however, most standard USB CD-ROM drives operate successfully with the BIG-IP system.

Occasionally, a BIG-IP WebAccelerator installation fails to proceed when booting off a particular brand of USB CD-ROM because the /cdserver directory is not properly mounted. When this occurs, the system either does not log an error message advising the user to change the USB CD-ROM hardware, or it logs a cryptic error message that appears similar to the following example:

usb.c: USB device not accepting new address=2 (error=-110)
usb.c: USB device not accepting new address=3 (error=-110)

Changing the USB CD-ROM drive hardware to a different brand will usually resolve the issue and allow the installation to proceed.

F5 Product Development tracked a Request for Enhancement (RFE) to log an error message advising the user to change the USB CD-ROM hardware when the /cdserver directory is not properly mounted during the installation process. F5 Product Development tracked this RFE as ID 222783 (formerly CR124411) and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
