K000141443: Zone based filter doesn't work for vwire on AFM

Type
Support Solution
Published
2024-10-27
Updated
2024-10-27
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000141443

Description

AFM doesn't filter traffic when the rule has Zones and VWires configured.

Environment

  • VWire
  • AFM
  • Zone based rules

Cause

BUG ID 1694181

Workaround

Change the rule to include VLANS explicitly instead of zones.

Additional Information

None
