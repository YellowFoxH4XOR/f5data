Description

There are cases where you dont have the ability to login to the BIG IP (lost admin and root password).

From VE console you get the Login prompt - no option to login too.

While the other BIG IP in the HA environment is function and have the ability to access the Web UI.

Environment

  • BIG IP VE
  • HA

Cause

lost password for admin and root.

Recommended Actions

Use the following steps:

  1. From the accessible BIG IP: Create another user (i.e. "admin_test") with Administrator role and access with "Advanced Shell"
  2. Sync with the other BIG IP.
  3. Once the Sync done log in the other BIG IP and use the same username and password you have created.

Additional Information

Another option to overcome it is by using single-user mode option - you may use the following articles to assist you:

  • K14662: Restarting the BIG-IP system in single-user mode (GRUB2)
  • K35811337: Recover the root password on non-RAID BIG-IP platforms (BIG-IP 14.1.0 and later)
