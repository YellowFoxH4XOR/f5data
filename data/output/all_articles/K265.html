Known Issue

This is the result of a known issue. When you perform a network boot and restore the system software from a UCS archive, BIG-IP does not correctly install the time zone data files.

F5 Networks Product Development tracked this issue as CR36993 and CR41795.

Workaround

To set the time zone, perform the following steps:

  1. Log in to the command line.
  2. Run the Setup utility, by typing the following command:

    config

  3. From the menu, choose option Z.

  4. Follow the prompts to set the time zone.
