K71335139: When BGP is enabled on LTM, BIG-IP sends several ARP requests over the interface asking for its own virtual addresses.

Source

Description
When BGP is enabled on LTM, BIG-IP sends several ARP requests over the interface asking for its own virtual addresses.  40 - 50 ARP Broadcasts per second. 

Environment
  • BGP enabled.
  • BIG-IP LTM.

Cause
Unknown at the time of publication.

Recommended Actions
Clear MCPD binary and reboot the device by running the below commands during a maintenance window.
  1. touch /forcefsck
  2. bigstart stop 
  3. rm -f /var/db/mcpd* 
  4. reboot
