Known Issue

This is the result of a known issue. The Packet Velocity ASIC (PVA) is not compatible with asymmetric connections across multiple VLANs.

F5 Product Development is tracking this issue as CR45694.

Workaround

To work around this issue, you can disable the PVA globally on the system. To do so, type the following command:

Note: The following command will disable all hardware acceleration.

bigpipe db Pva.Acceleration none

Note: If you are running a BIG-IP version previous to 9.1.0, you will need to ensure that the VLAN-keyed.connections feature is disabled. For information about disabling VLAN-keyed.connections, refer to K4604: Asymmetric routed connections dropped when VLAN-keyed connections are enabled.
