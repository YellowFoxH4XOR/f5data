https://my.f5.com/manage/s/article/K28500421

Description
The BIG-IP will be producing TMM core files downing all links, and going offline.
This will occur during connection resets on a virtual server configured with an APM profile, an IRule, and an HTTP profile not configured with a fallback host.
 

Environment

  • BIG-IP APM
  • APM Profile
  • iRules
  • HTTP Profile not configured with a fallback host

Cause

Bug ID 968929

Recommended Actions

  1. Follow the work around in the Bug Tracker link above.
    OR
  2. Open a support ticket to see if an engineering hotfix is available for ID 968929.
