Known Issue

Security policies may synchronize to peer devices as inactive policies.

This issue occurs when all of the following conditions are met:

  • You create a Sync-Only device group and enable the BIG-IP ASM Synchronization and Automatic Sync features.
  • You create a security policy that is synchronized to the device group.
  • The BIG-IP ASM system is configured with one of the following options:
    • There are no Sync-Failover device groups configured on the devices.
    • The Sync-Failover device group is configured for manual synchronization.

Impact

BIG-IP ASM policies are created as inactive policies on the peer device, resulting in an inconsistency between peers.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the Active Policies on the peer devices, the synchronized policy is not listed.
  • When you view the Inactive Policies on the peer devices, the synchronized policy is listed.

Workaround

To work around this issue, you can either disable the Automatic Sync feature on the Sync-Only device group with ASM Synchronization enabled, or you can enable the Automatic Sync feature for the Sync-Failover device group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Enable or disable the Automatic Sync feature for your device group, using the following syntax:

    modify /cm device-group <device group name> auto-sync <enabled or disabled>

    For example, to disable the Automatic Sync feature on a Sync-Only device group named MySyncOnlyGroup that has the ASM Synchronization feature enabled, type the following command:

    modify /cm device-group MySyncOnlyGroup auto-sync disabled

    To enable the Automatic Sync feature on a Sync-Failover device group named MyFailoverGroup, type the following command:

    modify /cm device-group MyFailoverGroup auto-sync enabled

  3. Save the configuration change by typing the following command:

    save /sys config
