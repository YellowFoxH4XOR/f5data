Description

When 'save sys config' command is executed or BIG-IQ runs a script for 'Stats Collection Status' followed by 'save sys config', below logs are generated in LTM logs for every 'save sys config':

clusterd[xxxx]: 013a0006:5: mcpd tells us that config is being saved; incrementing this blade's revision and saving cluster config

At the same time you can see a log entry for 'save sys config' command executed in audit logs: 
icrd_child[xxxx]: 01420002:5: AUDIT - pid=xxxxx user=admin folder=/Common module=(tmos)# status=[Command OK] cmd_data=save sys config

Environment
 
The above message is logged when one of the below conditions is true. 
  • BIG-IP is managed by BIG-IQ with 'Stats collection status' is enabled. 
  • 'save sys config' is executed on BIG-IP.
Cause

The message "mcpd tells us that config is being saved; incrementing this blade's revision and saving cluster config" simply means a config change has happened and the device has executed "Save sys config". This message tells us that the config change was successfully made and is being sent to the secondary blades.

If we do not have those logs we will not be able to tell if the secondary blades are getting the config changes. The mcpd daemon on the Viprion Host and the VCMP guest gets notified that it's being updated and updating the revision in clusterd. So that for example you were to bring another blade online it could span across the blade with the updated version information.
 
Recommended Actions
 
In summary the message is just clusterd got a notice from MCPD that something was updated. Clusterd makes note of that and logs the messages we saw. So this logs is just informational and does not harm or affect anything and also can be helpful in troubleshooting if something goes wrong.
