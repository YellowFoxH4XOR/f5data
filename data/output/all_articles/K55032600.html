K55032600: BIG-IQ HA File-Sync status does not reflect the latest successful synced date

Type
Support Solution
Published
2020-09-09
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ 7000
Source
https://my.f5.com/manage/s/article/K55032600

Description

The "File Sync Status" under BIG-IQ HA settings does not reflect the latest successful synced date / time even through manually pressing the "Sync Files” button.
BIG-IQ HA File-Sync is not updating.
In addition, the files does not perform File Sync no matter what is the internal set at the “File Sync Interval”.

You will see this error in restjavad logs:

/var/log/restjavad.2.log

[ERROR][YYYY-MM-DDTHH:MM:SS.MMM+HH:MM][/shared/ha/sync-files-task/<UUID>/worker SyncFilesTaskWorker]

Environment

  • BIG-IQ
  • High Availability
  • Version 7.1.0

Cause

task-scheduler is DISABLED

Recommended Actions

  1. Update a new start time and enabled the schedule from command line.

    Note: Replace the "YYYY-MM-DDTHH:MM:SS.MMM+HH:MM" to the current date and time

    # restcurl -X PATCH /shared/task-scheduler/scheduler/<UUID> -d '{"timeToStartOn" : "YYYY-MM-DDTHH:MM:SS.MMM+HH:MM"}'
    # restcurl -X PATCH /shared/task-scheduler/scheduler/<UUID> -d '{"status" : "ENABLED"}'
