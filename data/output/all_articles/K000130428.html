K000130428: Missing Accept Button for Violations

Type
Support Solution
Published
2023-01-01

Applies to

  • BIG-IP ASM
Source

Description

For some violations ( such as Illegal Response Status Code ), ASM does not show Accept Suggest button.


Environment

  • Accept Button Missing in both Event Log and Traffic Learning
  • Learning Suggestion is available in Traffic Learning


Cause

The affected policy was created using a Parent Policy.


In the Parent Policy, the Inheritance Setting is set to Mandatory (child inherits the settings).



With Mandatory, requests that trigger suggestions and/or violations, Administrator would not be able to add to the policy.


Recommended Actions

The setting can be changed to Optional or None from the Inheritance settings of the Parent Policy.


Additional Information

None.
