Topic

You should consider using this procedure under the following condition:

  • You want your BIG-IP DNS system to set the recursion available (RA) bit for all answers for wide IP names.

Description

The RA bit is set or cleared by a nameserver in all DNS responses to indicate if recursion services are available. The bit is true if the nameserver is willing to provide recursive service for the client, regardless of whether the client requested recursive service. However, some applications may not accept DNS responses that do not have the recursion bit set.

Two separate daemons can answer DNS queries on a BIG-IP DNS system. The gtmd process answers for wide IP names, and the named process answers for non-wide IP (BIND) DNS zone entries.

The gtmd process is authoritative for wide IP names and does not, by default, set the RA bit in responses. If you require the BIG-IP DNS system to set the RA bit for all gtmd answers for wide IP names, perform the following procedure for your version:

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access the BIG-IP DNS Configuration utility.
  • You have configured a wide IP on your BIG-IP DNS system.

Procedures

Setting the RA bit for all wide IP name answers for DNS queries (11.5.0 and later)

To configure the BIG-IP DNS system to set the RA bit for all wide IP name answers for DNS queries, perform the following procedure:

Impact of procedure: The BIG-IP DNS system enables recursive DNS queries, regardless of whether the requesting local DNS enabled recursive queries.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Settings > GSLB > General.
  3. Under the GSLB section, select the Set Recursion check box.
  4. Click Update.

Setting the RA bit for all wide IP name answers for DNS queries (10.x through 11.4.1)

To configure the BIG-IP DNS system to set the RA bit for all wide IP name answers for DNS queries, perform the following procedure:

Impact of procedure: The BIG-IP DNS system enables recursive DNS queries, regardless of whether the requesting local DNS enabled recursive queries.

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Global Traffic > General.
  3. Select the Gtmd Sets Recursion check box.
  4. Click Update.
