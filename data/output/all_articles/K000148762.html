F5 ACI ServiceCenter is an application that runs natively on Cisco Application Policy Infrastructure Controller (APIC), providing administrators a unified way to manage both L2-L3 and L4-L7 infrastructure in F5 BIG-IP and Cisco Application Centric Infrastructure (ACI) deployments. The application offers three main independent use cases, which include enhanced ACI-to-BIG-IP visibility, L2-L3 network management capability, and L4-L7 application services to ACI workloads. You can also use F5 ACI ServiceCenter as part of the ACI REST API model, which allows administrators to integrate the L2-L7 workflow into an organization's automation and orchestration model seamlessly.

Cisco updated the product roadmap for Cisco ACI and decided that, starting with ACI release 6.1.2, AppCenter and its application can no longer be hosted on Cisco APIC. 

For more information about F5 ACI ServiceCenter, refer to https://dcappcenter.cisco.com/f5-aci-servicecenter.

Advanced notification of the End of Support for F5 ACI ServiceCenter

Key details

  • End of Support (EoS) date: August 31, 2027
  • Affected product/service: F5 ACI ServiceCenter running on supported Cisco APIC version
  • Reason for change: Cisco APIC will no longer support DC apps starting in 6.1.2

What this means for customers

After the EoS date:

  • F5 will no longer provide updates, including security updates or bug fixes, for F5 ACI ServiceCenter.
  • Technical assistance and customer support for F5 ACI ServiceCenter will no longer be available.

Recommended next steps

Customers using F5 ACI ServiceCenter must use an alternative way to support their use cases with the application, which could be manual or automated (or both). For more information, refer to the resources in the following table.
