Source

Description

Edit the parameter : Value Meta Characters via Swagger file.

Environment

  • ASM policy
  • Swagger file
  • WAF declaration  

Cause

None

Answer/Recommended Actions

Swagger does not support meta-character modifications, we recommend using Declarative WAF for your ASM policy management.

This method provides the necessary control for advanced security settings that fall outside the standard OpenAPI spec.

Example of declarative WAF : https://clouddocs.f5.com/products/waf-declarative-policy/schema_v17_1.html

                           "metacharOverrides" : {
                              "items" : {
                                 "properties" : {
                                    "isAllowed" : {
                                       "type" : "boolean"
                                    },
                                    "metachar" : {
                                       "type" : "string"
                                    }
                                 },
                                 "required" : [
                                    "metachar"
                                 ],
                                 "type" : "object"
                              },
                              "type" : "array"
                           },
