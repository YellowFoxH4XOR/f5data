Topic

This article provides a brief description of the F5 individual Edge products.

  • BIG-IP Edge Gateway
  • BIG-IP Edge Portal
  • BIG-IP Edge Client for Windows, MAC OS X, and Linux
  • BIG-IP Edge Client for Apple iOS
  • BIG-IP Edge Client for Android

BIG-IP Edge Gateway

The BIG-IP Edge Gateway is a BIG-IP device that is licensed for multiple BIG-IP modules.  Prior to 11.4.0, the BIG-IP Edge Gateway is licensed for APM, WOM, and WebAccelerator. 

With the End of Sale announcement for BIG-IP Edge Gateway, the previously-described module combination is no longer available after you upgrade to 11.4.0 or later versions. The BIG-IP 11.4.0 release integrates the WebAccelerator and WOM modules into the Application Acceleration Manager (AAM) module.

Licensing and provisioning BIG-IP APM and BIG-IP AAM provides the same functionality as previous versions of BIG-IP Edge Gateway.

BIG-IP Edge Portal

The BIG-IP Edge Portal is an application that Apple iOS (iPhone, iPad, and iPod touch) and Android users can install on their devices to gain access to protected web applications.

For more information about the Apple application, refer to K12328: Overview of the BIG-IP Edge Portal application for Apple iPhone, iPad, and iPod touch.

For more information about the Android application, refer to K12644: Overview of the BIG-IP Edge Portal application for Android devices.

BIG-IP Edge Client for Windows, MAC OS X, and Linux

The BIG-IP Edge Client application is software that is installed on a user's device that allows them to establish a connection to BIG-IP Edge Gateway, BIG-IP APM, and FirePass controllers. The BIG-IP Edge Client application is available for Windows Operating Systems, Windows Mobile devices, Linux/Mac OS X.

You can use the BIG-IP Configuration utility or the FirePass Administrative Console to configure and download the BIG-IP Edge Client application for Windows Operating Systems and Windows Mobile devices. For more information about configuring and using the BIG-IP Edge Client application, refer to the Configuration Guide for BIG-IP Access Policy Manager or the FirePass Controller Administrator Guide, specific to your version.

While there is no external download site, Windows, Linux, and Mac OS X users can download and install the BIG-IP Edge Client software by connecting to a BIG-IP Edge Gateway, BIG-IP APM, or FirePass Controller with a browser, and then launching a Network Access session. Depending on the user's browser settings, the client components will either automatically download and install or the user will be prompted to start the download process.

Note: To confirm that your FirePass controller version supports Linux and Mac OS X clients, refer the Compatibility Matrix for your version. All BIG-IP Edge Gateway and BIG-IP APM versions support Linux and Mac OS X clients.

BIG-IP Edge Client for Apple iOS

The BIG-IP Edge Client for Apple iOS allows an iOS device to have full VPN access to BIG-IP Edge Gateway, BIG-IP APM, or FirePass.

You can download the BIG-IP Edge Client application for Apple iOS devices from iTunes or from Apple's F5 BIG-IP Edge Client website.

For information about the BIG-IP Edge Client App for iOS, refer to K12462: Overview of the BIG-IP Edge Client application for the Apple iPhone, iPad and iPod touch.

BIG-IP Edge Client for Android

The BIG-IP Edge Client for Android allows an Android device to have full VPN access through BIG-IP Edge Gateway, BIG-IP APM, or FirePass.

You can download the BIG-IP Edge Client application for Android from the Android Marketplace F5 BIG-IP Edge Client for Android. Choose the client for your version of the Android OS.

Note: The previous link takes you to a resource outside of AskF5, and it is possible that the information may be removed without our knowledge.

Note: Support for Apple iOS devices was introduced in FirePass 6.1.0. Older versions of FirePass do not support Apple iOS devices. All BIG-IP Edge Gateway and BIG-IP APM versions support Apple iOS devices.
