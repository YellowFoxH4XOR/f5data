Known Issue

Single sign-on (SSO) login attempts may fail between the Enterprise Manager system and discovered BIG-IP devices.

This issue occurs when all of the following conditions are met:

  • Enterprise Manager and BIG-IP systems are configured to use remote authentication such as LDAP or Active Directory.
  • You attempt to establish a connection to a discovered BIG-IP system through the Enterprise Manager system.

Impact

The Enterprise Manager system fails to log in to discovered BIG-IP devices.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You cannot access remotely discovered BIG-IP systems from the Enterprise Manager system.
  • In the /var/log/ltm file of the discovered device, you observe error messages similar to the following example:

    notice mcpd[6789]: 01070829:5: Input error: Remote user message dropped (admin123 in [All]) because duplicate partition.
    err mcpd[6789]: 01070827:3: User login disallowed: User (admin123) is not an administrator, does not have a UID of zero, and has not been assigned a role on a partition.

Workaround

To work around this issue, and to properly update the role, you can log in directly from your workstation to the discovered BIG-IP system using the remote user's credentials.

Impact of workaround: Performing the recommended workaround should not have a negative impact on your system.
