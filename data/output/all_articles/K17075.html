Known Issue

Secure Sockets Layer (SSL) sessions may be terminated if an SSL client attempts to resume with different ciphers.

This issue occurs when all of the following conditions are met:

  • You have a virtual server with a Client SSL profile configured.
  • The SSL client attempts to resume an SSL session to the virtual server.
  • The original ClientHello message contains a different cipher list from the resuming message, and the resuming message contains a stronger cipher than was originally selected.

Impact

SSL sessions may be terminated by the client.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The client does not accept a server response, and terminates the session with an “Illegal Parameter” fatal alert.
