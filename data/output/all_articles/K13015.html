Issue

Error Message

SSL Exception: BIO Error

Message Location

You may encounter this message in the following location:

  • VMWare vCenter Converter interface

Description

This message occurs when all of the following conditions are met:

  • The vCenter Converter remotely accesses a target computer through a WOM iSession tunnel.
  • The vCenter Converter agent is not installed on the converted computer.

Impact

VMWare vCenter Converter is unable to virtualize systems that are connected through a WOM iSession tunnel.

Recommended Actions

You can correct this issue by performing one of the following two procedures:

  • Configuring the wom-tcp-lan-optimized profile
  • Manually installing the vCenter Converter agent on the target system

Impact of procedure: none

Configuring the wom-tcp-lan-optimized profile

  1. Log in to the BIG-IP Configuration utility of the system to which the vCenter Converter computer is local.
  2. Click Local Traffic.

    The Local Traffic navigation panel expands.
  3. Click Profiles under the Local Traffic navigation pane.
  4. Move the cursor over the Protocol tab.

    The Protocol menu displays below the Protocol tab.
  5. Click TCP.

    The list of configured TCP Protocol profiles is displayed.
  6. Click wom-tcp-lan-optimized.
  7. Select the Custom check box.
  8. Select the Deferred Accept check box.
  9. Select the Verified Accept check box.
  10. Click the Update button.

Manually install the vCenter Converter agent on the target system

For instructions about how to manually install the vCenter Converter, refer to the VMWare documentation.
