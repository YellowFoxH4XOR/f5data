Description

F5 VPN Helper Application fails to establish VPN with the error "Failed to download resource page" when connecting to a virtual server using an untrusted/invalid certificate

Environment

  • macOS
  • F5 VPN Helper Application 7247 and newer
  • Untrusted or Invalid certificate specified in the clientssl profile applied to the Virtual Server

Cause

Updated QT libraries are being used in the F5 VPN Helper application as of version 7247. The newer QT library attempts to validate the server certificate and fails the TLS handshake if the validation fails.

 

Recommended Actions

Use a valid certificate that VPN clients trust, in the clientssl profile of the virtual server. For more information on configuring the clientssl certificate of a virtual server, refer to Certificate key chain setting described in K14783: Overview of the Client SSL profile (11.x - 17.x).
