Description

Where <very long failure message> contains:

"msg": "Could not find csr for nodes: blade-1.chassis.local"

Environment

  • OpenShift install on VELOS
  • Adding blade

Cause

Blade(s) in question unable to NFS mount an export from the active controller.

The journalctl --boot --unit platform-services-deployment.service --no-pager command shows output similar to the following on the blade:

platform-deployment[3225]: Job for var-mnt-chassis.mount failed. See "systemctl status var-mnt-chassis.mount" and "journalctl -xe" for details.

Reviewing systemctl status --all, the service unit nfs-server.service on the controller shows:

● nfs-server.service - NFS server and services
   Loaded: loaded (/usr/lib/systemd/system/nfs-server.service; enabled; vendor preset: enabled)
  Drop-In: /run/systemd/generator/nfs-server.service.d
           └─order-with-mounts.conf
   Active: inactive (dead)
 
controller-1.chassis.local systemd[1]: Dependency failed for NFS server and services.
controller-1.chassis.local systemd[1]: Job nfs-server.service/start failed with result 'dependency'.

The device unit dev-partition_image-export_chassis.device on the controller shows:

● dev-partition_image-export_chassis.device
   Loaded: loaded
   Active: inactive (dead)
 
controller-1.chassis.local systemd[1]: Job dev-partition_image-export_chassis.device/start timed out.
controller-1.chassis.local systemd[1]: Timed out waiting for device dev-partition_image-export_chassis.device.
controller-1.chassis.local systemd[1]: Job dev-partition_image-export_chassis.device/start failed with result 'timeout'.

Furthermore, the partition_image volume group does not exist on the controller, when reviewing the output of the vgs or vgdisplay commands.

Bug ID1827869 tracks this issue.

  • Bug ID 1827869: Partition upgrade or creation fails on controller

Recommended Actions

To recover from this condition, PXE boot the affected controller:

  • K000152443: VELOS PXE clean install of system controller

Failing over to the non-affected controller should allow the OpenShift install to complete.
