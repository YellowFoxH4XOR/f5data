Gaining access to the / directory

Note: This Solution assumes that you created a backup of the original kernel on the local hard drive in the "/" directory.

To gain access to the / directory, perform the following steps:

  1. Connect directly to BIG-IP with a keyboard and log in at the console.
  2. Power cycle the BIG-IP system.
  3. After BIG-IP starts the 4...3...2... boot process, interrupt it by pressing the Enter key.
  4. At the boot: prompt, type the following command:

    bsd.generic -s

  5. Press the Enter key.

    The kernel will begin to boot.

  6. At the Root device prompt, type the following:

    wd0a

  7. Press the Enter key.
  8. At the shell prompt, you have the option to accept the default sh shell, or you can type type following:

    /bin/bash

  9. Press the Enter key.

    The # prompt displays.

  10. Type the following command to assign read/write privileges to the / directory:

    mount -u /

  11. Press the Enter key.
  12. Change to the / directory by typing the following command:

    cd /

Reinstalling/recovering the kernel

Note: This Solution assumes that you created a backup of the original kernel on the local hard drive in the "/" directory.

The kernels are linked in the main references bsd file in the / directory. The kernel you use depends on your system type. Generally, BIG-IP switches use SMP and BIG-IP server appliances use ANIP.

The kernels are located in the following files:

/bsd.smp
/bsd.anip

Note: For additional information about the kernel, refer to K1691: Selecting the proper BIG-IP kernel.

To reinstall the kernel, perform the following steps:

  1. Copy the kernel you backed up to the correct default kernel name.

    For example, to copy the SMP kernel, type the following command:

    cp /bsd.smp.backup /bsd.smp

  2. Verify that the new file and the backup file are the same size after you copy the files. To do this, run the md5 command against each file and verify that the 32-bit MD5 sums are identical.

    For example, to compare the sums for the /bsd.smp and the /bsd.smp.backup file, type the following command:

    md5 /bsd.smp /bsd.smp.backup

    The output should appear similar to the following example:

    c307fb0269e52a85ce81ba7e59d64b64 /bsd.smp
c307fb0269e52a85ce81ba7e59d64b64 /bsd.smp.backup
  3. Verify the permissions for the file.

    For example, the bds and bsd.smp files should have the following permissions:

    lrwxr-xr-x  1 support  wheel        7 Feb 22 17:32 bsd@ -> bsd.smp
-rwxr-xr-x  1 support  wheel  2763768 Feb 22 17:32 bsd.smp*
  4. If the file permissions do not reflect these permissions, set them.

    For example, for SMP you would type the following command:

    chmod 755 /bsd.smp

  5. If the /bsd symbolic link does not exist, create it.

    For example, to create the SMP symbolic link, type the following command:

    ln -s /bsd.smp /bsd

  6. Reboot the system to make the original kernel operative.
