Known Issue

The Disable on parameter action is missing from the BIG-IP ASM Attack Signature Staging screen.

When the Enable Signature Staging option is configured for the security policy, the Attack Signature Staging Configuration utility screen should allow the administrator to disable an attack signature for a specific parameter after at least one incident has occurred.

This issue occurs when all of the following conditions are met:

  • Enable Signature Staging option is enabled in the policy
  • The system processes a request containing a parameter that triggers an attack signature

Impact

The administrator does not have the ability to disable a signature for a specific parameter from the Attack Signature Staging screen.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Disable on parameter action is missing from the Attack Signature Staging screen.

Workaround

To work around this issue, you can manually disable the attack signature for the parameter. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Application Security.
  3. Click Policies List.
  4. Click the policy name.
  5. Click Parameters.
  6. Click the appropriate parameter name.
  7. Click the Attack Signatures tab.
  8. Select the box next to the appropriate attack signature.
  9. From the State drop-down menu, select Disabled.
  10. Click the Update button.
  11. Click Policy.
  12. Click Apply Policy.
