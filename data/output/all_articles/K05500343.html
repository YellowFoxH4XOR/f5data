Known Issue

The F5 Access for iOS VPN profile configuration page may not fit on the screen. As a result, F5 Access does not properly render or display the Connection and Status buttons.

This issue occurs when all of the following conditions are met:

  • You are using the following F5 Access versions on iPadOS 15.1.
    • F5 Access 3.0.9
    • F5 Access 3.0.10
  • You are creating or viewing a profile on the VPN profile configuration page.

Impact

You are not able to see the Connection and Status buttons on the profile configuration page. This is a cosmetic issue for those familiar with the app while some users may not understand the information on the page.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe that the Connection or Status buttons are not rendered or displayed properly.
