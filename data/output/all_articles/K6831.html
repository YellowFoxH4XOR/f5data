Topic

Beginning with BIG-IP LTM 9.0.0, the BIG-IP LTM system supports alternate or non-standard FTP load balancing. This feature is handled through the FTP profile with the option to specify the alternative data port.

Although some FTP server applications allow the administrator to specify both the control port and the data port, most FTP server applications only allow the control port to be specified and will specify the data port as the control port value minus one.

For example, the Microsoft Internet Information Services (IIS) FTP server only allows the control port to be specified within the server configuration. If the control port is set to 2121, the server will automatically set the data port to 2120.

Configuring load balancing of non-standard FTP ports

To configure load balancing of non-standard ports, you must perform the following procedures:

  • Configuring the FTP pool
  • Configuring the FTP profile
  • Configuring the virtual server

Configuring the FTP pool

  1. Log in to the Configuration utility.
  2. Select Local Traffic.
  3. Select Pools.
  4. Select Create.
  5. Enter a name for the FTP pool.
  6. Select the health monitor you want to use. Unless you have created a custom FTP monitor, select tcp.
  7. Choose the load balancing method you want to use.
  8. Enter the member IP Address and the Service Port.

    Note: The Service Port is the command/control port of the FTP server.

  9. Select Finished.

The following example is a sample FTP pool configuration:

Name: AltPortFTP
Health Monitors: tcp
Load Balancing Method: Round Robin
Members: 10.10.1.10:2121, 10.10.1.11:2121

Configuring the FTP profile

  1. Log in to the Configuration utility.
  2. Select Local Traffic.
  3. Select Profiles.
  4. Select Services and FTP.
  5. Select Create.
  6. Enter a name for the FTP Profile.
  7. Select the Custom check box.
  8. In the Data Port field, enter the data port number you want to use.

    Note: If the FTP servers you are using allow both the Control and the Data Port to be specified, enter the Data Port value specified for the FTP server. If only the Control Port is available for specification, the Data Port will be the Control Port value minus 1.

  9. Select Finished.

The following example is a sample FTP profile configuration:

Name: AltPortFTP
Data Port: 2120

Configuring the virtual server

  1. Log in to the Configuration utility.
  2. Select Local Traffic.
  3. Select Virtual Servers.
  4. Select Create.
  5. Enter a name for the virtual server.
  6. Enter the Destination Address on which the virtual server will listen.
  7. From the drop-down menu for the Service Port, select FTP.
  8. Select the FTP Profile created in the previous procedure for the FTP Profile option.
  9. Select the FTP Pool created in the previous procedure for the Default Pool option.
  10. Select Finished.

The following example is a sample virtual server configuration:

Name: AlternatePortFTP
Destination: 172.16.0.2
Service Port: FTP
FTP Profile: AltPortFTP
Default Pool: AltPortFTP
