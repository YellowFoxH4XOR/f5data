Known Issue

When a B4300 blade is inserted into the VIPRION 4800 8-slot chassis, the blade will fail to join the cluster and reboot continuously.

This issue occurs when the following condition is met:

  • The blade boots to a boot location that is previous to BIG-IP 11.3.0.

The VIPRION 4800 chassis only support blades running BIG-IP 11.3.0 or later software. If a blade boots to an older version, it will be unable to join the cluster and some daemons on that blade will begin restarting repeatedly.

Impact

The newly inserted B4300 blade will be unable to join the cluster.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The blade will fail to join the cluster with multiple daemon cores and restarts.
  • The BIG-IP LTM log will contain messages that indicate that the mcpd process on the adjacent blades cannot be contacted and the newly added blade will isolate itself as a primary blade.
  • The blade will reboot continuously.

This issue does not affect BIG-IP 11.3.0 and later.

Workaround

To work around this issue, you must connect to the console interface of the affected blade and perform a clean installation of BIG-IP 11.3.0 or later. To do so, perform the following procedure:

Impact of workaround: None.

  1. Connect to the affected blade's console interface.
  2. If necessary, wait until the blade has booted. Then, quickly log on to the blade.
  3. Stop all BIG-IP services by entering the following command:

    bigstart stop

    This command will stop all inter-chassis communication with the new blade and break the continuous reboot cycle.
  4. You will now transfer a copy of a BIG-IP 11.3.0 or later software image from a functioning blade in the chassis to the affected blade. To do so, use the following command syntax, where <#> is the source blade and <Image_Filename> is the filename of the .iso file to transfer:

    scp slot<#>:/shared/images/<Image_Filename> /shared/images/

    For example, to copy an image file named BIGIP-11.3.0.2806.0.iso from blade 1, type the following command:

    scp slot1:/shared/images/BIGIP-11.3.0.2806.0.iso /shared/images/

    Note: Alternatively, the image file can be copied to the affected blade from a conventional USB mass storage device or USB DVD-ROM. For information, refer to K9661: BIG-IP support for USB mass storage devices.
  5. Once the image file copy is complete, install the image onto the affected blade. To do so, type the following command, where <Image_Filename> is the filename of the .iso file to be installed:

    image2disk --force --nosaveconfig --format volumes /shared/images/<Image_Filename>

Once the installation is complete, the blade will be restarted. When the blade boots running BIG-IP 11.3.0 or later, the blade will begin the automatic process of joining the cluster. For information about this process, refer to K13965: Overview of the automated process of joining a newly-installed VIPRION blade to the cluster.
