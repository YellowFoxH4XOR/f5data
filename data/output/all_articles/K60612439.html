Topic

You should consider using this procedure under the following condition:

  • You want to manually update the BIG-IP default certificate authority (CA) certificate bundle file (ca-bundle.crt).

Description

The ca-bundle.crt file is the BIG-IP default CA certificate bundle file located in the /config/ssl/ssl.crt directory and is referred to in the SSL Certificate List in the BIG-IP Configuration utility. The file is updated automatically during the BIG-IP upgrade process. Optionally, if you prefer to manually update the default CA certificate bundle, you can do so by either overwriting the default ca-bundle.crt file or updating it through the BIG-IP CA bundle manager.

Note: The BIG-IP CA bundle manager feature is available on BIG-IP 13.0.0 and later.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have administrative access to the BIG-IP system.
  • Have configured the BIG-IP system to resolve DNS host names.

    Note: For information about creating a DNS resolver on the BIG-IP system, refer to K13205: Configuring the BIG-IP system to resolve DNS hostnames (11.x and later).

Procedures

To watch a video demo of the Configuration utility procedures, go to  Manually update the BIG-IP default CA certificate bundle file.

  • Manually update the BIG-IP default CA certificate bundle file using the BIG-IP command line
  • Manually update the BIG-IP default CA certificate bundle file using the CA bundle manager

Manually update the BIG-IP default CA certificate bundle file using the BIG-IP command line

You can download the latest BIG-IP Certificate Authority Bundle and manually update the BIG-IP default CA certificate bundle file using the BIG-IP command line. To do so, perform the following procedure.

Note: For information about downloading F5 supported product files, refer to K167: Downloading software and firmware from F5.

Impact of procedure: Performing this procedure requires a reboot of the BIG-IP system. Rebooting disrupts traffic processing until the system is back up, or until the peer in an HA configuration has taken over.

  1. Download the latest Certificate Authority Bundle (blended-bundle.crt) from F5 Downloads.

    Note: The blended-bundle.crt file available from the F5 Downloads page may contain an ECC certificate with a curve that is unsupported on BIG-IP 11.6.x. For more information refer to K18013613: Configuration load failure: 010717e6:3: EC key contains unsupported curve and K12982: BIG-IP support for elliptic curve cryptography.

  2. Transfer the CA certificate bundle file to the BIG-IP device that you want to update.

    Note: For information about transferring files to a BIG-IP device, refer to K175: Transferring files to or from an F5 system.

  3. Log in to the BIG-IP command line.
  4. To create a backup copy of the current ca-bundle.crt file, enter the following command:

    cp /config/ssl/ssl.crt/ca-bundle.crt /config/ssl/ssl.crt/ca-bundle.crt.K60612439

  5. To copy the blended-bundle.crt file and overwrite the existing ca-bundle.crt file for your BIG-IP system, use the following command syntax:

    cp /<file_directory>/blended-bundle.crt /config/ssl/ssl.crt/ca-bundle.crt

    For example, to replace the current default CA certificate bundle file with the blended-bundle.crt uploaded under the /var/tmp directory, enter the following command:

    cp /var/tmp/blended-bundle.crt /config/ssl/ssl.crt/ca-bundle.crt

  6. To force the mcpd process to reload the configuration, enter the following command:

    touch /service/mcpd/forceload

    On VIPRION systems, enter the following command to run this on all blades:

    clsh touch /service/mcpd/forceload

  7. To restart the BIG-IP system, enter the following command:

    Important: This command interrupts traffic while the BIP-IP system either fails over to a peer system or completes the restart process.

    reboot

    On VIPRION systems, enter the following command to run this on all blades:

    clsh reboot

Manually update the BIG-IP default CA certificate bundle file using the CA bundle manager

Beginning in BIG-IP 13.0.0, you can manually update the BIG-IP default CA certificate bundle file using the CA bundle manager. To do so, perform either of the following procedures:

  • Configuration utility
  • tmsh utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > Certificate Management > Traffic Certificate Management > Bundle Manager List.
  3. To update the default CA certificate bundle, select ca-bundle from the list.
  4. Under Configuration, select the Update Now check box.
  5. Select Update.

tmsh utility

  1. Log in to the tmsh utility.
  2. Check the CA bundle manager update status by entering the following tmsh command:

    show /sys crypto ca-bundle-manager

    If you have not used the CA bundle manager to update before, the command should return an output similar to the following example:

    -----------------------------------------
    Sys::Crypto::CA Bundle Manager: ca-bundle
    -----------------------------------------
                          
    Total Updates        :          0
    Next Update (days)   :          0
    Certificate Count    :          0
    Reference Count      :          0
    Bundle Update Status :  no-change

  3. To update the default CA certificate bundle, enter the following tmsh command:

    modify /sys crypto ca-bundle-manager ca-bundle update-now yes

  4. Check the CA bundle manager update status again by entering the same tmsh command listed in step 2. If the update is successful, you should observe the Total Updates count increases by one and the Bundle Update Status showing success.

Note: If your BIG-IP system is not running any of the following versions:

  • BIG-IP 17.5.1.3 or later for the BIG-IP 17.5.x branch OR
  • BIG-IP 17.1.3 or later for the BIG-IP 17.1.x branch OR
  • BIG-IP 16.1.6.1 or later for the BIG-IP 16.1.x branch

and you observe the following log message in the /var/log/ltm file after performing the CA bundle manager procedure:

01a40000:5: Download failed: https://cdn.f5.com/product/ca-bundle/blended-bundle.crt - Peer certificate cannot be authenticated with given CA certificates

F5 recommends that you upgrade your BIG-IP to a version listed in the Recommendations section of K000157916: Update CA bundles on the BIG-IP system when the CA Bundle Manager fails with Peer certificate cannot be authenticated before attempting to perform the CA bundle manager procedure again to update the ca-bundle.crt file. Alternatively, you can perform the Manually update the BIG-IP default CA certificate bundle file using the BIG-IP command line procedure in this article to update the ca-bundle.crt file.
