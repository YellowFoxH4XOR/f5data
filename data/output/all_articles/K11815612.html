Description

Cannot see any requests for virtual server after applying log profile.

Environment

  • ASM security policy
  • Security log profile

Cause

Bug ID 912149

A message similar to the following can be seen in /var/log/ts/ts_debug.log when this issue occurs:

|ZEROMQ|Mar 24 02:42:45.416|24647|25847|25847|epoll.cpp:0060|~epoll_t()|(zmq_assert) Assertion failed: load.get () == 0

You may also observe that /var/log/ts/dcc.log is not logging any configuration changes, because the dcc process is stuck.

Recommended Actions

Restart asm_config_server to clear this condition:

pkill -f asm_config_server

Note: This is not traffic-impacting and asm_config_server will automatically be restarted after around 30 seconds.

Additional Information
