Topic

You should consider using this procedure under the following condition:

  • You need to determine the version of BIG-IP SSL Orchestrator software running on your system.

Description

You can use the BIG-IP SSL Orchestrator Configuration utility to display the software version.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Configuration utility.

Procedures

To determine the software version of your BIG-IP SSL Orchestrator system, you can use the Configuration utility or the TMOS Shell (tmsh). To do so, perform one of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Determining the software version using the Configuration utility

  • BIG-IP 14.1.0-5.x and later
    1. Log in to the Configuration utility.
    2. Navigate to SSL Orchestrator > Configuration.

      The software version displays in the Version box.

  • BIG-IP 13.0.0-2.x through 14.0.0-4.x
    1. Log in to the Configuration utility.
    2. Navigate to SSL Orchestrator > Updates.

      The software version displays in the Version box.

Determining the software version using tmsh (BIG-IP 13.1.0-3.x and later)

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Type the following command:

    list /mgmt shared iapp installed-packages

    The software version displays in the release attribute.

    For example:

    mgmt shared iapp installed-packages 9beb912b-4f1c-3f95-94c3-eb1cbac4ab99 {
        appName "f5-iappslx-ssl-orchestrator"
        arch "noarch"
        generation 4
        id "9beb912b-4f1c-3f95-94c3-eb1cbac4ab99"
        kind "shared:iapp:installed-packages:installedpackagestate"
        lastUpdateMicros 1552292670128245
        packageName "f5-iappslx-ssl-orchestrator-13.1.0-3.0.260.noarch"
        release "3.0.260"
        selfLink "https://localhost/mgmt/shared/iapp/installed-packages/9beb912b-4f1c-3f95-94c3-eb1cbac4ab99"
        status "READY"
        tags {
            "IAPP"
        }
        version "13.1.0"
    }
