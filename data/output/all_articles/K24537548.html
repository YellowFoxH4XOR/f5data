Topic

You should consider using this procedure under the following condition:

  • You want to use the 7-Zip utility on a Windows workstation to decompress and extract a BIG-IP support.tcpdump snapshot file.

Description

When you use the BIG-IP Configuration utility to create a support snapshot tcpdump file and download the file to a Windows workstation, the tcpdump snapshot is saved as a file named support.tcpdump. The support.tcpdump file is gzip-compressed and contains a tar file named support. The support file contains the tcpdump capture file(s). The tcpdump capture file(s) name format is tcpdump_#####.dmp. 

Prerequisites

You must meet the following prerequisite to use this procedure:

  • The 7-Zip utility is installed on your Windows workstation. For information about the 7-Zip utility, refer to 7-zip.org.
  • You download a BIG-IP support tcpdump snapshot file (support.tcpdump) to the Windows workstation.

Procedures

Using the 7-Zip utility on a Windows workstation to extract a BIG-IP support.tcpdump snapshot file

Accessing the tcpdump.#####.dmp files is a two-part process. You must first decompress the support.tcpdump file to access the support file. You then must extract the tcpdump.#####.dmp file(s) from the support file. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. On the Windows workstation, navigate to the folder that contains the support.tcpdump file.
  2. Right-click the support.tcpdump file, and select 7-Zip > Extract Here.

    Note: This step may produce the following error message:

    There are some data after the end of the payload data

    You can safely ignore this error message. To continue, click Close.

    The support file will be extracted to the current folder.

  3. Right-click the support file, and select 7-Zip > Extract Here.

    The tcpdump_#####.dmp file(s) will be extracted to the current folder.

    You can now open the tcpdump_#####.dmp file(s) using a capture analysis tool, such as Wireshark or tcpdump.
