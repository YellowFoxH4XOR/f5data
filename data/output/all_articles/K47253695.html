Description

Loading configuration from SCF file fails with missing files such as certificates, key, external monitors or scripts.

  • Configuration load fails with following message 
    01070712:3: Caught configuration exception (0), Failed: name (/Common/cert.example.crt) Cache path (/config/filestore/files_d/Common_d/certificate_d/:Common:cert.example.crt_385355_3) does not exist and there is no copy in trash-bin to restore from..

Environment

  • Loading configuration file from SCF archive that references file objects, e.g.:
    - SSL certificates
    - SSL keys
    - iFiles
  • Both tar archive of filestore and SCF file it self does exists

Cause

The issue is caused by a Bug ID932437

Recommended Actions

There was no fix available at a time this article was created. Open a ticket with F5 Technical Support to get an Engineering hot fix.
As a workaround extract files manually from the archive.
