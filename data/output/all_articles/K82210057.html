Known Issue

When the compression strategy option is set to latency, the CPU Saver setting may not work.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured for network access.
  • The CPU Saver setting is configured for BIG-IP Edge Client systems.
  • The compression strategy option on your BIG-IP APM system is set to latency.

    Example output:

    # tmsh list sys db compression.strategy
    sys db compression.strategy {
        value "latency"
    }

Impact

Network access tunnels intermittently fail to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H633245 on the Diagnostics > Identified > Medium page.
  • BIG-IP Edge Client intermittently displays the network access tunnel as Connected, yet no traffic is being processed.
  • Network access tunnels intermittently fail to establish.

Workaround

To work around this issue, you can set the compression strategy option to speed. To do so, perform the following procedures:

  • Enabling the CPU Saver setting
  • Setting the compression strategy option to speed

Impact of workaround: Changing the compression strategy option to speed focuses requests toward hardware compression, regardless of the desired quality.

Enabling the CPU Saver setting

Before you set the compression strategy option to speed, you must enable the CPU Saver setting using either the Configuration utility or the Traffic Management Shell (tmsh). To do so, perform either of the following procedures:

Using the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Secure Connectivity.
  3. Select the Connectivity Profile and click Edit Profile.
  4. Navigate to Compression Settings > Network Access.
  5. Ensure the CPU Saver check box is selected.
  6. Click OK.

Using tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To enable the CPU Saver setting, use the following command syntax:

    modify apm profile connectivity <profile_name> compress-cpu-saver true

    For example, to enable the CPU Saver setting for a connectivity profile named connect_profile, type the following command:

    modify apm profile connectivity connect_profile compress-cpu-saver true

Setting the compression strategy option to speed

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To set the compression strategy option to speed, type the following command:

    modify sys db compression.strategy value "speed"
