Description

After enabling the API crawler feature, how do you tell what the status is?

Environment

  • F5 Distributed Cloud

  • Load Balancer
  • API Security
  • API Crawling

Cause

It can take between 24 and 72 hours for the API crawling to begin. Unless you look at the status object you may not know if it is queued, finished, or has started. 

Recommended Actions 

1. Create a new crawler in the Load Balancer and click Save.

2. In the Load Balancer screen, click the three dots (⋯) menu.

3. Select “Show Child Object”.

4. Navigate to API Crawler and click Status View.

5. Click the Status Object UID.

You will now be able to see the scan status (e.g., Pending / Started / Completed) endpoints count and error messages and gain visibility into the crawler job state.
