Topic

BIG-IP WebAccelerator versions prior to 9.4.7 do not classify comma-separated values (CSV) files. There is not an object type specified for CSV file types in the default globalfragment.xml file.

F5 Networks Product Development tracked a request to add this functionality as CR109033 and it was added in BIG-IP WebAccelerator version 9.4.7. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Additionally, this functionality was added in BIG-IP WebAccelerator version 9.4.6 HF1.

Workaround

To add an object type for CSV files to the globalframent.xml file, and configure an acceleration policy to use the new object type, perform the following two procedures:

  • Adding a documents.csv object type for CSV files to the globalfragment.xml file
  • Configuring an acceleration policy with a CSV documents node that uses the documents.csv object type

Adding a documents.csv object type for CSV files to the globalfragment.xml file

To add a documents.csv object type for CSV files to the globalfragment.xml file, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa
  3. Back up the original globalfragment.xml file by typing the following command:

    cp globalfragment.xml globalfragment.xml.sol9641
  4. Open the globalfragment.xml file in a text editor.
  5. Add the following objType entry to the end of the objTypes section:

    <objType
                    type="csv"
                    group="documents"
                    category="common"
                    displayName="Comma-Separated Values"
                    ext="csv"
                    mimeType="
                        application/csv,
                        application/x-csv,
                        text/csv,
                        text/x-csv,
                        text/comma-separated-values"
                    compressToClient="policyControlled"
                />
    

    
  6. Save the globalfragment.xml file.
  7. Restart the pvac daemon by typing the following command: 
        
    Important: Restarting the pvac daemon will briefly disrupt connections and invalidate objects in the BIG-IP LTM RAM Cache. Restarting the pvac daemon should be scheduled accordingly.
    

    
    bigstart restart pvac
    

    



The documents.csv object type may now be specified as the Content Type in the Matching Rules section of a WebAccelerator acceleration policy.



Configuring an acceleration policy with a CSV documents node that uses the documents.csv object type



To configure an acceleration policy with a CSV documents node that uses the documents.csv object type perform the following procedure:



Note: Predefined Acceleration policies are not modifiable; this procedure must be performed on a User-defined Acceleration policy.



  1. Log in to the BIG-IP WebAccelerator Configuration utility.
  2. Click WebAccelerator.
  3. Click Policies.
        
        A new Policies Configuration window opens.
  4. Click on the User-defined Acceleration policy to be configured.
  5. Click the plus ( + ) sign to expand the Site nodes.
  6. Click the plus sign to expand the Static nodes.
  7. Click the plus sign to expand the Documents nodes.
  8. Click on the MS-Excel node.
  9. Click the Copy link at the top of the policy tree.
  10. Type CSV in the Name field.
  11. Click the Copy button.
  12. Click on the new CSV node.
  13. Select Matching Rules from the drop-down menu.
  14. Click Content Type.
  15. Replace documents.msexcel with documents.csv in the Value matches text field.
  16. Click the Save button.
  17. Click the Publish button.
  18. Optionally, type a comment or note in the Comment field.
  19. Click the Publish Now button.
