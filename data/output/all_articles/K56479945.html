Known Issue

DNS zones without servers prevent DNS Express from reading zone data.

This issue occurs when the following condition is met:

  • You have configured a DNS Express zone that does not reference a DNS server.

Impact

DNS Express does not return DNS requests for the zone that does not have a corresponding DNS server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system does not return DNS requests.

Workaround

To work around this issue, you can perform either of the following tasks:

Impact of workaround: Performing the following tasks should not have a negative impact on your system.

  • Remove the zone that does not have a corresponding server from DNS Express
  • Configure a corresponding server for the zone
