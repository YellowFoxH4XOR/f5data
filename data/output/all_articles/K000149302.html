Description

This article provides guidance on the best practices for removing servers from LDAP and LDAPS APM authentication configurations. When removing a server from LDAP and LDAPS APM authentication, customers often ask whether it is better to remove the server from the LTM pool or directly from the APM AAA Server LDAP configuration.


Environment

  • APM
  • LDAP Authentication

Cause

The confusion arises due to multiple configuration points (LTM pool and APM AAA Server LDAP profile) where a server might be associated. This often leads to uncertainty about the best location to make the change without affecting functionality.


Recommended Actions

The recommended best practice for removing servers from LDAP and LDAPS APM authentication is:

  1. Navigate to Access > Authentication > <LDAP Profile>.
  2. Remove the server directly from the specific LDAP profile.


By taking this approach:

  • The server will be automatically removed from the LTM pool.
  • The Access configuration will remain consistent and aligned with the intended authentication settings.
