Description
In some cases, the default autovacuum settings on a BIG-IQ will not prevent the database from growing larger. To prevent the postgres database from growing larger than it needs to be the autovacuum settings can be modified from the default settings. 

Environment

  • BIG-IQ  CM 7.1.x
  • BIG-IQ CLI

Cause
None

Recommended Actions
Edit the postgresql.conf file to modify the settings

  1. Create backup file:
    cp -p /var/lib/pgsql/data/postgresql.conf /var/lib/pgsql/data/postgresql.conf.bak_SR_Num
  2. Edit file postgresql.conf and add the following lines and save:
    autovacuum_max_workers = 6              # max number of autovacuum subprocesses
    autovacuum_naptime = 15                 # seconds between autovacuum runs
    autovacuum_vacuum_scale_factor = 0.05   # fraction of table size before vacuum
    autovacuum_analyze_scale_factor = 0.05  # fraction of table size before analyze
  3. Run psql command pg_reload_conf() to have the new setting take effect:
    psql -U postgres -d bigiq_db -c "SELECT pg_reload_conf();"

Additional Information
These are the default settings from BIG-IQ 8.x
