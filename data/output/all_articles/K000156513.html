K000156513: How to advertise a Load Balancer using a private IP

Description

When deploying services on F5® Distributed Cloud, there may be a need to advertise a load balancer (LB) using a private or internal IP address instead of a public IP. This is required when access to the service should be limited to users within an internal network or those connected via VPN, preventing exposure to the public Internet.

Environment

  • F5® Distributed Cloud HTTP LB

Cause

Load balancers are often set up with public IP addresses by default, which exposes the service externally. In scenarios where security and restricted access are necessary, it is essential to configure the VIP as a private IP so that only authorized internal or VPN users can reach the service.

Answer/Recommended Actions

To configure a load balancer with a private/internal VIP in F5 Distributed Cloud:

  1. Open the F5 Distributed Cloud Console and navigate to your load balancer other settings configuration.
  2. Set VIP Advertisement to Custom.
  3. Add an item and select where you want to publish the VIP:
    • Site
    • Segment on Site
    • Virtual Network
  4. Enter your desired private IPv4 or IPv6 address for the VIP.
  5. The Customer Edge (CE) device will announce this address locally within your network.
  6. With this setup, all traffic destined for the private VIP remains inside your network and does not traverse the public Internet.

Note: This feature is available only for CE-attached sites; it cannot be used on RE-only virtual sites.
