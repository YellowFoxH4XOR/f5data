Topic

Configuring BIG-IP to run as a proxy DNS server allows BIG-IP to manage host DNS queries and forward the requests to specified nameservers.

To configure DNS proxy on BIG-IP, perform the following steps:

  1. Obtain the IP addresses for the nameservers that you want to use.
  2. From the BIG-IP, type the following version-specific command.

    BIG-IP versions 4.2 - 4.6.4

    Type:

    config

    From the menu, choose D.

    BIG-IP versions 3.0 - 4.1.1 PTF-06

    Type:

    config_dns

  3. Answer the following prompts to configure the DNS proxy:
    • The first prompt asks if you really want to configure DNS.
    • The second prompt asks you for a nameserver list separated by spaces.
    • The third prompt asks for the Fully Qualified domain name of the BIG-IP.

    After you enter the appropriate values, BIG-IP writes the information to the /etc/named.conf file. DNS forwarding is now configured and local DNS resolution is enabled for BIG-IP itself.
