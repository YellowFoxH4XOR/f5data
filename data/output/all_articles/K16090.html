Security Advisory Description

The automatic signature update functionality in the (1) Phone Home feature in F5 BIG-IP LTM, AAM, AFM, Analytics, APM, GTM, and Link Controller 11.5.0 through 11.6.0, ASM 10.0.0 through 11.6.0, and PEM 11.3.0 through 11.6.0 and the (2) Call Home feature in ASM 10.0.0 through 11.6.0 and PEM 11.3.0 through 11.6.0 does not properly validate server SSL certificates, which allows remote attackers to conduct man-in-the-middle attacks via a crafted certificate. (CVE-2014-9326)

Impact

In the scenario where DNS records for callhome.f5.com are compromised, an attacker may be able to deliver a malicious payload to the BIG-IP system.

Security Advisory Recommended Actions

If the previous table lists a version in the Versions known to be not vulnerable column, you can eliminate this vulnerability by upgrading to the listed version. If the listed version is older than the version you are currently running, or if the table does not list any version in the column, then no upgrade candidate currently exists.

Mitigation

To mitigate this vulnerability, you can disable the automatic call home functionality. To do so, perform one of the following procedures:

  • Disabling the PhoneHome functionality for affected BIG-IP versions
  • Disabling the CallHome automatic attack signature update functionality on the BIG-IP ASM system
  • Disabling the automatic signature update functionality on the BIG-IP PEM system

Disabling the PhoneHome functionality for affected BIG-IP versions

Impact of action: The system does not perform the automatic update (phone home) check features; you should manually perform these checks.

  1. Disable automatic updates by following the instructions in K15000: Overview of the Automatic Update Check and Automatic Phone Home features.
  2. Manually update individual BIG-IP components by following the instructions in the following articles:
    • Major and minor releases - K167: Downloading software and firmware from F5 and K13123: Managing BIG-IP product hotfixes (11.x - 13.x)
    • Hotfix releases - K167: Downloading software and firmware from F5 and K13123: Managing BIG-IP product hotfixes (11.x - 13.x)
    • End-User Diagnostics - K167: Downloading software and firmware from F5 and K13123: Managing BIG-IP product hotfixes (11.x - 13.x)
    • EPSEC/OPSWAT - K10942: Installing OPSWAT hotfixes on BIG-IP APM systems (10.x - 11.3.0)
    • Geolocation - K11176: Downloading and installing updates to the IP geolocation database

Disabling the CallHome automatic attack signature update functionality on the BIG-IP ASM system

Impact of action: The BIG-IP signature database may be outdated if it is not manually updated on a regular basis.

For instructions to disable automatic signature updates and implement a manual update regime, refer to K8217: Managing BIG-IP ASM attack signatures.

Disabling the automatic signature update functionality on the BIG-IP PEM system

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to Policy Enforcement > Signatures.
  3. To disable the Automatic Updates setting, clear the Enabled box.
  4. Click Update.
