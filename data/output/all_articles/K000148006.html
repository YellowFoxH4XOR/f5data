K000148006: "Unexpected error when authenticating with identity provider" - Okta SSO

Source

Description

  • After configuring Okta SSO in F5® Distributed Cloud (XC) you are seeing this error when trying to use SSO: "Unexpected error when authenticating with identity provider"

Environment

  • F5® Distributed Cloud Okta SSO

Cause

  • Wrong configuration in Okta and Distributed Cloud SSO

Answer/Recommended Action

To check for the reason for that error message:

  1. Check the configuration in Distributed Cloud for SSO, you should see the default scope field in this screen where you need to add openid profile email
  2. Check Okta configuration, make sure that you have the same customer login link in the following fields: Sign-in redirect URIs, sign-out redirect URIs and initiate login URI.         
  3. Make sure that the Login initiated by is set as App Only  

Additional Information

  • Issue: Sign in with Okta is not working
