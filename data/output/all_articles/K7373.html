Known Issue

This is the result of a known issue. When you use the f5fpcsetup.exe /a command to extract the fpf5clients.msi package (the MSI installer package for FirePass Windows client components) from the f5fpcsetup.exe installer, the F5 Networks Client for Windows Setup Wizard may display the following error message:

Source file not found: C:\Docume~\JOHNDO~1\LOCALS~1\Temp\
F5_MIS_TMP1234abcd\F5\VPN\F5CustomDialer.dll.
Verify that the file exists and that you can access it.

If the f5fpcsetup.exe package was not configured to include every component, as listed on the Customize Package tab of the Device Management: Client Downloads: Windows (x86) page, this error message will appear, and the extraction of the MSI installer package will fail.

F5 Networks Product Development tracked this issue as CR64499 and it was fixed in FirePass versions 6.0.1 and 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Important: Starting in FirePass versions 6.0.1 and 6.1.0, use the /x command-line switch when extracting the fpf5clients.msi package instead of using the /a switch. For example:

f5fpcsetup.exe /x

Workaround

You can work around this issue by performing one of the following two procedures:

  • Downloading the f5fpcsetup.exe installer with all client components
  • Manually copying the extracted files from the temporary directory to your installation directory

Downloading the f5fpcsetup.exe installer with all client components

You can download the f5fpcsetup.exe installer with all client components, instead of a subset of components, and then specify the desired components to the msiexec command when you perform an installation. To download the f5fpcsetup.exe installer with all client components, perform the following procedure:

  1. Log in to the Administrative Console.
  2. In the main navigation pane, select Device Management.
  3. In the main navigation pane, select Client Downloads.
  4. In the main navigation pane, select Windows (x86).
  5. Select the Customize Package tab.
  6. Select the Select all items check box.
  7. Click the Update button.

    Note: You can select the Customize VPN Client tab to perform customizations.
  8. Select the Download tab.
  9. Click the Download customized package link.
  10. Save the file f5fpcsetup.exe when prompted by your browser.

This procedure will create an installer package with every FirePass client component. Run the msiexec command with the specified components after distributing the installer package.

Note: Rather than specify the desired components to the msiexec command, you can use an MSI editor such as Microsoft's Orca to rebuild the MSI installer package with only the desired subset of components. To do so, consult the documentation with the software you use to create MSI installer packages.

Manually copying the extracted files from the temporary directory to your installation directory

You can manually copy the extracted files from the temporary directory to your specified installation directory and then specify the subset of components. To do so, perform the following procedure:

  1. Open a command window.
  2. To change directories to the directory where you saved the f5fpcsetup.exe file, type the cd command.
  3. Type the following command:

    .\f5fpcsetup.exe /a

    A Security Warning window may appear, asking whether you want to run the f5fpclients.msi software.
  4. Click the Run button.

    The F5 Networks VPN Client for Windows Setup Wizard program appears.
  5. Click the Next button.

    A window prompts you to enter your organization name.
  6. Enter the name of your organization.
  7. Click the Next button.

    A window prompts you to enter the location to which the installation files will be extracted.
  8. Enter the path to the location or browse to it by using the Browse button.
  9. Click the Next button.
  10. Click the Install button to begin unpacking the installation files.

    The pop-up window with the Source file not found error message appears.

    Important: Do not click either the Retry or Cancel buttons.
  11. Using a Windows Explorer window, navigate to the temporary directory shown in the pop-up window, which will contain the extracted fpf5clients.msi MSI file, and the F5 VPN folder. Copy the file and the folder to the location you specified.
