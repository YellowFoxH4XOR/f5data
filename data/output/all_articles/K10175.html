Known Issue

This is the result of a known issue. The ARX 500 system will core and reboot if the ping command is issued while performing a network capture session.

Important: This issue will also occur if the show exports command is issued while a network capture session is being performed, because the show exports command uses the ping command. 

F5 Networks Product Development tracked this issue as ARX ID 34968 and it was fixed in ARX version 5.0.1. For information about upgrading, refer to the ARX Release Notes.
