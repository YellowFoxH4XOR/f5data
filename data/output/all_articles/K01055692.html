Topic

You should consider using this procedure under the following condition:

  • You want to use F5 vendor-specific attributes (VSA) when configuring remote TACACS+ authentication in the BIG-IP system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to your BIG-IP system.
  • You have administrative access to the TACACS+ server.
  • Your BIG-IP system has network connectivity to the TACACS+ server.
  • You have TACACS+ installed and running on the TACACS+ server.

Configure user accounts on the TACACS+ server

To use the F5 VSAs, you must add the user and group accounts in the tac_plus.conf file.

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Login to your TACACS+ server.
  2. Create the users Ann, John, and Bob on your TACACS+ server. In this example, you add users to the local /etc/passwd file.

    Note: On most Linux operating systems, you can use the commands useradd to add users and passwd to set the passwords. For more information, refer to your specific OS documentation to create local users.

  3. Edit the TACACS+ default authentication attribute to use /etc/passwd in the tac_plus.conf file on your TACACS+ server.

    Note: You can also define your own user database with TACACS+ instead of using /etc/passwd. Refer to your TACACS+ server to define your own user database.

    # Use /etc/passwd file to do authentication
    default authentication = file /etc/passwd

  4. Include the following configuration code example in the tac_plus.conf file.

    user = ann {
    name = "Admin User"
    member = "admin_group"
    }
    user = john {
        name = "Operator User"
        member = "operator_group"
    }
    user = bob {
        name = "Application Editor User"
        member = "app_editor_group"
    }
    group = admin_group {
            service = ppp protocol = ip {
                    F5-LTM-User-Info-1 = bigip_admin_group 
                    #The rest of the attributes are defined on the BIG-IP system
            }
    }
    group = operator_group {
            service = ppp protocol = ip {
                    F5-LTM-User-Info-1 = bigip_operator_group
                    #The rest of the attributes are defined on the BIG-IP system
            }
    }
    group = app_editor_group {
            service = ppp protocol = ip {
                    F5-LTM-User-Info-1 = remote_app_editor_group
                    F5-LTM-User-Role = 300
                    F5-LTM-User-Shell = tmsh
                    F5-LTM-User-Partition = app_editor_partition # A partition named app_editor_partition exists on the BIG-IP system
            }
    }

  5. Check the syntax of the tac_plus.conf file by entering the following command:

    Note: Depending on your TACACS+ installation, the command may vary. Refer to your TACACS+ and server documentation for more information.

    service tacacs_plus check

  6. Restart the TACACS+ server by entering the following command:

    Note: Depending on your TACACS+ installation, the command may vary. Refer to your TACACS+ and server documentation for more information.

    service tacacs_plus restart

Configure the BIG-IP system to use remote TACACS+ authentication

Perform the following procedure to configure the BIG-IP system to use remote TACACS+ authentication.

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to System > Users > Authentication.
  3. Under Authentication, select Change.

    Note: If your BIG-IP system is already authenticating against an external user directory, under External Users, select Change .

  4. For User Directory, select Remote - TACACS+.
  5. For Fallback to Local, select Enabled.

  6. Use the settings in the following table.

    ParametersSettings
    Servers<IP address of your TACACS+ server>
    Secret
    Confirm Secret    		The TACACS+ secret1
    EncryptionEnabled
    Service nameppp
    Protocol nameip

    1Note: You can locate the value of Secret in the tac_plus.conf file by referring to the key attribute.

    Leave the remaining optional parameters as default.

  7. For External Users > Role, select No Access.

    Note: This is the default role (level of access) assigned to an external user who is successfully authenticated but does not have a matching role assigned or found in the TACACS+ server configuration.

  8. Select Ok.

Configure the BIG-IP system with the remote role groups

In this procedure, you define the level of access for users in each remote role group. Perform the following procedure to create the following three remote role groups:

  • Administrator group
  • Operator group
  • Application Editor group

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to System > Users > Remote Role Groups.
  3. Select Create.
  4. Use the settings defined in the following table to create your remote role groups.

    For example, to create your first remote role group, use the settings in the Administrator group settings column.

    Note: The user attributes for the Administrator and Operator groups are defined on the BIG-IP system while the attributes for the Application Editor group are defined on the TACACS+ server using F5 Vendor VSA variable declaration.

  5. Select Finished.
  6. Repeat steps 3-5 to create the second and third groups, operator_group and app_editor_group, respectively.
