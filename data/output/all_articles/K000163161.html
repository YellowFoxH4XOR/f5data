K000163161: Outdated link in webtop settings for Horizon client download

Type
Support Solution
Published
2026-09-01
Updated
2026-09-01
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163161

Description

The VMware Horizon VDI Webtop resource in BIG-IP APM contains an obsolete client-download link. Selecting “Settings > here” redirects to a nonexistent page and returns an HTTP 404 “Page not found” error.

Environment

  • BIG-IP APM
  • VMware Horizon VDI resource
  • APM Webtop
  • VMware Horizon and HTML5 client options

Cause

Bug ID 2459589 causes the embedded VMware Horizon Webtop link to use an obsolete VMware client-download URL. Changes to the VMware/Omnissa website structure cause the URL to redirect to a page that no longer exists.

Recommended Actions

Create a separate Webtop link that points to the current official Omnissa Horizon documentation or client-download page:

  1. Go to Access > Profiles / Policies > Customization > Quick Start/Basic.
  2. Select Webtop links.
  3. Create or customize a Webtop link.
  4. Set the link’s application-uri to the official Omnissa Horizon documentation or download URL.
  5. Assign the link in the access policy using the appropriate Links, Sections and Webtop Assign actions.
  6. Save and apply the configuration, then verify that the link opens the required Omnissa page.

This workaround creates a functional replacement link but does not modify the embedded “Settings > here” link in the VMware Horizon VDI resource.

Important: Do not directly modify APM-delivered files. Such changes are unsupported and may be lost during an upgrade.

Monitor Bug ID2459589 for a permanent product correction or an engineering hotfix for  BIG-IP when available.

Additional Information

Omnissa download endpoints can vary by operating system and Horizon client release. Use the official Omnissa documentation or download page instead of relying on a permanent direct installer URL.

Example link:

https://customerconnect.omnissa.com/downloads/info/slug/virtual_desktop_and_apps/omnissa_horizon_clients/8
