Topic

You should consider using this procedure under the following conditions:

  • You want to install the iApps LX package on a BIG-IP system.
  • The BIG-IP system has a high availability (HA) configuration with more than one device in the device group.

Description

For BIG-IP systems with multiple devices in the Sync-Failover group, iApps LX uses a REST framework gossip mechanism to automatically synchronize the iApps LX configuration across members of the device group. To ensure the iApps LX package is properly synchronized, make sure the HA configuration is established and in a good state before you import the iApps LX RPM package.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have administrative access to the BIG-IP system.
  • Enable Automatic Sync in the Sync-Failover device group configuration.
  • Enable Network Failover in the Sync-Failover device group configuration.
  • Allow TCP port 443 in the self IP Port Lockdown setting.

    Note: The Allow Default option in the self IP Port Lockdown setting includes TCP port 443 access. For more information about port lockdown, refer to K17333: Overview of port lockdown behavior.

Procedures

Verifying the current REST framework gossip mechanism status using the BIG-IP command line

To have the iApps LX package properly synchronized across the HA members, you should make sure that the REST framework gossip mechanism status is ACTIVE on all members in the device group before importing the iApps LX package. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To check the status of the gossip mechanism, enter the following command:

    restcurl shared/gossip | grep status

  3. Verify the output status.

    For example, the following output indicates that the current gossip mechanism status is ACTIVE:

    "status": "ACTIVE",

Note: You should perform the previous procedure on all devices in the Sync-Failover group where you want to install the iApps LX package.

Installing the iApps LX RPM package on a BIG-IP HA system

To install iApps LX package on a BIG-IP HA system, you should import the RPM file using the Configuration utility on the active member in device group. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of the active device.
  2. Go to iApps > Package Management LX.
  3. Select Import.
  4. To import the RPM file, select Choose File.
  5. Select Upload.

Note: The iApps LX package synchronization happens automatically. It may take a while before the installed iApps LX package synchronizes across the HA members.
