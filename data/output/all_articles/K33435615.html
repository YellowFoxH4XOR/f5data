Known Issue

The BIG-IP system may fail to update the LCD display.

This issue occurs when the following condition is met:

  • Multiple LCD update requests are made simultaneously through the following actions:
     
    • When the BIG-IP system attempts to update the system state on the LCD display during a failover event (for example, you see the Unit going active message).
    • When either of the following actions are performed repeatedly:
       
      • You run the lcdwarn command.
      • You clear the LCD alert messages using the front panel buttons.

Impact

The LCD on the BIG-IP system may not display updated system state messages. This issue usually corrects itself eventually, but to allow the LCD display to be updated immediately, perform the suggested workaround.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The LCD on your BIG-IP system may not display the following messages during a failover event:
     
    • Unit going active
    • Unit going standby
  • When the front panel display daemon (fpdd) debug option is enabled, error messages appear in the /var/log/ltm file, similar to the following example:

    <135>Oct 07 14:29:55 bigip.f5.com fpdd[12949]: 00010012:7: Unknown message from LCDd listn les

Workaround

To work around this issue, you can restart the fpdd process. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Restart the fpdd process by typing the following command:

    restart /sys service fpdd
