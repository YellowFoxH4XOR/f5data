K000162969: Verifying Native SSD Capacity on an r12000 Appliance

Description

  • F5OS reports approximately 1.4 TB per SSD on an r12000 appliance, while the platform datasheet specifies 2 TB SSDs.

Environment

  • r12000 appliance
  • F5OS
  • Two U.2 NVMe SSDs
  • RAID configuration

Cause

The installed SSDs are 2 TB-class drives with approximately 1.92 TB of native capacity. F5 overprovisions the SSDs to approximately 1.5 TB to provide an endurance rating of approximately 3 drive writes per day (DWPD) for five years.

After storage and RAID configuration, F5OS may report approximately 1.4 TB per drive. This is the user-visible RAID capacity and does not represent the native SSD capacity.

Recommended Actions

Run the following commands from the appropriate F5OS support shell:

docker exec -it platform-hal nvme list

To view the native NVMe device information, run:

docker exec -it platform-hal smartctl -a /dev/nvme0

docker exec -it platform-hal smartctl -a /dev/nvme1

Check the following fields in the output:

Model Number

Serial Number

Total NVM Capacity

The Total NVM Capacity should be approximately 1.92 TB for each drive. This verifies that the appliance contains 2 TB-class SSDs.
