K91733256: BIG-IP Edge Client Always Connected mode may allow the traffic to internet temporarily

Type
Support Solution
Published
2021-05-06
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K91733256

Description

The BIG-IP Edge client is in Always Connected mode, when the VPN is not connected, it may allow the traffic to internet temporily.
Some scenarios:

  • When change the APM server, VPN disconnected and before login.
  • When Network environment changed.

Environment

  • BIG-IP Edge client
  • Always Connected mode
  • Block the traffic when out of corporate network or VPN is disconnected

Cause

None

Recommended Actions

The following article below can explain it:

  • K34467612: Overview of BIG-IP Edge Client autoconnect location awareness

"Note: During a network switch, such as changing WiFi connections, BIG-IP Edge Client's network location awareness must detect whether the new connection is local or remote. During this brief time period, as it switches networks, BIG-IP Edge Client does not block certain external websites and can be reached."

  • Manual Chapter : BIG-IP Edge Client for Windows

"During a network switch, such as changing Wifi connections, Edge Client with network location-awareness must detect whether the new connection is local or remote. During this detection timeframe, there is a brief amount of time that Edge Client does not block certain external websites and can be reachable during the network switch."
