K12504192: Unanticipated restart of TMM due to heartbeat failure

Type
Support Solution
Published
2022-03-21
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K12504192

Description

  • TMM restarts.
  • Unexpected failover
  • A core file might be generated without any message logged in /var/log/*.
  • LTM log get error messages similar as below

    notice sod[7378]: 01140041:5: Killing tmm.0 pid 23304.
    warning sod[7378]: 01140029:4: HA daemon_heartbeat tmm1 fails action is go offline down links and restart.
    notice sod[7378]: 010c0050:5: Sod requests links down.
    notice sod[7378]: 010c0054:5: Offline for traffic group traffic-group-1.
    notice sod[7378]: 010c003e:5: Offline

Environment

  • BIGIP LTM
  • Ports down

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1000973

Recommended Actions

Consider upgrade to a fixed version: 16.1.0, 16.0.1.2, 15.1.4, 14.1.4.3, 13.1.4.1

Additional Information

None
