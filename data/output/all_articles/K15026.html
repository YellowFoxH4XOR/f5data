Issue

Error Message

warning: Global concurrent access session limit reached.

For example:

warning tmm1[10186]: 01490508:4: 00000000: Global concurrent access session limit reached.

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file

Additionally, users who access the BIG-IP APM access profile logon page receive the following related messages:

Global access license usage is 9999 (99%) of 10000 total. Exceeded 75% threshold of total license.
The maximum number of concurrent user sessions has been reached. No new user sessions can start at this time.

Description

This message occurs when the following condition is met:

  • The licensed number of access sessions is exceeded.

The BIG-IP APM system is licensed for concurrent access sessions; this is the total number of sessions that the system can maintain regardless of the access session type.

Impact

Users are unable to establish a BIG-IP APM session.

Recommended Actions

F5 recommends that you monitor traffic volumes so you can proactively manage the license limit. If the rate limit warnings persist, you can perform the following actions:

  • Confirm whether maintenance traffic, such as security scanners, is causing BIG-IP APM to reach its concurrent connect limit.
  • Contact your F5 sales representative about acquiring an update to the license, allowing a higher threshold.
  • Configure the BIG-IP system to send SNMP traps and email messages to a specified address whenever the system logs a message as a result of the system reaching the global concurrent access session limit. For information about these notifications and email message options, refer to the Supplemental Information section.
