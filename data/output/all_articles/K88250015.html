K88250015: AS3 expected behavior of ''shareNodes'' in declarations

Type
Support Solution
Published
2021-08-11
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K88250015

Description
This article is to explain the expected behavior of the shareNodes key in a pool object of an AS3 declaration. 

  • shareNodes set to true will cause the node created for the pool member to be placed in the /Common partition
  • shareNodes set to false will cause the node created for the pool member to be placed in the application partition
  • when a node is in the  /Common partition it is available for use by the pool in other partitions
  • When a node is in an application partition it can only be used by pools in the same partition
  • If a declaration specifies a shareNode setting that conflicts with an existing  shareNode setting in another partition it will result in an error

Environment

  • Using AS3 to send declarations to BIG-IPs

Cause
This is the expected behavior

Recommended Actions

None
