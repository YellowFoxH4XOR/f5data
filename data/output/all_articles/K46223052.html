Issue

Error Message

01010027:2: Unable to attach to PCI device <PCI device address>

In this error message, note the following:

  • <PCI device address> is the address (Bus:Slot.FunctionCoordinates) of the affected PCI device.

For example:

01010027:2: Unable to attach to PCI device 10:00.00

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The Traffic Management Microkernel (TMM) process is unable to initialize a hardware device in the system.

During system startup, the TMM process attempts to initialize several hardware acceleration devices such as kernel network interfaces, HSB DMA engines, SSL crypto devices, and compression devices. 

Note: The following error message in a vCMP guest indicates that this specific hardware device is not being used in the vCMP guest and does not affect the vCMP guest traffic processing capability in any way: 01010027:2: Unable to attach to PCI device 00:06.06.

Impact

The TMM process is unable to use the affected hardware device and this situation may potentially impact traffic processing. It may also result in fallback to software compression or crypto operations in the event of the failure to initialize the compression or SSL crypto devices.

Recommended Actions

You may be able to recover the affected system from this issue by either restarting the TMM process or restarting the system to see if the system is able to re-initialize the affected hardware devices.
