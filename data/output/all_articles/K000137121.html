K000137121: Peoplesoft application is getting blocked

Type
Support Solution
Published
2023-10-04
Updated
2023-10-10
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.X, 14.1.0, 14.1.2, 14.1.3, 14.1.4, 14.1.5, 15.1.5
Source
https://my.f5.com/manage/s/article/K000137121

Description

Peoplesoft application is getting blocked with frame errors.

Client getting the below error when accessing the Peoplesoft application via the BIG-IP:

"Blocked a frame with origin https://<domain.name> from accessing a cross-origin frame."

 

Environment

• LTM Virtual Server passing traffic to Peoplesoft application

• Chorme 115 or higher
• Microsoft Edge

 

Cause

Starting in Chrome 115, websites will be unable to set document.domain: Chrome will make document.domain immutable.
Microsoft Edge is also planning to disable document.domain (Starting in version 118).
 

Recommended Actions

Create an iRule to insert the required header

when HTTP_RESPONSE {
	if { ![HTTP::header exists "Origin-Agent-Cluster"] } {
		HTTP::header insert "Origin-Agent-Cluster" "?0"
	}
}

 

Additional Information

Chrome disables modifying document.domain

https://developer.chrome.com/blog/document-domain-setter-deprecation/#:~:text=Starting%20in%20Chrome%20115%2C%20websites,or%20the%20Channel%20Messaging%20API
