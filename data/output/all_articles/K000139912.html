Description

Editing,creating deleting profiles via BIG-IQ GUI cause Error: Errors "coordination task already at final stage: FAILED incoming status: UPDATING, intermittently

restjavad.0.log shows errors similar to

Coordination task:432efb4f-1678-4a2c-b773-61771e036133 already at final stage:FAILED incoming stage:UPDATING

 

Environment

  • BIG-IQ CM
  • Configuration modification of profiles
  • Long uptime without restart

Cause

Task is taking longer than 10 seconds which is expected time to finish

 

Recommended Actions

Open support ticket to PE to increase task timeout, require updating app.js files

or 

reboot BIG-IQ CM to release some memory

Additional Information

from collected BIG-IQ Loopback tcpdump  while reproducing the issue

tcpdump -envi lo -s0 -A 'tcp port 8100' -w /var/tmp/bigiq_rest.pcap 

The reason why we see the error is response for

7093 2024-04-17 15:19:11.457173 0.000030 127.0.0.1 127.0.0.1 HTTP/JSON 2588 POST /mgmt/cm/adc-core/working-config/ltm/virtual/eb1d0efd-0f28-31bb-b350-7da2c713935f/profiles HTTP/1.0 , JSON (application/json)

Took more then 10 seconds.

9113 2024-04-17 15:19:38.057747 0.204277 127.0.0.1 127.0.0.1 HTTP/JSON 1055 HTTP/1.1 400 Bad Request , JSON (application/json)

It might be due to number of profiles or memory.
