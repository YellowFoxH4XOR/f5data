Description

When upgrading from v15.x+ to v17.x, you may experience poor performance with TMUI.

Environment

  • Product: BIG-IP LTM , LTM-DNS, APM, ASM, AFM, SSLO, WAF
  • Platform: All
  • Software Version: Upgrade from 15.x to 17.x+
  • Recent Action: Completed software upgrade

Cause

Insufficient resources allocated to TMUI, specifically the Management module set to “small/medium" instead of “large/custom”, which may result in repeated restarts of critical services after upgrade.

Recommended Actions

  1. Schedule Maintenance Window
    - Perform resource changes and upgrades during scheduled maintenance windows.
    - Perform commands listed in this procedure on the Standby unit within an HA cluster. 
  2. Optimize TMUI and Subsystem Performance (requires at least 8GB RAM)
    - During a maintenance window, run:
    tmsh modify sys db provision.extramb value 2048
    tmsh modify sys db provision.tomcat.extramb value 256
    tmsh modify sys db provision.restjavad.extramb value 384
    tmsh modify sys db icrd.timeout value 180
    tmsh modify sys db restjavad.timeout value 180
    tmsh modify sys db restnoded.timeout value 180
    tmsh save sys config
    tmsh restart sys service httpd tomcat restjavad restnoded

  3. You should notice a performance improvement right away.  You can also reload/reboot the F5 appliance with the following command:
    touch /service/mcpd/forceload && reboot

Additional Information

  • Standalone appliances can become inoperative when restarting major services in step #2 above. Please perform all commands during a maintenance window, and expect to reboot your appliance.
  • Make sure you have an admin user available with Advanced shell access in case additional troubleshooting is needed from the CLI/ssh.
