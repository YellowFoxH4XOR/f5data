K000093199: Error "01020036:3: The requested software desired (HDx.x) was not found" when trying to delete a volume from TMSH

Type
Support Solution
Published
2022-12-09
Updated
2022-12-09
Source
https://my.f5.com/manage/s/article/K000093199

Description

The next outputs/logs are shown in the console:

 

(tmos)# delete sys software volume HDx.x

 

01020036:3: The requested software desired (HDx.x) was not found.

 

(tmos)# show sys software status

 

---------------------------------------------------------------------

Sys::Software Status

Volume Product  Version  Build Active                     Status

---------------------------------------------------------------------

HD1.1   BIG-IP 12.1.3.5 0.0.10    yes                       complete

HD1.4   BIG-IP 14.1.5.1  0.0.6     no           failed to delete volumeset

 

In the /var/log/ltm logs:

 

Ltm   Error   mcpd[xxx] The requested software desired (HDx.x) was not found.

Ltm   Error   lind[xxx] Failed to delete volumeset HDx.x


Environment

  • BIG-IP LTM
  • TMSH
  • Volumeset


Cause

Unknown at the time of publication 


 Recommended Actions

There are two methods to attempt to resolve this. The least invasive would be to run the following command and then try to delete the "volumeset" again.

 

  # bigstart restart lind

 

Note: The "lind" process manages software installation/volume creation tasks.

 

After the process restarts you can attempt to remove the volume again.

 

  # tmsh delete sys software volume HDx.x

 

If that doesn't resolve the issue the BIG-IP device needs to be rebooted.

 

  # reboot
