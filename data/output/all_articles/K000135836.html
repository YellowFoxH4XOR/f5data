K000135836: Export ASM Security Policy Audit Logs in HTML format using REST API (iControl)

Type
Support Solution
Published
2023-10-22
Updated
2023-10-22
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.X.X, 17.1.X, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000135836

Description

You would like to export security Policy Audit Logs using the iControl REST API.
You would like to provide a Formal and text-rich document for auditing.

Environment

You are running on BIG-IP v17.1.x.
You have ASM module provisioned.

Cause

None.

Recommended Actions

  1. Get MD5 Hash ID of your ASM policy: 
    curl --silent --insecure --request GET --user admin:admin https://127.0.0.1/mgmt/tm/asm/policies?\$select=name,id | jq .

    Expected output: 
    {
"kind": "tm:asm:policies:policycollectionstate",
"selfLink": "https://localhost/mgmt/tm/asm/policies?$select=name%2Cid&ver=17.1.0",
"totalItems": 1,
"items": [ 
{ 
"kind": "tm:asm:policies:policystate",
"selfLink": "https://localhost/mgmt/tm/asm/policies/t2TxxpOjj4AjQWOcEVyBaA?ver=17.1.0",
"name": "asm_policy",          <=== ASM Policy Name
"id": "t2TxxpOjj4AjQWOcEVyBaA" <=== ASM Policy ID of "asm_policy"
}
]
}
  2. Generate a link for the audit log html file: 
    curl --silent --insecure --request POST --user admin:admin https://127.0.0.1/mgmt/tm/asm/tasks/export-to-file --data '{"restPath":"/mgmt/tm/asm/policies/t2TxxpOjj4AjQWOcEVyBaA/audit-logs","filename":"my-policy-audit-logs.html","filter":""}' | jq .

    Expected output: 
    {
"isBase64": false,
"inline": false,
"filter": "",
"status": "NEW",
"lastUpdateMicros": 1691509275000000,
"restPath": "/mgmt/tm/asm/policies/t2TxxpOjj4AjQWOcEVyBaA/audit-logs",
"kind": "tm:asm:tasks:export-to-file:export-to-file-taskstate",
"selfLink": "https://localhost/mgmt/tm/asm/tasks/export-to-file/ew3FqyqCmw_PU1n65I-9QQ?ver=17.1.0",
"filename": "my-policy-audit-logs.html",
"id": "ew3FqyqCmw_PU1n65I-9QQ",
"startTime": "2023-08-08T15:41:15.991907Z"
}
  3. Now you can download the generated audit log file from the BIG-IP device: 
    curl --silent --insecure --request GET --user admin:admin --remote-name "https://127.0.0.1/mgmt/tm/asm/file-transfer/downloads/my-policy-audit-logs.html"

Additional Information

None.
