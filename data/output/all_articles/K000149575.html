Description

Intermittent flapping is observed on wideip pool member (BIG-IP Virtual server)

 

Environment

BIG-IP DNS

iQuery connectivity flapping

 

Cause

Suspected Network issue

 

Recommended Actions

Use the following bash command to review the /var/log/gtm logs to identify connectivity issues:

 

grep "state change" /var/log/gtm*

 

alert gtmd[14927]: 011a500c:1: SNMP_TRAP: Box 10.10.10.10 state change green --> red (Unavailable)

 

Multiple messages logged at the same time for different servers would be an indicator of a common network issue.

 

Troubleshoot network path between BIG-IP DNS and BIG-IP where the VS is configured.
