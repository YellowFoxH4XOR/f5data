Known Issue

Using Priority Group Activation with Slow Ramp Time may cause the system to load balance traffic to a single pool member.

This issue occurs when all of the following conditions are met:

  • You have a pool configured to use Priority Group Activation with multiple priority groups.
  • The pool is also configured to use the Slow Ramp Time feature. The feature is enabled, by default, with a configuration of 10 seconds.
  • The highest priority group goes offline and the second highest is now used for traffic distribution.
  • A pool member in the newly active group goes offline, then online, triggering the slow ramp feature.

Impact

Traffic distribution to pool members is unevenly balanced.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Traffic distribution to pool members is uneven and does not occur as expected.

Workaround

To work around this issue, you can disable the Slow Ramp Time feature. To do so, perform the following procedure:

Impact of workaround: If you use dynamic load balancing methods, the statistics for a new pool member could affect the load balancing algorithm and overload the pool member.

  1. Log in to the BIG-IP system Configuration utility.
  2. Navigate to Local Traffic > Pool.
  3. Select the affected pool by name.
  4. Change Configuration from Basic to Advanced.
  5. Locate the Slow Ramp Time option and in the Seconds box, type 0.
  6. Select Update.
