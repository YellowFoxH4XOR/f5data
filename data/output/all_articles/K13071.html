Issue

Error Message

/bin/bigpipe: bigpipe is no longer supported; please use tmsh.

Message Location

You may encounter this message in the following location:

  • The BIG-IP console or command line

Description

This message occurs when the following condition is met:

  • You attempt to run the bigpipe command on a BIG-IP 11.x, or later, system.

The bigpipe utility was removed beginning in BIG-IP 11.0.0. Use the tmsh utility instead.

Impact

The bigpipe commands do not function in BIG-IP 11.0.0 or later.

Recommended Actions

You must use the tmsh utility to configure and manage the BIG-IP 11.x system from the command line.
