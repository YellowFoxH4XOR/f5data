K70209604: Problem with clients accessing from MACs and the Safari to the Portal

Type
Support Solution
Published
2021-04-07
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.2
Source
https://my.f5.com/manage/s/article/K70209604
Description

We use APM with the Portal Access (full webtop) set.
However, we have problems with clients accessing from Macs and the Safari browser.
Users are logged in to the portal and then close the browser.
They turn on the browser again after the session expires.
Without even trying to access the login page of the portal, sessions with APM are re-created in the background until the maximum number is reached.

Environment

  • Portal Access
  • Safari browser on MacOS
  • Maximum session number reached
Cause

Users had it in bookmarks/favourites and Safari show it on welcome screen.
After some time it decides to download new preview and generates request with "X-Purpose: preview" header.
Since bookmarked path is to webtop, APM redirect such request to login page

Recommended Actions

See the following article on DevCentral for an iRule that can resolve this issue: Show Browser Previews the Door
