Topic

This article outlines the recommended steps that you should take when planning to deploy BIG-IQ systems in an OpenStack environment.

Description

When you are deploying a BIG-IQ system in OpenStack, consider the following factors:

  • If your BIG-IQ system passes traffic through an OpenStack tenant network that uses some form of overlay network technologies such as virtual eXtended local area network (VXLAN), you may need to accommodate the overlay network protocol overhead by adjusting the maximum transmission unit (MTU) on the ingress/egress interface/VLANs. For more information, refer to K94427358: Configuring the MTU size on the BIG-IQ system when deploying in OpenStack.
  • If your BIG-IQ self IP address processes large data transfers while the router adjacent to the BIG-IQ system does not process IP fragments with both the Don't Fragment (DF) and More Fragment (MF) bits set, your BIG-IQ system may experience slowness in the data transfer or even data transfer failure. You may have to disable TCP segmentation offload (TSO) which is enabled by default using the command ethtool -K tmm tso off. For more information, refer to ID 875493 in Bug Tracker.

Recommendations

Based on the factors described in the previous section, F5 recommends that you modify the /config/startup file on your BIG-IQ to include the changes necessary for these factors. To do so, perform the following procedure:

Impact of procedure: The impact of the suggested workaround depends on the specific environment. F5 recommends testing these changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to the command line of the BIG-IQ system.
  2. Edit the /config/startup file using a text editor of your choice, for example vi.
  3. Add the following command syntaxes:

    /sbin/ifconfig eth0 mtu <MTU size>
    /sbin/ifconfig <VLAN> mtu <MTU size>
    ( sleep 60; /sbin/ethtool -K tmm tso off )&

    For example, you would replace <MTU size> with 1450 if the protocol overhead is 50 bytes and the physical network MTU size is 1500; and replace <VLAN> with the affected VLANs, for example Internal and External VLANs:

    /sbin/ifconfig eth0 mtu 1450
    /sbin/ifconfig Internal mtu 1450
    /sbin/ifconfig External mtu 1450
    ( sleep 60; /sbin/ethtool -K tmm tso off )&

  4. Save the changes and exit the text editor.
  5. Test your changes by restarting the BIG-IQ system during an appropriate maintenance window.
