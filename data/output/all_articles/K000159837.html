K000159837: nShield HSM client version 13.9 installation fails with GLIBC library errors on BIG-IP

Type
Support Solution
Published
2026-03-25
Updated
2026-03-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000159837

Description

When attempting to install Entrust nShield HSM client version 13.9 on BIG-IP LTM 17.1.3, the installation fails with GLIBC library dependency errors. The nc_hardserver.service enters a failed state, and the following error messages appear in the system logs: 

Jan 20 12:49:02 <big-ip> systemd[1]: Unit nc_hardserver.service entered failed state.
Jan 20 12:49:02 <big-ip> systemd[1]: nc_hardserver.service failed.
/usr/lib64/libc.so.6: version `GLIBC_2.28' not found (required by /opt/nfast/sbin/hardserver:
/usr/lib64/libc.so.6: version `GLIBC_2.25' not found (required by /opt/nfast/sbin/hardserver:

The system shows the following GLIBC packages installed:

[example:Standby:In Sync] ~ # rpm -qa | grep glibc
glibc-common-2.17-222.el7.0.0.11.x86_64
glibc-2.17-222.el7.0.0.11.i686
glibc-2.17-222.el7.0.0.11.x86_64

 

Environment

  • BIG-IP LTM
  • nShield HSM client
  • System GLIBC version: 2.17

Cause

nShield HSM client version 13.9 requires GLIBC versions 2.25 and 2.28, but BIG-IP 17.1.3 ships with GLIBC version 2.17. GLIBC is a core system library that cannot be upgraded independently from the BIG-IP operating system. Additionally, nShield client version 13.9 is not documented or validated for compatibility with BIG-IP 17.1.x in the official F5 Entrust nShield HSM Version Interoperability Matrix.

Recommended Actions

  1. Install the documented compatible nShield client version for BIG-IP 17.1.x (including 17.1.3):

    • Use nShield client version 12.81.2, which is officially supported according to the F5 Entrust nShield HSM Version Interoperability Matrix
    • Refer to K000151794 for installation guidance

  2. For newer nShield client version support:

    • Upgrade BIG-IP to version 17.5.x or later, which supports nShield client version 13.6.5 (the closest validated version to 13.9)
    • Note: nShield client version 13.9 is not currently documented as supported on any BIG-IP release

  3. If nShield client version 13.9 is business-critical:

    • Contact F5 Support to open a Request for Information (RFI) regarding future support for nShield client version 13.9
    • Provide both the nShield client version (13.9) and firmware version requirements for evaluation
    • Engage your F5 account team to submit a Customer Service Request (CSR) for product roadmap consideration

 

Additional Information

The F5 Entrust nShield HSM Version Interoperability Matrix documents the officially tested and supported combinations of BIG-IP versions with nShield client and firmware versions.

  • For BIG-IP 17.1.x, the highest supported nShield client version is 12.81.2.
  • For BIG-IP 17.5.x. the highest supported nShield client version is 13.6.5 

Similar GLIBC incompatibility issues have been documented with other HSM client software (such as AWS CloudHSM) that require newer GLIBC versions than what is available in the BIG-IP operating system. GLIBC is a fundamental system library that is tightly integrated with the operating system and cannot be independently upgraded without potentially causing system instability.
