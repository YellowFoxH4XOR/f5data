Known Issue

When a user accesses Outlook Web App (OWA) using the BIG-IP APM reverse-proxy engine, they may be unable to receive notifications from the OWA server. In addition, the user receives an error message that appears similar to the following example:

Notifications couldn't be retrieved.

Alternatively, they may view an error icon that when selected, produces the following error message:

If you can't receive alerts such as reminders or new e-mail notifications, or receive chat messages or see presence changes, make sure your network connection is working. If the problem continues, contact your helpdesk.

This error message occurs because the reverse-proxy engine does not properly handle the notifications responses sent by the OWA server. The client sends a request to the OWA server and the OWA server sends a response as expected. However, the response that the OWA server sends back does not reach the requesting client and the request times out.

F5 Product Development is tracking this issue as ID 344995 (formerly CR141037).

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP APM 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
