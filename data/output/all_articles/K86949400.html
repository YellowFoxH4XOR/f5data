Description
F5 TLS Cipher names are different from the SSLLabs Cipher names.

Environment

  • BIG-IP
  • SSL / TLS

Cause
F5 uses the OpenSSL naming, and SSLLabs uses IANA naming.

Recommended Actions
There are 2 main Cipher naming conventions that have been adopted. 

  • IANA
  • OpenSSL
Typically the F5 will use the OpenSSL cipher naming convention, while SSLLabs uses the IANA cipher naming convention, as does Wireshark too. Therefore, to confirm if the cipher referred to by each convention is the same, the cipher ID should be compared.

To view the cipher IDs on the BIG-IP, use either of the following commands:
  • tmm --clientciphers <cipher-string>
  • clientssl-ciphers <cipher-string>
For example:

# tmm --clientciphers 'ECDHE-RSA-AES128-GCM-SHA256'

   ID     SUITE                            BITS PROT    CIPHER              MAC     KEYX

0: 49199  ECDHE-RSA-AES128-GCM-SHA256      128  TLS1.2  AES-GCM             SHA256  ECDHE_RSA

Note: The ID is represented in decimal format, while elsewhere it is usually presented in a hexadecimal format. In the previous example, the ID in hex is 0x0C02F.
