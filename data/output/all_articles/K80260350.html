Description

Convert access policies to work between different TMOS versions

  • When you try to import access policy from version 14.1 into APM running 15.1, you see below error message:
Import error: config version 14.1 is not compatible with BIGIP version 15.1

Environment

  • Import/export access policies/profiles
  • APM

Cause

Converting access policies to work between different TMOS versions is not supported.
 Purpose of export/import option on APM policies was meant for backup/restore on the same system.

Recommended Actions

You can export or import an access profile for the purpose of backing up and restoring a profile or for copying it from one Access Policy Manager® (APM®) system to another. An access profile is exported to a compressed tar file. Import is supported on a system with the same version of APM that created the export file.
