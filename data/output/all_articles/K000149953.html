K000149953: ADFS: Fails to establish trust and the Configuration utility says "read_until: end of file"

Type
Support Solution
Published
2025-02-25
Updated
2025-02-25
Applies to
  • BIG-IP
  • BIG-IP APM: 17.X.X, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000149953

Description

As attempting to establish the trust to the ADFS server, the process fails and the Configuration Utility reports: "read_until: end of file"

Environment

BIG-IP

Cause

This may be because the Virtual Server lacks an HTTP profile.

Recommended Actions

Do please attach an HTTP profile to the Virtual Server.

Do please restart the ADFS proxy service: bigstart restart adfs_proxy

Do please attempt to establish the trust from scratch again.

Additional Information

The APM log file may show a record like that one:

Jan 01 12:00:00 F5-bigip err adfs_proxy[6892]: 01aeffff:3: (null):Common:00000000: Operation '' failed: ERROR: ERR_NOT_FOUND.
