Description

User with Operator role getting error Unexpected Error: Can't display all items, can't get object count from mcpd when running any of the following command:

  • tmsh list all-properties
  • tmsh list /security all-properties
  • tmsh show running-config

Environment

  • User with Operator role
  • BIG-IP ASM or BIG-IP AFM

Cause

This issue is currently tracked under ID 912277.

Recommended Actions

Consider one of the following options:

  • Specify the modules to get the information they need. For instance, use list security dos when you want to see the dos configuration, rather than using list all-properties or list security.
  • Create an alternative user role. For example, if you require to configure a read-only user, consider creating that user with Auditor role.
