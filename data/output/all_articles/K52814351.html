Known Issue

The BIG-IP ASM system may incorrectly trigger Malformed XML or JSON violations.

This issue occurs when all of the following conditions are met:

  • An XML or JSON profile is associated with a security policy.
  • The internal variable relax_unicode_in_xml or relax_unicode_in_json is set (based on the content profile associated with the security policy).
  • The XML or JSON request is processed by the BIG-IP ASM security policy that contains unicode characters.

Impact

The BIG-IP ASM system may report false positive Malformed XML or JSON violations.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP ASM system triggers the Malformed XML data violation, although the XML content is valid.
  • Your BIG-IP ASM system triggers the Malformed JSON data violation, although the JSON content is valid.
