K5035: The ntpd daemon is not restarted after the Setup utility is used to make time server configuration changes

Known Issue

This is the result of a known issue. BIG-IP and 3-DNS do not restart ntpd after you use the Setup utility to make changes to the time server configuration. As a result, BIG-IP and 3-DNS will continue to use the previously configured time servers until you restart ntpd or reboot the BIG-IP system.

To restart ntpd, use the following steps:

Note: If the newly configured time servers require the clock to be set back, you must reboot BIG-IP or 3-DNS in order to begin using the new time servers.

  1. Log in to the command line.
  2. Restart ntpd, by typing the following command:

    bigstart restart ntpd

F5 Networks Product Development is tracking this issue as CR36782 and CR42107.
