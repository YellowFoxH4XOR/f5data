Description

Error logs in /var/log/httpd/http_errors

Dec 12 16:15:29 bigip.hostname err httpd[18389]: [auth_pam:error] [pid 18389] [client 10.10.10.112:54226] AUTHCACHE Auth failed: Unable to access (/run/pamcache/WJZTOKENEXAMPLELQ3L2VMZT), referer: https://bigip.hostname/tmui/tmui/system/support/app/?ver=0.58.5.16.1.4.1

Note: "WJZTOKENEXAMPLELQ3L2VMZT" is a REST token.

Environment

BIG-IP versions which have the fix for ID1033837. (Such as 17.0.0+, 16.1.2.2+, 15.1.5.1+, 14.1.4.6+, 13.1.5+).

ID1033837 is a part of CVE-2022-1388. https://my.f5.com/manage/s/article/K23605346

Cause

The fix for ID1033837 improved BIG-IP security by adding an additional layer of authentication in Apache for token-based authentication. 

 

Before improvement, only pamcache cookies in /var/run/pamcache folder.

[bipip.hostname:Active:Standalone] pamcache # ll
total 12
-rw-r--r--. 1 apache apache 115 Jan 28 10:45 GVNO9Eu1gjelbMA5L6MbG78JZigjQLz01q8BONfc
-rw-r--r--. 1 apache apache 113 Jan 28 10:40 tywvcfORcj2pyxNScr3oC7JSGVG3dmsv6LWlMPNW
-rw-r--r--. 1 apache apache 113 Jan 28 10:30 WR4vzocfWJ2Hkbkb0rQL4B87ilBGt2v4Ynn0IXut

 

With the fix of ID1033837:

[bigip.hostname:Active:Standalone] pamcache # ll
total 16
-rw-r--r--. 1 root root 19 Jan 28 10:57 ABU4SIHWXUXRPXV5LGAGKAUAZJ ##### REST token also in /var/run/pamcache
-rw-r--r--. 1 apache apache 115 Jan 28 10:41 EDhirwBGITgnOZ2DhmGV1uYLhiYnVOG7t2D6XQgf

 

When there is an inconsistency between /var/run/pamcache folder and REST token, the error log is printed.

Recommended Actions

Customers can get rid of a specific error log entry by deleting REST auth token and /var/run/pamcache entry.

Additional Information

To delete REST tokens, follow the steps in https://my.f5.com/manage/s/article/K02126317 and then restart restjavad and httpd.
