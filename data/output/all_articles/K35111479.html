K35111479: Applying changes to an ASM policy fails with error code '(Errcode: 28)'

Type
Support Solution
Published
2022-01-28
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.X.X, 14.1.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 14.0.1, 14.0.0
Source
https://my.f5.com/manage/s/article/K35111479

Description

Applying changes to an ASM policy fails with a similar message in the Configuration Utility (GUI):

DBD :: mysql :: db do failed: Error writing file '/ts/var/cluster/temp/ucs_sync_file_temp.28286/ts_db.save_dir_28286.cstmp/ts_db.data.DCC.ACCOUNT_NEGSIG_SIGNATURE_PROPERTIES.cstcode: 28' (Errcode: 28)

You can find the same logs in /var/log/asm:

crit g_server_rpc_handler.pl[PID]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::handle_error): Code: 999, Error message = DBD::mysql::db do failed: Error writing file '/ts/var/cluster/temp/ucs_sync_file_temp.26976/ts_db.save_dir_26976.cstmp/ts_db.data.PLC.PL_POLICY_NEGSIG_SIGNATURES.cstmp' (Errcode: 28) at /usr/local/share/perl5/F5/ConfigSync.pm line 483.
crit g_server_rpc_handler.pl[PID]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::log_error_and_rollback): DBD::mysql::db do failed: Error writing file '/ts/var/cluster/temp/ucs_sync_file_temp.26976/ts_db.save_dir_26976.cstmp/ts_db.data.PLC.PL_POLICY_NEGSIG_SIGNATURES.cstmp' (Errcode: 28)

Environment

  • BIG-IP ASM
  • Applying changes to ASM policy

Cause

The BIG-IP system has a high disk usage in the /var/ partition.

Recommended Actions

Follow recommended actions from article K14403: Maintaining disk space on the BIG-IP system to resolve disk space issue in /var/.

Additional Information

None
