Known Issue

The iControlPortal.cgi process may restart when iControl calls are made using the Local.Monitor.get_template_string_property function.

This issue occurs when all of the following conditions are met:

  • You use a custom iControl client application to remotely monitor BIG-IP system pool members.
  • The application makes an iControl call using the Local.Monitor.get_template_string_property function with a property type of STYPE_UNSET.

Impact

All iControlPortal.cgi calls fail while the iControlPortal.cgi process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Remote iControl calls fail and the iControl client application receives an "HTTP 500 - Internal Server Error" message.
  • Error messages similar to the following example appear in the /var/log/httpd/httpd_errors file:

    err httpd[12345]: [error] [client 192.168.10.100] FastCGI: incomplete headers (0 bytes) received from server "/usr/local/www/iControl/iControlPortal.cgi"
    warning fcgi-[5678]: [warn] FastCGI: server "/usr/local/www/iControl/iControlPortal.cgi" (pid 5678) terminated due to uncaught signal '11' (Segmentation fault)
    warning fcgi-[5678]: [warn] FastCGI: server "/usr/local/www/iControl/iControlPortal.cgi" restarted (pid 12345)
