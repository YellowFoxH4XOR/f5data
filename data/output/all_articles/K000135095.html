K000135095: F5 SDC TTA script default destination path and option

Type
Support Solution
Published
2023-06-29
Updated
2023-06-29
Applies to
  • Traffix SDC: 5.X.X, 5.2.X, 5.2.0, 5.1.X, 5.1.0, 5.0.X, 5.0.0
Source
https://my.f5.com/manage/s/article/K000135095

Description

  • Sometimes the tta directory may be different in a different system.
  • The default directory is /var/log/rsyslog if it exists, and the fallback is /tmp. But if you want to use a specific directory. You can use -t or --target option

-t, --target       alternative temporary directory to store the archive

 

Environment

SDC 5.1
 

Cause

  • The default directory and fallback directory of the TTA script
 

Recommended Actions

  • The default directory is /var/log/rsyslog if it exists, and the fallback is /tmp
     

Additional Information

If you want to use specific directory. You can use -t or --target option
For example

  • /opt/traffix/scripts/tta-ng.sh -t /tmp
  • /opt/traffix/scripts/tta-ng.sh --target /tmp
