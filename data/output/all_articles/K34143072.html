K34143072: How to manually delete a BIG-IP device which can not be re-discovered or deleted from BIG-IQ

Type
Support Solution
Published
2022-04-08
Updated
2026-08-06
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X
Source
https://my.f5.com/manage/s/article/K34143072
Description
You are unable to delete and rediscover the problematic BIG-IP and an error message similar to the following is displayed:
Waiting for discovery to start <https://<big-iq ip address>/ui/devices/bigip-devices/view-device/2c08406d-cd9b-4869-aba1-f99dc74cde1b/services>
 
Environment
  • BIG-IQ
  • BIG-IP
Cause
Possible corruption issue.

Recommended Actions
Remove the BIG-IP device from the BIG-IQ configuration.
  1. Login to the BIG IP CLI and check the file "f5-rest-device-id" located in /config directory
# cat /config/f5-rest-device-id
  1. Copy the content of this file (UUID).
  2. Log on to the BIG-IQ (CM) command line
  3. Set variable matching the UUID of the failing BIG-IP on bash by typing the following:
     [root@BigIQCM:] config #UUID=<content_of_f5-rest-device-id_file_previously_copied>
  4. Make a list of URIs to DELETE.
    Example: One-line command to remove BIG-IP with the address 10.1.1.1: 
    restcurl shared/index/config?\$filter=uuid%20eq%20%27"${UUID}"%27|jq .items[].selfLink | cut -d '/' -f 5- | tr -d '"' >/var/tmp/10.1.1.1_group_uri.txt
     
  5. Delete from each group using the following command: 
    while read URI; do restcurl -X DELETE ${URI}; done < /var/tmp/10.1.1.1_group_uri.txt
     
  6. Log Back into the BIG-IQ (CM's) Configuration utility and verify if the BIG-IP device has been deleted.

    * If the BIG-IP is still listed, perform the following steps:
    • Remove the services on GUI
    • Delete the BIG-IP
    • To make sure that all the configuration is gone from the command line of the BIG-IP restart the restjavad process.
      tmsh restart /sys service restjavad
       
  7. Log back into the BIG-IQ Configuration utility and make sure that the device remains as gone.
  8. Re-import the BIG-IP Device
