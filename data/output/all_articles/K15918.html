Known Issue

A memory leak may occur when transferring zone resource records (RR) from a name server to a BIG-IP system. As a result, the zxfrd process may abort.

This issue occurs when transferring a zone to DNS Express.

Impact

The zone transfer operation fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H495912 on the Diagnostics > Identified > Medium screen.
  • The transferred zone database is incomplete because the zxfrd process terminates prematurely during the zone transfer operation.
  • A small memory leak occurs for each RR transferred. The memory leak becomes significant, and the zxfrd process may abort if the number of RRs in the zone is large and the zone transfer is frequent.
  • The zxfrd process generates a core file in the /shared/core directory.

Workaround

There is no work around for this issue. However, you can mitigate the issue by reducing the frequency of zone transfers to the zxfrd process.
