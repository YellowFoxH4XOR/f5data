BIG-IP WebAccelerator version 9.x

In BIG-IP WebAccelerator version 9.x you can write an iRule that modifies egress traffic, such as the headers and/or payload after BIG-IP WebAccelerator has finished processing the traffic.

For example, in version 9.x, the following iRule removes the Vary: Accept-Encoding header after BIG-IP WebAccelerator has finished processing the response:

Note: By default, the BIG-IP WebAccelerator system sends the Vary: Accept-Encoding header in responses when compression is enabled for the requested content.

when HTTP_RESPONSE {
   if {[HTTP::header exists "Vary"]}{
        #log local0. "Vary header exists"
        HTTP::header remove "Vary"
   }
}

BIG-IP WebAccelerator version 10.x

Starting in version 10.x, the BIG-IP WebAccelerator uses a plugin architecture. As a result, iRules that were used in version 9.x to modify post-WAM processing headers/data do not function in BIG-IP WebAccelerator version 10.x.

F5 Product Development is tracking a request for enhancement (RFE) to define an iRule event that can manipulate egress BIG-IP WebAccelerator traffic, as ID 223134 (formerly CR127876).

To manipulate egress traffic in version 10.x, define a virtual server-targeting-virtual server configuration, where a standard virtual server with BIG-IP WebAccelerator disabled references an iRule that modifies the post-WebAccelerator processing headers and data, and targets the BIG-IP WebAccelerator virtual server.

For example, the following configuration elements can be defined to remove the Vary: Accept-Encoding header after BIG-IP WebAccelerator has finished processing the response:

  • Define a standard virtual server with an HTTP profile and BIG-IP WebAccelerator disabled.
  • Assign an iRule that appears similar to the following to the standard virtual server:

    Note: WAM_vip is the BIG-IP WebAccelerator virtual server that should be targeted by the standard virtual server.

    when HTTP_REQUEST {
       virtual WAM_vip
    }

    when HTTP_RESPONSE {
       if {[HTTP::header exists "Vary"]}{
            #log local0. "Vary header exists"
            HTTP::header remove "Vary"
       }
    }
