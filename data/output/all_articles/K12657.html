Known Issue

This is the result of a known issue. The BIG-IP APM does not properly set the MRHSession cookie on the access session. As a result, when a client uses Internet Explorer 7 or Internet Explorer 8 to log in to the BIG-IP APM and access Microsoft Outlook Web Access 2007 with Service Pack 3 installed, they may receive an error message that appears similar to the following example:

Outlook Web Access was not able to process this request

F5 Product Development tracked this issue as ID 347437 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

In addition, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP APM version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
