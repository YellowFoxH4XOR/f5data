Topic

You should consider using this procedure under the following conditions:

  • The BIG-IP system is required to announce IPv6 prefixes and other IPv6 parameters (such as link MTU) to devices on the local network for auto-configuration.
  • You want devices on the local network to automatically use the BIG-IP system as their default gateway for IPv6.

Description

Neighbor Discovery Protocol (NDP) is used with IPv6 and is responsible for the following tasks:

  • Discovering other nodes on the link
  • Determining the L2 addresses of other nodes
  • Detecting duplicate addresses on the link
  • Finding available routers and Domain Name System (DNS) servers
  • Announcing address prefix
  • Maintaining reachability information about the paths to other active neighbor nodes

Router Advertisement (RA) is a feature of IPv6 NDP that allows stateless address autoconfiguration (SLAAC) of IPv6 hosts by advertising the default route, address prefix of the local network, and optionally MTU of the local network.

The BIG-IP system's current implementation of RA allows the system to listen for router solicitations and supply RAs to hosts on the network.

Note: The BIG-IP system does not currently support initiating router solicitations. For more information, refer to K12529: BIG-IP support for the Neighbor Discovery protocol for IPv6 and default route auto-configuration.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have TMOS Shell (tmsh) access to the BIG-IP system.
  • The BIG-IP system is configured with one or more Virtual Local Area Networks (VLANs) and IPv6 self IP addresses.
  • You have determined IPv6 prefixes that the BIG-IP system will advertise to IPv6 nodes.
  • IPv6 nodes are able to send ICMPv6 neighbor discovery messages to the BIG-IP system and respond to ICMPv6 neighbor discovery advertisements per Internet Engineering Task Force (RFC 4861).
  • IPv6 nodes are configured to accept RAs for SLAAC.

Procedures

  • Configuring RA for IPv6
  • Listing the RA configuration

Configuring RA for IPv6

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To configure RA for IPv6 on the BIG-IP system, use the following command syntax:

    create /net router-advertisement <name> vlan <vlan_name> enabled prefixes add { </path/object_name> { prefix <ipv6_prefix> prefix-length <prefix_length> } }

    For example, to configure the BIG-IP system to advertise IPv6 prefixes 2002:a0b:1037:: and 4002:a0b:1027:: on the VLAN External, use the following command:

    create /net router-advertisement NDPConfig vlan External enabled prefixes add { /Common/prefix-1 { prefix 2002:a0b:1037:: prefix-length 64 } /Common/prefix-2 { prefix 4002:a0b:1027:: prefix-length 64 } }

    Note: For more RA options, refer to the tmsh help /net router-advertisement command.

  3. Save the change by entering the following command:

    save sys config

Listing the RA configuration

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To list the RA configuration, use the following command syntax:

    list /net router-advertisement <name>

    For example, to list a configuration named NDPConfig, enter the following command:

    list /net router-advertisement NDPConfig

    Output appears similar to the following example:

    net router-advertisement NDPConfig {
        enabled
        prefixes {
            prefix-1 {
                prefix 2002:a0b:1037::
                prefix-length 64
            }
            prefix-2 {
                prefix 4002:a0b:1027::
                prefix-length 64
            }
        }
        vlan external
    }
