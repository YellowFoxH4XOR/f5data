K000164181: TMSH Shell tab auto-complete for certain commands throws an error after upgrade.

Type
Support Solution
Published
2026-11-10
Updated
2026-11-10
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000164181

Description

In the TMSH shell pressing Tab after a partial object name returns an error instead of completing the command.

When typing certain command options, tab completion returns the following error instead of completing the command:

01020036:3: The requested HTTP Profile (all-p) was not found.

On earlier versions, the same command completes to all-properties.

Tab completion does not work for the affected TMSH commands, interpreting tags as configuration objects and returning an error.

Environment

  • BIG-IP LTM running 17.5.1.10/11, 17.1.3.6, or 21.1.0.4.
  • Using TMSH tab completion on an HTTP profile name, for example: list ltm profile http all-p followed by Tab.

Cause

Bug ID 2534197 tracks the TMSH tab auto-completion failure for modify, list, and show commands.

Answer/Recommended Actions

Install fixed version, if available.

You may otherwise obtain an Engineering Hotfix (EHF) for Bug ID 253419 from F5 Support. Install the EHF during a maintenance window, then repeat the Tab completion test to confirm the fix.
