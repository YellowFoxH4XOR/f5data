Description

Prioritize TLS Versions on SSL profile

Environment

  • BIG-IP LTM

Cause

TLS ciphers not prioritized by version

Recommended Actions
Prioritizing the SSL profile to include a specific SSL cipher in particular order

    1.    Log in to the Configuration utility.
    2.    Go to to Local Traffic > Profiles > SSL > Client.
    3.    Select the Create button.
    4.    Type a name for the SSL profile.
    5.    In the Parent Profile list, select clientssl.
    6.    For Configuration, select Advanced.
    7.    For Ciphers, select the Custom check box.
    8.    In the Ciphers box, type the cipher string in the order you want to prioritize

    For example, TLS version ciphers appears similar to the following:

    DEFAULT:+TLSv1_2:+TLSv1_1:+TLSv1:+DTLSv1

    9.    Complete the remaining profile settings.
    10.    Select the Finished button.
