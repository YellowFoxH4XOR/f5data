Issue

BIG-IP 9.2.0 introduced the following changes to the interface media types:

Note: The changes to BIG-IP 9.2.0 and later are cosmetic changes to the media type syntax and displayed values. There are no changes to the interfaces in hardware.

BIG-IP 9.0.x and 9.1.x branchBIG-IP 9.2.0 and later
1000baseFX1000baseSX
1000baseTX1000baseT
10000baseFX10GbaseT
10000baseTX10GbaseT

Important: Upgrades to 9.2.0 and later will not convert interfaces that have been hard set to the media type setting in the previous version. Refer to K6894: Upgrading to version 9.2.x and rolling forward a 9.1.x configuration results in syntax error and failure to load the /config/bigip_base.conf file.
