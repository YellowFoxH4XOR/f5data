K000138265: NGINX Plus logs "GET" as $request_method in access.log even when client sends POST request

Type
Support Solution
Published
2024-01-17
Updated
2026-08-12
Status
Legacy Content
Applies to
  • NGINX Products
  • NGINX Plus: R26, R30, R29, R27, R31, R28
Source
https://my.f5.com/manage/s/article/K000138265

Description

NGINX Plus logs GET as $request_method in access.log even when client sends POST request.


Environment

- NGINX Plus

- error_page directive uses "/"


Cause

This is by design.


Recommended Actions

Please use "@" instead of "/".


Additional Information

None
