Topic

This article applies to BIG-IP 11.x through 21.x. For information about other versions, refer to the following article:

  • K8719: Configuring the BIG-IP to display host names instead of IP addresses (9.x - 10.x)

Purpose

You should consider using this procedure under the following condition:

  • You want the Configuration utility to display host names instead of IP addresses.

Prerequisites

You must meet one of the following prerequisites to use this procedure:

  • You have host names configured locally within your BIG-IP system.
  • You have DNS with reverse lookup to resolve host names that you have configured.

Description

You can configure the BIG-IP system to display host names rather than IP addresses, provided the IP address has a host name associated with it. You must manually enable this feature using the following procedure.

Note: Some pages experience delays when the configured DNS servers are not responding. This is an expected behavior as the system is attempting to resolve all IP addresses into host names, which depends on DNS server responses.

Procedures

  • Configuring the BIG-IP system to perform host name lookups
  • Configuring the Configuration utility to display host names

Configuring the BIG-IP system to perform host name lookups

Before you can configure the BIG-IP system to display host names, you must configure local host name lookups.

Impact of action: Performing the following action should not have a negative impact on your system.

To complete this task, perform the procedures in the following article:

  • K13206: Configuring local hostname resolution for BIG-IP (11.x and later)

Configuring the Configuration utility to display host names

The following procedure helps you configure the BIG-IP system so the Configuration utility displays resolvable host names instead of IP addresses.

Impact of procedure: This procedure may increase system boot time and decrease the responsiveness of BIG-IP management tools, particularly for large configurations.

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to System > Preferences.
  3. Under System Settings, select the Display Host Names When Possible check box.
  4. Click Update.
