K000133212: No details are shown in Web Application Security Event Logs

Type
Support Solution
Published
2023-03-27
Updated
2023-03-27
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000133212

Description

When selecting an event log in Monitoring >EVENTS > Web Application Security > Event Logs > Events, the details are no longer displayed.

Environment

  • BIG-IQ
  • ASM event logs
  • Details not available

Cause

Vertical grey bar in browser has been moved to the right

Recommended Actions

Move the vertical grey bar back to centre of screen to show additional details

Additional Information

None
