Description

When accessing the GUI Network Map, objects take a long time to load.

Environment

  • Network Map
  • Large configuration
  • System already has fix for ID757414 and ID710976

Cause

With very large configurations, some slowness can be expected when accessing the Network Map.

Recommended Actions

Consider increasing the provision.tomcat.extramb database variable, as this may improve performance.

Note: This step may be considered even if java.lang.OutOfMemoryError messages do not appear in /var/log/tomcat/catalina.out.

Under testing, setting this database variable to a value of 200 was found to improve performance when accessing the Network Map.

modify sys db provision.tomcat.extramb value 200
