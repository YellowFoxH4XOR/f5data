Issue

In BIG-IP 9.4.2 through 9.6.1, the bigpipe syslog remote server command allows only one remote server entry. The command syntax is as follows:

  • Adding the remote server:

    bigpipe syslog remote server <IP_addr>

  • Deleting the remote server:

    bigpipe syslog remote server none

In BIG-IP 10.0.0 and later versions, the bigpipe syslog remote server command allows multiple remote server entries. The command syntax is as follows:

  • Adding a single remote server:

    bigpipe syslog remote server {<name> {host <addr_or_hostname>}}

    For example:

    bigpipe syslog remote server hostname.f5.com host 192.168.1.1

    Note: Remote syslog server objects use object names similar to those used for virtual server objects. Replace <name> with a unique object name, such as the base hostname. The BIG-IP system does not attempt to resolve this name. Replace <addr_or_hostname> with the address or fully-qualified domain name (FQDN) of the remote syslog server. If you enter a hostname, the BIG-IP system saves the hostname in the configuration file, and attempts to resolve the name, when needed. 

  • Adding multiple remote servers:

    bigpipe syslog remote server {<name1> {host <addr_or_hostname>} <name2> {host <addr_or_hostname>} ... }

    For example:

    bigpipe syslog remote server {hostname.f5.com {host 192.168.1.1} hostname2.f5.com {host 192.168.1.2} }

    Note: Remote syslog server objects use object names similar to those used for virtual server objects. Replace <name> with a unique object name, such as the base hostname. The BIG-IP system does not attempt to resolve this name. Replace <addr_or_hostname> with the address or FQDN of the remote syslog server. If you enter a hostname, the BIG-IP system saves the hostname in the configuration file, and attempts to resolve the name when needed.

  • Deleting a single remote server:

    bigpipe syslog remote server <name> delete

    For example:

    bigpipe syslog remote server hostname.f5.com delete

  • Deleting multiple remote servers:

    bigpipe syslog remote server {<name1> <name2> ... } delete

    For example:

    bigpipe syslog remote server {hostname.f5.com hostname2.f5.com} delete

  • Deleting all remote servers:

    bigpipe syslog remote server none

Important: After making command line changes, save the configuration by typing the following command at the command line:

  • BIG-IP 10.0.0 through 10.2.1:

    bigpipe save

  • BIG-IP 10.2.2 and later versions:

    bigpipe save all

Note: For more information, refer to the bigpipe syslog man page by typing bigpipe syslog help at the command line.

Note: All log messages are sent to remote syslog servers, by default. For more information, refer to K11723: Filtering log messages sent to remote syslog servers (9.4.x - 10.x).
