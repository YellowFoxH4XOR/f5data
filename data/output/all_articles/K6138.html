Topic

Enterprise Manager may fail to discover BIG-IP devices or mark them impaired for several reasons. Begin by referencing the following known issues and informational articles:

ArticleTitle
K9742Enterprise Manager may need to install a new big3d data collection agent on managed devices
K10827Enterprise Manager marks the BIG-IP system with Kerberos profiles as Impaired
K11408Enterprise Manager marks the BIG-IP LTM system with rate shaping as Impaired
K11409The Enterprise Manager marks devices with wildcard routes as Impaired
K11669Enterprise Manager marks the BIG-IP system with a OneConnect profile as Impaired
K11695Enterprise Manager marks a BIG-IP system that has a non-ASCII character in the description field of an administrative partition as Impaired
K12306The Enterprise Manager may mark a BIG-IP ASM device as impaired
K12466The Configuration utility fails to process digital certificates with a Subject field greater than 1024 bytes
K12649The Enterprise Manager may fail to discover devices that generate very large UCS archives
K13962Enterprise Manager discovery may fail when the system does not have access to activate.f5.com
K14489Enterprise Manager may fail to completely discover a managed BIG-IP device containing comments in an iRule

If none of these articles apply to your situation, verify the communication between the Enterprise Manager and the BIG-IP system by performing the procedures described in K7823: Troubleshooting and debugging Enterprise Manager iControl connectivity.

If you need to open a case with F5 Technical Support to assist in troubleshooting your issue, refer to K7569: Information required when opening a support case for Enterprise Manager.
