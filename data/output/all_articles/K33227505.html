Description

On Windows 10 clients, the new Microsoft Chromium-based Edge browser is supported in the following APM versions:

  • 13.x
  • 14.x
  • 15.x
  • 16.x

Environment

  • BIG-IP APM versions 13.x, 14.x, 15.x, 16.x
  • Windows 10 clients with the new Microsoft Chromium-based Edge browser

Cause

None

Recommended Actions

None

Additional Information

On January 15 2020, Microsoft released the new Chromium-based Edge browser to the public. It is available for download for the following Windows clients: 10, 8.1, 8, and 7
