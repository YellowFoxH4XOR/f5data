K32557791: When does BIG-IP evaluation license expire?

Type
Support Solution
Published
2022-01-13
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K32557791

Description

Evaluation license expires the last millisecond of the last day of the evaluation.

Environment

  • BIG-IP

Cause

Eval license expires the last millisecond of the last day of the evaluation - on reaching the time 00:00:00 in the CURRENT TIMEZONE as configured by "ZONE" in "/etc/sysconfig/clock"

An evaluation license is no different than any other license except for the duration of the expiration. It is meant to be used in combination with the provisioning mechanism to allow users to evaluate other modules in such a way that when the eval license expires, they can view and maintain their configuration but functionality stops without door-stopping other licensed features. The one exception is LTM which is always partially provisioned and therefore can't support this evaluation license behavior - it's either licensed and accessible or it's not licensed and/or expired and, therefore, neither accessible nor functional. Consequently, TMM enforces functionality of features and has no concept of provisioning. It is purely based on whether feature flags exist in a license and have not expired.

Recommended Actions

Purchase a BIG-IP full license.
