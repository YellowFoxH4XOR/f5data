Description

Pod registry-console becomes ImagePullBackOff status whenever controller is rebooted, and need to workaround this issue by editing the registry-console file and changing the port, even upraded to 1.3.1, it returns every time rebooting Controllers.

 

Environment

  • F5OS-C
  • 1.3.1
  • Previsional worlaround (not documented) for Bug ID 1071673 is applied before upgraded to 1.3.1.

Cause

Proper workaround for Bug ID 1071673 was not applied before upgrade.

Upgrade will not rebuild Openshift, so once Openshift is broken it need to be rebuild.

 

Recommended Actions

In maintenance window, Bug ID 1071673 's workaround should run.

touch /var/omd/CLUSTER_REINSTALL

Once this command is run on Active Controller, 

monitor /var/log/openshift.log in both Controller.

Rebuild openshift will take typivally  for 1.5 hours.
