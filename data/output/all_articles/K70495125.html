Description

Configuring HSL to log DNS requests and responses on a virtual server, and no log data is sent to the HSL destination.

Environment

  • LTM virtual server processing DNS traffic
  • System does not have either a DNS module or AFM module add-on license
  • System configure as on K65762138

Cause

This is expected behavior. The DNS logging profile requires either a DNS or AFM license in order to be configured.

Note: This is a licensing requirement. The DNS or AFM modules do not need to be provisioned.

Recommended Actions

Unfortunately, at this time a DNS or AFM license is required. Although the documentation Configuring Remote High-Speed DNS Logging outlines the setup for LTM and DNS modules, only systems with an active DNS or AFM add-on license will work correctly. To acquire a DNS or AFM add-on license, please contact your F5 Account Team for further information.
