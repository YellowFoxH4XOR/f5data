Issue

Error Message

err vdi[<PID>]: 01490000: {<session_ID>} View signal: error processing client request: system:111 'Connection refused'

In this error message, note the following:

  • <PID> is the vdi process ID.
  • <session_ID> is a session identifier for the affected session.

For example:

err vdi[5968]: 01490000: {68c.S.} View signal: error processing client request: system:111 'Connection refused'

Message Location

You may encounter this message in the following locations when debug logging for virtual desktop infrastructure (VDI) is configured:

  • The /var/log/apm file

Description

This error message indicates that connection was refused by the back-end resource or the connection attempt was dropped while being routed to the resource.

This message may occur when the following condition has been met:

  • A BIG-IP APM session attempts to connect to a VMware View desktop resource and the connection is:
    • Refused by the destination resource.
    • Blocked by a firewall.
    • Routing issue.
    • Other network related issue.

Example log messages: 

notice vdi[5968]: 01490000: {68c.S.} Error reported for an outgoing connection
info vdi[5968]: 01490000: {68c.S.} Error reported on initiated outgoing connection.
err vdi[5968]: 01490000: {68c.S.} View signal: error processing client request: system:111 'Connection refused'

Impact

The VMware View desktop resource is not accessible.

Recommended Actions

  • Verify the ability to route from the BIG-IP APM system to the VMware View remote desktop resource.
  • Review the VMware View remote desktop configuration to ensure that the required TCP virtual servers are configured correctly.

    Note: For more information refer to the Presenting a View Desktop on an APM Webtop chapter of the BIG-IP APM  BIG-IP Access Policy Manager: Third-Party Integration manual. For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.
