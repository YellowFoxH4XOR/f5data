K000138328: System controller upgrade to F5OS-C 1.6.1 appears to be unsuccessful due to failed install status

Type
Support Solution
Published
2024-02-28
Updated
2024-02-28
Applies to
  • F5OS
  • F5OS-C: 1.6.1
Source
https://my.f5.com/manage/s/article/K000138328

Description

After performing an upgrade to F5OS-C 1.6.1 system reports unsuccessful install and the old version running, even though both system controllers appear to be properly running F5OS-C 1.6.1 for both the OS software and services software. Sample output of the show system version command:

 

controller-1 show system version

# show system version
system version os-version 1.6.1-19136
system version service-version 1.6.1-19136
system version product F5OS-C

controller-2 show system version

# show system version
system version os-version 1.6.0-18695
system version service-version 1.6.0-18695
system version product F5OS-C

Environment

  • F5OS-C 1.6.1

Cause

This is a known issue in F5OS-C 1.6.1

Recommended Actions

This is a cosmetic error and the upgrade was performed correctly. The problem is fixed in F5OS-C 1.6.2.

None
