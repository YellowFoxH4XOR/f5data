Known Issue

Description

The standby BIG-IP system may erroneously forward L2 traffic.

This issue occurs when all of the following conditions are met:

  • You have configured the VLAN group in transparent or translucent mode.
  • You have configured the virtual server with a FastL4 profile.
  • The vlangroup.flow.allocate BigDB key is set to enable.
  • The upstream switch forwards a SYN packet, which is destined for the virtual server, to the standby BIG-IP system.

If the upstream switch forwards a SYN packet to both BIG-IP systems, the standby BIG-IP system erroneously creates a new connection flow. In doing so, the standby BIG-IP system does not accept the mirrored connection data for the affected connection from the active BIG-IP system.

Impact

The active BIG-IP system is unable to mirror affected connections to the standby BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The connection entries for the affected virtual servers may differ between the active and standby systems.
  • In the event of a failover, established connections to the affected fastL4 virtual servers may fail.

Workaround

To work around this issue, you can set the vlangroup.flow.allocate BigDB key to disable, or configure the VLAN group to use Opaque mode. To do so, perform one of the following procedures:

Disabling the vlangroup.flow.allocate BigDB key

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. Set the vlangroup.flow.allocate BigDB key to disable by running the following command:

    modify sys db vlangroup.flow.allocate value disable
  3. Save the change by typing the following command:

    save /sys config

Configuring the VLAN group to use opaque mode

Impact of workaround: The VLAN group uses Proxy ARP with Layer 3 forwarding. For additional information, refer to the VLANs and VLAN Groups chapter of the BIG-IP TMOS: Concepts guide.

  1. Log in to the BIG-IP Configuration utility
  2. Navigate to Network › VLANs › VLAN Groups.
  3. Click the name of the affected VLAN group.
  4. Click Transparency Mode, and choose Opaque
  5. To save the changes, click Update.
