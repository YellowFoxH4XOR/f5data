Issue

BIG-IP software allows you to configure an HTTPS health monitor to use a client certificate for authentication purposes. Starting in BIG-IP 9.3.1 and 9.4.0, you can configure HTTPS monitors to use private keys stored in a FIPS module.

F5 Product Development tracked this feature request as CR77846, and it was added in BIG-IP 9.3.1 and 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this feature was added in Hotfix-BIG-IP-9.3.0-HF3 issued for BIG-IP 9.3.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about managing F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.
