Known Issue

This is the result of a known issue. In rare instances, the BIG-IP system may fail to send a Secure Sockets Layer (SSL) message, such as the server hello done message, to a client when the virtual server is configured to use Datagram Transport Layer Security (DTLS). As a result, the SSL handshake fails.

F5 Product Development tracked this issue as ID 226969 and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP LTM or APM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
