Known Issue

The BIG-IP system may fail to restart after a failure condition with the High-Speed Bridge (HSB) device.

This issue occurs when the following condition is met:

  • The BIG-IP system experiences a failure condition with the HSB device.

When the BIG-IP system experiences a failure condition with the HSB device, the system triggers a restart to recover. When this issue occurs, the BIG-IP system fails to restart and the Traffic Management Microkernel (TMM) restarts continually.

Impact

TMM restarts continually, causing interruptions in traffic processing.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to restart and TMM restarts continually.
  • The BIG-IP system fails over to a peer device in the device group.
  • TMM generates a core file to the /shared/core/ directory.
  • In the /var/log/tmm file, you notice messages similar to the following example:

    notice ifdown failed to disable hsb0
    notice Bring tmm HSB HA subsystem down

    notice panic: hsb interface 0 DMA lockup on transmitter failure.
    notice ** SIGFPE **

Workaround

To work around this issue, you can manually restart the BIG-IP system. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Advanced Shell (bash).
  2. Restart the system by typing the following command:

    reboot
