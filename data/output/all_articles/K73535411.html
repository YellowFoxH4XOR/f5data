Description
This article describes on how to delete/update the APM ACE via CLI 

Environment

  • BIG-IP APM
  • ACL/ACE
  • CLI/tmsh

Cause
None

Recommended Actions
Deleting/Updating specific APM ACEs via CLI has no straightforward approach, here is a method where you can quickly update the APM ACEs via CLI.

Important:

  • F5 recommends that before making any changes to your systems, you back up each system and store the backup in a remote and secure location. For information, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.
  • Ensure there is enough disk free space on /var/ and /shared/ partitions. For information, refer to K14403: Maintaining disk space on the BIG-IP system.
  • The changes will impact the traffic if the ACLs are assigned to a running APM resource, thus, we advise you to test first the changes before applying them in the production environment---in addition, test one ACE first before going for a bulk change.

For example:

  1. List and copy the ACLs to text file/notepad

    root@(BIGIP)(cfg-sync Standalone)(Active)(/Common)(tmos)# list apm acl /Common/dummy_acl
    apm acl dummy_acl {
        acl-order 20
        entries {
            {
                action discard
                dst-end-port http
                dst-start-port http
                dst-subnet 0.0.0.0/0
                protocol 6
                src-end-port http
                src-start-port http
                src-subnet 0.0.0.0/0
            }
            {
                action discard
                dst-end-port ftp
                dst-start-port ftp
                dst-subnet 0.0.0.0/0
                host dummy.ftp.localhost
                paths /
                scheme http
                src-end-port ftp
                src-start-port ftp
                src-subnet 0.0.0.0/0
            }
            {
                action discard
                dst-subnet 0.0.0.0/0
                host dummy.web.localhost
                paths /
                scheme http
                src-subnet 0.0.0.0/0
            }
        }
    }
     
  2. Modify the ACLs accordingly

    In this example, we need to remove the ACE with entries of:

            {
                action discard
                dst-end-port http
                dst-start-port http
                dst-subnet 0.0.0.0/0
                protocol 6
                src-end-port http
                src-start-port http
                src-subnet 0.0.0.0/0
            }

    Thus, in the text file/notepad the content should be the following:

    apm acl dummy_acl {
        acl-order 20
        entries {
            {
                action discard
                dst-end-port ftp
                dst-start-port ftp
                dst-subnet 0.0.0.0/0
                host dummy.ftp.localhost
                paths /
                scheme http
                src-end-port ftp
                src-start-port ftp
                src-subnet 0.0.0.0/0
            }
            {
                action discard
                dst-subnet 0.0.0.0/0
                host dummy.web.localhost
                paths /
                scheme http
                src-subnet 0.0.0.0/0
            }
        }
    }
