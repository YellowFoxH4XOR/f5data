K1237: Isolating NameSurfer problems by removing zone files

Topic

To remove NameSurfer zone files, perform the following steps:

  1. Log in to the command line.
  2. Change to the /usr/local/namesurfer/config directory, by typing the following command:

    cd /usr/local/namesurfer/config/

  3. Create a backup of the existing NameSurfer configuration files, by typing the following command:

    tar -czf /var/tmp/namesurfer-config.backup.tgz *

  4. Change to the /usr/local/namesurfer/db directory, by typing the following command:

    cd /usr/local/namesurfer/db/

  5. Create a backup of the existing NameSurfer zone files, by typing the following command:

    tar -czf /var/tmp/namesurfer-zones.backup.tgz *

  6. Using a text editor, such as vi or pico, edit the /usr/local/namesurfer/db/ns.zones file.
  7. Remove any lines that reference files reported in NameSurfer console or that log errors.
  8. Remove the file that describes the NameSurfer zone databases, by typing the following command:

    rm /usr/local/namesurfer/db/db.nsurf.zones

  9. Reinitialize the NameSurfer zone database, by typing the following command:

    /usr/local/namesurfer/bin/dbinit

  10. Restart NameSurfer.

    For specific instructions, refer to K1092: Restarting the NameSurfer process from the command line.

If NameSurfer starts successfully, this indicates that a file was missing. If this is the case, examine your 3-DNS Controller backups to determine if the file previously existed and was removed.
