Known Issue

Mac OS devices may be unable to establish a BIG-IP APM access session.

This issue occurs when all of the following conditions are met:

  • Your access policy is configured with one or more of the following endpoint security (client-side) agent checks:
    • Antispyware
    • Antivirus
    • Firewall
    • Hard disk encryption
  • Your BIG-IP APM system uses the OPSWAT library version 3.6.8642.2.
  • Users attempt to establish a session using a Mac OS X device.

Impact

The session fails to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When users attempt to establish a session using the Safari browser, the browser stops responding when the BIG-IP APM browser endpoint security (client-side) plugin attempts to check the client device configuration items.
  • When users attempt to establish a session using the Mozilla Firefox browser, the BIG-IP APM browser endpoint security (client-side) plugin fails.
