Known Issue

This is the result of a known issue. The PVAC process uses a single socket for MCP message processing. Since MCP messages can be either subscription events or request/response messages, this can result in lost events, or misprocessed request/response messages.

F5 Product Development tracked this issue as CR129672 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, BIGIP-10.0.1-378.0-HF3 has been issued for BIG-IP WebAccelerator version 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
