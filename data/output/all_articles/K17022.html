Known Issue

A server-side Secure Sockets Layer (SSL) resumed session may fail to utilize hardware acceleration.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system with a server-side SSL profile.
  • An SSL resumed session occurs, using a cipher that is normally allowed to be encrypted in hardware.

Impact

You may observe reduced performance for SSL transactions and higher CPU usage due to the SSL session being encrypted/decrypted in software for valid hardware ciphers.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Statistical information for SSL hardware acceleration for the server-side SSL profile may not report expected levels of hardware acceleration.

    For example:

    show ltm profile server-ssl serverssl

    SSL Hardware Acceleration              
      Full                                         0
      Partial                                      0
      None (Software)                           1.3K
                                           
    Session Cache                          
      Current Entries                              8
      Hits                                      1.3K
      Lookups                                   1.3K
      Overflows                                    0
      Invalidations                                0
