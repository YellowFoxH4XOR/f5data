K000139001: What events can trigger a change of the last-modified-time parameter under 'ltm virtual' configuration

Type
Knowledge
Published
2024-03-27
Updated
2024-09-10
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.0.0, 16.1.0, 16.0.X, 16.0.1, 15.1.9, 15.1.10, 16.X.X, 17.X.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 15.1.8
Source
https://my.f5.com/manage/s/article/K000139001

Description

  • last-modified-time will be updated when we modify the virtual server configuration except below:
    • metadata
    • clone-pool
    • persist
    • policies
    • profiles

Environment

  • BIG-IP LTM
  • Virtual Server

Cause

This is working as designed.

Recommended Actions

These commands can be run to verify the result:

root@(bigip)(cfg-sync Standalone)(/Common)(tmos)# list ltm virtual test last-modified-time

ltm virtual test {

  last-modified-time 2024-02-28:23:06:17

}

 

root@(bigip)(cfg-sync Standalone)(/Common)(tmos)# modify ltm virtual test metadata add { name { value test-server }} ; list ltm virtual test last-modified-time

ltm virtual test {

  last-modified-time 2024-02-28:23:06:17

}

 

root@(bigip)(cfg-sync Standalone)(/Common)(tmos)# modify ltm virtual test clone-pools none ; list ltm virtual test last-modified-time

ltm virtual test {

  last-modified-time 2024-02-28:23:06:17

}

 

root@(bigip)(cfg-sync Standalone)(/Common)(tmos)# modify ltm virtual test persist replace-all-with { cookie } ; list ltm virtual test last-modified-time

ltm virtual test {

  last-modified-time 2024-02-28:23:06:17

}

 

root@(bigip)(cfg-sync Standalone)(/Common)(tmos)# modify ltm virtual test policies replace-all-with { test } ; list ltm virtual test last-modified-time

ltm virtual test {

  last-modified-time 2024-02-28:23:06:17

}

 

root@(bigip)(cfg-sync Standalone)(/Common)(tmos)# modify ltm virtual test profiles replace-all-with { http } ; list ltm virtual test last-modified-time

ltm virtual test {

  last-modified-time 2024-02-28:23:06:17

}
