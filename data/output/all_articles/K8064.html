Known Issue

This is the result of a known issue. Setting the interface speed on a small form pluggable (SFP) fiber interface to any option other than auto may cause the interface to incorrectly report the link as up. This issue can occur when the link is unplugged, the link is not active on the other end, or when the interface speed is set or forced to a speed other than auto and the SFP transceiver is removed.

This issue affects the following platforms that contain the SFP fiber interfaces:

  • 1500
  • 3400/3410
  • 6800

F5 Product Development tracked this issue as CR52846 and it was fixed in BIG-IP version 9.4.2. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, and WebAccelerator Release Notes.

Workaround

You can prevent the interface from falsely reporting the link as up by changing the interface media speed to auto.
