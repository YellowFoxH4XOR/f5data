Known Issue

Why do I receive the following error message when I run the bigpipe verify load command?

The requested SNAT global attribute does not exist.



Although there may be valid reasons for this error, this may be the result of a known issue. When connection mirroring is enabled for a SNAT, the bigpipe verify load command will generate this error message.

This issue is cosmetic; it will not prevent the configuration from loading.

F5 Product Development tracked this issue as CR29751.
