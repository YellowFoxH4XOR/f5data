Description


Laptops using Edge Client are getting: 

 

Environment

  • BIG-IP APM
  • Edge client Version 7220,2022,308,1349
  • Windows 10

Cause

Bug alias 756468 VPN Driver covpnv64.sys may crash causing BSOD on windows 10

Recommended Actions

  1. Verify if laptop is using Windows Driver Verifier. For more information on Driver Verifier, including how to stop it, refer to Driver Verifier on the Microsoft website.

    • Using Windows Driver Verifier: It is most likely ID756468. Proceed to step 2.

    • Not using Windows Driver Verifier: Refer to K06273599: A Windows stop error appears during an established network access VPN session  

  2. Update/Upgrade to APM Client version to 7.2.2.2 or later
