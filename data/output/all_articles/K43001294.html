Description

Intermittent problems entering credentials into the BIG-IP Edge client logon form when the CTRL key is pressed while in the login dialog.

Environment

  • F5 Edge Client, build 7210
  • Passwords that contain special characters that utilize the CTRL+ALT (ALTGR) combination. Example: ?? @ ?? $ [ ] 

Cause

 BUG 942953 

Recommended Actions

The APM end user can work around this by pressing the CTRL button a second time.
