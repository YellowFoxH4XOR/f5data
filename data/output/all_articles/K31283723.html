K31283723: Trying to find lease time for APM lease pools?

Type
Support Solution
Published
2019-08-21
Updated
2023-02-21
Applies to
  • BIG-IP APM: 15.X.X
Source
https://my.f5.com/manage/s/article/K31283723

Description

  • Lease pool timeout

Environment

  • BIG-IP APM
  • Network Access configured with a lease pool

Cause

Lease pool times will be tied to the access sessions, however long the access session will last for the lease pool IP address will be tied to that user. There is a sweeper that run every 25ms that checks if there are any addresses that can be returned to the lease pool.

Recommended Actions

This can be verified through the following commands:

  • Using tmctl:

    tmctl -w200 leasepool_stat
     
  • Using tmsh:

    tmsh show apm resource leasepool <name_of_leasepool>

    For example, if you have a lease pool with the name lease_pool:

    tmsh show apm resource leasepool lease_pool
