Known Issue

Changes that you make to a data group do not automatically propagate to a Client SSL profile.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with a Client SSL profile.
  • The SSL Forward Proxy Bypass feature on the Client SSL profile is enabled and references a data group.
  • You subsequently update the data group that is referenced in the SSL Forward Proxy Bypass configuration.

Impact

Data group configuration changes are not automatically propagated to a Client SSL profile.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Changes you make to a data group do not take effect on a Client SSL profile.
  • After modifying the data group, you notice that the previously configured data group settings are in effect on a Client SSL profile.

Workaround

To work around this issue, you can update the affected Client SSL profile each time you modify the data group. To do so, perform the following procedure:

Note: You must perform this workaround each time a change is made to a data group that is referenced in a Client SSL profile that has the SSL Forward Proxy Bypass feature enabled.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client.
  3. Click the name of the affected Client SSL profile.
  4. Click Update.
  5. Repeat for each Client SSL profile that has the SSL Forward Proxy Bypass feature enabled and references the affected data group.
