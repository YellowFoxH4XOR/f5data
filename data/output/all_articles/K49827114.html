Security Advisory Description

BIG-IP Edge Client for macOS may allow unprivileged users to access files owned by the root account. (CVE-2019-6668)

Impact

BIG-IP Edge Client may allow an unprivileged user on the affected macOS device to get ownership of files owned by the root account on the local client host.
