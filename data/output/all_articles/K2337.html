Topic

To configure BIG-IP to allow SSL proxy to support TCP keep-alives, perform the following steps:

  1. Type the following commands to enable or disable TCP keep-alive support:

    bigpipe proxy <ip>:<port> client tcp keepalives <enable>|<disable>
    bigpipe proxy <ip>:<port> server tcp keepalives <enable>|<disable>

    This allows TCP keep-alive support on both the client and the server, if the keep-alives are sent all the way to the client.

  2. Save and reload the configuration, by typing the following commands:

    b save
    b load

    The proxy restarts and will now support TCP keep-alives.

Note: The sysctl variables net.inet.tcp.keepidle, net.inet.tcp.keepinterval and net.inet.tcp.keepcount also affect the keep-alive behavior. Review these variables to ensure the settings are configured according to your preferences. You can review the descriptions for these variables in the /etc/rc.systcl file.
