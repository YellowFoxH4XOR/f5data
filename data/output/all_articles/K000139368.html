Description

The DNS (previously known as GTM) module 'BIG-IP' monitor type is a special monitor intended for scenarios where the monitored target is a virtual-server on a connected BIG-IP LTM device. It takes advantage of the fact that the BIG-IP LTM is already monitoring the related pool, so it can ask the mcpd process on the LTM for the current status of the virtual server, instead of actually running a monitor probe and waiting for it to complete.

 

The BIG-IP monitor is automatically applied to any GTM server object of product type 'BIG-IP', or in other words, any BIG-IP devices that are configured to the GTM via iQuery. Although it is possible to apply a BIG-IP monitor to individual virtual servers, or even to GTM pools and/or GTM pool members, it should only be applied to GTM server objects - adding a BIG-IP monitor to a GTM pool can result in unexpected results, including the pool members being marked down with a state of 'big3d: timed out'.

 

Environment

  • BIG-IP DNS (previously known as GTM) provisioned
  • 'GTM server' -> 'virtual-servers' are configured on monitored LTM devices.

 

Cause

Apply a BIG-IP monitor at the pool level

 

Recommended Actions 

None
