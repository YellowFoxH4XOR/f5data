Topic

The BIG-IP system provides the ability to obtain system memory information through data collected by the Simple Network Management Protocol (SNMP).

Description

An SNMP-based network monitoring tool obtains data by polling BIG-IP SNMP objects that contain system memory information. Each SNMP object has a unique object identifier (OID). The network monitoring tool can be configured with the OIDs of the objects to perform SNMP-related tasks.

The SNMP objects for system memory are the standard objects found in the UC Davis UCD-SNMP management information base (MIB).
