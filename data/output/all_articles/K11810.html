Known Issue

This is the result of a known issue. An iSession tunnel using hardware compression may enter a tight loop when attempting to establish the control connection. As a result, TMM may miss a heartbeat request and restart.

F5 Networks Product Development is tracking this issue as ID 328335 and CR141733.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP version 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for version 10.2.0. You may download hotfixes or later versions of hotfixes from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing F5 Networks product hotfixes for BIG-IP version 10.x systems.
