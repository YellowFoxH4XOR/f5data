Known Issue

This is the result of a known issue. Rolling forward a BIG-IP LTM 4.5 PTF-04 through 4.5.12 or version 9.0 through 9.1.2 configuration to BIG-IP LTM 9.1.2 results in a mismatch of the time zones reported on the command line interface (CLI) and the Configuration utility.

This behavior is a result of a time zone change that occurred in BIG-IP LTM 9.1.2 (CR58315). For more information, refer to K6551: F5 software compliance with the Energy Policy Act of 2005 and K7021: BIG-IP compliance with the Energy Policy Act of 2005.

The host system, which is accessible through the CLI, will report a different time zone than the time zone specified in the Configuration utility. This mismatch causes inconsistencies between the times reported at the CLI and those reported within the Configuration utility.

F5 Product Development tracked this issue as CR64142, and it is was fixed in BIG-IP LTM 9.1.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

You can work around this issue by selecting a different time zone within the Configuration utility, and then setting the time zone back to the desired time zone. To do so, perform the following procedure:

  1. Log in to the BIG-IP LTM Configuration utility.
  2. Navigate to System > Platform.
  3. Select a different time zone.
  4. Click Update.
  5. Select the desired time zone.
  6. Click Update.

You can ensure the CLI time zone matches the time zone in the Configuration utility by typing the following command from the CLI:

date
