K84355951: Behavior when interfaces are disabled

Type
Support Solution
Published
2023-05-05
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K84355951

Description

Under some circumstances, such as, retiring a BIG-IP or migrating VEs, it is necessary to disable interfaces to prevent it from managing traffic.

Environment

  • Interfaces are disabled in an attempt to prevent the BIG-IP from taking traffic

Cause

What happens after the interface is disabled?
  • The BIG-IP continues to send monitor traffic until ARP expires for those nodes.
  • At that point, the monitors time out and these TCP connections expire. All nodes are marked down.
  • Then it only sends ARP requests for these nodes, but never receives a response.
This applies to standalone BIG-IPs and BIG-IPs in an highly available (HA) pair.

Recommended Actions

If unexpected traffic patterns occur after disabling these interfaces, check the following items.
  1. Collect tcdumps to confirm that no production traffic is reaching it.
  2. Clear MAC tables on neighboring devices to ensure they're not forwarding traffic to these BIG-IPs.
  3. Disconnect network cables on the BIG-IP.
