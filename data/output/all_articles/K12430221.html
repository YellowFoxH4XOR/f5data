Description
The BIG-IQ database structure is not always intuitive. This is an attempt to clearly illustrate the most important aspects of the BIG-IQ database with the intention of aiding in troubleshooting BIG-IQ issues.

Environment

  • Command Line access to the BIG-IQ system.
  • A user account that allows getting to a bash shell prompt.
  • A basic understanding of JSON notation.

Cause

  • There is an error in BIG-IQ that isn't descriptive in the GUI.
  • A discovered device in BIG-IQ GUI won't remove. 
  • You need to see a history from the conflict management portion within service discovery.
  • General BIG-IQ troubleshooting.

Recommended Actions

This is an index to the database structure available within the Mongo database of BIG-IQ.  There are some basic things to know when investigating:

Use of restcurl

You can construct the restcurl command once you find the portion of the iControl REST API database that you need information from.

Impact of procedure: Simple inquiries should not pose a significant risk. Using restcurl for PATCH or DELETE is beyond the scope of this article and should only be used when instructed to do so by a Network Support Engineer. More information about the iControl REST API for BIG-IQ can be found on Cloud Docs.

Example

  • You want to know specific device information for all BIG-IPs managed by BIG-IQ
  • You locate the desired URI/tree structure for this information:
    /shared/resolver/device-groups/cm-bigIp-allDevices/devices
  • You can construct the request with the appropriate URI:
    restcurl shared/resolver/device-groups/cm-adccore-allbigipDevices/devices

Viewing all database components in a module with an iControl REST URI

  • Use the following command to view all cm components:
    restcurl cm
  • Use the following command to view all shared components:
    restcurl shared
  • View all cm components without JSON formatting:
    restcurl cm | cut -d'/' -f5,6 | grep cm | sort | uniq
  • View all shared components without JSON formatting:
    restcurl shared | cut -d'/' -f5,6 | grep shared | sort | uniq
