Description

In a newly created security policy, Parameters configured to auto-detect value type don't detect base64 content.

Environment

  • Adv. WAF
  • Security Policy
  • Parameters are configured to auto-detect value

Cause

This might cause false-positive enforcement.

Recommended Actions

ASM admin should work closely with the application team to add parameters that need to have Base64 decoding enabled manually.

Additional Information

Starting v17.5.0, Adv.WAF support for Base64 Auto Detection has been added.
