Description
Some BIG-IP ASM Attack Signatures are showing as Staged when viewing request violations in Security > Event Logs, but they are Enforced in the Security Policy.

Environment

  • BIG-IP ASM
  • Wildcard parameter set with Perform Staging
  • Attack signatures

Cause

When the wildcard parameter is set with Perform Staging, all attack signatures which trigger on parameter elements will show as staging and will not block requests.

Recommended Actions

Enforce the wildcard parameter manually or accept a learning suggestion to enforce it. If the wildcard parameter was moved to Staging from Enforced state due to Policy Builder's Track Site Changes feature, you can increase the amount of traffic required from untrusted sources to loosen a security policy.

  1. Log on to the BIG-IP ASM Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking.
  3. Expand Policy Building Process section.
  4. Select Advanced from the dropdown menu on the right side of the page.
  5. Expand Minimize false positives (Track Site Changes) section.
  6. Configure Untrusted Traffic settings..
