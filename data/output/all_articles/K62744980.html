Known Issue

Under rare circumstances, the Traffic Management Microkernel (TMM) process may produce a core file.

This issue occurs when the following condition is met:

  • The exact condition that causes this core is unknown.

Impact

The device in the standby state for a traffic group is not operational until TMM restarts. If the device is active for a different traffic group, that traffic group will fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system logs an error message in the /var/log/tmm file that appears similar to the following example:

     "vmem_hashlist_remove not found" failed.
