Description

BIG-IP APM Application Tunnel connections fail if configured with a Host Name.

  • Applications fail to connect over a configured APM Application Tunnel.
  • In the logterminal file in the %temp% directory of the client PC or from a F5 Troubleshooting Utility (CTU) output you will observe the following log messages:
ELEVATIONHELPER, 48, \patchhosts.cpp, 6, ::PatchHosts, ENTER (remote host: <destination_host_name>, local host: <loopback_ip_address>, tunnel host: <destination_ip_address>, patch: 1)
HOST, 2, \UFilterService.cpp, 182, UFilterService::Connect(), Failure connecting to F5 DNS Relay Proxy service. Service is not installed or is not running.

Environment

  • BIG-IP APM Application Tunnel Resource with Destination configured as Host Name.
  • Windows Client PC

Cause

This is because the client PC does not have the DNS Relay Proxy installed.

Recommended Actions

Download and install the DNS Relay Proxy on the client PC.

Version 13.x and 14.x:

1. Login to the BIG-IP Admin GUI (Configuration Utility).
2. Navigate to Access > Connectivity/VPN > Connectivity > Profiles.
3. Select the Connectivity Profile that is in use on the APM Virtual Server.
4. Click on "Customize Package."
5. Select the "DNS Relay Proxy Service" and click Download.
6. Run the downloaded BIGIPEdgeClient executable on the client PC.
Note: The BIGIPEdgeClient executable must be installed as an Administrator.

Version 11.x and 12,x:

1. Login to the BIG-IP Admin GUI (Configuration Utility).
2. Navigate to Access Policy > Secure Connectivity.
3. Select the Connectivity Profile that is in use on the APM Virtual Server.
4. Click on "Customize Package."
5. Select the "DNS Relay Proxy Service" and click Download.
6. Run the downloaded BIGIPEdgeClient executable on the client PC.
Note: The BIGIPEdgeClient executable must be installed as an Administrator.

Additional Information

Application Tunnels use a local loopback IP Address on the client PC to connect the Application Tunnel destination. When the destination is a Host Name the DNS Relay Proxy is required so that a host mapping entry is added to map the Host Name to the loopback IP Address. 

On a client PC with the DNS Relay Proxy Service installed you will observe the following log messages in the logterminal file in the %temp% directory of the client PC or from a F5 Troubleshooting Utility (CTU) output:

HOST, 48, \UFilterService.cpp, 191, UFilterService::Connect(), Connected to F5 DNS Relay Proxy service.
HOST, 48,,,, UFilterService::AddStaticEntry(), Static entry added, "<destination_host_name>" => "<destination_ip_address>"
HOST, 48,,,, UFilterService::FltServiceAddMappingRule(), Rule added, rule="<destination_ip_address>:<port> => <loopback_ip_address>:<port>"
HOST, 48,,,, UFilterService::FltServiceAddMappingRule(), Rule added, rule="<loopback_ip_address>:<port> => <loopback_ip_address>:<port>"
