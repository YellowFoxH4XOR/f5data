Description

Publishing an NGINX [Plus] configuration through the NGINX Instance Manager's Config ui fails with the following error message:

request body has an error: doesn't match the schema: Error at "/configFiles/files/568/contents": maximum string length is 3145728
Schema:
  {
    "description": "The base64 encoded contents of the files.",
    "maxLength": 3145728,
    "type": "string"
  }

Environment

NGINX Instance Manager

Cause

HTTP body size restriction

Recommended Actions

Upgrade to NGINX Instance Manager v2.20.0 or higher

Additional Information

In NGINX Instance Manager v2.20.0 or higher, NIM regulates HTTP body size with the NGINX directive client_max_body_size (default size is 50MB)

$ sudo grep client_max_body_size /etc/nginx/conf.d/nms-http.conf
client_max_body_size  50M; # Increase in case of large configuration files
