Description
During a stop/start of an AWS EC2 instance running the F5 BigIP Market Place AMI the appliance loses its license and stops working.

Environment
  • AWS EC2 instance is stopped and started

Cause
Bug ID 720001: Using custom default gateway in AWS makes instance metadata endpoint 169.254.169.254 inaccessible

Recommended Actions

Reload the license on system startup by running a script once the system is up:
  1. Make the startup file writable:
    chmod +w /config/startup
  2. Put add line to /config/startup to run a script:
    echo '/config/startup_script_reloadlic.sh &' >> /config/startup
  3. Create a file named /config/startup_script_reloadlic.sh that contains the following content:
    #!/bin/bash
    # Filename: /config/startup_script_reloadlic.sh
    export REMOTEUSER=root
    # Limit to 7 times in while-loop, i.e., 7 x 60 secs sleep = 7 mins.
    MAX_LOOP=7
    while true
    do
    MCPD_RUNNING=`ps aux | grep "/usr/bin/mcpd" | grep -v grep | wc -l`

    if [ "$MCPD_RUNNING" -eq 1 ]; then
    # Here you could perform customized command(s) after MCPD is found running when the BIG-IP system starts up.
    # Customized startup command(s) can be added below this line.

    # added for ID720001 to work around license issue
    logger -p local0.debug "MCP =1 , wait 60 sec before reloading license"
    sleep 60
    logger -p local0.debug "Running reloadlic from /config/startup"
    reloadlic
    # Customized startup command(s) should end above this line.
    exit
    fi

    # If MCPD is not ready yet, script sleep 60 seconds and check again.
    sleep 60

    # Safety check not to run this script in background beyond 7 mins (ie. 7 times in while-loop).
    if [ "$MAX_LOOP" -eq 1 ]; then
    echo "MCPD not started within 2 minutes. Exiting script."
    exit
    fi
    ((MAX_LOOP--))
    done
  4. Make the script executable:
    chmod +x /config/startup_script_reloadlic.sh
