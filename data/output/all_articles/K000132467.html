Description

This articles describes methods for checking accepted learning suggestions on ASM.

Environment

  • Learning suggestions

Cause

None.

Recommended Actions

There are two methods to check what suggestions were accepted by system administrators or policy builder. 

Method 1: Check it on Configuration Utility

a. Navigate to Security > Application Security > Policy Building > Traffic Learning

b. Select the correct asm policy in the dropdown list.

c. Open filter, and apply Status: Accepted / Accepted and Staged / Accepted Globally / Accepted on Microservice. 


Method 2: Using Rest API commands

a. To locate the security policy MD5 hash identifier, refer to K58082590.
b. Use the following command to return a detailed list of accepted suggestion(s):

# curl -sku <username:password> https://<BIG-IP hostname or IP address>/mgmt/tm/asm/policies/<MD5hash>/suggestions | jq '.items[] | select( .status | contains("accept"))'
