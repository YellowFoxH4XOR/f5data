K42286905: Configure DNS HTTPS monitor to support TLS1.2 only

Description
Configure DNS HTTPS monitor to support TLS 1.2 only.

Environment

  • GTM/DNS
  • HTTPS Monitor

Cause
None.

Recommended Actions

Configure the cipher of GTM/DNS HTTPS monitor similar to the below 
gtm monitor https tls-1_2-only {
    cipherlist DEFAULT:TLS1.2:!SSLv3
    compatibility enabled
    defaults-from https
    destination *:*
    interval 30
    probe-timeout 5
    recv none
    send "GET /"
    timeout 120
}
To check the support cipher list for DNS monitor, you could use the command below,

openssl ciphers -v 'DEFAULT:TLS1.2:!SSLv3'
