Known Issue

This is the result of a known issue. When a user accesses a website through a BIG-IP APM proxy with HTML code that places the <body> tag before the <html> tag, the content detection logic may incorrectly identify the HTML content as plain text. As a result, the BIG-IP APM will not correctly rewrite the website. The user is able to connect to the website, but the content of the website will fail to load correctly.

This issue occurs because the content detection logic looks for <html> tags to determine how to handle the content. If the <body> tag is above the <html> tag, the content detection logic does not process the content as expected.

F5 Product Development is tracking this issue as ID 350131.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP APM version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
