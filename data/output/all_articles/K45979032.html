Description

Nessus scanner shows presence of file /opt/.sdm/usr/local/www/waui/WEB-INF/lib/log4j-1.2.15.jar.

Environment

  • BIG-IP LTM
  • Provisioned Module 'iRules Language Extensions (iRulesLX)'
  • NESSUS scanner

Cause

Provisioning iRules Language Extensions (iRulesLX) will create the file /opt/.sdm/usr/local/www/waui/WEB-INF/lib/log4j-1.2.15.jar, thus alerting any Nessus scanners to flag for (CVE-2021-4104).

Recommended Actions

This file does not present any exploit of the BIG-IP, but to effectively remove the offending file, you must de-provision module iRules Language Extensions (iRulesLX) and reboot the BIG-IP to remove the offending file.

Note: De-provisioning the iRules Language Extentions (iRulesLX) module does not remove the /opt/.sdm directory.
