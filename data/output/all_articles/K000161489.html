K000161489: F5 CIS (Container Ingress Services) compatibility with Kubernetes releases

Type
Support Solution
Published
2026-09-02
Updated
2026-09-02
Applies to
  • F5 Automation and Orchestration
  • F5 BIG-IP Container Ingress Services
Source

Description

F5 Container Ingress Services (formerly known as Container Connector) compatibilty for current Kubernetes release.

Environment

New Kubernetes release with F5 CIS.

Cause

Informational.

Answer/Recommended Actions

F5 will support each new Kubernetes and OpenShift version within 6 weeks of their release.

For example:

CIS compatibility for Kubernetes 1.36 will be added in version 2.20.4.

Additional Information

None
