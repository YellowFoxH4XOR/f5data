Known Issue

SNMP statistics for BIG-IP APM connection counts may not increment.

This issue occurs when all of the following conditions are met:

  • You have configured your BIG-IP APM system with an access profile.
  • Access sessions are established with the access profile.
  • You use SNMP to query the BIG-IP APM system for any of the following OIDs for connection counts:
    • apmPcStatTotConns
    • apmPcStatCurConns
    • apmPcStatMaxConns
    • apmGlobalConnectivityStatTotConns
    • apmGlobalConnectivityStatCurConns
    • apmGlobalConnectivityStatMaxConns

Impact

The connection counters do not increment.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the values returned by the SNMP query, the connection counter values are always 0 (zero).
  • When you view connection counter statistics that the following TMOS Shell (tmsh) command returns, the related counters increment:

    tmsh show /apm license
