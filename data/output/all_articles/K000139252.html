Description

Steps to reboot the BIG-IP from Web GUI

 

Environment

  • Web GUI
  • BIG IP
  • Reboot

Cause

None

 

Recommended Actions

How to reboot the BIG-IP via Web GUI :

  1. Log in to the BIG-IP system Web GUI
  2. Select the System tab
  3. Select Configuration > Device > General
  4. Under Properties and Operations > Reboot



Figure: Screenshot of the Steps to Reboot the BIG-IP via Web GUI

 

Important: Traffic will be interrupted during the reboot. It is recommended to do this in a maintenance window.
