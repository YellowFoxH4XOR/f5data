Known Issue

This is the result of a known issue. When a user accesses a Rich Text Format (RTF) file using Internet Explorer (IE), IE presents the user with two options: Open or Save. If the user selects the Open option while in Protected Workspace, IE does not launch the appropriate external application to open the RTF file.

Instead of opening the RTF file, Internet Explorer 6 (IE6) reports an error message that appears similar to the following example:

The page cannot be displayed
 
Instead of opening the RTF file, Internet Explorer 7 (IE7) reports that the file cannot be opened and prompts the user to save the file.
 
F5 Networks Product Development is tracking this issue as CR71187. 
 
Workaround
 
Users can work around this issue by selecting the Save option instead of the  Open option when accessing an RTF file using IE in Protected Workspace. Once the document is saved to the client system, the user can manually open the document.
 
Users can also work around this issue by using an alternate browser, such as Firefox, to connect to the FirePass controller.
