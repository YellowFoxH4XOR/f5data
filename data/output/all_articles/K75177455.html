Description

Topology load balancing distributes DNS name resolution requests based on the proximity of the LDNS to the data center housing the resource that responds to the request. When Topology load balancing is enabled, the BIG-IP system uses topology records to make load balancing decisions. The following article provides and overview on how to force the traffic from a specific region to another data center.

Environment

  • BIG-IP DNS
  • You have already configured the Topology load balancing method for a wide IP
  • You wish to redirect DNS traffic from a specific region to another data center

Cause

None

Recommended Actions

The Topology mode bases the distribution of requests on the topology records and the weighted scores configured for each record. The topology records direct DNS queries to the most appropriate resources, based on geographical information.

In the event that you need to force traffic to another location, eg, for troubleshooting purposes, you can temporarily create a topology record with a higher weighting than existing records, as the matching topology record with the highest weighting will be selected. To do so, perform the following procedure:

  1. Log in to the Configuration utility.

  2. Navigate to DNS > GSLB > Topology > Records.

  3. Click Create

  4. On the Topology Record Builder page, select Region > is  > Region_to_modify from the Request Source menus.

  5. On the Topology Record Builder page, select Data Center > is > Desired_Data_Center from the Destination menus.

  6.  In the weight section, select a value greater than the old Topology record

  7. Click Create.
