Topic

This article applies to BIG-IP 11.x through 12.x. For information about other versions, refer to the following article:

  • K15923612: Configuring Route Health Injection for use with BGP (13.x - 15.x)
  • K6165: Configuring Route Health Injection (RHI) for use with BGP (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to configure Route Health Injection (RHI) for BIG-IP virtual server addresses. RHI allows the BIG-IP system to advertise routes for virtual server addresses by way of the Border Gateway Protocol (BGP).

Description

There may be occasions when you want the BIG-IP system to advertise routes for virtual server addresses by way of BGP. For example, if you want BGP to advertise virtual server addresses or withdraw the advertisements if the virtual server goes down, you should configure RHI for BIG-IP virtual server addresses. To do so, perform the following procedures.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • Your BIG-IP system is licensed to include the BGP routing protocol.
  • Your BIG-IP system is configured as a BGP peer with the upstream routers.

Procedures

  • Configuring route advertisement for the virtual server address using the Configuration utility
  • Configuring route advertisement for the virtual server address using the Traffic Management Shell (tmsh)
  • Configuring BGP to redistribute kernel routes
  • Verifying that the BIG-IP system is advertising the route by way of BGP

Configuring route advertisement for the virtual server address using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Virtual Servers > Virtual Address List.
  3. Select the virtual address for which you want to enable route advertisement.
  4. For Advertise Route, select the option you want.
  5. Select the Route Advertisement check box.
  6. Select Enable.

Configuring route advertisement for the virtual server address using the Traffic Management Shell (tmsh)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

  2. To enable route advertisement, use the following command syntax:

    modify ltm virtual-address <IP address> route-advertisement <value>

    For example, to enable route advertisement for virtual server address 192.168.10.100, type the following command:

    modify ltm virtual-address 192.168.10.100 route-advertisement enabled

  3. To save the configuration, enter the following command:

    save sys config

Configuring BGP to redistribute kernel routes

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: Static routes configured in TMM are also pushed to IMI as kernel routes. In a corner case where a destination subnet configured as a static TMM route overlaps with the injected RHI prefix, kernel redistribution results in a prefix being advertised disregarding the virtual address state.

  1. Log in to the BIG-IP command line.
  2. To access the IMI shell, enter the following command.

    imish

  3. To enter enable mode, enter the following command:

    enable

  4. To enter configuration mode, enter the following command:

    configure terminal

  5. To enable the BGP routing process, use the following command syntax, where <ID> is the router ID:

    router bgp <ID>

  6. To configure BGP to redistribute kernel routes, enter the following command:

    redistribute kernel

  7. Exit the current mode by entering the following command:

    end

  8. Save the configuration by entering the following command:

    copy running-config startup-config

  9. Log out of the IMI shell by entering the following command:

    exit

Verifying that the BIG-IP system is advertising the route by way of BGP

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To access the IMI shell, enter the following command.

    imish

  3. To enter enable mode, enter the following command:

    enable

  4. To display BGP routes that the system is advertising or learning, enter the following command:

    show ip bgp

    For example, the following output indicates that the BIG-IP system is advertising the 10.0.0.1 virtual server address by way of BGP:

    BGP table version is 1, local router ID is 10.0.0.2
    Status codes: s suppressed, d     damped, h history, * valid, > best, i - internal, l - labeled
    S Stale
    Origin codes: i - IGP, e - EGP, ? - incomplete

    Network Next Hop Metric LocPrf Weight Path
    *> 10.0.0.1/32 0.0.0.0 32768 ?
    *> 10.0.0.248/32 10.0.0.248 0 0 500 ?
