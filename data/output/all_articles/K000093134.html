K000093134: Uneven Load Balancing with the Round Robin method

Source

Description

  • After checking the current connections statistics for a pool configured with the Round Robin load balancing method, you are suspecting traffic reaching a pool to be unevenly distributed.
    Some pool members hold connections in TIME-WAIT State longer than other members of the pool.
  • Or one of the pool member went down.

Environment

  • BIG-IP LTM
  • Round Robin
  • Pool
  • Load balance

Cause

  • The current connections statistics are not a valid method to validate the Round Robin load balancing method if there are pool members holding connections in TIME-WAIT State longer than other members of the pool.
  • There can be long live connection to the pool member which are already up.

 Recommended Actions

  1. Calculate the total number of connections within a given period of time to confirm uneven load balancing.
  2. Verify if there are any pool members holding TCP connections in TIME-WAIT State longer than other members.
  3. Check other possible causes of uneven load balancing referring to K10430: Causes of Uneven Load balancing
