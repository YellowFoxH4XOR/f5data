K000135111: Identify which process made changes to specific file or directory

Type
Support Solution
Published
2023-06-23
Updated
2023-06-23
Source
https://my.f5.com/manage/s/article/K000135111

Description

Unknown process in the system made modifications to specific file or directory in the filesystem e.g. SELinux permissions were changed.
 

Environment

  • Big-IP filesystem
     

Cause

 

Big-IP doesn't log verbose information about file modifications so it's difficult to find out if some background process is misbehaving.
 

Recommended Actions

Enable system auditing with auditctl.

1) In order to enable auditing on file or directory e.g. /shared/GeoIP edit /etc/audit/rules.d/audit.rules file and add below line at the end:
-w /shared/GeoIP -p rwa -k f5tag

2) Restart auditd
# service auditd restart

3) Verify line with f5tag was added
# auditctl -l
-w /etc/selinux -p wa -k MAC-policy
-w /shared/GeoIP -p rwa -k f5tag

4) When you noticed unexpected activity on watched directory examine auditd logs:
# ausearch -k f5tag -i

5)  To disable auditing remove added line in /etc/audit/rules.d/audit.rules and restart auditd.
