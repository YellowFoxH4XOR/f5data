Description
By default,  the BIG-IP APM Network Access is configured to dynamically modify source ports when there is a conflict between the users source port, and the network's port availability for the IP being requested.   This is to ensure that the user will get a valid connection to the backend resource even if there's a port conflict.  

For certain traffic like SIP, RTP, and other "streaming" type services, Port changes can cause problems as the protocol requires the port to remain the same. 
 

Environment

  • BIG-IP APM
  • Network Access VPN Tunnel
  • Streaming type services displaying  some type of error like "source port changed"  or traffic failing

Cause
Default:  Network Access configuration sets "Preserve Source Port Strict" to disabled by default. 

Recommended Actions

  1.  Login to the BIG-IP APM Configuration utility (GUI)
  2. Navigate to  Access > Connectivity / VPN > Network Access (VPN) > <your Network Access Profile> 
  3. Navigate to the "Network Settings" Tab. 
  4. Enable "Preserve source port strict" checkbox.
  5. Save the Change.
  6. Apply your Access policy
