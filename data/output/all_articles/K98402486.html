Known Issue

Encrypting multiple cookies in a request using the HTTP::cookie iRule command may cause the bd process to exit and produce a core file.

This issue occurs when all of the following conditions are met:

  • The affected virtual server processes a request that contains multiple cookies.
  • The affected virtual server has an iRule that uses the HTTP::cookie command for encryption.
  • The resulted HTTP header size after cookie encryption is larger than 64k.

Impact

The bd process becomes unresponsive and traffic processing is frequently disrupted. A failover may occur if the BIG-IP ASM system is part of a high-availability (HA) group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The bd process frequently exits and produces core files in the /var/core directory.
  • The BIG-IP system generates a SIGSEGV fault and stack trace to the /var/log/bd.log file.
