Issue

Prior to FirePass 6.0.2, the Request client certificate during logon feature was a global setting configured on the Device Management: Security: Certificates page in the FirePass Administrative Console.

Starting in FirePass 6.0.2, you can configure individual SSL web services to request client certificates instead of enabling or disabling this feature globally. This enhancement provides FirePass administrators greater flexibility when configuring client certificate checks.

Important: The Request client certificate during logon drop-down menu on the Device Management: Security: Certificates page, which allows you to specify the client certificate field used for the logon username, remains a global setting.

F5 Product Development tracked this enhancement as CR48369 and it was included starting in FirePass 6.0.2. For information about upgrading, refer to the FirePass release notes.

Configuring the FirePass controller to request client certificates

  1. Log on to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Security.
  4. Click Certificates.
  5. Select the Request client certificate during logon check box.
  6. In the Request client certificate during logon menu, select the client certificate field you want to use for logon username.
  7. Click Update.
  8. Click Device Management.
  9. Click Configuration.
  10. Click Network Configuration.
  11. Click the Web Services tab.
  12. Click the Configure link next to the SSL web service you want to configure.
  13. Select the Request Client Certificate check box.

    Note: This option appears only if the web service already has SSL enabled.

  14. Click Update.
  15. Repeat steps 7 through 9 for each SSL web service you want to configure.
  16. Click the Finalize tab.
  17. Click Finalize Changes.
  18. Click Apply Changes and Restart.
  19. Click Restart.
