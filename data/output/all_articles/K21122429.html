Description

In BIG-IP ASM v14.0.0 or later, ASM removes 100th and next cookies when forwarding request to server.

Environment

  • BIG-IP ASM v14.0.0 or later
  • asm.strip_asm_cookies (sys db variable) is set to true - default

Cause

Number of processed cookies is limited max_enforced_cookies ASM system variable - default value is 100.

Recommended Actions

If your application requires more than 100 cookies, you can modify max_enforced_cookies variable using following procedure:

  1. Increase number of enforced cookies in CLI to for example 120:

    /usr/share/ts/bin/add_del_internal add max_enforced_cookies 120

    Note: Once you added the variable in the CLI, you can see it and change its value in the GUI at Security  ››  Options : Application Security : Advanced Configuration : System Variables.

  2. The ASM must be restarted to make the change take effect:

    tmsh restart sys service asm
