Environment

  • F5OS-A
  • F5OS-C
  • CDP/UDLD

Cause

Discards on the interface due to CDP/UDLD enabled on switchport.

These discards have no impact on application traffic on VLANs to the BIG-IP tenants.

Recommended Actions

  1. Check the configuration of the peer switch port and compare with the configuration of the port on the F5OS side if it has the correct VLAN details.
  2. Even after checking the configuration and still see the discards - monitor the interface discards on how frequent you see a drop and if you see a drop - what exact value does it increment by? You can check the discards by using the below command;
    # show interfaces | include in-discards | repeat 1
  3. If you observe increment of 1 drop at a regular interval, once every 15 - 30 secs. So this tells us that the switch is sending these packets over each port at regular interval.
  4. You will need to check if CDP/UDLD is enabled on the switchport.
  5. If yes, then you will need to disable, as F5OS does not support these protocols.
