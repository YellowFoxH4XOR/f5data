K000154652: DNS Zone Synchronization when zone serial numbers are different

Type
Knowledge
Published
2025-09-29
Updated
2025-10-02
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.1.1
Source
https://my.f5.com/manage/s/article/K000154652

Description

Mismatched SOA serial numbers for DNS zones may occur across devices if DNS zone file synchronization is not enabled. This happens when changes (such as adding or removing NS records, or updating SOA records) are performed on different devices at different times. The serial number in the SOA record increments based on local changes, which can lead to inconsistencies between devices. If DNS zone file synchronization is later enabled while serial numbers differ, there is a risk that the device with the highest serial number will overwrite configurations on other devices.

Environment

  • Product: BIG-IP DNS (GTM)
  • Multiple GTMs managing DNS zone files
  • Devices joined in a sync group with DNS zone file synchronization disabled

Cause

  • Each device independently maintains its own copy of the zone file and SOA serial number when DNS zone sync is disabled.
  • Changes made to zones increment only the local device’s serial number.
  • Serial numbers become unsynchronized if changes are made at different times or on different devices.
  • Enabling DNS zone file synchronization with mismatched serial numbers causes the configuration from the device with the highest serial number to overwrite others.

Recommended Actions

  1. Ensure Serial Number Consistency Before Sync:
    • Confirm that the device holding the most current and correct configuration has the highest SOA serial number for each zone before enabling DNS zone file synchronization.
    • Manually edit and align SOA serial numbers across all relevant devices if necessary.
  2. Managing Changes Without Zone Sync:
    • With DNS zone sync disabled, any change (e.g., adding/removing NS records or updating SOA) only updates that specific device’s SOA serial number.
    • To maintain consistency, replicate changes and manually synchronize SOA serial numbers across all devices.
