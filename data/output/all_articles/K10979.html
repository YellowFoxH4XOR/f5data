Known Issue

This is the result of a known issue. Macintosh 10.5.x clients running the Thursby DAVE version 7.1.2 software may experience an issue in which a directory tree is no longer visible when browsing the CIFS share using the finder.

F5 Product Development tracked this issue as ID 36643 and it was fixed in ARX versions 4.1.1, 5.0.6, and 5.1.0. For information about upgrading, refer to the ARX release notes.

Workaround

Navigate to a different folder and then navigate to the desired directory.
