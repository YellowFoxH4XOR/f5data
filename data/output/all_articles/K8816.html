Most settings in the FirePass Administrative Console are synchronized from the primary cluster node to the secondary cluster nodes. The following table lists page locations and configuration settings that are not synchronized between cluster members:

Page locationSectionSetting(s)
Device Management: Configuration: Clustering and FailoverAllAll
Device Management: Configuration: Network ConfigurationAllAll
Device Management: Configuration: SNMPAllAll
Device Management: Configuration: TimeAllAll
Device Management: Maintenance: Troubleshooting ToolsAllAll
Device Management: Maintenance: User Session LockoutAllAll
Device Management: Security: Console Access SecurityAllAll
Device Management: Security: IPsec ConfigurationAllAll
Device Management: CustomizationAdvanced CustomizationWebDAV Password
Device Management: CustomizationAdvanced CustomizationDefault language*
Device Management: CustomizationAdvanced CustomizationDefault order for full user name*
Device Management: Security: Admin Name and Password(Refer to the following note)All
Device Management: Configuration : RSA SecureIDAllAll
Network Access: Global SettingsAllAll
Users: Endpoint Security: Pre-Logon SequenceSelect Sequence to UseDeleted Pre-Logon sequences**

* These settings are synchronized starting in version 6.0.1 of FirePass software.

** Deleted pre-logon sequences are not automatically synchronized starting in FirePass version 6.0.3 with hotfix HF-603-5.1 installed

Note: If the Admin account password is different prior to clustering, the password will remain unsynchronized until it is manually changed to match across the devices, or until a full synchronization is manually initiated. To initiate a full sychronization, select the Force Full Sync link on the Clustering : Stats page on the primary (master) cluster node.

Settings that are not synchronized between cluster members must be configured separately on each cluster node.
