K000137497: How to change user profile name on MyF5 portal

Type
Support Solution
Published
2023-11-08
Updated
2025-08-28
Source
https://my.f5.com/manage/s/article/K000137497

Description

User needs to change their profile name displayed on MyF5 portal.
 

Environment

  • MyF5
  • User Profile Name

Cause

None

Recommended Actions

  1. After logging into MyF5 portal, at the upper right, select your profile name, and then select User Profile.

  2. Go to Manage preferences section, click on Manage security preferences.  It will redirect to page (https://profile.account.f5.com/profile) where you can edit and update the correct name.

  3. Click on Edit My Profile to make the changes.

 Figure: My Profile page

  1. Click Save.
  2. Logout from MyF5 portal and re-login for the changes to take effect.

Additional Information

None
