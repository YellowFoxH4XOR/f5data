K10553: Individual Web Application Allow Lists are applied to all Web Application favorites assigned to a user

Known Issue

This is the result of a known issue. If you configure an Allow List for an individual Portal Access Web Application favorite, the Allow List will be applied to all Web Application favorites assigned to a user. For example, if you configure the http://*.example.com/* Allow List  for a Web Application favorite, FirePass will allow all Web Application favorites assigned to the user to access http://*example.com/*.

F5 Networks Product Development is tracking this issue as CR84052.

Workaround

You can mitigate this issue by defining specific URLs for each Web Application Allow List and by avoiding wildcard characters when possible.

For example, change the Web Application Allow List from http://*.example.com/*  to the following code:

http://site1.example.com/app1/app.php
http://site2.example.com/app2/index.html
http://site3.example.com/app3/*

Important: Defining strict Web Application Allow Lists will minimize the impact of this issue, but these Allow Lists will still be shared by all Web Application favorites assigned to each user.
