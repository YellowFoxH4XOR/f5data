Topic

You should consider using this procedure under the following condition:

  • You want to enable fast-path acceleration for one or more Layer 7 (L7) distributed denial of service (DDoS) profiles.

Description

Starting in BIG-IP 13.1.0, you can configure performance acceleration for a L7 DDoS profile. To do so, you must configure the system to use a FastL4 profile as a performance enhancement for DDoS detection and mitigation. When enabled, this option combines Layer 4 (L4) and L7 options and adds performance for DDoS mitigation. During normal operation, the system processes most traffic using the fast-path acceleration mode. The system switches acceleration on and off automatically depending on traffic intensity. Once the system detects an attack, traffic flows switch to full-proxy mode.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have an L7 DDoS profile associated with your virtual server.
  • You have access to the Configuration utility.

Procedures

Creating a custom Fastl4 profile

You can associate the default Fastl4 profile with the DDoS profile, or create a custom Fastl4 profile to suit your environment. To create a custom Fastl4 profile that you can associate with the L7 DDoS profile, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > Fast L4.
  3. Click Create.
  4. Type a name for the Fastl4 profile.
  5. Define any custom settings that are appropriate for your environment.
  6. Click Finished.

Enabling performance acceleration for the L7 DDoS profile

To enable performance acceleration for the L7 DDoS profile, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > DoS Protection > DoS Profiles.
  3. Click the name of the DoS profile that is associated with your virtual server.
  4. Click the Application Security tab.
  5. Under Application Security > General Settings, make sure that Application Security is enabled by clicking Edit and selecting the Enabled check box.
  6. Click Edit next to Performance acceleration.
  7. From the drop-down menu, select the name of the Fastl4 profile that you created in the previous procedure.
  8. Click Update.
