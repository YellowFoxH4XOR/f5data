Topic

The BIG-IP system performs an Incremental IP checksum calculation compliant with RFC1141.

If the BIG-IP system receives a negative zero (0xffff) IP checksum, the BIG-IP system will accept the packet as having a valid IP checksum, and perform the 0xfff to 0 (0x0000) translation, compliant with RFC1624.
