Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator does not correctly handle TCP half-closed connections. As a result, the client data is not processed and the client receives an HTTP 204 (No Content) error message.

This behavior typically occurs when the BIG-IP WebAccelerator receives a TCP FIN packet immediately following the client's GET request.

F5 Product Development tracked this issue as CR86490, and it was fixed in BIG-IP WebAccelerator 9.4.4. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Additionally, Hotfix-BIG-IP-9.4.3-HF2 has been issued for BIG-IP 9.4.3. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
