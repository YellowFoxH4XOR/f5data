Description

  • TLS 1.3 handshake fails with RST Cause "SSL handshake timeout exceeded".
  • The client's TLS Client Hello message is acknowledged by the BIG-IP virtual server, but BIG-IP does not send a Server Hello message back.

Environment

  • The LTM virtual server contains a client-ssl profile that has TLS 1.3 enabled and configured in accordance with K10251520:  BIG-IP support for TLS 1.3

Cause

'TLS 1.3 resumed sessions' is not supported in TMOS 14.x. This functionality was introduced in TMOS 15.0.0.
 

Recommended Actions.

  1. If you need to support TLS 1.3 session resumption, update the BIG-IP system to TMOS 15.0.0 or newer.

Additional Information

You can determine if the client is attempting to resume a previous session, by reviewing the headers of the Client Hello message, in Wireshark. A resumed TLS 1.3 session will include the key_share extension.
