Known Issue

The Bandwidth Delay setting was not removed as a TCP profile option. The bandwidth delay logic was removed from TMM in BIG-IP 9.4.2; however, the setting was not removed from the Configuration utility or command line utilities as a TCP profile option.

Impact

You can safely ignore this issue.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Bandwidth Delay setting appears as a TCP profile option.
  • Changing the Bandwidth Delay setting has no effect.
