Topic

The BIG-IP APM Client Application Programming Interface (API) includes an API for third party applications as part of the Software Development Kit (SDK). This API allows you to create customized SSL VPN clients or provide seamless SSL VPN support to your existing in-house applications.

You must distribute the API F5fpAPI.dll and scew_uls.dll files to the client workstations for the SDK programs to run correctly. You can find these files in the FPSDK.zip, FirepassClientSDK.msi, or BIGIPComponentInstaller.msi files that are part of the BIG-IP APM Windows Edge Client package download, located through the BIG-IP APM Configuration utility Access Policy > Secure Connectivity page or Access > Connectivity / VPN > Connectivity > Client Downloads page. If your users are experiencing issues using programs made with the F5 SDK, have them confirm that the two .dll files are located in their C:\Program Files (x86)\F5 VPN directory. New installations of the BIG-IP Edge Client will include the two necessary files by default.

Note: For instructions about downloading the BIG-IP Edge Gateway client, refer to the Configuration Guide for BIG-IP Access Policy Manager.

Note: You can obtain the DLL files and associated scripts from the F5 Downloads page.

Note: Additionally you can locate the f5fpapi.dll and scew_uls.dll files through the FirePass Configuration utility: Device Management > Client Downloads section.
