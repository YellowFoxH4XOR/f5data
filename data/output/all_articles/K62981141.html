Description

The BIG-IQ restjavad property file allows you to optionally specify custom values for various application properties in order to overwrite corresponding F5-defined default values for those properties, which are hard-coded in the restjavad binaries. restjavad loads these application constants on startup, and they are applicable throughout the execution of the application. This is unlike the various values representing application state, which are stored in the database and which can be modified through REST calls.

The property file is organized hierarchically as follows:

  • module (for example, platform)
    • property group (for example, logger)
      • property (for example, maxMessageLength).
Prior to BIG-IQ 8.0.0, the default installation contains only the restjavad.properties.json file, which is pre-filled with all the default property values. This behavior makes it difficult to distinguish between the default values and the customized values configured for a BIG-IQ instance. Additionally, this behavior creates problems during upgrades because a newer BIG-IQ version may try to access newly added properties for which the default values are not defined in the file originating from earlier versions.

Starting in BIG-IQ 8.0.0, BIG-IQ ships with two instances of the property file, which are both deployed under the /var/config/rest/config/ directory:

  1. restjavad.properties.json is the active file used by a running BIG-IQ. It contains no property values on a newly installed BIG-IQ. All the default property values are defined in the restjavad binaries. However, restjavad.properties.json contains all of the existing modules and property groups. This way, although the file contains no custom properties, it provides the structure that allows customization according to your environment.
     
  2. restjavad.properties.defaults.json contains all of the existing default property values. A running BIG-IQ system does not use these values. Rather, the file is intended for informational use, so that users know which application properties exist and thus may be eventually overwritten and what the default values for these properties are.
The behavior related to the property files is as follows:
  1. During the initial BIG-IQ installation, both the restjavad.properties.json and restjavad.properties.defaults.json files deploy to the /var/config/rest/config directory.
     
  2. Upon upgrade, the system maintains the previously used restjavad.properties.json file, which is transferred to the new version, so customized values are preserved. Also, the system deploys the latest copy of the restjavad.properties.defaults.json file to the /var/config/rest/config directory.

Recommendations

The following table gives a summary of the added or preserved restjavad properties files by the type of BIG-IQ 8.0.0 or later installation.

Installation typeNew files addedExisting file preserved
New installationrestjavad.properties.json
restjavad.properties.defaults.json		Not applicable
Upgraderestjavad.properties.json.original
restjavad.properties.defaults.json		restjavad.properties.json

If the copy of the upgrade preserved restjavad.properties.json file is heavily customized from an older version of BIG-IQ, F5 recommends to review the new version's restjavad.properties.defaults.json file to understand the default settings configured in the newly upgraded BIG-IQ version.

If you are upgrading your BIG-IQ system from a version prior to BIG-IQ 8.0.0 to BIG-IQ 8.0.0 or later, F5 recommends you replace the restjavad.properties.json file from the earlier BIG-IQ version with the restjavad.properties.json.original file from the BIG-IQ 8.0.0 or later ISO file. After the upgrade completes, both files reside under the /var/config/rest/config/ directory. The file from the earlier BIG-IQ version is preserved as restjavad.properties.json. The file from the ISO is named restjavad.properties.json.original. To avoid unnecessary duplication and clutter, F5 recommends that you only add property values to the restjavad.properties.json.original that you want to differ from the defaults, rename this file restjavad.properties.json, and replace the file from the earlier version.
