Description

 

You want to check and verify the version of jQuery installed on your BIG-IQ due to Vulnerability Assessment Scan Report.

 

 

Environment

 

  • BIG-IQ
  • jQuery version

 

 

Cause

 

None

 

 

 

Recommended Actions

 

To check jQuery version on BIG-IQ, from bash run the command below:

 

# jq --version

 

 

In this example, the version of jQuery installed is 1.5

 

config #jq --version

jq-1.5

 

 

 

Additional Information

 

jQuery version may be updated with each new release of BIG-IP software.

Note: For other BIG-IP third-party software installed on your device, refer to the Related Content section.
