K000140623: [F5OS] - The built-in admin and root accounts cannot be locked - VELOS / rSeries

Type
Support Solution
Published
2024-08-08
Updated
2024-08-08
Applies to

  • F5OS-A: 1.7.X, 1.5.X, 1.7.0, 1.5.2, 1.5.1, 1.5.0
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000140623

Description

With the recent software versions of F5OS-A and F5OS-C, we can no longer lock the built-in "admin" and "root" accounts.

This is a consequences of implementing fixed for the bug IDs mentioned below.

When attempting to lock those accounts, you'll be prompted with the following messages:

  • GUI: Access denied. The operation is not permitted.
  • CLI: Error: access denied


Environment

  • F5OS
  • VELOS
  • rSeries

Cause

  • ID1486697
  • ID1397145

Recommended Actions

None: the built-in root and admin accounts can no longer be locked.

Additional Information

Bug ID 1486697: Configuring Expiry-status of root and admin user should not be allowed.

Bug ID 1397145: Unable to add blade to Openshift cluster, if VELOS partition root password is expired or locked
