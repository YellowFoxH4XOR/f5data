K13254130: Data Protection menu is missing with AWAF license

Type
Support Solution
Published
2021-04-13
Updated
2023-02-21
Applies to
  • BIG-IP FPS: 16.X.X
Source
https://my.f5.com/manage/s/article/K13254130

Description

Data Protection menu is missing with AWAF license.

Message displayed:

Fraud Protection Service is not licensed
This module will not be operational until licensed.

Environment

  • AWAF licensed

Cause

Bug ID 873617

Recommended Actions

Reset the FPS license keys to default and reload the configuration:

tmsh modify sys db license.antifraud.id reset-to-default
tmsh modify sys db license.antifraud.applicationencryption reset-to-default
tmsh modify sys db license.antifraud.automatictransactiondetection reset-to-default
tmsh modify sys db license.antifraud.malwaredetection reset-to-default
tmsh modify sys db license.antifraud.mobilesafe reset-to-default
tmsh modify sys db license.antifraud.phishingdetection reset-to-default
tmsh load sys config

Note: AWAF/DataSafe does not use these keys, and the issue can occur even without modifying these keys from the defaults (for example, after a reboot).
