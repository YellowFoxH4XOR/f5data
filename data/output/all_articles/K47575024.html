Description

System is in “unknown state” after upgrade

  • After upgrade and reboot the system does not load the configuration.
  • Roll back to the previous version resolves the issue
  • error:0906D06C:PEM routines:PEM_read_bio:no start line:pem_lib.c:697:Expecting: ANY PRIVATE KEY
     

Environment

  • Issue shows after upgrade or UCS restore
  • Base LTM configuration load
  • Running '/usr/bin/openssl rsa -noout -modulus -passin pass: -in /etc/httpd/conf/ssl.key/server.key' generates an error (may not apply)

Cause

This issue is caused due to a corrupt /etc/httpd/conf/ssl.key/server.key file. 
The file starts similar to the following;

MIIEp*******************************************P0O41SOLE0EqcFwscjVPXuL9nL4B7js
Oz41fgPtB1AlAQ3BEzCYyJOoPDGrZFda51LmXofUGzk/AVc5/BBoAHTaVgg3wgcu

But should be as follows;

-----BEGIN RSA PRIVATE KEY-----
MIIEp*******************************************P0O41SOLE0EqcFwscjVPXuL9nL4B7js
Oz41fgPtB1AlAQ3BEzCYyJOoPDGrZFda51LmXofUGzk/AVc5/BBoAHTaVgg3wgcu

Recommended Actions

Check the file /etc/httpd/conf/ssl.key/server.key first, if it is indeed missing the "-----BEGIN RSA PRIVATE KEY-----" at the top of the txt, please edit the file /etc/httpd/conf/ssl.key/server.key and add the line -----BEGIN RSA PRIVATE KEY-----
then try to reload the config again.
