Known Issue

This is the result of a known issue. The qkview utility may hang when run from the command line on systems with large configurations, such as a large wideip.conf file. This issue occurs for larger configurations because qkview executes certain tmsh shell commands, which default to interactive mode when listing a large number of configuration objects. As a result, qkview will hang when the object count for one of the commands is greater than 100.

This issue is known to occur with larger BIG-IP GTM or BIG-IP Link Controller configurations because the qkview script calls the following BIG-IP GTM-related tmsh commands:

tmsh show gtm datacenter detail
tmsh show gtm distributed-application
tmsh show gtm wideip detail
tmsh show gtm iquery
tmsh show gtm rule
tmsh show gtm traffic

For example, when qkview executes the tmsh show gtm wideip detail command and the object count for the command exceeds 100, qkview hangs because the tmsh command requires a user to select a keyboard option.

Note: The interactive prompt does not display on the system console since qkview calls the tmsh command. However, if the tmsh command (with an object count greater than 100) were run by itself at the command line, a prompt that appears similar to the following example will display:

# tmsh show gtm wideip detail
Display all 753 items? (y/n)

F5 Product Development tracked this issue as CR122194 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

Workaround

You can work around this issue by increasing the tmsh display-threshold from 100 to a greater number, such as 1,000. This configuration changes the tmsh shell to enter interactive mode when listing 1,000 configuration objects. To increase the tmsh display-threshold to 1,000, enter the following command:

tmsh set cli preference display-threshold 1000

Note: Using ctrl+C or the kill command to terminate qkview while it is not responding may leave orphaned processes. For more information, refer to K10724: Using the ctrl+C key combination to terminate qkview leaves orphaned processes.
