Description

This article provides the SNMP OID for calculating the BIG-IP's disk partition size.

Environment

  • BIG-IP
  • SNMP

Cause

None

Recommended Actions

The partition size can be calculated with the following three oids:
 

F5-BIGIP-SYSTEM-MIB::sysHostDiskBlockSize
F5-BIGIP-SYSTEM-MIB::sysHostDiskTotalBlocks
F5-BIGIP-SYSTEM-MIB::sysHostDiskFreeBlocks


sysHostDiskTotalBlocks is the number of total disk block for a specific partition and sysHostDiskBlockSize is the size of each block in this partition, sysHostDiskFreeBlocks is the number of free disk block for a specific partition

For example: "/shared" partition has 5160607 disk blocks and each block size is 4096 bytes. The partition size of "/shared" is 5160607 * 4096 = 21,137,846,272 bytes, the free partition size of "/shared"  is 2011706*4096=8,239,947,776bytes
