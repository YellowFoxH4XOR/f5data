K000137651: A Security End-of-Life (SEoL) version of Apache Struts is installed

Type
Support Solution
Published
2023-11-22
Updated
2023-11-22
Source
https://my.f5.com/manage/s/article/K000137651

Description

Security Scanners, for example Nessus with plugin 182281 or 182224, raise an alert for a Security End of Life (SEoL) version of Apache Struts installed in F5 some F5 products (e.g., BIG-IP and BIG-IQ), or for an Unsupported Version (nessus plugin 117461)

Environment

  • BIG-IP (all versions)
  • BIG-IQ (all versions)

Cause

Apache Struts is installed. BIG-IP used Apache Struts internally in the Configuration Utility for BIG-IP AAM, BIG-IQ does not expose Apache Struts but does have it installed. When BIG-IP AAM is not provisioned, Apache Struts is not used; note that BIG-IP AAM has now reached EoSD (see K70113407 )

Recommended Actions

  • None, see Additional Information

Additional Information

Scanners such as Nessus will raise alerts when third party components (such as Apache Struts) reach their End of Life and are no longer supported by the original vendor, because the vendor ceases to offer security updates at that time.

F5 products, however, are not general purpose computing platforms and support and security fixes for the entire product are the responsibility of F5, Inc. As such, even when a third party component reaches EoL, F5 will continue to investigate the impact of any disclosed CVE regardless of whether it was disclosed in the version running on the F5 product or a later version and regardless of the support status of the third-party package with the vendor.

If a vulnerability does impact an F5 product, F5 reviews it for technical severity using the CVSS score and then prioritizes fixes based on the risk posed to the security of the platform. To maintain the system stability and compatibility with the other software installed on BIG-IP system, minor revisions will sometimes need customized patching instead of rebasing software packages to a new version. This practice is like that of Redhat's.

See the "Third-party software components" section of K4602 for more information.
