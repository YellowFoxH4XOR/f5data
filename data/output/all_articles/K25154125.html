K25154125: webd restarting, unknown directive in /etc/webd/webd.conf

Applies to

  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K25154125

Description

When following K31401771 to restrict access to the BIG-IQ, the following error was noted in the SSH console of the BIG-IQ CM:

Jan 18 11:28:25 mybigiq emerg logger: Re-starting webd
2022/01/18 11:28:25 [emerg] 17454#0: unknown directive "192.168.1.0/24" in /etc/webd/webd.conf:179

Environment

  • User had modified /etc/webd/webd.conf by following an F5 knowledge article such as  K31401771
  • The webd process had been restarted for the settings to take effect

Cause

Incorrect configuration syntax as show below:
<...>
location /ui {
  192.168.1.0/24;                         <<<<< keyword allow missing 
  deny all;
<...>

Recommended Actions

The following configuration is representative of correct syntax:

<...>
location /ui {
  allow 192.168.1.0/24;                   <<<<< keyword allow inserted 
  deny all;
<...>
