Known Issue

The BIG-IP Edge Client is unable to download proxy auto-config (.pac) files.

This issue occurs when all of the following conditions are met:

  • Your Network Access profile specifies a client proxy auto-configuration script URL for the .pac file.
  • The user's device proxy configuration points to a .pac file.
  • The .pac file URI uses mixed case or upper case.
  • The server providing the .pac file is URI case sensitive.
  • You attempt to establish an access session with the Network Access profile.

Impact

The access session fails to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system logs messages similar to the following in the BIG-IP Edge Client log:

     2220,2820,DIALER, 1, , 757, WritePACFileFromURL, Failed to connect for downloading a PAC file (URL: http://10.0.0.10/ieconfig/<proxy file name>.pac)
     2220,2820,DIALER, 48, , 922, WritePACFileFromURL2, try loading remote PAC file
     2220,2820,DIALER, 2, \m_sys.cpp, 388, ::FlushDNS, Failed to open DNScache service (error: 5)
     2220,3232,DIALER, 1, \URLConnect.cpp, 684, URLConnect::BeginConnection, HttpSendRequest failed with HTTP 404.
     2220,2820,DIALER, 1, , 757, WritePACFileFromURL, Failed to connect for downloading a PAC file (URL: http://10.0.0.10/ieconfig/<proxy file name>.pac)
     2220,2820,DIALER, 48, , 922, WritePACFileFromURL2, try loading remote PAC file
     2220,2820,DIALER, 2, \m_sys.cpp, 388, ::FlushDNS, Failed to open DNScache service (error: 5)
     2220,3236,DIALER, 1, \URLConnect.cpp, 684, URLConnect::BeginConnection, HttpSendRequest failed with HTTP 404.

  • When you analyze the request from the BIG-IP Edge Client to the .pac file, the URI request is all lower case, and the destination server responds with a HTTP 404 status code (Not Found).

Resolution

Status

F5 Product Development has assigned ID 625376 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can ensure that you configure the destination .pac file server to accept the .pac file URI request in all lower case. 

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
