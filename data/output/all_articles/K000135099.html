K000135099: Workaround to enable local time zone in restjavad-audit.log remote syslog logs for v12.X

Type
Support Solution
Published
2023-06-23
Updated
2023-06-23
Source
https://my.f5.com/manage/s/article/K000135099

Description

restjavad-audit logs in BigIP version 12 are sent with UTC timezone to remote syslog server.
In version 15 logs are sent with local timezone.
 

Environment

  • restjavad-audit logs enabled
  • logs sent to remote syslog server
 

Cause

Software version difference
 

Recommended Actions

V12.X reached EoSD so in order to send local timezone information with restjavad-audit logs to remote syslog server workaround is required. 

It's possible to affect timezone by changing log format from BSD to ISO. Follow below article to change iso-date:

K55725230: How to change the local syslog timestamp format
https://my.f5.com/manage/s/article/K55725230

"Note: Alternatively you can modify the configuration line iso-date disabled to iso-date enabled."

Please be aware that above change will cause local device logs to change format as well:

/var/log/ltm:
Jun 24 05:39:51 pungent-1-bigip info root: test                     <<<=== BSD format
2022-06-28T00:19:46.008-07:00 pungent-1-bigip notice root: test     <<<=== ISO format
