Topic

To reset the statistics on a 3-DNS versions 3.0 and later, type the following command:

Warning: The following commands will also clear all of the path statistics used by dynamic load balancing.

3ndc restart

To reset the statistics on a 3-DNS version prior to 3.0, use one if the following commands:

  • If the 3-DNS is a member of a redundant pair, type ndc restart.
  • If the 3-DNS is not a member of a redundant pair, type 3ndc restart.

This command restarts the 3-DNS engine with zero values for all statistics.
