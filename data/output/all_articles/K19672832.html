Description

Health monitor on a pool has been switched from default https monitor, to a custom https monitor (for example with send string "GET /teststring.txt").

Pool is reachable and shows UP. However, the backend server still gets http requests with the default monitor send string "GET /" from BIG-IP Self-IP.

Environment

  • Health monitor changed on a pool
  • Configuration not taking effect

Cause

The new configuration is not loading or taking effect possibly due to a configuration corruption.

Recommended Actions

To workaround the issue, perform an MCPD reload of the unit. This will help reload the configuration again, and you should see the new monitor sending the correct new monitor send string, example: "GET /teststring.txt".

K13030: Forcing the mcpd process to reload the BIG-IP configuration
