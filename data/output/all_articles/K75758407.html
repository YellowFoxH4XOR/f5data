Description

The password (-p) flag no longer exists when using the smbget utility for SMB EAV monitors in version 14.x and later.

Environment

  • BIG-IP LTM
  • SMB EAV Monitor
  • smbget utility

Cause

  1. The following smbget command in versions 14.x and later is not working and cause to mark the pool member as down when using SMB EAV monitor. 
# smbget -u <username> -p <password> --nonprompt --quiet --stdout smb://<Server_IP_Address>/F5/<File_Name>.txt | grep "ONLINE"

Example:

# smbget -u F5Monitor -p f5.12345 --nonprompt --quiet --stdout smb://10.10.10.1/F5/F5_SMB_Monitor.txt | grep "ONLINE"
ONLINE

  1. In versions 13.x and earlier the password (-p) flag is available when using the smbget utility.

Recommended Actions

If you need to use the smbget command described above in a BIG-IP LTM running version 14.x or later perform the following workaround to make it work. 

# smbget -U <username>%<password> --nonprompt --quiet --stdout smb://<Server_IP_Address>/F5/<File_Name>.txt | grep "ONLINE"
 

Example:

# smbget -U F5Monitor%f5.12345 --nonprompt --quiet --stdout smb://10.10.10.1/F5/F5_SMB_Monitor.txt | grep "ONLINE"
ONLINE
