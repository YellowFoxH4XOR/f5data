Known Issue

This is the result of a known issue. If you enable the Mac OS X Check Files inspector or the Linux Check Files inspector in a pre-logon sequence, Mac OS X and Linux clients may not complete the pre-logon sequence. When this issue occurs, the client browser displays the Checking files pre-logon prompt indefinitely, and never proceeds to the next action in the pre-logon sequence.

This issue occurs when the following two conditions are met:

  • You configured the Mac OS X or Linux Check File inspector to verify the MD5 checksum and/or file size for one or more files
  • The FirePass controller returns chunked XML data to the client-side component

F5 Networks Product Development tracked this issue as CR97452 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-601-11 has been issued for FirePass version 6.0.1 and Cumulative Hotfix HF-602-5 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the Cumulative Hotfixes from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by removing the MD5 checksum and file size checks from the Mac OS X and Linux Check File inspectors. To do so, perform the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. Next to the active pre-logon sequence, click the backup & edit link.
  4. Click the Check Files (Linux) action box, if configured.
  5. In the Edit Action window, click the Gets information about file on Linux link.
  6. In the Endpoint Inspector Details window, clear all MD5 and File size text fields.
  7. Click the Update button.
  8. Click the Close Panel link at the top right corner of the Edit Action window.
  9. Click the Check Files (Mac OS X) action box, if configured.
  10. In the Edit Action window, click the Gets information about file on Mac OS X link.
  11. In the Endpoint Inspector Details window, clear all MD5 and File size text fields.
  12. Click the Update button.
  13. Click the Back to console link in the top right corner of the page.
