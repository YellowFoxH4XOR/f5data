Known Issue

Users are unable to establish access sessions for network access or app tunnel profiles.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM virtual server is configured with a network access or app tunnel profile.
  • The virtual server is configured with a DoS protection profile.
  • Users attempt to establish an access session with the access profile.

Impact

Users are unable to establish the access session.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After the user authenticates to the access profile, the access session fails to establish.
  • The system logs a message similar to the following example to the /var/log/ltm file at the time of the event:

    err tmm2[32618]: 01470000:3: iSession: Connection error: isession_handle_syn:3641: No peer:4
    err tmm2[32618]: 01230140:3: RST sent from <virtual server ip address:port> to <user ip address:port>, [0x2635a6e:359] iSession error (err: isession_handle_syn:3641, No peer, ERR_ARG)

  • The system logs a message similar to the following example on the user device at the time of the event:

    964,3704,HOST, 1, \HostCtrl.h, 1461, CHostCtrl::Failed, Couldn't open proxy server (error: 0)
