Known Issue

The Master Control Program Daemon (MCPD) may restart and produce a core file during a DNS cache query.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured with a DNS cache.
  • The BIG-IP DNS cache contains a DNS record with an unrecognized record type.
  • The BIG-IP system subsequently receives a DNS query for the unrecognized DNS record.

Impact

The BIG-IP system may temporarily fail to process traffic, and may fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates an mcpd core file to the /shared/core directory.
  • The BIG-IP system fails over if configured for high availability (HA).
