Topic

The End-User Diagnostics (EUD) software is a set of diagnostic tests that provides reports about various components in the hardware unit. F5 updates the EUD software regularly and recommends that you install the latest version prior to running the EUD.

Note: In BIG-IP 13.0.0 and later, F5 no longer includes the EUD images in the base .iso image file. You must either install the latest EUD package from a BIG-IP-x.y.z.n.n.nnn-RECOVERY.iso image or download the EUD image of your specific platform from the Platform / EUD product page of the F5 Downloads site. For more information, refer to K03203114: Multiple BIG-IP iso images are available (13.x and later).

To determine the EUD version on the BIG-IP system, perform the following procedure:

  1. Log into the BIG-IP Advanced Shell (bash).
  2. Enter the following command:

    eud_info

If you are logged into the tmsh shell as a user with the admin role, you can temporarily enter into the advanced shell by entering the command:

run /util bash

Followed by the command:

eud_info
