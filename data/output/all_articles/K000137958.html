Description

You want to configure an advance external SMTP monitor


Environment

BIGIP


Cause

You want to configure an advance external SMTP monitor that provides more flexibility in the monitor's query


Recommended Actions

Using a text editor create a script file (shell / Perl, Python, etc.) that will perform the SMTP query, e.g:

#!/bin/sh

ncat ${node_ip} ${port} < ${input_file} | grep ${RECV}

 

In addition you will need to create an input text file for the script, e.g:

EHLO hostname

MAIL FROM: sender@example.com

RCPT TO:  recepient@example.com

DATA

From: Sender <sender@example.com>

To: Recipient <recepient@example.com>

Date: date

Subject: A test message from hostname

This is a test

.

QUIT

 

Note:

The script’s return value is 0 when the command’s response is true (having the string PIPELINING as an output) and 1 if it is false. The script is expecting to have the string PIPELINING in the response and base on this to determine if the query succeeded or not.

e.g:

# nc 192.168.80.27 25 < mail.txt | grep PIPELINING

250-PIPELINING

# echo $?

0

# nc 192.168.80.27 25 < mail.txt | grep example  

# echo $?

1


Upload the script and the SMTP input files to the ltm:

System ›› File Management : External Monitor Program File List

Click on Import and import the script file to the BIG-IP

Note:

In case that you need to modify/update the script, you should do it from the same location on the bigip

 

Associate the script and the with the monitor:

Created External monitor (type External)

In the External Program choose the script that you uploaded

Create Variables matching the variables that are in the script (node_ip, port, input_file, RECV) and add values:

The rest of the settings should be configured the same way that you are configuring a monitor

Associate the monitor with a pool
