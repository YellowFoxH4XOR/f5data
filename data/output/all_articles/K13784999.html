Description

After removing Global Traffic (DNS) or Global Traffic (GTM) module from the Resource Provisioning you will not be able to access the GUI (web console / Configuration Terminal).

If this device is in a HA pair, the peer device which still has the DNS/GTM provision is still able to access GUI.

java.lang.OutOfMemoryError error message seen in /var/log/tomcat/catalina.out file.

Environment

  • BIG-IP
  • No GUI access after removing Global Traffic (DNS) or Global Traffic (GTM) module from Resource Provisioning
  • GUI working when DNS/GTM module is provisioned
  • java.lang.OutOfMemoryError is seen in /var/log/tomcat/catalina.out file.

Cause

When DNS/GTM is provisioned on a BIG-IP device, it will allocate more memory to the management to process iQuery traffic.

When DNS/GTM module is removed, memory allocation for management is reduced thus might case GUI access issue.

Recommended Actions

You will need to allocate more memory to tomcat.

  1. Refer to article K9719 for the complete guide.
     
  2. Set the provision.tomcat.extramb database variable to the desired amount of additional memory to be allocated using the following command:

    modify /sys db provision.tomcat.extramb value <MB>

    In this command, note the following:

    For example, to allocate an additional 50 MB of additional memory, enter the following command:

    modify /sys db provision.tomcat.extramb value 50

    Note: F5 recommends an initial value of 50 MB, assuming the device has enough Other memory free (Important: Check output of free before continuing to confirm the device has enough usable memory available), but it may not resolve all instances of the error message. If the java.lang.OutOfMemoryError errors continue, you can repeat this procedure, increasing the value by 50 MB each time until you no longer encounter the error message. If this value goes above 1GB and you still experience the same error, open a support case with F5 Support before continuing.
     
  3. Restart the tomcat process by entering the following command:

    restart /sys service tomcat

  4. Increase provision.tomcat.extramb as needed.
