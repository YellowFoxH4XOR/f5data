Known Issue

This is the result of a known issue. When cookie persistence is configured for a BIG-IP LTM virtual server that references the BIG-IP ASM module, cookie persistence works only for the first persistent request on the connection. The second and subsequent requests on the connection receive a cookie with the internal IP address of the BIG-IP ASM daemon.

F5 Product Development tracked this issue as CR70409, CR70615, and CR70701 and it was fixed in version 9.2.4. For information about upgrading, refer to the BIG-IP ASM or LTM Release Notes.
