Known Issue

Custom health monitor syntax may trigger a configuration load failure.

This issue occurs when all of the following conditions are met:

  • You create a custom health monitor.
  • You enter the send or receive text values of the health monitor using cut-and-paste or copy-and-paste functionality.
  • The text includes a tab.
  • You attempt to load the system configuration.

Impact

The configuration fails to load and produces an error.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to load the system configuration, the system displays an error similar to the following example:

    Syntax Error:(/config/bigip.conf at line: <line number>) "<monitor text>" unknown property

Resolution

Status

Workaround

To work around this issue, you can use the Configuration utility or the Traffic Management Shell (tmsh) to modify the affected health monitor send or receive text, by replacing the tab text definition with \t to represent the tab. 

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
