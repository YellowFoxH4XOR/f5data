Known Issue

A Request Logging Profile may erroneously log an HTTP 200 response code.

This issue occurs when all of the following conditions are met:

  • A Request Logging Profile with request logging enabled is configured on a Virtual Server.
  • The Virtual Server receives an HTTP request.

Impact

This issue results in misleading messages in request logs. You can safely ignore these messages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • An HTTP 200 response code appears in a request log message, similar to the following example:

    10.1.1.1 - - [21/Nov/2014:11:35:41 -0800] "GET /test HTTP/1.1" 200 0 "-" "curl/7.19.7 (x86_64-unknown-linux-gnu) libcurl/7.19.7 NSS/3.12.6.2 zlib/1.2.3 libidn/1.18 libssh2/1.2.2" "-", 50, #015#0120,#015#012 , 10.1.1.2, 80
