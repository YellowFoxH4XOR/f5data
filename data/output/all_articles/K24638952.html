Description

You want to poll the F5 using SNMP for a specific OID numeric or string values

Environment

  • SNMP Server v1, v2c, v3
  • BIG-IP

Cause

You want to test if SNMP polling is returning the right value

Recommended Actions

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Print out any string or numeric OIDs using snmpwalk, use the following command syntax:

    Using Name format
    snmpwalk -v 2c -c <community string> <f5_hostname or IP_address> <OID variable string value>

    Using OID format
    snmpwalk -v 2c -c <community string> <f5_hostname or IP_address> <OID numeric value>

    Example:
    Using Name format
    # snmpwalk -v 2c -c public 10.10.10.1 F5-BIGIP-LOCAL-MIB::ltmPoolMemberStatServerCurConns
    Using OID format
    # snmpwalk -v 2c -c public 10.10.10.1 .1.3.6.1.4.1.3375.2.2.5.4.3.1.11

Additional Information

Printing all of the object OID pairs in a particular MIB file

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

1. Log in to the command line.
2. To print out all of the object OID pairs in a particular MIB file, use the following command syntax:
# snmptranslate -On -Tz -m <path to MIB file>

For example:

# snmptranslate -On -Tz -m /usr/share/snmp/mibs/F5-BIGIP-COMMON-MIB.txt
