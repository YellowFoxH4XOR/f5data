Description
BIG-IP GTM pool marked down with "no nodes up" error

•  Error: 'No nodes up'

Environment

• BIG-IP GTM/DNS
• iQuery
• BIG-IP monitor

Cause
The gtmd process appears to have cached the incorrect ltm_name in the iQuery communication.    
 

Recommended Actions
You may need to manually reconfigure the GTM/DNS virtual server object to include the correct 'ltm-name':           

  1. Log in to TMOS shell (tmsh) by typing the following command:
        tmsh
  2. Run the following command:
        modify gtm server <GTM-Server1> virtual-servers modify { <LTM-virtual-server1> { ltm-name <LTM-actual-virtual-server-name> } }

In the example above "GTM-Server1" is the Server object on the GTM/DNS, "Ltm-virtual-server1" is the virtual server listing under that GTM/DNS Server name, and "LTM-actual-virtual-server-name" is the virtual server name actually listed on the LTM configuration
