Topic

You should consider using this procedure under the following condition:

  • You need to determine the version of the F5 Declarative Onboarding (DO) running on your BIG-IP system.
  • You need to determine the version of the F5 Application Services 3 Extension (AS3) running on your BIG-IP system.

Description

You can use the BIG-IP Configuration utility, the TMOS Shell (tmsh), or the BIG-IP iControl REST API to display the AS3 and DO versions running on your BIG-IP system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Configuration utility, tmsh, or the iControl REST API.
  • If you are accessing the iControl REST API from a remote workstation, ensure you have the curl and jq utilities installed on the remote workstation. These utilities are commonly available on Linux systems but can also be installed on Microsoft Windows and Mac OS X systems. For more information about the jq utility, refer to https://stedolan.github.io/jq. Alternatively, you can access the iControl REST API from the BIG-IP command line as the root user.

Procedures

  • Display the DO version running on your BIG-IP system
  • Display the AS3 version running on your BIG-IP system

Display the DO version running on your BIG-IP system

To find the DO version running on your BIG-IP system, perform one of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Use the Configuration utility
  • Use tmsh
  • Use the iControl REST API

Use the Configuration utility

  1. Log in to the BIG-IP Configuration utility as the administrative user.
  2. Go to iApps > Package Management LX.
  3. Locate the f5-declarative-onboarding package; the DO version displays in the Version column next to this package.

Use tmsh 

  1. Log in to tmsh.
  2. Display the iApp packages installed on your BIG-IP system by entering the following command:

    list /mgmt shared iapp installed-packages

  3. Locate the package stanza with the appName f5-declarative-onboarding from the output; the DO version displays in the version field similar to the following example:

    mgmt shared iapp installed-packages 316c0f71-a1d2-3fbc-a04c-26c8b3262e1e {
        appName "f5-declarative-onboarding"
        arch "noarch"
        generation 2
        id "316c0f71-a1d2-3fbc-a04c-26c8b3262e1e"
        kind "shared:iapp:installed-packages:installedpackagestate"
        lastUpdateMicros 1660853744874005
        packageName "f5-declarative-onboarding-1.31.0-6.noarch"
        release "6"
        selfLink "https://localhost/mgmt/shared/iapp/installed-packages/316c0f71-a1d2-3fbc-a04c-26c8b3262e1e"
        status "READY"
        tags {
            "PLUGIN"
        }
        version "1.31.0"
    }

Use the iControl REST API

  1. Log in to the command line of the remote workstation that has the curl and jq utilities installed. Alternatively, you can log in to the BIG-IP command line as the root user.
  2. Display the DO version running on your BIG-IP system using the following command syntax:

    curl -sku <username:password> -H "Content-Type: application/json" -X GET https://<BIG-IP hostname or mgmt IP address>/mgmt/shared/declarative-onboarding/info | jq .

    For example, you would enter the following command from the BIG-IP command line using the admin user credentials:

    curl -sku admin:admin -H "Content-Type: appication/json" -X GET https://localhost/mgmt/shared/declarative-onboarding/info | jq .

    The command should return an output similar to the following example:

    [
      {
        "id": 0,
        "selfLink": "https://localhost/mgmt/shared/declarative-onboarding/info",
        "result": {
          "class": "Result",
          "code": 200,
          "status": "OK",
          "message": "",
          "errors": []
        },
        "version": "1.31.0",
        "release": "6",
        "schemaCurrent": "1.31.0",
        "schemaMinimum": "1.0.0"
      }
    ]
