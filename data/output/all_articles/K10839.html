Known Issue

This is the result of a known issue. If a user launches a Dynamic Application Tunnel (App Tunnel) using Firefox, and the Dynamic App Tunnel client component has not previously been installed, the App Tunnel fails to establish with the following error message:

Status: Failed to update browser components

Additionally, for FirePass 6.0.3 and 6.1.0, the following line also appears in the error message:

Click here to download and install required browser components manually.

Note: Web Application Tunnels are a type of Dynamic App Tunnel; therefore, they are also affected by this issue.

F5 Product Development tracked this issue as CR75312 and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.

Workaround

For FirePass 6.0.3 and 6.1.0, users can work around this issue by clicking the Click here link in the error message to install the required client component.

For FirePass 6.0.0 through 6.0.2, users can work around this issue by initially launching the Dynamic App Tunnel using Internet Explorer (IE). Once the client component is installed by IE, users can then launch the Dynamic App Tunnel using Firefox.

Alternately, administrators can work around this issue by pre-installing the FirePass Application Tunnels component on client systems. You can download this component on the Device Management: Client Downloads page in the FirePass Administrative Console.
