Description

When you want to check system logs for auditing or troubleshooting purposes, you realize that there are no logs at all both locally and on remote syslog servers.

  • Modifying, creating, deleting BIG-IP configurations does not have audit logs generated
  • No error logs in ltm/gtm for troubleshooting purposes
  • Restarting syslog-ng daemon does not help
  • If there is remote syslog server configured, there is no logs on syslog server as well
  • In Configuration Utility, navigate to System  ››  Logs : Configuration : Options and check Local Traffic Logging, Global Traffic Logging and Audit Logging, they are all set to default value.

Environment

  • BIG-IP
  • syslog-ng

Cause

The cause of this issue is unclear at the publication date of this article.

Recommended Actions

We recommend customer to rebuild mcpd following K13030:  Forcing the mcpd process to reload the BIG-IP configuration
If issue persists after force loading mcpd, please open a support case with F5 Support for further analysis.
