Known Issue

A pool member may remain disabled after an incremental synchronization.

This issue occurs when all of the following conditions are met:

  • The configuration consists of a pool resource with the health monitor enabled.
  • The BIG-IP system is configured as a member of a device group.
  • Actions occur in the following order:

    • A user changes a pool member's state to disabled or force offline.
    • The source device (either automatically or manually) initiates a configuration synchronization (ConfigSync).
    • A user changes the pool member's state to enabled.
    • The source device performs an incremental synchronization.

Note: Starting with BIG-IP 11.4.0, you can set the device group to automatically synchronize, with either an incremental synchronization or a full synchronization. For more information, refer to the Managing Configuration Synchronization chapter in the BIG-IP Device Service Clustering: Administration manual.

Impact

The target devices in the device group may not have the same configuration as the source device that initiated the incremental synchronization.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The affected pool member remains disabled on the target devices in the device group, while the source device has the affected pool member state set to enabled.
  • The configuration between the source device and the target devices in the device group is not synchronized.

Workaround

To work around this issue, you can perform a full load synchronization from the source device. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on the system initiating the synchronization. However, the full configuration sent to the target devices will cause a configuration reload.

  1. Log in to the Configuration utility of the source BIG-IP system.
  2. Click Device Management.
  3. Click Overview.
  4. Select the source device to perform the full load configuration synchronization.
  5. Select the Sync Device to Group option.
  6. Select the Overwrite Configuration check box.
  7. Click Sync.
