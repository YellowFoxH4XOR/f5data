Known Issue

This is the result of a known issue. The BIG-IP ASM asmqkview script used to gather BIG-IP ASM information for troubleshooting purposes omits the hostname of the system within the snapshots file name.

Note: For more information, refer to K6824: Overview of the asmqkview script.

After the asmqkview script gathers the necessary information, it writes the information to a file in the /var/tmp directory. The askmqkview script uses the following file name syntax, where <hostname> is the hostname of the device on which the asmqkview script was run:

asm_snapshot.<hostname>.tar.gz

In BIG-IP ASM versions 9.4.2 and 9.4.3, the asmqkview script omits the hostname resulting in the fasm_snapshot..tar.gz file written to the /var/tmp directory.

This behavior is cosmetic and does not affect the contents of the file.

F5 Product Development tracked this issue as CR85706 and it was fixed in BIG-IP ASM 9.4.4. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Workaround

You can work around this issue by allowing the hostname to be included in the file name. To do so, type the following command, replacing <hostname> with the hostname of the system:

mv /var/tmp/asm_snapshot..tar.gz /var/tmp/asm_snapshot.<hostname>.tar.gz

For example:

mv /var/tmp/asm_snapshot..tar.gz /var/tmp/asm_snapshot.asm.mysite.net.tar.gz
