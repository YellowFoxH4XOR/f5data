K38903282: Trouble accessing support cases or downloading resources via support.f5.com, supportfiles.f5.com, downloads.f5.com, ihealth.f5.com could be an issue with the F5 user account.

Description

If you're having trouble logging to one of the F5 websites below, and you already have an F5 WebSupport Portal user account, you can call the F5 Support line and talk with one of the TSC's (Technical Support Coordinators) who initially answer that line, and they can usually assist with resolving the issue. This applies to any trouble you might have seeing an open support case you're working on, or trouble downloading a new version of software from the downloads site. 

  • downloads.f5.com
  • ihealth.f5.com
  • support.f5.com
  • supportfiles.f5.com
This does not however include things like password resets, which can be done via the support.f5.com site on your own.

Environment

Using one of the F5 websites listed above.

Cause

Need to access one of the above listed resources, and help from the TSC's is needed to resolve an F5 WebSupport Portal user account issue.

Recommended Actions

Call the main F5 Support line and ask to speak with a TSC about a WebSupport Portal user account issue, and the TSC's who answer that line can assist with resolving the issue.
