Description

Virtual server has TLS1.3 enabled, Client SSL Profile has Client Authentication enabled, setting "require".
Then TLS1.3 connection fails in handshake.
 

Environment

  • BIG-IP v13.x-v14.x
  • Virtual server
  • TLS1.3
  • Client SSL profile 
  • Client Authentication
     

Cause

Do not support client authentication till v14.x.
 

Recommended Actions

Upgrade system to v15.x or above.
 

Additional Information
 

  • K10251520: BIG-IP support for TLS 1.3
