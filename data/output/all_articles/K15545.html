Known Issue

The tmsh load /sys config base command may overwrite the bigip.conf file.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system uses high level configuration items such as pools and virtual servers.
  • You run the tmsh load /sys config base command from the command line.

When users run the tmsh load /sys config base command from the command line, the contents of the bigip.conf file remain intact but are not loaded. This behavior is expected, and by design. However, in versions affected by this issue, the bigip.conf file is unexpectedly overwritten and high level configuration items are lost.

Impact

The loss of high level configuration items may result in interruptions in traffic processing.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • High level configuration items such as virtual servers and pools disappear from the Configuration utility after a user runs the tmsh load /sys config base command.
  • The BIG-IP system does not process traffic after a user runs the tmsh load /sys config base command.

Workaround

There is no workaround for this issue. You must use a previously saved bigip.conf file or user configuration set (UCS) archive to restore the configuration.
