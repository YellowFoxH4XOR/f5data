K04375653: BIG-IQ upgrade stuck at ''90% complete''

Type
Support Solution
Published
2022-09-23
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K04375653

Description

The Progress field has been showing "90% complete" for some time

Environment

Upgrade procedure to Software Version 8.2.0

  • The Status field shows "Running post upgrade tasks" 
  • All the devices show their upgrade status as "Finished" (both CM and DCDs)

Cause

The devices have been upgraded successfully, but the upgrade procedure is waiting for the cluster status to be "green"

Recommended Actions

Resolve the condition that impedes the cluster to be green.

For example, in the following case, the cluster status is yellow because of unassigned shards:

curl -s localhost:9200/_cluster/health?pretty

{
 "cluster_name" : "5b3f5a94-efab-4a95-9916-a42fd646b610",
 "status" : "yellow",
 "timed_out" : false,
 "number_of_nodes" : 5,
 "number_of_data_nodes" : 4,
 "active_primary_shards" : 3814,
 "active_shards" : 7354,
 "relocating_shards" : 0,
 "initializing_shards" : 0,
 "unassigned_shards" : 276,
 "delayed_unassigned_shards" : 0,
 "number_of_pending_tasks" : 0,
 "number_of_in_flight_fetch" : 0,
 "task_max_waiting_in_queue_millis" : 0,
 "active_shards_percent_as_number" : 96.3826998689384
}

Once the unassigned shards are deleted, the cluster status will be green, the upgrade procedure will then be marked as completed

It is recommended to start the upgrade procedure when the cluster status is green to avoid this condition
