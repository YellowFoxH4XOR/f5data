Topic

Quick Boot and Quiet Boot are boot features that were introduced in BIG-IP version 4.1.

Quiet Boot feature details

Some of the specifications of Quiet Boot are:

  • Consolidates boot information to one page.
  • Is turned on by default.
  • Performs faster on serial terminals.
  • Does not scroll the screen during boot.
  • Can be turned off by pressing F1 during the boot process (BIG-IP 2000 and BIG-IP 5000 only).
  • Can be enabled and disabled with the bigpipe global quiet_boot <enable/disable> command.

Note: To access the BIG-IP 2000 or BIG-IP 5000 BIOS, you must first turn off Quiet Boot using the bigpipe global quiet_boot disable command, or press the F1 key followed by the S key, when the BIG-IP displays System is Booting Please Wait. If you turn off Quiet Boot using the F1 and S keys, you must press them very quickly. It may take you a few attempts to get the timing down.

Quick Boot feature details

In Quick Boot, the following subsystems are left to start in the background, allowing the BIG-IP to process traffic sooner:

  • Health monitoring
  • Administrative access daemons such as apache and sshd.
  • Other daemons such as sendmail and gated.

Note: BIG-IP uses Quick Boot as the default boot method, beginning in BIG-IP version 4.2.
