Description

Performed license reactivation before the upgrade but after booting to the new volume, a "License Invalid" error is seen from the Configuration Utility (GUI). The full error shows:

"License invalid for <Licensed Version>
This device is not operational because the loaded configuration contained errors or unlicensed objects. Please adjust the configuration and/or the license, and re-license the device. The license for this device is not operational."

Environment

  • SKU Version V12, V13, V16, and V18
  • License Reactivation
  • VE Plus License Offering
  • Software Upgrade

Cause

The upgraded version is not supported by the license. Permitted Versions specifies which BIG-IP versions can be run on the platform.

In the below output those are versions 5.*.* - 15.*.*

# show sys license

Sys::License
Licensed Version                 11.6.0
Registration key                 XXXXX-XXXXX-XXXXX-XXXXX-XXXXX
Licensed On                      2015/07/31
Service Check Date               2020/11/23
Platform ID                      Z100k
Daily Renewal Notification Days  5
Permitted Versions               5.*.* - 15.*.*

Recommended Actions

Check what software version the unit is running on:
  1. Log in to the BIG-IP command line using SSH.
  2. Run command: #tmsh show sys license
  3. Observe the output: "Licensed Version 11.6.x"
  4. Based on the output, refer to K15643 to determine if the version is being supported by the current VE offering. 
Please contact your F5 Sales Representatives to purchase a license that supports your desired upgrade version.
