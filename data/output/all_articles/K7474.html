Known Issue

Changing the load balancing method of an existing pool to the least connections option can cause TMM to core when all of the following conditions for the pool exist:
  • The load balancing method is changed on an existing pool member to least connections
  • Priority Group Activation is enabled
  • The number of active members in the highest priority group is greater than the minimum active member count

F5 Product Development tracked this issue as CR78002 and it was fixed in BIG-IP LTM 9.3.1 and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.0-HF3 issued for BIG-IP 9.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
