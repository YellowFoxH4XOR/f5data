VLAN failsafe will cause the BIG-IP system to reboot when it is unable to detect or generate traffic on a VLAN for a specified amount of time. When the unit reboots, the standby unit will become active. In some configurations, the standby unit will never see any traffic. As a result, it will continually reboot as VLAN failsafe triggers.

You can modify the VLAN failsafe behavior as follows:

  • Prevent the standby unit from repeatedly rebooting
  • Configure the BIG-IP system to fail over before rebooting

Important: The following commands enable internal variables. Before using any internal variable, refer to K920: Overview of internal variables.

Preventing the standby unit from repeatedly rebooting

To prevent the standby unit from repeatedly triggering VLAN failsafe and rebooting, type the following command:

bigpipe internal set standby_failsafe_reboot = 0

Configuring BIG-IP to fail over before rebooting

To configure the active BIG-IP system to fail over to the standby unit before it reboots due to a VLAN failsafe timeout, type the following command:

bigpipe internal set vlan_failsafe_failover = 1
