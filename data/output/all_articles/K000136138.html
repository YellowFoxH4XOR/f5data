K000136138: Options List setting is changed on SSL profiles after the upgrade to v16

Type
Support Solution
Published
2023-09-08
Updated
2023-09-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136138

Description

During the upgrade of the BIG-IP to v16.x, Options List setting will be modified.

 

With the default setting,

options { dont-insert-empty-fragments no-tlsv1.3 }

 

After the upgrade, it will be set to

options { dont-insert-empty-fragments no-tlsv1.3 no-dtlsv1.2 }

 

For the customized Client SSL and Server SSL profiles, if this attribute is inherited from the parent, you may need to reset the Options List back to its inherited default value.

 

 

Environment

BIG-IP v16.x

Upgrading from v14.x to v16.x

 

 

Cause

Beginning in BIG-IP 16.0.0, F5 introduces support for Datagram Transport Layer Security (DTLS) 1.2 as defined in RFC6347.

To prevent an actual "functional" change in behavior on upgrade, the code will set options explicitly on the Client SSL and Server SSL profiles.

 

 

Recommended Actions

Reset the Options List back to its inherited default value:

tmsh modify ltm profile client-ssl <clientssl-child-profile> options { default-value }

tmsh modify ltm profile server-ssl <serverssl-child-profile> options { default-value }
