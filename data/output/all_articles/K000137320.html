K000137320: '404 NR route_not_found' when going through Istio proxy

Type
Support Solution
Published
2024-03-01
Updated
2024-03-01
Applies to
  • Aspen Mesh: 1.14
Source
https://my.f5.com/manage/s/article/K000137320

Description

Connection failure when going through istio-proxy.

Environment

- Aspen Mesh

- Sidecar object

Cause

Incorrect egress hosts line in Sidecar configuration.

Recommended Actions

Modify egress hosts to './*' instead of '*/*':

apiVersion: networking.istio.io/v1beta1
kind: Sidecar
metadata:
  generation: 3
  name: test-any-ingress
  namespace: some_namespace
spec:
  egress:
  - hosts:
    - './*'
  outboundTrafficPolicy:
    mode: ALLOW_ANY

Additional Information

Sidecar describes the configuration of the sidecar proxy that mediates inbound and outbound communication to the workload instance it is attached to.
