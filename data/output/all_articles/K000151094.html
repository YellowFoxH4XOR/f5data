K000151094: APM: None of the configured JWK keys match the received JWT header. The trigger - JWT Key ID is case sensitive

Type
Support Solution
Published
2025-04-30
Updated
2025-04-30
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000151094

Description

OAuth authentication failing

  • /var/log/apm contains messages like the one below:
    "... OAuth Scope: failed for jwt-provider-list '/Common/<name_of_provider_list>' , error: None of the configured JWK keys match the received JWT token, JWT Header: <Base64_encoded_value>"

Environment

  • BIG-IP with APM using OAuth
  • "Use Auto JWT" is disabled in "OAuth Client / Resource Server : Provider"
  • JWT key is configured manually

Cause

The "ID" field under "Access  ››  Federation : JSON Web Token : Key Configuration" was entered manually and does not exactly match the one provided in the token. This value is case sensitive and has to exactly match the Key ID (kid) value received in the token.

Recommended Actions

Decode "<Base64_encoded_value>" (e.g. using https://jwt.io) , then copy the "kid" value to the "ID" field of the JWT key configuration.
