Description

Attempting to load the configuration after upgrade with TMSH produces error messages similar to the following in /var/log/ltm:

Example: 
tmsh load sys config

Oct  9 17:52:35 mybigip err mcpd[7582]: 01070712:3: Caught configuration exception (0), Failed: name (/Common/my_WEBTOP_customization:webtop_popup.css) Cache path (/config/filestore/files_d/Common_d/customization_template_d/:Common:my_WEBTOP_customization::webtop_popup.css_267966_48) does not exist and there is no copy in trash-bin to restore from..
Oct  9 17:52:35 mybigip err tmsh[14077]: 01420006:3: Loading configuration process failed.
Oct  9 17:55:31 mybigip err mcpd[7582]: 01070712:3: Caught configuration exception (0), Failed: name (/Common/my_WEBTOP_customization:webtop_popup.css) Cache path (/config/filestore/files_d/Common_d/customization_template_d/:Common:my_WEBTOP_customization::webtop_popup.css_357458_48) does not exist and there is no copy in trash-bin to restore from..
Oct  9 17:55:31 mybigip err tmsh[14314]: 01420006:3: Loading configuration process failed.
Oct  9 17:58:55 mybigip err mcpd[7582]: 01070712:3: Caught configuration exception (0), Failed: name (/Common/my_WEBTOP_customization:webtop_popup.css) Cache path (/config/filestore/files_d/Common_d/customization_template_d/:Common:my_WEBTOP_customization::webtop_popup.css_446950_48) does not exist and there is no copy in trash-bin to restore from..
Oct  9 17:58:56 mybigip err tmsh[14614]: 01420006:3: Loading configuration process failed.
Oct  9 17:59:22 mybigip err mcpd[7582]: 01070712:3: Caught configuration exception (0), Failed: name (/Common/my_WEBTOP_customization:webtop_popup.css) Cache path (/config/filestore/files_d/Common_d/customization_template_d/:Common:my_WEBTOP_customization::webtop_popup.css_536442_48) does not exist and there is no copy in trash-bin to restore from..
Oct  9 17:59:22 mybigip err tmsh[14653]: 01420006:3: Loading configuration process failed.

When attempting to load the configuration multiple times the Cache path file name suffix referenced continually changes.
Note: The filename ending changes each time an attempt to load the configuration is executed.

Example:
:Common:my_WEBTOP_customization::webtop_popup.css_267966_48
:Common:my_WEBTOP_customization::webtop_popup.css_357458_48
:Common:my_WEBTOP_customization::webtop_popup.css_446950_48
:Common:my_WEBTOP_customization::webtop_popup.css_536442_48

Environment

  • BIG-IP APM
  • Upgrade to v13.1.x or above

Cause

The above listed files did not exist in /config/filestore/files_d/Common_d/customization_template_d/, but the file ":Common:my_WEBTOP_customization::webtop_popup.css_179017_48 "  did exist.

The BIG-IP APM object was previously customized with a special file reference:

apm policy customization-group /Common/my_WEBTOP_customization {
    cache-path /config/filestore/files_d/Common_d/customization_group_d/:Common:my_WEBTOP_customization_44594_6
    revision 6
    templates {
        webtop_popup.css {
Note  >>>>  cache-path /config/filestore/files_d/Common_d/customization_template_d/:Common:remote.mydomain.com_12sep2018_1_218003_48  <<<<
            name /Common/remote.mydomain.com_12sep2018_1
            revision 48
        }
    }
    type webtop
}
 

Recommended Actions

The file name for the template customization is derived from the customization-group name and the template:  
   :<partition>:<customization-group>::<template_name>_<serial_number>_<revision>


Manually change the config (/config/bigip.conf) to match the above syntax and the existing filename in /config/filestore/files_d/Common_d/customization_template_d/

apm policy customization-group /Common/my_WEBTOP_customization {
    cache-path /config/filestore/files_d/Common_d/customization_group_d/:Common:my_WEBTOP_customization_44594_6
    revision 6
    templates {
        webtop_popup.css {
            cache-path /config/filestore/files_d/Common_d/customization_template_d/:Common:my_WEBTOP_customization::webtop_popup.css_179017_48
            name /Common/my_WEBTOP_customization:webtop_popup.css
            revision 48
        }
    }
    type webtop
}
