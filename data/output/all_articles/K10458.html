K10458: The SSL-decode feature of the network packet dump utility does not decode AES-encrypted packets

Topic

Currently, the SSL-decode feature of the Network packet dump utility does not support AES (Advanced Encryption Standard) encryption. If an SSL session between a client system and the FirePass controller uses AES encryption, and you perform a network packet dump, selecting the Click here to view the same data SSL-decoded link does not decode the packets.

Note: The Network packet dump utility is located on the Device Management: Maintenance: Troubleshooting Tools page.
 
The encryption algorithm used in an SSL session is negotiated by the client system and the FirePass controller during the SSL handshake, as described in RFC2246. However, if you select High-grade security for the SSL Cipher Security setting on the Device Management: Security: User Access Security page, more SSL sessions will use AES encryption. For troubleshooting purposes, you may want to temporarily lower the security grade of the SSL Cipher Security setting if you need to perform a network packet dump. However, if the security settings in the client's browser only allow AES encryption, changing the SSL Cipher Security setting will not have an effect.
 
Note: For more information about the SSL Cipher Security setting, refer to K3795: Overview of SSL Cipher Security levels.
 
F5 Networks Product Development is tracking an enhancement request as CR126390 to add AES decryption to the SSL-decode feature.
