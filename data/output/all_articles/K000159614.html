K000159614: Key Exchange Algorithm Displays as "Unknown" or "Any" in F5 Edge Client When Using TLS 1.3

Type
Support Solution
Published
2026-01-19
Updated
2026-01-19
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000159614

Description

When establishing VPN connections through F5 Edge Client with TLS 1.3 enabled, the Key Exchange Algorithm displays incorrectly in the client interface,

  • Windows machines: Display shows "unknown (0-bit)"
  • MacOS machines: Display shows "any"

This occurs despite:

  • VPN connections functioning normally
  • Secure cipher configurations being in place
  • Successful SSL/TLS handshakes completing

Environment

  • BIG-IP
  • TLS 1.3 in use
  • Edge client for Windows and MacOS

Cause

This is a known cosmetic issue tracked in the following bug IDs:

  • 1073053 [Win] Key Exchange Algorithm not correct showing status in EDGE Client when using TLSv1.3
  • 1073049 [MAC OS] Key Exchange Algorithm not correct showing status in EDGE Client when using TLSv1.3

The Key Exchange Algorithm information is not being correctly fetched and propagated from the backend to the Edge Client GUI when TLS 1.3 is in use. This is a display-only issue in the client interface.

Recommended Actions

This is expected behaviour and a cosmetic issue only. No action is required
