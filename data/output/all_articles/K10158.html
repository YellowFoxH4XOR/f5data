Issue

In ARX versions prior to 5.0.0, the NSM recovery feature was disabled by default. In addition, enabling or disabling the feature required you to restart the ARX system.

Beginning in ARX 5.0.0, the NSM recovery feature is enabled by default. When the NSM recovery feature is enabled, a failed NSM processor will recover after a failure and go into a standby state. The recovered NSM processor will take over and manage network traffic if the active NSM processor fails. Additionally, you no longer have to restart the ARX system to enable or disable the NSM recovery feature.

Note: For more information about the NSM recovery feature, refer to the Redundant Pairs chapter in the ARX CLI Reference Guide.
