Description

You are able to SSH to the BIG-IP system but unable to access the GUI through the management port

Environment

  • LTM
  • GUI
  • Management port 

Cause

Unknown at the time of creating this article 
 

Recommended Actions

Restart the tomcat process and httpd process  

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Log in to the BIG-IP command line and type the following command:

tmsh restart /sys service tomcat
tmsh restart /sys service httpd

If problem still persist, the following procedures may help:
  1. Verify that the system is listening on port 443.

    telnet <mgmt IP> 443

  2. Review the system log files for issues (Ex. memory issues)

    • /var/log/ltm

    • /var/log/tomcat

    • /var/log/httpd

  3. Perform a reboot of the system if possible.

  4. Contact F5 support.
