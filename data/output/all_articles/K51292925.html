Known Issue

The bcm56xxd process may continue to log debug log messages after you change the log level from debug to the default value.

Note: The bcm56xxd process is the switch driver daemon for the BIG-IP system.

This issue occurs when all of the following conditions are met:

  • You previously set the log.bcm56xxd.level database key to debug and then you set it back to the default value.
  • You previously set the log.bcm56xxd.debugmask database key to a non-zero value and then you set it back to the default value.

Impact

Due to the large volume of debug log messages, the /var/log/ltm files will continue to grow in size until the logical volume is full.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You view disk space warnings regarding the /var/log volume.
  • You view debug level log messages in the /var/log/ltm file that appear similar to the following example:

    info bcm56xxd[17228]: 012c0016:6: VLAN 0: bcm_vlan_port_get: vid 1. pbm 0x2000000 upbm 0x0.

Workaround

To work around this issue, you can restart the bcm56xxd process. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system stops processing traffic. You should perform this operation only during a maintenance window or when the system is in a standby state.

  1. Log in to the BIG-IP command line.
  2. To restart the bcm56xxd process, type the following command:

    bigstart restart bcm56xxd
