Topic

Use this template to configure BIG-IP APM Virtual Edition (VE) for one of the four BIG-IP APM VE license SKUs created for VMware Horizon View 5.2, 5.3, 6.0, and 6.1. The iApp (and deployment guidance) is tailored toward building the VMware Horizon View reference architecture highlighted on f5.com at the following location: https://f5.com/partners/product-technology-alliances/vmware.

For complete instructions about using this iApp template, refer to the VMware Horizon View Optimized Solution Deployment Guide.

To download and install the iApp template, perform the following procedures:

Downloading the iApp template

Important: You must download the file; do not copy and paste the contents.

  1. Go to the F5 Downloads site.
  2. From the Downloads Overview page, click Find a Download.
  3. From the Product Line column, select iApp-Templates.
  4. Read the End User Software License Agreement and either accept the license by clicking I Accept, or cancel the process by clicking Cancel.

    If you accept the End User Software License Agreement, the Select a Download page appears, which shows a table with the file name, product description, and file size details.

    Note: After you accept the End User Software License Agreement, the system will not present the agreement again for subsequent downloads that you perform during the same browser session.

  5. From the Filename column of the table, select the file named iapps-x.x.x.x.x.zip. For example, the file for the June 2016 iApp release is named iapps-1.0.0.405.0.zip.
  6. F5 supports the FTP, HTTP, and HTTPS protocols for downloading files from F5. Select one of the three supported protocols listed by clicking the down arrow button.

    A pop-up window appears, prompting you to either open or save the file.

    Note: Some browsers save the file to a default location. You can review your specific browser's documentation to change the default location of where you want to save files.

  7. Select the option to save the file.

Installing the iApp template

  1. Unzip the zip file to a location that is accessible from your BIG-IP system.
  2. Log in to the BIG-IP Configuration utility.
  3. From the iApp tab, select Templates.
  4. Click Import.
  5. Select the Overwrite Existing Templates box.
  6. Click Browse.
  7. Browse to the location where you saved the iApp file.
  8. Select the file named f5.vmware_view_optimized_solution.vx.x.x that corresponds to the iApp version you want to install. For example, the file for the June 2016 release of this iApp is named f5.vmware_view_optimized_solution.v1.3.0.

    Note: Refer to the previously-listed Support Matrix to select the most current supported template for your BIG-IP software version.

  9. Click Upload.

When the upload completes, the iApp is available for use.

Features added

  • No new features were added in this release.

Issues resolved

  • The iApp now correctly uses Source IP persistence when an internal virtual server is used.
  • The iApp now allows using advanced monitors when the BIG-IP APM system is not used, by asking an additional question about the NetBIOS name. Previously, the iApp would display a script error.
  • The iApp no longer displays a script error when in LTM only mode. Previously, the iApp would display an error when BIG-IP APM was not provisioned.
