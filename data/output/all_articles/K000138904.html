K000138904: No stats under Monitoring > Secure Web Gateway on BIG-IQ

Type
Support Solution
Published
2024-03-13
Updated
2024-03-13
Source
https://my.f5.com/manage/s/article/K000138904

Description

You notice that there are no stats under Monitoring > Secure Web Gateway on the BIG-IQ while all other stats are working.


Environment

  • You are managing Secure Web Gateway on BIG-IQ.

Cause

You need to allow port 9090 access on the Discovery Address of all CMs and DCDs. 


Recommended Actions

You can open port 9090 by using tmsh command on each CMs and DCDs.


e.g.

# tmsh modify net self <IP address of the Discovery Address> allow-service replace-all-with { default tcp:9090 }

None
