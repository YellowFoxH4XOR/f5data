Topic

Starting in BIG-IP ASM version 9.4.4, you can define Disallowed object types in the security policy. When you define Disallowed object types in the security policy, you specify the object types that the security policy considers illegal, and you can specify whether to log or block the requests for those object types.

Note: Requests for Disallowed object types do not generate Learning suggestions.

To define Disallowed object types, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Web Applications.
  4. Click the relevant security policy.
  5. Click Object Types.
  6. Click the Disallowed Object Types List menu.
  7. Click Create.
  8. Enter the type of object that is not allowed in the security policy.

    Note: Object types are case-sensitive.

  9. Click Create.
  10. Click Apply Policy.
