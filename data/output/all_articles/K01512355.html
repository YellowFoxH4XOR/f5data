Description

You see the following log in var/log/ltm:

012a0003:3: HAL error getting baud rate: TTYDev: I/O error  [Input/output error] at TTYConDev.cpp:60

Environment

  • BIG-IP VE
  • Running version 16.x

Cause

This error message is expected and harmless on BIG-IP VE.
There are no serial ports, and BIG-IP does not need serial ports, so the odd baud rate does not affect anything other than cause an I/O error log message during QKView.

Recommended Actions

None.

None.
