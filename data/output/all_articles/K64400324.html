Description

On a BIG-IP system when activating a new Boot Location at System >> Software Management : Boot Locations, you would like to know if it's necessary to set Install Configuration to Yes or No.

The default selection is No.

Environment

  • BIG-IP
  • Software upgrade
  • Boot volumes

Cause

None

Recommended Actions

The Install Configuration option copies the configuration from the selected Source Volume to the destination boot location.

If you have not made any configuration changes between the time you have installed an upgrade and boot into the volume, it is not necessary to set Install Configuration to Yes. The software install process automatically installs the configuration from the currently active boot volume, by default1, at the time of software install.

1If either of the DB keys liveinstall.moveconfig and liveinstall.saveconfig are set to the non-default value of disable, no configuration from the active volume will be installed to the target volume. The default value for both keys is enable. For more information refer to K13438: Controlling configuration import when performing software upgrade/installation.

The Install Configuration option is useful if you have performed the initial upgrade, and plan to reboot into the newly upgraded volume some time later, after configuration changes have been made to the current volume. In this case, you probably want to install the configuration again from the currently active boot volume since it contains the latest changes.

Additional Information

This article assumes that you are installing an upgrade in a new boot location. If you are downgrading or rolling back to a lower code version, F5 recommends that you set Install Configuration to No since the new configuration will likely fail to load on the lower code version.
