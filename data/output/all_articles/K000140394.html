K000140394: Certificate Management OCSP Monitoring Connection Error Timed Out

Type
Support Solution
Published
2024-07-20
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000140394

Description

After configuring OCSP Stapling., the BIG-IP system displays the error, "OCSP Connection Error: Timed Out'., in 'Certificates Management > Trusted Certificates Management > SSL Certificates List'.


Environment

BIG-IP TMOS

OCSP Stapling


Cause

BIG-IP's 'DNS Resolver' configuration does not include a Forward Zone for the Fully-Qualified Domain Name (FQDN) pertaining to the certificate's AIA URL.


Recommended Actions

Add a Forward Zone for the certificate's AIA URL to the BIG-IP's DNS Resolver configuration. The Forward Zone should be a Fully-Qualified Domain Name (FQDN)


The DNS Resolver configuration can be found at: Network > DNS Resolvers > DNS Resolver List.
