Description 

You want to configure Priority Group and Ratio for FQDN pool members without auto populate configured 

Environment

  • BIG-IP LTM
  • FQDN pool with multiple members associated 

Cause

The ephemeral FQDN nodes and pool members fully inherits their Priority Group, Ratio, and Connection / Rate limit values from the parent FQDN member. Each ephemeral FQDN pool member uses the same value as the parent FQDN node without the option to modify the Priority Group activation, Ratio, or Connection / Rate limit values independently.

Recommended Actions

To configure different values for each different pool member, you will have to use static pool members, not FQDN members.
