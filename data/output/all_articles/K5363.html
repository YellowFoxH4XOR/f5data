K5363: 3dnsd -v will not report the 3dnsd version if 3dnsd is already running

Known Issue

This is the result of a known issue. The 3dnsd process always checks to make sure another 3dnsd process is not running before it starts. 3dnsd also performs this check when you run the 3dnsd -v command to find its version, which prevents 3dnsd from reporting its version if another copy of 3dnsd is already running.

When this issue occurs, you will receive the following error message:

An instance of 3dnsd (pid: <pid>) is already running! Exiting.

The config command executes the 3dnsd -v command when it begins, which will result in the same error message.

To find the version of the 3dnsd daemon you are running, perform the following steps:

  1. Log in to the command line.
  2. Execute the following command to find the version string in the 3dnsd file:

    strings /usr/sbin/3dnsd |grep Build

F5 Networks Product Development tracked this issue as CR23831, CR27501, and CR41826.
