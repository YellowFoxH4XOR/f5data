K000134464: ARP not resolving from Virtual server IP configured with route domain.

Type
Support Solution
Published
2023-05-04
Updated
2023-05-04
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000134464

Description

ARP not resolving from Virtual server IP configured with route domain.
Able to ping the Self-IP (floating and non-floating).
Source IP will always be like 0.0.0.0%0 even if changed to 0.0.0.0/0.

 

Environment

  • Route Domain
  • Port List
  • BIG-IP

Cause

Port list is in different partition.

 

 Recommended Actions

  1. Remove the Port list and add the VS with Port.
  2. IF need to Configure Multiple IP Addresses and Service Ports for a Virtual Server then can use the Port list along with the Address list. But they should be in correct RD. For more details follow the https://techdocs.f5.com/kb/en-us/products/big-ip_ltm/manuals/product/big-ip-ltm-virtual-servers-multiple-ip-port-14-1-0/01.html.

Additional Information

AFM Network Firewall uses Address and Port lists to collect multiple IP addresses and service ports in single configuration objects. Firewall policies are then configured to reference the appropriate address and port list. While you can create firewall policies that contain many individual IP address and service port entries, F5 recommends creating and associating address and port lists with your firewall policies to simplify administration.

  • Address lists - a configuration object containing multiple IP addresses.
  • Port lists - a configuration object containing multiple service ports.
