Description

When creating an APM Radius AAA Server Object, the GUI displays a General database error.

Environment

Relevant environmental factors specific to the topic

  • BIG-IP APM
  • AAA Radius
  • Radius Secret contains a semi-colon (;)

Cause

When creating a Radius APM AAA object the Radius Secure contains a Semicolon

This is tracked as Bug ID 940757: Semicolon (;) character not allowed in password with APM

Recommended Actions

Use a password that does not contain a semi colon.

None
