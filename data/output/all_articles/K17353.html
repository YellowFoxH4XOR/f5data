Known Issue

The monpd process may exit and restart if MySQL becomes unavailable.

This issue occurs when the following condition is met:

  • The BIG-IP system MySQL database unexpectedly becomes unavailable or is unable to start.

Impact

Statistical reporting charts are unavailable until MySQL is able to run properly, and the monpd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The monpd process generates a core file to the /shared/core directory.
  • Users cannot view BIG-IP reporting charts in the Configuration utility.
  • The system logs messages to the /var/log/ltm file that appear similar to the following example:

    emerg logger: Re-starting monpd
