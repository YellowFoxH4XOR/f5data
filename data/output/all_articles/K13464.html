Known Issue

You cannot configure a multicast failover address from the Configuration utility.

Impact

You cannot configure a multicast failover address from the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you enter a multicast failover address into the Multicast Address field and click update, the system displays error messages in the Configuration utility that appear similar to the following example:

    Invalid Multicast Address

    Form Error
    One or more fields contain invalid values.

Workaround

To work around this issue, you can configure multicast failover from the command line. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. To configure multicast failover with the default recommended settings (224.0.0.245, port 62960), use the following command syntaxes:

    modify cm device <hostname> multicast-interface eth0

    modify cm device <hostname> multicast-ip 224.0.0.245

    modify cm device <hostname> multicast-port 62960

    For example:

    modify cm device bigip1.example.com multicast-interface eth0

    modify cm device bigip1.example.com multicast-ip 224.0.0.245

    modify cm device bigip1.example.com multicast-port 62960
  3. Save the configuration by typing the following command:

    save sys config

    Note: This procedure will need to be executed on the peer device as well.
