Known Issue

The BIG-IP ASM system may reboot after you perform a ConfigSync operation on VIPRION systems.

This issue occurs when all of the following conditions are met:

  • You configure the VIPRION system as part of a device group.
  • You perform a ConfigSync operation on one of the VIPRION systems in the device group.
This issue is caused by a race condition involved with loading the device configuration.

Impact

The VIPRION system affected by this race condition restarts. If the affected VIPRION system is the active system in the device group, a failover occurs.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system logs messages to the /var/log/asm file that appears similar to the following example:

    crit g_server_rpc_handler_async.pl[12345]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::handle_error): Code: 303, Error message = Set active failed
