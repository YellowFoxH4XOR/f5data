K000151361: Core generated for autodosd daemon when synchronization process is terminated

Type
Support Solution
Published
2025-05-15
Updated
2025-05-15
Applies to
  • F5 Distributed Cloud Services
  • BIG-IP
  • BIG-IP AFM: 17.1.0, 17.1.2, 17.1.1, 17.1.X, 17.5.X, 17.5.0
Source
https://my.f5.com/manage/s/article/K000151361

Description

Autodosd is a daemon process that supports the DoS Auto Threshold feature within the F5's Application Traffic Management (ATM) and Advanced Firewall Manager (AFM) modules. This daemon is part of the control plane and is responsible for managing and enforcing DoS mitigation thresholds dynamically.  A core file may be generated by the autodosd process on BIG-IP systems, resulting in service disruption.

 

Environment

  • Product: BIG-IP AFM
  • Version: 17.1.x, 17.5.x 
  • Provisioned Modules: AFM

Cause

This can happen when AFM DoS vectors are configured. This can occur during normal operation but the specific conditions that trigger it are unknown. Autodosd is restarted, but up to 15 seconds of history may be lost. 

Answer/Recommended Actions

None at the time of Publishing. 

Additional Information

None.
