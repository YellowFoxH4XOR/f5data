Known Issue

The persistence record expires early if the system returns an error for a Session Initiation Protocol (SIP) BYE command.

This issue occurs when the following condition is met:

  • The system returns an error for a SIP BYE command.

Impact

If the system does not end the call, the persistence record expires early.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the system returns an error for a SIP BYE command, the system sets the persistence timeout to the transaction timeout.
