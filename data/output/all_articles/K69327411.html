Description

After issuing a load sys config verify, a failover occurs, the CLI prompt changes to MonitorFault, and messages similar to the following are observed in /var/log/ltm:

info mcpd[13893]: 0114002b:6: HA group_score_t /Common/traffic-group-1 enabled.
notice sod[14825]: 010c0091:5: HA monitor fault on device bigip1.ltm for traffic-group traffic-group-1.
notice tmm[19080]: 01340011:5: HA unit 1 state change: from 1 to 0.

Environment

  • load sys config verify
  • HA

Cause

ID1120345

Configuration to be verified contains a HA group and traffic group referencing it.

For example:

cm traffic-group /Common/traffic-group-1 {
    failover-method ha-score
    monitor {
        ha-group my-ha-group
    }
    unit-id 1
}
sys ha-group my-ha-group {
    pools {
        /Common/my-pool {
            minimum-threshold 1
            weight 10
        }
    }
}
ltm pool /Common/my-pool {
    members {
        /Common/10.10.10.1:80 {
            address 10.10.10.1
            session user-disabled
            state user-down
        }
    }
}

Recommended Actions

Issue a load sys config to clear the failover fault.

To avoid the issue, ensure that a traffic group does not reference the HA group object in the config to be verified.

Additional Information

This problem will also occur when using the from-terminal or file options, with the verify option.
