K31426731: Fail to deploy tenant with an invalid search domain configured

Type
Support Solution
Published
2022-10-27
Updated
2023-02-21
Applies to
  • rSeries Platforms
  • F5OS
Source
https://my.f5.com/manage/s/article/K31426731

Description

Tenants status may be stuck in pending status with the below symptoms :

  •  kubevirt virt-launcher pods stuck in a restart loop
[root@appliance-1 pods]#kubectl get pods
NAME                        READY   STATUS    RESTARTS   AGE
virt-launcher-ltm-1-abcd1   1/1     Running   0          3s
[root@appliance-1 pods]#kubectl get pods
NAME                        READY   STATUS     RESTARTS   AGE
virt-launcher-ltm-1-abcd2   0/1     Init:0/1   0          0s
[root@appliance-1 pods]#kubectl get pods
NAME                        READY   STATUS            RESTARTS   AGE
virt-launcher-ltm-1-abcd3   0/1     PodInitializing   0          2s
[root@appliance-1 pods]#kubectl get pods
NAME                        READY   STATUS   RESTARTS   AGE
virt-launcher-ltm-1-acbd4   0/1     Error    0          4s
  • There are below error logs found in the kubevirt  pod logs 
# kubectl logs virt-launcher-external-1-972hv
....
{"component":"virt-launcher","level":"error","msg":"failed to run DHCP: Search domain is not valid: 'example.com'","pos":"common.go:369","timestamp":"2022-09-29T06:02:35.014277Z"}
panic: Search domain is not valid: 'example.com'

Environment

  • VELOS
  • F5OS
  • rSeries

Cause
The customer configures an invalid search domain.

Recommended Actions
Correct the search domain configure or just remove it.

Additional Information

None
