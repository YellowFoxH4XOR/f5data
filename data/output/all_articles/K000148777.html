K000148777: F5OS primarykey not being updated via ansible's f5os_primarykey component

Type
Support Solution
Published
2024-11-28
Updated
2024-11-28
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000148777

Description

When trying to change the primary key to an F5OS device, by means of an the ansible component f5os_primarykey, it is not updated.

There are no errors that indicate that anything went wrong.

The result of running the playbook is succesful.

PLAY RECAP ******************************************************************************************************************************

<<IP>> : ok=1 changed=0 unreachable=0 failed=0 skipped=0 rescued=0 ignored=0

Environment

  • F5OS devices
  • Ansible playbook
  • f5os_primarykey
  • Configuration not updated

Cause

Undetermined at the time of publication.

What we have been able to determine is that the f5os_primarykey component only works the first time, then it does not work again.

Recommended Actions

Unfortunately, there is no workaround at this time that involves ansible. You can try a different method to update the primarykey.

Additional Information

Task looks similar to this:

- name: Setting Primary Key on F5OS Device
  f5os_primarykey:
    passphrase: "test-passphrase"
    salt: "test-salt"
    state: present
