Description

On deployment or initial start up of a vCMP guest, the host may log an error message similar to the following in /var/log/ltm: 

vcmp guest <guest name> has a poorly generated symmetric unit key.

Note: This error is reproducible when executing the following TMSH command on the same device: tmsh load /sys config verify

Environment

  • BIG-IP
  • vCMP
  • BIG-IP versions prior to 14.1.2


Cause

Bug ID 673842

Beginning in 15.0.0 the manner of generating Symmetric Unit Keys was changed to be more secure.  Because of the manner in which Symmetric Unit Keys work, the key cannot be changed once the guest has been created.  The system logs this error to note that the guest uses the older, less secure, Symmetric Unit Key.

Recommended Actions

  • You can ignore the error, as it does not impact the functioning of the vCMP guest
  • You can delete the guest and create a new guest, which will use the newer more secure Symmetric Unit Key.
