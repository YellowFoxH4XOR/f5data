Known Issue

This is the result of a known issue. If you configure a forwarding virtual server, and that virtual server attempts to forward a packet to a multicast address that is not a link-local address, TMM crashes.

Note: This issue occurs for both layer 2 and layer 3 forwarding virtual servers.

F5 Product Development tracked this issue as ID 211130 (formerly CR127266) and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.
