Topic

FirePass Network Access permits you to configure client web browser proxy settings, which are used for the duration of the Network Access session. This capability allows you to force web traffic through an internal proxy server through the FirePass Network Access connection. This configuration is typically used to control web access for remote users connected to FirePass Network Access for web content filtering, logging, authentication, and other services.

Configuring client web browser proxy setting

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Device Management : Client Downloads : Windows (x86).
  3. Click on the Custom Settings tab.
  4. Configure the options you want to use in the Proxy Settings section.
  5. Click the Update button/

However, this capability is only supported on Microsoft Windows client machines using Microsoft Internet Explorer web browser versions 5 and later. This capability is not available on Mac or Linux client machines.

F5 Product Development is tracking an enhancement to add this support as CR55523.
