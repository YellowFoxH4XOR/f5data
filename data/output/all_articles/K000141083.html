Description

You want to configure a multicast VXLAN tunnel. This configuration allows dynamic discovery of VXLAN endpoints, as opposed to statically configured endpoints.

Environment

  • BIG-IP

Cause

None

Recommended Actions

To configure a multicast VXLAN tunnel:

  1. Use the built-in VXLAN tunnel profile, or if you require a port other than the default 4789, configure a VXLAN tunnel profile with Flooding Type multicast. To view the built-in VXLAN tunnel profile from the Configuration utility, go to Network > Tunnels > Profiles > VXLAN.
  2. Configure a tunnel using the profile selected in step 1 with remote-address set to a multicast address. To create a tunnel using the Configuration utility, go to Network > Tunnels > Tunnel List, then select Create. For detailed information about creating tunnels, refer to the Configuring Network Virtualization Tunnels chapter of the BIG-IP TMOS: Tunneling and IPsec manual.

    Important: All endpoints must use the same multicast address. It is recommended to use a multicast address in the administratively-scoped block, also known as private use: 240.0.0.0/8. The equivalent IPv6 block is ff18::/16.

Additional Information

The Flooding Type set on the VXLAN tunnel profile determines how traffic is flooded when the endpoint for a specific destination MAC is not known. Multipoint requires static FDB entries, while multicast uses a multicast destination address for endpoint discovery.
