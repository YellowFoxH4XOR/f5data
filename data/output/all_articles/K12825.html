Known Issue

Description

Connecting to a Microsoft Windows Server 2008 terminal server through a FirePass Terminal Servers Favorite will not redirect to a printer using the easy print driver on client computers running a Windows x64 bit operating system. Microsoft Windows Server 2008 supports a technology called Easy Print that assists in redirecting print output to a printer on the user's local computer. When the user's session has printer redirection enabled, the Terminal Server will redirect anything printed to the defined printer to the user's local printer.

Impact

Users may be unable to redirect printing to a locally defined printer.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When a user prints from a remote desktop session, the print output will not print to their local printer
  • Viewing the model of the defined printer on the terminal server does not show as Remote Desktop Easy Print
