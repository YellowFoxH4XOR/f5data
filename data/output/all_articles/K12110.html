Topic

Multiple BIG-IP appliances of the same hardware platform and running the same product and version may have hard disks that are partitioned differently from one another depending on the software versions that have been previously installed and the methods used to install them.

Note: In BIG-IP 10.x, this disparity in disk partitioning is only applicable if the BIG-IP system is installed with the partitions disk-formatting scheme. For more information about determining whether the BIG-IP 10.x is installed with the partitions scheme or the volumes scheme, refer to K10817: Determining the disk formatting scheme used by a BIG-IP 10.x system.

For example:

A BIG-IP 3600 platform with a 320-gigabyte hard disk that was installed originally with BIG-IP 9.4.7 and then upgraded to BIG-IP 10.1.0 may have a different partition scheme than a BIG-IP 3600 platform with a 320-gigabyte hard disk that was installed with BIG-IP 10.1.0 using the clean installation process.

Partition sizing for two identical systems may appear similar to the following df command output:

For example:

A variety of partitioning schemes have been used over the life of the BIG-IP product. Therefore, if you want to ensure that all appliances of a common hardware and software configuration have the same partition table, you should reinstall both devices using the appropriate clean installation process for the version you want to run.

Note: For specific information about installing BIG-IP software using the clean installation process, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or Enterprise Manager release notes.

In addition, for general information about the BIG-IP 9.x clean installation process, refer to K9589: Installing BIG-IP software from a USB CD-ROM drive. For general information about the BIG-IP 10.x clean installation process, refer to K10819: Performing a clean installation of BIG-IP 10.x or Enterprise Manager 2.x.
