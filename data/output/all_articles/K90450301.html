Description

  • Requests with (Content-Type: application/json) are blocked by ASM
  • False positive attack signatures violation triggered

Environment

  • ASM provisioned
  • ASM security policy
  • Content profile

Cause

Allowed URL is not configured to handled JSON content and the request to the URL contains "Content-Type: application/json. Without a JSON content profile the ASM is unable to parser the JSON content hence it triggers false positive violations.

Recommended Actions

To stop blocking legitimate application/json requests assign a JSON content profile in the Security Policy to the HTTP/HTTPS URL in question

  1. On the GUI go to Security  >  Application Security > URLs > Allowed URLs
  2. Click on Click on URL in question
  3. On Header-Based Content Profiles set
    • Request Header Name: Content-Type
    • Request Header Value: *json*
    • On Request Body Handling: Select JSON Profile Name: You can use the Default one or create a custom one
  4. Click  Add
  5. Click  Update
  6. Apply changes
