Known Issue

This is the result of a known issue. When a user's FirePass client components have been updated using the Automatically Update Components option on the Customize Client Components tab of the Device Management: Client Downloads: Windows (x86) page, the config.f5c file is replaced with a file that does not include the FirePass server list or DNS suffixes; the empty file overwrites the existing file that includes that information. The next time the user attempts to connect to the FirePass controller with the FirePass client, they will not be given a list of FirePass controllers to connect to. The user will have to manually enter either the FirePass controller's Fully Qualified Domain Name or IP address.

F5 Networks Product Development tracked this issue as CR116995 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-610-2 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

The empty config.f5c file can be manually replaced with a pre-populated file on the user's machine. This file is located at C:\Program Files\F5 VPN. Users may also be instructed to manually enter the IP address or the Fully Qualified Domain Name of the FirePass controller that they should connect to. Once they have successfully connected to a FirePass controller, the config.f5c file will be repopulated.
