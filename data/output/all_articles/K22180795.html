Topic

When your BIG-IP system is licensed and configured with the PEM, AFM and ASM modules, the BIG-IP system provides an option for updating the classification signatures and engine. By updating the classification signatures, you maintain the system's ability to discover the enabled application and retrieve the latest signatures.

F5 releases a new classification signature update approximately every four weeks. The signatures include updates to existing applications and new applications requested by customers.

Description

You can find classification signature updates on the F5 Downloads site, listed under your BIG-IP version.

Classification signatures define different types of traffic that the BIG-IP PEM system can recognize through Traffic Intelligence. The BIG-IP PEM system recognizes a predefined set of signatures for common applications and application categories that are updated periodically. You can schedule the system to automatically update the signatures. Alternatively, you can manually install the classification signatures and updates. Manual installation is beneficial for BIG-IP systems without Internet access.

The application signature updates are cumulative; when you update the system-supplied application signatures, the update provides the latest signatures and all signatures from the previous updates. Updating the application signatures also provides any revisions to existing signatures and the engine.

Signature and engine updates are released only for supported software versions. For more information, refer to K5903: BIG-IP software support policy.

Recommendations

You can choose to automatically install an application signatures update from the update server when an update is available or perform a manual installation from an update file you download from the F5 Downloads site. To do so, perform either of the following procedures:

  • Configuring updates for classification signatures
  • Updating classification signatures manually

Configuring updates for classification signatures

Impact of procedure: The signature update process reloads the system configuration and may temporarily interrupt traffic processing. F5 recommends that you perform the signature update during a maintenance window.

  1. Log in to the Configuration utility.
  2. Go to Main > Traffic Intelligence > Classification > Signature Update.
  3. Click Check for Updates to verify that the update server has a new signature file available.
  4. In the Automatic Updates section, click Enabled.
  5. To specify how often you want the system to check for updates, in the Update Schedule setting, click Daily, Weekly, or Monthly.
  6. Click Update.

Updating classification signatures manually

Impact of procedure: The signature update process reloads the system configuration and may temporarily interrupt traffic processing. F5 recommends that you perform the signature update during a maintenance window.

  1. Log in to the Configuration utility.
  2. Go to Main > Traffic Intelligence > Classification > Signature Update.
  3. In the Signature Definitions section, click Import Signatures.
  4. In the Signatures File box, click Choose File to navigate to the locally downloaded signatures file.
  5. Click Upload.
  6. Click Update.
