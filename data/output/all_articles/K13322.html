Topic

Management information base (MIB) files define the SNMP data objects contained in the SNMP MIB. SNMP software uses MIB files to translate codes reported by the BIG-IP SNMP daemon into a user-friendly format. There are two sets of MIB files residing on the BIG-IP system that you can install or compile on your SNMP management station:

  • F5 Enterprise MIB files
  • Standard SNMP MIB files

You can download the MIB files directly from the BIG-IP system by performing one of the following procedures:

  • Download MIB files using the command line
  • Download MIB files using the Configuration utility
  • Download MIB files using iControl REST

Description

The MIB files available on the BIG-IP system are defined below:

F5 Enterprise MIB files

The F5-specific MIB files are included in the mibs_f5.tar.gz file on the BIG-IP system and contain information that your remote management station can use to perform the following tasks:

  • Polling the SNMP agent for BIG-IP system-specific information (GetRequest)
  • Receiving BIG-IP system-specific notifications (Trap)
  • Setting BIG-IP system data (SetRequest)
MIB fileDefinition
F5-BIGIP-APM-MIB.txtDefines APM objects, such as access and connectivity statistics, pool statistics, and general APM information
F5-BIGIP-COMMON-MIB.txtDefines common information for which all other BIG-IP MIB files reference, as well as the F5-specific SNMP traps.
F5-BIGIP-GLOBAL-MIB.txtDefines GTM objects, such as wide IPs, virtual servers, pools, links, servers, and datacenters. You can reset statistics for any of these objects.
F5-BIGIP-LOCAL-MIB.txtDefines LTM objects, such as virtual servers, pools, nodes, profiles, SNATs, health monitors, and iRules. You can reset statistics for any of these objects.
F5-BIGIP-SYSTEM-MIB.txtDefines BIG-IP system information, such as global statistic data, network information, and platform information.
F5-BIGIP-WAM-MIB.txtDefines WebAccelerator traffic objects, such as WebAccelerator specific statistic data, connection stats, or build information.

The Standard SNMP MIB files are included in the mibs_netsnmp.tar.gz file on the BIG-IP system, and contain information that your remote management station can use to perform a wide variety of SNMP-related tasks.

Recommendations

You can download the MIB files using the command line, the Configuration utility, or iControl REST. After you download the MIB compressed TAR files to your SNMP management station, you can decompress and untar (extract) the saved compressed TAR files and then install the MIB files in accordance with your SNMP management station software documentation.

Download MIB files using the command line

Using a command line tool from your workstation, you can download the MIB files from one of the following locations on the BIG-IP system:

  • The /usr/share/snmp/mibs/ directory contains all of the MIB files individually, in text format.
  • The /usr/local/www/docs/mibs/ directory contains compressed TAR files of the F5-specific MIB files (mibs_f5.tar.gz) and non-F5 specific MIB files (mibs_netsnmp.tar.gz).

For information about transfering the MIB files from the BIG-IP system, refer to K175: Transferring files to or from an F5 system.

To decompress and untar the downloaded MIB compressed TAR file, perform the Extract the MIB files from the MIB compressed tar files procedure.

Download MIB files using the Configuration utility

  1. Log in to the Configuration utility.
  2. In the Downloads section of the Welcome page, select Download F5 MIBs (mibs_f5.tar.gz) or Download NET-SNMP MIBs (mibs_netsnmp.tar.gz).
  3. Select a location on your local system to save the file.
  4. Select Save.
  5. To decompress and untar the downloaded MIB compressed TAR file, perform the Extract the MIB files from the MIB compressed TAR files procedure.

Download MIB files using iControl REST

You can copy the MIB compressed TAR files to the /shared/image directory, download them to your SNMP management station and then remove the MIB compressed TAR files copies in the /shared/image directory using the iControl REST API. To do so, perform the following procedure:

Impact of procedure: Performing this procedure should not have an impact on the BIG-IP system.

  1. Log in to your SNMP management station. Your SNMP management station must have the curl and jq utilities installed. If it does not, you should find a workstation that has the curl and jq utilities installed, download the MIB files, and then transfer them to your SNMP management station.
  2. Prior to downloading the MIB compressed TAR files, you need to copy them to the /shared/image directory. To do so, enter the following iControl REST command syntaxes:

    curl -sku <username>:<password> -H "Content-Type: application/json" -X POST https://<IP address>/mgmt/tm/util/bash -d "{\"command\":\"run\",\"utilCmdArgs\":\" -c ' cp -p /usr/local/www/docs/mibs/mibs_f5.tar.gz /shared/images/mibs_f5.tar.gz'\"}" | jq -r .

    curl -sku <username>:<password> -H "Content-Type: application/json" -X POST https://<IP address>/mgmt/tm/util/bash -d "{\"command\":\"run\",\"utilCmdArgs\":\" -c ' cp -p /usr/local/www/docs/mibs/mibs_netsnmp.tar.gz /shared/images/mibs_netsnmp.tar.gz'\"}" | jq -r .

    Replace:

    • <username> with the BIG-IP administrative user such as admin.
    • <password> with the password of the BIG-IP administrative user.
    • <IP address> with the BIG-IP management IP address.
  3. Download the MIB compressed TAR files by entering the following iControl REST command syntaxes:

    curl -ku <username>:<password> -X GET -O https://<IP address>/mgmt/cm/autodeploy/software-image-downloads/mibs_f5.tar.gz

    curl -ku <username>:<password> -X GET -O https://<IP address>/mgmt/cm/autodeploy/software-image-downloads/mibs_netsnmp.tar.gz

    Replace:

    • <username> with the BIG-IP administrative user such as admin.
    • <password> with the password of the BIG-IP administrative user.
    • <IP address> with the BIG-IP management IP address.
  4. When you have successfully downloaded the MIB compressed TAR files, remove the copies you made in step 2 from the /shared/image directory by entering the following iControl REST command syntax:

    curl -sku <username>:<password> -H "Content-Type: application/json" -X POST https://<IP address>/mgmt/tm/util/bash -d "{\"command\":\"run\",\"utilCmdArgs\":\" -c ' rm -rf /shared/images/mibs_*.tar.gz'\"}" | jq -r .

    Replace:

    • <username> with the BIG-IP administrative user such as admin.
    • <password> with the password of the BIG-IP administrative user.
    • <IP address> with the BIG-IP management IP address.
  5. To decompress and untar the downloaded MIB compressed TAR file, perform the Extract the MIB files from the MIB compressed TAR files procedure.

Extract the MIB files from the MIB compressed TAR files

After you have downloaded the MIB compressed TAR files to your SNMP management station, you can decompress and extract the saved MIB compressed TAR files using the Linux tar utility. To do so, perform the following procedure:

  1. Log in to your SNMP management station. If your SNMP management station is not a Linux-based device, you should perform this procedure on a Linux-based device and transfer the extracted MIB files to your SNMP management station.
  2. To decompress and un-tar the MIB compressed TAR file, enter the following command syntax:

    tar -zxvf <filename> -C <target directory>

    Replace:

    • <filename> with either mibs_f5.tar.gz or mibs_netsnmp.tar.gz
    • <target directory> with the directory you want to extract the MIB files to
  3. Transfer the MIB files to your SNMP management station as needed and install the MIB files in accordance with your SNMP management station software documentation.
