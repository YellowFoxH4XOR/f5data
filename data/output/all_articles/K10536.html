Known Issue

This is the result of a known issue. When a remote logging profile is configured for a Web Application and an Illegal HTTP Status in Response violation is triggered, with no other violations triggered, the violation is logged on the remote server but not logged locally, and a learning suggestion is not created.

The expected behavior is to log the violation locally and remotely, and to create a learning suggestion.

F5 Product Development tracked this issue as ID 333001 (formerly CR123840) and it was fixed in BIG-IP ASM 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue was fixed in Hotfix-BIGIP-9.4.8-396.1-HF3 issued for BIG-IP version 9.4.8, and BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
