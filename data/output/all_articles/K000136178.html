K000136178: SAML SLO configured with OneLogin as IdP using their template fails on 16.1 and above

Type
Support Solution
Published
2023-09-13
Updated
2023-09-13
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K000136178

Description

You are using OneLogin as SAML IdP and have SLO configured. You used the OneLogin "F5 BigIP VPN" template to set this up, but it is failing to perform the SAML SLO on BigIP version 16.1 or above.

Additionally, this error can be seen in session logs:

err tmm1[4527]: /Common/Access_Profile_Name:Session:SAML SSO: Invalid SLO request path. Expected (/saml/sp/profile/redirect/sls or /saml/sp/profile/redirect/slo), received (/saml/sp/profile/post/sls?SAMLResponse=<TOKEN>)

Environment

SAML SLO with OneLogin as IdP

Configuration set up using OneLogin F5 app template
BigIP 16.1 or above

Cause

This is due to an Update to SAML Single Logout URLs starting in v16.x (f5.com), which the OneLogin template does not account for. F5 is no longer accepting the old endpoints to perform SAML SLO.

Recommended Actions

You need to modify the endpoints on IdP to match the new ones F5 APM as SP expects. Unfortunately, since you set this up using the OneLogin "F5 BigIP VPN" template which has APM SLO endpoints hard-coded, you cannot change them from there.

The solution is to configure this again using the "Advanced SAML Custom Connector" template, to make sure this sends back the right request (/slo) and of the correct type (POST or REDIRECT).
