Topic

By default, the BIG-IP system includes a platform check that prevents a user configuration set (UCS) archive created on one BIG-IP platform type from being installed on a different BIG-IP platform type. You can use the TMOS Shell (tmsh) to bypass this platform check.

Description

The UCS archive backs up and restores the configuration set of a specific platform. When attempting to install a UCS archive on a dissimilar platform, the configuration may fail to load due to the differing hardware components. When you attempt to load the configuration, these failures require manual intervention to identify and resolve each error presented.

In certain cases, you may want to bypass the BIG-IP platform check. To do so, you can use the no-platform-check option in tmsh. Refer to the following example for the command syntax:

Note: F5 recommends that you use this command under the direction of F5 Technical Support.

tmsh load sys ucs [ucs file name] no-platform-check

When using the tmsh no-platform-check option to install a UCS archive taken from one BIG-IP platform to another BIG-IP platform, there are some potential issues that you should consider:

  • BIG-IP licensing is based in part on the underlying hardware. A new license needs to be generated, based on the new hardware and registration key. Refer to the following articles:
    • K7752: Licensing the BIG-IP system
    • K2595: Activating and installing a license file from the command line
    • K917: Finding the serial number or registration key of your F5 device
    • The Licensing section of K13132: Backing up and restoring BIG-IP configuration files (11.x - 12.x)
  • The device management IP address may change. You will need access to the console to reconfigure the setting. Refer to the following articles:
    • K7683: Connecting a serial terminal to a BIG-IP system
    • K9608: Configuring AOM network access (800, 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 series platforms)
  • The network interface numbering and speed/duplex may be different. Refer to the following article:
    • K14107: Configuring the media speed and duplex settings for network interfaces (11.x - 13.x)
  • In certain BIG-IP versions, the tmsh no-platform-check option may not function as expected. For more information, refer to K16216: The tmsh no-platform-check option may not function as expected

Recommendations

Important: In versions prior to 13.1.0 and 12.1.3, although you can bypass the platform check, F5 does not currently have a supported method for migrating UCS files between dissimilar BIG-IP platforms.  For example, performing a ConfigSync between different hardware platform types or between hardware and a virtual edition. In 13.1.0 and later, and 12.1.3 and later, refer to K82540512: Overview of the UCS archive platform-migrate option.  

When migrating between dissimilar BIG-IP platforms, F5 recommends that you use the single configuration file (SCF) feature. For more information about SCF, refer to K13408: Overview of single configuration files (11.x - 13.x).
