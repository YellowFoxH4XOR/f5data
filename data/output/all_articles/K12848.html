Known Issue

A small number of early ARX 500 platforms were not programed with the chassis serial number.

Impact

You must physically obtain the ARX serial number.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The serial number is not displayed in the show chassis chassinfo command output.
  • The serial number is not displayed in the ARX Manager GUI Chassis Summary page.
  • The F5 Upgrade Licensing server is unable to provide a Base Registration Key.

    Note: You must have a Base Registration Key to obtain an ARX license, and you must have an ARX license to upgrade to ARX version 6.0.0 and later. If you are affected by this issue and require a Base Registration Key, contact F5 Technical Support for assistance.

Resolution

Status

F5 Product Development has assigned ID 351073 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can physically locate the serial number on the product information sticker located on top of the chassis, on the front right corner of the system.

Impact of workaround: None
