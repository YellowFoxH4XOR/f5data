Description

The root certificate is about to expire, but the intermediate certificate is still valid. The question arises whether renewing the intermediate certificate is needed too.

Environment

  • BIG-IP 
  • Chain Certificate
  • Root certificate expiring

Cause

Need to renew root certificate

Recommended Actions

If Intermediate certificate is still valid, it is optional whether to renew it or not.
