Description

This article will show how you can view the number of active connections on the BIG-IP. 

Environment

You want to verify the statistics and counters that show the number of active/current connections.

  • You have access to the BIG IP Configuration Utility
  • You have access to the command line (TMOS shell)
  • You have several virtual servers configured on the BIG-IP

Cause

You want to verify the number of active/current connections on the BIG-IP.
You receive an alert from an external monitor system where the number of connections has exceeded the configured threshold.

Recommended Actions

  1. Verify your hardware specifications and the number of connections supported. 
    Go to https://www.f5.com/products

    For example, you have a Viprion with one 4300 blade. The hardware datasheet (https://www.f5.com/pdf/products/viprion-overview-ds.pdf page 9) lists the following specifications for this blade:

    • 2M L7 requests per second (B4340N)
    • 2.5M L7 requests per second (B4300)
    • 1.1M L4 connections per second (B4340N)
    • 1.4M L4 connections per second (B4300)
    • 14M L4 HTTP requests per second
    • 36M max L4 concurrent connections (B4300)
    • 72M max L4 concurrent connections (B4340N)
    • 80 Gbps L4, 40 Gbps L7
    • 1.2 Gbps included compression
    • 20 Gbps max hardware compression
    • Included SSL TPS: 12,000/blade
    • Max SSL TPS: 30,000 (2K keys)
    • Bulk crypto: 20 Gbps
  2. Verify active connections from the Configuration utility. Skip to the next step to view active connections from the command line.
    Go to Statistics > Performance Reports > select a period of time (for example 30 days)

    It will provide you a reference of how many connections you have. For a larger period, it will show you an average, and if you have some traffic peaks, you won't be able to see it. For those traffic peaks, you can use 3 hours.

Gathering virtual server statistics with SNMP polling

To query the BIG-IP via SNMP for virtual server statistics, the following OIDs listed under ltmVirtualServStat within the F5-BIGIP-LOCAL-MIB can be used:
Note: While the tmsh command list Bits In and Bits Out, the same SNMP OID reports the values in bytes. To convert the value to bits, multiply the output by 8 to convert.
 
Bytes In and Out:
ltmVirtualServStatClientBytesIn.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"
ltmVirtualServStatClientBytesOut.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"

Packets In and Out:
ltmVirtualServStatClientPktsIn.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"
ltmVirtualServStatClientPktsOut.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"

Current, Maximum, and Total Connections:
ltmVirtualServStatClientCurConns.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"
ltmVirtualServStatClientMaxConns.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"
ltmVirtualServStatClientTotConns.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"

Evicted and Slow Connections:
ltmVirtualServStatClientEvictedConns.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"
ltmVirtualServStatClientSlowKilled.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"

Min, Max, and Mean Connection Duration:
ltmVirtualServStatCsMinConnDur.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"
ltmVirtualServStatCsMaxConnDur.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"
ltmVirtualServStatCsMeanConnDur.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"

Total Requests:
ltmVirtualServStatTotRequests.\"/<Partition Virtual Resides In>/<Name of Virtual Server>\"

For example, to get an SNMP OID value from the system locally, you can perform the following:

1. Log into the command line

2. From the command line, enter the following command to get the total requests for example.com:

snmpget -v 2c -c public localhost ltmVirtualServStatTotRequests.\"/Common/example.com\"

The output will look similar to the following:

F5-BIGIP-LOCAL-MIB::ltmVirtualServStatTotRequests."/Common/HTTPVirtual" = Counter64: 17
