Description
Starting in versions 11.6.3.3 and 12.0.0 the Configuration Utility and TMSH now accept all printable ASCII characters as a SSL Profile key passphrase.

Environment

  • BIG-IP version 11.6.3.3 or 12.0.0 and later
  • SSL Profile with passphrase utilized for the SSL Key

Cause
There are minor limitations around the input of SSL Profile key passphrases, depending on the method used to enter the passphrase (CLI or Configuration Utility).

When using the Configuration Utility to enter a SSL Profile key passphrase, note that any leading or trailing spaces will be trimmed from the passphrase. The passphrase " leading_space" will be saved as "leading_space" (without the first character, a space) and the passphrase "trailing_space " will be saved as "trailing_space" (without the last character, a space).

When using TMSH to enter a SSL Profile key passphrase, ensure the passphrase is enclosed in double quotes and escape with a backslash the double quotes character ("), question mark character (?) and backslash character (\).

Here is an example of the same legal SSL Profile key passphrase entered both in Configuration Utility and TMSH/CLI.

Configuration Utility:
!"#$%&'( )*+,-./0123456789:;<=>?@ABCDEFGHIJKLMNOPQRSTUVWXYZ[\]^_`abcdefghijklmnopqrstuvwxyz{|}~

TMSH/CLI:
 "!\"#$%&'( )*+,-./0123456789:;<=>\?@ABCDEFGHIJKLMNOPQRSTUVWXYZ[\\]^_`abcdefghijklmnopqrstuvwxyz{|}~"

Note how the TMSH/CLI passphrase contains 5 more characters because it has the enclosing double quotes and three backslashes to escape the double quotes, question mark and backslash characters.

Recommended Actions

None
