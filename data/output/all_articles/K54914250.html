Description

You see traffic for one or more of your pool members is leaving the BIG-IP from the wrong Self-IP

Environment

  • BIG-IP LTM
  • Pool in a network segment without a floating Self-IP

Cause

BIG-IP will try to send traffic out the best match floating Self-IP before trying to use the non-floating Self-IPs, potentially causing the BIG-IP to send traffic out the wrong Self-IP

Recommended Actions

Review Self-IP configuration and ensure that you have both a floating and non-floating Self-IP configured for each attached network segment

Additional Information

None
