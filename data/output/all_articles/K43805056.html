Description

When parsing a range of logs with the tmsh show /sys log <module> command, no logs are shown.

Environment

  • Traffic Management Shell (tmsh) access.
  • Local Logs

Cause

If a given range has to parse through more than 10,000 lines, then show /sys log <module> command will stop <exit> with this message:

    Sys::Log
    --------------------------------------------
    Maximum line count (10000) exceeded
    Specify a narrower range or increase maximum
    --------------------------------------------

Recommended Actions

If the logs exceed the default maximum line count of 10000 and you want to view more or less than this default line count, you can specify your desired value using the lines option:

tmsh show /sys log <module> lines <maximum line count>

Note: Displaying beyond the default maximum line count may compete for more resources on a heavily utilized system.You should ensure your system has sufficient resources to display the logs beyond the default maximum line count of 10000. Alternatively, you should perform this when the system is less utilized.

For more information about other options such as date range when viewing local logs, refer to K16197: Reviewing BIG-IP log files.
