K000146818: How to filter/view WAF events by Support ID number

Type
Support Solution
Published
2024-11-08
Updated
2025-12-31
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Apps
  • F5 Distributed Cloud Multi-Cloud App Connect
Source
https://my.f5.com/manage/s/article/K000146818

Description

  • You want to filter a Support ID to view more in-depth information about the event
  • You tried to access a URL and got rejected with a warning page and a support ID number
    • The message states: "The requested URL was rejected. Please consult with your administrator. Your support ID is: ..."

Environment

  • F5® Distributed Cloud Console

 

Cause

Request gets blocked or rejected and generates a support ID that it's easy to find in the XC console.

Recommended Actions

Once you see the error message, please follow these steps: 

1. Copy the support ID shown in the error message

2. Go to Web App & API protection > [NAMESPACE] > Dashboards > Security Dashboards

3. At the bottom of the Dashboard > Search and click on the related Load Balancer

4. Go to Security Analytics

5. Click on Add Filter

6. Select req_idand paste the Support ID into the field

7. Click Apply

8. The event will be filtered there with more details

 

Additional Information

You can create WAF exclusion rules based on the support ID event. For the creation of a WAF exclusion rule you have to click the 3 dots under Actions and select: Create WAF exclusion rule
