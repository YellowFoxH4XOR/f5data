Known Issue

This is the result of a known issue. If you enable the WebAccelerator module on a 3900 platform, the BIG-IP system does not provision enough memory for the module, even if the Dedicated option is selected in the Resource Provisioning menu. As a result, the BIG-IP WebAccelerator performance may degrade.

F5 Product Development tracked this issue as ID 242875 (formerly CR135098), and it was fixed in BIG-IP version 10.2.0 through the use of custom provisioning tables. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue has been fixed in cumulative Hotfix-BIGIP-10.1.0-3372.0-HF1 through the use of custom provisioning tables, which has been issued for BIG-IP version 10.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

Important: To use the custom provisioning tables introduced in Hotfix-BIGIP-10.1.0-3372.0-HF1 and BIG-IP version 10.2.0, you must apply the provisioning levels specified in K11982: Recommended provisioning for BIG-IP WebAccelerator version 10.x. If you do not use the recommended provisioning levels, you cannot reference the custom tables, and the BIG-IP WebAccelerator may continue to have insufficient memory resources.

For information about installing version 10.x hotfixes, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.
