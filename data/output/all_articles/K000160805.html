K000160805: Time zone synchronization between the NTP server and rSeries tenants not working

Type
Support Solution
Published
2026-04-15
Updated
2026-05-19
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160805

Description

When using the America/Santiago time zone on a BIG-IP LTM tenant, the system does not automatically adjust for daylight saving time (DST) transitions, even though the rSeries host updates correctly. This results in the BIG-IP LTM tenant displaying the incorrect local time after DST changes.

 

Environment

BIG-IP LTM tenant, version 17.5.1

Platform: F5-BIG-BT-R5600, C129 (rSeries)

Location: Chile (DST observed, GMT-4 to GMT-3 transitions)

 

 

Cause

The root cause is an outdated tzdata (time zone database) on the BIG-IP LTM tenant. The version in v17.5.1.3, v17.5.1.5, and v21.0.0.1 is tzdata 2018e, which does not reflect recent Chilean DST rule changes.
This mismatch in tzdata versions between the host and tenant leads to the observed DST transition discrepancy.
A new bug (id 2277461) has been filed to update BIG-IP tzdata from 2018e to 2026a.

 

 

Answer/Recommended Actions

As a temporary workaround, set the tenant’s time zone to UTC and manually adjust as needed.
