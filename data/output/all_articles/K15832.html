Known Issue

Firefox 26, and later versions, may stop responding when accessing some web applications using portal access.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured to provide portal access for the web application.
  • Firefox 26, or a later version, is used to access the web application.
  • During webpage rendering, objects load from the browser cache while there are scripts to be loaded synchronously on the webpage.

Impact

The browser stops responding, and the webpage stops loading without displaying error messages.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You can load the web application page initially, but the webpage stops responding when you attempt to refresh or view the webpage again.
  • Users cannot fully render webpages that contain code for Google Analytics.
