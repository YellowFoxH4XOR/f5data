Known Issue

This is the result of a known issue. iControl communication issues may affect licensing for BIG-IP and Enterprise Manager systems. Specifically, iControl calls to Management::LicenseAdministration::install_license() with a well-formed license and a valid user returns the following error:

iControl::OperationFailed - primary code:16908289(0x1020001) secondary code: 0(0x0) string: Error copying temporary files

F5 Product Development tracked this issue as CR71959 and it was fixed in Enterprise Manager 1.2.2. For information about upgrading, refer to the Enterprise Manager release notes.

F5 Product Development tracked this issue as CR71959 for the BIG-IP system and it was fixed in BIG-IP versions 9.1.3, 9.3.0 and 9.4.1. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller release notes.
