K90928580: Error when adding a DCD device to BIGIQ Centralized Management on different versions

Type
Support Solution
Published
2020-10-22
Updated
2022-12-30
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.0.X, 7.0.0, 6.1.X, 7.X.X, 6.X.X
Source
https://my.f5.com/manage/s/article/K90928580

Description

Error when adding a DCD Device to BIGIQ Centralized Management

  • When attempting to add a DCD device to BIGIQ CM
  • Unable to add a DCD device to BIGIQ CM
  • Error message 
    [ERROR][DD MMM YYYY HH:MM:SS Timezone][/shared/device-discovery-tasks DeviceDiscoveryTaskCollectionWorker] Unable to discover peer BIG-IQ, versions are not equal. Local REST framework version: 7.0.0-0.0.718, remote REST framework version: 6.1.0-0.0.1224. Please ensure versions are the same
    [ERROR][DD MMM YYYY HH:MM:SS Timezone][/cm/shared/esmgmt/add-node/<UUID>/worker ESAddNodeTaskWorker] Discovery of BIG-IQ Data Collection Device 10.200.150.167 failed with state POST_FAILED and due to
    error 'Unable to discover peer BIG-IQ, versions are not equal. Local REST framework version:
    7.0.0-0.0.718, remote REST framework version: 6.1.0-0.0.1224. Please ensure versions are the same'

Environment

  • BIGIQ CM running version 7.0.0
  • BIGIQ DCD running version 6.1.0

Cause

Unable to discover peer BIGIQ due to different versions

Recommended Actions

  1. Ensure versions are the same between Central Management and Data Collection Device
  2. You can go the upgrade manual to perform the upgrade by follow this link - Manual
