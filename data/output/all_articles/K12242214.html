Description

What data to provide to Aspen Mesh Support when troubleshooting.

Environment

  • Kubernetes: 1.17x,1.18.x,1.19.x,1.20.x 
  • Aspen Mesh: 1.9.x, 1.11.x, 1.14.x 

Cause

If you are running into an issue with Aspen Mesh, we require log files to perform an analysis and get your service mesh up and running.

Recommended Actions

  • Use you istioctl command line tool to retrieve all components status, logs, and configuration from your environment
  • Perform troubleshooting or manual data gathering
  • Collect additional info from your environment

Use you istioctl command line tool to retrieve all components status, logs, and configuration from your environment.

In Aspen Mesh 1.9.x and above, you could easily retrieve data such as logs, configuration files, resources configurations, etc.

  1. Find the istioctl binary or export to your PATH environmental variable. For example:

    export PATH=$HOME/aspenmesh-1.9.1-am3/bin:$PATH

  2. Run the following command:

    istioctl bug-report

  3. The bug-report will retrieve everything to diagnose any issue with your service mesh, it will create .tgz file under the path you are executing the command.
  4. Since the report is already compressed, you can easily get it from your client and send it to Aspen Mesh Support.

Perform troubleshooting or manual data gathering.

If you own or made a script to retrieve data or you are running a version of Aspen Mesh before 1.9.x, Aspen Mesh Support will require at least the following information.

  1. All proxies' logs or the affected ones.
  2. All proxy's configuration files.
  3. Configuration resources like VirtualServices, DestinationRules, ServiceEntry, Gateways, Envoyfilters. For example:

    kubectl get -n <namespace> <resource-name> -o yaml > <resource-name>.yaml

    Note: use oc or kubectl according your needs.
  4. Logs from all the pods in the istio-system namespace.
  5. Helm override file that was used to install Aspen Mesh.

If you are running into issues while gathering logs or need assistance, refer to the following AskF5 Support Solutions:

  • K67125033: Aspen Mesh: How to get istio-proxy logs
  • K50554509: Basic troubleshooting commands for istio-proxy in Aspen Mesh

Collect additional info from your environment

When you submit a case to Aspen Mesh Support, provide the following information to ensure that your issue is resolved efficiently:

  • Version of Aspen Mesh
  • Version of Kubernetes
  • Environment
  • Description of problem and symptoms (only one problem description per request)
  • When did you notice the issue?
  • What changes were recently made to the environment?
  • Steps to reproduce issue
  • Log files and all other relevant output
  • What’s the business impact?
  • Case Severity
