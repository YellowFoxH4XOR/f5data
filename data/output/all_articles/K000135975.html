K000135975: [RFI] Regarding DAG using TEID hashing for GTP tunnels in Hardware in v16.1

Type
Support Solution
Published
2023-08-25
Updated
2023-08-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.0
Source
https://my.f5.com/manage/s/article/K000135975

Description

TEID hashing DAG enabled by DB key in 17.0.0.

Environment

BIG-IP with GTP-U Tunneling

Cause

NA

Recommended Actions

To enable TEID DAG, you must enable the iptunnel.gtp.teid_hash db key:


tmsh modify sys db iptunnel.gtp.teid_hash value enable


To disable TEID DAG:


tmsh modify sys db iptunnel.gtp.teid_hash value disable


Additional Information

As of 17.0.0 TEID disaggregation should work regardless of hardware, but there may be a CPU hit. See Bug ID 1049213: A new disaggregation (DAG) mode based on TEID field in GTP-U header is introduced for more information.
