Known Issue

This is the result of a known issue. The registration key is not displayed in the Licensing portion of the Configuration utility following an upgrade. This behavior affects any platform (except VIPRION) that was upgraded to BIG-IP 10.1.0 before it was licensed.

Note: The VIPRION blades are not affected by this issue as the registration key is contained within the hardware and not within the /config/RegKey.license file.

Important: This issue is cosmetic only and does not affect the ability to license the unit.

F5 Product Development is tracking this issue as CR133932.

Workaround

If you encounter this issue, you can obtain the registration key and license the platform. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Display the registration key located in the /config/RegKey.license file by typing the following command:

    cat /config/RegKey.license
  3. Copy the registration key into the Configuration utility Licensing screen to register and license the system.

Note: If the /config/RegKey.license file is missing, refer to K3782: Finding the serial number or registration key of your BIG-IP system.
