Description
When displaying the network interface status from the CLI with tmsh show /net interface, the interfaces appear to be disabled, however they can still be reached by pinging them from the peer BIG-IP.

Environment

  • Network Interfaces

Cause
Bug ID 471860: Disabling interface keeps DISABLED state even after enabling

Recommended Actions
Upgrade to a version where ID is fixed. To workaround the issue on affected versions, simply reboot the device as explained on the following article: K16209: After a disabled interface is enabled on BIG-IP VE, the interface may continue to appear disabled

Additional Information
You can see the enabled status on the interfaces using tmsh list /net interface, instead of tmsh show /net interface.
