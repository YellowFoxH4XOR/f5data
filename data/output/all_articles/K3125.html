Topic

The FirePass controller supports the TN3270 terminal emulation protocol for legacy host favorites, and does not currently support the TN3270E (TN3270 enhanced) protocol for legacy host favorites.

F5 Product Development tracked a request for enhancement (RFE) as ID 275106 to provide support for the TN3270E terminal emulation protocol. F5 added support for this protocol in FirePass 6.0.0. Support for LU names has not been implemented at this time.
