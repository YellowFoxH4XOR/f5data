Issue

Error Message

010719ba:3: Auto-blacklisting feature can only be set for Sweep attack vectors

Note: F5 is working to eliminate exclusionary language in our products and documentation. For more information, refer to K34150231: Exclusionary language in F5 products and documentation.

Message Location

You may encounter this message in the following locations:

  • Traffic Management Shell (tmsh) prompt
  • /var/log/ltm

Description

This message occurs when the following condition is met:

  • Using tmsh in the attempt to configure auto-blacklist option using the dos-device-vector configuration options.

    For example, the following tmsh command will result with the following error message:

    modify /security dos device-config dos-device-config dos-device-vector { bad-icmp-chksum { auto-blacklisting enabled blacklist-category denial_of_service } }

Only the Single Endpoint Sweep vector supports the auto-blacklist configuration option. Any attempt to configure auto-blacklist on other denial-of-service (DoS) vectors will encounter the previous error message. This behavior is expected.
