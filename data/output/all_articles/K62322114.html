Description

Not able to access the F5 BIG-IP Configuration Terminal (GUI) and command line (ssh) when license has expired.

Environment

This issue occurs when all the following conditions are met:

  • BIG-IP
  • BIG-IP license has expired
  • Management Interface is not used for administrative access
  • Administrative access is via the F5 BIG-IP's Self IP (including inline connectivity)

Cause

  • Administrative access via Self IP (including inline connectivity) will be processed by the BIG-IP's Traffic Management Microkernel (TMM).
  • TMM will only process traffic when the BIG-IP has a valid license.
  • The issue is an expected behavior as administrative access traffic will not be processed by TMM when license has expired.
  • Administrative access via Management Interface will not be impacted as this interface is being process by the Linux kernel and does not require a valid license.

Recommended Actions

To permanently resolve this issue, you will need to have a valid license. Please reach out to your local F5 Sales representative to acquire a valid license.
Once you have the valid license, you will need to gain temporary management access via console access.

  1. Long in to the BIG-IP system via console access.
  2. You will need to manually change the date of the device before license expiry date. To change the time, use the following command syntax:
    date <month><day><hour><minute><year>.<second>
    The specifi format is as follows:
    date MMDDHHMMYYYY.SS
    For example, if you license expires on January 20, 2020, you can revert the date of the machine a day before which is January 19, 2020. The command would be:
    date 011912002020.00
  3. To ensure that the BIG-IP system works correctly, you will need to restart the BIG-IP system with the following command:
    reboot
  4. Once the BIG-IP system has restarted, check the current date using the following command:
    date
  5. If the date has changed back to the current date instead of the manual date, the BIG-IP system is still getting date change update from the NTP server. You will need to stop the NTP service. Please run the following command:
    bigstart stop ntpd
  6. You will need to repeat step 2 to manually change the date again.
  7. Once the BIG-IP system is using the manual date which you have entered, you will be able to gain temporary access to the Configuration Terminal and update the license.
  8. Navigate to System > License.
  9. Click Re-active.
  10. Click Edit in Base Registration Key.
  11. Enter the new Base Registration Key which you have obtained from the F5 Sales representative.
  12. Click Next.
  13. Once you have correctly change the license, you will need to manually revert the date and time to the current date using step 2.
  14. If you need to restart the ntpd service, use the following command:
    bigstart start ntpd
