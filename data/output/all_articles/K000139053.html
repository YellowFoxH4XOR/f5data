Description

MAC masquerade not working in r2000/r4000 Series Appliance

Environment

  • r2000/r4000 rSeries Appliance (Pantera)
  • BIG-IP Tenant HA pair

Cause

Bug ID 1325737: Standby tenant cannot access floating traffic group when MAC masquerade is enabled

Recommended Actions

Disable MAC masquerade

Check ID 1325737 for fixed version. Contact F5 Support for Hotfix.
