Description

You are running BIG-IP APM in a high availability two device (HA) configuration and would like to confirm session failover behavior and that the BIG-IP APM is correctly configured to successfully synchronize session state information.

Environment

  • BIG-IP APM
  • HA
  • Session synchronization

Cause

None

Recommended Actions

The BIG-IP APM devices used in the HA (active-standby) configuration must meet the following requirements.

  • Established device trust between two BIG-IP APM systems.
  • Configured a sync-failover device group.
  • The BIG-IP APM peer devices (2) must use the same traffic group..
  • BIG-IP APM peer devices must use identical hardware and run the same software version including hotfix level.
  • The BIG-IP APM devices must be configured with a local mirror addresses and an active mirroring channel.



Expected Failover and user session synchronization behavior.

  • Maintains active BIG-IP APM sessions
  • Resets TCP and PPP connections
  • Automatically renegotiates disconnected client network connections
  • Maintains user sessions, including session state information
  • Will re-establish client applications connections when the tunneled protocol supports automatic reconnect (such as VPN and RDP protocols).
