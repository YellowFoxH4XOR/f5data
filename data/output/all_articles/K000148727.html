K000148727: Qualys scan detects SHA1 as a deprecated setting for SSH vulnerability.

Type
Support Solution
Published
2024-12-26
Updated
2025-11-21
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000148727

Description

A Qualys scan may flag the use of the SHA1 algorithm in SSH configurations as a deprecated setting, indicating potential vulnerabilities. Since 2011, SHA1 has been deprecated by the National Institute of Standards and Technology (NIST) and is considered cryptographically weak.

Environment

  • BIG-IP All versions
  • Qualys vulnerability scan
  • SSH ciphers

Cause

SHA1 is vulnerable to collision attacks and no longer meets modern security standards, making its use a potential risk.

Recommended Actions

If you determine that SHA1 is not required in your environment, you can disable it by following these steps:

  1. Check the SSH configuration file to identify if SHA1 is listed. 
    egrep -i 'MACS|Ciphers|KeyAlgorithms' /config/ssh/sshd_config
  2. Access BIG-IP's tmsh. Use the following command to modify the SSH settings:
    tmsh
edit /sys sshd all-properties
    This opens the configuration file in the vi editor.
  3. Modify the include lines to remove any SHA1 reference. If the"include" parameters is set to "none", it will be necessary to create a new string, same as the following example.  include "Ciphers 3des-cbc,aes128-cbc,aes192-cbc,aes256-cbc,aes128-ctr
    MACs hmac-sha2-256,hmac-sha2-512
    KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384"
    For more information, follow the below article:
    1. K000149087: Create a valid string of ciphers to use as part of the SSHD configuration. 
    2. K80425458: Modifying the list of ciphers and MAC and key exchange algorithms used by the SSH service on the BIG-IP or BIG-IQ systems
  4. To apply and persist the changes, execute the following command: 
    save /sys config

Additional Information

As specified in the /config/ssh/sshd_config file, entries such as 'MACS' or 'Protocol' may appear more than once within the file, however only the first instance (from the top-down) are honored:

# F5 Note
# If a directive appears multiple times, its first instance will be used

# have been configured via 'tmsh sys sshd include' and will therefore take
