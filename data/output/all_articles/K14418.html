Known Issue

Mirroring may fail for FTP virtual server connections.

This issue occurs when all of the following conditions are met:

  • The FTP profile has Inherit Parent Profile enabled.
  • The virtual server has connection mirroring enabled.

The FTP data channel is not mirrored properly to the standby device.

Impact

The FTP data channel will be reset for the established FTP connection.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H480581 on the Diagnostics > Identified > Medium screen.
  • The FTP data channel cannot be used after failover.
  • An ongoing FTP transfer may halt or abruptly terminate.

Workaround

There is no workaround for this issue. However, you can mitigate this issue by disabling Inherit Parent Profile on the affected FTP profile. To do so, perform the following procedure:

Impact of workaround: Disabling the Inherit Parent Profile setting causes the data channel to use FastL4 instead of TCP. When changes are applied to the FTP profile, virtual servers using the affected FTP profile may have service disruption. F5 recommends that you perform this modification during a maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles.
  3. Click Services.
  4. Select FTP.
  5. Select the FTP profile that is affected by this issue.
  6. In the Settings section, clear the box next to Inherit Parent Profile.
  7. Click Update.
