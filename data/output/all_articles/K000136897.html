Description

Base64 xml file uploads are not being recognized and sent to the ICAP Server in the ASM Policy.

Environment

  • BIG-IP ASM

Cause

You have set the XML corresponding element as sensitive parameter.

Recommended Actions

None

Additional Information

When the xml profile is given in the anti virus configuration, it will look for whatever is defined as sensitive data in the xml profile (namespace/atrribute/element). If that is found, all the xml payload will be given to the icap inspection, without decoding the base64 payload.
