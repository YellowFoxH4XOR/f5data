Description

Windows displays a popup window when connecting to a VPN service

Environment

  • VPN connection
  • Executing scripts automatically
Cause

If an application or script is triggered to execute automatically when a VPN tunnel is established, it is optional to alert the user of this.
Which gives them the opportunity to allow or not allow the script or application to run.

Recommended Actions

To disable the feature as a BIG-IP APM administrator, do the following:
  1. Login to the Configuration utility of the BIG-IP system.
  2. Navigate to : Access > Connectivity / VPN > Network Access (VPN) > Network Access Lists
  3. Click on the appropriate Network Access resource
  4. Click the Launch Applications tab
  5. Remove the tick from the checkbox for Display warning before launching applications  
  6. Click Update.
