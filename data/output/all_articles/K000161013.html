Description

After de-provisioning the Access Policy Manager (APM) module on a BIG-IP system, the default EPSEC package file remains in the filestore and is referenced in the configuration. This file is included in User Configuration Set (UCS) backups, resulting in significantly larger UCS file sizes. Attempts to remove the file using standard CLI or GUI methods fail, as the file is marked as a system package and cannot be deleted through supported interfaces and the delete button disabled in the GUI. 

 

  • 01071554:3: EPSEC - Cannot delete epsec system package file

This article provides a supported method to remove the EPSEC package and reduce UCS file size.

Environment

  • BIG-IP APM
  • EPSEC package

Cause

The default EPSEC package is marked as a system package (system-package true) and is not automatically removed. By design, this prevents deletion via standard CLI or GUI methods, ensuring system integrity if APM is re-provisioned in the future. As a result, the file remains on disk and is included in UCS backups.

Answer/Recommended Actions

Important: Always take a UCS backup before making any changes.

  1. Create a UCS backup:
    tmsh save sys ucs /var/local/ucs/pre_epsec_cleanup.ucs
  2. Backup the current configuration file:
    cp /config/bigip.conf /config/bigip.conf.pre_epsec_backup
  3. Edit the configuration file to remove the EPSEC reference:
    • Open /config/bigip.conf in a text editor (e.g., vi).
    • Locate and delete the following block:

    apm epsec epsec-package /Common/epsec-1.0.0-1963.0.iso {

    cache-path /config/filestore/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1963.0.iso_*

    oesis-version 4.3.5302.0

    revision 1

    version 1.0.0-1963.0

    }

    • Save and exit the editor.
  4. Verify the configuration:
    tmsh load sys config verify
  5. Reload the configuration:
    tmsh load sys config
  6. Delete the EPSEC ISO file from the filestore:
    rm /config/filestore/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1963.0.iso_*
  7. Save the configuration:
    tmsh save sys config
  8. Verify removal:
    • Check for any remaining EPSEC references:

    grep epsec /config/bigip.conf

    ls -la /config/filestore/files_d/Common_d/epsec_package_d/

    tmsh list /apm epsec epsec-package recursive

  9. Create a new UCS backup and check its size:

    tmsh save sys ucs /var/local/ucs/post_epsec_cleanup.ucs

    ls -lh /var/local/ucs/post_epsec_cleanup.ucs

  10. If using an HA pair:
    • Repeat the process on the other unit before performing ConfigSync.
