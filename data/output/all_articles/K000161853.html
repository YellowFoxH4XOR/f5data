K000161853: F5OS Terraform Provider Proxy Issue

Type
Support Solution
Published
2026-06-23
Updated
2026-06-23
Source
https://my.f5.com/manage/s/article/K000161853

Description

The F5OS Terraform provider fails to establish a connection when deployed in an environment requiring HTTP/HTTPS proxy usage, despite proper configuration of proxy environment variables such as http_proxy, https_proxy, HTTP_PROXY, and HTTPS_PROXY. The provider attempts direct connections to the F5OS management endpoint, resulting in timeout errors like:

Error: Get "https://gbwdclabah003.systems.uk.hsbc:443/api/data/openconfig-system:system/aaa": dial tcp 10.79.251.25:443: connect: connection timed out

In some instances, the error Error: Invalid provider configuration is reported, but the root cause lies in the provider's inability to route traffic through the configured proxy.

Environment

  • F5OS Terraform provider version 1.10.1
  • Terraform version v1.14.0
  • F5OS version 1.8.3
  • Deployment environment with restricted direct access to management endpoints, requiring all outbound connections to traverse a proxy that supports HTTP CONNECT on port 8888

Cause

The F5OS Terraform provider in version 1.10.1 does not support proxy configuration and ignores the specified proxy environment variables during connection attempts.

Answer/Recommended Actions

  1. Upgrade the F5OS Terraform provider to version 1.10.2 or later, which includes a fix for proxy handling.
  2. Ensure that the automation platform exports the required proxy variables (http_proxy, https_proxy, HTTP_PROXY, HTTPS_PROXY) correctly.
  3. Confirm that the proxy allows the HTTP CONNECT method for port 8888 destinations.
  4. After upgrading, re-run terraform plan or apply to verify successful connection through the proxy.
  5. The updated provider can be downloaded from: https://registry.terraform.io/providers/F5Networks/f5os/latest

Impact of workaround: Upgrading the provider will require a re-run of all Terraform workflows, which may cause temporary disruption in automation pipelines.

Additional Information

The issue was reproduced in internal lab testing and confirmed as a limitation in version 1.10.1. A curl command executed from the same environment may succeed via the proxy, indicating that general network reachability is functional; however, the Terraform provider continues to fail due to lack of proxy support. This discrepancy confirms the issue is specific to the provider’s connection logic. The fix was included in version 1.10.2.
