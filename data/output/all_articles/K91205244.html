Issue

Error Message

01070622:3: The monitor <monitor name> has a wildcard destination service and cannot be associated with a node that has a zero service.

In this error message, note the following:

  • <monitor name> is the name of the monitor that requires a destination port

For example:

01070622:3: The monitor /Common/http has a wildcard destination service and cannot be associated with a node that has a zero service.

Message Location

You may encounter this message in the following location[s]:

  • /var/log/ltm
Description

This message occurs when the following condition is met:

  • Occurs when attempting to associate a Pool member with zero port; associated with a monitor that requires a port (for example TCP, HTTP or HTTPS).

Impact

Monitors that require a destination port cannot be associated with pool members where the port is unspecified or zero.
 

Recommended Actions

Assure that the pool member has a non-zero specified port.
