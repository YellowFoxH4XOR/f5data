Known Issue

Border Gateway Protocol (BGP) last update timer may incorrectly reset to 0.

This issue occurs when the following condition is met:

  • The routing table contains BGP routes and the scan-time resets.

Impact

There is no impact; you can safely ignore this issue.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you display the routing table with the show ip route command, the last update timer for route entries is set to 0.

Resolution

Status
