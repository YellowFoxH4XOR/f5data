Issue

Error Message

A device with IP address <IP-Address> has already been added to BIG-IQ.

In this error message, note the following:

  • <IP-Address> is the IP address of the BIG-IP device that the system is attempting to discover.

For example:

A device with IP address 10.10.10.100 has already been added to BIG-IQ.

Message Location

You may encounter this message in the following locations:

  • On the BIG-IQ system user interface
  • In the BIG-IQ system restjavad log file /var/log/restjavad.0.log

Description

The error message for this issue varies depending on which version of BIG-IQ software you are running. This article discusses the error message that applies to BIG-IQ 5.0.0 - 5.1.0; for other BIG-IQ versions, refer to the following articles:

  • For BIG-IQ 5.2.0 and later, refer to K15938: Error Message: BIG-IQ has already discovered a device (<IP-Address>) with this machine ID
  • For BIG-IQ 4.5.0 - 4.6.0, refer to K01721712: Error Message: Unable to discover the device to be managed, reason(Duplicate item. Key already exists: deviceUri: https://<IP-Address>:443)

This message occurs when one of the following conditions is met:

  • You have cloned the BIG-IP Virtual Edition (VE) instance from an existing instance, and the BIG-IQ system is attempting to discover the cloned instance.
  • You got a user configuration set (UCS) archive file from one BIG-IP device and deployed it on another device by manually editing the configuration file, and the BIG-IQ system is attempting to discover the device with the edited configuration file.

If you encounter either of the previously mentioned scenarios, you will have two BIG-IP devices that share an identical REST device ID file. The subsequent discovery then fails because the duplicate REST device ID file on one BIG-IP device matches a BIG-IP device that has already been discovered by the BIG-IQ system. The REST device ID file is located in the /config/f5-rest-device-id file.

Impact

The system is unable to discover the device. In addition, the system may overwrite the existing device that has the same device ID file.

Recommended Actions

You can generate a new device ID file for the affected BIG-IP device by performing the following procedure:

Impact of recommended actions: The following procedure requires that you restart the restjavad process, therefore, the REST interface of this device will not be available while the system is restarting the process.

  1. Log in to the affected BIG-IP device.
  2. Rename the existing REST device ID file by typing the following command:

    mv -b /config/f5-rest-device-id /config/old.f5-rest-device-id

  3. Restart the restjavad process to generate a new REST device ID file by typing the following command:

    tmsh restart /sys service restjavad

  4. Validate that you have the new REST device ID in the /config/f5-rest-device-id file. With the new ID file, this BIG-IP device is now ready to be discovered by the BIG-IQ system.
  5. When the device discovery in step 4 has successfully completed, you can safely delete the old duplicate file that you renamed in step 2.

    To delete the file, type the following command:

    rm -f /config/old.f5-rest-device-id
