Issue

Error Message

err tmm[<PID>]: 01480002:3: <General function or subsystem failure error message>

In this error message, note the following:

  • <PID> is the process ID for the TMM process.
  • <General function or subsystem failure error message> is a general high-level description of the failure. 

For example:

err tmm2[14758]: 01480002:3: Can't initialize plugin configuration

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • A failure occurs in the system.

Impact

The impact varies according to the specific function or subsystem failure.

Recommended Actions

  • Review the /var/log/ltm file and look for error messages preceding the 01480002:3: error to determine the possible cause of the failure.
  • Troubleshoot the issue by generating a QKView file and uploading it to BIG-IP iHealth.
  • Contact F5 Technical Support for additional troubleshooting help.
