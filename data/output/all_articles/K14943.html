Topic

This article applies to BIG-IP 11.5.x and earlier. For BIG-IP 11.6.x and later, refer to the following article:

  • K15632: Disabling the admin and root accounts using the Configuration utility or tmsh

You should consider using these procedures under any of the following conditions:

  • You want to remove the administrative user from the BIG-IP host.
  • You want to create a new administrative user.

Description

Some security or administrative protocols may require you to remove the local Configuration utility administrator login. Reasons include changing the administrative login to a different username, or using remote authentication as the sole method for administrative user verification. To create a new user, disable the default user, or restore the default user, perform the following procedures:

  • Creating a new administrative user with the Configuration utility
  • Removing the default Configuration utility administrative user
  • Restoring the default administrative user

It is important to note that the system automatically restores the default administrative user when you perform any of the following administrative procedures:

Important: Administrators must manually disable the administrative user account after any of the following administrative procedures take place.

  • You load the BIG-IP configuration.
  • You restore a user configuration set (UCS) backup.
  • You upgrade your BIG-IP system to a later version.
  • You install a BIG-IP hotfix.

Note: These procedures do not remove command line access to the BIG-IP system.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have command line access to the BIG-IP host as the root user.
  • You have administrative privileges in the Configuration utility.

Procedures

Creating a new administrative user with the Configuration utility

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to System > Users > User List.
  3. Click Create.
  4. Enter a name and password.
  5. For Role, click Administrator.
  6. For Terminal Access, click Disabled.
  7. Click Finished.
  8. Click Log out.
  9. Test that your new administrative user is active by logging in with your new username and password.

    You can repeat this procedure if multiple administrative users are required.

Removing the default Configuration utility administrative user

Impact of procedure: The following procedure should not have a negative impact on your system.

Important: After performing this procedure, you may be unable to log in to the Configuration utility, unless you have created an alternative administrative user login.

  1. Log in to the BIG-IP command line as the root user.
  2. Remove the default administrative user by typing the following command:

    userdel admin

  3. To verify that the user has been removed, you can view if the administrative user no longer exists in the /etc/passwd file:

    grep ^admin: /etc/passwd

    If the administrative user has been removed, no command output will exist.

Restoring the default administrative user

To restore the default administrative user login and assign a new password, perform the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line as the root user.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. To reinstate the root user and password, use the following command syntax:

    BIG-IP 11.x and later

    modify /auth user admin password <password>

    In this command, note the following:

    <password> is the password you want to use for the administrative user.

    BIG-IP 10.x

    modify /auth user admin prompt-for-password

    When prompted, enter the password for the admin account and confirm the password.
