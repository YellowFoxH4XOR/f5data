Description

  • How memory is reserved for BIG-IP ASM module consumption?
  • Taking into account traffic of a given BIG-IP, how do I work out ASM's high level memory usage on the machine

Environment

  • ASM
  • BIG-IP

Cause

  • TMM and Host memory allocation/use is independent of  each other

Recommended Actions

  • None

Additional Information

  • BIG-IP TMM and Linux Host are totally independent in terms of memory allocation and consumption.
    • The BIG-IP system allocates memory to a module at a time of its provisioning.
    • Once the BIG-IP assigns a dedicated pool of memory to TMM, it is not available for the HOST or other host processes.
    • TMM memory consumption relates to the actual processing of traffic on the data-plane, including SSL offloading and other traffic related tasks like load balancing.
    • ASM is a Linux kernel process and hence wholly depends on HOST memory
    • To avoid capacity issues in BIG-IP 12.x and later, ASM module should be provisioned on a system with at least 8 GB or more of memory.
  • tmsh show /sys memory provides the current status of memory use on the system 
For Example, using the stated tmsh command, an example BIG-IP has the below memory use output 

      ---------------------------------
      Sys::Host Memory (bytes)
      --------------------------------
          Host: 0
            Available             15.7G
            Used                   8.9G
      ------------------------------
      Sys::TMM Memory (bytes)
      ------------------------------
          TMM: 0.0
            Available              2.8G         <---- total allocated memory to TMM
            Used                 842.8M

  -- So the output tells us that the system has a total of 15.7 GB physical Memory.

total Available memory      ==  15.7
total host used memory      ==  8.9
total TMM allocated         ==  2.8

 

    unused/unallocated ==  total Available memory - [ (total host used memory)  +  (TMM allocated)]
                       ==  15.7 - [8.9 + 2.8]
                       ==  15.7 - 11.7
                       ==  4 GB  [ the system has 4G memory, which the HOST can access ]
