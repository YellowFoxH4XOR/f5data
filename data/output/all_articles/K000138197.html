K000138197: HA pair going into Awaiting Initial Sync after a host reboot

Type
Support Solution
Published
2024-01-11
Updated
2024-01-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000138197

Description

  • HA pair of BIG-IP LTM vcmp guest go to "Awaiting Initial Sync/Changes pending" after vcmp host reboot
  • A log similar to the following can be seen on /var/log/ltm

notice logger[10627]: /usr/bin/mcpd -dbmem 512 -listen 127.0.0.1 -forceload -f ==> /usr/bin/bigstart disable pgadmind

Environment

  • BIG-IP LTM
  • HA Pair
  • vcmp Host
  • vcmp Guest

Cause

If the vcmp host is rebooted, the vcmp guest gets powered off and on by the host, hence mcpd starts with -forceload on the guest, causing the configuration to load from file. This in result updates the configuration commit ID therefore the Awaiting Initial Sync/Changes pending status.

Recommended Actions

None, seen behaviour is expected.

Additional Information

None
