K000139675: Cleared /var in BIG-IQ DCD, still BIG-IQ is not receiving the ASM/AFM event logs

Source
https://my.f5.com/manage/s/article/K000139675

Description

BIG-IQ Data Collection Device is experienced high disk usage of /var in the BIG-IQ DCD.

/var is cleared in BIG-IQ DCD and /var space is reduced. Still BIG-IQ is not receiving the ASM/AFM event log.

Following logs are noted in the  /var/log/restjavad.0.log

 

registerBigIQInternalSources failed: java.net.ProtocolException: status:507, body:{"error":{"httpStatus":"INSUFFICIENT_STORAGE","code":3,"message":"SOURCE_CATALOG_STORAGE_ERROR: ElasticsearchStatusException[Elasticsearch exception [type=cluster_block_exception, reason=blocked by: [FORBIDDEN/12/index read-only / allow delete (api)];]]","errorStack":[],"restOperationId":"07b12343-d5cf-4f0e-b553-67886e2cf3f2"}}, will retry

 

Environment

  • BIG-IQ Data Collection Device
  • Prior to reducing /var space, ASM/AFM event logs are displayed in BIG-IQ Centralized Management
  • Followed article K50385724 still latest ASM event logs are not displayed in BIG-IQ Centralized Management
  • Followed article K46666053  still latest ASM event logs are not displayed in BIG-IQ Centralized Management

Cause

Bug ID 1055153

Recommended Actions

Run the following command on the Centralized Manager or on any one of the data collection devices:

 

for idx in $(curl -ks https://localhost:9200/_cat/indices | awk '{print $3}'); do if [ $idx != ".opendistro_security" ]; then curl -k -u admin:admin -X PUT "https://localhost:9200/$(echo $(echo $idx | cut -d\+ -f1)*)/_settings?pretty" -H 'Content-Type: application/json' -d'{"index.blocks.read_only_allow_delete": false}'; fi; done
