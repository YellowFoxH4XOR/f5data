Known Issue

Secure Web Gateway (SWG) is incorrectly listed as a provisionable module on BIG-IP systems with less than 8 GB of memory

This issue occurs when all of the following conditions are met:

  • The BIG-IP appliance, BIG-IP Virtual Edition (VE), or Virtual Clustered Multiprocessing (vCMP) guest has less than 8 GB of memory allocated/available.
  • You attempt to provision modules using the Configuration utility or the Traffic Management Shell (tmsh)

The SWG module can only be provisioned on BIG-IP platforms with 8 GB of system memory or more. SWG is not supported on BIG-IP platforms with less than 8 GB of memory.

Impact

The SWG module is incorrectly shown as provisionable. Administrators may attempt to provision SWG on unsupported platforms.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to provision the SWG module, provisioning fails and the system displays an error message similar to the following example:

    01071008:3: Provisioning failed with error 1 - 'Memory limit exceeded. 5656 MB are required to provision these modules, but only 3964 MB are available.
