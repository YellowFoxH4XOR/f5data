K2544: Restricting access to NameSurfer by source IP address

Topic

NameSurfer has an administrative tool that allows you to limit NameSurfer access to a specified group of IP addresses. Unfortunately, due to the way that NameSurfer is integrated into 3-DNS, you cannot use this tool to limit administrative access to NameSurfer.

The NameSurfer user account administration tool will not work because the source address of the NameSurfer connection is 127.0.0.1 (the loopback address of the 3-DNS system). This address does not change, so if you try to limit access to NameSurfer using this method, you will be locked out of NameSurfer.

If you are locked out of NameSurfer, type the following commands to regain access:

cp -p /usr/local/namesurfer/db/db.nsurf.users.bak db.nsurf.users

bigstart restart namesurfer
