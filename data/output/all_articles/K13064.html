K13064: Portal Access favorites may show the server IP address

Type
Knowledge
Published
2011-08-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 7.0.0
Source
https://my.f5.com/manage/s/article/K13064

Topic

Portal Access favorites that use a protocol other than HTTP or HTTPS, such as FTP, may display the IP address of the backend server to the user.
