Known Issue

Prior to versions 4.5.13 and in versions 4.6 through 4.6.4, 3-DNS sends all virtual server probes simultaneously. When more than 500 virtual servers are configured, 3-DNS may not be able to handle all of the probes and, as a result, 3-DNS may not update the state of some virtual servers.

In versions 4.5.13 and 4.5.14, 3-DNS staggers the probes, rather than sending all probes at the same time, enabling 3-DNS to accurately probe as many as 2,000 virtual servers.
