K13494: Cookies that do not contain a period in the domain attribute are not passed by FirePass

Known Issue

Description

Some cookies are not passed by the FirePass portal access

This issue occurs when the following condition is met:

  • A back-end server sends a cookie that does not contain a period character ( . ) in the domain attribute

Impact

The user may be unable to properly access the website.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • FirePass does not pass the cookie to the client
  • The website may exhibit unexpected behavior that will vary based on the purpose of the cookie

Status

F5 Product Development has assigned ID 378674 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can ensure that your web server is sending a Fully Qualified Domain Name (FQDN) or an IP address in the domain attribute of the cookie.
