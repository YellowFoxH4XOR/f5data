K000157840: During recent F5 upgrade process we observed new local user account "srv_user"

Description

A local user account named "srv_user" appeared on BIG-IP LTM devices following an upgrade to 17.5.1.3.
Is this account created by F5 during the upgrade process ?

Environment

BIG-IP LTM, version 17.5.1.3 

Devices deployed as virtual appliances in AWS

Initial deployment utilized F5 Cloud Formation Templates from F5Networks GitHub

Devices configured for HA pairing

 

Cause

The automated creation of the "srv_user" account by F5's AWS Cloud Formation deployment templates during initial provisioning or upgrades on cloud-based BIG-IP instances is to support HA configuration tasks. This account is intended for temporary use and is removed automatically post-sync, but can be safely deleted manually without impacting device operation.

 

Recommended Actions

It is safe to manually delete the "srv_user" account if it remains present after deployment or upgrade; this will not affect HA functionality or system stability.

 

Additional Information

Relevant script: /config/cloud/aws/rm-srv-user.sh (removes srv_user post-sync)

Reference: https://github.com/F5Networks/f5-aws-cloudformation/blob/main/supported/failover/same-net/via-api/3nic/existing-stack/byol/f5-existing-stack-same-az-cluster-byol-3nic-bigip.template
