Description

  • Error messages from platform_mgr pod log as below:

telemetry/scheduler.go:184 Failed to send telemetry: "Message":"ErrorCode:IotHubUnauthorizedAccess;Unauthorized"


Environment

  • Nginx Controller

Cause

The connections between the platform_mgr pod and IoT Hub for telemetry is having an issue.


 Recommended Actions

Renew the secrets used to connect to IoT Hub via the script below:


   #!/bin/bash

   # Get the secret details of declarative-ext-api-certs-xxxx

   name=declarative-ext-api-certs

   filter=".items | map(select(.metadata.name | startswith(\"$name-\"))) | sort_by(.metadata.creationTimestamp) | last.metadata.name"

   s=$(kubectl get secret "$(kubectl get secret -o json | jq -r "$filter")" -o json)


   # Decrypt and output the va.crt, client.crt and client.key to loacal

   for n in ca.crt client.crt client.key; do jq -r ".data | .[\"$n\"]" <<<"$s" | base64 -d >"$n"; done


   # Get the pod IP of secrets-svc-xxxxx-yyyyy

   name=secrets-svc

   podip=$(kubectl get pod -l app=$name -o jsonpath='{.items[0].status.podIP}')


   # Filter out all the names of the Common Product Components and Libraries (CPCL) related secrets

   port=8443

   readarray cpcl_var < <(curl -fsSL --cacert ./ca.crt --cert ./client.crt --key ./client.key --resolve $name.nginx-controller.svc.cluster.local:$port:$podip https://$name.nginx-controller.svc.cluster.local:$port/api/v1/secrets/ | jq -r '.items[] | select(startswith("CPCL"))')


   # Renew all the CPCL related secrets by deleting them via APIs.

   for item in "${cpcl_var[@]}"; do

     curl -fsSL --cacert ./ca.crt --cert ./client.crt --key ./client.key --resolve $name.nginx-controller.svc.cluster.local:$port:$podip -X DELETE https://$name.nginx-controller.svc.cluster.local:$port/api/v1/secrets/$item

   done


   # Delete the secrets dumped to local previously

   for n in ca.crt client.crt client.key; do rm "./$n"; done


   # Recreate platform-mgr pod 

   kubectl delete pod -l app=platform-mgr
