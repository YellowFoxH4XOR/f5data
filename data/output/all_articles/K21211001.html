Known Issue

Using an iRule to retrieve Secure Sockets Layer (SSL) session IDs may return unusable data.

This issue occurs when all of the following conditions are met:

  • You configure a SSL Server profile.
  • You configure an iRule to retrieve the SSL session ID.

Impact

Data retrieved by the iRule is unusable.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Retrieving the server-side SSL session ID using an iRule does not work.
  • When you view the SSL session ID data retrieved by the iRule, the data is garbled.
  • iRules actions dependent on the SSL session ID data do not function correctly.
