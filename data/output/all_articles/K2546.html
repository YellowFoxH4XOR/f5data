Topic

The BIG-IP SSL health check, s_client, is part of the OpenSSL tool kit and is used to test connectivity to SSL-enabled services. It is not designed as a full health-monitoring tool and should not be used as one because it can generate zombie processes when run from a daemon.

To avoid receiving the zombies, use the cURL program for SSL-enabled service health checking. cURL is shipped with BIG-IP version 4.2 and later and provides the functionality to connect to an SSL-enabled service and return health information.

The following command is a simple cURL SSL health check that would send a GET/ to the server and return the information to grep looking for My_Site.

curl https://192.168.10.10 | grep My_Site

Using the arguments contained in the /usr/local/lib/pingers/sample_pinger, the resulting line would be:

/usr/local/bin/curl https://$1 2> /dev/null | grep -E -i $3 > /dev/null
