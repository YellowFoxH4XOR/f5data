Topic

SSL Performance

The best indication of overall Secure Socket Layer (SSL) performance is determined, not simply by noting the transactions per section (TPS), but by a combination of factors including, but not limited to, the following:

  • Number of new SSL handshake requests per second
  • Average page size
  • SSL session ID re-use
  • Number of concurrent connections

Each of these factors has a direct influence on overall SSL performance, demonstrating that despite the fact that a particular platform might be rated for 20,000 Max TPS, it is not the only factor in determining the BIG-IP LTM SSL decryption and encryption performance. Performance varies according to the environment in which the BIG-IP system is installed.

SSL performance varies primarily on page request size and SSL session ID re-use. The number of TPS is only an indication of how many new SSL handshakes per second that the BIG-IP system can service.

SSL Users

Regardless of the SSL requirements, there are essentially two types of SSL users: Low Volume Users and High Volume Users.

Low Volume Users

Low Volume Users utilize a relatively small number of TPS. This profile constitutes the majority of users. A single BIG-IP system scales much higher than required for low volume users.

High Volume Users

High Volume Users conduct a high number of TPS. This profile constitutes a smaller number of users. BIG-IP LTM 9.x platforms can typically accommodate these SSL requirements. For example, the 6800 platform can manage up to 2 Gb/s of SSL bulk crypto per unit.

Note: 1.7GBPS is approximately the full bandwidth of an OC24 and an OC12 combined.
