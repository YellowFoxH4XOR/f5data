K13822: The ARX 1500 and ARX 2500 'show chassis diskuse' command is reporting an unknown status

Known Issue

The RAID controllers in the ARX 1500 and ARX 2500 platforms may fail to properly report on the health of the RAID controller, logical drive, and physical drives.

Impact

The ARX system may fail to report the status of a failed Hard Disk or RAID controller.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After running the show chassis diskuse command, the Disk Details and RAID controller detail sections report unknown.

Following is an example of the show chassis diskuse command output, where the ARX system is not running the correct RAID controller software:

SWITCH# show chassis diskuse

 Logical Disk Details:

 Disk    Status                 Verification Mode  Verification Rate

 ------  ---------------------  -----------------  -----------------

 1       Unknown                Automatic             %

 Disk Details:

 Disk       Size          State               Transfer Rate   Model

 --------   -----------   -----------------   -------------   -----------------

  Bay 1                   Unknown                                        

  Bay 2                   Unknown                             

Note the "Unknown" items and the missing RAID Controller Details section.

 

Following is an example of the show chassis diskuse command output, where the ARX system is running the correct RAID controller software:

SWITCH# show chassis diskuse

 Logical Disk Details:

 Disk    Status                 Verification Mode  Verification Rate

 ------  ---------------------  -----------------  -----------------

 1       Optimal                Automatic          10 %

 Disk Details:

 Disk       Size          State               Transfer Rate   Model

 --------   -----------   -----------------   -------------   -----------------

  Bay 1     136.73G       Online              3.0Gb/sec       ST9146803SS  

  Bay 2     136.73G       Online              3.0Gb/sec       ST9146803SS  

 RAID Controller Details:

 Rebuild Rate  Max Transfer Rate  Firmware       RAID Alarm

 ------------  -----------------  -------------  ------------

 90 %          3.0Gb/sec          5.2-0[19203]   Enabled
