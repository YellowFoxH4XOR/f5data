What Happened?

  • Customers sometimes will ask or would like to know their time zone is set into their tenants.

 

Environment

  • F5® Distributed Cloud Console

 

Resolution/Answer

  • Everything in server is stored with UTC timestamp.
  • F5XC front-end converts that to user's local time zone and displays it.
  • For example, if you are in IST, and select 5:30PM, it converts it to UTC and saves it as 2023-06-29T12:00:00.000Z. And if you are viewing it, it will be displayed as 5:30PM in local time zone. This also covers daylight savings.

Additional Information

  • It is one of the best practices to store objects in UTC especially for application which are subject to different time zone. Users can just validate this via checking the object creation timestamp.
