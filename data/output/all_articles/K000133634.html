K000133634: "Failed to establish ADFS trust relationship on the virtual server /Common/adfs_vs: Can't connect to ADFS." when performing manual trust reestablish from the standby

Type
Support Solution
Published
2023-05-12
Updated
2023-07-26
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3, 14.1.4
Source
https://my.f5.com/manage/s/article/K000133634

Description

  • When you try to reestablish ADFS Proxy trust manually from the standby you get following APM error:
    `Failed to establish ADFS trust relationship on the virtual server <vs name>: Can't connect to ADFS`
  • This issue happens only on the currently Standby system, manual reestablish works fine from the Active unit

Environment

  • APM A/S Pair
  • APM ADFS Proxy
  • Manual sync used

Cause

Expected behaviour

 Recommended Actions

  1. According to Manual Chapter : APM as an Active Directory Federation Services (AD FS) Proxy this is expected. Manual trust reestablishment is possible only from the currently Active device.
  2. To fix the issue you have to manually failover from Active to Standby unit and run the manual trust reestablishment again
  3. Make sure to use auto sync for a device group containing ADFS Proxy VS
