Description

iRulesLX creates a /var/tmstat/blade/tmplugin_ilx_* file for each tmm. If a plugin is restarted, a new tmstat file is created but the old one is not removed. These files accumulate over time and can affect stats. As per requirement all generated files /var/tmstat/blade/tmplugin_ilx_* should be removed.

The presence of too many of these leftover files might prevent merged from rolling up stats and providing graphs and cause such errors:
err merged[8523]: 011b0900:3: TMSTAT error tmstat_remerge: Cannot allocate memory.


Environment

  • iRulesLX configured


Cause

Bug ID 1035757.
The ilx plugin is restarted causing a new tmstat file created and the old one not removed.


Recommended Actions

Delete stale tmplugin_ilx_* files manually.
