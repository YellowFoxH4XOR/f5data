Description
When reloading virtual config with tmsh load sys config file <file> replace command of a virtual with multiple iRules, if one rule is removed from the config, the load fails with error similar to the following:

# tmsh load sys config file test-virtual.conf replace
Loading configuration...
  /shared/tmp/test-virtual.conf
01070621:3: Rule priorities for virtual server (/Common/test-virtual-1) must be unique.
Unexpected Error: Loading configuration process failed.

Environment

  • Virtual Server with more than iRule defined.
  • Using tmsh replace verb to load a configuration

Cause
Bug ID 896817

Recommended Actions

Perform any of the following:
  • Delete and re-create the affected object in a single cli transaction
  • Modify the object using the Configuration Utility
