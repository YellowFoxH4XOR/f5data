Issue

Error Message

err mcpd[<PID>]: 01070277:3: The requested <object_type> (<object_name>) was not found

In this error message, note the following:

  • <PID> is the process ID of the mcpd process.
  • <object_type> is a BIG-IP configuration object.
  • <object_name> is the name of the object that you have configured for the <object_type> that is invalid or does not exist on the BIG-IP system.

For example:

err mcpd[23180]: 01070277:3: The requested vlan, vlangroup or tunnel (/Common/example_vlan) was not found

Message Location

You may encounter this message in the following locations:

  •     The /var/log/ltm file
  •     The Configuration utility
  •     The TMOS Shell (tmsh)
Description

This message occurs when all of the following conditions are met:

  • The object in the requested operation is invalid or does not exist.
  • You attempt to perform one of the following operations:
    • Loading a user configuration set (UCS) file
    • Manually loading the system configuration with the tmsh load sys config command
    • Performing a configuration synchronization (ConfigSync) to one or more peer BIG-IP systems
    • Creating or modifying a configuration object using tmsh

Impact

The requested operation fails to validate and is unable to complete.

Recommended Actions

Review the name of the affected object in the error message for syntax and variable use. You can attempt to work around this error by performing one of the following actions:

  • Determine if the affected object is required and add the object to the peer device, or remove the object from the peer if it is not required.
  • Make sure the affected object name uses the same spelling and case on the device group units.
  • In some cases, you may also be able to work around this error by forcing the mcpd process to reload the BIG-IP configuration. For more information, refer to K13030: Forcing the mcpd process to reload the BIG-IP configuration.
