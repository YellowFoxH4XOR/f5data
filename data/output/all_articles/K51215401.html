K51215401: LTM monitor status is unavailable after importing LTM objects from BIG-IQ

Type
Support Solution
Published
2021-06-04
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K51215401

Description

  • Monitor password complexity requirements on BIG-IQ
  • After importing some LTM devices, notice that some monitors have a yellow triangle warning icon that says:
    Secure attribute must be re-entered for attachment or modification of monitor.
     
  • Passwords that use complex characters but match commonly known passwords are not considered strong passwords.

Environment

  • BIG-IQ LTM monitors 
  • Password complexity enforcement

Cause

  • This is due to Bug ID1004201 which is an issue in which the BIG-IQ is attempting to enforce its local password policies for objects generated on remote systems.

Recommended Actions

  • Do not manage or update remotely managed BIG-IP passwords from the BIG-IQ system on unpatched versions.
  • Complete all password management tasks from the BIG-IP on which the password resides.  

Additional Information

None
