Description

After restarting Controller, it does not start.

Running the command, 

kubectl describe nodes <node name>

there is an error similar to this one:
Error from server (BadRequest): container "<component name>" in pod "<pod name>" is waiting to start: image can't be pulled

 Environment

  • Nginx Instance Manager v3.21.X or lower.
  • Controller was restarted.
  • Controller Image not present anymore.

 Cause

Unknown at the time of publication.

 Recommended Actions

  • Permanent: Upgrade to version 3.22.x, or later.
  • Workaround: 
    • If you have controller, install package on your nginx-controller,
    • Then, unzip the install package and find "controller.img.gz" on "controller-installer/files"

    • And then, run below command:

                      sudo gunzip -c controller.img.gz | sudo docker load 

  • Then check your docker images with the following command:
                      sudo docker images 
  • If you dont' have nginx-controller install package, then please download it on our F5 my portal (https://my.f5.com/manage/s/downloads)
