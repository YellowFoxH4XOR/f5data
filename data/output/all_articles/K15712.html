Topic

This article describes the current status of BIG-IP Edge Client on Mac OS X 10.10 (Yosemite).

Description

F5 will soon provide an upgrade of BIG-IP Edge Client for Mac OS X 10.10 (Yosemite) for BIG-IP APM: 11.6.0, 11.5.3, 11.5.2, 11.5.1, 11.5.0, 11.4.1, 11.4.0, 11.2.1, and 10.2.4. The FirePass controller is not and will not be supported.

Preliminary testing of the BIG-IP Edge Client on Mac OS X 10.10 has shown the following issues in the network access clients:

  • When you use the Mac OS X Safari browser with an established Network Access session through the BIG-IP Edge Client, the Safari Browser does not honor the established Network Access routes.*
  • When you connect to a BIG-IP APM 10.2.4 system with the BIG-IP Edge Client, network access can be intermittent, regardless of the Network Access configuration.
  • If a user interacts with the BIG-IP Edge Client using the menu bar icon (by clicking the menu bar icon or clicking the menu items from the menu bar icon), then the BIG-IP Edge Client creates high CPU usage and users may see high CPU usage warnings. The user interface associated with the menu bar icon is slow to respond.*
  • If you modify the Edge Client application folder, the OS (Mac OS Gatekeeper) shows the following warning: resource missing or invalid. To prevent this issue, do not change the Edge Client application folder.*
  • If a user selects the Edge Client icon on the menu bar, the icon stays highlighted until the user quits the Edge Client app. Also, traffic throughput next to the Edge icon is difficult to read.
  • Traffic throughput next to the Edge Client icon on the menu bar is difficult to read when you use the dark theme on this new OS.
  • The server drop-down list from the Edge Client’s Main Window has some visual disparities, but it should still function properly.*

Note: These issues have been fixed in the BIG-IP APM 12.0.0 and 11.6.0 HF4 releases. You can download and install this release and the hotfix release from the F5 Downloads site.
