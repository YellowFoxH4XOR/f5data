K12584194: Unable to ping Configsync IPs between two VEs

Description

Two VEs connected through an ACI fabric are not able to ping each other over Configsync interfaces. However, ping works fine for management interfaces across each device and ping from a client machine goes successful to both Configsync interfaces

Environment

  • BIG-IP VE
  • Configsync IP
  • VLAN/Interface configuration

Cause
Interface connected or assigned between two VEs was configured as tagged on both the sides on BIG-IP.  On ACI fabric it was configured as untagged which leads packets to drop at ACI fabric without reaching the other end as they are tagged packets.

Recommended Actions

Verify the interface configured on the virtual switch/ ACI fabric between two VEs. 
   a) If virtual switch interface is configured as tagged interface, configure the interface on BIG-IP VE to tagged.
   b) If virtual switch interface is configured as untagged interface, configure the interface on BIG-IP VE also as untagged.

Use below articles to perform the above recommendation,
   K24122354: Create and modify VLANs using the GUI utility
   K14961: Create and modify VLANs using the tmsh utility
