K000160922: Installation of software results in failed (unkown reason)

Applies to

Source

Description

After installing the software in a partition, it is showing failed (unknown reason).

/var/log/liveinstall.log shows

*** Live install start at 2026/01/01 01:00:48 ***  

/bin/nice: /usr/sbin/image2disk: Permission denied

 *** Live install end at 2026/01/01 01:00:48: failed (return code 126) ***

Environment

LTM

Cause

image2disk has no adequate permissions

[root@LTM:Active:Standalone] config # ls -al /usr/sbin/image2disk
-rw-r--r--. 1 root root 59567 Oct  7  2025 /usr/sbin/image2disk

Answer/Recommended Actions

Remount the /usr to have a rw permission

  1. Login to BIGIP CLI.
  2. Enter commands

            bash

            mount -o remount,rw /usr 

            chmod 755 /usr/bin/image2disk

   3. Confirm if the correct permissions are set, expected output should be:

[root@LTM:Active:Standalone] config # ls -al /usr/sbin/image2disk
-rwxr-xr-x. 1 root root 59567 Oct  7  2025 /usr/sbin/image2disk

   4. Retry installation of the image in the partition.
