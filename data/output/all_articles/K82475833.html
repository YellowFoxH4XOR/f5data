Description

Some environments may require ADA compliance for BIG-IP APM.

Environment

  • BIG-IP APM
  • APM Modern Customization
  • ADA Compliance

Cause

In v15.1 F5 introduced Modern Customization that meets ADA Compliance, therefore to support this feature you would need to upgrade your device to v15.1 to later and apply Modern Customization.

Recommended Actions

When creating an access profile/policy or per-request policy, you must select a Customization Type: either Standard or Modern. Some of the customization options vary depending on which type you select. The Modern type is the default UI, which provides a contemporary look, a responsive design, and ADA/AT reader compliance, in addition to many of the Standard customization features.
