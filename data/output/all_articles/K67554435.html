K67554435: After copying new controller and partition iso images to /var/export/chassis/import/iso, the images cannot be synchronized to standby controller. Status stays unchanged as ''In Queue''

Description

    After copying new controller and partition iso images to /var/export/chassis/import/iso, is looks that the images cannot be synchronized to standby controller and the status stays as "In Queue"

    Cause

    • Corrupted ISO file was used

    Recommended Actions

    • Remove the new images
    • Switchover controller card
    • Reboot of the chassis
    • Rebuild Openshift Cluster: "touch /var/omd/CLUSTER_REINSTALL"
    • Copy the ISO files again and confirm integrity

    Additional Information

    You need to check if the image is still deleted on both controllers, once you have switched over the controller card, as you may find that one of the controllers still has a copy of the image, and will start to sync the image back to the other controller.
