Issue

This article applies to BIG-IP 9.x. For information about other versions, refer to the following article:
  • K13222: Error Message: 0107071c:3: Trouble allocating mac address for trunk (<name>)
 
In BIG-IP 9.x, when the number of defined trunks in a configuration exceeds the maximum number of allowable trunks for the platform, the following error messages output to the /var/log/ltm file:
 
bcm56xxd[937]: 012c0010:3: Trunk resources exhausted
bcm56xxd[937]: 012c0010:3: Error creating trunk T2.6

Supplemental Information
