Known Issue

The BIG-IP system may generate SNMP v3 trap messages that contain incorrect msgAuthoritativeEngineBoots and msgAuthoritativeEngineTime values.

This issue occurs when the following condition is met:

  • The snmpd process restarts.

Impact

Some third party SNMP monitoring servers may lose the ability to poll the BIG-IP system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SNMP v3 trap messages contain incorrect msgAuthoritativeEngineBoots and msgAuthoritativeEngineTime values.
  • The msgAuthoritativeEngineBoots value is not synchronized with the engineBoots value in the /config/net-snmp/snmpd.conf file.
