Known Issue

Border Gateway Protocol (BGP) does not advertise the default route to a neighbor through the default-originate command.

This issue occurs when all of the following conditions are met:

  • You configure BGP routing on your BIG-IP system.
  • You configure multiple BGP neighbors in different VLANs or subnets using the default-originate command.

    Note: The default-originate command allows BGP to advertise default route 0.0.0.0/0 to a neighbor.

Impact

The BIG-IP system does not advertise the default route to all BGP peer neighbors; however, some of the BGP neighbors may receive the default route.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system does not advertise the default route to all BGP neighbors.

Workaround

To work around this issue and advertise the default route, you can add the network 0.0.0.0/0 command under the BGP configuration.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
