Description

You want to use High Speed Logging (HSL) for Bot Defense.

  • You try to set up HSL for Bot Defense but the logging profile you configured does not show up in the 'Remote Publisher' section when you are configuring the Request Log.

Environment

  • Not able to set up HSL for Bot Defense
  • Log Destinations, Log Publishers, Bot Defense Logging Profile
  • HSL for ASM/AdvWAF

Cause

Bot Defense only supports the splunk format destination

Recommended Actions

Please follow the steps outlined in the manual chapter Configuring Remote High-Speed Logging.

You will need to set a formatted destination with splunk as the configured format.
