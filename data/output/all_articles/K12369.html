Known Issue

Note: This Solution only applies to the following platforms licensed for BIG-IP Edge Gateway: BIG-IP 1600 (C102), 3600 (C103), 3900 (C106), 6900 (D104), and 8900 (D106).

This is the result of a known issue. When licensing a system for use with BIG-IP Edge Gateway, the BIG-IP system allocates an insufficient amount of memory for the WebAccelerator component. As a result, the WebAccelerator component will not be able to operate efficiently.

Important: Under normal circumstances, you should provision the WebAccelerator component as Dedicated in order to allocate the necessary amount of memory. However, in order for the BIG-IP system to work properly when all three components of the BIG-IP Edge Gateway are provisioned (APM, WOM, and WebAccelerator), you must provision the components as Nominal with the LTM option set to None.

F5 Product Development is tracking this issue as ID 342934.
