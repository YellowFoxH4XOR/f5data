K000132692: Virtual server availability when forwarding traffic to pool via irule

Published

Status

Applies to

  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000132692

When there is an irule assigned to direct traffic to pool based on condition and there is no pool assigned directly to the virtual server, any change in status to that pool from up to down or unchecked will be reflected on the virtual server status even if that pool is not assigned directly to the virtual server.

If the irule is referencing another active pool based on specific condition or there is another irule that is referencing an active pool assigned to that virtual server, or if there is another active pool assigned directly to the vip, then the virtual server will take the status of the active pool. For the virtual server to be tagged as down, all referenced pools should be down.
