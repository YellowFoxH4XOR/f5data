Known Issue

Hardware flow statistics may not update during FastL4 flow teardown.

This issue occurs when all of the following conditions are met:

  • A virtual server uses a FastL4 profile with Packet Velocity ASIC (PVA) acceleration enabled.
  • The virtual server receives User Datagram Protocol (UDP) or TCP traffic.
  • Your BIG-IP system receives an ICMP unreachable message from the server side.

Impact

FastL4 virtual server statistics display incorrect Current SYN Cache and curr_pva_assist_conn counts. This issue may also unexpectedly activate SYN cookie protection, if hardware SYN cookie protection is enabled.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tmsh show /ltm virtual <virtual_server_name> all-properties command output displays incorrect Current SYN Cache statistic counts, similar to the following example:
