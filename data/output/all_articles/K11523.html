Issue

Note: For information about rebuilding the RAID configuration, refer to K11525: Rebuilding the RAID configuration after a hard drive replacement.

When rebuilding the RAID configuration on an ARX system using the raid rebuild command, if one of the drives has failed, or if one of the drives has on old firmware version installed, the raid rebuild command will fail and error messages that appear similar to the following example are logged:

:ROOTD-0-ERR-RAID_REBUILD_DRIVE_FAILED:: Rebuild drive failed device error.
:CLI-0-ERR-RAID_OPERATION_FAILED:: The raid rebuild command failed.
:CLI-0-ERR-RAID_REBUILD_DRIVE_FAILED:: Rebuild drive failed device error.

You can use the show health command to determine the reason for the raid rebuild failure.

Note: For information about the raid rebuild and show health commands, refer to the ARX CLI Reference Guide.

Important: A mismatch between the ARX release version and the current running firmware version may be interpreted by the ARX systems as both a firmware mismatch and a disk failure.

For example, the following show health command output indicates a firmware mismatch and a hard disk failure:

System Health Information
Date                     ID      Event                       Description
---------------------------------------------------------------------------------------
Mon Jan 01 01:23:30 2010 (183) - firmwareMismatchRaise       Firmware version does not match Software version.
Mon Jan 01 01:23:34 2010 (131) - diskFail                    Disk in bay 2 failed

When the show health command indicates both a firmware mismatch and a disk failure, the drive reported as failed may not have actually failed. You should upgrade the ARX firmware before replacing the drive reported as failed.

Note: For information about upgrading the ARX firmware, refer to K9991: Upgrading the ARX firmware.
