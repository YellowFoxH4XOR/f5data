Topic

Summary

When running the show fastpath resources command on the ARX system, the NFS cache resources may show 100 percent utilization.

Description

The reported cache usage is correct and does not indicate an issue.  When the cache resource pools fill to capacity, the ARX system will automatically remove old entries as the need for new entries arises.

For example:

show fastpath resources
