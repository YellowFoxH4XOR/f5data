Known Issue

The BIG-IP APM system may not process all Security Assertion Markup Language (SAML) RelayState parameters correctly.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy is configured as a SAML IdP or SP service.
  • A SAML RelayState parameter includes an HTML or XHTML special character.

Impact

An incomplete RelayState value is sent to the SAML peer.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Access policy SAML authentication may fail.
  • When examining the SAML RelayState, the contents of the RelayState is missing.

Workaround

To work around this issue, you can use HTML entities to replace special characters used in the SAML RelayState parameters.

Impact of workaround: F5 recommends that you test any such changes during a maintenance window with consideration to the possible impact on your specific environment.

Example use of HTML entities in a SAML RelayState

  • RelayState parameter including the HTML/XHTML special character ( " ):

    {"dest":"https://gateway.samlsite.com/web","idpId":3}

  • Modified RelayState parameter replacing HTML/XHTML special character ( " ) with HTML entities:

    {&#34;dest&#34;:&#34;https://gateway.samlsite.com/web","idpId":3}
