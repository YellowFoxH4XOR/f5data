Known Issue

This is the result of a known issue. Using Internet Explorer with the Research Toolbar may cause a FirePass pre-logon sequence to loop indefinitely. The pre-logon sequence must contain the Extended Windows and IE info pre-logon inspector and the client must be using Microsoft Office 2003 in order for this issue to occur. Under these conditions, the progress bar indicates activity and the login page displays the following message:

Collecting Windows information...

However, the pre-logon sequence will not proceed beyond this point.

F5 Product Development is tracking this issue as ID 266930 (Formerly CR89263).

Workaround

Users can work around this issue by closing the Research Toolbar before the pre-login sequence runs. The Research Toolbar can be reopened after login to the FirePass controller.

Alternately, upgrading to Microsoft Office 2007 will correct this issue.
