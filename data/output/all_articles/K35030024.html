Description
You want to change the default boot volume location.

Note: The default behavior of the BIG-IP sets the default boot volume location when you boot into or activate a new boot volume location. Unless you specify a tmsh reboot command as listed below, a normal reboot will boot back into the current boot volume location.

Environment

  • BIG-IP v15.x
  • Command Line Access
  • Boot location

Cause
After booting to the upgraded version you notice that the default boot location is set to the old version

Recommended Actions

  1. Log in to the command line of the BIG-IP system.
  2. Type the following command to list the boot locations
    # switchboot -l
    Example:
    Current boot image:
        HD1.1 - title BIG-IP 15.1.2.1 Build 0.0.10
    Default boot image:
        HD1.1 - title BIG-IP 15.1.2.1 Build 0.0.10
    Available boot image(s):
        HD1.1 - title BIG-IP 15.1.2.1 Build 0.0.10
        HD1.2 - title BIG-IP 15.1.5 Build 0.0.10
  3. To set the default boot image location run the command below:
    # switchboot -b HD1.2

Additional Information
Note: If you have a VIPRION platform, please see the article K9296: Changing the default boot image location on VIPRION platforms
