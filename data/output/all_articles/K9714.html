K9714: The OSPF protocol fails to form adjacencies across a VLAN group

Known Issue

This is the result of a known issue. Multicast traffic destined for the OSPF multicast group addresses 224.0.0.5 and 224.0.0.6 fails to pass through a VLAN group. As a result, OSPF routers on either side of a VLAN group fail to establish adjacent neighbor relationships.

Note: When using the tcpdump utility on the BIG-IP system to examine traffic traversing a VLAN group, the system may not capture egress traffic. To view BIG-IP VLAN group egress traffic, F5 recommends that you capture traffic using a different system that has a port on the same network as the egress port on the BIG-IP system. If traffic on the VLAN group is light, you may be able to configure the BIG-IP system to mirror the VLAN group egress traffic and use tcpdump to capture on the mirrored-to interface.

F5 Product Development tracked this issue as CR111193 and it was fixed in BIG-IP LTM 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue still exists in the BIG-IP LTM 9.4 software branch.

Workaround

You can work around this issue by disabling the default OSPF listeners. For more information about this workaround, contact F5 Technical Support.
