Known Issue

The Point to Point Tunneling Protocol (PPTP) Application Level Gateway (ALG) does not support concurrent Generic Routing Encapsulation (GRE) tunnels on the same PPTP control channel between a client and a server.

This issue occurs when the following conditions are met:

  • The PPTP profile is configured on a virtual server.
  • You attempt to open multiple concurrent PPTP tunnels from the same client to the same server through the PPTP virtual server.

Impact

The PPTP client cannot issue requests on the same PPTP control channel.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/ltm log file, you may observe error messages similar to the following example:

    notice tmm3[20412]: 01700000:5: PPTP CALL-REQUEST id;60654 from;10.10.10.154 to;0.0.0.0 nat;91.91.91.0 ext-id;60654
    notice tmm3[20412]: 01700003:5: PPTP CALL-FAILED id;60654 reason;6 from;10.10.10.154 to;0.0.0.0 nat;91.91.91.0 ext-id;60654
