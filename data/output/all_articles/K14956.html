Topic

You should consider using this procedure under the following conditions:

  • You want to reset the F5 Application Visibility and Reporting statistics and graphs.
  • You want to recover from a possible database issue in which Application Visibility and Reporting stops gathering statistics.

Description

The F5 Application Visibility and Reporting module gathers performance information and provides detailed metrics, such as transactions per second, request and response throughput, and new and concurrent session data. There may be occasions when you want to reset the BIG-IP Analytics statistics database. For example, if you need to recover from a possible database issue in which the BIG-IP Analytics system stops gathering statistics, you can reset the Application Visibility and Reporting statistics database. To do so, perform the following procedure.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access the BIG-IP command line.

Procedures

Resetting the BIG-IP Analytics statistics database

Impact of procedure: The following procedure removes all Application Visibility and Reporting data and resets the MySQL database.

  1. Log in to the BIG-IP command line
  2. Create the /var/avr/init_avrdb file by entering the following command:

    touch /var/avr/init_avrdb

  3. Restart the monpd process by entering the following command:

    tmsh restart /sys service monpd

You can now log in to the Configuration utility and verify that the Application Visibility and Reporting statistics database is reset.
