Description

BIG-IP ASM/Advanced WAF systems may reset both the client and server sides connections with the below reset cause in traffic capture:

RST cause: Internal error (ASM requested abort (plugin abort error))

Environment

  • BIG-IP ASM/Advanced WAF
  • Virtual Server with ASM security policy
  • Receiving HTTP responses from the server
  • The server sends TCP FIN unexpectedly before complete response is transmitted
Cause

The BIG-IP ASM/Advanced WAF system expects to receive the complete HTTP responses from the server, before forwarding it to the client. If the server sends TCP FIN unexpectedly before complete response is transmitted, ASM/Advanced WAF system cannot parse the HTTP response properly, which will cause the system resets not only the server side but also the client side connections.

Recommended Actions
Apply any one of the below actions:

  1. Correct the server's behavior to make sure it sends complete HTTP responses.
  2. Change the server's behavior to use Chunked instead of Content-Length in HTTP responses.
