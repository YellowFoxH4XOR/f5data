Known Issue

The access policy Machine Cert Auth agent may select the wrong branch.

This issue occurs when all of the following conditions are met:

  • You are running the Mac OS X operating system.
  • The BIG-IP APM access policy is configured with the Machine Cert Auth agent.
  • Your device has a machine certificate installed without a matching key.

Impact

The fallback branch of the access policy is incorrectly selected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You are denied access or do not receive the proper resource assignments.
