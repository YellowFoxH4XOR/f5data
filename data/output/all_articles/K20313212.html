Description

The restjavad process provides control-plane access to the BIG-IP system using an HTTP REST API and you want to use iControl REST API to retrieve control-plane restjavad memory usage details.

Environment

  • BIG-IP LTM
  • iControl REST API
  • Restjavad

Cause

None

Recommended Actions

The following command example displays how to retrieve restjavad memory usage details.

  1. To retrieve restjavad memory usage information from a remote BIG-IP system, use the following cURL command syntax:

    # curl -k -u <admin>:<admin_passwd> https:://x.x.x.x/mgmt/shared/diagnostics/runtime | jq .jvmCalc

    {
      "jvmMaxMemoryMB": 170,
      "jvmTotalMemoryMB": 95,
      "jvmUsedMemoryMB": 63,
      "jvmFreeMemoryMB": 31,
      "jvmRealFreeMemoryMB": 106,
      "jvmRealMemoryUsedPercent": 37.477685975819 ---------------> Percent calculation of memory usage
    }
