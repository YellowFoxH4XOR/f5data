Known Issue

The BIG-IP system may experience high CPU usage when external SSL/OpenSSL monitors are used to obtain availability status for 30 or more pool members.

This issue occurs when all of the following conditions are met:

  • You are using an external SSL monitor including, but not limited to, one of the following:

    Extended Application Verification (EAV), LDAP, Session Initiation Protocol (SIP), Simple Object Access Protocol (SOAP), FirePass, snmpdca, Real Server, WMI, and Virtual Location.

  • You are monitoring approximately 30 or more pool members

Note: Internal monitors are not affected.

Impact

BIG-IP system performance is degraded.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After upgrading to an affected version, the BIG-IP system's CPU usage is much higher.
  • The BIG-IP system's CPU usage is unexpectedly high.

Workaround

To work around this issue, you can use a different type of monitor to obtain pool member availability status.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
