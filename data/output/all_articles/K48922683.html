Description

iRule to remove a part or portion from the URI

Environment

  • BIG-IP LTM
  • iRule

Recommended Actions

Use this iRule when a requirement is to remove a portion from the URI

  • In following example, the iRule purpose is to remove the "/test" part from URL, and do a redirect:

      when HTTP_REQUEST {
          if {[HTTP::uri] contains "/test"} {
              set removeContent [string map [list "/test" "" ] [HTTP::uri]]
              HTTP::redirect http://[HTTP::host]$removeContent
          }
      }

  • If verify with a CURL command, something like this will be seen:

config # curl -vk http://10.10.1.35/test/index.html                 <<-- Notice the complete URL
