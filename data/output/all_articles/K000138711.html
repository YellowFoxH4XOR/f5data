Description

How to enable LLDP using iControl REST APIs?

Environment

  • BIG-IP LTM v13.x or later
  • Using REST APIs

Cause

Though there are no specific functions to enable LLDP via REST API. But a tmsh command can be executed via iControl REST to achieve the same result.

Recommended Actions

A curl command can be used to enable LLDP for specific interface via iControl REST API. Syntax is given below:

 # curl -sku user:pass -X POST -H "Content-type: application/json" -d "{\"command\":\"run\", \"utilCmdArgs\": \"-c 'tmsh modify net interface 1.1 lldp-admin txrx'\"}" https://big-ip-mgmt/mgmt/tm/util/bash

Make sure to change the following:
user -> An user should have access bash/advanced shell access.
pass -> Password for above user.
1.1 -> Interface that needs to transmit and receive LLDP frames.
big-ip-mgmt -> Management IP of BIG-IP
