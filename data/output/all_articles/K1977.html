Topic

The following error occurs because forwarding virtual servers are intended to be used with networks and subnets, not specific host IP addresses:

b virtual 172.16.0.6:any netmask 255.255.255.255 forward
bigpipe: Virtual Server 172.16.0.6:0,  Ip address is not valid

You can work around this issue by using the following procedure.

Workaround

You can create a forwarding pool and a virtual server that uses the forwarding pool. The virtual server will use the same IP address that you want to forward through the BIG-IP system.

To configure this, use the following command syntax:

b pool <forward_pool> { forward }
b virtual <virtual IP address>:any use pool <forward_pool>
