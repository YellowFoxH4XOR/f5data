Description

When accessing the virtual server of BIG-IP APM, the browser maybe stuck and the screen like below:

"Waiting for Endpoint Inspection status"

In the log file C:\Users\<username>\AppData\Local\Temp\logterminal.txt , find the log like:

EPCHECK, 1, \f5/InputParamsBase.h, 109, f5::InputParamsBase::fill, EXCEPTION - sid parameter length is invalid, null
EPCHECK, 1, , 91, wWinMain, EXCEPTION caught: wWinMain
EPCHECK, 48, , 93, wWinMain, Endpoint check server process finished (res), -1

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • Endpoint Security (Client side)
  • Browser

Cause

In the access profile, the "HTTP Only" option is enabled for the cookie.

Recommended Actions

Please disable "HTTP Only" in the Cookie Options of the access profile, as it should not be enabled in this scenario.

  1. Login to the Configuration Utility.

  2. Navigate to Access  ››  Profiles / Policies : Access Profiles (Per-Session Policies).

  3. Click the Access Profile Name which applied to the virtual server.

  4. Under the tab SSO / Auth Domains, uncheck "HTTP Only", click "Update".

  5. Navigate to Access  ››  Profiles / Policies : Access Profiles (Per-Session Policies).

  6. Tick the access profile which applied to the virtual server, click "Apply".

Additional Information

For more information for the cookie option "HTTP Only", please refer to K15387:  Overview of BIG-IP APM session cookies.
