Known Issue

The Traffic Management Shell (tmsh) utility does not correctly validate whether the platform is supported when you use the tag-mode option to configure QinQ for a Virtual Local Areaa Network (VLAN). This situation allows you to enable the QinQ tag-mode option on a supported or unsupported platform.

This issue occurs when the following condition is met:

  • You use the following tmsh command syntax:

     tmsh create net vlan <name> tag <vlan tag> interfaces add { <interface> { tagged tag-mode <any value other than none> } }

Impact

There is no impact. Though the system allows you to configure QinQ tag-mode and an invalid value on non-supported platforms, the configuration has no effect, and there are no negative impacts to the system functionality.

Workaround

To work around this issue, you should configure the QinQ tag-mode option for only the following supported platforms:

  • BIG-IP 5050s and 5250v
  • BIG-IP 7050s and 7250v
  • BIG-IP 10050s and 10250v
  • BIG-IP VIPRION Blade B2150 SSD based models
