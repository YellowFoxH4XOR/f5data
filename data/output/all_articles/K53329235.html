K53329235: Support for 802.1x authentication with BIG-IP APM

Type
Support Solution
Published
2019-09-16
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM: 13.X.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.0.1, 13.0.0, 13.1.0
Source
https://my.f5.com/manage/s/article/K53329235

Description

Access Policy Manager (APM) does not support 802.1x Wired and Wireless Authentication.

Environment

  • Access Policy Manager (APM)
  • 802.1X Wired and Wireless Authentication

Cause

APM cannot be used as a network access solution for an 802.1x environment.

Recommended Actions

None.

Additional Information

802.1X is port based authentication over layer 2 (Data Link) and allows for dynamic VLAN assignment. APM is a SSL VPN solution (Application Layer Security).
