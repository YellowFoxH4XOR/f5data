K12426: The BIG-IP Edge Portal application for the Apple iPhone, iPad, and iPod touch does not show user favorites defined in FirePass

Type
Knowledge
Published
2010-12-08
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 7.0.0, 6.1.0
Source
https://my.f5.com/manage/s/article/K12426

Topic

The BIG-IP Edge Portal application for the Apple iPhone, iPad, and iPod touch will not show the user favorites defined in the FirePass controller. This is expected behavior. The user has to define an entry in the BIG-IP Edge Portal application for each resource they want to access.

F5 Product Development is tracking a request for enhancement (RFE) as ID 266978 to display user favorites in the BIG-IP Edge Portal application.
