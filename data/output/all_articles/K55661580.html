Known Issue

The Traffic Management Microkernel (TMM) may restart and produce a core file when processing non-HTML content types.

This issue occurs when all of the following conditions are met:

  • The Content-Type Selection list, in an HTML profile, is configured to process non-HTML content types such as text/javascript or other invalid mime types.
  • Your BIG-IP virtual server configuration includes the affected HTML profile and a Rewrite profile that is configured for URI translation.
  • The virtual server attempts to process the non-HTML content type.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting, and devices configured as a high-availability pair may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to a peer device in the device group.
  • TMM generates a core file in the /var/core directory.

Workaround

To work around this issue, you can modify the Content-Type Selection list in the HTML profile to only specify HTML content types.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
