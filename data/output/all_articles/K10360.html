Topic

The maximum number of CIFS sessions is 2,048 per client. This value is not configurable; it is enforced to prevent oversubscription of the ARX system and exhaustion of system resources.

When the maximum number of CIFS sessions is exceeded, the system drops new connections and logs a message that appears similar to the following example:

NET_CIFS-0-3-MSG3:: CIFS:Hit max sessions limit:2048 for client:10.8.1.150 - connection dropped.
