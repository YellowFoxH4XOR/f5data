K9695: The DNS Relay Proxy client component is not automatically updated

Topic

The DNS Proxy Relay service is an optional client component introduced in FirePass version 6.0.3. Currently, the DNS Relay Proxy client component is not automatically updated when a user logs on to the FirePass controller. After installing a hotfix or a new version of software on the FirePass controller, FirePass administrators can distribute the new version of the DNS Relay Proxy client for manual installation on the client systems.

You can download the DNS Relay Proxy client component on the Device Management : Client Downloads : Windows (x86) page in the FirePass Administrative Console.

Note: For more information about the DNS Proxy Relay service, refer to K9694: Overview of the DNS Relay Proxy service.
