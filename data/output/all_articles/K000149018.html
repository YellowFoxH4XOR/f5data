Description

Configuration of dynamic routing protocols using TMSH is not supported

Environment

  • BIG-IP where routing protocols (BGP, OSPF, BFD) can be configured via TMSH.

Cause

Added as an 'early access feature' in software version 13.1, the feature never entered official release state.

Answer/Recommended Actions

Use Zebos for dynamic routing protocol support

Additional Information

When enabling the feature, a warning is presented:

root@(localhost)(cfg-sync Standalone)(Active)(/Common)(tmos)# modify sys db tmrouted.tmos.routing value enable

root@(localhost)(cfg-sync Standalone)(Active)(/Common)(tmos)# list net routing

[api-status-warning] net/routing/profile/bgp is early_access
