K000148554: BigIQ has stopped showing ASM event logs

Support Solution
Published
2024-11-15
Updated

Applies to

  • BIG-IQ Centralized Management: 8.0.0, 8.1.0, 8.0.X, 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X
Source
https://my.f5.com/manage/s/article/K000148554

Description

BIG-IQ has stopped showing ASM event logs. Upon checking 'asmindex_writer' record within the BIG-IQ ElasticSearch aliases table is missing when using below command                                                                                         

 

# curl -s localhost:9200/_cat/aliases?v |grep -i asmindex_writer
  or
# curl -s -u admin:admin -k https://localhost:9200/_cat/aliases?v |grep asmindex_writer

 

Environment

  • BIG-IP AWAF successfully sent logs to BIG-IQ Centralized Management previously and stopped displaying now
  • Followed article K46666053 still logs are not displayed in BIG-IQ

 

Cause

The ASM index writer was missing. This issue can arise when the disk becomes full, causing BIG-IQ to run out of disk space due to accumulating events/logs. Additionally, the Elasticsearch alias "asmindex_writer" required for writing logs was not present.

 

Recommended Actions

  1. Find out latest ASM index using below command.                                                                           #curl -s -u admin:admin --insecure https://localhost:9200/_cat/indices?v  | grep -i asm                                                                                                                                                                                                                                                                                 
  2. Manual Creation of ASM Index Writer if Missing:                                                                            
  3. # curl -s -u admin:admin -k https://localhost:9200/_aliases -H 'Content-Type: application/json' -X POST -d '{"actions" : [ {"add" : { "index" : "asmindex_2024-10-08t18-05-14-0800" , "alias" : "asmindex_writer" }} ] }'
  6. In above example latest ASM index is asmindex_2024-10-08t18-05-14-0800. Proceed to check the ASM event log in the BIG-IQ
