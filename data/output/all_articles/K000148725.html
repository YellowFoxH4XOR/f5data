Description

What and where are log entries about licensing and usage monitoring in Nginx Plus R33.

Environment

  • Nginx Plus R33 and future versions

Cause

When the JWT token is not present, the usage report is not sent to F5.

Recommended Actions

Download the JWT token from MyF5 portal and place it and configure usage report.

Additional Information

Here is example of log entries 

nginx: [emerg] license expired
nginx: [emerg] cannot send usage report; traffic processing has been stopped
nginx: [warn] license will expire in 14 days
nginx: [alert] cannot send usage report; traffic processing will degrade in 178 days
[error] 36387#36387: server returned 500 for <fqdn>:<port> during usage report 
[error] 36528#36528: <fqdn>:<port> could not be resolved (host not found) during usage report 
[error] 36619#36619: connect() failed (111: Connection refused) for <fqdn>:<port> during usage report
