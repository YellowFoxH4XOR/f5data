Topic

This article describes the procedures for installing a BIG-IP 10.0.x hotfix on a BIG-IP system that uses the partitions disk formatting scheme. You cannot use the configuration utility to install a BIG-IP 10.x hotfix on a system using partitions. Instead, perform one of the following command line procedures to install the hotfix:

  • Installing a 10.0.x hotfix on a partitioned system when all other partitions are running version 9.x
  • Installing a 10.0.x hotfix on a partitioned system when another partition is running version 10.x

Important: If you are installing a BIG-IP ASM or BIG-IP WebAccelerator version 10.0.x hotfix, you can avoid a known issue by instead performing the procedure detailed in K11374: Installing a  BIG-IP WebAccelerator or BIG-IP ASM 10.0.x hotfix or product image may create a UCS file without a database configuration.

Important: Before following the procedures detailed in this article, you should review the information in K10025: Managing BIG-IP product hotfixes (10.x).

Important: F5 recommends that you install hotfixes using the serial console or an SSH connection to the management port IP address.

Note:  For more information, refer to the following articles:

  • K10817: Determining the disk-formatting scheme used by a BIG-IP version 10.x system
  • K6845: Managing BIG-IP product hotfixes (9.x)
  • The Installing a hotfix section in K10025: Managing BIG-IP product hotfixes (10.x)
  • If you are installing a BIG-IP version 10.0.0 hotfix, you may need to re-install the BIG-IP software on the partition from which you plan to perform the hotfix installation. Refer to K10063: BIG-IP 10.0.0 hotfix installations do not apply a configuration or license to the target installation location.

Installing a 10.0.x hotfix on a partitioned system when all other partitions are running version 9.x

  1. Log in to the command line.
  2. Determine the version 9.x partition from which you will run the hotfix installation, and the version 10.0.x partition on which the hotfix will be installed.

    Note: When installing a version 10.0.x hotfix on a partitioned system, you must run the hotfix installation from a partition other than the target partition. You must perform the installation from a version 9.4.2 or higher partition. Previous versions do not include all of the components used by the image2disk command, and installing a version 10.0.x hotfix from a lower-versioned partition will fail with the following error message:
    create_ucs failed; Illegal seek

    To determine the partition on which the 9.x and 10.0.x installations reside, type the following command:

    switchboot -l

    For example, the following switchboot -l command output indicates that the 10.0.x installation resides on the HD1.1 partition, and the 9.x installation resides on the HD1.2 partition:

    switchboot -l
    Current boot image:
        HD1.1 - title BIG-IP 10.0.0 Build 5401.0
    Default boot image:
        HD1.1 - title BIG-IP 10.0.0 Build 5401.0
    Available boot image(s):
        HD1.1 - title BIG-IP 10.0.0 Build 5401.0
        HD1.2 - title BIG-IP 9.4.6 Build 401.0     
  3. Set the default boot image to the 9.x installation location using the following command syntax:

    switchboot -b <9.x_location>
  4. Reboot the system to the version 9.x installation location by typing the following command:

    reboot
  5. Log in to the version 9.x installation.
  6. Change directories to the /shared/images/ directory by typing the following command:

    cd /shared/images/

    Note: If the /shared/images/ directory does not exist, you must create it by using the mkdir /shared/images/ command.
  7. Download the version 10.0.x hotfix ISO and MD5 files to the /shared/images/ directory.

    Note: BIG-IP version 10.x installation files are ISO archive files and use the .iso file extension.
  8. Verify the MD5 checksum for the hotfix.

    Note: For information about verifying the MD5 checksum for BIG-IP installation files, refer to K8337: Verifying the MD5 checksum for BIG-IP installation files.
  9. Use the image2disk command to install the version 10.0.x hotfix by using the following command syntax:

    image2disk --hotfix --nomoveconfig --instslot=<version_10.0.x_slot> <HF.iso>

    For example, if you are installing version 10.0.0-HF1 to the HD1.1 partition, you would type the following command:

    image2disk --hotfix --nomoveconfig --instslot=HD1.1 Hotfix-BIGIP-10.0.0-5460.0-HF1.iso

    Important: If you do not specify the --nomoveconfig switch, the BIG-IP system will save the 9.x configuration and install it on the 10.0.x partition. This behavior is undesirable during a hotfix installation.
  10. After the hotfix installation has completed, set the default boot image to the 10.0.x installation location using the following command syntax:

    switchboot -b <10.0.x_location>
  11. Reboot the system to the version 10.0.x installation by typing the following command:

    full_box_reboot

Installing a 10.0.x hotfix on a partitioned system when another partition is running version 10.x

Important: Do not use the image2disk utility to install the hotfix. Doing so may result in the following error:

Terminal error: SVM (Software Volume Management) is available, and this is not a format request.
Please use SVM, or include '--force' if you are sure you want to proceed.

If you receive this error, do not use the image2disk utility with the --force option; it will render your system non-functional. Instead, use the bigpipe software command to install the hotfix as described below.

  1. Log in to the command line.
  2. Determine the version 10.x partition from which you will run the hotfix installation, and the version 10.0.x partition on which the hotfix will be installed.

    Note: When installing a version 10.0.x hotfix on a partitioned system, you must run the hotfix installation from a partition other than the target partition. 

    To determine the partition on which each installation resides, type the following command:

    switchboot -l

    For example, the following switchboot -l command output indicates that a version 10.1.0 installation resides on the HD1.1 partition, and a version 10.0.1 installation resides on the HD1.2 partition:

    Current boot image:
        HD1.2 - title BIG-IP 10.1.0 Build 3341.0
    Default boot image:
        HD1.2 - title BIG-IP 10.1.0 Build 3341.0
    Available boot image(s):
        HD1.1 - title BIG-IP 10.1.0 Build 3341.0
        HD1.2 - title BIG-IP 10.0.1 Build 354.0

  3. Set the default boot image to a location other than that on which the hotfix will be installed using the following command syntax:

    switchboot -b <location>

    For example, to set the default boot image location to the version 10.1.0 partition in the example above, type the following command:

    switchboot -b HD1.1
  4. Reboot the system to the installation location by typing the following command:

    reboot
  5. After the system boots, log in to the command line.
  6. Change directories to the /shared/images/ directory by typing the following command:

    cd /shared/images/

    Note: If the /shared/images/ directory does not exist, you must create it by using the mkdir /shared/images/ command.
  7. Download the version 10.0.x hotfix ISO and MD5 files to the /shared/images/ directory.

    Note: BIG-IP version 10.x installation files are ISO archive files and use the .iso file extension.
  8. Verify the MD5 checksum for the hotfix.

    Note: For information about verifying the MD5 checksum for BIG-IP installation files, refer to K8337: Verifying the MD5 checksum for BIG-IP installation files.
  9. Use the bigpipe software command to install the hotfix image using the following syntax:

    bigpipe software desired <partition> product BIG-IP version <version_number> build <build_number>

    Note: The software version and the build number can be found in the ISO file name. For example, the Hotfix-BIGIP-10.1.0-3372.0-HF1.iso file contains BIG-IP 10.1.0, Build 3372.0

    For example, to install BIG-IP 10.0.1-HF4 on the HD1.2 partition, type the following command:

    bigpipe software desired HD1.2 product BIG-IP version 10.0.1 build 402.7.0
  10. To monitor the status of the hotfix installation from the command line, type the following command:

    watch bigpipe software status show

    The following sample command output from the bigpipe software status show command indicates that the installation status is 27.62 percent complete:

    SOFTWARE - Status:
    +-> SOFTWARE STATUS
    |   Key   Slot Product Version Build  Active Status
    |   HD1.1    0 BIG-IP  10.0.0  5401.0 yes    complete
    |   HD1.2    0 BIG-IP  10.0.0  402.7  no     installing 27.620 pct
  11. After the hotfix installation has completed, set the default boot image to the 10.0.x installation location using the following command syntax:

    switchboot -b <10.0.x_location>
  12. Reboot the system to the version 10.0.x installation by typing the following command:

    full_box_reboot
