Known Issue

Linux device users may be unable to launch the f5vpn client.

This issue occurs when all of the following conditions are met:

  • You download and install the browser f5vpn component for i386 Linux.
  • You attempt to initialize an access session from the Linux device by running the f5vpn component.

Impact

The access session fails to initialize.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the f5vpn component, the system displays an error message similar to the following example:

    f5vpn: error while loading shared libraries: libcrypto.so.1.0.0: cannot open shared object file: No such file or directory
