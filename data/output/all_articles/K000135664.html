Description

MS Defender for Cloud incorrectly detects the default SSL 'server.key' and/ or 'cakey.pem' file as insecure SSH key. Logs similar to the following may be observed:

server.key /appdata/mprov/local/HD1.1/mysqldb/server.key 01/03/2024, 06:13 AM
server.key /appdata/mprov/local/HD1.2/mysqldb/server.key 02/19/2024, 03:29 AM
cakey.pem /config/aaa/oam/AccessServerSDK/oblix/tools/openssl/simpleCA/cakey.pem

 

Environment

- BIG-IP on Azure

- Microsoft Defender for Cloud

 

Cause

MS Defender for some reason, thinks that the default BIG-IP server.key is an SSH key but it is actually the private SSL key used by internal process.

 

Recommended Actions

At this time, it is recommended to configure MS Defender for Cloud to ignore this as this is not an SSH key and there is no risk found to be associated in it being plaintext.
