Description

  • You observe messages similar to below in /var/log/ltm :
    err mcpd[<PID>]: 01071087:3: Killed connection for %TMM <PID> as current count of messages (xxxxxx) keeps building
    crit tmm[<PID>]: 01010020:2: MCP Connection aborted, exiting
     
  •  Multiple services suddenly restart.

Environment

  • BIG-IP
  • Multiple changes occurring on the device over a short period of time

Cause
The mcpd queries to tmm are getting overwhelmed.

Recommended Actions

  • Upgrade to version 15.x to benefit from the performance improvement introduced.
  • Use simple monitors ( tcp, icmp, etc, ...) instead of (tcp half open, https, etc ...).
  • Avoid doing too much iRule local logging and use high speed logging instead.
