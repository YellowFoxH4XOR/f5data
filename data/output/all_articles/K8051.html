K8051: Network Access policy registry checks for DWORD values need decimal conversion

Topic

In FirePass versions 6.0.2 and earlier, the Network Access policy checks can check Windows client systems for registry entries.  When creating a policy check that tests Windows registry key values of type DWORD, the test must be created in the policy using a decimal number, even if the key's value is entered as a hexadecimal number. Starting in FirePass version 6.0.3, the hexidecimal value can be used.

For example:

My Computer\HKEY_CURRENT_USER\Software\app1\testkey

If the example DWORD registry key contains a hexadecimal value of 0x000000ff, you would construct the following test for the exact value of the key using the decimal equivalent value (256) in the Check System registry field of the Policy Checks tab of the Network Access: Resources page:

"My Computer\HKEY_CURRENT_USER\Software\app1"."testkey" = "256"
