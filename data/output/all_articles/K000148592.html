Description

This page provides guidance on the MyF5 Self Service licensing for Flex Consumption Program (FCP). This is a step by step guide for generating license keys included in (Sized For) FCP contracts signed in January 2025 or later.

Environment

  • FCP Contract started January 2025 or later
  • BIG-IP Virtual Edition (VE)
  • MyF5 Customer Portal
  • Editor/Admin access to MyF5 Subscriptions

Cause

In this scenario, you need to generate license keys (+ Generate Registration Keys) that were included in the original FCP contact. 

There are two types of license keys:

  • Sized For (+ Generate Registration Keys): These are the license modules, add-ons, and planned quantities included in the original FCP contract.
  • New (+ Add to Subscription): These are fully customizable license modules and add-on combinations created after the FCP started. 

Recommended Actions

Generate license keys using the + Generate Registration Keys option from MyF5 Self Service.

  1. Logon to MyF5 and open the active FCP Subscription. 
  2. In Subscriptions, note the current Sized For products, capacity, quantity, and add-ons.
    • Product: The type of license, such as, best bundle, APM, NGINX, etc.
    • Capacity: Throughput or vCPUs
    • Sized for: The number of licenses included in the FCP contract
    • Add-ons: Such as concurrent VPN connections, DNS requests per second, Threat Campaign, etc. 
  3. For the product, if no license keys are available, select + Generate Registration Keys to create.
  4. In the slide out Summary page, select the Registration Keys Quantity amount then click submit. For BIG-IP VE, a maximum of 10 license keys can be generated at a time. For BIG-IQ, a maximum of 2 license keys can be generated at a time.
  5. Banners at the top of the page progress from yellow "Processing additions to subscription and generating Registration Keys" to green "Added to subscription; Registration Keys generated". A page refresh may be necessary to see this update. It may take up to 15 minutes for the keys to become available.
    • Note: If this request isn't successful after 30 minutes and an amber processing notification appears, please contact F5 Support.
  6. Under the product, the new license key status is "Ready to activate" and is available to be activated on a BIG-IP VE.
  7. If the BIG-IP VE is licensed from BIG-IQ, revoke that license first. Applying a new license without doing so results in two active licenses and causes potential billing issues. 
    • Revoke BIG-IP VE license offerings from the BIG-IQ
  8. Copy an available license key from MyF5 and activate it on the BIG-IP VE.
    • K7752: Licensing the BIG-IP system.
