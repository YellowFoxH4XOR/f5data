Description

All Learning Suggestions deleted for the ASM policy.
 

Environment

  • Disabled Learning Mode


Cause

When the Learning mode is disabled, ASM deletes pending Learning suggestions that were not Accepted or manually deleted.


Recommended Actions

None.
 

Additional Information

When the ASM policy is in Automatic Policy Building mode, the ASM will also delete learning suggestion after it has accepted the suggestion and applied it to the policy.
