K14749: Users cannot delete AAA server objects when deleting an access profile

Known Issue

You may encounter an error message when attempting to delete an access profile.

This issue occurs when all of the following conditions are met:

  • You have a AAA server or other resources associated with only one access profile
  • You attempt to delete this access profile and all associated resources at the same time

When you use the BIG-IP Configuration utility to delete an access profile, you have the option to simultaneously delete the resources and AAA servers used by that policy. This option is only presented if the policy you attempt to delete is the only policy using these resources or AAA servers.

Impact

You are unable to delete the access policy.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/apm file, you may observe an error message similar to the following:

    01071193:3: Cannot delete aaa active directory server (/Common/<aaa_pool>) because it is referenced by an agent (AD Auth) in access profile (/Common/<profile>).

Workaround

To work around this issue, you can delete the access policy and associated resources separately. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the BIG-IP Configuration utility.
  2. Click Access Policy.
  3. Click Access Profile.
  4. Click on the access profile you want to delete.
  5. Click Delete.
  6. Clear the options to delete AAA servers or other resources associated with this profile.
  7. Click Delete.

After completing this procedure, you can manually delete all of the resources associated with the access policy under the Access Policy menu options.
