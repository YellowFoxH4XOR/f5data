Known Issue

The BIG-IP system may not use all of the configured translation addresses. This issue occurs when all of the following conditions are met:

  • Two or more carrier-grade network address translation (CGNAT) virtual servers using the same source address ranges are associated with the same large-scale NAT (LSN) pool.
  • The LSN pool is configured for deterministic mode.

When multiple CGNAT virtual servers with the same source address ranges reference the same LSN pool, the translation addresses used by the BIG-IP system will be reduced by the same factor. For example, if there are three CGNAT virtual servers with the same source address ranges referencing the same LSN pool, the BIG-IP system will use one third of the translation addresses configured for the LSN pool.

Impact

As a result of the reduced numbers of translation addresses, CGNAT subscribers may experience service disruptions.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H425754 on the Diagnostics > Identified > Medium screen.
  • When configured in deterministic mode, the BIG-IP system does not use all translation configured addresses.
  • The dnatutil utility reports the available translation addresses that are a fraction of the number of subscriber addresses.
