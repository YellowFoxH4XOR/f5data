Description

This article explains the behavior of the Enforcement Readiness Period in BIG-IP Advanced WAF (ASM) security policy learning. It clarifies whether modifying the Enforcement Readiness Period resets the learning process or preserves existing data, and addresses if there is a way to monitor the progress or remaining days of the current learning period.

Environment

  • BIG-IP Advanced WAF (ASM)
  • Enforcement Readiness Period for ASM security policy learning
  • Security policy with learning mode enabled
  • Enforcement Readiness Period set to a custom value (default is 7 days, but can be configured as needed)

Cause

None

Recommended Actions

  1. Modifying Enforcement Readiness Period
    • Adjusting the Enforcement Readiness Period (for example, reducing it from 90 days to 60 days) does not reset or restart the learning process.
    • All previously learned data and entities are preserved after changing this value.
    • The system continues with its current state, maintaining both enforced and not-enforced entities as before.
  2. Monitoring Learning Progress
    • There is currently no built-in feature in ASM to display how many days have elapsed or remain in the current Enforcement Readiness Period.
    • A Request for Enhancement (RFE) Bug ID1089737 , exists for this functionality, but it has not been implemented yet.
    • As an alternative, users may attempt to infer timing from audit logs; however, this method is not practical for routine use.
