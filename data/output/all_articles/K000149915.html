Security Advisory Description

inffast.c in zlib 1.2.8 might allow context-dependent attackers to have unspecified impact by leveraging improper pointer arithmetic. (CVE-2016-9841)

Impact

This vulnerability may allow an attacker to cause a denial-of-service (DoS) on the BIG-IP or BIG-IQ system.

Security Advisory Status

F5 Product Development has assigned ID 1672313 (BIG-IP), ID 1672313-1  (BIG-IQ) and ID 1671653 (APM Clients) to this vulnerability.

Mitigation

The following mitigations are currently available. Additional mitigations may become available in the future as this security advisory is investigated further.

BIG-IP

To mitigate this vulnerability, you can: 

Impact of action: Depending on your environment, changing the compression method may result in different effects on performance. F5 recommends testing the change in a staging environment prior to implementing the change.

  • Set the Preferred Method of the HTTP Compression profile to Gzip.
  • Use gzip as the compression method in iRules

Note: For more information, refer to K15434: Overview of the HTTP Compression profile and the F5 Cloud Docs article, COMPRESS commands.

To update an HTTP Compression profile, use one of the following procedures:

  • Configuration utility
  • TMOS shell (tmos)

Configuration utility

  1. Log in to the BIG-IP Configuration utility.
  2. Go to Local Traffic > Profiles > Services > HTTP Compression.
  3. Select the affected profile.
  4. Change the Preferred Method setting to Gzip if not already configured.
  5. Select Update.

TMOS shell (tmsh)

To update an HTTP Compression profile on the tmos shell (tmsh):

  1. Log in to the TMOS Shell (tmsh) by typing the following command:
    tmsh
  2. To configure gzip in the compression profile, use the following command command syntax: 
    modify ltm profile http-compression <compression profile name> method-prefer gzip

    For example, enter the following command:
    modify ltm profile http-compression example_profile method-prefer gzip

  3. Save the changes by entering the following command:
    save /sys config
