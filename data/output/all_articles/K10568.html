Known Issue

This is the result of a known issue. If a user fails a pre-logon check, and the logon page language is set to French, FirePass displays an error message that appears similar to the following example:

Connexion refuse

The error message should instead appear as:

Connexion refusee

F5 Product Development tracked this issue as CR124417 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.
