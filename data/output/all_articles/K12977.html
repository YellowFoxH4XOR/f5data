K12977: BIG-IP GTM now supports discovery and monitoring of BIG-IP virtual server objects that are associated with route domains

Issue

Old Behavior

In versions of BIG-IP GTM prior to 10.2.2, BIG-IP GTM and big3d-related traffic is not compatible with the route domain feature, and the BIG-IP GTM system cannot discover or monitor virtual server objects that are configured in non-default route domains.

The BIG-IP system, by default, includes one route domain with an ID of 0. The BIG-IP GTM system is able to discover and monitor virtual server objects that are configured in the default route domain.

New Behavior

Beginning in BIG-IP GTM 10.2.2 (note that this functionality also exists in BIG-IP 10.2.1 HF-1, and later), BIG-IP GTM and big3d-related traffic is compatible with the route domain feature, and it is possible to configure the BIG-IP GTM system to discover and monitor BIG-IP virtual server objects that are associated with one or more route domains.

Note: For information about configuring GTM and big3d-related traffic so it is compatible with route domains, refer to K12969: Configuring GTM and big3d-related traffic to be compatible with route domains.

F5 Product Development tracked this change as ID 221998.
