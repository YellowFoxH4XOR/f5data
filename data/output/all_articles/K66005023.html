Description

The BIG-IP system uses an IP geolocation database to source data about the origin of an IP address.  
This can be used to drop dns requests originating from unwanted sources  

Environment

  • BIG-IP DNS
  • IP geolocation
  • Drop DNS requests

Cause
You want to drop dns requests from specific countries.

Recommended Actions

An iRule can be used in conjunction with GSLB Topology records to drop unwanted queries.

In the following example, all requests originating outside the UK are dropped:
  1. Using WideIP Irule:

    when DNS_REQUEST {
    set My_country [whereis [IP::client_addr] country]
    if { [whereis [IP::client_addr] country] ne "GB" } {
       log local0. "Cilent is from $My_country  which is not UK ..dropping"
            drop
        }
    }
     
  2.  Using GSLB Topology Records:
    a) Create a GSLB Pool ( expl: Drop_pool) with both the 'Preferred' and 'Alternate' Load Balancing Methods set to 'Drop Packet'
    b) Then, Create a GSLB Topology Records to send unwanted traffic ( for example non UK traffic) to the GSLB Pool 
    Request Source >> Country is not  >> United Kingdom
    Destination >> Pool is >> Drop_pool
