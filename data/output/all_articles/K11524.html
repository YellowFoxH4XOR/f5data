K11524: The pvac process internal memory threshold calculations

Issue

In BIG-IP WebAccelerator versions prior to 10.2.0, the pvac process uses the provisioned memory value to calculate various internal memory thresholds, and caps the internal memory buffer pool size at 2 GB. Although the BIG-IP WebAccelerator can use a maximum of 4 GB memory, it is possible to provision the BIG-IP WebAccelerator with more than 4 GB. When the BIG-IP WebAccelerator is provisioned with more than 4 GB, the internal memory thresholds are calculated at a percentage of provisioned memory rather than as a percentage of useable memory. As a result, the calculated thresholds may not be optimal.

Beginning in  BIG-IP WebAccelerator 10.2.0, and in BIG-IP WebAccelerator 10.1.0-HF1, the pvac process uses the provisioned memory value up to a maximum of 4 GB to calculate the internal memory thresholds, and the internal memory buffer pool size is no longer limited to 2 GB. When the BIG-IP WebAccelerator is provisioned with more than 4 GB, the pvac process calculates the internal memory thresholds as if the BIG-IP WebAccelerator was provisioned with 4 GB. The maximum size of the internal memory buffer pool is one of the calculated threshholds, and is no longer limited to 2 GB.

This change was a result of CR138494.
