Description
In the violation details of HTTP protocol compliance failed > Check maximum number of parameters compliance check, ASM reports an incorrect number of total parameters in the request. ASM violation details will look like as follows.

HTTP ValidationCheck maximum number of parameters
DetailsNumber of total parameters <number> in request (query string and post-data) exceed maximum limitation
Applied Blocking SettingsBlock   Alarm   Learn







Environment

  • ASM module is provisioned
  • The number of parameters in HTTP request exceeds the max number configured for the Check maximum number of parameters compliance
  • Violation of HTTP protocol compliance failed > Check maximum number of parameters is detected

Cause
It is due to a change in behavior from software fixes added by K58102101 (ID 917509) and ID 940897. As a result of the fix, ASM stops parsing parameters once it reaches a configured threshold. As a result, it is impossible to report the total number of parameters on BIG-IP versions with the fix.

F5 is currently investigating how to address the issue.

Recommended Actions
This is an issue with the logging of the number of parameters. The compliance check feature works as expected.
