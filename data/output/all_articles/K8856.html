Known Issue

This is the result of a known issue. If an SSL certificate specified within an SSL profile is also listed in a Trusted CA Chain file associated with the SSL profile, the SSL connection will fail to connect.

This behavior occurs when the client attempts to use the certificate at the same time TMM is accessing the server certificate within the chain.

F5 Product Development tracked this issue as CR71565 and it was fixed in BIG-IP 9.4.5. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.1-HF3 issued for BIG-IP 9.3.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.
