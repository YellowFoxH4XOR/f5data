K30214610: Configuring the maximum number of HTTP chunks allowed for a request

Type
Knowledge
Published
2018-10-24
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.0.0, 13.1.1, 13.1.0
Source

Topic

You should consider using this procedure under the following condition:

  • You want to change the maximum number of HTTP chunks allowed for a request.

Description

Chunked transfer encoding allows dynamically generated HTTP content to be transferred as a series of sequential chunks. The chunking mechanism divides the body of an HTTP message into a series of chunks, each of which is transferred independently of one another. Each chunk indicates its size in bytes, and ends with a zero-length chunk.

By default, the BIG-IP ASM system allows up to 1000 chunk segments for a request. The system blocks requests containing more than 1000 chunks, and generates the following message in the BIG-IP ASM event log:

Unparsable request content Chunks number exceeds request chunks limit: 1000.

You can adjust the maximum number of chunk segments that the BIG-IP ASM system allows by modifying the request_max_chunks_number internal variable.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have access to the BIG-IP ASM Configuration utility or the Advanced Shell (bash).

Procedures

Configuring the maximum number of HTTP chunks allowed for a request using the Configuration utility

Impact of procedure: Restarting the BIG-IP ASM service results in a brief service interruption.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Click Create.
  4. In the Parameter Name field, type the following variable name:

    request_max_chunks_number

  5. In the Parameter Value field, enter a value for the maximum number of HTTP chunks to allow for a request.
  6. Click Create.
  7. Log in to the command line.
  8. Restart the asm process by typing the following command:

    bigstart restart asm

Configuring the maximum number of HTTP chunks allowed for a request using the command line

Impact of procedure: Restarting the BIG-IP ASM service results in a brief service interruption.

  1. Log in to the BIG-IP ASM command line.
  2. To modify the the maximum number of HTTP chunks allowed for a request, use the following command syntax:

    /usr/share/ts/bin/add_del_internal add request_max_chunks_number <value>

    For example, the following command sets the maximum number of HTTP chunks allowed for a request to 1200:

    /usr/share/ts/bin/add_del_internal add request_max_chunks_number 1200

  3. After you modify the parameter, restart the BIG-IP ASM service by typing the following command:

    tmsh restart /sys service asm
