Topic

You can use alphanumeric characters in the security officer (SO) password for FIPS, as well as the following special characters:

' ! @ # $ % ^ & * ( ) -

Note: If you use a shell script to create or handle an SO password, the script might interpret the special characters by applying a special meaning as specified by the shell script language. F5 recommends that you ensure that all special characters are escaped properly if you use a shell script to create or manage an SO password.
