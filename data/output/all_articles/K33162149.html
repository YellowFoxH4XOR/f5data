Description

After upgrade BIG-IQ device to version 8.2 swap partition reporting size of 0 

example of output from  free -ght

              total          used          free       buffers        cached
Mem:          47.2M         46.8M        367.1K        283.8K         20.2M
-/+ buffers/cache:          26.3M         20.9M
Swap:             0             0             0
Total:         47.2M         46.8M        367.1K

Before upgrade size of /swap was increased to random values

Environment

  • BIG-IQ CM  upgrade to 8.2
  • Modified swap partition before upgade

Cause
Not Known

Recommended Actions

Use updateswap utility to recreate swap partition following steps in article :
K14100475: Allocating swap volume size using the BIG-IQ updateswap utility
