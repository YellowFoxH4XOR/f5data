Topic

When BIG-IP ASM receives client requests that include large parameter values, the ASM enforcement daemon may take a long time to perform negative regular expression checks against the request.

To prevent the delay, BIG-IP ASM 9.2.4 introduced an internal threshold, which defines the maximum request length negative pattern on which checking will be performed. BIG-IP ASM will cease to perform negative pattern checking for client requests larger than the specified threshold, and the following violation will be issued:

VALUE_TOO_LONG_FOR_PATTERN_CHECK

Note: BIG-IP ASM does not block the request that causes reporting of this violation. This violation is not reported in the Forensics section of the Configuration utility; it is reported in the /var/log/asm file.

BIG-IP ASM 9.2 and 9.3 software branch

In BIG-IP ASM 9.2.4 and later of the 9.2 software branch, including the 9.3 software branch, the default value is 300K. This value is configurable using the max_len_for_pattern_checks internal parameter. However, the max_len_for_pattern_checks internal parameter must first be entered manually into the BIG-IP ASM database before it is viewable on the internal parameters section of the Configuration utility.

Changing the max_len_for_pattern_checks internal parameter

To change the max_len_for_pattern_checks internal parameter, perform the following procedure:

  1. Log in to the BIG-IP ASM command line.

  2. Create the max_len_for_pattern_checks entry in the BIG-IP ASM database by typing the following command:

    Note: The following command has been split into multiple lines for formatting purposes only. Type the following command in one continuous string.

    mysql -p4Dm1n DCC -e "INSERT INTO INTERNAL_CONFIG_ITEMS VALUES
    (371,1,'max_len_for_pattern_checks','307200,'xxxxx','',NULL,0,0,2147483647,0);"

    Replace xxxxx in the above command with the desired value. For example, 51200.

  3. Restart the ASM daemon by typing the following command:

    bigstart restart asm

After this procedure has been performed once, you can view and configure the max_len_for_pattern_checks parameter in the internal parameters section of the Configuration utility. For information about accessing the internal parameters page, refer to K3853: Accessing the Internal parameters page.

BIG-IP ASM 9.4 software branch

In BIG-IP ASM 9.4 the default value is 50K. You can view and configure this value by using the max_len_for_pattern_checks internal parameter on the internal parameters section of the Configuration utility. For information about how to view or configure internal parameters, refer to K3853: Accessing the Internal parameters page.

Note: The max_len_for_pattern_checks internal parameter and its functionality was removed from the product in BIG-IP ASM 9.4.2 and later. Therefore, if you perform a fresh installation of BIG-IP ASM 9.4.2 or later, the max_len_for_pattern_checks internal parameter does not exist. However, the parameter is retained when a BIG-IP ASM is upgraded from an older version to a newer version (for example, if you upgrade a BIG-IP ASM 9.4.1 system to 9.4.3, or you import an older policy, the parameter is retained in the newer version).
