Topic

You should consider using this procedure under the following condition:

  • BIG-IP ASM, F5 BIG-IP Advanced WAF, and BIG-IP AFM are provisioned.

Description

When both BIG-IP ASM and AFM modules are provisioned, you must perform extra steps to navigate to the DoS Profile Properties page.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have administrative access to the Configuration utility.

Procedures

Navigate to the DoS Profile Properties page

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > DoS Protection > Protection Profiles.
  3. Under Profile Name select the protection profiles that have HTTP under Families.
  4. In the HTTP row, select the Edit link.
  5. Under HTTP Properties, select Use Legacy Application DoS view.

    The DoS Profile Properties page opens.
