Topic

F5 policies strictly prohibit the use of third-party hardware components with F5 products. For example, third-party power supplies, memory modules, hard disk drives, and XFP/SFP/QSFP+ optical components are not supported for use with F5 products, and may invalidate the product's warranty or inhibit efforts by F5 Customer Support to service or troubleshoot the altered product.

F5 Hardware Engineering and Testing teams have spent significant time and effort to ensure that all hardware components and modules sold by F5 have been tested and approved to work with our platforms to the specifications outlined in the product platform guides. Only parts tested in this manner and purchased from F5 are supported in our platforms.

This verification process is especially critical for the 100G interfaces, and possibly higher-speed interfaces in the future, as vendor specific tuning is necessary for such speeds. By using non-F5 qualified transceiver modules, the risk of resolving link-related issues will only increase and F5 Customer Support will be unable to escalate any link-related issues involving non-F5 qualified transceiver modules. For the best possible experience, ensure that your BIG-IP platform is using F5 qualified transceiver modules.

To purchase add-on hardware components for your BIG-IP platform, contact your F5 Reseller or F5 Sales Representative for specifications and pricing.

QSFP+ breakout cable

F5 offers three length options for the QSFP+ breakout cable -- 1 meter, 3 meters, and 10 meters. However, these cables have no active components/transceivers on either end. Therefore, if you require a QSFP+ breakout cable length other than the three lengths offered by F5, you may be able to purchase QSFP+ breakout cables of equivalent specifications from third-party vendors. For more information, refer to K15045: QSFP+ breakout cable options.

Verifying vendor names for XFP/SFP/QSFP+ optical components

  • BIG-IP 11.x and later
  • F5OS

BIG-IP 11.x and later

For BIG-IP 11.x and later, you can use the following TMOS Shell (tmsh) command to list the vendor names associated with any optical modules installed:

tmsh list net interface all vendor

The command output appears similar to the following, truncated example, which shows modular interfaces 2.1, 2.2 containing F5-branded SFPs, and interface 2.3, which contains an unsupported third-party module that may not perform as expected. Interface 2.4 is unpopulated. Interface 1.1 and mgmt are on-board RJ45 ethernet, which are displayed as none.

net interface 1.1 {
vendor none
}
net interface 2.1 {
vendor "F5 NETWORKS INC"
}
net interface 2.2 {
vendor "F5 NETWORKS INC"
}
net interface 2.3 {
vendor "FINISAR CORP"
}
net interface 2.4 {
vendor none
}
net interface mgmt {
vendor none
}

F5OS

For F5OS you can use the following command to list the vendor names associated with any optical modules installed:

show portgroups portgroup state vendor-name

The command output appears similar to the following example:

PORTGROUP                    
NAME       VENDOR NAME       
-----------------------------
5          F5 NETWORKS INC.  
6          F5 NETWORKS INC.  

BIG-IP 10.x (legacy product information)

For BIG-IP 10.x you can use the following bigpipe command to list the vendor names associated with any optical modules installed:

bigpipe interface all vendor

The command output appears similar to the following, truncated example, which shows modular interfaces 2.1, 2.2 containing F5-branded SFPs, and interface 2.3, which contains an unsupported third-party module that may not perform as expected. Interface 2.4 is unpopulated. Interface 1.1 and mgmt are on-board RJ45 ethernet, which will be displayed as none.

INTERFACE 1.1 - Vendor: none
INTERFACE 2.1 - Vendor: F5 NETWORKS INC
INTERFACE 2.2 - Vendor: F5 NETWORKS INC
INTERFACE 2.3 - Vendor: FINISAR CORP
INTERFACE 2.4 - Vendor: none
INTERFACE mgmt - Vendor: none
