Known Issue

This is the result of a known issue. If you install cumulative hotfix HF-602-5 on a FirePass controller, Domino Web Access (DWA) features may not function properly in Firefox when accessed through the Portal Access reverse-proxy engine. When this issue occurs, the user can log on to DWA, but when the user clicks any of the tabs, such as Mail, Calendar, or To Do, DWA reports an error message that appears similar to the following example:

Domino Web Access Warning. Sorry, we were unable to process your request at this time. If you are unable to continue working in your mail file, please dismiss this warning and then select View, Reload from your browser's menu.

Additionally, the associated items under each tab are not displayed in the browser. For example, email messages do not appear under the Mail tab and calendar entries do not appear under the Calendar tab.

F5 Networks Product Development tracked this issue as CR104710  and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

This issue was fixed in cumulative hotfix HF-602-6 issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround
 
You can work around this issue by uninstalling cumulative hotfix HF-602-5 from the FirePass controller. For instructions about removing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Alternatively, users can work around this issue by connecting to FirePass using a different browser, such as Internet Explorer.
