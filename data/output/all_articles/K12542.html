Known Issue

The BIG-IP system may incorrectly parse a remote role configuration object.

This issue occurs when one of the following conditions is met:

  • The remoterole configuration object is configured with an attribute ending in role.
  • The remoterole configuration object is configured with an attribute ending in deny and has a deny directive.

For example, the BIG-IP system would fail to parse the following remoterole configuration object containing both conditions:

remoterole {
   role info {
      lbbw-lob-role {
         attribute "lobrole=0"
         console "enable"
         line order 1001
         role "administrator"
         user partition "all"
      }
      lbbw-lob-rolet {
         attribute "lobdeny=0"
         deny enable
      }
   }
}

Impact

Remote authenticated users may be unable to login or have unexpected permissions.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Remote authenticated users are unable to log in or have unexpected permissions.

Resolution

Status

F5 Product Development has assigned ID 337934 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of Fix Fixes Introduced In Related Articles
Release None None
Hotfix None None

Workaround

To work around this issue, you can configure remote role attributes with a name that does not end with role or deny.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
