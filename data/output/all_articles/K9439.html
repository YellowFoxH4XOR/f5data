K9439: Network Access client components may fail to automatically install on a Linux client

Topic

In order to automatically install the FirePass or BIG-IP SAM Network Access client components on a Linux client system, the user must have sudo privileges on the client system or know the root (superuser) password. Sudo is a program that allows the user to run commands using the privileges of another user, typically root.

When the user launches a Network Access connection for the first time on a Linux client system, FirePass or BIG-IP SAM prompts the user to install the Network Access client components. The user is given two options for an automatic installation:

  • Enter the user’s password in the Password field and select the sudo password option button.
  • Enter the root password in the Password field and select the root password option button.
 
By default, the sudo password option is selected. The sudo password installation will fail if any of the following conditions are met:
  • The Linux client system does not use the sudo program.
  • The Linux client system uses the sudo program, but the user is not listed in the sudoers file.

    Note: The sudoers file is typically located at /etc/sudoers.
     
  • The user is listed in the sudoers file, but the user does not have the necessary sudo privileges to install the FirePass client components.

    Note: Sudo privileges are configured in the sudoers file.
  • The user has the necessary sudo privileges to install the FirePass client components, but the sudoers file contains the following line:

    Defaults requiretty
     
    Important: Some Linux distributions, such as Fedora 8 and Fedora 9, contain this line in /etc/sudoers by default.

If the user cannot install the client components using the sudo password option, and the user knows the root password, the user can select the root password option button to install the client components with root privileges. If both the sudo installation and the root installation fail, refer to the FirePass Controller Client Compatibility Matrix (FirePass versions 6.0.1 and later), the FirePass Release Notes (FirePass versions 6.0.0 and earlier), or to the BIG-IP Secure Access Manager Compatibility Matrix (all versions of BIG-IP SAM) to ensure that the client system is running a supported version of Linux.

If the client system is running a supported version of Linux, and both the sudo and root installation methods fail, contact F5 Networks Technical Support. Alternately, if you are running FirePass, refer to K9438: Manually installing the FirePass Network Access client components on a Linux client.
