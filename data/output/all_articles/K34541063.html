K34541063: Bypass Access Policy with an iRule

Type
Support Solution
Published
2020-08-19
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP APM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K34541063
Description

There is a virtual server with an APM Access Policy attached for authentication.
Specific traffic needs to bypass authentication.
For example to be forwarded directly to a pool.

Environment

  • BIG-IP APM
  • Virtual Server with Access Policy
Cause

All clients are required to be authenticated if an Access Policy is added to the Virtual Server.

Recommended Actions

Create an iRule, identify the traffic to bypass the Access Policy and use ACCESS::disable event to disable the Access Policy for the connection.

For example:
when HTTP_REQUEST {
       # Check the requested HTTP path
       switch -glob [string tolower [HTTP::path]] {
              "/apm_uri1*" -
              "/apm_uri2*" -
              "/apm_uri3*" {
                     # Disable APM for these paths
                     ACCESS::disable
                     # Forward request to a pool
                     pool my_pool
              }
              default {
                     # Enable APM for all other paths
                     ACCESS::enable
              }
       }
}
