Description

After a pool member is forced offline on an active unit, a config sync is performed, and the pool member re-enabled on the active unit, the same pool member remains down on the standby unit.

Environment

  • BIG-IP LTM
  • Pool member status on standby unit is incorrect
  • Sync of device group when pool member is forced offline

Cause

Bug ID 1297257

Recommended Actions

Apply the workaround for Bug ID 1297257 and upgrade to fixed software version.
