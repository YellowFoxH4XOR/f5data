K000148404: F5OS-C Getting error on Users & Roles page in Velos partition GUI

Type
Support Solution
Published
2024-11-06
Updated
2024-11-06
Applies to
  • F5OS
  • F5OS-C: 1.6.X, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000148404

Description

  • On Velos Chassis Partition GUI when navigating to Authentication and Access >> Users and Roles, you see below error:

    Server error: Failure for data/openconfig-system:system/aaa/authentication/f5-system-aaa:users API. The server or an underlying service is unreachable.

  • One Velos controller shows no output for partition2_user_manager on the partition show system health output

    Example:

    show system health
     
    controller-1
     
    services controller/services/partition2_user_manager
     state name partition2_user_manager
     state health ok
     state severity info
     
    controller-2
     
    No output for partition2_user_manager

Environment

  • F5OS-C 1.6.2
  • GUI
  • Users & Roles page

Cause

The partition2_user_manager is not running on the affected controller.

Recommended Actions

From affected controller (Login as root), start the partition user_manager container by running the following command:

docker container restart partition2_user_manager

Additional Information

None
