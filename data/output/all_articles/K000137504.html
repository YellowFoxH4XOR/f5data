K000137504: Controller upgrade failed from 1.5.1-14085 to 1.6.1-19136

Type
Support Solution
Published
2023-11-08
Updated
2023-11-08
Applies to
  • F5OS
  • F5OS-C: 1.6.1
Source
https://my.f5.com/manage/s/article/K000137504

Description

System controller upgrade failed with "Compatibility verification failed" error.

Compatibility verification failed.
error-type : application
error-tag : malformed-message
error-path : /openconfig-system:system/f5-system-controller-image:image/set-version
error-message : Compatibility verification failed.
 

You can see also following error in the log controller  /var/log_controller/cc-upgrade.dbg :

Upgrade transaction failed to validate: /oc-sys:system/aaa/authentication/f5-aaa-ldap:ldap/ssl (value "start_tls"): ssl cannot be start-tls with server type ldaps

Environment

  • F5OS - VELOS
  • Upgrade to v1.6.1
  • LDAP config

Cause

Issue with LDAP validation during the upgrade, even if LDAP is not configured and LDAP server-groups are not present

Recommended Actions

Adjust "system aaa authentication ldap ssl start_tls" to "system aaa authentication ldap ssl on" or "system aaa authentication ldap ssl off"

Additional Information

None
