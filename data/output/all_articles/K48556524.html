Description

Packets sent out of a VLAN with a single interface when the interface was DOWN.

Environment

  • VLAN

Cause

It is possible for packets to be sent out of a VLAN with a down interface. This is because a VLAN itself is not marked down when an interface it uses is marked down.

Recommended Actions

None

Additional Information

VLANs may be assigned multiple interfaces or trunks.
