Description

  • Attempting to add a Universal persistence profile to a Virtual Server or Sync a config with Universal persistence causes an error.

Environment

  • LTM
  • Virtual Server with Universal persistence

Cause

Universal persistence uses an irule to set up the persistence data. However that irule doesn't make the load balancing decision. A Universal persistence profile is used for that.
The irule is specified inside the Universal persistence profile. If that irule is also applied to the Virtual Server directly then it is called twice. This is an invalid configuration.

  • If the irule is applied first and subsequently the persistence profile is added, then this error will be reported.
  • If the persistence profile is applied first and subsequently the irule is added, no error is reported. However it is still invalid, the results are indeterminate and the configuration may fail to load on later releases.

Recommended Actions

  1.  Remove the irule from the Virtual Server.
