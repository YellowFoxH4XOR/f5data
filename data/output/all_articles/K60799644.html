Issue

Error Message

Disk partition <partition> has only <free_space> free

In this error message, note the following:

  • <partition> is the name of the disk partition.
  • <free_space> is the percentage of disk space available.

For example:

err diskmonitor: 011d0004: Disk partition var has only 0% free

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • Available disk space on the BIG-IP system dropped below a critical threshold.

The diskmonitor utility runs periodically to monitor disk usage on the BIG-IP system. When free space for a partition falls below a defined threshold, the diskmonitor utility sends this error message to the syslog-ng utility.

Impact

Further increases in disk usage may degrade system performance over time and can eventually lead to traffic disruptions. Upgrades and hotfix installations may fail due to a lack of available disk space, and disk read and write operations may fail.

Recommended Actions

To help prevent disk utilization issues on the BIG-IP system, F5 recommends that you follow the guidelines outlined in

  • K14403: Maintaining disk space on the BIG-IP system.
  • K21175584: Removing unnecessary OPSWAT EPSEC packages from the BIG-IP APM system 
  • K000133778: Unable to delete Epsec Packages from GUI or CLI after removing them manually
