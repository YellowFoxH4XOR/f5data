Policy Information

F5 hereby announces the End of Life plan for the Windows 98 (including Windows 98 Second Edition) and Windows ME client support feature in FirePass. This applies to all fully licensed FirePass products running on 600, 1000, 4000, 1200 and 4100 hardware platforms.

Microsoft announced the end of Extended Support for Windows 98 and Windows ME in July 2006. Security patches and bug fixes will no longer be available as a part of Microsoft's support options, as stated in following URL:

http://www.microsoft.com/windows/support/endofsupport.mspx

ProductFeatureFeature End of Software Development (EoSD)

600, 1000, 4000, 1200 and 4100 Platforms		10/1/2006

Product Support

If you are using Windows 98 and Windows ME Clients for remote access, F5 will continue to provide software and phone support in accordance with your maintenance contracts.

After the End of Software Development (EoSD) date, 10/1/2006, F5 Networks will not provide software fixes for any technical issues with Windows 98 and Windows ME Remote Access Clients connecting to FirePass. In addition, after the EoSD date, 10/1/2006, F5 will provide technical support for Windows 98 and Windows ME clients on a best-effort basis.

For information about End of Life terms and definitions, refer to the End of Life Cycle Glossary located in K3225: F5 Networks End of Life Policy.
