Topic

You should consider using this procedure under the following condition:

  • You want to test a BIG-IP update or upgrade in a lab environment using a BIG-IP Virtual Edition (VE) system and lab license.

Description

When planning your BIG-IP software updates or upgrades, you can install your production configuration on a BIG-IP VE lab system and test the upgrade procedure in a lab environment before running the upgrade in production. Doing so can help you become familiar with the upgrade steps and may help you find potential issues before you encounter them in a production environment. To test the upgrade procedure using a BIG-IP VE lab system, perform the following procedures:

  • Obtain a BIG-IP VE Version Plus license
  • Confirm your cloud / hypervisor environment
  • Download the BIG-IP VE images
  • Deploy and license the BIG-IP VE system
  • Install the production configuration on the BIG-IP VE system
  • Install the upgrade version on the BIG-IP VE system

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have a current user configuration set (UCS) backup file that contains the BIG-IP configuration data from your production environment.

Procedures

Obtain a BIG-IP VE Version Plus license

F5 offers a low-cost developer lab license to help F5 customers improve their deployment, development, and upgrade practices for the BIG-IP platform. Contact your F5 Sales representative to purchase the BIG-IP VE Version Plus license and ask for the appropriate BIG-IP VE SKU for your environment. If you want to test the upgrade process for a BIG-IP HA configuration, you may need to purchase more than one license.

For information about the BIG-IP VE Version Plus license, refer to the following article: K15643: BIG-IP VE Version Plus license offerings.

Confirm your cloud / hypervisor environment

Before you download and deploy the BIG-IP VE image, confirm that your cloud / hypervisor environment is compatible with the BIG-IP VE release you want to install. For more information, refer to: BIG-IP Virtual Edition Supported Platforms.

For example, if you are running VMware ESXi hypervisor 7.0 and want to test upgrading your system from 15.1.x to 16.0.x, review the BIG-IP Virtual Edition Supported Platforms matrix to confirm that F5 supports these versions of BIG-IP VE on the specified hypervisor.

Download the BIG-IP VE images

Next, download the appropriate BIG-IP VE images as required for your environment. You need the following images to complete the initial deployment and update or upgrade process:

  • An image to deploy a BIG-IP VE; the image should be the same version that you are currently running in production.
  • An image to update or upgrade the BIG-IP VE system; the upgrade file should be the version to which you intend to upgrade your production system.

For example, if you plan to test the update or upgrade process in a VMware ESXi environment, you should download the following images:

  • The BIG-IP VE OVA image that matches the BIG-IP version that you are currently running in production.
  • The BIG-IP VE ISO upgrade file that matches the BIG-IP version to which you intend to upgrade.

For specific instructions for downloading software, refer to K167: Downloading software and firmware from F5.

Deploy and license the BIG-IP VE system

After you have downloaded the images, deploy the BIG-IP VE image to the cloud or hypervisor environment and install the BIG-IP VE Version Plus license. For information about deploying the BIG-IP VE image to your cloud or hypervisor environment, refer to the following resources:

  • Cloud
    • Deploy BIG-IP VE in AWS
    • Deploy BIG-IP VE in Microsoft Azure
    • Deploy BIG-IP VE in Google Cloud
    • Deploy BIG-IP VE in Alibaba Cloud
    • Deploy BIG-IP VE in Oracle Cloud Infrastructure
  • Hypervisor
    • Deploy BIG-IP VE in VMware ESXi
    • Deploy BIG-IP VE in Linux KVM
    • Deploy BIG-IP VE in Linux Xen Project
    • Deploy BIG-IP VE in Microsoft Hyper-V
    • Deploy BIG-IP VE in Citrix XenServer
    • Deploy BIG-IP VE in Nutanix AHV

For information about licensing the BIG-IP VE image with the BIG-IP VE Version Plus license, refer to the following resource: K7752: Licensing the BIG-IP system.

Install the production configuration on the BIG-IP VE system

After you have deployed the BIG-IP VE image to the cloud or hypervisor environment, install a UCS backup file that contains the production BIG-IP configuration on the BIG-IP VE system. To do so, perform the following tasks:

  • Copy the production UCS backup file to the BIG-IP VE system.
  • Load the UCS file on the BIG-IP VE system using the no-platform-check option in tmsh. For more information on the no-platform-check option, refer to K14906: Overview of the UCS 'no-platform-check' tmsh option.

Install the upgrade version on the BIG-IP VE system

After you have installed the production BIG-IP configuration on the BIG-IP VE system and verified that the system is operating properly in the lab environment, update or upgrade the BIG-IP VE system to the BIG-IP version to which you intend to run in production. For specific upgrade instructions, refer to the following article:

  • K84205182: BIG-IP update and upgrade guide | Chapter 1: Guide contents
