Description

tcpdump shows SYN packets going out from the Standby F5 but SYN ACK packets are being returned to the Active F5.

Active and Standby F5 shows the same MAC-address for different non-floating IP addresses.

You may observe it after a failover. 

Environment

  • HA pair
  • SYN packets going out from the Standby
  • SYN ACK packets returning to the Active
  • Active and Standby showing same MAC-address

Cause

Configuration object is using the same IP address as the non-floating self-IP of the Standby device.

Recommended Actions

Change the IP of the configuration object, or remove the object entirely.

OR

update the non-floating Self-IP of the Standby unit to an available IP address.
