Description

ASM might trigger violation as illegal data type when user configured the request parameter value as alphanumeric. Requests with parameter value as Alphanumeric getting blocked as Illegal parameter data type expecting Integer data type, even though configured data type is Alphanumeric at parameter level.

 

Environment

  • BIG-IP ASM
  • ASM violations
  • Illegal parameter data type
  • Alphanumeric value

 

Cause

The issue is unknown at the time of publication.

 

 Recommended Actions

We recommend to follow the below workaround to resolve the issue.

1) Modify parameter Data Type from Alpha-Numeric to Integer.

2) Click "Update" button.

3) Modify parameter Data Type from Integer back to Alpha-Numeric.

4) Click "Update" button.

5) Apply policy in question.

6) The ASM no longer triggers "Illegal parameter data type" violation expecting integer parameter value data type.
