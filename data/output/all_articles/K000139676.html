K000139676: [F5OS-A] VLAN can be removed from Trunk even if it assigned to a tenant

Type
Support Solution
Published
2024-08-27
Updated
2024-08-27
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000139676

Description

VLAN can be removed in the LAG configuration on F5OS level even if it is still assigned as a vlan in one of the deployed tenants. This might cause the Trunk on the tenant level to go down if missed.

Environment

F5OS

LAG

VLAN

Cause

VLAN removed on the LAG on the F5OS level even if it is still configured in the tenants. 

Recommended Actions

Do not remove vlans that are still associated with any tenant and review your configuration carefully before making any changes.
