K5395: The OIDs within the .1.3.6.1.4.1.3375.1.1.110 hierarchy cannot be queried

Status

Applies to

  • BIG-IP 4.X: 4.6.4
Source

Topic

The OIDs in the .1.3.6.1.4.1.3375.1.1.110 hierarchy are SNMP traps. These OIDs only report information when the traps are triggered by syslog file activity. An SNMP walk of these OIDs should not typically return any data.
