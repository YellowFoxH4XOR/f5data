K18410717: Platform page in GUI does not load

Type
Support Solution
Published
2022-10-06
Updated
2024-07-16
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP Platforms
Source
https://my.f5.com/manage/s/article/K18410717

Description

After recently finishing the initial configuration setup, GUI page does not load when going to System > Platform

you can see the following error message: 

An error has occurred while trying to process your request

Environment

  • BIG-IP VE
  • AWS Cloud Platform
  • VMware
  • Configuration Utility 
  • WebUI

Cause

The DHCP management route was not properly applied during the initial setup process. 

# tmsh list sys management-ip does not return a value

Recommended Actions

  1. Delete the management route
    #tmsh delete /sys management-route <name>
  2.  Save the configuration changes
    # tmsh save sys config 
  3. Reboot the device
    # reboot

Additional Information

None
