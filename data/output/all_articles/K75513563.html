K75513563: Can't Access Configuration Utility (GUI) and MCPD Causing High CPU Usage

Type
Support Solution
Published
2021-01-07
Updated
2023-10-16
Source

Description

Can't access the GUI and the Diagnostics page in iHealth shows a Critical Heuristic (H511618) saying my box is compromised when it actually isn't.

  • Multiple syslog-ng processes running
  • Process called supervising syslog-n
  • False-positive Critical Heuristic H511618 in iHealth saying my box was compromised
  • High CPU usage caused by mcpd

Environment

  • Accidentally started a second syslog-ng service
  • Cannot access the GUI
  • High CPU usage

Cause

This process that caused the false-positive Heuristic (H511618) in iHealth Diagnostics is expected to sometimes run when there are multiple syslog-ng processes running:

supervising syslog-n

Recommended Actions

To reduce the CPU usage and regain access to the GUI, you just need to kill all instances of syslog-ng and restart it again with these commands

killall syslog-ng
bigstart start syslog-ng
