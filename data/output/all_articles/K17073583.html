Description

  • New external health monitor created
  • High CPU observed after implementing the health monitor

Environment

  • External monitor created
  • As an example for external health monitoring script using snmpwalk command:
    /bin/snmpwalk -v 2c -c PASSWORD $IP .1.3.6.1.4.1.3417.2.7.1.2.1.1.2.19.117.115.101.114.46.73.78.84.69.82.78.69.84.45.67.72.69.67.75 

Cause

Using snmpwalk might cause high CPU 

Recommended Actions

  1. use snmpget instead of snmpwalk command
  2. Add -m ' ' to the arguments of snmpget
