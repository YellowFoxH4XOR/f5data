Description
If you remove all ASM configuration items and have de-provisioned ASM, you will note that the datasync-global-dg device group is still there. By design, you are not able to delete it either from the configuration utility or with TMSH. 
Except for small resource consumption maintaining the device group, leaving the datasync-global-dg device group should not cause issues. However, if you wish to remove the device group, you can do so using a text editor such as vi.

Environment

  • ASM configuration has been deleted and ASM has been de-provisioned

Cause
Due to its necessity for ASM to function correctly, there is no built in function to remove the datasync-global-dg device group, even when ASM is de-provisioned.

Recommended Actions

  1. One can delete the configuration manually utilizing vi: (remove everything between the two "REMOVE" lines). 
    Important: If you are not confident and comfortable editing a configuration manually using vi, it is advised to contact F5 Support for assistance: K2633: Instructions for submitting a support case to F5

  2. Remove ASM provisioning - then remove device-groups and references from the bigip_base.conf:
    [root@f5-lab-1:Standby:Disconnected] config # vi bigip_base.conf
    ---------------------------- REMOVE ----------------------------
    cm device-group /Common/datasync-device-f5-lab-1.local-dg {
        auto-sync enabled
        devices {
            /Common/f5-lab-1.local { }
            /Common/f5-lab-2.local { }
        }
        full-load-on-sync true
        hidden true
        network-failover disabled
    }
    cm device-group /Common/datasync-device-f5-lab-2.local-dg {
        auto-sync enabled
        devices {
            /Common/f5-lab-1.local { }
            /Common/f5-lab-2.local { }
        }
        full-load-on-sync true
        hidden true
        network-failover disabled
    }
    cm device-group /Common/datasync-global-dg {
        devices {
            /Common/f5-lab-1.local { }
            /Common/f5-lab-2.local { }
        }
        full-load-on-sync true
        network-failover disabled
    }

    security datasync global-profile *         <<<< There are multiple rows, omitted here for brevity

    security datasync update-file *            <<<< There are multiple rows, omitted here for brevity

    sys folder /Common/datasync-device-f5-lab-1.local {
        device-group /Common/datasync-device-f5-lab-1.local-dg
        hidden true
        inherited-devicegroup false
        inherited-traffic-group false
        traffic-group /Common/traffic-group-local-only
    }
    sys folder /Common/datasync-device-f5-lab-2.local {
        device-group /Common/datasync-device-f5-lab-2.local-dg
        hidden true
        inherited-devicegroup false
        inherited-traffic-group false
        traffic-group /Common/traffic-group-local-only
    }
    sys folder /Common/datasync-global {
        device-group /Common/datasync-global-dg
        hidden false
        inherited-devicegroup false
        inherited-traffic-group false
        traffic-group /Common/traffic-group-local-only
    }
    ---------------------------- REMOVE ----------------------------

  3. Then run the following commands:
    tmsh load sys config partitions all
    tmsh save sys config partitions all
