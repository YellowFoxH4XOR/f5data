Description

This article lists the common issues and best practices to consider when upgrading BIG-IP systems. It provides key recommendations and references to official F5 documentation to ensure a smooth upgrade process.

Environment

  • Upgrade of BIG-IP planned

Cause

None

Answer/Recommended Actions

F5 recommends referring to the K84205182: Guide contents | BIG-IP update and upgrade guide when performing upgrades. The guide includes important upgrade details, such as how to choose an upgrade version, how to prepare your BIG-IP system for an upgrade and how to perform an upgrade for your specific BIG-IP platform.

Before running the upgrade, consider the following:

  • Good practice - save your running configuration:
    tmsh save sys config
    Refer to: K14624: Configure Automatic Sync to save the configuration on the remote devices
  • Re-activate your license before the upgrade and verify the "service check date" is updated:
    Refer to: K7727: Licensing and activation overview
  • Use .iso images for upgrades (including virtual environments):
    Refer to: K000139975: Do I need an ISO or OVA image file to upgrade my BIG-IP Virtual Edition
  • Delete unused boot locations:
    If there are boot locations that are no longer in use, consider deleting them to free up space.
    Refer to: K33265170: Managing boot locations
  • Check your configuration for errors before upgrading:
    Run the following command to verify your configuration:
    tmsh load sys config verify
    Refer to: K53233552: How to verify if BIG-IP configuration contains errors
  • Unable to download software from MyF5:
    K59533861: Unable to download software from MyF5
  • Prevent upgrade issues with AAM/WAM/WOM objects in BIG-IP 16.x and later:
    K000149084: Preventing Upgrade Issues with AAM/WAM/WOM Objects in BIG-IP 16.x and Above

Additional Information

Engineering Hotfixes and Security Vulnerabilities:
BIG-IP vulnerabilities disclosed in the October 2025 Quarterly Security Notification have already been addressed in BIG-IP versions 17.5.1.3 and 17.1.3.
For guidance on whether you need to install an additional fix on top of 17.1.3 or 17.5.1.3, refer to: K000156986: Engineering Hotfix guidance for October 2025 QSN
