Description

After upgrading Windows Defender per KB4052623 for Microsoft Defender Antivirus, some users are unable to connect via the BIG-IP APM VPN.

Environment

  • BIG-IP APM
  • Windows Client with recently upgraded Windows Defender
  • APM with On-Demand Certificate Authentication
  • BIG-IP Edge client displays "Connecting..."

Cause

This is suspected to be a Microsoft Bug.

Recommended Actions

Collect a decrypted packet capture on the BIG-IP APM filtered by the client IP. When the On-Demand Cert Auth agent in the policy is reached, the client fails to complete TLS renegotiation and stops responding after APM issues a Hello Request.

This issue was resolved in two ways:
Note: These are Microsoft Windows adjustment on the client side and should be approved by your IT department before executing

  1. Microsoft instructed another customer to disable Windows Defender network protection and TLS processing feature via PowerShell:

    Set-MpPreference -EnableNetworkProtection Disabled
    Set-MpPreference -DisableTlsParsing $true

  2. Excluding EdgeClient (f5fpclientW.exe) from getting scanned by Windows Defender seems to solve the problem.
