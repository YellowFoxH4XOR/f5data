Topic

The Common Alerting Protocol (CAP) is an XML-based protocol used for standardizing alert notifications across different warning systems to many applications. The BIG-IP ASM XML profile supports the CAP protocol for documents transported through HTTP.

Using a BIG-IP ASM XML profile to protect CAP-based traffic provides the following security benefits:
  • Validating CAP documents:

    You can upload a CAP-based schema file into the XML profile to provide document validation for requests containing CAP messages. The schema file helps verify that the CAP messages are well formatted.
  • Validating requests containing CAP messages:

    The XML profile can validate requests containing CAP messages against attack signatures.
  • Limiting the XML payload:

    You can limit the payload of XML, CAP-based messages by using the XML profile defense configuration settings.
  • Protecting the back-end parser from Denial of Service attacks:

    The XML profile protects the XML parser by parsing and verifying XML documents.
