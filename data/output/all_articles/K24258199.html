Topic

You should consider using this procedure under the following condition:

  • You want to change the interval at which the BIG-IP system allows duplicate SNMP traps to be sent to a SNMP management station.

Description

When you define an SNMP trap destination on the BIG-IP system, the alert daemon monitors system error messages and triggers a trap notification when the error message matches an alert code. By default, the BIG-IP system suppresses duplicate trap notifications and does not send a duplicate trap instance for 60 seconds after sending an initial trap instance.

The BIG-IP system determines whether a message instance is a duplicate by examining the alert code and message content; if two messages contain the same alert code and message content, the system considers them to be identical and does not send an additional trap within the 60 second period. The following examples illustrate how the system determines whether a message instance is a duplicate.

  • In the following example, the BIG-IP system sends only the first message as a trap notification to the network management station. The second message is logged 30 seconds after the first message and contains the same alert code and message content. As a result, the BIG-IP system considers the second message to be a duplicate and does not send a trap notification for the second message:

    Sep  7 00:34:00 emerg system_check[18829]: 010d0004:0: Chassis 1: temperature (35) is too high.
    Sep  7 00:34:30 emerg system_check[18829]: 010d0004:0: Chassis 1: temperature (35) is too high.

  • In the following example, the BIG-IP system sends both messages as trap notifications to the network management station. In this example, the second message is logged 30 seconds after the first message; however, since the message content is different in the second message, the BIG-IP system considers the messages to be different and issues a trap notification for both messages:

    Sep  7 00:34:00 emerg system_check[18829]: 010d0004:0: Chassis 1: temperature (35) is too high.
    Sep  7 00:34:30 emerg system_check[18829]: 010d0004:0: Chassis 2: temperature (40) is too high.

In some cases you may want to change the trap suppression interval, trap suppression count, or disable trap suppression altogether. To do so, perform the following procedures:

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the TMOS Shell (tmsh).

Procedures

  • Modifying the interval at which the BIG-IP system sends duplicate SNMP traps
  • Modifying the number of duplicate SNMP traps the BIG-IP system sends during the suppression interval (14.x and later)

Modifying the interval at which the BIG-IP system sends duplicate SNMP traps

To modify the interval at which the BIG-IP system sends duplicate SNMP traps or disable trap suppression, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the interval at which the system sends duplicate traps, use the following command syntax:

    modify /sys db snmp.bigiptraps.suppress.interval value <number of seconds>

    For example, to change the interval to 90 seconds, type the following command:

    modify /sys db snmp.bigiptraps.suppress.interval value 90

    To disable trap suppression, type the following command:

    modify /sys db snmp.bigiptraps.suppress.interval value 0

    To restore the default value, type the following command:

    modify /sys db snmp.bigiptraps.suppress.interval value 60
     

Modifying the number of duplicate SNMP traps the BIG-IP system sends during the suppression interval

In BIG-IP 14.x and later, you can modify the number of duplicate SNMP traps the BIG-IP system sends during the configured suppression interval. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the number of duplicate traps the system sends during the suppression interval, use the following command syntax:

    modify /sys db snmp.bigiptraps.suppress.count value <number>

    For example, to change the count to 1, type the following command:

    modify /sys db snmp.bigiptraps.suppress.count value 1
