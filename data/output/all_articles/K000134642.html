K000134642: PEM classification signature scheduled auto update fails

Type
Support Solution
Published
2023-05-17
Updated
2024-03-25
Applies to
  • BIG-IP
  • BIG-IP PEM: 16.1.3, 15.1.8, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000134642

Description

PEM classification signature scheduled updates do not complete in versions including 15, 16 and 17.0.x whilst Manual updates work fine.

Environment

  • PEM signatures
  • Auto Update

Cause

This issue is due to a known Bug ID1167889.

Recommended Actions

To resolve this issue, you can upgrade the VE system to 17.1.0 and later versions as this ID is fixed there. If upgrade to v17.1.x is not desired, feel free to contact F5 support team and request for EngHF but please note EngHFs only offered on the latest maintenance release built of the supported versions.
