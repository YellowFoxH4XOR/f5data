Description

Device showing INOPERATIVE and configuration unable to load after upgrade. The following error message is observed when running tmsh load /sys config verify:

01070734:3: Configuration error: Can't associate folder (/Common/EPSEC/Status) folder does not exist

Environment
  • BIG-IP
  • Upgrade of BIG-IP to a new software version
Cause

Unknown at the time of publication.

Recommended Actions
  1. Create the directory Status in the /Common/EPSEC/ directory:

    tmsh create /sys folder /Common/EPSEC/Status

  2. Create a backup for /config/bigip_base.conf:

    cp /config/bigip_base.conf /config/bigip_base.conf-backup

  3. Edit the /config/bigip_base.conf file:

    vi /config/bigip_base.conf

  4. Add in the following lines :

    sys folder /Common/EPSEC {
    hidden false
    inherited-devicegroup true
    inherited-traffic-group true
    }

  5. Load the configuration 
     tmsh load /sys config 
  6. Save the configuration
    tmsh save /sys config
