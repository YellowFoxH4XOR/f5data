Topic

The BIG-IP Edge Client uses captive portal detection when users attempt to establish a BIG-IP Edge Client access session. When the BIG-IP Edge Client detects a captive portal, the system presents the captive portal to users in a BIG-IP Edge Client window. The following section covers the behavior of the BIG-IP Edge Client window for captive portals.

Description

The BIG-IP Edge Client renders captive portal pages through an ActiveX control that is hosted inside a BIG-IP Edge Client window.

The captive portal window behaves as a native browser using the browser's security measures and the local user device browser settings.

The BIG-IP Edge client automatically attempts to connect to the captive portal URL. If the captive portal URL connection fails, the BIG-IP Edge Client does not render a captive portal window to the user. When the connection to the captive portal URL succeeds, the BIG-IP Edge Client displays the captive portal content in a window, setting the target URL of the hosted content to the captive portal URL (using ActiveX).

The BIG-IP Edge Client uses captive portal detection when users attempt to establish a BIG-IP Edge Client access session. When the BIG-IP Edge Client detects a captive portal, the system presents the captive portal to users in a BIG-IP Edge Client window.

If the captive portal URL connection fails, the BIG-IP Edge Client does not render a captive portal window to the user. When the connection to the captive portal URL succeeds, the BIG-IP Edge Client displays the captive portal content in a window, setting the target URL of the hosted content to the captive portal URL (using ActiveX).

Because the URL used for captive portal detection change to http://cdn.f5.com/product/avail.txt, F5 strongly encourages using the latest Edge Client or APM Clients in order to maintain functionality. Network access functionality for older Edge Client versions is impacted under certain conditions when the old captive portal URL (http://www.f5.com:80/apps/all/avail.txt) is not available.

Additional Information

Beginning in BIG-IP Edge Client for Windows and Mac OS, APM Clients 7.2.4.1, the use of HTTP connections in BIG-IP Edge Client is disabled by default and affects connection to plain http URL used for captive portal detection. For more information and workaround, refer to K000134621: The use of HTTP connections in BIG-IP Edge Client is disabled by default
