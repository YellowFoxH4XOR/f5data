Description

When configuring a virtual server with a BIG-IP ASM security policy you receive an error message similar to the following:
error_string : Could not update policy due to ASMConfig exception: [303] Set active failed

Environment

  • BIG-IP ASM
  • Security policy
  • BIG-IP VE or vCMP guest with less than 8 GB of memory

Cause

This is expected behavior. For more information refer to: K15796: Hardware requirements to host BIG-IP VE on private cloud platforms.

Recommended Actions

Assign more RAM to the VE or vCMP guest virtual machine (8 GB minimum)

Additional Information

You can confirm the VE or vCMP guest available with the following procedure:

  1. Log on to the BIG-IP ASM command line.
  2. Type the following tmsh command:

    tmsh show /sys memory

  3. Review the command output to validate available memory

    Example:

    Sys::System Memory Information

    ------------------------------------------------------------
    Sys::Host Memory (bytes)
    ------------------------------------------------------------

    Host: 0
      Available              3.9G           <==== Note
      Used                   2.6G
