Issue

Error Message

01670010:7: Inbound entry:<inbound IP address>:<external service port>, ds-lite remote::: local::: timeout:<timeout period> for key:<internal IP address>3%0:<service port> proto:<protocol> added. ha mirrored: <true|false>

In this error message, note the following:

  • <external IP address> is the IP address of the inbound or external client.
  • <external service port> is the inbound or external Large Scale NAT (LSN) translation service port.
  • <timeout period> is the configured LSN connection timeout period.
  • <internal IP address> is the IP address of the internal DS-Lite subscriber. 
  • <internal service port> is the internal LSN translation service port.
  • <protocol> is the number protocol identifier. 6 is UDP and 17 is TCP. 
  • <true|false> is the current mirroring configuration, either enabled (true) or disabled (false).

For example:

01670010:7: Inbound entry:192.168.10.1%0:5070, ds-lite remote::: local::: timeout:300 for key:10.10.10.1%0:1025 proto:17 added. ha mirrored: false

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file.

Description

This message occurs when the following condition is met:

  • An inbound client session has been received and has connected to a DS-Lite client on the internal subscriber side.

Note: The LSN logging level must be set to debug to view this error message. The default level is error.

Impact

There is no impact; this message is informational only.

Recommended Actions

You can set the LSN logging level to debug to help troubleshoot LSN connectivity issues. To set the LSN logging level to debug, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To enable LSN debug logging, type the following command:

    modify sys db log.lsn.level value debug

  3. Once troubleshooting has completed, type the following command to disable debug logging:

    modify sys db log.lsn.level value error
