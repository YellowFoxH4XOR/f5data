Description

Live Update default factory file for Server Technologies cannot be reinstalled once it is no longer the currently installed update file.

Environment

  • ASM signatures
  • Live Update

Cause

This is likely due to the bug tracked in ID920149

Recommended Actions

Download ASM signature files from the official website: https://downloads.f5.com/

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: For the purpose of this example, the Server Technologies used is : ServerTechnologies_20190828_172623.im

1. Manually copy the genesis file to /var/lib/hsqldb/live-update/update-files/

2. Update Permissions, Owner, and Group to match the other genesis files:

chmod 744 ServerTechnologies_20190828_172623.im
chown tomcat:tomcat ServerTechnologies_20190828_172623.im

3. Run the following commands:

tmsh stop sys service tomcat
rm -f /var/lib/hsqldb/live-update/liveupdatedb.*
tmsh start sys service tomcat
