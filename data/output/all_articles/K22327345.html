Cause

Database issue causing tokumx not able to determine that an upgrade is not needed and will continue to restart.

Recommended Actions

Note: 

If this is a new install, the customer should be able to kill tokumx, remove the entire /var/config/rest/toku/data directory and then simply run clear-rest-storage.

If you know the initial configuration since it is a new installation, they should be able to follow these steps to clear the issue:
 
  1. Login to command line (CLI)
  2. Run the following command to kill tokumx
    # bigstart kill tokumx
  3. Run the following command to remove Tokumx data
    # /bin/rm -r /var/config/rest/toku/data
    # /bin/rm -r /shared/tmp/tokudata_<timestamp>
  4. Run the following command to clear REST database
    # clear-rest-storage

Additional Information

For clarity, tokumx is started at bootup to determine if there is an upgrade that needs to occur.  Once the upgrade completes, tokumx should be stopped and the system started.  If for some reason there is a problem with the database that is attempting to start, tokumx will not be able to determine that an upgrade is not needed and will continue to restart.  This will prevent the Big-IQ from coming online properly.
