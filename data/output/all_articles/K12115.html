Known Issue

This is the result of a known issue. If you have multiple network connections active, such as a wired Ethernet connection and a wireless connection, the VPN client may not be able to route traffic properly through the VPN connection. This issue occurs when the F5 Networks VPN client for Mac OS X attempts to determine the best route to an IP address and incorrectly passes IP traffic to the wrong interface.

F5 Networks Product Development is tracking this issue as ID 317614 (formerly  CR129145).

This issue has been fixed in cumulative hotfix HF-610-3-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

To work around this issue, ensure that only one network interface is active while accessing VPN.
