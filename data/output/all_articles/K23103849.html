Description

  • Unable to discover/import ASM device configuration to BIG-IQ
  • The following error message can be seen on BIG-IQ GUI:

    Failed to copy configuration to working-config; reason: Illegal argument for valueType:auto-detect. Possible values are: xml, user-input, static-content, ignore, json, dynamic-content, dynamic-parameter-name

Environment

  • BIG-IP ASM running software version 15.1 or above
  • BIG-IQ CM running software version 7.1

Cause

Seen behavior is the result of a design limitation between BIG-IQ CM 7.1.0 and BIG-IP ASM 15.1. Parameters with value type auto-detect are not supported on BIG-IQ

Recommended Actions

This limitation will be improved at future versions of BIG-IQ. As a workaround, all the parameters with a value type set to auto-detect should be reconfigured to xml, user-input, static-content, ignore, json, dynamic-content.
