K000161717: Post upgrade to version BIGIP-21.1.0-0.0.38.iso, device configuration is not loading with error: err tmsh[13009]: 01420006:3: "options", invalid value "dont-insert-empty-fragmentsno-sslv3"

Description

After upgrade to version 21.1.x, your configuration is not loading, while trying to load it you observe below error message:

May 30 07:34:53 hostname err tmsh[13009]: 01420006:3: "options", invalid value "dont-insert-empty-fragmentsno-sslv3"
May 30 07:34:53 hostname load_config_files[13006]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- Loading schema version: 17.5.1.3

Environment

  • BIG-IP

  • Version 21.1.x

Cause

This is due to bug ID2337369, which only affects devices on which default client-ssl profile was changed, which is not recommended by F5.

Due to above bug, during upgrade "dont-insert-empty-fragments no-sslv3" gets changed to "dont-insert-empty-fragmentsno-sslv3", due to that config is not loading as this part is not recognized by the system.

Answer/Recommended Actions

Using text editor, edit /config/bigip.conf with the default ssl profile that had changes, to introduce the missing space, and reload the config with tmsh load sys config.
