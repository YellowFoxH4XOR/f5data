Known Issue

Windows filers using a base GMT or UTC time zone will return a snapshot creation time that ends with a Z. The ARX system interprets the snapshot create time ending with a Z as invalid, causing the ARX-managed snapshots to fail.

This issue occurs when all of the following conditions are met:

  • The ARX-managed volume is configured to manage snapshots for the Windows filer
  • The Windows filer is configured to use a base GMT or UTC time zone:

    (GMT) Casablanca
    (GMT) Coordinated Universal Time
    (GMT) Greenwich Mean Time : Dublin Edinburgh, Lisbon, London
    (GMT) Monrovia, Reykjavik
    (UTC) Casablanca
    (UTC) Coordinated Universal Time
    (UTC) Greenwich Mean Time : Dublin Edinburgh, Lisbon, London
    (UTC) Monrovia, Reykjavik

    Note: Only the base GMT or UTC time zones are affected. Windows filers configured to use a time zone with a positive or negative offset from GMT or UTC are not affected.

Impact

ARX-managed snapshots fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

ARX version 6.x

  • The ARX snapshot report will have a status of FAILED, and contain an error message that appears similar to the following example:

    % ERROR: SNAP_BE_FILER_CMD_FAILED (44367910): Snapshot command 'Win32_ShadowCopy::create' failed on filer 'Windows-domain' (192.168.11.12) while attempting to CREATE. The response from the filer was: 'Failed to query windows filer '192.168.11.12', spn 'WINFILER-001@DOMAIN.COM', the error is 'the Windows file system returned invalid snapshot create time 2011-11-11T12:34:00.123456Z'.'
  • The ARX syslog file will contain an error message that appears similar to the following example:

    :SNAPD-0-ERR-SNAP_CREATE_FAILED_MSGS:: Snapshot create failed message for namespace [namespace01-cifs] volume [/arx_test] snapshot rule [hourly] virtual snapshot [hourly0] message [Snapshot command 'Win32_ShadowCopy::create' failed on filer 'WinFiler-001' (192.168.11.12) while attempting to CREATE. The response from the filer was: 'Failed to query windows filer '192.168.11.12', spn 'WINFILER-001@DOMAIN.COM', the error is 'the Windows file system returned invalid snapshot create time 2011-11-11T12:34:00.123456Z'.']).

ARX version 5.x

  • The ARX snapshot report will have a status of FAILED, and contain an error message that appears similar to the following example:

    % ERROR: SNAP_BE_FILER_CMD_FAILED (44367908): Snapshot command 'Win32_ShadowCopy::create' failed on filer 'Windows-domain' (192.168.11.12) while attempting to CREATE. The response from the filer was: 'Failed to query windows filer '192.168.11.12', spn 'WINFILER-001$@DSFOREST1.COM', the error is 'received invalid install data in Win32_ShadowCopy object'.'
  • The ARX syslog file will contain an error message that appears similar to the following example:

    :FILER_MGMT_LIB-0-ERR-SNAP_BE_FILER_CMD_FAILED:: Snapshot command 'Win32_ShadowCopy::create' failed on filer 'Windows-domain' (192.168.11.12) while attempting to CREATE. The response from the filer was: 'Failed to query windows filer '192.168.11.12', spn 'WINFILER-001$@DSFOREST1.COM', the error is 'received invalid install data in Win32_ShadowCopy object'.'
