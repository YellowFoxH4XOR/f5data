Topic

Beginning in BIG-IP ASM version 10.1.0, you can access the BIG-IP ASM security policy in a human-readable format by navigating to the Security Policies screen in the Configuration utility and clicking the Export as XML button. You can also manually edit and then import XML-formatted security policies to the BIG-IP ASM by navigating to the Security Policies screen and clicking the Import button. To successfully import a manually-edited BIG-IP ASM security policy, you must ensure that the policy conforms to the internal XML schema that the BIG-IP ASM uses.

The following files, available on the BIG-IP ASM device, define the BIG-IP ASM security policy XML schema; all manual changes you make to a BIG-IP ASM security policy must conform to the XML schema defined in these files.

Note: You can load these files into the XML validation tool of your choice.

  • /usr/lib/perl5/site_perl/F5/policy_info.xsd
  • /var/ts/share/import_export_xml.xsd
  • /var/ts/share/xml/generic_schemas/soap-encoding.xsd
  • /var/ts/share/xml/generic_schemas/soap-envelope-12.xsd
  • /var/ts/share/xml/generic_schemas/soap-envelope.xsd
  • /var/ts/share/xml/generic_schemas/xml.xsd

For more information about transferring these files from the BIG-IP ASM device, refer to K175: Transferring files to or from an F5 system.
