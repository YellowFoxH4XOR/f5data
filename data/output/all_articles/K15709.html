Known Issue

Attempting to change logging options for vCMP guests may fail.

This issue occurs when all of the following conditions are met:

  • You are attempting to change logging options for vCMP guests from the following menu in the BIG-IP Configuration utility:

    System > Logs > Configuration > Options

  • You are running 11.4.1 HF2, HF3 or HF4

Impact

You will be unable to change the logging configuration using the BIG-IP Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H485195 on the Diagnostics > Identified > Low screen.
  • You will see the following error message in the Configuration utility:

    General database error retrieving information.

Resolution

Status

Workaround

To work around this issue, you can change the options using the Traffic Management Shell (tmsh).
