K000149553: upstream sent more data than specified in "Content-Length" header while reading upstream

Type
Support Solution
Published
2025-02-12
Updated
2025-02-12
Applies to
  • NGINX Products
  • NGINX Plus: R25, R28
Source
https://my.f5.com/manage/s/article/K000149553

Description

NGINX is logging the following warning in the error logs:

Upstream sent more data than specified in the Content-Length header while reading upstream

 

Environment

NGINX Plus and OSS NGINX

 

Cause

This indicates a mismatch between the Content-Length header and the actual data sent by the upstream server.

 

Recommended Actions

If expected, this warning message can be safely ignored, as it does not affect request processing by NGINX. However, we recommend addressing the issue on the upstream application side to ensure that the Content-Length header value accurately reflects the data sent.
