Description

You want to understand the log when manually disable or force offline a pool member using the Configuration utility (Local Traffic >> Pools : Pool List >> <Pool Name> - Current Members).

Environment

  • Configuration utility
  • Audit log
  • LTM log
  • ConfigSync

Cause

None

Recommended Actions

You can find the related logs in /var/log/ltm and /var/log/audit. For example: You may want to disable or force offline a pool member 192.168.0.59:80 in pool /Common/pool_example.

Note:  In an HA device group, you will find the same logs in /var/log/ltm on peer BIP-IP after configcync, however there is no relevant log in /var/log/audit on the peer BIG-IP.
  • When you disable a pool member:
In /var/log/ltm:
 
notice mcpd[6957]: 01070639:5: Pool /Common/pool_example member /Common/192.168.0.59:80 session status forced disabled.

In /var/log/audit:

Note: The "pool_member_new_session_enable 1 pool_member_monitor_state 3" means the pool member is manually Disabled.

notice mcpd[6957]: 01070417:5: AUDIT - client tmui, user admin - transaction #484803-2 - object 0 - modify { pool_member { pool_member_pool_name "/Common/pool_example" pool_member_node_name "/Common/192.168.0.59" pool_member_port 80 pool_member_update_status 1 pool_member_new_session_enable 1 pool_member_monitor_state 3 } } [Status=Command OK]
  • When you force offline a pool member:
In /var/log/ltm:
 
notice mcpd[6957]: 01070807:5: Monitor /Common/http instance 192.168.0.59:80 has been disabled.
notice mcpd[6957]: 01070639:5: Pool /Common/pool_example member /Common/192.168.0.59:80 session status forced disabled.
notice mcpd[6957]: 01070638:5: Pool /Common/pool_example member /Common/192.168.0.59:80 monitor status forced down. [ /Common/http: up ]  [ was up for 0hr:18mins:40sec ]

In /var/log/audit:

Note: The "pool_member_new_session_enable 1 pool_member_monitor_state 20" indicates the pool member is manually Forced Offline.

notice mcpd[6957]: 01070417:5: AUDIT - client tmui, user admin - transaction #496088-2 - object 0 - modify { pool_member { pool_member_pool_name "/Common/pool_example" pool_member_node_name "/Common/192.168.0.59" pool_member_port 80 pool_member_update_status 1 pool_member_new_session_enable 1 pool_member_monitor_state 20 } } [Status=Command OK] 
  • Additionally, when you enable a pool member from Disabled or Forced Offline:
In /var/log/ltm:
 
notice mcpd[6957]: 01070639:5: Pool /Common/pool_example member /Common/192.168.0.59:80 session status enabled.

In /var/log/audit:

Note: The "pool_member_new_session_enable 2 pool_member_monitor_state 3" means the pool member is manually Enabled.

notice mcpd[6957]: 01070417:5: AUDIT - client tmui, user admin - transaction #490387-2 - object 0 - modify { pool_member { pool_member_pool_name "/Common/pool_example" pool_member_node_name "/Common/192.168.0.59" pool_member_port 80 pool_member_update_status 1 pool_member_new_session_enable 2 pool_member_monitor_state 3 } } [Status=Command OK]

Additional Information
Regarding numeric codes of pool_member_new_session_enable and pool_member_monitor_state, you can see those in F5-BIGIP-LOCAL-MIB.txt file. For more information for MIB files, refer to K13322: Overview of BIG-IP MIB files.

ltmPoolMemberNewSessionEnable OBJECT-TYPE
SYNTAX INTEGER {
user-disabled(1), <----------- !!!
user-enabled(2), <----------- !!!

}
