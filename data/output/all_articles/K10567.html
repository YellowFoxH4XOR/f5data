Known Issue

This is the result of a known issue. The BIG-IP system does not log a message to the /var/log/audit file when a failover action is initiated from the Configuration utility. The BIG-IP system should write a message to the /var/log/audit file, similar to the message logged when the same operation is performed from the command line using the bigpipe utility.

F5 Product Development is tracking this issue as ID 223114 (formerly CR127659).
