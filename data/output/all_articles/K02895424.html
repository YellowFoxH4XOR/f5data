Description
top command shows tmm.0 CPU usage is high.

 PID  USER      PR  NI    VIRT    RES    SHR S  %CPU %MEM     TIME+ COMMAND
13595 root       1 -19   43.3g 148852 125248 S 122.4  0.2   1069:55 tmm.0

Environment

  • BIG-IP
  • tmm
  • CPU

Cause
tmm.0's CPU and Memory usage is for the total numbers of TMM instances on the blade or the platform.
So memory usage, and CPU usage can be high, depending on the numbers of tmm instance running on the platform.

Recommended Actions

TMM cpu usage should be checked with the command below
tmsh show /sys tmm-info
 
If you can see any TMM instance is particularly high or all are high, then check which virtual server is using high CPU.
tmsh show /ltm virtual server
