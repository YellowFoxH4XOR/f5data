Known Issue

This is the result of a known issue. Certain 4100 platforms, used for stand-alone BIG-IP ASM systems, have Intel processors with HyperThreading enabled.

As a result, the BIG-IP ASM system running on these platforms may experience instability or traffic handling issues.

Note: Only a small number of the 4100 platforms have the Intel HyperThreading enabled.

F5 Product Development recommends disabling this option to prevent any issues from affecting customers.

Determining if Hyperthreading is enabled

To determine if your 4100 platform has HyperThreading enabled, perform the following procedure:
  1. Log in to the command line
  2. To verify the platform information, type the following command:

    bigpipe platform

    Your 4100 platform is not affected if the output from this command appears similar to the following example:

    PLATFORM INFORMATION --
    | Marketing Name: BIG-IP 4100 <-- Platform Type
    +-> CPU 0
    | | Type: Intel(R) Xeon(TM) CPU 2.40GHz Speed: 2399.381MHz
    | | Temp: 24degC Fan speed: 5192rpm
    +-> CPU 1
    | | Type: Intel(R) Xeon(TM) CPU 2.40GHz Speed: 2399.381MHz
    | | Temp: 31degC Fan speed: 5273rpm
  3. If the output from this command displays four processors instead of two, your 4100 platform is affected and you will need to disable HyperThreading,. In this situation, the output would appear similar to the following example:

    PLATFORM INFORMATION --
    | Marketing Name: BIG-IP 4100 <-- Platform Type
    +-> CPU 0
    | | Type: Intel(R) Xeon(TM) CPU 2.40GHz Speed: 2399.381MHz
    | | Temp: 24degC Fan speed: 5192rpm
    +-> CPU 1
    | | Type: Intel(R) Xeon(TM) CPU 2.40GHz Speed: 2399.381MHz
    | | Temp: 31degC Fan speed: 5273rpm
    +-> CPU 2 <-- Virtual Processor as a result of HyperThreading
    +-> CPU 3 <-- Virtual Processor as a result of HyperThreading

Disabling HyperThreading

To disable HyperThreading, perform the following procedure:
  1. Open the grub.conf file for editing by typing the following command:

    grub_open
  2. Create a backup of the grub.conf file by typing the following command:

    cp /var/run/grub.conf /var/tmp/grub.conf
  3. Open the grub.conf file using a text editor.
  4. Locate the kernel line in the grub.conf file and add noht immediately before the directive quiet, for all the BIG-IP ASM system installation slots.

    For example:

    Important: The kernel line should not wrap; it should be one continuous line.

    kernel (hd0,1)/boot/2/vmlinuz ro root=UUID=52fd2fb3-02c6-40a0-b631-1c1853196a03 console=ttyS0,19200 panic=1 mem=1152M platform=D46 noht quiet
  5. Save the changes made to the grub.conf file.
  6. Commit changes made to the grub.conf file by typing the following command:

    grub_close
  7. Reboot the unit to update the kernel changes.
  8. Once you have rebooted, check the system by logging in to the command line and typing the bigpipe platform command.

    After the reboot, the complete output of the bigpipe platform command should only display the physical CPU cores.

    For example:

    # bigpipe platform
    PLATFORM INFORMATION --
    | Marketing Name: BIG-IP 4100 <-- Platform Type
    +-> CPU 0
    | | Type: Intel(R) Xeon(TM) CPU 2.40GHz Speed: 2399.381MHz
    | | Temp: 24degC Fan speed: 5192rpm
    +-> CPU 1
    | | Type: Intel(R) Xeon(TM) CPU 2.40GHz Speed: 2399.381MHz
    | | Temp: 31degC Fan speed: 5273rpm
