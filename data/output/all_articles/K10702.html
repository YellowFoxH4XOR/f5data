Known Issue

This is the result of a known issue. The version of the image2disk utility that shipped with BIG-IP version 9.4.5 does not support the --format option. As a result, BIG-IP Administrators who want to install BIG-IP version 10.x will not be able to choose between the volumes and partitions disk formatting schemes.

If the --format option (specifying either value) is passed to the image2disk utility during an upgrade to BIG-IP version 10.x, the upgrade process will immediately terminate and return the following error message:

Unknown option: format

If the --format option is not passed to the image2disk utility during an upgrade to BIG-IP version 10.x, the partitions disk formatting scheme is assumed and the upgrade process will complete successfully.

Attempts to install a newer version of the image2disk utility by running the im command against a BIG-IP version 10.x ISO file will fail; the image2disk utility is detected on the system and is not reinstalled.

Note: For more information about the image2disk utility, refer to K9880: Error Message: The im utility is no longer used to upgrade software images.

F5 Networks Product Development is tracking this issue as CR131343.

Workaround

To work around this issue, you must first uninstall the version 9.4.5 image2disk utility and then install a later version from a BIG-IP version 10.x ISO file. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. To uninstall the image2disk utility, type the following command:

    rpm -e tm_install-2-1.0.96.0

    Note: Executing this command will produce no output.

  3. Install a new version of the image2disk utility by typing the im command against a BIG-IP version 10.x ISO file

    For example:

    im /var/tmp/BIGIP-10.0.1.283.0.iso

    Note: The im command output appears similar to the following example:

    info: media has tm_install version 2.5.0, release 80.0
    info: adding bin/../isolinux/install/tm_install.rpm to system...

    A new version of the image2disk utility is installed and the --format option is now available.
