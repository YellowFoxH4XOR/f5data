Issue

Description

Importing an iApp template using the command-line interface (CLI)

Environment

  • CLI Access
  • iApp template to be imported

Cause

None

Recommended Actions

Use the following procedure to import an iApp Template from the BIG-IP CLI.

  1. Copy the the iApp template (*.tmpl) file to the BIG-IP system's /shared/tmp directory. For more information about copying files into BIG-IP system, refer to K175: Transferring files to or from an F5 system.
  2. Log in to the command line of the BIG-IP system.
  3. Import the iApp template file using the following command syntax:
    Note: This overwrites the existing template if one exists.

    tmsh load /sys application template <path/to/iApp/template/file>

    For example, to import the /shared/tmp/myiApp.tmpl iApp Template file, type the following command:

    tmsh load /sys application template /shared/tmp/myiApp.tmpl

  4. Save the configuration by typing the following command:

    tmsh save /sys config
