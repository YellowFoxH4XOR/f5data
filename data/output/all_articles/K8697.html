K8697: The IP Group Filter rule with incorrect syntax may not be deleted after an upgrade

Topic

This is the result of a known issue.  After upgrading from FirePass software version 5.5.1 and earlier to a later version, you may not be able to delete IP filter rules with incorrect syntax configured in the Address/Mask field for IP Group Filters of Network Access favorites. Examples of incorrect syntax include non-numeric characters or certain embedded whitespace characters. IP Group Filters are configured from the IP Group Filters tab on the Network Access: Resources page.

Note: You must select the Use packet filter to access LAN check box in order for the IP Group Filters tab to be visible.

Attempting to delete the incorrect rule after an upgrade results in an error message that appears similar to the following example:

error: Invalid IP Address

F5 Networks Product Development is tracking this issue as ID 266950 (Formerly CR91419).
