K000151690: How to migrate Viprion vCMP guest to different blade(s) on the same chassis

Description

This documents the steps to move a vCMP guest from the current blade(s) to different blade(s) by expanding the guest across all the blades and then shrinking it by removing the old blade(s)

 

Environment

Viprion

vCMP

 

Cause

How to article. This preserves the configuration without needing to load from a UCS

 

Recommended Actions

Important Note:

F5 recommends that before making any changes to your systems, you back up each system e.g. both VCMP host and guest, and store the backup in a remote and secure location. For information, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.

Ensure there is enough disk free space on the /var/ and /shared/ partitions on the destination blades. For information, refer to K14403: Maintaining disk space on the BIG-IP system.

Ensure the password of the root account is not expired, see K13121: Changing system maintenance account passwords (11.x - 16.x)

Procedure: Migrating guest by expanding it to all blades and then shrinking it by removing the old blades assigned to the guest

1. In the VCMP Host Configuration Utility/GUI, under vCMP > Guest List, select the guest and change its state to Configured, see K20081511: Shutting down and restarting the vCMP guest from the vCMP host. This will automatically shut down the VCMP guest.

2. Once the Guest is fully offline, select the guest from the VCMP Host Configuration Utility/GUI, under vCMP > Guest List.

  •     Ensure Guest Properties are set to "Advanced".
  •     In the "Allowed Slots List" area, select the new blades in the 'Available' list and move them to the 'Selected' list on the left.
  •     Change the state of the VCMP guest to Deployed.
  •     Click Finish.
This will create virtual disks on the new blades.

3. Validate configurations to ensure things are working as expected and that the new virtual disk creation has completed.

4. In the VCMP Host Configuration Utility/GUI, under vCMP > Guest List, select the guest and change its state to Configured

5. Once the Guest is fully offline, select the guest from the VCMP Host Configuration Utility/GUI, under vCMP > Guest List.

  •     Ensure Guest Properties are set to "Advanced".
  •     In the "Allowed Slots List" area, select the old blades in the 'Selected' list and move them to the 'Available' list on the right.
  •     Change the state of the VCMP guest to Deployed.
  •     Click Finish.

6. Validate configurations to ensure things are working as expected.

7. In the VCMP Host Configuration Utility/GUI, under vCMP > Virtual Disk List, remove the now-unused virtual disks on the old blades.
