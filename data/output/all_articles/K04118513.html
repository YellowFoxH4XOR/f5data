K04118513: BIG-IQ Rotating Archive may fail if the user that created it no longer exists

Type
Support Solution
Published
2021-12-31
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K04118513

Description

Rotating Archive on BIGIQ fails

  • UCS Backups are not created 
  • Rotating Archive job does not complete and there is an error
  • Error similar to:   com.f5.rest.workers.storage.KeyNotFoundException: Get document for key: cm/system/authn/providers/ldap/0ada2557-2c2d-4429-b2bb-f34c66ec8f55/users/8d5e1a14-2fc1-31e7-a52d-507851ef180a returned nothing

Environment

Relevant environmental factors specific to the topic

  • In the BIG-IQ configuration utility:  System>>Back-up & Restore>>Backup Schedules   OR   Devices>>Back-up and Restore>>Backup Schedules
  • Rotating Backup Schedule
  • BIG-IQ CM

Cause

The user that created the rotating backup job no longer exists, locally or remotely.

Recommended Actions

  1. Delete the failed rotating backup.
  2. Recreate the rotating backup using the local admin user.
