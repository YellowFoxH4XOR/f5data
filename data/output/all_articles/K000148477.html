K000148477: BIG-IQ unable to transfer UCS backup archive to external server via SCP with error “com.jcraft.jsch.JSchException: verify: false”

Description

When a scheduled device backup task is configured to store the UCS archive on an external server using Backup Schedule > Devices > Backup Archive, the transfer fails even though the archive is generated locally on BIG-IQ.

Manual SSH or SCP from the command line works successfully.

The following error can be found in the GUI and log files:

com.jcraft.jsch.JSchException: verify: false

Environment

  • BIG-IQ
  • Backup scheduled to transfer archives to an external server via SCP

Cause

The issue was caused by a limitation in the Java JSch library version used by BIG-IQ. This version does not support SSH keys using the ecdsa-sha2-nistp521 algorithm.

Bug ID 1701809 has been opened to track this issue.

Recommended Actions

The workaround is to configure the SSH/SCP server to use the ecdsa-sha2-nistp256 key instead of ecdsa-sha2-nistp521 or ecdsa-sha2-nistp384.

An alternative option is to copy the archives using a custom shell script executed by a cron job on BIG-IQ after the local archives have been generated and collected by BIG-IQ.
