Known Issue

This is the result of a known issue. When restoring a backup configuration to a FirePass Controller, the current software version and the backup software version must be identical — including hotfixes. The restore operation will fail even if the current version hotfix list supersedes the hotfix list in the backup.

F5 Product Development tracked this issue as CR54027 and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.
