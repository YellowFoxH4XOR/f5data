Known Issue

Updating the dynamic ratio of a node or pool member may cause the ConfigSync status to change.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP members configured in a device group.
  • You manually update the dynamic ratio of a node or pool member using the Traffic Management Shell (tmsh) or iControl.

Updating the dynamic ratio of a node or pool member using a built-in dynamic ratio monitor such as SNMP does not cause the ConfigSync status to change.

Impact

If auto-sync is enabled, this results in a configuration synchronization (ConfigSync) across members of the device group. Additionally, a sync conflict may occur if the dynamic ratio is updated frequently (for example, when updating an external monitor or an iControl script).

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After you manually update the dynamic ratio of the node or pool member, the ConfigSync status shown in the Configuration utility and BIG-IP command line changes to Changes Pending or Not All Devices Synced.
  • After you manually update the dynamic ratio of the node or pool member, the BIG-IP systems auto synchronize the configuration.

Workaround

To work around this issue, you can update the dynamic ratio using the guishell utility. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To update the dynamic ratio of a pool member, use the following command syntax:

    guishell -c "update pool_member set dynamic_ratio=<number> where pool_name='/<path>/<pool_name>' and node_name='/<path>/<node_name>' and port='<port#>'"

    In this syntax, the node name is the full folder path to the object name, which might be the node address with the pool folder prepended. In external monitor scripts, the node name is available in the NODE_NAME environment variable.

    For example:

    guishell -c "update pool_member set dynamic_ratio=123 where pool_name='/Common/SMTP_Servers' and node_name='/Common/10.50.5.251' and port='25'"
