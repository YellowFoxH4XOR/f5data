Known Issue

This is the result of a known issue. Using the BIG-IP ASM cross-site request forgery (CSRF) and BIG-IP WebAccelerator Intelligent Browser Referencing (IBR) features simultaneously may cause page load issues. This issue is caused by the manner in which the BIG-IP WebAccelerator and BIG-IP ASM influence client requests. For example:

  • When IBR is enabled for the BIG-IP WebAccelerator policy, the system appends a pv tag to certain URLs on the page
  • When CSRF protection is enabled for the BIG-IP ASM security policy, the BIG-IP ASM system appends a CSRF token to URLs

When both the pv tag and the CSRF token are appended to the request, the BIG-IP system fails to remove the pv tag before sending the request to the server. The request sent to the server may appear similar to the following example:

GET /image.gif;pvxxxxx?CSRF=xxxxx HTTP/1.1

When the system fails to remove the pv tag, the server may not be able to process the request and return an error message; for example, the server may return an HTTP 404 Not Found error message.

F5 Product Development tracked this issue as ID 339381 and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP ASM and WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
