K05504040: BIG-IQ fail to assign pool license to BIG-IP with error ''Unparseable license format''

Type
Support Solution
Published
2022-06-08
Updated
2023-02-21
Applies to

  • BIG-IQ Platforms

Source

Description
When try to assign an activated pool license offering from a BIG-IQ to BIG-IP devices, the license is not deployed on the BIG-IP devices.

The following error message can be found in restjavad log file /var/log/restjavad.0.log.

[ERROR][27 May 2022 18:53:56 SGT][/cm/device/licensing/pool/utility/licenses/S1234-12345-67890-12345-1234567/offerings/e12b39ce-6e86-4452-b32c-4f222f129b46/members UtilityLicenseMemberCollectionWorker] Utility license S1234-12345-67890-12345-1234567, offering F5-BIG-MA-MSP-TEST-LIC-DEV: Grant https://localhost/mgmt/cm/device/licensing/pool/utility/licenses/S1234-12345-67890-12345-1234567/offerings/e12b39ce-6e86-4452-b32c-4f222f129b46/members/cf0e96e7-c155-44d0-8311-9362516d2750: Error installing: Unparseable license format: com.f5.rest.workers.device.license.LicenseException: Unparseable license format

Environment

  • BIG-IQ CM
  • BIG-IQ License Manager

Cause
The error typically happens when the license text to be installed on the BIG-IP is malformed. This is usually because the license text was not copied and pasted properly during manual activation on the BIG-IQ GUI.

Recommended Actions

  1. Re-activate the license and the offerings automatically, this will reduce human errors that would happen in manual activation.
  2. If automatic activation is not possible, make sure the license text is copied unchanged in manual activation. Record the license text you copied into BIG-IQ GUI for later reference.
