K88027052: Error Message ''Unexpected Error: can't get oid for nested object, keyword (white-ip) join table (bot_defense_asm_white_ip)''

Type
Support Solution
Published
2021-06-30
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.4
Source
https://my.f5.com/manage/s/article/K88027052

Description

  • Running the command `tmsh -q -c 'cd /; list recursive'` results in an error message.
  • Error message occurs and the command does not succeed
  • Error message "Unexpected Error: can't get oid for nested object, keyword (white-ip) join table (bot_defense_asm_white_ip)"

Environment

  • ASM 
  • IP address exception entry with an invalid network mask configured at Security  ››  Application Security : IP Addresses : IP Address Exceptions
  • Whitelist IP entry with an invalid network mask configured at Security  ››  Bot Defense  ››  [bot defense profile name] ›› Whitelist

Cause

Invalid network mask in the ASM policy or Bot Defense configuration

Recommended Actions

  1. Navigate to the invalid entry in the policy IP Address Exception or Bot Defense Whitelist and remove the entry.
    • Security  ››  Application Security : IP Addresses : IP Address Exceptions
    • Security  ››  Bot Defense  ››  [bot defense profile name] ›› Whitelist
