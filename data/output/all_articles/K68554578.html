K68554578: Ansible's bigiq_device_info module returns error when gathering the system-info subset

Type
Support Solution
Published
2021-01-07
Updated
2023-10-16
Applies to
  • F5 Automation and Orchestration
  • F5 Modules for Ansible
Source

Description

All but the system-info subset in the bigiq_device_info module have no errors in ansible

Environment 

  • Ansible v2.9
  • BIG-IQ 7.0 or later

Cause

The iControl calls made by the bigiq_device_info module are no longer supported in BIG-IQ starting in version 7.0. This only affects Ansible v2.9 base, as the collection and v2.10 will not attempt to make the same iControl calls when the BIG-IQ is v7.0 or later. 

Recommended Actions

If you are using the bigiq_device_info with Ansible v2.9 to collect information about a BIG-IQ version 7.0 or later, be sure not to include the system-info subset, by adding !system-info to the gather_subsets
