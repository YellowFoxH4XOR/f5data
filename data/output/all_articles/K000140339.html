Description

 

F5OS doesn't log when a client access to management port from an IP address that is not allowed for protocols - 443 (HTTPS), 80 (HTTP), 8888 (RESTCONF), 161 (SNMP), 7001 (VCONSOLE), and 22 (SSH).

 

Example for SSH :

 

RSeries# show running-config system allowed-ips 

system allowed-ips allowed-ip my_ssh_allow

 config ipv4 address 192.168.1.1

 config ipv4 prefix-length 32

 config ipv4 port 22

!

 

Environment

  • F5OS-A
  • Allow List for F5OS management is configured

 

Cause

 

This is by design because at system level F5OS filter connection attempts through the system iptables firewall and it don't log traffic dropped by iptables.

 

Recommended Actions

 

A new design was introduced in F5OS-A/C 1.8.0. See ID 1268433.
