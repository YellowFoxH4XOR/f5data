Security Advisory Description

Stack-based buffer overflow in the catopen function in the GNU C Library (aka glibc or libc6) before 2.23 allows context-dependent attackers to cause a denial of service (application crash) or possibly execute arbitrary code via a long catalog name. (CVE-2015-8779)

Impact

A stack overflow vulnerability in the glibc catopen() function may allow execution of arbitrary code or cause applications that pass long strings to the catopen() function to crash.
