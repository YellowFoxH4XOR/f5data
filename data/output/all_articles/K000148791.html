K000148791: 503 Service Unavailable returned via HTTP Explicit Proxy, even though there were DNS responses

Description

A virtual server configured to act as an HTTP Explicit Proxy is returning 503 Service Unavailable responses to clients, despite apparent successful DNS resolution.

Environment

  • HTTP Explicit proxy
  • DNS resolver
  • DNS queries

Cause

DNS query response returned does not match the case pattern that was used in the query sent from the BIG-IP.

For example, given a query for:

wwW.eXaMPle.CoM

An invalid response might be for:

wwW.eXaMple.CoM

Note the non-matching case of the p character.

With this example, a valid response must match:

wwW.eXaMPle.CoM

Recommended Actions

Investigate why DNS servers are returning invalid responses, and fix the issue.

Alternatively, you may be able to work around this issue by disabling Randomize Query Character Case in the DNS resolver configuration. Note that disabling this option reduces protection from DNS poisoning.

Additional Information

This issue could also happen if DNS servers are returning valid but delayed responses. See bug ID969553 for more information.

  • Bug ID 969553: A DNS Cache (or Network DNS Resolver) returns SERVFAIL to some queries.
