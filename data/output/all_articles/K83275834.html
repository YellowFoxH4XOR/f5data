Description

A Wide IP Pool status is available even when its pool members are marked offline on the BIG-IP LTM.

Environment

  • BIG-IP DNS
  • Wide IP Pool where all members are LTM virtual servers
  • TCP Monitor associated to the Wide IP Pool

Cause

  • The Wide IP Pool relies on the associated TCP monitor to determine its members availability
  • The pool members (virtual servers) on the LTM are responding to TCP requests even when offline

Recommended Actions

Remove the TCP Monitor associated to the Wide IP Pool.

Important: When all members of a BIG-IP DNS pool are BIG-IP LTM virtual servers, you do not need to associate a monitor with the DNS pool. The health monitors on the BIG-IP LTM system provide the status for those virtual servers, and the BIG-IP LTM system's big3d agent uses iQuery to report the BIG-IP LTM virtual server status to the BIG-IP DNS system.
