Description

Removal of the following tenant configurations at F5OS level does not remove the corresponding configurations from the tenant BIG-IP VE:

  • VLAN
  • Virtual Wire
  • Trunk

Environment

  • Tenant BIG-IP VE has VLAN, Virtual Wire, or trunk configuration.
  • One or more of those configuration objects are removed from the tenant configuration.

Cause

In F5OS, VLANs, Virtual Wires, and LAGs (trunks) are configured at the F5OS network settings. The configured objects are then available for selection on the tenant as needed. When those configuration objects are removed from tenant configurations at F5OS level, the tenant BIG-IP VE will not automatically remove them from its configuration because doing so may cause config validation errors at start up due to existing references to the VLANs, Virtual Wires, and trunks from other configuration objects.

The behavior is tracked as ID 1154737.

Recommended Actions

When you have removed a VLAN, Virtual Wire, or trunk from the tenant configuration at the F5OS level, you should also remove them directly from the tenant and save config by running the following commands on the BIG-IP VE tenant.

# tmsh delete net vlan-group <virtual_wire>
# tmsh delete net vlan <vlan>
# tmsh delete net trunk <trunk>
# tmsh save sys config
