Known Issue

This is the result of a known issue. When a user exits Protected Workspace, the FirePass client-side component fails to delete the Windows shortcuts from the Microsoft Office most recently used (MRU) directory. The purpose of the MRU feature is to provide quick access to recently accessed files, but for security reasons, many administrators prefer not to have these files listed.

The default location for the Microsoft Office MRU shortcuts is as follows:

%USERPROFILE%\Application Data\Microsoft\Office\Recent

Note: For more information about clearing the Microsoft Office MRU list, refer to the following website:

http://support.microsoft.com/kb/826208.

This link takes you to a resource outside of AskF5, and it is possible that the documents may be removed without our knowledge.

F5 Product Development tracked this issue as CR93835 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by manually deleting the Microsoft Office most recently used (MRU) shortcuts. The default location for the Microsoft Office MRU shortcuts is as follows:

%USERPROFILE%\Application Data\Microsoft\Office\Recent
