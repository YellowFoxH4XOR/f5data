Topic

You should consider using this procedure under the following condition:

  • You would like to use the performance enhancements available with the ARX 2500.

Description

As of version 6.2.0, the ARX system contains performance improvements for the ARX-2500 with a new resource profile. This profile dedicates three separate hardware cores to network processing. The former resource profile divided the processing among four virtual cores that shared the same hardware resources. Upgraded ARX-2500 devices retain their pre-6.2.0 legacy profile.

You can verify your ARX system configuration by typing the following command on the ARX CLI:

show running-config

If the legacy configuration is in place, you will see resource-profile legacy under the system category, which appears similar to the following example:

================================ system =================================
config

  hostname ARX1

  ip name-server 172.168.0.10

  resource-profile legacy

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You are using an ARX 2500.
  • You have upgraded the ARX system to version 6.2.0 or greater from a prior release.

Procedures

Converting to the optimized resource profile

You may use the no resource-profile legacy CLI command to disable the legacy profile and enable the new optimized resource profile.

Impact of procedure: Enabling this feature requires a reboot of both devices simultaneously causing an approximate 10 to 15 minute outage.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. Enter config mode by typing the following command:

    config

  4. Disable the Legacy profile by typing the following command:

    no resource-profile legacy

  5. Return to privileged mode by typing the following command:

    end

  6. Perform the previous steps on peer switch.
  7. Issue a dual reboot on one of the ARX systems by typing the following command:

    dual-reboot
