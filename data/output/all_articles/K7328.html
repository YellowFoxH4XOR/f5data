Known Issue

This is the result of a known issue. When you run Network Access from the FirePass Webtop, then close the browser window that runs the Webtop, you will not receive a warning pop-up message if you are using Internet Explorer 6 (IE6) SP1 with Microsoft Security Update MS06-042 (KB ID 918899) or a later version of IE6.

Normally, if you close the browser window that runs the Webtop, a warning pop-up message appears with text similar to the following example:

You closed the window containing the Firepass webtop. Do you want to close current application tunnel/VPN connection?

However, when using IE6 with Microsoft Security Update MS06-042 (KB ID 918899) or a later version of IE6, this warning pop-up message will not appear. Instead, when you close the Webtop's window, the Network Access connection is terminated.

F5 Networks tracked this issue in CR70734 and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass Release Notes.

Additionally, a hotfix has been issued. For feature release version 6.0.0 of FirePass software, this issue was fixed in cumulative hotfix HF-600-8. You may download this hotfix or a later version of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
