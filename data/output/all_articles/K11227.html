Known Issue

This is the result of a known issue. The Simple Object Access Protocol (SOAP) monitor does not function if debugging is enabled in the monitor configuration. When a SOAP monitor is in debug mode, the BIG-IP system does not run any health checks and marks the monitored pool members as down. In addition, error messages are logged to the SOAP monitor debug file, which appear similar to the following example:

*** glibc detected *** /usr/share/monitors/SOAP_monitor: free(): invalid pointer: 0xf7739780 ***

Note: BIG-IP versions prior to 10.1.0 also log similar error messages when debugging is enabled; however, in these versions, the SOAP monitor carries out the health checks as expected.

F5 Product Development tracked this issue as ID 226788 (formerly CR142148) and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP release notes.
