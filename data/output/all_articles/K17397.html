Issue

Old Behavior

In versions prior to BIG-IP 12.0.0, access to the iControl SOAP application programming interface (API) could not be restricted to a specific IP address or subnet.

Prior to BIG-IP 12.0.0, any Configuration utility user with the Administrator role can access the iControl SOAP API, regardless of their source IP address.

New Behavior

Beginning in BIG-IP 12.0.0, access to the iControl SOAP application programming interface (API) can now be restricted to a specific IP address or subnet.

F5 Product Development tracked this change as ID 457587.

Impact

Access to the iControl SOAP API on the BIG-IP system can now be restricted to a specific IP address or subnet.

Recommended Actions

You can use the tmsh utility to restrict iControl API access to a specific IP address or subnet. For more information, refer to: K17459: Restricting access to the iControl API by source IP address.
