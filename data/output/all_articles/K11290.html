Known Issue

This is the result of a known issue. Modifying the TTL value for a BIG-IP GTM wide IP pool does not update the associated TTL for the BIND resource records. For example, if you use the Configuration utility to modify the TTL value for a pool from the default value of 30 to 60, the Configuration utility and wideip.conf file will show the new TTL value of 60, but the corresponding BIND resource record TTL value continues to show the original TTL value of 30.

This issue occurs because the mcp daemon does not send a message to the ZoneRunner daemon, zrd, indicating that the TTL has changed.

F5 Product Development tracked this issue as ID 224994 (Formerly CR138270), and it is fixed on BIG-IP 11.0.0.

Workaround

To work around this issue, update the BIND zone database file using the ZoneRunner utility. To change the value for a resource record using the ZoneRunner utility, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Global Traffic.
  3. Click ZoneRunner.
  4. Click the Zone List menu.
  5. Click the appropriate zone name.
  6. Click the Resource Records menu.
  7. Click the appropriate resource record from the list.
  8. Update the TTL value to match the TTL value for the wide IP pool.
  9. Click Update.
