Known Issue

Description

Creating a subfolder on a Microsoft Windows Distributed File System (DFS) share through the FirePass Windows Files Favorites fails. When you configure the file share favorite to access a DFS share, and the user attempts to create a subfolder with the Create subfolder: option, the attempt fails with an error message that appears similar to the following example:

Couldn't create <directory name> in \\<path to DFS share>
Click here to return.

Impact

This issue prevents users from creating new subfolders on a DFS share.

Symptoms

As a result of this issue, you may experience the following symptoms:

  • When you create a new subfolder, the system displays the following error message:

    Couldn't create <directory name> in \\<path to DFS share>
    Click here to return.

  • The new subfolder is not created.
