Description

Adding devices to Device Group which are set to Forced Offline. The system shows Traffic Group has the message Initializing/Not Synced under next active device.
Sync works between the systems however, and the upper left corner in the GUI shows "In sync" in green.

Environment

  • HA group
  • Systems Forced Offline or Offline
  • Traffic Group shows Initializing/Not Synced
  • Config-sync still works despite the Traffic Group message

Cause

System was added in while in "Forced Offline" status.

Recommended Actions

Release device from "Forced Offline" state. 
  1. Log in to the Configuration utility.
  2. Go to Device Management > Devices.
  3. Select the local device (Self).
  4. Select Release Offline.
The message will clear up and show "In sync".
