Description

In OpenAPI (Swagger) specification file, The pattern keyword lets you define a regular expression template for the string value. Only the values that match this template will be accepted.


Environment

  • OpenAPI (Swagger) specification file.
  • API Security policy template.

Cause

The system might create URLs without the expected JSON profile due to noncompliance regular expression.


 Recommended Actions

Regular expressions are case-sensitive, that is, [a-z] and [A-Z] are different expressions. therefore, please make sure the defined regular expression is compliant with JavaScript's regular expression syntax (more specifically, ECMA 262).
