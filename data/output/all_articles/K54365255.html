Issue

Error Message

warning tmm[<PID>]: 01010291:4: TCP: Memory pressure deactivated. Dropped <#> packets, <#> bytes

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (tmm) process.
  • <#> is the number of dropped packets or bytes.

For example:

warning tmm[8484]: 01010291:4: TCP: Memory pressure deactivated. Dropped 314 packets, 414263 bytes

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The tm.tcpmemorypressure database variable is set to enabled (default).
  • The TMM memory utilization has previously exceeded the threshold set in tm.tcpmemorypressure.lowater database variable, is now below the threshold.

Impact

The message indicates that memory utilization has previously exceeded TCP memory pressure thresholds, the BIG-IP system may drop ingress TCP packets and service may be disrupted due to the lost TCP payload and packets.

Recommended Actions

Frequent appearance of the message may indicate that the BIG-IP system does not have sufficient memory resource for TMM under high traffic load. To mitigate the issue, you can reduce the traffic load to the high traffic load virtual server or reduce overall traffic to the BIG-IP system. If the BIG-IP system is a virtualized instance such as a virtual edition (VE) or a vCMP guest, you can increase the amount allocated memory of the BIG-IP instance.
