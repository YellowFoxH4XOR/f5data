Known Issue

You may be unable to configure an SNMP trap destination record.

This issue occurs when the following condition is met:

  • You attempt to configure your BIG-IP device with an SNMP trap destination record using Default for the trap destination network.

Impact

The system does not create the SNMP trap destination record.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use the Configuration utility to create the SNMP trap destination record, you observe an error message similar to the following example:

    Some fields below contain errors. Correct them before continuing.

  • When you use the TMOS Shell (tmsh) to create the SNMP trap destination record, the system displays an error message similar to the following example:

    01070911:3: The requested enumerated (default) is invalid (, mgmt, other) for network in /<partition>/snmpd trapsess (/<partition>/<trap record name>)
