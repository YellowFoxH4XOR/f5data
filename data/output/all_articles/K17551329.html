Topic

You should consider using this procedure under the following condition:

  • You want to snapshot a system disk by creating an image of a disk or partition.

Description

During ongoing maintenance of your BIG-IP or BIG-IQ system you may need to take a snapshot of the system disk by creating a disk image, also referred to as a clone of the disk.

Important: A disk image created in this way may also be used for forensics; note, though, that forensic investigation companies may have specific requirements for creating the disk image which you will need to adhere to and you may need to follow their specific instructions. F5 does not provide any forensic services.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have root privileges on the BIG-IP or BIG-IQ command line

Procedures

Create a disk image of a partition or an entire disk

You can use the dd utility to create a disk image of an entire disk or a partition. The procedure creates an exact replica of the source disk or partition.

Impact of procedure: Depending on the size of the disk, the replication process may take an extended period of time and constrain system resources. F5 recommends performing this procedure during a maintenance window.

  1. Log in to the BIG-IP or BIG-IQ command line
  2. Determine the disk or partition you want to create an image of by typing the following command:

    fdisk -l

    The command output appears similar to the following example. You may also see a list of logical volumes.

    Disk /dev/sda: 42.9 GB, 42949672960 bytes, 83886080 sectors
    Units = sectors of 1 * 512 = 512 bytes
    Sector size (logical/physical): 512 bytes / 512 bytes
    I/O size (minimum/optimal): 512 bytes / 512 bytes
    Disk label type: dos
    Disk identifier: 0x00000000

    Device Boot Start End Blocks Id System
    /dev/sda1 * 1 409599 204799+ b W95 FAT32
    /dev/sda2 409600 442367 16384 82 Linux swap / Solaris
    /dev/sda3 442368 83885071 41721352 8e Linux LVM

  3. Determine the target location to store the disk image, such as a mounted high capacity USB drive or a mounted network drive.

    Example of mounting a network drive:

    mount -t cifs -o username=user1,vers=2.0 //software.mylab.local/snapshots /snapshots

    Example of mounting a USB drive

    mount /dev/sdb1 /mnt/usb

  4. To create a disk image, use the dd utility with the following syntax:

    dd if=/dev/<disk name you want to copy> of=</full/path/of/new/file>.img

    Example of creating a snapshot of a disk:

    dd if=/dev/sda of=/snapshots/users/user1/sda_snapshot.img

    Example of creating a snapshot of a partition:

    dd if=/dev/sda3 of=/snapshots/users/user1/sda3_snapshot.img

  5. To verify the partition table of the disk image you created, type the following command:

    fdisk -l <image file>

    For example:

    fdisk -l /snapshots/users/user1/sda_snapshot.img

    The command output appears similar to the following example:

    Disk /snapshots/users/user1/sda_snapshot.img: 42.9 GB, 42949672960 bytes, 83886080 sectors
    Units = sectors of 1 * 512 = 512 bytes
    Sector size (logical/physical): 512 bytes / 512 bytes
    I/O size (minimum/optimal): 512 bytes / 512 bytes
    Disk label type: dos
    Disk identifier: 0x00000000

    Device Boot Start End Blocks Id System
    /snapshots/users/user1/sda_snapshot.img1 * 1 409599 204799+ b W95 FAT32
    /snapshots/users/user1/sda_snapshot.img2 409600 442367 16384 82 Linux swap / Solaris
    /snapshots/users/user1/sda_snapshot.img3 442368 83885071 41721352 8e Linux LVM
