Description 

In the bigip.conf  file, found the symbole '.' (Dot) appears instead the traditional ':' (Colon) when preparing new BIG IP environment.
An example:
 

ltm monitor http /Common/HTTP_TEST {
 adaptive disabled
 defaults-from /Common/http
 description BIGIP01_UI
 destination *.80         <<    With a DOT instead of COLON
 interval 15
 ip-dscp 0
 recv "200 OK"
 recv-disable none
 send "GET /healthcheck HTTP/1.1\r\nHost: BIGIP01.com\r\nConnection: close\r\n\r\n"
 time-until-up 0
 timeout 46
}

 

Environment 

  • BIG IP
  • Configuration file

Cause 

As expected

Recommended Actions 

None

Additional Information

The behavior is intentional to accommodate ipv6 addresses.

With ipv6, you'll use the Period as separator- eg: *.80 and for ipv4 - Colon *:80
