Known Issue

The BIG-IP Configuration utility may not allow you to view or delete an SNMP agent access record.

This issue occurs when the following conditions are met:

  • The SNMP agent access record contains an IP address format where the source value is an IP address with a netmask in either of the formats illustrated below:

    • 10.10.10.0/24
    • 10.10.10.0/255.255.255.0
  • You attempt to use the Configuration utility to view or delete the SNMP agent access record from the record list.

Impact

Users cannot delete the SNMP access record using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H388359 on the Diagnostics > Identified > Low screen.
  • When you navigate to System > SNMP > Agent > Access (v1,v2c), and select the SNMP access record to view the configuration, the system generates the following error message:

    No object identifier specified in context.
  • When you attempt to delete the SNMP access record from the Configuration utility on the Confirm Delete page, you may see an error message that appears similar to the following example:

    No records to display.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to perform the SNMP access record deletion. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. You can list the SNMP access record by using the following command:

    list /sys snmp communities

    The output appears similar to the following:

    sys snmp {
    communities {
    comm-public {
    community-name public
    source default
    }
    ipublic_LTM_1 {
    community-name public_LTM
    oid-subset .1
    source 10.10.10.0/24
    }
    }
    }
  3. You can delete a SNMP access record using the following command syntax:

    modify /sys snmp communities delete { <community_configuration_name> }

    For example, to delete an SNMP access record community configuration named ipublic_LTM_1 you would type the following command:

    modify /sys snmp communities delete { ipublic_LTM_1 }

  4. Save the changes by typing the following command:

    save sys config
  5. To exit the tmsh command utility, type the following command:

    quit
