K000150650: Inconsistency in error status for disconnected interfaces on VELOS unit after upgrade to 1.8.0

Type
Support Solution
Published
2025-07-07
Updated
2025-07-07
Applies to
  • F5OS
  • F5OS-C: 1.8.0, 1.8.1
Source
https://my.f5.com/manage/s/article/K000150650

Description

Inconsistency with alarms within port groups 3/1 and 3/2 despite ports 3/1.4 and 3/2.4 being in the exact same status.

You can observe that two disconnected port groups may differ in reporting behavior - eg. VELOS chassis will report 3/1.4 interface being Down, but second one (3/2.4) will not, despite that they are both without connected cable in port.

Environment

F5OS-C

Cause

BUG ID 1858657

Recommended Actions

Unfortunately currently there is no workaround or mitigation for this inconsistency.

For further updates please follow below Bugtracker article:

Bug ID 1858657: Inconsistency with receiver power low alarms on portgroups 3/1 and 3/2 despite ports 3/1.4 and 3/2.4 being in the exact same state
