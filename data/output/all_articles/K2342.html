Note: Beginning in BIG-IP version 4.0, you can load balance PPTP connections. This option was not available prior to BIG-IP version 4.0.

To configure PPTP connection load balancing you will need to perform the following procedures:

  • Create a pool with PPTP servers to load balance
  • Create a wildcard port virtual server to allow key negotiation and GRE packets
  • Enable the any_ip option for the virtual address to allow GRE packets
  • Create a rule which passes only PPTP traffic to a secure wildcard virtual server (optional)

The standard port for PPTP is TCP port 1723; however, TCP port 1723 is used only for the PPTP control connection.

The data connections use GRE (IP protocol 47), which is not TCP or UDP. To pass the data connection GRE packets, the virtual server ust be a wildcard port virtual server (virtual_address:any) with the any_ip feature enabled for the virtual address.

For instructions about how to create pools, virtual servers, or iRules refer to the BIG-IP manuals,

The following example configuration represents a wildcard port virtual server with the any_ip feature enabled for the virtual address:

pool pptp {
member <member IP address>:1723
member <member IP address>:1723
}
virtual <VIP address>:any unit 1 {
use pool pptp
}
virtual <VIP address>: any_ip enable
virtual <VIP address>: any_ip timeout 15

If creating a wildcard virtual server is a security concern, you can configure the wildcard virtual server to use the following example iRule:

Note: This iRule will only allow port 1723 (PPTP control) or protocol 47 (GRE) packets; all other packets will be discarded.

rule pptp_gre_filter {
if (ip_protocol == "47" or server_port == "1723") {
use pool pptp
}
else {
discard
}
}

The following example represents a configuration with an optional rule used to secure the wildcard port virtual sever to only PPTP traffic:

pool pptp {
member <member IP address>:1723
member <member IP address>:1723
}
rule pptp_gre_filter {
if (ip_protocol == "47" or server_port == "1723") {
use pool pptp
}
else {
discard
}
}
virtual <VIP address>:any unit 1 {
use rule pptp_gre_filter
}
virtual <VIP address>: any_ip enable
virtual <VIP address>: any_ip timeout 15
