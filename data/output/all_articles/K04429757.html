Description

Configuring Machine Cert Auth with the certificate chain, but authenticate Failed. Change the access policy log level to debug, see the log like below:

debug apmd[PID]: 01490266:7: /Common/<Access_policy_name>:Common:<session_id>: modules/FarEndInspection/CheckMachineCert/CheckMachineCertAgent.cpp: 'CheckMachineCertAgentexecuteInstance()': 648: agent_endpoint_check_machinecert: X509_verify_cert failed: error #: 2 at depth 1, error message:unable to get issuer certificate

Environment

  • BIG-IP APM 13.1.1, BIG-IP APM 14.1.x
  • Machine Cert Auth
  • Client certificate is signed by the intermediate CA certificate

Cause

BIG-IP APM cannot verify the certificate chain.

Recommended Actions

  1. Verify the certificate chain.
  2. Append the Root CA certificate to the Intermediate CA certificate file.
    • Using Configuration Utility:
      1. Go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List and click Import...
      2. Select Import Type as Certificate
      3. On Certificate Name, type a name for the certificate bundle
      4. On Certificate Source, choose Paste Text
      5. Copy and paste the certificate text of the Root CA, and below that copy and paste the certificate text of the Intermediate CA
      6. Click Import
    • Using CLI:
cat Intermediate.crt root.crt > Intermediate_and_root.crt
  1. Import the certificate bundle and apply to the SSL : Certificate Authority profile
    1. Go to Local Traffic > Profiles > SSL > Certificate Authority
    2. Click on the name of the certificate authority you are using for your Machine Cert Auth
    3. On Configuration ›› Trusted Certificate Authorities, select the new certificate bundle created
    4. Click Update
