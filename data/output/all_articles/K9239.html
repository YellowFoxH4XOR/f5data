Known Issue

This is the result of a known issue. When more than two domains are configured per virtual processing unit (VPU), the amount of memory allocated to the metadata cache may leave insufficient memory resources. This behavior results in poor system performance, or a failover. 

Note: For more information, refer to the Changing the Number of Domains Per VPU section of the ARX CLI Storage-Management Guide.

Note: The metadata cache-size setting specifies how much cache memory (in MB) to allocate for managed-volume metadata. This size is used for each VPU domain used by the current namespace. The default value for the metadata cache-size setting is 512. 

F5 Product Development tracked this issue as ARX ID 21925, and it was fixed in ARX 5.2.0. For information about upgrading, refer to the ARX release notes.

Workaround

When more than two domains are configured per VPU, use the metadata cache-size 256 command to reduce the amount of memory allocated for the metadata cache to be 256 MB.

Note: For information about the metadata cache-size command, refer to the ARX CLI Reference Guide.
