You can change the TCP idle timeout used by a virtual server by changing the existing TCP profile, or by creating a new TCP profile that uses a different timeout value.

Changing the idle timeout for an existing TCP profile

  1. Log in to the Configuration utility.
  2. In the main navigation pane, click Local Traffic.
  3. In the sub-menu, select Profiles.
  4. Click the Protocol tab.
  5. In the drop-down box, select TCP.
  6. Click the TCP profile for which you want to change the idle timeout.
  7. Enter the new Idle Timeout in seconds.
  8. Click Update.

Note: Changing the idle timeout value for an existing TCP profile does not affect existing virtual server connections; existing connections continue to use the previous idle timeout value.

Creating a new TCP profile that uses a different timeout value

  1. Log in to the Configuration utility.
  2. In the main navigation pane, click Local Traffic.
  3. In the sub-menu, select Profiles.
  4. Click the Protocol tab.
  5. In the drop-down box, select TCP.
  6. Click the Create button.
  7. Name the new TCP profile.
  8. Select TCP as the Parent Profile.
  9. Check the Custom checkbox.
  10. Enter the new Idle Timeout in seconds.
  11. Click the Finished button.
  12. In the sub-menu, select Virtual Servers.
  13. Select the virtual server you want to change.
  14. In the Configuration drop-down box, select Advanced.
  15. In the Profile drop-down box, select the new profile you created.
  16. Click the Update button.

The virtual server will now use the new idle timeout setting.
