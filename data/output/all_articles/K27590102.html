Description

Get the gtm log repeatedly below:

notice gtmd[PID]: 011a001c:5: SYNC_ZONES from <SELF IP> skipped. Reason: sync_zones currently running from ip <SELF IP>
err zrd[PID]: 01150a39:3: Sync Zones pid:<PID> exited with error 255

Environment

  • BIG-IP GTM/DNS
  • Zone Configuration Synchronization

Cause

When configuring the Configuration Synchronization, the device still using the default device certificate, CN is localhost.localdomain, and the CN confusion causes the issue.

Recommended Actions.

  1. Refer to K6353, renew the device certificate, make sure each device have unique CN.
  2. Refer to K13312, run the bigip_add on each device, make sure each device trust the certificate from others.

None.
