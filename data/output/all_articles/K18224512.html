K18224512: Restoring a BIG-IP ASM/Adv WAF Security Policy Version in version 16 and later

Type
Support Solution
Published
2022-07-12
Updated
2024-03-02
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.X.X, 16.1.X, 16.0.X, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K18224512

Description

Beginning BIG-IP version 16, the menu to restoring a specific version of a security policy has changed, it is now found by accessing security policy list and viewing the available versions of the policy then restoring the specific version. 

Environment

Security Policy
BIG-IP ASM / Adv WAF version 16 and later

Cause

The menu to restore a version of a Security Policy has changed in version 16.

Recommended Actions

To restore a previous version of a BIG-IP ASM/Adv WAF Security Policy in version 16 and later, review the Security Policy version in  the Configuration Utility. 

Go to Security  ››  Application Security : Security Policies : Policies List  ››  <Security Policy Name>, under the general settings in the "Version" section click on the "date and time" in blue text to pull up the policy's history. 

Hover over the available version in the Policy Version History list you would like to restore, then click on the Replace current policy clock icon.
