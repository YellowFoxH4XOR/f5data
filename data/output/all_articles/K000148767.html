K000148767: When configuring neighbor Local-AS for BGP, Local-AS can not be configured above highest signed 32 bit integer (2147483647)

Type
Support Solution
Published
2025-01-27
Updated
2025-01-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000148767

Description

  • When attempting to assign the neighbor peer or peer-group Local-AS to a 32 bit integer higher than 2147483647, the BIG-IP will default the setting to 2147483647. Any selections below 2147483647 will configure as expected, and this same issue is not seen while configuring the Remote-AS.
  • Error is only found after running sh run in imish after configuring BGP router settings.
  • Example:

[root@bigip-a:Active:Standalone] config # imish

bigip-a[0]>enable

bigip-a[0]#conf t

Enter configuration commands, one per line. End with CNTL/Z.

bigip-a[0](config)#router bgp 123456

bigip-a[0](config-router)#neighbor TEST remote-as 4200000002

bigip-a[0](config-router)#neighbor TEST local-as 4200000002

bigip-a[0](config-router)#end

bigip-a[0]#wr

Building configuration...

[OK]

bigip-a[0]#sh run

!

no service password-encryption

!

bgp extended-asn-cap

!

router bgp 123456

bgp graceful-restart restart-time 120

neighbor TEST peer-group

neighbor TEST remote-as 4200000002

neighbor TEST local-as 2147483647

!

line con 0

login

line vty 0 39

login

!

end

 

 

Environment

  • BIG-IP LTM
  • BGP
  • imish
  • 32 bit ASN enable

Cause

The 32 bit integer used to configure Local-AS is saved as a string. and then back to a signed integer. F5 Development has identified this as ID1772201.

Recommended Actions

Currently, Local-as can only be configured up to 2147483647. ASN needs to be below the highest signed 32 bit integer or use 16 bit integers.
