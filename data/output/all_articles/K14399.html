Topic

You should consider using this procedure under the following condition:

  • You want to use Simple Network Management Protocol (SNMP) to determine the failover status of a BIG-IP system in a device group.

Description

The F5-BIGIP-SYSTEM-MIB file contains the sysCmFailoverStatusId object identifier (OID) (1.3.6.1.4.1.3375.2.1.14.3.1) that can be queried through SNMP to determine the failover status of a BIG-IP system in a device group. The sysCmFailoverStatusId uses an integer value to represent the status of the BIG-IP system. The following table provides the possible values for this OID.

ValueFailover statusDescription
0unknownThe failover status of the device is unknown.
1offlineThe device is offline.
2forcedOfflineThe device is forced offline.
3standbyThe device is standby.
4activeThe device is active.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access an SNMP agent.
  • If you are performing the query from a remote SNMP agent, ensure that you have configured the BIG-IP system to allow the remote SNMP agent to perform a SNMP query against it.

Procedures

Using SNMP commands to determine the failover status

You can use either the snmpget or snmpwalk command to determine the failover status of the BIG-IP system from the command line. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your SNMP agent.
  2. Enter either of the following SNMP command syntaxes to determine the failover status:

    snmpwalk -v 2c -c <SNMP community string> <SNMP host> .1.3.6.1.4.1.3375.2.1.14.3.1

    snmpget -v 2c -c <SNMP community string> <SNMP host> .1.3.6.1.4.1.3375.2.1.14.3.1.0

    For example, enter the following snmpget command on a BIG-IP system using the SNMP community string of public to query itself:

    snmpget -v 2c -c public localhost .1.3.6.1.4.1.3375.2.1.14.3.1.0
