Topic

During boot up, BIG-IP writes the following message to the console:

Loading /boot
Press ESC to boot now or any other key to interrupt boot sequence.

The boot interrupt sequence timer is included in the /etc/boot.default file. The complete file appears as follows:

echooff
-bootdebug 0
-autodebug -q
-console auto

To adjust the boot interrupt sequence timer, you must add a pause entry to the end of the /etc/boot.default file as follows, where <n> is the number of seconds that you want the BIG-IP to pause:

Warning: Do not adjust the boot interrupt sequence timer to a lower value.

-pause <n>

Important: F5 Networks recommend that you do not set the pause setting to 0, because it would make it impossible to interrupt the boot sequence and boot into single user mode. Single user-mode is required when using fsck to repair a damaged file system and to run the diskdefect command.

For example, the following /etc/boot.default file has been modified to add a pause of 10 seconds:

echooff
-bootdebug 0
-autodebug -q
-console auto
-pause 10

Important: Any typographical errors or extra lines in the boot.default file can leave the BIG-IP unable to reboot. When modifying the boot.default file, it is important that you double-check all syntax and statements for errors or blank lines before saving the file.
