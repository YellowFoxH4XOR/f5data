Description

After deploying a new BIG-IP Next instance using the VMware provider, the BIG-IP Next instance status is stuck at the "Creating..." phase.

Attempting to connect to the API server of the BIG-IP Next instance fails.

Eventually, Central Manager deletes the BIG-IP Next instance with an instance creation error.

Environment

  • BIG-IP Next Central Manager
  • Using the VMware provider to create a new instance
  • You completed the wizard, deployed the instance, confirmed the instance was deployed and the BIG-IP Next virtual machine is running

Cause

When going through the instance create wizard, in the BIG-IP Next Instance Properties screen, you did not fill out the DNS and NTP server settings. You need to scroll down the page in order to see these settings, and they are not required but the BIG-IP Next API server will not come online without them.

Recommended Actions

Use the Create Instance wizard in Central Manager again, but this time ensure that you fill out the DNS and NTP server settings with valid IP addresses.
