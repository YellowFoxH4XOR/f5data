Known Issue

Some pool members may not receive traffic after the pool load balancing algorithm is modified.

This issue occurs when the following condition is met:

  • The load balancing algorithm for a pool is changed to one of the following methods, while one or more pool members are in a disabled state:

    • Least Connections
    • Fastest
    • Least Sessions

Impact

Affected pool members no longer receive traffic until after the BIG-IP system has restarted.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Pool statistics indicate that no requests are sent to the affected pool members.

Workaround

To mitigate this issue, you can verify that pool members are all enabled prior to changing the load balancing algorithm for a pool.
