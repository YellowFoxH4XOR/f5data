K61950942: ASM policy changed to blocking mode after license reactivation

Source

Description

After the BIG-IP is relicensed, ASM policies that were previously in transparent mode are now in blocking mode.  

On /var/log/ltm you see messages about configuration failing to load:

emerg load_config_files[<PID>]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed.
warning mcpd[<PID>]: 01071423:4: High config load failed during a license reset. Fallback to base load.


You may find similar messages in /var/log/asm where process tsconfd deletes ASM policies:

01310053:6: ASMConfig change: Security Policy /Common/<ASM_policy> [delete] { audit: component = tsconfd }

Environment

  • BIG-IP ASM
  • ASM security policy 
  • After license reactivation

Cause

Bug ID 842013

Recommended Actions

Follow workaround of Bug ID 842013
