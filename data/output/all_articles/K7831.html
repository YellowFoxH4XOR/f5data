Known Issue

This is the result of a known issue. If a user accesses a Portal Access Windows File Favorite in a non-English version of FirePass, the Username and Password prompts are not translated correctly on the webtop. This issue occurs after installing cumulative hotfix HF-600-13 for FirePass version 6.0.0, or after installing cumulative hotfix HF-601-2, HF-601-3, or HF-601-4 for FirePass version 6.0.1.

F5 Networks Product Development tracked this issue as CR81392 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.
 

Additionally, cumulative hotfix HF-600-14 has been issued for FirePass version 6.0.0 and cumulative hotfix HF-601-5 has been issued for FirePass version 6.0.1. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
