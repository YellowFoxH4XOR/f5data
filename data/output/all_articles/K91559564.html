Description

  • ASM policy taking indefinite time to load on GUI
  • Management GUI shows sluggish performance
  • restjavad logs are flooded message similar to the following:

    [I][406597][10 Nov 2022 09:22:10 UTC][ApiSettings] Setting default mask for api settings
    [I][406598][10 Nov 2022 09:22:10 UTC][ApiSettings] Setting default mask for log resource settings
    [I][406599][10 Nov 2022 09:22:10 UTC][ApiSettings] Setting default mask for log resource property settings
    [I][406600][10 Nov 2022 09:22:10 UTC][ApiSettings] Setting default mask for api settings
    [I][406601][10 Nov 2022 09:22:10 UTC][ApiSettings] Setting default mask for log resource settings
    [I][406602][10 Nov 2022 09:22:10 UTC][ApiSettings] Setting default mask for log resource property settings

Environment

  • ASM Policies
  • GUI
  • Configuration Utility

Cause

Restjavad got affected and is running in a inconsistent state.

Recommended Actions

Please restart the restjavad process

  1. Connect to CLI
  2. Run

    bigstart restart restjavad
