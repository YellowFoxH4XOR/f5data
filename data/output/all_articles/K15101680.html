Known Issue

iControl produces an HTTP 404 - Not Found error message while creating records successfully.

This issue occurs when the following condition is met:

  • You create a BIG-IP DNS (formerly known as BIG-IP GTM) topology record without using the full path in iControl.

Impact

The resulting code and information is not compatible with the actual result.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • iControl produces and HTTP 404 - Not Found error message while creating the BIG-IP DNS topology record successfully.

Resolution

Status

F5 Product Development has assigned ID 583084 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, use the full path when creating a BIG-IP DNS topology record in iControl.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
