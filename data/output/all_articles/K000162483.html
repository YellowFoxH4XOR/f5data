K000162483: Impact of Microsoft Azure Network Adapter (MANA) rollout on F5 Distributed Cloud: Customer Edge (CE) deployments in Azure

Description

Microsoft Azure is introducing the Microsoft Azure Network Adapter (MANA) across multiple existing and new virtual machine (VM) families. MANA is a next-generation network interface designed to improve performance, latency, and reliability of Azure virtual machines. 

At present, the F5 Distributed Cloud: Customer Edge (CE) software does not support MANA. Support is planned for future releases. In the meantime, customers running Customer Edge (CEs) on Azure can follow recommended configurations to ensure a smooth and reliable networking experience. 

Environment

  • F5® Distributed Cloud
  • Microsoft Azure Network Adapter (MANA)

Cause

As part of Azure infrastructure modernization, Microsoft is gradually enabling MANA on a wide range of VM families, including both existing and newer instance types. For Customer Edge (CE) deployments:

 

  • When placed on MANA-enabled hardware, Customer Edge (CE) cannot leverage the MANA interface.
  • Networking falls back to the legacy NetVSC adapter, with existing drivers in CE continuing to work.
  • This fallback behavior should work seamlessly. 

F5 is currently conducting a comprehensive evaluation to determine whether Customer Edge (CE) nodes deployed on MANA-enabled virtual machines may experience any performance degradation. The findings will be communicated to customers once the assessment is complete and validated. 

 

Answer/Recommended Actions

F5 recommends the following options for customers running F5 Distributed Cloud Customer Edge (CE) in Azure: 

 

Option 1: Use Legacy VM Placement (Recommended – Short Term) 
Apply the LegacyVMNVA tag to your virtual machines or Virtual Machine Scale Sets (VMSS). 

 

  • Prevents placement on MANA-enabled hardware
  • Ensures continued use of supported networking behavior
  • Serves as a temporary mitigation during transition 

For implementation details, refer to Microsoft documentation on MANA opt-out.  

 

Important: The LegacyVMNVA tag must be applied by July 31, 2026. VMs that are created or tagged after this date may be placed on MANA-capable hardware. After May 31, 2027, the tag is ignored and all MANA-eligible VM series will be placed on MANA-capable hardware. 

 

Option 2: Allow Placement on MANA-enabled Hardware 
If the LegacyVMNVA tag is not applied

 

  • VM instances may be placed on MANA-enabled infrastructure
  • Customer Edge (CE) instance will fall back to NetVSC
  • Networking functionality continues but without MANA benefits. 

F5 is currently conducting a comprehensive evaluation to determine whether Customer Edge (CE) deployed on MANA-enabled virtual machines may experience any performance degradation. The findings will be communicated to customers once the assessment is complete and validated.
