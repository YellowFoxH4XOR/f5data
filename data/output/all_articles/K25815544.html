Description

This explains how to change the default favicon icon for APM related VS.

Environment

  • APM
  • Full Webtop 

Cause

At the moment APM VS don't present a favicon to browsers, hence browsers fall back to their default favicon.

Recommended Actions

  1. Go to Local Traffic > iRules > iFile List ==>> upload the new image here
  2. Then create the following iRule in Local Traffic > iRules > iRule List ==> Create

    when CLIENT_ACCEPTED {
        ACCESS::restrict_irule_events disable
    }
    when HTTP_REQUEST {
         if { [HTTP::has_responded] }  { return }
         if { [HTTP::uri] equals "/favicon.ico" }  {
            # replace <favicon_iFile> in below line with the name of the Favicon iFile
            HTTP::respond 200 content [ifile get <favicon_iFile>] "Content-Type" "image/x-icon" }
        }

  3. Apply iRule to VS : Local Traffic > Virtual Servers > Virtual Server List
    • Select VS Resource tab
    • iRule move it in Selected section.
