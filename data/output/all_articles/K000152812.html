Description

The user is unable to download software from MyF5 > Resources > Downloads as the "Select product family" dropdown is greyed out and cannot be selected

Environment

MyF5

Software Downloads

 

Cause

The user has been approved for downloads but their MyF5 role is still "Pending Approval"

 

Recommended Actions

Contact the Admin user to elevate the user's role to "viewer" or above

Contact F5 Support if the account has no Admin user

 

Additional Information

None
