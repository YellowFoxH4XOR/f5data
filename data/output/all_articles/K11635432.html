Issue

Error Message

com.f5.devmgmt.certmgmt.CertMgmtInitializer.initializeTrustDomain(CertMgmtInitializer.java:707): Initial trust configuration created

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions is met:

  • The BIG-IP system is a member of a device trust and is in the process of initializing after a reboot.
  • The BIG-IP system is successfully added to a device trust.

Device trust establishes trust relationships between BIG-IP devices through certificate-based authentication.

Impact

There is no impact. This message is informational.

Recommended Actions

None
