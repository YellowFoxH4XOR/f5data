K000147514: How do I mask the URL that was redirected from HTTP Load Balancer?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-21
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147514

Description

I have 1 domain (one.example.com) and want to redirect it to my second domain (two.example.com) but masking the URL of the second domain so the customer can only see my first domain in the browser.

Environment

  • F5® Distributed Cloud HTTP Load Balancer 

Cause

  • None

Answer/Recommended Actions

To mask the URL:

  1. Create an Origin Pool for the Origin Server two.example.com with TLS enabled. (SNI rewrite option is not required)
  2. Create a HTTP Load Balancer Simple Route with Prefix "/"
  3. In the route refer the Origin Pool as well as specify Host Rewrite Method as Disable Host Rewrite
