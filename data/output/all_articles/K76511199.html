Description
After upgrading or restoring the configuration in the Centralized Manager, CM, seems to no longer be collecting the status of the configuration objects that had been imported earlier.
Also, there are DCDs configured but they are NOT collecting statistics.

Environment

  • CM Upgrade/reconfiguration
  • Configuration Objects.

Cause
If statistics are not being collected for this device, the device status should be retrieved directly from the Big-IP using the Rest API.  This is controlled by the useAppIqDCD setting. 

Recommended Actions

  1. Verify the current configuration
restcurl /cm/adc-core/current-config/stats-refresh
  1. If the entry for useAppIqDcd reads true, then we need to switch it to false
restcurl cm/adc-core/current-config/stats-refresh -X PUT -d '{"isMonitorRunning": true,"useAppIqDcd":false}'
  1. Verify that the change was performed
restcurl /cm/adc-core/current-config/stats-refresh
  1. Wait for 10-15 minutes and check again if the statuses are being collected now.
  2. If the statuses are still not being collected, the restjavad needs to be restarted
bigstart restart restjavad
