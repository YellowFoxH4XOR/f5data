Description

BIGIP SIP MRF dropping 200 OK responses to requests for example INVITE.


Environment

MRF SIP ALG virtual server.

Default settings for SIP MRF router profile.


Cause

The MRF SIP router profile has session timers which control dialogue establishment namely "Transaction Timeout" and "Dialog Establishment Timeout".

If any one of the two expires then dialogue establishment will fail because the BIGIP will terminate the session. "Transaction Timeout" is reset each time a provisional response is received.

Recommended Actions

Ensure callee sends provisional responses within 10 second window to reset the "Transaction Timeout" timer.

If the callee cannot continue to send frequent provisional responses then set "Transaction Timeout" to a value which will avoid dialogue getting prematurely terminated.

The "Transaction Timeout" timer setting is found LTM SIP Message Routing router profile.
