Issue

Error Message

01420006:3: Loading configuration process failed.

Message Location

You may encounter this message in the following location:

  • The TMOS Shell (tmsh) prompt
  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • One or more BIG-IP system configuration objects have been improperly configured or contain syntax errors.

Impact

The affected configuration object will fail to load into the BIG-IP system's running configuration.

Recommended Actions

This error message will be preceded by additional logging information to assist with troubleshooting. In the following example, a custom HTTP monitor object is configured to use quotation marks, but is missing the necessary escape characters:

err mcpd[5678]: 01070642:3: Monitor /Common/example_http parameter contains unescaped " escape with backslash.    
err tmsh[12345]: 01420006:3: Loading configuration process failed.
