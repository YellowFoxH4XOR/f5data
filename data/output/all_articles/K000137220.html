Description

You found some unexpected logs in /var/log/kern.log similar to the following:
info kernel: Program hsb_snapshot tried to access /dev/mem between 2ae8593000->2ae8594000.
debug kernel: mmap_mem: range denied [0x2ae8593, 0x1000 RO] hsb_snapshot

Note that it is expected that the memory ranges are usually different than in the above logs.

You would like to know if there is any negative impact on your system.

Environment

  • BIG-IP
  • /var/log/kern.log file

Cause

These logs are generated every time QKview script is run when it runs the hsb_snapshot utility.

 Recommended Actions

You can safely ignore these logs, they are informative only and have no negative impact on your system.
