Description

LTM provisioning is not required for F5 Analytics iApp.

Environment

  • Big-IP
  • Analytics Consumer such as BIG-IQ or Splunk
  • F5 Analytics iApp

Cause

On the BIG-IP platform memory availability for any particular module or host is a function of total memory and resource provisioning. At times, it may be preferred to yield more memory to either the Host or other modules such as ASM. 

Recommended Actions

If you are not using LTM-specific features on the device you can de-provision LTM by setting LTM to none as described in K17173140: Setting LTM Provision NONE does not disable licensed LTM functionality and still have traffic handling functionality.

Additional Information

Note: Some iApp templates require LTM be provisioned.
