K25471040: BIG-IQ Cannot create Administrative Partition for BIG-IPs

Type
Support Solution
Published
2021-12-09
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 6.0.0, 7.0.X, 6.1.X, 6.1.0, 6.0.X, 6.0.1, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0, 7.1.X, 7.1.0, 7.0.0, 6.X.X, 7.X.X, 8.X.X
Source
https://my.f5.com/manage/s/article/K25471040

Description
BIG-IQ Central Manager cannot create and push Administrative Partitions to a BIG-IP.

  • BIG-IQ can import, modify, and create objects in existing partitions
  • An application deployed to a tenant with the same name as a preexisting partition will remove any preexisting objects and replace them with the application objects

Environment

  • BIG-IQ managing BIG-IP configured with Administrative Partitions

Cause
This is functioning as designed. 

Recommended Actions

To create a new partition on a BIG-IP, configure the partition locally on the BIG-IP and then reimport the configuration to the BIG-IQ. After completion, objects can be created, modified, and deleted in the partition using the BIG-IQ.
