K000163306: F5 Insight software installation job failure due to no inactive volume(s) available

Type
Support Solution
Published
2026-09-11
Updated
2026-09-11
Applies to
  • BIG-IP
  • F5 Insight: 1.2.1
Source
https://my.f5.com/manage/s/article/K000163306

Description

A F5 Insight software installation job can fail with the following error when deploying software to a BIG-IP instance:

no inactive volume available for NEXT_INACTIVE strategy (set createVolume to create one)

The error occurs when the BIG-IP instance selected under the Instances section has only one volume, while the Set Target Volume option for the installation job is set to either First Inactive (Numerically) or Last Inactive (Numerically).

Because the instance has only one volume, no inactive volume is available for the installation.

Environment

  • F5 Insight
  • Software installation job
  • BIG-IP instance (single volume)

Symptoms

The installation job fails during volume planning and reports:

no inactive volume available for NEXT_INACTIVE strategy (set createVolume to create one)

Cause

In the Instances section of the Software Installation Job, Set Target Volume is set to either First Inactive (Numerically) or Last Inactive (Numerically).

Leaving either option selected will cause the installation workflow to fail because the BIG-IP instance has only one volume available. 

Resolution

When configuring the installation job for a BIG-IP instance with a single volume, select Next Sequential (New) under the Instance Set Target Volume option.

Alternatively, with First Inactive (Numerically) selected, manually specify a new volume name by following the procedure below.

  1. Open or create the F5 Insight software installation job.
  2. Under Instances, select the BIG-IP instance.
  3. Locate the Target Volume name field.
  4. Manually enter a target volume name. Do not simply leave the system-selected default value name.
  5. If you want to use the system-selected default volume name, manually enter the same name in the Target Volume field. You will then be prompted to create the volume using that default system-selected name.
  6. After entering the Target Volume name, continue configuring and save the installation job.
  7. Run the installation job again.

Important Information

 Set Target Volume: Options

  • First Inactive (Numerically) — F5 Insight sets the target volume to the first inactive volume in numerical order.
  • Last Inactive (Numerically) — F5 Insight sets the target volume to the last inactive volume in numerical order.
  • Next Sequential (New) — F5 Insight sets the target volume to a new volume based on the existing volumes. For example, if the last install was on HD1.2, F5 Insight targets HD1.3 and creates that volume at execution.

Note: Using First Inactive (Numerically) allows you to rerun the job later with minimal reconfiguration; you only need to update the target version.

For example, the initial job installs Hardened Release 1 on HD1.2, while HD1.1 is the active volume. A few weeks later, rerunning the job with First Inactive (Numerically) selected installs Hardened Release 2 on HD1.1, while HD1.2 is active.

Administrators can rerun the installation job between the same two slots (HD1.1 & HD1.2) on a recurring basis with minimal reconfiguration.
