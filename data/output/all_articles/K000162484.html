K000162484: "Firmware updates are currently in progress" status stuck on r2000 and r4000-series appliances while upgrading from F5OS 1.x to 2.0

Type
Support Solution
Published
2026-09-03
Updated
2026-09-03
Applies to
  • F5OS Products
  • F5OS: 2.0.0
Source
https://my.f5.com/manage/s/article/K000162484

Description

The system displays Firmware upgrade in-progress in the CLI prompt status and web user interface after the firmware upgrade is no longer active. Subsequent firmware updates may be blocked.

Logs (/var/log/messages) may include:

cat: /sys/devices/system/cpu/cpu5/cpufreq/cpuinfo_max_freq: Device or resource busy

echo: write error: Device or resource busy

An intermittent kernel panic and reboot may also occur.

Environment

  • F5 r2000- or r4000-series appliance 
  • Upgrading from F5OS 1.x to F5OS 2.0 for the first time.
  • The issue occurs during a live upgrade involving an NAC firmware upgrade.
  • The firmware upgrade is no longer active, but the upgrade status remains displayed.

Cause

Bug 2297905 causes a kernel panic reboot during the upgrade. The issue is associated with an ice driver kernel core dump, which can cause an intermittent reboot and leave the firmware-upgrade status stuck.

Answer/Recommended Actions

If Firmware upgrade in-progress remains displayed and no firmware upgrade is actively running:

  1. Reboot the system.
  2. Verify that the system services are running and stable.
  3. If the status remains displayed, restart the diag-agent container:
    system diagnostics os-utils docker restart node platform service diag-agent
  4. Confirm that the firmware-upgrade status has cleared before starting another firmware update.
