Topic

F5 supports the PXE installation process on all F5 hardware platforms that are shipped without a CD-ROM drive, or without the ability to interface with a CD-ROM drive. This currently includes the following F5 products:

  • Server appliances (D35 equipment)
  • BIG-IP Blade Controllers
  • BIG-IP switch platforms, including the following:
    • BIG-IP 1000
    • BIG-IP 2000
    • BIG-IP 2400
    • BIG-IP 5000
    • BIG-IP 5100 series
    • BIG-IP 1500
    • BIG-IP 3400
    • BIG-IP 6400
    • BIG-IP 6800
    • BIG-IP 8400
    • BIG-IP 8800

For more information, refer to K2306: Network interfaces cards supported by the F5 PXE network boot server.
