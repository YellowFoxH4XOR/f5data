K000158769: Some rSeries platform do not log message ID 0x5804000000000087 when there is a mismatch in vlan tag between F5OS and tenant

Description

The rSeries r2000 and r4000 will not log the following entry when there is a mismatch in vlan tagging between F5OS ( host ) and the tenant:

2025-12-11T06:37:58.888639+01:00 R5900 api-svc-gateway[13]: priority="Err" version=1.0 msgid=0x5804000000000087 msg="Error occurred while processing listener request" TENANT="tenant1" REASON="bad vlan tag" VALUE="2073".

Environment

  • Mismatch in vlan tag between host and tenant
  • r2000
  • r4000

Cause

This is due to physical and software architectural difference between the two different platform family ( r2000|r4000 versus r5000|r10000|r12000 ).

Recommended Actions

Please ensure that the vlan tagging configuration in the host matches that of the tenant.
