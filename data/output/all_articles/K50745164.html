Topic

The F5 restcurl utility is provided as part of the iControl REST framework distribution on BIG-IP and BIG-IQ systems.

Description

The restcurl utility is written in Java and can be used for both local and remote BIG-IP and BIG-IQ REST transactions. The following is an example of restcurl syntax:

restcurl [-s] [-u username:password] [-X method] <url> [-d data]

Note: If the specified URL is just a path, then http://localhost:8100/ is used.

Common restcurl options 

OptionDescription
-sSend HTTPS request out through HTTP/SSL for HTTPS signing. This does not add authorization to the request, so use this option with the -u option.
-uAdd username and password authorization to request.
-dSpecify payload data to send in the REST request. For example:

restcurl /shared/echo -d '{"content":"Hello, world!"}'

Note: The -d option assumes a POST request. If another request method, such as PUT, is needed, also include the -X option.

-XSend the specified method instead of the default. Valid methods are GET, POST, PUT, DELETE, and PATCH.
-c

Include the X-F5-REST-Coordination-Id header in the request.

For more information, refer to Demystifying iControl REST Part 7 - Understanding Transactions on DevCentral.
