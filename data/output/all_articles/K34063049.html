Issue

Error Message

0107143c:5: Connection to CMI peer <IP address> has been removed

In this error message, note the following:

  • <IP address> is IP address of the remote centralized management infrastructure (CMI) peer.

For example:

0107143c:5: Connection to CMI peer 192.168.10.100 has been removed

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions is met:

  • A remote BIG-IP system was removed from the device trust.
  • Network issues are preventing connectivity between CMI peers over TCP port 4353.
  • A BIG-IP system belonging to a device trust and has been rebooted to a partition where device trust is not configured.

Note: CMI is also referred to as device service clustering (DSC).

Impact

If the remote CMI peer is expected to be part of the local device trust, configuration synchronization or failover will not occur. If the remote CMI peer is not expected to be part of the local device trust, there is no impact other than moderate disk space consumption due to the additional logging messages.

Recommended Actions

  • Ensure that the network allows proper connectivity between the CMI peer systems.
  • For more troubleshooting information, refer to K13946: Troubleshooting ConfigSync and device service clustering issues (11.x - 12.x).
