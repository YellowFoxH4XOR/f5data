Description

After updating Device Certificate on GUI (System ›› Certificate Management : Device Certificate Management : Device Certificate ›› server.crt), GUI is still presenting old certificate.
 

Environment

  • BIG-IP 
  • any version
  • GUI
  • Device Certificate
     

Cause

BIG-IP GUI certificate is cached in the memory, so that it is required to restart httpd.
 

Recommended Actions


Log in to CLI and restart httpd using the command below: 
# tmsh restart /sys service httpd
 
For multi-bladed devices, restart httpd on all blades using the command 
# clsh bigstart restart httpd
 
Note: While restarting httpd, there is no impact for BIG-IP to process traffic, but can not access to GUI.
