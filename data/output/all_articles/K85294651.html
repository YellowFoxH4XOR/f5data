Issue

BIG-IQ 7.0 has incomplete support for BIG-IP 15.0.0 ASM Security Logging options. The presence of the following keywords in the BIG-IP configuration prevents the BIG-IQ from successfully importing the BIG-IP system configuration:

  • microservice
  • vs_name
  • log-challenge-failure-requests

microservices and vs_name are Application Security Storage Format names introduced in BIG-IP 14.1.0.

log-challenge-failure-requests is a Bot Defense logging option introduced in BIG-IP 15.0.0.

Error Messages

When these keywords are present, importation or re-importation of the configuration fails with one of the following errors:

Failed to copy configuration to working-config; reason: Failed copying from source subcollections to target subcollections: java.lang.IllegalArgumentException: Invalid format field value

Failed to copy configuration to working-config; reason: Failed copying from source subcollections to target subcollections: java.lang.IllegalArgumentException: Invalid format field value : vs_name

Failed to copy configuration to working-config; reason: Failed copying from source subcollections to target subcollections: java.lang.IllegalArgumentException: Invalid filter name : log-challenge-failure-requests

Log Challenge Failure Requests are accepted and you can import configurations including this setting in BIG-IQ 7.1.

Recommended Actions

Do not use these keywords if you manage your BIG-IP ASM deployment with the BIG-IQ system.
