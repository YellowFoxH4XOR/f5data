Description
When In-TMM monitoring is enabled, a small portion of monitored resources may be erroneously marked down when they should be Available.

Environment

  • BIG-IP
  • v13.1.0 and later
  • Pool/Node
  • In-TMM monitoring enabled (disabled by default)

Cause
Bug ID 822245

Recommended Actions

Disable in-tmm monitor on CLI run below command:

tmsh modify sys db bigd.tmm value disable

Alternatively, the number of monitored instances can be reduced, however this is typically impractical and is not recommended.
If in-tmm monitor is enabled due to high CPU usage, please refer to: K42421592: High CPU utilization of bigd

Additional Information
See Bug Tracker entry for Bug ID 822245
