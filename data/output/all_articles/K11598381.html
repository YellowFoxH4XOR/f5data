Issue

Error Message

warning tmm[<PID>]: 01010213:4: L3 Address LB method deprecated; using 'Least Connections' for pool <pool_name>

In this error message, note the following:

  • <PID> is the process ID of the tmm process.
  • <pool_name> is the name of the pool that is using L3 Address as a load balancing method.

For example:

warning tmm[4859]: 01010213:4: L3 Address LB method deprecated; using 'Least Connections' for pool example_pool_name

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You attempt to configure a pool to use L3 Address as a load balancing method.

The L3 Address load balancing method, which passes connections sequentially to each member using its Layer 3 (L3) address, is deprecated.

Impact

The BIG-IP system uses the Least Connections (member) load balancing method for the pool instead of the deprecated L3 Address load balancing method.

Recommended Actions

You should configure the pool reported in the error message to use a load balancing method other than L3 Address, such as Least Connections (member). To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Pools > Pool List.
  3. Select the name of the affected pool.
  4. Select the Members tab.
  5. For Load Balancing Method, select another load balancing method to replace L3 Address.
