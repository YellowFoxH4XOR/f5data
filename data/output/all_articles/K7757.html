Known Issue

This is the result of a known issue. When the user launches a Dynamic Application Tunnel or a Web Application Tunnel, FirePass uses the Split Tunneling settings configured for the Default master group instead of the Split Tunneling settings configured for the users master group. Split Tunneling is configured under the Dynamic Tunnels/Web Application Tunnels tab on the Application Access : App Tunnels : Master Group Settings page.

F5 Networks Product Development tracked this issue as CR75717 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.
 

Additionally, cumulative hotfix HF-600-12 has been issued for FirePass version 6.0.0 and cumulative hotfix HF-601-1 has been issued for FirePass version 6.0.1. You may download these hotfixes or later versions of the cumulative hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
