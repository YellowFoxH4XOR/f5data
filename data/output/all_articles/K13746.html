Known Issue

For some leaf nodes, Path matching rules may behave in an unexpected manner, for example, not matching expected paths.

This issue occurs when the following condition is met:

  • You have a Path matching rule that is longer than 940 bytes in length.

When a Path matching rule is longer than 940 bytes, it is ignored and is not matched, and a less specific leaf node is used instead.

Impact

The BIG-IP WebAccelerator system may apply incorrect acceleration rules to responses associated with affected requests.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Affected requests may not match the expected nodes in the policy.

Workaround

To work around this issue, F5 recommends that you limit the length of the Path matching rules to less than 900 bytes, and use multiple nodes if you want to exceed this limit. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the BIG-IP Graphical Configuration Utility.
  2. Click WebAccelerator.
  3. Click Policies.
  4. Under each leaf node, edit the Path component of the Matching rules that exceed 900 bytes by selecting the leaf node and clicking Path under the Name column.
  5. Count the number of characters in the Value(s) section of the node editor.   If the number is greater than 900 bytes, create new leaf nodes, each within the 900 byte boundary, with the remaining paths.
  6. Click Save.
  7. When you are ready for the changes to go into production, publish them.
