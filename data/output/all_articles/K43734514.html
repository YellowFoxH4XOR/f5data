Issue

Error Message

warning lacpd[<PID>]: 01160024:4: warning: no receive on <interface> for <#>s (timeout=<#>s)

In this error message, note the following:

  • <PID> is the process ID for the lacpd process
  • <interface> is the interface on the BIG-IP system
  • <#> is the number of seconds

For example:

warning lacpd[10254]: 01160024:4: warning: no receive on 1.4 for 45s (timeout=90s)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • A trunk on your BIG-IP system is configured to use Link Aggregation Control Protocol (LACP)
  • One of the trunk's member interfaces fails to receive LACP protocol data units for longer than half the timeout period

Impact

This message warns of potential issues with the LACP communication on the trunk.

Recommended Actions

To workaround this issue, you can review the log files for any other related messages at the time of the occurrence. Statistics for the trunk may provide additional details. To view trunk statistics, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To view statistics for the trunk, use the following syntax:

    show /net trunk <name> detail

    For example,

    show /net trunk example_trunk detail
