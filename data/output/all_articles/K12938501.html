Description

The BIG-IP LTM system does not limit the TCP message size of Request Logging Profile.  
Note: The maximum User Datagram Protocol(UDP) message size of Request Logging profile is around 64 kilobytes.  This is defined in RFC 5426. 

  • The BIG-IP LTM system does not send log information to the remote syslog server when User Datagram Protocol(UDP) message size exceeds around 64 kilobytes.

  • Request Logging Profile
