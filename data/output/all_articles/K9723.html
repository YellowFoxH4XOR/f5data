Topic

You can use different type of actions and different types of rules to create a pre-logon sequence policy.

To create a pre-logon sequence, you must perform the following procedures:

Important: This Solution is only to be used for reference; the specific information used will be dependent on your environment.

Important: Do not make changes to your registry unless you have confirmed there will be no negative impact.

  • Locating a key to check in pre-logon sequence
  • Create a pre-logon sequence on FirePass
  • Editing the pre-logon sequence
  • Activating the pre-logon sequence

Locating a key to check in pre-logon sequence

  1. On the computer you will use to connect to the FirePass device, click on the Windows Start tab.
  2. Click Run.
  3. Start a new command shell by typing the following command:
    cmd
  4. To access the Windows registry editor, type the following command:
    regedit
  5. Expand the HKEY_LOCAL_MACHINE > SOFTWARE > field.
  6. Select a key to use in this exercise.

Creating a pre-logon sequence on FirePass

  1. Navigate to the Device Management: Users: Endpoint Security: Pre-Logon Sequence page.
  2. In the Create new sequence field, enter a name for the pre-logon sequence.
    For example:
    myregcheck1
  3. In the Based on drop-down menu, select the template Empty option.
  4. Click Create.

Editing the pre-logon sequence

  1. Navigate to the Device Management: Users: Endpoint Security: Pre-Logon Sequence: Select Sequence to Use section.
  2. Next to the name of the pre-logon sequence you just created, click the Edit link.
  3. Hover your mouse over the line between Sequence Start and Logon Allowed Page.
    A plus sign (+) should appear.
  4. Click on the plus sign.
    FirePass will open a Change Sequence panel on the right side of the browser.
  5. In the Predefined actions section, select Check Registry.
  6. Click Apply Changes.
  7. The Check Registry action now appears in the Pre-Logon Sequence, along with two rules: success and fallback.
  8. Click the Check Registry action.
    An Edit Action panel will open on the right side of your browser.
  9. In the Description field, enter a description for this action.
    For example: 
    Check for EXAMPLE
  10. Click the Update Details button.
  11. Click the Windows registry checker link.
    An Endpoint Inspector details screen will open, displaying two form fields.
    Note: The first field is pre-filled with reg_check****.
  12.  In the Check System registry field, enter your registry key.

    For example:

    "HKEY_LOCAL_MACHINE\SOFTWARE\EXAMPLE"ISPR

    Important    : Ensure that the position of the quotation mark is correct.
  13. Click Update.

    Note: The number after reg_check will be determined by the FirePass device and does not need to be populated.
  14. In the upper right corner, click Back to Console.

Activating the pre-logon sequence

  1. Select the name of the pre-logon sequence you want to activate.
  2. Click Apply.

Note: In order to complete the check successfully, you will need to download the F5 plugins onto the client. You should be prompted for these Active-X controls if they are not installed. Once installed, you will receive the pre-logon page and be prompted to login.
