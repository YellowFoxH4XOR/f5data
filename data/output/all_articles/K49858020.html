Description

When a virtual server is configured with HTTP or HTTP/2 profile along with irule containing 'persist add' command, HA pair experiences a failover with a TMM crash generating a core disrupting traffic. 

Environment

  • A virtual server with HTTP or HTTP/2 profile
  • irule with 'persist add' command attached to virtual server

Cause

Tmm crashes due to BUG 1005489

Recommended Actions

1. Open a case with technical support to get an engineering hotfix.
