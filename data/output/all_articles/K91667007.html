Description

New configuration:  A user in a group in Local Database using Portal Access.
Portal access is showing too many resources for a user in a group in Local Database.
A user in a group in Local Database should only see one portal access resource, but seeing 5 additional portal access resource.
Apm log  /var/log/apm: Error:  Rule evaluation failed with error: missing close-bracket.

Environment

  • Access > Authentication > Local User DB: Users  < A user that belongs to a group> 
  • VPE: Local Database > Branch Rules >  <select Branch Rule>  Change > Advanced.
  • APM: Portal Access

Cause

Syntax of expression is incorrect. 
expr { [mcget {session.localdb.groups] } contains "engineer" }   // Closing curly brace is NOT in the correct place.

Recommended Actions

Correct the syntax expression. 
expr { [mcget {session.localdb.groups}] contains "engineer" }   // Closing curly brace is now in the right place.
