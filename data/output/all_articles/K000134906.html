Description

After upgrading from BIG-IP 14.x to 16.x for example from 14.2.4 to 16.1.3.4, you may receive the configuration change alert for all SNMPv3 user account auth-password-encrypted and privacy-password-encrypted properties similar to the following:

01420013:4: [api-status-warning] sys/snmp, properties : deprecated : traps/auth-password-encrypted, traps/privacy-password-encrypted, users/auth-password-encrypted, users/privacy-password-encrypted

Environment

  • BIG-IP LTM
  • SNMPv3

Cause

The deprecated properties warning is caused by the fix for bug ID 532181. This fix added the new properties auth-password and privacy-password to sys snmp users which are encrypted by the BIG-IP master key. The auth-password-encrypted and privacy-password-encrypted properties have been deprecated but are displayed for backwards compatibility. You'll observe the error message when you save the configuration; therefore, if you have automated configuration saves, the messages will appear repeatedly in the logs.

Bug ID 532181: SNMP passphrases appear to change each time they are displayed in TMSH

Recommended Actions

To stop receiving this configuration warning, try the following:

  1. Log into the active BIG-IP command line.
  2. Set api-status log resource-property deprecatedApiAllowed to false using the following command:

    tmsh modify mgmt shared settings api-status log resource-property deprecatedApiAllowed false

  3. Set api-status log resource deprecatedApiAllowed to false using the following command:

    tmsh modify mgmt shared settings api-status log resource deprecatedApiAllowed false

  4. Save the configuration by entering the following command:

    tmsh save /sys config

  5. Configsync from the active to the standby unit.

Note: deprecatedApiAllowed is set to true by default.
