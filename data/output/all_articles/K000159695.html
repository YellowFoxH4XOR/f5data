K000159695: APM: Error in processing URL /.well-known/openid-configuration

Type
Support Solution
Published
2026-01-24
Updated
2026-01-24
Source

Description

BIG-IP APM administrator may get the below error in UI "Access  ››  Federation : OAuth Client / Resource Server : Provider  ››  New":

An error occurred:
Error in processing URL https://<hostname>/.well-known/openid-configuration. The message is - java.net.UnknownHostException: <hostname>

Environment

  • APM

  • oAuth Provider

Cause

oAuth Provider hostname entry can't be resolved.

Answer/Recommended Actions

To make sure that DNS server defined in 'System  ››  Configuration : Device : DNS' is able to resolve the oAuth Provider's hostname entry.
