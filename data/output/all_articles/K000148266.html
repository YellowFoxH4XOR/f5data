Description

Does a virtual server destination address need to be in the same subnet as the pool members?

 

Environment

BIG-IP

 

Cause

-You are attempting to configure a virtual server address

-You need to make a change to the virtual server address, or add/change pool members.

-You are troubleshooting an issue with a virtual server/pool member and want to verify the networking configuration.

 

Recommended Actions

The virtual server address does not need to be in the same subnet as the associated pool members. The virtual IP which represents the virtual server in a configuration listens for the traffic which then load balances traffic through destination address translation. As the VIP does not represent a physical device, it does not need to be routable to the subnet containing the pool members, and can distribute traffic according to your configuration regardless of what subnet they are in.

 

To ensure that a pool members response returns through the BIG-IP, you can either configure the default route on the server to be a self IP address on an internal VLAN, or you can configure SNAT and assign it to the virtual server. For more details about configuring virtual servers, pool members, or SNAT (Source Network Address Translation), see the documentation below.
