K10503: Obsolete configuration parameters are contained in the pvsystem.conf file

Known Issue

This is the result of a known issue. Obsolete parameters exist in the pvsystem.conf file. Due to changes in the BIG-IP WebAccelerator architecture, the following unused settings exist in the /config/wa/pvsystem.conf file:

  • httpOwsPort
  • httpsOwsPort
  • owsReconnectTimeout
  • httpListenBacklog
  • maxPendingRequests
  • maxPendingProxies
  • keepAliveTimeout
  • maxKeepAliveRequests
  • maxTransactionTTL
  • idleConnScrubberSleepTime
  • hardwareAcceleratorId
  • enableOwsConnectionPoolScrubbing
  • owsConnectionPoolScrubInterval
  • owsConnectionPoolMaxSize

F5 Product Development tracked this issue as ID 210818 (formerly CR126706), and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
