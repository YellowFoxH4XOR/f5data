K000092738: [AWS] Intermittent backup issue as part of default automation

Published
2023-01-11
Updated
2023-01-11
Source

Description

[AWS] Automated UCS backup might fail intermittently

 

The following errors are seen in /var/log/cloud/aws/autoscale.log

2022-10-05T22:33:20.180Z verbose: [pid: 13673] [lib/util.js] tryUntil error: tries left: 0 

2022-10-05T22:33:20.180Z silly: [pid: 13673] [lib/util.js] tryUntil: retryOrReject: numRemaining: 0 , code: undefined , message: 

2022-10-05T22:33:20.180Z verbose: [pid: 13673] [lib/util.js] Max tries reached. 

2022-10-05T22:33:20.187Z info: [pid: 13673] [lib/util.js] Autoscale finished. 

2022-10-05T22:33:20.186Z error: [pid: 13673] [scripts/autoscale.js] autoscaling error: tryUntil: max tries reached: unknown 

Environment

AWS Autoscale automated backups.

Cause

The default timeout of 120 seconds might not be sufficient for UCS save operation to complete.

Recommended Actions

Please edit the file /config/cloud/aws/node_modules/@f5devcentral/f5-cloud-libs/lib/bigIp.js

The following line in saveUcs function needs to be modified

 

From:

{
    maxRetries: 60,
    retryIntervalMs: 2000
},

 

To:

{
    maxRetries: 90,
    retryIntervalMs: 2000
},

Additional Information

None
