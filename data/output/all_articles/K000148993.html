K000148993: How to obtain the number of unique visitors for a specific virtual server

Type
Support Solution
Published
2024-12-16
Updated
2024-12-16
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000148993

Description

You want to obtain the number of unique visitors accessing a specific virtual server based on the client IP address.

Environment

  • BIG-IP
  • AVR module provisioned
  • Virtual server

Cause

None.

Recommended Actions

Note: The AVR module (Application Visibility and Reporting) has to be licensed and provisioned on the BIG-IP.

 

Both TCP and HTTP analytics profiles provide an option to collect client/remote IP addresses. Please note that you need to create a custom TCP/HTTP analytics profile since default profiles do not gather this information.

 

Using the Configuration utility to configure a custom HTTP analytics profile

 

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Analytics > HTTP Analytics.
  3. Click Create.
  4. Type a name for the profile.
  5. Associate virtual server with this HTTP analytics profile (this can be also done from the virtual server level).
  6. Under Collected Entities select Client IP Addresses.
  7. Click Finished.

The HTTP statistics can be viewed by going to Statistics > Analytics > HTTP > Overview. Then select the time range and the specific virtual server for which you want to view the statistics. The number of the unique IP client IP addresses will be visible on the right side panel named Client IP Addresses. 

 

Using the Configuration utility to configure a custom TCP analytics profile

 

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Analytics > TCP Analytics.
  3. Click Create.
  4. Type a name for the profile.
  5. Associate virtual server with this HTTP analytics profile (this can be also done from the virtual server level).
  6. Under Collected Entities select Remote Host IP Address.
  7. Click Finished.

The TCP statistics can be viewed by going to Statistics > Analytics > TCP. Next, select the time range and Virtual Server from the View By drop down list. And then, again from the View By list select Remote Host IP address. The number of the unique IP client IP addresses will be visible on the bottom right corner as Total Entries.
