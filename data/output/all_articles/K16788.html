Known Issue

BIG-IP PEM may produce a benign error message with the Secure Sockets Layer (SSL) connection flow classification.

This issue occurs when all of the following conditions are met:

  • The affected BIG-IP PEM profile configuration has the Connection Optimization setting enabled.

    Note: The PEM Connection Optimization setting is enabled by default.
  • The BIG-IP PEM system classifies the incoming SSL connection for a Layer 7 (L7) application.
  • An L7 policy (CPM) handles the affected SSL connection after the PEM classification.

Impact

There is no impact; the specific error message is benign and should not impact the configured functionality.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The affected SSL connection flows that were originally classified and optimized by the BIG-IP PEM profile, are later processed by an L7 policy matching (CPM) Common name, but the classification module is already deactivated.
  • The configuration functions as expected; however, error messages appear in the /var/log/ltm log file that are similar to the following example:

    016e0002:3: Execution of action 'pem classify application=/Common/ssl application_id=199 ssl-session-id' failed, error ERR_NOT_FOUND

Workaround

To work around this issue, you can prevent the error message from occurring by disabling the Connection Optimization setting in the BIG-IP PEM profile. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Policy Enforcement > Profiles > Policy Enforcement.
  3. Select the name of the affected BIG-IP PEM profile.
  4. In the Optimization section, in order to access the Connection Optimization setting, select the check box.
  5. Change the Connection Optimization setting to Disabled.
  6. Click Update.
