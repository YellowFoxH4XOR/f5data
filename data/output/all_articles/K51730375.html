K51730375: Client session interrupted with ''http_process_state_prepend - Invalid action''

Type
Support Solution
Published
2025-07-01
Updated
2025-07-01
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K51730375

Description
APM client connection gets terminated with message logged in /var/log/ltm:

   ... http_process_state_prepend - Invalid action:0x10a041 clientside (10.10.10.12:54007 -> 110.10.30.3:443) serverside (127.0.0.1:10001 -> 10.10.10.12:51186) (Client side: vip=/Common/my_virtual_server profile=http pool=_tmm_firepass_apd_pool client_ip=10.10.10.12)

Environment

  • BIG-IP
  • APM
  • iRule applied to Virtual Server with both "ACCESS::session remove" and "HTTP::close" in the same event:
       when HTTP_RESPONSE {
           if {$delete_apm_session} {
              ACCESS::session remove
           }
           HTTP::close
      }

Cause
Unknown

Recommended Actions

Use two events:

    when HTTP_RESPONSE {
        HTTP::close
    }
   when HTTP_RESPONSE_RELEASE {
       if {$delete_apm_session} {
          ACCESS::session remove
       }
    }
