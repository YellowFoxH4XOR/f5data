Known Issue

The BIG-IP system may send Internet Control Message Protocol (ICMP) TTL Exceeded messages with the incorrect source address.

This issue occurs when all of the following conditions are met:

  • Network diagnostic utilities that use ICMP error messages (such as the traceroute utility) are used to test network connectivity from a client to a destination IP address.
  • A return route for the client IP address does not exist on the BIG-IP system.

Impact

Traffic performance is not affected. However, network diagnostic utility outputs (such as traceroute outputs) may be misleading.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using the traceroute utility through a BIG-IP system, the utility fails to display the BIG-IP self IP address for the BIG-IP hop instead of the destination IP address.
