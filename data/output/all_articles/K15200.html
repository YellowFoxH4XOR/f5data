Known Issue

The BIG-IP APM system may not alert for Document Object Model (DOM) security exceptions.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access with JavaScript patching enabled.
  • The web application uses browser-based scripts to access the document objects across windows in violation of the Same Origin policy (SOP).

The DOM provides browser-based scripts access to document objects. Accessing certain information from a document in a different domain across windows violates the SOP. Beginning in BIG-IP APM 11.4.0, when the user attempts this type of access using portal access, the system displays a Permission denied message.

Impact

Cross-window script functionality is impaired without warning.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Portions of the web application fail to load in the page.
  • The BIG-IP APM system rewrites links incorrectly.
  • The web application logic breaks when accessed through the BIG-IP APM system.
