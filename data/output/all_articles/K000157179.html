K000157179: Who Needs to Take Action when F5 Distributed Cloud(XC) Sends Notification of IP Range Updates?

Type
Support Solution
Published
2025-10-28
Updated
2025-10-28
Applies to
  • F5 Distributed Cloud Services
Source
https://my.f5.com/manage/s/article/K000157179

Description

  • F5 Distributed Cloud (XC) periodically sends notifications to customers regarding updates to the public IP ranges used by its infrastructure
  • These notifications are intended to inform customers who may need to update their firewall or allow-list configurations to ensure continued service availability

Environment

  • F5 Distributed Cloud (XC)

Cause

None

Answer/Recommended Actions

Typical scenarios where action may or may not be required:

  • In most routed DDoS (BGP/GRE) deployments, no action is needed because traffic is scrubbed and forwarded without relying on Regional Edge (RE) egress IPs to reach your origin Most customers do not whitelist F5 RE source ranges for routed DDoS
  • If you have custom policies that explicitly permit F5 scrubbing-center egress IPs to your origin, you should confirm with Support whether updates are required
  • Customer Edge (CE)-only deployments, where origins are reached from your own CE addresses, generally do not require action
  • If you are unsure whether your deployment uses RE egress to reach your origins, check your origin firewall rules for “F5 Distributed Cloud” allowlists or contact Support to review your configuration

Action is required if you use any RE-based services that initiate connections to your origin from F5 infrastructure, including:

  • HTTP(S) Load Balancer, TCP/UDP Load Balancer
  • Web Application Firewall (WAF), Bot Defense, API Security
  • CDN/cache and origin health checks run from RE
  • Any workflow where your origin firewall/ACLs explicitly allow only F5 Distributed Cloud source IPs

To determine if you need to update your allow-lists:

  • Review your origin firewall rules for any “F5 Distributed Cloud” allowlists
  • If you use HTTP(S) Load Balancer, TCP/UDP Load Balancer, WAF, Bot Defense, API Security, CDN/cache, or origin health checks from RE, update your allowlists to include the new F5 Distributed Cloud IP ranges
  • For the latest F5 Distributed Cloud public IP ranges, refer to the official documentation: Firewall or Proxy Reference for Network Cloud
  • If you are unsure, contact F5 Support for a configuration review

Additional Information

  • The official F5 Distributed Cloud documentation provides up-to-date public IP ranges and their intended regions: Firewall or Proxy Reference for Network Cloud.
