K75575413: Sophos anti virus is not detected by BIG-IP edge client

Type
Support Solution
Published
2022-08-01
Updated
2023-02-21
Applies to
  • Virtual Editions
  • VIPRION Platforms
  • Public Cloud
  • BIG-IP
  • BIG-IP Platforms
  • Private Cloud
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K75575413

Description

Client is failing to authenticate/connect. 

Error noticed on CTU logs:

"errors1": "Failed to get 'db_time'. code: -4 (Invalid state) mId: 3 iId: 9\nFailed to get 'last_scan'. code: -6 (Object not found) mId: 12 iId: 9\nFailed to get 'db_signature'. code: -2 (Not implemented) mId: 2 iId: 9\n",

"errors2": "Failed to get 'state'. code: -4 (Invalid state) mId: 5 iId: 9\nFailed to get 'last_scan'. code: -32 (Access denied) mId: 12 iId: 9\nFailed to get 'db_signature'. code: -2 (Not implemented) mId: 2 iId: 9\n"


Environment

  • BIG-IP APM
  • Windows 10 or 11
  • BIG-IP Edge Client
  • EPSEC (End point security) 

Cause

Sophos antivirus version 2022.1.1.3 and the running EPSEC version 1156 build were not compatible, which makes BIG-IP Edge Client unable to detect the Sophos antivirus details.
 

Recommended Actions

  1. Open case with F5 and request an upgrade to EPSEC build 1268 or greater.

Additional Information
None.
