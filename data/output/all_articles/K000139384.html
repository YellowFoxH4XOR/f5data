Description

You may observe TLS handshake failures and upon further investigation see that you received Illegal parameter alerts. 

During a TLS negotiation BIG-IP does not include the max_fragment_length TLS extension in the  SERVER_HELLO portion of the conversation, which may cause issues for certain client software.

Environment

  • BIG-IP
  • TLS
  • TLS HANDSHAKE

Cause

Caused by defect ID1505753

Whilst BIG-IP does honour a client request for a particular size of max_fragment_length, it does not confirm that it is doing so, which it should as part of the SERVER_HELLO portion of the negotiation.

Recommended Actions

​​​​​​​There is no workaround, please request an engineering hotfix from F5 Technical Support.
