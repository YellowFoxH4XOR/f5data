Description

Can we disable pool member only on specific Wide IP?

Environment

  • BIG-IP DNS
  • Wide IP
  • Ability to control Pool member status

Cause
None

Recommended Actions

It is not possible to disable pool members on Wide IP, you will need to disable it on pool level.
This will affect other Wide IP, so we recommend to make separate pool for each Wide IP.
