K000152686: rSeries Device not Discoverable on SNMP Manager

Type
Support Solution
Published
2025-07-23
Updated
2025-07-29
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000152686

Description

While performing a SNMP Discovery for the rSeries Host on ServiceNow, received error " Active, Couldn't verify".

Environment

  • F5-BIG-AWF-R5600, C129
  • SNMP Discovery
  • ServiceNow (SNMP Manager)

Cause

MIB Files from the rSeries device are not loaded into ServiceNow

F5OS on rSeries uses specific MIBs (both standard and F5-specific). If ServiceNow does not have these MIBs, it may not be able to classify the device correctly.

Recommended Actions

Download the MIBs from the rSeries appliance:

  • WebUI: System Settings > File Utility >select the "mibs" directory and download both NetSNMP and F5OS MIBs.
  • CLI/API: Use the file export command or API as described in the documentation.
