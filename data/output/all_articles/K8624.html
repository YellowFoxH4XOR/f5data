Known Issue

This is the result of a known issue. If you navigate to the Users: Groups: Master Groups page and click the Local link in the Users column for a particular master group, FirePass displays all local user accounts instead of the local user accounts that belong to the master group.

Note: For FIrePass version 6.0.2, this issue only occurs if you installed Cumulative Hotfix HF-602-1, HF-602-2, or HF-602-3 on the FirePass controller. For FIrePass version 6.0.1, this issue only occurs if you installed Cumulative Hotfix HF-601-9 or HF-601-10 on the FirePass controller.

F5 Networks Product Development tracked this issue as CR94052 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative hotfix HF-601-11 has been issued for FirePass version 6.0.1 and cumulative hotfix HF-602-4 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
