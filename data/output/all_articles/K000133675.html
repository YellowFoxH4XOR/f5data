K000133675: Lease pools from the Access Policy are not synced

Type
Support Solution
Published
2023-05-17
Updated
2023-05-17
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.3
Source
https://my.f5.com/manage/s/article/K000133675

Description

Lease address pools assigned by a Variable Assign agent in the policy are not synced to the HA pair (Sync-Only).

 

Normal Configuration:

Access Policy >> Network Access >> Lease IPv4 Pool

 

Not synced Configuration:

Access Policy >> Variable Assign agent (Network Access & Lease Pool binding)

 

For example, there are more Lease Address Pools on the BIGIP A where the configuration was made, but there are less Lease Address Pools on the pair device BIGIP B.

 

BIGIP A:

Network Access: 20

Lease Pool: 35

 

BIGIP B:

Network Access: 20

Lease Pool: 14

 

 

 

Environment

BIGIP APM 15.x or above

Variable Assign agent with Network Access and Lease Address Pools assignment.

 

Cause

Only the Lease Address Pools assigned to a Network Address resource itself there will be synchronized.

 

Recommended Actions

You can choose one of these options:

 

  • If exists a BIG-IQ in your environment, it is possible to pin certain object to the specific device, it does not matter the sync status itself.
  • Avoid to use this kind of configuration.
