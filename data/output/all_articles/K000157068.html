K000157068: Unable to Select Pool When Creating or Modifying LTM Policy Rules After Upgrading to BIG-IP 17.1.3 or 17.5.1.x

Type
Support Solution
Published
2025-10-20
Updated
2026-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3, 17.5.1
Source
https://my.f5.com/manage/s/article/K000157068

Description

After upgrading to BIG-IP LTM version 17.1.3 or 17.5.1,x you are unable to create or modify LTM policy rules using the "Forward traffic to Pool" action because the pool selection dropdown in the GUI was greyed out and unresponsive.

Environment

  • BIG-IP LTM version 17.1.3 or 17.5.1.x
  • LTM policies configured to use "Forward traffic to Pool" actions

Cause

Bug ID 2078797

Recommended Actions

  • Use TMSH (CLI) to create or modify LTM policy rules as a temporary workaround.
  • Bug ID 2078797 is fixed in versions 17.1.3.1,, 17.5.1.4 and 21.0.0.

Additional Information

None
