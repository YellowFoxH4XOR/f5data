Source

Description

The License Usage page on BIG-IQ Central Manager (CM) was not displaying license statistics for specific APM devices, while other APM devices reported correctly. The affected devices did not show expected license usage data, and BIG-IQ logs showed repeated HTTP 502/503 errors when attempting to collect APM license statistics from these devices.

 

restjavad.log from BIG-IQ:

BIG-IQ reporting REACTIVATE LICENSE:Standalone in prompt

BIG-IQ license was not reactivated before upgrade

 

 

 

Environment

  • BIG-IQ Cluster
  • Managed APM devices
  • No APM License usage information

 

Cause

Undetermined. The most possible scenario is BIG-IQ license was not reactivated before upgrade which result in REACTIVATE LICENSE:Standalone state. In this state system shouldn't work but it does at least for some tasks.

 

Answer/Recommended Actions

  • Reactivate license on BIG-IQ
  • restart restjavad service: bigstart restart restjavad
