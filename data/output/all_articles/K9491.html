Topic

TCP/IP fingerprinting is a method of determining the target host operating system (OS) of a target host by capturing network traffic from the host, and comparing the traffic to a database of TCP signatures. This behavior allows the fingerprinting software to distinguish between different implementations of TCP/IP, and attempt to determine the host OS of the target system.

Description

The two types of TCP/IP fingerprinting are passive and active monitoring:

  • Passive fingerprinting

    Passive fingerprinting is a method by which the fingerprinter captures traffic from the target system without generating traffic to the system. The fingerprinter uses the response traffic to determine the operating system of the targeted host.

  • Active fingerprinting

    Active fingerprinting is a method by which the fingerprinter sends TCP/IP probes to known ports on the target system. The fingerprinter then examines the response in order to classify the traffic.

Starting in version 9.0, the BIG-IP Traffic Management Operating System (TMOS) operating system implements a full proxy architecture for virtual servers configured with a TCP profile. A full proxy architecture allows the BIG-IP LTM to act as a TCP peer to both the client and the server by associating two independent TCP connections with the end-to-end session.

A BIG-IP virtual server using a TCP profile maintains its own TCP connection behavior to both the client and server sides of the session. Therefore, the fingerprinting tool may report the target host OS to be a BIG-IP system.

Note: Virtual servers that operate on a packet-by-packet level, such as those using the FastL4 profile, do not operate in full proxy mode. Therefore, the fingerprinter software receives the actual fingerprint from the origin server's OS.

While it may be possible to attempt to obfuscate the BIG-IP TCP fingerprint by changing the default TCP profile values, F5 does not recommend this practice for the following reasons:

  • The default protocol profile settings are optimized for most uses and should only be changed based on performance needs.
  • TCP/IP fingerprinting signature files can be updated to detect subtle changes made to BIG-IP profile settings.
