Description

Configuring the outbound-smtp mailhub option on the BIG-IP, and getting an error similar to the following:

530 5.7.1 Client was not authenticated

Environment

  • Outbound-smtp mailhub configured

Cause

Configuration parameters missing in /etc/ssmtp/ssmtp.conf file when SMTP mail host is using SSL authentication.

Recommended Actions

If the SMTP mail host supports Secure Sockets Layer (SSL)/TLS authentication, you must add the following four additional parameters into the /etc/ssmtp/ssmtp.conf configuration file:

UseSTARTTLS=yes
UseTLS=yes
AuthUser=<SMTP-Account-Username>
AuthPass=<SMTP-Account-Password>

For more details on this configuration, see:

K13180: Configuring the BIG-IP system to deliver locally generated email messages (11.x - 15.x)

Additional Information

The error can also be similar to: 554 5.7.1 Authentication required. 

Error 530 and error 554 are both SMTP protocol related errors. For more details see: https://serversmtp.com/smtp-error/
