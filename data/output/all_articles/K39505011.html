Description
Large Receive Offload (LRO) functionality is enabled by default on VMXNET2 (Enhanced) and VMXNET3 devices. In some scenarios, Linux TCP/IP stack has a low performance when handling LRO-generated packets. As a result, having LRO enabled for these devices in a virtual machine running a Linux guest operating system can cause poor TCP performance.

Some features like LRO and other third-party technologies effect acceleration of TCP traffic by coalescing TCP segments, IP packets, Ethernet frames, and NIC interrupts; each of these imparts delays inherent in their design and operation. In some scenarios, a combination of these technologies may combine/amplify delays and trigger normal TCP behavior that reduces TCP performance. In those cases, disabling LRO, the other feature(s), or both/all of them is the only option to eliminate the poor TCP performance.

Environment

  • BIG-IP Virtual Edition
  • VMware ESXi host using VMNET3 network drivers
  • Guest OS running Linux kernel 2.6.24 or later
    • BIG-IP 11.5 and after (K3645: Base operating system information for the BIG-IP host system)
  • Poor TCP Performance

Cause
LRO or Generic Receive Offloading (GRO) enabled

Recommended Actions

Turning off LRO or GRO
Although there are a number of ways to turn off LRO, the most reliable way is to connect to the virtual machine and use the ethtool utility.

  1. SSH to log into the Advanced Shell.
  2. Run the following commands, replacing <VLAN> in each of the examples with the VLAN associated with the interface.
    Note: On a BIG-IP system, the interface name will be the name of the VLAN you have configured.
    Note: The following examples make changes to VLAN external. You will change this to the name of your VLAN.
    • Turn Off rx-checksumming:
      ethtool -K <VLAN> rx off

      For Example:
      [root@BIG-IP-1:Active:Standalone] config # ethtool -K external rx off
      Actual changes:
      rx-checksumming: off
      tx-checksumming: off
      tx-checksum-ip-generic: off [requested on]
      udp-fragmentation-offload: off [requested on]
      Note: tx-checksumming, tx-checksum-ip-generic and udp-fragmentation-offload are modified as a result of how the linux ethtool "other features" operates.
       
    • Turn off LRO using the following syntax:
      ethtool -K <VLAN> lro off

      For Example:
      ethtool -K external lro off
       
    • Turn off GRO using the following syntax:
      ethtool -K <VLAN> gro off

      For Example:
      ethtool -K external gro off

    Note: It is expected behavior for other features to be disabled when running this command.
     
  3. Verify the applied settings using the following syntax:
ethtool -k <VLAN>

For Example:

ethtool -k external
 

The following are the expected values:
</snip>
rx-checksumming: off
generic-receive-offload: off
large-receive-offload: off
</snip>

 

Additional Information

  • Disabling LRO in the Guest Operating System is a best practice per VMware:
    • Poor TCP performance might occur in Linux virtual machines with LRO enabled (1027511)
