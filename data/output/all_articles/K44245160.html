Description
In order to use WMI monitoring the file F5.IsHandler.dll needs to be downloaded. This file will be installed in Windows IIS servers to be monitored. 

Environment

  • BIG-IP LTM
  • Windows Server IIS

Cause
None.

Recommended Actions

Downloading F5.IsHandler.dll plug-in file using the Configuration utility:

  1. Log in to the Configuration utility.
  2. Click About.
  3. Under Plug-ins, click Microsoft® Windows Server® 2008/Microsoft® Internet Information Services (IIS) 7.0 Handler or Microsoft Server 2008/IIS 7.0 Handler.
  4. Click Save.
  5. Select a location on your local system to save the file.
  6. Click Save.
