Known Issue

This is the result of a known issue. EUD versions 12.6 and later fail to install on BIG-IP 3600, 3900, 6900, and 8900 systems formatted with the partitions disk-formatting scheme. This issue occurs because EUD versions 12.6 and later are too large to fit on the boot partition of BIG-IP 3600, 3900, 6900, and 8900 systems formatted with the partitions disk-formatting scheme.

As a result, the installation fails and the system returns an error message that appears similar to the following example:

error: copy /mnt/tm_install/9023.a9Lfnl/sOx4bxP46j/shared/mfg/eud/EUD_M-initrd.386 failed; No space left on device

In addition, if the BIG-IP system is running version 10.1.0 or later, the following error message is also returned:

error: Disk full (boot partition). See SOL#10636

However, do not refer to SOL10636 as suggested by this error message. None of the workarounds included in SOL10636 allow you to install EUD version 12.6 or later on a BIG-IP 3600, 3900, 6900, or 8900 system formatted with the partitions disk-formatting scheme.

When this issue occurs:

  • The previous EUD version is removed from the system.
  • Because the new EUD version fails to install, no EUD entry will be available in the GRUB menu.
  • Subsequent installations of BIG-IP version 10.x may fail and return a Disk full error message indicating that the boot partition is full. You should be able to work around this issue and continue with the installation by performing the Removing the EUD workaround described in K10636: Upgrading to BIG-IP version 10.1.0 fails with a 'Disk full' error message. This procedure will remove any files left in the boot partition by the EUD version 12.6 or later installation process.

F5 Products Development is tracking this issue as ID 210044 (formerly CR125308).

Workaround

If you require running the EUD on a BIG-IP 3600, 3900, 6900, or 8900 system that includes an older version of the EUD or no EUD at all, you can run EUD version 12.6 or later from a USB CD-ROM drive or a USB mass storage device.

Note: For more information, refer to the EUD release notes.
