Known Issue

This is the result of a known issue. BIG-IP GTM returns an incorrect status for BIG-IP LTM virtual servers when the BIG-IP LTM virtual server transitions to a new state. For example, if the status of the BIG-IP LTM virtual server changes from available to offline, BIG-IP GTM may not update its status for the virtual server. When this issue occurs, BIG-IP GTM will continue to resolve requests for the virtual server.

F5 Product Development tracked this issue as CR64514, CR64515, and CR68157 and it was fixed in BIG-IP GTM 9.2.4, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP GTM release notes.
