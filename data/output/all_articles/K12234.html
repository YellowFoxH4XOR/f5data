Known Issue

This is the result of a known issue. Handheld device users accessing a Portal Access Web Application that uses a sed script to process the content may be unable to view the application correctly. The sed script may not run correctly when accessed with mobile devices, such as iPhone and Microsoft Windows Mobile devices.

F5 Product Development is tracking this issue as ID 341353.

This issue has been fixed in cumulative hotfix HF-610-5 issued for FirePass version 6.1.0, and in cumulative hotfix HF-70-2 issued for FirePass version 7.0.0.

You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
