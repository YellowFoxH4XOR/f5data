Description

  • Device certificate update broke the connection between DNS and LTM.
  • Running this command shows devices "Disconnected" state: 
    • tmsh show gtm iquery
  • Running bigip_add on DNS to fix this situation is throwing the following error:
    • Unrecognized argument "username@company.com@ltm_self_ip_address"
  • Login account being used is a remotely authenticated account of this format: "username@company.com"
  • Command format being used is this: "bigip_add -a username@company.com@ltm_self_ip_address"

Environment

  • BIG-IP GTM and DNS devices disconnected
  • Device certificate update.
  • Running bigip_add command on DNS is failing with error "Unrecognized argument"
  • Using a remote login account with "@" symbol for the bigip_add command.

Cause

Using the remotely authenticated account with an "@" symbol seems to be a problem.

Recommended Actions

  • Use the BIG-IP LTM local root account for bigip_add command.
  • If it is disabled, temporarily enable it and rerun the bigip_add command with root and then disable it afterwards. 
    • bigip_add root@<existing_DNS_or_LTM_IP_address>
  • Follow the instructions for bigip_add in this document: Overview of the BIG-IP DNS big3d_install, bigip_add, and gtm_add utilities (11.x - 17.x)
