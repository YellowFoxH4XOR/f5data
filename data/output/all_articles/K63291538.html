Known Issue

The BIG-IP system may not honor the liveinstall.moveconfig system database variable during software installation.

This issue occurs when all of the following conditions are met:

  • The liveinstall.saveconfig database variable is set to enable.
  • The liveinstall.moveconfig database variable is set to disable.
  • You are performing an upgrade of the inactive target slot with pre-existing BIG-IP configuration residing on it.
  • The desired BIG-IP software version is newer than the target slot, but older than the active slot.
  • The target slot has a valid configuration to roll forward.

When the liveinstall.saveconfig and liveinstall.moveconfig database variables are both set to enable, the configuration of the currently active software slot will install on the target slot. This is the default behavior. When the liveinstall.saveconfig database variable is set to enable and the liveinstall.moveconfig database variable is set to disable, the configuration of the target software slot (if any is present) will reinstall on the target slot after installation is complete. This option fails for the affected versions. This behavior is not to be confused with downgrading BIG-IP software. For information about downgrading BIG-IP software, refer to K14568: Downgrading BIG-IP software (10.x - 11.x).

Impact

The BIG-IP system will not roll forward the configuration and any pre-existing BIG-IP configurations residing on the target slot during the software installation process will be removed.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you boot into the target slot, you notice that the BIG-IP resets to the default configuration.
