K000148858: AWAF Guided Configuration only accessible by users with Administrator role

Support Solution
Published
2026-11-03
Updated

  • BIG-IP ASM: 17.1.X, 17.5.X, 17.5.1, 17.5.0, 17.1.3, 17.1.2, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000148858

Description

Big-IP ASM / Advanced WAF includes an easy to use, step by step, policy creation option called "Guided Configuration", abbreviated with GC, in the Web Configuration Utility. This is available by navigating to "Security >> Guided Configuration".

Users assigned to a role other than "Administrator", for example "Resource Administrator", will see an ever circling icon indicating "Initializing . . ." but the GC page will not appear and the page is stuck at initializing.

Environment

  • Big-IP ASM / Advanced WAF
  • Guided Configuration version 10.0

 

Cause

This limitation is due to BugID 1757129. 

 

Recommended Action

Assign user to role "Administrator" to make use of the Guided Configuration, or use the regular ASM Policy Configuration.

 

Additional Information
