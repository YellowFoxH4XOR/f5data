Topic

You should consider using this procedure under the following condition:

  • You want to enable F5 Application Services 3 Extension (AS3) burst handling feature.

Description

This article covers how to enable the burst handling feature on BIG-IQ systems installed with AS3 3.23 or later. The burst handling feature is supported beginning in AS3 3.23 and provides an alternative flow management when handling multiple AS3 declarations simultaneously. When the burst handling feature is enabled, AS3 queues the incoming requests and processes each declaration individually without rejecting subsequent requests.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IQ system.

Procedures

Enabling AS3 burst handling using BIG-IQ command line 

You can enable AS3 burst handling feature by sending a POST declaration to the shared/appsvcs/settings endpoint from the BIG-IQ command line. To do so, perform the following procedure:

Impact of procedure: The suggested procedure alters the default AS3 declaration handling behavior. You should test any such changes in a staging environment or during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to the BIG-IQ command line.
  2. To verify the AS3 version, enter the following command:

    curl http://localhost:8105/shared/appsvcs/info

    Note: For AS3 3.22 and earlier, you must upgrade to AS3 3.23 before you can enable the feature with the REST API endpoint. For information about upgrading, refer to K54909607: BIG-IQ Centralized Management compatibility with F5 Application Services 3 Extension and F5 Declarative Onboarding.

  3. To enable the burst handling feature, enter the following command:

    curl -H "Content-Type: application/json" -X POST -d '{"burstHandlingEnabled": true}' http://localhost:8105/shared/appsvcs/settings

    The output appears similar to the following example:

    {"burstHandlingEnabled":true}

  4. To verify if the burst handling feature is enabled, enter the following command:

    curl http://localhost:8105/shared/appsvcs/settings
