Description

Receiving Cross Site Request Forgery (CSRF) error message in the Configuration Utility GUI when going to some Security >> Application Security options. The error message appears in the GUI and /var/log/asm logs.

In /var/log/asm:
Feb 05 00:12:34 bigip.localhost info httpd[12345]: The system detected a CSRF attack and the operation was aborted. Page: js_http_action_items.php
Feb 05 00:12:34 bigip.localhost info httpd[12345]: The system detected a CSRF attack and the operation was aborted. Page: js_http_save_filter.php

In the Configuration Utility:
This request was unauthorized. The system detected a CSRF attack and the operation was aborted.

Environment

  • BIG-IP ASM
  • Cross Site Request Forgery error message
  • / (root) filesystem full

Cause
This error is caused by the BIG-IP not properly matching the CSRF token sent by the client to existing session data and improperly detecting it as a CSRF attack. When / is full it can be due to improperly saving user files to the root directory instead of the /var/tmp or /shared folders.

Recommended Actions

  1. Run the following command to verify the available space in the / directory:
    df -h 
  2. The output would look similar to the following...Filesystem Size Used Avail Use% Mounted on
    /dev/mapper/vg--db--sda-set.1.root 427M 427M 0 100% /

    NOTE: Output truncated for brevity.
  3. Run the following command to find the file(s) using most of the space in /:
    ll -h /
  4. Review the output. It may help to compare it to another BIG-IP to see what may not belong there. Remove any unnecessary files you have identified. Some of these could be old packet captures or text files that were mistakenly placed there.   5. Those can be removed by using the rm command. For example: [root@Omega:Active:Standalone] / # rm testy.pcapng
    rm: remove regular file 'testy.pcapng'? y
    [root@Omega:Active:Standalone] / #
  6. Once the files have been removed check the filesystem by running the df -h command. If / no longer shows at 100% then try to access the GUI.

Note: If you have any doubts on what do delete, please contact F5 support.
Note: The proper directory to save files would be the /shared/tmp.
