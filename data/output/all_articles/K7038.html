Issue

You should use the BIG-IP Setup utility for initial setup configurations, and the Configuration utility to make additional changes to the BIG-IP system configuration. The BIG-IP Setup utility creates an external and an internal default VLAN upon initial configuration.

If you have previously run the Setup utility, and your BIG-IP system has existing external and internal VLANs containing advanced network configuration (such as trunks, multiple self IP addresses, or VLAN groups), and you plan to re-run the Setup utility, the Basic Network Configuration screen in the Setup utility displays an error message similar to the following example:

VLAN "internal" has a configuration that is not supported by the Setup Utility

If you receive this warning message, click the Finished button, and use the Configuration utility to make configuration changes. Alternatively, you can use the Configuration utility to delete the advanced network configuration from the external and internal VLANs, and then re-run the Setup utility.

For information about running the Setup utility, refer to K7037: Overview of the BIG-IP Setup utility.
