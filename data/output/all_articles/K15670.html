Known Issue

The dnatutil utility may fail to parse the remote syslog log file for Deterministic NAT (DNAT) data. This issue occurs when all of the following conditions are met:

  • You configure a log destination as the Remote Syslog type and configure its Syslog Format setting to the Syslog method (RFC 5424 format).
  • You configure a Large Scale NAT (LSN) pool with a log publisher that uses this log destination for sending DNAT data to the remote syslog server.

Impact

Users cannot map external addresses and ports back to internal clients.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H481972 on the Diagnostics > Identified > Medium screen.
  • The dnatutil utility reports an unparseable line when invoked to parse the log from the remote syslog server.
  • The remote syslog server contains logs in the RFC 5424 format. These logs typically start with a 1 and have a section enclosed in brackets ([ ]) with key/value pairs, followed by the raw syslog message after the section enclosed in the square brackets.

    For example:

Workaround

If your DNAT data is already in the RFC 5424 log format, you can manually extract the raw syslog format from the end of the RFC 5424 formatted DNAT log entries. To do so, you can delete all content within the square brackets, including the brackets before invoking the dnatutil utility to parse the log file. Using the previous example, the raw syslog format should appear similar to the following example:

<134>1 2014-07-02T14:37:31-07:00 7000-3.sh.pdsea.example.com tmm 21768 2 "Jul 02 2014 14:37:31 PDT","172.27.76.111","7000-3.sh.pdsea.example.com","3","LSN_CFG","DNAT config change","/Common/dnatpool","10.10.20.0/24","4.4.6.0/24","1025","65535","platform=D110 npus=4 npgs=1 online=0x1 dver=19 dname=hdag dhsbs=1 dhash=4 dfold=0 dseed=0 dosize=0 dodata=: dflags=0x2","mode=addr port1:1=yes addr1:1=yes","d41d8cd98f00b204e9800998ecf8427e","1404337051"

To prevent this issue from occurring, you can configure the log destination to use the BSD Syslog method for its Syslog Format setting. The BSD Syslog method is the default method for the Syslog Format setting. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Logs > Configuration > Log Destinations.
  3. Select the affected log destination.
  4. For the Syslog Format setting, select BSD Syslog.
  5. Click Update.
