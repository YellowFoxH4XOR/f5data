Known Issue

The BIG-IP ASM system may reset client connections when the Session Awareness feature is enabled.

This issue occurs when all of the following conditions are met:

  • The Session Awareness feature is enabled on a BIG-IP ASM system.

    Note: To determine if the Session Awareness feature is enabled, you can navigate to the Configuration utility Security > Application Security > Sessions and Logins page, and review the Session Tracking Configuration section.

  • Client connections take longer than 10 seconds to complete (from the request start until the response end).

Impact

Client connections are reset, resulting in errors when attempting to load requested web pages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If TCP RST logging is enabled, messages similar to the following example are logged to the /var/log/ltm file:

    err tmm2[12345]: 01230140:3: RST sent from 10.11.12.100:80 to 10.11.12.1:23456, [0x1f958dc:459] Internal error (ASM requested abort (plugin abort error))

    Note: For more information about TCP RST logging, refer to K13223: Configuring the BIG-IP system to log TCP RST packets.
