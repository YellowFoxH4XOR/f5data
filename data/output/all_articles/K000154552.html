Description

  • The native NGINX Plus Prometheus endpoint (/metrics), provided by the Prometheus-njs module, exposes a limited subset of NGINX Plus metrics .
  • In contrast, the nginx-prometheus-exporter accesses and exposes a broader set of feature-specific metrics—including resolver statistics, HTTP requests, rate limiting, connection limiting, and cache data by querying the NGINX Plus REST API endpoints.
  • You want to know why "Prometheus-njs module" has a limited set of NGINX Plus metrics. 

Environment

  • NGINX Plus
  • Prometheus
  • Prometheus-njs
  • nginx-prometheus-exporter
  • REST API
  • Metrics

Cause

  • nginx-plus-module-prometheus as an njs Dynamic modules, it is hard coded to use ONLY a subset of NGINX /api endpoint to access its metrics

Recommended Actions

  • For extended monitoring and access to additional NGINX Plus metrics, deploy nginx-prometheus-exporter alongside your NGINX Plus instance.
  • nginx-prometheus-exporter being a reliant on the built-in metrics of NGINX Plus REST API Endpoints, it provides a broader set of metrics as well as various status information
  • the exporter gather NGINX metrics via NGINX API module as stated here Module ngx_http_api_module

Additional Information

  • NGINX Plus Dashboard, in the same manner as nginx-prometheus-exporter, relies on NGINX REST API to collect and expose metrics.
  • NGINX Native Dashboard also utilize the same API to expose metrics
