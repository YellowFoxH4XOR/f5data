Description

When accessing to a previous accessed VPN using Edge Client, it does not ask for user credentials an it gets directly accessed.

Environment

  • F5 as SAML SP
  • Edge Client 

Cause

This is a default configuration.
 

Recommended Actions

If asking for credential in Edge is always required, let's use ForceAuthn flag in the SP profile configuration.
  1. In the GUI, navigate to Access >> Federation >> SAML Service Provider
  2. In ForceAuthn, select Enable
