Description

After importing, or reviewing, SSL certificates there is a gray box in the status column.  If scrolled over, the popup text merely states "Status monitoring is not enabled or Status is not yet available".

  • What is causing this?
  • Does the certificate still work?

Environment

  • BIG-IP running 13.x or higher
  • Using non-default SSL certificates

Cause

The gray box is the result of a new feature released for OCSP stapling called "Certificate Monitoring".  OCSP Certificate Monitoring allows the BIG-IP system to monitor the revocation status for SSL certificates.  The gray box status has no effect over the functionality of the certificate itself.  If you wish to configure OCSP stapling so that you can accurately monitor the status of your SSL certificates then you can find more information in the article on configuring OCSP stapling below.

Recommended Actions

None at this time.
