Known Issue

When the Enterprise Manager system takes more than ten minutes to transfer the user configuration set (UCS) archive from a managed device via iControl, the Enterprise Manager auth token times out and the file transfer fails.

This issue occurs when one or both of the following conditions are met:

  • The affected UCS archive is particularly large
  • The network latency between the Enterprise Manager system and the managed device is high

Impact

The Enterprise Manager system is unable to transfer and save the UCS archive of the affected managed device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Enterprise Manager system fails to complete the transfer of a UCS archive, and reports errors similar to the following example in the /var/log/em file:

    04010b08:3: Unable to save the configuration for device with UID 3: iControl error: 'iControl::char*:SOAPException: 'Unexpected return code: 401 F5 Authorization Required, Invalid Token''
    04060300:3: Unable to archive configuration for device with UID 3: iControl error: 'iControl::char*:SOAPException: 'Unexpected return code: 401 F5 Authorization Required, Invalid Token''
    04060307:3: Archiving stopped due to unrecoverable error: Failed to archive configuration for device(s): 3
  • The affected managed device reports an error similar to the following example in the /var/log/httpd/httpd_errors file:

    err httpd[<pid>]: [error] [client <EM management IP address>] Got exception while handling EM auth token request: Invalid Token: The EM authentication token has expired.  This may happen if the clock on the managed device has been changed after it was discovered by the EM.  You should attempt to reauthenticate to the managed device from the EM.  This may involve either simply clicking on the device on the device list and entering a username and password, or deleting the device from the device list and rediscovering. (Token timestamp: <timestamp>, Current system time: <system time>, Token lifetime: 600 seconds)

Workaround

To work around this issue, you can reduce the potential size of the UCS archive by removing unnecessary files (signature updates, ISO files, traffic captures, etc.) from the affected managed device. To do so, perform the recommendations described in the following article that is appropriate to the affected managed device's version:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  • K14403: Maintaining disk space on the BIG-IP system (11.x)
  • K12263: Maintaining disk space on the BIG-IP system (9.x - 10.x)
