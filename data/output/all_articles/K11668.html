Known Issue

This is the result of a known issue. The BIG-IP ASM web scraping option may prevent some pages with JavaScript from executing.

This behavior occurs when the web scraping option is enabled; if the option is enabled in learning mode with blocking enabled, the following violation message will be reported when JavaScript is encountered:

Type mis-match

For more information about web scraping, refer to the Configuration Guide for BIG-IP Application Security Manager.

F5 Product Development tracked this issue as CR134511 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
