Description

ATA bus error means that data corruption occurred during transmission over ATA bus (SATA or PATA). Transmission errors can cause wide variety of symptoms ranging from device ICRC error to random device lockup, and, for many cases, there is no way to tell if an error condition is due to transmission error or not; therefore, it's necessary to employ some kind of heuristic when dealing with errors and timeouts. For example, encountering repetitive ABRT errors for known supported command is likely to indicate ATA bus error.

If the disk encounters ATA bus error, you may find these symptoms below.

  • /var/log/kern.log may show messages below.

Dec  2 05:46:06 bigip-1 err kernel: ata5.00: failed command: WRITE FPDMA QUEUED
Dec  2 05:46:06 bigip-1 err kernel: ata5.00: cmd 61/90:00:61:76:54/00:00:00:00:00/40 tag 0 ncq 73728 out
Dec  2 05:46:06 bigip-1 err kernel: res 40/00:0c:f9:76:54/00:00:00:00:00/40 Emask 0x10 (ATA bus error)
Dec  2 05:46:06 bigip-1 err kernel: ata5.00: status: { DRDY }

  • Or the console log may show similar messages from kernel below.

ata5.00: failed command: WRITE FPDMA QUEUED
ata5.00: cmd 61/02:08:95:07:f9/00:00:04:00:00/40 tag 1 ncq 1024 out
         res 40/00:e4:4f:ff:f8/00:00:04:00:00/40 Emask 0x10 (ATA bus error)
ata5.00: status: { DRDY }

Environment

  • SATA
  • Hard disk

Cause

An "ATA bus error" generally implies an issue with SATA interface. This could be a hardware issue of SATA interface on the unit and/or the hard disk, and it could be a firmware/software issue on the unit and/or the hard disk. In addition, poorly seated hard disk and insufficient power supply may cause this error.

Recommended Actions

  1. If you see this error on a device with a replacable hard disk, please reseat the disk to see if the issue still persists.
  2. If it does, please open a support case with F5 Support and provide the following:
    • End-User Diagnostic report - please select option A Run All (Non-Interactive) Tests
    • QKview - K12878: Generating diagnostic data using the qkview utility
