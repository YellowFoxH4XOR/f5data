K000148759: Removed VLANs still show in LAG GUI under Trunk VLANs

Type
Support Solution
Published
2024-11-27
Updated
2024-11-27
Applies to
  • F5OS
  • F5 Distributed Cloud Services
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000148759

Description

You are experiencing an issue where VLANs that were previously assigned to a Link Aggregation Group (LAG) still appear in the Graphical User Interface (GUI) even after they have been deleted. This is a cosmetic issue and does not affect the actual functionality or performance of the system.

Environment

  • F5OS-A
  • VLANs previously assigned to LAG
  • Issue observed in GUI

Cause

  • Cosmetic issue

Recommended Actions

  1. Re-create the VLAN assigned to the LAG.
  2. Remove the VLAN from the LAG.
  3. Delete the VLAN.

Additional Information

None
