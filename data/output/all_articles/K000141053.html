Description

This article describes step-by-step how to renew f5_api_com.crt if steps in article K000137950 are not working - the date remains the same after all steps.

Environment

  • BIG-IP / BIG-IQ
  • any version

Cause

Unknown at time of publication.

Recommended Actions

Delete the certificate and also remove f5_api_com.crt from /config/ssl/ssl.crt/, upon re-activation new certs are issued with 3 years validity from the time of request.

Note: Performing below actions shouldn't impact traffic.

1) To remove certificate use below command:

# rm /config/ssl/ssl.crt/f5_api_com.crt

2) Upon license re-activation, it's not required to install f5_api_com.crt, it can be done by running the following command:

# tmsh create sys file ssl-cert f5_api_com.crt source-path file:///config/ssl/ssl.crt/f5_api_com.crt

# tmsh save sys config

Additional Information

This certificate is used to secure communication to api.f5.com. Services such as ELA reporting, phonehome, automatic update check, uploading qkview to iHealth from F5 unit etc., connect to api.f5.com.
