K64554007: AS3 error ''unable to validate certificate, invalid x509 file''

Type
Support Solution
Published
2021-02-03
Updated
2023-02-21
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K64554007

Description

  • using AS3 to configure BIG-IP
  • configuring an HTTPS Virtual Server and provide SSL certificate and key
  • Error message in response from BIG-IP:
    "{"results":[{"code":422,"message":"declaration failed","response":"01070712:3: unable to validate certificate, invalid x509 file (/SampleTenant/SampleApp/SampleCert.crt).","host":"localhost","tenant":"SampleTenant","runTime":5439}],..."
     

Environment

  • AS3 v3.25.0
  • Example AS3 declaration snippet:
     
        ...
        "SampleCert": {
                  "class": "Certificate",
                  "certificate": "-----BEGIN CERTIFICATE-----
        MIIDiTCCAnGgAwIBAgIJAI/ohWc3iFACMA0GCSqGSIb3DQEBCwUAMFsxCzAJBgNV
        BAYTAlVTMRUwEwYDVQQHDAxEZWZhdWx0IENpdHkxHDAaBgNVBAoME0RlZmF1bHQg
        ...
        WJBrtAwJFIt8wAuPjNGsQvt//w55B3g6e66r4UxkgM5TJm3AvPig2IGpvmA/8GK/
        T+VCs0va09ETrHGFlBSXtyDjqnByJ4V7pIQsKhClZE3aGjZ3vCX+uqIrK9gV
        -----END CERTIFICATE-----",
        ...

Cause

Certificate in AS3 declaration does not match format expected by AS3.

Recommended Actions

  1.    Put cert/key in Notepad++
  2.    Go to View | Show Symbol | Show End of Line
  3.    Do a Replace using "Extended" Search Mode, replacing "\r\n" (when End of Line symbol shows "CRLF") or "\n" (when End of Line symbol shows "LF") with a random string (e.g. "erarfgarvrvrq")
  4.    Do a Replace using "Normal" Search Mode, replacing the random string (e.g. "erarfgarvrvrq") with "\n"
  5.    Use the result as the cert or key string in the AS3 declaration

        ...
        "SampleCert": {
                  "class": "Certificate",
                  "certificate": "-----BEGIN CERTIFICATE-----\nMIIDiTCCAnGgAwIBAgIJAI/ohWc3iFACMA0GCSqGSIb3DQEBCwUAMFsxCzAJBgNV\nBAYTAlVTMRUwEwYDVQQHDAxEZWZhdWx0IENpdHkxHDAaBgNVBAoME0RlZmF1bHQg\n...\nWJBrtAwJFIt8wAuPjNGsQvt//w55B3g6e66r4UxkgM5TJm3AvPig2IGpvmA/8GK/\nT+VCs0va09ETrHGFlBSXtyDjqnByJ4V7pIQsKhClZE3aGjZ3vCX+uqIrK9gV\n-----END CERTIFICATE-----",
        ...

    ("certificate" is one long line )
