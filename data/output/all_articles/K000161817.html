K000161817: [F5OS] Manual license activation fails with "License validation failed"

Description

When performing manual license activation on an F5OS rSeries appliance, the process fails with a "License validation failed" error in the GUI. The error details show:

error-type    : application
error-tag     : malformed-message
error-path    : /openconfig-system:system/f5-system-licensing:licensing/f5-system-licensing-install:manual-install
error-message : License validation failed

Environment

  • F5OS-A (rSeries)
  • Manual license activation via GUI or CLI

Cause

During the manual licensing process, the F5 licensing portal (activate.f5.com) returns a page containing two distinct sections:

  1. The End User License Agreement (EULA) — a block of legal text displayed at the top of the page
  2. The license file — the machine-readable license data displayed below the EULA

The EULA text was copied and pasted instead of the license file content into the F5OS licensing interface. The F5OS license parser cannot find valid license data in the EULA text, resulting in the validation failure.

Recommended Actions

  1. Return to the F5 licensing portal at https://activate.f5.com/license/dossier.jsp. The previously generated license should still be retrievable using the same dossier or registration key — no need to regenerate.

  2. On the licensing portal results page, locate the license file content — this is the section that appears below the EULA. The license file begins with a header similar to:

    # This file is automatically generated by F5 Networks, Inc.

    and ends with the outbound license authorization signature block:

    # Outbound License Authorization Signature
# Authorization : <signature string>

  3. Copy only the license file content (from the header # line through the end of the authorization signature). Do not include the EULA text.

  4. Paste the license content into the correct field:

    • GUI: Navigate to System Settings → Licensing, paste into the License text box, and click Activate.
    • CLI: Enter config mode and run: 
      system licensing manual-install license
      Paste the license content when prompted.

  5. Verify successful activation:

    • GUI: The licensing page should display the registration key, licensed date, and active modules.
    • CLI: Run show system licensing to confirm the license details are populated.

Additional Information

  • For full manual licensing steps on F5OS rSeries, refer to K000151705: Viewing and licensing or reactivating a license for F5OS rSeries.

  • If the error persists after pasting the correct license file content, refer to K000157151: Unable to reactivate F5OS license - Error 51075 for other known causes of manual license activation failure.

  • Licensing must always be performed at the F5OS platform layer, not from within a BIG-IP tenant. The tenant automatically inherits the license from the platform.
