Security Advisory Description

BIG-IP APM Edge Client for Linux exposes the full session ID in the local log files. (CVE-2020-5908)

Impact

This vulnerability may allow unauthorized disclosure of the BIG-IP APM session ID and expose sensitive information to the user of the client device.

Security Advisory Status

F5 Product Development has assigned ID 857669 (BIG-IP) to this vulnerability.
