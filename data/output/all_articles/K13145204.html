Known Issue

The Traffic Management Microkernel (TMM) process may produce a core file and restart when an iRule attempts to update non-existent sessions.

This issue occurs when the following condition is met:

  • Your BIG-IP PEM system is configured with iRules that update a non-existent target BIG-IP PEM session with policies.

Impact

Traffic is disrupted while the TMM process produces a core file and restarts. The affected BIG-IP system that is configured as part of a high availability (HA) device group may fail over to a peer device. In addition, you may observe spikes in the CPU utilization graphical chart.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process generates a core file to the /shared/core directory.
  • The affected BIG-IP system unexpectedly fails over to another system when configured as part of a HA device group.
