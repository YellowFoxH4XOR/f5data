Description

With the DNS Security profile applied to the DNS profile, no DNS response is received.

In the event logs ( Security > Event Logs > Protocol > DNS ), there is a Drop for the Attack type: query opcode.

Without the DNS Security profile, the requests are allowed.
 

Environment

  • Upgrade from 14.x to 15.x
  • No DNS response received

Cause

In the DNS Security Profile, for the section "Header Opcode Exclusion" , "query" is included in the Active section.

 

From the bigip.conf it would appear as below:

security dns profile /Common/dns_sec {
    header-opcode-exclusion { query } <-----------
    query-type-filter { a }
    query-type-inclusion yes
}


Header Opcode Exclusion, lists the OPCODES that you want the system to allow or drop if they appear in the headers of DNS packets.

With "query" in the Active section, it is instructing the system to drop. Hence the block.
 

Recommended Actions

Move the option "query" to the Available section to allow the traffic when "query" OPCODE appears in the headers of the DNS packets.
