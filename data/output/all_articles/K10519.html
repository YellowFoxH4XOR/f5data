Topic

This article applies to BIG-IP 10.x. For information about other versions, refer to the following articles:

  • K13127: Restoring the BIG-IP configuration to factory default settings (11.x - 17.x)
  • K7550: Restoring the BIG-IP configuration to factory default settings (9.3.x - 9.4.x)

Purpose

You should consider using this procedure under the following condition:

  • You want to restore the BIG-IP configuration to factory default settings on the currently-active boot location.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You must have root, administrator, or resource-admin access to the Traffic Management Shell (tmsh).
  • You must perform this procedure using the management IP address or serial console.

Description

You may occasionally need to remove the current BIG-IP configuration and restore the system to the factory default setting. To do so you can use the tmsh load /sys default-config command. The tmsh load /sys default-config command saves the currently-running configuration to the /var/local/scf/backup.scf file, and then restores the configuration to the factory default settings by loading the /defaults/defaults.scf file.

Note: The tmsh load /sys default-config command retains certain configuration elements such as those that are necessary for maintaining basic administrative functionality.

When you restore the BIG-IP configuration to factory default settings, the system performs the following tasks:

  • Removes all BIG-IP local traffic configuration objects
  • Removes all BIG-IP network configuration objects
  • Removes all non-system maintenance user accounts
  • Retains the management IP address
  • Removes system maintenance user account passwords (root and admin)
  • Retains the BIG-IP license file
  • Retains files in the /shared partition
  • Retains manually-modified bigdb database variables

Procedure

Restoring the BIG-IP configuration to the factory default setting using the tmsh utility:

To restore the BIG-IP configuration to the factory default settings, perform the following procedure:

Impact of procedure: Using this procedure removes all BIG-IP local traffic and network configuration objects.

Note: The tmsh load /sys default-config command was introduced in BIG-IP 10.1.0. For 10.0.0 and 10.0.1, follow the clean install instructions in K10819: Performing a clean installation of BIG-IP 10.x or Enterprise Manager 2.x

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To restore the BIG-IP configuration to the factory default settings, type the following command:

    load /sys default-config

  3. To confirm the restore, type y.
  4. Save the change by typing the following command:

    save /sys config
