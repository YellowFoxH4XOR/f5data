K000161922: BIG-IP LTM: Configuration Utility disconnects and reloads repeatedly due to Tomcat Java heap exhaustion

  • BIG-IP GTM
  • BIG-IP APM

Source

Description

When you access the BIG-IP Configuration Utility (GUI) on a standby device in a High Availability (HA) pair, the interface repeatedly disconnects and reloads. You may also observe that the Tomcat service restarts frequently. The issue does not affect virtual server traffic processing — only GUI access is impacted.

Environment

  • BIG-IP Local Traffic Manager (LTM)
  • BIG-IP 17.5.1
  • High Availability (HA) Active/Standby configurations
  • All hardware platforms

Cause

The Tomcat service is allocated insufficient Java heap memory. When the default allocation of 128 MB is exhausted, the system logs repeated java.lang.OutOfMemoryError: Java heap space errors in /var/log/tomcat/catalina.out, causing Tomcat to restart continuously and rendering the Configuration Utility unstable.

Recommended Actions

Verify the issue

  1. Log in to the BIG-IP command line.
  2. Check the Tomcat log for out-of-memory errors by running the following command:

    grep "OutOfMemoryError" /var/log/tomcat/catalina.out

    If the issue is present, you see output similar to the following:

    java.lang.OutOfMemoryError: Java heap space

  3. Verify the current Tomcat memory allocation by running the following command:

    tmsh list sys db provision.tomcat.extramb

Increase the Tomcat Java heap allocation

  1. Run the following commands to increase the Tomcat extra memory allocation to 512 MB:

    tmsh modify sys db provision.tomcat.extramb value 512

    tmsh save sys config

    tmsh restart sys service tomcat

  2. After the Tomcat service restarts, verify that the Configuration Utility loads and remains stable.

Additional Information

  • Monitor the device for 24 to 48 hours after applying the change to confirm the issue does not recur.
  • This issue affects GUI access only. Virtual server traffic processing is not impacted.
  • The default Tomcat extra memory allocation may be insufficient in environments with high GUI activity or large configurations.
