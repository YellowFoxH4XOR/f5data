Known Issue

When you synchronize a very large configuration 3-DNS may take several seconds to load the new configuration files. In some cases, all 3-DNS Controllers in a synchronization group may attempt to load the new configuration files at the same time. When this occurs, all DNS requests are handled by named. This may result in an interruption in service if named is not configured to provide an appropriate response.

F5 Networks Product Development tracked this issue as CR23431.
