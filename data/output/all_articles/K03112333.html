Known Issue

TMOS Shell (tmsh) help documentation for the RESOLV::lookup iRules command is incorrect.

This issue occurs when the following condition is met:

  • You run the following tmsh command:

    tmsh help ltm rule command RESOLV::lookup | grep "Note: The results" -A6

Impact

There is no impact; this issue is cosmetic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The documentation for the RESOLV::lookup iRules command contains a description of a bug where PTR (Pointer) records are not cached. The documentation includes a workaround for this bug; however, this bug was corrected in BIG-IP 11.4.0.
