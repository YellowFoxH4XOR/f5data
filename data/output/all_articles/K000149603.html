K000149603: Not able to select version 8.0 when selecting i440fx for Machine when using Proxmox to create/license a BIG-IP

Type
Support Solution
Published
2025-02-03
Updated
2025-02-03
Source
https://my.f5.com/manage/s/article/K000149603

Description

The use of Proxmox to create a virtual instance of a BIG-IP requires the use of version 8.0 after selecting i440fx for the the Machine. However, that choice is not seen during the install steps. You move forward without that, but then licensing fails. In some cases a 51133 error will be seen if activation fails. In the LTM log will be a log entry similar to... localhost.localdomain warning chmand[4103]: 012a0004:4: CHMAN request (from get_dossier) for tag:19 failed each time an attempt is made to activate the license.

Environment

  • Installing a BIG-IP on Proxmox.
  • You may get as far as the GUI, but once you review the GUI you see that you cannot get passed the license activation.
  • Upon contact with F5 to request support a review of the F5 license server shows an error message of

"F5 registration key is not compatible with the detected platform This platform, "", cannot be activated with this registration key "XXXXXXX-XXXXXXX"." (The value of X will be 2 sequences of capital letters.)

Cause

The underlying cause for this was a change made on Proxmox.

To overcome that you must follow the steps in K85183351: How to deploy BIG-IP VE with Proxmox Virtual Environment under the section titled Create a new virtual machine (VM) step 12 to select 8.0 for Version after selecting 1440fx for Machine. But the ability to 8.0 is not there.

Recommended Actions

To correct that running the command qm set <VM-ID> --args "-machine pc-i440fx-8.0" should correct that issue.

  1.  That command will alter the hardware for the machine, and the Proxmox interface now offers a different version to choose from when a new Virtual Machine is created.
