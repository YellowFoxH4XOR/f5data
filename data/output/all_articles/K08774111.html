Issue

Error Message

01010221:3: Pool <pool_name> now has available members

In this error message, note the following:

  • <pool_name> is the name of the pool being monitored.

For example:

01010221:3: Pool example_pool now has available members

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • A pool member becomes available in a pool that previously had no available pool members.

The pool may have had no available members due to administrative action, monitors, connection limits, or other constraints on pool member selection.

Impact

At least one pool member is available in the pool to receive traffic.

Recommended Actions

None
