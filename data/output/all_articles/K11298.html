Known Issue

This is the result of a known issue. When restoring a snapshot on your FirePass controller, you may receive the following error message at the end of the restore process:

133 Broken pipe

This error message occurs when a file that is used to restore to the active partition contains superfluous information and remains open. The restore process ignores the superfluous information and completes, but it does generate an error message. You can safely ignore this error message if the restore status bar has reached 100 percent. You can verify that the restore was successful by navigating to the known configuration settings that exist in the restored configuration and confirming that they are correct.

Note: For more information about creating snapshots, refer to K3244: Backing up and restoring FirePass system software

F5 Networks Product Development is tracking this issue as CR135105.
