Topic

FIPS messages are logged in the /usr/contrib/ncipher/log file.

You can change the information that is logged to the FIPS log file, by performing the following steps:

  1. Log in to the command line.
  2. Using a text editor, such as vi or pico, open the /etc/nfast.conf file.

  3. Locate the following line:

    export NFAST_SERVERLOGLEVEL=

  4. Add one of the following codes to change the log level:

    infoIncludes all messages, the default.
    noticeExclude client connection/disconnection messages.
    clientExclude normal operational messages, show client misbehavior.
    errorExclude client misbehavior, show errors.
    seriousExclude non-serious errors.

  5. After you make changes to this file, restart the nfast daemon, by typing the following command:

    bigstart restart nfast
