Topic

You should consider using this procedure under the following condition:

  • You want to access the BIG-IP Always-On Management (AOM) Command Menu.

Description

AOM is a separate subsystem that provides lights-out management for the BIG-IP system using the 10/100/1000 Ethernet management port over secure shell (SSH), or using the serial console.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have serial console or SSH access to the system.

Procedures

Accessing the AOM Command Menu using the serial console
Accessing the AOM Command Menu using SSH

Accessing the AOM Command Menu using the serial console

To access the AOM Command Menu using the serial terminal, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Connect the serial console to the CONSOLE port.
  2. Display the AOM Command Menu by holding the 'Esc' key while simultaneously pressing the ' ( ' key:

    Esc (
    The AOM Command Menu displays, as follows:

AOM Command Menu (i850, i2000, i4000, i5000, i7000, i10000 series platforms)

AOM Command Menu:
B --- Set console baud rate
I --- Display platform information
P --- Power on/off host subsystem
R --- Reset host subsystem
N --- Configure AOM network
S --- Configure SSH Server
A --- Reset AOM
Q --- Quit menu and return to console

AOM Command Menu (2000, 4000, 5000, 7000, 10000 series platforms)

AOM Command Menu:
B --- Set console baud rate
I --- Display platform information
P --- Power on/off host subsystem
R --- Reset host subsystem
N --- Configure AOM network
S --- Configure SSH Server
A --- Reset AOM
H --- Host Console Capture Buffer
E --- Error report
Q --- Quit menu and return to console

AOM Command Menu (1600, 3600, 3900, 6900, 89XX, 11000, 11050 series platforms)

AOM Command Menu:
1 --- Connect to Host subsystem console
2 --- Reboot Host subsystem (sends reboot command)
3 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!)
4 --- Reset AOM subsystem (issues hardware reset--USE WITH CARE!)
5 --- Power off Host subsystem (issues hardware shutdown--USE WITH CARE!)
B --- AOM baud rate configurator
L --- AOM subsystem login
N --- AOM network configurator
P --- AOM platform information

AOM Command Menu (VIPRION 2100, 2150, 2250)

AOM Command Menu:
B --- Set console baud rate
C --- Capture blade console
I --- Display platform information
P --- Power on/off blade
R --- Reset blade
Q --- Quit menu and return to console

AOM Command Menu (VIPRION 4100, 4200, 4300, 4450)

AOM Command Menu:
B -- Set baud rate
C -- Capture blade console
I -- Display blade info
P -- Control blade power
Q -- Quit menu
R -- Reset blade

Accessing the AOM Command Menu using SSH

You can also access the AOM Command Menu using SSH for most platforms. To access the AOM Command Menu, refer to one of the following procedures based on your desired platform:

  • Accessing the AOM Command Menu using SSH (i2000, i4000, i5000, i7000, i10000 series platforms)
  • Accessing the AOM Command Menu using SSH (2000, 4000, 5000, 7000, 10000 series platforms)
  • Accessing the AOM Command Menu using SSH (1600, 3600, 3900, 6900, 89XX, 11000, 11050 series platforms)

Note: Some menu options, such as Configure AOM network, are only available using the serial console, and are not available over SSH.

Accessing the AOM Command Menu using SSH (i850, i2000, i4000, i5000, i7000, i10000 series platforms)

You can access the AOM Command Menu remotely using the SSH utility from a management workstation or another BIG-IP device. Before you access the AOM Command Menu using SSH, you must assign a management IP address, netmask, and gateway for the AOM network. To access the AOM Command Menu, perform the following procedure:

Note: On these platforms, AOM allows only one SSH connection at a time.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Configure AOM network access. For more information, refer to K11400446: Configuring AOM network access (i2000, i4000, i5000, i7000, and i10000 series platforms). 
  2. Log in to the command line of a management workstation that has the SSH utility and is connected to the same subnet as the platform's management (MGMT) interface.

    Note: F5 recommends connecting to the iSeries platform residing in the same subnet, although you may be able to connect to the iSeries platforms from a remote network.

  3. Access the AOM by typing the following command, replacing <ip addr> with the IP address that you configured on the AOM:

    ssh <ip addr>

  4. Enter the AOM administrative user account and password.

    Note: By default, the AOM administrative user account does not exist and needs to be created using the aom_setup_user utility. For more information, refer to K11400446: Configuring AOM network access (i2000, i4000, i5000, i7000, and i10000 series platforms).

  5. When prompted, deactivate another concurrent session by pressing Enter.
  6. Display the AOM Command Menu by holding the 'Esc' key while simultaneously pressing the ' ( ' key:

    Esc (

    The AOM Command Menu opens as follows:

    AOM Command Menu:
    B --- Set console baud rate
    I --- Display platform information
    P --- Power on/off host subsystem
    R --- Reset host subsystem
    S --- Configure SSH Server
    E --- Display error report
    Q --- Quit menu and return to console

Note: To leave the AOM Command Menu, enter the following SSH control sequence: ENTER > TILDE ( ~ ) > Period ( . ).

Accessing the AOM Command Menu using SSH (2000, 4000, 5000, 7000, 10000 series platforms)

To access the AOM Command Menu, perform the following procedure:

Note: This procedure applies to platforms running version 12.0.0 or earlier. If you are running 12.1.0 or later, refer to the serial console procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line using the management interface.
  2. Access the AOM by typing the following command:

    ssh aom

  3. Enter the user name and password.

    Note: By default, the AOM user name and password uses the root logon credentials.

  4. Press Enter to deactivate another concurrent session.
  5. Display the AOM Command Menu by holding the 'Esc' key while simultaneously pressing the ' ( ' key:

    Esc (

    The AOM Command Menu opens as follows:

    AOM Command Menu:
    B --- Set console baud rate
    I --- Display platform information
    P --- Power on/off host subsystem
    R --- Reset host subsystem
    S --- Configure SSH Server
    E --- Display error report

Accessing the AOM Command Menu using SSH (1600, 3600, 3900, 6900, 89XX, 11000, 11050 series platforms)

To access the AOM Command Menu using SSH for 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 series platforms, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line using the management interface.
  2. Access the AOM by typing the following command:

    ssh aom

  3. Open the hostconsh shell by typing the following command:

    hostconsh

  4. Display the AOM Command Menu by holding the 'Esc' key while simultaneously pressing the ' ( ' key:

    Esc (
