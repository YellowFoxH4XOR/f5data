Topic

When your BIG-IQ system collects statistics from a BIG-IP system that has Analytics enabled, you view the Analytics dashboard on the BIG-IQ user interface because the Analytics dashboard does not display any data on the BIG-IP Configuration utility.

Description

On the BIG-IP system, when you navigate to Statistics > Analytics and then select any category, such as HTTP, the page displays No data.
 

Environment

  • BIG-IP LTM
  • BIG-IP Analytics
  • BIG-IQ
  • HTTP Analytics
     

Cause
By default, use-offbox setting is enabled and BIG-IP system will send the statistics to BIG-IQ without saving the data locally on the device.

To verify how the BIG-IP system keeps analytics data, run the below command on the BIG-IP system.

# tmsh list analytics global-settings 
        analytics global-settings {
        avrd-interval 30
        ecm-port 443
        enable-bigiq-configuration enabled
        offbox-protocol https
        offbox-tcp-addresses { 10.0.0.1 10.0.0.2 }
        offbox-tcp-port 443
        source-id 62038ca1-07bd-4bb4-9e93-c697b00c37d1_10.0.0.3
        use-offbox enabled
        }
Note: It is not possible to configure BIG-IP Analytics to send data to DCD and also keep data locally on the BIG-IP device.

Recommended Actions

You can view analytics data on BIG-IQ by navigating to Monitoring > Dashboards and choosing a product or feature category and a metric type. From there you can filter for a specific BIG-IP system.
