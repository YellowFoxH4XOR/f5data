K000149737: Missing HTTP Strict-Transport-Security (strict-transport-security) header when using redirect routes

Type
Support Solution
Published
2025-02-10
Updated

Description

HTTP Strict-Transport-Security is enabled on the load balancer

You are using a Redirect Route

Header strict-transport-security is present when visiting the site however the header is not present when a request ID is returned i.e. when the request is blocked

Environment

  • Web App & API Protection
    • HTTP Load Balancer

Cause

By design, strict-transport-security header is not added when traffic is blocked using routes.

Recommended Actions

Review why the traffic was blocked by reviewing the logs and if needed add an exception to allow the traffic.
