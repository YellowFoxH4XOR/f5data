Known Issue

The BIG-IP GTM configuration may fail to load after an upgrade.

This issue occurs when all of the following conditions are met:

  • You attempt to BIG-IP 11.x from a release version prior to BIG-IP 11.0.0.
  • Your BIG-IP GTM configuration contains duplicate virtual server names.

Important: Virtual server names that are differentiated with a space at the end of the name are considered duplicates.

Impact

Attempts to load the BIG-IP GTM configuration fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After a version upgrade, the initial attempt to load the BIG-IP GTM configuration fails.
  • When manually running the esrapmtg parsing utility, after upgrading the BIG-IP GTM configuration, the utility fails and writes an esrapmtg core file to the /shared/core directory.

Workaround

To work around this issue, you can modify the BIG-IP GTM configuration to resolve any duplicate virtual server names prior to upgrading.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
