Known Issue

This is the result of a known issue. Traffic destined for a host accessible only over a trunked VLAN that originated from a single or non-trunked VLAN is not correctly forwarded.

This behavior only occurs when the following network configuration is used with the BIG-IP VIPRION:

For example, this issue may occur when the client attempts to contact the server through a BIG-IP VIPRION for which the server-side network is accessible only through a VLAN trunk. When the packet is received on the trunked interface, the BIG-IP VIPRION directs the packet to the incorrect interface/VLAN.

F5 Product Development tracked this issue as CR99759 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP 10.0.1 and in Hotfix-BIGIP-9.6.1-HF2 issued for BIG-IP 9.6.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
