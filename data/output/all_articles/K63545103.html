K63545103: Maximum Concurrent TCP connection on BIND

Type
Support Solution
Published
2023-04-28
Updated
2025-02-03
Source
https://my.f5.com/manage/s/article/K63545103

Description
TCP requests that are directed to the local BIND server on a Big-IP DNS either fail to connect or have a very slow response time.
 

Environment

This occurs:

  • Any version Big-IP DNS
  • A DNS listener is using a dns profile where " Use BIND Server on BIG-IP" is enabled.

Cause

BIND 9 has a maximum number of concurrent TCP connection limit. See http://www.zytrax.com/books/dns/ch7/hkpng.html#tcp-clients.
 

"By default DNS uses UDP port 53 for queries but is defined to allow both TCP and UDP. The tcp-clients allows the user to define the maximum number of TCP connections to be supported. The BIND 9 default is 100. This statement may only be used in a global options clause."

So if this TCP maximum connections is exceeded then TCP requests to Big-IP DNS records that are directed to the local BIND server then these requests may get a connection refused or a very slow response.
To check if this limit is being reached, then the command:
 

netstat -pano | grep "127.0.0.1:53" | grep LISTEN | grep tcp

Output may be similiar to below. Note the 2nd column with the number 11. This is the Recv-Q which shows the number of requests queued for the IP:port. So we can see 11 requests are waiting for a response from named on tcp port 53.

tcp       11      0 127.0.0.1:53            0.0.0.0:*               LISTEN      21261/named          keepalive (0.07/0/0)

The below command can also be executed to gauge the number of connections in various states to BIND on tcp port 53. A number close or over 100 means BIND is exceeding this limit.

netstat -pano | grep "127.0.0.1:53" | grep tcp | wc -l

Recommended Actions

Change the BIND tcp client limit to a suitable value.

  1. Follow https://my.f5.com/manage/s/article/K6963 and follow section "Using the ZoneRunner utility to manage the BIND configuration file"
  2. Add a new line within the curly brackets of the options section with 
    • tcp-clients 300;

  3. See below where I added tcp-clients 300; to the last line of the options section. (Highlighted below)

    options {
    listen-on port 53 {
        127.0.0.1;
        "zrd-acl-000-000";
    }
    recursion no;
    directory "/config/namedb";
    allow-transfer {
        localhost;
    };
    check-names master warn;
    check-integrity yes;
    max-journal-size 1M;
    version "none";
    masterfile-format text;
    tcp-clients 300;
};

Additional Information

Refer to BIND 9 documentation for further information on this limit

F5 support for BIND is limited to issues that impact security, critical defects, and configuration changes needed to support DNS Express within the BIND feature.  For more information, see:  K7176: F5 support for ZoneRunner, BIND, and the named process
