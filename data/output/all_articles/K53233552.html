Description
You want to verify configuration to see if there is any errors. These errors could stop the configuration from loading after an upgrade or license reactivation. 

Environment

  • BIG-IP
  • Command line
  • Upgrade 

Cause
None

Recommended Actions

Run the following tmsh command to check the config:

Note: Performing the following command validates the specified configuration from files without changing the running configuration and should not have a negative impact on your system.

tmsh load sys config verify partitions all
If the output contains no error, BIG-IP will allow loading the configuration.
If the output contains error which blocks the configuration to be loaded, fix all errors in order to load the configuration. If you need further assistance, please contact F5 Technical Support

None
