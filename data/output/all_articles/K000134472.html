K000134472: Is 'Services > Workspace > Edit Api Proxy > Gateway Proxy Hostname' the same as 'Infrastructure > Workspace > Edit Environment > Hostname'?

Source

Description

'Services > Workspace > Edit Api Proxy > Gateway Proxy Hostname' looks the same as 'Infrastructure > Workspace > Edit Environment > Hostname'. Can this be autopulated?

Environment

NMS: ACM

Cause

These are different because the Environment has different runtimes, i.e. Gateway Proxy and Portal Proxy. In Services, when publishing a proxy, it has a descriptive label calling out explicitly Gateway Proxy Hostname and Portal Proxy Hostname to say which hostname is available to select. The dropdown is pre-populated and as such it is not an input field. I.e. it will only show what is available for selection.
