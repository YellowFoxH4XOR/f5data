K000154674: VELOS management connection lost after system controller upgrade to F5OS-C 1.8.1

Type
Support Solution
Published
2025-09-12
Updated
2025-09-12
Applies to
  • F5OS
  • F5OS-C: 1.8.1
Source
https://my.f5.com/manage/s/article/K000154674

Description

Upgraded VELOS chassis to F5OS-C v1.8.1, but can no longer access the management interface.

Upgrade otherwise appears to have been successful.

Management connectivity was working without issue in the previous version.

Environment

  • After VELOS upgrade
  • Management connectivity

Cause

Multiple management port aggregations are configured.

For example:

interfaces interface mgmt-aggr                              <-- #1
 config name mgmt-aggr
 config type ieee8023adLag
 hold-time config up 0
 hold-time config down 0
 aggregation config lag-type LACP
 aggregation config distribution-hash src-dst-ipport
!
interfaces interface mgmt_aggr                              <-- #2
 config name mgmt_aggr
 config type ieee8023adLag
 hold-time config up 0
 hold-time config down 0
 aggregation config lag-type LACP
 aggregation config distribution-hash src-dst-ipport
!
 
interfaces interface 1/mgmt0
 config name 1/mgmt0
 config type ethernetCsmacd
 config enabled
 hold-time config up 0
 hold-time config down 0
 ethernet config aggregate-id mgmt_aggr
!
interfaces interface 2/mgmt0
 config name 2/mgmt0
 config type ethernetCsmacd
 config enabled
 hold-time config up 0
 hold-time config down 0
 ethernet config aggregate-id mgmt_aggr
!
 
lacp interfaces interface mgmt-aggr
 config name mgmt-aggr
 config interval FAST
 config lacp-mode ACTIVE
!
lacp interfaces interface mgmt_aggr
 config name mgmt_aggr
 config interval FAST
 config lacp-mode ACTIVE
!

After the upgrade, the switchd service adds the mgmt-aggr LAG first, then "ignores" the mgmt_aggr LAG. This is a problem since the management ports are aggregated on mgmt_aggr.

Recommended Actions

The presence of two management aggregations is a misconfiguration that can lead to issues. There can be only one.

Delete the unused aggregation:

e.g.
no lacp interfaces interface mgmt-aggr
no interfaces interface mgmt-aggr

Then reboot the controllers.

Additional Information

The fix for ID2025949 will prevent the creation of multiple management aggregations.
