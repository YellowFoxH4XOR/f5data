Description

You want to delete a particular VLAN but you saw the following error message:

01070623:3: The vlan ([/Partition-name][/VLAN-name]) is referenced by one or more virtual servers.

Environment

  • BIG-IP

Cause

The particular VLAN is being referred or used by one or more virtual servers. In other words, one or more virtual server configuration is depending on the VLAN you are trying to delete.

Recommended Actions

Find which virtual servers are using that particular VLAN and remove that VLAN from the virtual server configuration using Configuration Utility.

Find the files containing the particular VLAN configuration information.

If you have multiple partitions with multiple virtual servers it can be quite tedious to find where the particular VLAN you are trying to delete is used by virtual servers. The fastest and most simplest way to check which all virtual server is using the VLAN you plan to delete is uploading the qkview to ihealth and searching in the /config/bigip.conf file. If there are multiple partitions used then click on the (All) to search through the entire bigip.conf file in a go.

Alternatively, below steps can be followed to check from the CLI of the BIG-IP.

To find which partition virtual server the VLAN is being used run the blew command in the BIG-IP CLI

cd /config

grep -ir --include="bigip.conf" <vlan-name>

The output of the above commands, the file names you should be looking for should be
partitions/<partition-name>/bigip.conf:           /<partition-name>/<vlan-name>     ---> In particular partition
bigip.conf:                                       /Common/<vlan-name>               ---> In Common partition

Find the Virtual Server

Once the file is found, open the each bigip.conf file and search where the VLAN is in the configuration file. Either you can copy the entire configuration file to notepad and search  or follow the below procedure to search in the command line itself.

cat -n partitions/<partition-name>/bigip.conf | grep <vlan-name>

Either of the below command can be used which virtual server the VLAN is used. Repeat steps until found all the virtual server using the VLAN and take a note of it.

head -n <line-number> partitions/<partition-name>/bigip.conf

cat -n partitions/<partition-name>/bigip.conf | head -n <line-number>

Delete the VLAN from the Virtual Server

From GUI (Configuration Utility)
Go to virtual server  (Local Traffic  ››  Virtual Servers : Virtual Server List  ››  <virtual-server>)
Scroll down and you will see VLANs and Tunnels.
Move <VLAN-name> from selected list to available list.
Click Update

Once all the dependencies are removed, then the VLAN can be deleted. Make sure you are on the right partitions.

Additional Information

Sometimes you want to delete certain VLANs in your environment which are no more in use - Orphan configurations. The above steps can be used to find the configuration files where the objects you are looking for.

grep -r <enter-the-string-to-search-for> .

With the above command you can search for a string in all directories. The -r is used as a recursive function and the . at the end is to search all directories.
