K000149567: Troubleshooting ERR_CONNECTION_RESET after changing VIP Advertisement on XC Load Balancer

Updated

Applies to

Description

    You want to restrict traffic to only a specific region. After implementing this change, you need to verify if the modification results in an ERR_CONNECTION_RESET error.

    Environment

    • F5® Distributed Cloud HTTP Load Balancer

    Answer/Recommended Actions

    1. Verify DNS resolution:

      • Check if the new public VIP IP resolves correctly with the your domain.

      • If it does not resolve, proceed to the next step.

    2. Check the CNAME Record:

      • Confirm whether the CNAME of the Load Balancer correctly resolves to the new VIP.

    3. Perform a DNS Lookup:

      • Run a DIG command on the customer's domain to determine whether the DNS record is using an A record or a CNAME.

      • Example command:

        dig my-domain.com

    4. Update the DNS Record:

      • If the domain is using an A record, you have two options:

        • Manually update the A record to point to the new IP.

        • Recommended: Change the record to a CNAME pointing to the Load Balancer. This ensures future IP changes do not require manual updates.

    Following these steps should resolve the ERR_CONNECTION_RESET issue and ensure proper DNS resolution after modifying the VIP Advertisement on the XC Load Balancer.

    Cause

    When updating the virtual site to use a new public IP and modifying the VIP Advertisement, the ERR_CONNECTION_RESET error typically indicates that the customer has only configured an A record for their Load Balancer (LB) but has not added the corresponding CNAME entry.
