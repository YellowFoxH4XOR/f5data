Issue

Error Message

warning mcpd[<pid>]: 01071057:4: Configuration warning: This device does not support the requested 'cmp-hash' setting (<type>) in hardware. Performance may be limited.

In this error message, note the following:

  • <pid> is the process ID of the currently running mcpd process.
  • <type> is either src-ip for source address or dst-ip for destination address.

For example:

warning mcpd[5319]: 01071057:4: Configuration warning: This device does not support the requested 'cmp-hash' setting (src-ip) in hardware. Performance may be limited.

warning mcpd[5319]: 01071057:4: Configuration warning: This device does not support the requested 'cmp-hash' setting (dst-ip) in hardware. Performance may be limited.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions are met:

  • The Virtual Local Area Network (VLAN) Clustered Multiprocessing (CMP) hash setting is set to Source Address or Destination Address.
  • Your BIG-IP system does not support the hardware-based disaggregator (DAG).

BIG-IP 11.3.0 introduced an additional DAG for CMP hashing based on either source or destination addresses. This new DAG can be fully processed by Traffic Management Microkernel (TMM) in software, but newer BIG-IP systems include a hardware-accelerated DAG. In BIG-IP 11.4.0 and later, this warning message will display when a source or destination address DAG configuration is loaded on a BIG-IP system that does not support the hardware-accelerated DAG. In these instances, the BIG-IP system will revert to the software-based DAG.

Note: CMP Hash Source Address and Destination Address options are not supported in vCMP guests.

BIG-IP platforms that support the hardware accelerated DAG include the following:

  • 4450 blade
  • 4300 blade
  • B2100 blade
  • B2150 blade
  • B2250 blade
  • BIG-IP 10000 series
  • BIG-IP 7000 series
  • BIG-IP 5000 series

For more information about BIG-IP disaggregators, refer to the Clustered Multiprocessing: Changing the Rules of the Performance Game white paper.

Impact

Performance may be limited when using the software-based DAG on heavily-loaded systems.

Recommended Actions

If your configuration requires a high volume of source/destination CMP hashing, F5 recommends that you consider a hardware upgrade to a device that supports hardware-accelerated DAG.
