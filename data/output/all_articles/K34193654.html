Known Issue

BIG-IP configurations containing an invalid Address Resolution Protocol (ARP) entry may fail to load.

This issue occurs when the following condition is met:

  • The BIG-IP ARP table contains an entry with an IP address that is unreachable.

Impact

The configurations fail to load, making the BIG-IP system unreachable.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After a reboot, the BIG-IP configurations fail to load.
  • The BIG-IP system logs messages to the /var/log/ltm file that appear similar to the following example:

    err mcpd[8689]: 01070711:3: Caught runtime exception, 'Cannot get route for dest 1.1.1.1 in rd0 - netlink error: 101 (Network is unreachable)' - rolling back...
    err mcpd[8689]: 01070712:3: Caught configuration exception (0), Cannot get route for dest 1.1.1.1 in rd0 - netlink error: 101 (Network is unreachable).
    err mcpd[8689]: 01070734:3: Configuration error: Current folder /foo has been removed. Exit session.
