Topic

The Switch Card Control Processor (SCCP) is an embedded Linux system. The SCCP does not keep log files in non-volatile storage. As a result, log files are lost whenever the SCCP is shut down or rebooted.

When the SCCP boots, it begins logging with the Unix epoch date stamp, January 1, 1970, which is the default system date. The SCCP will log using the January 1, 1970, date stamp until the SCCP is able to synchronize the time and date with the host system.

The SCCP runs the ntpdate utility to synchronize its time and date with the host system during the boot process, and again on the hour, every hour through a cron job. If the SCCP fails to synchronize the time and date with the host system during the boot process, the SCCP will attempt again every hour, on the hour. Once the time and date have been synchronized, the logs will indicate the current date.
