Known Issue

This is the result of a known issue. The GRUB menu does not display on the console after a power cycle for the following platforms running BIG-IP version 10.1.0:

  • BIG-IP 1600 (C102)
  • BIG-IP 3600 (C103)
  • BIG-IP 3900 (C106)

The issue occurs because the BIOS on the above platforms initializes on the host, and passes control of the boot process to the GRUB bootloader before the AOM has fully booted, and before the AOM's serial console redirection feature is fully operational. This results in the GRUB menu not being printed to the user's terminal.

Note: Appliances released from manufacturing after December 23, 2009 are not subject to this issue.

F5 Product Development tracked this issue as ID 242705 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, or WOM release notes.

Workaround

You can work around this issue by allowing the system to boot fully to the default BIG-IP installation. You can then log into the command line and reboot the system using the reboot command. The reboot command does not power cycle the system, allowing the GRUB menu to be displayed as expected.
