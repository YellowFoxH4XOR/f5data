K000151350: F5OS default key length of self signed certificate key

Published

Source

Description

This document describes about default key length of self-signed certificate key.

Environment

F5OS

Cause

By default, F5OS uses a self-signed certificate and key for device management.

The default key length of the self-signed certificate key is 4096 bit.

Recommended Actions

None

None
