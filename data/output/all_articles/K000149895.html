Description

When integrating Cisco DUO OIDC with BIG-IP APM with Edge Client version 7.2.3.1 or later, a JavaScript error occurs in the Edge Client mini browser during authentication. The error message displayed is:

Object doesn't support property or method 'addEventListener'.

This issue was fixed in Edge Client version 7.2.3.1 or later as per Bug ID 1047501 but you are still seeing the error.

Environment

  • BIG-IP APM
  • Duo prompt
  • JavaScript Error

Cause

The issue is related to how the DUO prompt interacts with the Edge Client mini browser on specific environments. This was fixed in BIG-IP Edge Client version 7.2.3.1.  This issue does not occur when using an external/default browser for the same authentication process. F5 was unable to reproduce this issue reliably, it may occur due to unknown specific customer environments.

Recommended Actions

Workaround Using External Browser for Authentication: Configure the BIG-IP Edge Client to use an external/default browser for authentication instead of the mini browser. Refer to K000141526: "BIG-IP Edge Client Windows uses default browser for authentication" for detailed steps.
