Description

  • Allow voice communication using Skype in a non-default route domain

Environment

  • APM
  • VoIP
  • Skype

Cause

  • APM does not support Skype or VoIP technology deployment in a non-default route domain environment 

Recommended Actions

  • VoIP technology must be deployed in route domain 0 following article K16680: VoIP through Network Access connections

  • None
