Description

Webpage is not loading when ASM policy is applied, even in transparent mode.

Browser shows a connection reset occurred.

Environment

  • HTTP profile with Response Chunking set to Preserve
  • ASM policy
    • Feature enabled that injects JavaScript

Cause

ASM is injecting JavaScript into the server's chunked response, while not updating the chunk size field in the HTTP chunks, due to the HTTP profile's response-chunking preserve configuration. This causes the browser to reset the connection.

Recommended Actions

Configure Response Chunking to Selective in the HTTP profile. This will ensure that chunked responses are re-chunked when sending the modified response to the client.

Additional Information

For more information about HTTP chunking, refer to:

  • K5379: Overview of HTTP chunking

Selective
Specifies that the system unchunks the HTTP content, processes the data, re-adds the chunk headers, and then sends the chunked request or response to the client.
