Description

Addition of RMA unit results in an Active-Active situation.

Verified connectivity between failover IPs, but system always returns to Active shortly after being made Standby.

Environment

  • HA
  • After RMA replacement
  • Or adding a new device

Cause

Network Failover is disabled on the Sync-Failover Device Group.

cm device-group /Common/dg-failover {
    devices {
        /Common/ltm01.com { }
        /Common/ltm02.com { }
    }
    full-load-on-sync true
    network-failover disabled               <---
    type sync-failover
}

A BIG-IP system detects the failover status of the peer exclusively using the serial cable in this situation, so log messages similar to the following may be observed:

notice sod[7214]: 010c006d:5: Leaving Standby for Active (best load): Serial:.

If no serial cable is present, then an Active-Active situation will occur.

Recommended Actions

Enable Network Failover in the Sync-Failover Device Group.
