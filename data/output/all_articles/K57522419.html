Issue

Old Behavior

In versions prior to BIG-IP 11.5.0, if a Secure Sockets Layer (SSL) profile is configured to request or require a remote certificate, the following certificates are advertised:

  • The certificate configured in the Trusted Certificate Authorities setting for the Client SSL or Server SSL profile
  • The certificate configured in the Advertised Certificate Authorities setting for the Client SSL profile

New Behavior

Beginning in BIG-IP 11.5.0 and later, if an SSL profile is configured to request or require a remote certificate, the certificate configured in the Trusted Certificate Authorities setting is not advertised to the client or server during the SSL connection, and only the certificates in the Advertised Certificate Authorities setting are advertised.

F5 Product Development tracked this change as ID 247958.

Impact

The certificates configured in the Trusted Certificate Authorities setting are not included in the certificate chain sent by the BIG-IP system.

Recommended Actions

If you want to include certificates for verification during the SSL handshake, you can configure the certificates in the chain certificate setting instead of the Trusted Certificate Authorities setting. To configure SSL chain certificates, refer to K13302: Configuring the BIG-IP system to use an SSL chain certificate (11.x - 12.x).
