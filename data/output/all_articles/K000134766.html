Description

While updating the URL option within an Address Space profile, the APM returns an error "invalid data received".

Environment

  • APM
  • 16.1.x and up
  • Address Space profiles
  • Zoom or Office 365 customized
The WebUI for Access Policy > Connectivity/VPM > Network Access (VPN) > Address Spaces > [Address Space Name] reports "Status: Failed, Error: Error in creating data message for provider /Common/<address-space-name>. Reason: invalid data received".

Cause

The text format of the URL is incorrect.

Recommended Actions

Correct the format of the custom URL file. Refer to the default example from Zoom or Office365 for reference.

Additional Information

apm resource address-space /<custom-address-space-name> {
   cfg-uri https://example.com/docs/ipranges/<custom>.txt
   discovery-interval 10080
   ipv4 { 1.1.1.1/32 ... 9.9.9.9/32 }
   last-discovery-time 2023-05-26 12:09:00
   trusted-ca-bundle /Common/ca-bundle.crt
   type zoom
}
