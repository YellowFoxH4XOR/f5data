K63407506: Config Sync Status changes to ''Change Pending'' with no reason due to AVR daemon produces a core file.

Applies to

Source
https://my.f5.com/manage/s/article/K63407506

Description

The BIG IP may produce an avrd core file and the status of Configsync changes to "Changes Pending" without any action performed.

  • The Configsync status show "Changes Pending"
  • There is a core file for the avrd daemon under /var/core
  • There are the following messages on /var/log/avr/avrd.log at the same time the core file was produced :
AVRD_CONFIG|NOTICE|Feb 25 11:04:07.815|30634|lib/avrpublisher/infrastructure/avr_mcp_msg_parser.cpp:2988| Modified Analytics Global Settings, added "0" offbox TCP addresses A

Environment

  • You have an HA pair

Cause

The Analytics global-settings are updated either explicitly, using a tmsh command, or implicitly, by an internal process script.

F5 Product Development has assigned ID 749461 to this issue Recommended Actions

Recommended Actions

There is no workaround.
