K000140985: APM SAML IdP error "Error matching requested NameID format"

Type
Support Solution
Published
2024-09-18
Updated
2024-09-18
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000140985

Description

APM SAML IdP dumps this error after receiving the SAML Auth request from SAML SP

 

"SAML SSO: Error matching requested NameID format"

Environment

  • BIG-IP provisioned with APM
  • APM deployed as SAML IdP

Cause

SAML Auth request received by APM SAML IdP contains 'NameIDPolicy' element

 

<samlp:NameIDPolicy AllowCreate="true" Format="urn:oasis:names:tc:SAML:1.1:nameid-format:persistent"/>

 

APM supports SAML v2.0
SAML v2.0 standard (saml-core-2.0-os, Ch 8.3.7) states that Persistent Identifier URI is "urn:oasis:names:tc:SAML:2.0:nameid-format:persistent"
 
Base on SAML V2.0 standard, APM rejects SAML Auth request due to wrong NameID format.

Recommended Actions

SAML SP must be fixed with right Persistent Identifier URI in SAML v2.0

Additional Information

https://docs.oasis-open.org/security/saml/v2.0/saml-core-2.0-os.pdf
