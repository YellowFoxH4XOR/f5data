K70360852: GUI not available after upgrade

Type
Support Solution
Published
2020-07-14
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K70360852

Description
After installing over the top of a previous version, the Management GUI is inaccessible while SSH access works, which shows prompt may show named being restarted.

Environment

  • SSH access works.
  • Shell prompt may show logger[1234]: Re-starting named
  • bigstart start httpd fails

Cause
Bug ID 759564: GUI not available after upgrade

Recommended Actions

Perform one of next:

- Boot back in previous volume to install in a brand new volume:

  1. Boot back to the previous boot volume
  2. Delete the boot volume containing the failed install
  3. Install the software on a new boot location
  4. Boot to other newly installed boot location

- Alternatively next can be done in the affected volume: 

1. Login to tmsh
2. Restore httpd modules with the next commands: 

# restorecon -Rv /usr/lib/httpd/modules/
# httpd -k start
# bigstart status httpd

Note: Command bigstart status httpd should show httpd up


3. Create a new named file and copy content of the original one to the new one:
# mv /var/named/config/named.conf /var/named/config/named_bak.conf
# touch /var/named/config/named.conf
# cp -n /var/named/config/named_bak.conf /var/named/config/named.conf
# bigstart stop named
# bigstart start named
