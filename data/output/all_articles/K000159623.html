K000159623: AS3 Per-Application Deployment Does Not Apply SNAT Translation Timeout Parameters

Type
Support Solution
Published
2026-01-20
Updated
2026-01-20
Applies to

  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000159623

Description

When deploying AS3 declarations using the per-application API endpoint, SNAT Translation timeout parameters are not applied to the BIG-IP configuration. Specifically, the following parameters in the SNAT_Translation class are not being set:


ipIdleTimeout

tcpIdleTimeout

udpIdleTimeout


 Environment

  • BIG-IP LTM version 17.1.3 and 17.1.2.1
  • AS3 version 3.55.0 and earlier
  • Per-application deployment
  • AS3 declaration containing SNAT_Translation class with timeout parameters:
    • ipIdleTimeout: 120
    • tcpIdleTimeout: 300
    • udpIdleTimeout: 60

Cause

Bug in AS3 version 3.55.0 and earlier: The per-application deployment API endpoint failed to properly apply SNAT_Translation timeout parameters (`ipIdleTimeout`, `tcpIdleTimeout`, `udpIdleTimeout`) to the BIG-IP configuration objects, even though AS3 correctly stored these values internally. This was a code defect specific to the per-app deployment path that did not affect standard AS3 declarations.

Bug ID 2197113 has been created for this code defect


 

Answer/Recommended Actions

The official fix will be on AS3 version 3.56.0 which will be released tentativley in Feburary 2026 at the time of publishing this article
