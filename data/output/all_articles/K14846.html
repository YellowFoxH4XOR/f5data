Topic

Summary

FirePass does not support Windows 8.1, and F5 has no future plans to add support for Windows 8.1. F5 support for Internet Explorer 11 on Windows 7 is available in a maintenance release of FirePass. For more information, refer to K17404: FirePass support for Internet Explorer 11.

F5 recommends that FirePass customers migrate to the BIG-IP APM system at their earliest convenience. For information about the FirePass End of Sale notice, refer to K13366: End of Sale announcement for FirePass.

Description

FirePass does not currently support clients running either the Windows 8.1 operating system or Internet Explorer 11.

Impact

FirePass may not correctly detect clients running Windows 8.1 or Internet Explorer 11. This situation may cause the following issues:

  • FirePass client operating system detection may not correctly detect the Windows 8.1 operating system.
  • FirePass client-type detection may not correctly detect Internet Explorer 11.
  • You cannot upgrade the Windows 8.1 installed F5 components.
  • The standalone BIG-IP Edge Client may not install correctly on devices running Windows 8.1.
