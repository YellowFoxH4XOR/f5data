K000160476: Observing "Is not part of allowed Keyx list" message when attempting to commit system security changes on rSeries

Type
Support Solution
Published
2026-03-26
Updated
2026-03-30
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.8.X, 1.8.3, 1.8.0, 1.5.4, 1.5.3, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000160476

Description

When attempting to modify cryptographic parameters for the SSH service on rSeries devices, following the instructions in the article below:

  •  K000139008: Managing the list of ciphers and MAC and Key Exchange algorithms used by the SSH service on the VELOS or rSeries systems.

An error message similar to the following may be observed when attempting to commit the changes:

Aborted: 'system security services service sshd': rijndael-cbc@lysator.liu.se Is not part of allowed Keyx list

Environment

  • Modifying ciphers, MACs or key exchange algorithms
  • F5OS confd CLI

Cause

Cryptographic parameters can only be set to supported values, and this is validated during the commit phase. In the example above, the error indicates that that 'rijndael-cbc@lysator.liu.se' is not a supported key exchange algorithm on the F5OS system

Recommended Actions

Use only supported cryptographic settings and parameters. To view a list of supported key exchange algorithms on the version of F5OS in use, you can use the command line completion function:

For example:

R2600(config)# system security services service sshd config kexalgorithms [ <hit tab or ?>
Possible completions:
  [ diffie-hellman-group1-sha1 diffie-hellman-group14-sha1 diffie-hellman-group14-sha256 diffie-hellman-group16-sha512 diffie-hellman-group18-sha512 diffie-hellman-group-exchange-sha1 diffie-hellman-group-exchange-sha256 ecdh-sha2-nistp256 ecdh-sha2-nistp384 ecdh-sha2-n
istp521 curve25519-sha256 curve25519-sha256@libssh.org gss-gex-sha1- gss-group1-sha1- gss-group14-sha1- ]
  ]

Additional Information

These options can also be configured in the System Security page via the WebUI, but this page is not available in F5OS-A 1.5.x.
