K000090850: Unable to on board NGINX instance onto NGINX Instance Manager

Type
Support Solution
Published
2021-11-03
Updated
2026-07-30
Source
https://my.f5.com/manage/s/article/K000090850

Description

  • You want to manage your NGINX Plus and Nginx instances from NGINX Instance Manger \[NIM\]
  • You installed NGINX Instance Manger
  • You also downloaded the right NGINX-agent package and installed it
  • But the agent fails to run and logs the below error in /var/log/nginx-agent/nginx-agent.log file

Nov 22 07:55:15 example .com systemd\[1\]: nginx-agent.service: main process exited, code=exited, status=1/FAILURE
Nov 22 07:55:15 example .com systemd\[1\]: Unit nginx-agent.service entered failed state.
Nov 22 07:55:15 example .com systemd\[1\]: nginx-agent.service failed.
Nov 22 07:55:17 example .com rc.local\[1321\]: oswbb heartbeat:Tue Nov 22 07:55:17 CDT 2021
Nov 22 07:55:20 example .com systemd\[1\]: nginx-agent.service holdoff time over, scheduling restart.
Nov 22 07:55:20 example .com systemd\[1\]: Stopped nginx-agent.

Environment

  • NGINX Instance Manager
  • NGINX Agent
  • NGINX Plus

Cause

The NGINX instance manager, /etc/nginx-manager/nginx-manager.conf file has missing bind_address

Recommended Actions

  • Using a text editor modify /etc/nginx-manager/nginx-manager.conf file on NGINX instance manager and update the bind_address
    • vi etc/nginx-manager/nginx-manager.conf
  • Modify bind_address and change it to the Linux instance IP address in which NIM running on
  • Save the changes to the file
  • Restart nginx-manager service
    • sudo systemctl restart nginx-manager
