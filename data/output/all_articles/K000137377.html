K000137377: ASM Blocking Page is not shown, or shows a blank page

Type
Support Solution
Published
2023-11-28
Updated
2023-11-28
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.1.X, 17.1.1
Source
https://my.f5.com/manage/s/article/K000137377

Description

 

BIG-IP ASM event log have been generated for the blocking in local logging, but no ASM blocking page is shown on browser or  blank page with no content is displayed on the client-side browser.

Environment

  • ASM or AWAF module provisioned with version running BIG-IP v17.x
  • Issue occurred after upgrade to BIG-IP v17.x
  • ASM Policy with Blocking settings enabled
  • An ASM violation occurred and led to blocking event
  • ASM blocking page is not shown or blank page is shown on browser

 

Cause

Unknown

 

Recommended Actions

As a temporary workaround to resolve this problem, you can run the below command to restart the asm service.

Impact of workaround: Restarting the asm process causes the BIG-IP ASM system to fail over to the remaining members of the device group.
 

# tmsh restart sys service asm

If still issue occurs even after asm restart and generate a qkview file and open a support case. For more information, refer to the following articles:

  • K000090853: Exchange files with F5 Support using MyF5
  • K12878: Generating BIG-IP diagnostic data using the qkview utility
