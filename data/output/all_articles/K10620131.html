Known Issue

When a DNS lookup connection to a disabled nameserver fails, it causes the Traffic Management Microkernel (TMM) to restart.

This issue occurs when the following condition is met:

  • A DNS lookup tries to connect to a nameserver that cannot be reached.

    An explicit RESOLV::lookup command used in an iRule, internal BIG-IP APM process, or HTTP process can trigger the DNS lookup.

Impact

A TMM restart disrupts traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • TMM restarts in response to a DNS lookup to a disabled nameserver.

Workaround

To prevent this behavior from occurring, verify connectivity to the nameserver and refrain from using the RESOLV::lookup command in iRules.
