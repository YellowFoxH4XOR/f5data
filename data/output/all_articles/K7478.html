Topic

To create self-signed client certificates, you must perform the following four procedures:

  • Configuring the FirePass controller as a Certificate Authority (CA) by installing a self-signed client root certificate
  • Issuing a self-signed client certificate to an internal FirePass user
  • Configuring the master group to require a valid self-signed client certificate
  • Enabling the client certificate request on a web service

Configuring the FirePass controller as a CA by installing a self-signed client root certificate

To configure the FirePass controller as a CA using a self-signed client root certificate, perform the following procedure:












  1. Log in to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Security.
  4. Click Certificates.
  5. Under Install Client Root Certificate and CRL, click Self-Signed Certificate.
  6. Enter the certificate information.
For example: Common Name: ClientRootCert Country Name: US State: Washington City: Seattle Company: Your Company Organizational Unit: IT Contact Email: it@siterequest.com Expiration: 1 year Key Size: 2048 bits Encryption Password: mypass Confirm Password: mypass Note: The Confirm Password field does not appear in FirePass version 5.4. Also, the Key Size field only appears in FirePass versions 6.0.0 and later.
  • Click the Generate Certificate button. A screen displays the information you entered in step 6.
  • At the bottom of the screen, click the word here in the sentence that reads Click here to download your new self-signed client root CA certificate and private key.
  • Download the file and save it in a secure location.
  • Save the certificate by performing one of the following two options, depending on the version of FirePass software you are running:
    • FirePass versions 5.5 and later: Click the Save Certs button
    • FirePass version 5.4: click the Save button
  • Click the Click here to restart link.

    Note: You can restart the FirePass services at a later time by clicking the Restart Services link located on the Device Management: Maintenance: Restart Services page.

  • Click the Restart button.

    • The FirePass reloads as a CA that can generate self-signed client certificates.

    Issuing a self-signed client certificate to an internal FirePass user

    To issue a self-signed client certificate to an internal FirePass user, perform the following procedure:

    1. Log in to the FirePass Administrative console.
    2. Click Users.
    3. Click the Edit button next to the user who will receive a client certificate and take note of the user's master group.
    4. Optional: You can fill the OU value of the client certificate with the user's master group name noted in step 3. If the check box is cleared, the client certificate OU value defaults to the OU value of the Client Root Certificate. To populate the client certificate OU value with the users master group, select the Fill Organization Unit (OU) name with FirePass group name (master group name) check box.
    5. Click the New Client Certificate button at the bottom of the page. The user's certificate information is now displayed under the Client Certificate section.
    6. You have the option to email the client certificate to the user, or download the client certificate.
      • Option 1: Email the client certificate and installation instructions to the user:
        Click the E-Mail Client Cert Package button.
      • Option 2: Download the client certificate:
        Enter a password next to Encryption Password.
        Re-enter your password if prompted.
        Click the Download button to download the certificate.

        Note: In FirePass version 5.4.2, clicking the Download button brings you to another screen. Click the word here in the sentence that reads Click here to download your new PKCS#12 client certificate package. Download the file, and then click the Done button.

    7. Install the client certificate on the user's web browser. When prompted for a password, use the encryption password you entered when you created the client certificate.

      Note: For information about installing client certificates, refer to the user's web browser documentation.

    Configuring the master group to require a valid self-signed client certificate

    To configure a master group to require a valid self-signed client certificate, perform the following procedure:

    1. Log in to the FirePass Administrative console.
    2. Click Users.
    3. Click Groups.
    4. Click Master Groups.
    5. Under Group Name, click the user's master group.
    6. Click the Authentication tab.
    7. Select the check box next to Require client certificate for user logon.
    8. In the Required client certificate issuer drop-down menu, select the Common Name for the self-signed client root certificate you created earlier.

      For example:

      ClientRootCert

    9. Click the Update button.

      All users in that master group must now supply a valid client certificate in addition to their logon credentials in order to logon to the FirePass system.

    Enabling the client certificate request on a web service

    Beginning in FirePass version 6.0.2, a new feature is included to allow per VHOST client certificate authentication.

    For more information on understanding a VHOST client certificate request, refer to the FirePass Controller Administrator guide for your version of FirePass.

    On FirePass version 6.0.2 and later, the following procedure enables the request client certificate option on the web service. 

    1. Click Device Management.
    2. Click Configuration.
    3. Click Network Configuration.
    4. Click the Web Services tab.
    5. Click Configure next to the SSL-enabled web service that will service the users logins, using passwordless authentication with certificates.
    6. Select the Request Client Certificate check box.
    7. Click the Update button.

    For information about detecting client certificates in a pre-logon sequence, refer to K7479: Detecting client certificates in a pre-logon sequence.

    For information about passwordless authentication on FirePass 6.0.1 and earlier, refer to K7481: Configuring passwordless authentication using client certificates.

    For information about passwordless authentication on FirePass 6.0.2 and later, refer to K8392: Configuring passwordless authentication using client certificates.
