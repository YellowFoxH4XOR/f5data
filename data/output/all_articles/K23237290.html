Description

Deploying BIG-IP on Google Cloud Platform fails with this error found in /var/log/boot.log

error: 01070903:3: Constraint 'hostname must contain less than 65 characters' failed for '/Common/system'

Environment

  • Terraform deployment
  • deploying BIG-IP into Google Cloud Platform (GCP)
  • using github scripts 

Cause

Character limitation set on the Base OS level. The GCP hostname is set by DHCP which is a combination of the GCP deployment name, project name and the region.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Use shorter GCP deployment and project name to limit the hostname to less than 65 characters.
