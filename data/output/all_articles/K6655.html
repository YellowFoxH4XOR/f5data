Topic

Note: The procedure for performing a local installation changed in the BIG-IP 9.3.0 and 9.4.0 software branches. For information about removing an image using the local-install script for BIG-IP 9.3.x or 9.4.x, refer to K8678: Using the local install IM package to remove an image installed on a boot image slot.

To remove an image installed on one of the boot image slots, use a BIG-IP 9.1.1 through 9.2.5 local-install script to discard the image, by performing the following procedures:

  • Boot the BIG-IP system to an image that is not the image to be dele
  • Install the local-install IM package on the booted image
  • Run the local-install script and discard the image to be removed

Booting the BIG-IP system to an image that is not the image to be deleted

  1. Log in to the BIG-IP command line.
  2. Use the switchboot utility to select the image to which you would like to boot. This image is not the image that is to be deleted.

    Note: For information about using the switchboot utility to view images installed on the boot image slots, refer to K5658: Overview of the switchboot utility.

    Note: If the BIG-IP system is already booted to an image which is not the image to be deleted, do not perform step 3.

  3. Boot the BIG-IP to the selected image, by typing the following command:

    reboot

Installing the local install IM package on the booted image

Install the local-install IM package that supports the booted version, in accordance with the installation instructions in the Local Installation section of the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator Release Notes.

The release notes provide a link to the Local Installation document for your specific BIG-IP version. A local-install IM package is available for BIG-IP 9.1.1 and later for the BIG-IP 9.1 software branch, and BIG-IP 9.2 and later for the BIG-IP 9.2 software branch.

Note: The local install IM package installed must support an upgrade from the version that is currently booted into the system. For example, if the currently booted version is BIG-IP 9.2, you would not install the BIG-IP 9.1.1 local install IM package; you would instead install the BIG-IP 9.2 or later local install IM package.

Running the local-install script and discarding the image to be removed

Note: You will not actually be performing an upgrade during the following procedure.

  1. Log in to the BIG-IP command line.
  2. Run the local-install script, by typing the following command:

    local-install

  3. From the BIG-IP Welcome screen, select Continue.
  4. From the BIG-IP Copyright screen, select Continue.
  5. From the BIG-IP Install screen, select Yes to continue.
  6. From the BIG-IP Syslog Configuration screen, select OK.

    Do not enter an IP address or host name for a remote syslog server.

  7. From the BIG-IP Installation Server screen, select No.

    Do not select another installation URL or path.

  8. From the BIG-IP Boot Image Configuration screen, highlight the boot image location you want to discard, and select OK.
  9. From the BIG-IP Configuration screen, highlight Discard Installation and select OK.
  10. From the BIG-IP Boot Image Configuration screen, highlight Done and select OK
  11. From the BIG-IP Boot Option screen, highlight the boot image location, press the Spacebar, and then select OK.

    The BIG-IP will boot from the selected boot image location after the system reboots once you have completed this procedure.

  12. From the BIG-IP Summary screen, select Continue.
  13. From the BIG-IP Install screen, select Yes.

The local-install script will remove the image to be discarded and reboot the BIG-IP system.
