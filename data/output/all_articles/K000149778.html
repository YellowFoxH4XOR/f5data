K000149778: How do I collect debug logs for Kubernetes CE site?

Type
Support Solution
Published
2025-02-13
Updated
2025-02-13
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
  • F5 Distributed Multi-Cloud Network Connect
Source
https://my.f5.com/manage/s/article/K000149778

Description

A Kubernetes site is created and there's a need to collect debug logs to troubleshoot an issue.

Environment

  • Multi-Cloud Network Connect
    • Kubernetes Site
    • Site on a K8s

Cause

There's no debug collection mechanism for Kubernetes CE site.

Recommended Actions

Please execute the following commands and share the compressed ves-system-logs-<hostname>-YYYYMMDDTtimeZ.tar.gz file with support.

# kubectl get pods -n ves-system -o jsonpath='{range .items[*]}{.metadata.namespace} {.metadata.name}{"\n"}{end}' | while read -r namespace pod; do   echo "Fetching logs for pod $pod in namespace $namespace";   kubectl logs -n "$namespace" "$pod" --all-containers=true > "${namespace}_${pod}.log"; done

# tar -czvf "ves-system-logs-$(hostname -s)-$(date -u +%Y%m%dT%H%M%SZ).tar.gz" -- *.log
