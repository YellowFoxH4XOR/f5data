K000150663: F5 BIG-IP VE instantiated through OpenShift Virtualization does not show MAC addresses assigned.

Type
Support Solution
Published
2025-04-01
Updated
2025-04-01
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150663

Description

When deploying BIG-IP Virtual Edition (VE) on OpenShift Virtualization, the virtual machine interfaces may not display MAC addresses, and the Traffic Management Microkernel (TMM) may enter a continuous restart loop. Relevant error messages observed in logs include:

Jan 12 00:00:00 bigipve.f5test.com notice virtio_mtu_set(): MTU should be between 68 and 1500
Jan 12 00:00:00 bigipve.f5test.com notice dpdk[0000:05:00.0]: Error: rte_eth_dev_set_mtu failed: err=-22
Jan 12 00:00:00 bigipve.f5test.com notice xnet[05:00.0]: Error: Command 0 failed: 5
Jan 12 00:00:00 bigipve.f5test.com notice xnet_lib [pci:0000:05:00.0]: Queue configuration complete (rx: 0/0 tx: 0/0)
Jan 12 00:00:00 bigipve.f5test.com notice xnet(1.4)[05:00.0]: Error: rx queue activation failed - cnt: 0 sz: 0
Jan 12 00:00:00 bigipve.f5test.com notice xnet(1.4)[05:00.0]: Waiting for tmm1 to reach state 4...
Jan 12 00:00:00 bigipve.f5test.com notice xnet_lib [pci:0000:05:00.0]: Error: Queues being cleared but not already configured
Jan 12 00:00:00 bigipve.f5test.com notice xnet_lib [pci:0000:05:00.0]: Error: Invalid queue configuration
Jan 12 00:00:00 bigipve.f5test.com notice xnet_lib [pci:0000:05:00.0]: Error: Queue configuration failed
Jan 12 00:00:00 bigipve.f5test.com notice xnet[05:00.0]: Error: Command 2 failed: 3

Additionally, the command ' tmctl -i tmm/device_probed ' output shows no drivers in use for the network interfaces.

Environment

  • BIG-IP VE
  • OpenShift 
  • KVM 

Cause

This is related to ID1492337

Recommended Actions

Run the workaround to create /config/tmm_init.tcl with the MTU between 68 and 1500 MTU.  

ndal mtu <MTU> 1af4:1041

For example:

ndal mtu 1474 1af4:104121

None.
