Known Issue

This is the result of a known issue. FirePass versions 6.1.0 and earlier do not support the Network Access feature on Linux distributions using 64-bit kernels.

F5 Networks Product Development is tracking this issue as CR56612.

Starting FirePass version 7.0.0, some versions of Linux have been qualified by F5 Networks on 64-bit platforms. For a full list of qualified Operating Systems, reference the Compatibility Matrix. For information about upgrading, refer to the FirePass Release Notes.

Workaround

To bypass this issue, you can use the 32-bit version of your browser.

Important: FirePass does not support all 64-bit browsers; use of a 64-bit browser may result in unexpected behavior.
