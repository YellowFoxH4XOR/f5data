Known Issue

If you modify a Secure Sockets Layer (SSL) profile's certificate and key pair, multiple SSL certificate and key pairs may become associated with the SSL profile on a high availability (HA) peer device.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP systems in an HA configuration.
  • Your configuration includes one or more virtual servers with an associated client SSL profile.
  • You have performed at least one full configuration synchronization (ConfigSync) to the HA peer devices.
  • You create or import a new SSL certificate and key pair.
  • You perform the following modifications to one or more client SSL profile:
    • Select the box to allow editing of Certificate Key Chain option.
    • Select the currently associated SSL certificate and key object.
    • Select Edit and choose the new SSL certificate and key from the Certificate and Key options.
  • Perform a full ConfigSync to the peer HA devices.

Note: This issue occurs because both the new and existing SSL certificate / key pairs are associated with the SSL profile on remote BIG-IP HA peers.

Impact

The BIG-IP system may process SSL connections using the wrong SSL certificate and key pair.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice that client SSL connections are being processed with the wrong SSL certificate and key pair.
  • You notice some BIG-IP systems in an HA configuration have multiple SSL certificate and key pairs associated with a client SSL profile.

Workaround

To work around this issue, you can set the BIG-IP system device group to incremental sync, delete and recreate the client SSL profile with the new SSL certificate and key pair, and then perform a ConfigSync operation. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure impacts how secure connections are processed, and you should perform the procedure only during a maintenance window.

  1. Log in to the Configuration utility of the BIG-IP system.
  2. Set the device group to incremental sync, as follows:
    1. Navigate to Device Management > Device Groups.
    2. Under Group Name, select the device group name used to synchronize the configuration.
    3. Ensure the Full Sync and Automatic Sync options are cleared.
    4. Click Finished.
  3. Remove the SSL profile from the virtual server, as follows:
    1. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
    2. Under Name, select the virtual server.
    3. In the SSL Profile (Client) section, select the existing SSL profile under the Selected window.
    4. Move the client SSL profile to the Available window using the >> icon.
    5. Click Update.
  4. Delete the client SSL profile, as follows:
    1. Navigate to Local Traffic > Profiles > SSL > Client.
    2. Under Name, select the box next to the profile.
    3. Click Delete.
  5. Perform a ConfigSync operation, as follows:
    1. Navigate to Device Management > Overview.
    2. Under Device Groups, click the name of the device group used to ConfigSync.
    3. Under Devices, click the name of the local BIG-IP system indicated with (Self).
    4. Under Sync Options, ensure Push the selected device configuration to the group is selected.
    5. Click Sync.
  6. Create a new SSL profile, as follows:
    1. Navigate to Local Traffic > Profiles > SSL > Client.
    2. Click Create.
    3. Select the Custom box.
    4. Configure the new SSL using the new SSL certificate and key. 
    5. Click Finished.
  7. Add the SSL profile to the virtual server, as follows:
    1. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
    2. Under Name, select the virtual server.
    3. In the SSL Profile (Client) section, select the new SSL profile under the Available window.
    4. Move the new client SSL profile to the Selected window using the << icon.
    5. Click Update.
  8. Perform a ConfigSync operation, as follows:
    1. Navigate to Device Management > Overview.
    2. Under Device Groups, click the name of the device group used to ConfigSync.
    3. Under Devices, click the name of the local BIG-IP system indicated with (Self).
    4. Under Sync Options, ensure Push the selected device configuration to the group is selected.
    5. Click Sync.
