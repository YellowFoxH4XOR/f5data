Security Advisory Description

Unspecified vulnerability in Oracle Java SE 6u101, 7u85, and 8u60; Java SE Embedded 8u51; and JRockit R28.3.7 allows remote attackers to affect integrity via unknown vectors related to Security. (CVE-2015-4872)

Impact

A remote attacker may affect the integrity of the system through unknown vectors.

F5 Product Development has assigned INSTALLER-1946 (Traffix) to this vulnerability, and has evaluated the currently supported releases for potential vulnerability.
