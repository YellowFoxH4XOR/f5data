BIG-IP DNS (formerly known as BIG-IP GTM) ZoneRunner character support for DNS zone and resource record names is in accordance with RFC1034 and RFC1035. The ZoneRunner utility supports names containing the following values:

Configuring the BIG-IP DNS system to accept underscore characters ( _ ) in wide IP names and A or AAAA records earlier than BIG-IP 12.1.0 requires additional configuration. For more information, refer to K14926: Configuring the BIG-IP DNS system to accept underscore characters.

  • Alpha characters a through z
  • Numeric characters 0 through 9
  • The dash character ( - )
  • The underscore character ( _ )
  • The wildcard character ( * )

Note: When configuring your BIG-IP DNS system with a resource record that uses a wildcard, use the asterisk character ( * ) to represent the wildcard character.

If you attempt to configure a DNS zone or resource record name that contains an unsupported character, the system displays an error message. For example, if you try to create a zone named example^domain.com, the system displays an error message similar to the following example:

0107137a:3: DNS Zone name (example^domain.com) is not a valid domain name or contains invalid characters (see RFC 1035).

Note: Character support for BIND configurations may include other characters.
