Description

You're using BIG-IP APM API Protection profiles.

And the application is making use of "websocket".


Environment

  • BIG-IP APM API Protection profile

Cause

Such setup is supported but it may require further configuration.


Recommended Actions

We'd need to update the configuration of the Virtual Server with:

  • Configuration: choose "Advanced"
  • WebSocket Profile (Client): choose "websocket" (or any custom profile you may have created);
  • WebSocket Profile (Server): choose "(use client profile)" (or any custom profile you may have created).
