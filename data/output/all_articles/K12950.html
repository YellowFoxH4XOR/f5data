Known Issue

Description

After installing FirePass 7.0.0 HF-70-3, a Citrix web portal favorite or Citrix terminal server will not display the Citrix application icons.

This issue occurs when all of the following conditions are met:

  • FirePass 7.0.0 with hotfix HF-70-3 is installed
  • A Citrix web portal favorite or Citrix terminal server is defined

Impact

Users will be unable to launch applications through the Citrix web portal or Citrix terminal server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When accessing the Citrix web portal favorite or Citrix terminal server no application icons will display.

Status

Workaround

To work around this issue, you can remove hotfix HF-70-3 from the FirePass controller. To do so, perform the Removing a hotfix procedure in K3430: Installing FirePass hotfixes.

Impact of workaround: Removing HF-70-3 will remove any other fixes that are addressed by the hotfix. In addition, uninstalling the hotfix will automatically restart the controller and FirePass services will be unavailable during the restart.
