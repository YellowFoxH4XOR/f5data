Description

SSL handshake may fail while using SSL Client Certificate Constrained Delegation (C3D)

  • SSL handshake failure during Client Certificate authentication step
  • Error message in /var/log/ltm similar to 
    tmm1[33161]: 01260009:4: Connection error: ssl_shim_vfycerterr:4060: certificate revoked (44)

Environment

  • You are using Client Certificate Authentication with OCSP verification in client SSL profile
  • You are using Client Certificate Constrained Delegation feature (C3D) in client SSL profile
  • Revoked certificate was replaced with valid one recently

Cause

The client certificate's serial number is not acquired correctly causing wrong data cached in OCSP status cache due to bug ID892485

Recommended Actions

Open a case with F5 Technical Support to get engineering hotfix

None
