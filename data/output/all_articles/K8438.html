Topic

RSA SecurID is a two-factor authentication scheme that uses a combination of a known password and a digitally generated string to grant access to the FirePass controller. For more information about RSA SecurID authentication, refer to the FirePass Controller Administrator Guide.

To configure RSA SecurID Authentication on a FirePass failover pair, perform the following two procedures:

  • Configuring the Agent Host record on the RSA Server
  • Configuring RSA SecurID Authentication on a FirePass failover pair

Configuring the Agent Host record on the RSA Server














  1. Add the FirePass controller as an Agent Host.

    For example:
Name: firepass.siterequest.com Network address: <virtual IP address of the FirePass failover pair or NAT translated IP address> Important: Because the FirePass controller is a multi-homed appliance with multiple IP addresses, the Network address setting is very important. If there is a NAT device between the FirePass controller and the RSA authentication server, enter the translated IP address of the FirePass controller. If there is not a NAT device between the FirePass controller and the RSA authentication server, enter the virtual IP address configured on the FirePass failover pair. If you have multiple interfaces configured on the FirePass controllers, enter the virtual IP address of the interface “closest” to the RSA authentication server. gent type: Unix Agent Encryption Type: DES Secondary Nodes: <real IP addresses of the FirePass controllers> Important: If there is a NAT device between the FirePass controller and the RSA authentication server, you do not need to configure the Secondary Nodes setting. If there is not a NAT device between the FirePass controller and the RSA authentication server, enter the real (non-virtual) IP address of each FirePass controller. If you have multiple interfaces configured on the FirePass controllers, enter the real IP address of the interface “closest” to the RSA authentication server. Other settings: For the remaining Agent Host settings, configure the settings appropriate for your environment.
  • Generate and download the configuration file for the FirePass Agent Host you just created.

    Note: This configuration file is typically named sdconf.rec.
  • Activate the FirePass Agent Host on the user and group profiles that require access to the FirePass controllers.

    • Configuring RSA SecurID Authentication on a FirePass failover pair

    1. Log in to the active FirePass controller.
    2. Navigate to the Failover: Settings page.

      If any synchronization errors are reported, resolve those issues before proceeding to the next step.
    3. Navigate to the Users: Groups: Master Groups page.
    4. Click the Create new group button.
    5. In the New group name field, enter the name of the new Master Group.
    6. In the Users in group field, select Local or External.
    7. In the Authentication Method menu, select RSA SecurID.
    8. Click the Create button.

      This brings you to the Master Group configuration page.
    9. Click the Authentication tab.
    10. Click the Configure a new RSA SecurID Server link.
    11. In the Name field, enter a name to identify your RSA server. This name is for local use and does not need to be DNS resolvable.

      For example:

      rsasrv1
    12. In the Configuration File field, enter the full path to the Agent Host configuration file you downloaded in Step 2 of the Configuring the Agent Host record on the RSA Server procedure.

      For example:

      C:\sdconf.rec
    13. In the Source IP field, enter the IP address you configured for the Network address setting on the RSA authentication server.

      Important: RSA authentication will not work unless the IP address you enter in this field matches the IP address you entered for the Network address setting in Step 1 of the Configuring the Agent Host record on the RSA Server procedure.
    14. Click the Add button.
    15. Navigate to Users: Groups: Master Groups
    16. Click on the RSA SecurID link next to the Master Group you created.
    17. Click the Update button.

    The FirePass failover pair is now configured for RSA SecurID authentication. The settings you configured on the active FirePass controller are automatically synchronized to the standby FirePass controller.
