Known Issue

The Configuration utility may not display the correct expiry date of the renewed default SSL certificate and key pair.

This issue occurs when all of the following conditions are met:

  • You renew the default SSL certificate (default.crt) and key (default.key), by following the procedure in the article: K13579: Generating new default certificate and key pairs for BIG-IP SSL profiles.
  • You view the default SSL certificate and key details using the Configuration utility.

Impact

Instead of displaying the updated expiry date of the renewed default SSL certificate key pair, the system displays the previous expiry date.

Note: You can safely ignore this issue; the system will process network requests using the renewed default certificate and key with the correct expiry date when you select them in an SSL profile.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system displays the previous expiry date when you use the Configuration utility to view the default SSL certificate and key.

Resolution

Workaround

To work around this issue, you can force the mcpd process to reload the configuration by following the procedure in the article: K13030: Forcing the mcpd process to reload the BIG-IP configuration.

Impact of workaround: The suggested procedure requires that you reboot the BIG-IP system. If the BIG-IP system is the active member of a redundant system, rebooting will cause a failover. If the BIG-IP system is a standalone unit, rebooting will interrupt traffic processing. F5 recommends that you perform this procedure during a maintenance window.
