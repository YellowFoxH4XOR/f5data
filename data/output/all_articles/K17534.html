Known Issue

The BIG-IP system may fail to redistribute Equal Cost Multipath (ECMP) routes to the Traffic Management Microkernel (TMM).

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP system licensed with BIG-IP Advance Routing Module (BIG-IP ARM).
  • You configure your BIG-IP system to use Open Shortest Path First (OSPF).
  • You add multiple Equal Cost Multipath (ECMP) default routes to the OSPF configuration.

Impact

TMM routes traffic using one of the default routes instead of across the multiple ECMP default routes.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The OSPF routing table lists multiple nexthop addresses for the default route, but the TMM routing table lists only one nexthop address.
  • The TMM route table does not contain multiple ECMP default routes.
