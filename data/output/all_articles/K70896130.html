Known Issue

The BIG-IP system may determine the wrong HTTP version for fragmented HTTP responses.

This issue occurs when all of the following conditions are met:

  • The HTTP response is fragmented.
  • The HTTP version field spans multiple packets.

When parsing the HTTP header of a fragmented HTTP response, if the HTTP version field is fragmented and spans multiple packets, the HTTP version may be parsed incorrectly. Typically, the response is detected as an HTTP/0.9 response rather than an HTTP/1.0 or HTTP/1.1 response.

Impact

The detected HTTP version for fragmented HTTP responses may be incorrect.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The detected HTTP version of fragmented HTTP responses may be incorrect. Typically, the response is detected as an HTTP/0.9 response rather than an HTTP/1.0 or HTTP/1.1 response.
  • The system may not perform BIG-IP functions that rely on the HTTP version, or decisions that rely on the HTTP version may not function as expected.
  • The affected HTTP application traffic may not be processed or function as expected.
