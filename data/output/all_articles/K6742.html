Known Issue

This is the result of a known issue. The BIG-IP LTM TCP proxy can ignore pipeline requests for the httpclass pool. The BIG-IP LTM TCP proxy currently disconnects the server-side flow after the response is forwarded to the client. As a result, the BIG-IP LTM system can ignore the next pipeline request.

F5 Product Development tracked this issue as CR68835, CR69125, and CR69170 and it was fixed in version 9.2.4. For information about upgrading, refer to the BIG-IP LTM or ASM Release Notes.
