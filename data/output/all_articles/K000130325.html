Description

The BIG-IP SSL device certificate is not able to modify/remove the SHA-1 fingerprint

Environment

- SSL BIG-IP Device Certificate

Cause

This is not an issue. A certificate's fingerprint is the unique identifier of the certificate, Browsers tend to display it as if it were a part of the certificate. It is not a part of the certificate, but it is computed from it.

Recommended Actions

No action is needed. The fingerprinting is calculated by the browser or other end entities, therefore, the BIG-IP is not able to change or remove the SHA-1 fingerprint.

Additional Information

This article is only related to fingerprints, the fingerprint is different than the certificate signature Algorithm, which can be changed by

K16507: The device certificate is generated using the SHA-2 hash algorithm (11.5.0 and later)
