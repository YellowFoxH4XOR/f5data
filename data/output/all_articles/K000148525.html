K000148525: How can I disable 'Illegal cross-origin' false positives occurring after the upgrade?

Type
Support Solution
Published
2024-11-13
Updated
2024-11-13
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.5, 17.1.1
Source
https://my.f5.com/manage/s/article/K000148525

Description

False positives for 'Illegal cross-origin request' are being triggered and blocking requests after upgrading to the latest version of BIG-IP, despite having the same security policy configurations as the previous version. 

Environment

  • BIG-IP
  • ASM
  • False positive alerts and blocking for Illegal cross-origin request

Cause

BUG ID 1284097

Recommended Actions

If you have already upgrade to a fixed version for BUG ID 1284097 and are still encountering the issue with Illegal cross-origin request then implement the following steps 

1. Log in to the BIG-IP command line and execute update the following commands.

/usr/share/ts/bin/add_del_internal add cors_match_protocol_port 1

/usr/share/ts/bin/add_del_internal add cors_default_port_80 1

2. Restart the ASM service

tmsh restart sys service asm

Important: BIG-IP could experience a temporary traffic interruption due to the service restart.
