K6392: The Topology Record or Topology Region cannot be deleted if the Topology Region name contains the ampersand (&) character

Known Issue

You cannot delete a Topology Region if the Topology Region name contains the ampersand (&) character. An error message similar to the following example displays:

01020036:3: The requested GTM region (first) was not found.

Note: In this error message, (first) represents the portion of the Topology Region name before the ampersand (&) character. The Topology Region name in this example is first&last.

Additionally, you cannot delete a Topology Record if the associated Topology Region name contains the ampersand (&) character. For example, an error message similar to the following example displays when the Topology Region name selected is first&last:

01020036:3: The requested GTM top item (GTM_REGION_TYPE_REGION mcp_false first GTM_REGION_TYPE_CIDR mcp_false 172.25.33.0/24) was not found.

Note: In the previous error message, first is the portion of the Topology Region name before the ampersand (&) character.

F5 Product Development tracked this issue as CR63561. This issue does not occur in BIG-IP GTM 10.0.0 and later.

Workaround

To resolve this issue you must manually edit or delete the Topology Record and Topology Region.

To edit the Topology Record and Topology Region, perform the following procedure:

  1. Log in to the BIG-IP GTM command line.
  2. Create a backup of the original region.user file, by typing the following command:

    cp /config/gtm/region.user /config/gtm/region.user.orig

  3. Using a text editor, open the /config/gtm/region.user file.
  4. Edit the Topology Region name with the invalid character.

    For example, change the ampersand (&) character to the underscore (_) character.

  5. Save the file and exit the text editor.
  6. Create a backup of the original topology.inc file, by typing the following command:

    cp /config/gtm/topology.inc /config/gtm/topology.inc.orig

  7. Using a text editor, open the /config/gtm/topology.inc file.
  8. Edit the Topology Record with the invalid Topology Region name.

    For example, change the ampersand (&) character to the underscore (_) character.

  9. Save the file and exit the text editor.
  10. Load the new BIG-IP GTM configuration, by typing the following command:

    gtmload

  11. The gtmload command will provide output messages similar to the following example:

    gtmload: Initializing ...
    /usr/bin/monitors/builtins/gtm_base_monitors.conf: SUCCESS
    /usr/local/gtm/include/base_region.ISP: SUCCESS
    /config/gtm/region.user: SUCCESS
    /config/gtm/topology.inc: SUCCESS
    /config/gtm/wideip.conf: SUCCESS
    gtmload: SUCCESS

  12. If the new configuration fails to load successfully, review the modified files for errors, and repeat the gtmload command.

    Note: The Topology Record and Topology Region may now be deleted, if desired, using the BIG-IP GTM Configuration utility.
