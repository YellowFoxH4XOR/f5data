Known Issue

The BIG-IP system may incorrectly sync user accounts in sync-only device groups.

This issue occurs when one of the following conditions is met:

  • The BIG-IP system is configured to perform a full synchronization of the configuration data.

    Note: The ability to perform incremental synchronizations was added in BIG-IP 11.4.0, and is now the default behavior. However, you can still configure the system to perform full synchronization, instead.

  • A ConfigSync operation is performed using the Overwrite Configuration option from the Configuration utility. For more information, refer to K13920: Performing a ConfigSync using the Configuration utility.
  • A ConfigSync is performed using the tmsh set-sync-leader command option. For more information, refer to K13887: Forcing a BIG-IP device group member to initiate a ConfigSync operation.

Impact

User account passwords may be unexpectedly overwritten on devices within a sync-only device group.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You cannot log in to BIG-IP systems after a ConfigSync operation.

    Note: If you need to reset your BIG-IP system account passwords, refer to K13121: Changing system maintenance account passwords (11.x - 14.x).
