K000149127: Unable to restore license on BIG-IP via UCS that was assigned from BIG-IQ

Type
Support Solution
Published
2024-12-29
Updated
2025-02-07
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000149127

Description

If BIG-IP license was assigned from BIG-IQ, the license cannot be restored via UCS restore due to error similar to presented below:

# tmsh load sys ucs /var/local/ucs/bigip1.ucs

Oct 30 01:08:15 bigip1.local info tmsh[12801]: Begin config install operation: /var/local/ucs/bigip1.ucs
Oct 30 01:08:22 bigip1.local info install_ucs.pm[13274]: Install the license file from UCS onto the system.
Oct 30 01:09:37 bigip1.local info install_ucs.pm[13274]: UCS installation success.
Oct 30 01:09:49 bigip1.local err iprepd[18633]: 01180002:3: License validation error 298.
Oct 30 01:09:49 bigip1.local err iprepd[18633]: 01180010:3: [license processing][error]: license verification failed
Oct 30 01:09:49 bigip1.local err iprepd[18633]: 01180010:3: [license processing][error]: failed processing license management data

Oct 30 01:18:37 bigip1.local emerg mcpd[7272]: 01070608:0: License is not operational (expired or digital signature does not match contents).

Environment

  • BIG-IP 
  • BIG-IP license was assigned from BIG-IQ

Cause

If BIG-IP license was assigned from BIG-IQ, the license reactivation should be performed through webUI of BIG-IQ.

Recommended Actions

Please restore UCS with no-license option and re-assign the license from BIG-IQ like below.

  1. On BIG-IQ GUI, "Revoke" license from Source BIG-IP 
  2. On New BIG-IP, load ucs with "tmsh load sys ucs <ucs filename> no-license"
  3. On BIG-IQ GUI, "Assign" license to New BIG-IP
