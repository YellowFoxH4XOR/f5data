Known Issue

This is the result of a known issue. If the mcp daemon, mcpd, receives a partial MCP message, the result is an mcpd heartbeat failure.

The mcpd heartbeat failure is detected by the sod utility and results in a BIG-IP system failover.

F5 Product Development tracked this issue as CR73247 and it was fixed in BIG-IP 9.1.3, 9.3.0, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator release notes.
