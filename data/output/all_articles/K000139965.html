Description

User may notice duplicate ASM event log formats being sent to the remote syslog server. When ASM logging profile is configured on the BIG-IP ASM on the remote SIEM server we may notice duplicate entries of logs where one log shows the correct format and another log shows an incorrect format. Due to this issue, user may not be able to review ASM events on the SIEM server.

Environment

  • BIG-IP ASM
  • Remote Logging Profiles
  • Remote SIEM server
  • ASM Event logs

Cause

Issue is due to misconfiguration. 

 

Apart from ASM remote logging profile configurations, it also has local3 logging configured to forward ASM log messages to the same remote syslog server. This configuration will create duplicate logs in incorrect format on the SIEM server.

Recommended Actions

Remove the additional syslog configuration on BIG-IP that was sending local3 logs to the remote server. 

 

Impact of the procedure: Performing the following procedure should not have a negative impact on your system

1. We can verify the existing syslog configuration using the below command:  

#tmsh list sys syslog all-properties

2. To remove the syslog server and filter configuration run the below command using tmsh.

#tmsh modify sys syslog include none

3. Save the configuration on the system

#tmsh save sys config
