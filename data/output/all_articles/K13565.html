Topic

You should consider using these procedures under the following condition:

  • You want to enable request logging for the Configuration utility to the httpd SSL log files.

Description

In BIG-IP 9.x and 10.x, all HTTPS requests to the Configuration utility are logged to the /var/log/httpd/ directory. Beginning in BIG-IP 11.0.0, the system no longer logs these requests by default.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You are familiar with the Linux vi text editor.

Procedures

 

Important: Exercise caution when enabling HTTPS logging on devices receiving many requests to the iControlREST API. If you perform any of the following procedures, each API request generates one or more access logs. This may cause the system to write a large number of logs to disk and may impact the stability of your system. 

  • Enable HTTPS logging for the BIG-IP system (11.2.x and later)
  • Disable HTTPS logging for the BIG-IP system (11.2.x and later)
  • Enable HTTPS logging for the BIG-IP system (11.0.0 through 11.1.x)
  • Disable HTTPS logging for the BIG-IP system (11.0.0 through 11.1.x)

Enable HTTPS logging for the BIG-IP system (11.2.x and later)

In BIG-IP 11.2.x and later, you can enable HTTPS logging using the following TMOS Shell (tmsh) procedure. The system generates HTTPS logs to the /var/log/httpd/ssl_access_log and /var/log/httpd/ssl_request_log files.

Impact of procedure: Performing the following procedure can cause the system to generate a large number of logs, which may impact system stability.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Change the log level by entering the following command:

    modify sys/ syslog local6-from info

  3. Save the changes to disk by entering the following command:

    save sys/ config

Disable HTTPS logging for the BIG-IP system (11.2.x and later)

To disable HTTPS logging, you can set the log level back to notice using the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Change the log level by entering the following command: 

    modify sys/ syslog local6-from notice

  3. Save the changes to disk by entering the following command:

    save sys/ config

Enable HTTPS logging for the BIG-IP system (11.0.0 through 11.1.x)

The following tmsh procedure enables logging to the ssl_access_log and ssl_request_log files in the /var/log/httpd directory.

Impact of procedure: Performing the following procedure can cause the system to generate a large number of logs, which may impact system stability.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Edit the syslog configuration file by entering the following command:

    edit /sys syslog all-properties

  3. Replace the line that states include none with the following lines of text:

    Note: Be sure to include all of the following text exactly as shown. F5 recommends that you cut and paste the text.

    include "
    log {
    source(s_syslog_pipe);
    source(s_httpd);
    filter(f_local6_httpd_ssl_acc);
    destination(d_httpd_ssl_acc);
    };

    log {
    source(s_syslog_pipe);
    source(s_httpd);
    filter(f_local6_httpd_ssl_req);
    destination(d_httpd_ssl_req);
    };
    "

  4. Exit the vi editor and save by entering the following command:

    :wq!

  5. When prompted to save your changes, enter Y.
  6. Save the changes to disk by entering the following command:

    save sys/ config

  7. Exit tmsh by entering the following command:

    quit

Disable HTTPS logging for the BIG-IP system (11.0.0 through 11.1.x)

To disable logging, you must reverse changes from the previous procedure. To do so, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Delete the following lines of text that you inserted from step 3 of the previous procedure:

    include "
    log {
    source(s_syslog_pipe);
    source(s_httpd);
    filter(f_local6_httpd_ssl_acc);
    destination(d_httpd_ssl_acc);
    };

    log {
    source(s_syslog_pipe);
    source(s_httpd);
    filter(f_local6_httpd_ssl_req);
    destination(d_httpd_ssl_req);
    };
    "

  2. Replace the deleted text with the include none statement.
