Topic

You can view the following interface statistics using the netstat command:

  • Interface Index (Index)
  • MAC Address (Address)
  • Inbound Packets (Ipkts)
  • Inbound Errors (Ierrs)
  • Outbound Packets (Opkts)
  • Outbound Errors (Oerrs)
  • Collisions (Coll)
  • Dropped Frames (Drop)

To view these statistics, perform the following steps:

  1. Log in to the command line.
  2. Type the following command:

    netstat -nsi

    The output will appear similar to the following:

    Name   Index   Address        Ipkts  Ierrs Opkts  Oerrs  Coll  Drop
exp0*   1   00:01:d7:1c:5d:80   0      0     0      0      0     0
bsg2    6   00:01:d7:1c:5d:ba   0      0     0      0      0     0
bsg3    7   00:01:d7:1c:5d:bb   0      0     0      0      0     0
bs0    12   00:01:d7:1c:5d:a0   0      0     0      0      0     0
bs1    13   00:01:d7:1c:5d:a1   0      0     0      0      0     0

    The counters display from the last reboot and may contain residual values. If you are troubleshooting interface errors, run the command several times over a period of 10 to 30 minutes and monitor the Ierrs and Oerrs error counters to see if they are incrementing. A healthy link has no incrementing Ierrs.
