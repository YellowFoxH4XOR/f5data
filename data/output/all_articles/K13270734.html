Known Issue

Changing the default header background color in the access policy has no effect on the ACL Deny page.

This issue occurs when the following condition is met:

  • You change the default header background color in the page header settings for an access policy.

You can use the Advanced Customization view to personalize the pages associated with an access policy. When you modify the header background color for the page header settings, the ACL Deny pages for that access policy do not display the new color.

Impact

The change in color is not reflected in the ACL Deny page presented to users.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Color changes to the header background color take affect for the Logon page, but not for the ACL Deny page.
  • Users view a white header background when presented with ACL Deny pages, regardless of customizations.
