Known Issue

This is the result of a known issue. If you select the Disable Database Logging check box on the Device Management: Maintenance: Logs page, FirePass ignores the concurrent logon limit you configured on the Device Management: Security: User Access Security page.

Note: If the concurrent logon limit is set to the default value of Unlimited, you will not be affected by this issue.

F5 Networks Product Development tracked this issue as CR89353 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative hotfix HF-602-1 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by performing the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Maintenance: Logs page.
  3. In the Logging Options section, clear the Disable Database Logging check box.
  4. Click the Apply Changes button.
