Description

When publishing a configuration from NIM that includes a WAF configuration and policy, it may fail with the following error or similar:

(nginx_instance): Config apply failed (write): error running nginx -t -c /etc/nginx/nginx.conf:

error running nginx -t -c /etc/nginx/nginx.conf:
{
"completed_successfully": false,
"event": "configuration_load_failure",
"error_message": "Failed to read /etc/nms/NginxDefaultPolicy.tgz: open /etc/nms/NginxDefaultPolicy.tgz: permission denied",
"error_line_number": 27,
"softwareVersion": "5.10.0",
"componentVersions": {
"wafEngineVersion": "11.583.0",
"wafNginxVersion": "5.550.0"
}

Environment

NGINX Instance Manager

F5 WAF for NGINX

Cause

The user defined in the NGINX configuration on the NGINX instance does not have permissions to access directory /etc/nms

Recommended Actions

Ensure the user defined in the NGINX configuration has permissions to access directory /etc/nms. For example, the default user within the NGINX configuration file, /etc/nginx/nginx.conf, is nginx. The default group that owns /etc/nms, set by NGINX Agent, is nginx-agent.

$ getent group nginx-agent
nginx-agent:x:1001:root,nginx

If the user defined within the NGINX configuration is not present in the NGINX Agent group that owns /etc/nms, then add it. For example:

$ sudo usermod -aG nginx-agent nginx
