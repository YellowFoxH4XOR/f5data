K11027: Import will fail for a directory using a reserved DOS device name

Topic

If the ARX system attempts to import a directory using a reserved DOS device name, the import will fail with error messages logged to syslog that appear similar to the following example:

:DNAS_IMPORT-1-3-IMPORT_FIND_FILES_CIFS_ERROR:: CIFS find-files failed for directory '/PathA/PathB/CON' on share FP-01-MASTER (\\10.10.5.1\ARX-1 <file://\\10.10.5.1\ARX-1> [42]), Error: 'STATUS_ACCESS_DENIED'.

:DNAS_IMPORT-0-3-MSG3:: failed to enumerate directory, "/PathA/PathB/CON" -213, share FP-01-MASTER (\\10.10.5.1\ARX-1 <file://\\10.10.5.1\ARX-1> [42])

Files or directories using a reserved DOS device name should be renamed before an import is performed.

The following list contains known reserved DOS device names: 

  • CON
  • PRN
  • AUX
  • CLOCK$
  • NUL
  • COM0
  • COM1
  • COM2
  • COM3
  • COM4
  • COM5
  • COM6
  • COM7
  • COM8
  • COM9
  • LPT0
  • LPT1
  • LPT2
  • LPT3
  • LPT4
  • LPT5
  • LPT6
  • LPT7
  • LPT8
  • LPT9
