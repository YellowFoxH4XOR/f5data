K000132421: Impossible to perform backup F5OS

Type
Support Solution
Published
2023-02-06
Updated
2023-02-28
Applies to
  • F5OS
  • F5OS-A: 1.3.X, 1.2.X, 1.3.1, 1.3.0, 1.2.0
Source
https://my.f5.com/manage/s/article/K000132421

Description

After setting snmp configuration, unable to take configuration backup.

 

GUI shows

Failure for data/openconfig-system:system/f5-allowed-ips:allowed-ips/allowed-ip=snmp/config API. The server or an underlying service is unreachable.

Hide Details

error-message : Failure for data/openconfig-system:system/f5-allowed-ips:allowed-ips/allowed-ip=snmp/config API. The server or an underlying service is unreachable.

original-error : Request failed with status code 500

 

in /var/F5/F5/system/log/platform.log

Core-helper.Appliance: priority="Err" msgid="0x6501000000000001" msg="Core dumped on Appliance" process="underdog" location="/var/shared/core/container/core.system_control.underdog.<ID>.core.gz"

 

you have similar to the below bad config, which has no IP address:

system allowed-ips allowed-ip my_bad_allowed_ip         <<----- this is the cause.
!
system allowed-ips allowed-ip my_good_allowed_ip       <<----- this is good config
 config ipv4 address x.x.x.x
 config ipv4 prefix-length xx
 config ipv4 port xxx
!

 

Environment

  • F5OS-A
  • v1.2.x-1.3.x
  • rSeries
  • config backup
  • snmp

Cause

Bug ID 1194073

Recommended Actions

remove allowed-ips entry without any IP address.

su admin  #      <---- this is only when you are not logged in to CLI as admin

config
no system allowed-ips allowed-ip <object_name_for_bad_allowed_ip>
commit and-quit

then go to bash mode (log in to CLI as root)

docker restart system_control
