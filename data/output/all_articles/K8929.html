Known Issue

This is the result of a known issue. The configsync process may fail if the same profile name is used for different profile types on systems in the redundant pair.

For example, if you create an FTP profile named test_prof on one system in the redundant pair, and a FastL4 profile named test_prof on the peer system, the configsync process will fail between the units, and the following error message will be displayed on the configsync page in the Configuration utility:

BIGpipe: profile creation error:
01070293:3: The profile name <profile_name> is already assigned to another profile.

F5 Product Development is tracking this issue as CR101301.

Note: The BIG-IP version 9.4 software branch is not affected by this issue.
