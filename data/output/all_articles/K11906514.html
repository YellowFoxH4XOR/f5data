Known Issue

The BIG-IP system fails to process traffic on Virtual Local Area Networks (VLANs) configured to use IEEE 802.1 QinQ, also known as double tagging.

This issue occurs when the following condition is met:

  • You configure one or more VLANs on the BIG-IP system to use double tagging.

    Note: You can configure double tagging on the BIG-IP system using VLAN > General Properties > Customer Tag.

Impact

The BIG-IP system fails to process application traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptom:

  • F5 iHealth lists Heuristic H709892 on the Diagnostics > Identified > High page.
  • Application traffic fails on VLANs configured with Customer Tag.

Workaround

To work around this issue, you can disable Large Receive Offload (LRO). To do so, perform the following procedure:

Impact of workaround: Performing the following procedure may increase CPU usage. For more information about LRO, refer to K15609: Overview of TCP Segmentation Offload and Large Receive Offload.

  1. Log in to the TMOS shell (tmsh) by typing the following command:

    tmsh

  2. To disable LRO, type the following command:

    modify sys db tm.tcplargereceiveoffload value disable

  3. To save the configuration, type the following command:

    save sys config
