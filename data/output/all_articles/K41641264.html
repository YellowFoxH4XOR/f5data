Description

Carriage return does not add newline in BIG-IQ Script field

Environment
  • BIG-IQ 7.x/8.x

Cause

This issue is caused by bug ID960201

Recommended Actions

Workaround is to use a text editor to create/edit the script, then paste it into the Script field in BIG-IQ.
