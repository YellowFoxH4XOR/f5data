Known Issue

This is the result of a known issue. System logs viewed through the Configuration utility display the incorrect timezone and timestamp after the Daylight Saving Time change.

This issue is cosmetic and does not affect system performance. This issue only occurs when the log files are viewed from the Configuration utility. When viewed from the command line, the log files display the correct timezone and timestamp information.

F5 Networks Product Development tracked this issue as CR76567 and it was fixed in versions 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, or Link Controller Release Notes.
