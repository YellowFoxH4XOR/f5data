Known Issue

This is the result of a known issue. A user cannot log on to the BIG-IP Configuration utility if the user password contains a plus (+) character.

Note: SSH is unaffected by this issue. If the user has terminal access, the user will able to log on through SSH using a password containing a plus character.

F5 Product Development tracked this issue as CR129134 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

Workaround

No workaround exists for this issue. However, if you are locked out of the Configuration utility as a result of this issue, perform the following procedure to the change the password of the administrative user:

  1. Log on to the command line as the root user.
  2. To change the admin password, type the following command:

    f5passwd admin
  3. You will be asked to enter a new password twice. Choose a password that does not contain a plus character.
