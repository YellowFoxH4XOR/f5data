Known Issue

The BIG-IP system reassembles fragmented Internet Control Message Protocol (ICMP) packets, regardless of how the Reassemble IP Fragments setting is configured.

This issue occurs when all of the following conditions are met:

  • Large fragmented ICMP packets pass through the BIG-IP system.
  • The FastL4 profile Reassemble IP Fragments option is not selected.

Impact

Applications that expect a fragmented ICMP packet receive an unfragmented ICMP packet, which may cause unexpected behavior.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system unexpectedly reassembles fragmented ICMP packets.
