K50015119: Chassis fan speed is returned as 0 via SNMP on iSeries platform

Type
Support Solution
Published
2023-08-29
Updated
2023-08-29

  • BIG-IP

  • BIG-IP i5000 Series

  • BIG-IP i15000 Series

  • BIG-IP i10000 Series
Source
https://my.f5.com/manage/s/article/K50015119

Description

Chassis fan speed is returned as 0 via SNMP on iSeries platform.

For example, when querying the fan speed locally via SNMP:

# snmpwalk -c public localhost sysChassisFanSpeed
F5-BIGIP-SYSTEM-MIB::sysChassisFanSpeed.1 = Gauge32: 0
F5-BIGIP-SYSTEM-MIB::sysChassisFanSpeed.2 = Gauge32: 0
F5-BIGIP-SYSTEM-MIB::sysChassisFanSpeed.3 = Gauge32: 0
F5-BIGIP-SYSTEM-MIB::sysChassisFanSpeed.4 = Gauge32: 0

Environment

  • BIG-IP

  • i2000, i4000, i5000, i7000, i10000 iSeries platforms

Cause

Bug ID 712067

Recommended Actions

It is not possible to query the chassis fan speed via SNMP on the affected platforms.

You may use the following command to check fan speed.

# ipmiutil sensor | grep -i fan
0007 SDR Full 01 01 20 a 04 snum 2a Fan_0 = 60 OK 9600.00 RPM
0008 SDR Full 01 01 20 a 04 snum 2b Fan_1 = 64 OK 10000.00 RPM
0009 SDR Full 01 01 20 a 04 snum 2c Fan_2 = 60 OK 9600.00 RPM
000a SDR Full 01 01 20 a 04 snum 2d Fan_3 = 60 OK 10000.00 RPM
