Known Issue

Users cannot configure the Variable Assign action for BIG-IP Edge Gateway policies.

This issue occurs when the following conditions are met:

  • The BIG-IP Edge Gateway device is running 11.1.0 HF9 or HF10.
  • A user attempts to use the Configuration utility visual policy editor to create or modify an access policy to include the Variable Assign entry.

Impact

The user cannot add an entry to the Variable Assign action.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When a user attempts to add an entry to the Variable Assign action, the visual policy editor does not respond.
