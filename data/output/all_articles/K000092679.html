K000092679: Cannot configure VLAN Tagging in rSeries Tenant

Type
Support Solution
Published
2022-11-21
Updated
2025-12-18
Source
https://my.f5.com/manage/s/article/K000092679

Description


When trying to assign VLAN as 'tagged' to a Tenant interface, this error will pop up (interface 0.1 for example):

01020036:3: The requested vlan_member (/Common/Test 0.1) was not found

Environment

・BIG-IP rSeries r5000/r10000 platform
・BIG-IP VELOS platform

Cause

Trying to assign a 'tag' to VLANs in Tenant

Recommended Actions

Do not try to create a VLAN or tag a VLAN in the Tenant. VLANs are created in the F5OS. We only need to add the VLAN to an interface. The tagging is handled in F5OS.

Additional Information

None.
