Environment

  • BIG-IP
  • VE
  • CPU usage
  • Number of core

Cause

  • your system is using a license prior to 2014.

Recommended Actions

To check the number of CPUs allowed, run the below command on the CLI

tmsh show sys license detail | grep perf_VE_cores

If you are running a new license, the command output should appear similar to the following example:

'perf_VE_cores [12]'

If so, contact your usual Sales and renew license
or
chage the number of core in hypervisor level.
