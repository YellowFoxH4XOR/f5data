Known Issue

If a BIG-IP LTM monitor configuration has a custom string that ends with a backslash character, the saved configuration fails to load.

This issue occurs when all of the following conditions are met:

  • You have either a recv, send, or recv-disable monitor parameter that ends with a backslash.
  • You save the configuration.

For example, the send string in the monitor configuration in the bigip.conf file looks like the following example:

send "GET / Connection: close\r\n\r\n\"

Impact

The BIG-IP system remains inoperable and does not pass any traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP configuration fails to load.
  • The BIG-IP system remains in an inoperable state.

Workaround

To work around this issue, you can avoid ending custom strings with a backslash.
