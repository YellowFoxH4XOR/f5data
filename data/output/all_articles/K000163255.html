K000163255: Devices show "Disconnected" after upgrade when ConfigSync uses the management IP

Type
Support Solution
Published
2026-09-08
Updated
2026-09-10
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000163255

Description

  • After upgrade to v17.1.3.4, v17.5.1.8 or v21.1.0.1 devices show "Disconnected" even if they are on the same software version.
  • /var/log/ltm contains peer certificate verification errors referring to a self-signed certificate
  • the devices remain in "Disconnect" state even after rolling back to previous boot location
  • Messages like the those below are logged in /var/log/ltm:

Jan 1 01:01:01 bigip.domain notice mcpd[7950]: 01071432:5: CMI peer connection established to 10.10.10.1 port 6699 after 0 retries
Jan 1 01:01:01 bigip.domain warning tmm1[18774]: 01260006:4: Peer cert verify error: self signed certificate in certificate chain (depth 2; cert /CN=Root CA)
Jan 1 01:01:01 bigip.domain warning tmm1[18774]: 01260009:4: 10.10.10.1:4353 -> 127.1.1.2:55996: Connection error: ssl_shim_vfycerterr:4610: alert(48) self signed certificate in certificate chain
Jan 1 01:01:01 bigip.domain warning tmm1[18774]: 01260013:4: SSL Handshake failed for TCP 10.10.10.1:4353 -> 127.1.1.2:55996
Jan 1 01:01:01 bigip.domain notice mcpd[7950]: 0107143c:5: Connection to CMI peer 10.10.10.1 has been removed

Environment

  • BIG-IP systems in a high availability configuration where ConfigSync is configured to use the management IP address on both devices (the database variable that allows ConfigSync over the management address is enabled)
  • Upgrade to v17.1.3.4, v17.5.1.8 or v21.1.0.1

Cause

Changes to the file /shared/bin/big3d to fix other software defects unintentionally resulted in this new software defect. This is tracked as ID 2450009.

Answer/Recommended Actions

To fix the issue after rolling back to previous boot location run the commands below:

   bigstart stop big3d; rm -f /shared/bin/big3d; cp /usr/sbin/big3d /shared/bin/big3d; bigstart start big3d

You also have to run the above commands if you previously upgraded  to v17.1.3.4, v17.5.1.8 or v21.1.0.1 and then upgraded to v17.1.3.5, v17.5.1.9 or v12.1.0.2 .

If you have NOT YET upgraded to v17.1.3.4, v17.5.1.8 or v21.1.0.1, upgrade to either v17.1.3.5, v17.5.1.9 or v12.1.0.2 .
