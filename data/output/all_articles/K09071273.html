K09071273: Loading keys from the file. Cannot open unit key store.

Type
Support Solution
Published
2022-03-26
Updated
2026-07-14
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.1, 14.1.0
Source
https://my.f5.com/manage/s/article/K09071273

Description

After upgrade to v13.x or to 14.x prior to 14.1.0.2 the configuration does not load and error messages similar to the following are logged to /var/log/ltm:  

localhost.localdomain notice mcpd[8621]: 01071038:5: Loading keys from the file.
localhost.localdomain notice mcpd[8621]: 01071029:5: Cannot open unit key store
localhost.localdomain notice mcpd[8621]: 01071038:5: Loading keys from the file.
localhost.localdomain notice mcpd[8621]: 01071029:5: Cannot open unit key store.
 

Environment

  • BIG-IP
  • Upgrade
  • iSeries platforms
  • inoperative state

Cause

Bug ID 759403 fixed in 16.0.0.

Recommended Actions

  • Upgrade to 16.0.0
  • Direct upgrade from 13.1.1.4 to 14.1.0.2
