Topic

An auto MDI/MDIX port detects either a straight-through or crossover Ethernet cable connection type, and automatically configures the connection. This behavior eliminates the need for crossover cables when connecting LAN devices. When auto MDI/MDIX is enabled, you can use either type of cable connection, and the interface automatically establishes the link.

Note: BIG-IP 21.x is not supported on BIG-IP standard series, iSeries and VIPRION platforms. For more information, refer to K9476: The F5 hardware/software compatibility matrix.

Description

TMM interfaces

Auto MDI/MDIX functionality is retained when you manually configure an interface to use specific speed and duplex settings. Therefore, you can use either a straight-through cable or a crossover cable when media settings are forced, and you will be able to successfully link to either DTE or DCE devices.

In BIG-IP versions prior to 10.1.0, when you change a BIG-IP Traffic Management Microkernel (TMM) switch port from the auto-negotiate setting to a fixed speed and duplex mode, the port will lose the auto MDI/MDIX capability. Therefore, when the interface speed is manually set in BIG-IP versions prior to 10.1.0, you must use the proper cable connection type when connecting the interface to another switch or host. For example, for the F5 switch platforms noted in this article, F5 assumes that you use Data terminal equipment (DTE) wiring when the interface speed is fixed. As a result, when the interface speed is fixed, you should use an Ethernet crossover cable when connecting the port to a DTE device, such as a host.

Note: The TMM interfaces on iSeries platforms do not support disabling auto MDI/MDIX.

Management interface

BIG-IP platforms that support auto MDI/MDIX on the management (MGMT) interface, the Auto MDI/MDIX functionality is retained when you manually configure the MGMT interface to use specific speed and duplex settings.

Note: The MGMT interfaces on the 1500, 34XX, 6400, 6800, 8400, and 8800 platforms do not support auto MDI/MDIX. Additionally, the MGMT interfaces on iSeries platforms do not support disabling auto MDI/MDIX.

Failover serial port

The serial failover port does not support auto MDI/MDIX functionality.

Note: For the list of platforms that use a standard RJ-45 port as the failover interface, refer to K1426: Pinouts for the failover cable used with BIG-IP platforms.
