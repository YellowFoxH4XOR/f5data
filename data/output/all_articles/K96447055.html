Description

RestAPI calls fail with HTTP 401 remote host after upgrading from BIG-IP v15.1.6 to v15.1.6.1

  • Rest API calls suddenly start failing after upgrade.
  • Error shows "{"code":401,"message":"Authorization failed: no user authentication header or token detected....}"

Environment

  • BIG-IP LTM
  • Upgraded from BIG-IP v15.1.6 to BIG-IP v15.1.6.1
  • A restart of restjavad and restnoded doesn't fix the issue.

Cause

This is due to a known bug ID1146373

Recommended Actions

The workaround is to use token-based authentication for Rest API calls.
(OR)
If a fix is required, please open a case with the support team and request an Engineering Hotfix (EHF) for this bug.
