K000130550: Network map page stuck on loading after upgrade

Type
Support Solution
Published
2023-01-10
Updated
2023-01-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.2
Source
https://my.f5.com/manage/s/article/K000130550

Description

Network map page stuck on loading after upgrade when pool member name contains double portion of ports included

 

Example:

10.1.1.100:8080:8080

Note: All Virtual servers and objects are visible on Network map

Environment

  • BIG-IP Upgrade to versrion 15.x or above
  • Network Map under Local traffic reports Loading
  • Pool Member created with name ip:port:port

Cause

ID1223589

Recommended Actions

Workaround:

Recreate pool member to not contain syntax causing this issue

Additional Information

None
