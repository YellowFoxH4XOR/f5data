K000132265: BIG-IP devices not listed to deploy firewall rules

Type
Support Solution
Published
2023-01-26
Updated
2024-07-04
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0, 8.2.0, 8.1.0
Source

Description

When trying to deploy firewall policy using the Configuration utility path Configuration >> SECURITY >> Network Firewall >> Firewall Policies, no BIG-IP devices are listed.

Environment

  • BIG-IQ
  • AFM
  • Firewall policies

Cause

You can not see the BIG-IPs listed because you need to first provide a context to your firewall policy.

Recommended Actions

  1. Log in to the BIG-IQ webUI.
  2. Go to Configuration >> SECURITY >> Network Security >> Contexts.
  3. Select the name of the context object where you want to apply a firewall policy.
  4. Your firewall policies will appear at the Shared Objects: Firewall Policies section at the bottom.
  5. Select the firewall policy that you want to apply.
  6. Drag and drop the firewall policy to the appropriate option; Enforced Firewall Policy or Staged Firewall Policy. Alternatively, you can click on either the Add Enforced Firewall Policy or Add Staged Firewall Policy link; the BIG-IQ webUI will pop up a Select from Available Firewall Policies dialog listing the available firewall policies, select the firewall policy and click Add.
  7. Select Save & Close.
  8. Go to Configuration >> SECURITY >> Network Firewall >> Firewall Policies.
  9. Select the firewall policy you want to deploy and click on Deploy; if you now select Find Relevant Devices under the Target Device(s) section, you should be able to see the BIG-IP device(s) which you have set context in previous steps listed in the Available box.

Additional Information
