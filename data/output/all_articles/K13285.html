Topic

This article applies to BIG-IP 11.x - 16.x. For information about other versions, refer to the following article:

  • K5924: Support for WebDAV in a BIG-IP LTM HTTP profile (9.x - 10.x)

Web-based Distributed Authoring and Version (WebDAV) is a set of extensions to the HTTP/1.1 protocol specification that allows users to collaboratively edit and manage files on remote web servers.

Description

Since it coincides with the HTTP/1.1 standard defined in RFC2616, WebDAV functionality is supported using a virtual server with an HTTP profile applied. However, the BIG-IP HTTP profile does not currently support all request methods added in the WebDAV HTTP Extensions specification (RFC2518).

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

Supported WebDAV methods

  • DELETE
  • LOCK
  • UNLOCK
  • PROPFIND

Unsupported WebDAV methods

  • PROPPATCH
  • MKCOL
  • COPY
  • MOVE

Recommendations

For the BIG-IP system to successfully forward requests using unsupported methods, you may need to disable further HTTP processing for the request by applying an iRule to the virtual server. The DevCentral iRules codeshare contains an example iRule, which disables HTTP processing for the current request if the request uses specific request methods:

Disabling HTTP Processing For Unrecognized HTTP Methods on DevCentral.
