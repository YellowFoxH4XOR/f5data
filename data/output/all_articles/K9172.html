Known Issue

This is the result of a known issue. The Configuration utility does not display the configuration information of a Certificate Revocation List Distribution Point (CRLDP) profile after it has been created.

CRLDP profiles are located under Local Network: Profiles: Authentication: Profiles.

Note: This issue only affects the Configuration utility; you can still view CRLDP profiles using the command line.

F5 Product Development tracked this issue as CR99346 and it was fixed in BIG-IP LTM version 9.4.6. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP version 9.4.5, for the BIG-IP 9.4 software branch. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.
