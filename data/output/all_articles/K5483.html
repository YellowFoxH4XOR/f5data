Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K16165: Testing an HTTPS monitor with user authentication from the command line (11.x - 12.x)

You can test an HTTPS monitor from the command line using the interactive s_client utility. The s_client utility allows you to establish an SSL session with the member server you want to test.

The syntax for the s_client is similar to the following example:

openssl s_client -host <IP_Address> -port <Port>

Once the session is established, you are able to interactively type HTTP formatted requests. The HTTP formatted requests should be entered in the same format as in the send line of the monitor definition you created. Monitor definitions may be viewed in the /config/bigip.conf file or the output of the bigpipe list command. When entering the HTTP formatted request, replace the /n (newlines) with real newlines by pressing the Enter key. Terminate the HTTP request by pressing Enter on a blank line.

HTTPS Monitor definitions will appear similar to the following example:

monitor ssl_test {
# type https
use "https"
interval 5
timeout 16
dest *:*
send "GET /testpage.asp HTTP/1.0\nAuthorization: Basic dGVzdHVzZXI6dGVzdHBhc3N3b3Jk\n"
recv "matchthis"
username "testuser"
password "testpassword"
}

To test an HTTPS Monitor against a member 10.1.1.1:443, you would type the following s_client command and HTTP request:

openssl s_client -host 10.1.1.1 -port 443 <Enter>
GET /testpage.asp HTTP/1.0 <Enter>

Authorization: Basic dGVzdHVzZXI6dGVzdHBhc3N3b3Jk <Enter>
<Enter>

The receive string is defined in the monitor definition recv line. In the above example, the matchthis string is the desired receive string.

After typing the command, you would parse the HTTP response from the member to verify the desired receive string was present.

Additionally, if you configured the HTTPS monitor to use a client certificate, you can use the -cert and -key options to specify the client certificate and key. For example:

openssl s_client -host 10.1.1.1 -port 443 -cert /config/ssl/ssl.crt/<some-client-cert.crt> -key /config/ssl/ssl.key/<some-client-cert.key> <Enter>
GET /testpage.asp HTTP/1.0 <Enter>

Note: Replace <some-client-cert.crt> with the name of the client certificate file, and replace <some-client-cert.crt> with the name of the corresponding private key file.
