Known Issue

The TMM process may produce a core file and restart when processing DNS traffic.

This issue occurs when all of the following conditions are met:

  • A virtual server is configured with a UDP profile, DNS profile, and an iRule.
  • The associated UDP profile has Datagram LB disabled.
  • The associated iRule uses a suspending command (table command).
  • The virtual server and associated iRule processes traffic, which triggers a DNS event.

Impact

If the BIG-IP system is a member of a redundant configuration, traffic will fail over to the standby BIG-IP system. If the BIG-IP system is not part of a redundant pair, traffic will be interrupted until TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H510131 on the Diagnostics > Identified > Medium|High screen.
  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system fails over to another host in the device group.

Workaround

To work around this issue, you can enable the Datagram LB setting for the UDP profile. To do so, perform the following procedure:

Enabling the Datagram LB setting for the associated UDP profile

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > UDP.
  3. Click on the name of the affected UDP profile.
  4. To enable Datagram LB mode for the UDP profile, check the Datagram LB setting.
  5. To save the change, click Update.

If enabling the Datagram LB setting for the UDP profile is not appropriate for your particular environment, you can mitigate this issue by disabling DNS queuing.

Disabling DNS queuing

Impact of workaround: Performance may be significantly impacted by disabling DNS queuing.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Disable DNS queuing by typing the following command:

    modify sys db dns.queuing value disable

  3. Save the changes by typing the following command:

    save /sys config

  4. To exit tmsh, type the following command:

    quit
