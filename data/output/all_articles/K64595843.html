Description
vCMP guest may temporarly fail to send information to the vCMP host with error message similar to below in /var/log/ltm:
slot1/localhost info guestagentd[4858]: 01810007:6: Exit flags for PID 30469: 0x500

Environment

  • vCMP Guest
  • vCMP host has more than 4 vCMP guests

Cause

  • This message with exit status code of 0x500 is reported by RSYNC (invoked by guestagentd) when it is unable to setup the client-server protocol
  • These are logged when the vCMP host has existing RSYNC connections with four other vCMP guests while a fifth guest is attempting to establish an RSYNC connection
  • This issue is tracked in Bug ID 1036169

Recommended Actions

  1. If a fix is not available on a released version, please contact F5 Support to avail an engineering hotfix (EHF) on your preferred version
  2. Please note that the EHF only needs to applied to the vCMP host
  3. Please consult the K14088: vCMP host and compatible guest version matrix
  4. Follow the workaround steps listed below:
    • tmsh modify sys db vcmp.dynamic_rsync_conn_allowed value true
    • tmsh save sys config
Note: ???????If upgrading to a new version later on, a new EHF may need to be requested

Additional Information

  • On a vCMP system, guestagentd and hostagentd daemons communicate via an IP tunnel established over a shared memory interface
  • The information exchanged involves the use of RSYNC to push information to the vCMP host
