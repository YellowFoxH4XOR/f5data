Known Issue

Generating an Application Security report using the TMOS Shell (tmsh) may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured with partitions.
  • A virtual server in a non-default partition is configured with an application security policy.
  • The virtual server has processed traffic.
  • You log in to tmsh as an administrator.
  • You attempt to generate a BIG-IP Analytics Application Security report using partition-based entities.

Impact

The report generation fails and produces an error.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to generate a BIG-IP Analytics Application-Security report, the system displays an error message similar to the following:

    Data Input Error: Invalid entity value /<partition>/<security policy name>
