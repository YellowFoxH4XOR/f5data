K7499: The bigpipe platform command may display the chassis temperature as 0 (zero) degrees Celsius on BIG-IP 3400 platforms

Known Issue

This is the result of a known issue. Some BIG-IP 3400 platforms incorrectly display the chassis temperature as 0 (zero) degrees Celsius.

For example, the following output from the bigpipe platform command incorrectly displays the chassis temperature, indicated by (1), as 0degC:

# bigpipe platform
PLATFORM INFORMATION --
| Type: C62
| Chassis serial: bip073080s Level 200 part: 200-0116-05 REV C
| Switch board serial: PCA0063MF401 part: PCA-0063-05 REV A
| Host board serial: TY5AG0510415 part: MOB-0013-01 REV A
| Annunciator board serial: 1234563 part: OEM-0029-02 REV A
| BIOS Rev: AMIBIOS (C)2001 American Megatrends Inc., 
| Version 07.00.00 TYAN S2707 Motherboard v1.05a REV. F
|
base MAC 00:01:D7:32:07:80
|
| CPU 1 - temp 48degC fan speed 6617rpm
|
| CHASSIS TEMPERATURE
| (101) 28degC (1) 0degC
|
| CHASSIS FAN
| (101) active (102) active (103) active (104) active
| (105) active (106) active
|
| POWER SUPPLY
| (101) active

F5 Product Development tracked this issue as CR79997 and it was fixed in BIG-IP version 9.4.2. For information about upgrading, refer to the BIG-IP LTM, GTM and Link Controller release notes.
