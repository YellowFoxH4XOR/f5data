Known Issue

This is the result of a known issue. If an origin web server response contains a Cache-Control: no-cache or Cache-Control: private directive and a field argument is also passed to the directive, such as Cache-Control: no-cache=set-cookie, the BIG-IP WebAccelerator may become unstable. In addition, the pvac daemon may core and log error messages in the pvac.log file that appear similar to the following example:

File: PvAccelerator.cxx, Line: 2588
Message: Caught terminating signal, probably due to invalid application state. 

F5 Networks Product Development tracked this issue as CR112042 and it was fixed in BIG-IP WebAccelerator version 9.4.7 and 10.0.1. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-10.0.0-5514.0-HF2 issued for BIG-IP version 10.0.0. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
