Description

Some HTTP requests are not logged in the F5 ASM Event Logs in Web GUI.

Environment

Web Acceleration Profile is assigned in Virtual Server.
ASM Policy is assigned in Virtual Server.

Cause

This is caused by web acceleration cache.

The webacceleration sends the response to the client in prior to the request being processed by ASM. As a result, ASM does not process the request, because it was already cached, so no log is sent to the remote server because of the cache.

Also please keep in mind that even with an illegal request, the cache is the one that responds, the request is not even reaching the backend server.

Recommended Actions

For those requests processed by the web acceleration cache, you may consider creating a LTM request log profile to have the requests sent to syslog server.
