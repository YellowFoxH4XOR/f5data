Description

  • Unable to update Bot signatures
  • The following message appear on GUI: "You do not have permissions"
  • Can not update bot signatures after upgrade to 14.1.x or 15.x

Environment

  • Bot Signatures
  • BIG-IP ASM running software version 14.1.x or 15.x

Cause

Seen behavior is expected if the unit in question is running software version 14.1.x or 15.x and does not have Threat Campaign subscription. With the release of BIG-IP 14.1.0, the Bot signature feature requires a separate license. Bot signature updates are part of the Threat Campaigns subscription-based service license. Without a Threat Campaigns add-on license, bot signatures cannot be updated using manual or automatic updates; however, you can still add custom bot signatures.

Note: Bot signatures are updated on each major version.

Recommended Actions

To update bot signatures, you need to contact F5 Sales to get a Threat Campaigns subscription-based service add-on license.
