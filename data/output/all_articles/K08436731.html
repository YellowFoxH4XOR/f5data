Description

Sometimes it is necessary to reverse the order of value lists in an HTTP header.  In this example the X-Forwarded-For IP addresses must be reversed so that the first entry is now the last entry.

Environment

  • HTTP enabled VS.
  • Comma separated list of values in an HTTP header.

Cause

Using an iRule we can reverse these values.

ie:

X-Forwarded-For: 10.10.10.100, 10.10.10.12, 10.10.10.35

Will become:

X-Forwarded-For: 10.10.10.35, 10.10.10.12, 10.10.10.100

Recommended Actions

Apply the following iRule to the VS:

when HTTP_REQUEST {
    if { [HTTP::header exists X-Forwarded-For] } {
        set xff_rev {}
        set values [split " [HTTP::header X-Forwarded-For]" ","]
        set i [llength $values]
        while {$i} {lappend xff_rev [lindex $values [incr i -1]]}
        set xff_fini [join $xff_rev ","]
        HTTP::header replace X-Forwarded-For "$xff_fini"
        unset xff_fini
        unset xff_rev
    }
}

Note: X-Forwarded-For header can be replaced with any comma separated value list header.
