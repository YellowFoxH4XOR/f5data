Known Issue

This is the result of a known issue. If you configure a Network Access favorite or a Static Application Tunnel favorite to auto-launch an application, and you select the Display message box before launching applications check box, users do not receive the message box if the URL of the FirePass controller appears in the Internet Explorer (IE) Trusted Sites list.

Note: This issue occurs in FirePass version 6.0.2 after installing cumulative hotfix HF-602-6 or later versions of the cumulative hotfix.

Security zones, including the Trusted Sites zone, is a security feature of IE. The FirePass Trusted Sites implementation consults IE’s Trusted Sites list through a FirePass client component. This component allows all browsers to access the IE Trusted Sites list. Therefore, this issue occurs even if the user connected to FirePass using an alternate browser, such as Firefox.

F5 Product Development tracked this issue as CR117261 and it was fixed in FirePass 6.1.0. for information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-2.1, which has been issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
