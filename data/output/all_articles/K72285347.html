K72285347: Unable to provision Add-On key to BIG-IQ under FCP license with error: Unable to grant license key: Error 51086, Add-on Module Key is not a valid option for the Base Registration Key

Type
Support Solution
Published
2020-09-17
Updated
2025-02-07
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K72285347

Description

You are unable to provision an Add-On key to BIG-IQ under ELA Utility (subscription) license.

You may see a similar error message:

Unable to grant license key: Error 51086, Add-on Module Key is not a valid option for the Base Registration Key

Environment

  • BIG-IQ
  • FCP license
  • Add-on key

Cause

The FCP license does not support 'Add-on' keys.

Recommended Actions

Contact your regional F5 Sales representative to discuss your requirements.

Additional Information

None
