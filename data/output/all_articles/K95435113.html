Issue

Error Message

mcpd [<PID>]: 01070043:3: Monitor <name> parent not found.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <name> is the partition and name of the new monitor you are creating  

For example:

mcpd [9272]: 01070043:3: Monitor /Common/monitor_new parent not found.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The TMOS Shell (tmsh)
Description

This message occurs when the following condition is met:

  • You attempt to create a monitor, but the referenced parent monitor does not exist in the configuration.

    For example, the following command will fail if the mon_example_tcp monitor does not exist in the configuration:

    tmsh create /ltm monitor tcp mon_new defaults-from mon_example_tcp

Impact

You are unable to create the new monitor and the configuration remains unchanged.

Recommended Actions

When creating monitors, ensure that any referenced parent monitors already exist in the configuration.
