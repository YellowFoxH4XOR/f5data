Known Issue

When you use the BIG-IQ system to upgrade a VIPRION or Virtual Clustered Multiprocessing (vCMP) system, the upgrade task does not detect when the target system boots to the new volume and will then stall waiting for the target system. The upgrade task eventually times out and reports the following error:

Timeout waiting for device to return from reboot

This issue occurs when the following condition is met:

  • You attempt to use your BIG-IQ system to perform an upgrade on a VIPRION or vCMP system.

Impact

The BIG-IQ system's upgrade task does not correctly register that the target system has rebooted into the newly installed volume; therefore, you must manually verify the status of the upgrade.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The upgrade on the target device completes successfully, but the BIG-IQ system reports a timeout error.
  • In the /var/log/restjavad.0.log file, you observe messages that appear similar to the following example:

    Task failed on device: java.lang.Exception: Timeout waiting for device to return from reboot

Workaround

To avoid the previously mentioned error, you can pause the task before you reboot the system. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. When creating the Managed Device Install task, in the Options settings list, select the check box for Pause for reboot confirmation.
  2. When the task pauses, cancel the task and manually restart the target device.
