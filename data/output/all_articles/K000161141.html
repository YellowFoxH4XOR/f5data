K000161141: BIG-IP SSLO or SWG forward web proxy returns "503 Service Unavailable"

Type
Support Solution
Published
2026-05-06
Updated
2026-05-06
Applies to
  • BIG-IP
  • BIG-IP SSL Orchestrator
Source
https://my.f5.com/manage/s/article/K000161141

Description

When either BIG-IP SSLO or SWG is configured as a forward web proxy, web traffic may fail with the browser displaying "503 Service Unavailable" error.

Tests performed show that the virtual server accepts client connections, but the proxy fails to establish a tunnel to the destination site.

Environment

  • BIG-IP SSLO or BIG-IP SWG
  • Forward web proxy configuration
  • Non-default route domain

Cause

A non-default route domain associated with the VLAN containing the impacted traffic object does not have a configured parent domain (the Parent Name is set to None). This prevents objects in the non-default route domain from reaching objects routable via VLANs defined in the default route domain, blocking the proxy from forwarding traffic to internet destinations.

Recommended Actions

Identify the affected non-default route domain and set the parent of the non-default route domain (e.g., ID 1) to "0" (the default route domain) on the affected unit:

  1. Log in to the BIG-IP Configuration Utility.
  2. Navigate to Network > Route Domains.
  3. Click the name of the non-default route domain.
  4. Set the Parent Name to 0 (Partition Default Route Domain).
  5. Click Update.
