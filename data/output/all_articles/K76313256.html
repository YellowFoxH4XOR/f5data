Known Issue

The Traffic Management Microkernel (TMM) restarts when traffic passes through an IPSec interface.

This issue occurs when the following condition is met:

  • You update an Internet Key Exchange (IKE) 2 IKE-peer, or the system first defines it at startup.

Impact

TMM restarts and produces a core file, and the restart disrupts traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • TMM restarts and produces a core file.
