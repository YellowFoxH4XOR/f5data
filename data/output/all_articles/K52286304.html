Topic

The BIG-IP system has three predefined administrative accounts named root, admin, and f5hubblelcdadmin. These administrative accounts have been granted additional privileges to allow the management of BIG-IP resources not available to the standard user accounts.

Description

The names and common uses for each of the BIG-IP system administrative accounts are described in the following sections.

admin

You can use the administrator account to perform significant configuration operations using the Configuration utility, such as adding new users. The administrator account has full access to all BIG-IP system resources and administrative partitions.

By default, the administrator account has access only to the Configuration utility. However, the administrator account can be granted terminal access to both the TMOS Shell (tmsh) and the Advanced Shell (bash). For more information about terminal access, refer to K12029: Accessing the Traffic Management Shell.

f5hubblelcdadmin

The f5hubblelcdadmin account is introduced in BIG-IP 12.1.0. This is an internal account for the iSeries platforms. The BIG-IP system software uses this internal account only when receiving user input from the iSeries platform liquid crystal display (LCD) panel. The f5hubblelcdadmin account is secure and not remotely accessible. The f5hubblelcdadmin account must remain present in the system.

root

You can use the root account to perform significant configuration operations using the Advanced Shell (bash). For example, editing Linux system files such as the /etc/crontab file. The root account has full access to all BIG-IP system resources and administrative partitions.
