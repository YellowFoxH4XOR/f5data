K000138236: APM session mirror failed

Type
Support Solution
Published
2024-08-05
Updated
2024-08-05
Source
https://my.f5.com/manage/s/article/K000138236

Description

APM sessions are unable to sync to standby units after migrating VE to new hypervisor.

  • Before migration, everything went well
  • There are not any config changing.
  • There are not any Error messages

Environment

  • BIG-IP APM
  • HA
  • APM session mirror

Cause

CPU core of Active and standby VE are different.

Recommended Actions

APM HA units should have the same CPU and memory resource.

To contact Hypervisor team fixing this issue.


Additional Information

None
