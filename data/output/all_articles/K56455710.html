K56455710: Upgrade to BIG-IQ 7.1 fails with error: STORAGE_UPGRADE_FAILED

Type
Support Solution
Published
2020-11-25
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K56455710

Description

BIG-IQ 7.1 upgrade fails with an error message in the Launch.log:

[...]
Verify if Tokumx is up, if not bring it up
Bringing Tokumx up on data directory /shared/tmp/toku
Tokumx is up and running
Checking if upgrade is needed
Toku upgrade is needed and also run the Toku to Pg transfer
Fetch previous Toku Upgrade status
Previous Toku Upgrade status: STORAGE_UPGRADE_FAILED
There is a Failure in previous Toku upgrdae attempt, please fix it before retrying Upgrade
Exiting Upgrade
Stopping Tokumx
[...]

Environment

  • BIG-IQ v6.0 and v7.1
  • Upgrade attempt from v6.0 or 7.0 to v7.1

Cause

Post upgrade db corruption as a result of a Toku upgrade failure

Recommended Actions

  1. Boot back to the previous working version. 
    # switchboot 

  2.  Patch mongodb by running this command on BIG-IQ CM:
    # mongo bigiqDb --eval 'db.bigiqCurrentConfig.update({"_value.name": "threat-campaigns", "_value.kind":"cm:asm:working-config:policies:sections:sectionstate"}, {$set: {"_value.kind":"cm:asm:current-config:policies:sections:sectionstate"}}, {multi:true})'

  3. Remove corrupted post-upgrade DB by running:
    # rm -rf /shared/tmp/toku

  4. Delete the previous installation location, e.g:
    # tmsh delete sys software volume HD1.1

  5.  Install BIG-IQ v7.1 in a new volume.

Additional Information

None.
