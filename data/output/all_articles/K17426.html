Known Issue

The idle timeout period is five seconds when using embedded Packet Velocity Acceleration (ePVA) acceleration.

This issue occurs when all of the following conditions are met:

  • You are running BIG-IP 11.4.1 HF9 or 12.0.0.
  • Your BIG-IP system has an ePVA chip.

    For more information about platforms with the ePVA chip, refer to K12837: Overview of the ePVA feature.

  • The system processes traffic with a TCP virtual server that has an associated FastL4 profile.
  • The FastL4 profile's PVA acceleration value is either full or assist, and the idle timeout value is greater than five seconds.

    Note: The default idle timeout value is 300 seconds.

  • Long-lived TCP connections are idle for five seconds.

Impact

The BIG-IP system prematurely closes long-lived TCP connections.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system unexpectedly resets (RST) TCP connections when they are idle for five seconds.

Workaround

To work around this issue, you can disable ePVA in the FastL4 profile. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure may increase CPU utilization as TCP connections are subsequently processed in software by the Traffic Management Microkernel (TMM).

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Disable ePVA by using the following command syntax:

    modify ltm profile fastl4 <profile_name> pva-acceleration none

    For example, to disable ePVA for a profile named example_fastL4, type the following command:

    modify ltm profile fastl4 example_fastL4 pva-acceleration none

  3. Save the configuration by typing the following command

    save sys config
