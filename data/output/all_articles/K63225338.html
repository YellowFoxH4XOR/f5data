K63225338: The mcpd Process May Fail and Restart with Log Messages Similar to 'pgstat wait timeout'

Description
The mcpd process may fail and restart sometimes with one or more of the following symptoms.

 -- Errors such as the following may appear in log files:
 - notice postgres[10872]: [466-1] WARNING: pgstat wait timeout.
 - notice sod[27693]: 01140041:5: Killing /usr/bin/mcpd pid 7144.
 - BD_CONF|ERR| ...failed to connect to mcpd after 5 retries, giving up...
 - BD_CONF|ERR| ...can't read message from mcp conn, status:16908291.
 - BD_MISC|CRIT| ...Received SIGABRT - terminating.
 - Couldn't send BLOB notification
 - MCP err 16908291.
 - Got a terminate/abort signal - terminating ...
 - Terminating mcp_bridge thread.

 -- Processes may restart unexpectedly, including mcpd, bd, and postgresql.

Environment

  • This issue has been found on BIG-IP v13 and later.

Cause
This issue is caused by a known software issue marked as ID 777389.

Recommended Actions

Make sure control plane processes have sufficient memory to run efficiently.
