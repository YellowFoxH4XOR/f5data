Note: For information about how to perform this procedure in BIG-IP version 9.x, refer to K4411: Reinstalling system software from a network boot server.

If you want to restore factory settings, you can reinstall the system software to remove all of the configuration settings.

To reinstall the system software, perform a network boot of the system software using the following steps:

  1. Designate a PC to use as a network boot server.

    The PC must meet the criteria outlined in K3506: Hardware requirements for the BIG-IP network boot server.

  2. Connect the network boot server to the same network to which the BIG-IP admin interface is connected. You must use the admin interface for network installation.

    Note: If you connect the network boot server directly to the BIG-IP admin interface, you must use an Ethernet cross-over cable.

  3. Insert the system software CD into the CD-ROM drive of the network boot server.
  4. Reboot the network boot server.

    After the system boot completes, a menu similar to the following displays:

    Select installation option: 

    1 Install software onto hard disk
    2 Setup server to provide network installation
  5. Select 2 and press Enter.
  6. If prompted, select the network interface to use for the network boot server. Select the interface that you connected to the same network as BIG-IP or 3-DNS in step 2.
  7. When prompted to specify a DHCP server, choose the existing DHCP server or allow the network boot server to act as a DHCP server.

    Use the following guidelines to select a DHCP server.

    • If you have an existing DHCP server on the subnet that you want to use, type yes. The server configuration will complete automatically. Proceed to step 12.
    • If you do not have an existing DHCP server that you want to use, type no and proceed with step 8.
  8. When prompted, use the following criteria to enter the IP network for the DHCP server:

    • If you are connected to an existing network, choose an IP address range that is compatible.

    • If you are not connected to an existing network, use the default address range.
  9. When prompted, use the following criteria to enter the IP address for the network boot server:

    • If you are connected to an existing network, choose a compatible IP address that is not already in use.

    • If you are not connected to an existing network, use the default IP address.
  10. When prompted, use the following criteria to enter the lowest IP address that you want BIG-IP to use during the installation process:

    • If you are connected to an existing network, choose a compatible IP address that is not already in use.

    • If you are not connected to an existing network, use the default IP address.
  11. When prompted, use the following criteria to enter the highest IP address that you want BIG-IP to use during the installation process:

    • If you are connected to an existing network, choose a compatible IP address that is not already in use.

    • If you are not connected to an existing network, use the default IP address.

    The settings you chose are displayed.

  12. If the settings are correct, press Enter to continue.

    If there is a mistake in the settings, type no and press Enter. Return to step 6.

    The system will display the following messages:

    Server ready for installations

    Note: Ignore the following termination warning:

    The automated installation procedure terminated for some reason -- to restart it enter the command ''setup''

  13. Enable network boot on the BIG-IP as described in K4726: Configuring BIG-IP or 3-DNS to boot from a network boot server.
  14. Reboot BIG-IP or 3-DNS, by typing the following command:

    reboot

    After the boot completes, the system will display the following menu options: 

    1 Install software onto hard disk
    2 Setup server to provide network installation
  15. Select 1 and press Enter.

    The system displays a warning message.

  16. To proceed with the installation and remove your current configuration, press Y and then press Enter.

    The installation will proceed.

  17. When prompted, press Enter to reboot the system.
