K07302193: PPP tunnel for MacOS Fails to Established through NAT

Type
Support Solution
Published
2020-09-24
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.3
  • APM Clients
Source
https://my.f5.com/manage/s/article/K07302193

Description

BIG-IP Edge Client for MacOS may fail to establish a PPP tunnel when connecting through a Internet Proxy, NAT or Firewall.  Users are able to successfully complete the Access Policy but are unable to establish a tunnel session

Environment

  • Internet Proxy, NAT, or Firewall
  • BIG-IP Edge Client
  • MacOS Catalina
  • MacOS Mojave
  • BIG-IP APM 13.1.3

Cause

BIG-IP Edge Client for MacOS utilizes port 4433 or 8443 for establishing the PPP Tunnel instead of port 443 like the BIG-IP Edge Client for Windows. The Internet proxy, NAT, or Firewall will generally open port 443 to establish the PPP tunnel causing PPP Tunnel connections on ports 4433 or 8443 to be blocked.  
 

Recommended Actions

Allow ports 4433 and 8443 through the Internet proxy, NAT, or Firewall to allow MacOS Edge Client users to establish a DTLS tunnel

Additional Information

  • edge.log shows similar log messages
TunnelController, tunnelError(), Error code, Connection to remote server cannot be established
  • Tcpdump will show DTLS Client Hello with no corresponding DTLS Server Hello
192.168.0.1 → 192.168.0.2  678 12345 4433 DTLS Client Hello
192.168.0.1 → 192.168.0.2  678 12345 4433 DTLS Client Hello
192.168.0.1 → 192.168.0.2  678 12345 4433 DTLS Client Hello
