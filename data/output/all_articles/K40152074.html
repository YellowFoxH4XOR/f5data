Description

This article describes how to use the BIG-IP APM Visual Policy Editor to assign resources in an Access Policy when users do not belong to an AD group.

Environment

  • BIG-IP APM
    • Visual Policy Editor
      • Assigning resources when users do not belong to an Active Directory (AD) group.

Cause
None

Recommended Actions

Use following expression with the Visual Policy Editor object to assign a resource for any user that is not a member of an AD group.

Impact of procedure: making any change to an existing AccessPolicy may induce disruption. F5 recommends implementing the changes to either an Access Policy that is not in use yet; or to perform the operations during a maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Profiles / Policies > Access Profiles (Per-Session Policies).
  3. ...

    expr { [string match -nocase {*<AD_Group_Name>*} [mcget {session.ad.last.attr.memberOf}]] == 0 }

    In this expression, note the following:

        <AD_Group_Name> is the AD group the user should not belong to, to get the resource assigned.

    For Example, to assign a resource to a user that does not belong to the test domain, use the following:

    expr { [string match -nocase {*test*} [mcget {session.ad.last.attr.memberOf}]] == 0 }
