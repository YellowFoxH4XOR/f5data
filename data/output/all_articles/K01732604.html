Description

  • ASM security policy in blocking mode not blocking requests that triggers attack signatures violations
  • Requests matching attack signatures are not being blocked
  • Violation report example:

    Violation Details
    Attack signature detected [1]
    Detected Keyword: /.svn
    Attack Signature: Signature ID 200100079
    Signature Name: /.svn directory access
    Context: URL
    Applied Blocking Settings: Staged

Environment

  • ASM security policy in blocking mode
  • Attack signatures are enforced

Cause

Seen behavior is expected if the matching attack signature with URL context contains a wildcard URL in Staging

Recommended Actions

To block such requests you need to enforce the wildcard URL

  1. On GUI go to Security > Application Security > URLs > Allowed URLs > Allowed HTTP URLs
  2. On Current edited security policy select the Security policy in question
  3. Check the box next to the HTTPS wildcard url
  4. Click Enforce
  5. Click Apply Policy
