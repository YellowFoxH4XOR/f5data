Issue

Error Message

notice mcpd[PID]: 01071027:5: Master key OpenSSL error: <error>

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <error> is the error message describing the issue.

For example:

notice mcpd[9872]: 01071027:5: Master key OpenSSL error: 1503728924:error:06065064:digital envelope routines:EVP_DecryptFinal_ex:bad decrypt:evp_enc.c:587:

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The BIG-IP system experiences a problem with OpenSSL processing for the device's secure vault feature or with device group mutual authentication.
  • The BIG-IP system experiences a problem with a corrupt master key, unit key, device group key or certificate, or experiences failures with certificates or keys used for high availability.

 Error messages related to problems with OpenSSL processing should be rare and are mostly caused by out of memory conditions.  

Impact

Loading or synchronizing BIG-IP configurations with encrypted attributes fails.

Recommended Actions

Depending on the error, you may be able to work around the issue by resetting the device trust or by reloading a backup UCS archive.  For information about resetting device trust, refer to K13946: Troubleshooting ConfigSync and device service clustering issues.  For information about loading UCS archives, refer to K9420: Installing UCS files containing encrypted passwords or passphrases.
