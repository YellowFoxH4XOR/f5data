Description

BIG-IP is licensed for FIPS, however when running the following command FIPS shows as not licensed:

show sys crypto fips

Example:
FIPS 140 is not licensed.

Environment

  • BIG-IP licensed for FIPS 140-2 Compliance

    Example command:  tmsh show /sys license | grep fips140
    security_fips140_compliance : enabled
     
  • FIPS HSM (Hardware Security Module) is not installed.

Cause
This is because the FIPS 140 is not licensed error refers to the HSM license, not the compliance license.  A BIG-IP licensed for a hardware HSM will normally have an F after the model number, and the license will appear like so:
Example command:  tmsh show /sys license | grep fips
security_fips140_compliance : enabled
security_fips : enabled

Recommended Actions

No action is required.
