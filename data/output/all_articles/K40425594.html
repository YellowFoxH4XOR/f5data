Description

Receiving an error when attempting to make any change to a virtual server:

0107028f:3: The destination (0.0.0.0) address and mask (::) for virtual server (/Common/http-vs) must be be the same type (IPv4 or IPv6).

Environment

  • Virtual server with TMC (traffic-matching-criteria, for example, address list)
  • IPv6 not in use
  • Conditions not met for ID 957993

Cause

Bug ID 1027237

Recommended Actions

There is no permanent fix for bug ID 1027237 at the time of this article's publication.

There are two possible workarounds for this issue:

Please note that both of these are service disrupting so they should be done on the standby first then failover and do the peer 

1) You can force mcpd to reload the config.  

Note: this workaround requires a reboot

K13030: Forcing the mcpd process to reload the BIG-IP configuration
https://my.f5.com/manage/s/article/K13030

2) Change the IP address so that the type of IP (IPv4 or IPv6) of the host matches the mask:

a) go to your virtual server properties
b) go down to destination address and change it from Address List to host.  You can leave the host IP at the default of 0.0.0.0/0 for right now.
    Note: this presumes you have no other 0.0.0.0 already defined.
c) click update 
d) after it's done saving go back into the properties
e) go back to Destination Address and change it back from host to Address List and choose your list then click update
