Known Issue

iControl representational state transfer (REST) receives error code 500 and Internal error occurred in the return for the list (GET) for /mgmt/tm/sys/crypto/cert.

This issue occurs when all of the following conditions are met:

  • The certificate is not self-signed and has an Online Certificate Status Protocol (OCSP) validator assigned to it.
  • You use the /mgmt/tm/sys/crypto/cert to obtain the certificate's content.

Impact

The system prints the certificate's properties after the error messages, and the JSON parser cannot properly parse the properties.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system returns error code 500 and Internal error occurred messages, followed by the certificate's properties, when you attempt to list (GET) the certificate's properties using sys/crypto/cert and iControl REST.
  • The system prints the certificate information, but a JSON parser may not properly parse the information.
