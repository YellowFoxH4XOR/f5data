Description

Is there a solution to reserve the IP address for a while like DHCP does?

This is not possible using BIG-IP internal mechanisms.

Environment

  • APM
  • VPN
  • IP Lease time

Cause
There is a sweeper function running every 25 ms that checks the session, and if it is killed, then the IP is restored to the lease pool.

Recommended Actions

None
