Topic

When customizing an installation package for BIG-IP Edge Client for Windows, you can enable the Enable Always connected mode option. When this option is enabled, the BIG-IP Edge Client tries to connect to network access immediately after you log on to Windows, and it prohibits you from disconnecting the Network Access. You’re prevented from accessing the Internet and the local network until a network access connection is established. The control is implemented through the use of the F5 Networks Stonewall Service and F5 Networks Traffic Control Service Windows services. You can configure this option in the connectivity profile when customizing your BIG-IP Edge Client package by using the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity > Profiles.

    Note: For BIG-IP 12.x and earlier, go to Access Policy > Secure Connectivity.

  3. Select the name of your connectivity profile.
  4. Select Customize Package.
  5. Select BIG-IP Edge Client.
  6. Select the Enable Always connected mode check box.

Description

Beginning in BIG-IP 12.1.0, when the Enable Always connected mode is enabled, additional options are available for Traffic flow when Network Access is disconnected. These options include the following:

  • Allow: In this mode, all traffic is allowed. This allows unrestricted access to any network before the client connects and after it disconnects.
  • Allow-Only-In-Enterprise-LAN: In this mode, when the client system is connected to the Enterprise LAN, traffic is allowed. When the client system is not connected to the Enterprise LAN and network access is not established, the traffic rules described in the F5 Networks Stonewall Service traffic rules section in this article are enforced. For this option, BIG-IP Edge Client uses the Location Awareness feature to determine if the client is using an enterprise LAN. For more information about the Location Awareness feature, refer to K34467612: Overview of BIG-IP Edge Client autoconnect location awareness.
  • Block: In this mode, when network access is not established, the traffic rules described in the F5 Networks Stonewall Service traffic rules section are enforced.

F5 Networks Stonewall Service traffic rules 

When you select Allow-Only-In-Enterprise-LAN and the client system is not in the enterprise LAN, or when you select Block, when network access is disconnected, the following traffic rules take effect:

  • Allow traffic on the local loopback
  • Allow inbound traffic
  • Allow DHCP requests
  • Allow DNS requests
  • Allow TCP/UDP/ICMP traffic to exclusion IP address if exclusions are specified

    Note: Beginning in BIG-IP 13.0, an exclusion list is available which allows host addresses or FQDNs to be added for exclusion from the rules preventing traffic flow before network access is established. 

  • Deny all other outbound traffic. Traffic services such as RDP, browser traffic, ping, Telnet, and so on may fail.

If the BIG-IP Edge Client is running, it also allows traffic to the virtual server IP address and to a captive portal where probe packets are sent to be able to connect to network access. After network access is established, the rules previously listed are not enforced.

Client side system changes

When the BIG-IP Edge Client connects to the virtual server, it downloads configuration changes you made to the connectivity profile such as Server List, Location DNS List, and other traffic control options and writes them to the following files:

  • C:\ProgramData\F5 Networks\Secure Access Client\config.f5c
  • C:\Program Files (x86)\F5 VPN\config.f5c

However, for changes to the BIG-IP Edge Client package, such as Enable Always connected mode, you need to download the new package from the Configuration utility and distribute the package to each client system for installation. After installation on your Windows systems, you will observe the following message in the BIG-IP Edge Client interface:

Always connected mode

Edge Client attempts to connect automatically at login. To changes these settings, contact your system administrator.

The F5 Networks Stonewall Service and F5 Networks Traffic Control Service Windows services will be running.

Recommendations

In cases where your Windows client systems need to verify with a Certificate Revocation List (CRL) Endpoint in order to verify the certificate on the BIG-IP APM virtual server, communication with the CRL Endpoint fails. As a result, VPN cannot establish. In such cases, in BIG-IP APM 13.0 and later, an exclusion list feature is introduced where you can specify addresses with which the Windows client is able to communicate. You can find this option at the same page when configuring Enable Always connected mode.
