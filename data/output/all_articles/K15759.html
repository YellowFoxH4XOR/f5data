Known Issue

The fips-util utility does not support the advertised maximum Security Officer password length of 14 characters. The maximum allowable password length is 13 characters.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system has an internal NG FIPS security module.
  • The FIPS security domain is being initialized.
  • A Security Officer password of 14 characters is entered when prompted.

Impact

The password strength level for Security Officer is reduced by one character.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the security domain is reset, an error message similar to the following example appears at the command line:

    Enter new Security Officer password (min. 7, max. 14 characters): ERROR: Too long input (max.: 13 characters)

    Re-enter Security Officer password:
    ERROR: Failed to read password
