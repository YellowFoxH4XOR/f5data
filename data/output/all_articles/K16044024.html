Description

The attack signature "Leading space in header name" is triggered by a request with no space in the header name.

The violation refers to a space in the decoded header value.


Environment

  • Attack signature check enabled on the HTTP header ( Authorization  )
  • Attack Signature Triggered 200018063 ( Leading space in header name )
  • Upgrade from 14.14.4 to 14.1.4.5


Cause

The observed behaviour is linked to the fix that was introduced for ID785873.

The fix causes a different handling of the Authorization header.

Starting 14.1.4.5, the 'Negotiate' at the beginning of the Authorization header is treated as NTLM, while in 14.1.4.4, it is treated as Unknown.


Recommended Actions

Therefore, it is recommended to disable the Attack Signature ID 200018063 in the Authorization header.


Additional Information

Furthermore, due to the same fix in ID785873, Attack Signatures 200018080, 200018064, 200003341 are likely to be triggered when matched.

Product Engineering has opened ID1076621 to enhance the Attack Signature ID 200018063.
For 200018080, 200018064, 200003341, Product Engineering has opened ID1097117.
