Known Issue

This is the result of a known issue. When attempting to launch the mstsc.exe application through Network Access on a Windows XP SP3 client, the following error message is seen:

An error occurred while loading file C:\WINDOWS\system32\mstsc.exe

This issue appears to be isolated to FirePass version 6.0.2 starting with HF-602-6; Windows XP SP2 users should not be affected.

The FirePass device calls ShellExecuteEx with both the command and parameters set to C:\Windows\system32\mstsc.exe. However, the command line that is trying to execute turns into c:\windows\system32\mstsc.exe c:\windows\system32\mstsc.exe. The older version of the RDP client is more tolerant to this issue, but the latest RDP client (6.1.0) recognizes the input parameters as invalid, and will not start.

F5 Product Development tracked this issue as CR108997 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative HF-602-8 has been issued for FirePass version 6.0.2. You may download this hotfix or a later version of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

The client can work around this issue by uninstalling Microsoft hotfix KB952155 to revert to the older RDP client.
