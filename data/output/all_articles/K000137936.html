K000137936: The mirrored connection not showing on standby, if the gateway VLAN name mismatch on the HA devices

Published

Applies to

  • BIG-IP LTM: 13.1.3
Source
https://my.f5.com/manage/s/article/K000137936

Description

Connection mirroring is properly configured and the mirroring session shows "connected", but the "show sys connection" on standby outputs an empty connection table.


Environment

BIG-IP LTM 13.1.3

  • Connection mirror enabled.
  • Different VLAN names on the two HA devices.

Cause

Bug ID882725

Recommended Actions

Correct the VLAN name from one of the devices, and make sure the VLAN name is the same on both devices.
