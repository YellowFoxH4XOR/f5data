Description

Malformed packets stats keep incrementing when viewing virtual server detailed stats.

To verify any virtual server you can use the command below:

tmsh show ltm virtual detail | grep Malformed

Output such as the following indicates that 2k malformed packets where received on this virtual:

| Malformed Packets 2K

Environment

  • BIG-IP LTM

Cause

The malformed packet could be any packet that breaks RFC, for example the packet was not reassembled because of its length or the headers are bigger than expected.

Recommended Actions

The malformed packets indicate that an issue with external network sending incorrect packet headers or incorrect HTTP responses. The only way to verify the actual header that is causing the stats to increase is to collect a pcap on the affected virtual or profile and review the packets flowing over the virtual.

Additional Information

If the stats are showing up on a virtual with fastl4 profile, then the malformed packet counter is incremented based on layer 4 or lower and forwarding of malformed packets will continue. On the other hand if the malformed packets are incrementing on standard virtual with L7 profile such as HTTP, then the connection will be RST.
