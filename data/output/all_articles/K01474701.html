Description
When uploading new SSL key via GUI, you see errors:

  • 01070712:3: Key size of 8192 is not valid for key /KeyName,
  • Import Failed: Key management library returned bad status: -99

Environment

GUI

Cause
F5 currently does not support 8192 length keys. 

Recommended Actions

Upload key that is smaller than 8192 - for example 4096 or 2048.

Additional Information

K13067: Performance impact of transitioning to 2048-bit SSL key sizes
K60857690: Error Message: Key management library returned bad status: -99
