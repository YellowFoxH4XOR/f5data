Known Issue

The Traffic Management Shell (tmsh) may produce a core file when deleting iRules objects.

This issue occurs when the following condition is met:

  • You attempt to delete multiple iRules objects within a tmsh command by using the wildcard (*) or open square bracket ([) character.

    For example, you use the following command syntax to delete iRules objects with object names that start with testrule (testrule1, testrule2, and so on):

    tmsh delete /ltm rule testrule\*

Impact

tmsh produces a core file, and, as a result does not delete the iRules objects. The BIG-IP system should remain operational because no other system services are affected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you run the affected tmsh command on the console or terminal of the BIG-IP system, you notice the following error message:

    Segmentation fault (core dumped)

  • The system produces a tmsh core file in the /shared/core directory.

Workaround

To avoid this issue, you can individually delete each iRules object by running the tmsh delete command for each iRules object and specifying the object name in full.

Impact of workaround: Performing the suggested procedure should not have a negative impact on your system.
