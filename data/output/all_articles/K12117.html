Topic

When setting up AAA authentication using Native RSA SecurID, you must add BIG-IP APM as an Agent Host to the authentication server. The Agent Host record identifies BIG-IP APM within the Native RSA SecurID server's authentication database, and includes information about communication and encryption. This configuration is completed on the Native RSA SecurID server. The IP address that is used for the Agent Host IP address setting should be the IP address that the Native RSA SecurID will receive authorization packets from. Typically this IP address will be a self IP address on the BIG-IP APM system. However, if there is a network device (such as a router or a firewall) that sits between that BIG-IP APM system and the Native RSA SecurID server that performs a network address translation (NAT), the IP address needs to be set to the translated IP address. After configuring the Agent Host IP address setting on your Native RSA SecurID server, the BIG-IP APM system needs to be configured to use the Native RSA SecurID server for authentication. The Agent Host IP address setting does not modify the source IP address of the packets that are sent to the Native RSA SecurID server. The Agent Host IP address setting is only used to modify the layer 7 (application layer) information that is sent to the Native RSA SecurID server.

When configuring a high availability (HA) deployment with RSA native SecurID, you must create a floating IP address for the agent host from the RSA server. Also, you should define static self IP addresses of the nodes as secondary nodes. The configuration file generated on the RSA server contains all three IP addresses, so the originating traffic from any of the subnodes will be accepted.

Configuring BIG-IP APM to use a Native RSA SecurID Authentication server

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > AAA Servers by Type > SecurID.
  3. Click Create.
  4. In the Name box, type a name for your Native RSA SecurID server.
  5. For the Agent Host IP Address, select an option as appropriate to match the IP address configured on your Native RSA SecurID device:
     
    • Select from Self IP List: Choose this option when there is no NAT device between BIG-IP APM and the RSA Authentication Manager. Select an IP address from the list of those configured on the BIG-IP APM system.
    • Other: Choose this option when there is a NAT device in the network path between BIG-IP APM and the RSA Authentication Manager server. If selected, type the IP address as translated by the NAT device.

      Important: The IP address entered must match the IP address configured on your Native RSA SecurID device; otherwise, authentication fails.

  6. Next to SecurID Configuration File, click Browse.
  7. Navigate to the sdconf.rec file.

    Note: The sdconf.rec file is generated on the Native RSA SecurID server. For instructions about generating and retrieving the sdconf.rec file, refer to the BIG-IP APM Configuration Guide.

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

  8. Click Finish.
