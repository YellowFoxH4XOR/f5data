Description

You want to reactivate the license for rSeries and VELOS devices.

Environment

  • rSeries
  • VELOS
  • Licensing

Cause

None

Recommended Actions

Licensing must be performed on the host (For rSeries appliance) or chassis controller (For VELOS). 
If you are not currently on the host/controller, verify which device in your network is acting as the host/controller and perform the licensing there. 

Additional Information

The tenants (such as BIG-IP VEs) running on these platforms do not require separate licensing; instead, they inherit their licensing from the host or controller. You should see the following login screen if you are accessing the host (rSeries) or controller (VELOS). This confirms you are in the correct location to reactivate the license.
