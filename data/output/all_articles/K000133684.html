K000133684: NTLM Machine Account password renewal failure

Description

  • It was observed that when there are multiple domain controllers the password renewal might fail if repeated frequently (approx in less than 2 minute intervals).
  • Following errors might be observed in the WebUI:

Environment

  • BIG-IP APM Active/Standby pair
  • NTLM auth/machine account
  • Multiple domain controllers
  • Domain Controller FQDN property left unspecified - DNS is used to discover and resolve A, Kerberos and LDAP services records
  • All required ports are opened/no firewall

Cause

Cause seems to lie in the Kerberos/AD limitations, but was not specified fully

 Recommended Actions

  1. Unless the issue is intermittent in nature it was confirmed it has no impact to the actual NTLM auth process
  2. Enabling DNS Cache in System ›› Configuration : Device : DNS has reportedly reduced the frequency/occurrence of the issue
  3. Generally there is no point to renew the machine account password repeatedly and password renewal process is not used during the actual NTLM auth flow
