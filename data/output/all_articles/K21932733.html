K21932733: High Other Memory utilization

Type
Support Solution
Published
2022-10-20
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
Source
https://my.f5.com/manage/s/article/K21932733

Description

  • Other Memory reports high usage
  • Output from tmsh show /sys memory shows a large percentage of Other Memory being used

    Sys::System Memory Information
    -----------------------------------------------------------------
    Memory Used(%)     Current  Average  Max
    -----------------------------------------------------------------
    TMM Memory Used          3        3           3
    Other Memory Used       86       86          88
    Swap Used                    12       12          12

Environment

  • BIG-IP
  • Other Memory
  • TMM MEmory

Cause

Seen behaviour is expected. "Other Memory" is allocated to other processes on the Linux host and kernel threads and this mostly includes buffers and disk caching, which may give an appearance of high memory usage but allows the system to run more efficiently.

Recommended Actions

There is no recommended action to get "Other Memory" lower. F5 recommends to monitor TMM memory as when TMM memory usage goes high, it can eventually cause a decrease in performance, or a system reboot due to memory exhaustion.
