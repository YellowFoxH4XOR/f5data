Issue

Error Message

Response rate limit was reached

Message Location

You may encounter this message in the following location:

  • The response details in the Security > Event Logs > Application > Requests page of the Configuration utility
Description

This message occurs when all the following conditions are met:

  • You enable response logging in the logging profile associated with the virtual server.
  • The number of responses-per-second received by the BIG-IP ASM system exceeds the configured value for the response_log_rate_limit system variable.

When response logging is enabled in the logging profile, the BIG-IP ASM system logs the responses to requests in addition to the request details. By default, the system logs up to 10 responses-per-second and logs the first 10,000 bytes of responses. If the BIG-IP ASM system receives greater than 10 responses-per-second, the system displays a Response rate limit was exceeded message in the Configuration utility and stops response logging until the responses-per-second fall below the limit.

The response_log_rate_limit value is divided by the number of bd threads on the system. bd runs on all cores, so it generally has an equivalent number of threads. In some cases, you may encounter this error message with relatively low traffic, particularly if there are many bd threads.

Note: If the response lacks a Content-Type header, the BIG-IP ASM system does not log the response and displays the following message in the Configuration utility:

Response was not logged because the system does not support response logging of this content type

Impact

The BIG-IP ASM system does not log responses until the number of responses-per-second falls below the configured limit.

Recommended Actions

If you see this error message frequently, you may want to modify the response log rate limit to a value appropriate for your environment. To do so, perform one of the following procedures:

  • Modify the response_log_rate_limit variable using the Configuration utility and Advanced Shell (bash)
  • Modify the response_log_rate_limit variable using bash

Modify the response_log_rate_limit variable using the Configuration utility and Advanced Shell (bash)

The response_log_rate_limit system variable is not exposed in the Configuration utility by default. However, if the variable has been previously modified using the /usr/share/ts/bin/add_del_internal add command, you can modify the variable using the Configuration utility. To do so, perform the following procedure:

Impact of procedure: The following procedure restarts services related to BIG-IP ASM processing and should be performed during a maintenance window.

  1. Log in to the Configuration utility.
  2. Go to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. For BIG-IP ASM 13.1.0 and later, select the response_log_rate_limit parameter name.

    Note: If there are numerous parameter name entries, response_log_rate_limit may appear on an additional page. You can go to additional pages by scrolling to the bottom of the page and selecting Page 2 of 2 (or similar).

  4. For the Parameter Value, enter an appropriate value.
  5. Select Update. 

    Note: For BIG-IP ASM 13.0.0 and earlier, scroll to response_log_rate_limit on the System Variable page, enter the appropriate value for Parameter Value, and select Save.

  6. Log in to bash.
  7. Restart the BIG-IP ASM services by entering the following command:

    tmsh restart /sys service asm

Modify the response_log_rate_limit variable using bash

To modify the response_log_rate_limit system variable and expose it in the Configuration utility, perform the following procedure:

Impact of procedure: The following procedure restarts services related to BIG-IP ASM processing and should be performed during a maintenance window.

  1. Log in to bash.
  2. Modify the value for the response_log_rate_limit system variable using the following command syntax:

    /usr/share/ts/bin/add_del_internal add response_log_rate_limit <value>

    For example, to increase the limit from its default value of 10 to a value of 20, enter the following command:

    /usr/share/ts/bin/add_del_internal add response_log_rate_limit 20

  3. Restart the BIG-IP ASM services by entering the following command:

    tmsh restart /sys service asm
