Known Issue

This is the result of a known issue. When the Application Security Module receives a request URI containing certain extended ASCII characters, the BIG-IP ASM bd process hangs for approximately 90 seconds and then answers with a FIN to close the connection. When this behavior occurs, the request is not sent to the Web server.

F5 Product Development tracked this issue as CR72258, and it was fixed in BIG-IP ASM 9.4.1. For information about upgrading, refer to the BIG-IP ASM Release Notes.
