Description

On BIG-IP with defined user roles, only users belonging to Admin group may use Username and Password with REST API requests. All other users have to obtain authorization token in order to access REST API resources. Using REST API requests without using token based authentication results in "401 Authorization failed" error messages.

This is the expected behavior. 

Environment

  • User based roles
  • Local or remote REST API requests

Cause

This works as designed and implemented. Only method for non administrator to access REST API interface is to use token based authentication.

Recommended Actions

Obtain Authorization token for the  desired user in the following format:
        curl -s -k -u user:password -X POST -H "Content-Type: application/json" -d '{ "username": "user", "password": "password", "loginProviderName": "tmos"}' https://localhost/mgmt/shared/authn/login | jq . 

    Example:
    username - oper
    password -123
           curl -s -k -u oper:123 -X POST -H "Content-Type: application/json" -d '{ "username": "oper", "password": "123", "loginProviderName": "tmos"}' https://localhost/mgmt/shared/authn/login | jq .
