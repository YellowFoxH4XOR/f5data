K12603: The metadata share name specified with the metadata share command is case sensitive

Topic

The metadata share name specified with the metadata share command is case sensitive. When trying to specify the name of a pre-existing metadata share, if the case used for the name does not match, the command will fail with an error message that appears similar to the following example:

% ERROR: FILER_SHARE_IN_USE_BY_METADATA (41353964):
Filer share is being used for metadata by at least one volume.

Note: For information about the metadata share command, refer to the ARX CLI Reference Guide.

F5 Product Development is tracking a request for enhancement (RFE) as ID 348042 to ignore case when specifying the metadata share name of a pre-existing metadata share.
