Known Issue

This is the result of a known issue. When importing an XML schema from a collection of WSDL and XSD files, the BIG-IP ASM Configuration utility may be unable to complete the schema import function. If the files reference common target namespaces across different external schema files, the compilation of the schema may fail and produce error messages that appear similar to the following example:

An error has occurred while processing the schema. (Can't use an undefined value as a SCALAR reference)

F5 Product Development tracked this issue as ID 338021 and it was fixed in BIG-IP ASM version 10.2.1. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1789.0-HF2, which has been issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
