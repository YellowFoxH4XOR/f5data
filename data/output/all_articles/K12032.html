Known Issue

This is the result of a known issue. When accessing a web application through FirePass using a Japanese language set, the FirePass can misinterpret the proxy of the HTML content and display corrupt data. The Portal Access reverse-proxy engine rewrites HTML code, JavaScript code, and Java applets to ensure that all Portal Access content is proxied through the FirePass controller. If the HTML code contains a tilde (~) or a backslash (\) character, FirePass will misinterpret the character and the rewrite of the HTML code will be corrupt, causing hyperlinks or other linking data to be incorrectly formatted.

F5 Networks Product Development tracked this issue as ID 294180 (formerly CR132566-1), and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, issue ID 317658 (formerly  CR132566) has been fixed in cumulative hotfix HF-610-3-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
