K000160407: F5 Distributed Cloud Global Log Receiver (GLR) Fails to Connect to Azure Event Hub Using Basic SKU

Type
Support Solution
Published
2026-03-19
Updated
2026-06-12
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud WAF
Source
https://my.f5.com/manage/s/article/K000160407

Description

F5 Distributed Cloud (XC) Global Log Receiver (GLR) fails to connect to Azure Event Hub when configured with the Basic SKU. Testing the GLR connection from the F5 XC console results in an HTTP 500 error: "Http failure response: 500 Server Error There was a server error in processing request connection test status: error getting connection test result from test job logs."

Environment

  • F5 Distributed Cloud (XC) Global Log Receiver (GLR)
  • Azure Event Hub as the log streaming destination
  • Event Hub SKUs: Basic (issue occurs), Standard (issue resolved)
  • GLR configured in "shared configuration" within the F5 XC console
  • Connection string from Azure Event Hub used in GLR configuration

Cause

Azure Event Hub Basic SKU does not support the Kafka feature required by F5 Distributed Cloud GLR for log streaming. According to Azure's documentation, the Kafka feature is supported only in the Standard, Premium, and Dedicated tiers.

Answer/Recommended Actions

  1. Verify the SKU of your Azure Event Hub instance.
  2. If the Event Hub is set to Basic SKU, upgrade to at least the Standard SKU.
  3. After upgrading, re-test the GLR connection from the F5 XC console.
  4. Ensure the connection string and access permissions are correctly configured.
  5. Reference Azure documentation for supported features by SKU.

Additional Information

  • The Kafka feature required for GLR integration is only available in Standard, Premium, and Dedicated tiers of Azure Event Hub.
  • The issue is not related to network connectivity or IP restrictions if external access is already confirmed.
  • Consistent HTTP 500 errors during the test indicate unsupported features in the selected SKU.
