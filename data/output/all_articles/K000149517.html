Description

How to perform a Manual Category Check

 

Environment

  • BIG-IP APM
  • SWG
  • SSLO
  • Category checking

 

Cause

Site miss-categorized

 

Recommended Actions

To determine the category for a specific website, test the database by checking for a category in the master database. Note that these functions do not test custom categories.

 

Via GUI

From the administration GUI, navigate to Access >> Secure Web Gateway >> Database Settings >> URL Category Lookup, enter the URL, and click Search.

Note: This does not return custom category results.

 

Via Terminal/CLI

Locate the latest (highest numbered) websense database file:

     find /var/urldb/master/ -name websense.db

Then replace the filename below with your websense.db file’s location.

     urldb -m /PATH/TO/websense.db -c https://f5.com/ (-a <URL'S IP ADDRESS>)

Replace f5.com with any URL you wish to query. IP address is provided in the runtime system. Provide both URL and target IP address for the most accurate categorization result.
