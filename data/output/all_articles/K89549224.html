Description
When attempting to create a UCS archive with the "Encryption" option set to "Enabled" and older EPSEC packages are present, the process can timeout and fail.

Environment

  • BIG-IP APM
  • Older EPSEC packages

Cause
The encryption of data takes additional time and when extra data is included the process can take longer than the allotted timeout.

Recommended Actions

Ensure that all unnecessary configuration objects and extra packages are removed when they are no longer in use.
