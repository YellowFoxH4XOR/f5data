Description

You may consider the recommendation of this article if a vCMP HOST running v12.x and missing some/all vCMP guests statistics graphs.

Environment

  • vCMP Host is running v12.x.
  • From Statistics ›› Analytics : vCMP, you cannot view some/all vCMP guests statistics graphs.

Cause

This issue might be a result of Bug ID 635553.

Recommended Actions

Use the workaround in Bug ID 635553.
