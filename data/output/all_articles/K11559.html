Known Issue

If more than 150,000 sessions are logged in the access profiles reports and you attempt to run a search for a specific session, the time it takes to run the report may exceed your time-out value, and you may have to log back in.

F5 Product Development tracked this issue as CR137738 and was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
