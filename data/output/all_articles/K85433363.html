Description

  • External HSM has been upgraded
  • DNSSEC keys are no longer being created
  • LTM log messages indicate incompatibility of HSM and BIG-IP software version:
    Note: These message are found in /var/log/ltm
    err pkcs11d[16970]: 01680025:3: Signal 15 received.
    err pkcs11d[6835]: 01960001:3: netHSM: Cannot load HSM vendor library [/opt/nfast/toolkits/pkcs11/libcknfast.so] with error [/opt/nfast/toolkits/pkcs11/libcknfast.so: wrong ELF class: ELFCLASS32].
    err pkcs11d[6835]: 01680002:3: Attach error.

Environment

  • BIG-IP DNS
  • External HSM

Cause

External HSM version is incompatible with BIG-IP software

Recommended Actions

Ensure External HSM version is compatible with BIG-IP software version.  Refer to HSM Interoperability Matrix

Run these commands in the BIG-IP bash cli to extract the relevant details.
  • Show BIG-IP software version: 
    • tmsh show sys version
  • Show netHSM version:
    • nethsm-info.sh
