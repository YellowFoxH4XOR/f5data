K50433412: APM sessions getting logged out unexpectedly

Type
Support Solution
Published
2021-12-29
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 16.X.X, 16.0.1, 16.0.0, 16.1.X, 16.1.0, 16.0.X, 16.1.3, 16.1.2, 16.1.1
Source
https://my.f5.com/manage/s/article/K50433412

Description

APM user sessions are getting logged out unexpectedly at random intervals. When this issue happens, we can see the following log in /var/log/apm for the affected session/s:

Dec 28 15:41:13 bigip1.example.local notice tmm1[17212]: 01490501:5: /Common/test_AP:Common:dce954f9: Session deleted due to user logout request.


in a HAR/HWL capture, in the HTTP response, we can see that it is redirecting to /vdesk/hangup.php3

(Status-Line)    HTTP/1.1 302 Found
Connection    close
Location    /vdesk/hangup.php3

Environment

  • BIG-IP APM
  • LTM+APM mode
  • HTTP profile with Fallback Host configured

Cause

The HTTP profile attached to the VS has Fallback Host configured as "/vdesk/hangup.php3".

ltm profile http /Common/http_prof {
    app-service none
    defaults-from /Common/http
    fallback-host /vdesk/hangup.php3   <--------- !  
    proxy-type reverse
}

As it turns out, this was configured as a workaround for bug ID 968929

Recommended Actions

1. remove the Fallback Host from the affected HTTP profile
(Local Traffic  ››  Profiles : Services : HTTP  ››  <http-profile-name>)

2. contact F5 support to get an EHF for bug ID 968929
