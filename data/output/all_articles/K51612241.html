Known Issue

The BIG-IP Edge Client for Mac OS password setting may revert to the default setting.

This issue occurs when all of the following conditions are met:

  • Your Mac OS device is installed with the BIG-IP Edge Client for Mac OS software.
  • You launch the BIG-IP Edge Client.
  • You clear the Save password checkbox on the BIG-IP Edge Client.
  • You close the BIG-IP Edge Client.
  • You launch the BIG-IP Edge Client.

Impact

The Save password checkbox reverts to the enabled (checked) state.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you start the BIG-IP Edge Client for Mac OS, the Save password checkbox is always in the enabled (checked) state.
