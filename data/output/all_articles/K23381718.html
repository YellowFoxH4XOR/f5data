Description
Downloading files processed through the BIG-IP are slow.

Environment

  • BIG-IP
  • LTM

Cause

The TCP connections on client side and server side are not optimized for best performance.

Recommended Actions

Change the virtual server TCP profiles for client and/or server side to use an optimized TCP profile for that type of connection (lan or wan). The best answer is to build a custom profile based on your specific environment and requirements. For more information, refer to Stop using the base TCP profile on DevCentral.

For example:
  • tcp-mobile-optimized: when the virtual server has an HTTP profile. You may use this even if your client devices are not mobile devices.
  • tcp-wan-optimized when users are connecting to the virtual server from the WAN or load balanced servers are located on the WAN.
  • tcp-lan-optimized when users or destination servers are located on the LAN

A common scenario is inbound connections to the virtual server are from the WAN and load balanced request are to the LAN. To best accommodate this configuration the use of the tcp-wan-optimized TCP profile for Client and tcp-lan-optimized TCP profile for Server side is recommended.  
 

Additional Information

f5-tcp-progressive, f5-tcp-wan, f5-tcp-lan, and f5-tcp-mobile are updated versions of tcp-wan-optimized, tcp-lan-optimized, and tcp-mobile-optimized. For more information, refer to F5 unveils new built-in TCP profiles on DevCenral.
