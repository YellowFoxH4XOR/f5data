K000148839: How to base64 encode a BIG-IP/BIG-IQ UCS backup file for text format storage.

Type

Published
2025-02-25
Updated
2025-02-26
Source

Description

 

 

Some backup files storage systems require backup files to be text base64 encoded for proper storage.

UCS is a compressed type file that might need base64 encoding conversion to be properly handled and stored by such backup files storage systems.

 

Environment

 

  • BIG-IP
  • BIG-IQ

 

 

Cause

 

Some backup files storage systems require all backup files to be text base64 encoded.

 

 

Recommended Actions

 

Generate a UCS file of BIG-IP/BIG-IQ system following standard procedure.

Encode resulting UCS file using "base64" encoding linux command.

 

 

Procedure

 

1.- Generate a UCS file following described procedures in article  K13132: Backing up and restoring BIG-IP configuration files with a UCS archive

2.- Encode UCS file using base64 linux utility:

 

Access BIG-IP/BIG-IQ unit via ssh to access CLI interface.

Access UCS backup files directory:

 

cd /var/local/ucs/

 

Run base64 encoding command:

 

base64  myUCSbackup.ucs  > myUCSbackup.base64




Verify base64 encoded file has been generated.




 


Transfer new base64 encoded backup file using SCP command or any file trensfer tool of your choice.


 


Delete original ucs and base64 encoded files to recover disk space.


 


 


Additional Information


 


base64 encoded files should not be generated/manipulated in any system that might add special characters to base64 txt file, this to preserve UCS file integrity; otherwise, resulting backup file will be rendered unusable.
