K10365: The Operating mode of a shadow-copy rule remains in 'Full tree walk' mode

Topic

Summary

If you configure a shadow-copy rule that copies a size-based or age-based fileset, the rule will always operate in Full tree walk mode.

Description

To evaluate size-based and age-based filesets, the ARX system must scan the entire source volume during each shadow copy session. This volume scan is also referred to as a Full tree walk. The ARX system shadow-copy rule uses the full tree walk mode because the ARX system does not store the size, last-accessed time, or last-modified time of files in the ARX metadata.

Note: To view the Operating mode of a shadow-copy rule, use the show shadow command.

Recommendations

If you do not want the ARX system to operate in a Full tree walk mode, configure a shadow-copy rule that copies a name-based fileset. A rule with a name-based fileset can operate in Inline notification mode because the ARX system stores file names in the metadata. In Inline notification mode, the ARX system tracks which directories have changed since the last shadow copy, and examines only the changed directories during the shadow copy session.

Note: You can use the inline-notify and no inline-notify commands to enable or disable Inline notification mode.
