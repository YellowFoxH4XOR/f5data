Description

  • After configuring a DNS Listener, to use for load-balancing DNS queries to a pool of DNS servers, you find that the DNS resolution is timing out

Environment

  • BIG-IP Virtual Server, configured as a DNS Listener

Cause

Although a DNS Listener is essentially the same as an LTM Virtual Server, there is a slight difference in the default configuration of each. When configured as a DNS Listener, the Advanced Configuration options 'Address Translation' and "Port Translation" are disabled. This prevents the the resulting virtual server from being able to forward the traffic to your DNS Pool.

Recommended Actions

  1. Within the Virtual Server's Configuration settings, display the Advanced configuration options.
  2. Enable the Address Translation property, by selecting the checkbox.
  3. Click Update.
