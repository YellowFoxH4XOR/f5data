Topic

You should consider using this procedure under the following condition:

  • You want to restrict access to only web resources defined on the webtop.

Description

By default, a webtop includes the ability for the user to enter custom URLs. Sometimes you may want to remove the URL box from a BIG-IP APM webtop. This restricts access to only web resources that are defined on the webtop.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a BIG-IP APM access policy configured with a webtop resource.

Procedures

Removing the URL box from the hometab

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

For BIG-IP APM 11.4.0 and later the ability to remove the Show URL Entry Field can be specified in the webtop profile of the access profile.

  1. Log on to the Configuration utility.
  2. Navigate to Access Policy > Webtops.
  3. Select an existing webtop profile name that is configured as type Full or click create to create a new webtop type Full profile.
  4. In the Configuration section locate Show URL Entry Field and uncheck the checkbox to the right.
  5. Click Finish if you are creating a new webtop profile or Update if you are modifying an existing webtop profile.
  6. When modifying an existing access profile webtop profile click Apply Access Policy in the upper left corner of the Configuration utility, then click Apply Access Policy.

For BIG-IP APM versions prior to 11.4.0, the URL box can be removed from the hometab by editing the advanced configuration settings of the webtop.

  1. Log in to the Configuration utility. 
  2. Navigate to the Customization: Advanced page:
  3. Under the Branding tab, navigate to Customization Settings>Webtops and click the plus sign (+).
  4. Expand the folder for the webtop you want to customize.
  5. Click Web Applications Hometab Settings.
  6. Click Set of elements to be displayed. 
  7. Delete the following text:

    ,url 

  8. Click Save.
  9. Click Apply Access Policy at the top left of the page.
  10. On the resulting page, click Apply Access Policy to save the change.

Note: You may need to clear your browser cache and restart your browser prior to testing, to view these changes.
