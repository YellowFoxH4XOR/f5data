K000157245: SNMP Temperature OID Value Change in F5OS 1.8.x

Published
2026-03-25

2026-03-25
Applies to

  • F5OS-C: 1.8.0, 1.8.X, 1.8.2, 1.8.1

Source

Description

After upgrading F5 rSeries devices from F5OS-A 1.7.0 to F5OS-A 1.8.x, SNMP temperature OID values are returned as integers (e.g., 174) instead of string values with decimals (e.g., "17.4"). This results in monitoring tools displaying abnormally high temperature readings (e.g., 174°C instead of 17.4°C) if not interpreted correctly.

Environment

SNMP

F5OS

Cause

Changes in F5OS 1.8.0 and later modified the SNMP temperature OID output from a string (with decimal) to an integer value. The MIB now uses a DISPLAY-HINT of "d-1", indicating that the integer value should be interpreted with one decimal place (e.g., 174 means 17.4°C).

Recommended Actions

  • SNMP temperature OID values are now returned as integers in F5OS 1.8.0 and later. The integer value must be divided by 10 (move the decimal one place to the left) to obtain the correct temperature in Celsius.
  • Monitoring tools must be configured to interpret the integer value according to the MIB's DISPLAY-HINT "d-1". For example, a value of 174 should be displayed as 17.4°C.
  • If your monitoring tool displays the value as 174°C, adjust its configuration or parsing logic to apply the decimal shift as specified in the MIB.
  • There is no option on the F5 device to revert the temperature OID output back to string format or to change the unit from Celsius to Fahrenheit. Any such conversion or formatting must be handled on the monitoring/NMS server side.
  • Ensure that the latest F5 MIBs are imported into your monitoring system to support correct interpretation of the OID values.

Additional Information

  • The change to integer output with DISPLAY-HINT "d-1" is compliant with RFC 2579 (Textual Conventions for SMIv2).
  • The DISPLAY-HINT in the MIB is a standard way to indicate how to interpret the integer value (e.g., d-1 = one decimal place).
  • Some SNMP monitoring tools may automatically interpret the DISPLAY-HINT, while others may require manual configuration.
  • The temperature OID and its interpretation are documented in the F5-PLATFORM-STATS-MIB.txt.
