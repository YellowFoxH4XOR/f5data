K74004244: Unable to reactivate existing license on AWS BIGIP due to ''halGetDossier returned error (1): Dossier generation failed'' and K43503050 has already been applied

Description

When trying to reactivate license on BIG-IP AWS Instance, you are getting the error "The Dossier cannot be blank" message similar to below:

tmsh install sys license registration-key XXXXX-XXXXX-XXXXX-XXXXX-XXXXXXX add-on-keys { YYYYYYY-YYYYYYY YYYYYYY-YYYYYYY }

License server has returned an exception.
   Fault code: 51140
   Fault text: Error 51140, The Dossier cannot be blank. - The Dossier cannot be blank.

After running the get_dossier command per K2595: Activating and installing a license file from the command line, the below error shows:

get_dossier -b XXXXX-XXXXX-XXXXX-XXXXX-XXXXXXX

<131>Jan 01 01:02:02 ip-10-10-10-1 get_dossier[28609]: 01170003:3: halGetDossier returned error (1): Dossier generation failed.

Environment

  • Amazon Web Services (AWS) metadata service
  • BIG-IP Virtual Edition in AWS
  • License reactivation error

Cause

Amazon Web Services (AWS) added a token-based Instance MetaData Service API (IMDSv2). Prior versions of BIG-IP Virtual Edition supported only a request/response method (IMDSv1). The latest version of BIG-IP Virtual Edition now supports instances started with IMDSv2.

Recommended Actions

With the latest version of BIG-IP VE, for example 15.1.5.1 or 16.1.2.1, you can now initialize IMDSv2 only instances in AWS and migrate your existing instances to IMDSv2 only using aws-cli commands.

For more information including the BIG-IP versions that support IMDSv2, refer to the following:

  • ID968657 on bugtracker
  • Instance Metadata Service Version 2 (IMDSv2) on Clouddocs
  • Use IMDSv2 in AWS documentation
