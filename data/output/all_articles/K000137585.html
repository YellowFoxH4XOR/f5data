K000137585: ASM policy blocks allowed URLs after an upgrade

Type
Support Solution
Published
2023-11-14
Updated
2026-09-09
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000137585

Description

After upgrading the BIG-IP TMOS software, ASM begin blocking requests to URLs in the allowed URL list. The requests are blocked due to the "Illegal URL" violation.

Environment

  • BIG-IP AWAF/ASM
  • BIG-IP TMOS was upgraded recently

Cause

This occurs because the allowed URL object’s "Content Profile" reference is not inserted and is missing from the policy configuration database after the upgrade.

This issue is tracked under Bug ID1280813.

Recommended Actions

The workaround is to delete the allowed URL entries and re-add them in the security policy.

An alternative workaround for ID1280813 is to export the affected policy in XML format and then import the policy back in XML format. This approach typically requires less effort than manually recreating the allowed URLs, especially if the policy contains a large number of URL entries.
