Known Issue

Note: This issue applies to Internet Explorer 7 and 8. In addition, this issue applies to Internet Explorer 6 for Windows XP SP2 and SP3.

This is the result of a known issue. If you manually disable the F5 Networks Auto Update ActiveX control in Internet Explorer, then attempt to use a Dynamic Application Tunnel Favorite, you will receive a JavaScript error message and the Dynamic Application Tunnel Favorite will fail.

Internet Explorer's controls are enabled and disabled from Manage Add-ons... option of the Tools menu. In the Manage Add-ons window, highlighting F5 Networks Auto Update, and selecting Disable in the Settings panel will disable the control. Thereafter, any attempt to use a Dynamic Application Tunnel Favorite or Web Application Tunnel Favorite will cause Internet Explorer to display a Script Error window (after requesting that you download and install a new browser component), with an error message that appears similar to the following example:

Error: Object does not support this property or method;

Clicking the Yes button in the window will dismiss the window, but the Dynamic Application Tunnel Favorite or Web Application Tunnel Favorite will not run.

F5 Product Development tracked this issue as ID 294536 (formerly CR73432) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

Workaround

Important: Do not disable the F5 Networks Auto Update control.

If you encounter this error message, you can work around this issue by enabling the F5 Networks Auto Update control from the Manage Add-ons... option of the Tools menu.
