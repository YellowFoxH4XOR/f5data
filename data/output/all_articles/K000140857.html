K000140857: LACP LAG with different actor_oper_key values

Type
Support Solution
Published
2024-08-27
Updated
2024-08-27
Applies to
  • F5OS
  • F5OS-C: 1.6.X, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000140857

Description

  • Different actor_oper_key values for ports on different blades.
  • One or more ports in the LACP trunk (aggregate link) will not be able to join the trunk.

Environment

  • F5OS-C 1.6.2
  • Velos
  • LACP LAG

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1497717

Recommended Actions

This issue is fixed in F5OS version in F5OS-C 1.8.0.

Additional Information

None
