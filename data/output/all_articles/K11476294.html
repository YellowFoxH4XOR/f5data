K11476294: Error: Profile is a required property and may not be set to none or an empty value

Type
Support Solution
Published
2021-02-04
Updated
2025-12-05
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K11476294

Description
When attempting to deploy changes from the BIG-IQ onto the BIG-IP. In the /var/log/restjavad.x.log, the below log appears:

[ERROR][Timestamp][/cm/adc-core/tasks/distribute-config/<task job ID>/worker AdcDistributeTaskWorker] Transaction <transaction ID> on BIG-IP <IP address> failed after 0 seconds: "profile" is a required property and may not be set to "none" or an empty value

Environment

  • BIG-IQ CM
  • Application Deployment

Cause
In some cases, The BIG-IQ tries to patch the tunnel (s) with an empty profile. For more information, refer to ID 970033.

Recommended Actions

Patch the profiles with a different ifIndex:

  1. Write all tunnels to a file
restcurl /cm/adc-core/working-config/net/tunnels/tunnel | jq .items[] -c > /var/tmp/wc
restcurl /cm/adc-core/current-config/net/tunnels/tunnel | jq .items[] -c > /var/tmp/cc
  1.  Diff content of ifIndex
cat /var/tmp/cc | jq .id -r | sort | while read uuid ; do grep $uuid  /var/tmp/cc | jq .ifIndex > /var/tmp/mycc ; grep $uuid  /var/tmp/wc | jq .ifIndex > /var/tmp/mywc ; diff /var/tmp/mywc /var/tmp/mycc >/dev/null ; if [ $? -eq "1"  ] ; then echo $uuid ; fi  ; done > /var/tmp/diffout
Make sure that diffout contains UUID only, and test one of them to check the difference.

 

  1. Create a file named fixTunnel.sh with the below content:
TUNID=$1
restcurl "/cm/adc-core/current-config/net/tunnels/tunnel/$TUNID" | sed -e 's/current/working/g' |  jq 'del(.generation,.lastUpdateMicros)' > workfinal
curl "localhost:8100/cm/adc-core/working-config/net/tunnels/tunnel/$TUNID" -X PUT -d @workfinal | jq .
  1. Use the existing fixTunnel.sh script to correct the ifIndex:
    cat /var/tmp/diffout |  while read UUID ; do echo $UUID ; ./fixtunnel.sh $UUID ;  done
    At the end of the procedure, you can re-run steps 1 and 2 again, and confirm that /var/tmp/diffout is empty.
