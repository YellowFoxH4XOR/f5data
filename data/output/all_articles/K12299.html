Known Issue

This is the result of a known issue. If a user performs a custom installation of the BIG-IP Edge Client that has been downloaded from a FirePass version 7.0.0 device, they may see an option to install the Traffic Control Services feature. However, if they select that feature and attempt to complete the installation, the installation will fail. The user will receive an error message that appears similar to the following example:

Source file not found: C:\<installation_directory>\F5TrafficSrv.exe. Verify that the file exists and that you can access it.

The f5trafficsrv.exe file is not included in the download package and is not currently a supported feature for FirePass users.

F5 Product Development is tracking this issue as ID 342772.

This issue has been fixed in cumulative hotfix HF-70-5 for FirePass version 7.0.0

Workaround

This error message can be resolved by extracting the BIG-IP Client msi installer, deselecting the Traffic Control Services option, and performing the installation again.

  1. Extract the BIG-IP Edge Client msi installer. For details on extracting the msi installer, refer to K9606: Installing Windows client components from a command line or script.
  2. Run f5fpclients.msi.
  3. Click the Next button.
  4. Click the Custom icon.
  5. Click Traffic Control Service.
  6. Select X Entire feature will be unavailable.
  7. Click the Next button.
  8. Click the Install button.
