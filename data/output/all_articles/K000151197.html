K000151197: Cookies containing double quotation marks (") in their values may be truncated by BIG-IP ASM/Advanced WAF before being forwarded to the backend server.

Type
Support Solution
Published
2025-05-06
Updated
2025-05-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 16.1.3, 16.1.4, 16.1.5, 16.1.6, 15.1.7, 15.1.8, 15.1.9, 15.1.10, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000151197

Description

BIG-IP ASM/WAF is truncating cookie values before forwarding requests to the backend servers. This behaviour occurs when cookie values contain double quotation marks ("). As a result, some cookies are delivered to the server with incorrect values, potentially causing various application malfunctions depending on how those cookies are used.

Example:

Cookie received in the client request:

'Cookie: pageCache="{\"sord\":\"desc\",\"page\":\"0\",\"nd\":\"1617864648351\",\"sidx\":\"l.VERSION_NO\",\"rows\":\"10\"}"; JSESSIONID=AD934305A39200CA8B1D0F6C68E8B754; 
TS01a95a8e=01a1d43c86136b002f5cdb3ebab2575df3a7bd11c9bafb36ddd51444f93f7081935f525e1eb0240d33a535bc2eab11141aecf9f6422e709615b85164e0f8a17759ac74536f1aaa24a9ef24bfc7b86c948bfb2a9b71c00f34c9ec17504dddc4482a1cf0671b'

Cookie load balanced to the server (pool member):

Cookie: pageCache="{\"; JSESSIONID=AD934305A39200CA8B1D0F6C68E8B754\r\n  <<<<<<!!!!!

pageCache cookie value is truncated. (Please note that here TS cookie is dropped and its by design, TS cookies are for ASM use, not for the application servers)

Environment

  • BIG-IP ASM
  • Cookies having double quotation (") in the value.

Cause

ID1014973

Recommended Actions

As part of the fix to ID1014973 a new db variable is introduced, however this is disabled by default. Please perform below actions to enable it.

1.Log in to the CLI BASH and execute the below command.

/usr/share/ts/bin/add_del_internal add include_double_quotes_in_cookie_value 1

2. Restart asm

bigstart restart asm

3. Verify the variable value correctly changed from BIG-IP UI by navigating to Security ›› Options : Application Security : Advanced Configuration : System Variables and looking for this variable.

Important: This change will be included in the configuration sync to the peer device. However, you must restart ASM on each device individually. Restarting ASM can trigger a failover, so it's recommended to perform this during a maintenance window.

Additional Information

The above variable is only available in ID1014973 fixed version, please refer the bug tracker article to check the fixed versions. Bug ID 1014973: ASM changed cookie value.
