Known Issue

Attempting to modify virtual servers in a BIG-IP GTM server object using the Traffic Management Shell (tmsh) may fail.

This issue occurs when the following condition is met:

  • You attempt to modify a virtual server in a BIG-IP GTM server object using the replace-all-with method.

    For example:

    modify /gtm server server1 virtual-servers replace-all-with { test_vs2 { destination 192.168.1.100:80 } }

    In the previous example, note the following:

    - server1 is the name of the server within the data center, and test_vs2 is the name of the virtual server on that server.

Impact

Users are unable to use the replace-all-with method for modifying virtual servers in a BIG-IP GTM server object using tmsh.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You see an error message similar to the following when you use the tmsh utility:

    The requested Virtual Server (/Common/<gtm-server-name> ) was not found.

Workaround

To work around this issue, you can use the Configuration utility to make the modification, or delete and add each individual virtual server using the tmsh utility. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Using the tmsh utility to delete and add BIG-IP GTM virtual server objects

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To delete a virtual server, use the following command syntax:

    modify /gtm server <server> virtual-servers delete { <vs_name> }

    Note the following:

    - <server> is the name of the server within the data center, and <vs_name> is the name of the virtual server on that server.

    For example:

    modify gtm server server1 virtual-servers delete { test_vs2 }

  3. To add a virtual server, use the following command syntax:

    modify gtm server <server_name> virtual-servers add { <vs_name> { destination <ip_address:port> } }

    Note the following:

    - <server_name> is the name of the server within the Data Center.

    - <vs_name> is the name of the virtual server on the server you would like to add.

    - <ip_address:port> is the IP address and port of the virtual server.

    For example:

    modify gtm server server1 virtual-servers add { test_vs2 { destination 192.168.1.1:80 } }

  4. Repeat the previous steps to delete and add the required number of virtual servers for your configuration.
