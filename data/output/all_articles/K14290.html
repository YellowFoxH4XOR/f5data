Known Issue

BIG-IP APM network access resources that use the client proxy auto configuration do not properly resolve host names.

This issue occurs when the following conditions are met:

  • You enable Client Proxy Settings in a network access resource.
  • The client browser is Internet Explorer.

Beginning in BIG-IP 11.1.0, F5 added support to the proxy configuration to support IPV6. This required the use of the isInNetEx function, which does not resolve host names to IP addresses and can cause entries that the host or domain names configure to be incorrectly identified.

Impact

Client traffic may not be able to access resources that require access through a proxy server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Clients that access a resource that must use the proxy server fail to connect to the resource.

Workaround

To work around this issue, you can populate the DNS address space. To do so, perform the following procedure:

Populating the DNS address space adds the appropriate JavaScript function to the proxy configuration file.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Access Policy.
  3. Click Network Access.
  4. Click the name of the network access resource that contains the proxy configuration.
  5. Click the Network Settings tab.
  6. In the DNS Address space DNS box, enter the DNS domain name of the DNS name space that will be directed to the proxy host.
  7. Click Add.
  8. Repeat steps 6 and 7 for each additional DNS name space.
  9. Click Update.
  10. In the upper-left corner, click the Apply Access Policy link.
  11. Click Apply Access Policy.
