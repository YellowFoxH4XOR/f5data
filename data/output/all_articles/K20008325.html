Known Issue

Excessive local logging may occur when you configure high-speed logging (HSL) incorrectly.

This issue occurs when all of the following conditions are met:

  • You configure your BIG-IP system to use remote HSL with the destination log server type of ArcSight.
  • You configure components other than BIG-IP AFM, ASM, or SWG to use the ArcSight remote HSL log filter.

Impact

The remote HSL functionality fails to forward log data to the ArcSight server.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system writes log data to the local device at the debug log level.
  • Your BIG-IP system steadily uses increased local storage. In extreme cases, the system uses all of the local storage, causing poor system performance or a system failure.

Resolution

Status

F5 Product Development has assigned ID 409062 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can configure log filters that publish logs to ArcSight for only the supported components of BIG-IP AFM, ASM, and SWG systems.
