Description

After a vCMP Guest has had it's state changed to provisioned, you see the Host show it in permanently in a 'stopping' state.

When you mouse over to the vCMP guest, the following error message can be seen.
slot id: 1; Status: Stopping; Comment: Stopping
Note: slot id refers to the slot the vCMP is deployed.

Environment

  • Administrator changes vCMP Guest State
  • vCMP Guest Triggers restart due to failsafe condition

Cause

Due to  ID 720651, Guests do not stop and change status until vcmpd process is restarted

Recommended Actions

To address the issue, it is recommend you upgrade the vCMP host to a software version not effected by this issue. Note: Refer to ID 720651 in Related Content for a list of unaffected versions

If upgrade cannot be done in a timely manner either of the follow options may recover the guest or guests. Note: Both options will effect all guests on the vCMP Host
  • Restart vcmpd
    bigstart restart vcmpd
  • Reboot vCMP Host
    reboot
