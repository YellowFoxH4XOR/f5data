K000149867: Tenant deployment on a blade fails with the error "Tenant deployment failed – Platform is not ready."

Support Solution

2025-03-05
Updated
2026-07-07

  • F5OS-C: 1.8.X, 1.8.2, 1.8.1, 1.8.0
Source

Description

When attempting to deploy a tenant on an F5OS Chassis system, the deployment fails with the error: "Tenant deployment failed – Platform is not ready."

Logs and diagnostics may show the following symptoms:

  • Firmware update errors on the affected blade: firmware-update-status EVENT NA "Firmware update for vqf 0 generated an error"
  • Blade health warnings:

Service ready status ok warning false

Service health monitor error ok warning No response to ready request

Service health monitor error count ok warning <value>

  • The cluster state for the affected blade shows dma-agent-state stuck at DMA_AGENT_INIT, while other blades are at DMA_AGENT_RDY.

Environment

  • F5OS - Chassis
  • Deploying tenants in multi-blade Velos chassis environment.

Cause

The root cause of this issue was identified as a hardware defect in one of the compute blades (blade-1). The defective blade was unable to complete firmware updates or achieve platform readiness, resulting in tenant deployment failures.

Recommended Actions

To resolve this issue, follow these steps:

  1.  Reboot the affected blade using the chassis partition webU:. Navigate to SYSTEM SETTINGS > General. Select "Reboot" next to the slot containing the affected blade.
  2. Verify if rebooting resolves the issue by checking tenant deployment status and cluster readiness.
  3. Perform a PXE Clean Install of the Affected Blade: If rebooting does not resolve the problem, perform a clean install of the affected blade using PXE boot as per K000130388: VELOS PXE clean install of compute blade.
  4. If issues persist after a clean install, generate fresh qkview files from both partition and controller levels and contact F5 Networks Support.
