Topic

If you have received a USB memory stick containing the BIG-IP software installation 2.0 with your Return Materials Authorization (RMA) device, you may encounter errors and subsequent failure when attempting to install the BIG-IP system on hosts with mirrored RAID hard disks.

This issue affects BIG-IP 6900, 8900, 7000, and 11000 platforms that are running with mirrored hard disk drives. Hosts with solid state drives (SSD) or single non-RAID configurations are not affected.

Note: This tool is only distributed by the F5 RMA team, and is not the same as the Bootable USB Thumb Drive created when you use the mkdisk utility.

Description

If you see errors similar to the following examples, review the recommendations that follow to complete the software installation.

error: requested volume sdc.dat.boot does not exist

error: failed to mount boot volume sdc.dat.boot

error: requested volume sdc.dat.boot does not exist

error: failed to mount boot volume sdc.dat.boot

info: Creating standard volumes for cpmirror

error: tm_install::MultiVolume::MultiVolume_size_scheme -- array cpmirror has no members present

info: adding cpmirror.dat.share, size 0...

error: tm_install::CpMirror::CpMirror_volume_add -- requested multi-disk has no members present.

error: MultiVolume_add cpmirror.dat.share failed.

Installing with command:

# image2disk --format=volumes --nosaveconfig --nvlicenseok /usbrma/images/BIG-IP/BIGIP-11.2.1.797.0.iso

info: Expert mode enabled for non-TMOS context.

info: Repository tm_install version/release is 2.7.5/47.0

info: System tm_install version/release is 2.8.2.1/4.0

info: Platform id is <platform id>

Terminal error: Could not find a Volume Set to retrieve configuration and/or license from. at /usr/sbin/image2disk line 146.

umount: /usbrma: device is busy

umount: /usbrma: device is busy

WARN: Error unmounting USB flash drive.

Recommendations

When you attempt to install a BIG-IP image using the BIG-IP software installation 2.0 USB memory stick, perform one of the following procedures to work around the issue:

  • Performing a manual install using the bootable USB memory stick
  • Performing a clean installation using a user-created bootable USB key

Performing a manual install using the bootable USB memory stick

The following procedure allows you to bypass the error with the USB 2.0 memory stick. You must enter all commands using the serial console. For additional information on connecting a serial console, refer to K7683: Connecting a serial terminal to a BIG-IP system.

Impact of procedure: All hard disks and other attached storage devices on the BIG-IP system will be erased and formatted, and you will be unable to recover any data.

  1. Reboot the BIG-IP device with the USB key inserted into one of the USB ports of your BIG-IP system.
  2. When you see the following text, press Ctrl + C:

    Terminal type? [vt100]

  3. To make sure the USB device is unmounted, type the following command:

    umount /usbrma

    If the following example error appears, you can safely ignore it:

    umount: /usbrma: not found

  4. Physically remove the USB memory stick from the BIG-IP system.

    Important: If you fail to remove the USB memory stick, the system could erase the memory stick in the next step.

  5. To erase and format all attached disks, type the following command:

    diskinit --style volumes

  6. Physically re-insert the USB memory stick into the BIG-IP system.
  7. To mount the USB memory stick, type the following command:

    mount LABEL=USBRMA /mnt/thumb/

  8. All available BIG-IP images should now be available from the /mnt/thumb/images/BIG-IP/ directory, and you can list them by typing the following command:

    ls -l /mnt/thumb/images/BIG-IP/

  9. To install a particular image, use the following command syntax:

    image2disk --instslot=MD1.1 --nosaveconfig --nosavelicense /mnt/thumb/images/BIG-IP/<image>.iso

    In the previous example, <image> is the name of the BIG-IP image you want to install.

    For example, to install the BIG-IP 11.2.1 image, you would type the following command:

    image2disk --instslot=MD1.1 --nosaveconfig --nosavelicense /mnt/thumb/images/BIG-IP/BIGIP-11.2.1.797.0.iso

  10. Once the installation is complete, unmount the USB thumb drive by typing the following command:

    umount /mnt/thumb

  11. To reboot the BIG-IP system to complete the install, type the following command:

    reboot

Performing a clean installation using a user-created bootable USB key

You can create a single-version bootable USB key by following the directions in K13117: Performing a clean installation of BIG-IP 11.x - 13.x or Enterprise Manager 3.x. Note that not all USB memory sticks are compatible. You may choose to use the memory stick provided by the F5 RMA team, but this will erase the USB memory stick and you will be unable to attempt the previous procedure.

Impact of procedure: All hard disks and other attached storage devices on the BIG-IP system will be erased, formatted, and you will be unable to recover any data.
