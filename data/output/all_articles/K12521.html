K12521: Requests containing Expect: 100-Continue headers now bypass WebAccelerator processing

Issue

Starting in BIG-IP WebAccelerator 10.1.0 HF2 and 10.2.0 HF1, if an HTTP request contains an Expect: 100-Continue header, the request bypasses the BIG-IP WebAccelerator processing. When requests are bypassed, the BIG-IP WebAccelerator features, such as content assembly, cannot be utilized. This change was introduced as part of ID 324322 and ID 328307, which resolved an issue regarding Expect: 100-Continue headers and stalled connections.

Note: When WebAccelerator processing is bypassed, the X-PvInfo response header includes an S code of S10413.

Previously, HTTP requests containing Expect: 100-Continue headers were processed by the BIG-IP WebAccelerator system.
