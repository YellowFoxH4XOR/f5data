Topic

BIG-IP LTM+APM Microsoft SharePoint access configurations require the use of persistent cookies.

Description

BIG-IP APM access profiles, used in conjunction with a BIG-IP virtual server that load balances Microsoft SharePoint servers, require the use of APM persistent cookies. The persistent cookies are stored locally on the user's device when accessing the SharePoint LTM+APM virtual server. Alternatively, you can configure the BIG-IP APM system to use portal access to the Microsoft SharePoint resource instead of storing persistent cookies on local device storage.
