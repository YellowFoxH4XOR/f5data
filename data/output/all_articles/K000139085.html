K000139085: Some fields in Nginx App Protect security logs are base64 encoded

Type
Support Solution
Published
2024-03-28
Updated
2024-03-28
Source
https://my.f5.com/manage/s/article/K000139085

Description

  • Some fields in Nginx App Protect security logs are base64 encoded
  • In the Nginx App Protect security logs the fields URL, Username and httpRequest are encoded in Base64

Environment

  • Nginx App Protect configured
  • Nginx App Protect security log directive is configured with json_log for the format_string

Cause

This is expected behavior when using the json_log format string. All string data taken from traffic are encoded in base64. This is necessary because traffic-based contents may contain arbitrary binary data, and JSON strings are limited to UTF-8. The JSON document structure does not support binary data.

Recommended Actions

No action is required. Functioning as designed.

Additional Information

Example configuration:

{
  "filter": {
    "request_type": "illegal"
  },
  "content": {
    "format": "user-defined",
    "format_string": "%json_log%", 
    "max_request_size": "4k",
    "max_message_size": "32k"
  }
}
