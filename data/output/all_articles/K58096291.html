Description

Due to bug ID 748044, BIG-IP administrators may encounter a scenario where the BIG-IP incorrectly reports the actual status of RAID array. In some cases, it may appear to be replicating for longer than expected. A sample output may look like the following:

# tmsh show sys raid array
---------------------
Sys::Raid::Array: MD1
---------------------
Size (MB)  931.5K

---------------------------------------------------------
Sys::Raid::ArrayMembers
Bay ID  Serial Number    Name  Array Member  Array Status
---------------------------------------------------------
1       WD-WX2222222222  HD2   yes           ok
2       WD-WX1111111111  HD1   yes           replicating

Environment

  • RAID-capable BIG-IP platforms running on the affected version.

Cause

  • Bug ID 748044.

Recommended Actions

Run the "array" command from Bash CLI to get an accurate status of RAID.

# array

Bay  name    t/s/r count         state         Serial Number
---  ----    -------------       -----         -------------
1.1  HD2     20/20/0             ok            WD-WX2222222222
1.2  <empty>                                   <none>
2.1  HD1     20/20/0             ok            WD-WX1111111111
2.2  <empty>                                   <none>

(Legend: t = total, s = synchronized, r = replicating)

If the actual status differs from the output of the command "tmsh show sys raid array", the condition can be cleared by rebooting the device. Otherwise, further RAID troubleshooting would need to be performed.
