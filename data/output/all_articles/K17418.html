Known Issue

Description

The BIG-IP APM Machine Info agent may not recognize legacy logon clients.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy is configured with the Machine Info agent.
  • A user initiates a connection to the BIG-IP APM system through a legacy logon client.

Machine Info agent is only supported for web logon browsers and BIG-IP Edge Clients. However, when connecting through a legacy logon client such as mobile clients and Linux CLI, the Machine Info agent does not produce an error.

Impact

The Machine Info agent provides no indication of an unsupported logon client, which leads to unexpected behavior.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When connecting through a legacy logon client, the access policy session stops at the Machine Info agent.
  • When connecting through a legacy logon client, the Machine Info agent completes but does not record machine information in session variables (session.machine.*).
  • When connecting through a legacy logon client, the BIG-IP APM system does not create an error session variable.

Workaround

There is no workaround. However, you can use the BIG-IP APM Client Type agent in the access policy to distinguish between legacy logon clients and supported logon clients. By taking this action, you can ensure that only the Machine Info agent is only used for supported logon client branches.
