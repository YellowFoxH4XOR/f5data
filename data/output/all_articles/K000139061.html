Description

You're looking for a way to perform SSL client authentication against HTTPS Virtual Server and redirect users with revoked certificates to a specific webpage.

 

Environment

  • LTM
  • HTTPS Virtual Server
  • SSL Client Authentication with CRL check

Cause

There's no native way to achieve this.

 

Recommended Actions

Following iRule can meet the requirements.

You need to configure clientssl profile option Client Authentication to "Request" (to initially allow all invalid client certificates).

==========

CLI:

(tmos)# modify ltm profile client-ssl <my-clientssl-profile> peer-cert-mode request

 

GUI:

Local Traffic ›› Profiles : SSL : Client ›› my-clientssl-profile ›› Client Certificate

==========

 

 

And then using iRule you can reject or redirect the clients with invalid certificates on the HTTP layer:

==========

when CLIENTSSL_CLIENTCERT {

if { [SSL::verify_result] == 0 } {}

elseif { [SSL::verify_result] == 23 } {

 set cert_revoked 1

}

else {

 reject

}

}

 

when HTTP_REQUEST {

 if { $cert_revoked } {

   HTTP::redirect "https://my-error-page.com"

 }

}

==========
