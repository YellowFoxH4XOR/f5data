Description

Unable to install/update new ASM Attack signatures due to the Error "ASM-AttackSignatures_<date>.im failed to upload. An update file with the same file location already exists."

Environment

  • Update ASM attack Signatures

Cause

The issue occurred because the Tomcat daemon froze and became unresponsive.

Answer/Recommended Actions

Note: Restarting the Tomcat daemon will not disrupt production traffic managed by TMM. It is safe to run on a production BIG-IP system.

1)_ Back up the current Live Update signature files:
    
    tar zcvf /var/tmp/$HOSTNAME-live-update-backup.tar.gz /var/lib/hsqldb/live-update/*

2)_ Restart the Tomcat service:
    
    bigstart restart tomcat
