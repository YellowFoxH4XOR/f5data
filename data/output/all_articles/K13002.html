Known Issue

A file history archive database for a volume with more than 20 million files may be too large for the ARX to parse.

This issue occurs when all of the following conditions are met:

  • The file history archive was created for a volume with greater than 20 million files.
  • The show file-history archive <archive_name> contents command is used to parse the specified archive.

Impact

You cannot obtain detailed archive information for a file on any given dates.

Symptoms

As a result of this issue, you may encounter the following symptoms when running the show file-history archive <archive_name> contents command:

  • The error.log file contains XML parser errors similar to the following:

    :SNAPD-0-ERR-MSG3:: XML SAX Parser fatal error 'Unterminated start tag, &apos;Export&apos;' on line 325, col 94

    :SNAPD-0-ERR-MSG3:: XML SAX Parser fatal error 'Expected equal sign' on line 336, col 31

  • A files volume name is parsed incorrectly and is preceded with an _ instead of a /.
  • As a result of the incorrect volume name, the associated namespace is not found, resulting in subsequent error messages similar to the following:

    :SNAPD-0-ERR-MSG3:: ParseConfigForNspace: No namespaces found in '/home/acopia_file_history/VFANPC01-1 affa70e-6bca-11df-a636-517c0227d397/2011/06/06/FS1/_VOLUME1'
    :SNAPD-0-ERR-MSG3:: Volume is '_VOLUME1' but should be '/VOLUME1'
