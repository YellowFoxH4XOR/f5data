K000160596: BIG-IQ warning "For BIG-IP versions 14.0.0 and greater, a cipher group must be configured unless TM Option 'No TLSv1.3' is enabled. Deployment will FAIL."

Type
Support Solution
Published
2026-04-08
Updated
2026-04-08
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.1
Source
https://my.f5.com/manage/s/article/K000160596

Description

  • You have parent profile which is using TLS1.3.
  • You have child SLL profile which is inheriting the settings of parent SSL profile and the child SSL profile is attached to virtual server.
  • When you do a configuration evaluation on BIG-IQ, you see below warning message:
    For BIG-IP versions 14.0.0 and greater, a cipher group must be configured unless TM Option 'No TLSv1.3' is enabled. Deployment will FAIL.
  • Despite the warning, deployments succeeds and there is no negative service impact observed in production traffic.

Environment

  • BIG-IQ
  • Managed BIG-IPs
  • SSL profiles using TLS1.3

Cause

At the moment looks like cosmetic issue - BIG-IQ is unable to recognize that the parent profile has appropriate cipher group configured and child SSL profile is inheriting those settings.

Answer/Recommended Actions

Check box the cipher group box on the child profile which BIG-IQ is reporting the warning. This can be done either in BIG-IP or BIG-IQ.

Additional Information

Disabling TLS1.3 (enabling "No TLS1.3") will also suppress the warning, but is not recommended if TLS1.3 traffic is required.
