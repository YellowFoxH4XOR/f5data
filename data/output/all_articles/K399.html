Known Issue

This is the result of a known issue. When you run the config command, you may receive the following error:

ERR: An instance of 3dnsd (pid:xxx) is already running!  Exiting.

This error is harmless. The config command is designed to check for, and stop, any instance of 3dnsd that is running.

F5 Networks Product Development tracked this issue as CR27501 and CR41826.
