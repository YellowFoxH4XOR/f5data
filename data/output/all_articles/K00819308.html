Description

This article highlights the locations of the diagnostic logs for each of the BIG-IP APM VPN clients.

Environment

  • BIG-IP Edge Client on Windows and MAC
  • Linux f5fpc VPN client
  • VPN Browser clients (Windows, Mac, Linux)
  • F5 Access (IOS, Android, Chrome, Windows, Mac)

Cause

None

Recommended Actions

When troubleshooting various BIG-IP APM VPN related issues, F5 recommends that you collect log files from the client device as part of the troubleshooting effort. The following table provides reference to client logs that are available, the log collection method, and F5 Support's recommended method.

BIG-IP Edge Client MacWith recent security improvements, logs may be found in user or system log locations (or be present in both):
  • User Logs in ~/Library/Logs/F5Networks/
    • edge.log
    • install.log
  • System Logs in /Library/Logs/F5Networks/
    • policyserver.log
    • svpn.log
    • svpn_proxy.log
    • f5fwctl.log 
      (with Always Connected mode)
    • f5fwctl.pid
Logs will be created only when specific modules are being used.

When collecting logs it is also useful to collect the configuration files at:
  • /Library/Application\ Support/F5Networks/config.f5c
  • /Library/Application\ Support/F5Networks/f5fwctl.xml
    (if used for Always Connected Mode)
 
  • Manual Log Collection
  • Manual Log Collection. Run the following command to save the logs on the Desktop in a file called edgeclientlogs.zip:

    zip  ~/Desktop/edgeclientlogs.zip ~/Library/Logs/F5Networks/*

    Note: In recent versions, the system library may not be readable by non-administrator users.

    Use the following multiple commands to first create a zip of the main logs and then add the other privileged logs and configuration files (if present)

    zip  ~/Desktop/edgeclientlogs.zip ~/Library/Logs/F5Networks/*
    cd /Library/Application\ Support/F5Networks/
    sudo zip  ~/Desktop/edgeclientlogs.zip /Library/Logs/F5Networks/*  config.f5c f5fwctl.xml

    Note some of the path names above have spaces so these are escaped with a left slash, the line starting with sudo will prompt for your password, and this will leave the file on the Desktop as still owned by root.

F5 Access Mac
  • In ~/Library/Group Containers/*.group.com.f5.access.macos/
    • Application.log
  • In /var/root/Library/Group Containers/*.group.com.f5.access.macos/
    • PacketTunnel.log
    • DNSProxy.log (if config uses it)
  • Manual Log Collection required

Note that, on recent MacOS versions logs have been moved to a randomly numbered group container, such as "57P3AG5GS.group.com.f5access.macos".

Use the following multiple bash commands to first create a zip of the Application logs and then add the other privileged logs (if present):

DIR_NAME=$(find ~/Library/Group\ Containers -maxdepth 1 -type d -name "*.group.com.f5.access.macos" -exec basename {} \;)

zip f5access.zip ~/Library/Group\ Containers/$DIR_NAME/Application.log

sudo zip f5access.zip /var/root/Library/Group\ Containers/$DIR_NAME/PacketTunnel.log

sudo zip f5access.zip /var/root/Library/Group\ Containers/$DIR_NAME/DNSProxy.log
