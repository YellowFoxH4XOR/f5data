Description

The latest version of PostgreSQL uses scram-sha-256 however F5 version is old and needs Md5
psql: authentication method 10 not supported


Environment

ASM 
LTM

 

Cause

F5 software has PostgreSQL v9.3.2 built-in software, and the 9.3.2 version is old and password encryption is not supported.

Recommended Actions

Till the F5 third party software comes with the new version of PostgreSQL, Change the password_encryption of the user to MD5 in the PostgreSQL DB configuration which is used in the monitor on server side.

Example
Replace \"md5\" with \"scram-sha-256\" in pg_hba.conf and restart PostgreSQL.
