Known Issue

This is the result of a known issue. Attempting to remove the last NTP server entry using the Configuration utility fails, and the IP address for the NTP server remains in the list.

F5 Networks Product Development is tracking this issue as CR75138.

This issue does not exist in BIG-IP version 9.4 or later.

Workaround

To work around this issue, you can remove the NTP server entries from the command line. To do so, perform the following procedure:

1. Log in to the command line.

2. Clear the list of NTP servers by typing the following command:

bigpipe db ntp.servers \<null\>

3. Save the changes made by typing the following command:

bigpipe save

4. Activate the change made to the ntp.servers db key by typing the following command:

/usr/bin/tw_activate_keys ntp.servers

5. Verify that the changes made are now active by typing the following command:

bigpipe db ntp.servers

For example:

# bigpipe db ntp.servers
ntp.servers = <null>

When the output reports <null>, the NTP server list is now clear. This change will also be reflected in the Configuration utility, and new NTP servers can be added to the list.
