Description

Unable to publish policy in configuration utility, getting error remoteSender:<ip_address>, method:PUT

  • Create new access policy in apm
  • Attempt to publish policy takes very long time
  • After get error message in configuration utility similar to
        remoteSender:<ip_address>, method:PUT

Environment

  • APM configured
  • Modifying existing policy or publishing a new policy

Cause

Bug ID 858189: Make restnoded/restjavad/icrd timeout configurable with sys db variables.

Recommended Actions

To resolve this issue, it is recommended to restart restjavad daemon

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the restjavad process, type the following command:

    restart sys service restjavad
