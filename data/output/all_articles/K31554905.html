Known Issue

iSeries platforms may continuously log Host Power Cycle Event messages to the /var/log/sel file.

This issue occurs when all of the following conditions are met:

  • You are running one of the following iSeries platforms: i5600, i5800, i7600, i7800, i10600, or i10800.
  • The platform's complex programmable logic device (CPLD) code is 0x45 or earlier.
  • You perform any of the following procedures:
    • You use the Always-On Management (AOM) system to shut down the host subsystem.
    • You use the LCD touchscreen to shut down the host subsystem.
    • You run the halt command from the BIG-IP system command line.
  • After waiting a few seconds, you use the AOM system or the LCD touchscreen to turn on the host subsystem.

Note: You can find the CPLD version in the Hardware Version Information section of the tmsh show sys hardware command output.

For example:

Hardware Version Information
Name cpld
Type cpld
Model F5 CPLD
Parameters -- --
version 0x45

Impact

Continuous message logging may affect AOM interface performance, and the system's /var file system may eventually reach 100 percent capacity.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice messages similar to the following examples are logged to the /var/log/sel file every two seconds:

    1b3f 02/07/18 07:57:10 INF Host Power Cycle Event
    1b40 02/07/18 07:57:12 INF Host Power Cycle Event

  • You experience performance delays while managing the BIG-IP system with the AOM interface or the LCD touchscreen.

Workaround

To work around this issue, you can perform a graceful restart on the device by turning the power off and then back on. To do so, perform the following procedure:

Impact of workaround: The following procedure halts all traffic processing until the unit completes the restart cycle. You should perform this procedure during a planned maintenance window.

  1. Log in to the BIG-IP system Advanced Shell (bash).
  2. To shut down the system, type the following command:

    shutdown -H now

  3. Shut down the system using either the local power distribution unit (PDU) or by unplugging the power cables.
  4. Turn on the system using either the local PDU or by plugging the power cables in.
