K000136148: SDC and EMS Configuration Manager communication

Type
Support Solution
Published
2024-12-17
Updated
2024-12-17
Applies to
  • Traffix SDC: 5.1.0
Source
https://my.f5.com/manage/s/article/K000136148

Description

  • In a multi-site setup, SDC CM will attempt to connect the both EMS CM. It is set in the /opt/traffix/sdc_version/sysconfig/traffix.
  • When running netstat, you will notice all SDC components will have established connections to the CM as it is also in-charge of config change, status update.
  • A good way to view their connection relationship is using the webui > topology > sdc components > site internal connections and filter for the cm service port.
  • SDC CM also needs to ask EMS CM for the config, only when SDC CM confirms EMS CM isn't reachable then it starts to use its local xml config files.
  • These are the CM communications between each nodes.

SDC node to EMS node = 1 connection to each EMS CM ; SDC IP dynamic port to EMS IP port 61617.

SDC node to SDC node = 2 connections ; SDC 1 IP dynamic port to SDC 2 IP port 61617 and SDC 1 IP port 61617 to SDC 2 IP dynamic port

EMS node to EMS node = 2 connections ; EMS 1 IP dynamic port to EMS 2 IP port 61617 and EMS 1 IP port 61617 to EMS 2 IP dynamic port


Environment

  • SDC 5.1
  • Configuration Manager
  • SDC and EMS

Cause

By Design.


 Recommended Actions
