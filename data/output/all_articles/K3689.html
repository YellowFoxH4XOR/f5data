K3689: Routes are removed from the /etc/netstart and /config/routes files after upgrading

Applies to

Topic

In versions 4.5.11 and 4.6.3, BIG-IP and 3-DNS introduced an official means of loading static routes. During the installation of these or later versions in the 4.x software branch, the routes that are included in the /etc/netstart file are moved to the new /config/static_routes file. In addition, if a /config/routes file exists, it is converted to the new /config/static_routes file and the original file is renamed /config/routes.bkp.

In versions prior to 4.5.11 and 4.6.3, the /config/routes file was used to automatically execute commands when the system was booted. This procedure no longer works in BIG-IP versions 4.5.11, 4.6.3, and later, because the /config/routes file no longer runs during boot.

In order to restore commands that were included in the /config/routes file, add the commands to the /config/startup file. BIG-IP will execute the /config/startup file on startup in the same manner that BIG-IP executed the /config/routes file prior to this change.

For additional information, refer to K3687: Managing static routes.
