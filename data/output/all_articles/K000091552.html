Description

  • You want to build your own Nginx Plus Ingress Controller image using Nginx source code following Building the Ingress Controller Image
  • You meet all of the Prerequisites
  • You cloned the directory and uploaded Nginx-repo.cert/key files to kubernetes-ingress folder
  • You attempted to build the image but failed with the below error

 Environment

  • Nginx Ingress Controller Image
  • NGINX Plus
  • Make

 Cause

  • Invalid certificate or expired subscription 

 Recommended Actions

  • Check certificate and subscription validity following article How to verify nginx-repo.cert validity before pulling or building Nginx Plus image
  • Alternatively, simply download fresh cert/key from your myF5 portal https://account.f5.com
