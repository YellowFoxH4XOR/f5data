K000160279: Client Side Defense fails silently when no route to API server

Type
Support Solution
Published
2026-03-09
Updated
2026-03-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160279

Description

When no TMM route to the API server exists, Client Side Defense (CSD) fails to deliver CSD Javascript to clients. Symptoms include:

  • Clients receive an empty 200 OK when requesting CSD javascript files
  • No log message is generated
  • No statistics are generated indicating failure
  • If a default management route exists, the API pool may be marked up

 

Environment

  • Client Side Defense profile configured
  • No TMM route to the CSD API pool (including no default route)

 

Cause

CSD requires a TMM route to the API pool, as requests for CSD Javascript are proxied via BIG-IP.


Additionally, due to Bug ID 2229625 the requests fail silently.

 

Answer/Recommended Actions

Configure a TMM route to the CSD API pool. This may be a default route.

 

Additional Information

None.
