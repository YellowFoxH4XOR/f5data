Known Issue

The httpd process fails to start when you attempt to remove a previously configured httpd include directive. This issue occurs when all of the following conditions are met:

  • You configured the httpd include directive using the bigpipe httpd include or tmsh modify sys httpd include command
  • The httpd include directive consists of the following syntax:

    include /config/httpd/conf.d/*.conf
  • You attempt to remove the directive using the bigpipe httpd include none or tmsh modify sys httpd include none command

Impact

The BIG-IP Configuration utility is not accessible.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Configuration utility is not accessible
  • When you attempt to perform the bigpipe httpd include none or tmsh modify sys httpd include none commands, the BIG-IP system logs error messages to the command line and the /var/log/ltm file; the error messages appear similar to the following example:

    01070920:3: Application error for confpp: Syntax OK
    STDERR/STDOUT text begins
    Reconfiging httpd: /etc/init.d/httpd: line 120: kill: (2798) - No such process
    [FAILED]
    STDERR/STDOUT text ends
    *************************************************************
    /etc/init.d/httpd: line 120: kill: (2798) - No such process
    Reconfiging httpd: [FAILED]

Workaround

To work around this issue, you can manually remove the offending configuration entry from the httpd configuration. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP command line.
  2. Backup the /config/httpd/conf/httpd.conf file by typing the following command:

    cp -p /config/httpd/conf/httpd.conf /var/tmp/httpd.conf.sol13073

  3. Use a text editor of your choice to edit the /config/httpd/conf/httpd.conf file.
  4. Locate the offending configuration entry that appears similar to the following example:

    Note: This entry should be located at the end of the httpd configuration file.

    Include /config/httpd/conf.d/*.conf

  5. Remove the offending configuration entry from Step 4.
  6. Save the modification and exit the text editor.
  7. Restart the httpd process by typing the following command:

    bigstart restart httpd

  8. Remove the offending configuration entry from the BIG-IP configuration by typing the following command:

    tmsh modify sys httpd include none

  9. Save the modification by typing the following command:

    tmsh save sys config
