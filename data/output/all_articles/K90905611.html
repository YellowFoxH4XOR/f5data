Issue

Error Message

tmsh[<PID>]: 01420001:2: <tmsh error message>

In this error message, note the following:

  • <PID> is the process ID for the TMOS Shell (tmsh) process.
  • <tmsh error message> is the error that tmsh encountered. Typically, the format appears as <error message>:<cause or reason>.

For example:

crit tmsh[10671]: 01420001:2: connect() failed: Connection refused

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • Possible user input issue causes an internal operation error. As a result, tmsh session may terminate, and the system logs this message.

Example messages

Possible error messages include the following:

Error messages related to idle timeout

  • Unable to call thread method watch_time_left: 
  • Unable to access user tty path
  • Failed to create timeout thread:

Error messages related to internal functioning of tmsh 

Note: These may be related to user input.

  • fatal:  <error_string>
  • exception:  <error_string>
  • cfg exception:  <error_string>
  • std exception:  <error_string>
  • unexpected exception
  • boost assertion failed: <error_msg> file: <filename> line: <line_number>

Impact

tmsh terminates, and the system produces the error message.

Recommended Actions

Review the command syntax to ensure you are properly formatting and using it.
