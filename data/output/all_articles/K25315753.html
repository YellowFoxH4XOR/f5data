Issue

Error Message

01071436:5: CMI listener established at <IP address> port <TCP port>

In this error message, note the following:

  • <IP address> is the IP address used to accept remote centralized management infrastructure (CMI) connections.
  • <TCP port> is the TCP port used by the local mcpd process when connecting to the local Traffic Management Microkernel (TMM).

For example:

01071436:5: CMI listener established at 192.168.10.100 port 6699

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The mcpd process has initialized and created a listener to accept incoming CMI connections.

The local mcpd process connects to the local TMM process using TCP port 6699. The local TMM then creates secure connections to remote CMI peer TMMs using TCP port 4353.

Note: CMI is also referred to as device service clustering (DSC).

Impact

None. The message is informational.

Recommended Actions

For more information about DSC technology, refer to K13946: Troubleshooting ConfigSync and device service clustering issues (11.x - 12.x).
