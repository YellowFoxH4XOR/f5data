Topic

Resource Groups and Master Groups were introduced in FirePass software version 5.0 FP 1-3. A FirePass administrator can define a collection of resources (Resource Group), and assign one or more Resource Groups to a collection of users (Master Group). These groups provide the administrator with granular control of user access, and simplify administration by eliminating the need to configure several similar groups.

Resource Group

A Resource Group is a collection of resources (also called favorites), access control lists, and protection criteria. Within this collection of resources include your company's intranet servers, applications, and network shares. With Resource Groups, you can define sets of resources and control access to these resources discretely.

Master Group

A Master Group is a collection of users. It contains authentication settings, overall security configuration settings for groups of users, network access filtering policies, user experience (appearance and sequence of the user’s home page), and user accounts, if you are maintaining users on the FirePass controller. With Master Groups, you can define sets of users, and enforce different authentication requirements and security settings for different groups. Each user who connects to the FirePass controller is associated with only one Master Group, but you can assign multiple Resource Groups to a single Master Group.

For additional information and specific instructions about configuring Resource and Master Groups, refer to the FirePass Controller Administrator Guide.
