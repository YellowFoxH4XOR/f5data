Description

Configsync is successful, but pool member status does not match between peer units.
 

Environment

  • BIG-IP all versions
  • Device group, Active/Active or Active/Standby
     

Cause

Monitor packet is generated by each device. Configsync synchronize only configuration but not status.
Monitor status can be different between devices in the device group.
 

Recommended Actions

  • Check "Manual resume" is enabled in the montor applied to node/pool. Further information, please check:  K83316932: Overview of the Manual Resume feature for BIG-IP LTM monitors
  • Take tcpdump and troubleshoot further
    e.g. tcpdump -ni0.0nnn -s0 host <self ip> and host <pool member ip> and host <pool member port> -w /var/tmp/<output file name>.pcap
