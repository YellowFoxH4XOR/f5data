Known Issue

Data group elements larger than 65535 bytes may fail to load and cause TMM to fail when referenced.

This issue occurs when the following condition is met:

  • You are referencing an external data group element from within an iRule.
  • You have data group elements larger than 65535 bytes.

Impact

The BIG-IP system may temporarily fail to process traffic and fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The TMM process fails and produces a core file in the /var/core directory.

Resolution

Workaround

To work around this issue, you can use individual data group entries that are smaller than 65535 bytes in length.
