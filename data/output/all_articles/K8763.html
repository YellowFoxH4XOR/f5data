Known Issue

This is the result of a known issue. If a user launches a Network Access connection from the FirePass webtop using Internet Explorer 6.0 (IE6), and then clicks on a Portal Access or Application Access favorite, FirePass opens a pop-up window reporting an error message that appears similar to the following example:

You navigated away from the FirePass Webtop.
Do you want to close current Application Tunnel/VPN connections?

The correct behavior is for FirePass to open the Portal Access or Application Access favorite without reporting an error message.

F5 Networks Product Development tracked this issue as CR95104 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-601-11 issued for FirePass version 6.0.1 and cumulative hotfix HF-602-4 issued for FirePass version 6.0.2.  You may download the hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can click the Cancel button in the error message pop-up window to allow the Network Access connection to remain open. You can prevent the error message from occurring by selecting the Leave VPN Connection/Application tunnels open when webtop is closed check box on the Network Access: Global Settings page in the FirePass Administrative Console.

Important: The Leave VPN Connection/Application tunnels open when webtop is closed option is disabled by default. Before enabling this option, review the potential security and load implications to your environment. For example, you may not want to enable this option if users logon to the FirePass controller using a public or shared terminal, or if your licensed concurrent session limit is frequently reached.
