Description

This article explains how to create and assign a custom logging profile on the BIG-IP system to locally log Application Security Manager (ASM) events. This is useful for auditing, troubleshooting, and monitoring web application firewall activity.

Environment

  • BIG-IP ASM

Steps

To monitor and audit security policy activity, you can configure a custom logging profile on the BIG-IP system to locally store Application Security events. Once created, this logging profile can be assigned to any Virtual Server where logging is needed.

Create a Logging Profile

  1. On the Main tab, navigate to:
  2. Security > Event Logs > Logging Profiles.
  3. Click Create to open the "Create New Logging Profile" screen.
  4. In the Profile Name field, enter a unique name for the new logging profile.
  5. Check the Application Security box.
  6. Additional configuration fields will appear.
  7. Under the Application Security tab:
    • Set Configuration to Advanced.
    • For Storage Destination, ensure Local Storage is selected.
    • (Optional) Enable Guarantee Local Logging to log requests even under high system load.
  8. Set Response Logging as needed:
      • Off: Do not log responses.
      • For Illegal Requests Only: Log responses only for illegal requests.
    • For All Requests: Log all responses (typically used with All Requests filter type).
  9. Configure the Storage Filter > Request Type:
    • Illegal requests only
    • Illegal requests, and requests that include staged attack signatures
    • All requests

       10. (Optional) Use Advanced Storage Filter settings for more granular control.

       11. Click Finished to save the logging profile.

 

Assign the Logging Profile to a Virtual Server

  1. On the Main tab, go to:
  2. Local Traffic > Virtual Servers.
  3. Select the Virtual Server you want to configure.
  4. On the Security tab of the Virtual Server settings, click Policies.
  5. In the Log Profile section:
    • Set the dropdown to Enabled.
    • From the available profiles list, select your newly created logging profile and move it to the Selected list (left side).

       6. Click Update to apply the changes.

Check Event Logs:

  1. Navigate to:
    Security > Event Logs > Application > Requests

  2. You should see log entries corresponding to the traffic that triggered ASM enforcement or staging rules.

  3. Use filters such as "Illegal Requests", "Staged Signature Matched", or date/time ranges to narrow results.
