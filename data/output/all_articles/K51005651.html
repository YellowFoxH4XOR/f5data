Source

Description

Enable BIG-IQ Events Logging for managed BIG-IP Web Application Security Events

Environment
  • Managed BIG-IP device provisioned with Application Security Manager (ASM)
  • BIG-IQ Centralized Management v7.0.0
  • BIG-IQ Data Collection Device (DCD) v7.0.0

Cause
None

Recommended Actions

  • Activate Web Application Security events logging service for one or more BIG-IQ Data Collection Devices (DCD).
  • Create a basic illegal requests only logging profile with a remote storage destination of BIGIQ selected.
  • Associate the logging profile to the virtual server used by the web security policy.

Activate Web Application Security events logging service for one or more BIG-IQ Data Collection Devices (DCD).

BIG-IQ Centralized Management requires Web Application Security service activation to be enabled for viewing Web Application Security event logs from multiple BIG-IP devices.

  1. At the top of the screen of the BIG-IQ, click System, then, on the left, click BIG-IQ DATA COLLECTION >>  BIG-IQ Data Collection Devices.
    The BIG-IQ Data Collection Devices screen opens listing the data collection devices in the cluster. The Services column lists the BIG-IP services monitored by each DCD.

  2. Access the properties of the desired DCD device(s) by selecting on the Device Name.
    The properties screen for the data collection device opens.

  3. Select the SERVICES option on the left hand column. 
    The screen displays a listing of available services.

  4. For the Web Application Security service, confirm that the Listener Address and Listener Port are correctly set, and then click Activate.
    When the service is successfully added, the Service Status changes to Active.

  5. Click Save & Close.

Create a basic illegal requests only logging profile with a remote storage destination of BIGIQ selected.

To set up remote logging for Application Security Manager (ASM), you need to have created a logging profile with Application Security enabled. You can configure a custom logging profile to log application security events remotely to BIG-IQ.

  1. On the Main tab of the BIGIQ, click Configuration >  Web Application Security >> Shared Security >>  Logging Profiles.
    The Logging Profiles list screen opens.

  2. Click Create.
    The Create New Logging Profile screen opens.

  3. In the Name field, type a unique name for the profile.

  4. Select the Application Security option on the left hand column.
    The screen displays the Application Security status.

  5. On the Application Security status page, set status as Enabled.
    The screen displays additional fields for both Configuration and Storage Filter. 

  6. In the Configuration section, set Local Storage to Disabled. 

  7. In the Configuration section, set Remote Storage to Enabled. 
    The screen displays additional fields.

  8. For the Logging Format field list, select BIG-IQ 

  9. For the Server Addresses list, populate the IP Address list for the DCD logging devices and click Add
    Optional: Populate any other fields as necessary. 

  10. Click Save & Close.

Note: For information about application security events logging configuration, refer to Logging Application Security Events 

Associate the logging profile to the virtual server used by the web security policy.

A logging profile determines where events are logged and what details are included. By default, when you create a security policy, the system associates the Log Illegal Requests profile with the virtual server used by the policy. You can change which logging profile is associated with the security policy or assign a new one to the virtual server.

  1. On the Main tab of the BIGIQ, click Configuration >>  Web Application Security >> Virtual Servers 

  2. Click on the Virtual Server Name in order to access it's properties.

  3. In the Properties page click on the hyperlink that reads "To configure Shared Security Virtual Server settings, please click here".
    The system displays the general properties of the virtual server.

  4. Relocate the newly created Logging Profile over to Selected area. 

  5. Click Save & Close.

Evaluate and deploy the virtual server logging profile changes.

Note: For information about managed configuration change deployment, refer to Evaluating and Deploying Changes

Viewing Web Application Security Event Logs

BIG-IQ Centralized Management enables a single view of all filters and log entries (and details for each entry) from multiple managed BIG-IP devices. 

  1. Click Monitoring >> Events >> Web Application Security >> Events

Additional Information

Bidirectional communication over TCP port 8514 between the managed BIG-IP devices and the BIG-IQ data collection devices are required for Logging profile communication of Web Application Security log events.
