K09458125: Low available space in /appdata partition

Support Solution
Published
2021-01-29

2023-02-21

  • BIG-IP Analytics: 15.1.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0

Source
https://my.f5.com/manage/s/article/K09458125
Description

/appdata partition is almost full.
 Following command output shows it. 
# df -h
Filesystem                              Size     Used    Avail      Use%     Mounted on
/dev/mapper/vg--db--vda-dat.appdata     25G      21G     2.3G       91%      /appdata  

Environment

  • ASM
  • AVR
Cause

This is due to the corruption is the AVR/PRX database .
Following command output shows the database corruption
 
# mysqlcheck -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password(user => q{root})'` -A | tee /var/tmp/mysqlcheck.out | grep -v "OK"
 
AVR.AVR_STAT_ASM_NETWORK_T
Error    : Out of resources when opening file './AVR/AVR_STAT_ASM_NETWORK_T#P#T_2021_0122_170001_1611363601.MYD' (Errcode: 24)
Error    : Can't open file: './AVR/AVR_STAT_ASM_NETWORK_T.frm' (errno: 24)
error    : Corrupt
PRX.REQUEST_LOG
Error    : Out of resources when opening file './PRX/REQUEST_LOG#P#p94200001.MYD' (Errcode: 24)
Error    : Can't open file: './PRX/REQUEST_LOG.frm' (errno: 24)
error    : Corrupt
 

Recommended Actions

If there is any error or corruption messages to the CLI like above , then run the following command to repair the database .
 
   # mysqlcheck -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password(user => q{root})'` -A -r
 
After successful repair /appdata usage went low.
 
# df -h
Filesystem                              Size      Used    Avail      Use%     Mounted on
/dev/mapper/vg--db--vda-dat.appdata     25G       5.5G    19G       23%      /appdata
