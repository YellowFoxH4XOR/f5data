K30803921: BIG-IQ stat collection is not supposed to work on vCMP hosts

Type
Support Solution
Published
2019-11-26
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K30803921

Description

Stats collection via BIG-IQ is not supported on vCMP hosts.
Enabling stats collection on a vCMP host will not yield accurate results such as hardware health and resource utilization.
 

Environment

  • BIG-IP vCMP systems being managed by BIG-IQ CM and DCD cluster.
     

Cause

Stats collection requires a fully provisioned AVR module to perform its functions. In systems where AVR is not provisioned, stats collection will not function.
 

Recommended Actions

Make sure that only vCMP guests statistics are being collected via BIG-IQ
 

Additional Information

None
