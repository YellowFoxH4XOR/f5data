Description

When reactivating license in WebGUI, error "File request failed, please check log file for details" is displayed.
 

Environment

  • BIG-IP
  • Reactivation of license
  • WebGUI

Cause

None

Recommended Actions

 

 

Option 1:

 

Follow https://my.f5.com/manage/s/article/K2595#manual_activate to activate a license using the command line and the manual activation method.

 

 

Option 2:

 

Reactivate license in GUI following "manual" procedure, stop when you get the license text file from F5 licensing site.

 

In CLI run commands:

 

cd /config

cp bigip.license bigip.license.backup

rm bigip.license                                Answer "yes" to question

nano bigip.license                            Paste reactivated license text provided by F5 licensing site

ctrl-x                                                 Answer "yes" to save new license file

reloadlic

 

-- Verify unit reloads license and configuration correctly 

 

Additional Information

Consider doing a mcpd forceload procedure to ensure unit is running exactly as configured

Review article: K13030: Forcing the mcpd process to reload the BIG-IP configuration
