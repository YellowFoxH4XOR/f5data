Known Issue

SNMP configuration changes that are made using the Configuration utility are not saved in the bigip_base.conf file.

This issue occurs when all of the following conditions are met:

  • You have installed affected versions of BIG-IP 11.2.1 HF5 or later.
  • You used the Configuration utility to change the SNMP configuration.

Impact

Changes will take effect, but the system will not display them in the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Changes are saved to the /config/snmp/snmpd.conf file, but not to the bigip_base.conf file.
  • Changes are not displayed in the Configuration utility.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to modify SNMP configurations. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To modify the Machine Location in the SNMP configuration, type the following command:

    modify sys snmp sys-location test-location

    Note: You can find additional SNMP modifications within the tmsh utility under sys snmp.
