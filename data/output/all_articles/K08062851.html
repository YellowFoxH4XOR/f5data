Known Issue

If you modify users, a configuration synchronization change conflict might occur.

This issue occurs when all of the following conditions are met:

  • You configure two or more BIG-IP devices in a Sync-Failover device group.
  • You modify the local user configuration on one of the devices by, for example, creating a new user.

The BIG-IP system uses a REST framework to synchronize some configuration elements separately from synchronization performed by the ConfigSync process. When this issue occurs, the user configuration is synchronized to the peer devices, even when Automatic Sync is disabled in the device group settings. The BIG-IP system interprets this as a manual change being performed on the devices and triggers a change conflict.

Impact

The REST framework synchronizes the user configuration to the other devices in the device group causing a change conflict between the devices.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The synchronization status for devices in the device group indicates Changes Pending. For example, the output of the tmsh show cm sync-status command appears similar to the following example:

    -------------------------------------------------------------------------------------------------
    CM::Sync Status
    -------------------------------------------------------------------------------------------------
    Color    red
    Status   Changes Pending
    Mode     high-availability
    Summary  There is a possible change conflict between device1 and device2.
    Details
             device1: connected
             devicegroup1 (Changes Pending): There is a possible change conflict between device1 and device2.
              - Recommended action: Synchronize device2 to group devicegroup1

  • Users that were synchronized by the REST framework have an incorrect role or partition assignment

Workaround

To work around this issue, you can manually synchronize the configuration from the device where the original modification occurred, to the device group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of one of the devices in the device group.
  2. Navigate to Device Management > Overview.
  3. Under Device Groups, click the name of the device group.
  4. Click the device on which the original user modification occurred.
  5. For Sync Options, click Sync Device to Group.
  6. If necessary, select the Overwrite Configuration check box.
  7. Click Sync.
