Description

If for some reason the Admin local user gets locked and you can not longer use the admin user:



Environment

F5OS Appliance

Admin local account


Cause

N/A.


Recommended Actions

If for some reason the Admin local account is locked you can enable it again from the CLI using the following commands from the configuration mode:


[root@appliance-1(R10900-R87-S33) ~]# su admin


Welcome to the Management CLI

admin connected from 1.1.1.1 using ssh on R10900-R87-S33


R10900-R87-S33#


(config)# system aaa authentication users user admin config expiry-status enable

(config)# commit and-quit
