Description

Is it possible to use SAML, OIDC or Kerberos authentication to access the F5 BIG-IP Configuration Utility (Management GUI).

Environment

  • BIG-IP 
  • LTM, APM
  • Remote authentication

Cause

This is product design limitation where the BIG-IP Configuration Utility (Management GUI) does not support advanced authentication mechanisms like SAML or Kerberos, even if the APM module is licensed and provisioned.

APM can provide a "System Authentication" Profile. However this does not support any kind of interaction. Not even a Message Box. OIDC and SAML do not function.

Recommended Actions

The BIG-IP Configuration Utility (Management GUI) can only be accessed using local accounts, remote authentication via RADIUS, LDAP, TACACS+, or Active Directory, and does not support SAML or Kerberos authentication for administration purposes.

 

Additional Information

APM module license will enable advanced authentication methods like SAML and Kerberos for application traffic managed by BIG-IP, but they do not extend to the Management GUI itself.

A change to this is documented as RFE 537968. The intent is to support NIST L4. This is status "Planned" as of the end of 2025.
