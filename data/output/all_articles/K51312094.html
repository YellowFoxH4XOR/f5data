Known Issue

Starting the mcpd process at the command line may cause system instability.

This issue occurs when the following condition is met:

  • You start the mcpd process at the command line while an instance of mcpd is running.

    For example, you type mcpd at the BIG-IP command line, or you mistype a command such as ls | mcpd instead of ls | grep mcpd.

Impact

The system may experience instability, and some utilities are not able to connect to the mcpd process.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Some utilities are not able to interact with the mcpd process.
  • In the /var/log/ltm file, the system logs error messages that appear similar to the following example:

    notice mcpd[29730]: 01071539:5: Mcpd is starting.  The BIG-IP version is 11.5.4.
    err mcpd[29730]: 01070014:3: Initialize MCPListener socket failed.
    crit mcpd[29730]: 01070011:2: Failed to create socket listener (127.0.0.1) for mcpd.

Resolution

Workaround

To work around this issue, you can refrain from starting the mcpd process from the command line while another instance of the process is running.
