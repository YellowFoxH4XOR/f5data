Issue

When attempting to use a Java client enabled web application, you may view the following error message:

java.io.IOException: F5Socket(1): deny connection

This error message is created when the socket connection for the Java client is blocked by an Access Control List (ACL) policy.

To correct this error message, you can check your ACL policy to make sure that the specific host's IP address is not blocked, and that the default policy is not set to Deny. To do so, perform the following procedure:

  1. To view the ACL policy, go to Portal Access: Web Applications: Master Group Settings.
  2. In the Java Sockets Access Control Lists section, review the IP addresses or subnets listed in the Deny List box. If the client's IP address is denied, correct the Deny List to not include the IP address or subnet.
  3. Click the Update button.
  4. If the Default Action drop-down menu is set to Deny, change the setting to Allow.
  5. Click the Update button.

Have your user log in again and confirm that your changes have resolved the issue.
