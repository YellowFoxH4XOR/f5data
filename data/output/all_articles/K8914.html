Known Issue

This is the result of a known issue. If a user accesses an IBM Lotus Domino Web Access (DWA) server through Portal Access, and searches for a valid contact on the Search Contacts screen, no search results are returned. Additionally, the user’s browser may report a scripting error message when the user clicks the search icon.

F5 Networks Product Development tracked this issue as CR99325 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Workaround

You can work around this issue by configuring a Web Application Content Processing Script. To do so, perform the following procedure: 

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Portal Access : Web Applications : Content Processing page.
  3. In the Web Applications Content Processing Scripts section, click the Add New Favorite link.
  4. In the Processing script name field, enter a name for the processing script.

    For example:

    DWA
     
  5. In the URL match patterns field, enter the following:

    *NG.js*
     
  6. In the Content Type field, enter the following:

    text/javascript
  7. In the Sed processing script field, enter the following:

    s@F5_Invoke_getResponseHeader.\([^,]\+\),\([^)]\+\).@\1.getResponseHeader(\2)@g
     
  8. In the Processing menu, select Post-process response data (after content patching).
  9. Click the Add New button.
