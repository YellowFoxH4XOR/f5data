Topic

Beginning with BIG-IP 9.4.0, you can use the HTTP class to rewrite URIs without sending an HTTP redirect to the client. The Rewrite URI setting specifies what TCL expression the system uses to rewrite the request URI that is forwarded to the server. You can configure the Rewrite URI setting when you use the Hosts or URI Paths options in the HTTP Class profile.

Beginning in BIG-IP 11.4.0 and later, the HTTP Class profile is no longer supported. For more information, refer to K14409: The HTTP Class profile is no longer available in BIG-IP 11.4.0 and later.

Note: If you use static text for the Rewrite URI setting instead of using a TCL expression, the system maps the specified URI for every incoming request that matches the class configuration. Additionally, Rewrite URI is not available when the value of the Send To setting is set to Redirect To.

For example, the following two procedures outline two ways that you can use the Rewrite URI setting:

Using the Rewrite URI setting to rewrite the /price.php URI to /index.php

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. From the Protocols box, select HTTP Class.
  5. Click Create.
  6. Type a name for the HTTP Class profile.
  7. From the Parent Profile box, select httpclass.
  8. Select the box next to URI Paths, and from the URI Paths box, select Match only.
  9. Type the following regular expression syntax in the URI Path box:

    (?i)price\.php$

    Note: The syntax (?i) turns on the case insensitivity matching mode modifier inside the regular expression. Your web server may not require case insensitivity matching. Consult your web server documentation for more information. For information about regular expression mode modifier, refer to the following Regex Tutorial. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

    http://www.regular-expressions.info/modifiers.html

  10. From the Entry Type box, select Regular Expression (regex).
  11. Click Add.
  12. Select the box next to Rewrite URI.
  13. Type the following URI in the Rewrite URI box:

    /index.php

  14. Click Finished.

Using the Rewrite URI setting to replace the http://host.com/uri1/index.php URI with http://host.com/uri2/index.php

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. From the Protocols box, select HTTP Class.
  5. Click Create.
  6. Type a name for the HTTP Class profile.
  7. From the Parent Profile box, select httpclass.
  8. Select the box next to URI Paths and from the URI Paths box, select Match Only.
  9. Type the following regular expression syntax in the URI Path box:

    (?i).*uri1.*

    Note: The syntax (?i) turns on the case insensitivity matching mode modifier inside the regular expression. Your web server may not require case insensitivity matching. Consult your web server documentation for more information. For information about regular expression mode modifier, refer to the following Regex Tutorial. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

    http://www.regular-expressions.info/modifiers.html

  10. From the Entry Type box, select Regular Expression (regex).
  11. Click Add.
  12. Select the box next to Rewrite URI.
  13. Type the following TCL expression in the Rewrite URI box:

    [string map { uri1 uri2 } [HTTP::uri]]

  14. Click Finished.

    Once you have created the HTTP Class profile, you must associate it with the virtual server.
