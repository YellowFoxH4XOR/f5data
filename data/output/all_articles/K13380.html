Topic

This article applies to BIG-IP 11.x - 16.x. For information about other versions, refer to the following article:

  • K8442: Configuring the BIG-IP system to use an NTP server from the command line (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP system to use a network time protocol (NTP) server from the command line.

Description

You may configure the BIG-IP system to synchronize its clock with an NTP server. You can use the TMOS Shell (tmsh) to modify or list the NTP settings, as appropriate, for your installation. To do so, perform one of the following procedures:

  • Configuring the BIG-IP system to use an NTP server
  • Configuring the BIG-IP system to use a preferred NTP server
  • Listing the NTP servers configured on the BIG-IP system
  • Removing the NTP server configuration
  • Removing the preferred NTP server configuration

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access tmsh on the BIG-IP system.

    Note: The NTP servers should reside either on the management network or route domain 0 of the BIG-IP system.

Procedures

Configuring the BIG-IP system to use an NTP server

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To configure one or more NTP servers for the BIG-IP system, use one of the following command syntaxes:

    modify /sys ntp servers add {hostname hostname....}

    or

    modify /sys ntp servers add {ip_addr ip_addr....}

    For example, to add NTP servers with the 192.168.1.123 and 192.168.1.124 IP addresses, you would type the following command:

    modify /sys ntp servers add {192.168.1.123 192.168.1.124}

  3. Save the change by typing the following command:

    save /sys config

    Note: F5 recommends that you configure at least three external NTP servers for reliability.

Configuring the BIG-IP system to use a preferred NTP server

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To configure the preferred NTP server for the BIG-IP system, use the following command syntax:

    Note: The edit command opens the ntp configuration using the vi text editor.

    edit /sys ntp all-properties

  3. Replace the include none line with the following command syntax:

    Note: To avoid duplicate NTP servers, specify a unique NTP server that is not listed in the /sys ntp servers.
    include "server hostname prefer"

    or

    include "server ip_addr prefer"

    For example, to prefer the NTP servers with the 192.168.1.123 IP address, you would type the following command:

    include "server 192.168.1.123 prefer"

  4. Save the configuration to memory by exiting the vi editor. To do so, type the following command:

    :wq!

  5. The vi editor will prompt you with a confirmation to save the changes. Type y to confirm.

    For example:

    Save changes? (y/n/e) y

  6. Save the configuration to the configuration files by typing the following command:

    save /sys config

Note: To verify communication with the NTP server, refer to K10240: Verifying NTP peer server communications.

Listing the NTP servers configured on the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To list the NTP servers that are currently defined on the BIG-IP system, type the following command:

    list /sys ntp servers

Removing the NTP server configuration

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To remove the NTP servers that are currently defined on the BIG-IP system, type the following command:

    modify /sys ntp servers none

  3. Save the change by typing the following command:

    save /sys config

Removing the preferred NTP server configuration

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To remove the preferred NTP server that is currently defined on the BIG-IP system, type the following command:

    modify /sys ntp include none

  3. Save the change by typing the following command:

    save /sys config
