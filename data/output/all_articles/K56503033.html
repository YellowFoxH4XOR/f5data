Description

How to view the discovery address of the BIG-IQ in the command line

Environment

  • BIG-IQ v8.x
  • Central Management
  • Data Collection Device
  • Command line access
  • No GUI access

Cause
You want to view the discovery address of your BIG-IQ in the command line when you don't have GUI access

Recommended Actions

  1. Login to command line
  2. Run the following command:
    # cat /var/config/rest/service.config.json | grep discovery

    Example output:
    # cat /var/config/rest/service.config.json | grep discovery
          "discoveryAddress": "10.10.10.11"
