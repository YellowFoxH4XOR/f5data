The wlnode() function allows you to construct an iRule that can read the WebLogic session cookie and persist connections to the IP address and port contained in the cookie.

The syntax for the wlnode() function is as follows:

wlnode(<expression>, <protocol>)

Replace <expression> with an expression that provides the WebLogic session cookie.

For example, if the cookie is named WebLogic, you would enter the following:

http_cookie("WebLogic")

Replace <protocol> with either http or https. Choose the protocol the BIG-IP system should use when persisting the connection.

If it is not able to read the cookie or if the IP address contained in the cookie is not a valid node, the wlnode() function will use the address 0.0.0.0:0.

In the following example, the wlnode() function reads a cookie named WebLogic and sends the connection using the HTTP protocol:

wlnode(http_cookie("WebLogic"), "http")

Note: The wlnode() function was valid only for WebLogic version 6.x. The WebLogic format of the WebLogic session ID has been modified several times since this function was introduced.  For more current versions of WebLogic, F5 Networks recommends using iRules to enforce JsessionID persistence. Examples of this solution are maintained in the DevCentral codeshare at the following location:
