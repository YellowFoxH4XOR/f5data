Known Issue

This is the result of a known issue. By default, the BIG-IP ASM blocks HTTP requests containing non-RFC compliant cookies and displays a Not RFC compliant cookie violation on the Reporting screen. When the BIG-IP ASM processes an HTTP cookie with a space in the cookie name or cookie value, the request is blocked and a Not RFC compliant cookie violation is displayed in the Reporting screen.

If the space character is at the end of a cookie value, the space character is not displayed in the full request output on the Reporting screen. As a result, the non-RFC compliant request appears to be valid.

F5 Product Development tracked this issue as CR114119 and it was fixed in BIG-IP ASM 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.
