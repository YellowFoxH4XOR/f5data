Known Issue

When you attempt to add a device to a Device Trust, the Configuration utility may display ambiguous error messages. 

This issue occurs when all of the following conditions are met:

  • Your attempt to add the peer device to a Device Trust fails.
  • The IP address of the peer device you are adding is not accessible.

The BIG-IP system logs a Java error message that does not clearly indicate why adding the device to the Device Trust fails.

Impact

The Configuration utility displays an ambiguous error message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you try to add the peer, the Configuration utility displays an error message similar to the following example:

    java.ioException: Could not read response from server: ParseError at [row, col]:[1,238] Message: The processing instruction target matching "[xX[mM][L]" is not allowed

Workaround

To work around this issue, you can verify that the peer IP address is correct, and that you are able to route the address before attempting to add it to the Device Trust.
