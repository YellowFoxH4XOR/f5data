BIG-IP can mirror connection and persistence information.

Connections

BIG-IP can mirror TCP or UDP connections that pass through a virtual server or a SNAT. In addition, connections through a virtual server that use other protocols can be mirrored if any_ip, is enabled on the virtual server.

Persistence

BIG-IP can mirror the following persistence information between peers:

  • Simple IP address persistence
  • SSL session ID persistence
  • SIP Call-ID persistence
  • Destination address affinity

Enable Connection and Persistence mirroring when the loss of a session, due to failover, would cause the user's session to be significantly disrupted.

Long term connections, such as FTP and Telnet, are good candidates for mirroring. Generally, HTTP and UDP connections are not good candidates for mirroring, as they allow for failures of individual requests without loss of the entire session.

Enabling Mirroring

Before you can enable connection mirroring for specific virtual servers and SNATs, you must enable mirroring globally. You can enable connection mirroring globally from the Configuration utility or from the command line.

Configuration utility

  1. In the main navigation pane, select System.
  2. Click the Redundant Properties tab.
  3. Check the Stateful Failover Mirror Enable checkbox.
  4. Click the Apply button.

Command Line

  1. Enable mirroring, by typing the following command:
bigpipe global mirror enable
  • Save the change, by typing the following command:
bigpipe save

Enabling Connection Mirroring for a Virtual Server

You can enable connection mirroring for a virtual server from the Configuration utility or from the command line.

Configuration utility

  1. In the main navigation pane, select Virtual Servers.
  2. Click the virtual server you wish to modify.
  3. Check the Mirror Connections checkbox.
  4. Click the Apply button.

Command Line

  1. Enable connection mirroring, by typing the following command:

    bigpipe virtual <address>:<port> mirror conn enable

    Replace <address> with the virtual server address and <port> with the service port.

  2. Save the change, by typing the following command:

    bigpipe save

Enabling Persistence Mirroring for a pool

You can enable connection mirroring for a pool from the Configuration utility or from the command line.

Configuration utility

  1. In the main navigation pane, select Pools.
  2. Click the pool you wish to modify.
  3. Click the Persistence tab.
  4. Check the Mirror Persistence checkbox.
  5. Click the Apply button.

Command Line

  1. Enable persistence mirroring, by typing the following command:

    bigpipe pool <name> { persist_mirror enable }

    Replace <name> with the name of the pool you wish to change.

  2. Save the change, by typing the following command:

    bigpipe save

Enabling Connection Mirroring for a SNAT

You can enable connection mirroring for a SNAT from the Configuration utility or from the command line.

Configuration utility

  1. In the main navigation pane, select NATs.
  2. Click the SNATs tab.
  3. Click the SNAT you wish to change.
  4. Check the Mirror Connections checkbox.
  5. Click the Apply button.

Command Line

  1. Enable connection mirroring, by typing the following command:

    bigpipe snat <address> mirror enable

    Replace <address> with the SNAT address.

  2. Save the change, by typing the following command:

    bigpipe save
