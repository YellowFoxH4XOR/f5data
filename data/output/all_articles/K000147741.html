Description

I want to know how to use the DNS Load Balancer overview dashboard.

Environment

  • F5® Distributed Cloud (XC) Console

Answer/Recommended Actions

Access the DNS Load Balancer dashboard by using the DNS Management tile in the F5 Distributed Cloud Console Home menu.

On this page, you can:

  • Survey the overall health and status of your DNS Load Balancer configuration 
  • View the service overview of each load balancer service in your DNS Load Balancer environment
  • Monitor the status of the pools associated with each of the DNS Load Balancers
