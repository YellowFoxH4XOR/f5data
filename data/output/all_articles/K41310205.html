Description

An IP intelligence database is a list of IP addresses with questionable reputations.

IP addresses gain a questionable reputation and are added to the database as a result of having performed exploits or attacks, or these addresses might represent proxy servers, scanners, or systems that have been infected.

The BIG-IP system can prevent system attacks by excluding traffic from malicious IP addresses by using this IP intelligence database when properly licensed and configured.

To prevent system attacks using the IP Intelligence subscription service the BIG-IP system must be able to connect to Brightcloud's IP intelligence database to download the contents. It can also automatically keep the database up to date. 

The IP Intelligence database itself is maintained online by a third party - Brightcloud.

In BIG-IP versions 13.0.0 and earlier, the hostname vector.brightcloud.com is the third party database server that manages the external IP reputation database and provides updates to the BIG-IP systems with the IP Intelligence subscription.

In BIG-IP versions 13.1.0 and later, vector2.brightcloud.com is the hostname.

In BIG-IP version 15.1.4 and later for the BIG-IP 15.x branch, the following are the hostnames:

  • api.bcti.brightcloud.com (default)
  • localdb-ip-daily.brightcloud.com (base file)
  • localdb-ip-rtu.brightcloud.com (updates)

In BIG-IP 15.1.6, 16.1.3, 17.0.0, and later, the following are the hostnames:

  • api.bcti.brightcloud.com (default)
  • localdb-ip-daily.brightcloud.com (base file)
  • localdb-ip-rtu.brightcloud.com (updates)
  • localdb-ipv6-daily.brightcloud.com (IPv6 updates)

Environment

  • BIG-IP
  • IP Intelligence

Cause

BIG-IP Product Design

Recommended Actions

  1. Ensure that IPI Subscription is in place and the service has been configured.  Please refer to the Product Manual for this. For example, for version 13.1 see Manual Chapter : Enabling IP Address Intelligence
  2. Ensure that the BIG-IP can properly reach the IP reputation database:
    • For versions 13.0.0 and earlier: the public host vector.brightcloud.com has been removed. You can change your public host to vector2.brightcloud.com  using this command:  
      tmsh modify sys db iprep.server value vector2.brightcloud.com
       
    • For versions 13.1.0 and later: ensure that public host vector2.brightcloud.com can be reached through your firewall on port 443
    • For version 15.1.4 and later for the 15.1.x branch: ensure the following public hosts can be reached through your firewall on port 443
      • api.bcti.brightcloud.com
      • localdb-ip-daily.brightcloud.com
      • localdb-ip-rtu.brightcloud.com
    • For version 15.1.6, 16.1.3, 17.0.0, and later: ensure the following public hosts can be reached through your firewall on port 443
      • api.bcti.brightcloud.com
      • localdb-ip-daily.brightcloud.com
      • localdb-ip-rtu.brightcloud.com
      • localdb-ipv6-daily.brightcloud.com

  3. If having connectivity through your firewall does not allow the BIG-IP IPI to work as expected, continue troubleshooting with K03011490:  Verifying connectivity for the IPI Subscription service
