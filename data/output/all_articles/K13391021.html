Issue

Error Message

err mcpd[<PID>]: 01071392:3: Background command '<Command>'  failed.  <Status>

In this error message, note the following:

  • <PID> Is the process id of mcpd.
  • <Command> is the command which mcpd executed.
  • <Status> is the exit status of the command.

For example:

01071392:3: Background command '/usr/bin/set-rsync-mgmt-fw close' failed. The command exited with status 1.
01071392:3: Background command '/usr/bin/rsync-cmi stop ' failed. The command exited with status 3.
01071392:3: Background command '/usr/bin/mprov.pl  --displayminimums' failed. The command exited with status 11.

Message Location

You may encounter this message in the following location:

  • /var/log/ltm
Description

This message occurs when the following conditions is met:

  • The mcpd process fails to execute the shown command
Many components use mcpd to execute a command. If the command fails, this message is logged for the command.
 

Impact

The exact impact depends on the command being run.

Recommended Actions

Further debugging may be possible by increasing the logging level in mcpd to info. For more information on configuring log levels, refer to K5532: Configuring the level of information logged for TMM-specific events.
