K33962833: Client ID is not synced between BIG-IP APM HA pair

Type
Support Solution
Published
2021-04-06
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM: 14.1.2
Source
https://my.f5.com/manage/s/article/K33962833

Description

In the Configuration Utility, navigate to Access  ››  Federation : OAuth Authorization Server : Client Application, the client ID is different between the HA pair.

Environment

  • BIG-IP APM 14.1.2.6
  • Oauth
  • Client Application

Cause

Unknown yet.

Recommended Actions

Please delete the client application on the standby device, then sync the configuration from active device to the standby device.

  1. Login the standby device via admin.

  2. Navigate to Access  ››  Federation : OAuth Authorization Server : OAuth Profile  ››  <OAuth_profile_name>, move the Client Application "Client_App_name" to "Available" list, then click "Update".

  3. Navigate to Access  ››  Federation : OAuth Authorization Server : Client Application, delelet "Client_App_name".

  4. Sync the configuration from active device to standby device.

Additional Information

Maybe the configuration is In-sync, bug the client ID is different.
Maybe the configuration is not synced, and cannot sync, get the error:

Sync Failed
A validation error occurred while syncing to a remote device
Sync error on SZVE-APIGW-LB1A.cmbchina.com: Load failed from /Common/<Hostname> 01071b24:3: The client ID for the client app (/Common/<Client APP name>) cannot be modified.
Recommended action: Review the error message and determine corrective action on the device
