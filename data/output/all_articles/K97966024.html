Known Issue

Windows client systems may fail when establishing a network access session.

This issue occurs when all of the following conditions are met:

  • The client computer is running Windows 8.1.
  • The client system is missing the %systemroot%\system32\drivers\urfltv64.sys file.

Impact

The Windows client system fails and restarts while establishing a network access session.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Windows client system displays the following error message on a blue screen:

    driver_irql_not_less_or_equal (ndis.sys)
