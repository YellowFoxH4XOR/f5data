Known Issue

This is the result of a known issue. When the virtual server discovery feature is enabled on the BIG-IP GTM system, and a virtual server IP address or port is changed on the BIG-IP LTM system, the BIG-IP GTM system does not populate the virtual server name when the virtual discovery feature detects changes to an updated virtual server.

For example, if the BIG-IP GTM system configuration contains a virtual server called http_virtual, and the IP address of the virtual server is changed on the BIG-IP LTM system, the BIG-IP GTM virtual server discovery feature detects the change and updates the virtual server IP address. However, the BIG-IP GTM system does not repopulate the virtual server name.

F5 Product Development tracked this issue as CR93523, and it was fixed in BIG-IP GTM 9.4.2. For information about upgrading, refer to the BIG-IP GTM release notes.
