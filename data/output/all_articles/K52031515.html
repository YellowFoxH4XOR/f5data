Description

You have Verified Accept enabled in the TCP profile and you observed that the traffic received by SSLo has no further forwarding out or responding the same.  

ltm profile tcp /Common/verified-accept {
    app-service none
    defaults-from /Common/tcp
    fast-open disabled
    verified-accept enabled  <----- !
}

Environment

  • SSL Orchestrator module
  • TCP profile with Verified Accept enabled

Cause
Bug ID 842149: Verified Accept for SSL Orchestrator

Recommended Actions

If your setup can afford without Verified Accept enabled, you may consider disabling it.

The bug is scheduled to be fixed in the upcoming 16.1.0 version. If you require an engineering hotfix (EHF), please contact F5 Support to request for the EHF and follow article K55025573 to install it.
