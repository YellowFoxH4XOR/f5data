Description

You have a need to change the license type on an existing BIG-IP managed by BIG-IQ which uses FCP license offerings. This process allows you to make the license changes without losing BIG-IP existing configuration or having to create a new instance.

Environment

  • FCP
  • BIG-IQ
  • BIG-IP

Cause

The FCP license provides you with many options to choose from, based on specific modules, capacity, transactions, and resources. It is not possible to add or remove any of these features, instead, you will need to replace the license with a suitable one.

Recommended Actions

You will need to revoke the license from the existing BIG-IP, which avoids being charged for it in the future. You will select and deploy the new license to the existing BIG-IP.

Impact of action: Traffic processing is briefly interrupted while BIG-IP system services are restarted. F5 recommends performing this operation during a maintenance window.

Re-license process

  1. Log in to BIG-IQ.
  2. Select Devices.
  3. Go to License Management > Licenses.
  4. Select the Name of the license key you will use.
  5. Review and select the Offering Name you will use.
  6. Under Assignment, select License Devices.
  7. Ensure Unit of Measure is set to YEARLY.
  8. Add a Chargeback Tag to identify this instance (optionally leave blank).
  9. If your BIG-IP is:
    • Managed: Select the device from the list
    • Not managed: Fill in Device Address, confirm Port, Username, and Password.
  10. Select Assign in the bottom right side of the screen.
  11. Confirm Assignment select OK.
  12. Notice under Assignments BIG-IP is now licensed with a Green status.
