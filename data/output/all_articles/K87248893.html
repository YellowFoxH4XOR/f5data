Description:

Failure may happen when the client performs SAML IDP/SP login after the APM system reboot.

The system may log an error message in /var/log/apm similar to the following example:

014d1105:3: <access_policy_name>:SAML:<session_id>:SAML SSO: Error creating signed SAML message - failed to find certificate: <certificate_name>

In the log message example, note the following:
  • <access_policy_name> is the name of impacted access policy which is using the corresponding SAML SSO
  • <session_id> is the id of impacted session
  • <certificate_name> is the name of the certificate which is assigned to the SAML SSO

Environment:
  • BIG-IP 
  • APM module is provisioned
  • SAML Single-Sign-On is deployed
Cause:

Bug ID 768025

Recommended Actions:
 
For workaround information and fixed versions, refer to Bug ID 768025: SAML requests/responses fail with "failed to find certificate"
