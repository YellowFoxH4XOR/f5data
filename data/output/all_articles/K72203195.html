Description

Is there a way (via GUI or CLI) to understand if the BIG-IP is setting the DF bit.

For example if a connection to a server behind the BIG-IP arrives at it when it sends the return traffic will it set the DF bit or not?

Environment

  • BIG-IP LTM
  • DF bit

Cause

This is by design.
 

Recommended Actions

BIG-IP supports DF bit.
 

Additional Information

tm.pathmtudontfragoverride dbvar introduced. If the value is changed from 'disable' (this is the default) to 'enable', then DF bit will not be set in IP fragments generated by TMM.

To enable DF bit in the command line;
tmsh modify sys db tm.pathmtudontfragoverride value enable

To disable DF bit in the command line;
tmsh modify sys db tm.pathmtudontfragoverride value disable
