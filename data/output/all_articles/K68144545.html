K68144545: One-Click Apply Multiple Policies is no longer available in BIG-IP ASM 15.1.0 and later

Type
Support Solution
Published
2021-10-19
Updated
2024-12-20
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.0.X, 14.1.0, 14.0.1, 14.1.2, 14.0.0, 14.X.X, 14.1.3, 14.1.X, 14.0.X, 15.0.1, 15.0.0, 14.1.5, 14.1.4
Source
https://my.f5.com/manage/s/article/K68144545

Description

One-Click Apply Multiple Policies was introduced in BIG-IP ASM 14.0.0; however; it is no longer available in BIG-IP ASM 15.1.0 and later versions.

Environment

  • BIG-IP ASM 15.1.0 and later versions
  • Security > Application Security > Security Policies > Policies List page

Cause

The Policies List page was redesigned in BIG-IP ASM 15.1.0 to display the name, enforcement mode, virtual servers, last modified date/time, and OWASP compliance. The Perform action on multiple policies screen that appeared when multiple policies in the list were selected was removed.
 

Recommended Actions

None
