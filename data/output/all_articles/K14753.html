Issue

Error Message

BIG-IP 11.4.0 and later

com.f5.tmui.util.Syscall$CallException: Error: Failure to create certificate <cert-name> with error: Key management library returned bad status: -32, Invalid Subject Alternative Name

In this error message, note the following:

  • cert-name is the name of the SSL certificate

For example:

com.f5.tmui.util.Syscall$CallException: Error: Failure to create certificate testCert with error: Key management library returned bad status: -32, Invalid Subject Alternative Name

BIG-IP 11.2.0 through 11.3.0

com.f5.tmui.util.Syscall$CallException: Error: Failure to create certificate <cert-name> with error: Key management library returned bad status: -7, error:2207507C:X509 V3 routines:v2i_GENERAL_NAME_ex:missing value

In this error message, note the following:

  • cert-name is the name of the SSL certificate

For example:

com.f5.tmui.util.Syscall$CallException: Error: Failure to create certificate testCert with error: Key management library returned bad status: -7, error:2207507C:X509 V3 routines:v2i_GENERAL_NAME_ex:missing value

Message Location

When a user attempts to create a self-signed or Certificate Authority (CA) certificate, the BIG-IP Configuration utility reports the error message in the following location:

  • System > File Management > SSL Certificate List > Create

Description

This message occurs when all of the following conditions are met:

  • A user creates a self-signed or CA certificate, and omits the DNS: prefix when entering host name information in the Subject Alternative Name (SAN) field.
  • You click Finished.

Impact

The self-signed or CA certificate is not created.

Recommended Actions

When entering a host name within the SAN field, the host name must be prefixed with a DNS: prefix. Additionally, when entering multiple host names, you must separate each with a comma. For example,

DNS:www.example.example.com, DNS:example.com, DNS:internal.example.com, DNS:www.internal.example.com
