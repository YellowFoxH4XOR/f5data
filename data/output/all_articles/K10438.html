Known Issue

This is the result of a known issue. The volumeset utility, which is used to create virtual volumes on a physical disk, will report an error when run on systems that contain dual hard drives that were initially formatted for BIG-IP version 10.0.0.

The behavior occurs after an LVM installation of BIG-IP version 10.0.0 is upgraded to version 10.0.1 on the BIG-IP 6900 or BIG-IP 8900 platform. Once the system(s) has been upgraded and booted into version 10.0.1, any attempt to use the volumeset utility will result in the following error message to be reported to the console:

Undefined subroutine &tm_install::TMOS::Volume_parse called at /usr/lib/perl5/site_perl/tm_install/TMOS.pm line 616.

F5 Product Development is tracking this issue as ID 327301 (formerly CR125966).

This issue was fixed in Hotfix-BIGIP-10.0.1-342.0-HF1, which has been issued for BIG-IP version 10.0.1, for the BIG-IP 10.0 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
