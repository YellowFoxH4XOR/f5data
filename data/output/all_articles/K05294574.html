Known Issue

An iControl query may not honor CLI global-settings when returning service values.

This issue occurs when all of the following conditions are met:

  • The CLI global-settings is set to display the service number using the following Traffic Management Shell (tmsh) command:

    modify cli global-settings service number

  • You execute an iControl query that is expected to return service number.

Impact

The iControl query returns the service name instead of the service number.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The iControl query always returns the service name, even when you set the CLI global-setting service to number.

    For example, the following iControl query returns the http service name instead of the port number:

    ltm virtual http-server {
        destination 192.168.1.1:http
        ip-protocol tcp
        mask 255.255.255.0
        persist {
            source_addr {
                default yes
            }
        }
        profiles {
            http { }
            tcp { }
        }
        source 0.0.0.0/0
        vs-index 7
    }

However, the tmsh list ltm virtual http-server output may display the virtual with the correct port number.
