Security Advisory Description

A potential vulnerability in some AMD processors using frequency scaling may allow an authenticated attacker to execute a timing attack to potentially enable information disclosure. (CVE-2022-23823 also known as hertzbleed)

Impact

Successful exploitation of this vulnerability could lead to disclosure of sensitive information.

This hardware issue impacts all of the following F5 platforms using AMD processors. For information about hertzbleed and Intel processor platforms, refer to K14335949: Intel processors vulnerability CVE-2022-24436:

  • BIG-IP 6900 (D104)
  • BIG-IP 11000 (E101)
  • BIG-IP 11050 (E102)

Important: The aforementioned BIG-IP platforms have reached End of life (EoL). For more information refer to the EoL table in K4309: F5 hardware product lifecycle support policy.
