Description

If additional client access to BIG-IP is needed beyond default value of 10.

  • Unable to access GUI
  • Login failure

Environment

  • Management Access
  • BIG-IP

Cause

Httpd_errors log:

err httpd[1768]: [error] server reached MaxClients setting, consider raising the MaxClients setting

Recommended Actions

In order to increase the max-clients for HTTP access to management.
 

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To increase the value of the MaxClients setting by typing the following command:

    modify /sys httpd max-clients <value>

  3. Save the configuration by typing the following command:

    save /sys config

  4. Run the following command to verify the chosen value has been updated.
    tmsh list sys httpd max-clients
     
  5. Restart the httpd service by typing the following command:
    restart /sys service httpd

 

Additional Information

Max setting for Client access to Big-IP is 10 clients by default. 

If more clients need access then increase the value for httpd max clients.
