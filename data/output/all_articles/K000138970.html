K000138970: Malicious Source IP Addresses

Type
Support Solution
Published
2024-03-21
Updated
2025-02-12
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000138970

Description

You may observe malicious source IP addresses in Security ›› Event Logs : Application : Requests

Environment

  • BIG-IP ASM
  • Requests Log Summary

Cause

Same source ip is having request status illegal or blocked for more than 10 times.

Recommended Actions

  • Add an IP address exception to the ASM security policy that blocks the IP address. For more information, refer to the Manual Chapter : Managing IP Address Exceptions of the  Manual : BIG-IP Application Security Manager: Implementations guide.

Additional Information

None
