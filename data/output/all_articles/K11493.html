Topic

The Pre-Logon Sequence custom variable, also know as a User Defined Variable (UDV), allows FirePass administrators to define their own unique session variables. Custom variables provide a simple method for storing custom data within a users session.

A UDV can be used anywhere in the FirePass configuration where a regular session variable can be used.

UDV's are configured within the Pre-Logon Sequence Editor found on the Users : Endpoint Security : Pre-Logon Sequence page in the FirePass Administrative console. All UDV's you create must have unique name. To refer to the UDV within the FirePass configuration, prepend the UDV name with session.userdef. and enclose it within percent (%) characters. For example, if your UDV name is MyUDV, you would refer to it as follows:

%session.userdef.MyUDV%

Important: UDV names are case-sensitive. Therefore, if you configured an UDV with the name MyUDV, you would refer to it as %session.userdef.MyUDV%.

UDV's can be assigned simple data, such as a name or number, or can be assigned the value of other session variables. For example:

MyUDV=Bob
MyUDV=%session.os.platform%

Important: UDVs are evaluated at runtime at the moment they are needed. If the UDV references an undefined session variable, an empty string is used for the value of the undefined session variable.

If you want to view all session variables assigned to a user, temporarily enable the Save user's session variables to Logon Reports setting on the Device Management : Maintenance : Troubleshooting Tools page. The next time the user logs on to FirePass, you can view the users's session variables by selecting the user’s logon name on the Reports : Logons page.

Important: Enabling the Save user's session variables to Logon Reports setting will increase the load on the FirePass controller. This setting should only be enabled temporarily for troubleshooting purposes

Defining a UDV in a Pre-Logon Sequence

  1. Logon to the FirePass Administrators console.
  2. Navigate to Users : Endpoint Security : Pre-Logon Sequence.
  3. Click edit next to the name of the Pre-Logon Sequence in which you are adding a UDV.
  4. Mouse over the line next to the step where you want to insert the UDV.
    A plus character (+) appears on the line.
  5. Click the + character.
    The Change Sequence panel will open on the right.
  6. Select New action from the Using drop-down menu.
  7. Click Apply changes.
  8. In the name field type a name for your UDV action.
  9. Click the Update details button.
    The action you just created will appear in your sequence diagram to the left.
  10. Select Define custom variable from the Add new inspector drop-down menu.
  11. Click the Add inspector button.
    A new section appears labeled Inspectors.
  12. Click Define custom variable under the Name column.
  13. In the Expression: field type the name of your variable, the equal sign (=), and the value you want to assign to your variable.

    For example:

    MyUDV=Penguins
  14. Click the Update button.
  15. Optional: You can define multiple UDVs in one Pre-Logon Sequence step by repeating steps 11 to 14.

Your custom variables will be activated by your Pre-Logon Sequence and available for use in FirePass.

Note: If you plan to use your UDVs in your Pre-Logon Sequence, your sequence step defining the UDVs needs to be placed before the step(s) where they are used.

Note: For additional information about defining and using custom variables in Pre-logon Sequences click the HELP link in the FirePass Administrative Console and navigate to Users : Endpoint Security : Inspectors : Define custom variable.
