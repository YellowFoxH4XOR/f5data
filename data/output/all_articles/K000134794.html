Description

You have removed unnecessary OPSWAT EPSEC packages from the BIG-IP APM system as per solution K21175584.
You upgraded first device successfully, but caught an error after upgrading the second device, trying to sync from the first device to the second:
 
rsync: write failed on "/config/filestore/.snapshots_d/epsec_package_d/:Common:EPSEC:Images:epsec-1.0.0-1434.0.iso_63802_1": No space left on device (28)
 
Environment

  • BIG-IP APM,
  • Removed OPSWAT EPSEC package
  • Recent upgrade
  • Device group configuration sync enabled
  • No space left on device

Cause

A known software bug (ID 860205) causes orphaned files to accumulate in /config/filestore/files_d/Common_d/epsec_package_d/ when APM EPSEC package objects are created and deleted over time. These files are not properly removed by standard cleanup procedures, eventually filling the /config partition and preventing successful configuration syncs or other operations that require disk space.

Recommended Actions

Find and remove orphaned Epsec image files using the following procedure:

  1. # cd filestore/.trash_bin_d/.current_d/Common_d/epsec_package_d/
  2. # du -sk *
  3. You will see output similar to the following:

138872  :Common:EPSEC:Upload:epsec-1_519943_1
138872  :Common:EPSEC:Upload:epsec-1_519965_1
138872  :Common:EPSEC:Upload:epsec-1_519969_1

Remove EPSEC orphaned files from directory filestore/.trash_bin_d/.current_d/Common_d/epsec_package_d/
