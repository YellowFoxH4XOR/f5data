Description

This article explains how to permanently set the CLI prompt on F5OS-A or F5OS-C systems. By default, changes to the CLI prompt using the <prompt1> command are temporary and revert after logout. To make the prompt persistent across sessions, use configuration commands to set the oper-prompt or config-prompt value. 

Environment

  • F5OS-A and F5OS-C version 1.8.0 and later.

Cause

Functional question regarding persistent CLI prompt customization.

Answer/Recommended Actions

To permanently set the CLI prompt1 or prompt2 in F5OS-A CLI:

  1. Log in to the CLI with an account that has admin privileges.
  2. Enter configuration mode:
    config
  3. Set the operational prompt (equivalent to prompt1):
    system settings config oper-prompt "<desired_prompt_text>"
  4. Example:
    system settings config oper-prompt "f5os1: "
  5. To set the configuration prompt (equivalent to prompt2), use:
    system settings config config-prompt "<desired_config_prompt_text>"
  6. Commit the changes:
     commit

After committing, the new prompt will persist across CLI sessions and logins.
