K000159881: Cannot configure Virtual server with APM Access Profiles if Client SSL profile has Trusted Certificate Authorities and Session Ticket option enabled

Type
Support Solution
Published
2026-02-04
Updated
2026-02-04
Applies to
  • BIG-IP
  • BIG-IP APM: 17.0.0, 17.1.0, 17.0.X, 21.X.X, 17.X.X, 21.0.X, 21.0.0, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000159881

Description

Cannot configure the following combination of configurations:

Virtual Server + Client SSL profile with Trusted Certificate Authorities and Session Ticket + Access Profile

An MCPD validation error occurs (visible on GUI, TMSH, or /var/log/ltm):

0107174b:3: Client ssl profile attached to virtual </Common/test-virtual> with access profile has either session ticket option enabled or retain certificate not enabled.

Environment

BIG-IP APM

Cause

The behavior is due to a by-design behavior to prevent the APM admin from creating an incompatible configuration.

Answer/Recommended Actions

As the above combination of configuration cannot be configured, consider using other features or another combination of features.
