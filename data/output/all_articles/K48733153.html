Issue

Old Behavior

In versions prior to BIG-IP 11.6.0, you can only assign a user account a single role (level of access). Additionally, you can only assign the user account access to one specific partition, or to all partitions.

New Behavior

Beginning in BIG-IP 11.6.0, you can now define user accounts with multiple roles and/or access to single or multiple partitions.

For example, you can configure a user as an operator for the Common partition, a manager for Partition_1, and a manager for Partition_2.

Note: You can only assign a user a single role for any specific partition. For example, if you configure User1 as an operator for the Common partition, you cannot also configure User1 as a manager for the Common partition. Additionally, you can only assign a single user role to a user if partition All is selected.

F5 Product Development tracked this change as ID 342501.

Impact

This new behavior improves granularity for user access and permission levels.
