K000148683: Unable to rollback to previous boot location after upgrade

Type
Support Solution
Published
2025-03-28
Updated
2025-03-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148683

Description

Upgrading a BIG-IP 5250V (C109) to version 17.1.x results in compatibility issues where the device does not support this version. The attempt to roll back to the previous version is unsuccessful because the option is not available from the GUI.

Environment

  • Software Upgrade
  • Appliance: 5250V (C109)

Cause

The BIG-IP 5250F (C109) platform is incompatible with software version 17.x, as indicated by the F5 hardware/software compatibility matrix.

Recommended Actions

To resolve the issue, perform the steps below from the bash shell:

1.- Verify Boot Locations: Log in to the command line of the BIG-IP system and list available boot locations using: 

switchboot -l

 

2.- Set Default Boot Location: Identify the boot location for the previous version and set it as the default using: 

switchboot -b HD1.<location>

 

3.- Reboot Device: Reboot the system to apply changes: 

reboot

Additional Information

Before upgrading, consult the F5 hardware/software compatibility matrix to ensure that your platform supports the target software version in K9476: The F5 hardware/software compatibility matrix
