K41595502: Upgrade fails with 01070096:3: Virtual server <Virtual Server Name> lists profiles incompatible with its protocol.

Type
Support Solution
Published
2021-03-12
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP AFM: 16.X.X, 16.0.X, 14.1.3, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.1.X, 16.0.0, 15.1.2, 15.1.1, 16.0.1
Source
https://my.f5.com/manage/s/article/K41595502

Description

Upgrading BIG-IP but the the configuration could not be loaded, and the following error is logged in /var/log/ltm:

Error Message: 01070096:3: Virtual server <Virtual Server Name> lists profiles incompatible with its protocol.

Environment

  • BIG-IP AFM
  • FastL4 virtual server (Protocol field configured to either Other or All Protocols)
  • Protocol Inspection Profile
  • After upgrade
    to:    14.1.3.115.1.1 and v16 or later
    from:
    • 13.1.0 - 13.1.3
    • 14.1.0 - 14.1.3
    • 15.0.0 - 15.1.0

Cause

Due to K60344652: BIG-IP AFM vulnerability CVE-2020-27714, the fix is for FastL4 virtual server with an AFM protocol inspection profile requires to set TCP or UDP.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Prior to upgrading, set the FastL4 Virtual Server's Protocol to UDP or TCP.

  2. If it need to have both protocols, create a new exact same Virtual Server but set Protocol TCP/UDP.

  3. Once updated the config copy current location's config to newly installed boot location with the following command
    (or install later version to new boot location)

    cpcfg <new boot location's name>
    e.g. cpcfg HD1.2

  4. Boot from the new version's location.
