K000093139: Delete iRules using restcurl in BIG-IQ

Type
Support Solution
Published
2022-12-08
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000093139

Description

  • There is a need of deleting the iRules left behind when removing a BIG-IP device
IMPORTANT: This command will remove ALL the iRules in the BIG-IQ. 

Environment

  • BIG-IQ
  • Restcurl
  • Configuration left behind.

Cause

Unknown at the time of publication

 

 Recommended Actions

Run these commands in CLI

  • restcurl /cm/adc-core/working-config/ltm/rule | jq .items[].selfLink | awk -F 'mgmt' '{ print $2 }' | sed 's/.$//' >> /var/tmp/irules.txt
  • for i in $(cat /var/tmp/irules.txt) ; do restcurl $i | grep -i name -m 1; restcurl -u admin:<changepassword> -X DELETE $i ; echo "================"; done
  • rm -f /var/tmp/irules.txt.txt
