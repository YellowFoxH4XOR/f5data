Topic

By default, when communicating with a slow or unresponsive pool member, the BIG-IP system sends three SYN retransmissions for a connection before sending a TCP reset to the client system.

Note: For more information about TCP resets, refer to K9812: Overview of BIG-IP TCP RST behavior.

For example, when a client system makes a TCP connection to a BIG-IP virtual server that is configured with a TCP profile and a pool, the BIG-IP system selects a pool member and initiates a TCP SYN request to the server. If the pool member is slow to respond or unresponsive, the BIG-IP system sends three SYN retransmissions to the pool member before sending a TCP reset to the client system to close the connection.

This behavior is by design and controlled by the Maximum SYN Retransmissions TCP profile setting. The Maximum SYN Retransmissions setting specifies the maximum number of SYN retransmissions that the BIG-IP system sends to the pool member before closing the connection. The default setting is three SYN retransmissions.

To adjust the Maximum SYN Retransmissions setting, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles.
  3. From the Protocols menu, click TCP.
  4. Click the relevant TCP profile.
  5. Update the Maximum SYN Retransmissions setting.
  6. Click Update.
