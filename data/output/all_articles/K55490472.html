Topic

You should consider using these procedures under the following condition:

  • You want to configure the BIG-IP system to add an Address Resolution Protocol (ARP) entry to the ARP table only when the system sends non-ARP traffic to a host or node.

Description

By default, the BIG-IP system automatically creates an ARP entry under the following conditions:

  • Your BIG-IP system receives an ARP response from a host in response to its own ARP requests.
  • A host on the network sends an ARP request (who-has packet) to the BIG-IP system.

There may be occasions when you want to configure the BIG-IP system to create an ARP entry only when it needs to send non-ARP traffic to a host or node. When you disable the Reciprocal Update ARP option, the BIG-IP system does not add an entry to the ARP cache in response to receiving who-has packets from a host. Instead, the system creates an ARP cache entry for a host when the system needs to send non-ARP traffic to that host. Disabling the reciprocal update provides a security benefit against certain ARP poisoning attacks by preventing the BIG-IP system from adding ARP cache entries in response to receiving malicious ARP who-has packets from a host.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You can access the Configuration utility or the TMOS Shell (tmsh).

Procedures

  • Using the Configuration utility to disable reciprocal ARP updates
  • Using tmsh to disable reciprocal ARP updates

Using the Configuration utility to disable reciprocal ARP updates

Impact of procedure: Disabling reciprocal ARP updates reduces the performance of the system.

  1. Log in to the Configuration utility.
  2. Navigate to Network > ARP > Options.
  3. Clear the Reciprocal Update check box.
  4. Click Update.

Using tmsh to disable reciprocal ARP updates

Impact of procedure: Disabling reciprocal ARP updates may have a negligible performance impact on the system depending on your specific configuration, deployment, and traffic.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Type the following command:

    modify /sys db arp.addreciprocal value disable
