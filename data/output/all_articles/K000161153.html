K000161153: Error message "Disk usage exceeded threshold. Removing" occurs when uploading tenant image files

Updated
2026-05-07
Applies to

Source

Description

Error message "Disk usage exceeded threshold. Removing" occurs when uploading tenant image files (.tar.bundle or .qcow2.zip.bundle) to F5OS platforms, even though disk usage appears below configured limits. This prevents new tenant images from being added.

Environment

  • F5OS version 1.8.3
  • Disk partition for tenant images: /var/export/chassis
  • VDO (Virtual Data Optimizer) enabled
  • Disk usage checks show logical usage at 34–38%
  • Configured disk usage thresholds: warning-limit 85%, error-limit 90%, critical-limit 97%
  • Both .qcow2.zip.bundle and .tar.bundle image formats tested

Cause

VDO thin provisioning and deduplication cause logical disk usage to be about half the actual physical usage. F5OS enforces a 40% logical usage threshold for VDO-backed volumes to prevent physical disk exhaustion (equates to ~80% physical usage). When logical usage reaches 40%, image uploads are blocked and existing images may be removed, regardless of apparent available space. This threshold is hardcoded and cannot be changed or disabled except by reinstalling F5OS 1.5.1 or later, which does not provision VDO.

Answer/Recommended Actions

  1. Remove unused tenant images from /var/export/chassis to reduce logical usage below 40% before uploading new images.
  2. Verify if VDO is present:
    - Run lsblk and check for a vdo_vol device in the storage stack for /var/export/chassis.
  3. If VDO is present, the 40% logical usage threshold applies and cannot be increased or disabled.
  4. For environments requiring higher disk utilization:
    - Perform a clean installation of F5OS 1.5.1 or later (which does not use VDO) to restore the 80% threshold.
    - Upgrading from older versions retains VDO; only a clean install removes it.
  5. Monitor disk usage regularly and remove obsolete images to avoid hitting the threshold.
  6. To check disk usage:
    - Use df -h /var/export/chassis to view logical usage.
    - If logical usage approaches 40%, expect threshold errors.
  7. If threshold is exceeded:
    - The system will log "Disk usage exceeded threshold. Removing" and delete the uploaded image.
    - Remove additional files or images to free space and retry the upload.

Additional Information

  • VDO is created at the time of initial installation. It cannot be removed or disabled without a full system reinstallation.
  • Systems without VDO (clean installs of F5OS 1.5.1 and later) allow disk usage up to 80% before threshold errors.
  • The threshold applies to tenant images and F5OS images stored in /var/export/chassis.
  • The logical usage reported by tools like df may not reflect actual physical consumption due to VDO's thin provisioning.
