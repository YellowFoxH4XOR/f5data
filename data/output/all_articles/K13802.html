Topic

This article applies to BIG-IP 11.2.0 and later versions. For information about other versions, refer to the following article:

  • K8261: Enabling a dynamic routing protocol (9.x - 11.1.0)

You should consider using this procedure under the following condition:

  • You want to enable a dynamic routing protocol for a route domain.

Description

Before you can configure a dynamic routing protocol on the BIG-IP LTM system, you must enable the appropriate protocol. A protocol is enabled when at least one instance of the protocol is enabled for a route domain. You can enable a dynamic routing protocol on the BIG-IP LTM system by performing one of the following procedures:

  • Using the Configuration utility to enable a dynamic routing protocol
  • Using tmsh to enable a dynamic routing protocol

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your BIG-IP LTM system must be licensed for the appropriate advanced routing protocol.

Procedures

Using the Configuration utility to enable a dynamic routing protocol

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Route Domains.
  3. Click the route domain for which you want to enable the dynamic routing protocol.
  4. In the Dynamic Routing Protocols section, move the desired routing protocol to the Enabled box.
  5. Click Update.

Using tmsh to enable a dynamic routing protocol

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To enable the dynamic routing protocol for the route domain, use the following command syntax:

    modify /net route-domain <route_domain_name> routing-protocol add { <routing_protocol> }

    For example, to enable the BGP routing protocol for route domain 0, type the following command:

    modify /net route-domain 0 routing-protocol add { BGP }

  3. Save the change by typing the following command:

    save /sys config
