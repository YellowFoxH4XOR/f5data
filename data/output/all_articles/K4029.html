K4029: Tab key does not work in Legacy Host sessions

Type
Knowledge
Published
2007-08-24
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.0.1, 6.0.0
Source
https://my.f5.com/manage/s/article/K4029

Topic

The tab key does not work in Java-based Application Access Legacy Host Favorites, such as mainframe, AS/400, X-Windows, and Telnet sessions, when the client accessing the Favorite uses the Sun Microsystems Java Virtual Machine (JVM).

The JVM does not accept the use of the tab key within Java applets, such as the Java-based Legacy Host Favorites. Sun has stated that this is intentional behavior and that they do not plan to change the behavior. For more information, refer to the following Sun bug report:

http://bugs.sun.com/bugdatabase/view_bug.do?bug_id=4650902

Workaround

You can work around this issue by downloading and installing the Microsoft JVM, which allows tab key input. This update is available directly from Microsoft.
