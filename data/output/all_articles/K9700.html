Known Issue

This is the result of a known issue. When the When all virtual server(s) are available option is enabled for the Advertise Route setting on a shared virtual address and at least one of the virtual servers utilizing that address has a status of Unknown (represented by a blue square), the resulting virtual address status may be counterintuitive. For example, a combination of Unknown/blue and Offline/red virtual servers will cause the virtual address to reflect an Unknown/blue status, while a combination of Unknown/blue and Available/green virtual servers will cause the virtual address to reflect an Offline/red status.

F5 Product Development is tracking this issue as CR110539.

Workaround

F5 recommends that all of the virtual servers reflect a known status (either Offline/red or Available/green) by configuring appropriate monitoring of the pools assigned to the virtual server. If you are using HTTP classes or iRules to select a pool for a virtual server, refer to K6514: BIG-IP may not reflect the expected status for virtual servers that use iRules or HTTP classes to select a pool for more information about how the pool status is reflected to the virtual server status.
