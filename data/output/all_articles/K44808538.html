Security Advisory Description

When multiple HTTP requests from the same client to configured SAML Single Logout (SLO) URL are passing through a TCP Keep-Alive connection, traffic to the Traffic Management Microkernel (TMM) can be disrupted. (CVE-2020-5934)

Impact

A remote attacker may be able to cause a traffic disruption or failover event on the BIG-IP APM system.
