Issue

In BIG-IP 9.0.0 through 10.0.1, you can use the f5adduser command to create local user accounts on the BIG-IP system, and the f5passwd command to change passwords for user accounts. The f5adduser and f5passwd commands were removed from the product starting in BIG-IP 10.1.0.

Note: For more information about the f5adduser command, refer to K5661: Using the f5adduser command.

In BIG-IP 9.4.0 and later, you can use the bigpipe user command to manage BIG-IP user accounts from the command line.

Note: For more information about the bigpipe user command, type bigpipe user help at the command line.

In BIG-IP 10.0.0 and later you can also use the tmsh utility to manage BIG-IP user accounts from the command line.

For example:

tmsh create auth user testuser prompt-for-password

Note: For more information about the tmsh utility, refer to the Traffic Management Shell (tmsh) Reference Guide.

F5 Product Development is tracking this issue as ID 212707 (formerly CR130381).

Note: You can also create and manage BIG-IP system user accounts using the browser-based Configuration utility. For more information, refer to the BIG-IP Network and System Management Guide.
