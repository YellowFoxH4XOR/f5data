Known Issue

A configuration with valid HTTP class URLs fails to load after performing a software upgrade to BIG-IP LTM 11.5.x or later.

This issue occurs when all of the following conditions are met:

  • You attempt to upgrade a BIG-IP system that is currently running 11.0.0 through 11.3.0 software.
  • You attempt to upgrade the BIG-IP system to the 11.5.x software branch.
  • Your configuration contains an HTTP Class profile.
  • In the /config/bigip.conf file, the HTTP Class profile's url-rewrite option does not contain quotes.

    For example:

    url-rewrite /my/new/uri/

Impact

The BIG-IP system configuration fails to load.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system configuration fails to load and you may view an error message in the /var/log/ltm file that appears similar to the following example:

    ERROR: The httpclass profile(s) for policy <HTTP Class profile name> did not roll forward:
           policy rule(s) created from <HTTP Class profile name> do not contain a proper URL.
           See Solution SOL14409.

Workaround

To work around this issue, you must reboot the system to the original installation partition. You can then either upgrade to 11.4.1 to convert the classes correctly, or edit the bigip.conf file. To do so, perform one of the following procedures:

Upgrading first to 11.4.1 and then 11.5.x or later

Impact of workaround: The following procedure will require a new software installation. You should perform this procedure only during a scheduled maintenance window.

  1. Boot the BIG-IP system to the original partition you used to upgrade. For more information, refer to K5658: Overview of the switchboot utility.
  2. Upgrade the BIG-IP system to 11.4.1.
  3. Perform a second upgrade from 11.4.1 to 11.5.x or later.

Editing the /config/bigip.conf file

Impact of workaround: The following procedure will require a new software installation. You should perform this procedure only during a scheduled maintenance window.

  1. Boot the BIG-IP system to the original partition you used to upgrade. For more information, refer to K5658: Overview of the switchboot utility.
  2. Edit the /config/bigip.conf file using a text editor:

    vi /config/bigip.conf
  3. Type the ESC key and the colon ( : ) character.
  4. Copy and paste the following command:

    %s/url-rewrite \/\(.*\)$/url-rewrite \"\/\1\"/gc

    Note: This command will add quotations to each url-rewrite option.

    For example:

    /my/new/uri/ will become "/my/new/uri/"

  5. When prompted, type y:

    replace with url-rewrite \"\/\1\" (y/n/a/q/l/^E/^Y)?
  6. Save the file by hitting the ESC key and typing the following command:

    :wq!
  7. Perform a software upgrade to 11.5.x or later.
