Topic

A BIG-IP APM webtop link is limited to displaying a Detailed Description that is a single line, 33 characters in length. The Detailed Description field can hold a significant number of characters. However, any characters over 33 are truncated on the webtop. Additionally, if you use the formatting tag <br /> to create a multiline description, the system will display only the first 33 characters of the first line.
