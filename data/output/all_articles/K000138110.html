K000138110: VPN users stuck on ''Initializing'', log message "LCP_UNKNOWN_OPTIONS 3,LCP_PROTO_REJ 1"

Type
Support Solution
Published
2024-01-02
Updated
2024-02-01
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000138110

Description

APM users getting stuck on "Initializing" when trying to establish Network Access VPN tunnel

Message in /var/log/apm contains string "LCP_UNKNOWN_OPTIONS 3,LCP_PROTO_REJ 1,FSM_UNEXPECTED_DOWN 1"

Environment

  • BIG-IP APM
  • Users connecting to Network Access tunnel either with EdgeClient or web browser
  • HP drivers
  • Intel ICPS (Intel Connectivity Performance Suite)

Cause

Intel ICPS (Intel Connectivity Performance Suite) is causing connectivity problems.

Recommended Actions

1. Download the updated software from Intel at https://www.intel.com/content/www/us/en/download/738623/intel-connectivity-performance-suite-for-intel-wireless-products.html.

OR

2. Stopping and disabling the following services should address the issue:

Intel Connectivity Network Service

Intel Dynamic Bandwidth Management

IntelConnect Service

 

Additional Information

None
