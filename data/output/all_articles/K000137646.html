Description

As part of tightening up security(port lockdown) customers asked in the past if ports 6123-6128 are necessary for the security policy synchronization between the devices of a sync group. These ports are not necessary for the config sync operation of asm as long as the sync is going through tmm and not management.

Environment

  • ASM sync

Cause

None

Recommended Actions

Port lockdown can exclude TCP port range 6123-6128 from the allowed list and the config-sync will still work for asm.

None.
