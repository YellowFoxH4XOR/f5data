Issue

When the BIG-IP ASM logging profile feature is configured to send log information to a remote syslog server, and BIG-IP ASM is unable to communicate with the remote server, the following message is logged to the /var/log/asm file:

ASM configuration error: event code L517 Failed to write to remote logger account: <number> 

 

Note: The event code L<numeric value> produced in the error message may vary.

The BIG-IP ASM system will attempt to recover and reconnect to the remote syslog server. Any messages sent during the time the communication issue was encountered and reported will be lost.
