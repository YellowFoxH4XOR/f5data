Known Issue

This is the result of a known issue. As described in K10120: The pre-logon sequence window does not close properly for Microsoft Internet Explorer 8 users, FirePass hotfixes were issued to display the following message in Internet Explorer 8 after a user exits Protected Workspace:

You have successfully switched to Protected Workspace. You can close this browser window.

However, this message always appears in English. The correct behavior is for FirePass to display the message in the user’s preferred language, as configured on the Language Preference screen in Internet Explorer.

F5 Product Development is tracking this issue as CR127728.
