Description

IEEE is the registration authority that manages a list of 24-bit numbers to uniquely identify a hardware manufacturer.

MAC Addresses uniquely identify a Network Interface Controller (NIC) to communicate with other devices.

Each MAC Address is composed of 48-bits (6 octets), with each octet segmented by a colon (00:94:A1:F5:F5:F5) or hyphen (00-94-A1-F5-F5-F5). 

Environment

  • All Classic BIG-IP (cBIP) platforms, such as iSeries, any thousand series appliances, and VIPRION
  • F5OS-A (rSeries)
  • F5OS-C (VELOS)
  • BIG-IP Next

Cause

Need to identify MAC Addresses in use by F5, Inc for its hardware platforms. 

Recommended Actions

This is the current list of OUIs assigned to F5, Inc maintained by IEEE.

  • 00:01:D7
  • 00:0A:49
  • 00:23:E9
  • F4:15:63
  • 00:94:A1
  • 14:A9:D0
  • 24:2D:4B

Additional Information

The most recent list of OUIs can be pulled from the master list maintained by IEEE regularly by entering the following command:

$ curl -sk https://standards-oui.ieee.org/ | grep 'F5 Inc' -A 3

For BIG-IP guests (VE or Virtual Edition), the MAC Addresses for the interfaces (tmsh list net interface) will be for the respective hypervisor the guest is a tenant of.

In this example, the OUI (00:50:56) is for VMWare, Inc (ESXi hypervisor).

root@(bigip1)(cfg-sync In Sync)(Active)(/Common)(tmos)# list net interface mac-address
net interface 1.1 {
    mac-address 00:50:56:9d:6c:eb
}
