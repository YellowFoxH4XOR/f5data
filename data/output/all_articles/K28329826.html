Description

BIG-IP APM does not support Remote Desktop Protocol on VMWare View proxy deployments. The error message below can be observed from /var/log/apm when attempting to use RDP.

Failed to handle View request: RDP protocol is not supported for VMWare View

Environment

The below error can be seen when in the /var/log/apm log when:

  • BIG-IP APM
  • VMware View Proxy
  • VMware client using RDP
 

Cause

BIG-IP APM does not support the use of RDP on VMWare View proxy deployments at this time. Bug ID 419239 is currently filed as a future enhancement request for this feature.

Recommended Actions

Use PCOIP, HTML5 or BLAST protocols instead of RDP

None.
