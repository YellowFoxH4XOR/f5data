Topic

You should consider these details under the following conditions:

  • You have standalone and/or clustered BIG-IP devices in your environment that you want to manage with iWorkflow.
  • You are considering updates to the Device Service Clustering (DSC) configuration for BIG-IP devices managed by iWorkflow.

Description

The iWorkflow system supports the following BIG-IP DSC configurations:

  • iWorkflow supports BIG-IP devices in active-standby high-availability pair configurations that use the default traffic group. In this configuration one BIG-IP is active and the other BIG-IP is in standby status in the device group. Connection mirroring is supported in this model so that in the event of failover traffic can be migrated to the newly designated active BIG-IP with no disruption to service.
  • iWorkflow monitors the BIG-IP device group and ensures that the active member is always associated with the Cloud and that the standby member is always disassociated. This ensures that Tenant Service deployments and stats collection happens on the active BIG-IP.
  • iWorkflow supports automatic configuration synchronization and traffic group failover.

    Note: F5 recommends that the BIG-IP administrators enable automatic synchronization for the device groups when they are managed by iWorkflow. When iWorkflow is used to setup a BIG-IP cluster this feature is enabled by default.
