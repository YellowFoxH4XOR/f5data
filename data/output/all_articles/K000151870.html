K000151870: Configuration for SMTP using TLS 1.2 or higher

Type
Support Solution
Published
2025-06-16
Updated
2025-06-16
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000151870

Description

You have configured a SMTP on the BIG-IP in Device -> Configuration -> SMTP, but during communication the SMTP is using TLS v1 where mail server is using a TLS v1.2 or higher

Environment

  • BIG-IP
  • SMTP
  • TLS

Cause

The SMTP support only TLS 1.0.

Recommended Actions

There is no support for the TLS 1.2 for the SMTP so there are no tmsh commands or configuration options to change the TLS version for the built-in SMTP alerting/reporting functions.

Additional Information

None
