K000139233: The system returned an unexpected error (400 Bad Request). Only one task can be created at a time

Type
Support Solution
Published
2024-04-09
Updated
2024-09-05
Source
https://my.f5.com/manage/s/article/K000139233

Description

  • Upon choosing to add a new BIG-IP device for discovery and inputting the device's IP and credentials, then clicking 'Add', an error popup promptly appears, presenting the following message:

Environment

BIG-IQ / Device Discovery

Cause

A task that was previously executed has failed to complete and is currently stuck.

Recommended Actions

Find the ID of the stuck task and then proceed to delete it by following these steps:

1. Identify the ID of the stuck task by searching the BIG-IQ /var/log/restjavad.* logs for the 'CANCEL_REQUESTED' string.

[WARN][29 Mar 2024 07:36:16 PDT][/cm/global/tasks/device-trust BigIPTrustTaskCollectionWorker] Task trust_192.168.1.35 (https://localhost/mgmt/cm/global/tasks/device-trust/54c688bb-f552-4e64-9c7c-5b3d928ce6fa) in a running (CANCEL_REQUESTED) state.

From the result sample above, the Task ID will be 54c688bb-f552-4e64-9c7c-5b3d928ce6fa.

Alternatively, you can run this command in the BIG-IQ command line, bash shell and find the Task ID of the task that is in a "CANCEL_REQUESTED" state:

#restcurl -X GET /cm/global/tasks/device-trust 

2. Use the PATCH command and set the task to a failed status:

    restcurl -X PATCH /cm/global/tasks/device-trust/<insert task_id here> -d '{"status": "FINISHED","generation": 0}'

For example:

restcurl -X PATCH /cm/global/tasks/device-trust/54c688bb-f552-4e64-9c7c-5b3d928ce6fa -d '{"status": "FINISHED","generation": 0}'

3. Delete the stuck task:

restcurl -X DELETE /cm/global/tasks/device-trust/<insert task_id here>

For example:

restcurl -X DELETE /cm/global/tasks/device-trust/54c688bb-f552-4e64-9c7c-5b3d928ce6fa

4. Try adding the BIG-IP device again.

Additional Information

None.
