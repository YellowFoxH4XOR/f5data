Description

MCPD process cannot come up after device reboot.
The below error is logged in /var/log/ltm during configuration load attempt.

"/usr/bin/tmsh -n -g -a load sys config partitions all base " - failed. -- Error: failed to reset strict operations; disconnecting from mcpd. Will reconnect on next command. The connection to mcpd has been lost, try again.

Environment

  • BIG-IP with APM provisioned
     

Cause

See following article K34172543: After rebooting the device unable to access the GUI. Console Error: failed to reset strict operations; disconnecting from mcpd

Recommended Actions

Complete the procedure described in K34172543 to resolve this issue.
