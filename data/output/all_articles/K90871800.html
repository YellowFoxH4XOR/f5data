K90871800: BIG-IQ sending alarms for expired certificates

Type
Support Solution
Published
2023-04-09
Updated
2023-04-09
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K90871800

Description

BIG-IQ generates multiple alerts saying that:

Certificate {{__property__cert_name}} on Hostname: {{__device_hostname__}} will expire in {{latest}} days
Certificate certificate1.crt on Hostname: BIG-IP.local will expire in -1450 days.

Environment

  • BIG-IQ
  • Alerts for Certificates

Cause

N/A.

Recommended Actions

To resolve this issue, follow these steps to update the "alertType" entry in the "defaultAlertConfigs.json" file::

  1. Check current expression in "alertConditionExpression": 
    restcurl /cm/shared/event/alert-config/certificate_expire_threshold | grep -i "alertConditionExpression"
restcurl /cm/shared/event/alert-config/certificate_expire_threshold_1 | grep -i "alertConditionExpression"
restcurl /cm/shared/event/alert-config/certificate_expire_threshold_2 | grep -i "alertConditionExpression"
  2. Log output to files: 
    restcurl /cm/shared/event/alert-config/certificate_expire_threshold > /tmp/certificate_expire_threshold.json
restcurl /cm/shared/event/alert-config/certificate_expire_threshold_1 > /tmp/certificate_expire_threshold_1.json
restcurl /cm/shared/event/alert-config/certificate_expire_threshold_2 > /tmp/certificate_expire_threshold_2.json

  3. For all JSON files generated above (/tmp/certificate_expire_threshold.json, /tmp/certificate_expire_threshold_1.json, and /tmp/certificate_expire_threshold_2.json), search for "alertConditionExpression" and replace "le" with "eq". You can use VIM or VI editors on the BIG-IP, or edit the files in Notepad using an SFTP tool like WinSCP or FileZilla.

  4. Update changes in REST by performing a PATCH operation: 
    curl -X PATCH localhost:8100/cm/shared/event/alert-config/certificate_expire_threshold -H "application/json" -d @/tmp/certificate_expire_threshold.json
curl -X PATCH localhost:8100/cm/shared/event/alert-config/certificate_expire_threshold_1 -H "application/json" -d @/tmp/certificate_expire_threshold_1.json
curl -X PATCH localhost:8100/cm/shared/event/alert-config/certificate_expire_threshold_2 -H "application/json" -d @/tmp/certificate_expire_threshold_2.json
  5. Restart restjavad: 
    bigstart restart restjavad
  6. Check expression in "alertConditionExpression" for all timings (30days, 15days, 7 days) to ensure all changes are in place: 
    restcurl /cm/shared/event/alert-config/certificate_expire_threshold | grep -i "alertConditionExpression"
restcurl /cm/shared/event/alert-config/certificate_expire_threshold_1 | grep -i "alertConditionExpression"
restcurl /cm/shared/event/alert-config/certificate_expire_threshold_2 | grep -i "alertConditionExpression"

  7. Monitor the issue. If it persists, obtain a Qkview and contact F5 Support.
