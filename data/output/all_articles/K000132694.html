Description

When Microsoft Strong Key Protection is enabled and a user connect to APM using the Edge Client for On-Demand Certificate Authentication it will create two sessions.

Environment

  • BIG-IP APM
  • On-Demand Certificate Authentication
  • Strong Key Protection Enabled

Cause

ID691065 [EdgeC] On-Demand Cert Auth creates two sessions

Recommended Actions

It would be recommended to increase the SSL handshake timeout from 10 to 30 seconds in the Client SSL Profile.

  1. Navigate to Local Traffic ›› Profiles : SSL : Client ›› <Client_Profile>
  2. In Configuration - Select Advanced
  3. Scroll to Handshake Timeout and adjust to 30 seconds.
