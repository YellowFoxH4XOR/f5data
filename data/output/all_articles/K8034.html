Known Issue

This is the result of a known issue. If you configure a pre-logon sequence using the Check OS pre-logon inspector, and a Windows Vista client accesses the FirePass controller using Firefox, FirePass incorrectly detects the client operating system as Windows NT instead of Windows Vista.

F5 Networks Product Development tracked this issue as CR78183 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Note: A similar issue occurs in FirePas version 6.0.2 when using Firefox 3. For more information, refer to K9131: The Check OS inspector detects Windows Vista clients as Windows NT clients when using Firefox 3.
