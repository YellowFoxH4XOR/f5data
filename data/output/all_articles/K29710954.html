Description

After upgrading the device to version 15.1.4.x or 15.1.5.x or 16.x IPSEC tunnel is not working anymore.

The following logs appear in /var/log/racoon :

2022-10-13 02:01:12: INFO: IPsec-SA established: ESP/Tunnel 10.10.10.12[0]->10.10.10.60[0] spi=3554621113(0xd3df53f5)
2022-10-13 02:01:12: ERROR: pfkey UPDATE failed: No buffer space available

The configuration is using IKE version1:

net ipsec ike-peer myconfigipsec {
    description "myconfigipsec"
    my-id-value 10.10.10.12
    peers-id-value 10.10.10.60
    phase1-auth-method pre-shared-key
    phase1-encrypt-algorithm 3des
    phase1-hash-algorithm sha256
    preshared-key-encrypted $M$NL$HUhSvbPE7ektPs36wEiInw==
    prf sha256
    remote-address 10.10.10.60
    version { v1 }
}

Environment

  • BIG-IP LTM
  • IPSEC
  • Upgrade
  • IKEV1

Cause

This is a known issue tracked with this ID 1048137.

Recommended Actions

The only workaround is to switch to IKEv2.

None.
