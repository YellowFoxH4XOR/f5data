K000147112: Why do I get Distributed cloud console access request email even if I am not the tenant owner?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147112

What Happened?

  • You are receiving an email in your mailbox when someone from your organization is requesting access but you are not the tenant owner

Environment

  • F5®Distributed Cloud Console
  • Any mailbox

 

Resolution/Answer

  • You will get the access request email if you have system namespace admin role.
  • You can ignore the email if not sure as all the tenant owners will get the request; any one of the   tenant owners can provide the access.
