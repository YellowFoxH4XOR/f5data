Known Issue

The BIG-IP system may not reliably update the status changes of the virtual address to the tmrouted service.

This issue occurs when all of the following conditions are met:

  • The configuration contains at least one virtual address with route advertisement enabled.
  • Routing protocol (for example, BGP) is enabled on the BIG-IP system that is licensed with advance routing.
  • State changes occur on the affected virtual address.

Impact

The affected BIG-IP system may contain incorrect route entries.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the virtual server status changes, the BIG-IP system may fail to update the virtual address state changes to the routing services, such as tmrouted.
