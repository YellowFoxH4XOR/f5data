Description

If the throughput of a base license was ever upgraded, the correct add-on key to purchase should be based on the initial base license's Bill of Materials (BOM) instead of on the upgraded one.
 
For example: Initially, F5-BIG-LTM-VE-25MV16(25MB) was purchased as the base license, then its throughput was later upgraded by adding new add-on keys like F5-ADD-BIG-VE-UP200M(200MB) or F5-ADD-BIG-VE-UP-1G (1GB). Even if the throughput is now upgraded, additional add-on modules should still be purchased based on the BOM of the initial 25MB base license, F5-BIG-LTM-VE-25MV16(25MB).

A similar error such as the one below will occur during license activation when the new add-on key was not purchased based on the initial base license's BOM:

"Unable to grant license key: Error 51086, Add-on Module Key is not a valid option for the Base Registration Key - Product BIG-LTM-VE-25MV16 does not allow the Add-On modules to be included: XXXXXXX-XXXXXXX (LIC-PKG-SBS-BIG-VE-IPI-2-1YR)."
 

Environment

  • Add-on module
  • License activation
  • Base key with upgraded throughput
     

Cause

None.
 

Recommended Actions

Contact F5 Support  or your F5 Sales Representative to find out the correct add-on SKU to purchase.
 

Additional Information

None.
