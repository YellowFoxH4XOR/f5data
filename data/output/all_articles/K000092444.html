Description

Getting the following errors under /var/log/apm:

Delta Database replication file received. Filename 'localdb.dbdump.delta.F5.all.1665064295'

Oct 6 09:51:35 F5 err localdbmgr[24273]: 01ab0012:3: Delta Database replication for file '/var/apm/localdb/localdb.dbdump.delta.F5.all.1665064295' failed with error (-1).

Oct 6 09:52:07 F5 localdbmgr[24273]: 01ab0038:3:


 Environment

BIG-IP VE

APM

ASM

 Cause

mysql database corrupted

 Recommended Actions

1. Generate a UCS file (backup)

2. Run: tmsh load sys config default (this will load the default configuration but mangament-ip will remain and password will be reset by default admin/admin root/default)

3. Delete mysql old volumes from System ›› Disk Management ›› HD1

4. Reboot

5. Load the UCS from #1
