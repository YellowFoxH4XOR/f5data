Topic

You should consider using this procedure under the following condition:

  • You want to license an ARX system from the active.license file after you have cleared the configuration using the delete statup-config command.

Description

When an ARX system is licensed, the license is saved in an active.license file. After you clear an ARX system's configuration with the delete startup-config command, and the system reloads, the system will boot without a running or global configuration. Additionally, the ARX system will not be licensed. The ARX system will indicate license activation is required with the following prompt:

ARX software must be licensed. Please configure the in-band management IP address and DNS for automatic license activation.

At this point you could configure the network and DNS configurations in order to license the ARX system multiple ways. However, because the ARX system was previously licensed, you can license the ARX system using the local active.license file instead of connecting to the F5 license server to obtain a new license.

Once the ARX system has been licensed, you can configure the ARX system or replay saved running and global configuration files.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • The ARX system must have been previously licensed with an active license

Procedures

License the ARX system using the active.license file

Impact of procedure: None.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. License the ARX system by typing the following command:

    license activate file active.license

    The command output should indicate whether the ARX system was licensed successfully. For example:

    % INFO: The license has been successfully activated.
