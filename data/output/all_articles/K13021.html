Issue

Error Message

Value may not contain literal newline characters

Message Location

You may encounter this message in the following Configuration utility location(s):

  • The Local Traffic > Monitors > New Monitor screen
  • The Local Traffic > Monitors > <existing_monitor_name> screen

Description

This message occurs when the following conditions are met:

  • You attempt to create or edit an HTTP or HTTPS monitor in which the Send String or Receive String field(s) contains one or more literal newline characters.
  • The Configuration utility inserts a literal newline character each time the Enter key is pressed to create a line break. For example, the system generates the previously-mentioned error message if you attempt to use the following string in the monitor's Receive String field:

    Receiving information
    item one on line 2
    item two on line 3

Impact

The monitor creation or update fails.

Recommended Actions

You must use the proper metacharacters when constructing HTTP and/or HTTPS monitors in which the Send String or Receive String field(s) contain multiple lines.

To replace the literal line breaks, reformat the previously-mentioned string using newline metacharacters as follows:

Receiving information\nitem one on line 2\nitem two on line 3\n

Supplemental Information

  • K2167: Constructing HTTP requests for use with the HTTP or HTTPS application health monitor
