Description

How to update the DNS Lookup Servers for BIG-IQ

Environment

  • BIG-IQ

Cause

Provide DNS lookup information for BIG-IQ

Recommended Actions
  1. Navigate to System Tab if on a BIG-IQ Configuration Manager.

    Note: If on a BIG-IQ Data Collection Device, the System Tab is the only available Tab.

  2. Navigate to DNS & NTP under This Device on the left-hand menu.
  3. Click Edit button on the far-right hand top of the screen
  4. Fll in the applicable information.
  5. Click Save & Close towards the bottom of the screen.

None.
