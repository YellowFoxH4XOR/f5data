Description

  • Any manual modification to /etc/krb5.conf file (such as those mentioned in K43193482: Configure BIG-IP APM Kerberos SSO for multiple KDCs for highest performance) is automatically synchronized between all devices in the Failover Device group.
  • Any change made to this file either in Active Device or Standby device will be automatically synced to other device.
  • In Chassis, all the Secondary blades will mirror the file on the Primary blade. Any manual change done on the Secondary blade(s) will be lost. The admin has to do the changes on Primary blade only and it will be synchronized with all others blades.
  • This is independent of of the Sync Type setting and seems to be instantaneous.

Environment

  • BIG-IP APM since version 12.1.2 and later

Cause

This is expected and was introduced with a fix to Bug ID 561348: krb5.conf file is not synchronized between blades and not backed up

  • None, informational only
