K48404012: Upgrade of BIG-IQ Centralized Management from 8.0.0 to 8.1.0: An error occurred while doing post upgrade tasks

Type
Support Solution
Published
2021-10-16
Updated
2026-01-08
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0, 8.1.0
Source
https://my.f5.com/manage/s/article/K48404012

Description

When upgrading the BIG-IQ  from  version 8.0.0 to 8.1.0, upgrade fails and following errors are noted in GUI.

An error occurred while doing post upgrade tasks

Below logs are noted in /var/log/restjavad.0.log

[WARN][08 Oct 2021 23:44:21 PDT][/cm/access/rewrite-stats-collector ProfileRewriteStatsCollectorWorker] org.elasticsearch.client.ResponseException: method [GET], host [https//127.0.0.1:9200], URI [/], status line [HTTP/1.1 503 Service Unavailable]
Open Distro not initialized

Environment

  • Upgrade of BIG-IQ Centralized Management from 8.0.0 to 8.1.0
  • BIG-IQ Centralized Management
  • BIG-IQ Data Collection Device

Cause

None

Recommended Actions

  1. Login into BIG-IQ Centralized Management using SSH

    Run below command to disable opendistro security (run below command as a whole) in  BIG-IQ Centralized Management only.

    ENA=false
    URL=$(curl -su admin: localhost:8100/cm/shared/esmgmt/cluster-ssl-task -H 'Content-type: application/json' -d "{\"enable\":\"$ENA\"}" | jq .selfLink -r | egrep -o "/cm.*") ;
    STA=STARTED  ; while [ $STA == STARTED ] ; do STA=$(restcurl $URL  | jq .status -r) ; echo "$(date) - Status is: $STA" ; grep cluster-ssl-task /var/log/restjavad.0.log | tail -n1 ; sleep 10  ; done

    Wait for the command to complete. Once command is completed, confirm that opendistro was disabled by accessing the cluster using below command

    curl -s "http://localhost:9200/_cat/health?pretty"
     
  2. Re-enable the opendistro security in the BIG-IQ Centralized Management

    Run below command to enable opendistro security (run below command as a whole)

    ENA=true
    URL=$(curl -su admin: localhost:8100/cm/shared/esmgmt/cluster-ssl-task -H 'Content-type: application/json' -d "{\"enable\":\"$ENA\"}" | jq .selfLink -r | egrep -o "/cm.*") ;
    STA=STARTED  ; while [ $STA == STARTED ] ; do STA=$(restcurl $URL  | jq .status -r) ; echo "$(date) - Status is: $STA" ; grep cluster-ssl-task /var/log/restjavad.0.log | tail -n1 ; sleep 10  ; done

    Wait for the command to complete. Once command is completed, confirm that opendistro was enabled by accessing the same endpoint over https

    curl -su admin:admin -k "https://localhost:9200/_cat/health?pretty"
     
  3. Then proceed to check the BIG-IQ Centralized Management upgrade status and it will be  successful
