Issue



The following error message may be reported on the Reports: System Logs page, or output to the syslog file of your syslog server (if configured):

GarbageCollection[?????]: Misconfiguration: AdminAddr and/or AdminPort not defined

This message indicates the Desktop Access feature is licensed, but there is no Web Service configured with the Desktop Agent bound to it.

To eliminate this message, perform the following procedure:

  1. Log in to the Administration console using an account with administrator privileges.

  2. In the main navigation pane, click on the Device Management menu.

  3. Click the Configuration menu.

  4. Click the Network Configuration menu.

  5. Click the Web Service Configuration tab.

  6. Click Configure next to a Web Service without SSL.

  7. Select the check box next to Desktop.

  8. Click the Update button at the bottom of the page.

  9. Restart the FirePass Services.

Note: The syslog level and severity for this message is Local1.Info.
