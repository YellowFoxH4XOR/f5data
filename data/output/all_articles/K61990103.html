Description

When using an when using an iRule to extract a UPN per K17063: Extracting UPN value from certificate SAN during Access Policy Evaluation,  if the UPN contains a UTF-8 special character, Tcl returns an incorrect value.

Environment

  • BIG-IP APM
  • iRule
  • On-Demand Certificate Authentication

Cause

This is due to ID 999881

Recommended Actions

You can use any of the following workarounds:
  1. Use iRuleLX.
  2. Do not use Unicode characters in the payload.
  3. Use a custom Tcl proc to iterate through the string using lindex
