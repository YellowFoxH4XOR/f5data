Known Issue

The VIPRION system may not report PVA status and statistics.

This issue occurs when the following conditions are met:

  • You have a VIPRION 2400/2200 chassis with a B2250 blade installed.
  • You attempt to use the Traffic Management Shell (tmsh) or Configuration utility to view the PVA acceleration status for PVA accelerated virtual servers.

Impact

PVA functionality is enabled and functioning but you are unable to determine the status or statistics for PVA accelerated virtual servers.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing the properties of a PVA accelerated virtual server using the tmsh utility, you notice the PVA Acceleration status row is missing from the output of the tmsh show ltm virtual <virtual server> command.
  • When viewing the properties of a PVA accelerated virtual server in the Configuration utility, you notice the PVA Acceleration status row is missing from the Virtual Server Properties page.
