K8561: The Policy Builder does not initiate sampling or use information in responses when in Trusted IP mode

Known Issue

This is the result of a known issue. When the Policy Builder is configured to only accept traffic in Trusted IP mode, it does not initiate sampling or use information in responses.

This behavior results in the following:

  • Static Parameters are not set properly
  • Dynamic Parameters are not discovered
  • Predefined user created parameters are ignored by Policy Builder and are not tuned or updated

This issue can affect customers that use Trusted IP traffic to generate policies using Policy Builder due to security requirements.

F5 Product Development tracked this issue as CR94137 and it was fixed in BIG-IP ASM 9.4.5. For information about upgrading, refer to the BIG-IP ASM Release Notes.
