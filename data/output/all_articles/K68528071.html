Description

User may encounter error while generating UCS archive, CLI output may have :

Saving active configuration...
tar: root/.tmsh-history-domain\user1: Cannot stat: No such file or directory
tar: root/.tmsh-history-domain\user2: Cannot stat: No such file or directory
tar: root/.tmsh-history-domain\user3: Cannot stat: No such file or directory
tar: root/.tmsh-history-domain\user4: Cannot stat: No such file or directory
tar: Error exit delayed from previous errors
Fatal: executing: tar --no-recursion -rf /var/tmp/im13786/configsync-2.0-1-Linux-2.6.32220.6.5.8664.im --files-from=/tmp/im.13867/Files
Operation aborted.
/tmp/configsync.spec: Error creating package
WARNING:There are error(s) during saving.
Not everything was saved.
Be very careful when using this saved file!
Error creating package
Error during config save.
Unexpected Error: UCS saving process failed.

Environment

  • BIG-IP
  • Using TACACS authentication for management users.

Cause

GNU tar doesn't support backslash in filename, which breaks UCS process.

Recommended Actions

  1. Remove or rename files containing backslash, for example:
    # rm .tmsh-history-domain\\user
  2. Upgrade BIGIP [version >= 11.6.2].
