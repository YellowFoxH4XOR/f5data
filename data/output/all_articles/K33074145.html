Description
How to re-associate (after failover) IPs with multiple destination Elastic Network Interfaces

Environment

  • Amazon Web Services
  • Legacy (pre Cloud Failover Extension) failover script - pre-version 14

Cause
The selected Elastic Network Interface (ENI) to failover to depends on the subnet.  When two of the target ENIs to failover to exist on the same subnet, they are selected randomly by the script, and sometimes colliding when it goes through both traffic groups of failover objects.

Recommended Actions

  1. Use separate subnets per Elastic Network Interface.
