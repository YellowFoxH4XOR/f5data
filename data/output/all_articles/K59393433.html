Description

Article describes how to Enforce Single Attack Signature ID on ASM policy. 

Environment

  • Enforce Attack Signature on ASM policy

Cause

In some cases it's more convenient and/or effective to enforce ASM Attack Signature using iControl REST API. This procedure can be used to create script that enforces signature for multiple policies.

Recommended Actions

  1. List ASM policies and corresponding links:

    curl -u admin:password -ks "https://localhost/mgmt/tm/asm/policies" | jq '.items[].name,.items[].selfLink'

    Example output:
    "test_policy"
    "https://localhost/mgmt/tm/asm/policies/euMwbEcwgGlvVz1Gb0XZCA?ver=15.1.0"

     euMwbEcwgGlvVz1Gb0XZCA is ASM policy ID for REST calls.

  2. Find REST ID of Attack Signature that you want to enforce:

    curl -u admin:password -ks "https://localhost/mgmt/tm/asm/policies/euMwbEcwgGlvVz1Gb0XZCA/signatures?ver=15.1.0" | jq '.items[] | select(.signatureReference.signatureId == 300000000) | .id'

    Example output:
    "NjGb4S0qK-e26ODogweKsw"

    300000000 is a Attack Signature ID

    To verify current Attack Signature properties use:

    curl -u admin:password -ks "https://localhost/mgmt/tm/asm/policies/euMwbEcwgGlvVz1Gb0XZCA/signatures?ver=15.1.0" | jq '.items[] | select(.signatureReference.signatureId == 300000000) | .'

     Example output:
     {
       "lastUpdateMicros": 1615210483000000,
       "kind": "tm:asm:policies:signatures:signaturestate",
       "selfLink": "https://localhost/mgmt/tm/asm/policies/euMwbEcwgGlvVz1Gb0XZCA/signatures/NjGb4S0qK-e26ODogweKsw?ver=15.1.0",
       "signatureReference": {
      "link": "https://localhost/mgmt/tm/asm/signatures/DlWwTc-DcVlx7dMrpwETWw?ver=15.1.0",
      "name": "TEST_customer",
      "signatureId": 300000000
       },
       "isPriorRuleEnforced": false,
       "alarm": true,
       "id": "NjGb4S0qK-e26ODogweKsw",
       "block": true,
       "performStaging": true,
       "learn": true,
       "enabled": true
     }

     
  3. Enforce Attack Signature:

    curl -k -u admin:password -H "Content-Type: application/json" -X PATCH "https://localhost/mgmt/tm/asm/policies/euMwbEcwgGlvVz1Gb0XZCA/signatures/NjGb4S0qK-e26ODogweKsw?ver=15.1.0" -d '{"performStaging": "false"}'

    Verify the change:

    curl -u admin:password -ks "https://localhost/mgmt/tm/asm/policies/euMwbEcwgGlvVz1Gb0XZCA/signatures?ver=15.1.0" | jq '.items[] | select(.signatureReference.signatureId == 300000000) | .'

  4. Apply ASM Policy using this command:

    curl -k -u admin:password -X POST "https://localhost/mgmt/tm/asm/tasks/apply-policy" -d '{"policyReference": {"link": "https://localhost/mgmt/tm/asm/policies/euMwbEcwgGlvVz1Gb0XZCA"}}'
