Topic

You should consider using this procedure under the following condition:
  • You need gather data to create a historical view of BIG-IP CPU utilization.
Note: To create a historical record, the data collected should be captured and saved within an SNMP Management system. Otherwise, running the command at the command line will only provide a snapshot of the last 5 seconds, 1 minute, or 5 minutes.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP command line.

Description

There are several tools and commands to gather CPU usage and process utilization. For example, the Linux top utility displays system summary information, such as memory and CPU utilization and a corresponding list of processes currently managed by the system. The top utility reads from the /proc file system to gather kernel information. However the top utility is limited in its ability to provide a historical reference of CPU usage, and such information is important in troubleshooting many scenarios.

The following procedures can help you collect historical BIG-IP CPU utilization information:

  • Displaying BIG-IP CPU cycles using tmsh
  • Using the SNMP F5-BIGIP-SYSTEM-MIB OID sysTmmStatTmUsageRatio to view TMM CPU busy
  • Using the SNMP F5-BIGIP-SYSTEM-MIB OID sysGlobalHostCpuUsageRatio to gather CPU utilization ratios of the BIG-IP system

Procedures

Displaying BIG-IP CPU cycles using tmsh

You can use SNMP to view Traffic Management Microkernel CPU cycles over a period of time (in seconds).

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh).
  2. Type the following command to display the CPU cycles of the BIG-IP system:

    show /sys cpu

Using the SNMP F5-BIGIP-SYSTEM-MIB OID sysTmmStatTmUsageRatio to view TMM CPU busy

You can poll the BIG-IP system using the MIB sysTmmStatTmUsageRatio to gather the percentage of time the TMM was previously utilized. There are three options available with this OID: 

sysTmmStatTmUsageRatio5s - The percentage of time the TMM was busy over the last 5 seconds.
sysTmmStatTmUsageRatio1m - The percentage of time the TMM was busy over the last 1 minute.
sysTmmStatTmUsageRatio5m - The percentage of time the TMM was busy over the last 5 minutes.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. Type the following command:

    snmpwalk 127.0.0.1 -c public -v2c F5-BIGIP-SYSTEM-MIB::sysTmmStatTmUsageRatio5s

Note: You can configure the BIG-IP to allow external polling. For more information refer the Implementations Monitoring BIG-IP System Traffic with SNMP chapter of the BIG-IP LTM External Monitoring of BIG-IP Systems manual.

Using the SNMP F5-BIGIP-SYSTEM-MIB OID sysGlobalHostCpuUsageRatio to gather CPU utilization ratios of the BIG-IP system

You can use sysGlobalHostCpuUsageRatio MIB to gather usage ratio of CPU for the system. It is calculated by (sum of deltas for user, niced, system)/(sum of deltas of user, niced, system, idle, irq, softirq, and iowait), where each delta is the difference for each stat over the last 10-second interval.

There are three additional options available with this OID:
sysGlobalHostCpuUsageRatio5s - This is usage ratio of CPU for the system. It is calculated by 
    (sum of deltas for user, niced, system)/(sum of deltas of user, niced, system, idle, irq, softirq, and iowait) over a 5 second interval.

sysGlobalHostCpuUsageRatio1m - This is usage ratio of CPU for the system. It is calculated by 
    (sum of deltas for user, niced, system)/(sum of deltas of user, niced, system, idle, irq, softirq, and iowait) over a 1 minute interval.

sysGlobalHostCpuUsageRatio5m - This is usage ratio of CPU for the system. It is calculated by 
    (sum of deltas for user, niced, system)/(sum of deltas of user, niced, system, idle, irq, softirq, and iowait) over a 5 minute interval.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. Type the following command:

    snmpwalk 127.0.0.1 -c public -v2c F5-BIGIP-SYSTEM-MIB::sysGlobalHostCpuUsageRatio5s

Note: You can configure the BIG-IP system to allow external polling. For more information refer the Implementations Monitoring BIG-IP System Traffic with SNMP chapter of the BIG-IP LTM External Monitoring of BIG-IP Systems manual.

SNMP output appears similar to the following:

F5-BIGIP-SYSTEM-MIB::sysGlobalHostCpuUsageRatio5s.0 = Gauge32: 5
