Issue

Error Message

01020037:3: The requested <object_type> (<object_name>) already exists

In this error message, note the following:

  • <object_type> is the type of configuration object.
  • <object_name> is the name of the configuration object.

For example:

01020037:3: The requested management IP (10.10.10.10) already exists

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A client attempts to create a non-partitioned object that already exists in the database.

The primary key for a database object must be unique. The mcpd process generates this error message when there are duplicates.

Impact

Client transactions fail.

Recommended Actions

This issue can be caused by corrupted objects in the BIG-IP configuration. You should review the BIG-IP configuration, and remove and recreate or re-import any corrupted objects.
