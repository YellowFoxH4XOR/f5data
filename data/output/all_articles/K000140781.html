K000140781: Latency or possible packet loss with FastL4 virtual servers after upgrade to v17+

Type
Support Solution
Published
2024-08-29
Updated
2024-08-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000140781

Description

After upgrading to version 17+ of BIG-IP Advanced Firewall Manager(AFM) higher latency and packet loss might be experienced on FastL4 virtual servers.  Reviewing packet captures taken from the BigIP AFM device, there might be retransmissions introducing latency into the TCP stream from the client. Review of AFM logs, whether local or remote, so TCP ACK(TS) DOS Vector being triggered.  

 

Environment

  • BIG-IP AFM
  • Upgraded to v17.1
  • FastL4
  • Latency and Packet Loss

Cause

During upgrade to version 17+, TCP ACK(TS) DOS Vector could be triggered because of lower default values kept during upgrade.  These values need to be increased to larger values in version 17+ because of combining of several vectors into TCP ACK(TS).

 

Recommended Actions

Please review K000139860: The tcp-ack-ts vector with lower thresholds is triggered after upgrading to v17.1 for additional information and remediation.
