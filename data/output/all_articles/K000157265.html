Description

After upgrading BIG-IP DNS (GTM) devices from version 15.1.10.3 to 16.1.6.1, the GTM configuration failed to load due to decryption errors related to DNSSEC keys. Error messages included "Failed to decrypt private text of DNSSEC Key Generation..." and "Master Key decrypt failure," resulting in the GTM configuration not being applied and the device remaining offline.

 

Environment

  • BIG-IP DNS (GTM) module
  • Software upgrade
  • DNSSEC enabled with key and zone objects in configuration

 

Cause

DNSSEC keys in bigip_gtm.conf were encrypted with a master key or schema incompatible with 16.1.6.1, causing decryption and config load failure after upgrade.

 

Recommended Actions

  • After upgrading to BIG-IP 16.1.6.1, remove all DNSSEC key and zone objects from bigip_gtm.conf before attempting to load or sync the configuration.
  • Reload the GTM configuration using: 
    • tmsh load sys config gtm-only
  • Reboot the device to ensure the configuration loads successfully.
  • If DNSSEC functionality is required, recreate the DNSSEC keys and zones on the upgraded device after confirming the configuration loads without errors.
  • Back up the configuration before making any changes.
