K13740808: BIG-IQ Centralized Management GUI ''Secondary TokuMX (x.x.x.x) reporting a fatal error''

Support Solution
Published
2020-04-29
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X, 6.X.X
Source
https://my.f5.com/manage/s/article/K13740808

Description

BIG-IQ Centralized Management GUI shows alert "Secondary TokuMX (x.x.x.x) reporting a fatal error"

/var/log/restjavad.0.log shows:

Get Peer status failed: java.net.ConnectException

Environment

  • BIG-IQ Centralized Management Cluster ( 2 Centralized Management Devices)
  • Secondary BIG-IQ CM reports "Waiting for BIG-IQ services to become available"
  • Secondary TokuMX Database Status Red

Cause

Corruption of secondary TokuMX database

Recommended Actions

Manually synchronize database from CLI using following scripts:

1. On primary CM use following command: ha_sync_files <IP of discovery IP>
2. On primary CM:  ha_resync_db <discovery IP>
3. Wait until database is synchronized
4. On standby CM: restart restjavad tokumond tokumx
