Source

Description

You have replace the hardware device and given the temporary mgmt ip and its still active and you are able to ping even after loading the config containing the Mgmt IP of the old hardware device.

For example :

Mgmt IP: 172.16.240.12  (active on the new hardware after loading the config)
Temp. mgmt IP: 172.16.240.116 (active before loading the config and still active after loading, but not present in the config files and not under "tmsh list sys management-ip")

You have also reboot to fix the issue however it did not worked

When you perform a grep in the config dir, you can see, that the IP still exists in "/config/bigpipe/bigip_base.conf", "/config/.diffVersions/config/bigip_base.conf/" and some others.
