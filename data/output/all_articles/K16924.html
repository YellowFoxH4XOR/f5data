Known Issue

Network Access sessions may unexpectedly terminate and restart.

This issue occurs when all of the following conditions are met:

  • You use the BIG-IP Edge Client for the MAC OS to establish your Network Access session.
  • The Network Access profile specifies a Client Proxy Autoconfig Script URL for the proxy.pac file.
  • The URL referenced proxy.pac file is larger than 10KB.
  • You use a browser or application to access a destination resource that intern requests the proxy.pac file.

Impact

The Network Access session may terminate and re-establish a connection.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Network Access session is terminated when you use a browser or application that requests the proxy.pac file.
  • The Network Access session is maintained when you use browsers or applications that do not request the proxy.pac file.
  • The BIG-IP Edge Client logs messages similar to the following example at the time of the event:

    svpn, 1, , 75, CPACHelper::WriteRemote(), Failed to download remote, 12, 8
    svpn, 1, , 76, CPACHelper::WriteRemote(), EXCEPTION - Failed to download remote pac file
    svpn, 1, , 265, UProxyMonitor::isConfigured(), EXCEPTION - Proxy monitor has been stopped
    svpn, 1, , 1594, , EXCEPTION caught
    svpn, 0,,,, --------- Exit of Tunneling Loop  --------

Workaround

To work around this issue, you can minimize the size of the original proxy.pac file to under 10 KB.
