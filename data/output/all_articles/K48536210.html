Description

You are not able to change the root password with the following error message.
[admin@BIG-IP:Active:In Sync] ~ # tmsh modify auth password root
/bin/bash: auth: No such file or directory

It is also noticed that the following alias was created.
[admin@BIG-IP:Active:In Sync] ~ # awk '/^cli.alias/,/^}/' bigip_*.conf
cli alias shared /Common/modify {
    command bash
}

Environment

  • BIG-IP
  • tmsh
  • Changes to the bash script with the creation of an alias

Cause

The bash script has been changed with the creation of an alias which messes with the modify command.
You will need to consult with a forensic investigator to identify more details of this alias creation.
This could might be related to CVE-2020-5902.

Recommended Actions

  1. Login to the Command Line.
  2. Make a backup of /config/bigip_base.conf with the following command:
    cp /config/bigip_base.conf /config/bigip_base.conf.backup
  3. You will need to edit /config/bigip_base.conf with a text editor such as nano or vi. The following command is to edit /config/bigip_base.conf using nano:
    nano /config/bigip_base.conf
  4. Comment those 3 config lines, or delete it. You can comment that by putting '#' stings at the beginning of the line just like this:
        # cli alias shared /Common/modify {
        # command bash
        # }
    Important: Do not modify anything else in /config/bigip_base.conf.
  5. Load the configuration with command:
    tmsh load sys config
  6. You can proceed to change your root password with the following command:
    tmsh modify auth password root
