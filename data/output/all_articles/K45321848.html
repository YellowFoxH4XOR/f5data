Description

From GUI, you can not select LTM object (node, pool, profiles, etc) in LTM policy, because the part of GUI on the LTM Policy  is grayed out.
NOTE: it is possible to apply change through CLI
 

Environment

  • BIG-IP
  • any version
     

Cause

One of the object has bad character.
 

Recommended Actions

  1. To find bad characters running tmsh list ltm <object type> command.
    e.g.
    tmsh list ltm profile
    tmsh list ltm node
    tmsh list ltm pool
     
  2. When you find characters which is not display properly, remove the character on GUI or on CLI
     
  3. load config with command
    tmsh load sys config
