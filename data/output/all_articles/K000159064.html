Description

F5OS allows you to deploy multiple tenants with the same management IP address without displaying any validation errors or warnings in either the CLI or GUI. While this configuration is technically possible due to intentional tenant isolation on the management network, it's not a recommended practice.

Environment

  • Multiple tenants deployed with duplicate management IPs on the same chassis

Cause

This is tracked by Product Engineering as Bug ID1080405.

F5OS currently lacks the validation logic needed to detect and prevent duplicate management IP assignments during tenant deployment. This gap allows the system to accept identical IPs across tenants without raising any alerts.

Recommended Actions

Immediate Workaround: Manually track and verify management IP uniqueness before deploying new tenants.

Long-term Resolution: This issue is now tracked as Bug ID1080405 with a targeted fix in a future F5OS release.
