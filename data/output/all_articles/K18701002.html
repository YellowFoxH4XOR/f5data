Known Issue

The tmsh list /gtm listener <listener name> command incorrectly displays the default values for translate-address and translate-port.

This issue occurs when all of the following conditions are met:

  • The translate-address or translate-port options are enabled for the GTM listener.
  • The system sends the output from the tmsh list /gtm listener <listener name> command to a file.

    For example:

    tmsh list gtm listener gtm_listener > /shared/temp/listenerconfig.txt

    The tmsh list command should not show the default settings. If either the translate-address or translate-port option is set to enabled, the system does not display the settings when you run the tmsh list command. If you use the tmsh list command with the tmsh merge command, you may experience traffic disruption.  The tmsh merge command uses the default LTM behavior of not displaying default options, and the system acts as though it set the translate-address or translate-port options to their default settings, since the settings are not displayed.

    For example, merge the previously listed file with the system configuration using the following command syntax:

    tmsh load sys config merge file /path/to/file/<filename>

    For  example:

    tmsh load sys config merge file /shared/temp/listenerconfig.txt

    After the merge, list the GTM listener information using the following command syntax:

    tmsh list gtm listener <listener name>

    Notice that the previous change to either translate-address or translate-port has been reset to its default value of disabled, and is now listed in the output.

Impact

The tmsh /list gtm listener command does not display the ‘translate-address'/'translate-port' options, as expected.

Note: Traffic may fail if you set address or port translation to enabled, and use the output of the tmsh merge command.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tmsh list command incorrectly displays the default values for the GTM listener translate-address/translate-port settings.

Workaround

To work around this issue, you can use the all-properties flag. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Use the all-properties flag with the tmsh list command to display the information correctly, as shown in the following command syntax.

tmsh list gtm listener <listener name> all-properties

For example:

# tmsh list gtm listener dns_listener all-properties
gtm listener dns_listener {
address 10.12.14.141
advertise no
app-service none
auto-lasthop default
description none
enabled
fallback-persistence none
ip-protocol udp
last-hop-pool none
mask 255.255.255.255
partition Common
persist none
pool none
port domain
profiles {
dns {
context all
}
udp_gtm_dns {
context all
}
}
rules none
source-address-translation {
pool none
type automap
}
source-port preserve
translate-address enabled
translate-port enabled
vlans {
external
}
vlans-enabled
}
