Known Issue

You cannot use the Configuration utility to remove a health monitor that has an existing Receive String and Receive Disable String.

This issue occurs when one of the following conditions is met:

  • You attempt to remove the existing Receive String on an HTTP, HTTPS, TCP or UDP monitor.
  • You attempt to remove the existing Receive String and Receive Disable String on an HTTP, HTTPS, TCP or UDP monitor.

Impact

You are unable to remove the existing setting on a health monitor's Receive String and Receive Disable String from the BIG-IP Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H389813 on the Diagnostics > Identified > Low  screen.
  • After attempting to remove the Receive String and Receive Disable String, you click Update, and the strings setting remains configured for the monitor.

Workaround

To work around this issue, you can remove the monitor string settings using the Traffic Management Shell (tmsh) utility. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To remove the Receive Disable String, use the following tmsh command syntax:

    tmsh modify /ltm monitor <health_monitor_type> <health_monitor_name> recv-disable none

    For example:

    tmsh modify /ltm monitor http my_monitor recv-disable none

  3. To remove the Receive String, use the following tmsh command syntax:

    Note: To remove the Receive String setting, you must first remove the Receive Disable String setting.

    tmsh modify /ltm monitor <health_monitor_type> <health_monitor_name> recv none

    For example:

    tmsh modify /ltm monitor http my_monitor recv none

  4. Save the configuration in tmsh by typing the following command:

    save /sys config

  5. To exit tmsh, type the following command:

    quit

  6. Press Enter.
