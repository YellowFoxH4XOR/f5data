Known Issue

The BIG-IP dashboard may display inaccurate data.

This issue occurs when the following condition is met:

  • The dashboard statistic numeric value is greater than 32 bits.

Impact

This issue is cosmetic. Displayed dashboard values are temporarily inaccurate.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing dashboard statistics, a large numeric value displays that is not relevant to the specific statistic.
  • When attempting to view dashboard statistics, an error displays.
  • The dashboard value displays correctly when statistic values are less than 32 bits.
