Known Issue

BIG-IP APM remote desktop Custom Parameters may not affect the session.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an application access RDP remote desktop profile.
  • The application access remote desktop profile Custom Parameters is configured with more than one parameter.

Impact

The custom parameters do not affect the remote desktop session.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you configure Custom Parameters with more than a single parameter, the system does not uses any of the parameters when establishing the remote desktop session.
  • When you view the parameters that were sent to the remote desktop application, you will notice that all the parameters are sent in a single one line string.
