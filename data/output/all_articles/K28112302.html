Description

After upgrading the device to 14.x and later, when running show sys ... command fails with below error:

[root@bigip:Active:Standalone] config # tmsh show sys
Unexpected Error: Error: unable to parse availability log


Environment

  • Upgraded to 14.x and later

  • Standard 'tmsh' shell

Cause

This symptom is caused by a code defect characterized as Bug ID 837885.

Recommended Actions

To temporarily work around this issue, you can restart the sod process and reset the statistics for sys availability component. To do so, perform the following procedure:

Impact of workaround: Restarting the sod process causes a failover and results in a brief traffic interruption. This workaround only mitigates the issue, and the issue may re-occur.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the sod service, type the following command:

    restart sys service sod

  3. To reset the stats for sys availability, run the following command: 

    reset-stats sys availability
