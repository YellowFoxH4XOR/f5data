Known Issue

This is the result of a known issue. If you enable the Windows antivirus checker in a pre-logon sequence, users running AVG Anti-Virus 7.x may experience a browser crash after logging on to the FirePass webtop. When this issue occurs, the user successfully logs on to the FirePass controller, but after a brief time (approximately 20 to 30 seconds) the browser crashes and closes. This issue occurs when OPSWAT 2.5.7 (Hotfix-99074) is installed on the FirePass controller.

F5 Product Development tracked this issue as CR99534 and it was fixed in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass 5.x branch. To monitor the status of this CR, refer to the FirePass release notes.

Additionally, this issue was fixed in hotfix-100382 (OPSWAT 2.5.8) issued for FirePass version 5.5, 5.5.1, 5.5.2, 6.0.1, and 6.0.2. You may download this hotfix or later versions of the OPSWAT hotfix from the F5  Downloads site.

For instructions about obtaining and installing an OPSWAT hotfix, refer to K6664: Obtaining and installing OPSWAT hotfixes.
