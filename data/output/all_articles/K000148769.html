Description

When using the Configuration Utility (GUI) to enable TLS 1.3 with a custom cipher string, you are unable to save the config, and a message like this one is shown:

01b40001:3: A cipher group must be configured when TLS 1.3 is enabled (validation failed for profile /<partition>/<profile>)

This message occurs when the following conditions are met:

  • You attempt to configure an SSL profile with TLS1.3 enabled.
  • You want the SSL profile to use a custom cipher string.
  • The SSL profile is not associated with a cipher group.

Environment

  • BIG-IP LTM
  • Enable TLS 1.3

Cause

You are trying to enable TLS 1.3 from the Configuration Utility (GUI) including a custom cipher string, this change is not allowed without an associated cipher group.

Recommended Actions

You should first create a custom cipher rule, transform it into a cipher group and then associate it to the TLS1.3 enabled SSL profile. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Create a cipher rule

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Ciphers > Rules and click on Create...
  3. Fill the required fields and paste your custom cipher string in the Cipher Suites section.

Important: Never include the prefix f5- in a cipher rule name. This prefix is reserved for pre-built cipher rules only.

  1. Wait until the string is validated, then click Finished.

Create a cipher group

  1. Navigate to Local Traffic > Ciphers > Groups and click on Create...
  2. Fill in the name.
  3. In the Group Creation section, in the right panel, select the checkbox next to you custom cipher rule (the one you just created) and using the arrows move it to your desired module (Allow / Restrict / Exclude).
  4. Wait until the group is validated, then click Finished.

Associate the cipher group to the SSL profile

  1. Navigate to Local Traffic > Profiles > SSL > Client.
  2. Click the SSL profile for which you want to associate with a cipher group.
  3. For Configuration, click Advanced.
  4. Select the Custom check box.
  5. For Ciphers, click Cipher Group.
  6. From list, choose your custom cipher group.
  7. In the Option List section, move no TLSv1.3 from the Enabled Options to the Available Options by selecting it and clicking Disable.
  8. Click Update.
