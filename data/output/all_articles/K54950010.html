Description

After selecting new boot location, system takes very long time (more then 10 minutes) to reboot and stays offline after booting up. GUI can display 500 status "Internal Server error".

Environment

  • Booting BIG-IP with new software version.

Cause

This issue can be caused by extremely large UCS file, that is created and used during upgrade process. Due to the size a time needed to create UCS, processes related to upgrade/boot process may timeout and fail.

Recommended Actions

If you are experiencing similar symptoms and UCS file is very large (like > 300MB), please try following:
  1. Rollback to older Software version.
  2. Verify size of UCS by creating one.
  3. If UCS file is very large:
    • Check if it's not containing unneeded files:
      K12278: Removing non-essential files from a UCS when disk space errors are encountered
      Note: After identifying unneeded files, move/remove them directly on BIG-IP to make sure that newly created UCS will not include it.
    • If you use or used BIG-IP APM, remove unnecessary OPSWAT EPSEC packages:
      K21175584: Removing unnecessary OPSWAT EPSEC packages from the BIG-IP APM system
  4. After decreasing size of UCS, try to boot to new software version.
  5. If upgrade process is still failing, please contact F5 Support team.
