Description

When enabling bot defense, some features require javascript code injection into the back-end's server HTML responses or javascript code being sent back by big-ip to the client as a white page. From the console output of the browser, an error similar to the following can be seen.


084e627c82a54353453451313c792de8b86ffa6aaf3159bf3aba3fb8fb6bc9e7aa515320178aed23?type=9:85 Uncaught TypeError: Cannot read properties of undefined (reading '1')

   at zl (084e627c82a54353453451313c792de8b86ffa6aaf3159bf3aba3fb8fb6bc9e7aa515320178aed23?type=9:85:308)

   at XMLHttpRequest.<anonymous> (084e627c82a54353453451313c792de8b86ffa6aaf3159bf3aba3fb8fb6bc9e7aa515320178aed23?type=9:76:82)


Environment

  • Bot Defense

Cause

The error above is related to the "Single Page Application" code injection in the response. If the application can not handle it can cause the page to break.


Recommended Actions

The "Single Page Application" feature of Bot Defense should be disabled to avoid this error, or appropriate adjustments on the page should be considered if the feature is desired.


Security --> Bot Defense --> Bot Defense Profiles --> Choose the profile --> Browser --> Disable "Single Page Application"
