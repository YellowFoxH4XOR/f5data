K000139195: Receive "Error getting auth token from login provider" error on GUI if TMSH cli private alias are configured

Type
Support Solution
Published
2024-04-05
Updated
2024-04-05
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000139195

Description

  • When navigating to the following GUI menus, "Error getting auth token from login provider" may be thrown.

Device Management >> Overview
Local Traffic >> Network Map => only "Loading..." message is displayed.
System >> Support >> Support => "Last Generated Snapshot" or "QKView Upload History" stuck with "Loading..."

  • On "/var/log/restjavad.*.log" log file, you will see errors something similar to below.

Bad response while waiting for icrd: java.lang.Exception: Unable to process request /tm/cm/device-group. Service is unavailable.

  • On iHealth diasgnostics zomething similar to the following will appear:

Indicators of Compromise (IoCs) are found on the system.
Command bash with an unshared alias list

  • An output similar to the following appears when you run awk '/cli alias private.*list \{/,/\}/' /config/bigip_user.conf

cli alias private list {
   command bash
   user x
}
cli alias private list {
   command bash
   user x
}

Environment

  • BIG-IP
  • Configured TMSH cli private aliases for list command

Cause

The configured TMSH cli private aliases for list command causes internal REST communication on the GUI to fail.

Recommended Actions

1. Connect to CLI

2. Delete cli private aliases for list command

tmsh delete cli alias private list

3. Save the configuration changes

tmsh save sys config

4. Restart restjavad

tmsh restart sys service restjavad
