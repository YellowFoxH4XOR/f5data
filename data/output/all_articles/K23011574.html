Issue

Error Message

01070265:3: The <object> (<object_name>) cannot be deleted because it is in use by a <object> (<object_name>).

In this error message, note the following:

  • <object> is a configuration object such as a virtual server or profile.
  • <object_name> is the name of the configuration object.

For example:

01070265:3: The Pool (/Common/pool_http) cannot be deleted because it is in use by a policy action (/Common/policy_rule).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • You attempt to delete a configuration object that another configuration object is currently referencing.

For example, if you attempt to delete a VLAN that is associated with one or more self IP addresses, the mcpd process generates this message.

Impact

The transaction fails and the configuration rolls back to its previous state.

Recommended Actions

If the configuration object referencing the object you want to delete is orphaned or not currently in use, consider reconfiguring the unused object or removing it from the configuration. For more information about removing orphaned configuration objects, refer to K15335: F5 recommends removing orphaned configuration objects.
