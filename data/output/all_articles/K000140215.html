Description

Many clients are having rejected to access to VPN due to Antirus database is not updated, but actually it is updated. Antivirus is Sophos which is supported by current EPSEC version.

 

Environment

  • BIG-IP APM
  • VPN
  • AntiVrus check
  • Sophos
  • definition date

 

Cause

  • Full scan was not done after installing EdgeClient (Please refer: K000132356: What is the time of APM AV last scan time 
  • EPSEC versino is older.
  • Edge client is older.

 

Recommended Actions

  1. Make sure Full scan is done (quick scan is not considered by Antivirus check)
  2. Make sure EPSEC version is latest.
  3. Make sure using latest Edge Client.
