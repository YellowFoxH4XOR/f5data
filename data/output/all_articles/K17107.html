Known Issue

The BIG-IP APM rewrite profile may incorrectly process JavaScript events.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The BIG-IP APM system rewrites HTML pages that contain JavaScript events.
  • The JavaScript code, in the HTML page, uses the getAttribute() method.
  • The getAttribute() method is called to obtain the value of a JavaScript event.

In the following example, the getAttribute method is called to retrieve the value of the onload event:

  <html>
  <body onload='i=0;'>
  <script>
  document.body.innerHTML=document.body.getAttributeonload
  </script>
  </body>
  </html>

Instead of returning the 'i=0;' value, the BIG-IP APM system returns internal rewritten functions and the web page fails to render properly.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using portal access, requested pages that include JavaScript events fail to display.
  • Web applications malfunction or fail to render properly in browsers.
