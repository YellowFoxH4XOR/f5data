K000136922: Error related EPSEC files when backing up the BIG-IP configuration to SCF file.

Description

When saving a BIG-IP configuration to SCF file using TMSH and error similar to the following is displayed:

/bin/tar: files_d/Common_d/epsec_package_d/\:Common\:epsec-1.0.0-1372.0.iso_67155_1: Cannot stat: No such file or directory 
/bin/tar: Exiting with failure status due to previous errors Unexpected Error: Failed to append to temp tar file "/var/system/tmp/tmsh/0VVQiY/data" cache path "/config/filestore/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1372.0.iso_67155_1"exit code (2).


Environment

  • BIG-IP
  • SCF


Cause
An EPSEC file is referenced to be included in the backup that has been deleted. 

Recommended Actions

The workaround is to create an empty file with the same name as the missing file in the directory (path) as noted in the error message

Example error message:

Unexpected Error: Failed to append to temp tar file "/var/system/tmp/tmsh/0VVQiY/data" cache path "/config/filestore/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1372.0.iso_67155_1"exit code (2). 

  1. Use the command line command touch to create an empty reference file:

    touch /<path><missing file name>

    Example:
    touch /config/filestore/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1372.0.iso_67155_1

    Note: Where /config/filestore/files_d/Common_d/epsec_package_d/ is the path.
    Note: Where :Common:epsec-1.0.0-1372.0.iso_67155_1 is the missing file name.

  2. After creating the empty 'EPSEC' file, the .scf file can be saved without issue:

    tmsh save /sys config file <scf file name> no-passphrase

    Note: Replace <scf file name> with the desired name for your SCF file.
