Issue

Error Message

012b0021:5: Executable <path/to/big3d> version <big3d version>

In this error message, note the following:

  • <path/to/big3d> is path to the big3d agent on the system. 
  • <big3d version> is the version of the big3d agent.

For example:

012b0021:5: Executable /usr/sbin/big3d version 'big3d Version 13.0.0.2.0.1671'
012b0021:5: Executable /shared/bin/big3d version 'big3d Version 13.0.0'

Message Location

You may encounter this message in the following location:

  • The /var/log/gtm file

Description

This message occurs when one of the following conditions is met:

  • You start the system.
  • You install the big3d agent.

When the modification time stamp of big3d under /shared/bin is up-to-date and its signature is correct, the system retrieves and writes the versions of /shared/bin/big3d and /usr/sbin/big3d to the log file. This ensures that the system copies the /usr/sbin/big3d file over to the /shared/bin/big3d file when the version of /usr/sbin/big3d is newer than /shared/bin/big3d.

Impact

This is an informational log message to provide verification of the versions of /shared/bin/big3d and /usr/bin/big3d. 

Recommended Actions

If the time stamp and version of /usr/bin/big3d are more recent than /shared/bin/big3d, or if the signature of /shared/bin/big3d fails, you should perform a manual copy of /usr/bin/big3d to /shared/bin/big3d. For more information, refer to K13703: Overview of big3d version management.
