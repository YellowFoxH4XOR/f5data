K1391: The First-Time Boot/Setup utility does not work correctly with Microsoft Windows HyperTerminal

Type
Knowledge
Published

Updated
2023-02-21
Status
Legacy Content
Applies to

  • 3-DNS: 4.6.4
  • BIG-IP 4.X: 4.6.4
Source
https://my.f5.com/manage/s/article/K1391

Topic

When using HyperTerminal and a serial connection to connect to BIG-IP or 3-DNS systems, the cursor (arrow) keys do not work properly in the First Time Boot/Setup utility.

This is an issue with HyperTerminal. You can work around this issue by setting the HyperTerminal preferences to VT100 and to Terminal Keys.
