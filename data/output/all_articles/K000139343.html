Description

Does a decision box in an APM policy support having two options and then a fallback.


Environment

BIG-IP LTM

Cause

This is expected behavior

Recommended Actions

Even though the policy editor allows you to create a branch with 2 separate options and a failback this is not a supported configuration - you should never fail a decision box, you should only have 1 option path and then a failback with the 2nd option

Additional Information

In the logs the problem is demonstrated like this

Option 1 goes to path 1

Option 2 goes to path 2

Option 0 is fallback.


For example of a failure you would see an entry similar to the following:


Apr 18 21:37:05 apmhost1.local.com notice apmd[14578]: 01490115:5: /Common/Our_policy:Common:ff3ad488: Following rule 'Successful' from item 'Antivirus' to terminalout 'OK'

Apr 18 21:38:24 apmhost1.local.com notice apmd[14578]: 01490116:5: /Common/Our_policy:Common:ff3ad488: User chose option: 0
