K000133314: Big3d restart loop after modifying trusted server certificate in BIG-IP DNS

Type
Support Solution
Published
2023-04-19
Updated
2024-06-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000133314

Description

Big3d went into restart loop after modifying trusted server certificate stored in BIG-IP /config/big3d/client.crt. For example, after updating third party CA certificates as per K54213074.  

Similar logs found in /var/log/gtm:

bigip.example.com notice big3d[10168]: 012b0000:5: big3d Version 16.1.3.1.0.105.11 started =============================== bigip.example.com err big3d[10168]: 012b3003:3: SSL_CTX_load_verify_locations: SSL error:0906D066:PEM routines:PEM_read_bio:bad end line bigip.example.com err big3d[10168]: 012b3003:3: SSL_CTX_load_verify_locations: SSL error:0B084009:x509 certificate routines:X509_load_cert_crl_file:PEM lib

You check the trusted server certificate bundle and found syntax error. For example, there is a missing newline between 'END CERTIFICATE' and 'BEGIN CERTIFICATE'.

Environment

  • BIG-IP DNS
  • Big3d
  • Modify trusted server certificate

Cause

Certificate syntax error

Recommended Actions

1. Stop big3d service to prevent the noise produced from logging.
bigstart stop big3d
2. Use vim or other editor to make changes to the certificate bundle.
vim /config/big3d/client.crt
3. Insert a new line between 'END CERTIFICATE' and 'BEGIN CERTIFICATE'. Press 'Esc' key and enter the following command to save and quit from vim editor.
:wq

Note: Leading and trailling dashes '-' is important. Please refer PEM file format for more information. This link takes you to a resource outside of MyF5, and the third party could remove the document without our knowledge.

4. Start big3d service
bigstart start big3d
