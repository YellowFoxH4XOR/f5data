Known Issue

This is the result of a known issue. When the BIG-IP WebAccelerator writes stack trace information into the logs, the stack trace will detail every outstanding request, rather than only the offending response or request. As a result, the log files may contain excessive amounts of stack trace information that is not useful, and can prevent effective troubleshooting.

F5 Networks Product Development is tracked this issue as CR94243 and CR98435 and it was fixed in BIG-IP WebAccelerator version 9.4.6. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Additionally, this issue has been fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP WebAccelerator version 9.4.5. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about how to manage F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

After installing BIG-IP 9.4.5-HF2, you must enable a new stackTraceSimplified variable in the /config/wa/pvsystem.conf file. To do so, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa
  3. Backup the original pvsystem.conf file by typing the following command:

    cp pvsystem.conf pvsystem.conf.sol8798
  4. Open the pvsystem.conf file in a file editor.
  5. Change the <stackTraceSimplified>false</stackTraceSimplified> entry to the following:

    <stackTraceSimplified>true</stackTraceSimplified>
  6. Save the pvsystem.conf file.
  7. Stop the BIG-IP WebAccelerator services by typing the following command:

    bigstart stop pvac
  8. Start the BIG-IP WebAccelerator services by typing the following command:

    bigstart start pvac
