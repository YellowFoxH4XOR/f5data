Description

  • You'd like to adjust the logon page so more objects are visible without scrolling
  • Customization has been reworked since 12.x and since then it's approached via CSS and JS only.

Environment

  • BIG-IP APM
  • Logon Page
  • Customization Type set to Modern

Cause

N/A

 

Recommended Actions

The general information regarding customization is described in Manual chapters:

Manual Chapter : Access Policy and Macros - Logon Pages - Modern and Standard  
Manual Chapter : Advanced Customization Coding
 

First you need to determine the style element that you want to modify. Load the dev tools in your browser and use the inspect function to find the name of the style you want to change.

You can now make these changes in the user CSS file.

Click Profiles/Policies >> Customization >> Advanced, then navigate to the Logon Page's user-logon.css file.

If your Logon Page is a part of macro you just need to expand the /<partition>/<policy_name> >> Macros branch and find the adequate user-logon.css object there.

Please try this CSS code (put it in an adequate user-logon.css):

.apmui-header {
    height: 0px;
    min-height: 0px;
}

.apmui-content h2 {
    font-size: 1em;
    line-height: 1;
}

.apmui-form input[type=password], .apmui-form input[type=tel], .apmui-form input[type=text] {
    padding: 0 10px;
    height: 30px;
}
 

Before changing, user-logon.css is blank, default values:


End result after changing user-logon.css (note the vertical scroll bar is missing now):



Let's break down each element one by one:

.apmui-header {
    height: 0px;
    min-height: 0px;
}

 

This effectively shrinks the height of header (banner) to 0, feel free to change height and min-height values, alternatively you can try:

.apmui-header {
    display: none;
}

 

But please note that this will cause the header to be hidden completely
 

.apmui-content h2 {
    font-size: 1em;
    line-height: 1;
}

 

This changes h2 header element size from 1.7em default to 1em and it's line-height to 1 from 1.16 default

 
.apmui-form input[type=password], .apmui-form input[type=tel], .apmui-form input[type=text] {
    padding: 0 10px;
    height: 30px;
}

 

This changes the default height and spacing of the input fields
