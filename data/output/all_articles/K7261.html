Known Issue

Important: The following information applies to network failover only. It does not affect systems using the hardwire failover cable.

This is the result of a known issue. The BIG-IP system variable Failover.NetRetryLimit is not honored in BIG-IP failover pairs. This results in the standby unit becoming active when the value set for Failover.NetTimeoutSec is exceeded, which occurs when a heartbeat packet is missed or dropped. This behavior can occur on networks that experience connection or communication problems, resulting in an active-active situation or units continuously failing over to to each other.

For information about the BIG-IP system variables for network failover, refer to K7249: Overview of Network Failover timers.

F5 Networks Product Development tracked this issue as CR57155 and CR56621, and it was fixed in BIG-IP LTM version 9.1.2 and 9.2.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
