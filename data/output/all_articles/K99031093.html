K99031093: Cannot delete SP connector automation object

Type
Support Solution
Published
2020-11-09
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.0
Source
https://my.f5.com/manage/s/article/K99031093

Description

Delete from GUI/TMSH

  • apm sso saml-sp-automation /AWS-TEST - OK
  • apm sso saml-sp-connector /urn_amazon_webservices_d1400bed2d51772ab34da144f5c65222 - returns error

Delete from TMSH with transaction

  1. create cli transaction
  2. delete apm sso saml-sp-automation /AWS-TEST
  3. delete apm sso saml-sp-connector /urn_amazon_webservices_d1400bed2d51772ab34da144f5c65222
  4. submit cli transaction - returns error

Delete from /config/partitions/TEST/bigip.conf and do load sys config - returns error
01071d81:3: At least one metadata URL must be configured for SAML SP metadata automation (/AWS-TEST ).
Unexpected Error: Loading configuration process failed.

Environment

  • BiGIP APM v15
  • Connector automation object and SP object

Cause

The /urn_amazon_webservices_d1400bed2d51772ab34da144f5c65222 seems to be locked.

Recommended Actions

  1. Delete link between SP connector and SP connector automation objects with TMSH command:
    modify apm sso saml-sp-connector <sp_connector_name> automation-object none
  2. Delete SP connector object in TMSH/GUI, does not matter
  3. Delete SP connector automation object in TMSH/GUI, does not matter

Additional Information

None
