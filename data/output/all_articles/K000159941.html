Description

Recurring TCL errors occur during scheduled backup pruning operations managed by the f5-automated-backup iApp on BIG-IP systems. The errors appear in logs during automated backup file cleanup tasks and include messages such as:

<date> <device> err scriptd[18925]: 014f0013:3: Script (/Common/f5.automated_backup__backup_pruning) generated this Tcl error: (script did not successfully complete: (couldn't execute "/var/tmp/autopruning.sh": text file or pseudo-device busy

<date> <device> err scriptd[18865]: 014f0013:3: Script (/Common/f5.automated_backup__Backup_pruning) generated this Tcl error: (script did not successfully complete: (couldn't execute "/var/tmp/autopruning.sh": permission denied


These errors persist across multiple iApp template versions and may also impact remote backup file transfers. The backup functionality itself typically continues to work, but the pruning operations generate error messages in the logs.

Environment

  • BIG-IP version 17.5.1 (errors may occur on other versions)
  • Automated backup and pruning managed via the f5-automated-backup iApp prior version 3.2.4

Cause

A defect or incompatibility in f5-automated-backup iApp template versions prior to 3.2.4 causes improper handling of the dynamically generated autopruning.sh script during backup pruning operations. The iApp creates, executes, and deletes this script as part of the pruning process, but earlier template versions contain logic errors that result in TCL execution failures and file access errors.

Recommended Actions

To resolve the TCL errors during backup pruning operations:

Update the f5-automated-backup iApp template to version 3.2.4:

  • Download the latest template from: https://github.com/tabernarious/f5-automated-backup-iapp/blob/main/f5.automated_backup.v3.2.4.tmpl.tcl
  • Navigate to iApps > Templates > Import in the BIG-IP GUI
  • Select the checkbox 'Overwrite Existing Template'
  • Upload the v3.2.4 template file

If the errors persist, you may need to re-associate all application services with the updated template.
