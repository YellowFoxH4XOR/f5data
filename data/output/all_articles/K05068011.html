K05068011: Removing BIG-IP configuration from BIG-IQ GUI

Type
Support Solution
Published
2021-10-07
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K05068011

Description
Instruction on how to remove BIG-IP configuration (Virtual Servers, profiles, etc.) from BIG-IQ GUI.

Environment

  • BIG-IQ 7.x, 8.x
  • BIG-IP LTM

Cause
None

Recommended Actions

  1. Discover and import LTM config.
  2. On BIG-IQ go to: Configuration >  Local traffic > VS
  3. Check VS and remove it (Delete button).
  4. In BIG-IQ GUI go to: Deployment > Evaluate & Deploy > Local Traffic & Network
  5. Create an Evaluation. View the Differences and see that it will remove the VS.
  6. Deploy the evaluation.
  7. Verify that the VS has been removed from the BIG-IP.
