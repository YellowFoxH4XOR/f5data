Description

Software upgrade failed when attempting to save a UCS file, returning an error similar to the following:

/etc/logrotate.d : Directory does not exist

WARNING:There are error(s) during saving.
        Not everything was saved.
        Be very careful when using this saved file!

Error creating package
Error during config save.
Unexpected Error: UCS saving process failed.

A manual UCS save attempt also fails with the same error.

The directory listed in the error does exist.

Environment

  • Software upgrade
  • UCS save

Cause

A custom entry is present in /usr/libdata/configsync/cs.dat. The syntax of this entry may not be correct, causing the system to attempt locating a directory which actually does not exist.

In the example given in this article, an extra space is present after the directory name.

Recommended Actions

Review /usr/libdata/configsync/cs.dat for any unusual entries and fix any errors that are present.

Note: The /usr filesystem is mounted as read-only by default, so it must be mounted read-write in order to make changes.
