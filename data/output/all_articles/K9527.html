K9527: The Configuration utility restricts .key and .crt extensions to SSL keys and certificates respectively

Issue

In BIG-IP versions prior to 9.4, the Configuration utility did not restrict .key and .crt extensions to SSL keys and certificates allowing key and certificates to be imported with the .key or .crt within the name of the file.

Beginning in BIG-IP 9.4, the Configuration utility restricts .key and .crt extensions to SSL keys and certificates respectfully. For example, if a certificate such as www.askf5.com.key.crt is imported using the Configuration utility, the Configuration utility will automatically remove the .key portion of the file name so that the file is imported as www.askf5.com.crt.

Due to the new restriction for SSL key and certificate extensions, upgrading or installing a UCS from a previous version that did not contain the extension restrictions will result in an error message if any attempt are made to delete a key or certificate using the Configuration utility.

For example, assume a UCS containing a certificate named www.askf5.com.key.crt, which was initially created on a previous version of the BIG-IP system, is installed on an upgraded version of BIG-IP running version 9.4.5 or later. The www.askf5.com.key.crt and www.askf5.com.key will correctly display and match in the Configuration utility. However, if an administrator attempts to remove the www.askf5.com.key.crt certificate to replace it with an updated certificate, an error message that appears similar to the following example may be reported by the Configuration utility indicating the certificate cannot be deleted:

error:0906D06C:PEM routines:PEM_read_bio:no start line

Workaround

If you encounter an issue from attempting to delete a certificate or key that includes .key within the name of the certificate file or .crt within the name of key file, you can work around this issue to rename the affected certificate or key. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Change directories to the /config/ssl/ssl.crt directory if you need to change the name of a certificate, or to the /config/ssl/ssl.key directory if you need to change the name of a key, by typing one of the following commands:

    cd /config/ssl/ssl.crt

    or

    cd /config/ssl/ssl.key
  3. Locate the affected certificate or key, and change the name by typing the move command:

    For example:

    mv www.askf5.com.key.crt www.askf5.com.crt
  4. Once you change the name of the affected certificate or key, you can now remove the affected certificate or key file using the Configuration utility
