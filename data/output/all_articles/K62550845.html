Description

Virtual Clustered Multiprocessing (vCMP) host devices show Standalone in F5 GUI and CLI prompt.

Environment

  • BIG-IP vCMP host

Cause

None. This is intended behavior. vCMP hosts should be standalone and not configured in a high availability configuration.

Recommended Actions

You should not configure vCMP hypervisor hosts for HA or failover. In addition, you should not configure VLAN fail-safe and other HA features on the host system.

Additional Information

For information about additional vCMP configuration considerations, refer to K15930: Overview of vCMP configuration consideration
