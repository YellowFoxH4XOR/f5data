Topic

Starting in FirePass version 6.0.1, with cumulative hotfix HF-601-11, you can access group and summary reports using the load_reports.php page. Previously, the group report was available only on the Reports: Group Report page and the summary report was available only on the Reports: Summary Report page.

Note: This enhancement is not yet available on any other version of FirePass.

To access summary and group reports, access the load_reports.php script using the following parameters:

  • reporttype

    The type of report. Specify either summary or group.
  • output

    Format of the report output. Specify xml, html, or txt (comma-separated text).
  • from

    The start date of the report. If this parameter is not specified, the lastweek value is used.

    The possible values are:

    • lastweek
    • last2weeks
    • lastmonth
    • lastyear
    • Date in the format of YYYY-MM-DD
  • to (optional)

    The end date of the report in the format of YYYY-MM-DD. If this parameter is not specified, the current day is used for the end date.
  • group (optional)

    The name of the master group. This is an optional parameter for use with the summary report. If this parameter is not specified, all master groups are included in the summary report.

Important: By default, the load_reports.php page is password protected and all network ranges are allowed to access the page. The username for the load_reports.php page is gtmuser, and you can configure the password on the Device Management: Monitoring: Load Status Access Security page. Additionally, you can limit access by specifying permitted network ranges on the Device Management: Monitoring: Load Status Access Security page.

For example, if your FirePass hostname is firepass.siterequest.com, you can generate an HTML-formatted group report for the dates 12/15/2007 through 1/15/2008 using the following URL:

Note: The URLs in the following examples should be on one continuous line; they have been split into two lines for formatting purposes only.

https://firepass.siterequest.com/load_reports.php?reporttype=group&output=html&from=
2007-12-15&to=2008-01-15

You can generate a text-formatted group report for the past two weeks using the following URL:

https://firepass.siterequest.com/load_reports.php?reporttype=group&output=txt&from=
last2weeks

You can generate an XML-formatted summary report for the group Sales, for the past year using the following URL:

https://firepass.siterequest.com/load_reports.php?reporttype=summary&output=xml&from=
lastyear&group=Sales
