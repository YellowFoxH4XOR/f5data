Topic

This article applies to all BIG-IP FIPS platforms, except for BIG-IP 5250F, 7200F, 10200F, 11000F, and 11050F. For the 5250F, 7200F, 10200F, 11000F, and 11050F platforms, refer to the following article:

  • K45724553: Updating the firmware for a FIPS protected internal HSM to version CN16XX-NFBE-FW-2.2-130013

You should consider using this procedure under the following conditions:

  • You want to maintain your BIG-IP system's FIPS device compliance with the National Institute of Standards and Technology (NIST).
  • You want to ensure that the BIG-IP system's FIPS protected internal Hardware Security Module (HSM) is running the latest firmware version.

Description

When you upgrade the BIG-IP system's software, the system also automatically updates internal hardware components that require new firmware. However, when the BIG-IP system's FIPS protected internal HSM requires a firmware update, user intervention is required to apply the latest HSM firmware. This is due to security authorization requirements for accessing the FIPS protected HSM.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command line access to the BIG-IP system.
  • You have the FIPS HSM security officer (SO) password.
  • You have the HSM security domain.

Procedures

Updating the FIPS HSM Firmware

The installed BIG-IP system software will contain the approved HSM firmware updates. To ensure the internal HSM is running the latest firmware, perform the following procedure.

Impact of procedure: Performing the following procedure requires a reboot of the system, and you should perform the procedure only during a planned maintenance period. This procedure does not affect the current HSM configuration.

  1. Log in to the command line of the BIG-IP system.
  2. Create a UCS archive and store off of the BIG-IP system.
  3. To install the latest HSM firmware update, type the following command:

    fipsutil fwupdate

  4. To reboot the system, type the following command:

    reboot
