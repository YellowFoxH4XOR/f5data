Description

After upgrading a vCMP Host, guests fail to deploy with the error message similar to the following:

Status failed: Comment: Cannot deploy guest due to license limit. Maximum number of deployed guests is: 0 

Environment

  • Upgrade
  • vCMP
  • License

Cause

Service check date of the device is earlier than the license check date for the version.
For more information on the license check date, refer to K7727: License activation may be required before a software upgrade for BIG-IP

Recommended Actions

You can attempt to manually reactivate the license. If the service check date is still not updated after a successful license reactivation, do a rollback first and reactivate the license again.

  1. Login to Configuration Utility or Command Line to reactivate the license.
  2. Login to the Command Line and enter the following command to check the service check date:

    tmsh show sys license | grep "Service Check Date"

  3. Rrun the following command to restart vcmpd:

    bigstart restart vcmpd
  4. Enter the following command (as in step #2) to verify the service check date:

    tmsh show sys license | grep "Service Check Date"

    Note:  If after restarting vcmpd the Service Check Date is displayed correctly you do not need to do steps 5-11.

  5. Check if the above output showing the latest "Service Check Date" and verify the vCMP max guests value.
  6. If the device has valid support entitlement but the service check date is still not updated, perform the following steps:
  7. Rollback to the previous version.
  8. Reactivate the license.
  9. Delete the partition which has the new installed software.
  10. Perform a fresh upgrade/install.
  11. Boot into the new volume.
