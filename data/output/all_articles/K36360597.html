Known Issue

BIG-IP GTM removal of an interdependent virtual server from Virtual Servers Dependency List may be unsuccessful.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP GTM system is configured with a virtual server that uses the Virtual Servers Dependency List setting.
  • The Virtual Servers Dependency List setting contains multiple entries.
  • You use the Configuration utility to remove the first virtual server of the alphabetical virtual server dependency list.

Impact

Virtual server dependencies are not removed from the Virtual Servers Dependency List setting.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Virtual servers that are removed from the Virtual Servers Dependency List setting are still included in the Virtual Servers Dependency List setting configuration.
  • You can use the Traffic Management Shell (tmsh) to remove virtual servers from the Virtual Servers Dependency List setting.

Workaround

To work around this issue, you can use the tmsh utility to remove virtual server dependencies. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Remove a virtual server from the Dependency List setting configuration by using the following command syntax:

    modify /gtm server <server name> virtual-servers modify { <virtual server name> { depends-on delete { /<partition>/<server name>:<dependent virtual server name> } } }

    In this command syntax, note the following:

    • <server name> is the server name of the virtual server that is configured with the Dependency List setting.
    • <virtual server name> is the name of the virtual server configured with the Dependency List setting.
    • <dependent virtual server> is the name of the virtual server you want to remove from the dependency list.
  3. To save the configuration change, type the following command:

    save /sys config gtm-only
  4. To exit the tmsh utility, type the following command:

    quit
