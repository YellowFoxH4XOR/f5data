Description

Using BIG-IP Edge client for pre-login (Windows Logon Integration).Want to know if there is any specific windows call that BIG-IP edge client makes to invoke logon scripts/group policies

Environment

  • BIG-IP APM
  • Network access
  • Edge Client

Cause

N/A

Recommended Actions

When enabled, this option emulates the Windows logon process for a client on an Active Directory domain. Network policies are synchronized when the connection is established, or at logoff. The following items are synchronized:

  1. Logon scripts are started as specified in the user profile.
  2. Drives are mapped as specified in the user profile.
  3. Group policies are synchronized as specified in the user profile. Group Policy logon scripts are started when the connection is established, and Group Policy logoff scripts are run when the network access connection is stopped.


The GPO Sync used by Edge Client to the Windows API:

-----
LOG_USER(_T("synchronizing GPO"));
RefreshGPO();
------
RefreshGPO() in turn calls the following Windows APIs
(WINAPI *lpfnRefreshPolicy)(BOOL bMachine);
(WINAPI *lpfnRegisterGPNotification) (HANDLE hEvent, BOOL bMachine);
(WINAPI *lpfnUnregisterGPNotification) (HANDLE hEvent);
