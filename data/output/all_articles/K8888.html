Topic

Changing the share where a volume's metadata is stored, and migrating the existing metadata is known as metadata migration. You can perform metadata migration by using the nsck migrate-metadata command.

The nsck migrate-metadata command is used only for migrating a volume's existing metadata. This command is not used for the initial import of a volume's metadata, or for subsequent maintenance on the metadata on the share where it exists.

Important: The metadata migration process interrupts client access to the associated managed volume until the metadata migration completes. However, concurrent client access to other volumes is unaffected.

Supplemental Information

  • For information about metadata migration, including syntax, usage instructions, and examples of the nsck migrate-metadata command, refer to the Adding a Managed Volume chapter in the ARX CLI Storage Management Guide
  • For information about the treatment of each related command, refer to the ARX CLI Reference Guide
