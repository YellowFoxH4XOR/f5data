Description

Exporting an Access report in *.CSV format fails with an error message "Exceeded the maximum download row count 40000"

Environment

  • APM Access report
  • Export *.CSV format

Cause

Export limit for 40000  rows introduced to address ID 426209 "Java out of Memory" issue. 
Bug ID 426209: exporting to a CSV file may fail and the Admin UI is inaccessible

Recommended Actions

To work around the issue export the file with lesser than 40000 rows

Additional Information

This issue occurs only when exporting and generating the report higher than 40000 rows has no impact.
