Description

BIG-IP upgrades can fail for a variety of reasons. This document will attempt to consolidate common known issues when upgrading to v16 or v17.

 

Environment

  • BIG-IP Upgrade
  • Upgrade Failure

 

Cause

Various

 

Common Issues:

  • K000133239: Device is INOPERATIVE mode after software upgrade from 15.1.8 or 15.1.8.1 to 16.x or 17.x
  • K01017758: Configuration load failure after upgrade due to a Provisioning Error because of Lack of Disk Space on the BIG IP.
  • K000140382: AFM DoS feature could drop packets if vCMP Host run TMOS v17.1.x and Guest TMOS version is lower
  • K000141089: Configuration load fails at sshd include after upgrade to BIG-IP 16.1.5 and 17.1.2
  • K000149711: Pool Monitors are flapping after upgrade to 17.1.2 on F5OS tenant
  • K10541621: ASM policy parameters reset to default after upgrade
  • K000138474: Intermittent DNSSEC issue after upgrade

Recommended Actions

After upgrade, run the following command to verify the configuration:

 

tmsh load sys config verify

 

Search F5 knowledge base for error message to find existing articles

 

If no appropriate article is found, open support case for further investigation.
