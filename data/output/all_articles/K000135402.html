Description

You want to use Postman with the iControl REST API to generate a license for your unreachable BIG-IP from your BIG-IQ FCP utility pool.

Environment

  • BIG-IQ LM or CM
  • BIG-IP
  • ELA / FCP licensing

Cause

BIG-IQ traditionally expects to be able to connect to any BIG-IP devices it is going to license.
If your BIG-IP is not on the same network as the BIG-IQ, using Postman with iControl REST on BIG-IQ is an easy way to create BIG-IP license files.

Recommended Actions

The Postman tool will need network access to the BIG-IQ, you will need to set up basic auth (user name and password) or use the X-F5-Auth-Token header to access the iControl REST API. For more information refer to K43725273: The BIG-IQ system has HTTP basic authentication disabled by default and K04452074: Overview of using the BIG-IQ system authentication token. The JSON requires the management IP address of the BIG-IP and its MAC address, utility pool name, SKU name, and hypervisor type you want to use. This is a 2 step process requiring a PUSH and a GET to the BIG-IQ. Finally you will need to use Notepad++ or another text editor to find and replace text.
  1. Set Postman to POST.
  2. Set the address to the following:

    https://<BIG-IQ address>/mgmt/cm/device/tasks/licensing/pool/member-management

    For example:

    https://10.1.1.1/mgmt/cm/device/tasks/licensing/pool/member-management

  3. Select body and raw and paste the following example:  
    {
  "licensePoolName": "CAT-A-1",
  "command": "assign",
  "address": "192.0.2.1",
  "skuKeyword1": "BT",
  "skuKeyword2": "1G",
  "unitOfMeasure": "yearly",
  "assignmentType": "UNREACHABLE",
  "macAddress": "FF:11:11:11:FE:DE",
  "hypervisor": "vmware",
  "chargebackTag": "Project 1016"
}
  4. Edit the JSON example to include your unique values.
    Note: The options for hypervisor are aws, azure, gce, vmware, hyperv, kvm, xen.
  5. Go to Authorization tab select Basic Auth and enter the username and password or add the X-F5-Auth-Token header with the token as the Value.
  6. Click on Send.
  7. Review the output text and look for a line starting with selflink.
  8. Copy the entire https selflink address including the unique number.
  9. Open a new tab in Postman (click the +)
  10. Change the method from POST to GET.
  11. In the address / URL area paste the selflink address and change localhost to the IP address of the BIG-IQ.
  12. Click on Send.
  13. Review the output. Notice in licenseText the value is the license file and output starts with #\n#\nAuth vers : and the file ends with a \n just before skuKeyword1.
  14. Copy the whole license file from the starting and ending points noted previously (do not include the speech/quotation marks) and paste it into Notepad++.
  15. In notepad, press CTRL + H.
  16. In the Find what field, enter:
    \\n
  17. In the Replace with field, enter:
    \r\n
  18. Make sure the Search Mode is set to Extended.
  19. Click on Replace All to perform the translation throughout the text.
  20. Save the file as bigip.license.
  21. Copy the file to /config on the BIG-IP.
  22. To reload the new license on the BIG-IP system, log into the CLI and enter the following command:
    reloadlic
