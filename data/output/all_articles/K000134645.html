K000134645: BlackHole cluster issue observed in AM 1.14.6-am1 with dual-stack mode

Type
Support Solution
Published
2023-05-19
Updated
2023-07-19
Applies to
  • Aspen Mesh: 1.14
Source
https://my.f5.com/manage/s/article/K000134645

Description

When dual-stack mode is enabled in AM 1.14.6-am1 following messages are seen in istio-proxy logs even with ServiceEntry in place:

apiVersion: networking.istio.io/v1alpha3
kind: ServiceEntry
metadata:
  name: external-svc-http
spec:
  hosts:
  - www.f5.com
  location: MESH_EXTERNAL
  ports:
  - number: 7443
    name: http
    protocol: http
  resolution: DNS

[2023-05-17T18:59:49.738Z] "- - -" 0 UH - - "-" 0 0 9 - "-" "-" "-" "-" "-" BlackHoleCluster - 108.138.94.114:7443 10.244.2.5:44754 - -
[2023-05-17T19:00:38.035Z] "- - -" 0 UH - - "-" 0 0 0 - "-" "-" "-" "-" "-" BlackHoleCluster - 108.138.94.54:7443 10.244.2.5:58396 - -
[2023-05-17T19:00:38.881Z] "- - -" 0 UH - - "-" 0 0 0 - "-" "-" "-" "-" "-" BlackHoleCluster - 108.138.94.114:7443 10.244.2.5:37852 - -
[2023-05-17T19:00:39.653Z] "- - -" 0 UH - - "-" 0 0 0 - "-" "-" "-" "-" "-" BlackHoleCluster - 108.138.94.54:7443 10.244.2.5:58412 - -

Environment

1.14.6-am1

Cause

After ServiceEntry has been applied, the corresponding listener is not created, hence redirecting traffic to BlackHole cluster:

➜  aspenmesh-carrier-grade-1.14.6-am1 istioctl pc listeners sleep-5fcc5d667d-nj9xw | grep 7443
➜  aspenmesh-carrier-grade-1.14.6-am1

Recommended Actions

Upgrade to AM 1.14.6-am2

Additional Information

Expected behavior after upgrading to 1.14.6-am2

➜  aspenmesh-carrier-grade-1.14.6-am2 istioctl pc listeners sleep-b945bdc7-p884c | grep 7443
0.0.0.0      7443  ALL                                                                      Route: 7443
::           7443  ALL                                                                      Route: 7443.ipv6
