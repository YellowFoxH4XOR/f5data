Known Issue

This is the result of a known issue. The PVA does not honor the Priority Group Activation pool setting when in Full Acceleration mode. As a result, the system treats all of the pool members as though they are within the same priority group, and load balances connections to all members.

F5 Product Development is tracking this issue as ID 248270 (formerly CR81846).

Note: BIG-IP versions later than 11.1.0 do not support platforms containing a PVA chip.

Workaround

You can work around the issue by allowing the PVA to recognize the Priority Group Activation setting on the pool. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > Fast L4.
  3. Click the name of the FastL4 profile that is associated with the affected virtual server.
  4. Select the PVA Acceleration check box.
  5. From the PVA Acceleration box, select Assist.
  6. To save the changes, click Update.
