Known Issue

This is the result of a known issue. Under the following conditions, the BIG-IP WebAccelerator may erroneously add the X-Pvinfo header containing the S10202 (Proxy due to expire) tag to a response, indicating that the content will be immediately expired in the BIG-IP WebAccelerator cache:

  • A node is configured with the Ignore no-cache HTTP headers in the response setting enabled
  • An origin web server (OWS) returns a response with a No-Cache header for an object which is otherwise eligible for intelligent browser referencing (IBR)

F5 Networks Product Development is tracking this issue as CR125167.

Workaround

You can work around this issue by modifying the BIG-IP WebAccelerator policy to force proxying for the affected object, which prevents the object from being SmartCached and from being eligible for IBR. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Browse to Policies.
  3. Select the policy you want to modify.
  4. Select Acceleration Rules from the drop-down box.
  5. Click the Proxying tab.
  6. Select or create a node which includes the affected object.
  7. Configure a proxy rule or enable the Always proxy setting.
  8. Click Save.
