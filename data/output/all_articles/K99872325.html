Topic

You should consider using this procedure under the following conditions:

  • You want to modify the HTML content using the BIG-IP system.
  • The web pages use one of the following content types:
    • text/html
    • text/xhtml
    • text/xml

Description

You can use HTML profiles to modify HTML content sent in responses from the back-end servers. When you configure an HTML profile, you create one or more HTML rules to locate and modify specific parts of the HTML content. HTML rules allow you to remove comments, tags, and attributes, prepend and append HTML content, and modify HTML using iRules. The Raise Event on Tag and Raise Event on Comments rule types raise the HTML_TAG_MATCHED and HTML_COMMENT_MATCHED iRule events, respectively, when matched. You can use an iRule to trigger on the events and perform the content modifications.

For example, a web page may have <a> tags with href links to internal and external URLs. If you want browsers to open a new tab when the external links are clicked, you can add the target="_blank" attribute to the <a> tag.  Using an HTML profile, you can search for the <a> tags that contain href attributes with external links, and use an iRule to append the target attribute to the tag.

If the original <a> tag appears as follows:

<a href="http://www.example.com">External Page</a>

When the BIG-IP system sends the page to the client, the resulting <a> tag contains the target:

<a href="http://www.example.com" target="_blank">External Page</a>

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have administrative access to the BIG-IP Configuration utility.

Note: Event on Tag Rule does not recognize wildcards or Regex for the Match Attribute Value. Only the literal string of the Match Attribute value, would trigger the event. For example, when the match attribute value is set to "http://www.example.com/*", the rule will not match "http://www.example.com/1", "http://www.example.com/test/", "http://www.example.com/**" or anything else apart from literally "http://www.example.com/*".

Procedures

Creating the HTML profile

When you create an HTML profile, you can create HTML rules during the profile creation process, or you can create HTML rules first and associate them with the HTML profile afterwards. This example creates an HTML profile that matches the example <a> tag previously mentioned and raises the HTML_TAG_MATCHED iRule event.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Content > HTML.
  3. Select Create New Profile.
  4. For Profile Name, type a name for the profile.
  5. For Parent Profile, select a profile from the list.
  6. Select Content Settings to review the configured content types.

    The default content types are text/html and text/xhtml.

  7. Optional: To add more content types, select Add, type the new content type in the box, and select Update.
  8. Select HTML Rules.
  9. To expose the list of HTML rule types, select the down arrow next to Create Rule.
  10. Select the Raise Event on Tag rule type.
  11. For Rule Name, type a name for the rule.
  12. Select Match Settings.
  13. For Match Tag Name, type the name of the HTML tag you want to match.

    For this example, you would type the letter a to match the <a> tag.

  14. For Match Attribute Name, type the name of the tag attribute to match.

    For this example, you would type href.

  15. For Match Attribute Value, type the tag attribute value to match.

    For this example, you would type the following:

    http://www.example.com

  16. Select OK.
  17. Under Available Rules, select the name of the newly created rule.
  18. Select < to move the rule to Selected Rules.
  19. Select OK.
  20. Go to Local Traffic > Virtual Servers.
  21. Select the name of the virtual server.
  22. For the HTML Profile setting under Content Rewrite, select the new HTML profile.
  23. Select Update.

Creating the iRule

When using the Raise Event on Tag rule type in an HTML profile, you also need to create an iRule with the HTML_TAG_MATCHED event to modify the HTML. When the HTML rule matches, it raises the HTML_TAG_MATCHED event and triggers the iRule. For the example scenario, the iRule inserts the target attribute with a value of _blank which prompts browsers to open a new window or tab. To create the iRule, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > iRules.
  3. Select Create.
  4. For Name, type a name for the iRule.
  5. For Definition, type the code for your rule.

    For example, to insert the target="_blank" attribute, enter the following code:

    when HTML_TAG_MATCHED {
       log local0. "matched tag = [HTML::tag name]"
       log local0. "matched link = [HTML::tag attribute "href"]"
       HTML::tag attribute insert "target" "_blank"
    }

  6. Select Finished.
  7. Go to Local Traffic > Virtual Servers.
  8. Select Edit next to the name of the virtual server.
  9. Under iRules, select Manage.
  10. Under Available, select the name of the iRule.
  11. Select << to move it to Enabled.
  12. Select Finished.
Note: this procedure doesn't apply to content inside of Javascript files, or in case of using a tag within a <script></script> section as the behavior could lead to broken applications. However if replacing content within Javascript files is needed, then you can use Stream profile to replace any text within the HTML document or Javascript file.
