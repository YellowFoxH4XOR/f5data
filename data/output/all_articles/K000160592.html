Description

You want to know whether BIG-IP Advanced Web Application Firewall (Advanced WAF), also known as Application Security Manager (ASM), can inspect and protect IMAP traffic.

Environment

  • BIG-IP Advanced WAF (ASM)
  • IMAP/IMAPS traffic
  • Security inspection

Cause

BIG-IP Advanced WAF (ASM) inspection engine is limited to HTTP/HTTPS protocols and requires an HTTP profile, which IMAP traffic does not use.

Recommended Actions

BIG-IP Advanced WAF/ASM does not support security inspection for IMAP protocol traffic.

For IMAP/IMAPS traffic, use BIG-IP LTM for:

  • Load balancing
  • SSL offload
  • Health monitoring
  • Persistence

Note: If deep application-layer security inspection of IMAP/email traffic is required, deploy a dedicated email security gateway solution, as this is outside the scope of BIG-IP Advanced WAF

Additional Information

  • ASM (Advanced WAF) is exclusively designed for HTTP/HTTPS traffic and requires an HTTP profile on the virtual server.
  • IMAP/IMAPS traffic is fundamentally incompatible with ASM policy enforcement due to protocol and profile requirements.
  • BIG-IP LTM can handle IMAP/IMAPS for traffic management purposes but does not provide WAF-level security inspection.
