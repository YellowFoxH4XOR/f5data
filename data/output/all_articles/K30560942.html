Description

BIG-IP DNS provides the availability information for pool and pool members status. You can check the information by iControl REST. This is especially helpful when there are a lot of A record pools and pool member objects and you need to effectively retrieve all of the availability information with one command. You can also specify a single A record pool to view pool member availability.
  • View all pools and their pool members
  • View a specified pool and its members
  • View only selected information in pool output
If the workstation you are using does not have the jq (command line JSON processor) utility installed, you can omit that portion of the command by removing the | jq . that ends the command string.

View all pools and their pool members
To view all pools and their pool members you can use the following syntax.

curl -sku <username>:<password> "https://<IP address or localhost>/mgmt/tm/gtm/pool/a/members/stats" | jq .

For example:

curl -sku admin:admin "https://localhost/mgmt/tm/gtm/pool/a/members/stats" | jq .

The output will show the pool's availability as well as each member. The following example output displays a single pool and one of it's members. Note the two levels of status.availabilityState one for the pool and one for the pool member.

View a specified pool and its members
To view a specified pool and its pool members you can use the following syntax:
curl -sku <username>:<password> "https://<IP address or localhost>/mgmt/tm/gtm/pool/a/~Common~<pool>/members/stats" | jq .
For example:
curl -sku admin:admin "https://localhost/mgmt/tm/gtm/pool/a/~Common~MyPool/members/stats" | jq .

The following example output shows a single member of the specified pool:

View only selected information in pool output
To view only the virtual server name and poolmember availability you can filter the output with the jq utility. For example:

curl -sku admin:admin "https://localhost/mgmt/tm/gtm/pool/a/~Common~MyPool/members/stats" | jq '.entries[].nestedStats.entries | .vsName,."status.availabilityState"'

The output appears similar to the following example:

{
  "description": "/Common/MyVS1"
}
{
  "description": "available"
}
{
  "description": "/Common/MyVS2"
}
{
  "description": "offline"
}
