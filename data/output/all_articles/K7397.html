A vulnerability exists that allows an authenticated FirePass user to download files from the filesystem of a FirePass controller. In order to download a file, the user must first log in to the FirePass controller webtop or the Admin UI, and type a specially crafted URL into their web browser. This vulnerability does not permit the user to write files to the filesystem, only to download existing files. Such files may contain sensitive configuration information.

Important: This issue can only be exploited after a user has successfully authenticated to the FirePass controller.

Users without a valid login to the FirePass controller cannot reproduce this issue.

F5 Product Development tracked this issue as CR77921 and it was fixed in FirePass software version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, hotfixes have been issued for certain versions of the FirePass software. For FirePass versions 5.5 and 5.5.1, the issue was fixed in hotfix-75705-77921. For FirePass version 5.5.2, the issue was fixed in cumulative hotfix HF-552-8. For FirePass version 6.0.0, the issue was fixed in cumulative hotfix HF-600-13. For FirePass version 6.0.1, the issue was fixed in cumulative hotfix HF-601-2.

You may download this hotfix or a later version of the cumulative hotfix from the F5 Downloads site.

For information about downloading software, refer to K167: Downloading software from F5.
