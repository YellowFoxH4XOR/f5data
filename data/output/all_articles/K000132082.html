K000132082: Monitor BIG-IP devices using SNMPv3. Randomly some devices stop answering SNMP queries

Type
Support Solution
Published
2023-01-19
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K000132082

Description

  • Randomly some devices stop answering SNMP queries, then start to respond again
  • Only devices with 300 OIDs requested do not experience this issue
  • NETWORK_ERROR on SNMP client

Environment

  • SNMPv3
  • Monitoring tool for example Zabbix
  • Large configuration on BIG-IP devices

Cause

Bug ID 798885

 

Large configuration on BIG-IP devices

 

 Recommended Actions

  • Lengthen time for pooling large tables - change interval.
  • Consider pool more specific OIDs, not walking through entire trees.

 

Additional Information

None
