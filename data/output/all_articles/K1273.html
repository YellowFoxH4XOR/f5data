Topic

The BIG-IP system requires client and server certificates and keys in the BIG-IP PEM (OpenSSL) format.

Any certificate from a Certificate Authority (CA) that is marked for OpenSSL, Apache with OpenSSL, Apache with Stronghold, or Stronghold is in BIG-IP PEM format and will work with the BIG-IP system.

If you are required to perform a conversion of the PKCS certificates to PEM format, the related articles are as follows:

  • To convert PKCS certificates to PEM format, refer to K6549: Converting PKCS certificates to PEM format for use with the BIG-IP system.
  • There is a limitation on the supported file size of a Certificate Revocation List (CRL) that can be applied to a Secure Sockets Layer (SSL) profile. For information about this limitation, refer to K10054: The BIG-IP file size limits for CRL files.
