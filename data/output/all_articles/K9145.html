Topic

The FirePass Application Logs (App Logs) report contains a list of actions that users, administrators, and superusers perform on the FirePass controller. The App Logs report is located on the Reports: App Logs page, and you can use this report to track user activity on the FirePass controller. You can enable App Logs by selecting the Enable App Logs check box on the Device Management: Maintenance: Logs page. By default, App Logs are enabled on the FirePass controller.

When App Logs are enabled on the FirePass controller, you have the option to enable Extended App Logs by selecting the Enable Extended App Logs check box on the Device Management: Maintenance: Logs page. By default, Extended App Logs are disabled on the FirePass controller. When Extended App Logs are enabled, FirePass logs additional parameters (such as form variables) that are used to trigger the application event. Extended App Logs provide a greater level of detail into user activity, and may assist in troubleshooting issues.

For example, when Extended App Logs are enabled and a FirePass administrator creates a new Portal Access Web Application favorite, the Reports: App Logs page displays entries that appear similar to the following example:

When Extended App Logs are disabled and a FirePass administrator creates a new Portal Access Web Application favorite, the Reports: App Logs page displays a single entry that appears similar to the following example:
 
09/03/2008 16:33:52 192.168.0.131 admin 4c85c [949267] Access menu Resources
 
Important: By default, the Enable Extended App Logs check box is not selected. Enabling this option may significantly increase the amount of log data created and stored on the FirePass controller. Additionally, enabling this option increases the CPU and memory usage on the FirePass controller. Unless otherwise required for troubleshooting or auditing purposes, FirePass administrators should consider leaving the Enable Extended App Logs option to its default disabled setting.
 
For more information about App Logs, including configuring specific log levels for App Logs, refer to the FirePass Controller Administrator Guide.
