Issue

Error Message

notice mcpd[<PID>]: 010713b8:5: Propose change to system hostname (<hostname>)

In this error message, note the following:

  • <PID> is the process ID of the mcpd process.
  • <hostname> is the new host name of the vCMP guest.

For example:

notice mcpd[5187]: 010713b8:5: Propose change to system hostname (example_hostname)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when following conditions is met:

  • The vCMP hypervisor implements a change in the host name of the vCMP guest.

Note: This message is a notification of a change in the host name of the vCMP guest initiated from the vCMP host. This can happen during the normal system start process or when an administrator makes a change to the host name of the guest from the vCMP host.

Impact

The system host name of the vCMP guest is updated to the new value.

Recommended Actions

You should verify that the change is intentional. In addition, verify the value of the new vCMP host name by performing the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Verify the value of the new host name by typing the following command:

    tmsh show sys hypervisor-info
