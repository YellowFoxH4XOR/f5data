Known Issue

This is the result of a known issue. When a client certificate is presented for authentication to BIG-IP APM, and the certificate Subject Alternative Name entry is populated with a Microsoft Active Directory Universal Principal Name (UPN), BIG-IP APM will return the following error message:

Subject Alternative Name: othername:<unsupported>

The BIG-IP x509 certificate parser does not recognize the object identifier (OID) for the Microsoft UPN data.This issue can affect access policy checks that rely on UPN information stored in a client certificate, for example, when the BIG-IP APM attempts to perform an Active Directory group lookup based on the user's UPN.

F5 Product Development tracked this issue as ID 336881 and it was fixed in BIG-IP APM 10.2.2 and 11.0.0. For information about upgrading, refer to the BIG-IP APM release notes.
