K000152882: Disabling Trace Menu from being accessible to end users [Portal Access]

Description

When using BIG-IP APM Portal Access for RDS(Remote Desktop Services), users may see a "TRACE" menu when right-clicking inside the RDS web portal session. Activating this menu and clicking "Apply" displays F5 debug code, and an F5_DebugMode cookie is set with the selected trace options. This internal debug/trace menu should not be accessible to end users in production environments.

Environment

  • BIG-IP APM
  • Portal Access
  • Webtop with RDP resource

Cause

The TRACE menu is part of the APM Portal Access web application engine's internal debugging functionality. It becomes available when specific system database variables are set:

  • log.webapplications.level is set to "Debug" or higher 
  • log.webapplications.trace.sessionid contains a session value

These settings enable the debug/trace menu for user sessions.

Recommendations

To disable the TRACE menu and prevent user access to this debug feature:

  1. Clear the Debug Session ID:

    Remove any value from the session ID variable:
    tmsh modify /sys db log.webapplications.trace.sessionid { value " " }

  2. Set Logging Level to "Notice" or lower:

    Change logging level from "Debug" to "Notice":
    tmsh modify /sys db log.webapplications.level { value "Notice" }

  3. Restart User Sessions:

    After applying these changes, ensure users start new sessions (log out and back in) so that the TRACE menu no longer appears.

  4. Optional Verification:
  • Confirm settings with:

    tmsh list sys db log.webapplications.level
    tmsh list sys db log.webapplications.trace.sessionid

  • Clear browser cookies/cache if the menu persists.
