Description

In order to better protect your network you may find you need to alter some settings. For the BIG-IP one way to do this is by using specific Port Lockdown settings for the Self-IPs that are used to pass traffic. 

Environment

Using the proper Port Lockdown settings can restrict access to the BIG-IP and can permit only specific traffic by Protocol/port number. 

Cause

This brings up some questions.

  1. How would that effect data traffic?
    1. There are 4 exceptions. One of those is that "defined" virtual server traffic overrides any Port Lockdown setting and traffic will work as configured in the virtual server settings. Those 4 exceptions are listed in K17333: Overview of port lockdown behavior (12.x - 17.x)
  2. How would that effect monitor traffic?
    1. The port lockdown settings of “Allow none” and "Allow Custom" do NOT prevent the Self-IP from being used to perform monitor checks on pool members. Specifically those settings apply to incoming traffic to the selfip. So if you were trying to access the BIG-IP via the non-floating self-ip then it would not be allowed if not allowed per the Port Lockdown setting. The monitor traffic is being initiated by the BIG-IP to a specified destination. 
  3. How would that effect HA traffic?
    1. HA will break over the network interface when set to Allow None. K14666670: Setting a self IP to ''Allow None'' for Port Lockdown will disrupt HA
  4. How would that effect sync traffic?
    1. It is not effected because it uses the same port (4353) as iQuery which is one of the 4 exceptions.

Recommended Actions

Decide which Port Lockdown setting..."Allow None" (default setting), "Allow All", "Allow Default", or "Allow Custom" is needed based on network demands. These settings restrict "ACCESS" to the BIG-IP. Albeit in different manners. They do not necessarily restrict traffic traversing the BIG-IP.

  • Allow Default: Activates only the default protocols and services. You can determine the supported protocols and services by running the tmsh list net self-allow defaults command on the command line.

  • Allow All: Activates all TCP and UDP services on this self IP.

  • Allow None: Specifies that this self IP accepts no traffic.

  • Allow Custom: Expands the Custom List option, where you can specify the protocols and services to activate on this self IP.

  • Allow Custom (Include Default): Activates the default protocols and services as well as the custom protocols and services you select for this self IP address using the expanded custom list options.
