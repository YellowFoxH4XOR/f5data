K000140200: Setting the logging level for snmp-service to suppress "Invalid fan instance:" log message

Type
Support Solution
Published
2024-07-01
Updated
2024-07-01
Source
https://my.f5.com/manage/s/article/K000140200

Description

The following log message is benign, and can be suppressed:  

2024-06-03T09:55:05.442126+09:00 appliance-1 snmp-service[1]: priority="Err" version=1.0 msgid=0x6a01000000000016 msg="Invalid fan instance:" fan_instance=5.

 

Environment

F5OS SNMP

 

Cause

This log is because the device logs errors for fans that don't exist. This platform has 4 fans but is expecting 12. The logs are benign but can be stopped with the steps outlined below

 

Recommended Actions

You can use these steps to stop those messages:

appliance-1(config)# system logging sw-components sw-component snmp-service config severity CRITICAL

appliance-1(config-sw-component-snmp-service)#

appliance-1(config-sw-component-snmp-service)# commit

Commit complete.

appliance-1(config-sw-component-snmp-service)#
