Description

  • I want to know how to use the F5® Distributed Cloud DNS dashboard

Environment

  • F5® Distributed Cloud DNS

Answer/Recommended Actions

Use the DNS dashboard

Access the DNS Service dashboard by using the DNS Management tile and clicking on Domain Management > DNS Management

 

 

By default on this page, you can:

  • See how many zones you have created (both Primary and Secondary)
  • View the status of each zone in your Primary DNS Cloud Service environment
  • Click Actions > Manage Configuration to View the details for that DNS zone
  • Create and deploy a primary or secondary DNS zone
  • Modify the fields to display in the dashboard in the engine icon
