Description

This article will explain how to use only TLS 1.2 (and disable other SSL/TLS versions) for the BIG-IP GUI (web Configuration utility/terminal) and its impact.

Environment

  • BIG-IP
  • Use TLS 1.2 only for the GUI.

Cause

None

Recommended Actions

Use tmsh to configure GUI to only accept TLS 1.2

Impact of procedure: The GUI will only use TLS 1.2. Your client browser will need to support TLS 1.2. Clients who do not support TLS 1.2 may not be able to connect. Updated browsers should support TLS 1.2.

This action can only be performed on the command line.

  1. Login to the BIG-IP command line.
     
  2. Log in to tmsh by typing the following command:
    tmsh
     
  3. Modify the enabled SSL protocols using the following command:
    modify /sys httpd ssl-protocol TLSv1.2
     
  4. Save the configuration change by typing the following command:
    save /sys config
