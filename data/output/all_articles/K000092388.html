Description

Restjavad restarting after upgrade to v16.1.3.1 from v13.1.5 and device lcd is still showing host inaccessible or in diagnostic mode with error

  • Error: Uncaught Error causing restjavad to exit. Thread id 25, 'Non-Blocking threadPool_4': java.lang.OutOfMemoryError: Java heap space

 

 Environment

  • BIG-IP running 16.1.3.1
  • Host Inaccessible or in Diagnostic Mode
  • Restjavad exiting immediately due to an uncaught Error

 Cause

16.1.3.1 has a new variable, sys db provision.restjavad.extramb, which defaults to 192, which is definitely going to be too low.

A bug filed regarding this already:

Bug ID 1153853: Revision of initial value for provision.restjavad.extramb to avoid OOM errors in restjavad

 

 Recommended Actions

Modify restjavad variables via CLI:

 

Note: The below commands can cause a short traffic disruption as HA failover might occur while the services restart, so should be done during a maintenance window.

 

1. tmsh modify sys db provision.extramb value 2000

2. tmsh modify sys db provision.restjavad.extramb value 1500

3. tmsh modify sys db provision.tomcat.extramb value 1000

4. tmsh modify sys db restjavad.useextramb value true

5. bigstart restart restjavad && sleep 20 && bigstart restart restnoded
