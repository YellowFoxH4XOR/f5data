K000156032: Existing APM Citrix Client bundle cannot be updated for new HTML5 Package

Type
Support Solution
Published
2025-09-16
Updated
2025-09-16
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000156032

Description

An existing APM Citrix Client bundle cannot be updated for new HTML5 Package. Or a new Citrix Client bundle for HTML5 with new package cannot be created.


Trying to update the html5 package in an existing citrix client bundle throws an error:

 


And also trying to create a new HTML5 client bundle is not allowed:

 



Environment

  • BIG-IP APM
  • Citrix Client bundle for HTML5


Cause

Currently the overwriting of the HTML5 package is not allowed and it is identified as an improvement.


Recommended Actions

  1. Disassociate previous citrix client bundle "citrix-html5" from connectivity profile and select the default bundle
  2. Delete the client bundle "citrix-html5"
  3. Now upload the Windows package file to a new client bundle "html5_test"
  4. Associate client bundle "html5_test" to the connectivity profile
