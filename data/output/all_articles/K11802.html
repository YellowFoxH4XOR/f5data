Known Issue

This is the result of a known issue.  On hosts with a switch card control processor (SCCP), when there is no fiber cable connected to an SFP port, but the the SFP is installed, the BIG-IP system may incorrectly report the port as unpopulated instead of down.

For example:

Apr 15 15:50:27 local/sccp info bcm56xxd[16888]: 012c0015:6: Link: 2.4 is UNPOPULATED

Note: For more information about the SCCP, refer to K3454: Overview of the SCCP.

When a fiber cable is connected to the existing SFP, it will be correctly reported as up.

F5 Product Development is tracking this issue as ID 328310 (formerly CR140174).

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP version 10.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
