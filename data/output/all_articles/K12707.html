K12707: FirePass does not retain the state of the webtop banner between sessions for external user accounts

Type
Knowledge
Published
2011-03-10
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 7.0.0, 6.1.0
Source
https://my.f5.com/manage/s/article/K12707

Topic

FirePass allows users to hide the webtop banner. For a local user account, FirePass retains the state of the banner from the user's previous session. For external user accounts, such as Active Directory or Radius accounts, FirePass does not retain the state of the banner. In addition, FirePass sets the banner to the value configured in the user's master group Webtop doesn't show logo and banner by default setting.

This behavior is expected. FirePass does not store local information for external user accounts.
