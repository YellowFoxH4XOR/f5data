Known Issue

This is the result of a known issue with the ZoneRunner utility. During large zone transfers between BIND and ZoneRunner, or when attempting to view a large list of records within ZoneRunner, ZoneRunner is overwhelmed by the large amount of data received from BIND at one time, and will not be able to read or display the resource records. Under these circumstances, the ZoneRunner configuration utility will display an error message that appears similar to the following example:

zrd: 01150b07:3: Resolver returned error from initparse.
zrd: 0115010c:3: Unable to query zone '<zone name>.'

This error message reports that ZoneRunner is unable to read a zone. The error message will also be logged in /var/log/gtm log file.

This issue only occurs when ZoneRunner attempts to handle large zone files and does not affect DNS requests. Only ZoneRunner is affected, in that the ZoneRunner configuration utility is unable to read and display the zone information—the zone transfer still occurs between BIND and ZoneRunner.

F5 Product Development tracked this issue with the ZoneRunner utility as CR73297 and it was fixed in BIG-IP GTM 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
