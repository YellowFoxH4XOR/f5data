Known Issue

This is the result of a known issue. When TMM receives a flow teardown message from the PVA10 chip, a warning message similar to the following is logged to the /var/log/ltm file:

tmm tmm[2063]: 012f0002:4: WARN at ../modules/hudproxy/bigproto/pva/pva_connection.c:997:Unknown table type 5, discarding

The warning message does not indicate a critical condition and does not impact the system's performance. The PVA10 chip generates a teardown message for PVA assisted TCP flows when it receives an RST or FIN/ACK packet, or when a PVA-assisted flow has timed out.

F5 Product Development is tracking this issue as CR89262.
