Known Issue

This is the result of a known issue. The gatewayOffline event is not cleared after a gatewayOnline event. The gatewayOffline event continues to display in the show health command output, as shown in the following example:

System Health Information
Date                     ID      Event                       Description
-----------------------------------------------------------------------------------------
Fri Dec 25 12:34:56 2009 (185) - gatewayOffline              gatewayOffline event message

F5 Product Development tracked this issue as ID 37037 and 340643 and it was fixed in ARX versions 5.3.1 and 6.0.0. For information about upgrading, refer to the ARX release notes.
