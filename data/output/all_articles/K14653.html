Known Issue

You cannot use the BIG-IP Configuration utility to create SSL certificates and keys in system sub-folders.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP system with one or more system sub-folders, in addition to any high-level folders, such as the default /Common folder.
  • You attempt to use the BIG-IP Configuration utility to create a certificate or key in a sub-folder by referencing the system folder path.

For example:

  • You use the Traffic Management Shell (tmsh) to create a system folder in the /Common folder named folder1.
  • You then use the BIG-IP Configuration utility to attempt to create a certificate named cert1 in the /Common/folder1 folder.
  • From the SSL Certificate List screen, you click Create.
  • In the Name box for the new certificate, you enter /Common/folder1/cert1 and click Finished.
  • An error message appears, indicating an invalid certificate name.

Impact

You cannot use the BIG-IP Configuration utility to create certificates and keys in sub-folders.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When using the BIG-IP Configuration utility to create a certificate or key with the system folder path, the command fails. In addition, an error message displays that is similar to the following example:

    Invalid certificate name. Certificate names must start with a letter or number and may have the following characters: [A-Za-z][0-9]-._

Workaround

To work around this issue, you can use the tmsh utility to create certificates and keys in system folders. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

    Note: If you are currently logged in to tmsh, you can skip this step.

  2. Change directories to the desired system folder name using the following command syntax:

    cd /<path-to-folder>

    For example, to change directories to the system folder named Folder1 in /Partition1, type the following command:

    cd /Partition1/Folder

  3. To create the key or certificate for the current system folder excluding the system folder path, use the following command syntax:

    create /sys crypto key <key name> key-size <size of key in bits>

    In this command, note the following:

    • <size of key in bits> can be 512, 1024, 2048, or 4096
    For example, to create a key named key1, type the following command:

    create /sys crypto key key1 key-size 2048

  4. To save the changes you made to all system folders and partitions, type the following command:

    save /sys config partitions all

  5. To exit the tmsh utility, type quit and press Enter.
