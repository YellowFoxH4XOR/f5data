K03215628: Running preUpgradeCheck script fails

Type
Support Solution
Published
2022-05-04
Updated
2023-02-21
Applies to
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X, 6.X.X
Source
https://my.f5.com/manage/s/article/K03215628

Description

When executing preUpgradeCheck, sometimes it fails. You may get the following error message:
KeyError: 'isLicenseExpired'

Environment

  • BIG-IQ

Cause

You use an old version of preUpgradeCheck.

Recommended Actions
Use the latest version of preUpgradeCheck script. You can go to downloads.f5.com and download F5_Networks_BIG_IQ_PreUpgradeCheck_Tool-<version>.tar which contains this script.

Additional Information

None
