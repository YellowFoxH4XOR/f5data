Known Issue

This is the result of a known issue. When the DNS servers that are configured on the DNS tab of the Device Management: Configuration: Network Configuration page are unreachable, certain pages in the Administrative Console fail to refresh or to load after entering hostnames, fully qualified domain names (FQDN) or IP addresses into configuration fields.

The following pages may fail to load:

  • Device Management: Security: Admin Access Security
  • Device Management: Configuration: SNMP

F5 Networks Product Development is tracking this issue as ID 266837 (Formerly CR81196).

Workaround

Ensure that the FirePass controller has at least one valid DNS server configured on the DNS tab of the Device Management: Configuration: Network Configuration page and the server is responding to DNS queries. Restoring DNS response will permit access to the Device Management: Security: Admin Access Security page and the Device Management: Configuration: SNMP page.
