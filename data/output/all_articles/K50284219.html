Description

This article describes the procedure of using REST API to generate and export ASM Event Reports.


Environment

  • Local logging profile applied to Virtual Server
  • iControl REST API


Cause

None.


Recommended Actions

The following describes the procedure for exporting ASM event reports.
 

  1. Log in to the BIG-IP CLI.
  2. Run the curl command to generate ASM event report:

    curl -X POST -sku <username>:<password> https://localhost/mgmt/tm/asm/tasks/export-to-file -d '{"restPath":"/mgmt/tm/asm/events/requests","filename":"ASM_security_event_report_<date-and-time>.html","filter":"id eq '<support_id>'"}' | jq .

    Where,
    <username> : User name of the Administrator
    <password> : Password of the Administrator
    <date-and-time> : Date and Time of the required Event Report
    <support_id> : Support ID of the Event

    A successful response will be similar as below:

    {
        "isBase64": false,
        "inline": false,
        "filter": "id eq '<support_id>'",
        "status": "NEW",
        "lastUpdateMicros": <lastUpdateMicros>,
        "restPath": "/mgmt/tm/asm/events/requests",
        "kind": "tm:asm:tasks:export-to-file:export-to-file-taskstate",
        "selfLink": "https://localhost/mgmt/tm/asm/tasks/export-to-file/<response-id>?ver=14.1.4",
        "filename": "ASM_security_event_report_<date-and-time>.html",
        "id": "<response-id>",
        "startTime": "<start-time>"
    }
  3. Download the file with following command:

    curl -sku <username>:<password> https://localhost/mgmt/tm/asm/file-transfer/downloads/ASM_security_event_report_<date-and-time>.html

    Where, 
    <username> : User name of the Administrator
    <password> : Password of the Administrator
    <date-and-time> : Date and Time of the required Event Report
