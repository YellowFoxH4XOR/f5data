Topic

Note: Beginning in BIG-IP WebAccelerator version 10.0.0, the .json file type is recognized by the BIG-IP WebAccelerator's globalfragments.xml file. Additionally, the pre-defined Acceleration Policies include the JSON node, with properties similar to the XML node.

The BIG-IP WebAccelerator 9.x versions do not have an object type in the /config/wa/globalfragment.xml file to support JavaScript Object Notation (JSON) files. These files usually have a .json extension and are labeled with the application/json or text/json MIME media type.

F5 Product Development tracked a request for enhancement to add this functionality as CR104405, and it was added in BIG-IP WebAccelerator version 10.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Workaround

If upgrading is not an immediate option, you can add an object type for JSON files to the globalfragment.xml file and configure an acceleration policy to use the new object type. To do so, perform the following two procedures:

  • Adding a pages.json object type for JSON files to the globalfragment.xml file
  • Configuring an acceleration policy with a JSON node that uses the pages.json object type

Adding a pages.json object type for JSON files to the globalfragment.xml file

To add a pages.json object type for JSON files to the globalfragment.xml file, perform the following procedure:

  1. Log in to the command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa

  3. Back up the original globalfragment.xml file by typing the following command:

    cp globalfragment.xml globalfragment.xml.sol10171

  4. Open the globalfragment.xml file in a text editor.
  5. Add the following objType entry to the end of the objTypes section:

    <objType
                    type="json"
                    group="pages"
                    category="common"
                    displayName="Json"
                    ext="json"
                    mimeType="
                        application/json
                        application/x-json
                        text/json"
                    compressToClient="policyControlled"
                    predefined="true"
                />

  6. Save the globalfragment.xml file.
  7. Restart the pvac daemon by typing the following command:

    Important: Restarting the pvac daemon briefly disrupts connections and invalidates objects in the LTM RAM Cache. Restarting the pvac daemon should be scheduled accordingly.

    bigstart restart pvac

The pages.json file can now be used for the Content Type in the Matching Rules section of a WebAccelerator policy.

Configuring an acceleration policy with a JSON node that uses the pages.json object type

To configure an acceleration policy with a JSON node that uses the pages.json object type, perform the following procedure:

Note: Pre-defined Acceleration policies are not modifiable; this procedure must be performed on a User-defined Acceleration policy.

  1. Log in to the BIG-IP WebAccelerator Configuration utility.
  2. Click WebAccelerator.
  3. Click Policies.

    A new Policies Configuration window opens.
  4. Click the User-defined Acceleration policy to be configured.
  5. Click the plus ( + ) sign to expand the Site nodes.
  6. Click the plus sign to expand the Application Generated nodes.
  7. Click the XML node.
  8. Click the Copy link at the top of the policy tree.
  9. Type JSON in the Name field.
  10. Click Copy.
  11. Click the new JSON node.
  12. Select Matching Rules from the drop-down menu.
  13. Click Content Type.
  14. Delete the contents of the Value matches field.
  15. Type pages.json in the Value matches field.
  16. Click Save.
  17. Click Publish.
  18. Optionally, type a comment or note in the Comment field.
  19. Click Publish Now.
