Description

  • Config sync disconnected after upgrade
  • Error message in /var/log/ltm 
    Peer cert verify error: self signed certificate in certificate chain

Environment

  • Upgrade from version vulnerable to CVE-2019-6649 to fixed version
  • Config sync configured to use management IP
  • Device trust certificate of authority for both devices was different prior to the upgrade
     

Cause

In earlier versions where CVE-2019-6649 was not fixed CMI connections using the management interface address did NOT use the device trust certs to encrypt the traffic. The CA bundles being different did not affect HA or config sync because the certificates were not used to encrypt the traffic.  After upgrade to a version where CVE-2019-6649 is fixed CMI connections for config sync are encrypted and thus some configurations that were working before upgrade will not config sync after upgrade.
 

Recommended Actions

If you are using the management IP address for config sync, you should ensure the CA matches on both devices in the trust before upgrade. 

To mitigate the issue after upgrade rebuild device trust:
K42161405: Rebuilding device trust using the Configuration utility (11.x - 15.x)

K40832524: Rebuilding device trust using tmsh (11.x - 15.x)

 
 

Additional Information

To identify versions where CVE-2019-6649 is fixed refer to Security advisory K05123525: ConfigSync vulnerability CVE-2019-6649
