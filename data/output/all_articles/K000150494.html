K000150494: Unable to tcpdump on VELOS partition with error: "threshold limit (2GB) reached! Aborting the client"

Type
Support Solution
Published
2025-03-21
Updated
2025-03-21
Applies to
  • F5OS
  • F5OS-C: 1.8.X, 1.6.X, 1.8.0, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000150494

Description

Unable to write a VELOS partition tcpdump to a file with the system diagnostics tcpdump command.

Observing an error similar to the following:

errbuf ERROR:partition Current Partition shared Volume(/var/F5/partition1/shared/) threshold limit (2GB) reached! Aborting the client
tcpdump: pcap_loop: partition Current Partition shared Volume(/var/F5/partition1/shared/) threshold limit (2GB) reached! Aborting the client

Environment

  • VELOS
  • tcpdump

Cause

This message indicates there is insufficient disk space on the partition's filesystem of the controller that is running-active for the partition.

A bug also exists in F5OS-C v1.6.2 that prevents tcpdump, even if there is adequate disk space. This bug is fixed in F5OS-C v1.8.0.

Recommended Actions

Verify that there is adequate disk space on the partition's filesystem.

You may investigate this from the controller that is running-active for the partition, with the following command:

find /var/F5/partition<id>/shared -type f -exec du -sh {} \; | sort -hr

Delete files that are no longer required, as necessary, to free up disk space.

If you continue to observe the error message, despite adequate disk space, restart the tcpdumpd_manager container on the controller that is running-active for the partition, from bash:

docker container restart partition<id>_tcpdumpd_manager

Additional Information

Use the show partitions command from the active system controller to determine which controller is running-active for the partition.
