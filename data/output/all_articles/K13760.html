K13760: The BIG-IP system does not send resets on connection timeout when the ‘Reset on Timeout’ and ‘Loose Close’ settings are enabled in a FastL4 profile

Topic

Old Behavior

In BIG-IP software versions prior to 9.6.1, when the Reset on Timeout and Loose Close settings are both enabled in a FastL4 profile, the BIG-IP system will send a reset on connection timeout.

New Behavior

In BIG-IP 9.6.1 and later, when the Reset on Timeout and Loose Close settings are both enabled in a FastL4 profile, the BIG-IP system does not send resets on connection timeout. If the Reset on Timeout setting is enabled on its own, the system will send a reset on connection timeout.

Impact

Hosts connected to the BIG-IP system that do not receive a reset on connection timeout may accumulate excessive stale connections. If that host's TCP timeout is sufficiently high or infinite, the unclosed stale connections may cause system instability.

Recommended Actions

None
