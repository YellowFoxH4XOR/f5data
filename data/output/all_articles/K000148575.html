K000148575: Can I apply a WAF policy to my TCP load balancer?

Type
Support Solution
Published
2024-11-15
Updated
2024-11-15
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
  • F5 Distributed Cloud DNS Load Balancer
Source
https://my.f5.com/manage/s/article/K000148575

Description

My application is not an HTTP application or I cannot offload TLS to F5 Distributed Cloud (F5 XC). 

Environment

  • F5® Distributed Cloud (XC)
  • Load Balancer
  • TCP

Resolution/Answer

  • No, TCP load balancers do not support WAF functionality.
  • You can, however, still enjoy layer 3 and 4 data protections like DDoS protection, deny lists, rate limiting, and threat intelligence. 

Cause

  • WAF depends on reading HTTP headers and data. It must be able to parse HTTP content. A TCP load balancer does not have this functionality.
