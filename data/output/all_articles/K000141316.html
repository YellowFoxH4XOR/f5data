Description

The Base Registration Key shows as invalid when trying to activate it from GUI

Environment

  • BIG-IP
  • BIG-IQ

Cause

​​​​​​​Base Registration Key is in wrong format however it seems to be correct.

Recommended Actions 

  • Copy the Base Registration Key in notepad to confirm that the format is wrong
  • The Base Registration Key shows in wrong format as below
    ABCDE--ABCDE--ABCDE--ABCDE--ABCDEFG
  • Remove manually both dashes and put them again (ONE ONLY)
    ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG
