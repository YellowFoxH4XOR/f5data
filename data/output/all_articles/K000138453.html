K000138453: SNMP monitoring server is not able to poll SNMP UDP port 161 from BIG-IP

Type
Support Solution
Published
2024-02-27
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000138453

Description

The SNMP monitoring server (example: NetAct SNMP monitoring) server failed to poll SNMP UDP port 161 from BIG-IP with below error:

Connection Failure to to an SNMP Host: Host Unreachable

 

Environment

  • BIG-IP
  • GUI
  • SNMP Monitoring Server
  • Polling Agent

 

Cause

BIG-IP management interface network firewall rules are not defined to allow SNMP UDP port 161. There is a last global rule that blocks any traffic reaching the BIG-IP Management Interface that is not allowed in any existing rules.

Recommended Actions

Add BIG-IP management interface network firewall rules to allow SNMP UDP port 161, steps as below.

Impact of procedure: The BIG-IP system denies access to the Configuration utility if the rule configuration is incorrect for your environment.

  1. Log in to the Configuration utility.
  2. Go to System > Platform.
  3. Select the Security tab.
  4. To create a new rule, select Add.
  5. Enter a name for the rule.
  6. To automatically generate a Universally Unique Identification Number (UUID) for the rule, select the Auto Generate UUID check box. When you select this option, the BIG-IP system generates a unique 32-character identifier for the rule.
  7. For Order, select the order position for the new rule to appear in the rule list. The system processes rules from top to bottom in the rule list.
  8. For State, select the state you want the rule to take after saving.
  9. For Protocol, select UDP to match SNMP UDP port 161 protocol.
  10. For Source, for Address/Region, select Specify, then select the appropriate option:
    • If you select Address, enter the source IP address, and select Add. Repeat as necessary to add more source IP addresses.
    • If you select Address List, select the address list you want to use, and select Add.
    • If you select Address Range, enter the beginning and ending source IP addresses for the range, and select Add. Repeat as needed to add more IP address ranges.
  11. For Source, for Port, select Any.
  12. For Destination, for Address/Region, select Specify, then select the appropriate option:
    • If you select Address, enter the destination IP address, and select Add. Repeat as necessary to add more destination IP addresses.
    • If you select Address List, select the address list, and select Add.
    • If you select Address Range, enter the beginning and ending destination IP addresses for the range, and select Add. Repeat as needed to add more IP address ranges.
  13. For Destination, for Port, select Specify, then select the appropriate option:

    Note: This Port option is available for selection when you select TCP or UDP at step 9 for Protocol.

    • Select Port, enter the destination port number, and select Add to add "161" as SNMP UDP port number.
  14. For Action, select the action to perform when the rule matches. If you select Disable, the system does not apply the rule after creation.
  15. For Logging, select Enabled to enable logging for the rule. Log messages are logged to the /var/log/ltm file.

    Note: For the BIG-IP system to log locally, the local-syslog setting must be enabled in the default-mgmt-acl-log-publisher log publisher.
