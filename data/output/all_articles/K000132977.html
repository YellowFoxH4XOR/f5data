Source

Description

Modifying some Access Policies does not prompt to 'Apply Policy' but changes immediately take effect.


Environment

Big-IP APM

Cause

Expected Behavior

Recommended Actions

Create a copy the policy generated by the iApp and apply it to the appropriate virtual server to prevent changed from being immediately applied

Additional Information

When an Access Policy is deployed using an iApp and manually modified, any changes made will immediately take effect without prompting to 'Apply Policy' changes.
