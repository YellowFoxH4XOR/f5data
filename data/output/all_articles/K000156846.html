K000156846: Software Image upload failure

Type
Support Solution
Published
2025-10-09
Updated
2025-10-09
Applies to
  • VELOS Platforms
  • F5OS
  • F5OS-C: 1.6.1, 1.8.1
  • VELOS CX410
  • VELOS CX1610
Source
https://my.f5.com/manage/s/article/K000156846

Description

When uploading a new software image, it completed successfully but it is unavailable on the standby. Attempts to manually delete the image and upload again may lead the the following message

  • File upload in progress, please do not refresh the page

Environment

Relevant environmental factors specific to the topic

  • F5OS-C 1.6.1 upgrading to 1.8.x
  • New software image

Cause

Rsync failure or timeout. Root cause is unknown at this time.

 

Recommended Actions

  1.  Manually sync image to other controller # rsync /var/export/chassis/import/iso/F5OS-C-1.8.1* controller-2:/var/export/chassis/import/iso/
