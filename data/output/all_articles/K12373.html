K12373: The BIG-IP GTM and BIG-IP DNS Configuration utility screens do not include the network map feature

Topic

The BIG-IP LTM Configuration utility screen includes a network map feature. The network map page displays a visual representation of the local traffic objects on the BIG-IP system, such as virtual servers, pools, nodes, and iRules. The network map also displays statistics about existing objects. However, the BIG-IP GTM and BIG-IP DNS Configuration utility screens do not include the network map feature. Therefore, you cannot use the BIG-IP GTM or BIG-IP DNS Configuration utility screens to display a visual representation of either module's configuration objects.

Workaround

In BIG-IP DNS 12.x and BIG-IP GTM 10.x and 11.x, you can use the Traffic Management Shell (tmsh) from the command line to display information similar to the network map. To do so, perform the following procedure:

Note: For more information, refer to K12029: Accessing the Traffic Management Shell.

  1. Log in to the BIG-IP command line.
  2. To display a summary of wide IP and related objects, use the following command syntax specific to your BIG-IP version:

    • BIG-IP DNS 12.x

      tmsh show gtm wideip <rr_type> <wideip_name> detail

    • BIG-IP GTM 10.x and 11.x

      tmsh show gtm wideip <wideip_name> detail

      Note: Pool member IP addresses do not appear in the BIG-IP GTM 11.x output for this command. The pool members are virtual servers that belong to a server object. To view the pool member IP addresses, you can display a server object's summary using the following syntax:

      tmsh show gtm server <server_name> detail
