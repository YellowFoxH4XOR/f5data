Description

 

Configuration fails to load with diagnostics

err mcpd[6324]: 010717e1:3: Client SSL profile cannot contain more than one set of same certificate/key type.
err tmsh[17404]: 01420006:3: Loading configuration process failed.

 
Environment

BIG-IP LTM with client SSL profiles configured

Cause

Some profiles happen to contain more than one set of same certificate/key type

ltm profile client-ssl /Common/example {
    app-service none
    cert /Common/example.crt
    cert-key-chain {
        example1 {                             <============
            cert /Common/example1.crt
            chain /Common/example1-chain.crt
            key /Common/example1.key
        }
        example2 {                             <============
            cert /Common/example2.crt
            chain /Common/example1-chain.crt
            key /Common/example2.key
        }
    }
    chain /Common/example1.crt
    inherit-certkeychain true
    key /Common/example1.key
    passphrase none
}

 

 

Recommended Actions

Edit the configuration file to leave only one set under each profile

    ltm profile client-ssl /Common/example {
    app-service none
    cert /Common/example.crt
    cert-key-chain {
        example1 {                             <============
            cert /Common/example1.crt
            chain /Common/example1-chain.crt
            key /Common/example1.key
        }
    }
    chain /Common/example1.crt
    inherit-certkeychain true
    key /Common/example1.key
    passphrase none
}
