Description

Delay/slowness when accessing the virtual server or when uploading/downloading files through virtual server on BIG-IP Virtual Edition (VE) lab license.
However no issues observed when bypassing BIG-IP virtual server and accessing server directly. 

Environment

  • BIG-IP with Virtual Edition (VE) lab license.
  • maximum allowed throughput rate is 10 mbps
  • Slowness/latency when uploading/downloading files

Cause

The throughput limitation of the VE (10 Mbps) could account for this kind of slowness issue. The global throughput limitation is divided by the number of Traffic Management Microkernels (TMMs). 
You can determine the maximum allowed throughput rate on the BIG-IP VE system using steps provided in article: K14356: Determining the maximum allowed throughput rate on the BIG-IP VE system

Recommended Actions

  • Upgrade the BIG-IP device to a higher throughput license. 

Additional Information

When troubleshooting why a tcp transfer is slow, it's helpful to compare the performance between using a fastL4 profile and a tcp profile.
If the performance is better when using fastL4, then it points toward an issue with the settings in the tcp profile.
