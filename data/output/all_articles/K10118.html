Prior to ARX version 5.0.0, the ARX CLI Reference Guide does not include the proper syntax to join a CIFS global server to a nested organizational unit (OU). The proper syntax is to separate each layer in a nested OU path with a backslash ( \ ).

For example, to join a nested OU of Support and ARX to the askf5.f5.com domain, you would type the following command:

domain-join askf5.f5.com ou "Support\ARX"

Note: This information was included in the ARX CLI Reference Guide beginning in ARX version 5.0.0.

Note: For more information about the domain-join command, refer to the Front-End Services section of the ARX CLI Reference Guide.
