K30047782: Net HSM Partition named fortanix not working

Type
Support Solution
Published
2021-06-10
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K30047782

Description

When creating a new SmartKey HSM on the F5, the recommended nethsm-partition name at the time of this article's creation, 'fortanix', does not work.

  • Equinix SmartKey HSM is not working with nethsm-partition 'fortanix' and results in this pkcs11d error message:

    err pkcs11d[21535]: 01680040:3: netHSM: Failed to find partition with label 'fortanix' on the netHSM

  • BIG-IP does not connect to the HSM and SSL traffic is disrupted.

Environment

  • Setting up the Equinix SmartKey HSM with nethsm-partition 'fortanix' or anything other than 'auto'

Cause

This Known Issue is being tracked with Bug ID 1020069: Equinix SmartKey HSM is not working with nethsm-partition 'fortanix'.

Recommended Actions

Use the nethsm-partition 'auto', instead of 'fortanix' or anything else, with this command:

tmsh create sys crypto fips nethsm-partition auto

Additional Information

None
