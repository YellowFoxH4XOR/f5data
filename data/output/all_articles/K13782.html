Known Issue

A BIG-IP APM network access tunnel does not use a configured floating IP address as the egress IP of a network access tunnel.

This issue occurs when all of the following conditions are met:

  • The network access tunnel is configured with secure network address translation (SNAT) automap.
  • The Virtual Local Area Network (VLAN) to which the network access tunnel is passing traffic has a configured floating IP address.

Impact

Services that require a specific source address may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When a failover occurs, the system drops sessions.
  • Network traffic shows your BIG-IP system communicating using the VLAN local self IP address.

Workaround

To work around this issue, you can create a SNAT pool that contains the floating self IP address and associate the SNAT pool to a network access resource. To do so, perform the following procedure:

Impact of workaround: If the floating self IP address is changed, you need to manually update the SNAT pool.

Note: The BIG-IP APM system can use only a SNAT pool that is in the default route domain.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Self IPs.

    Note the configured floating self IP address.

  3. Navigate to Local Traffic > SNATs.
  4. Click the SNAT Pool List tab.
  5. Click Create.
  6. Enter a name for the SNAT pool.

    For example:

    FloatingIP-SNAT

  7. Enter the IP address from step 3 in the IP Address box.
  8. Click Add.
  9. Click Finished.
  10. Click Access Policy.
  11. Click Network Access.
  12. Click the name of the network access resource for which you are adding the SNAT pool.
  13. Click the Network Settings tab.
  14. Select the SNAT pool you previously created from the SNAT Pool menu.
  15. Click Update.
