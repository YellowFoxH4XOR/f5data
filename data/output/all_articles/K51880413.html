Known Issue

Importing an access profile with hosted content may fail.

This issue occurs when all of the following conditions are met:

  • You configure an object in an access policy that is linked to hosted content on the BIG-IP APM system.
  • You export the access policy and import it to another BIG-IP APM system that does not have the hosted content files.

Impact

The import process fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP APM system logs a message to the /var/log/apm file similar to the following example:

    01070734:3: Configuration error: Cannot find sandbox file (Common/hosted-content:example.html_1361913754973) referred in resource webtop (/Common/import-example) Unexpected Error: Validating configuration process failed.

  • You are unable to import the access policy to another BIG-IP APM system.

Workaround

To work around this issue, you can perform one of the following actions:

  • Remove the webtop link to the hosted content from the original access policy, then export and import the access policy again.
  • Upload the hosted content files to the other BIG-IP APM system before attempting to import the access policy.
