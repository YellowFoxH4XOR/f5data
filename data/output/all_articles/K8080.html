Topic

This procedure describes the process for changing the hostname or Fully Qualified Domain Name (FQDN) of a single FirePass controller. You should not follow this procedure if the FirePass controller is part of a failover pair, cluster, or SSL Offload configuration, since the steps will vary slightly for those configurations.

To change the FQDN of a single FirePass controller, perform the following procedure:

  1. Create a DNS record for the new FQDN of the FirePass controller, which points to the same IP address as the old FQDN. Create this DNS record on the authoritative DNS server for your domain.

    Important: When you create the DNS record for the new FQDN, do not delete the DNS record for the old FQDN. Keep the old DNS record in place until the procedure is complete and connectivity to the new FQDN is verified.

    Note: You may want to allow 24 to 48 hours for the new DNS record to fully propagate before proceeding to the next step.

  2. Log on to the FirePass Administrative Console.
  3. Navigate to the Device Management: Configuration: Network Configuration page.
  4. Click the Hosts tab.
  5. In the FQDN of the controller: text box, enter the new FQDN of the FirePass controller.

    6. For example:

    firepass001.siterequest.com

  6. Click the Update button.
  7. Click the Web Services tab.
  8. Click the Configure SSL Certificates >> link.
  9. Click the Self-Signed Certificate button to generate a new self-signed certificate (if you use self-signed certificates), or click the Generate Certificate Request button to generate a new Certificate Request (if you use certificates signed by third-party companies such as VeriSign or GeoTrust). Ensure that you enter the new FQDN In the Server Name: text box.

    10. Note: For detailed information about generating certificates and certificate requests, refer to the FirePass online help on the Device Management: Configuration: Network Configuration: Web Services page.

  10. Install the new certificate on the FirePass controller, and note the filenames of the public and private keys.

    For example:

    cert1.pem, key1.pem

    Note: For detailed information about installing certificates, refer to the FirePass online help on the Device Management: Configuration: Network Configuration: Web Services page.

  11. Click the Web Services tab.
  12. Next to the Web Service you want to configure, click the Configure link.
  13. Depending on whether the Hostname text box contains the old FQDN, perform one of the following two procedures:

    14. The Hostname text box contains the old FQDN

    a. Enter the new FQDN in the Hostname text box.

    b. If the Use SSL check box is selected, select the new certificate installed in Step 10 from the Certificate drop-down menu.

    For example:

    cert1.pem, key1.pem

    Note: If you are unsure which certificate to choose, click the Web Services tab and then click the Configure SSL Certificates >> link. Locate the certificate that contains the new FQDN in the Common Name column. The Filenames column for that certificate contains the option you should select in the Certificate drop-down menu.

    c. If the Use SSL check box is cleared, and the old FQDN is listed in the HTTPS URL to redirect to text box, enter the new FQDN in the HTTPS URL to redirect to text box.

    d. Click the Update button.

    The Hostname text box does not contain the old FQDN

    a. If the Use SSL check box is cleared, and the old FQDN is listed in the HTTPS URL to redirect to text box, enter the new FQDN in the HTTPS URL to redirect to text box.

    b. Click the Update button.

  14. Click the Web Services tab to return to the Web Services main page.
  15. Repeat Steps 12 through 15 for each Web Service.
  16. Click the Finalize tab.
  17. Click the Finalize Changes button.
  18. Click the Apply Changes and Restart button.
  19. Click the Restart button to restart the FirePass controller.
