K000137068: When using ts_cookie_add_attrs to append to TS Cookies, it is a raw concatenation requiring semi-colons to be inserted where needed.

Published

  • BIG-IP ASM: 16.0.0, 16.0.X, 16.0.1, 16.X.X, 17.X.X, 15.1.10, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0

Description

When using the internal parameter ts_cookie_add_attrs to append a string to TS cookies, the string will be concatenated as-is and without any regards for syntax or interpretation. As a result, when using the parameter to insert the SameSite or Secure flags to a cookie, semicolons will need to be inserted as well for the cookie to be properly formatted.


Environment

  • BIG-IP with traffic that generates TS Cookies generated via a Security Policy or other security features
  • Using the internal parameter ts_cookie_add_attrs to append a string to the TS cookies

Cause

The internal parameter ts_cookie_add_attrs is documented in ID 875909. However, it can be confusing as to the behavior of this parameter. The value for the string to be appended is appended directly and without any regard for proper cookie syntax.

 

Recommended Actions

To append a SameSite and secure string to the end of the TS cookies, use the following command:


/usr/share/ts/bin/add_del_internal add ts_cookie_add_attrs ";SameSite=None;secure"
