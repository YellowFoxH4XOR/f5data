K000150797: Fastl4 virtual server intermittent issues after upgrade to version 17.1 for AFM provisioned systems

Type
Support Solution
Published
2025-04-10
Updated
2025-05-16
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.1.X, 17.1.2, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000150797

Description

After upgrading a bigip to version 17.1, fastl4 virtual servers can experience intermittent traffic issue. This behavior is observed with systems provisioned with AFM and is related to the new attack vectors that have been introduced.

Environment

  • AFM
  • fastl4 with ePVA

Cause

The behavior is tracked by Bug ID 1691505 and Bug ID 1671149.

Recommended Actions

To workaround this issue one of the the following actions can be taken:

  • Upgrade to version 17.5.0 where this bug ID is resolved.
  • Disable ePVA acceleration for the fastl4 profile in v17.1
  • Disable the (TS) attack vector and Timestamp Cookie inside the vector options menu.
