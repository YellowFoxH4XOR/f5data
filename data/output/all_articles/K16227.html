Known Issue

Description

The BIG-IP system does not update new time zone changes for the Traffic Management Microkernel (TMM) log messages.

This issue occurs when the following condition is met:

  • You change the time zone settings of the BIG-IP system.

After you change the BIG-IP system time zone, the new time zone changes may not update for TMM log messages. The TMM logs may have incorrect timestamps. However, BIG-IP LTM logs under the /var/log/ltm file update correctly with new timestamps.

Impact

The TMM logs have incorrect timestamps after you change the time zone.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you change the BIG-IP system time zone, the TMM log timestamps do not update to the new time zone.

Workaround

To work around this issue, you can restart the TMM process from the Traffic Management Shell (tmsh). To do so, perform the following procedure:

Impact of workaround: The BIG-IP system goes offline and temporarily stops processing traffic. You should perform this procedure while the BIG-IP system is in a standby state or during a maintenance window.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. To restart the TMM process, type the following command:

    restart sys service tmm
