Topic

This article discusses BIG-IP APM and BIG-IP GTM client redirection support.

Description

You can combine the BIG-IP GTM and BIG-IP APM systems to provide high availability and secure remote access to corporate resources from anywhere in the world. Using the BIG-IP APM and BIG-IP GTM solution, the BIG-IP GTM system intelligently directs access request traffic to the closest configured and available BIG-IP APM deployment. The BIG-IP APM system redirects the client from a global fully-qualified domain name (FQDN) (vpn.example.com) to a local FQDN (chicago.vpn.example.com) using an HTTP 302 redirect response. The redirected request then establishes a secure session with the local BIG-IP APM system. You can select the BIG-IP APM destination using topology or high availability. For more information, refer to the F5 BIG-IP GTM with APM for Global Remote Access deployment guide.
