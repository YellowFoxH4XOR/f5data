K000133640: [F5OS] In management interface configuration disabling IPv6 by selecting IPv4 only is not taking effect.

Type
Support Solution
Published
2023-04-28
Updated
2023-04-28
Applies to
  • F5OS
  • rSeries Platforms
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000133640

Description

In management interface configuration disabling IPv6 by selecting IPv4 only is not taking effect. After refreshing options, configurations is back to IPv4 & IPv6.

Environment

  • F5OS-A v1.3.x
  • F5OS-C v1.3.x-1.5.x
  • GUI: Management Interface > Management IP Addresses > Address

Cause

  • Bug ID 1211777
NOTE: This bug tracker may say affect only F5OS-A, but it affect F5OS-C

Recommended Actions

Please leave Management Interface > Management IP Addresses > Address with the value: IPv4 & IPv6
