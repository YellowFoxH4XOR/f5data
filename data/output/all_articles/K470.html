K470: Using IP forwarding in combination with NAT to allow IP protocols other than TCP and UDP

Topic

If a NAT exists for a node, and IP forwarding is enabled, clients could attempt to access the node by its actual IP address; however, when the node replies to the client, the reply traffic would be handled by the NAT. This action will break communications between the client and the node.

Note: In BIG-IP 4.0.0 and later, F5 recommends that you use forwarding virtual servers or forwarding pools, rather than IP forwarding.

In BIG-IP 4.2.0 and later you, can achieve the same results as the combination of a NAT and IP forwarding by using a virtual server and a SNAT, and enabling the any_ip setting.
