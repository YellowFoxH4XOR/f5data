Description
When logging to the device's CLI you see the following error messages being broadcasted:

hostname kernel: mce: [Hardware Error]: PROCESSOR 0:306e4 TIME 1604491201 SOCKET 0 APIC 0 microcode 424
hostname kernel: mce: [Hardware Error]: CPU 0: Machine Check: 0 Bank 7: cc00020000010093
hostname kernel: mce: [Hardware Error]: TSC 0 ADDR 1ae73afc0 MISC 24401a9a86
hostname kernel: mce: [Hardware Error]: PROCESSOR 0:306e4 TIME 1604491201 SOCKET 0 APIC 0 microcode 424

Environment

  • VIPRION
  • Blade

Cause

Unknown at the time of publication

Recommended Actions

  1. Reboot the vCMP host by following the instructions in article K44259537
  2. If reboot doesn't work, collect a EUD test from the affected blade. Follow the instruction in article K7172
  3. Open a new service request with the F5 support team and provide the results of the EUD test
