K000140627: How to Upgrade VELOS Chassis Partition Using WebUI

Type
Support Solution
Published
2024-08-08
Updated
2024-08-08
Applies to
  • F5OS
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000140627

Description

You are attempting to perform a rolling upgrade on a chassis partition using the system controller webUI. This process involves upgrading one blade at a time within a chassis partition, which might cause an outage on any running tenants. Once the installation is successful on the initial blade, the remaining blades in the chassis partition will be updated. During this process, if the upgrade fails, the system will revert to the last working software version.

Environment

• VELOS Chassis F5OS

Cause

Performing a rolling upgrade on a chassis partition where each blade is upgraded sequentially.

Recommended Actions

  1. Log in to the VELOS system controller webUI using an account with admin access.
  2. On the left, click CHASSIS PARTITIONS.
    1. The Chassis Partitions screen opens.
  3. In the Partition list, select the chassis partition that you want to upgrade.
  4. Click Edit.
  5. Select an installation type:
    • Choose Bundled to install an ISO image.
    • Choose Unbundled to install a base OS version and service version independently.
  6. In the Partition Image section, select the software image version (or versions if performing an unbundled upgrade).

  7. Click Save.
