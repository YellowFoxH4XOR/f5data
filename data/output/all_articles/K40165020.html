Description

Configuration fails to load after upgrading to device from olde versions to 14.x or later (can happen in case of 13.x as well). The output of 'tmsh load sys config verify' will show below error:

01071008:3: Provisioning failed with error 1 - 'Memory limit exceeded. <#> MB are required to provision these modules, but only <#> MB are available.' . Unexpected Error: Loading configuration process failed
 

Environment

  • AAM is provisioned
  • Upgraded device to major release from older versions like 12.x or 11.x 
     

Cause

Insufficient disk space or memory allocated.
 

Recommended Actions

  1. Roll back to older version and check modules provisioned. 
     
  2. Deprovison the unsed modules. 
     
  3. Deprovision AAM (Application Acceleration Manager ) module. K70113407: End of Software Development for BIG-IP AAM
    Note: Before deprovisioning the AAM module, remove the AAM profile from the respective Virtual Servers if any. 
     
  4. Once module is deprovisioned, upgrade to desired version.
