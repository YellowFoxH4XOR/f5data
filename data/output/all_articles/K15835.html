Known Issue

Loading a user configuration set (UCS) may fail if UCS uses Secure Vault for encryption.

This issue occurs when the following condition is met:

  • You load the UCS archive on a BIG-IP system that is not the originating system of the UCS archive.

Impact

The UCS archive fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H490182 on the Diagnostics > Identified > High screen.
  • The system logs error messages to the /var/log/ltm file that appear similar to the following example:

    err tmsh[7676]: 01420006:3: Loading configuration process failed.
    err load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all" - failed. -- Loading system configuration...

    01071769:3: Decryption of the field (secret) for object (/Common/secure_site) failed. Unexpected Error: Loading configuration process failed.
