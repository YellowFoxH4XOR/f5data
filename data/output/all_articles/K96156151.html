Known Issue

The gtm_add script may produce error messages and prevent the BIG-IP LTM configuration from loading.

This issue occurs when all of the following conditions are met:

  • You run the gtm_add script to add a BIG-IP GTM system to a sync group.
  • The system master keys for each BIG-IP GTM system do not match.

Impact

When rebooting the BIG-IP system or restarting services, the system is unable to load the configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The first time you run the gtm_add script, no errors are reported at the console, but the master key for the GTM device that you are adding is not updated.
  • If you run the gtm_add script a second time, you observe the following messages:

    Error trying to rekey: 01071769:3: Decryption of the field (secret) for object (/Common/sctp) failed.
    Cannot set local master key.

  • In the /var/log/ltm file, you observe messages similar to the following example:

    err mcpd[]: 0107102b:3: Master Key decrypt failure - decrypt failure - final
    notice mcpd[]: 01071029:5: Master decrypt final
    notice mcpd[]: 01071027:5: Master key OpenSSL error: 1519594440:error:06065064:digital envelope routines:EVP_DecryptFinal_ex:bad decrypt:evp_enc.c:601:
    err mcpd[]: 01071769:3: Decryption of the field (secret) for object (/Common/sctp) failed.
