K000132880: Observed high CPU spikes every 5 days

Type
Support Solution
Published
2023-03-07
Updated
2023-03-07
Status
Final
Source
https://my.f5.com/manage/s/article/K000132880

Description

  • High CPU spike every 5 days around the same time of the day.
  • Java causing the CPU spike
  • On /var/log/restjavad.0.log you can see executions of \"/cm/autodeploy/software-images\" matching the periods of CPU spikes.

[WARNING][496462][27 Feb 2023 04:01:38 UTC][8100/cm/autodeploy/software-images SoftwareImageWorker] Failure updating software image list: java.util.concurrent.TimeoutException: remoteSender:http://localhost:8100/cm/autodeploy/software-images, method:PUT

Environment

  • BIG-IP device not managed by BIG-IQ
  • LTM
  • Restjavad

Cause

Stuck BIG-IQ related API request task.

Recommended Actions

To clear the stuck task, please clear the REST data on BIG-IP device.

  1.  Connect to BIG-IP CLI
  2.  Run
clear-rest-storage

Additional Information

None
