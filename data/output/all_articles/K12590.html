Topic

You can create custom protected configurations and pre-logon sequences, which allow you to set or evaluate a session variable. You can use the assignment operator ( = ) to change the value of a session variable within protected configurations or a pre-logon sequence, or the comparison operator ( == ) to evaluate the existing value. Changes to the session variable using the assignment operator will only affect the scope of protected configurations or a pre-logon sequence in which the session variable was assigned a value. By using the assignment operator, subsequent rules that use the session variable will use the value that was set by that protected configuration. If you use the comparison operator instead of the assignment operator, the value of the session variable will be evaluated rather than changed. You should use the comparison operator when you want to determine if the value of a session variable meets certain criteria. You should use the assignment operator to change the value of the session variable.

For example, if the Alpha, Bravo, and Charlie protected configurations use the session.example.variable session variable and Alpha and Charlie use the comparison operator, but Bravo uses the assignment operator, Alpha will set the initial value. However, Bravo has the ability to change the value, and Charlie will use the value that Bravo sets. Using the assignment operator can be useful when you want a specific expression's value to supersede subsequent rules.

Protected ConfigurationExpression in a RuleEvaluates toResult
Alphasession.example.variable==monkeysTruesession.example.variable has the value monkey
Bravosession.example.variable=robotsTruesession.example.variable has the value robots
Charliesession.example.variable==baconFalsesession.example.variable still has the value robots

In the above table, the first protected configuration, Alpha, sets the value to monkeys and determines that the expression is true. The next rule processed is Bravo. Because Bravo uses an assignment operator, rather than a comparison operator, Bravo sets the value of the variable to robots and also determines that the expression is true. The final protected configuration is Charlie. Charlie identifies the robots value that was set by Bravo. Because Charlie is using a comparison operator, it determines that the value does not match its criteria of bacon and will determine that the expression is false.

Note: In FirePass versions prior to 6.0.0, the assignment operator behaves the same as the comparison operator and can be used interchangeably. If you upgrade from FirePass version 6.0.0 or earlier to version 6.0.1 or later, the syntax used in the earlier version will be carried over and you may need to manually change the assignment operator to the comparison operator if you want to inspect the existing value rather than set it.
