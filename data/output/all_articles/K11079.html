Known Issue

This is the result of a known issue. After installing OPSWAT versions 3.4.4 through 3.4.8 , the Windows antivirus checker no longer detects Kaspersky Anti-Virus 2010 (version 9.x) on Windows Vista or Windows 7 clients. For other versions of Windows, such as Windows XP, the Windows antivirus checker detects the software, but cannot detect extended attributes, such as engine version or database age. As a result, clients running Kaspersky Anti-Virus 2010 may fail the antivirus check.

Note: OPSWAT 3.4.3 is not affected by this issue. Additionally, this issue was resolved starting in OPSWAT 3.4.9.

The FirePass Windows antivirus checker uses software libraries from a software development kit (SDK) created by OPSWAT. OPSWAT provides a vendor-independent framework for endpoint security management. OPSWAT is aware of the issue described in this Solution and is working on a resolution. Once a resolution is available from OPSWAT, F5 Networks will issue a hotfix to address this issue.

F5 Product Development tracked this issue as ID 331758 (formerly CR135954) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in OPSWAT version 3.4.9 in hotfix-137605-1 for FirePass versions 6.1.0, 6.0.3, 5.5.2, 5.5.1 and 5.5. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
