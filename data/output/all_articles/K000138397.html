Description

Difference in connections statistics between Virtual server and Pool/Pool members when checked at below path in GUI.


Statistics ›› Module Statistics : Local Traffic ›› Virtual Addresses OR Virtual Servers


Statistics ›› Module Statistics : Local Traffic ›› Pools


Environment

  • BIG-IP LTM
  • Virtual Server
  • Pool
  • Pool member

Cause

This is expected behavior.


Virtual server count will be always higher than the server side because Virtual server reuses the existing connections of server side for new client connections.


Also not all client side connections will go to the server side when Virtual server responds back to client connections from its cache.


Recommended Actions

None.
