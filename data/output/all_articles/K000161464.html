K000161464: How to Disable TCP Keepalives in NGINX Plus for Specific Upstreams

Description

  • Following a product change in behavior, NGINX Plus enables keepalives by default to configured upstream after version R37.
  • You wish to know on how to explicitly disable TCP keepalive connections for specific web applications in NGINX Plus.

Environment

  • NGINX Plus
  • Upstream
  • HTTP/1.1 connections
  • keepalive Directive 

Cause

  • The default enablement of keepalive connections for upstream HTTP/1.1 in NGINX Plus R37, which led for explicit requirement to disable this behavior for specific web applications.

Answer/Recommended Actions

  • Setting keepalive 0 in the upstream block disables keepalive connections as per official documentation.
  • To disable keepalive connections for specific upstreams, add keepalive 0; within the relevant upstream block in nginx.conf. Example:
			upstream backend {
			    server 192.168.1.1 ;
			    server 192.168.1.2 ;

			    keepalive 0;
			}

Additional Information

  • NGINX documentation -
    • keepalive directive – "The zero value disables keepalive connections to upstream servers"
