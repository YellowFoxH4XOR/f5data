Description

Some third-party software requires a domain attribute in a cookie from BIG-IP.  You should consider using this procedure under the following condition:

  • You have a requirement for a domain attribute in the BIG-IP persistence cookie.
  • That domain needs to be other than the direct host name in the uri.  (For example. the host name is ab.def.com, but you need the domain attribute to reflect def.com rather than the lower level sub-domain)

Environment

  • BIG-IP LTM
  • Cookie Persistence profile

Cause

None

Recommended Actions

You can add a domain attribute and specify its value with the steps:

Configure a custom cookie persistence profile with a static name:
  1. Navigate to Local Traffic --> Virtual Servers --> Profiles --> Persistence and click the Create button
  2. Give your custom profile a name (i.e. BIG_IP_Domain_Cookie) and select "Persistence Type: Cookie"
  3. Select the Custom checkbox to the far right of "Cookie Name" and provide a desired name for your cookie. (i.e. Domain_Cookie).
  4. Click on Finished to save your custom profile.
Configure a iRule to add the domain attribute to the cookie and apply the cookie and iRule to virtual server
  1. Create a iRule to apply the domain attribute to the persistence cookie by navigating to Local Traffic --> Virtual Servers --> iRules and click the Create button.
  2. Name your iRule something meaningful to you. (i.e. Add_Domain_to_Cookie)
  3. Add the following text to the iRule Definition<
    when HTTP_RESPONSE { if {[HTTP::cookie exists "<<cookie name>>"]} { # set the domain attribute as the cookie does not have one by default HTTP::cookie domain "<<cookie name>>" "domain name"  } }

    Where <<cookie name>> is the name you configured in Step 3 of configuring the cookie and <<domain name>> is the domain name you need.

  4. Select or create the virtual server that needs this cookie.  
  5. If the virtual server was already created, click on the "Resources" tab for the virtual server.
  6. Under "Default Persistence Profile" select the custom persistence profile you created earlier.
  7. Beside iRules, select the "Manage..." button and select the iRule you just created from the "Available" list of iRules.
  8. Click the << button to apply the iRule to the virtual server and click "Finished"
