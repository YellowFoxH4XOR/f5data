Description

When accessing the BIG-IP command line to make changes to the management interface via config command, the following error message is seen.

ERROR: route_mgmt_entry count is greater than 2:x

x represents the total number of management routes which has been configured. For example, if you have 8 management route configured, the error message is:

ERROR: route_mgmt_entry count is greater than 2:8

Environment

  • BIG-IP command line
  • Running config command
  • Error message when accessing config: ERROR: route_mgmt_entry count is greater than 2:x

Cause

The issue is related to bug ID933737. You are not able to proceed with config tool when you have management routes.

Recommended Actions

The workaround to the issue is to remove all existing management route, make changes in config tool and re-add the management routes.

  1. Login to the BIG-IP Command line.
     
  2. Show all the management routes with the following command:
    tmsh list /sys management-route
     
  3. Copy the management routes to a notepad for reference.
     
  4. Delete all management route except for default. Use the following command to delete the management route one at a time.
    tmsh delete /sys management-route <name>

    If the management route name is example-route, the command would be:
    tmsh delete /sys management-route example-route
     
  5. Once all the management route has been delete (leaving default route) access the config tool with command:
    config
     
  6. Make the changes needed in the config tool.
     
  7. Once the changes has been done, re-add the deleted management route with the following command:
    tmsh create /sys management-route <name> network <destination network>/<netmask> gateway <management gateway>

    If the management route name is example-route, the destination network is 10.10.10.0/24 and the gateway is 10.1.1.1 the command would be:
    tmsh create /sys management-route example-route network 10.10.10.0/24 gateway 10.1.1.1
     
  8. Save the changes:
    tmsh save /sys config
