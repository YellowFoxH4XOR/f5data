Description

The F5 VIPRION platform provides flexibility and configurability by allowing you to install or remove blades from the chassis as needed. However, installing different blade types in some types of chassis is not supported for traffic processing, while installing different blade types in other types of chassis is not recommended for performance reasons. The following table provides the details:

Chassis typeSupport for mixed blade types
VIPRION C4800Mixing blade types in this chassis may potentially limit the performance of the higher spec blade type to that of the lower spec blade type installed. F5 recommends that for maximum performance you do not mix blade types in this chassis. This chassis supports up to eight B4300 or B4400 series blades.
VIPRION C4480Mixing blade types in this chassis may potentially limit the performance of the higher spec blade type to that of the lower spec blade type installed. F5 recommends that for maximum performance you do not mix blade types in this chassis. This chassis supports up to four B4200, B4300, or B4400 series blades.
VIPRION C4400Mixing blade types in this chassis may potentially limit the performance of the higher spec blade type to that of the lower spec blade type installed. F5 recommends that for maximum performance you do not mix blade types in this chassis. This chassis supports up to four B4100* or B4200 series blades.
VIPRION 2400F5 does not support mixing blade types in this chassis. However, you can migrate the configuration from a B2100 blade to a B2150/B2250 blade within the same chassis by performing the procedures described in the VIPRION Systems: Blade Migration guide. This chassis supports up to four B2000 series blades.
VIPRION 2200F5 does not support mixing blade types in this chassis. However, you can migrate the configuration from a B2100 blade to a B2150/B2250 blade within the same chassis by performing the procedures described in the VIPRION Systems: Blade Migration guide. This chassis supports up to two B2000 series blades.

* The VIPRION B4100 blade has reached its Platform End of Technical Support (EoTS) on June 30, 2019.
