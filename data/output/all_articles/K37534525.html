Description

Hyper-V Azure Big-IP VE experiencing packet loss and latency

  • /proc/unic shows tx_errcnt increasing
  • at boot dmesg log: hv_netvsc vmbus_17 (unregistered net_device): timeout before we got a set response....
  • command 'ethtool -l eth0' output reports 'Combined: 1' on the last line of output.

Environment

  • Big-IP VE in Azure Cloud or Hyper-V

Cause

This condition occurs when a timeout occurs while booting, resulting in the NIC driver not getting necessary information from Hyper-V host hypervisor.

Recommended Actions

Rebooting the BIG-IP VE may clear the condition if the hypervisor load has reduced.
