Issue

Error Message

info sdmd[<PID>]: 018e0017:6: pid[<PID2>] plugin[<PathtoiRule>] <Informational Message>

In this error message, note the following:

  • <PID> is the process ID for the sdmd process.
  • <PID2> is the process ID for the iRules LX API plug-in process.
  • <PathtoiRule> is the path to the iRule location. The default partition is /Common.
  • <Informational Message> describes what the API plug-in is performing or encountering or provides the current status.

For example:

info sdmd[5544]: 018e0017:6: pid[23235] plugin[/Common/TestiRulesLX] Creating TestiRulesLX Transaction for userId[TestUser1].

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file

    Note: This is the default location.

  • The /var/log/ilx file

    Note: The file appears here when the ILX plug-in extension is configured with ilxLogging enabled.

Description

This message occurs when the following condition is met:

  • An iRules LX Node.js plug-in process writes to stdout using the Node.js console.log() API.

Impact

The impact is defined by the user.

Recommended Actions

None
