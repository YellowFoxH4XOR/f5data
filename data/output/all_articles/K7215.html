Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K15582: Configuring multiple default routes on the BIG-IP system (11.x)

The BIG-IP system has the ability to configure multiple default gateways. Configuring multiple default gateways for the BIG-IP allows the flow of traffic to continue even if one of the gateway routers is unable to pass traffic.

To configure multiple default gateways on the BIG-IP, you must configure a default gateway pool that contains the IP addresses of the routers that the BIG-IP system will use as gateways, including a gateway monitor, then configure that pool as the default gateway pool for the BIG-IP system.

Configuring the gateway monitor

First, create a transparent gateway ICMP monitor using the procedure detailed in K8971: Creating transparent ICMP health monitors.

Note: Refer to the transparent gateway ICMP monitors section.

Configuring the default gateway pool

To configure the default gateway pool that contains the IP addresses of the routers that the BIG-IP system will use as gateways, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Pools.
  4. Click Create.
  5. Type a name for the pool, such as Default_GW_Pool.
  6. From the Health Monitors section, select the transparent gateway ICMP monitor you created above and move it to the Active window.
  7. Select a load balancing method for the pool.
  8. In the Address field, type the IP address of one of the default gateway addresses.
  9. From the Port drop-down menu, select * All Services.
  10. Click Add to add the default gateway to the New Members field.
  11. Repeat Step 8 through 10 for each default gateway address.
  12. Click Finished.

Configuring the pool as the default gateway for the BIG-IP system

To assign the pool you created as the default gateway for the BIG-IP system, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Click Network.
  3. Click Routes.
  4. Click Add.
  5. From the Type drop-down menu, select Default Gateway.
  6. From the Resource drop-down menu, select Use Pool.
  7. Choose the default gateway pool you created in the previous procedure.
  8. Click Finished.
