Description

TMM crashes and generates core file with the following error log in the /var/log/tmm log:

notice panic: ../dev/mpi/mpi_mem.c:1129: Assertion "tail not past head" failed.
notice ** SIGFPE **

Environment

  • Affecting versions 15.1.0 and below
  • BIG-IP processing MRF traffic
  • TMM Core with SIGFPE signal

Cause

Message Routing Framework (MRF) traffic of type Diameter and SIP. Auto-initialization enabled on peer, but can happen without auto-initialization enabled, just at a less-predictable rate.

This issue is tracked with Bug ID 868781: TMM crashes while processing MRF traffic.

Recommended Actions

Upgrade to version 15.1.1 or above.

Note: If you prefer to stay on the same version, open a case with support to evaluate the possibility to get an Engineering Hot Fix (EHF) for your version.
