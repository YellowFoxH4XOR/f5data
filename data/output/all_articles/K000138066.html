K000138066: BIG-IQ not able generate QKview file

Type
Support Solution
Published
2023-12-28
Updated
2023-12-28
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0, 8.2.0, 8.1.X, 8.0.X, 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.1.0
Source
https://my.f5.com/manage/s/article/K000138066

Description

BIG-IQ unable to generate qkview with the following error generated in CLI:
mkdir: cannot create directory '/var/tmp/restjavad_logs': File exists
mkdir: cannot create directory '/var/tmp/bigiqdiags': File exists
 

Environment

  • BIG-IQ
  • qkview
  • CLI

Cause

File already exists under /var/tmp
 

Recommended Actions

1. On BIG-IQ CLI bash, use the following command to verify the error:
qkview -v

2. The following errors are spotted from the CLI:

Gathering System Diagnostics: Please wait ...
Loading Postgres configuration from /var/config/rest/service.config.json...
Postgres configuration successfully loaded!
Checking PostgreSQL availability...
PostgreSQL is ready to accept connections.
Performing BIG-IQ database backup to /var/tmp/storage_binary_dump/bigiq_db_dump.bin...
BIG-IQ database backup successful.
mkdir: cannot create directory '/var/tmp/restjavad_logs': File exists
mkdir: cannot create directory '/var/tmp/bigiqdiags': File exists

3. Remove the conflict directories with the following commands in CLI:
rm -rf /var/tmp/restjavad_logs
rm -rf /var/tmp/bigiqdiags
