Description

You want to know the equivalent protocol based on the INTEGER value from the snmpwalk command.

For the example:

[root@LB_A:Active:In Sync] config # snmpwalk -v2c -c public 127.0.0.1 F5-BIGIP-LOCAL-MIB::ltmVirtualServIpProto
F5-BIGIP-LOCAL-MIB::ltmVirtualServIpProto."/Common/Test_TCP" = INTEGER: 6
F5-BIGIP-LOCAL-MIB::ltmVirtualServIpProto."/Common/Test_UDP" = INTEGER: 17

Environment

  • BIG-IP
  • SNMP service
  • Virtual Server's IP protocol is configured on the device

Cause

None.

Recommended Actions

  1. We can check through the F5 SNMP MIB files, refer to the K13322. 

    For the example, from the above MIB (ltmVirtualServIpProto). The object information is located in the file F5-BIGIP-LOCAL-MIB.

    ltmVirtualServIpProto OBJECT-TYPE
        SYNTAX INTEGER
        MAX-ACCESS read-only
        STATUS current
        DESCRIPTION
            "The IP protocol (see RFC 1340) used by the specified virtual server."
        ::= { ltmVirtualServEntry 7 }

  2. Check further on the RFC 1340 site (page 6), mentioned about protocol types.

    Note: This link takes you to a resource outside of AskF5. The third-party could remove the document without our knowledge.
