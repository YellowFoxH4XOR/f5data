Issue

Error Message

err mcpd[<PID>]: 0107147f:3: Could not read certificate file (<certificate_file>)

In this error message, note the following:

  • <PID> is the process ID.
  • <certificate_file> is the certificate file.

For example:

err mcpd[7377]: 0107147f:3: Could not read certificate file (/Common/SSL_CA_v1.crt)

Message Location

You may encounter this message in the following locations:

  • The Configuration utility
  • The TMOS Shell (tmsh)
Description

This message occurs when the following condition is met:

  • You attempt to sign for read-only scripts, such as iRule, CLI, APL, or App template scripts, with a certificate that cannot be read by the BIG-IP system.

Impact

You cannot sign scripts on the BIG-IP system.

Recommended Actions

F5 recommends using a valid certificate when attempting to sign your scripts.

Note: F5 system certificates cannot be used to sign scripts.
