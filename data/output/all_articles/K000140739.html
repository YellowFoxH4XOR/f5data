Description

Software upgrade using regular upgrade method on 2 slot BIG-IP in Azure will not be reflected in Azure Dashboard in "Image reference/version" in "Virtual Machines/Settings/Operating system".

Environment

  • BIG-IP

  • Azure

Cause

Azure dashboard will not update software changes on BIG-IP in "Image reference".

Recommended Actions

This will not have any impact on your regular day to day actions, but it might have an impact if you are going to attempt redeploying your device in case your initial image was deprecated, as it will not be possible when source image is no longer available on Azure Marketplace.

If you would like you this information to be updated, you will need to redeploy BIG-IP using one of the newer releases as source image.

Additional Information

Before your initial image will be deprecated, you should receive an email with alert that it will be deprecated soon. Please check article in "Related content" for more details about this alerts.
