K8531: A webtop link has been added for i-mode clients

Topic

Starting in FirePass software version 6.0.2, when an NTT DoCoMo i-mode client accesses a Portal Access Web Application, a Back link and a Logout link appear at the bottom of the web page. Users can click the Back link to return to the FirePass webtop, or the Logout link to log out from FirePass.

In FirePass software versions 5.5.1, 5.5.2, 6.0.0, and 6.0.1, when an i-mode client accessed a Portal Access Web Application, only the Logout link appeared at the bottom of the web page.

In FirePass software version 5.5.0 and earlier, a Back to FirePass Webtop link appeared, but not a Logout link.

F5 Networks Product Development tracked this enhancement as CR72356, and it was added to FirePass software version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.
