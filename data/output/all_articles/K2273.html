Topic

After you install the 520/540 platform in the network and run the Setup utility, you can initialize the FIPS 140 hardware security module (HSM) to prepare the HSM for the Security World.

The FIPS standard is a set of requirements designed to facilitate the construction, measure the security of cryptographic modules, and define methods for protecting cryptographic keys from unauthorized access.

Once you have imported private keys into the FIPS Security World, you cannot export or decrypt the keys for use in a non-FIPS environment.
