Description

After creation/modification/deletion of multiple virtual severs the BIG-IP goes offline or fails over.

Log messages similar to the following are logged to /var/log/ltm:
notice sod[7876]: 01140045:5: HA reports tmm NOT ready.
notice sod[7876]: 010c0050:5: Sod requests links down.
info lacpd[8440]: 01160016:6: Failover event detected. (Switchboard failsafe disabled while offline)

A TMM core is file generated in /var/core at the time of the issue.
 

Environment

  • BIG-IP < v15.1.3
  • BIG-IP v16.x
  • Large configuration of objects
  • TMM core file in /var/core

Cause

Bug ID 945853

Recommended Actions

Upgrade to fixed software version.
