Viewing the Enterprise Manager version information using the Configuration utility

Enterprise Manager 2.0.0 or later

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click Configuration.
  4. Click Device.
  5. Click General.

    The Enterprise Manager version information is listed in the Version field.

Enterprise Manager 1.0.0 through 1.8.0

  1. Log in to the Configuration utility
  2. Click System.
  3. Click General Properties.

    The Enterprise Manager version information is listed in the Version field.

Viewing the Enterprise Manager version information using the command line

  1. Log in to the Enterprise Manager command line.
  2. View the Enterprise Manager software version information by typing the following command:

    bigpipe version | less
