Description

I want to create a support ticket with Distributed Cloud Console but am not sure how.

Environment

  • F5® Distributed Cloud (XC) Console

Cause

None

Answer/Recommended Actions

To create a support ticket via XC Console:

  1. Access Distributed Cloud Console
  2. Select Support from the configuration menu on the left
  3. Click on Create new support request in the New Support Request tile
  4. Select the question type for the What kind of question do you have? field
  5. Select the topic from the What is your question about? field
  6. Select the priority
  7. Enter a short subject for your problem in the Please choose a subject for your issue field
  8. Describe the problem in the Please explain the problem below field
    • Add the name and contact information of the person who owns the ticket
    • Accurate time, including the time zone, of the events
    • Precise description of the issue
    • Impact of the incident from your point of view
    • Additional information to help resolving the issue such as: Logs, error messages, screenshots, etc.
  9. Optionally include useful screenshots using the Add a screenshot option
  10. Click Send
