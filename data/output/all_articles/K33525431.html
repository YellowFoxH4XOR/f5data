Description

DNS configured with a caching profile does not respond with data residing in the local system's Zonerunner configuration.  
 

Environment

  • DNS
  • Local cache definition configured (Transparent or Resolver)
  • Custom DNS profile using that cache configuration

Cause

Because of the DNS order of precedence for query handling, the Cache configuration will be used before local BIND data. The caching profile configuration requires other nameservers to reference, and does not pull data in from the local nameserver by default.
 

Recommended Actions

Configure the DNS system to cache from the local BIND (Zonerunner) setup:

  1) Create a nameserver for localhost:  DNS >> Delivery >> Nameservers >> Nameserver List, add localhost 127.0.0.1 as a nameserver.

  2) Create a DNS Express zone: DNS >> Zones >> Zones >> Zone List, add "zone.example.com" and use the localhost nameserver
 
  Note: There are several other options on this configuration screen, but for most implementations there is no need to fill out the Allow Notify From or Zone Transfer Clients sections.
 
  3) Give the system a few seconds to populate the data from BIND, and then test from your remote desktop workstation again.
 
  Note: You can verify in /var/log/ltm that the zone transfer was successful. You should also see your zone data in the output of "dnsxdump".
