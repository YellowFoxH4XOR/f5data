K000157937: HTTP Load Balancer - Errors: http1.codec_error

Description

I want to use the F5® Distributed Cloud Load Balancers with RDP connections but when configuring an HTTP Load Balancer I get the following error: "http1.codec_error"

Environment

  • F5® Distributed Cloud

  • HTTP Load Balancer

Cause

The RDP application is missing/not sending the authority (host) header resulting in the packet being dropped on XC.

Recommended Actions

You have to configure a TCP Load Balancer on port 3389. 

Additional Information

If the application uses port 443 it is also recommended to configure both, an HTTP Load Balancer on port 443 and a TCP Load Balancer on port 3389
