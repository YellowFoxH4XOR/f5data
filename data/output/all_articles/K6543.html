Known Issue

This is the result of a known issue. Installing the big3d agent from a BIG-IP GTM running version 9.2.3 to a BIG-IP LTM running version 9.1.2 will cause the big3d installation to fail and display the following error message:

This BIG-IP version is not currently supported

The /usr/local/bin/big3d_install script file on the BIG-IP GTM version 9.2.3 system does not contain entries for BIG-IP LTM version 9.1.2, because BIG-IP version 9.1.2 was released after BIG-IP version 9.2.3.

This issue holds true for any instance where the BIG-IP GTM version was released prior to the version of the system receiving the big3d agent installation. For example, BIG-IP GTM versions 9.2.2 and 9.2.3 are not aware of the following versions that have been or could be released:

  • 4.5.14
  • 9.1.2
  • 9.2.4

The following entries in the my %matches section of the /usr/local/bin/big3d file indicate the supported versions by default for a version 9.2.3 system:

'4.2'           => $big3d_bsdi,'4.2-PTF01'     => $big3d_bsdi,'4.2-PTF02'     => $big3d_bsdi,'4.2-PTF03'     => $big3d_bsdi,'4.2-PTF04'     => $big3d_bsdi,'4.2-PTF05'     => $big3d_bsdi,'4.2PTF-06'     => $big3d_bsdi,'4.2PTF-07'     => $big3d_bsdi,'4.2PTF-08'     => $big3d_bsdi,'4.2PTF-09'     => $big3d_bsdi,'4.2PTF-10'     => $big3d_bsdi,'4.5'           => $big3d_bsdi,'4.5PTF-01'     => $big3d_bsdi,'4.5PTF-02'     => $big3d_bsdi,'4.5PTF-03'     => $big3d_bsdi,'4.5PTF-04'     => $big3d_bsdi,'4.5PTF-05'     => $big3d_bsdi,'4.5PTF-06'     => $big3d_bsdi,'4.5PTF-07'     => $big3d_bsdi,'4.5PTF-08'     => $big3d_bsdi,'4.5.9'         => $big3d_bsdi,'4.5.10'        => $big3d_bsdi,'4.5.11'        => $big3d_bsdi,'4.5.12'        => $big3d_bsdi,'4.5.13'        => $big3d_bsdi,'4.6'           => $big3d_bsdi,'4.6.1'         => $big3d_bsdi,'4.6.2'         => $big3d_bsdi,'4.6.3'         => $big3d_bsdi,'4.6.4'         => $big3d_bsdi,'9.0.5'         => $big3d_path,'9.1.0'         => $big3d_path,'9.1.1'         => $big3d_path,'9.2.0'         => $big3d_path,'9.2.2'         => $big3d_path,

If you are installing big3d onto a version of the system that is not listed, you must add the desired version using the procedure detailed in the Workaround section.

Important: Hotfixes for BIG-IP LTM version 9.1.2 will affect how the version is reported. Therefore, the /usr/local/bin/big3d_install script file will need to be updated to include entries for BIG-IP LTM version 9.1.2 hotfixes.

F5 Product Development tracked this issue as CR60562 and CR67982 and it was fixed in BIG-IP version 9.3.0. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller release notes.

Workaround

You can work around this issue by modifying the /usr/local/bin/big3d_install script file on the BIG-IP GTM to include entries for the required versions.

To modify the /usr/local/bin/big3d_install script file, perform the following procedure:

  1. Log in to the BIG-IP GTM command line.
  2. Change directories to the /usr/local/bin directory by typing the following command:

    cd /usr/local/bin

  3. Back up the original big3d_install script file by typing the following command:

    cp big3d_install big3d_install.sol6543

  4. Using a text editor, edit the big3d installation file.
  5. Add the desired entries to the my %matches section.

    For example:

    '4.5.14'        => $big3d_bsdi,'9.1.2'         => $big3d_path,'9.1.2 HF1'     => $big3d_path,'9.1.2 HF2'     => $big3d_path,'9.1.2 HF3'     => $big3d_path,'9.2.3'         => $big3d_path,
  6. Save the big3d_install file.

You may now install the big3d agent from the BIG-IP GTM system to the desired BIG-IP system.
