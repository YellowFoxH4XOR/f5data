Known Issue

This is the result of a known issue. The SharePoint Explorer View window may not display properly through a BIG-IP WebAccelerator virtual server for Microsoft Vista or Windows 7 clients.

Instead of displaying an Explorer View window, the browser may display an error message that appears similar to the following example:

Internet Explorer cannot display the webpage

This issue occurs when the BIG-IP WebAccelerator sends a FIN packet in response to the SharePoint server's HTTP 401 Unauthorized response. When this occurs, the Windows webclient service may not request or pass the correct information to the SharePoint server.

F5 Product Development is tracking this issue as CR134822 and ID 327796.

This issue does not affect the BIG-IP WebAccelerator 10.x software branch.

Note: This issue may also cause NTLM authentication to fail with certain web browsers such as Chrome. For more information, refer to K11202: NTLM authentication fails with some browsers.
