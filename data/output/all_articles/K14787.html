Known Issue

Gateway failsafe pools may not be correctly removed.

This issue occurs when the following conditions are met:

  • You use the Configuration utility to remove a gateway failsafe pool.
  • You have one or more systems in a device group.

Impact

The BIG-IP system continues to use the gateway failsafe pool.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H435083 on the Diagnostics > Identified > Medium screen.
  • The Configuration utility does not display the gateway failsafe pool as configured.
  • The tmsh utility shows the gateway-failsafe-device designation as part of the pool properties.

    For example, the following command output shows that the gateway-failsafe-device designation appears before the device name:

    tmsh list /ltm pool Pool-3

    ltm pool Pool-3 {
    gateway-failsafe-device BIGIP-1.local
    members {
    pool_member-1:any {
    address 10.11.1.1
    }
    }
    monitor gateway_icmp
    }

Workaround

To work around this issue, use the tmsh utility to disable the gateway failsafe pool. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command

    tmsh

  2. Type the following command to disable a gateway failsafe from a pool:

    modify ltm pool <pool_name> gateway-failsafe-device none

    In the previous command syntax, note the following:

    • <pool_name> is the name of the BIG-IP pool configured as a gateway failsafe.
  3. Save the change by typing the following command:

    save /sys config
