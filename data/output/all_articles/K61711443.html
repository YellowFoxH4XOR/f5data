Known Issue

The system does not update HTTP profile statistics when you use the HTTP::respond iRule command.

This issue occurs when the following condition is met:

  • An iRule uses the HTTP::respond command to respond to a request.

Impact

Responses generated by the HTTP::respond iRule command are not included in the HTTP profile statistics.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system reports incorrect statistics for virtual servers that use iRules with the HTTP::respond command.
