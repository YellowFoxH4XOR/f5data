Environment

  • BIG-IQ CM and DCD Cluster
  • Elasticsearch commands throws 401 Unauthorized
  • Missing ANONYMOUS group in ES config

Cause

The root-cause how cluster went into thats state is currently unknown. F5 is tracking this issue under:

Bug 1397197 – Elasticsearch API returns 401 Unauthorized when username and password are not specified

Recommended Actions

As workaround please specify -u admin:admin when using curl commands for elasticsearch outputs for example:

curl -sk https://localhost:9200/ -u admin:admin
