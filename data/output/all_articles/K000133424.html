K000133424: Error installing EHF "No base image installed or compatible volume to install the Hotfix"

Type
Support Solution
Published
2023-04-26
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4, 14.1.5
Source
https://my.f5.com/manage/s/article/K000133424

Description

Facing issue when installing the EHF on Viprion BIG-IP GUI, and prompted with error message as below:

 "No base image installed or compatible volume to install the Hotfix"

 

Environment

  • BIG-IP
  • Viprion
  • vCMP
  • Guest
  • Upgrade
  • EHF

Cause

Missing base image installer in the vCMP guest which is required together with EHF instead of getting from the vCMP HOST

Recommended Actions

There are two options available as listed below:

  • Copy both base image and EHF image file onto the vCMP guest "/shared/images" folder
OR 
  • workaround the issue by initiate EHF installation via TMOS command
# tmsh install sys software hotfix <image_file.iso> volume <inactive_volume_location>
