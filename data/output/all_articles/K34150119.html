Topic

You should consider using this procedure under the following conditions:

  • Your BIG-IP is licensed and provisioned with the BIG-IP APM module.
  • You want to restrict access to a virtual server using Terminal Access Controller Access-Control System Plus (TACACS+) authentication.

Description

You can configure the BIG-IP APM system to prompt users for their TACACS+ authentication credentials when accessing a virtual server.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • The BIG-IP is configured with the virtual server to which you want apply TACACS+ authentication.
  • You have previously deployed TACACS+ server(s) in your environment and the BIG-IP system can access them.

Procedures

  • Creating the TACACS+ authentication profile
  • Creating the access profile
  • Creating the access policy
  • Applying the access profile to the virtual server

Creating the TACACS+ authentication profile

The following procedure outlines the steps to create a new BIG-IP APM TACACS+ authentication profile that references existing TACACS+ servers of your environment.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Access > Authentication > TACACS+.
  2. Select Create.
  3. Enter a name for the TACACS+ authentication profile.
  4. Enter a name for the Server Pool Name.
  5. For Server Address, enter the IP address of the TACACS+ server.
  6. Select Add.
  7. Repeat steps 5 and 6 for all TACACS+ server pool members.
  8. For Server Monitor, select gateway_icmp.
  9. Leave Server Port at the default, 49, unless your TACACS+ server deployment uses a custom port.
  10. For Encryption, select Enabled (default setting).
  11. For Secret, enter the TACACS+ server secret.
  12. For Confirm Secret, re-enter the TACACS+ server secret.
  13. For Service, select PPP.
  14. For Protocol, select IP.
  15. For Authentication Type, select PAP (default setting).
  16. For Authentication Service, select PPP (default setting).
  17. Select Finished.

Creating the access profile

The following procedure outlines the steps to create a new BIG-IP APM access profile and configure the associated access policy to present a logon page and authenticate users to existing TACACS+ server or servers in your environment.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Access > Profiles/Policies.
  2. Select Create.
  3. Enter a name for the access profile.
  4. For Profile Type, select LTM-APM.
  5. For Profile Scope, select Virtual Server or Profile.
  6. For Customization Type, leave at the default setting of Modern.

    Important: If you are configuring an application access control scenario where you are using an HTTPS virtual server to authenticate and then sending the user to an existing HTTP virtual server to use an application, clear the check box for the SSO Across Authentication Domains > Secure setting.

  7. For Language Settings, for Factory BuiltIn Languages, select the languages you want to use and move them to Accepted Languages.
  8. Select Finished.

Creating the Access policy

The following procedure outlines the steps to create a new BIG-IP APM access profile and configure the associated access policy to present a logon page and authenticate users to existing TACACS+ server or servers in your environment.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
  1. Go to Access > Profiles/Policies.
  2. Next to your access profile, select Edit link to open the Virtual Policy Editor (VPE).
  3. In VPE, select the Add icon (+).
  4. Select Logon Page.
  5. Select Add Item.
  6. Modify the Form Header Text.
  7. Select Save.
  8. After the Logon Page agent, select the Add icon (+).
  9. Select the Authentication tab.
  10. Select TACACS+ Auth.
  11. Select Add Item.
  12. For Server, select the TACACS+ server profile you created in the previous procedure.
  13. Select Save.
  14. Select the Deny ending of the Successful branch.
  15. Select Allow.
  16. Select Save.
  17. Select Apply Access Policy.
  18. Select Close to exit VPE.

Applying the access profile to the virtual server

The following procedure outlines the steps to apply the newly create access profile and the associated access policy to an existing virtual server.

Impact of procedure: Performing the following procedure will require users present their TACACS+ credentials when accessing a virtual server that is configured with the BIG-IP APM access profile/policy.

  1. Go to Local Traffic > Virtual Servers > Virtual Server List.
  2. Select the name of the virtual server to which you want to apply the TACACS+ authentication access profile.
  3. For Access Policy, select the recently created access profile.
  4. Select Update.
