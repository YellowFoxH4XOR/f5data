Issue

Description

During a BIG-IP software hotfix upgrade, the following error may be observed from the Configuration utility:

Failed (software compatibility tests failed)

Environment

  • During BIG-IP software hotfix upgrade

Cause

  • The required base image build does not exist in the System > Software Management > Image List page.
  • Hotfix is being installed to a volume where its required base image is not installed and is of a different build number.

Recommended Actions

Import the correct required base build ISO file to the BIG-IP system and re-run the software installation. To do so, perform the following procedure:

Impact of procedure: Performing this procedure should not have a negative impact to the system.

  1. Remove the incorrect base build ISO file from the /shared/images directory of the BIG-IP device or through the System > Software Management > Image List page in the Configuration utility. Back up the incorrect base build ISO file to a network file repository.
  2. Download the required base build ISO file from F5 Downloads site and import it to the BIG-IP system using the Configuration utility or by copying it to the /shared/images directory of the BIG-IP system.
  3. Delete the failed install volume where the error was received. For example, if HD1.1 is the failed install volume, navigate to System > Disk Management  > HD1. Under Contained Software Volumes, select the check box for HD1.1 and click Delete.
  4. Install required base build ISO file to the deleted install volume. Following the previous example, if HD1.1 is the deleted install volume, navigate to System > Software Management  > Image List. Check the required base build ISO file, then click Install. Type 1 in the Volume set name and click Install.
  5. Wait for the required base build installation to finish. Then, verify that the installation is completed successfully before proceeding to next step.
  6. Install the hotfix to the recently installed volume. Continuing from previous example of installing the required base build image on HD1.1, navigate to System > Software Management > Hotfix List. Click the appropriate hotfix ISO file, then click Install. Type 1 for the Volume set name setting and click Install.
  7. Wait for the hotfix installation to finish and verify that this installation completes with no errors.
  8. Boot in to new installed boot location HD1.1 which has the installed BIG-IP SW hotfix by navigating to System > Software Management > Boot Locations. Click HD1.1 and click Activate.

Additional Information

Example error log from the /var/log/liveinstall.log file:

sfdisk: cannot open /dev/sdd for reading
info: Basic disk format validation passed.
error: The hotfix is intended for base build 0.0.1645, not 0.0.1475 >>>>>>>>>!!!!!!!!!!
Terminal error: Software compatibility tests failed.
*** Live install end at 2017/07/11 15:10:00: failed (return code 255) ***

For this referenced error log, the required base build 0.0.1645 is not installed on the destination volume which the hotfix requires, where instead, the base build installed is build 0.0.1475. The hotfix installation fails.
