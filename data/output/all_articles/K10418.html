Known Issue

This is the result of a known issue. The BIG-IP system does not honor the Proxy Exclusion List. As a result, multiple ARP responses, address conflicts, ARP table thrashing, and adverse connection behavior occurs.

Proxy Exclusion Lists are defined when BIG-IP(s) are deployed in a redundant pair with a VLAN group configuration to prevent ARP resolution conflicts. The list is used to define ARP traffic that should not be forwarded across the VLAN group.

Note: For more information about the Proxy Exclusion List, refer to the Configuring VLANs and VLAN Groups chapter in the BIG-IP Network and System Management Guide. For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

F5 Product Development tracked this issue as ID 209118 (formerly CR123608) and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-342.0-HF1, which has been issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
