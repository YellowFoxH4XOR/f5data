K000157300: BIG-IP LTM GUI Services List Empty and Qkview Generation Failure Due to Root Password Expiry

Type
Support Solution
Published
2026-03-25
Updated
2026-03-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0, 17.1.2, 17.1.1, 17.5.X, 17.1.X, 17.5.1, 17.5.0, 17.1.3
Source
https://my.f5.com/manage/s/article/K000157300

Description

The GUI "Services" list tab appears empty and does not display any services. Qkview generation fails with the error: "Failed to run qkview on slot: X".

Environment

LTM

Cause

Root password expiry on the BIG-IP system prevented backend processes from functioning correctly, resulting in both the empty services list in the GUI and qkview generation failures.

Recommended Actions

To resolve the issue:

  1. Check the root password status:
    • Run: chage -l root
    • If the password is expired, update it and set expiry to never or to your password lifecycle protocol:
      • Change the root password: passwd root
      • Set expiry to never: chage -M -1 root
  2. Verify that the password expiry is set to "never":
    • Run: chage -l root
    • Confirm "Password expires : never"
  3. After updating the root password, verify:
    • The GUI Services list is populated.
    • Qkview generation completes successfully.
