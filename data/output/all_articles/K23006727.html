Description

You want to determine the root cause of the failover events.

  • Your BIG-IP system experiences one or more unexpected failover events.
  • Your BIG-IP system logs error messages related to failovers.
  • Additional error messages shows 01190004:4: address conflict detected for <IP> (<MAC>) on vlan <VLAN>

    For example:
    warning tmm[14891]: 01190004:4: address conflict detected for 10.10.10.10 (00:00:5e:00:53:ff) on vlan 4000

Environment

  • BIG-IP 
  • Active/Standby HA Pair
  • logs in /var/log/ltm
     

Cause

Assigning a virtual server destination, secure network address translation (SNAT), or network address translation (NAT) addresses to the ‘traffic-group-local-only’ group may result in a standby device processing traffic.

You configure an IP address on the BIG-IP system and another device on the network issues a gratuitous Address Resolution Protocol (gARP) request for that same IP address. Network traffic using that IP address may experience interruptions or outages.
 

Recommended Actions

When you see these messages, locate the device with the conflicting IP address and assign a different address.  The MAC address of the conflicting interface is logged in the message and you can use it to identify the device with the conflicting address.

Make sure the virtual server destination, secure network address translation (SNAT), or network address translation (NAT) addresses doesn't belong to the ‘traffic-group-local-only’ group.
