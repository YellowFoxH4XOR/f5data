K000132861: rSeries system events: Firmware update is running for <no value>

Type
Support Solution
Published
2023-03-06
Updated
2023-03-06
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000132861

Description

Observed numerous events similar to the following on rSeries:

firmware-update-status EVENT NA "Firmware update is running for <no value> 0" "2023-02-06 10:47:01.057198392 UTC"
firmware-update-status EVENT NA "Firmware update completed for asw 0" "2023-02-06 10:47:14.149885801 UTC"

Environment

  • rSeries 5xxx or 10xxx
  • System events

Cause

These events are expected when an rSeries appliance with FPGA hardware is (re)booted; the FPGA is loading its bitstream.

Recommended Actions

No action is required.

Additional Information

None
