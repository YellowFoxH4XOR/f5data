Known Issue

This is the result of a known issue. Enterprise Manager halts configuration collection if the BIG-IP LTM version 9.3 is configured with four or more pools that reference the same monitor. The Enterprise Manager reports the following message in the /var/log/em log file:

Exception Message: getInstanceDependencies: iControl error: 'iControl::OperationFailed - primary code:0(0x0) secondary code: 16908327(0x1020027) string: MCP call failed: MCP error 0x1020027: 01020031:3: Opened and closed structures are mixed up.'

F5 Product Development tracked this issue as CR80046 and it was fixed in BIG-IP version 9.3.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue has been fixed in Hotfix-BIG-IP-9.3.0-HF1 which has been issued for BIG-IP version 9.3.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
