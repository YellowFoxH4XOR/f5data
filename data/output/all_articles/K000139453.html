Description

  • You are deploying NGINX Instance Manager (NIM) and NGINX Plus instances.
  • NIM will be deployed in a different network from NGINX Plus instances
  • Between these two different networks where NIM and Nginx Plus reside, inbound or outbound connectivity permitted only through firewall rules


  • You want to know source/destination ports to allow/open for effective connectivity between
    • NIM and Nginx Plus instances
    • NIM and Nginx Agent
    • NIM and License registration
    • Nginx Plus instances and License Registration

Environment

  • NGINX plus
  • NGINX Management Suite
  • NGINX Instance Manager
  • NGINX Agent
  • Licensing
  • Clickhouse

Cause

  • None

Recommended Actions

  • NGINX Management Suite, uses port 443 for both gRPC and API/web interfaces,
    • Port 443 also encompasses licensing for both NGINX Plus as well as NIM.
  • By default, the agent is configured to connect with NGINX Management Suite on port 443,
