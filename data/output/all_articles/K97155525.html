Description
The BIG-IP GUI  has an alert in the upper left corner that says, "Network Firewall: Update Failed"

You may see errors like these in /var/log/ltm: 
<date/time> <hostname> emerg pccd[13165]: 015d0000:0: Serialization failed: No Blobs available.
<date/time> <hostname> emerg pccd[13165]: 015d0000:0: Transaction failed.

Environment

  • BIG-IP AFM module provisioned and in use
  • Changes were made to some portion of the configuration

Cause

PCCD cores for not having enough memory. F5 tracked this issue as bug ID 499473.

Recommended Actions

For information about fixed versions, and workaround of provisioning additional memory, refer to Bug ID 499473: PCCD might restart because there is not enough memory
