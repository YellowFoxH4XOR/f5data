Description
How to license BIG-IQ Central Manager
Then complete the initial system setup

Environment

  • BIG-IQ Centralized Management system

Cause
None

Recommended Actions

The following will walk you through activating the license for BIG-IQ Central Manager, then complete the initial setup:
  1. Log in to BIG-IQ
  2. In the base registration key box, copy and paste the Base registration key of BIG-IQ.
  3. In the Activation Method, select Automatic.
  4. Click on Activate button
  5. In the  End User License agreement box, review and click on Agree 
    A text by the side of the Activate button, "license activation completed successfully" 
  6. Click on the Next. 
  7. System personality: select BIG-IQ Central Management, click next at the bottom right of the screen.
    Note: Only do this if the BIG-IQ is meant to a Central Manager. If your BIG-IQ license is only for a BIG-IQ License Manager, see: K18132312: How to license BIG-IQ License Manager and complete initial setup
  8. Hostname and Management Address: Fill in an FQDN hostname, management IP and management route (only if the management route is not a default route), Discovery address can be set to use management Port. Click Next.
  9. Services: DNS details should be pre-populated along with NTP (time servers), these can be tested by clicking the test button, set your Time zone location. Click next.
  10. Master Key: Check the requirements and type in the Master key and confirmation. Click Next, On the pop-up box click close.
  11. Password: Change admin and root passwords, and Click on next
  12. Launch: Review the data and click on Launch bottom right of the screen.
  13. Pop up box: Restart services, click on the restart button 
You will now see a User session terminated pop up box, you can click on Logout.
Refresh the web browser, you will see the BIG-IQ restarting screen, and then the logon screen.
  1. Log into BIG-IQ
  2. System--This Device--Licensing
  3. Review license details.
