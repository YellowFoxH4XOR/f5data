Description

When generating QKView from the GUI, you get the message:
Error generating QKView snapshot.

Environment

    • 15.1.0
    • 15.1.0.1
    • 15.1.0.2

    • 16.0.1

    • 16.0.1.2
    • 16.1.0
    • 16.1.1
    • 16.1.2
  • Not able to generate QKView from GUI with error  "Error generating QKView snapshot."
  • Some times, there won't be any error message. The GUI may show like a Qkview has been generated but no Qkview will be listed that can be downloaded.

Cause

This issue is related to Bug ID 967573.

Recommended Actions

At the time of publication, there is no fix to this issue.

The workaround is to generate the QKView from the Command Line.

The command is:
qkview

You can read article K23928121 for more QKView options via Command Line.
