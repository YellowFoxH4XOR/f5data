Known Issue

Note: Feature release 6.0.1 of FirePass software is the first release to support Microsoft Windows Vista clients.

This is the result of a known issue. Integrated IP Filtering does not support Microsoft Windows Vista clients in feature release 6.0.1 of FirePass software.

Integrated IP Filtering is an option available for Network Access Favorites, which implements client-side packet filtering rules to prevent access from the network to the remote access client, or through the remote access client to the remote LAN, using the Network Access tunnel. Integrated IP Filtering is available from the Policy Checks tab of the Network Access: Resources page.

Users connecting to the FirePass controller with the Microsoft Windows Vista operating system will not be able to successfully launch a Network Access Favorite that has Integrated IP Filtering configured. An error message that appears similar to the following example displays in the Status section of the Network Access window:

Integrated IP filtering engine is not available for Windows Vista and later systems. Your Network Access connection was terminated.

F5 Product Development tracked this issue as CR73174 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Workaround

To work around this issue, you can create a pre-logon sequence that detects Microsoft Windows Vista clients and provides a Vista-specific option, such as a Logon Denied Page, configured with a message appropriate for Microsoft Windows Vista users. Another option is you can allow Microsoft Windows Vista users to log on, but deny access to the Network Access Favorite using Protected Resources and session variables.

For information about detecting Microsoft Windows Vista clients in a pre-logon sequence, refer to K7177: Detecting Microsoft Windows Vista clients in a pre-logon sequence.
