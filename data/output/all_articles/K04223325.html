K04223325: On ESX, BIG-IP VE management interface shows no packets.

Type
Support Solution
Published
2023-09-21
Updated
2023-09-21
Applies to
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K04223325

Description

No packets on mgmt interface after moving VE to new ESX host
show net interfaces
has the interfaces up
1.1, 1.2, shows traffic, mgmt shows none

Environment

  • ESX 6.7 and others.
  • Virtual Edition of BIG-IP

Cause
The VMware configuration does not have the "Connect on Startup" option ticked on the network interfaces.
 

Recommended Actions

  1.  Ensure "Connect on Startup" is ticked
  2. Shutdown VM, optionally migrate to a new host
  3. Start VM

Additional Information
None.
