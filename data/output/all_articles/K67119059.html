Description

Interfaces down after upgrading from version 13.x to v15.x

Environment

  • BIG-IP VE is deployed on ESXi 6.7 Update 2 or above
  • you upgrade BIG-IP VE from version v13.x to v15.x 
  • While being in version v13.x you applied the workaround mentioned in article K74921042

Cause

The interfaces prior to upgrade were using the "unic" driver

[root@localhost:Active:Standalone] config # tmctl -d blade tmm/device_probed
pci_bdf      pseudo_name type      available_drivers     driver_in_use
------------ ----------- --------- --------------------- -------------
0000:03:00.0             F5DEV_PCI sock, vmxnet3, unic,
0000:0b:00.0 1.1         F5DEV_PCI sock, vmxnet3, unic,  unic
0000:13:00.0 1.2         F5DEV_PCI sock, vmxnet3, unic,  unic
0000:1b:00.0 1.3         F5DEV_PCI sock, vmxnet3, unic,  unic

After the upgrade unic driver is no longer available:
[root@localhost:Active:Standalone] config #  tmctl -d blade tmm/device_probed
pci_bdf      pseudo_name type      available_drivers     driver_in_use
------------ ----------- --------- --------------------- -------------
0000:03:00.0             F5DEV_PCI xnet, vmxnet3, sock,
0000:13:00.0             F5DEV_PCI xnet, vmxnet3, sock,
0000:0b:00.0             F5DEV_PCI xnet, vmxnet3, sock,
0000:1b:00.0             F5DEV_PCI xnet, vmxnet3, sock,

Recommended Actions
Follow the workaround steps that are detailed in ID893341.

Additional Information
F5 Product Development has assigned ID893341 to this issue.
