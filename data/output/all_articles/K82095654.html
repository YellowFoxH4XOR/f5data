Description

  • F5 device has become slow after upgrading from 13.1.x to 15.1.5.1
  • GUI Hangs

Environment

  • BIG-IP
  • Platform: B2100 Blade (BIG-IP VPR-B2100) (A109)
  • Software version 15.1.5.1

Cause

Software version 15.1.5.1 is not compatible/supported by hardware platform (VPR-B2100-A109). As per K9476 the highest software version compatible/supported by hardware platform (VPR-B2100-A109) is 13.1.1.

Any other software version which is not compatible/supported can result in degraded performance and instability.

Recommended Actions

Please install a software version which is compatible/supported with the hardware.
