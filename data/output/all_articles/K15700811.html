Description

When upgrading or restoring UCS backup, the system remains offline although there are no config errors seen. The following error is seen when viewing /var/log/ltm:

  • err mcpd[xxxx]: 01071bf3:3: LDAP authentication feature not licensed. Logged x times.
Example: 
Nov 26 07:45:52 bigipA.test.lab.net err mcpd[6812]: 01071bf3:3: LDAP authentication feature not licensed. Logged 3 times.
Nov 26 08:24:55 bigipA.test.lab.net err mcpd[6798]: 01071bf3:3: LDAP authentication feature not licensed. Logged 3 times.
Nov 26 08:42:13 bigipA.test.lab.net err mcpd[6820]: 01071bf3:3: LDAP authentication feature not licensed. Logged 3 times.

Environment

  • Upgrade or UCS restore
  • License change
  • LDAP Auth

Cause

The error is triggered when the license used is changed and the new license does not include ACA. The license responsible for LDAP Auth shown above is Advanced Client Authentication (ACA) which is already EOL.

Recommended Actions

Remove or delete all referenced objects used by LDAP Auth. If necessary, search the configuration files to determine which file contains the object with the issue by entering the following command syntax:

#grep -r "auth ldap" /config/*

Additional Information

ACA is now fully replaced by APM. If LDAP Auth is required, consider setting-up Authentication with APM instead.
