Known Issue

Synchronization may fail with validation errors after loading the base configuration.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP systems configured as peer members in a synchronization device group.
  • You load the base configuration on one of the BIG-IP systems by typing the following command:

    tmsh load sys config base
  • You perform a configuration synchronization (ConfigSync) either manually or because the device group Auto-Sync feature is enabled.

Impact

The ConfigSync fails between peer members in the synchronization device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Configuration utility at Device Management > Overview displays the device group's sync status as Sync Failed.
  • The following Traffic Management Shell (tmsh) command output displays that the sync status failed due to a validation error:

    tmsh show cm sync-status
    -------------------------------------------------------------------
    CM::Sync Status
    -------------------------------------------------------------------
    Status Sync Failed
    Mode high-availability
    Summary A validation error occurred while syncing to a remote device

Workaround

To work around this issue, on the device that has the base configuration loaded, ensure a ConfigSync does not occur immediately after loading the base configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. To ensure that the Auto-Sync feature is disabled, use the following command syntax:

    modify cm device-group <name> auto-sync disabled

    For example, to disable Auto-Synce for the device group named example_dg, type the following command:

    modify cm device-group example_dg auto-sync disabled
  3. To save the configuration, type the following command:

    save sys config
  4. To load only the base configuration, type the following command:

    load sys config base
  5. To save the configuration, type the following command:

    save sys config
  6. To load the configuration, type the following command:

    load sys config
  7. To synchronize the configuration to all members in the device group, use the following command syntax:

    run cm config-sync to-group <name>

    For example, to synchronize the configuration to all members in the device group named example_dg, type the following command:

    run cm config-sync to-group example_dc
  8. To enable auto-sync, use the following command syntax:

    modify cm device-group <name> auto-sync enabled

    For example, to enable auto-sync for the device group named example_dg, type the following command:

    modify cm device-group example_dg auto-sync enabled
  9. To save the configuration, type the following command:

    save sys config
