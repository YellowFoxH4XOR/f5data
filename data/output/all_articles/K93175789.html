Description
When using tmsh to create an HTTP or HTTPS monitor with a query string starting with a question mark in the URI, it does not get the expected response from the server and fails. Pool members may return a 404 status code or unexpected response content that doesn't match the receive string.

Environment

  • BIG-IP

Cause
Archived - K12836: The question mark character must be escaped in tmsh commands

Recommended Actions

Either escape the question mark with a '\' in your tmsh command or edit the send string in the Configuration Utility

Example corrected tmsh command:
create http my_monitor defaults-from http recv "UP" send "GET /path/\?value=true\r\n" interval 5 timeout 16
