Description

  • Unable to display username/hostname  on the APM/BIG-IQ Active Session

Environment

  • APM
  • BIG-IQ

Cause

  • APM session is established through the use of Device certificate
  • Session variables 'session.logon.last.username' is not included when APM session established
  • APM Access  ››  Overview : Active Sessions
    • username display N/A

Recommended Actions

  •  On the VPE of the Access profile
    • use Variable Assign APM object to create a custom session variable AFTER user AUTH completed successfully  [successful branch]
      • custom variable  =  session.logon.last.username
      • session variable =  session.hostname
        • Apply Policy
