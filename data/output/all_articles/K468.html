K468: Load balancing FTP servers that use custom ports

Topic

You can use BIG-IP to load balance FTP servers by creating virtual servers using the normal FTP ports (20 and 21) and configuring the virtual servers to use nodes on the custom ports. This will allow clients to connect to BIG-IP on the default FTP ports and the traffic will be sent to the nodes on the custom ports.

For example, you could use the following configuration:

Virtual Server 1:172.16.101.20:21
Nodes:10.90.100.1:10021
10.90.100.2:10021
 
Virtual Server 2:172.16.101.20:20
Nodes:10.90.100.1:10020
10.90.100.2:10020

In addition, you must enable persistence across the virtual servers to ensure that the data and control sessions are always sent to the same node.
