Known Issue

This is the result of a known issue. If you run the qkview utility against BIG-IP WebAccelerator 10.0.x, the new qkview output does not include the BIG-IP WebAccelerator configuration data contained in the MySQL database.

F5 Product Development tracked this issue as CR123993 and it was fixed in BIG-IP WebAccelerator version 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Workaround

You can work around this issue by running the wa_configsync.pl script. To do so, type the following command at the BIG-IP WebAccelerator command line:

/usr/local/wa/scripts/wa_configsync.pl save

The script produces the /var/tmp/wa_db.sql.cstmp file, which contains the MySQL configuration data.
