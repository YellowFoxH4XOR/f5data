Topic

You should consider using these procedures under the following conditions:

  • You have an iOS device with the F5 Access app installed.
  • You want to collect additional data to troubleshoot client-side issues.

Description

To investigate client-side connection issues with F5 Access for iOS, you may need to collect additional diagnostic data beyond the basic logs gathered by the BIG-IP APM system.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have an iOS device with the F5 Access app installed.
  • You have a BIG-IP APM system configured to provide network access to resources.
  • An email client is configured on the iOS device.
  • You have access to a macOS device to collect packet captures.

Procedures

Use the following procedures to collect diagnostic data when troubleshooting connectivity issues using F5 Access for iOS.

Note: The following procedures involve using third-party applications that could change without our knowledge.

  • Collecting client logs
  • Collecting DNS settings on the iOS device
  • Collecting the iOS routing table
  • Collecting a packet capture on the iOS device

Collecting client logs

Use this procedure to collect the base-level diagnostic logs from the F5 Access app on the iOS device.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open the F5 Access app and establish a network access session to the BIG-IP APM system.
  2. Tap Settings.
  3. Under Support, tap Email logs.
  4. Enter an email address where you can receive the logs as an email attachment and send the email.

Note: "Email logs" should bring up the Email App. If the device presents a message "Unable to Send Email. No mail  account setup on device." and there is a working Email App, then check if it uses a Mobile Device Manager (such as Intune).

MDM settings can prevent data sharing with unmanaged apps. If mail is not managed, this prevents F5 Access from using email. This requires MDM profile changes.

Collecting DNS settings on the iOS device

Use this procedure to collect DNS information from the F5 Access app on the iOS device.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open the F5 Access app and establish a network access session to the BIG-IP APM system.
  2. Tap Settings.
  3. Under Support, tap Diagnostics.
  4. Tap DNS Servers.
  5. Create a screen capture of the DNS Servers page on the iOS device.
  6. Open the Photos app, find the screen capture, and tap the Share icon to send the capture to an email address where you can receive the image as an attachment.

Collecting the iOS routing table

Use this procedure to collect client routing table from the F5 Access app on the iOS device.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open the F5 Access app and establish a network access session to the BIG-IP APM system.
  2. Tap Settings.
  3. Under Support, tap Diagnostics.
  4. Tap Routing Table (IPv4) or Routing Table (IPv6).
  5. Tap the Share icon to send the capture to an email address where you can receive the routing table as an email attachment.

Collecting a packet capture on the iOS device

Use this procedure to collect a packet capture from an iOS device.

Note: The procedure requires a macOS device with iTunes installed.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Clear the DNS cache on the iOS device by turning on Airplane Mode for 10 seconds and then turning it off.
  2. Connect the iOS device to a macOS device using a USB cable.
  3. On the macOS device, get the unique identifier (UDID) of the iOS device:
    1. Launch iTunes.
    2. Choose the iOS device from the iTunes menu at the top left and make sure that the Summary section is selected.
    3. Click the serial number of the iOS device to display its UDID.
  4. On the macOS device, create a remote virtual interface (RVI) for the iOS device by running the following command from a terminal window:

    rvictl -s <UDID_of_iOS>

    Note: If the rvictl command is not found, install and open Xcode, open a new terminal window, and run the command again.

  5. Using a capture utility such as Wireshark or tcpdump on the macOS device, start capturing on the RVI interface created in step 4.
  6. Open the F5 Access app on the iOS device.
  7. Establish a network access session to the BIG-IP APM system and reproduce the traffic you want to capture on the iOS device.
  8. On the macOS device, stop and save the packet capture.
