Known Issue

The Session Initiation Protocol (SIP) application layer gateway (ALG) profile may hairpin messages when the destination address is not in the network address translation (NAT) IP subnet.

This issue occurs when all of the following conditions are met:

  • Your system configuration uses BIG-IP Carrier-Grade NAT (CGNAT) and a SIP ALG profile.
  • Both SIP peers reside in the same local NAT IP subnet.
  • The destination SIP proxy, used by the peers, is located in a network that is external to the local NAT network.

Impact

Systems may be missing SIP messages and accounting information, due to messages not being forwarded correctly to the external SIP proxy.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SIP messages are not sent to the external SIP proxy server as expected.
  • SIP accounting information is incorrect.
