Description

  • Getting iApp strict updates enabled error when trying to modify a non-iApp object
  • Virtual server rendered by iApp. with a Client SSL profile which isn't rendered by iApp as a parent profile.
  • An error message similar to the following can be seen on /var/log/ltm

    err mcpd[6296]: 010715bc:3: The application service (/Common/service.app/service) has strict updates enabled, the object (ClientSSL Profile /Common/client_ssl_profile) must be updated using an application management interface.

Environment

  • LTM
  • Virtual server
  • iApp
  • SSL profile
  • Device running software version 13.x or below.

Cause

Seen behavior is caused by a Bug tracked with the ID 1072401

Recommended Actions

Upgrade to software version 14.1.0 or above

None
