Topic

The FirePass controller provides the ability to obtain system memory information through data collected by the Simple Network Management Protocol (SNMP). An SNMP-based network monitoring tool obtains data by polling FirePass SNMP objects that contain system memory information. Each SNMP object has a unique Object ID (OID). The network monitoring tool is configured with the OIDs of the objects so that it can poll for the object's data.

The SNMP objects for system memory are the standard objects found in the Net-SNMP MIB (formerly known as the UC Davis UCD-SNMP MIB).

The parameters are listed in the following table, with their official SNMP Object name, OID, and OID type.

 Parameter Object Name OID Object Type
 Total Swap Size memTotalSwap 1.3.6.1.4.1.2021.4.3.0 INTEGER32
 Available Swap Space memAvailSwap 1.3.6.1.4.1.2021.4.4.0 INTEGER32
 Total RAM in system memTotalReal 1.3.6.1.4.1.2021.4.5.0 INTEGER32
 Total RAM unused memAvailReal 1.3.6.1.4.1.2021.4.6.0 INTEGER32
 Total RAM Free memTotalFree 1.3.6.1.4.1.2021.4.11.0 INTEGER32
 Total RAM Shared memShared 1.3.6.1.4.1.2021.4.13.0 INTEGER32
 Total RAM Buffered memBuffer 1.3.6.1.4.1.2021.4.14.0 INTEGER32
 Total Cached MemorymemCached 1.3.6.1.4.1.2021.4.15.0 INTEGER32
