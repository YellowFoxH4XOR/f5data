Known Issue

You are unable to obtain traffic group failover objects using the iControl REST interface.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with traffic group failover objects.
  • You use the iControl REST interface to query the BIG-IP system for traffic group failover objects.

Impact

You are unable to query for traffic group failover objects. 

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the iControl REST interface to query the BIG-IP system for traffic group failover objects, the system returns an HTTP 500 error message similar to the following example:

    List property is not implemented! Detail [cm traffic-group failover-objects {\n self IP {\n /<partition>/<ip address> traffic-group <traffic group name>

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to obtain the objects. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To query the traffic group failover objects, use the following command syntax:

    show /cm traffic-group <traffic group name> failover-objects 

    For example:

    show /cm traffic-group traffic-group-1 failover-objects

  3. To exit tmsh, type the following command:

    quit
