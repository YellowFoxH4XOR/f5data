K44915535: Access Denied when trying to view qkivew uploaded by others

Type
Support Solution
Published
2021-08-18
Updated
2025-09-02
Applies to
  • BIG-IP
  • BIG-IQ
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K44915535

Description

When a qkview file was uploaded by one user and another user tries to view the qkview diagnostic results from iHealth, the below error is encountered:

Access Denied  You do not have sufficient permission to view this page. If you believe this is an error, please go back to the main iHealth page and contact us using the Feedback link. 
 

Environment

  • F5 iHealth
  • MyF5 portal

Cause

This is expected as only the owner of the QKview file can view the diagnostic result of it.

Recommended Actions

If you believe this is an error, please go back to the main iHealth page and contact us using the Feedback link. 

Additional Information

None
