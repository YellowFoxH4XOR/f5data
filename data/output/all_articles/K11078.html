Known Issue

This is the result of a known issue. The Extended Windows and IE info pre-logon inspector cannot detect hotfixes on Windows 7 clients. As a result, if you configure a pre-logon check that requires Windows 7 clients to have a particular hotfix installed, those clients will fail the check.

F5 Networks Product Development tracked this issue as CR135831 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue has been fixed in cumulative hotfix HF-610-1, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
