Description

Where does the rSeries store the tenant ISO file?

Environment

  • F5OS
  • rSeries

Cause

None

Recommended Actions

The tenant ISO file is stored at /var/F5/system/IMAGES

Additional Information

  • The F5OS-A system image is stored on /var/images directory.
  • The F5OS-A ISO image is stored on /var/F5/system/images/import/iso/ directory.
