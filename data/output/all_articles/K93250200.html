Topic

With the cloud provider configured, you can use the BIG-IQ system to create new BIG-IP Virtual Edition (VE) devices in the Azure cloud environment.

You should consider using this procedure under the following condition:

  • Configuring the Azure cloud provider on the BIG-IQ system.

Description

This article describes the procedure to configure the Azure cloud provider on the BIG-IQ system so that the BIG-IQ system knows how to connect to your Azure environment.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to a valid account subscription on the Azure portal.
  • You want to configure Azure cloud provider on the BIG-IQ system.

Procedures

Locating the account data from the Azure portal

To connect the BIG-IQ system to your Azure subscription environment, you need the following four items from your account in the Azure portal:

  • Tenant ID: This refers to the Directory ID of your account in the Azure portal.

    To locate the tenant ID from the Azure portal, from go to Azure Active Directory > Overview. From there, you can locate your tenant ID string value.

  • Client ID: This refers to the registered app's application ID in the Azure portal.

    To locate the client ID from the Azure portal, go to Azure Active Directory > App Registrations and select the display name of your target app that your BIG-IQ system connects to. From the target app page, locate the client ID or application ID string.

  • Service Principal Secret: This refers to the application password for the connecting application to prove its identify. The BIG-IQ system uses the secret string to connect to the Azure registered app. To locate it from the registered app, select Certificates & Secrets. You can generate a new client secret from this page.
  • Contributor role: This refers to the Azure access control (IAM) contributor role for the registered app.

    To configure the contributor role from the Azure portal, perform the following procedure:

    1. Go to All services > Subscriptions.
    2. Select your Subscription name.
    3. Select Access control (IAM).
    4. Select + Add.
    5. Select Add role assignment and assign the following values:
      • For Role, select Contributor.
      • For Assign access to, select Azure AD user, group, or service principal.
      • For Select, enter the name of the registered app.
    6. Select Save.
         

Configuring cloud provider on BIG-IQ system

Configuring the cloud provider on BIG-IQ system lets BIG-IQ know how to connect to the Azure cloud environment and which Azure registered app it uses.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ user interface.
  2. Go to Applications > ENVIRONMENTS and select Cloud Providers.
  3. Select Create.
  4. Specify a name for the cloud provider.
  5. Provide a description for the cloud provider.
  6. For Provider Type, select Azure.
  7. Using the data gathered on the Azure account from previous procedure, enter the Tenant ID, Client ID, and Service Principle Secret.
  8. Select Test. If the Azure test connection is successful, Subscription ID is automatically populated. Azure uses this subscription ID to track all of the metrics for the account associated with these credentials. If the test connection is unsuccessful, revisit the previous procedure to ensure you have gathered the correct information from the Azure account.
