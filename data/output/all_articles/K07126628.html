K07126628: Unable to push ASM policy into BIG-IP device from BIG-IQ

Source

Description

Unable to push ASM policy ito BIG-IP device from BIG-IQ

Error:
Failed waiting for discovery task for bigip1.example.com (10.0.0.1) to finish; reason: Error getting resource provisioning from /mgmt/tm/sys/provision on bigip1.example.com (10.0.0.1), network communication failed due to protocol error

Environment

  • Conditions: Push ASM policy from BIG-IQ to BIG-IP device
  • Configuration objects and settings: ASM Security Policy
  • Products and features: BIG-IQ, BIG-IP, ASM

Cause

The BIG-IP returns a 400 error to the rest REST request because the rest storage database on the BIG-IP is in a conflicted state.

Recommended Actions

Clear the REST storage on the BIG-IP and let it rebuild. Doing this on a BIG-IP will not lose any of the configurations.  It will not disrupt traffic .

On the BIG-IP CLI:

    clear-rest-storage -l

Note: the -l clears the REST logs on the BIG-IP
