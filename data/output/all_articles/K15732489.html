Security Advisory Description

When authentication is set to require, the Client SSL or Server SSL profile does not report an error when it has an associated invalid Certificate Revocation List (CRL).

This issue occurs when all of the following conditions are met:

  • The Client SSL or Server SSL profile is associated with a virtual server.
  • The profile is associated with an invalid CRL that is not signed by a trusted Certificate Authority (CA).
  • The CRL issuer has the same subject name as one of the certs in the trusted CA.
  • The client or server certificate authentication is set to require.

Impact

An invalid CRL which has not been properly signed may be used.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • An error is not reported for the invalid CRL.
