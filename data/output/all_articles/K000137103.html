K000137103: Too big subrequest response

Type
Support Solution
Published
2023-11-09
Updated
2023-11-22
Applies to
  • NGINX Products
  • NGINX Plus: R27
Source
https://my.f5.com/manage/s/article/K000137103

Description

When using nginx shared_cache feature and while fetching the cache from http_api_module - below error is observed.

[error] 7071#7071: *58914954 too big subrequest response: 150716 while sending to client ...


Environment

  • Nginx Plus Instance
  • Nginx Plus configuration 

Cause

  • The buffer size is still insufficient. 

Recommended Actions

Increase the buffer size to a few megabytes for the test.
For example:
subrequest_output_buffer_size 10m;
 

Additional Information

None
