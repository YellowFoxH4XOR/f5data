Known Issue

This is the result of a known issue. BIG-IP Link Controller version 9.x is missing the following dynamic load balancing modes:

  • Least Connections
  • Observed
  • Predictive
  • Fastest

F5 Product Development tracked this issue as CR69150 and it was fixed in BIG-IP Link Controller versions 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP Link Controller release notes.
