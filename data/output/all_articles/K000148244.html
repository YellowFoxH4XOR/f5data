Description:

This article guides you through the steps to locate the SKU (Stock Keeping Unit) of a network interface card (NIC) or Small Form-factor Pluggable (SFP) transceiver module on an F5 BIG-IP device. The SKU is often required when raising a Return Merchandise Authorization (RMA) request. The SKU can be found using the tmsh command-line utility to list interface properties and identify the relevant part number.

 

Environment:

  • F5 BIG-IP device
  • TMOS (Traffic Management Operating System)
  • CLI access using a root account

 

Cause:

When raising an RMA request, the F5 support team requires the SKU of the part that needs replacement. For network-related components like the SFP module, the SKU can be identified by executing the correct command and analyzing the output.

 

Recommended Actions:

Follow the steps below to find the SKU of the SFP or other interfaces on your F5 BIG-IP device:

Access the CLI:

    • Log in to the BIG-IP device using SSH or via direct console access.
    • Ensure you have admin privileges to run the necessary commands.
    • Run the Command:
      Execute the following tmsh command to list all network interfaces and their properties:

                     tmsh list /net interface all-properties -hidden

 

  1. Identify the SFP Interface: After running the command, the output will include detailed information about each network interface. Look for the relevant interface (e.g., 1.2, 1.1) where the SFP module is installed. The output will show details such as the interface name, media type, MAC address, and other related properties.
  2. Locate the SKU: In the output for each interface, look for the field labeled vendor-partnum. The value next to this field is the SKU of the SFP or other module connected to that interface. For example:

 

In this case, the SKU for the SFP module is OPT-0016.

vendor-partnum OPT-0016

  1. Example Output: Here is a sample output for reference:

 

In this example, the vendor-partnum shows OPT-0016, which is the SKU for the installed F5 Qualified Optic SFP.

}

 

Use the SKU for RMA: Now that you have the SKU (e.g., OPT-0016), you can use this information when raising an RMA request to replace the specific module.

 

Additional Information:

  • Ensure that the interface you're checking is the correct one for the part that needs replacement.
  • You may refer to F5's official hardware documentation or contact F5 Support for a complete list of SKU numbers for various components.
