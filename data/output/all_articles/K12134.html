Known Issue

The BIG-IP system reverts the tri-speed copper SFP port media settings to 1000BASE-T full after reboot.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP device is one of the following:
    • 1600 (C102)
    • 3600 (C103)
    • 3900 (C106) - version 10.1.0 and later
    • 6900 (D104)
    • 8900 (D106)
    • VIPRION (J100, J101)
  • Your device uses the tri-speed copper small form-factor pluggable (SFP).
  • The tri-speed copper SFP is configured with the 10BASE-T or 100BASE-TX fixed media settings.
  • You have rebooted the BIG-IP device.

Impact

The SFP does not retain the configured media settings.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After rebooting the BIG-IP device, the SFP is configured at 1000BASE-T full.
  • You may experience loss of network connectivity through the SFP interfaces.
  • In the /var/log/ltm file, you may observe log messages similar to the following example:

    err bcm56xxd[PID]: 012c0007:3: Trouble setting port speed for unit=0, port=1 bs_media.c(233)
    err bcm56xxd[PID]: 012c0010:3: Trouble setting interface <interface number> SFP media type: media=0x0 bsx.c(1201)

Workaround

To work around this issue, you can modify the copper SFP interface media settings. To do so, perform the following procedure:

Impact of workaround: Network connectivity may temporarily be disrupted.

To modify the copper SFP interface media settings, you must first set the copper SFP interface media settings to auto, then you must set it to the originally configured media mode. To do so, perform one of the following procedures:

  • Modifying interface settings using the Configuration utility (10.1.0 and later)
  • Modifying interface settings using the command line interface (all versions)

In BIG-IP 10.1.0 and later, you can also run the commands automatically when the system starts up. To do so, perform the following procedure:

  • Automating interface settings on system startup (10.1.0 and later)

Modifying interface settings using the Configuration utility (10.1.0 and later)

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Click Network.
  3. Click Interfaces.
  4. Click Interface List.
  5. Click the affected interface name.

    For example:

    2.1

  6. From the SFP Requested Media menu, select auto.
  7. Click Update.
  8. From the SFP Requested Media menu, select the originally configured media mode.
  9. Click Update.

Modifying interface settings using the command line interface (all versions)

Impact of workaround: For BIG-IP 10.0.x, network connectivity for all network interfaces may be briefly interrupted, as this procedure requires that you restart the bcm56xxd process.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Use the following command syntax to set the media settings of the copper SFP interface to auto:

    modify /net interface <interface_name> media-sfp auto

    For example, to set the media settings of interface 2.1 to auto, type the following command:

    modify /net interface 2.1 media-sfp auto

  3. Use the following command syntax to set the media settings of the copper SFP interface to the originally desired media mode:

    modify /net interface <interface_name> media-sfp <media_option>

    Note: For <interface_name>, substitute the name of the interface you want to configure. For <media_option>, substitute the desired media option. Available media options include 10T-FD, 10T-HD, 100TX-FD, and 100TX-HD.

    For example, to set the media settings of interface 2.1 back to the media mode to which it was originally configured (100TX-FD), you would type the following command:

    modify /net interface 2.1 media-sfp 100TX-FD

  4. For BIG-IP devices running 10.0.x, you need to restart the bcm56xxd process by typing the following command:

    bigstart restart bcm56xxd

    Note: BIG-IP 10.1.0 and later are not required to restart the bcm56xxd process.

Automating interface settings on system startup (BIG-IP 10.1.0 and later)

Impact of workaround: This script may cause a 45 second delay to bring up the affected interface that you are configuring in this procedure.

  1. Log in to the BIG-IP command line.
  2. Using a text editor, create a new file that contains the following lines:

    #!/bin/bash
    export REMOTEUSER=root
    sleep 45
    /usr/bin/tmsh modify /net interface <if_name> media-sfp auto
    /usr/bin/tmsh modify /net interface <if_name> media-sfp <media_option>

    Note: Substitute the name of the interface you want to configure and the desired media option. Available media options include 10T-FD, 10T-HD, 100TX-FD, and 100TX-HD. If you must configure multiple interfaces, replicate the final two lines of the script for each interface to be configured, modifying the interface name and media option to reflect the desired configuration.

    For example, the following lines will set the media option for interface 2.1 and 2.2 to 100BASE-TX full:

    #!/bin/bash
    export REMOTEUSER=root
    sleep 45
    /usr/bin/tmsh modify /net interface 2.1 media-sfp auto
    /usr/bin/tmsh modify /net interface 2.1 media-sfp 100TX-FD
    /usr/bin/tmsh modify /net interface 2.2 media-sfp auto
    /usr/bin/tmsh modify /net interface 2.2 media-sfp 100TX-FD

  3. Save the file in the /config directory with the following name:

    sol12134.sh

  4. Exit the text editor.
  5. Change the permissions of the script file to allow it to run, by typing the following command:

    chmod a+x /config/sol12134.sh

  6. Change permissions on the /config/startup file to allow modifications, by typing the following command:

    chmod +w /config/startup

  7. Using a text editor, open the /config/startup file and add the following command at the bottom of the file:

    /config/sol12134.sh &

  8. Save the changes and close the file.

The BIG-IP system will now reset the media options for the indicated interfaces upon system startup.

Note: For more information about running scripts during system startup, refer to K11948: Configuring the BIG-IP system to execute commands or scripts upon system startup.

Note: You cannot automate these steps using a script in BIG-IP 10.0.0 and 10.0.1, due to another issue with the /config/startup not running during startup. For more information, refer to K12132: BIG-IP system does not execute startup commands or scripts during system startup.
