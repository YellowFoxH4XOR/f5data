Topic

This article applies to BIG-IP 9.3.x through 10.x For information about other versions, refer to the following article:

  • K14923: Configuring the BIG-IP GTM to answer TCP or UDP DNS requests (11.x - 14.x)

Purpose

You should consider using this procedure under the following conditions:

  • You want to configure a UDP listener for standard DNS queries.
  • You want to configure a TCP listener in conjunction with UDP for large size DNS responses.
  • You want to configure a TCP listener for use with DNS zone transfers.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP GTM system.

Description

To configure the BIG-IP GTM, you can define one or more listener objects to control what protocols are available for the BIG-IP GTM to process DNS requests. A listener is assigned to a specific IP address and protocol UDP or TCP on which the BIG-IP GTM receives and processes traffic. When the BIG-IP GTM listener address receives a DNS request, the request is forwarded to the gtmd process. The gtmd process then processes the traffic locally or forwards the traffic to the appropriate resource.

The BIG-IP GTM listener objects can be configured to use the TCP and UDP protocols. This feature is useful when a DNS response may span multiple packets exceeding the maximum DNS UDP packet size of 4096 bytes. When a DNS UDP response is larger than 4096 bytes the client initiating the DNS request will utilize the TCP protocol to make a subsequent TCP request. This is typical when resolving DNS records that have been configured to respond with DNSSEC keys. Additionally, if you want to import zones to the BIG-IP GTM with a zone transfer from other DNS servers the GTM need to be configured with a listener IP address using the TCP protocol.

Procedures

Impact of procedure: The following procedure should not have a negative impact on your system.

To configure a new UDP or TCP listener, perform the following procedure.

  1. Log in to the Configuration utility.
  2. Navigate to Global Traffic > Listeners.
  3. Click Create.
  4. For General Properties, click Advanced.
  5. For Destination, type the listener IP address.
  6. For Protocol, click either UDP or TCP.
  7. To enable an IP address to be a listener for both UDP and TCP, repeat these steps using the same IP address and creating a listener for each of the protocols.
