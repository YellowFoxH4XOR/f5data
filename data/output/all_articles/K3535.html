Topic

You can view users and their associated roles through the Configuration utility or the command line.
 

Configuration utility

To view the list of users and their associated user roles using the Configuration utility, perform the following steps:

  1. From the Configuration utility, click System Admin.
  2. Click the User Administration tab.

Command line

To view the list of users and their associated user roles using the command line, type the following command:

ldap -U
