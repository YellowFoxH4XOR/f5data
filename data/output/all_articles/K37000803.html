K37000803: Protocol Inspection no longer functions after upgrade due to new requirement for subscription license key

Applies to

Topic

In versions prior to BIG-IP AFM 13.1.0.3, the BIG-IP AFM Protocol Inspection feature works with any license that is valid for the BIG-IP AFM module. This includes a Good, Better, or Best license or an add-on license to another module, such as BIG-IP LTM.

Description

Beginning in BIG-IP AFM 13.1.0.3, BIG-IP AFM Protocol Inspection requires a standalone BIG-IP AFM license. Other modules can be added, but the base license must be for BIG-IP AFM. Alternatively, a specific add-on license key for Protocol Inspection can be applied to any of the other valid BIG-IP AFM licenses including Good, Better, or Best, or BIG-IP AFM as an add-on to another module, such as BIG-IP LTM.

Note: Currently, the Protocol Inspection feature is plumbed only on the following platforms.

  • VIPRION Chassis (C2200, C2400, C4480, and C4800)
  • iSeries Appliance (i2000, i4000, i5000, i7000, i10000, i11000, and i15000)
  • Virtual Edition V16 and Virtual Edition V18
  • BIG-IP 10350

Without one of these licenses, Protocol Inspection fails silently. There is no configuration validation in the Configuration utility to prevent you from configuring and applying Protocol Inspection profiles without the required license. After upgrading to BIG-IP AFM 13.1.0.3 or later, Protocol Inspection is not applied to application traffic. Signatures and compliance checks are not used.

F5 Product Development tracked this change as ID 737558 and ID 702419.

Recommendations

You can purchase a valid license to add Protocol Inspection functionality. A subscription to Protocol Inspection Signature updates will be available for purchase in a future release.
