Description

When the BIG-IP system process connections from the origin IP address matching a SNAT automap definition, it chooses a translation address from the available self IP addresses. Floating self IP addresses on the egress VLAN are preferred to support seamless failover. If multiple floating self IP addresses are configured on the VLAN, the BIG-IP system translates the address of client connections by alternating through a pool of all floating self IPs on the VLAN.

However, the virtual server continues to use the client ip address as the source when connecting to the backend pool members even when SNAT is enabled.

Environment

  • Virtual Server
  • SNAT automap / SNAT pool
  • Pool

Cause

The pool is configured to disallow SNAT.

Recommended Actions

1. Navigate to "Local Traffic  ››  Pools : Pool List" and click the affected pool.
2. Change the Configuration view from Basic to Advance.
3. Set 'Allow SNAT' to Yes
4. Click [Update] button to save changes.
