Description:

Virtual Server with ASM security policy applied sending a large number connection reset with reason "No flow found for ACK."

After reset with reason "Internal error (ASM requested abort (plugin abort error))".

Environment:

  • Virtual server with ASM security policy.
  • HTTP/HTTPS response from server.

Cause:

Further traffic from client resets with reason " No flow found for ACK."  as connection has been removed from connection table.

This is due to previous reset reason "Internal error (ASM requested abort (plugin abort error)"

Recommended Actions:

Need to correct the server's behavior to make sure it sends complete HTTP responses. Instead of unexpected connection closure from server end (by sending FIN) HTTP response should be sent completely.

None.
