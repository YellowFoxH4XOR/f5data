Description
You want to check if the physical hard disk inside F5 appliance is encrypted or if any type of encryption is applied inside the hard disk for configuration or logs.

Environment

  • BIG-IP appliance
  • Hard Disk encryption
  • Physical security
  • Password security
  • Tamper detection

Cause
You might want to encrypt the physical Hard Disk of the BIG-IP to apply physical security.

Recommended Actions
On current products we do not have a whole disk encryption option. Any third party alteration that may be applied, wouldn't be covered by F5 support so it is not recommended. 

We do have a feature ("The Secure Vault feature") to protect password type information in config files which provides an additional layer of security to the BIG-IP system by encrypting passwords and passphrases stored on the system, refer to K73034260: Overview of the BIG-IP system Secure Vault feature.

Additional Information
None.
