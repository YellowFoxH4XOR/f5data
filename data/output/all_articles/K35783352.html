Description

Before upgrading a BIG-IP to a new version, you must Re-Activate it's License in order to update the License's Service Check Date. If you don't Re-Activate the BIG-IP's License before upgrading, when the BIG-IP boots into the new upgrade Boot Location (volume), the configuration can fail to load due to the License's Service Check Date being outside the acceptable range. And a message banner stating "The Configuration Has Not Yet Loaded" appears at the top of the management WebUI. 

And at that point, the License must be Re-Activated post-upgrade, or the BIG-IP has to be rolled back to the previous Boot Location, and the entire upgrade process, starting with License Re-Activation, must be performed again. 

Additionally, since the BIG-IP wipes the running-config from RAM when License Re-Activation is performed and then reloads it from the saved-config on the hard drive, the BIG-IP is unable to process any traffic during this time, since it has no config to tell it what to do with the traffic. Once the config reloads, traffic processing will resume. So the License Re-Activation activity can cause traffic interruption and potentially trigger a Failover event if performed on the Active HA peer BigIP.

Environment

Relevant environmental factors:

  • BIG-IP being prepared for a software upgrade.

Cause

Need to upgrade BIG-IP software.

Recommended Actions

There are two ways to perform BIG-IP License Re-Activation via the WebUI Configuration Utility. The first is the Manual method of License Re-Activation; which is used when the BIG-IP does NOT have Internet access. And the second is the Automatic method of License Re-Activation; which is used when the BIG-IP does have Internet access. Both procedures are documented below...

License Re-Activation via the Manual method in the WebUI Configuration Utility:

  1. Connect to the BIG-IP's management interface using a web browser and login using the appropriate admin account.
  2. Navigate to System ›› License and click the Re-activate button.
  3. Select Manual for the Activation Method option, and click Next.
  4. Follow the WebUI's instructions on the next page to copy the Dossier to the PC's clipboard. Access the F5 Licensing server on the Internet. Paste the Dossier into the License server's License Re-Activation page. Accept the License server's End User License Agreement. Copy the new License file content into the PC's clipboard. And paste it into the BIG-IP's WebUI, all as instructed by the WebUI.
  5. Click Next to apply the new License file to the BIG-IP.
  6. As explained above, the BIG-IP will wipeout it's running-config from RAM, and will then reload the config while ensure it's in compliance with the newly updated License. And that will cause the BIG-IP to temporarily stop passing traffic since it has no config to tell it what to do with the traffic. Once the config reloads, traffic processing will resume.

License Re-Activating via the Automatic method in the Configuration Utility:

  1. Connect to the BIG-IP's management interface using a web browser and login using the appropriate admin account.
  2. Navigate to System ›› License and click the Re-activate button.
  3. Select Automatic (default) for the Activation Method option, and click Next.
  4. The BIG-IP will reach out to F5's Licensing server and will automatically update the License.
  5. As explained above, the BIG-IP will wipeout it's running-config from RAM, and will then reload the config while ensure it's in compliance with the newly updated License. And that will cause the BIG-IP to temporarily stop passing traffic since it has no config to tell it what to do with the traffic. Once the config reloads, traffic processing will resume.
