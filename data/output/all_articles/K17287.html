Known Issue

Objects configured with a connection rate limit may continue to appear as unavailable after the connection rate falls back below the configured threshold.

This issue occurs when all of the following conditions are met:

  • A configuration object is configured with a connection rate limit.
  • The connection rate exceeds the configured threshold causing the object to be marked as unavailable (yellow).
  • The connection rate falls back below the configured threshold allowing the object to be eligible to receive connections again.
  • The object does not receive any subsequent connections.

After the connection rate falls back below the configured value, the object's status continues to show yellow (unavailable) until the object receives additional traffic.

Note: This issue is most likely encountered in a test environment and not likely to affect a production environment.

Impact

An object available to receive connections may appear as yellow (unavailable).

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The availability status for objects configured with a connection rate-limit remain yellow after the object is available to process connections again.
