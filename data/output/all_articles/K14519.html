Known Issue

A BIG-IP APM system that is configured for authentication checks of client certificates may fail with the following error message:

Cert serial number 4294967295 status is revoked

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system has been configured with Certificate Revocation List Distribution Point (CRLDP) to check client certificates against a certificate revocation list.
  • A client presents a certificate with a 20-character hexadecimal string certificate serial number format.

In some instances, client certificates may fail the BIG-IP APM CRLDP certificate revocation check. The issue occurs when the BIG-IP APM system attempts to parse a client's certificate for authentication and is unable to parse the presented certificate serial number. Windows-issued 2008R2 CA (large certificates 32bits in length) can use a serial number that is formatted as a 20-character hexadecimal string. The BIG-IP APM system does not correctly parse this style of serial number representation, and subsequently fails the client's connection as a revoked certificate.

For example, when the BIG-IP APM system is presented with a certificate that has a serial number string like the one shown in the following example, the BIG-IP APM CRLDP check does not correctly parse this style of serial number (even when the client certificate is valid).

61 90 56 fd 00 00 00 00 00 2d

Impact

  • Client connections fail when accessing BIG-IP APM resources that are configured with CRLDP.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H424984 on the Diagnostics > Identified > Medium screen.
  • Client connections fail when accessing a BIG-IP APM resource that is configured with CRLDP.
  • Clients receive an error message stating that the certificate serial number 4294967295 has been revoked.
