Topic

Beginning in version 13.1.0, BIG-IP Edge Client lets administrators run a custom logoff script after users disconnect from Network Access VPN.

Description

As a BIG-IP APM administrator, you may need to perform various administrative tasks on your users' client devices after they disconnect from Network Access VPN. For example, these tasks may include:

  • Modifying the network proxy configuration.
  • Modifying network adapter settings.
  • Performing necessary cleanup tasks according to enterprise policy, such as removing the dial-up entry, temporary files, cookies, and cache.
  • Setting the client device at the correct security posture. For example, setting Windows registry values.

This logoff script feature is supported only on Windows and MAC client devices. Linux clients are not supported.

Procedures

To configure the BIG-IP Edge Client logoff script feature, perform the following procedures:

  • Configure the connectivity profile
  • Download and distribute the BIG-IP Edge Client package
  • Optional: Configure the APM session variable in the access policy
  • Create the logoff script on the client

Configure the connectivity profile

To enable the logoff script feature on the BIG-IP system, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity > Profiles.
  3. Select the connectivity profile that is associated to the network access virtual server.
  4. Select Edit Profile.
  5. Select Win/Mac Edge Client.
  6. To enable the logoff script feature on the client device, select the Run session log off script check box.
  7. Optional: For Windows clients, to display a pop-up security alert on the client device, select the Show warning to user before launching script check box.
  8. Select OK.

Download and distribute the BIG-IP Edge Client package

After updating the connectivity profile (previous procedure), you must download, distribute, and install or reinstall the new BIG-IP Edge Client package on every client device. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity > Profiles.
  3. Select the down arrow next to Customize Package.
  4. Select Windows or MAC as appropriate for your client devices.
  5. Configure the installation package and select Download.
  6. Distribute the package and install it as Administrator on the client devices.

Optional: Configure the APM session variable in the access policy

You can pass dynamic variables from the BIG-IP system to the client devices via the session.edgeclient.scripting.logoff.params APM session variable. To set the session.edgeclient.scripting.logoff.params session variable, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Access > Profiles / Policies > Access Profiles (Per-Session Policies).
  3. Next to the name of the access profile associated to the network access virtual server, select Edit.
  4. To assign a value to a session variable, select the Add icon at the appropriate stage in the login flow of the access policy, such as before the Resource Assign or Advanced Resource Assign policy item.
  5. Select the Assignment tab.
  6. Select the Variable Assign radio button.
  7. Select Add Item.
  8. Select Add new entry.
  9. Select change.
  10. To the left of Custom Variable, enter the following:

    session.edgeclient.scripting.logoff.params

  11. To the right of Custom Expression, enter the value you want to assign the variable. For example:

    concat "Hello [mcget {session.logon.last.username}] [mcget {session.client.platform}]"

  12. Select Finished and Save.
  13. Select Apply Access Policy.

Create the logoff script on the client

You should create your own logoff script and save it on each client device. Use the following example as appropriate for your client operating system:

Note: You must save your script with the exact file name and location specified in the procedure.

  • Windows:

    Open an editor and save the following example script in C:\Program Files (x86)\F5 VPN\scripts\onSessionTermination.bat:

    whoami >> %TEMP%\logoff-script.txt
    echo %date% %time%: Script location: %0. %1 %2, Client OS: %3 (More parameters if any after): %4 %5 %6... >> %TEMP%\logoff-script.txt

  • MAC:
  1. Open an editor and save the following example script in /Library/Application\ Support/F5Networks/EdgeClient/Scripting/onSessionTermination:

    Note: The backslash (\) character between “Application” and “Support” is required.

    echo "`date`: --Script Start -- by user `whoami`" >> ~/Library/Logs/F5Networks/logoff-script.txt
    echo Script location: $0. $1 $2, Client OS: $3. More parameters if any after: $4 $5 $6... >> ~/Library/Logs/F5Networks/logoff-script

  2. The system runs the script by using the privileges of the Network Access VPN user. Provide the user with execute privileges to the script. For example, enter the following command:

    chmod ug+x /Library/Application\ Support/F5Networks/EdgeClient/Scripting/onSessionTermination

Troubleshooting

To troubleshoot issues with running the logoff scripts, consider the following actions:

  • The system runs the logoff script by using the privileges of the VPN user. Ensure that the user has sufficient privileges to perform the administrative tasks you scripted.
  • You can include additional information in your script to log data such as dates, time stamps, and the dynamically generated APM session variables as parameters.
  • Verify the Edge Client logs on the client device by performing the following tasks as appropriate for your client operating system:

Windows: Verify %TEMP%\logterminal.txt by entering the following command:

type %TEMP%\logterminal.txt | findstr LogoffScript

MAC: Verify ~/Library/Logs/F5Networks/edge.log by entering the following command:

grep Logoff ~/Library/Logs/F5Networks/edge.log

Recommendations

When using this feature, you should consider the following:

  • The system can run the logoff script when the VPN user selects Disconnect or when a BIG-IP administrator ends the APM session. The system does not run the logoff script when there are external network issues, such as an unplugged network cable.
  • On Windows systems, you can configure an additional feature to present a security alert to the VPN user before the system runs the script. The security alert displays when either of the following conditions is met:
    • You selected the Show warning to user before launching script check box in the connectivity profile.
    • The fully qualified domain name (FQDN) of the BIG-IP network access virtual server is not on the Trusted sites list on the Windows client.
