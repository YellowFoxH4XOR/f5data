K000092709: tcpdump: pcap_loop: DMAA error, packets cannot be captured

Type
Support Solution
Published
2022-11-23
Updated
2022-11-24
Source
https://my.f5.com/manage/s/article/K000092709

Description


Tcpdump may be unusable and log an error after upgrading F5OS from v1.1 to v1.3. The error relates to the inability to connect to a DMAA socket.
  
# system diagnostics tcpdump
running /usr/sbin/tcpdump -nnn
tcpdump: verbose output suppressed, use -v or -vv for full protocol decode
listening on 0/0.0, link-type EN10MB (Ethernet), capture size 262144 bytes
 errbuf ERROR:DMAA error, packets cannot be captured
tcpdump: pcap_loop: DMAA error, packets cannot be captured
0 packets captured
0 packets received by filter
0 packets dropped by kernel

In addition, tcpdumpd is repeatedly logging the following to /var/F5/system/log/platform.log: 
appliance-1 tcpdumpd-manager[8]: priority="Crit" version=1.0 msgid=0x5406000000000029 msg="DMAA socket  failed:" comp="connect" errno=2.
appliance-1 tcpdumpd-manager[8]: priority="Crit" version=1.0 msgid=0x5406000000000029 msg="DMAA socket  failed:" comp="connect" errno=2.
appliance-1 tcpdumpd-manager[8]: priority="Crit" version=1.0 msgid=0x5406000000000029 msg="DMAA socket  failed:" comp="connect" errno=2.
 

Environment

  • F5OS
 

Cause

F5 is investigating this issue and tracking it under bug ID1188921
 

Recommended Action

Should tcpdump fail to run after an upgrade with the above errors, please reach out to F5 Support via a support case for further investigation.
