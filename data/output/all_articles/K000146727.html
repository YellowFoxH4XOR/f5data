Description

Router Monitoring is an additional feature where Distributed Cloud Services receive flow data directly from your router. If you are interested in turning on this feature, please contact your Technical Account Manager or Sales representative.

Netflow sends sampled data about the "flow" of traffic passing through the customer network to F5 Distributed Cloud Services Collectors. That data is analyzed in real-time, looking for known patterns indicating potential attacks, characterized by multiple signature types. The F5 Distributed Cloud Services Collectors SOC team uses this information to proactively mitigate attacks, protecting customer networks.

For the Router Monitoring feature, SNMP read-only access must be allowed to our collectors. Without SNMP access the feature will not be available and XC won't perform any configuration for Router Monitoring

 

Environment

  • F5® Distributed Cloud Console
  • DDoS
  • Local Router
  • Netflow v5 or v9

Cause

None

Answer/Recommended Actions

To configure local router monitoring with XC Services:

Step 1: Allow list the following on your local router:

  1. Distributed Cloud Services Edge IP(s): 
    1. DCA: 107.162.8.254, 
    2. SJC: 107.162.9.254, 
    3. FRA: 107.162.10.254, 
    4. SIN: 107.162.11.254, 
    5. LON: 107.162.15.254
  2. TCP/UDP port 161

Step 2: Open a ticket with the SOC with the following information:

  1. Confirmation that you Allowlisted the above list.
  2. IMPORTANT: Must identify which interfaces to listen on (usually the WAN interface)
  3. Exporter IP - this is the IP address of the router that will be monitored (to be used for SNMP & Netflow export)
  4. Distributed Cloud Services's Egde where you woul
  5.  like to send the Netflow data
    • Example traceroute:

  6. Confirm if you are using Netflow version v5 or v9 - Our collectors don't support other versions
  7. Confirm if SNMPv3 is supported on your devices, as we no longer support SNMPv2 on the Distributed Cloud platform.
    • Using SNMPv3, the following details are required: 
      • SNMP Security Level:
        • No authentication and no privacy (noAuthNoPriv)
        • Authentication and no privacy (authNoPriv)
        • Authentication and privacy (authPriv) 
      • SNMP Authentication Protocol
      • SNMP Authentication Username
      • SNMP Authentication Password
        • It is not recommended to use passphrases containing special characters. Example:  ! ` *.
      • SNMP Privacy Protocol (if applicable)
        • Currently, our collectors only support AES-128 for encryption.
        • Provide SNMP Privacy Key.
    • Must grant Read-Only access for the SNMP v3 user created
  8. SNMP community string (Optional, this can be generated by customer or SOC)
    • Must grant Read-Only access for the SNMP community string
  9. Confirm that the Sampling rate is set to 1:1000 (This is mandatory and can't be changed)
  10. Flow time out period
  11. Destination port (Netflow collector): Port 2055

Other Options

Restricting SNMP Access

  • The following MIBs are necessary if the customer wishes to refine the stats sent from their information-base: (Cisco)
    •  IF-MIB : 1.3.6.1.2.1.2.
    • HOST-MIB : .1.3.6.1.2.1.25.
    • SYSTEM-MIB : 1.3.6.1.2.1.1.1

Example: Device Specific Configuration

Cisco IOS Devices

flow record flow-to-f5xc

match ipv4 tos
 match ipv4 protocol
 match ipv4 source address
 match ipv4 destination address
 match transport source-port
 match transport destination-port
 collect transport tcp flags
 collect interface input
 collect interface output
 collect flow sampler
 collect counter bytes
 collect counter packets
 collect timestamp sys-uptime first
 collect timestamp sys-uptime last


 flow exporter export-to-f5xc
 description f5xc netflow v5
 destination $NETFLOW_COLLECTOR
 source $SOURCE_INTERFACE
 transport udp 2055
 export-protocol netflow-v5
 template data timeout 60
 option interface-table
 option exporter-stats
 option sampler-table

!

flow monitor monitor-to-f5xc
exporter export-to-f5xc
 cache timeout active 60
 statistics packet protocol
 record flow-to-f5xc
 !

sampler sampler-to-f5xc
 mode random 1 out-of 1000

interface $CUSTOMER_INTERFACE
 ip flow monitor monitor-to-f5xc sampler sampler-to-f5xc input

access-list 55 permit 107.162.8.0 0.0.3.255

snmp-server community $COMMUNITY ro 55
