Known Issue

This is the result of a known issue. When the qkview utility is performed, the bigpipe db variable for displaying service names is set to false (disabled).

Note: The default value of the bigpipe db variable for displaying service names is true (enabled).

When the display service names option is set to true, the bigpipe command will display the service name, rather than the port number.

For example:

  • port 80 will be displayed as HTTP
  • port 23 will be displayed as Telnet
  • port 21 will be displayed as FTP

F5 Networks Product Development tracked this issue as CR82268 and it was fixed in the qkview utility version 6.2.5. You can obtain the most recent version of qkview on the F5 Networks Downloads site by clicking BIG-IP 9.x, and selecting 9.x from the version drop-down menu.

Workaround

You can work around this issue by reverting the bigpipe db variable for displaying service names to true. To do so, type the following command:

bigpipe db Bigpipe.DisplayServiceNames true

Verifying your current display service names setting

To verify your current display service names setting, type the following command:

bigpipe db Bigpipe.DisplayServiceNames

The output will appear similar to the following example:

Bigpipe.DisplayServiceNames = true

Verifying your version of the qkview utility

To verify your version of the qkview utility, type the following command:

qkview -v

The command output will appear similar to the following example:

Thu Oct 01 01:23:00 PST 2007
Qkview v6.2.4 UPTIME: 09:12:13 up 2 days, 2:31, 2 users, load average: 0.15, 0.13, 0.10

Note: For more information, refer to K1858: Overview of the qkview utility.
