Description
You may face one time parity error in /var/log/bcm56xxd log:

Example-1;
[bcmMEM_SCAN.0]L3_DEFIP.ipipe0 failed(NAK)
[bcmDPC]unit 0 L3_DEFIP_DATA_ONLY entry XXXX parity error
[bcmDPC]SER_CORRECTION: reg/mem:YYYY btype:-1 sblk:0 at:3 stage:0 addr:0x00000000 port: 0 index: XXXX
[bcmDPC]mem: YYYY=L3_DEFIP_DATA_ONLY blkoffset:6
[bcmDPC]RESTORE[from Y pipe]: L3_DEFIP_DATA_ONLY[YYYY] blk: ipipe0 index: XXXX

Example-2;
[bcmMEM_SCAN.0]L3_DEFIP.ipipe0 failed(NAK)
[bcmMEM_SCAN.0]  SER Parity Check Error.
[bcmDPC]L3_DEFIP entry ZZZZ TCAM parity error
[bcmDPC]SER_CORRECTION: reg/mem:XXXX btype:6 sblk:0 at:0 stage:0 addr:0x00000000 port: 0 index: ZZZZ
[bcmDPC]mem: XXXX=L3_DEFIP blkoffset:6
[bcmDPC]CLEAR_RESTORE: L3_DEFIP[XXXX] blk: ipipe0 index: ZZZZ : [0][0]

Environment

  • BIG-IP appliance 

Cause
The log basically means, mainboard or memory encounter a temporary issue(SER Parity Check Error) and got self corrected(SER_CORRECTION,CLEAR_RESTORE).
 

Recommended Actions

If the error is not output continuously or there is no service impact, it should be benign and you can safely ignore the message.
If the error is logged continuously, it might be hardware failure, please contact F5 Support.
