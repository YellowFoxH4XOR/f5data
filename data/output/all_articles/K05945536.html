Description

Config doesn't load after upgrade with the following error: 

/var/log/ltm
err tmsh[<PID>]: 01420006:3: URL passed is invalid: Parsed text violates expected format
emerg load_config_files[<PID>]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- Loading schema version: 13.1.4.1
err mcpd[<PID>]: 01070425:3: Full configuration load failed.

Note: The same error might also show in /var/log/messages with details of the affected line number, from bigip.conf.

Environment

  • Upgrading
  • Config load

Cause

This happens when you have a certificate that contains one or all of the following characters in its name, or other offending characters: 

  • Open square bracket: [ 
  • Close square bracket: ] 
  • Pipe: | 

This is documented in Bug ID 765761: URI Parsing is failing when certificate name contains "[", "]"

Recommended Actions
  1. Check the line where the error presents, this can be known by reviewing /var/log/messages or when running "tmsh load sys config verify" by the following error line: Syntax Error:(/config/bigip.conf at line: 10385) URL passed is invalid: Parsed text violates expected format.
  2. Go to specific line on bigip.conf and change the name of the offending certificate or remove the config.
  3. Load the config again using the following command: tmsh load sys config.
