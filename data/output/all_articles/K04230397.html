Description

  • Monitor platform like Nagios could alert to an event similar to the following:

    Too many bigd running (# = 12)

  • On BIG-IP CLI you can see an output similar to the following when running ps | grep bigd

    8092 ?        S      0:02 runsv bigd
     8942 pts/0    S+     0:00 grep bigd
    15278 ?        S     18:09 /etc/bigstart/scripts/bigd.start --procs 12

Environment

  • BIG-IP
  • Multiple core system
  • bigd

Cause

The observed behavior is expected. Starting in v12.0, 'bigd' supports "multi-process" where several bigd instances are launched (based on the number of CPU cores available), and each 'bigd' process manages a subset of the monitors.  These 'bigd' processes are named, 'bigd.0', 'bigd.1', 'bigd.2', etc.
