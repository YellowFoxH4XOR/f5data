K000148365: How to exclude data for specific metrics in Telemetry Streaming

Type
Support Solution
Published
2024-11-01
Updated
2024-11-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000148365

Description

You would like to exclude specific metrics in TS (Telemetry Streaming) such that relevant statistics are forwarded to your consumer. Using TS excludeData option some metrics are filtered successfully, however, some metrics to be excluded continue to be sent to the consumer.

Environment

  • TS Data Modification

Cause

Nil

Recommended Actions

This steps discuss filtering a child data object, under pool.<pool name>.members.

  1.  Explore the data structure poll by enabling trace at Telemetry_System class. Refer to TS Tracing
    1. For instance, all of the serverside statistics under pool members have to be filtered. Examine the location of those statistics from /var/tmp/telemetry/<telemetry systempoller classname>

  1. Modify the TS declaration accordingly and POST the updated declaration.
{
  "class": "Telemetry",
  "My_System": {
    "class": "Telemetry_System",
    "trace": true,
    "systemPoller": {
      "actions": [
        {
          "excludeData": {},
          "locations": {
            "pools": {
              ".*": {
                "members": {
                  ".*": {
                    "serverside*": true
                  }
                }
              }
            }
          }
        }
      ]
    }
  }
}
