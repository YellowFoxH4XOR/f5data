Description

After configuring SAML authentication BIG-IP is showing the following APM log message:

/Common/accesspolicy.app/accesspolicy.com:Common:6acb9427: SAML Agent:

/Common/accesspolicy.app/accesspolicy.com_saml_auth_ag failed to process signed assertion, error: RSA decrypt

 

Environment

  • BIG-IP APM
  • SAML

Cause

It could be that cert automatically imported as part of metadata causing issues.

Recommended Actions

Try manually importing the cert and specify it in the external Idp connector.

None
