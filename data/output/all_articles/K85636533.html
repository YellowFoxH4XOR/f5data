Description

After upgrade to v14 or later, or reboot, BIG-IP VE version on Azure logs below:

warning:tm_install::DosPtable::scan_table-identification of/dev/sdb1 failed:ID is 7 null does not exist.

Environment

  • BIG-IP v14 and later
  • Azure
  • Reboot / Upgrade

Cause

  • Bug ID 832653

Recommended Actions

This message is benign as the devices boots up normally, so this message can be safely ignored.
