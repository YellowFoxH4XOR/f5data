Known Issue

In the event that the global license limit for the number of concurrent sessions has been reached, subsequent users may be denied access even if the license limit is no longer exceeded. The corresponding error message will also appear in the /var/log/apm file:

profile limit exceeded

This issue occurs when the total number of user accounts exceed the global license limit because the BIG-IP APM or Edge Gateway device does not properly update the session count after the limit has been reached.

F5 Product Development tracked this issue as ID 242176 (formerly CR133170-1) and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

F5 Product Development is tracking this issue as ID 315149 (formerly CR133170) for BIG-IP 10.1.0.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2 issued for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
