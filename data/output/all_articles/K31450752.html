K31450752: Big-IQ shows no devices after volume resize

Type
Support Solution
Published
2020-11-06
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K31450752

Description
After resizing he BIG-IQ CM and DCD the CM does not show the existing BIG-IP devices, instead showing 'There are no items to show in this view.'
On trying to re-add a device the administrator sees a message saying that the device is already trusted

Environment

  • BIG-IQ
  • Managed BIG-IP devices

Cause
Trust has failed between the BIG-IQ and the managed BIG-IP.

Recommended Actions

  1. Find the f5-rest-device-id of the BIG-IP
    SSH to the BIG-IP, navigate to /config, use 'cat f5-rest-device-id' to see the ID number for that BIG-IP

  2. Set variables in the local environment required to run the command:

    IP=<IP_TARGET_BIGIQ>
    USERNAME=<USER_NAME>
    PASSWORD=<PASSWORD>

    Example:

    IP=192.0.2.50
    USERNAME=admin
    PASSWORD=ExAmP1EpAsSwOrD

  3. Get auth token and save in a variable:
    Note: The token expires after 5 minutes.

    TOKEN=$(curl -sk -H "Content-Type: application/json" https://${IP}/mgmt/shared/authn/login -X POST -d '{"username": "'$USERNAME'","password":"'$PASSWORD'","loginProviderName": "tmos"}' | jq '.token.token' | tr -d '"')

  4. Find the UUID from step #1 and save it in a variable:

    UUID=<uuid>

    Example:

    UUID=caf1981c-db31-4e66-bb11-e8cb7b005fbb

  5. Save POST data to a variable that will be used to make the request to remove all Services:

    POST_BODY=$( echo '{"moduleList":[{"module":"adc_core"},{"module":"access"},{"module":"asm"},{"module":"fps"},{"module":"firewall"},{"module":"security_shared"},{"module":"dns"}],"deviceReference":{"link":"https://localhost/mgmt/cm/system/machineid-resolver/'$UUID'"},"createChildTasks":true,"name":"remove_all_services_'${UUID}'"}')

  6. Make a request to remove all Services for the device:

    curl -sk -H "Content-Type: application/json" -H "X-F5-Auth-Token: ${TOKEN}" https://${IP}/mgmt/cm/global/tasks/device-remove-mgmt-authority -X POST -d $POST_BODY | jq .

  7. Save POST data to a variable that will be used to make the request to remove the device:

    POST_BODY=$(echo '{"deviceReference":{"link":"https://localhost/mgmt/cm/system/machineid-resolver/'$UUID'"},"name":"device-remove-'${UUID}'"}')

  8. Make POST request to remove the device:

    curl -sk -H "Content-Type: application/json" -H "X-F5-Auth-Token: ${TOKEN}" https://${IP}/mgmt/cm/global/tasks/device-remove-trust -X POST -d $POST_BODY | jq .

  9. Re-discover the BIG-IP device and import the configuration as needed
