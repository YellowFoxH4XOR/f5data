OpenSSL requires a configuration file (generally named openssl.cnf or openssl.conf) to use for basic defaults. The BIG-IP OpenSSL configuration file is named /config/bigconfig/openssl.conf.

To configure OpenSSL on the BIG-IP system, use the BIG-IP OpenSSL configuration file by typing the following command:

openssl <method> -config /config/bigconfig/openssl.conf

For example:

openssl req -config /config/bigconfig/openssl.conf
