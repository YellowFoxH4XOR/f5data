K7287: Pre-logon sequence check for registry key fails if user has no read permissions

Topic

If you configure the Windows registry checker to check for the existence of a registry key on a client system, the user must have read permissions on the registry key in order to pass the pre-logon check. If the user does not have read permissions on the registry key, the user is directed to the fallback action you configured for the Windows registry checker in the pre-logon sequence.

Viewing registry key permissions

To view the permissions on a registry key, perform the following procedure:

  1. Log in to the Windows client system.
  2. Open the Windows registry using the regedit program.
  3. Locate the registry key you want to check.
  4. Right-click the registry key and select Permissions... from the menu.
