Description

You are attempting to assign more than one role (e.g., Certificate Manager, Auditor) to a remote role group in BIG-IP to provide granular control.

Environment

  • BIG-IP system

Cause

By design, you cannot assign multiple roles to a remote role group in BIG-IP.

Recommended Actions

To manage this scenario, consider using BIG-IQ for Role-Based Access Control (RBAC) to provide granular control over user permissions. This requires BIG-IQ integration.

Additional Information

For more information on role-based user access in BIG-IQ, refer to Manual Chapter: About role-based user access
