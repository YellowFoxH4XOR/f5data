Issue

Description

Hotfix installation can stuck with a message "Waiting for image" showing in Configuration Utility

  • In the "Details" section you can see following status description 
    waiting for cleanup; multiple base builds found (BIG-IP <main version>)
  • In tmsh you can see similar message as above. Please see an example below. 
    tmsh show sys software status

-------------------------------------------------------------------------------------------------------------
Sys::Software Status
Volume  Product   Version    Build  Active                                                             Status
-------------------------------------------------------------------------------------------------------------
HD1.1    BIG-IP  13.1.3.2   0.49.4     yes                                                           complete
HD1.2    BIG-IP  13.1.1.4   0.97.4      no  waiting for cleanup; multiple base builds found (BIG-IP 13.1.3.2)

Environment

  • Regular or Critical hotfix installation without installing main release
  • You have two or more ISO files with the same main version on the disk. Please see an example below. Version 13.1.3.2 is the same version and build number for two different files. 
    tmsh list sys software image
sys software image TEST-13.1.3.2.iso {
    build 0.0.4
    build-date "Tue Nov 5 18 45 57 PST 2019"
    checksum fd872d11e00a74cee88a91c476059c49
    file-size "2075 MB"
    last-modified "Mon Aug 31 19:58:17 2020"
    product BIG-IP
    verified yes
    version 13.1.3.2
}
sys software image BIGIP-13.1.3.2-0.0.4.iso {
    build 0.0.4
    build-date "Tue Nov 5 18 45 57 PST 2019"
    checksum fd872d11e00a74cee88a91c476059c49
    file-size "2075 MB"
    last-modified "Mon Aug 24 17:49:41 2020"
    product BIG-IP
    verified yes
    version 13.1.3.2
}

Cause
While installing hotfix image without installing main image, the system needs to install main image prior to hotfix installation. The BIG-IP tries to find if any ISO file of the main image does exist in /shared/images directory. If there are two or more ISO image file for the same main version exist on the disk, the system is not able to select which one to use and upgrade process stuck

Recommended Actions

Either way below should fix the issue.
  • Install main version before installing hotfix
  • Delete duplicate ISO images from the system
