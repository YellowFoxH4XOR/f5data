K11101: Configuring the SSO credential mapping action to remove the domain name from a username

Topic

You can add the single sign-on (SSO) credential mapping action to an access policy to automatically forward user credentials to applications and servers. Since different applications and resources support different authentication mechanisms, the SSO system may be required to store and translate credentials that differ from the credentials supplied on the logon page.

When Active Directory authentication is enabled in an access policy, users may use the format username, DOMAIN\username, or username@domain when logging in to the BIG-IP APM system. If the back-end application you configured for SSO does not support the format DOMAIN\username or username@domain, you can configure the SSO credential mapping action to strip the domain name from the username.

Beginning in version 10.2.0 you can configure the BIG-IP to remove the domain information from a username in SSO credential mapping by selecting the Username Conversion Enable check box. In BIG-IP versions prior to 10.2.0, perform the following procedure:

Note: This procedure assumes that you have a working access policy that uses the SSO Credential Mapping action. For information about configuring an access policy, refer to the Configuration Guide for BIG-IP Access Policy Manager.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Access Policy.
  3. Click Access Profiles.
  4. Next to the access policy you want to configure, click Edit.

    The visual policy editor opens.
  5. Click the SSO Credential Mapping action you previously configured.
  6. In the SSO Token Username menu, select Custom.
  7. In the SSO Token Username text field, enter one of the following three expressions:

    To remove <DOMAIN>\ from the beginning of user names:

    [regsub {(.+\\|^)}  [mcget {session.logon.last.username}] "" x; set username $x]

    To remove @<domain> from the end of user names:

    [regsub {(\@.+)}  [mcget {session.logon.last.username}] "" y; set username $y]

    To remove both <DOMAIN>\ and @<domain> from user names:

    [regsub {(.+\\|^)}  [mcget {session.logon.last.username}] "" x; set username $x; regsub {(\@.+)} $username "" y; set username $y]
     
  8. Click Save.
  9. Click Apply Access Policy.

F5 Product Development considered this request for enhancement (RFE) to allow the SSO credential mapping action to support the user name formats DOMAIN\username and username@domain without additional customization. F5 Product Development tracked this RFE as ID 242512 (formerly CR134118) and has been added beginning in version 10.2.0.
