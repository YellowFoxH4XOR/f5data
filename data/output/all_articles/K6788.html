Known Issue

This is the result of a known issue. When using the Dynamic Ratio load-balancing method for a pool containing two or more links, the throughput statistics for the links do not match the Link Ratio settings. When this issue is present, you may observe behavior such as all traffic traversing one of the links.

F5 Product Development tracked this issue as CR69985 and CR69986, and it was fixed in BIG-IP Link Controller 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP Link Controller Release Notes.
