Issue

Starting in BIG-IP APM and Edge Gateway 10.2.1 (and 10.1.0 with HotFix-BIGIP-10.1.0-3402.0-HF2 installed and 10.2.0 with Hotfix-BIGIP-10.2.0-1755.1-HF1 installed), the processing of URLs is more efficient. The BIG-IP system now creates a per session cache, rather than performing a session database query each time a URL is accessed.

F5 Product Development tracked this request for enhancement as ID 226569 (formerly CR141782) and it was added in BIG-IP APM 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

This feature enhancement was introduced in HotFix-BIGIP-10.1.0-3402.0-HF2 for version 10.1.0 and Hotfix-BIGIP-10.2.0-1755.1-HF1 for 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
