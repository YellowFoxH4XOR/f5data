Description

You want to know if a different IP address than the one configured as a DNS primary can send NOTIFY requests

Environment

  • DNS Management

Answer

No,

NOTIFY requests do not have to come from the host that is configured as the primary nameserver. However, we will only perform zone transfer from the configure primary server(s).

Additional Information

Sending NOTIFY from a host that is not configured as the primary DNS server is not a standard behavior and is generally not supported by most DNS implementations.
