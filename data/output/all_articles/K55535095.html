K55535095: Configuring the BIG-IP DNS system to return multiple pool resources in a DNS response

Type
Knowledge
Published
2017-08-31
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP DNS: 13.0.0
Source
https://my.f5.com/manage/s/article/K55535095

Topic

You should consider using this procedure under the following condition:

  • You want to configure the wide IP to return multiple pool resources (resource records) in a DNS response.

Description

In BIG-IP DNS (formerly known as BIG-IP GTM) prior to 13.0.0, you can configure the system to return a maximum of 16 pool resources (resource records) in a response.

In BIG-IP DNS 13.0.0 and later you can configure the system to return up to 500 pool resources in a response by modifying the Maximum Answers Returned GSLB pool setting. You can configure the Maximum Answers Returned setting for the following record types:

  • A
  • AAAA
  • MX
  • SRV
  • NAPTR

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access the Configuration utility or TMOS Shell (tmsh).

Procedures

Using the Configuration utility to configure the BIG-IP DNS system to return multiple pool resources in a DNS response

Impact of procedure: Configuring the system to return larger DNS packets may result in truncated responses or lower throughput capacity.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Pools > Pool List.
  3. Click Create.
  4. In the Name box, type a name for the pool object.
  5. From the Type menu, select the appropriate record type.
    For example:

    NAPTR

  6. In the Maximum Answers Returned box, type the maximum number of available virtual servers that you want the system to return in a response.

    Note: The maximum value is 500.

  7. Complete the remaining pool settings.
  8. Click Finished.
Using tmsh to configure the BIG-IP DNS system to return multiple pool resources in a DNS response

Impact of procedure: Configuring the system to return larger DNS packets may result in truncated responses or lower throughput capacity.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Create the GSLB pool object using the following syntax:

    create /gtm pool <record_type> <pool_name> members add { <virtual_server> <virtual_server> etc } max-answers-returned <1-500>

    For example, the following command creates a pool named GSLB_pool with five pool members and a maximum answers returned value of 5:

    create /gtm pool a GSLB_pool members add { BIGIP-1:/Common/vip1 BIGIP-1:/Common/vip2 BIGIP-1:/Common/vip3 BIGIP-1:/Common/vip4 BIGIP-1:/Common/vip5 } max-answers-returned 5

  3. Save the configuration by typing the following command:

    save /sys config
