Known Issue

The Traffic Management Microkernel (TMM) may restart and produce a core file when processing a FLOW_INIT iRules event.

This issue occurs when the following condition is met:

  • A TCL method executed in a FLOW_INIT event returns an error.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting, and devices configured as a high availability (HA) pair may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting.
  • If configured for HA, the affected BIG-IP device fails over to a configured peer device.
  • The system generates a TMM core file to the /shared/core directory.
  • Your BIG-IP system logs an error message to the /var/log/tmm file that appears similar to the following example:

    notice ** SIGABRT **

  • In the /var/log/ltm file, you observe error messages that appear similar to the following example:

    TCL error: /Common/iRule2 <FLOW_INIT> - no listener /Common/VS3 (line 1) invoked from within "FLOWTABLE::limit virtual $vs_name"
