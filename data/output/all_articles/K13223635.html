Description

Configuration Utility (GUI) shows a banner with the following error message.

This device is not operational because the loaded configuration contained errors or unlicensed objects. Please adjust the configuration and/or the license, and re-license the device.

Environment

The following conditions must be met:

  • The device is operational either in ACTIVE or STANDBY state.
  • All objects are available.
  • CLI does not show that the device configuration is not loaded.

Cause

This is related to Bug ID 662301: 'Unlicensed objects' error message appears despite there being no unlicensed config.

Recommended Actions

You will need to restart MCPD banner error message.

  1. CLI to the device and run the following command.

    # bigstart restart mcpd

  2. After the restarting MCPD service, the banner should be cleared.

For Viprion bladed systems, MCPD needs to be restarted on all blades. Note this will cause all blades in the Viprion cluster to go down.
  1. Restart MCPD on all blades using .

    # clsh "bigstart restart mcpd"

  2.  After restarting the MCPD service, the banner should disappear.

For vCMP Guest,
  1. Restart MCPD on vCMP guest.

    # bigstart restart mcpd

  2.  If the issue is not resolved after restarting MCPD, follow the below steps. 
  3. Login to the GUI of the vCMP Host system.
  4. Change the vCMP guest to configured state.
  5. Change the  vCMP guest back to deployed state.
  6. Login to vCMP guest using GUI and the banner should be cleared.
