Topic

You should consider using this procedure under the following condition:

  • You need to deploy a vCMP guest on the BIG-IP 10200v platform.

Description

Beginning with BIG-IP 11.3.0 HF5, you can license and provision vCMP on a BIG-IP 10200v platform and deploy vCMP guests running BIG-IP 11.3.0 HF5 or later. If you attempt to deploy a vCMP guest on the BIG-IP 10200v platform running BIG-IP 11.3.0 with no hotfixes or with hotfixes prior to HF5, the system does not allow you to license and provision. In addition, the system reports an error message similar to the following example:

010715ff:3: Invalid configuration for vCMP (myguest)

To deploy a vCMP guest on a BIG-IP 10200v platform, you must perform the following tasks:

  1. First, upgrade the vCMP host to BIG-IP 11.3.0 HF5 and boot to the upgraded slot.
  2. Next, when the vCMP host is up and running BIG-IP 11.3.0 HF5, configure, provision, and deploy a vCMP guest with the base version of BIG-IP 11.3.0.
  3. Then, when the vCMP guest is up and running, upgrade each vCMP guest to BIG-IP 11.3.0 HF5 using its own Software Management module.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have a BIG-IP 10200v platform running BIG-IP 11.3.0 and licensed and provisioned with vCMP.
  • You must have a copy of the following images:
    • BIGIP-11.3.0.2806.0 software image (for vCMP guest)
    • Hotfix-BIGIP-11.3.0-3117.0-HF5 hotfix image (for both vCMP host and guest)

Procedures

  • Upgrading and booting the vCMP host to BIG-IP 11.3.0 HF5
  • Configuring, provisioning, and deploying a vCMP guest with base BIG-IP 11.3.0
  • Upgrading and booting the vCMP guest to BIG-IP 11.3.0 HF5

Upgrading and booting the vCMP host to BIG-IP 11.3.0 HF5

Note: If your BIG-IP 10200v platform is already running BIG-IP 11.3.0 HF5, you can skip this procedure and proceed to the next procedure.

Impact of procedure: The BIG-IP system is be unavailable during the system restart.

  1. Log in to the Configuration utility of the vCMP host.
  2. Navigate to System > Software Management > Hotfix List > Import.
  3. For Software Image, click Choose File.
  4. Browse to the location of the Hotfix-BIGIP-11.3.0-3117.0-HF5 hotfix image and choose it.
  5. Click Import.
  6. When the hotfix image is uploaded successfully, check the Hotfix-BIGIP-11.3.0-3117.0-HF5 hotfix image and click Install.
  7. In the Install Software Hotfix dialog box, select or type a Volume set name. For example, to install the HF5 to a new volume MD1.4, type 4 in the Volume set name.
  8. Click Install.
  9. When the upgrade is complete, navigate to System> Software Management > Boot Locations.
  10. Click the boot location that contains BIG-IP 11.3.0 HF5. Using the previous example, click MD1.4.
  11. Click Activate to restart the system and boot to the newly upgraded slot on the vCMP host.
  12. Click OK to confirm and wait for the vCMP host to completely boot.

Configuring, provisioning, and deploying a vCMP guest with base BIG-IP 11.3.0

Impact of procedure: None.

  1. Log in to the Configuration utility of the vCMP host.
  2. Click vCMP.
  3. Click Guest List.
  4. Click Create.
  5. For the Initial Image setting, click BIGIP-11.3.0.2806.0.iso.
  6. For Requested State, click Provisioned.
  7. Enter the rest of the settings as needed.
  8. Click Finish.
  9. When the system has completed provisioning for the vCMP guest, check on the vCMP guest and click Deploy.

Upgrading and booting a vCMP guest to BIG-IP 11.3.0 HF5

Impact of procedure: The vCMP guest undergoing upgrading is unavailable during system restart.

  1. Log in to the Configuration utility of the vCMP guest.
  2. If the vCMP guest is started for the first time, it may run the Setup Utility. Proceed with the Setup Utility with the configuration you want.
  3. Navigate to System > Software Management > Image List > Import.
  4. Click Choose File and choose the BIGIP-11.3.0.2806.0 software image.
  5. Click Import.
  6. When the software image is uploaded successfully, navigate to System> Software Management > Hotfix List > Import.
  7. Click Choose File and choose the Hotfix-BIGIP-11.3.0-3117.0-HF5 hotfix image.
  8. Click Import.
  9. When the hotfix image is uploaded successfully, check the Hotfix-BIGIP-11.3.0-3117.0-HF5 hotfix image and click Install.
  10. In the Install Software Hotfix dialog box, click or type a Volume set name. For example, to install HF5 to a new volume HD1.2, type 2 in Volume set name.
  11. Click Install.
  12. When the upgrade is completed, navigate to System > Software Management > Boot Locations.
  13. Click the boot location that contains BIG-IP 11.3.0 HF5. Using the previous example, click HD1.2.
  14. Click Activate to restart the system and boot to the newly upgraded slot on the vCMP guest.
  15. Click OK to confirm and wait for the vCMP guest to completely boot.
