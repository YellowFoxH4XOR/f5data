Description

When running the F5 BIG-IQ Pre-Upgrade-Check Tool (versions v9 and v12),  the script may fail with error below 

    * Running CPU, Memory and disk space compatibility checks for DCD node 192.168.1.1
    ********************************************************************************
    Provide the root account password if prompted.
    Traceback (most recent call last):
     File "./preUpgradeCheck", line 1023, in <module>
      sys.exit(main())
     File "./preUpgradeCheck", line 1010, in main
      runDiskSpaceChecks(session)
     File "./preUpgradeCheck", line 892, in runDiskSpaceChecks
      with SshConnection(ip, account, 22) as conn:
     File "./preUpgradeCheck", line 109, in __init__
      self._start_master_proc()
     File "./preUpgradeCheck", line 205, in _start_master_proc
      "ssh connection failed, exit code: %d" % master_rc)
    Exception: ssh connection failed, exit code: 255

    Environment

    • Product: F5 BIG-IQ Centralized Management
    • Version: 7.1.0 (upgrade target version 8.4; upgrade path is 7.1 > 8.0 > 8.4)
    • Platform: F5-BIQ-VE-LOG-NODE
    • Pre-upgrade tool versions tested: v9 and v12

    Cause

    • The script fails when trying to SSH from CM to DCD, the failure (no matching cipher found) is due to mismatched SSH cipher suites between BIG-IQ CM and DCD

    Recommended Actions

    • SSH Cipher Mismatch:
      Update SSH client ciphers on BIG-IQ to match server requirements if you see a cipher mismatch error.
      Refer to K21770469: Changing supported SSH ciphers on F5 products . Note: You may need to add or remove ciphers from /etc/ssh/ssh_config or /etc/ssh/sshd_config depending on your security policy and upgrade requirements.
