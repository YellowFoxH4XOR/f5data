K4173: FirePass memory utilization increases even when there are no active sessions

Source

Topic

FirePass memory utilization will increase, even when there are no active sessions. This behavior is most likely the result of FirePass caching frequently-used code. The kernel will not release memory as long as there is memory available for use.

This behavior optimizes performance.
