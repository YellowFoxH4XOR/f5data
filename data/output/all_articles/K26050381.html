Issue

Error Message

warning tmm[<PID>]: 01230001:4: Interface <Interface.Identifier>: link is up, <Speed>Mbps <Duplex>

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <Interface.Identifier> is the interface that is reporting its link is up.
  • <Speed> is the interface speed in Mbps that the interface is reporting.
  • <Duplex> is the duplex setting that the interface is reporting.

For example:

warning tmm[15344]: 01230001:4: Interface 0.2: link is up, 1000Mbps Full Duplex

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • On startup, the informational message appears about an internal interface link status.

Impact

None

Recommended Actions

None
