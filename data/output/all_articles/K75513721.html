Known Issue

The default Client SSL profile does not support multiple key/cert pairs.

This issue occurs when the following condition is met:

  • You are trying to access multiple key/cert pairs from a virtual server with a default Client SSL profile.

Impact

The default Client SSL profile supports only one key/cert pair that is stored in the key/cert/chain/passphrase profile. Selecting the cert/key pair from the cert-key-chain configuration may return unexpected results.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system returns incorrect results for a default Client SSL profile when you select a cert/key pair from the cert-key-chain configuration.
