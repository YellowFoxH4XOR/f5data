Description

When configuring TACACS+ authentication to authenticate BIG-IP administrative users, authentication is failing and below messages are logges in /var/log/secure logs :

  • pam_tacplus: (pam_tacplus) converse returned 19
  • pam_tacplus: that is: Conversation error
  • pam_tacplus: unable to obtain password
  • pam_unix(sshd:auth): conversation failed
  • pam_unix(sshd:auth): auth could not identify password for [username]

Environment

  • BIG-IP
  • TACACS+ authentication configured for admin users including local root and admin accounts.

Cause

Authentication fails when authentication server fails to validate password or user. 

Recommended Actions

Check below steps in case of above errors: 

  1. Make sure TACACS+ secret is similar on LTM and TACACS+ authentication server.
  2. The TACACS+ secret key must not contain the number sign (#). Please refer: K12304
  3. Make sure ACS group name/attribute match with the configuration on LTM for TACAS+.
