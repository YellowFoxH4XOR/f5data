K000156580: Updating SSL certificate and chain using F5 Modules for Ansible may briefly impact traffic

Type
Support Solution
Published
2025-09-23
Updated
2025-09-23
Applies to
  • F5 Automation and Orchestration
  • F5 Modules for Ansible
Source
https://my.f5.com/manage/s/article/K000156580

Description

When updating SSL certificates, keys, and chains on F5 BIG-IP devices using the F5 Ansible collection (imperative modules), a brief period of application unavailability can occur. This is due to a mismatch between the certificate and chain files during the update process, as separate Ansible tasks are required to update each component. The imperative Ansible collection does not currently support updating the certificate, key, and chain in a single atomic operation.

Environment

  • Product: F5 BIG-IP
  • Modules: F5 Ansible Collection (imperative modules: bigip_ssl_key_cert, bigip_ssl_certificate, bigip_profile_client_ssl)

Cause

Separate tasks are required to import the certificate/key and the chain when using imperative F5 Ansible modules. This results in a short window where the certificate and chain are not synchronized, potentially causing SSL handshake failures or temporary application downtime.

Recommended Actions

  1. Temporary SSL Elements Approach
    • Create new temporary SSL certificate, key, and chain objects with unique names (e.g., add a -temp suffix).
    • Update the client SSL profile to use these temporary objects.
    • Update the original certificate, key, and chain files.
    • Switch the client SSL profile back to reference the original objects.
    • Remove temporary objects if no longer needed.
  2. Chain Overlap Approach
    • Add both old and new intermediate certificates to the chain file before updating the cert/key.
    • Perform the cert/key update.
    • Remove old intermediate certificates from the chain after completion.
    • Note: Some clients may not properly handle superfluous certificates in a chain; test this approach extensively in your environment.
  3. Use Declarative AS3 via Ansible
    • Use Application Services 3 Extension (AS3) with declarative Ansible (bigip_as3_deploy).
    • AS3 enables updating certificate, key, and chain in a single transaction for atomic changes without mismatch windows.
