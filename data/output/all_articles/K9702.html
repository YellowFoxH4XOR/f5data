Topic

You can clear an IP address restriction if you have been locked out from accessing the FirePass Administrative Console. If the IP address you are attempting to connect from locks you out from accessing the FirePass Administrative Console, you will receive the following error message:

Access to the Administrative Console is not allowed from this IP address 10.10.10.10

This issue may occur if you incorrectly define the IP address as restricted, or change the IP address that you are trying to connect from.

Note: The IP address listed will show the IP address that the FirePass device sees you trying to connect from. The NAT translated IP address will show the translated IP address, rather than the IP address of your workstation.

To clear this message, perform the following procedure:

  1. Connect to the FirePass Maintenance Console.

    Note: For more information, refer to K9286: Access the FirePass Maintenance Console.
  2. Use the down arrow to select Remove IP-access and/or Client cert restrictions for Admin Console.
  3. Select OK.
  4. Select 1 Remove IP-access restriction for Admin Console.
  5. Select OK.  

To apply a new IP address restriction, go to Device Management: Security: Admin Access Security and populate the applicable information.
