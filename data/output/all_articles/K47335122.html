Known Issue

BIG-IP ASM Event Logs Requests report filters may return unexpected results.

This issue occurs when the following condition is met:

  • You filter the BIG-IP ASM Event Logs Requests report by using the Violation filter.

Impact

When attempting to filter the BIG-IP ASM Event Logs Requests report, the Violation filter fails to return the expected results.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Filtering the BIG-IP ASM Event Logs Requests report, for requests that match some violations, returns unexpected results.
