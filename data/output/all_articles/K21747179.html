Description

Endpoint Inspection uses regularly updated libraries from OPSWAT to check for compliance in an Access Policy. The OPSWAT libraries are licensed and these licenses can expire. 
An EPSEC version using an expired license will cause endpoint inspection to fail with an error logged in /var/log/apm: 

Sep  6 19:49:13 bigip.local info apmd[5136]: 01490007:6: /Common/access_policy:Common:8fadbf9a: Session variable 'session.check_software.last.av.item_2.errors' set to 'Failed to get 'last_scan'. code: -12 method: 1004 define: 'WAAPI_ERROR_COMPONENT_METHOD_NOT_IMPLEMENTED' description: 'Defines an error when a method call was made on a component that does not implement it.' '

The client log logterminal.txt will log an error: 
2021-09-02, 2:55:34:927, 13632,8624,OesisInspector4, 1, \ProductFinder.h, 188, ProductFinder:Run(), Exception occurred. Error=Init failed:{},result=error=Init%20failed%3a%7b%7d

Environment

  • APM Access Policy with one or more endpoint inspection agents
  • EPSEC Versions prior to and including 1.0.0-969.0 

Cause

The OPSWAT packages before version 1.0.0-969.0 contain a license that expired on 2 September 2021

Recommended Actions

Upgrade to a version newer than version 1.0.0-969.0 (the latest version is recommended)

Note that current BIG-IP maintenance versions ship with an affected version (v928), and need to be updated after upgrading to that BIG-IP version.

Additional Information

Recently, new versions of EPSEC are released every 2 months.
Versions between 1.0.0-969.0 and 1.0.0-1025.0 will expire in Feb 2023.
