K000149571: Misleading error "Image with the same name already exists" when customizing the APM logon page

Type
Support Solution
Published
2025-03-06
Updated
2025-03-06
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149571

Description

  • You'd like to upload a new image to customize the Edge Client logon page or change the branding
  • "Image with the same name already exists" error is observed, even though the file name is unique

Environment

  • Personalized client page

Cause

The "Image with the same name already exists" error message can be misleading, as it suggests a problem with the file name uniqueness. However, the actual cause may be a lack of available space on the /var partition. When the /var partition is full, the system cannot save new files, leading to this confusing error message. 

Recommended Actions

To resolve this issue, check the available disk space on the /var partition and free up space if necessary.

For detailed steps on how to extend the /var disk space on appliances, refer to the instructions provided in article K34126971: Extending /var disk space on appliances.
