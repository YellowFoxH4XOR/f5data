Known Issue

ZoneRunner may not produce an error when you add a resource record and your attempt fails.

This issue occurs when all of the following conditions are met:

  • You add a new resource record using ZoneRunner by way of the Configuration utility.
  • The resource record is invalid in the context of the BIG-IP GTM configuration.

     For example, the record would be invalid when you attempt to add a resource record type of delegation signer (DS) when subdomain delegation is not configured.

Impact

The system does not create a resource record.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When creating an invalid resource record through ZoneRunner, you receive no notification when the system fails to create the record.
  • You are unable to locate the newly-created resource record when you query the BIG-IP GTM system for the record.
