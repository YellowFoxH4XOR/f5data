Known Issue

This is the result of a known issue. If a FirePass 4100 controller's switch port is set to a fixed speed and full-duplex mode, and the interface on the connected switch's interface has a similar configuration, the FirePass switch port may run in half-duplex mode. As a result, network performance may degrade significantly.

You can view or configure the speed and mode of FirePass 4100 switch port interfaces on the Interfaces tab of the Device Management : Configuration : Network Configuration page. When the interface's Speed/Mode setting is 100Mbps/Full Duplex, and the interface is connected to a switch on a port that is also configured to 100 Mb/sec, full-duplex, the FirePass controller's port may run in half-duplex mode, even though the Show Current Speed/Mode settings for Network Devices option on the Interfaces tab states that the interface is running in full-duplex mode. The primary symptoms are a degradation of network performance through that FirePass interface, and errors displayed in the statistics for the port on the connected switch, such as elevated collision levels.

F5 Product Development tracked this issue as CR72669 and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by setting both the FirePass controller's interface and the connected switch's interface to auto-negotiate speed and mode. Typically, this configuration will result in a speed of 100 Mb/sec and a mode of full-duplex, thus providing the same performance and functionality as manually setting the speed and mode.
