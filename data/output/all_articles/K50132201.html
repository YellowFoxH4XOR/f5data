K50132201: Creating and mailing scheduled reports from BIG-IQ

Applies to

Source

Description
To schedule and email statistics reports.

Environment

  • BIG-IQ version 8 and later

Cause
To schedule and email statistics reports from BIG-IQ

Recommended Actions

  1. To email statistics reports, you must first configure an SMTP server.  To configure SMTP servers, go to System > THIS DEVICE > SMTP Configuration.
  2. Go to Monitoring > DASHBOARDS and select one of the Analytics Dashboards. These are dashboards that receive traffic and service module statistics from Application Visibility and Reporting.  (L7 Dashboard, Bot Traffic Summary and DDoS Protection Summary are not Analytics Dashboards.)
  3. Click Export & Schedule Report from the top right of the screen and select Schedule.  The Create Scheduler screen displays settings.
  4. In the Name field, enter a unique name to identify the purpose or service data contained in the report. 
  5. In the Emails field, enter the email address(es) of the statistics report recipients.
  6. To configure the report schedule, enter the Start Date and the Start Time.
  7. Configure the End Date for scheduled reporting.
  8. From the Frequency field, select how often you want the system to create statistics reports.
  9. From the Retention Policy field, select the number of dats you would like the system to save each statistics report before it is deleted.
  10. Click Create
The system will now generate, export and save statistics reports according to your configured settings.
