Description

An SSH connection to BIG-IP fails when using HostKeyAlgorithms ssh-rsa with an error like below.

# ssh -oHostKeyAlgorithms=ssh-rsa <IP_of_BIG-IP>
Unable to negotiate with <IP_of_BIG-IP> port 22: no matching host key type found. Their offer: rsa-sha2-512,rsa-sha2-256,ssh-ed25519

 

The same issue occurs even after following K49586523: Modifying the host key algorithms used by the ssh server on the BIG-IP to add HostKeyAlgorithms ssh-rsa explicitly.

Environment

  • Try to connect BIG-IP using SSH
  • The following command output contains ssh-rsa
    sshd -T | grep -i hostkeyalgorithms

Cause

As part of the fix of ID 1238693 for FIPS mode, F5 removed support of ssh-rsa as a host key algorithm. However, the change also affected non-FIPS mode.

Recommended Actions

Avoid using ssh-rsa host key algorithm and use other supported host key algorithms.​​​​​​
