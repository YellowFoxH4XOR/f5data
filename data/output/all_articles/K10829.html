Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator does not correctly parse certain headers, such as Content-type and Content-disposition headers, returned from a Microsoft Exchange 2010 server. When this behavior occurs, the BIG-IP WebAccelerator may match content with the wrong policy node.

F5 Product Development tracked this issue as CR130879 and it was fixed in BIG-IP WebAccelerator version 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-9.4.8-379.3-HF1 issued for BIG-IP version 9.4.8 and in Hotfix-BIGIP-10.0.1-378.0-HF3 issued for BIG-IP version 10.0.1. You may download these hotfixes or later versions of these cumulative hotfixes from the F5 Downloads site.
