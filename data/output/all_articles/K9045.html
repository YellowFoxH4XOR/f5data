Known Issue

This is the result of a known issue. When a user launches a Citrix Metaframe Terminal Server favorite, from the FirePass webtop, the user’s browser window may freeze for several seconds while the Citrix ICA Client loads. This issue occurs when the Enable session reliability check box is selected in the Terminal Server favorite configuration.

Note: Terminal Server favorites are configured on the Application Access > Terminal Servers > Resources page in the FirePass Administrative Console.

F5 Product Development is tracking this issue as CR80135. 

Workaround

You can work around this issue by disabling session reliability for the Citrix MetaFrame Terminal Server favorite. To do so, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Application Access > Terminal Servers > Resources.
  3. In the Resource Group menu, select the name of the resource group that you want to configure.
  4. Click the name of the Terminal Server favorite that you want to configure.
  5. Clear the Enable session reliability check box.
  6. Click Update.
