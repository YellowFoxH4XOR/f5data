Known Issue

The Configuration utility may fail to enable Auto Last Hop when you create a Dynamic Host Configuration Protocol (DHCP) relay virtual server.

This issue occurs when one of the following conditions is met:

  • The DHCP relay virtual server references a VLAN that has its Auto Last Hop setting configured with the value of disabled.
  • The DHCP relay virtual server references a VLAN that has its Auto Last Hop setting configured with the value of default and the Global Auto Last Hop setting configured with the value of disabled.

Note: Enabling Auto Last Hop is necessary for a DHCP relay virtual server to function properly.

When you use the Configuration utility to create a DHCP relay virtual server, the system uses default for the virtual server's Auto Last Hop setting, by default. As a result, the DHCP relay virtual server inherits the Auto Last Hop setting from either the VLAN it references, or globally, depending on the configuration of these two objects. For more information about the relationship of Auto Last Hop settings between the virtual server, the referenced VLAN, and the Global setting, refer to K13876: Overview of the Auto Last Hop setting (11.x - 13.x).

Note: By default, the Configuration utility does not provide any means to modify the Auto Last Hop setting for the DHCP relay virtual server.

Impact

The newly created DHCP relay virtual server fails to forward DHCP packets from the client to the server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The DHCP relay virtual server fails to relay DHCP packets from client to the server, as expected.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to modify the Auto Last Hop setting for the affected DHCP relay virtual server to enabled. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Modify the Auto Last Hop setting for the affected DHCP relay virtual server and set the value to enabled by using the following command syntax:

    modify /ltm virtual <VS name> auto-lasthop enabled

    For example:

    modify /ltm virtual MyDHCPvirtual auto-lasthop enabled

  3. Save the changes by typing the following command:

    save /sys config
