K59462473: After installing new certificates in BIG-IP GTM/DNS, the iQuery connection is flapping

Type
Support Solution
Published
2022-07-29
Updated
2023-02-21
Applies to
  • VIPRION Platforms
  • BIG-IP GTM
Source
https://my.f5.com/manage/s/article/K59462473

Description

LTM virtual servers are constantly flapping

  • Keep getting big3d timeouts for the LTM devices.
  • tmsh show gtm iquery keeps showing that the GTM is connected, but the server keeps changing from BIG-IP DNS to unknown.
  • Keep getting left <gtm-ip> sync group <sync-group> and <gtm-ip> joined sync group <sync-group>

Environment

  • BIG-IP GTM/DNS devices
  • Recently the certificates were updated with new certificates.
  • The devices are using internal CA signed certificates.

Cause

One of the reasons it can happen is if the new certificates contain special attributes called Bag Attributes that are empty.

Recommended Actions

This is being internally tracked under ID1127805. There are two ways to address this.

  1. Generate a fresh certificate without empty Bag Attributes.
    (OR)
  2. On each GTM, run bigip_add for all defined BIG-IP servers
To verify if the certificate is using Bad Attributes, the OpenSSL command below may be used:
# openssl x509 -text -in /config/httpd/conf/ssl.crt/server.crt | grep -i 'Bag Attributes'
