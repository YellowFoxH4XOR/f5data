Known Issue

Editing iRule data group address records may result in an invalid entry.

This issue occurs when all of the following conditions are met:

  • You configure the iRule data group Address type in the Configuration utility.
  • You attempt to edit an address record.

Impact

Address records are not properly edited.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When editing an address record, the Address and Value fields are not properly parsed.
