Known Issue

The BIG-IP system may log invalid QSFP+ OPT-0030 transceiver error messages.

This issue occurs when the following conditions are met:

  • The BIG-IP platform is equipped with 40GbE QSFP+ ports.
  • The platform contains OPT-0030 transceivers, where the label reads OPT-0030-01.
  • The Digital Diagnostics Monitoring (DMM) feature is enabled.

Impact

There is no impact; however, the invalid error messages may cause confusion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/ltm file, the system logs error messages that appear similar to the following example:

    Note: When the transmit power too high warning cleared message follows the transmit power too high warning.Transmit... message in the /var/log/ltm file, you can safely ignore the DDM errors. For example, you can safely ignore the following messages (the interface number will be the interface with an OPT-0030, which in this example is 1/1.13).

    err bcm56xxd[5607]: 012c0017:3: DDM interface:1/1.13 transmit power too high warning.Transmit power(mWatts) 0.9845 1.2679 0.9854 1.1759.
    err bcm56xxd[5607]: 012c0019:3: DDM interface:1/1.13 transmit power too high warning cleared.

  • The system generates SNMP traps indicating that the DDM interface transmit power is too high.

    For example:

    012c0017:3: DDM interface:5.0 transmit power too high warning.Transmit power(mWatts) 1.2940 1.2418 1.2640 0.9623

Workaround

To work around this issue, you can disable the DDM feature. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Type the following command:

    modify /sys db ddm.bcm56xxd.enable value disable

  3. Confirm that DDM is disabled by typing the following command:

    list /sys db ddm.bcm56xxd.enable
