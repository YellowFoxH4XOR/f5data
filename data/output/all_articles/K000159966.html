K000159966: Changing SSH Key size to 4096

Type
Support Solution
Published
2026-07-07
Updated
2026-07-07
Source
https://my.f5.com/manage/s/article/K000159966

Description

It is not possible to change the SSH host key size (for example, to 4096 bits) on F5OS platforms, including BIG-IP Next LTM running F5OS. There is no supported procedure or documentation for increasing SSH key size on F5OS.

Environment

  • BIG-IP Next LTM on F5OS
  • F5OS version 1.8.0
  • Security baseline or compliance requirement to change SSH host key size

Cause

Current F5OS releases do not support changing SSH host key size.

Recommended Actions

There is no supported CLI, GUI, or API method to change the SSH host key size on F5OS platforms. If changing the SSH host key size is a compliance requirement, escalate the enhancement request with your F5 account team for updates on future support.
