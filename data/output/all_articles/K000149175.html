Description

This article describes an incident when a specific log entry is recorded in the logterminal.txt file:

SWManager::AddRules, Failed to add rule:"allow all to <ip_address> out", error 3

Environment

  • Edge Client package with Always Connected Mode enabled
  • Multiple FQDN addresses added to the Exclusions List 

Cause

Error 3 is generated when the F5 Networks Stonewall service tries to add a rule that already exists. The Stonewall process generates "error 3" upon the second attempt to add the same IP address, despite the IP address being successfully added on the first attempt.

For instance, if multiple records that resolve to the same IP address are added to the Exclusions List, such as:

  • account.f5.com
  • identity.account.f5.com

(at the time of writing this article both resolve to the same IP address: 159.60.134.92)

This scenario will result in an error log entry in the file located in: C:\Users\%USERNAME%\AppData\Local\Temp\logterminal.txt 

SWManager::AddRules, Failed to add rule:"allow all to 159.60.134.92 out", error 3

Recommended Actions

This behavior is by design, and the error message can be disregarded.
