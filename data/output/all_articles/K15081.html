Topic

BIG-IP systems using solid state disks (SSD) may not list disk options when you attempt to install a software image.

Description

When attempting to install a software image on an SSD-based system, such as the VIPRION B2150, the Select Disk drop-down menu in the Install Software Image box may not list disk options. This behavior occurs when the platform does not support the software version you have selected to install.

For example, the VIPRION B2150 blades supports BIG-IP software 11.4.1 and later. If you navigate to System > Software Management and select a software image that is not supported by the B2150 blade, such as 11.3.0, the Install Software Image box does not list hard disk options upon which to install the image.

Recommendations

Install a supported BIG-IP version.
