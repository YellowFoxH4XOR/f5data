K000163403: F5OS passwords with the special character ’ works through the CLI but fails through the GUI.

Type
Support Solution
Published
2026-09-24
Updated
2026-09-24
Applies to
  • F5OS Products
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000163403

Description

GUI login fails when the password contains a curly apostrophe (’), while ssh login succeeds.

Environment

  • F5OS-A
  • F5OS-C
  • Password with Special character curly apostrophe (’)

Cause

This behavior is tracked under Bug ID 2525529.

Answer/Recommended Actions

Avoid using the character ’ when creating passwords through the GUI until Bug ID2525529 is addressed.

Additional Information

None
