K000150000: Unable to select a bandwidth controller policy from virtual server bandwidth controller drop down section

Description

When attempting to attach a bandwidth controller policy to a Virtual Server (VIP), the bandwidth controller section/drop-down in the VIP configuration appears empty, and no policies are available for selection.

This occurs when only dynamic bandwidth controller (bwc) policies are configured. 

Environment

  • BIG-IP LTM 

Cause

Dynamic bandwidth controller (bwc) policies cannot be directly assigned to a Virtual Server (VIP) through the GUI or drop-down menu. These types of policies are designed to be applied via iRules using events such as SERVER_CONNECTED or CLIENT_ACCEPTED. The absence of static bwc policies in the configuration results in an empty drop-down list for bandwidth controllers in the VIP settings. 

Recommended Actions

To resolve this issue, follow one of these approaches based on your requirements:

  1. Use iRules to assign dynamic bandwidth controller policies to virtual server.
  2. Use static bandwidth controller policies to apply to virtual server from bandwidth controller drop down option.

For more details on Managing Traffic with Bandwidth Controllers, please refer to attached guide in additional information section.
