Known Issue

When you access StoreFront applications using the Internet Explorer browser, they may fail to open.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM webtop in StoreFront replacement mode.
  • You publish Citrix applications or desktops to your webtop.
  • You have access to the BIG-IP APM webtop using an Internet Explorer version prior to 11.
  • You attempt to launch a Citrix application or desktop.

Impact

Access to the Citrix application or desktop silently fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The web browser does not display messages indicating a failure.
  • When viewing network level traffic or the Citrix logs, your session request launches twice when you click the webtop Citrix application or desktop launcher.

Workaround

To work around this issue, you can add the BIG-IP APM virtual server fully qualified domain name (FQDN) to the list of the Internet Explorer browser's trusted sites. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Open the Internet Explorer browser.
  2. Navigate to Tools > Internet options > Security > Trusted Sites.
  3. Click Sites.
  4. Type the BIG-IP APM FQDN in the Add this website to the zone text box.

    For example:

    https://apm.example.com

  5. Click Add.
  6. Click Close.
  7. Click OK.
