Description

I want to know how the request will match the WAF Exclusion Rule List if I have multiple rules and the execution order.

 

Environment

  • Distributed Cloud (SaaS)
  • F5® Distributed Cloud Load Balancer

 

Cause

None

Answer/Recommended Actions

There are 2 sections in the WAF exclusion rule, match part and action part, the Domain and Path, Methods belong to the match part, and Signature ID, Violations, and Attack Types belong to the action part.

 

If a request goes to the WAF, it will check the match part first, and if the first rule matches the request, then it will go to the first rule and won't be checked by the rest of the rules. 

So if your first rule in the list is like the below, then every request will be matched and go to this rule, and the rest rules won't be checked.
