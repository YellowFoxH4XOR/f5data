Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator system displays PDF documents dynamically by using URL normalization when performing PDF linearization. If the BIG-IP WebAccelerator virtual server is configured to use a non-standard HTTP port, the URL normalization fails and the PDF document does not display.

Note: For more information, refer to K8548: BIG-IP WebAccelerator URL normalization fails for virtual server configured with non-standard HTTP port.

F5 Product Development is tracking this issue as ID248727 (formerly CR92719).
