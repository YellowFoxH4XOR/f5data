Known Issue

Using an SNMP query to identify the platform model for the BIG-IP 4000 series may fail.

This issue occurs when all of the following conditions are met:

  • The platform belongs to the BIG-IP 4000 series (C113).
  • The BIG-IP system is running on the affected version.
  • You performed an SNMP query using the sysObjectID OID for the platform's model.

Impact

You are unable to identify the platform model with the SNMP query using sysObjectID.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • An SNMP query for the system device model OID will return an unknown output.

    For example, to query for sysObjectID.0, you would enter the snmpwalk command on localhost:

    snmpwalk -v2c -c public localhost sysObjectID.0

    The unknown command output may appear similar to the following example:

    SNMPv2-MIB::sysObjectID.0 = OID: F5-BIGIP-SYSTEM-MIB::unknown
