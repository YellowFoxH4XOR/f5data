Topic

The BIG-IP LTM system can be configured to offload SSL VPN traffic to one or more FirePass controllers. The VPN client uses SSL to connect to the BIG-IP LTM client SSL virtual server, and the BIG-IP LTM system then proxies the unencrypted connection to the FirePass controller. This behavior offloads SSL decryption from the FirePass controller, preserving CPU resources and other resources.

For more information about configuring the BIG-IP system to load balance and offload SSL transactions for FirePass controllers, refer to the Managing and Monitoring the FirePass Controller chapter of the FirePass Controller Administrator Guide, version 6.0.3.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

After configuring SSL offload, the client fails to connect to the FirePass webtop, and the web browser displays the following error message:
SSL ciphersuite RC4-MD5 not permitted. Please see your system admin

Workaround

You can work around this issue by configuring the SSL Cipher Security setting to low level security. To do so, perform the following procedure:

 

  1. Log in to the Administrative console.
  2. From the main navigation pane, select Device Management.
  3. Click Security.
  4. Click User Access Security.
  5. In the SSL Cipher Security section, click Low level security.
  6. Click Requires services restart.
  7. Click the Restart button to restart FirePass services.
