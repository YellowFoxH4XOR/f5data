Issue

Note: FirePass version 6.0.1 requires Cumulative Hotfix HF-601-6 or a later version of the Cumulative Hotfix to support Protected Workspace on Microsoft Windows Vista clients.

When you attempt to enter Protected Workspace using a Microsoft Windows Vista client, the login progress bar stops while displaying Protected Workspace, and the following error message appears on the login page:

Some Windows updates are required to run Protected Workspace.
Please click on the following link for more details:

Windows Update for IE7 and non-default desktop on Vista

OR contact your system administrator for assistance.
OR click here to continue.

Note: Clicking the first link will take the user to a page on the Microsoft Knowledge Base where one of the required updates can be downloaded. Clicking the second link will take the user to the default Logon Denied page on the FirePass controller.

This error message occurs when certain Microsoft Updates for Windows Vista are not installed on the system used to log in to the FirePass controller using Protected Workspace. These updates are required for Windows Vista clients to use Protected Workspace. The FirePass controller performs a scan of the file system for specific executable and dynamically linked library files, and compares the versions of these files to the minimum required versions. If the versions of the files on the system do not meet the minimum required versions, the FirePass controller stops the pre-logon sequence and displays the previous error message.

To resolve this issue, you must install Microsoft Update KB935855 and KB933566 on the Windows Vista system used to access Protected Workspace. For more information, refer to the following websites:

http://support.microsoft.com/kb/935855

http://support.microsoft.com/kb/933566

Note: Other combinations of Microsoft Updates for Windows Vista that are not listed in this Solution may provide the versions of files required to use Protected Workspace. You can list installed updates by clicking the View installed updates link under Programs and Features in the Microsoft Vista Control Panel.
