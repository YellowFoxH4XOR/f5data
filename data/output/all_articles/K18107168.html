Issue

Error Message

debug mcpd[<PID>]: 01071a15:7: device_trust_group: Sending device data to device <Name of Peer Device>

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <Name of Peer Device> is the peer device to which the system is sending data.

For example:

debug mcpd[9614]: 01071a15:7: device_trust_group: Sending device data to device %cmi-mcpd-peer-/Common/B10250.sea.test.local.

Message Location

You may encounter this message in the following location:

  • /var/log/ltm

Description

This message occurs when the following condition is met:

  • When the device in a sync group needs to send data to a peer.

Impact

None

Recommended Actions

None
