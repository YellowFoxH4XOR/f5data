Issue

When installing a hotfix, the IM package returns Failed dependencies errors similar to the following after attempting the first pass of the installation process:

# im Hotfix-BIG-IP-9.0.4-CR44909.imChecking integrity of packages.../tmp/rpmdisk.l3KGrb/RPMS/i686/tmm-1.0.F5-9.0.4.121.0.i686.rpm/tmp/rpmdisk.l3KGrb/RPMS/i686/tmm-debug-1.0.F5-9.0.4.121.0.i686.rpm/tmp/rpmdisk.l3KGrb/RPMS/i686/tmm-strict-1.0.F5-9.0.4.121.0.i686.rpm/tmp/rpmdisk.l3KGrb /var/tmpUpgrading to new and/or revised packages...>>>>>> Beginning single-package install pass 1...error: Failed dependencies:tmm = 1.0.F5-9.0.4.118.5 is needed by (installed) tmm-strict-1.0.F5-9.0.4.118.5tmm = 1.0.F5-9.0.4.118.5 is needed by (installed) tmm-debug-1.0.F5-9.0.4.118.5error: Failed dependencies:tmm = 1.0.F5-9.0.4.121.0 is needed by tmm-debug-1.0.F5-9.0.4.121.0error: Failed dependencies:tmm = 1.0.F5-9.0.4.121.0 is needed by tmm-strict-1.0.F5-9.0.4.121.0>>>>>> Upgrading all packages...Preparing packages for installation...tmm-1.0.F5-9.0.4.121.0tmm-debug-1.0.F5-9.0.4.121.0tmm-strict-1.0.F5-9.0.4.121.0**************************************************************Hotfix application complete.**************************************************************

It is normal to receive Failed dependencies errors on the first pass of an installation. These errors are benign. F5 designs hotfixes to abort completely and return an error if BIG-IP cannot install the packages.

In the example, you can see that the IM package looks at the current files and determines which packages it will need to install to satisfy the dependencies noted in the Failed dependencies error.

On the second pass, the hotfix installs the dependent files as follows:

>>>>>> Upgrading all packages...Preparing packages for installation...tmm-1.0.F5-9.0.4.121.0tmm-debug-1.0.F5-9.0.4.121.0tmm-strict-1.0.F5-9.0.4.121.0In the event of a failed hotfix installation, the administrator would not see the following message that signifies the packages were installed properly:**************************************************************Hotfix application complete.**************************************************************
