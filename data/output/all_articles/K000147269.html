Description

You want to know how many resources you can set up on your HTTP Load Balancer.

Environment

  • F5® Distributed Cloud HTTP Load Balancer 

Resolution/Answer

For Routes:

You can add up to 256 routes to an HTTP Load Balancer.

  • If you use custom routes, each route object you reference can contain 257 individual route configurations.
  • The default quota of route objects is 10, so that's 2570 route configs total if you just use those 10 route objects.

For Origin Pools

You can add up 3000 origin pools in the tenant level. And one Load Balancer can contain max 8 origin pools.

For Ports

An HTTP Load Balancer can support 64 ports by default.

For SSL certificates

16 for Legacy Certs (inline) and 32 for Cert objects.
