K000150405: F5OS-A The priority and severity of a log message are not the same

Type
Support Solution
Published
2025-03-17
Updated
2025-03-17
Applies to
  • F5OS
  • F5OS-A: 1.8.0
Source
https://my.f5.com/manage/s/article/K000150405

Description

You may notice that the priority and severity of a log message are not the same.

alert-service[9]: priority="Notice" version=1.0 msgid=0x2201000000000021 msg="Sending ." func="postAlertLedSeverityVanquish" ACTION="POST_LCD_LED_ALARM_SEVERITY" source="interface-8.0" severity=4 dest="tcp://127.0.0.1:1046".

Environment

  • F5OS-A
  • Log message priority
  • Log message severity

Cause

The log level and alarm severity are different, and they are not 1-1 mapped.

Priority is Log Level Priority but Severity is Alarm Severity so both are not same.

Recommended Actions

None.

Additional Information

None.
