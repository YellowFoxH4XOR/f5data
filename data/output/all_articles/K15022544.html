Description

After upgrade the BIG-IP version from v15.1.x to v16.1.x, when access a site through a LTM Virtual Server that listening on a Layer2 Virtual Wire/VLAN and has an iRule 'virtual' command to call a SSLO's virtual server does not work for connections.

In /var/log/ltm log file, you would see similar logs as below are logged: 

info tmm2[22156]: Rule /Common/(<iRule_name>) <HTTP_REQUEST>: www.example.com hit on Internal domain_contains
err tmm2[22156]: 01230140:3: RST sent from 10.10.10.100:56814 to 20.20.20.200:80, [0x2fff729:14638] TCP retransmit timeout
err tmm2[22156]: 01230140:3: RST sent from 20.20.20.200:80 to 10.10.10.100:56814, [0x2fff729:14638] {peer} TCP retransmit timeout

Environment

  • BIGIP upgrade
  • L2 virtual-wire
  • iRule 'virtual' command

Cause
Bug ID 1091969: iRule 'virtual' command does not work for connections over virtual-wire.

Recommended Actions

Please contact F5 Support to request for an engineering hotfix.
