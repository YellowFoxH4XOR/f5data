Known Issue

This is the result of a known issue. The Secure Via header SIP profile option inserts an incorrect protocol in the header for SIP communication over TLS.

The correct Secure Via header is SIP/2.0/TLS 192.168.1.1:2310. However, the BIG-IP LTM incorrectly inserts SIPS/2.0/TLS 192.168.1.1:2310.

This behavior is not in compliance with RFC3261.

F5 Product Development tracked this issue as CR99219 and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue still exists in the BIG-IP LTM version 9.4 software branch.
