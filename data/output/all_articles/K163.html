Topic

When both the preferred and alternate load balancing modes fail, the 3-DNS Controller provides the wide IP key, (called Return To DNS) as the answer to DNS inquiries.

The wide IP key is the same address as the A record listed for the domain name, and it binds the host address to the 3-DNS Controller for wide-area load balancing. This is also sometimes referred to as the fallback address.

The following example is a DNS A record and the accompanying wide IP key:

DNS record

www.domain.com. IN A 192.168.101.60

Wide IP

wideip {
    address 192.168.101.60
    port 80 // http
    name ?www.domain.com?
    ttl 55
    port_list 80 110 443 
    pool {
        name vsb
        preferred rtt
        alternate	ratio
        fallback null
        address 192.168.101.220 ratio 2
        address 192.168.101.221 ratio 12
        address 192.168.101.231 ratio 2
    }
}
