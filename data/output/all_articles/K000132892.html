K000132892: TMM memory increase when mirroring configured with hardwired failover

Published

Applies to

Source

Description

TMM memory increases over time when failover is configured and enabled. BIG-IP is configured for hardwired failover only.

 

"persist" may be high in "show sys memory"

Environment

  • BIG-IP Classic
  • Hardwired failover between devices in pair
  • Network failover address not configured
  • Mirroring addresses configured
  • At least one persistence profile has mirroring configured

Cause

A combination of:

  • Mirroring does not function when network failover is not configured, because the active device cannot elect a next-active peer
  • Bug ID 801541

 Recommended Actions

F5 recommends that you configure Network Failover in addition to hardwired failover. Monitoring of related processes can be done via CMD line:

root@(BIGIP1)(cfg-sync Changes Pending)(Standby)(/Common)(tmos)# show sys memory | grep persistence
dns_persistence                              0                  0           80
persistence                               1.5K               1.5K            1
