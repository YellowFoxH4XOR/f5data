Topic

Internet Protocol version 6 (IPv6) is designed to succeed IPv4, which is currently the dominant protocol used to route nearly all internet traffic. IPv6 is designed primarily to deal with the problem of IPv4 address exhaustion. IPv4 uses 32-bit addresses, which limits the total IPv4 address space to 4.2 billion (4.3×109) unique addresses. By comparison, IPv6 uses 128-bit addresses, which allows for an address space of 340 undecillion (3.4×1038) addresses, and can accommodate many more devices and users on the internet.

IPv6 is currently only implemented for limited network segments across the internet. To function in the predominantly IPv4 environment, IPv6 devices must either be dual-stack and support both IPv4 and IPv6 on the same device, or connect to IPv4 networks using a dual-stack proxy that performs bi-directional IPv6 to IPv4 address translation. This network design requires topologies similar to current IPv4 deployments that allow private networks using RFC1918 address space to communicate with globally routable IPv4 address space. BIG-IP controllers can facilitate this proxy-based architecture.

Description

IPv6 on BIG-IP

The BIG-IP system can act as a full proxy and termination point providing application availability, bi-directional address translation, authentication and security services, and DNS services that cross IPv4 and IPv6 network boundaries.

  • IPv6 modules

    Note: To enable BIG-IP Advanced Routing Module (BIG-IP ARM), you must purchase an additional license key, depending on your version of BIG-IP software. For more information, contact F5 Technical Support.

    • The BIG-IP IPv6 Gateway module provides IPv6 support for the following:
      • IPv4 and IPv6 addressing for self IPs, virtual servers, proxies, nodes, secure network address translation (SNAT), Simple Network Management Protocol (SNMP) agents and destinations, iControl API, and statistics reporting.
      • AAAA, A6, and DNAME DNS records
    • The BIG-IP ARM system includes support for the following IPv6 routing protocols:
      • RIPng
      • OSPFv3
      • BGP4+
      • IS-ISv6
  • ICMPv6

    You can configure the radvd service to send Internet Control Message Protocol version 6 (ICMPv6) routing advisory messages and respond to ICMPv6 route solicitation messages. This enables the BIG-IP system to support auto-configuration of downstream nodes and the downstream nodes to automatically discover that the BIG-IP system is their route.

Recommendations

You can use the BIG-IP system to facilitate a complete migration to IPv6 or a mixed deployment of IPv6 with existing IPv4 networks. While there is considerable IPv6 support for core BIG-IP functionality, certain BIG-IP features and modules may have limited or no support for IPv6.
