Description

  • There is a existing pool with traffic. Another pool member is added.
  • It receives traffic immediately, even if the pool member is not functional

Environment

  • Pool with health monitor.

Cause

  • If the health monitor has not yet run, the pool member will be in state "unchecked" (blue).
  • Unchecked pool members are valid targets for load balancing.

Recommended Actions

  1. Add the pool member to the pool in state "Disabled". It will not receive traffic but will be monitored.
  2. Allow enough time for the health monitor to complete its timeout, normally 16 seconds.
  3. Change state to "Enabled". The pool member state will now depend on the health monitor results.
