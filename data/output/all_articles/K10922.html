Known Issue

This is the result of a known issue. If the proper upgrade steps are not completed when upgrading to FirePass version 6.1.0, you may receive the following error message:

Installation script failed with status: Error: (number-&gt;string) bad argument type: 17\n\n\n\n\n\nRELOAD. Please, contact F5 technical support

If you receive this error message, or the upgrade to 6.1.0 fails and you are unable to log on to the FirePass controller, you will need to revert to the last working snapshot and then upgrade again.

Note: This issue can also occur if a services restart is attempted when a master group name includes a period ( . ) in the group name and hotfix HF-133285-1 or cumulative hotfix HF-610-1 or later has not been installed after upgrading to FirePass version 6.1.0. For more information, refer to K11126: Unable to access the Administrative Console after a services restart.

Note: This issue was tracked as CR133285, and fixed in FirePass version 7.0.0. For more information, refer to K11126: Unable to access the Administrative Console after a services restart.

Reverting to the last working snapshot and upgrading again

  1. From the F5 Networks Downloads site, download the following files:
    • HF-133602-1 for your current FirePass version
    • Cumulative HF-610-1 or later
      Note: HF-133285-1 is included in cumulative hotfix starting in HF-610-1. If the individual hotfix has been previously installed, the cumulative hotfix is not needed for this issue.
       
    Note: For more information, refer to K167: Downloading software from F5 Networks.
  2. Revert back to the previous working snapshot.

    Note: For more information, refer to K3244: Backing up and restoring FirePass system software.
  3. Install the pre-upgrade hotfix HF-133602-1.

    Note: For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
  4. Install the FP-6.10-20091009.tar.gz.enc release file.
  5. After the FirePass controller has rebooted, install cumulative hotfix HF-610-1 or later.

If you are unable to revert to a working snapshot, you will need to revert to the factory default snapshot when prompted.

Reverting to the factory default snapshot

  1. Revert back to the factory default snapshot.

    Note: For more information, refer to K3244: Backing up and restoring FirePass system software.
  2. Install the FP-6.10-20091009.tar.gz.enc release file.
  3. After the FirePass controller has rebooted, install cumulative hotfix HF-610-1 or later.
  4. Navigate to Device Management : Maintenance : Backup/Restore.
  5. Click the Browse button under Restore FirePass controller configuration from a previous backup.
  6. Select the FirePass backup file you created prior to attempting the upgrade.
  7. Click the Restore your saved configuration link and follow the prompts. More information regarding restoring is located in the online help.

Important: If you restore your backup to the factory default snapshot prior to upgrading to 6.1.0, you will need to install the pre-upgrade hotfix HF-133602-1 before upgrading.
