Topic

Starting in BIG-IP ASM 14.1.2.7, for BIG-IP ASM 14.x, BIG-IP ASM-enabled virtual servers support connection mirroring with certain limitations. For more information about the limitations and configuration, refer to the Connection Mirroring with ASM chapter of the BIG-IP Application Security Manager: Implementations manual for BIG-IP ASM 14.x.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Description

For BIG-IP ASM versions prior to 14.1.2.7, ASM-enabled virtual servers do not support connection mirroring. If you attempt to enable connection mirroring on a BIG-IP ASM-enabled virtual server, or if you attempt to add a BIG-IP ASM-enabled local traffic policy or HTTP class to a virtual server that has connection mirroring enabled, the Configuration utility displays an error message that appears similar to the following example:

01070692:3: ASM is not supported on connection-mirrored virtual servers.

Note: You don't typically need to mirror HTTP connections, as the HTTP protocol allows individual requests to fail without losing the entire session. In a failover scenario, the connections are dropped but the browser automatically re-initiates them.

Note: Connection mirroring is not currently implemented in BIG-IP 15.x or BIG-IP 16.x.
