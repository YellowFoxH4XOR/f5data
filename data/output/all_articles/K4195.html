Topic

Starting in version 4.6.3, F5 Networks has added the following SNMP v2 traps:

  • loadBalTrapPowerFailedV2
  • loadBalTrapCPUFanFailingV2
  • loadBalTrapCPUTooHotV2
  • loadBalTrapFanFailingV2

These traps already exist for SNMP v1. For more information about SNMP traps, refer to the BIG-IP Reference Guide.
