To verify that NameSurfer is running, perform the following steps.

  1. Log in to the command line.
  2. Type the following command:

    ps -a | grep -w ns

    The output should appear similar to the following:

    502 1 0 0 ?? 2 0 Ss 0.0 0.0 368 /usr/local/namesurfer/bin/ns

If you receive no results, NameSurfer is not running.

If NameSurfer is not running refer to K1092: Restarting the NameSurfer process from the command line.
