Known Issue

The Traffic Management Microkernel (TMM) may restart when the iRule catch command is used to suppress errors from the possible invalid use of square brackets.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server to process client traffic.
  • The virtual server references an iRule which uses the following commands:

    • The proc command
    • A parking command such as table, session, open or send
  • Both commands are included in a catch block, which uses square brackets.

    For example:

       proc example1 {
           catch { [ table lookup "key" ] }
       }
  • Prior to the execution of the catch block, an error occurs.

Impact

TMM may restart and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.

Workaround

To work around this issue, you can make either of the following modifications to the affected iRule:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  • Move the catch statement outside of the proc command, and into the body of the iRule. 
  • Remove the square brackets which indicate that the result of the command should be evaluated.
