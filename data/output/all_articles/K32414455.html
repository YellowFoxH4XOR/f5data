Issue

Error Message

Error Message: netHSM: Failed to open file <file_name>

In this error message, note the following:

  • <file_name> is the file name associated with the process.

For example:

netHSM: Failed to open file [%s]

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The pkcs11d service does not exist, or you are not logged on using the root account.

Impact

The network hardware security module (HSM) fails to generate keys and an SSL handshake.

Recommended Actions

You can take one of the following actions to correct this issue:

  • Install and start the pkcs11d service
  • Restart the pkcs11d service
  • Reinstall the HSM client using the root user account

Install and start the pkcs11d service

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line:
  2. Install the pkcs11d service by typing the following command:

    bigstart add pkcs11d

  3. Start the pkcs11d service by typing the following command:

    bigstart start pkcs11d

Restart the pkcs11d service

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Restart the pkcs11d process by typing the following command:

    restart /sys service pkcs11d

Reinstall the HSM client using the root user account

Note: Reinstalling the HSM client causes the Traffic Management Microkernel (TMM) to restart. You should perform this procedure during a maintenance window as restarting the TMM interrupts traffic processing.
