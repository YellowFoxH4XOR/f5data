Topic

You should consider using this procedure under the following condition:

  • You want to update the F5 SSL Orchestrator software within the same branch. For example, updating SSL Orchestrator 9.0 to 9.2.

Note: For information about upgrading F5 SSL Orchestrator software across branches, refer to K64003555: BIG-IP update and upgrade guide | Chapter 23: Update or upgrade the F5 SSL Orchestrator.

Description

If you upgrade the BIG-IP system base version from an earlier version and go to SSL Orchestrator > Configuration in the Configuration utility for the first time, the system triggers an auto-install operation using the on-box SSL Orchestrator software Redhat Package Manager (RPM) package. Subsequent navigation to this page does not trigger the auto-install operation. The on-box RPM package is typically located in the /usr/share/packages/f5-iappslx-ssl-orchestrator directory. If you are looking to update the F5 SSL Orchestrator software within the same branch, you should download the SSL Orchestrator software RPM package from F5 Downloads site and import to your F5 SSL Orchestrator to install it.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the F5 SSL Orchestrator Configuration utility.
  • You have access to F5 Downloads site.

Procedures

  • Update using the on-box SSL Orchestrator RPM package
  • Update using the SSL Orchestrator RPM package downloaded from F5 Downloads site

Update using the on-box SSL Orchestrator RPM package

You can update your SSL Orchestrator using the on-box SSL Orchestrator RPM package by performing the following procedure:

Note: This procedure works if this is the first time you go to the SSL Orchestrator > Configuration page. Subsequent visits to this page do not trigger an auto-install.

Impact of procedure: F5 recommends performing the SSL Orchestrator software update during a scheduled maintenance for existing SSL Orchestrator deployments.

  1. Log in to your F5 SSL Orchestrator Configuration utility.
  2. Go to SSL Orchestrator > Configuration.
  3. If this is the first time you go to SSL Orchestrator > Configuration page, the system triggers an auto-install operation using the on-box SSL Orchestrator software RPM package. This is followed by the SSL Orchestrator configuration upgrade. The duration of this process depends on the number of configuration objects deployed. You must wait for the entire process to complete. If this is a new deployment with no existing SSL Orchestrator configuration, you can refer to F5 SSL Orchestrator Deployment Guide for information about configuring a new deployment.

Update using the SSL Orchestrator RPM package downloaded from F5 Downloads site

You can update your SSL Orchestrator using the RPM package downloaded from F5 Downloads site by performing the following procedure:

Impact of procedure: F5 recommends performing the SSL Orchestrator software update during a scheduled maintenance for existing SSL Orchestrator deployments.

  1. Download the required SSL Orchestrator RPM package from F5 Downloads site to your workstation. The SSL Orchestrator RPM packages are located under the SSL Orchestrator product line under the Security group on the F5 Downloads site. For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.
  2. Log in to your F5 SSL Orchestrator Configuration utility.
  3. Go to iApps > Package Management LX.
  4. Select Import.
  5. Select Choose File and locate the SSL Orchestrator RPM package you have downloaded to your workstation from step 1.
  6. Select Upload. This action triggers an auto-install operation using the uploaded SSL Orchestrator RPM package. If this is a new deployment with no existing SSL Orchestrator configuration, you can refer to F5 SSL Orchestrator Deployment Guide for information about configuring a new deployment.
