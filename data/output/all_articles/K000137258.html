K000137258: BurpSuite may flag GUI access as vulnerable

Type
Support Solution
Published
2024-11-18
Updated
2024-11-18
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.9
Source
https://my.f5.com/manage/s/article/K000137258

Description

  • BurpSuite flag BIG-IP GUI access as vulnerable

Environment

  • BIG-IP
  • BurpSuite

Cause

BurpSuite may require encryption on every single HTTP request

 Recommended Actions

There should be no network device encrypting every HTTP request separately.

Customer should ignore the scanning result of BurpSuite.

Additional Information

None.
