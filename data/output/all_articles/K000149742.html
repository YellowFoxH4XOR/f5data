Topic

This article describes what you should do on the release of F5OS-A 1.5.3 FIPS.

Description

F5OS-A 1.5.3 introduces FIPS 140-3 Level 3 Validated version of the Marvell HSM, as well as Common Vulnerability Exposures (CVE) fixes, and other fixes in F5OS-A 1.5.x software branch.

A recent update from one of our third-party vendors has removed support for PKCS#1 v1.5 to comply with FIPS 140-3 regarding deprecated algorithms. The RSA handshake algorithms, when used with TLS 1.2 and older, relies on PKCS#1 v1.5 for encrypting the pre-master secret during the key exchange. This update means that SSL/TLS servers/clients attempting to use TLS 1.2 and older versions with the RSA handshake will experience connection failures. This affects r5920-DF and r10920-DF platforms running F5OS-A 1.5.3 or higher only.

To ensure continued secure connectivity, we strongly recommend migrating away from the deprecated forms of the RSA handshake. For more information on the following:

  • how to disable RSA key exchange ciphers, refer to the upgrade procedure section.
  • the deprecated forms of the RSA handshake, refer to the Additional Information section.

F5 recommends that you use ECDHE with TLS 1.2: Configure your rSeries-DF platforms to use the Elliptic Curve Diffie-Hellman Ephemeral (ECDHE) key exchange algorithm.

ECDHE is a FIPS 140-3 approved algorithm and provides forward secrecy, a security feature not offered by the RSA handshake.

  • Supported ECDHE Key Exchange Algorithms:
    • ECDHE-ECDSA (preferred for ECC certificates)
    • ECDHE-RSA (for RSA certificates)
  • Supported Cipher Suites:
    • ECDHE-ECDSA-AES128-GCM-SHA256
    • ECDHE-ECDSA-AES256-GCM-SHA384
    • ECDHE-RSA-AES128-GCM-SHA256
    • ECDHE-RSA-AES256-GCM-SHA384

This article does not apply to rSeries appliances that do not have a FIPS HSM.

Recommended Actions

You are required to upgrade to F5OS-A 1.5.3 when you are running the following rSeries platforms:

  • rSeries 5920-DF
  • rSeries 10920-DF

Upgrade procedure

As part of the upgrade to F5OS-A 1.5.3, you will also be required to perform the following procedures:

  • Upgrade the BIG-IP tenant software version to run BIG-IP 17.1.2. There will be severe impact to traffic if the BIG-IP tenant is not upgraded.
  • Upgrade the FIPS firmware version. For more information on doing so, refer to FIPS firmware upgrade.
  • After you upgrade the supported ciphers to align with the latest security and FIPS 140-3 standards, RSA Key Exchange will no longer present itself as an issue. RSA key exchange ciphers can be disabled by appending :!RSA to the cipher string.
    For example, DEFAULT:!RSA or FIPS:!RSA. For more details, see K000132660: How to disable a cipher or cipher suite.

FIPS firmware upgrade

Use the following section to upgrade the FIPS firmware on your FIPS platform with embedded hardware HSM.

Pre-requisites

Before you upgrade the firmware on your F5 FIPS platform, you must meet the following prerequisites:

  • You have upgraded to F5OS-A 1.5.3.
  • You have admin CLI access to the F5 system.
  • You have the FIPS HSM Security Officer (SO) password. 
  • Upgrade the BIG-IP tenants' software version to BIG-IP 17.1.2.
  • You have backed up any critical data or keys stored on the FIPS Platform. For more information, see sections FIPS system backup and restore and F5 rSeries to F5 rSeries in the manual chapter F5 Platforms: FIPS Administration

Upgrade FIPS firmware from the CLI

After you performed a software upgrade to F5OS-A 1.5.3, perform the following procedure to upgrade to the new firmware version. 

Impact of procedure: F5 recommends that you perform this upgrade during a scheduled maintenance window.

  1. Log in to the command line interface (CLI) of the system using an account with admin access.
  2. When you log in to the system, you are in user (operational) mode. Display the firmware version available for upgrade on the system.

    show fips firmwares

    You may observe an output similar to the following:

    appliance-1# show fips firmwares
    IMAGE                                         SOURCE    ID FW TYPE
    -----------------------------------------------------
    CNN35XX-NFBE-FW-2.09-0702 INTERNAL - -  

    In this example, the image CNN35XX-NFBE-FW-2.09-0702 is available for upgrade to, and its source is internal.

  3. Before upgrading to the latest firmware version, change the state of the F5OS FIPS tenants to Configured.

  4. Enter the following command to change to config mode:
    config

    The CLI prompt changes to include 
    (config)

  5. Verify that the FIPS HSM is in the Init state and you know the so-password. To display the fips state, enter the following:
    do show fips

    Verify that the fips status state value is 2.

    If you need to initialize fips or forgot your passord, enter the following command:
    fips hsm init

  6. Use the following syntax to upgrade the firmware version:
    fips set-firmware source <ImageVersion> so-password

    For example, enter the following command:
    fips set-firmware source internal image CNN35XX-NFBE-FW-2.09-0702 so-password

    You may observe a summary similar to the following:

    appliance-1(config)# fips set-firmware source internal image CNN35XX-NFBE-FW-2.09-0702 so-password
    Value for 'so-password' (<string, min: 7 chars, max: 30 chars>): ******** 
    result fips firmware has been set successfully. please reboot the system to reflect the update!

  7. Reboot the system to load the HSM with the upgraded firmware.

    reboot

    The embedded HSM in the system is now running the latest firmware.

  8. After upgrading to the latest firmware version, change the state of the F5OS FIPS tenants from the Configured to Deployed.
