K000147857: Can I manually deploy a node in AWS?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147857

What Happened?

  • You're trying to manually instantiate a node in a wavelength zone via the AWS console
  • You have access to the local admin page
  • When you configure it always comes back to the same screen where it thinks it has not yet been configured

Environment

  • Site Management

Resolution/Answer

  • No, we do not support it as of today. You cannot manually deploy a node in AWS.
  • You can use Terraform automated mode in F5® Distributed Cloud Console to deploy a node in AWS.
