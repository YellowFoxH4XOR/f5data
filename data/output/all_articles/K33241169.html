Known Issue

Disabling IPsec IKE peers fails, and network traffic continues.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system with an operational IPsec IKE peer setting.
  • You have changed the IKE peer state to Disabled using one of the following methods:
    • Using the Configuration utility, you navigated to Network > IPsec > IKE Peers List, and then clicked the IKE peer name, and for the State option, selected Disabled.
    • Using the TMOS Shell (tmsh), you used the following command syntax:

      modify /net ipsec ike-peer <IKE_PEER_NAME> state disabled

      For example:

      modify /net ipsec ike-peer mynet100 state disabled

Impact

The system does not disable the IPsec IKE peer, as expected, and as a result, may continue to establish new connections.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you disable the IPsec IKE peer, the system saves the change, but the network traffic continues between the IKE peers.

Workaround

There is no work around for this issue. However, you can delete the target IPsec IKE peer to prevent the system from establishing new connections. To do so, perform one of the following procedures:

  • Using the Configuration utility to delete the target IPsec IKE peer
  • Using tmsh to delete the target IPsec IKE peer

Impact of procedure: If you delete the IPsec IKE peer, you lose all of the configuration details that you have previously configured for the IKE peer. If you intend to re-use the same IKE peer configuration, ensure that you have a backup copy of the BIG-IP configuration.

Using the Configuration utility to delete the target IPsec IKE peer

  1. Log in to the Configuration utility.
  2. Navigate to Network > IPsec > IKE Peers List.
  3. Select the box next to the IKE peer name that you want to delete, and click Delete.

Using tmsh to delete the target IPsec IKE peer

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To delete the target IPsec IKE peer, use the following command syntax:

    delete /net ipsec ike-peer <IKE_PEER_NAME>

    For example:

    delete /net ipsec ike-peer mynet100
