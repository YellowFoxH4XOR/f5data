K000141333: Error loading UCS: Decryption of the field (secret) for object (/Common/system-auth) failed while loading configuration that is encrypted with a different master key.

Type
Support Solution
Published
2024-10-04
Updated
2024-10-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.9
Source
https://my.f5.com/manage/s/article/K000141333

Description

UCS configuration fails to load and shows error “Decryption of the field (secret) for object (/Common/system-auth) failed while loading configuration that is encrypted with a different master key.”

Environment

BIG-IP

Cause

Device which is attempting to load the UCS has a different master key then the origin device.

Recommended Actions

Copy the master key from the origin device to the destination device, then reload UCS. Note: Both devices must be a part of the same DSC (Device Service Clustering) group.

 

1. SSH to both devices

2. On the device that originated the UCS, run the command “f5mku -K”. The output should look something like “oruIVCHfmVBnwGaSR/+MAA==” . Copy the output.

3. On the destination device, carefully run the following command, making sure the key matches on both systems: “f5mku -r [key value]” (replace [key value] with the output from step 2. Do not include the square brackets.

4. You can now verify the keys match on both systems with the “f5mku -K” command.

5. On the destination device, restore the UCS archive by typing the command: “tmsh load sys ucs file_name.ucs no-license”.

6. On the destination device, save the configuration using the command: “tmsh save sys config”

7. On the destination device, load the configuration using the command “tmsh load sys config”

8. Back on the origin device, establish it as the sync leader using the command: “tmsh modify cm device-group device_group devices modify { existing_BIG-IP { set-syncleader } }

 

NOTE: device_group is the name of the device group both systems are members of, and existing_BIG-IP is the name of the origin device

 

9. Now, on the origin device again, run the command “tmsh run cm config-sync togroup device_group”. This may take a few minutes.

10. Confirm sync status using command: “tmsh show cm sync-status”

Additional Information

Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)
