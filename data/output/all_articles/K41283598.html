Description

Interpreting SYN cookie statics from "show ltm virtual server" and tmctl.

  • BIG-IP set for SYN cookie protection global or via AFM
  • SYN Flood or related SYN DOS attack

Environment

  • BIGIP configured for SYN flood attack
  • Configuration can be default or custom for SYN cookie generation and validation.
  • Below are different SYN cookie configuration and results when SYN cookies get triggered.

Cause

None

Recommended Actions

None

Additional Information

Output of virtual server "SYN cookies" statistics based on the pvasyncookies.enabled and connection.syncookies.algorithm database key settings.
