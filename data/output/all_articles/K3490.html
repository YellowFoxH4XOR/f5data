Topic

The proper setting for Gigabit Ethernet link negotiation is Auto. You cannot configure BIG-IP tri-speed interfaces for 1000baseTX operation.

Gigabit Ethernet systems use Auto-Negotiation to establish the primary-secondary signal timing control required to make the link operational. As such, setting link negotiation to Auto is required on 1000BASE-T systems, as 1000BASE-T systems are Gigabit Ethernet systems.

Although you can manually select operating speed by disabling Auto-Negotiation, selecting the 1000BASE-T mode of operation still requires that Auto-Negotiation be used.

Refer to the following link for further information about the IEEE interpretation for IEEE Standard 802.3-2002 pertaining to section 37 and 40.5.1 Support for Auto-Negotiation:

http://standards.ieee.org/reading/ieee/interp/IEEE802.3af-2003interp-6.pdf
