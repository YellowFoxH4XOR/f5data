K000134729: Newly active device fails to process traffic with Verified Accept and connection mirroring enabled

Type
Support Solution
Published
2023-05-22
Updated
2023-05-22
Source
https://my.f5.com/manage/s/article/K000134729

Description

Standby system does not correctly remove server side connections from Verified Accept SYN cache until idle timeout has expired on the connection. This could lead to overruns of the Verified Accept SYN cache and if the standby device become active it could appear to fail to process new connections.

Environment 

  • v15.1.8
  • Verified Accept enabled
  • Connection Mirroring enabled

Cause

Product Engineering has identified BZ1297549

Recommended Actions

Do not use Verified Accept and connection mirroring together on the same virtual server
