Known Issue

This is the result of a known issue. After installing either hotfix HF-601-6 or hotfix HF-601-7 for FirePass version 6.0.1, users are unable to run multiple applications within a Citrix App Tunnel favorite for a Citrix WebInterface server accessed through a portal access reverse proxy. Attempts to run multiple applications will result in no response from the Citrix WebInterface server.

F5 Networks Product Development tracked this issue as CR86148 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue has been fixed for FirePass version 6.0.1 in cumulative hotfix HF-601-8. You may download this hotfixes or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
