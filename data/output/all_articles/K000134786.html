Description

The Traffic Management Microkernel (TMM) controls all of the BIG-IP switch ports (TMM interfaces) and the underlying Linux operating system controls the BIG-IP management interface. The management interface processes only administrative traffic. The TMM interfaces process both application traffic and administrative traffic.

BIG-IP routing table consists of two routing subtables, MGMT subtable for management routes and TMM subtable for TMM routes.
Routes in the TMM subtable have lower metric than routes in the MGMT subtable. Routes with the lowest metric are preferred by the system. 

Server connections in some AAA objects can be Direct or through a high availability (HA) pool of servers.
TMM creates an AAA HA internal virtual server (IVS) and binds the pool to that listener.
APM supports the following AAA servers for HA: RADIUS, Active Directory, LDAP, CRLDP, and TACACS+. 

When an HA pool is configured, only the TMM subtable is used to route AAA traffic. Source IP address of that traffic will be a floating Self-IP.
If TMM can not route that traffic, it will not fallback to the MGMT subtable and an error like "RADIUS module: authentication with 'xxx' failed: no response from server" will be dumped

When configuring a Direct server, no HA IVS is used. TMM subtable will be preferred over MGMT subtable and if TMM subtable has not a route for AAA traffic then MGMT subtable will be used. Source IP address of that traffic will be a local Self-IP.
