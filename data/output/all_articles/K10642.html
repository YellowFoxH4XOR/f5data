Known Issue

This is the result of a known issue. If a BIG-IP LTM is licensed with an unprovisioned BIG-IP ASM module, and the system is being managed by an Enterprise Manager, the following error message is reported in the /var/log/asm file every hour:

purge_mysql_logs.pl ->  /ts/tools/purge_mysql_logs.pl errors: Can't connect to database 'DBI:mysql:host=localhost': Can't connect to local MySQL server through socket '/var/lib/mysql/mysql.sock' (2)
asm_update_sigfile -> /ts/tools/asm_update_sigfile errors iControlPortal.cgi[1686]: 01310027:2: ASM subsystem error (-e,Logger::error): ASM is not licensed/enabled.

The error messages are informational only. The scripts reporting the error messages are run when the BIG-IP ASM system is licensed, provisioned, and operating normally to check the database logs as well as check for updated signature files.

F5 Product Development tracked this issue as CR128801 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM or ASM release notes.

This issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
