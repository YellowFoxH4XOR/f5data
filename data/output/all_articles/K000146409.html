Description

When subscribed to the F5 FCP program, your are required to share usage reports each month. You want to know what data is included in the standard and obfuscated versions of the report.

Environment

  • BIG-IQ 8.X

  • FCP cat licenses (which are being reported on)

Cause

It is important to know what data you are sharing with F5. This article shows what is collected in the normal and obfuscated versions of the report file (known as the json file)

Note: the report file is plain text / json format and can be easily read and reviewed in notepad.

Answer/Recommended Actions

Both versions of the report collect the following information: Product (BIG-IQ), Version of BIG-IW, Report type, Pool type (CLPv2), Reg key for the BIG-IQ, pool reg key (Cat license reg key), Cat license pool name, start and end dates for this report.

In the standard report we include BIG-IP IP addresses, Hostname and Tenant (if used), these are replaced in the Obfuscated version, with X's or redacted-hostname, see lab box report below showing the side by side comparison of the report types.
