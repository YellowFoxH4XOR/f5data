K000141018: Configuration Requirements for Inline Layer 2 Services on rSeries tenants

Type
Support Solution
Published
2024-09-12
Updated
2024-12-04
Source
https://my.f5.com/manage/s/article/K000141018

Topic

When deploying an SSL Orchestrator Inline Layer 2 Service on a BIG-IP Classic rSeries tenant, health check failures of the WAF will occur when using either:

  • tenant deployment defaults of One for the MAC Data/MAC Block Size.
  • BIG-IP Classic traffic group MAC masquerading configuration defaults.

When health checks fail, traffic will not traverse the WAF.

 

Required Action

For an Inline Layer 2 Service to work in a BIG-IP Classic tenant on an rSeries device, the tenant deployment needs to have a pool of MACs; that is, to not use One for the MAC Data/MAC Block Size setting.

 

Important: Altering this configuration setting requires the tenant be set to either Provisioned or Configured. The BIG-IP tenant will not process traffic in these states.

 

If MAC masquerade is desired/required, follow K35390915 to enable per-VLAN MAC masquerade.

 

Important: As noted in K35390915, per-VLAN MAC masquerading is incompatible with VLAN Groups and ePVA accelerated traffic.
