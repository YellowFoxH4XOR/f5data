K13018: Identical software versions must be running on all systems during setup of a BIG-IP WebAccelerator symmetric deployment

Type
Knowledge
Published
2011-08-03
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • BIG-IP WebAccelerator: 10.2.2, 10.2.1, 10.2.0, 10.1.0
Source
https://my.f5.com/manage/s/article/K13018

Issue

Old Behavior

Previously, setting up a BIG-IP WebAccelerator symmetric deployment did not require the BIG-IP WebAccelerator systems to run the same version of software. Although this is not a requirement, F5 recommends that the BIG-IP WebAccelerator systems run the same major and minor version minimally. For example, F5 recommends that all BIG-IP WebAccelerator systems run software version 10.2.0, rather than a mix of versions 9.4.8 and 10.0.1 during the setup of a BIG-IP WebAccelerator symmetric deployment.

New Behavior

Beginning in BIG-IP WebAccelerator 10.1.0, the wam_add.pl script strictly requires the BIG-IP WebAccelerator systems to run the same version of software (including hotfixes) during the setup of a BIG-IP WebAccelerator symmetric deployment. When the wam_add.pl script is executed on the BIG-IP WebAccelerator system that is not running the same version of software as the central BIG-IP WebAccelerator system, the wam_add.pl script fails to add the remote BIG-IP WebAccelerator system to the symmetric deployment and logs an error message in the console output that appears similar to the following example:

ERROR: The central WebAccelerator [<IP address>] is not running the same software version (BIG-IP Version 10.2.2 763.3) as this WebAccelerator (BIG-IP Version 10.2.1 297.0). For a symmetric deployment, both WebAccelerators must be on the same version.

In this error message, note the following

  • <IP address> is the self IP address of the central BIG-IP WebAccelerator system

The wam_add.pl script is executed once per remote BIG-IP WebAccelerator system during the setup of a symmetric deployment. Therefore, the strict requirement for operating with the same software version applies only during the setup. The BIG-IP WebAccelerator systems will perform as expected when running different software versions after the symmetric deployment setup.

F5 Product Development tracked this change as ID 208288.

Impact

None

Recommended Actions

Ensure that all BIG-IP WebAccelerator systems are operating with the same software version before setting up a symmetric deployment.
