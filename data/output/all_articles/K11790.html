Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 10.1.0. F5 recommends that all customers currently running 10.1.0 install HotFix-BIGIP-10.1.0-3402.0-HF2, or a later version of the cumulative hotfix rollup, as soon as possible.
