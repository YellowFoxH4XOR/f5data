Source

Description

Access policy has modern customization and "Prompt user before password expiration" is enabled on "AD Query" agent.
When the users are prompted with the below screen:

New Password
Verify Password
Do not change password => if this checkbox is enabled by the user, the above fields are not greyed out and the user can still change the password.

 

Environment


1. Create AccessProfile with ModernUI settings 
2. Add "AD Query" agent in VPE + "Prompt user to change password before expiration"
3. Log on to the Virtual Server portal
4. When prompted to enter new password: put a new password and enable the checkbox "Do not change password"
5. The password is getting changed!
Note: Expected behaviour should be - "New password" fields get greyed out as soon as you click "Do not change password", which does not happen

Cause

This is a known issue ID917645

Recommended Action

There is no workaround or fix
