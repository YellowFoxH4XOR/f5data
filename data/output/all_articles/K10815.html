K10815: The BIG-IP WebAccelerator incorrectly sets the no-cache directive when the Ignore no-cache HTTP headers in the response setting is disabled

Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator system may incorrectly set the no-cache directive in the Cache-Control header of certain responses. When a node in the WebAccelerator policy is modified by disabling the Ignore no-cache HTTP headers in the response setting, the BIG-IP WebAccelerator system mishandles the Cache-Control header in the event that the origin web server (OWS) inserts a no-cache directive.

F5 Product Development tracked this issue as CR130145 and it was fixed in BIG-IP WebAccelerator 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue was fixed in BIGIP-10.0.1-378.0-HF3, which has been issued for BIG-IP WebAccelerator 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about installing 10.x hotfixes on a Logical Volume Management (LVM) disk-formatted system, refer to in K10025: Managing BIG-IP product hotfixes (10.x).

For information about installing 10.x hotfixes on a partitioned system, refer to K9819: Installing a BIG-IP version 10.x hotfix on a partitioned system.

Workaround

You can work around this issue by enabling the Ignore no-cache HTTP headers in the response setting. To do so, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator Configuration utility.
  2. Open the policy.
  3. Click the appropriate node.
  4. From the drop-down box, select Acceleration Rules.
  5. Click the Lifetime tab.
  6. Select the Ignore no-cache HTTP headers in the response check box.
  7. Click Save.
