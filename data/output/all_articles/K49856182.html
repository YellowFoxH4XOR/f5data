Description

  • Unable to transfer cert files, using the SCP utility, from the path /config/filestore/file_d/Common_d/certificate_d/ after upgrading to BIG-IP version 15.1.5.1
  • The BIG-IP User Name has Terminal Access set to either Disabled or tmsh
  • When attempting to transfer files with SCP, you will see a message similar to the following:

    path not allowed

    For example, using the BIG-IP admin user with Terminal Access set to tmsh, the output of the SCP utility would look similar to the following:

    scp admin@bigip.local:/config/filestore/files_d/Common_d/certificate_d/* .

    (admin@bigip.local) Password:
    path not allowed

Environment

  • BIG-IP
  • Certificate and key files
  • SCP

Cause

The observed behavior is expected and is the result of the fix introduced for the SCP vulnerability, K38271531: BIG-IP and BIG-IQ SCP vulnerability CVE-2022-26340.

Recommended Actions

For BIG-IP users assigned the Administrator role, you can set Terminal Access to Advanced shell. To do so, perform one of the following procedures.

Impact of procedure: Allowing Advanced shell (bash) access for a BIG-IP user allows full bash access to the BIG-IP system. Access should be limited to trusted users and only for the duration where that access is needed. For more information about managing user accounts, refer to the BIG-IP Systems: User Account Administration manual.

  • Use the BIG-IP Configuration utility to grant Advanced shell access to a user
  • Use the TMOS Shell (tmsh) to grant Advanced shell access to a user

Use the BIG-IP Configuration utility to grant Advanced shell access to a user

  1. Log in to the BIG-IP Configuration utility with Administrator role credentials
  2. Go to System > Users > User List.
  3. Select the User Name of the user to be granted bash access.
  4. For Terminal Access, select Advanced shell.
  5. Select Update.

Use the TMOS Shell (tmsh) to grant Advanced shell access to a user

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. Modify the user to whom you will be granting bash access using the following command syntax:

    modify /auth user <user name> shell bash

    For example, to enable bash access for user jdoe, enter the following command:

    modify /auth user jdoe shell bash

  3. To save changes, enter the following command:

    save /sys config
