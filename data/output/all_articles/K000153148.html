K000153148: BIG-IP GUI intermittently kicks the user with an error “Unable to contact BIG-IP device.”

Type
Support Solution
Published
2025-09-15
Updated
2025-09-15
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000153148

Description


While actively working the the BIG-IP GUI, the browser would intermittently disconnect with a pop-up saying "Unable to contact BIG-IP device". Configuring objects through the GUI also takes a long time and may sometimes end up with the pop-up that says BIG-IP can not be contacted. This occurs when there are a number of Bot Defense Profiles that contain staged signatures.


Environment


  • BIG-IP ASM


Cause


  • When there are a large number of bot defense signatures that are in staging and iApp is used to create bot defense profiles with signatures, MCPD can take a while to build a response to app_instance query due to query recursion that needs to be done. The app_instance query is called whenever MCPD needs to save a config. Since MCPD is single-threaded, this causes a cascading effect where the response to GUI's "coloradvisory" probe gets delayed before the browser script's allowed timeout (default 30s) expires. PD will be addressing the root cause through BZ ID2034933.


Recommended Actions


  • There is no fix available at this time. The workaround is to enforce all staged bot defense signatures.
