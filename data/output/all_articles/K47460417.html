Topic

When you set up a newly installed BIG-IP system, you must configure certain BIG-IP system objects. To do so, you can use the Configuration Worksheet.

Description

When you deploy your BIG-IP system for the first time, you must make decisions or provide values to progress through the system deployment process. You can use the Configuration Worksheet to gather the answers and values in advance, so you can provide them when performing the initial setup.
