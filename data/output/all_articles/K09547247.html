Environment

  • BIG-IP
  • Virtual Server with http_router profile configured
  • Prolonged CPU spike
  • Multiple unexpected failover events
  • Core files for TMM in /var/core

Cause
Issue is related to ID 1012533, which is triggered when a connection flow is being torn down and there are still HTTP/2 event(s) queued up to be processed.  Because the connection flow for the remaining events no longer exists, the system runs into the equivalent of an invalid reference, causing the process to crash and generating core files.  The http_router profile shares common code elements with the TMOS HTTP/2 code, which is why it can trigger the ID behavior.

Recommended Actions
Upgrade to a version that is not impacted by this ID (15.1.4.1, 16.1.x).
