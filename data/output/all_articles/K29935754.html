Source

Description

logrotate script fails to run and produces an error similar to the following:

error creating output file /var/lib/logrotate.status.tmp: Permission denied

Environment

  • Logrotate

Cause

SELinux context is incorrect.

Recommended Actions

Execute the following command to restore the SELinux context:

restorecon /var/lib/logrotate.status

Additional Information

None
