Description

When using SSH to connect to the mgmt IP from an account that is already logged in, SSH connects automatically to the Root user and does not ask for a password. Some administrators may like to be asked for a password before connecting via SSH.

Example:

[admin@BIGIP:Active] ~ # ssh 10.x.x.x
Last login: Thu Jun 10 01:17:03  from 172.x.x.x
[root@BIGIP:Active] config # exit <------------- logged in as root user using ssh

Environment

  • SSH
  • BIG-IP

Cause

The login is using Public Key Authentication by default.

Recommended Actions

Disable automatic login with Public Key Authentication via SSH and ensure that the user is asked for a password, run the following commands on the BIG-IP:

# tmsh modify sys sshd include "PubkeyAuthentication No"
# tmsh save sys config

After disabling this option, the SSH connection will ask for password:

[admin@BIGIP-B:Active:Disconnected (Trust Domain Only)] ~ # ssh 10.x.x.x <-------- logged in with ssh
Password: <--------- asked for password
Last login: Fri Jun 11 00:41:40  from 10.x.x.x
