K000152726: Creation of a datagroup

Description

Data groups are used to store and manage lists of related data elements, such as IP addresses, URLs, or strings, for use within iRules. They provide a way to efficiently perform lookups and comparisons against live traffic conditions, making them useful for tasks like access control, traffic management, and content switching. 

Environment

  • BIG-IP LTM
  • iRules
  • Configuration:  data group to reference within iRule

Cause

To create a data group on an F5 BIG-IP device, you can use either the Configuration utility (GUI) or the tmsh command-line interface. Data groups are used to store lists of items that can be referenced in iRules for various purposes like URL filtering, IP address filtering, or other string/integer-based lookups

Recommended Actions

Using the Configuration Utility: 

  1. Log in: the BIG-IP Configuration Utility.
  2. Navigate: Go to Local Traffic > iRules > Data Group List. 
  3. Create: Click the Create button. 
  4. Name: Enter a name for the data group. 
  5. Type: Select the appropriate data type (e.g., String, IP Address, Integer). 
  6. Populate: Add the data entries, either manually or by importing a file. 
    • Manual: For string data, you'll need to specify the string and its corresponding value. For IP addresses, you'll enter the IP address and optionally a value. 
    • External File: If you have a large list of entries, you can import a file containing the data.  For external data groups, you need to import the file first using the File Management section in the Configuration utility.  
      See: K73862425: Creating external data groups
  7. Save: Click Finished to save the data group. 
Using tmsh (command-line):
 
  1. Log in: Access the BIG-IP command line (tmsh).
  2. Create: Use the following syntax: create /ltm data-group internal <data_group_name> type <data_type> records replace-all-with { <record1> <record2> ... }.
    • Replace <data_group_name> with the desired name for your data group.
    • Replace <data_type> with the appropriate data type (e.g., string, ip, integer).
    • Replace <record1>, <record2>, etc., with the actual data entries.
  3. Save: Use save sys config to save the configuration.
