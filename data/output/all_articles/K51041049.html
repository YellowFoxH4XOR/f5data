You use a Network Access Virtual Private Network (VPN) client to establish a VPN connection to the BIG-IP APM system. Use a Network Access VPN client that works with the operating system on your client device. For comprehensive information about configuration parameters that enable you to manage client-side behavior, refer to K49720803: BIG-IP Edge Client operations guide | Chapter 3: Common approaches to configuring VPN.
