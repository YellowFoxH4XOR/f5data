Known Issue

The BIG-IP system fails to include the Acct-Session-Id in the RADIUS packet when sending a RADIUS Accounting monitor probe. This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured with a custom RADIUS Accounting monitor.
  • The custom RADIUS Accounting monitor is assigned to a pool or pool member.

When this issue occurs, the RADIUS pool member may report an error message that it has received a RADIUS packet with an invalid attribute or insufficient information and stops responding to the BIG-IP RADIUS Accounting monitor. As a result, the BIG-IP system marks the RADIUS pool member as down.

Note: Depending on the type of RADIUS server used, the RADIUS pool member may or may not report the described error messages. F5 recommends you consult your RADIUS server manual for information regarding error messages or enabling verbose error messages to be reported.

According to RFC2866, the Acct-Session-Id is a RADIUS attribute Type 44. It provides a unique accounting ID to match start and stop records in a log file, and must be included in a RADIUS Accounting request packet.

Impact

RADIUS traffic processing may be interrupted.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H429337 on the Diagnostics > Identified > Low screen.
  • The BIG-IP system marks the RADIUS pool member down without any reported error messages. However, the RADIUS pool member may report that it has received a RADIUS packet with an invalid attribute or insufficient information.
  • A packet capture on the affected RADIUS traffic shows the RADIUS Accounting packet sent by the BIG-IP RADIUS Accounting monitor does not contain the Acct-Session-Id attribute Type 44.
