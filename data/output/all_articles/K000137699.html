Description

Deployment of Virtual server with HTTP Analytics profile on cluster devices failing with Gui error:

"Writing changes to the peer failed so they were not synced to this device".

On peer big-ip error:

Failed pushing added objects to device localhost.f5.com : status:400, body:{"code":400,"message":"One of the following features must be licensed/provisioned for the URI ltm/profile/analytics : avr","errorStack":[],"apiError":1}

 

Evaluation passes

 

Environment

BIG-IQ CM

BIG-IP without AVR provisioned

Virtual server Deployment with HTTP Analitics profile

Cause

No AVR Provisioned.

Recommended Actions

Provision AVR before deploying VS

Additional Information

Evaluation does not check provisioning on BIG-IPs. Its focused on configuration
