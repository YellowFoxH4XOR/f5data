Description

BIG-IP VE on AWS is unable to generate a dossier after its license expires or after its license is revoked.

Errors similar to the following can be seen in the LTM log file around the time that the dossier is being generated:

 

   err chmand[4610]: 012a0003:3: DossierReq exception: VirtDossier Service: Instance identity retrieval from the metadata failed. Check network connectivity to the instance metadata before retrying

   warning get_dossier[10914]: 012a0004:4: hal_request_dossier: request failed

   err get_dossier[10914]: 01170003:3: halGetDossier returned error (1): Dossier generation failed.

Environment

  • BIG-IP VE on AWS
  • Single NIC (1nic)

Cause

An incorrect route parameter is set due to a race condition during config load after a license expires or after the license gets revoked. This prevents the BIG-IP VE from being able to communicate with the AWS metadata server which is necessary during dossier generation.

F5 PD is tracking this as ID1757585.

Recommended Actions

Workaround is to force the default route to use the "internal" device rather than "mgmt" using the command:

tmsh create net route default gw {gateway_IP_addr} 

where {gateway_IP_addr} is the actual management gateway IP address of the AWS BIG-IP VE instance.

 

Restart TMM thereafter using the command:

 bigstart restart tmm
