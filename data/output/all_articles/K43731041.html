Description
External health monitor that wrote by Python is not working in 14.1.x version and it returns an error like below:

ssl.SSLError: [SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed (_ssl.c:579)
 

Environment

  • External monitor
  • External monitor script is written by Python 
  • SSL connection is initiated using Python httplib library 

Cause
Certification verification has been added on version 14.1.x for python code under /etc/python/cert-verification.cfg

Recommended Actions

Modify verify=platform_default  as verify=disable on /etc/python/cert-verification.cfg

#verify=platform_default
verify=disable
