Description

Environment

  • OpenShift 4.x
  • Aspen Mesh 1.11.x
 

Cause

Incorrect Service Account used by the scripts to communicate with the kube-apiserver

 

Recommended Actions

Make sure to use the correct Service Account with access to the kube-apiserver
