K000163473: Authentication failed when logging in to the partition

Type
Support Solution
Published
2026-09-30
Updated
2026-09-30
Source
https://my.f5.com/manage/s/article/K000163473

Description

Authentication fails when system controller credentials are used to access a partition. System controller, partition, and tenant accounts are separate and cannot be used interchangeably.

Environment

  • F5OS system
  • Newly created partition
  • Access attempted with system controller credentials

Cause

The partition requires partition-level credentials. System controller credentials are not valid for partition access.

Recommended Actions

  1. Use an account configured specifically for the partition.
  2. At first login to the partition use default credentials: admin/admin
  3. Change any default partition credentials before placing the system into production.

Additional Information

System controller, partition, and tenant accounts are unique to their respective management levels. Authentication fails when credentials from one level are submitted at another level.
