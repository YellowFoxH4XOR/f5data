Known Issue

When an unmatched connection occurs, the system may not send a Transmission Control Protocol (TCP) reset (RST) for a data packet.

This issue occurs when all of the following conditions are met:

  • You provision BIG-IP LTM.
  • You provision BIG-IP AFM or BIG-IP ASM 12.1.0 or later.
  • You set the TCP profile connection timeout to 30s.
  • In the TCP profile, you have set the Reset on timeout to No.
  • The system sends the data packet to the virtual server after the connection timeout, or packets other than a SYN packet arrive, with no entry in the connection table.

Impact

The client retransmits several times and then terminates the TCP connection. The BIG-IP system does not send an RST to the client for the unmatched connection.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the TCP connection times out (there is no entry in the show sys conn field), a subsequent data packet that is not a SYN packet comes in.
  • The BIG-IP system does not send an RST to the client to reset the connection.
