Known Issue

Creation of a BIG-IP APM virtual server may fail.

This issue occurs when all of the following conditions are met:

  • The system is licensed with only the BIG-IP APM module (standalone license).
  • You attempt to create a virtual server that uses a Performance (Layer 4) FastL4 profile.

Impact

Virtual server creation fails validation.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use the Configuration utility to create a virtual server that references the fastL4 profile, you receive a validation error and the system does not create the virtual server.
  • When you attempt to create a virtual server that references the fastL4 profile, or attempt to create an IPSec configuration, you may observe, in the /var/log/ltm file, an error message similar to the following example:

    The requested profile (/<partition>/fastL4) was not found.
