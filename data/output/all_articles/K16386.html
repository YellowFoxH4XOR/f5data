Known Issue

An iRule may execute the wrong proc command.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration has multiple administrative partitions.
  • You have a virtual server and an associated iRule configured in each administrative partition.
  • Each iRule has defined a proc command using the same name.

Impact

  • Virtual servers may unexpectedly share an iRules proc command.
  • Client connections may receive unexpected data.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H516581 on the Diagnostics > Identified > Medium screen.
  • Virtual servers appear to share the same iRules proc command.
  • Clients receive unexpected data.

Workaround

To work around this issue, ensure all iRules proc names defined in the BIG-IP configuration are unique.
