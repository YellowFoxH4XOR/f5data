Topic

You should consider using this procedure under the following condition:

  • You want to associate a virtual server with an explicit link object.

Description

A link is an optional BIG-IP DNS or BIG-IP Link Controller configuration object that represents a device (such as a router) and connects your network to the Internet. When you create one or more links on the BIG-IP DNS or BIG-IP Link Controller system, the system uses the following logic to automatically associate virtual servers with the link objects:

  • The BIG-IP DNS and Link Controller systems associate the virtual server with the link by matching the subnet addresses of the virtual server, link, and self IP address. Most of the time, the virtual server is associated with the link that is on the same subnet as the self IP address.
  • In some cases, the BIG-IP DNS system and BIG-IP Link Controller cannot associate the virtual server and link because the subnet addresses do not match. When this issue occurs, the system associates the virtual server with the default link, which is assigned to the data center. This association may cause issues if the link that is associated with the virtual server does not provide network connectivity to the virtual server.

If the virtual server is associated with a link that does not provide network connectivity to that virtual server, the BIG-IP DNS system and BIG-IP Link Controller may incorrectly return the virtual server IP address in the DNS response to a wide IP query even if the link is disabled or marked as down.

Prerequisites

You must meet one of the following prerequisites to use this procedure:

  • You can access the Configuration utility. Version 11.6.0 and later.
  • You can access the Traffic Management Shell (tmsh). All versions.

Procedures

  • Associating a virtual server object with an explicit link using the Configuration Utility
  • Associating a virtual server object with an explicit link using tmsh

Associating a virtual server object with an explicit link using the Configuration Utility.

Note: The ability to use the Configuration utility is only available in BIG-IP DNS systems running software versions 11.6.0 and later.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to DNS > GSLB > Servers > Server List.
  3. For Name, select the server that manages the virtual server object.
  4. Select Virtual Servers.
  5. For Name, select the virtual server.
  6. Under General Properties, select the Link name.
  7. Select Finished.

Associating a virtual server object with an explicit link name using tmsh

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by entering the following command:

    tmsh

  2. To associate a virtual server object with an explicit link name, use the following syntax:

    modify /gtm server <server> virtual-servers modify { <virtual server> { explicit-link-name <link> } }

    For example, to associate a virtual server called HTTP-VIP with a link object named LINK-B, type the following command:

    modify /gtm server GTM-A virtual-servers modify { /Common/HTTP-VIP { explicit-link-name LINK-B } }

  3. Save the change by entering the following command:

    tmsh save /sys config gtm-only

  4. For BIG-IP GTM and BIG-IP Link Controller 11.2.1 - 11.4.1, you may need to restart the gtmd process for the explicit link to show up, due to a display issue. For more information, refer to K14881: BIG-IP GTM and Link Controller may not correctly display virtual server link references.
