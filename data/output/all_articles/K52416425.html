Description

BIG-IP AFM does not report an error when a user associates a single NAT source or destination translation object with multiple NAT policies or with multiple NAT rules in the same NAT policy. However, such configuration is invalid and traffic may not be processed and forwarded as expected.

Environment

  • BIG-IP AFM
  • Static NAT configured for source or destination translation object
  • The single source or destination translation object is associated with multiple NAT policies or multiple NAT rules in the same NAT policy.

Cause

Static NAT should provide a 1:1 mapping between Private and Public IP's. Public IP's should not be shared among private IP's.

Recommended Actions

FW NAT source/destination translation object should not be associated with multiple NAT policies. When translation object is already associated with multiple NAT policies and traffic is not processed as expected, follow steps below to make it working again.

  1. Dissociate the source/destination translation object from all the policies (both the original and additional policies)
  2. Associate the translation object to only one NAT policy
