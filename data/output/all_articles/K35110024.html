K35110024: GARP for Self IP is not sent during failover if the address is also used for SNAT in a multi-tenants environment

Description
In a multi-tenants environment, the floating Self IP address will not send out its GARP when failover is occurred which will break the application traffic.

Environment

  • BIG-IP HA (DSC)
  • Partition
  • Multiple traffic group

Cause
When the same IP address is used for both floating Self IP and SNAT translation address, there is a chance that they are configured with different traffic group. In this scenario, the GARP for this IP address cannot be sent due to the confusing of the accurate traffic group to which the IP address belongs.

Recommended Actions

  1. Avoiding such IP address use case. SNAT should use a dedicated IP address (range) to make sure the availability and capacity.
  2. If such use case is required, make sure each LTM objects that using the same IP address are configured with the same traffic group manually. By default these LTM objects can inherit the traffic group configuration from the root folder in multi-tenants environment which may cause inconsistence settings.
