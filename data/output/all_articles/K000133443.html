Description

You are experiencing unexpected changes on your BIG-IP system and want to identify who is making these changes.

Environment

  • BIG-IP system
  • Multiple users with access to the system

Cause

N/A

Recommended Actions

  1. Log in to the BIG-IP system via SSH or console as an administrator.
  2. Change to the /var/log/audit directory by running the command:   cd /var/log/audit
  3. Search for the objects related to the changes by using the 'grep' command. Replace '<object_name>' with the name of the object you want to find:

grep -i '<object_name>' *.log

This command will display the log entries containing the object name, along with the username and timestamp of each change event.
