Description

When tenant's interface is marked down, no SNMP traps are sent by the tenant.

In the tenant's /var/log/ltm file, no messages similar to below are logged:

Error Message: 01230002:4: Interface <#>.<#>: link is down

Environment

  • rSeries r2000/r4000 F5OS-A appliance
  • BIG-IP Tenant
  • SNMP Trap

Cause

Link Down/Up message is not logged on tenant even if Link Down/Up occurs on F5OS-A.

This is tracked internally as ID 1474381.

Recommended Actions

Use F5OS-A SNMP traps for monitoring interface status.

Additional Information

rSeries F5OS-A SNMP Monitoring and Alerting
