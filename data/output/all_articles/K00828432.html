Issue

Error Message

notice zxfrd[<PID>]: 0153002c:5: An instance of zxfrd (pid: <#>) is already running! Exiting

In this error message, note the following:

  • <PID> is the process ID for the new zxfrd process instance
  • <#> is the process ID for the existing zxfrd process 

For example:

notice zxfrd[8485]: 0153002c:5: An instance of zxfrd (pid: 6016) is already running! Exiting

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • An instance of the DNS Express zone transfer daemon (zxfrd) has attempted to start while another instance was already running.

This is most likely to occur if an instance of the zone transfer daemon was manually started using the /var/service/zxfrd/run script.

Impact

The second instance of the DNS Express zone transfer daemon will exit leaving the first to continue processing.

Recommended Actions

If there is a single instance of this message, occurring in a situation where the BIG-IP system or the zxfrd process has recently been started, then there is likely no issue and no action required.

If this message persists or is occurring in a situation where the BIG-IP system or the zxfrd process has not recently been started, then it might indicate a problem with the status of zxfrd. You may be able to resolve the issue by restarting the zone transfer daemon using the bigstart restart zxfrd command.
