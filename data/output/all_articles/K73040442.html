Description

The BIG-IP system uses crond to run the check-cert utility every Sunday at 4:22 AM and logs the alert/log about any certificate expiration on device. 
You get a warning log similar to the following, indicating that a certificate on the default BIG-IP CA-bundle has expired :

warning tmsh[<PID>]: 01420008:4: Certificate 'CN=<CertificateName> CA,O=<CertIssuer>, Inc.,C=US' in file /Common/ca-bundle.crt expired on <Month> <Day> <HH:MM:SS> <YEAR> <TIME ZONE>
This article is to describe how to disable or remove this logs or alerts completely from the ltm logs. 

Environment

  • Ca-bundle certificates on BIG-IP

Cause

The default CA certificate bundle file used by the system contains some expired certificates and device logs the alert/log about any certificate expiration on device. 

Recommended Actions
You can refer one of the two methods below:

Disable the line which does the cert check in corn.weekly: 

  1. Run below command to navigate to directory:
    cd /etc/cron.weekly
  2. Open 5checkcert file in vi editor using below command:
    vi 5checkcert
  3. Hit enter and 'i' to edit the file.
  4. Add '#' at the start of below line as below:
    #/usr/bin/tmsh run sys crypto check-cert stdout disabled
  5. Hit 'ESC' on keyboard and type ':wq!' to save and exit the vi editor.
OR

You can completely move the 5checkcert file from /etc/cron.weekly to some other directory so that crond will no longer run it weekly:
To move the 5checkcert file from /etc/cron.weekly to some other directory, run below commands:
cd /etc/cron.weekly mv 5checkcert /var/tmp/
