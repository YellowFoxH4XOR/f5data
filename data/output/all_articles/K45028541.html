Description

NGINX Plus, as part of the ELA / FCP, is charged per installed device and consumed from the annual commit value.
F5 Requires that you share an accurate count of NGINX Plus instances at least once a quarter.
This solution shows how to install the F5 Telemetry Tracker script on NGINX Controller.

Environment

  • NGINX Plus
  • Controller Agent
  • NGINX Controller
Cause

You will SSH into your Controller, Download and install Second Sight script, configure, and execute it.
You will then send the results by email to your Customer Success Manager.

Recommended Actions

You will log into the Controller and add new device, copy the curl or wget command and execute it on the NGINX(PLUS) instance to install Controller “Agent”

  1. SSH into your NGINX Controller
  2. Download Second Sight from GitHub

    git clone https://github.com/F5Networks/SecondSight  

  3. Change directory to /SecondSight/f5tt

    cd SecondSight/f5tt

  4. Edit the file called f5tt.sh

    vi f5tt.sh

  5. Uncomment the 4 “NGINX_CONTROLLER” export lines (remove the # at the start of each line)
    Edit the NGINX_CONTROLLER_FQDN line to the IP address and port of your Controller.
    Note: the script needs the username and password fields to be uncommented, but NGINX Controller does not use them currently.

    export DATAPLANE_TYPE=NGINX_CONTROLLER
    export DATAPLANE_FQDN="http://10.1.1.1:443"
    export DATAPLANE_USERNAME="admin"
    export DATAPLANE_PASSWORD="Password"

  6. Save the file
  7. Start the script

    ./f5tt.sh &

  8. Query the instance count by running the curl command below

    curl -s http://127.0.0.1:5000/instances | jq

  9. Observe the output under “instances”

    "instances": [
        {
          "nginx_plus_online": 0,
          "nginx_oss_online": 1
        ...
        }

  10. Please copy and paste the above output to your Customer Success Manager.
