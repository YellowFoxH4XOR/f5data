K01116401: BIG-IP iRules do not support the LB::select iRule command on CMP-enabled virtual servers that use persistence

Type
Knowledge
Published
2016-08-02
Updated
2023-02-21
Applies to
  • BIG-IP PEM: 16.X.X
Source
https://my.f5.com/manage/s/article/K01116401

Topic

BIG-IP iRules do not support the LB::select command on Clustered Multiprocessing (CMP)-enabled virtual servers that use persistence. A CMP-enabled virtual server may require that a Traffic Management Microkernel (TMM) retrieve persistence data from another TMM instance, and the LB::select iRule command is not supported in this scenario. You may intermittently observe connection stalls if the unsupported configuration is used in your environment.

Note: Beginning in BIG-IP 12.1.0, the LB::select iRule command has been removed from the Traffic Management Shell (tmsh) help and Configuration utility auto-complete.
