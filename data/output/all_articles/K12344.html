Known Issue

If you upgrade to ARX version 5.2.0, and your configuration prior to the upgrade contains two or more share farms, the upgrade process may corrupt the share farm configuration. When this issue occurs, the ARX system intermittently dumps core and reloads after the upgrade.

Important: You should not upgrade to ARX version 5.2.0 (build 12637) if your current configuration contains two or more share farms.

F5 Product Development tracked this issue as ID 344117 and it was fixed in ARX 5.2.2. For information about upgrading, refer to the ARX Release Notes.

Workaround

Customers affected by this issue should contact F5 Technical Support for further assistance.

If you did not experience any issues after upgrading to ARX version 5.2.0, you may continue to run this version. The issue described in this Solution only affects the upgrade process, so you may safely add or remove share farms.
