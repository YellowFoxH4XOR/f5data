Known Issue

This is the result of a known issue. When the BIG-IP ASM system encounters violations within a split-request (such as a POST request), it may incorrectly duplicate the violation entries and report the following error messages to the /var/log/asm file:

perl[15994]: 01310027:2: ASM subsystem error (learning_manager.pl,main::learn_illegal_file_type):
Duplicate entry '10288845649378174110' for key 1 on "INSERT INTO PLC.LRN_UNDEF_FILE_TYPES (account_id,request_id,obj_crc,extension,actual_extension,total_len,uri_len,query_len,
post_len,flg_tightening,flg_disallowed_file_type) VALUES (?,?,?,?,?,?,?,?,?,?,?)" values=
(5,10288845649378174110,10707370446933721087,*,no_ext,3544,34,0,1319,1,0)

Note: The LRN_UNDEF_FILE_TYPES table name may differ, but the meaning is the same.

This issue typically occurs with POST requests that are sent as two parts, with the headers in one packet and payload in separate packets within the same TCP stream. You can determine that you are experiencing this issue by identifying at least one of the following behavior patterns:

  • Client sends POST request headers (including content length), but no data is sent
  • Server responds with an HTTP 100 (continue)

    Note: This is typical response behavior when sending a POST request that spans multiple packets.
  • The client sends a second POST request that includes data
  • Server responds with an ultimate response code

When this issue occurs, the BIG-IP ASM system logs any violations encountered from the initial request headers into the database. After subsequent data is received, such as data expected to immediately follow the request headers, the BIG-IP ASM system will immediately log those violations as well. As a result, duplicate violation entries are logged in the database, which the Learning Manager attempts to process.

Important: No violation information is lost when this issue occurs, and learning suggestions will still be correctly generated.

F5 Product Development is tracking this issue as CR103699. To monitor the status of this CR, refer to the BIG-IP ASM Release Notes.
