Description

While traffic is passing through BIG-IP, you are getting "Unable to perform query" error message in VMWare Cloud Director and most of the windows are not being loaded correctly.

 

Environment

  • BIG-IP
  • VMWare Cloud Director

 

Cause

Page content is not being loaded correctly due to maximum header count being exceeded.

If you obtain packet capture, you will see that connections are being reset with below reset cause:

[F5RST(peer): HTTP header count exceeded by server]

 

Recommended Actions

Increase maximum header count in HTTP profile to 128 according to K22518624: HTTP profile can restrict the header count

If that would not resolve the issue, increase it to 256.

None.
