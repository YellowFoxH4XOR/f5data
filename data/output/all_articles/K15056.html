Topic

You should consider using this procedure under the following condition:

  • You want to disable the IPv6 capabilities of the BIG-IP system.

Description

For either network policy or security reasons, you may have to disable IPv6 functionality on a BIG-IP system. To do so, perform the following procedure.

Note: The output of ifconfig -a still shows a configured IPv6 mac addresses, but the BIG-IP system does not receive or transmit IPv6 traffic.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can log in to the BIG-IP command line as the root user or have administrator privileges in the TMOS Shell (tmsh).

Procedures

Disabling or enabling IPv6

You can disable IPv6 by modifying a BIG-IP database key.

Impact of procedure: The BIG-IP system will no longer send or respond to IPv6 traffic.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To view the current setting of the ipv6.enabled system db variable:

    list /sys db ipv6.enabled
     
  3. To disable IPv6, type the following command:

    modify /sys db ipv6.enabled value false

    To enable IPv6, type the following command:

    modify /sys db ipv6.enabled value true

  4. Save the change by typing the following command:

    save /sys config
