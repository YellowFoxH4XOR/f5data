Known Issue

When creating a new Network Access lease pool on a partition other than the common partition, which has a route domain greater than zero, you may receive the following error message:

In leasepool <lease pool name>, the member does not have a valid address range: only IPv4 addresses are supported

This error message may occur when you enter either a single IPv4 address or a range of IPv4 addresses. This error message does not occur if the Network Access lease pool has been created on the common partition. It also does not occur of the partition other than the common partition has the default route domain 0.

F5 Product Development tracked this issue as CR137226, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
