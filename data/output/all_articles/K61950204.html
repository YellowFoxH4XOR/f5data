Description

FIPS Integrity Check fails after creating certificate archive with the following error:

missing     /config/ssl/ssl.csr

1 critical file(s) missing

=======================================================

0 critical file(s) modified

=======================================================

Integrity Check Result: [ FAIL ]

Environment

  • FIPS-140 Licensed
  • Generate a new SSL Certificate Archive:
    • System  >  Certificate Management > Traffic Certificate Management > SSL Certificate List  >  Archive
      • Click Generate & Download Archive
  • /config/ssl/ssl.csr is missing.

Cause
ID 939085

Recommended Actions

Recreate /config/ssl/ssl.csr directory and set correct file permissions.

mkdir /config/ssl/ssl.csr
chmod 755 /config/ssl/ssl.csr/
chcon -R --reference=/config/ssl/ssl.crt/ /config/ssl/ssl.csr

None
