Description

When attempting to add an alias port to an LDAP monitor in BIG-IP, an error message "Cannot modify the address type of monitor" is encountered. This issue arises even after removing the monitor from the pool.

Environment

  • Product: BIG-IP LTM
  • Version: 16.X or 17.X
  • Configuration: LDAP monitor

Cause

The error "Cannot modify the address type of monitor" is due to a bug (Bug ID 955617). This issue occurs when attempting to modify properties of a monitor that is already in use by a pool. The monitor instance continues to reference the pool member even after the monitor is removed from the pool.

Recommended Actions

Create a new monitor with custom alias port and attach it to the Pool.

Additional Information

None.
