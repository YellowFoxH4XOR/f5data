Known Issue

The Java version of the Microsoft Terminal Services (Remote Desktop) client is currently incompatible with Norwegian keyboards. If you configure a Microsoft Terminal Server favorite and select the Java client check box, the Java client may incorrectly interpret characters entered from a Norwegian keyboard.

Note: The ActiveX version of the Microsoft Terminal Services works correctly with Norwegian keyboards.

F5 Product Development is tracking this issue as CR127390.

Workaround

If you do not need to support Linux and Mac OS X clients, you can work around this issue by enabling the ActiveX version of the Microsoft Terminal Services client. To do so, perform the following procedure:
  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Application Access: Terminal Servers: Resources page.
  3. Select the name of the Terminal Servers favorite you want to configure.
  4. Clear the Java client check box.
  5. Click the Update button.
When users launch the Terminal Server favorite, the client system will now use the ActiveX version of the Microsoft Terminal Services client.
