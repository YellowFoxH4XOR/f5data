Description

Connecting through a virtual server, an 8 second delay in sending the SSL/TLS Client Hello is observed in the server-side connection.

The preceding TCP connection is established without delay.

Environment

  • Client + Server SSL profiles
  • HTTP profile
  • Mirroring enabled

Cause

The sys db statemirror.secure and/or sys db statemirror.verify database keys are not enabled.

sys db statemirror.secure {
    default-value "disable"
    scf-config "true"
    value "disable"
    value-range "disable enable"
}
sys db statemirror.verify {
    default-value "disable"
    scf-config "true"
    value "disable"
    value-range "disable enable"
}

Recommended Actions

Enable the sys db statemirror.secure and sys db statemirror.verify database keys, as recommended in:

  • K17391: Configuring SSL connection mirroring for Client SSL virtual servers

tmsh modify /sys db statemirror.secure value enable
tmsh modify /sys db statemirror.verify value enable

Alternatively, disable mirroring for the virtual server.
