Description

This article describes how to set up the management IP on rSeries/VELOS systems for the first time from the CLI.

Environment

  • F5OS-A / F5OS-C
  • rSeries / VELOS
  • CLI
  • Management IP Address
  • Initial setup

Cause

  • n/a

Recommended Actions

  1. Connect through the console port. For more information, refer to K000139067: Connecting to the serial console on the rSeries and VELOS
  2. When prompted for the username and password use the default values admin/admin.

    Note: The root/default credentials will log you into bash. Run the following command in that case: su admin

  3. To enter ConfD mode, run the following command:

    config

  4. To configure the management IP address, use the following syntax:

    system mgmt-ip config ipv4 <system> address <management IP>
    Note: For VELOS, replace <system> with controller-1, controller-2, or floating as appropriate.

    system mgmt-ip config ipv4 prefix-length <network prefix, normally 24>
    system mgmt-ip config ipv4 gateway <gateway for the management interface IP>

    Note: please refer to further CLI reference in Additional Information.
