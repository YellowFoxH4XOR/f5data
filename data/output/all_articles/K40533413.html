Topic

You should consider using this procedure under the following condition:

  • You want to list the BIG-IP ASM attack signatures for a particular security policy using the iControl REST API.

Description

You can use the iControl REST API to perform many BIG-IP ASM system management and configuration tasks. For example, you may want to use the iControl REST API to list the BIG-IP ASM attack signatures for a particular security policy and then import the data into a spreadsheet application for review. For more information about the iControl REST API, refer to the iControl REST User Guide that applies to your BIG-IP version, available on DevCentral.

Note: A DevCentral login is required to access this content.

curl and jq utilities

Performing the following procedure requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems but can also be installed on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure from a BIG-IP system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP system is licensed, provisioned, and configured with a management IP address.
  • You have administrative access to the BIG-IP Configuration utility.
  • You have login access to DevCentral to review iControl REST API documentation.

Procedures

Determining the MD5 hash identifier for the security policy

Each BIG-IP ASM security policy configured on the system has a unique MD5 hash identifier that represents the policy name. Before you can list the attack signatures for a security policy using the iControl REST API, you must determine the MD5 hash identifier for the specific policy in question, and then include the MD5 hash value when you define the URI to retrieve the signature list. To determine the MD5 hash identifier for the specific policy, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to determine the MD5 hash identifier for the policy name:

    curl -sku <username:password>  https://<BIG-IP hostname or management IP address>/mgmt/tm/asm/policies?\$select=name,id | jq '.'

    For example, the following command returns a single security policy named asm_pol2 and related MD5 hash identifier (2jmmsuDvxWreQtHPCgngZw) for host BIGIP.example.com:

    curl -sku admin:admin  https://BIGIP.example.com/mgmt/tm/asm/policies?\$select=name,id | jq '.'

Listing the BIG-IP ASM attack signatures for a security policy

To list the BIG-IP ASM attack signatures for a security policy, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to list the BIG-IP ASM attack signatures for a security policy:

    curl -sku <username:password>  https://<BIG-IP hostname or management IP address>/mgmt/tm/asm/policies/<MD5 hash identifier>/signatures | jq '.'

    For example, the following command returns the list attack signatures for the security policy with the MD5 hash identifier of 2jmmsuDvxWreQtHPCgngZw for host BIGIP.example.com:

    curl -sku admin:admin  https://BIGIP.example.com/mgmt/tm/asm/policies/2jmmsuDvxWreQtHPCgngZw/signatures | jq '.'

  3. Review the attack signature data and optionally import the data into a spreadsheet application for later review.
