Description

When booting into the newer software volume and choosing 'Install Configuration' option, following errors are noted in GUI.

Internal Server Error
The server encountered an internal error or misconfiguration and was unable to complete your request.

Below logs are also noted in  /var/log/ltm  and the upgrade process will not proceeded further.

Aug 15 00:05:06 LTM1 err syscalld[8196]: 0127000a:3: OPERATION_TIMEOUT -- the operation /usr/sbin/cpcfg (pid 10419) may be hung or taking a long time.
Aug 15 00:05:06 LTM1 err syscalld[8196]: 0127000a:3: OPERATION_TIMEOUT -- the operation /usr/sbin/cpcfg (pid 10419) timed out, so we are no longer monitoring it. 

Environment
  • BIG-IP software upgrade

Cause
None

Recommended Actions

1. Restart the hung syscalld process
# bigstart restart syscalld

Additional Information
The configuration is automatically copied from the existing volume when installing the software on the new volume during the upgrade process. "Install Configuration" option is only needed if you have updated the configuration on the existing volume after install but prior to booting into the new volume.
