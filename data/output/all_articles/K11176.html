Topic

This article describes how to download and install updates to the IP geolocation database.

Description

You can download the IP geolocation database files and install them on the BIG-IP system by performing the following procedures:

  • Determining whether the IP geolocation database is up-to-date
  • Downloading the geolocation database
  • Backing up the existing geolocation database
  • Installing the geolocation database update
  • Restoring the previously backed up geolocation database

To watch a video demo of these procedures, go to  Downloading and installing updates to the IP geolocation database.

Note: The IP Geolocation Pulse database requires at least 900 MB of system memory. Ensure you provision sufficient system memory when updating or migrating to the GeoIP Pulse database. For more information, refer to ID 1070841.

Determining whether the IP geolocation database is up-to-date

F5 regularly releases database updates in the GeoLocationUpdates container on the MyF5 Downloads site. If the IP geolocation database on your BIG-IP system is not the latest, you can download and install the updated IP geolocation database files. To determine whether the IP geolocation database files on the BIG-IP system are up-to-date, use both of the following methods:

  • refer to the procedure in K12866: Troubleshooting IP geolocation database inaccuracies.
  • In addition, you can verify the version from the output of the geoip_lookup command to query the database. For example, the following command syntax queries one of the database files for a specific IP address:

geoip_lookup <IP address>

Observe the version from the output when querying the default /shared/GeoIP/v2/F5GeoIP.dat file. For example:

# geoip_lookup 104.219.104.154
opening database in /shared/GeoIP/v2/F5GeoIPOrg.dat
size of geoip database = 23004752, segments = 9236544, version = Copyright (c) F5 Networks Inc, All Rights Reserved GEOIP2 v1, 20260401
[...]

Note: F5 does not support IP geolocation database that is not released by F5.
Note: IPv6 is included in the default RPM packages, not as a separate file.

Downloading the geolocation database

You can download database updates by performing the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Access the MyF5 site.
  2. Go to Resources > Downloads.
  3. In Account, if you have more than one MyF5 account, select the account you want.
  4. Select the check box to agree with the End User License Agreement and Product Terms.

    Note: The check box displays only when F5 does not yet have a record of you accepting these agreements.

  5. In Group, select the product family you want. In this case, you should select BIG-IP.
  6. In Product Line and Product Version, select the product and version you want. For example, BIG-IP v21.x / Virtual Edition with Traffic Management Operating System (TMOS) for Product Line and 21.0.0 for Product Version.
  7. Under Select a product container, select the product container you want. In this case, you should select GeoLocationUpdates_Edge (to use Edge database) or GeoLocationUpdates_Pulse (to use Pulse database).
  8. Under Select a download file, select a file that you want to download. In this case, you should select the ip-geolocation file with file extension .zip. For example, ip-geolocation-v2-2.0.0-20260504.838.0.zip.

    Note: You can download only one file at a time.

  9. At the bottom of the page, in Download locations, select the location nearest you.
  10. Select Download.
  11. After the system finishes downloading the first file you selected, return to the Select a download file section, and then select the next file you want to download. In this case, you should select the MD5 file of the ip-geolocation file you have downloaded from previous steps. For example, ip-geolocation-v2-2.0.0-20260504.838.0.zip.md5.
  12. Repeat the steps 9 through 10 to download the MD5 file.

Backing up the existing geolocation database

The BIG-IP system software ships with the default IP geolocation database files located in the /usr/share/GeoIP directory. When you download and update the IP geolocation files, files are extracted to the /shared/GeoIP directory. If you have already installed a non-default database, you can backup that database by performing the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Advanced shell (bash).
  2. Create a backup directory by entering the following command:

    mkdir /shared/GeoIP_backup

  3. Back up the database by entering the following command:

    cp -R /shared/GeoIP/* /shared/GeoIP_backup/

    Note: You do not need to back up the default database files located in /usr/share/GeoIP.

Installing the geolocation database update

After you download the database update, you can install it using the following procedure:

Note: You may encounter the known issues ID 705869 and ID 1642301 when loading the RPMs in this procedure. 
Note: The database update is not shared through the Configuration utility. If your BIG-IP system is part of a high-availability (HA) configuration, you need to repeat this process on each system in your configuration.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Copy the ip-geolocation zip and MD5 files you downloaded from the MyF5 Downloads site to the /shared/tmp directory on the BIG-IP system.

    Note: You may encounter the known issue ID 819429 when transferring files to /shared/tmp. You can workaround the issue by performing the workaround, to transfer the file to the /var/tmp directory instead.

    Note: For information about transferring files to the F5 system, refer to K175: Transferring files to or from an F5 system.

  2. Log in to the BIG-IP command line.
  3. Change the working directory to the /shared/tmp directory by entering the following command:

    cd /shared/tmp

  4. Check the MD5 checksum of the downloaded file by using the following command syntax:

    md5sum -c <ip-geolocationfile>.zip.md5

    For example:

    md5sum -c ip-geolocation-v2-2.0.0-20260504.838.0.zip.md5

    If the checksum matches, the system displays a result similar to the following example:

    ip-geolocation-v2-2.0.0-20260504.838.0.zip: OK

  5. Unzip the file you copied in step 1 to extract the RPM files. To do so, use the following command syntax, where <ip-geolocationfile>.zip is the name of the zip file you copied to the /shared/tmp directory:

    unzip <ip-geolocationfile>.zip

    For example:

    # unzip ip-geolocation-v2-2.0.0-20260504.838.0.zip

    Archive: ip-geolocation-v2-2.0.0-20260504.838.0.zip
      inflating: geoip-data-v2-Region2-2.0.0-20260504.838.0.i686.rpm
      inflating: geoip-data-v2-ISP-2.0.0-20260504.838.0.i686.rpm
      inflating: geoip-data-v2-Org-2.0.0-20260504.838.0.i686.rpm
      inflating: README.txt

  6. For each RPM file you extracted, use the following command syntax to install and load the database file, where </path/to/rpm> is the path to the RPM file:

    geoip_update_data -f </path/to/rpm>

    For example:

    # geoip_update_data -f /shared/tmp/geoip-data-v2-Org-2.0.0-20260504.838.0.i686.rpm

  7. Verify that the geolocation database loaded by using the geoip_lookup command to query the database. For example, the following command syntax queries one of the database files for a specific IP address:

    geoip_lookup -f <path/to/db/files> <IP address>

    For example:

    # geoip_lookup -f /shared/GeoIP/v2/F5GeoIPOrg.dat 104.219.104.154
    opening database in /shared/GeoIP/v2/F5GeoIPOrg.dat
    size of geoip database = 197233251, segments = 15753089, version = Copyright (c) F5 Networks Inc, All Rights Reserved GEOIP2 v1, 20260504
    geoip_seek = 00006894
    geoip record ip = 104.219.104.154
    name = f5 inc.
    Scope = 21

    Note: Omitting the -f option to specify a database file causes the geoip_lookup command to default to querying the /shared/GeoIP/v2/F5GeoIP.dat file.

    Note: In BIG-IP 12.1.0 and later, the GeoIP files are located in the /shared/GeoIP/v2/ folder. In BIG-IP 12.0.0 and earlier, the GeoIP files are located in the /shared/GeoIP/ folder. If you upgrade your BIG-IP system to BIG-IP 12.1.0 or later from a version prior to BIG-IP 12.1.0 and have not updated the GeoIP files, the GeoIP files continue to reside in the /shared/GeoIP/ directory. All subsequent updates to the GeoIP files on the upgraded BIG-IP system install the GeoIP files to the /shared/GeoIP/v2/ directory. 

    Note: The v1 GeoIP file format became officially unsupported when BIG-IP 12.0.0 went EoTS in December 2017. Refer to K5903: BIG-IP software support policy for more information. BIG-IP 12.1.0 and later use the v2 format.

  8. (Optional) If you need to reclaim disk space, you can remove the geolocation zip, MD5 and RPM files you downloaded and extracted by using the following syntax:

    rm -i </path/to/file>

    For example:

    rm -i /shared/tmp/ip-geolocation-v2-2.0.0-20260504.838.0.zip

Note: If your BIG-IP system is part of a high-availability (HA) configuration, you need to repeat this process on each system in your configuration.

Restoring the previously backed up geolocation database

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to bash.
  2. Delete the current database by entering the following command:

    rm -r /shared/GeoIP/*

    Enter y to confirm what rm is deleting, or, if you know you haven't made any typos with the command, enter n and enter the command again with the addition of the -f option to suppress the confirmations.

  3. Restore the previous database by entering the following command:

    cp -R /shared/GeoIP_backup/* /shared/GeoIP/

Note: If your BIG-IP system is part of a high-availability (HA) configuration, you need to repeat this process on each system in your configuration.
