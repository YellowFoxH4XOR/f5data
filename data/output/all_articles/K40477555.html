Issue

Old Behavior

In versions prior to BIG-IP AFM 12.1.0, the detection thresholds and limits configured in denial-of-service (DoS) Protection profiles are enforced for each Traffic Management Microkernel (TMM).

You can configure detection thresholds and limits for known attack types in DoS Protection profiles. You can then apply the DoS Protection profiles to virtual servers to provide protection against DoS attacks.

The following example shows the configured settings for the DNS A Query attack type in a DoS Protection profile:

  • Detection Threshold Packets Per Second: 250000
  • Detection Threshold Percent: 500
  • Rate Limit Packets Per Second: 2500000

In versions prior to BIG-IP AFM 12.1.0, the system reports an attack started when any of the TMMs on the device detect more than 250000 packets per second (PPS) matching the attack type. For BIG-IP AFM systems with multiple TMMs, the total PPS detected by the system globally across all TMMs can exceed the configured threshold before an attack is triggered. For example, a device with four TMMs could potentially receive as much as 1000000 PPS (250000 x 4) before an attack is detected if the packets are distributed evenly.

New Behavior

Beginning in BIG-IP AFM 12.1.0, the detection thresholds and limits configured in DoS Protection profiles are enforced globally for the device.

Instead of enforcing detection thresholds for each TMM on the device, the BIG-IP AFM system considers the total PPS across all TMMs on the device.

Using the example configuration from above, when the BIG-IP AFM system detects more than 250000 PPS matching this attack type globally across all TMMs on the device, the BIG-IP AFM reports that an attack started. For example, if the system has two TMMs, PPS for TMM0 could be 240000 but if PPS for TMM1 is only 9000, the BIG-IP AFM system does not detect an attack. However, if PPS for TMM1 suddenly increases by more than 1000 PPS and PPS for TMM0 does not decrease, the BIG-IP AFM system reports an attack started and and logs a message similar to the following example in the /var/log/ltm file:

err tmm[19917]: 01010252:3: A DNS <virtual_server_name> DOS attack start was detected for vector A query DOS, Attack ID 228892298.

When the number of globally detected PPS matching this attack falls below the configured threshold, the BIG-IP AFM system reports the attack has stopped and logs a message similar to the following in the /var/log/ltm file:

notice tmm[19917]: 01010253:5: A DNS <virtual_server_name> DOS attack has stopped for vector A query DOS, Attack ID 2976291543.

Note: DoS Device Protection (called Device Configuration in BIG-IP versions prior to 14.0.0) protects the system as a whole. DoS Device Protection vector thresholds for detection and mitigation are still interpreted per-TMM. The Single Endpoint Sweep and Single Endpoint Flood vectors are an exception; the threshold settings for these vectors are interpreted globally for Device Protection as well as DoS Protection profiles.

Impact

As a result of this change, consider the following:

  • When upgrading from previous BIG-IP AFM versions to BIG-IP 12.1.0, DoS Protection profile thresholds and limits are automatically increased in accordance with the new behavior. For example, if your BIG-IP AFM system has four TMMs and you configure the Detection Threshold for the DNS A Query attack type to be 250000, the Detection Threshold increases to 1000000 when upgrading to BIG-IP 12.1.0 or later.
  • You may see a message similar to the following when attempting to load the configuration following an upgrade to BIG-IP AFM 12.1.0 or later:

    Dos vector limit has been changed from per tmm thread to total tmm threads per box

  • Using detection threshold or limit settings from a version prior to BIG-IP APM 12.1.0 on a system running 12.1.0 or later with multiple TMMs results in attack detection occurring sooner because the setting is enforced globally rather than per-TMM. To convert the older settings, multiply the setting value by the number of TMMs on the system. You can determine the number of TMMs running on your system by typing the following command:

    tmsh show /sys tmm-info | grep "Sys::TMM"

Recommended Actions

When configuring DoS Protection profile detection thresholds and limits on BIG-IP AFM 12.1.0 and later, you should set the value based on the global PPS for the device.
