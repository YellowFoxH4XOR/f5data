K000163761: BGP crashed with all neighbors

2026-11-05

Source

Description

BIG-IP running BGP (ZebOS bgpd) restarted several times with a bgpd core file, dropping all BGP peerings.

Environment

- BIG-IP 17.5.1.9 (Point Release 9, build 0.0.12), F5-BIG-LTM-R5800 platform with AFM.

- eBGP peers. Route-flap dampening (bgp dampening 30) enabled.

Cause

Bug ID1126425

Answer/Recommended Actions

1. Disable dampening if it is not needed. Run:

imish -r 1

enable

configure terminal

router bgp <local AS>

no bgp dampening

end

write

Check with: zebos -a cmd show running-config that the bgp dampening line is gone. Without write, the change is lost on restart or upgrade.

2. If dampening must stay on, open a case with F5 Technical Support and request an EHF for ID1126425

Additional Information

At the moment of writing this article there is no planned BIG-IP version in which the issue is going to be fixed.
