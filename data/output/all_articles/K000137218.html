K000137218: Statistics records for Chrome and Edge browsers are counted together in AVR Analytics module.

Type
Support Solution
Published
2023-10-26
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP Analytics: 16.1.3
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000137218

Description

AVR analytics module doesn't distinguish Edge (chromium based) from Chrome browser in statistics records.
Requests sent by Chrome and Edge browsers are counted together as Chrome in name column in Analytics query results.

For example:
tmsh show analytics http report view-by browser

------------------------------------------
Analytics query result
-------------------------------------------
Time range: 12/31/1969:16:00 (PST)
-------------------------------------------
name            | transactions
-------------------------------------------
MSIE            | 62951026  <=== Internet Explorer
Chrome PC       | 10113763  <=== Chrome and Edge (Chromium engine)
Chrome Android  | 4317944
Safari iOS      | 1726275
Firefox PC      | 1514687
Android         | 746970
Edge            | 634990    <=== Edge prior to January 2020 (EdgeHTML engine)
Safari PC       | 351030
Opera           | 56186
Firefox Android | 16084
Opera Mobile    | 3022
UC Browser      | 3016
MSIE Mobile     | 2788
Opera Mini      | 740

Environment

  • BIG-IP AVR
  • Edge browser requests sent from versions past January 2020

Cause

Prior to January 2020, Edge browser was on EdgeHTML engine.
After January 2020 the Edge browser moved to the Chromium engine, and it is detected by the AVR analytics module as Chrome.

Recommended Actions

None

Additional Information

MS Internet Explorer browser requests are counted in AVR as MSIE.
