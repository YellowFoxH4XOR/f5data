Known Issue

This is the result of a known issue. When the BIG-IP LTM SSL profile is configured to require a client certificate, and the client presents a revoked SSL certificate, the BIG-IP system generates the following incorrect SSL alert:

bad_certificate(42)

BIG-IP LTM should generate the following SSL alert:

certificate_revoked(44)

F5 Product Development tracked this issue as CR62632 and it was fixed in BIG-IP LTM 9.1.3 and 9.3.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue still exists in the BIG-IP 9.4.x software branch.
