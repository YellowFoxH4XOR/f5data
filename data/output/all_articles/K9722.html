Known Issue

This is the result of a known issue. The VLAN failsafe listener may cause a memory leak if the VLAN is unresponsive.

This issue occurs when the BIG-IP system does not detect traffic on the VLAN, and triggers the VLAN failsafe feature. The failsafe feature sends two packets each second, one in IPv4 format and one in the IPv6 format. The memory leak occurs within the failsafe listener when the broadcast packets are sent.

For brief network interruptions, the BIG-IP is able to recover quickly; for longer interruptions you may see TMM experience memory exhaustion, during which time the memory sweeper will enter aggressive reaping mode to free memory.

F5 Product Development tracked this issue as CR115835 and it was fixed in versions 9.4.7 and 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.0-5514.0-HF2 issued for BIG-IP version 10.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
