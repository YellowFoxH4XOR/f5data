K000090861: You may receive RISK_COULD_NOT_BE_DETERMINED when configuring an NGINX WAF policy.

Type
Support Solution
Published
2021-11-10
Updated
2024-02-22
Source
https://my.f5.com/manage/s/article/K000090861

Description

When you configure a WAF policy within NGINX you may encounter RISK_COULD_NOT_BE_DETERMINED.

 Environment

  • NGINX WAF policy

 Cause

This is caused when the .conf is configured without a section in there that defines what violations and what to do with them. For example:


{

   "policy":

   {

       "name": "policy_name",

       "template":

       {

           "name": "POLICY_TEMPLATE_NGINX_BASE"

       },

       "applicationLanguage": "utf-8",

       "enforcementMode": "blocking",

       "urls":

       [

           {

               "isAllowed": false,

               "name": "/admin",

               "protocol": "http",

               "type": "explicit"

           },

           {

               "isAllowed": false,

               "name": "/admin",

               "protocol": "https",

               "type": "explicit"

           }

       ]

   }

}

 Recommended Actions

In the below example you will see where the blocking-settings have been set. When they are missing the error message RISK_COULD_NOT_BE_DETERMINED will be the likely result.

{

   "policy": {

       "name": "/Common/user_defined_URL",

       "template": {

           "name": "POLICY_TEMPLATE_NGINX_BASE"

       },

       "applicationLanguage": "utf-8",

       "enforcementMode": "blocking",

       "blocking-settings": {

           "violations": [

               {

                   "name": "VIOL_URL",

                   "alarm": true,

                   "block": true

               }

           ]

       },

       "urls": [

           {

               "method": "*",

               "name": "/test*",

               "protocol": "http",

               "type": "wildcard",

               "wildcardOrder": 1,

               "attackSignaturesCheck": true,

               "signatureOverrides": [

                   {

                       "enabled": true,

                       "signatureId": 200010008

                   },

                   {

                       "enabled": false,

                       "signatureId": 200010093

                   }         

               ]

           }

       ]

   }

}
