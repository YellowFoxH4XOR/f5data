Topic

The vconsole utility is a telnet-based console access utility for the Virtual Clustered Multiprocessing (vCMP) host to connect to its vCMP guest instance.

Description

A vCMP guest does not have a physical serial port from which to access its console. The vconsole utility is a telnet-based console access utility for the vCMP host to connect to its vCMP guest instance.

Recommendations

When you perform troubleshooting on a vCMP guest on the console access level, you can use the vconsole utility to connect to the target guest instance.

Connect to a vCMP guest

To connect to a vCMP guest using the vconsole utility, you must first log in to the vCMP host's TMOS Shell (tmsh) or BIG-IP command prompt to run the vconsole command.

The vconsole command syntax appears as follows:

vconsole <guest_name> <slot_number>

In this command syntax, note the following:

  • <guest_name> is the name of the vCMP guest instance for which you want to have console access.
  • <slot_number> is the chassis platform slot where the target vCMP guest is located; the slot number is not required when the vconsole utility is targeting a vCMP guest on an appliance platform.

Note: The -h flag of the vconsole command displays general command syntax accepted by the vconsole command.

Disconnect from a vCMP guest

To exit the vconsole utility, use the telnet escape sequence CTRL-].

To quit the telnet prompt, enter q.
