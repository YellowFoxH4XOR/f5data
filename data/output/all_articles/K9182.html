K9182: Ratio values for wide IP pool members are set to zero when the update button is pressed

Known Issue

This is the result of a known issue. After pressing the update button in the Configuration utility, any changes made to the ratio values for wide IP pool members are set to zero.

F5 Product Development tracked this issue as CR51871.

Workaround

You can work around this issue by manually editing the /config/3dns/etc/wideip.conf file and reloading the changes. To update the ratio values of wide IP pool members and prevent the ratio values being reset to zero, perform the following procedure:

  1. Log in to the 3-DNS command line.
  2. Change directories to the /config/3dns/etc directory by typing the following command:

    cd /config/3dns/etc
  3. Prior to making changes, create a backup of the wideip.conf file by typing the following command:

    cp wideip.conf wideip.conf.ORIGINAL
  4. Edit the wideip.conf file.
  5. Locate the pool members for which you want to change the ratio value.

    The following example displays pool members before changing their ratio values:

    /*** Wide IP Definitions (1) ***/

    wideip {
       address           215.23.145.247
       port              80 // http
       name              "www.askf5.com"
       ttl               30

       pool {
          name           "askf5_poola"
          ratio          6
          preferred      ratio
          alternate      null
          fallback       null

          address        172.24.73.65   ratio 0
          address        172.24.73.66   ratio 0
       }

       pool {
          name           "askf5_poolb"
          ratio          7
          preferred      ratio

          address        172.24.73.65   ratio 0     
          address        172.24.73.66   ratio 0
       }
    }

    The following example displays pool members after manually changing their ratio values:

    wideip {
       address           215.23.145.247
       port              80 // http
       name              "www.askf5.com"
       ttl               30

       pool {
          name           "askf5_poola"
          ratio          6
          preferred      ratio
          alternate      null
          fallback       null

          address        172.24.73.65   ratio 1
          address        172.24.73.66   ratio 2
       }

       pool {
          name           "askf5_poolb"
          ratio          7
          preferred      ratio

          address        172.24.73.65   ratio 3     
          address        172.24.73.66   ratio 4
       }
    }
  6. Close and save the changes made to the wideip.conf file
  7. Verify that the changes have been made correctly and no syntax errors exist by typing the following command:

    3dparse --picky

    Note: If any syntax errors are reported, re-open the configuration file and make the necessary changes.
  8. Load the changes by typing the following command:

    3dnc reload
