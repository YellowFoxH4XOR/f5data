K55636305: BIG-IQ statistics collection stopped working after BIG-IP upgrade

Description

BIG-IQ stopped collecting statistics after BIG-IP upgrade to v14.1.5. v15.1.5.1 or v16.1.3

Environment

  • BIG-IQ
  • Stats Collection Enabled
  • BIG-IP v14.1.5, v15.1.5.1 or v16.1.3

Cause

Bug ID 1112777

Recommended Actions

Apply the workaround to BIG-IP provided in Bug ID 1112777

Additional Information

A new db variable restjavad.disablerpmtasks was introduced in v14.1.5, v15.1.5.1 and v16.1.3 and is enabled by default.
