Topic

The Broadcom SSL accelerator is used in BIG-IP Server Appliances as a standalone card, and in the BIG-IP IP Application Switch series as an integrated chip. You can test both types of the Broadcom SSL accelerator with the bsdiag utility.

To run the bsdiag utility from the command line, type the following command:

bsdiag

Following are samples of output you will see after running the bsdiag utility.

Sample output from a BIG-IP 2000 with a single SSL accelerator chip integrated on the switch fabric

big-ip:~# bsdiag
Starting RSA test for bcm5820 crypto card...
total rsa_mod_exp_crt time = 6710550 us
ave. rsa_mod_exp_crt time = 1315.794118 us
rsa_mod_exp_crt = 759.997318 ops per sec

Sample output from a BIG-IP 540 Server Appliance with dual SSL accelerator cards

big-ip:~# bsdiag
Starting RSA test for bcm5820 crypto card...
total rsa_mod_exp_crt time = 3366709 us
ave. rsa_mod_exp_crt time = 660.139020 us
rsa_mod_exp_crt = 1514.832437 ops per sec

The following table explains the output shown in the preceding examples.

OutputDescription
total rsa_mod_exp_crt timeThe total elapsed time spent on the RSA modulus encryption test, in useconds.

ave. rsa_mod_exp_crt time
The average amount of time spent on a single RSA modulus encryption test, in useconds.

sa_mod_exp_crt
The number of RSA modulus calculations (SSL key transactions) completed in one second. This is usually the information that an administrator is interested in, since this is the main usage of the SSL Accelerator in a BIG-IP.
