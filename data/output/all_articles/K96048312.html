Known Issue

The monitor configuration may trigger a configuration load failure.

This issue occurs when all of the following conditions are met:

  • You create a monitor that inherits values from an existing transparent monitor.
  • The newly created monitor name phonetically precedes the inherited monitor name.

Impact

You are unable to load the configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to load the system configuration, the system displays an error messages similar to the following example:

    01070045:3: Monitor /<partition>/<monitor name> type cannot have transparent attribute.
    Unexpected Error: Loading configuration process failed.

Workaround

To work around this issue, you can manually delete the affected monitor and re-create the new monitor to phonetically follow the inherited monitor. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Using either the vi or pico text editor, edit the /config/?bigip.conf file.
  3. Locate the newly created monitor, and remove the monitor configuration starting with the type and name declaration, through the closing curly bracket (}).

    For example, you would locate and remove the following newly created monitor A_Monitor configuration stanza from the /config/bigip.conf file:

    ltm monitor http A_Monitor {
    adaptive disabled
    defaults-from B_Monitor
    destination 192.168.0.10:http
    interval 5
    ip-dscp 0
    send "GET /\r\n"
    time-until-up 0
    timeout 16
    transparent enabled
    }

    Important: Be sure to remove any monitor name references throughout the bigip.conf, such as pool monitors.

  4. Save the changes to the bigip.conf file, and exit the text editor.
  5. Load the configuration by typing the following command:

    tmsh load /sys config

  6. Using the Configuration utility or Traffic Management Shell (tmsh), re-create the deleted monitor with a name that phonetically follows the inherited monitor name.
