Known Issue

You cannot remove a CIFS attribute fileset using the ARX management GUI.

Impact

You cannot remove a CIFS attribute fileset using the ARX management GUI.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You cannot remove the CIFS attribute fileset.
  • An error appears on the ARX management GUI that appears similar to the following:

ERROR: The name 'cifs-Attr-fileset' is defined as a cifs attributes fileset

Workaround

To work around this issue, you can remove the fileset using the ARX CLI. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. Enter global mode by typing the following command:

    global

  4. Remove the fileset configuration by using the following command syntax:

    no policy-cifs-attributes-fileset [fileset name]

    For example:

    no policy-cifs-attributes-fileset cifs-Attr-fileset-test

  5. Exit the global edit mode by typing the following command:

    End
