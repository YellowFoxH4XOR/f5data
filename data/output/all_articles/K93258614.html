Description

RDP with client type ActiveX is not working after upgrading to 14.1.4.4, you might experience this:

The system displays the error message: This page can not be displayed.

Environment

  • BIG-IP APM 
  • Remote Desktop, ActiveX

Cause

This is the result of Bug ID 1056669. Unfortunately at this time there is no publicly available information on this bug.

Recommended Actions

  1. If you still want to use ActiveX in v14.1.4.4 you can use the following workaround, create the following article and attach it to the VIP:
    when CLIENT_ACCEPTED {
         ACCESS::restrict_irule_events disable  }
    when HTTP_REQUEST {
        if { [HTTP::uri] starts_with "/vdesk/resource_all_info.eui" && [HTTP::uri] contains "remote_desktop" } {
            #strip out %230 in URI
            HTTP::uri [string map {"%230" ""} [HTTP::uri]]
        }
    }
     
  2. We strongly recommend switching to native rdp per K24493695: Configuring native user defined Remote Desktop Resources. In newer versions ActiveX is not supported.
    Access ›› Connectivity / VPN : VDI / RDP : Remote Desktops >> Select the one that you want to modify
  3. Finally under Client Type change it to Native
