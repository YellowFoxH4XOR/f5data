Description

RESPONSE_MSECS logging parameter value is measured between HUDEVT_REQUEST_DONE and HUDEVT_RESPONSE_DONE events and is intended to measure time needed by server to provide response.
However when client sends request with "100 Continue" header, BIG-IP will not wait for the full request to be received, instead it will start to transfer it to the server while still receiving it from client.
This is causing request and response being transferred at the same time which is causing RESPONSE_MSECS value to be calculated inaccurately.

Environment

  • HTTP profile
  • Logging profile with response logging enabled
  • HTTP request with "100 Continue" header
Cause

This works as designed 

Recommended Actions

None

None
