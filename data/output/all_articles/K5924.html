Topic

This article applies to BIG-IP version 11.x. For information about other versions, refer to the following article:

  • K13285: Support for WebDAV in a BIG-IP LTM HTTP profile (11.x)

The BIG-IP HTTP profile supports HTTP and HTTP-like protocols. Web-based Distributed Authoring and Version (WebDAV) is a set of extensions to the HTTP/1.1 protocol specification that allows users to collaboratively edit and manage files on remote web servers. Since it coincides with the HTTP/1.1 standard defined in RFC2616, WebDAV functionality is supported using a virtual server with an HTTP profile applied. However, the BIG-IP HTTP profile does not recognize request methods that are not defined in RFC2616, such as those added in the WebDAV HTTP Extensions specification (RFC2518): 

  • PROPFIND
  • PROPPATCH
  • MKCOL
  • DELETE
  • COPY
  • MOVE
  • LOCK
  • UNLOCK

For the BIG-IP system to successfully forward requests using these unrecognized methods, you may need to disable further HTTP processing for the request by applying an iRule to the virtual server. The DevCentral iRules codeshare contains an example iRule, which disables HTTP processing for the current request if it uses specific request methods:
