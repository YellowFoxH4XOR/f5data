What Happened?

  • You identified that the client traffic was being blocked due to the configured behavior on the HTTP load balancer.

  • You would like to understand why Threat Mesh blocks specific IP addresses.

Environment

  • F5 Distributed Cloud HTTP Load Balancer 
  • F5 Threat Mesh

Resolution/Answer

For visibility, additional Threat Mesh details are available in the JSON view of the relevant security event within Security Analytics. 

To view additional details for a security event, select the >` icon to the left of the event entry. This expands the Information tab and displays the event details in a fully expanded view.

Select the JSON tab to view the same information in JSON format. The Information tab indicates whether the request was blocked due to a Threat Mesh violation. A Threat Mesh violation means the source IP address has recently been blocked for malicious activity targeting this application or another application across the F5 XC platform.

For deeper insight into the associated behavior or attack patterns, open the JSON tab and expand the threat_mesh_detail object. This section provides additional context and specifics that explain why the IP address was classified as malicious and subsequently blocked.

  1. Go to Home -> Web App & API Protection -> namespace -> Overview -> Security
  2. Security Analytics tab , Events 
  3. Choose JSON and scroll down to threat_mesh_details: 

Cause

If an IP address generates multiple security violations across different customers, it may be classified as malicious and added to Threat Mesh. Once classified, traffic from that IP address can be blocked for additional tenants.

Additional Information

Threat Mesh blocking decisions are not based on customer specific configuration or specific security traffic patterns. Instead, they rely on global threat intelligence derived from malicious behavior observed across the entire F5 Distributed Cloud platform.
