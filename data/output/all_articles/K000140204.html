K000140204: APM did not set the Samesite parameter on the cookie MRHSHint when enable Samesite

Type
Support Solution
Published
2024-07-01
Updated
2024-07-01
Applies to

  • BIG-IP APM: 16.0.0, 16.0.X, 16.0.1, 16.X.X, 17.X.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source

Description

When using the security scan tool to scan the virtual server with APM access policy, it may report the vulnerability that Samesite parameter is missing.

Even enable Samesite setting, but the security tool still report the issue.

After enable Samesite setting, the HTTP data may similar with:

GET / HTTP/1.1
Accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/avif,image/webp,image/apng,*/*;q=0.8,application/signed-exchange;v=b3;q=0.7
Accept-Encoding: gzip, deflate, br, zstd
Accept-Language: zh-CN,zh;q=0.9
Cache-Control: max-age=0
Connection: keep-alive
Host: vpn.example.com
Sec-Fetch-Dest: document
Sec-Fetch-Mode: navigate
Sec-Fetch-Site: none
Sec-Fetch-User: ?1
Upgrade-Insecure-Requests: 1
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/125.0.0.0 Safari/537.36
sec-ch-ua: "Google Chrome";v="125", "Chromium";v="125", "Not.A/Brand";v="24"

HTTP/1.0 302 Found
Server: BigIP
Location: /my.policy
Set-Cookie: LastMRH_Session=18a68661;path=/;secure;samesite=strict
Set-Cookie: MRHSession=99bb8cbe5ab2dbff666187d418a68661;path=/;secure;samesite=strict
Set-Cookie: MRHSHint=deleted; expires=Thu, 01-Jan-1970 00:00:01 GMT; path=/;secure     <<<<< missing samesite parameter
Connection: close
Content-Length: 0

Environment

  • BIG-IP APM
  • Access profile

Cause

It is false positive.

Recommended Actions

In the HTTP response, set the cookie MRHSHint, the value is ”deleted", the original value was override.

The cookie was expired too, so in the follow HTTP request, this cookie will not be attached.

So this issue is false positive, if the scan tool evaluate the value and expire time, it should not report the vulnerability.

Additional Information

In K15387: Overview of BIG-IP APM session cookies, the purpose of the cookie MRHSHint:

Cookie is used for Microsoft SharePoint or for IBM Lotus Domino iNotes.  MRHSHint cookie is used to carry information for SharePoint ActiveX controls.
