K65232525: Pool and Pool members statistics from BIG-IP device are not collected using BIG-IQ

Type
Support Solution
Published
2021-08-29
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K65232525

Description

BIG-IP device without Application Visibility and Reporting (AVR) module is managed by BIG-IQ Centralized Management.
Pool and Pool members statistics from BIG-IP device are not collected but virtual server statistics are collected.

Environment

  • BIG-IP device is managed by using BIG-IQ Centralized Management
  • BIG-IP device is provisioned without AVR module
  • Statistics collection using BIG-IQ Centralized Management
  • Statistics collection is enabled in BIG-IQ Centralized Management for managed device

Cause

Pool and Pool members statistics will not be collected without AVR module provisioned in BIG-IP. But BIG-IQ Centralized Management will collect the following basic statistics from the BIG-IP device when provisioned without AVR module. It is by design and this is expected behavior.

  1. Device Health (CPU Usage, Memory, Disk statistics, Interface health )
  2. Device Traffic (New connection, Concurrent connection, Interface traffic)
  3. Virtual Server statistics( New connection, Concurrent connection, Throughput )

Recommended Actions

Provision Application Visibility and Reporting (AVR) module in the BIG-IP device to get Pool and Pool members statistics from BIG-IP device
Follow the article K12111: Provision licensed BIG-IP modules to provision Application Visibility and Reporting (AVR) module
