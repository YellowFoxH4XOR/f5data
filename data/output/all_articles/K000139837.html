Description

Your IT Security department may use the Tenable Nessus product to create a security scan report, which states that your BIG-IP is running an operating system that is no longer supported. The report states that:

The operating system running on the remote host is no longer supported

Environment

  • BIG-IP
  • 3rd-Party Security Scan

Cause

The Nessus tool has detected that the BIG-IP runs a version of Unix (Centos) that it thinks is no longer supported or receiving security updates.

Recommended Actions

None, F5 provides support for the OS via upgrades.

None
