K000139284: UCS restore on F5OS tenant or vCMP guest fails with error: 01070712:3: Cannot set MTU for <vlan> to <vlan mtu> in <route domain> - ioctl failed: No such device

Description

BIG-IP configuration restore from a UCS may fail with the following error message:

load_config_files[<pid>]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- 01070712:3: Cannot set MTU for <vlan> to <vlan mtu> in <route domain> - ioctl failed: No such device
Unexpected Error: Loading configuration process failed.

The same issue may also happen when associating a VLAN to a route domain and modifying MTU for the VLAN in a single transaction.

Environment

  • F5OS tenant
  • vCMP guest
  • Restoring BIG-IP configurations from UCS
  • The configuration in the UCS has a VLAN in a non-default route domain and a non-default MTU

Cause

ID 1575269

Recommended Actions

  • When restoring the configuration with a UCS, the configuration data is installed on the system even if the configuration load fails so rebooting the guest or tenant may clear the condition and allow the configuration to load properly.
  • Change MTU of the VLAN or associate the VLAN to a route domain before restoring UCS.
  • Change MTU of the VLAN and associate the VLAN to a route domain in two separate transactions.
