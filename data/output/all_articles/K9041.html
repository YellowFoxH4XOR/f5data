Known Issue

This is the result of a known issue. The bigpipe packet filter help page specifies that an action of none can be used as an argument for modifying a packet filter rule.

This option is not available in the Configuration utility, and cannot be used from the command line. If you use the bigpipe packet filter <filter_name> action command, the following error message will display on the console:

BIGpipe packet filter operation error:
01070087:3: Packet filter rule '<filter_name>': must specify an action”

F5 Product Development tracked this issue as CR103443 and it was fixed in BIG-IP LTM 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.
