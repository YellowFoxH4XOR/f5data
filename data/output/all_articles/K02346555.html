Description

An HTTP / HTTPS virtual server configured with a pool on which the load balancing method is set to Ratio (session) is balancing traffic only to a specific pool member.

Environment

  • HTTP / HTTPS virtual server
  • Pool with load balancing method set to Ratio (session)

Cause

The Ratio (session) load balancing method in order to blalance traffic properly requires a layer 7 ( HTTP profile ) assigned on the respective virtual server.

Recommended Actions

Assign an HTTP profile on the respective virtual server.

None
