Description

NTPv3 NTP server is cofigured in BIG-IP / BIG-IQ, but failing to sync.

Environment

  • BIG-IP
  • NTPv3 servers
Cause
  • There are NTPv3 servers out there which have problems with NTPv4 packets.  
    NOTE: By default, the BIG-IP uses NTPv4, which is designed to be backwards compatible with NTPv3.
Recommended Actions

K98582354: Force BIG-IP to use NTPv3 (NTP version 3) only


Additional Information
  • K22595813: Does BIG-IP support NTP version 3, 2 or 1 (NTPv3, NTPv2 or NTPv1)?
