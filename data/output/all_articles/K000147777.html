K000147777: Access to "login" path is not working and I get stuck

Description

This article addresses an issue where users are unable to access the "login" path of their web application through an F5 Distributed Cloud (XC) HTTP Load Balancer and get stuck, often experiencing a redirect loop or failure to reach the login page.

  • The user is attempting to connect to their WebApp's login page using an HTTP Load Balancer.
  • The Origin Pool is configured with a Public DNS.

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Cause

The issue occurs because the HTTP Load Balancer is not configured with a Simple Route and Host Rewrite option, which is required for proper routing to the login page when using a Public DNS origin.

Answer/Recommended Actions

To resolve the issue and avoid getting stuck in a loop:

  1. Configure a Simple Route in your HTTP Load Balancer.
  2. Add the Host Rewrite option, specifying the host you are trying to access.
  3. This ensures that requests to the login path are routed correctly to the origin server.

For detailed steps, refer to:

  • How to setup path-based routing or application load-balancing
