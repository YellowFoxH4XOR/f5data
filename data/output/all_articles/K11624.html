K11624: The default BIG-IP SSL profiles no longer include DES-CBC-SHA and ciphers containing the MD5 hash

Issue

In BIG-IP versions prior to 10.2.0, the default BIG-IP SSL profiles included DES-CBC-SHA and ciphers containing the MD5 hash.

Starting in BIG-IP 10.2.0, the DES-CBC-SHA cipher and ciphers using the MD5 message-digest algorithm are removed from the default SSL profile cipher lists. The DES-CBC-SHA cipher is a low-strength cipher and the MD5 algorithm has known weaknesses that may allow for collisions in output.

There may be occasions when you want to enable one or more low-strength SSL ciphers, such as DES-CBC-SHA, and/or ciphers using the MD5 message-digest algorithm for a particular virtual server. Starting in BIG-IP 10.2.0, you can use the clientssl-insecure-compatible and serverssl-insecure-compatible profile types to allow low-strength ciphers for a Client SSL or Server SSL virtual server. The cipher lists for the clientssl-insecure-compatible and serverssl-insecure-compatible profiles include deprecated ciphers, such as DES-CBC-SHA and all MD5 cipher suites.

Note: For more information about ciphers included in the clientssl-insecure-compatible and serverssl-insecure-compatible profiles, refer to K11631: SSL ciphers used in the clientssl-insecure-compatible and serverssl-insecure-compatible SSL profiles.

To configure a clientssl-insecure-compatible or serverssl-insecure-compatible profile, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles.
  3. Choose Client (or Server) from the SSL menu.
  4. Click Create.
  5. Type a name for the SSL profile.
  6. Choose clientssl-insecure-compatible, or if you are creating a server-side SSL profile, serverssl-insecure-compatible, from the Parent Profile menu.
  7. Choose appropriate Certificate & Key from the Configuration menu.
  8. Click Finished.
  9. Associate the newly-created SSL profile with the appropriate virtual server.

The virtual server will now allow connections from clients requesting low-strength ciphers.

Note: For more information about configuring the cipher strength for SSL profiles, refer to K7815: Configuring the cipher strength for SSL profiles.
