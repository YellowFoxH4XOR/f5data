Issue

Error Message

notice mcpd[<PID>]: 01070639:5: Pool /<partition>/<name> member /<partition>/<name>:<port> session status <status>

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <partition> is the partition where the pool or pool member resides
  • <name> is the name of the pool or pool member
  • <port> is the port number for the pool member
  • <status> is the session status for the pool member: enabled, disabled, node disabled, forced disabled.

For example:

notice mcpd[6401]: 01070639:5: Pool /Common/vs_example member /Common/pool_example:80 session status enabled

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You configure a pool with pool members and associate it with a virtual server
  • The session status for one of the pool members changes

For example, this message is generated when an administrator disables a pool member using the Configuration utility or the Traffic Management Shell (tmsh).

Impact

This message is informational. If the status reflects a disabled state, the pool member is no longer available to accept connections.

Recommended Actions

If the disabled session state was not intentional, verify connectivity to the affected node or pool member. To change the pool member session status to enabled, refer to K13310: Disabling nodes or pool members for maintenance (11.x - 13.x).
