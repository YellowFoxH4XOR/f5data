Known Issue

BIG-IP iRules may produce a truncated response when you use ASN1 (Abstract Syntax Notation).

This issue occurs when all of the following conditions are met:

  • You are using the ASN1::encode command within a BIG-IP iRule to encode one or more values.
  • The encoding of any of these values results in a representation containing a NUL '\x0' byte.

Impact

Applications that rely on valid ASN1-encoded output may fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Encoded values are truncated at the first NUL byte.

To work around this issue, if possible, you can use a different encoding scheme.

Impact of workaround: The impact and feasibility of using a different encoding scheme depends on your particular application.
