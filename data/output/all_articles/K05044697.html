Description

  • Unable to deploy ASM policy from BIG-IQ to managed ASM devices
  • Auto-Deploy of ASM security policies fails with GUI error KeyNotFoundException
  • Error messages similar to the following can be seen on /var/log/restjavad.0.log

    [ERROR][01 Jan 2020 01:01:01 GMT][ConfigException] ERROR: Object /Common/comments (3) does not exist, URI http://localhost:8100/shared/storage?key=cm/asm/current-config/signatures/719d9e5e-1270-39f8-ada0-5b18b21ea1e4; reason com.f5.rest.workers.storage.KeyNotFoundException: cm/asm/current-config/signatures/719d9e5e-1270-39f8-ada0-5b18b21ea1e4 [ERROR][25 Mar 2020 09:55:43 GMT][ConfigException] ERROR: Object /Common/automated client access "libwww" does not exist, URI http://localhost:8100/shared/storage?key=cm/asm/current-config/signatures/f1da72b2-ab65-3be2-a39c-96822f0883fe; reason com.f5.rest.workers.storage.KeyNotFoundException: cm/asm/current-config/signatures/f1da72b2-ab65-3be2-a39c-96822f0883fe

Environment

  • BIG-IQ CM
  • ASM security policy

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 826633

Recommended Actions

Upgrade to software version 7.1.0 where ID 826633 is fixed

-- OR --

apply the following workaround

  1. Connect to BIG-CM CLI
  2. Clear ASM optimization data

    restcurl -X DELETE /cm/asm/current-config/change-status > /dev/null

Additional Information

None.
