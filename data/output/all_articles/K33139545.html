Description

After upgrading the BIG-IP to version 14.1.0.2 and later, remote users without advance shell permissions cannot SFTP to the management interface.


Environment

  • Upgrade to BIG-IP 14.1.0.2 and later
  • Remote Authentication is used for the account.


Cause

This change in behavior to mitigate K38941195: BIG-IP Resource Administrator vulnerability CVE-2019-6617, and implement fix for Bug ID 745165: Users without Advanced Shell Access are not allowed SFTP access.
 

Recommended Actions

Option 1: 
Use an account with Advance Shell assigned permissions.

Option 2:
use SCP instead of SFTP.
- In WinSCP, you can change the protocol to SCP and the shell to 'bash' and still use WinSCP GUI to get the SFTP like behavior:

  1. In WinSCP, either hit New Site to create a new site, or click your existing site (to your BIG-IP) then hit Edit
  2. Under File protocol section, change it to "SCP"
  3. Click  Advanced box
  4. In the Advanced Site Settings and under Environment tree, click SCP/Shell
  5. For Shell, type in: bash
         Note:  WinSCP provides the following options in the drop down for Shell
                      - Default
                      - /bin/bash
                      - /bin/ksh
                      - sudo su -
                   But do NOT select any of them even /bin/bash.  This /bin/bash does NOT work.  Instead, simply type in the word bash.
  6. Save this configuration or just click Login to connect to the BIG-IP.

You should be able to login to the BIG-IP with a remote user via scp protocol using WinSCP GUI.
