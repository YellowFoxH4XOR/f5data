Description

This article goes over what the /config/.diffVersions directory is on the BIG-IP filesystem

Environment

  • Any BIG-IP platform on versions 13.x or above

Cause

Files in the /config/.diffVersions directory take up space on the filesystem and it may be desired to remove the contents to free drive space or reduce the size of UCS backup files

Recommended Actions

It is safe to remove the .patch files found inside this directory. These files contain the differences found in various configuration files when the configuration is saved. They are only used to patch the configuration while the configuration is being saved, and are not used again afterward. It is worth noting that these files can act as a sort of configuration history, but only go back over the previous 250 configuration saves.

Additional Information

Each time the configuration is saved, the system runs the generate_config_diffs.sh shell script. The generate_config_diffs.sh script uses the cmp utility to perform a byte-by-byte comparison of the following configuration files, and their last-saved versions:

  • bigip.conf
  • bigip_base.conf
  • bigip_gtm.conf
  • bigip_script.conf
  • bigip_user.conf
  • BigDB.dat

If the system detects any changes between the current configuration file and the last saved file, the system uses the diff utility to generate a patch file, which contains the differences. Patch files are stored in the /config/.diffVersions directory. The patch file contains the sections of the configuration that have changed, as well as three lines of unchanged content.

The generate_config_diffs.sh script is configured to keep only the most recent 250 patch files; it then begins to age out the oldest versions.


e.g
/config/.diffVersions/config/bigip.conf

--- /config/bigip.conf  2022-06-24 02:13:41.093074743 -0700  <<<--- Date and time of this config change.
+++ /config/.diffVersions//config/bigip.conf/bigip.conf 2022-06-24 00:28:01.242694647 -0700  <<<---- Date and time of the previous bigip.conf config change.
@@ -404,13 +404,6 @@ ltm classification auto-update settings

     enabled no
 }
