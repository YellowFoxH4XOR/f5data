Issue

When a virtual server using the diameter profile sends a Capabilities-Exchange-Request (CER) to a Diameter server, and the CER/CEA handshake fails, the BIG-IP system logs an error message that appears similar to the following example to the /var/log/ltm file:

tmm[7097]: 014c0001:3: diameter hud_dime_handle error Prerequisite operation not in progress

Note: The virtual server sends the CER after establishing a TCP connection with the Diameter server. If the virtual server cannot establish the TCP connection, the system does not log the previously-listed error message.

The log message does not indicate an issue with the BIG-IP system. The typical reasons that a CER/CEA handshake fails are as follows:

  • The Diameter server does not respond to the CER with a Capabilities-Exchange-Answer (CEA).
    For example, the Diameter server closes the TCP connection instead of sending a CEA, because a server-side connection limit has been reached.
  • The CEA returned by the Diameter server contains a result code in the 5,000 range (5xxx), which indicates a permanent failure.
    For example, the result code contained in the CEA is 5010, indicating that there are no common applications supported between the peers.
