Description

When you attempt to log into the GUI, the page fails to load and your browser gets a 504 error:  The page isn't working right now.  <ip> took too long to respond.  HTTP ERROR 504
  • You are able to log into the console and run commands
  • The 'kubectl get deploy' command output indicates that not all pods are running.  mbiq-ado-query-feature is not running.

Environment

  • BIG-IP Next Central Manager
  • Central Manager was recently installed
  • Other environmental conditions that trigger this are unknown

Cause

Something unknown caused some of the system components to fail to start up fully. 

Recommended Actions

Reboot Central Manager

Additional Information

None
