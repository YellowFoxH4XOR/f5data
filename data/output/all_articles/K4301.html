Known Issue

This is the result of a known issue. BIG-IP will not display the certificate Issuer and Subject information correctly if the certificate is created using ASN1 BMPSTRING or UTF8STRING encoding.

F5 Networks Product Development tracked this issue as CR27049 and CR41936 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the 4.6 software branch.
