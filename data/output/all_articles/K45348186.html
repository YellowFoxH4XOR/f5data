Description
This is a non F5 issue caused by a recent Microsoft update.

  • known issue that might cause authentication failures related to Kerberos tickets you acquired from Service for User to Self (S4U2self). This issue occurs after you install the November 9, 2021 security updates on domain controllers (DC) that are running Windows Server. (KB5008602)
  • Your F5 APM logs may indicate errors such as:
    • Failed to get ticket for User
    • can't get S4U2Proxy ticket for server

Environment

  • BIG-IP
  • APM
  • Windows Server Domain Controllers using Kerberos

Cause
Issue is caused by a Microsoft security update that was dispatched November 9th 2021.  Authentication might fail on DCs with certain Kerberos delegation scenarios

 

Recommended Actions
Microsoft released an update that resolves the issue created by the November 9th update. November 14, 2021—KB5008602(OS Build 17763.2305) Out-of-band
 

  • Some environments may require the websso service to be restarted on the BIG-IP after applying the recommended update from Microsoft.
    • bigstart restart websso
      • Restarting the websso service will cause SSO to temporarily not function while the service is restarting. K17346: BIG-IP APM daemons (12.x - 13.x)
 

Additional Information

  • For more information related to service and daemons and how to restart them please see: K48615077: BIG-IP daemons (15.x - 16.x)
