Topic

You should consider using this procedure under the following conditions:

  • The BIG-IP APM, BIG-IP Edge Client for Windows download package is configured with the Allow Password Caching option.
  • Users establish access sessions with the BIG-IP Edge Client software selecting the Save Password option.
  • Users automatically log on to an access session with the BIG-IP Edge Client Save Password option.
  • Users want to manually clear a cached password.

Description

You can configure the BIG-IP APM customizable BIG-IP Edge Client package to allow users to cache their access session authentication credentials to their Windows device.

Caching the authentication credentials allows the user a facilitated access to establish an access session when starting the BIG-IP Edge Client application. For various reasons, a user may want to remove their cached credentials. When you select the Save Password option, the password is saved in the client.f5c BIG-IP Edge Client profile file and encrypted by a dynamic key:

C:\Users\<username>\AppData\Roaming\F5 Networks\VPN\client.f5c

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have read and write access to the BIG-IP Edge Client profile file.

Procedures

To clear the cached credentials, perform one of the following procedures:

  • Deselect the Save Password option when logging in
  • Delete the BIG-IP Edge Client profile file

Deselect the Save Password option when logging in

Closing and reopening BIG-IP Edge Client takes you to the logon page the next time you connect. From the logon page you can clear the cached password. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on the system.
  1. Log in to the Windows device.
  2. Exit and close the BIG-IP Edge Client.

    Note: Ensure that the program is not minimized to the system tray. You must exit and close the program.

  3. Open BIG-IP Edge Client.
  4. Select Connect. 
  5. On the Logon page, deselect the Save Password option.
  6. Select Logon.

The next time you disconnect and reconnect, the password is not presented.

Delete the BIG-IP Edge Client profile file

Deleting the BIG-IP Edge Client profile file clears the BIG-IP Edge Client cached password on the same device. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on the system.

  1. Log in to the Windows device.
  2. Exit and close the BIG-IP Edge Client.

    Note: Ensure that the program is not minimized to the system tray. You need to exit and close the program.

  3. Open Windows Explorer.
  4. Go to the following directory:

    C:\Users\<username>\AppData\Roaming\F5 Networks\VPN\

  5. Delete client.f5c.

    Note: This removes the BIG-IP APM server information in the profile as well as the the credentials.

  6. Open BIG-IP Edge Client.
