Issue

The BIG-IP bigd process logs the following error message to the /var/log/ltm file when health monitors are configured for pool members or nodes whose IP address reside on, or would be routed by way, of the management network:

Health check would route via mgmt port, node <ip_address>. Check routing table.

In some versions, the bigd process sends monitor traffic to the affected nodes or pool members by way of the management port, and the error message may refer to an IP address other than that of the affected member.

Note: For more information, refer to K7106: The bigd daemon erroneously routes health monitors out the management port and reports the wrong IP address.

In other versions, the address of the affected node or pool member is correctly logged, and no monitor traffic is sent to the affected nodes or pool members.

The management network was never intended to host any part of the load balancing configuration, such as virtual servers and pool members. To resolve this issue, F5 strongly recommends that you move the nodes or pool members so they reside on a VLAN defined in the BIG-IP load balancing configuration.
