K000133499: CPU plane in WebGUI is missing in r2600 BIG-IP tenant

Type
Support Solution
Published
2024-02-09
Updated
2024-02-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000133499

Description

Plane CPU graph is missing in the System Performance statistics from the BIGIP Tenant of rSeries 2600.

 

Environment

  • LTM Hyperthreading
  • BIGIP Tenant
  • rSeries 2600

 

Cause

Data and control plane graph are displayed for BIG-IP system with CPU using Intel Hyper-Threading Technology. 
There is no Hyperthreading on rSeries 2600.

 

Recommended Actions

There are no required actions.  This is an expected behavior.

 

Additional Information

None
