K12118: The BIG-IP ASM Charts feature will graph only the most recent 100,000 events

Topic

In BIG-IP ASM 10.1.0, F5 added the Charts feature to the BIG-IP ASM reporting tools. The data set that the BIG-IP ASM reporting system uses to generate charts is limited to the most recent 100,000 entries. This behavior may lead to misleading results when you select a custom filter to generate a chart.

For example, if you set the value for Time Period in the chart filter to Last Week, but the BIG-IP ASM system has received 100,000 violations in one day, the feature does not graph any violations on columns for the previous days of the week; all 100,000 entries are consumed and graphed for the current day.

Additionally, the 100,000 requests that the charts feature are a smaller value than the value on the table that the Reporting feature uses to report requests. This situation may result in a discrepancy between the two features, with the system reporting requests in the Reporting feature that are not reported in the Charts feature, because the requests exceeded the table limit.

The actual number of requests may vary depending on how frequently the BIG-IP ASM system processes requests. The BIG-IP ASM charts can log several thousand additional events between the time the limit is reached and the time the system clears the relevant table in the database. For example, under constant load, the various events logged in the BIG-IP ASM charts may total up to 110,000.

This Charts feature limitation has been re-architected and moved to BIG-IP Analytics (AVR) starting in BIG-IP 11.5.0. Since BIG-IP ASM leverages BIG-IP Analytics for its charts automatically, you do not need to specifically provision BIG-IP Analytics for this feature.
