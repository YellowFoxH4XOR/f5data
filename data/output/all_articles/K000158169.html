Description

You want to use the Microsoft's Entra ID RBAC roles as an authorization policy enforcement point and want to know if this is supported by F5 XC.

Environment

  • SSO

Answer

  • Q. Do you want to stop the authentication if the authenticated user does not have specific RBAC role? 
    A. If yes, you may able to enforce this during Entra ID authentication itself. XC authentication system currently does not support it as we have to do the poc before officially supporting it.
  • Q. Do you want to map the Entra ID role to XC Role, so the tenant owner does not have to assign XC roles to the users? 
    A. XC does not support it.
