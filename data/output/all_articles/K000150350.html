K000150350: Unable to load application. Error getting is clustered.environment status; Unable to connect to BIG-IP

Type
Support Solution
Published
2025-03-14
Updated
2025-03-14
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150350

Description

On the BIG-IP system, when you navigate to Statistics > Analytics and then select any category, such as HTTP, the page displays No data and following error message is seen on the Configuration Utility:

"Unable to load application. Error getting is clustered.environment status; Unable to connect to BIG-IP"

Environment

  • BIG-IP LTM
  • BIG-IP Analytics
  • HTTP Analytics

Cause

The issue is still unknown and being investigated.

Recommended Actions

To recover from this anomaly, the following workaround has been provided.

  1. Log in to the CLI
  2. Run the following commands:
  3. bigstart restart restjavad
  4. bigstart restart restnoded
