K70264409: BIG-IP platforms that contain HSB chips

Type
Support Solution
Published
2022-06-08
Updated
2024-08-17
Applies to

  • BIG-IP Platforms
  • BIG-IP LTM: 15.1.0, 15.1.2, 15.1.1, 17.1.X, 16.1.X, 15.1.X, 17.1.1, 17.1.0, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 15.1.10, 15.1.9, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3
Source

Description

The High-Speed Bridge (HSB) is the interface used on certain BIG-IP platforms to connect the switch fabric to the host subsystem. On those platforms that employ this technology, one or more HSBs may be present. Below lists the BIG-IP platforms utilizing the HSB chips:

Note: BIG-IP platforms that have reached End of Life (EOL) may not be included in this list.

  • BIG-IP 5000 (C109)
  • BIG-IP 7000 (D110)
  • BIG-IP 12250 (D111)
  • BIG-IP 10000 (D113)
  • BIG-IP 10350 (D112)
  • BIG-IP 11000 (E101)
  • BIG-IP 11050 (E102)
  • VIPRION B4300 Blade (A108)
  • VIPRION B4340N Blade (A110)
  • VIPRION B4450N Blade (A114)
  • BIG-IP iSeries i4x00 (C115)
  • BIG-IP iSeries i10000(C116)
  • BIG-IP iSeries i2x00 (C117)
  • BIG-IP iSeries i7000 (C118)
  • BIG-IP iSeries i7820-DF (C126)
  • BIG-IP iSeries i5000 (C119)
  • BIG-IP iSeries i5820-DF (C125)
  • BIG-IP iSeries i11000 (C123)
  • BIG-IP iSeries i11x00-DS (C124)
  • BIG-IP iSeries i15000 (D116)
  • BIG-IP iSeries i15820-DF (D120)
  • VIPRION B2100 Blade (A109)
  • VIPRION B2150 Blade (A113)
  • VIPRION B2250 Blade (A112)

Environment

  • HSB equipped BIG-IP platforms

Cause

Confirmation needed for BIG-IP platform specifications regarding HSB availability and troubleshooting.

Recommended Actions

You can also use the following methods to find out if your BIG-IP system has HSB or display HSB information:

  1. Command line options. Enter the following commands on the command line:
    • tmsh show sys hardware | grep -i hsb
    • hsb_tool info
    • hsb_tool -m edag

               Note: If the system does not have HSB, you may observe an output similar to the following: hsb_tool: command not found

  2. ihealth option:
    1. Go to iHealth.f5.com.
    2. Select Hardware on the left panel
    3. Select Specs
