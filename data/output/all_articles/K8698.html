Known Issue

This is the result of a known issue. The FirePass controller provides an Attack Notification and Prevention feature, which allows the administrator to configure the number of failed logon attempts and a time window before deactivating the user account. Additionally, email notification is sent to the email address configured for administrative emails.

Note: The Attack Notification and Prevention settings are configured on the Device Management: Security: User Access Security page. The address to which administrative messages are sent is configured on the Device Management: Configuration: Admin E-Mail page.

Normally, the FirePass controller sends no more than one email per 30 minutes as a result of failed logins, in order to minimize email volume in the event of an automated attack that generates large numbers of logins per unit of time. The online help states the following:

The email is generated no more than once every half hour for any account to prevent a flood of emails in case of repeated, automated hacking attacks.

However, the FirePass controller may send more than one email per 30 minutes when multiple logon failures occur.

F5 Product Development tracked this issue as ID 269295 (formerly CR90222) and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Note: For more information about upgrading, refer to K8444: The FirePass pre-upgrade checklist.
