Description

Apple Mac OS X connections fail with Native Remote Desktop Configurations.

  • You observe the following error message in .var/log/apm:

    <big-ip_hostname> err vdi[PID]: 019cffff:3: /Common/<access_policy_name>: {5221.C} An exception is thrown: Expression(static_cast<bool>(IsEndOfStream(rb)) == true) failed [0 != 1] at handlers/msrdp/rdp/Nego.hpp:136

Environment

  • Big-IP Access Policy Manager (APM)
  • Apple Mac OS X
  • Microsoft Remote Desktop Client for Mac OS version 8.x
  • APM Native RDP configuration.

Cause

The client sends "Client X.224 Connection Request PDU" in a packet that is malformed. There are two additional bytes at the end of the packet which does not conform to Microsoft RDP specifications. For information refer to Microsoft article 2.2.1.1 Client X.224 Connection Request PDU.

Recommended Actions

The MS RDP 8.x client is deprecated so we recommend upgrading to version 10.x.
