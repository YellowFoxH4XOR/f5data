Topic

You should consider using these procedures under the following conditions:

  • You are using the F5 Application Connector.
  • You want to enable cookie persistence on the virtual server for the application service.

Description

Application Connector allows you to securely connect your on-premises or co-located BIG-IP system to private nodes contained in a cloud provider so that system treats the cloud nodes as local nodes. The system does this using a secure WebSocket tunnel that one or more Application Connector proxies residing in the private cloud network establish. To configure cookie persistence for virtual servers that use Application Connector, you must assign a special iRule to the virtual server.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have Application Connector installed and configured on your BIG-IP system.
  • You have configured one or more application virtual servers to deliver HTTPS traffic to pool members that reside in the cloud, and the BIG-IP system load balances this traffic.

Procedures

To enable cookie persistence, you must add the /Common/application_connector_plugin/client_cookie_persistence iRule, which is installed along with the Application Connector Service Center, to your virtual server. To do so, perform one of the following procedures:

  • Configuring cookie persistence using the Configuration utility
  • Configuring cookie persistence using tmsh

Configuring cookie persistence using the Configuration utility

Impact of procedure: Although this procedure adds an additional iRule to the virtual server, it should not have a negative impact on traffic.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Click the name of the virtual server on which you want to enable cookie persistence for Application Connector.

    The virtual server's Properties tab opens.

  4. Click the Resources tab.

    The iRules section should contain at least one iRule called /Common/application_connector_plugin/client_traffic_director.

  5. Click Manage.
  6. In the Available box, select the iRule called /Common/application_connector_plugin/client_cookie_persistence and click << to add it to the Enabled box.
  7. Using the Up and Down buttons, reorder the list so that the /Common/application_connector_plugin/client_cookie_persistence iRule appears at the top of the Enabled list, before the /Common/application_connector_plugin/client_traffic_director iRule.

    Important: The /Common/application_connector_plugin/client_cookie_persistence iRule must execute before the /Common/application_connector_plugin/client_traffic_director iRule. If /Common/application_connector_plugin/client_cookie_persistence is not first, cookie persistence will not function for pool members tunneled through Application Connector.

  8. Click Finished to save the changes.
  9. In the Load Balancing section, for Default Persistence Profile, select cookie.
  10. Click Update.

After you've enabled cookie persistence, test your system to make sure that it is working.

Configuring cookie persistence using tmsh

You can use the TMOS Shell (tmsh) to enable cookie persistence for application virtual servers using Application Connector.

Impact of procedure: Although this procedure adds an additional iRule to the virtual server, it should not have a negative impact on traffic.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To add the /Common/application_connector_plugin/client_cookie_persistence iRule to the virtual server and reorder the associated iRules, using the following command syntax:

    modify /ltm virtual <virtual server name> rules { application_connector_plugin/client_cookie_persistence application_connector_plugin/client_traffic_director }

    For example, the following command adds cookie persistence and reorders the associated iRules on a server named vs1:

    modify /ltm virtual vs1 rules { application_connector_plugin/client_cookie_persistence application_connector_plugin/client_traffic_director }

    Important: The /Common/application_connector_plugin/client_cookie_persistence iRule must execute before the /Common/application_connector_plugin/client_traffic_director iRule. If /Common/application_connector_plugin/client_cookie_persistence is not first, cookie persistence will not function for pool members tunneled through Application Connector.

  3. To save the configuration, type the following command:

    save /sys config

After you've enabled cookie persistence, test your system to make sure that it is working.
