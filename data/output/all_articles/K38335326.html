Known Issue

The Traffic Management Microkernel (TMM) may stop responding if misconfigured Generic Routing Encapsulation (GRE) tunnel and route objects cause an ill-formed routing loop inside the TMM.

This issue occurs when all of the following conditions are met:

  • You configure a GRE tunnel with a specific endpoint address.
  • You configure a network route that encompasses the network IP address of the GRE tunnel endpoint.

Impact

TMM stops responding due to an internal routing loop.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A routing loop occurs internally, which can be indicated by an increase in traffic or memory usage.
  • TMM stops responding.
  • Traffic is disrupted while the BIG-IP system restarts.

Workaround

There is no workaround for this issue. To prevent this issue from occurring, before you deploy your configuration, you can check the GRE tunnel and route objects to ensure that a routing loop is not inadvertently created.
