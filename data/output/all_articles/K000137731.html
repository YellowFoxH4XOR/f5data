Description

  • You can modify this command as needed to get other desired config too. The basic premise of this command is using one-line, grep and cut commands.
  • You use this command to get a list of your desired config.

Environment

  • appropriate permissions to the BIG-IP CLI

Cause

Not Applicable

Recommended Actions

Login to the BiIG-IP using SSH, if you do automatically get to the TMOS prompt type 'bash' to get to the bash CLI prompt.

The following command will give you a list of all VS and IP address that has "policies none" from the common partition only
tmsh list ltm virtual all-properties one-line | grep "policies none" | cut -d' ' -f 3,28

The following command will give you a list of all VS and IP address that has "policies none" from all partitions
tmsh -c 'cd /; list ltm virtual all-properties one-line recursive' | grep "policies none" | cut -d' ' -f 3,28

Additional Information

 

How this command works.tmsh list ltm virtual all-properties one-line

This gives you a list of all virtual server config listed in a single line. ( Output may look as if it is wrapped around in your ssh shell )
| grep -i "policies none"

This grep ignores case sensitivity and filters lines with the matching phrase "policies none"
| cut -d' ' -f 3

This cuts out all column values using the delimeter ' ' ( the list ltm virtual)
