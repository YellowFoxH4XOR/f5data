Description

How to announce Route Origination BGP Prefixes using the XC Portal RO tool

Environment

  • XC DDoS
  • XC Routed Customer (Route Organization)
  • Always Available

Procedure

Navigate to Routed DDOS > Manage > Route Advertisement  

1. Find the prefix that you want to advertise

Note: Network Prefix entry must exist in "Manage > Prefixes" tab and "Review Status" must be "Approved"

2. Chose prefix from the list click on three dots on right side

3. Select "Advertise Route Advertisement".

 The BGP advertising process will begin.

Note: The prefix must be already advertised by you to Distributed Cloud.
