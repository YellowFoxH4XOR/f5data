Known Issue

The nexthop iRules command may not work as expected.

This issue occurs when all of the following conditions are met:

  • You configure an IPv6 virtual server.
  • You create an iRule that includes the nexthop command using the following syntax:

    nexthop <vlan> <IP address>

    or

    nexthop <IP address>

  • You associate the iRule with the IPv6 virtual server.
  • The virtual server processes an IPv6 connection that triggers the iRule.

Impact

IPv6 connections are delayed or time out.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • F5 iHealth lists Heuristic H506541 on the Diagnostics > Identified > Medium page.
  • You observe an error message similar to the following in the /var/log/ltm file:

    01220001:3: TCL error: /Common/<iRule-name> <iRule-event> - while executing 'nexthop IPv6_address.'

  • You observe that some IPv6 connections are delayed or time out.

Workaround

You may be able to work around this issue by rewriting the affected iRule to use the nexthop <vlan> <ethernet address> syntax, instead of the nexthop [<vlan>] <IP address> syntax.

Impact of workaround: Changing the design of an iRule may have additional effects on traffic processing. Ensure that any modifications are compatible with your environment.
