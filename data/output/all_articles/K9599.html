Topic

You can configure the BIG-IP system to perform a boot from the network boot server using the command line, the Configuration utility, or by enabling the PXE boot option directly in the BIOS depending on the platform.

Note: The Always-On Management (AOM) subsystem does not include an option to enable network boot, however the PXE boot option in the BIOS provides this function if there are no available BIG-IP system boot locations on the device.

To perform a boot from a network boot server, perform one of the following procedures:

  • Configuring the BIG-IP system to perform a netboot using the command line
  • Configuring the BIG-IP system to perform a netboot using the Configuration utility
  • Configuring the BIG-IP system to perform a netboot using the platform BIOS
     
    • BIG-IP 1600, 3600, and 3900 platforms
    • BIG-IP 6900 and 8900 platforms
    • BIG-IP 2x00, 4x00, 5x00, 7x00, and 10x00 platforms

Note: To enable network boot on SCCP based platforms refer to K3525: Configuring SCCP-based BIG-IP platforms to boot from a network boot server.

Note: After the BIG-IP system has booted from the network once, it will reset itself to boot from its local hard drive for subsequent boots.

Configuring the BIG-IP system to perform a netboot using the command line

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To set the netreboot database variable, type the following command:

    tmsh modify sys db boot.netreboot value enable

  3. When you are ready to reboot the system, type the following command:

    reboot

Configuring the BIG-IP system to perform a netboot using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. In the main navigation pane, click System.
  3. Click General Properties, or in BIG-IP 10.x, click Configuration.
  4. Select the check box next to Network Boot.
  5. To confirm that you want the system to be configured to boot from the network, click OK.
  6. Click Update.
  7. When you are ready to reboot, log in to the command line and reboot the system by typing the following command:

    reboot

Configuring the BIG-IP system to perform a netboot using the platform BIOS

To configure the BIG-IP system to perfrom a netboot using the platform BIOS, perform one of the following procedures for your platform.

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

BIG-IP 1600, 3600, and 3900 platforms

  1. Set up your PXE server and verify that it is on the same network as the appliance you need to boot.
  2. Connect to the AOM subsystem either using the serial console or, if it was assigned an IP address, by opening a secure shell (SSH) connection.
  3. If connecting using the serial console, display the AOM subsystem menu by pressing the following:

    Esc (

    If connecting via SSH, first enter the hostconsh command, and then press the following:

    Esc (

  4. Type 3 to select the Reset Host subsystem option.
  5. Press Enter.
  6. When prompted, press Y to confirm your choice.

    The BIG-IP Host subsystem will reset and the AOM subsystem will automatically connect to the Host subsystem console.

  7. When the BIOS information is displayed, press DEL to enter the BIOS setup.
  8. Once inside the BIOS setup screen, use the arrow keys to navigate to the Chipset tab.
  9. Enter the South Bridge Configuration sub screen and change the Onboard NIC PXE option to Enabled.
  10. Press ESC to go back to the main BIOS setup screen.
  11. Navigate to the Exit tab.
  12. Select Save Changes and Exit.
  13. Choose Ok when prompted to save configuration changes and exit setup.

    The BIG-IP Host subsystem will restart and will attempt to locate a network server from which to boot.

Note: The Boot.NetReboot bigpipe database variable dictates the value of the Onboard NIC PXE BIOS option. After you successfully re-install and boot into the BIG-IP system, the database variable and the BIOS option will automatically revert to Disabled.

BIG-IP 6900 and 8900 platforms

  1. Set up your PXE server and verify that it is on the same network as the appliance you need to boot.
  2. Open a serial console terminal on the appliance you want to enable for PXE boot.
  3. To display the AOM Command Menu, type the following key sequence:

    Esc (

    Note: The key sequence is Shift + ESC + 9.

  4. Select the following option:

    2 --- Reboot Host subsystem (sends reboot command)

  5. Type Y to reboot the Host.
  6. Select the following option:

    1 --- Connect to Host subsystem console

BIG-IP 2x00, 4x00, 5x00, 7x00, and 10x00 platforms

  1. Set up your PXE server and verify that it is on the same network as the appliance you need to boot.
  2. Open a serial console terminal on the appliance you want to enable for PXE boot.
  3. To display the AOM Command Menu, type the following key sequence:

    Esc (

    Note: The key sequence is Shift + ESC + 9.

  4. Select the following option :

    R --- Reset host subsystem

  5. When prompted, press Y to confirm your choice.
  6. Select the following option:

    Q --- Quit menu and return to console

  7. As the unit begins rebooting, press the p key as soon as you see the BIOS message:
