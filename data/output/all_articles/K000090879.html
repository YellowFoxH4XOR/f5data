K000090879: APM Kerberos SSO fails with error "Kerberos: can't get S4U2Proxy ticket for server HTTP/account@REALM - Message stream modified (-1765328343)"

Type

Published

Updated
2021-11-23
Status
Final
Source

Description

Some applications with Kerberos SSO may failed. Check the /var/log/apm, there are error messages like:

Kerberos: can't get S4U2Proxy ticket for server HTTP/account@REALM - Message stream modified (-1765328343)

 Environment

  • BIG-IP APM
  • Kerberos SSO
  • Recent MS patch(es)

 Cause

MS KB5007247

 Recommended Actions

Please check the MS KB5008603 and install the patch:  KB5008603: Authentication fails on domain controllers in certain Kerberos scenarios on Windows Server 2012 R2

 Additional Information

None
