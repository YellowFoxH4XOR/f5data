Known Issue

This is the result of a known issue. FirePass may incorrectly report an error message similar to the following example when users attempt to access a Portal Access Web Application with a valid URL:

Security exception
Access to http://<hostname>/ is denied.
Reason: Hostname is invalid.

This issue occurs when the Web Application URL is a hostname instead of a fully qualified domain name (FQDN), and the first character of the URL is numeric. For example, the following URLs would be affected by this issue:

http://5mx
https://5mx
http://501
https://501

The following URLs would not be affected by this issue:

http://5mx.lab.siterequest.com
https://5mx.lab.siterequest.com
http://501.siterequest.com
https://501.siterequest.com

F5 Product Development tracked this issue as CR88616 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-552-11 has been issued for FirePass version 5.5.2, cumulative hotfix HF-601-9 has been issued for FirePass version 6.0.1, and cumulative hotfix HF-602-1 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

For administrator-defined favorites, you can work around this issue by performing the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Portal Access: Web Applications: Resources page.
  3. In the Resource Group menu, select the Resource Group you want to configure.
  4. In the Web Application Favorites section, click the name of the Web Application you want to configure.
  5. In the URL: text field, replace the hostname in the URL with the fully qualified domain name (FQDN).

    For example:

    http://5mx/records/page1.html

    Replace the above example with the following:

    http://5mx.lab.siterequest.com/records/page1.html

  6. If you are running FirePass version 6.0.0 or later, click the Add to allow list link.
  7. Click the Update button.
