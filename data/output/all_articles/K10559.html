Topic

FirePass supports single sign-on (SSO) for many applications through the use of session variables. Since the Microsoft Terminal Services Client (mstsc.exe) does not offer command line parameters for passing the username or password, you cannot configure SSO for a Network Access or Application Access favorite which auto-launches mstsc.exe.

Note: The Microsoft Terminal Services Client is also referred to as the Remote Desktop (RDP) client.

Newer versions of the Microsoft Terminal Services Client allow users to configure and save logon credentials on the Options >> General tab to an RDP file. After connecting to a Network Access or Application Access favorite, a user can launch the RDP file to automatically log in to the remote server.

Note: If the Options >> General tab does not display the Allow me to save credentials option or the Save my password option, the user is running an older version of the Microsoft Terminal Services Client. Newer versions are distributed through Windows Update and Windows Service Packs. Additionally, newer versions can be downloaded at the Microsoft Download Center.
