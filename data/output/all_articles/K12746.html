Topic

The Apple iOS Edge Client configuration list shows the saved connections from which the user can select. The user cannot currently sort that list and must search for the specific connection they want to use.

F5 Product Development has fixed this issue in BIG-IP Edge Client for Apple iOS 1.0.1 and later versions.
