Issue

Error Message

notice lind[<PID>]: 013c0006:5: Image (<image_filename>) has a software image entry in MCP database but does not exist on the filesystem

In this error message, note the following:

  • <PID> is the process ID of the lind process.
  • <image_filename> is the name of the software image that the lind process is unable to find on the filesystem.

For example:

notice lind[5603]: 013c0006:5: Image (BIGIP-13.1.0.2-0.0.6.iso) has a software image entry in MCP database but does not exist on the filesystem

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all the following conditions are met:

  • You are attempting to install a software image.
  • The local lind process is unable to find the specified filename of the software image on the filesystem.

The master control program daemon (mcpd ) maintains records of software images uploaded in its MCP database. The lind process, which manages software installation and volume creation tasks, also keeps records of the same software images. As software images are added and removed from the system, if a record exists in the MCP database but the lind process is unable to locate it in the filesystem during a software installation process, this error message is logged.

Impact

The requested installation operation does not complete and stays in a waiting state.

Recommended Actions

Import the required software image file to the BIG-IP system, restart the lind service, and perform the hotfix installation again. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Import the software image to the /shared/images directory of the BIG-IP system using the procedure in K175: Transferring files to or from an F5 system.
  2. Log in to the command line of the BIG-IP system.
  3. Restart the lind service by typing the following command:

    tmsh restart /sys service lind

  4. Perform the software installation again.
