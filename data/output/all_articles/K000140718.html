K000140718: BIG-IP Next Central Manager unable to re-add deleted instances

Description

Inability to re-add a BIG-IP Next instance after deleting it from BIG-IP Next Central Manager

Environment

BIG-IP Next Central Manager

The BIG-IP Next Instance was successfully deleted from Central Manager

Attempting to re-add the Instance (which has been factory reset) back to BIG-IP Next Central Manager

Cause

Skipped step in the Procedure:  must ensure that the instance has been setup to allow it to be managed by the Central Manager (i.e. setup scripts or at the very least the default admin password has been changed, which must be done outside of Central Manager)

Recommended Actions

Ensure that the instance has had its default admin password changed (i.e. setup scripts have been run on the instance, or at the very least the default admin password has been changed using the api/v1/me endpoint).

If the BIG-IP Next instance is inaccessible or cannot be completed for some reason, consider deleting this instance from its hypervisor and deploying a fresh instance, then perform all the manual onboarding as necessary for that instance's platform.
