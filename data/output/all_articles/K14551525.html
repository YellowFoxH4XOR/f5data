Known Issue

The static route may fail to route traffic to the destination address.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a Virtual Local Area Network (VLAN) and self IP address.
  • You create a static route to a node or pool member address using the VLAN of the self IP as the gateway with a 32-bit destination netmask.

    For example:

    vlan-B is configured with the self IP address of 172.16.2.50/24

    tmsh create /net route node_specific_route { interface vlan-B network 172.16.55.10/32 }

    net route node_specific_route {
        interface /Common/vlan-B
        network 172.16.55.10/32
    }

Impact

Traffic does not route to the destination address.

Symptoms

Workaround

To work around this issue, you can modify the route configuration setting the destination node address with a netmask other than /32, or when possible use gateway routes. 

Impact of workaround: Performing the following procedure should not have a negative impact on your system as long as the netmask chosen does not create network overlap with existing networks in the environment.
