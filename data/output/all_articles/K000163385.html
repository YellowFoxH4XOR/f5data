K000163385: Downgrading BIG-IP LTM to an Unconfigured Partition

Type
Support Solution
Published
2026-09-23
Updated
2026-09-23
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000163385

Description

Booting an earlier BIG-IP LTM software version on an unconfigured partition preserves the existing management IP address, but resets the administrative login credentials to the default or initial credentials for that installation.

Environment

  • Product: BIG-IP LTM
  • Target partition: Newly installed or unconfigured

Cause

Booting an earlier BIG-IP LTM software version on an unconfigured partition.

Recommended Actions

  1. Record the current management IP address and verify console access before starting.
  2. Install or boot the earlier BIG-IP software version on the unconfigured partition.
  3. Access the system using the retained management IP address.
  4. Use the default or initial administrative credentials associated with the new installation.
  5. Verify the following:
    • Management IP connectivity
    • Administrative login credentials
    • Licensing

   6. Rebuild the configuration manually or install a UCS file that matches the downgraded software version.
