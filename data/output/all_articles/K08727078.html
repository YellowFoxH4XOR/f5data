Description
HTTP monitor does not send requests when a web server only replies to a request which contains FQDN

Environment

  • HTTP monitor
  • nhost header
  • FQDN request

Cause
Built-in HTTP monitor always uses IP address to send requests.

Recommended Actions

If the built-in monitor works with nhost header, please add nhost information. To add nhost information, please follow the below steps:
  1. Log in to the configuration utility
  2. Create a new monitor by navigating to Local Traffic > Monitors > Create
  3. Create a monitor with HTTP as a parent monitor 
  4. In the send string add,
      GET /login http/1.1\r\nhost: <FQDN>\n
                Example:
        GET /login http/1.1\r\nhost: my_FQDN.com\n
    5. Click Update.

If the monitor does not work with nhost header, consider using EAV external monitor.
