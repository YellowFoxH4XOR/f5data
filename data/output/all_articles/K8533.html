Topic

Starting in version 6.0.2 of FirePass software, you can configure a size limit for FirePass log files. In the Purge Logs section of the Device Management: Maintenance: Logs page, you can configure a numeric value between 0.5 and 1.8 Gigabytes in the A purge of logs will be forced when the size of any log file exceeds this limit field. If a log file reaches the size limit you configured before the next scheduled log purge, FirePass purges all log files.

Note: The next scheduled log purge is displayed at the top of the Purge Logs section of the Device Management: Maintenance: Logs page. You can configure the log purge schedule by selecting a time interval in the Keep logs for menu in Purge Logs section of the Device Management: Maintenance: Logs page.

On heavily loaded FirePass controllers, a smaller log file size limit may improve FirePass performance. In recent versions of FirePass software prior to version 6.0.2, FirePass automatically purged logs once a log file reached approximately 1.8 Gigabytes. This was not a configurable option.

F5 Networks Product Development tracked this enhancement as CR61801. For information about upgrading, refer to the FirePass Release Notes.
