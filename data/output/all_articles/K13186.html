Known Issue

The Next: Run Time and Next: End Time for an ARX schedule may not display properly.

This issue occurs when all of the following conditions are met:

  • A schedule is created where an instance of the Schedule: Interval occurs prior to the Schedule: Start Time.

    For example, on November 1, 2011, a schedule is created with a Schedule: Start Time of November 11, 2011 and a Schedule: Interval of Every Sunday. This schedule would be affected because there is a Sunday (November 6) before the schedule's initial Schedule: Start Time of November 11.
  • The show policy schedule details are viewed using the show policy schedule CLI command or on the Schedule Summary page in the ARX Manager GUI.

This is an issue with how the ARX calculates the Next: Run Time and Next: End Time when displaying the policy details. The schedule will use the expected Schedule: Start Time and Schedule: Stop Time as configured and will not start prior to the configured Schedule: Start Time.

Impact

This issue is cosmetic only.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The show policy schedule CLI command will indicate the Next: End Time is prior to the Next: Run Time.

    For example, in the following show policy schedule command output, the Next: End Time is listed as Nov 6, but the Schedule: Start Time is November 11:

      Schedule:         test
        Start Time:       Fri Nov 11 12:00:00 2011
        Stop Time:        Sat Dec 31 12:00:00 2011 (Expires in 58 d 20:05:34)
        Interval:         Every Sunday
        Duration:         05:00:00
        Status:           Waiting for start time (runs in 3 d 20:05:34)

        Next:
          Run Time:         Fri Nov 11 12:00:00 2011 (Schedule Start)
          End Time:         Sun Nov  6 17:00:00 2011


  • The Schedule Summary page in the ARX Manager GUI will indicate the Next Run time is prior to the schedule's configured Started time.

     Schedule   Started                    Next Run                  Last Run   Interval       Run Duration   Reference Count
     test       Nov 11, 2011 12:00:00 PM   Nov 6, 2011 12:00:00 PM   N/A        every Sunday   5 hours        0
