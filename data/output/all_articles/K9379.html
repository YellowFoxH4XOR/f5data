Topic

This solution updates F5 Networks' best practice recommendations for migrating an existing load balancing configuration from BIG-IP version 4.x to the current maintenance release in the BIG-IP LTM version 9.x branch, based on the following two factors:

  • Changes have been made to the originally recommended upgrade path
  • Support for the One Time Conversion Utility (OTCU) is limited for some versions

Changes have been made to the originally recommended upgrade path

In some cases, the original upgrade path referenced in the Release Notes of early BIG-IP LTM versions is no longer available, or is no longer the optimal upgrade path from BIG-IP version 4.x to BIG-IP LTM version 9.x.

Support for the OTCU is limited for some versions

In some cases, the BIG-IP version 4.x configuration may not migrate along with the software upgrade. Upgrading the BIG-IP software typically migrates the existing configuration just as well without user intervention, but the configuration may fail when upgrading from certain BIG-IP versions. The OTCU was created to assist in migrating existing BIG-IP versions, which include version 4.5.12 and prior, to BIG-IP LTM version 9.x; it was not updated to include new features added in BIG-IP versions 4.5.13, 4.5.14, or 4.6.x.

It may be possible to use the OTCU to convert a UCS archive from version 4.5.13 through 4.6.x, but if the configuration uses any of the new features added since version 4.5.12, the conversion will fail. If the OTCU is unable to convert the existing configuration to the new BIG-IP LTM schema, you must recreate the previous configuration manually once the BIG-IP LTM software has been installed on the existing hardware.

Note: Manually recreating the BIG-IP version 4.x configuration in BIG-IP LTM version 9.x is a helpful way to become more familiar with the new modular profile-based configuration paradigm adopted for BIG-IP LTM version 9.x, and may result in a more efficient and intuitive final configuration.

Note: For more information about running the OTCU, refer to the Migrating from BIG-IP 4.x to Local Traffic Manager 9.x Release Notes. For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

For details about the optimal upgrade and migration path to BIG-IP LTM, refer to the following table:

Current versionUpgrade and migration path
BIG-IP versions 4.2 through 4.5 PTF-03

Upgrade to BIG-IP version 4.5.12. To do so, refer to the BIG-IP 4.5.12 Release Note.

Next, upgrade from BIG-IP version 4.5.12 to the current 9.3.x maintenance release. To do so, refer to the BIG-IP Local Traffic Manager and TMOS Release Note.

Use the OTCU to migrate your configuration, or recreate it manually after the upgrade is complete.

BIG-IP versions 4.5 PTF-04 through 4.5.12

Upgrade to the current version 9.3.x maintenance release. To do so, refer to the BIG-IP Local Traffic Manager and TMOS version 9.3.1 Release Note.

Use the OTCU to migrate your configuration, or recreate it manually after the upgrade is complete.

BIG-IP versions 4.5.13 through 4.5.14

Upgrade to the current version 9.3.x maintenance release. To do so, refer to the BIG-IP Local Traffic Manager and TMOS version 9.3.1 Release Note.

You can attempt to use the OTCU to migrate your configuration, or recreate it manually after the upgrade is complete.

Note: The OTCU may not fully migrate a UCS archive created in BIG-IP version 4.5.13 or 4.5.14.

If the OTCU cannot successfully migrate the existing configuration, manually recreate it after the BIG-IP LTM version 9.x software installation is complete.

BIG-IP versions 4.6 through 4.6.4

Upgrade to the current version 9.3.x maintenance release. To do so, refer to the BIG-IP Local Traffic Manager and TMOS version 9.3.1 Release Note.

You can attempt to use the OTCU to migrate your configuration, or recreate it manually after the upgrade is complete.

Note: The OTCU may not fully migrate a UCS archive created in BIG-IP version 4.6.

If the OTCU cannot successfully migrate the existing configuration, manually recreate it after the BIG-IP LTM version 9.x software installation is complete.

Note: If you require assistance with upgrading, migrating, or recreating a configuration after upgrading, contact F5 Professional Services.
