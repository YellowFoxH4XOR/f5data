K23159853: Error: No such file or directory in user.log, messages and snmpd.log when route domains are configured

Type
Support Solution
Published
2022-03-04
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 14.1.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.X.X, 14.1.0, 14.0.1, 14.0.0, 14.1.2
Source
https://my.f5.com/manage/s/article/K23159853

Description

When a route domain is configured on the BIG-IP log messages similar to the following are logged:

/var/log/snmpd.log:
Cannot statfs net:[4026532676]
: No such file or directory
Cannot statfs net:[4026532552]
: No such file or directory

/var/log/messages:
Sep 24 03:32:57 <hostname> No such file or directory
Sep 24 03:32:57 <hostname> No such file or directory

/var/log/user.log:
Sep 24 07:15:28 <hostname> No such file or directory
Sep 24 07:16:58 <hostname> No such file or directory
 

Environment

  • BIG-IP 14.1.x
  • route domains configured
  • snmp configured and running

Cause

Bug ID 760468

Recommended Actions

There is no functional impact. The message logged does not indicate functional issues. However, the issue might occur frequently, which can be erroneously concerning.
For more information refer to: K72356248: warning diskmonitor[11436]: 011d0002:4: Skipping net:[4026532451]. Stat returned message: /usr/bin/stat: cannot read file system information for net:[4026532451]: No such file or directory
