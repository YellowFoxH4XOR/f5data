Known Issue

You may erroneously create virtual servers with HTTP Strict Transport Security (HSTS) without a Client SSL profile.

This issue occurs when all of the following conditions are met:

  • You have configured the HTTP profile with HSTS enabled.
  • You create or modify a virtual server with the HTTP profile without a Client SSL profile.

You should enable HSTS only on virtual servers with client SSL profiles.

Impact

You may produce invalid configurations.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H645660 on the Diagnostics > Identified > Low page.
  • You may erroneously create or modify a virtual server with HSTS without a Client SSL profile.
