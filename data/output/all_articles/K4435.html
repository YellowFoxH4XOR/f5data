Topic

Multiple Spanning Tree Protocol (MSTP) is supported only on BIG-IP 1500, 3400, 6400, 6800 and later platforms. MSTP is not supported on BIG-IP 1000, 2400, or 5100 platforms, although those platforms will run BIG-IP versions 9.0 and later.

If you attempt to enable MSTP on an unsupported platform, you will receive the following error message:

01070102:3: MSTP mode is not supported on this platform.

If you have BIG-IP 1000, 2400, and 5100 platforms and have upgraded these platforms to version 9.0 or later, you may use Spanning Tree Protocol (STP), Rapid Spanning Tree Protocol (RSTP), or passthrough modes, rather than MSTP.
