Description

If the Virtual Server Client SSL profile is configured to be TLS 1.3 only, Windows 10 Edge Client users cannot connect.

Environment

  • Software version supporting TLS 1.3
  • A Virtual Server with a Access Policy using a Network Access object. (in other words, terminating a VPN)
  • The Client SSL profile configured to only allow TLS 1.3
  • Edge Client users for Windows, version 7222 or later.

Cause

  • Microsoft does not support TLS 1.3 across its core code in Windows 10. Although the Control Panel. Internet Options, Advanced, allows TLS1.3 to be enabled, this is not reflected in the core libraries that are used by the Edge Client.

Recommended Actions

  1. Set to TLS 1.2
  2. Upgrade to Windows 11

Additional Information

The Edge Client leverages the Windows platform code.
