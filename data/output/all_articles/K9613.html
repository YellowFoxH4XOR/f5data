Known Issue

This is the result of a known issue. Disabling and then re-enabling VLAN failsafe requires a bigstart restart, which can interrupt traffic and reset persistence information.

F5 Networks Product Development tracked this issue as CR128179 and CR89893.

CR128179 was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, PSM, WebAccelerator, or WAN Optimization Release Notes.

CR89893 was fixed in BIG-IP version 9.4.7 and version 9.6.1. The version 10.x branch is not affected. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, PSM, WebAccelerator, or WAN Optimization Release Notes.

In addition, CR89893 was fixed in Hotfix-BIGIP-9.4.8-396.1-HF3 issued for BIG-IP version 9.4.8, and Hotfix-BIGIP-9.4.6-425.0-HF1 issued for BIG-IP version 9.4.6. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
