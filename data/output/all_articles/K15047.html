Known Issue

A RADIUS health monitor configured with a password that contains more than 16 characters does not work as expected.

This issue occurs when all of the following conditions are met:

  • The configuration has a RADIUS health monitor with a password that is more than 16 characters.
  • You have applied the affected health monitor to monitor a resource.

Impact

The system might incorrectly mark the status of the resource that is using the affected RADIUS health monitor as down.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The password on the RADIUS health monitor does not match the user's associated password on the RADIUS server, even when the password was typed correctly.
  • The resource pool using the affected health monitor may be falsely marked down.
  • When you have enabled debugging on the affected health monitor, you may notice an error message in the debug log similar to the following example:

    Expected code '2', got ''

Workaround

To work around this issue, you can modify the password of the RADIUS health monitor to be 16 characters or less. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Local Traffic > Monitors.
  3. Select the name of the affected RADIUS monitor.
  4. Enter the new RADIUS password with 16 characters or less into the Password field.

    Note: The new RADIUS password for the associated user must also be modified on the RADIUS server.

  5. To save the changes, click Update.
