Description

When running a performance test of LTM in AWS, we are getting some low-performance results in the case of the amount of connections.

However, CPU and memory of BIG-IP usage appear low.

 

Environment

  • BIG-IP
  • AWS
  • Security group connection tracking is set in AWS

Cause

Amazon EC2 defines the maximum number of connections that can be tracked per instance.

After the maximum is reached, any packets that are sent or received are dropped because a new connection cannot be established. When this happens, applications that send and receive packets cannot communicate properly.

This AWS limitation can limit the amount of connection on LTM.

Use the conntrack_allowance_available network performance metric to determine the number of tracked connections still available for that instance type.

Recommended Actions

Remove security group tracking or use a bigger EC2 instance. Bigger EC2 instances have higher capacity in the case of the maximum number of tracked connections.

Additional Information

There is more information regarding EC2's maximum number of connections:

https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/security-group-connection-tracking.html
