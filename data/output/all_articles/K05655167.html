Description

Learning Speed is set to Custom, instead of Fast, Medium or Slow.

Environment

  • ASM Security Policy
  • Learning Mode enabled

Cause

A modification has been made to one of the 3 stages of the Policy Building Process (Loosen Policy, Tighten Policy, or Minimize false positives (Track Site Changes)). When set to Advanced, users can view and change the conditions under which the Policy Builder modifies the security policy during any of the three stages. Changing the values in any of the rules (to values not matching any of the default values) also changes the learning speed to the Custom learning speed type (instead of Fast, Medium, or Slow).

This is configured at Security >> Application Security : Policy Building : Learning and Blocking Settings : Policy Building Process

Recommended Actions

This is by design. However, the Custom setting can be over-ridden, if needed, by manually changing the Learning Speed, clicking Save, then clicking Apply Policy.

Additional Information

Minimize false positives (Track Site Changes) can only be changed when Learning Mode is set to Automatic. However, if the change in the Policy Building Process is left in a non-default state for Minimize false positives (Track Site Changes) and the Learning Mode is changed to "Manual" the Learning Speed will still show Custom unless manually changed.
