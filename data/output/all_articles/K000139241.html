Description

You would like to change the format of the syslog logs to the CEF(Arcsight) on the BIG-IP.

Environment

  • BIG-IP
  • Syslog

Cause

CEF format is not supported for Syslog

Recommended Actions

The CEF format is not supported for Syslog logs. If you would like to use the CEF you have to use the HSL logging.

Additional Information

Configuring Remote High-Speed Logging
