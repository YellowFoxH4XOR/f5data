Description

When attempting to load the configuration on a VIPRION platform error messages similar to the following are displayed:
err mcpd[4215]: 0107134b:3: (rsync: write failed on "/config/filestore/.snapshots_d/epsec_package_d/:Common:EPSEC:Upload:epsec-1.0.0-570.0.iso_29550_1": No space left on device (28) rsync error: error in file IO (code 11) at receiver.c(301) [receiver=3.0.6] ) errno(0) errstr().
Note: This issue may be more prominent on BIG-IP APM due storage of EPSEC files.

Environment

  • VIPRION
  • BIG-IP

Cause
The /config partition is full.

Recommended Actions
Remove unnecessary files from the /config partition

Additional Information

  • K21175584: Removing unnecessary OPSWAT EPSEC packages from the BIG-IP APM system
