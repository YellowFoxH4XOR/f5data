Description

Even if MS Window Defender is disabled on the client PC, endpoint check still show the antivirus as enabled.

Environment

  • BIG-IP APM
  • Antivirus endpoint check
  • MS Windows Defender

Cause

MS Window defender automatically turns back on - by design

It is not enough to disable the Real-time protection

Recommended Actions

To completely turn Window defender off and all its services (not safe) but if you want to disable it, there is an elaborate explanation on how to do it in the references.
