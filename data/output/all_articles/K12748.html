Topic

The FirePass and BIG-IP APM systems can automatically launch web applications when a client authenticates to the FirePass or BIG-IP APM controller. In order for the automatic launch of applications to work, the Virtual Private Network (VPN) client must support that action. This feature is implemented in the iOS Edge Client 1.0.1 to allow automatic launching of web applications from the BIG-IP Edge Client for Apple iOS.

You can download the latest BIG-IP Edge Client for Apple iOS from http://itunes.apple.com/us/app/f5-big-ip-edge-client/id411062210.
