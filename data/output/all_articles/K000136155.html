K000136155: Offline Helm Installation of NGINX Ingress Controller Fails

Type
Support Solution
Published
2023-09-11
Updated
2023-09-11
Applies to
  • NGINX Products
  • NGINX Ingress Controller: 3.X.X, 3.0.0, 3.0.1, 3.0.2, 3.0.X, 3.1.0, 3.1.1, 3.1.X, 3.2.0, 3.2.1, 3.2.X
Source
https://my.f5.com/manage/s/article/K000136155

Description

Installing NGINX Ingress Controller with Helm in a k8s cluster that does not have access to the Internet fails. An error similar to the following occurs:

Error: INSTALLATION FAILED: values don't meet the specifications of the schema(s) in the following chart(s):

nginx-ingress:

Get "https://raw.githubusercontent.com/nginxinc/kubernetes-json-schema/master/v1.26.1/_definitions.json": dial tcp [2606:50c0:8000::154]:443: connect: network is unreachable

Environment

Kubernetes Ingress Controller

Cause

File ./kubernetes-ingress/deployments/helm-chart/values.schema.json is used for configuration testing during a Helm installation and contains external links that required Internet access.

Recommended Actions

Move or delete file ./kubernetes-ingress/deployments/helm-chart/values.schema.json
