K000141530: The customized configuration lost after upgrade SSLO

Type
Support Solution
Published
2024-10-21
Updated
2024-10-21
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator: 17.X.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000141530

Description

Change the Topology / Security Policy from Protected to Unprotected, customize the configurations, then upgrade the BIG-IP SSLO, the customized modification was lost, the Topology / Security Policy become Protected again.

Environment

  • BIG-IP SSLO
  • Unprotected Topology / Security Policy
  • Upgrade

Cause

On upgrading from anything below 9.0 (16.1.x) to anything 9.0 or above causes redeploy of most/all blocks. The redeployment would cause custom modifications to be lost.

Recommended Actions

After change the Topology / Security Policy to Unprotected Configuration, please document all modifications, after upgrade, check it again, and redo it again if lost.

Additional Information

None.
