K000137583: HA group not working as expected on tenant

Type
Support Solution
Published
2023-11-14
Updated
2024-03-26
Applies to
  • F5OS
  • F5OS-A: 1.4.0, 1.5.0
Source
https://my.f5.com/manage/s/article/K000137583

Description

Failover not working as expected after interface associated with a trunk (that part of HA Group score) state is changes (up or down).

Environment

  • VELOS or rSeries platform
  • F5OS-A
  • BIG-IP running on F5OS tenant
  • HA Group score includes Trunk

Cause

If trunks are used for HA Group the scores associated to the trunks are not deducted from the overall health scores regardless of whether the interfaces in the trunks are up or not. This is tracked as Bug ID 1293305: LAG interface status is not updated on the BIG-IP tenant

Recommended Actions

ID1293305 is fixed F5OS-A 1.5.1, 1.6.0 and 1.7.0 -- so we recommend to upgrade the host to the fixed version or the workaround as stated in ID1293305 can be followed.
