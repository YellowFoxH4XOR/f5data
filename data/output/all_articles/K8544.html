Known Issue

This is the result of a known issue. Upgrading from BIG-IP ASM 9.4.3 and rolling forward a configured UCS to BIG-IP ASM 9.4.4, prevents the Advanced Firewall SMTP Security profile feature from displaying in the Configuration utility.

This behavior prevents the configuration of the Advanced Firewall SMTP Security profile. As a result, attempting to associate an SMTP profile to a virtual server will immediately reset all connections to the virtual server after the connection handshake.

F5 Product Development tracked this issue as CR96091 and it was fixed in BIG-IP ASM 9.4.5. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Workaround

Important: If you want to use the Advanced Firewall SMTP Security profile, you cannot roll forward a BIG-IP ASM 9.4.3 configuration.

To use the Advanced Firewall SMTP Security profile, you must perform the following procedures:

  • Exporting any BIG-IP ASM security policies
  • Performing a clean installation of BIG-IP ASM 9.4.4
  • Re-configuring the clean installation of BIG-IP ASM 9.4.4
  • Importing the BIG-IP ASM security policies

Exporting any BIG-IP ASM security policies

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Web Applications.
  3. Click the name of the web application you want to export.
  4. In the Policies List section, select the active policy.
  5. Click the Export button.
  6. Follow the steps to download the policy.

Performing a clean installation of BIG-IP ASM 9.4.4

Perform a clean installation of BIG-IP ASM 9.4.4 as outlined in the BIG-IP ASM 9.4.4 Release Notes. You can skip the step to create a config.ucs file in the root directory.

Re-configuring the clean installation of BIG-IP ASM 9.4.4 manually

You must manually re-configure the clean installation of BIG-IP ASM 9.4.4.

Importing the BIG-IP ASM security policies

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Policies List.
  3. Click the Import button.
  4. In the Import Security Policy List section, click the Browse button.
  5. Locate the security policy to import.
  6. Click the Import button to import the Security Policy.
