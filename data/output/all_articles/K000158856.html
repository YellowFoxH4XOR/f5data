K000158856: Base64 Decoding is enabled by default after creating a security policy with a swagger file

Applies to

  • BIG-IP ASM: 17.5.0, 21.0.0, 17.5.1, 21.X.X, 17.5.X, 21.0.X
Source

Description

When importing a Swagger/OpenAPI file into a BIG-IP ASM security policy (version 17.5.x and later), the "Base64 Decoding" setting for URL parameters is automatically set to "Enabled," even if it was previously disabled. This differs from earlier versions, where the default was "Disabled." Manual changes to this setting may be reset after each re-import of the API specification, and there is no direct way to control this behavior through the Swagger/OpenAPI file.

Environment

  • Product: BIG-IP ASM (Application Security Manager)
  • Product Group: BIG-IP
  • Version: 17.5.1 and later (including 21.0.0)
  • Configuration Object: ASM Security Policy, URL Parameters
  • Feature: Swagger/OpenAPI import for policy creation
  • Recent Action: Re-importing Swagger/OpenAPI file into an existing ASM policy

Cause

The behavior results from a design change in BIG-IP ASM version 17.5.x and later:

  • The "Base64 Decoding" setting now supports three options—"Enabled," "Disabled," and "Required."
    • "Enabled": Auto-detect; decodes only if value is valid Base64.
    • "Required": Enforces decoding; raises violation if value is not legal Base64.
    • "Disabled": Disables Base64 decoding.
  • Upon OpenAPI import, parameters default to "Enabled" (auto-detect). There is no method to specify "Disabled" directly in the Swagger/OpenAPI file.

Recommended Actions

After importing, manually edit affected parameters in the ASM security policy UI to set your preferred Base64 decoding option.

Additional Information

  • In versions ≥17.5.x, “Enabled” means auto-detection of valid Base64 values—decoding occurs only when appropriate.
  • This new behavior allows enforcement of signatures within Base64 values without triggering violations for non-Base64 data.
  • The change is intentional and part of product design evolution.
  • There is currently no way to specify or override this setting directly within imported Swagger/OpenAPI files.
