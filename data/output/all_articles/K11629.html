Topic

By default, single sign-on (SSO) credential mapping employs the username and password supplied by the user when logging in to a BIG-IP APM device. However, some environments may want to use other credentials for SSO authentication than the credentials used to gain access to the BIG-IP APM system. Users can configure custom session variables for SSO credential mapping that can be set on a customized logon page. To do so, perform the following procedures:

Prompting the user for SSO credentials on the Logon page

  1. Log in to the BIG-IP Configuration utility.
  2. Click Access Policy.
  3. Click Access Profiles.
  4. Next to the access policy you want to configure, click Edit.

    The visual policy editor opens.
  5. Click Logon Page.
  6. Under Logon Page Agent, select text from the menu on line three.
  7. In the corresponding Post Variable Name field, enter a name that the user will know in order to supply their SSO username.

    For example:

    SSO_Username

  8. Under Logon Page Agent, select password from the menu on line four.
  9. In the corresponding Post Variable Name field, enter a name that the users will know in order to supply their SSO password.

    For example:

    SSO_Password

  10. Click Save and continue to the next procedure.

Configuring the custom SSO session variable

  1. In your Access Policy, click SSO Credential Mapping.
  2. Select Custom from the SSO Token Username menu.
  3. Change the session variable to the following:

    [mcget {session.logon.last.field3}]

    Note: This step will retrieve information that the user submits in the third field on the Logon page.

  4. Select Custom from the SSO Token Password menu.
  5. Change the session variable to the following:

    [mcget {session.logon.last.field4}]

    Note: This step will retrieve information that the user submits in the fourth field on the Logon page.

  6. Click Save.
  7. Click Close.
  8. Select the Access Policy you just configured by selecting the check box next to its name.
  9. Click Apply Access Policy.
