These vulnerabilities are described as methods under which an attacker could generate a PNG file that would cause applications that use libpng to execute arbitrary code. Since an attacker would require root access to the BIG-IP or 3-DNS in order to exploit this vulnerability, it is considered to be a minor risk.

F5 Product Development tracked this issue as CR39078, and it was fixed in BIG-IP 4.5.11 and 4.6.3, in which the version of libpng was upgraded to version 1.2.5.
