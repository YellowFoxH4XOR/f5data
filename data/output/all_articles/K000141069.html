Description

Changing the port numbers for CLI (SSH) F5OS is currently not supported.  Currently, the default port for SSH listens on 22.

Environment

  • F5OS
  • CLI/SSH
  • SSHD listening on the port 22

Cause

None, behavior explanation.

Recommended Actions

The current F5OS configuration does not support changing the default port ssh for the CLI or SSH access.

Note: Even if you successfully change the SSHD listening port by modifying the configuration file under /etc/ssh/sshd_config, F5OS will still be listening on the default port 22.

Additional Information

This feature is tracked as RFE ID 2152825.
