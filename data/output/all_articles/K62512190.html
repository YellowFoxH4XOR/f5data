Topic

You should consider using this procedure under the following condition:

  • You want to observe traffic utilization for a BIG-IP system using the iControl representation state transfer (REST) API.

Description

The BIG-IP REST API provides endpoints for viewing traffic and performance statistics, both globally and for specific traffic objects, such as virtual servers, pools, and nodes. You can use the iControl REST API to perform most of the BIG-IP system management and configuration tasks that you can perform using the TMOS Shell (tmsh). For more information about the iControl REST API, refer to the iControlREST Home page on F5 Cloud Docs.

This article focuses on returning statistics using the following API endpoints. The equivalent tmsh commands and Configuration utility references are provided for clarification.

API endpointtmshConfiguration utilityDescription
/mgmt/tm/sys/traffictmsh show /sys trafficStatistics > Module Statistics > Traffic Summary > GeneralDisplay the general traffic summary statistics for the BIG-IP system.
/mgmt/tm/sys/icmp-stattmsh show /sys icmp-statStatistics > Module Statistics > Traffic Summary > ICMPDisplay IPv4 and IPv6 specific packet and error-related statistics.
/mgmt/tm/sys/ip-stattmsh show /sys ip-statStatistics > Module Statistics > Traffic Summary > IPDisplay IPv4 and IPv6 specific packet, error, and fragment-related statistics.

The curl and jq utilities

Performing the following procedures requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems but can also be installed on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure from an alternate BIG-IP system. For more information about the jq utility, refer to https://stedolan.github.io/jq.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP system is licensed, provisioned, and configured with a management IP address.
  • You have administrative access to the BIG-IP Configuration utility.
  • You have command line access to a system with the curl utility and, optionally, the jq utility installed. For more information, refer to The curl and jq utilities section of this article.
  • You have access to the iControlREST Home Cloud Docs page to review iControl REST API documentation.

Procedures

  • Viewing general traffic summary statistics for the BIG-IP system
  • Viewing IPv4 and IPv6 specific packet and error-related statistics
  • Viewing IPv4 and IPv6 specific packet, error, and fragment-related statistics

Viewing general traffic summary statistics for the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to view the general traffic summary statistics for the BIG-IP system:

    curl -sku admin:<password> -H "Accept: application/json" -X GET https://<BIG-IP hostname or mgmt IP address>/mgmt/tm/sys/traffic | jq -M .

    For example, to view the traffic summary on a BIG-IP using the previously listed Example configuration, type the following command:

    curl -sku admin:testing -H "Accept: application/json" -X GET https://LTM1.example.com/mgmt/tm/sys/traffic | jq -M '.'

    The output looks similar to the following truncated example:

    {
      "kind": "tm:sys:traffic:trafficstats",
      "selfLink": "https://localhost/mgmt/tm/sys/traffic?ver=17.1.0.3",
      "entries": {
        "https://localhost/mgmt/tm/sys/traffic/0": {
          "nestedStats": {
            "entries": {
              "clientSideTraffic.bitsIn": {
                "value": 19315080
              },
              "clientSideTraffic.bitsOut": {
                "value": 107630088
              },
              "clientSideTraffic.curConns": {
                "value": 1019
              },

    This output has been limited because of the large number of results returned. You can use the jq utility to limit the results to only those of interest. For example, to view only the current connections, use the previous command with the following jq filter:

    curl -sku admin:training -H "Accept: application/json" -X GET https://LTM1.example.com/mgmt/tm/sys/traffic | jq -M '.entries[].nestedStats[]."clientSideTraffic.curConns"'

    Note: The jq utility uses the dot (.) character as a separator. When a key contains a dot character, as in the example with clientSideTraffic.curConns, you must enclose the key with double quotes and the entire filter string with single quotes.

    The output looks similar to the following example:

    {
      "value": 1019
    }

    To return only the value, add square brackets ([]) after the clientSideTraffic.curConns key. Notice that the square brackets are not included inside the double quotes. For example:

    curl -sku admin:training -H "Accept: application/json" -X GET https://LTM1.example.com/mgmt/tm/sys/traffic | jq -M '.entries[].nestedStats[]."clientSideTraffic.curConns"[]'
