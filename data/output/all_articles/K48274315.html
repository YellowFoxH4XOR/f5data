K48274315: What permissions are needed by F5 Access on mobile devices?

Type
Support Solution
Published
2019-08-26
Updated
2023-02-21
Applies to
  • BIG-IP
  • F5 Access
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K48274315

Description

When configuring the app to connect to the VPN, the user is asked to 'Activate this device administrator' which "gives the App the right to lock the device or erase the phones data".

Environment

  • APM
  • F5 Access App

Cause
The F5 Access client requires administrative permissions to some services on mobile devices for full functionality.

ServiceUse
Photos/Media/FilesThis is used to create and store diagnostic reports and share them with other apps such as email.
CameraThis is used for scanning of QR codes for provisioning RSA SecurID tokens.
Wi-Fi connection informationThis is used to create the VPN connection, monitor the Wi-Fi network state and collect the Wi-Fi MAC address.  It is also used to pair with Bluetooth devices and collect the device name for Access Policy reports.
Device ID and call informationThis is used to collect unique information about the device such as IMEI/MEID and creates APM session variables.  These variables are provided to the MDM for verification of the device's security state.

Recommended Actions

None.
