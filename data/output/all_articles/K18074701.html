Description


iHealth Upgrade Advisor feature provides ability to perform bug scrubs on version targeted for upgrade.  The Upgrade Advisor bug list is a list of unresolved bugs which may affect the target upgrade version.  Bug scrubs help customers determine the level of risk a given version may pose.  Bugs in result list are based on licensed features in the qkview.  Results can be exported as CSV or PDF.

A bug scrub is NOT a list of all the unfixed bugs in a given release of software. Some Bug IDs do not get included because they are low in likeliness, or are are low in impact.

 

Environment

  • iHealth
  • Software Upgrade
     

Cause

Upgrade to new version.

 

Recommended Actions

Use Upgrade Advisor in ihealth to assist in planning upgrades.  Select target version and then submit to generate the list.
