Description
Subscriber keep getting provision-pending from PEM even though PCRF did send CCA reply contain Charging-Rule-Install to PEM.

(tmos)# show pem sessiondb all
<OMITTED>
Session State             provisioning-pending

Wireshark/tcpdump showing the CCA reply contains Charging-Rule-Install.

Diameter Protocol
<OMITTED>
    Flags: 0x40, Proxyable
    Command Code: 272 Credit-Control
    ApplicationId: 3GPP Gx (16777238)
<OMITTED>
    AVP: Charging-Rule-Install(1001) l=40 f=V-- vnd=TGPP

However PEM gx stat showing CCA received is zero.

(tmos)# show pem stats gx
<OMITTED>
CCA received                              -    -      0        -       0
  CCA-initial received                    -    -      0        -       0
  CCA-update received                     -    -      0        -       0
  CCA-usage-monitoring received           -    -      0        -       0
  CCA-termination received                -    -      0        -       0

Environment

  • PEM
  • PCRF
  • Diameter

Cause
PCRF server replied the CCA with prohibited AVPs.

Diameter Protocol
    Version: 0x01
    Length: 392
    Flags: 0x40, Proxyable
    Command Code: 272 Credit-Control
    ApplicationId: 3GPP Gx (16777238)
<OMITTED>
    AVP: Result-Code(268) l=12 f=-M- val=DIAMETER_SUCCESS (2001)
    AVP: Destination-Realm(283) l=17 f=-M- val=EXAMPLE.COM
    AVP: Destination-Host(293) l=34 f=-M- val=2001:DB8:0:0:0:0:0:6

Destination-Host AVP and Destination-Realm AVP must not be present in Answer messages according to RFC6733.

Recommended Actions

PCRF server should remove those prohibited AVPs when reply the CCA.
