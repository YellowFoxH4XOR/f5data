Known Issue

The configuration load fails when a BIG-IP ASM-enabled virtual server resides in a non-default partition.

This issue occurs when all of the following conditions are met:

  • A BIG-IP ASM-enabled virtual server is configured in a partition other than the /Common partition.
  • The virtual server is configured with a DoS profile.
  • The DoS profile is configured in the /Common partition.
  • You attempt to load the configuration using the Traffic Management Shell (tmsh) utility or roll the configuration forward during an upgrade.

Impact

MCP validation fails, which causes the configuration load to fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Following an upgrade, the BIG-IP system does not load the configuration into memory.
  • After creating a virtual server with a DoS profile, the configuration fails to load and you see an error message similar to the following example:

    DoS profile with Application Security enabled requires HTTP profile.

Workaround

To work around this issue, create virtual servers and associated profiles in the /Common partition.
