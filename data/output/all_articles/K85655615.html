Description
When installing a new TLS Certificate, the import fails with the following error in the terminal or /var/log/tmm

tmsh install sys crypto cert swgCA.crt from-local-file /path/to/certificate.crt
failed to read password encryption key from the file
/shared/fips/nfbe0/pek.key_1, error 40000229

/var/log/tmm
localhost notice failed to read password encryption key from the file /shared/fips/nfbe0/pek.key_1, error 40000229

Environment

  • BIG-IP
  • FIPS 140

Cause
Bug ID 646633

The FIPS Card has not been initialized.

Recommended Actions

Initialize the FIPS card.

    Additional Information
    When the FIPS card is initialized for the first time, the directory and file /shared/fips/nfbe0/pek.key_1 are created. This file is referenced any time a new TLS Certificate is imported into the BIG-IP, regardless if the Certificate is being imported as a FIPS Encrypted object or not.
