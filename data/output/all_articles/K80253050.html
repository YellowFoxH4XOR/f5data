Known Issue

The BIG-IP system may disrupt Internet Key Exchange version 2 (IKEv2) negotiations when the remote peer request contains a remote address configuration option.

This issue occurs when the following condition is met:

  • The remote IKEv2 peer sends the address lease-pool configuration option in its IKEv2 negotiation.

    For example, a CISCO APIC device sends an IKEv2 request with an address lease-pool configuration option to the BIG-IP system.

Impact

The BIG-IP system fails to establish an Internet Protocol Security (IPsec) security association (SA) with a remote peer.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe that the traffic-selector selection in an IKEv2 negotiation results in incorrect matching results.
  • You observe that the system fails to establish an IPsec SA with a remote peer.
