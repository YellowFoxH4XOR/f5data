Topic

You can configure an iRule to issue a redirect message to new connections when the number of active nodes in the specified pool is less than the specified amount.

For example, the following iRule redirects users to a maintenance page when the number of active nodes drops below two:

when HTTP_REQUEST {if { [active_members http_pool ] < 2 } {HTTP::redirect  "http://www.askf5.com/SORRY.HTML"}}
