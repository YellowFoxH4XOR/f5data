K000138123: Qualys scan shows that F5OS port 7001 is using SHA1 for SSH.

Type
Support Solution
Published
2024-01-03
Updated
2024-01-03
Source
https://my.f5.com/manage/s/article/K000138123

Description

A Qualys scan is run and it comes back with the following:

QID - 38909 (There are a couple of other QIDs that may also show up).

Title : SHA1 deprecated setting for SSH

Port : 7001


Environment

F5OS does use SHA1 for the SSH kexalgorithms on the VConsole, and the VConsole uses port 7001.


Recommended Actions

If you need to remove SHA1:

1) You can check which kexalgorithms F5OS will use for the sshd service by using the system security services service sshd config kexalgorithms command.

Example;

appliance-1(config)# system security services service sshd config kexalgorithms ?

Description: User specified kexalgorithms.

Possible completions:

[ diffie-hellman-group1-sha1 diffie-hellman-group14-sha1 diffie-hellman-group14-sha256 diffie-hellman-group16-sha512 diffie-hellman-group18-sha512 diffie-hellman-group-exchange-sha1 diffie-hellman-group-exchange-sha256 ecdh-sha2-nistp256 ecdh-sha2-nistp384 ecdh-sha2-nistp521 curve25519-sha256 curve25519-sha256@libssh.org gss-gex-sha1- gss-group1-sha1- gss-group14-sha1- ]


2) Run this command to change it, picking from the prior list what you want to use:

Example:

appliance-1 (config)# system security services service sshd config kexalgorithms [ diffie-hellman-group14-sha256 diffie-hellman-group16-sha512 ecdh-sha2-nistp256 ecdh-sha2-nistp384 ecdh-sha2-nistp521 ]


3) You check them with this command:

show system security


4) Review running the command from before to get a list:

system security services service sshd config kexalgorithms ?


5) Don't forget to commit the change:

appliance-1 (config)# commit
