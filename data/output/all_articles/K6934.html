Known Issue

This is the result of a known issue. Versions of Sun's Java Run-time Environment (JRE), beginning with JRE 1.5.0_08, will prevent the tab character from being sent to the host when using a Java-based Legacy Host Favorite.

Legacy Host Favorites permit you to connect to an ASCII terminal-based application on a remote host, using a TELNET-based protocol. Using a Legacy Host Favorite will create a terminal window in your web browser. You can use a Java applet or an ActiveX control to configure FirePass Legacy Host Favorites to provide terminal access.

When using a Legacy Host Favorite, pressing the tab key should send a tab character to the remote application. However, the tab character is not sent to the remote application under the following circumstances:

  • The Legacy Host Favorite uses any of the Java-based Term-type settings, such as VT100, VT220, VT320, or TN3270
  • Your client operating system's JRE version is 1.5.0_08 or higher

If the above conditions are met, pressing the tab key causes the window focus to move to the next focusable element in the browser window.

Note: The version of the JRE on a Windows-based client can be found by opening the Java Control Panel and selecting the About option. For instructions about determining the JRE version used in a non-Windows operating system, consult the documentation for your operating system.

F5 Product Development tracked this issue as CR72308 and it is fixed in version 6.0.1 of FirePass software. For information about upgrading, refer to the FirePass release notes.

Additionally, a hotfix has been issued. For version 6.0.0 of FirePass software, this issue was fixed in Cumulative Hotfix HF-600-10. For version 5.5.2 of FirePass software, this issue was fixed in Cumulative Hotfix HF-552-4. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing hotfixes.
