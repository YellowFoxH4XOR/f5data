Source
https://my.f5.com/manage/s/article/K15311551

Description

Configuration fails to load after an upgrade, with a message similar to the following:

emerg load_config_files[10678]: "/usr/bin/tmsh -n -g -a load sys config partitions all gtm-only" - failed. -- Loading schema version: 13.1.1.2

Environment

  • GTM/DNS not provisioned

Cause

  • Bug ID 837637

Recommended Actions

Execute the following commands to fix the issue:

rm -f /config/bigip_gtm.conf

bigstart restart

Additional Information

This issue typically occurs when GTM/DNS was provisioned at some point in the past, and is no longer used.
