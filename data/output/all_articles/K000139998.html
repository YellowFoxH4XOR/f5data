K000139998: CGNAT Port Block Allocation (PBA) mode not working on r4800 system

Type
Support Solution
Published
2024-06-12
Updated
2024-06-12
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000139998

Description

On the r4800 platform, CGNAT with PBA mode is not working (traffic doesn't route). CGNAT with NAPT mode works correctly.


Environment

r4800 and other r-series platforms which do not contain the necessary FPGA chip.

CGNAT Port Block Allocation (PBA) mode


Cause

PBA is only compatible with SP-DAG. If a VLAN is used that's not compatible with SP_DAG, then NAPT mode must be used.

SP-DAG requires an FPGA chip on-board. r4800 does not have the necessary FPGA


Recommended Actions

Some R-Series appliances (r5000 and r10000) support SP-DAG (PBA mode can be used): https://techdocs.f5.com/en-us/f5os-a-1-5-0/f5-rseries-systems-administration-configuration/title-additional-system-tasks.html#service-provider-feature-overview

For other systems, such as r4800, CGNAT must be configured to use NAPT mode.


Additional Information

When attempting to change to SP-DAG mode on unsupported platform, such as r4800, the following expected warning can be observed:


root@(tenant)(cfg-sync Standalone)(Active)(/Common)(tmos)# modify net vlan test cmp-hash dst-ip

There were warnings:

This device does not support the requested 'cmp-hash' setting (dst-ip) in hardware.

Performance may be limited.

01bb0010:3: Modifying cmp-hash within a guest system is not supported on the deployed host system.
