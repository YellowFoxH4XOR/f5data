Known Issue

The BIG-IP GTM Configuration utility may report an error when attempting to make configuration changes.

This issue occurs when all of the following conditions are met:

  • You attempt to update any of the settings in the following sections of the Configuration utility:
    • System › Configuration › Global Traffic: General
    • System › Configuration › Global Traffic: Load Balancing
    • System › Configuration › Global Traffic: Metrics Collection

When the Configuration utility reports an error, the modifications you made are not applied.

Impact

You cannot make configuration changes using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Configuration utility reports an error message similar to the following example:

    An error has occurred while trying to process your request.

  • An error message similar to the following example is reported in the /var/log/tomcat/catalina.out file:

    java.lang.IllegalStateException: A name must be specified when updating an object.
    at com.f5.view.web.pagedefinition.shuffler.handler.DBOperation.execute(DBOperation.java:110)

Workaround

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

To work around this issue, you can use the Traffic Management Shell (tmsh) utility to make the desired changes.
