K000163201: ENOMEM error when deploying as3 json using terraform

Type
Support Solution
Published
2026-09-03
Updated
2026-09-03
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000163201

Description

An AS3 declaration submitted through Terraform fails with spawn ENOMEM while reading the /Common/appsvcs/settings data group. Related logs may show RPM_BUILD_FAILED, terminated package-build processes, or Connection refused responses from BIG-IP REST services.

Environment

  • BIG-IP LTM
  • AS3 declarations deployed through Terraform
  • AS3 and related iApp package operations using the BIG-IP REST framework
  • Management memory settings:
    • provision.extramb: 0 MB

Cause

Insufficient management-plane memory is available for AS3, restjavad, and related package-build operations. The resource shortage can cause spawned processes to fail with ENOMEM or be terminated, preventing AS3 from reading /Common/appsvcs/settings and completing the Terraform deployment.

Recommended Actions

  1. Schedule a maintenance window before changing management memory allocation.
  2. Increase the management-plane memory allocation:
    tmsh modify sys db provision.extramb value 500
  3. Increase the restjavad memory allocation:
    tmsh modify sys db provision.restjavad.extramb value 584
  4. Save the configuration if required by the platform configuration procedure.
  5. Retry the AS3 declaration deployment through Terraform.
  6. Confirm that the deployment completes successfully and that spawn ENOMEM and RPM_BUILD_FAILED messages no longer occur.

Impact of workaround: Changing management memory allocation may temporarily interrupt traffic while the system recovers from a TMM restart. In an HA configuration, the system may also fail over. Perform the change during an approved maintenance window.
