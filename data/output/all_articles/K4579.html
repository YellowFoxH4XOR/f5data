Known Issue

This is the result of a known issue. If you enable cookie persistence and connection mirroring for a virtual server, connections for that virtual server will no longer be mirrored.

This is generally not a serious problem. Connection mirroring is rarely used for HTTP and cookie persistence ensures that the client is directed to the same node after the connection is reestablished.

F5 Networks Product Development tracked this issue as CR47153.
