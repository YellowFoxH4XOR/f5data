Topic

Attack signatures are rules that identify attack sequences or classes of attacks on a web application and its components. You can apply attack signatures to both requests and responses to identify known security violations.

The BIG-IP ASM attack signature logic is proprietary information and is not displayed in the BIG-IP ASM Configuration utility. Information about the type of attack vector that a given signature is designed to protect against is not confidential information, and F5 can release this information upon request.

F5 Product Development is tracking a Request For Enhancement (RFE) to display attack signature logic in the BIG-IP ASM Configuration utility as ID 305775 (formerly CR100640).
