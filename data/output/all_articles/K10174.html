Known Issue

This is the result of a known issue. If you enable the Lockout new user sessions setting on a secondary cluster node, the setting is disabled during the next synchronization. This issue occurs regardless of whether or not the Lockout new user sessions setting is enabled on the primary cluster node.

Note: The Lockout new user sessions setting is located on the Device Management: Maintenance: User Session Lockout page.

Note: For information about which settings are synchronized between members of a cluster, refer to K8816: Configuration parameters that are not synchronized between members of a cluster.

F5 Product Development is tracking this issue as ID 296434 (Formerly CR122201).
