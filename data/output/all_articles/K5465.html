Topic

This article applies to BIG-IP 9.x through 10.x. For information about later versions, refer to the following article:

  • K13833: Managing static routes in BIG-IP and BIG-IQ

You can manage static routes on the BIG-IP system using either the Configuration utility or the command line.

Note: Static routes added to a BIG-IP system using the Configuration utility or the command line are stored in the /config/bigip.conf file which is synchronized between peer units during a configsync operation.

Adding a route

Configuration utility

  1. Log in to the Configuration utility.
  2. In the main navigation pane, click Network.
  3. From the menu, click Routes.
  4. Click Add.
  5. Select Route from the Type menu.
  6. Enter the Destination IP Address.
  7. Enter the Netmask Address.
  8. Select the desired option from the Resource field.
    • If you select Use Gateway, enter a gateway IP Address.
    • If you select Use Pool, select a pool.
    • If you select Use VLAN, select a VLAN.
    • If you select Reject, the system will drop packets sent to this destination.
  9. Click Finished.

Command line

  1. Log in to the command line.
  2. Add a route by using the following command syntax:

    bigpipe route <address> netmask <netmask> gateway <address>

  3. Save the routes by typing the following command:

    bigpipe save

    For example:

    To add routes to host address 172.16.25.1, and to network address 172.16.0.0/16 using gateway 172.16.1.1, you would type the following commands:

    • To add the host route, you would type the following command:

      bigpipe route 172.16.25.1 gateway 172.16.1.1

       

    • To add the network route, you would type the following command:

      bigpipe route 172.16.0.0 netmask 255.255.0.0 gateway 172.16.1.1

Deleting a route

  1. Log in to the command line.
  2. To delete a route, use the following command syntax:

    bigpipe route <route key> delete

    For example, to delete the example host route created in step 3 from the previous procedure, type the following command:

    bigpipe route 172.16.25.1 delete

Note: For more information about the bigpipe route command, refer to the route section in the Bigpipe Utility Reference Guide.
