Description
        Newly created VLAN on the Host is available to the guest, but when applied to the guest
        the guest does not communicate with the host or outside networks. Host can communicate
        with outside networks using the newly created vlan.

Environment

  • VCMP

Cause
        Newly created VLANs are not automatically applied to the guest on the Guest Status page.

Recommended Actions

  1.  Verify that the active vlans on the VCMP > Guest Status page include the newly create vlan.

Additional Information
       This is a different issue from a guest self-ip communicating with a host self-ip.
       Guest self-ip's are prohibited from communicating with host self-ip's as part of the security design.
