K000152720: How to Create an iRule to Redirect a Specific URI to a Custom Page on BIG-IP LTM

Type
Support Solution
Published
2025-07-24
Updated
2025-07-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000152720

Description:

When configuring URL redirection on BIG-IP LTM, traffic targeting a specific URI (such as the root path "/") may not be redirected to the intended destination if the iRule only checks for the HTTP host header and not the URI. This can result in requests not being properly redirected, even though no error messages are displayed.

 

Cause:

The issue occurs when the iRule is configured to match only the HTTP host header without considering the requested URI path. As a result, requests to certain paths (e.g., "/") are not redirected as required.

 

Recommendations:

To ensure proper redirection based on both host and URI, update your iRule to check for the desired URI value. For example, to redirect all requests arriving at "/" to a specific target URL, use:

when HTTP_REQUEST {
   if { [HTTP::uri] eq "/" } {
      HTTP::redirect "<target_url>"
}
}

Replace <target_url> with your intended destination URL.

This approach ensures that only requests matching the specified URI will be redirected accordingly.
