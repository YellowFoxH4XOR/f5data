Description

How to monitor DNSSEC KSK expiration?

BIG-IP does not provide alerting by default

 

Environment

  • BIG-IP DNS
  • DNSSEC
  • KSK expiration

 

Cause

None

Recommended Actions

You can query the rest api to generate a report. Run the following command on the BIG-IP to get the output for all the dnssec keys:

 

restcurl -u admin tm/ltm/dns/dnssec/key | jq '.items[].tmGenerationReference.link'| sed 's/^.*\/tm/\/tm/' | sed 's/\"//' | while read link; do restcurl -u admin $link; done > /var/tmp/dnskeys.json
