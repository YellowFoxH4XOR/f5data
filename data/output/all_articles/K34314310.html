Topic

You should consider using this procedure under the following conditions:

  • You want to view IP addresses and the configuration objects that they are associated with on the BIG-IP system.

Description

During ongoing maintenance of your BIG-IP system, you may need to review the configured IP addresses. You can display the IP addresses in a single table with the system module of the TMOS Shell (tmsh). The output shows IP addresses assigned to the BIG-IP system itself or IP addresses of remote systems that the BIG-IP system interacts with, such as a pool member or a device service clustering (DSC) peer device. The output table includes four columns based on the various elements of the configuration object:
Important: Self IP addresses do not appear in the IP address table unless they are included in the DSC configuration. You must use the command tmsh list net self address to view them.
Note: The virtual-address object appears in the table rather than the individual virtual servers associated with it.

  • The Entry column displays the IP address.
  • The Component column displays the configuration object type. 
  • The Object-ID column displays the configuration object name.

    Note: If the IP address is used as the object name, the output table displays the IP address in the Object-ID column.

  • The Property column displays the specific object property where the IP address is configured. This column doesn't appear in the output by default.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access tmsh.

Procedures

To display the IP address table using tmsh, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To view the IP address table in the current partition, choose one of the following options:
    • To view the Entry, Component, and Object-ID columns in the output table, type the following command:

      show /sys ip-address

    • To view the Entry, Component, Object-ID, and Property columns in the output table, type the following command:

      show /sys ip-address all-properties

  3. If you have more than one partition and you want to view the IP address table for a specific partition, you must first change partition using the following command syntax in the tmsh utility:

    cd /<partition name>

    For example,

    cd /partition1

    Then proceed to the previous step to view the IP address table for that specific partition.

Alternatively, if you want to view the IP address table in each partition, you can use the following Advanced Shell (bash) script from the BIG-IP command line:

  1. Log in to the command line of the BIG-IP system.
  2. Using a text editor (vi or pico), open the new file K34314310.sh.
  3. Place the following text in the file:

    #!/bin/bash
    #Identify all partitions
    part_var=($(/bin/tmsh list auth partition one-line | awk '{print $3}' ))

    echo "There are ${#part_var[@]} partitions"

    for p in ${part_var[@]}
    do
        echo "For the $p partition:"
        tmsh -c "cd /${p} ; show /sys ip-address all-properties"
        echo "=================================================="
    done

  4. Save the file.
  5. To execute the bash script, enter the following command:

    bash ./K34314310.sh
