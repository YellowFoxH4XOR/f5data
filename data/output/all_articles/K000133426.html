K000133426: BIG-IQ failing to add to BIG-IP

Type
Support Solution
Published
2023-04-06
Updated
2023-04-06
Source
https://my.f5.com/manage/s/article/K000133426

Description

  • Unable to discover/import BIG-IP device on BIG-IQ
  • An error message similar to the following can be seen on BIG-IP /var/log/secure

err httpd[1544]: [auth_f5_auth_token:error] [pid 1544] [client 10.0.0.1:50086] Got exception while handling EM auth token request: Invalid Certificate: Could not open certificate file: "/shared/em/ssl.crt/x.x.x.x.crt": Permission denied, referer: http://localhost:8100/shared/device-discovery-tasks

Environment

BIG-IQ CM
BIG-IP
Device discovery/import

Cause

Failure is triggered due to "Permission denied" when attempting to access "/shared/em/ssl.crt/x.x.x.x.crt".

Recommended Actions

On BIG-IP device delete the existing cert "/shared/em/ssl.crt/x.x.x.x.crt".

Example:

/shared/em/ssl.crt/192.168.0.1.crt

1.  Connect to BIG-IP CLI
2.  Delete cert file 
rm -rf /shared/em/ssl.crt/192.168.0.1.crt
3.  From BIG-IQ add BIG-IP device.
