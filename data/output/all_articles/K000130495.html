Description

Observing connection errors and crit tmm messages in /var/log/ltm similar to the following after updating a CRL object:

crit tmm[11825]: 01260027:2: Profile /Common/prod-clientssl - cannot load CRL /config/filestore/files_d/Common_d/certificate_revocation_list_d/:Common:crl-new-full_88714_11063: Unknown error.

crit tmm[11825]: 01260000:2: Profile /Common/prod-clientssl: could not load CRL

warning tmm[11825]: 01260009:4: Connection error: hud_ssl_handler:1164: invalid profile (40)

No SSL connections can be established.

Environment

  • SSL Profiles
  • CRL

Cause

ID964673

CRL file contains duplicate entries, resulting in invalid SSL profile configuration when applied.

Recommended Actions

Bug ID 964673 does not have a fix at the time of this article's publication.

To work around the immediate issue, load a CRL file without duplicate entries.

To avoid the issue, validate the content of CRL files before importing them to the configuration, ensuring there are no duplicate entries.
