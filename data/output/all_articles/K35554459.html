Issue

Description

You experience problems or delays when connecting to VPN using BIG-IP Edge Client or the web browser client. You observe messages such as: 

  • Network Access Connection Device was not found.
  • Re-installing Network Access Connection Device. Please wait...

Environment

  • BIG-IP APM
  • Network access VPN in Full or Split Tunnel mode
  • BIG-IP Edge Client
  • Microsoft Windows
  • BIG-IP Browser Network Access Client

Cause

These errors indicate a problem was detected between the F5 provided PPP driver, Windows Registry, or RAS Registration of the adapter. For possible causes with log messages found in the %temp%/logterminal.txt file, refer to the following:  

  • F5 PPP driver not found in the Windows Registry.  

    • <date>,<time>, DIALER \driverstatechecker.cpp, GetVPNDriverRASDeviceName, VPN device not found

    • <date>,<time>, DIALER, 48, , 114, GetVPNDriverStateAndName, VPN Adapter RAS device name, ''

  • Driver not registered with RAS 

    • <date>,<time>, DIALER \driverstatechecker.cpp, GetVPNDriverRASDeviceName, RasDeviceName is empty

  • Querying RAS devices failed 

    • <date>,<time>, DIALER, 1, , 255, EnumRASDeviceInstalled, (0xffffffff) EXCEPTION - Enumeration failed. error,, 1058

The most common cause of these driver errors occurs because drivers were installed without Administrator rights.

Recommended Actions

BIG-IP Edge Client has self-recovery functions that will attempt to re-install the PPP driver automatically. If it cannot complete the recovery process, or is not able to fix the driver installation, you should follow the Manually removing BIG-IP APM client components procedure in K8253: Removing BIG-IP APM client components from Windows client systems. After removal, you should install BIG-IP Edge Client and/or browser VPN components with Administrator rights.

Note: Windows 10 Remote Access Connection Manager cannot be started under any conditions if DNS Client or Secure Socket Tunneling Protocol Service are disabled, deleted, or working improperly while the Remote Access Connection Manager is stopped. The Routing and Remote Access service cannot be launched.
