K000139190: 400 Bad Request, license does not allow assigning pool licenses to managed devices

Type
Support Solution
Published
2024-04-05
Updated
2025-05-29
Source
https://my.f5.com/manage/s/article/K000139190

Description

While attempting to apply a new license to a BIG-IP VE from BIG-IQ, it returns: 

Error on server request
The system returned an unexpected error (400 Bad Request). Your system license does not allow assigning pool licenses to managed devices.

Environment

  • BIG-IQ License Manager

  • Big-IP Virtual Edition (VE)

  • Flexible Consumption Program (FCP)

Cause

A BIG-IQ licensed as License Manager can only apply new licenses to unmanaged devices. It can't apply a new license to a managed device. Previously, this BIG-IQ was licensed as Centralized Manager (CM) and the BIG-IPs were imported as managed devices, but the BIG-IQ has since been relicensed as just License Manager.

Recommended Actions

Relicense the BIG-IQ as Centralized Manager.

Note: Reactivating the device license on BIG-IQ only affects the BIG-IQ as its services restart. No BIG-IPs are impacted during this process.

  1. Log on to my.f5.com
  2. Click Subscriptions
  3. Open an active subscription ID
  4. Check for available BIG-IQ CM base registration keys (BRKs)
  5. If BIG-IQ CM BRKs are available, apply one to the BIG-IQ
    • Big-IQ > System tab > Expand This Device > Licensing > Reactivate
    • Replace current base registration key 
    • Click Activate

If no Centralized Manager licenses are available, contact F5's Customer Success team at customersuccess@f5.com.
