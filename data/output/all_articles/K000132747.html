Description

You may wish to replace the existing Virtual Edition (VE) license for your BIG-IP instance with a new license with higher version (e.g. v16 to v18).

Environment

  • BIG-IP Virtual Edition (VE)
  • Purchased a new VE license Base Registration Key (BRK) to upgrade features such as ability to upgrade to new BIG-IP software releases. 

Cause

None

Recommended Actions

To replace VE license on existing instance perform the following steps:

Important: Add-On Keys are associated with a Base Registration Key once it's been activated and cannot be transferred to another Base Registration Key. If features on the Add-On Keys are currently used and required after up-license, please contact your F5 Account team or your third party vendor to seek an advice for the new purchase.

Impact of procedure: This procedure impacts traffic while the BIG-IP system reloads the configuration. F5 recommends performing this during a scheduled maintenance window.

  1. Navigate to GUI: System >> License and click Re-activate.
  2. Click Edit next to the Base Registration Key field and paste the new base registration key.
    Note: Clicking Edit should have deleted any add-on keys from the list. If not, delete any existing add-on keys in the Add-On Registration Key List field.
  3. Paste the new add-on keys to the Add-On Registration Key List field.
  4. Proceed with normal licensing procedure using either Automatic or Manual activation method per K7752: Licensing the BIG-IP system .

Additional Information

To replace the VE license for a High Availability pair, perform the following:

Impact of procedure: Performing the following procedure forces the BIG-IP system to fail over to another device in the device group. All active traffic groups will fail over.

    1. Replace the VE license on the first system.
      1. On the standby system, perform the procedure in the Recommended Actions sections on the first HA pair.
      2. Verify the new license is activated on the first HA pair.
    2. Perform a failover by forcing the active system to standby.
      1. Navigate to GUI: Device Management >> Devices on the active BIG-IP system.
      2. Select the name of the local device showing (Self).
      3. Confirm Status of the devices shows active.

        Note: You cannot force the active system to standby using the Configuration utility of the standby system.

      4. To move the up-licensed system to the active role, force the active BIG-IP system into standby mode by clicking Force to Standby.
    3. Replace the VE license on the second system.
      1. Replace the VE license on the second system by performing the procedure in the Recommended Actions sections on the second system.
      2. Verify the new license is activated on the second system.
