Known Issue

When you attempt to install the F5 Virtual Private Network (VPN) Client for Windows, or the web browser session attempts to install or update client components, you may receive a security warning message stating that the software certificate is expired.

This warning message is benign. If your local policy allows, you can acknowledge the warning and continue the installation.

F5 Product Development tracked this issue as ID 244015 (formerly CR138935) and ID 294412 (formerly CR138935-1), and it was fixed in BIG-IP 10.2.0 and FirePass 7.0.0. For information about upgrading, refer to the BIG-IP APM and FirePass release notes.

F5 Product Development is tracking this issue as ID 327357 (formerly CR138935-2) for BIG-IP 10.1.0, ID 317735 (formerly CR138935-3) for FirePass 6.1.0, ID 296556 (formerly CR138935-4) for FirePass 6.0.3, ID 322951 (formerly CR138935-5) for FirePass 5.5.2, and ID 308091 (formerly CR138935-6) for FirePass 5.5.1.

This issue has been fixed in cumulative hotfix 610-3, which has been issued for FirePass 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
