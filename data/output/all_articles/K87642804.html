Description
When configuring remote logging, you might see a difference in the amount of data per session in the remote destination.
This might be caused by the log level configured in the logging profile.

Environment

  • BIG-IP APM
  • Remote logging
  • Log Profiles

Cause
Log settings in the APM logging profile are not set to Informational, this is the required level so APM sends logs to the remote destinations

Recommended Actions

  1. Verify the log settings for the policy. Go to Access ›› Profiles / Policies : Access Profiles (Per-Session Policies) in the configuration utility and select the access policy in question
  2. Go to the Log tab in the upper part
  3. Verify the log setting that is attached to this policy
  4. Go to     Access  ››  Overview : Event Logs : Settings and select the logging setting that is being used in the policy
  5. Go to "Access System Logs" section and verify that the log settings are configured for at least the informational level.
