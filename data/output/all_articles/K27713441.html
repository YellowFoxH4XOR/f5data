Description

When attempting to load an Attack Signature Update file on a BIG-IP ASM system an error message similar to one of the following is displayed:

  • Service contract cannot be verified. Please re-license your installation of Big-IP manually.
  • Service contract cannot be verified (Cannot handle state FAULT_RETURNED). Please re-license your installation of Big-IP manually.
  • Service contract cannot be verified (No response from license server). Please re-license your installation of BIG-IP manually.

Environment

  • BIG-IP ASM
  • Attack Signature update

Cause

License must have been re-activated within the last 18 months or signature updates will fail.

Recommended Action

Reactivate the system license and reattempt the attach signature update.
Impact of procedure: The license reactivation process may reload the configuration and temporarily interrupt traffic processing.

Note: Be sure to log in as the admin user to re-license the system.
For more information, refer to K9965: The admin user account must be used to license the system.

  1. Log in to the Configuration utility.

  2. Navigate to System > License > Re-activate.

  3. Click either Automatic or Manual as the activation method.
    Important: If your system does not have Internet access to the F5 license server, you must click Manual.

  4. Click Next and follow the instructions.
    Note: For more information about automatic or manual license activation, refer to K7752: Licensing the BIG-IP system.


Additional Information

To view the service check date of a license from the command line to show if it has been reactivated within the last 18 months:

  1. Log in to the command line.
  2. Parse the license output for the Service Check Date
    tmsh show /sys license detail | grep "Service Check Date"
    Note: The date format is month/day/year.
