Issue

Error Message

014e0007:6: mysqlhad starting to monitor mysqld

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The high availability (HA) subsystem begins monitoring the MySQL process, mysqld. This occurs whenever mysqld starts.

The mysqlhad process monitors mysqld by attempting to obtain a usable database handle. Every 5 seconds, mysqlhad attempts to connect to the database and call the ping method on the database handle. If this process fails, the system issues a SIGHUP signal and attempts to restart mysqld. If mysqld does not restart properly, the system triggers the appropriate action designated in the HA table.

Impact

None: the error message is informational.

Recommended Actions

None
