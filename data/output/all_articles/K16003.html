Known Issue

The Traffic Management Microkernel (TMM) may produce a core file on a BIG-IP PEM system, when Gx Endpoint is not available.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP PEM system configuration uses a PEM listener with the Gx Endpoint setting enabled.
  • The Gx Endpoint setting virtual server is not available for connection.
  • The subscriber session is not provisioned.
  • There is a large amount of incoming new subscriber traffic to the PEM listener.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP PEM system briefly fails to process traffic.
  • The BIG-IP PEM system fails over to another system in the device group.
  • TMM generates a core file in the /var/core directory.
