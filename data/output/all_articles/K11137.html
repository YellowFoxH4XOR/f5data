Known Issue

This is the result of a known issue. A client connecting to a BIG-IP WebAccelerator enabled virtual server may be connected to the BIG-IP Configuration utility. The client will be prompted for the BIG-IP Configuration utility user name and password when all of the following conditions are met:

  • The virtual server is configured to listen on port 80
  • The virtual server is enabled for BIG-IP WebAccelerator
  • The BIG-IP WebAccelerator configuration is configured to process requests for unmapped hosts
  • The host name accessed begins with a number (digit) rather than a letter (character)

F5 Product Development tracked this issue as CR118437 and it was fixed in BIG-IP 10.0.1. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
