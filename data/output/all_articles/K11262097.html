Description
The APM Access Guided Configuration (AGC) system can be upgraded.
However that package is not version checked.
After installing an incorrect version, an earlier version cannot be installed.
The AGC can be set to factory default with the following procedure.

Environment.
AGC is supported in Version 13 and later, APM must be licensed.

Note
The package tar.gz  file from downloads.myf5.com is not version checked. That package is a container for other files for the individual use cases. Those files are version checked.
So, despite upgrading the package beyond the supported version, AGC should continue to work correctly.

Procedure
AGC use cases are iapp LX templates.
In the Configuration utility, navigate to
iApps ›› Package Management LX

Select the f5-iappslx-access* and f5-iappslx-waf* packages and uninstall them. Likely this is all of it.

When the Guided Configuration packages are gone, go back to the
Access ›› Guided Configuration
page and it will perform an installation of the default version.
If you now go back to iApps ›› Package Management LX you can see its is now populated, this time with the factory version.
