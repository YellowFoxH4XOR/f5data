K000151188: F5OS GUI cannot be accessed

Type
Support Solution
Published
2025-05-06
Updated
2025-05-06
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000151188

Description

F5OS GUI is inaccessible even though SSH is working. Browser shows connection error or SSL handshake issue. Logs seen on the http-server shows:

 

[root@appliance-1(F5OSHSTNAME) /]# docker exec -it http-server cat var/log/httpd/ssl_error_log
[Sat Jan 04 04:18:12.426424 2025] [ssl:error] [pid 118747] AH02203: Init: Privatekey not found 
[Sat Jan 04 04:18:12.426506 2025] [ssl:error] [pid 118747] SSL Library Error: error:0D0680A8:asn1 encoding routines:ASN1_D2I_READ_BIO:not enough data

Environment

F5OS

Cause

SSL configured to the device is either expired or got corrupted.

Recommended Actions

Generate a new self-signed certificate using the CLI to enable access to the F5OS GUI.

 

1. Login to F5OS CLI.
2. Enter commands

   su admin
   config
   system aaa tls create-self-signed-cert name <name> email <email> city <city> region <region> country <country> organization <org> unit <unit> version 1 days-valid <3650> key-type encrypted-ecdsa curve-name secp384r1 store-tls true key-passphrase

 

      Example:

 

   F5HOSTNAME (config) #system aaa tls create-self-signed-cert name jim email jim@f5.com city Boston region MA country US organization F5 unit Sales version 1 days-valid 3650 key-type encrypted-ecdsa curve-name secp384r1 store-tls true key-passphrase

 

3. Verify that the self-signed certificate is configured.

 

     show system aaa tls

 

4. Reinstall the CA certificate if needed by following the article Installing a Device Certificate in F5OS 

 

Additional Information

None.
