K000092568: Network connectivity fails after adding, removing or modifying an interface in the OpenStack agent for an existing BIG-IP VE

Updated

Source

Description

  • Network connectivity fails after adding, removing or modifying an interface in the OpenStack agent for an existing BIG-IP VE

Environment

  • OpenStack
  • BIG-IP

Cause

Enumeration is broken when underlying hypervisor configuration changes. 
 

 Recommended Actions

When adding, removing or modifying interfaces within a hypervisor, you need to rebuild the binary mcpd configuration as described in a similar hypervisor article for ESX at https://support.f5.com/csp/article/K12149.  After making the changes in the OpenStack agent perform the following steps.

 

  1. # touch /service/mcpd/forceload
  2. # reboot

None.
