Description
You need a copy repo certificate and key to allow you to download NGINX plus

Environment

  • NGINX Controller
  • NGINX Plus
Cause

The Repo certificate and key are not always available in the My F5 portal.

Recommended Actions

Log into the NGINX Controller, change the address to point to the api address, press return, review the downloaded zip file which contains the repo cert and key:

  1. Log into the NGINX Controller GUI
  2. In the address bar delete everything after the FQDN or IP address and replace with: 

    api/v1/platform/licenses/nginx-plus-licenses/controller-provided

    for example:

    https://10.1.1.245/api/v1/platform/licenses/nginx-plus-licenses/controller-provided

  3. You can use 7Zip to open and review the file
  4. You can copy the cert and key to your desired location to allow download of the NGINX Plus software
Additional Information

If you have Controller or Instance Manage available in the My F5 portal, an alternative method of obtaining NGINX Plus binary is to click on resources, NGINX Downloads and choose NGINX Plus on the left side. This will give you a choice of versions and platforms
