K000160153: Automatic DNS Record Creation Not Supported for HTTP Load Balancers with Custom Certificates in F5 Distributed Cloud

Type
Support Solution
Published
2026-02-25
Updated
2026-06-12
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000160153

Description

When using F5 Distributed Cloud (XC) DNS Zone Management with the "Allow Application Load Balancer Managed Records" option enabled, DNS records are not automatically created for HTTP Load Balancers configured with custom certificates.

Users may observe the following symptoms:

  • DNS zone is configured with "Allow Application Load Balancer Managed Records" enabled
  • HTTP Load Balancer is created with a custom certificate (not AutoCert)
  • The expected DNS records (A or CNAME records) for the Load Balancer domain do not appear in the DNS Zone's Resource Record Sets
  • DNS queries for the Load Balancer domain return NXDOMAIN (domain does not exist)
  • No error messages are displayed in the console

Environment

  • Product: F5 Distributed Cloud (XC)
  • Feature: HTTP Load Balancer, DNS Zone Management
  • DNS Zone configuration: "Allow Application Load Balancer Managed Records" enabled
  • Load Balancer certificate type: Custom certificate (user-provided)
  • Load Balancer type: HTTP/HTTPS
  • Domain delegation: XC-managed DNS zone with NS records pointing to ns1.f5clouddns.com and ns2.f5clouddns.com

Cause

Automatic DNS record creation in XC-managed DNS zones is only supported for HTTP Load Balancers configured with automatic certificates (AutoCert). When a custom certificate is used, the system does not populate the required DNS management fields in the Load Balancer's virtual host configuration. Without these fields, the DNS automation workflow is not triggered, and no DNS records are created for the Load Balancer domain.

This is expected behavior by design.

Answer/Recommended Actions

To resolve this issue, choose one of the following options:

 

  • Option 1: Use Automatic Certificates (Recommended)
    • If you require automatic DNS record creation for your HTTP Load Balancer in an XC-managed DNS zone, reconfigure the Load Balancer to use automatic certificates (AutoCert) instead of a custom certificate
    • Navigate to your HTTP Load Balancer configuration
    • Under "Domains and LB Type > Load Balancer Type", select "HTTPS with Automatic Certificate"
    • Save the configuration
    • The DNS records will be created automatically in the DNS Zone
  • Option 2: Manually Manage DNS Records
    • If you must use a custom certificate, you will need to manually create DNS records for the Load Balancer domain
    • In the DNS Zone Management console, navigate to your DNS zone
    • Add the appropriate A or CNAME records pointing to your Load Balancer's hostname or IP address

Important Notes:

  • Recreating the Load Balancer or performing "dummy updates" (e.g., changing the description) will not resolve this issue for HTTP LBs with custom certificates
  • The "Allow Application Load Balancer Managed Records" setting only applies to HTTP LBs using AutoCert

Additional Information

  • When AutoCert is enabled, the system automatically manages both the ACME challenge DNS records and the application DNS records
  • This is not a bug or configuration error; it is the intended behavior of the platform
