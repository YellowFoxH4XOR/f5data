Known Issue

You cannot create listener objects using the TMOS Shell (tmsh) while in a non-common partition.

This issue occurs when all of the following conditions are met:

  • You are currently in a partition that is not the common partition.
  • You attempt to create a listener using tmsh while you are in the partition.

Impact

The system will not create the listener.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Any attempt you make to create a listener using tmsh while in another partition fails and results in an error message similar to the following example:

    01020036:3: The requested profile (/Common/<partition name>/<listener name>>) was not found.
