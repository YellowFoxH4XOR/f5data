Known Issue

Traffic Management Microkernel (TMM) processes may restart and produce a core file when using cookie persistence.

This issue occurs when the following conditions are met:

  • A virtual server is configured to use cookie persistence.
  • An iRule is associated with the virtual server that disables persistence. For example, by using the persist none command.
  • The virtual server processes a client connection that uses cookie persistence.
  • TMM is unable to locate a persistence cookie for the connection.

Impact

If the BIG-IP system is a member in a redundant configuration, traffic fails over to a standby BIG-IP system. If the BIG-IP system is not part of a redundant pair, traffic is interrupted until TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to another host in the device group.
  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
