Known Issue

Connection distribution may be very uneven when a virtual server is associated with a OneConnect profile and certain node-based dynamic load balancing methods.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is running the affected versions with one of the following hotfixes:
    • BIG-IP 11.4.1 HF6, HF7, or HF8
    • BIG-IP 11.2.1 HF11, HF12, HF13, HF14, or HF15
  • You have a virtual server that references a OneConnect profile.
  • The virtual server references a pool that is configured to use one of the following dynamic load balancing methods:
    • ratio (node)
    • least connections (node)
    • observed (node)
    • predictive (node)

Impact

Traffic is load balanced to pool members in a very uneven pattern.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Client traffic is being load balanced to pool members in a very uneven pattern.

Resolution

Status

Workaround

There is no workaround for this issue. To attain an even distribution of traffic among pool members, choose a load balancing algorithm that is not listed in the description conditions.
