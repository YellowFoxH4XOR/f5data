K000151894: VLAN created on rSeries tenant does not work

Description

You have created a VLAN on an rSeries tenant and it does not work.

Environment

  • rSeries
  • Tenant

Cause

The new VLAN should be added on the host device. Tenants inherit VLANs from the host.

Recommended Actions

In order to create a new VLAN on the host and add it to the tenant's configuration, please follow the instructions below.

1. Go to Network Settings > VLANs.

2. Create a new VLAN.

3. Go to Network Settings > Interfaces.

4. Bind the new VLAN to an interface.

5. Go to Tenant Management > Tenant Deployments.

6. Add the new VLAN to Tenant Management > Tenant Deployment and click Save & Close.

7. The new VLAN should by visible in Network > VLANs in the tenant's Configuration utility (please refresh or login again).
