Topic

This article applies to the remote access service (RAS) on the Microsoft Windows operating system. You should consider using this procedure under the following condition:

  • Users connect to BIG-IP APM running the Windows operating system.
  • Users experience connectivity issues when connecting to BIG-IP APM to establish network access sessions.

Description

RAS is a Windows service that provides remote access capabilities to VPN applications on computers running Windows. The BIG-IP Edge Client may experience connectivity issues due to RAS errors. In such cases, you can enable RAS tracing on Windows to troubleshoot the issue.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrator credentials on the Windows client.

Procedures

To enable RAS tracing on Windows perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Using administrator privileges, open a Windows command prompt (cmd).
  2. To enable RAS logging, enter the following command:

    netsh ras set tracing * enabled

  3. Attempt to establish a network access VPN connection.
  4. Stop RAS logging by entering the following command:

    netsh ras set tracing * disabled

  5. In the %windir%\tracing folder, examine the RRASEtwTracing.etl log file to search for anomalies.
  6. You can view the log file in the following two formats:
    • ETL file: You can view ETL files using the Event Viewer utility on Windows. For more information, refer to your Microsoft Windows operating system documentation.
    • TXT file: You can also convert the ETL file to a text file using the following command syntax:

      netsh trace convert input=RRASEtwTracing.etl out=<output filename>.txt

      For example:

      netsh trace convert input=RRASEtwTracing.etl out=exampleRASLogs.txt

  7. Open the RRASEtwTracing.etl file to analyze the trace information regarding RAS and PPP Setup and Negotiation.
