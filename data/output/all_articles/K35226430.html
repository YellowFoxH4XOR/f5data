Description
You may decide to remove ASM from your BIG-IP configuration altogether and possibly de-provision it. You will be unable to de-provision ASM until most ASM configuration items are removed from LTM objects, such as virtual servers.

Environment

  • ASM provisioned
  • ASM configuration, including policies and profiles

Cause
N/A

Recommended Actions

Important: The below actions may require you to reboot the BIG-IP systems and should be performed during a maintenance window.

Disable synchronization on all redundant systems

  • Disable ASM policy sync:
    • Security > Options > Application Security > Synchronization > Application Security > Synchronization and in the dropdown set it to None and click Save.
  • Disable automatic sync, if it is in-use for the Sync-Failover Device Group:
    • Device Management  > Device Groups  > <Device Group Name>

Remove ASM policy associations and delete the inactive security policies

  1. Log into the Configuration utility of the standby BIG-IP system.
  2. Go to Security > Application Security > Security Policies > Policies List.
  3. Under Virtual Server(s), select the virtual server name.
  4. On the virtual server properties page, select Security. 
  5. On the Policy Settings page, select None from Application Security Policy.
  6. Select Update.
  7. Select the virtual server Resources tab.
  8. Under iRules, verify if there are any iRules attached to the virtual server that enable or disable an ASM security policy. If so, you may need to re-write or disable the iRule.
  9. Under Policies, verify if there are any LTM policies attached to the virtual server that enable or disable an ASM security policy. If so, you may need to re-configure or disable the LTM policy.
  10. Repeat steps 2-9 for each virtual server listed on the ASM Policies List page.
  11. Go to Security > Application Security > Security Policies > Policies List and verify that there are no longer any security policies associated with a virtual server. This has to be done for each policy.
  12. Select the inactive security policies and select Delete. (BIG-IP versions prior to 15.1.x)

De-provision ASM

Impact of procedure: The BIG-IP system will become INOPERATIVE during de-provisioning and may require a reboot.

  1. Go to System > Resource Provisioning.
  2. Under Module, deselect Application Security (ASM).
  3. Select Submit.

Repeat the above steps on the active system.

If Auto sync was in-use on the Sync-failover Device Group:

  • Enable automatic sync:
    • Device Management  ››  Device Groups  ››  <Device Group Name>
