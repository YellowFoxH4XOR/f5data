Known Issue

This is the result of a known issue. The BIG-IP ASM remote logging profile allows you to configure where the system logs requests to the web application, and which part of the requests the system logs. When creating a remote logging profile, if you enter an IP address with an octet of 255 in the Server IP field, an error message that appears similar to the following example displays:

Incorrect Server IP

The BIG-IP ASM system incorrectly interprets the octet of 255 as a broadcast IP address.

F5 Product Development tracked this issue as CR106885 and it was fixed in BIG-IP ASM 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.
