Known Issue

Client certificate Secure Sockets Layer (SSL) authentication is unable to bind to a Lightweight Directory Access Protocol (LDAP) server.

This issue occurs when the following condition is met:

  • An SSL Client Certificate LDAP authentication profile is configured with an admin password.

Starting in BIG-IP 11.4.0, authentication configuration secrets are saved to the configuration file in an encrypted format; however, LDAP configuration secrets are not properly decrypted.

Impact

LDAP binds fail, due to incorrect passwords.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H522695 on the Diagnostics > Identified > Medium screen.
  • A message similar to the following example is logged to the /var/log/secure file:

    err tamd[6682]: pam_ldap: error trying to bind (Invalid credentials)
