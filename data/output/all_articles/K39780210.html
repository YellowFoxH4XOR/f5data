Description

Under specific scenarios, F5 Support may request to generate the Client Troubleshooting Utility (CTU) report on the testing (or complaining) Windows machine using administrator rights.  There is a possibility to verify whether the report is generated using standard domain user or administrator rights.

Environment

  • APM
  • CTU
  • Administrator rights

Cause

To verify if the CTU report was generated using administrator rights

Recommended Actions

Open the report generated by CTU utility and locate 'Table of Contents -> Command-Line Utilities -> netstat.exe -abno'.
Follow the command link.
The administrator rights assume that the command gives the output.
When the CTU report is generated without administrator rights, then the command output won't contain any data.
