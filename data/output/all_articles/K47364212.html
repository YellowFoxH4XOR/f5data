Issue

Error Message

err mcpd[<PID>]: 01071d64:3: Invalid multicast address '<ip_address>' specified for multicast-ip.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <ip_address> is the IP address used for the multicast address in the failover configuration.

For example:

err mcpd[<4566>: 01071d64:3: Invalid multicast address '240.0.0.245' specified for multicast-ip.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility 

Description

This message occurs when the following condition is met:

  • You attempt to configure a multicast failover address with an invalid IP address.

When configuring a multicast failover address on the BIG-IP system, you must use an address in the 224.0.0.0/4 subnet (224.0.0.0 through 239.255.255.255) for IPv4 and you must use the ff00:/8 prefix for an IPv6 address. Attempting to configure any other IP address as a multicast failover address results in this error message.

Impact

You are unable to configure the multicast failover address on the BIG-IP system.  No multicast failover packets are sent thus reducing the reliability of operation in high-availability (HA) cluster.

Recommended Actions

Configure a valid multicast address on all devices in the device group.
