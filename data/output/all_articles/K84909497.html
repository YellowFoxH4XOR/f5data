Description
This error is seen when attempting to deploy an application from BIG-IQ that exists on a partition other than Common.

Environment

  • BIG-IQ version 7.x

Cause
The ability to deploy / create applications on the BIG-IQ GUI and deploy them to a partition other than /Common is not available.

Recommended Actions

Use the AS3 Application deployment method from BIG-IQ.  The AS3 Application 'Tenant' field is essentially the same as the 'Partition' field on the BIG-IP.  As such, partitions can be utilized with your AS3 applications.  The one limitation is that you cannot deploy objects to the Common partition using AS3 from BIG-IQ.
