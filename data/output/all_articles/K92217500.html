Issue

Error Message

01700009:3: Unable to locate flow <client_ip>:<port> -> <server_ip>:<port>.

In this error message, note the following:

  • <client_ip> is the IP address of the client for the connection
  • <server_ip> is the IP address of the server
  • <port> is the TCP port used for the connection

For example:

01700009:3: Unable to locate flow 10.10.10.10:50485 -> 172.16.10.10:1723.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • A virtual server is configured to process Point-to-Point Tunneling Protocol (PPTP) traffic.
  • Your BIG-IP system is unable to look up an existing flow for established PPTP traffic.

For example, the flow has expired or was deleted from the connection table.

Impact

The PPTP connection to the BIG-IP system fails.

Recommended Actions

None
