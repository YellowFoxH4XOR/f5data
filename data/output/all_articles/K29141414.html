K29141414: The ping_access_agent process continually restarts on BIG-IP platforms with more than 24 CPU cores

Known Issue

The ping_access_agent process continually restarts on BIG-IP platforms with more than 24 CPU cores.

This issue occurs when all of the following conditions are met:

  • BIG-IP APM is licensed and provisioned on the BIG-IP system.
  • The BIG-IP platform has more than 24 CPU cores or BIG-IP Virtual Edition (VE) is running on a platform with more than 24 CPU cores.

Impact

The ping_access_agent process restarts continually and PingAccess integration functionality in the BIG-IP APM system is unavailable.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The ping_access_agent process restarts continually after upgrading to BIG-IP APM 13.0.0.
  • PingAccess integration with the BIG-IP APM system fails for user requests.

Workaround

To work around this issue, you can modify the ping_access_agent file and restart the process. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure requires restarting the ping_access_agent process.

  1. Log in to the BIG-IP APM Advanced Shell (bash).
  2. Create a backup of the ping_access_agent file by typing the following command:

    cp -a /etc/bigstart/scripts/ping_access_agent /etc/bigstart/scripts/ping_access_agent_K29141414

  3. Stop the ping_access_agent process by typing the following command:

    tmsh stop /sys service ping_access_agent

  4. Using a text editor, open the /etc/bigstart/scripts/ping_access_agent file for editing.
  5. Locate the following line of code in the file:

    cpu_count=$(get_number_cpu)

    Replace the line with the following:

    tmm_count=$(get_tmm_count)

  6. Locate the following line of code in the file:

    exec /usr/sbin/${service} -n ${cpu_count}

    Replace the line with the following:

    exec /usr/sbin/${service} -n ${tmm_count}

  7. Save the changes and exit the text editor.
  8. Restart the ping_access_agent process by typing the following command:

    tmsh start /sys service ping_access_agent
