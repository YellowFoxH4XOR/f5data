K000139367: How to check if BIG-IP is using SSL Client authentication

Type
Support Solution
Published
2024-04-24
Updated
2024-06-05
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000139367

Description

You want to check if your device is using SSL Client Authentication however it would be tedious to check each SSL Profiles due to some environment having huge configurations.

Environment

  • LTM
  • SSL Profile - Client Authentication

Cause

BIG-IP has reported that there is a vulnerability where the affected configuration object is SSL Profile (clientside or serverside) that uses Client Authentication.

Recommended Actions

  1. Login to F5 CLI.
  2. To check if there are any SSL Profiles that uses Client authentication, enter commands below.
    bash
    tmsh list ltm profile | grep -B 15 -E 'peer-cert-mode'

  3. To check if the SSL Profiles that have authentication is associated in any virtual servers, enter commands below.
    bash
    tmsh list ltm virtual | grep -B 15 -E '<clientssl profile name>|<serverssl profile name>'

Below is an example of a configuration with Client Authentication option enabled.

config # tmsh list ltm profile | grep -B 15 -E 'peer-cert-mode'

ltm profile client-ssl clientssl-auth {
    app-service none
    ca-file default.crt
    cert-key-chain {
        default {
            cert default.crt
            key default.key
        }
    }
    client-cert-ca default.crt
    defaults-from clientssl
    inherit-ca-certkeychain true
    inherit-certkeychain true
    peer-cert-mode require          <<<<<<<<<<<---------------!!!!!!!!!!
}
ltm profile server-ssl serverssl-auth {
    app-service none
    ca-file default.crt
    defaults-from serverssl
    peer-cert-mode require          <<<<<<<<<<<---------------!!!!!!!!!!

 

To check if it is attached to any virtual servers.

config # tmsh list ltm virtual | grep -B 15 -E 'clientssl-auth|serverssl-auth'

ltm virtual vs-clientsslauth {
    destination 10.10.10.10:https
    ip-protocol tcp
    mask 255.255.255.255
