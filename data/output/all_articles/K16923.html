Known Issue

The Thales fipskey.nethsm command does not support the -m module option when generating Secure Sockets Layer (SSL) keys from the BIG-IP system.

Note: The -m (or --module=MODULE) option allows more than one netHSM to be targeted for SSL key generation.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration uses Thales netHSM to protect SSL keys.
  • You attempt to generate an SSL key on a second Thales netHSM by using the fipskey.nethsm command and the -m (or module) option.

Impact

SSL keys are not generated on a second Thales netHSM.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When running the Thales fipskey.nethsm command, you can only target the first Thales netHSM for SSL key generation.
