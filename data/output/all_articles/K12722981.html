K12722981: Bad Request. This combination of host and port requires TLS.

Type
Support Solution
Published
2023-05-25
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K12722981

Description

Clients sending requests to the BIG-IP receive the an error in response.

  • This can effect some, or all, requests
  • These requests fail
Example: Bad Request. This combination of host and port requires TLS.

Environment

  • Virtual server processing HTTP content
  • Pool members configured to process HTTPS content

Cause

These requests are likely receiving this error due to a misconfiguration of the virtual server or the pool members.  This can happen in a number of ways:

  1. The virtual server is configured to handle unencrypted traffic and the pool has members configured to handle encrypted traffic 
  2. The virtual server is configured to handle encrypted traffic and has a client-ssl profile but no server-ssl profile

Recommended Actions

To correct this error you will need to choose one of the options below.

  • Modify the pool members to accept unencrypted traffic
or
  • Add a server-ssl profile

Additional Information

In short this error is seen when a plain-text request is sent to a TLS/SSL endpoint.
