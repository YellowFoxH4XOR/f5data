Note: By default in BIG-IP version 9.4.x, the members of a high availability pair use their primary connection mirror addresses for ConfigSync operations.

If you have set up a BIG-IP high availability pair, but you have not configured a primary connection mirror address or a custom ConfigSync peer address, the ConfigSync operation will fail. However, ConfigSync tasks executed in this context will not produce a clear error message, and the ConfigSync operation may appear to have completed.

For example, the following ConfigSync output was taken on a BIG-IP system configured without an address:

Synchronizing Master Keys...Cannot fetch unit certificate from 255.255.255.255

Saving active configuration...
Configsync Mode: Push
Transferring UCS to peer...
Installing UCS on peer...
Obtaining results of remote configuration installation...
Saving active configuration...
Current configuration backed up to /var/local/ucs/cs_backup.ucs.
Product : BIG-IP
Version : 9.4.8
Hostname: bigip.askf5.com
Installing full configuration on host bigip.askf5.com
Installing...
Reloading configuration... It may take a few minutes...
Reading configuration from /defaults/config_base.conf.
Reading configuration from /config/bigip_base.conf.
Reading configuration from /config/bigip_sys.conf.
Reading configuration from /usr/bin/monitors/builtins/base_monitors.conf.
Reading configuration from /config/profile_base.conf.
Reading configuration from /config/daemon.conf.
Reading configuration from /config/bigip.conf.
Reading configuration from /config/bigip_local.conf.
Loading the configuration ...

The ConfigSync operation may appear to have completed successfully, except for the following ambiguous error message:

Synchronizing Master Keys...Cannot fetch unit certificate from 255.255.255.255

Although the message is unclear, it indicates that the ConfigSync operation failed.

To prevent this issue, ensure that you configure at least one pair of connection mirror addresses when setting up a BIG-IP high availability pair.

Note: For more information, refer to the Configuring High Availability section of the BIG-IP Network and System Management Guide.

Note: Beginning in BIG-IP version 10.0.0, if you attempt to synchronize the configuration in the same context, the system returns a more accurate error message:

01110034:3: This system needs to be a redundant pair and have a peer address specification.
