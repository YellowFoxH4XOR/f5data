Known Issue

This is the result of a known issue. On some SNMP management stations, the acopiasmi.my MIB file may fail to compile. An error message that appears similar to the following example will report on the management system:

Syntax error, needed BITS from: SNMPv2-SMI, at line 11, while compiling acopiasmi.my

This issue occurs because the acopiasmi.my MIB file incorrectly contains an IMPORTS statement using a BITS construct.

Note: RFC2578 indicates IMPORTS statements should not include a BITS construct.

F5 Product Development tracked this issue as ARX ID 35527 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX release notes.
