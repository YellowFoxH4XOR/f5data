Known Issue

SSL negotiation may log erroneous critical errors.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP virtual server is configured with an SSL profile cipher list that includes Elliptic Curve Diffie-Hellman (ECDH) ciphers.
  • An invalid value is sent to the virtual server during an ECDH key exchange.

Impact

Critical errors are erroneously logged.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system logs messages to the /var/log/ltm file that appear similar to the following example:

    crit tmm2[10771]: 01010025:2: Device error: sw_crypto Couldn't get ECDH secret key x coordinate. OpenSSL error:100E806A:elliptic curve routines:ec_GFp_nistp256_point_get_affine_coordinates:point at infinity
    crit tmm5[10772]: 01010025:2: Device error: sw_crypto Couldn't get ECDH other public value. OpenSSL error:1006706B:elliptic curve routines:ec_GFp_simple_oct2point:point is not on curve
