Description

Not every BIG-IP software release is explicitly listed in K9476: The F5 hardware/software compatibility matrix for every model. This article provides a process to determine if a specific software release is supported on a specific BIG-IP hardware product if it is not listed under K9476.

Environment

  • Software Release
  • End of Software Support (EoSS)
  • End of New Software Support (EoNSS)

Cause

As described in K4309: F5 hardware product lifecycle support policy, when a hardware product goes End of New Software Support (EoNSS) it will no longer have new software versions (Major and Minor versions) tested on it and subsequent software versions will not be supported on it. Consequently a software release will only be supported on a hardware product if the release's Major and Minor version was published before the hardware product's EoNSS date

When a hardware product goes End of Software Support (EoSS) it will no longer have new Maintenance or Point releases tested on it. Future maintenance or point releases are not supported and no new bug fixes or security updates will be introduced for this hardware product.

Recommended Actions

A multi-step process is needed to determine the support for a specific software/hardware combination utilizing existing, authoritative solution articles as seen below.

  1. Determine the Major and Minor software version in question (Major, Minor, and Maintenance). For example 12.1.3.4 has a Major version of 12 and a Minor version of 1 and a Maintenance release of 3.  The point release of 4 doesn't matter for this calculation.
  2. Determine the model of the specific hardware product. See: K13144: Determining the BIG-IP model and platform type (11.x - 17.x)
  3. Locate the row(s) corresponding to the full software version in K9412: The BIG-IP release matrix and then determine if the hardware product in question is listed. 

If the hardware product is listed in any row then the software/hardware combination has been tested and supported. Any rows matching the desired Maintenance release have been tested and are supported, any row matching just the Major and Minor release indicate the desired Maintenance release has not been tested and is not supported. If there are no rows matching the Major and Minor release then the software has not been tested, is not supported and may even fail to install on the hardware product.

Additional Information

Alternatively, support for a specific release can be determined manually without using the Supported hardware products column from K9412: The BIG-IP release matrix. For example if a new release or hardware product is not currently present in the article.

  1. Determine the software version in question (Major, Minor, and Maintenance). For example 12.1.3.4 which has a Major version of 12, a Minor version of 1, and a Maintenance release of 3. The Point release of 4 does not apply in this calculation.
  2. Determine the model of the specific platform. See: K13144: Determining the BIG-IP model and platform type (11.x - 17.x) 
  3. Determine the EoNSS and EoSS dates for the specific hardware product. See: K4309: F5 hardware product lifecycle support policy
  4. Determine the release date of the software version by reviewing the Release date column in K9412: The BIG-IP release matrix. This date is also included next to the download link on https://downloads.f5.com.

If the publish date for the software version occurred before the EoNSS then the software has been tested on the hardware product and is supported on it. If the software was published after the EoNSS and before the EoSS, only new Maintenance versions, not new Major/Minor versions have been tested on it. If the software version was published after the EoSS date, then no further testing has been performed and the software is not supported on that hardware product.

Example:  We have a 5250v and want to upgrade to version 15.

As per K4309, the 5250v went End of New Software Support (EoNSS) on 01-Apr-2020 and End of Software Support (EoSS) on 01-Apr-2021.

  • 15.1.0 was released on 11-Dec-2019.  It is fully supported on the 5250v.  15.1.0.3 was released on 05-May-2020.  Because it is a point release of a supported version, it is supported.  Hotfixes built against 15.1.0.3 will be provided until 01-Apr-2021 after which no further hotfixes, security updates, or consulting services will be offered.  Even though 15.1.x has new software development until 31-Dec-2024, because the hardware product is no longer under software support, no further hotfixes will be provided.  
  • 15.1.1 was released 15-Oct-2020.  It is fully supported on the 5250v, and any point releases under 15.1.1 will be supported.
  • 15.1.2, was released on 18-Nov-2020, after the End of New Software Support (EoNSS), but before End of Software Support (EoSS).  It is supported on the 5250v, and any point releases under 15.1.2 will be supported. 
  • 15.1.3, however, was released 22-Apr-2021, just after the End of Software Support (EoSS). It is not supported on the 5250v.

So in our example, we could potentially upgrade to the latest point release on 15.1.0, 15.1.1, or 15.1.2, but we could not upgrade to 15.1.3 and expect it to be supported.
