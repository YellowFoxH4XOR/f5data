Description

/var/log/ltm logs similar to below error message

err statsd[<PID>]: 011b0600:3: Error ''/var/rrd/endpisession' is too small (should be 6487576 bytes)' during rrd_update for rrd file '/var/rrd/endpisession'

Also qkview generation may fail.
 

Environment

  • BIG-IP
  • v11.5 and later

Cause

Bug ID 883049
 

Recommended Actions

To apply the workaround written in Bug ID 883049.
No impact for processing traffic is expected for the workaround, however recommended to do it in in maintenance window.
 

Additional Information

When this issue is hitting your unit, 

  • Qkview generation may fail
  • Command "tmsh show sys memory" may not complete.
