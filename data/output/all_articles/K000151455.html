Description

This article provides a method to monitor the expiration status of a device trust certificate (such as dtca.crt) on a BIG-IP system. The solution uses a shell script to check the certificate's expiry date, calculate the number of days remaining, and log messages to the system log (LTM log) with different severity levels depending on the certificate status.

Environment

  • BIG-IP system (any platform or version)
  • Device trust certificate (e.g., dtca.crt)
  • Access to the BIG-IP shell (bash)
  • Ability to schedule scripts via cron

Solution

Shell Script for Certificate Expiry Monitoring

Below is a sample shell script that checks the expiry date of a specified certificate file and logs the result:

#!/bin/bash

 
CERT_PATH="/config/ssl/ssl.crt/dtca.crt"

 
if [ ! -f "$CERT_PATH" ]; then

  echo "Certificate not found: $CERT_PATH"

  exit 1

fi


EXPIRY_DATE=$(openssl x509 -enddate -noout -in "$CERT_PATH" | cut -d= -f2)

EXPIRY_SECONDS=$(date -d "$EXPIRY_DATE" +%s)

NOW_SECONDS=$(date +%s)

DAYS_LEFT=$(( (EXPIRY_SECONDS - NOW_SECONDS) / 86400 ))

 
if [ "$DAYS_LEFT" -lt 0 ]; then

  echo "Certificate expired on $EXPIRY_DATE"

  logger -p local0.err "Device Trust certificate has expired (on $EXPIRY_DATE)"

elif [ "$DAYS_LEFT" -le 30 ]; then

  echo "Certificate is running in $DAYS_LEFT days from (on $EXPIRY_DATE)"

  logger -p local0.warning "Device Trust Certificate expires in $DAYS_LEFT days from (on $EXPIRY_DATE)"

else

  echo "Certificate is valid until $EXPIRY_DATE ($DAYS_LEFT Days remaining)"

  logger -p local0.notice "Device Trust Certificate is valid until $EXPIRY_DATE ($DAYS_LEFT Days remaining)"

fi

How It Works

  • The script sets the path to the certificate file.
  • It checks if the certificate file exists. If not, it outputs an error and exits.
  • It extracts the expiry date from the certificate using openssl.
  • It calculates the number of days left until the certificate expires.
  • Depending on the result:
    • If the certificate is expired, it logs an error.
    • If the certificate will expire within 30 days, it logs a warning.
    • If the certificate is valid for more than 30 days, it logs a notice.

Example LTM Log Output

May 19 10:17:17 localhost [26282]: Device Trust certificate has expired (on May 16 10:00:04 2025 GMT)

Scheduling the Script

You can schedule this script to run at your desired interval (e.g., daily or weekly) using cron. For example, to run the script every day at midnight, add the following line to your crontab:

0 0 * * * /path/to/your/script.sh

Recommendations

  • Regularly monitor the LTM logs for warnings or errors about certificate expiry.
  • Adjust the script and scheduling as needed for your operational requirements.

Additional Notes

  • The script can be adapted to monitor other certificates by changing the CERT_PATH variable.
  • Ensure the script has execute permissions and is owned by an appropriate user.
  • Logging to local0 allows easy filtering and alerting based on certificate status.

This approach provides proactive monitoring and helps prevent unexpected issues due to expired device trust certificates on BIG-IP systems.
