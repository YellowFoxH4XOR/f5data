Topic

You should consider using this procedure under the following conditions:

  • Your BIG-IP APM system is configured to authenticate View Clients for View Connection Server load-balancing, or to present a View Desktop on a Webtop.
  • Your VMware Horizon View configuration uses custom ports numbers for HTTP/HTTPS and PCoIP traffic. 

Description

VMware Horizon View configurations, by default, use TCP port 443 for HTTPS traffic, and UDP port 4172 for PCoIP traffic. When you configure VMware Horizon View to process traffic on custom ports numbers, you need to configure consequent modifications on the BIG-IP APM system.  

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your BIG-IP APM system must be configured to process VMware View Horizon on default ports.

Procedures

To configure the BIG-IP APM system for non-default ports on VMware Horizon View, perform the following procedures:

  • Configuring an HTTPS virtual server on a desired non-default port
  • Configuring a UDP virtual server on a desired non-default port
  • Modifying the access policy on the HTTPS virtual server with Variable Assign

Configuring an HTTPS virtual server on a desired non-default port

This is the virtual server that users will specify in the View Client. The virtual server handles View Client access and handles XML protocol data.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. On the Main tab, click Local Traffic > Virtual Servers.
  2. Click Create.
  3. In the Name box, type a unique name for the virtual server.
  4. In the Destination Address box, type the IP address for a host virtual server.

    This field accepts an address in CIDR format (IP address/prefix). However, when you type the complete IP address for a host, you do not need to type a prefix after the address. Use this same IP address for the virtual servers you create to handle PCoIP and UDP traffic.

  5. In the Service Port box, type the desired non-default port for HTTPS traffic.
  6. From the HTTP Profile list, select http.
  7. For the SSL Profile (Client) setting, in the Available box, select a profile name, and using the Move button, move the name to the Selected box.
  8. For the SSL Profile (Server) setting, select pcoip-default-serverssl.
  9. From the Source Address Translation list, select Auto Map.
  10. In the Access Policy area, from the Access Profile list, select the access profile you configured for VMware Horizon View.
  11. From the Connectivity Profile list, select the connectivity profile.
  12. From the VDI Profile list, select a VDI profile. You can select the default profile, vdi.
  13. Locate the Resources area of the screen, and from the Default Persistence Profile list, select one of these profiles:

    cookie - This is the default cookie persistence profile. Cookie persistence is recommended.

    source_addr - This is the default source address translation persistence profile. Select this profile only when the cookie persistence type is not available.

  14. Click Finished.

Configuring a UDP virtual server on a desired non-default port

This virtual server handles PCoIP traffic for VMware View Clients.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. On the Main tab, click Local Traffic > Virtual Servers.
  2. Click Create.
  3. In the Name box, type a unique name for the virtual server.
  4. In the Destination Address box, type the same IP address as the one for the View Client authentication virtual server.
  5. In the Service Port box, type the desired non-default port for PCoIP traffic.
  6. From the Protocol list, select UDP.
  7. From the Source Address Translation list, select Auto Map.
  8. In the Access Policy area, from the VDI Profile list, select a VDI profile.
  9. Select the default profile, vdi.
  10. Click Finished.

Modifying the access policy on the HTTPS virtual server with Variable Assign

In the access policy, you can add a Variable Assign item to use custom ports.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. On the Main tab, click Access > Profiles / Policies.
  2. In the Access Policy column, click the Edit link for the access profile you configured for VMware Horizon View.

    The virtual policy editor opens the access policy in a separate screen.

  3. To add an item to the policy, click the (+) icon to the right of the VMware View Logon Page.
  4. Select Assignment tab.
  5. Select Variable Assign.
  6. Click Add Item.
  7. Click the Variable Assign agent.
  8. Click the change link for rule one.
  9. Select Custom Variable.
  10. Enter the following text in the Custom Variable box:

    view.transport_port

  11. In the Custom Expression box, enter the value of the desired non-default transport port.

    For example if the non-default port is 4444, type the following text:

    expr {"4444"}

  12. Click Finished.
  13. Click Add new entry.
  14. Click the change link for rule two.
  15. Select Custom Variable.
  16. Enter the following text in the Custom Variable box:

    view.signal_port

  17. In the Custom Expression box, enter the value of the desired non-default signal port.

    For example, if the non-default port is 2222, type the following text:

    expr {"2222"}

  18. Click Finished.
  19. Click Save.
  20. In the upper left corner of the visual policy editor, click Apply Access Policy.
