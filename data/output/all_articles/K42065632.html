Known Issue

Under rare circumstances, the chmand process may receive an out-of-sync lights-out processor (LOP) response from a management network interface status query. A late or timed-out LOP response from a different, earlier query may cause the mismatched response.

This issue occurs when the following condition is met:

  • You are running one of the following BIG-IP platforms:
    • BIG-IP 2000 series appliances
    • BIG-IP 4000 series appliances
    • BIG-IP 5000 series appliances
    • BIG-IP 7000 series appliances
    • BIG-IP 10000 series appliances
    • BIG-IP 12000 series appliances
    • VIPRION 2100 blades
    • VIPRION 2150 blades
    • VIPRION 2250 blades

Impact

The system erroneously marks down the management network interface on the affected blade or appliance, making temporarily unavailable the services on the BIG-IP system that use the management network interface (for example, the Configuration utility). Additionally, a failover event may occur if you configure the BIG-IP system with only the management network interface in its high availability (HA) configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • While your BIG-IP system attempts to read the management network interface registers, you notice warning messages in the /var/log/ltm file that appear similar to the following example:

    warning chmand[7018]: 012a0004:4: getLopReg exception: No LopCmd reply match found for action=0x1 obj_id=0x67 subobj=0x0 slot=0xff.
    err chmand[7018]: 012a0003:3: GET_MEDIA failure (status=0xffffffff) page=0x%1 reg=0x0  : File mgmtif/BourneMgmtIfSvc.cpp Line 357.
    warning chmand[7018]: 012a0004:4: getLopReg: lop data size does not match, u16DataLen=0x5 expected=0x7.
    warning chmand[7018]: 012a0004:4: getLopReg: lop data size does not match, u16DataLen=0x7 expected=0x5.

  • Additionally, the management network interface may flap and your BIG-IP system shows messages in the /var/log/ltm file that appear similar to the following example:

    Dec  23 00:31:12 slot1/VIPRION notice chmand[7018]: 012a0005:5: Interface: 1/mgmt is DOWN
    Dec  23 00:31:24 slot1/VIPRION notice chmand[7018]: 012a0005:5: Interface: 1/mgmt is UP
