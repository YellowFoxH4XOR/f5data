Topic

The End User Diagnostics (EUD) software is a set of diagnostic tests that provide reports about various components in the hardware unit. In BIG-IP versions prior to 13.0.0, the EUD software is pre-installed on each BIG-IP system.

Description

There are different EUD packages depending on the platform:

  • Field Testing F5 Hardware: iSeries Platforms
  • Field Testing BIG-IP and BIG-IQ Hardware: BIG-IP 2000, 4000, 5000, 7000, 10000, 12000, and BIG-IQ 7000
  • Field Testing BIG-IP Hardware: 800, 1600, 3600, 3900, 6900, 8900, 8950, 11000, 11050, EM4000
  • Field Testing BIG-IP Hardware: VIPRION B2000 Series Blades
  • Field Testing BIG-IP Hardware: VIPRION B4100/B4200 Blades
  • Field Testing BIG-IP Hardware: VIPRION B4300/B4400 Blades 

When troubleshooting a potential hardware problem, F5 recommends that you download and install the latest version of the EUD for your platform before you run system diagnostics. F5 recommends that you install the latest version of EUD for the following reasons:

  • The EUD software is updated regularly for the relevant platform types. The latest EUD versions contain fixes and up-to-date changes for supported hardware platforms.
  • Older versions of the EUD may not contain updates that pertain to platform changes, such as those for RoHS compliance systems.
  • Failure to use the latest released version of the EUD may result in false negative or false positive EUD reports. EUD reports containing false information or inaccuracies can delay the resolution of any potential underlying hardware problem.
Important: Before you run these tests, you should disconnect all network cables from the system. Any cables connected to the system during the tests could cause false-positive results.

Note: For information about the EUD software, such as supported platforms, downloading and running the EUD, and EUD fixes and enhancements, refer to the End User Diagnostics release notes.

Note: For instructions about checking the EUD version on your BIG-IP system, refer to K8002: Determining the End-User Diagnostics version.

Note: In BIG-IP 13.0.0 and later, F5 no longer includes the EUD images in the base .iso image file. You must either install the latest EUD package from a BIG-IP-x.y.z.n.n.nnn-RECOVERY.iso image or download the EUD image of your specific platform from the Platform / EUD product page of the F5 Downloads site. For more information, refer to K03203114: Multiple BIG-IP iso images are available (13.x and later).
