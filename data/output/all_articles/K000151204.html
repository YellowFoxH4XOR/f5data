Description

Would like to Review the ASM's Custom Response Headers using the REST API.

 

Environment

  • ASM
  • Custom Response Headers
  • REST API

Cause

None

 

Recommended Actions

Run the following API call, replacing the username and password with the correct details.

export My_Token=$(curl -ks https://localhost/mgmt/shared/authn/login -d'{"username":"admin","password":"admin"}' |jq '.token.token'|awk -F'"' '{print$2}')
curl -sk -H "X-F5-Auth-Token: $My_Token" https://localhost/mgmt/tm/asm/policies?\$select=name,id|jq .|grep '"id":'|awk -F'"' '{print$4}' > /var/tmp/policy_hashes


This creates a list of the Policy Hashes in /var/tmp/policy_hashes

We then use the following script to create a file /var/tmp/policy_headers

for i in `cat /var/tmp/policy_hashes`; do \
curl -sk -H "X-F5-Auth-Token: $My_Token" https://localhost/mgmt/tm/asm/policies/$i | jq . |grep '"name":' ;\
curl -sk -H "X-F5-Auth-Token: $My_Token" https://localhost/mgmt/tm/asm/policies/$i/response-pages?\$select=responseHeader | jq .|grep '"responseHeader"' ;\
 done > /var/tmp/policy_headers

This may take some time if you have a lot of ASM Policies.

 

It gives you a list of Policy names followed by any Custom Response Headers.

If a Policy only has default Response Headers, then nothing is listed, or if a Policy has multiple Custom Response Headers, each Header will be listed.
