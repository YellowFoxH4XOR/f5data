K14222230: Pools created outside the Common partition cannot be modified within the Configuration utility HA Groups page

Known Issue

You cannot modify, within the Configuration utility HA Groups page, pools that you created outside the Common partition.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system as a high availability (HA) system.
  • You have created the pool outside the Common partition.
  • You attempt to modify the pools by navigating to the edit page at System > High Availability > HA Groups in the Configuration utility.

Impact

The Edit button within the edit page at  System > High Availability > HA Groups does not work.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the HA Groups edit page, you can modify or delete only the Pools that you created in the Common partition.

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to edit or remove pools.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
