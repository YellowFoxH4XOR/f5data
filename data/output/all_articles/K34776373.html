Description
Velos controller does not have access to outside, and need to upload latest software iso image for partition or controller.

Environment

  • Velos
  • F5OS-C
  • upload software
  • CLI
  • scp
     

Cause

n/a


Recommended Actions

Important: F5 strongly discourages the use of the root user account to perform image uploads to the VELOS chassis. F5 strongly recommends to use either the VELOS chassis webUI or the REST API to upload images to the VELOS chassis. For information about using REST API to upload images to the VELOS chassis, refer to K000139146: Upload a file to the VELOS or rSeries system using REST API.

You will need to upload controller/partition iso to ACTIVE controller with root or root equivalent account (admin account can not be used).
Recommend to use Floating Controller IP.

From your linux system, specify account root or root equivalent account you have, and location is /var/import/staging:

e.g

scp <iso_filename> root@<Floating_IP_of_Controller>:/var/import/staging
NOTE: if you are not in the directory where iso file stored, then specify full directory in <iso_filename>
IMPORTANT: While you are uploading and system is replicating the iso image from Active to Standby, do not failover between Controller.
 

Additional Information

After upload is finished, check the image status with F5OS command:

show image 

BOTH controllers need to have ready status for controller/partition before you install it. Replecation from Active Controller to Standby Controller might take time.
