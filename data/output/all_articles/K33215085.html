Description

SNMP polling doesn't work from remote devices after upgrade to 15.1.1
Local snmpwalk working fine. Configuration contains v2-traps section under snmp:

tmsh list sys snmp

...
v2-traps {
        test_traps {
            community SNMPTRAPLAB
            host 10.0.0.100
        }
...

Environment

  • BIG-IP Upgrade to version 15.1.1
  • SNMP polling configured

Cause

ID969737

Recommended Actions

Move v2-traps section to traps by manually editing config
  1. Open /config/bigip_base.conf in text editor ( for example VI)
  2. Move snmp traps config from section v2-traps to traps
    ...
    v2-traps {
            test_traps {
                community SNMPTRAPLAB
                host 10.0.0.100
            }
    ...

    to

    traps {
            test_traps {
                community SNMPTRAPLAB
                host 10.0.0.100
            }
    ...
    NOTE:If section traps already exists for SNMPv3, please move config from v2-traps to traps.
  3. Perform 'load sys config'
    NOTE: load sys config can cause traffic interruption. Recommendation is to start doing this on standby device then do failover  and perform on another unit.
