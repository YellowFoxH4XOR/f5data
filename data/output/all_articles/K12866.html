Issue

The BIG-IP system uses an IP geolocation database to source data about the origin of an IP address. F5 releases the updates to the Edge and Pulse databases in the GeoLocationUpdates (_Edge or _Pulse) container on the MyF5 Downloads site.

Note: F5 does not support IP geolocation database that is not released by F5.

Note: The IP geolocation database uses the ISO 3166-2 standard for countries and regions.

After updating the IP geolocation database files, you may notice IP address location differences reported by the BIG-IP system. Minor differences observed in the database are to be expected, and are likely a result of database improvements made by the geolocation database vendor. However, if you observe an obvious inaccuracy in the database, you should verify that the database files are up to date before reporting the inaccuracy.

For example, if the BIG-IP system reports an IP address with a geographical location of the United Kingdom when it should be geographically located in the United States, you can perform the following steps to troubleshoot the inaccuracy:

  • Determining if the IP geolocation database is up-to-date on the BIG-IP system
  • Updating the IP geolocation database
  • Reporting database inaccuracies

Note: The BIG-IP system may fail to report the geographical location of an IP address when querying the IP geolocation database with a time zone that has a non-whole number offset. For additional information, refer to K12758: The BIG-IP system fails to parse a time zone containing an offset that is not a whole number when querying the IP geolocation database

Determining if the IP geolocation database is up-to-date on the BIG-IP system

You can determine if the IP geolocation database is up-to-date on the BIG-IP system by comparing the date of the data files with the file name of the updates on the MyF5 Downloads site. To do so, perform the following procedure:

  1. Log in to the command line.
  2. To list the date of the IP geolocation database files, use the following command syntax:

    ls -ltr <path/to/files>

    For example:

    ls -ltr /shared/GeoIP/v2

    The output in the following example shows that the IP geolocation database on the BIG-IP system has data files that are dated 11 May 2018:

    -rw-r--r--. 1 root root  29177090 2018-05-11 08:34 F5GeoIPRegion2v2.dat
    -rw-r--r--. 1 root root   2517670 2018-05-11 08:34 F5GeoIPISPv2.dat
    -rw-r--r--. 1 root root 211866464 2018-05-11 08:34 F5GeoIPOrgv2.dat
    lrwxrwxrwx. 1 root root        33 2018-05-15 09:54 F5GeoIPOrg.dat -> /shared/GeoIP/v2/F5GeoIPOrgv2.dat
    lrwxrwxrwx. 1 root root        33 2018-05-15 09:55 F5GeoIPISP.dat -> /shared/GeoIP/v2/F5GeoIPISPv2.dat
    lrwxrwxrwx. 1 root root        37 2018-05-15 09:56 F5GeoIPv6.dat -> /shared/GeoIP/v2/F5GeoIPRegion2v2.dat
    lrwxrwxrwx. 1 root root        37 2018-05-15 09:56 F5GeoIP.dat -> /shared/GeoIP/v2/F5GeoIPRegion2v2.dat

    Note: In BIG-IP 12.1.0 and later, the GeoIP files are located in the /shared/GeoIP/v2/ or the /usr/share/GeoIP/v2 folder. In BIG-IP 12.0.0 and earlier, the GeoIP files are located in the /shared/GeoIP/ or the /usr/share/GeoIP folder. For more information about the IP geolocation database locations, refer to K15042: Looking up IP geolocation data using the geoip_lookup command.

  3. Determine the latest update for the IP geolocation database by locating the update file in the GeoLocationUpdates container on the MyF5 Downloads site.

    For example, the filename ip-geolocation-v2-2.0.0-20180611.322.0.zip provides the IP geolocation database with files dated 11 June 2018.

  4. Compare the dates from steps 2 and 3 to determine if the IP geolocation database is up-to-date on the BIG-IP system.

    For example, using the examples in steps 2 and 3, the IP geolocation database on the BIG-IP system contains data that is current as of 11 May 2018, while the IP geolocation database on the MyF5 Downloads site contains data that is current as of 11 June 2018.

Updating the IP geolocation database

You can install the update for IP geolocation database by following the steps in K11176: Downloading and installing updates to the IP geolocation database.

Note: F5 releases updates for the IP geolocation database every week (typically on Wednesday Pacific Time zone). You may want to check MyF5 downloads site for the latest release.

Reporting database inaccuracies

If the database is still inaccurate after installing the latest geolocation database update (either Edge or Pulse) and you have specific questions about the content of the geolocation data, contact F5 Support or Digital Element directly using the following email address:

IP-Data@digitalelement.com
