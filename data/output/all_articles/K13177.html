Known Issue

If a client abandons an active connection with the BIG-IP system at the same time that the BIG-IP system is attempting to send a Selective Acknowledgement (SACK) packet to the client, the BIG-IP system may continually try to resend the same SACK packet.

This issue occurs when all of the following conditions are met:

  • The active TCP connection between the client and the BIG-IP system is abandoned.
  • The BIG-IP system tries to send a SACK packet as the session is abandoned.
  • The BIG-IP system is running version 10.2.0 with HF2 or later, or version 10.2.1 with no hotfix.
  • SACK has been enabled on the TCP profile.

    Note: SACK is enabled by default.

Impact

Performance may degrade over time, and the system may eventually become unresponsive due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Due to excessive memory allocation that may lead to swap pressure, Traffic Management Microkernel (TMM) may miss answering watchdog polls and cause a restart. The system may register log files that appear similar to the following example to the /var/log/ltm log file, indicating a TMM process heartbeat time-out:

    01140029:5: HA daemon_heartbeat tmm fails action is failover and restart

  • The system may restart or fail over due to either a watchdog time-out, or a memory leak, impacting other system daemons.
  • The console, SCCP log file or AOM log file may display an error that appears similar to the following example:

    ERROR: Host processor watchdog timer has expired

Workaround

To work around this issue, you can disable SACK in the TCP profile. To do so, perform the following procedure:

Impact of workaround: Disabling SACK may negatively impact the BIG-IP system's performance by increasing processing usage and the number of packets sent across the network.

  1. From the Configuration utility, click Local Traffic.
  2. Click Profiles, click Protocol, and then click TCP.
  3. Click the TCP profile link.
  4. Clear the Selective ACKs check box.
  5. Click the Update button.
