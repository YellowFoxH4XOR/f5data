Description

  • A bootable USB drive is left in an Appliance.
  • You wish to reboot to TMOS.
     

Environment

  • You do not have physical access to the Appliance.
  • You have AOM access.
     

Cause
The default boot order prioritizes USB drives over the internal media.
 

Recommended Actions

  • Use the AOM.
  • Reset the host    (R)
  • Switch to the host console (Q)
  • When the Bios message appears, press c. to enter the BIOS.
 
Note that unlike commodity hardware, there is no "press F11 for boot device"
 
 
The default boot device will be the USB device (specified by brand. "Cruzer" or "Sandisk"  etc)
  • Go to the “boot” menu in the BIOS.
  • Select BBS
  • Change the order so the internal device is highest priority
  • Use the menu option to "save config and exit". Do not press F4.
  • The device will boot to TMOS.
 
This change is not permanent. Follow up by removing the USB device.
