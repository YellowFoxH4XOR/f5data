Topic

The DNS-Lite module is added on BIG-IP LTM-licensed BIG-IP platforms.

Description

DNS-Lite module is available on BIG-IP 11.4.0 through 12.1.0 as a heavily rate-limited, non-licensed, and provisioned evaluation and testing of DNS and global server load balancing (GSLB) services at no charge.

The DNS-Lite module is added when all of the following conditions are met:

  • You license a BIG-IP LTM system after August 2013
  • You activate the BIG-IP LTM license on one of the following BIG-IP platforms:
    • VIPRION
    • Virtual Edition
    • 10000 series
    • 7000 series
    • 5000 series
    • 4000 series
    • 2000 series

After you activate the license, the bigip.license file will include a line that appears similar to the following example:

active module: GTM-DNS, RL, LO

Recommendations

For evaluation purposes, the DNS-Lite module provides non-production versions of the following services:

  • GSLB
  • DNS Express
  • Domain Name System Security Extensions (DNSSEC)

If the BIG-IP system is running 11.4.0 or later, you can provision the DNS-Lite features for evaluation purposes.

If the BIG-IP system is running 11.3.0 or earlier, the new module is added to the license file, but no new functionality is enabled.
