Known Issue

The BIG-IP system may return NSEC3 records with a different type bitmap field in queries for the same Domain Name System (DNS) name.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to sign DNS server responses using Domain Name System Security Extensions (DNSSEC).
  • The DNSSEC zone delegates authority to an unsigned subzone.

Impact

DNS lookups may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If the DNSSEC validator rejects the delegation, DNS lookups fail.
  • If debug DNSSEC logging is enabled, the system logs an error message that appears similar to the following example:

    got insecure response; parent indicates it should be secure
