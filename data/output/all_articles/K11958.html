Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator is designed to serve a stale object from the cache until the Stand-in Period has expired without reporting an error message. However, the BIG-IP WebAccelerator pvac process may dump core instead of serving an expired object from the cache when the following conditions are true:

  • A cached object configured in an Edge Side Include (ESI) has expired
  • The origin web server (OWS) is not able to serve a fresh version of the requested object
  • A Stand-in Period is configured for the object on the BIG-IP WebAccelerator system
  • The Stand-in Period has not expired

Note: The Stand-in Period cache setting dictates how long the BIG-IP WebAccelerator system will serve expired content from the cache after the content has expired but the OWS is not able to serve the requested object. For example, this may occur if the OWS goes down completely, or if a requested file is missing from the OWS file system, but the BIG-IP WebAccelerator system has already cached the requested file. The Stand-in Period is configured in the policy editor on the Lifetime tab of the Acceleration Rules screen.

When the system dumps a core, messages that appear similar to the following example are logged to the /var/log/wa/pvac.log file:

debug WA Debug ( 3693): [             TmPlugin.cxx:2584          error_on_esi ] ERROR for ESI! wa_context [0xf1c96a20]
debug WA Debug ( 3693): [            PvContext.cxx:596       PvCharStar_Debug ]

The BIG-IP WebAccelerator may also log messages that appear similar to the following example in the /var/log/wa/pvac.log file:

debug WA Debug (10422): [     PvContentRecord.cxx:3944        getContentType ] metaFile is  NULL!
debug WA Debug (10526): [     PvContentRecord.cxx:3944        getContentType ] metaFile is  NULL!
debug WA Debug (10526): [     PvContentRecord.cxx:3554         getChangeTime ] metaFile is  NULL!
debug WA Debug (10526): [     PvContentRecord.cxx:3605  getOWSLastModifiedTime ] metaFile is  NULL!

Note: In BIG-IP version 10.2.0 at default logging levels, the system may dump a core file without logging the additional metaFile is NULL! error messages.

Note: Similar error messages may be logged when the BIG-IP WebAccelerator system attempts to parse poorly constructed HTML code in OWS responses processed by  ESI.

F5 Networks Product Development is tracking this issue as ID 336691.
