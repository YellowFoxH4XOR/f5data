Known Issue

This is the result of a known issue. If you configure a Terminal Server favorite for access to a Microsoft Windows Terminal Server, and the master group screen resolution is set to Full Screen, FirePass displays the Terminal Server favorite inside the webtop window instead of launching it in full screen mode. Additionally, if users in that master group enter Ctrl-Alt-Break to manually switch to full screen mode, the Terminal Server favorite displays in the middle of the screen, with a screen resolution of 800x600, and a black border fills the remainder of the screen.

This issue occurs when the screen resolution on the client system is set to a higher resolution than 1600x1200.

Note: In FirePass versions 5.2 through 6.0.2, the master group screen resolution for Terminal Server favorites is configured in the Screen resolution section of the Application Access: Terminal Servers: Master Group Settings page. In FirePass version 5.0, the master group screen resolution for Terminal Server favorites is configured in the Screen resolution section of the Application Access: Terminal Servers page.

F5 Product Development tracked this issue as CR64881 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, this issue was fixed in cumulative hotfix HF-601-11 issued for FirePass version 6.0.1 and cumulative hotfix HF-602-6 issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can work around this issue by setting their screen resolution to 1600x1200, or a lower resolution setting.
