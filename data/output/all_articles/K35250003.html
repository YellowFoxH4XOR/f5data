Description
This article describes the configuration steps to have an HTTP AAA server using session variable.
Doing so, you have the capability to tell BigIP APM to select an HTTP AAA server, depending on various conditions.

Environment

  • HTTP AAA from BigIP APM;
  • Configuring multiple HTTP servers
  • Going through the AccessPolicy, a session variable eventually hosts the IP address or the FQDN of the HTTP server to connect to.

Recommended Actions

First, let's agree the session variable hosting the FQDN or the IP address of the HTTP AAA server is: session.custom.http.server;
And the HTTP servers do require a connection to the following resource: "http://<server>/dir1/login.html".
  1. Open the Configuration Utility
  2. For BigIP v11.x and v12.x: Navigate to Access Policy >> AAA servers >> HTTP
  3. For BigIP v13.x and onwards: Navigate to Access >> Authentication >> HTTP
  4. Click the HTTP AAA object name, to display its properties
  5. For "Start URI", put: "http://%{session.custom.http.server}/dir1"
  6. For "Form Action", put: "/login.html"
  7. Click "Update"
  8. Click "Apply Access Policy" on the top left, if prompted to do so.
