K01254335: Pool is not load-balancing correctly

Type
Support Solution
Published
2022-06-09
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.4
Source
https://my.f5.com/manage/s/article/K01254335

Description
OneConnect profile with source-mask set too high can cause uneven pool load-balancing in certain configurations

Environment

  • BIG-IP
  • Virtual server with the following profiles defined:
    • OneConnect profile with custom source-mask
    • Cookie persistence
    • TCP profile with high timeout value
  • Virtual Server pool with Least Connections defined as the LB method

Cause
OneConnect source-mask can match too many source IPs, causing uneven load balancing to pool members

Recommended Actions
Reduce the source-mask of the OneConnect profile to a lower value, such as /32

Additional Information
None
