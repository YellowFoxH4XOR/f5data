Description

./helper.sh configtls command is not updating the Controller's UI certificate with the following error:

./helper.sh configtls /tmp/cert/wc.corelb.xxxx.net.crt /tmp/cert/wc.corelb.xxxxx.net.key

Applying platform settings changes and restarting services. This can take up to 2 minutes.

2023-02-06T15:39:10.891Z    [INFO]     global-settings-ctrl-2.29.16  controller/reconcile.go:285   NGINX Controller update in progress, global settings controller suspended

 

Environment

  • NGINX Controller
  • reconcile disabled

Cause

The configtls command fails, because reconciliation has been disabled.

Recommended Actions

You can temporary disable reconciliation and re-enable it once the certificate has been updated.

  • Re-enable reconciliation

kubectl -n nginx-controller create configmap controller-updating --from-literal=SUSPEND_RECONCILE=false

  • Run the configtls command to update certificate

./helper.sh configtls /tmp/cert/wc.corelb.xxxx.net.crt /tmp/cert/wc.corelb.xxxxx.net.key

  • Disable reconciliation again

kubectl -n nginx-controller create configmap controller-updating --from-literal=SUSPEND_RECONCILE=true
