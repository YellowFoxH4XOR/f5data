It is possible to bypass the Deny list configured in the Accessibility Scope section of the Portal Access: Web Applications: Master Group Settings page using a URL with a decimal-encoded IP address.

When you log in to the FirePass Webtop, you can enter a URL into the Webtop Address Bar if the FirePass Administrator has not checked the Show administrator-defined favorites only box in the Access limitation section of the Portal Access: Web Applications: Master Group Settings page. By entering the URL in the Address Bar with a decimal-encoded IP address, you can bypass any IP address-based patterns in the the Deny list and access restricted web sites through Portal Access.

Additionally, FirePass encodes URLs accessed by users through Portal Access, as seen in the browser's Address Bar. By altering the encoded URL so that the URL uses a decimal-encoded IP address, a user can circumvent the Deny lists, regardless of whether the Show administrator-defined favorites only box is checked.

F5 Product Development tracked this issue as CR59558 and it was fixed in FirePass version 5.5.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, a hotfix has been issued for FirePass versions 5.5.0 and  5.5.1. Customers affected by this issue should contact F5 Technical Support to request the hotfix, referencing the CR number and the number of this Solution.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around the issue caused by the vulnerability described in this Security Advisory by using the Limit Web Applications Access to Intranet Favorites only feature under the Access limitation section of the Portal Access: Web Applications: Master Group Settings page to remove the Address bar on the FirePass Webtop. By checking the box, you are limited to the use of the Portal Access Favorites configured by the FirePass Administrator.

No workaround exists to prevent a user from entering a decimal-encoded IP address in URL in the browser Address bar.
