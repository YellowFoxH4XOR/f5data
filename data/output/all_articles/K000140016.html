K000140016: AS3 Declarations failing after BIG-IP upgrade

Type
Support Solution
Published
2024-06-14
Updated
2025-10-21
Applies to
  • BIG-IP
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.0, 8.3.X, 8.2.X, 8.3.0
  • BIG-IP LTM: 17.X.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000140016

Description

After upgrading the BIG-IP system, AS3 declarations fail when pushed from the BIG-IQ system. On the BIG-IQ console, you observe following error:

Failed to install AppSvcs on 2 devices: 1. (machineId 00000-0000-1111-2222-41521564): New endpoint mgmt/shared/appsvcs/info was not up in 60 seconds, 2. (machineId 00000-0000-1111-2222-41521564): New endpoint mgmt/shared/appsvcs/info was not up in 60 seconds

Environment

  • BIG-IQ
  • BIG-IP
  • AS3

Cause

None

Recommended Actions

There are two possible workarounds for the problem:

1)

a. Use SSH to log in to the target BIG-IP on which the AS3 application is deployed.

b. Type the command: bigstart restart restnoded

c. Close the SSH session.

 

2) Reinstall AS3 RPM package as below:

a) Download the latest RPM package from F5 Github 

b) Click iApps > Package Management LX

c) Delete the f5-appsvcs then press import select downloaded .rpm package from step a) and upload.
