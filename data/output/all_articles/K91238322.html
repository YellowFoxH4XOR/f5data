Description

Trend Micro Virus Buster Monthly Edition not detected by Endpoint Check.

Environment

  • Trend Micro Virus Buster Monthly Edition
  • EPSEC Build 892.0 or earlier

Cause

OPSWAT come to the conclusion that VirusBuster Monthly Edition is no longer supported in v3 so that v3v4 adapter will not recognize it.

Recommended Actions

Instead it is recognized as "Virus Buster Biz Edition" which is supported in epsec build 892.0 for OESIS SDK4(v14.1.0 or later)

Session Variable

session.check_software.last.av.item_1.id' set to '2956'
session.check_software.last.av.item_1.name' set to 'Trend Micro VirusBuster'
session.check_software.last.av.item_1.signature' set to '3014'
session.check_software.last.av.item_1.state' set to '1'
session.check_software.last.av.item_1.vendor_id' set to '148'
session.check_software.last.av.item_1.vendor_name' set to 'Trend Micro, Inc.'
session.check_software.last.av.item_1.version' set to '16.0'


OESIS v3v4 adapter will not recognize it, but can be recognized as "Virus Buster biz client" in epsec build 900 or later.

Session Variable

session.check_software.last.av.item_1.id' set to '167039'
session.check_software.last.av.item_1.name' set to 'Virus Buster biz client'
session.check_software.last.av.item_1.state' set to '1'
session.check_software.last.av.item_1.vendor_id' set to '167'
session.check_software.last.av.item_1.vendor_name' set to 'Trend Micro, Inc.'
session.check_software.last.av.item_1.version' set to '16.0'
