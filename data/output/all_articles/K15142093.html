Description

BIG-IP APM Portal Access Support for ES6/ES7 is available in v15.1.9, v16.1.4 and v17.1.0

Currently, JavaScript ECMAScript ES8+ is not supported.
  • When troubleshooting you might see one of the following symptoms:
    • Requests not being rewritten correctly causing resets in the browser. 
    • Browser console errors when accessing the site through Portal Access.

Environment

  • BIG-IP APM
  • Portal Access resource configured
  • Backend website uses ES6/ES7/ES8+

Cause

Not supported at time of publication

Recommended Actions

If you believe you are running into this issue:

  • If you observe that requests are not being rewritten correctly and getting reset you can follow K13500329 to help resolve your issue.
  • If you observe errors in the browsers console please open a support case and provide data captures.
