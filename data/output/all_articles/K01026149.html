Description

Below error message found in /var/log/asm file.

  • crit perl[24502]: 01310027:2: ASM subsystem error (asm_start,F5::NwdUtils::Nwd::log_failure): Watchdog detected failure for process. Process name: asm_config_server.pl, Failure: Memory Size reached a threshold (detected memory usage: xxxx, threshold: xxxx).

Environment

  • BIGIP
  • ASM

Cause

The error is caused by asm_config_server.pl was requesting the memory bigger than the max value defined in the system.

Recommended Actions

1. Log in to the CLI
2. Make a back-up copy of the /etc/ts/tools/asm_config_server.cfg file and /etc/ts/tools/nwd.cfg file by typing the following command:
#cp -p /etc/ts/tools/asm_config_server.cfg /var/tmp/asm_config_server.cfg.bak
#cp -p /etc/ts/tools/nwd.cfg /var/tmp/nwd.cfg.bak
3. Edit the /etc/ts/tools/asm_config_server.cfg file using a text editor(like vi)
4. Find this line:
MaxMemorySize=471859200  <<<< (The value could be different from the example here)
5. Extend the MaxMemorySize value to something like the following:
MaxMemorySize=1073741824
6. Save and return to the CLI
7. Edit the /etc/ts/tools/nwd.cfg file using a text editor(like vi)
8. Find this line:
MaxMemorySize=536870912 <<<< (The value could be different from the example here)
9. Extend the MaxMemorySize value to something like the following:
MaxMemorySize=1073741824
10. Save and return to the CLI
11. Restart the asm_config_server processes via the command below:
#pkill -f asm_config_server
NOTE: The workaround may only work on certain platform and configurations, please monitor the device for a while after the workaround performed.
