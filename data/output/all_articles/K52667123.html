K52667123: Configuration doesn´t load even when the correct master key is installed

Type
Support Solution
Published
2026-09-08
Updated
2026-09-08
Source
https://my.f5.com/manage/s/article/K52667123

Description

You are replacing an RMA device, however, even when you have installed the master key on the device the configuration does not load.

Environment

  • You are installing a UCS archive into an RMA device
  • You have copied the master key from the active unit following the steps of article K9420: Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)
  • The output of the command f5mku -k shows the correct master key installed on this RMA device
  • Even when the master key seems to be correct, the configuration fails and you see logs similar to these ones in /var/log/ltm:
notice mcpd[11862]: 01071027:5: Master key OpenSSL error: 1547247988:error:06065064:digital envelope routines:EVP_DecryptFinal_ex:bad decrypt:evp_enc.c:637:
notice mcpd[11862]: 01071029:5: Master decrypt final
err mcpd[11862]: 0107102b:3: Master Key decrypt failure - decrypt failure - final

Cause

Unknown

Recommended Actions

Perform the next steps on the exact same order:

 1- Extract the Master Key from the current Active peer node.

 2- Force the mcpd process to reload the BIG-IP configuration.

    a. Log in to the Advanced Shell (bash).
    b. To create a null file with the file name forceload in the /service/mcpd directory, enter the following command:
        touch /service/mcpd/forceload
    c. To restart the BIG-IP system, enter the following command:
        reboot

 3- Install the original Master Key ( From the Active box or the original box)

    a. Log in to the RMA BIG-IP system command line.
    b. Install the master key that you copied in step 1 to the RMA BIG-IP system using the following command syntax:
        f5mku -r <key_value>
        For example:
        f5mku -r oruIVCHfmVBnwGaSR/+MAA==

 4- Try to load the UCS file with the no-license parameter.

    a. Restore the UCS file to the RMA BIG-IP system using the following command syntax:

       tmsh load sys ucs <file_name>.ucs no-license

 5- Verify no config errors

    tmsh load sys config verify

 6- If no errors above

    tmsh save sys config
