Description

Some of the GTM pool members are showing the following unlicensed as the following example:

-------------------------------------------------------
Gtm::Pool: /Common/example-pool
-------------------------------------------------------
Status
Availability : unlicensed
State : enabled
Reason : Not Authorized


Environment

  • GTM GLSB
  • The link-cost patch has already been installed
  • gtm.loadlinkcost DB key is enabled
  • The BIGIP has recently upgraded or re-licensed

Cause

The MCPD binary may have some corrupted or stalled information that incorrectly marks the GTM objects unlicensed.

Recommended Actions

Check the following article first to make sure the configuration is expected.

  • K000092482: Link Controller Link status is unlicensed and Not Authorized
  • K15834: End of Life announcement for inbound and outbound cost-based link load balancing and inbound link path-based load balancing

If the issue persists, rebuild the MCPD binary by the following article.

  • K13030: Forcing the mcpd process to reload the BIG-IP configuration
