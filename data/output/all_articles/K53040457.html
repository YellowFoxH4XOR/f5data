Description

Client IP in APM Active Session Report does not match Clients current public IP address

Environment

  • BIG-IP APM
  • Network Access 

Cause

Client IP address reported in APM Active Session table is a static value displayed when the client starts a new Access Session.
If the clients public IP address changes and reconnects using the existing Access session, the Configuration Utility (GUI) does not update the Client IP, however the APM log does report the change.
