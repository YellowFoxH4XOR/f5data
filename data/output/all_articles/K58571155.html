Known Issue

The BIG-IP ASM system experiences high CPU usage when you run Policy Builder.

This issue occurs when all of the following conditions are met:

  • You have a security policy or multiple security policies configured with Automatic Policy Builder.
  • Your security policies are configured with a combination or all of the following set to Always:
    • File Types > Learn New File Types
    • URLs > Learn New HTTP URLs
    • URLs > Learn New WebSocket URLs
    • Parameters > Learn New Parameters
    • Cookies > Learn New Cookies
    • Redirection Protection > Learn New Redirection Domains

Impact

The BIG-IP ASM system experiences high CPU usage that impedes the ability to process traffic.

Workaround

To work around this issue, you can modify the Policy Builder learning mode from Automatic to Manual or alternatively you can configure Policy Builder to use the configuration options of Compact, Selective, or Never for automatic learning. To do so, perform one of the following procedures:

  • Modifying the Policy Builder from Automatic to Manual
  • Modifying the Policy Builder Policy Building Settings

Modifying the Policy Builder from Automatic to Manual

Impact of workaround: Performing the following procedure will turn off automatic policy building for the security policy. Additional policy building will require manual policy updates.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Set the Current edited security policy to the affected security policy.
  4. In the General Settings section, set Learning Mode to Manual.
  5. Click Save.
  6. Click Apply Policy.

Modifying the Policy Builder Policy Building Settings

Use this procedure to modify the Policy Builder's entity learning from Always to Compact, Selective, or Never.

Impact of workaround: The following procedure removes the automatic learning of all entities to the selected method of learning.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Set the Current edited security policy to the affected security policy.
  4. In the Policy Building Settings, expand the appropriate section URLs, Parameters, Cookies, or Redirection Protection.
  5. Modify the Learning option to use Compact, Selective, or Never based on your security policy requirements.
  6. Click Save.
  7. Repeat steps 4 through 6 for each Policy Building setting where learning is configured as Always.
  8. Click Apply Policy.
