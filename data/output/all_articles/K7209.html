K7209: H.323 call sessions may end unexpectedly

Topic

For information about BIG-IP 9.x, refer to K7210: H.323 call sessions may end unexpectedly.

H.323-based call software (commonly used in Voice over IP and IP-based video conferencing) typically uses TCP port 1720, the call signaling channel, to initiate a call. Once the call as been established, additional TCP or UDP connections are established to handle data such as audio and video.

The H.323-based signal channel on TCP port 1720 remains connected for the entire call session, but typically remains idle during this period.

Note: This behavior is similar to FTP, in that a control channel is used to send commands and a separate data channel is established to send and receive data. The control channel is subject to long idle periods, during which time the control channel is not used, while data is being transferred.

The default TCP timeout for a virtual server service is 1005 seconds (16 minutes, 45 seconds).

Since the signal channel can remain idle for long periods of time, the Idle Connection Timeout TCP timeout value for the virtual server can close down the connection, terminating the call, due to its primary channel being closed.

To prevent this behavior from occurring, you can create a virtual server that can be used to handle the communication and increase the TCP idle timeout value for the new virtual server. To create a new virtual server with IP address 0.0.0.0 and port 1720, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Select Virtual Servers.
  3. Select Add.
  4. Enter 0.0.0.0 for the Address.
  5. Enter 1720 for the Service.
  6. Select Next.
  7. Select the VLAN on which you want the virtual server to listen. The default is ALL.
  8. Select Next.
  9. Select Next.
  10. Select the Pool that contains the servers handling the H.323 communication.
  11. Select Done.
  12. Select the newly created Virtual Server.
  13. Select the Virtual Service Properties tab.
  14. Change the default Idle Connection Timeout TCP value of 1005 seconds to a higher value.

    For example, if the default Idle Connection Timeout TCP value is 1005 seconds (16 minutes, 45 seconds) you would change the value to one of the following or greater values:

    • 3600 seconds - 1 hour
    • 7200 seconds - 2 hours
    • 14400 seconds - 4 hours
    • 21600 seconds - 6 hours
    • 28000 seconds - 8 hours
  15. Select Apply.
