Known Issue

This is the result of a known issue. The Frame URL Normalization method and the URL Authorization method do not function as expected. When URL Normalization is enabled, the Redirect URL Normalization method and the Cookie Authorization method will be used, no matter which normalization method or authorization method are configured. When Require Authorization is enabled for the the URL Authorization method, requests fail with an HTTP 404 Not Found status response.

F5 Networks Product Development is tracking this issue as ID 133821 (formerly CR133821).
