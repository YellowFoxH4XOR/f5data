Description

When disable/enable pool on GUI >> DNS >>GSLB>>Wide IPs >>Pools, it takes no effect. No error message can be seen.
Environment

  • BIG-IP DNS v14, v15 and v16

  • Wide IP

  • Wide IP pool

Cause

This is tracked by ID857953

Recommended Actions

As a temporary workaround, you can remove the pool from Wide IP when you want to disable it, and add it back when you want to enable it.
