Description

Currently, when a BIG-IP device is in ForcedOffline state, a network administrator regardless of privilege level cannot reach the router configuration shell 'imish'. 

Log from CLI is seen as below:

config # imish

% Can't set FD_CLOEXEC to IMI socket: Bad file descriptor

Environment

  • Access to imish
  • User management

Cause

This is by design to avoid unnecessary non-optimal routes be advertised within the network.

Recommended Action

Make the device ONLINE and this will feature will be enabled

  • config #tmsh run sys failover online
  • config # imish
