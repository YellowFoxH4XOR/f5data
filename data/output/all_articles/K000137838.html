K000137838: How to upgrade Luna Safenet HSM client software

Type
Support Solution
Published
2023-12-15
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000137838

Description

If you need to upgrade Luna Client Software on BIG-IP already intergraded with network HSM you can run nethsm-safenet-install.sh script which will uninstall the currently installed client software and install a new version.

The Luna Client software is available on Thales Group support portal: https://supportportal.thalesgroup.com/ 

Make sure to download relevant version of F5 client for Luna package created for integration with BIG-IP.

Environment

  • BIG-IP
  • Safenet network HSM module

Cause

Upgrade of Luna HSM client software.

Recommended Actions

To upgrade Luna client software:

  1. Download the required version of F5 client for Luna tar archive to /shared/safenet_install/ directory on BIG-IP. The most current version of Luna client software supported by F5 at time of publication is 10.4 with a tar archive name Luna_10.4_Client_Software.tar
  2. Run nethsm-safenet-install.sh script with required options. To use the Luna_10.4_Client_Software.tar please run nethsm-safenet-install.sh --image=Luna_10.4_Client_Software.tar You will also need to specify HSM IP address(es) , HSM partition name(s) etc... You can use options used for the initial software installation.
