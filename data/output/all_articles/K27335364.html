Description

SSH Proxy is configured on BIG-IP, but it's not working as expected. SSH connection through a virtual server works without SSH Proxy profile, but it does not work with the SSH Proxy profile.

Environment

  • SSH Proxy profile is associated with a virtual server

Cause

Configuration is incomplete.

Recommended Actions

When using the SSH Proxy profile, you must ensure that the BIG-IP and SSH server are configured correctly.

SSH Proxy Profile

  • Proxy Client Auth Private Key : Client's private key [/home/user/.ssh/id_rsa] (Required for public key authentication)
  • Proxy Server Auth Private Key : BIG-IP's private key [/root/.ssh/id_rsa or whatever you'd like to use for ssh proxy] (Required)
  • Real Server Auth Public Key : Server's public key [/etc/ssh/ssh_host_rsa_key.pub] (Required)

Note: The Proxy Client Auth and Proxy Server Auth public keys will be automatically populated from the private keys.

SSH Server

Ensure the HostKey /etc/ssh/ssh_host_rsa_key line is present and uncommented in the server's sshd_config file:

grep -Ev '^#|^$' /etc/ssh/sshd_config

Furthermore, ensure the server's authorized_keys file contains the following for public key authentication.

  • Proxy client auth public key (client's public key [/home/user/.ssh/id_rsa.pub])
  • Proxy server auth public key (BIG-IP's public key [/root/.ssh/id_rsa.pub]) 

The easiest way to install the public keys in the server's authorized_keys file is to use ssh-copy-id before adding the SSH Proxy Profile to the virtual server.

Additional Information

Review the /var/log/sshplugin file for indicators of configuration issues with the SSH Proxy Profile.

Note: SSH traffic events are logged using a Security Log Profile, attached to the virtual server.

Refer to the SSH Proxy Security manual chapter for your BIG-IP version for more detailed configuration information.
