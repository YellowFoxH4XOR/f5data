K81310610: SSLO Configuration: Access forbidden or Not Found or show wizard of new topology

Type
Support Solution
Published
2022-08-25
Updated
2025-06-05
Applies to
  • F5 App Protect
  • BIG-IP SSL Orchestrator: 15.1.X, 15.1.1, 15.1.0
Source
https://my.f5.com/manage/s/article/K81310610

Description

When access the Configuration Utility, navigate to SSL Orchestrator  ››  Configuration, get the error like below:

Not Found
The requested URL was not found on this server.

Or

Access forbiddened!
You don't have permission to access the requested objects.

Or

the page become the wizard of new topology.

Environment

  • BIG-IP SSL Orchestrator

Cause

ID 1626337: RPMS not being included in the generated UCS with fix of ID985329 incorporated

Note: Contact F5 support to request an engineering hotfix (EHF).

Recommended Actions

Please follow the steps to fix the issue:

  1. Query the f5-iappslx-ssl-orchestrator package ID (9beb912b-4f1c-3f95-94c3-eb1cbac4ab99), and use the returned ID in the following step.

restcurl shared/iapp/installed-packages | jq -r '.items[] | select(.appName=="f5-iappslx-ssl-orchestrator") | .id'

The output example:

9beb912b-4f1c-3f95-94c3-eb1cbac4ab99     

  1. Delete existing f5-iappslx-ssl-orchestrator package references (please replace the string 9beb912b-4f1c-3f95-94c3-eb1cbac4ab99).

restcurl -X DELETE shared/iapp/global-installed-packages/9beb912b-4f1c-3f95-94c3-eb1cbac4ab99

restcurl -X DELETE shared/iapp/installed-packages/9beb912b-4f1c-3f95-94c3-eb1cbac4ab99

  1. Stop the REST framework daemons.

bigstart stop restjavad restnoded

  1. Make sure the /var/iapps/www/ directory exists.

mkdir -p /var/iapps/www/

  1. Create the RPMS.save directory.

mkdir -p /var/config/rest/iapps/RPMS.save

  1. Check if the current f5-iapplx-ssl-orchestrator RPM (e.g., 14.1.0-5.5.8) is present at the default location.

ls -la /var/config/rest/iapps/RPMS/

-- If it is not present, try to get it from either the /usr/share/packages/f5-iappslx-ssl-orchestrator/ directory or from the remote high availability (HA) peer device (/var/config/rest/iapps/RPMS/). Make sure the RPM version matches the current SSL Orchestrator configuration/version (e.g., 14.1.0-5.5.8). If you cannot find a copy of your original RPM locally, download the latest RPM available for your chosen BIG-IP version from downloads.f5.com.

-- Once obtained, copy the RPM to /var/config/rest/iapps/RPMS/ (locally).

  1. Copy the current f5-iapplx-ssl-orchestrator (e.g., 14.1.0-5.5.8) RPM to the RPMS.save directory.

cp /var/config/rest/iapps/RPMS/f5-iappslx-ssl-orchestrator-14.1.0-5.5.8.noarch.rpm /var/config/rest/iapps/RPMS.save/

  1. Make sure you have only one f5-iappslx-ssl-orchestrator RPM in the RPMS.save/ directory and that it matches the RPM version. Remove other RPMs, if any.

  2. Remove the current SSL Orchestrator user interface artifacts.

rm -rf /var/iapps/www/f5-iappslx-ssl-orchestrator/

rm -rf /var/config/rest/iapps/f5-iappslx-ssl-orchestrator

  1. Restart the REST framework.

bigstart restart restjavad restnoded

  1. Wait at least 30 seconds.

  2. Open Consiguration Utility on the affected device, and navigate to SSL Orchestrator :: Configuration.

  3. The SSL Orchestrator Self-Guided Configuration page should initialize and eventually load successfully.
