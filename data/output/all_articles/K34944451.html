Known Issue

The Configuration utility may not display the Network Map objects in subfolders.

This issue occurs when all of the following conditions are met:

  • You configure a virtual server under a partition subfolder.
  • You attempt to view the Network Map when the parent partition is selected.

For example, you configure virtual server VS1 under the /Common/sub-folder/VS1 subfolder and select the /Common parent partition to view the Network Map object VS1.

Impact

You are unable to view Network Map objects in the subfolder.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system does not display the Network Map objects in the subfolder under a partition.

Resolution

Status

Workaround

To work around this issue, you can select the All[Read Only] partition in the Configuration utility to view all of the objects in the subfolders.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
