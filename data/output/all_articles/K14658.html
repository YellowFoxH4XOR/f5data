Topic

You should consider using this procedure under the following condition:

  • You want to determine which version of GRUB bootloader your BIG-IP, BIG-IQ, or Enterprise Manager system uses.

Description

GRUB 0.97 is installed in versions prior to BIG-IP 11.3.0. Beginning in BIG-IP 11.3.0, the binaries for both GRUB 0.97 and GRUB2 are installed on all systems. However, only one of the GRUB bootloaders is in use by the system at any one time. This article helps you determine which version of the bootloader your BIG-IP system uses.

Note: Because both binaries are installed, the grub --version command always indicates GRUB 0.97, even for platforms that actually use GRUB2.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access the BIG-IP, BIG-IQ, or Enterprise Manager system's command line or advanced shell with the access credential of an Administrator role.

Procedures

To determine which version of GRUB bootloader your BIG-IP, BIG-IQ, or Enterprise Manager system uses, perform the following procedures:

  • Displaying part of the GRUB configuration
  • Determining the GRUB version from its configuration

Displaying part of the GRUB configuration

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP, BIG-IQ, or Enterprise Manager command line.
  2. To display the GRUB configuration for the software slot entry "TMOS maintenance", type the following command:

    grub_default -d | grep -A6 "TMOS maintenance"

Determining the GRUB version from its configuration

To determine the GRUB bootloader version, note the GRUB configuration syntax from the previous procedure.

  • For the system that uses GRUB2 as the bootloader, the software slot entry for "TMOS maintenance" contains the following syntax:
    • The boot slot name or description is set by the GRUB command menuentry.
    • The boot slot name is followed by braces { ... } enclosing the software slot boot-up setting.

    For example, GRUB2 output for the software slot "TMOS maintenance" may appear similar to the following:

    menuentry 'TMOS maintenance' {
    set root='(lvm/vg--db--sda-dat.boot)'
    linux /vmlinuz.mos root=/dev/ram0 rw console=ttyS0 ramdisk_size=224707.5 skip_media
    initrd /initrd.img.mos
    # TIC_STATIC_KEY: st.mos
    # TIC_STATIC_VERSION: 2.8.1-44.0
    }

  • For the system that uses GRUB 0.97 as the bootloader, the software slot entry for "TMOS maintenance" contains the following syntax:
    • The boot slot name or description is set by the GRUB command title.
    • The boot slot name is followed by the next few lines depicting the software slot boot-up setting.

    For example, GRUB 0.97 output for the software slot "TMOS maintenance" may appear similar to the following:

    title TMOS maintenance
    root (hd0,0)
    kernel /vmlinuz.mos root=/dev/ram0 rw console=tty0 ramdisk_size=224707.5 skip_media
    initrd /initrd.img.mos
    # TIC_STATIC_KEY: st.mos
    # TIC_STATIC_VERSION: 2.8.1-44.0
