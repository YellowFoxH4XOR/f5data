Issue

Old Behavior

In versions prior to BIG-IP 11.2.0, the fpdd process uses the Failover.BigipUnitMask database variable to determine the high availability (HA) failover state of the device. The information and versions screens of the LCD panel only display an HA failover state of active or standby for redundant systems.

New Behavior

Beginning in BIG-IP 11.2.0, the fpdd process uses the Failover.State database variable to determine the HA failover state of the device. Using the Failover.State database variable allows the fpdd process to provide a more accurate HA failover state of a redundant system. The information and versions screens of the LCD panel now display an HA state of active, standby, offline, or forced offline for redundant systems.

F5 Product Development tracked this change as ID 373563.

Impact

The fpdd process provides a more accurate HA failover state on the LCD panel.
