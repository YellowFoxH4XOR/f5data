Description
The BIG-IP APM VPN client software - EdgeClient - can be automatically launched at startup.
In case a VPN connection was up when the client machine was restarted, the EdgeClient program tries to resume the connection upon restart, leading users to get prompted enter credentials, if needed.

Environment

  • You're using BIG-IP APM VPN;
  • The VPN connections are made using the EdgeClient software;
  • The client machine is set up to launch the EdgeClient software at startup;
  • The VPN is up when the client machine is either switched off or rebooted.

Cause
This is the expected behaviour..

Recommended Actions

Instruct the users they may be prompted with an authentication window
-- or --
Educate the users to close the VPN connection before shutting down the client machine

Additional Information
When the VPN connection is established, we can see the following records, in the client.f5c file:
<STATE>
      <LAST_CONNECTION_MODE>ALWAYS_CONNECTED</LAST_CONNECTION_MODE>
</STATE>
This record instructs EdgeClient to initiate the VPN connection upon restart.
