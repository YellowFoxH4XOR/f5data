Known Issue

If a Secure Sockets Layer (SSL) connection begins to gracefully disconnect during SSL acceleration hardware data encryption, the connection remains open until the TCP profile timeout occurs instead of immediately closing.

This issue occurs when all of the following conditions are met:

  • You have a virtual server with a Client SSL profile or Server SSL profile.
  • You are using Nitrox SSL hardware acceleration.
  • An SSL connection closes by means of a TCP FIN packet or an iRules command during SSL record encryption.

Impact

During service disruption, higher memory usage may cause the Traffic Management Microkernel (TMM) to crash due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • CPU use of one or more TMMs suddenly rises to 100 percent.
  • Your BIG-IP system experiences memory exhaustion.
  • Your BIG-IP system produces a TMM core file.
