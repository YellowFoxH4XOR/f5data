Description

SSL hardware acceleration is always showing partial even when using on SSL hardware offload capable platforms.

  • "tmsh show ltm profile client-ssl global" shows SSL Hardware Acceleration with Full 0 and rest Partial.
    <snip>
    SSL Hardware Acceleration
      Full                                                              0
      Partial                                                       58.6G
      None (Software)                                                   0
    <snip>

Environment

  • iSeries platform.
  • SSL cipher string is set to DEFAULT.

Cause

An SSL/TLS handshake has several steps like like signing, key exchange, key derivation, master secret calculation etc. As of now, few of the steps are done in hardware for SSL hardware acceleration based off Intel chipsets.

Recommended Actions

There are internal RFEs (Request For Enhancement) associated with this and in future all steps involved in an SSL/TLS handshake should be offloaded to hardware. There is no ETA for now. But as long as SSL Hardware Acceleration is shown as partial, the huge chunk of encryption (bulk encryption) should be done in hardware, there are few steps still performed in software.
