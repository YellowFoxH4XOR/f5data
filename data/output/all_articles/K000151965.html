K000151965: 01070734:3: Configuration error: Less than the required minimum number of profiles found on <VIrtual Server Name>: Exactly 1 of (UDP Profile (clientside), TCP Profile (clientside), SCTP Profile (clientside))

Type
Support Solution
Published
2025-06-20
Updated
2025-06-20
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000151965

Description

This message occurs when  the following condition is met:

  • You are trying to configure/create a new virtual server using the following CLI command:

For example:

create ltm virtual test destination 1.2.3.4:443 ip-protocol tcp mask 255.255.255.255 pool test_pool profiles replace-all-with { http tcp-lan-optimized { context clientside } tcp-lan-optimized { context serverside } serverssl { context serverside } clientssl { context clientside } } source 0.0.0.0/0 source-address-translation { type automap } translate-address enabled translate-port enabled

Environment

  • The /var/log/ltm file
  • The /var/log/audit file

Cause

You are trying to configure the same tcp profile on both client and server sides.

Recommended Actions

Use the option { context all } as follows:

create ltm virtual test destination 1.2.3.4:443 ip-protocol tcp mask 255.255.255.255 pool test_pool profiles replace-all-with { http tcp-lan-optimized { context all } serverssl { context serverside } clientssl { context clientside } } source 0.0.0.0/0 source-address-translation { type automap } translate-address enabled translate-port enabled
