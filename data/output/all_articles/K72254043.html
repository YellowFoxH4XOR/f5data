Description

Changes to ASM are synchronized to the peer but errors in the log appear:

  crit g_server.pl[14544]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::Cgc::Channel::new): Could not open a cgc connection with group_id '/Common/asm01.local', service 'asm_cgc_high_pri_to_single'

Environment

  • device-group with ASM sync enabled
  • The device name of HA Pair has been changed

Cause

stale records of asm-sync exists

Recommended Actions

  • delete stale records of asm-sync 

Delete stale records of asm-sync

  1. Log in to the BIG-IP ASM command line.
  2. List asm device-sync records.
            tmsh list asm device-sync recursive
  1. Delete stale records to be specified with old device name.
            tmsh delete asm device-sync <stale record>
  1. Repeat 3. for all stale records.
