Description

You would like to review F5OS-A log files

 

Environment

  • F5OS-A

 

Cause

None

 Recommended Actions

F5OS-A log files are stored in /var/F5/system/log/.

Common Linux log files are stored in /var/log/.

 

/var/F5/system/log/

audit.log, confd.log, devel.log - Confd related logs

k3s_events.log - k3s related events

platform.log - Mostly all of the F5OS related daemon and services are std-out the logs in this log file.

 

/var/log/

ansible.log - ansible playbook related log

containers - its has all k3s and kubevirt container related log

/var/log/platform/pel - its hardware platform related log

sw-mgmt.debug, sw-upgrade.log and sw-util.log - F5OS software upgrade/installation related.

kubevirt-install.log - kubevirt installation related.
