Known Issue

This is the result of a known issue. Using the Check Names feature in Microsoft SharePoint 2007 and SharePoint 2010 will fail with the Mozilla Firefox or Apple Safari browsers. This issue does not affect Microsoft Internet Explorer. When you click on the Check Names icon, it appears to not function. If you open an error console on the browser, you view an error message that appears similar to the following example:

Error: s is undefined Source File:https://sharepoint.example.com/private/fm/cache-fm.js Line: 8153

This issue occurs because the reverse-proxy rewrite engine in BIG-IP APM and FirePass controllers incorrectly patches the JavaScript for SharePoint.

F5 Product Development is tracking this issue as ID 336865 for FirePass.

F5 Product Development tracked this issue as ID 337005 for BIG-IP and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

In addition, this issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
