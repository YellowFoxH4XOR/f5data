Topic

External monitors are user-defined health or performance monitors that verify the status of a service by accessing the application on the remote web server.

In BIG-IP versions prior to 10.1.0, external monitors were installed in the /usr/bin/monitors directory on the BIG-IP system.

In BIG-IP 10.1.0 - 10.2.4, external monitors must be installed in the /config/monitors directory.

Note: For information about importing external monitor files to the BIG-IP system in version 11.x and later, refer to K13423: Importing external files to the BIG-IP system.
