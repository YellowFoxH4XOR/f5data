Topic

The BIG-IP WebAccelerator version 10.x includes the following pre-defined acceleration policies:

  • BEA AquaLogic (Plumtree with Collaboration)
  • BEA AquaLogic (Plumtree without Collaboration)
  • BEA Weblogic
  • Ecommerce
  • Hyperion Financial
  • IBM WebSphere
  • Level 1 Delivery
  • Level 2 Delivery
  • Lotus Domino
  • MatrixOne eMatrix
  • Microsoft Internet Information Service (IIS)
  • Microsoft Outlook Web Access (OWA) 2003
  • Microsoft Outlook Web Access (OWA) 2007
  • Microsoft Sharepoint Services 2003
  • Microsoft Sharepoint Services 2007
  • Oracle - Peoplesoft 9
  • Oracle 11i
  • Oracle AS 10g Portal
  • Oracle JD Edwards ERP
  • Oracle Peoplesoft
  • Oracle Siebel CRM
  • SAP Portal
  • Symmetric Deployment

Note: For information about the pre-defined acceleration policies for BIG-IP WebAccelerator version 9.x, refer to K8675: The BIG-IP WebAccelerator version 9.4.x pre-defined acceleration policies.

Note: For information about the pre-defined acceleration policies for WebAccelerator version 5.x, refer to K7274: Default policies included with the WebAccelerator version 5.x.
