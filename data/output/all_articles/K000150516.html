Description

Syslog traffic routed through an F5 BIG-IP LTM Standard Virtual Server may become intermittent and unstable. Logs may be delayed, missing, or not transmitted at all.

 

Environment

BIG-IP LTM

 

Cause

The root cause was identified as inefficiency in handling high-speed log streams due to limitations in buffer management and window scaling within the Standard Virtual Server configuration type. The Standard VS creates full-stack TCP connections on both client-side and server-side, leading to rapid buffer saturation under heavy log traffic conditions.

 

Recommended Actions

Switch Virtual Server type from Standard to Performance (Layer 4) using a fastL4 profile.
