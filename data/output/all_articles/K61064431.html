Description

How to restrict users from accessing a VPN or a policy by limiting their access by a predefined list of MAC addresses 

Environment

  • BIG-IP APM
  • Access Policy
  • MAC address

Cause

None

Recommended Actions

To restrict access by MAC address, complete the following four procedures in the order presented:

Create a Datagroup called MAC list:

  1. Go to Local Traffic -> iRules -> Data Group -> (+)
  2. Enter name "MACList"
  3. Set type as "String"
  4. In the String field, enter a MAC address in lowercase hex, separated by colons, eg; >1a:2b:3c:4d:5d:6f
  5. In the Value field, enter an optional value or leave it blank, eg: "John's laptop"
  6. Click Add
  7. Repeat the above 3 steps, until all required MAC addresses are in the list
  8. Click Finished


Create an iRule called

    CheckMAC

    1. Go to Local Traffic -> iRules -> Rule List -> (+)
    2. Enter name "CheckMAC"
    3. If you need to check a single MAC Address, copy and paste the below iRule.

      #################################################
      when ACCESS_POLICY_AGENT_EVENT {
        if { [ACCESS::policy agent_id] eq "CheckMAC" } {
          set mac [string tolower [ACCESS::session data get "session.machine_info.last.net_adapter.list.\[0\].mac_address" ]]
          if { [class match $mac equals MACList] }{
            ACCESS::session data set "session.logon.custom.checkmac" 1
          } else {
            ACCESS::session data set "session.logon.custom.checkmac" 0
          }
        }
      }
      ##############################################
    4. If you need to check multiple MAC Addresses, use the following iRule.

      #################################################
      when ACCESS_POLICY_AGENT_EVENT {
        if { [ACCESS::policy agent_id] eq "CheckMAC" } {
          set i 0
          # Check for 0 1 and 2
          set loopCount 3
          ACCESS::session data set "session.logon.custom.checkmac" 0
          while { $i < $loopCount } {
            set mac [string tolower [ACCESS::session data get "session.machine_info.last.net_adapter.list.\[$i\].mac_address" ]]
            if { [class match $mac equals MACList] }{
              ACCESS::session data set "session.logon.custom.checkmac" 1
            }
            incr i
          }
        }
      }
      #################################################
       
    5. Click Finished


    Edit your policy in the VPE 

    1. Add the activity for "Machine Info" from the Endpoint Security Client Side Checks, inserted at the point where you want the MAC Address to be checked.
    2. Add an iRule Event activity immediately after the "Machine Info" success branch
    3. Set the iRule Event Custom iRule Agent ID as "CheckMAC"
    4. Add a branch rule
    5. Set the branch rule expression in the advanced tab to be "expr {[mcget {session.logon.custom.checkmac}] == 1}"


    Edit the Virtual server

    1. Go to Local Traffic -> Virtual Server -> Virtual Server List 
    2. Select your specific virtual server
    3. Click the Resources tab
    4. To the right of iRules, click Manage
    5. Select CheckMAC from the list and click <<
    6. Click Finished
