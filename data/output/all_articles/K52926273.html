Description

This article will detail how to use a Variable Assign to combine Access Policy Session Variables.

  • In the example use case we will combine domain and username values for use in a Outlook Web Access (OWA) Single Sign On (SSO) configuration.

Environment

  • BIG-IP Access Policy Manager (APM)
  • Virtual Policy Editor.
  • Variable Assign object.

Cause

You need to combine Session Variables into a single Custom Variable.

Recommended Actions

Create a custom variable combining domain and username in a Down-Level Logon Name Format (domain\username):

  1. Logon to the BIG-IP Admin GUI.
  2. Navigate to Access>Profiles / Policies>Access Profiles (Per-Session Policies).
  3. Click on the Edit icon to open the Virtual Policy Editor (VPE).
  4. Go to the Assignment tab and select Variable Assign.
  5. Click Add Item.
  6. In the Variable Assign click the Change link.
  7. In the Custom Variable field enter the name of the custom variable. For example:
    session.logon.last.domain_and_username
  8. In the Custom Expression enter the following:
    expr { "[mcget {session.logon.last.domain}]\\[mcget {session.logon.last.username}]" }
  9. Click Finished
  10. Click save.
  11. The new Custom Variable will have the Down-Level Logon Name Format:
    session.logon.last.domain_and_username=domain\username

Additional Information

You can use the sessiondump command line utility to verify the custom session variable is being populated correctly. For information refer to the Session Variables chapter of the BIG-IP Access Policy Manager: Visual Policy Editor guide.
