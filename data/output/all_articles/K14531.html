Known Issue

When you update an iRule through the Traffic Management Shell (tmsh), if the iRule uses the recv command, modifying the iRule causes the tmsh utility to display an incorrect warning.

Note: This warning is generated by the control plane (when loading or modifying an iRule), and does not occur when TMM executes an iRule.

This issue occurs when the following conditions are met:

  • The recv command is used within an iRule.
  • The tmsh utility is used to modify or load the configuration.

Impact

The false error message may cause confusion, but it can safely be ignored.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H425502 on the Diagnostics > Identified > Low screen.
  • A warning message that appears similar to the following example may display on the command prompt. The same warning may be seen if loading the configuration using the tmsh utility:

    warning: [variable reference used where variable name expected][$conn_id]
