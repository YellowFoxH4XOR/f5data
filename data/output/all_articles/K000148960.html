Description

The HTTP header contains client information, such as the type and version of web browser, operating system, and platform. You can create an iRule to block requests from 1.0 version to avoid some limitations.

Environment

  • HTTP 1.0
  • Virtual server

Cause

None

Recommended Actions

Configure below iRule to block HTTP 1.0 request to Virtual Server:
 

Impact of procedure: F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

when HTTP_REQUEST {

log local0. "hitting irule"

if { [HTTP::version] eq "1.0" } {

reject

}}

 

Note: Make sure to attach the iRule with Virtual server and test it.
