Description

Getting requests logged with source IP address or URL listed in the bot defense profile whitelist.

Environment

  • ASM
  • Bot Defense
  • IP Whitelist

Cause

The Bot Defense profile whitelist items have two options, disable Browser Verification and Device ID Challenges and Mitigation Actions. There is currently no option to disable alarming for any bot type.

Recommended Actions

No action is required.

As long as the whitelisted source IP is not being challenged or blocked then the whitelist is working as expected.
