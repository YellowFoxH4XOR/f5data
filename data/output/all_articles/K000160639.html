Description

When POSTing a CFE declaration, the request times out with a 503 response code. CFE logs in /var/log/restnoded/restnoded.log show the CFE extension is stuck in a loop.

 

 

Environment

- Cloud Failover Extension

- Large internal datagroups in use (tens or hundreds of thousands of objects)

- CFE logs show the extension is in a retry loop after the /declare endpoint returns a 503 response code

 

 

Cause

This may be due to ID2230669, which should be fixed in an upcoming release of the Cloud Failover Extension. Please review CFE release notes for details on when this issue is fixed.

 

 

Answer/Recommended Actions

If possible, convert large internal datagroups to external datagroups. Internal datagroups use additional system resources due to extensive searching requirements on large data groups. External datagroups are more performant and scale significantly better for larger datagroups.

 

If converting to external datagroups is not possible, upgrade the CFE to a version where ID2230669 is fixed. If there is no fix available, open a support case with F5 requesting workaround options.
