Known Issue

When a virtual server configured with an HTTP profile and a OneConnect profile receives a response shorter than the indicated Content-Length header, followed by a FIN, the client-side connection hangs until the associated protocol profile times the connection out, and the client never receives the expected response.

F5 Product Development tracked this issue as ID 223894 (formerly CR132654) and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, or WebAccelerator release notes.

Workaround

You can work around this issue by removing the OneConnect profile from the affected virtual server.
