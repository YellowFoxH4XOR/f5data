K000148397: Container Ingress Services (CIS) problem populating static routes from OpenShift

Type
Support Solution
Published
2025-01-14
Updated
2025-01-14
Source

Description

The static routes configured in the CIS configmap are not populating in the BIG-IP even though the option is configured.  

Environment

  • F5 CIS ovn-k8s 2.13 or greater. 

Cause

Either one of the below annotation options are required in order for ovn-kubernetes static routes to be auto-populated on the BIGIP:

  • Annotate the nodes with: 
    • OVNK8sNodeSubnetAnnotation = “k8s.ovn.org/node-subnets” and OVNK8sNodeIPAnnotation = “k8s.ovn.org/node-primary-ifaddr” by default.
  • Or anotate the nodes with:   
    • OVNK8sNodeIPAnnotation = “k8s.ovn.org/host-addresses” if –static-route-node-cidr is configured in CIS deployment args.

CIS Configuration options in the configmap should reflect these options: 

- --static-route-node-cidr=10.1.1.0/24
- --static-routing-mode=true
- --orchestration-cni=ovn-k8s

Recommended Actions

If the environment requires the use of 'k8s.ovn.org/host-addresses' annotation,  the annotation needs to be applied to all the nodes with relevant workloads within the cluster in order for CIS to deploy the routes to the BIGIP.
