Description

When attempting to add a record to a Zonerunner "forward" zone, the following errors are seen:

  GUI message:  01150b21:3: RCODE returned from query: 'NXDOMAIN'.

  /var/log/gtm log:
    Mar 18 15:34:15 lab-v12a err zrd[19879]: 01150b21:3: RCODE returned from query: 'NXDOMAIN'
  Mar 18 15:34:15 lab-v12a notice zrd[19879]: 01150818:5: Error querying for SOA record 7.7.7.in-addr.arpa. while modifying zone Resource Records. Will not attempt to set SOA serial number.
  Mar 18 15:34:15 lab-v12a err zrd[19879]: 0115070e:3: Unable to get nsupdate commands for zone 'name: 7.7.7.in-addr.arpa., view: external, type: forward, file: '
  Mar 18 15:34:15 lab-v12a notice zrd[19879]: 01150216:5: Notice from named-checkconf: server reload successful

A side effect of these errors is that the forward zone is removed from Zonerunner.
 

Environment

  • DNS
  • Zonerunner "forward" zone
 

Cause

There is no zone file created for a "forward" DNS zone in Zonerunner, so there is no location to add local records into. Adding local zone records for a 'forward' type zone is not supported.
