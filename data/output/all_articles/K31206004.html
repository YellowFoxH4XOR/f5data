K31206004: Changes to the ASM Configuration utility in BIG-IP 14.0.0

Issue

Old Behavior

In versions prior to BIG-IP ASM 14.0.0, the Policy Properties page, Enforcement Readiness Period setting, and Signature Staging setting are located as follows in the Configuration utility:

  • Policy Properties page

    The basic and advanced Policy Properties page is located on the following Configuration utility page: Security > Application Security > Policy > Policy Properties.

  • Enforcement Readiness Period setting

    The Enforcement Readiness Period setting is located on the following Configuration utility page: Security > Application Security > Policy > Policy Properties.

  • Signature Staging setting

    The Signature Staging setting is located on the following Configuration utility page: Security > Application Security > Policy > Policy Properties.

New Behavior

Beginning in BIG-IP ASM version 14.0.0, the above mentioned settings are located as follows in the Configuration utility:

  • Policy Properties page

    The Policy Properties settings is located on the following Configuration utility page: Security > Application Security > Security Policies > Policies List.

  • Enforcement Readiness Period setting

    The Enforcement Readiness Period setting is located on the following Configuration utility page: 14.0.0 - Security > Application Security > Policy Building > Learning and Blocking Settings > Advanced.

  • Signature Staging setting

    The Signature Staging setting is located on the following Configuration utility page: Security > Application Security > Policy Building > Learning and Blocking Settings > Advanced.

Impact

None

Recommended Actions

Accessing the security policy properties page

In ASM version 14.0.0, you can access the basic and advanced security policy properties by performing the following procedure:

  1. Log into the Configuration utility.
  2. Navigate to Security > Application Security > Security Policies > Policies List.
  3. On the Policies List page, click the name of the security policy.
  4. Click the Policy Properties tab.
  5. Click Basic or Advanced to toggle between basic and advanced views.

Accessing the Enforcement Readiness Period setting

In ASM version 14.0.0, you can access the Enforcement Readiness Period setting by performing the following procedure:

  1. Log into the Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. In the General Settings list, click Advanced.
  4. Under General Settings, find the Enforcement Readiness Period box.

Accessing the Signature Staging setting

In ASM version 14.0.0, you can access the Signature Staging setting by performing the following procedure:

  1. Log into the Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. In the General Settings list, click Advanced.
  4. Click Attack Signatures to display attack signature options.
  5. Find the Enable Signature Staging option.
