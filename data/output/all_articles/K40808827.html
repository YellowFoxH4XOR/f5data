Description
 

  • AD/LDAP groups fail to import on Standby device in "Use Pool" mode
  • Below error is thrown in GUI
     Error
     Unable to import groups

Environment

  • APM
  • AD AAA
  • LDAP AAA

Cause

Such behavior is by design:

  • In case of "Use Pool" mode the BIG-IP uses it's floating IP to reach AD/LDAP servers.
  • In case of "Direct" mode the BIG-IP uses it's non-floating IP to reach AD/LDAP servers.
  • While the "Direct" mode will allow Active and Standby to reach the servers, "Use Pool" mode will only work for the Active unit which has the floating IP enabled.

Recommended Actions

The workaround to be able to list the groups on the Standby would be:

  • to perform the failover, import groups and then perform failover again

       or

  •  to switch to "Direct" mode, retrieve the groups and then switch to "Use Pool" mode again
