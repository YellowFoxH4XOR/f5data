Known Issue

This is the result of a known issue. You cannot set the LIND, CSYNCD, or CLUSTERD logs to the Emergency or Alert logging levels. If you attempt to do so, an error message similiar to the following example is displayed:

01070911:3: The requested enumerated (emergency) is invalid (critical, error, warning, notice, informational, debug) for loglevel in daemon_lind

Note: The CLUSTERD log only applies to VIPRION systems.

F5 Product Development is tracking this issue as ID 344252.
