K000150521: After removing Tacacs configuration "SendFailed: sending to X.X.X.X port tacacs failed" error is received

Type
Support Solution
Published
2025-03-25
Updated
2025-03-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150521

Description

After deleting Tacacs configuration, the log below is still received.

  • Log: SendFailed: sending to X.X.X.X port tacacs failed

Environment

  • Tacacs
  • Remote authentication

Cause

Db variable "config.auditing.forward.destination" still has the tacacs server's IP configured.

sys db config.auditing.forward.destination {
    default-value "::"
    scf-config "true"
    value "X.X.X.X"
    value-range "string"
    }

Recommended Actions

Reconfigure config.auditing.forward.destination to default.

tmsh modify sys db config.auditing.forward.destination reset-to-default

tmsh save sys config

Additional Information

None.
