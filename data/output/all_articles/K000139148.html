Description

  • When executing "tmsh show net f5optics", the following error is displayed:

rpmdb: /shared/lib/rpm/Name: unexpected file type or format
error: cannot open Name index using db3 - Invalid argument (22)
rpmdb: /shared/lib/rpm/Name: unexpected file type or format
package f5optics is not installed

  • Log messages similar to the following can be seen on /var/log/ltm

err logger[7346]: f5optics_installation: Installation failed
err logger[7349]: Error 139 installing f5optics package /var/f5optics/images/f5optics-1.0.0-62.0.im.

Environment

  • BIG-IP.
  • RPM packages.
  • f5optics.

Cause

The RPM database is corrupted.

Recommended Actions

To fix the issue you can perform the following procedure to restore the RPM database and manually install the f5_optics RPM package (No impact).

1. Backup the RPM

mv /shared/lib/rpm /shared/tmp/rpm.bak

2. Remove corrupted RPM database:

rm -rf /shared/lib/rpm/

3. Initialize rpm database and update

/opt/bin/rpm --root /shared --dbpath /lib/rpm --initdb
/opt/bin/rpm --dbpath /shared/lib/rpm -qa

4. Install the f5_optics RPM package:

/usr/bin/f5optics_install
