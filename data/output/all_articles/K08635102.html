Policy Information

F5 Anti-Bot Mobile SDK extends bot identification in Advanced Web Application Firewall (Advanced WAF) and BIG-IP ASM protection to allow mobile applications to identify as valid applications, which eliminates bot threats. To use this enhanced capability, you must integrate the F5 Anti-Bot Mobile SDK with your mobile applications. The partnership between F5 and Appdome allows Anti-Bot customers to use Appdome's service to integrate the F5 SDK with their own applications.

Appdome Support

For support during the application integration phase, contact Appdome at support@appdome.com or via the chat window within the Appdome platform.

F5 Technical Support

For support after the application is running on the mobile device, contact F5 Technical Support.

Note: The F5 Anti-Bot Mobile SDK license allows application access via ABM_SDK to the BIG-IP system. F5 delivers the Anti-Bot Mobile SDK via the Appdome portal, which includes fusing services and access to Appdome ONEShield. Any additional services within the Appdome portal may require additional fees to Appdome.
