Description

  • HTTP chunking gets enabled when DDoS protection profile is assigned to VS and large files are being served.
  • HTTP profile chunking settings "Sustain" is not preserved.

Environment

  • ASM provisioned
  • DoS profile assigned to virtual server

Cause

Seen behaviour is caused by a known issue tracked with the Bug ID 881757

Recommended Actions

Upgrade to a software version where Bug 881757 is fixed.
