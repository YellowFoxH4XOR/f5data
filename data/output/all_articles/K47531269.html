Description

After uploading new certificate, key, crl or csr files, you might notice the files show without the expected extension .crt or .key in the list or on the SSL profile where they are attached.

For example:

tmsh list ltm profile client-ssl SSL-Profile-Name
ltm profile client-ssl SSL-Profile-Name {
    cert-key-chain {
        Certificate-Name {
            cert myDomain
            key myDomain
        }
    }
}

Instead of the expected output with extensions:

tmsh list ltm profile client-ssl SSL-Profile-Name
ltm profile client-ssl SSL-Profile-Name {
    cert-key-chain {
        Certificate-Name {
            cert myDomain.crt
            key myDomain.key
        }
    }
}

Environment

  • Running BIG-IP version 14.0 or higher
  • Certificate, key, csr or crl has been imported/created
  • File name extension (key/crt/csr/crl) in name field hasn't been specified

Cause

This is due to a behaviour change since 14.0.

tmsh, iControl REST daemon (iCRD), and the GUI no longer implicitly adds extensions to key/cert/csr/crl file objects when using create/query/delete commands, and the system will use the exact name/label specified. For example, if you specify the name 'test' when using tmsh, iCRD, or the GUI to create a key and a certificate, the system will create the key named 'test' and certificate named 'test' (without an extension).

Bug ID 535122: [tmsh/iCRD/GUI] Do not automatically add extensions to SSL key/cert/crl/csr file objects.

Recommended Actions

Specify the correct extension for the type of object you are creating / importing.

Additional Information

Note: The traffic on the Virtual Server with the SSL Profile and Certificates attached, will still work with or without the extensions.

Additional symptoms can include getting random behaviour when using iControl Rest API to get SSL certificate info. For example, using GET https://<management_IP>/mgmt/tm/sys/crypto/cert/~Common~Cert_name.crt, needs to be queried the same way the certificate was imported (with or wothout .crt), or the call will fail.
