Known Issue

You cannot release blocked sessions and user names, or view session tracking status information using the Configuration utility.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured for high availability (HA).
  • You configure a security policy with session tracking.
  • A session is blocked through security policy session tracking.
  • You attempt to view Session Tracking Status or release a blocked session or user name.

Impact

The Session Tracking Status page does not display any session tracking information.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to view session tracking information, the Session Tracking Status page is blank.
  • You are unable to release blocked sessions and user names.

Workaround

To work around this issue, you can restart the Traffic Management Microkernel (TMM) process on all devices in the HA group. To do so, perform the following procedure:

Impact of workaround: Restarting the TMM process causes the BIG-IP ASM system to fail over to an HA peer.

  1. Log in to the Traffic Management Shell (tmsh).
  2. To restart the TMM process, type the following command:

    restart /sys service tmm

  3. Repeat steps 1 and 2 on the HA peer device.
