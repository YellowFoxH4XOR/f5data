Known Issue

When using passwordless client certificate authentication, the BIG-IP system bypasses the logon page and retrieves logon information from the client's certificate. Since the user did not enter their username and password, the session.logon.last.username session variable is not populated with the username information. As a result, when using passwordless client certificate authentication, the username in the Access Policy Manager reports will be blank.

F5 Product Development tracked this issue as ID 338149, and it has been fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.
