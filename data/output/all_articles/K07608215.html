Topic

You should consider using this procedure under the following condition:

  • You want users to establish a BIG-IP APM VPN access session before logging in to Windows.

Note: Windows logon integration does not work with TLS 1.3. For more information, refer to ID 1072901.

Description

In some environments, you want Windows users to establish a network access session before logging in to their Windows domain account.

The following procedure outlines how to configure the BIG-IP APM Connectivity/VPN profile and Customized Windows Client Package software download to automatically prompt Windows users to establish a network access session before accessing a Windows account on their Windows device when they select network login from the Windows log-in screen.

Prerequisites

You must meet the following prerequisite to use this procedure:

Note: The BIG-IP APM virtual server Client SSL profile must use a trusted SSL certificate.

  • You have configured your BIG-IP APM system with a network access profile and access policy for Network Access (VPN) connectivity. For more information, refer to the Configure Network Access Resources chapter of the BIG-IP Access Policy Manager Network Access manual.

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Procedures

  • Configure the network access BIG-IP Edge Client software download Dialup settings
  • Download the BIG-IP Edge Client package
  • Install the BIG-IP Edge Client on Windows devices
  • Log in to Windows (Windows Logon Integration)

To watch a video demo of these procedures, go to  Configure BIG-IP Edge Client to establish a network access session before logging in to Windows.

Configure the network access BIG-IP Edge Client software download Dialup settings

Perform the following procedure to configure the BIG-IP APM Connectivity/VPN profile and the BIG-IP Edge Client Customized Windows Client Package software download Dialup settings so that the BIG-IP system prompts Windows users to establish a network access session before logging in to Windows when the client software is installed on a Windows device.

Impact of procedure: Performing the following procedure allows Windows users to establish a network access session from their Windows device and reuse their user credentials to automatically log in to the Windows device and domain.

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity > Profiles.
  3. Select the profile name of the network access connectivity profile.
  4. Select Edit to edit the connectivity profile.
  5. Expand Win/Mac Edge Client and select the Reuse Windows Logon Session check box.
    Note: Beginning BIG-IP 17.5.0, expand Desktop Client Settings.
  6. Select the Allow Password Caching check box and for Save Password Method, select memory.

    Important: When Allow Password Caching is enabled, the user’s network access session and Windows domain credentials must be the same.

  7. Select Server List.
  8. Select Add.
  9. Enter an Alias name and the Host Name of the network access BIG-IP APM virtual server, then select Update.
  10. Optionally select Location DNS List for configuration, depending on your deployment requirements.
    Note: The Location DNS List requires additional configuration. The system considers DNS suffixes you add to the Location DNS List to be in the local or internal network (the destination network of the network access/VPN access session).The BIG-IP Edge Client uses these suffixes when the user selects Auto-Connect.
    When the BIG-IP Edge Client detects that it is on one of the configured (DNS) internal networks, it remains idle and does not attempt to establish a network access session. When the BIG-IP Edge Client detects that it is not on one of the internal networks (the local network does not match any of the networks configured in the Location DNS List) the it attempts to establish a network access session. For more information, refer to the BIG-IP Edge Client for Windows chapter of the BIG-IP APM BIG-IP Access Policy Manager: Edge Client and Application Configuration manual. For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.
  11. Select OK to save the connectivity profile configuration.

Download the BIG-IP Edge Client package

  1. Select the connectivity profile name.
  2. Select Customize Package > Windows in the list at the bottom of the page.
  3. For Available Components, select the following:
    • BIG-IP Edge Client
    • BIG-IP Edge Client COM API
    • Dialup Entry/ Windows Logon Integration
    • Component Installer Service
    • User Logon Credentials Access Service
  4. For BIG-IP Edge Client, optionally select Enable Always connected mode, depending on your deployment requirements.
  5. For Dialup Settings, enter a name for Dialup Entry / Windows Logon Integration > Phonebook Entry Name.
  6. Select the check boxes to enable Prompt Username and Password and Enforce Access Policy in Custom Dialer.
  7. Select Download to download the customized installer.

Install the BIG-IP Edge Client on Windows devices

Note: Administrative privileges may be required.

Note: If a previous install of the BIG-IP Edge Client software exists on the Windows device, use the Windows Control Panel to uninstall the software before continuing with the installation of the new BIG-IP Edge Client software.

Note: This creates a Windows Dial-up and VPN adapter using the name specified earlier.

Log in to Windows (Windows Logon Integration)

  1. After you install the BIG-IP Edge Client software, select switch user on the Windows device log-in screen.
  2. Select the network icon.
    • Network logon (Windows 7)
    • Network sign-in (Windows 8)
    • Networks or Network sign-in (Windows 10 and 11)

    Note: If the Network logon option does not appear on the Windows log-in screen, the feature may not be supported on your Windows version.

  3. Select the network adapter with the Phonebook Entry Name you configured earlier.
  4. Enter the user authentication credentials.

Note: If the BIG-IP Edge Client authentication pop-up window appears, re-enter the user authentication credentials.

Note: When the network access session establishes, the user is automatically logged in to Windows using the authentication credentials used to establish the network access session.
