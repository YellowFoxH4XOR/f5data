Description

  • When the "Inherit Parent Profile" in the FTP profile is disabled and the file transfer performed in the FTP passive mode, the idle timeout of the FTP data channel will be as follows: 
    • If the idle timeout of the TCP profile applied to the FTP virtual server is set to 301 seconds or more, the idle timeout of the FTP data channel will still be 300 seconds.
    • If the idle timeout of the TCP profile applied to the FTP virtual server is set to 300 seconds or less, the idle timeout of the FTP data channel will be the idle timeout set for the TCP profile.
  • When the "Inherit Parent Profile" in the FTP profile is disabled and the file transfer performed in the FTP active mode, the idle timeout of the FTP data channel inherits the TCP profile used by the control channel. 
  • When the "Inherit Parent Profile" in the FTP profile is enabled, the idle timeout of the FTP data channel inherits the TCP profile used by the control channel regardless of the file transfer mode.
  • Once data channel file transfer in any of the scenarios above, the idle time of the control channel will be 0 and will survive until the idle timer expires unless the control channel connection is closed.

Environment

  • Virtual server
  • FTP profile
  • TCP profile

Cause

None

Recommended Actions

  • If you prefer to set the idle timeout of FTP virtual server to 301 seconds or more, you will need to:
    • enable the "Inherit Parent Profile" in the FTP profile.
    • set the idle timeout of the TCP profile to your preferred value.
Important: The idle timeout value configured in the TCP profile will be used for both control channel and data channel.
