Description

K15858: How BIG-IP utilizes gratuitous ARP states "On devices where the Traffic Management Microkernel (TMM) starts before the interfaces are brought online, the BIG-IP system does not send gratuitous ARP requests for the non-floating self IP addresses." This article provides instructions on how to determine when tmm and interfaces become available identifying which platform this notes applies to.

Environment

  • BIG-IP
  • i7800
  • i10800

Cause

Functions as designed

Recommended Actions

Review log file /var/log/ltm after rebooting the BIG-IP system. The log entries indicating tmm start time "HA reports tmm ready" and interface start time "Link: x.x is UP". Reviewing times indicated will show if tmm started before interfaces became operational. The example below shows tmm starting before interfaces where operational, resulting in GARPs not being sent for non-floating self-ip addresses;

 

Sep 19 11:50:47 bigip.example.com notice sod[9204]: 01140044:5: HA reports tmm ready.

...

Sep 19 11:50:49 bigip.example.com info bcm56xxd[9983]: 012c0015:6: Link: 1.1 is UP
