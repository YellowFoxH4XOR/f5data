Description
When configuring BIG-IP VE in Google Cloud Platform (GCP) in order for Alias Addresses to failover between High Availability (HA) peers there must be a virtual address in the range of the alias.
 

Environment

  • BIG-IP VEs in HA pair
  • Google Cloud Platform
  • Failover configured via API

Cause
The failover script that controls the API failover compares Traffic Group failover objects to the Alias addresses to determine which GCP objects are moved

Recommended Actions

  1. Configure a virtual server in the Alias Address range for each Alias object you want to failover between the HA pair.
