Topic

You should consider using this procedure under the following condition:

  • You want to view CPU, memory, logical disk usage, or network interface stats for the BIG-IP system.

Description

The BIG-IP system administrator can use the iControl REST API to get quick system health statistics.

The information provided by API is intended for advance usage and may require extra formatting for presentation. Each of the commands that follow also include a TMOS Shell (tmsh) equivalent command that returns comparable results.

curl and jq utilities

Performing the following procedures requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems, but you can also install them on Microsoft Windows and Mac OS X systems. Additionally, you can perform these procedures from an alternate BIG-IP system. The use of jq to format the query output is optional but recommended for interactive viewing. For more information about the jq utility, refer to https://jqlang.org.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP system is licensed, provisioned, and configured with a management IP address.
  • You have administrative access to the BIG-IP Configuration utility.
  • You have command-line access to a system with the curl utility and, optionally, the jq utility installed. For more information, refer to the curl and jq utilities section in this article.

Procedures

  • System CPU and memory utilization
  • Detailed CPU utilization
  • Detailed memory utilization
  • Logical disk usage
  • Network interface statistics

System CPU and memory utilization

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to view the combined CPU and memory usage for the BIG-IP system:

    curl -sku admin:<password> -H "Accept: application/json" "https://<BIG-IP hostname or mgmt IP address>/mgmt/tm/sys/performance/system" | jq -r .entries

    For example, to view the combined CPU and memory usage on a BIG-IP system using the values from the Example configuration, enter the following command:

    curl -sku admin:testing -H "Accept: application/json" "https://LTM1.example.com/mgmt/tm/sys/performance/system" | jq -r .entries

    The output appears similar to the following truncated example:

    {

Logical disk usage

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to view the disk usage for the BIG-IP system:

    curl -sku admin:<password> -H "Accept: application/json" "https://<BIG-IP hostname or mgmt IP address>/mgmt/tm/sys/disk/logical-disk" | jq -r .items[]

    For example, to view the disk usage on a BIG-IP system using the values from the Example configuration, enter the following command:
