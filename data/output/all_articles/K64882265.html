Description
Increase throughput of BIG-IP Virtual Edition (VE) with add-on license using CLI to achieve your desired throughput.

Environment

  • BIG-IP VE
  • Base license key
  • Increase throughput
  • Add-on license
  • CLI

Cause
None

Recommended Actions
To increase the licensed throughput from the base throughput to a higher desired throughput, you need to acquire an add-on license for each throughput level between the base and the desired throughput.

Licenses are available for throughputs of 10 Gbps, 5 Gbps, 3 Gbps, 1 Gbps, 200 Mbps, or 25 Mbps. They are cumulative.
This is dependent on the SKU of the base license and what optional add-on modules are available in the BOM.

Verifying the total licensed throughput
You can view the throughput of each base and add-on license, and the total licensed throughput of BIG-IP VE system with the following command:
cat /config/bigip.license | grep 'perf_VE'

Example 1:
With a correct combination of base and add-on licenses:
#       LTM, 200 Mbps -1 Gbps Upgrade    perf_VE_throughput_Mbps 800  key ABCDEFG-ABCDEFG
#       LTM, 25 Mbps - 200 Mbps Upgrade  perf_VE_throughput_Mbps 175  key ABCDEFG-ABCDEFG
#       LTM, 25 Mbps, VE                 perf_VE_throughput_Mbps 25   key ABCDEFG-ABCDEFG
perf_VE_throughput_Mbps :     1000

With 25Mbps base + Upgrade from 25Mbps to 200Mbps (175Mbps) + Upgrade from 200Mbps to 1GB (800Mbps) : Total 1Gbps

Example 2:
With an incorrect combination of base and add-on licenses:
#       LTM, 200 Mbps -1 Gbps Upgrade  perf_VE_throughput_Mbps 800  key ABCDEFG-ABCDEFG
#       LTM, 25 Mbps, VE               perf_VE_throughput_Mbps 25   key ABCDEFG-ABCDEFG
perf_VE_throughput_Mbps :     825

With 25Mbps base + Upgrade from 200Mbps to 1Gbps (800Mbps) : Total 825Mbps
