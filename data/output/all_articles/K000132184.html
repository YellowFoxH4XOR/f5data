K000132184: No auto populated member IP address when adding FQDN node into pool

Type
Support Solution
Published
2023-07-11
Updated
2025-06-24
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000132184

Description

FQDN IP addresses for pool members are not auto populated or are not added when resource record for FQDN is modified on the DNS server that is used to resolve pool member IPs.

An error similar to the following may appear on LTM log:

01070734:3: Configuration error: Cannot enable pool member to autopopulate: node (/Common/<fqdn>) has autopopulate set to disabled.
​​​​​
Environment
  • FQDN pool member or node
  • FQDN "autopopulate" disabled
  • FQDN node previously used but had been created with default settings

Cause

Due to ID1077405, when a pool member has previously been created with autopopulate set to disabled, BIG-IP only allows creation of a single ephemeral node based on the first IP address from resource record in the DNS resolution response. This prevents the creation of node addresses even when a pool member was set with autopopulate enabled.
 

 Recommended Actions

  1. Delete FQDN pool member
  2. Delete related FQDN node and other FQDN nodes sharing IP address if they have autopulate disabled
  3. Re-add FQDN pool member with autopopulate enabled

Additional Information

1. Delete the FQDN template pool member and node using the following commands. Make sure to replace <affected_pool> with the actual pool name, <fqdn_pool_member_name> with affected pool member name, and <port> with actual pool member port.
 

tmsh modify ltm pool <affected_pool> members delete { <fqdn_pool_member_name>:<port> }

tmsh delete ltm node <fqdn_pool_member_name>

 

2. Verify that there are no other FQDN nodes sharing the same IP address. If there are, delete them as well and if attached to a pool use the commands in step 1 as a guide.
 

3. Recreate the FQDN template pool member using the following command, again, replace the variables with actual values:

tmsh modify ltm pool <affected_pool> members add { <fqdn_pool_member_name>:<port> { fqdn { autopopulate enabled interval ttl name <fqdn_pool_member_name> } }

This should automatically create the FQDN nodes based on records from DNS resolution response.
