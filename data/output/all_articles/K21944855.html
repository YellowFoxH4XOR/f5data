Issue

Error Message

011f0008:3: <current> - Invalid state transition to <pending>

In this error message, note the following:

  • <current> is the current processing state of the HTTP parser.
  • <pending> is the processing state to which the HTTP parser is transitioning.

For example:

011f0008:3: http_process_state_parse_header - Invalid state transition to ST_HTTP_ABORTED

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The HTTP parser in the BIG-IP system attempts to transition to a state that is incompatible with the current state during request processing.

The system typically generates this message when an iRule alters the normal connection flow in the Traffic Management Microkernel (TMM). For example, this error message may occur when a single HTTP request event in an iRule forcibly closes an active connection in TMM while attempting to redirect the request.

Impact

Depending on the conditions under which this error message is generated, the BIG-IP system may reset the active connection or may simply log a benign informational message.    

Recommended Actions

This message indicates an iRule negatively impacted the connection flow in TMM. You may need to enable additional logging in the iRule and examine the invalid state transition to determine the root cause.
