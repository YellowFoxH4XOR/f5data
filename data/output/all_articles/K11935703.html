Topic

You should consider using this procedure under the following conditions:

  • You want to disable the Windows prompts:
    • Did you mean to switch apps?
      "Microsoft Edge" is trying to open "F5 Networks Endpoint Inspector"
    • Did you mean to switch apps?
      "Microsoft Edge" is trying to open "F5 Networks VPN"
  • You are connecting to BIG-IP Network Access on Windows 10 using the F5 Helper Application

Description

When opening some endpoint checks with the Windows Edge browser, the Windows dialog  "Did you mean to switch apps?" dialog appears. This occurs because a protocol handler calls an external program from Windows Edge Browser. Clicking "Yes" will dismiss the dialog box and allow the action to proceed forward.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have sufficient administrative privileges to modify the Windows registry.
  • You have installed the F5 Helper Application on a Windows 10 client machine.

Procedures

  • Disabling warning for Endpoint Inspection
  • Disabling warning for Network Access

Disabling warning for Endpoint Inspection

The F5 Helper Application is needed for running Endpoint Inspection on a Windows client by way of a browser. This will result in a Windows prompt when switching apps.

Impact of procedure:

Make these changes at your own risk. Additionally, use the registry editor with extreme caution. If you make an error while editing the Windows registry settings, you can create issues that you can solve only by reinstalling the operating system.

  1. Log in to the Windows client system using an account with privileges to edit the registry for users on the system.
  2. Click the Start menu.
  3. In the Search field, type the following text and press Enter:

    regedit.exe

    Note: If User Account Control (UAC) is enabled, you may need to click Yes when prompted before the regedit utility opens.

  4. In the navigation pane of the regedit utility, click the icon to expand the HKEY_CURRENT_USER field.
  5. Click the icon next to Software.
  6. Click the icon next to Microsoft.
  7. Click the icon next to Internet Explorer.
  8. Click the icon next to ProtocolExecute.
  9. Right-click ProtocolExecute and select New > Key.
  10. When prompted to name the key, enter the following text:

    f5-epi

  11. Right-click the new f5-epi folder and select New > DWORD (32-Bit) Value.
  12. When prompted to name the DWORD, enter the following text:

    WarnOnOpen

  13. Press Enter
  14. Close the regedit utility
