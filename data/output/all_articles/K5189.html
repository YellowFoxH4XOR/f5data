K5189: The Configuration utility may refresh with information from another 3-DNS or BIG-IP when multiple browser instances are open

Known Issue

This is the result of a known issue. If you have more than one browser instance connected to different BIG-IP or 3-DNS Configuration utilities, and the Configuration utility attempts to perform a refresh, the wrong browser instance may be updated.

To avoid this problem, use only one Configuration utility at a time, or open separate windows in different browsers. For example, opening one window in Netscape and another in Internet Explorer will prevent this problem from occurring.

F5 Network Product Development tracked this issue as CR9333.
