Description

When discovering LTM  from the BIG-IQ the following error message is visible:

Error while transforming Self IP, the message 'Missing/empty parameter: partition' was returned

Environment

Relevant environmental factors specific to the topic

  • The subPath contains a '.' in it.
  • A curl request is made - adding BIG-IP to the BIG-IQ

Cause

Bug ID 846137

Recommended Actions

Performing software upgrade to the newest version non affected by Bug ID 846137.
