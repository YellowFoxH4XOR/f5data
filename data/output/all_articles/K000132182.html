Description

  • BIG-IP LTM SNAT translation address snat-translation has default idle timeout settings set to indefinite.
  • Sample configuration:
    [sysadmin@bigip1:Active:Standalone] config # tmsh list ltm snat-translation 192.0.2.150 all-properties
    ltm snat-translation 192.0.2.150 {
        address 192.0.2.150
        app-service none
        arp enabled
        connection-limit 0
        description none
        enabled
        inherited-traffic-group true
        ip-idle-timeout indefinite
        partition Common
        tcp-idle-timeout indefinite
        traffic-group traffic-group-1
        udp-idle-timeout indefinite
        unit 1
    }

Environment

  • LTM SNAT configuration
  • LTM Global SNAT configuration
  • LTM SNAT pool configuration

Cause

Default idle timeout settings are by design.

Recommended Actions

When configuring SNAT, Global SNAT or SNAT pool ensure to modify all related snat-translation addresses timeout settings. Leaving settings as default will cause connections which are not gracefully terminated to remain in the connection table indefinitely. 

Important: Connections left in the connection table indefinitely use memory which may lead to memory exhaustion.

Modify snat-translation address timeout values as below:
tmsh modify ltm snat-translation 192.0.2.150 { ip-idle-timeout 120 tcp-idle-timeout 300 udp-idle-timeout 60 }
tmsh save sys config

Additional Information

With the idle timeout set to Indefinite, the BIG-IP system internally limits UDP and IP SNAT translation idle timeout periods to a maximum of 300 seconds. The system sets TCP SNAT translation idle timeout periods to 2^32 or 4294967296 seconds (49710 days/136 years).
