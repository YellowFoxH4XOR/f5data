Description

Below warning message in /var/log/daemon.log

   warning sflow_agent[(PID)]: AgentX master agent failed to respond to ping.  Attempting to re-register
   warning rmonsnmpd[(PID)]: AgentX master agent failed to respond to ping.  Attempting to re-register.

Environment

  • BIG-IP
  • snmp

Cause

These warning messages are logged when the connection between snmpd master agent on the BIG-IP and its sub-agents, rmonsnmpd and sflow, was interrupted for some reason.
These warning messages should not have any impact the traffic processing.
This could potentially indicate that either snmpd or system in whole was too busy to allocate the required CPU cycles to snmpd at the time therefore snmpd did not responds to its sub agents within expected timeout.

Recommended Actions

If these warnings occur at high frequency please check the followings when the warnings are generated:

  • Total system CPU usage and more specifically snmpd is not higher than normal
  • Verify if /var/core contains a recent core file including snmpd as this could have information to explain why snmpd experienced an error
  • Verify the status of the snmp and sflow services to be up and running with the following Bash syntax:
    tmsh show sys service | egrep -i 'snmp|sflow'

Additional Information

On Virtual Edition platforms, rmonsnmpd service does not exist therefore the warning only reported by sflow_agent.
