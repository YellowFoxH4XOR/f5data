K50532179: How to customize the BIG-IP tmsh cli or bash shell prompt to display FQDN

Source

Description

You want to use the FQDN for the BIG-IP tmsh cli or bash shell prompt rather than the default hostname.

For example, your default bash prompt message may look like this:

[root@bigip:Active:Standalone] config #

You want to customize it using the FQDN like below:

[root@bigip.exmple.com:Active:Standalone] config #

Environment

  • BIG-IP LTM
  • tmsh cli
  • Bash prompt
  • FQDN

Cause

None

Recommended Actions

For bash cli prompt, you may achieve this goal by appending the following scripts to ~/.bash_rc

# This will customize the shell prompt status by using a FQDN for the host. 
if [ "$PS1" ]; then
  if [ -z "$PROMPT_COMMAND" ]; then
    case $TERM in
    xterm*|vte*)
      PS1='[$USER@$(getFqdn):$(getPromptStatus)$(getAvcCount):$(getConfigSyncStatus)]\[\e]0;$(getHostName)\a\] \W \$ '
      ;;
    screen*)
      PS1='[$USER@$(getFqdn):$(getPromptStatus)$(getAvcCount):$(getConfigSyncStatus)] \W \$ '
      ;;
    *)
      PS1='[$USER@$(getFqdn):$(getPromptStatus)$(getAvcCount):$(getConfigSyncStatus)] \W \$ '
      ;;
    esac
  fi
  # Turn on parallel history
  shopt -s histappend
  history -a
  # Turn on checkwinsize
  shopt -s checkwinsize
  [ "$PS1" = "\\s-\\v\\\$ " ] && PS1="[\u@\h \W]\\$ "
  # You might want to have e.g. tty in prompt (e.g. more virtual machines)
  # and console windows
  # If you want to do so, just add e.g.
  # if [ "$PS1" ]; then
  #   PS1="[\u@\h:\l \W]\\$ "
  # fi
  # to your custom modification shell script in /etc/profile.d/ directory
fi

Note: This script will only take effect by the user you logged in to and you may  need relogin for the script to take effect. It will not be synced between HA clusters and it will not be delivered to the new version when you are doing an upgrade.

For tmsh cli, you may follow the below step:

  1. Log in to tmsh by entering the following command:
    tmsh

  2. To modify the tmsh cli to display the FQDN, use the following command syntax:
    modify cli preference prompt { fully-qualified-host }

  3. Save the configuration by entering the following command:
    save /sys config

Note: CLI preference settings are configurable on a per-user basis
