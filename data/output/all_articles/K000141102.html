Description

When uploading the ISO image, you receive the following error message:

  • Upload Error
  • No Space left on device
  • Progress failed

Environment

  • BIG-IP
  • vCMP guest upload

Cause

  • By default, the ISO image is uploaded to the /shared/images directory on the root filesystem.
  • The partition or logical volume has insufficient free space to accommodate the ISO file. 

Recommended Actions

  • Remove any unnecessary or unwanted files on the root filesystem to free up space if full - K11176458: 011d0004:3: Disk partition / (slot #) has only 0% free space
  • If the error persists, resize the logical volume to allocate more space to the root directory - K14952: Extending disk space on BIG-IP VE
