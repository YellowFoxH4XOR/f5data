Known Issue

This is the result of a known issue. When a delay of several minutes occurs between logging requests, and then a request is successfully sent to the remote logger, an error message may be logged to the /var/log/bd.log file that appears similar to the following example:

BD_MISC|ERR LoggingAccount.cpp:1050|remote log write FAILED res = -3 handle=-1279262864 buffer to write: "Illegal HTTP status in response","500","GET","/" len: 49 Removing remote logger

F5 Networks Product Development is tracking this issue as CR136715.

This issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
