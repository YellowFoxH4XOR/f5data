Known Issue

This is the result of a known issue. In BIG-IP 10.2.0 HF2, the qkview utility does not collect all necessary MCP database objects.

While this issue does not affect the normal operation of the unit, if you upload a qkview to the iHealth website, some information about the BIG-IP system may not be displayed. In addition, some iHealth diagnostics may not run properly.

For example, the iHealth website will not display module licensing and provisioning details for qkviews generated on BIG-IP 10.2.0 HF2.

F5 Product Development tracked this issue as ID 341460, and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.
