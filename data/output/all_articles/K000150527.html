Environment

LTM

Cause

The file dead.letter is consuming the /root directory. The dead.letter file found in the root directory is a standard file created by Unix-like operating systems (including the underlying OS of F5 BIG-IP devices) when an email message sent from the system cannot be delivered. This typically happens when a process or user tries to send an email (for example, system notifications, cron job outputs, or alert messages)

Recommended Actions

To fix the immediate issue of configuration file not loading, move the dead.letter file on the root directory to /var/tmp.

1. Login to BIGIP CLI.
2. Enter commands.
      bash
      mv /root/dead.letter /var/tmp
3. Try loading the config again.
      tmsh load sys config 
4. After services are back, check on the details on dead.letter for any issue why logs are written to it.
