K84277028: How to use Putty.exe to save serial console output to a file

Type
Support Solution
Published
2019-10-22
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K84277028

Description

You can administer a BIG-IP system by using a null modem cable to connect a management system that runs a terminal emulator program (Putty) to the BIG-IP serial port. 

Environment

  • You need to collect serial console output for self-analysis or as requested by F5 Technical Support.

Cause
None

Recommended Actions

Configure Putty.exe to save serial console output to a file

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open putty by double clicking on the Putty.exe application file
  2. Click on Session > Logging
    • Select Printable Output
    • Change the name of the output file as necessary and browse to the preferred storage location
    • Select Serial and verify serial settings
      See K7683: Connecting a serial terminal to a BIG-IP system for more information.
  3. Click on Open

Now Putty will save the serial console output to a file.

Additional Information
Depending on which BIG-IP® system you have, you can use either the supplied RJ45 to DB9 console port cable, serial console cable, or the RJ45F to RJ45M rolled serial adapter to connect the system to a serial console server.
