Issue

Old Behavior

In versions prior to BIG-IP 12.1.0, you can force a specific device group member to initiate a configuration synchronization (ConfigSync) operation. You do this to make a device group member with an older configuration synchronize its configuration to devices with a newer configuration. The set-sync-leader command temporarily designates a specific device group member as the synchronization leader and forces the device to initiate a one-time ConfigSync operation.

New Behavior

Beginning in BIG-IP 12.1.0, the force-full-load-push command option sets the current device as synchronization leader, and forces the current device to initiate a ConfigSync operation to the device group. This command option provides more simplicity since it's included as an option for the tmsh run cm config-sync command as opposed to a property configured for a device.

F5 Product Development tracked this change as ID 487538.

Impact

You may lose configurations on other devices in a device group if you use the force-full-load-push command to force the current device to initiate the ConfigSync operation to the group. For example if the device group member that is initiating the ConfigSync has an older configuration.

Recommended Actions

Forcing a current device to initiate a one-time ConfigSync operation

Impact of procedure: The force-full-load-push command option forces the device to initiate a one-time ConfigSync operation to the device group. You may lose configurations on other devices after the ConfigSync operation. The command is not persistent, and must be re-run for every attempt to initiate the ConfigSync process from a device with an older configuration.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To set the device as the synchronization leader of the device group and force the device to initiate the ConfigSync process, use the following command syntax:

    run cm config-sync force-full-load-push to-group <group name>

    For example, to force a full-load ConfigSync operation from the current device to the MyDeviceGroup device group, type the following command:

    run cm config-sync force-full-load-push to-group MyDeviceGroup
