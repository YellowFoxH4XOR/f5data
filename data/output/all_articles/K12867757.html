Known Issue

F5 VPN and endpoint inspection applications may exit on Linux clients with Qt 5.10.1 or later installed.

This issue occurs when all of the following conditions are met:

  • You use a Linux client to connect to the BIG-IP APM system.
  • The Linux client system is running Qt 5.10.1 or later.

Impact

You are unable to establish a network access session to the BIG-IP APM system. Client endpoint inspection fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The F5 VPN application exits prematurely when using Linux clients.
  • The client endpoint inspection application exits prematurely when using Linux clients.
  • Linux users are unable to establish network access sessions.
  • Users are presented with a pop-up window indicating that the version of Qt needs to be later than 5.5.

Resolution

Status

F5 Product Development has assigned ID 710407 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can install Qt 5.9.0 or lower on the Linux client system. For more information, refer to the documentation for your distribution.
