Known Issue

The BIG-IP GTM system may fail to verify virtual server availability. This issue occurs when all of the following conditions are met:

  • The Verify Virtual Server Availability global setting is disabled.
  • The Verify Virtual Server Availability setting is enabled for the BIG-IP GTM pool.

The Verify Virtual Server Availability feature forces the BIG-IP GTM system to verify the availability of the virtual servers or the members of a resource pool before using the resource. The Verify Virtual Server Availability feature is configured in the BIG-IP GTM Global Settings and in the BIG-IP GTM pool properties.

The Verify Virtual Server Availability global setting and BIG-IP GTM pool setting are both enabled by default. However, when the global setting is disabled, the BIG-IP GTM pool setting is not honored.

Impact

The BIG-IP GTM system may provide name resolution records for an unavailable resource.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP GTM system may provide name resolution records for an unavailable resource.

Workaround

To avoid the issue, you may enable the Verify Virtual Server Availability global setting and enable or disable the Verify Virtual Server Availability at the BIG-IP GTM pool level as desired.

Impact of workaround: None.

Enabling the Verify Virtual Server Availability global setting

Using the BIG-IP Configuration utility

BIG-IP GTM 11.5.0 and later

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to DNS > Settings > GSLB > Load Balancing.
  3. Select the Verify Virtual Server Availability check box.
  4. Click Update.

BIG-IP GTM 10.x through 11.4.1

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to System > Configuration > Global Traffic > Load Balancing.
  3. Select the Verify Virtual Server Availability check box.
  4. Click Update.

Using the Traffic Management Shell (tmsh) utility

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh
  2. Enable the Verify Virtual Server Availability global setting by typing the following command:

    modify /gtm global-settings load-balancing verify-vs-availability yes
  3. Save the changes by typing the following command:

    save sys config
  4. To exit the tmsh utility, type the following command:

    quit

Modifying the Verify Virtual Server Availability setting for a particular BIG-IP GTM pool

Using the BIG-IP Configuration utility

BIG-IP GTM 11.5.0 and later

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to DNS > GSLB > Pools.
  3. Select the target pool name and change the configuration to Advanced mode.
  4. Change the setting for Verify Virtual Server Availability as desired.
  5. Toggle the setting for Verify Virtual Server Availability by selecting (to enable) or clearing (to disable) the check box.
  6. Click Update.

BIG-IP GTM 10.x through 11.4.1

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Global Traffic > Pools.
  3. Select the target pool name and change the configuration to Advanced mode.
  4. Change the setting for Verify Virtual Server Availability as desired.
  5. Toggle the setting for Verify Virtual Server Availability by selecting (to enable) or clearing (to disable) the check box.
  6. Click Update.

Using the Traffic Management Shell (tmsh) utility

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh
  2. Modify the Verify Virtual Server Availability setting on the BIG-IP GTM pool properties as required.

    To enable the setting, use the following command syntax:

    modify /gtm pool <gtm-pool-name> verify-member-availability enabled

    To disable the setting, use the following command syntax:

    modify /gtm pool <gtm-pool-name> verify-member-availability disabled

    For example, to disable the Verify Virtual Server Availability setting on the BIG-IP GTM pool properties for a pool named eg_pool, you would type the following command:

    modify /gtm pool eg_pool verify-member-availability disabled
  3. Save the changes by typing the following command:

    save sys config
  4. To exit the tmsh utility, type the following command:

    quit
