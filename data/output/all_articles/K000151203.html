K000151203: Brute Force violations in event logs show "NaN" for Enforcement Action, Detection Period and Maximum Prevention Duration

Description

Brute Force violations in event logs show "NaN" for Enforcement Action, Detection Period and Maximum Prevention Duration

Environment

  • Advanced WAF provisioned.
  • Advanced WAF policy with Brute Force configured.

Cause

The values of Enforcement Action, Detection Period and Maximum Prevention Duration will return "NaN" (not a number) when the violation details exceed the maximum message size we can store in the protobuf.

Recommended Actions

Consider increasing the max_protobuf_data_msg_size. The below command doubles the size.

  • Restarting ASM will impact traffic and cause a failover if the device is in an active state.
  • Monitor disk space and memory usage after making a change to the DB variable below.

# /usr/share/ts/bin/add_del_internal add max_protobuf_data_msg_size 102400 --default 51200

# bigstart restart asm
