Issue

Error Message

<daemon[pid]> <error_code> Certificate with subject <subject> from issuer <issuer> is revoked

In this error message, note the following:

  • <daemon[pid]> is the daemon that logged the error message and the associated process ID.
  • <error_code> is the error code associated with the message.
  • <subject> is the entity or organization to which a certificate belongs.
  • <issuer> is the entity that verified the information and signed the certificate.

For example:

  • When the gtmd process logs the message, the error appears similar to the following:

    gtmd[18283]: 011ae20b:4: Certificate with subject C = US, ST = WA, L = Sea, O = F5, OU = KS, CN = BIGIP-A from issuer C = US, ST = WA, L = Sea, O = F5, OU = ES, CN = BIG-IP Certificate is revoked.

  • When the big3d process logs the message, the error appears similar to the following:

    big3d[18281]: 012b310b:4: Certificate with subject C = US, ST = WA, L = Sea, O = F5, OU = KS, CN = BIGIP-A from issuer C = US, ST = WA, L = Sea, O = F5, OU = ES, CN = BIG-IP Certificate is revoked.

In addition, the system may log error messages to the /var/log/gtm file indicating the iQuery connection to the remote host has failed. The error messages may appear similar to the following:

011a500c:1: SNMP_TRAP: Box 192.0.2.10 state change green --> red (Unavailable)
011a5004:1: SNMP_TRAP: Server /Common/BIGIP-A (ip=192.0.2.10) state change green --> red (No communication)
012b310f:3: Unable to reverify the iQuery connection to ::ffff:192.0.2.10:47134: Cannot verify the peer certificate.

Message Location

You may encounter this message in the following locations:

  • The /var/log/gtm file

Description

This message occurs when the following condition is met:

  • The SSL certificate used for iQuery communication is revoked.

Starting in BIG-IP 16.x, you can configure the system to check for revoked SSL certificates for components that use the iQuery communication mechanism, such as BIG-IP DNS synchronization.

Impact

The BIG-IP system rejects remote iQuery connections.

Recommended Actions

  • Replace the BIG-IP system's device certificate with a new certificate authority- (CA-)signed or self-signed device certificate.
