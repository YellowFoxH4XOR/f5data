K78135108: Constant High CPU usage on core 0 and core 1

Type
Support Solution
Published
2020-06-24
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K78135108

Description

  • High CPU usage on first two cores.
  • Low usage on the rest of available cores
  • Degraded performances reports from end-users on published websites on LTM.

Environment

  • BIG-IP VE with 8 cores allocated.
  • BIG-IP VE deployed on Cloud environment.

Cause

Seen behaviour is expected. Despite having 8 available cores, the license is limiting the VE to just 2 tmm cores.

Recommended Actions

If you wish to utilize the rest of the allocated cores then you will need to upgrade the license as per K14810.

Additional Information

You can confirm BIG-IP VEs core license limit running the following command.

tmsh show /sys license detail | grep "perf_VE_cores"

The output will be similar to:

perf_VE_cores [2]

Where [2] is the number of cores limit by the license
