K8468: Customized Portal Access error page for denied URLs

Topic

Starting in FirePass version 6.0.2, you can configure a customized error page to be returned to users when a requested web page is denied by a Portal Access access control list (ACL). A web page may be denied if its URL is not included in the respective Portal Access Allow List, or if its URL is included in the respective Portal Access Deny List. For more information about configuring ACLs, refer to the FirePass Controller Getting Started Guide.

Before configuring a customized error page, WebDAV customization must be enabled in the FirePass controller. For more information about enabling WebDAV customization, refer to K4440: Overview of WebDAV.

To configure a customized error page, create an HTML page named exception.inc. You may optionally include one or more of the following variables in the HTML source code:
  • %F5_MSG_TITLE%
    The %F5_MSG_TITLE% variable contains the title of the error message.
  • %F5_MSG%
    The %F5_MSG% variable contains the text of the error message.
  • %F5_URL%
    The %F5_URL% variable contains the URL that the user attempted to access.

Once you have created the exception.inc page, upload it to the FirePass WebDAV sandbox. For more information about uploading files to the WebDAV sandbox, refer to K4440: Overview of WebDAV.

A basic customized error page will appear similar to the following example:

<HTML>
<BODY>
<H1>Custom error page</H1>
<H3> %F5_MSG_TITLE% </H3>
<P>Error message: %F5_MSG%</P>
<P>URL: %F5_URL%</P>
</BODY>
</HTML>

Using the example above, if a user attempted to access http://www.gmail.com through Portal Access, but www.gmail.com was denied by a Portal Access ACL, FirePass would return a web page similar to the following example:

Custom error page

Security exception

Error message: Your administrator has not allowed access to this URL.

URL: http://www.gmail.com/

For more information about WebDAV customization, including additional customizable error pages, refer to the Device Management: Customization: Global: Advanced WebDAV customization section of the FirePass online help.
