Topic

  • K14947: The BIG-IP Edge Client components for Mac OS X
  • K10407: The FirePass client components

Summary

BIG-IP Edge Client for Windows comprises individual components that provide Windows log on integration, endpoint protection, client inspection, and network and application access.

Description

BIG-IP Edge Client for Windows comprises several services that the client provides and, in turn, each service comprises individual components. These components work together to create the services that the client uses to access the BIG-IP APM system. These services include Windows log on integration, endpoint protection, client inspection, and network and application access. The following table displays the major services that BIG-IP Edge Client provides, and individual components that compose the service. A description of each component follows the table.

You can view the installed services and components on a client system by using the Client Troubleshooting Utility (CTU), which you can download from the BIG-IP Configuration utility. For more information on the CTU, refer to K12444: Overview of the Client Troubleshooting Utility for Windows.

Note: You cannot install all components on a client system. The BIG-IP APM or Edge Gateway administrator can customize the BIG-IP Edge Client to exclude certain services.

Component Function Details

InstallerControl

This component installs other F5-signed components onto the system. The InstallerControl component is used for cases when the SuperHost client component attempts a version upgrade, but the user rights assigned to the component are insufficient. This component is not required for day-to-day operations, but it does help when you encounter the following situations:

  • Upgrades are presented to the client and the Windows User Account Control (UAC) is enabled.
  • The user does not have local administrator rights.
  • The web browser runs as a non-administrator.

SuperHost

This component creates a unified user interface for Application Tunnel and VPN webifyers. All user interfaces are made on DHTML with JavaScript. The SuperHost control also allows several VPN/Application Tunnel sessions in one window. This component also checks versions against the host control and checks versions to perform upgrades.

Host

This component downloads, installs, and upgrades other modules, initializes and controls execution, and displays messages to the user. The host control is implemented as a self-installed browser component plugin for compatible browsers, and ActiveX in Windows.

InspectionHost

This component handles pre-logon inspection-related features, such as file checks and operating system product and version queries.

VPN

This component manages the BIG-IP APM VPN adapter and initializes the VPN adapter. The VPN component is also responsible for modifications in the local client routing table according to the split tunneling setting. The VPN component is responsible for policy enforcement, including checking for certain processes and monitoring routing table changes. If the VPN component encounters changes in the local routing table, the component attempts to restore the routing table. If this configuration is not possible, the VPN component terminates the session. The VPN component also manages the local proxy autoconfiguration script, set by the client's local proxy configuration.

TunnelServer

This component handles the Secure Sockets Layer (SSL) connection between the BIG-IP APM system and the client for Application Tunnel and Network Access connections. The TunnelServer component creates a local TCP socket so that it can communicate with the VPN driver. The TunnelServer component then proxies communication back to the BIG-IP APM system.

Protected Workspace

This component manages Protected Workspace desktop sessions on the client. This feature is deprecated and no longer supported. For more information, refer to K43204221: BIG-IP APM Windows Protected Workspace is deprecated.

Win32 Inspector

This component handles Windows-specific pre-logon inspection-related features, such as registry checks, file checks, and other Windows-specific checks.

OPSWAT Libraries

This component is the OPSWAT Antivirus and Firewall inspector, which allows the BIG-IP APM system to collect and analyze the antivirus and firewall configuration of the client system. This collected information includes the vendor and version of the antivirus and firewall software; it also indicates the last time that the system underwent updates and scans. The following lists some of the files installed:

  • BIG-IP 14.x and later: f5OesisInspectorCom4.dll
  • BIG-IP 13.x: wa*.exe, libwa*.dll, f5OesisInspectorCom.dll

Machine Certificate Checker

This component accesses the local machine certificate and sends this information to the BIG-IP APM system for inspection.

Cache Cleaner

This component purges information that was cached by the client during the clients session, including the web history for URLs accessed through the BIG-IP APM system and the cookies associated with URLs accessed through the BIG-IP APM system. The cache is purged when the client logs out of the session or the browser window (if the BIG-IP APM system is accessed through a web browser).

Windows Group Policy

This component applies a group policy template assigned by the BIG-IP APM access policy to the client system.

Inspector Service

This component installs and registers a Windows service that supports OPSWAT Endpoint inspection with escalated privilege (Administrator).

Custom Dialer

This component integrates the BIG-IP Edge Client VPN service to the Windows log on service. This allows a BIG-IP APM VPN session to be established prior to Windows logon.

Component installer

This component installs and registers a Windows service that installs F5-signed components onto the system.

BIG-IP Edge Client for Windows

This is the Windows executable that the user runs to start the BIG-IP Edge Client standalone.

Machine Tunnel Service

This component installs and registers a Windows service that provides the client side support for Machine Tunnels. For more information on the machine tunnel feature, refer to the About machine tunnels for Windows section of the BIG-IP Edge Client for Windows chapter in the BIG-IP Access Policy Manager: Edge Client version 7.1.7 and Application Configuration manual. 

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation. 

BIG-IP Edge Client COM API

This component is the API interface for the BIG-IP Edge Client. This allows third-party applications to use the BIG-IP Edge Client SDK to access the BIG-IP Edge Client VPN services.

DNS Relay Proxy

This component is an optional Windows-based service that assists in routing DNS requests to the appropriate DNS server. For more detail on the DNS Relay Proxy, refer to K9694: Overview of the Windows DNS Relay Proxy service.

Traffic Control

This component manages directing and shaping the network traffic that is defined by the Client Traffic Classifiers in the network access resource.

BIG-IP Edge Client installation and updates

When you configure the BIG-IP APM or Edge Gateway systems for endpoint inspection, and the user accesses the system, required plug-ins automatically instruct the client browser or existing Edge Client application to install or update the BIG-IP Edge Client components. The system installs and updates the components based on the connectivity profile settings of the BIG-IP APM or Edge Gateway system and the current revision levels of the installed components. For more information, refer to K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows and Mac OS.
