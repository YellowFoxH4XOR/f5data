K90345533: Accept Request does not have any effect on policy

Type
Support Solution
Published
2022-02-25
Updated
2023-02-21
Applies to

  • BIG-IP ASM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K90345533

Description

When accepting a request in the Configuration utility in Security > Event Logs : Application > Requests for a triggered violation that states "No suggestion available", the accept action does not have an effect on the security policy.

Environment

  • ASM
  • Event logs

Cause

This is an expected behavior. 
When there is no Traffic Suggestions generated clicking  the "Accept" button will take no action.

Recommended Actions

None

Additional Information

None
