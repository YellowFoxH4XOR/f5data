K000159025: Attempts to set the primary-key on an F5 VELOS fails with error

Type
Support Solution
Published
2026-01-08
Updated
2026-01-08
Applies to
  • F5OS
  • F5OS-C: 1.8.1
Source
https://my.f5.com/manage/s/article/K000159025

Description When

  •  Attempting to set the primary key on an F5OS-C (VELOS) system, the key migration process fails with one of the following statuses:

     system aaa primary-key state status "RECOVERY_RESTORE_KEY_FAILED"
     system aaa primary-key state status "ABORTED Initiated: <timestamp>"

  • The following error messages appear in the velos.log:

    confd-key-migrationd[9]: nodename=controller-1 priority="Err" version=1.0 msgid=0x1b01000000000010 msg="Failed to set element in cdb" path="/system/ntp/ntp-keys/ntp-key{12}/state/key-value" error="" errno="Interrupted system call".
    |
    confd-key-migrationd[9]: nodename=controller-1 priority="Crit" version=1.0 msgid=0x1b01000000000002 msg="Key Migration failed, attempting to restore" stage="RESTORE_SECURE_ELEMENTS".

Environment

  • F5 VELOS CX410 platform.
  • F5OS-C software version 1.8.1
  • NTP key is configured.

Cause

ID2037233

Recommended Actions

  • Remove the NTP key from the configuration.
  • Perform the key migration.
  • Re-add the NTP key to the configuration.

Additional Information

None
