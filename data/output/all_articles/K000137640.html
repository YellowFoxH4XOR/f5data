K000137640: [F5OS-C] Velos: Tenant failing to load after upgrade

Type
Support Solution
Published
2023-11-21
Updated
2023-11-21
Source
https://my.f5.com/manage/s/article/K000137640

Description

After upgrade, the tenant is unable to start and you see the following error:


0/X nodes are available: X Insufficient devices.kubevirt.io/kvm, X Insufficient devices.kubevirt.io/tun, X Insufficient devices.kubevirt.io/vhost-net, X Insufficient hugepages-2Mi, X node(s) didn't match node selector, X Insufficient f5.com/qat."


Environment

F5OS-C

Velos

Tenant Deployment

Cause

Base OS and Service versions are mismatched

Recommended Actions

Please ensure OS and service software versions match. This can be done by going to the chassis partitions page and setting the partition image for that partition to an ISO image using the Bundled option. The alternative would be to use the Unbundled option setting both the Base OS version and Service version to the same version.
