Description
Packet filter has been configured to block port 443 on self-ip address.
Connectivity toward virtual server which having same ip address as that self-ip is affected.
 

Environment

  • BIGIP
  • Self-ip
  • Virtual Server
  • Packet filter

Cause

  • Packet filter has been configured to block port 443 on self-ip address.
  • Self-ip address and virtual server having same ip and same port number.


(tmos)# list net self ex-self-1 { address };list ltm virtual { destination };list net packet-filter;list sys db packetfilter
net self ex-self-1 {
    address 10.201.31.160/16
}
ltm virtual VS_1 {
    destination 10.201.31.160:https
}
net packet-filter DENY_1 {
    action reject
    logging enabled
    order 10
    rule "( dst net 10.201.31.160/32 ) and ( dst port 443 )"
}
sys db packetfilter {
    value "enable"
}

  • /var/log/pktfilter showing the packet has been rejected.
reject on /Common/ex, len: 74 [IPv4 60 10.201.31.165 -> 10.201.31.160 TCP 33801 -> 443 S]
 

Recommended Actions

  1. Disable packet filter
  2. If packet filter not able to be disabled, have to update the source ip to be allowed in the configuration of packet filter, such as below, to allow 172.16.0.0/12 subnet. 
    • net packet-filter ALLOW_1 {
    action accept
    logging enabled
    order 5
    rule "( src net 172.16.0.0/12 ) and ( dst net 10.201.31.160/32 )"
}
