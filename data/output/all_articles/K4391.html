Topic

You can use uppercase or lowercase letters for a class name; however, the BIG-IP configuration is case sensitive. When you use a class name in a configuration, you must use the same case that you used when it was created. This is particularly true when you configure a node select expression, because the Configuration utility will not prevent you from entering the name of a class that does not exist. In this event, the class will not be found and the feature that uses the specified class will fail.
