Known Issue

In rare conditions, the mcpd process may stop responding and produce a core file when a password is changed.

This issue occurs when the following condition is met:

  • You attempt to change the password for a nonexistent user.

Impact

If the BIG-IP system is a member of a redundant configuration, traffic may fail over to the standby BIG-IP system. If the BIG-IP system is not part of a redundant pair, traffic may be interrupted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • An mcpd core file appears in the /shared/core directory.
  • Errors similar to the following example appear in the /var/log/ltm file:

    info sod[7041]: 010c0009:6: Lost connection to mcpd - reestablishing.
    err lacpd[7275]: 01160004:3: MainEventHandler.cpp:103 - MCP connection lost
    err snmpd[6326]: 010e0001:3: Cannot connect to MCPD server.
