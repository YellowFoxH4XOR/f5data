Description

The vCMP host can not get the status information from the vCMP guests

  • Guest status of the affected guest is not populating in Configuration Utility
  • A vCMP guest cannot access software images and hotfix ISOs from the host.

Environment

  • vCMP is provisioned
  • Configuration Utility has redirect-http-to-https is enabled.

Cause

The issue is caused by Bug ID 793121

Recommended Actions

Upgrade affected vCMP guest to a fixed version. Please see Bug ID 793121 for more details

This issue can be worked around by disabling the redirect-http-to-https setting with the following command;

  1. Log in to the TMOS shell (tmsh) by typing the following command:
    tmsh
  2. Type the following command:
    modify sys httpd redirect-http-to-https disabled
  3. Save the configuration by typing the following command:
    save /sys config
    NOTE: This will need to be done on both systems if your system is part of a HA pair.
