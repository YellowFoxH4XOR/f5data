K45627439: A license reactivation must be performed prior to upgrading BIG-IQ 5.1.0 managed systems with extended service contracts

Topic

When you use BIG-IQ 5.1.0 as a license manager, and you plan to upgrade the software for a managed BIG-IP system with an extended service contract, you must first reactivate the BIG-IP system license.

Description

When you upgrade the BIG-IP system software, a license check date enforcement is applied during system startup. The system compares the license check date (LCD) to the service check date (SCD) in the license file to ensure that the system has a valid service contract. If your BIG-IP system has an extended service contract, the license must be reactivated prior to performing the software upgrade from the BIG-IQ system.

  1. Log in to the BIG-IQ Configuration utility.
  2. Find the license or license pool from which the BIG-IP system is licensed.
  3. Reactivate the registration key or license pool to get the updated SCD.
  4. License the BIG-IP system.
  5. Upgrade the BIG-IP system software.

Follow the licensing procedures found in the License Management section of the BIG-IQ Centralized Management: Device guide.
