K000156966: Spam email "Stats processing delay" from BIG-IQ

Type
Support Solution
Published
2025-11-02
Updated
2025-11-02
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000156966

Description

You are receiving spam email with subject "Stats processing delay" from BIG-IQ.

Environment

  • BIG-IQ

Cause

BIG-IQ CM has not selected a NTP server to with with.

# ntpq -pn

 remote           refid      st t when poll reach   delay   offset  jitter
==============================================================================
192.0.2.10     203.0.113.20   3 u  645 1024  377    0.324   -9.384   6.368

For example in above NTP server 192.0.2.10, * is missing from it.

Recommended Actions

restart ntpd in BIG-IQ CM.

# tmsh restart /sys service ntpd

Verify if BIG-IQ CM selected NTP server to sync with. You should see * in the selected server. For example as shown below:

# ntpq -pn

     remote           refid      st t when poll reach   delay   offset  jitter
==============================================================================
*192.0.2.10    203.0.113.20   3 u   80 1024  377    0.683  -11.612   6.853
