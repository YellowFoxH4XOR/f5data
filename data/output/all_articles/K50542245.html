K50542245: Using Edge client for MAC/Mojave may result in PingFederate IDP error

Source

Description

Certain versions of Mac Mojave and Safari result in PingFederate idp error jOFhv3lPV9 when using the edge client

Environment

Relevant environmental factors specific to the topic

  • Client running Mac OS X Mojave 10.14.4 (and Mojave 10.14.6)
  • Client running Safari v12.x
  • Any version of edge client for MAC

Cause

This is not an F5 bug, but an Apple webkit bug:

https://bugs.webkit.org/show_bug.cgi?id=198181

The issue is the PF= cookie issued by a PingFederate identity provider is not retained properly during the initial communication, therefore this provider is not able to identify the clients session for subsequent calls and returns an error instead of a proper logon prompt.

"Cookies specifying `SameSite=None` or sending an invalid value, e.g. `SameSite=nonsense` appear to be treated as `Strict` and are therefore not being sent with cross-site requests as intended."

Recommended Actions

Upgrade Safari past v12.x to 14.0 by installing macOS Supplemental Update 10.14.6 and Security Update 2020-004.
