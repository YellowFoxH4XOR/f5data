K000163124: F5 Insight: Failed to delete software image

Type
Support Solution
Published
2026-08-27
Updated
2026-08-27
Applies to
  • BIG-IP
  • F5 Insight: 1.2.2
Source
https://my.f5.com/manage/s/article/K000163124

Description

F5 Insight displays “Failed to delete software image” when attempting to delete a software image.

Environment

  • Product: F5 Insight (v1.2.2)
  • Software images imported into the Software Images inventory
  • Images distributed to or installed on managed instances

Cause

Software images that have been distributed to or installed on managed instances cannot be deleted from the F5 Insight portal.

Recommended Actions

  • Review the affected images and confirm their distribution or installation status.
  • If an image must be removed, follow the supported F5 Insight software image management workflow to remove any distribution or installation dependencies first.

Additional Information

Deleting a software image from the F5 Insight portal does not remove software that has already been distributed to or installed on managed instances. The deletion failure is expected behavior for distributed or installed images.
