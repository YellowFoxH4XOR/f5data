K000157098: Re-activate button is not visible.

Source

Description

Upgrading BIG-IP APM to version 17.5.1.3 from a previous 17.1.x release may result in the configuration failing to load due to a licensing issue. The "Re-activate" button for relicensing is not visible within the BIG-IP instance interface when it is hosted on F5OS, preventing direct license reactivation from the BIG-IP instance.

Environment

  • Product: BIG-IP APM
  • Version: 17.5.1.3 (upgrade from 17.1.x)
  • Host OS: F5OS
  • Deployment: BIG-IP instance running as a tenant on F5OS
  • Re-activate license

Cause

Licensing for BIG-IP instances hosted on F5OS is managed at the F5OS layer rather than within the individual BIG-IP instance itself. Therefore, the "Re-activate" button does not appear in the BIG-IP GUI, and relicensing actions must be performed through the F5OS management interface.

Recommended Actions

  • Perform license reactivation directly on the F5OS device using its management interface.
  • Use the licensing workflow provided by F5OS to re-activate or update the license for your BIG-IP tenant.
  • Once reactivation is completed successfully in F5OS, the associated BIG-IP instance will recognize the updated license and configuration loading should proceed normally.
  • For detailed steps on licensing and managing tenants in F5OS, refer to official F5OS documentation.
