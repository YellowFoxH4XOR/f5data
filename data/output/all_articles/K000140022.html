Description

Clients with limited number of IPv6 addresses fail to connect to websites through HTTP Explicit Forward Web Proxy while others are able to connect to websites without any issue.

 

Environment

  • IPv6 virtual server with HTTP explicit proxy profile.
  • Source-address-translation on the IPv6 HTTP explicit proxy virtual-server with any option configured other than a SNAT pool consisting of IPv4-only IPs.
  • DNS returns an A record (IPv4).
  • A standard virtual server is used to forward traffic; a FastL4 virtual server including ip-forward virtual server is NOT used to forward traffic.

Cause

ID 1587225

Recommended Actions

Do one of the following:

  • Use FastL4 virtual server (FastL4 virtual server including ip-forward virtual server) to forward traffic.
  • On the IPv6 virtual-server with http explicit proxy profile, use a SNAT pool with IPv4 addresses only.
