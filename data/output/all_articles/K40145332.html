K40145332: BIG-IQ GeoIP Databases Management fails with ''failed updating devices''

Type
Support Solution
Published
2020-06-22
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K40145332

Description

Not able to update GEOIP databases via BIG-IQ. In GUI Devices -> GeoIP Databases Managment -> Update History -> error "Failed updating devices."

/var/log/restjavad.0.log contains:

[/cm/device/geoip/task/push-update/cd4e9d5b-6377-459f-8f48-a712b2f679d8/worker DeviceGeoIpPushUpdateTaskWorker] GeoIP Message: DeviceGeoIpPushUpdateTaskWorker: Task [cd4e9d5b-6377-459f-8f48-a712b2f679d8] failed at step CHECK_SHELL_ACCESS: java.lang.Exception: Could not execute command 'echo test': Only requests from users with advanced shell access are supported
    at com.f5.rest.workers.device.ihealth.qkviewdownload.DeviceShellTask$1.check(DeviceShellTask.java:134)
    at com.f5.rest.workers.device.ihealth.qkviewdownload.DeviceShellTask$1.check(DeviceShellTask.java:99)
    at com.f5.rest.workers.device.subtask.tasks.RestPollTask$2.completed(RestPollTask.java:168)
    at com.f5.rest.workers.device.subtask.tasks.RestPollTask$2.completed(RestPollTask.java:163)

In the BIG-IQ GUI you may see the following message: 
Shell Access for the admin users on those devices. For more information, see AskF5 article K12029.

Environment

  • BIG-IQ Centralized Management
  • GEOIP Database management via BIG-IQ
  • BIG-IP 13.x or later

Cause
Wrong rights assigned to Admin user.
Root-cause described in:  K22650515: Updating BIG-IP IP geolocation database using BIG-IQ

Section: Updating IP geolocation database on the managed BIG-IP devices

Note: In order to have the BIG-IQ system to initiate the update script on target BIG-IP devices running on version 13.0.0 and later, you must enable Advanced Shell Access for the admin user on the target BIG-IP devices. For more information, refer to K12029: Accessing the TMOS Shell.

Recommended Actions

Configure Admin user to have Advanced Shell access

On BIG-IP:
  1. Go to  System > Users
  2. Modify Admin user
  3. From Terminal Access list chose Advanced shell
