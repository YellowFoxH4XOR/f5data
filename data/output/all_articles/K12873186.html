Description

It's possible to run 'URL Category Lookup' search for multiple sites in CLI instead of manual 'one-by-one' URL check in GUI in Access  ››  Secure Web Gateway : Database Settings : URL Category Lookup

Environment

  • URL Category Lookup
  • CLI
  • APM
  • SWG
Cause

None

Recommended Actions

  1. Create the list of sites which you would like to process (verify) against 'Category Lookup' mechanism.
    For example, the file 'sites.txt' with the following sites:
    # cat /var/tmp/sites.txt
    https://google.com
    https://yahoo.com
    https://facebook.com
    https://example.com
     
  2. Check the latest master database updates version number on APM:
    # ll /var/urldb/master/
        6477/   6478/   backup/
    in this example, it's 6478
     
  3. Check the latest real-time database updates version number on APM:
    # ll /var/urldb/rtu/
        total 8
        drwxr-xr-t. 2 root root 4096 Aug 14 11:34 742034
        drwxr-xr-t. 2 root root 4096 Aug 14 11:34 742035
    in this example, it's 742035
     
  4. Run URL Category Lookup check in CLI on APM:
    cat /var/tmp/sites.txt | while read line; do SITES=$(urldb -m /var/urldb/master/<version# from step 2>/websense.db -r /var/urldb/rtu/<version# from step 3>/rtu.db -l 7 -c $line | head -1); echo $line $SITES; done;

    For example:
    # cat /var/tmp/sites.txt | while read line; do SITES=$(urldb -m /var/urldb/master/6478/websense.db -r /var/urldb/rtu/742035/rtu.db -l 7 -c $line | head -1); echo $line $SITES; done;
