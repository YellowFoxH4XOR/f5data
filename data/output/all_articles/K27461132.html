Topic

Advanced WAF / BIG-IP ASM matches requests to parameters defined in the security policy based on a defined criteria.

Description

Parameter levels

When defining a parameter in the Advanced WAF / BIG-IP ASM security policy, you select the parameter level. The parameter levels are defined as follows:

  • Global parameter is a parameter that is not associated with a flow or URL.
  • URL parameter is a parameter that is associated with a specific URL.
  • Flow parameter is a parameter that is associated with a specific flow. A flow is the order in which a web application may require that web pages be accessed by the end user.

Parameter matching

When processing a request, Advanced WAF / BIG-IP ASM looks up parameters in the security policy based on the defined parameter level. In some cases you might want to confirm how the system matched a request to a parameter. For example, if your security policy includes multiple parameters that use the same name, you may want to verify how the system matched a request to a specific parameter. The matching criteria is as follows:

For the request: GET /users?id=12345, the system performs the following parameter lookup:

  1. Search the policy for any flow parameter with the name id for URL: <ANY, /users>.
  2. If the URL <GET, /users> is in the policy:
    • Search for a URL-level parameter with the name id for URL <GET, /users>.
    • If not found proceed to step 4.
  3. If the URL <ANY, /users> is in in the policy:
    • Search for a URL-level parameter id for URL <ANY, /users>.
    • If not found proceed to step 4.
  4. Search the policy for a global parameter with the name id.
  5. If no matching global parameter is found, match to a wildcard (*) parameter.
