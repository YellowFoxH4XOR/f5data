Description

Error Message: 01010038:4: Syncookie counter <value> exceeded vip threshold <value> for virtual = <IP>:<port> logged by BIG-IP.

  • Flood of new TCP connections exceeding the value set by "Per Virtual Server SYN Check™ Threshold' divided by the number of tmms
  • Error message logged in /var/log/ltm

01010038:4: Syncookie counter 22 exceeded vip threshold 16 for virtual = 192.0.2.150:80

Environment

  • BIG-IP and SYN Cookie protection
  • SYN cookie protection is enabled
  • Flood of new TCP connections exceeding the value set by "Per Virtual Server SYN Check™ Threshold' divided by the number of tmms

Cause

This is expected behaviour when the rate at which new TCP connection requests goes above the value per tmm defined by "Per Virtual Server SYN Check™ Threshold'.

Recommended Actions

None

Additional Information

"Per Virtual Server SYN Check™ Threshold' can also be set via tmsh with command:

tmsh modify ltm global-settings connection { default-vs-syn-challenge-threshold <value> }

The value set is divided by the number of tmms which differs depending on platform. To obtain the platform number of tmms value run:

tmsh show sys hardware | grep core

The physical value corresponds to the number of tmms. For Viprion chassis multiply the value by the number of active blades to get total number of tmms.
