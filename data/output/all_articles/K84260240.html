Description

Some Firewall and Antivirus products are increasing the security of their products, and as they update versions.  Sometimes this causes them to then fail the configured Access Policy when the new version now requires extra access privileges.

You will see one of the following APM log messages that reference Access Denied when the failures are due to insufficient privileges.

Session variable 'session.check_software.last.av.item_x.errors' set to 'Failed to get 'db_version'. code: -32 (Access denied) mId: 1 iId: 9 
Failed to get 'db_time'. code: -32 (Access denied) mId: 3 iId: 9 
Failed to get 'last_scan'. code: -32 (Access denied) mId: 12 iId: 9 
Failed to get 'engine_version'. code: -32 (Access denied)

Environment

  • BIG-IP APM with configured Access Policy using Endpoint Inspection (version 13.1 onwards)
  • Client using Edge Client or Browser helper applications on Microsoft Windows (version 7.1.5 onwards)
  • Inspector Service (an optional Component install) is not running

Cause

Some AV products have started to require Privilege escalation to Check Last Scan date and other state information. On Microsoft Windows this is done by an optional component "Inspector Service" that may not be installed or running.

Recommended Actions

Check that "Inspector Service" is installed and running

  1. Type "services" in the windows search bar to launch the services GUI
  2. Once the "Services(Local)" are displayed, scroll down and check the ones starting with F5
  3. Check that "F5 Networks Inspector Service" is shown as running (f5InspectorService.exe).
  4. If it is shown but not running, you should try to restart the service.
  5. If it is not shown, re-install the Edge Client with the service included as below

The F5 "Client Troubleshooting utility (CTU aka F5wininfo.exe)" will also display if the Inspector Service is installed by showing a green dot. 
K12444: Overview of the Client Troubleshooting Utility for Window
 



Reinstall Edge Client with the "Inspector Service" included

  1. Follow the instructions in
    K44328534: BIG-IP administrator instructions for downloading BIG-IP Edge Client for Windows and Mac OS X, and Linux clients
  2. When you reach the "Select Customize Package" step, ensure the box labeled "Inspector Service" is ticked (along with any other required optional service) and download the revised package.
  3. Once this updated package is re-installed on the windows device, reboot and confirm the service is running as above.
  4. Check that endpoint inspection test no longer have escalation issues

Additional Information

The following Windows products (for each SDK method) are known to be affected at the time of publication:

  • GetLastScanTime: Windows Defender, BitDefender, Acronis Cyber Protection Agent
  • GetRealTimeProtectionState: ESET File Security for Microsoft Windows Server
  • GetDefinitionState: FireEye Endpoint Agent
  • GetFirewallState: AVG Internet Security, AhnLab V3 Internet Security


The MacOS Installer package installs with privilege escalation by default since 13.1
The Linux endpoint inspection does not support privilege escalation.
