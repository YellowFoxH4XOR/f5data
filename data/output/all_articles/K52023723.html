Description

In some cases ASM can block or mark request as illegal with violations like:
  • Illegal parameter *
  • Illegal URL *

Environment

  • ASM blocks or marks request as illegal.
  • Very long query string (URL)
  • Event log can show that parameter that triggered violation has strange/short name. For example, request contains parameter "location" in URL and violation is triggered for "l" or "loc" parameter.

Cause

When ASM policy allows for URLs / Query Strings longer then 2048 bytes, request is not fully processed due to global request URI limit of 2048 bytes. This setting is controlled by ASM System variable ecard_max_http_req_uri_len.

Example

  • Allowed Parameters:
    • alpha
    • beta
    • gamma
    • epsilon
    • [No wildcard parameter "*"]
  • File type php: Query String Length with value 3000 bytes.

Recommended Actions

Increase ecard_max_http_req_uri_len value in GUI Security  ››  Options : Application Security : Advanced Configuration : System Variables to value of maximum allowed URL length.
Note: You must perform a 'tmsh restart sys service asm' for this change to take effect! If you are using a device group you must perform 'tmsh restart sys service asm' on all members of the device group for this change to take effect!
