Description

Users who apply for a BIG-IP VE Free Trial License and wish to test SSL Orchestrator (SSLO) functionality will find that SSLO is not included in the base trial license. When attempting to provision or configure SSLO, users may encounter errors or find that the SSLO module is not available in the provisioning menu. The trial license provides access to core BIG-IP functionality (such as LTM, DNS) but does not include advanced modules such as SSL Orchestrator.

 

Environment

  • SSL Orchestrator (SSLO)
  • Trial License

 

Cause

The trial license is designed as a base license that provides access to core BIG-IP features only. SSL Orchestrator (SSLO) is an advanced module that requires a separate license and is not included in the base trial license configuration. To test SSLO functionality, a dedicated evaluation license that includes SSLO must be requested.

 

Recommended Actions

Reach out to the F5 Sales team or your designated Account Manager (if applicable) to request an evaluation license with SSLO functionality for testing purposes.
