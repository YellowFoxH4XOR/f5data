Description

You may run into this error message if you are attempting to rerun, reconfigure, or delete an iApp and a profile that was created by the iApp is in use elsewhere within the configuration.

For example:

Aug 30 09:55:15 BIG-IP-LB-01 err mcpd[4835]: 01020036:3: The requested virtual server fallback persistence profile (/Common/test-www.app/test-www_source-addr-persistence) was not found.
 

Environment

  • Reconfigure or delete an iApp
  • Profiles
  • Error Message

Cause

When you remove a profile (persistence, ssl, etc..) by reconfiguring the iApp the profile will be deleted. However if that profile is in use somewhere else within the configuration it cannot be deleted thus resulting in the error.

Recommended Actions

  1. You must disassociate the profile from any other configuration objects within the configuration before you can remove/delete it from within the iApp.
