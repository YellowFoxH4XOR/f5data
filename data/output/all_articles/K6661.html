K6661: BIG-IP LTM can use excessive memory and CPU cycles when processing a high number of SSL connections from congested clients

Known Issue

This is the result of a known issue. When BIG-IP LTM processes a high number of Secure Sockets Layer (SSL) connections from congested clients, the SSL encrypted transfer queue can grow continuously, causing excessive memory and CPU usage.

F5 Product Development tracked this issue as CR69478 and it was fixed in BIG-IP LTM 9.1.3. For information about upgrading, refer to the BIG-IP LTM release notes.
