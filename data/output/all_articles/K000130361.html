K000130361: Some system logs are being discarded

Type
Support Solution
Published
2023-03-20
Updated
2025-03-20
Source
https://my.f5.com/manage/s/article/K000130361

Description


Excess iRule logging is obscuring other log messages such as node state changes or daemon restarts.

Symptoms


Logs are full of messages coming from an iRule.
LTM log under /var/log is very big.
iRule is logging more than 150 messages per second.


Environment

  • Virtual Server
  • iRule
  • High volume of traffic processing



Cause


If an iRule hits the 200 messages per second limit or higher, important system logs may be discarded. 


Recommended Actions
Disable the iRule logging for the affected virtual server configured iRule.
