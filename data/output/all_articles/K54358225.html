Security Advisory Description

In F5 BIG-IP APM software versions 11.5.0, 11.5.1, 11.5.2, 11.5.3, 11.5.4, 11.6.0, 11.6.1, 12.0.0, 12.1.0, 12.1.1 and 12.1.2 BIG-IP APM portal access requests do not return the intended resources in some cases. This may allow access to internal BIG-IP APM resources, however the application resources and backend servers are unaffected. (CVE-2017-0301)

Impact

When BIG-IP APM is licensed and provisioned, this vulnerability may allow access to internal BIG-IP APM resources. The application resources and backend servers are unaffected.
