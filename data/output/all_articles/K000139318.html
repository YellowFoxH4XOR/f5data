Description

After device state changes from "Offline" to "Standby" or "Active", you can notice that scripts /config/failover/active or /config/failover/standby were not triggered.

Environment

  • BIG-IP LTM

  • HA pair

Cause

This is expected behavior, and this scripts are executed only if device state was changed from "Standby" to "Active" or from "Active" to "Standby".

Recommended Actions

If you prefer scripts to be executed whenever device state is changed to "Active" to Standby" regardless of previous device state, instead of using active/standby failover scripts, you could consider using tgactive/tgstandby scripts.
