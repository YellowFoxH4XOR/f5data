K000130564: Pulse GeoIP DB (Digital Envoy) not updated since December 7th 2022

Type
Support Solution
Published
2023-01-12
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K000130564

Description

  • Pulse GeoIP DB (Digital Envoy) has not been updated for over a month (since December 7th, 2022)

Environment

  • Migration of GeoIPDB from Edge to Pulse
  • Last GeoIP update on the downloads page is 12/07/2022

 

Cause

There were automation script errors while building the updates, these are fixed now.

New GeoIP updates for Pulse DB (Digital Envoy) should be tentatively available for download by 15th Jan 2022. Further updates can be expected every week.

 

However, when there is a build failure internally at F5, a weekly release may be delayed or can be skipped unexpectedly. 

Please check https://downloads.f5.com/ for update availability.

 

 

 Recommended Actions

 None
