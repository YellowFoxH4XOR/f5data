Description

Using BIG-IQ you would like to discover and import the service configuration from a single or multiple BIG-IP devices.

Environment

  • BIG-IQ
  • BIG-IP

Cause

None

 

Recommended Actions

  • To discover a single BIG-IP and import a service configuration:
    K63557165: Discovering a BIG-IP device with a BIG-IQ system and importing the BIG-IP service configuration

  • To discover multiple BIG-IPs and import their service configurations:
    K31035272: Discovering multiple BIG-IP devices with your BIG-IQ system and importing the BIG-IP service configurations

    Note: The procedures outlined in each of the articles are similar. However, there are subtle differences between importing a single BIG-IP device and service configuration and importing the service configurations from multiple discovered BIG-IP devices.
