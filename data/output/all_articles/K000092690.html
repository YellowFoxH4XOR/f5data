K000092690: BaDoS dynamic signatures not shown in the GUI during the attack

Type
Support Solution
Published
2022-11-22
Updated
2023-12-07
Source
https://my.f5.com/manage/s/article/K000092690

Description

BaDoS dynamic signatures are not displayed in the GUI during the attack "Security - Dos Protection - Signatures".

 

Environment

  • DoS dynamic signatures

 

Cause

BaDoS Dynamic Signatures ( in Staging ) are generated every 10 seconds. However, these are not displayed on the GUI "Security - Dos Protection - Signatures".

This is expected behaviour.

 

Recommended Actions

None.

Note: An RFE has been submitted for the same; ID1070041 : BADoS to add more logs on the default INFO log level for better visibility to improve it." in order to improve this behaviour in future releases.


Additional Information

None
