Known Issue

The BIG-IP system may fail to authenticate TACACS+ users when the Protocol Name setting is empty.

This issue occurs when either one or both of the following conditions are met:

  • The BIG-IP system is configured to use the remote TACACS+ authentication method for the Configuration utility.
  • A virtual server is configured to use an authentication profile with TACACS+ authentication.

Impact

  • Users are unable to log in to the BIG-IP Configuration utility.
  • Users fail to access the virtual server.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • System users using the TACACS+ authentication method fail to log in to the BIG-IP Configuration utility.
  • Users fail to access the virtual server that is associated with the affected TACACS+ authentication profile.
  • The BIG-IP system logs an error message to the /var/log/secure file. The error message appears similar to the following example:

    pam_tacplus: TACACS+ protocol type not configured

Workaround

To work around this issue, you can configure a value for the TACACS+ authentication method's Protocol Name setting. To do so, perform either of the following procedure appropriate for your environment:

Impact of workaround: None.

Configuring the Protocol Name setting for system authentication

  1. Log in to the BIG-IP Configuration utility.
  2. Click System.
  3. Click Users.
  4. Click Authentication.
  5. In the Protocol Name box, enter a value.

    For example:

    ip

    Note: For a list of accepted values, refer to the Configuration utility online Help.
  6. Click Update.

Configuring the Protocol Name setting for the TACACS+ authentication profile

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. Click Authentication.
  5. Click Configurations.
  6. Click on the name of the affected authentication configuration.
  7. In the Protocol Name box, enter a value.

    For example:

    ip

    Note: For a list of accepted values, refer to the Configuration utility online Help.
  8. Click Update.
