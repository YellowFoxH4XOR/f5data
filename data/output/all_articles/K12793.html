Vulnerability description and product information

The regcomp implementation in the GNU C Library (aka glibc or libc6) allows context-dependent attackers to cause a denial-of-service (DoS) attack. This applies to GNU C Library versions through 2.11.3, and also versions 2.12.x through 2.12.2.
