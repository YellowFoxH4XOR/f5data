Description

  • Why is TLS configuration not available in XC GLR for AWS S3 Bucket receiver?
  • You want to configure custom TLS settings for your GLR object routing to your AWS S3 Bucket receiver, but the custom TLS configuration is not available in XC Console.

Environment

  • Global Log Receiver
  • AWS S3 Bucket receiver
  • XC Console

Answer

The AWS S3 log receiver in F5 Distributed Cloud (XC) does not currently support TLS configuration in the same way as generic HTTP/HTTPS receivers.

This distinction is critical: S3 receivers use a different transport mechanism that is not user-configurable for TLS within the GLR UI. Instead, the logs are sent using AWS’s native S3 API, which is inherently encrypted in transit using HTTPS under the hood, but not exposed for TLS configuration or certificate management in the GLR interface.
