Description

Buffer overflows (CWE-120) are a class of vulnerabilities that can affect applications written in many programming languages, and the name describes any situation in which the software attempts to move data from one location in memory into a fixed-length buffer (in another location in memory) which is too small to hold the data.

If we talk about web applications, specifically, it may be possible to mitigate buffer overflow attacks against a web application or web server using BIG-IP Advanced WAF, Silverline WAF etc to enforce length checks against user-supplied input (in the form of HTTP parameters, URIs, and headers). 

If the violation of Buffer Overflow is detected, BIG-IP Advanced WAF may show its attack type as N/A, instead of Buffer Overflow, in the event logs.

Environment

  • BIG-IP Advanced WAF

  • Buffer Overflow

  • Event log

  • Attack type

Cause

This is related with POST Data Length in Violation Details.

  • If the Detected POST Data Length is above 40% of the defined size (Expected POST Data Length), BIG-IP reports the Attack Types as Buffer Overflow.

  • If the Detected POST Data Length is not above the 40% of the defined size (Expected POST Data Length), BIG-IP reports the Attack Types as N/A.

 Recommended Actions

This is by design.
