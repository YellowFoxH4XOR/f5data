Topic

To load balance using the dynamic_ratio method with non-standard server-side management information bases (MIBs), use the existing snmp_dca_base monitor template to add a new monitor with the OID name and OID number for the destination system. This will return memory utilization with the expected response for dynamic_ratio and will help you to determine the health of the server.

Note: If you are using a Microsoft MIB OID, refer to K727: The snmp_dca health monitor is not fully compatible with the Microsoft http_server MIB.

Configuring a new monitor

To configure a new monitor, perform the following steps:

  1. From the navigation pane of the Configuration utility, select Monitors.
  2. Click Add.
  3. In the Name field, type the name of the new Monitor.
  4. From the Inherits From drop-down list, select snmp_dca_base.
  5. Click Next.
  6. Enter the Interval and Timeout ratios.
  7. In the Community text box, type the community string of the node that you want to monitor.

    Note: If you do not know what the node's community string is, contact to your system administrator for assistance.
  8. Click Next.
  9. In the Variable Name field, type a value similar to the following:

    ssCpuSystem.0

    This is the OID for system CPU utilization.

    Note: Be sure to verify that the OID that you enter is valid, since you are using non-standard MIBs.
  10. In the Value field, enter the threshold at which you do not want the BIG-IP system to send more traffic to the server.

    For example, if you want the BIG-IP system to stop sending traffic when the server reaches 75% capacity, you would enter:

    75
  11. Leave the Destination IP and Destination Service at the default settings.

    Note: These settings are used to change the Port and IP address of the server queried. This is not a setting that you typically modify, but the option is provided for advanced users. If you have a server listening on a non-standard SNMP port, you will have to change the Port from 161. If you require assistance in doing that, contact F5 Technical Support.
  12. Click Done.

Associating the monitor with the node from the Configuration utility

After you configure the monitor, associate it with the node by performing the following steps:

  1. From the navigation pane of the Configuration utility, select Monitors.
  2. Click the Node Associations tab.
  3. From the Choose Monitor menu, select the monitor you created.
  4. Click the >> button to populate the Monitor Rule text box.
  5. Check the box in the Associate Current Monitor Rule column, check the box next to the node you want to associate with this monitor.
  6. Click Apply.

Setting the node's pool to dynamic_ratio load balancing

You must set the pool (of which the node you are monitoring is a member) to dynamic_ratio load balancing so that the associated SNMP data will affect load balancing and the node will be associated with the new monitor.

To set the node's pool to dynamic_ratio load balancing, perform the following steps:

  1. From the navigation pane of the Configuration utility, click Pools.
  2. Select the pool that contains the nodes that you want to load balance based on Dynamic Ratio.
  3. From the Load Balancing Method menu, select Dynamic Ratio.

    Note:     For additional information about configuring and using Dynamic Ratio load balancing, refer to the BIG-IP Reference Guide.
