Known Issue

This is the result of a known issue. When running the Policy Wizard, you can define a Trusted IP list that specifies a range or list of IP addresses that the Policy Wizard considers to be safe addresses. The Policy Wizard accepts only class C network addresses when using the Address List drop-down selection to define Trusted IPs. If you enter an IP address that does not belong to a class C network, the following error message is displayed on the Configuration utility screen:

You've entered invalid IP address

F5 Product Development tracked this issue as CR91343 and it was fixed in BIG-IP ASM 9.4.4. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Workaround

To work around this issue, select Address Range from the Trusted IPs drop-down menu and enter a range of IP addresses. If you select Address Range from the Trusted IPs drop-down menu instead of Address List, the system allows you to enter a range of class C network addresses.
