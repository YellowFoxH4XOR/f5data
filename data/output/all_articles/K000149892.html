Description

In some scenarios, customers need to operate cloud credentials. If you are not an administrator, the drop-down box may be gray or cannot be clicked, as shown in the following figure. What should you do to solve the problem?

Environment

  • F5® Distributed Cloud (SaaS)

Cause

 

Answer/Recommended Actions

Please try to assign you f5xc-multi-cloud-network-connect-monitor role (or user/admin role) and please assign this role in the same namespace as the cloud credentials, assuming the cloud credentials are in the system namespace, then you need to be f5xc-multi-cloud-network-connect-monitor (or user/admin role) in the system namespace as well.
