K000154645: TMM memory is showing 0% usage, and other memory usage has increased after the version upgrade

Type
Support Solution
Published
2025-09-24
Updated
2025-10-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000154645

Description

The TMM memory usage is showing 0% usage, and the other memory usage has increased after the version upgrade. Output of below command shows value 0 in TMM memory.

tmsh show sys tmm-info

-------------------------------------------------------
Sys::TMM Memory (bytes)
-------------------------------------------------------
TMM: 1.10
Available 0
Used 0

TMM: 1.12
Available 0
Used 0

TMM: 1.14
Available 0
Used 0

Environment

  • F5 VELOS Chassis platforms installed and deployed with BIG-IP tenant with a number of blades 5 or above.
  • Version upgrade of BIG IP tenant from 17.1.x to 17.5.1. 

Cause

Bug ID 2037409

Recommended Actions

Bug ID 2037409 is fixed in 17.5.1.3.

Additional Information

None
