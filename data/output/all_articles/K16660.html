Known Issue

Priority Group Activation settings may be ignored if the Slow Ramp Time setting is enabled.

This issue occurs when all of the following conditions are met:

  • Your system is running BIG-IP 11.4.1 HF6.
  • You have a pool configured to use the Priority Group Activation feature.
  • The same pool configuration has the Slow Ramp Time setting enabled.

    Note: The Slow Ramp Time setting is enabled by default, with a configuration of 10 seconds.

Impact

All pool members are utilized, regardless of priority configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system does not distribute traffic as expected.

Workaround

To work around this issue, you can disable the Slow Ramp Time setting. To do so, perform the following procedure:

Impact of workaround: If you use dynamic load balancing methods, the statistics for a new pool member can affect the load balancing algorithm and overload the pool member.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Pool.
  3. Select the affected pool.
  4. Change the Configuration option, from Basic to Advanced.
  5. Locate the Slow Ramp Time setting, and type 0 in the Seconds box.
  6. Click Update.
