Description

How to add device trust of a VELOS partition to BIG-IQ CM via REST API

Environment

  • BIG-IQ
  • VELOS

Cause

Needing to add VELOS to BIG-IQ CM

Recommended Actions

1) Get an valid auth token for the BIG-IQ CM:

TOKEN=$(curl -sku admin:<admin_password> -X POST https://<BIG-IQ.MGMT.IP.ADDR>/mgmt/shared/authn/login -H "Content-Type: application/json" -d '{"username": "admin","password": "<admin_password>", "loginProviderName": "local"}' | jq -r '.token.token')

2) Add a VELOS System into BIG-IQ CM:

curl -k -X POST https://<BIG-IQ.MGMT.IP.ADDR>/mgmt/cm/f5os/config -H "Content-Type: application/json" -H "X-F5-Auth-Token: $TOKEN" -d '{
"name":"<VELOS PARTION NAME>",
"username":"admin",
"password":"<admin_password>",
"address":"<IP.ADDRESS.VELOS.PARTION>"
}' | jq .

Additional Information

Please keep in mind that a partition needs to exist on VELOS before attempting to add VELOS system into BIG-IQ CM to avoid bug ID1323085.
