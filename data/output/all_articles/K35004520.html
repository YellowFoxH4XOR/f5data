Description

To determine the number of local traffic objects currently configured in the default partition on the system, use the following command syntax:

tmsh list ltm one-line | wc -l

To narrow down to a specifc ltm object, use the following command syntax:

tmsh list ltm <object> one-line | wc -l

For example, to list the number of local traffic objects configured in the default partition, refer to the following table:

ObjectCommand
Virtual servertmsh list ltm virtual one-line | wc -l
SNATtmsh list ltm snat one-line | wc -l
Pooltmsh list ltm pool one-line | wc -l
Nodetmsh list ltm node one-line | wc -l

To determine the number of local traffic objects currently configured in all partitions on the system, use the following command syntax:

tmsh -c 'cd /; list ltm <object> recursive one-line' |wc -l

For example, to list the number of local traffic objects configured in all partitions, refer to the following table:

ObjectCommand
Virtual servertmsh -c 'cd /; list ltm virtual recursive one-line' |wc -l
SNATtmsh -c 'cd /; list ltm snat recursive one-line' |wc -l
Pooltmsh -c 'cd /; list ltm pool recursive one-line' |wc -l
Nodetmsh -c 'cd /; list ltm node recursive one-line' |wc -l

Environment

  • local traffic objects
  • Configuration

Cause

None

Recommended Actions

The output from the tmsh commands can be important, as having in excess of 15,000 LTM objects has been seen in the past to cause problems on some systems due to lack of processing power or memory.

Additional Information

It's currently recommended to keep the number of LTM objects on a system below 15,000 to avoid problems with system management resources.

Example script

To get the total number of local traffic objects currently configured in all partitions on the system, you can modify the following example to what you need:

tmsh -c 'cd /; list ltm recursive one-line' | egrep '^ltm' | awk '{count[$1" "$2]++; total++} END {for (t in count) print count[t], t; print total, 'TOTAL'}'
