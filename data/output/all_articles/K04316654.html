Description

When a virtual server configured with multiple client SSL profiles and if the profile configuration/settings do not match with each other, an error message is shown as:
107157c:3: Selected client SSL profiles do not match security policy when you are trying to assign to the virtual server.

Environment

  • BIG-IP LTM v13 or prior
  • Virtual server assigned with multiple client SSL profiles

Cause
 All assigned client SSL profile settings in a virtual server should be the same on BIG-IP versions prior to v14.

Recommended Actions

Note: The below procedure should be done in a maintenance window, removing/modifying the SSL profile may impact the traffic. 
  1. Remove all client SSL profiles from Virtual Server
  2. Update Client SSL profiles
  3. Make sure All client SSL settings are the same in client SSL profiles
  4. Add the modified SSL profiles to Virtual Server 
  5. Update the virtual server
