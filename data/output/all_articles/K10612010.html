Issue

Old Behavior

In versions earlier than BIG-IP 14.0.0, you can log in as a root or admin user with the default passwords when you first start the BIG-IP system. The passwords do not expire, so you can use them indefinitely.

New Behavior

Beginning in BIG-IP 14.0.0, the root and admin default passwords are marked as expired on new installations. After logging in with the default password, you are required to change the password before proceeding. Additionally, the password policy is enabled by default. The new passwords must meet the password policy requirements.

F5 Product Development tracked this change as ID 661909.

Impact

If you are installing BIG-IP 14.0.0 and logging in for the first time, you are required to change your root and admin passwords, and the passwords must meet the password policy requirements.

If you upgrade to BIG-IP 14.0.0 (you boot the system to a BIG-IP 14.0.0 boot location and roll forward the configuration from a version earlier than 14.0.0), the passwords from the rolled forward configuration remain valid and are not marked as expired, and the system does not require that you change them.

Recommended Actions

When you log in to the BIG-IP system for the first time as a root or admin user, be prepared to change your root and admin passwords. The password must meet the following password policy requirements:

  • The password must be greater than six characters.
  • The password must pass the basic pam_cracklib checks, which checks for the following issues:
    • Does the password contain dictionary words.
    • Is the password a palindrome.
    • Is the new password the same as the old one with only a case change.
    • Is the new password too similar to the old password.
    • Is the password too simple.
    • Is the new password a rotated version of the old password.

Important: Changing the root password for the first time also changes the admin password if you set the admin password to the default password.

When you log in for the first time as a root user, you are prompted to change the password. When you change the root password, the admin account password is changed to the same password, but it is also marked as expired. When you log in as an admin user for the first time, log in using the password you set for the root account, and then change your admin password.
