K5649: Japanese attachment names are corrupted in Mobile Email

Topic

When you use Mobile Email, attachment names with Japanese characters can be corrupted. The character encoding used by the client sending the email may cause the corruption. The supported encodings for names of attachments with Japanese character sets are as follows:

  • MIME-B encoded ISO-2022-JP
  • Shift-JIS

If the email client that attached the file does not use one of these encodings, the filename displays incorrectly.

Since most new Japanese email clients support multiple encoding schemes, the client that is sending the email should be configured to use one of the above supported encodings. MIME-B encoding is preferable to Shift-JIS. MIME-B is the most popular encoding system for attachments, although this encoding does not comply with RFC 2047. Shift-JIS encoding is an option for older Japanese email clients.

Note: The FirePass controller does not support unencoded ISO-2022-JP and encodings using RFC 2231 MIME extensions.
