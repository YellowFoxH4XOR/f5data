K18203002: [F5OS-A] OS upgrade failure

Type
Support Solution
Published
2022-08-11
Updated
2024-10-18
Applies to
  • rSeries Platforms
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K18203002

Description

After upgrade F5OS-A, system is not working properly.
The symptom includes

  • Upgrading the base image of f5os is stuck with the status 'In progress'.
  • From console, the AOM menu cannot be invoked with the "ESC-(" combination of key presses.
  • From the management configuration CLI, the error is encountered when the following command is executed:
[root@appliance-1 ~]# system reboot

The reboot of the system results in data plane and management connectivity to be disrupted. Proceed? [no,yes] yes
Error: application communication failure

  •  Alarm: Fault detected ini LCD module
  • Both LED power supply status is off, even though both power supplies are working
  • All interface port is down
  • Some of GUI menus, like 'Port Groups', 'Interface' and 'VLAN' in the F5OS GUI cannot be accessed and display this error message:
'Something Went Wrong. Check the web browser console for more details or contact technical support for assistance'

Environment

  • F5OS-A
  • v1.0.1 - v1.3.x
  • rSeries
  • Upgrade

Cause

  • Bug ID 1211025 
  • Bug ID 1134613

Recommended Actions

To determine if you encounter for this issue, log in to CLI as root, and run below in bash mode, the device with the address of f5f5:df11 confirms the LOP is in bootloader mode.:

lsusb | grep f5f5

Bus 001 Device 002: ID f5f5:df11 <<---[KO]
 

then follow workaruond in Bug ID 1134613
 


If the value is other than df11, then isseu is not  the bug mentioned in this case.

Bus 001 Device 002: ID f5f5:3800 <<---[OK]
Bus 001 Device 002: ID f5f5:3000 <<---[OK]
