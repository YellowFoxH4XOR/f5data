 Environment

-BIG-IP version: BIG-IP 14.1.4.4 Build 0.27.4 Engineering Hotfix

-deployed in CSTv1 in AWS (Cloudformation template)


 Cause

The script waits for completion of ucs for 2 minutes (60 *2s) before it errors out

 Recommended Actions

Edit file from /config/cloud/aws/node_modules/@f5devcentral/f5-cloud-libs/lib/bigIp.js



The following line in saveUcs function needs to be modified:


from -


{

maxRetries: 60,

retryIntervalMs: 2000

},


to


{

maxRetries: 90,

retryIntervalMs: 2000

},
