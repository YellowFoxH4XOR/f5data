Description

MobileSafe alerts are not getting sent to the BIG-IQ

Environment

  • BIG-IQ CM and one or more DCDs (VE)
  • BIG-IP provisioned with Fraud Protection Service (FPS)

Cause

the /var directory on the DCD has run out of space. df -h output shows that /var is 100% utilized.

Recommended Actions

1. extend the size of the /var file system

    K30902515: Resizing the /var, /var/log, or /shared file system on a BIG-IQ Virtual Edition
    
2. remove old FPS logs on the DCD. You can use a command similar to the following:

    # curl -X DELETE localhost:9200/<index_name>
