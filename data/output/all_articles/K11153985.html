K11153985: Change RAT-Type parameters inside messages

Published

Source

Description

The SDC system (in DRA configuration) have the possibility to change parameters inside the messages. For this purpose we are using Transformation tables in the Flows menu on the GUI.

The Transformation decision tables defines how to apply transformation scripts to an incoming message before it is processed by the session management and routing rules decision tables and/or after it is processed by them.

From the GUI are two tabs for "Post-Routing" and "Pre-Routing". There can be define transformation scripts.

Environment

  • Traffic SDC

Cause

Possibility to change RAT-Type parameters inside messages

Recommended Actions

  1. Run EMS or SDC GUI and go to Flows -> Transformation -> Post-Routing -> outTR-0
  2. Put of the content example script for change RAT-Type parameters inside the messages to outTR-0
Example script commands, change all incoming RAT-Type value in the message to "1004" 
userTraceLogger.info(">>> before change RAT-Type <<<< " +  incomingMessage.getValue("RAT-Type"));
incomingMessage.replaceAll("RAT-Type",1004);
userTraceLogger.info(">>> after change RAT-Type <<<< " +  incomingMessage.getValue("RAT-Type"));
  1. In the logs /var/log/rsyslog/sdc1.CPF.main.log you can find confirmation of this change
2021-04-27 15:28:02,093 INFO  [10801] *** USER TRACE *** >>> before change RAT-Type <<<< 1. [Request Message Executor_1_10] [UserTraceLoggerWrapper.info()]
2021-04-27 15:28:02,094 INFO  [10801] *** USER TRACE *** >>> after change RAT-Type <<<< 1004. [Request Message Executor_1_10] [UserTraceLoggerWrapper.info()]
  1. Below is the fragment of the other script which change value "1004" or "0" to "1" and for value "null" and "default" change to "0":
switch (entry){
    case 1004: ByteArrayUtils.setAsciiString(UserData,index,"1");
            // userTraceLogger.info("RAT-TYPE: Setting AVP to 1 for MSISDN: " + Msisdn);
            break;
    case 0: ByteArrayUtils.setAsciiString(UserData,index,"1");
            // userTraceLogger.info("RAT-TYPE: Setting AVP to 1 for MSISDN: " + Msisdn);
            break;
    case null:  ByteArrayUtils.setAsciiString(UserData,index,"0");
            userTraceLogger.info("RAT-TYPE: No Entry in UserTables for this MSISDN, Setting AVP to 0 for MSISDN: " + Msisdn);
            // sendTrap("1.3.6.1.4.1.3375.3.1.4.5.5", "Cannot get RAT-Type value from UserTable");
            break;
    default: ByteArrayUtils.setAsciiString(UserData,index,"0");
            // userTraceLogger.info("RAT-TYPE: Setting AVP to 0 for MSISDN: " + Msisdn);
            break;

}
// Replace AVP in the message
incomingMessage.replace("Sh-User-Data", UserData);
