Summary

Virtual Clustered Multiprocessing (vCMP) guests running on the BIG-IP 10200v, 7200v, and 5250v platforms do not have access to the Federal Information Processing Standard (FIPS) hardware.

Description

The BIG-IP 10200v, 7200v, and 5250v platforms include the option to install a FIPS hardware security module (HSM) hardware. When these platforms are installed with the FIPS HSM and licensed and provisioned to run vCMP, the vCMP guest deployed on the platforms does not have access to the installed FIPS HSM hardware.

Recommendations

If you require the use of FIPS HSM on these platforms, F5 recommends provisioning these platforms for BIG-IP LTM instead of vCMP. If you require the use of FIPS HSM for vCMP guests on these platforms, you may want to consider using an external HSM.
