K000146868: Unable to create local user in XC console

Type
Support Solution
Published
2024-11-08
Updated
2025-02-14
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000146868

Description

  • Tenant owner is unable to create a local user as Add user Button is missing on the console

 

Environment

  • F5® Distributed Cloud Console

 

Resolution/Answer

  • Disable SCIM then you can see the Add User button to add Local Users on the console.

Cause

  • When SCIM is enabled it disables account creation for local users from the console.

Additional Information
