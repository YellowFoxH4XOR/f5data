Known Issue

The audit_forwarder process may consume large amounts (> 90 percent) of CPU usage.

This issue occurs when one of the following conditions are met:

  • You terminate the syslog-ng process ungracefully.

    For example, you terminate the syslog-ng process by typing the following command:

    kill -9 $(pidof syslog-ng)

  • On rare instances, a normal restart of the syslog-ng process may trigger the issue.

When the syslog-ng process terminates, the audit_forwarder process may unexpectedly continue to run and consume large amounts (> 90 percent) of CPU usage. If you then restart the syslog-ng process, the system starts a second instance of the audit_forwarder process. The initial rogue instance of the audit_forwarder process will continue to run and consume the CPU. Additionally, the mcpd process will also begin consuming high CPU usage.

Impact

The BIG-IP system performance may be degraded.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The audit_forwarder process consumes large amounts (>90 percent) of CPU usage.
  • The output of the top utility may show one or multiple instances of the audit_forwarder process, with the rogue instance consuming a large percentage of CPU, similar to the following output:

    PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND
    5153 14150515 20 0 31304 20m 12m R 93.1 0.5 0:44.65 audit_forwarder
    5906 root 20 0 178m 124m 16m R 90.2 3.1 194:12.07 mcpd
    9782 root RT 0 2379m 118m 93m S 10.6 3.0 572:54.97 tmm.0
    5295 14150529 20 0 31300 20m 12m R 3.3 0.5 0:00.64 audit_forwarder
    4932 root 25 5 56888 10m 7396 S 1.3 0.3 57:26.01 merged
    ~~~ output truncated for display purposes ~~~

  • The mcpd process consumes a large amount (> 90 percent) of CPU usage.

Workaround

There is no workaround. To recover from this issue, you can identify and stop the rogue audit_forwarder process. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Identify the PID of the rogue audit_forwarder process using the top utility. For more information, refer to K16739: Understanding 'top' output on the BIG-IP system.

    The following example shows PID 5153 as the rogue audit_forwarder process that is erroneously consuming 93.1 percent of CPU:

    PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND
    5153 14150515 20 0 31304 20m 12m R 93.1 0.5 0:44.65 audit_forwarder
    5906 root 20 0 178m 124m 16m R 90.2 3.1 194:12.07 mcpd
    9782 root RT 0 2379m 118m 93m S 10.6 3.0 572:54.97 tmm.0
    5295 14150529 20 0 31300 20m 12m R 3.3 0.5 0:00.64 audit_forwarder

  3. To stop the rogue audit_forwarder process, use the following command syntax:

    kill -9 <PID>

    For example, to stop the rogue audit_forwarder process identified from the example in step 2, type the following command:

    kill -9 5153

    Note: Once the rogue audit_forwarder process is stopped, the mcpd process with unusually high CPU usage should automatically return to normal CPU consumption.
