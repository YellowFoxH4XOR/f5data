K6665: A match-failed iRule event is added for BIG-IP ASM virtual server connections

Issue

In BIG-IP versions prior to 9.2.4 and 9.4.0, the BIG-IP system does not have an iRule event for requests to a BIG-IP ASM virtual server where no matching HTTP class is found. Beginning with BIG-IP 9.2.4 and 9.4.0, F5 added a HTTP_CLASS_FAILED iRule event to the BIG-IP system.

F5 Product Development tracked this issue as CR69172 and CR69318, and it was fixed in BIG-IP ASM 9.2.4 and 9.4.0. For information about upgrading, refer to the BIG-IP ASM release notes.
