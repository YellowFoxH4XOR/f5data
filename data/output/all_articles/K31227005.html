Description

Similar logs similar to the following are logged to /var/log/messages.
notice pendsect[11461]: skipping drive --
notice pendsect[11461]: No known drives detected for pending sector check.   Exiting

Environment

  • BIG-IP
  • i2x00
  • i4x00
  • Seagate HDD

Cause
None - Cosmetic issue

Recommended Actions
You can suppress this message by disabling 'pendsect' from /etc/cron.daily.

  1. Log on to the BIG-IP command line.
  2.  Change directories to /etc/cron.daily.
    cd /etc/cron.daily
     
  3. Create new directory called suppress.
    mkdir suppress
     
  4. Move pendsect to the new suppress directory.
    mv pendsect ./suppress

Additional Information

  • K18412043: Error such as "skipping drive" and "No known drives detected" are logged under /var/log/messages
