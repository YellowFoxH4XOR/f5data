Known Issue

This is the result of a known issue. Dynamic group mapping to Active Directory may fail if you use a nested group, which is a group that is the member of another group. This issue may occur if you have a nested group in which the group name and pre-Windows 2000 group name do not match in Active Directory.

F5 Product Development is tracking this issue as ID 317757 (formerly CR140964).

This issue has been fixed in cumulative hotfix HF-610-4 for FirePass version 6.1.0 and cumulative hotfix HF-70-4.1 for FirePass 7.0.0.

You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

You can work around this issue by ensuring that your group name and pre-Windows 2000 group name are the same in Active Directory.
