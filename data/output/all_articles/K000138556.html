Cause

Recommended Actions

You can recover from this issue by stopping the tenant and increasing the tenant storage size from F5OS. Around 10GB should be sufficient in most cases, but more space will allow the tenant to accommodate additional boot locations.

Additional Information

Bug ID 1077789 can be triggered by any type of configuration load failure, it doesn't have to be ID 1296925.
