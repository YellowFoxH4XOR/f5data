K33504943: Unable to reactivate license pool - Waiting for License Text.

Type
Support Solution
Published
2021-09-30
Updated
2026-03-04
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0, 8.X.X, 8.4.X, 8.4.1, 8.4.0, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X
Source
https://my.f5.com/manage/s/article/K33504943

Description

  • You are unable to reactivate the license pool, you see the message Waiting for License Text.
  • You also see that reactivate button is grayed

Environment

  • License pool
  • BIG-IQ CM

Cause

Unknown.

Recommended Actions

On your BIG-IQ CLI:

  1.  Make a backup before start:
    tmsh save sys ucs <some_name>
  2. Perform a PATCH to modify the status of the pool activation:
    restcurl -X PATCH cm/device/licensing/pool/utility/licenses/<your_bsk_here> -d '{"status": "ACTIVATING_AUTOMATIC"}'
  3. Wait for the activation to fail or succeed. To check status:
    restcurl cm/device/licensing/pool/utility/licenses/<your_bsk_here>| jq '. | {name, status, message, selfLink, sortName, regKey}'

Additional Information

None.
