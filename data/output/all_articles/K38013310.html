Description

Can we manage BIG-IP device using BIG-IQ without collecting the device statistics?

Environment

  • BIG-IP  
  • BIG-IQ Centralized Management

Cause

On BIG-IP versions 13.1.0.5 and later, BIG-IP can be managed on a BIG-IQ, and also disable sending device statistics. 

Recommended Actions

Follow below steps for disabling statistics collection in BIG-IQ 
  1. Login into BIG-IQ using GUI
  2. Navigate to Devices >>Choose device >>Statistics collection  >> Uncheck 'Collect Statistics Data'
  3. Save and Close

Additional Information

If you want to enable device statistics in future, please take not the that the device statistics can be viewed either from BIG-IQ or from BIG-IP. There is no way to distribute statistics across the BIG-IP & BIG-IQ.
