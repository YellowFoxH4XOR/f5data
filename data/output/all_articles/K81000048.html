K81000048: Connectivity issues with VPN using Windows Edge Client caused by third party software

Type
Support Solution
Published
2022-10-25
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K81000048

Description

If you are experiencing connectivity issues with your VPN, and you see the following error message in the CTU report:
How to generate a CTU report:

K12444: Overview of the Client Troubleshooting Utility for Windows

Error messages:
2022-10-18,05:45:45:737, 19908,10064,, 1, \UOverlappedIOSocket.cpp, 442, UOverlappedIOSocket::isAvailable(), WSAGetOverlappedResult() error, 10053, An established connection was aborted by the software in your host machine. (tunsvr)

Environment

  • APM provisioned
  • Failure to connect to VPN
  • Edge Client installed on Windows

Cause

There is an application on your local PC causing the connectivity issue.
The applications could be:
  • Any additional VPN solution still installed (or that was previously installed and that was not cleaned properly after uninstalling)
  • Any kind of local security software such as Antivirus/Firewall/IPS/AntiMalware. connections for instance.
  • Differences in GPO pushed on laptops
Contact the local IT administration for more information, to find out more about what software it could be that is causing this issue.

Recommended Actions

Remove potential causes, and make sure the VPN is working.
Add the potential causes one by one and see which one specifically is affecting you.
