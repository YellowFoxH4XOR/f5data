Description

This article provides guidance on establishing Key Performance Indicators (KPIs) and threshold values for monitoring CPU, memory, and other system resources on BIG-IP LTM systems. It defines what constitutes normal, medium, and critical utilization levels to support effective system health monitoring and proactive management.

Environment

  • BIG-IP Appliance or Virtual Edition
  • Local Traffic Manager (LTM); may include others depending on provisioned features
  • Device resources (CPU and Memory)

Cause

Operational thresholds are required to distinguish between normal, medium, and critical resource utilization. This enables timely detection of potential performance or capacity issues and supports proactive system management.

Recommended Actions

  • Normal Utilization: System is operating optimally.
  • Medium Utilization: Resource usage is approaching upper limits; monitor closely and consider optimization.
  • Critical Utilization: Immediate action recommended to prevent performance degradation.

Additional Information

Short spikes are normal under load, but sustained high CPU can indicate a problem and may warrant investigation.

**It is normal for a Linux system, including the BIG-IP system, to use swap. The Linux kernel sometimes prefers to swap idle processes' memory to disk so that more physical memory is available for more active processes, buffers, and caches.
