Issue

Error Message

010d0009:0: <component>: voltage (<voltage>) is too high.

In this error message, note the following:

  • <component> is the hardware component.
  • <voltage> is the voltage sensor reading.

For example:

010d0009:0: Blade 1.5V voltage: voltage (1722) is too high.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The platform LCD panel

    Note: The platform alarm LED may also turn red.

Description

This message occurs when the following condition is met:

  • A voltage sensor on the BIG-IP system takes a reading that exceeds operational limits.

Impact

If the condition continues, the BIG-IP system can become unstable or experience hardware failure.

Recommended Actions

This message can indicate a potential hardware problem, and may require the unit to be taken offline for End-User Diagnostics (EUD) tests.
