Description

Sync failed after an upgrade or configuration reload, with an error similar to:

01070712:3: Caught configuration exception (0), Values (my-rule) specified for Cipher Group Rule (/Common/my-group 2 my-rule): foreign key index (cipher_rule_FK) do not point at an item that exists in the database

Sync was previously working.

Environment

  • After upgrade
  • Configuration reload
  • Cipher Groups

Cause

One or more of the Cipher Group's Cipher Rules do not exist in the configuration.

In the example given in the description of this article, the Cipher Rule my-rule does not exist.

ltm cipher group my-group {
    allow {
        f5-default { }
    }
    require {
        my-rule { }
    }
}

Recommended Actions

Using tmsh, modify the Cipher Group to reference a Cipher Rule that exists, then perform a full sync of the sync-failover Device Group. For example:

tmsh modify ltm cipher group my-group require replace-all-with { f5-default }
tmsh run cm config-sync to-group Failover force-full-load-push

Additional Information

tmsh allows a Cipher Group referencing a non-existent Cipher Rule to be created in some cases. Such a Cipher Group is invalid, and this is caused by bug ID 493740. Care should be taken to reference a Cipher Rule that exists.
