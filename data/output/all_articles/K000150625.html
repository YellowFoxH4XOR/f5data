Description

You have followed K000141008: RADIUS authentication vulnerability CVE-2024-3596. Logging into BIG-IP (using external authenticator) or APM related configuration, BIG-IP inserts Message-Authenticator field, but when it comes to using RADIUS or RADIUS Accounting monitor BIG-IP does not include Message-Authenticator field.

Environment

  • BIG-IP
  • RADIUS monitor
  • RADIUS Accounting monitor

Cause

Known issue. Logged as ID1889205.

Recommended Actions

At the moment BIG-IP does not send Message-Authenticator field in RADIUS or RADIUS accounting monitor.

Below are few options you can consider for the time being until a fix is introduced:

Option 1 - Use a different monitor

Option 2 - Do not use any monitors at all. Traffic will still pass without a monitor but of course if the server or service goes down on that server BIG-IP would not know.

Option 3 - Do not enforce message-authenticator check on the backend server. Disable it. This can be cause security weakness.

Best is to follow Option 1 for time being until the message-authenticator feature is introduced in the monitor.
