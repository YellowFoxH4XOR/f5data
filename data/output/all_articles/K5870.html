Topic

The racs utility creates a new FIPS Administrator Card Set to replace a set that was created with the new-world utility.

The racs utility usage is as follows:

racs [-f] [-s <slot>] [-m <module>]

The -f flag tells the racs utility to allow the use of smart cards that already contain data. Any existing data will be erased. If a card contains data, and this flag is not specified, racs prompts you to decide whether or not to continue.

The -m flag specifies the Module ID to use.

The -s flag specifies the nCipher slot number for the smart card reader to use, as identified by slotinfo. If your module has only one smart card reader, the slot is 0.
