K000149775: Integrated Service Failed closed behavior

Type
Support Solution
Published
2025-02-12
Updated
2025-02-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149775

Description

The configuration for the BIG-IP's Integrated service (Security > Options > Application Security > Integrated Services > Anti-virus protection) for the Anti-virus server is set to "Guarantee Enforcement". When the Anti-virus server is unavailable the BIG-IP fails closed and no traffic will flow though the Advanced WAF.


Environment

BIG-IP Advanced WAF with anti-virus protection and Guarantee Enforcement


Cause

Guarantee enforcement does just that, guarantees that all traffic will be inspected by the anti-virus.


Recommended Actions

If you would prefer that your network fail open if the anti-virus server is unavailable, uncheck Guarantee Enforcement.
