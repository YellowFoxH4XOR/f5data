Known Issue

This is the result of a known issue. When a user attempts to locate the previous version of a file or directory using the Previous Versions tab in the Properties dialog box in Windows Explorer, some or all of the previous versions available on the back-end filer may not appear. This issue can occur when multiple snapshots with the same creation time are shared across volumes.

F5 Product Development tracked this issue as ARX ID 35947 and it was fixed in ARX version 5.0.5. For information about upgrading, refer to the ARX release notes.

Additionally, this issue has been fixed in a hotfix available for ARX versions 4.1.1 and 5.0.1. Customers affected by this issue should request the hotfix from F5 Technical Support, referencing this Solution number and ARX ID 35947.

Workaround

Users can work around this issue by locating the previous versions of the file or directory in the snapshot directory. By default, the snapshot directory is named ~snapshot and it is located under each directory in the volume. However, the snapshot directory name and accessibility options are configurable. For more information, refer to the Configuring Volume Snapshots section of the ARX CLI Maintenance Guide.
