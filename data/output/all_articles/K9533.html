K9533: Browsers may report a JavaScript error message when accessing a page with HTML FRAMESET tags through Portal Access

Known Issue

This is the result of a known issue. If a user accesses a web page with HTML <frameset> tags through Portal Access, the page displays correctly.

For example:

<html>
   <frameset cols="25%,75%">
    <frame src="frame1.html">
    <frame src="frame2.html">
   </frameset>
</html>

However, the browser may report a JavaScript error message that appears similar to the following example:
 
Error: Object expected
 
F5 Product Development tracked this issue as CR109661 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.
 
Additionally, this issue was fixed in cumulative hotfix HF-602-9 issued for FirePass version 6.0.2 and in cumulative hotfix HF-603-1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Workaround
 
This issue only occurs if the Open in new window check box is selected for the Portal Access favorite. To work around this issue, clear the Open in new window check box in the Portal Access favorite configuration.
 
Note: Portal Access favorites are configured on the Portal Access > Web Applications > Resources page.
