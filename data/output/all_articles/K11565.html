Known Issue

This is the result of a known issue. After installing BIG-IP 10.1.0 HF1, you can no longer generate a qkview file on the System >> Support page of the BIG-IP Configuration utility. If you attempt to generate the file, the Configuration utility reports the status as Processing indefinitely.

F5 Product Development is tracking this issue as ID 244005 (formerly CR138849).

This issue has been fixed in BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

Workaround

You can work around this issue by running the qkview command from the BIG-IP command line. The output of qkview lists the full path to the file, once it has been generated. For example:

[root@B3600:Active] config # qkview
Gathering System Diagnostics: Please wait ...
Diagnostic information has been saved in:
/var/tmp/B3600.example.com.tgz
Please send this file to F5 support.
[root@B3600:Active] config #

For instructions on copying files from the BIG-IP system, refer to K175: Transferring files to or from an F5 system.
