Known Issue

BIG-IP ASM may log URLs that contain navigation parameters incorrectly.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM policy is configured with navigation parameters.
  • The size of the URL combined with the navigation parameter is 16, 64, 128, 650, or 1620 characters.

Impact

The ASM event log displays the navigation parameter incorrectly.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The ASM event log displays the navigation parameter incorrectly.
