Known Issue

This is the result of a known issue. When you use the Traffic Management Shell (tmsh) to configure a Client SSL or Server SSL profile, and the next parameter should be a certificate file, certificate bundle file, or key file, the tmsh utility does not display or auto-complete file names when you press the Tab key.

In the following example, <Tab> indicates that the Tab key was pressed instead of the Enter key:

root@ltm01(Active)(tmos)# create /ltm profile client-ssl somesslprofile cert <Tab>
Options:
none
Values:
[enter value]
root@ltm01(Active)(tmos)#

F5 Product Development is tracking this issue as ID 247746 (formerly CR131921).

Workaround

You can work around this issue by viewing available certificates and certificate bundles in the /config/ssl/ssl.crt/ directory and viewing available keys in the /config/ssl/ssl.key/ directory. For example:

[root@ltm01:Active] ssl.key # ls /config/ssl/ssl.crt/
ca-bundle.crt default.crt example.com.crt
[root@ltm01:Active] ssl.key # ls /config/ssl/ssl.key/
default.key example.com.key
[root@ltm01:Active] ssl.key # tmsh
root@ltm01(Active)(tmos)# create /ltm profile client-ssl somesslprofile cert example.com.crt key example.com.key
root@ltm01(Active)(tmos)#
