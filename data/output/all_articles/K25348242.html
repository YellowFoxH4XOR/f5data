Known Issue

Under certain conditions, the BIG-IP system does not send monitor probes at the configured interval.

This issue occurs when the following condition is met:

  • You configure the monitor interval to a number that is lower than the sum of the monitored resources using that interval. For example, you configure the monitor interval to 30 seconds for 40 monitors with a 30-second interval.

Impact

The system does not consistently perform monitor probes at the interval you configured.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you configure sufficient resources with the same monitor interval, and the monitor timeout value is no more than two times the monitor interval, the system marks the monitored resource as unavailable (due to a timeout) and then immediately marks the resource as available.

  • In the /var/log/gtm file, the following example sequence of log messages repeat:

    011ae0f2:1: Monitor instance /Common/my_monitor 10.1.1.1:80 UP --> DOWN from /Common/my_server (no reply from big3d /Common/my_server(192.168.1.1): timed out)
    011ae0f2:1: Monitor instance /Common/my_monitor 10.1.1.1:80 DOWN --> UP from 192.168.1.1 (state success)

Workaround

To work around this issue, you can set the monitor interval to a value greater than the number of monitored resources that use that same interval value. 

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

The key to this workaround is to ensure that the sum of the monitored resources at a given interval is not greater than the interval. You can achieve this work around in several ways, depending on your configuration and requirements.

For example, if the monitoring interval is 30 seconds, and there are 40 different monitors with a 30-second interval, and each monitor is assigned to exactly one resource, you have at least two options:

  • Change the interval for 10 of the monitors to a different value.
  • Set the monitor interval to 40.

Note: If you change the monitor interval, make sure to also change the timeout value to follow best practices: timeout value = (3 x interval) + 1.
