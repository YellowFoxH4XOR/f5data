K6814: Adding SRV or other DNS records not supported through the 3-DNS NameSurfer utility

Topic

The 3-DNS does not support adding some types of DNS records, such as Services (SRV) records, through the NameSurfer utility.

Note: The ability to add an SRV record through the 3DNS NameSurfer utility was added in 3_DNS version 4.6.4. However, the following workaround will allow you to add unsupported DNS records and SRV records in earlier versions of 3-DNS.

You can add an SRV record or other unsupported record to a zone by exporting your DNS zone file, adding the record manually, then re-importing the DNS zone file back into the NameSurfer utility. To do so, perform the following procedure:

  1. Log in to the 3-DNS Configuration utility.
  2. Click NameSurfer.
  3. Click on the zone you want to modify.
  4. From the Export zone section, click DNS master file.

    The zone file should be displayed with output similar to the following example:

    ; Generated by NameSurfer 2.2.3 on Wed, 16 Aug 2006 19:31:40 GMT

$ORIGIN yourdomain.com.
yourdomain.com.	86400	IN	SOA	server.yourdomain.com. 
		 	hostmaster.server.yourdomain.com. ( 
			2006081611 28800 7200 604800 86400 )
			NS	ns1
			A	172.28.22.228
server		A	172.30.79.10
  5. Copy the zone file output to a text editor.
  6. Edit the output by adding the desired SRV or other records in BIND format.

    The resulting zone file will look similar to the following example:

    ; Generated by NameSurfer 2.2.3 on Wed, 16 Aug 2006 19:31:40 GMT

$ORIGIN yourdomain.com.
yourdomain.com.	86400	IN	SOA	server.yourdomain.com. 
			hostmaster.server.yourdomain.com. ( 
			2006081611 28800 7200 604800 86400 )
			NS	ns1
			A	172.28.22.228
server		A	172.30.79.10
_foobar._tcp		SRV	0 1 9 server
*._tcp			SRV	0 0 0 .
  7. Save the text zone file.
  8. From the bottom of the Configuration utility, click Return to Configuration Utility.
  9. Click NameSurfer.
  10. Click on the zone you want to modify.
  11. From the Import names section, click Upload.
  12. Click the Browse button.
  13. Navigate to and select the text zone file saved in step 7.
  14. Click the Upload button.

You will see the new zone records displayed. The symbol displayed for the zone records will be a question mark (?).
