Topic

When you boot a system (such as a laptop, desktop, or server) using the F5 PXE boot CD, the speed and duplex settings for the network interface card on the server are set to auto-negotiate. You cannot change this default setting.

When you push the NetBoot button on a BIG-IP switch platform or server appliance, the relevant interface defaults to auto-negotiate mode.

Note: If a 3.1 interface (switch platform) or a 1.1 interface (server appliance) is plugged into a device that does not use auto-negotiate mode, the speed in which BIG-IP or 3-DNS software installs will be reduced.
