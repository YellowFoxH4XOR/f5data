Description

Web GUI menu's do not show correctly.

 

Figure: Web Gui Menu missing

Environment

  • LTM
  • WEB GUI
  • Web Browser
  • CLI

 

Cause

Issue with web browser.

Issue using an old, outdated web browser.

Recommended Actions

Try any of the following options below to see if it resolves the issue -

  • Clear the browser cache
  • Use a different browser
  • Use a browser on a different computer to access the page
  • Use a modern updated web browser

If the actions above do not solve the issue, please run below command in the CLI.
# bigstart restart restjavad restnoded tomcat httpd

Impact: Running this command won't disrupt production traffic, so no Maintenance Window is needed. GUI will be temporarily unavailable until all daemons are up.
