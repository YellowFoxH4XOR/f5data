Description

When trying to modify a client ssl profile like by CLI like next:

Example:

tmsh modify ltm profile client-ssl myprofile key f5key.new.key cert f5cert.new.crt

Getting an error like this:

01070277:3: The requested key (/Common/f5.new.key) was not found.

 

Environment

- Upgrade from 13.X to 15.X

Cause

Not requiring the .key or .crt extension in the command after 15.X

Recommended Actions

Run same command with no .key and .crt, like next:

tmsh modify ltm profile client-ssl myprofile key f5key.new cert f5cert.new

None
