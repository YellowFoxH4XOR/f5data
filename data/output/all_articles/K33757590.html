Security Advisory Description

A DLL hijacking issue exists in cachecleaner.dll included in the BIG-IP Edge Client Windows Installer. (CVE-2021-23023)

Impact

This vulnerability may be exploited to allow an unprivileged user to use a malicious DLL to gain privilege escalation on the client Windows system. Customers are advised to update to a fixed version of the BIG-IP Edge Client software as listed in the security advisory.
