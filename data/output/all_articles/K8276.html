This procedure configures dynamic group mapping using a RADIUS vendor-specific attribute (VSA), with the standard VSA, number 26. The standard VSA is defined in RFC2138: Remote Authentication Dial In User Service (RADIUS), and RFC2865: Remote Authentication Dial In User Service (RADIUS). If your RADIUS server is not RFC compliant, refer to your vendor documentation to determine the appropriate VSA number for your implementation.

This procedure maps the RADIUS group salesgroup to the FirePass group Sales. The RADIUS group is defined by the value of the VSA Some-Vendor-Attribute as shown in the following example:

jsmith
User-Password = "password1"
Some-Vendor-Attribute = "salesgroup"

To configure dynamic group mapping using a RADIUS vendor-specific attribute, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Dynamic Group Mapping page.
  3. Select the Determine the user's master group dynamically using the master group mapping table check box, located under the Group Mapping Sequence tab.
  4. Navigate to the Users: Groups: Master Groups page.
  5. Click the Create new group button.
  6. In the New Group name field, enter the name of the new Master Group.

    For example:

    Sales
  7. In the Users in group menu, select External.
  8. In the Authentication method menu, select RADIUS.
  9. Click the Create button.You are redirected to the Master Group configuration page.
  10. Under the General tab, select the Allow users to be assigned to this master group using dynamic master group mapping check box.
  11. Click the Authentication tab.
  12. Configure the settings required for your RADIUS server.
  13. Click the Save Settings button.
  14. Click the Test Saved Settings button.
  15. Enter a valid RADIUS username and password in the Username and Password fields, and then click the Test RADIUS Settings button.

    If the RADIUS test passed, proceed to the next step.

    If the RADIUS test failed, compare the information you entered in Step 12 with your RADIUS server configuration, and adjust the FirePass configuration as necessary. Additionally, ensure that your RADIUS server has the IP address of the FirePass controller configured as a RADIUS client.
  16. Navigate to the Users: Groups: Dynamic Group Mapping page.
  17. Click the Group Mapping Methods tab.
  18. In the Mapping methods drop-down menu, select RADIUS.
  19. Click the Add mapping method button.
  20. Click the Configure link next to the RADIUS mapping method.
  21. In the RADIUS Settings and Primary RADIUS server sections, configure the settings required for your RADIUS server. If you are using backup and tertiary RADIUS servers, complete the Backup RADIUS server and Tertiary RADIUS server sections.
  22. In the RADIUS attribute field, enter 26.

    Note: If your RADIUS server is not RFC2865 compliant, you may need to enter a different numeric value in this field.
  23. Next to the Attribute contains button, select the option that matches the format of the VSA value.

    For example:

    Single group
  24. Click the Update button.
  25. Click the Master group mapping table tab.
  26. Select RADIUS from the Master group mapping table drop-down menu.
  27. Click the Add button.
  28. In the RADIUS Group column, enter the group name contained in the VSA value.

    For example:

    salesgroup

    Important: The RADIUS Group field is case-sensitive. If you enter SalesGroup and the RADIUS server returns salesgroup, FirePass does not consider that a match.
  29. In the FirePass Group column, select the name of the Master Group you configured in Step 6.

    For example:

    Sales
  30. Click the Add button.
  31. Enter a valid RADIUS username and password in the User name and Password fields, and then click the Test button.

If the RADIUS group mapping test passed, the procedure is complete. If the test failed, compare the information you entered in Steps 22 through 24 with your RADIUS server configuration, and adjust the FirePass configuration as necessary.
