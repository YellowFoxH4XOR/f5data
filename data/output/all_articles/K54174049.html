K54174049: Enable or disable Appliance-mode for F5OS-A rSeries

Description

The F5 rSeries systems have the option of running in Appliance mode. Appliance mode is designed to limit the system administrative access to match that of a typical network appliance and not a multi-user UNIX device.

  • The Always-On Management (AOM) subsystem is not able to access the host. AOM is only able to reset the host using a hardware reset command.
  • Access to the Advanced shell (bash) is removed
  • System root user cannot log in to the device by any means, including from the serial console.

Environment

Relevant environmental factors specific to the topic

  • F5OS-A 1.x
  • The F5 rSeries hardware products such as r5900 

Cause

For security reasons, you may want to keep the appliance mode enabled, unless you need to go to the AOM menu or you need to go to the bash shell or use the root user in the CLI, in these cases you would need to disable the appliance mode. 

Recommended Actions

In case you need to disable the appliance mode:

Impact of procedure: Performing this procedure should not have any impact on your system. Note that once you commit the changes, it takes effect immediately; the F5 rSeries system does not require a reboot to effect the change and any running tenants will not be affected.

  1. Log in to the command-line interface (CLI) of the system controller using an account with admin access.
    When you log in to the system, you are in user (operational) mode.
  2. Check whether the system is in appliance mode:
    # show system appliance-mode state
    If appliance mode is enabled, proceed to disable it. Otherwise, skip the following steps.
  3. Change to config mode.
    # config
    The CLI prompt changes to include (config).
  4. Disable appliance mode:
    (config)# system appliance-mode config disabled
  5. Commit the configuration changes.
    (config)# commit
  6. Leave config mode.
    (config)# exit

In case you need to enable the appliance mode:

Important: If your rSeries system is running F5OS-A 1.1.0 and you have enabled appliance mode on it, you must not power down the system from Linux using certain commands. If you do so, the system becomes permanently disabled. For more information, refer to K22954168: The rSeries appliance fails to boot in certain circumstances.
