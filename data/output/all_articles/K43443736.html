K43443736: Receiving errors deploying AS3 declarations through BIG-IQ to BIG-IP

Type
Support Solution
Published
2021-10-29
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X, 6.X.X
Source
https://my.f5.com/manage/s/article/K43443736

Description

AS3 deployments are failing with the following message

"results": [
    {
        "message": "Failed to send declaration: Failed to process declaration for device https://10.10.10.200:443; status: 0; message: Declaration successfully submitted; response: null",
        "code": 422,
        "host": "localhost",
        "tenant": "tenant1",
        "runTime": 47670
    }
]

Environment

  • BIG-IQ used for AS3 deployment
  • BIG-IP that has been discovered by BIG-IQ

Cause

restjavad not responding on the BIG-IP

Recommended Actions

Restart restjavad on the BIG-IP 
# tmsh restart sys service restjavad

Additional Information

None
