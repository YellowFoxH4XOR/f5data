Known Issue

PolicySync may not remove temporary folders after synchronization.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration includes at least one access profile.
  • Your BIG-IP APM system is configured for synchronization to peer devices in a device group.
  • You synchronize the BIG-IP APM configuration with the peer devices of the device group.

Impact

The temporary system synchronization folder of the access profile is not deleted.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After synchronizing the BIG-IP APM configuration, related access profile system synchronization folders are not deleted.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to remove the temporary system synchronization folders. To do so, perform the following procedure:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Remove the system synchronization folder of the deleted access profile by using the following command syntax:

    delete /sys folder POLICYSYNC_<profile name>

  3. To exit the tmsh utility, type the following command:

    quit
