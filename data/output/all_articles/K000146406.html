Description

Daemon.log is taking lot of disk space.

Environment

  • BIG-IP
  • Logging files
  • Disk space full

Cause

The SNMPD logs can grow large but are not rotated so the /var/log space can become full.

Recommended Actions

Use the TMSH sys log-rotate command to modify the log-rotate settings to add the snmpd.log:

The syntax is:

tmsh modify sys log-rotate syslog-include "/var/log/snmpd.log {

compress

missingok

notifempty

postrotate

killall -HUP snmpd 2>/dev/null || true

endscript

}

"
