Recommended Actions

Writing the output to a custom file would require Tcl command file which is disabled in standard iRule syntax. Please see the following article for the complete list of disabled commands

K36322151: List of disabled Tcl commands for iRules (12.x - 17.x)

Additional Information

File operations may be implemented using node.js available via iRules LX functionality.
