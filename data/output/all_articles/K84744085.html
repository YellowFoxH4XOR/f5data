Description

  • Configuration utility becomes unresponsive and displays a blank page or load partially.
  • High analysis plane CPU usage
  • There are multiple audit_forwarder processes running.

Environment

  • BIG-IP
  • Configuration utility (GUI)

Cause

Seen behaviour is caused by a known issue tracked with the Bug ID 628703

Recommended Actions

Restart the syslog process. The following procedure will not have a negative impact on the production traffic, only remote logging is stopped while the process restarts.

  1. Connect to CLI
  2. Restart syslog process

    bigstart stop syslog-ng

Additional Information

The issue is triggered when running multiple instances of syslog-ng. You can avoid triggering the issue by not manually starting more than one instance of syslog-ng.
