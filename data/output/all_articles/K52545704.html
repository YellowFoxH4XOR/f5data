Description

/var/log is filling up and /var/log/ltm logs below error message:

diskmonitor[<PID>]: 011d0004:3: Disk partition /var/log has only 0% free

And you can see /var/log/journal folder size is large.
 

Environment

  • BIG-IP
  • v14.1.x - v17.1.2.2
  • /var/log/journal/
     

Cause

Bug ID 867253
 

Recommended Actions

Run below command to delete older then 7 days
 

find /var/log/journal/`cat /etc/machine-id`/user*  -mtime +7 -type f -delete


You can also implement cronjob daily task follow below procedure:

  1. login to CLI as root or administrative level user account , and execute crontab edit mode:
    crontab -e
     
  2. press [shift]+[i] key combination to go in to insert mode.
     
  3. then move the cursor to the end of file and add new line
     
  4. type desired minutes, hour, and the command
    For example if you want to run command daily 3:20 AM, crontab must have
    20 3 *  *  * find /var/log/journal/`cat /etc/machine-id`/user* -mtime +7 -type f -delete
    NOTE: First number is minute, second number is hour when you want the command to run.
     
  5. press [Esc] key to exit insert mode
     
  6. to save change, type below and press [Enter] key
    :qw!
     
  7. to check the change, run below command:
    crontab -l
     

Additional Information

You may have other reason for /var/log is occupied, please follow K14403: Maintaining disk space on the BIG-IP system
