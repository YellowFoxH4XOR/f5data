Issue

Error Message

01070394:3: <command> in rule (<r_name>) requires an associated <type> profile on the virtual server (<vs_name>)

In this error message, note the following:

  • <command> is the iRule command generating the error message.
  • <r_name> is the name of the iRule in the configuration.
  • <type> is the type of profile required to resolve the error message.
  • <vs_name> is name of the virtual server with the associated iRule.

For example:

01070394:3: HTTP_REQUEST event in rule (maintenance_page) requires an associated HTTP or FASTHTTP profile on the virtual server (vs_example_443)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions are met:

  • You have created an iRule that processes a specific type of traffic.

    For example:

    when HTTP_REQUEST {
        HTTP::respond 200
    }

  • You attempt to associate the iRule with a virtual server.
  • The virtual server does not reference a traffic processing profile required to support the iRule.

Virtual servers, iRules, and traffic processing profiles must work together when processing traffic. Virtual servers use iRules to direct network traffic and to modify payload data, but must have the proper associated traffic processing profile to understand the type of traffic being processed.

Impact

The virtual server will not pass validation or process traffic.

Recommended Actions

Most iRule and traffic processing profile errors occur at Layer 4 (TCP and UDP) and layer 7 (HTTP, DNS, SSL, etc.) of the Open Systems Interconnection (OSI) model. Think about the traffic processing protocols involved when you associate an iRule with a virtual server, and associate the appropriate traffic processing profile. For example, if you intend to use the HTTP::disable command in an iRule, your virtual server should have an associated TCP and HTTP profile. If you intend to use the SSL::handshake command in an iRule, your virtual server should have an associated Client SSL and TCP profile.
