Known Issue

This is the result of a known issue. If you configure a specific fixed media type for a BIG-IP interface, the setting is not retained following a system reboot or a restart of the mcpd process.

For example, if you change the requested media for interface 1.1 from autonegotiate to 100baseTX, full, the requested media changes back to the auto-negotiate setting following a system reboot or a restart of the mcpd process. This behavior occurs for both the management port and TMM ports.

F5 Product Development tracked this issue as CR106999 and it was fixed in BIG-IP 9.4.7. For information about upgrading, refer to the BIG-IP BIG-IP LTM, ASM, GTM, Link Controller, PSM, or WebAccelerator release notes.

Note: For information about a similar issue affecting BIG-IP versions prior to 9.4.5, refer to K4358: The management port interface only supports the auto-negotiate media setting.

Workaround

You can work around this issue and restore the media type setting for the affected interfaces by issuing the bigpipe load command at the BIG-IP command line after mcpd completes its initialization and logs the following message in /var/log/ltm:

Oct 14 19:10:57 big-ip mcpd[1989]: 01070427:5: Initialization complete. The MCP is up and running

This command will then load the custom interface settings, which will remain active until mcpd restarts.

In addition, you may automate the bigpipe load command execution by using the alertd facility to monitor the logs for the above message. To do so, perform the following procedure:

  1. Open the /config/user_alert.conf file in a text editor.
  2. Add the following lines to the end of the file:

    alert if_media_workaround "Initialization complete. The MCP is up and running" {
    exec command="/bin/bigpipe load"
    }

  3. Save and close the file.
  4. At the command line, execute the following command to persist this change through future reboots:

    bigpipe save all

The system will now recognize an mcpd restart, and will automatically execute the bigpipe load command to reload the custom interface settings.
