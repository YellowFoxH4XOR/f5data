Known Issue

This is the result of a known issue. The Extended Windows and IE info inspector fails to detect the existence of Service Pack 1 (SP1) on clients running 64-bit editions of Windows Vista. For example:

( (session.win_info.os_version=="WinVI64"} AND EXIST(session.win_info.hotfixes.hf_sp1) )

If you configured a pre-logon sequence with the Extended Windows and IE info inspector and inserted the example rule, clients running 64-bit editions of Windows Vista will not match that rule even if SP1 is installed on the client system.

F5 Networks Product Development tracked this issue as CR108533 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative hotfix HF-602-8 has been issued for FirePass version 6.0.2 and cumulative hotfix HF-603-1 has been issued for FirePass version 6.0.3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
