Description

Specific SR-IOV hardware cause IPv6 virtual servers response failure to NDP(Network Discovery Protocol) solicitations, resulting in ping or traffic failure.

Environment

  • BIG-IP LTM
  • OpenStack using SR-IOV
  • Intel X520 NIC hardware
  • IPv6 Virtual Servers

Cause

MAC(Media Access Control) filters for IPv6 addresses are not populated until ingress vlan is assigned.  This issue is due to F5 bug ID 615329

Recommended Actions

  1. Assign ingress vlan to vlan-enabled configuration of virtual server with the following commands:
modify ltm virtual <name> vlans-enabled
modify ltm virtual <name> vlans add { <vlans> }
