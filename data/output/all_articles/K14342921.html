Issue

Error Message

01910014: FATAL error: non_initial state <state_id> and some state vars are unknown (cluster: <cluster_id>, primary: <primary_blade>)

In this error message, note the following:

  • <state_id> is the process state ID.
  • <cluster_id> is the cluster ID of your VIPRION system.
  • <primary_blade> is the blade in the primary slot.

For example:

01910014: FATAL error: non_initial state (3) and some state vars are unknown (cluster: 0, primary: 0)

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • Your VIPRION systems are configured as part of a high availability (HA) group.
  • Your license state is unknown or the routing license is expired on the standby unit.

Impact

The tmrouted process restarts on the standby VIPRION system. The BIG-IP system may temporarily fail to process traffic as it recovers from the tmrouted restart.

Recommended Actions

You should renew the license for the BIG-IP system before it expires. For more information about licensing the BIG-IP system, refer to K7752: Licensing the BIG-IP system.
