K000139082: Not able to upload/download files from F5OS via /API

Type
Support Solution
Published
2024-03-28
Updated
2024-03-28
Source
https://my.f5.com/manage/s/article/K000139082

Description

When you go to download a file, such as a F5OS Backup, using API it fails.

Environment

According to F5 documentation the use of either ip:443/api and/or ip:8888/restconf should be interchangeable when uploading/downloading files.

  • Downloading an F5OS Backup via API

Cause

Per current design F5OS currently only supports /restconf. The issue has been identified as ID1572137 Upload/Download API should work with /api as well as /restconf

Recommended Actions

The issue is projected to be corrected in a future release.

The workaround is to use /restconf as there is no workaround to enable the use of /api.
