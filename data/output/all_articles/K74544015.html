K74544015: Removing nginx/<version> from HTTP response headers

Type
Support Solution
Published
2020-01-07
Updated
2025-04-02
Applies to
  • NGINX Products
  • NGINX Plus: R22, R21, R20
Source
https://my.f5.com/manage/s/article/K74544015

Description

How to remove the NGINX identifying server header from HTTP responses. 

Environment

  • NGINX Plus

Cause

The default HTTP Server header for NGINX Plus is nginx/<version>. For example, the default Server response header for an NGINX server running version R20 would be nginx/1.17.6.

Note: NGINX Plus version R20 is based on NGINX Open Source version 1.17.6. For more information, refer to NGINX Plus Release 20 (R20).

Recommended Actions

  1. Log in to the command line of the NGINX Plus system.
  2. Disable the output of product and version by adding the following server_tokens directive to the HTTP context of your /etc/nginx/nginx.conf file:

    server_tokens '';

  3. Reload the nginx process by running the following command:

    sudo nginx -t && sudo service nginx reload

Additional Information

The server_tokens directive supports the following options. For more information, refer to the Module ngx_http_core_module page.

OptionHTTP Server response header
on (default)Displays nginx/<version>. For example, nginx/1.17.6.
offDisplays only nginx, without any additional version information.
build (NGINX R12 and later)Displays NGINX build name, in addition to nginx/<version>. For example, nginx/1.15.10 (nginx-plus-r18-p1).
<string> (NGINX R9 and later)Displays only a string, defined by <string>. For example, using the server_tokens 'example'; directive, the response header would return only the string example.
