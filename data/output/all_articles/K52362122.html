Description

Console log contains B9 character while booting or running EUD

For example (Out put of console log)

12 04 2021 14:38:35 Test Complete: PASSED
...
--More--(41%)[Press space to continue, 'q' to quit.]1019F5A1A3A3A7A9AAAAABAFB0B1AF1019F5A1A3A3A7A9A7A7A7A8A9A9A9AAAAAAAEAFB0B1B4B2B3B6B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B7B8B9B9 <==

This symptom indicate possible hardware issue, and we can proceed RMA    

Environment

  • BIG-IP
  • Console log

Cause

During boot it is normal for a series of Hexidecimal numbers to appear in the Console
However, if the boot does not progress any further, it is possible a hardware failure has occurred
 

Recommended Actions

  1. If you see a similar console log as mentioned above, please proceed with the EUD test to verify the hardware problem.
  2. Save the serial console output of the EUD tests to a file for uploading to F5 Support.
  3. Contact F5 Support for further investigation and assistance.
