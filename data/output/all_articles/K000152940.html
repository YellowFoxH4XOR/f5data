Description

Custom user role to upload OpenAPI Specification Files

Environment

  • F5® Distributed Cloud Console

Resolution/Answer

A custom role can be created with the following API groups to enable user access to upload OpenAPI Specification Files:

system namespace:

  • f5xc-core-platform-services-basic-monitor

default namespace:

  • f5xc-core-platform-services-standard-monitor
  • f5xc-core-platform-services-standard-user
