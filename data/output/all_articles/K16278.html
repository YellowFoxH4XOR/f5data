Known Issue

TMM may produce a core file when the SSL forward proxy feature is enabled for the SSL profile.

This issue occurs when the following condition is met:

  • Forward proxy passthrough is enabled in the profile or in an iRule.

Impact

The Traffic Management Microkernel (TMM) may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system sends a SIGSEGV signal to TMM, resulting in a stack trace and core file.
