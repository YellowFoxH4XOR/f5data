Description

NGINX Plus Docker Agent container fails to connect to NGINX Instance Manager's APIGW service and the following error, or similar, is reported:

ERRO[0003] Unable to create command channel: rpc error: code = Unavailable desc = connection error: desc = "error reading server preface: http2: failed reading the frame payload: %!w(<nil>), note that the frame header looked like an HTTP/1.1 header"

Environment

NGINX Instance Manager

NGINX Plus Docker Agent

Cause

This issue can occur when Agent, within the NGINX Plus Docker Agent container, is started without TLS enabled. For example:

docker exec (docker_agent_container) sh -c "/usr/bin/nginx-agent --server-host=(apigw_service_host) --server-grpcport=443 --log-level=debug --tls-skip-verify=true"

Recommended Actions

Enable TLS when starting Agent. For example:

docker exec (docker_agent_container) sh -c "/usr/bin/nginx-agent --server-host=(apigw_service_host) --server-grpcport=443 --log-level=debug --tls-enable=true --tls-skip-verify=true"
