Description

You may encounter the following error when attempting to install certain BIG-IP versions on an unused volume:

Severity: Error failed (Archive signature test failed.)

This is because, starting with select BIG-IP releases (including 17.5.1.3), F5 updated the image signing and verification process. If your system is FIPS-licensed (or has signature verification enabled), the upgrade process enforces that both the ISO and its corresponding .sig file are present and valid. If the .sig file is missing, invalid, or the image was signed with a key not recognized by your current system, the upgrade will fail with this error.

This is expected behavior for FIPS-licensed systems or systems with signature verification enabled.

Environment

  • Affected versions:
    • BIG-IP 17.5.1.3
    • BIG-IP 17.1.3
    • BIG-IP 16.1.6.1*
    • BIG-IP 15.1.10.8*+
  • You attempt installation on an unused volume.
  • The liveinstall.checksig database variable is enabled.

Cause

A key update in October 2025 modified the image signing and verification process for select BIG-IP releases listed above. Images signed with new keys may not be automatically verified by earlier BIG-IP versions, resulting in installation failures due to signature verification errors.

Recommended Actions

To install one of these affected releases on a non-FIPS BIG-IP, perform the following procedure:

  1. Ensure both the ISO and .sig file are present in the correct directory on the BIG-IP before starting the upgrade.
  2. Temporarily disable BIG-IP ISO signature verification as documented in K15225: Enabling signature verification for BIG-IP and BIG-IQ ISO image files.
  3. Manually verify the signatures; refer to K24341140: Verifying BIG-IP and BIG-IQ software images using SIG and PEM files.
  4. Install the desired BIG-IP release (for example, one of the affected versions).
  5. Re-enable BIG-IP ISO signature verification after installation is complete.

    Note: The liveinstall.checksig database variable is disabled by default except on FIPS-licensed systems in which it is enabled by default. 

For detailed instructions, refer to K15225: Enabling signature verification for BIG-IP and BIG-IQ ISO image files.
