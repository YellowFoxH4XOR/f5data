Topic

This article applies to BIG-IP 11.x through 13.x. For information about earlier versions, refer to the following article:

  • K9337: Persistence entries mirrored to the standby BIG-IP system show an age of 0 seconds (9.x - 10.x)

The persistence mirroring feature duplicates the active BIG-IP system's persistence information to standby device group members. When failover occurs, persistent connections can proceed as the peer system becomes active.

When viewing the mirrored persistence entries on the standby unit, using the Configuration utility or the command line, the age value is always displayed as 0 (zero) seconds.

For example, when run on the standby system, the tmsh show /ltm persistence persist-records all-properties command displays the age as 0, as shown in the following output:

Sys::Persistent Connections
source-address - 10.11.16.225:22 - 10.11.16.216:22
--------------------------------------------------
TMM 1
Mode source-address
Value 10.11.16.216
Age (sec.) 0
Virtual Name /Common/ssh_vip
Virtual Addr 10.11.16.225:22
Node Addr 10.11.16.216:22
Pool Name /Common/ssh_pool_1
Client Addr 10.11.16.216
--------------------------------------------------

This behavior is expected. The active system does not mirror the persistence age to the standby system.
