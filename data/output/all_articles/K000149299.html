Description

After upgrading one of the 2 units in the DSC cluster configsync no longer worked between them.

Environment

  • BIG-IP
  • Configsync
  • DSC
  • Upgrade

Cause

BIG-IP units must be on the same major/minor software version in order for configsync to function. Having upgraded one of the units in the cluster, both units were no longer on the same software version.

Recommended Actions

Upgrade all units to the same version and configsync will be restored.

None
