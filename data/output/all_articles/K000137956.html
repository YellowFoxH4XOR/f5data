K000137956: F5OS GUI and API changes may not have associated audit logs

Type
Support Solution
Published
2023-12-19
Updated
2023-12-19
Source
https://my.f5.com/manage/s/article/K000137956

Description

If you create objects in the GUI or use the API, and you create multiple objects at the same time, you may not see audit logs for every object created

Environment

F5OS Controller or Appliance

Cause

This issue is assign ID1411137 Audit log entries throttled or missing when creating or deleting objects via UI or API

Workaround

If you only create single objects, then you should see the associated audit logs
