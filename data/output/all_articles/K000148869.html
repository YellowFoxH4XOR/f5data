Description

The apmd process is running out of file descriptors with similar messages in /var/log/apm:

Nov 18 05:09:28 apm1.hostname.local err apmd[18928]: 01490000:3: ApmD.cpp func: "process_apd_request()" line: 2094 Msg: Error 3 reading/parsing response from socket 1329. strerror: Too many open files, queue size 0, time since accept 0

Nov 18 05:09:28 apm1.hostname.local err apmd[18928]: 01490000:3: HTTPParser.cpp func: "readFromSocket()" line: 117 Msg: epoll_create() failed [Too many open files].

Environment

BIG-IP APM

Cause

Unknown

Recommended Actions

In order to determine the cause please capture the following data and create a support case for investigation.

1. On an ssh session run the following:

{ lsof -p $(pidof apmd) | grep TCP; lsof -p $(pidof apmd); } > /var/tmp/apmd_lsof_log.txt

2. On another ssh session run the following for at least 5 minutes:

strace -o /var/tmp/strace_log.txt -CyttT -f -p $(pidof aced) -s 512 -e 'trace=network'
