Known Issue

VIPRION Virtual Clustered Multiprocessing (vCMP) guests can access networks through interfaces no longer assigned to a trunk.

This issue occurs when all of the following conditions are met:

  • You have a VIPRION system provisioned for vCMP.
  • You have configured a trunk using multiple interfaces on the vCMP host.
  • You have a vCMP guest that connects to remote devices using the trunk.
  • Using the Configuration utility on the vCMP host, you remove interfaces previously used by the vCMP guest from the trunk configuration.

Impact

VIPRION vCMP guests have unexpected access to network subnets.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • vCMP guests are accessing networks that should no longer be inaccessible.
