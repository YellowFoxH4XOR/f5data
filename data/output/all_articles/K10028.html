K10028: Users are unable to connect from a Windows Mobile device if a client certificate is requested

Topic

Users that attempt to connect to a FirePass Controller that requests a client certificate from a Windows Mobile device might not be able to access the logon page. This issue can also occur when the client certificate is requested (not required).

If you are running FirePass version 6.0.2 or 6.0.3, you can configure a virtual host on the FirePass controller that does not request a client certificate, and direct all Windows Mobile devices to the virtual host with a pre-login sequence rule. For more information about configuring a virtual host to use for logon, refer to the FirePass Controller Administrator Guide.
