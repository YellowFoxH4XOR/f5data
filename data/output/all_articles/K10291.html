K10291: Application Tunnels for Citrix MetaFrame Terminal Server favorites open two ports when session reliability is enabled

Topic

When you configure a Citrix MetaFrame Terminal Server favorite and select the Enable session reliability check box, two Application Tunnels are opened when the user launches the favorite. The first tunnel is for the legacy port number you configured in the Port field (typically port 1494), and the second tunnel is for the session reliability port you configured in the Session reliability port field (typically port 2598).

This behavior ensures that a user can connect to the favorite even if the Citrix server has session reliability disabled, or if the version of the Citrix ICA client installed on the client system does not support session reliability.

If you do not want to users to be able to connect to the legacy port number, configure the session reliability port number in both the Port field and the Session reliability port field.

Note: Terminal Server favorites are configured on the Application Access: Terminal Servers: Resources page.
