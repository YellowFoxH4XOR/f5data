Description

You are unable to import a new certificate or key.

Environment

  • Using the Configuration Utility (GUI)

Cause

The root file system  /   is full.
Start a command line session, (bash) and run
df -h

The /  filesystem must have available space.
 

Recommended Actions

  1. Find and delete the files which are using the space.
  2. Retry the Import.

Additional Information

Refer   K11176458   011d0004:3: Disk partition / (slot #) has only 0% free space
for methods for finding and removing the unwanted files.
The  /  filesystem is not intended to store  information and is small.
