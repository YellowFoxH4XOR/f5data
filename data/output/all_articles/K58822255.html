Description

  • When trying to remove an iApp a similar error shows: "The application service (/Common/iAppName.app/iAppName) has strict updates enabled".
  • When trying to access the iApp on the Configuration Utility, to disable strict updates, the iApp is not visible.

Environment

  • iApp with Strict Updates enabled
  • Configuration Utility (GUI)

Cause
The iApp description is set to "hide".

Recommended Actions

  1. Log into the BIG-IP using CLI and change the description of the iApp to "None". This will show the iApp on the GUI again.
    # tmsh modify /sys application service iAppName.app/iAppName description none
  2. Then you can proceed to disable Strict Updates and delete the iApp.
    K51699308: Modifying or deleting an iApp
