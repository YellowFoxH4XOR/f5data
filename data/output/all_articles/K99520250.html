Description

After the HTTP analytics profile is created and associated with the virtual servers, the information in analytics does not appear.

Environment

  • HTTP analytics profile.
  • BIG-IP LTM/AVR
  • Virtual server.

Cause

Unknown. 

Recommended Actions

To apply the changes the avrd service should be restarted:

#tmsh restart /sys service avrd

Optional:

Please clear statistics of that VS to have accurate information.

Additional Information

None.
