Source

Description

AS3: Wrong policy action created when setting X-Forwarded-Prefix insert value to "http".


Environment

BIG-IP

AS3 v3.55.0 and prior


Cause

https://github.com/F5Networks/f5-appsvcs-extension/issues/859


Recommended Actions

This issue will be fixed in AS3 v3.56.0


Additional Information

example AS3 declaration snippet:


"actions": [

{

"event": "request",

"type": "httpHeader",

"insert": {

"name": "X-Forwarded-Host",

"value": "http"

}

}

]


# tmsh list ltm policy /Policy_Rule_Tenant/Policy_Rule_App/Policy_Rule_Endpoint_Policy


ltm policy /Policy_Rule_Tenant/Policy_Rule_App/Policy_Rule_Endpoint_Policy {

  partition Policy_Rule_Tenant

  requires { http }

  rules {

    Policy_Rule_rule1 {

      actions { <<<<<< Incorrect 'actions' was created

        0 {

          http

          enable

        }

      }

      conditions {

        0 {

          http-uri

          path

          starts-with

          values { / }

        }

      }

    }

  }

  status legacy

  strategy all-match

}


Expected Action configuration should be:


      actions {

        0 {

          http-header

          insert

          name X-Forwarded-Proto

          value http

        }
