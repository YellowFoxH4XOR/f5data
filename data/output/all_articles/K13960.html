Known Issue

The Enterprise Manager may assign an incorrect role to a user account.

This issue occurs when all of the following conditions are met:

  • You attempt to perform a Copy User Access Configuration task on an Enterprise Manager from one managed device to another managed device.
  • The managed devices are running BIG-IP 11.0.0 or later.
  • The managed device has a user configured with one of the following user roles:

    • Acceleration Policy Editor
    • Auditor
    • iRule Manager
    • Web Application Security Editor

Impact

The user may not be able to perform expected administrative tasks due to the incorrect role assigned.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The affected user account copied to the destination managed device may have the role displayed as No Access in the Configuration utility > System > Users > User List.
  • The Traffic Management Shell (tmsh) utility may display an incorrect role for the affected user account. For example, if the my_user1 user account is supposed to have a role of auditor at the source managed device, the tmsh list /auth user command output should appear similar to the following example:

    auth user my_user1 {
        description "my_user1"
        encrypted-password "$1$14BATdAB$PX0gxa60s2amXq4fUtTPt."
        partition Common
        partition-access all
        role auditor
        shell none
    }

    However, due to this known issue, the output may appear similar to the following example:

    auth user my_user1 {
        description "my_user1"
        encrypted-password "$1$14BATdAB$PX0gxa60s2amXq4fUtTPt."
        partition Common
        partition-access all
        role no-access
        shell none
    }

Workaround

To work around this issue, you can manually modify the role for the affected user account on the destination managed device after the Enterprise Manager completes the Copy User Access Configuration task. To do so, perform the following procedure:

Impact of workaround: You must have administrative access to the Configuration utility or tmsh utility of the affected managed devices. This task may require a substantial amount of time if the number of affected user accounts on the destination managed devices is large.

 

Modifying the role of the affected user account on the destination managed device

Using the Configuration utility

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click Users.
  4. Click User List.
  5. Click the affected user name.
  6. Modify the value for Role to the appropriate setting.
  7. Click Update.
  8. Repeat step 5 through 7 for other user accounts that need to be modified.

Using the Traffic Mangement Shell

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. Modify the user account to the correct value for its role using the following command syntax:

    modify auth <User-Name> role <Correct-Role-Value>

    For example:

    modify auth my_user1 role auditor
  3. Repeat step 2 for every other user account that needs to be modified to the correct role.
  4. Save the changes by typing the following command:

    save /sys config
  5. To exit, type the following command:

    quit
