K73427047: FEP down while incoming connection cannot be established with error udev: renamed network interface eth0 to eth4

Source

Description

You may encounter the below symptoms,
  • FEP down due to incorrect ethernet interface
  • Incoming connection cannot be established
  • Similar error message:
    • udev: renamed network interface eth0 to eth4

Environment

Traffix SDC 5.1

Cause

Backup files of 70-persistent-net.rules present in directory /etc/udev/rules.d/

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Move backup files of 70-persistent-net.rules to another location.
  2. Reboot the system.
  3. Make sure the MAC address mentioned in ifcfg-ethX and 70-persistent-net.rules
  4. Remove any extra rules if present in 70-persistent-net.rules file
