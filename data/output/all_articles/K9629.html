Topic

This article applies to BIG-IP versions 10.x and 9.x. For information about version 11.x, refer to the following article:

  • K13404: Overview of BIG-IP GTM global variables (11.0.0 - 11.4.1)

BIG-IP GTM global variables are system-wide settings, including load-balancing, metrics collection, and general configuration parameters. BIG-IP GTM global variables are configured in the Configuration utility:

  • On the System > Configuration > Global Traffic screen (10.x)
  • On the System > General Properties > Global Traffic screen (9.x)

Configured global variables can also be viewed in the globals section of the /config/gtm/wideip.conf file. Unconfigured variables do not appear in the wideip.conf file and take the specified default value.

The following tables list the global variables as they appear in the Configuration utility, and their corresponding values in the wideip.conf file.

Load Balancing global settings

Load Balancing global settings are located on the Load Balancing tab.

Configuration utility settingwideip.conf settingDefaultDescription
Respect Fallback Dependencyfb_respect_dependsnoSpecifies whether GTM accepts virtual server status when the load balancing mode changes to the Fallback method
Ignore Path TTLpaths_never_dienoSpecifies whether GTM dynamic load-balancing modes can use path data, even after the TTL for the path data expires
Verify Virtual Server Availabilitycheck_static_dependsyesSpecifies whether the GTM checks the availability of virtual servers before sending a connection to those virtual servers
Topology: Longest Match Firstlongest_matchyesSpecifies whether the GTM selects the longest matching or the first matching topology record. Longest match returns the record that most specifically matches the IP address in an LDNS request, regardless of the order of the records. First match selects the first matching record.
