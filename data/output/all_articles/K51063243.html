K51063243: Files in /home directories may cause upgrade to fail

Type
Support Solution
Published
2021-02-19
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K51063243

Description

Large files in home directories may cause an upgrade failure. This can occur if the  / file system, referred to as the root file system, has been expanded from its default size. The expanded size will not carry forward during the upgrade. If the pre-upgrade disk usage is larger or equal to the default size of the new install slot root filesystem, the upgrade root will run out of space. This can cause failures because some processes depend on having free root space to operate. 
 
Common locations where files will increase the root partition usage
  • /home/<user>
  • /tmp/

Symptoms that might indicate this has occurred
  • root filesystem is showing 100% usage
  • some services are not able to start

Environment

  • The root file system has been expanded on the current install slot

Cause

  • This is the expected behavior, modifications to the current root size are not carried forward

Recommended Actions

If the size of the current root file system has been increased and the current usage is greater than 427 MB (default root size as of 7.1.0), do not attempt an upgrade prior to reducing the disk usage below 427 MB.
