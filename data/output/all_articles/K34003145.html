Known Issue

FTP virtual server connections may rapidly reuse ephemeral ports.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a virtual server to process active FTP traffic.
  • You configure the FTP virtual server to use Source Port = Change.
  • The FTP virtual server processes thousands of FTP connections in a short period of time (under 300 seconds).
  • Your BIG-IP deployment uses any of the following hardware platforms:
    • 5000 series (C109)
    • 7000 series (D110)
    • 10000s/10050s/10200v/10250v (D113, D112)
    • VIPRION blades B4300/B4340N(A108, A110)

Impact

The system may fail to establish FTP connection requests.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The virtual server intermittently sends the FTP protocol error 425 unable to build data connection: address already in use to FTP connection requests.

Resolution

Workaround

To minimize the impact of this issue, you can modify the affected virtual server to use Source Port = Preserve.

Impact of workaround: Performing the suggested workaround minimizes the impact of the issue and does not resolve the issue.
