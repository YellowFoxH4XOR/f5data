K000159050: Examples provided in Terraform documentation for f5os_system prior to version 1.10.1 can cause k3s to not load

Type
Support Solution
Published
2026-03-24
Updated
2026-03-24
Applies to

  • F5OS
  • F5OS-A: 1.8.0, 1.8.X, 1.8.3
Source
https://my.f5.com/manage/s/article/K000159050

Description

After using the terraform example provided for the f5os_system resource in the f5os provider documentation, k3s installations fail with the following error in manage_k3s_service.log:

Failed to connect to the host via ssh: Unable to negotiate with 127.0.0.1 port 22: no matching MAC found

Environment

  • Documentation for terraform-provider-f5os prior to version 1.10.1

Cause

The documentation for f5os_system includes an example with a weak sshd_mac_alg algorithm: "hmac-sha1-96". Weak SSH MAC algorithms are known to cause k3s installation failures in F5OS as described in ID2163677.

Recommended Actions

Avoid using weak algorithms when configuring the f5os_system resource. The examples provided in terraform-provider-f5os documentation have been updated to avoid this issue starting with version 1.10.1 and up.
