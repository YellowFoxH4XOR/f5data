K000140449: [NEXT CM] - With querying the onboarding-manifest API endpoint, the "siteInto" record may be missing.

Description

The "onboarding-manifest" API call returns the onboarding manifest on a BIG-IP Next Instance. The response may contain a "siteInto" record, as the example below shows:

"siteInfo": {

"dnsServers": "[2001:db8:245:245::53, 192.0.2.53]",

"ntpServers": [],

"remoteSyslogServers": []

},

When the BIG-IP Next instance is an F5OS tenant, the "siteInfo" record is not visible.

Environment

BIG-IP Next Central Manager.

Cause

The NTP and DNS parameters are configured with VE Next instances, and not with F5OS instances.

As such, with F5OS Next tenants, the "siteInfo" record can't be returned.

A Request For Enhancement - RFE - has been raised to have the record available for BIG-IP Next F5OS tenant.

Recommended Actions

Do please feel free to raise a Support ticket to query the status of the aforementioned RFE.
