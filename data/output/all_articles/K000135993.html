Description

This article explains the values found in the GSLB topology record builder for ISP (request source).
There are no new records of ISPs, but there are 12 fixed static records of ISPs.

Environment

  • DNS
  • GSLB
  • Topology

Cause

The static files used for ISP are no longer updated, but the values are maintained for users who are still using them.

 Recommended Actions

To use the GSLB topology record builder for ISP, please use Geolocation ISP instead.
