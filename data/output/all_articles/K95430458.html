Known Issue

Installation of the SafeNet/Thales hardware security module (HSM) software may be incomplete.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system runs on a VIPRION platform.
  • The Chassis is in the standby state or secondary chassis blades (slots) are not configured with management addresses.
  • You use the nethsm-safenet-install.sh script to install the SafeNet/Thales HSM software.

Impact

Network HSM traffic processing fails when affected slots are utilized to process Secure Sockets Layer (SSL) traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing the running services for the pkcs11d service, some slots show the service as not running.

    For example, the command line check of the pkcs11d service appears similar to the following:

    clsh bigstart status pkcs11d

    === slot 1 addr 127.3.0.1 color green ===
    pkcs11d run (pid 9384) 30 minutes
    === slot 3 addr 127.3.0.3 color green ===
    Service pkcs11d has not been added to bigstart.
    === slot 4 addr 127.3.0.4 color blue ===
    === slot 5 addr 127.3.0.5 color blue ===
    === slot 6 addr 127.3.0.6 color blue ===
    === slot 7 addr 127.3.0.7 color green ===
    pkcs11d run (pid 9143) 30 minutes
    === slot 8 addr 127.3.0.8 color blue ===
    === slot 2 addr 127.3.0.2 color green ===
    pkcs11d run (pid 8127) 4 minutes

  • Slots without a running instance of the pkcs11d service are unable to use SafeNet/Thales HSM encryption service.

Workaround

To work around this issue, you can manually install the missing pkcs11d service on individual slots. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected slot.
  2. Install the pkcs11d service on the slot by typing the following bigstart commands:

    bigstart add pkcs11d

    bigstart start pkcs11d

  3. Optional: Repeat steps 1-2 for each affected slot.
