K000138609: A cosmetic issue in BIG-IQ backup schedules is causing certain GUI options to appear greyed out

Type
Support Solution
Published
2024-02-14
Updated
2025-09-11
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.X, 8.1.X, 8.2.X, 8.2.0, 8.1.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000138609

Description

In the BIG-IQ System>Backup>Backup schedules, some configuration settings are not displayed as previously configured. Also some option are greyed out in the backup schedules menu.

Environment

  • BIG-IQ
  • Backup Schedules
  • GUI

Cause

 It's a cosmetic issue and has been logged as ID1301225

Recommended Actions

This can be safely ignored, as the already created backup schedules will continue to work. If you would like to make some changes to the existing backup schedules you have to re-configure them again or create new ones.

 

Additional Information

None
