K000092341: Source IP is showing as self IP for outbound traffic through the F5

Type
Support Solution
Published
2022-08-25
Updated
2022-08-31
Source
https://my.f5.com/manage/s/article/K000092341

Description

Outbound traffic from our network that is passing through the BIG-IP is having the address translated to the self IP address.


 Environment

  • BIG-IP LTM
  • Address translation
  • SNAT

 Cause

The traffic is being handled by an unexpected Virtual server.


ltm virtual /Common/Forwarding {

destination /Common/0.0.0.0:0

ip-forward

mask any

profiles {

/Common/fastL4 { }

}

source 0.0.0.0/0

source-address-translation {

type automap <===== Disable snat automap and the traffic should no longer use the floating self IP address.

}

translate-address disabled

translate-port disabled

}

 Recommended Actions

Disable snat automap and the traffic should no longer use the floating self IP address.

 Additional Information

You can configure wireshark to display the Virtual server information by following the steps in K14812111. Once done you will want to expand the F5 Trailer Header and view the Low details. This will show you the Virtual server that is handling the traffic captured.



If you cannot remove snat automap from the Virtual server because it is handling traffic from other devices that require it. You can create another Virtual server with similar settings Destination 0.0.0.0 but configure the Source IP address to be your pool member or node X.X.X.X.
