Description

AS3: Unable to set requireSNI to true with multiple certificates in a single profile.

Using multiple SSL/TLS certificates in a single profile

 

Environment

BIG-IP LTM

AS3

 

Cause

"requireSNI" is being set at the TLS_Server level, which will be applied to all profiles.

 

Recommended Actions

This issue is fixed in AS3 v3.54.1. 

 

Additional Information
