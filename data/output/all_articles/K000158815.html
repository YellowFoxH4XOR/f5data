K000158815: LACP Trunk Down in iSeries devices, even though the interfaces themselves are UP

Type
Support Solution
Published
2025-12-30
Updated
2025-12-30
Source
https://my.f5.com/manage/s/article/K000158815

Description

LACP trunks configured on BIG-IP LTM interfaces become non-functional, with the trunk status showing as DOWN and no traffic passing through, even though the interfaces themselves are UP. The problem persists after replacing cables and SFPs.

Symptoms include:

  • LACP trunk status: DOWN
  • No interface flapping observed after reload/reboot

Environment

  • BIG-IP LTM
  • F5-BIG-LTM-ISeries devices
  • LACP trunk configuration with Cisco switch
  • Device in Standby mode when issue observed
  • Cables and SFPs replaced during troubleshooting steps
  • Trunk moved to other interfaces and works as expected

Cause

The likely cause is a stuck "pfmand" process, which handles link monitoring, link statistics, and media settings for some BIG-IP platforms including the I4800 series.

The "pfmand" process manages link monitoring; if it becomes unresponsive, it can affect interface/trunk status without hardware errors or flapping.

Recommended Actions

A system reloads or MCPD process restart typically clears this condition.

Perform an MCPD reload to restore functionality:

touch /service/mcpd/forceload; reboot
