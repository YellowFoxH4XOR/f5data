K12809: Configuring an ARX namespace for only Kerberos and NTLMv2 authentication causes access failure for clients using NTLM authentication

Note: For information about NTLMv2 support for ARX, refer to K8820: Support for NTLMv2.

When you configure an ARX namespace to enable only Kerberos and NTLMv2 authentication, clients using NTML authentication fail to gain access to the ARX virtual server. The Network Security: LAN Manager authentication level security setting for some Windows clients may be configured for NTLM only and not NTLMv2, so when you configure an ARX namespace for authentication, take note of how you have configured the Network Security: LAN Manager authentication level security setting for the Windows client.

For information about the Network Security: LAN Manager authentication level setting, refer to the following Microsoft TechNet article:

http://technet.microsoft.com/en-us/library/cc738867.aspx

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

When you configure the client's Network Security: LAN Manager authentication level setting to use only NTLM authentication, and you have configured the ARX namespace to enable only Kerberos and NTLMv2 authentication, clients fail to gain access to a share.

Clients use Kerberos authentication when attempting to access a share using the long name (fully qualified domain name) for the virtual server. If the Kerberos authentication fails, clients use NTLM authentication. Clients also use NTLM authentication when attempting to access a share using the Windows short name (IP address) of the virtual server.

Alternative options for configuring the ARX namespace

  • Enable NTLM authentication for the ARX namespace using the cifs authentication command. For information about the cifs authentication command, refer to the ARX CLI Reference Guide.
  • Configure the client's Network Security: LAN Manager authentication level setting to use NTLMv2 authentication. For information about the Network Security: LAN Manager authentication level setting, refer to the following Microsoft TechNet article: http://technet.microsoft.com/en-us/library/cc738867.aspx

    Note: For information about client incompatibilities when you modify security settings, such as the LAN Manager authentication level, refer to the following Microsoft KB article: http://support.microsoft.com/kb/823659.
