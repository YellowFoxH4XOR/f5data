Known Issue

Note: This article applies to the BIG-IP 1500, 1600, 3400, 3600, 3900, 4100, 4500, 6400, 6800, 6900, 8400, 8800, 8900, and VIPRION platforms only.

F5 has identified a potential issue with the Cavium Networks NITROX card used by the BIG-IP system to accelerate SSL connections. When this issue occurs, SSL processing may stop entirely.

Although the conditions that cause this issue are rare and you are unlikely to be affected, F5 recommends upgrading to rule out any possibility of experiencing this issue.

Since this issue is difficult to troubleshoot manually, a diagnostic is available on the F5 iHealth website. If you are running BIG-IP version 10.x and want to check your system, generate a qkview file and upload it to the iHealth website. If your system matches an affected platform and version, the qkview will trigger iHealth diagnostic H741842. This means that your system is susceptible to the issue. In this case, the iHealth diagnostics will also attempt to determine whether the system is currently affected by the issue.

F5 Product Development tracked this issue as ID 339524, and it was fixed in BIG-IP version 10.2.0 for the BIG-IP 1600, 3600, 3900, 6900, 8900 and VIPRION platforms and BIG-IP version 10.2.1 for the BIG-IP 1500, 3400, 4100, 4500, 6400, 6800, 8400 and 8800 platforms. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, APM, WebAccelerator, WOM or Edge Gateway release notes.

Additionally, this issue has been fixed for the BIG-IP 1500, 3400, 4100, 4500, 6400, 6800, 8400 and 8800 platforms in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
