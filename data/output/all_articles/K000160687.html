K000160687: Fails to upload file to F5OS-A by the root account via SCP command

Type
Support Solution
Published
2026-04-23
Updated
2026-04-23
Applies to
  • F5OS Products
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000160687

Description

You might fail to upload file to F5OS by the root account via scp command if relative path is in use.

For example :

# scp F5OS-A-1.8.0-17564.R2R4.EHF-1.iso root@<F5OS mgmt IP address>:images/staging/
--- snip ---
Password:
scp: images/staging/: No such file or directory

 

Environment

・Uploading file to F5OS by the root account via scp command

 

Cause

This is by design. For the root account, SCP uploads are only supported when specifying the absolute path (for example : /var/import/staging).

 

Answer/Recommended Actions

When using the root account, specify the absolute path (/var/import/staging) for SCP uploads.

 

For example :

 

# scp F5OS-A-1.8.0-17564.R2R4.EHF-1.iso root@<F5OS mgmt IP address>:/var/import/staging
