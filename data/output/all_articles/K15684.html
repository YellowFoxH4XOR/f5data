Topic

You should consider using this procedure under the following conditions:

  • A vCMP guest has potential performance issues.
  • You need additional information to determine what guest and what resource is reaching capacity.

Description

As of BIG-IP 11.6.0, the vCMP hypervisor can view detailed guest performance statistics such as Disk usage, CPU usage and Network Throughput using Analytics, also called Application Visibility and Reporting (AVR). You can use AVR to view current and trending data regarding vCMP guest resource and network utilization. You can generate PDF reports and either downloaded or email them from the BIG-IP system. You can configure your BIG-IP system to send email by Navigating to System > Configuration > Device > SMTP and clicking Create. Once the SMTP profile is created you can select the profile to email reports.

Note: This AVR functionality is enabled by default and does not require licensing or provisioning. You cannot enable AVR on vCMP hosts to provide additional vCMP guest information.

Procedures

Viewing AVR statistics on the vCMP host from the Configuration utility

Using the Configuration utility, you can view AVR guest statistics at Statistics > Analytics > VCMP.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • To view CPU usage, navigate to:

    Statistics > Analytics > VCMP and select the CPU Usage tab at the top of the page

  • To view average network throughput, navigate to:

    Statistics > Analytics > VCMP and select the Network tab at the top of the page

  • To view disk IO information, navigate to:

    Statistics > Analytics > VCMP and select the Disk Usage tab at the top of the page

Viewing AVR statistics on the vCMP host from the tmsh

Using the Traffic Management Shell (tmsh), you can view AVR guest statistics using the following commands.

Note: The ability to generate PDF style reports with tmsh is not possible at this time.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Log in to the tmsh utility by typing the following command:

    tmsh

  • To view CPU usage, use the following command syntax:

    show analytics vcmp report view-by guest measures { average-cpu-usage }

  • To view average network throughput in bytes, use one of the following command syntax examples:

    show analytics vcmp report view-by guest measures { network-average-in-throughput }
    show analytics vcmp report view-by guest measures { network-average-out-throughput }

  • To view disk IO information, use one of the following command syntax examples:

    show analytics vcmp report view-by guest measures { diskio-bytes-read }
    show analytics vcmp report view-by guest measures { diskio-bytes-written }
