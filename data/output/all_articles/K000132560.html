Description

  • The rSeries appliance does not automatically boot up when input power is applied.
  • The serial console shows only the AOM menu prompt:
--- Press <ESC>( for AOM Command Menu.

Environment

  • rSeries appliance

Cause

The system was previously powered down with the halt -p, poweroff, or shutdown commands. 

 Recommended Actions

Use the AOM menu to power on the appliance.

  1. Connect to the console, press ESC + ( to enter the AOM menu.
  2. Enter P to use "Power on/off host subsystem" command.
  3. Enter 1 for the option to power on the appliance.
  4. Enter y to confirm the power-on.

In some cases, using only the "Power on/off host subsystem" command in AOM does not power on the system. In such cases, taking the additional step of using the 'Reset host subsystem' (AOM command 'R') successfully restarts the system.

  1. Connect to the console, press ESC + ( to enter the AOM menu.
  2. Enter R to use "Reset host subsystem" command.
  3. Enter y to confirm the reset the host subsystem.

Additional Information

An rSeries appliance implements a power policy of "last power state". If the appliance is powered down with the halt -p, poweroff, or shutdown commands, and then the input power is removed and re-applied, the appliance will remain powered down. The "last power state" of the appliance is "powered off".

Alternatively, you can power off the system using the halt command (do not use the -p option). Once the serial console reports the device has been halted, then unplug the power to the appliance. In this case the "last power state" of the appliance is "powered on". When input power is re-applied, the appliance will automatically power on and boot.
