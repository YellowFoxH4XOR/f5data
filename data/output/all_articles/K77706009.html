Topic

You should consider using these procedures under the following conditions:

  • You have one or more BIG-IP Virtual Edition (VE) systems with active support contracts.
  • You want to use BIG-IQ License Manager to assign and revoke standalone BIG-IP VE licenses.

Description

Beginning in BIG-IQ Centralized Management 5.1.0, you can assign, refresh, revoke, and reassign remote BIG-IP VE device licenses using the License Manager. BIG-IQ License Manager organizes licenses into groups using a registration key (RegKey) pools concept. After you create a RegKey pool, you activate new registration keys and begin assigning licenses to your BIG-IP VE devices. In addition, starting from BIG-IQ 5.2.0, F5 offers a specially licensed virtual edition of the BIG-IQ Central Management system, which allows you to use BIG-IQ License Manager as a standalone module. To obtain a free BIG-IQ License Manager license, refer to Obtaining BIG-IQ License Manager.

Notes:

  • For information about BIG-IQ-supported BIG-IP VE devices, refer to: K34133507: BIG-IQ Centralized Management compatibility matrix.
  • You must use BIG-IQ 5.3.0 or later to assign and revoke licenses for BIG-IP VE systems running in 1NIC mode.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have one or more registration keys that you have not used to license a BIG-IP VE system.
  • Your BIG-IP VE systems have active support contracts.
  • You have the necessary BIG-IQ role to license BIG-IP devices.
  • You have administrative access to the BIG-IP VE systems that you are licensing (unmanaged devices only).

Procedures

  • Obtain a BIG-IQ License Manager (Optional)
  • Activate a registration key with License Manager (automatic method)
  • Activate a registration key with License Manager (manual method)
  • Reactivate a registration key with License Manager (automatic method)
  • Reactivate a registration key with License Manager (manual method)
  • Assign a license from the RegKey pool to a BIG-IP VE device
  • Refresh a license in the RegKey pool to a BIG-IP VE device
  • Revoke a license in the RegKey pool from a BIG-IP VE device
  • Assign an add-on key to a licensed BIG-IP VE device

Obtain a BIG-IQ License Manager (Optional)

For BIG-IQ version 7.1.0 and earlier, you can obtain the free BIG-IQ License Management license by performing the following procedure:

  1. Contact your sales representative to request a free BIG-IQ License Manager registration key.
  2. Download the virtual edition of BIG-IQ Centralized Management, which is available on the F5 Downloads page.

    Note: Make sure to obtain BIG-IQ Centralized Management 5.2.0 or later.

  3. After you install BIG-IQ Centralized Management, you can license the system. For more information, refer to K15094: Licensing the BIG-IQ system.

Activate a registration key with License Manager (automatic method)

After you obtain your base registration key from F5, typically in the form of an email, you can create a standalone RegKey pool and add and activate registration keys for that pool. You can automatically contact the F5 license server for activation if the BIG-IQ system meets the following criteria:

  • It is connected to the public Internet.
  • It can access the activate.f5.com site.
  • Its existing firewalls allow port 443 to pass through.

Note: You cannot reactivate or import registration keys from currently active BIG-IP VE licenses. For already licensed devices in your network, contact F5 Technical Support for assistance with transferring the devices to the BIG-IQ system for license management.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system with your administrator username and password.
  2. Select Devices.
  3. Go to LICENSE MANAGEMENT > Licenses.
  4. Perform one of the following actions:

    If no RegKey pool exists, select Add RegKey Pool and, in the Name box, enter a name for the new RegKey pool.

    If a RegKey pool exists, select the name of the RegKey pool for which you want to activate a license.

  5. Select Add RegKey.
  6. In the Registration Key box, enter or paste the registration key, and into the Add-on Keys box, enter or paste an associated add-on key.
  7. For the Activation Method setting, select Automatic.
  8. Select Activate.
  9. Review the end user license agreement, and, if you agree with the terms, select Accept.
  10. After the activation status displays Active, you can assign a license from the pool to a BIG-IP VE device.

Activate a registration key with License Manager (manual method)

After you obtain your base registration key from F5, typically in the form of an email, you can create a standalone RegKey pool and add and activate registration keys for that pool. If your BIG-IQ system is not connected to the public Internet, you must activate the registration key using the following manual procedure:

Note: You cannot reactivate or import registration keys from currently active BIG-IP VE licenses. For devices in your network already licensed, contact F5 Technical Support for assistance with transferring the devices to the BIG-IQ system for license management.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system with your administrator username and password.
  2. Select Devices.
  3. Go to LICENSE MANAGEMENT > Licenses.
  4. Perform one of the following actions:

    If no RegKey pool exists, select Add RegKey Pool and in the Name box, enter a name for the new RegKey pool.

    If a RegKey pool exists, select the name of the RegKey pool for which you want to activate a license.

  5. Select Add RegKey.
  6. In the Name box, enter the name and optional Description for the RegKey pool.
  7. Select Add RegKey.
  8. In the Registration Key box, enter or paste the registration key, and into the Add-on Keys box, enter or paste an associated add-on key.
  9. For the Activation Method setting, select Manual.
  10. Select Generate Dossier.
  11. Select and copy the dossier.
  12. Select Access F5 manual activation web portal.
  13. On the F5 Product Licensing page, paste the dossier into the Enter your dossier box, and select Next.

    Alternatively, select Choose File and go to the location where you saved the dossier.

  14. Review the end user license agreement and, if you agree with the terms, select Accept.
  15. Select and copy the license.
  16. Paste the license into the License Text box on the BIG-IQ system.
  17. Select Activate.

Note: If the activated license contains multiple offerings, you must repeat this process for each offering to fully activate the license. You can assign individual offerings that you already reactivated to a BIG-IP, as needed.

Reactivate a registration key with License Manager (automatic method)

To upgrade licensed BIG-IP systems, you must update the service check date by periodically reactivating the base registration key.

When your BIG-IQ system meets the following criteria, you can automatically contact the F5 license server for activation. Your BIG-IQ system:

  • Is connected to the public internet.
  • Can access the http://activate.f5.com site.
  • Has existing firewalls that allow port 443 to pass through.

Impact of procedure: Performing the following procedure should not have a negative impact on your BIG-IQ nor any BIG-IP system licensed from this pool.

  1. Log in to the BIG-IQ system as an administrator.
  2. Select Devices.
  3. Go to LICENSE MANAGEMENT > Licenses.
  4. Select the check box next to the license pool you want to reactivate, and then select Reactivate.

    You can add or remove add-on keys as needed.

  5. Select Automatic.
  6. Select Reactivate.

    The end user license agreement may display.

  7. Review the end user license agreement and, if you agree with the terms, select Accept.
  8. After the activation status displays Active, you can refresh the licenses from the pool to a BIG-IP VE device.

Reactivate a registration key with License Manager (manual method)

To upgrade licensed BIG-IP systems, you must update the service check date by periodically reactivating the base registration key. If your BIG-IQ system is not connected to the public internet, you must activate the registration key using the following manual procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your BIG-IQ system nor any BIG-IP licensed from this pool.

  1. Log in to the BIG-IQ system as an administrator.
  2. Select Devices.
  3. Go to LICENSE MANAGEMENT > Licenses.
  4. Select the check box next to the license pool you want to reactivate, and then select Reactivate.

    You can add or remove add-on keys as needed.

  5. Select Manual.
  6. Select Generate Dossier.
  7. Select and copy the dossier.
  8. Select Access F5 manual activation web portal.
  9. On the F5 Product Licensing page, paste the dossier into the Enter your dossier box, and select Next.

    Alternatively, select Choose File and go to the location where you saved the dossier.

  10. Review the end user license agreement and, if you agree with the terms, select Accept.
  11. Select and copy the license.
  12. Paste the license into the License Text box on the BIG-IQ system.
  13. Select Reactivate.

Note: If the reactivated license contains multiple offerings, you must repeat this process for each offering to fully reactivate the license. You can refresh individual offerings that you already reactivated to assigned BIG-IP systems, as needed.

Assign a license from the RegKey pool to a BIG-IP VE device

After you activate a VE license from the RegKey pool, you can assign the registration key to a BIG-IP VE device. You assign a license from the RegKey pool to a BIG-IP VE device to authorize the device to run F5 services that support your applications.

Impact of procedure: Performing the following procedure triggers the license activation process. The process may reload the configuration and temporarily interrupt traffic processing on the target BIG-IP system. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

  1. Select Devices.
  2. Go to LICENSE MANAGEMENT > Licenses.
  3. Under Name, select the name of the RegKey pool that contains the registration key you want to assign.
  4. Under Registration Key, select the registration key you want to assign by selecting the box next to its name.
  5. Select Assign.
  6. For managed devices, select the BIG-IP device you want from the list, or select Unmanaged Device, then enter the device IP Address, Port, Username, and Password for unmanaged devices.

    Note: BIG-IQ 5.3.0 and later allows you to modify the default service port 443.

    Important: The BIG-IQ system must use service port 8443 to license BIG-IP VE devices running in 1NIC mode.

  7. Select Assign and confirm the assignment.
  8. Ensure that the License Status indicates Licensed.

Refresh a license from the RegKey pool to a BIG-IP VE device

Note: Refreshing the BIG-IP license from the BIG-IQ system is also referred to as reactivating a BIG-IP license

After reactivating the base registration key from the License server, you need to pass the updated license information to the BIG-IP system to ensure it contains a recent service check date. This procedure is required on all BIG-IP systems that are scheduled for an upgrade.

Impact of procedure: Performing the following procedure triggers the license activation process. The process may reload the configuration and temporarily interrupt traffic processing on the target BIG-IP system. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

  1. Select Devices.
  2. Go to LICENSE MANAGEMENT > Licenses.
  3. Under Name, select the name of the RegKey pool that contains the registration key you want to refresh.
  4. Under Registration Key, select the registration key you want to refresh by selecting the check box next to its name.
  5. Select More.
  6. Select Refresh.
  7. For unmanaged devices, enter the username and password of the BIG-IP system.
  8. Select OK to confirm the refreshing.

Revoke a license in the RegKey Pool from a BIG-IP VE device

When fewer devices are required for your applications, you can revoke licenses to reassign them to other BIG-IP VE devices as needed.

Impact of procedure: Performing the following procedure removes the license from the target BIG-IP system.

  1. Select Devices.
  2. Go to LICENSE MANAGEMENT > Licenses.
  3. Under Name, select the name of the RegKey pool that contains the registration key you want to revoke.
  4. Under Registration Key, select the registration key you want to revoke by selecting the box next to its name.
  5. Select Revoke.
  6. The new page displays the IP address and Offering (registration key), and you must provide the Username and Password for the unmanaged BIG-IP device.
  7. Select Revoke again, and confirm the revocation.

This license is now available for reassignment to another BIG-IP VE device.

Assign an add-on key to a licensed BIG-IP VE device

When BIG-IQ system manages the registration key, you can associate and activate additional add-on keys to an already licensed BIG-IP VE device, as needed.

Impact of procedure: Performing the following procedure triggers the license activation process. The process may reload the configuration and temporarily interrupt traffic processing on the target BIG-IP system. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

  1. Select Devices.
  2. Go to LICENSE MANAGEMENT > Licenses.
  3. Under Name, select the name of the RegKey pool that contains the registration key you want to append the add-on key.
  4. Under Registration Key, select the registration key you want to append the add-on key by selecting the check box next to its name.
  5. Select More.
  6. Select Reactivate.
  7. In the Add-on Keys box, enter or paste an associated add-on key.
  8. Select Reactivate.
  9. To activate the license with the new add-on keys, see the Refreshing a license from the RegKey pool to a BIG-IP VE device section in this article.
