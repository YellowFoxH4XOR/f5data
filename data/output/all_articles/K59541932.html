K59541932: AS3 GET API Method only displays virtual servers created within AS3

Type
Support Solution
Published
2022-09-22
Updated
2023-02-21
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K59541932

Description

Created a new configuration partition and virtual servers. AS3 GET (https://<IP add of F5 device>/mgmt/shared/appsvcs/declare?show=full) is only returning the virtual servers that I have created with AS3.  The existing virtual servers in the existing Common partition are not returned.

Environment

BIG-IP AS3
BIG-IP LTM virtual servers

Cause

This is expected behavior. AS3 will only return configuration objects which were created with AS3. Configuration objects created within the Configuration Utility GUI or TMSH command line cannot be referenced with AS3

Recommended Actions

None. Working as intended.

Additional Information

None
