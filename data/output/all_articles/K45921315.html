Description

When Amazon Web Services (AWS) BIG-IP high availability (HA) peers are configured each in a different AWS Availability Zone (AZ) requiring that the HA Self-IP addresses reside in different network subnets, LOCAL_ONLY Static Routes must be configured in order to support HA traffic between the HA peer BIG-IP systems, since their respective HA Self-IP addresses reside in different network subnets. Since the two respective HA peer BIG-IP HA subnets are different, the Static Routes must be configured in the LOCAL_ONLY Config Partition that does not participate in ConfigSync operations. This allows the two HA peer BIG-IP systems to be configured with different Static Routes pointing to different Default Gateway IP addresses.

Environment

Relevant environmental factors:

  • An HA pair or cluster of AWS BIG-IP instances residing in different AWS AZs.
  • Where-in the respective HA Self-IP's reside in different network subnets.

Cause

Because the two respective HA peer BIG-IP HA Self-IPs reside in different network subnets, due to being configured in different AWS AZs, LOCAL-ONLY Static Routes are required to support the BIG-IP to BIG-IP HA traffic flow for ConfigSync, Network Failover, and Mirroring (the 3 aspects of HA)

Recommended Actions

To support such multi-AZ AWS HA BIG-IP deployment, use the following procedures.

  1. Create a LOCAL_ONLY Configuration/Administrative Partition that does not take part in ConfigSync operations.
    1. Navigate to System  ›› Users : Partition List and click the + button to create a new Config/Admin Partition.
    2. In Partition Name, enter an appropriate name such as "LOCAL_ONLY".
    3. Uncheck the Inherit device group from root folder option, and set Traffic Group to None, since it will contain device unique configuration that should not be synced between HA peer BIG-IPs, and which should not Failover between the HA peers.
    4. Click Finished to save the new LOCAL_ONLY Config/Admin Partition.
  2. Create the required device unique Static Routes on the respective HA peer BIG-IPs, being sure to create them within the LOCAL_ONLY Config/Admin Partition.
    1. Navigate to Network ›› Routes from within the new LOCAL_ONLY Config/Admin Partition, and click the + button to create a new Static Route.
    2. In Name, enter an appropriate name for the Static Route.
    3. In Destination & Netmask, enter the appropriate destination network subnet address and subnet mask.
    4. Leave Resource set to Gateway, and set the Gateway Address to IP address with the appropriate Gateway IP address for the local subnet.
    5. Click Finished to save the new Static Route.
    6. Repeat this process on the other HA peer BIG-IP using the appropriate Destination, Netmask, and Gateway Address.
