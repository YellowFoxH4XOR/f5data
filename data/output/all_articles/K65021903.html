Known Issue

Modifying or deleting non-system file objects consumes additional disk space.

This issue occurs when the following condition is met:

  • You modify or delete numerous non-system files.

    Note: The term non-system refers to objects that are not part of the default BIG-IP system. For example, custom external monitors, data groups, ifiles, etc.

Impact

The BIG-IP system's disk space may become full.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system's /config directory has no remaining space.
  • You are unable to create new file objects.
  • You are unable to perform a configuration synchronization (ConfigSync).

Workaround

To work around this issue, you can save and reload the configuration after modifying or deleting non-system files. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. To log in to the Traffic Management Shell, type the following command:

    tmsh

  3. To save the system configuration, type the following command:

    save sys config

  4. To load the system configuration, type the following command:

    load sys config
