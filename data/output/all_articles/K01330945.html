Description

When installing or replacing a new blade the management IP can't be configured either with the config utility or via TMOS with tmsh.

Environment

  • Replacing or installing a VIPRION blade.
  • Can't access the config utility tool with the config command.
  • Can't access TMOS with the tmsh command.
  • The message "Unexpected Error: MCP must be in the running phase" is displayed in the CLI after entering any of the previously mentioned commands.
  • The tmsh show sys mcp-state command shows the base-config-load-failed message:
-------------------------------------------------------
Sys::mcpd State:
-------------------------------------------------------
Running Phase                   platform
Last Configuration Load Status  base-config-load-failed
End Platform ID Received        true
Cluster Quorum Reached          true

Cause

The bigip_base.config file can't be loaded

Recommended Actions

  1.  Back up the current bigip_base.config file.
mv bigip_base.conf bigip_base.conf_backup
  1.  Load the config.
tmsh load sys config
  1.  Restore the BIG-IP configuration to factory default settings.
tmsh load sys config default
