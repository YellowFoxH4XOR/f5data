Description

Explains how to use known labels in network policy rules to control ingress and egress traffic. 

Note: Controlling traffic using labels is only supported for known labels.

Environment

  • F5® Distributed Cloud Console
  • One or more web applications deployed on F5® Distributed Cloud Services sites or Regional Edge sites
  • HTTP load balancer advertising your services
  • Optionally, F5 Distributed Cloud site

Answer/Recommended Actions

Procedure

The example steps shown in this article assume that there is a sample web application deployed using Distributed Cloud Services vK8s (virtual Kubernetes) and the application has product catalogue, details, and reviews as services.

Perform the following in Distributed Cloud Console:

Create known labels

  1. Log into Distributed Cloud Console and go to Shared namespace. Select Manage->Labels-> Known Keys.
  2. Click Add Known key. 
  3. Enter a key in the Label key field.
  4. Enter a value in the Label Value field.  
  5. Click Add key.
  6. Repeat Steps 1-5 to create more known labels as per your requirement.
  7. Verify that the known labels are displayed in the Manage->Labels->Known Labels page.

Apply Known Labels to Applications

Apply the labels created in previous section to your vK8s deployment. The labels are added in the deployment manifest as shown below:

Note: Ensure that you add known labels to each service so that later communication between the services can be controlled using these labels.

Create Network Policy Rules

  1. Go to your application namespace.
  2. Select Security->vK8s Network Policy->Network Policies.
  3. Click Add Network Policy. 
  4. Enter metadata and configure the Policy for Endpoints section. Use the Label Selector option for Endpoints field and enter the key-value pair of a known label you created in previous step. This is the local endpoint and ensure that you add the label of a deployed service.
     
  5. Go to the  Connections To and From Endpoints section and click on configure for Ingress rules. 
  6. Enter metadata and select deny or allow for Action field.
  7. Select Label Selector for the Select Other Endpoint field. 
  8. Enter another key-value pair of the known label for another service.
  9. Click Apply.
  10. Repeat the previous steps for Egress rules.
  11. Click Save and Exit.

Apply Network Policy

  1. Go to your application namespace. Select Security->vK8s Network Policy->Active Network Policies
  2. Click Select Active network policy. 
  3. In the active network policies window, click Select Network Policy 
  4. Select the policy you created in the previous section
  5. Click Select Network Policy to apply the policy to active network policies.
  6. Click Save and Exit.

Verify Rule Enforcement

Send a request to your web application using the domain name configured. Click a product and try to request reviews or details from the product page. Blocked requests indicate successful enforcement of rules.
