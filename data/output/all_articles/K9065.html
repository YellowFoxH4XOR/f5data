K9065: The SSL::enable and SSL::disable iRule commands do not enable or disable SSL processing for server-side iRule events

Known Issue

This is the result of a known issue. The SSL::enable and SSL::disable iRule commands do not properly enable or disable SSL processing for server-side iRule events. For example, the following iRule does not properly disable server-side SSL processing for the LB_SELECTED iRule event:

rule SSL_test {
when LB_SELECTED {
SSL::disable serverside
}
}

F5 Product Development tracked this issue as CR96845 and it was fixed in BIG-IP 9.4.5. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You can work around this issue by rewriting the iRule to enable or disable SSL processing on the client-side iRule event. For example, the previous iRule could be rewritten to disable SSL processing on the client-side iRule event as follows:

rule SSL_test {
when CLIENT_CONNECTED {
SSL::disable serverside
}
}
