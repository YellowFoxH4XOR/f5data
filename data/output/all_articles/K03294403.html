Description

Error message appears in the GUI (Configuration Utility):

Error Message: requires a profile of type websecurity for ltm policy

Environment

  • LTM policy applied to Virtual Server
  • Updating Draft Policy with a rule to apply ASM policy
  • Upon save, message displayed in GUI: require controls for asm

Cause

While a published LTM policy is applied to the virtual server, and an attempt is made to apply ASM policy to its Draft version, the system is not able to publish the LTM policy as virtual server doesn't have a websecurity profile associated with it yet.

Recommended Actions

  1. Remove the LTM policy from the virtual server
  2. Create a draft of the LTM policy
  3. Create or modify rule to Enable
  4. Add ASM policy
  5. Save and publish the Draft Policy
  6. Apply the published policy to the virtual server
Additional Information

Websecurity profile is applied by the BIG-IP when an ASM policy is applied to the virtual server either manually (via the security section) or when an LTM policy (that contains rule to apply ASM policy) is applied to the virtual server.
