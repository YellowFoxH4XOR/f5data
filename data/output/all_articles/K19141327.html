Description
BIG-IP lost its configuration and now need to restore BIG-IP configuration from BIG-IQ
Has BIG-IP UCS file backed up on BIG-IQ, UCS file includes: 

  • System-specific configuration files
  • License
  • User account and password information
  • SSL certificates and keys

Environment

  • BIG-IP
  • UCS available on BIG-IQ

Cause
There are many variables that this behavior can happen.  If root cause analysis is needed, please contact F5 Support.
K2633: Instructions for submitting a support case to F5

Recommended Actions

  1. Download UCS backup collected on the BIG-IQ
  2. Restore system configuration using downloaded UCS file.
    K13132: Backing up and restoring BIG-IP configuration files with a UCS archive
