K000091326: Unable to update NGINX

Type
Support Solution
Published
2022-03-17
Updated
2024-05-23
Source
https://my.f5.com/manage/s/article/K000091326

Description

You are trying to pull new Nginx image for the purpose of upgrade or new installation, but you are encountering the below error. 

failure: repodata/repomd.xml from nginx-plus: [Errno ###] No more mirrors to try.
https://pkgs.nginx.com/plus/*****/2/x86_64/repodata/repomd.xml: [Errno ###] HTTPS Error 400 - Bad Request

    Environment

    • NGINX Plus
    • Upgrade existing Nginx instance
    • Install a new NGINX Plus instance

     Cause

    • Expired certificate and key pair in /etc/ssl/nginx/

     Recommended Actions

    Verify if you have a valid/active subscription certificate and key (cert/key) files 

    1. Navigate to MyF5 Customer Portal https://my.f5.com
    2. Access Subscriptions
    3. Select the latest NGINX subscription
    4. Download the nginx-repo.crt and nginx-repo.key files.

    Replace existing certificate and key files on the NGINX server.

    Note: This procedure doesn't impact traffic, but F5 recommends performing this work during a maintenance window.

    1. Connect to the NGINX Plus server where the cert/key file expired
    2. Upload the newly downloaded key/cert pair, from step two above, to node's home directory
    3. Copy the nginx-repo.crt and nginx-repo.key files to the /etc/ssl/nginx/ directory:
      • sudo cp nginx-repo.crt /etc/ssl/nginx/
      • sudo cp nginx-repo.key /etc/ssl/nginx/

    If you do not have a valid subscription to replace expired cert/key files, please contact your customer success manager or customersuccess@f5.com.

     Additional Information

    You can verify if you have a valid NGINX cert/key.repo by running the below command 

    openssl x509 -in /etc/ssl/nginx/nginx-repo.crt -text -noout | grep -i "Not After" 

    For example:

    [user@localhost ~]$ openssl x509 -in /etc/ssl/nginx/nginx-repo.crt -text -noout | grep -i "Not After"

    Returns:

    Not After : Aug 22 16:32:03 2021 GMT   <--- here certificate is showing expired
