K6928: Validity date range of certificate used to sign F5 Networks controls is older than current date

Topic

If you examine the digital certificate used to digitally sign F5 Networks controls, you may see a certificate whose valid date range is older than the current date. This typically occurs when your version of FirePass software is older than the most current maintenance or feature release of FirePass software. This is not a security risk, only an indication that your version of the F5 Networks controls are not the most current version. As long as the certification path for the expired certificate is still valid, the browser can perform the needed security checks.

Note: The digital certificate used to sign F5 Networks controls should not be confused with the FirePass Secure Sockets Layer (SSL) server certificate. The F5 Networks code-signing digital certificate is owned and used by F5 Networks exclusively to sign F5 Networks' ActiveX controls and Java applets.

The FirePass controller downloads ActiveX controls and Java Applets to perform many basic FirePass functions, such as Network Access or Application Access. To ensure these controls are genuine, F5 Networks digitally signs the files using F5 Networks' code-signing digital certificate. This digital signature is compared to a digital signature computed by the browser when it downloads the files. By comparing the digital signatures, the browser can determine whether the files have been issued by F5 Networks and have been downloaded without alterations.

When downloading an F5 Networks control for the first time, your browser will normally issue a warning pop-up, which prompts you to install or reject installation of the control. Typically, the pop-up allows you to display information about the control, including the F5 Networks code-signing digital certificate which signed the control.

With Internet Explorer 6 and 7, you can display the valid date range of the F5 Networks code-signing certificate when the Internet Explorer - Security Warning pop-up appears, by performing the following procedure:

  1. Click the F5 Networks link, in the Publisher: field.

    The Digital Signature Details window appears.

  2. Click the View Certificate button.

    The Certificate window appears.

  3. Under Certificate Information, the valid date range is displayed.

    For example:
    Valid from 3/5/2006 to 3/5/2008
     

If you upgrade to the most current maintenance or feature release of FirePass software, the update will include the latest F5 Networks code-signing digital certificate, and the controls will have current validity ranges. Certain hotfixes may also update the F5 Networks code-signing digital certificate.
