K8586: When creating new mandatory headers using the BIG-IP ASM Configuration utility, the Select Header option does not display existing headers

Known Issue

This is the result of a known issue. Starting in BIG-IP ASM 9.4.4, you can add mandatory headers to the security policy. A mandatory header must appear in a request in order for the request to be accepted by the security policy. When you create a new mandatory header, you can choose New Header or Select Header from the Header menu. The Select Header option specifies that you are configuring an existing header as mandatory in the security policy. If you choose the Select Header menu option, no existing headers are displayed.

F5 Product Development tracked this issue as CR91675 and it was fixed in BIG-IP ASM 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can work around this issue by creating mandatory headers using the BIG-IP ASM Configuration utility. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Application Security > Web Applications.
  3. Click the relevant security policy.
  4. Click Headers.
  5. Click the Mandatory Headers menu.
  6. Click Create.
  7. From the Header menu, select New Header.
  8. Type the name of the header you want to make mandatory in the security policy.
  9. Click Create.
  10. Click Apply Policy.
