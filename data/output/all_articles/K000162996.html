Description

How to remove all self ip address and keeping only management IP address in BIG-IQ version 8.4.1 without losing GUI access?

Environment

  • BIG-IQ
  • 8.4.1

Cause

None

Answer/Recommended Actions

tmsh modify sys db provision.1nic value forced_disable

Additional Information

To check current provision.1nic configured setting.

tmsh list sys db provision.1nic value
