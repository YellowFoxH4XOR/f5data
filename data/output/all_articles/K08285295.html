Topic

You should consider using this procedure under the following condition:

  • You want to push the F5 Helper Applications to using Windows Group Policies

Description

Starting in BIG-IP 13.0.0, the BIG-IP APM system no longer uses browser plugins when performing the endpoint security checks or when creating an SSL VPN tunnel. The BIG-IP APM now uses two helper applications when an access policy requires endpoint checks on the connecting client device.

You can download the helper applications for MAC OS X and Linux devices directly from the Configuration utility. Helper applications for Windows devices are not available for download through the Configuration Utility.

Perform the following procedures to retrieve the BIG-IP APM the helper application for Windows.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP system is licensed and provisioned with the BIG-IP APM module.
  • You have administrative access to the Configuration utility or can login to an APM Virtual Server configured with a webtop
  • Your BIG-IP system version must be 13.x and later.

Procedures

  • Retrieving the SSL VPN helper application for Windows using the Configuration utility
  • Retrieving the endpoint security helper applications for Windows using the Configuration utility
  • Retrieving the SSL VPN helper application for Windows using the BIG-IP APM virtual server
  • Retrieving the endpoint security helper applications for Windows using the BIG-IP APM virtual server

Retrieving the SSL VPN helper application for Windows using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Use the following URL syntax to download the f5vpn_setup.exe helper application executable file:

    https://<big-ip ip address>/sam/webtop/public/download/f5vpn_setup.exe

    Note: Replace <big-ip ip address> with the IP address or host name of your BIG-IP system.

    For example:

    https://10.10.20.11/sam/webtop/public/download/f5vpn_setup.exe

  3. Save the f5vpn_setup.exe file to your local device.

Note: After saving the f5vpn_setup.exe file, you can distribute the SSL VPN helper application to your Windows users.

Retrieving the endpoint security helper applications for Windows using the Configuration utility

Perform the following procedure provide to retrieve the endpoint security helper application using HTTPS:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
  1. Log in to the Configuration utility.
  2. Modify the following URL syntax to replace <big-ip ip address> with the IP address or host name for the BIG-IP Management interface:

    https://<big-ip ip address>/sam/webtop/public/download/f5epi_setup.exe

    Note: Replace <big-ip ip address> with the IP address or host name of your BIG-IP system.

    For example:

    https://172.16.1.245/sam/webtop/public/download/f5epi_setup.exe
  3. Save the f5epi_setup.exe file to your local device.

Note: After saving the f5epi_setup.exe file, you can distribute the SSL VPN helper application to your Windows users.

Retrieving the SSL VPN helper application for Windows using the BIG-IP APM virtual server

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM virtual server and go to the webtop.
  2. Use the following URL syntax to download the f5vpn_setup.exe helper application executable file:

    https://<APM ip address>/public/download/f5vpn_setup.exe

    Note: Replace <APM ip address> with the IP address or host name of your BIG-IP APM virtual server.

    For example:

    https://myapm.my.domain/public/download/f5vpn_setup.exe

  3. Save the f5vpn_setup.exe file to your local device.

Note: After saving the f5vpn_setup.exe file, you can distribute the SSL VPN helper application to your Windows users.

  3. Save the f5epi_setup.exe file to your local device.
