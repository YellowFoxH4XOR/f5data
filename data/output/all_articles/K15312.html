Known Issue

BIG-IP APM portal access may not rewrite server content correctly.

This issue occurs when all of the following conditions are met:

  • Users connect to BIG-IP APM portal access using the Internet Explorer 8 browser.
  • The destination web server returns content that includes the following meta tag:

    <meta http-equiv="X-UA-Compatible" content="IE=8" />
  • The server webpage contains a coded event action.

Impact

Content may not render correctly for the BIG-IP portal access user.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Content processed by the portal is incomplete.
  • Users cannot interact with displayed content.
  • Content takes an excessive amount of time to render.
  • Using compatibility mode in the Internet Explorer 8 browser changes the displayed content.
