Known Issue

When a FirePass controller or BIG-IP system is configured to launch an application located in the Windows system32 directory on a 64-bit Windows operating system, the application fails to launch with an error message that appears similar to the following example:

Failed to launch application
"telnet.exe"
error=2

Note: For this example, telnet.exe is used in the error message. This issue will affect any application located in a 64-bit Windows system32 directory.

This behavior is caused by the File System Redirector in 64-bit Windows operating systems redirecting the BIG-IP Edge Client request for an application located in the Windows system32 directory to the Windows SysWOW64 directory.

Note: For more information about the File System Redirector, refer to the following Microsoft document. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://msdn.microsoft.com/en-us/library/aa384187(v=vs.85).aspx

F5 Product Development is tracking this issue as ID 343578 for FirePass and ID 369759 for BIG-IP.

Workaround

You can work around this issue by performing one of the following options:

  • Install the program to a different directory.

    For example:

    c:\program files\xxx\xxx.exe

  • For 64-bit versions of Windows Vista and Windows 7, you can substitute the Sysnative directory syntax.

    For example:

    %windir%\sysnative\telnet.exe
