Known Issue

The BIG-IP ASM system may log an erroneous critical error.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP device does not have the BIG-IP ASM module provisioned.
  • Your BIG-IP device is running an affected version.

Impact

The system logs a critical error to the /var/log/asm file hourly. You can safely ignore this error.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system logs error messages similar to the following example to the /var/log/asm file on devices where the BIG-IP ASM module is not provisioned:

    crit perl[<pid>]: 01310027:2: ASM subsystem error (update_scanner_site_map.pl,): $VAR1 = bless( {"code" => 0,"message" => "TSocket: Could not connect to 127.0.0.1:9781 (Connection refused)"
