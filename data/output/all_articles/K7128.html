Known Issue

This is the result of a known issue. The BIG-IP GTM system does not probe paths loaded from the ldns.gz file that do not contain a round trip time (RTT) measurement.

The ldns.gz file is used by the BIG-IP GTM system to track LDNS paths and maintain probe results. If a path that requires an RTT measure is written to the ldns.gz file and the system is restarted or rebooted before probing can be performed on the path, the BIG-IP GTM system will ignore any path entries in the ldns.gz file that do not contain an RTT measurement and will not queue them to be probed. As a result, the path does not obtain RTT metrics for use in handling DNS requests.

F5 Product Development tracked this issue as CR71056 and CR70925 and it was fixed in BIG-IP GTM 9.3 and 9.4. For information about upgrading, refer to the BIG-IP GTM Release Notes.
