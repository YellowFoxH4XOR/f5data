Description

Unable to collect the backup due the large UCS file

Environment

  • BIG-IP ASM/AWAF  13.1.x, 14.1.x, 15.0.x - 15.1.6.1, 16.0.x - 16.1.3
  • Policy history
  • UCS archive
Cause

/var getting full that prevents collecting UCS backup
High number of old policy history files filling up /var

Recommended Actions

We can limit the number of policy history files created 
This is controlled by configuration file /etc/ts/tools/policy_history.cfg:

----------------------------------------------------------------------
[CleanPolicyHistory]
maxSizeOfSavedVersions=100000000
minRetainedFilesInDir=2
----------------------------------------------------------------------

As per above setting:

  • maxSizeOfSavedVersions says the total size of all policy history files will be limited to 100MB
  • minRetainedFilesInDir ensures that the last 2 history files for each policy are preserved

Important: Increasing the size of  'maxSizeOfSavedVersions ' may increase the size of /var which can cause some negative impact , decreasing it may result in loosing history files.

If the above file is modified, in order for this to take in effect, ASM must be restarted:

# bigstart restart asm

Important: Restarting the asm process causes a brief traffic disruption

Additional Information

By default maxSizeOfSavedVersions is commented, that means there is no size limitation.
For BIG-IP versions 15.1.7 or later, 16.1.3.1 or later, and 17.0.0 or later, please refer to K15125052: Huge UCS backup file due to /var/ts/dms/policy/policy_versions.
