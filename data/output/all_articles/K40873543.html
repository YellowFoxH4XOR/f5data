K40873543: TFTP transfers fail through virtual server with TFTP profile

Support Solution
Published
2021-08-17
Updated

Status
Legacy Content
Applies to

  • BIG-IP LTM: 12.1.3, 12.1.2, 12.1.1, 12.1.0, 12.0.X, 12.0.0
Source
https://my.f5.com/manage/s/article/K40873543

Description
Trivial File Transfer Protocol (TFTP) fails through virtual server with TFTP profile. When the client picks a new source port (eg, when the TFTP client is restarted) one transfer works, but additional transfers fail.

You may see an ICMP Destination Unreachable (Port unreachable) message sent by BIG-IP to the server when this occurs.

Environment

  • BIG-IP
  • Virtual Server configured with TFTP profile

Cause
Bug ID 615432

Recommended Actions

  1. Upgrade to a version where Bug ID 615432 is fixed.
