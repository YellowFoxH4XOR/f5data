Description
Active connections to VMware UAG servers are being timed out after a period of time smaller than the persistence value.

Environment

  • BIG-IP LTM
  • VMware UAG server
  • The virtual server has a OneConnect profile configured.

Cause

VMware UAG servers only allow one client per TCP session. If the OneConnect profile is assigned to the virtual server, it will minimize the number of server-side TCP connections, by making existing connections available for reuse by other clients. This behavior will close the client sessions even if the persistence is profile applied.

Recommended Actions

Disable OneConnect from the virtual server configuration.

Additional Information

None
