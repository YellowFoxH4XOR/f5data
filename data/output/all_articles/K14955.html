Known Issue

The BIG-IP system does not properly evaluate a local traffic policy condition.

This issue occurs when all of the following conditions are met:

  • You configure a virtual server to use a local traffic policy.
  • The local traffic policy rule contains an http-uri operand in the conditions.
  • The virtual server processes a client request with a URI larger than the maximum segment size (MSS).

Impact

The BIG-IP system does not evaluate the local traffic policy condition as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H445558 on the Diagnostics > Identified > Medium screen.
  • An error message similar to the following example logs to the /var/log/ltm file:

    err tmm1[8636]: 016e0003:3: Retrieval of operand  'http-uri path' failed, error ERR_ARG
  • The system does not evaluate the condition in the local traffic policy, and the associated action is not taken.
  • The system resets the client connection.
