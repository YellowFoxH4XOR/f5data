Known Issue

This is the result of a known issue. The FirePass 1200 controller with End-User Diagnostics (EUD) versions 10.0.9.15.0 and earlier may fail with the following error message:

Error i2c_write_2b: Operation not permitted SEEPROM Read Error

The issue may occur at any time while in the EUD interface. The error message does not represent an actual issue with the FirePass hardware and can safely be ignored.

Users experiencing this issue should upgrade their FirePass controller to EUD version 10.0.9.16.0 or later.  

F5 Product Development tracked this issue as ID 351604 and it was fixed in FirePass EUD version 10.0.9.16.0 for the FirePass 1200 controller. For information about upgrading the EUD, refer to K7960: Obtaining and installing the latest version of End-User Diagnostics.
