Note: For BIG-IP versions 9.x and later, refer to K3525: Configuring the BIG-IP system to boot from a network boot server.
 
To configure BIG-IP or 3-DNS to perform a boot from a network boot server, perform the following procedure:
  1. Log in to the command line.
  2. Enable the net_reboot global variable by typing the following command:

    bigpipe global net_reboot enable
  3. When you are ready to reboot the system, type the following command:

    reboot

    Note: If you are using a BIG-IP 1000, 2000, 2400, 5000, or 5100 and you receive a The requested operation is not supported by the hardware message after you type the reboot command, use a paperclip to push the Reset button on the front panel. Then, within the next 10 seconds, use a paperclip to push the NETboot button.
After the system has booted from the network once, it will reset itself to boot from its local hard drive for subsequent boots.

Note:  This solution does not apply to the BIG-IP 520 and 540 (D35) platforms.
