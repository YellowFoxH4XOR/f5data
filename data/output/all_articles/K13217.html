Known Issue

Mirroring fails for device groups with more than two members.

This issue occurs when all of the following conditions are met:

  • A device group has at least three members.
  • Local Mirror Address is set in the network mirroring configuration for the members of a device group.
  • Mirroring is enabled on either a virtual server or a Secure Network Address Translation (SNAT).

In BIG-IP 11.3.0 and earlier, you can implement mirroring only between a static pair of two BIG-IP devices, because the BIG-IP system maintains only a single global connection and persistence mirroring channel. The active BIG-IP system in a high-availability (HA) device group can mirror to only one specific standby BIG-IP system using this global mirror channel. If there are three or more devices in the failover device group, mirroring will be silently disabled.

Impact

Connections are not mirrored as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H385431 on the Diagnostics > Identified > Low screen.
  • No connections are mirrored between members of a device group with three or more members.

    Note: You can monitor mirroring traffic using the tcpdump utility and watch for traffic on TCP port 1028.

  • Connection mirroring stops if a device group with two members has mirroring enabled, and a third device is added to the group.
