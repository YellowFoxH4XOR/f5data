K000150147: CE rebooted for unknown reason

Type
Support Solution
Published
2025-04-17
Updated
2025-04-17
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Multi-Cloud Network Connect
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000150147

Description

The CE got restarted/rebooted without apparent reason and we need to find out what caused it.

Environment

  • Multi-Cloud Network Connect
  • CE

Cause

VM was restarted manually or by the cloud provider.

Recommended Actions

Check if log below is present in VPM logs after reset

Feb 26 23:29:55 master-0 vpm[2097]: {"severity":"ERROR","time":"2025-02-26T23:29:55.532Z","message":"Which RPCs will not be available in REST url to RPC mapping","RPCSet":"[ves.io.schema.operate.debug.CustomPublicAPI.ListVolterraServices ves.io.schema.operate.debug.CustomPublicAPI.Reboot ves.io.schema.operate.debug.CustomPublicAPI.SoftRestart ves.io.schema.operate.debug.CustomPublicAPI.Status]","messageid":"672a6e7d-11c7-41d9-aed5-966d5544924f","alertlevel":"minor"}

 

If it is, it may indicate the VM was restarted manually. Confirm by checking VM/Cloud provider logs.
