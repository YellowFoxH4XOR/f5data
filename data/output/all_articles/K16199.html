Known Issue

Secure Sockets Layer (SSL) handshakes may fail when the SPDY profile is enabled.

This issue occurs when all of the following conditions are met:

  • An SPDY client connects to an SPDY-enabled virtual server.
  • The client attempts to use Next Protocol Negotiation (NPN) during the SSL handshake.
  • The BIG-IP system uses Cavium Nitrox SSL acceleration hardware.

Impact

SPDY clients may experience connection failures.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SPDY clients fail to connect to SPDY-enabled virtual servers.
  • SSL handshakes fail.

Workaround

To work around this issue, you can select a COMPAT SSL cipher that does not use Nitrox acceleration. For a list of COMPAT ciphers, refer to K13163: SSL ciphers supported on BIG-IP platforms (11.x). For instructions to configure an alternate cipher in your SSL profile, refer to K13171: Configuring the cipher strength for SSL profiles (11.x).

Impact of workaround: The suggested workaround may significantly affect SSL performance.
