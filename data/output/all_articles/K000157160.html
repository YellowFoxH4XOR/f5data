K000157160: Send F5 Authentication and Audit logs to Secure Remote syslog server

Description

This article describes how to configure F5 BIG-IP LTM systems to forward only authentication and audit logs to a remote syslog server, including steps for securing log transmission using SSL/TLS. The configuration ensures that only the specified log types (audit and authentication events) are sent to the remote syslog destination, with encrypted communication for enhanced security.

Environment

  • Product: F5 BIG-IP LTM
  • Version: 17.1.2
  • Platform: F5-BIG-BT-I5800, C119
  • Key configuration elements:
    • syslog-ng filters in BIG-IP’s /sys syslog configuration
    • Remote syslog server(s) (UDP port 514 or TLS port 6514)
    • SSL/TLS certificates for secure forwarding
    • Optional: High-Speed Logging (HSL) for advanced use cases

Cause

None

Recommended Actions

A. Forwarding Only Audit and Authentication Logs

  1. Access tmsh on the BIG-IP system:
    tmsh
  2. Edit the syslog configuration:
    edit /sys syslog all-properties
  3. Customize syslog-ng filters:
    Add or replace with the following (adjust IPs/ports as needed):

    include "

    filter f_audit { match(AUDIT); };

    filter f_authpriv { match(AUTH); };

    destination d_syslog_server {

       udp("<remote_syslog_ip>" port(514));

    };

    log { source(s_syslog_pipe); filter(f_audit); destination(d_syslog_server); };

    log { source(s_syslog_pipe); filter(f_authpriv); destination(d_syslog_server); };

    "

    This setup forwards only "AUDIT" and "AUTH" matching entries.
  4. Save and apply changes:
    :wq!
    save /sys config

B. Securing Log Forwarding with SSL/TLS

  1. Import Certificates: 
    Import client certificate/key for BIG-IP and CA bundle for the remote syslog server via GUI:
    - System > Device Certificates > Import
  2. Create a Remote Syslog Server Pool: 
    create ltm pool pool_remote_secure_syslog {
      members replace-all-with { <remote_syslog_ip>:6514 { address <remote_syslog_ip> } }
      monitor tcp_half_open
    }
  3. Create a Server SSL Profile: 
    create ltm profile server-ssl profile_serverssl_syslog {
      ca-file <CA_bundle.crt>
      cert <client_cert.crt>
      key <client_key.key>
      peer-cert-mode require
      defaults-from serverssl
    }
  4. (Optional) Set Up Internal VLAN & Self IP:
    create net vlan vlan_securelog
    create net self <self_ip> vlan vlan_securelog
  5. Configure an Encrypting Virtual Server:
    create ltm virtual-address <vs_ip> traffic-group traffic-group-local-only auto-delete false
    create ltm virtual vs_secure_syslog_target {
               &nb...  &nb... destination <vs_ip>:514
    ip-protocol tcp
    pool pool_remote_secure_syslog
    profiles replace-all-with { profile_serverssl_syslog tcp }
    vlans replace-all-with { vlan_securelog }
    vlans-enabled
    }
  6. Redirect Audit/Auth Logs via Syslog-ng Filters:
    Update /sys syslog configuration:

    modify sys syslog { include " destination d_to_secure_syslog { tcp("<vs_ip>" port(514)); }; log { source(s_syslo... log { source(s_sy... " }

  7. Save your configuration:
    save /sys config
  8. Test and verify that only audit and authentication logs are securely sent to the remote server.

Additional Information

  • Adjust match conditions in filters ("AUDIT", "AUTH") based on actual log message formats or specific authentication event requirements.
  • For advanced scenarios, consider configuring High-Speed Logging (HSL).
  • Always test after making changes to confirm only intended logs are forwarded.
