K149: Disabling a link on the 3-DNS Controller or the BIG-IP Link Controller

Topic

To disable a link on 3-DNS, perform the following procedure:

  1. Log in to the command line.
  2. Using a text editor, edit the /config/3dns/etc/wideip.conf file.
  3. Locate the section of the configuration that contains the link definition. You can search for the link IP address or name to find the appropriate section.
  4. Within the brackets {} that contain the link definition that you want to disable, locate the line that begins with link. This line will appear similar to the following:

    link 172.16.20.1

  5. Change the line using the following syntax:

    link <address> disabled_until <time>

    Replace <address> with the IP address of the link that you want to disable and <time> with the time and date (in UNIX epoch time). The link should remain disabled.

    For example:

    link 172.16.20.1 disabled_until 1110822940

    Note: For information about UNIX epoch time, refer to K148: Converting a date and time into the number of seconds since the beginning of the UNIX epoch.

  6. Save the file and exit the editor.
  7. Load the configuration into memory, by typing the following command:

    3ndc restart

The link is now disabled and will remain disabled until the specified time is reached.
