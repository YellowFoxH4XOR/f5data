K7139: Attempting to create a SNAT that overlaps with another SNAT does not produce an error

Known Issue

This is the result of a known issue. If you attempt to create a secure network address translation (SNAT) that overlaps the origin address with another SNAT, the SNAT will not be created. However, the BIG-IP LTM Configuration utility does not report an error message.

F5 Product Development tracked this issue as CR63586 and it was fixed in BIG-IP LTM 9.1.3. To monitor the status of this CR, refer to the BIG-IP LTM Release Notes.
