Issue

Description

This article describes how to remove vCMP from a BIG-IP system and load a UCS archive onto the system.

Environment

  • vCMP host with a single vCMP guest configured

Cause

None

Recommended Actions

  • Creating a backup
  • Performing a clean Install of software volume
  • Backing out
  • Shutting down other blades
  • Loading UCS onto clean install
  • Powering on other blades

Creating a backup

Note: See K4423: Overview of UCS archives for more information on managing UCS archives.

  1. Log in to the TMOS shell (tmsh) of the vCMP guest.
  2. Reset the master key by typing the following command:

    modify /sys crypto master-key prompt-for-password

  3. At the password prompt, enter the master key password or passphrase.
  4. Save the BIG-IP configuration by typing the following command:

    save /sys config

  5. Create a new UCS by using the following command syntax:

    save /sys ucs <ucs_archive_name>

  6. Download the UCS off of the BIG-IP system.

Performing a clean install of software volume

Important: Perform the following procedure on all installed blades.

  1. Create a new logical volume by typing the following command:

    lvcreate -L 3g -n install vg-db-sda

  2. Format the new volume to EXT3 by typing the following command:

    mkfs.ext3 /dev/vg-db-sda/mnt/install

  3. Create a new directory by typing the following command:

    mkdir /mnt/install

  4. Mount the new volume by typing the following command:

    mount -t ext3 /dev/vg-db-sda/mnt/install /mnt/install

  5. Copy the software image you want to use to /mnt/install/<image_name>.

    For example, to copy BIGIP-12.1.3.2-0.0.4.iso from /shared/images/BIGIP-12.1.3.2-0.0.4.iso to /mnt/install/BIGIP-12.1.3.2-0.0.4.iso:

    cp /shared/images/BIGIP-12.1.3.2-0.0.4.iso /mnt/install

  6. Use image2disk to overwrite all software volumes and perform a clean install of the image. For example:

    image2disk --nvlicenseok --nosaveconfig --setdefault --reboot --format=volumes /mnt/install/BIGIP-12.1.3.2-0.0.4.iso

  7. Repeat steps 1 through 5 on all installed blades.

Backing out a clean install

Note: If step 5 from Performing a clean install of software volume is successful, then you may not back out using this procedure.

  1. Unmount the temporary volume:

    umount /mnt/install

  2. Remove the /mnt/install directory:

    rm -rf /mnt/install

  3. Remove the logical volume:

    lvremove /dev/vg-db-sda/mnt/install

Shutting down other blades

Note: On a VIPRION system, make sure to shut down all other blades before loading the UCS archive.

  1. Shut down blade 2 by typing the following command:

    bladectl -s 2 -p 0

Loading UCS onto clean install

  1. Log in to tmsh of the vCMP guest.
  2. Reset the master key by typing the following command:

    modify /sys crypto master-key prompt-for-password

  3. At the password prompt, enter the master key password or passphrase from step 2 in Creating a backup.
  4. Upload the UCS archive to /var/local/ucs.
  5. Load the UCS by using the following command syntax:

    load /sys ucs <ucs_archive_name> no-license platform-migrate

Powering on other blades

  1. Power on all other blades:

    bladectl -s 2 -p 1

Additional Information

While the procedures described in this article are not the only way to remove vCMP provisioning from a BIG-IP system, they do not require you to physically insert a USB thumb drive into the system.
