Security Advisory Description

The agent configuration file /etc/controller-agent/agent.conf is world readable with current permission bits set to 644. (CVE-2021-23021)

Impact

Local attackers are able to obtain the sensitive data, such as the API key.

Mitigation

To mitigate this vulnerability, you can change the permission bits on the affected configuration file. To do so, perform the following procedure:

Impact of action: Performing the following procedure should not have a negative impact on your system.

To change the permission bits on the /etc/controller-agent/agent.conf file, enter the following command:

chmod 640 /etc/controller-agent/agent.conf
