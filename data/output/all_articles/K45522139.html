Description

By default, BIND responds with its internal hostname when it receives a DNS request that sends a query for the hostname bind resource with record type TXT and class CHAOS.

This type of query can be generated using either the dig (dig CH TXT hostname.bind @<LISTENER IP>) or nslookup (nslookup -type=txt -class=chaos hostname.bind <LISTENER IP>) utility.

Example: 

# dig CH TXT hostname.bind @192.168.100.1
;; Got answer:
;; ->>HEADER<<- opcode: QUERY, status: NOERROR, id: 42233
;; flags: qr aa rd; QUERY: 1, ANSWER: 1, AUTHORITY: 1, ADDITIONAL: 1
;; WARNING: recursion requested but not available

;; OPT PSEUDOSECTION:
; EDNS: version: 0, flags:; udp: 4096
;; QUESTION SECTION:
;hostname.bind.                 CH      TXT

;; ANSWER SECTION:
hostname.bind.          0       CH      TXT     "GTM1.example.local"   --------------------->>>>

;; AUTHORITY SECTION:
hostname.bind.          0       CH      NS      hostname.bind.

Environment

  • BIG-IP DNS
  • Sending a query for the hostname bind resource with record type TXT and class CHAOS

Cause

By default, BIND responds with its version number as well as the hostname when it receives a DNS request that sends a query. 


Recommended Actions

The actions or steps required to address this is similar to K6827 but instead of version " ";, we need to add hostname " " instead.   

Impact of procedure: BIND may momentarily stop responding to DNS requests during the restart, and then resume responding to the requests when the process successfully restarts.

  1. Log in to the BIG-IP command line.
  2. To stop the ZoneRunner process on the BIG-IP system, type the following command:

    tmsh stop /sys service zrd

    Note: Stopping the zrd process does not prevent the BIG-IP GTM system from processing wide IP requests or BIND from processing DNS requests.

  3. To change directories to the /var/named/config/ directory, type the following command:

    cd /var/named/config/

  4. To back up the current named.conf file, type the following command:

    cp named.conf named.conf.original

  5. Using a text editor, edit the named.conf file.

    Note: F5 does not support editing the named.conf file directly on BIG-IP Link Controller-only systems. This action may result in DNS zone file synchronization issues if the Synchronize DNS Zone Files settings is enabled on the BIG-IP Link Controller system.

  6. Locate the options section and add the following line to the end of the section:

    hostname " ";

    Note: You can type anything within the quotes, or leave the space between the quotes blank.

    For example:

    options {
       listen-on port 53 {
          127.0.0.1;
          "zrd-acl-000-000";
    };
       listen-on-v6 port 53 {
          ::1;
    };
    recursion no;
    directory "/config/namedb";
    allow-transfer {
    localhost;
    };
    hostname " ";
    };

  7. Save the changes and exit the text editor.
  8. To restart named, type the following command:

    tmsh restart /sys service named

    To restart the ZoneRunner process, type the following command:

    tmsh start /sys service zrd

  9. Test the changes by doing the dig or nslookup test.
