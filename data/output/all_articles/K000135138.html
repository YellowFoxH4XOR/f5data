K000135138: Error "/usr/jdk/latest/bin/jps: No such file or directory" when performing a TTA

Applies to

Source
https://my.f5.com/manage/s/article/K000135138

Description

  • When running the ./tta-ng.sh script (in CF 26) for SDC and EMS sites, an error is generated that jps files are not found.
  • The errors looks like the ones below : 

./tta-ng.sh: line 608: /usr/jdk/latest/bin/jps: No such file or directory

./tta-ng.sh: line 793: /usr/jdk/latest/bin/jps: No such file or directory

./tta-ng.sh: line 793: /usr/jdk/latest/bin/jps: No such file or directory


Environment

  • Traffix SDC 5.1 CF 26
  • TTA

Cause

Incorrect path that references the jps and jstack files.


 Recommended Actions

Apply the following workaround by adding a sympolic link:

1. For jps;

#cd /usr/jdk/latest/bin

#ln -s /usr/bin/jps jps


2. For jstack;

#cd /usr/jdk/latest/bin

#ln -s /usr/bin/jstack jstack


3. Apply the changes in all the SDC nodes.


Additional Information

The permanent fix is in CF29.
