Description

You may want to add dual authentication (two factor) to your Outlook Web Access (OWA) after deploying Microsoft Exchange using an iApp.

Environment

  • BIG-IP APM
  • OWA | Exchange iApp Deployed.

Cause

No two factor authentication configured for OWA after the exchange iApp has been deployed.

Recommended Actions

Below are the steps to configure a landing URI.

Note: The landing URI will automatically direct users with an 'owa' URI to the two factor authentication branch of the policy, while also allowing users without the 'owa' URI to proceed with your configured non two factor authentication branch.

  1. Turn off strict updates.
  2. Add a Landing URI check to the beginning of the APM policy.
  3. Check for /owa or /owa/ and forward these to one branch.
  4. All traffic with a non owa URI follows the other branch.
  5. Duplicate the new branch of the policy to match the other, only add a dual authentication section.
