Known Issue

Exporting a Secure Sockets Layer (SSL) certificate or key from the Configuration utility may fail.

This issue occurs when the following condition is met:

  • You attempt to export an SSL certificate and/or key with a filename (including the path) longer than 64 characters.

Impact

Users cannot export an affected SSL certificate and/or key.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Attempts to export an affected SSL certificate or key from the Configuration utility will fail, and the system displays an error message similar to the following example:

    An error has occurred while trying to process your request.

Resolution

Status

F5 Product Development has assigned ID 494575 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Release12.0.0K2200: Most recent versions of F5 software
Hotfix11.4.1 HF10K9502: BIG-IP hotfix matrix

Workaround

To work around this issue, you can create SSL certificate/key pairs with names of 64 characters or less.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
