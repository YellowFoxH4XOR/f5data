Known Issue

When accessing the Configuration utility of a BIG-IP system using a proxy or port translation device, the dashboard may not be accessible.

This issue occurs when the following condition is met:

  • The configuration of the device that redirects the access to the Configuration utility is through a port number that is not 443.

Impact

You are unable to access the dashboard when accessing the Configuration utility of the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Access to the Configuration utility's dashboard fails and the system displays an error message similar to the following example:

    Error

    You may have logged out or your session may have
    expired. Please close this window and log in
    via the BIG-IP Configuration utility

Resolution

Status

F5 Product Development has assigned ID 380884 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table.

Type of fixFixes introduced inRelated articles
ReleaseNoneNone
HotfixNoneNone

Workaround

To work around this issue, you can modify the proxy or port translation configuration to use port 443.

Impact of workaround: You will need to have administrative access to the device that configures the proxy or port translation to access the Configuration utility.
