Description

This article outlines key considerations for integrating BIG-IP into a large network with hundreds of thousands of routes redistributed into BIG-IP. 

BIG-IP holds its routing entries into small memory segments spanning 128 bytes for each route. However if you are worried of memory utilization you can verify how much memory and how many routing entries are installed in TMM via the command below:

tmctl memory_usage_state | grep "rt_entry" | grep -v "if"

rt_entry 2304 2304 128 8 18

As we can see the rt_entry table holds information about the routing entries installed, here we have 18 routes, each route holds a memory footprint of 128 bytes, thus the total memory consumed is 2304 bytes.

Keep in mind that the total routing entries a BIG-IP can handle up to 1 million route entries.

 

Note: These entries are only related to dataplane or TMM routing, whereas if you want to add such routing to managment or control plane, then we adhere to Linux kernel defaults.  You can use the following command to verify Linux kernel maximum route entries:

sysctl net.ipv4.route.max_size
