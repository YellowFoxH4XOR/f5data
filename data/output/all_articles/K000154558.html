K000154558: When monitor has invalid regular expression and In-TMM monitor is enabled, TMM may crash.

Description

When In-TMM monitor is in use and monitor is configured with invalid regular expression, TMM may crash and generate core file. TMM does not crash when In-TMM monitor is not used (default). TMM does not crash when regular expression is valid.

For example, assume server provides HTTP response string '{"status":"ok"}'.

user1@ubuntu2204server1:~$ curl http://localhost/monitor.php
{"status":"ok"}
user1@ubuntu2204server1:~$

 

If monitor string is configured with invalid escape character as shown below, TMM may crash. Here, unnecessary escape character '\' precedes response string 'ok' and '\o' is not valid regular expression.

ltm monitor http /Common/my_bad_http_mon {
    recv "^HTTP\/1\.[01]\s200.*\{\"status\"\:\"\ok\"\}"
    send "GET /monitor.php HTTP/1.0\r\n\r\n"
}

 

Figure: monitor with invalid regex

 

Here is correct monitor configuration.

ltm monitor http /Common/my_http_mon {
    recv "^HTTP\/1\.[01]\s200.*\{\"status\"\:\"ok\"\}"
    send "GET /monitor.php HTTP/1.0\r\n\r\n"
}

 

Figure: monitor with valid regex

 

Environment

  • In-TMM monitor is enabled (sys db bigd.tmm enable).
  • Monitor recv string is configured with invalid regular expression (invalid use of escape character '\').

 

Cause

Bug ID 2037221.

 

Recommended Actions

Fix invalid regular expression.

 

Additional Information

None.
