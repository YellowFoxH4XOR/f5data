Description

The number of BIG-IP devices appears to have decreased since the FCP usage script was last run.

The FCP usage script shows a random amount of BIG-IP devices each time it is run or none.

Inventories summary shows "1 STARTED" not FINISHED.

Environment

  • BIG-IQ CM 8.4.x

  • FCP Usage Script

Cause

The FCP usage tool uses the BIG-IQ inventory api call to collect information about each of the managed BIG-IP devices.

However if for any reason BIG-IQ is not able to see the BIG-IP device (shows red in device list) this BIG-IP will not be included in the output.

Recommended Actions

Please ensure each of the managed BIG-IP devices has network access to the BIG-IQ see this article: BIG-IQ - BIG-IP device status ''This device is not available''

Review BIG-IQ GUI: Devices--BIG-IP Devices, note the 2 devices in RED "This device is not available" status and 2 devices in GREEN "This device is active and running"

When we run the FCP usage script, we see the following:

Only the 2 BIG-IP devices are captured by the script.
