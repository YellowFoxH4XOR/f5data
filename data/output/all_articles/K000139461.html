Description

When trying to upgrade the BIG-IP Next Central Manager, the installation process gets stuck on one of the upgrading steps.

When reviewing the current version, the upgrade has not been performed.

The Login Page loops between <ip>/gui/login and <>/gui/dashboard. It does NOT allow to type the username and password.


The output of this command is Maintenance Mode

curl -k https://localhost/api/system-info -i

Output:

{"description":"upgrade in progress","reason":"maintenance-mode"}



Environment

  • BIG-IP Next Central Manager
  • Failed Upgrade
  • Maintenance mode

Cause

Undetermined at the time of publication.

Recommended Actions

Run these commands to perform and finalize the upgrade:

  1. echo $(kubectl get secret mbiq-db-postgresql -o jsonpath='{.data}' | jq -r '."postgres-password"' | base64 -d)
  2.  Copy the password and supply it into the next command.
  3. kubectl exec mbiq-db-postgresql-0 -c postgresql -i -t -- psql -h localhost -U postgres -d bigiq_db -c "UPDATE mbiq_shared.tasks SET state='resumeFromSelfUpgrade', status='running' WHERE task_type='cm-upgrade-task' AND status='running';"
  4. ​kubectl rollout restart deployment mbiq-upgrade-manager-feature
