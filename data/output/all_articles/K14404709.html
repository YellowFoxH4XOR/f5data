Description

How do I determine if my BIG-IP virtual server is using an iRule with sideband connections? You can do so by performing the procedures described in Recommended Actions section.

Environment

  • iRules
  • sideband connection
  • connect command

Cause

N/A

Recommended Actions

You can check if your BIG-IP virtual server is using sideband connections (connect iRule command) by using one of the following procedures:

Check if your BIG-IP virtual server is using sideband connections using the Configuration utility
  1. Log into the Configuration utility.
  2. Go to Local Traffic > Network Map.
  3. Select Advanced Filter.
  4. Use the following filters:
    • For Partition, select All.
    • For Show, select virtual servers.
    • For of status, select any.
    • For Search iRule definition, type the following: connect.
  5. Virtual servers using an iRule with sideband connections are displayed. If you don't have any virtual servers using an iRule with sideband connections, no virtual servers are displayed.
Check if your BIG-IP virtual server is using sideband connections using the command line
  1. Log in to your BIG-IP system as root user.
  2. Find out how many iRules you have on your BIG-IP system by entering the following command:

    tmsh list ltm rule | grep "ltm rule" | grep -v "ltm rule _sys"

    The output should list "ltm rule" followed by the iRule name and end with a parenthesis {. For example:

    ltm rule MyiRule {
    ltm rule Collect_Payload {
    ltm rule Collect_iRule {
    ltm rule DNS_iRule {
    ...

  3. With the list of iRules, you can now proceed to find out which iRules contain the connect command by using the following command syntax:

    tmsh list ltm rule <iRule name> | grep -w "connect"

    For example, the following command finds one instance of the connect iRule command in the iRule named MyiRule:

    tmsh list ltm rule "MyiRule" |grep -w "connect"
    set conn_id [connect 10.10.10.10:80]

    Note: If the output includes the word 'connect' in the iRule comments, you may want to adjust the command to exclude comment blocks. For example,

    tmsh list ltm rule <iRule name> | grep -w "connect" | grep -v "#"

  4. Repeat step 3 for each iRule on the system.
  5. Now that you have determined which iRules contain the connect command, you should find out if the iRule is in use by any virtual server. To do so, use the following command syntax:

    tmsh list ltm virtual rules | grep "<iRule name>" -A 2 -B 2

    For example, the following command indicates that the iRule named MyiRule is associated with a virtual server named MyVirtual:

    tmsh list ltm virtual rules | grep "MyiRule" -A 2 -B 2

    ltm virtual MyVirtual {
        rules {
            MyiRule
        }
    }

  6. Repeat step 5 for each iRule that contains the connect command. If the command in step 5 does not return any output, then the iRule is not associated with a virtual server.

Additional Information

The following iRules commands and events work with sideband connections; however, only the connect command establishes sideband connections:

  • connect - Establishes a sideband connection
  • close - Closes an existing sideband connection
  • connect info - Returns a Tcl list of the specified information
  • recv - Receives data from a given sideband connection
  • send - Sends data on an existing sideband connection
