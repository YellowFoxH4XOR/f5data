Known Issue

Pool members may reject connections when a rate threshold is exceeded, even when the limit subsequently goes below the threshold.

This issue occurs when all of the following conditions are met:

  • You have configured a Connection Rate Limit on a pool member.
  • The pool member is under sustained load and the Connection Rate Limit is exceeded.
  • The pool member is disabled and re-enabled.

Impact

The system may not fully utilize available pool members.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The affected pool member permanently rejects traffic.

Workaround

To work around this issue, you can disable Connection Rate Limits. To do so, perform the following procedure:

Impact of workaround: Rate limiting functionality will be disabled.

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to Local traffic > Nodes.
  3. Select the member on which you want to disable rate limits.
  4. In the Connection Rate Limit field, set the value to 0.
  5. To save your changes, click Update.
