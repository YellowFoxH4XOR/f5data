Issue

Error Message

01010019:5: Caught signal <id>, exiting

In this error message, note the following:

  • <id> is the BIG-IP system signal identifier.

For example:

01010019:5: Caught signal 15, exiting

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The Traffic Management Microkernel (TMM) has received either a SIGINT (2) or a SIGKILL (15) signal and will restart immediately.

Note: The most common way to send TMM one of these signals is with the kill command from the BIG-IP Advanced shell (bash). For more information, refer to K13002225: Producing a diagnostic core file for F5 Technical Support (12.x).

Impact

Traffic processing will be interrupted while TMM restarts.

Recommended Actions

None
