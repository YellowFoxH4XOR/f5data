Known Issue

BIG-IP Edge Client users who run Windows may be unable to authenticate.

This issue occurs when all of the following conditions are met:

  • The installed BIG-IP Edge Client is configured with Reuse Windows Logon Credentials.
  • The Windows user uses the BIG-IP Edge Client when accessing the BIG-IP APM system.
  • The user enters invalid credentials.

Impact

Windows users are unable to authenticate.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You attempt to log in to a BIG-IP APM system and fail, and the system does not provide you a subsequent attempt.
  • After the failed log in attempt, the Edge Client displays an error message similar to the following example:

    Logging on to the network has failed. Contact your administrator for assistance.

  • Before attempting to log in again, the user must reboot their Windows device.
