Known Issue

The BIG-IP APM system may fail to detect Microsoft firewall software on Windows 8.1.

This issue occurs when all of the following conditions are met:

  • An access policy is configured with an Endpoint Security Client-Side Agent to check for the Microsoft firewall software.
  • Users connecting to the BIG-IP APM system are running the Windows 8.1 operating system.

Impact

BIG-IP APM denies users access to the system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP APM denies users access to the system.
  • The session information that the system logs in Access Policy > Reports > Session Details displays a message that appears similar to the following example:

    Following rule 'fallback' from item 'Firewall Check' to ending 'Deny'
