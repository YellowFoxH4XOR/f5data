Description

How much memory is required or recommended to provision iRulesLX on a BIG-IP

Environment

  • BIG-IP
  • iRulesLX

Cause

 iRulesLX requires additional memory space when provisioned.

Recommended Actions

The general recommendation for memory allocation for iRulesLX is 4GB.

Please also note that you may need to allocate more memory then this depending on several factors:

  • **Memory Usage Per iRule**: Each iRulesLX instance will consume memory based on its complexity and the amount of data it processes. Simple iRules might use a small amount of memory, while more complex iRules that perform extensive data processing can use significantly more.
  • **Node.js Runtime**: iRulesLX uses the Node.js runtime, which itself consumes memory. Each instance of Node.js can use tens to hundreds of megabytes of RAM depending on the modules loaded and the tasks performed.
  • **Concurrent Connections**: The number of concurrent connections that an iRulesLX script needs to handle can significantly impact memory usage. Higher numbers of concurrent connections generally require more memory.

Additional Information

For more information about provisioning modules, please refer to  K13114858 "Hardware requirements for multiple modules on VMware ESXi"
