Topic

The BIG-IP system includes functionality to install multiple versions of the BIG-IP software on different boot image slots on one unit. A boot image slot is a portion of a drive with adequate space required for an installation. If the hardware supports multiple boot image slots, you are prompted to install the software to one of the multiple boot image slots during the installation.

The command tmsh reboot volume <volume> can be used to change the default boot image on the BIG-IP systems. Additionally, this command reboots the BIG-IP system to the desired boot image immediately after execution.

The switchboot utility is also available to manage installations on different boot image slots. You can use the switchboot utility from the command line to select which installed image boots. Using the switchboot utility to change the default boot image has different results depending on the platform:

  • When running the switchboot utility to change the default boot image on VIPRION platforms, the system saves the configuration and immediately reboots all blades upon exiting the utility. This behavior is by design.

    For example, when running interactive switchboot or switchboot -b <location> to change the default boot image on VIPRION platforms, the system reboots without warning after the command is entered.

  • When running the switchboot utility to change the default boot image on BIG-IP appliance platforms, the system saves and implements the configuration the next time the system is rebooted.

    For example, when running interactive switchboot or switchboot -b <location> to change the default boot image on BIG-IP appliance platforms, the system saves and implements the configuration the next time the system is rebooted by an administrator. To perform a reboot from the command line refer to K7369: Shut down and restart the BIG-IP system.

Using switchboot in interactive mode

To run the switchboot utility in interactive mode, type the following command:

switchboot

A list of boot image slots and their boot image descriptions displays. Use the arrow keys or type the number of the boot image slot you want to boot at startup, then press Enter. When you reboot, the system starts from the boot image you specify.

Note: The switchboot utility will only list boot image slots that contain an installation.

Note: Any change you make using the switchboot utility is saved in the boot configuration grub.conf file.

Using switchboot in non-interactive mode

If you know which boot image slot you want to boot, you can type the following command and specify the short-form description of a boot image location (example: HD1.1) for <location>:

switchboot -b <location>

If you want to list the available boot image slots without specifying a new boot image from which to boot, type the following command:

switchboot -l

To list the options for the switchboot utility, type the following command:

switchboot -h
