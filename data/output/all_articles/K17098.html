Known Issue

The brute force mechanism may not trigger for low volume, failed login attacks.

This issue occurs when the following condition is met:

  • You experience low volume login failures (typically less than one login failure per second).

Impact

Brute force login attacks may go undetected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Slow rate brute force login attacks may not trigger a violation.

To improve brute force mitigation, F5 has made the following changes in the previously listed releases:

  • Added a new BIG-IP ASM internal parameter: bf_num_sec_per_value. This parameter defines the number of seconds for a single unit of measure for a failed login. For example, if you want to configure seven failed logins per five seconds, in the Configuration utility, in the Failed Login Attempts Rate reached setting (in the Detection Criteria area of the Brute Force Protection Configuration screen), enter 7 as the threshold value. From the command line, enter 5 as the value of the bf_num_sec_per_value internal parameter.

    Note: The default value for the bf_num_sec_per_value internal parameter is 1 second.

  • The minimum values for all the threshold options in the Configuration utility have been changed. You can now enter low values such as 1 or 2 in the Detection and Suspicious Criteria fields.

Changing the bf_num_sec_per_value parameter value

Impact of procedure: You must restart BIG-IP ASM services. For redundant systems, the active system may fail over to the standby system, and some traffic may be briefly interrupted. For standalone systems, traffic may be briefly interrupted.

  1. Log in to the BIG-IP ASM command line.
  2. Change the bf_num_sec_per_value parameter value to the value you want, by using the following command syntax:

    /usr/share/ts/bin/add_del_internal add bf_num_sec_per_value <value>

    In the previous command syntax, <value> is the threshold unit size, in seconds.

    For example:

    /usr/share/ts/bin/add_del_internal add bf_num_sec_per_value 5

  3. Restart the bd process by typing the following command:

    Important: This step may interrupt traffic on the device.

    bigstart restart asm

Workaround
