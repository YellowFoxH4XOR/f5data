Known Issue

This is the result of a known issue. When running BIG-IP version 10.0.0 and later, the following platforms experience slow SNMP response times when querying SNMP objects:

  • BIG-IP 6400 (D63)
  • BIG-IP 6800 (D68)
  • BIG-IP 8400 (D84)
  • BIG-IP 8800 (D88)

This behavior primarily affects SNMP requests for switch port information. For example, when an SNMP request is made for information regarding switch port statistics, the affected platforms running 10.0.0 or later may take two seconds or longer to report the information; the same platforms running 9.4.x will respond within .5 seconds.

F5 Product Development is tracking this issue as ID 343610.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.2-852.0-HF1, which has been issued for BIG-IP version 10.2.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
