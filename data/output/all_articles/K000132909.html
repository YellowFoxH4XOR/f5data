Description

How to check the Software Upgrade logs on F5OS.

Environment

  • F5OS-A (rSeries)
  • F5OS-C (VELOS)
  • Software Upgrade
  • Logging

Cause

None

 Recommended Actions

For the upgrade log, we can check form the files below:

  • F5OS-A (rSeries)
    • Software upgrade logs are located on:
      • From BASH : /var/log/sw-upgrade.log
      • From F5OS CLI: log/host/sw-upgrade.log
  • F5OS-C (VELOS)
    • Software upgrade logs are located on:
      • From BASH: /var/F5/controller/log/cc-upgrade.dbg
      • From F5OS CLI: log/controller/cc-upgrade.dbg
    • If OpenShift is upgraded (K8S Cluster), you can check OpenShift logs from:
      • BASH on /var/log/openshift.log
      • From F5OS CLI: log/host/openshift.log
