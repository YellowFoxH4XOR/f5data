Known Issue

This is the result of a known issue. Virtual servers configured with a setting that should demote PVA acceleration to partial acceleration (Assist) may incorrectly indicate that the PVA acceleration level is full acceleration on 6800 platforms. This behavior occurs when the port translation setting is enabled for the virtual server, and after making multiple configuration changes, such as enabling/disabling pool members or nodes, or changing virtual server resources, such as the destination pool. When this issue occurs, the BIG-IP system may close valid connection attempts.

For example, the Configuration utility should indicate that the PVA acceleration level is set to Assist for a performance Layer 4 virtual server that matches a SNAT. However, if the Port Translation setting is enabled for the virtual server, and multiple configuration changes are made to the virtual server (for example, using an iControl script), the Configuration utility may incorrectly indicate that the PVA acceleration level is Full for the virtual server.

F5 Product Development tracked this issue as ID 338852 and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue has also been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
