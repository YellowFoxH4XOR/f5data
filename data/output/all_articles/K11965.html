Topic

BIG-IP 6900 and 8900 platforms shipping with BIG-IP 10.1.0 and newer support RAID, and use mirrored volume sets by default. Additionally, when you upgrade one of these platforms from version 9.x to version 10.x using the image2disk command, the installation utility formats the file system to use a mirrored volume set. There may be occasions when users upgrading these platforms to version 10.x want to format the file system without creating a mirrored set. The image2disk --noarray command prevents the installation utility from creating the RAID array, even if the BIG-IP system supports it.

Note: For more information about hard disk mirroring , refer to K10856: Hard drive mirroring (RAID) for BIG-IP 10.1.0 through 10.2.4.

Installing the BIG-IP in a non-RAID configuration

Important: In order to disable disk mirroring on the device, the hard drives must be reformatted; this will destroy all the data on the device.

Running image2disk on BIG-IP 10.2.1 and later

  1. Back up and save a copy of the running configuration to a UCS archive.

    Note: For more information, refer to K11318: Backing up and restoring BIG-IP configuration files (10.x).

  2. Log in to the BIG-IP system command line.
  3. To reformat the hard drives with the image2disk utility, using the following command syntax:

    image2disk --format=volumes --nosaveconfig --noarray <ISO file>--autocreate

    For example:

    image2disk --format=volumes --nosaveconfig --noarray /shared/images/BIGIP-10.2.0.1707.0.iso  --autocreate

    Important: You should only use the --noarray option to format a BIG-IP system to use the LVM disk-formatting scheme. For more information, refer to K11964: Using the image2disk command with the --noarray and --format=partitions options together renders the system unbootable.

  4. When the installation has completed, install the previous configuration from the UCS archive created in step 1.

Running image2disk on BIG-IP 9.4.6 through 10.2.0

  1. Back up and save a copy of the running configuration to a UCS archive.

    Note: For more information, refer to K11318: Backing up and restoring BIG-IP configuration files (10.x).

  2. Log in to the BIG-IP system command line.
  3. To reformat the hard drives with the image2disk utility, using the following command syntax:

    image2disk --instslot=<target slot> --format=volumes --nosaveconfig --noarray <ISO file>--autocreate

    For example:

    image2disk --instslot=HD1.1 --format=volumes --nosaveconfig --noarray /shared/images/BIGIP-10.2.0.1707.0.iso  --autocreate

    Important: You should only use the --noarray option to format a BIG-IP system to use the LVM disk-formatting scheme. For more information, refer to K11964: Using the image2disk command with the --noarray and --format=partitions options together renders the system unbootable.

  4. When the installation has completed, install the previous configuration from the UCS archive created in step 1.

Upgrading the image2disk utility

The --noarray command option is included with the image2disk utility starting in BIG-IP 10.1.0. If you want to upgrade a BIG-IP 6900 and 8900 platform running versions 9.4.6 through 9.4.8 and format the file system without creating a mirrored set, you must first upgrade the image2disk utility. To do so, perform the following procedure:

  1. Download the version 10.2.0 ISO image from the F5 Downloads site to the target BIG-IP system.

    For example:

    /shared/tmp

    Note: For information about downloading software, refer to K167: Downloading software and firmware from F5.

  2. To verify the current version of the image2disk utility, type the following command:

    rpm -q tm_install

    Note: Versions of image2disk that are equal to or older than tm_install-2.5.0-80.0 do not support the --noarray command option.

  3. To remove the current version of the image2disk utility package, type the following command:

    rpm -e tm_install

  4. To verify that the utility was removed, type the following command:

    rpm -q tm_install

  5. To install the new image2disk utility, use the following command syntax:

    im <path_to_10.2.0.iso>

    For example:

    # im /var/tmp/BIGIP-10.2.0.1707.0.iso

  6. To verify that the image2disk utility package has been upgraded, type the following command:

    rpm -qa tm_install

    Note: The reported version should be tm_install-2.6.0-234.0 or later.

  7. You can now proceed with the installation of version 10.x using the --noarray option.
