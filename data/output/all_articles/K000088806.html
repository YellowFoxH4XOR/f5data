K000088806: Sticky Cookie Adding a "." before Cookie Domain Name in Browser - Expected Behavior?

Description

Dot "." added before Domain Name attribute in Cookie

Nginx configuration:

sticky cookie srv_id domain=xxxxx.com path=/;

There is a "." added before the domain name in browser:

srv_id XXXXXXXXXXXXXXXX .xxxxx.com / 

The session stickiness seems to be working fine, but there is a little concerned about the addition of the "." 

Environment

  • NGINX Plus R20

Cause

None

Recommended Actions

No action required. The dot is added by a browser to comply with the following RFC2965.

====

Domain=value
   OPTIONAL. The value of the Domain attribute specifies the domain
   for which the cookie is valid. If an explicitly specified value
   does not start with a dot, the user agent supplies a leading dot.

====

This allows a cookie to be available for other subdomains.

The behavior is expected and doesn’t indicate a problem.
