Known Issue

Note: This issue only occurs if the redistribute static parameter is in the ZebOS.conf file at startup.

This is a result of a known issue. If the redistribute static parameter is specified in the ZebOS.conf file before startup for the OSPF router, the nsm daemon crashes after ZebOS is started and OSPF forms adjacencies with neighbors.

If the redistribute static parameter is configured manually after the system startup, the system will not crash and static routes are properly redistributed; however, upon the next reboot, the system will re-read the ZebOS file and the system will crash.

F5 Product Development tracked this issue as CR32381 and it was fixed in BIG-IP version 4.5.10. For information about upgrading, refer to the BIG-IP release notes.

F5 Product Development tracked this issue as CR70607, CR70609, and CR70610, and it was fixed in BIG-IP LTM versions 9.3.0 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.
