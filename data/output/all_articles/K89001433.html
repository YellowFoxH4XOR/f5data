Description
This article covers how to provide Advanced Shell access to a non-local user with the Resource Administrator role.

Environment

  • BIG-IP TMOS Version 12.1.4 and earlier, 13.1.1.4 and earlier, 14.1.0.1 and earlier.
  • BIG-IP Configuration utility access
  • Remote authentication (such as AD, Radius)
  • Remote users with Resource Administrator role and want Advanced Shell access.

Cause
By default, BIG-IP allows only remote users with Administrator role to access bash (Advanced Shell). Other remote user roles cannot be given direct access to the Advanced Shell as they do not have an account defined in the /etc/passwd file, so a custom shell cannot be defined. As a result, the shell for all non-admin remote user roles defaults to tmsh. 

This is expected behavior; however, a local user who has Administrator or Resource Administrator roles can access bash.

Recommended Actions

To provide Advance Shell access to remote users, you can create a local user with the same name of the Remote user and assign the Resource Administrator role to access bash.

  1. Log into the BIG-IP GUI (preferably with an admin local account).
  2. Go to System > Users > User list and create a new user with the exact same name as of the remote user (this value is case sensitive).
  3. Select the Resource Administrator role and access to all partitions. Also select Advanced Shell for Terminal Access.
  4. Click on Finished.

The user will still get authenticated against a remote authentication server, but the access privileges of the locally created account will be taken into account to provide Advance Shell access. 

Additional Information
The procedure in the Recommended Actions section is no longer allowed beginning in BIG-IP 12.1.4.1, 13.1.1.5, 14.1.0.2, and 15.0.0.
