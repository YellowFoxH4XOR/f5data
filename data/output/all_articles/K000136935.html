Description

vCMP guest in failsafe fault mode and the following error shows up on CLI:

:ModuleNotLicensed::LICENSE INOPERAT*:Changes Pending

 

Environment

  • Failsafe Fault
  • vCMP guest
  • CLI

Cause

Software issue causing Failsafe Fault mode triggered on the vCMP guest

Recommended Actions

1) Refer to K63050110: Failsafe Fault message in the GUI after removing/disabling a blade and follow the recommended actions

2) Reload the license on the vCMP guest by typing the following command in CLI bash:
 reloadlic

None
