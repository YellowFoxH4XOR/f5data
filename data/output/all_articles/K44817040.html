K44817040: BIG-IQ IPV6 mgmt interface can not connect to other IQ mgmt interface

Type
Support Solution
Published
2019-10-03
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K44817040

Description

IPV6 HA management addresses in local IPv6 subnet are unreachable when IPV6 gateway down

  • BIG-IQ unable to connect to peer BIG-IQ over IPv6 management address
  • BIG-IQ unable to connect to BIG-IQ DCD over IPv6 management address

Environment

  • Management address configured with IPv6 address
  • Peer BIG-IQ and/or BIG-IQ DCD configured on local IPv6 subnet
  • IPv6 defauly gateway down

Cause

After reboot NDP does not bind to local IPv6 subnet addresses until after IPv6 default route is resolved

Recommended Actions

The issue can be worked around by toggling eth0 down/up after reboot. 

The following addition to the /config/user_alert.conf will automate toggling eth0 down/up after reboot:

alert K44817040_workaround  "Initial management network proposals triggered (initConfigStateMachine: mcp phase running)" {
exec command="/sbin/ifdown eth0; /sbin/ifup eth0"
}
