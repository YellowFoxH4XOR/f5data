K000138719: Renewed certificates still shown as expired in GUI

Type
Support Solution
Published
2024-03-27
Updated
2024-03-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.9
Source
https://my.f5.com/manage/s/article/K000138719

Description

After renewal of the certificate it is shown as expired in System  ››  Certificate Management : Traffic Certificate Management : SSL Certificate List, but when opened, it displays the correct expiry date.

Environment

  • BIG-IP
  • Certificate
  • Certificate renewal

Cause

Cosmetic issue

Recommended Actions

Impact of procedure: BIG-IP system traffic processing is interrupted while the system restarts.

  1. Log in to the Advanced Shell (bash).
  2. To create a null file with the file name forceload in the /service/mcpd directory, enter the following command:

    touch /service/mcpd/forceload

  3. To restart the BIG-IP system, enter the following command:

    reboot
