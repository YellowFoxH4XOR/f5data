K000138639: License error: 51092 without MAC address change

Type
Support Solution
Published
2024-02-16
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000138639

Description

An error is received even though mac address had not changed.
51092 Error without MAC address change

Environment

  • VE
  • Licensing
  • Allow Move

Cause

Changes in Hyper-V environment caused changes to the UUID.

Recommended Actions

Reach out to F5 Support for an "Allow move".

Additional Information

On a virtual environment any changes made on the hardware can change the UUID, which result in change in MAC address.
