Known Issue

The clean_db.pl process may remove learning suggestions from the BIG-IP ASM database.

This issue occurs when the following condition is met:

  • BIG-IP ASM generates learning suggestions.

The clean_db.pl process runs at regular intervals and removes violations and learning suggestions from the request tables in order to manage the size of the BIG-IP ASM database. The storage engine component of the BIG-IP ASM database, INNOdb, calculates the number of rows to be deleted at a given time by using an approximation rather than an actual count of existing row data. The estimated number of rows may vary from the actual number of rows by as much as 50 percent, causing more rows of data to be deleted from the table than is necessary to maintain the table size. As a result, less learning suggestions may display than would be expected.

Impact

Fewer than expected learning suggestions may display.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Manual Traffic Learning screen displays fewer learning suggestions than expected.
