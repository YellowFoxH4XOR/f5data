K4236: Configuring FirePass to ensure secure access to Microsoft Outlook Web Access

Topic

When you use Microsoft Outlook Web Access (OWA) with Internet Explorer, Internet Explorer caches the Microsoft OWA session information. If another user attempts to access Microsoft OWA through the same Internet Explorer session, it may be possible to access your Outlook account.

To prevent this from occurring, enable the FirePass NTLM and Basic Authentication proxy by performing the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. In the main navigation pane, select Portal Access.
  3. In the upper navigation pane, select Web Applications.
  4. In the sub-menu, select Master Group Settings.
  5. In the Master Group drop-down menu, select the name of the master group you want to configure.
  6. In the NTLM and Basic Auth Proxy section, select the Proxy Basic and NTLM auth using FirePass user logon form check box.

Note: A Preference drop-down menu appears when you enable this feature. The Preference setting controls the type of authentication FirePass attempts when prompting for user authentication. When using Microsoft OWA, select the NTLM Authentication.

FirePass will now prompt you for authentication whenever you use Microsoft Outlook Web Access.
