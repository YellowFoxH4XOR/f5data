Topic

You should consider using these procedures under the following condition:

  • You want to back up / restore the F5OS-A configuration on your rSeries system using the API.

Description

To completely backup the rSeries system you must perform the following tasks:

  • Back up the F5OS-A configuration
  • Back up each tenant TMOS configuration

This article describes how to back up and restore the F5OS-A configuration using the F5OS API. For information about backing up and restoring each tenant TMOS configuration, refer to the following article: K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.

The confd process manages the F5OS-A configuration on an rSeries system. The system stores the configuration in its configuration database. When you back up the configuration, the backup file contains F5OS-A configuration elements such as the following:

  • Tenant management configuration
    • Tenant images
  • Network settings
    • Port groups, Interfaces, VLANs
  • System settings
    • DNS, Log settings, NTP
  • Diagnostic settings
    • iHealth configuration
  • User management settings
    • Authentication settings, Users

Note: Beginning in F5OS-A versions that contain the fix for ID 1080041, when the database config-backup is performed, the license file is not included in the backup file. You must manually backup the appliance license information (Registration key and any add-on keys).

The backup file is saved in an XML ASCII format and does not require a file extension. The backup file is located in the /var/F5/system/configs directory on the file system, which is also known as the configs/ file path when you are logged in as the administrator user.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the management interface (REST API) of the rSeries system.
  • Your local workstation IP address can access port 8888 on the rSeries system. For information on configuring these features, refer to K000134482: Configure the Allow List on the F5 rSeries system.
  • Your local workstation should have the curl, awk and grep, utilities installed.

Procedures

  • Set the primary key
  • Back up the F5OS-A configuration data using the API
  • Restore the F5OS-A configuration data using the API
  • Download the backup file using the API
  • Import the backup file using the API
  • Manage the F5OS-A configuration file using the API

Set the primary key

Important: Before saving the configuration file, you must complete this procedure if you plan to restore the config file on a different rSeries appliance. If you have already completed this task, you can skip this procedure.

The F5 rSeries system uses a primary key to perform encryption and decryption of highly sensitive passwords/passphrases in the configuration database. The primary key is randomly generated by F5OS during initial installation and should be set to a known value before performing a configuration backup. In the case of a configuration migration such as moving configuration to a replacement device due to RMA, it is important to set the primary key to a known value so that the same key can be used to decrypt the passwords/passphrases in the configuration restored on the replacement device.

  1. Log in to your local workstation with the curl, awk and grep utilities installed.
  2. Set the primary key by entering the following command syntax:

    curl -k -u <username>:<password> -X POST -H 'Content-Type: application/yang-data+json' -d'{"passphrase":"<passphrase>","confirm-passphrase":"<passphrase>", "salt":"<salt>", "confirm-salt":"<salt>"}' https://<mgmt IP>:8888/restconf/data/openconfig-system:system/openconfig-system:aaa/f5-primary-key:primary-key/set

    Where

    • <username>:<password> is the username and password of the user with admin role on the rSeries system.
    • <passphrase> is the passphrase for the primary key.
    • <salt> is the string used to create a unique hash for the passphrase.
    • <mgmt IP> is the floating management IP address of the rSeries system.

    For example,

    curl -k -u admin:admin -X POST -H 'Content-Type: application/yang-data+json' -d'{"passphrase":"StrongPassphrase123","confirm-passphrase":"StrongPassphrase123", "salt":"StrongHash", "confirm-salt":"StrongHash"}' https://172.16.87.32:8888/restconf/data/openconfig-system:system/openconfig-system:aaa/f5-primary-key:primary-key/set

  3. Confirm the primary key was set by entering the following command syntax:

    curl -k -H "Content-Type: application/yang-data+json" -u <username:password> -s -X GET https://<mgmt IP>:8888/restconf/data/openconfig-system:system/openconfig-system:aaa/f5-primary-key:primary-key/state/status

    Where

    • <username>:<password> is the username and password of the user with admin role on the rSeries system.
    • <mgmt IP> is the floating management IP address of the rSeries system.

    For example,

    curl -k -H "Content-Type: application/yang-data+json" -u admin:admin -s -X GET https://172.16.87.32:8888/restconf/data/openconfig-system:system/openconfig-system:aaa/f5-primary-key:primary-key/state/status

    The output should appear similar to the following example:

    { "f5-primary-key:status": "COMPLETE Initiated: Tue Aug 13 17:33:24 2024" }

  4. Record the salt and passphrase strings in a secure manner because they are required to restore the configuration on a replacement system.

For more information, refer to Manual Chapter : Additional System Tasks in the F5 rSeries Systems: Administration and Configuration manual.

Back up the F5OS-A configuration data using the API

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your local workstation with the curl, awk and grep utilities installed.
  2. Back up the F5OS-A configuration by entering the following command syntax:

    curl -k -L -H "Content-Type: application/yang-data+json" -u <username:password> -X POST "https://<mgmt IP>:8888/restconf/data/openconfig-system:system/f5-database:database/f5-database:config-backup" -d '{ "f5-database:name":"<backup filename>" }'

    Where

    • <username>:<password> is the username and password of the user with admin role on the rSeries system.
    • <mgmt IP> is the floating management IP address of the rSeries system.
    • <backup filename> is the name of the F5OS-A configuration backup file you want to create.

    For example,

    curl -k -L -H "Content-Type: application/yang-data+json" -u admin:admin -X POST "https://172.16.87.32:8888/restconf/data/openconfig-system:system/f5-database:database/f5-database:config-backup" -d '{ "f5-database:name":"F5OS-BACKUP-APPLIANCE1-08072024" }'

  3. Confirm that the F5OS-A back up file was created by entering the following command syntax:

    curl -k -L -H "Content-Type: application/yang-data+json" -u <username:password> -X POST "https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/list" -d '{ "f5-utils-file-transfer:path":"configs/" }'

    Where

    • <username>:<password> is the username and password of the user with admin role on the rSeries system.
    • <mgmt IP> is the floating management IP address of the rSeries system.

    For example,

    curl -k -L -H "Content-Type: application/yang-data+json" -u admin:admin -X POST "https://172.16.87.32:8888/restconf/data/f5-utils-file-transfer:file/list" -d '{ "f5-utils-file-transfer:path":"configs/" }'

    The output should appear similar to the following example:

    {
      "f5-utils-file-transfer:output": {
        "entries": [
          {
            "name": "F5OS-BACKUP-APPLIANCE1-08072024",
            "date": "Thu Aug 07 22:06:07 UTC 2024",
            "size": "46KB"
          }
        ]
      }
    }

Restore the F5OS-A configuration data using the API

If the configuration backup file is located at a remote location, you should import the backup file prior to restoring the configuration. To restore the configuration data from a backup file, perform the following procedure:

Impact of procedure: Performing this procedure overrides the existing F5OS-A configuration on your rSeries system with the configuration data in the backup file.

  1. Log in to your local workstation with the curl, awk and grep utilities installed.
  2. Restore the F5OS-A configuration by entering the following command syntax:

    curl -k -L -H "Content-Type: application/yang-data+json" -u <username:password> -X POST https://<mgmt IP>:8888/restconf/data/openconfig-system:system/f5-database:database/f5-database:config-restore -d '{ "f5-database:name": "<backup filename>" }'

    Where

    • <username>:<password> is the username and password of the user with admin role on the rSeries system.
    • <mgmt IP> is the floating management IP address of the rSeries system.
    • <backup filename> is the name of the F5OS-A configuration backup file.

    For example,

    curl -k -L -H "Content-Type: application/yang-data+json" -u admin:admin -X POST https://172.16.87.32:8888/restconf/data/openconfig-system:system/f5-database:database/f5-database:config-restore -d '{ "f5-database:name": "F5OS-BACKUP-APPLIANCE1-08142024" }'

    The output should appear similar to the following example:

    "result": "Database config-restore successful."

    F5 recommends that you perform a reset-to-default operation to clear the existing configuration before attempting to restore to a previous configuration. For more information about performing a reset-to-default operation, refer to K20024872: Restoring the rSeries configuration to factory default settings. If you have completed the reset-to-default operation on your rSeries system, enter yes to proceed with the configuration restoration to the system.

  3. The appliance may automatically reboot.

Download the backup file using the API

You can download the backup file from your rSeries system to your local system. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your local workstation with the curl, awk and grep utilities installed.
  2. Obtain the authorization token from the rSeries system by using the following command syntax:

    curl -fsSkI -u <username:password> -X GET "https://<mgmt IP>:8888/restconf" | grep -i 'x-auth-token' | awk -F: '{print $2}' | tr -d ' \r'

    Where

    • <username>:<password> is the username and password of the user with admin role on the rSeries system.
    • <mgmt IP> is the floating management IP address of the rSeries system.

    For example,

    curl -fsSkI -u admin:admin -X GET "https://172.16.87.32:8888/restconf" | grep -i 'x-auth-token' | awk -F: '{print $2}' | tr -d ' \r'

    The output should appear similar to the following example:

    eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJTZXNzaW9uIElEIjoiYWRtaW4xNzIzNzQ2MDQyIiwiYXV0aGluZm8iOiJhZG1pbiAxMDAwIDkwMDAgXC92YXJcL0Y1XC9zeXN0ZW0iLCJidWZmZXJ0aW1lbGltaXQiOiIzMDAiLCJleHAiOjE3MjM3NDY5NDIsImlhdCI6MTcyMzc0NjA0MiwicmVuZXdsaW1pdCI6IjUiLCJ1c2VyaW5mbyI6ImFkbWluIDE3Mi4xOC4wLjgzIn0.itTH4OiURpBjhYr_d0dzB5qWJ6szWu8DRfh7rjlAStk

  3. Download the F5OS-A configuration file by entering the following command syntax:

    curl -k --location --request POST "https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/f5-file-download:download-file/f5-file-download:start-download" -H "Content-Type: multipart/form-data" -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: <auth token>" -F "file-name=<filename>" -F file-path="configs/" > </path/filename>

    Where

    • <username>:<password> is the username and password of the user with admin role on the rSeries system.
    • <mgmt IP> is the floating management IP address of the rSeries system.
    • <auth token> is the authorization token you obtained from step 2.
    • <filename> is the name of the F5OS-A backup file.
    • </path/filename> is the local path and filename of the F5OS-A backup file that you are downloading to the local system.

    For example,

    curl -k --location --request POST "https://172.16.87.32:8888/restconf/data/f5-utils-file-transfer:file/f5-file-download:download-file/f5-file-download:start-download" -H "Content-Type: multipart/form-data" -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJTZXNzaW9uIElEIjoiYWRtaW4xNzIzNzQ2MDQyIiwiYXV0aGluZm8iOiJhZG1pbiAxMDAwIDkwMDAgXC92YXJcL0Y1XC9zeXN0ZW0iLCJidWZmZXJ0aW1lbGltaXQiOiIzMDAiLCJleHAiOjE3MjM3NDY5NDIsImlhdCI6MTcyMzc0NjA0MiwicmVuZXdsaW1pdCI6IjUiLCJ1c2VyaW5mbyI6ImFkbWluIDE3Mi4xOC4wLjgzIn0.itTH4OiURpBjhYr_d0dzB5qWJ6szWu8DRfh7rjlAStk" -F "file-name=F5OS-BACKUP-APPLIANCE1-08142024" -F file-path="configs/" > /Downloads/F5OSbackup/F5OS-BACKUP-APPLIANCE1-08142024

  4. Check your local system and verify that the F5OS-A file was downloaded as expected.

Import the backup file using the API

You can import a backup file from your local device to your rSeries system using the API. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your local workstation with the curl, awk and grep utilities installed.
  2. Obtain the authorization token from the rSeries system by using the following command syntax:

    curl -fsSkI -u <username:password> -X GET "https://<mgmt IP>:8888/restconf" | grep -i 'x-auth-token' | awk -F: '{print $2}' | tr -d ' \r'

    Where

    • <username>:<password> is the username and password of the user with admin role on the rSeries system.
    • <mgmt IP> is the floating management IP address of the rSeries system.

    For example,

    curl -fsSkI -u admin:admin -X GET "https://172.16.87.32:8888/restconf" | grep -i 'x-auth-token' | awk -F: '{print $2}' | tr -d ' \r'

    The output should appear similar to the following example:

    eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJTZXNzaW9uIElEIjoiYWRtaW4xNzIzNzQ2MDQyIiwiYXV0aGluZm8iOiJhZG1pbiAxMDAwIDkwMDAgXC92YXJcL0Y1XC9zeXN0ZW0iLCJidWZmZXJ0aW1lbGltaXQiOiIzMDAiLCJleHAiOjE3MjM3NDY5NDIsImlhdCI6MTcyMzc0NjA0MiwicmVuZXdsaW1pdCI6IjUiLCJ1c2VyaW5mbyI6ImFkbWluIDE3Mi4xOC4wLjgzIn0.itTH4OiURpBjhYr_d0dzB5qWJ6szWu8DRfh7rjlAStk

  3. Initiate the import and obtain the required upload-id by entering the following command syntax:

    curl -k -L -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: <auth token>" -X POST "https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/f5-file-upload-meta-data:upload/f5-file-upload-meta-data:start-upload" -d '{ "f5-file-upload-meta-data:file-path": "configs/", "f5-file-upload-meta-data:name": "<file name>", "f5-file-upload-meta-data:size": <file size> }'

    Where

    • <auth token> is the authorization token you obtained in the previous step.
    • <mgmt IP> is the floating management IP address of the rSeries system.
    • <file name> is the F5OS-A back up file that you want to import to the rSeries system.
    • <file size> is the size of the F5OS-A back up file.

    For example,

    curl -k -L -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJTZXNzaW9uIElEIjoiYWRtaW4xNzIzNzQ2MDQyIiwiYXV0aGluZm8iOiJhZG1pbiAxMDAwIDkwMDAgXC92YXJcL0Y1XC9zeXN0ZW0iLCJidWZmZXJ0aW1lbGltaXQiOiIzMDAiLCJleHAiOjE3MjM3NDY5NDIsImlhdCI6MTcyMzc0NjA0MiwicmVuZXdsaW1pdCI6IjUiLCJ1c2VyaW5mbyI6ImFkbWluIDE3Mi4xOC4wLjgzIn0.itTH4OiURpBjhYr_d0dzB5qWJ6szWu8DRfh7rjlAStk" -X POST "https://172.16.87.32:8888/restconf/data/f5-utils-file-transfer:file/f5-file-upload-meta-data:upload/f5-file-upload-meta-data:start-upload" -d '{ "f5-file-upload-meta-data:file-path": "configs/", "f5-file-upload-meta-data:name": "F5OS-BACKUP-APPLIANCE1-08142024", "f5-file-upload-meta-data:size": 46188 }'

    The output includes the upload-id and should appear similar to the following example:

    {
      "f5-file-upload-meta-data:output": {
        "upload-id": "juZuq2FG"
      }
    }

  4. Import the F5OS-A configuration file by entering the following command syntax:

    curl -k -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: <auth token>" -H "File-Upload-Id: <upload ID>" -X POST "https://<mgmt IP>:8888/restconf/data/openconfig-system:system/f5-image-upload:image/upload-image" --form "=@<backup filename>"

    Where

    • <auth token> is the authorization token you obtained from step 2.
    • <mgmt IP> is the floating management IP address of the rSeries system.
    • <upload ID> is the upload id that you obtained in the previous step.
    • <backup filename> is the F5OS-A backup file that you are importing to the rSeries system.

    For example,

    curl -k -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJTZXNzaW9uIElEIjoiYWRtaW4xNzIzNzQ2MDQyIiwiYXV0aGluZm8iOiJhZG1pbiAxMDAwIDkwMDAgXC92YXJcL0Y1XC9zeXN0ZW0iLCJidWZmZXJ0aW1lbGltaXQiOiIzMDAiLCJleHAiOjE3MjM3NDY5NDIsImlhdCI6MTcyMzc0NjA0MiwicmVuZXdsaW1pdCI6IjUiLCJ1c2VyaW5mbyI6ImFkbWluIDE3Mi4xOC4wLjgzIn0.itTH4OiURpBjhYr_d0dzB5qWJ6szWu8DRfh7rjlAStk" -H "File-Upload-Id: juZuq2FG" -X POST "https://172.16.87.32:8888/restconf/data/openconfig-system:system/f5-image-upload:image/upload-image" --form "=@F5OS-BACKUP-APPLIANCE1-08142024"

    The output should appear similar to the following example:

    { "result-tag": "uploaded-successfully" }

Manage the F5OS-A configuration file using the API

If you need to manage the F5OS-A configuration files backed up over a period of time, you can perform the following procedure to list them and delete them as needed:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your local workstation with the curl, awk and grep utilities installed.
  2. List the F5OS-A configuration files in the configs/ path by entering the following command syntax:

    curl -k -L -H "Content-Type: application/yang-data+json" -u <username:password> -X POST "https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/list" -d '{ "f5-utils-file-transfer:path":"configs/" }'

    Where

    • <username>:<password> is the username and password of the user with admin role on the rSeries system.
    • <mgmt IP> is the floating management IP address of the rSeries system.

    For example,

    curl -k -L -H "Content-Type: application/yang-data+json" -u admin:admin -X POST "https://172.16.87.32:8888/restconf/data/f5-utils-file-transfer:file/list" -d '{ "f5-utils-file-transfer:path":"configs/" }'

    The output should appear similar to the following example:

    {
      "f5-utils-file-transfer:output": {
        "entries": [
          {
            "name": "F5OS-BACKUP-APPLIANCE1-08072024",
            "date": "Thu Aug 07 22:06:07 UTC 2024",
            "size": "46KB"
          },
          {
            "name": "F5OS-BACKUP-APPLIANCE1-07062025",
            "date": "Thu Jul 06 20:07:05 UTC 2025",
            "size": "50KB"
          },
          {
            "name": "F5OS-BACKUP-APPLIANCE1-02252026",
            "date": "Thu Feb 25 08:46:18 UTC 2025",
            "size": "55KB"
          }
        ]
      }
    }

  3. To remove one of the F5OS-A configuration files in the configs/ path, enter the following command syntax:

    curl -k -L -H "Content-Type: application/yang-data+json" -u <username:password> -X POST "https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/delete" -d '{ "f5-utils-file-transfer:file-name":"configs/<file name>" }'

    Where

    • <username>:<password> is the username and password of the user with admin role on the rSeries system.
    • <mgmt IP> is the floating management IP address of the rSeries system.
    • <file name> is the name of the F5OS-A configuration file you want to remove

    For example,

    curl -k -L -H "Content-Type: application/yang-data+json" -u admin:admin -X POST "https://172.16.87.32:8888/restconf/data/f5-utils-file-transfer:file/delete" -d '{ "f5-utils-file-transfer:file-name":"configs/F5OS-BACKUP-APPLIANCE1-02252026" }'

    The output should appear similar to the following example:

    {
      "f5-utils-file-transfer:output": {
        "result": "Deleting the file"
      }
    }

  4. Perform step 2 again to verify that the F5OS-A configuration file has been removed from the system.
