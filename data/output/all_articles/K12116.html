Known Issue

When you click terminate to end a Network Access session or the Network Access session ends automatically for FirePass or a BIG-IP APM system connected through Safari 5 for Mac OS X, you may receive the following error message:

F5 SSL VPN Plugin (Safari Internet plug-in) quit unexpectedly

This error message does not affect the performance or operation of the F5 Secure Sockets Layer (SSL) Virtual Private Network (VPN) client because it occurs after the client session is closed.

For information about fixes, refer to the following list:

  • F5 Product Development is tracking this issue as ID 336382 for BIG-IP 10.1.0.
  • F5 Product Development tracked this issue as ID 336383 for BIG-IP 10.2.x and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing a hotfix, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

  • F5 Product Development is tracking this issue as ID 327723 (formerly CR142530) for FirePass controller.

    This issue has been fixed in cumulative HF-70-1 issued for FirePass 7.0.0, and in cumulative HF-610-3-1 issued for FirePass 6.1.0. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.
