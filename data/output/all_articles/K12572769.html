K12572769: BIG-IP import fails with error indicating a configuration object name has invalid character

Description

  • You attempt to import a BIG-IP module like AFM
  • You encountered an error as shown below 
Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.IllegalArgumentException: Property 'name' value 'my BIG-IP object' has an invalid character that is not in the allowed set of characters '-a-zA-Z_.0-9'.

Environment

  • BIG-IP
  • BIG-IQ

Cause

  • ID 621516

Recommended Actions

  • BIG-IQ is very particular about the characters used in BIG-IP objects. In this case, the vale of NAME  'my BIG-IP Virtual' contains white spaces.
  • White spaces are not allowed and a name must be made up of characters '-a-zA-Z_.0-9'.
    • you would need to replace or remove the space in value 'my BIG-IP object' to something like myBIG-IPVirtual
