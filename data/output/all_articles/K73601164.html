Description
Multiple ASM instances cause all services to stop responding. CPU 100% utilization.

  • No access to configuration utilities (GUI or SSH/CLI)
  • CPU spikes up to 100%
  • Multiple copies of ASM processes.
    • asm_config_server.p
    • asm_config_server_rpc_handler.p
    • asm_config_server_rpc_handler_async.p
  • /var/log/ts/bd.log
    BD_MISC|NOTICE|Dec 29 20:30:10.356|19455|temp_func.c:4246|UMU: total 102781 (171M) VM (2960M) RSS (444M) SWAP (  0M) trans    12
    BD_MISC|WARN  |Dec 29 20:30:12.120|19455|temp_func.c:4250|IO or CPU resources are probably not available to the bd

Environment

  • BIG-IP ASM 

Cause

Bug ID 723790: Idle asm_config_server handlers consumes a lot of memory

Recommended Actions

Reference ID723790 for Workaround and Resolution.
Contact support to verify root cause.
