Known Issue

Citrix applications fail to open when accessed through BIG-IP APM.

This issue occurs when all of the following conditions are met:

  • The Citrix application is published to a BIG-IP APM webtop
  • The user is accessing BIG-IP APM with Internet Explorer 9

Impact

Users cannot access Citrix applications that are published through a BIG-IP APM webtop

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The users web browser displays the following error message:

    JS error:SCRIPT5022: DOM Exception: INVALID_CHARACTER_ERR (5)

Resolution

Status

F5 Product Development has assigned ID 367726 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can enable Compatibility View on Internet Explorer 9.

For more information about Internet Explorer 9 Compatibility View, refer to the following Microsoft document. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

Internet Explorer 9 Compatibility View

Impact of workaround: None.
