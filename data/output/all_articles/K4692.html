K4692: Reasons why 56-bit clients may fail when trying to establish a session with an SSL proxy that uses a Step-Up Certificate

Topic

Step-Up Certificates (also known as Server Gated Cryptography) allow browsers that use 56-bit cryptography to utilize 128-bit cryptography under certain circumstances. This enables browsers that normally can only use 56-bit cryptography to connect to a site that uses only 128-bit cryptography.

Some 56-bit browsers are not compatible with Step-Up Certificates or suffer from bugs that prevent the step-up procedure from working correctly. Those browsers will hang when trying to access a site that uses any type of Step-Up Certificate.

These browser issues are not the result of a problem with the BIG-IP SSL proxy. The browser issue will occur with any server-side SSL applications that are accessed by these faulty clients. In most cases, upgrading to the newest version of your browser will resolve this issue.

If you cannot upgrade your browser immediately, you can disable the 56-bit ciphers and force the browsers to initialize with 40-bit (instead of 56-bit) ciphers, then step-up to 128-bit ciphers. You can perform this procedure from the Configuration utility or the command line.

Configuration utility

  1. Log in to the Configuration utility.
  2. From the navigation pane, click Proxies.
  3. Click the address of the SSL proxy that you want to modify.
  4. Click the Proxy Advanced Properties tab.
  5. In the Client Cipher List String text box, type the following:

    EXPORT40:HIGH:MEDIUM

  6. Click the Apply button.

56-bit browsers should now be able to establish a session with the SSL proxy.

Command line

  1. Log in to the command line.
  2. Define the cipher set that is presented to the client, using the following command syntax:

    bigpipe proxy <ip>:<port> clientssl ciphers \"EXPORT40:HIGH:MEDIUM\"

    Replace <ip> and <port> with the IP address and port of the SSL proxy that you want to modify.

  3. Save the configuration changes by typing the following command:

    bigpipe save

56-bit browsers should now be able to establish a session with the SSL proxy.
