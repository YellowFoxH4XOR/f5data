K000149610: How to translate F5OS MIB files to OID

Type
Support Solution
Published
2025-02-04
Updated
2025-02-07
Applies to

  • F5OS-A
Source

Description

Translate F5OS MIB Files to OID

Environment

  • F5OS-A
  • SNMP MIBS

Cause

Command snmptranslate not available on F5OS-A.

[root@appliance-1 ~]#snmptranslate -On -Tz -m /tmp/mibs_f5os_appliance/F5OS-APPLIANCE-ALERT-NOTIF-MIB.txt
bash: snmptranslate: command not found

Recommended Actions

1. Run snmptranslate in BIG-IP or any device with snmptranslate installed.

2. Extract and download all F5OS MIB files in one directory.

Example: Create f5osmibs folder in BIG-IP /var/tmp/.  Download and extract all F5OS MIB files in f5osmibs directory.

[root@bigip01:Standby:In Sync] ~ # ls /var/tmp/f5osmibs/
EtherLike-MIB.txt                   F5-PLATFORM-STATS-MIB.txt  RFC1213-MIB.txt            SNMP-TARGET-MIB.txt         SNMPv2-TC.txt
F5-ALERT-DEF-MIB.txt                HOST-RESOURCES-MIB.txt     SNMP-COMMUNITY-MIB.txt     SNMP-USER-BASED-SM-MIB.txt  SNMP-VIEW-BASED-ACM-MIB.txt
F5-COMMON-SMI-MIB.txt               IANAifType-MIB.txt         SNMP-FRAMEWORK-MIB.txt     SNMPv2-CONF.txt             TRANSPORT-ADDRESS-MIB.txt
F5OS-APPLIANCE-ALERT-NOTIF-MIB.txt  IF-MIB.txt                 SNMP-MPD-MIB.txt           SNMPv2-MIB.txt
F5-OS-SYSTEM-MIB.txt                IPV6-TC.txt                SNMP-NOTIFICATION-MIB.txt  SNMPv2-SMI.txt

3. Run snmptranslate specifying the mibs directory

[root@bigip01:Standby:In Sync] ~ # snmptranslate  -On -Tz -M /var/tmp/f5osmibs/ -m /var/tmp/f5osmibs/F5OS-APPLIANCE-ALERT-NOTIF-MIB.txt
