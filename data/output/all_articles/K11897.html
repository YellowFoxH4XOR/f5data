Known Issue

This is the result of a known issue. BIG-IP ASM may report false positive web scraping attacks for web objects when the security policy is in transparent mode.

When this issue occurs, the Web Scraping Statistics screen may report that the system detected web scraping attacks for any requests for a web object, including non-HTML objects, such as text objects.

F5 Product Development is tracking this issue as ID 225414 (formerly CR139341).

This issue has been fixed in Hotfix-BIGIP-10.2.0-1755.1-HF1, which has been issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
