Known Issue

This is the result of a known issue. Changes to the Refresh Password setting are not imported when an administrator exports existing users to a text file, makes a change to the Refresh Password field, and imports the users back into the FirePass controller. However, changes to other settings will be imported; also, if the administrator adds a new user to the text file before importing the file, values set to the Refresh Password setting are imported.

Note: Administrators can export and import users by navigating to the Users: User Management page and selecting the File Export check box.

F5 Networks Product Development tracked this issue as CR136220 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-610-2 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
