What Happened?

I want to test the feature of L7 DDoS detection attacks but I am not seeing any attack event happening.

Environment

  • F5® Distributed Cloud Services
  • App Networking
  • DDoS L7

Resolution/Answer

In order to see a L7 DDoS attack being triggered you have to have several conditions:

  1. Having a baseline of what is a normal traffic, that is:
    1. Have normal requests before 30 minutes of requests
    2. 7 days of historic requests data
    3. multiple source of IP attacks (1 IP may not be enough).
      1. Why? Because if only one src_ip is used for normal requests and also only one src_ip is used for attack requests, internally the IP distribution didn't change, even though the attack src_ip is different from the normal src_ip. If one src_ip for normal request and two different src_ips for attack requests, security events would be triggered.
