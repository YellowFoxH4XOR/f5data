Description

  • How to perform DNS queries for zones being configured in F5 Distributed Cloud Services
  • Are the name servers documented publicly?

Environment

  • F5 Distributed Cloud DNS

Procedure

  • Yes. You can query against the anycast addresses that are returned when you create a new zone, and you can find them in the details of a zone.
  • Be sure to use the following for the DNS nameservers with your Domain Registrar:
    Nameserver FQDNIPv4 addressIPv6 address

    2604:e180:1071::3:1
