Description

Receiving an error when attempting to install Bot Signature Live Updates:

Fail load update files: Can't use an undefined value as an ARRAY reference at /usr/local…./BotSignature.pm line 32

Environment

  • Live Update
  • Bot Signatures
  • GUI

Cause

Bug ID 883853: Bot Defense Profile with staged signatures prevents signature update

Recommended Actions

To workaround the issue, enforce the staged signature(s) in the Bot Defense profile, then attempt to install the update again. It should succeed.

Alternatively, upgrade to a fixed version.

An engineering hotfix may also be made available by contacting F5 Support.

Additional Information
