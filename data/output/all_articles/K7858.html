Issue

Previously, if a user closed the webtop browser window in Microsoft Internet Explorer (IE), the user's Network Access connection and Application Tunnels would remain open.

Beginning with FirePass 6.0.0, the FirePass system terminates the Network Access connection and Application Tunnels if the user closes the webtop browser window in IE.

Reverting to the previous behavior

In FirePass 6.0.0 with cumulative hotfix HF-600-15 or later, and in FirePass 6.0.1 and later, you can work around this change in behavior by performing the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Network Access > Global Settings.
  3. In the Network Access Settings section, select the Leave VPN Connection/Application tunnels open when webtop is closed check box.
