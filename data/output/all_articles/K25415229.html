Issue

Error Message

notice tmm[<PID>]: 01010259:5: External Datagroup (<name>) <status>.

In this error message, note the following:

  • <PID> is the process ID for the tmm process
  • <name> is the name of the affected data group
  • <status> is a message indicating the status of the operation

For example:

notice tmm[14304]: 01010259:5: External Datagroup (/Common/ex_datagroup) update finished.

Message Location

You may encounter this message in the following location:

  • The /var/log/tmm file
Description

This message occurs when all of the following conditions are met:

  • You are using external data groups in your BIG-IP configuration.
  • You perform an operation on the data group, such as creation, update, or deletion, using the Configuration utility, the TMOS Shell (tmsh), or by using a script.

Possible values for the status message include the following:

  • queued or queued for update
  • creation finished or update finished
  • deleted
  • failed
If the message is failed, processing of the external data group did not complete successfully. This behavior is generally a result of a tmm out-of-memory condition or a Tool Command Language (Tcl) error.

Impact

When the status message is failed, an error occurred and the operation failed to complete.

Recommended Actions

Messages with a failed status may occur due to excessive memory usage. You can monitor memory usage using Linux utilities, such as top, ps, and free. For example, to view a list of processes sorted by resident memory usage, you can use the ps aux --sort -rss | head command.
