Description

You want to know what endpoints can be used to monitor the Uptime of the service Account Protection

 

Environment

  • F5® Distributed Cloud Account Protection

Answer

F5 Distributed Cloud has 2 endpoints that can be used;

  1. POST provision (exists in all environments); This endpoint is not for health check purposes, it returns
    • HTTP 200 OK if the tenant is a valid Shape customer
    • HTTP 403 if the tenant is not valid customer
  2. GET health
