Known Issue

FIPS accelerated Secure Sockets Layer (SSL) connection requests may sporadically fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured for FIPS SSL acceleration.
  • You provision the BIG-IP LTM, BIG-IP DNS, BIG-IP GTM, or Link Controller module.
  • Your BIG-IP system actively processes SSL traffic.

Impact

Accelerated SSL session connection requests sporadically fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H527602 on the Diagnostics > Identified > Low page.
  • The affected virtual server does not respond to SSL client hello requests, causing SSL handshakes to fail.
  • When accelerated SSL connections fail, you observe log messages similar to the following example in the /var/log/ltm file:

    crit tmm5[<pid>]: 01260000:2: Profile /<partition>/<ssl profile name>: could not load key file
    crit tmm6[<pid>]: 01260010:2: FIPS acceleration device failure: cannot locate key
