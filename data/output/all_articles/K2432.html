Topic

When a VLAN group is configured, BIG-IP will proxy ARP traffic between the two VLANs in the group. When BIG-IP is deployed in a redundant pair, traffic to and from the standby system may be proxied by the active system. This can result in multiple ARP responses and address conflicts.

To avoid this issue, you can configure a proxy ARP exclusion class so that ARP traffic to or from members of the configured proxy_arp_exclude class will not be proxied.

You can configure a proxy ARP exclusion class using the Configuration utility or the command line.

Configuration utility

To configure a proxy ARP exclusion class using the Configuration utility, perform the following steps:

  1. Log in to the Configuration utility.
  2. From the navigation pane, click Rules.
  3. From the Rules page, click the Classes tab.
  4. From the Classes page, click the Add button.
  5. In the Class Name field, type proxy_arp_exclude.
  6. Add each self IP address to the address list.
  7. Click the Done button.

Command line

To configure a proxy ARP exclusion class using the command line, perform the following steps:

  1. Log in to the command line.
  2. Create the proxy_arp_exclude class, using the following command syntax:

    bigpipe class proxy_arp_exclude { host <address> ... host <address> }

    For example:

    bigpipe class proxy_arp_exclude { host 172.16.22.6 host 10.10.91.6 }

  3. Save the configuration, by typing the following command:

    bigpipe save
