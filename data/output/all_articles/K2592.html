K2592: Configuring synchronization groups that contain both 3-DNS and BIG-IP Link Controller

Topic

Starting in version 4.5 PTF-05, 3-DNS and BIG-IP Link Controllers can be contained within the same synchronization group.

Once you add the BIG-IP Link Controller to the 3-DNS Controller's synchronization group, the 3-DNS Controller will become aware of the ISP Links from the BIG-IP Link Controllers and will manage traffic based on the load balancing methods specified on each.

To integrate BIG-IP Link Controllers into a 3-DNS Controller synchronization group, perform the following three tasks:

  • Run the merge_configs script on the synchronization group's principal 3-DNS Controller.
  • Add the BIG-IP Link Controller to the synchronization group on the principal 3-DNS Controller.
  • Run the 3dns_add script on the BIG-IP Link Controller.

Note: F5 recommends that before you perform the following tasks, back up the configuration for both the 3-DNS and the BIG-IP Link Controller.

Run the merge_configs script

From the command line of the principal 3-DNS Controller, type the following command, where <ip_address> is the IP address of the BIG-IP Link Controller that you want to add to the synchronization group:

/usr/local/bin/merge_configs -peer <ip_address>

Add the BIG-IP Link Controller to the synchronization group

  1. Log in to the Configuration utility of the principal 3-DNS Controller.
  2. From the navigation pane, click 3-DNS Sync.
  3. From the toolbar, click Add to Group.
  4. Check the box next to the BIG-IP Link Controller that you want to add to the synchronization group.
  5. Click Add.

Run the 3dns_add script

The 3dns_add script moves the synchronized configuration to the BIG-IP Link Controller, and finalizes the synchronization group setup. Run the script from the BIG-IP Link Controller.

The BIG-IP Link Controller is now added to the 3-DNS Controller's synchronization group.
