K000135058: Why doesn't putting NTLM::disable in an iRule throw an error when there is no NTLM profile on the VS?

Type
Support Solution
Published
2023-06-16
Updated
2023-06-16
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000135058

Description

Introducing a line with "NTLM::disable" in an irule bound to a VS does not throw any errors in the GUI, and neither does attaching such an iRule to an existing VS without an NTLM profile assigned.


Environment

LTM


Cause

NTLM::disable in irule does not require an existing NTLM profile to be already bound on VS, because logically an admin could be enabling NTLM somewhere else in the same iRule via some logic, or even in a different iRule which will also be bound to the same VS.

This level of checking for possible consistency violations inside an iRule is beyond the current scope of iRule checks which are done at configuration time at present.


Recommended Actions

None.


Additional Information

None.
