Description

Clicking the import button from the System  ››  Software Management  Image List/Hotfix List/APM Clients or System >>  Certificate Management >> Traffic Certificate Management >> SSL Certificate List  pages may result in a "No access" error message. 
Users will encounter the following errors when running into this issue:

  • catalina.out log will have the following error
    • ERROR [ajp-bio-127.0.0.1-8009-exec-7] web.FormHandler:doAllowedCharactersCheck     - /tmui/Control/form returning response as, No Access
  • GUI: "No access" is displayed within a grey banner with yellow triangle

Environment

  • TMOS Version 14.1.4.4
  • TMOS Version 15.1.3.1
  • TMOS Version 16.1.0
  • Import button on the following GUI pages
    • Image List
    • Hotfix List
    • APM Clients
    • SSL Certificate List

Cause

This issue is related to ID 1046433

Recommended Actions

To work around this issue users can select "Import..." from the left-hand navigation menu instead of clicking "Import..." on the page

  1. System >> Software Management >> Image List >> Import...
  2. System >> Software Management >> Hotfix List >> Import...
  3. System >> Software Management >> APM Clients >> Import...
  4. System >>  Certificate Management >> Traffic Certificate Management >> SSL Certificate List >> Import...
