Description

  • Suggestion to Add a File Type to the disallowed File Type list but can see the can't see the request that generated the suggestion
  • The learning suggestion shows the following message:

    No valid traffic requested it

Environment

  • ASM learning suggestions
  • ASM with learning mode enabled

Cause

Seen behavior is expected. This type of learning suggestion is a policy tightening suggestion, no request samples exist because the relevant traffic did not generate any violation.

Tightening suggestions are to make a policy more restrictive. For example the ASM suggests to add "cmd" file type to the Disallowed File types because there were not seen any requests from trusted sources to files with extension "cmd"

Recommended Actions

You can consider accept the suggestion
