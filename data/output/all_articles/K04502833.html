Description

How do I determine if my BIG-IP virtual server is using the HTTP::collect iRules command? You can do so by performing the procedure described in Recommended Actions section via CLI or the tmsh utility.

Environment

  • iRules
  • HTTP::collect

Cause

N/A

Recommended Actions

You can check if your BIG-IP virtual server is using the HTTP::collect iRule command by performing the following steps:
  1. Log in to your BIG-IP system as root user.
  2. Find out how many iRules you have on your BIG-IP system by entering the following command:

    tmsh list ltm rule | grep "ltm rule" | grep -v "ltm rule _sys"

    The output should list "ltm rule" followed by the iRule name and end with a parenthesis {. For example:

    ltm rule MyiRule {
    ltm rule Collect_Payload {
    ltm rule Collect_iRule {
    ltm rule DNS_whitelist {
    ...

  3. With the list of iRules, you can now proceed to find out which iRules contain the HTTP::collect command by using the following command syntax:

    tmsh list ltm rule <iRule name> | grep "HTTP::collect"

    For example, the following command finds one instance of the HTTP::collect iRule command in the iRule named MyiRule:

    tmsh list ltm rule MyiRule | grep "HTTP::collect"
    HTTP::collect $content_length

  4. Repeat step 3 for each iRule on the system.
  5. Now that you have determined which iRules contain the HTTP::collect command, you should find out if the iRule is in use by any virtual server. To do so, use the following command syntax:

    tmsh list ltm virtual rules | grep "<iRule name>" -A 2 -B 2

    For example, the following command indicates that the iRule named MyiRule is associated with a virtual server named MyVirtual:

    tmsh list ltm virtual rules | grep "MyiRule" -A 2 -B 2

    ltm virtual MyVirtual {
        rules {
            MyiRule
        }
    }

  6. Repeat step 5 for each iRule that contains the HTTP::collect command. If the command in step 5 does not return any output, then the iRule is not associated with a virtual server.

Additional Information

The HTTP::collect iRule command collects an amount of HTTP body data, optionally specified with the length argument. When the system collects the specified amount of data, it calls the Tcl event HTTP_REQUEST_DATA or HTTP_RESPONSE_DATA.
