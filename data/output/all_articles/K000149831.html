K000149831: Device is not rechable and HA is also failing

Type
Support Solution
Published
2025-03-19
Updated
2025-03-19
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.1, 17.1.0, 17.0.X, 17.X.X, 17.1.X, 17.1.2, 16.1.4
Source
https://my.f5.com/manage/s/article/K000149831

Description

After upgrade from version 16.1.4 to the 17.1.0 the device went unoperative . The GUI display the banner that configuration didn't load. The "tmsh load sys config verify" command display similar error to example below:

Syntax Error:(/config/bigip_base.conf at line: 415) "rules", "all" may not be used to add new items to the set, please provide specific items

Environment

  • BIG-IP
  • Upgrade

Cause

Unknown

Recommended Actions

  1. Delete the security firewall Management-ip-rules that is mentioned in the error and then re-create it again after second step
  2.  After that please load config again with the below command:

tmsh load sys config

 

Additional Information

None
