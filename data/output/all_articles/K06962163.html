Topic

You should consider using this procedure under the following condition:

  • You want to reset a lost or forgotten Admin password.

Description

The NGINX Controller Admin account is created with a user-selected email address during the installation process. By design, the password recovery procedure for the Admin account on an NGINX Controller system relies on the Simple Mail Transfer Protocol (SMTP) settings on the system, and a functional email service in the environment so that the password recovery message is delivered to the Admin account email. Alternatively, if the email service is not working or the SMTP settings on the NGINX Controller system are not properly configured, you can retrieve the password reset code (generated during the password recovery procedure) by manually sending a SQL query to the Postgres database used by the NGINX Controller system. 

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have functional SMTP settings on the NGINX Controller host.

Procedures

  • Resetting the Admin account password using the NGINX Controller mail service

Resetting the Admin account password using the NGINX Controller mail service

You can reset the Admin account password from the NGINX Controller web interface login page if the SMTP server is configured during the NGINX Controller installation. To do so, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to the NGINX Controller login page.
  2. Select the Forgot password link on the page.
  3. For Email, enter the Admin account email.
  4. Select Reset.
  5. Select Ok.
  6. Go to the Admin email inbox, and check for the password reset request email from NGINX Controller.

    Note: A message will be sent to the Admin email address containing a link to reset your password. If you do not receive your email within a few minutes, check your spam folder.

  7. To open the NGINX Controller password reset page, select the password reset link in the email.
  8. For New password, enter and confirm the password you want.
  9. Select Save.
