Issue

Error Message

Your session could not be established. Invalid Nonce

Message Location

You may encounter this message in the following location:

  • The BIG-IP APM login page, after your login attempt fails.

Description

This message occurs when the following condition is met:

  • A client logging in to a BIG-IP APM resource provides an invalid value (cryptographic nonce) when attempting to establish the session.

Note: A cryptographic nonce (number used once) is a random or pseudo-random number that is used in authentication protocols, such as HTTP digest authentication. Generated nonce values should be sufficiently random to ensure they are not repeated in order to prevent replay attacks and session hijacking.  The Invalid Nonce message indicates that a cryptographic value that the client provided to the BIG-IP APM system is not valid.

Impact

The client login attempt fails. 

Recommended Actions

When encountering this message, consider the following:

  • This message is normally only displayed when you use the On-Demand Cert Auth agent in the access policy and the nonce value provided by the client does not match the value used by the BIG-IP APM system when collecting the client certificate during SSL handshake renegotiation.
  • Due to a regression in the fix for Bug ID 488588, this message can be generated due to an invalid session ID. This can occur in a number of different circumstances related to session ID rotation.  For example, if access policy evaluation fails for some reason and the BIG-IP APM system resets the client connection, the client may attempt to resend the previous request. If the BIG-IP APM system has already rotated the session ID (a security defense against session hijacking), the system considers stale the session ID sent by the client and generates the message. Subsequent login attempts should not be affected.
  • Due to Bug ID 760550, you may see this message when retransmissions occur on the network, On-Demand certificate authorization is processing a client certificate, and the BIG-IP system and the client exchange nonce. F5 recommends running a BIG-IP release which has the fix for bug ID 760550.
  • If the wording of the message is unclear or confusing, you can customize the message to something more appropriate for your environment.  For more information about customizing BIG-IP APM access policy error messages, refer to K21310423: Customizing BIG-IP APM access policy error messages.
