K95352448: ''Client SSL profiles <profile> have been removed after upgrade'' error in AGC after upgrade to 16.x

Source

Description

After upgrading BIG-IP to 16.x, the "Client SSL profiles <profile> have been removed after upgrade" error message appears under the Virtual section in AGC (Access Guided Configuration).

insert screenshot showing error here: https://imagebin.es.f5net.com/uploads/8ULfiI.jpeg

Environment

  • BIG-IP APM
  • Access Guided Configuration (AGC)
  • Client-SSL profile

Cause
Adding support to create multiple SSL profiles for IAP (Identity-Aware Proxy) use-case under AGC triggers this message.
As per that change/design, only SSL profiles that have "default for SNI" enabled are shown in the AGC virtual server step and has a value other than "none" under servername are shown in the AGC Application step.
 

Recommended Actions

There are two changes needed in the Client SSL profile on the TMUI page to show the desired Client SSL in Virtual Server and Application AGC page dropdown.
You need to make changes to the client-ssl profile in question before/after the upgrade. That should take care of this message.

  1. To show the client SSL profile in the virtual server step of AGC page dropdown, we have to check the "Default for SNI" checkbox
  2. To show the client SSL profile in the application step of AGC page dropdown, "Default for SNI" should be unchecked and the servername should not be empty/none.
