Known Issue

Upgrades may fail when the BIG-IP ASM module is not provisioned.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is licensed and provisioned with the BIG-IP ASM module.
  • You create and assign an application security policy to a virtual server.
  • You deprovision the BIG-IP ASM module.
  • You upgrade to BIG-IP 12.1.0 or later.

Impact

The configuration fails to load after upgrading.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When loading the configuration after upgrading, you observe log messages similar to the following example in the /var/log/ltm file:

    err mcpd[6634]: 01071ab3:3: ASM must be provisioned when a Virtual Server is using a websecurity (/<partition>/<application security policy name>) profile.
    err tmsh[10559]: 01420006:3: Loading configuration process failed.
    emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all " - failed. -- 01071ab3:3: ASM must be provisioned when a Virtual Server is using a websecurity (/<partition>/<application security policy name>) profile. Unexpected Error: Loading configuration process failed.
    err mcpd[6634]: 01070425:3: Full configuration load failed.

Workaround

To work around this issue, you can, prior to upgrading, provision the BIG-IP ASM module or modify virtual servers assigned with security policies removing the security policy assignments. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  3. Click on the name of the virtual server configured with the application security policy.
  4. Hover on the Security tab and click Policies.
  5. Set Application Security Policy to Disabled.
  6. Click Update.
  7. Repeat steps 3 - 5 for each virtual server that is configured with an application security policy.

Note: Once you complete this process, you can proceed with upgrading the system.
