Topic

F5 distributes new versions of the End-User Diagnostics (EUD) as hotfixes. Each product has its own EUD hotfixes. The FirePass-specific hotfixes for the current version of EUD software are available from the F5 Downloads site. For each supported version of FirePass software, an EUD hotfix is typically available for each supported hardware platform that supports EUD. The FirePass EUD software is identical to the EUD software for other F5 products running on the same hardware platform, but it is bundled differently due to different hotfix installation mechanisms.

Important: When downloading an EUD hotfix from the F5 Downloads site, ensure that you have chosen the hotfix that is specific to your FirePass hardware platform and software version.

Note: For more information for running the EUD, refer to K6620: Overview of End-User Diagnostics for the FirePass 1200 platform or K6504: Overview of End-User Diagnostics for the FirePass 4100 and 4300 platforms.

To view the version of EUD software installed on a FirePass controller, run the EUD. The version number displays above the EUD menu. For example:

Product:       HSIBJ Family End User Diagnostics
Build:         build 10.0.9.11.0
Build date:    Mon Mar 24 10:04:05 PDT 2008

Additionally, if you updated the EUD software through an EUD hotfix, you can view the version of EUD software on the Device Management: Current Settings page in the FirePass Administrative Console. Locate and select the hotfix number to view the hotfix details, and the EUD version will display next to Summary.

Note: If you upgraded to a later version of FirePass software after installing the EUD hotfix, the hotfix will no longer display on the Device Management: Current Settings page. In this case, you must run the EUD to view the EUD version.

Important: EUD hotfixes support specific FirePass software and hardware platforms. For example, Hotfix-88708 supports FirePass 4100 and 4300 platforms running version 6.0.2 of FirePass software. Hotfix-88708 does not support the FirePass 1200 platform, nor does it support a 4100 or 4300 platform running an earlier version of FirePass software.

For instructions about downloading a hotfix, refer to K167: Downloading software from F5.

For instructions about installing the EUD hotfix, refer to K3430: Installing FirePass hotfixes.

Note: The EUD hotfix is approximately 30 megabytes.
