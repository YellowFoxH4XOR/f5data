Description

A Server SSL profile configured for session mirroring shows 0 sessions under SSL Mirroring. '

You can view profile statistics using the show ltm profile server-ssl command.

Environment

  • BIG-IP
  • Server SSL profile with the following settings:
    • Session Mirroring: enabled
    • Cache Size: 0

Cause

SSL session mirroring mirrors the SSL session cache, allowing cached sessions to be reused after a failover. If the system is configured with a cache size of 0, it does not cache sessions and cannot mirror them.

Recommended Actions

If you require SSL session mirroring: 

  1. Change the cache size setting to a value greater than 0.

Additional Information

SSL session mirroring is not the same as SSL connection mirroring, and these features are not compatible. SSL connection mirroring does not affect the SSL profile mirroring statistics.
