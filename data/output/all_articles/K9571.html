Topic

BIG-IP ASM does not currently offer a feature to automatically synchronize security policies between multiple standalone BIG-IP ASM systems.

To configure multiple standalone BIG-IP ASM systems with identical security policies, you must manually export the policies from the remote BIG-IP ASM system using the policy export feature, and then import the policies to the target BIG-IP ASM systems using the policy import feature.

Note: For information about exporting and importing a security policy, refer to the BIG-IP ASM Configuration Guide.

F5 Product Development is tracking a feature enhancement request as CR114702 to add multi-site BIG-IP ASM policy synchronization.
