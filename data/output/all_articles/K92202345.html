Description

The ASM module does not send SNMP traps to communicate a blocked request and request violation

Environment

  • ASM
  • SNMP configured
  • BIG-IP software version 11.6.0 and above

Cause

Seen behaviour is expected. By default, the BIG-IP ASM system does not log security events locally. As a result, there are no security events for SNMP to trap and the system does not send emails.

Starting in BIG-IP ASM 11.6.0, the system does not write security events to syslog by default and it does not log them locally to the /var/log/asm file.This behavior is introduced as part of several enhancements to improve system performance and stability.

Recommended Actions

If you want to collect a log of security events, you should configure remote logging on the BIG-IP ASM system and send those events to a remote log server. If you want to receive emails when BIG-IP ASM security events occur, you should configure the remote log server to trap on those events and generate emails.
