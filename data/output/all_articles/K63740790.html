K63740790: The Management GUI is not accessible or pages in the GUI do not load properly

Type
Support Solution
Published
2022-08-11
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K63740790

Description

The GUI (Management Interface) is inaccessible or pages do not load properly.

You may experience any one of the following issues:

  • Attempt to access the GUI and see the message "This page cannot be displayed" yet traffic is flowing without issues
  • Able to log into the GUI but a configuration page does not load properly
  • Able to log into the cli and traffic is flowing as expected, only GUI is inaccessible

Environment

Must have admin and root access to the F5

  • GUI
  • SSH
  • BIG-IP

Cause

Web server daemons need to be restarted 

Recommended Actions

Restart the daemons related to the web utility

The tomcat daemon provides web server functions for the BIG-IP web utility
The http daemon performs HTTP web server functions

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Logged into cli of the F5 using ssh as root user, run the following commands in bash:

# bigstart restart httpd tomcat

or

# tmsh restart /sys service httpd tomcat
