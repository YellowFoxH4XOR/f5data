Known Issue

F5 Access for iOS does not render the SAML IdP logon page correctly. The logon window extends beyond the screen and part of it is not visible.

This issue occurs when all of the following conditions are met:

  • You are using the following F5 Access versions on iOS 15.1.
    • F5 Access 3.0.9
    • F5 Access 3.0.10
  • You configured BIG-IP APM as a SAML service provider (SP) with an external identity provider (IdP).

Impact

This is a cosmetic issue. You can continue to log in.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to log in with F5 Access you get redirected to the external IdP logon page. You do not see the entire logon page.

Workaround

This issue happens only in landscape (horizontal) mode. To work around this issue, you can switch to portrait (vertical) mode.
