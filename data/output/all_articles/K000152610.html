K000152610: libvirtd core found but tenants are running fine

Type
Support Solution
Published
2025-07-16
Updated
2025-07-16
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.5.X, 1.8.0, 1.5.3, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000152610

Description

libvirtd core and crc files were found under /var/shared/core/container/

  • Tenants are running fine
  • One or more libvirtd core file along with crc is found.
  • Example: core..libvirtd.12345.1788386650.core.gz core..libvirtd.12345.1788386650.core.gz.crc

Environment

  • F5OS-A v1.8.0 (or lower)
  • Tenants are configured

Cause

This is due to know bug ID1519005.

Recommended Actions

The crash that generates these core files occur intermittently when the device is rebooting. There should be no impact to the tenants are they would be stopped before the device go down for a reboot. There should be no impact to tenants and no special action is required.

However, if the number of core files keep increasing it may fill up disk space. Delete the core and crc files using commands below.

  1. List the core files:

    # system diagnostics core-files list
  2. Delete core files:
    # system diagnostics core-files delete files [ <core-file> ]

Additional Information

This bug is tentatively scheduled to be fixed in F5OS-A v2.0
