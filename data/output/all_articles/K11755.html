Known Issue

Note: The issue described in this article only affects the BIG-IP 1600, 3600, 3900, 6900, 8900, 8950, and 11050 platforms. Refer to release notes for the supported versions on each platform.

This is the result of a known issue. A link is not established if both the management port of the BIG-IP system and the switch port on the remote end are configured with one of the following fixed media settings:

  • 10baseT full
  • 10baseT half
  • 100baseTX full
  • 100baseTX half

Note: The other available fixed media settings (1000baseT full and 1000baseT half) do not cause the issue described in this article.

Note: By default, the management port of the BIG-IP system is configured to perform auto-negotiation.

Note: You cannot change the configuration of the management port from the Configuration utility. To modify the configuration of the management port, you must use the bigpipe utility from the command line. For more information, type the bigpipe interface help command.

F5 Product Development tracked this issue as ID 327388 and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

If you require the management port of the BIG-IP system to operate at a fixed speed of 10 or 100 Mbps, configure one of the endpoints to use the desired media setting and configure the other endpoint to perform auto-negotiation.
