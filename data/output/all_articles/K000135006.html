K000135006: Comments after the closing bracket in an iRule are deleted after and upgrade

Type
Support Solution
Published
2023-06-13
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000135006

Description

  • After an upgrade, comments are missing from an iRule

  • No error messages are reported, and the iRule continues to function properly.

Environment

  • An iRule is created with comments after the closing bracket in the iRule

  • An upgrade is performed

Cause

This issue is caused by bug ID490139.

Recommended Actions

  1. Do not place comments after the closing bracket of an iRule. 

Additional Information

Example of an iRule with a comment after the closing bracket, prior to upgrade:

# this is a before code comment
when HTTP_REQUEST {
  log local0. "============================================="
}
# this is an after code comment

 

 

After an upgrade, the comment after the closing bracket is no longer present:

 

# this is a before code comment
when HTTP_REQUEST {
  log local0. "============================================="
}
