Description

Provisioning AFM will caused unsaved Zebos configuration edits to be lost

Environment

  • BIG-IP with routing protocols enabled
  • Unsaved configuration changes in zebos.conf
  • Provision AFM

Cause

Provisioning AFM triggers a restart of Zebos related processes (eg; tmrouted)

Recommended Actions

Save Zebos configuration before provisioning AFM via "copy running-config startup-config"

Additional Information

BFD is equally affected.
