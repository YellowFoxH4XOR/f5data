Known Issue

Importing a BIG-IP APM access profile may fail.

This issue occurs when all of the following conditions are met:

  • You have configured the access profile with a Secure Sockets Layer (SSL) certificate file object including any of the following:

    • Online Certificate Status Protocol (OCSP) responder
    • Certificate Authority (CA) profile
    • Server SSL profile
    • Client SSL profile
  • You have exported the access profile.
  • You attempted to import the exported access profile on an alternate BIG-IP APM system.

Impact

Importing the BIG-IP APM access profile fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to import an access policy containing an SSL certificate with the Configuration utility, you view an error message that appears similar to the following example:

    Import Error: 0107134a:3: File object by name (/Common/access-policy-specific-ca-bundle.crt) is missing. Unexpected Error: Validating configuration process failed.

  • When using the ng_import command line tool to import an access policy containing an SSL certificate, you view an error message that appears similar to the following example:

    Import Error: Syntax Error:(at line: 2) "cache-path" unknown property
