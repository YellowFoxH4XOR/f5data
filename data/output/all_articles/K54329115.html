Description
 

After upgrading the BIG-IP, LACP trunks may go down unexpectedly after some time. It may not be immediately after the upgrade.

You will also see the interfaces in a UP state.


On the /var/log/ltm,  you may be able to see the following logs:


warning lacpd[8199]: 01160024:4: warning: no receive on 1.1 for 45s (timeout=90s)
warning lacpd[8199]: 01160024:4: warning: no receive on 1.1 for 45s (timeout=90s)
info lacpd[8199]: 01160016:6: Interface 1.1, link admin status: enabled, link status: up, duplex mode: full, lacp operation state: down
info lacpd[8199]: 01160010:6: Link 1.1 removed from aggregation
info bcm56xxd[16620]: 012c0012:6: delete working member 1.1 of the trunk <trunk name>
warning lacpd[8199]: 01160024:4: warning: no receive on 1.2 for 45s (timeout=90s)
warning lacpd[8199]: 01160024:4: warning: no receive on 1.2 for 45s (timeout=90s)
info lacpd[8199]: 01160011:6: Link 1.1 Actor Out of Sync
info lacpd[8199]: 01160012:6: Link 1.1 Partner Out of Sync


If you take a packet capture you will see the LACP messages arriving in the BIG-IP but the trunk will not come up.

 

Environment
 

  • BIG-IP LTM
  • LACP Trunk
  • HSB FPGA Chipset
 

Cause
 

Unknown, this is a very rare condition.
 

Recommended Actions
 

Reboot the device
reboot

Additional Information

None.
