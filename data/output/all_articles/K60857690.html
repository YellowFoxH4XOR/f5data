Issue

Error Message

Key management library returned bad status: -99

Message Location

You may encounter this message in the following location:

  • The Configuration utility

Description

This message occurs when of the following condition is met:

  • You are logged in to the Configuration utility and attempt to archive the certificate and keys.

Impact

Exporting of SSL certificates and keys into a TGZ archive file fails.

Recommended Actions

To work around this issue, you can restart the httpd service and then create a test certificate. After you perform these procedures, you should be able to successfully archive certificates and keys.

  • Restarting the httpd service
  • Creating a test certificate
  • Performing the certificate archive

Restarting the httpd service

Impact of procedure: Your system may temporarily lose connection to the Configuration utility during this process.

  1. Log in to the BIG-IP command line.
  2. Access the TMOS Shell (tmsh) by typing the following command:

    tmsh

  3. Restart the httpd service by typing the following command:

    restart /sys service httpd

  4. Verify the service is running by typing the following command:

    show /sys service httpd

Creating a test certificate

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Certificate Management > Traffic Certificate Management.
  3. Click Create.
  4. For Issuer, click Self.
  5. Fill out all of the required values.
  6. Click Finished.

Performing the certificate archive

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Certificate Management > Traffic Certificate Management.
  3. Select the check boxes for the certificates you want to archive.
  4. Click Archive.
