Known Issue

In rare and intermittent circumstances, the Traffic Management Microkernel (TMM) process may produce a core file due to a RAM Cache key collision.

This issue occurs when the following condition is met:

  • The RAM Cache feature is enabled.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from the TMM restart, and devices configured as a high-availability pair may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system fails over to the standby system, if configured for high availability (HA).
