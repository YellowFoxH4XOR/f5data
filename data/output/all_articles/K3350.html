Topic

This article applies to BIG-IP 9.x - 10.x. For information about other versions, refer to the following solution:

  • K13121: Changing system maintenance account passwords (11.x - 13.x)

Description

For BIG-IP 9.x and 10.x, you can reset the administrative password from either the Configuration utility or the command line. To do so, perform one of the following procedures:

  • Changing an administrative account password in BIG-IP 10.x:
    • Resetting the administrative password from the command line using tmsh
    • Resetting the administrative password from the Configuration utility
    • Resetting lost or forgotten root password
  • Changing an administrative account password in BIG-IP 9.x:
    • Resetting the administrative password from the command line
    • Resetting the administrative password from the Configuration utility
    • Resetting lost or forgotten root password

Changing an administrative account password in BIG-IP 10.x

Resetting the administrative password from the command line using tmsh

F5 recommends that you use the TMOS Shell (tmsh) to change the administrative password from the command line for BIG-IP 10.x. To do so, perform the following procedure:

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To reset the administrative password for the user, type the following command:

    modify auth user admin prompt-for-password

  3. When prompted, type the new administrative password.
  4. When prompted, retype the new administrative password.
  5. To save the changes to the configuration files, type the following command:

    BIG-IP 10.1.0 and later:

    save sys config

    BIG-IP 10.0.x:

    save config

  6. To exit tmsh, type quit and press Enter.

If you have a redundant pair, repeat these steps on the peer system. Configuration synchronization (ConfigSync) may not work correctly until you have changed the passwords on both units to the same value.

Resetting the administrative password from the Configuration utility

To change the administrative password from the Configuration utility, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to System > Users.
  3. Click the name of the user whose password you want to update.
  4. In the Password section, type the password for the user in the New and Confirm fields.
  5. Click Update.

If you have a redundant pair, repeat the previous steps on the peer system.

Resetting a lost or forgotten root password

To reset a lost or forgotten root (or support) password, perform the following procedure:

Important: Due to a known issue in BIG-IP 10.1.0, you cannot use the passwd utility to change the root password when the system is running in single-user mode. For more information, and an alternative procedure, refer to K11190: The passwd utility fails to update the password for the root user when a connection to the MCP daemon cannot be established.

  1. Boot the system into single-user mode.

    Note: For specific instructions, refer to K4178: Restarting the BIG-IP system in single-user mode (GRUB 0.97).

  2. Type the following commands:

    mount -a

    passwd <account>

    For example:

    passwd root

  3. When prompted, enter a new password.
  4. To return to the normal operating mode, type exit or reboot.

After the system reboots, you should be able to log in using the new password.

Changing an administrative account password in BIG-IP 9.x

Resetting the administrative password from the command line

To change the administrative password from the command line, perform the following procedure:

  1. Log in to the command line.
  2. To reset the administrative password, type the following command:

    f5passwd admin

  3. When prompted, type the new administrative password.
  4. When prompted, retype the new administrative password.

    The BIG-IP system displays a message that appears similar to the following example:

    Changing password for user admin.
    passwd: all authentication tokens updated successfully.
    The ConfigSync user's password has changed. You should change the password
    on the peer system as well.

If you have a redundant pair, repeat the previous steps on the peer system. ConfigSync will not work correctly until you have changed the passwords on both units to the same value.

Resetting the administrative password using the Configuration utility

To change the administrative password using the Configuration utility, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to System > Users.
  3. Click the admin user to edit its properties.
  4. Change the password in both Password fields.
  5. To save changes, click Update.

    Note: If configuring a redundant pair, click OK in the dialog box that warns you that the change must be made on both units.

If you have a redundant pair, repeat the previous steps on the peer system. ConfigSync will not work correctly until you have changed the passwords on both units to the same value.

Resetting a lost or forgotten root password

To reset a lost or forgotten root (or support) password, perform the following procedure:

  1. Boot the system into single-user mode.

    Note: For specific instructions, refer to K4178: Restarting the BIG-IP system in single-user mode (GRUB 0.97).

  2. Type the following commands:

    mount -a

    passwd <account>

    For example:

    passwd root

  3. When prompted, enter a new password.
  4. To return to the normal operating mode, type exit or reboot.

After the system reboots, you should be able to log in using the new password.
