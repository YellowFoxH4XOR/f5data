Topic

When troubleshooting ARX environments, including EMC NAS storage devices, F5 Technical Support may request support information from an EMC NAS storage device. The support information can often be collected using the collect_support_materials.sh script, which is available on some EMC NAS storage devices. The collect_support_materials.sh script collects system data from the Control Station and creates a gzipped tar single-file archive of that data.

Note: The collect_support_materials.sh script is normally located in the /nas/tools directory, and requires the user to be logged in with nasadmin or root user privileges. 

Note: For more information about the collect_support_materials.sh script, refer to the product documentation for your specific EMC device and software version.

Note: For information about sending files to F5 Technical Support, refer to K2486: Providing files to F5 Technical Support.
