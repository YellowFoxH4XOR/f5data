Topic

On January 31, 2012, Mozilla launched the release of Firefox 10. F5 has verified that the following F5 products support the Firefox 10 browser:

  • BIG-IP Edge Gateway 11.1.0 with HF2
  • BIG-IP APM 11.1.0 with HF2
  • BIG-IP Edge Gateway 10.2.4
  • BIG-IP APM 10.2.4
  • BIG-IP Edge Gateway 10.2.3 with HF1
  • BIG-IP APM 10.2.3 with HF1
  • FirePass 7.0.0 with HF-70-6
  • FirePass 6.1.0 with HF-610-8

The following F5 products are being evaluated and will have support for Firefox 10 at a future date:

  • BIG-IP Edge Gateway 11.0.0
  • BIG-IP APM 11.0.0
  • BIG-IP Edge Gateway 10.2.2
  • BIG-IP APM 10.2.2
  • BIG-IP Edge Gateway 10.2.1
  • BIG-IP APM 10.2.1

F5 Product Development is tracking the following enhancement requests to add Firefox 10 client browser support:

  • FirePass: ID 376727
  • BIG-IP Edge Gateway and BIG-IP APM: ID 376724

There are currently no plans to add Firefox 10 support for versions of BIG-IP or FirePass not listed in this article.
