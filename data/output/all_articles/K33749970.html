Topic

You should consider using this procedure under the following condition:

  • You want to perform basic management tasks for local traffic policies on a BIG-IP system using the TMOS Shell (tmsh).

Description

In BIG-IP 12.1.0 and later, local traffic policies exist in two forms: draft and published. You can only modify draft policies, and you can only apply published policies to a virtual server. To manage traffic, each local traffic policy includes a matching strategy for the specified rules, as well as conditions and actions configured within each rule. This article explains how to perform basic management tasks for local traffic policies using tmsh. For more information about Local Traffic policy feature configuration, refer to K04597703: Overview of the Local Traffic Policies feature (12.1.0) and the BIG-IP Local Traffic Management: Getting Started with Policies manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Note: After you upgrade to BIG-IP 12.1.0 or later, migrated local traffic policies from previous software versions appear in published form.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrator credentials for tmsh.
  • You are familiar with tmsh.
  • You have experience designing and implementing local traffic policies in your network environment.

Creating a new local traffic policy

To create a new local traffic policy, you must first create the policy in draft form and then publish it.

Note: After you publish a local traffic policy, the BIG-IP system removes its draft form version.

Impact of procedure: The impact of the following procedure depends on the changes you apply through the local traffic policy. Always ensure modifications are compatible with your environment. F5 recommends that you test any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Create the draft local traffic policy using the following command syntax:

    create /ltm policy /Common/Drafts/<policy_name> strategy <policy_strategy> rules add { <rule_name> { <rule_definition> } }

    In this syntax:

    • <policy_name> is the name of the policy you are creating.
    • <policy_strategy> can be all-match, best-match, or first-match, depending on your requirements. For more information about each of these strategy options, refer to K04597703: Overview of the Local Traffic Policies feature (12.1.0 and later).
    • <rule_name> is the name of the rule you are creating.
    • <rule_definition> typically comprises of the conditions definition and the actions definition depending on your requirements. For more information about these definitions, refer to K04597703: Overview of the Local Traffic Policies feature (12.1.0 and later).

    For example, to create a local traffic policy named policy1 and a rule named rule1 with a description configured using the first-match strategy, enter the following command:

    create /ltm policy /Common/Drafts/policy1 strategy first-match rules add { rule1 { description "rule1_description" } }

    For another example, to create a local traffic policy named RestrictHostPathExample that restricts HTTP traffic to only requests with URL path starting with /api/ and the host name is askf5.com, enter the following command:

    create /ltm policy /Common/Drafts/RestrictHostPathExample rules add { host { conditions add { 0 { http-host host not values { askf5.com } request } } actions add { 0 { shutdown connection request } } } path { conditions add { 0 { http-uri path not starts-with values { /api/ } request } } actions add { 0 { shutdown connection request } } } } requires add {http } strategy first-match

    Note: Due to the possible complex combinations of rules for different environments, you may want to refer to  K04597703: Overview of the Local Traffic Policies feature (12.1.0 and later) for guidance on drafting rules specific to your requirements and environment. For more examples of different use cases, refer to the articles listed in Supplemental Information section of this article.

  3. Publish the local traffic policy using the following command syntax:

    publish /ltm policy /Common/Drafts/<policy_name>

    For example, to publish a local traffic policy named policy1, enter the following command:

    publish /ltm policy /Common/Drafts/policy1

  4. Save the configuration by entering the following command:

    save /sys config

Displaying published local traffic policies

You can display all published local traffic policies on the BIG-IP system.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. List all published local traffic policies on the BIG-IP system by entering the following command:

    list /ltm policy

  3. Optional: To list a specific published local traffic policy, use the following command syntax:

    list /ltm policy <policy_name>

    For example, to list a published local traffic policy named policy1, enter the following command:

    list /ltm policy policy1

    If a match is found, the command output appears similar to the following example:

    ltm policy policy1 {
        last-modified 2016-10-16:23:44:06
        rules {
            rule1 {
                description rule1_description
            }
        }
        status published
        strategy first-match
    }

Displaying draft local traffic policies

Draft versions of local traffic policies reside in the /Common/Drafts folder on the BIG-IP system. You can list all of the draft local traffic policies.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To list all draft local traffic policies on the BIG-IP system, enter the following command:

    list /ltm policy /Common/Drafts/*

  3. Optional: To list a specific draft local traffic policy, use the following command syntax:

    list /ltm policy /Common/Drafts/<policy_name>

    For example, to list a draft local traffic policy named policy1, enter the following command:

    list /ltm policy /Common/Drafts/policy1

    If a match is found, the command output appears similar to the following example:

    ltm policy Drafts/policy1 {
        last-modified 2016-10-16:23:38:29
        published-copy policy1
        rules {
            rule1 {
                description rule1_description
            }
        }
        status draft
        strategy first-match
    }

Modifying a published local traffic policy

You can only modify a local traffic policy in its draft form. If you want to make changes to a published local traffic policy, you must first create a draft copy of the published policy. Changes you make to the local traffic policy copy take effect only after you publish it.

Note: If you attempt to modify a published local traffic policy without creating a draft copy, the system stops the modification and responds with an error message similar to the following: 01071abb:3: Cannot create/modify published policy '/Common/<name of the published policy>' directly, try specifying a draft folder like '/Common/Drafts/<name of the published policy>'.

Impact of procedure: The impact of the following procedure depends on the changes you apply through the local traffic policy. Always ensure modifications are compatible with your environment. F5 recommends that you test any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Create a draft copy of the local traffic policy by using the following command syntax:

    modify /ltm policy <policy_name> create-draft

    For example, to modify a published local traffic policy named policy1, enter the following command:

    modify /ltm policy policy1 create-draft

  3. Modify the draft local traffic policy by using the following command syntax:

    modify /ltm policy /Common/Drafts/<policy_name> rules <rule_operation> { <rule_name> { <rule_definition> }

    For example, to modify the rule description of rule1 in the local traffic policy named policy1, enter the following command:

    modify /ltm policy /Common/Drafts/policy1 rules modify { rule1 { description "modify_rule1_description" } }

  4. Save the configuration by entering the following command:

    save /sys config

Publishing a local traffic policy

After you make changes to a draft local traffic policy, you must publish the policy before your changes take effect. If you are creating a new local traffic policy, you cannot assign it to a virtual server until you publish it.

Note: After you publish a local traffic policy, the BIG-IP system removes its draft form version.

Impact of procedure: The impact of the following procedure depends on the changes you apply through the local traffic policy. Always ensure modifications are compatible with your environment. F5 recommends that you test any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To publish a draft local traffic policy, use the following command syntax:

    publish /ltm policy /Common/Drafts/<policy_name>

    For example, to publish a local traffic policy named policy1, enter the following command:

    publish /ltm policy /Common/Drafts/policy1

  3. Save the configuration by entering the following command:

    save /sys config

Copying a local traffic policy

To create a draft local traffic policy with the same settings as an existing local traffic policy, you can copy the original policy in its draft or published form. Once you copy the local traffic policy, you can modify it, publish it, and associate it with a virtual server.

Note: After you publish a local traffic policy, the BIG-IP system removes its draft form version.

Impact of procedure: The impact of the following procedure depends on the changes you apply through the local traffic policy. Always ensure modifications are compatible with your environment. F5 recommends that you test any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To copy a local traffic policy from an existing local traffic policy, use the following command syntax:

    create /ltm policy /Common/Drafts/<policy_name> copy-from <original_policy>

    For example, to copy a local traffic policy named policy2 from an existing published local traffic policy named policy1, enter the following command:

    create /ltm policy /Common/Drafts/policy2 copy-from policy1

  3. To publish the new copy of the local traffic policy, use the following command syntax:

    publish /ltm policy /Common/Drafts/<policy_name>

    For example, to publish a copied local traffic policy named policy2, enter the following command:

    publish /ltm policy /Common/Drafts/policy2

  4. Save the configuration by entering the following command:

    save /sys config

Deleting a local traffic policy

You can delete a draft or published version of a local traffic policy when it becomes obsolete or you no longer use it. Before you can delete a published local traffic policy, you first need to dissociate it from its virtual server.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Delete the local traffic policy by using the following command syntax:

    delete /ltm policy /Common/Drafts/<policy>

    For example, to delete a draft local traffic policy named policy2, enter the following command:

    delete /ltm policy /Common/Drafts/policy2

  3. Save the configuration by entering the following command:

    save /sys config
