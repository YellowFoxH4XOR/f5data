Description
Cloud Failover Extension (CFE) requires outbound connectivity to Amazon Web Services (AWS) S3 endpoints for functionality.  If failover is not working and the logging indicates a connection refused towards an AWS S3 endpoint, routing will need to be adjusted.

Environment

  • Amazon Web Services (AWS)
  • BIG-IP Virtual Edition
  • Cloud Failover Extension

Cause
The Cloud Failover Extension needs access to Amazon's Public APIs.

Recommended Actions

  1. Verify the issue is logged /var/log/restnoded/restnoded.x.log:
    Thu, 08 Oct 2020 16:36:38 GMT - severe: [f5-cloud-failover] Failover initialization failed: connect ECONNREFUSED 52.219.104.133:443 Error: connect ECONNREFUSED 52.219.104.138:443 at Object._errnoException (util.js:1022:11) at _exceptionWithHostPort (util.js:1044:20) at TCPConnectWrap.afterConnect [as oncomplete] (net.js:1198:14)
     
  2. Is the IP refused an AWS IP? 
    Utilize a resource such as mxtoolbox.com to verify - 52.219.104.138 is a PTR for s3.us-east-2.amazonaws.com. 
    Note: The important part of the URL is the hostname "s3" portion of the URL.
     
  3. Add a route to the Amazon Virtual Private Cloud (VPC) for Internet Access, allowing port 443 via a TMM (non-management) interface. 
    Note: For specific directions on this, please refer to AWS current documentation.

Additional Information
If Internet Access via the VPC is not desirable, you may create a VPC endpoint.  For further information on this refer to:
Using VPC Endpoints with Cloud Failover Extension
