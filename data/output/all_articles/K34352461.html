Issue

Error Message

010c0018:5: Standby

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions are met:

  • You have multiple BIG-IP systems in a high availability (HA) configuration.
  • An Active BIG-IP system has transitioned to Standby for one of the following reasons:
    • A user has manually performed a BIG-IP system failover. 
    • The BIG-IP system has performed a failover based on a daemon heartbeat failure or a vlan failsafe event.

Impact

Stateful connections may be dropped if connection mirroring is not enabled.

Recommended Actions

Review the following articles to minimize the impact of a failover event:

  • K16049: Limiting network failover disruptions
  • K13478: Overview of connection and persistence mirroring (11.x - 12.x)
  • K13502: Configuring MAC masquerade (11.x - 14.x)
