Description

gtmd and pfmand cored after upgrading BIG-IP to version 15.1.6

  • LTM logs show constant restart of gtmd with multiple messages similar to below:
         notice mcpd[7667]: 01070404:5: Add a new Publication for publisherID GTM_Publisher and filterType 0
    info gtmd[32654]: 0114002b:6: HA daemon_heartbeat gtmd enabled.
  • Diagnostics in iHealth qkview show heuristic H448762 device cores for gtmd and pfmand. You will see one or more core files in /var/core directory
  • cli command "show sys service gtmd" will show output of restarts similar to below:
            gtmd run (pid 32292) 4 seconds, 1 start, 2482 restarts [DUMPING CORE]

Environment

BIG-IP with DNS provisioned and configured

  • After upgrading device to v15.1.6

Bug ID 1137485

 Open support case and request EHF to address both BugIDs 957637 and 1137485
