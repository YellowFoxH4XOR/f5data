Issue

Error Message

error mcpd[<PID>]: 010718e3:3: Certificate (</PATH/Certificate>) has enabled OCSP at cert-validation-option but is not associated with any OCSP cert-validator.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • </PATH/Certificate> is the path and the name of the certificate being reported.

For example:

error mcpd[<12345>]: 010718e3:3: Certificate (/Common/MyCert.crt) has enabled OCSP at cert-validation-option but is not associated with any OCSP cert-validator.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • TMOS Shell (tmsh) 
  • iControl
  • Configuration utility

Description

This message occurs when the following condition is met:

  • You try to enable Online Certificate Status Protocol (OCSP) monitoring for a certificate that has no OCSP validator assigned.

Impact

None

Recommended Actions

You can assign an OCSP validator to the certificate first and then enable the OCSP monitoring for the certificate. For more information about how to configure OCSP protocol, refer to K75106155: Configuring OCSP stapling (13.x - 15.x).
