Description

You upgraded your BIG-IP to a newer version and noticed an additional prompt that the browser sends when connecting to the VPN, that says

"This site is trying to open F5 Networks Endpoint Inspector". This prompt may look similar to the following:

Environment

Recently upgraded BIG-IP

Windows client machine

VPN

Cause

In some of the recent updates to the BIG-IP, a custom protocol behavior for endpoint checks (f5-epi://) was introduced as a security measure. This behavior impacts how web browsers run BIG-IP components that perform endpoint checks. When users attempt to access VPN via the browser and endpoint check runs, they will notice an additional confirmation prompt from their web browsers.

Recommended Actions

None - this behavior is not enforced by the BIG-IP, and is rather a security measure built into browsers. There is no setting on the BIG-IP that would prevent this from happening when running a custom protocol.
