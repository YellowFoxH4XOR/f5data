Description

During Windows logon, the BIG-IP Edge Client has an options to enable Network Logon using the Dialup Entry/WIndows Logon Integration. Certain versions of Microsoft Surface machines are known to not offer this option.

Environment

  • BIG-IP APM
  • F5 Edge Client
  • Microsoft Surface Machines

Cause

This is due to Windows not supporting Network Logon on certain version of Windows on Surface Machines

Recommended Actions

Below is a list of versions of Windows that the network logon option where Network Logon has been a known issue to not appears

ModelBuildVerion
Microsoft Surface170917763.74
Microsoft Surface180317134.113
Microsoft Surface180916299.1508
Note: This is not a complete list and may affect additional models and versions.
