Topic

In BIG-IP versions 9.0.0 through 9.4.1, basic snmpd configuration is provided using the Configuration utility, and any custom snmpd configuration must be done by manually editing the /config/snmp/snmpd.conf file. For example, snmpd settings that are not configurable using the Configuration utility must be configured by using a text editor and manually editing the /config/snmp/snmpd.conf file. Then, in order for the new SNMP configuration to be loaded into system memory, you must run the bigstart restart snmpd command.

Starting in BIG-IP versions 9.4.2, basic snmpd configuration is provided using the Configuration utility, and custom snmpd configuration must be performed using the bigpipe snmpd command. When you define snmpd configuration using the bigpipe snmpd command, the snmpd configuration is stored in the /var/run/config/snmpd.conf file and  /config/bigip_sys.conf file. Refer to the BIG-IP Command Line Interface Guide, or the snmpd man page for a list of configurable snmpd settings.

Important: F5 recommends that users of the Configuration utility exit the utility before using the bigpipe snmpd command to make changes to the system. Using the bigpipe snmpd command to make changes to the system causes a restart of the snmpd daemon. Likewise, restarting the snmpd daemon creates the necessity for a restart of the Configuration utility.

Examples of bigpipe snmpd commands

  • To list the current snmpd configuration, type the following command:

    bigpipe snmpd list all
  • To list the system contact for the snmpd agent, type the following command:

    bigpipe snmpd syscontact show
  • To set the system contact for the snmpd agent, type the following command:

    bigpipe snmpd syscontact <email_address>
  • To add a range of SNMP clients to the /etc/hosts.allow file, where <IP_network_range>/<netmask> is the IP network range and netmask of the client systems you want to allow access to the BIG-IP snmp daemon, type the following command:

    bigpipe snmpd allow <IP_network_range>/<netmask>
  • To display the snmpd help page, type the following command:

    bigpipe snmpd help
