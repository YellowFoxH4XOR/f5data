Description

You find an error messages similar to the following logged to /var/log/apm:

notice tmm[12345]: 01490501:5: <session id>: Session deleted due to user logout request.
notice tmm[12345]: 01490567:5: <Access Policy Name>:Common:<session id>: Session deleted (user_initiated; code - 1)
err tmm1[12345]: 0149059c:3: (null):(null):<session id>: Snapshot not found
 

Environment

  • BIG-IP APM.

Cause
Expected behavior.
The message shows that the session <session id> was deleted with the user logout while the tunnel establishment was in progress. When the session is deleted, the BIG-IP removes the snapshot reference. 

Recommended Actions

None.
