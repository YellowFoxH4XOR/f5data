K42303533: The maximum number of interfaces in a trunk increased to 32 or 64 for BIG-IP platforms

Type
Knowledge
Published
2017-05-10
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.X.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.0.1, 13.0.0, 13.1.0
Source
https://my.f5.com/manage/s/article/K42303533

Issue

Note: For the VIPRION platforms, the maximum limit applies to the entire chassis, regardless of the number of blades installed.

Old Behavior

In versions prior to BIG-IP 13.0.0, the maximum number of interfaces in a trunk is limited to either 8 or 16, depending on your specific platform.

New Behavior

Beginning in BIG-IP 13.0.0, the maximum number of interfaces in a trunk has increased to either 32 or 64, depending on your specific platform.

Note: The following BIG-IP platforms can use the increased maximum members per trunk limit:

  • BIG-IP 10000 series appliance
  • VIPRION 4450N blade (A114)
  • VIPRION 4300 Blade (A108)
  • VIPRION 2250 Blade (A112)

F5 Product Development tracked this change as ID 597309.

Impact

The maximum number of interfaces per trunk has increased to 32 or 64. You can aggregate up to 32 or 64 interfaces per trunk depending on your specific platform.

Note: This change does not affect any currently configured trunks on BIG-IP platforms.

Recommended Actions

You can determine the maximum number of interfaces that you can configure for a trunk on your specific BIG-IP version and BIG-IP platform, by typing the following command on the BIG-IP command line:

guishell -c "select MAX_MBRS_PER_TRUNK from platform"

The output of the command may appear similar to the following examples:

  • The following output on a BIG-IP 10200 system running BIG-IP 13.0.0 indicates that up to a maximum of 32 interfaces are supported in a trunk:

    ----------------------
    | MAX_MBRS_PER_TRUNK |
    ----------------------
    |                 32 |
    ----------------------
    1 row 0.061s (mcpd: 0.002s, mcpj: 0.002s, hsql: 0.049s, conn: 0.002s, format: 0.004s)
                  (rcv: 0Kb, 0.001s, snd: 38b, 0.001s)

  • The following output on a BIG-IP 10200 system running BIG-IP 11.6.0 indicates that up to a maximum of 16 interfaces are supported in a trunk:

    ----------------------
    | MAX_MBRS_PER_TRUNK |
    ----------------------
    |                 16 |
    ----------------------
    1 row 0.063s (mcpd: 0.001s, mcpj: 0.004s, hsql: 0.052s, conn: 0.002s, format: 0.003s)
                  (rcv: 0Kb, 0.001s, snd: 38b, 0.000s)
