K25642034: Saving BIG-IQ config through REST API

Type
Support Solution
Published
2021-10-07
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K25642034

Description
You are trying to send a POST or Curl request to /mgmt/tm/sys/config location to save config on BIG-IQ

Environment

  • BIG-IQ
  • Rest Framework
  • Curl command
  • HTTP request 
  • Command line access

Cause
Webd does not allow request to /mgmt/tm/sys/config location

Recommended Actions

  1. It is by design to not allow request to REST Framework on /mgmt/tm/sys/config location.
  2. It is allowed from localhost, you can run below command in BIG-IQ command line:
    # restcurl -u admin:admin /mgmt/tm/sys/config -d '{"command":"save"}'
