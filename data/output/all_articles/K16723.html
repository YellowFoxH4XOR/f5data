Known Issue

BIG-IP high availability (HA) systems may experience an unexpected active-active state after an upgrade or system restart.

When you restart or boot to an upgraded boot location, the sod process may experience a rare race condition during the initialization process that occurs during startup.

Note: The sod process manages the BIG-IP system's active or standby states, and also provides failover and restart capability.

Impact

An undesired active-active condition may cause an interruption to production traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H526228 on the Diagnostics > Identified > High screen.
  • You observe that multiple HA devices become active and attempt to process traffic.

    In this example, when you run the following Traffic Management Shell (tmsh) command on the active system (bigip5-askf5.com-HA), the system displays an incorrect status for the standby device (bigip4-askf5.com) if the standby device is upgraded from 11.4.1 to 11.5.2 and rebooted to the 11.5.2 partition:

    # show cm traffic-group

    Warning: SOD Configuration CRC values disagree amongst the devices. Changes must be synced.
    --------------------------------------------------------------------------------
    CM::Traffic-Group
    Name Device Status Next
    Active
    --------------------------------------------------------------------------------
    traffic-group-1 bigip4-askf5.com active false
    traffic-group-1 bigip5-askf5.com-HA active false
    traffic-group-local-only - - -

  • You observe that the peer device appears as offline on the standby device, while the device is actually in an active state.

    In this example, when you run the following tmsh command on the standby system (bigip4-askf5.com), the system displays an incorrect status for the active device (bigip5-askf5.com-HA) if the standby device is upgraded from 11.4.1 to 11.5.2 and rebooted to the 11.5.2 partition:

    # show cm traffic-group

    ------------------------------------------------------------------------------
    CM::Traffic-Group
    Name Device Status Next
    Active
    ------------------------------------------------------------------------------
    traffic-group-1 bigip4-askf5.com active false
    traffic-group-1 bigip5-askf5.com-HA offline false
    traffic-group-local-only - - -

Workaround

To work around this issue, you can restart the sod process on the affected platform to correct the HA status. To do so, perform the following procedure:

Impact of workaround: Restarting the sod process after an upgrade or reboot clears the condition. The following procedure will disrupt traffic processing and should only be performed during a maintenance window.

  1. Log in to the BIG-IP command line.
  2. To restart the sod process, type one of the following commands:
    • For a BIG-IP appliance:

      bigstart restart sod

    • For a VIPRION blade:

      clsh bigstart restart sod
