Description

The BIG-IP device group members become out of sync and display Changes Pending when one or more BIG-IQ (DCD) Statistics Monitoring options are chosen when a newly added DSC member is added to the BIG-IQ inventory.

Environment

  • Data Collection Device (DCD) 
  • ConfigSync (manual) DSC 

Cause

A ConfigSync Changes Pending state is encountered when the following conditions are met:

  • One of the DSC paired BIG-IP device group members have been added to the BIG-IQ inventory list for the first time.
  • When you select at least one data collection device (DCD) Statistics Monitoring option during the device add process.
  • You did not select or create a DSC group (Cluster Display Name) with the Initiate BIG-IP DSC sync when deploying configuration changes (Recommended) option during the device add process.

The Pending Changes behavior is due to the F5 Analytics iApp being pushed out over to the one BIG-IP DSC member added for BIG-IQ statistics monitoring handling and where the iApp has not been synchronised over to the paired DSC member.

 

Recommended Actions

Select an existing DSC Group Cluster Display Name or create a new DSC group during the device add process with the option of Initiate BIG-IP DSC sync when deploying configuration changes (Recommended). Do so by performing the following steps:

  1. At the top of the screen, click Devices.

  2. On the left, click BIG-IP Devices.

  3. Click Add Device.

  4. Populated the required fields for the BIG-IP device being added.

    Note: For the Cluster Properties section select either Use Existing or Create New. If Create New is selected then ensure to click Initiate BIG-IP DSC sync when deploying configuration changes (Recommended).

  5. Click Add.

Additional Information

 

Initiate BIG-IP DSC sync when deploying configuration changes (Recommended): 

  • Select this option if this device is part of a DSC pair and you want this device to automatically synchronise configuration changes with the other member in the DSC group.

Ignore BIG-IP DSC sync when deploying configuration changes: 

  • Select this option if you want to manually synchronise configurations changes between the two members in the DSC group.
