K3505: The /config partition may not be large enough to contain very large DNS configurations

Known Issue

If you have a large number of zone files, it is possible to run out of inodes. F5 Product Development tracked this issue as CR25575.

Workaround

To work around this issue, you can create symlinks to other partitions that contain more inodes. To do this, perform the following steps:

  1. From the 3-DNS Controller, create a /3dns/namedb directory, by typing the following command:

    mkdir /3dns/namedb

  2. Move all the files from the /config/3dns/namedb/ directory to the new /3dns/namedb directory, by typing the following command:

    mv /config/3dns/namedb/* /3dns/namedb

  3. Remove the empty directory, by typing the following command:

    m -rf /config/3dns/namedb

  4. Link the deleted directory to the new location, by typing the following command:

    ln -s /3dns/namedb /config/3dns/namedb
