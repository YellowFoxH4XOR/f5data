Description

Distributed Cloud allows customers to denylist source IP addresses so that traffic from these source IP addresses is always dropped. This article outlines how to denylist IP addresses for Routed services.

 

Environment

  • Distributed Cloud DDoS
    • Routed
  • DDoS IP Denylist

 

Answer/Recommended Actions

1. In the XC Console, navigate to Routed DDOS > Manage > Denylist Rules

2. This opens the Deny List Rules page on where you can see the list of deny lists.

3. To add a new Denylist, select the +Add Deny List Rule button in the upper left.

4.Enter the Name and prefix, that you wish to denylist.

  • You may specify an expiration period, if required.

How to Format the IPs

An IP address is entered in CIDR notation.  An example of a prefix would be:

198.51.100.0/24 - this would block any address in the range 198.51.100.0 - 198.51.100.255.

Individual hosts can be blocked as well, for example: 198.51.100.100/32 would block traffic from the source 198.51.100.100.

  Be sure to not add Restricted IP Addresses.  

 

5. Click Add Deny List Rule to save.
