Issue

Error Message

010d0017:0: <PSU>: milli-voltage (<voltage>) is too low.

In this error message, note the following:

  • <PSU> is the power supply unit (PSU).
  • <voltage> is the milli-voltage reading.

For example:

010d0017:0: Power supply #1 meas. AC input v: milli-voltage (300) is too low.
 

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
  • The platform LCD panel
Description

This message occurs when one of the following conditions is met:

  • External power to the PSU is lost.
  • Input power readings are out of the recommended range.

Impact

The power supplied to the PSUs is insufficient to power the system. Power redundancy for the BIG-IP system may be compromised.

Recommended Actions

  • Verify the external power supplied to the BIG-IP system is within the acceptable range.
  • If the external power is known to be functioning properly, a PSU may be experiencing a hardware issue.
