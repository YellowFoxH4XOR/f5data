K000157947: Metric Difference on Vmware CE site

Type
Support Solution
Published
2025-11-24
Updated
2025-11-24
Source
https://my.f5.com/manage/s/article/K000157947

Description

For the VMware CE site, the metrics displayed on the XC portal—such as CPU, memory usage, and disk usage—differ from those shown on the VMware portal.

 

Environment

  • F5® Distributed Cloud (SaaS)
  • F5® Distributed Cloud (SaaS) CE site

Cause

This is expected; VMware will consistently report differing values due to various DPDK-related issues on the VMware side.

 

Answer/Recommended Actions

The VMware side will consistently report higher values due to the way resource allocations are handled; therefore, monitoring the values reported by the XC portal provides a more accurate representation.
