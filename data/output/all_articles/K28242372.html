Description

URLs configured in DataGroup are partially recognized and work intermittently.

Environment

  • BIG-IP verion 13.1.3
  • Multiple URIs configured in the DataGroup.
  • Inconsistent traffic flow when using DataGroup for matching URIs in the iRule.

Cause

Strings configured in the DataGroup have uppercase letters.

Recommended Actions

Update the strings in the DataGroup to be all lowercase letters.

Additional Information
None.
