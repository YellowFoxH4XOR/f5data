K000150403: Autocertificate - Load Balancer stuck in provisioning state for chaining the CNAME records.

Source

Description

  • I have multiple auto-generated certificates attached to a load balancer and one of them fails.
  • Does that failure impact the renewal of certificates that were previously validated?

Environment

  • F5® Distributed Cloud (XC) DNS Management

 

Cause

  • Chaining of cname is not supported.

Answer/Recommended Actions

  • You need to directly set the cname to the value we show in the XC console and it cannot be redirected to a different domain.
  • The failed certificate of one domain on Load Balancer (LB) would not impact on another LB.
  • If you have multiple domains we generate one auto certificate for all the domains and during the cert generation we flag the errors with all domains that are having issues.
