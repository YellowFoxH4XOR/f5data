K73534735: UCS does not include APM client software

Type
Support Solution
Published
2021-07-27
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K73534735

Description

UCS does not include APM client software.
APM client version goes back to default even restoring UCS when RMA.

Environment

  • BIG-IP APM is provisioned
  • BIG-IP APM client version is updated from default
  • UCS is restored

Cause

It's expected behavior.

Recommended Actions

Update BIG-IP APM client again after restoring UCS when RMA.

Additional Information

None
