Description

In some scenarios, you may need to Increase the default size of "Maximum Entry Length" under the ASM Event Logging Profile (e.g., from 2K to 10K), and looking forward to see if there is any Impact on either the F5-side or the Remote Log Collector.

Environment

  • ASM / AWAF Module Provisioned
  • Event Logging Profile
  • Remote Logging is configured

Cause

In versions prior to 12.1.0, the "Maximum Entry Length" for remote servers supporting UDP was 1 Kilobyte. In versions 12.1.0 and later, Log Entry Sizes such as 1K, 2K, 10K, and 64K can be selected to send much Data to the Remote Log Collector / SIEM.

Recommended Actions

There is no direct or linear relationship between Increasing the Log Entry Size and the Resource Utilization on either F5-side or SIEM-side. However, that should be normally expected that choosing larger value for "Maximum Entry Length" could lead to higher Resource Utilization on both ASM-side as well as the Remote Log Collector, due to additional processing needed for much data. So, you may need to Monitor both the ASM and the Remote Log Collector server's resources to make sure there is no critical Issue at all time.
