Known Issue

The BIG-IP ASM system Enforcement Readiness filter may display unexpected results in the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You attempt to display the list of parameters (Application Security > Parameters > Parameters list) in the Configuration utility.
  • The Enforcement Readiness filter is applied in basic configuration mode.
  • The list of parameters consists of at least two pages.

Impact

The system does not correctly apply the Enforcement Readiness filter to the list of parameters.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Enforcement Readiness filter is not correctly applied to the list of parameters.
  • The Enforcement Readiness filter is correct only for the first page of the list of parameters.

Workaround

To work around this issue, you can configure the Enforcement Readiness filer in the Advanced filter mode. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Parameters > Parameters List.
  3. Set Current edited policy to the name of the affected security policy.
  4. In Parameters List, click Advanced filter.
  5. In the Enforcement Readiness list, click the relevant filter.
  6. Click Go.
  7. Click Apply Policy to put the changes into effect .
