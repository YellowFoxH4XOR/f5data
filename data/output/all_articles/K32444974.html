K32444974: BIG-IP APM Endpoint Inspection fails with the error Application update failed: PolicyServer pkg not found in server connectivity profile

Type
Support Solution
Published
2020-03-01
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.0
Source
https://my.f5.com/manage/s/article/K32444974

Description

Endpoint Inspection fails for clients.

  • Clients fail client side checks (Endpoint Inspection).
  • You will observe the following error in a client browser:
    Application update failed: PolicyServer pkg not found in server connectivity profile.

Environment

  • BIG-IP Access Policy Manager (APM)
  • BIG-IP Local Traffic Manager (LTM)
  • Endpoint Inspection objects (Antivirus check, Firewall check, Registry check, File check, etc.)
  • Connectivity Profile.
  • Virtual Server

Cause

This issue is occurs because the Virtual Server is missing a Connectivity Profile.

Recommended Actions

Select a Connectivity Profile on the APM Virtual Server:

  1. Login to the Admin GUI.
  2. Navigate to Local Traffic>Virtual Servers>Virtual Server List.
  3. Select the Virtual Server.
  4. Navigate to the Access Policy section.
  5. In the drop-down for Connectivity Profile select the appropriate profile.
  6. Click update.

Additional Information

You can verify the Connectivity Profile by using a Browser and navigating to the APM Virtual Server with the following uri:

https://<fqdn>/pre/config.php?version=2.0

If the Connectivity Profile is selected and functioning you should see Endpoint Inspection settings in an XML Format.
