Known Issue

The SNMP table index may be generated incorrectly, resulting in incomplete data and an error message.

This issue occurs when the following conditions are met:

  • Making an SNMP request (snmpget) and the full OID.
  • The requested object has a name that is greater than 30 characters.

Impact

The snmpget requests may fail for some objects.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system logs an error message that appears similar to the following example:

Unknown Object Identifier (Index out of range: 8000 (ltmPoolMemberNodeName))

Resolution

Workaround

To work around this issue, you can change the object names to 30 characters or less.

Note: This is a safe value determined by F5 development; longer object names may be successful.

Impact of workaround: None
