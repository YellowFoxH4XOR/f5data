Description

When you use the VMWare Horizon client to log in to APM with RADIUS two factor authentication, you may encounter the following error message:

Environment

  • BIG-IP APM 13.1.x and 14.0.x
  • VMWare Horizon client
  • Radius authentication with challenge

Cause

The error is caused by ID 747621.

Recommended Actions

Upgrade to a BIG-IP version that contains the fix. Refer to ID 747621 for fixed versions.

Additional Information

None.
