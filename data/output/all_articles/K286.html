Mounting a CD-ROM

To mount a CD-ROM, perform the following steps:

  1. Place the CD into the CD-ROM drive.
  2. If the /cdrom directory does not already exist, create it by typing the following command:

    mkdir /cdrom

  3. Mount the CD-ROM drive to the /cdrom directory by typing the following command:

    mount_cd9660 /dev/sr0a /cdrom

    Note: For 3-DNS version 4.0, the command is mount_cd9660 /dev/acd0a /cdrom.

  4. Change to the /cdrom directory by typing the following command:

    cd/cdrom

Unmounting a CD-ROM

To unmount the CD-ROM, perform the following steps:

Warning: You must perform step 1 before ejecting the CD from the CD-ROM drive.

  1. Type the following command:

    unmount /cdrom

  2. Eject the CD and remove it from the CD-ROM drive.
