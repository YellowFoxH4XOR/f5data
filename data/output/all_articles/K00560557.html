Description

There are available SNMP OID for SynCookie Protection feature which can be used for monitoring through SNMP. Custom SNMP trap can also be created for SynCookie Protection feature from SynCookie related messages.
 

Environment

A potential Syn Flood attack may be encountered and SynCookie Protection may trigger may be needed to be monitored thru SNMP.

Cause

Certain events such as a Syn Flood attack or Unexpected traffic spike may trigger SynCookie Protection and SNMP may be used to monitor these events.

Recommended Actions

Review the relevant F5 Articles related to SynCookie and SNMP configuration: 

K13322: Overview of BIG-IP MIB files
K13322 lists the available SNMP MIB text files in /usr/share/snmp/ for BIG-IP where specific OIDs are be related to the SynCookie feature.

K14805: Configuring SYN cookie protection (11.4.x - 12.x)

K3727: Configuring custom SNMP traps

K11127: Testing SNMP traps on the BIG-IP system (9.4.x - 15.x)

For example : 

Custom SNMP OID for "Syncookie HW mode activated" message

alert Syncookie_HW_mode_activated "Syncookie HW mode activated(.*)" {
 snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.600"
}

Custom SNMP OID for "Syncookie SW mode activated" message

alert Syncookie_HW_mode_activated "Syncookie SW mode activated(.*)" {
 snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.601"
}

See also K11127: Testing SNMP traps on the BIG-IP system (9.4.x - 15.x)
 

Additional Information


When SynCookie protection is triggered, different version of the SynCookie feature's messages may also be generated. Review relevant BIG-IP SW version SynCookie  feature specific messages and use them as needed should you need custom SNMP OID to monitor the related event.
