Environment

  • BIG-IP
  • TACACS / TACACS+ administrative authentication

Cause

The TACACS+ shared secret contains a '#' symbol. If you configure a Terminal Access Controller Access-Control System Plus (TACACS+) profile for application authentication, and the TACACS+ shared key secret contains a number sign (#), authentication fails without the BIG-IP sending a request to the server.
Note: See K12304 in Related Content for additional information

Recommended Actions

Reconfigure the BIG-IP's TACACS+ shared secret to use a string that doesn't contain a '#' symbol
