K10720: Users may be assigned duplicate Network Access favorites when resource group mapping is enabled both globally and at the master-group level

Known Issue

If a user is assigned a Network Access resource through global dynamic resource group mapping, and the user is assigned the same Network Access resource through dynamic resource group mapping configured within the master group, the Network Access resource will appear twice on the webtop.

Note: This issue only affects Network Access resources. Other types of resources, such as Application Access and Portal Access resources, are not duplicated on the webtop.

Dynamic resource group mapping is configured globally on the Users : Groups : Dynamic Group Mapping page, and it can also be configured at the master group level on the Users : Groups : Master Groups page under the Mapping Methods and Mapping Table tabs.

F5 Product Development tracked this issue as CR125802 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-5 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
