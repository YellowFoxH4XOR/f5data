K94262722: Full /var/log/ partition caused by not rotating the /var/log/appiq/configserver-month-day-year-1.log files

Type
Support Solution
Published
2021-03-05
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K94262722

Description

  • /var full
  • Log rotate is not rotating the /var/log/appiq/configserver-month-day-year-1.log files
  • emerg alertd[4965]: 01100048:0: Log disk usage still higher than 80% after logrotate and 24 times log deletion
  • err diskmonitor: 011d0004:3: Disk partition /var/log has only 0% free
  • alert alertd[4965]: 01100045:1: /var/log disk usage exceeds 90%. Reduce log disk space now

Environment

  • BIG-IQ Cluster up and running for a long time

Cause

 ID721189

Recommended Actions

Manually modify configuration files to start log rotate for appiq service logs:
  1. Use text editor to Modify <DefaultRolloverStrategy max="10"/>  in  file: /var/config/appiq/agentmanager/config/log4j2.xml
  2. Replace <DefaultRolloverStrategy max="10"/> with: 
    <DefaultRolloverStrategy max="10">
    <Delete basePath="/var/log/appiq/" maxDepth="2">
                   <IfFileName glob="agentmanager-*.log.gz" />
                   <IfLastModified age="P7D" />
                   </Delete>
    </DefaultRolloverStrategy>
     
  3. Use text editor to Modify <DefaultRolloverStrategy max="10"/> in file: /var/config/appiq/configserver/config/log4j2.xml
  4. Replace <DefaultRolloverStrategy max="10"/> with:
    <DefaultRolloverStrategy max="10">
    <Delete basePath="/var/log/appiq/" maxDepth="2">
                   <IfFileName glob="configserver-*.log.gz" />
                   <IfLastModified age="P7D" />
                   </Delete>
    </DefaultRolloverStrategy>
  5. Reboot
