Description

You would like to configure a HTTP monitor that requires authentication with a username and password in the HTTP header (the backend server should have the HTTP authentication enabled as well).

Environment

  • BIG-IP LTM.
  • HTTP health monitors.

Cause

The backend end server requires authentication for HTTP requests.

Recommended Actions

This can be achieved by adding  \r\nusername: username\r\npassword: password\r\n in the HTTP health monitor string.

For example, the backend server requires authentication with a username Rest and password Rest000
the send string in an HTTP would look like :

GET /index.html HTTP/1.1\r\nHost: host.x.x.x.x.com\r\nusername: Rest\r\npassword: Rest000\r\nConnection: Close\r\n\r\n

If we capture monitor traffic we will see the following:

Hypertext Transfer Protocol
    GET /index.html HTTP/1.1\r\n
    Host: host.x.x.x.x.com\r\n
    username: Rest\r\n
    password: Rest000\r\n
    Connection: Close\r\n
    \r\n
    [Full request URI: http://x.x.x.x.com/index.html]
    [HTTP request 1/1]
    [Response in frame: 38]
