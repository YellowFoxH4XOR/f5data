Source

Description

When creating GSLB pool for DNS, customer may find they cannot add virtual server to pool because the dropdown list button is invisible as below:

Environment

  • BIG-IP DNS
  • GSLB Pool
  • Virtual server

Cause

There is a known bug Bug ID 726412: Virtual server drop down missing objects on pool creation
This bug does not include all conditions, it is found when the virtual server name contains one or more blank or tab, it will make the dropdown list invisible when creating pool. This issue can be found even in the fixed version in the bug tracker.

 Recommended Actions

Refer the workaround solution in the bug link above or using tmsh command to create the pool with virtual servers.
