Known Issue

This is the result of a known issue. The PVAC process crashes when HTTP processing is disabled for a virtual server for which WebAccelerator is enabled. For example, if you use an iRule to disable HTTP processing on a CLIENT_ACCEPTED iRule event, and the WebAccelerator is enabled for the virtual server, the PVAC process will crash when receiving ingress data.

F5 Product Development tracked this issue as CR126925 and it was fixed in BIG-IP WebAccelerator version 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

This issue was fixed in BIGIP-10.0.1-378.0-HF3, which has been issued for BIG-IP WebAccelerator version 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about installing 10.x hotfixes, refer to in K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

Workaround

You can work around this issue by disabling the WebAccelerator using the WAM::disable iRule command prior to disabling HTTP processing in the iRule.
