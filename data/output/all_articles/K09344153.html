Description

The below logs are observed in /var/log/ltm when restjavad starts to restart in loop:

Rest request failed: {"code":404,"message":"URI path /mgmt/shared/authz/tokens not registered.  Please verify URI is supported and wait for /available suffix to be responsive."

Environment

  • Authentication tokens
  • Restjavad restarting

Cause

 Lack of memory for restjavad process.  It is known issue ID 776393.

Recommended Actions

Give restjavad extra memory, using the following commands:

tmsh modify sys db restjavad.useextramb value true 

tmsh modify sys db provision.extramb value 2000

bigstart restart restjavad

Additional Information

Workaround needs to be implemented on HA peers separately as the change does not get synced.
Please also be cautious with enabling 'restjavad.useextramb' as this may cause ID 1025261 to kick in.
