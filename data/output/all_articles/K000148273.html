Description

BIF-IP application security policies can be cloned and save as a new with the same security configuration. 

Environment

  • BIG-IP
  • ASM

Cause

None

Recommended Actions

You can clone a policy by following these steps:

  1. Log in to the BIG-IP system Configuration Utility.
  2. Navigate to Security > Application Security > Security Policies > Policies List.
  3. Select the policy you want to clone using the checkbox right before it.
  4. Click on the three dots (...) next to Create and select Clone Policy.
