K000161707: With F50S-A 1.8.4, CLI memory platform-used value is different from SNMP F5-PLATFORM-STATS-MIB::memPlatformUsed."platform" value.

Type
Support Solution
Published
2026-06-15
Updated
2026-06-15
Applies to
  • F5OS
  • F5OS-A: 1.8.4
Source
https://my.f5.com/manage/s/article/K000161707

Description

F5OS-A v1.8.4 may report different "Platform Memory Used", whether the appliance is queried over SNMP or with using ConfD:

  • SNMP:

(host) # snmpwalk <options> <rseries_appliance1_ip> .1.3.6.1.4.1.12276.1.2.1.4.1

F5-PLATFORM-STATS-MIB::memAvailable."platform" = Gauge32: 1826549760 bytes

F5-PLATFORM-STATS-MIB::memFree."platform" = Gauge32: 745349120 bytes

F5-PLATFORM-STATS-MIB::memPercentageUsed."platform" = INTEGER: 92 percentage

F5-PLATFORM-STATS-MIB::memPlatformUsed."platform" = Gauge32: 1539715072 bytes <====[!!]

  • ConfD:

rSeries-appliance# show components component platform state memory

state memory total 134725894144

state memory available 10427768832

state memory free 725659648

state memory used-percent 92

state memory platform-total 16106782720

state memory platform-used 5822992384 <====[!!]

state memory platform-used-percent 36

 

Environment

F5OS-A v1.8.4

 

Cause

(Bug alias 2298349) F5OS:Memory-related SNMP OIDs (memAvailable, memFree, memPlatformUsed) in F5-PLATFORM-STATS-MIB truncated to 32-bit Gauge32, cannot represent values above 4GB

 

Answer/Recommended Actions

Do please rely on ConfD to get the actual memory usage of the platform.

 

Additional Information

Some API calls are also available:

GET https://{{rseries_appliance1_ip}}:8888/restconf/data/openconfig-platform:components/component=platform/state/f5-platform:memory
