K000147459: SSL/TLS verification failure on origin server resulting in 503 error

Type
Support Solution
Published
2024-11-08
Updated
2026-03-25
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Apps
  • F5 Distributed Cloud Multi-Cloud App Connect
Source
https://my.f5.com/manage/s/article/K000147459

Description

  • HTTP Load Balancer (LB) as a front proxy to protect a web server (origin server)
  • The web server has TLS certificate and origin pool   
    • followed the steps under 2.3*. to enable origin server verification using default or custom certificate authority (CA) list
      • *Web App Security & Performance Step 2.3: Create origin pool
  • A client
    • Can access origin web server without any issue
    • Gets 503 error when using XC Load Balancer 

Environment

  • F5® Distributed Cloud (SaaS)
  • F5® Distributed Cloud Load Balancer (section; origin pool TLS configuration)

Cause

  • The certificate was not signed by one of the certificate authorities defined in the TLS client policy trust bundle;
    • User's web server CA does not contain the Intermediate/Chain certificate
    • You can test the origin server certificates with some online tool, for example, SSL Server Test
  • A client can directly access the origin web server because all browsers automatically download intermediate certs to complete the chain when the server sends an incomplete chain
  • Our load balancer is not a browser,  it will not explicitly add the missing pieces
  • The certificate is no longer valid (expired).
  • The Subject Alternative Name (SAN) does not match the requested DNS hostname.

Answer/Recommended Actions

  • Add the missing Intermediate/Chain certificates to the CA file,  use this for the origin server verification
    For example

    • -----BEGIN CERTIFICATE-----
      dsajiodsajiowjda...CERT-1-Contents
      -----END CERTIFICATE-----

      -----BEGIN CERTIFICATE-----
      ASKDJfojdOIwadjoadajlsak....CERT-2-Contents
      -----END CERTIFICATE-----

  • Depending on the output of the SSL Server Test, fix the issue as appropriate. For example, if the certificate is expired, renew and replace the certificate as needed. For more information on configuration, refer to Web App Security & Performance or Create HTTP Load Balancer.
