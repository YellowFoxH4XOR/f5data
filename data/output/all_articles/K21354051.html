Description

Idle asm_config_serv can remain loaded for a long time and add unnecessary memory pressure.

Environment

  • ASM

Cause

Bug ID833685

Recommended Actions

  1. Kill asm_config_server.

    Note: Killing 'asm_config_server does not have a negative impact on your system.

    # pkill -f asm_config_server

  2. As a temporary solution, create a cron.daily job to kill 'asm_config_server'

    // access to cron.daily
    # cd /etc/cron.daily

    // creating a script to kill asm_config_server daily
    # vi asm_config_server.sh

    // create script
    #!/bin/sh
    date >> /var/log/asm
    echo "Restarting asm_config_server from cron for ID833685" >> /var/log/asm
    pkill -f asm_config_server

    // Change the permissions
    chmod +x asm_config_server.sh

Note: This script will kill this process daily.
