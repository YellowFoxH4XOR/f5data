K000152719: No destinations are reachable after the BigIP is upgraded.

Type
Support Solution
Published
2025-07-24
Updated
2025-07-24
Applies to
  • BIG-IP
  • BIG-IP APM
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000152719

Description

After BigIP upgrade to v17x, it seems the responses from the remote destinations simply vanish within the SSLo box: they are not forwarded back to the clients.

Environment

BIG-IP SSLO w/ TLS 1.3 on version 17

Cause

This is caused by 1788105 TLS1.3 connections between BIG-IP and server hangs with an APM policy that is invoked after the server's SSL handshake finishes.

In an SSL Orchestrator setting, inline HTTP and ICAP services make use of APM policies that use L7 protocol lookup. Server Certificate and L7 protocol lookup conditions also make use of events that trigger the APM policy after the SSL handshake has completed.

Recommended Actions

An Engineering hotfix is available. You may also be able to apply one of these workarounds:

1. Disable TLS1.3 on the serverSSL profile

2. Avoid using events that trigger the policy after the SSL handshake on the server has completed (for example avoid Event Wait and L7 protocol Lookup)
