Known Issue

BIG-IP Edge Client may display an error message when attempting to establish a network access session.

This issue occurs when the following condition is met:

  • Your BIG-IP APM access profile's access policy login page includes a third type option of select.

Impact

BIG-IP Edge Client displays an error message when attempting to establish the network access session.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to establish a network access session, BIG-IP Edge Client displays a script error window with a message similar to the following example:

    An error has occurred in the script on this page.
    Line: 356
    Char: 13
    Error: Object doesn't support property or method 'trim'
    Code: 0
    URL: https://<VPN_URL>/my.policy

    Do you want to continue running scripts on this page?

    The script error window displays Yes and No buttons; selecting either button allows the system to establish the session.

Workaround

To work around this issue, you can modify the logon.inc customization file of the access profile to eliminate the error. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility. For information on how to log in to the Configuration utility, refer to K55532313: How do I log in to the BIG-IP Configuration utility?.
  2. Navigate to Access Policy > Customization > Advanced.
  3. Expand the Access Profiles section.
  4. Select the affected access profile.
  5. Expand the affected access profile Logon Pages section.
  6. Expand the Logon Page section.
  7. Click logon.inc.
  8. In the logon.inc file, locate the following lines of code (approximately lines 124 and 126):

    <? include_customized_page("logout", "session_expired.js"); ?>

    var globalRestartOnSubmit = false;
  9. Between the noted code lines from step 8 (at approximately line 125), add the following lines to the logon.inc file:

    if(typeof String.prototype.trim !== 'function') {
    String.prototype.trim = function() {
    return this.replace(/^\s+|\s+$/g, '
    };
    }

    For example, the modified lines may appear similar to the following:

    <? include_customized_page("logout", "session_expired.js"); ?>

    if(typeof String.prototype.trim !== 'function') {
    String.prototype.trim = function() {
    return this.replace(/^\s+|\s+$/g, '
    };
    }

    var globalRestartOnSubmit = false;
  10. In the upper-right corner of the code editor, click Save Draft.
  11. In the Do you want to save your changes? window, click Yes.
  12. In the upper-left corner of the editor, click Save.
  13. In the upper-left corner of the Configuration utility, click Apply Access Policy.
  14. Click Apply Access Policy.
