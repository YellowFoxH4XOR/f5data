Description

  • A whitelisted URL is being denied, the SYN packet is getting dropped on the PEM.

Environment

  • PEM configured with flow filter policies.
  • PEM configured with custom category and the action is allowed.

Cause

If the SYN packet from the client is getting dropped on the PEM device, the only cause could be incorrectly configured flow filters. The PEM classification engine may not be even triggering in this case, as for the URLCAT filter to trigger the PEM needs to see the HTTP GET or SSL client hello.

 

The other reason could be the SRDB engine dropping the traffic.

 

 

 Recommended Actions

  1. Verify the flow filters are correctly configured and ensure there are no syntax error in the flow filters.
  2. Try to disable the SRDB engine to verify before raising a case with the F5 support.

# tmsh modify sys db tmm.pem.srdb.enable value false 

# tmsh modify ltm classification ce ce_pem cache-results off.

 

NOTE: ce_pem is the presets, as an example, connected to virtual <virtual-server> -> Classification Profile(classification_pem)->Preset(ce_pem).

NOTE: changes in srdb.enable may not take affect unless tmm is restarted. However "cache-results off" will take affect immediately without tmm restart and will serve the purpose.
