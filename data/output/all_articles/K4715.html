Resetting FirePass to default settings

To reset a FirePass controller to its default settings, perform the following procedure:

  1. Connect a workstation to the serial port of the FirePass controller using a null-modem cable.

    Important    : A null-modem cable is required for the serial connection. Other types of cables such as crossover or rollover cables will not work.
  2. Configure a communications program, such as HyperTerminal or XTerm, using the following settings:
    • Baud rate: 19200
    • Data bits: 8
    • Parity: none
    • Stop bits: 1
    • Flow control: hardware
  3. Start the serial connection.

    The screen changes to show a logon prompt
  4. Type maintenance at the logon prompt.

    If prompted for a password, enter the password you configured on the Device Management: Security: Console Access Security page in the Administrative Console. By default, there is no password required for accessing the Maintenance Console.
  5. Review the conditions and press Enter to continue.

    A screen of maintenance options opens.
  6. Select option 1: Reset settings and/or admin password.
  7. When prompted, select option 1: Reset settings and/or admin password.

    A warning screen appears, displaying the default settings that will be present after the FirePass controller has been reset.

    Below the information, a final prompt appears to confirm or halt the reset.

    Important: Typing yes at this point will erase your FirePass configuration.
  8. At the prompt, type yes and press Enter.

    A prompt appears, asking whether to change the default FirePass IP settings.
  9. Type no or press Enter to use the factory default network settings.

    Alternately, type yes and press Enter to configure custom network settings appropriate for your network.

    The FirePass will reconfigure and reboot.

After the FirePass controller reboots, it will use the following settings:

  • Administrative console admin account: admin
  • Admin account password: admin

Additionally, If you reset the FirePass controller to its factory default network settings, it will use the following settings:

  • FirePass host name: firepass.company.xyz
  • FirePass IP address: 192.168.1.99
  • FirePass netmask: 255.255.255.0
  • DNS server IP address: 192.168.1.1
  • Gateway IP address: 192.168.1.1

Connecting to FirePass

If you reset the FirePass controller to its factory default network settings, you can connect to FirePass by performing the following procedure:

  1. Configure a workstation to use the 192.168.1.0/24 network.
  2. Connect the configured workstation to the same network as the FirePass controller.
  3. Logon to the FirePass Administrative Console at https://192.168.1.99/admin/.

If you configured custom network settings in Step 9, you can log on to the FirePass Administrative Console at https://<FirePass_Hostname>/admin/ where FirePass_Hostname is the hostname or IP address you configured for the FirePass controller.
