Topic

You should consider using this procedure under the following condition:

  • You want to use the command line to update the protocol inspection signatures on the BIG-IP AFM system.

Description

BIG-IP AFM protocol inspection profiles use sets of signatures to detect protocol anomalies in traffic. F5 periodically updates these signatures and releases them on the MyF5 Downloads site.

You can download and install protocol inspection updates on the BIG-IP AFM system using the TMOS Shell (tmsh).

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You licensed and provisioned the BIG-IP AFM module on your BIG-IP system.
  • You have internet access to the MyF5 Downloads site.
  • You have administrative access to tmsh.

Procedures

  • Manually updating the protocol inspection signatures
  • Automatically updating the protocol inspection signatures (14.1.x and later)

Manually updating the protocol inspection signatures

To download, install, and load BIG-IP AFM protocol inspection updates manually using the tmsh utility, perform the following procedure:

Impact of procedure: The BIG-IP AFM protocol inspection update does not synchronize to peer members of a high availability (HA) device group. You must perform the procedure on each member of an HA device group.

  1. On MyF5, go to Resources > Downloads.
  2. In Account, if you have more than one MyF5 account, select the account you want.
  3. Select the check box to agree with the End User License Agreement and Product Terms.

    Note: The check box displays only when F5 does not yet have a record of you accepting these agreements.

  4. In Group, select BIG-IP.
  5. In Product Line and Product Version, select the product and version you want.
  6. Under Select a product container, select ProtocolInspection-LatestUpdate.

    The files available for download display beneath the product container section after you select a product container.

  7. Under Select a download file, select a file with the filename format pi_updates_<BIG-IP version>-<YYYYMMDD>.<build number>.im that you want to download.

    You can download only one file at a time.

  8. At the bottom of the page, in Download locations, select the location nearest you.
  9. Select Download.
  10. After the system finishes downloading the first file you selected, return to the Select a download file section, and then select the MD5 file for the signature file you downloaded in the previous steps. The MD5 file should have the filename format pi_updates_<BIG-IP version>-<YYYYMMDD>.<build number>.im.md5.
  11. Repeat steps 8 through 9 to download the MD5 file.
  12. After you have downloaded the necessary files, F5 recommends that you perform MD5 checksum verification on the signature file you have downloaded. For instructions on how to perform the MD5 checksum verification, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.
  13. Copy the update file to the /shared/protocol_inspection_updates directory on the BIG-IP AFM system. For more information on how to copy the file to the BIG-IP AFM system, refer to K175: Transferring files to or from an F5 system.
  14. Log in to tmsh.
  15. View the currently installed and available updates by typing the following command:

    show /security protocol-inspection update

Automatically updating the protocol inspection signatures (14.1.x and later)

Starting in BIG-IP AFM 14.1.x, you can configure the BIG-IP AFM system to automatically update protocol inspection signatures daily, weekly, or monthly using the tmsh utility. To configure the BIG-IP AFM system to automatically download, install, and deploy the protocol inspection signature updates, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh.
  2. Enable the auto-update for the protocol-inspection feature by entering the following command:

    modify /security protocol-inspection auto-update settings enabled yes

  3. Set the update schedule to daily, weekly or monthly by entering the following command syntax:

    modify /security protocol-inspection auto-update settings auto-update-interval [daily / monthly / weekly]

    For example, you would enter the following command to set the schedule to monthly:

    modify /security protocol-inspection auto-update settings auto-update-interval monthly

  4. Save the changes by entering the following command:

    save /sys config

  5. View the auto-update configuration by entering the following command:

    list /security protocol-inspection auto-update settings

    Based on the previous example, you should observe an output similar to the following:

    security protocol-inspection auto-update settings {
        auto-update-interval monthly
        enabled yes
    }
