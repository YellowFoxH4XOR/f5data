Topic

The bigd process performs health checks on the BIG-IP platform. On a dual processor machine, the bigd process runs on CPU0 (primary processor) while the CPU1 (secondary processor) is dedicated to the TMM process.

This applies to the following dual processor BIG-IP platforms:

  • BIG-IP 4100 D46
  • BIG-IP 5100 and 5110 (D51)
  • BIG-IP 6400 (D63)
  • BIG-IP 6800 (D68)
  • BIG-IP 6900 (D104)
  • BIG-IP 8400 (D84)
  • BIG-IP 8800 (D88)

To verify which processor is running a particular process, type the following command into the command line:

top -p `pidof tmm` -p `pidof bigd`

The output will appear similar to the following example:

PID USER PRI NI SIZE RSS SHARE STAT %CPU %MEM TIME CPU COMMAND11062 root RT 0 3806M 3.7G 3804M R 49.9 1768.6 20088m 1 tmm11026 root 15 0 7052 2956 2736 S 0.0 1.3 29:37 0 bigd

Note: The CPU column indicates that the tmm process is running on CPU1 and the bigd process is running CPU0.
