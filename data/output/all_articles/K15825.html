Known Issue

After deleting an external data group, the data for the new external data group does not propagate to the Traffic Management Microkernel (TMM) and is unavailable for use.

This issue occurs when all of the following conditions are met:

  • You delete an existing external data group.
  • You then import a new data group or edit an existing data group.
  • You are in an administrative partition other than the /Common partition.

Impact

iRules that use data groups may contain incorrect or outdated data, and do not function as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • No errors display when a user imports or edits a data group.
  • iRules that use data groups produce unexpected results due to incorrect or outdated data.

Workaround

To work around this issue, you can restart the BIG-IP system to force a refresh of BIG-IP data. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system temporarily stops processing traffic during restart. This procedure should only be performed when the BIG-IP system is in a standby state or during a maintenance window.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Restart all system services by typing the following command:

    restart sys services all
