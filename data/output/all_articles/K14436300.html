Topic

You should consider using this procedure under the following condition:

  • You attempt to connect the BIG-IP system to a Calico Border Gateway Protocol (BGP) Kubernetes cluster.

Description

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You are running compatible versions of Kubernetes and BIG-IP in accordance with the BIG-IP Controller/Platform compatibility matrix on the F5 Container Ingress Services Releases and Versioning page.
  • Your BIG-IP system is licensed for advanced routing.

Procedures

When connecting the BIG-IP system to a Calico Kubernetes cluster, the BIG-IP is added as a global BGP peer in the cluster. For more information, refer to Configuring BGP Peers. 

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

To configure the BIG-IP system to establish BGP neighbor adjacency and exchange routing information with Kubernetes nodes, perform the following procedures:

  • Configuring the BIG-IP system to connect the Calico Kubernetes cluster
  • Verifying BGP connectivity with Calico Kubernetes cluster nodes

Configuring the BIG-IP system to connect the Calico Kubernetes cluster

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Enable the BGP on your route domain. For more information, refer to K13802: Enabling dynamic routing protocols for a route domain.
  2. Log in to the BIG-IP command line.
  3. Access the IMI Shell (imish) by entering the following command:

    imish

  4. Enter enable mode by entering the following command:

    enable

  5. From the prompt, enter configuration mode by typing the following command:

    config terminal

  6. Enable BGP routing and specify the AS number configured in your Calico Kubernetes cluster. For example, to configure the default Calico AS 64512, entering the following command:

    router bgp 64512

  7. Create a BGP peer group for the calico nodes. For example, to create a peer group called calico-k8s, enter the following command:

    neighbor calico-k8s peer-group

  8. Configure the peer-group members (Calico Kubernetes nodes) as BGP neighbors by entering the following command:

    neighbor calico-k8s remote-as 64512

  9. Add Calico Kubernetes nodes as a member of the BGP peer-group. For example, to add node 172.24.171.55, enter the following command:

    neighbor 172.24.171.55 peer-group calico-k8s

    Note: Repeat this step for all Calico Kubernetes nodes.

  10. Write the configuration by entering the following command:

    write

  11. Exit configuration mode by entering the following command:

    end

Verifying BGP connectivity with Calico Kubernetes cluster nodes

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Access the IMI Shell (imish) utility by entering the following command:

    imish

  3. Enter enable mode by entering the following command:

    enable

  4. Verify that the BIG-IP system is in Established state with Calico Kubernetes nodes by entering the following command:

    show ip bgp neighbors

    The following command output displays the expected result of the command on the BIG-IP system:

    BGP neighbor is 172.24.171.53, remote AS 64512, local AS 64512, internal link
 Member of peer-group calico-k8s for session parameters

  Last read 22:17:13, hold time is 90, keepalive interval is 30 seconds
...
BGP neighbor is 172.24.171.55, remote AS 64512, local AS 64512, internal link

  BGP version 4, remote router ID 172.24.171.55
  BGP state = Established, up for 22:17:13
  Last read 22:17:13, hold time is 90, keepalive interval is 30 seconds

  5. Verify that the BIG-IP system learned Calico Kubernetes pods routes by entering the following command:

    show ip route
