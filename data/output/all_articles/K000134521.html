K000134521: You can't access the management IP. CLI and logs show Disk partition /var has only 0% free.

Published

Status
Legacy Content
Applies to

  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K000134521

Description

You can't access the management IP one of the Viprion GUEST. Comand Line of the HOST and logs show disk partition /var has only 0% free on specific slot.

Environment

  • BIG-IP
  • GUEST
  • VIPRION

Cause

Old backup files which didn't get overwritten by new ones occupied the space of the /var folder.

Recommended Actions

  • Clear the /var folder from old files, for example, backups, qkview, etc.

Optional:

  • Resizing the /var file system on a VCMP guest to add extra space.

Additional Information

None
