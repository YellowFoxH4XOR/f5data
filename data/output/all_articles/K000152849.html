Description

F5OS provides a comprehensive API for both retrieving device state and configuring various parameters on F5 VELOS systems. This article specifically addresses how to query the state of a particular interface on an F5 VELOS system running F5OS-C using the F5OS REST API. A key consideration for VELOS systems is the interface naming convention, which includes a forward slash (`/`) (e.g., `1/1.1` or `2/1.1`, where the first digit denotes the blade number). Since the forward slash is a special character in URLs, it must be URL-encoded as `%2F` when used as part of a key value.

Environment

  • Product: F5OS-C
  • Platform: VELOS system
  • Automation method: F5OS API

Cause

The necessity for URL encoding arises from the standard URL specification, where a forward slash (`/`) acts as a path delimiter. When an interface name on an F5 VELOS system contains a forward slash (e.g., `1/1.1`), it's interpreted as part of the path structure rather than a literal character within the interface name itself. To correctly identify the specific interface as a key value in the API request, the forward slash must be replaced with its URL-encoded equivalent, `%2F`.

Recommended Actions

To successfully retrieve interface state using the F5OS-C API on a VELOS system, ensure that any forward slashes in the interface name are URL-encoded.

Example of API Call

$ curl -k -H "Content-Type: application/yang-data+json" -H "X-Auth-Token: $TOKEN" -X GET https://$IP/api/data/openconfig-interfaces:interfaces/interface=1%2F1.1 | jq .
