Known Issue

Configuring IPsec over an iSession connection fails after you perform an upgrade. This occurs because beginning in BIG-IP 11.6.1, the anonymous IKE Peer is disabled by default, which prevents IPsec over iSession from working.

This issue occurs when all of the following conditions are met:

  • You have configured IPsec as the IP encapsulation type for iSession connections.
  • You upgrade from BIG-IP 11.6.0 to a BIG-IP version listed in the Applies to (see versions) box, located in the upper-right corner of this article.

Impact

The iSession connection fails to pass traffic. 

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The iSession connection fails to pass traffic.
  • In the /var/log/tmm file, you observe messages similar to the following example:

    notice cmp'd pkt_flow_key 10.2.1.1:8 -> 10.1.0.1:23382 can't be matched by policy (reqid=aeee)

Resolution

Status

F5 Product Development has assigned ID 648264 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can configure the iSession configuration to use a one-sided iSession and IPsec to NAT traversal. For more information, refer to the Setting Up iSession and IPsec To Use NAT Traversal on One Side of the WAN chapter of the BIG-IP LTM BIG-IP TMOS: Tunneling and IPsec guide.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system

Note: The Quick Start : Symmetric Properties of the Configuration utility is considered obsolete due to the lack of support for IKEv2. Using the encapsulation option as outlined in the Setting Up iSession and IPsec To Use NAT Traversal on One Side of the WAN chapter of the BIG-IP LTM BIG-IP TMOS: Tunneling and IPsec guide is meant for demonstration purposes using low security defaults. This configuration is not recommended for use in production environments.

Important: Configuring IPsec IKEv1 with the anonymous IKE-peer General Properties setting of State "Enabled" can expose a known security vulnerability. This configuration should only be utilized when testing in a closed lab environment. For more information refer to: K10133477: BIG-IP IPsec IKE peer listener vulnerability CVE-2016-5736
