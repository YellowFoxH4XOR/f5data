Known Issue

Client SSL sessions that require client certificate authentication may fail.

This issue occurs when one of the following conditions is met:

  • The virtual server's Client SSL profile is configured to require client certificate authentication.
  • The client certificate is validated by a Certificate Revocation List (CRL) file.
  • The client certificate and CRL have been signed by a different Certificate Authority (CA).

    Note: You can typically differentiate a CA by the unique Authority Key Identifier.

This issue occurs because the BIG-IP system attempts to validate the CRL file using the CA used to sign the client certificate. The CRL file is not validated for BIG-IP versions prior to 10.2.2.

Impact

Clients may be unable to establish SSL connections.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • A BIG-IP system running 10.2.1 or earlier may be configured as described above. When such a configuration is upgraded to an affected version, the configuration may fail to load. In addition, the system may return error messages that appear similar to the following example:

    Error reading ca validation fail PEM file /config/filestore/files_d/Common_d/certificate_d/:Common:ca1.crt_1 for profile /Common/clint_one: Failed to find valid certificate for the crl.
  • The BIG-IP system fails to authenticate client SSL connection attempts and logs an error message in the /var/log/ltm file. The error message appears similar to the following example:

    01260004:2: Invalid signature on CRL
