Issue

Prior to FirePass version 6.0.2 with Cumulative Hotfix HF-602-3, the Remove Components tool in the FirePass Components Troubleshooting Utility (f5wininfo.exe) did not support Windows Vista systems. If a user attempted to remove FirePass components on a Windows Vista system using the Remove Components tool, the FirePass Components Troubleshooting Utility reported an error message that appears similar to the following example:

Is not available under MS Vista!

Starting in FirePass version 6.0.2 with Cumulative Hotfix HF-602-3, the Remove Components tool in the FirePass Components Troubleshooting Utility now supports Windows Vista systems.

Note: For more information, refer to K8701: Change in Behavior: Components Troubleshooting Utility Remove Components tool now supports Windows Vista systems.

Note: The FirePass Components Troubleshooting Utility was introduced in FirePass version 6.0.2.
