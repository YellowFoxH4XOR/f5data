Description

Inability to connect from a single machine or a single machine suffers random disconnections.

Environment

  • BIG-IP APM
  • Single client effected
  • Mac, Windows, Linux, iOS, or Android device

Cause

In scenarios of clients failing to connect or VPN disconnections that only effect a single user. It is almost always a client side issue of some sort. The following are just a couple of the possibilities that we have seen.

  • AV, Firewall, or anti-malware software interfering
  • Bad client install
  • Local network issue
  • ISP issues
  • Modem or router issues
  • Other vpn clients or software installed and causing conflicts
  • Other 3rd party software or toolbars

Recommended Actions

It is recommended that you perform the following actions in order to try and narrow down the cause of the trouble.
  1. Uninstall and reinstall the edge client software using the client troubleshooting utility per K12444: Overview of the Client Troubleshooting Utility for Windows.
  2. Ensure the Edge Client, Browser Components, F5 helper Application are installed by a user with ADMIN privileges.
  3. Remove or uninstall any 3rd party VPN clients
  4. Perform an Anti-Virus, Malware scan.
  5. White list the client as well as the FQDN/IP address of the APM VPN in any Anti-Virus or Anti-Malware software running on the client.
  6. Add the FQDN/IP of the APM virtual server to the trusted sites list.
  7. Attempt to connect from a different location.
  Note: In many of these single user or single client scenarios there is very little that can be done on the BIG-IP APM to resolve these issues. You may need to contact Microsoft to troubleshoot Windows VPN issues, or consider re-imaging the single client. F5 Support is not designed to troubleshoot the Windows Network stack issues for a single client.
