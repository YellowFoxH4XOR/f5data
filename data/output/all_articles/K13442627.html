K13442627: BIG-IQ configured for Management only, forces BIG-IP with SSLO enabled to Read Only mode

Type
Support Solution
Published
2021-03-15
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K13442627

Description

When BIG-IQ manages a BIG-IP device with SSLO enabled, the SSLO user interface on BIG-IP is made read-only.
 

Environment

  • BIG-IP with SSLO enabled is managed by BIG-IQ
  • SSLO module is not managed by BIG-IQ

Cause

ID939193

Recommended Actions

Upgrade to a fixed BIG-IP software version.  If not available, you may open a service request to request an Engineering Hotfix.

Additional Information

None
