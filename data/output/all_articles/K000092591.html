K000092591: 5.1CF21 flowmanager.xml missing <CreateTDR> tags

Type
Support Solution
Published
2022-11-26
Updated
2022-11-26
Source
https://my.f5.com/manage/s/article/K000092591

Description

  • When checking routing rules in flowmanager.xml there are some that are missing the "<CreateTDR>" tags.
  • ﻿The CreateTDR tag appears only when you enable the checkbox "Create Transaction Data Records". If you had initially created the TDR and later unchecked the box, it shows the parameter but with the value as False.

Environment

  • SDC 5.1

Cause

By design.

 Recommended Actions

None.

Additional Information

In flowmanager.xml, the <CreateTDR> tag only appears for Rules that have the "Create Transaction Data Records" checked in the GUI.

[root@ems-01 1609890493637]# xmllint --format flowManager.xml |egrep -n --color "<Id>RT\-(.*)</Id>|<CreateTDR>(.*)</CreateTDR>"

191:      <Id>RT-24</Id>

423:      <Id>RT-23</Id>

628:       <CreateTDR>true</CreateTDR>  <<<<< Checked "Create Transaction Data Records"

656:      <Id>RT-25</Id>

866:      <Id>RT-26</Id>

1076:      <Id>RT-27</Id>

1281:       <CreateTDR>true</CreateTDR>  <<<<< Checked "Create Transaction Data Records"

1309:      <Id>RT-22</Id>

1517:       <CreateTDR>true</CreateTDR>  <<<< Checked "Create Transaction Data Records"

 

Adding AVP to that rule will also reflect when checking flowmanager.

[root@ems-01 1609891280669]# xmllint --format flowManager.xml |egrep -n --color "<Id>RT\-(.*)</Id>|<CreateTDR>(.*)</CreateTDR>"

191:      <Id>RT-24</Id>

423:      <Id>RT-23</Id>

628:       <CreateTDR>True</CreateTDR> <<< Added AVP;showing value True.

656:      <Id>RT-25</Id>

888:      <Id>RT-26</Id>

1120:      <Id>RT-27</Id>

1325:       <CreateTDR>true</CreateTDR>  <<< Added AVP;showing value True.

1353:      <Id>RT-22</Id>

1561:       <CreateTDR>true</CreateTDR>  <<< Added AVP;showing value True.

 

Unchecking the "Create Transaction Data Records" will also reflect in the flowmanager. Example for RT-27 and RT-22; we can see now that the value is False.

[root@ems-01 1609891453559]# xmllint --format flowManager.xml |egrep -n --color "<Id>RT\-(.*)</Id>|<CreateTDR>(.*)</CreateTDR>"

191:      <Id>RT-24</Id>

423:      <Id>RT-23</Id>

628:       <CreateTDR>false</CreateTDR>  <<< Unchecked the "Create TDR box"; showing value False.

656:      <Id>RT-25</Id>

888:      <Id>RT-26</Id>

1120:      <Id>RT-27</Id>

1325:       <CreateTDR>false</CreateTDR>  <<< Unchecked the "Create TDR box"; showing value False.
