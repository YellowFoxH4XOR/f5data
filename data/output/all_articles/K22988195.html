K22988195: After upgrade to 16.0.0.1 or 15.1.4 the APM SAML policy is not accessible anymore and client receives an error: /my.logout.php3?errorcode=25.

Type
Support Solution
Published
2022-04-01
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 16.0.1, 15.1.4
Source
https://my.f5.com/manage/s/article/K22988195

Description
After upgrade to 16.0.0.1 or 15.1.4 from 15.1.0.5 the APM SAML policy is not accessible anymore and client receives an error: /my.logout.php3?errorcode=25.
When viewing network traffic using Wireshark you notice the message "[F5RST: Route domain not reachable (strict mode)]" 

Environment

  • BIG-IP APM
  • SAML
  • Upgrade

Cause
Unknown

Recommended Actions

For the Route Domain where SAML Policy is configured, choose one of the following:
  • Disable Strict isolation
  • Add "Parent Name = 0  (Partition Default Route Domain)

Additional Information
None
