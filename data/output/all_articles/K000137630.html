K000137630: Error when upgrading to Hotfix version - ''Disk full (volume group)'' SOL#10636

Type
Support Solution
Published
2024-05-23
Updated
2024-07-17
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM: 16.0.X, 16.0.0, 16.0.1, 16.1.0, 16.1.1, 16.1.2, 16.1.3, 16.1.4, 16.1.X
Source
https://my.f5.com/manage/s/article/K000137630

Description

Device was upgraded from 16.0.1 to 16.1.4 base image

When installing the hotfix image to a new volume, it failed with Disk Full error SOL #10636

Environment

  • LTM
  • EHF/Hotfix Upgrade

Cause

Not enough disk space to install the hotfix.  

K91895955: Unable to upgrade with error "Disk full (volume group)"

Recommended Actions

Rollback to the previous version. 

  1. Delete the failed volume
  2. Boot to the volume of the previous version

Upgrade directly to the Hotfix version

  1. Verify both base and hotfix iso images are imported to /shared/images directory
  2. Install the hotfix image to the inactive volume
  3. Activate the hotfix image to upgrade to the EHF version
