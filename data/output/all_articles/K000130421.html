K000130421: Server side SSL choose different version of TLS while configured to use only TLSv1.3 on server-ssl profile

Type
Support Solution
Published
2022-12-31
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.5
Source
https://my.f5.com/manage/s/article/K000130421

Description

Server-side ssl picks different versions of TLS while configured to use only TLSv1.3 on the server-ssl profile.


Environment

  • Server SSL profile in use
  • Options field configured to remove the TLS versions not in use.


Cause

server-ssl profile with no-tls under options causes the profile to choose a version that is configured not to use:


ltm profile server-ssl /Common/test-serverssl_tls1.3 {

options { dont-insert-empty-fragments no-ssl no-tlsv1.1 no-tlsv1.2 no-sslv3 no-tlsv1 no-tls }


 Recommended Actions

Configure the server-ssl profile without "no-tls" under options as seen below:


ltm profile server-ssl /Common/test-serverssl_tls1.3 {

options { dont-insert-empty-fragments no-ssl no-tlsv1.1 no-tlsv1.2 no-sslv3 no-tlsv1}
