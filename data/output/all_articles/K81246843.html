K81246843: api.f5.com is rejecting FCP report submissions with error: unable to submit license report. Report generated but submission failed for (license key)

Type
Support Solution
Published
2021-06-11
Updated
2026-09-23
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K81246843

Description

You have set up automated reporting each month or have tried to send a utility report via the automated method and see the error message “api.f5.com is rejecting ELA report submissions with the following error: unable to submit license report. Report generated but submission failed for (license key)."

Environment

  • BIG-IQ versions 7.X and 8.X
  • Using FCP
  • Sending automated utility report

Cause

One of your BIG-IQ certificates has expired and needs to be updated. 

Recommended Actions

From the command line of the BIG-IQ as the root user run the following command, to check when your license was last reactivated: 

restcurl /cm/device/licensing/pool/utility/licenses/ | jq '.items[].regKey' -r | while read regKey;do echo "for regKey: $regKey";restcurl "/cm/device/licensing/pool/utility/licenses/$regKey" | jq .apiCert -r | base64 -d | openssl x509 -dates -noout;done

The output will look similar to this:
notBefore=Jun  9 21:52:33 2021 GMT
notAfter=Jun  9 22:02:33 2026 GMT

Important: If you have a not after date of "Jun  9 22:02:33 2026 GMT" you will need to reactivate the BIG-IQ ELA load license.

  • Automatically updating the BIG-IQ license
  • Automatically updating the FCP license
  • Manually updating the BIG-IQ license
  • Manually updating the FCP license
  • Activating individual FCP offerings
  • Sending the FCP usage report

Automatically updating the BIG-IQ license 

You need to update the BIG-IQ base license (service check date) to ensure the FCP / CAT license also gets updated.
Note:  This only needs to be done on the “active” unit, the certificate will get shared to a standby in HA pair. This is not service impacting on existing BIG-IP’s.

  1. Go to System > This Device > Licensing 
  2. Click on “Reactivate” 
  3. Activation method, choose Automatic 
  4. Click on “Activate” 
  5. Review “Service Check Date” 

Automatically updating the ELA license 

To update the certificate, you will need to reactivate the FCP CAT license. 
Note: The FCP CAT license update will update additionally the certificate. 

  1. Go to Devices > License management > Licenses
  2. Select the status check box for each ELA load license.
  3. Click Reactivate
  4. Activation Method choose Automatic
  5. Click Reactivate in the bottom right-hand side of the screen
  6. Click on blue link to “Name”
  7. Review “Service Check Date”
  8. Go back to the command line and rerun the RestCurl command to check the certificate dates have been updated for that license key, repeat for each license key:

    restcurl /cm/device/licensing/pool/utility/licenses/ | jq '.items[].regKey' -r | while read regKey ; do echo "for regKey:$regKey";restcurl "/cm/device/licensing/pool/utility/licenses/$regKey" | jq .apiCert -r | base64 -d | openssl x509 -dates -noout;done

    The output will look similar to the following:
    notBefore=Jun 25 21:14:34 2026 GMT
    notAfter=Nov 22 18:21:49 2028 GMT     

Note: The reactivation process takes about 10 minutes as the BIG-IQ reactivates each of the 30 SKU offerings. Once the reactivation is complete you can send the ELA usage report. 
 
Manually updating the BIG-IQ license 

You need to update the BIG-IQ base license (service check date) to ensure the FCP / CAT license also gets updated. This only needs to be done on the “active” unit, the certificate will get shared to a standby in HA pair. This is not service impacting on existing BIG-IP’s.

  1. Go to System > This Device > Licensing 
  2. Click on “Reactivate” 
  3. Activation method, choose Manual 
  4. Click on “Generate Dossier”
  5. Copy the contents of the “Device Dossier”
  6. Open a web browser to https://activate.f5.com click link to “activate F5 product registration key"
  7. Paste the dossier into “Enter your Dossier” box 
  8. Click “Next”
  9. Copy the “license”
  10. On the BIG-IQ GUI paste the license in the “License Text” box.
  11. Click on “Activate” 
  12. Review “Service Check Date”

Manually updating the ELA license

To update the certificate, you will need to reactivate the FCP license(s). 
Note: If you see a status in yellow of “Pending” for any of the Licenses, you will initially have to activate each of the underlying license offerings. Review process How to manually license FCP in BIG-IQ

  1. Go to Devices > License management > Licenses
  2. Select the status check box for the FCP CAT license, you can only do one at a time and every load will need to go through the reactivate process.
  3. Click Reactivate
  4. Activation Method choose Manual
  5. Click on “Generate Dossier”
  6. Copy the dossier text from “Device Dossier” box
  7. Open https://activate.f5.com in a browser click link to “activate F5 product registration key"
  8. Paste the dossier into “Enter your Dossier” box 
  9. Click “Next”
  10. Copy the “license”
  11. On the BIG-IQ GUI paste the license in the “License Text” box.
  12. Click on “Reactivate” 

Activating individual FCP offerings: 

  1. Click on license Name to expand the FCP offerings
  2. Click on offering name
  3. Copy dossier from Device Dossier box. 
  4. Paste the dossier into the Enter Your Dossier box, and then click Next
  5. Copy the license and paste it into License text on BIG-IQ
  6. Click on Activate in the bottom right of the screen.
  7. Repeat this for each of the FCP license offerings available.
  8. Go back to the command line and rerun the RestCurl command to check the certificate dates have been updated for that license key, repeat for each license key:

    restcurl /cm/device/licensing/pool/utility/licenses/ | jq '.items[].regKey' -r | while read regKey ; do echo "for regKey:$regKey";restcurl "/cm/device/licensing/pool/utility/licenses/$regKey" | jq .apiCert -r | base64 -d | openssl x509 -dates -noout;done

    The output will look similar to the following:
    notBefore=Jun 25 21:14:34 2026 GMT
    notAfter=Nov 22 18:21:49 2028 GMT     

Sending the ELA usage report 

  1. Go to Devices > License management > Reports 
  2. Click Reports 
  3. Type “Utility Billing Report” 
  4. Move all licenses to Selected 
  5. Set Submission Method to "Automatically submit report to F5” 
  6. Click Submit
