K000147605: How do I point a root domain to another domain?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-22
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147605

Description

  • I want to create a DNS record to point a root domain to another domain.
  • I can't use a CNAME record because it requires a subdomain, and CNAME records can't be placed at the root of a domain due to conflicts with other DNS records.

 

Environment

  • F5® Distributed Cloud HTTP Load Balancer

 

Resolution/Answer

You can add an ALIAS record in DNS zone management. ALIAS records are mainly used to direct a root domain to a CNAME target, which isn't possible with a standard CNAME record.

  • Add new Resource Record Sets under DNS Zone Management.
  • Choose the Record Set as ALIAS and insert the Domain name.
