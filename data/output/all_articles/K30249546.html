K30249546: BIG-IQ CAT License - Reactivate Button is Greyed Out

Type
Support Solution
Published

Updated
2026-10-29
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K30249546

Description

The 'Reactivate' button is greyed out, the Catalog license status is Pending, and only some of its license offerings are Active.

Environment

  • BIG-IQ
  • Flex Consumption Program (FCP)
  • Catalog (CAT) License offerings
  • Pending (yellow triangle) status
  • Prior Manual Activation

Cause

This is expected behavior when using the manual option for activating CAT keys. Reactivate is greyed out and the CAT remains in Pending (yellow triangle) status until all its license offerings are activated (green circle). After all license offerings are activated and the CAT status is Active (green circle), the Reactivate option is available. 

Recommended Actions

Perform the following steps to activate all license offerings so you can reactivate the CAT license:

  1. On the BIG-IQ, navigate to Devices tab > License Management > Licenses.
  2. Click on the CAT license name to view its license offerings.
  3. Click on the license offering name.
  4. Copy dossier from Device Dossier box. 
  5. Click into the Licensing Server link, Access F5 manual activation web portal.
  6. On this Activate F5 Product site, paste the dossier into the Enter Your Dossier box then click Next.
  7. Copy the license text and paste it into License text window on the BIG-IQ. 
    Note: Each license offering has a unique dossier.
  8. Click on Activate in the lower right corner of the screen.

Repeat the above steps for every pending CAT license offering. 
The 'Reactivate' button will be available when all the offerings' statuses show as Active.

Additional Information

When the Reactivate button is finally available, if possible, use the "automatic" option so all license offerings are available and to avoid the manual activation in the future.
