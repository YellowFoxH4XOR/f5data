Description

The BIG-IP receives a packet from a client with a source and destination that matches a traffic-selector. The BIG-IP does not try to start the associated IPsec tunnel.

As a result, no connection is established between the client and the remote service. 

Environment

  • Correct configuration for IPsec policy and IPsec IKE peer.
  • A SNAT also matches the traffic.

Cause

SNAT rules may match with the inbound packet and change the source or destination IP, resulting in the packet no longer matching the traffic-selector. Outbound traffic-selector evaluation happens after listener / Virtual Server processing, so by the time the packet leaves the Virtual Server, the IPs have changed.

Recommended Actions

Any of the following method can avoid this issue.

  • Change the SNAT configuration to ignore the traffic for the IPsec traffic selector.
  • Change the traffic selector to match the SNAT traffic.
