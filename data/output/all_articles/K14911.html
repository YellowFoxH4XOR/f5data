Known Issue

The Traffic Management Microkernel (TMM) process may restart when using the Session Initiation Protocol (SIP) profile.

This issue occurs when all of the following conditions are met:

  • Your system passes traffic through a virtual server with the SIP profile enabled.
  • The SIP client closes the connection while the server is sending data.

Impact

TMM restarts and the BIG-IP system temporarily stops processing traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system temporarily fails to process traffic and potentially fails over to the standby system.
  • TMM produces a core file at the time of the trace in the /shared/core directory.
  • The BIG-IP system generates a SIGSEGV fault and stack trace in the /var/log/tmm file, which appears similar to the following example:
