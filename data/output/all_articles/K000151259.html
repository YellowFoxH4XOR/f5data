K000151259: F5OS resolving activate.f5.com via DNS when using system licensing install with proxy-server option

Type
Support Solution
Published
2025-05-09
Updated
2025-05-09
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.0
  • F5OS-C: 1.8.X, 1.8.1, 1.8.0
Source
https://my.f5.com/manage/s/article/K000151259

Description

When re-activating the system license with the proxy-server option, the F5OS system first resolves activate.f5.com via DNS, before sending the HTTP CONNECT request to the proxy server.

The system then sends a HTTP CONNECT request in the following format:

CONNECT <IP of activate.f5.com>:443 HTTP/1.0
Host: <IP of activate.f5.com>

Instead of the expected:

CONNECT activate.f5.com:443 HTTP/1.0
Host: activate.f5.com:443

The system should send the HTTP CONNECT request to the proxy server using the FQDN as-is, without resolving activate.f5.com.

DNS resolution for the target host is typically the role of the proxy server.

Environment

  • F5OS-A
  • F5OS-C
  • License activation via proxy

Cause

This issue is tracked by bug ID1933769 - Licensing via proxy server should use license server's FQDN.

Recommended Actions

To work around this issue, you must ensure that the F5OS system can resolve activate.f5.com, either by configuring a DNS server, adding a host-entry for activate.f5.com, or allowing access to the root DNS servers.

Additional Information

If the system cannot resolve activate.f5.com, license re-activation will fail. No request will be sent to the proxy server.

The system will return an error similar to the following:

result Error: Cannot determine IP for license server
