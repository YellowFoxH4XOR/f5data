Description
This article will detail how to use a 'Variable Assign' to split 'Access Policy Session Variables' from the 'Local Database' 'Groups' field into individual variables.
By default, when the value of the groups is called, the value returned will include all groups as comma separated values.
In this example use case we will separate 2 groups assigned to users and assign them as separated variables.

Environment

  • BIG-IP Access Policy Manager (APM)
  • Visual Policy Editor
  • Variable Assign object

Cause
None

Recommended Actions

Assign multiple groups to a user:
  1. Logon to the BIG-IP Admin GUI.
  2. Navigate to Access >> Authentication >> Local User DB >> Users
  3. Create or modify a user and assign multiple groups to the user
Create a custom variable for each group assigned:
  1. Logon to the BIG-IP Admin GUI.
  2. Navigate to: Access>Profiles / Policies>Access Profiles (Per-Session Policies).
  3. Click on the Edit icon to open the Virtual Policy Editor (VPE).
  4. Go to the Assignment tab and select Local Database.
  5. Create a 'Read' action, enter in the destination variable of:
    session.localdb.groups
        And a source DB property of
    groups
  6. Click Save
  7. Create a 'Variable Assign' object
  8. Click on the new 'Variable Assign' object and 'Add new entry'
  9. Click 'change' on the empty entry and under the 'Custom variable' enter the new variable for the first group
    session.custom.group0??
    In the Custom Expression use the following to extract the first group
    expr { [lindex [split [mcget {session.localdb.groups}] ","] 0] }
  10. Repeat steps 8 and 9 for each group incrementing each expression:
    Example:
    session.custom.group1
    expr { [lindex [split [mcget {session.localdb.groups}] ","] 1] }
  11. Click Finished
  12. Click 'Save'
Now you can call each group as a variable separately and use them in your policy.

Additional Information
You can use the sessiondump command line utility to verify the custom session variable is being populated correctly. For information refer to the Session Variables chapter of the BIG-IP Access Policy Manager: Visual Policy Editor manual.
