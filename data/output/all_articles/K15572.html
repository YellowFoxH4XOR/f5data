Known Issue

The BIG-IP system logs AgentX error messages in the /var/log/ltm or /var/log/zebos file every ten seconds.

This issue occurs when all of the following conditions are met:

  • Advanced routing is enabled on the BIG-IP system and configured to exchange routing information.
  • The BIG-IP system is configured to send SNMP traps for ZebOS events.

Impact

None. You can safely ignore this error message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H476687 on the Diagnostics > Identified > Low screen.
  • You find error messages in the /var/log/ltm or /var/log/zebos file that appear similar to the following example:

    warning OSPF[13527]: OSPF: AgentX: process_packet (Operational state), Response-PDU, 123456:234567
    warning OSPF[13527]: OSPF: AgentX: requested pdu : 1
    warning OSPF[13527]: OSPF: AgentX: process_packet, unhandled PDU, Operational state
