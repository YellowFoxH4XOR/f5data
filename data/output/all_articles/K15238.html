Known Issue

The BIG-IP APM Configuration utility portal access setup wizard may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system configuration uses multiple partitions.
  • You run the Configuration utility portal access setup wizard in a partition other than the Common partition.

Impact

Creation of the portal access profile with the portal access setup wizard fails.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After completing the Review Configuration step in the portal access setup wizard, the system displays an error message similar to the following example:

    General database error.

  • Creating a portal access profile with the portal access setup wizard in the Common partition is successful.
