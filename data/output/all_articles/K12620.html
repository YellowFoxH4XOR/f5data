Known Issue

This is the result of a known issue. In BIG-IP WebAccelerator version 10.2.0-HF2 and 10.2.1, using the Intelligent Browser Reference (IBR) feature may result in a memory leak in the pvac service and a degradation in performance. This performance degradation may be particularly acute if the system begins to swap.

For information about the IBR feature, refer to the Specifying content assembly options section of the Configuring Assembly Rules chapter in the the Policy Management Guide for the BIG-IP WebAccelerator System.

F5 Product Development tracked this issue as ID 349483 and it was fixed in BIG-IP WebAccelerator 10.2.2. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
