K8173: Dynamic Application Tunnels and Web Application Tunnels cannot access TCP ports greater than 32767

Known Issue

This is the result of a known issue. If you have a network application that listens on TCP port 32767 or greater, users cannot access that network application using a Dynamic Application Tunnel or a Web Application Tunnel. Specific symptoms or errors that users experience will vary based on the network applications that users attempt to access.

Note: Application Tunnels are configured on the Application Access: App Tunnels: Resources page in the FirePass Administrative Console.

F5 Networks Product Development tracked this issue as CR89969 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-1 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by configuring Static Application Tunnels instead of Dynamic Application Tunnels or Web Application Tunnels to access TCP ports greater than 32767.

If you require a Dynamic Application Tunnel and you can configure your network application to listen on TCP port 32767 or lower, you can work around this issue by performing the following procedure:

  1. Configure the affected network application to listen on TCP port 32767 or lower.
  2. Log on to the FirePass Administrative Console.
  3. Navigate to the Application Access: App Tunnels: Resources page.
  4. In the Resource Groups drop-down menu, select the Resource Group you want to configure.
  5. Under the Application Tunnels tab, select the Application Tunnel you want to configure.
  6. In the Allow List text box, change the port number to the new port number you configured in Step 1.For example:

    server.siterequest.com:41321

    Replace the above example with the following:

    server.siterequest.com:21321

  7. Click the Update button.
