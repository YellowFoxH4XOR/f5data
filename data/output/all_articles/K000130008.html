K000130008: Configured "External Users Role" to "No Access" and this has cause allowed "Remote Role Group" users not able to login admin to BIG-IP via GUI/SSH

Type
Support Solution
Published
2022-12-20
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000130008

Description

Customer configured below, and this cause allowed LDAP users cannot login admin to BIG-IP via GUI or SSH

  1. External Users Role
    •  Role: No Access
    • Terminal Access: Disabled
  2. Remote Role Group
    • attribute CN=example_Group_name,CN=User,DC=example.domain,dc=com

Environment

  • BIG-IP 
  • Remote Authentication
  • LDAP/Active Directory

Cause

The reason is because the "Remote Role Groups" configured DN name missing "memberOf=", thus BIG-IP cannot match it to the desired LDAP groups.
Example:
# list auth remote-role 
auth remote-role {
    role-info {
        example_Group_name {
            attribute CN=example_Group_name,CN=User,DC=example.domain,dc=com
            console tmsh
            line-order 1002
            role operator
            user-partition All
        }

Recommended Actions

Login to the BIG-IP and configure via "BIG-IP GUI > System > Users > Authentication > Remote Role Groups" start with "memberOf=" (is a must have) then follow by the DN name, example below.

-- Remote Role Groups attributes as below entry:
"memberOf=CN=example_Group_name,CN=Users,DC=example.domain,DC=com"
 

Additional Information

How to find the exact DN name, may follow the steps below:
1. Login to BIG-IP shell and run below bash command:
# ldapsearch -xLLL -H 'ldap://ldapserver.ip_or_fqdn' -b "cn=users,dc=example.domain,dc=com" -s sub -D "domain\admin" -w 'password' "(cn=example_Group-name)"

2. Look for the first entry of "DN name" from the output.
example results:
# ldapsearch -xLLL -H 'ldap://10.x.x.x' -b "cn=users,dc=example.domain,dc=com" -s sub -D "domain\admin" -w 'password' "(cn=example_Group_name)"
dn: CN=example_Group_name,CN=Users,DC=example.domain,DC=com     << !! DN name
objectClass: top
objectClass: group
cn: example_Group_name
member: CN=ldapuser01,CN=Users,DC=example.domain,DC=com
member: CN=ldapuser02,CN=Users,DC=example.domain,DC=com
...

Notes: Please remember to change the DN "cn=users,dc=example.domain,dc=com", LDAP User login "domain\admin" and Group Name "cn=example_Group_name" to your company domain FQDN and domain, admin login, group name.

3. Once you found the DN name, please replace the Remote Role Groups attributes as below:
Attribute String: memberOf=CN=example_Group_name,CN=Users,DC=example.domain,DC=com
