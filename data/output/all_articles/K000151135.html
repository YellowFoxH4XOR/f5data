K000151135: Issues with inherinting/updating virtual servers on new BIG-IP DNS to BIG-IP LTM connection

Description

  • BIG-IP LTM Virtuals are not showing up on BIG-IP DNS after running bigip_add and big3d_install scripts.
  • BIG-IP DNS sees the active virtual servers in the BIG-IP LTM as offline.
  • Non-floating self-IP of BIG-IP LTM is being used.

 

Environment

  • BIG-IP LTM
  • BIG-IP DNS
  • New BIG-IP LTM - BIG-IP DNS connection

 

Cause

BIG-IP DNS non-floating self-IP has not been added to the same Data Center Server list as the BIG-IP LTM.

 

Recommended Actions

Go to -> DNS ›› GSLB : Servers : Server List -> Create -> add the BIG-IP DNS using its non-floating self-ip to the Data Center Servers list.

 

Wait a couple of minutes and check if the Virtual Servers turn green.

(Optional) If virtual servers don't turn green to match the BIG-IP LTM at this point, please proceed with the following:

1) Restart the following daemons on the BIG-IP DNS:

bigstart restart gtmd big3d

2) Restart the following daemons on the BIG-IP LTM:

bigstart restart big3d
