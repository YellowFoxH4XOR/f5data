Description

SSO Application stopped working post upgrade.

Error message seen in /var/log/apm:

Could not find SSO domain, check variable assign agent setting

Environment

  • SSO
  • BIG-IP upgraded

Cause

This happens due to the missing NTLM domain in SSO configuration.

Recommended Actions

To  add the NTLM domain for the SSO Configuration refer to K41357230: Configuring BIG-IP APM NTLM SSO for portal access

None.
