K71557891: Azure failover doesn't work after upgrade to 14.x

Description

After upgrading a BIG-IP instance in Azure to 14.x from an earlier version, failover may appear to work from the Configuration Utility of the BIG-IP, but the actual virtual servers do not fail over.  

Environment

  • Azure BIG-IP deployment from an ARM template earlier than version 14.
  • Upgrade to version 14.
Cause

In version 14, a new database key was introduced - failover.selinuxallowscripts.
By default, it is not touched for BIG-IPs that are upgraded.
New BIG-IPs are deployed with this set to "enable" in Azure.
If upgrading from an older Azure deployment using the .iso file, this key is set to "disable".

Recommended Actions

  1. From the command line of the BIG-IP, run the following command:

    tmsh list sys db failover.selinuxallowscripts

  2. If the output shows value "disable", enable it:

    tmsh modify sys db failover.selinuxallowscrtips value enable

  3. Save the configuration:

    tmsh save sys config
