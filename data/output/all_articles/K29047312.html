Topic

This article covers the compatibility of F5 VNF Manager and the NFV Packaged Solutions with internal components, BIG-IP and BIG-IQ systems and plugins.

Description

F5 VNF Manager manages the lifecycle of BIG-IP VE instances, deployed as virtualized network functions (VNFs). This functionality is leveraged to offer packaged network function virtualization (NFV) offerings.

For the compatibility overview of VNF Manager and the NFV Packaged Solution releases, based on version and hotfix level, refer to the following tables.
