Known Issue

This is the result of a known issue. Users connecting to a Network Access resource when using a standalone client with auto-launch enabled on the Network Access resource may receive the following error message:

Error: Already Exists

This error message only occurs in Simple Mode. Advanced Mode and Legacy Logon features are not affected.

Note: The error is benign and can be ignored. This issue only affects FirePass Version 6.0.3 with Cumulative Hotfix HF-603-1 installed.

F5 Product Development is tracking this issue as CR99563-3.
