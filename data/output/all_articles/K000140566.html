Description

REST API sometimes times out and then gets stuck in a failed state where all responses are 400/401, even for built-in users like f5hubblelcdadmin

Logs seen in /var/log/restjavad.X.log when issue begins:

[RestOperation] failure handler for GET http://localhost:8100/mgmt/tm/auth/source 400 threw unexpectedly: java.lang.IllegalStateException: AsyncContext completed and/or Request lifecycle recycled

 

Environment

  • BIG-IP
  • restjavad

Cause

Bug ID1710621

Recommended Actions

Restart restjavad and restnoded services

  1. Log in to bash shell
  2. Restarting these services will briefly interrupt REST API access
    bigstart restart restjavad && sleep 20 && bigstart restart restnoded

If restjavad and restnoded restart do not work, use 'clear-rest-storage' to work around the issue

Important: Do not run 'clear-rest-storage command on devices that have SSLO provisioned and configured. As it removes the SSLO configuration from the REST Storage and it will no longer show in the SSLO Guided Config.

  1. This command restarts restjavad and restnoded processes as well clearing rest storage and deleting pamcache. Refer to K67220984: Clear-rest-storage. What does it do?
    clear-rest-storage
