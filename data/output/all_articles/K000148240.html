K000148240: Duo Universal prompt on F5 Access mobile is not working. getting "403 The request could not be satisfied" error

Type
Support Solution
Published
2024-10-24
Updated
2024-10-24
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148240

Description

You've configured the Duo Universal prompt on the BIG-IP APM as per https://community.f5.com/kb/technicalarticles/apm-configuration-to-support-duo-mfa-using-irule/283971


It works fine with the BIG-IP Edge Client and browser-based access from PCs. However, when you try it from the F5 Access mobile app, it does not work and you get this "403 The request could not be satisfied" error.


Environment

  • F5 Access mobile
  • Duo Universal prompt

Cause

There is a missing parameter in the "auth-redirect-request" configuration object on the BIG-IP APM


Recommended Actions

Add the "redirect_uri" parameter with type "redirect-uri" for the "auth-redirect-request" configuration object


  1. Navigate to Access ›› Federation : OAuth Client / Resource Server : Request ›› <auth-redirect-request_object-name>
  2. add the following parameter:
  • Parameter Type: redirect-uri
  • Parameter Name: redirect_uri
