Issue

Error Message

notice tmm[<PID>]: 01340001:5: HA Connection with peer <IP>:<port> for traffic-group <name> established.

In this error message, note the following:

  • <PID> is the process ID for the tmm process
  • <IP> is the IP address used by the peer for the mirroring connection
  • <port> is the port number used by the peer for the mirroring connection
  • <name> is the partition and name of the affected traffic-group

For example:

notice tmm[18354]: 01340001:5: HA Connection with peer 10.10.10.10:1029 for traffic-group /Common/traffic-group-1 established.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The connection used for high availability (HA) features between BIG-IP peers, such as persistence and connection mirroring, establish successfully.

For example, this message is generated when the peer BIG-IP system in an HA configuration boots up or is restarted, or after initially configuring the mirroring IP addresses.

Impact

The HA connection between peer BIG-IP system is established and the systems can now transmit data for HA features.

Recommended Actions

None
