Description

You should consider using the following procedures under the following condition:

  • You want to enable or disable RADIUS authentication for BIG-IP administrative users.

The RADIUS protocol provides access control for network devices using one or more centralized servers. RADIUS operates over User Datagram Protocol (UDP) and provides authentication, authorization, and accounting (AAA) management for users connecting to a network service. You can change the authentication source for BIG-IP administrative users from using the local database to using an external authentication source, such as RADIUS. Configuring the remote RADIUS authentication source specifies that the BIG-IP system uses a remote RADIUS server to authenticate administrative users.

Important: It is not possible to use local and remote RADIUS authentication concurrently for administrative users.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have configured administrative user accounts on the remote RADIUS server.

Procedures

To watch a video demo of this procedure, go to  Configure RADIUS authentication for BIG-IP administrative users using the Configuration utility.

Configure RADIUS authentication for administrative users

To configure RADIUS authentication for BIG-IP administrative users, perform one of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility using the administrator account.
  2. Go to System > Users > Authentication.
  3. In the Authentication section, select Change.
  4. For User DirectorySelect Remote - RADIUS.
  5. Define the RADIUS server configuration settings to match those on the RADIUS server, including the port and shared secret settings:
    • Host: Specifies the name of the primary RADIUS server.
    • Port: Specifies the port for primary RADIUS server communications. The default is 1812.
    • Secret: The secret is a shared secret text string used between the BIG-IP system and the RADIUS server.
  6. If you want the system to use the local authentication method if the RADIUS server is not available, select Fallback to Local.
  7. Select Finished.

Traffic Management Shell

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

  2. Configure a RADIUS server using the following command syntax:

    create /auth radius-server <server_name> server <server_IP> secret <shared_secret>

    For example, the following command creates a RADIUS server called MyAuthServer with an IP address of 10.11.1.1, and shared secret of radiussecret:

    create /auth radius-server MyAuthServer server server 10.11.1.1 secret radiussecret

  3. Create a RADIUS configuration object that references the RADIUS server using the following command syntax:

    create /auth radius system-auth servers add { <server_name> }

    For example, the following command creates a RADIUS configuration object that references the RADIUS server called MyAuthServer:

    create /auth radius system-auth servers add { MyAuthServer }

  4. Optional. Adjust the RADIUS settings:

    modify /auth radius-server <name> ?
     
    Identifier:
    [object identifier]RADIUS server name

  5. Change the authentication source type to RADIUS by entering the following command:

    modify /auth source type radius

  6. Save the configuration by entering the following command:

    save /sys config

Disable RADIUS authentication for administrative users

To disable RADIUS authentication and change the authentication method to use the BIG-IP system's local database, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility using the administrator account.
  2. Go to System > Users > Authentication.
  3. In the Authentication section, select Change.
  4. For User Directory, select Local.
  5. Select Finished.

User DirectoryTraffic Management Shell

 

  1. Log in to the tmsh utility by entering the following command:

    tmsh

  2. Change the authentication source type to local by entering the following command:

    modify /auth source type local

  3. Save the configuration by entering the following command:

    save /sys config

Note: If the remote user accounts are unable to log in to the BIG-IP system, the locally defined user accounts, such as the default administrator account and the root command line account, will be able to log in to the system.
