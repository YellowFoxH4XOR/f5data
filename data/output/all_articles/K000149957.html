Description

Configuring TLSv1.3 as the ssl-protocol for the management interface results in errors similar to:

  1. tmsh modify sys httpd ssl-protocol "TLSv1.3"
  2. 01070920:3: Application error for confpp: [DDD MMM DD hh:mm:ss.xxxxx YYYY] [core:warn] [pid <PID>] AH00114: Useless use of AllowOverride in line 283 of /var/run/config/httpd.conf.
  3. AH00526: Syntax error on line 107 of /etc/httpd/conf.d/ssl.conf:
  4. SSLProtocol: Illegal protocol 'TLSv1.3'

 

Environment

  • BIG-IP Configuration Utility / GUI 
  • F5OS Configuration Utility / GUI 
  • Web brower

 

Cause

  • TLSv1.3 is not currently supported for the BIG-IP configuration utility (at the time of this solution is published/updated)

 

Recommended Actions

If you need TLSv1.3 support for the Configuration Utility / GUI,   please contact F5 support.
