K000135546: Regarding password policy enforment feature "Password Memory" for root user

Type
Support Solution
Published
2023-07-20
Updated
2026-09-25
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135546

Description

The password policy enforcement feature "Password Memory"' does not work the same way for the root user as it does for other users.

 

Environment

  • BIG-IP
  • Password policy enforcement
  • Password memory
  • root user

Cause

By design, due to root privileges, "Password Memory" feature does not work the same way for the root user as it does for other users.

 

Recommended Actions

  • "Password Memory" works for root user by manually expire the password using the passwd.bin utility.
    • passwd.bin --expire root

Additional Information

None
