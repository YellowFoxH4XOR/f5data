Known Issue

The Traffic Management Shell (tmsh) allows you to configure the IKE-Peer Phase 1 phase1-perfect-forward-secrecy setting with the invalid None option.

This issue occurs when the following condition is met:

  • You use the tmsh utility to set the phase1-perfect-forward-secrecy setting to None. 

Impact

Connectivity through an affected IPsec tunnel fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • IPsec tunnels cannot establish connections to Internet Explorer or Safari browsers.
  • The racoon process fails to start.
  • In the /var/log/racoon.log file, you observe an error message similar to the following example:

     INFO: Reading configuration from "/etc/racoon/racoon.conf"
    ERROR: /etc/racoon/racoon.conf.bigip:59: "}" DH group required.
    ERROR: fatal parse failure (1 errors)
    ERROR: failed to parse configuration file.

Workaround

To work around this issue, you can avoid setting the phase1-perfect-forward-secrecy setting to None.
