Description
You want to activate or reactivate the FCP CATALOG license on BIG-IQ either manually or automatically.
License activation process was not fully completed.
The license is showing in a "Pending" state and "reactivate" button is greyed out.

Environment

  • BIG-IQ
  • FCP
  • license activation not fully completed on BIG-IQ or License server

Cause

There are two main causes for this issue.

CAUSE 1:

If one or more offerings under the FCP license are pending activation, you will need to activate each of them, then go back and re-activate the license key.

Please review solution K15420056 which show's you how to manually license each offering

Note: If this step is not complete the steps below will cause an error message when you attempt to reactivate the dossier :

Error on server request
Number of Errors: 2
1. The system returned an unexpected error (400 Bad Request). Validation of PATCH failed
2. No error message

CAUSE 2:
Bug ID 1033457
When the GUI times out or you navigate away from the license page, BIG-IQ gets stuck waiting for the license dossier and does not proceed or time out. Clicking into the CAT License details, its License Status reads "Waiting for EULA Acceptance".

Also if the license server is slow to respond, the BIG-IQ may also fail to activate some of the license OFFERINGS under a cat license and you will need to reactivate.

Recommended Actions

To resolve ID1033457, replace properties in the URL visible in the address bar with reactivation:

  1. Navigate to Devices -> License Management -> Licenses
  2. Click on the blue name of the license in the "pending" state
  3. Note the URL or address in the browser bar:
    Example: https://<IP>/ui/devices/license-management/licenses/properties/Utility/<UUID>
  4. Replace the word "properties" with "reactivation":
    Example: https://<IP>/ui/devices/license-management/licenses/reactivation/Utility/<UUID>
  5. The page which loads is the License activation page and it will request the dossier, you can continue to license the FCP as normal.

Additional Information

If you are not able to reactivate using either method above, please raise a support call share the FCP license registration key and ask for an allow move.

Once completed try the above 2 methods again and this should allow you to license and reactivate as needed.

If it fails again, you will need to delete and re-add the FCP license key.

Firstly revoke any assigned licenses, delete the FCP license key and re-add it, then assign BIG-IP licenses as you did before.
