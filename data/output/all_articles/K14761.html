K14761: Attack signatures with minor updates are not placed in staging

Topic

Major and minor attack signature updates are included during the attack signature update process. However, only signatures with major updates are placed in staging following an update. Minor updates only include changes that do not affect the signatures themselves, such as a change to a signature's description. Major updates involve changes to the signatures themselves and can change the signature's functionality.

Description

Beginning in BIG-IP ASM 11.0.0, attack signature update details are reported in the BIG-IP ASM Configuration utility immediately following an update. Details now include the number of signatures added or removed, the number of signatures with major or minor updates, and a full list of the affected signatures. After successfully updating the attack signatures, a message in the Configuration utility appears similar to the following example:

Attack signatures successfully updated
122 attack signatures were added and placed in staging in relevant security policies
146 attack signatures had major updates and were placed in staging in relevant security policies
6 attack signatures had minor updates
105 attack signatures were removed

The message indicates that all newly added signatures and signatures with major updates were placed in staging following the update, and the six attack signatures with minor updates were not placed in staging.

Recommendations

When performing an attack signature update, review the update history for full details of all changes made to signatures.
