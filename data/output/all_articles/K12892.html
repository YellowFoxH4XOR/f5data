Known Issue

Description

Users are unable to access Windows Universal Naming Convention or Uniform Naming Convention (UNC) paths.

This issue occurs when all of the following conditions are met:

  • A user attempts to connect to UNC path through a Web Application favorite
  • The UNC path includes an ampersand (&)

Impact

Users are unable to access affected Windows file share resource.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system truncates the UNC path at the ampersand character and fails to open the share name. For example, if the full path is \\fileshare\a&b\monkeys.jpg, the path that opens is \\fileshare\a.

Workaround

To work around this issue, you can rename the UNC path to not include an ampersand. To do so, refer to the documentation for your file share server.
