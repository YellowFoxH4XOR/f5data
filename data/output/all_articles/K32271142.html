Known Issue

You cannot use pre-defined custom filters from within a scheduled report.

This issue occurs when all of the following conditions are met:

  • You create a custom filter from the Requests page or by using ASM Statistics.
  • You attempt to use a pre-defined filter in a scheduled report.

Impact

You are unable to use user-defined filters in scheduled reports.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system does not display custom filters in the pre-defined filter list.
