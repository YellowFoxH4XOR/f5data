Known Issue

The standby BIG-IP system in an HA device group may be unable to properly form Open Shortest Path First (OSPF) adjacency.

This issue occurs when all of the following conditions are met:

  • The BIG-IP HA device group members communicate through a VLAN group.
  • OSPF is configured to listen on the VLAN group.

Impact

Standby hosts will not have current OSPF routing information.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The imish -e "show ip ospf neighbor" command run on the active host shows the standby BIG-IP in an Init/DROther state.
  • The imish -e "show ip ospf neighbor" command run on the standby host shows no neighbors.
