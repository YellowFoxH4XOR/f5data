Known Issue

This is the result of a known issue. If a user enters a certain sequence of keys after logging on to the FirePass webtop, and before the webtop is loaded into the browser, FirePass may not report an expiration time for that user's session on the Reports: Sessions page under the Currently active tab.

Additionally, in version 5.5.2 of FirePass software, if the session has no expiration time listed on the Reports: Sessions page and then the session is terminated due to a possible intrusion attempt, FirePass continues to count the terminated session as an active session. If this issue occurs numerous times, it can consume all available FirePass user licenses, which prevents users from logging in to the FirePass controller. For information about how FirePass detects and reports possible intrusion attempts, refer to K8014: Error Message: Possible intrusion attempt detected against account.

Note: The potential licensing issue affects only version 5.5.2 of FirePass software.

F5 Product Development tracked this issue as CR77072 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, Cumulative Hotfix HF-552-11 has been issued for FirePass version 5.5.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
