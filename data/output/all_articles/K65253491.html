K65253491: Customization Group was not found

Type
Support Solution
Published
2021-04-26
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.2
Source
https://my.f5.com/manage/s/article/K65253491
Description

When trying to deploy with Guided Configuration and you have deleted a service (ex. SAML) previously, you have an error similar to the following:
transaction failed:01020036:3: The requested Customization Group (/Common/example.app/example_resource_saml) was not found

Environment

  • BIG-IP APM 
  • Using Guided Configuration 
Cause

The Guided configuration creates different objects when first deploy it.
Erasing an application through the Guided Configuration not always erase all the objects created.

Recommended Actions

Delete manually the iApp that shows in the error

  1. Log in to the Configuration utility.
  2. Navigate to iApps > Application Services.
  3. Click the name of the iApp.
  4. Click the Properties tab.
  5. Click Delete.
