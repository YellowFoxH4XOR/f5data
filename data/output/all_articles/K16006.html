Known Issue

Creating an sFlow receiver and Virtual Local Area Network (VLAN) group, in succession, may cause a Traffic Management Microkernel (TMM) restart loop.

This issue occurs when the following condition is met:

  • You use the Traffic Management Shell (tmsh) to create an sFlow receiver first, and then a VLAN group.

    For example, the command syntax may appear similar to the following:

    tmsh create sys sflow receiver <receiver name> { address <IP address> state enabled }
    create net vlan-group <group name> { members add { <vlan> } }

Impact

TMM may continuously restart and produce a core file, and the BIG-IP system will be unable to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system continuously reboots.
  • The BIG-IP system fails over to another system in the device group.
  • TMM generates a core file in the /var/core directory.
