Known Issue

Virtual servers may bounce when they reference pools that are configured with fully-qualified domain name (FQDN) node auto populate members.

This issue occurs when all of the following conditions are met:

  • You have configured FQDN-identified nodes.
  • You have configured new members for pools as new FQDN nodes, which automatically enables Auto Populate.
  • The FQDN DNS response returns the same addresses.

Impact

The virtual server changes its status to Unavailable and later to Unchecked.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the FQDN node and pool are configured with Auto Populate enabled, the BIG-IP system changes the virtual address status (for example, RED :: BLUE :: DOWN :: UNCHECKED), and the FQDN DNS response returns the same addresses.
