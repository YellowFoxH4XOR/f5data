K08427894: How to copy BIG-IP ASM security policy with a new name

Type
Support Solution
Published
2019-10-31
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K08427894

Description
To create a new security policy using an existing security policy, you may export the existing policy and import the policy, however, you can alternatively create the existing policy as a template and use the template to create a new policy. 

Environment

  • ASM policy 
  • Security Policy Template 

Cause
None

Recommended Actions

To create a template you may follow the below procedure. 

Creating a security policy Template

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Security Policies > Policies List.
  3. In the Active Security Policies list, select the security policy that you want to create a template, and then click Save as Template

Creating the new security policy using the Template

  1. Navigate to Application Security > Security Policies > Deployment Wizard
  2. Select Local Traffic Deployment Scenario 
  3. Select Create a security policy manually or use templates (advanced) 
  4. Type the security policy name under the security properties section
  5. Under application-ready Security Policy,  select the template you created. 
  6. Click Next 
  7. Click finish. 

Additional Information
ASM template allows you to create a security policy with a new name, hence if you want to rename an existing security policy, you may consider using the template to create a policy with the new name.
