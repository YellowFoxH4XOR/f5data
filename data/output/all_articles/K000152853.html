Description

Steps to perform a migration from legacy BIG-IP appliances to F5OS-based rSeries platforms using UCS file and the platform-migrate option.

Environment

Migration from legacy BIG-IP to rSeries using UCS file with the platform-migrate option.

Cause

Migration to rSeries.

Recommended Actions

  1. Upgrade the legacy BIG-IP appliance to a version matching the target tenant. Refer to K86001294 for compatibility.
  2. Deploy the rSeries appliance as per the following manual: F5 rSeries system initial configuration
  3. Create a BIG-IP tenant with resources sized appropriately for expected traffic load (vCPU, memory, disk) and assign necessary VLANs and interfaces. Refer to: Deploying an rSeries BIG-IP Tenant
  4. On the source device, generate a UCS file and copy the master key:

    tmsh save sys ucs <filename>

    f5mku -K

  5. Remove trunk objects from the UCS file before importing it to the target device (see K50152613 )

  6. On the target device (tenant), install the master key that you copied from the source device and load the UCS:

    f5mku -r <key_value>

    tmsh load sys ucs <filename> no-license platform-migrate

  7. If UCS import fails, review error messages and manually edit configuration files to resolve issues:

    tmsh load sys config verify

    tail -f /var/log/ltm

  8. Test all critical services and HA functionality before going live.
