K000150629: Command to list the virtual servers without encrypted cookies in HTTP profiles

Type
Support Solution
Published
2025-06-24
Updated
2025-06-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000150629

Description:

You are looking to identify HTTP profiles that either have or lack cookie encryption and map them to their associated virtual servers. This provides a set of commands that can help you quickly assess the configuration across all partitions. 

Environment

  • BIG-IP LTM
  • This article applies to BIG-IP 17.x or lower

Cause

  • None. Informational only.

 

Recommended Actions

Follow the steps below using the bash scripting approach to identify HTTP profiles and their associated virtual servers:

 

  1. Run the following command to list HTTP profiles with and without cookie encryption:
     
    PROFILES=$(tmsh -c 'cd /; list ltm profile http recursive one-line' | grep -E "defaults-from.*http" | awk '{print $4}' | sed 's/^/\//' | tr '\n' ' '); 
for profile in $PROFILES; do 
    if tmsh list ltm profile http "$profile" encrypt-cookies | grep -q "encrypt-cookies {"; then 
        echo "Cookie encryption is ENABLED for profile: $profile"; 
    else 
        echo "Cookie encryption is DISABLED (none) for profile: $profile"; 
    fi; 
done


    Output Example:
    Note: This command is designed to show all profiles across all partitions.
    Cookie encryption is DISABLED (none) for profile: /Common/local_NO_Cookie_Encryption
    Cookie encryption is DISABLED (none) for profile: /Common/local_NO_Cookie_Encryption_2
    Cookie encryption is ENABLED for profile: /Common/local_custom
    Cookie encryption is ENABLED for profile: /Cookie_Encrypt/Cookie_Encrypt_Enabled_NonCommon
    Cookie encryption is DISABLED (none) for profile: /Cookie_Encrypt/No_Cookie_Encrypt_NoCommon

    Important:  For larger configurations with numerous profiles BIG-IP performance can become a concern because the command iterates over every profile. For such scenarios, we recommend saving the output to a file to optimize performance. Here's how you can do that:
    PROFILES=$(tmsh -c 'cd /; list ltm profile http recursive one-line' | grep -E "defaults-from.*http" | awk '{print $4}' | sed 's/^/\//' | tr '\n' ' '); 
    for profile in $PROFILES; do 
        if tmsh list ltm profile http "$profile" encrypt-cookies | grep -q "encrypt-cookies {"; then 
            echo "Cookie encryption is ENABLED for profile: $profile"; 
        else 
            echo "Cookie encryption is DISABLED (none) for profile: $profile"; 
        fi; 
    done >> /var/tmp/profiles_cookie_encrypt.txt

    2. Run the following command to identify the virtual servers associated with HTTP profiles with and without cookie encryption:
     
    PROFILES=$(tmsh -c 'cd /; list ltm profile http recursive one-line' | grep -E "defaults-from.*http" | awk '{print $4}' | sed 's/^/\//' | tr '\n' ' '); 
for profile in $PROFILES; do 
    profile_name=$(echo "$profile" | sed 's/^\/\([^/]*\)\///' | xargs); 
    if tmsh list ltm profile http "$profile" encrypt-cookies | grep -q "encrypt-cookies {"; then 
        CATEGORY="with cookie encryption"; 
    else 
        CATEGORY="without cookie encryption"; 
    fi; 
    VS=$(tmsh -c 'cd /; list ltm virtual recursive one-line' | grep -E "profiles.*\{.*\b${profile_name}\b.*\}" | awk '{print $3}'); 
    if [ -z "$VS" ]; then 
        echo "No virtual servers found for profile: $profile ($CATEGORY)"; 
    else 
        for vs in $VS; do 
            echo "Virtual server: $vs uses profile: $profile ($CATEGORY)"; 
        done; 
    fi; 
done


    Output Example:
    Virtual server: Common/VS_NO_COOKIE_ENCRYPT uses profile: /Common/local_NO_Cookie_Encryption (without cookie encryption)
    Virtual server: Common/VS_NO_COOKIE_ENCRYPT2 uses profile: /Common/local_NO_Cookie_Encryption_2 (without cookie encryption)
    Virtual server: Common/VS_Cookie_Encryption uses profile: /Common/local_custom (with cookie encryption)
    Virtual server: Cookie_Encrypt/NonCommon_Cookie_Enabled uses profile: /Cookie_Encrypt/Cookie_Encrypt_Enabled_NonCommon (with cookie encryption)
    Virtual server: Cookie_Encrypt/NonCommon_No_Cookie_Encrypt_Enabled uses profile: /Cookie_Encrypt/No_Cookie_Encrypt_NoCommon (without cookie encryption)

    Important:     For larger configurations with numerous profiles and virtual servers, performance can become a concern because the command iterates over every profile and executes potentially expensive operations like grep and tmsh queries for each one. For such scenarios, we recommend saving the output to a file to optimize performance. Here's how you can do that:
    OUTPUT_FILE="/var/tmp/http_cookie_encrypt_output.txt"PROFILES=$(tmsh -c 'cd /; list ltm profile http recursive one-line' | grep -E "defaults-from.*http" | awk '{print $4}' | sed 's/^/\//' | tr '\n' ' '); 
    > "$OUTPUT_FILE"; 
    for profile in $PROFILES; do 
        profile_name=$(echo "$profile" | sed 's/^\/\([^/]*\)\///' | xargs); 
        if tmsh list ltm profile http "$profile" encrypt-cookies | grep -q "encrypt-cookies {"; then 
            CATEGORY="with cookie encryption"; 
        else 
            CATEGORY="without cookie encryption"; 
        fi; 
        VS=$(tmsh -c 'cd /; list ltm virtual recursive one-line' | grep -E "profiles.*\{.*\b${profile_name}\b.*\}" | awk '{print $3}'); 
        if [ -z "$VS" ]; then 
            echo "No virtual servers found for profile: $profile ($CATEGORY)" >> "$OUTPUT_FILE"; 
        else 
            for vs in $VS; do 
                echo "Virtual server: $vs uses profile: $profile ($CATEGORY)" >> "$OUTPUT_FILE"; 
            done; 
        fi; 
    done

    This  generates an output file in the specified path /var/tmp/http_cookie_encrypt_output.txt for easier review and reduced processing.

    Recommended Actions

    The commands provided in this article can also be adjusted to look for other specific features in the HTTP profile configuration. Here is an example of the command adjusted to look for profiles with "insert-xforward-for" enabled:

    PROFILES=$(tmsh -c 'cd /; list ltm profile http recursive one-line' | grep "insert-xforwarded-for enabled" | awk '{print $4}')
echo "HTTP Profiles with 'insert-xforwarded-for' enabled:"
echo "$PROFILES"
