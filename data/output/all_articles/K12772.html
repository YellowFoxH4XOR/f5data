Known Issue

This is the result of a known issue. The bgpd process does not accept community attributes that contain reserved values.

In ZebOS versions 5.4 through 7.5.0, you can configure a BGP daemon community attribute using any value. Starting in ZebOS version 7.5.1, the BGP daemon enforces the community attribute ranges reserved by RFC1997 as follows: 0x0000000 through 0x0000FFFF and 0xFFFF0000 through 0xFFFFFFFF.

As a result, if you attempt to configure a BGP daemon community attribute with a value outside of the above ranges, the system does not save the attribute to the /config/ZebOS.conf file.

F5 Product Development tracked this issue as ID 348368 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP LTM release notes.

In addition, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP LTM version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
