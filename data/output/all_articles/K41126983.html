Description
After the APM VPN connection is established, you're trying to connect to the BIGIP Configuration Utility [GUI].
The traffic goes through the VPN  tunnel smoothly but after you put the credentials, you are forwarded back to the GUI login page, over and over again.

Environment

  • You're using BIGIP APM;
  • You  connect to the BIGIP management interfaces through the VPN tunnel.

Cause
Due to the nature of the traffic coming out of the VPN, the Configuration Utility - actually: the Linux PAM module managing the authentication - can raise false positive alarms about "cookie impersonation".

Recommended Actions

  1. Using the Configuration Utility
    • open a connection to the GUI;
    • navigate to System  ››  Preferences
    • uncheck the box for the parameter "Require A Consistent Inbound IP For the Entire Web Session"
    • click "Update"
  2. Using TMSH:
    • open an SSH connection to BIGIP;
    • ensure you're in the TMIS Shell (prompt should be "(tmos) #"
    • issue the command: modify sys httpd { auth-pam-validate-ip off }
