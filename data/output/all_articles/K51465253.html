K51465253: Interfaces uninitialized but not working after upgrading BIG-IP VE on VMware ESXi 6.7 host to Update 2 (or later)

Type
Support Solution
Published
2020-05-21
Updated
2025-02-06
Applies to
  • BIG-IP
  • Virtual Editions
  • Vmware ESXI and vCloud Director
Source
https://my.f5.com/manage/s/article/K51465253

Description

After upgrading BIG-IP VE, interfaces are in "Uninitialized" state and not working.

Environment

  • BIG-IP VE running on VMware ESXi 6.7
  • Applied workaround for bug ID 774445 described in article K74921042: BIG-IP VE may fail to process traffic after upgrading the VMware ESXi 6.7 host to Update 2 (or later)
  • Upgraded to BIG-IP VE to fixed version of Bug ID 774445 
    • v15.x
    • v14.0.0.5 and later
    • v14.1.0.6 and later
    • v13.1.3 and later
       

Cause

Workaround for Bug ID 774445  is valid only on affected BIG-IP software versions.
 

Recommended Actions

After booting to Fixed versions of Bug ID 774445 :

  1. Verify that the workaround has been applied by viewing /config/tmm_init.tcl file content:
    # cat /config/tmm_init.tcl

    Depending on previous SW version, those outputs confirm, that workaround has been applied:
    14.1.0 and later
    device driver vendor_dev 15ad:07b0 sock
    14.0.0 and earlier
    device driver vendor_dev 15ad:07b0 unic
     
  2. Remove /config/tmm_init.tcl file:
    # rm /config/tmm_init.tcl
     
  3. Restart tmm:
     # bigstart restart tmm
