Description

Can BIG-IP ASM  inspect SFTP traffic on port 22 for Attacks like brute force?

Environment

  • BIG-IP ASM  
  • SFTP

Cause

To secure a virtual server using BIG-IP ASM an HTTP profile is required and for SFTP virtual server HTTP profile cannot be applied. Hence it's not possible to secure SFTP using ASM.

Recommended Actions

None

Additional Information

SFTP traffic can be secured using Protocol profile if BIG-IP AFM is provisioned in the system. For more information, refer SSH Proxy Security.
