Known Issue

Routes configured in a single configuration file (SCF) may be missing from the Linux kernel route table after you load the SCF.

This issue occurs when the following condition is met:

  • In an SCF, you modify a self IP address for a VLAN on which routes are also configured and then load the SCF.

The default gateway or static routes associated with the VLAN of the modified self IP address may be missing from the Linux kernel route table after you load the SCF file.

Impact

Linux host applications may not be able to connect when expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • F5 iHealth lists Heuristic H426079 on the Diagnostics > Identified > Low page.
  • The Linux host applications may not be able to connect when expected.
  • The Linux kernel route table does not have a default gateway or static route that is configured from the loaded SCF.

Workaround

To work around this issue, you can clear the running configuration before loading an SCF. To do so, perform the following procedure:

Impact of workaround: Performing this procedure on the active system causes traffic interruption.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Clear the running configuration by typing the following command:

    load sys default

  3. Load the SCF you want by using the following command syntax:

    load sys scf <SCF_filename>
