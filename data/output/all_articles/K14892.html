Known Issue

An active BIG-IP system synchronizes external datagroup updates to other systems in the device group, but iRules that use the external datagroups do not detect the updates.

This issue occurs when all of the following conditions are met:

  • You use an iRule that uses an external datagroup.
  • You have two or more systems in a device group with synchronized configurations.

Impact

iRules may cause unexpected behavior when a system fails over to another system in a device group.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After failover, iRules cannot access the same data within the configured external datagroups.

Workaround

To work around this issue, you can restart the tmm process after each external datagroup change. To do so, perform the following procedure:

Impact of workaround: The system temporarily goes offline.

  1. Log in to the standby BIG-IP system as the root user.
  2. From the command line, type the following command:

    bigstart restart tmm
