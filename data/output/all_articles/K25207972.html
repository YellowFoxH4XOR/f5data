Description

For deployments that use a Network Access webtop with the Minimize to Tray setting enabled in conjunction with the Network Access resource, only the pop-up window for the Network Access get minimized; the main webtop window stays open (i.e., it doesn't get minimized).

Environment

  • BIG-IP APM versions that use F5 Helper Apps for the browser technology. see K22991440 for more details.
  • Network Access webtop with Minimize to Tray enabled

Cause

this is a change in behavior due to F5's switch to using the F5 Helper Apps for both epi (endpoint inspector) and vpn functionalities for browser-based VPN
Bug ID 756970: Network access webtop is not minimized

Recommended Actions

None. This is by-design due to a change in behavior

Additional Information

In comparison, for earlier BIG-IP APM versions (14.0/13/12/11/10.x), in the case of Internet Explorer browser, it uses the ActiveX control. Deployments utilizing the same setup (i.e., 'Network Access' webtop with 'Minimize to Tray' enabled), the whole Network Access window gets minimized to the tray/taskbar, upon successful VPN connection.

Support for Google Chrome and Microsoft Edge browsers (and certain Mozilla Firefox versions) were only added in BIG-IP APM version 13.0, with the introduction of the F5 Helper Apps. see the Release Notes in the Related Content section below for more details.
