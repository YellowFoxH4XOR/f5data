Description

  • RADIUS server is not load balancing

Environment

  • APM
  • RADIUS AAA pool
  • AD AAA pool

Cause

  • AAA with pools, such as RADIUS pools or Active Directory pools
  • APM does NOT support AAA load balancing
  • APM must define each pool member with a different priority group
  • APM assigns each pool member with a different number for the pool member's priority group value
  • Priority group number increases automatically with each created pool member
  • A priority group can have only one AAA pool member
  • APM uses the AAA pool member with the highest priority group value for Auth/Query
  • Unless that pool member becomes unavailable
  • APM then uses the AAA pool member with the next highest priority group value.

Recommended Actions

  • None

Additional Information

  • Manual Chapter : About Pools > About priority group numbers
