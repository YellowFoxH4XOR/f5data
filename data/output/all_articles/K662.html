Topic

After you have configured the 3-DNS through the First-Time Boot/Setup utility and have configured the 3-DNS as one of the controllers in a redundant pair, you need to define it as such in the 3-DNS server statement. You can modify the server statement by editing the wideip.conf file or by using the Configuration utility.

Command line configuration

To define the 3-DNS server statement from the command line, use vi or pico and edit the wideip.conf file with the following syntax, where <IP address> is the IP address of the shared alias on the redundant system and <NIC IP address> is the external IP address for each system on the exp0 interface:

server {
type 3dns
address <IP address>
name <3dns_name>

[ remote {
secure <yes | no>
user <user name>
}]
[ interface { address <NIC IP address>
address <NIC IP address>
}]

Repeat this on the standby 3-DNS system.

Configuration utility configuration

To define the 3-DNS server statement from the Configuration utility, perform the following steps:

  1. From the Configuration utility navigation pane of the active 3-DNS, click 3-DNS Servers.
  2. From the toolbar, click Add 3-DNS Server.

    The Add New 3-DNS Server screen opens.

  3. In the 3-DNS Server Name box, type the name of the redundant pair.
  4. In the 3-DNS Server IP Address box, type the shared IP address of the 3-DNS redundant pair.
  5. From the toolbar, click Configure Interfaces.
  6. In the Interface Settings box, type the IP address of each 3-DNS.
  7. Click Update.
  8. Repeat these steps on the standby 3-DNS system.
