Description

When configuring your network access resource with IP exclude address space addresses. This works for Windows, Mac, and IOS users but fails for Android users.
 

Environment

Relevant environmental factors specific to the topic

  • BIG-IP APM provisioned
  • Network Access configured IPV4 Exclude Address Space
  • Android users
  • F5 Access

Cause

IPV4 Exclude Address feature is not supported by F5 Access for Android. This is not a limitation of BIG-IP APM, or F5 Access client, but a limitation of Android VPN Framework.

None
