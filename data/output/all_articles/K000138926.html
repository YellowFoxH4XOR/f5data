Description

How can the FEC (Forward Error Correction) setting for interfaces be changed on VELOS ?

 

Environment

  • VELOS
  • BX110
  • F5OS

 

Cause

FEC settings can be changed via the confd commands, and cannot currently be modified in the Web configuration utility

 

Recommended Actions

Connect to ssh on the partition, and issue the following command, where you can see the FEC options available. Just select the one appropriate for your needs.:

partition-2(config)# interfaces interface 2/2.0 config forward-error-correction
Possible completions:
auto disabled enabled
partition-2(config)#
