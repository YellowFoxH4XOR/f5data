Description

When accessing protected web applications, users encounter a Chrome browser prompt stating, "Look for and connect to any device on your local network." This occurs when the F5 BIG-IP ASM Bot Defense module's browser challenge logic triggers Chrome's Local Network Access (LNA) security feature. The prompt is observed when the Bot Defense profile is configured with browser verification and/or device ID fingerprinting, resulting in browser-initiated requests to localhost that Chrome interprets as attempts to access the local network.


Environment

BIG-IP ASM (Bot Defense)

Bot Defense profile with browser verification and/or device ID fingerprinting enabled

Chrome browser with LNA security feature enabled


Cause

The Chrome LNA prompt is triggered by a loopback (localhost) verification test within the Bot Defense browser challenge logic. This test causes the browser to attempt connections to localhost, which Chrome interprets as a request for local network access, resulting in the security prompt.


Answer/Recommended Actions

  1. Download and install the latest Browser Challenge Live Update file for your BIG-IP ASM version from the F5 download server.
  2. Wait for the 48-hour activation period after installation for the update to take effect.
  3. After activation, verify that:
    • The Chrome LNA prompt no longer appears when accessing protected applications.
    • No requests to localhost are observed in browser developer tools.


Additional Information

The update removes the specific browser challenge logic that triggers the Chrome LNA prompt.

Activation of the update is not immediate; a 48-hour window is required for the changes to take effect.
