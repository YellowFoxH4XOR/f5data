Description


Does F5OS support SNMPv3?
 

Environment

  • F5OS-C (VELOS)
  • F5OS-A (rSeries)
  • SNMPv3
     

Cause

None

 

Recommended Actions

  • For rSeries platforms, starting version F5OS-A 1.2.0 SNMPv3 support was added.
  • For VELOS platforms, SNMPv3 support is added starting F5OS-C 1.6.0.
