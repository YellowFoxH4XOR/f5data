K000164313: BIG-IP Azure Marketplace Image Deprecation

Type
Knowledge
Published
2026-11-26
Updated
2026-11-26
Source

Description

Microsoft Azure has scheduled deprecation of BIG-IP BYOL image version 17.5.103000 (f5-networks:f5-big-ip-byol:f5-big-all-2slot-byol) in the Azure Marketplace. Customers need to know whether HA instances must be rebuilt or can be upgraded in place.

This is an Azure Marketplace housekeeping process, not an F5 end-of-support notice. Existing BIG-IP systems are not affected.

Environment

  • Product: BIG-IP LTM
  • Version: 17.5.1
  • Deployment: High Availability (HA) pair

Cause

Microsoft Azure periodically removes older image versions from the Marketplace when newer versions are published.

Answer/Recommended Actions

Existing BIG-IP virtual machines continue to run after the deprecation date. Azure will not stop or delete them, and standard BIG-IP software upgrades remain supported. The impact is limited to deploying new VMs or scaling out VMSS instances from the deprecated image.

Plan of Action: 

  1. Upgrade BIG-IP software to the latest available point release using the standard upgrade process. The 2-slot image supports this, so the upgrade can be performed in the inactive slot.
  2. Plan a redeployment of VMs from the latest Marketplace image at a convenient time. This provides a current baseline image for future disaster recovery.
  3. To find the latest image, use the Azure CLI command recommended in the Azure notice:
    az vm image show --location [Insert location] --urn f5-networks:f5-big-ip-byol:f5-big-all-2slot-byol:latest
