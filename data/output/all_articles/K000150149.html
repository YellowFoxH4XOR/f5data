K000150149: Cannot login as 'root' user to Chassis Partition on VELOS Platform

Type
Support Solution
Published
2025-02-28
Updated
2025-02-28
Applies to
  • F5OS
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000150149

Description

Users are unable to log in as the 'root' user directly to a Chassis Partition on F5 VELOS systems.

 

Environment

  • F5OS-C (VELOS) with Chassis Partition.
  • The system appliance-mode is verified as disabled.
  • Attempts to reset the root password do not resolve the issue.

 

Cause

By design, direct 'root' login to Chassis Partitions is not supported on the VELOS platform. Root-level access must be performed indirectly through the System Controllers using specific commands.

Recommended Actions

To gain indirect root access to a Chassis Partition, follow these steps:

 

1. Identify the Partition ID:

Log in to the System Controllers using the 'admin' user and run the following command to list all the existing partitions and their corresponding Partition IDs:

# show partitions

 

2. Access the Partition Bash as 'root':

Log in to the System Controllers with the 'root' user account and use the following command format to access a specific partition's bash shell interactively:

# docker exec -it partition<ID>_cli bash

 

In above command, replace <ID> with the desired Partition ID (e.g., for Partition ID "2", use partition2_cli).

 

3. Once completed your tasks as 'root' user in Partition-level, you can use the below command to come back to the System Controllers console:

# exit
