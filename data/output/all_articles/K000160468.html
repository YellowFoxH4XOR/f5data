Description

You are unable to import an OpenAPI specification file (YAML) into BIG-IP ASM due to the error: "Unsupported OpenAPI version: 3.1.0. Swagger Parser only supports versions 3.0.0, 3.0.1, 3.0.2, 3.0.3."

Environment

  • BIG-IP ASM
  • Attempt import of an OpenAPI 3.1.0 YAML specification file

Cause

At the time of creation of this article, BIG-IP ASM does not support OpenAPI version 3.1.0. The Swagger Parser integrated with ASM only supports OpenAPI versions 3.0.0 through 3.0.3. Attempting to import a 3.1.0 specification results in a version incompatibility error.

Answer/Recommended Actions

  • Engage the application development team to generate or export the API specification in a supported OpenAPI version (≤ 3.0.3).

Additional Information

We already have an RFE in our backlog to provide support for OpenAPI 3.1.0
