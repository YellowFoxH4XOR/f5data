K33322221: BIG-IQ Application error for confpp: /config/ssh/sshd_config line 19: Bad ssh2 cipher

Type
Support Solution
Published
2020-05-05
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ 7000
Source
https://my.f5.com/manage/s/article/K33322221

Description

01070920:3: Application error for confpp: /config/ssh/sshd_config line xx: Bad SSH2 cipher spec 'chacha20-poly1305@openssh.com,aes256-gcm@openssh.com'

Environment

  • BIG-IQ 7.0.0

Cause

  • BIG-IQ base system is based on TMOS 12.1.2.
  • On TMOS 12.1.2 sshd doesn't support chacha20-poly1305@openssh.com and aes256-gcm@openssh.com.
    ?

Recommended Actions

  1. To verify on BIG-IQ 7.0 run the following commands.
     
  2. # rpm -qa |grep openssh
    Example output : openssh-5.3p1-104.el6_6.1.0.0.6.i686
     
  3. # strings /usr/sbin/sshd |egrep "chacha|aes"

    Example output :
    EVP_aes_256_cbc EVP_aes_256_ecb EVP_aes_192_cbc EVP_aes_192_ecb EVP_aes_128_cbc EVP_aes_128_ecb aes128-ctr,aes192-ctr,aes256-ctr,aes128-cbc,3des-cbc,aes192-cbc,aes256-cbc,rijndael-cbc@lysator.liu.se aes128-ctr,aes192-ctr,aes256-ctr,arcfour256,arcfour128,aes128-cbc,3des-cbc,blowfish-cbc,cast128-cbc,aes192-cbc,aes256-cbc,arcfour,rijndael-cbc@lysator.liu.se aes128-cbc aes192-cbc aes256-cbc aes128-ctr aes192-ctr aes256-ctr ssh_aes_ctr_iv: no context ssh_aes_ctr_init: wrong aes key length ssh_aes_ctr_init: cannot initialize aes encryption
