Description

Management provisioning adds extra memory to management and make memory available to control plane process. This article applies to management provisioning in vCMP host.

In non-vCMP devices, TMM is assigned most of the available memory to the device, and management provisioning takes the specified memory from TMM allocated memory as explained in K26427018.

In vCMP enabled host, TMM is assigned limited amount of memory and management provisioning take the memory allocated from the vCMP host  instead of TMM memory.

Environment

  • vCMP Host
  • Addition to control plane Memory.
  • Memory allocation

Cause

It may be required in certain situations to add extra memory to control plane processes in vCMP host. By default, TMOS is assigned small amount of memory as vCMP host itself doesn't process Guest destined traffic. Control plane processes in vCMP host still need to perform control plane tasks like Guest management, LACP trunk. STP, Cluster management.

Recommended Actions

Before performing management provisioning in vCMP host, please consider memory assigned to vCMP host which is reserved for guests and directly impacts guest memory allocation.
