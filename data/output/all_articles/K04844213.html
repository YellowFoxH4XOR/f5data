Known Issue

Border Gateway Protocol (BGP) routing may not match route tags when using route maps.

This issue occurs when all of the following conditions are met:

  • You have configured the dynamic routing protocol to use BGP.
  • You redistribute routes into BGP using a route map that matches route tags.

Impact

BGP routing table may not populate all IP address prefixes from other routing protocols.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The show ip bgp command output may not display all the routes after redistribution.
