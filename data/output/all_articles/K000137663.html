Description

  • After software upgrade or iRule configuration the following log line may appear:

    01220001:3: TCL error: /Common/<iRule_name> <HTTP_REQUEST_DATA> - More data required (line 1) invoked from within "HTTP::payload"
where <iRule_name> is the name of the iRule that generated the log message.
  • You may encounter this message in the following location: the /var/log/ltm file
  • Some HTTP transactions might fail with reset cause "BIG-IP: iRule execution error"

Environment

  • BIG-IP
  • iRules
  • 'HTTP::payload' or 'HTTP::payload length' TCL commands used in iRule

Cause

This is due to bug ID1144117

Recommended Actions

Do not use the 'HTTP::payload' or 'HTTP::payload length' TCL commands or upgrade your system to non-affected software version (17.1.1, 16.1.4, 15.1.9 at time of publication).

None.
