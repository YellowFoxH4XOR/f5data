Known Issue

This is the result of a known issue. If you use the Configuration utility on BIG-IP/3-DNS combination products and BIG-IP Link Controllers, the default gateway entry is converted to a default gateway pool. This means that the individual, static, default route that you entered will be converted into a default gateway pool with a single member. This has no effect on the routing behavior, and your routes should continue to function normally.

F5 Product Development tracked this issue as CR30783 and CR41803.
