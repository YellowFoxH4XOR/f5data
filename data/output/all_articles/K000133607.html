Description

The Bot Defense feature in the profile is injecting Javascript and the results are not as expected.

 

The indexing of the website is affected.

 

Environment

  • JavaScript is injected within <APM_DO_NOT_TOUCH> tags
  • Single Page Application ( SPA )

Cause

This behaviour is due to Bug ID 748851.

 

 

Recommended Actions

A new ASM internal parameter 'asm.inject_apm_do_not_touch' has been created to to prevent the <APM_DO_NOT_TOUCH> tag from being injected, thus allowing the applications to correctly be indexed.

 

The parameter is available from version 15.0.0 and above as well as 13.1.1.4 ( in 13.1.x ). However, the issue persists in version 14.1.x

 

The parameter is enabled by default, therefore, to disable, run the following command:

 

# tmsh modify sys db asm.inject_apm_do_not_touch value false

# tmsh save sys config


Note: For version 14.1.x an Engineering Hot Fix must be requested to add the internal parameter.
 

Additional Information

The <APM_DO_NOT_TOUCH> tag within which the Javascript is injected, is due to SPA ( feature ) being enabled.

 

These are referred to as SPA ajax hooks and Bot Defense injects these in to search engines.

 

The hooks are only to validate that the page is SPA.
