K000163453: Login to the BIG-IP Configuration Utility fails when the root account is used.

Description

Login to the BIG-IP Configuration Utility fails when the root account is used.

Environment

  • BIG-IP
  • BIG-IP Configuration Utility

Cause

The root account is intended for command-line and Advanced Shell access. It is not the appropriate account for accessing the BIG-IP Configuration Utility. Therefore, failure to log in to the Configuration Utility with root is expected behavior and does not, by itself, indicate a BIG-IP system fault.

Recommended Action

  1. Open a browser from a workstation with network access to the BIG-IP management IP address or a permitted self IP address.
  2. Access the Configuration Utility using:
    https://<management-or-self-IP-address>/
  3. Log in using the admin account or another account assigned the Administrator role.
  4. Do not use the root account for Configuration Utility login. Use root for Advanced Shell or command-line access only.
