Topic

FirePass and FirePass Virtual Edition (VE) use a highly modified version of OpenSSL 0.9.7d that includes modifications to address vulnerabilities and enhance security.

Note: For more information about the F5 security vulnerability response policy, refer to K4602: Overview of the F5 security vulnerability response policy.
