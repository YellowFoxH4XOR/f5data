Description

A pool Member sees the BIG-IP floating self IP, instead of the client's source IP.

Environment

  • BIG-IP Virtual Server
  • Virtual Server has Source Address Translation enabled (it's set to either SNAT or Automap).

Cause

Source Address Translation masquerades the incoming source IP address, rewriting it as either the floating Self IP or another specifically-configured IP address.

Recommended Actions

Disable the Source Address Translation, by setting it to 'None'. When doing so, you must ensure that the pool member server itself is properly configured to route its return traffic back to the BIG-IP's Floating Self IP.

Additional Information

K7820: Overview of SNAT features
K7336: The SNAT Automap and self IP address selection
