Known Issue

This is the result of a known issue. If you install cumulative hotfix Hotfix-BIGIP-9.3.1-66.0-HF5 or a later version of the cumulative hotfix, and auto last hop is disabled, the BIG-IP system can no longer communicate with IPv6 devices.

Note: For more information about auto last hop, refer to K11796: Overview of the Auto Last Hop setting.

F5 Product Development tracked this issue as ID 344365 and it was fixed in BIG-IP version 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

By default, auto last hop is enabled. If you no longer require auto last hop to be disabled, you can work around this issue by enabling auto last hop. To do so, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Click System.
  3. Click General Properties.
  4. From the Local Traffic drop-down menu, select General.
  5. Select the check box next to Auto Last Hop.
  6. Click the Update button.
