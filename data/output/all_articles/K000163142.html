K000163142: Ansible module bigip_ssl_certificate fails to upload the file with error "Failed to upload the file".

Description

The bigip_ssl_certificate Ansible module failed to upload a certificate to BIG-IP.
File receiver rejected the transfer because the Content-Range header specified 112040 bytes while the received buffer contained 112041 bytes.

Environment

  • BIG-IP
  • f5networks.f5_modules.bigip_ssl_certificate
  • Ansible collection version 1.42

Cause

A defect in Ansible collection version 1.42 caused the certificate upload request to generate an incorrect Content-Range byte count. The BIG-IP REST file receiver detected that the declared chunk length was one byte smaller than the actual received buffer and rejected the transfer, resulting in Failed to upload the file.

Answer/Recommended Actions

Upgrade the F5 Ansible collection to version 1.44.0 or later, once available.
