Description

Sometimes, software installation may get stuck or slow due to underlying hard drive issue. It is helpful to monitor disk I/O statistics by iostat command. Following command generates iostat statistics data every 2 seconds with timestamps.

 

# iostat -N -x 2 | awk '{OFS="\t";print strftime("%y/%m/%d %H:%M:%S"), $0}'

 

Here is an example. In the following example, we are going to install new software to HD1.2 (vg--db--vda-set.2.*). We can monitor "vg--db--vda-set.2.*" lines, as new software package files are to be copied to those devices.
