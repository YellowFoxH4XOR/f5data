Issue

The BIG-IP system runs a daily log rotation script between 3:00 a.m. and 4:30 a.m. local time, which reloads the syslog-ng process. As a result, at that time, the system logs a message to the /var/log/messages file similar to the following example:

syslog-ng[<PID>]: Configuration reload request received, reloading configuration;

In the log message example, note the following:

  • <PID> is the syslog-ng process ID.

To verify, check for logs in /var/log/messages.x for the last couple of days. Reload of the configuration occurs around the same time daily.

If the syslog-ng process reloads for another reason, such as when you run the bigstart restart command, the system writes the same log message to the /var/log/messages file. However, restarting the system does not log this error message.

Note: For more information about the log rotation script, refer to K7115: Managing log files on the BIG-IP system (9.4.x - 10.x).
