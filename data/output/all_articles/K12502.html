Topic

The Terminal Access Controller Access-Control System Plus (TACACS+) remote access authentication for BIG-IP system administration supports the Password Authentication Protocol (PAP) authentication method.

The ASCII, CHAP, ARAP, and MSCHAP TACACS+ authentication methods are not supported.
