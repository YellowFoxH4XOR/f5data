K000132780: BIG-IQ API - 2 different api call give me same id

Support Solution
Published
2023-02-28
Updated
2023-02-28
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000132780

Description

Duplicate REST API ID's found for objects with the same name.

 

Example:

 

There is a system default profile and monitor called "udp" using the same ID.

 

/mgmt/cm/adc-core/current-config/ltm/profile/udp/aaaa-bbbb-cccc-dddd

 

/mgmt/cm/adc-core/current-config/ltm/monitor/udp/aaaa-bbbb-cccc-dddd

 

Environment

BIG-IQ

Duplicate REST ID

 

Cause

Functioning as designed.

The REST API identifier is tied to the name of the object, so if the object name is the same, the id will be the same.

 

Recommended Actions

The REST ID's are not unique.

Use the full endpoint path if uniqueness is desirable for further logic processing.

None
