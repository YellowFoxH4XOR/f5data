Description

F5 support dynamic CRL check for SSL profile.
This article describes how dynamic CRL check works if a client certificate contains multiple CRLDP entry.

Dynamic CRL check does not support multiple CRLDP entry in a client certificate.

Dynamic CRL check takes only the first item in output of openssl X509 command, second item is not checked.

Environment

BIG-IP v15.1.x later

Cause

It is by design.
