Known Issue

This is the result of a known issue. The show interface gigabit <#> stats command will always display 0 (zero) for packet sizes of 1519 and greater. This is a display issue and does not affect the ARX system behavior.

Note: For information about the show interface command, refer to the ARX CLI Reference Guide.
