K4058: Configuring BIG-IP or 3-DNS systems to create a core file when the Configuration utility crashes

Topic

By default, programs that use setuid, such as the Configuration utility, do not write a core file to disk when they crash.

Starting in BIG-IP and 3-DNS 4.5.11 and 4.6.3, you can enable an internal variable to allow programs that use setuid to write core files to disk. This variable is disabled by default.

Important: Do not change an internal variable unless you are aware of, and accept, the risks outlined in K920: Overview of internal variables.

Enabling Configuration utility core dumps

To enable Configuration utility core dumps, type the following command:

bigpipe internal set dump_setuid_cores = 1

Disabling Configuration utility core dumps

To disable Configuration utility core dumps, type the following command:

bigpipe internal set dump_setuid_cores = 0
