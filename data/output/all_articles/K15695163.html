Description

This article provides an overview of the output of the command tmsh show gtm server. This command can be helpful in having visibility over how many BIG-IP DNS (GTM) monitors are in the queue for a particular big3d agent.

Environment

  • BIG-IP DNS
  • tmsh command line interface
  • GTM server
  • big3d agent

Cause

None.

Recommended Actions

To check for the statistics, run the command tmsh show gtm server <server name>.

Sample output would be similar to the following:

----------------------------------------------
Gtm::Server: GTMServer1
----------------------------------------------
Status
  Availability : available
  State        : enabled
  Reason       : iQuery communication established

Global
  Virtual Server Picks      0
  Connections               0

Throughput                 In     Out
  Bits/sec                  0       0
  Packets/sec               0       0

Prober Queue Depths     Total  Active  Pending
  Monitors                  0       0        0
  SNMP                      0       0        0
  Path                      0       0        0
  Trace                     0       0        0

Definition of items under the Prober Queue Depths are:

  Monitors
  SNMP
  Path
  Trace

Prober queue depth counters:

  Total
  Active
  Pending
