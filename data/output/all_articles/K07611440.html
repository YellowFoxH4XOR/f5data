Known Issue

The Configuration utility may stop responding or fail to load.

This issue occurs when the following condition is met:

  • An internal connection between the Configuration utility and MCP is de-allocated improperly, leaving pending transactions.

The Configuration utility communicates with MCP using internal connections, which are allocated and de-allocated as needed. If the internal connection is de-allocated improperly, future queries to MCP may fail. This issue occurs most frequently when you use the Configuration utility to delete users from the BIG-IP APM local user database.

Impact

The Configuration utility may not display pages correctly, and administrators may be unable to log in to the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Refreshing the Configuration utility produces a blank page.
  • You are redirected to the license activation page in the Configuration utility.
  • In the /var/log/ltm file, you observe messages similar to the following example:

    notice mcpd[7271]: 01070418:5: connection 0x59c442c8 (user admin) was closed with active requests

Workaround

To work around this issue, you can restart the tomcat process. Additionally, if this issue occurs when deleting a user from the BIG-IP APM local user database, you can work around this issue by deleting the user with the ldbutil command instead of the Configuration utility. To do so, perform one of the following procedures:

Restarting the tomcat process
Deleting a user from the local user database using the ldbutil command

Restarting the tomcat process

Impact of workaround: The Configuration utility is temporarily unavailable while the tomcat process restarts.

  1. Log in to the BIG-IP command line.
  2. To restart the tomcat process, type the following command:

    tmsh restart /sys service tomcat

Deleting a user from the local user database using the ldbutil command

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line as the root user.
  2. To delete the user, use the following command syntax:

    ldbutil --delete --uname="<user_name>" --instance="/<partition>/<instance_name>" 

    For example, to delete a user named Bob from the localusers instance in the /Common partition, type the following command:

    ldbutil --delete --uname="Bob" --instance="/Common/localusers"
