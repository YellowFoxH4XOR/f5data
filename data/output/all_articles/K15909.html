Topic

This article applies to BIG-IP 11.x. For information about other versions, refer to the following articles:

  • K36322151: List of disabled Tcl commands for iRules (12.x - 14.x)
  • K6319: List of disabled Tcl commands for iRules (9.x - 10.x)

The iRules feature of the BIG-IP system uses the industry-standard Tool Command Language (Tcl), version 8.4.6, to create scripts for managing local network traffic. However, there is a subset of Tcl commands that is disabled on the BIG-IP system. Therefore, you should avoid using these commands when writing iRules.

Description

The following list includes Tcl commands that are disabled in BIG-IP 11.x:

  • auto_execok
  • auto_import
  • auto_load
  • auto_mkindex
  • auto_mkindex_old
  • auto_qualify
  • auto_reset
  • bgerror
  • cd
  • dict
  • eof
  • exec
  • exit
  • fblocked
  • fconfigure
  • fcopy
  • file
  • filename
  • flush
  • gets
  • glob
  • http
  • interp
  • load
  • lrepeat
  • lreverse
  • memory
  • namespace
  • open
  • package
  • pid
  • pkg::create
  • proc (enabled in version 11.4.0 and later)
  • pwd
  • rename
  • seek
  • socket
  • source
  • tcl_findLibrary
  • tell
  • time
  • unknown
  • update
  • vwait
