Description

This article provides a comprehensive overview of FIPS validated BIG-IP platforms and licenses, including how to verify if your device is FIPS-enabled, special considerations for BIG-IP VE, and support details for iSeries, VIPRION, and VE models. It is designed to help users understand the requirements and verification steps for FIPS compliance across different BIG-IP environments. 

Environment

BIG-IP iSeries hardware platforms
BIG-IP VIPRION hardware platforms
BIG-IP Virtual Edition (VE)
BIG-IP LTM, APM, DNS, ASM modules
FIPS 140-2 and 140-3 Full-Box FIPS add-on licenses
FIPS 140 Level 1 Virtual add-on license

 

Cause

 

FIPS (Federal Information Processing Standards) compliance is required for certain environments to meet regulatory and security standards. F5 offers FIPS validated solutions for both hardware and virtual platforms, but proper licensing and configuration are essential to ensure compliance. Verification steps may differ between hardware and VE, and cosmetic issues may affect how FIPS status is displayed in VE environments.

Answer/Recommended Actions

1. FIPS Validated Platforms and Licenses

  • Platform FIPS (Full-Box FIPS Add-on License):
    • Applies to specific hardware platforms (iSeries, VIPRION) and BIG-IP VE with the appropriate FIPS add-on license.
    • For a list of validated platforms and versions, see the official F5 Certifications page.
    • VIPRION and iSeries: Both can be FIPS validated if the Full-Box FIPS add-on license is installed and the FIPS installation kit (tamper-evident stickers) is applied.
    • BIG-IP VE: Requires a FIPS 140-2 or 140-3 Level 1 Virtual add-on license.

2. How to Check if Your Device is FIPS-Enabled

  • GUI:
    • Navigate to System > License > Active Modules.
    • If "FIPS" is listed in Active Modules, your device is licensed for FIPS.
    • Reference: K000151998 How to verify if the device is licensed with FIPS?
  • CLI:
    • Run: tmsh show sys license
    • Look for "FIPS" in the output.
    • For VE, check the DB variable:
      tmsh list sys db security.fips140.compliance
      If the value is "true", FIPS mode is activated.
    • Reference: K34409208 FIPS feature does not show up as Active Module in BIG-IP VE license
  • Additional CLI Checks:
    • tmsh run util fips-util info
    • fips-util -v info
    • tmsh show /sys crypto
    • tmsh show /sys crypto fips
  • File Check:
    • cat /config/f5_public/fips.conf
    • If the response is 1, FIPS mode is enabled.
  • Log File Validation (VE and others):
    • Check /var/log/tmm*` for entries like:
      • "OpenSSL is initialized in FIPS mode."
      • "FIPS 140 Compliance is licensed"
    • Reference: K34409208 FIPS feature does not show up as Active Module in BIG-IP VE license

3. Supported Models and End of Support

  • iSeries and VIPRION: Only supported for FIPS past EoTS if the FIPS Addon license is present.
    • Reference: K9476 The F5 hardware/software compatibility matrix
    • Reference: K000139937 BIG-IP 15.1.x and 16.1.x are reaching End of Technical Support
  • VE: Supported with FIPS Addon license as described above.
