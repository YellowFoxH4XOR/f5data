Description

When attempting to perform a clean device install using the PXE boot method, the install fails to progress after 
> Loading /f5os-a/images/pxeboot/vmlinuz... ok 
> Loading /f5os-a/images/pxeboot/initrd.img...

Environment

BIG-IP rSeries Platform
Attempting clean install via PXE environment

Cause

Device is timing out before competing file transfer of the second file.

This is being tracked as ID1315381

Recommended Actions

In order improve the data transfer rate to the device, the following items should be checked:

  • TFTP server has adequate bandwidth to the Management interface
  • TFTP storage device being used has adequate read performance
  • Ensure there are no hubs or limiting network devices between the TFTP and Management port

You should also ensure that your PXE-boot environment distributes up-to-date versions of syslinux.efi and ldlinux.e64. The binaries available at kernel.org have been found to suffer from slow TFTP transfer speeds which may contribute to this issue. Modern Linux distributions ship with updated versions that offer improvements in TFTP transfer speeds.

Additional Information

A clean install from a USB drive removes all the networking issues and may be quicker. For more information refer to the Clean installation using a USB flash drive section of the Install or Upgrade Software chapter of the F5 rSeries Systems manual.

As an enhancement tracked by ID1975797, F5 will be providing a recommended set of syslinux.efi and ldlinux.e64 binaries in the tftpboot directory of F5OS ISO images. These should be available starting with the F5OS v2.0.0 release.

If there is still an issue with adequate bandwidth then please collect /var/log/platform/* as well as a full PXE transcript and qkview to allow further research.
