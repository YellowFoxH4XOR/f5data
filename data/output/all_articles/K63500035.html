Description
After upgrading, MySQL failed to initialize with the error messages similar to the following example observed in /var/log/mysql.out log file:

May 26 14:30:27 Setting up MySQL
May 26 14:30:32 waiting for mysql to set up user defined functions ...
May 26 14:30:32   installing UDF functions for ASM and AVR
ERROR 1125 (HY000) at line 1: Function 'inet6_ntop' already exists
May 26 14:30:35 Setting up MySQL AVR/UDF functions failed
May 26 14:30:35 Setting up MySQL database failed.
 

Environment

  • BIG-IP
  • Module that depends on MySQL functionality (for example, ASM) is provisioned
  • System upgrade

Cause
After upgrading, some essential user defined functions (UDF), especially for AVR, in MySQL that must be installed during the initialization are already existed. This will cause the initialization of the MySQL failed.

Recommended Actions

To workaround this issue and make the system running properly, follow the steps below.

  1. Run the following command to backup the initialization script:

    # cp /var/avr/create_udf.sql /home/create_udf.sql_backup

  2. Run the following commands to make sure there's protection mechanism during the initialization when installing the UDFs:

    # for fn in $(cat /var/avr/create_udf.sql | awk '{print $3}'); do echo "DROP FUNCTION IF EXISTS $fn;" >> /home/create_udf.sql; done
    # cat /var/avr/create_udf.sql >> /home/create_udf.sql
    # cat /home/create_udf.sql > /var/avr/create_udf.sql
    # rm -f /home/create_udf.sql

    Note: Please run the above 4 commands only once in order. Running them multiple times will make the initialization script inconsistent. If you run into such situation, restore the backup on step 1 above by using the following command and then try the above 4 commands again:

    # cp /home/create_udf.sql_backup /var/avr/create_udf.sql

  3. Run the following command to restart the system services:

    # bigstart restart

    Important: This will restart ALL of the system services and your application traffic will be terminated during the restarting.
