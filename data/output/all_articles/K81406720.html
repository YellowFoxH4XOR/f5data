Topic

How to enable/disable bash access

Description

This article provides steps to enable or disable bash access to the system. 
 


Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have root access to the BIG-IP command line.
  • You have administrative access to the BIG-IP command line.


Procedures

The following procedures will allow you to check the status of bash on the system and enable or disable if desired.

  • Check the status of Bash.
  • Enable Bash access.
  • Disable Bash access.

Check the status of bash

The following procedure will allow you to check the status of bash access to the system.

Impact of procedure: Performing the following action should have no negative impact on your system.

  1.  Log in to the Traffic Management Shell (tmsh) by typing the following command:
    tmsh
  2. Run the following command to view the status of bash access on the system.
    list /sys db systemauth.disablebash 

    The output should look similar to the following:
    root@BIG-IP(Active)(/Common)(tmos)# list sys db systemauth.disablebash
    sys db systemauth.disablebash {
        value "false"
    }


Enable bash access.
 

The following procedure can be used to enable bash access on the system.

Impact of procedure: Performing the following action should have no negative impact on your system.

  1.  Log in to the Traffic Management Shell (tmsh) by typing the following command:
    tmsh
  2. Run the following command to enable bash access on the system.
    modify /sys db systemauth.disablebash value false
  3. Run the following command to verify the status of bash access on the system has been changed,
    list /sys db systemauth.disablebash 

    sys db systemauth.disablebash {
        value "false"
    }


Disable bash access.
 

The following procedure can be used to disable bash access on the system.

Impact of procedure: Performing the following procedure will prevent users from having bash access to the system, but should not have a negative impact on your system.

  1.  Log in to the Traffic Management Shell (tmsh) by typing the following command:
    tmsh
  2. Run the following command to disable bash access on the system.
    modify /sys db systemauth.disablebash value true
  3. Run the following command to verify the status of bash access on the system has been changed,
    list /sys db systemauth.disablebash 

    The output should look similar to the following:
    sys db systemauth.disablebash {
        value "true"
    }

    You can also attempt to change from tmos to bash by typing bash. If disabled you will see the following:
    root@BIG-IP(cfg-sync Disconnected)(Active)(/Common)(tmos)# bash
    bash access has been disabled
