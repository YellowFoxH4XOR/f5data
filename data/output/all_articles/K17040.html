Known Issue

The Traffic Management Microkernel (TMM) may restart when processing HTTP traffic for a connection flow that has been suspended by an iRule.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server to process HTTP traffic.
  • The virtual server references an iRule that processes a connection by using the following flow of execution:

    • The iRule executes a command that temporarily suspends traffic processing
    • Once suspended, the iRule executes the HTTP::disable command

Impact

TMM restarts and temporarily fails to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.

Workaround

There is no workaround. To avoid this issue, you can avoid using the HTTP::disable command while a command suspends iRule processing.
