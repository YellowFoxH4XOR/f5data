Issue

Old Behavior

In versions prior to 11.6.0, BIG-IP Virtual Edition (VE) instances within Amazon Web Services (AWS) environments have the root user account enabled by default.

New Behavior

Beginning in BIG-IP 11.6.0, the root user account is disabled by default for BIG-IP VE instances within AWS environments.

Impact

Attempts to log in as the root user for a BIG-IP VE instance fail, and users receive an error.

Recommended Actions

If you want to gain Advanced Shell (bash) access to the BIG-IP VE instance, you can log in to the Traffic Management Shell (tmsh) with a user account that has Administrator role credentials, then type bash to access the bash prompt.
