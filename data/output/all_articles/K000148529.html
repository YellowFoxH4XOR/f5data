Description

You may encounter a situation where AdvWAF is blocking due to a violation it refers to as Expired timestamp

Environment

The BIG-IP AdvWAF uses a default setting for the timestamp in the cookie of 600 seconds. When you review the Event Log you should see something similar to this...

Cause

The system checks that the timestamp in the HTTP cookie is not old. An old timestamp indicates that a client session has expired. If it has expired the AdvWAF blocks the expired request. To do this the timestamp is extracted and validated against the current time. If the timestamp is expired, and it is not an entry point, the system issues the Expired Timestamp violation.

Doing this prevents using other users' credentials to access the web site or other illegal use of the web site's resources which are limited by a usage time. This provides session hijacking mitigation.

Recommended Actions

In the event that this block is not acceptable for your network there are a couple of ways to deal with it...

  1.  In the GUI go to Security ›› Application Security : Policy Building : Learning and Blocking Settings :: Cookies and disable the setting by unchecking the Block box if this temporary while you investigate the issue. It can also become a permanent setting if it is deemed as the best way to handle the situation. If that becomes necessary then also uncheck Alarm and Learn if they are checked.
  2. In the GUI go to Security ›› Options : Application Security : Advanced Configuration : System Variables :: cookie_expiration_time_out and adjust the time setting. This would be the preferred way to deal with the situation, if the traffic in question is known to be good and the situation cannot be dealt with in another way. Such as correcting the behavior that is causing the long time periods.
    1. Review the violation, and others like it if they are available. Use the Time Passed Since Expiration Period Ended as the reference point for adjusting the time.
    2. In the screenshot example it shows 3318 seconds. Other events may or may not be similar. Taking those events in to consideration, and working with any possible outliers that may not fall along with the others, adjust the setting accordingly
