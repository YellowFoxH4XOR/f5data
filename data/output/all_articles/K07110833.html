Description

Searching IPv6 addresses using "::" string is not possible in GUI LTM->Virtual Server List search engine

Environment

  • IPv6
  • BIG-IP
Cause

Due to some cosmetic issue Searching IPv6 addresses using "::" string is not possible
See also: ID1043013

Non-working scenarios:
  • If I search with shortened IPv6 2a00:15e4:5f1:de::11 address - search is not working
  • If I search with part of IPv6 address using :: in it 2a00:15e4:5f1:de:: - search is not working
  • If I search with part of IPv6 address in it 2a00:15e4:5f1:de:0 - search is not working
  • If I search with part of IPv6 address in it 2a00:15e4:5f1:de:0:0:0 - search is not working

Recommended Actions

The search of IPv6 address is possible while using address like in following examples:
  • If I search with full IPv6 address set for VS 2a00:15e4:5f1:de:0:0:0:11 - search is working
  • If I search with part of IPv6 address set for VS 2a00:15e4:5f1:de - search is working
  • If I search with part of IPv6 address set for VS 2a00:15e4 - search is working
