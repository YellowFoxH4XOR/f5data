K000152437: OCSP stapling not working for certain issuers, but working with openssl test

Type
Support Solution
Published
2025-07-07
Updated
2025-07-07
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000152437

Description

A certificate is configured with OCSP monitoring enabled, the Issuer Certificate is configured correctly, but the "Status" shows "OCSP Response Error: Request unauthorized."


Environment

  • BIG-IP with LTM
  • The OCSP validator is configured with the default Request Signing "Hash Algorithm" (SHA256)


Cause

The OCSP server responds with an "unauthorized (6)" response status because it cannot handle the BIG-IP's SHA256 request.



Recommended Actions

Change the Request Signing "Hash Algorithm" in the OCSP object to "SHA1".
