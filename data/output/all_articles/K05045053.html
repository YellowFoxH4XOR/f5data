Description

When attempting to ping a Virtual Address you receive no response, despite the Virtual Address being enabled for ICMP.

Environment

  • BIG-IP version 15.1.0, 15.1.1, 16.0.0
  • Virtual Address object has ICMP enabled
  • Virtual Address also has a matching snat-translation address

Cause

Due to ID948757, snat-translation addresses may fail to reply to ICMP echo requests. If the snat-translation address matches a Virtual Address, this can also cause the Virtual Address to fail to reply.

Recommended Actions

  1. Upgrade to a version ID948757 is fixed in
