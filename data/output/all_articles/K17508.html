Known Issue

BIG-IP AFM may produce a 'The requested user role partition (admin Common) was not found' message.

This issue occurs when the following condition is met:

  • You use either of the following Configuration utility locations to search for a non-existent profile:
    • Security > Protocol Security > Security Profiles
    • Security > DoS Protection > DoS Profiles

Impact

This issue is cosmetic; the message displays when there are no matches for the specified search string.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When there are no matches for the specified search string, the Configuration utility displays a message similar to the following example:

    Could not fetch list of profiles. 01020036:3: The requested user role partition (admin Common) was not found.
