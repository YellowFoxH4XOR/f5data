K000149557: [F5OS] admin user fails to log into GUI/CLI, CLI gives error "Failed to connect to server"

Type
Support Solution
Published
2025-01-30
Updated
2025-06-24
Applies to
  • VELOS Platforms
  • rSeries Platforms
  • F5OS
  • F5OS-C: 1.6.0, 1.6.2, 1.6.1
  • F5OS-A: 1.4.X, 1.5.2, 1.5.1, 1.5.0, 1.4.0
Source
https://my.f5.com/manage/s/article/K000149557

Description

Upgraded F5OS-A or F5OS-C to 1.8.0, then unable to go to confd mode in CLI and getting following error:

Failed to connect to server

Checking the log with below command, you can see this error message:

F5OS-A: tail -1 /var/F5/system/log/confd.log
F5OS-C controller: tail -1 /var/confd/log/confd.log
F5OS-C pattition: tail -1 /var/F5/partition<x>/log/confd.log
<CRIT> DD-MMM-YYYY::hh:mm:ss.xxxx appliance-1 confd[<PID>]: - Internal error: Startup failed; probably due to incorrect WebUI settings in confd.conf

Environment

  • F5OS-A v1.4.x 1.5.0-1.5.2
  • F5OS-C v1.6.0-1.6.2
  • The system has been upgraded to v.1.8.0 and then downgraded.

Cause

  • Bug ID 1712009

Recommended Actions

  1. First your upgrade is fully succeeded: K000149570: [F5OS-A] Upgrade failure lost access to GUI/CLI as admin and booted from 1.8.0.
  2. then Follow the workaround written in Bug ID 1712009
