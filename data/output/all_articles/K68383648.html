K68383648: ASM does not generate event log after software upgrade

Source
https://my.f5.com/manage/s/article/K68383648

Description
After an upgrade,  BIG-IP ASM is unable to display *any* event logs, unless they are searched for by support ID.

Environment

  • BIG-IP ASM 
  • Event Logs

Cause
Bug ID 746682: ASM unable to display *any* event logs, unless they are searched for by support ID

Recommended Actions

As a workaround, you may follow the below procedure. 

1. Run the below command to set the REQUEST_LOG_CLEARED.request_log_id to 0

# mysql -t -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "update PRX.REQUEST_LOG_CLEARED set request_log_id=0"

or 

2. Reset the value in PRX.REQUEST_LOG_CLEARED.request_log_id to use the max value in PRX.REQUEST_LOG.id to allow ASM to display the latest log events. 

# mysql> UPDATE PRX.REQUEST_LOG_CLEARED SET PRX.REQUEST_LOG_CLEARED.request_log_id = (SELECT MAX(PRX.REQUEST_LOG.id) FROM PRX.REQUEST_LOG);

# mysql> DELETE FROM PRX.REQUEST_LOG_PROPERTIES WHERE PRX.REQUEST_LOG_PROPERTIES.request_log_id NOT IN (SELECT PRX.REQUEST_LOG.id FROM PRX.REQUEST_LOG);
