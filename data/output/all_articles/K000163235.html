K000163235: The BIG IQ is not allowing us to configure an encrypted backup

Type
Support Solution
Published
2026-09-08
Updated
2026-09-08
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.2
Source
https://my.f5.com/manage/s/article/K000163235

Description

On BIG-IQ VE 8.4.2, encrypted backup schedules for the BIG-IQ itself failed with `400 Bad Request: key length not 128/192/256 bits`, while unencrypted backups succeeded. Creating a new encrypted schedule and converting an existing schedule to encrypted both succeeded after restarting `restjavad`.

 

Environment

- BIG-IQ VE version 8.4.2.

- Backup schedules were configured for the BIG-IQ system itself.

- Unencrypted backup schedules completed successfully.

- Encrypted backup schedules used an administrative account and a passphrase.

- An equivalent encrypted backup configuration using the same passphrase worked on a separate BIG-IQ system.

 

Cause

A transient fault or invalid runtime state in the BIG-IQ `restjavad` secure-storage/backup processing caused the stored encryption passphrase to be processed as key material with an unsupported length. This produced the `Key length not 128/192/256 bits` error during passphrase decryption. Restarting `restjavad` cleared the condition and restored successful encrypted backup processing. The deeper reason the invalid state occurred was not determined.

 

Answer/Recommended Actions

- Restart `restjavad` on the affected BIG-IQ when this specific encrypted-backup error recurs, following the applicable operational procedures.

- Verify that a newly created encrypted backup schedule completes successfully.

- Verify that the existing backup schedule can be changed to encrypted and completes successfully.

- Monitor subsequent scheduled encrypted backups for recurrence of the key-length error.

 

Additional Information

- KB K000163017 was referenced in the case as describing the encrypted-backup key-length behavior.

- Do not include the actual backup passphrase when creating support cases or diagnostic data.
