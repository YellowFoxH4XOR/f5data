Description

In software versions prior to 13.0, when setting up a BIG-IP DNS Redundant System, the GUI allows you to create a GSLB server Product of BIG-IP System (Redundant) where you can find options to add the IP address of the server under the address List setting and IP addresses of the back up system under the Peer Address List setting.

These options are no longer available in version 13.0 and above.

 

Environment

BIG-IP DNS
Configuration Utility (GUI)
Redundant System
Software version v13.0 or above

Cause

Changes were introduced from software version 13.0, when Setting up a BIG-IP DNS Redundant System.

The GSLB server product type BIG-IP System (Redundant) has been replaced with BIG-IP System and a new tab called Devices for the GSLB Server has been introduced where both the IP address of the server and the backup system are now configurable.

Recommended Actions

To Configure the IP address of the server and the backup system in version 13.0 and above:

1- Navigate to DNS ›› GSLB : Servers : Server List

2- Select or create the Server object

NB: make sure the product type is BIG-IP System

3- Under the Devices tab, add two devices (one that represents the active system and one that represents the standby system)
