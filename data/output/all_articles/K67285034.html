Description

The BIG-IP system may reset connections with a reset-cause of  "Unexpected IVS Result" when a request-adapt profile with "service-down-action reset" configured and no pool members are available for internal virtual server configured in the request-adapt profile.

Environment

  • Virtual server is configured with request-adapt profile 
  • The configured request-adapt profile is configured with internal virtual server
  • The internal virtual server has no available pool members

Cause
This is the expected result when configuring a request-adapt profile for "service-down-action reset" and when no pool members are available for the internal ICAP virtual server

Recommended Actions

  1. Troubleshoot connectivity to the ICAP servers configured in the request-adapt profile

Additional Information
The Configuring Content Adaptation for HTTP Requests and Responses chapter of the BIG-IP Local Traffic Manager: Implementations guide
