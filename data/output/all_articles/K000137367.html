K000137367: APM - DOC - DUO Universal Prompt On MACs Fail after 10 Seconds

Type
Support Solution
Published
2023-12-21
Updated
2023-12-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K000137367

Description

Mac users using edge client version 724x with an IdP configured with DUO's Universal Prompt 2FA may attempt to login and see the login page again


Environment

  • Mac OS various versions
  • APM Edge Client version 7242
  • IdP with DUO configured for Universal Prompt

Cause

bz 1328933 - a 10 second hardcoded timeout value causes the login page to be displayed again


Recommended Actions

Ensure you are using the latest edge client version or open a support case to get an Edge Client that has bz 1328933 included


Additional Information

  • Users have 10 seconds to approve DUO's prompt
  • DUO is sunsetting the traditional prompt
  • Configuring APM and DUO to use the new Universal Prompt
    • Getting Started at DUO - https://duo.com/docs/f5bigip-web
    • Configuring APM - https://community.f5.com/t5/technical-articles/apm-configuration-to-support-duo-mfa-using-irule/ta-p/283971
