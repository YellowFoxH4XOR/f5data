Issue

Error Message

1140101:6: Overdog daemon shutdown

For example:

1140101:6: Overdog daemon shutdown.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP system is shutting down or has begun restarting.

The overdog process monitors the high availability table for failover action types of restart, restart-all, or reboot, and the process cannot be managed using the TMOS Shell (tmsh).

Impact

While the overdog process restarts, configured failover action types of restart, restart-all, or reboot do not occur.

Recommended Actions

None
