K000150260: Procedure for failing a single virtual server IP from the active to the standby device

Description

  • This procedure is useful for troubleshooting failover scenarios.
  • This procedure creates guidance for sending just 1 virtual IP address from the active device to the standby device.
  • The standby device is still available as standby for all the other vips if the active device needs to go to standby.

Environment

  •  BIG-IP HA pair currently in Active/Standby state
  • Need to fail 1 virtual IP over to standby device

Cause

 N/A

Answer/Recommended Actions

  1. Create a 2nd traffic-group which has a different floating MAC address.
    1. Device Management > Traffic Groups > Create a new traffic group
  2. Change the desired virtual server address to use the new Traffic Group.
    1. Local Traffic > Virtual Servers > Virtual Address List and select the virtual address that you want to float separately.
    2. Designate the new Traffic Group for this Virtual Address
  3. After syncing the changes between the HA pair, you can manually force the failover scenario for just that traffic group by checking the traffic group selection box and by using the "Force to Standby" button
    1. Device Management > Traffic Groups
    3. After failing over, both devices will show active but will be hosting different failover objects.
