Known Issue

The BIG-IP system may fail to provision BIG-IP Analytics. This issue occurs when the following condition is met:

  • You attempt to provision the BIG-IP Analytics, LTM, ASM, and WebAccelerator modules together on a BIG-IP 3600 platform

Impact

BIG-IP Analytics cannot be deployed on the BIG-IP 3600 platform.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP 3600 platform fails the provisioning attempt and reports the following error message in the Configuration utility:

    01071008:3: Provisioning failed with error 1 - 'Memory limit exceeded. 4568 MB are required to provision these modules, but only 3960 MB are available.'

  • The BIG-IP 3600 platform fails the provisioning attempt and logs messages to the /var/log/ltm file that appear similar to the following example:

    Memory limit exceeded. 4568 MB are required to provision these modules, but only 3960 MB are available.
    Provisioning (validation) failed.
    Provisioning failed with error 1 - 'Memory limit exceeded. 4568 MB are required to provision these modules, but only 3960 MB are available.'
