Description

This article describe the procedure for fixing a failure to upload BIG-IP configuration

Environment

  • Upgrade of BIG-IP from v12.1.3 to v13.1.3.6
Cause

The root cause is a non valid settings of the media-sfp value while mcpd is not running.
Due to mcpd not running, the configuration cannot be save via either GUI or TMSH

Recommended Actions

  1. Backup /config/bigip_base.conf:

    # cp /config/bigip_base.conf /config/bigip_base.conf.bak

  2. Using vi or nano editor, edit the bigip_base.conf and remove the media-sfp line:
    net interface 5.0 {
        lldp-tlvmap 114552
        media-sfp 1000T-FD       <== remove this line
    }
  1. Save and exit
  2. Validate the configuration:

    # tmsh load sys config verify

  3. If no errors observed, load the configuration:

    # tmsh load sys config
