Known Issue

This is the result of a known issue. An nPath configuration with connection mirroring enabled on the virtual server does not work correctly.

When an nPath configuration uses a virtual server with connection mirroring enabled, the mirrored connection information is not correctly passed to the standby unit. As a result, all nPath connections that use the virtual server with mirroring enabled are lost when the active unit fails over to the standby unit.

F5 Product Development tracked this issue as CR90893, and it was fixed in BIG-IP 9.4.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
