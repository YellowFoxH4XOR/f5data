K000147758: Do Fast ACLs work on child tenants?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Multi-Cloud Network Connect
Source
https://my.f5.com/manage/s/article/K000147758

Description

I want to know if the Fast ACLs (access control lists) work with child tenants.

Environment

  • Fast ACLs

Resolution/Answer

  • No, Fast ACLs do not work with child tenants.

Cause

In order to make it work, child tenants must have a dedicated VIP assigned.

Additional Information
