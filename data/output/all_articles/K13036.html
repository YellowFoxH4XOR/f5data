Known Issue

Installation media connected by way of the USB port to a BIG-IP 1500 boots up the platform with no output to the serial console.

This issue occurs when either of the following two conditions is met:

  • A USB thumb drive is created with the mkdisk utility from a BIG-IP software version 10.2.2 or later ISO installation image.
  • A BIG-IP version 10.2.2 or later ISO is mounted on a CD/DVD-ROM.

And this issue occurs when all of the following conditions are met:

  • The USB thumb drive or USB CD/DVD-ROM drive is plugged into the USB port of a BIG-IP 1500 platform.
  • The BIG-IP system is rebooted using the USB thumb drive or USB CD/DVD-ROM drive as the boot device.

This issue occurs because the BIG-IP 1500 platform fails to configure its serial port properly and displays no output to the serial console.

The mkdisk utility is used to create a bootable USB thumb drive containing a BIG-IP software installation image. You can use this USB thumb drive to boot a BIG-IP platform, which serves as the installation source to install BIG-IP software. For more information about the mkdisk utility, refer to the Creating a Bootable USB Thumb Drive chapter in the BIG-IP Systems: Getting Started Guide.

Impact

You cannot upgrade the BIG-IP 1500 platform to BIG-IP version 10.2.2 or install version 10.2.2 using a USB thumb drive or USB CD/DVD-ROM drive.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • If the BIG-IP 1500 platform was previously powered off, the platform stops booting after the system logs the following messages on the serial console:

    System is booting, please wait...
    Press Ctrl-c to stop autoboot: 0
    kernel.core_uses_pid = 0
    kernel.core_pattern = /var/core/%e.sccp.core
    Host Console Shell --- Press ESC + ( for command menu.

  • If the BIG-IP 1500 platform was previously powered on and was reset or rebooted, the platform stops booting after messages that appear similar to the following example are logged on the serial console:

    SYSLINUX 3.11 0x4a399196 CBIOS Copyright (C) 1994-2005 H. Peter Anvin

Workaround

To work around this issue, you must complete the installation by using a USB thumb drive installation method, and before attempting to install, add the baud rate setting to the syslinux.cfg boot loader configuration file that resides on the affected USB thumb drive. To do so, refer to the  Creating a Bootable USB Thumb Drive chapter in the BIG-IP Systems: Getting Started Guide. Once you have created a USB bootable thumb drive, perform the following procedure:

Impact of workaround: None

Editing the boot loader configuration file on a Windows machine

  1. Plug the USB thumb drive into a Windows machine.
  2. Start the text editor application.
  3. Select File >> Open.
  4. Select All documents (*.*) from the file type drop-down menu.
  5. Locate the thumb drive and select the syslinux.cfg file.
  6. Click the Open button.
  7. Locate the line serial 0.
  8. Add a space followed by the baud rate 19200 to this line; it should look like serial 0 19200 after the edit.
  9. Select File >> Save.
  10. Exit the text editor.
  11. Eject the USB thumb drive.

Editing the boot loader configuration file on a Linux machine

Note: You can perform the following procedure on a BIG-IP system.

  1. Plug the USB thumb drive into a Linux machine.
  2. Create a temporary directory (for example, /mnt/thumb) by typing the following command:

    mkdir /mnt/thumb

  3. Locate the device name of the USB thumb drive (for example, /dev/sdc), and mount the USB thumb drive to the temporary directory by typing the following command:

    mount /dev/sdc /mnt/thumb

    Note: The mkdisk utility creates no partitions on the USB thumb drive. Therefore, when mounting the drive, the device name will appear as /dev/sdc, not /dev/sdc1.

  4. Edit the boot loader configuration file using a text editor of your choice:

    vi /mnt/thumb/syslinux.cfg

  5. Locate and modify the line serial 0 to appear as serial 0 19200.
  6. Save and exit the text editor.
  7. To unmount the USB thumb drive, type the following command:

    umount /mnt/thumb

  8. Unplug the USB thumb drive from the Linux machine.
