Description

  • By checking the K15934495, you may know that there are facilities defined for /var/log/secure.
  • So we are able to set up the remote syslog server log to send the /var/log/secure.

Environment

  • BIG-IP
  • Configuring the remote syslog for /var/log/secure

Cause

None.

Recommended Actions

You can use the below filter as an example, this filter will help you to send the local /var/log/secure logs to the remote syslog.

sys syslog {
    include "
        filter f_remote_loghost {
        facility(auth, authpriv);
    };
    destination d_remote_loghost {
        udp(\"192.0.2.10\" port(514));
    };
    log {
        source(s_syslog_pipe);
        filter(f_remote_loghost);        
        destination(d_remote_loghost);
    };
    "
}

Note: Replace the example address 192.0.2.10 with an IP address appropriate for your environment.
