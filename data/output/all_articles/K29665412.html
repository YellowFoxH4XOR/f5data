K29665412: Error Message : http_process_state_client_drain - Invalid action:0x1130a1 clientside ()

Type

Published

Updated

Applies to

Source

Description

The http_process_state_client_drain messages indicate that the HTTP proxy in the LTM was being passed a FIN before it has finished "draining" data from a buffer. Most likely this problem will be handled by the application or at the TCP level. 

Cause
This log is generated possibly when the client is terminating the connection before the LTM completes sending the data during a connection to a virtual server.

Recommended Actions

To investigate why the FIN or RST packet occurs from client-side:
  1. Enable the RST cause logging: K13223: Configuring the BIG-IP system to log TCP RST packets
  2. Take packet capture when the problem occurs: tcpdump -nei 0.0:nnnp host <client ip address> -s0 -v -w /shared/tmp/<file_name>.pcap

None.
