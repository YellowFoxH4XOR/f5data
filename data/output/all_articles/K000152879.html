K000152879: Some Automation Tools may fail working with a FIPS 140-3 Compliance-Enabled BIG-IP running v17.1.0.1+

Type
Support Solution
Published
2025-08-05
Updated
2025-08-05
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0, 17.1.2, 17.1.1, 17.1.X, 17.5.X, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000152879

Description

After upgrading your BIG-IP to version 17.1.0.1 and later with FIPS 140-3 Compliance Enabled, REST API connections to the Management Interface may fail. In affected scenarios, the TLS handshake is aborted immediately after the ServerHelloDone message, with the BIG-IP sending a FIN packet and closing the connection, and No errors are logged on the BIG-IP. Packet captures show that the connection is closed before the client can respond. 

Environment

  • BIG-IP LTM v17.1.2.2 and later
  • FIPS 140-3 Compliance Enabled (security_fips1403_compliance)
  • BIG-IP accessed via REST API (iControl REST)
  • A custom or third-party self-service Tools connecting to the BIG-IP

Cause

With FIPS 140-3 compliance enabled in BIG-IP v17.1.0.1 and later, all HTTP Clients connecting to the BIG-IP (e.g., via the Management Interface) must support the TLS "Extended Master Secret" extension as required by updated FIPS standards and implemented under Bug ID 1252093. If a client does not support this extension, BIG-IP will not fall back to legacy master secret negotiation and will abort the TLS handshake, resulting in immediate connection closure after TLS ServerHelloDone. 

Recommended Actions

  • Ensure all Clients/Tools connecting to BIG-IP Management via HTTPS/REST API support TLS "Extended Master Secret".
  • Update or reconfigure any self-service or Automation Tools to use a TLS library/version supporting "Extended Master Secret".
  • For legacy Clients that cannot be updated, consider alternative access methods or review if Non-FIPS-compliant configuration is acceptable.

Note: FIPS 140-2 Compliance is not available on v17.1.x+

Additional Information

For Troubleshooting purpose, you can follow the below recommendations:

  • Capture packets during handshake and verify if "Extended Master Secret" is present.
  • Review logs for related SSL/TLS negotiation failures.
  • Reference F5 article K000137600 for similar Automation Tool compatibility issues with FIPS 140-3.
