Topic

Use this template for a temporary way of quickly enabling/disabling Web Acceleration on a per user session basis, using a browser cookie, for debugging or performance benchmarking. This iApp creates a new virtual server using the same IP address (but different port) as the existing virtual server for which you want to enable or disable acceleration. The new virtual server sets or deletes the acceleration disable cookie when you browse to it.

Downloading the iApp template

Important: You must download the file. Do not copy and paste the contents.

  1. Go to the F5 Downloads site.
  2. From the Downloads Overview page, click Find a Download.

    The Select a Product Line page displays.

  3. From the Product Line column, click iApp-Templates.
  4. Read the End User Software License Agreement and either accept the license by clicking I Accept, or cancel the process by clicking Cancel.

    If you accept the End User Software License Agreement, the Select a Download page appears, which shows a table with the file name, product description, and file size details.

    Note: After you accept the End User Software License Agreement, the system will not present the agreement again for subsequent downloads that you perform during the same browser session.

  5. From the Filename column of the table, click the file named iapps-x.x.x.x.x.zip. For example, the file for the June 2016 iApp release is named iapps-1.0.0.405.0.zip.

    The Select a Download Method page appears.

  6. F5 supports the FTP, HTTP, and HTTPS protocols for downloading files from F5. Choose one of the three supported protocols listed by clicking the down arrow key.

    A pop-up window appears, prompting you to either open or save the file.

    Note: Some browsers save the file to a default location. You can review your specific browser's documentation to change the default location of where you want to save files.

  7. Select the option to save the file.

Installing the iApp template

  1. Unzip the zip file to a location accessible from your BIG-IP system.
  2. Log in to the BIG-IP Configuration utility.
  3. Click the iApp tab and clickTemplates.
  4. Click Import.
  5. Select the Overwrite Existing Templates box.
  6. Click Browse.
  7. Browse to the location where you saved the iApp file.
  8. Select the file named f5.accel_disable_by_cookie.vx.x.x that corresponds to the iApp version you want to install. For example, the file for the June 2016 release of this iApp is named f5.accel_disable_by_cookie.v1.0.0.

    Note: Refer to the previous Support Matrix section to choose the most current supported template for your BIG-IP software version.

  9. Click Upload.

When the upload completes, the iApp is available for use.
