K000161008: No HTTP method override recommendations for allowed URLs from the policy builder

Support Solution
Published
2026-04-28

Applies to

  • BIG-IP ASM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000161008

Description

HTTP request methods are missing from the allowed URL list after accepting learning suggestions in BIG-IP ASM, even though the "Learn Allowed Methods on URLs" setting is enabled. When a new HTTP method is detected and accepted via a learning suggestion, it is not added to the allowed methods for the relevant URL, and no override is created for the specific URL.

Environment

  • Product: BIG-IP ASM
  • Version: 17.1.3 (also observed in latest releases)
  • Setting: "Learn Allowed Methods on URLs" enabled in Learning and Blocking settings

Cause

This behavior is by design. When an allowed URL is created by the policy builder, the "Override policy allowed methods" option is not enabled by default. As a result, method override suggestions are not generated for that URL, even if new methods are detected in requests. There is an existing Request for Enhancement (RFE) tracked by ID1240509.

Answer/Recommended Actions

To ensure that HTTP method override suggestions are generated and accepted methods are added to the allowed list for specific URLs, follow these steps:

  1. Manually Enable "Override policy allowed methods" for URLs:
    • Edit the desired Allowed URLs in the ASM GUI.
    • Enable the "Override policy allowed methods" option for each relevant URL.
  2. Bulk Update via Database (Advanced/At Your Own Risk):
    • Identify the security policy ID:
    # mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "SELECT id,name,policy_name_crc from PLC.PL_POLICIES where name ='<add_security_policy_name_here';"

     

    • Enable the override for all URLs in the policy (replace 147 with your policy ID):
    # mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "UPDATE PLC.PL_OBJECTS SET flg_check_obj_methods = 1 WHERE policy_id = 147;"

     

    • Make a minor change to the security policy (e.g., update the description) and apply the change to ensure the update takes effect.
    • Verify in the GUI that the override option is enabled for the relevant URLs.

Important: Test these changes in a non-production environment or on a test policy before applying to production.

Additional Information

  • This is expected behavior based on the current ASM design.
  • The feature works as intended; method override suggestions are only generated if the "Override policy allowed methods" option is enabled for the Allowed URL.
  • There is no official fix at this time; the enhancement request is tracked under ID1240509.
