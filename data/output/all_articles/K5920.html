K5920: Tracking LDNS persistence information for a wide IP

Topic

Wide IP persistence specifies the number of seconds 3-DNS maintains a persistent connection for an LDNS server request. The persistence timer is reset with each additional LDNS request for the wide IP. LDNS persistence information is stored in 3-DNS memory and written to the /3dns/ldns.gz file every 3600 seconds by default. The time value is based on the timer_persist_cache global variable.

You can track LDNS persistence information for a specific wide IP by performing the following procedure:

  1. Log in to the 3-DNS command line.
  2. To dump the LDNS cache from memory to the /3dns/ldns.gz file, type the following command:

    3ndc dumpdb

  3. To view the contents of the /3dns/ldns.gz file, type the following command:

    gzcat/3dns/ldns.gz

    For example, the following output from the /3dns/ldns.gz file shows persistence information from LDNS IP address 10.10.10.10 to the www.wip.com wide IP:

    ldns {
address          10.10.10.10
cur_target_state 0
ttl              2419199
probe_protocol   icmp
connection {
wideip    "www.wip.com"
pool      "wip_pool"
vs        172.24.65.34:80
expires   1159302136 // 09/26/2006 13:22:16 (1 hits)
}
  4. Locate the expires line for the LDNS IP address you are tracking. The expires line represents the last time the LDNS queried the wide IP.

    In the following example, 1159302136 is the Unix timestamp, and 09/26/2006 13:22:16 is the UTC date and time of the last request from the LDNS server to the wide IP:

    expires 1159302136 // 09/26/2006 13:22:16 (1 hits)

  5. To determine the length of time that the persistent connection is valid, the wide IP persistence TTL time can be added to the expires time value.

    For example, if the wide IP persistence TTL value is 3600 seconds, add 3600 to the Unix timestamp 1159302136, and convert the value to UTC time, as follows:

    1159302136 + 3600 = 1159305736

    1159305736 is the Unix timestamp when the persistence record will expire.

Note: Use a Unix timestamp calculator to convert the Unix timestamp to UTC.
