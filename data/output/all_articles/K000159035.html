Description

namedGroups used with Cipher_Rule currently can only have the following values: “DEFAULT”, “P256”, “P384”, “X25519”.

Customer would like X25519MLKEM768 and X25519MLKEM768 to be added to the list.

 

Environment

AS3 with Cipher_Rule objects in use.

 

Cause

RFE ID2131617 Add PQC KEM support to the schema

None.
