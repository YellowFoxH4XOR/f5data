Description

You want to delete the qkviews that you have uploaded to iHealth.

Environment

  • F5 iHealth
  • qkview utility

Cause

None

Recommended Actions

To delete QKView files, you must first move them to the Hidden tab in iHealth. From the Hidden tab, you can select and remove files. To do so, perform the following procedure:

  1. Log in to iHealth.
  2. Select the QKView files that you want to delete.

    Important: Make sure you are not deleting QKView files being used in active cases or service requests.

  3. Above the QKView file list, select the Hide button. When prompted for confirmation, select Hide.
  4. Select the Hidden tab.
  5. Select the QKView files that you want to delete again.
  6. Select Remove. When prompted for confirmation select Confirm.

None
