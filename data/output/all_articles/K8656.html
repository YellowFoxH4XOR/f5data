Issue

If you attempt to install an SSL server certificate, and the private key you enter does not match the SSL server certificate, FirePass reports an error message that appears similar to the following example:

Error: writing RSA key. The certificate you entered does not match the private key

This behavior typically occurs when you mismatch two certificates (for example, entering the SSL certificate from the first certificate and the private key from the second certificate). In rare instances, this issue occurs when the Certificate Authority (CA) did not correctly issue the SSL certificate or private key.

If you are entering the SSL server certificate and the corresponding private key exactly as they were provided by your issuing CA, contact the CA to obtain a corrected SSL certificate or private key.
