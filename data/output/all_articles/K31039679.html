Description

The OWASP dashboard is not visible in older versions of AWAF

Environment

BIG-IP Advanced WAF

Cause

The OWASP dashboard was released in AWAF v15.0.0, it is not avaliable in older versions.

Recommended Actions

If the OWASP dashboard is required upgrade to at least AWAF v15.0.0
Release Notes : BIG-IP 15.0.0 New and Installation

Additional Information

**New in 15.0.0 :: ASM
OWASP Compliance Dashboard

The AWAF feature. The OWASP Compliance Dashboard details the coverage of each security policy for the top 10 most critical web application security risks as well as the changes needed to meet OWASP compliance. Using the dashboard, you can quickly improve security risk coverage and perform security policy configuration change
