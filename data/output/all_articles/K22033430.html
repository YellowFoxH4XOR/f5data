Description

When request-logging profile is attached to virtual server which has OneConnect and HTTP/2 profile, connection is terminated prematurely.
The virtual server appends characters to some client response.
 

Environment

  • BIG-IP
  • v13.1.x - 17.1.x (exclude: 15.1.9 and later &  16.1.4 and later)
  • Virtual server
    • HTTP/2 profile
    • OneConnect profile
    • request-logging profile 
 

Cause

  • Bug ID 1000561
 

Recommended Actions 

  • Follow work around in Bug ID 1000561.
