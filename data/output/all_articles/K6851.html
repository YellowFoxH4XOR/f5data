Topic

The BIG-IP ASM sets cookies in the HTTP response to the client request. The cookies are used to enforce elements in the security policy.

Note: For more information about BIG-IP ASM cookies, refer to K6850: Overview of BIG-IP ASM cookies.

When defining advanced Flows in the BIG-IP ASM security policy, you can configure the BIG-IP ASM Flow frame cookie to specify the index of the HTML frame targeted by the Flow by modifying the frame target setting.

By setting a frame target number for a specific Flow, you can configure the BIG-IP ASM to save referrer objects and dynamic values on that specific frame cookie number.

When setting a specific BIG-IP ASM Flow to frame target 5, the client will receive a cookie similar to the following example:

TSXXXXXX_5

The six X characters are a hexadecimal representation of the HTTP class name that holds the active policy.

A maximum of 32 frame targets can be used in the BIG-IP ASM. Frame targets should be configured between the numbers 0 to 31. A Frame target of 0 is used to clear the user session, and will erase the additional frame targets sent to the client browser.

Note: Beginning with BIG-IP ASM version 9.4, frame target number 15 is reserved for the DCV cookie.

Note: Once a Flow is created, it is not possible to change the frame target value without recreating the Flow.

To view the frame target value for a Flow, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Web Applications.
  4. Click the name of the web application you want to view.
  5. Under Web Application Properties, click the name of the active policy.
  6. From the menu, click Flows.
  7. Click the plus symbol (+) next to the entry point you want to edit.
  8. Click the entry point.

    The Frame Target value is listed under Flow Structure.
