Description
This is a quick overview of the "ng_export", "ng_import", and "ng_profile" commands and related arguments.   These commands can be used to move Access policies via Command line interface.


NOTES

  • when exporting with -t make sure to import with -t as well 
  • - t profile_access is the default so not specifying -t is like adding -t profile_access

ng_export

Access Profile Export utility <Version>

Usage: ng_export [-t|-type access_policy|profile_access|profile_api_protection] <name> <filename> [-p|-partition <partition>]
       
exported profile would be saved as /shared/tmp/type-<filename>.conf.tar.gz

  • -t (profile/policy type) == the access profile type
    • -t profile_access - This is the default and is for your profiles configured under Access --> Profiles / Policies --> Access Profiles (Per-Session Policies)
    • -t access_policy - This is for those policies configured under Access --> Profiles / Policies --> Per-Request Policies
    • -t profile_api_protection - This is for those profiles configured under Access --> API Protection --> Profile
  • -p (partition) == specifies the partition to import into
  • --logfile = creates an ng-import.log file located at /shared/tmp/apmom/uilogs/

ng_import

Access Profile/Policy Access Import utility <version>

Usage: ng_import [-s] [-t access_policy] <templatefile.conf.tar[.gz]> <new_name> [-p | -partition <partition>]

  • -s (Share) - like selecting "Reuse Existing Objects" in TMUI
  • -t (profile/policy type) -  the access profile type
    • -t profile_access - This is the default and is for your profiles configured under Access --> Profiles / Policies --> Access Profiles (Per-Session Policies)
    • -t access_policy - This is for those policies configured under Access --> Profiles / Policies --> Per-Request Policies
    • -t profile_api_protection - This is for those profiles configured under Access --> API Protection --> Profile
  • -p (partition) - specifies the partition to import into
  • --logfile - creates an ng-import.log file located at /shared/tmp/apmom/uilogs/


ng_profile

Profile/Policy Management Tool <Version>

Usage: ng_profile [-partition|-p <partition_name>] [-type|-t <type>] -command cparams

       -p <partition_name> or -partition <partition_name>: operating partition. Default: Common
       -t <type> or -type <type>: profile_access or access_policy. Default: profile_access
       -command: -list, -deleteall, -deletelisted, -copy
       cparams: see examples

ng_profile [-p <p>] [-t <t>] -list <name>[ <name_2>...]                     lists all shareable objects.
ng_profile [-p <p>] [-t <t>] -deleteall <name>[ <name_2>...]                deletes all shareable objects.
ng_profile [-p <p>] [-t <t>] -deletelisted <filename> <name>[ <name_2>...]  deletes only shareable objects listed in filename.
ng_profile [-p <p>] [-t <t>] -copy <existing_name> <new_name>               copies object under exisiting_name and heirs to new_name.
