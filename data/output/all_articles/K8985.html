Known Issue

This is the result of a known issue. Nodes or pool members that reach the connection limit or are otherwise unavailable, are not marked yellow in the Configuration utility.

When the BIG-IP system marks a node or pool member as unavailable, the node or pool member's status indicator is changed to yellow in the Configuration utility. Yellow status indicates that the node is enabled but is currently unavailable. For example, the BIG-IP system changes a node's status indicator to yellow when the number of concurrent connections to the node exceeds the value defined in the node's Connection Limit setting.

F5 Product Development tracked this issue as CR80815 and it was fixed in BIG-IP LTM 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

This issue still exists for the BIG-IP LTM 9.3 software branch.
