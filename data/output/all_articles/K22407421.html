Known Issue

The configuration fails to load if a DNS Express Zone name contains an underscore character ( _ ).

This issue occurs when all of the following conditions are met:

  • The Domain Validation setting is configured as None, Allow Underscores or idn-compatible.

    Note: The idn-compatible value is only available using the Traffic Management Shell (tmsh) and will display as None in the Configuration utility.

  • The configuration contains a DNS Express zone with an underscore in the name.

Note: The Domain Validation configuration path using tmsh is /gtm global-settings general domain-name-check. The Configuration utility uses the following configuration path for your version:

  • 11.5.0 and later:

    DNS > Settings > Zones > Domain Validation

  • 11.4.1 and earlier:

    System > Configuration > Global Traffic > General > Domain Validation

Impact

The configuration will fail to load.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The configuration fails to load when it contains a DNS Express zone with an underscore in the name.

Workaround

To work around this issue, you can manually load the configuration by loading the BIG-IP GTM-only configuration first, then loading the full configuration. To do so, perform the following procedure:

Impact of workaround: Every time you load the configuration, you will be required to manually load the BIG-IP GTM configuration first.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Load the BIG-IP GTM-only configuration by typing the following command:

    load sys config gtm-only

  3. Load the full configuration by typing the following command:

    load sys config
