Description

You will see below symptoms when you run into this issue.

  • In Configuration Utility Statistics >> Module Statistics: DNS: GSLB >> iQuery, the last sync column is empty on GTM device which is behind NAT (picture 1). Peer device will show the exact time somehow for both (picture 2).

  • When running 'tmsh show gtm iquery' output on DNS device which is behind NAT, the server type for itself is BIGIP, the configuration time is 'None', local big3d version is empty and the Configuration Commit Originator is '---'. The same couldn't be seen on peer device.
