Description

  • iprepd db discrepancy for some IP address records
  • Some BIG-IPs report different verdicts for the same IP
  • An error messages similar to the following can be seen on /var/log/iprepd/iprepd.log:

    Failed memory allocation in vMergeLists!

Environment

  • BIG-IP
  • IP Intelligence
  • iprepd

Cause

The observed behavior is caused by a known issue tracked with the Bug ID 998781.

Recommended Actions

At the time of creation of this article the issue not fixed on available releases. An with the fix EngHF can be provided if required.
