Description

SNMP monitoring for BIG-IQ VE temperature

 

Environment

BIG-IQ VE

snmp trap for device temperature

Cause

None, by design

Recommended Actions

This is not possible because the BIG-IQ device is a Virtual Edition, VM doesn't have the temperature MIB, this also applies to BIG-IP if they are Virtual editions

Additional Information

BIG-IQ MIBS directory is on /usr/share/snmp/mibs/F5-BIGIQ-MIB.txt
