Description

For requirement of getting Client IP address in SIEM /Syslog server configure iRule to extract X-Forwarded-For value from HTTP header.

Environment

  • HTTP header.
  • SIEM /Syslog server.
  • Virtual server

Cause

None

Recommended Actions

Configure below iRule to log each incoming http-request and apply the same to Virtual Server.

when HTTP_REQUEST {
log local0. "method=[HTTP::method];path=[HTTP::path];client_ip=[IP::client_addr]"
}

Note: Log facility local0. writes into the /var/log/ltm and logs will be replicated to the remote syslog server as well.
