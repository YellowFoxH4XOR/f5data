Description

The goal is to define a domain proxy to the backend server subdirectory through the Nginx Controller GUI.

The expectation is to use URL address in browser http://example.link.org and open page from backend http://10.10.10.10/example/website/
In browser will be display only URL http://example.link.org

The initial configuration was done doing a proxying using an NGINX open source instance as per below:

(public domain) www.example.link.org --> (backend) http://10.10.10.10/example/website/

Below config works fine on Nginx open source instance

server 
{
   listen 80;
   server_name  example.link.org;
   location / 
   {
      proxy_pass http://10.10.10.10/example/website/;
      proxy_set_header X-Real-IP $remote_addr;
      proxy_set_header Host $host;
      proxy_redirect off;
      proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
      proxy_connect_timeout 90;
      proxy_send_timeout 90;
      proxy_read_timeout 90;
      client_max_body_size 10m;
      client_body_buffer_size 128k;
      proxy_buffer_size 4k;
      proxy_buffers 4 32k;
      proxy_busy_buffers_size 64k;
  }
}


This article showing how to migrate the example.link.org domain from NGINX open source instance to NGINX+ cluster.

Environment

  • Nginx Controller 3.22.5+
  • Nginx Plus 27+

Cause

None

Recommended Actions

Below you will find snapshots which showing step by step, how you should do configuration covered in the description.

In our scenario Nginx Plus instance (10.155.207.3) has been use for to create Gateways with name - example.link.org


 

  1. Create gateway using Nginx Plus instance and define Hostname -> http://example.link.org
 
  1. Create Apps
  1. Create component for created Apps:
  • Put name and choose gateway created in the first step
  • Add URI - "/"
  • Add Workload Group and as a Backend Workload URI - http://10.10.10.10
  • In Snippets add the following lines for URI Snippets
  • Next Submit Component configuration
  1.  On the Nginx+ instance, nginx.conf should contain the following data: 
upstream webservers_http_482f0956-c58c-4acd-b030-d9096d5ae390 {
        zone webservers_http_482f0956-c58c-4acd-b030-d9096d5ae390 160k;
        server 10.10.10.10:80;
        keepalive 64;
        keepalive_requests 100;
        keepalive_timeout 60s;
}
server {
        server_name example.link.org;
        listen 80;
        status_zone server_5d542036-0a88-3c93-9c40-17da95c7e05a;
        set $f5_gateway example.org_gw;
        f5_metrics_marker gateway $f5_gateway;
        set $f5_environment test_env;
        f5_metrics_marker environment $f5_environment;
        location / {
                error_log /dev/null;
                access_log off;
                set $f5_app example.link.org_apps;
                f5_metrics_marker app $f5_app;
                set $f5_component example.link.org_component;
                f5_metrics_marker component $f5_component;
                proxy_set_header X-Forwarded-For $remote_addr;
                proxy_set_header Host $host;
                proxy_set_header Connection '';
                proxy_http_version 1.1;
                rewrite_log on;
                rewrite '^/$' /example/website break;
                proxy_pass http://webservers_http_482f0956-c58c-4acd-b030-d9096d5ae390;
        }
}
