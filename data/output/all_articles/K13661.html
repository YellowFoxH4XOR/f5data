Known Issue

Description

The NFS Access Control List edit page of the ARX Manager GUI does not have a method to commit modifications to existing ACLs.

Impact

Users are unable to commit ACL changes using the ARX Manager GUI.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • There is no OK button on the NFS Access Control List edit page of the ARX Manager GUI to commit changes to the global configuration.

Workaround

To work around this issue, you can edit the affected ACL through the CLI or remove and re-create the affected ACL. To do so, perform one of the following two procedures:

Editing the affected ACL

Impact of workaround: None.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter global mode by typing the following command:

    global
  4. Configure the NFS access list in question using the following command syntax, replacing <list-name> with the name of the NFS access list you want to configure:

    nfs-access-list <list-name>

    For example:

    nfs-access-list list1

    You are now in gbl-nfs-acl mode.
  5. From gbl-nfs-acl mode, you may edit the existing rules from the NFS access list.
Note: For the full syntax of the permit and deny statements, refer to the ARX CLI Reference Guide. Note: These changes will not take effect until you exit gbl-nfs-acl mode. You may edit them at your leisure and review the results before exiting.

  • Verify the changes to the list by using the following command syntax:

    show nfs-access-list [list-name]

  • Return to privileged mode by typing the following command:

    end

    • Removing and re-creating the NFS ACL

    Impact of workaround: The existing ACL will not be available after the removal process.

    1. Navigate to the ARX GUI and log in.
    2. Expand the Authentication tab.
    3. Select NFS Access Lists.
    4. Select the check box to the right of the ACL you want to delete.
    5. Click Remove.
    6. Confirm by clicking OK.
    7. To re-create the ACL to the new specifications, click Add.
