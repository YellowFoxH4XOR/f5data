K7868: Removing all BIG-IP ASM Forensics log entries

Topic

When the BIG-IP ASM security policy processes large amounts of traffic, the Forensics log can become cluttered. Occasionally, it may be useful to remove all of the BIG-IP ASM Forensic log entries from the system.

The Clear All button on the Forensics page clears log entries defined by the Forensics Log Filter. By default, clicking the Clear All button only removes the first 1,000 log entries. To remove all BIG-IP ASM Forensic log entries from the system, you must first update the Forensics Log Filter, and then remove the log entries by clicking the Clear All button.

To remove all BIG-IP ASM Forensic log entries from the system, perform the following procedure:

  1. Log in to the BIG-IP ASM Configuration utility.

  2. Click Application Security.

  3. Click Web Applications.

  4. Click the web application from which you want to remove the log entries.

  5. Click the Forensics menu.

  6. Click the Filter down arrow button.

  7. Click the All option button in the Search in field.

  8. Click the Go button next to the Filter field.

    Note: Clicking the Go button will apply the filter, and the Forensics page should display the total number of violations.

  9. Click the Clear All button.

All entries that apply to the filter are now cleared.
