K000156638: After applying new Device Certificate, browser continues displaying old certificate on Secondary Blade(s)

Type
Support Solution
Published
2025-09-25
Updated
2025-09-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000156638

Description

After applying new Device Certificate, browser continues displaying old certificate on secondary blade or blades.

Environment

Relevant environmental factors specific to the topic

  • Viprion muti-bladed system
  • Changed or updated server certificate

Cause

The BIG-IP system did not automatically restart the configuration utility's Apache httpd process on one or more of the secondary blades, therefore, it continues to use the old certificate.

Recommended Actions

  1.  Login to Viprion Host CLI (SSH).
  2. Execute the following TMSH command to restart HTTPD and Activate the new cert on all blades:
    # clsh tmsh restart sys service httpd
  3. Execute the following TMSH commands - *ONLY* if Step (#2) above reported "FAILED" when restarting any of the slot HTTPD daemon:
    # clsh tmsh stop sys service httpd
    # clsh killall -9 httpd
    # clsh tmsh start sys service httpd
    # clsh tmsh show sys service httpd
