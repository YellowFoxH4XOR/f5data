K000133745: Unable to install Nginx nms-instance-manager

Type
Support Solution
Published
2023-04-29
Updated
2023-04-29
Applies to
  • NGINX Products
  • NGINX API Connectivity Manager: 1.4.1
Source
https://my.f5.com/manage/s/article/K000133745

Description

  • You plan to install Nginx Instance Manager following guide
  • You furnished the host with required resources and supported Linux distribution, like Ubuntu 20.04
  • you followed the steps from the above article and attempt to install Instance manager, but the instillation failed to initiate with the below error
root@client# sudo apt-get install -y nms-instance-manager
Reading package lists... Done
Building dependency tree... Done
Reading state information... Done
E: Unable to locate package nms-instance-manager

Environment

  • Nginx Management suite
  • Nginx Instance Manager
  • subscription

Cause

  • Absence of valid nginx-repo.cert and nginx-repo.key in directory /etc/ssl/nginx

Recommended Actions

  • Get a valid subscription or trail-license to receive valid nginx-repo.cert and nginx-repo.key

Additional Information

  • If you installed NGINX Plus as a prerequisite for the NGINX Management Suite, you would have completed these steps .
  • You can further verify, the presence of valid nginx-repo.cert and nginx-repo.key following the below curl command
    • curl --cert /etc/ssl/nginx/nginx-repo.crt --key /etc/ssl/nginx/nginx-repo.key -k https://pkgs.nginx.com/nms/ubuntu/dists/focal/InRelease,
  • If No certificate present, you would see an output similar to
curl: (58) could not load PEM client certificate, 
               OpenSSL error error:02001002:system library:fopen:No such file or directory, (no key found, wrong pass phrase, or wrong file format?)
  • If certificate present but it is either invalid or expired, you would see an output similar to
** Cert and Key **
<html>
<head><title>400 The SSL certificate error</title></head>
<body>
<center><h1>400 Bad Request</h1></center>
<center>The SSL certificate error</center>
<hr><center>nginx/1.21.5</center>
</body>
</html>

In conclusion, while it is possible to make use of Nginx OSS, this only allows you to install NGINX Management Suite, which is a management plane solutions without its core modules. Instance manager instillation process requires you to have a valid nginx-repo.cert/key pair under directory /etc/ssl/nginx. You can get a trial subscription for NGINX Management Suite. On the other hand , if you already subscribed and have a trial license, then you must rename the files as stated here in step 3, https://docs.nginx.com/nginx-management-suite/admin-guides/installation/on-prem/install-guide/#add-nms-repo.
