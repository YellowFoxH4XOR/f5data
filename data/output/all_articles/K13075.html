Known Issue

The Android VPN service will limit the split tunneling address list to six entries.

This issue occurs when all of the following conditions are met:

  • BIG-IP APM or FirePass Network Access is configured to use split tunneling
  • BIG-IP APM or FirePass is configured with more than six address/mask entries in the LAN Address Space table
  • The user is running the Android Edge Client

Impact

Android Edge Client users are unable to access resources through BIG-IP APM or FirePass.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Android Edge Client continually displays a reconnecting message

Workaround

To work around this issue, you can limit the split tunneling address list to six entries. To do so, perform the following procedure for either BIG-IP APM or FirePass:

Important: Changing the LAN Address Space list will affect all clients connecting to the Network Access tunnel. F5 recommends that you create a separate Network Access policy to connect to for BIG-IP Edge Client for Android users. For more information about configuring BIG-IP APM or FirePass for the BIG-IP Edge Client for Android, refer to the BIG-IP Edge Client for Android guides listed in the Supplemental Information section.

Impact of workaround: This workaround limits the split tunnel address list to six entries and may limit access to resources in your environment for any client accessing the network tunnel .

Editing the BIG-IP APM split tunnel address list

  1. Log in to the Configuration utility.
  2. Click Access Policy.

    The Access Policy navigation menu expands.

  3. Click Network Access.
  4. Click the name of the Network Access profile you want to edit.
  5. In the Lan Address Space text box, ensure that the list contains six or less IP address/network mask entries.
  6. Remove unnecessary entries and change the network masks to group large LAN address spaces into one entry.

Editing the FirePass split tunnel address list

  1. Log on to the administrator interface.
  2. Click Network Access.
  3. Select the resource group to edit from the Resource Group drop-down menu.
  4. Click the Client Settings tab.
  5. In the Lan address space text box, ensure that the list contains six or less IP Address / network mask entries.
  6. Remove unnecessary entries and change the network masks to group large LAN address spaces into one entry.
