Topic

BIG-IP Edge Client for Apple OS X supports the use of a client certificate to provide authentication or additional verification of a user's identity.

Description

BIG-IP Edge Client for OS X can pass a client certificate to BIG-IP APM or FirePass. The client certificate can then be used to perform additional verification of the user's identity. BIG-IP Edge Client uses the OS X certificate keychain as the source for certificate storage. For BIG-IP Edge Client to be able to access a client certificate stored in the keychain, OS X requires an Identity Preference to be associated with the certificate.

Recommendations

When configuring a client certificate for OS X, you should complete the following tasks:

  • Installing a client certificate in OS X

    For information about installing a client certificate in OS X, refer to the Adding certificates to a keychain Apple document.

    For information about configuring an identity preference for a client certificate for OS X, refer to your Apple OS help section, product documentation, and online discussions regarding the New Identity Preference configuration.
