Description

A TCP SYN/ACK packet generated by the BIG-IP in response to a SYN packet, which arrived via an IPsec tunnel, may fail to be received by the SYN sender.

A packet capture on the BIG-IP will show an outbound SYN/ACK packet but show no corresponding ESP packet (containing the SYN/ACK) outbound.

The ltm log may report that syncookie mode has been activated, or DOS protection against a SYN variety attack is active.

You may find corresponding logs timestamped during the network scan, for example:

err tmm7[13506]: 01010252:3: A Enforced Device DOS attack start was detected for vector TCP SYN flood, Attack ID 1167369740.
notice tmm6[13506]: 01010253:5: A Enforced Device DOS attack has stopped for vector TCP SYN flood, Attack ID 1167369740.


Packets causing TCP half-open DOS vector activation:

warning tmm[30703]: 01010038:4: Syncookie counter 64022 exceeded vip threshold 64000 for virtual = 10.0.0.0:0
err tmm[30703]: 01010252:3: A Enforced Device DOS attack start was detected for vector TCP half open, Attack ID 111958213.
notice tmm[30703]: 01010240:5: Syncookie HW mode activated, server = 10.0.0.0:0, HSB modId = 1

Packets causing per-VLAN syncookie hardware detection or exceeding the Global SYN Check threshold:

warning tmm[30703]: 01010038:4: Syncookie counter 64050 exceeded vip threshold 64000 for virtual = 10.0.0.0:0
notice tmm[30703]: 01010240:5: Syncookie HW mode activated, server = 10.0.0.0:0, HSB modId = 1

The ltm logs may not show any of the above logs if DOS or syncookie protection activated and remained active while logrotate removed the ltm log that containing the activation message.

 

Environment

  • The BIG-IP has an IPsec "tunnel" mode tunnel, over which the TCP SYN arrived.
  • Syncookie mode, or DOS protection (in the case of AFM provisioning) for a TCP attack has activated.
 

Cause

Syncookies cannot be sent over an IPsec tunnel when the ipsec-policy is in tunnel mode.
 

Recommended Actions

You may take any one of the following remedial steps, as appropriate to your environment.

When hardware or software syncookie protection is triggering, you may do any one of the following:
  • Convert the tunnel mode IPsec configuration to IPsec interface mode. Syncookies can then be sent over the tunnel.
  • Disable syncookie protection.

When a DOS protection (AFM) vector is triggering, you may do any one of the following:
  • Convert the tunnel mode IPsec configuration to IPsec interface mode. Syncookies can then be sent over the tunnel.
  • If DOS protection for TCP is activating, increase the threshold on the relevant DOS TCP profile
  • Configure an AFM whitelist for the source address of the remote IPsec peer IP.
 

Additional Information

Network scans or throughput testing over an IPsec tunnel can lead to activation of the DOS "IP uncommon proto" vector.
