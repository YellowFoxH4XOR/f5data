K000148526: Generating UCS takes very long time.

Description

  • Generating UCS takes very long time (Hours or Days)
  • Log messages similar to the following can be seen on /var/log/restnoded/restnoded.log

    severe: [ErrorHandlingModule] RestOperation failed: "/shared/iapp/rpm-spec-creator". {"code":500,"message":"ENOSPC: no space left on device, write","referer":"http://localhost:8100/shared/iapp/build-package","originalRequestBody":"{\"specFileData\":{\"name\":\"f5-iappslx-access-saml-sp\",\"summary\":\"Default exported iApp summary\\\\.\",\"version\":\"2.5.0\",\"release\":\"0.0.1629\",\"description\":\"Default exported iApp description.\",\"srcBasePath\":\"/var/config/rest/iapps/f5-iappslx-access-saml-sp\",\"user\":\"restnoded\",\"group\":\"restnoded\"},\"generation\":0,\"lastUpdateMicros\":0}","errorStack":[]}
  • Log messages similar to the following can be seen on /var/log/restjavad.0.log

    [RestOperation] failure handler for GET http://localhost:8100/shared/storage?key=shared/iapp/build-package/a879e491-48d2-4eb5-a03c-fcc9106de086 400 threw unexpectedly: java.lang.IllegalStateException: Called too many times! Pending: 4, completed 5

Environment

  • BIG-IP
  • UCS
  • Java

Cause

The restjavad process got stuck in a bad state due to a previous disk full issue.

Recommended Actions

Restart restjavad and restnoded processes

  1. Connect to CLI
  2. Run

    bigstart restart restjavad restnoded

None
