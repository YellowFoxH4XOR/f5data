Known Issue

The Traffic Management Microkernel (TMM) may restart when you configure connection rate limiting on a virtual server.

This issue occurs when the following condition is met:

  • Your BIG-IP system is managing traffic using a virtual server.
  • You have configured the virtual server to use rate limiting.
  • An unexpected load balancing selection occurs after a connection is in progress. For example, an iRule issues an LB command after a TCP::release.

Impact

Service may be interrupted as TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H486542 on the Diagnostics > Identified > High screen.
  • All traffic processing is intermittently interrupted.
  • A TMM core file is present in the /shared/core directory.
