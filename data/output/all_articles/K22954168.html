Known Issue

If you power down the rSeries appliance from Linux (for example, using the halt -p, poweroff, shutdown now, shutdown -h now, shutdown -P now, or shutdown --poweroff now commands) while in Appliance mode, the device becomes permanently disabled.

In this state, nothing external can be done to power on the Linux host, for example, cycling power, accessing the LCD Power on option, or pressing the Power button.

This issue occurs when all of the following conditions are met:

  • Appliance mode is enabled (this is the state the 'appliance-setup-wizard' wizard sets when it runs to completion).
  • The host is powered down (e.g., using halt -p, poweroff, shutdown now, shutdown -h now, shutdown -P now, or shutdown --poweroff now).

Impact

The AOM command menu is not available to power on the host. A power cycle of the appliance does not power on the host.

You must replace the disabled appliance.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to access the AOM menu from the serial console, you view the following message:

    AOM Command Menu - disabled for security purposes.

Workaround

If you have already encountered this issue, contact F5 Support to request an RMA. For more information, refer to K12882: Overview of the F5 RMA process.

To work around this issue, you can power off the system by using the halt command without any arguments (do not use the -p option). Once the serial console reports the device has been halted, unplug the power to the appliance.

Important: Do not power off the rSeries device using commands, such as halt -p, poweroff, shutdown now, shutdown -h now, shutdown -P now, or shutdown --poweroff now.
