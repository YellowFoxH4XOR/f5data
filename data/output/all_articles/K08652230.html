Description

When doing a Workspace reload (for the iRules LX module), the device goes offline briefly and some daemons restart. You can see similar logs in /var/log/ltm:

emerg logger: Re-starting bigd
emerg logger: Re-starting bigd
emerg logger: Re-starting tmm
emerg logger: Re-starting tmm1

A SIGFPE core file can be generated into the /var/core directory, similar logs can be seen on /var/log/tmm:

notice panic: Tcl Object 5703110c5308 is currently on free list
notice panic: Tcl Object 570311b47158 is currently on free list

Environment

  • Using iRules LX
  • tmm core

Cause

Bug ID 696908: Updating iRule causes TMM to crash

Recommended Actions

Upgrade to a version where Bug ID 696908 is fixed or open a ticket with F5 support to obtain an Engineering Hotfix for this ID on affected versions.

None
