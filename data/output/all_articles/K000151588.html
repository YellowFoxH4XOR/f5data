Description

IP Intelligence (IPI) database updates may fail resulting in the IPI database not updating and leaving threat intelligence outdated. The following errors may be observed in the iprepd logs:

iprepd|ERR|SSL error: error:14090086:SSL routines:ssl3_get_server_certificate:certificate verify failed
iprepd|ERR|Cannot send to host api.bcti.brightcloud.com: Success
iprepd|ERR|Query(getipfile): Send: Failed to send request

Environment

  • IP Intelligence (IPI) feature enabled
  • Route domains present
  • Management proxy configured for IPI updates

Cause

A misconfigured or incorrect  proxy setting on the F5 device can prevent successful SSL communication with BrightCloud update servers. This results in SSL certificate verification failures and blocks IPI database updates.

Recommended Actions

Proper connectivity to the proxy should be verified as well as making sure that the proxy is allowing proper communication with the BrightCloud server.
