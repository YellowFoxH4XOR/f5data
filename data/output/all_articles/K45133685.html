Description

After restoring configurations using a UCS on a new device, the device may remain in an Offline state. 

The /var/log/ltm is filled with the following error message, which indicates ID 816733. However, the ID suggests that the logs are benign.

localhost err mcpd[6708]: 01070678:3: Full gtm configuration load failed ( Repeated ).
localhost err mcpd[6708]: 01070678:3: Full gtm configuration load failed ( Repeated ).

On the terminal console, an error similar to the one below may be produced (may or may not be written to a log file):

localhost load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all gtm-only" - failed. -- Data Input Error:(/config/bigip_gtm.conf at line: 0) Invalid version:13.1.1.5: Supported cli versions: 11.5.0 11.5.1 11.5.2 11.5.3 11.5.4 11.5.5 11.6.0 11.6.1 11.6.2 11.6.3 12.0.0 12.1.0 12.1.1 12.1.2 12.1.3 13.0.0 13.0.1 13.1.0 13.1.0.1 13.1.0.2 13.1.0.3 13.1.0.4 13.1.0.5 13.1.0.6 13.1.0.7 13.1.0.8 13.1.1 13.1.1.1 13.1.2 13.1.3 13.1.3.4

Environment

  • BIG-IP configurations are restored from UCS
  • The first line of /config/bigip_gtm.conf contains older version of TMSH-VERSION

Cause

The error message "Full gtm configuration load failed ( Repeated )" is known to be logged as a result of another error while loading configurations.

In this case, the original issue or the trigger of the message above is the issue described in K43491463, which causes the BIG-IP device to remain in an Offline state. Once you perform the recommended actions described in K43491463 and the issue is resolved, the message "Full gtm configuration load failed ( Repeated )" will also go away.

Recommended Actions

Refer to K43491463 and perform the recommended actions.
