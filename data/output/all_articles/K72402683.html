Description

This message occurs in /var/log/kern.log:

warning kernel: linux-kernel-bde 0000:09:00.0: VPD access failed.  This is likely a firmware bug on this device.  Contact the card vendor for a firmware update


Environment

  • Platform with Broadcom switch chip, including iSeries and Viprion platforms

Cause

The message is caused by ID396273.
It is related to ID437586 in that it shows up on devices with broadcom chipsets.
This is a cosmetic error and of no concern.

This can occur when 'lspci -vvv' is executed.
This is a benign message, and you can safely ignore it as it is not a functional issue.

Recommended Actions

None, it is cosmetic

None
