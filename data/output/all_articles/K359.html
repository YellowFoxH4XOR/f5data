K359: Known Issue: It is not possible to configure a URI path for a fallback host using the command line

Known Issue

This is the result of a known issue. When you configure a fallback host for a pool from the command line, BIG-IP does not allow you to configure a URI path.

F5 Networks Product Development tracked this issue as CR26843 and CR41822.

Workaround

To work around this issue, configure the fallback host using the Configuration utility.

If you cannot access the Configuration utility, add the URI path to the fallback host from the command line by performing the following steps:

  1. Log in to the command line.
  2. Configure the fallback host for the pool, using the following command syntax:

    bigpipe pool <pool> fallback <URL>:<port>

    • Replace <pool> with the name of the pool to which you want to add the fallback host.
    • Replace <URL> with the protocol and host portion of the URL, but do not include the URI.
    • Replace <port> with the port used for the service.

    For example:

    bigpipe pool askf5pool fallback http://10.90.100.1:80

    This will add the fallback host to the configuration without a URI.

  3. Save the configuration, by typing the following command:

    bigpipe save

  4. Backup the bigip.conf file, by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.original

  5. Using a text editor, such as vi or pico, edit the bigip.conf file.

    cp /config/bigip.conf /config/bigip.conf.original

  6. Locate the configuration statement for the pool that you want to modify. Within that statement, locate the line that begins with fallback.

    Using the previous example, the line would appear as follows:

    fallback http://10.90.100.1:80

  7. Change the line so that the URI follows the existing URL and the full URL is enclosed in quotes.

    For example:

    fallback "http://10.90.100.1:80/askf5.html"

  8. Save the file and exit the editor.
  9. Load the configuration, by typing the following command:

    bigpipe load

The fallback host is now configured with a URI path.
