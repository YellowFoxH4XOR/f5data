Description

During software upgrade, license upgrade, or re-activation, the learning process is stopped. All learning suggestions are lost.


Environment

  • BIG-IP ASM or Advanced WAF (AdvWAF)

  • Learning mode enabled


Cause

Expected behavior

 

Recommended Actions

Before any software upgrade, license upgrade or re-activation, make sure to review and accept meaningful Learning suggestions. ASM will re-learn suggestions after it starts processing traffic again.
