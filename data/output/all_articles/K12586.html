Known Issue

If you apply the pre-packaged sys_APM_ExchangeSupport_main iRule to a virtual server, Traffic Management Microkernel (TMM) may crash.

The sys_APM_ExchangeSupport_main iRule is used to proxy authentication for Exchange and is preconfigured on the BIG-IP APM device starting in 10.2.1. When TMM attempts to synchronize data between different clients, but one of the client connections has been closed, TMM will crash. To the user, this behavior will appear to be random.

Note: While the sys_APM_ExchangeSupport_main iRule is not pre-configured on BIG-IP 10.1.0 and 10.2.0, this issue will affect users that manually create the same rule.

F5 Product Development tracked this issue as ID 340081 and it was fixed in BIG-IP 10.2.2. For information about upgrading, refer to the BIG-IP APM release notes.

In addition, BIG-IP iHealth may list Heuristic H359631 on the Diagnostics > Identified > Medium screen.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
