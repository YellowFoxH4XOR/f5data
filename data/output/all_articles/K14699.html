Known Issue

The access policy logon page may not display the logout timeout warning for Safari browsers.

This issue occurs when all of the following conditions are met:

  • Clients accessing the access policy are using a Safari browser.
  • The configured access policy timeout setting is surpassed.

Impact

Clients will not see the session timeout warning before being logged out.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Clients are unable to see the access policy timeout message and are logged out.
  • Clients will be required to log in after the session timeout has expired.

Workaround

To work around this issue, you can modify the logon page code to ensure the session logout message is displayed. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy.
  3. Navigate to Access Policy > Customization.
  4. Select Advanced Customization.
  5. From the Edit Mode menu, select Advanced.
  6. Select the resource type folder for Access Profiles.
  7. Select the subfolder that shares the name of the affected access policy.
  8. Select the folder Logon Pages > Logon Page.
  9. Select the logon.inc file.
  10. Locate the function "sessionTimedOut()" (typically line 112 of an unmodified login.inc file).

    function sessionTimedOut()
    {
    // restart session automatically upon "submit" for edge-like clients if logon form is compatible
    if ((undefined != window.external.WebLogonResetSession) && (null != globalInputs)) {

  11. Modify the syntax replacing the if statement line (typically line 115 of an unmodified login.inc file) with the following:

    if (("undefined" != typeof(window.external)) && (undefined != window.external.WebLogonResetSession) && (null != globalInputs)) {

  12. In the top right corner of the editor click Save Draft.
  13. In the top left side of the editor click Save.
  14. In the top left corner of the Configuration utility click Apply Access Policy.
  15. Click Apply Access Policy.
