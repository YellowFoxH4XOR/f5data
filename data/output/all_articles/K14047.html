Topic

The BIG-IP APM system uses several client software packages, such as stand-alone client or web browser plug-ins, to provide users with Virtual Private Network (VPN) access through a BIG-IP APM system.

Note: System hardware requirements are not outlined in the client compatibility matrix. Instead it reports OS and browser compatibility with the APM client; therefore, if your system is capable of running the compatible OS, then it can also run the APM client such as the BIG-IP Edge Client.

BIG-IP APM client compatibility

To view whether a specific version of an operating system or web browser is supported, refer to the BIG-IP APM client compatibility matrix for your version.
