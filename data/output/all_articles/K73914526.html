Topic

This article covers the compatibility of DDoS Hybrid Defender with BIG-IP releases.

Description

DDoS Hybrid Defender is a hybrid solution that detects network and application layer attacks. To run, it requires certain versions of the BIG-IP system. The following table lists the necessary BIG-IP versions on which DDoS Hybrid Defender must run.

* The compatible BIG-IP versions listed in this table include their respective point releases. For example, BIG-IP 13.1.0.1 through BIG-IP 13.1.0.8 are compatible with DDoS Hybrid Defender 13.1.0-3.1.334. Additionally, certain DDoS Hybrid Defender versions report misleading error message about unsupported versions when the system is upgraded to a version whose minor version is not '0'. For more information about this issue, refer to ID 863009.
