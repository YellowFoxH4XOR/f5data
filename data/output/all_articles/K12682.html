Known Issue

This is the result of a known issue. When the acceleration policy references a response rewrite script that is not present on the system, the BIG-IP WebAccelerator logs an error message to the /var/log/wa/pvac.log file that appears similar to the following examples:

BIG-IP WebAccelerator 10.x

WA Debug ( 7682): [StateFactory.cxx:33 StateFactory ] StateFactory failed to read file [/var/wa/config/policies/localhost:8081/transforms/no404s.code]

BIG-IP WebAccelerator 9.4.x

WA Debug: Could not create StateFactory object for file '/usr/local/wa/config/policies/localhost:8081/transforms/no404s.code'

This issue may occur under the following two scenarios:

  • Associating the predefined Ecommerce policy with an application

    Note: The predefined Ecommerce policy references a response rewrite script that is no longer present on the system.
  • Importing and using a policy from an earlier BIG-IP WebAccelerator version without uploading the response rewrite script to the system

F5 Product Development is tracking this issue as ID 349003; BIG-IP iHealth may list Heuristic H383278 on the Diagnostics > Identified > Low screen.
