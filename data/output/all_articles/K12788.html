Known Issue

When a client connection flow is prematurely aborted while the BIG-IP system is processing a RAM Cache request, the TMM process may core and restart. This issue occurs when the code attempts to access a NULL request pointer while processing the canceled request.

The RAM Cache feature stores HTTP objects in the BIG-IP RAM that subsequent connections can reuse. The feature reduces the amount of load on the back-end servers.

Impact

This issue causes the TMM process to crash and temporarily interrupts traffic processing.

Symptoms

As a result of this issue, the BIG-IP system may experience the following symptoms:

  • TMM produces a core file.
  • The system generates a SIGSEGV fault and stack trace to the /var/log/tmm file.
