Topic

Beginning in BIG-IP 11.6.0, F5 introduced the logpublisher.atomic database key to allow the log publisher to log to the available logging destinations when a logging destination becomes unavailable.

Description

By default, the logpublisher.atomic database key is set to True, indicating that the system makes all logging destinations available so you can log to each destination when you configure the log publisher with multiple destinations. If any of the destinations fail, the log publisher fails to publish logs to all of the logging destinations.

For example, when you configure the log publisher to use two logging pools with the logpublisher.atomic database key set to True (the default value), you observe the following behavior:

  • When both pool members are up, the system sends the logs to both pool members.

    For example, the system sends the logs to the HSL pool members dest_log_remote1 and dest_log_remote2, simultaneously:

    sys log-config publisher /Common/lp-cgnat {
        destinations {
            /Common/dest_log_remote1 { } 
            /Common/dest_log_remote2 { }
        }
    }

  • The system stops logging for all pool members when either of the pool members is marked down.

    For example, the system will not send logs to the HSL pool member dest_log_remote1 when pool member dest_log_remote2 is marked down.

If you want the log publisher to log to the available pool members when a pool member becomes unavailable, you must set the logpublisher.atomic database key to False. You should first obtain the current value of the database key before you make a modification.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the TMOS Shell (tmsh).

Modify the DB Key value

To modify the logpublisher.atomic database key so the system logs to the available logging destination, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To list the default-value, the current value, and the possible value-range of a system database key, use the following command syntax:

    list /sys db <DB key name> all-properties

    For example, to list all-properties for the logpublisher.atomic database key, enter the following command:

    list /sys db logpublisher.atomic all-properties

  3. To modify the value of a system database key, use the following command syntax:

    modify /sys db <DB key name> value <value>

    For example, to modify the logpublisher.atomic database key to False, enter the following command:

    modify /sys db logpublisher.atomic value false
