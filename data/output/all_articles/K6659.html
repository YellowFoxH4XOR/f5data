Known Issue

This is the result of a known issue. Floating point equations in iRules return formatting strings instead of the expected values for floating point calculations.

F5 Product Development tracked this issue as CR68915 and CR69858 and it was fixed in BIG-IP 9.2.5, 9.3 and 9.4. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller Release Notes.
