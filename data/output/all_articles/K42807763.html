Known Issue

Deleting a BIG-IP partition may fail.

This issue occurs when all of the following conditions are met:

  • A BIG-IP APM sandbox configuration exists in a partition other than the Common partition.
  • You have not provisioned BIG-IP APM for the BIG-IP system

Impact

Administrators are unable to delete the affected BIG-IP partitions.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to delete a partition, you observe an error message in the /var/log/ltm log file that appears similar to the following example:

    0107082a:3: All objects must be removed from a partition (Test) before the partition may be removed, type ID (16514)

Workaround

To work around this issue, remove the bigip.conf file from the affected partition and reload the configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround will temporarily interrupt active BIG-IP APM sessions.

  1. Log in to the BIG-IP command line.
  2. To remove the bigip.conf file, type the following command:

    rm /config/partitions/<partition_name>/bigip.conf

    For example, to remove the bigip.conf file in the /datacenter partition, type the following command:

    rm /config/partitions/datacenter/bigip.conf

  3. Reload the system configuration by typing the following command:

    tmsh load sys config

  4. Delete the affected partition by typing the following command:

    tmsh delete sys folder /<partition_name>

    For example, to delete the /datacenter partition, type the following command:

    tmsh delete sys folder /datacenter
