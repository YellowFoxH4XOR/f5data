Known Issue

A user role may limit the ability to export application request log data.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured with an active security policy.
  • The virtual server configured with the security policy has processed traffic.
  • A BIG-IP user assigned with the Auditor user role logs on to the BIG-IP ASM Configuration utility.
  • The user navigates to Security > Event Logs > Application > Requests and attempts to export the log request data.

Impact

The Auditor user role is unable to export the request log data.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility Export button is greyed out and does not function..
