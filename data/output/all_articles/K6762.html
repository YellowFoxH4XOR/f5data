Known Issue

This is the result of a known issue. When a Secure Socket Layer (SSL) certificate containing an apostrophe ( ' ) is installed on the BIG-IP LTM system, the Configuration utility will fail to display the SSL Certificates page.

The BIG-IP LTM Configuration utility will display the following error message when attempting to import the SSL certificate:

General database error retrieving information

BIG-IP LTM will log the following error message to the catalina.out log file:

java.io.UTFDataFormatException: Invalid byte 2 of 3-byte UTF-8 sequence

F5 Product Development tracked this issue as CR57804, CR60883, CR70181, and CR60884 and it is fixed in BIG-IP 9.1.3, 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
