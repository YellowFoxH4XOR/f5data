K63314212: BIG-IP Logged traffic dropped after 'Accept Decisively' rule

Type
Support Solution
Published
2020-04-17
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP AFM: 13.1.1
Source
https://my.f5.com/manage/s/article/K63314212

Description

You see traffic drops are being logged on traffic that should match an Accept-Decisively firewall rule, but find that the traffic is still being working.

Environment

  • BIG-IP AFM
  • 13.1.1.4
  • Accept-Decisively firewall rules

Cause

ID 890737

Recommended Actions

Verify whether or not traffic is actually reaching it's intended destination. If traffic is reaching the intended destination, you are likely seeing symptoms of ID 890737. Plan on upgrading to a software version where this ID is fixed.

Additional Information

None
