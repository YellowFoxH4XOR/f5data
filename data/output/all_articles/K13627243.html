Known Issue

Spurious ACK packets may increment the SYN Cookies 'Total Software Rejected' statistic when SYN cookie status is not activated.

This issue occurs when one of the following conditions are met:

  • The client sends a SYN cookie, the BIG-IP system sends a SYN-ACK packet, and then the client sends a bad ACK packet.
  • The client sends an ACK packet for a connection that does not exist in the connection table.

Impact

The 'Total Software Rejected' counter may display inaccurate statistics.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tmsh show /ltm virtual <virtual-server-name> command output displays inaccurate statistics for the 'Total Software Rejected' counter.

    For example, the following output shows a virtual server with an incorrect 'Total Software Rejected' count:

    ------------------------------------------------------------------
    Ltm::Virtual Server: VIP_TEST_FORWARD
    ------------------------------------------------------------------
    ..
    SYN Cookies
    Status not-activated
    Hardware SYN Cookie Instances 0
    Software SYN Cookie Instances 0
    Current SYN Cache 0
    SYN Cache Overflow 8
    Total Software 27573
    Total Software Accepted 0
    Total Software Rejected 189035
    Total Hardware 0
    Total Hardware Accepted 0
    ..
