Description

When you attempt to export/import a file from/to F5OS using scp/sftp to/from a remote host, the file export/import may fail and display an error message similar to the following example:

Host identity could not be verified

Environment

  • Attempting to export/import a file from/to F5OS using scp/sftp protocol to/from a remote host
  • F5OS 2.0.0

Cause

The F5OS 2.0.0 system does not have the fingerprint identity of the remote host. 

Recommended Actions

You need to add the identity of the remote host to the F5OS 2.0.0 system. To do so, perform the following procedure:

Impact of procedure: Performing this procedure should not have a negative impact to your system.

  1. Log in to the CLI of your F5OS 2.0.0 system as the administrative user.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Add the identity of the remote host to the F5OS 2.0.0 system by entering the following command syntax:

    file known-hosts known-host <IP address of the remote host>

  4. Save the change by entering the following command:

    commit

    The F5OS 2.0.0 system proceeds to obtain the fingerprint of the remote system and prompt to add it to its known hosts list.

  5. Confirm the change by entering yes when prompted.
  6. Exit the configuration mode terminal by entering exit twice.
