K555: Resetting a root password when the password command will not change it

Topic

If you use the passwd command to change the root password and the change does not take effect, do the following:

  1. Use vi or pico to edit the password file.
    • To edit the password file with the vi editor, type the following command:

      vipw

    • To edit the password file with the pico editor, type the following commands:

      export EDITOR=pico
      vipw

      The password file will look similar to the following example:

    root:_J9..p9w8hRCyVJD0ZVk:0:0:daemon:0:0:System Administrator:/root:/bin/bash
support:_J9..1fnHY9nqgjRyOV2:0:0:daemon:0:0:F5 Labs User Support:/root:/bin/bash
daemon:*:1:1::0:0:System Daemon:/nonexistent:/sbin/nologin
sys:*:2:2::0:0:Operating System:/nonexistent:/sbin/nologin
bin:*:3:7::0:0:BSDI Software:/nonexistent:/sbin/nologin
operator:*:5:5::

 :0:System Operator:/nonexistent:/sbin/nologin
tty:*:6:6::0:0:Terminal User:/nonexistent:/sbin/nologin
nobody:*:32767:32766::0:0:Unprivileged user:/nonexistent:/sbin/nologin
nonroot:*:65534:32766::0:0:Non-root root user for NFS:/nonexistent:/sbin/nologin
  2. Delete the password portion of the root line. The password portion of the line is between the colons that immediately follow the name. For example:
    root:_J9..p9w8hRCyVJD0ZVk:0:0:daemon:0:0:System
Administrator:/root:/bin/bash

    Using this example, you would change this line to look like the following:

    root::0:0:daemon:0:0:System Administrator:/root:/bin/bash

    Only the following portion is deleted:

    _J9..p9w8hRCyVJD0ZVk

  3. Save the file.
  4. Reset the root password by typing the following command:

    passwd root

  5. Follow the prompts to change your password.

Once you have completed this procedure, the changes to the root account will take effect.
