Known Issue

This is the result of a known issue. A Network Access connection cannot be successfully established through a proxy server if the web service on the FirePass controller is running on a high port. If a user tries to launch Network Access through a proxy service on a high port, the pop-up window may either disappear or show a known error message. This issue occurs when the Network Access client sends a negative port value to the proxy server.

F5 Product Development tracked this issue as ID 294310 (formerly CR136371) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-610-2 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

If the proxy server does not need to use a high port, you can work around this issue by using a port number below 1025. If the proxy server must use a high port, try using a port between 1025 and 32767.

To change the port that the proxy server is listening on, refer to the vendor's documentation.

To change the port that the FirePass controller uses, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Device Management : Configuration : Network Configuration page.
  3. Click on the Web Services tab.
  4. Click on the Configure link next to the Web Server Configuration your users use to access the FirePass Controller.
  5. Change the number in the Port: field to a number between 1025 and 32767.

    Important: Make sure the port number matches the configuration on your proxy server.
  6. Click the Update button.
  7. Click on the Finalize Settings link.
  8. Review your configuration and click the Finalize Changes button.
