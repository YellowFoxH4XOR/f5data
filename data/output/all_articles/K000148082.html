K000148082: How to configure OneLogin SSO with F5 Distributed Cloud

Description

  • I want to use OneLogin as your SSO Identity provider
  • I need help setting up OneLogin for my F5® Distributed Cloud
  • I want to connect to a custom OpenID Connect (OIDC) application in OneLogin

Environment

  • OneLogin

  

Cause

  • None

Answer/Recommended Actions

To configure OneLogin SSO with F5® Distributed Cloud:

1. Sign into OneLogin as an Administrator

2. Navigate to Applications and click Add App

3. Search for Oidc and select openId Connect (OIDC)

4. Add a display name of your choosing and click Save

5. Navigate to the Configuration tab and add the Login URL (this is tenant specific, for example: https://your-tenant.console.ves.volterra.io/)

6. Add a Redirect URI (You can use the same one, https://your-tenant.console.ves.volterra.io/). Click Save

7. Go to SSO page in OneLogin

8. In a separate browser window go to F5 Distributed Cloud > Account Settings > Administration  Login Options > Click Set up SSO > Custom > Next button

9. Enter a display name and copy over Client ID and Client Secret from the SSO page in OneLogin

10. Add your Authorization URL. Example: https://your-domain.onelogin.com/oidc/2/auth

  • Note: This will be specific to your OneLogin Domain

11. Add your token URL. Example: https://your-domain.onelogin.com/oidc/2/token

  • Note: This will also use the domain you chose for OneLogin

12. Click Next and copy the Redirect URI 

13. Back in OneLogin go to Configuration and paste the Redirect URI on a separate line under the first redirect URI you entered there

14. In F5 Distributed Cloud click complete SSO set up

15. In the SSO page in OneLogin set Token Endpoint to use POST instead of Basic for the authentication method and hit Save

16. Click on your new app to log into F5 Distributed Cloud 

17. You may be prompted to click add to existing account button if you already have an existing user in F5 Distributed Cloud

18. Click confirm account linking in the email you receive

19. You should now be able to log in via OneLogin
