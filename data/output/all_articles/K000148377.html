K000148377: SSH proxy error - Error listening to socket: ECDSA, ED25519, DSA, or RSA host key file must be set

Type
Support Solution
Published
2024-12-18
Updated
2025-08-11
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.5.X, 17.5.1, 17.5.0, 17.1.2, 17.0.X, 17.0.0, 17.X.X, 17.1.X, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000148377

Description

Connections are reset immediately after TCP 3WHS with the server, with the following error in /var/log/sshplugin:

err sshplugin[14019]: SSHPLUGIN: sshplugin_0|SSHPlugin|sshplugin_client_handler|Core|Error listening to socket: ECDSA, DSA, or RSA host key file must be set

Environment

  • BIG IP
  • AFM
  • Proxy SSH

Cause

Incomplete or incorrect configuration

Recommended Actions

On the BIG-IP, create a new SSH Proxy profile i.e. "test-ssh-profile"

1. In SSH Proxy profile - Security ›› Protocol Security : Security Profiles : SSH Proxy ›› test-ssh-profile > Key management

- Proxy Server Auth Private Key = An existing SSH proxy system's private or generate a pair on BIGIP using 'ssh-keygen' command.

- Paste the private key generated from above command (on BIG-IP) under "Proxy Server Auth Private Key" (include "-----BEGIN RSA PRIVATE KEY-----" and "-----END RSA PRIVATE KEY-----)

2. For Real Server Auth "Public Key", paste the Public key of the SSH backend server ( under /etc/ssh/ssh_host_rsa_key.pub)

4. Restart SSH service on backend server

 i.e. service ssh restart

Additional Information

Also note that from the backend SSH server (pool member), make sure the line HostKey from /etc/ssh/ssh_host_rsa_key is NOT commented out.
