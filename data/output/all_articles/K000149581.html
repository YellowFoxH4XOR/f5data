K000149581: Edge client on Windows 11 takes too long to connect successfully.

Type
Support Solution
Published
2025-01-31
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000149581

Description

Trying to connect using the edge client, "Connecting to server...." status is shown for too long, this condition is happening when the client is using Windows 11.

Environment

      • BIG-IP APM
      • Edge client
      • WIN 11 OS

Cause

Looking at Packet Captures, unexpected "Fin" packet is received while the BIG-IP and the Edge Client were exchanging session information to stablish the connection.

Verify if the environment has a Firewall between the Edge Client and BIG-IP, this particular behavior was seen when an IPS (Intrusion Prevention System) was analyzing the traffic before the BIG-IP,

Recommended Actions

It's suggested to remove the IPS feature from the device in question.
