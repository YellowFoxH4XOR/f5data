Topic

If you want to revert the FirePass configuration to a previous configuration snapshot, but you cannot access the FirePass Maintenance Console, you can boot the FirePass controller into Recovery Mode. Recovery Mode is a special boot mode that allows you to revert the FirePass configuration to the last working configuration snapshot or to the factory default configuration snapshot.

Note: Typically, you use the FirePass Maintenance Console to revert the FirePass configuration to a previous configuration snapshot. For instructions about accessing the FirePass Maintenance Console, refer to the FirePass Controller Getting Started Guide.
 
To boot a FirePass controller into Recovery Mode, perform the following procedure:
 
  1. Connect a workstation to the serial port of the FirePass controller using a null-modem cable.

    Important: A null-modem cable is required for the serial connection. Other types of cables such as crossover or rollover cables will not work.
     
  2. Configure a communications program, such as HyperTerminal or XTerm, using the following settings:
n            Baud rate: 19200
n            Data bits: 8
n            Parity: none
n            Stop bits: 1
n            Flow control: hardware
 
  1. Start the serial connection.
  2. Restart the FirePass controller.

    Important: If you cannot access the FirePass Administrative Console to restart the FirePass controller, power off the FirePass controller and then power it back on.
     
  3. At the boot: prompt, type Recover and then press the enter key.

    Important: You must quickly type the first letter of the word Recover to prevent FirePass from booting into the default boot mode. If you did not type Recover in time, restart the FirePass and repeat this step.
     
  4. Type maintenance at the logon prompt.
  5. Review the conditions and press Enter or type y continue.
 
A screen of recovery options displays, from which you can revert the FirePass configuration to the last working configuration snapshot or to the factory default configuration snapshot. For more information about FirePass snapshots, refer to K3244: Backing up and restoring FirePass system software.
