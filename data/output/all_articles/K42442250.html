Topic

You should consider using this procedure under any of the following conditions:

  • You use the iControl representational state transfer (REST) interface to make a long-lived transaction, such as saving a large system configuration or creating a large user configuration set (UCS).
  • You anticipate using a larger number of successive iControl REST application programming interface (API) transactions.
  • You need a list of the available iControl REST API asynchronous transactions.

Description

Synchronous iControl REST API transactions require client applications to pause processing until they receive a response from the BIG-IP system. Some client applications fail due to timeout issues, causing subsequent API transactions to fail.

Asynchronous iControl REST API transactions enable client applications to continue processing other tasks while the BIG-IP system processes previously-received asynchronous transactions. There is a set of these transactions, which you can find by querying the tm/task URI.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command line access to a Linux-based operating system.

Procedures

Obtaining the iControl REST asynchronous API transaction list

There are multiple ways to obtain and parse the iControl REST response. The following procedure is the most basic method, as it involves tools available on most Linux operating systems.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. To query the tm/task URI and capture the results to a file, use the following command syntax:

    curl -s -k --user admin:password -H "Content-Type: application/json" -X GET https://ip_address/mgmt/tm/task > file_name

    For example, to query the tm/task URI for a BIG-IP system using the administrator password admin and the IP address 192.168.1.1, and capture the results in a file named icr_tasks, you type the following command:

    curl -s -k --user admin:admin -H "Content-Type: application/json" -X GET https://192.168.1.1/mgmt/tm/task > icr_tasks

  2. To format the file into a readable format, use the following command syntax:

    sed -i 's/,/\n/g' file_name

    For example, to format the icr_tasks file from step 2, type the following command:

    sed -i 's/,/\n/g' icr_tasks

  3. To view the list of asynchronous transactions, use the following command syntax:

    cat file_name

    For example, to view the icr_tasks formatted file from step 3, type the following command:

    cat icr_tasks
