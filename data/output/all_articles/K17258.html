Known Issue

BIG-IP APM Citrix Remote Desktop sessions may fail to establish connections.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a Citrix Remote Desktop profile.
  • Citrix is deployed in integration mode.
  • Users are running the Citrix Receiver on the iOS operating system.
  • The Citrix Web Interface generates a session ICA file without the following properties.

    DoNotUseDefaultCSL=On
    HTTPBrowserAddress=!
    LocHttpBrowserAddress=!

Impact

The Citrix session fails to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the Citrix ICA file returned from the Citrix Web Interface, the following properties are not present:

    DoNotUseDefaultCSL=On
    HTTPBrowserAddress=!
    LocHttpBrowserAddress=!
  • In the /var/log/apm file, when the session initiation fails, you may observe an error message similar to the following example.

    notice tmm[<pid>]: 01490505:5: : Invalid APM ticket: SOCKS '0.0.0.0'
