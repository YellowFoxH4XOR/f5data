K000138159: The token that was generated using Postman has expired earlier than expected.

Type
Support Solution
Published
2024-01-09
Updated
2024-01-09
Applies to
  • VIPRION Platforms
Source
https://my.f5.com/manage/s/article/K000138159

Description

Token created by token based authentication was deleted before expiry

  • Token default expiry is 20 min
  • Token goes missing from /run/pamcach before expiry 
  • Tokens will be deleted at every 10min interval

Environment

  • Token authentication
  • icontrol rest
  • VCMP Guest
  • Contain fixes for 1103369

Cause

Bugid 1475041

Recommended Actions

Workaround

  1. Comments out the 3 lines belong to pamcache monitor in /etc/csyncd.conf
  2. Restart the csyncd process: bigstart restart csyncd

​​​​

Additional Information

Section of the csyncd.conf to be commented off.

#monitor dir /run/pamcache {

#        pull any2any

#}

The caveats of this update is tokens are not replicated across the VIPRION blades and when a primary blade change occurs the user will need to be re-authenticated as the new primary blade will not have any token.
