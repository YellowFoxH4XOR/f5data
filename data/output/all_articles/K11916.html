Known Issue

This is the result of a known issue. When the SMTP configuration has been deleted with the no mail-server command, the ARX system will continue to send emails until the exit command is issued to exit the SMTP configuration mode. The no mail-server command will immediately update the SMTP configuration. However, the ARX system's e-mail home daemon is not updated until the SMTP configuration mode is exited.

Note: For information about the mail-server command, refer to the ARX CLI Reference Guide.

F5 Product Development tracked this issue as ID 38319 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.

Workaround

To configure the ARX system to stop sending emails, perform the following procedure:

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter configuration mode by typing the following command:

    config
  4. Enter SMTP configuration mode by typing the following command:

    smtp
  5. Remove the SMTP mail server configuration by typing the following command:

    no mail-server
  6. Exit the SMTP configuration mode and apply the updated SMTP configuration to the e-mail home daemon by typing the following command:

    exit
  7. Exit the configuration mode by typing the following command:

    exit
