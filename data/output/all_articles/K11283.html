Known Issue

Note: The issue described in this article affects only the BIG-IP 6900 and 8900 platforms. The BIG-IP 6900 platform is supported only in versions 9.4.6 and later, and the BIG-IP 8900 platform is supported only in versions 9.4.7 and later.

This is the result of a known issue. BIG-IP 9.4.x fails to install on a 6900 or 8900 platform when all of the following conditions are met:

  • The BIG-IP system was upgraded to version 10.x or underwent a clean installation of version 10.x.
  • During the aforementioned upgrade or clean installation, the disk drives were formatted to use the partitions disk-formatting scheme.
  • During the aforementioned upgrade or clean installation, HD1.1 was chosen as the installation location.
  • You are attempting to install BIG-IP 9.4.x on the HD1.2 installation location.

When all of the above conditions are met, the BIG-IP 9.4.x installation terminates abruptly and displays an error message that appears similar to the following example:

warn: Unexpected event. See session log.
error: An installation error has occurred; code 1
info: The remote system will now reboot.
Restarting system.

Note: This issue does not occur when the installation locations are reversed. Installing BIG-IP 10.x on HD1.2 and then BIG-IP 9.4.x on HD1.1 does not result in the issue described in this article.

Note: This issue occurs regardless of the installation methods used to install BIG-IP 10.x and 9.4.x.

F5 Product Development is tracking this issue as ID 249297 (formerly CR117480).

Workaround

If you must run BIG-IP 9.4.x and 10.x on the same BIG-IP 6900 or 8900 system, you can work around this issue by avoiding the problematic installation layout by installing BIG-IP 10.x on HD1.2 and BIG-IP 9.4.x on HD1.1.

Note: Due to a different known issue, after you install BIG-IP 9.4.x, the Maintenance Operating System (MOS) may no longer be displayed in the GRUB menu. For more information, refer to K11774: The GRUB entry for MOS is removed during an installation of BIG-IP version 9.x.

Note: Due to a different known issue, it is not possible to format a BIG-IP 6900 or 8900 system to use the partitions disk-formatting scheme by executing the image2disk --format=partitions command against the BIG-IP 10.1.0 ISO image. For more information, refer to K11063: Installing BIG-IP version 10.1.0 on a 6900 or 8900 platform fails and corrupts the bootloader.
