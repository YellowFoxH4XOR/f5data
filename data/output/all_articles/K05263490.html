This article describes how to update a BIG-IQ Centralized Management (CM) system in a standalone or high availability (HA) configuration without a data collection device (DCD) cluster configured.

Note: To update or upgrade a BIG-IQ system configuration with a DCD cluster, refer to K51342220: Upgrading the BIG-IQ videos and procedures

Upgrade a BIG-IQ CM system in a standalone or HA configuration

The first step is to ensure that your system does not have a DCD configured.

Verify no BIG-IQ DCD is configured

  • Log in to the BIG-IQ CM user interface.
  • Go to System > BIG-IQ Data Collection Cluster > BIG-IQ Data Collection Devices and confirm that it indicates No BIG-IQ Data Collection Device is added.

If applicable, remove the standby system from the HA group

If your system is part of an HA configuration, remove the standby system using the following steps:

  1. Log in to the standby system user inteface.
  2. Go to System > BIG-IQ HA.
  3. Select Remove Standby.
  4. Select Remove to confirm.

    Note: The system logs you out when you complete this step.

Upgrade the active BIG-IQ system

  1. Log in to BIG-IQ user interface.
  2. Go to System > Software Management > Installations.
  3. Select Upgrade.
  4. For Software Image, select the image to install.
  5. In the Target Volume list, select the volume on which you want to install the image.
  6. Select the Reboot into Target Volume check box if you want BIG-IQ system to automatically restart after the software installation.
  7. Select the Back up the BIG-IQ system before upgrade check box to generate a UCS backup.
  8. Select Install.
  9. The BIG-IQ system reboots into the new volume and loads the new software version after installation completes.

    Important: Depending on your configuration and the number of devices you are managing, the installation process can take up to an hour. During this time, it is important that you do not interrupt the installation process by restarting services or the server.

  10. If your system is part of an HA configuration, repeat these steps to upgrade the standby BIG-IQ system.

After performing the previous steps, if your system is part of an HA configuration, refer to the following article to learn how to reestablish HA connectivity: K36398804: Managing high availability on the BIG-IQ system.
