Known Issue

The BIG-IP system may incorrectly generate a FIPS error message.

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP platform that does not contain FIPS hardware. 
  • You perform a certificate/key management operation using the following methods:
     
    • Configuration utility
    • F5 Enterprise Manager system, if the system is managing the BIG-IP system
    • iControl API

Impact

There is no impact. This error message does not indicate a functional problem on a non-FIPS platform, and you can safely ignore the message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/daemon.log file, you may notice an error message similar to the following example:

    Jun 20 21:29:29 bigip err iControlPortal.cgi[14031]: Checking for FIPS card.. FIPS open failed.
