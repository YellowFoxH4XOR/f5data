Description

The BIG-IP 'DNS Relay Proxy Service' runs as a Windows service and is an optional component in the BIG-IP Edge Client package.

More details are in articles:

  • K9694: Overview of the Windows DNS Relay Proxy service
  • K72735781: DNS relay proxy service functionality on Windows

Environment

  • DNS Relay Proxy Service
  • APM
  • VPN 
  • EdgeClient

Cause

BIG-IP APM admin wants to verify the presence of 'DNS Relay Proxy Service' component on Windows machine

Recommended Actions

There are several methods how to check the presence of 'DNS Relay Proxy Service' on Windows machine:

  1. Download the Client Troubleshooting Utility (CTU) (more details in K12444) on the testing Windows machine and launch it. On the left tab menu on the bottom, there is the 'DNS Relay Proxy' line.
    • If the component is installed, then the service has the green checkmark and on the main central details tab, the administrator can see the component which consists of 2 files F5FltDrv.sys and F5FltSrv.exe with details.
    • If the component is not installed, then under the main details tab the status listed as 'not installed' accordingly.
       
  2. Download the Client Troubleshooting Utility (CTU) on the testing Windows machine, launch it, go to 'File -> Generate Report'.
    • Inside of CTU report, there are 2 sections where the APM administrator can confirm that 'DNS Relay Proxy Service': Components or F5 Network Access Diagnostic.
       
  3. On Windows machine, open Services Manager (services.msc) utility, if the DNS Relay Proxy Service is installed, then search for 'F5 Networks DNS Relay Proxy Service'
