K000153027: F5XC Login Stuck at “Your access request is being Processed”

Description

When accessing the F5 Distributed Cloud (F5XC) Console, a user may encounter the message “Your access request is being Processed” and is unable to proceed to the dashboard. This occurs if the user is assigned only the default role "ves-io-default-role", which lacks permissions to access other required resources. 

Environment

  • F5®Distributed Cloud (XC) Console
  • User role: ves-io-default-role
  • Identity/Access Management in F5XC 

Cause

 The role ves-io-default-role is assigned to the user, which only includes the following API Groups:

  • ves-io-web-access-read
  • ves-io-web-access-write

This role is insufficient for accessing the F5XC Console beyond the login screen. Without additional permissions, the system holds the login request for admin approval, displaying the “Your access request is being Processed” message.

Answer/Recommended Actions

To quickly resolve this login issue, follow the steps below. Before making any changes, ensure you have admin-level IAM privileges in the tenant.

1. Verify Current Role Assignment

    • Navigate to: Tenant → Identity & Access Management → Roles.
    • Confirm if the user is assigned only ves-io-default-role.

2. Assign an Appropriate Role or Group

  • Add the user to a role/group with adequate permissions, for example:
      • f5xc-account-protection-monitor (read-only/monitoring)
    • Or another functional role based on required access level.

3. Confirm Login

    • Ask the user to log out and log back in.
    • Validate that they can now access the dashboard successfully.

Additional Information

  • The ves-io-default-role is primarily for minimal web access and does not allow full platform access.
  • Selecting the correct group depends on the level of access required by the user (monitoring, configuration, admin, etc.).
  • For more details on role-based access control in F5XC, refer to: Role-based Access Control Concepts
