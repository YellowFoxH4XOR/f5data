K69416543: ICMP echo reply packets are sometimes blocked

Type
Support Solution
Published
2022-03-14
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.2, 16.1.1, 16.1.0, 15.1.4
Source
https://my.f5.com/manage/s/article/K69416543

Description

Sometimes after the clients have switched networks for example between docked / undocked or ethernet / wifi the client can no longer ping certain servers located on the corporate network.

Environment

Relevant environmental factors specific to the topic

  • CMP is enabled
  • The default route domain is used

Cause

This is related to Bug ID 1047213: Client to Client communication on default route domain is failing when CMP is enabled

Recommended Actions

Demote the virtual server from CMP processing.
# tmsh modify ltm virtual <virtual> cmp-enabled no

OR

You can request an Engineering Hotfix for with the fix for ID 1047213.

  •  Please open a case with F5 Support and reference this Support Solution to request the Engineering Hotfix
     K4918: Overview of the F5 critical issue hotfix policy
