Description
You're trying to update an BIG-IP SSL Orchestrator [SSLO] configuration with a new CA certificates bundle.
After you click "Deploy", the Configuration Utility reports the following error message:
invalid argument 0; expected syntax spec:"4905 15][TCP::release 0]

Environment

  • You're using BIG-IP SSLO;
  • You're running an HA pair;
  • You're trying to deploy a new CA certificate bundle to an existing SSLO configuration.

Cause
This is a consequence of BUG ID747588

Recommended Actions

You would need to sync the cluster (so that the new CA certificate bundle object is pushed to the peer unit).
K13920: Performing a ConfigSync using the Configuration utility???????

Additional Information
Depending the modification you tried to deployed to SSLO, you may need to first undo the failed deployment.
To do so:

  1. Navigate to the SSLO main menu
  2. Click the tab related to the modification you were trying to implement
  3. Click the check box to the name of the object
  4. Click Delete
