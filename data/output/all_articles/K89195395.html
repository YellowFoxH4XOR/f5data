Known Issue

BIG-IP APM Oracle Access Manager (OAM) integration may fail for JDK version 1.6.0_27 or later.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration includes an access profile for OAM.
  • The OAM Access Server is installed with JDK version 1.6.0_27 or later.

Impact

Attempts to authenticate through BIG-IP APM OAM fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users cannot authenticate through BIG-IP APM OAM.
  • When running the eamtest tool to check connectivity to the OAM Access Server, the system logs error messages that appear similar to the following examples:

    Preparing to connect to Access Server. Please wait.
    Access Server you specified is currently down.
    Please check your Access Server.oamconfig[2368]: Could not configure OAM

Workaround

To work around this issue, you can install the OAM Access Server with a JDK version older than 1.6.0_27.
