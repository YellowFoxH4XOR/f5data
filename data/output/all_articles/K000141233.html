Description

How to renew self-signed certificate in Velos

Environment

  • F5OS-C
  • GUI
  • Device Certificate

Cause

How to renew self-signed certificate in Velos

Recommended Actions

  1. Login to the active controller via GUI
  2. Go to Authentication & Access
  3. Select TLS Configuration
  4. Under Self-signed certificate, click Create certificate
  5. Fill out the form
  6. Store TLS, set to True
  7. Click Save

Additional Information

These steps will overwrite the existing certificate and you will be logged out from the system.

Login again once prompted.
