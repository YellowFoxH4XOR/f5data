Known Issue

Accessing the DNS properties page in the Configuration utility causes the ConfigSync status to change.

This issue occurs when all of the following conditions are met:

  • You have a redundant BIG-IP pair with a properly synchronized configuration.
  • You navigate to the DNS properties page in the Configuration utility as follows: System > Configuration > Device > DNS.

Impact

The ConfigSync status changes to Sync Recommended.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • While no configuration changes are being made to the BIG-IP configuration, the ConfigSync status changes to Sync Recommended.
