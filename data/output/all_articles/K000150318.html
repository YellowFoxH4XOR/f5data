Description

After removing a local user(s) from the BIG-IP system, local user directories remain in the /home directory despite no longer having any user associated with them.

Environment

Relevant environmental factors specific to the topic

  • You have deleted a local user via TMSH
  • You have deleted a local user via the Configuration Utility
  • You no longer need information stored by that user/in that directory

Cause

Local configuration files are created at the same time as new users and stored in the /home directory.

Directories are not removed automatically after a user is removed from the BIG-IP system.

 

Recommended Actions

This is expected and normal behavior - however if you no longer need any of the information or files stored in the user directory, you can safely delete the user directories no longer in use.

For example user "exampleuser"

Commands:

cd /home

rm exampleuser

Additional Information

Reboot will not remove user directories automatically.
