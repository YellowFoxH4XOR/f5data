K41134052: BIG-IQ Not collecting stats from BIG-IP avrd log error: Can't insert messages to queue - some external log will be lost!

Type
Support Solution
Published
2020-09-27
Updated

  • BIG-IP

Source
https://my.f5.com/manage/s/article/K41134052

Description

Stats Collection doesn't work. BIG-IP device has properly deployed Analytics IApp and BIG IP has connectivity to Data Collection Node

bigip.conf contains:

analytics global-settings {
    avrd-interval 30
    ecm-port 443
    enable-bigiq-configuration enabled
    offbox-protocol https
    offbox-tcp-addresses { 10.0.0.1 10.0.0.2 }
    offbox-tcp-port 443
    source-id cf4c8bd5-a5bc-4b9c-887d-3b594eaee895_10.0.0.15
    use-offbox enabled
}

/var/log/avr/avrd.log

EXTERNAL_MESSAGES|ERROR|Sep 03 13:28:33.429|15742|lib/avrpublisher/infrastructure/avr_http_connection.cpp:0124| Can't insert messages to queue - some external log will be lost!

Environment

  • BIG-IQ CM and DCD Cluster
  • Stats Collection enabled
  • BIG-IQ CM shows assigned DCD node to BIG-IP device
  • Analytics IApp properly deployed on BIG-IP
  • BIG-IP bigip.conf contains "analytics global-settings" section
  • telnet from BIG-IP to BIG-IQ DCD works on port 443
Cause

Bug ID 898333

Recommended Actions

Restart avrd daemon on affected BIG-IP Device
  1. Run following command in CLI form bash:
    bigstart restart avrd

Note: The BIG-IP Analytics module does not collect, aggregate, and publish application performance data at the time of restart
