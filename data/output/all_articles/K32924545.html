K32924545: BIG-IP ASM/Advanced WAF system may report empty parameter value for requests with non-empty parameters due to improper json format.

Description

If a security policy has the violation "Illegal empty parameter value" configured, the BIG-IP ASM/Advanced WAF system may report empty parameter value for requests with non-empty parameters due to improper json format. In this case, the BIG-IP ASM/Advanced WAF system may block the requests due to this violation, if the security policy is enforced.

Environment

  • BIG-IP ASM
  • Security policy configured with the violation "Illegal empty parameter value"
  • Improper JSON request

Cause

Due to improper JSON format, the system cannot parse the parameter value properly, which causes the BIG-IP ASM/Advanced WAF system mistakenly recognizes it as an empty parameter value.
For example:

"redirect_url":www.test.com,
With proper json format, the parameter should be sent as:
"redirect_url":"www.test.com",

Recommended Actions

As a temporary workaround, you may consider disabling this violation check in policy building.
  1. Log on to the BIG-IP ASM Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Select your security policy.
  4. In Parameters, uncheck the box for "Illegal empty parameter value".
  5. Click Save.
  6. Click Apply Policy.


For permanent solution, you should correct the improper formatting of JSON of the application.
