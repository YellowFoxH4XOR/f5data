K41255924: Some IPv6 client connections get RST when connecting to APM virtual

Type
Support Solution
Published
2021-12-28
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K41255924

Description

Remote VPN clients with some IPV6 addresses are unable to connect to BIG-IP APM VPN

Environment

  • BIG-IP APM
  • VPN
  • Client with IPV6 address

Cause

IPv6 client has the last 4 bytes of the IP address set to some special-purpose address, e.g., multicast address.

Recommended Actions

Change the last 4 bytes of the client IPv6 address to avoid the IPv4 special-address range.
