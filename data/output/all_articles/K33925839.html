Topic

This article applies to BIG-IP APM licensing for VELOS.

Description

BIG-IP APM base and add-on licenses come with 500 SSL-VPN (CCU) user sessions. You can augment the BIG-IP APM base license with Add-on Throughput, Add Max, and incremental SSL-VPN (CCU) user-session licenses. The following table outlines VELOS Throughput, Add Max, and SSL-VPN user licensing.

Important: You may need to apply and activate a new license to obtain the licensed features presented in this article.

The BIG-IP APM system uses different types of licenses, depending on the type of resource you access:

  • The system uses an access session license when you start any new session.
  • The system uses an SSL-VPN user connectivity license (CCU) when you are assigned one or more BIG-IP APM resources with tunnel-type access.
  • The system uses a secure web gateway (SWG) license when you employ a URL filtering service or an SWG service.

Beginning in September 2019, for BIG-IP APM standalone, GBB (Best), and BIG-IP APM add-on licenses, after you re-activate the license on your BIG-IP system, you may observe that the value of the total access sessions and total swg limited sessions increases to a large value (10M, 20M, and so on) as displayed in the following example output:

# tmsh show apm license
--------------------------------------------
Global Access License Details:
--------------------------------------------
 total access sessions: 10.0M
 [...]
 total swg limited sessions: 10.0M

This occurs so that the number of total access sessions and total swg limited sessions are not restricted based on licensing. Note, however, that the values (10M, 20M, and so on) do not indicate your BIG-IP APM system's capacity to handle the number of sessions. You must continue performing capacity and sizing tests before you deploy your BIG-IP system in production. This licensing change does not affect the current CCU and SWG license enforcement.
