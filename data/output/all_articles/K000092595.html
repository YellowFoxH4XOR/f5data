K000092595: "No space left on device" error while creating UCS file

Type
Support Solution
Published
2022-11-16
Updated
2022-11-16
Source
https://my.f5.com/manage/s/article/K000092595

Description

When generating a UCS archive or saving configuration, users may see similar error output:


Unexpected Error: Can't write temp config file "bigip.conf", in temp dir "/.config.tmp/euUFPt", No space left on device.

Error during config save.

Unexpected Error: UCS saving process failed.


Also, the df -h command may produce the following output, which indicates that the root file system is at 100 percent usage:

Filesystem     Size Used Avail Use% Mounted on

/dev/md4       427M 427M    0 100% / <------- FULL

none            24G 2.2M  24G  1% /dev/shm

/dev/md6       3.2G  76M 2.9G  3% /config

/dev/md5       3.3G 2.5G 636M 80% /usr

/dev/md7       3.0G 563M 2.3G 20% /var

/dev/md1        30G 3.9G  25G 14% /shared

/dev/md2       6.9G 192M 6.4G  3% /var/log

none            24G  54M  24G  1% /shared/rrd.1.2

none            24G  21M  24G  1% /var/tmstat

none            24G 1.3M  24G  1% /var/run

prompt         4.0M  24K 4.0M  1% /var/prompt

none            24G    0  24G  0% /var/loipc


Environment

  • Big-Ip
  • UCS Archive
  • Disk Space


Cause

The / partition was full



Recommended Actions

  1. Review the / file system if there are unexpected files and delete them.
  • Check / file system with command in bash:

find / -xdev -type f -exec du {} \; | sort -rn | head -20
