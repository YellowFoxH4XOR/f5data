Description

Publishing an NGINX [Plus] configuration from the NIM ui fails with the following error or something similar:

A conflict was detected while publishing the configuration. The published configuration is older than the active instance configuration. Please reload the most recent instance configuration, then try again.
Error code: 131025

This issue may occur when one of the following actions is performed:

  • Publish an NGINX [Plus] configuration in Staged Configs two times, one after the other
  • Publish an NGINX [Plus] configuration in Instances two times where the NGINX [Plus] configuration has changed on the NGINX Plus instance between publishings

Environment

NGINX Instance Manager

Cause

The issue is due to a NIM ui held timestamp that is compared to the timestamp of the current configuration on the NGINX [Plus] instance.

Recommended Actions

To resolve the conflict:

  • Click away from the staged or instance configuration, e.g. click on the Manage link within the left column
  • Click back into the staged or instance configuration
  • Publish the configuration
