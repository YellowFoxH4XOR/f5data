Issue

You should consider using this procedure under the following conditions:

  • The BIG-IQ user interface is stuck with a Waiting for BIG-IQ services to become available error message
  • The BIG-IQ user interface is unresponsive

Symptoms

When attempting to login to the BIG-IQ system, you may encounter one or more of the following symptoms:

  • The BIG-IQ user interface has started, but you are unable to log in.
  • The BIG-IQ user interface displays following error message for an extended period, which may last upto 10 minutes or longer.

          Waiting for BIG-IQ services to become available

Recommended Actions

This issue may occur when the BIG-IQ database or other indexing processes has stopped functioning properly, or there are other unusual query demands on the database. The issue may be resolved by restarting the BIG-IQ database and indexing processes. To do so, perform the following procedure.

Note: By restarting services through the Traffic Management Shell (tmsh), they are shut down cleanly and brought back up, alleviating any issues from a previous reboot.

Impact of procedure:Performing this procedure will temporarily pause statistics gathering and management of BIG-IP devices, if they were running.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To restart the BIG-IQ services, type the following command:

    BIG-IQ 7.1.0 and later

    restart /sys service postgres tokumond restjavad webd guiserver

    Prior to BIG-IQ 7.1.0

    restart /sys service tokumx tokumond restjavad webd guiserver
