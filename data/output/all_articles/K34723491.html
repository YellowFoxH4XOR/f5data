K34723491: Unable to use the F5 Extension to install Declarative Onboarding from vscode

Type
Support Solution
Published
2021-09-27
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • F5 Automation and Orchestration
  • F5 Declarative Onboarding
Source
https://my.f5.com/manage/s/article/K34723491

Description
When using the VSCode Extension (https://marketplace.visualstudio.com/items?itemName=F5DevCentral.vscode-f5) you may have versioning inconsistencies that don't allow for installation of the Declarative Onboarding with the extension

Environment

  • Declarative Onboarding
  • BIG-IP

Cause
The vscode extension is not supported by F5 Support as it is a creation from DevCentral and community driven.  Support can be found here:
https://github.com/f5devcentral/vscode-f5/issues

Recommended Actions
Alternatively, you may wish to use one of the supported methods of Declarative Onboarding

  1. Postman - Example on how to install AS3: https://clouddocs.f5.com/training/community/automation/html/class01/module2/lab2.html
  2. Ansible https://f5-automation-toolchain-lab.readthedocs.io/en/latest/docs/module6/lab2.html
  3. Image generator - Create a VM image with DO pre-installed https://github.com/f5devcentral/f5-bigip-image-generator
