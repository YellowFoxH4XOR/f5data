Description

You want to configure BIG-IP to load balance outbound (internet) traffic between multiple ISP/gateways.

Environment

  • BIG-IP LTM / BIG-IP LC
  • Wildcard Virtual Server

Cause

None

Recommended Actions

Create a Transparent ICMP Health Monitor
A transparent health monitor forces the BIG-IP to ping through the transparent device (ISP router) to a destination address (for ex. 8.8.8.8). This behavior allows the transparent device to be tested, and, if there is no response from the destination, the BIG-IP system marks the transparent device down.
  1. In the Configuration Utility, open the Local Traffic > Monitors page and click Create.
  2. Use the following information below for the new monitor:
     
    Form FieldValue
    Name<Health Monitor Name>
    TypeGateway ICMP
    TransparentYes
    Alias Address<Destination Address>
    for ex. 8.8.8.8
  3. Click Finished.

Create a Default Gateway Pool
A default gateway pool is the address of the ISP router or the gateway.
  1. In the Configuration Utility, open the Local Traffic > Pool > Pool List page and click Create.
  2. Use the following information below for the new pool:
     
    Form FieldValue
    Name<Pool Name>
    Health Monitors<Custom Transparent Health Monitor>
    Load Balancing Method<Modify based on your preference>
    New Members (Address)<Gateway IP address>
    New Members (Service Port)* All Services
  3. Click Add. Configure additional pool members if multiple ISP/Gateways will be load balanced.
  4. Once all is added, click Finished.

Create a Default Wildcard Virtual Server
A default wildcard virtual server is a wildcard virtual server that listens to 0.0.0.0 and uses port 0 and handles traffic for all services.
  1. In the Configuration Utility, open the Local Traffic > Virtual Servers > Virtual Server List page and click Create.
  2. Use the following information below for the new virtual server:
     
    Form FieldValue
    Name<VS Name>
    TypePerformance (Layer 4)
    Destination Address / Mask0.0.0.0/0
    Service Port* All Ports (0)
    Protocol* All Protocols
    VLAN and Tunnel TrafficEnabled on..
    <Internal VLAN>
    Source Address TranslationAutomap
    Address TranslationDisabled
    Port TranslationDisabled
    Default Pool<Gateway Pool>
  3. and then click Finished.
You should now have a Wildcard Outbound Virtual Server. It should be configured to listen only in your Internal VLAN (Private Network) and load balance internet traffic between multiple ISP/gateway. The source address will be translated to the outgoing external public self-ip of the BIG-IP since we set the SNAT to Automap.
