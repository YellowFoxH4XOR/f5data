Description

After a power outage on the hypervisor, the virtual edition device is unable to reboot and perform tmsh commands.
Similar errors appear on cli window.
 

# tmsh exception: (Can't create tmsh temp directory "/var/system/tmp/tmsh" Read-only file system) (framework/TempDir.cpp, line 144), exiting...

 
If you try to reboot the system you get the following error.
 

# reboot

Failed to start reboot.target: Activation of org.freedesktop.systemd1 timed out
See system logs and 'systemctl status reboot.target' for details.
Failed to open /dev/initctl: No such device or address Failed to talk to init daemon.

Environment

  • BIG-IP - VE LTM
  • Hypervisor power off
 
Cause
 
Unknown at the time of publishing this article.
 
 
Recommended Actions
 
  1. Apply the following commands.

    # umount /
    # mount /
    # systemctl --force --force reboot

Additional Information

  • Even when the system comes back, the file system is already corrupted, so it is important to consider redeploying.
  • This process has not been tested on a physical appliance.
