Known Issue

This is the result of a known issue. A memory leak may occur when the Detect ConfigSync Status feature is enabled on a BIG-IP LTM high availability pair. The Detect ConfigSync Status feature is used to detect synchronization changes between the two systems in a redundant pair.

Note: The Detect ConfigSync Status feature is the most visible cause of the memory leak due to the constant communication that occurs when this feature is enabled. Performing a manual configsync or using iControl requests will also result in a memory leak; however, the leak will occur at a slower rate than a leak that resulted from using the Detect ConfigSync feature.

F5 Networks Product Development tracked this issue as CR83777 and CR83759 and it was fixed in BIG-IP LTM versions 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

You can enable or disable the Detect ConfigSync Status feature from the command line or the Configuration utility.

Important: The following work around only helps prevent the most common cause of the memory leak that results when the Detect ConfigSync Status feature is used. The memory leak can still occur when a manual configsync is performed or an iControl application sends requests to the BIG-IP system.

Command line

  • To enable the Detect ConfigSync Status feature from the command line, type the following command:

    bigpipe db ConfigSync.Autodetect enable

  • To disable the Detect ConfigSync Status feature from the command line, type the following command:

    bigpipe db ConfigSync.Autodetect disable

Configuration utility

To enable or disable the Detect ConfigSync Status feature from the Configuration utility, perform the following procedure:

  1. Log in to the BIG-IP LTM Configuration utility.
  2. Select System.
  3. Select High Availability.
  4. Select ConfigSync.
  5. Depending on whether you want to enable or disable the Detect ConfigSync Status feature, select or clear the Detect ConfigSync Status check box.
  6. Select Update.
