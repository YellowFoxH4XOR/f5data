Known Issue

Pool level current sessions statistics display an inaccurate value.

This issue occurs when all of the following conditions are met:

  • You configure your BIG-IP system with a virtual server that uses an HTTP profile and pool resource.
  • When the system load-balances an HTTP request to a pool member, it terminates the request before the pool member sends an HTTP response.
  • You view the pool level statistic for current sessions.

Impact

The system increases pool-level statistics related to current sessions with each request and does not decrease them when it terminates the session.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view pool level statistics for an affected pool, the current session's value increases with each request and does not decrease when the session terminates.
  • Current sessions statistics appear unexpectedly large in relation to what you expect for session counts.
