Known Issue

New releases of NGINX Controller support the four latest versions of NGINX Plus. If you attempt to update NGINX Controller Agent when the Controller is paired with an unsupported NGINX Plus instance, the update may fail with error messages appear similar to the following example:

 E           RuntimeError: The component entered an isError state while checking for existence. See data provided in currentStatus.state.conditions: [{'message': 'Failed testing config before applying: nginx: [emerg] dlopen() "/etc/nginx/modules/ngx_stream_f5_metrics_module.so" failed (/etc/nginx/modules/ngx_stream_f5_metrics_module.so: cannot open shared object file: No such file or directory) in /etc/nginx/nginx.conf:8\nnginx: configuration file /etc/nginx/nginx.conf test failed\n', 'type': 'failed'}]

For information about compatible NGINX Controller and Plus versions, refer to the NGINX Tech Specs Guide.

Resolution

To recover from the error and resume the NGINX Controller Agent update, perform the following linked procedures:

  1. Upgrade the NGINX Plus instance to a supported version by following the NGINX Plus Admin Guide: Installing NGINX Plus.
  2. Reinstall the NGINX Controller Agent by following the NGINX Controller Admin Guide: Installing NGINX Controller Agent.
