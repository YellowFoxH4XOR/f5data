Topic

Note: This feature is referred to as "autoconf" in the configuration files, as "discovery" in the Configuration utility, and is frequently referred to as "auto-configuration."

When the Discovery option is enabled, 3-DNS automatically collects all of the virtual server information from a BIG-IP system, 3-DNS, or a host. Before the Discovery option was available, you had to manually enter virtual server information into the wideip.conf file.

When enabling the Discovery option, specify one of the following three settings:

Note: For discovery to work on hosts, you must enable Simple Network Management Protocol (SNMP) probing for that host. For information about SNMP probing, refer to the Probing and Metrics Collection chapter in the 3-DNS Reference Guide. 3-DNS will be able to discover virtual servers from all load balancers except for the Cisco Local Director.

ON
When the Discovery option is set to ON, the 3-DNS Controller polls the BIG-IP systems and host systems in the network every 30 seconds to update the configuration information for those systems. Any changes, additions, or deletions are then made to the controller's configuration.

ON/NO DELETE
When the Discovery option is set to ON/NO DELETE, the 3-DNS Controller polls the BIG-IP system and host systems in the network every 30 seconds to update the configuration information for those systems. Any changes or additions are then made to the controller's configuration. Any deletions in the configuration are ignored. This setting is helpful if you want to take systems in and out of service without modifying the 3-DNS configuration.

This is the recommended level, as it discovers the virtual servers but it helps prevent a virtual server from being deleted unintentionally from a BIG-IP system or host.

OFF
When the Discovery setting is set to OFF, the 3-DNS Controller does not collect any configuration information from the BIG-IP system and host systems in the network. Instead, you must make all changes to the configuration either by using the Configuration utility, or by editing the wideip.conf file.

This is the default setting. This is behavior most similar to 3-DNS versions prior to 4.5.

Product-specific behaviors

Behavior on 3-DNS

When a 3-DNS uses discovery on another 3-DNS, it gathers information from the wideip.conf file.

Behavior on BIG-IP systems

When a 3-DNS uses discovery on a BIG-IP system, it gathers information from the bigip.conf file.

Behavior on BIG-IP and 3-DNS combination systems or BIG-IP Link Controller

When a 3-DNS uses discovery on a BIG-IP system that is also licensed for the 3-DNS module or a BIG-IP Link Controller, it gathers information from the bigip.conf file.
