Issue

If the BIG-IP system is not licensed for LDAP, Radius, SSL OCSP, or TACACS authentication features, error messages similar to the following may appear after you start the BIG-IP system and it attempts to load base authentication profiles:

Jun 2 10:37:32 D63TTT mcpd[2699]: 01070356:3: LDAP Authentication feature not licensed.
Jun 2 10:37:32 D63TTT mcpd[2699]: 01070356:3: RADIUS Authentication feature not licensed.
Jun 2 10:37:32 D63TTT mcpd[2699]: 01070356:3: SSL Online Certificate Status Protocol feature not licensed.
Jun 2 10:37:32 D63TTT mcpd[2699]: 01070356:3: TACACS Authentication feature not licensed.

These error messages indicate expected behavior; they do not indicate an issue with the BIG-IP system. However, F5 Product Development is tracking this issue as CR48862.
