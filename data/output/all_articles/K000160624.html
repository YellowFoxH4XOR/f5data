K000160624: Sdm group user definition in "/etc/group" file may differ between HA units.

Type
Support Solution
Published
2026-04-06
Updated
2026-04-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0, 17.1.2, 17.1.1, 17.1.X, 17.5.X, 21.0.X, 21.0.0, 17.5.1, 17.5.0, 17.1.3
Source
https://my.f5.com/manage/s/article/K000160624

Description

The sdm group user definition in "/etc/group" file may differ between BIG-IP HA units. Here is example. On "bigip1", no user account is added to sdm group user. Meanwhile, on "bigip2", two default user accounts, "f5hubblelcdadmin" and "admin", were added to sdm group. This happened when user ran full config-sync from "bigip1" to "bigip2".

 

[BIG-IP HA unit1]

[root@bigip1:Active:In Sync] config # grep ^sdm /etc/group
sdm:x:995:
[root@bigip1:Active:In Sync] config #

[BIG-IP HA unit2]

[root@bigip2:Standby:In Sync] config # grep ^sdm /etc/group
sdm:x:995:f5hubblelcdadmin,admin		<=== !!! two user accounts were added to sdm group
[root@bigip2:Standby:In Sync] config #

 

If remote authentication is used for BIG-IP administrative access (SSH/HTTPS), remotely authenticated user accounts may also be seen on sdm group users as well as default user accounts. For example, when remotely authenticated user account "user101" logged in to "bigip1" and full config-sync ran from "bigip1" to "bigip2", only "bigip2" can have "user101" user account name in sdm group users, as shown below.

 

[BIG-IP HA unit1]

[root@bigip1:Active:In Sync] config # grep ^sdm /etc/group
sdm:x:995:admin,f5hubblelcdadmin
[root@bigip1:Active:In Sync] config #

[BIG-IP HA unit2]

[root@bigip2:Standby:In Sync] config # grep ^sdm /etc/group
sdm:x:995:f5hubblelcdadmin,admin,user101		<=== !!! remotely authenticated user "user101" exists
[root@bigip2:Standby:In Sync] config #

 

Multiple remotely authenticated administrative user accounts may be added to sdm group users if multiple remotely authenticated administrative users logged in to BIG-IP and full config-sync ran. If many user accounts were added to sdm group users and sdm group line exceed 4000 characters, restnoded may fail to start up properly and restart loop may happen. Refer to K000138389 for more information.

 

Note: sdm group user is allowed to access to iRules LX (ILX) workspaces.

 

Environment

  • BIG-IP HA pair without iRules LX licensed/provisioned.
  • Full config-sync runs from one of HA unit to peer.

 

Cause

Bug ID2260905.
