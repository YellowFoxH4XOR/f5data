Description

  • Traffic disrupted while tmm restarts
  • Core file with SIGSEV 
  • Similar logs seen on /var/log/ltm:

    sod[8097]: 01140045:5: HA reports tmm NOT ready.
    sod[8097]: 010c0050:5: Sod requests links down.

Environment

One or more of the following:

  • A FastL4 virtual server that has hardware acceleration enabled
  • A NAT or SNAT object without a virtual server

Cause

Tmm receives an update from the ePVA for a hardware accelerated connection that is matched to the wrong correction. This can result in a tmm core, which is reported as a segment fault in the tmm log files. This is tracked with below ID:

Bug ID 841649: Hardware accelerated connection mismatch resulting in tmm core

Recommended Actions

To workaround the BUG temporarily, you can Disable hardware acceleration for this profile. 

For a permanent solution open a case with F5 support and request Eng HF.
