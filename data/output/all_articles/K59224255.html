Description

How to create address-list using the TMOS shell (tmsh).

Environment

  • Command-line interface (CLI) access
  • BIG-IP running 14.1.x and later

Cause

You want to create an address-list using the CLI.

Recommended Actions

  1. Login to tmsh from bash

    tmsh

  2. To create an address-list, use the following command syntax:

    create /net address-list [name] addresses [add | delete | modify | replace-all-with] {[IP address]}

    For example, to create an address-list named alist1, enter the following command:

    create /net address-list alist1 addresses add { 10.10.1.1 10.10.1.2 192.168.24.0/24 }

  3. To display an address-list, use the following command syntax:

    list /net address-list [[name] | all | [property]]

    For example, to view the addresses in an address-list named alist1, enter the following command:

    list /net address-list alist1

    The output appears similar to the following example:

    net address-list alist1 {
        addresses {
            10.10.1.1 { }
            10.10.1.2 { }
            192.168.24.0/24 { }
        }
    }

  4. To modify an existing address-list, use the following command syntax:

    modify /net address-list [name] addresses [add | delete | modify | replace-all-with] {[IP address]}

    For example, to add the IP address 10.10.1.3 to the address-list named alist1, enter the following command:

    modify /net address-list alist1 addresses add { 10.10.1.3 }

  5. If you want to delete an address-list, run following command:

    delete /net address-list [[name] | all]

    For example:

    delete /net address-list alist1

  6. For more help with the address-list command, enter the following command:

    help /net address-list
