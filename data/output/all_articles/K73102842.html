Description
Issue with performing automatic HA failover.  After implementing failover and testing, automatic HA failover is failing.

Environment

  • BIG-IQ 6.0.1, 6.0.0, 5.4.0
  • Automatic Failover

Cause
Feature functionality has changed in BIG-IQ.  Automatic fail-over is not supported in BIG-IQ 6.0.1

Version 4.4.0 included automatic fail-over.
Manual Chapter : Configuring for High Availability - "Configuring a high-availability pair is optional. However, if you configure a high-availability BIG-IQ system and the active peer fails, the standby peer will become active, enabling you to continue to manage devices."

With version 5.3 this is not the case as there is no automatic fail-over.
The notice in article K14736: BIG-IQ daemons about failed services causing fail-over is out of date.
