Known Issue

F5 Access fails to establish network access sessions for Windows devices configured with Secure Boot.

This issue occurs when all of the following conditions are met:

  • Your device uses the Microsoft Windows 10 operating system.
  • The Windows device has Secure Boot enabled.
  • You installed the BIG-IP Edge Client.
  • You use F5 Access to try to establish a network access session.
  • The Network Access profile has the Client Side Security > Integrated IP filtering engine option enabled.

Impact

F5 Access fails to establish a network access session.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • F5 Access fails to establish a network access session.
  • When you view the BIG-IP Edge Client log for the affected device, the system logs messages similar to the following for the attempted network access session:

Workaround

To work around this issue, you can disable Secure Boot on the Windows device or the Client Side Security > Integrated IP filtering engine option in the affected Network Access profile.

To disable the Client Side Security > Integrated IP filtering engine option, perform the following procedure:

Impact of workaround: Performing the following procedure disables the Client Side Security > Integrated IP filtering engine option in the Network Access profile.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to Access > Connectivity/VPN > Network Access (VPN) > Network Access Lists.
  3. Select the Network Access profile you want.
  4. Select the Network Settings tab.
  5. In Client Settings, select Advanced.
  6. Clear the Client Side Security > Integrated IP filtering engine check box.
  7. Select Update.
  8. Select Apply Access Policy.
