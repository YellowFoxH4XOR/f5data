Issue

Old Behavior

In versions prior to BIG-IP 10.1.0, the BIG-IP system allows the pool member ratio to be configured with a value between 1 and 65,535, and the node ratio to be configured with a value between 1 and 4,294,967,295.

New Behavior

Beginning in BIG-IP 10.1.0, the BIG-IP system allows the pool member ratio and node ratio to be configured with a value between 1 and 100.

Impact

If you upgrade a BIG-IP system to BIG-IP 10.1.0 and later, the configuration will fail to load if the previous configuration contained a pool member ratio or node ratio with a value outside of the 1 to 100 range. In addition, the system will display an error message that appears similar to the following examples:

  • Pool member ratio error message:

    01070081:3: The requested ratio for the pool member (10.10.10.10:80) is invalid.  [1..100].

  • Node ratio error message:

    01070694:3: The requested ratio for the node address (10.10.10.10) is invalid. The ratio must be between 1 and 100.

Recommended Actions

Before upgrading to BIG-IP 10.1.0 and later, F5 recommends that you configure the pool member ratio and node ratio with a value between 1 to 100. For information about modifying the affected ratio, refer to the Configuration Guide for BIG-IP Local Traffic Management.

If you have upgraded to BIG-IP 10.1.0 and later, you can recover the configuration by manually modifying the affected ratio. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Make a backup copy of the /config/bigip.conf file by typing the following command:

    cp -p /config/bigip.conf /var/tmp/bigip.conf.sol13884

  3. Edit the /config/bigip.conf file using a text editor of your choice.
  4. Locate the pool member or node configuration stanza.

    For example:

    Pool member configuration stanza

    pool testRatiopool {
       lb method member ratio
       members {
          10.10.10.10:http {
             ratio 65535
          }
       }
    }

    Node configuration stanza

    node 10.10.10.10 {
       ratio 4294967295
    }

  5. Modify the value on the ratio line to a value between 1 to 100 (inclusive).

    For example:

    Pool member configuration stanza

    pool testRatiopool {
       lb method member ratio
       members {
          10.10.10.10:http {
             ratio 99
          }
       }
    }

    Node configuration stanza

    node 10.10.10.10 {
       ratio 99
    }

  6. Save the modifications and exit the text editor.
  7. Load the configuration by typing the following command:

    tmsh load sys config
