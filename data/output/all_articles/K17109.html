Known Issue

The Update Check feature reports a different version of IP Geolocation database than what is currently installed.

This issue occurs when the following condition is met:

  • An Update Check is triggered either automatically or manually.

Impact

The Update Check feature continuously reports an out-of-date Geolocation database.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Update Check feature reports an out-of-date Geolocation database even after the latest database has been installed.
  • The Update Check feature is reporting a different Geolocation database version than what is currently installed.
