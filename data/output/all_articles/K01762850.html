K01762850: Edge Client crashes on Windows 11 ARM device

Type
Support Solution
Published
2022-06-16
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP APM: 16.1.3, 16.1.2, 16.1.1, 16.1.X, 16.1.0
Source
https://my.f5.com/manage/s/article/K01762850

Description
When connecting to VPN using a Windows ARM device, the Edge Client is crashing.
 

Environment

  • Windows PC or Tablet with APM64 CPU 
  • Edge Client
  • VPN

Cause
ARM64 support for the Edge Client was added from version 7220. Older versions of apmclient or Edge Client will not work on ARM devices, and will also not work in the WOW64 emulator

 

Recommended Actions

  1. Upgrade BIG-IP to at least version 16.1.2.2, as this is the first version to support the installer for ARM64
  2. Upgrade the apmclients to at least version  7.2.2.0 

Additional Information
None.
