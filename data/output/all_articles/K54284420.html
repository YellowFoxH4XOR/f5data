Known Issue

The BIG-IP system may not honor the Maximum Segment Size (MSS) value configured in the TCP profile when SYN cookie protection mode is activated.

This issue occurs when all of the following conditions are met:

  • You have a virtual server configured with a TCP profile that has a non-default MSS value. The default value is 1460 bytes.
  • The virtual server has either the software or the hardware SYN cookie protection enabled.

    Note: Hardware SYN cookie protection is enabled by default in the TCP profile. If the platform does not support hardware SYN cookie protection, the system uses software SYN cookie protection instead.

  • The SYN cookie protection mode is activated. For more information on SYN cookie protection activation, refer to K14779: Overview of BIG-IP SYN cookie protection (11.3.x - 12.x).

Impact

When the SYN cookie protection mode has been activated, the affected virtual server does not honor the MSS value specified in the TCP profile. As a result, this situation may affect network environments that require a non-default MSS value.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the SYN cookie protection mode has been activated, you may notice from a tcpdump capture that the BIG-IP system responds with the default MSS value (1460) instead of the customized value configured in the TCP profile.

    The following tcpdump capture shows a network connection from a client with an IP address of 192.168.72.68, using a customized TCP profile with the MSS value set to 984 bytes, and the BIG-IP system with an IP address of 192.168.72.37, responding with an MSS value of 1460 bytes.
