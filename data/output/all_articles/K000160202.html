Description

  • You have NGINX Instances send usage reports to the NGINX Instance Manager
  • The NGINX Instance Manager is not showing usage information in the [NGINX Usage] section
  • Verified usage reports are consistently sent from the NGINX instance from the nginx-agent.log
2026/02/02 14:14:14 [info] 2701568#2701568: usage report was sent
  • The NGINX Instance Manager reports an error from the nms.log
NGINX usage tracking: bad request: clock skew exceeded maximum tolerance, entry not created

Environment

  • NGINX Instance Manager

Cause

There is a clock skew between the NGINX host and the NIM host.

Answer/Recommended Actions

Syncing the hosts' system time with your NTP server.
