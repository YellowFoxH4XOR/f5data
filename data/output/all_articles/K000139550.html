K000139550: "SEVERE" and "probable memory leak" in Catalina Logs

Type
Support Solution
Published
2024-05-16
Updated
2024-05-16
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000139550

Description

You have encountered GUI issues on the Configuration Utility and noticed "SEVERE" messages in the Catalina logs, indicating memory leak like following example log:

SEVERE: The web application [/tmui] created a ThreadLocal with key of type [java.lang.ThreadLocal] (value [java.lang.ThreadLocal@199e5fd]) and a value of type [com.f5.util.User] (value [[ admin:true operator:false guest:false]]) but failed to remove it when the web application was stopped. Threads are going to be renewed over time to try and avoid a probable memory leak.

Environment

  • BIGIP Configuration Utility
  • GUI Issues

Cause

Bug ID 410420.

Recommended Actions

These log messages are cosmetic in nature and do not reflect an actual memory leak within the system. They only occur during shutdown processes and are not indicative of ongoing issues with system stability or performance.
