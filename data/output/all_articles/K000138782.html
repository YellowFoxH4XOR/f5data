Description

FTP connection is reset with reason 'FTP Not Connected' observed from packet captures

 

Environment

FTP virtual server

FTP profile

FTP Passive Mode

Cause

FTP servers can be configured to send a different IP address, along with other parameters like minimum and maximum port numbers when entering Passive mode, to be used by the client as the data channel. This is not supported by the FTP profile as it expects the data channel to be established on the same IP as the control channel.

Recommended Actions

Do not use 'pasv_address' parameter, or assign a different Passive Address to ensure that the IP remains the same

None
