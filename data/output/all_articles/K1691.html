Topic

BIG-IP is provided with two kernels: the ANIP kernel and the SMP kernel. BIG-IP will generally enable the correct kernel based on your configuration, but in some cases, you must configure BIG-IP to use a specific kernel.

SMP Kernel

The SMP kernel is used with both single and multiple processor BIG-IPs.

ANIP Kernel

The ANIP kernel is used on BIG-IP systems that are equipped with advanced networking hardware, such as Gigabit NICs or the Packet Velocity ASIC. Under medium and higher traffic load, BIG-IP traffic management functions can consume interrupt time on the CPU, preventing high-speed network interfaces from running at their maximum speed. The ANIP kernel dedicates one processor for low level network functions, and one for operating system and traffic management functions, allowing high speed network interfaces to operate at their maximum speed.

Default Behavior

The following platforms use SMP kernels, by default:

  • F5 Switch Appliances
  • Blade Servers
  • Dell Server Appliances

The following table outlines kernel usage for F5 server appliances

The ANIP kernel is the default kernel for IP Switch Appliances with two CPUs.

Note: Do not enable the ANIP kernel on F5 server appliances with a single CPU unless directed to do so by F5 Networks.

Choosing a Kernel

If you use a BIG-IP server appliance, there are two system configurations which can improve BIG-IP performance by changing the BIG-IP kernel from the default option.

BIG-IP server appliance in a Pure SSL Environment

If you use a BIG-IP server appliance for processing only SSL traffic and the BIG-IP server appliance is not equipped with a Gigabit NIC, you can improve performance by as much as 30% by using the SMP kernel.

BIG-IP server appliance in a Mixed SSL and Layer 4 Environment

If you use a BIG-IP server appliance for processing a majority of SSL and Layer 4 traffic and the BIG-IP server appliance is equipped with a Gigabit NIC, you can improve performance by using the ANIP kernel. The amount of improvement depends on the mix of traffic and is likely to be minimal.

In either scenario, if you would like to change to the alternate kernel, F5 Networks recommends you test the performance of each configuration before making the change in a production environment.

Determining Which Kernel You Are Using

You can determine which kernel you are using from the command line or the Configuration utility.

Command line:

  1. Log in to the command line.
  2. Display the kernel symbolic link, by typing the following command:

    ls -l /bsd

    You will receive output similar to the following:

    lrwxr-xr-x 1 root wheel 9 Mar 27 09:48 /bsd@ -> /bsd.anip

The end of the referenced line shows the kernel file with which the /bsd symbolic link is associated. In the preceding example, the ANIP kernel is configured.

Configuration utility:

  1. Log in to the Configuration utility.
  2. In the main navigation pane, select System.
  3. Click the Properties tab.
  4. Locate the Processing Mode field.

    The current kernel is displayed.

  5. Next to Processing Mode, the type of kernel is displayed.
  6. Next to Processors, the number or processors is displayed.

Determining the Number of Processors Installed in Your BIG-IP

You can determine how many processors are installed in your BIG-IP by using either the command line or the Configuration utility.

Command line:

  1. Log in to the command line.
  2. Display the system statistics summary by typing the following command:

    bigpipe summary

A number of lines are displayed. Near the end of the output you will see the number of processors installed in the line BIG-IP Total Number of CPUs.

Configuration utility:

  1. Log in to the Configuration utility.
  2. In the main navigation pane, select System.
  3. Click the Properties tab.
  4. Locate the Processors field.

The number of processors will be displayed.

Changing the Default Kernel

To change the kernel, use the following steps:

  1. Log in to the command line.
  2. Set the Local.Bigip.Boot.Kernel bigdb variable, by typing the following command:

    bigpipe db set Local.Bigip.Boot.Kernel = <kernel>

    Replace <kernel> with either SMP or ANIP, depending upon which kernel you would like to use.

    For example:

    bigpipe db set Local.Bigip.Boot.Kernel = ANIP

  3. To begin using the new kernel, reboot the system, by typing the following command:

    reboot

Restoring the Default Kernel

To restore the default kernel for your configuration, use the following steps:

  1. Log in to the command line.
  2. Delete the Local.Bigip.Boot.Kernel bigdb variable, by typing the following command:

    bigpipe db unset Local.Bigip.Boot.Kernel

  3. To begin using the default kernel, reboot the system, by typing the following command:

    reboot
