Description
When upgrading from 11.6.x to 13.1.3.5 (or lower) the configuration fails to load with the following /var/log/ltm message: 01070734:3: Configuration error: Can't associate classification overview selection (/[All]/uwid<ID String>) folder does not exist

A configuration item is set for the [all] partition instead of a specific partition.
Beginning in BIG-IP 13.1.0, the system no longer supports the [All] partition in the configuration file.

Environment

  • BIG-IP
  • Upgrade to v13.x or later
  • Loading the configuration on v13.x or later

Cause
Bug ID 949593: Unable to load config if AVR widgets were created under '[All]' partition

Conditions
This occurs if one or more AVR widgets in the configuration was created under the read-only '[All]' pseudo-partition.
This could have occurred if you were running a version of BIG-IP which did not include the fix for ID 721408.

Fixed In:
16.0.1.2, 15.1.3, 14.1.4, 13.1.4

Recommended Actions

1. Upgrade to a fixed version.

2. Manually edit the /config/bigip.conf configuration file and change '[All]' to 'Common':
    # sed -i 's/\\\[All\]/Common/g' /config/bigip.conf
    # tmsh load sys config
    # tmsh save sys config

This should be done before upgrading to BIG-IP v13.x or later, or before saving configuration to be loaded later, or before loading a saved configuration from the config files.
