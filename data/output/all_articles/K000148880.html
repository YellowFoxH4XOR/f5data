K000148880: Creating HTTP Monitors for Backend Servers using HTTP CONNECT on F5 BIG-IP

Applies to

  • BIG-IP DNS: 17.1.1
Source

Description

This article provides instructions on creating an HTTP monitor profile with HTTP CONNECT method to monitor backend Proxy server.

Environment

  • BIG-IP LTM
  • Monitor Profile
  • HTTP CONNECT Method
  • Pool Member: Explicit Proxy server

Cause

Guidance on creating an HTTP monitor profile with HTTP CONNECT method to monitor backend Proxy server.

Recommended Actions

A. Please refer to steps below for LTM Monitor profile.

  1. Login to BIG-IP GUI >> Local Traffic >> Monitors >> Create...
  2. Give the new HTTP monitor a new monitor profile name
  3. Select Type "HTTP"
  4. Under the "Send String", insert below HTTP CONNECT method code
    CONNECT fqdn:443 HTTP/1.1\r\nHost: fqdn\r\nConnection: Close\r\n\r\n
    Example code on www.example.com
    CONNECT www.example.com:443 HTTP/1.1\r\nHost: www.example.com\r\nConnection: Close\r\n\r\n
  5. Under the "Receive String", insert below HTTP received response code
    HTTP/1.[0-1] 200
  6. Leave the rest as default or configure it as you see fit.
  7. Click Finished to save the new monitor profile
  8. Attach it to the Explicit Pool that you have setup on LTM Pool

B. Please refer to steps below for GTM Monitor profile.

  1. Login to DNS >> Delivery >> Load Balancing >> Monitors >> Create...
  2. Give the new HTTP monitor a new monitor profile name
  3. Select Type "HTTP"
  4. Under the "Send String", insert below HTTP CONNECT method code
    CONNECT fqdn:443 HTTP/1.1\r\nHost: fqdn\r\nConnection: Close\r\n\r\n
    Example code on www.example.com
    CONNECT www.example.com:443 HTTP/1.1\r\nHost: www.example.com\r\nConnection: Close\r\n\r\n
  5. Under the "Receive String", insert below HTTP received response code
    HTTP/1.[0-1] 200
  6. Leave the rest as default or configure it as you see fit.
  7. Click Finished to save the new monitor profile
  8. Attach it to the Explicit Pool that you have setup on DNS Pool
