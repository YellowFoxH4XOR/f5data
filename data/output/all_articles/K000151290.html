K000151290: Can't download backup via API after upgrade to 1.8.0

Type
Support Solution
Published
2025-05-13
Updated
2025-05-13
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000151290

Description

After an upgrade to 1.8.0, you are no longer able to download the backup file via API using the /restconf path through TCP/443.


Environment

  • F5OS 1.8.0
  • using /restconf path on port 443

Cause

In F5OS 1.8.0, the /restconf API endpoint is accessible only via port 8888.


Recommended Actions

Use the /restconf path on port 8888.


Additional Information

API calls to port 443 must use the /api path.

API calls to port 8888 must use the /restconf path.
