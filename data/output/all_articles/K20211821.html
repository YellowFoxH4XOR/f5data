Description

During upgrade process, when trying to boot into the new volume, device shows inoperative in the command line. An error message similar to the following is logged to /var/log/ltm:
Software version is not covered by service agreement Service Check Date xxxxxxxx version date xxxxxxxx.
Note: The value xxxxxxxx represents the date displayed in relation to the BIG-IP Service Check Date & version date.


Environment

  • BIG-IP
  • Upgrade
  • Licensing


Cause

Service check date in license file does not meet requirement to install new software version. For more information refer to K7727: License activation may be required before a software upgrade for BIG-IP


Recommended Actions

  1. To verify the device has active support contract refer to: K32755669: How to verify support contract end date.
  2. For a device with an active service contract, try the workaround specified in K52240358: Error Message: 0107070e:0: Software version not covered by service agreement. Reactivate license before continuing.
  3. If the error still exists after applying the workaround, try the following steps:
    1. Boot to old software version volume
    2. Delete the newly created volume
    3. Re-activate license (see K7752: Licensing the BIG-IP system or K2595: Activating and installing a license file from the command line)
    4. Reinstall the software from ISO image. 
    5. Boot to newly installed volume
