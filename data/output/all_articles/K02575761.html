Description

APM setting "CAPTCHA After Number of Logon Attempts Equals" behavior:

This CAPTCHA counter value is related to the end of evaluation of Access Policy such as Allow or Deny. If the policy evaluation is finished with deny, it increases this internally tracked value. If the evaluation is finished with Allow, the counter value is reset.  The counter will persist for the IP or the username until it is reset.  If the counters upper value is reached, then the captcha will continuously be displayed for every logon attempt, and will get more complicated the more logins that fail (if using Google's CAPTCHA).

The captcha counter that is being tracked, for say the username, only increments when the client gets a DENY in the policy.  It does not increment just from entering a bad password.  You can test this easy by putting a message box on the ad auth agents failure branch.  The message box does not show up after entering a bad password once, but after 5 times, and then the client is sent to DENY in the policy.

Example:

If an ad auth agent settings is configured with "Max Logon Attempts Allowed" to 5, and my captcha setting to 4, I need to enter a bad password 20 times before the captcha shows up. I need to fail 5 attempts, by hitting DENY in the VPE (then captcha counter goes up), until after my 4th failure of hitting DENY in the policy. 

When this setting is set to frequency '0', the CAPTCHA shows up at the initial logon page the first logon attempt.  Once the CAPTCHA has been satisfied, it will not show up again, if the user successfully logs in. This internal counter that is used to track these logon failures (hitting DENY in the VPE), can ONLY be reset by restarting TMM.  

Restarting TMM will result in traffic disruption so use with caution, only do this in a testing environment.

Environment

APM w/ Google v3 CAPTCHA configuration defined in the configuration, and also included on logon page in a per-session policy.

  • APM per-sesson policy
  • Google CAPTCHA resource configured in Access  ››  Authentication : CAPTCHA Configurations
  • Logon page agent configured captcha dropdown selected pointing to latter resource that was configured on the APM.
