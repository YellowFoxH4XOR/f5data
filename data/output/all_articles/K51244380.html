Known Issue

The F5-BIGIP-APM-MIB::apmPmStatConfigSyncState SNMP object identifier (OID) may return an incorrect value.

This issue occurs when all of the following conditions are met:

  • An access profile has been edited, but not yet applied.
  • An SNMP client requests the F5-BIGIP-APM-MIB::apmPmStatConfigSyncState OID from the BIG-IP APM system.

Impact

The value returned for the F5-BIGIP-APM-MIB::apmPmStatConfigSyncState OID does not reflect the correct status (applied or not applied) of the edited access profile.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The F5-BIGIP-APM-MIB::apmPmStatConfigSyncState OID erroneously returns a zero value for a BIG-IP APM access profile that has been edited but not yet applied.
