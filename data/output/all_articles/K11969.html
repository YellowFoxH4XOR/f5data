Known Issue

When Linux or Mac OS X users establish a network access session, the BIG-IP APM and FirePass systems generate gratuitous log messages in the /var/log/messages file. This issue occurs even when logging has been completely disabled.

F5 Product Development is tracking this issue as ID 317745 (formerly CR139699), ID 327365 (formerly CR139699-2), ID 324308 (formerly CR139699-3), and ID 294445 formerly (CR139699-1).

This issue was fixed in cumulative hotfix HF-610-3-1 issued for FirePass 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
