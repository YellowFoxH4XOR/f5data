Known Issue

This is a result of a known issue. TMM can crash if an HTTP class profile is configured with header matching for a cacheable HTTP header.

F5 Networks Product Development tracked this issue as CR73355 and it was fixed in BIG-IP LTM version 9.4.1. For information about upgrading, refer to the BIG-IP LTM release notes.
