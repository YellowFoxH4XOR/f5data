K01102628: How can I add a large number of networks to a BIG-IP APM Network Access split tunnel configuration?

Description
Here is an efficient way to add a large number of networks into a split tunnel configuration for a BIG-IP APM Network access resource configuration.  Using the GUI may take a large amount of time to manually enter a whole list of networks (20+). 

Environment

  • BIG-IP APM
  • Network Access configuration in Split-Tunnel mode.
  • Very large list of networks to configure  in IPv4 Address Space.

Cause
None

Recommended Actions

You can use TMSH Command line entry to configure a list of networks as part of a split tunnel Network Access (NA) solution.   

Open and login to the Configuration utility and command line:
Note: The entry is literal and overwrites the existing entries in the list.  Be sure to have all the required networks  configured in your command. 

  1. Login to the command line and enter
    tmsh
  2. In the tmsh shell, enter:
    modify apm resource network-access <NA Resource name> address-space-include-subnet { { subnet 192.168.1.0/24} {subnet 172.16.1.0/24} {subnet 10.0.1.0/24 }}
  3. On the Configuration utility, refresh the GUI and navigate to: Access Policy  ››  Network Access : Network Access List  ››  <Network access name> >>  Network Settings tab.
  4.  Verify your new networks are listed in the split tunnel  IPV4 Lan Address Space  field.
  5. Return to the command line and enter:
    save sys config
  6. On the Configuration utility, if you observe an option to Apply access policy, select it to apply the changes.
  7. Enter:
    quit

Additional Information
This command is useful if you have a large number of specific subnets that you need to allow in a split-tunnel environment.
