Description

Lots of informational messages with keyword "Active Flow" and errdefs_msgno "23003155" may be generated.

  • info tmm[PID]: 23003155 "[bigip management-ip]","[bigip hostname]","Route Domain","[route-domain object]","Active Flow", "XXXXX",
  • info tmm[PID]: 23003155 "[bigip management-ip]","[bigip hostname]","Global","Global Network","Active Flow", "XXXXX",
  • info tmm[PID]: 23003155 "[bigip management-ip]","[bigip hostname]","Virtual Server","[virtual-server name]","Active Flow", "XXXXX",

Here are examples.

Environment

  • AFM provisioned.
  • Default "global-network" security logging profile is customized. "Traffic Statistics" is configured with log publisher and "Active Flows" option is enabled.

Figure: "global-network" security log profile configuration.

  • If virtual server uses the security log profile, log message with "Virtual Server" context will also be generated.

Figure: virtual server security log profile configuration.

 

 

Cause

These messages are "Traffic Statistics" logs.

 

Recommended Actions

You can disable "Traffic Statistics" option on security logging profile if these stats logs are not necessary.

 

Additional Information

None.
