Topic

Connecting an Ethernet cable to the serial port may cause the Always-On Management (AOM) serial console to display garbled output.

Description

The following BIG-IP platforms use an RJ45-type connector for the Console port, and implement automatic baud-rate detection to attempt to synchronize the AOM serial console port with the serial terminal that is connected to it:

  • VIPRION B2100 blade
  • BIG-IP 2000-series appliances
  • BIG-IP 5000-series appliances
  • BIG-IP 7000-series appliances
  • BIG-IP 10000-series appliances

It is easy to confuse the RJ-45 type connector used for the serial console port with an Ethernet port. If you accidentally connect an active Ethernet cable to the serial console port, some network traffic patterns may trigger an automatic baud-rate change. As a result, when you subsequently connect a serial console using a serial cable, the baud rate may not match, and cause the displayed output to be garbled.

Recommendations

To correct this condition, you need to synchronize the AOM and terminal baud rates. To do so, perform the following procedure:

  1. Connect the serial console to the CONSOLE port.
  2. Issue a break condition on the serial interface.

    Note: How this is done depends on the terminal software connected to the console. In Putty, for example, you click the command menu (upper left corner), and select Special Command > Break. In TeraTerm, you select Control > Send break from the menu.

  3. Press Enter (up to five times) to have the AOM cycle through the supported baud rates (115200, 57600, 38400, 19200, and 9600) until you select the correct baud rate.

    When the baud rates are synchronized, the system displays the following prompt:

    Press <ESC>( for AOM Command Menu.
