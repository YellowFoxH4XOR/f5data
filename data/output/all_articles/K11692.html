Known Issue

This is the result of a known issue. Error messages containing non-numeric or hexadecimal identifiers in the first four characters are ignored by alertd regular expression matching. For example, the following critical message contains the letter a in the first four characters of the alert:

2 LOG_CRIT 011a0001 BIGIP_GTMD_MEMORY_ERROR "%s: out of memory"

However, the regular expression statements located at the bottom of the alert.conf file are only designed to match numeric characters, which is displayed in the following statement from the alert.conf file:

alert BIGIP_LOG_CRIT "^[0-9]{8}:2: (.*)" {
snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.31"
}

F5 Product Development tracked this issue as CR126103 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

This issue has been fixed in Hotfix-BIGIP-9.4.8-407.0-HF4 issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
