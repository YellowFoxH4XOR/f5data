Known Issue

The BIG-IP system may fail to process File Transfer Protocol (FTP) data connections. This issue occurs when all of the following conditions are met:

  • The FTP virtual server is configured with port translation enabled.
  • Depending on the FTP connection type:

    • For active FTP, the affected FTP virtual server is either enabled with autolasthop or associated with a lasthop pool. Also, no Secure Network Address Translation (SNAT) configuration is associated with the affected FTP virtual server.
    • For passive FTP, the BIG-IP system is configured with a gateway pool.

Impact

FTP data connections fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H424329 on the Diagnostics > Identified > High screen.
  • An FTP data connection fails after its control connection is established.
  • The BIG-IP system sends an RST to the FTP pool member for an active FTP data connection. If the BIG-IP system is configured to log TCP RST packets, the system logs a message to the /var/log/ltm file that appears similar to the following example:

    01230140:3: RST sent from <src IP address:Port> to <pool member IP:Port>, [0x160a55c:2648] No route to host

Workaround

To work around this issue for active FTP data connections, you can configure the affected FTP virtual server with the SNAT configuration. To do so, perform the following procedure:

Note: There is no workaround for passive FTP data connections.

Impact of workaround: Depending on your application environment, you may need to add the SNAT address to the allowed list of various devices.

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. If you want to create a pool of SNAT addresses, perform steps 4 through 10. Otherwise, skip to step 11.
  4. Click SNATs.
  5. Click SNAT Pool List.
  6. Click Create.
  7. Type a name for the SNAT pool.
  8. Type a SNAT IP address in the IP Address box and click Add.
  9. Repeat the previous steps for the remaining SNAT IP addresses.
  10. To save the changes, click Finished.
  11. To enable the virtual server with the SNAT configuration, perform steps 12 through 16.
  12. Click Virtual Servers.
  13. Click Virtual Server List.
  14. Click the name of the affected FTP virtual server.
  15. Select the desired option from the SNAT Pool drop-down list.
  16. To save the changes, click Update.
