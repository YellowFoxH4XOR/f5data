Environment

ClientSSL profile with Client Authentication enabled

 Client Certificate set to 'Require'

 

 

Cause

When Client Certificate is set to Require the client must present a valid certificate during the TLS handshake, failing to do so can result in TLS handshake failures.

Recommended Actions

If the client is unable to present a valid certificate during the TLS handshake, you can configure the Client Certificate to Request or Ignore. Both options are explained below per notes from K14783

Request: The BIG-IP system requests and verifies a client certificate, but grants client access regardless of the status or absence of the certificate.

Ignore: This is the default setting. The Ignore setting disables client certificate authentication. The BIG-IP system ignores any presented certificate and does not authenticate the client before
