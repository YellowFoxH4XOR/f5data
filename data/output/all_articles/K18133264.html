Known Issue

Secure Sockets Layer (SSL) certificates that contain RSA padding with Distinguished Encoding Rules (DER) encoding fail verification.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with a Client SSL Profile.
  • Client Authentication for the Client Certificate is set to Required.
  • The client certificate contains RSA padding with DER encoding.

Impact

The SSL handshake fails because the certificate verification fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The SSL handshake fails.
  • In the /var/log/ltm file, you observe an error message similar to the following example:

    01260006:4: Peer cert verify error: certificate signature failure (*certificate information*) and 01260009:4: Connection error: ssl_shim_vfycerterr:4403: certificate signature failure (42)
