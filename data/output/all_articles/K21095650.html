Description

Duplicate entry issue when updating ASM Attack Signatures.

Error Message in /var/log/asm: 

ASM subsystem error (asm_config_server.pl,F5::Sigfile::Update::store_error_and_die): Failed on insert to PLC.NEGSIG_SYSTEMS (DBD::mysql::db do failed: Duplicate entry '58' for key 'PRIMARY')
ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::handle_error): Failed update_sigfile on duplicate record for
ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::log_error_and_rollback):  already exists.
ASM subsystem error (com.f5.liveupdate.update.negativesignatures.sigfile.Update.applyChanges.pl,F5::LiveUpdate::PayloadHandler::clean_fail): Fail load update files:  already exists.


Environment

  • Unable to Update ASM Attack Signatures


Cause

Bug ID 832205


Recommended Actions

The following provides steps to remove signature systems with null systems_group from the database and re-adding the signature system.

Impact of Procedure: There should be no impact on the production traffic.
  1. Delete these signature systems by running the following command:

    mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "DELETE FROM PLC.NEGSIG_SYSTEMS WHERE system_group = ''"

    Note: This remove the signatures with null system_groups from the database.
     
  2. To re-add the signature system, perform a signature update.


Additional Information

To find the signatures with null system_groups from the database, following command could be used:

mysql -uroot -p`perl -I/ts/packages -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` -e "SELECT * FROM PLC.NEGSIG_SYSTEMS WHERE system_group = ''"
