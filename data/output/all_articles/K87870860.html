Description

Loading UCS archive, the following error is encountered:
01080023:3: Error return while getting reply from mcpd: 0x1070911, 01070911:3: The requested flow_eviction_policy object (/Common/Global-EvictionPolicy) does not exist for global_flow_eviction_policy in ltm (/Common/ltm)
 

Environment

  • UCS archive
  • The configuration from the UCS contains a global flow-eviction policy defined

Cause

Bug ID 1053037

Recommended Actions

The error can be ignored as long as the system restore continues on (and eventually succeeds).

Additional Information

The issue occurs when restoring a UCS archive that contains a global flow-eviction policy defined, when that flow eviction policy is not defined in the existing configuration on the target BIG-IP.
