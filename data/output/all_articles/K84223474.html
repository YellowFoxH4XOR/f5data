K84223474: ''Error uploading to iHealth'' banner in WebUI, ''Error 200202'' in logs

Type
Support Solution
Published
2023-04-21
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K84223474

Description

When generating a qkview and choosing the "Generate and Upload QKview to iHealth" option, a red banner appears that states "Error uploading to iHealth". However, the upload is successful.

Environment

  • A proxy IP is configured via tmsh.

    tmsh list sys db proxy.host value
    tmsh modify sys db proxy.host value <proxy IP>
    tmsh save sys config
     
  • The LTM logs report "Error 200202". The 200202 is a concatenation of a 200 from the proxy to indicate the connections was successful then a 202 from ihealth to indicate the upload is processing. Though its logged as error 200202, the upload is successful.

Cause

Bug ID 1054405: Error generated by ihealth script when uploading qkviews via proxy

Recommended Actions

  1. On https://ihealth.f5.com, confirm the qkview uploaded.
  2. On the BIG-IP, delete this qkview .

Additional Information

None.
