K000092963: Chain CA bundle takes precedence over chain attached to certificate in Client SSL Certificate field

Type
Support Solution
Published
2022-12-04
Updated
2022-12-05
Source
https://my.f5.com/manage/s/article/K000092963

Description

The issue revolves around a certificate in a PKCS format which contains Cert+Chain inside added to the Certificate field. This chain contains an expiring soon intermediate CA certificate. The user imported a separate Chain certificate with an updated intermediate CA and assigned it as a chain to the profile. The question is which Chain will be used and how it affects the profile.

 

 Environment

  • BIG-IP LTM
  • Client SSL Profile
  • PKCS Certificate imported with expiring Intermediate CA Cert
  • Chain configured with different non-expiring Intermediate CA Certificate

 Cause

Certificate Chain Used in Chain Field takes precedence over the chain loaded in the certificate field.

 

 Recommended Actions

Load Expected CA Bundle in the chain field.
