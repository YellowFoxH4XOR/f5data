Known Issue

The restjavad (icrd) process may spawn excess icrd_child processes.

This issue occurs when all of the following conditions are met:

  • You use the iControl REST application programming interface (API) to obtain data from or to modify the configuration of your BIG-IP system.
  • An iControl REST request takes longer than you expect to process.

When a request takes longer than you expect to process, the system triggers a race condition that causes the iControl REST (icrd) process to kill and respawn excess icrd_child processes.

Impact

The BIG-IP system uses more memory over time, which may eventually cause a decrease in performance or a system reboot due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system fails to process iControl REST queries.
  • In the /var/log/restjavad.0.log file, you observe error messages that appear similar to the following example:

    [ChildWrapper] Timed out waiting for GET request at http://localhost:8100/tm/sys/software/status. Killing child process 21287
    [ChildWrapper] Killing IcrdChild process 21287
    [ChildWrapper] Child runner thread was interrupted. Killing child: fdd32613-6296-4e4c-aead-cda74763e3a3
    [ChildWrapper] IcrdChild process fdd32613-6296-4e4c-aead-cda74763e3a3 is starting
    [ChildWrapper] Child runner thread was interrupted. Killing child: fdd32613-6296-4e4c-aead-cda74763e3a3
    [ChildWrapper] Killing IcrdChild process 21287
    [ChildWrapper] IcrdChild process fdd32613-6296-4e4c-aead-cda74763e3a3 is starting
    [ChildWrapper] Killing IcrdChild process 21287
    [ChildWrapper] IcrdChild process fdd32613-6296-4e4c-aead-cda74763e3a3 is starting

  • The BIG-IP system uses more memory over time, which may eventually cause a decrease in performance or a system reboot due to memory exhaustion.
