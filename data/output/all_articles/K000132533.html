Description

The DTLS connection for the user is unstable. User using TLS as an alternative method. 

Is there a registry key I can change to force the client to only use TLS for the connection?

 Environment

  • Windows
  • DTLS

 Cause

None

 Recommended Actions

  1. Open the registry editor;
  2. Locate the registry path "SOFTWARE\F5 Networks\RemoteAccess" (in my case it was in HKEY_CURRENT_USER);
  3. Locate the key "EnableDTLSTransport" (if it does not exist, do feel free to create it as DWORD)
  4. Set the value to "0"

Once done, save the changes, restart the Edge Client again and test.
