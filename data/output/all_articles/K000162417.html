Security Advisory Description

The BIG-IP Edge Client Dialup Entry/Windows Logon Integration may expose native Windows operating system functionality through the rendered web interface prior to Windows user logon. This action opens the Windows print dialog in the security context of the BIG-IP Edge Client pre-logon account (F5 Pre-Logon User). F5 Pre-Logon User is a standard Windows user account.

This issue occurs when all of the following conditions are met:

  • BIG-IP APM is configured with Dialup Entry/Windows Logon Integration.
  • User has access to Windows system Logon Screen where BIG-IP Edge Client is installed.

Impact

A user with access to the BIG-IP Edge Client pre-logon rendered web interface may be allowed access to Windows operating system functionality that is outside the intended authentication workflow accessible to the F5 pre-logon user account. For example, the user may be able to browse the filesystem, create or modify files in writable locations, and launch local applications. This issue does not result in privilege escalation and does not directly affect the confidentiality, integrity, or availability of BIG-IP Edge Client software.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP Edge Client pre-logon rendered web interface may allow access to the Windows print dialog.
  • Users are able to browse the local filesystem, create or save files, or launch local applications in locations accessible to the F5 Pre-Logon User account.
