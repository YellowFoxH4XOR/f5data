Known Issue

The BIG-IP system may fail to delete log files and XML customization files in the /tmp directory.

This issue occurs when either of the following conditions are met:

  • You edit a BIG-IP APM access policy in the visual policy editor
  • You edit an access policy customization

The visual policy editor and customization pages create temporary files in the /tmp directory. The BIG-IP system may not remove the files when editing is complete.

Impact

The /tmp directory files may fill the root volume. As a result, performance may degrade and the system may crash.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The ls /tmp command output displays file entries that appear similar to the following example:

    apm_log_parser.log
    --C-o-m-m-o-n--F-5--V-P-N--P-r-o-f-i-l-e-1--a-c-t--d-e-c-i-s-i-o-n--b-o-x--t-w-o--1--a-g-_7745583.xml

Workaround

To work around this issue, you can clear the /tmp directory by removing the files. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Type the following commands:

    rm -rf /tmp/apm*
    rm -rf /tmp/*.xml

Impact of workaround: This workaround is a manual process that relies on an individual running the command whenever changes are made to an access policy.
