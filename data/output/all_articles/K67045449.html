Issue

Error Message

notice chmand[pid]: 012a0005:5: Cpu utilization over 300 seconds is <#>%, exceeded log level <#>%

In this error message, note the following:

  • <pid> is the process ID of the chassis manager daemon (chmand) process.
  • <#> is a percentage number value.

For example:

chmand[8123]: 012a0005:5: Cpu utilization over 300 seconds is 83%, exceeded log level 80%

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions are met:

Note: The message can occur for a variety of reasons; these conditions are a few of the known common reasons.

  • An overloaded system is attempting to handle more traffic than it is capable of handling.
  • An improper configuration exists, such as excessive monitors or poorly written iRules.
  • A system encountering an issue that may be an existing known issue.
  • A BIG-IQ system performing device discovery.

Impact

This message indicates that at least one CPU has exceeded the configured log level set by the cpu.logthreshold system database variable. By default, the cpu.logthreshold system database variable is set to a value of zero which disables the log level. You can modify the value using the tmsh command syntax modify sys db cpu.logthreshold value <value between 0 and 100>. For example, if you set the value to 80 and at least one CPU usage exceeds 80% for more than 300 seconds, the system logs the error message.

Recommended Actions

This error message may occur for a wide variety of reasons; one action will not fit every situation. F5 suggests that you upload a QKView file to iHealth and review the heuristics that pertain to potential CPU issues as a starting point. If you continue to encounter this error message after resolving the issue, you may be required to open a case with F5 Support. Optionally, it may also be beneficial to contact F5 Sales to review your hardware requirements.
