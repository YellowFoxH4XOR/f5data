K83542023: Endpoint Management connection to a MDM fails with error: Error during updating device details: Authentication error (Authentication error for get all devices request)

Description

This solution describes the events that cause this error and how to resolve them.

  • Endpoint Management connection to a MDM fails.
  • Endpoint Management configuration is unable to pull device details from MDM.
  • You observe the following logs in /var/log/apm:
<big-ip_hostname> notice mdmsyncmgr[16841]: 019dffff:5: (null)::00000000: {} /Common/<access_policy>: Start querying devices from <mdm_fqdn>
<big-ip_hostname> err mdmsyncmgr[16841]: 019dffff:3: (null)::00000000: {} /Common/<access_policy>: Error during updating device details: Authentication error (Authentication error for get all devices request)

Environment

  • Access Policy Manager (APM)
  • Endpoint Management Configuration
  • Mobile Device Management (MDM) solution.

Cause

1. The username and/or password configured in the Endpoint Management is not correct.

2. The account has become locked due to the periodic polling that APM does to the MDM.

Recommended Actions

Verify the correct username and password in the Endpoint Management configuration.

  1. Login to the BIG-IP Admin GUI.
  2. Navigate to Access>Authentication>Endpoint Management Systems
  3. Click on the MDM configuration name.
  4. Verify/Update the username/password in the Username and Password fields.
  5. Click Update.
Verify the account used in the Endpoint Management configuration has not been locked in the remote AAA server.
