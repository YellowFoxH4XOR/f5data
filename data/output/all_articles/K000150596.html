Description

  • BIG-IP recently updated software versions but failed to re-activate the license before doing so or with an expired service contract.
  • BIG-IP will display this warning: "A valid service contract is required to complete installation."

Environment

  • BIG-IP recently had software upgrade.
  • Support contract for BIG-IP recently extended or updated.
  • Product serial number has a current valid support contract.
  • License was not re-activated right before the upgrade or it was re-activated under the old service contract.

Cause

License activation is required to update the service check date on the device to the latest applicable... a date that satisfies the license check date criteria for the software version.

Recommended Actions

Re-activate the license following the steps included in this document: 

  • License activation may be required before a software upgrade for BIG-IP
