Description

Traffic Intelligence system-generated presets (with name ce_*) are not saved to the configuration file. As a result, changes are lost on mcpd restart/configuration reload and Configuration Utility allows changes to be deleted.

  • Changes made to system default presets are disappeared
  • No error message or audit logging records configuration loss

Environment

  • Traffic Intelligence is licensed and in use. E.g. AFM or PEM license with traffic classification option
  • System-generated presets are modified. E.g. applying LTM policy to classify traffic flow
  • Affected version of BIG-IP software is in use. Please refer to Bug ID 744914 for more details

Cause

The issue caused buy a Bug ID 744914

Recommended Actions

To fix the issue upgrade to a version where the bug was fixed. Please refer to Bug ID 744914 for more details
To workaround create custom preset and use it
