Description

 

When SAML SP and SAML IDP are configured on the same BIGIP, SAML Artifact (Artifact resolution service pointing to the IDP Virtual Server) does not work.

 

It fails with similar error messages:

 

SAML Agent: failed to process SAML artifact, error: Failed to resolve Artifact

 

err apmd[5007]: 01490000:3: modules/Authentication/Saml/SamlSPAgent.cpp func: "sendSAMLArtifactResolveRq()" line: 5894 Msg: Failed to connect to artifact resolution service. Error (52): Server returned nothing (no headers, no data)
err apmd[5007]: 01490000:3: modules/Authentication/Saml/SamlSPAgent.cpp func: "resolveSAMLArtifact()" line: 5944 Msg: Error resolving artifact

 

 

Environment

BIGIPas SAML SP

BIGIP as SAML IDP

BIGIP as SAML ARS (Artifact Resolution Service)

 

SP and IDP services configured on the same BIGIP

 

Cause

There are limitations when SP and IdP are configured on the same BIG-IP

 

Recommended Actions

We suggest to have SAML SP on one BIGIP and SAML IDP on another BIGIP. ARS (Artifact Resolution Service) can point to the same IDP Virtual Server.
