Description

When selecting a Web Application Security Event Log in the BIG-IQ GUI, the following pop-up error window appears, or the Violation Rating is missing.

Environment

  • BIG-IP ASM
  • BIG-IQ

Cause

Use the default value 2K for the "Maximum Entry Length" when Logging Format is BIG-IQ in the Security logging profile.

Recommended Actions

  1. Go to BIG-IP ASM->Security->Event Logs->Logging Profiles
  2. Select your Logging Profile
  3. Select 'Advanced' in the Configuration of Application Security 
  4. Increase "Maximum Entry Length" to 64K when Logging Format is BIG-IQ.
  5. Click 'Update'

Additional Information

None.
