K10605: Configuring the Read/Write Timeout setting to more than three hours may result in system instability

Topic

In BIG-IP WebAccelerator 9.4.x, the pvac process has a internal active transaction timeout of three hours. If a transaction exceeds the timeout period, it is considered stale, and pvac will reuse the transaction slot for a new connection. The internal transaction timer is not configurable.

The BIG-IP WebAccelerator also provides the Read/Write Timeout setting which enforces an explicit timeout for idle connections. The default  Read/Write Timeout value is 30 seconds. Configuring the Read/Write Timeout setting to a value greater than the internal transaction timeout value of three hours (10,800 seconds) may result in system instability and pvac process crashes.

If you have configured the Read/Write Timeout setting to a value more than three hours, you can prevent pvac crashes by reducing the value. To reduce the Read/Write Timeout setting perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click WebAccelerator.
  3. Click Applications.
  4. From the Main tab, click Destination Hosts.
  5. Click BIG-IP Internal Pool.
  6. Change the Read/Write Timeout setting to a value less than 10,800 seconds.
  7. Click Save.

Note: For more information about why the Read/Write Timeout may have been modified from the default value, refer to K9367: HTTP 503 Service Unavailable response: An error occurred while fetching the URI. Please retry.
