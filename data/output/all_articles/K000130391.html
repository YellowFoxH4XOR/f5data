K000130391: Error when trying to configure Certificate Order Manager

Type
Support Solution
Published
2022-12-28
Updated
2022-12-28
Source

Description

When trying to configure Certificate Order Manager the configuration utility displays the following error:

[{code=access_denied|missing_permission, message=Access denied due to missing_permission.}]

 

Environment

  • BIG-IP Certificate Order Manager
  • Digicert

 

Cause

The URL to download the certificate is wrong.

 

Recommended Actions

Undetermined.
