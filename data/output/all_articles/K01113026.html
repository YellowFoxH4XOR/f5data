K01113026: When was the software volume installed?

Source

Description

You need to confirm the timestamp of when the software installation started and when it completed.

  • Reviewing the timeline of events following recent maintenance

Environment

  • Big-IP

Cause

You need to review the timeline of events following recent maintenance.

Recommended Actions

These details are found in /var/log/liveinstall.log

  1. This is when the installation started.
    *** Live install start at YYYY/MM/DD HH:MM:SS ***
     
  2. This is when the installation completed.
    ** Live install end at YYYY/MM/DD HH:MM:SS: succeeded ***
     
  3. This is when the device booted into the new volume.
    YYYY-MM-DDTHH:MM:SS+00:00 bigip.com notice boot_marker : ---===[ HD1.1 - BIG-IP 14.1.5.2 Build 0.0.3 <HD1.1> ]===---
