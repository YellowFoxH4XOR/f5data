K28312510: RSA tests of nethsm fail using PKCS11 with this message: Error in call to pkcs1v15_encrypt, err = -1.

Type
Support Solution
Published
2021-04-06
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K28312510

Description

Testing external HSM with PKCS11 fails with error message

  • Error in call to pkcs1v15_encrypt, err = -1.

  • You see the error when running this command:

    run -a ACTION_GEN_RSA_KEYPAIR -l f5test -d -m 2048 -r 'auto' -v`

Environment

  • C_Sign failures showed up at ltm log when running HSM test utility

Cause

This is a result of ID 1006137 where using the pkcs11 test utility results in an RSA sign failed due to incompatible message length passed.

Recommended Actions

Upgrade to 15.0 or later for a permanent fix
