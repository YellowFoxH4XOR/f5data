Description
Newly created datagroups are not in the drop-down list for policy rule conditions in the GUI (Configuration Utility).

Environment

  • BIG-IP
  • Configuration Utility
  • LTM Policy
  • Datagroups

Cause
Bug ID 722691

Recommended Actions

Follow workaround of Bug ID 722691. Use TMSH to configure the policy rule condition.

Additional Information
When creating a new policy rule, previously created datagroup is not listed in drop-down.

Steps to reproduce this behavior:

  1. Log in to GUI (Configuration Utility)
  2. Create a new data group
  3. Create a new LTM policy
  4. Create a rule for the new policy
  5. Create a condition for the new rule
  6. Select TCP - address - matches - in datagroup, then click the drop-down for the datagroups
