Description

After performing steps from K74200262 you still cannot proceed with the upgrade and device is in inoperative state.

Environment

  • BIG-IP physical appliance
  • Upgrade

Cause

The root cause was overallocation of disk space to the /appdata logical volume, leaving insufficient free space in the volume group for the installation of a new BIG-IP software volume. This is a known issue described in F5 article K91895955, where the /appdata volume must be reduced in size to free up space for new installations. However, sometimes /appdata didn't mount automatically again and you need to do it manually.

Recommended Actions

Check whether /appdata directory is present:

# df -h /appdata

If not, mount it again:

# mount /appdata
