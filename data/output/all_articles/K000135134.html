K000135134: Maximum number of configuration objects in Traffix SDC

Type
Support Solution
Published
2023-06-25
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.0
Source
https://my.f5.com/manage/s/article/K000135134

Description

  • Each configuration object has different limitations.
  • The list below shows the limitation for each object :

-Association Rules : 500

-Transformation rules : 1000 for InTransformation ; 1000 for Outtransformation

-Peers : 1000

-Pools : 500

-Routing rules : 1000

-Peer profiles : 1000

-Session management : Check the topology file.

On the MasterBlade, go to /srv/traffix and view the topology.xml, under the topology.xml there is a section for tripo and it will have the maxSessions. 

    <tripo>

      <secondSiteIP1>1.1.1.1</secondSiteIP1>

      <secondSiteIP2>1.1.1.1</secondSiteIP2>

      <maxSessions>1000</maxSessions>

      <tripoVersion>latest</tripoVersion>

      <srrInterface>IC-eth1</srrInterface>

      <srrListenPort>43211</srrListenPort>

<secondSiteSrrPort>43211</secondSiteSrrPort>

 

Environment

  • Traffix SDC 5.x

Cause

By design.

 Recommended Actions

None.

Additional Information

None.
