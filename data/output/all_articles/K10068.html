Known Issue

This is the result of a known issue. The TCP profile Verified Accept setting allows the BIG-IP system to verify that a pool member is available to accept the connection by sending the server a SYN packet prior to responding to the client with a SYN-ACK packet.

A BIG-IP WOM-optimized virtual server using the Verified Accept setting may stop responding to client requests. When this behavior occurs, the client sends a SYN request to the BIG-IP WOM-optimized virtual server and the virtual server does not respond to the client with a SYN-ACK packet.

F5 Product Development tracked this issue as CR115565 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM, WebAccelerator or WOM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.0.0-5460.0-HF1, which has been issued for BIG-IP 10.0.0, for the BIG-IP 10.x software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).
