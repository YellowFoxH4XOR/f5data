Description

Changing asm system variable , /var/log/audit logs onlt few changes not all.


Environment

ASM

logging

Cause

This is by design , audit log is just for a policy. Changing system variable, will log only log in /var/log/asm.

Recommended Actions

From V 17.x , similar to following log in /var/log/asm

ASMConfig change: System Variable ignore_cookies_msg_key [add]: Min Value was set to 0. name was set to ignore_cookies_msg_key. Max Value was set to 1000000000. value was set to 1. Default Value was set to 1. { audit: component = admin }
