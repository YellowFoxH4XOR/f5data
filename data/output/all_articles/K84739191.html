Description

BIG-IP can assign user roles to specific LDAP groups so that its members inherit the permissions described in the role when logging into the system. You must meet the following prerequisite to use this procedure:

- You already have a working LDAP Auth Provider configured in the system.

Once you have configured the remote authentication and the remote role groups on the BIG-IP and still any unauthorized user is able to login to the BIG-IP.

Environment

  • BIG-IP 
  • LDAP remote authentication
  • Remote role groups

Cause

When authentication of external users is set to Administrator the BIG-IP does not validate the remote role group configured.

Recommended Actions

Disable the local role and access for the remote users.

  1. Log on to the BIG-IP Configuration utility.
  2. Go to BIG-IP GUI > System > Users > Authentication > External Users > Role and Terminal Access
  3. Set Role to No Access
  4. Set Terminal Access to Disabled
