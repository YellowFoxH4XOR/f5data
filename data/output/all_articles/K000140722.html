Known Issue

The BIG-IP Next Central Manager may fail to manage BIG-IP Next instances with a Provider.

This issue occurs when all of the following conditions are met:

  • The BIG-IP Next Central Manager is configured with one or more Providers.
  • The Provider’s SSL certificate is changed.

Impact

The BIG-IP Next Central Manager is unable to deploy new BIG-IP Next instances to the affected Provider and unable to delete existing BIG-IP Next instances that was deployed via the BIG-IP Next Central Manager on the affected Provider.

Note that editing BIG-IP Next instances’ settings like networking, VLANs, Apps deployment is not affected by this issue.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP Next Central Manager is unable to deploy new BIG-IP Next instances to the affected Provider.
  • The BIG-IP Next Central Manager is unable to delete existing BIG-IP Next instances that were deployed via the BIG-IP Next Central Manager on the affected Provider and reports an error similar to the following example:

    tls: failed to verify certificate: x509: certificate is not valid for any names, but wanted to match myprovider.f5.com

Workaround

There are no workarounds to completely resolve this issue at this time. The following are possible scenarios which you can recover from or prevent this issue:

  • Recovery from this issue
  • Preventing this issue from occurring

Recovery from this issue

If you still possess a copy of the affected Provider’s previous SSL certificate, you should restore the previous SSL certificate on the affected Provider (assuming the previous SSL certificate is still valid).

If you no longer possess the Provider’s previous SSL certificate or the previous SSL certificate is no longer valid, then there is no method to recover from this issue.

Preventing this issue from occurring

If you have not deployed any BIG-IP Next instances via the BIG-IP Next Central Manager on the affected Provider, F5 recommends that you delete the affected Provider from BIG-IP Next Central Manager and ensure the affected Provider is installed with the new SSL certificate before adding it to the BIG-IP Next Central Manager.

For information about adding a Provider to the BIG-IP Next Central Manager, refer to How to: Add a Provider for VE, VELOS and rSeries from BIG-IP Next Central Manager.
