Issue

FirePass may report an error message similar to the following example on the Reports: System Logs page in the FirePass Administrative Console:

Database recovery failed:
/usr/local/uroam/bin/mysqlcheck: Got error: 2002: Can't connect to local MySQL server through socket '/usr/local/uroam/var/mysql/mysql.sock' (2) when trying to connect

FirePass typically reports this error message at startup, when the FirePass Services may start before the MySQL database service is fully initialized. If FirePass reports this error message infrequently, it can typically be safely ignored. If FirePass repeatedly reports this error message, it can indicate an issue with the FirePass database.

For more information, refer to K8124: Checking and repairing the FirePass database.
