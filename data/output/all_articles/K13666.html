Issue

Old Behavior

Prior to BIG-IP WebAccelerator 11.0.0, the BIG-IP WebAccelerator system used the BIG-IP RAM Cache (sometimes called Hot Cache) for RAM-based object caching and Smart Cache disk-based object caching. You could view the contents of the BIG-IP WebAccelerator Hot Cache or RAM Cache using bigpipe or tmsh commands, and view the Smart Cache contents by looking in the /var/wa/hds or /wam/hds directory on the BIG-IP filesystem.

New Behavior

Beginning in BIG-IP WebAccelerator 11.0.0, all caching is done by way of a new data structure called the MetastorDatastor. The BIG-IP WebAccelerator system no longer uses the Linux filesystem to store data, but rather a proprietary data structure called the MetastorDatastor. There are currently no tools available to interrogate this data structure.

Impact

It is no longer possible to view or list files that are stored in cache. 

Recommended Actions

None. There is a request for this functionality in a future release of the BIG-IP WebAccelerator system.
