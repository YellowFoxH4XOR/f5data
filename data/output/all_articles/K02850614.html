Description
On starting your CIS (Container Ingress Services) cluster, it runs for a short time (minutes) then fails.
It logs messages similar to:

2021/08/15 22:25:35 [ERROR] [2021-08-15 22:25:35,056 __main__ ERROR] Encountered error: BIG-IP connection error: 401 Unexpected Error: F5 Authorization Required for uri: https://10.11.2.2:443/mgmt/shared/authn/login
2021/08/15 22:25:35 [INFO] Text: u'{"code":401,"message":"status:503, body:{\\"code\\":503,\\"message\\":\\"There is an active asynchronous task executing.\\",\\"errorStack\\":[],\\"apiError\\":32964609}","referer":"10.11.1.1","restOperationId":98391841,"kind":":resterrorresponse"}'. Retrying for 1 seconds.
2021/08/15 22:25:49 [INFO] [2021-08-15 22:25:49,074 __main__ INFO] BIG-IP connection established.
2021/08/15 22:25:49 [INFO] [2021-08-15 22:25:49,366 __main__ INFO] entering inotify loop to watch /tmp/k8s-bigip-ctlr.config173011341/config.json
fatal error: concurrent map read and map write

Environment

  • You have deployed  https://github.com/F5Networks/k8s-bigip-ctlr     Repository for F5 Container Ingress Services for Kubernetes & OpenShift.
    This proxies REST calls to the BIG-IP.
  • You are using Basic Authentication.
  • In the BIG-IP,  REST Requests are intermittently failing with a 401 error. The /var/log/restjavad-audit.*.log shows these requests are closely preceded by a 503 response from /mgmt/tm/auth/source.

Cause

  • This is issue   Bug ID 1035661: REST Requests return 401 Unauthorized when using Basic Auth
  • The failure of the REST calls result in subsequent failure of the CIS system.

Recommended Actions

  1. Use Token Based Authentication in place of Basic Authentication.
