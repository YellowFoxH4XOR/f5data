K2547: Accessing Microsoft Exchange Server through a BIG-IP SSL proxy

Topic

Microsoft Outlook Web Access is typically configured on two sets of nodes. The Outlook Web Access nodes provide the web front-end and communicate with back-end Microsoft Exchange Server nodes for mail data.

When you access Microsoft Outlook Web Access through a BIG-IP SSL proxy, Outlook Web Access responds to requests with URLs that specify the HTTP protocol, because the session was decrypted by BIG-IP before it was received by the Outlook Web Access server. When this occurs, the session fails because the client responds with HTTP requests while the BIG-IP SSL proxy accepts only HTTPS requests.

To work around this issue, you can configure BIG-IP to insert an HTTP header named FRONT-END-HTTPS with a value of on. Microsoft Outlook Web Access will send URLs that specify HTTPS whenever it receives this header in a request.

Important: There is a known issue in Microsoft Exchange Server 2000 that may prevent this feature from working correctly. For more information about this issue, refer to the following Microsoft Knowledge Base article:

http://support.microsoft.com/kb/q283195/

For more information about the Microsoft Exchange Server Custom HTTP Header feature, refer the following Microsoft Knowledge Base article:

http://support.microsoft.com/?kbID=307347

To configure BIG-IP to add the necessary HTTP header for Microsoft Outlook Web Access compatibility, perform the following steps:

Command Line

  1. Log in to the command line.

  2. Configure the SSL proxy to insert the necessary HTTP header, using the following command:

    bigpipe proxy <address>:<service> header insert \"FRONT-END-HTTPS: on\"

    Replace <address> with the address of the existing SSL proxy.

    Replace <service> with the service port of the existing SSL proxy.

  3. Save the configuration by typing the following command:

    bigpipe save

The BIG-IP is now configured to provide the necessary header. OWA should work normally with the SSL proxy.

Configuration utility

To specify the header value (stored in bigdb) for the proxy to insert into the request using the command line, perform the following steps:

  1. From the Configuration utility, click Proxies.
  2. Click on the proxy that decrypts OWA traffic.
  3. Click on the Proxy Advanced Properties tab.
  4. In the Header Insert box at the top of the screen, type:

    FRONT-END-HTTPS: on

  5. Click the Apply button.

The BIG-IP is now configured to provide the necessary header. OWA should work normally with the SSL proxy.
