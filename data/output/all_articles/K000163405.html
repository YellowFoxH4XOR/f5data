K000163405: HTTPS monitor can report inconsistent pool member status when it uses a server SSL profile with Server Authentication enabled

Type
Support Solution
Published
2026-09-24
Updated
2026-09-24
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000163405

Description

An HTTPS monitor that uses a server SSL profile with Server Authentication enabled can mark a pool member UP when the server certificate should fail validation against the configured Trusted Certificate Authorities. Status can also be inconsistent after changes to the profile or to the monitoring mode.

Environment

  • BIG-IP LTM
  • HTTPS monitor that uses a server SSL profile with Server Authentication enabled:
    - Server Certificate is set to Require
    - Trusted Certificate Authorities is configured (required when Server Certificate is set to Require; refer to K14806)
  • In-TMM monitoring is disabled (default)

Cause

When In-TMM monitoring is disabled, HTTPS monitors run in bigd, which does not consistently apply the server SSL profile's Server Authentication settings.

With In-TMM monitoring disabled (the default), pool member status may be inconsistent: a member may be shown as UP with an invalid Trusted Certificate Authorities configuration, or as DOWN with a valid one.

With In-TMM monitoring enabled, pool member status reflected the tested Server Authentication settings as configured.

Recommended Actions

Choose one of the following options, depending on whether the monitor needs to authenticate the server:

  • If https monitor does not need to authenticate the server: Set Server Certificate to Ignore in the server SSL profile that the monitor uses.
    If a virtual server uses the same profile, create a separate server SSL profile for the monitor and set Server Certificate to Ignore only in that profile. The virtual server keeps its Server Authentication settings. With this option, the monitor does not validate the server certificate.
  • If https monitor must authenticate server's certificate in-TMM monitoring should be enabled.
