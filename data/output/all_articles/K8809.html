Known Issue

This is the result of a known issue. When enabled, the TACACS+ remote authentication debug logging option logs the username and password in cleartext within the /var/log/secure file.

This behavior occurs regardless of whether encryption is enabled within the TACACS+ remote authentication configuration.

F5 Networks Product Development tracked this issue as CR92836 and it was fixed in BIG-IP LTM version 9.4.6. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP version 9.4.5, for the BIG-IP 9.4 software branch. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about how to manage F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.
