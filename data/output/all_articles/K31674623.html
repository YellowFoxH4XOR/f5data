Environment

  • LTM
  • AVR
  • Virtual Server with Analytic profile assigned
  • Page Load Time is enable on the Analytics profile

Cause

Seen behavior is expected. The script injected in the response body is part of the BIG-IP Analytics CSPM injection. The CSPM feature injects JavaScript into HTTP responses to allow the BIG-IP Analytics module to track the Page Load Time metric. This feature is supported by only certain browsers, but by default the JavaScript is injected without regard to whether the client browser type supports the feature.

Recommended Actions

You can disable the feature by clearing the Page Load Time option on the analytics profile

  1. On GUI go to Collected Metrics > Page Load Time
  2. disable the feature by clearing the Page Load Time option
Or you can consider Disabling CSPM injection with iRules. For additional information please refer to K13859
