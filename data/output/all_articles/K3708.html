Topic

Unlike the bigpipe load command, the bigpipe merge command only loads portions of the configuration that are different from the running configuration. Because of this, the bigpipe merge command will not interrupt unchanged portions of the configuration.

The syntax for the bigpipe merge command is as follows:

bigpipe merge <filename>

For the <filename> attribute, you can specify /config/bigip.conf or any other file containing valid BIG-IP configuration statements.
