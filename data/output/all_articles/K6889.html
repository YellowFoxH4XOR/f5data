K6889: You cannot create a Link object if the BIG-IP Link Controller system is configured as Unit ID 2

Known Issue

This is the result of a known issue. This issue applies to redundant BIG-IP Link Controllers systems. If the BIG-IP Link Controller system is set to Unit ID 2, creating a Link object will fail and the following error message will be reported in the Configuration utility:


01070179:3: Link link1 must have an associated data center

If the Unit ID is set to 1, the Link object is created successfully.

F5 Networks Product Development tracked this issue as CR69074, CR69075, and CR69729 and it was fixed in BIG-IP Link Controller versions 9.2.4, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP Link Controller Release Notes.
