Known Issue

This is the result of a known issue. The big3d process may crash and produce a core file when the following two conditions are met:

  • The big3d process receives a monitor request that generates an XML parse error
  • The big3d process receives a second monitor request while closing the first monitor connection

F5 Product Development tracked this issue as CR69127 and it was fixed in BIG-IP GTM 9.2.4 and 9.3.0. For information about upgrading, refer to the BIG-IP GTM release notes.
