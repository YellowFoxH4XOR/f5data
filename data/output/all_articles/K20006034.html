Description

Config-Sync not working, showing the following error on the GUI after attempting sync:

One or more devices are unreachable. Resolve any communication problems before attempting to sync.

You observe the following critical error message on /var/log/ltm

01010201:2: Inet port exhaustion on 192.168.1.2 to 192.168.1.3:4353 (proto 6)

Note: The IP addresses on the above example, are the ones configured as Config-Sync IPs for the HA pair, and port 4353 is the TCP port used for Config-Sync.

Environment

  • The CMI channel on port 4353
  • Config-Sync IPs

Cause

TMM has run out of source ports and cannot open new communications channels for sync on TCP port 4353.

Bug ID 727292: SSL in proxy shutdown case does not deliver server TCP FIN

Recommended Actions

Upgrade to a version where ID727292 is fixed. Alternatively, to workaround the issue on affected versions perform one of these steps:

  1. Reboot the HA peer showing port exhaustion logs or restart tmm with: tmsh restart sys service tmm
  2. Configure a different IP to be used for Config-Sync
