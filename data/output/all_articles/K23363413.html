K23363413: iRule command HTTP::respond is not valid in SERVER_CLOSED.

Type
Support Solution
Published
2023-03-28
Updated
2026-09-25
Status
Legacy Content
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K23363413

Description

TMM will crash if  iRule command HTTP::respond is used in SERVER_CLOSED. 

Environment

  • iRule includes HTTP::respond in SERVER_CLOSED

Cause

Bug ID 1002321: The system does not throw a validation error of this syntax, and an attempt to use HTTP::respond on the closed connection will result in tmm crash. 

Recommended Actions

Please ensure not to use an HTTP::respond command during a SERVER_CLOSED event

None
