Description

You are coming across the following error:

  • Invalid TLS certificate and/or Private key: tis: failed to parse private key
  • spec.loadbalancer_type.https.tls_parameters.tls_certificates.private_key.secret_info_oneof.blindfold_secret_info.location should be of URL form (<domain-name.com>), got string:
  • spec.loadbalancer_type.https.tls_parameters.tls_certificates.private_key.secret_info_oneof.blindfold_secret_info.location fails rule ves.io.schema.rules.string.uri_ref constraint true due to value string:

 

Environment

  • F5® Distributed Cloud Console
  • TLS certificate
  • F5 Distributed Cloud HTTP Load Balancer

Cause

  • This private key is passphrase protected

Answer/Recommended Actions

Convert the private key to PKSCS#1:

$ openssl rsa -in <key-with-passphrase.key> -out <key-without-passphrase.key>
-----BEGIN RSA PRIVATE KEY-----
MIICXQIBAAKBgQDymMsf+68EERSkXO7lwucBa5Ibw+74z+dL/yYWsHxsl+j9E3ZK
<omitted>
uehkYsNKd45pNxZr0ZZN1UlVht7kBZWX/+Ij2ezShYDA
-----END RSA PRIVATE KEY-----

and set it up again with above new format.
