Description

You want to configure the BIG-IP DNS to return a CNAME record for A and AAAA DNS requests.

Environment

  • BIG-IP DNS
  • CNAME record
  • A / AAAA records

Cause

None

Recommended Actions

Configuring the CNAME pool

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Pools > Pools List.
  3. Click Create.
  4. Specify a name of your CNAME pool 
  5. For Type, click CNAME.
  6. Under Member List section, choose Wide IP from the available list.
    Note: If you want BIG-IP DNS to use a CNAME record that does not exist on the device, check the Static Target box and type in CNAME (such as test.com) for Wide IP .
  7. Click Add.
  8. Click Finished.
     
Creating a CNAME pool using the iControl REST API

Alternatively, you can create a CNAME pool with the iControl representation state transfer (REST) application programming interface (API), using the following cURL command syntax.
Impact of procedure: Performing the following procedure should not have a negative impact on your system.

curl -sk -u 'admin:<password>' -H 'Content-Type: application/json' -X POST https://<bigip ip address>/mgmt/tm/gtm/pool/cname -d '{"name":"<cname pool name>","members":[{"name":"<existing wideip name"}]}'

Example:
curl -sk -u 'admin:admin' -H 'Content-Type: application/json' -X POST https://192.168.1.68/mgmt/tm/gtm/pool/cname -d '{"name":"example_cname_pool","members":[{"name":"example.com"}]}'


Configuring the Wide IP

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Wide IPs > Wide IPs List.
  3. Click Create.
  4. Specify a name for the wide IP.
  5. For Type, click the record type for the wide IP. For example, A.
  6. In Pools section, select the CNAME pool created in the previous procedure from the Pool list.
  7. Click Add.
  8. Click Finished.
Creating a Wide IP that utilizes the CNAME pool, using REST

Alternatively, you can create a new Wide IP that references a CNAME pool with iControl REST using the following cURL command syntax.
Impact of procedure: Performing the following procedure should not have a negative impact on your system.

curl -sk -u 'admin:<password>' -H 'Content-Type: application/json' -X POST https://<bigip ip address>/mgmt/tm/gtm/wideip/a -d '{"name":"<new wideip name>","poolsCname":[{"name":"<cname pool name>","partition":"<cname pool partition>"}]}'

Example:
curl -sk -u 'admin:admin' -H 'Content-Type: application/json' -X POST https://192.168.1.68/mgmt/tm/gtm/wideip/a -d '{"name":"www.example.com","poolsCname":[{"name":"example_cname_pool","partition":"Common"}]}'
 

Additional Information

After you complete the previous procedures, the BIG-IP DNS returns a CNAME record for any A or AAAA DNS request that matches the domain name.

For example, the following output shows that the BIG-IP DNS returns the example.com CNAME record in response to a request for the www.example.com A record:

#dig @10.10.10.10 A www.example.com

Note: it is not possible to assign a health monitor to a CNAME Pool or CNAME Pool Member.
