Known Issue

This is the result of a known issue. When you upgrade from version 5.5 through version 5.5.2 of FirePass software to version 6.0.2, FirePass may display both the Compatibility Mode 1 and the Compatibility Mode 2 buttons as enabled on the Portal Access: Web Applications: Content Processing page under the Global Settings tab. This issue occurs when the Compatibility mode (enable legacy version of Web Applications handler) check box was selected on the Portal Access: Web Applications: Content Processing page under the Global Settings tab prior to the upgrade. Although both the Compatibility Mode 1 button and the Compatibility Mode 2 button appear enabled, FirePass correctly uses Compatibility Mode 1.

F5 Networks Product Development tracked this issue as CR89653 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Workaround

You can work around this issue by performing the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Portal Access: Web Applications: Content Processing page.
  3. Click the Global Settings tab.
  4. Clear the Compatibility Mode (enable legacy versions of Web Applications engine) check box.
  5. Click the Compatibility Mode 1 (Version 5.2.1 and earlier default engine) button.

Note: Since FirePass is already using Compatibility Mode 1, a service restart is not required after completing this procedure.
