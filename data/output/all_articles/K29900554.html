Description

Application traffic is reset with reason "Invalid HTTP headers blocked".

Environment

  • HTTP Protocol Security profile configuration is:
    ...
        methods {
            alarm enabled
            block disabled
            values { GET HEAD POST }
        }

Cause

This is due to a known is tracked with Bug ID 932553: An HTTP request is not served when a remote logging server is down

In the ltm logs, during the time the resets occurred, the monitor of the High Speed logging pool was down and hence pool was unavailable. 

Recommended Actions

At the time this article was published, a fix version or workaround was not available.

Please open a case with F5 Support to request for an Engineering Hot Fix.
