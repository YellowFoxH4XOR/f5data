Security Advisory Description

F5 BIG-IP 13.0.0-13.0.1, 12.1.0-12.1.3.6, or 11.2.1-11.6.3.2 HTTPS health monitors do not validate the identity of the monitored server. (CVE-2018-5542)

Impact

This vulnerability may allow unauthorized disclosure and modification of monitor traffic by an attacker with a privileged network position (MITM).

Note: This vulnerability affects HTTPS monitors that are configured on Traffic Management Microkernel (TMM) interfaces and monitors that are configured on the management interface (MGMT).

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by upgrading to a version listed in the Fixes introduced in column and performing the tasks in the Mitigation section.

Mitigation

To completely mitigate this vulnerability, you must upgrade to BIG-IP 13.1.0 or later and perform all of the following tasks:

  • Ensure that your HTTPS health monitors are configured to use a TMM interface and not the management interface.

    Note: The In-TMM monitoring feature is not available for monitors using the MGMT interface.

  • Configure the In-TMM monitoring feature.

    Note: The In-TMM monitoring feature is only available in version 13.1.0 and later.

    • For information about enabling In-TMM monitoring, refer to K11323537: Configuring In-TMM monitoring.
  • Configure a Server SSL profile with server authentication.
    • For information about Server SSL profiles and server authentication, refer to K14806: Overview of the Server SSL profile (11.x - 13.x).
  • Associate the Server SSL profile with the HTTPS monitor.
