Description

IPsec may not re-establish a tunnel connection automatically when the renewal of Security Associations (SAs) should happen.

There is no issue when manually establishing the IPsec tunnel.

Environment

  • BIG-IP
  • IPsec may not establish a tunnel connection at re-key time.
  • No issue establishing IPsec tunnel manually.

Cause

There is a difference in IPsec lifetime settings for both the IPsec peers.

Under rare conditions if each IPsec peer decides on a different lifetime for the SAs (the tunnel) then if the peer with a lower lifetime is in passive mode, it may not start the re-key process and expire the existing SAs.

Rare vendor interop issues may also occur when different IKE or IPsec SA lifetimes are configured on each peer.

Recommended Actions

On both IPsec devices, set the same IKE and IPsec SA lifetimes. If the peer is not a F5 BIG-IP, refer its product manual on how to make changes to the IPsec lifetime.

On a F5 BIG-IP follow the steps below for IKE SAs.

  1. Login to a F5 BIG-IP Configuration Terminal
  2. Navigate to Network > IPsec > IKE Peers
  3. Click on the name of the IKE peer config
  4. Under Lifetime, enter the same value as the peer IPsec configuration
    Note: The default Lifetime value is 1440 minutes
  5. Click Update

For IPsec SAs:

  1. Login to a F5 BIG-IP Configuration Terminal
  2. Navigate to Network > IPsec > IPsec Policy
  3. Click on the name of the IPsec policy config
  4. Under Lifetime, enter the same value as the peer IPsec configuration
    Note: The default Lifetime value is 1440 minutes
  5. Click Update
