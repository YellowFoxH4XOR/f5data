Description

Cannot reset BIG-IP root password via single user mode when following solutions such as K35811337.

Observing output similar to the following:

sh-4.2# passwd root
cat: /config/bigip/auth/localusers: No such file or directory
-- ERROR --
The user root is currently authenticated from a remote source.
Please change the password at the remote authentication server.

Environment

  • Single user mode
  • Recovery tasks
  • Password reset

Cause

This error could get returned in a few scenarios:

  • /config/bigip/auth/pam.d/local/system-auth is inaccessible/missing
  • /config/bigip/auth/localusers is inaccessible/missing
  • /config/bigip/auth/localusers does not contain the user in question (i.e. root)

Typically the ultimate root cause is that the config filesystem was not mounted. Note the No such file or directory in the example given in this article's description.

Recommended Actions

Ensure that you follow the process correctly.

For example, if the platform is a VE, and the boot location in question is HD1.2, this is the typical sequence of commands that would need to be run:

mount -o remount,rw /sysroot
mount -o remount,rw /sysroot/usr
mount /dev/mapper/vg--db--vda-set.2._config /sysroot/config     # Take care not to skip this step
mount /dev/mapper/vg--db--vda-set.2._var /sysroot/var
chroot /sysroot
passwd root
touch /.autorelabel
exit
exit

Additional Information

This error message might also appear in legitimate cases where you try to change the password for a remote authenticated user from within TMOS.
