K1697: Error message: Error: Configuration sync/save/install already in progress

Topic

When a configuration synchronization process is initiated, a /usr/local/ucs/.timetag file is created as both a lock file and a timestamp for the process. This file is normally deleted as soon as the synchronization is complete; however, this file will be retained if BIG-IP crashed or spontaneously rebooted interrupting a previous configuration synchronization process.

If the /usr/local/ucs/.timetag file already exists when the configuration synchronization processes is started, the configsync command will fail and you will receive the following error:

Error: Configuration sync/save/install already in progress

If you have verified that there are no other configuration synchronization processes running, delete the /usr/local/ucs/.timetag file and rerun the b config sync command. This should eliminate the error.
