Known Issue

When you upgrade from BIG-IP 10.2.x, the Internet Group Management Protocol (IGMP) and Protocol-Independent Multicast (PIM) are not in the self-allow default list.

This issue occurs when the following condition is met:

  • You upgrade from BIG-IP 10.2.x.

Impact

Advance routing with multicast or PIM does not work.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H651208 on the Diagnostics > Identified > Low page.
  • Advance routing with multicast or PIM does not work when you configure it after you upgrade the system using the default self-allow list.

Workaround

To work around this issue, you can manually add PIM or IGMP to the self-allow default list. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To add IGMP and PIM to the default port list, type the following Traffic Management Shell (tmsh) command:

    tmsh modify net self-allow defaults add { igmp:0 pim:0 }

  3. Save the changes by typing the following command:

    tmsh save sys config
