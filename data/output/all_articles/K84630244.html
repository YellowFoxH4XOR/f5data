Description

Peer Authority Devices information is not properly populated at Device Management  ››  Device Trust : Peer List. The following information of the device peer are missing.

  • Hostname
  • Serial Number
  • MAC address

Environment

This issue occurs in the following conditions.
  • Not able to properly setup High Availability HA Failover.
  • ConfigSync status shows Disconnected from all devices.

Cause

The cause of the issue is unknown.

    Recommended Actions

    The workaround to this issue is to remove all HA configurations and reconfigure them back before re-adding the device trust. Please follow the details steps below.

    1. Reset Device Trust on both devices.
      • Device Management  ››  Device Trust : Local Domain
    2. Remove all HA configurations on both devices.
      • Device Management  ››  Devices  ››  <device.name.self>  ››  Device Connectivity  ››  ConfigSync
      • Device Management  ››  Devices  ››  <device.name.self>  ››  Device Connectivity  ››  Failover Network
    3. Check if HA configurations for both devices has been properly removed.
    4. Reconfigure the HA configurations back on both devices.
    5. Add the Device Trust Peer.
      • Device Management  ››  Device Trust : Peer List
