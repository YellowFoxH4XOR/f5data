Issue

Error Message

err mcpd[<PID>]: 01070151:3: Rule [<name>] error: <message>

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <name> is the name of the affected iRule.
  • <message> is a descriptive message indicating the Tool Command Language (Tcl) error and problematic code.

For example:

err mcpd[6202]: 01070151:3: Rule [/Common/rule_example] error: Unable to find pool (pool_example) referenced at line 13: [pool pool_example]

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility

Description

This message occurs when all of the following conditions are met:

  • You update an iRule using the Configuration utility or the Traffic Management Shell (tmsh).
  • The BIG-IP system encounters a general Tcl parsing error when validating the iRule for the update process.

Impact

You cannot successfully update an iRule until all coding errors are corrected.

Recommended Actions

The log message describes the Tcl error encountered by the BIG-IP system and information about the problematic code. The recommended action depends on the type of error encountered. To correct the problematic code, consider the following:

  • If the message contains syntax errors such as "missing brace" or "unexpected extra argument," inspect the code near the line indicated by the log message to ensure braces ({ and }) are paired and commands use the correct number of arguments.
  • If the message indicates a command is invalid, ensure the commands are being used in the proper context. For example, provision necessary modules before using module-specific iRule commands.
  • If the errors are caused by incorrectly referenced objects, such as a data group that has yet to be created, ensure the objects exist in the configuration and the iRule references the correct object names.
