Issue

Error Message

01140100:6: Overdog daemon startup

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP system is shutting down or has begun restarting.

The overdog process monitors the high availability (HA) table for failover action types of restart, restart-all, or reboot, and you cannot manage the process using the TMOS Shell (tmsh).

Impact

While the overdog process restarts, configured failover action types of restart, restart-all, or reboot will not occur.

Recommended Actions

None
