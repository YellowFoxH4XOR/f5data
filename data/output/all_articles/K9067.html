Topic

  • K15203: Configuring IPv6 link-local self IP addresses (10.x - 13.x)

Starting in BIG-IP LTM 9.4.4, the dynamic routing modules bundle includes support for the IS-IS routing protocol. When IS-IS is used to advertise IPv6 prefixes, an IPv6 link-local address on the BIG-IP system is used as the next hop for those prefixes.

The Traffic Managment Microkernel (TMM) automatically generates an IPv6 link-local address in the fe80::0/64 network for each Virtual Local Area Network (VLAN) configured on the system (based on the MAC address of the VLAN). However, for failover to occur without interruption, BIG-IP systems in a redundant pair must be configured with an IPv6 link-local floating self IP address.

To configure an IPv6 link-local floating self IP address in BIG-IP 9.4.4 through 9.4.8, you must perform the following procedures:

  • Determining the VLAN tag
  • Converting the VLAN tag to hexadecimal
  • Configuring an IPv6 link-local self IP address on each system
  • Configuring an IPv6 link-local floating self IP address

Determining the VLAN tag

You must determine the VLAN tag for the VLAN which requires to be configured with an IPv6 link-local floating self IP address. To do so, execute the following command:

bigpipe vlan <vlan name> | grep tag

For example, the following command specifies the external VLAN name:

bigpipe vlan external | grep tag

The command output displays the VLAN tag number; for example, 60:

VLAN external  tag 60   00:01:D7:1F:B8:45   MTU 1500

Converting the VLAN tag to hexadecimal

Once you have determined the VLAN tag, you must convert this value to hexadecimal.

For example, a VLAN with a tag of 60 would be the following in hexadecimal:

0x3C

Because of the procedures that follow, you may find convenient to represent the hexadecimal value using four digits (two bytes); in the case of the above example:

0x003C

Configuring an IPv6 link-local self IP address on each system

Before you can configure an IPv6 link-local floating self IP address, you must configure an IPv6 link-local self IP address on each BIG-IP system. The syntax for IPv6 link-local self IP addresses is as follows:

fe80:<vlan tag in hex using little endian byte ordering>::<arbitrary value (1-ffff)>

For example, if the VLAN tag is 60, the following is a valid IPv6 link-local self IP address:

fe80:3c00::11

Once you have determined the IPv6 link-local self IP address you want to assign to the VLAN, proceed creating it.

Note: For more information about creating a self IP address using the Configuration utility, refer to the BIG-IP Network and System Management Guide.

Note: For more information about creating a self IP address from the command line, refer to the Bigpipe Utility Reference Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Repeat this procedure on the peer BIG-IP system. Ensure you use a different (yet appropriate) IPv6 link-local self IP address. For example, if the VLAN tag is 60, you can use the following IP address:

fe80:3c00::12

Configuring an IPv6 link-local floating self IP address

Using the same syntax used in the previous procedure, create an appropriate IPv6 link-local floating self IP address. For example, if the VLAN tag is 60, you can use the following IP address:

fe80:3c00::10

Once you have created the IPv6 link-local floating self IP address, synchronize the configuration to the peer system.

Note: Beginning in BIG-IP 9.6.0 and 10.0.0, you are no longer required to encode the VLAN tag in the address. Instead, you can append the %vlan<vlan_tag> syntax to the address. For more information, refer to K15203: Configuring IPv6 link-local self IP addresses (10.x - 13.x).
