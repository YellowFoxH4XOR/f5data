K39000314: BIG-IP DNS resolving IP when all pool members are down/disabled

Type
Support Solution
Published
2021-07-04
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP DNS: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K39000314

Description

All GLSB pool members on a BIG-IP DNS has been marked disable or the status is offline but the BIG-IP DNS is still resolving the IP address of all the pool members.

This behavior does not happen when there is at least one pool member of the GSLB pool still available.

In the GSLB pool's Load Balancing Method, Alternate and/or Fallback would have been configured to Return to DNS.

For example, you have created wide IP for www.dns-example.example.com that have 3 pool members which have the IPs of 10.0.0.1, 10.0.0.2 and 10.0.0.3. When there is only one pool member available (the rest are disabled and/or offline) the BIG-IP DNS will only resolve the pool member which is available, example 10.0.0.1. When all pool members are disable and/or offline, the BIG-IP DNS will resolve to all 3 IPs without referring to any of the Load Balancing Methods.

Environment

  • BIG-IP DNS
  • All GSLB pool members are disabled and/or offline but BIG-IP DNS is resolving IPs of all pool members
  • Return to DNS has been configured in the Load Balancing Method in Alternate and/or Fallback

Cause

When creating a Wide IP list with its pool, this configuration will also be created in the ZoneRunner for redundancy purpose.

When Return to DNS has been configured and all pool members are down, the BIG-IP DNS will refer to the ZoneRunner for the zone name (for the example above the zone name is www.dns-example.example.com) and resolved the IPs configure in the zone file.

You can read further on Return to DNS in this article K28650431.

Recommended Actions

This is an expected behavior. You can change the BIG-IP DNS behavior to:

  • BIG-IP DNS does not resolve any IP address
  • BIG-IP DNS resolve to a fallback virtual server (another IP other than the pool members)
BIG-IP DNS does not resolve any IP address
  1. Log in to the BIG-IP DNS system Configuration Terminal.
  2. Navigate to DNS > GSLB > Pools > Pool List.
  3. Click on the impacted pool name.
  4. Click Members tab.
  5. Change Return to DNS in Alternate or Fallback to None.
  6. Click Update.
BIG-IP DNS resolve to a fallback virtual server (another IP other than the pool members)
Note: You can fallback to the virtual server which displays a disclaimer such as "Page Under Maintenance".
  1. Log in to the BIG-IP DNS system Configuration Terminal.
  2. Navigate to DNS > GSLB > Pools > Pool List.
  3. Click on the impacted pool name.
  4. Click Members tab.
  5. Change Return to DNS in Alternate or Fallback to Fallback IP.
  6. In Fallback IP change to the IP of the Virtual Server
    Important: This Virtual Server will not be monitored for availability.
  7. Click Update.
