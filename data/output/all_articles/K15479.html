Known Issue

Disabling synchronization on a BIG-IP GTM system may disable synchronization on all devices in the synchronization group.

This issue occurs when all of the following conditions are met:

  • Your system uses a synchronization group that includes multiple BIG-IP GTM devices.
  • You disable synchronization on one of the BIG-IP GTM devices.

Impact

In a synchronization group that contains multiple BIG-IP GTM systems, disabling synchronization on one device will disable synchronization on all other BIG-IP GTM devices.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Synchronization is disabled for all BIG-IP GTM devices in the synchronization group.

Workaround

To work around this issue, you can change the synchronization Group Name value prior to disabling synchronization. To do so, perform the following procedures:

Removing the BIG-IP GTM system from a synchronization group

Impact of workaround: Performing the following procedure stops the BIG-IP GTM system from receiving any configuration updates.

BIG-IP 11.5.0 and later

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Settings > GSLB > General.
  3. Modify the Group Name value to differ from the current group name value.

    For example, if the group name is default, change it to default_SOL15479.
  4. Click Update.
  5. Clear the Synchronize check box.
  6. Click Update.

BIG-IP 11.4.0 and 11.4.1

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Global Traffic > General.
  3. Modify the Group Name value to differ from the current group name value.

    For example, if the group name is default, change it to default_SOL15479.
  4. Click Update.
  5. Clear the Synchronization check box.
  6. Click Update.

Returning the BIG-IP GTM system to a synchronization group (optional)

If you want to return a disabled BIG-IP GTM system to an active synchronization group, perform one of the following procedures:

  • Using the gtm_add command to return a BIG-IP GTM system to a synchronization group
  • Using the Configuration utility to return a BIG-IP GTM system to a synchronization group (11.5.0 and later)
  • Using the Configuration utility to return the BIG-IP GTM system to a synchronization group (versions prior to 11.5.0)

Using the gtm_add command to return a BIG-IP GTM system to a synchronization group

To re-add a BIG-IP GTM system as a member of a synchronization group, you can use the gtm_add command from the command line of the synchronization-disabled BIG-IP GTM system.

Impact of workaround: This pulls the configuration of the command-referenced BIG-IP GTM system to the local BIG-IP GTM system, overwriting the configuration with the referenced BIG-IP GTM configuration.

  1. Log on to the command line of the synchronization-disabled BIG-IP GTM member referencing the "fake" synchronization group name.
  2. Use the following command syntax, replacing <IP address of a BIG-IP GTM system residing in the desired synchronization group> with the IP address of an alternate member of the desired synchronization group:

    gtm_add <IP address of a BIG-IP GTM system residing in the desired synchronization group>

    For example:

    gtm_add 10.0.1.53

Using the Configuration utility to return a BIG-IP GTM system to a synchronization group (11.5.0 and later)

To enable a disabled synchronization group member, you can modify the referenced synchronization group name from the "fake" name matching the desired synchronization group.

Impact of workaround: This pushes the configuration of the local BIG-IP GTM system to all members of the newly referenced synchronization group.

  1. Log on to the command line of the synchronization-disabled BIG-IP GTM member referencing the "fake" synchronization group name.
  2. Navigate to DNS > Settings > GSLB > General.
  3. Replace the "default_sol15479" synchronization group name with the desired/existing synchronization group name in the Group Name text box.

    Note: The "default_sol15479" synchronization group name is the synchronization group name used when disabling synchronization in the removal procedure.
  4. Select the Synchronize check box.
  5. Select the Synchronize DNS Zone Files check box.
  6. Click Update.

Using the Configuration utility to return a BIG-IP GTM system to a synchronization group (versions prior to 11.5.0)

To enable a disabled synchronization group member, you can modify the referenced synchronization group name from the "fake" name matching the desired synchronization group.

Impact of workaround: This pushes the configuration of the local BIG-IP GTM system to all members of the referenced synchronization group.

  1. Log in to the Configuration utility of the BIG-IP GTM system that you want to add to the sync group.
  2. Navigate to System > Configuration > Global Traffic > General.
  3. Replace the "default_sol15479" synchronization group name with the desired/existing synchronization group name in the Group Name text box.

    Note: The "default_sol15479" synchronization group name is the synchronization group name used when disabling synchronization in the removal procedure.
  4. Select the Synchronization check box.
  5. Select the Synchronize DNS Zone Files check box.
  6. Click Update.
