K50952603: Bundle state 'disabled' for optic OPT-0043 is invalid

Type
Support Solution
Published
2022-01-20
Updated
2023-10-16
Applies to

  • BIG-IP
  • VIPRION B2250 Blade
Source

Description

After migration to a new hardware, you may see interfaces with OPT-0043-01 are disabled and below following ltm log messages:

info bcm56xxd[<PID>]: 012c0015:6: Link: 1/1.1 is UNPOPULATED
info bcm56xxd[<PID>]: 012c0015:6: Link: 1/1.2 is UNPOPULATED
info bcm56xxd[<PID>]: 012c0015:6: Link: 1/1.3 is UNPOPULATED
info bcm56xxd[<PID>]: 012c0015:6: Link: 1/1.4 is UNPOPULATED
err bcm56xxd[<PID>]: 012c0010:3: Unbundled interfaces found. Bundle state 'disabled' for optic OPT-0043 is invalid.
err bcm56xxd[<PID>]: 012c0024:3: Invalid Bundle Config for optic OPT-0043
err bcm56xxd[<PID>]: 012c0010:3: Unsupported module in use on interface 1/1.1
info bcm56xxd[<PID>]: 012c0015:6: Link: 1/1.1 is DISABLED
err bcm56xxd[<PID>]: 012c0010:3: Unsupported module in use on interface 1/1.2
info bcm56xxd[<PID>]: 012c0015:6: Link: 1/1.2 is DISABLED
err bcm56xxd[<PID>]: 012c0010:3: Unsupported module in use on interface 1/1.3
info bcm56xxd[<PID>]: 012c0015:6: Link: 1/1.3 is DISABLED
err bcm56xxd[<PID>]: 012c0010:3: Unsupported module in use on interface 1/1.4
info bcm56xxd[<PID>]: 012c0015:6: Link: 1/1.4 is DISABLED
 

Environment

  • B2250
  • BIG-IP v15.1.4
  • F5-UPG-QSFP+BD (OPT-0043-01) - 40G-SR-BiDi 100m QSFP+ Bi-Directional 40G Transceiver with DDM Support
 

Cause

OPT-0043 is a Bi-Directional optical transceiver made up of 2 20G channels.
Do not unbundle OPT-0043 - that is an unsupported configuration.

# tmsh list net interface 1/1.1

net interface 1/1.1 {
    bundle enabled    <<<<  This is the correct configuration.
...
    vendor F5 NETWORKS INC.
    vendor-partnum OPT-0043
}
 

Recommended Actions
 

You can use tmsh to configure bundling for the 40GbE interfaces on the platform.
For example, 

tmsh modify net interface 1/1.1 bundle enabled
