Description

You're providing access to internal resources through APM VPN.
You want to make sure that some users are always able to get connected, 
To this purpose, you are looking for a way to "reserve" or "assign" some connectivity licenses to this very group of users.

Environment

  • You're using BIG-IP APM;
  • You're using NetworkAccess technology to provide VPN connections.
Cause

The license is global to the BIG-IP APM and we cannot:

  • split the license, in any way
  • attach some of the connectivity resources to one particular AccessProfile, or to one group of users.

Recommended Actions

As there's no existing solution to implement such a configuration, F5Networks would recommend to engage with F5 Professional Services to discuss the options and other approach, suitable to address this requirement.
Otherwise, we can suggest investigating the following lead:
  • to pay attention to the current usage of the CCU / connectivity license session, system-wide;
  • to discard any connection attempt for a user that does not belong to a high priority group.
To do so, we can use the following expressions, in of any agent in the AccessPolicy/VPE:
  • expr {[mcget -license {tmm.license.global_connectivity}]} <--- tell us about the max CCU, as per the license.
  • expr {[mcget -license {tmm.license.global_connectivity#}]} <--- tell us the amount of CCU currently in use
