Description

RAM cache is a cache of HTTP objects stored in the BIG-IP system’s RAM that is reused by subsequent connections to reduce the amount of load on the back-end servers. It is useful if an object on a site is under high demand, if the site has a large quantity of static content, or if the objects on the site are compressed.

 

Common questions about RAM cache questions:

 

What does that mean 100% utilization of the Byte rate?

Byte rate basically tells how much we deliver content from the ram cache in bytes but calculating its ratio (in %).

 

What is the difference between Byte rate and Hit rate?

The hit rate is a packet rate while the byte rate is throughput in bytes.

 

If the reading is so high, does that mean that we need to do something regarding capacity planning?

Unlike CPU or memory 100%, high RAM cache utilization is not a concern. It's telling how much RAM cache feature has been utilized. There is nothing to worry about.
