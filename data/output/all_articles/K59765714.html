K59765714: Overview of Address and Port Translation

Type
Support Solution
Published
2023-03-07
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K59765714

Description

Virtual Servers will by default send traffic to pool members using the configured pool member's IP address as the destination IP, and the configured pool member's port as the destination port. This behavior can be altered by disabling the Address Translation and Port Translation options in the virtual server configuration, but doing so unnecessarily can lead to routing loops where traffic sent by the Big-IP to a pool member is instead routed back to the virtual server specified in the untranslated destination IP.

Environment

  • Port Translation Settings
  • BIG-IP LTM (Local Traffic Manager)
  • NAT/SNAT (Network Address Translation/Secure Network Address Translation)
  • Pool Member IP/Port

Cause

Disabled address and port translation options can prevent requests from reaching the pool member.

Recommended Actions

For most configurations, enable address and port translation, and ensure that responses are directed through the BIG-IP.

Additional Information

Address Translation - Specifies, when checked (enabled), that the system translates the address of the virtual server. When cleared (disabled), specifies that the system uses the address without translation. This option is useful when the system is load balancing devices that have the same IP address. The default is enabled.

Port Translation - Specifies, when checked (enabled), that the system translates the port of the virtual server. When cleared (disabled), specifies that the system uses the port without translation. Turning off port translation for a virtual server is useful if you want to use the virtual server to load balance connections to any service. The default is enabled.
