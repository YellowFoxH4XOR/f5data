Description

  • SAML Authentications fail. The message logged in /var/log/apm is "Saml Failed to pass assertion. Response is not encrypted"

Environment

  • The BIG-IP is a SAML Service provider.
  • You have updated your site certificate because the old one has expired.
  • The Configuration has "Encrypt Assertion" enabled
  • apm aaa saml /Common/remote.example.com {
    entity-id https://remote.example.com
    idp-connectors {
        /Common/ADFS { }
    }
    sp-certificate /Common/remote.example.com.crt
    sp-decryption-cert /Common/remote.example.com.crt
    sp-decryption-key /Common/remote.example.com.key
    sp-signkey /Common/remote.example.com.key
    want-assertion-encrypted true
}
    The IDP may be ADFS.

Cause

This configuration is using the site's certificate, remote.example.com.crt, to  encrypt the assertion.
This type of certificate is typically renewed yearly.
If you renew the certificate on the BIG-IP because the old certificate is expired but fail to update the certificate on the ADFS server this message may be logged.
The ADFS server sees the old remote.example.com certificate is expired and does not encrypt the assertion.

Recommended Actions

  1. Update the encrypting certificate (remote.example.com)  on the ADFS server

Additional Information

Other IDP's may behave in other ways.
