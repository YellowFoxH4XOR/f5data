Known Issue

This is the result of a known issue. The Cipher server preference option in the Client SSL profile has no effect. The BIG-IP system always behaves as if the option is active, even when the option is disabled.

F5 Product Development is tracking this issue as ID 227237.

Additional information

Client SSL profiles include the Cipher server preference option. This option, which is disabled by default, is intended to control whether the system uses the client's cipher preference or the server's cipher preference, when determining which cipher it uses for the Secure Sockets Layer (SSL) connection. The client cipher preference walks the client's cipher list and selects the first cipher that is also in the server's cipher list. The server cipher preference walks the server's cipher list and selects the first cipher that is also in the client’s cipher list.

Client SSL profiles have always operated exclusively in server cipher preference mode. F5 Product Development has determined that this mode should be the only available mode, and will remove the Cipher server preference option in a future version of the software.

Note: Due to a different known issue, the BIG-IP system may follow the client cipher preference. For more information, refer to K12391: The BIG-IP system may choose the cipher for an SSL connection based on the client's cipher preference.

Note: Server SSL profiles also include the Cipher server preference option. However, these profiles should not include this option because the cipher used for an SSL connection is chosen by the server, not by the client. Therefore, when a virtual server is configured with a Server SSL profile, and the BIG-IP system acts as the client in an SSL connection, the BIG-IP system plays no role in choosing which cipher will be used for the connection.
