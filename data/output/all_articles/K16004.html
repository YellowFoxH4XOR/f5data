K16004: User accounts that were not created on both BIG-IQ devices may be removed when configuring the BIG-IQ system in a high-availability cluster

Known Issue

When configuring the BIG-IQ system in a high-availability (HA) cluster, you might remove user accounts that were not created on both BIG-IQ devices.

This issue occurs when all of the following conditions are met:

  • You created user accounts on one BIG-IQ device, and did not create the accounts on the other BIG-IQ device.
  • You configured the BIG-IQ devices in an HA cluster.

Impact

After you configure the BIG-IP HA cluster, the system may remove the user accounts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • User accounts are unexpectedly missing from the BIG-IQ system.

Workaround

To work around this issue, ensure that both BIG-IQ devices have the same set of user accounts. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BASH prompt of the BIG-IQ device that has a full set of user accounts.
  2. Copy and rename the /config/bigip_user.conf file to a temporary location on the secondary BIG-IQ system.

    The following example uses the secure copy (SCP) utility to copy and rename the bigip_user.conf file to the /var/tmp directory on the BIG-IQ system with a smaller set of user accounts:

    scp /config/bigip_user.conf root@<Secondary BIG-IQ address>:/var/tmp/temp_bigip_user.conf

  3. Log in to the BASH prompt of the secondary BIG-IQ device that has just received the temp_bigip_user.conf file.
  4. Using a text editor, remove the root user definition from the /tmp/temp_bigip_user.conf file and save the file.

    For example:

    auth user root {
        description "root"
        encrypted-password "$1$tAiUgKE3$t27ER2uyRzoplfh91./94."
        shell bash
    }

  5. Merge the user accounts with the running configuration by typing the following command:

    tmsh load sys config merge file /var/tmp/temp_bigip_user.conf

  6. Save the new user accounts by typing the following command:

    tmsh save sys config

  7. Configure the BIG-IQ devices in an HA cluster.
