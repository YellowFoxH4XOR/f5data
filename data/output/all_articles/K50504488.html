K50504488: Removing all files and folders from /var/log/ prevents all users from logging in

Type
Support Solution
Published
2021-11-05
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K50504488

Description

  • Cannot login to the F5 via CLI or GUI
  • Login failed message

Environment

  • All files/folders removed from /var/log

Cause

Removing all files/folders from /var/log.

Recommended Actions

  1. Reboot
Note: When attempting to clear disk space do not remove all files/folders within /var/log/. Open a case with F5 support if you need assistance regarding disk space.
