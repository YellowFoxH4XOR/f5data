Description

Additional information on the "144 /var/annotate/<##>" found in /var/ directory

 

Environment

-BIG-IP

Cause

These directories are expected and created by the system by design.

Recommended Actions

No actions required, as these directories are system directories created during normal processes. Unless you run into the behavior described in known issue tracked in ID472645

Additional Information

In some instances a large number of these directories can lead to tomcat running out of memory. This behavior and workaround is currently tracked with ID472645.
