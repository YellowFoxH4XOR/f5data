Known Issue

BIG-IP Edge Client may fail to initiate connections from iOS 6.x. BIG-IP Edge Client 2.0.3 for iOS has been found to have an issue running on all versions of iOS 6.x.

This issue occurs when all of the following conditions are met:

  • The user device is running iOS 6.x.
  • BIG-IP Edge Client 2.0.3 is installed on the user's iOS device.

Impact

BIG-IP Edge Client fails to initialize connections.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP Edge Client disconnects immediately when attempting to establish a connection.
  • When analyzing network communications on the BIG-IP APM or FirePass system, there is no connection information for the BIG-IP Edge Client connection attempt.
  • When running iOS 7, BIG-IP Edge Client functions as expected.

Workaround

To work around this issue, F5 recommends that iOS 6.x users do not install BIG-IP Edge Client 2.0.3; alternatively, users can upgrade iOS to version 7 or later before installing BIG-IP Edge Client.
