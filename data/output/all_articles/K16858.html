Known Issue

Enterprise Manager does not receive configuration or availability status change notifications for pool members or nodes.

This issue occurs when all of the following conditions are met:

  • You use Enterprise Manager to manage one or more remote BIG-IP LTM systems.
  • The remote system is running BIG-IP 11.6.0.
  • You modify the configuration or the availability status for a pool member or node.

Impact

Changes to configuration and status, for pool members or nodes, are not received by the Enterprise Manager system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You notice a discrepancy between the Enterprise Manager system and a remote BIG-IP LTM system, for a node or pool member configuration or availability status.
