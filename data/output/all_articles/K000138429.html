Description

When you run the below command on an F5OS device, you see the following error:

snmpwalk -c public -v 2c <F5OS Device IP Address> ifAlias 
IF-MIB::ifAlias = No Such Instance currently exists at this OID

 

Environment

  • F5OS-C / F5OS-A
  • Velos or rSeries
  • - v1.8.0

 

Cause

  • Bug ID 1497385

 

Recommended Actions

  • Please reach out to F5 Support for information on a fix for this error.
