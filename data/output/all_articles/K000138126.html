Topic

This article applies to BIG-IP Next Central Manager instances. For more information about other systems, refer to the following articles:

  • K000136925: Restore a BIG-IP Next instance to factory default settings
  • K05531172: Restoring the VELOS configuration to factory default settings
  • K20024872: Restore the rSeries configuration to factory default settings
  • K13127: Restoring the BIG-IP configuration to factory default settings (11.x - 17.x)
  • K15886: Restore the BIG-IQ system to factory default settings

You should consider using this procedure under the following conditions:

  • You want to restore the BIG-IP Next Central Manager instance configuration to the factory default settings.

Description

You can restore a BIG-IP Next Central Manager instance to the factory default settings using the BIG-IP Next Central Manager command line (CLI). This removes the instance's configuration and loads the default configuration onto the instance leaving the management IP configuration in place. All the data and content for the BIG-IP Next Central Manager instance are removed, including but not limited to the following:

  • Managed BIG-IP Next instances inventory

    Note: The managed BIG-IP Next instances are removed from the BIG-IP Next Central Manager however the configuration on these managed instances are not removed; for example, the application configurations are not removed and the disabled users are not re-enabled including the default admin user. If you are adding these removed instances to another BIG-IP Next Central Manager, you need to use the management credentials that was setup with this BIG-IP Next Central Manager instance instead of the default admin user. If you prefer the managed BIG-IP Next instances to be properly removed from the BIG-IP Next Central Manager, you should perform the procedure described in How to: Remove a managed BIG-IP Next instance from BIG-IP Next Central Manager before you proceed to restore the BIG-IP Next Central Manager instance configuration to the factory default settings.

  • Infrastructure providers configuration on the BIG-IP Next Central Manager
  • Application services configuration on the BIG-IP Next Central Manager
  • QVKiew files
  • Backup files
  • Image files

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the BIG-IP Next Central Manager CLI.

Procedures

Use the BIG-IP Next Central Manager CLI

To restore a BIG-IP Next Central Manager instance to factory default settings using the BIG-IP Next Central Manager CLI, perform the following procedure:

Important: Performing /opt/cm-bundle/cm uninstall -c does not clean external storage from the configuration. If you want to set up different external storage, you will need to deploy a new Central Manager instance.

 

Impact of procedure: All managed BIG-IP Next instances, BIG-IP Next Central Manager configuration (such as providers, application services etc), backup files and images are removed when you perform the BIG-IP Next Central Manager uninstallation. This process is not reversible; consider carefully before proceeding.

  1. Login to the BIG-IP Next Central Manager command line as the admin user.
  2. Uninstall the BIG-IP Next Central Manager by typing the following command:

    /opt/cm-bundle/cm uninstall -c

  3. When the uninstall process is complete, perform the BIG-IP Next Central Manager setup by typing the following command:

    setup

  4. You would be prompted for the following information during the setup process:
    • Hostname - this should be the Fully Qualified Domain Name (FQDN) of the BIG-IP Next Central Manager system.
    • IP address(es) - the setup process will discover if there is an existing management IP address and prompt if you want to configure a new management IP address. If you wish to keep the existing management IP address, enter N for the Do you want to configure a static IP address (N/y) [N]: prompt.
    • Primary NTP server address - This is optional. Enter the IP address of the primary NTP server.
    • Alternate NTP server address - This is optional. Enter the IP address of the secondary NTP server.
    • IPv4 network CIDR to use for service IPs [100.75.0.0/16]: This is the default IPv4 address range for services use within the Kubernetes cluster. Ensure the defaults listed do not conflict with the existing IP address space in your application environment. If they do, choose a different IP range for the service IPs to resolve the conflict.
    • IPv4 network CIDR to use for pod IPs [100.76.0.0/14]: This is the default IPv4 address range for pods use within the Kubernetes cluster. Ensure the defaults listed do not conflict with the existing IP address space in your application environment. If they do, choose a different IP range for the pod IPs to resolve the conflict.
    • If you have previously setup the BIG-IP Next Central Manager to mount an external storage, you would need the following information of the external storage:
      • the storage type (samba/nfs)
      • storage server address
      • share path
      • username and password (for samba)
  5. Once you are done entering these information, the setup process presents the configuration information and prompts if the information is correct:

    Would you like to complete configuration with these parameters (y/N) [N]:

    Enter y to confirm the configuration information. The setup process then prompts if you would like the setup process to complete the setup:

    Would you like to start the BIG-IP Next Central Manager application installation (Y/n) [Y]:

    Note: Starting in version 20.2.1, this option is now performed in the webUI, after the setup is completed.

    Enter Y to proceed and then wait for the setup process to complete. When the setup process has completed, it displays the following:

    [INFO] Setup completed successfully.

  6. When the setup process has completed, you should login to the BIG-IP Next Central Manager webUI using the default admin credentials (admin/admin). The webUI will prompt you to create a new admin user password for the BIG-IP Next Central Manager system.
