Description

When use AD Group Resource Assign or LDAP Group Resource Assign, the client cannot get the expected resource.
Maybe the client cannot get any resource, fallback into LTM+APM mode, in the log /var/log/apm, the session log like:

notice apmd[<pid>]: 01490102:5: /Common/<access profile name>:Common:<session id>: Access policy result: LTM+APM_Mode

Environment

  • BIG-IP APM
  • Virtual server
  • Access Profiles (Per-Session Policies)
  • AD Group Resource Assign or LDAP Group Resource Assign

Cause

The LDAP path changed in the AD or LDAP server, it mismatch with the string in the APM configuration.

Recommended Actions

When configure the AD Group Resource Assign or LDAP Group Resource Assign, in the configuration, the expression is like:

CN=Group1,OU=OU-1,DC=example,DC=local

In the AD / LDAP server, change the object path to

CN=Group1,OU=OU-2,DC=example,DC=local

This configuration will not sync to BIG-IP APM, please delete and reconfigure this object in the APM.

Additional Information

Suggest to define some groups in the AD / LDAP server, and do not change the path for them, only change the user in the groups.
