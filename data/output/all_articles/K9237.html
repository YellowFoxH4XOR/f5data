Known Issue

This is the result of a known issue. If you impersonate a user’s account on the Users : Impersonate User page and then launch a Web Application Tunnel from the user’s webtop, the Application Tunnel pop-up window reports the tunnel status as Connected but the browser window reports that the page cannot be displayed.

F5 Networks Product Development tracked this issue as CR101966, and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative Hotfix HF-602-7.2 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
