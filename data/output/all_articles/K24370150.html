Description

The model of one-vlan-per-interface is becoming quickly outmoded in favor of tagged VLANs on LAGs over multiple interfaces. The byproduct of this is that any statistics in the GUI or TMSH result in seeing the statistics for the trunk, but not the individual VLAN. This article describes how to view these statistics.

Environment

  • BIG-IP

Cause

None.

Recommended Actions

This can be gathered via either CLI (Advanced Shell / bash only) or via SNMP polling.

SNMP via ifXTable
Note: Beginning in BIG-IP 11.5.2 HF1 and 11.6.1, the F5-BIGIP-SYSTEM-MIB::sysVlanStatTable OIDs are deprecated and replaced by IF-MIB::ifXTable OIDs. (K17203: The sysVlanStatTable OIDs are deprecated and replaced by ifXTable OIDs) 
These IF_MIB::ifXTable OIDs allow statistics on a per-VLAN basis. Recall that IF-MIB is an IETF standard MIB file per K13322.
