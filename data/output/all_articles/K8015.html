Known Issue

This is the result of a known issue. If a Windows Vista client attempts to launch a Network Access connection inside Protected Workspace, Network Access may fail to connect. When this issue occurs, an error message similar to the following example will display:

Status: The system could not update the phone book file.

This issue occurs when the following two conditions are met:

•    Windows Vista User Account Control (UAC) is disabled on the client system
•    The Network Access client component was pre-installed on the client system as part of an MSI package

Note: MSI packages are customized and downloaded on the Network Access: Client Downloads page in the FirePass Administrative Console.

UAC is a security component in Windows Vista. For more information about UAC, refer to the following web site:

http://technet2.microsoft.com/WindowsVista/en/library/00d04415-2b2f-422c-b70e-b18ff918c2811033.mspx
 
F5 Networks Product Development tracked this issue as CR86288 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in Cumulative Hotfix HF-601-8 issued for FirePass version 6.0.1. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

To work around this issue, enable User Account Control on your Windows Vista system. For more information about enabling User Account Control, refer to your Microsoft Windows documentation.
