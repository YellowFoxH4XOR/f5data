Known Issue

The BIG-IP system fails to update the SNMP hbInterval setting after an upgrade to BIG-IP 11.3.0 or later. This issue occurs when the following condition is met:

  • You have upgraded the affected system from BIG-IP 11.2.0 or BIG-IP 11.2.1

The SNMP hbInterval setting determines the amount of time, in seconds, that the snmpd process can wait for a response. This setting is accessible in the /config/snmp/bigipTrafficMgmt.conf file. In BIG-IP 11.2.0 through 11.2.1, the SNMP hbInterval setting is set to 60 by default. In BIG-IP 11.3.0 and later, the hbInterval setting is set to 300 by default.

On a heavily loaded system, the sod (watchdog) process is likely to stop the snmpd process if the hbInterval setting is less than 300. As a result, the snmpd process produces a core file in the /shared/core directory.

Impact

The SNMP hbInterval setting does not update to the value of 300 after an upgrade to BIG-IP 11.3.0 and later, and the snmpd process produces a core file in the /shared/core directory.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The sod process stops and restarts the snmpd process, causing the snmpd process to produce an snmpd core file in the /shared/core directory.
  • The SNMP hbInterval setting remains at the value of 60 after an upgrade to BIG-IP 11.3.0 and later.

Workaround

To work around this issue, you can manually update the SNMP hbInterval setting by editing the /config/snmp/bigipTrafficMgmt.conf file. To do so, perform the following procedure:

Impact of workaround: The snmpd process cannot process any SNMP requests or send SNMP traps during this procedure.

  1. Log in to the command line on the affected BIG-IP system.
  2. Stop the snmpd process by typing the following command:

    bigstart stop snmpd
  3. Back up a copy of the /config/snmp/bigipTrafficMgmt.conf file by typing the following command:

    cp -p /config/snmp/bigipTrafficMgmt.conf /var/tmp/bigipTrafficMgmt.conf.sol16654
  4. Edit the /config/snmp/bigipTrafficMgmt.conf file using a text editor of your choice (for example: vi).
  5. Locate the hbInterval setting, and replace the value of 60 with 300.
  6. Save the changes and exit the text editor.
  7. Start the snmpd process by typing the following command:

    bigstart start snmpd
