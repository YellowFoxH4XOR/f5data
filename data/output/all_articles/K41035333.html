K41035333: New BIG-IQ deployment - unable to access Configuration Utility

Description

The BIG-IQ Centralized Management Configuration Utility may be inaccessible on HTTPS port 443 after deploying a new BIG-IQ virtual edition system or after a successful BIG-IQ upgrade.

Environment

  • BIG-IQ virtual edition 8.1.0 deployed using an OVA

  • Single-NIC deployment

  • Hyper-V host

  • BIG-IQ is reachable from the command line

  • Attempts to access the Configuration Utility on port 443 fail

  • BIG-IQ Centralized Management upgraded from 8.4.0 to 8.4.1

Cause

Port 443 is blocked, or the HTTPD SSL port is configured as 8443 instead of the expected port 443.

Recommended Actions

  1. Check the configured HTTPD SSL port:
    list sys httpd ssl-port

  2. If the HTTPD SSL port is 8443, configure it to use port 443:
    tmsh modify /sys httpd ssl-port 443

  3. Restart the HTTPD service:
    restart sys service httpd

  4. Confirm that the Configuration Utility is accessible through the management IP address.
