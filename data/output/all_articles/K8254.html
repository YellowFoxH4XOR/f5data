Topic

This article discusses the runtime state change that occurs when a redundant a BIG-IP system is configured for Open Shortest Path First (OSPF) dynamic routing and experiences a failover event. It also discusses how to configure the BIG-IP systems to not be elected as an OSPF Designated Router (DR) or Backup Designated Router (BDR).

Description

One of the advanced routing protocols supported by the BIG-IP system is the OSPFv2/OSPFv3 protocol, which is a link-state dynamic routing protocol for external networks.

When multiple BIG-IP systems in a high availability (HA) configuration are running OSPF, each BIG-IP system participates independently in the OSPF-aware area. BIG-IP OSPF implementation is not traffic-group aware. With redistribution configured, the active unit advertises routes as long as they are present in RIB. For this reason, F5 recommends that you do not use OSPF in active-active HA configurations.

When a failover occurs, the BIG-IP system changes the OSPF runtime state as follows.

ProtocolRuntime State Change
OSPFv2The OSPF interface cost is increased on all interfaces to the maximum value (65535) when the status of the device is Standby. 
Also, all external type 2 Link State Advertisements (LSAs) are aged out.
OSPFv3The OSPF interface cost is increased on all interfaces to the maximum value when the status of the device is Standby.

When a BIG-IP system is in an HA configuration, F5 recommends that you configure an OSPF priority of 0 (zero) on every interface on which OSPF routing is enabled. This configuration will help the BIG-IP system avoid being elected as OSPF DR or BDR.

Configuring an OSPF priority of 0 on an interface

To configure an OSPF priority of zero on an interface, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. To access the IMI shell (imish), type the following command:

    imish

  3. To enter enable mode, type the following command:

    enable

  4. To enter configuration mode, type the following command:

    configure terminal

  5. To enter interface configuration mode for an interface, where <interface_name> is the name of the interface or VLAN that you are configuring, type the following command:

    interface <interface_name>

  6. To set the OSPF priority to 0 on the interface, type the following command:

    ip ospf priority 0

  7. To exit the interface configuration mode, type the following command:

    exit

  8. Repeat steps 4 through 6 for every interface on which OSPF routing is enabled.
  9. Type exit.
  10. To write the current configuration file, type the following command:

    write memory

  11. To exit the IMI shell (imish), type the following command:

    exit
