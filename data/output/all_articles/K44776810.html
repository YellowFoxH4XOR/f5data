Description

Traffic Classification based on SSL SNI extension may fail as a result unexpected traffic behaviour may be observed

Environment

  • LTM policy with CE profile type is used to classify the traffic
  • LTM policy uses SNI extension as a condition for traffic classification
  • Length of SNI extension used in the condition is greater then 64 bytes
  • Classification database released before January 2020 is in use.

Cause

The issue is caused by limit of Classification Database which supports SSL SNI with length up to 64 bytes.

Recommended Actions

To fix the issue update Classification Database to the latest version where 256 bytes SSL SNI support was added
