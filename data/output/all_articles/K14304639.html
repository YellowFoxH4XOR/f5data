Known Issue

Network access sessions may fail to establish when you use a Variable Assign agent to assign WINS and DNS for the access session.

This issue occurs when all of the following conditions are met:

  • You have configured your BIG-IP APM system with a network access profile.
  • The access policy of the access profile uses the Variable Assign agent to assign WINS or DNS server information.
  • The assigned WINS or DNS server information is empty.
  • Users attempt to establish a network access session.

Impact

The network access session fails to establish.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When a user attempts to establish a network access session, the user can supply their credentials, and the system runs any configured EndPoint Security agent. However, the system terminates the access session with an error message similar to the following example:

    An error occurred while configuring Network Access connection.
    Please contact your system administrator
    Network Access connection is terminated.

Workaround

To work around this issue, you can ensure that the Variable Assign agent is configured to assign non-empty DNS or WINS values. 

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
