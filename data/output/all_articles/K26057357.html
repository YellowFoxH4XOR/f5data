Topic

You should consider using this procedure under the following condition:

  • You want to change the BIG-IP system host name using either the Configuration utility or the TMOS Shell (tmsh).

Note: For information about changing the host name for Virtual Clustered Multiprocessing (vCMP) guests, refer to the following article: K84630501: Change the BIG-IP system host name for a vCMP guest.

Description

The BIG-IP system displays its host name in the upper-left corner of the Configuration utility and in the command prompt of the Advanced Shell (bash). You can use either the Configuration utility or tmsh to change the BIG-IP system host name that is displayed in both locations.

Two other visible configuration objects are identified using the BIG-IP system host name and will not be updated when the host name changes. While the BIG-IP system functions normally in this configuration, you may want to also change the configuration objects in the following table to avoid confusion.

Configuration objectDescription
Device Service Clustering (DSC) Device NameThis DSC Device Name appears on all remote DSC peer systems when you view the list of Device Trust Members. You can update the DSC Device Name using the procedures in K15700: Changing the BIG-IP host name does not update the device name when the device is a member of a DSC device group.
Device Certificate Common NameThe Device Certificate Common Name appears in the SSL certificate information you receive when you connect to the BIG-IP system Configuration utility. You can update the Device Certificate Common Name using the procedures in K16951115: Changing the BIG-IP DNS system device certificate using the Configuration utility.
Note: Use the procedure described in the Renewing the device certificate section for BIG-IP LTM only systems.

You can use either of the following procedures to change the BIG-IP system host name displayed in the Configuration utility and bash.

  • Using the Configuration utility to change the host name
  • Using tmsh to change the host name

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the Configuration utility or tmsh utility.

Procedures

To watch a video demo of this procedure using the Configuration utility, go to   Change the host name of your BIG-IP system using the Configuration utility.

Use the Configuration utility to change the host name

Impact of procedure: If you are using a DNS server to resolve the host name of the BIG-IP system, you should make sure to update the host name on the DNS server.

  1. Log in to the Configuration utility.
  2. Go to System > Platform.
  3. Under General Properties, locate Host Name.
  4. Enter the new BIG-IP system host name.

    For example:

    bigip1.example.com

  5. Select Update.
  6. The BIG-IP system host name should now be updated in both the Configuration utility and bash.

Use tmsh to change the host name

Impact of procedure: If you are using a DNS server to resolve the host name of the BIG-IP system, you should make sure to update the host name on the DNS server.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the system host name, use the following command syntax:

    modify /sys global-settings hostname <new host name>

    For example, to modify the system host name to bigip1.example.net, type the following command:

    modify /sys global-settings hostname bigip1.example.net

  3. To save the configuration, type the following command:

    save /sys config

  4. The BIG-IP system host name should now be updated in both the Configuration utility and bash.
