Issue

Starting in FirePass 6.0.2 with cumulative hotfix HF-602-8 and in FirePass 6.0.3 with cumulative hotfix HF-603-2.1, the FirePass standalone VPN client supports auto-launching a Network Access connection when the standalone client is running in advanced mode. Previously, the standalone VPN client would only launch a Network Access connection if the standalone client was running in simple mode.

In order for a Network Access connection to automatically launch in advanced mode, you must select the Autolaunch based on endpoint protection check box in the Network Access connection configuration under the Client Settings tab.
 
Users can switch to advanced mode by selecting the Switch to Advanced Mode option in the View menu of the standalone VPN client.
 
F5 Product Development is tracking this enhancement as CR99563.
