Description
Need to find where an SSL Certificate is applied in my configuration.
You might need to perform this if:
An expired or expiring certificate needs replaced, and you need to know where in your configuration the expired or expiring certificate is being used.

Environment
  • BIG-IP
  • Client SSL certificate
  • Server SSL certificate

Cause

The Configuration Utility does not communicate clearly which certificates are being used, and what profiles and or virtual servers they are applied to.

Recommended Actions

The majority of the configuration in the BIG-IP is located in /config and primarily is contained in the bigip.conf file. Using the steps below you can search this file for an object name, such as an expiring certificate, to quickly locate which profile it is being used in and subsequently which virtual servers are using said profile.
If using Administrative Partitions please see K13895: The BIG-IP configuration files may reside in multiple locations for additional bigip.conf locations.

  1.  Obtain the bigip.conf file from the device. An example is using a program such as WinSCP, or the file search in iHealth.
  2.  Search for the name of the certificate in question (The name that was used when the certificate was imported into the BIG-IP).
  3.  Record which profile it is attached to.
  4.  Search for that profile to find what virtual servers are using it.
Example of an SSL profile with certificate name and profile name being pointed to:

ltm profile client-ssl /Common/TEST-LOW {  <==== Profile Name
    app-service none
    cert /Common/default.crt  <==== Certificate Name
    cert-key-chain {
        default {
            cert /Common/default.crt   
            key /Common/default.key
        }
    }
    chain none
    cipher-group none
    ciphers ECDHE_ECDSA+AES-GCM:ECDHE+AES-GCM
    defaults-from /Common/clientssl
    inherit-ca-certkeychain true
    inherit-certkeychain true
    key /Common/default.key
    options { dont-insert-empty-fragments no-ssl no-tlsv1.3 no-tlsv1.1 single-dh-use no-tlsv1 }
    passphrase none
    renegotiation disabled
    secure-renegotiation request
}

Example of the above profile being used by a virtual server:

ltm virtual /Common/ssl-web {  <==== Virtual server name
    creation-time 2021-06-07:12:08:40
    destination /Common/10.0.1.140:443
    ip-protocol tcp
    last-modified-time 2021-06-08:10:20:53
    mask 255.255.255.255
    pool /Common/pool-http
    profiles {
        /Common/TEST-LOW {  <==== Profile Name
            context clientside
        }
        /Common/http-low { }
        /Common/httpcompression { }
        /Common/tcp { }
        /Common/webacceleration { }
    }
    serverssl-use-sni disabled
    source 0.0.0.0/0
    source-address-translation {
        type automap
    }
    translate-address enabled
    translate-port enabled
}
