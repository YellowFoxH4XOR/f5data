Issue

Error Message

012a0004:4: ledSet error: LopDev: sendLopCmd: Lopd status: 1 packet: action=2 obj_id=3c sub_obj=0 slot_id=<slot number> result=2 len=0 crc=<checksum> payload= (error code:0x2)

In this error message, note the following:

  • <slot number> is the blade slot number that is unpopulated on the VIPRION 2400 system.
  • <checksum> is the calculated checksum for the blade slot on the VIPRION 2400 system based on a few parameters.

For example:

012a0004:4: ledSet error: LopDev: sendLopCmd: Lopd status: 1 packet: action=2 obj_id=3c sub_obj=0 slot_id=2 result=2 len=0 crc=e071 payload= (error code:0x2)

Message Location

You may encounter this message in the following location:

  •  The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The VIPRION 2400 system has one or more blade slots that are unpopulated.
  • You run the lcdwarn command to remotely clear the LCD and the Alarm LED as described in K11094: Clearing the LCD and the Alarm LED remotely.

When running the lcdwarn command against a blade slot that is unpopulated, the chmand process times out while probing the blade and logs the described message. Although the blade slots are visually numbered 1 to 4, the chmand process refers to the blade slots as 0 to 3.

Impact

The error message is benign and does not affect traffic processing capability of the VIPRION 2400 system.

Recommended Actions
