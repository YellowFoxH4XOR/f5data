Known Issue

This is the result of a known issue. If you restore the configuration of a FirePass controller from a backup file on the Device Management > Maintenance > Backup/Restore page, the restored Network Access packet filter rules do not take effect until you restart the FirePass services or restart the FirePass controller. This issue affects global packet filter rules defined on the Network Access > Global Settings page and group packet filter rules defined on the Network Access : Resources page under the IP Group Filters tab.

F5 Product Development tracked this issue as CR100454 and it was fixed in FirePass version 6.0.3. For information about upgrading refer to the FirePass release notes.

Additionally, cumulative HF-602-6 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by restarting the FirePass services. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management > Maintenance > Restart Services page.
  3. Click the Restart Services link.
  4. Click Restart.
