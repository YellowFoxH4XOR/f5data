Description

Attempted to upload a file to the Software Management page, but it appears to silently fail.

Reviewing the request/response with browser developer tools shows a POST request is made to:

/restconf/data/openconfig-system:system/f5-image-upload:image/upload-image

A 500 response was returned with the following response body:

{ "errors": { "error": [ { "error-tag": "failed-to-execute-auth-token-validation", "error-type": "protocol" } ] } }
{ "errors": { "error": [ { "error-tag": "internal-error", "error-type": "application" } ] } }

Environment

  • F5OS-A
  • GUI Software Management page
  • File upload

Cause

These errors have been seen when there is a truncated/incomplete ISO present in /var/import/staging, or when uploading a non-ISO file via the Software Management page. For example, a .md5 file, or small file renamed with a .iso suffix as a test.

Recommended Actions

Delete any non-ISO files from /var/import/staging.

Ensure that ISO files in /var/import/staging are the correct size.

Do not attempt to delete any ISO files directly from /var/import/staging unless directed to do so by F5 Support.

Ensure that you are uploading only ISO files, and that they are the correct and expected size.

Additional Information

ISO files in /var/import/staging are made immutable once successfully uploaded and imported.

The status of image import operations can be reviewed in /var/log/sw-mgmt.debug. The contents of this log file can be cryptic, but a successful upload and import will end with an entry similar to:

INFO: sw-mgmt: priority=info msgid=0x3501000000000114 msg=Finished import of /var/export/chassis/import/iso/F5OS-A-1.7.0-8741.R2R4.iso.
