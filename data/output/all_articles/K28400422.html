Description

You want to prevent client from being directed to pool member directly due to in-page hyperlinks

Environment

  • BIG-IP LTM
  • Virtual Server with HTTP profile applied

Cause
None

Recommended Actions

By using a stream profile, you can rewrite in-page links as they are being sent to the client to point to the virtual server instead of the pool member

  1. Navigate to Local Traffic > Profiles > Other > Stream
  2. Create a new Stream profile
  3. Configure the Source value to the address you would like to rewrite  Ex. http://example.com
  4. Configure the Target value to the desired rewritten address Ex. http://example2.com
  5. Apply the Stream profile to the Virtual Server
  6. Result: In-page links to http://example.com will be replaced with links for http://example2.com

Additional Information

If you find that the stream profile isn't able to modify in-page links, you may need to add an HTTP Compression profile to enable BIG-IP to parse chunked responses
