Description

F5 introduced a new variable as an improvement filed under ID 542564 that enables bigd load monitoring.

Environment

All platforms that exercise bigd after version 12.1.0

Conditions

The new db variable is bigd.debug.timingstats and can either be set to enable or disable. Disable is the default value.

When enabled, bigd will log the following to the /var/log/bigdlog file
  • Load (0-100%) 1-minute mean
  • Load (0-100%) 5-minute mean
  • Average delay for each probe in ms
  • Number of monitor instances active for this bigd process
  • Number of active file descriptors, 30-second average, for this bigd process
  • Peak number of active file descriptors past 30 seconds, for this bigd process

Cause

Bug ID 542564: bigd detection and logging of load and overload

Recommended Actions

Review the current value of bigd.debug.timingstats using tmsh 
[root@vtest:Active:Standalone] log #  tmsh  list sys db bigd.debug.timingstats all-properties
sys db bigd.debug.timingstats {
    default-value "disable"
    scf-config "true"
    value "disable"
    value-range "disable enable"
}

Enable bigd debug timing stats feature using tmsh 
tmsh modify sys db bigd.debug.timingstats value enable

Review the new load statistics in the /var/log/bigdlog file
