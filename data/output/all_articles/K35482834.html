K35482834: Unable to add new DCD to cluster BIG-IQ VE

Support Solution
Published
2020-11-05

Source

Description

  • When attempting to add a BIG-IQ Data Collection Device (DCD) to BIG-IQ Centralized Management, the following error appears.
  • Error: BIG-IQ is unable to find this device in the Data Collection Device (DCD) cluster. To resolve this issue, check that there is network connectivity between this BIG-IQ and the DCD then verify that the BIG-IQ system’s management address and the DCD's IP address settings are correct. Correct any errors and try adding this device again.

Environment

  • BIG-IQ CM and BIG-IQ DCD
  • Adding a DCD to a BIG-IQ Cluster

Cause

The BIG-IQ DCD will show a similar message to the following in the log file:  /var/log/elasticsearch/eslognode.log

  • [<MachineID>] failed to send join request to master [{<MachineID>}{MWCi8TAMSrmlfhJo6lwjNw}{8Eu9V7NpQIqy4DXygeTUJA}{10.0.0.1}{10.0.0.1:9300}{zone=default}], reason [RemoteTransportException[[<MachineID>][10.0.0.1:9300][internal:discovery/zen/join]]; nested: IllegalArgumentException[can't add node {<MachineID>}{MWCi8TAMSrmlfhJo6lwjNw}{suhpfVB7RYqGMbAsMYfXXQ}{10.0.0.2}{10.0.0.2:9300}{zone=default}, found existing node {<MachineID>}{MWCi8TAMSrmlfhJo6lwjNw}{8Eu9V7NpQIqy4DXygeTUJA}{10.0.0.1}{10.0.0.1:9300}{zone=default} with the same id but is a different node instance]; ]

Recommended Actions
Check the general setting and connectivity to the DCD from the CM.

  1. Confirm you have configured and are using a Self-IP for the Discovery and Data Collection IP Address
  2. Test the connection to the DCD from the BIG-IQ CM via a command line:
    • telnet <DCD Self-IP> 443
    • telnet <DCD Self-IP> 22
      • If either of these fail, please check your network path from the CM to the DCD and open all necessary ports listed here:
      • K15612: Connectivity requirements for the BIG-IQ system
Once you have confirmed the above two steps, and are still getting the original error message, it could be linked to an error on the DCD itself.
Running the below command will clear the current elasticsearch database on the DCD and should allow the CM to recognize and connect to it.
  1. Log into the command line of the BIG-IQ DCD
  2. Ensure you are in a bash prompt, not a (tmos) # prompt
  3. Run the following command:
    • # rm -rf /var/config/rest/elasticsearch/data/*
  4. You should be able to associate the DCD to the CM now.
If you are still unable to add the DCD to the CM, please open a Service Request with F5 Network Support.
