K95829631: Error 01070608:0: License is not operational (expired or digital signature does not match contents)

Published

Updated
2025-04-02
Applies to
  • BIG-IP
Source

Description

Upgraded to a new version but keeps booting back to old boot volume despite using a valid license file.

Error 01070608:0: License is not operational (expired or digital signature does not match contents) ​​​​​​

Environment

  • Licensing
  • Software Upgrade

Cause

Corrupted boot volume.

 

Recommended Actions

  1. Verify that the steps for licensing the device was followed correctly - especially if you opt for the manual activation method.  
  2. If the steps are correct, and issue persist, go to Step 3.
  3. Install the software images on separate boot location, then boot the BIG-IP system to the volume. If it works, that confirms that the previous boot location is corrupted. 
  4. Contact F5 Support for assistance if the issue persist. 


Additional Information

Licensing the BIG-IP system
Booting the system to a different software image
