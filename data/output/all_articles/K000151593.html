Description

 Under iHealth diagnostics of a qkview you see 'Indicators of Compromise (IoCs) are found on the system' and when you expand 'Details', under 'Additional Information' it reads something like "ping is found". 

Environment

  •  BIG-IP
  • IHealth Diagnostics
  • Indicators of Compromise 

Cause

The way iHealth process qkview for IoCs, in this case, it found a file name that includes the word "ping", The F5 iHealth diagnostics is likely a false positive and can safely be ignored. It means, that the (local) admin should validate it. (ie; the file name was part of known local configuration.)

Recommended Actions

 If the (local) admin validated the found string to be part of a file name, which originated from known configuration, then this is a false positive and can safely be ignored.
