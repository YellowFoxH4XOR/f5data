Note: A serial terminal is configured by default for the BIG-IP IP Application Switch platform. This Solution is specifically for the BIG-IP Server Appliance.
 
Note: For BIG-IP 9.x and later, refer to K7683: Connecting a serial terminal to a BIG-IP system.

There are two ways to add a serial terminal to BIG-IP. One is to add a serial terminal in addition to the BIG-IP console; the other is to add a serial terminal in place of the BIG-IP console. The differences between the two are as follows:

  • A serial terminal that is configured as a terminal displays a simple login. With this configuration, you can log in, run commands, and edit files. You can use the serial terminal in addition to the keyboard and monitor.

  • A serial terminal that is configured as a console displays system messages and warnings, in addition to the features of a terminal. When the serial terminal is configured as a console, it replaces the keyboard and monitor.

Important: It may not be possible to use the serial terminal as a console with 2U platforms when running BIG-IP version 4.5 or BIG-IP version 4.5 PTF-01. F5 Networks Product Development assigned CR25183 to track this issue and it was resolved in BIG-IP version 4.5 PTF-02. For information about upgrading, refer to the BIG-IP Release Notes.

Configuring a serial terminal in addition to the BIG-IP console

To configure a serial terminal console for the BIG-IP, in addition to the standard console, perform the following steps:

Note: This process applies to BIG-IP and 3-DNS server appliances. Switch appliances do not have standard console ports.

  1. Before booting the BIG-IP, attach a serial device to the serial port. This ensures that BIG-IP uses the serial port as the console.

  2. Configure the serial terminal settings as follows: 
    
9600 baud

8 bits

1 stop bit

no parity

no flow control

VT100 emulation

  3. Open the /etc/ttys file and find the line that reads tty00 off.

  4. Edit the line to appear as follows:

    
# PC COM ports (tty00 is DOS COM1)

tty00 "/usr/libexec/getty pccons" vt100 in secure

  5. Save and close the /etc/ttys file.

  6. Unplug the serial cable.

    Important: If you do not allow the BIG-IP to boot up without a connection on the serial port after making the aforementioned changes, you will receive looping "Login:" messages after the system boots. Once the system has booted, you can connect a serial cable to avoid experiencing this anomaly.

  7. Reboot the BIG-IP.

Configuring a serial terminal as the BIG-IP console

There are two ways to configure a serial terminal as the BIG-IP console:

  • Unplugging devices from console ports and attaching a serial terminal (server appliances only)

  • Modifying the boot.default file (server and switch appliances)

Unplugging devices from console ports and attaching a serial terminal (server appliances only)

To configure a serial terminal as the BIG-IP console, perform the following steps:

  1. Disconnect the keyboard from the BIG-IP.

  2. Plug the serial terminal into the serial port on the BIG-IP.

    Note: By default, BIG-IP will use the keyboard as its console unless there is only a connection through the serial port and no keyboard connected. In this event, BIG-IP will use the serial port as the only console.

  3. Turn on the serial terminal.

  4. Reboot the BIG-IP.

Modifying the boot.default file (server and switch appliances)

Warning: Use caution when editing the boot.default file. Any typographical errors or extra blank lines can leave your system unbootable. Before you save the file, double-check the syntax of all statements and ensure there are no blank lines.

  1. Using a text editor, such as vi or pico, open the /etc/boot.default file and find the following entry:

    
-console auto

  2. Edit the entry to read:

    
-console com

    Important: When you make this modification, it is crucial that you do not change the tty00 off line. If you change the line to vt100 in secure, the looping login problem will remain.

  3. Save and close the /etc/boot.default file and exit the text editor.

  4. Plug the serial terminal into the serial port on the BIG-IP.

  5. Turn on the serial terminal.

  6. Reboot the BIG-IP.

Note: Reboot is only required on server appliances.
