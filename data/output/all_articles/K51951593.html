Description

GUI appears blank on login after upgrade.

The following error appears under /var/log/tomcat/catalina.out:

SEVERE: Allocate exception for servlet org.apache.jsp.tmui.accessctrl.mainmenu_jsp
java.lang.ClassFormatError: Illegal UTF8 string in constant pool in class file org/apache/jsp/tmui/accessctrl/mainmenu_jsp

Environment

  • GUI
  • After upgrade

Cause

Java class file is corrupted:

/usr/local/www/tmui/WEB-INF/classes/org/apache/jsp/tmui/accessctrl/mainmenu_jsp.class

Recommended Actions

Option 1: reinstall the software to a new boot location

Option 2: If you have working unit which is in same version

NOTE: this may not work if other software files are also corrupted
  1. Log in to the CLI/bash of non working unit.
     
  2. To remount the /usr file system in read-write mode and rename the file, type the following 3 commands in order :
    (1) mount -o remount,rw /usr
    (2) mv /usr/local/www/tmui/WEB-INF/classes/org/apache/jsp/tmui/accessctrl/mainmenu_jsp.class /usr/local/www/tmui/WEB-INF/classes/org/apache/jsp/tmui/accessctrl/mainmenu_jsp.class.bk
    (3) rm /usr/local/www/tmui/WEB-INF/classes/org/apache/jsp/tmui/accessctrl/mainmenu_jsp.class
     
  3. SCP the file (/usr/local/www/tmui/WEB-INF/classes/org/apache/jsp/tmui/accessctrl/mainmenu_jsp.class)  from working unit to non-working unit using following command:
    scp -p /usr/local/www/tmui/WEB-INF/classes/org/apache/jsp/tmui/accessctrl/mainmenu_jsp.class <username>@<non-working-unit-mgmt_ip>:/usr/local/www/tmui/WEB-INF/classes/org/apache/jsp/tmui/accessctrl/mainmenu_jsp.class
     
  4. Remount the /usr file system in read-only mode, by running following command :
    mount -o remount,ro /usr
     
  5. Restart tomcat service on non-working unit by running following command from CLI/bash :
    tmsh restart sys service tomcat
