Known Issue

This is the result of a known issue. The BIG-IP GTM system typically saves LDNS path and persistence information to the /config/gtm/ldns.gz file. On occasion, the BIG-IP GTM system incorrectly saves LDNS entries with no path or persistence records to the ldns.gz file. In addition, the BIG-IP GTM system aggressively reaps LDNS entries containing path information.

F5 Product Development tracked this issue as CR74922 and it was fixed in BIG-IP GTM 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
