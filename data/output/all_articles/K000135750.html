Description

On the GUI under Local Traffic -> Nodes -> Node List -> (select the Node) -> Statistics 
After loading for some time, will appear "Internal Server Error" with "please contact support..." and it doesn't show any data

Environment

  • BIG-IP
  • Node/pool member statistics
  • GUI

Cause

Not clear at the moment if the issue is mostly related to memory allocation to tomcat and restjavad or also a stalled statsd daemon

Recommended Actions

The Internal Server Error issue related to Node Statistics the issue seems to be a combination of memory and stalled process, the solution is the following:

K63328426: Increase memory for Tomcat and Restjavad when Out of Memory

If after increasing the memory allocation as described in the above KB article, the issue still persist, then restart the following daemons:

bigstart restart statd restnoded
