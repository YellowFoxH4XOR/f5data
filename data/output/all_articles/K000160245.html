K000160245: 413 "Payload Too Large" Error when buffer policy is disabled and Bot Defense is enabled

Applies to

Description

Users encounter a 413 "Payload Too Large" error when uploading files through an F5 Distributed Cloud HTTP Load Balancer, even after disabling the buffer policy at both the load balancer and route levels. The error typically appears as:

  • HTTP 413 Payload Too Large
  • Error message: "request_payload_too_large"
  • Uploads of files larger than 1 MB fail, while smaller files succeed

This issue occurs when Bot Defense (Bot Protection) is enabled on the load balancer or domain.

Environment

  • F5 Distributed Cloud HTTP Load Balancer
  • Load balancer with buffer policy disabled ("disabled": true, "max_request_bytes": 0)
  • Bot Defense (Bot Protection) is enabled on the entire domain or path prefix "/"
  • File uploads to endpoints such as /upload

Cause

When Bot Defense is enabled, F5 Distributed Cloud applies an internal filter that enforces a request size limit of 1,048,576 bytes (1 MB). This limit takes precedence over the buffer policy configuration and cannot be adjusted through the F5 Distributed Cloud console. As a result, uploads larger than 1 MB are rejected with a 413 error, regardless of buffer policy settings.

Answer/Recommended Actions

To resolve the 413 "Payload Too Large" error for file uploads:

  1. Exclude file upload paths from Bot Defense protection:
    • Navigate to the load balancer's Bot Defense configuration.
    • Modify the protected app endpoint(s) to exclude the file upload path (e.g., /upload).
    • If Bot Defense is required for other paths, configure it to apply only to those paths and not to file upload endpoints.
  1. Save and apply the configuration changes.
  2. Test file uploads to confirm that uploads larger than 1 MB are now successful on the excluded paths.

Note: There is currently no option in the F5 Distributed Cloud console to adjust the request size limit enforced by Bot Defense. The only solution is to exclude file upload paths from Bot Defense protection.

Additional Information

  •  The buffer policy setting ("disabled": true, "max_request_bytes": 0) alone is not sufficient to allow large uploads if Bot Defense is enabled on the upload path.
  • The 413 error is expected behavior when Bot Defense is active on a path and the upload exceeds 1 MB.
  • Disabling Bot Defense for the upload path does not affect Bot Defense protection on other paths.
