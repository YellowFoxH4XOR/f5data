Description
When inspecting the memory utilization, the SWAP memory is slowly increasing in time. 

Environment
  • BIG-IP ASM

  • top command is showing admd process is consuming most of the Swap memory:

PID   UID  Priority  Nice  Size  Resident  Shared    State    %CPU    %MEM    Runtime   CPU #  Swap    Command line
13703 root    20       0   6.7G   1.4G      28.6M    S        10.0    7.3   64:18:22.73   2    72.2M    /usr/bin/admd -d

Cause
This was identified as a Bug ID 1046469. 

Recommended Actions
Growing SWAP memory may eventually lead to Out Of Memory and restarting ADMD daemon.
At this moment there is no permanent fix, but ADMD daemon can be restart once a week to prevent out of memory situations.
Note: Restarting the ADMD daemon will not cause any traffic impact

Workaround
To workaround the issue, ADMD could be restart manually - it will avoid reaching Out Of Memory which might affect other daemons.
Note: This will not affect active traffic processing
# bigstart restart admd

Additional Information

Bug ID 1046469: Memory leak during large attack
