Known Issue

F5 BIG-IP Carrier-Grade NAT (CGNAT) may fail to hairpin subscriber traffic.

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP CGNAT virtual server configured with a FastL4 profile.
  • You have a Large Scale NAT (LSN) pool configured with Hairpin Mode set to Enabled.
  • The BIG-IP CGNAT virtual server processes a connection between two subscribers.

Impact

Traffic between subscribers, using the affected BIG-IP CGNAT virtual server, fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You notice that traffic between subscribers using the affected BIG-IP CGNAT virtual server is failing.

Workaround

If upgrading is not an immediate option, you may be able to work around the issue by configuring the affected BIG-IP CGNAT virtual server to use a profile other than the FastL4 profile.

Impact of workaround: The impact of this workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
