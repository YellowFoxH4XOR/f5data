K000133691: iRule error: <HTTP_REQUEST> - ERR_BOUNDS (line x) invoked from within "HTTP::path -normalized"

Type
Support Solution
Published
2023-04-27
Updated
2023-04-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000133691

Description

You get an error similar to the following for a certain URL path, especially in case the URL path is long and contains URL-encoded characters.

err tmm2[xxxxx]: 01220001:3: TCL error: /Common/<virtual server name> - ERR_BOUNDS (line 1) invoked from within "HTTP::path -normalized"

 

Environment

You are using an iRule HTTP::path command with the -normalized option.

e.g.

when HTTP_REQUEST {

  set PATH [string tolower [URI::decode [HTTP::path -normalized]]]

  ...

}

 

Cause

The iRule HTTP::path command with the -normalized option can only accept up to 255 escape characters (such as \' and \") at most. When the number of escape characters exceed 255, you get an error similar to the above and the connection gets reset.

 

Recommended Actions

Limit the number of escape characters contained in the HTTP path to 255 or fewer.
