Known Issue

This is the result of a known issue. If you create a health monitor to check a specific port, assign that monitor to a server object with a wildcard virtual server, and then restart the system, the BIG-IP GTM configuration may be missing from the Configuration utility. When this behavior occurs, the BIG-IP GTM system sends incoming DNS requests to BIND.

F5 Product Development tracked this issue as CR66510 and it was fixed in BIG-IP GTM 9.4.0. For information about upgrading, refer to the BIG-IP GTM Release Notes.

Workaround

To work around this issue, perform the following procedure:

  1. Log in to the command line.
  2. Change directories to the /config/gtm/ directory by typing the following command:

    cd /config/gtm/
  3. Make a backup of the wideip.conf file by typing the following command:

    cp wideip.conf wideip.conf.original
  4. Use a text editor to edit the /config/gtm/wideip.conf file.
  5. Remove the monitor entry from the wideip.conf file and save the changes.
  6. To verify that there are no syntax errors in the wideip.conf file, type the following command:

    gtmparse -1
  7. Load the corrected wideip.conf file by typing the following command:

    gtmload
