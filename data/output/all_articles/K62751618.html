Description

After a programmed or unexpected reboot, the BIG-IP no longer recognizes the HDD. You will see the following error message when the BIG-IP tries to boot:

Version 2.15.1236. Copyright (C) 2012 American Megatrends, Inc. [2;1HF5 Platform: D110 OBJ-0482-xx BIOS (Build: 2.07.215.0) Date: 10/14/2015
Press <c> to enter setup.
Press <e> to launch F5 Disk Erase Utility.

No valid boot device found.
Insert a boot device and press any key to reboot.

Environment

  • BIG-IP 7250V
  • Booting up after an upgrade process or reboot.

Cause

  • A BIG-IP device is unable to find a bootable partition on the HDD
  • The HDD on a BIG-IP device is not functioning or not reachable
  • Some other hardware failure is interrupting communication with the HDD

Recommended Actions

Install and run the End-User Diagnostics (EUD) utility to determine the state of the hard disks for your device. To do so, perform all of the following tasks:

  1. Refer to the documentation for information about installing and running the EUD:  
    • For  BIG-IP 2000, 4000, 5000, 7000, 10000, 12000, and BIG-IQ 7000 Series: 
      • Field Testing BIG-IP and BIG-IQ Hardware
  2. Follow Loading the EUD onto a USB flash drive procedure using the EUD manual that is appropriate to your device.
  3. After running the EUD utility, contact F5 Technical Support and submit the resulting EUD output report.

If you see the following lines after the EUD ends an HDD or full appliance RMA may be needed.
