Description

  • Explains how to generate a valid Transaction Signature Key (TSIG) based on the Primary DNS key name.

Environment

  • F5® Distributed Cloud DNS

Procedure

The steps to accomplish topics outlined in Description.

  1. Start a Linux terminal - What are Linux terminals?
  2. Run the command 
    sudo apt install bind9  # For Debian/Ubuntu
    sudo yum install bind-utils # For CentOS/RHEL

      3. Run the command 

tsig-keygen -a <HMAC Function> <Your server key name>

      4. Use the secret value from the response in the F5 Distributed Cloud Portal to set the TSIG.

key "<Your server key name>" {
algorithm hmac-md5;
secret "<Generated secret value>";
};
