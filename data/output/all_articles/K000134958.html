K000134958: How to gather information about Request and Response sizes for an HTTP application through the BIG-IP

Source

Description

Sometimes it is desired to try to understand the nature of HTTP traffic processed by the BIG-IP.  This can include but is not limited to such information like HTTP request sizes, HTTP response sizes, typical headers, relative busyness of different virtual servers, and HTTP response codes.  Leveraging the HTTP Analytics profile, this information can be quickly and efficiently gathered for review and use.  Possible BIG-IP-related use-cases include determining which application responds with large responses or which URIs have large client requests.

Environment

  • HTTP-based application that is served through the BIG-IP via a Standard-type virtual server
  • BIG-IP with AVR provisioned

Cause

None.

Recommended Actions

The HTTP Analytics profile can collect statistics and requests if Traffic Capturing Logging is enabled.  Perform the following steps to be able to collect and view relevant statistics on the HTTP traffic desired.

  1. Create an HTTP Analytics profile from Local Traffic  ››  Profiles : Analytics : HTTP Analytics  
  2. Enable Statistics Logging Type: Internal.
  3. Enable Traffic Capturing Logging Type: Internal
  4. Optional: Select any options for Capture Request Details and Capture Response Details to be able to view those as well.
  5. Update/Save the profile.
  6. Apply the HTTP Analytics profile to the virtual servers you wish to gather information about.

Some important notes:
  1. The captured traffic will be viewable in System  ››  Logs : Captured Transactions
  2. There is a non-configurable maximum limit of 1000 transactions that can be logged before the Analytics profile will stop capturing traffic.  
  3. To capture more traffic after the limit is reached, the existing logs must be cleared which will clear all captured logs.
  4. To limit and narrow the focus on specific parameters like only requests larger than a certain size, optional settings can be configured in the HTTP Analytics profile's Capture Filter settings at the bottom of the profile configuration screen.
  5. To view the details about a transaction, click on the transaction entry in the list.  The details will be shown below the entire list of transactions at the bottom of the page.
