Known Issue

An error occurs when you create a virtual server that references a Request Logging profile and an HTTP profile with Proxy Mode set to Transparent.

This issue occurs when the following condition is met:

  • You attempt to create a virtual server that references a Request Logging profile and an HTTP profile with Proxy Mode set to Transparent.

Impact

Users are unable to create a virtual server with a Request Logging profile and a Transparent HTTP profile.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You receive an error message similar to the following example when you attempt to create a virtual server that has a Request Logging profile and a Transparent HTTP profile:

    01070734:3: Configuration error: In Virtual Server (/Common/example_virtual) HTTP is configured as a Transparent Proxy, and thus is incompatible with any other filter other than PEM.
