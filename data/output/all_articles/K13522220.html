Topic

You should consider using this procedure under the following condition:

  • You want to test a health monitor before applying it to a pool, a pool member, or a node.

Description

The BIG-IP LTM system offers a health monitor test feature for verifying monitor settings on a given target host. After a health monitor is configured, you can test the monitor using the test button before assigning it to a pool, a pool member, or a node. All BIG-IP LTM health monitors are compatible with the monitor test button feature, except for the following monitor types:

  • inband
  • module-score
  • radius-accounting
  • real-server
  • sasp
  • snmp-dca-base
  • snmp-dca
  • virtual-location
  • wmi

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP Configuration utility.
  • You have a configured health monitor that is not assigned to a pool, pool member, or node.

Procedures

Testing a health monitor on a target host

To test a health monitor before assigning it to a pool, a pool member, or a node, perform the following procedure:

Note: If you attempt to run a monitor test on an assigned monitor, the system displays a message similar to the following example:

01020037:3: The requested monitor instance (/Common/http 10.117.20.130 80 ltm-pool-member) already exists.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Monitors.
  3. Select the name of the monitor you want to test.
  4. Select the Test tab.
  5. For Address, type the IP address and port number of the destination host.

    Note: Address is a required field and you must fill it in before the system can initialize the test. The field is pre-populated if the health monitor has a configured alias address or service port.

  6. Select Test.
  7. Verify the test result.

    For example, the following output test result shows a monitor in an up state:

    ---------------------------
     LTM::Monitor /Common/http 
    ---------------------------
     Monitor Test Result:
       Destination:  165.160.15.20:80
       Last state:   up
       State time:   2019.01.10 14:09:33 (0hr:0min:2sec ago)
       Last result:  Test Completed (UP)
                     See /var/log/monitors/Common_http-Common_monitor_test-80.log

  8. Optionally, review the monitor logging in the /var/log/monitors/ directory for further verification.

    Note: For more information about monitor logging, refer to K12531: Troubleshooting health monitors.
