Issue

If certain registry settings on a Windows client become damaged, a Network Access or Application Access favorite may fail to connect with an error message that appears similar to the following:

Error getting PropertyBag interface

To determine whether the Windows registry settings are damaged on a Windows client system, and for instructions on how to restore these settings, refer to the following Microsoft KB article 824923. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://support.microsoft.com/kb/824923

Note: The Microsoft article is written for Windows XP 32 bit and Windows Server 2003 32 bit systems.

Note: For 64 bit versions of the Windows operating systems, substitute sysWOW64 for system32 in the Microsoft KB article.

If this issue persists after checking the Windows registry, contact F5 Technical Support for additional assistance.
