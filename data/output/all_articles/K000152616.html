Description

In F5OS-A, you find out-of-memory (OOM) logs similar to the following logged in /var/log/messages:

 

2025-04-16T21:04:38 bigip1 kernel: virt-operator invoked oom-killer: gfp_mask=0x201da, order=0, oom_score_adj=1000

- snip -

2025-04-16T21:04:38 bigip1 kernel: [ pid ]  uid tgid total_vm   rss nr_ptes swapents oom_score_adj name

- snip -

2025-04-16T21:04:38 bigip1 kernel: [12795]   0 12795 2556244 1925040  3840    0       0 l2_agent

 

l2_agent has a large "rss" value (1925040). Multiply this by 4096 (4KB), 1925040 x 4096 = 7.3GB, you find l2_agent having an unexpectedly large memory usage.

 

If OOM occurs frequently, F5OS-A GUI may appear slow/unresponsive.

Environment

  • F5OS-A 1.8.0
  • F5OS-C 1.8.0

Cause

Bug ID 1890297

Recommended Actions

Follow the workaround of Bug ID 1890297.
