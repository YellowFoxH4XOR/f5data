Known Issue

The BIG-IP system may deny access to the /var/log/sa6 and /var/log/sa6/sa directories.

This issue occurs when any of the following conditions are met:

  • A non-root user attempts to write to, or create a file in, the /var/log/sa6 or /var/log/sa6/sa directories.
  • A non-root process (such as SMTP or Mail) attempts to write to, or create a file in, the /var/log/sa6 or /var/log/sa6/sa directories.

Impact

Write actions fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the permissions of the /var/log/sa6 and /var/log/sa directories, the permissions are set to -rw-r--r-- (0644).
  • When non-root users or processes attempt to create or write to the /var/log/sa6 or /var/log/sa6/sa directories, the system produces an error message similar to the following examples:

    Cannot open /var/log/sa6: Permission denied

    Cannot open /var/log/sa6/sa: Permission denied

Workaround

To work around this issue, you can modify the permissions of the /var/log/sa6 and /var/log/sa directories. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected system.
  2. As a root user, type the following command:

    chmod 755 /var/log/sa6 /var/log/sa6/sa
