Known Issue

The mcpd process may restart when a wide IP, pool, or prober pool object is created and modified in a single batch mode transaction.

This issue occurs when all of the following conditions are met:

  • You have licensed and provisioned the BIG-IP GTM module.
  • You attempt to create and modify a wide IP, pool, or prober pool object in a single batch mode transaction.

Impact

The BIG-IP system may temporarily fail to process traffic and fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates an mcpd core file to the /shared/core directory.
  • A failover may occur if the system is configured for high availability (HA).
