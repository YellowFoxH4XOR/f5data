Known Issue

This is the result of a known issue. The BIG-IP ASM InnoDB MySQL database may exceed the capacity of the /var file system.

F5 Product Development tracked this issue as CR124002 and it was fixed in BIG-IP ASM version 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue was fixed in BIGIP-10.0.1-378.0-HF3 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing 10.x hotfixes on a Logical Volume Management (LVM) disk-formatted system, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about installing 10.x hotfixes on a partitioned system, refer to K9819: Installing a BIG-IP version 10.x hotfix on a partitioned system.
