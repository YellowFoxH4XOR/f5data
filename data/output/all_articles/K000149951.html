Description

This article describes about how to obtain audit logging for changes made on ZoneRunner.

Environment

  • BIG-IP DNS
  • ZoneRunner

Cause

By default, add or delete event of resource records is not logged.

ZoneRunner log level is notice which does not record those add or delete event, while those events are at info level.

Recommended Actions

If you want to obtain the add or delete event log, you may set BigDB key log.zrd.level value to info following, so that those event log is written down to /var/log/gtm file.

Impact of procedure: Changing the ZoneRunner log level info will increase the size of log file.

# tmsh modify sys db log.zrd.level value info
