Description
When customizing text in any configuration object of an Access Policy with modern customization, text tags in HTML will not be reflected such as a break line with <br>.
This type of change can be possible by modifying the text in Java Script.

Environment

  • Modern Customization
  • APM Access Policy

Cause

Works as designed.

Recommended Actions

In Customization Settings, go to Access Profiles >> [Select the Access Profile in question] >> Access Policy >> [Select the appropiate category]>> [Select the module] and select the .js page to make the modifications using java script. 

Additional Information

An example of how to insert a break line between "Secure logon" and "for F5 Networks"  in the logon page is the one below. You will need to insert it in 'user-logon.js':

In Customization Settings, go to  Access Profiles >> <Select the Access Profile in question> >> Access Policy >> Logon Pages >> Logon Page and select 'user-logon.js and create the modification

Please Note: You will have to also update the text value in the "Customization : General" section, for the corresponding text value to be replaced with 2 spaces. If you do not apply this, you may experience an issue where the default text value is appended to your custom string when the screen is updated/refreshed.
