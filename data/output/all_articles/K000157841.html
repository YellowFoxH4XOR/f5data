K000157841: unzip command is not found in version 21.0.0

Type
Support Solution
Published
2025-11-23
Updated
2025-11-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 21.0.0
Source
https://my.f5.com/manage/s/article/K000157841

Description

After upgrading to version 21.0.0, you are unable to unzip files. You are trying to unzip IP geolocation database but unable to do so with below error message.

-bash: unzip: command not found

Environment

  • LTM
  • IP geolocation database
  • Upgraded to version 21.0.0

Cause

ID2143141

Recommended Actions

As per BIG-IP 21.0.0 Fixes and Known Issues (under known issues section), the unzip package is removed. The BUG ID is 2143141.

As an alternative you try to unzip the files in your computer and then transfer those extracted files to the BIG-IP and install them. You could follow from step 6 of Installing the geolocation database update of this Downloading and installing updates to the IP geolocation database article.

Additional Information

None
