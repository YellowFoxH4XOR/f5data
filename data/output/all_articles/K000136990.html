Description

The newly created Virtual server does not load balance UDP packets between pool members.

For example: when creating UDP VIP to handle syslog packets sent to backend SPLUNK servers

 

Environment

  • BIGIP LTM
  • UDP logging server

 

Cause

After creating the UDP profile the following configuration needs to be changed from the default value:

 

list ltm profile udp myudp all-properties

 

ltm profile udp myudp {

  allow-no-payload disabled

  app-service none

  buffer-max-bytes 655350

  buffer-max-packets 0

  datagram-load-balancing disabled ---> change to enable

  defaults-from none

  description none

  idle-timeout 60

  ip-df-mode pmtu

  ip-tos-to-client 0

  ip-ttl-mode proxy

  ip-ttl-v4 255

  ip-ttl-v6 64

  link-qos-to-client 0

  no-checksum disabled

  partition Common

  proxy-mss disabled

}

 

Recommended Actions

Modify UDP profile configuration so it can support datagram-load-balancing feature

tmsh modify ltm profile udp <udp_profile_name> datagram-load-balancing enabled
