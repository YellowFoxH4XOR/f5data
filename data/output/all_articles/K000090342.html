K000090342: NGINX Controller with 'Disconnected' license type shows 'No license found' error

Type
Support Solution
Published
2023-03-20
Updated
2023-03-20
Source
https://my.f5.com/manage/s/article/K000090342
Description:
The NGINX Controller with 'Disconnected' license type encounters a license issue after a period of time throwing the error 'No license found' in the GUI.

Environment:
  • NGINX Controller uses 'Disconnected' license type

Cause:
  • The secrets-svc pod is not running properly

Recommended Actions:
  • Check if all pods are running properly using the following command:

    kubectl get pod
 
  • If the secrets-svc pod is not running properly (e.g. in CrashLoopBackOff status), proceed with deleting the pod so that it gets re-created

    kubectl delete pod -l app=secrets-svc
 
  • If the issue continued to persist, create a ticket with support for further investigation and provide a support package using the following command:

    /opt/nginx-controller/helper.sh supportpkg
