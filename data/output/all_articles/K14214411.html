Description
BIG-IP systems may experience high CPU utilization due to TCP keepalive timers of zombie connections.

Environment

  • BIG-IP LTM
  • Virtual servers for TCP connections.

Cause
This is caused by ID 915281.

Recommended Actions

Customers need to upgrade to a software version with fix to ID 915281 to have this issue fixed.

Additional Information
None.
