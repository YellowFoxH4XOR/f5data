Known Issue

This is the result of a known issue. When configuring an Authorization Profile to use SSL Client Certificate LDAP, the profile does not allow the User Base DN or the Certificate Map Base DN to be left blank.

This functionality should be allowed. If no User Base DN or Certificate Map Base DN is specified, a default search beginning at the root of the tree would ensue; instead, the search defaults to a specific branch of the tree specified by the Distinguished Name (DN) when the fields are left blank.

F5 Product Development tracked this issue as CR70296, CR70298, CR69277, and CR68992 and it was fixed in BIG-IP LTM 9.1.3, 9.2.4, 9.3, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM release notes.
