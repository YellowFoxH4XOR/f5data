Known Issue

The restjavad process may run out of memory after a large number of iControl REST authentication token requests.

This issue occurs when one of the following conditions are met:

  • You have made a large number of authentication queries to a BIG-IP system using the iControl REST application programming interface (API).
  • You have configured the BIG-IP system for vCMP and have deployed at least one guest.

    Note: On a vCMP guest, guestagentd generates an authentication token every 90 seconds for hostagentd on the vCMP hypervisor.

Impact

The iControl REST API fails to accept queries.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your iControl REST client query fails and receives a Bad Gateway error message.
  • In the /var/log/restjavad.0.log file, you may observe error messages that appear similar to the following example:

    "errorStack":["java.lang.Exception: java.lang.OutOfMemoryError: Java heap space","at com.f5.rest.common.RestOperation.fail

Workaround

To work around this issue, you can restart restjavad after approximately 10,000 authentication tokens. On vCMP systems, you can disable authentication token generation. To do so, perform one of the following procedures:

Restarting restjavad on the BIG-IP system

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the restjavad process, type the following command:

    restart sys service restjavad

Disable authentication token generation

Impact of workaround: Performing the following procedure will disable the vCMP host's ability to gather guest statistics using the tmsh show vcmp health command.

  1. Log in to the command line of the vCMP host system.
  2. To enter the Traffic Management Shell (tmsh), type the following command:

    tmsh

  3. To disable authentication token generation, type the following command:

    modify vcmp guest all capabilities add { stats-isolated-mode }

  4. To restart the hostagentd process, type the following command:

    restart sys service hostagentd
