Security Advisory Description

Out-of-bounds Read vulnerability in Apache HTTP Server with mod_headers and mod_mime and multiple response languages. This issue affects Apache HTTP Server: from 2.4.0 through 2.4.67. (CVE-2026-43951)

Impact

There is no impact; F5 products are not affected by this vulnerability.

Security Advisory Status

F5 Product Development has evaluated the currently supported releases for potential vulnerability, and no F5 products were found to be vulnerable.

Note: F5 previously reported F5OS as vulnerable to CVE-2026-43951. Further research has allowed us to re-evaluate these products as not vulnerable to this CVE.

Security Advisory Recommended Actions

None
