Topic

You should consider using this procedure under the following conditions:

  • You want to clear the historical data used by the BIG-IP dashboard utility.
  • Your BIG-IP dashboard utility data becomes corrupted.

Description

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have administrative access to the Configuration utility and command line.

Procedures

Clearing RRD data files used by the BIG-IP dashboard utility

The BIG-IP dashboard utility information populates through the Round Robin Database tool (RRDtool) data files. To clear the historical data used by the dashboard utility, you can remove the supporting RRD data files.

Impact of procedure: The data time frame presented by the dashboard utility will commence after the procedure is completes and the statsd process starts. All previous historical data is no longer available for reference by the BIG-IP dashboard.

  1. Log on to the command line of the affected device.
  2. Verify that the BIG-IP LTM system is connected to a working network time protocol (NTP) server by typing the following command.

    ntpq -np

    and check for an asterisk (*) to the left of the one of the entries.

    Note: If the BIG-IP system does not have access to a working NTP server, resolve NTP connectivity before continuing.

  3. Stop the statsd service by typing the following command:

    tmsh stop /sys service statsd

  4. Create a backup directory to copy the current RRD data files by typing the following command:

    mkdir -p /shared/rrd.backup

  5. Copy existing RRD files to the backup directory by typing the following command:

    cp -rp  /shared/rrd.1.2*  /shared/rrd.backup/

  6. Delete the current RRD data files by typing the following command. 

    rm -rf  /shared/rrd.1.2/*
    rm -rf  /shared/rrd.1.2.perm/*

    Important: All RRD statistic data will be deleted.

  7. Restart the statsd service by typing the following command:

    tmsh start /sys service statsd

  8. Verify that the RRD files repopulated to the /var/rrd directory by typing the following command:

    ls -lR /var/rrd /shared/rrd.1.2*

    Note: The  /var/rrd directory is a symbolic link to the /shared/rrd.1.2 directory.

  9. Log on to the Configuration utility.
  10. Navigate to Statistics > Dashboard.
  11. Verify that the data includes the accurate time period from after clearing the RRD file data.

    Note: Depending on the volume of traffic processed by the BIG-IP system, statistics may take several minutes to display.
