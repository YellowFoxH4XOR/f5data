Known Issue

The BIG-IP APM system may not display access profile customized logout pages.

This issue occurs when all of the following conditions are met:

  • You have customize the access profile logout page.
  • Your access policy is configured for authentication.
  • The user fails to authenticate.

Impact

The system displays the default logout page to the user.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When users fail authentication, your BIG-IP APM system displays the default logout page.
  • When user sessions are terminated, the system displays the access policy customized logout page.
