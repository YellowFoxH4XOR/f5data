K35797201: ERR_HTTP2_SERVER_REFUSED_STREAM on Chrome 80 if using HTTP/2 profile

Type
Support Solution
Published
2020-02-18
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 12.1.2
Source
https://my.f5.com/manage/s/article/K35797201

Description

Connection is reset or fails when using Chrome version 80, with ERR_HTTP2_SERVER_REFUSED_STREAM.

Environment

  • HTTP2 profile
  • Chrome 80

Cause

Bug ID 677119: HTTP2 implementation incorrectly treats SETTINGS_MAX_HEADER_LIST_SIZE

Recommended Actions

Upgrade to a version where bug ID 677119 is fixed.

Additional Information

None
