Description
Network access is configured with Exclude IP of Skype or VOIP device but still see some of the excluded traffic passing through the tunnel.
ACLs applied too do not work as expected.

Environment

  • Network access
  • Any VOIP device using STUN Protocol
Cause

The applications running on STUN protocol indicate that this try to bind explicitly to every interface that is available and hence some UDP(STUN) binding requests will go through the tunnel.

Recommended Actions

Either of the following options could be used to prevent STUN traffic using the VPN tunnel:
  • A firewall following the APM can block the port and IP 
  • ACLs set in the Access Policy Resource Assign to deny (this would also allow for some logging information on the Big IP)
