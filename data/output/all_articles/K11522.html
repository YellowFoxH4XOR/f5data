Known Issue

This is the result of a known issue. The != comparison operator does not work correctly for inspecting a user's registry in access policies for both client side actions and client side checks. If the != comparison operator is used in an expression, you will receive a syntax error message.

Note: The != comparison operator represents not equal to.

F5 Product Development is tracking this issue as ID 226699 (formerly CR141999).
