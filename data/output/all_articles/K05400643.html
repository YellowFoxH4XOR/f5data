Description

  • Not able to Apply ASM security Policy with error:

    Apply Policy Configuration Set active failed

  • Applying changes to ASM security policy results in  error "operation failed", and the security policy cannot be applied properly.
  • The following error messages can be seen on /var/log/asm:

Environment

  • ASM provisioned along with other modules
  • Complex policy

Cause

The seen behavior is the result of lack of host memory (memory pressure), the host memory/TMM provisioning is not ideal.

Recommended Actions

The solution is provisioning tweaking to release some TMM memory so that Host has more available memory.

Note: Before modifying, provisioning, or adding more memory to an existing Management (MGMT) setting, review the available and utilized memory of the BIG-IP system.
K16419: Overview of BIG-IP memory usage, K26427018: Overview of Management provisioning


Impact: The BIG-IP system experiences a temporary traffic interruption as it recovers from the TMM restart, and devices configured as a high-availability (HA) pair may fail over. F5 recommends changing the Management memory size allocation during a scheduled maintenance window.
  1. Connect to the Bash CLI of the affected device.
  2. Add an additional amount of Memory to the management plane with the below syntax: tmsh modify sys db provision.extramb value <amount in MB to add>
  3. Save the configuration change by entering the following command: tmsh save sys config partitions all
