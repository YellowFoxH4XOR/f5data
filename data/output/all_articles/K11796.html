Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K13876: Overview of the Auto Last Hop setting (11.x)

Auto Last Hop is a global setting that is used to track the source MAC address of incoming connections. When enabled, Auto Last Hop allows the BIG-IP system to send return traffic from pools to the MAC address that transmitted the request, even if the routing table points to a different network or interface. As a result, the BIG-IP system can send return traffic to clients even when there is no matching route. For example, if the BIG-IP system does not have a default route configured and the client is located on a remote network. Additionally, Auto Last Hop is useful when the BIG-IP system is load balancing transparent devices that do not modify the source IP address of the packet. Without the last hop option enabled, the BIG-IP system could return connections to a different transparent node, resulting in asymmetric routing.

For most network configurations, Auto Last Hop is a desired behavior and so it is enabled by default. F5 strongly recommends leaving the Auto Last Hop setting enabled unless you have a specific reason for disabling it. For some network configurations, Auto Last Hop is not the desired behavior. For example, if you want the BIG-IP system to use the routing table to determine the next hop for return traffic, Auto Last Hop must be disabled. Additionally, Auto Last Hop may not function properly in environments where the last hop MAC address can change.

Note: If the last hop is a set of redundant routers or firewalls that do not use a shared MAC address, you can configure a last hop pool for the virtual server instead of disabling Auto Last Hop. For more information, refer to K2211: Using last hop pools to correctly return traffic to upstream redundant devices.

Note: For information about BIG-IP compatibility with VRRP and HSRP, refer to K9487: BIG-IP support for neighboring VRRP/HSRP routers.

Enabling the Auto Last Hop setting

The Auto Last Hop setting is enabled by default. If Auto Last Hop is currently disabled, you can re-enable it by performing one of the following three procedures:

Using tmsh (BIG-IP versions 10.0.0 and later)

  1. Log in to the command line.
  2. Type the following command:

    tmsh modify /ltm global-settings connection auto-last-hop enabled

Using the bigpipe command (BIG-IP versions 9.4.2 through 10.2.4)

  1. Log in to the command line.
  2. Type the following command:

    bigpipe ltm auto last hop enable

Using the Configuration utility

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click Configuration or General Properties, depending on the version of BIG-IP software.
  4. From the Local Traffic menu, select General.
  5. Select the Auto Last Hop check box.
  6. Click Update.

 

Disabling the Auto Last Hop setting

To disable the Auto Last Hop setting, perform one of the following three procedures:

Important: F5 strongly recommends leaving the Auto Last Hop setting enabled unless you have a specific reason to disable it.

Using tmsh (BIG-IP versions 10.0.0 and later)

  1. Log in to the command line.
  2. Type the following command:

    tmsh modify /ltm global-settings connection auto-last-hop disabled

Using the bigpipe command (BIG-IP versions 9.4.2 through 10.2.4)

  1. Log in to the command line.
  2. Type the following command:

    bigpipe ltm auto last hop disable

Using the Configuration utility

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click Configuration or General Properties, depending on the version of BIG-IP software.
  4. From the Local Traffic menu, select General.
  5. Clear the Auto Last Hop check box.
  6. Click Update.
