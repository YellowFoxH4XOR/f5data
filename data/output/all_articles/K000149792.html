Description

AAA authentication breaks after changing an APM AAA object password.

 

 

Environment

BIG-IP with APM

  • Active Directory or LDAP "Admin Password"
  • Radius, TACACS+ "Secret"

 

Cause

DB variable "security.configpassword" was changed to a non-default value (default is "<null>"). This is expected behavior.

 

 

Recommended Actions

Change the DB variable "security.configpassword" back to "<null>" before making the password change. If the password has already been changed, change it again.

tmsh modify sys db security.configpassword value "<null>"
