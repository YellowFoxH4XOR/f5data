Description

Need to establish HA between two BIG-IP devices, but one of them shows Disconnected state as it was in HA previously.

Environment

  • HA
  • ConfigSync
  • Device Trust

Cause

One device still belongs to a previously established trust domain.

Recommended Actions

  1. On both devices, reset the trust domain by navigating to Device Management >> Device Trust >> Reset Device Trust, then select Generate New Self-Signed Authority, and click Update.

  2. Ensure that both devices have Failover and ConfigSync IPs defined Under Device Management >> Devices

    K14135: Defining network resources for BIG-IP HA features
  3. Establish trust between the two devices by navigating to Device Management >> Device Trust >> Device Trust Members >> Add

  4. Proceed to add a trusted peer using the management IP and Administrator credentials of the peer

    Important: Ensure that both devices meet the requirements for a redundant pair:

    K8665: BIG-IP redundant configuration hardware and software parity requirements

  5. Once trust is established, create a sync-failover device group under Device Management >> Device Groups, add both devices to it
  6. Sync the configuration
  7. Devices should now be In Sync and Active/Standby
