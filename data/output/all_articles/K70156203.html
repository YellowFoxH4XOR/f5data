Description
This article provides the steps for configuring a static IPv6 NDP entry (equivalent to IPv4 static ARP entry) for mapping IPv6 IP address into MAC address.

Environment

  • BIG-IP
  • IPv6

Cause
None

Recommended Actions

Adding a static IPv6 NDP table entry using the Configuration utility

  1. Log in to the BIG-IP Configuration utility.
  2. If required, change to the relevant Administrative Partition.
  3. Click Network.
  4. Click ARP.
  5. Click Create.
  6. In the Name box, type a name for the IPv6 NDP mapping configuration object.
  7. In the IP Address box, type the IPv6 address of the host for which you are creating an NDP entry.
  8. In the MAC Address box, type the MAC address associated with the IP address.
  9. Click Finished.

Adding a static IPv6 NDP table entry using the tmsh utility

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. If required, change the partition to the relevant administrative partition using the following command syntax:

    cd /<partition name>

    For example:

    cd /partitionA

  3. Create a static IPv6 NDP entry using the following command syntax:

    create net ndp <name> ip-address <IPv6 address> mac-address <MAC address>

    For example, to create a static NDP entry named myNdp for IP address fec0:f515::c001 with a MAC address of 00:0B:DB:3F:F6:57, type the following command:

    create ndp myNdp ip-address fec0:f515::c001 mac-address 00:0B:DB:3F:F6:57
    To verify that the static ARP entry was created, as expected, type the following command:

    show net ndp static

    The entry appears in the IPv6 NDP table similar to the following example:

    ------------------------------------------------------------

    Net::Ndp 

    Name                                    Address                           HWaddress

    ------------------------------------------------------------

    /partitionA/myNdp         fec0:f515::c001            00:0B:DB:3F:F6:57

  4. If you want the IPv6 NDP entry to persist a system reboot, you must save the configuration. To do so, type the following command:

    save /sys config
