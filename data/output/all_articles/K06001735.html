Issue

Error Message

info mcpd[<PID>]: 01071aff:6 AOM webui is not available in this release.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.

For example:

info mcpd[12663]: 01071aff:6 AOM webui is not available in this release.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions is met:

  • You type following TMOS Shell (tmsh) command: modify sys aom webui enabled.
  • You type the following tmsh command: modify sys aom webui disabled.

Impact

None. The AOM web services are not supported in this release of BIG-IP software. Typing the tmsh command doesn't do anything.

Recommended Actions

None
