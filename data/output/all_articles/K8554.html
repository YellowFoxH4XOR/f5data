K8554: FirePass uses anonymous credentials to retrieve Citrix MetaFrame Portal published application list

Issue

In FirePass 6.0.2, when a user selects a Citrix MetaFrame Portal Terminal Server favorite, FirePass contacts the Citrix master browser using anonymous credentials to obtain a list of published applications. If successful, FirePass displays a link for each retrieved application on the webtop, and the user is prompted for Citrix credentials after selecting one of the application links. If unsuccessful, FirePass prompts the user for Citrix credentials in order to obtain a list of published applications from the Citrix master browser.

Important: This change in behavior may not be compatible with all Citrix configurations. For more information, refer to K8555: Users cannot execute certain Citrix MetaFrame Portal applications from the webtop.

In previous versions of FirePass software, when a user selected a Citrix MetaFrame Portal Terminal Server favorite, FirePass prompted the user for Citrix credentials before obtaining an application list. FirePass contacted the Citrix master browser using the supplied user credentials and obtained a list of applications configured for the specified Citrix user account. 

F5 Product Development tracked this enhancement as CR79339. For information about upgrading, refer to the FirePass Release Notes.

Starting in FirePass 6.0.2 with Cumulative Hotfix HF-602-2 and in FirePass 6.0.3, a Use anonymous credentials to retrieve application list from Citrix servers check box is available on the Application Access: Terminal Servers: Master Group Settings page. This check box enables or disables the new behavior described in this article. For more information, refer to K8555: Users cannot execute certain Citrix MetaFrame Portal applications from the webtop.
