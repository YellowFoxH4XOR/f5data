K24402524: No related zone record created when creating wildcard WideIP

Type
Support Solution
Published
2022-06-16
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP GTM
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K24402524

Description

Normally, when a Wide-IP is created with a pool associated with pool member, the related zone and record will also be created automatically. but for wildcard WideIP, you may not find the related zone and record created as expected.

Environment

  • BIG-IP DNS
  • WideIP
  • Resource Record
  • ZoneRunner.

Cause

Wildcard WideIP needs additional settings to make this work.

Recommended Actions

1. Login the configuration utility and go to the tab below:
DNS>> Settings>>GSLB>>General
2. Tick the option below under gslb
Create Wildcard Wide IP DNS Records
