K000157900: An error occurred while adding the BIG-IQ: Timed out waiting for secondary to report system started

Support Solution

2025-11-23
Updated
2025-11-23
Applies to

  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000157900

Description

  • You are setting up auto failover BIG-IQ HA with Quorum DCD and management floating IP address.
  • When you create it, after sometime you get either of below error message.

    An error occurred while adding the BIG-IQ: Timed out waiting for secondary to report system started

    or

    An error occurred while adding the BIG-IQ: DNS connectivity check failed on device <Peer CM or DCD's IP address>

  • When you close the error message, you see HA is formed but you do not see the quorum DCD nor management floating IP address.

Environment

  • BIG-IQ
  • Auto failover
  • Quorum DCD and management floating IP address

Cause

DNS server connectivity failure in the CM or the DCD depending on the IP address mentioned in the error message.

Recommended Actions

Remove any non-reachable DNS server from the DNS settings (System > THIS DEVICE > DNS & NTP)  and only keep the DNS server which are reachable from CM and DCD. Once the right DNS server is used, make sure to test the DNS connection by clicking on Test DNS connection. You should get a succeeded result if it is configured properly.
