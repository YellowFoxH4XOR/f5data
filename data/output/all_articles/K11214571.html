Known Issue

The security denial-of-service (DoS) profile may fail to detect Internet Control Message Protocol (ICMP) flood attacks.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP AFM system with a forwarding virtual server with the * All Protocols protocol.
  • You configure the virtual server with a security DoS protection profile.
  • An ICMP flood attack is initiated on a device in which the forwarding IP virtual server connections for the device are processed by the forwarding IP virtual server.

Impact

The ICMP flood attack is not detected and/or mitigated.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When analyzing the ICMP traffic, the volume of traffic exceeds the values configured for the Dos Protection > Device Configuration > ICMP Flood properties.
  • All of the ICMP flood packets processed by the forwarding virtual server pass to the destination host.
