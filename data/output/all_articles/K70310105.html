Description

  • You apply solution described in article K73304774: AFM + IP Intelligence does not block requests using X-Forwarded-For header value
  • X-forwarded-For header contains multiple IP address as it traverse the network 
  • The last client IP address extracted from x-forwarded-for header by AWAF security policy, for example the IP address of a proxy and not the true source of the request
  • Meaning, If a malicious actor initiated the request but the request traverse through multiple hops, it leads the described solution of IP reputation not being effective

Environment

  • ASM
  • IP-reputation 
  • X-forwarded-for
  • BIG-IP

Cause

  • The BIG-IP system appends the source IP address to the existing X-Forwarded-For header
  • If multiple X-Forwarded-For headers are present in the request, the BIG-IP system appends the source IP address to the value of the last X-Forwarded-For header in the request.
  • By design and a change of behavior introduced following ID 632532.
  • K50499256: The BIG-IP system appends the source IP address to the existing X-Forwarded-For header

Recommended Actions

  • A custom iRule like the one described below can be used 
  • The iRule iterates and identifies all IP address/es in the X-Forwarded-For header and applies IP-reputation to each IP-address identified
  • You would need to verify and possibly adjust the below iRule for your environment 

Additional Information

when HTTP_REQUEST {
#Variables for the Log Message
set xforwarderfor [HTTP::header "X-Forwarded-For"]
set http_host [HTTP::host]
set http_uri [HTTP::uri]
set http_user_agent [HTTP::header "User-Agent"]
set xhost [HTTP::header "X-Host"]
### Only check the website example.com

if  {[HTTP::header "X-Host"] eq "example.com"}{
    foreach axff [HTTP::header values X-Forwarded-For] {
    foreach anip [split [string map {" " ""} $axff] ","] {
        set ip_reputation_categories [IP::reputation $anip]
        
        ### if the IP have a bad reputation the lengh will be NOT zero
        if {[llength [IP::reputation $anip]] != 0}{
            log "action=blocked,http_host=\"$http_host\",http_user_agent=\"$http_user_agent\",http_uri=\"$http_uri\",xforwarderfor=$xforwarderfor,xhost=\"$xhost\",badip=\"$anip\",reputation=\"[IP::reputation $anip]\""
            reject}
        }
    }
    }
}
