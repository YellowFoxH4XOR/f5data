Description

You have a sync-only device group with multiple members, and no sync-failover group. You observe that DoS profiles and Bot defense present in the /Common partition aren't synced between devices.

You would like to know if there is a way for DoS profiles to be synced between all peers using a sync-only group, to avoid having to recreate the configuration.

Environment

  • Config Sync
  • Sync-only device groups
  • DoS Profile
  • Bot Defense Profile

Cause

None

Recommended Actions

By default, objects under /Common are only synced with the sync-failover device group, and this includes DoS and Bot-defense profiles. Perform below steps to achieve the objective.
 

  1. Create Sync failover group under Device Management  ››  New Device Group

  2. Select the device that requires DoS and Bot defense profiles requires to be in sync

  3. Navigate to System ›› Users : Partition List ›› Common ›› Traffic group ›› None and then click Update for configuration to take effect.

  4. Create Dos and BOT defense profile under /Common and proceed to sync. Check whether the profiles are populated in peer device
