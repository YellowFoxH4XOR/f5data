Known Issue

Traffic Management Microkernel (TMM) may produce a core file when using a suspending iRule command with a FastL4 virtual server.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with the following properties:

    • An iRule that uses a suspending command (for example, the table command)
    • A FastL4 profile

This issue can occur when the FastL4 virtual server uses the iRule to suspend a client-side event and then attempts to close a non-existent server-side flow

Impact

The BIG-IP system may temporarily fail to process traffic whileTMM restarts. If the system is configured as part of a high-availability system, the device may fail over.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system unexpectedly fails over to another system in the device group.
  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
