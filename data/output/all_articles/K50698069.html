Issue

Error Message

Error Message: notice tmrouted[<PID>]: 01910301:5: HA daemon heartbeat enabled with <time> period. Last value is <counter>.

In this error message, note the following:

  • <PID> is the process ID of the tmrouted process.
  • <time> is the time period the tmrouted process has enabled for HA heartbeat.
  • <counter> is a counter for the total number of heartbeat periods that the tmrouted process is registered with the HA system.

For example:

Error Message: notice tmrouted[19250]: 01910301:5: HA daemon heartbeat enabled with 9s period. Last value is 1.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The tmrouted process enables a dynamic routing protocol for use in a route domain for the first time in the BIG-IP system.

Note: This can happen when the BIG-IP system is starting or when you manually add a dynamic routing protocol when configuring a route domain.

Impact

The dynamic routing protocol is enabled for the route domain you configured.

Recommended Actions

This message is a notification that the tmrouted process enabled a dynamic routing protocol for a route domain.
