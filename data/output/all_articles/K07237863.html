K07237863: Network page stuck on loading

Type
Support Solution
Published
2022-06-14
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source

Description

When accessing Network Map page from GUI, the page is stuck on loading.

Environment

  • GUI
  • Network map
  • LTM, AVR

Cause

Unknown

Recommended Actions

Execute the following command to restart the 'tomcat' and 'httpd' processes:
Note:  restarting 'tomcat' and 'httpd' will have no effect on traffic passing through the BIG-IP

tmsh restart sys service restjavad restnoded tomcat httpd


If the above action does not resolve the issue, check the allocated system memory and if there is spare memory, increase the amount of tomcat memory by 50mb and also restjavad:

  1. To increase Tomcat memory run the following:

    tmsh modify /sys db provision.tomcat.extramb value 50

  2. To view the change run this command:

    tmsh list sys db provision.tomcat.extramb

  3. Restart tomcat:

    bigstart restart tomcat

  4. Run the following two commands, in sequence:

    1. tmsh modify sys db restjavad.useextramb value true

    2. bigstart restart restjavad restart_tomcat

  5. Clean the browser's cache and cookies and open Network Map.
