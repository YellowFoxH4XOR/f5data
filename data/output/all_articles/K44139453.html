K44139453: BIG-IQ TACACS+ settings not found in bigip.conf

Type
Support Solution
Published
2021-09-20
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K44139453

Description

Setting up TACACS+ authentication via BIG-IQ GUI, TACACS+ configuration is not found in bigip.conf or not displayed when running TMOS commands.

Environment

  • BIG-IQ GUI
  • TACACS+ configuration

Cause

This is an expected behavior.
When setting up TACACS+ using BIG-IQ GUI, configuration is saved in database, and will not be written onto bigip.conf file.

Recommended Actions

None.

Additional Information

None.
