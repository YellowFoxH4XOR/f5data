Topic

F5 has released two applications for Apple iOS:

  • The BIG-IP Edge Portal application for Apple iOS includes support for web portal applications. For more information about the BIG-IP Edge Portal application, refer to K12328: Overview of the iOS BIG-IP Edge Portal application for Apple iPhone, iPad, and iPod touch.
  • The BIG-IP Edge Client application for Apple iOS includes support for full Secure Sockets Layer (SSL)-Virtual Private Network (VPN) access. For more information about the BIG-IP Edge Client application, refer to K12462: Overview of the BIG-IP Edge Client application for the Apple iPhone, iPad, and iPod touch.

BIG-IP Edge Gateway, APM, and FirePass provide the following support for Apple iOS:

  • Secure access to Web Applications using the Apple iOS web browser

    Note: Includes all supported versions of FirePass, BIG-IP APM, and Edge Gateway starting in 10.1.0.

  • Support for email, calendar, and contact synchronization to Microsoft Exchange mail server using the ActiveSync protocol

    Note: Includes FirePass starting in 6.0.3, and BIG-IP APM and Edge Gateway starting in 10.2.0.

  • Support for Apple iOS access to Windows Files and Mobile Email using Portal Access

    Note: Includes all supported versions of FirePass, but does not include support for BIG-IP APM or Edge Gateway.

Note: For more information about which features, browsers, and versions are supported for Apple iOS clients, refer to the FirePass Controller Client Compatibility Matrix for your version of FirePass software or the release notes for your version of BIG-IP APM or Edge Gateway.
