K13880333: Error: ''Failed - slot x: upgrade needed'' when upgrading vCMP guest

Type
Support Solution
Published
2021-04-11
Updated
2025-02-06
Applies to
  • BIG-IP LTM: 13.X.X
Source
https://my.f5.com/manage/s/article/K13880333

Description

vCMP guest upgrade would fail during the install process. When mouse over the Failed word, the following error message is seen.

slot x : upgrade needed

For an example, if the vCMP guest is on slot 1, the following error message is seen.

slot 1 : upgrade needed

From the CLI, it is noticed that lind process is constantly restarting with the following message.

ltm-example.local emerg logger: Re-starting lind

You have followed article K75051412 but it is not resolving the issue.

Environment

  • Failed to upgrade vCMP guest
  • Error message: slot x : upgrade needed
  • lind process keeps restarting
  • Following K75051412 did not resolve the issue

Cause

The vCMP guest is not able to properly access the ISO image from the vCMP host.

Recommended Actions

The workaround to this issue is to copy the ISO image from the vCMP host to the vCMP guest. This will allow the installation to proceed with the ISO image in the Local selection.

  1. Login to the vCMP host Command Line.
     
  2. Navigate to the ISO image directory by typing:
    cd /shared/images/
     
  3. Use scp to copy the ISO image from the vCMP host to the vCMP guest.
    scp <local.ISO> <remote.login.credential>@<vCMP.guest.ip.address>:/shared/images/

    For example; when <local.ISO> is BIGIP-14.1.2.1-0.0.4.iso, <remote.login.credential> is root, <vCMP.guest.ip.address> is 10.10.10.10 than the command would be:
    scp BIGIP-14.1.2.1-0.0.4.iso root@10.10.10.10:/shared/images/
     
  4. Once the file has been transferred, login to the vCMP guest's GUI.
     
  5. Navigate to System > Software Management.
     
  6. You will see there are 2 software images with the intended upgrade version.
     
  7. Select the image which is in Local (not Host) and proceed with the software installation.
