K000136059: Failed to install image

Type
Support Solution
Published
2023-09-01
Updated
2023-09-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.2
Source
https://my.f5.com/manage/s/article/K000136059

Description

Unable to install new software image from GUI or CLI. Liveinstall .log contains the error below and the installation fails instantly.

var/log/liveinstall.log
error: Target system (C119) has a prototype Trusted Platform Module (type : Not Found). It must be updated immediately.
Terminal error: Failed to install.
 

Environment

  • BIG-IP Platform
  • BIOS
  • TPM

Cause

BIG-IP is not able to read TPM data. An example of a properly working and non-working unit can be seen below by running the command:

dmidecode -t 11

# dmidecode 3.0
Getting SMBIOS data from sysfs.
SMBIOS 3.0 present.

Handle 0x000A, DMI type 11, 5 bytes
OEM Strings
      String 1: TPM Type = 2.0
      String 2: TPM Self Test Status: PASS
      String 3: TPM Manufacturer: IFX
      String 4: TPM Vendor String 1: SLB9
      String 5: TPM Vendor String 2: 665
      String 6: TPM Vendor String 3: <NULL>
      String 7: TPM Vendor String 4: <NULL>
      String 8: TPM FW Version 1: 0005003e
      String 9: TPM FW Version 2: 000c3600
ERS - not working

If the unit has the hardware issue 

# dmidecode 3.0
Getting SMBIOS data from sysfs.
SMBIOS 3.0 present.

Handle 0x000A, DMI type 11, 5 bytes
OEM Strings
      String 1: TPM Type = Not Found

 

Recommended Actions

If you got the "TPM Type = Not Found" for the command, please escalate the case with the qkivew and the above command output.
