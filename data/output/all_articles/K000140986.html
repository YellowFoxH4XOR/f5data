Description

BIG-IP Ansible command module (bigip_command) is failing when ü,ö,ä, etc. characters are used and the following error message is logged on BIG-IP /var/log/audit:

 

notice icrd_child[25885]: 01420002:5: AUDIT - pid=25885 user=user folder=/Common module=(tmos)# status=[Syntax Error: double quotes are not balanced] cmd_data=run util bash -c

 

Environment

  • BIG-IP
  • Ansible
  • F5 Python module
  • Imperative Collection Release 1.30.1 or lower

Cause

https://github.com/F5Networks/f5-ansible/issues/2427

Recommended Actions

Upgrade module to the latest version

https://github.com/F5Networks/f5-ansible-f5modules/releases
