Known Issue

This is the result of a known issue. When restoring a FirePass controller configuration from a backup file, users' client certificates will not be restored when using only the Restore Users and Groups Settings option.

When a backup configuration is uploaded using the Device Management: Maintenance: Backup/Restore page, the FirePass displays the uploaded configuration, and provides the following two check boxes to control the behavior of the restore:

  • Restore Networking Configuration
  • Restore Users and Groups Settings

If only the Restore Users and Groups Settings is selected, any client certificates assigned to users will not be restored. If you deleted a client certificate (or a user account which contained a client certificate) after creating the configuration backup, FirePass does not restore the client certificate from the configuration backup file.

F5 Product Development tracked this issue as CR73108 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by selecting both the Restore Networking Configuration and Restore Users and Groups Settings check boxes when performing a restore of the backup.
