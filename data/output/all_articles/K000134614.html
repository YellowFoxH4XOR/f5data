K000134614: "Could not send e-mails: SMTP Error: Could not connect to SMTP host" when sending ASM scheduled reports

Description

When sending ASM schedule reports via email, it's failing with below error:

"Could not send e-mails: SMTP Error: Could not connect to SMTP host." 


Environment

  • ASM/AdvWAF
  • ASM Scheduled Reports


Cause

BUG ID 767473


Recommended Actions

This issue occurs when the remote SMTP server requires TLS1.2 or higher which is currently not supported by AVR reporting feature.

Bug ID 767473: SMTP Error: Could not authenticate


The workaround is to configure the BIG-IP to relay mail through a locally administered SMTP server that allows TLS 1.0 connections.


Additional Information

To verify: Take a tcpdump and see if SSL/TLS handshake is failing due to protocol version. For e.g.:


13 17.288273 0.021566 <BIG-IP_MGMT_IP> → <SMTP_server_IP> 237 41508 587 TLSv1 Client Hello

14 17.330421 0.042148 <SMTP_server_IP> → <BIG-IP_MGMT_IP> 587 41508 TLSv1.2 Alert (Level: Fatal, Description: Protocol Version)
