Description

On rare occasions, one may encounter a situation where you have uploaded a file - for instance, a custom image for an APM policy - that does not exist on the file system.  That is, only the pointer exists in bigip.conf.  This may be discovered if one tries to import to a Big IQ, or if one tries to reload a configuration. 

Environment

  • BiG-IP
  • APM
  • BIG-IQ

Cause

Unknown.  Most likely, the file was removed by hand using 'rm' instead of a tmsh command (as below) or by way of the configuration utility. 

Recommended Actions

  1. Log in at the command line through ssh with the root account or another administrative account
  2. Run the following command:

    tmsh delete apm policy image-file /Common/owa_policy-8_Common_PSE-Transparent-small-logo%01.png

    For instance, if you have a filename called common_image-1%01.png in partition Common, you would do this:

    tmsh delete apm policy image-file /Common/common_image-1%01.png

  3. Save your configuration:

    tmsh save sys config
