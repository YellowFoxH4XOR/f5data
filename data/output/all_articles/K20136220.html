Issue

Description

This article describes the steps to update an iApp to a newer version without losing your current settings.

Environment

  • BIG-IP with a current iApp configured
  • Latest iApp downloaded from Askf5.com

Cause

Periodically, applications and resources are updated to newer version and require additional configurations. Newer versions of iApps can be released to accommodate these changes.

Recommended Actions

Backing up current configuration by using the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to System > Archives.
  3. Click Create.
  4. In the File Name box, type a name for the file.

    Important: You must use a unique file name. If a file with the same name already exists, the system does not create the UCS archive file and displays a warning message that appears similar to the following example: The file already exists on the system

    Optional: If you want to encrypt the UCS archive file, for Encryption, click Enabled and enter a passphrase. You must supply the passphrase to restore the encrypted UCS archive file.

    Optional: If you want to exclude SSL private keys from the UCS archive, from the Private Keys list, click Exclude.

  5. To create the UCS archive file, click Finished.
  6. When the system completes the backup process, examine the status page for any reported errors before proceeding to the next step.
  7. To return to the Archive List page, click OK.
  8. Copy the *.ucs file to another system.

Importing the new iApp version

  1. Log in to the Configuration utility.
  2. Navigate to iApps >  Templates > Templates
  3. Click Import.
  4. Click Choose File.

    Note: Selecting the Overwrite Existing Template check box indicates whether existing templates of the same name should be overwritten by the template you are importing.

  5. Locate and choose the *.tmpl file to import.
  6. Click Upload.

Updating the iApp to the new version

  1. Log in to the Configuration utility.
  2. Navigate to iApps  > Application Services > Applications.
  3. Click the iApp you are updating.
  4. Click the Reconfigure tab.
  5. For Template , click Change.
  6. Choose the newer iApp template from the list.
  7. Scroll to the bottom and click Update.
