Known Issue

You are unable to remove Secure Sockets Layer (SSL) keys and certificates from subfolders by using the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You have an SSL key or certificate that was created in a subfolder.
  • You attempt to remove the SSL key or certificate by using the Configuration utility.

Impact

The system does not delete the SSL keys and certificates.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to delete an SSL key or certificate, the Configuration utility returns a Not Found error message.

Workaround

To work around this issue, you can delete keys by using the Traffic Management Shell (tmsh). To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Change directories to the affected subfolder by using the following command syntax:

    cd <subfolder name>

    For example, to change directories to a subfolder named example, type the following command:

    cd example

  3. Remove the affected SSL key by using the following command syntax:

    delete /sys crypto key <key name>

    For example, to remove a key named example.com, type the following command:

    delete /sys crypto key example.com.key

  4. To remove the example.com.crt certificate, which is associated with the example.com.key SSL key, type the following command:

    delete /sys crypto cert example.com.crt

  5. Save the change by typing the following command:

    save /sys config
