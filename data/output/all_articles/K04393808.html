Known Issue

BIG-IP iRule commands may report an incorrect request status for web scraping.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP ASM system for Web Scraping Anomaly Detection in Alarm mode.
  • You have configured an iRule to use the BIG-IP ASM status of web requests.

    For example, the following iRule will incorrectly log blocked requests detected by web scraping as alarmed.

    when ASM_REQUEST_DONE {
    log local0. "Request Status: [ASM::status];"
    }

Impact

BIG-IP iRule commands incorrectly report the request status for web scraping.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Web requests detected as alarmed by web scraping are instead reported by iRule commands as blocked.
