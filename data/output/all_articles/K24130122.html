K24130122: BIG-IP's GUI disappears after 24-36hrs

Support Solution
Published
2022-01-26
Updated

Applies to

  • BIG-IP LTM: 16.X.X, 16.0.X, 16.1.0, 16.0.1, 16.0.0, 16.1.X, 16.1.2, 16.1.1, 16.1.3
Source
https://my.f5.com/manage/s/article/K24130122

Description

If the unit was re-imaged and leave it as the default username/password and default IP address, the GUI splash screen and SSH accounts are stable.
However, if you change the GUI password, SSH password and default IP address (and power cycle), the device is stable for 24-36 hours but after that the GUI splash screen disappears completely.
The SSH logon screen is available but it will not recognize the new or old password. 

Environment

  • BIG-IP
  • Changed the GUI password, SSH password and default IP address

Cause

The OS was manually installed and then BIG-IP's ISO.
It was not installed according to K13117: Performing a clean installation of BIG-IP 11.x - 16.x.

Recommended Actions

Perform a clean installation following K13117: Performing a clean installation of BIG-IP 11.x - 16.x.
