K000163431: Slow SSH and Web Application Tunnel Performance with APM Client 7.2.7

Type
Support Solution
Published
2026-09-28
Updated
2026-09-28
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163431

Description

BIG-IP APM Application Tunnels establish successfully but provide very slow data transfer for SSH and web applications when using APM Client 7.2.7 Build 7567.0. Packet captures show repeated idle gaps without corresponding TCP retransmissions. 

Environment

  • Product: BIG-IP APM
  • Feature: Application Tunnel
  • Client operating system: Microsoft Windows
  • Affected client: APM Client 7.2.7 Build 7567.0
  • Affected traffic: SSH and HTTP
  • Affected configurations: Default and non-default route domains

Cause

The behavior is associated with Bug ID 2504945, [App Tunnel] Slow response times observed for App Tunnel connections over SSH and HTTP. The issue involves an interaction between APM Client 7.2.7 and BIG-IP APM Application Tunnels. The underlying mechanism was not conclusively determined.

Recommended Actions

  1. Use APM Client 7.2.6 as a workaround where possible.
  2. Install a release containing the fix for Bug ID 2504945. ( fix planned with 7.2.7.3 HR3 release)
  3. Validate SSH and web Application Tunnel data transfer after installing the fixed release.
