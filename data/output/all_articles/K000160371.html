Description

  • When attempting to register a CNAME record on F5 BIG-IP DNS, the following error message occurs:

org.xbill.DNS.Tokenizer$TokenizerException: :1: <label>.example.com.: label too long


Environment

  • Product: F5 BIG-IP DNS (formerly GTM)
  • Version: 17.x.x
  • Scenario: Registering CNAME records for domain validation (e.g., for HTTPS certificate issuance)


Cause

The CNAME label being registered exceeds the DNS RFC maximum of 63 characters per label. BIG-IP DNS enforces this standard, resulting in the "label too long" error.


Answer/Recommended Actions

  1. Verify the length of each label (the part between dots in the domain name) in the CNAME record.
  2. Ensure that no label exceeds 63 characters, as required by DNS RFC standards.
  3. Remove any hidden spaces or formatting errors in the label string.
  4. If the label is longer than 63 characters, modify it to comply with the limit before registering it on BIG-IP DNS.
  5. If the CNAME value is provided by a third party (e.g., a certificate authority), contact them to request a compliant value if possible.


Additional Information

  • This is expected behavior as per DNS RFC standards. Each label (section between dots) in a domain name must not exceed 63 characters.
  • BIG-IP DNS strictly enforces this limit and will not accept labels longer than 63 characters.
