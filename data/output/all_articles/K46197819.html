Description

When viewing the Session Initiation Protocol (SIP) profiles statistics on the BIG-IP system, the Generated Failure Response Statistics and Response Message Statistics doesn't match.

Environment

  • Virtual server with SIP Profile assigned
  • Viewing statistics either from GUI or tmsh

Cause

This section of the statistics only counts the failure response which are generated by BIGIP. If the error is generated by server peer and NOT generated by BIG-IP then this error statistics will not be added.

 Response Code                             Sent   Not Sent  Total
  400 - Bad Request                           0         23     23
  404 - Not Found                             0          0      0
  413 - Request Entity Too Large              0          0      0
  416 - Unsupported URI Scheme                0          0      0
  480 - Temporarily Unavailable               0          0      0
  481 - Transaction Does Not Exist            0          0      0
  482 - Loop Detected                         0          0      0
  483 - Too Many Hops                         0          0      0
  484 - Address Incomplete                    0          0      0
  488 - Not Acceptable Here                   0          0      0
  500 - Server Internal Error                 0          0      0
  501 - Not Implemented                       0          0      0
  503 - Service Unavailable                   0          0      0
  505 - Version Not Supported                 0          0      0


This section of the statistics includes received response from Server side.

  1xx - Provisional                        7.7M
  2xx - Successful                         7.8M
  3xx - Redirection                           0
  4xx - Client-Failures                    1.5M   
  5xx - Server-Failures                  111.2K
  6xx - Global-Failures                   10.7K

When the failed responses are generated by BIGIP, such as a malformed SIP INVITE, BIG- IP will generate a 400 Bad request, and "Generated Failure Response Statistics" 400 - Bad Request count will increase. For any failed responses from server peer, "Generated Failure Response Statistics" count will not increase.

Recommended Actions

None. Working as designed.
