Description
In some scenarios you may be required to create a SNMPv3 user using TMOS

Environment

  • BIG-IP
  • SNMPv3

Cause
Expected Behavior

Recommended Actions

Create a user from the TMOS shell.
  1. Enter TMOS:
    # tmsh
     
  2. Create user replacing <test_group> <example_user> <password>:
    root@(apm4)(cfg-sync Standalone)(Active)(/Common)(tmos)# modify sys snmp users add { <test_group> { username <example_user> auth-protocol sha privacy-protocol aes security-level auth-privacy oid-subset .1 auth-password "<password>" privacy-password "<password>" } }

    Example:
    root@(apm4)(cfg-sync Standalone)(Active)(/Common)(tmos)# modify sys snmp users add { group1 { username test_user auth-protocol sha privacy-protocol aes security-level auth-privacy oid-subset .1 auth-password "123456789" privacy-password "1234567890" } }
    Note: You can use the Tab key to view available parameter options, K13625 provides additional details.
     
  3. Save the configuration:
    (tmos)# save sys config
     
  4. Test the user from bash:
    # snmpwalk -v3 -u test_user -l authPriv -a SHA -A "123456789" -x AES -X "1234567890" localhost F5-BIGIP-SYSTEM-MIB::sysSystemNodeName
        F5-BIGIP-SYSTEM-MIB::sysSystemNodeName.0 = STRING: apm.example.local
