K11055: The session.os.platform variable contains an additional value for Mac OS X clients

Type
Knowledge
Published
2010-11-02
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.1.0, 6.0.3
Source

Issue

Before upgrading from FirePass 5.5.2 to 6.0.3 or later, F5 recommends that you check any reference to the session.os.platform variable if you have Mac OS X users. In FirePass 5.5.2, Mac OS X users are recognized without having a specific definition for Mac OS X. In FirePass 6.0.3 and later, Mac OS X users will be rejected if a definition for Mac OS X has not been specified.

In FirePass 5.5.2, most session.os.platform variable references appear similar to the following example:

session.os.platform == "MacOS" OR session.os.platform == "Mac OS"

Beginning in FirePass 6.0.3, Mac OS X users will be rejected if the session.os.platform variable references are not updated to the following:

session.os.platform == "MacOS" OR session.os.platform == "Mac OS" OR session.os.platform == "MacOSX"

By adding the second OR variable definition, Mac OS X users will be properly identified. In addition, the Apple iPhone, iPad, and iPod touch will be identified as MACOS or MACOSX.

Note: To further identify the iOS family of devices, refer to K12238: Assigning FirePass resources based on the mobile OS platform using the session.browser.user_agent session variable.
