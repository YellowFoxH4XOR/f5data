Issue

Error Message

01140044:5: HA reports tmm ready.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The Traffic Management Microkernel (TMM) reaches a running state and is ready to process traffic.

The sod process generates this message when TMM has completed the startup process and is able to accept traffic.

Impact

There is no impact; this message is a notification that TMM is up and ready to process traffic.

Recommended Actions

None
