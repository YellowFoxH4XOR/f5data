Description

The timestamp in gtm.configtime will be updated when this is triggered by deleting wideip or pools etc.
You can use the gtm.configtime database variable to check the timestamp.

# tmsh list sys db gtm.configtime
sys db gtm.configtime {
   value "1578034956"
}

Environment

・ BIG-IP GTM/DNS

・ Synchronization Group


Cause

DB variable gtm.configtime check each one's config time among Synchronization Group.

 

Recommended Actions

None
