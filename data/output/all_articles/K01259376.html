K01259376: New VE floating IPs not pingable/addressable after migration from physical to VE

Type
Support Solution
Published
2021-04-27
Updated
2025-02-06
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IP Platforms
Source
https://my.f5.com/manage/s/article/K01259376

Description

Floating IP is not pingable between physical equipment and VE on the same subnet network.

Environment

  • Physical and VE are configured with the same MAC masquerade value

Cause

Same MAC masquerade value on physical and VE on the same network will cause conflict.

Recommended Actions

Option 1: Remove MAC masquerade from Physical or VE.

Option 2: Modify MAC masquerade to a different value.

Additional Information

None
