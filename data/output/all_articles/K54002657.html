Description

When attempting to import an SSL certificate via GUI (Configuration utility):
  • System > Certificate Management > Traffic Certificate Management (13.x-17.x)
  • System > File management > SSL Certificate list (11.x-12.x)
It fails with the following error:  
Import Failed: OpenSSL error: Exception caught in Management::urn:iControl:Management/KeyCertificate::key_import_from_file()
Exception: Common::OperationFailed
primary_error_code : -7 (0xFFFFFFF9)
secondary_error_code : 0
error_string : error:0D0680A8:asn1 encoding routines:ASN1_CHECK_TLEN:wrong tag

Environment

  • BIG-IP configuration utility
  • Importing a new SSL certificate

Cause

While importing the certificate an incorrect Import Type is selected. 

Recommended Actions

  1. Verify if there is any white space in the certificate file: K32288220: Cannot update device certificate on F5
  2. If there is no white space then verify if the certificate file format is .cer or .pem or .pfx.
  3. In this example, a user tried importing a certificate file in .cer format with Import Type as PKCS 12 (IIS). 
  4. Select the correct Import Type as Certificate while importing the certificate file.
