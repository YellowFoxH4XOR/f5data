K8418: Multiple client root certificates are not supported when using a FirePass internal PKI

Topic

The FirePass controller can support multiple client root certificates from third-party certificate authorities, but only if an external PKI is used. When the FirePass controller is configured to use its internal PKI, only a single client root certificate is supported, either a self-signed client root certificate or a client root certificate issued by a third party. When the FirePass controller is configured to use an external PKI, only client root certificates from third-party certificate authorities are supported, but multiple client root certificates can be used.

You configure the FirePass controller to use its internal PKI when you intend to use the FirePass controller to create the client certificates for FirePass users, rather than creating the client certificates from an external source, such as the Microsoft Certification Authority. The FirePass controller is configured to use its internal PKI either by creating a self-signed client root certificate or by installing a third-party client root certificate and its private key. This prevents configuration of additional client root certificates from third-party certificate authorities or of additional self-signed client root certificates.

The menu to configure client root certificates is located under the Install Client Root Certificate and CRL section of the Device Management: Security: Certificates page.  When no client root certificates are installed, all menu options are selectable (blue links).

When third-party client root certificates are installed and the FirePass is not using its internal PKI, the Client Root Certificate and Certificate Revocation List are selectable (blue links), and the Self-Signed Certificate option is not selectable (grey text).

When a third-party client root certificate or self-signed client root certificate is installed and the FirePass is using its internal PKI, all menu options are not selectable (grey text).

A feature request has been made to add multiple client root certs with internal PKI use. F5 Networks Product Development is tracking an enhancement for this issue as CR88712.
