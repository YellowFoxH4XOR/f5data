Description

You may notice in LTM's configuration utility that there is a Local Host Name under the SMTP configuration page, as shown in the screenshot below.

Environment

  • LTM
  • SMTP

Cause

The SMTP Local Host Name on BIG-IP is a configuration setting that specifies the hostname with which BIG-IP will identify itself in the SMTP EHLO header when connecting to other SMTP servers.

Recommended Actions

None.
