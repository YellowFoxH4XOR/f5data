Topic

To configure the BIG-IP or BIG-IQ system to run startup commands or scripts, you should append the commands or scripts to the end of the /config/startup file. The /config/startup file is called by /etc/rc.local, and the file is saved in user configuration set (UCS) archive files and synchronized to redundant BIG-IP systems during ConfigSync operations. The /config/startup file is also saved during an upgrade.

Important: F5 recommends that you modify the startup commands or scripts only when directed by F5 Support.

Note: F5 periodically changes the /etc/rc.local file between software releases and does not recommend that you use /etc/rc.local to run startup commands or scripts.

Note: The /config/startup file and any customized startup scripts in the /config directory are not synchronized to redundant BIG-IP systems in an 11.x-12.x ConfigSync operation.

Description

To create a customized startup script and enable the BIG-IP or BIG-IQ system to run the script when the system starts up, perform the following procedures:

  • Create a customized startup script
  • Enable the BIG-IP or BIG-IQ system to run the script

Create a customized startup script

Perform the following procedure to create the startup script /config/startup_script_sol11948.sh file as appropriate for your BIG-IP version and BIG-IQ version:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Important: The mcpd process may not complete its initialization during system startup. However, depending on what the script does, it may require mcpd to be up and running. The following script performs a check to ensure that the MCP process completes its initialization before running any commands.

  • BIG-IP 15.1.0 and later or BIG-IQ 8.0.0 and later
  • Prior to BIG-IP 15.1.0 or to BIG-IQ 8.0.0

BIG-IP 15.1.0 and later or BIG-IQ 8.0.0 and later

  1. Log in to the command line.
  2. Use a text editor to create the customized startup script /config/startup_script_sol11948.sh file.

    #!/bin/bash
    # Filename: /config/startup_script_sol11948.sh

    source /usr/lib/bigstart/bigip-ready-functions
    wait_bigip_ready

    # Here you could perform customized command(s) after MCPD is found running when the BIG-IP system starts up.
    # Customized startup command(s) can be added below this line.

    # Customized startup command(s) should end above this line.

    # End of file /config/startup_script_sol11948.sh

    In the previously described script, insert the customized startup commands between the following two lines:

    # Customized startup commands can be added below this line.

    # Customized startup commands should end above this line.

    For example, if you want the BIG-IP system to add the Address Resolution Protocol (ARP) entry for the upstream device, IP address 10.0.0.1, upon system startup, the customized startup commands section of the script may appear similar to the following example:

    # Customized startup command(s) can be added below this line.
    tmsh create /net arp 10.0.0.1 mac-address 00:01:01:01:01:F3
    # Customized startup command(s) should end above this line.

  3. Save the changes you made to the /config/startup_script_sol11948.sh file and exit the text editor.
  4. Enable executable mode for the /config/startup_script_sol11948.sh file, and enter the following command:

    chmod +x /config/startup_script_sol11948.sh

Prior to BIG-IP 15.1.0 or to BIG-IQ 8.0.0

  1. Log in to the command line.
  2. Use a text editor to create the customized startup script /config/startup_script_sol11948.sh file.

    #!/bin/bash
    # Filename: /config/startup_script_sol11948.sh
    export REMOTEUSER=root

    # Limit to 4 times in while-loop, ie. 4 x 30 secs sleep = 2 mins.
    MAX_LOOP=4

    while true
    do
    MCPD_RUNNING=`ps aux | grep "/usr/bin/mcpd" | grep -v grep | wc -l`

    if [ "$MCPD_RUNNING" -eq 1 ]; then
    # Here you could perform customized command(s) after MCPD is found running when the BIG-IP system starts up.
    # Customized startup command(s) can be added below this line.

    # Customized startup command(s) should end above this line.

    exit
    fi

    # If MCPD is not ready yet, script sleep 30 seconds and check again.
    sleep 30

    # Safety check not to run this script in background beyond 2 mins (ie. 4 times in while-loop).
    if [ "$MAX_LOOP" -eq 1 ]; then
    echo "MCPD not started within 2 minutes. Exiting script."
    exit
    fi
    ((MAX_LOOP--))
    done
    # End of file /config/startup_script_sol11948.sh

    In the previously described script, insert the customized startup commands between the following two lines:

    # Customized startup commands can be added below this line.

    # Customized startup commands should end above this line.

    For example, if you want the BIG-IP system to add the Address Resolution Protocol (ARP) entry for the upstream device, IP address 10.0.0.1, upon system startup, the customized startup commands section of the script may appear similar to the following example:

    # Customized startup command(s) can be added below this line.
    tmsh create /net arp 10.0.0.1 mac-address 00:01:01:01:01:F3
    # Customized startup command(s) should end above this line.

  3. Save the changes you made to the /config/startup_script_sol11948.sh file, and exit the text editor.
  4. Enable executable mode for the /config/startup_script_sol11948.sh file, and type the following command:

    chmod +x /config/startup_script_sol11948.sh

Enable the BIG-IP or BIG-IQ system to run the script

Perform the following procedure to edit /config/startup to call /config/startup_script_sol11948.sh upon system startup:

Impact of procedure: If you intend to restart and verify the customized startup script, perform the following procedure only during a scheduled maintenance window.

  1. Log in to the command line.
  2. Change permissions on the /config/startup file to allow modifications by entering the following command:

    chmod +w /config/startup

  3. Using a text editor, edit the /config/startup file. Append the following line to the end of the file:

    /config/startup_script_sol11948.sh &

    Note: The ampersand symbol (&) at the end of the line causes the system to perform the customized startup script on a separate process so as to not disrupt the BIG-IP system original boot sequence. The /config/startup_script_sol11948.sh file is the customized startup script containing the commands that you want the system to perform when the BIG-IP system starts. This is the file that you create in step 5.

  4. Save the changes made to the /config/startup file and exit the text editor.

  5. On the next start, the BIG-IP system performs the customized commands in the /config/startup_script_sol11948.sh file.

Note: For information about configuring the BIG-IP system to run commands or scripts upon failover, refer to K6008: Configuring the BIG-IP system to run commands or scripts upon failover.
