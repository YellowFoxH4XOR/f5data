Known Issue

A previously-exported BIG-IP APM access policy cannot be imported to the BIG-IP system.

This issue occurs when the following condition is met:

  • You have an exported access profile that has two or more files that have been customized in Access Policy > Customization > Advanced.

Impact

You are unable to import previously-exported access profiles.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • An error message that appears similar to the following example is displayed in the Configuration utility:

    Import Error: 01070734:3: Configuration error: DB validation exception, unique constraint violation on table (customization_template_file) object ID (<advanced customization file name>). A duplicate value was received for a non-primary key unique index field. DB exception text (Can't save/checkpoint DB object, class:customization_template_file status:13) Unexpected Error: Loading configuration process failed.

  • The access policy is not imported to the BIG-IP system.
