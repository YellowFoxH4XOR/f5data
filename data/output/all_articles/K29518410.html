Description

  • Deploying SSL Configuration changes re-deploys the entire SSL Orchestrator topology
  • Making changes to any SSL configuration and deploying results in the entire Topology being re-deployed.

Environment

  • SSL Orchestrator topology configured and deployed
  • SSL Orchestrator SSL configuration modified
    • SSL Orchestrator  ››  Configuration :: SSL Configurations (tab)
  • SSL Orchestrator provisioned

Cause

This is expected behavior

Recommended Actions

You may be required to review and change back configurations such as Interception Rules.
