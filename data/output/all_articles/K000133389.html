K000133389: Unexpected Error: Database connection could not be established

Type
Support Solution
Published
2023-04-05
Updated
2023-04-05
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000133389

Description

  • When performing the "tmsh list" command, getting the below error

root@(bigip1)(cfg-sync In Sync)(/S1-green-P::Active)(/Common)(tmos)# list

Display all 3215 items? (y/n) y

Unexpected Error: Database connection could not be established.


  • When saving UCS backup, getting the below error:

mysql: Can't read dir of '/var/lib/mysql/cnf' (Errcode: 2)

Fatal error in defaults handling. Program aborted

{"kind":":resterrorresponse","message":"/var/lib/hsqldb/live-update/live-update.yaml (No such file or directory)","responseCode":500}


Environment

  • VCMP guest deployed on Viprion platform.
  • BIG-IP 16.1.3

Cause

Unknown


 Recommended Actions

  • This looks like the system file is missing or corrupted, use the software image to create a new HD1.x volume and install the software again.
  • After the new software volume is created, boot into the new software volume.
