Known Issue

The Master Control Program Daemon (MCPD) may produce a core file during a configuration synchronization (ConfigSync) operation on VIPRION platforms.

This issue occurs when all of the following conditions are met:

  • Your system uses a VIPRION platform.
  • The mcpd log level is set to debug or info.

    Note: The default setting is notice.

    For example:

    tmsh list /sys db log.mcpd.level

    sys db log.mcpd.level {
    value "debug"
    }

Impact

Service is interrupted while the mcpd process restarts and/or the system fails over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The VIPRION system fails over to the standby system if configured for high availability (HA).
  • Messages similar to the following example are logged to the /var/log/ltm file:

    info sod[7162]: 010c0009:6: Lost connection to mcpd - reestablishing.
    err clusterd[8308]: 013a0004:3: IO error on recv from mcpd - connection lost
    info chmand[8539]: 012a0006:6: MCP connection lost.

  • Messages similar to the following example are logged to the /var/log/messages file:

    notice logger: Started writing core file: /var/core/mcpd.bld675.0.core.gz for PID 8540
    notice logger: Finished writing 44982978 bytes for core file: /var/core/mcpd.bld675.0.core.gz for PID 8540

  • The VIPRION system generates mcpd core files to the /var/core directory, with a time stamp that correlates to the traffic interruption, similar to the following example:

    -rw-r--r-- 1 root root 144M Apr 29 10:17 mcpd.bld675.0.core.gz

Workaround

To work around this issue, you can change the mcpd log level from debug/info to notice or a higher level. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Set the mcpd log level to notice or higher by using the following command syntax:

    modify /sys db log.mcpd.level value <level>

    For example, to set the log level to notice, type the following command:

    modify /sys db log.mcpd.level value notice

    Note: Alternatively, you can reset the db variable to the default value by using the modify /sys db log.mcpd.level reset-to-default command.

  3. Save the change by typing the following command:

    save /sys config
