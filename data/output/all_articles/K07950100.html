Topic

You should consider using this procedure under the following condition:

  • You want to find the F5OS-A software version on the F5 rSeries system.

Description

F5OS-A software includes the Base OS and Service components. The Base OS component includes the CentOS Linux operating system. The Service component includes specific F5 software, such as the qkview utility and platform-specific packages.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have root or admin user access to the command-line interface (CLI).
  • Have admin user access to the webUI or REST API.

Procedures

To find the version information for each of these components, perform one of the following procedures:

  • Display the F5OS-A version using the webUI
  • Display the F5OS-A version using the CLI
  • Display the F5OS-A version using the REST API

Display the F5OS-A version using the webUI

To find the F5OS-A version information using the webUI, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the webUI of the F5 rSeries system as admin user.
  2. Go to SYSTEM SETTINGS > General.
    The Base OS and Service versions display under the System Operations & Status section.

Display the F5OS-A version using the CLI

To find the F5OS-A version information using the CLI, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the CLI as admin user.
  2. For F5OS-A 1.7.0 and later, enter the following command:

    show system version

    The command returns output similar to the following example:

    system version os-version 2.0.0-22925
    system version service-version 2.0.0-22925
    system version product F5OS

  3. For F5OS-A 1.5.x and earlier, display the Base OS software version installed on the F5 rSeries system by entering the following command:

    show system image state os

    The command returns output similar to the following example; the version that is indicated as true in the IN USE column is the currently running version:

                                                IN            
    VERSION OS   STATUS  DATE        SIZE       USE    TYPE   
    ----------------------------------------------------------
    2.0.0-22925  ready   2026-05-20  2167.80MB  true          
    1.8.4-26491  ready   2026-04-16  925.36MB   false  EHF-1  
    1.5.2-21056  ready   2024-02-29  927.12MB   false  LTS    

  4. For F5OS-A 1.5.x and earlier, display the Service software version installed on the F5 rSeries system by entering the following command:

    show system image state services

    The command returns output similar to the following example; the version that is indicated as true in the IN USE column is the currently running version:

    VERSION                                  IN            
    SERVICE      STATUS  DATE        SIZE    USE    TYPE   
    -------------------------------------------------------
    2.0.0-22925  ready   2026-05-20  2.96GB  true          
    1.8.4-26491  ready   2026-04-16  2.73GB  false  EHF-1

    1.5.0-5781   ready   2024-02-29  2.49GB  false  LTS    

Display the F5OS-A version using the REST API

To find the F5OS-A version information using the REST API, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the CLI as the root user. Alternatively, you can log in to a system with the curl utility installed.
  2. For F5OS-A 1.7.0 and later, use the following command syntax:

    curl -X GET -sku <username:password> -H "Content-Type: application/yang-data+json" https://<management IP address>/api/data/openconfig-system:system/f5-system-version:version

    In the previous syntax, note the following:

    • Replace <username:password> with the administrative username and password to access the F5 rSeries system.
    • If you are running the command from the system CLI, replace <management IP address> with localhost.
    • If you are not running the command from the system CLI, replace <management IP address> with the management IP address of the F5 rSeries system.

    For example, if you are running it from the system CLI, enter the following command:

    curl -X GET -sku admin:admin -H "Content-Type: application/yang-data+json" https://localhost/api/data/openconfig-system:system/f5-system-version:version

    The command output appears similar to the following example:

    {
      "f5-system-version:version": {
        "os-version": "2.0.0-22925",
        "service-version": "2.0.0-22925",
        "product": "F5OS"
      }
    }

  3. For F5OS-A 1.5.x and earlier, display the Base OS software version installed using the following command syntax:

    curl -X GET -sku <username:password> -H "Content-Type: application/yang-data+json" https://<management IP address>/api/data/openconfig-system:system/f5-system-image:image/state/os
