Issue

Error Message

notice clusterd[<PID>]: 013a0015:5: Blade <blade number> <quorum state increasing status>

In this error message, note the following:

  • <PID> is the process ID for the clusterd process.
  • <blade number> is the blade number being reported.
  • <quorum state increasing status> is the reported blade's quorum state.

For example:

notice clusterd[7142]: 013a0015:5: Blade 1 quorum state increasing from INITIAL to QUORUM_WAIT.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The blade is online after a reboot.
  • You add a new blade to the chassis.
  • You re-provision the blade.

Impact

None. This is a notification of quorum state change.

Recommended Actions

None
