Description

When trying to upload Virtual Server that has multiple Client SSL Profile  with an updated certificates, prompted with below error:

0107149e:3: Virtual server /Common/vs_test.com_443 has more than one clientssl/serverssl profile with same server name.

 

Environment

  • BIG-IP
  • LTM
  • Virtual Server with multiple Client SSL Profile
  • Configuration Utility (GUI)
 

Cause

Some of the Client SSL Profiles are sharing the same Server Name Indication (SNI) or subject name.
 

Recommended Actions

Workaround the issue by adding alternate SAN name to the certificate if the new certificate has to have the exact same SNI as per the existing certificates.
Screenshot as an example of the alternate SAN name (highlighted in yellow).
Note: The Subject Alternate Name "DNS:" entry is case sensitive, please make sure it is in full capital.
