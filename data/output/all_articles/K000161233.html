K000161233: Antivirus issue after upgrade to 17.5.1.3

Type
Support Solution
Published
2026-08-26
Updated
2026-08-26
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000161233

Description

Users experience failures with antivirus endpoint inspection when connecting via the web browser VPN client after upgrading BIG-IP APM to version 17.5.1. The antivirus check prompt appears, but no antivirus is detected and connections are denied. The issue is caused by the web browser plugin installer relying on an embedded 7-Zip version that may be blocked by organizational security policies requiring a newer version, preventing plugin installation and resulting in failed endpoint inspection. The Edge Client is not affected.

Environment

  • BIG-IP APM version 17.5.1.x
  • Web browser VPN client (browser-based endpoint inspection)
  • Edge Client (native VPN client)
  • Endpoint inspection policy with antivirus check
  • Organizational security policy requiring a newer 7-Zip version
  • EPSEC package installed

Cause

The web browser plugin installer uses a self-extracting file with an embedded 7-Zip version that may be blocked by security policies, preventing plugin installation and causing endpoint inspection failures.

Recommended Actions

  • Use the Edge Client for users who require endpoint checks and cannot relax the 7-Zip version policy.
  • Request a security policy exception for the required 7-Zip version in the endpoint security policy for the plugin installation path, if feasible.
  • If neither workaround is possible, request a product enhancement to update the embedded 7-Zip version in the web plugin.
  • Troubleshoot by verifying plugin installation attempts and checking for security policy blocks related to 7-Zip version enforcement.
  • If antivirus checks must be bypassed temporarily, set "DB Age Not Older Than (days)" to 0 in the access policy (not recommended as a long-term solution).

Additional Information

  • The Edge Client does not require the browser plugin and is not affected by the 7-Zip version restriction.
  • The issue is specific to browser-based VPN endpoint inspection and does not impact native client connections.
