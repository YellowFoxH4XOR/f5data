Known Issue

The BIG-IP ASM may fail to correctly parse a CSRT token.

This issue occurs when the following conditions are met:

  • The Cross-site request forgery (CSRF) feature is enabled in the security policy
  • The CSRT token appears in the middle of the query string

Impact

Requests containing a CSRT token may not be processed as expected

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Requests containing a CSRT token may not be processed as expected
  • Packet captures may indicate that the BIG-IP ASM corrupts requests containing a CSRT token in the middle of the query string.

    For example, the following client-side request contains a CSRT token in the middle of the query string:

    GET /index.php?csrt=123&p=ab

    After the BIG-IP ASM processes the request, the system appends erroneous characters to the end of the request string. For example:

    GET /index.php?p=ab3
