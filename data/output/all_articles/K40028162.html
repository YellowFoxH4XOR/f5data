Description

Attempting to access Local Traffic Policy produces the error message: An error occurred [object Object]

  • Attempting to modify a Local Traffic Policy
  • In the Admin GUI you will see the error message: An error occurred [object Object]

Environment

  • Local Traffic Manager (LTM)
  • Local Traffic Policies

Cause

An issue has occurred with the restjavad service.

Recommended Actions

You can correct this issue by restarting the restjavad service:

1. Log in to the command line.
2. Use the following command syntax to restart the service:

bigstart restart <service_name>

For example:

#bigstart restart restjavad
 

Additional Information

The restjavad daemon provides control-plane access to the BIG-IP using an http REST api.
