K58819361: BIG-IP PAYG VE have the same base registration key

Type
Support Solution
Published
2022-06-02
Updated
2025-02-06
Applies to
  • Public Cloud
  • BIG-IP
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K58819361

Description
You had multiple  BIG-IP Pay As You Go (PAYG) VE from public marketplaces, such as Amazon Web Services (AWS), Azure and Google
Prior to upgrade, you notices multiple BIG-IP VE are using same base registration key. 

Environment

  • BIG-IP VE
  • Pay As You Go (PAYG) image
  • Public marketplaces

Cause

This is an expected behavior.

Recommended Actions

Beginning in BIG-IP VE 13.1.0.2, 12.1.3.3, and later, PAYG BIG-IP VE will be assigned with PAYG license automatically during setup.
As a pool of licenses is reserved for PAYG BIG-IP VE, there is a chance that 2 of the BIG-IP VE is provided with the same license key within the license pool.

Additional Information

When you upgrade BIG-IP 13.1.0.2, 12.1.3.3, and later PAYG VE images in a cloud marketplace, you do not need to (nor are you allowed to) reactivate the license before you upgrade. The upgrade process does not check or enforce the SCD.
