Description:

APM webtop login page requires end-user to provide usernames and passwords. This information can be saved by browsers and the former will be automatically filled next time when we log in. This may become a vulnerability if another end-user uses the same client to log in.

Environment:
  • BIG-IP APM
  • Login Page assigned
  • Chrome Browser
Cause:

autocomplete="off" is already set in the source code of logon page.
<input type="text" name="username" class="credentials_input_text" value="" id="input_1" autocomplete="off" autocapitalize="off">
<input type="password" name="password" class="credentials_input_password" value="" id="input_2" autocomplete="off" autocapitalize="off">
While Google Chrome 34 and higher drops recognition of autocomplete="off" attribute for password input.

Recommended Actions:

Customize the logon page 

For more details, please refer to Manual Chapter : Changing Customized Properties in Advanced View 
  1. Log in to the Configuration Utility of the BIG-IP APM system.
  2. Navigate to Access >> Profiles / Policies >> Customization >> Advanced
  3. Expand the foler in left work window one by one: Customization Settings >> Access Profiles >> /Common/<access_policy_name> >> Access Policy >> Logon Pages >> Logon Pages
  4. Click the file logon.inc in the expanded folder.
  5. Make the changes you require to the file.
    • To save a draft of your changes without applying them, click the Save Draft button.
    • To discard any changes saved with the Save Draft button, click Revert, and follow the instructions on the confirmation dialog box.
  6. After you customize settings, click the Save icon at the top of the Customization tool.
