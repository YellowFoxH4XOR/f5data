K000156030: Importing BIG-IP GTM (DNS) devices with large WideIP configurations in BIG-IQ fails

Type
Support Solution
Published
2025-09-16
Updated
2025-09-16
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000156030

Description

BIG-IQ device discovery and import fails with "network communication failed due to protocol error" and "SocketTimeoutException" when importing GTM devices with large WideIP configurations.

Environment

  • DNS
  • Discovery
  • Import
  • Devices with very large WideIP configurations

Cause

The default BIG-IQ socketTimeoutMillis (305s) is insufficient for importing GTM devices with very large WideIP configurations, causing protocol errors and timeouts during discovery.

Recommended Actions

1.Increase the timeout in BIG-IQ of "socketTimeoutMillis" in "var/config/rest/config/restjavad.properties.json" file  (by default, it is 305 seconds) to 480 seconds using nano or vi editor as on example below:

{
"version":"5.4",
"platform" :
{
.......
"apacheAsyncClient" :
{
"maxIdlePooledConnectionTimeoutMillis": "45000",
"socketTimeoutMillis": "480000"
},
........
}
}

2.After changes restart the restjavad process so the changes can be applied:

bigstart restart restjavad
