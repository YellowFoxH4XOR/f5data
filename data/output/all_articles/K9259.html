Topic

This article applies to BIG-IP 9.x - 10.x. For information about other versions, refer to the following article:

  • K13151: Configuring the rate at which the BIG-IP system issues TCP RSTs or ICMP unreachable packets (11.x - 12.x)

The TM.MaxRejectRate database key can be used to reduce the effects of a denial-of-service attack (DoS) on the BIG-IP system. The database key allows you to limit the number of TCP RSTs or Internet Control Message Protocol (ICMP) unreachable packets that the BIG-IP system sends in response to incoming client-side or server-side packets that cannot be matched with existing connections to traffic management listener IP addresses, such as virtual servers or secure network address translations (SNATs).

The default value for the TM.MaxRejectRate database key is 250 TCP RSTs or 250 ICMP unreachable packets per second. The minimum value allowed is 1 and the maximum value is 1000. To configure the TM.MaxRejectRate database key, type the following command:

bigpipe db TM.MaxRejectRate <value>

TCP

When the TM.MaxRejectRate threshold has been exceeded for TCP, the BIG-IP system stops sending TCP RST packets in response to unmatched packets, and logs a message to the /var/log/ltm file that appears similar to the following example:

tmm tmm[1609]: 011e0001:4: Limiting closed port RST response from 299 to 250 packets/sec

When the BIG-IP system receives a packet matching a traffic management listener IP address and port or self IP address and port, but the packet is not a SYN packet and does not match an established connection, an error message that appears similar to the following example is logged to the /var/log/ltm directory:

011e0001:4: Limiting open port RST response from <number> to <number> packets/sec

When the BIG-IP system receives a packet matching a traffic management listener IP address or self IP address, but the packet specifies an invalid port, an error message that appears similar to the following example is logged to the /var/log/ltm directory:

011e0001:4: Limiting closed port RST response from <number> to <number> packets/sec

ICMP

When the TM.MaxRejectRate threshold has been exceeded for ICMP, the BIG-IP system stops sending ICMP unreachable packets in response to unmatched packets, and logs a message to the /var/log/ltm file that appears similar to the following example:

tmm tmm[1609]: 011e0001:4: Limiting icmp unreach response from 299 to 250 packets/sec

Note: For more information about preventing DoS attacks, refer to K7301: Protecting the BIG-IP system against denial-of-service attacks (9.x - 11.3.x).

Note: In BIG-IP 10.0.0 and 10.0.1, the system does not log an error message when the TM.MaxRejectRate threshold is exceeded. For more information, refer to K11021: The BIG-IP system does not log an error message when the TM.MaxRejectRate threshold is exceeded.
