Topic

This article applies to BIG-IP 15.1.0 and later. For information about other versions, refer to the following articles:

  • K17441: Viewing Client SSL profile connection data (12.x - 15.0.x)

You should consider using this procedure under the following condition:

  • You want to view connection and statistical information for the Client SSL profile.

Description

Beginning in BIG-IP 15.1.0, the SSL statistics are improved to better reflect SSL connection and statistical information for the client SSL profiles. The BIG-IP system displays SSL connection-related data in a table format similar to the following example.

ConnectionsOpenMaximumTotal
Native12011002000

Field descriptions

  • Open represents the number of currently open SSL connections.
  • Maximum represents the highest number of SSL connections at one time.
  • Total represents the cumulative number of SSL connections after a system restart or statistics reset.
  • Native represents the number of SSL connections using the BIG-IP system's NATIVE SSL stack.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have access to the TMOS Shell (tmsh), or the Configuration utility.

Procedures

    Viewing SSL connection statistics for the Client SSL profile using tmsh

    1. Log in the TMOS Shell (tmsh) by typing the following command:

      tmsh

    2. To view connection statistics for a Client SSL profile, use the following command syntax:

      show ltm profile client-ssl <profile_name> | grep -m 1 Connections -A 2

      For example, to view connection statistics for a Client SSL profile named example_ssl, enter the following command:

      show ltm profile client-ssl example_ssl | grep -m 1 Connections -A 2

      Example output:

      Connections                  Open   Maximum  Total
        Native                     120       1100   2000

    Viewing SSL connection statistics for the Client SSL profile using the Configuration utility

    1. Log in to the Configuration utility.
    2. Go to Statistics > Module Statistics > Local Traffic.
    3. For Statistics Type select Profiles Summary.
    4. Under Global Profile Statistics, for Client SSL, select View.
    5. Locate the Connections table.
