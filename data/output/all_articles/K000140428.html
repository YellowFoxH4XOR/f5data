Description

When you try to create a local user on your device you may encounter this type of error in GUI:

01070101:3: Can't change username for user <user> (user <user> has no UID)

Environment

  • BIG-IP Virtual Edition

Cause

System can't create a user because of existing reference to that account in /etc/shadow file.  

Recommended Actions

1. Check if there is reference of the user you want to create:

# cat /etc/shadow

2. Make a backup of shadow file with:

# cp /etc/shadow /etc/shadow_bkp

3. Remove that reference with bash text editor from main shadow file and save changes (vi, nano).

4. Look for these files in /etc directory and remove them:

# rm -f passwd.lock

# rm -f shadow.lock

# rm -f group.lock

5. Try to create user via GUI, for now there shouldn't be a problem.
