Description

ASM out of memory error message coming up repetitively under /var/log/asm

2021 Feb 15 15:29:29 F5-XXX: 01310003:0: ASM out of memory error: event code P272

Environment

  • ASM
  • memory
Cause

This can be due to the asm system memory is growing beyond the resource provisioned. 
Response accumulation can cause asm to use more memory ,this can contribute  asm to reach out of memory situation. 
In some cases enabling  ‘Learn from response’ or 'Server Technology Detection'  in multiple policies can cause this. 

Here are the some other asm features which causes response accumulation :

Data guard
Dynamic parameters extractions
Login page learning
Server technologies
Response signatures
Dynamic session ID in URL

Recommended Actions

  • If the tmm memory usage is low then changing the LTM provisioning to 'None' will add more memory to HOST and can be used by ASM related processes.
    For more information  see following article :
    K17173140: Setting LTM Provision NONE does not disable licensed LTM functionality
     
  • If not necessary  disable ‘Learn from response’ and possibly other features which causes response accumulation
    Here is the steps to disable learn from response :
    1. Go to Security  ››  Application Security : Policy Building : Learning and Blocking Settings.
    2. In the dropdown on the right change it to Advanced.
    3. At the bottom there's option, Uncheck the "learn from response"
    4. Save and apply the policy
       
  • If not necessary disable 'Server Technology Detection'
    Here is the steps to disable 'Server Technology Detection'
    1. Go to Security  ››  Application Security : Policy Building : Learning and Blocking Settings.
    2. In the dropdown on the right change it to Advanced. At the bottom of the Policy Building Settings will be Server Technologies. Click the arrow to the left of that. Uncheck Enable Server Technology Detection.
    3. Save and apply the policy
