Description

When you troubleshoot Configsync issue, you may notice Configsync time in GUI Device Management >> Overview and tmsh command output of "show cm device-group" does not match.

GUI Configsync time
2019-Jan-16 02:58:40

# tmsh show cm device-group
----------------------------------------------------------------
CM::Device-Group
----------------------------------------------------------------
Group Name                       Failover
Member Name                      LTM1.example.com
Time Since Last Sync (HH:MM:SS)  00:11:07
Last Sync Type                   incremental-manual-sync
CID Originator                   /Common/LTM1.example.com
CID Time (UTC)                   2019-Jan-16 11:08:57
LSS Originator                   /Common/LTM2.example.com
LSS Time (UTC)                   2019-Jan-16 10:58:40

Environment

  • BIG-IP is a part of Device Group

  • BIG-IP's TimeZone is set the non-UTC timezone

Cause

On CLI, LSS Time and CID Time are displayed in UTC.
On GUI, Last time in Sync status for Device Groups and Configuration Time for device group members are displayed in the Timezone set configured on BIG-IP.
 

Recommended Actions
none
