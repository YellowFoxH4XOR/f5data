Description

Set up list of allowed Host names in Security >> Application Security : Headers : Host Names.

Policy is in Blocking mode.

Any value Host header is accepted.

How do we enforce an allowed list of Host names?

Environment

  • Version 12, 13, 14
  • HTTP Host header

Cause

In order to enforce Host names in BIG-IP AWAF, the Illegal host name violation must have Block enabled in the Learning and Blocking Settings.

The Illegal host name violation is not available until BIG-IP AWAF 15.1.0 and later.

Recommended Actions

Consider an upgrade to BIG-IP AWAF 15.1.0 or later.

In earlier releases, an iRule or traffic policy can be used for HTTP Host header enforcement.
