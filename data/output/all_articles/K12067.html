Topic

The BIG-IP Advanced WAF / ASM system checks that the cookie header length that does not exceed the length specified in the security policy.

Description

The BIG-IP ASM security policy verifies cookie boundaries for all incoming requests. You can configure the policy to block requests, log an alarm, and learn for requests containing an illegal cookie length violations. When you configure the policy to log an alarm and the system detects an illegal cookie length violation, the system logs the following error message to the /var/log/asm file and the Requests screen:

Illegal cookie length

Configure Learning and Blocking settings for cookie length violations

To configure Learning and Blocking settings for Illegal cookie length violations, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Select Cookies.
  4. For Illegal cookie length, select the check boxes for Block, Learn and Alarm, as needed.
  5. Select Save.
  6. Select Apply Policy.

Configure the maximum cookie header length

To configure the maximum cookie header length, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Security > Application Security > Security Policies > Policies List > <Security Policy Name>.
  3. Select Policy Configuration.
  4. Select General Settings.
  5. In the Basic HTTP Message Settings section, select Length for Maximum Cookie Header Length.
  6. Enter the maximum number of bytes to be allowed for a cookie's header length.
  7. Select Save.
  8. Select Apply Policy.
