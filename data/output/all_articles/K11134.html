Topic

When a user connects to the BIG-IP APM system, they are assigned a unique session ID. To locate a user’s session ID, perform one of the following three procedures:

  • Locate a user’s session ID from the BIG-IP command line
  • Locate a user’s session ID from the BIG-IP Configuration utility
  • Display a user’s session ID in the login sequence

Locate a user’s session ID from the BIG-IP command line

  • To locate an active session ID from the BIG-IP command line, enter the following command where <username> is the user name:

    sessiondump -allkeys | grep -i <username>

    The session ID appears at the beginning of each line of output. In the following example, the session ID for the user jsmith is 65a6b075:

    [root@APM1:Active] config # sessiondump -allkeys | grep -i jsmith
    65a6b075.session.assigned.uuid 26 tmm.uuid.AD-Basic.jsmith
    65a6b075.session.logon.ad_auth_and_resources_act_logon_page_ag.username 8 jsmith
    65a6b075.session.logon.last.username 8 taccount
    [root@APM1:Active] config #

  • To locate a session ID that is no longer active, search for the user name in the /var/log/apm file. The session ID is listed in the column to the left of the user name.

    For example:

    [root@3400a:Active] config # grep -i jsmith /var/log/apm
    Feb 10 12:52:15 local/3400a notice apd[6308]: 01490010:5: 50b8257c: Username 'jsmith'
    Feb 10 12:52:15 local/3400a notice apd[6308]: 01490103:5: 50b8257c: Retry Username 'jsmith'
    Feb 10 12:53:20 local/3400a notice apd[6308]: 01490010:5: 723d28dc: Username 'jsmith'
    Feb 10 12:53:20 local/3400a notice apd[6308]: 01490103:5: 723d28dc: Retry Username 'jsmith'
    Feb 10 12:55:22 local/3400a notice apd[6308]: 01490010:5: 65a6b075: Username 'jsmith'
    Feb 10 14:22:00 local/3400a notice apd[6308]: 01490010:5: 21e07b9a: Username 'jsmith'
    [root@3400a:Active] config #

    To search for session IDs through the archived /var/log/apm log files, use the following command syntax:

    zgrep -i <username> /var/log/apm*

Locate a user’s session ID from the BIG-IP Configuration utility

To locate a user's BIG-IP APM session ID from the Configuration utility, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Access > Overview > Active Sessions.

    Note: For BIG-IP 11.6 and 12.x, go to Access Policy > Manage Sessions.

  3. For Search, enter a search term. For example, enter a user name.

Display a user’s session ID in the login sequence

You may want to display session IDs to users during the login sequence. For example, if you want users to provide a session ID when contacting Support. To display the session ID during the login sequence, for Message, configure a message box action in the access policy with the session variable %{session.user.sessionid}.

For example:

Your session ID is %{session.user.sessionid}.

Note: For detailed instructions about configuring a message box action to display session variables, refer to K11123: Displaying session variables using a message box event.
