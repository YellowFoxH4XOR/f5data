Description

The systemd service unit for httpd shows a status of inactive (dead) after restarting httpd via bigstart restart httpd:

[root@bigip:Active:Standalone] config # systemctl status httpd
* httpd.service - LSB: start and stop Apache HTTP Server
   Loaded: loaded (/etc/rc.d/init.d/httpd; enabled; vendor preset: enabled)
   Active: active (running) since Mon 2023-11-13 09:54:39 GMT; 8s ago

[root@bigip:Active:Standalone] config # bigstart restart httpd
Stopping httpd:                                            [  OK  ]
Starting httpd:                                            [  OK  ]

[root@bigip:Active:Standalone] config # systemctl status httpd
* httpd.service - LSB: start and stop Apache HTTP Server
   Loaded: loaded (/etc/rc.d/init.d/httpd; enabled; vendor preset: enabled)
   Active: inactive (dead) since Mon 2023-11-13 09:55:06 GMT; 5s ago

Cause

This is currently expected.

This happens because httpd is being restarted outside of its systemd service unit when bigstart restart httpd is executed.
In this case, httpd is running, but systemd is no longer aware of it.

Bug ID1395349 tracks this behavior.

Recommended Actions

To confirm httpd is running, you can use the following commands:

bigstart status httpd

ps ax | grep '[h]ttpd'

If you would like to clear the stale state, restart httpd via its systemd service unit:

systemctl restart httpd
