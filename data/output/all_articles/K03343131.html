Known Issue

F5 SSL Orchestrator fails to process Internet Content Adaptation Protocol (ICAP) traffic.

This issue occurs when all of the following conditions are met:

  • Your SSL Orchestrator system is running version 13.0.0-2.3.
  • You configure an ICAP service using the IPv6 address of an ICAP server.
  • SSL Orchestrator processes a network request and attempts to send the request to the ICAP server.

SSL Orchestrator 13.0.0-2.3 supports IPv6 traffic processing and allows orchestrating IPv6 devices into the service chain. When this issue occurs, SSL Orchestrator cannot process ICAP traffic if the ICAP service is configured using the IPv6 address of the ICAP server.

Impact

SSL Orchestrator fails to process ICAP traffic when configured with an IPv6 ICAP server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SSL Orchestrator fails to process ICAP traffic when the ICAP servers are configured to use an IPv6 address. However, the system works as expected when the ICAP servers are configured to use an IPv4 address.

Workaround

To work around this issue, you can specify the IPv4 address of the ICAP server in the SSL Orchestrator configuration. With an IPv4 ICAP server configured, SSL Orchestrator can process IPv4 and IPv6 ICAP traffic from the client. When processing IPv6 ICAP traffic, the system translates IPv6 to IPv4 before sending the traffic to the IPv4 ICAP server.

Impact of workaround: The suggested workaround should have a minimal impact on system performance.
