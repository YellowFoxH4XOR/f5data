Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K15234: Adding trunked ports to a VLAN using the tmsh utility (11.x - 13.x)

To add trunked ports to a Virtual Local Area Network (VLAN) from the command line, you must complete the following procedures:

  • Creating a trunk
  • Enabling Link Aggregation Control Protocol (LACP) for the trunk
  • Creating a VLAN
  • Adding the trunk to the VLAN
  • Viewing the VLAN and trunk configuration

Creating a trunk

To create a trunk on the BIG-IP LTM system, type the following command:

bigpipe trunk <trunk_name> <interface key list>

For example, the following command creates a trunk named mytrunk, which contains interfaces 1.5 and 1.6:

bigpipe trunk mytrunk { interface 1.5 1.6 }

Note: The BIG-IP system allows up to eight interfaces in a trunk. F5 recommends that you use the exponent of 2 (for example: 2, 4, 8) for the number of interfaces in a trunk. Other numbers will work, but they will not be as efficient.

Enabling Link Aggregation Control Protocol (LACP) for the trunk

Note: Link Aggregation Control Protocol (LACP) is not required, but recommended if supported by both endpoints. LACP must either be enabled on both or disabled on both endpoints.

Note: Both endpoints of the trunk should also have identical LACP configuration, however, if both endpoints are set to Passive mode, LACP does not send control packets.

To enable LACP for the trunk, type the following command:

bigpipe trunk <trunk_name> lac enable

For example, the following command enables LACP in active mode for the trunk named mytrunk:

bigpipe trunk mytrunk lacp enable

Once you have configured the trunk, you can display the trunk configuration by typing the following command:

bigpipe trunk list

trunk mytrunk {
lacp enable
interfaces {
1.5
1.6
}
}

You can also view the trunk statistics by typing the following command:

bigpipe trunk show

trunk status bandw pkts pkts pkts pkts bits bits errors

              Mb/s   in  out drop coll   in  outmytrunk   UP  2000    0    6    0    0    0 6144      0

Note: The bandw Mb/s column shows the aggregate speed of the trunk. Each interface in the trunk is 1000baseT full, which makes the trunk capacity 2000 Mb/s.

Creating a VLAN

To create a VLAN, type the following command:

bigpipe vlan <vlan_name> tag <tag #>

For example, the following command creates a VLAN named myVLAN with a tag number of 4050:

bigpipe vlan myVLAN tag 4050

The VLAN tag is used for interfaces that are added as a tagged interface to the VLAN.

Note: When configuring a VLAN tag to be used with either tagged interfaces or tagged trunks, you must know the IEEE 802.1q VLAN tag number that corresponds with the tag on the upstream peer device, such as a Cisco switch.

Adding the trunk to the VLAN

You can add a trunk to a VLAN as either tagged or untagged.

Tagged

To add a trunk to a VLAN as tagged, type the following command:

bigpipe vlan <vlan_name> trunk tagged <trunk_name> add

For example, the following command adds a trunk named mytrunk to the VLAN myVLAN, as tagged:

bigpipe vlan myVLAN trunk tagged mytrunk add

Note: When adding a trunk to a VLAN as tagged, you must also configure the upstream peer device trunk to be tagged.

Untagged

To add a trunk to a VLAN as untagged, type the following command:

bigpipe vlan <vlan_name> trunk <trunk_name> add

For example, the following command adds a trunk named mytrunk to the VLAN myVLAN, as untagged:

bigpipe vlan myVLAN trunk mytrunk add

Viewing the VLAN and trunk configuration

Once you have added the trunk to the VLAN, you can view the VLAN configuration by typing the following command:

bigpipe vlan <vlan_name> list

For example, the following command enables you to view the VLAN configuration for a VLAN named myVLAN:

bigpipe vlan myVLAN list

When you add the trunk to the VLAN as a tagged resource, the keyword tagged will appear in the output similar to the following example:

vlan test {
tag 100
trunks tagged mytrunk
}

When you add the trunk to the VLAN as an untagged resource, the output will appear similar to the following example:

vlan test {
tag 100
trunks mytrunk
}

To view the VLAN statistics, type the following command:

bigpipe vlan <vlan_name> show

For example, the following command enables you to view the VLAN configuration for a VLAN named myVLAN:

bigpipe vlan myVLAN show
