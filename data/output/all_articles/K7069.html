Known Issue

This is the result of a known issue. When a version 5.x FirePass controller that has Application Tunnel Favorites containing more than one tunnel is upgraded to FirePass version 6.0.0, only one tunnel per Favorite is displayed in the Admin UI after the upgrade. However, all tunnels within the Favorite still exist.

You can see all tunnels listed when clicking on the arrow icon next to the Favorite name in the Application Tunnel Status pop-up window.

FirePass Application Access Application Tunnel Favorites contain one or more tunnels—combinations of IP address and TCP port.

An Application Tunnel Favorite for a Citrix ICA Web Client might consist of two tunnels, one for browsing the Citrix portal and one for the ICA connection. For example:

ClientRemote Host:PortLocal Host:Port
Customcitrix.f5.com:80127.10.13.67:80
Customcitrix.f5.com:2598127.10.13.67:2598

F5 Networks Product Development tracked this issue as CR65792, and it was fixed in version 6.0.1 of FirePass software. For more information about upgrading, refer to the FirePass Release Notes.

Additionally, a hotfix has been issued for version 6.0.0. This issue was fixed in cumulative hotfix 600-2. You may download this hotfix or a later version of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about how to obtain a hotfix, refer to K167: Downloading software from F5 Networks. For instructions about installing a hotfix, refer to K3430: Installing hotfixes.

Workaround

You can work around this issue by deleting the static Application Tunnel Favorite after upgrading to version 6.0.0, and creating a new static Application Tunnel Favorite with the same configuration.
