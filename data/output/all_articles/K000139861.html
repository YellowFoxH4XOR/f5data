Description

top command is showing the following:

top - 05:07:17 up 3 days, 5:10, 1 user, load average: 17.16, 16.86, 15.83

Tasks: 362 total, 6 running, 355 sleeping, 0 stopped, 1 zombie

 

ps aux | grep Z

USER   PID PPID %CPU %MEM  VSZ  RSS TTY  STAT START TIME  COMMAND

root  9390 9380 0.0 0.0 4.2M 612.0K ?  S May27 00:00:00.03 /etc/bigstart/scripts/tmm.start /var/run 8 8 0 --platform Z100 -m -s 10448

root  11536 9398 0.0 0.0  0  0 ?  Z May27 00:00:00.01 (mysql)

root  12500 9390 58.7 1.0 12.8G 158.5M ?  S May27 14:11:52.51 tmm.0 -T 8 --tmid 0 --npus 8 --platform Z100 -m -s 10448 

 

Environment

BIG-IP LTM

AVR

 

Cause

In this specific case is likely AVR DB was corrupted to lead mysql process failure.

 

Recommended Actions

1) Restart MySQL

bigstart restart mysql

 

2) If it does not improve then clear and reset the AVR database

touch /var/avr/init_avrdb; bigstart restart monpd
