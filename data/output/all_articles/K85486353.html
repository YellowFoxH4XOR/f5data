K85486353: Resetting FIPS to factory default

Type
Support Solution
Published
2021-07-08
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K85486353

Description

Resetting FIPS to factory default.

Environment

  • FIPS enabled hardware

Cause

None

Recommended Actions
 

  1. Log in to the command line.

  2. Use the following command syntax to stop all system services:

    Impact of procedure: Performing the following procedure will disrupt traffic handling.

    # tmsh stop sys service all
     

  3. Reset FIPS to factory default:


    # fipsutil -f reset

    ==================== WARNING ================================
    The FIPS device will be reset to factory default state.
    All keys and user identities currently stored in the device
    will be erased.
    Any configuration objects dependent on FIPS keys will cause
    the configuration fail to load.

    Press <ENTER> to continue or Ctrl-C to cancel

    Resetting the device ...

    The FIPS device is now in factory default state.
     

  4. Use the following command syntax to start all system services:


    # tmsh start sys service all

Additional Information

Options:
        -h ... Print this usage message.
        -f ... Force operation (override safety checks)
        -v ... Verbose output (for debugging).
