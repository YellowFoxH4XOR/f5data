K000152037: DoS Protection dashboard is not displaying data

Type
Support Solution
Published
2025-06-24
Updated
2025-06-24
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000152037

Description

DoS protection dashboard is empty.

This could be connected with having an external logging before, specifically BIG-IQ.

Environment

  • ASM
  • Dashboard: Behavioral DoS (it could also be other dashboards)

Cause

After removing the external logging (SIEM, BIG-IQ or something else) the settings on the BIG-IP are still pointing to send the logs externally.

Recommended Actions

To confirm your settings, run the following command on your BIG-IP

tmsh list analytics global-settings all-properties

 

The output should be something like this:

analytics global-settings {

  avrd-debug-mode disabled

  avrd-interval 300

  disable-all-internal-logging disabled

  ecm-address any6

  ecm-port 0

  enable-bigiq-configuration disabled

  external-logging-publisher none

  offbox-protocol none

  offbox-tcp-addresses none

  offbox-tcp-port 0

  partition Common

  source-id none

  tenant-id default

  trigger-configuration-update disable

  use-ecm disabled

  use-hsl disabled

  use-offbox disabled

}

 

If it is not, change the local logging settings to default by running the following commands:

1. Set the global-settings to default values.

tmsh modify analytics global-settings enable-bigiq-configuration disabled offbox-protocol none offbox-tcp-addresses none offbox-tcp-port 0 source-id none use-offbox disabled avrd-interval 300 ecm-port 0

 

2. Save the configuration:

tmsh save /sys config

Note: Running this command will not affect traffic, see article K14564 .
