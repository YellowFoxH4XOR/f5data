Known Issue

This is the result of a known issue. Adding a server that uses a translated IP address to the BIG-IP GTM system causes the gtmd process to core and continuously restart. This behavior prevents the use of any servers that require address translation, such as servers that are located behind a firewall.

F5 Product Development tracked this issue as CR78721, and it was fixed in BIG-IP GTM 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
