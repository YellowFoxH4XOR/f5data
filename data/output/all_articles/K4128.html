K4128: Reasons why 3-DNS may mark a host as down

Topic

3-DNS will mark host that it probes as down, under the following two conditions:

  • The probe receives no response.
  • The probe attempt fails.

When the 3-DNS probe does not receive a response from a host, it will mark the host down as soon as it reaches the configured maximum number of contact attempts.

When a probe fails, 3-DNS will mark the host down as soon as the TTL expires. A probe attempt fails when 3-DNS cannot send it. For example, if big3d is not running, all probe attempts will fail.
