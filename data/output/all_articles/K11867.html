Known Issue

This is the result of a known issue. If you click the Update button on the System > High Availability > Network Failover screen on an active BIG-IP unit, the unit switches to Standby mode. This issue occurs even if you did not make a configuration change prior to clicking the Update button.

F5 Product Development tracked this issue as ID 328317 (formerly CR140354) and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP LTM, APM, ASM, GTM, Link Controller, PSM, WebAccelerator, or WOM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1, which has been issued for BIG-IP 10.2.0. You may download this hotfix, later versions of the hotfix, or later versions of the BIG-IP system from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).
