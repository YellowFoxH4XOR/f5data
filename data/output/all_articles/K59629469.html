Description

License reactivation from the GUI fails with the error: Unable to Grant License Key: Error 0
This error comes up after the dossier is entered on https://activate.f5.com/license/dossier.jsp

Environment

  • BIG-IP
  • License reactivation

Cause

Unknown at the time of article creation.

Recommended Actions

Generate the dossier from CLI.

  1. Log in to CLI in bash mode and enter the below command:

    get_dossier -b <base registration key>

    Example:  get_dossier -b ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG

  2. Copy the dossier and proceed with the license reactivation either from the GUI or CLI. 

Additional Information

For the complete reactivation steps from CLI, refer to K2595: Activating and installing a license file from the command line.
