Description

  • In a Remote Desktop Protocol (RDP) connection, all features are allowed.
  • To disallow specific features, you can add in custom parameters to the RDP resources.
  • This outlines how to disable the copy and paste feature from one desktop across RDP sessions.

Environment

  • BIG-IP APM
  • Existing RDP configuration within APM

Cause

Without defining custom parameters in the RDP connection configuration, all features are available including copy and paste.

Recommended Actions

Add custom parameter to RDP resource to disable copy and paste

Note: This procedure is not officially supported as RDP users and malicious actors can find a way to bypass this control*. This is out of F5 support and you implement this at your own risk. F5 Product Development has assigned ID 423519 to track this issue.

You should consider disabling RDP users copy paste and file transfer on the RDP server. For more information, refer to How to disable users copy and paste and file transfer via RD Gateway.
This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

  1. Navigate to:
    Access  ››  Connectivity / VPN › VDI / RDP › Remote Desktops
     
  2. Click the RDP resource
     
  3. Under Custom Parameters, add in the following:
    redirectclipboard:i:0
     
  4. Click Update
