K000092473: Ingress Controller routing to different services using a single Transportserver resource

Type
Support Solution
Published
2022-10-19
Updated
2022-10-19
Source
https://my.f5.com/manage/s/article/K000092473

Description

You are looking to perform application level routing based on different versions of your application, but using a single transportserver resource to route both versions.
 

Environment

Kubernetes
Nginx+ Ingress Controller

 

Cause

Transportservers use Nginx stream, and only perform logical operations at layers 3 and 4.

Nginx cannot distinguish between two different apps using the same IP:PORT when using the transportserver resource

 

Recommended Actions

Move one of the applications to a separate TCP/UDP Port so Nginx can identify which application is being accessed, and route accordingly.
 

Additional Information

https://docs.nginx.com/nginx-ingress-controller/configuration/transportserver-resource/
