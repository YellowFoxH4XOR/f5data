Topic

This article applies to Enterprise Manager. For information about other BIG-IP versions, refer to the following articles:

  • K13121: Changing system maintenance account passwords (11.x - 15.x)
  • K3350: Changing system maintenance account passwords (9.x - 10.x)

You should consider using this procedure under the following conditions:

  • You want to modify the passwords for the root or admin users.
  • You want to reset a lost or forgotten root password.

Description

You should always modify the passwords for BIG-IP system maintenance accounts from their defaults. The procedures in this article provide multiple ways to modify the system maintenance account password to comply with password policies, standards such as PCI compliance, or other security policies appropriate to your organization. If you forget or lose the root password, you can reset it without reinstalling the system software.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • To modify the root or admin passwords, you must have either administrator or root-level access to either the Enterprise Manager Configuration utility or the command line, respectively.
  • To reset a lost or forgotten root password, you must have access to the Enterprise Manager serial console.

Procedures

  • Modifying system maintenance account passwords using the Configuration utility
  • Modifying system maintenance account passwords from the tmsh utility in Enterprise Manager 2.x or later
  • Modifying an administrative account password from the command line in Enterprise Manager 1.7.0 to 1.8.0
  • Resetting a lost or forgotten root password

Modifying system maintenance account passwords using the Configuration utility

To modify an administrative password from the Configuration utility or the command line, perform the following procedure:

Impact of procedure: None.

  1. Log in to the Configuration utility.
  2. From the System menu, select Platform.
  3. In the User Administration section, choose the Password field for either Root Account or Admin Account.
  4. Type the new password.
  5. Type the same password in the Confirm field for the account chosen in Step 3.
  6. Click Update.
  7. If you have updated the password for Admin Account, you will be logged out of the Configuration utility and will need to log in again using the new password.

Modifying system maintenance account passwords from tmsh in Enterprise Manager 2.x or later

To modify an administrative account password using the Traffic Management Shell (tmsh), perform the following procedure:

Impact of procedure: None.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To modify the password for the root account, type the following command:

    Note: If you need to modify the password for only the admin account, skip to step 5.

    modify auth password root

  3. When prompted, type the new root password.
  4. When prompted, retype the new root password to confirm.

    Note: If you need to modify the password for only the root account, skip the remaining steps.

  5. To modify the password for the admin account, type the following command:

    modify auth user admin prompt-for-password

  6. When prompted, type the new admin password.
  7. When prompted, retype the new admin password to confirm.
  8. To save the changes to the configuration files, type the following command:

    save sys config

  9. To exit the tmsh utility, type quit and press Enter.

Modifying an administrative account password from the command line in Enterprise Manager 1.7.0 to 1.8.0

To modify an administrative password from the command line, perform the following procedure:

Impact of procedure: None.

  1. Log in to the command line.
  2. Reset the administrative password by typing the following command:

    f5passwd admin

  3. When prompted, type the new administrative password.
  4. When prompted, retype the new administrative password.

    The system displays the following message:

    Changing password for user admin.
    passwd: all authentication tokens updated successfully.
    The ConfigSync users password has changed. You should change the password
    on the peer system as well.

Resetting a lost or forgotten root password

To reset a lost or forgotten root or support password, perform the following procedure:

Important: Due to a known issue in Enterprise Manager 2.0.0, you cannot use the passwd utility to change the root password when the system is running in single-user mode. For more information, and an alternative procedure, refer to K11190: The passwd utility fails to update the password for the root user when a connection to the MCP daemon cannot be established.

Impact of procedure: None.

  1. Boot the system into single-user mode.

    Note: For specific instructions, refer to K4178: Booting BIG-IP in single-user mode.

  2. Type the following commands:

    mount -a

    passwd <account>

    For example:

    passwd root

  3. When prompted, type a new password.
  4. Type exit or reboot to return to the normal operating mode.

After the system reboots, you should be able to log in using the new password.
