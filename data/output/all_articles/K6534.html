Topic

The Server HTTP header allows an HTTP server to provide information about the software the server uses to handle HTTP requests. The Server HTTP header field may contain product and version information, as well as comments identifying the server and any significant sub-products. While this information may be useful for some clients, it is considered unnecessary information leakage. As a result, the BIG-IP ASM system removes the Server HTTP header from responses to increase application security.

Certain web browsers may require the Server header to be present for authentication to the OWS. For example, Internet Explorer 7.x fails Digest Authentication with IIS 6.0 when the Server header is not present in the OWS response.

Note: Microsoft announced the end of support for Internet Explorer on June 15, 2022. You should use supported browsers, such as Microsoft Edge, Chrome, or Firefox.
