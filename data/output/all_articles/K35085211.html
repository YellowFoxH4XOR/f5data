Known Issue

The Thales installation script does not support Thales high availability (HA) in an HA pair.

This issue occurs when the following condition is met:

  • You use the Thales installation script for installing Thales in an HA pair.

Impact

The system does not install Thales on the other unit within the HA pair.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Thales is not installed on the other unit within the HA pair.

Resolution

Status

Workaround

To work around this issue, you can run the script on each chassis and blade that is part of the HA configuration.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
