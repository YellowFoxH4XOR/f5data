Known Issue

SSL Orchestrator may fail to install an RPM software package manager on BIG-IP systems when you upgrade using SSL Orchestrator Guided Configuration in the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You perform an upgrade from SSL Orchestrator 9.0.x to any newer version.
  • You perform the upgrade using SSL Orchestrator Guided Configuration in the Configuration utility. SSL Orchestrator > Configuration.

BIG-IP 16.0.x, 16.1.0, and 16.1.1 include SSL Orchestrator 9.0.x.

Impact

You cannot upgrade F5 SSL Orchestrator RPM software packages on these systems.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to upgrade, you observe an error message on the Configuration utility similar to the following:

    Invalid File. Cannot install f5-iappslx-ssl-orchestrator-16.1.1-9.2.noarch.rpm, package version should be 16.1.0-x.x.x and higher than 16.1.0-9.0.x

Workaround

To work around this issue, you can import the affected RPM software package manager using the Package Management LX page. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to iApps > Package Management LX.
  3. Select Import.
  4. Select Choose File and then select the RPM software package manager.
  5. Select Upload.
