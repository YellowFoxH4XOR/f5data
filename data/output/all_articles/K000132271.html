Description

How to upgrade the BIG-IP software running within a F5OS tenant.

 

Environment

  • VELOS or rSeries platform
  • F5OS-C or F5OS-A
  • BIG-IP running on F5OS tenant

 Recommended Actions

The steps to upgrade the BIG-IP software running on an F5OS tenant is the same as upgrading a hardware appliance or a Virtual Edition.

  1. Download the ISO image of the software version you wish to install from Downloads on MyF5.
    1. Not every software version supports running within a tenant.
    2. Look to see if the software version download options include an F5OS tenant image, this indicates that it supports running within a tenant.
    3. Download the standard ISO image, not the tenant image for upgrades. Tenant images are used only to initially deploy the VE within a tenant.
    Note: Prior to BIG-IP 14.1.0, no check is made to see if the image being installed supports running in a tenant, so it is possible to install a software version that cannot run in a tenant. This will result in an unusable tenant that will need to be redeployed.
  2. Log into the GUI of the BIG-IP on the tenant.
  3. Upload the image to System ›› Software Management : Image List, click Import button, click choose file and then click import
  4. Under Available Images tick / check the image, then click Install to launch the install wizard.
  5. Select disk  HD1 usually,  if this is a first upgrade you will need to type 2 in Volume set name to create the second partition "HD1.2", click on install, if this has been upgraded before you could now select volume set name 1 (HD1.1) to reuse it.
  6. System, Software management, Boot locations, click on the new HD1.2 (or back to HD1.1, is this was previously upgraded), click on install configuration (yes or no), click on activate
  7. Complete the install and reboot the tenant to the volume with the new software installed.

Important: F5 rSeries FIPS platforms r5xxx-DF and r10xxx-DF  only support tenants running BIG-IP software version 17.1.0.1 or later.

Additional Information

Note: it is not possible to upgrade a T1 tenant as there is insufficient virtual disk space, You will need to redeploy the tenant with the new software version and then restore the config from a UCS backup.
