Description
You activated the Catalog Key for the Flexible Consumption Program and need to license the BIG-IP Virtual Edition from BIG-IQ License Manager. 

Environment

  • BIG-IQ
  • BIG-IP Virtual Edition (VE)
  • Catalog (CAT) Key
  • License Offerings
  • Flexible Consumption Program (FCP)

Cause
The FCP uses CAT keys that provide a bundle of license offerings for BIG-IP VE.

Recommended Actions

To manage BIG-IQ FCP licenses and activate the license on the managed devices, follow the below procedure. 

Important: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration after license assignment. When licensing redundant BIG-IP systems, F5 recommends that you assign the license on your BIG-IP devices while they are in standby mode and during a maintenance window.

Note: By default, the BIG-IQ pulls in the current name of the BIG-IP. If this is a new BIG-IP, to avoid duplicate names in BIG-IQ, change hostname of the BIG-IP VE before licensing it. From BIG-IP command line, run "tmsh modify sys global-settings hostname <new host name here>" then "tmsh save sys config".

  1. Log into the BIG-IQ UI.
  2. Navigate to Devices at the top, then License Management.
  3. Click Licenses.
  4. Select the Catalog name to view available licenses. 
  5. Choose the desired license that you want to activate under Offering Name.
  6. Under Assignments, click License Devices.
  7. In Unit of Measure ensure you set this to YEARLY.
  8. Optionally add a Chargeback Tag if desired (useful when you get your usage reports).
  9. In Unmanaged devices, fill in the Device IP address, port (443), username and password. Otherwise, select the Managed device from the drop down menu.
  10. Click Assign. 
  11. Click OK.

You may view the BIG-IP device is licensed, to view management console, select the linked device name. 
You may provision the BIG-IP device from the management console. 

To revoke the BIG-IP license follow the below procedure

  1. Navigate to License Management > Assignments.
  2. Select the check box for the license you want to revoke. 
  3. Click Revoke.
  4. Enter the username and password of the device.
  5. Click Revoke.
  6. Click OK.
