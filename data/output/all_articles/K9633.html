Topic

Important: This article applies only to BIG-IP platforms that contain a Switch Card Control Processor (SCCP). To determine whether a specific BIG-IP platform contains SCCP, refer to K9476: The F5 hardware/software compatibility matrix. The Always-On Management (AOM) subsystem does not support remote logging; therefore, this article is not applicable to BIG-IP platforms with AOM.

By design, the SCCP does not store log files locally in non-volatile storage, and the files are lost if the SCCP is shut down or rebooted.

Since the SCCP is responsible for controlling the switch hardware, remote logging information reported by the SCCP can assist with monitoring or troubleshooting if an issue occurs with the system.

To configure remote logging, perform the following procedure:

Important: In order to be able to send its logs to a remote server, the SCCP must have access to the network. If you have not done this already, configure the SCCP network interface now. For more information, refer to K3753: Configuring the switch card control processor so that it can be accessed over the network.

Important: If your SCCP is version 12.0.8, refer to K11146: The SCCP version 12.0.8 cannot establish outgoing connections.

  1. Log in to the BIG-IP command line.
  2. To log in to the SCCP, type the following command:

    ssh sccp

  3. To change directories to the /etc directory, type the following command:

    cd /etc

  4. To add write permissions to the /etc/syslog.conf file, type the following command:

    chmod +w syslog.conf

  5. Edit the syslog.conf file and add the following content to the end of the file:

    Note: The SCCP includes the vi text editor only.

    # SCCP remote logging configuration
        local0.* @<ip address of remote logging server>

    For example:

    # SCCP remote logging configuration
        local0.* @10.0.0.25

  6. Save the changes made to the syslog.conf file.
  7. To remove write permissions to the /etc/syslog.conf file, type the following command:

    chmod -w syslog.conf

  8. To add write permissions to the /etcnvfiles.manifest file, type the following command:

    chmod +w nvfiles.manifest

  9. To ensure the remote logging configuration is kept across reboots, edit the /etc/nvfiles.manifest file and add the following content to the end of the file:

    Note: The nvfiles.manifest file specifies a list of non-volatile files that the SCCP saves to its flash memory and restores after a power cycle.

    /etc/syslog.conf

  10. To remove write permissions to the /etc/nvfiles.manifest file, type the following command:

    chmod -w nvfiles.manifest

  11. To force the SCCP to save its non-volatile files now, type the following command:

    /usr/bin/savenv
