K000163858: F5 SSL Orchestrator snapshot operations fail when device-group-failover state requires repair

Type
Support Solution
Published
2026-10-22
Updated
2026-10-22
Applies to
  • BIG-IP
  • BIG-IP SSL Orchestrator: 17.5.X, 17.5.0
Source
https://my.f5.com/manage/s/article/K000163858

Description

Snapshot restoration fails on F5 SSL Orchestrator running on BIG-IP 17.5.1 with:

Snapshot cannot be restored. Open the TMSH/ssh shell and review errors in /var/log/resnoded/restnoded.log and /var/log/ltm. Please retry restore or use the backup before restore to proceed. Error:

 

Snapshot creation on the active device also fails with:

There was an error creating the snapshot sloSS_GENERIC. Please try again.

 

Snapshot creation succeeds on the standby device.

 

Environment

  • F5 SSL Orchestrator on BIG-IP 17.5.1
  • Device group with active and standby devices
  • Snapshot restoration and creation fail on the active device
  • Snapshot creation succeeds on the standby device
  • f5-iappslx-ssl-orchestrator is registered through:
  • restcurl shared/iapp/installed-packages
  • Telemetry Streaming is not installed

Cause

The device-group-failover state requires repair. In the observed configuration, repairing this state with sslofix stopped the SSL Orchestrator snapshot warning. The available evidence does not establish a more specific underlying configuration defect.

 

Additional Information

The snapshot operation returned HTTP 500 for:

/shared/iapp/f5-iappslx-ssl-orchestrator/ssloSnapshot

with the following error:

Cannot save the snapshot when there is an error in the config

An earlier restore attempt also produced a REST API 400 error in /var/log/ltm and a java.lang.NullPointerException in restjavad.0.log.

 

Answer/Recommended Actions

Repair the device-group-failover state by running the following commands from the TMSH or SSH shell:

sslofix -D device-group-failover -H --diagnostic 2>&1 | grep -E 'warning:|error:|info:'

sslofix -D device-group-failover -H --dryrun

sslofix -D device-group-failover -H

After the repair completes, retry the snapshot restoration or creation operation. In the observed F5 SSL Orchestrator on BIG-IP 17.5.1 configuration, this sequence stopped the SSL Orchestrator snapshot warning.
