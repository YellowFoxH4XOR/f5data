Topic

You should consider using this procedure under the following conditions:

  • You want to access the Configuration utility from an external network using a BIG-IP APM Network Access tunnel.
  • You want to access the Secure Shell (SSH) from an external network using a BIG-IP APM Network Access tunnel.

Description

Depending on the configuration of your network environment, the Configuration utility or SSH may not be accessible from outside of your network. By configuring a virtual server on the internal network and using a BIG-IP APM Network Access tunnel, you can access the Configuration utility or SSH through a virtual server.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • The BIG-IP APM system must be configured with a Network Access policy.

Procedures

Configuring the Configuration utility virtual server

This procedure creates an iRule and virtual server that allows access to the Configuration utility using a Network Access tunnel.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
Important: Be aware that these steps can expose you to CVE-2022-33962.  If you need to take this action, it is also recommended to apply the mitigation in K80970653: BIG-IP iRules vulnerability CVE-2022-33962.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click the name of the iRule to edit
  4. In the Name box, type the following:

    adminui-irule

  5. In the Definition box, enter the following text:

    when CLIENT_ACCEPTED {
    node 127.0.0.1:443
    }

  6. Click Finished.
  7. Click Virtual Servers.
  8. Click Create.
  9. In the Name box type the following:

    adminui_vs

  10. In the Destination Address box, type the IP address on the internal network you want to associate with the Configuration utility.

    Note: This IP address will allow access to the Configuration utility. You should secure the virtual server to limit access.

  11. From the Service Port menu, select HTTPS.
  12. Scroll to the iRules section.
  13. From the Available list, click adminui-irule.
  14. Click <<.

    adminui-irule moves to the Enabled list.

  15. Click Finished.

Configuring the SSH virtual server

This procedure creates an iRule and virtual server that allows access to the SSH using a Network Access tunnel.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click the name of the iRule to edit
  4. In the Name box, type the following:

    adminssh-irule

  5. In the Definition box, enter the following text:

    when CLIENT_ACCEPTED {
    node 127.0.0.1:22
    }

  6. Click Finished.
  7. Click Virtual Servers.
  8. Click Create.
  9. In the Name box type the following:

    adminssh_vs

  10. In the Destination Address box, type the IP address on the internal network you want to associate with the BIG-IP SSH.

    Note: This IP address will allow access to the SSH. You should secure the virtual server to limit access.

  11. From the Service Port menu, select SSH.
  12. Scroll to the iRules section.
  13. From the Available list, click adminssh-irule.
  14. Click <<.

    adminui-irule moves to the Enabled list.

  15. Click Finished.
