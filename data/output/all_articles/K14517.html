Known Issue

The BIG-IP system may not generate link status SNMP traps for interface transitions.

This issue occurs when all of the following conditions are met:

  • A status change (Up/Down/Disabled) occurs for one or more of the interfaces.
  • The BIG-IP system is configured to send SNMP traps.
  • The BIG-IP platform is one of the following:

    • BIG-IP 4000 series (4000s, 4200v)
    • BIG-IP 2000 series (2000s, 2200s)

The /etc/alertd/alert.conf file is missing the following required alertd configuration entry:

alert BIGIP_PFMAND_PFMANDERR_LINKSTATUS {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.37";
}

Additionally, for BIG-IP versions prior to 11.4.0, the interface status information is not sent to syslog. For more information, refer to K14516: The BIG-IP system may not generate link state log messages for interface transitions.

Impact

SNMP management agents will not be notified of link state transitions.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H424881 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system fails to send an SNMP trap when a status change occurs for one or more of the interfaces.

Workaround

There is no workaround for BIG-IP versions prior to 11.4.0.

To work around this issue for BIG-IP 11.4.0 and later, you can create a custom SNMP trap entry. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Back up your /config/user_alert.conf file by typing the following command:

    cp /config/user_alert.conf /config/user_alert.conf.sol14517
  3. Using the text editor of your choice, open the /config/user_alert.conf file.
  4. Add the following SNMP trap entry:

    alert BIGIP_PFMAND_PFMANDERR_LINKSTATUS {
        snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.37";
    }
  5. Save the file and exit the editor.

Note: If the alertd process fails to start, examine the newly added entry to ensure that it contains all of the required elements and punctuation.
