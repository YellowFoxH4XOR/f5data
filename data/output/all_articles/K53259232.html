Issue

Old Behavior

In versions prior to BIG-IP 16.0.0, the volume size for the /var partition is 3.1 GB. For some BIG-IP deployments, the 3.1 GB volume size may be insufficient. For example, if your system has multiple BIG-IP modules provisioned and is processing a high volume of traffic, the /var partition size may be inadequate.

The following TMOS Shell (tmsh) output is from a BIG-IP VE system running version 15.1.2.1 and shows the /var partition size is 3145728K:

tmsh show sys disk directory

Directory Name                  Current Size    New Size
--------------                  ------------    --------
/config                         2273280         -
/shared                         15728640        -
/var                            3145728         -
/var/log                        3072000         -
/appdata                        26128384        -

New Behavior

Beginning in BIG-IP version 16.0.0, the logical volume size for the /var partition was increased to 4.7 GB.

This change applies to the following BIG-IP platforms:

  • Hardware based appliances
  • BIG-IP VE systems
  • BIG-IP vCMP systems

The following tmsh output is from a BIG-IP VE system running version 16.0.0 and shows the /var partition size is 4718592K:

tmsh show sys disk directory

Directory Name                  Current Size    New Size
--------------                  ------------    --------
/config                         2273280         -
/shared                         15728640        -
/var                            4718592         -
/var/log                        3072000         -
/appdata                        26128384        -

Impact

The logical volume size for the /var partition was increased by 50% in version 16.0.0 and later; systems running multiple BIG-IP modules have increased storage capacity.

Recommended Actions

If you have previously used manual procedures to resize the /var partition, you should reevaluate whether you need to continue to do so after upgrading to BIG-IP version 16.0.0 or later.
