Issue

Error Message

err mcpd[<PID>]: 0107004e:3: LTM configuration is not allowed when VCMP is provisioned. Virtual server </Partition/Virtual Server Name> conflicts with VCMP.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • </Partition/Virtual Server Name> is the partition name and virtual server name being reported as conflicting

For example:

err mcpd[5020]: 0107004e:3: LTM configuration is not allowed when VCMP is provisioned. Virtual server /Common/My_Virtual conflicts with VCMP.

Message Location

You may encounter this message in the following location[s]:

  • The /var/log/ltm file
  • The TMOS Shell (tmsh) command line
  • The Configuration utility

Description

This message occurs when the following condition is met:

  • You create or enable virtual servers while Virtual Clustered Multiprocessing (vCMP) is provisioned.

Impact

Virtual servers can't be used when VCMP is provisioned.

Recommended Actions

To work around this issue, you can delete all virtual servers when vCMP is provisioned.
