Description

After upgrading BIG-IP LTM, an SNMP trap containing the message "Failed to Create Catalog at tmm.session" may be sent. The related log entry from apmd is:

AccessPolicyProcessor/AccessPolicyProcessor.cpp func: "setCatalogKey()" line: 383 Msg: Initializing Config Snapshot Infrastructure, Failed to Create Catalog at tmm.session.f5f5f5f5f5f5f5f5f5f5f5f5f5f5f5f5

This event typically occurs during the system boot process.

Environment

  • Product: BIG-IP LTM.
  • Upgrade.
  • APM provisioned.

Cause

The SNMP trap and log message are generated when the apmd process attempts to connect to tmm (Traffic Management Microkernel) before tmm is fully initialized during system startup. This is expected behavior and does not indicate a malfunction.

Recommended Actions

  • If this log message and SNMP trap occur only once during boot or immediately after an upgrade, they can be safely ignored.
  • No further action is required unless these messages persist or recur during normal operation, in which case additional investigation should be performed.
