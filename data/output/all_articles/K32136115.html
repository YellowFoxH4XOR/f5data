Issue

Error Message

bcm56xxd[<PID>]: 012c0014:6: Exiting...

In this error message, note the following:

  • <PID> is the process ID for the bcm56xxd process.

For example:

bcm56xxd[5527]: 012c0014:6: Exiting...

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The bcm56xxd process shuts down as a result of the bigstart restart or bigstart stop commands.
  • The bcm56xxd process initiates a restart to facilitate an interface bundling change.

Impact

None. This message is informational only.

Recommended Actions

None
