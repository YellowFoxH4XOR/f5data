Known Issue

The TMOS Shell (tmsh) range filter displays unexpected or no results.

This issue occurs when one of the following conditions are met:

  • Your BIG-IP system is not configured to use the Coordinated Universal Time (UTC) time standard.
  • You attempt to filter BIG-IP system logs using the tmsh range filter in either of the following ways:
    • Filtering logs by the hour
    • Filtering logs for less than eight hours of information

Note: This issue occurs due to the tmsh range filter displaying results in the UTC time standard.

Impact

The tmsh range filter presents an unexpected range of data.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use tmsh range to filter by the hour, the results do not match the filter query.

    Note: In the following example, the displayed results are seven hours ahead, or the difference between the local time and UTC time.

    tmsh show sys log ltm range 01-30:12:00

    Sys::Log
    ltm 01-30 17:00:00 info two bcm56xxd[3456]: Link: 1.1 is DOWN

  • When you use the tmsh range filter to filter eight or less hours of logging for the current day, the system displays no results.

    For example:

    tmsh show sys log range now-8h

    No log message found that matches query. File may be empty

Workaround

To work around this issue, you can calculate the difference between the BIG-IP system time and UTC time and subtract the difference from the tmsh filter query. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure may impact your BIG-IP system if a large amount of log information is displayed and the BIG-IP system is experiencing high resource utilization.

  1. Log in to the Advanced Shell (bash).
  2. To determine the BIG-IP system time, type the following command:

    date

    Output appears similar to the following example:

    Wed Jun 14 12:00:00 PDT 2017

  3. To determine the BIG-IP system time in UTC, type the following command:

    date -u

    Output appears similar to the following:

    Wed Jun 14 19:00:00 UTC 2017

  4. Calculate the time difference between steps 2 and 3.

    The previous examples indicate that UTC is seven hours ahead of local time.

  5. Subtract the time difference from the tmsh range filter query.

    For example, to filter logging results to 12:00 (12pm), use 05:00 (5am), or seven hours earlier.

    tmsh show sys log ltm range 01-30:05:00

    Sys::Log
    ltm 01-30 12:00:00 info two bcm56xxd[3456]: Link: 1.1 is DOWN
