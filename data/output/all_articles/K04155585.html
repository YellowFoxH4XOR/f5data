K04155585: TFTP timeout when putting file to TFTP server.

Type
Support Solution
Published
2021-05-03
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K04155585

Description

  • Transfer timeout when putting file to TFTP server.

    For example:
    tftp> put TFTP.ucs
    putting TFTP.ucs to 10.10.10.10:TFTP.ucs [octet]
    Transfer timed out.
     
  • No file found in TFTP server

Environment

  • BIG-IP
  • Running software version is 15.x
  • Route to the TFTP server is set through management interface.
  • Reachable to TFTP server by ping.
  • UDP/69 is allowed between BIG-IP <-> TFTP server

Cause

TFTP traffic is dropped when using management interface to enhance BIG-IP security on K03126093.

Recommended Actions

  • Modify security firewall rule via GUI
  • Modify security firewall rule via CLI
Modify security firewall rule via GUI
  1. Log in to the Configuration utility.
  2. Go to System > Platform > Security.
  3. Click 'Add'
  4. Add the necessary information.
    - Name of the rule
    - Type -> Rule
    - State -> Enable
    - Protocol
    - Source -> Server IP address
    - Destination
    - Action
    - Logging (optional)
  5. Click 'Finished'
For example:
Name of the rule: ALLOW_TFTP_SERVER
Type: Rule
State: Enable
Protocol: Any
Source: Address - 10.10.10.10
Destination: Any
Action: Accept

Modify security firewall rule via CLI
  1. Modify security firewall rule to allow traffic through BIG-IP management interface:

    tmsh modify security firewall management-ip-rules rules add  { <name_Of_the_rule> { place-before first action accept ip-protocol any source { addresses add { <server_IP_address> { } } } } }
     
  2. Save the configuration:

    tmsh save /sys config

    For example:
    tmsh modify security firewall management-ip-rules rules add  { ALLOW_TFTP_SERVER { place-before first action accept ip-protocol any source { addresses add { 10.10.10.10 { } } } } }
    tmsh save /sys config
