Description

This article provides information on controlling whether or not the Citrix Remote Desktop Toolbar is displayed, when using the BIG-IP APM Webtop as a Storefront replacement. In this scenario, the BIG-IP APM Webtop and it's Remote Desktop object point to the Citrix server acts as a replacement client application for Citrix's Receiver and WebInterface clients.

As such, the BIG-IP APM Webtop and it's Remote Desktop object do not natively provide the kind of Remote Desktop configuration parameters that the Citrix Receiver and WebInterface provide to the Citrix server when they connect and establish an APM Session. 

However, you can configure the BIG-IP Remote Desktop object to include such configuration parameters using it's Custom Parameters field. And the BIG-IP will sends those Custom Parameters to the Citrix server when it initiates the Citrix Remote Desktop session to ensure that the resulting Remote Desktop session will use those parameters.

In this case, the Custom Parameter to be used to control whether or not the Citrix Remote Desktop Toolbar is displayed is shown below.

Example to ensure that the Toolbar IS displayed:
ConnectionBar=1

Example to ensure that the Toolbar is NOT displayed (or just don't specify this parameter):
ConnectionBar=0

Environment

Relevant environmental factors:

  • BIG-IP APM
  • Citrix Remote Desktop presented using an APM Webtop and Remote Desktop object.

Cause

None

Recommended Actions

The actions or steps required to ensure that the Citrix Remote Desktop sessions Toolbar IS displayed.

  1. Navigate to Access >> Connectivity / VPN >> VDI / RDP >> Remote Desktop and click on the pertinent Remote Desktop object.
  2. Add ConnectionBar=1 to the Custom Parameters field to ensure that the Citrix Remote Desktop Toolbar IS displayed when a Remote Desktop session is established.
  3. Then click the Update button to save the change to the Remote Desktop object's config.
  4. And finally, click Apply Access Policy in the upper-left corner to ensure that this changes is put into use by the Access Policy.

The actions or steps required to ensure that the Citrix Remote Desktop sessions Toolbar is NOT displayed.

  1. Navigate to Access >> Connectivity / VPN >> VDI / RDP >> Remote Desktop and click on the pertinent Remote Desktop object.
  2. Modify ConnectionBar=1 to ConnectionBar=0, or remove it entirely, in the Custom Parameters field to ensure that the Citrix Remote Desktop Toolbar is NOT displayed when a Remote Desktop session is established.
  3. Then click the Update button to save the change to the Remote Desktop object's config.
  4. And finally, click Apply Access Policy in the upper-left corner to ensure that this changes is put into use by the Access Policy.
