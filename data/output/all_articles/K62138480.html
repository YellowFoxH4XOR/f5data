K62138480: Interface status of the vCMP guest is uninitialized

Type
Support Solution
Published
2023-02-02
Updated
2023-09-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP i5000 Series
  • BIG-IP i7000 Series
  • BIG-IP i10000 Series
  • BIG-IP i11000 Series
  • BIG-IP LTM: 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K62138480

Description

You have deployed an vCMP guest and after it boots up, one of the interface shows as uninit when you execute command tmsh show net interface. For example:

# tmsh show net interface
--------------------------------
Net::Interface
Name  Status    --- snipped ---
--------------------------------
0.5       up
0.6       up
0.7       up
0.8   uninit
mgmt      up
#

Further more, you can find following log messages in /var/log/tmm:

notice start attach pde 0:7.0 if: 0.8
notice hsb0: F5 High Speed Bridge PDE device
notice Invalid VCMP PDE state version
notice No VCMP state found for interface 0
notice hsb0: F5 High Speed Bridge PDE device attach failed.

Environment

  • vCMP provisioned

  • TurboFlex Profile

  • BIG-IP i5xxx/i7xxx/i10xxx/i11xxx platform

Cause

Bug ID 1060149: BIG-IP vCMP guest data-plane failure with turboflex-adc selected on the host.

Recommended Actions

Upgrade the BIG-IP version to the fixed version of this ID or follow the procedures below:

Note: If there is UDP protocol based service or IPv6 based service or DoS vector related service on the vCMP guest, then following procedures will make it can not take advantage of ePVA feature.

  1. Execute command tmsh list sys turboflex on the vCMP host, the output should look like below:

sys turboflex profile-config {
    type turboflex-adc
}

  1. Execute command tmsh show sys turboflex profile all on the vCMP host to make sure you have turboflex-base available. The expected output looks like:

===========================================================================================
Sys::FPGA Turboflex Profiles:
===========================================================================================
PROFILE                     FEATURES

------------------------------------------------------------------------------------------------------------------------
turboflex-adc               epva-tcpipv4 epva-syncookie basic-tunneling epva-udp epva-ipv6 global-syncookie adv-tunneling
turboflex-base              epva-tcpipv4 epva-syncookie basic-tunneling adv-tunneling
...

  1. If turboflex-base is available, then change the turboflex profile to it with commands below:

# tmsh modify sys turboflex profile-config type turboflex-base
# tmsh save sys config

    Additional Information

    You may deploy multiple vCMP guests, but you may only see one of them has this issue.
