Description

The rSeries datasheet provides one Layer 7 requests-per-second (L7 RPS) value per model without the traffic profile and measurement criteria needed to reproduce or apply the result to production traffic.

Environment

  • BIG-IP LTM 17.5.1
  • Capacity planning using datasheet specifications for L7 RPS, Layer 4 connections per second, Layer 4 HTTP requests per second, concurrent connections, and throughput

Cause

The published L7 RPS value is based on controlled performance testing, but the datasheet does not specify the complete traffic profile or performance criteria. The exact test conditions for each model and software release may require confirmation from the performance-test team.

Answer/Recommended Actions

  • Treat the published L7 RPS value as a benchmark for a defined test profile, not as a guaranteed rate for all production traffic patterns.
  • L7 RPS values are based on controlled performance testing using standardized BIG-IP LTM scenarios, including full-proxy HTTP tests with varying numbers of requests per TCP connection.
  • Small request and response objects are commonly used for transaction-rate measurements. Separate throughput tests generally use larger objects.
  • For capacity planning, request the model- and software-release-specific performance test report or methodology through the F5 account team or Systems Engineer.
  • Confirm the following parameters in the applicable report:
    • HTTP Keep-Alive behavior
    • Requests per TCP connection
    • Request and response object sizes
    • HTTP version
    • TLS usage
    • Concurrent connections
    • Performance pass/fail criteria

Additional Information

Datasheet performance values are based on local traffic-management services and are subject to change.
