Topic

The BIG-IP APM system does not populate the session.assigned.clientip session variable until access policy processing is completed. This behavior prevents actions in an access policy from making decisions or displaying information based on the network access lease pool IP address assigned to the client by the BIG-IP APM system. This issue occurs because the client lease pool IP address is not assigned to the client until the access policy is fully processed.

To view the assigned IP address for a user, use one of the following procedures:

Locating a user's assigned client IP address from the BIG-IP Configuration utility

Note: The BIG-IP Access Policy logging level must be set to notice or lower for the assigned client IP address to be logged.

  1. Log in to the BIG-IP Configuration utility.
  2. Click System.
  3. Highlight Logs.
  4. Select Access Policy from the sub-menu.

    The Access Policy logs will display.
  5. In the Search field, enter the user's user name.
  6. Click Search.

    The Search results will display. Session IDs are displayed in the Session ID column.
  7. Click the Session ID that you want to view the client IP address for.

    The Session Summary window opens.
  8. Locate the Assigned PPP IP entry.

    In the following example, the user's assigned IP address is 10.10.10.56:

    Wed May 11 11:37:40 PDT 2011 notice 01490505 Assigned PPP IP: 10.10.10.56

Locating a user's assigned client IP address from the BIG-IP command line

Note: This procedure can only locate IP addresses for active user sessions.

  1. Log in to the BIG-IP command line.
  2. To obtain the user's session ID, use the following command syntax, replacing <username> with the user's user name:

    sessiondump -allkeys | grep <username>

    The session ID appears at the beginning of each line of output. In the following example, the session ID for the user jsmith is 65a6b075:

    [root@3400a:Active] config # sessiondump -allkeys | grep jsmith
    65a6b075.session.assigned.uuid 26 tmm.uuid.AD-Basic.jsmith
    65a6b075.session.logon.ad_auth_and_resources_act_logon_page_ag.username 8 jsmith
    65a6b075.session.logon.last.username 8 jsmith
    [root@3400a:Active] config #
  3. To obtain the session client IP address, use the the following command syntax, replacing <sessionid> with the session ID retrieved in step 2:

    sessiondump <sessionid> | grep assigned.clientip

    The client IP address is returned. In the following example, the client IP address assigned to the user jsmith is 10.10.10.56:

    [root@3400a:Active] config # sessiondump 65a6b075 | grep assigned.clientip
    65a6b075.session.assigned.clientip 11 10.10.10.56
