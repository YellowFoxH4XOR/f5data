Topic

Purpose

You should consider using this procedure under the following condition:

  • You want to ensure AOL clients are persisted to the same server when using source address affinity persistence.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • The virtual server is configured to use a source address affinity persistence profile.

Description

The America Online (AOL) network is connected to the Internet through several mega-proxies. These proxy servers assign arbitrary, frequently changing, IP addresses to AOL users. The mega-proxies may provide different IP addresses for each connection from a user. As a result, it is difficult to provide persistence to AOL users for protocols, such as HTTP, where multiple connections may comprise a single session.

You can ensure that AOL clients are persisted to the same server by configuring AOL as the proxy address data group setting and ensuring that the Map Proxies option is enabled in the source address affinity persistence profile.

To ensure that AOL clients are persisted to the same server by using the Traffic Management Shell (tmsh) in BIG-IP 11.x, perform the following procedures:

  • Configuring the proxy address data group by using the tmsh utility (11.x)
  • Ensuring that the Map Proxies option is enabled in the source address affinity persistence profile by using the tmsh utility (11.x)

To ensure that AOL clients are persisted to the same server by using the Configuration utility, perform the following procedures:

  • Configuring the proxy address data group by using the Configuration utility
  • Ensuring that the Map Proxies option is enabled in the source address affinity persistence profile by using the Configuration utility

Procedures

Configuring the proxy address data group by using the tmsh utility (11.x)

To configure the proxy address data group for the AOL proxies, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Configure the proxy address data group to use the AOL proxies by typing the following command:

    modify /ltm persistence global-settings proxy-group /Common/aol
  3. Save the change by typing the following command:

    save /sys config

Ensuring that the Map Proxies option is enabled in the source address affinity persistence profile by using the tmsh utility (11.x)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: The Map Proxies option is enabled, by default, in source address affinity persistence profiles.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Enable the Map Proxies option in the desired source address affinity persistence profile by using the following command syntax:

    modify /ltm persistence source-addr <profile name> map-proxies enabled

    For example, you would type the following command to enable the Map Proxies option in the mysource profile:

    modify /ltm persistence source-addr mysource map-proxies enabled
  3. Save the change by typing the following command:

    save /sys config

Configuring the proxy address data group by using the Configuration utility

To configure the proxy address data group for the AOL proxies, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Local Traffic > Persistence.
  3. From the Proxy Address Data Group menu, select AOL.
  4. Click Update.

Ensuring that the Map Proxies option is enabled in the source address affinity persistence profile by using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: The Map Proxies option is enabled by default in source address affinity persistence profiles.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Persistence.
  3. Select the Source Address Affinity profile associated with the virtual server.
  4. Select the Map Proxies check box.
  5. Click Update.
