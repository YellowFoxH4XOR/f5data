Description

This article provides a rough estimate of the minimum /var disk space required for BIG-IP AWAF upgrades.

Environment

This article applies to BIG-IP ASM only. Other BIG-IP modules are not covered.

Cause

none.

Answer/Recommended Actions

The rough calculation for minimal /var disk space for an ASM module would be as follow:

Disk space used in current /var partition + /var/ts size in UCS file + size of a freshly generated UCS

Here is an example of how to estimate the disk size:

Disk space used in current /var partition:

[root@bigip:ACTIVE:Standalone] ucs # df -h Filesystem Size Used Avail Use% Mounted on /dev/mapper/vg--db--vda-set.2.root 419M 76M 317M 20% / devtmpfs 3.9G 4.0K 3.9G 1% /dev tmpfs 3.9G 2.3M 3.9G 1% /dev/shm tmpfs 3.9G 2.3M 3.9G 1% /run tmpfs 3.9G 0 3.9G 0% /sys/fs/cgroup /dev/mapper/vg--db--vda-set.2._usr 6.4G 5.2G 887M 86% /usr /dev/mapper/vg--db--vda-set.2._config 2.1G 30M 2.0G 2% /config /dev/mapper/vg--db--vda-dat.share 15G 11G 3.0G 79% /shared none 3.9G 44M 3.9G 2% /shared/rrd.1.2 /dev/mapper/vg--db--vda-set.2._var 4.4G 2.5G 1.7G 60% /var <===2.5GB used!!! prompt 4.0M 28K 4.0M 1% /var/prompt none 3.9G 24M 3.9G 1% /var/tmstat /dev/mapper/vg--db--vda-dat.log 2.9G 117M 2.6G 5% /var/log /dev/mapper/vg--db--vda-dat.appdata 25G 4.0G 20G 18% /appdata none 3.9G 0 3.9G 0% /run/pamcache none 3.9G 0 3.9G 0% /var/loipc tmpfs 799M 0 799M 0% /run/user/91 tmpfs 799M 0 799M 0% /run/user/0

/var/ts size in UCS file:

[root@bigip:ACTIVE:Standalone] ucs # tar -tvzf freshly_generated.ucs | grep /ts/ | perl -e 'while(<>) { @a = split; $size += $a[2] } print qq{Total size = $size\n}'
Total size = 814457806 <== around 814MB

Size of a freshly generated UCS:

[root@bigip:ACTIVE:Standalone] ucs # ls -lh
total 786M
-r--r--r--. 1 root root  176 Jan 20 20:14 cs_backup_rotate.conf
-rw-r--r--. 1 root root 786M Feb 12 11:03 freshly_generated.ucs    <===around 718MB!!!
drwxr-xr-x. 2 root root 4.0K Jan 25 02:49 tmp

Therefore with above example: minimal /var disk space for the upgrade would be:

~2.5G + ~814MB + ~786MB = 4032MB
