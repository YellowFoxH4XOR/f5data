Description
The output of the tmsh show sys connection command can be confusing and it may not be clear from the documentation what the exact meaning of each column is. For example what does each column mean in the two entries below?

10.0.0.1:164     10.0.0.2:8      10.0.0.1:164     10.0.0.2:8      icmp  7   (slot/tmm: 1/0)  none

10.0.0.34:52344  10.0.0.38:80  10.0.0.1:52344  10.0.0.3:80  tcp  0  (tmm: 0)  none  none

Note: When displaying a protocol that is not port based the displayed information includes port values for the connection. For example the ICMP protocol does not utilize specific ports for communication:
Client port will record the ICMP Identifier (from the echo request packet) as the remote port
Server port will record the ICMP type code (echo request Type 8) as the local port

Note: The netstat or ss commands display control plane connections. These are connections that are handled by the Linux host system such as syslog, SNMP, ssh, httpd, etc. The tmsh show sys connection command displays data plane connections. These are connections that TMM is handling via a virtual server or another listener. For more information about control plane and data plane traffic refer to K44525501: Overview of BIG-IP data plane and control plane.

Environment

  • BIG-IP connection table

Cause

The following diagram and table explain each property in the connection table output:

                       Client-Side                                         Server-Side
-----------------------------------------------         -----------------------------------------------
   [Source IP:Port] [Destination IP:Port]   [Source IP:Port] [Destination IP:Port]    [Protocol] [Age] [Slot/TMM] [PVA Acceleration] [Neuron Rules]

 

ProxySectionDescription
Client-SideSource IP:Port
Destination IP:Port		Source IP:Port and Destination IP:Port that was received by the BIG-IP on the client-side. These are incoming connections into the BIG-IP initiated by a client
Server-SideSource IP:Port
Destination IP:Port		Source IP:Port and Destination IP:Port that was sent by the BIG-IP. These are outgoing connections initiated by the BIG-IP as the proxy. Typically these are load-balanced connections to pool members.
 ProtocolThis is the type of protocol being used. Possible values are udp, tcp, icmp etc.
 AgeThis column represents the idle-time for this connection and it will be updated if the BIG-IP receives additional packets for this connection. Timing is in seconds.
 Slot/TMMThis column represents info on which slot number and TMM instance was used for this connection.
 PVA AccelerationThis column indicates the degree to which PVA acceleration is utilized by this connection. If no PVA is used, the value would be displayed as none. Possible values are client-side, server-side, both-sides and none.
 Neuron RulesNeuron Rules status only appears on certain platforms that provide FIX protocol acceleration and Anti-DDoS security features such as BIG-IP iSeries platforms.


Recommended Actions

To view more detail in connection table output, you can append the all-properties option. To do so run the following command:
tmsh show sys connection all-properties
