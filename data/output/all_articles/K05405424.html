K05405424: Manually Checking the License Check Date

Type

Published
2021-03-04
Updated
2025-04-01
Applies to

Source

Description
Check the License Check Date before upgrading any BIG-IP or BIG-IQ system.

Environment

  • BIG-IP
  • BIG-IQ

Cause

When upgrading a BIG-IP or BIG-IQ system, the Service Check Date must be later (greater-than or equal-to) than the License Check Date.

Recommended Actions

Identify the License Check Date of a BIG-IP ISO from the Command Line of a BIG-IP

  1. Copy the ISO to /shared/images/ or upload the ISO through the GUI

  2. SSH to log into the Advanced Shell (bash) of the BIG-IP

  3. Run the following commands:
    Note: Change /shared/images/BIGIP-16.0.1.1-0.0.6.iso to the name of the ISO you want to verify.

    ISO=/shared/images/BIGIP-16.0.1.1-0.0.6.iso
    VERSION_DATE=$(isoinfo -f -R -i "${ISO}" | grep version_date)
    isoinfo -R -i "${ISO}" -x "${VERSION_DATE}"

    Example Output:

    20200616

    In this example, to be able to upgrade to 16.0.1.1, the Service Check date of your BIG-IP system must be 16 June 2020 or later.

    Note: The above output is YYYYMMDD

Additional Information

The License Check Date is the first date the Base ISO was released.

More information regarding License Check Dates can be found in K7727: License activation may be required before a software upgrade for the BIG-IP or Enterprise Manager system
