Known Issue

Launching multiple applications during a Citrix session may utilize additional Citrix sessions.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured to access Citrix applications.
  • When connected to the BIG-IP APM system, you use a Citrix XenApp version prior to 6.5 to access Citrix resources.
  • You launch multiple Citrix application sessions.

Impact

Citrix application sessions are not persisted to the same Citrix destination resource.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Citrix session license utilization increases based on the number of open applications.
