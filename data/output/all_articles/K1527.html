Issue

You may receive errors similar to the following in the /var/log/proxyd log file:

11:06:29.082683: Warning: 25400000 client SSL_accept()'s delayed due to SSL Gateway Level rate limiting. This is not proportional to the number of clients attempting to connect, however, some client connections have been delayed. Contact F5 to purchase additional SSL capacity.

This error indicates that you are using all of the SSL proxy licenses that you have available and that any additional connections are being rate limited. To eliminate this error message, upgrade your SSL proxy license to a higher gateway level.
