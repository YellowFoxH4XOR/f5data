Description

When is the file /var/ts/var/install/ucs_install.id created?

Environment

  • ASM provisioned
  • LTM provisioned
  • Sync enabled or UCS file loaded

Cause

/var/ts/var/install/ucs_install.pid is created
1. On UCS load
2. When asm_config_server starts but only under certain conditions not specified

Recommended Actions

None required.
