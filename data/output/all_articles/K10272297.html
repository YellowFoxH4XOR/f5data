Description
  • You are using Ansible module to collect UCS backups 
  • You can successfully generate UCS file from tmsh command or GUI  (graphical user interface)
  • Ansible playbook only fails to backup intermittently and on certain LTM instances
  • At the time of the failure, we note REST requests timing out,
  • we note the below logs in the restjavad log file
/var/log/restjavad.0.log
