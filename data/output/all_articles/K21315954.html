Known Issue

The BIG-IP SaaS Bot Defense profile erroneously limit the tenant ID to 12 characters.

This issue occurs when all of the following condition is met:

  • You attempt to enter a tenant ID that is more than 12 characters in the SaaS Bot Defense profile.

The BIG-IP SaaS Bot Defense profile is designed to work with the legacy F5 Cloud Services portal. The character and length limitations on some of the settings in the profile are imposed to work specifically with that platform. However, the new F5 Distributed Cloud (F5 XC) platform uses tenant IDs that are longer than 12 characters. As a result, you experience this error when you attempt to enter a F5 XC tenant ID in the Tenant ID setting of the SaaS Bot Defense profile.

Impact

You are unable to create a SaaS Bot Defense profile to work with F5 XC Bot Defense.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system reports an error similar to the following example:

    01db0003:3: The field (tenant-id) length should be (12) characters only.

Workaround

If you are attempting to create a SaaS Service Bot Defense profile to work with F5 XC Bot Defense, you can work around this issue by entering a dummy twelve character string into the Tenant ID setting and then use an iRule to replace the dummy tenant ID with your F5 XC tenant ID. To do so, perform the following procedure:

Note: This workaround assumes that you have already configured F5 XC Bot Defense and enabled on your application in the F5 XC Portal. If you have not done so, you may want to refer to the F5 Distributed Cloud Services Bot Defense documentation.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Login to the F5 Distributed Cloud Console Home page. Click the Bot Defense card. Select the three dots in the Actions column next to your application on the Applications page. Obtain the necessary information for your application, for example, App ID, Tenant ID, API Key, and so on. 

  2. Log in to the BIG-IP Configuration utility.
  3. Go to Local Traffic > iRules > iRule List.
  4. Select Create.
  5. Enter a name for the Name setting, for example, K21315954-workaround.
  6. Copy the following iRule syntax and paste it into the Definition setting:

    when HTTP_REQUEST {
      HTTP::header replace "sed-api-tenant-id" "<your-tenant-id>"
    }

    You should replace the <your-tenant-id> with your tenant ID from the F5 XC Portal.

  7. Select Finished to save the iRule.
  8. Go to SaaS Services > Bot Defense > BD Profiles.
  9. Select Create.
  10. Enter a profile name for the Name setting.
  11. In the API Request Settings section, enter a example tenant ID for the Tenant ID setting, for example abcdefghijkl.
  12. In the API Request Settings section, enter the rest of the settings with the information from the F5 XC Portal. For example, App ID for the Application ID setting, API Key for the API Key setting etc.
  13. In the Advanced Features section, select the iRule you have created in step 5 through 7 from the Available box and move it to the Enabled box.
  14. Configure the rest of the settings as needed. When you are ready, select Finished to save the profile.
