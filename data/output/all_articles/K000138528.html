K000138528: What is Network Tenant Interface (NTI) setting for VLAN?

Description

When using tmsh list command, you may come across a new "nti" setting. For example:

(/Common)(tmos)# list /net vlan all-properties

net vlan Internal {

  app-service none

  auto-lasthop default

  cmp-hash default

  customer-tag none

  dag-adjustment none

  dag-round-robin disabled

  dag-tunnel outer

  description none

  failsafe disabled

  failsafe-action failover-restart-tm

  failsafe-timeout 90

  fwd-mode l3

  hardware-syncookie disabled

  if-index 672

  interfaces {

    1.0 {

      app-service none

      tag-mode none

      tagged

    }

  }

  ipv6-prefix-len 128

  learning enable-forward

  mtu 1500

  nti 0   <========

  partition Common

  sflow {

    poll-interval 0

    poll-interval-global yes

    sampling-rate 0

    sampling-rate-global yes

  }

  source-checking disabled

  syn-flood-rate-limit 1000

  syncache-threshold 6000

  tag 938

}

 

Environment

  • All BIG-IP platforms, including VE, iSeries and VELOS/rSeries
  • v15.1.8 and later
  • v16.1.4 and later
  • v17 and later

Cause

None

Recommended Actions

None

Additional Information

NTI is a construct added for the VELOS/rSeries platforms, it is not supported on any other platforms.

The NTI is used in the L2-wire application for rSeries. It is used to forward traffic from one VLAN in a vlan-group to another.

An NTI value of 0 means that NTI is not in use. The NTI should not be changed by the user. Again, it’s only used on VELOS/rSeries and changing it on other platforms will produce unpredictable results.
