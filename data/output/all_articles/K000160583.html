K000160583: “Check Maximum Number of Parameters” Violation Shows Only Configured Limit

Type
Support Solution
Published
2026-04-02
Updated
2026-04-02

Source

Description

When the “Check maximum number of parameters” HTTP Protocol Compliance violation is triggered in BIG-IP ASM, the event logs and reports display only the configured maximum limit, not the actual number of parameters in the request.


For example, the violation message appears as:


"Number of parameters in request (query string and post-data) exceeded maximum limitation of <500>."


This means the system reports the threshold (500), but not how many parameters were actually sent.

Environment

  • Product: BIG-IP ASM (Application Security Manager)
  • Configuration: ASM policy with “Check maximum number of parameters” enabled
  • Condition: Requests exceeding the configured parameter limit

Cause

This behavior is introduced by Bug ID 1004801.


Starting from version 17, ASM stops parsing parameters once the configured limit is exceeded. As a result, the system no longer knows the total number of parameters in the request and cannot report it.

Recommended Actions

This is expected behavior. There is currently no workaround to display the actual parameter count in request.


Additional Information

This change was introduced to improve handling of large or abusive requests.
