Known Issue

This is the result of a known issue. If you edit an installed SSL server certificate and enter an intermediate certificate chain in the Optionally, put your intermediate certificate chain here (in the PEM format) field, FirePass sends the updated SSL server certificate to clients without the intermediate certificate chain.

Note: You can edit an installed SSL server certificate by selecting the Web Services tab on the Device Management: Configuration: Network Configuration page. Click the Configure SSL Certificates link, and then click the Edit link next to the SSL server certificate that you want to edit.

This issue occurs when the SSL server certificate you edited was not initially installed with an intermediate certificate chain. If you did configure an intermediate certificate chain when you installed the SSL server certificate, you can update the intermediate certificate chain by editing the SSL server certificate.

F5 Product Development is tracking this issue as ID 319252 (formerly CR95487).

Workaround

You can work around this issue by installing the SSL server certificate, along with its intermediate certificate chain, as a new certificate instead of editing the existing certificate. Once the certificate is installed, configure all SSL web services to use the new certificate instead of the old certificate. You can configure web services on the Device Management: Configuration: Network Configuration page under the Web Services tab.

Note: For more information about installing SSL server certificates and managing web services, refer to the FirePass Controller Administrator Guide.
