K06024717: Traffic disruption with OneConnect and Web Acceleration profiles on 16.1.x

Type
Support Solution
Published
2021-10-28
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.X, 16.1.3, 16.1.2, 16.1.0, 16.1.1
Source
https://my.f5.com/manage/s/article/K06024717

Description

Traffic is significantly delayed or fails completely.

A packet trace shows TCP resets with an f5ethtrailer reset cause of F5RST: HTTP internal error (bad state transition).

An error similar to the following is observed in /var/log/ltm:

err tmm[3182]: 011f0007:3: http_process_state_prepend - Invalid action:0x107030 serverside (10.10.10.8:443 -> 10.10.10.1:28741) clientside (10.10.30.100:4264 -> 10.10.30.5:443) (Server side: vip=/Common/https_vs_test profile=http pool=/Common/https_pool_test server_ip=10.10.10.8)

Environment

  • 16.1.x
  • OneConnect
  • Web Acceleration

Cause

Bug ID 1055097: TCP proxy with ramcache and OneConnect can result in out-of-order events, which stalls the flow.

Recommended Actions

Upgrade to a fixed version.

A workaround is to remove the Web Acceleration profile.

Additional Information

None
