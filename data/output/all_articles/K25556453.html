Description

You receive a Malformed XML data ASM violation, and the description shows Profile Configuration failed.

The learning system may make the following suggestion as a result of this:

Action: Add Content-Type:*xml* - Type: apply value and content signatures to Header-Based Content Profiles.

Furthermore, you will see repeated messages similar to the following in /var/log/ts/bd.log:

xml_validation.cpp:0244|Cannot allocate <x> more bytes for XML parser. current memory size <x> (in bytes)

Environment

  • Request with XML payload

Cause

The issue is caused by the XML processing engine running out of memory.

Recommended Actions

Increase the amount of memory allocated to the XML processing engine by making use of the total_xml_memory and additional_xml_memory_in_mb internal parameters. For more information, refer to the following article:

  • K10803: Customizing the amount of memory allocated to the BIG-IP ASM XML processing engine

Note: The value of total_xml_memory is represented in bytes, whereas the value of additional_xml_memory_in_mb is represented in megabytes.

Additional Information

You can check the current level of memory used in the XML processing engine with the following command:

tmctl -Pf /var/tmstat/blade/asm_memory_util_stats asm_memory_util_stats

Similarly, you can check memory used over the last ~2 days with the following command:

tmctl -D /shared/tmstat/snapshots/blade0 -T public -R 3600 asm_memory_util_stats -i -s time,total_xml_mem_used,total_xml_max_mem
