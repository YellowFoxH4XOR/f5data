Topic

You can control BIG-IP Edge client by using the command line interface when you access the BIG-IP APM system. You can access and control BIG-IP Edge Client interactively or use an API. If you use the command line interface, you can employ scripted applications to establish a network access connection and open one or more application tunnels.

Description

With the BIG-IP Edge Client command line interface, you can access and control BIG-IP Edge Client interactively. For more information, refer to the following sections:

  • Controlling BIG-IP Edge Client using the -start command
  • Controlling BIG-IP Edge Client using the -stop command
  • Controlling BIG-IP Edge Client using the -info command
  • Controlling BIG-IP Edge Client using the -profile command

Controlling BIG-IP Edge Client using the -start command

The -start command begins the BIG–IP APM controller session, logs on to the specified host, and automatically runs the Network Access favorites specified in parameters. You can use the -start command to begin a session with the BIG-IP APM controller, log on to the controller, and run one or more favorites. The command returns a 0 (zero) when successful, and writes the assigned session ID to stdout. You can specify that -start run in one of two modes.

  • Blocked

    Returns on failure or upon completion of a specified operation (for example, session establishment or favorite start).

  • Nonblocked

    Starts the specified operation and immediately returns a value, without waiting for the operation to complete. You can use the -info command to get operation status at a later time.

The -start command provides arguments for using a unique ID to start a session or favorite, or a name to start a favorite. The following table contains a list of the arguments that the -start command supports.

 
ParameterAliasValuesDescriptionComment
/config/cStringSpecifies the configuration profile file name.Uses the default program profile, if /conf is not specified.
/nonblock/nbNoneTurns on nonblocking mode.Returns immediately.
/host/h[http|https]host[:port] [/landing_uri]Represents the BIG-IP APM controller host name. 
/user/uStringIndicates the user name. 
/password/pStringIndicates the password. 
/quiet/qNoneQuiet mode will suppress all pop-ups and application messages.Available with BIG-IP Edge Clients starting with the BIG-IP APM release 11.4.0.
/userhex/uhStringIndicates the user name in hex-encoded format. 
/passwordhex/phStringIndicates the password in hex-encoded format. 
/mode/m[simple|advanced]Indicates the UI mode.Simple is the default mode.
/sid/sStringIndicates the session ID.Starts a favorite in an already established session. /sid is a required parameter. All other parameters are optional. You can use the -info command to get the /sid value.
/fid/fStringRepresents the favorites unique ID.You can use the -info command to get the /fid value.
/fname/nname[:{vpn|apptunnel|terminal}]Indicates the name of the favorite to affect.You can also specify a type if the name is not unique. You can use the -info command to get the /fname value.
/verbose/vNoneEnables verbose output to stdout. 
/minimize/tNoneMinimizes the window after start. 
/?-helpNoneShow help for using the -start commandIf the -start command is not specified, the system displays a list of f5fpc all commands.

Note: When the -start command values are not specified, the local user's device profile defaults are used, or a dialog box is presented.

The following examples demonstrate the use of the the -start command flag.

  • To show help for the -start command:

    f5fpc -start -help

  • To view information about the session including session and favorite ID values:

    f5fpc -info

  • To run the standalone client in simple mode, and the system does not send a return value until the system authenticates the user and establishes the session:

    f5fpc -start /h BIG-IP APM.com:443 /u joe

  • To establish a session named corp and start the favorite named sales in nonblocking mode:

    f5fpc -start /nb /h BIG-IP APM.com /u joe /p password /m advanced /n corp:vpn /n sales:apptunnel

  • To start the favorite named sales in the already established session with a session ID of 15:

    f5fpc -start /s 15 /n sales:vpn

  • To Start the favorite whose favorite ID is 1 in the already-established session with a session ID of 345:

    f5fpc -start /s 345 /f 1

Note: You can get session and favorite ID values using the -info command. The following table contains a list of exit codes that the system returns when you run the -start command.

 
CodeDescription
0x0Operation completed successfully.
0x1User terminated operation.
0x2Authentication attempt failed.
0x4Auto launch operation failed.
0x8User attention requested.
0x10Favorite start failed.
0x100Error unknown.
0x200Parameter unknown.
0x300Parameter value incorrect.
0x400Session ID unknown.
0x500Favorite ID unknown.

Controlling BIG-IP Edge Client using the -stop command

The -stop command halts the BIG-IP APM controller session, or a specified favorite within an established session.logs on to the specified host. You can use the -stop command to terminate a session with the BIG-IP APM controller, or to terminate a session favorite. The command returns a 0 (zero) when successful, and writes the assigned session ID to stdout. The following table contains a list of the arguments that the - stop command supports.

ParameterAliasValuesDescriptionComment
/sid/sstringIndicates the session ID.Halts the session as well as all established favorites running in the session. /sid is a required parameter. All other parameters are optional.
/fid/fstringRepresents the favorites unique ID.You must also include the /sid.
/fname/nname[:{vpn|apptunnel|terminal}]Indicates the name of the favorite to affect.You must also include the /sid. You can also specify a type if the name is not unique.
/?-helpNoneShow help for using the -stop commandIf the -stop command is not specified, the system displays a list of f5fpc all commands.

Note: You can get /sid, /fid, and /fname values using the -info command.

The following examples demonstrate the use of the -stop command.

  • To view help for the -stop command:

    f5fpc -stop -help

  • To close the Network Access connection whose session ID is 15, and halts all running favorites:

    f5fpc -stop /s 15

  • To Close the Network Access connection whose name is corp, and halt all running favorites:

    f5fpc -stop /s 15 /n corp:vpn

  • To stop the favorite with the unique ID 1 running in the session whose ID is 345:

    f5fpc -stop /s 345 /f 1

The following table contains a list of exit codes that the system returns when you run the -stop command flag:

 
CodeDescription
0x0Operation completed successfully.
0x100Error unknown.
0x200Parameter unknown.
0x300Parameter value incorrect.
0x400Session ID unknown.
0x500Favorite ID unknown.

Controlling BIG-IP Edge Client using the -info command

The -info command posts to the screen information about sessions and favorites. You use the -info command to retrieve details about the session and information about favorites based on the name of the favorite as with apptunnel, network access (vpn), and terminal sessions. You can use the -info command in conjunction with the -start and -stop commands. The following table contains a list of the arguments that the -info command supports.

  
ParameterAliasValuesDescriptionComment
/sid/sstringIndicates the session ID.For -info commands that do not contain a value for /sid, the operation returns a list of all sessions and statuses. For -info commands that contain a value for /sid, the operation returns a list of favorites and their status codes. For -info commands that do not contain a value for /fid or /fname, the operation returns a list of all favorites and status codes. For -info commands that contain a value for /fid or /fname, the operation returns information about only that favorite.
/fid/fstringRepresents the favorites unique ID.You must also include the /sid.
/fname/nname[:{vpn|apptunnel|terminal}]Indicates the name of the favorite to affect.You must also include the /sid. You can also specify a type if the name is not unique.
/?-helpNoneShow help for using the -info commandIf the -info command is not specified, the system displays a list of f5fpc all commands.

The following examples demonstrate the use of the -info command flag.

  • To view help for the -info command:

    f5fpc -info -help

  • To view all active sessions:

    f5fpc -info

  • Returns the status and list of favorites for sessions whose ID is 15:

    f5fpc -info /s 15

  • To view the session code status for session ID 15 and favorite type name 1:

    f5fpc -info /s 15 /f 1

  • To view the session favorite type name and code status for session ID 15 and favorite 1:

    f5fpc -info /s 15 /f 1

  • To view information about the favorite whose name is sales, for session ID 15:

    f5fpc -info /s 15 /n SALES:apptunnel

The following table contains a list of exit codes that the system returns when you run the -info command.

CodeDescription
0x0Operation completed successfully.
0x100Error unknown.
0x200Parameter unknown.
0x300Parameter value incorrect.
0x400Session ID unknown.
0x500Favorite ID unknown.

The following table contains a list of status codes returned for sessions.

 
codestatus
0x1Session established.
0x2Log on in progress.
0x4User must select the host from presented list.
0x8Auto launch in progress.
0x10User attention required.

The following table contains a list of status codes returned for favorites.

Controlling BIG-IP Edge Client using the -profile command

The -profile command returns information from the profile configuration file. The profile contains information such as BIG-IP APM controller IP address and gateway IP addresses. The -profile command provides an argument for specifying the configuration file name. The following table describes the /conf argument that the -profile command supports.

ParameterAliasValuesDescriptionComment
/conf/cstringRepresents the configuration profile file name.If no /conf value is specified, the operation uses the default current program profile.
/?-helpNoneShow help for using the -stop command.If the -profile command is not specified, the system displays a list of f5fpc all commands.

The following examples demonstrate the use of the the -profile command flag.

  • To show additional help for the -profile command:

    f5fpc -profile -help

  • To view information about the BIG-IP APM controllers configured in the default local profile:

    f5fpc -profile

    Example output:

    Name Address Port Description
    Main 44.58.251.1 443 The main gateway
    Asia 28.45.13.22 443 Asia gateway

The following table contains a list of exit codes returned when you run the -profile command.

CodeDescription
0x0Operation completed successfully.
0x100Error unknown.
0x200Parameter unknown.
0x300Parameter value incorrect.
