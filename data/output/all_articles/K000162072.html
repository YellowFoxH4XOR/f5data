Description

After the upgrade to 21.1.0, the client-ssl profile "options" became malformed, and config would not load.

 

 

Environment

- BIG-IP upgraded to version 21.1.0 from any earlier version.

- modified default client-ssl profile with custom "options".

- config not loading with error:

Syntax Error:(/config/bigip.conf at line: XXX) "options", invalid value "dont-insert-empty-fragmentsno-sslv3"

 

 

Cause

The upgrade process concatenates SSL option tokens in modified default client-ssl profiles, resulting in invalid values and syntax errors.

"dont-insert-empty-fragmentsno-sslv3" should be "dont-insert-empty-fragments no-sslv3" (notice the space between values).

 

ID2337369 was raised to address this issue.

 

 

Answer/Recommended Actions

Manually correct malformed SSL option strings in bigip.conf file (i.e. add the whitespace) before loading configuration.
