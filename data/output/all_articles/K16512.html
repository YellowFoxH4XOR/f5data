Topic

This article applies to LineRate 2.x releases.

The following matrix lists third-party software that runs on the LineRate operating system (LROS) on LineRate systems.

Kernel vs Application

OpenSSL and Node.js each have two versions installed on a LineRate system; one referred to as Kernel, and the other as Application.

  • Kernel version refers to the one that the kernel (operating system) was compiled against.
  • Application version refers to the one that the load balancing (proxy) application and other tools are using.

Important: LineRate maintenance releases may include upgrades and security fixes for the third-party software packages listed in the following table. When you evaluate vulnerability status for third-party software, F5 recommends that you refer to Security Advisory articles to determine if a LineRate release is vulnerable.
