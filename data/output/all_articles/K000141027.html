K000141027: Azure BIG-IP VE fail to start after changing the HD

Type
Support Solution
Published
2024-09-11
Updated
2025-04-01
Applies to
  • Public Cloud
  • BIG-IP
  • Microsoft Azure
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K000141027

Description

  • Azure VE fail to start after changing the VM disk
  • An error similar to the following appears when you try to start the VM:

    "Failed to start virtual machine 'azure-big-ip-ve'. Error: Unable to deploy from the Marketplace image or a custom image sourced from Marketplace image. The part number in the purchase information for VM 'azure-big-ip-ve/providers/Microsoft.Compute/virtualMachines/vm-wafedge-networking-core-ncus-01azure-big-ip-ve'>azure-big-ip-ve' is not as expected."

Environment

  • BIG-IP VE deployed in Azure
  • Replacing VM disk

Cause

If the BIG-IP VE original deployment image is still available on Azure's marketplace, then the issue is not F5 related.

Recommended Actions

If it is not possible to recover the VM with Azure assistance. We recommend to redeploy a new VM, and then restore the configuration from UCS.

Additional Information

To validate which BIG-IP VE images are available on Azure marketplace, you can run the following command on Azure CLI:

az vm image list --publisher f5-networks --offer f5-big-ip-byol --sku f5-big-all-2slot-byol --all --output table
