Known Issue

The BIG-IP Link Controller system does not report link throughput statistics.

This issue occurs when the following conditions are met:

  • The BIG-IP Link Controller system is configured in a high-availability pair.
  • Traffic traverses the links.

Throughput statistics are reported correctly on the standby BIG-IP Link Controller system; however, the active BIG-IP Link Controller system reports the throughput statistics as zero.

Impact

The BIG-IP Link Controller system does not enforce traffic limits for the affected links.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H435087 on the Diagnostics > Identified > Medium screen.
  • The active BIG-IP Link Controller system reports the throughput statistics as zero.
  • The BIG-IP Link Controller does not enforce traffic limits on the affected links.
