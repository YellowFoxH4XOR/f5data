Issue

3-DNS logs the following message each time an iQuery connection is made to the BIG-IP:

Jan 1 12:00:01 askf5 3dnsd: STATE:iqmTcpConnect: 
Connection in progress to 10.90.100.1:iqmgmt.c:502

When the connection is successful, 3-DNS logs a second message, similar to the following:

Jan 1 12:00:01 askf5 3dnsd: STATE:iqmFinishConnect: 
Connection complete to 10.90.100.1:iqmgmt.c:366

If you see the first message repeatedly and never see the second message logged, it indicates that the iQuery connection was not successful.

Check the status and configuration of the BIG-IP that receives the iQuery connection.
