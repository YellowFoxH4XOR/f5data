Description

  • You want to perform attack signature live updates under CLI

Environment

  • ASM module is licensed and provisioned in BIG-IP device

Cause

None.

 Recommended Actions

  1. Download the attack signature file from downloads.f5.com
  2. Upload the attack signature file with a SFTP Client to /var/lib/hsqldb/live-update/update-files/
  3. Change the permission and ownership of the attack signature file as follow:
    chown tomcat:tomcat /var/lib/hsqldb/live-update/update-files/ASM-AttackSignatures_20221229_154433.im
    chmod 644 /var/lib/hsqldb/live-update/update-files/ASM-AttackSignatures_20221229_154433.im
  4. Run command as follow in order to create a fileLocationReference in live update database.
    tmsh create mgmt tm live-update asm-attack-signatures update-files fileLocationReference { link '/var/lib/hsqldb/live-update/update-files/ASM-AttackSignatures_20221229_154433.im' }
  5. Run command as follow in order to check the availability of the newly created fileLocationReference of the attack signature file
    tmsh list mgmt tm live-update asm-attack-signatures update-files

    <...> mgmt tm live-update asm-attack-signatures update-files ff80808185ed3cb30185ed53be590001 {
    createDateTime "2022-12-29T15:44:33Z"
    fileLocationReference { link "https://localhost/mgmt/tm/live-update/file-transfer/downloads/ASM-AttackSignatures_20221229_154433.im" }
    filename "ASM-AttackSignatures_20221229_154433.im"
    id "ff80808185ed3cb30185ed53be590001"
    isFileAvailable true
    isFileManuallyUploaded true
    isGenesis false
    kind "tm:live-update:asm-attack-signatures:update-filesstate"
    md5 "6EF2AC165E37CBC1642587C24D15F43E"
    selfLink "https://localhost/mgmt/tm/live-update/asm-attack-signatures/update-files/ff80808185ed3cb30185ed53be590001"
    }
  6. Install the attack signature file with command below:
    tmsh modify mgmt tm live-update asm-attack-signatures installations ff80808185ed3cb30185ed53be590001 status INSTALL
  7. To query the installation status, run command below:
    tmsh list mgmt tm live-update asm-attack-signatures installations ff80808185ed3cb30185ed53be590001 status
    Example output:
    {
       status "install-in-progress"
    }
  8. When installation finished, you should see a new status by running the command again:
    tmsh list mgmt tm live-update asm-attack-signatures installations ff80808185ed3cb30185ed53be590001 status
    Example output:
    {
       status "install-complete"
    }
