Description

When creating a Regex even using one that is PCRE (Perl compatible Regex format), it is not valid and I want to know how the Distributed Cloud (XC) F5 regex works.

Environment

  • F5® Distributed Cloud HTTP Load Balancer 

Cause

  • Using PCRE for XC LB while XC LB uses Go Regex

Answer / Recommended Actions

F5 Distributed Cloud uses GO's standard regex https://pkg.go.dev/regexp.

To create a regex that will work with Distributed Cloud you can use the following web app. Please selecting the Golang syntax

https://regex101.com/
