Description

This article provides a basic overview of route advertisement with links in the following sections to configure it via BGP on other BIG-IP and F5 products.

Route Advertisement is a feature of Virtual Addresses whereby their value can be injected in the kernel routing table of the BIG-IP. This is typically used to allow the BIG-IP to make routing decisions based on them and more importantly, advertise them as an address or network out to routing peers so that those remote devices route traffic for that destination to the BIG-IP. With route advertisement, routes can be dynamically added or removed from the BIG-IP's kernel depending on the status of the Virtual Address.

In versions prior to 13, there are only two states, enabled and disabled. For more information, refer to K85543242: Additional virtual address Route Advertisement configuration options available.

There are four states a virtual address can be in: Unknown, Enabled, Disabled and Offline. When the virtual address is in Unknown or Enabled state, its route will be added to the kernel routing table. When the virtual address is in Disabled or Offline state, its route will be removed if present and will not be added if not already present. For more information, refer to K00409413: The BIG-IP system does not advertise advanced routing protocols when the system is disabled or offline.

Additional Information

By default BIG-IP will create a default kernel route entry with /32 subnet range for each virtual address enabled on the unit. When the virtual-address route advertisement is set to enabled, then the real subnet mask of this virtual-address will also be advertised to kernel, for example if we have a virtual-address with /24 configured, then the kernel route of this entry will remain /32 until we enable route advertisement.
