Description

An F5 Distributed Cloud HTTP Load Balancer public VIP may return “Listed by PBL” when checked against Spamhaus ZEN. As a result, an external domain-validation, onboarding or security process may reject the domain because the domain's DNS A record resolves to the listed public VIP.

Typical Spamhaus results may show:

  • PBL: Listed by PBL.
  • SBL: Not listed.
  • CSS: Not listed.
  • XBL: Not listed.
 A PBL only result is a mail policy classification and does not indicate spam, abuse, exploitation or malicious activity by the application.

Environment

  • F5 Distributed Cloud.
  • F5 Distributed Cloud HTTP Load Balancer
  • External domain-validation or security process using Spamhaus ZEN.

Cause

  • The public VIP belongs to an address range covered by a Spamhaus Policy Block List (PBL) classification. PBL is a policy-based list intended for email infrastructure and identifies IP ranges that should not directly send email to the Internet.
  • The issue occurs when a third-party domain validation process incorrectly applies a mail-policy reputation check to a web-facing DNS A record.

Resolution

A fix is available through either of the following approaches:

  • Submit a Spamhaus PBL delisting request for the affected VIP. https://check.spamhaus.org/
  • As last resource and for emergencies, provision a other public VIP, but first verify that it is not listed and update the DNS and Load Balancer configuration.

The preferred long term fix is to exclude PBL from web domain A record validation or validate the domain’s actual mail infrastructure instead.

Additional Information

  • PBL identifies addresses that should not directly originate mail; it is not a web-domain reputation list.
  • Replacing a VIP may require DNS changes and service migration.
  • A replacement address from the same regional edge space may be subject to the same policy and should be checked before deployment.
  • PBL range classifications can recur.
  • A VIP can be dedicated to one tenant while still being included in a provider address range covered by a policy list.
