Description

  • ASM security policy in transparent mode blocks/breaks forward proxy traffic

Environment

  • ASM security policy
  • Forward proxy

Cause

Seen behavior is expected.
The http CONNECT method is used when connecting to a forward proxy.
ASM doesn't support this type of deployment since the traffic is encrypted and ASM can't parse/enforce anything in that tunnel.

Recommended Actions

To allow traffic that works with the http CONNECT method we recommended to use the iRule below to disable ASM when CONNECT is detected.

  1. On the GUI navigate to: Local Traffic > iRules > iRule List
  2. Click on Create
  3. Give a name to the iRule and add the syntax below in the iRule definition

    when HTTP_REQUEST {
        if { [HTTP::method] eq "CONNECT" } {
            ASM::disable
        }
    }

  4. Apply the iRule to your virtual server by clicking on the virtual server name and going to the Resources tab.
