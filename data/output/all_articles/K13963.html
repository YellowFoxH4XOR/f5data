Known Issue

The system may incorrectly display BIG-IP management routes after you modify an existing management route.

Impact

The system incorrectly displays management routes when you use the ip route or netstat -r commands.

Symptoms

As a result of this issue, you may encounter the following symptoms after making changes to a non-default management route:

  • The tmsh commands list sys management-route and show sys ip-address correctly show the routing changes you have made.
  • The ip route and netstat -r commands indicate that the changes you made to a management route were applied to the default management route.

Workaround

Recovery

If you have already modified a management route and are affected by this issue, you need to save your configuration and reboot the BIG-IP system to recover. After you restart the system, the ip route and netstat -r commands correctly display the updated management route information.

Impact of workaround: A system reboot interrupts traffic, and you should perform the reboot during a maintenance window.

Note: Until you can reboot the system, you can use the tmsh list sys management-route command to view the configured management routes.

Prevention

To modify a management route without this issue occurring, you can delete and then re-create the management route instead of modifying it. To delete and re-create a management route, perform the following procedure.

Impact of workaround: Management traffic using the affected route is interrupted while you delete and re-create the route. You may need to perform these changes from a serial console or from an SSH session by using one of the BIG-IP switch ports.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To display the list of configured management routes, type the following command:

    list sys management-route

    For example, you may see output that appears similar to the following example:

    sys management-route 0.0.0.0 {
              gateway 172.29.21.1
              network default
          }
          sys management-route testroute {
              gateway 172.29.21.50
              network 2.2.2.0/24
          }

  3. Delete the route you intend to update using the following command syntax:

    delete sys management-route <routename>

    For Example:

    delete sys management-route testroute

  4. Re-create the route with the desired changes using with the following command syntax:

    create sys management-route <routename> gateway <gateway-ip> network <destination-network>

    For Example:

    create sys management-route testroute gateway 172.29.21.100 network  2.2.2.0/24

  5. Save the change by typing the following command:

    save /sys config
