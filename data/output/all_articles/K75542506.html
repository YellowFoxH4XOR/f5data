Description:

When using APM as a VPN server, some clients may not able to establish a connection.
The %temp%/logterminal.txt file on the Windows computer contains errors similar to the following:

HOST, 0,,,, starting local TunnelServer
HOST, 48, \HostCtrl.h, 829, CHostCtrl::OnStartTunnelServer, enter
HOST, 1, \HostCtrl.h, 929, CHostCtrl::OnStartTunnelServer(), (0x80020009) EXCEPTION - startServer() COM call failed, -2147352567
HOST, 1, \HostCtrl.h, 950, CHostCtrl::OnStartTunnelServer, EXCEPTION caught: CHostCtrl::OnStartTunnelServer() - EXCEPTION
HOST, 1, \HostCtrl.h, 1465, CHostCtrl::Failed, Failed to initialize local Tunnel Server (error: 0)
HOST, 48, , 367, CHostCtrl::ProxyClose(), enter
HOST, 48, , 283, CHostCtrl::PostProcessProxyDataThreadProc(), enter
HOST, 48, , 358, CHostCtrl::PostProcessProxyDataThreadProc(), Thread finished
HOST, 48, , 445, CHostCtrl::ProxyClose(), exit
HOST, 1, \HostCtrl.h, 1496, CHostCtrl::Failed, Firing OnError event (message: Failed to initialize local Tunnel Server)
HOST, 48, \HostCtrl.h, 966, CHostCtrl::OnStartTunnelServer(), exit

Environment:
  • BIG-IP APM
  • Network Access VPN in Full or Split Tunnel mode
  • BIG-IP Edge Client
  • Microsoft Windows
Cause:
Undetermined client Operating System issues

Recommended Actions:
  • Disable any proxy and connect to Internet Directly and then connect to VPN
  • Check if any network firewall is blocking the VPN connection
  • Check if any software firewall is blocking the VPN connection
  • Re-install corrupted Add-ons
  • Re-build client's OS
Disable any proxy and connect to Internet Directly and then connect to VPN
 
If the connection works after connecting to the Internet directly, then allow the VPN IPs in the proxy server or allow it without requiring any authentication.
 
Check if any network firewall is blocking the VPN connection

Firewall logs should show if the VPN connection was blocked. If this is found to be the reason, then add a firewall rule for the VPN IP addresses.
 
Software Firewall

Windows Firewall or any other Software firewall can also block the VPN. many of the modern Antivirus Softwares have an inbuilt firewall. Some other software that intercepts the network traffic like McAfee Intrusion Prevention can also block the VPN connection. To check this, disable all the software firewalls or any other software which intercepts and affects network traffic and then tries. If this turns out to be the issue, then allow your VPN IPs through the software firewall.
 
Re-install corrupted Add-ons

Sometimes, removing all the F5 components from the machine and then reinstalling them from fresh works. For more details, please refer to the link in section Related Content.
 
Re-build client's OS

If all of these steps failed, we have to re-build the client's Operation System to make the environment clean.
