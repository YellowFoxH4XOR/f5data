K000160645: BIG-IQ DCD ports 8020 and 8514 are down

Description

BIG-IQ Data Collection Devices (DCDs) fail to listen on ports 8020 (DoS Protection) and 8514 (Web Application Security/ASM), resulting in disruption of statistics collection for DoS Protection and Web Application Security services. Telnet tests confirm the ports are down.

Environment

  • Features: DoS Protection and Web Application Security (ASM) services configured on DCDs
  • Ports affected: 8020 (DoS Protection), 8514 (Web Application Security/ASM)
  • Condition: Ports not listening; services not collecting statistics

Cause

The DoS Protection and Web Application Security services on the affected DCDs were not properly activated, causing the Java-based logging listener process to not open ports 8020 and 8514.

Recommended Actions

  1. Navigate to System > BIG-IQ DATA COLLECTION > BIG-IQ Data Collection Devices in the BIG-IQ GUI.
  2. Select the affected DCD and click SERVICES.
  3. Confirm that:
    • DoS Protection (port 8020) shows as Active
    • Web Application Security (port 8514) shows as Active
  4. If either service is inactive or not functioning:
    • Deactivate the service from the GUI.
    • Reactivate the service from the GUI.
  5. Verify that the ports are now listening and services are operational.
