Description


We notice below APM debug logs for the session failing in /var/log/apm :

  • Rule evaluation failed with error: can't use invalid octal number as operand of "*"
  • session variable '<Session variable name>' not created due to invalid TCL Expression

Environment

  • APM 

Cause


The reason for this error is that one of the variables you are feeding into your expression is an octal value (meaning it starts with a 0). The expr command interprets numbers that start with 0 as an octal number, so it must be the case that whatever value is being fed to expr is a number that starts with 0 but is not a valid octal.

For example:
09 is not a valid octal number, and expr won't simply interpret it as an decimal 9 that's left-padded with a 0

Recommended Actions

Please refer https://wiki.tcl-lang.org/page/Tcl+and+octal+numbers to see how this can be fixed.
