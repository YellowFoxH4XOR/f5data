K000156874: How do I know BIG-IP Advanced WAF is configured on a virtual server with Server-Side Request Forgery (SSRF) protection?

Description

You want to determine if BIG-IP Advanced WAF is configured on a virtual server with Server-Side Request Forgery (SSRF) protection enabled. SSRF protection helps mitigate vulnerabilities where an attacker might abuse the server's functionality to access internal systems.

Environment

  • BIG-IP Advanced WAF
  • BIG-IP platform
  • Virtual server using HTTP or API-based traffic
  • WAF policy specifically configured for SSRF protection

Cause

SSRF protection is an essential feature of the WAF security policy, ensuring web application security against this attack vector.

Answer/Recommended Actions

  1. Log in to the BIG-IP configuration utility (GUI).
  2. Navigate to Security > Application Security > Security Policies.
  3. Locate the security policy attached to the virtual server.
  4. Within the policy details, check for the Attack Signatures and verify that SSRF-specific signatures are enabled:
    • Signature-based detection for SSRF exploits, such as Server-Side Request Forgery Attacks, should be enabled.
    • You can also look for bot defense settings and other correlated features to enhance SSRF mitigation.
  5. Alternatively, check these settings via CLI:
    • Run the following command to display WAF policies attached to the virtual server: tmsh list security policy.
  6. Verify the configuration of SSRF protection in the displayed policy details.
