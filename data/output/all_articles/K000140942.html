K000140942: tmsh show ltm virtual '/*/*' detail - fails with error

Type
Support Solution
Published
2024-09-04
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000140942

Description

  • Command tmsh show ltm virtual detail fails when a PingAccess profile is assigned to the virtual server
  • Running command tmsh show ltm virtual '/*/*' detail fails with an error similar to the following:

    The requested server SSL profile: virtual server object (/common/virtual_server:/common/ssl_profile) was not found

Environment

  • BIG-IP with APM provisioned
  • PingAccess profile assigned to virtual server
  • tmsh show ltm virtual detail

Cause

Seen behaviour is caused by a known issue tracked with Bug ID 799225 "tmsh show ltm virtual detail failed with PingAccess profile".

Recommended Actions

At the time of creation of this article, there is no fix available. Alternatively, you can use iControl Rest queries to get the virtual servers statistics

K30801544: Use iControl Restful API to gain availability status of a Virtual Server, Pool, Pool Member, or Node
