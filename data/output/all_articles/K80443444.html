Description

      When ucs file is created, GUI or CLI display similar to below messages:

tar: config/.diffVersions/config/bigip.conf/<filename>.patch: Cannot stat: No such file or directory
tar: config/.diffVersions/config/BigDB.dat/<filename>.patch: Cannot stat: No such file or directory
tar: Exiting with failure status due to previous errors
Fatal: executing: tar --no-recursion -rf /var/tmp/im<no>/configsync-<no>-Linux-<no>.im --no-unquote --files-from=/var/tmp/im.<no>/Files
Operation aborted.
/var/tmp/configsync.spec: Error creating package

WARNING:There are error(s) during saving.
Not everything was saved.
Be very careful when using this saved file!


Environment

  • BIG-IP V13.0.0 and later
  • Saving UCS archive.


Cause

       Bug ID755197: UCS creation might fail during frequent config save transactions

Recommended Actions

  • Follow workaround written in ID755197. 
  • If this issue occurs on Standby unit only while auto-sync is enabled for configsync, then disable auto-sync just before you attempt to create UCS for standby unit. After the success of creation, enable auto-sync.


Additional Information

      From BIG-IP V13.0.0, the BIG-IP systems keeps historical records of changed made to certain configuration files to /config/.diffVersions/ .
