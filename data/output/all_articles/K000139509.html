Description

Unable to configure security logging profile from CLI

 

The requested firewall log application (/<partition name>/<securitylog profile name>) was not found.

 

Environment

BIG-IP ASM

Security logging profile

Cause

Configuring security log profile in CLI requires partition name prefix

Recommended Actions

Use the following syntax to modify the profile

 

tmsh
