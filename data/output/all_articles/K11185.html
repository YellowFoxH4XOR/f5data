K11185: Configuring hundreds of branch rules for a single action may cause the mcpd process to crash

Known Issue

This is the result of a known issue. If you configure hundreds of branch rules for a single action, the mcpd process may crash when the access policy is initially loaded or applied. When this issue occurs, the BIG-IP system will also restart other daemons, briefly interrupting production traffic.

F5 Product Development tracked this issue as ID 327324 (formerly CR133234-1) and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes.

Workaround

You can work around this issue by configuring multiple actions or using iRules instead of configuring hundreds of branch rules for a single action.
