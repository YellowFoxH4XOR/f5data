K000151166: Application stopped working behind F5 LTM

Type
Support Solution
Published
2025-05-05
Updated
2025-05-05
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151166

Description

Application traffic is not going through the F5, but when bypassing the F5 the application works.


Environment

VIP with SSL Passthrough

http profile applied


Cause

HTTP profile on the VIP.

When an HTTP profile is on the VIP the F5 will wait for an HTTP request to come in from the client before it forwards anything to the pool member. This means SSL traffic (a Client Hello) from the client will not be passed to the pool and the SSL handshake will time out.


Recommended Actions

Remove the HTTP profile from the Virtual Server

OR

Configure a Client SSL profile and apply it to the Virtual Server.


Additional Information

None.
