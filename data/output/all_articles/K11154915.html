Description

The csyncd process is exhibiting higher CPU utilization than expected.

Environment

  • BIG-IP 
  • Multi-slot cluster system like VIPRION, vCMP guests, and VELOS tenants
  • High CPU
  • csyncd
  • iApps LX packages are installed

Cause

ID 1002969

The csyncd daemon checks all files indexed for updates. If it detects a change in file, it initiates a synchronization of it, and the more files to monitor, the busier it gets. An iApps LX package RPM is composed of many files, and they are located in a package directory under /var/config/rest/iapps. 

Recommended Actions

To determine if this is the cause of high CPU for csyncd, run the following command on the BIG-IP. It shows the number of files per iApps LX package directory.

(printf "Path Files\n----- -----\n";
for dir in $(find /var/config/rest/iapps/ -maxdepth 1 -mindepth 1 -not -path '*/RPMS'); do
  echo "$dir $(find "$dir" -type f -not -path '*~' |wc -l)";
done) | column -t

For example, output would look like below when 3 iApps LX packages DO, AS3, and Telemetry Streaming are installed.

Path                                              Files
-----                                             -----
/var/config/rest/iapps/f5-telemetry               9327    # Telemetry Streaming
/var/config/rest/iapps/f5-appsvcs                 1143    # AS3
/var/config/rest/iapps/f5-service-discovery       11818   # AS3's subpackage
/var/config/rest/iapps/f5-declarative-onboarding  1932    # DO

If a directory contains more than 1000 files, and the system is having high CPU usage by csyncd, the directory is a possible candidate of the workaround for ID 1002969.

Follow the procedure below to workaround the issue.

  1. Per K000140861, check if iApps LX files have been synchronized between blades and sync them when necessary.

  2. Perform the workaround like ID 1002969.

    1. Backup csyncd.conf.
      clsh "cp /etc/csyncd.conf /etc/csyncd.conf.$(date +%Y%m%d_%H%M%S)"

    2. Set TARGET_DIR and apply the ignore option. Change TARGET_DIR to the directory you want to ignore.
      TARGET_DIR="<target_dir>" bash -c 'clsh "sed -i \\\"/\/var\/config\/rest\/iapps/a\        ignore $TARGET_DIR\\\" /etc/csyncd.conf"'
      For example, the following command sets f5-appsvcs directory ignored.
      TARGET_DIR="f5-appsvcs" bash -c 'clsh "sed -i \\\"/\/var\/config\/rest\/iapps/a\        ignore $TARGET_DIR\\\" /etc/csyncd.conf"'

    3. Repeat step II for all the directories to exclude.

    4. Restart csyncd.
      clsh "bigstart restart csyncd"
