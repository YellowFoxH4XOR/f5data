Known Issue

Security Assertion Markup Language (SAML) single logout (SLO) fails when the Single Logout Response URL setting is not configured.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured as a SAML serviceprovider (SP) or Identity Provider (IdP)
  • A BIG-IP APM External SP Connector or External IdP Connector is configured for SLO
  • A URL is configured in the Single Logout Request URL field in the external connector but the Single Logout Response URL field is not configured with a URL

The Single Logout Request URL and Single Logout Response URL fields must both be configured in order for SLO to function properly. SLO fails when the SLO Service Settings for an external connector is only configured with a Single Logout Request URL.

Impact

SAML SLO fails.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H451480 on the Diagnostics > Identified > High screen.
  • When a user logs out of a SAML-authenticated application, the user will not be automatically logged out of the other applications authenticated by the SAML session.

Workaround

To work around this issue, you can configure both the Single Logout Request URL and Single Logout Response URL in the SLO Service Settings for the connector. To do so, perform one of the following procedures:

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Configuring the Request and Response URL for IdP Connector

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > SAML > BIG-IP as SP.
  3. Click the External IdP Connectors tab.
  4. Click the IdP connector to be configured.
  5. Click Edit.
  6. Click SLO Service Settings.
  7. Enter the remote URLs for Single Logout Request URL and Single Logout Response URL.
  8. Click OK.

Configuring the Request and Response URL for SP Connector

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Access Policy > SAML > BIG-IP as IdP.
  3. Click the External SP Connectors tab.
  4. Click the SP connector to be configured.
  5. Click Edit.
  6. Click SLO Service Settings.
  7. Enter the remote URLs for Single Logout Request URL and Single Logout Response URL.
  8. Click OK.
