Description

User can't access to Configuration Utilities (Web GUI). An example of error message from the /var/log/ltm may look like:

Oct 11 23:40:30 lb1.example.bigip.com err httpd[14640]: [mpm_prefork:error] [pid 14640] AH00161: server reached MaxRequestWorkers setting, consider raising the MaxRequestWorkers setting.

Environment

  • BIG-IP LTM
  • Configuration Utilities (Web GUI)

Cause

HTTP Service unresponsive 

Recommended Actions

Configuring MaxClients using the command line in BIG-IP 

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Assign the value of 20 to the MaxClients setting by typing the following command:

    modify /sys httpd max-clients 20

  3. Save the configuration by typing the following command:

    save /sys config

  4. Restart the httpd service by typing the following command:

    restart /sys service httpd
