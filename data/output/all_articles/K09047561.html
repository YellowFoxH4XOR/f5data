Topic

You should consider using these procedures under the following condition:

  • You want to view the current number of system-wide Traffic Management Microkernel (TMM) connections.

If you want to view current connection details, you can display the connection table. For more information refer to the following article:

  • K53851362: Displaying and deleting BIG-IP connection table entries from the command line

Description

If your BIG-IP platform has Clustered Multiprocessing (CMP) capability, the system runs multiple instances of TMM to speed up connection handling. The BIG-IP system distributes connections to a CMP-enabled virtual server among the TMM instances. Then, each TMM applies the pool load balancing algorithm independently.

For more information about CMP and an example of CMP-enabled virtual server behavior, refer to K14358: Overview of Clustered Multiprocessing.

You can view the number of connections each TMM is processing at a given time by using the TMOS Shell (tmsh) or tmctl, which can be helpful when troubleshooting.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have access to the Advanced Shell (bash) of the BIG-IP system.

Procedures

  • Using tmsh to view the current number of TMM connections
  • Using tmctl to view the current number of TMM connections
  • Creating an alias for the tmctl command
  • Making aliases permanent

To watch a video demo of these procedures, go to  Viewing current number of TMM connections from the BIG-IP command line.

You can view the current connections, along with other traffic statistics, by using a tmsh command.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To display the TMM traffic statistics, enter the following command:

    show /sys tmm-traffic

  3. Locate the Current Connections row for each TMM instance.

Using tmctl to view the current number of TMM connections

To view the current connections in simple output, you can use the tmctl command to display them from the tmm_stat table.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To display the slot ID (for VIPRION systems), CPU, client-side current connections, and server-side current connections columns from the tmm_stat table, enter the following command:

    tmctl tmm_stat -s slot_id,cpu,client_side_traffic.cur_conns,server_side_traffic.cur_conns

    In the previous command, note the following:

    -s <column>[,column] allows you to choose the columns that appear in the table.

Creating an alias for the tmctl command

You can create a short alias for the tmctl command. An alias is a method to reference another command with a name that you have chosen.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To create an alias for the tmctl command described previously, enter the following command:

    alias showTmmConns='tmctl tmm_stat -s slot_id,cpu,client_side_traffic.cur_conns,server_side_traffic.cur_conns'

  3. Enter the alias to execute the full tmctl command. You can use tab completion when entering the following alias:

    showTmmConns

  4. To prepend the watch command to the tmctl command, and combine them into an alias, enter the following command:

    alias watchTmmConns='watch tmctl tmm_stat -s slot_id,cpu,client_side_traffic.cur_conns,server_side_traffic.cur_conns'

  5. Execute the command by entering the following alias:

    watchTmmConns

  6.  To stop the running command, select Ctrl+C.

Making aliases permanent

You can add aliases to the ~/.bashrc file, so they are available upon subsequent logins. This file is included in a UCS archive, so it persists when you upgrade.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Use a text editor such as vi to open the ~/.bashrc file. For vi, enter the following command:

    vi ~/.bashrc

  3. In the # User specific aliases and function section, add the aliases described in the previous procedure.
  4. Save and close the file. For vi, enter the following command:

    :wq
