Description

Tmm logs are truncated when running a the kubectl log command against the tmm pod or deployment 
kubectl logs pod/f5-fsm-tmm
kubectl logs deploy/f5-fsm-tmm

Environment

  • BIG-IP Next Virtual Edition
  • You are logged into the console as root running kubectl commands

Cause

One of the following could be the cause:
  • A container in f5-fsm-tmm was restarted
  • The log file exceeded 300MB and the log file was rotated
 

Recommended Actions

Any of these actions will allow you to retrieve the full log file
  • If the file was rotated, the rotated log file can be found at /var/opt/f5/mbip-ve/f5-toda-logs/log
  • Use the API endpoint at /api/v1/systems/{{system_id_1}}/logs/
