K000164328: [Behavior Change] On 17.1.5.6 or earlier Advanced WAF does not raise signature violations for a single large JSON parameter value containing malicious strings, on 17.5.1.7 or later a violation is raised and the request is blocked.

Description

[Behavior Change] On 17.1.5.6 or earlier Advanced WAF does not raise signature violations for a single large JSON parameter value containing malicious strings, on 17.5.1.7 or later a violation is raised and the request is blocked.

Environment

Advanced WAF provisioned

JSON Body under/over 1MB sent

Cause

This behavior change is due to a fix for (Bug alias 2256725) "Disallowed file upload content detected" does not trigger file over 1MB."

Answer/Recommended Actions

Upgrade to 17.5.1.7 or later.
