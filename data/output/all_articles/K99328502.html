K99328502: BIG-IQ fails to backup the UCS archive to the remote server as per schedule

Type
Support Solution
Published
2021-09-01
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K99328502

Description

BIG-IQ fails to backup the UCS archive to the remote server.

The following error message are noted in /var/log/restjavad.0.log

Task <name_of_ucs_file> failed: to archive backup while making ssh connection to external_host_ip>java.net.NoRouteToHostException: No route to host (Host unreachable)

The Configuration Utility displays the following error message under System > BACKUP & RESTORE > Backup Files > Status

Backup Failed

Environment

  • BIG-IQ Centralized Management
  • Scheduled UCS backup

Cause

This issue happens when remote server is not reachable from BIG-IQ.
 

Recommended Actions

  1. Validate the IP address, credentials and directory of the external host as configured in 
    System > BACKUP & RESTORE > Scheduled Backup > Backup Archive

  2. Validate the external host is listening on port 22 for SCP or SFTP.

  3. Validate the directory configured to store backup archive in external server has read/write permissions.

  4. Validate  BIG-IQ has valid route configured  to reach the remote server IP address.

  5. Validate the SSH connectivity from the BIG-IQ to the remote server using below command
    # ssh <user>@<external_host_ip>

Additional Information

BIG-IQ does not retry the UCS backup task immediately after the failure, but the task is due for execution on the next schedule as configured under
System > BACKUP & RESTORE > Scheduled Backup
