K000130532: /var/named/lib is not mounted

Type
Support Solution
Published
2023-01-12
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.X.X, 14.1.X, 14.0.X, 14.0.1, 14.0.0, 14.1.2, 14.1.0, 14.1.5, 14.1.4, 14.1.3
Source
https://my.f5.com/manage/s/article/K000130532

Description

You may notice that /var/named/lib is not mounted.

For example, normally /var/named/lib is mounted since system is started :

[root@LTM1:Standalone] config # mount | grep named
[root@LTM1:Standalone] config #                         <---- no output !


Environment

・BIG-IP
 

Cause

named is disabled
 

Recommended Actions

You can check named status by the following command :

[root@LTM1:Standalone] config # tmsh show sys service named
named        down, manually disabled

Note : No action is needed if named is disabled in purpose.
 

Additional Information

None
