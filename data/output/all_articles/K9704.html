Topic

The capture and view packets utility allows the FirePass administrator to troubleshoot networking issues by capturing the network packets coming to and from the FirePass controller.

To capture and view packets, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Device Management: Maintenance: Troubleshooting tools: Network packet dump section.
  3. Select a network interface.
  4. Select the scope of the packets to capture: UDP, TCP, or all types of packets.
  5. Select the maximum number of packets to capture.
  6. Optionally, select a destination IP address.

    Note: An empty address field indicates that all traffic is captured.
  7. Optionally, select the Exclude your browser address option to filter out the traffic to your current browser.
  8. Optionally, select the Ignore broadcasts and Ignore ARP options to filter out broadcast and ARP requests.
  9. To start capturing traffic, click on the Please click here to start sniff the network traffic link. 
  10. In a pop-up window, wait until the maximum packet count is reached, or click the Stop link to terminate the dump.

    The packet dump screen appears.
  11. View the data inline, or click on the Click here to download the data link to analyze the packet dump file (.dmp) offline with an application, such as WireShark or tcpdump.

    Note: To view the data offline, you must have a copy of your SSL server private key to decrypt the data. For instructions about using the key, refer to the documentation from the application you are using.
  12. To view the data decrypted in your web browser, click the Click here to view the same data SSL-decoded link.
