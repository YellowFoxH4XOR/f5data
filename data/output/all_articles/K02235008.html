Description

In the /var/log/httpd/httpd_errors log file, you find the  following logs:err httpd[8528]: [error] [client <ipaddress>] AUTHCACHE Error writing cookie <CookieID> - No space left on device

err httpd[28109]: [error] [client <ipaddress>] AUTHCACHE Error writing cookie <CookieID> - No space left on device
err httpd[30698]: [error] [client <ipaddress>] AUTHCACHE Error writing cookie <CookieID> - No space left on device

There are several symptoms related to this issue:
  • Unable to access appliance through GUI.
  • Unable to perform Sync between an HA pair.
  • Unable to save UCS.
  • Unable to save QKview.

Environment

  • BIG-IP LTM
  • Disk Space Issue.

Cause

The issue is caused due to lack of space on disk volumes on inodes, for example in /var/run

Recommended Actions

Create a forcefsck file in the root directory

NOTE: This procedure allows you to schedule a file system check during the next reboot of the system by creating a blank file, named forcefsck, that resides in the / directory. The presence of the /forcefsck file causes the system to perform a file system check the next time the system boots.

  1. Log in to the command line.
  2. To create the /forcefsck file, type the following command:

    touch /forcefsck

    During the next reboot, the /forcefsck file causes the system to perform a file system check.

  3. If you want to reboot the system at this time, type the following command:

    reboot

Note: The /forcefsck file is deleted as the system boots and does not remain for subsequent reboots.
