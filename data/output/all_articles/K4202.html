K4202: Disabling the system_check script

Topic

Using SNMP, the system_check script checks fan speed, CPU temperature, and power supply status every two minutes. If the values exceed healthy thresholds, the script logs these events through syslog. These log messages are used to generate the corresponding SNMP traps of these events. If you do not need to monitor this information, you can disable the system_check script. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Using a text editor, edit the /etc/crontab file.
  3. Locate the line that appears as follows:

    */2 * * * * root /usr/local/bin/system_check -q

  4. Comment out the line by adding a number sign (#) to the beginning of the line. The line should now appear as follows:

    #*/2 * * * * root /usr/local/bin/system_check -q

  5. Save the file and exit the editor.

The system_check script will no longer run.
