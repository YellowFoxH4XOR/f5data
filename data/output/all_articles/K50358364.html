Description

How to configure ssl ciphers that are 256 bit or higher

Environment

  • BIG-IP LTM
  • Client SSL Profile or Server SSL Profile

Cause

None

Recommended Actions

Run the following command from the CLI to view the existing ciphers within the 'DEFAULT' group or another group if needed: 
tmm --clientciphers 'DEFAULT'

       ID  SUITE                            BITS PROT    CIPHER              MAC     KEYX
 0: 49199  ECDHE-RSA-AES128-GCM-SHA256      128  TLS1.2  AES-GCM             SHA256  ECDHE_RSA
 1: 49171  ECDHE-RSA-AES128-CBC-SHA         128  TLS1    AES                 SHA     ECDHE_RSA
 2: 49171  ECDHE-RSA-AES128-CBC-SHA         128  TLS1.1  AES                 SHA     ECDHE_RSA
 3: 49171  ECDHE-RSA-AES128-CBC-SHA         128  TLS1.2  AES                 SHA     ECDHE_RSA
 4: 49191  ECDHE-RSA-AES128-SHA256          128  TLS1.2  AES                 SHA256  ECDHE_RSA
 5: 49200  ECDHE-RSA-AES256-GCM-SHA384      256  TLS1.2  AES-GCM             SHA384  ECDHE_RSA


Note: This example is truncated. You device will return the full list of accepted ciphers when either of the commands are run.

Review the output and prepend an '!' to each cipher suite to be prohibited and a ':' between each one that is below 256 bit. Example:

tmm --clientciphers 'DEFAULT;!AES128-SHA:!AES128-GCM-SHA256:!ECDHE-RSA-AES128-GCM-SHA256:!ECDHE-RSA-AES128-CBC-SHA:!DHE-RSA-AES128-SHA'
       ID  SUITE                            BITS PROT    CIPHER              MAC     KEYX
 0: 49200  ECDHE-RSA-AES256-GCM-SHA384      256  TLS1.2  AES-GCM             SHA384  ECDHE_RSA
 1: 49172  ECDHE-RSA-AES256-CBC-SHA         256  TLS1    AES                 SHA     ECDHE_RSA
 2: 49172  ECDHE-RSA-AES256-CBC-SHA         256  TLS1.1  AES                 SHA     ECDHE_RSA
 3: 49172  ECDHE-RSA-AES256-CBC-SHA         256  TLS1.2  AES                 SHA     ECDHE_RSA


Note: This example is truncated. You device will return the full list of accepted ciphers when either of the commands are run.

Confirm ciphers are 256 bit or higher and apply the same string to the ssl profile.
