Description

How to read the License Activity Report from the Flexible Consumption Program (FCP).

Environment

  • BIG-IP VE (Virtual Edition) 
  • NGINX
  • SW-on-HW
  • Cloud Hosted 
  • BIG-IQ License Manager/Centralized Manager
  • Flexible Consumption Program (FCP)

Cause

This article serves as a reference guide for understanding how to interpret the usage reporting provided by an F5 Customer Success Manager (CSM).

Recommended Actions

The License Activity Report (LAR) is one of the two reports provided monthly and on-demand to FCP customers to show their usage. 
The LAR has two main sections:

  1. Monthly Run Rate Product Detail 
  2. License Activity Detail – with three sub-sections:
    • BIG IP VE Licensing Activity Details
    • Software (BIG-IP VE and NGINX)
    • Software on Hardware

    Monthly Run Rate Product Detail

    This section includes software (BIG-IP VE and NGINX) and software on hardware, based on what is used in the FCP. Both of these subsections follow the same layout.
     
      

    • Month-Year: This is the usage for this specific month of the year.
    • SKU Title (ex. F5-NGX-APP-PRT-ELA): This is the Product Name/SKU.
    • Annual Unit Price: This is the List Price to run a single instance of this SKU for one year.
    • Monthly Quantity (for SKU): How many full days of usage per BIG-IP VE this SKU was used during the month in question.
    • Total Price (for SKU): The List Price for a year.
    • Monthly Quantity: Sum of all Monthly Quantities for all SKUs during the month.
    • Total Price: Sum of the Total Price for all SKUs during the month.

    Important: Total Price listed in each SKU's section and the Total Price are both annual and not monthly costs. For example, if every month of the customer's term had 9 instances of F5-NGX-APP-PRT-ELA running in April, May, and June, they would expect to pay $54K List.

    Note: To determine how many instances were running for an SKU in a month, divide the SKU's Total Price by the SKU's Annual Unit Price.

    License Activity Detail

    This section shows details about the active instances' duration. For BIG-IP VE, it lists the active CAT SKUs, specific image SKUs, start and end dates, and the number of days they have been running. For NGINX and SW-on-HW, it shows the quantity of each SKU and tracks changes made to that quantity.

    BIG IP VE

    • Pool Reg Key: This is the license key for either a CAT SKU on BIG-IQ or a single BIG-IP VE on MyF5 Self Service. 
      • Typically the CAT SKU includes multiple image SKUs to denote multiple BIG-IP VEs and license offerings, whereas, there is a unique Pool Reg Key and single line per BIG-IP VE from MyF5 Self Service.
    • Business Unit: This is the description of the CAT SKU from BIG-IQ. It will be empty for the BIG-IP VE on MyF5 Self Service.
    • Image SKU: This is the Product Name for a specific SKU. 
    • Chargeback Tag: A configurable attribute that can be used for tracking usages for customer's administrative purposes (internal billing). It can be assigned during license activation from the BIG-IQ or updated from the Chargeback tag option within MyF5 Self Service.
    • ID: A unique identifier for a specific instance of an Image SKU
    • Grant Date and Time (GMT): When an Image SKU is assigned to a BIG-IP VE instance.
    • Revoke Date and Time (GMT): When an Image SKU was removed from a BIG-IP VE instance, stopping the license usage. The row for that instance will no longer be displayed in the following months.
    • Total Duration (Days): Number of days the license has been active

    NGINX

    This is called "Software".

     

    • As of Date: When the SKUs were at the indicated quantity.
    • Rating Platform Module: This is the Product Name for the specific SKU
    • Quantity: How many units of the SKU are active. This is cumulative so the value is taken from the most recent entry.

    Software on Hardware

     

    • As of Date: When these specific SKUs were at the indicated quantity.
    • Rating Platform Module: This is the Product Name for the specific SKU
    • Quantity: How many units of the SKU are active. This is cumulative so the value is taken from the most recent entry.
