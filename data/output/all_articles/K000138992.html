Description

After upgrade config failed to load due to the following error:

01070585:3: Virtual server (/Common/header.example-http) cannot reference rule (/Common/example_persist) more than once (check persistence, auth and rules).

Unexpected Error: Loading configuration process failed.

Environment

  • LTM
  • iRule
  • Upgrade

Cause

Unknown at the time of publication

Recommended Actions

Edit the bigip.conf and comment out the iRule lines:

ltm virtual /Common/header.example-http {

  destination /Common/192.168.1.6:80

 fallback-persistence /Common/source_addr

 ip-protocol tcp

 mask 255.255.255.255

 persist {

  /Common/example_persist       <<-- This Rule is referred in the error

   }  

 

Comment out the iRule lines in the bigip.conf:

 pool /Common/prod-pool

 profiles {

  /Common/http_vf_mc { }

  /Common/oneconnect { }

  /Common/tcp { }

 }  

# rules {

#  /Common/example_persist    <<-- This Rule is referred in the error

# }  

Save config and reload.

Additional Information

The iRule you have commented out will not work in this Virtual server, you may need to add iRule uisng GUI, if there is any error, please review iRule and further investigate the cause of error.
