K12889: ARX virtual service unable to join domain when policy requires LDAP Server Signing

Topic

LDAP Server Signing is a security setting that reduces the risk of man-in-the-middle (MITM) attacks. ARX does not currently support joining a CIFS virtual service to an Active Directory domain when the domain controller and domain security policies require LDAP Server Signing. When the domain controller and domain security policies require LDAP Server Signing, attempting to join a CIFS virtual service to the Active Directory domain will fail. In addition, an error message that appears similar to the following example is logged to syslog:

:GUI-0-ERR-ADJOIN_GENERIC:: The domain-join operation failed due to a generic error. See documentation for next steps.

F5 Product Development is tracking a Request for Enhancement (RFE) as ID 345252 to support joining a CIFS virtual service to an Active Directory domain when LDAP Server Signing is required.

You can work around this limitation by disabling the LDAP Server Signing requirement on your domain controller, then joining the ARX virtual service to the domain. After the domain join has successfully completed, the LDAP Server Signing requirement can be re-enabled.
