K000153020: Configuration may fail to load after upgrading to version 17.5.x if the system license is not reactivated

Type
Support Solution
Published
2025-08-14
Updated
2025-08-14
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000153020

Description

 

After upgrading BIG-IP systems from versions to 17.5.1, users may see a login message stating that the configuration has not yet loaded. If this message persists, it indicates a configuration loading issue—often confirmed via CLI as a license activation problem preventing the system from loading its configuration.

 

Environment

  • Product: BIG-IP LTM, GTM VE
  • Platform: F5-BIG-LTM-VE-08-V18, BIG-IP
  • Software Version: Upgrade from 17.1.2 / 17.2.1 to 17.5.1
  • Provisioning: High Availability (HA) production setup
  • Typical Upgrade Method: Creating and booting into a new software volume

Cause

The issue occurs when the system license is not activated after installing and booting into the new software volume during the upgrade process. Without activation, the system cannot load its configuration.

 

Recommended Actions

  1. Boot back to the old (working) volume:

     
    switchboot -l # List current and default boot locations
    switchboot -b HD1.1 # Example: boot to old volume (replace with actual volume name)

  2. Reactivate the license on the system.

  3. Delete the previous (problematic) volume where the configuration failed to load.

  4. Reinstall the target software version by creating a new volume.

  5. In the BIG-IP Configuration Utility, go to:
    System ›› Software Management : Boot Locations

  6. In the Install Configuration dropdown, select Yes.

  7. Boot into the new volume.

  8. Verify successful login with credentials and confirm that the configuration loads correctly.

  9. Repeat the same steps to upgrade the secondary (HA) unit.

Additional Information

Refer to K7727: License activation may be required before a software upgrade for BIG-IP.
