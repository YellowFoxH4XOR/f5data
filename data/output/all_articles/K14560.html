Known Issue

RADIUS authentication may fail when a RADIUS server returns an access challenge with an empty State Attribute Value Pair (AVP) number 24 to the BIG-IP APM system.

This issue occurs when all of the following conditions are met:

  • A BIG-IP APM policy is configured to use RADIUS authentication.
  • The BIG-IP APM system receives a RADIUS authentication access challenge with an empty State AVP.

Impact

Authentication fails for clients attempting to access the BIG-IP APM resource with a policy configured for RADIUS authentication.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H425758 on the Diagnostics > Identified > Medium|High screen.
  • RADIUS authentication fails for the client's authentication request.

Workaround

To work around this issue, configure the RADIUS server not to send the State AVP when sending the RADIUS access challenge. To do so, refer to the RADIUS server guides that outline how to configure attribute-specific settings for vendor-specific attributes.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
