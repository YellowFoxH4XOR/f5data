Topic

Dynamic content value parameters are for use with web applications that set the value on the server side. When a dynamic content value parameter is configured, the BIG-IP system verifies that the client is not changing the parameter value set by the server.

Note: For information about configuring dynamic content value parameters, refer to the BIG-IP ASM Configuration Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Dynamic content value parameters are often used with web applications that use sessions. The BIG-IP ASM system discovers and populates values for dynamic content value parameters, based on specific content types.

BIG-IP ASM 9.4.0 through 9.4.1

Extraction and population of dynamic content value parameters only occurs on the following content types:
  • text/html
  • text/xml
  • application/x-shockwave-flash

BIG-IP ASM 9.4.2 through 10.0.1

Extraction and population of dynamic content value parameters only occurs on the following content types:

  • text/html
  • text/xml
  • application/x-shockwave-flash
  • application/sgml
  • application/x-javascript
  • application/xml
  • application/xhtml
