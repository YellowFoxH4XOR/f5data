K01755841: How to tune Java memory allocation for SDC components?

Type
Support Solution
Published
2021-07-09
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.0, 5.1.X
Source
https://my.f5.com/manage/s/article/K01755841

Description

When SDC components such as Front End Proxy, Config Manager, CPF, and NMS experience insufficient memory, an error message is logged as shown below: 

java.lang.OutOfMemoryError: Java heap space 

Environment

  • Front End Proxy
  • Config Manager
  • CPF
  • NMS

Cause

Symptoms of insufficient memory allocation observed in the Front End Proxy, Config Manager, CPF and NMS

Recommended Actions

The following steps serve as a general guide only and does not take into consideration any custom SDC setup. In addition, the Xmx or MaxMetaspaceSize value provided in the below steps are used as hypothetical value to illustrate how to change respective memory generation size of a SDC component process. We strongly encourage customers to seek additional assistance through F5 Professional Services regarding appropriate Java memory allocation tuning values to use for their production environment.

Backup the EMS 01

  1. # cd /data

  2. # tar cvfpz backup.data.tar.gz ./backup

  3. # cd /srv/pillar/

  4. # cp currentVersion.sls currentVersion.sls.bkp_<date>

  5. # cd /srv/salt/<SDC version>/cpf/

  6. # cp traffix_cpf_init traffix_cpf_init<date>

  7. # cd /opt/traffix/sdc5.1_21_2/lib

  8. # mv groovy-all-2.4.5.jar groovy-all-2.4.5.jar.<orig>

Repeat above Steps on EMS 02.

Backup the SDC
  1. Login to SDC via SSH.
  2.  Backup the current Java configuration
     
    a.     # cd /srv/pillar/
    b.     # cp currentVersion.sls currentVersion.sls.bkp_<date>
    c.     # cd /srv/salt/<SDC version>/cpf/
    d.     # cp traffix_cpf_init traffix_cpf_init<date>
    e.     # cd /opt/traffix/sdc5.1_21_2/lib
    f.      # mv groovy-all-2.4.5.jar groovy-all-2.4.5.jar.<orig>

Repeat above Step 1 and 2 on all the SDC nodes.

Memory allocation verification

  1. # cd /opt/traffix/sdc<version>/config/sysconfig/
  2. # cat traffix_<process name>
  3. # monit status
  4. # ps aux |grep <pid> |grep -xmx  --color

Repeat above Step 1 to 4 for all EMS and SDC nodes.

Java Memory Allocation Update (EMS)

  1. # vi /srv/pillar/currentVersion.sls
  2. Locate the “<process>JavaParameters:” section
  3. Under “prod” section, update the “xmx” (Max memory allocation for Old Generation) value with the new value
  4. Save and exit the file

Repeat above Step 1 to 4 for Config Manager and NMSAgent. Peform the same on other EMS too.

EMS process will be modifying:
     Config_manager Xmx new value : 2513m
   NMSagent Xmx new value : 2500m

Update groovy.all.jar file (EMS)

  1. Put groovy-all-2.4.9.jar in <SDC installation path>/lib     (Step #1 is not needed if you are running SDC 5.1 CF29 and above.)
    Note: Please contact F5 support for the groovy-all-2.4.9.jar.zip


Java Memory Allocation Update (SDC)

  1. Modify the /srv/pillar/currentVersion.sls with the new memory size per each process.
  2. # cd /srv/pillar/
  3. # vi currentVersion.sls
  4. Locate the “<process>JavaParameters:” section
  5. Under “prod” section, update the “xmx” (Max memory allocation for Old Generation) value with the new value
  6. Save and exit the file

Repeat above Steps 1 to 6 for each process on all SDC nodes.

SDC process will be modifying:
   Config_manager Xmx new value : 2513m
   NMSagent Xmx new value : 2500m
   CPF Xmx new value : 5G
   Fep Xmx new value : 2500m

Update groovy.all.jar file (SDC)

  1. Put groovy-all-2.4.9.jar in <SDC installation path>/lib     (Step #1 is not needed if you are running SDC 5.1 CF29 and above.)
    Note: Please contact F5 support for the groovy file.
  2. Modify the /srv/salt/<SDC version>/cpf/ traffix_cpf_init with the new memory size per each process.
  3. # cd /srv/salt/<SDC version>/cpf/
  4. # vi traffix_cpf_init
  5. Change MaxMetaspaceSize from 512m to 1024m
  6.  Save and exit the file

Repeat the steps for other SDCs too.

SDC process will be modifying:
   CPF new value : MaxMetaspaceSize 1024m

Apply the Changes

  1. Make sure all processes are running
    # monit summary
  2. Restart the salt-minion process and make sure the process is running
    # monit restart salt-minion
  3. Restart the salt-api process and make sure the process is running
    # monit restart salt-api
  4. View the summary
    # monit summary

Restart the EMS/SDC process that was modified/updated, and make sure the process is running

  1. # monit restart <process name> ( i.e NMS_agent<name> )
  2. # monit summary
  3. Review the process logs at /opt/traffix/sdc5.1_21_2/logs/<process name>
  4. Make sure that there are no failures (such as startup failure or restarts)
  5. Monitor traffic

 After completing the Verification step, repeat the Procedure Java Update Steps on the next node.
