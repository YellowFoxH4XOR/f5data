K000150699: APM: About logterminal.txt as part of CTU report

Type
Support Solution
Published
2025-04-03
Updated
2025-09-30
Source
https://my.f5.com/manage/s/article/K000150699

Description

BIGIP APM administrators may need to review and download the logterminal.txt file separately which is normally a part of CTU report (aka f5wininfo.exe). This KB article explains where to find this file. 

Environment

  • APM
  • CTU (aka f5wininfo.exe)
  • logterminal.txt

Cause

None

Answer/Recommended Actions

The logterminal.txt file is normally located under C:\Users\<REPLACE_WITH_USERNAME>\AppData\Local\Temp. This folder can be also opened in 'File Explorer' tool if you type %temp%.

For example, from lab windows 10 cmd output:
