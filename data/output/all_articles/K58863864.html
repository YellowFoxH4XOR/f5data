K58863864: Pool member marked down (red) even though monitor shows it is available (green)

Type
Support Solution
Published
2020-10-28
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K58863864

Description
Pool member is Red rectangle status (marked down), but the pool member monitor shows Green circle status (available).

Environment

  • BIG-IP
  • Pool member parent node has a health check such as an ICMP monitor

Cause
The availability of a pool member may be overridden by the availability of its parent node. For more info, see K16008: Overview of BIG-IP pool status (11.x - 15.x)

Recommended Actions
None

Additional Information
None
