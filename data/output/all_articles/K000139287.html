Topic

The F5 knowledge base is a crucial resource for efficiently resolving issues and disseminating information about product features, implementation details, and security updates. Using Knowledge-Centered Service (KCS®), F5 enhances support by enabling both internal and external stakeholders to contribute valuable content from their interactions, enriching our collective knowledge.

To empower self-service and provide immediate access to the latest information, F5 has implemented a cutting-edge GenAI engine in the MyF5 knowledge base. This integration allows everyone to access our knowledge as quickly as it's available and blends both search and Large Language Model (LLM) experience in one interface by collating answers from multiple sources of F5 content.

Important: This F5 GenAI engine is intended to generate answers limited to F5-specific issues in order to reduce potential for GenAI hallucinations.

Description

SEARCH method

When you search or prompt F5 GenAI search, remember to apply the SEARCH methodology to help ensure that queries are as contextually relevant as possible and to improve search accuracy and effectiveness:

Specify your query. Use clear, specific terms and avoid vague language.

Experiment with variations. Try different phrasings or synonyms if the first attempt is not successful.

Ask in full sentences. Formulate queries in full sentences to provide more context.

Refine iteratively. Adjust the query based on the results to home in on what you’re looking for.

Check spelling and context. Ensure correct spelling and include contextual keywords to improve relevance.

Harness advanced features. Use quotation marks for exact phrases, and employ filters, if available.

The following is an example of the SEARCH methodology in action:

Initial query: Virtual server problems

Specify: Clarify what specific problem you're having with the virtual server. For example:

Virtual server down when it shouldn’t be

Experiment: Try different terms that describe the issue. For example:

Virtual server marked down when it should be up.

Ask: Formulate the query in a full sentence. For example:

Why is my virtual server marked down when it should be marked up?

Refine: Adjust the query based on initial results. For example:

Why is my BIG-IP LTM 17.1.x VS mrkd down after reboot when it should be marked up?

Check: Ensure technical terms are spelled correctly.

Why is my BIG-IP LTM 17.1.x virtual server marked down after reboot when it should be marked up?

Harness: Use quotes if you know a specific error message.

Why is my “BIG-IP LTM 17.1.x” virtual server marked down “after reboot” when it should be marked up?

By applying the SEARCH methodology, each query becomes more targeted, making it far more likely that the F5 GenAI system will retrieve the most relevant and useful results. This structured approach not only enhances search efficiency but also leverages the capabilities of the natural language processing system to its full extent.

Important: Review K000138965: How F5's world class support teams troubleshoot issues for more details on how to refine your question, issue, or problem statement before starting to apply SEARCH.

Recommended Actions

In addition to the SEARCH methodology, the following methods and tips can help you structure prompts for the best results.

User story or role-prompting framework

This approach is for gleaning information from the GenAI tool. In it, you include information about a specified role, story, or both to delimit the search.

Note: This technique is similar to writing a User Story in software development and product management roles.

Example: As a <role>, I want to be able to <action>, so that I can <goal/why>.

However, when you apply this approach to the F5 GenAI engine, it already “knows” some information: for example, that you are an F5 customer working with F5 products. So, you need not include the role in your prompt.

Example prompt: Am I vulnerable to CVE-####-####?

Refined prompt: Am I vulnerable to CVE-####-#### if I am running BIG-IP ##.##?

Cause and effect or role prompting framework

This approach works well when you don't know the solution and/or the cause of an issue, as when you know the symptom your system is experiencing, but you don’t know where to start looking for answers. For example, you are researching a symptom: you saw <symptom>, when you did <action>.  and you want to know why it’s occurring.

Example:

  • Initial prompt: SSL error
  • Refined prompt: : SSL handhakes failure with internal error 80

The approach also works well if you want to ask a question. For example, you want to know <what/how>, to do something so that you can <accomplish result>.

Example:

  • Initial prompt: CVE-2020-5902
  • Refined prompt: How do I mitigate CVE-2020-5902?

Example 2:

  • Initial Prompt: Update cert
  • Refined Prompt: How do I update a new client side certificate on my virtual server?

This approach enables you to see what sources of content the F5 GenAI uses to generate the response (otherwise known as Retrieval Augmented Generation), which appears below the response. It also allows you to rephrase the response to meet your preferred format.

After you find a response that best matches your needs, you can copy and paste it into an application. Additionally, you can provide feedback based on your experience. If you want to provide constructive feedback, leave detailed information about the prompts you tried that did not work for you.

Tips for prompts

When using F5 GenAI or any large language model (LLM), the way you phrase your prompts can greatly change the resulting answer. The following is a list of best practices and tips you can use to improve your results.

  • Include context. Are you asking for a comparison? An explanation? A detailed analysis? Make sure to include that in your query. For example: Compare to and provide detailed specifications about how they differ. However, if you want general information, use open-ended questions. For example, Tell me about .
  • Be specific. The more specific you are about what you want to know, the better the chances are you’ll be able to find it. For example, what are the types of BIG-IP virtual servers?
  • Use open-ended questions to encourage detailed responses. For example, How does packet capture work?
  • Use closed-ended questions to get simple answers. For example, Is BIG-IP 18.x available?
  • If the answer isn’t specific or clear, request more clarification. For example, Can you clarify how works?
  • To ask for explanations, use “how” questions. For example, How do I license my BIG-IP system?
  • If you want the Gen AI to provide an opinion or a recommendation, ask for one. For example, In your opinion what is the best time of day to perform maintenance on my BIG-IP system? or Can your recommend the best packet capture tool?
  • Ask about specifics by using prompts like “when,” “what if,” “where,” “who,” and “why” as appropriate for the answer you want.
  • Combine phrases to receive more comprehensive and complete answers. For example, After I upgrade my BIG-IP system to 17.1.x what are the CVEs that I need to worry about?

Generative AI makes mistakes

Generative AI enables users to quickly create new information using existing resources. While there have been remarkable advancements in this technology, systems that rely on generative AI sometimes make mistakes and produce inaccurate answers. Generative AI models are essentially pattern-matching algorithms that can generate plausible-sounding text based on the patterns in their training data. However, they do not have a true, human-like understanding of the world, which can lead it to produce incorrect or inappropriate answers. For example, generative answering may misinterpret words in a question or make incorrect predictions when putting together words that constitute an answer, resulting in incorrect answers.

If you have questions or concerns about an answer your receive from generative answering, or you want additional assistance with your issue, contact F5 Support.
