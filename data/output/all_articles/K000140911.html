K000140911: Next Central Manager may shows as "Disconnected" while it has been set up as "connected".

Source

Description

BIG-IP Next Central Manager [CM] can be set up as "Connected" or "Disconnected". Switching to "Disconnected" mode is made through API and PostMan.

Even though actions have been made to switch BigIP Next CM to "connected", the GUI keeps reporting it's "Disconnected".

Environment

  • BIG-IP Next
  • Central Manager

Cause

It can be 2 reasons for this:

  1. we'd need to ensure we logged out of the GUI, after we configured it as "connected"
  2. it may also be because BIG-IP Next CM cannot connect to "https://product.apis.f5.com/"

Recommended Actions

  • Please open an SSH connection to BIG-IP Next CM, using the "admin" account
  • Please run the command curl -vk https://product.apis.f5.com/ee/v1/certificates
  • Please ensure you can see any HTTP response
