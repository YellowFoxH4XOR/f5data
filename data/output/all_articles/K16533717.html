Description

You want to apply an iRule to replace a string in the URI of an HTTP Request before BIG-IP forwards it to the backend server.

For Example:

Original HTTP Request
https://www.yourdomain.test/public/page/login.html

New HTTP Request
https://www.yourdomain.test/private/page/login.html

Environment

  • BIG-IP LTM
  • HTTP/HTTPS Virtual Server
  • Replace a string in the HTTP Request URI

Cause

None

Recommended Actions

Method 1: Using String Map

when HTTP_REQUEST {
if {[HTTP::uri] starts_with "/public/"} {
HTTP::uri [string map {"/public/" "/private/"}[HTTP::uri]]
pool pool_web
}
}


Method 2: Using RegSub

when HTTP_REQUEST {
if {[HTTP::uri] starts_with "/public/"} {
if { [regsub -nocase /public/ [HTTP::uri] /private/ new_uri] > 0 } {
HTTP::uri $new_uri
}
pool pool_web
}
}

Additional Information

What is the difference between Method 1: String Map and Method 2: RegSub?

  • String Map will replace every instance of the key string found in the URI with the new value.

    For Example: (you used the iRule on Method 1)

    Original HTTP Request
    https://www.yourdomain.test/public/page/public/login.html

    New HTTP Request
    https://www.yourdomain.test/private/page/private/login.html
     
  • RegSub (without -all option) will only replace the first instance of the key string found in the URI with the new value.

    For Example: (you used the iRule on Method 2)

    Original HTTP Request
    https://www.yourdomain.test/public/page/public/login.html

    New HTTP Request
    https://www.yourdomain.test/private/page/public/login.html
