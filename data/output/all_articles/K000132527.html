Description

LCD display stuck on loading status.

 

Environment

  • LCD display
  • iSeries Platform

 

Cause

None

 

Recommended Actions

LCD display can be manually reset via the following IPMI commands issued in CLI bash mode:

 

1) ipmiutil cmd 00 20 e8 29 5 1

2) ipmiutil cmd 00 20 e8 29 5 0

None
