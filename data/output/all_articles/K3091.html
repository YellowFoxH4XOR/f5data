K3091: Reasons why the bigpipe pool command may report a syntax error when you attempt to define a fallback host

Topic

If you have used any of the following string formats, verify that they are contained within quotes:
  • %h
  • %p
  • %u

For example:

b pool <poolname> { fallback \"%h:%p/%u\" }

Or:

b pool <poolname> '{ fallback "%h:%p/%u" }'

Using these string formats without the quotes will result in a syntax error.

You may also receive a syntax error if you attempt to define a fallback host that uses a URI. For more information about this problem, refer to K3000: The bigpipe pool command cannot be used to define a fallback host with a URI.
