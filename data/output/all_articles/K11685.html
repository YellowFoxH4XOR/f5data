Known Issue

This is the result of a known issue. The WebAccelerator 4500 platform uses the incorrect HAL management interface service to obtain interface statistics. As a result, error messages that appear similar to the following example may be displayed in the /var/log/ltm file on 4500 platforms running version 9.4.8:

chmand[1977]: 012a0003:3: HAL stats not found for
chmand[1977]: 012a0003:3: HAL stats not found for

This issue is cosmetic and does not affect system performance.

F5 Product Development tracked this issue as CR107479 and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, Hotfix-BIGIP-9.4.8-407.0-HF4 has been issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing a hotfix for version 9.x systems, refer to K6845: Managing F5 product hotfixes for BIG-IP version 9.x systems.
