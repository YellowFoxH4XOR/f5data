Issue

Error Message

warning tmm[<PID>]: 01190004:4: address conflict detected for <IP> (<MAC>) on vlan <VLAN>

In this error message, note the following:

  • <PID> is the process ID for the TMM process.
  • <IP> is the IP address experiencing the conflict.
  • <MAC> is the conflicting MAC address detected by the BIG-IP system.
  • <VLAN> is the name of the VLAN for the associated IP address.

For example:

warning tmm[14891]: 01190004:4: address conflict detected for 10.10.10.10 (00:23:e9:77:a1:c3) on vlan 1000

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You configure an IP address on the BIG-IP system.
  • Another device on the network issues a gratuitous Address Resolution Protocol (ARP) request for the same IP address.

Impact

Network traffic using that IP address may experience interruptions or outages.

Recommended Actions

When you see this message, locate the device with the conflicting IP address and assign a different address.  The MAC address of the conflicting interface is logged in the message and you can use it to identify the device with the conflicting address.
