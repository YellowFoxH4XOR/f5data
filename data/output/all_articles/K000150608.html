K000150608: How to add Greek URI path to service policy

2025-03-29
Applies to

Source

Description

I want to allow or deny a request based on e.g. a Greek or other language-based URI path.

Environment

  • F5® Distributed Cloud
  • F5 WAAP

 

Cause

When adding the URI path as a prefix in languages such as Geek, French, German, Spanish, or any other non-English language, the error "Field must be a valid HTTP path" appears.


 

Answer/Recommended Actions

To fix this error, regex will work for other languages like French, German, Spanish, or any other non-English languages as long as the F5 Distributed Cloud (XC) Service Policy supports UTF-8 character matching in regex patterns.

Some Samples of URI Path and their valid regex:

French (fr)

Path:

arduinoCopyEdit/assurance-auto/réparateurs

Regex:

rubyCopyEdit^/assurance-auto/réparateurs$

German (de)

Path:

arduinoCopyEdit/versicherung-auto/hersteller

Regex:

rubyCopyEdit^/versicherung-auto/hersteller$

Spanish (es)

Path:

bashCopyEdit/seguro-coche/fabricantes

Regex:

rubyCopyEdit^/seguro-coche/fabricantes$
