K10976: The BIG-IP ASM limits syslog logging for duplicate violations

Topic

When the BIG-IP ASM security policy blocks a request, it generates a blocking response that contains a support ID for the violation, and logs a violation error to both the /var/log/asm file and the Reporting screen.

When the security policy detects and blocks the same violation within a 10-minute period, the BIG-IP ASM logs only the first instance of the violation in the /var/log/asm file. This behavior is by design; it is meant to avoid flooding the logs during a denial-of-service (DoS) attack.

Note: Duplicate violations processed within a 10-minute period are logged to the Reporting/Requests screen.
