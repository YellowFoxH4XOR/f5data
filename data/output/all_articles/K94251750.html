Description

Configuration fails to load due to a corrupted ltm node name/syntax

Environment

  • BIG-IP LTM
  • v11.x and later
  • /var/log/ltm logs similar to below error message:
    01070734:3: Configuration error: Invalid create, modify, or delete for node_address objects in the root folder
  • Corrupted Node name
  • The configuration fails to load.

Cause

This message occurs when 

  • A node configuration was corrupted due to due to incomplete boot or upgrade. 
  •  BIG-IP configuration file is missing for some node parameter as a result (node name, node partition)

Recommended Actions

1.-Edit properly the node configuration in  /config/bigip.conf  or  /config/<partition name>/bigip.conf file looks as follows. 

Incorrect Syntax:

For example: 
ltm node /Partition1 {
    address 192.168.1.20
}

or 

ltm node /Node1 {
    address 192.168.1.20
}

Note: In the above examples, the configuration syntax is incorrect. It should be ltm node /<Partition>/<NodeName>

Correct Syntax:

ltm node /<Partition>/<NodeName> {
    address x.x.x.x
}
For Example: 
ltm node /Partition1/Node1 {
    address 192.168.1.20
}

Note: You can use any method to edit the configuration file. If the corrupted node is being used or referenced by another object it should be changed as well.
 

2.- Reload the BIGIP configuration on all partitions.
# tmsh load sys config partitions all

3.-Verify load configuration process
#tmsh load sys config verify

4.-Save the BIG-IP configuration.
# tmsh save sys config partitions all
