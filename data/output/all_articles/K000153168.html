K000153168: Files payload.tar.gz and flatrock.xml in the /var/cache/tomcat/temp might trigger vulnerability alert from security scanner

Type
Support Solution
Published
2025-08-26
Updated
2025-09-29
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000153168

Description

Microsoft Defender Security Center scanner might flag these two files on F5 are malware.

  • /var/cache/tomcat/temp/Live-Update8XXXX/PAYLOAD/campaigns/php/generic/PHP Backdoor upload/PHP Backdoor upload - xbcmd\flatrock.xml
  • /var/cache/tomcat/temp/Live-Update7XXXXX\payload.tar.gz

 

Environment

  • ASM Live Update
  • Third Party Scanner 

 

Cause

These files are not malware. They are automatically generated as part of the process for updating attack and threat signatures. Due to their nature, they may include keywords that can be flagged as malicious by scanning tools

Note: The system auto-deletes them after the update process finishes successfully. The files will persist if the update process was interrupted.

 

Recommended Actions

If these files persist, they are safe to delete.
