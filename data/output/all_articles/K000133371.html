K000133371: Message Box / Decision Box after OAuth Client causes "Access policy already in process" error message

Type
Support Solution
Published
2023-04-03
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.X, 15.1.X, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0
Source
https://my.f5.com/manage/s/article/K000133371

Description

  • Access Policy processing does not complete when Message Box or Decision Box object is placed after Oauth Client object in Access Policy
  • Error message in client browser: "Access policy evaluation is already in progress for your current session."
  • Message in /var/log/apm: "Session deleted (restarted)."

Environment

  • BIG-IP with APM
  • BIG-IP configured as OAuth Client or Client/ResourceServer

Cause

Software defect when processing Message Box POST (ID 1006601). No fix available yet.

 Recommended Actions

As a workaround, a Logon Page agent can be used to behave the same as a Message Box or Decision Box agent.
Such Logon Page options will help achieve it:

  •     all fields Type will be set to none
  •     any custom message for the users will be mentioned in the Form Header text field
  •     Logon Button value will be changed from Logon to Continue
