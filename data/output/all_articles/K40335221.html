Description

This article is intended for LTM-based product modules (ie: LTM, GTM, ASM, APM, etc ) as a means to remove BIG-IQ Product management from their appliance. This solution is especially helpful for people importing/migrating configurations from a device (managed or no longer managed by BIG-IQ) onto another appliance. BIG-IQ's management configuration on the new destination appliance would also be installed by default, and this could lead to conflicts and device management for the new appliance. Although a device should always be removed from BIG-IQ control before creating a UCS archive, not all F5 administrators have access to the BIG-IQ directly to make changes. Ideally devices should be added/removed from BIG-IQ administrative management directly, and this solution should be used as a last resort when no BIG-IQ access is available in order to prevent conflicts.

Environment 

  • Any BIG-IP appliance managed by BIG-IQ.

Cause

There is no direct documentation on how to remove BIG-IQ management from an LTM appliance. You have to refer to BIG-IQ product documentation which isn't helpful if you are not familiar with the BIG-IQ. There can be may reasons why a person would want to remove a product from the BIG-IQ. One being that they need to migrate a UCS archive from one appliance to another.

Recommended Actions

Warning: This solution should be used as a last resort when no BIG-IQ access is available in order to prevent conflicts.

  1. Log in to the BIG-IP system's Advanced Shell (bash).
  2. Determine the machineId of the BIG-IQ reference from the BIG-IP system's REST database by entering the following command:

    restcurl shared/resolver/device-groups/cm-bigip-allDevices/devices | jq '.items[] | select(.product == "BIG-IQ") | {product,machineId}'

    The command returns an output similar to the following example:

    {
      "product": "BIG-IQ",
      "machineId": "81391234-98ef-4b64-9df9-0b5de12341d9"
    }

  3. Remove the BIG-IQ reference from the REST database on the BIG-IP system by entering the following command syntax:

    restcurl -X DELETE shared/resolver/device-groups/cm-bigip-allDevices/devices/<BIG-IQ reference machineId>

    Using the example from previous steps, you would enter the following command:

    restcurl -X DELETE shared/resolver/device-groups/cm-bigip-allDevices/devices/81391234-98ef-4b64-9df9-0b5de12341d9

  4. Verify that the BIG-IQ reference ("product": "BIG-IQ") no longer exists in the REST database on the BIG-IP system by entering the following command:

    restcurl shared/resolver/device-groups/cm-bigip-allDevices/devices
     

       5. Restart restjavad:
            tmsh restart sys service restjavad

        All references on the LTM device for the BIG-IQ controller should now be removed. You will no longer see a banner in the GUI stating: "Device managed by BIG-IQ".

        Note: Care should be taken to remove configuration references for this device on the BIG-IQ device directly.
