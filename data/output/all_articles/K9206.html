Issue

In an active/standby high availability configuration, the active unit answers all client requests for virtual addresses configured on the system.

In BIG-IP LTM versions prior to 9.4.0, the standby unit could not connect to virtual addresses configured on the system.

Beginning in BIG-IP LTM 9.4.0 and later, the standby unit can connect to virtual addresses configured on the system.

Note: In all versions of BIG-IP LTM, the active unit can connect to virtual addresses configured on the system.

F5 Product Development tracked this issue as CR59729 and it was fixed in BIG-IP 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.
