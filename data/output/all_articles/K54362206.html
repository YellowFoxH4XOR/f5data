Description
To add a user to APM local user DB via CLI is needed.

Environment

  • BIG-IP APM
  • Local User DB
  • CLI

Cause
None

Recommended Actions

Use a bash command like next to add the entry to the DB:

# ldbutil --add --uid=<uid>" --uname="<user name>" --password="<password>" --instance="<Data base name>" --user_groups="<user group>" --login_failures="0" --change_passwd="0" --locked_out="0" --first_name="<First name>" --last_name="<last name>" --email="<name>"

Note: Only desired fields need to be populated, otherwise leave it blank
Note: Change_passwd = 0 means not request to change password, 1 will request to change it
Note: If no 'uid' is set, it will be automatically assigned 

Example: 

To create test02 in MyDB with no 'uid'

  1. Login via SSH to the BIG-IP
  2. In bash mode, introduce next command:
    # ldbutil --add  --uname="test02" --password="test02" --instance="/Common/MyDB" --user_groups="" --login_failures="0" --change_passwd="0" --locked_out="0" --first_name="" --last_name="" --email=""
  3. To check if the entry was added, use next command:
    # ldbutil --allusers --list | grep <user name>
     For example:
    # ldbutil --allusers --list | grep test02
