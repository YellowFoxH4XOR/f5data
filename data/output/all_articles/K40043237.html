Known Issue

Asymmetric FTP data connections may fail to establish.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with an associated FTP profile.
  • You have enabled the virtual server's Connection Mirroring setting.
  • The FTP profile's Inherit Parent Profile option is set to Disabled.

    Note: Disabled is the default setting for the Connection Mirroring setting and Inherit Parent Profile option.

  • You have disabled the following database keys:
    • connection.autolasthop
    • connection.vlankeyed

      Note: Enabled is the default setting for the previous database keys.

  • Remote FTP client data connections are asymmetric.

    Note: Asymmetric refers to return traffic bypassing the BIG-IP system and returning directly to the client.

Impact

FTP data connections fail to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • FTP data connections fail when return traffic bypasses your BIG-IP system.
  • FTP data connections fail after upgrading your BIG-IP system to an affected software version.

Workaround

To work around this issue, you can ensure your backend servers are configured to route FTP data connections back to the BIG-IP system.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
