K21334605: Upgrade failed with error: Could not access configuration source; CPmirror, <#>

Type
Support Solution
Published
2022-11-11
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.0.0
Source
https://my.f5.com/manage/s/article/K21334605

Description

  • While attempting to install volume 16.1.2, the following error is encountered

    info:        /dev/mapper/vg--db--cpmirror-set.2._usr is already mounted on /opt/.sdm/usr
    info:        /dev/mapper/vg--db--cpmirror-set.2._usr is already mounted on /opt/.sdm/lib
    info:        /dev/mapper/vg--db--cpmirror-set.2._usr is already mounted on /opt/.sdm/lib64
    info: >----
    error: status 8192 returned by command: umount /mnt/tm_install/5178.Z7V4DS/shared
    info: >++++ result:
    info: umount: /mnt/tm_install/5178.Z7V4DS/shared: not mounted
    info: >----
    Terminal error: Could not access configuration source; cpmirror, 2
    *** Live install end at 2022/10/31 11:17:46: failed (return code 32) ***

Environment

  • Current active volume is 16.0.0
  • iRulesLX is provisioned

Cause

ID 915605

Recommended Actions

Perform either of the workarounds.
  1. De-provision iRulesLX if no longer needed, then reboot the BIG-IP.
  2. Perform workaround in K05920565.

Additional Information

None
