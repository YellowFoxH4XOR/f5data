Description
Using an F5 authentication token when accessing the REST API on BIG-IPs and BIG-IQs is often necessary. This token value is used in the HTTP header X-F5-Auth-Token to authenticate requests to the REST API. This article will demonstrate how to declare a BASH shell function to retrieve an auth token from a remote or local device. 

Environment

  • Linux BASH shell

None

Create a shell function that can retrieve authentication tokens

Declaring the shell function
  1. Using a text editor create a file /var/tmp/f5_auth_token_shell_function_source.txt that contains the following code:

    ######## Cut Below #######
    ##################################################################
    # Fetch HTTP auth token from BIG-IP or BIG-IQ
    # Arguments:
    #   $1 IP or hostname of target device
    #   $2 username for login
    #   $3 password for login
    #   $4 "brief" if supplied only the token is returned
    # To load the function:
    #   source /var/tmp/f5_auth_token_shell_function_source.txt
    ##################################################################
    function fetch_f5_auth_token () {
      funcname=${FUNCNAME[0]}
      function usage_message () {
        echo -e 'Fetches an auth token and prints an example curl using the token'
        echo 'Optional: add "brief" to output only the token'
        echo 'Usage:'
        echo "${funcname} <IP address> <username> <password> [brief]"
      }
      function missing_required_args () {
        echo -e "Not enough argments, function requires 3!"
      }
      if [[ $# -eq 0 ]] ; then
        usage_message
        return
      elif [ -z "$1" ]; then
        missing_required_args
        usage_message
        return
      elif [ -z "$2" ]; then
        missing_required_args
        usage_message
        return
      elif [ -z "$3" ]; then
        missing_required_args
        usage_message
        return
      fi
      ip=$1
      username=$2
      password=$3
      brief=$4
      post_result=$(curl -sk -H "Content-Type: application/json" "https://${ip}/mgmt/shared/authn/login" -X POST -d '{"username": "'$username'","password":"'$password'","loginProviderName": "tmos"}' | jq .)
      if [ -z "$post_result" ]; then
        echo "Request to "${ip}" failed"
        return
      fi
      token=$(echo "$post_result" | jq '{"token"}.token' | grep -w token | awk '{print $2}' | tr -d '",')
      print_example () {
      echo "Example curl:"
      echo "curl -sk -H \"Content-Type: application/json\" -H \"X-F5-Auth-Token: ${token}\" "https://"${ip}"/mgmt/shared/identified-devices/config/device-info""
      }
      if [ "$brief" = "brief" ]
        then
          echo "${token}"
      else
        echo "token is $token"
        echo ""
        print_example
      fi
    }
    ######## Cut Above #########

  2. Load the shell function from the file:
    source  /var/tmp/f5_auth_token_shell_function_source.txt

  3. To view the function in memory:
    declare -f fetch_f5_auth_token

Usage examples
Note: The authentication token retrieved in the examples have a five minute expiration

  • Usage:
    fetch_f5_auth_token <IP address> <username> <password> [brief]

  • Fetch and display token and  show example curl command populated with the token header and target host:
    # fetch_f5_auth_token 192.0.2.10 admin fAkePaSsWoRd 
    token is C6XRGF36LYO4ENUV4RRJPLDP2Q
    Example curl:
    curl -sk -H "X-F5-Auth-Token: C6XRGF36LYO4ENUV4RRJPLDP2Q" https://192.0.2.10/mgmt/shared/identified-devices/config/device-info

  • Fetch only the token using "brief":
    # fetch_f5_auth_token 192.0.2.10 admin fAkePaSsWoRd brief
    4ARA3XNTDCUTHNDZEP3OUWANX

  • Save token to a variable and use the variable in a request:
    Note: Make sure and use the  brief option to put just the token value into the variable

    • Save token to a variable:
      token=$(fetch_f5_auth_token 192.0.2.10 admin fAkePaSsWoRd brief)

    • Use token in an authentication header for a request:
      curl -sk -H "X-F5-Auth-Token: ${token}" https://192.0.2.10/mgmt/shared/identified-devices/config/device-info
