Description

When deploying the Exchange 2016 iApp, an existing Access profile was selected rather than choosing to create a new Access profile.
The Access profile selected was configured as type ALL.

Environment

  • VE on ESxi,
  • 14.0.0.3
  • iApp template for Exchange 2016 v.10.2

Cause

An existing Access profile which was of type ALL which the iApp "bring your own Access Profile" feature is not supported.

Recommended Actions

  1. Choose to create a new Access profile or select an existing Access profile of type LTM-APM while configuring the iApp.
