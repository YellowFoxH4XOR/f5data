Topic

When BIG-IP Edge Client connects to a BIG-IP APM system configured with a logon page that has external links that open in a new window, the links cannot open the referenced pages. This can affect various operations, such as two-factor authentication solutions that use a pop-up window to provide the token.

Description

Recommendations

If your logon page requires links to external sites, F5 Technical Support recommends using a web browser to connect to the BIG-IP APM system instead of BIG-IP Edge Client.
