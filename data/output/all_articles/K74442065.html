K74442065: Virtual server is marking offline by bigip monitor when duplicated BIG-IP DNS server was disabled

Type
Support Solution
Published
2021-02-01
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP GTM
  • BIG-IP DNS: 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.1.0
Source
https://my.f5.com/manage/s/article/K74442065

Description

The BIG-IP DNS is marking the virtual server offline.
The virtual server is shown as available on the LTM, and iQuery connection is full mesh, the bigip monitor should mark the virtual server as available.

show /gtm server virtual-servers
---------------------------------------------------------------
Gtm::Server: /Common/ltm1.example.com (Unit: 0)
---------------------------------------------------------------
Status
  Availability : available
  State        : enabled
  Reason       : Available
Global
  Virtual Server Picks        1.4M
  Connections                 1.5K
  -------------------------------------------------------------
  | Gtm::Virtual Server: /Common/Virtual_server_1
  -------------------------------------------------------------
  | Status
  |   Availability : offline
  |   State        : enabled
  |   Reason       :  Monitor /Common/bigip from /Common/ltm1.example.com : no reply from big3d: timed out
  |   Destination  : 192.168.100.100:0

Environment

  • BIG-IP DNS
  • BIG-IP LTM server is available in the GSLB via bigip monitor
  • Virtual server status is available in the BIG-IP LTM
  • One duplicated BIG-IP DNS server existed, state is disabled, 

Cause

The configuration is incorrect, the duplicated BIG-IP DNS server should not be created.

Recommended Actions

Remove the duplicated BIG-IP DNS server.

Additional Information

None.
