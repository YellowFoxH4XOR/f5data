K000149176: BIG-IQ SMTP communication with mailserver uses TLS1.0

Type
Support Solution
Published
2025-01-03
Updated
2025-04-04
Applies to

  • BIG-IQ Centralized Management: 8.2.X, 8.0.X, 8.1.X, 8.3.X, 8.2.0, 8.1.0, 8.0.0, 7.1.0, 7.0.0, 7.0.X, 7.1.X, 7.X.X, 8.3.0
Source
https://my.f5.com/manage/s/article/K000149176

Description

BIG-IQ SMTP uses TLS1.0 for communication with Mailserver. If Mailserver does not support TLS1.0 communication brakes and we can see errors in collected tcpdump

TLSv1 59 0.014996000 Alert (Level: Fatal, Description: Protocol Version)

Environment

  • BIG-IQ CM
  • SMTP configuration
  • TLS v1.0
  • TLS v1.2
  • Upgrade

Cause

BIG-IQ only support TLS 1.0 in SMTP configuration.

There is an ID opened to track this issue, ID1784257.

Recommended Actions

ID1784257 has been fixed in Big-IQ v8.4.0 release. Please upgrade Big-IQ to v8.4.0 to benefit from this fix.
