Known Issue

When streaming interleaved data, the BIG-IP system issues a TCP reset with an RTSP Too Big error.

This issue occurs when all of the following conditions are met:

  • You have configured a Real Time Streaming Protocol (RTSP) profile and assigned it to a virtual server.
  • The connection contains multiple interleaved streams.
  • The system is experiencing packet re-transmissions due to an unreliable network connection.

Impact

RTSP traffic is interrupted.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The RTSP connection is dropped or interrupted midstream.

Workaround

To work around this issue, you can set the Maximum Header Size and Maximum Queued Data values in the RTSP profile to a value greater than 64 KB. To do so, perform the following procedure:

Note: This is a partial workaround as it does not completely eliminate the issue from occurring. To prevent further traffic disruption, F5 highly recommends that you upgrade to a fixed version.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Services > RTSP > Your Custom RTSP Profile.
  3. Enter a value of 65536 or greater in the Maximum Header Size and Maximum Queued Data fields.
  4. To save the changes, click Update.
