Known Issue

The ClientSSL profile may be created with an incorrect key, certificate, or chain.

This issue occurs when all of the following conditions are met:

  • You create a custom ClientSSL parent profile with a user defined certificate, key, or chain.
  • You create a ClientSSL child profile from the standard BIG-IP ClientSSL profile.
  • You modify this ClientSSL child profile to use the defaults from the custom ClientSSL profile you created.

Impact

The BIG-IP system may fail to load the erroneous ClientSSL configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP Configuration utility shows the correct key/certificate/chain for the modified child profile, whereas the Traffic Management Shell (tmsh) shows the child profile to have the default key and certificate.
  • The BIG-IP system produces an error message similar to the following example when loading the configuration:

    err mcpd[6930]: 01070710:3: Database error (13), Can't save/checkpoint DB object, class:clientssl_certkeychain status:13 - EdbCfgObj.cpp, line 127
