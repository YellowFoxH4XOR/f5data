K33404337: The tmsh and bigstart utilities can no longer be used to individually manage the racoon service

Issue

Old Behavior

In versions prior to BIG-IP 12.0.0, you can use the Traffic Management Shell (tmsh) and bigstart utilities to individually manage (such as start, stop or restart) the racoon service.

The racoon daemon is an open source user-space daemon running on the Linux system. This daemon handles Internet Key Exchange version 1 (IKEv1) for IPsec. IKEv2 is not handled by racoon.

New Behavior

Beginning in BIG-IP 12.0.0, you can no longer use the tmsh and bigstart utilities to individually manage the racoon service. To manage (start, stop or restart) the racoon service, dependencies require that you perform the desired action on the tmipsecd process. The tmipsecd process subscribes to notifications from IPsec-related configuration objects. When you stop, start, or restart the tmipsecd process, dependencies will also cause the system to perform the action on the racoon service.

Impact

You can no longer use the tmsh and bigstart utilities to manage the racoon service. If you attempt to manage the racoon service with the tmsh or bigstart utilities, your attempt will fail and the system will display an error message similar to the following example:

Couldn't find service: racoon

Recommended Actions

To restart IPsec-related services, such as the racoon service, restart the tmipsecd process using one of the following commands:

bigstart restart tmipsecd

or

tmsh restart /sys service tmipsecd
