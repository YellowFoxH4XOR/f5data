Description

Getting the following error when trying to delete an ISO file from vCMP guest.

Data Input Error: Could not locate image "BIGIP_ <version>.iso"

Environment

  • vCMP Guest
  • vCMP Host

Cause

The ISO file resides in the Host instead of the Guest.

Recommended Actions

If you want to delete the ISO file, you have to perform this task in the Host.
Note: that will delete the ISO for the whole unit.

Additional Information

None.
