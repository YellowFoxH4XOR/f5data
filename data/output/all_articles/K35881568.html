Issue

Error Message

01070596:3: An unexpected failure has occurred, <reason>, exiting...

In this error message, note the following:

  • <reason> is additional diagnostic information regarding the reason for the error

For example:

01070596:3: An unexpected failure has occurred, There is no active database transaction, status: 0 - EdbDbConnection.cpp, line 133, exiting...

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The Master Control Program Daemon (mcpd) has encountered an unrecoverable error.

The mcpd process is the messenger service that allows two-way communication between userland processes and the Traffic Management Microkernel (TMM).

Impact

No traffic management functionality. You cannot retrieve or update the system status, and the system cannot be reconfigured; other daemons will not be functional.

Recommended Actions

  • The mcpd process should automatically recover from an unexpected failure. If mcpd does not recover, manually force the mcpd process to reload by performing the procedure in K13030: Forcing the mcpd process to reload the BIG-IP configuration.
