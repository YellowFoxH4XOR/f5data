Topic

The TMOS Shell (tmsh) has several built-in Help features to help you understand the syntax required to execute a tmsh command.

Description

  • Using command completion with tab complete
  • Using help help
  • Using help
  • Using help <command>
  • Using help /<module>
  • Using help /<module> <component>
  • Using help /<module> <component> <topic>
  • Obtaining context-sensitive help
  • Using help search <text>
  • Filtering tmsh command output using the Linux grep command

tmsh help command examples

The help command examples in this article use the variables <module>, <component>, and <topic> as follows:

  • <command> indicates the configuration action of the command you want to use. The actions include, but are not limited to, the following command types:

    create, delete, edit, exit, help, list, load, modify, quit, reboot, restart, run, save, show, start, and stop

    Additional commands types include the following:

    bash, ccmode, cd, cp, dig, domain-tool, establish-adfs-trust, fipscard-sync, fips-util, gencert, generate, get-ccn-dossier, get-dossier, imish, install, mv, netstat, ping, ping6, publish, pwd, qkview, racoonctl, reset-stats, revoke, send-mail, shutdown, ssh-keyswap, ssldump, submit, tcpdump, telnet, test-monitor, tracepath, tracepath6, traceroute, traceroute6, vconsole, and zebos

  • <module> indicates the licensed module, licensed-module sub configuration objects, or area of BIG-IP system configuration.

    Modules include, but are not limited to, the following:

    analytics, apm, asm, auth, cli, cm, gtm, ltm, mgmt, net, security, sys, util, and wom.

    Note: The modules apm, asm, gtm, ltm and wom are licensed modules. auth, cli, cm, mgmt, net, security, sys and util are BIG-IP system configuration modules.

  • <component> signifies a configuration component of the module. For example the following is a list of DNS configuration components of the BIG-IP DNS/BIG-IP GTM module:

    datacenter, distributed-app, link, listener, prober-pool, region, rule, server, and topology

  • <topic> is a sub-component (topics that are available for the module or the module configuration) for the configuration of a specific module.

Command completion with Tab complete

In tmsh, you can press the Tab key to display a list of command options available to complete a command you've started entering.

For example, if you begin by entering create /ltm profile http , you can press the Tab key to display all possible options to finish that command. The output when you press the Tab key for this example appears similar to the following:

Configuration Items: Drafts/ datasync-global/ http-explicit EPSEC/ http http-transparent

Note: The listed configurations may not be limited to the output displayed in this example.

Using help help

Entering the help help command displays the man page for the help command syntax.

Using help

Entering the help command displays a list of topics that include General, Commands, Modules, and Utilities.

Using help <command>

Entering the help <command> command syntax displays the tmsh man page for the selected command variable, including a list of topics that are available for use with the command.

For example, entering help show returns the tmsh man page for the show command.

Using help /<module>

Entering the help /<module> command syntax displays the tmsh man page for the selected module variable, with a list of topics available for use with that module.

Using help /<module> <component>

Entering the help /<module> <component> command syntax displays a list of topics for the selected module variable related to the component variable.

help /<module> <component> <topic>

Entering the help /<module> <component> <topic> command syntax displays the tmsh man page for the specific module component variable related to the topic variable.

For example, entering help /ltm profile http returns the tmsh man page for http profile.

Obtaining context-sensitive help

You can use the help command with the question mark (?) at any point in the tmsh command syntax to get additional information to assist in completing the command.

Using the question mark (?) in tmsh commands

  • When you use a question mark immediately following any portion of a command, the possible completions for the command are displayed.
  • When you use a space before the question mark, descriptive text explaining the commands, components, or properties is displayed.
  • When you use a question mark in the middle of a command, Help syntax relating to the command displays.

    For example, entering modify /ltm virtual ? returns output similar to the following:

    Options:
    all Apply the command to all configuration items
    Identifier:
    [object identifier] Name of the virtual server ...

    Note: The possible options are not limited to the output displayed in this example.

Using help search <text>

Entering the help search <text> command syntax displays options relevant to the text variable.

For example, entering help search syn-cookie returns output similar to the following:

ltm global-settings connection
ltm profile fasthttp
ltm profile fastl4
ltm profile tcp
security dos profile

Filtering tmsh command output using the Linux grep command

In tmsh, you can filter command output using the Linux grep command.

Note: This command does not apply to the Help feature

For example, entering list /ltm profile tcp f5-tcp-lan returns output similar to the following:

ltm profile tcp f5-tcp-lan {
app-service none
defaults-from tcp
init-cwnd 16
init-rwnd 16
minimum-rto 200
nagle auto
proxy-buffer-high 65535
proxy-buffer-low 32768
rate-pace enabled
send-buffer-size 65535
tail-loss-probe enabled
}

Using the grep command, you can extract a subset of the configuration information. For example, to only view the buffer settings of the configuration, you would enter the following command:

list /ltm profile tcp f5-tcp-lan | grep buffer

This returns output similar to the following:

proxy-buffer-high 65535
proxy-buffer-low 32768
send-buffer-size 65535

Note: When using the grep command, regardless of the matched strings, tmsh presents the following warning message syntax: Display all <number> items? (y/n). The value of <number> is the total amount of items for the command or module. However only the matching objects found by the grep command in the list are displayed.

Recommendations

tmsh includes man pages for each of the commands and components available within the utility. To access the tmsh utility main man page from the command line, you can execute the following command:

man tmsh

For more information about tmsh syntax for BIG-IP 13.x, refer to Where to Find the TMSH Command Reference Guide for Version 13.X.

Note: Although the information contained in the reference manual relates to previous versions of tmsh, the general command structure, modules, and utilities do not vary greatly between BIG-IP releases.
