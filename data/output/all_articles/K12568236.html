Description
Is it possible to configure smart card authentication for the BIG-IP management interface (Configuration utility)?

Environment

  • BIG-IP
  • Smart card
  • Configuration utility

Recommended Actions

    You can configure smart card authentication for logging in to the BIG-IP Configuration utility by using the Remote-ClientCert LDAP authentication method. This method uses client authentication, OCSP, and an LDAP directory; therefore, the smart card must provide a client certificate for the browser to use when accessing the Configuration utility. For more information refer to K000149580: Configure LDAP client certificate authentication for BIG-IP administrators.


    Additional Information

    There is also a DevCentral article that explains how to configure Remote-ClientCert LDAP for use with smart cards:

    Configuring Smart Card Authentication to BIG-IP Management Interface
