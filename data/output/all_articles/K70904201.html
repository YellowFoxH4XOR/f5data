K70904201: Logs not generating on device

Type
Support Solution
Published
2021-12-17
Updated
2026-07-16
Status
Legacy Content
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K70904201

Description

Device is not generating logs and we can see receive queue has packets by running below command:

 netstat -pan | grep -i syslog

Active Internet connections (servers and established)
Proto Recv-Q Send-Q Local Address           Foreign Address         State       PID/Program name     Timer
udp   214272      0 127.0.0.1:514           0.0.0.0:*                           2486/syslog-ng       off (0.00/0/0)   <---- Recv-Q has packets
 

Environment

  • BIG-IP
  • Syslog

Cause

Syslog is not reading packets in the receive queue.
 

Recommended Actions

1. Login to Device CLI/bash mode
2. Restart syslog-ng service using below command:
bigstart restart syslog-ng

Additional Information

None.
