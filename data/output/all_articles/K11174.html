Known Issue

This is the result of a known issue. When the BIG-IP WebAccelerator pvac daemon services an invalidation request for an object in the WebAccelerator Cache, all objects are evicted from the BIG-IP RAM Cache. The BIG-IP RAM Cache eviction does not usually impact the OWS because the WebAccelerator Cache still has all of the unexpired cached content available. The BIG-IP RAM Cache is rapidly repopulated with content from the WebAccelerator Cache.

This issue should have minimal impact from the client perspective, as the slight latency introduced by the BIG-IP RAM Cache repopulation from the WebAccelarator Cache will be short-term and negligible. The most noticeable effect is the appearance of the BIG-IP RAM Cache performance graphs.

F5 Product Development is tracking this issue as ID 222349 (formerly CR118237).
