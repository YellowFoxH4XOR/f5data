Known Issue

This is the result of a known issue. When you run the big3d_install script from a BIG-IP GTM system running version 9.2.3 to a BIG-IP LTM system running version 9.1.2 or earlier, big3dshim symbolic links are not updated properly. As a result, two big3dshim processes begin at boot up, which causes the iQuery communication between the BIG-IP GTM and BIG-IP LTM to fail.

F5 Product Development tracked this issue as CR69166 and it was fixed in BIG-IP GTM 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP GTM Release Notes.
