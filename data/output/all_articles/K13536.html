K13536: Error Message: Failed to authenticate connection to the Secure Agent at <IP_Address>

Issue

Error Message

Failed to authenticate connection to the Secure Agent at <IP_Address>.  Be sure the passwords configured on the switch and for the Secure Agent at <IP_Address> match.

In this error message, note the following:

  • <IP_Address> is the IP address of the domain controller hosting the ARX Secure Agent

For example:

Failed to authenticate connection to the Secure Agent at 192.198.10.50.  Be sure the passwords configured on the switch and for the Secure Agent at 192.198.10.50 match.

Message Location

You may encounter this message in the following location:

  • The syslog file

Description

This message can occur when one of the following conditions are met:

  • The ARX Secure Agent password was changed
  • The ntlm-auth-server configuration of the ARX global config contains an incorrect password
  • The ntlm-auth-server configuration of the ARX global config does not have a password defined

The message indicates the ARX was unable to authenticate with the ARX Secure Agent because the password in the ntlm-auth-server configuration of the ARX global-config is missing or does not match the password configured on the ARX Secure Agent.

Impact

Clients using NTLM or NTLMv2 authentication will be unable to access CIFS services.

Recommended Actions

Ensure the password configured for the ARX ntlm-auth-server configuration matches the password configured on the ARX Secure Agent running on the domain controller.

  • Use the ntlm-auth-server password command to configure the password on the ARX
  • Use the ARX Secure Agent Management Applet to change the password on the ARX Secure Agent
