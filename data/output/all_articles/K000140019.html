K000140019: How to view Insert Client Certificate in HTTP header and forward to the node

Type
Support Solution
Published
2024-06-14
Updated
2024-06-14
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000140019

Description

You are experiencing an issue where you are unable to view the certificate being inserted into the HTTP header. This problem is typically identified when you expect to see a certificate within the HTTP header of a request or response but find that it is not present.

Environment

  • BIG-IP Local Traffic Manager (LTM) is in use

Cause

No logging was set up to monitor the certificate insertion into the HTTP header.

Recommended Actions

To address this issue, please perform the following actions:

  1. Add logging to the iRule to monitor the certificate insertion function. Ensure that you have administrative access to modify iRules on the BIG-IP system.
  2. Apply the following iRule to log the necessary information:

when HTTP_REQUEST {
    HTTP::header insert X-Client-Cert [b64encode [SSL::cert 0]]
    set LogString "Client [IP::client_addr]:[TCP::client_port] -> [HTTP::host][HTTP::uri]"
    log local0. "============================================="
    log local0. "$LogString (request)"
    foreach aHeader [HTTP::header names] {
        log local0. "$aHeader: [HTTP::header value $aHeader]"
    }
    log local0. "============================================="
}

when HTTP_RESPONSE {
    log local0. "============================================="
    log local0. "$LogString (response) - status: [HTTP::status]"
    foreach aHeader [HTTP::header names] {
        log local0. "$aHeader: [HTTP::header value $aHeader]"
    }
    log local0. "============================================="  
}

After applying the iRule, monitor the logs for entries related to the certificate insertion to confirm its functionality.

Additional Information

Ensure that SSL profiles are properly configured on the BIG-IP system to allow for SSL certificates to be accessible by iRule.
