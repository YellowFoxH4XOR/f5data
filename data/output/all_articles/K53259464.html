K53259464: Resources cached for only 1 second with Web Acceleration profile

Applies to

Source
https://my.f5.com/manage/s/article/K53259464

Description

When viewing ramcache output with the show ltm profile ramcache command, Expires time is 1 second later than Received, similar to the following example:

Host: www.ltm1.com
URI : /root/images/123.jpg
---------------------------------------
  Source Slot/TMM  1/1
  Owner Slot/TMM   1/1
  Rank             4

  Size (bytes)     42746
  Hits             0
  Received         2019-07-12 08:04:56
  Last Sent        2019-07-12 08:04:56
  Expires          2019-07-12 08:04:57
  Vary Type        none
  Vary Count       1
  Vary User Agent  none
  Vary Encoding    none

Environment

  • Web Acceleration profile

Cause

This is expected behavior when a HTTP server returns a response with a Cache-Control: max-age=0 header.

Recommended Actions

Investigate if this is an improper Cache-Control setting on the web server.

None
