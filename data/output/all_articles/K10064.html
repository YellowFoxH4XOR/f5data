Known Issue

This is the result of a known issue. The SNMP logs found in Reports: System Logs will report legitimate SNMP queries even when the SMTP logging level is set to Emergency. This behavior may cause the log file to fill quickly, resulting in performance issues.

F5 Product Development has tracked this issue as CR109120 and it was fixed in FirePass version 6.1.0.

This issue has been fixed in cumulative hotfix HF-602-11 issued for FirePass version 6.0.2 and in cumulative hotfix HF-603-3 issued for FirePass version 6.0.3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
