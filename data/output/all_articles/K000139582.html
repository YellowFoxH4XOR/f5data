Topic

The F5OS system provides extensive logging to help you troubleshoot issues. This article describes the different logging locations and files you should check when troubleshooting F5OS issues.

    Description

    Refer to the following sections on F5OS logging:

    • Log locations
    • Configure log verbosity

    Log locations

    Depending on which F5OS service you are troubleshooting, refer to the following list of the different log locations and files you can refer to:

    LogsLog location and accessAdditional Information

    velos.log

    platform.log

     

    		F5OS-C:
    • System controller logs: /var/log_controller/velos.log
    • Partition logs: /var/F5/partitionXXX/log/velos.log
    F5OS-A:
    • Appliance logs: /var/F5/system/log/platform.log
    • These are the main F5OS system logs and should be referred to at the first instance of any issues. Messages are consolidated and logged by the rsyslogd daemon.
    • Refer to the F5OS-C on VELOS and F5OS-A on rSeries error catalogs on Clouddocs
    • Example: grep -E 'Emerg|Crit' /var/log_controller/velos.log
    F5OS-C log commands:
    • file show log/controller/velos.log
    • bash access is required to view /var/F5/partitionXXX/log/velos.log
    F5OS-A log commands:
    • file show log/system/platform.log
    Specific F5OS services log filesF5OS-C:
    • System controller: /var/log_controller directory
      Partition: /var/F5/partitionXXX/log directory
    F5OS-A:
    • Appliance logs: /var/F5/system/log directory
    		Some F5OS services have their own dedicated logs in addition to the system logs (velos.log or platform.log). For example, audit.log, devel.log, snmp.log and so on. Refer to the following for the specific service that you are troubleshooting:

    VELOS

    • K000134457: Overview of F5 VELOS chassis controller services
    • K000134684: Overview of F5 VELOS partition services

    rSeries

    • K000134978: Overview of F5 rSeries system services
    F5OS-C log commands:
    • file show log/controller/<file>
    • bash access is required to view /var/F5/partitionXXX/log/<file>
    F5OS-A log commands:
    • file show log/system/<file>
    Common Linux log files/var/log directory

    F5OS-C: Common Linux log files. (E.g. dmesg, messages, secure, openshift.log)
    F5OS-A: Common Linux log files. (E.g. dmesg, messages, k3s.log, appliance.log)

    If you observe cluster issues from the output of show cluster on confD, refer to openshift.log, and k3*.log on F5OS-C and F5OS-A respectively.

     

    file show log/host/<file> displays files in /var/log

    System events and alarms through confD
    • System controller, VELOS Partition: confD
    • rSeries: confD

    Other than log files, you can also find system events, alarms from the F5OS management CLI, confD using the show command. Depending on whether you are accessing the system controller CLI or partition CLI, you can retrieve different log and state information through confD. Refer to the following examples: 

    • show system alarms
    • show system events
    • show system health
    • show cluster
    Docker container logsLogin to bash on the system and use the following syntax:
    docker logs --details -t  <container_name>    		Example:  docker logs --details -t ihealth-service
    Note: When no entries are logged, it does not necessarily indicate an issue.
    Individual application logs within each docker containerLogin to bash on the system and use the following syntax to login into the specific docker container:
    docker exec -it <container_name> bash

    After logging in to the container, logs are generally located in /var/F5 and /var/log directories. For example, the /var/log/httpd/access_log and error_log contains the well known http server logs.

    Example: docker exec -it http-server bash

    Remote loggingRemote server

    Verify logs on your remote server if you configured remote logging

    Configure log verbosity

    The F5OS system lets you adjust the logging level at the software services level (e.g. orchestration-manager, vcc-confd and so on). You can increase the logging verbosity of the software service that you are troubleshooting. To do so, use the following resources:

    • VELOS: K51486849: Configuring the level of information of the VELOS system log messages
    • rSeries: The Log and report configuration overview section of the System Settings of the F5 rSeries Systems: Administration and Configuration manual.

    Depending on whether you logged in to the system controller or partition or rSeries, in the procedure, ensure you have enough diskspace for the additional logs in /var/log_controller and /var/F5/partitionXXX/log/, /var/F5/system/log respectively.
