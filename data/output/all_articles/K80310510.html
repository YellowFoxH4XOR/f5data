Topic

You should consider using this procedure under the following condition:

  • You want to determine which BIG-IP SSL profiles use a specific SSL certificate.

Description

You can determine which BIG-IP SSL profiles use a specific SSL certificate by using the Configuration utility or BIG-IP iControl REST API or BIG-IP command line.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the Configuration utility or BIG-IP iControl REST API.
  • If you plan to use the BIG-IP command line, you should have either the root user access or an administrative user with Advanced Shell access.
  • If you plan to use the BIG-IP iControl REST API, ensure that the workstation you are querying from is installed with the curl and jq utilities.

Procedures

You can use the Configuration utility or BIG-IP iControl REST API or command line to determine which BIG-IP SSL profiles use a specific SSL certificate. To do so, perform one of the following procedures:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

  • Configuration utility
  • iControl REST
  • BIG-IP command line

Configuration utility

  1. Log in to the Configuration utility as the administrative user.
  2. Go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  3. Select the SSL certificate you want to check.
  4. Select Instances.

iControl REST

  1. Log in to the workstation you are querying from.
    Note: The workstation must have the curl and jq utilities installed.
     
  2. Display the list of SSL certificates installed on the BIG-IP system by entering the following command syntax:

    curl -sku <username:password> https://<BIG-IP IP address>/mgmt/tm/sys/crypto/cert/ | jq ‘.items[]|{certname: .name}’

    For example, if you are querying from the BIG-IP command line, replace <BIG-IP IP address> with localhost:

    curl -sku admin:admin https://localhost/mgmt/tm/sys/crypto/cert/ | jq '.items[] | {certname: .name}'

    The command returns output similar to the following example:

    {
      "certname": "/Common/askf5_chain"
    }
    {
      "certname": "/Common/ca-bundle.crt"
    }
    {
      "certname": "/Common/default.crt"
    }
    {
      "certname": "/Common/f5-ca-bundle.crt"
    }
    {
      "certname": "/Common/f5-irule.crt"
    }
    {
      "certname": "/Common/webserver1.askf5.local"
    }

    Note the name of the SSL certificate you want from the returned list.

  3. Determine the Client SSL profiles that are using the SSL certificate by entering the following command syntax:

    curl -sku <username:password> https://<BIG-IP IP address>/mgmt/tm/ltm/profile/client-ssl/ | jq '.items[] | select((.c3dClientFallbackCert,.c3dOcsp,.caFile,.clientCertCa,.proxyCaCert,.certKeyChain[].cert,.certKeyChain[].chain) | contains("<SSL cert name>")) | {profile: .fullPath}'

    For example, if you are querying for Client SSL profiles that are using the SSL cert webserver1.askf5.local, replace <SSL cert name> with webserver1.askf5.local:

    curl -sku admin:admin https://localhost/mgmt/tm/ltm/profile/client-ssl/ | jq '.items[] | select((.c3dClientFallbackCert,.c3dOcsp,.caFile,.clientCertCa,.proxyCaCert,.certKeyChain[].cert,.certKeyChain[].chain) | contains("webserver1.askf5.local")) | {profile: .fullPath}'

    The command returns output similar to the following example:

    {
      "profile": "/Common/clientssl-test"
    }

  4. Determine the Server SSL profiles that are using the SSL certificate by entering the following command syntax:

    curl -sku <username:password> https://<BIG-IP IP address>/mgmt/tm/ltm/profile/server-ssl/ | jq '.items[] | select((.c3dCaCert,.caFile,.chain,.cert,.ocsp) | contains("<SSL cert name>")) | { profile: .fullPath}'

    For example, if you are querying for Server SSL profiles that are using the SSL cert webserver1.askf5.local, replace <SSL cert name> with webserver1.askf5.local:

    curl -sku admin:admin https://localhost/mgmt/tm/ltm/profile/server-ssl/ | jq '.items[] | select((.c3dCaCert,.caFile,.chain,.cert,.ocsp) | contains("webserver1.askf5.local")) | { profile: .fullPath}'

    The command returns output similar to the following example:

    {
      "profile": "/Common/serverssl-test"
    }

BIG-IP command line

  1. Log in to the BIG-IP command line as the root user or an administrative user with Advanced Shell.
  2. Display the list of SSL certificates installed on the BIG-IP system by entering the following command syntax:

    tmsh list /sys crypto cert | grep "sys crypto cert" | awk '{print $4}'

    The command returns output similar to the following example:

    askf5_chain
    ca-bundle.crt
    default.crt
    f5-ca-bundle.crt
    f5-irule.crt
    webserver1.askf5.local

    Note the name of the SSL certificate you want from the returned list.

  3. Determine the Client SSL profiles that are using the SSL certificate by entering the following command syntax:

    tmsh list /ltm profile client-ssl cert | grep -B1 <SSL cert name> | awk '$3 == "client-ssl" { print $4 }' 2> /dev/null

    For example, if you are querying for Client SSL profiles that are using the SSL cert webserver1.askf5.local, replace <SSL cert name> with webserver1.askf5.local:

    tmsh list /ltm profile client-ssl cert | grep -B1 webserver1.askf5.local | awk '$3 == "client-ssl" { print $4 }' 2> /dev/null

    The command returns output similar to the following example:

    clientssl-test

  4. Determine the Server SSL profiles that are using the SSL certificate by entering the following command syntax:

    tmsh list /ltm profile server-ssl cert | grep -B1 <SSL cert name> | awk '$3 == "server-ssl" { print $4 }' 2> /dev/null

    For example, if you are querying for Server SSL profiles that are using the SSL cert webserver1.askf5.local, replace <SSL cert name> with webserver1.askf5.local:

    tmsh list /ltm profile server-ssl cert | grep -B1 webserver1.askf5.local | awk '$3 == "server-ssl" { print $4 }' 2> /dev/null

    The command returns output similar to the following example:

    serverssl-test
