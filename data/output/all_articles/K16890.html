Known Issue

The BIG-IP system may use TCP source port 0 for server side connections.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server to process client traffic.
  • The virtual server source port setting is set to change. The default setting is Preserve.
  • The server side VLAN CMP hash value is set to either src-ip or dst-ip. The default setting is Default.

Impact

Server side TCP ports are reused too quickly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system is using TCP port 0 for server side connections.
  • Server side TCP ports are being reused too quickly.
