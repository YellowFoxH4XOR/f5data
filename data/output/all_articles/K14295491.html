Description
Merging configuration from the terminal fails with an error message. 

    root@(LTM1.Example.com)(tmos)# load sys config merge from-terminal
    Enter configuration. Press CTRL-D to submit or CTRL-C to cancel.
    gtm listener gtm_listener_udp {
        address 192.168.1.254
        ip-protocol udp
        mask 255.255.255.255
        port domain
        profiles {
            dns { }
            udp_gtm_dns { }
        }
        translate-address disabled
        translate-port disabled
    }
    Loading configuration...
    Syntax Error: "gtm-listener" component cannot be loaded because it is not a valid component.
    root@(LTM1.Example.com)(tmos)#

Environment

  • GTM listeners
  • Merging Configuration 
  • TMSH / CLI

Cause

If the GTM listener is merged via terminal or a file, an error message is displayed as given below under /var/log/ltm file or TMSH command line. 

Syntax Error: "gtm-listener" component cannot be loaded because it is not a valid component.

Recommended Actions

To merge 'gtm listener' configuration, the following steps can be taken to modify the configuration pre-merge:
  1. Replace 'GTM listener' with 'LTM virtual'
  2. Replace 'address' with 'destination'
  3. Add ':<port number>' to the end of the destination address
  4. Remove the 'port' line
The following example shows the appropriate configuration to merge a 'gtm listener' configuration:

    root@(LTM1.Example.com)(/Common)(tmos)# load sys config merge from-terminal
    Enter configuration. Press CTRL-D to submit or CTRL-C to cancel.
    ltm virtual gtm_listener_udp {
        destination 192.168.1.254:53
        ip-protocol udp
        mask 255.255.255.255
        profiles {
            dns { }
            udp_gtm_dns { }
        }
        translate-address disabled
        translate-port disabled
    }
    Loading configuration...
    root@(LTM1.Example.com)(/Common)(tmos)#
