K000137801: There may be a mismatch between the actual boot locations available when comparing the Big-IP and Big-IQ

Type
Support Solution
Published
2023-12-05
Updated
2023-12-05
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0
Source
https://my.f5.com/manage/s/article/K000137801

Description

When using BIG-IQ to manage devices and reviewing the device properties, and looking at the available boot locations in BIG-IQ GUI, you see the volume information does not match.  This can happen when adding new or removing existing volumes.

Example below (left side is the managed device with HD1.2 and HD1.4, right side is BIG-IQ only showing HD1.4)

 

Environment

BIG-IQ
BIG-IP managed device

Cause

Big-IP doesn't dynamically refresh the API endpoint the Big-IQ uses to gather this information.

Recommended Actions

Restart restjavad on the managed device and wait a minute:

# bigstart restart restjavad

Impact: While restjavad restarts you will temporarily lose rest API calls. There is no impact to TMM traffic.

 

Additional Information

None
