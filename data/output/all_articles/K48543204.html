Description

When trying to reconfigure iapp that was deployed with LDAP template you are unable to edit. 
you may see similar messages in the webui log or in the webui

  • Error parsing template:MCP call 'mcpmsg_set_string_item(msg, CID2TAG(m_cid), val.c_str())' failed with error: 16908375, 01020057:3: The string with more than 65535 characters cannot be stored in a message.
  • webui	 2021-09-20 21:24:26.608 +02:00 	 Error	 ajp-bio-127.0.0.1-8009-exec-8 application.template_jsp:error - com.f5.app_template.BindingException: MCP call 'mcpmsg_set_string_item(msg, CID2TAG(m_cid), val.c_str())' failed with error: 16908375, 01020057:3: The string with more than 65535 characters cannot be stored in a message.
at com.f5.app_template.TclDataBinder.getAsScalar(TclDataBinder.java:87)

Environment

This occurs when there is a large configuration or a large number of items to be returned from a query the iApp calls.

  • return string exceeds 65K character
  • iApp configured using the default LDAP template

Cause

Limitation in the amount of data that can be returned from iApp

Recommended Actions

  1. Manually reconfigure the LDAP template to make use of ::safe_display function
- Create a copy of f5.ldap iApp template

  iApps > Templates > click f5.ldap > scroll to bottom and click Copy

  * default name of file is "Copy_of_f5.ldap"

 - Edit the "Presentation" section of "Copy_of_f5.ldap" and change the following:


         choice pool_to_use display "xxlarge" default "/#create_new#" tcl {
            package require iapp 1.1.3
            return "/#create_new#\n[iapp::get_items ltm pool]"

TO:

        choice pool_to_use display "xxlarge" default "/#create_new#" tcl {
            package require iapp 1.1.3
            set ::choices  "/#create_new#\n[iapp::get_items ltm pool]"
	    return  [iapp::safe_display ::choices]
        }

==============================================================================

	optional ( create_new_pool == "Use Pool..." ) {
            choice reuse_pool_name display "xlarge" tcl {
                tmsh::run_proc f5.app_utils:get_items ltm pool
                package require iapp 1.1.3
                return [iapp::get_items ltm pool]
            }
        }

TO:

        optional ( create_new_pool == "Use Pool..." ) {
            choice reuse_pool_name display "xlarge" tcl {
                tmsh::run_proc f5.app_utils:get_items ltm pool
                package require iapp 1.1.3
                set ::choices  [iapp::get_items ltm pool]
	        return [iapp::safe_display ::choices]
            }
        }

==============================================================================

- click Save
- Create a new iApp using "Copy_of_f5.ldap" template
