Description

ASM requires an HTTP profile to be attached to the Virtual Server in order to operate.  The FIX protocol is not HTTP and instead uses the FIX profile on BIG-IP.  ASM does not understand the FIX protocol.

Environment

  • BIG-IP ASM
  • FIX protocol

Cause

ASM does not understand the FIX protocol

Recommended Actions

None

About FIX profiles
