Known Issue

Multiple concurrent requests for a resource can cause excessive BIG-IP APM memory usage.

This issue occurs when all of the following conditions are met:

  • Access to a resource is provided by a virtual server configured with an APM Access Profile.
  • Multiple concurrent attempts to access the resource are processed by the BIG-IP APM system.

Impact

A memory leak occurs, which may cause the BIG-IP APM system to experience memory exhaustion. If the system is configured for high-availability, the device may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Memory usage on the BIG-IP APM system steadily increases over time.
  • Traffic processing by the BIG-IP APM system is impaired or halts.
  • Aggressive mode sweeper messages appear in the /var/log/ltm file.
  • The /var/log/httpd/access_log file is filled with entries containing "/access_notfound.php3?ORIG_URI=".
