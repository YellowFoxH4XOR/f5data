Description

F5 recommends having devices with the same FIPS firmware version. In an RMA situation, the replacement device may have a different version of FIPS firmware. 

Note: FIPS synchronization will still work in most cases with different versions, however, its always a good practice to have same version on HA devices.

Combinations of versions that have been tested to synchronize correctly.

  • 1.0-39 to 1.0.52
  • 1-0-39 to 1.1.02
  • 1.0.52 to 1.1-02

 

Environment

  • FIPS
  • BIG-IP 13.1.x
  • BIG-IP 14.1.x
  • BIG-IP 15.1.x
  • BIG-IP 16.1.x
  • BIG-IP 17.0.x
  • BIG-IP i5820
  • BIG-IP i7820
  • BIG-IP i15820
  • BIG-IP 10350V-F

Cause

Receiving an RMA replacement device with newer FIPS Firmware
 

Recommended Actions

It is not recommended to downgrade FIPS version if you receive RMA device with higher version of FIPS. Best practice is to upgrade device with the older FIPS firmware version to a newer version.

For instance

  • LTM-1 device is running and installed with FIPS firmware 1.0.39
  • RMA device is with FIPS firmware 1.1.02

In the above scenario it is recommended to upgrade FIPS firmware version of LTM-1 to 1.1.02. 

Note: Upgrading FIPS firmware will not delete the existing FIPS keys. Best practice is to create a system backup before making any changes.

 

Upgrade Actions

  1. Verify FIPS firmware version with the command fipsutil info
  2. Upgrade from 1.0.39  to 1.0.52 please see instructions in K26061560
  3. Upgrade from 1.0.39 to 1.1.02 requires a step upgrade
    • First upgrade to 1.0.52 K26061560
    • Second upgrade to 1.1.02 instructions are in the FIPS Administration guide

Additional Information

If the RMA device is with older version, consider the firmware upgrade on the RMA device to match to the working device.
