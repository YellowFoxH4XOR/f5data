Known Issue

Querying the configuration data of a virtual server that is associated with a local traffic policy may fail when you use the representational state transfer (REST) interface for iControl.

This issue occurs when all of the following conditions are met:

  • You have added the iControl REST service to the BIG-IP system.
  • You attempt to query the configuration data of a virtual server using the iControl/REST API.
  • The affected virtual server is associated with a local traffic policy.

Starting in BIG-IP 11.4.0, you can associate a virtual server with a Local Traffic Policy. For more information, refer to the Local traffic policies chapter of the BIG-IP Local Traffic Manager: Concepts guide.

Impact

You cannot query the affected virtual server using the REST interface for iControl.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • RESTful request to the iControl service returns an HTTP 500 - Error Response, similar to the following example:

    {"code": 500,"message": "Status code:500, uri:http://localhost:8110/tm/ltm/virtual/vip_ssl/

Workaround

There is no workaround for this issue. However, you can query the affected virtual server on the local BIG-IP system by using the Configuration utility or Traffic Management Shell (tmsh).
