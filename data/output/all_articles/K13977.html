K13977: Active FTP connections may fail when an FTP virtual server is configured to reference another FTP virtual server

Known Issue

Description

If a virtual server is configured with an iRule that targets another FTP virtual server on the same BIG-IP system, Active FTP connections will fail.

This issue occurs when the following condition is met:

  • Each FTP virtual server has an FTP profile associated

Impact

FTP clients are unable to transfer files or list directories in Active mode.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • FTP will fail to build data channel in Active mode
  • FTP PORT command is not passed to the FTP virtual server referenced by the iRule

Resolution

Status

F5 Product Development has assigned ID 366901 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can remove the FTP profile from the FTP virtual server configured with the iRule that targets the second FTP virtual server. To do so, perform the following procedure:

Impact of workaround: Changing the profile type for a virtual server may have additional effects on traffic processing. Ensure any modification is compatible with your environment.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Choose the FTP virtual server configured with the iRule that references the second FTP virtual server.
  4. Change the FTP Profile setting to None.
  5. Click Update.
