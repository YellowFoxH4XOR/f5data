K03743990: Application service remove fails with ''Failed to get cm-bigip-allBigIpDevices device java.lang.IllegalStateException: Device not found in device group.: Device not found in device group'' error

  • BIG-IQ Centralized Management: 8.0.0, 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X
Source
https://my.f5.com/manage/s/article/K03743990

Description

Removing application service in BIG-IQ CM GUI may receive the below error: 

Failed to get cm-bigip-allBigIpDevices device java.lang.IllegalStateException: Device not found in device group.: Device not found in device group

Environment

  • BIG-IQ
  • Application service
  • CLI

Cause

Dependencies not fully deleted in BIG-IQ database

Recommended Actions

Application component can be remove via CLI.
1. Login into the active BIG-IQ CM CLI
2. List the applications that you are trying to delete:

restcurl /cm/global/global-apps/ | jq '.items[]|{name:.name,id:.id}'

Example output:

{
  "name": "Unknown Applications",
  "id": "69cf49ad-de27-3540-b38f-9773d06ca1c4"
}
{
  "name": "MyApplicationToRemove",
  "id": "2f2520c6-277b-3730-a2be-ac1c60b8f048"   
}

3. Check deployed application in the group:

restcurl /cm/global/global-apps/<app-id>

Example:

restcurl /cm/global/global-apps/2f2520c6-277b-3730-a2be-ac1c60b8f048

{
  "name": "MyApplicationToRemove",
  "description": "",
  "componentCount": 1,
  "appComponents": [
    {
      "configSetName": "MyApplication_Component_To_remove",
      "selfLink": "https://localhost/mgmt/cm/global/config-sets/bbe56026-af78-39c0-9871-378554651787"    <---------- Line with component ID
    }
  ],
  "id": "2f2520c6-277b-3730-a2be-ac1c60b8f048",
  "generation": 1,
  "lastUpdateMicros": 1606402688387029,
  "kind": "cm:global:global-apps:globalapplicationstate",
  "selfLink": "https://localhost/mgmt/cm/global/global-apps/2f2520c6-277b-3730-a2be-ac1c60b8f048"
}

4. Remove application component:

restcurl -u admin:admin /mgmt/cm/global/config-sets/<component-ID> -X DELETE

Example:

restcurl -u admin:admin /mgmt/cm/global/config-sets/bbe56026-af78-39c0-9871-378554651787 -X DELETE
