Topic

This article applies to BIG-IP versions 9.x and 10.x. For information about other versions, refer to the following article:

  • K13144: Determining the BIG-IP model and platform type (11.x - 13.x)

BIG-IP platforms are identified by a model name and platform type. You can determine the model and type of your BIG-IP hardware platform from the command line, or by physically inspecting the system. To do so, perform one of the following procedures:

Identifying your platform using the command line

  1. Log in to the command line.
  2. Type the following command:

    bigpipe platform

    The command output displays similar to the following example:

    PLATFORM INFORMATION --
    |     Marketing Name: BIG-IP 3400
    |     BIOS Rev: S (C)2001 American Megatrends Inc., Version 07.00.00 TYAN S2707 Motherboard v1.05a 0227041730 OBJ-0075-00 REV. F
    |     base MAC: 00:01:D7:32:07:80
    |     PVA Version: 2
    +-> SYSTEM INFO
    |     Type: C62
    |     Chassis   serial: bip073080s   Level 200 part: 200-0116-05 REV C
    |        Switch board   serial: PCA0063MF401   part: PCA-0063-05 REV A
    |     Host board   serial: TY5AG0510415   part: MOB-0013-01 REV A
    |     Annunciator board   serial: 1234563   part: OEM-0029-02 REV A
    |     Memory: 1.479GB

    The command output indicates a marketing name of BIG-IP 3400, and the platform type is listed as C62.

    Note: On the following platforms: 1500, 1600, 3400, 3410, 3900, 6400, 6800, 6900, 8400, 8800, 8900, 8950, 11050 and VIPRION blades, the PLATFORM INFORMATION will list the platform in the Marketing Name section. Older platforms that support BIG-IP versions 9.x and 10.x will display the chassis type in the Type section.

Identifying your platform by physical inspection

If you are unable to boot your BIG-IP system, you must identify the system based on physical inspection. Use the following methods to identify your platform:

  • The LCD display may show the model.
  • For the BIG-IP 1600, 3600, 3900, 6900, and 8900 platforms, the model number is located on the front panel above the LCD display.
  • For the VIPRION platform, the word VIPRION is printed to the left of the LCD display.
  • For the BIG-IP 1500, 3400, 3410, 4100, 4500, 6400, 6800, 8400, and 8800 platforms, the model number is located on a label on the back above the CE logo. If there is no label with the CE logo, there should be a small label with a 200-level part number and a platform identifier.
