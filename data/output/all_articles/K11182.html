To view or install OPSWAT hotfixes on a BIG-IP APM version 10.1.0 system, you must enter the epsec command at the BIG-IP command line. Currently, you cannot manage OPSWAT hotfixes using the BIG-IP APM Configuration utility in version 10.1.0.

Note: For instructions about installing OPSWAT hotfixes, refer to K10942: Installing OPSWAT hotfixes on BIG-IP APM systems.

F5 Product Development tracked multiple requests for enhancement (RFE) to add an option to the BIG-IP APM Configuration utility to manage OPSWAT hotfixes as ID 242449 (formerly CR133973),  ID 243260 (formerly CR136115), and ID 243283 (formerly CR136180). This enhancement was included in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.
