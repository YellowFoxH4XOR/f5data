Known Issue

This is the result of a known issue. The Enterprise Manager external database feature is designed to work on a standalone system or in a high-availability system in an active/standby pair. To ensure proper communication with the database, the Enterprise Manager system stores a unique identifier on the external database system. The Enterprise Manager system may lose access to the external database in the following two scenarios:

  • You configure an Enterprise Manager system to use an external database, and you later replace that Enterprise Manager system with another system.
  • You associate the Enterprise Manager system with an external database and then upgrade the Enterprise Manager software on another boot location.

F5 Product Development is tracking this issue as ID 351014.

Workaround

To work around this issue and restore access to the external database system, you must perform one of the following procedures:

  • Resetting the external database
  • Resetting the unique identifier on the external database

Note: The external database must reside on a system that runs Oracle MySQL 5.1 with patch 30 or later.

Resetting the external database

To reset the database (remove all collected data), create a new external database, and configure the new Enterprise Manager system to use the external database, perform the following procedure:

Note: When you perform this procedure, you lose all data in the existing database. As a result, you do not have to reset the unique identifier on the external database.

  1. Log in to the MySQL database on the external database system.
  2. Create a new database by using MySQL command syntax similar to the following example, where <database> is the name of the external database:

    create database <database>

  3. To grant appropriate privileges to the database, use the following command syntax, where <host> includes the IP address of the Enterprise Manager system that is storing data on the external database and <password> is the password for the user name specified:

    grant all privileges on <database>.* to <username>@<host> identified by <password>

  4. To set privileges to the specified user to execute stored procedures required for the Enterprise Manager system to store and access data on the external database, type the following command:

    grant select on mysql.proc to <username>@<host>

  5. To relax the privilege conditions so that the Enterprise Manager system can create necessary stored functions and procedures that enable you to store and retrieve statistics data, type the following command:

    set global log_bin_trust_function_creators = 1

You may now configure the new Enterprise Manager system to store statistics in the database you created. For specific instructions, refer to the Configuring Enterprise Manager to store statistics to an external database section of the Enterprise Manager: Monitoring Network Health and Activity manual.

Resetting the unique identifier on the external database

To reset the unique identifier on the external database and configure the Enterprise Manager system to use the external database (while retaining the previously collected data), perform the following procedure:

Important: Resetting the identifier on the external database allows you to merge data from the previously installed Enterprise Manager system with data you collect using the new Enterprise Manager system. Merging this data may cause some data corruption. To avoid any potential issues, we recommend that you perform the Resetting the external database procedure instead.

  1. Log in to the MySQL database on the external database system.
  2. Use MySQL command syntax similar to the following:

    DELETE FROM metadata WHERE name = 'em.statistics.origin.id'

You may now configure the Enterprise Manager system to store statistics in the external database. For specific instructions, refer to the Creating an external database for health and performance monitoring statistics storage section of the Enterprise Manager: Monitoring Network Health and Activity manual.
