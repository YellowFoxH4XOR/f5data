K10220: The password expiration warning may not display if the gPLink attribute contains multiple Group Policy Objects

Known Issue

This is the result of a known issue. The gPLink attribute is a Windows Group Policy attribute that contains a prioritized list of Group Policy Objects (GPOs). If the gPLink attribute returned by an Active Directory server contains multiple GPOs, FirePass may not display a password expiration warning to users.

This issue occurs because FirePass only examines the first GPO defined in gPLink. If the password expiration policy is defined in a subsequent GPO, FirePass does not retrieve the password policy for that GPO. Therefore, FirePass does not warn users of password expiration.

Note: The Active Directory password expiration warning was introduced in FirePass version 6.0.3. For more information, refer to K9790: Change in Behavior: FirePass now warns users when their Active Directory password is set to expire.

F5 Product Development tracked this issue as ID 296444 (formerly CR122548) and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally this issue has been fixed in cumulative hotfix HF-603-4 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
