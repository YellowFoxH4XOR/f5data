Topic

The BIG-IP system has two sets of Simple Mail Transfer Protocol (SMTP) configurations to support email message delivery in various modules and features. This article describes the differences between mailhub and device SMTP configurations, and their supporting modules/features on the BIG-IP system.

Description

You should verify the corresponding SMTP configurations on the BIG-IP system before implementing local email delivery required features. The two SMTP configurations are listed as follows:

The outbound SMTP mailhub

The BIG-IP mailhub configuration is used by ssmtp to send locally generated email messages. You should configure the mailhub when you want email delivery function for the SNMP trap alerts configured in the /etc/alertd/alert.conf and the /config/user_alert.conf files on the BIG-IP system.

Note: The mailhub is only configurable from the BIG-IP command line. For more information, refer to: K13180: Configuring the BIG-IP system to deliver locally generated email messages.

The BIG-IP system device SMTP server

The device SMTP server can be configured from the BIG-IP Configuration utility by navigating to System > Configuration > Device > SMTP. The configuration is required for enabling email delivery service on the following modules and features:

  • AVR Application Statistics Collection
  • ASM Health and Resource Alerts
  • ASM Application Security Reports
  • APM One-Time Password (OTP) Authentication
  • APM Secure Web Gateway (SWG) Statistics
  • AAM ROI Statistics
  • PEM Application Visibility Statistics

You must configure the device SMTP server before you can enabling email delivery function on these reports, alerts, and statistics.
