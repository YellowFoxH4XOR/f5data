K000130593: Upgrade fails with error message: Unable to allocate necessary space (XXXXX KiB) on sda.dat.boot

Type
Support Solution
Published
2023-01-25
Updated
2023-01-25
Source

Description

The upgrade fails with the following message in liveinstall.log:


info: No sysinit extension supplied for disk sda, location X.

error: tm_install::Process::update_boot_files -- Unable to allocate necessary space (XXXXX KiB) on sda.dat.boot

Terminal error: Failed to install.

*** Live install end at XXXX/XX/XX XX:XX:XX: failed (return code 2) ***


Environment

  • BIG-IP
  • Installation into new boot volume

Cause

During the creation of a new boot volume the process fails due to lack of space in /dev/sda1(sda.dat.boot) to create an initial ramdisk(initrd) for a new volume.


 Recommended Actions

Remove unused volumes to free up space. To do so, follow the instructions provided in K33265170: Deleting a boot location volume to free up disk space.
