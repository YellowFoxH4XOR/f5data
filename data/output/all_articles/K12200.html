Known Issue

This is the result of a known issue. If you configure a NAT or SNAT for a non-default route domain, the BIG-IP system does not report statistics for that NAT.

For example:

nat 10.0.0.240%1 to 192.168.1.240%1

The following example displays no statistics for the configured NAT:

[root@B6900:Active] config # tmsh show ltm nat

NAT: 2610:0:c10:f501:0:1:a01:f0
---------------------------------
Traffic                ServerSide
  Bits In                       0
  Bits Out                      0
  Packets In                    0
  Packets Out                   0
  Current Connections           0
  Maximum Connections           0
  Total Connections             0

[root@B6900:Active] config # bigpipe nat
NAT 10.0.0.240%1  TO 192.168.1.240%1
|     enable    ARP enable    unit 1
|     (cur, max, limit, tot) = (0, 0, 0, 0)
|     (pkts,bits) in = (0, 0), out = (0, 0)
[root@B6900:Active] config #

Note: The default route domain has an implicit value of zero.

F5 Product Development tracked this issue as ID 341323, and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, LinkController,  WebAccelerator, WOM, APM, Edge Gateway release notes.
