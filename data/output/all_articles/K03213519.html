Description

In the Configuration Utility (GUI), under Devices > License management > Licenses.
After the license is added, the license status shows

"Waiting For Offering License Texts" 

or

"Status: ACTIVATING_MANUAL_OFFERINGS_NEED_LICENSE_TEXT"
 

Environment

  • BIG-IQ License Manager
  • ELA License 
  • Manual activation
  • Load license

Cause

The error occurs because only the main ELA license was activated, not the offerings. 
 

Recommended Actions

When using the MANUAL activation method, each offerings must be manually activated as well. To activate each offerings, follow these steps. 

  1. Click on license Name to expand the ELA offerings
  2. Click on offering name
  3. Copy dossier from Device Dossier box. 
  4. Paste the dossier into the Enter Your Dossier box, and then click Next
  5. Copy the license and paste it into License text on BIG-IQ
  6. Click on Activate in the bottom right of the screen.
  7. Repeat this for each of the ELA license offerings available.
