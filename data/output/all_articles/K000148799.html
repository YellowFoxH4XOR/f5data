K000148799: BIG-IP Next SPK tmm pod has a missing vlan after restart

Type
Support Solution
Published
2024-12-04
Updated
2024-12-04
Applies to
  • BIG-IP Next
  • BIG-IP Next SPK: 1.7.11, 1.7.10, 1.7.9
Source
https://my.f5.com/manage/s/article/K000148799

Description

When restarting tmm pods, one or more can come back up with a missing vlan interface.

Environment

  • BIG-IP Next SPK

Cause

This is a known issue ID1670313 that can happen when a simultaneous TMM scale-down and scale-up event occur (ie. one pod is in the deletion state while another pod is starting up).

Recommended Actions

The recommended workaround is to update the ConfigMap to match the self IP assignments on the TMMs and restart the F5ingress pod.
