K000161354: Tenant console fallback authentication fails when TACACS+ is unavailable and systemauth.nolocalonly=true

Type
Support Solution
Published
2026-05-22
Updated
2026-05-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000161354

Description

When using TACACS+ as remote authentication with Fallback to Local Auth enabled logging in directly to the console fails with no error, just returning the login prompt.

Environment

TACACS+ remote Authentication on Big-IP

 

Cause

When PAM fails to connect to the TACACS server the console login service fails instead of falling back to local auth. SSH and HTTP access continue to fail back properly

 

Answer/Recommended Actions

Either use SSH to connect or use a remote auth method other than TACACS+
