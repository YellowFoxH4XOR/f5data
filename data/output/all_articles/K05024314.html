Description

  • Unexpected failover
  • The following error messages can be seen on var/lib/mysql/mysqld.err

    /usr/sbin/mysqld: Can't create/write to file '/var/tmp/ib5K4hBL' (Errcode: 28)
    210907  9:17:03  InnoDB: Error: unable to create temporary file; errno: 28

  • An error message similar to the following can be seen on var/log/asm

    crit g_server_rpc_handler.pl[14695]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::SetActive::Impl::set_active): Setting policy active failed: DBD::mysql::db column_info failed: Got error 28 from storage engine at /usr/local/share/perl5/F5/DbUtils.pm line 199.
     

Environment

  • ASM provisioned
  • HA pair

Cause

Seen behaviour is the result of /var/tmp directory running our of space.

Recommended Actions

Manually delete files in /var/tmp/ following the recommendation described on K14403 to maintain adequate disk space.

Additional Information

None.
