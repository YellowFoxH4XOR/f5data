K000163179: BIG-IP Tenant configuration load fails with 01070257 after F5OS-A VLAN or LAG changes

Type
Support Solution
Published
2026-09-02
Updated
2026-09-02
Applies to
  • F5 Distributed Cloud Services
Source
https://my.f5.com/manage/s/article/K000163179

Description

A BIG-IP tenant fails to load its saved configuration after a VLAN, interface, trunk, or LAG change on the F5OS-A host.

The configuration load fails with:

01070257:3: Requested VLAN member (1.5) is currently a trunk member
Unexpected Error: Loading configuration process failed.

Environment

  • F5OS-A 1.5.x
  • F5OS-A rSeries R2800 and R4800
  • BIG-IP tenant

Cause

Bug 1292541: Loading saved configuration on BIG-IP fails if host modifications are made after tmsh save sys config on R2800/R4800 platforms.

Answer/Recommended Actions

1. Roll back the F5OS-A VLAN, interface, trunk, or LAG change to the last known-good configuration.

2. Confirm the BIG-IP tenant returns to Active and that tmsh load sys config completes successfully.

3. Upgrade F5OS-A to a supported 1.8.x release or later before making further production LACP changes. F5OS-A 1.5.1 reached End of Technical Support on August 31, 2026.
