Known Issue

This is the result of a known issue. If you run the End User Diagnostics (EUD) test #6 and see the 12VDC voltage reading at 4.87 or a value much lower than 12V, this is a known issue with the EUD test, and is not a hardware issue.

The following is an example of the output of the End User Diagnostic test #6, where the voltage reading displays incorrectly:

LCD test started.
Firmware ver: CFA541:h3.0,b0.99.
Original ATX Power Control = active low
Original ATX Reset Control = active low
ATX Power Control = active low
LCD data[0]=139 data[1]=11
5VDC voltage reading: 4.92V
LCD data[2]=0 data[3]=0
12VDC voltage reading: 4.87V <-----------------

F5 tracked this issue as CR58666 and it was fixed in BIG-IP LTM, GTM, and ASM 9.4. For information about upgrading, refer to the LTM, GTM, or ASM Release Notes.
