Issue

Old Behavior

In versions of BIG-IP earlier than 12.1.3 and 13.1.0, the following platforms cannot provide hardware acceleration of AES-GCM ciphers to Virtual Clustered Multiprocessing (vCMP) guests:

  • B2100 blade
  • B2150 blade
  • B4200 blade
  • B4300 blade
  • B4340N blade

vCMP guests can still perform AES-GCM in software. AES-GCM was enabled by default starting in BIG-IP 11.6.0.

New Behavior

Beginning in BIG-IP 12.1.3 and 13.1.0, all affected platforms supporting vCMP can offer hardware acceleration for AES-GCM ciphers to vCMP guests.

F5 Product Development tracked this change as ID 650152.

Impact

You should see reduced CPU usage on vCMP guests using AES-GCM ciphers on affected platforms.

Recommended Actions

When you implement vCMP guests with affected platforms, you should consider the following:

  • You must upgrade both vCMP host and vCMP guest to take advantage of this change.
  • Prior to this change, if you do not require the use of AES-GCM ciphers and you are using an affected platform running BIG-IP 11.6.0 or later, you may be able to reduce CPU usage by disabling AES-GCM.
