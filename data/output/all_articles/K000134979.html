Description

When running version 15.1 and using cipher group in the serverssl profile, SSL handshake is not completed.

If in the pcap you can see that F5 sends a Client Hello to the pool member and there's no response (no Server Hello).

Validate the signature algorithms send in the Client Hello.

rsa_pkcs1_sha1 is not present in the not-working scenario.

 

Environment

- LTM,

- https pool member,

- pool member uses a certificate with sha1WithRSAEncryption signature,

- cipher group is being used in the serverssl profile.

 

Cause

SHA-1 is an old and weak algorithm that is being deprecated.

 

K36506401 Deprecation of SHA-1 SSL certificates

ID1106037 Remove support for legacy signature algorithms as per RFCs rfc9155, rfc5246, rfc8446

 

 

On 15.1, the cipher rule cannot be configured with this rsa-sha1 signature algorithm.

However, cipher suite can still be used which supports this signature algorithm.

 

Recommended Actions

It's recommended to not use insecure certificates signed with sha1WithRSAEncryption.

If necessary use cipher suite instead of cipher group in the serverssl profile to allow these certificates.
