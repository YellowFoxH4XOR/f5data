K54688334: APM NetworkAccess static DNS hosts are not available with ''DialUp Entry / Window Integration'' mode.

Type
Support Solution
Published
2025-04-09
Updated
2025-04-09
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • VIPRION Platforms
Source
https://my.f5.com/manage/s/article/K54688334

Description
With APM NetworkAccess, we can establish VPN connections during Windows login. This is known as "Windows Logon / DialUp Entry".
At the same time, the APM NetworkAccess object allows for static hosts to be created.
When using "Windows Logon", those static hosts are not available to the client, when the VPN is eventually up.

Environment

  • You're using APM;
  • You're using the NetworkAccess /VPN feature;
  • This VPN object is set up with "Static Hosts".

Cause
This is known limitation.
Such limitation is tracked through the following bugID: ID563470 DNS domain suffix in NA does not take effect if user login via "Network Logon"

Recommended Actions

None.
