K000132439: iQuery connections can be broken or with intermittence if DNS server objects are configured with certain characters

Type
Support Solution
Published
2023-02-07
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.1.3
Source
https://my.f5.com/manage/s/article/K000132439

Description

  • iQuery connections can be broken or with intermittence if DNS server objects are configured with certain characters
  • iQuery connections are unstable
  • Error messages like this can be seen on GTM logs:

no reply from big3d: timed out

BIG-IP GTM /Common/<DNS-server-name> (<ip-address>) left sync group Sync

 

Connection complete to <ip-address> Starting SSL handshake

SSL handshake complete to <ip-address>

 

Environment

  • DNS module provisioned
  • DNS server objects misconfigured

 

Cause

  • DNS Server objects configured with names that contain certain characters like: ", {, }, ^, &, :
  • For example, a DNS server object configured with a name like this can cause this condition, because it contains a & symbol :

            gtm server /Common/NameServer&2

 

 Recommended Actions

  1. Do not use the special characters shown in this article when configuring an DNS server object.

Additional Information

K59339744: BIG-IP DNS object names should not contain certain characters or words
