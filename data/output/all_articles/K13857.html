Known Issue

A BIG-IP iRule may fail to parse cookies with an all-numeric name.

This issue occurs when the following conditions are met:

  • The iRule references the HTTP::cookie command
  • The client sends a cookie containing an all-numeric name

A cookie with an all-numeric name is allowed according to RCF2109, and may appear similar to the following example:

1234=cookie_value

Impact

The BIG-IP system may close the connection with a TCP RST packet.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system logs an error message to the /var/log/ltm file that appear similar to the following example:

    tmm1[5138]: 01220001:3: TCL error: MyiRule <HTTP_REQUEST> - expected boolean value but got "" while executing "if { [HTTP::cookie exists "1234"] } { HTTP::cookie secure "1234" enable }"

  • The BIG-IP system closes the connection with a TCP RST packet.
