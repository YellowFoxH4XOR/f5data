Description

To extract the configuration from another Boot Volume, while being on the active/default (current) Boot Volume is desired

Environment

Verify the configuration files from another Boot Volume.

Cause

None

Recommended Actions

Impact of procedure: There should not be any impact to your system as long as you do not modify or remove any files in the mounted directory.

  1. Mount the bootable volume on which you have the old boot volume installed:
    volumeset -f mount HD1.x
  2. Then change directory to the mounted units config fylesistem:
    cd /mnt/HD1.x/config/

For example:
