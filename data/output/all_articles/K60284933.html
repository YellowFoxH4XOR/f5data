Description

BIG-IP has a constant disk partition warning for /shared and /usr.

The file csyncd.out in the partition /shared/tmp fails with below error, and the partition is getting full.

# tail -n 50 csyncd.out rsync: change_dir#3 "/home/f5cm/cm/bigip14.1.2.3/1161432/f5_build/BUILD/clusterd-14.1.2.3/cov_obj" failed: No such file or directory (2)

Environment

  • Disk partition warnings

Cause

Unknown at the time of creation of this article.

Recommended Actions

In some cases you need to stop the csyncd process and deleted the csyncd.out file:

  1. Stop the csyncd process:
    bigstart stop csyncd
  2. Run a process check to verify csynced has stopped:
    ps -e|grep csyncd
  3. Remove the largest file in the volume that is not needed, the csyncd.out file:
    rm -f /shared/tmp/csyncd.out
  4. List the file to verify it has been removed:
    ls -l /shared/tmp/csyncd.*
  5. Start the csyncd process:
    bigstart start csyncd
  6. Check the volume size:
    df -h
