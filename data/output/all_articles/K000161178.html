K000161178: How to determine whether the debug mode of the ConfD process is enabled or disabled

Description

When you have enabled/disabled debug logs from the F5OS for the ConfD process and you would like to verify the current value.

Environment

  • F5OS-A
  • Enabling or disabling debug logs from the F5OS for the ConfD process

Cause

None

Answer/Recommended Actions

  • Use the following command to display the current value of /confdConfig/logs/developerLogLevel:

 

  ゜docker exec system_manager confd_cmd -c 'mget /confdConfig/logs/developerLogLevel'

 

  • To change the value, use:

 

  ゜docker exec system_manager confd_cmd -c 'mset /confdConfig/logs/developerLogLevel <desired_level>'

 

Replace <desired_level> with the required log level (e.g., info, trace).

 

For example :

[root@appliance-1:Active] ~ # docker exec system_manager confd_cmd -c 'mset /confdConfig/logs/developerLogLevel trace'
[root@appliance-1:Active] ~ # docker exec system_manager confd_cmd -c 'mget /confdConfig/logs/developerLogLevel'
trace


[root@appliance-1:Active] ~ # ~ # docker exec system_manager confd_cmd -c 'mset /confdConfig/logs/developerLogLevel info'
[root@appliance-1:Active] ~ # ~ # docker exec system_manager confd_cmd -c 'mget /confdConfig/logs/developerLogLevel'
info
