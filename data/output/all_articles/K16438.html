Known Issue

Access policy Endpoint Security Client-Side agent checks may fail to correctly detect the user device state.

This issue occurs when all of the following conditions are met:

  • Users are connecting to the BIG-IP APM access profile using the Mac OS X operating system.
  • Your access policy is configured with one or both of the following Endpoint Security Client-Side agents:

    • Firewall Software Check agent
    • Hard Disk Encryption Check agent.
  • When configured with the Firewall Software Check agent, the connecting user device uses the ipfw firewall.

Impact

Users are unable to connect to the BIG-IP APM access profile.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When users attempt to access the BIG-IP APM system, their session is terminated with the following error message:

    Your session could not be established.
    The session reference number: <session id>
    Access was denied by the access policy. This may be due to a failure to meet access policy requirements.

  • In the /var/log/apm file, you may observe log messages similar to the following example, at the time of the event, when you configure your access policy with the Firewall Software Check agent and the user's device uses the ipfw firewall type:

    notice apd[7187]: 01490010:5: 3789d1c2: Username '<username>'
    notice apd[7187]: 01490005:5: 3789d1c2: Following rule 'fallback' from item 'Firewall' to ending 'Deny'
    notice apd[7187]: 01490102:5: 3789d1c2: Access policy result: Logon_Deny
    notice tmm[10736]: 01490501:5: 3789d1c2: Session deleted due to user logout request.

  • In the /var/log/apm file, you may observe log messages similar to the following example, at the time of the event, when you configure your access policy with the Hard Disk Encryption Check agent:

    notice apd[7187]: 01490005:5: b002e657: Following rule 'fallback' from item 'Hard Disk Encryption' to ending 'Deny'
    notice apd[7187]: 01490102:5: b002e657: Access policy result: Logon_Deny
    notice tmm[10736]: 01490501:5: b002e657: Session deleted due to user logout request.
