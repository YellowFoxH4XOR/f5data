K56415473: BIG-IP APM 13.1.1 Config load fails due to Citrix bundle missing

Type
Support Solution
Published
2019-09-03
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.1
Source
https://my.f5.com/manage/s/article/K56415473

Description

The configuration may fail to load with the following error message:

 

sb-citrix-client-package-file /Common/citrix-client-package:CitrixReceiver.exe-1451942567621 referenced by citrix-client-bundle /Common/Citrix.app/CiS_Citrix_client_bundle does not exist Unexpected Error: Loading configuration process failed.

Environment

  • BIG-IP APM 13.1.1
  • Configuration Reload

Cause

Unknown at the time of publication.

Recommended Actions

You can remove the referenced entry from the bigip.conf file
  1.  Log into the Command Line Utility (CLI)
  2. Make a copy of the bigip.conf file with the following command:
    cp /config/bigip.conf /config/bigip.conf.bak.1
  3. Open the bigip.conf with the vi editor
    vi /config/bigip.conf
  4. Comment out, or remove the offending entry. Here is an example entry:

    apm resource remote-desktop citrix-client-bundle /Common/cpg-secure.app/cpg-secure_apm_client_bundle {
        app-service /Common/cpg-secure.app/cpg-secure
        sb-windows-package /Common/citrix-client-package:CitrixReceiver.exe-1518759032628
    }
     
  5. Save the changes made in vi with:
    ESC :wq!
  6. Reload the configuration with the following command:
    tmsh load sys config
