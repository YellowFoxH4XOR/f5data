K000151315: Unable to see data interfaces on BIG-IP Virtual Edition on top of Linux KVM

Description

New deployment. You see only management interface which is up and running. There is no interface for data traffic like 1.1 or 1.2 etc. on the BIG-IP.

Environment

  • BIG-IP VE
  • KVM

Cause

There's a misconfiguration at host level. You did not create an additional virtual interfaces and assign that to the VM - BIG-IP VE.

Recommended Actions

You need create one more virtual interface and assign it to the VM - BIG-IP VE, so that you can have another interface like 1.1 for data traffic. 

Additional Information

If you only create one virtual interface and assign that to VM - BIG-IP VE, in the BIG-IP you will see 1.0 and mgmt and both will have same MAC. Basically you have only assigned 1 interface for management. You will need at least one or more interfaces for data traffic and once the interfaces are provisioned, you should see the interfaces as 1.1, 1.2, etc.
