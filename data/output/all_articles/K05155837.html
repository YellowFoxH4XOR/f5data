Description

After upgrade from 13.1.3.2 to 15.1.2 the license cannot be reactivate and the system logs the following messages:

01070608:0: License is not operational (expired or digital signature does not match contents). 01071dc3:0: This license does not allow software version 15.1.2 to run. This license is only valid for versions 5.*.*-15.0.*.

Environment

  • BIG-IP VE
  • BIG-IP VE Version Plus license

Cause

Version Plus licenses enable customers to use BIG-IP VE with perpetual usage. However, upgrades are limited to software versions within a pre-established range of software releases. In this case, the current license covers versions up to 15.0.* and 15.1.2 is higher than that.

Recommended Actions

Contact your F5 account manager or sales representative to acquire the recommended replacement for this license.

Additional Information

Note: this issue can affect when upgrading from versions other than 13.1.3.2.
