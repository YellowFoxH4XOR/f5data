Description

In versions 13.1.0 and later, once ASM entities are configured, they can no longer be modified.

Environment

  • Running version 13.1.0 or later
  • Unable to modify the URLs

Cause

This is due to a code improvement for a bug that caused ASM configsync related issues.

Now the ability to change the URL has been disallowed.
 

Recommended Actions

To modify URLs, recommendation is to export the ASM policy and modify the URLs in the file.
  1. Access the BIG-IP configuration utility
  2. Export the desired ASM policy using the steps provided in the article K13905104: Overview of importing and exporting BIG-IP ASM security policies
  3. Using any text editor open the XML file
  4. In the XML file, search for <url protocol=
  5. Edit the desired URL
  6. Save the XML file
  7. Import the XML file to the BIG-IP using the article provided in step 2.
