Description

When modifying a Virtual Server’s IP address with another IP address using the following command: tmsh modify gtm server <LTM-name> virtual-servers replace-all-with { <VIP_name> { destination x.x.x.x:x } }, be aware that running this command will delete all existing Virtual Servers without any warning if multiple Virtual Servers are present.

Environment

  • Replacing/modifying/changing an existing Virtual Server's IP address with another IP address
  • GTM/BIGIP DNS
  • LTM Server Object includes more than one Virtual Server 
  • CLI

Cause

This command is working as expected.

Recommended Actions

1. Create a backup prior to making any changes

2. Instead of running this command:
tmsh modify gtm server <LTM-name> virtual-servers replace-all-with { /<Partition>/<Virtual Server Name> { destination <address>:<port> } }  

Run command below: 
tmsh modify gtm server <LTM-name> virtual-servers modify { /<Partition>/<Virtual Server Name> { destination <address>:<port> } }
