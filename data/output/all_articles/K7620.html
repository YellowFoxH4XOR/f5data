Known Issue

This is the result of a known issue. In some instances FirePass may repeatedly log the following error message:

 
error  15398 Cannot open SSLSessionCache DBM file 
`/usr/local/uroam/var/run/apache5.ssl_scache' 
for reading (fetch) (System error follows)

error  15398 System: No such file or directory (errno: 2)

This error message is the result of multiple processes attempting to access the same cache file. This error message does not indicate a problem with FirePass and can be ignored.

F5 Product Development tracked this issue as CR31929 and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-552-2 has been issued for FirePass version 5.5.2 and cumulative hotfix HF-600-8 has been issued for FirePass version 6.0.0. You may download these hotfixes or later versions of the cumulative hotfix from the F5 Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
