K62015492: Requesting ticket can't get forwardable tickets (-1765328163)

Type
Support Solution
Published
2020-10-22
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.X.X, 15.0.X, 15.1.0, 15.0.1, 15.0.0, 15.1.8, 15.1.7, 15.1.6, 15.1.X, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.5
Source
https://my.f5.com/manage/s/article/K62015492

Description

APM SSO Kerberos constrained delegation authentication failure. With APM websso debug log enabled an entry similar to the one below is witnessed:

4144fe26:S4U ======> trying to fetch S4U2Proxy ticket for user: xxxxx@EXAMPLE.COM server: HTTP/webapp.example.com@EXAMPLE.COM
4144fe26:Kerberos: can't get S4U2Proxy ticket for server HTTP/WEBAPP.example.com@EXAMPLE.COM - Requesting ticket can't get forwardable tickets (-1765328163)

Environment
  • APM provisioned
  • Kerberos SSO constrained delegation
  • websso debug logging enabled

Cause

One of the settings in AD for a user account tab properties is a tick box to say that the account is sensitive and cannot be delegated. This prevents delegated authentication which occurs when a network service accepts a request from a user and assumes that user's identity in order to initiate a new connection to a second network service.

A BIGIP tcpdump capture obtained between the F5 and KDC over port 88 should display kerberos transactions including a TGS-REQ. The TGS-REQ frame properties contains a KDC-options section where forwardable is seen set as False which is problematic:

kdc-options: 00810000 (renewable, canonicalize)
                0... .... = reserved: False
                .0.. .... = forwardable: False <==============
                ..0. .... = forwarded: False

Recommended Actions

  • User accounts in Active Directory are not configured with the "Account is sensitive and cannot be delegated" flag set.
  • The domain KRBTGT account is not configured with the "Account is sensitive and cannot be delegated" flag set.

The TGS-REQ >> KDC-options section of a tcpdump capture should now display forwardable set as True as seen below once the recommended changes above have been implemented:

req-body
            Padding: 0
            kdc-options: 40830000 (forwardable, renewable, constrained-delegation, canonicalize)
                0... .... = reserved: False
                .1.. .... = forwardable: True <==============
                ..0. .... = forwarded: False
