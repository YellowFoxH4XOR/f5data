K31530046: Using create_vlans results in a ''TypeError'' failure

Description

Using the create_vlan module from the Ansible Galaxy collection fails with the error:

An exception occurred during task execution. To see the full traceback, use -vvv. The error was: TypeError: split() takes no keyword arguments

Environment

  • BIG-IP

  • Ansible

  • Python 2.x

Cause

The F5 create_vlan Ansible module relies on syntax unavailable on older versions of the python interpreter. The module in question is:

ansible_collections/f5networks/f5_modules/plugins/module_utils/teem.py

The line is:

python_version = sys.version.split(' ', maxsplit=1)[0]

Python2 cannot handle split with the maxsplit parameter name.

Recommended Actions

Instead utilize python3.x on the control node.


Additional Information

This kind of error can also present on an Ansible control node that has both python2 and python3 installed, if the ansible-playbook environment has the capability of utilizing python2 for any portion of its play.
