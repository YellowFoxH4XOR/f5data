Description

After upgrade to 13.X, LDAP over SSL/TLS monitors will require /etc/openldap/ldap.conf file to be modified as recommended in article K19560414

This will cause monitor disruptions if there are other TLS LDAP monitors running on versions lower than TLS 1.2

Environment
  •     F5 BIG-IP LTM LDAPS monitors
  •     OS version 13.X or above 
  •     Some LDAP over TLS monitors running on TLS 1.2 and other on lower TLS versions.

Cause

Modification of /etc/openldap/ldap.conf file as recommended in article K19560414 will enable LDAP over TLS monitors to work on TLS 1.2, but will disable all other lower TLS versions.

Recommended Actions

1. Modify openldap configuration file to include the ciphers required for all TLS versions for LDAPS monitors. 

With the text editor of your choice modify the /etc/openldap/ldap.conf file to add the cipher into line  TLS_CIPHER_SUITE in the file.
Note: TLS_Cipher_Suite configures what ciphers will be accepted and the preference order.


Examples of ciphers you can introduce: 
TLS_CIPHER_SUITE ECDHE-ECDSA-AES256-GCM-SHA384

TLS_CIPHER_SUITE ECDHE:TLSv1:TLSv1_1

Note: Only one line can be used at a time, select the proper one

First option will permit LDAP over TLS monitor to work specifically as described in article K19560414.
Second option will use all ECDHE ciphers (included first option's) plus all TLS1 + TLS1.1 ciphers.


 
2. Your config file should then look similar to the following:

#
# LDAP Defaults
#
# See ldap.conf(5) for details
# This file should be world readable but not world writable.
#BASE   dc=example,dc=com
#URI    ldap://ldap.example.com ldap://ldap-master.example.com:666
#SIZELIMIT      12
#TIMELIMIT      15
#DEREF          never
TLS_REQCERT     never
TLS_CACERTDIR   /etc/openldap/certs
TLS_CIPHER_SUITE <INSERT CIPHER SUITE HERE>

FOR EXAMPLE: 
#
# LDAP Defaults
#
# See ldap.conf(5) for details
# This file should be world readable but not world writable.
#BASE   dc=example,dc=com
#URI    ldap://ldap.example.com ldap://ldap-master.example.com:666
#SIZELIMIT      12
#TIMELIMIT      15
#DEREF          never
TLS_REQCERT     never
TLS_CACERTDIR   /etc/openldap/certs
TLS_CIPHER_SUITE ECDHE-ECDSA-AES256-GCM-SHA384

3. Save the config using below command:

# tmsh save sys config 


Another option you can also configure LDAP servers to not be dependent on ciphers which BIG-IP is presenting in SSL handshake

 
    Additional Information

    Cipher definition syntax must be closely observed, as configuration errors in /etc/openldap/ldap.conf file will cause the cipher suite not to work as expected.
