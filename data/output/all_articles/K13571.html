Known Issue

The BIG-IP mcpd process may leak memory over time.

This issue occurs when the following conditions are met:

  • You are using certificate revocation lists (CRL) in a client or server SSL profile.
  • The bigpipe load or tmsh load sys config commands are run.

Each time the bigpipe load or tmsh load sys config commands are run, the mcpd process leaks memory and steadily grows.

Impact

The lack of system memory causes system instability.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The mcpd process memory usage steadily grows over time.
  • Overall free system memory slowly declines.

Workaround

To work around this issue, you can restart the mcpd process to release the leaked memory. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system becomes temporarily inoperative, all BIG-IP processes restart, and all connections are lost. As a result, F5 recommends that you perform the following procedure during a maintenance window.

  1. Log in to the BIG-IP command line.
  2. To restart the mcpd process, type the following command:

    bigstart restart mcpd
