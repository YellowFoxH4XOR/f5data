Known Issue

The BIG-IP system may log an excessive number of error messages to the restjavad log file.

This issue occurs when the following condition is met:

  • You use the iControl REST API to obtain data from the BIG-IP system under heavy load.

Impact

Over time, the restjavad log file fills with an excessive number of error messages. As a result, the system may quickly rotate out other log messages.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/restjavad.log file, you observe an excessive number of error messages that appear similar to the following example:

    [ChildWrapper] Exception found in child runner thread: null

  • The system quickly rotates out other message logged to /var/log/restjavad.log and consequently you do not see them.
