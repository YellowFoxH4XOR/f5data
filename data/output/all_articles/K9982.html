K9982: Additional application templates have been added to the Templates section of the Configuration utility

Issue

Application templates are a configuration tool that provide an efficient way to configure the BIG-IP system to process traffic for certain applications. Starting in BIG-IP version 10.0.0 HF2, the following application templates are added to the release:

  • HTTP
  • IP Forwarding
  • Radius
  • LDAP

F5 Product Development is tracking this issue as CR115226.

This feature was added in BIGIP-10.0.0-5514.0-HF2 for BIG-IP 10.0.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
