Note: For information about UCS archives, refer to K4423: Overview of UCS archives.

You can verify the integrity of a backup UCS file by using the following command syntax from the command line:

gzip -t -v /<directory>/<name of file>

In the following example, the backup UCS file is /var/local/ucs/myconfig.ucs:

gzip -t -v /var/local/ucs/myconfig.ucs

The -t flag verifies the compressed file integrity. The -v flag provides verbose output, and will display the following message if the file integrity is verified as OK.

/var/local/ucs/myconfig.ucs: OK

Note: This command cannot verify whether individual files held in the UCS archive contain a BIG-IP loadable configuration—it can only verify that the UCS archive was created and compressed without corruption.
