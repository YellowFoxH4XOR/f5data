K000150956: Alternative Methods to Export F5 BIG-IP ASM Traffic Learning Data to Excel or CSV

Source

Description

When exporting Traffic Learning data from F5 BIG-IP ASM (Application Security Manager), the only available export format is HTML.

There is no built-in option to export this data directly as Excel (.xlsx) or CSV (.csv) files, which may complicate analysis and reporting when handling large datasets.

Environment

  • F5 BIG-IP ASM (Application Security Manager)
  • Feature/Module: Traffic Learning export

Cause

The BIG-IP ASM GUI supports exporting Traffic Learning data exclusively in HTML format. Direct export to spreadsheet-compatible formats such as CSV or Excel is not currently implemented.

 

Recommended Actions

1. Manual Conversion:

1.1) Export the Traffic Learning data as an HTML file from the BIG-IP ASM GUI.

1.2) Use online conversion tools or custom scripts to convert the exported HTML into CSV or Excel format for further processing and analysis.

2. iControl REST API Usage.

2.1) Retrieve Traffic Learning data programmatically using the iControl REST API provided by F5.

2.2) Process and convert the API output into CSV or Excel files using custom scripts or automation tools.
