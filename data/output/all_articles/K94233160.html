Important: The following article is intended to provide some answers and guidance to general questions and emerging issues you may experience surrounding CVE-2020-5902. For the official information such as vulnerable versions, fixed versions, and mitigation information, refer to K52145254: TMUI RCE vulnerability CVE-2020-5902.

Description

Answers and references for some of the general questions being asked about CVE-2020-5902:

 

  • Q: Where can I find technical information about CVE-2020-5902?
    • A: K52145254: TMUI RCE vulnerability CVE-2020-5902
  • Q: Is there a video guide on this?
    • A: Yes. Check out our F5 DevCentral Lightboard Lesson Explaining CVE 2020-5902 and how to mitigate.
  • Q: Am I compromised or vulnerable to CVE-2020-5902?
    • A: For information about which products and versions are vulnerable, refer to K52145254: TMUI RCE vulnerability CVE-2020-5902.
    • A: For information about versions not listed in K52145254, refer to K00207029: Currently running a version not listed in K52145254: TMUI RCE, Are you vulnerable?

      Note: Per K11438344: Considerations and guidance when you suspect a security compromise on a BIG-IP system F5 does not provide forensic services, but will "will endeavor to assist customers based on what we find in the logs or provide mitigation or recovery information". Please review the article for information and guidance when you suspect a possible compromise on a BIG-IP.

  • Q: What should I do if I think my system may have been compromised?
    • A: K11438344: Considerations and guidance when you suspect a security compromise on a BIG-IP system.
  • Q: The security advisory article (K52145254) indicates the issue is fixed in some versions. However, the Release Notes for that version do not list the issue as fixed. Why?
    • A: The initial release of the Release Notes for fixed versions did not include information on the vulnerability as it had not yet been disclosed. However, current versions of the Release Notes have been updated to reflect the fix for CVE-2020-5902.
      • Release Note BIG-IP 15.1.0.4
      • Release Note BIG-IP 14.1.2.6
      • Release Note BIG-IP 13.1.3.4
      • Release Note BIG-IP 12.1.5.2
      • Release Note BIG-IP 11.6.5.2
  • Q: How do I install a fixed version?
    • A: For information about installing a fixed version, refer to 
      • K84554955: Overview of BIG-IP systems software upgrades and K13845: Overview of supported BIG-IP upgrade paths and an upgrade planning reference.
      • Patching BIG-IP HA systems with a point release to resolve the CVE-2020-5902 vulnerability
      • How to Upgrade Managed Devices to New Versions of TMOS with BIG-IQ

         

       

  • Q: How do I mitigate CVE-2020-5902?
    • A: For information about mitigation options, refer to K52145254: TMUI RCE vulnerability CVE-2020-5902.
  • Q: In a vCMP deployment, do I upgrade the host or the guest?
    • A: For vCMP deployments you must upgrade both the GuestOS and the HostOS. For information about upgrading a vCMP system refer to the following:
      • Upgrade considerations section of K15930: Overview of vCMP configuration considerations
      • Upgrading software on a vCMP system section of K84554955: Overview of BIG-IP system software upgrades
      • K13748: Maintaining host resources when upgrading vCMP guests
  • Q: Why did the mitigation for CVE-2020-5902 change?
    • A: F5 provide initial configuration-based mitigations which were intended to block all unauthenticated exploits. Upon further investigation, it has been determined that all previously provided mitigations were not completely effective and K52145254: TMUI RCE vulnerability CVE-2020-5902 was updated with new mitigations. F5 continues to investigate and you should continue to monitor K52145254: TMUI RCE vulnerability CVE-2020-5902 for updated information.
  • Q: How do I get notified about security alerts from F5?
    • A: K9970: Subscribing to email notifications regarding F5 products
  • Q: Checked K4309: F5 platform lifecycle support policy. My platform is past its End of Software Development (EoSD) date, what can I do? 
    • A: When a platform passes the EoSD date and enters the Extended Support phase, F5 is no longer liable to provide security updates, or software fixes (hotfixes) for that specified product. Refer to the Mitigations section in K52145254: TMUI RCE vulnerability CVE-2020-5902.
  • Q: BIG-IP AFM allows the configuration of packet filters, can I use this function for CVE-2020-5902?
    • A: This function does NOT apply to the configuration utility. Please upgrade or apply workaround in K52145254: TMUI RCE vulnerability CVE-2020-5902.
