K26143646: OAuth tokens report is empty

Type
Support Solution
Published
2020-04-17
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.X.X, 15.1.X, 15.1.1, 15.1.2, 15.1.3, 15.1.4, 15.1.5, 15.1.6, 15.1.7, 15.1.8, 15.0.0, 15.0.1, 15.1.0, 15.0.X
Source
https://my.f5.com/manage/s/article/K26143646

Description

APM OAS supports two types of access tokens; Opaque and JWT.
Only non-JWT (Opaque) OAuth tokens are stored in the persistent MySQL database because JWT tokens includes all the information to validate a token inside itself.
This is the reason APM OC validates JWT tokens internally.

Environment

  • APM
  • OAuth Tokens Reports
  • OAuth 2.0 Client
  • JWT Tokens
Cause

By design when JWT tokens are enabled the Tokens reports won't display any tokens on the GUI reports:

OAuth Reports >> Tokens

Recommended Actions

None 

Additional Information

Configuration example from bigip.conf file:
apm profile oauth /Common/oauthsrvt.migdal.co.il_az {
    jwt-token enabled
    openid-connect enabled
}
