Known Issue

This is the result of a known issue. When the same client concurrently opens multiple files on a remote share, the WOC plug-in CPU utilization spikes to 95 percent or higher, and the WOC plug-in dumps core and restarts. When this occurs, a large set of error messages is logged to the /var/log/wocplugin file, including the following message:

wocplugin-1[5339:f76236d0] WJPlugin.cpp:1786 : wocplugin coredumped

Note: This issue has been observed when the same client has as few as six files open concurrently.

F5 Product Development is tracking this issue as ID 340620.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1789.0-HF2, which has been issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
