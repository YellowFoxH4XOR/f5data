Description

How can I use the F5 Ansible modules to create a Rewrite profile as seen under  Virtual Servers > Profiles > Services > Rewrite profile in the Web GUI

Environment

  • BIG-IP
  • Ansible
  • AS3

Cause

None

Recommended Actions

Use AS3 (preferred method) 

or

Use the f5networks.f5_modules.bigip_command Ansible module to issue tmsh commands to first create the profile, then use the f5networks.f5_modules.bigip_virtual_server to assign the profile to your virtual server.

See the link to Ansible modules under related content.
