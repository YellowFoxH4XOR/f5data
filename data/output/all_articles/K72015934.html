Topic

You should consider using these procedures under the following condition:

  • You want to display the NGINX software version information.

Description

You can use the command line or the NGINX user interface to display the NGINX software version.

Note: For information about displaying the version information for other F5 products, refer to K914: Displaying the software version of your F5 product.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have a valid user account to access the NGINX system.

Procedures

  • Display the NGINX Plus software version using the command line
  • Display the NGINX Agent software version using the command line
  • Display the F5 WAF for NGINX software version using the command line
  • Display the NGINX App Protect WAF version using the command line
  • Display the F5 DoS for NGINX software version using the command line
  • Display the NGINX App Protect DoS version using the command line
  • Display the NGINX Instance Manager software version using the command line
  • Display the NGINX Instance Manager software version using the user interface

Display the NGINX Plus software version using the command line

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the NGINX Plus system.
  2. To display the NGINX Plus software version, enter the following command:

    nginx -v

Display the NGINX Agent software version using the command line

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the NGINX Plus or NGINX OSS system.
  2. To display the NGINX Agent software version, enter the following command:

    nginx-agent -v

Display the F5 WAF for NGINX software version using the command line

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the F5 WAF for NGINX system.
  2. To display the F5 WAF for NGINX release number, enter the following command:

    cat /opt/app_protect/RELEASE

Display the NGINX App Protect WAF version using the command line

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the NGINX App Protect system.
  2. To display the NGINX App Protect WAF release number, enter the following command:

    cat /opt/app_protect/RELEASE

Display the F5 DoS for NGINX software version using the command line

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the F5 DoS for NGINX system.
  2. To display the F5 DoS for NGINX plugin version, enter the following command:

    admd -v

Display the NGINX App Protect DoS version using the command line

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the NGINX App Protect DoS system.
  2. To display the NGINX App Protect DoS plugin version, enter the following command:

    admd -v

Display the NGINX Instance Manager software version using the command line

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the NGINX Instance Manager system.
  2. To display the NGINX Instance Manager software version, enter the following commands:

    nms-core -v
    nms-dpm -v
    nms-ingestion -v

Display the NGINX Instance Manager software version using the user interface

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the user interface of the NGINX Instance Manager system.
  2. To locate the NGINX Instance Manager software version,

    Select the question mark icon (Help) located at the top right corner followed by About. The user interface displays a popup indicating the NGINX Instance Manager version.
