Topic

Starting in BIG-IP APM version 10.2.0 with Hotfix-BIGIP-10.2.0-1789.0-HF2 installed, BIG-IP APM is able to support back-end WebGate deployments. WebGate is a web server plugin that is part of Oracle Access Manager (OAM). WebGate intercepts HTTP requests, and authenticates and authorizes the user against an access server.

Prior to installing Hotfix-BIGIP-10.2.0-1789.0-HF2, you must disable or remove WebGate. After installing the hotfix, BIG-IP APM is able to generate an ObSSOCookie cookie, which is recognized by WebGate to grant users access to the web resource. However, F5 recommends that you disable WebGate whenever possible to improve performance.

Note: For more information about WebGate, refer to the Oracle Access Manager Installation Guide for your version. The following link will take you to a resource outside of AskF5, and it is possible that the document may be moved without our knowledge:

http://download.oracle.com/docs/cd/B28196_01/index.htm

F5 Product Development tracked this request for enhancement (RFE) as ID 224807, and it was added in BIG-IP APM version 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

Additionally, it was added in BIG-IP APM version 10.2.0 with Hotfix-BIGIP-10.2.0-1789.0-HF2 installed. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
