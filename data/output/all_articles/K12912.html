Known Issue

The BIG-IP Configuration utility does not allow Secure Socket Layer (SSL) certificate and key deletion on the VIPRION system. This issue occurs because the underlying engine is unable to delete the SSL certificate and key from all blades in the VIPRION system.

Impact

You are unable to delete SSL certificates and keys from the Configuration utility on the VIPRION system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Delete button does not appear on the Local Traffic > SSL certificate > Certificate List page in the Configuration utility.

Workaround

To work around this issue, you can use the clsh rm command to delete the SSL certificate and key from the command line. The clsh rm command removes files or directories from all blades. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line
  2. Verify that the SSL certificate you want to delete is not referenced in the BIG-IP configuration. To do so, use the following syntax for your version where <cert filename> refers to the file name of the SSL certificate you want to remove:
    • BIG-IP 10.x

      tmsh list ltm profile client-ssl | grep -i <cert filename>

      tmsh list ltm profile server-ssl | grep -i <cert filename>

    • BIG-IP 9.6.1

      bigpipe profile clientssl list | grep -i <cert filename>

      bigpipe profile serverssl list | grep -i <cert filename>

    If any of the commands return an entry for the SSL certificate, you must locate the SSL profile that references this SSL certificate and remove the SSL certificate from the SSL profile. For more information, refer to the Understanding Profiles chapter of the Configuration Guide for BIG-IP Local Traffic Management.

    For example, if you type the tmsh list ltm profile client-ssl | grep -i mysslcert.crt command, and the output appears similar to the following example:

    cert mysslcert.crt

    You should locate the SSL profile that is configured to reference mysslcert.crt and remove the mysslcert.crt reference from the SSL profile.

  3. Remove the SSL certificate by using the following command syntax, where <cert filename> refers to the file name of the SSL certificate you want to remove:

    clsh rm /config/ssl/ssl.crt/<cert filename>

  4. Remove the matching SSL key by using the following command syntax, where <key filename> refers to the file name of the matching SSL key you want to remove:

    clsh rm /config/ssl/ssl.key/<key filename>
