Known Issue

This is the result of a known issue. The ServerSSL profile does not reply with an empty certificate when it receives a request for a certificate. The ServerSSL profile should reply to the request with an empty certificate and continue with the connection. However, when a request is received for a client certificate, the ServerSSL profile does not complete the request and terminates the connection.

F5 Product Development tracked this issue as CR79708, and it was fixed in BIG-IP LTM 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.0-HF1 issued for BIG-IP LTM 9.3.0, and in Hotfix-BIG-IP-9.4.1-HF1 issued for BIG-IP LTM 9.4.1. You may download these hotfixes or later versions of these hotfixes from the F5 Downloads site.
