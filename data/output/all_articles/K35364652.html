Description

GTM resource records have a default TTL set to '0'. 

  • A records in Zone Runner of the BIG-IP DNS show a TTL of 0
  • Requesting local domain name system (LDNS) must resend every request

Environment

When a wide-ip is created and linked to a DNS pool with virtual servers, Zone Runner will take this information to auto-create DNS records in the local BIND instance.

  • Wide-ip creation with pool causes auto-creation of DNS records
  • DNS records are auto-created with a TTL of 0
  • BIG-IP DNS

Cause

This is the default and correct behavior as the local BIND instance is intended as a fallback.  The TTL of 0 is intended so as to not overwrite or cause any issues for when the wide-ip becomes available again.

Recommended Actions

If the 0 TTL is not desired, it can be manually modified in Zone Runner records.  Also, when creating the wide-ip, the Zone Runner records can be created first with the desired TTL.
