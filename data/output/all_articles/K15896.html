K15896: iRules that include the HTTP::is_redirect command may fail with an error

Topic

Virtual servers with iRules that use the HTTP::is_redirect command may fail.

Note: The HTTP::is_redirect command is synonymous with the HTTP::header is_redirect command.

This issue occurs when all of the following conditions are met:

  • Your virtual server uses an iRule with the HTTP::header is_redirect or HTTP::is_redirect commands.
  • Incoming traffic to the affected virtual server triggers the iRule.

Description

Impact

The affected iRule displays an error, and the affected virtual server may not function as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • F5 iHealth lists Heuristic H494700 on the Diagnostics > Identified > Medium screen.
  • When the HTTP::is_redirect command fails to work correctly, the tmm process generates a TCL error message similar to the following example:

    err tmm3[1251]: 01220001:3: TCL error: /Common/MyTest <HTTP_RESPONSE> - Operation not supported (line 2) invoked from within "HTTP::is_redirect"

  • When the HTTP::header is_redirect command fails to work correctly, the tmm process generates a TCL error message similar to the following example:

    err tmm1[15021]: 01220001:3: TCL error: /Common/MyRedir <HTTP_RESPONSE> - Operation not supported (line 5) invoked from within "HTTP::header is_redirect"

Workaround

To work around this issue, you can use the HTTP::status command to validate the status code, with reference to the HTTP redirect status code that is required in the affected iRule.

For more information about the HTTP response status code, refer to HTTP::status on F5 Cloud Docs.
