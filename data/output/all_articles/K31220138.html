Known Issue

When a large number of IPsec tunnels are in use, new Internet Protocol Security (IPsec) tunnels fail to establish and the Traffic Management Microkernel (TMM) may restart.

This issue occurs when all of the following conditions are met:

  • You configure your BIG-IP system as an IPsec tunnel endpoint.
  • You configure IPsec tunnels to use the Internet Key Exchange version 2 (IKEv2) protocol.
  • A large number of currently active IPsec tunnels are in use.

Impact

The BIG-IP system temporarily fails to pass traffic while TMM restarts. If you configured your system for high availabilitiy (HA), the system may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • IPsec tunnels using the IKEv2 protocol fail to establish or function properly.
  • The /shared/core/ directory includes a tmm core file.
