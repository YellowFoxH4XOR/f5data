Known Issue

The Configuration utility may display incorrect Packet Velocity ASIC (PVA) assisted connection counts.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a virtual server that uses the FastL4 profile.
  • The virtual server has PVA enabled.
  • The system hardware includes an embedded Packet Velocity Acceleration (ePVA) chip.

Impact

Virtual server PVA assisted connection counts do not increment.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H501812 on the Diagnostics > Identified > Medium screen.
  • When using the Configuration utility to view statistics for the virtual server, the PvaAssist value is always 0.
  • When using the Traffic Management Shell (tmsh) to view statistics for the virtual server, the PvaAssist value reflects the actual value of assisted connections.

Workaround

To work around this issue, you can use a tmsh command to display the virtual server statistics. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To display statistics for the affected virtual server, use the following command syntax:

    show ltm virtual <virtual server name>

  3. To exit the tmsh utility, type the following command:

    quit
