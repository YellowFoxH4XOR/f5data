K13060953: Changing ASM Policy Building Setting for 'Check for maximum number of headers' using REST API

Type
Support Solution
Published
2021-03-12
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP ASM: 13.1.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.X.X, 13.1.0, 13.0.1, 13.0.0, 13.1.1
Source
https://my.f5.com/manage/s/article/K13060953

Description

This article provides the steps to change an ASM Policy Building Setting for 'Check for maximum number of headers' using iControl REST API.
 

Environment

  • BIG-IP ASM
  • REST API

Cause

None.

Recommended Actions

1. Get the hashed ID of the ASM policy to be used for subsequent requests. In this example, we are working on ASM Policy named Sample_ASM_Policy. The policy hash ID is XGp3iHjJslXdlVlsoAESeQ.

[root@bigip1:Active:Standalone] tmp # curl -sku "admin" "https://localhost/mgmt/tm/asm/policies?\$select=name,id" | jq .
<snip>
{
  "kind": "tm:asm:policies:policycollectionstate",
  "selfLink": "https://localhost/mgmt/tm/asm/policies?$select=name%2Cid&ver=13.1.3",
  "totalItems": 1,
  "items": [
    {
      "kind": "tm:asm:policies:policystate",
      "selfLink": "https://localhost/mgmt/tm/asm/policies/XGp3iHjJslXdlVlsoAESeQ?ver=13.1.3",
      "name": "Sample_ASM_Policy",
      "id": "XGp3iHjJslXdlVlsoAESeQ"
    }
  ]
}
</snip>



2. Send a GET request to fetch the current settings and be able to get the ID for 'Check maximum number of headers'.

   Output should be similar to the following. The parameter hash ID is 995ZTh0R4GRQ8hEGdmX_Fw.

[root@bigip1:Active:Standalone] tmp # curl -sku "admin" "https://localhost/mgmt/tm/asm/policies/XGp3iHjJslXdlVlsoAESeQ/blocking-settings/http-protocols" | jq .
<snip>
   {
      "httpProtocolReference": {
        "link": "https://localhost/mgmt/tm/asm/sub-violations/http-protocols/995ZTh0R4GRQ8hEGdmX_Fw?ver\u003d13.1.3"
      },
      "maxHeaders": 25,
      "lastUpdateMicros": 1.612493771e+15,
      "description": "Check maximum number of headers",
      "selfLink": "https://localhost/mgmt/tm/asm/policies/XGp3iHjJslXdlVlsoAESeQ/blocking-settings/http-protocols/995ZTh0R4GRQ8hEGdmX_Fw?ver\u003d13.1.3",
      "kind": "tm:asm:policies:blocking-settings:http-protocols:http-protocolstate",
      "id": "995ZTh0R4GRQ8hEGdmX_Fw",
      "learn": true,
      "enabled": false
    },
</snip>



3. Create the JSON payload file to set maxHeaders, say for example to 27. Or you can also manually define the payload on run-time using --data-raw '{"maxHeaders":27}'.

[root@bigip1:Active:Standalone] tmp # cat payload.json
{ "maxHeaders": 27 }


4. Send an HTTP PATCH request together with the payload towards REST endpoint '/mgmt/tm/asm/policies/<policy_hash_id>/blocking-settings/http-protocols/<parameter_hash_id>'.
 
  The response should show the modified value for maxHeaders.

[root@bigip1:Active:Standalone] tmp # curl -sku "admin" "https://localhost/mgmt/tm/asm/policies/XGp3iHjJslXdlVlsoAESeQ/blocking-settings/http-protocols/995ZTh0R4GRQ8hEGdmX_Fw" -X PATCH -H "Content-Type: application/json" -d @payload.json | jq .
{
  "httpProtocolReference": {
    "link": "https://localhost/mgmt/tm/asm/sub-violations/http-protocols/995ZTh0R4GRQ8hEGdmX_Fw?ver=13.1.3"
  },
  "maxHeaders": 27,
  "lastUpdateMicros": 1612495533000000,
  "description": "Check maximum number of headers",
  "selfLink": "https://localhost/mgmt/tm/asm/policies/XGp3iHjJslXdlVlsoAESeQ/blocking-settings/http-protocols/995ZTh0R4GRQ8hEGdmX_Fw?ver=13.1.3",
  "kind": "tm:asm:policies:blocking-settings:http-protocols:http-protocolstate",
  "id": "995ZTh0R4GRQ8hEGdmX_Fw",
  "learn": true,
  "enabled": false
}


5. Apply the changes to the policy by sending a POST request to REST endpoint /mgmt/tm/asm/tasks/apply-policy with JSON data pointing to the selfLink in Step 1. See format of the payload below:

[root@bigip1:Active:Standalone] tmp # curl -ksu "admin" -H "Content-Type: application/json" -X POST "https://localhost/mgmt/tm/asm/tasks/apply-policy" -d '{"policyReference": {"link":"https://localhost/mgmt/tm/asm/policies/XGp3iHjJslXdlVlsoAESeQ"}}' | jq .
{
  "kind": "tm:asm:tasks:apply-policy:apply-policy-taskstate",
  "selfLink": "https://localhost/mgmt/tm/asm/tasks/apply-policy/GhMRowMBrwJ1HYce24BWYQ?ver=13.1.3",
  "policyReference": {
    "link": "https://localhost/mgmt/tm/asm/policies/XGp3iHjJslXdlVlsoAESeQ?ver=13.1.3"
  },
  "status": "NEW",
  "id": "GhMRowMBrwJ1HYce24BWYQ",
  "startTime": "2021-02-05T03:28:53Z",
  "lastUpdateMicros": 1612495733000000
}


6. Verify by directly accessing the 'http-protocols' endpoint together with the parameter ID.

[root@bigip1:Active:Standalone] tmp # curl -sku "admin" "https://localhost/mgmt/tm/asm/policies/XGp3iHjJslXdlVlsoAESeQ/blocking-settings/http-protocols/995ZTh0R4GRQ8hEGdmX_Fw" | jq .
{
  "httpProtocolReference": {
    "link": "https://localhost/mgmt/tm/asm/sub-violations/http-protocols/995ZTh0R4GRQ8hEGdmX_Fw?ver=13.1.3"
  },
  "maxHeaders": 27,
  "lastUpdateMicros": 1612495533000000,
  "description": "Check maximum number of headers",
  "selfLink": "https://localhost/mgmt/tm/asm/policies/XGp3iHjJslXdlVlsoAESeQ/blocking-settings/http-protocols/995ZTh0R4GRQ8hEGdmX_Fw?ver=13.1.3",
  "kind": "tm:asm:policies:blocking-settings:http-protocols:http-protocolstate",
  "id": "995ZTh0R4GRQ8hEGdmX_Fw",
