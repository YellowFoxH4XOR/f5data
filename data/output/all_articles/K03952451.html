Known Issue

The BIG-IP system may erroneously allow the Round Robin DAG (RRDAG) feature to be configured on unsupported platforms.

This issue occurs when all of the following conditions are met:

  • You configure the RRDAG feature on the BIG-IP system.
  • The BIG-IP system does not belong to one of the following platforms:
    • BIG-IP appliances
      5000/5200 series (C109), 7000/7200 series (D110), and 10000/10200 series (D113)
    • VIPRION blades
      B2100 (A109), B2150 (A113), B2250 (A112), and B4300 (A108)
Enabling the RRDAG feature on a supported platform allows the BIG-IP system to evenly distribute stateless User Datagram Protocol (UDP) traffic across all Traffic Management Microkernel (TMM) instances between blades or High-Speed Bridges (HSBs).

Impact

Although the RRDAG feature is configured, the feature does not work on the unsupported platform.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You configure the RRDAG feature on the BIG-IP system; however, the feature does not work as expected. On an unsupported platform, the configuration may appear similar to the following example:

    net vlan vlan123 {
    dag-round-robin enabled
    if-index 352
    interfaces {
    1.1 {
    tag-mode service
    tagged
    }
    }
    tag 123
    }
