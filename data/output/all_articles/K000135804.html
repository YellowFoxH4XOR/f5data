K000135804: Cannot start more than one tenant at the same time on r5800 system

Type
Support Solution
Published
2023-08-10
Updated
2023-08-10
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000135804

Description

Unable to start more than one tenant at the same time on an r5800 system.

First tenant (running) has 8 vCPU cores.

Second tenant has 14 vCPU cores, but will not start.

The show tenants output reveals:

0/1 nodes are available: 1 Insufficient cpu

Environment

  • r5800
  • Tenants

Cause

Running (deployed) tenants can use a maximum of 18 vCPUs on an r5800 system.

Recommended Actions

Either assign fewer vCPUs to tenants, or upgrade to the r5900 license, which should allow tenants to use up to 26 vCPUs at once.

Additional Information

Refer to the platform data sheets for more information on tenant vCPU limits.
