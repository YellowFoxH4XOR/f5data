Known Issue

This is the result of a known issue. If you enable the WebAccelerator module on a 3600 platform, BIG-IP does not provision enough memory for the module, even if the Dedicated option is selected in the Resource Provisioning menu. As a result, WebAccelerator performance may become degraded.

F5 Product Development tracked this issue as ID 242936 (formerly CR135271), and it was fixed in BIG-IP version 10.2.0 through the use of custom provisioning tables. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

In addition, BIG-IP iHealth may list Heuristic H752694-1 on the Diagnostics > Identified > High screen.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.1.0-3372.0-HF1 through the use of custom provisioning tables, which has been issued for BIG-IP version 10.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

Important: In order to utilize the custom provisioning tables introduced in Hotfix-BIGIP-10.1.0-3372.0-HF1 and BIG-IP version 10.2.0, the provisioning levels specified in K11982: Recommended provisioning for BIG-IP WebAccelerator version 10.x, must be applied. Failure to utilize the recommended provisioning levels will not allow the custom tables to be referenced and the BIG-IP WebAccelerator may continue to suffer from insufficient memory resources.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
