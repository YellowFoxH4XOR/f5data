Topic

To stop BIG-IP from load balancing traffic, it needs to be put in maintenance mode. When in maintenance mode, BIG-IP stops accepting new connections to the virtual servers (VIPs), but allows existing connections to finish.

Putting BIG-IP in maintenance mode

To put the BIG-IP in maintenance mode, perform the following steps:

  1. From the command line, type the following command:

    bigpipe maint

    The following prompt appears:

    Do you want to put BIG-IP into maintenance mode? [Y]

  2. Press Enter.

BIG-IP is now in maintenance mode.

Bringing BIG-IP out of maintenance mode

To bring BIG-IP out of maintenance mode, perform the following steps:

  1. From the command line, type the following command:

    bigpipe maint

    The following prompt appears:

    **BIG-IP is currently in Maintenance State**

Do you want to take BIG-IP out of maintenance mode? [Y]

  2. Press Enter.

BIG-IP is now out of maintenance mode.
