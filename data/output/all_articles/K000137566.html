Description

A Link-Local IPv6 address is an IP address that is intended only for communications within the network segment or the broadcast domain that the host is connected to. 

The primary function of a Link-Local IPv6 address is to allow communication in the local network.  
These addresses are used by network protocols when communicating with neighboring nodes on the same network link. 
They are used for tasks such as automatic address configuration, neighbor discovery protocol, or by routing protocols such as OSPF or BGP.

The BIG-IP system automatically generates an IPv6 link-local address in the fe80::0/64 network for each VLAN configured on the system (based on the MAC address of the VLAN).
Command ip -f inet6 addr show will list all IPv6 addresses configured, including IPv6 link-local addresses.
 

Symptoms

Unable to see interfaces of VLAN and its Link-Local IPv6 addresses.
 

Environment

  • LTM
  • Route Domain
 

Recommended Action

It is expected.
In BIG-IP, the default route domain is 0. If VLAN is added in route domain 0, "ip -f inet6 addr show" or "ifconfig" will list the vlan you want, and available in default route domain.

However, if relevant vlan is configured with other route domains, link-local IPv6 addresses will be not displayed by default because of different route domain.

For checking IPv6 link-local addresses in non-default route domains, perform command as below before "ip -f inet6 addr show" or "ifconfig", based on K37059707: Displaying current Route Domain that you are working in.
# rdsh <route domain id>

In this command, note the following:
<route domain id> is the route domain to which you want to change shell

For example, you may change shell to route domain 1 by entering the following command:
# rdsh 1
