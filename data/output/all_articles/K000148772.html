Description

Sometimes some of webtop menu does not display. Once the browsing cache is deleted, it show up, and stays stable for a while.

 

Environment

  • BIG-IP APM
  • Webtop
  • Browser

 

Cause

  • Broken browser cache

 

Recommended Actions

Hard refresh or delete the browser cache. (Depending on the browser and OS, the way to conduct hard refresh is different. Please ask your browser provider how to hard refresh with your OS.)

 

If the hard refresh does not work, then please gather below data.

1. tcpdump on the Active unit CLI after changing db value to get proper information.

tmsh modify sys db tm.rstcause.pkt value enable 
tmsh modify sys db tm.rstcause.log value enable 
tmsh modify sys db tcpdump.sslprovider value enable 
tmsh modify sys db log.ssl.level value Debug 

 

then start tcpdump

tcpdump -s0 -ni 0.0:nnnp -w /var/tmp/"$HOSTNAME"_"$(date +%H-%M-%S-%d-%m-%y)".pcap --f5 ssl -vv host <client_public_IP>

NOTE: Replace <client_public_IP> with the public IP address of the client machine that is observed by BIG-IP during session establishment.

 

2. start developer tool on the browser and type URI and login, and save video for the desktop.

3. Find session ID for this client.

To find the Session ID:

Navigate on GUI to: Access >> Overview >> Access Reports. (you can find it by client IP)

4. And then keep the browser open, initiate "hard reload".

5. Terminate tcpdump by pressing [Ctrl]+[c] and save the developer tool's data.

 

If the super reload works means browser cache is broken ---> No F5 issue, recommend to clear the browser cache.
If the super reload does not work, then continue to next step

 

6. then take qkview

qkview -s0 -f /var/tmp/"$HOSTNAME"_"$(date +%H-%M-%S-%d-%m-%y)".qkview

7. just in case tarball for /var/log

tar -czpf /var/tmp/"$HOSTNAME"_logfiles.tar.gz /var/log/*

 

8. revert back the db value

tmsh modify sys db tm.rstcause.pkt value disable
tmsh modify sys db tm.rstcause.log value disable
tmsh modify sys db tcpdump.sslprovider value disable
tmsh modify sys db log.ssl.level value Warning

 

Then send us the following data when you open the case with F5 Support

  • tcpdump file
  • session ID 
  • developer tool file (har file) 
  • video
  • qkview
  • tar ball of /var/log
