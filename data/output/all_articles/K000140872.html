K000140872: Fortimail upgrade - Email Agent: Message send message send failed.

Type
Support Solution
Published
2024-08-28
Updated
2024-08-28
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000140872

Description

You have upgraded Fortimail to version v7.6.0(GA-Feature), build726, 2024.07.31

With BIG-IP APM configured to send OTP code through email, users are not receiving those OTP codes after Fortimail upgrade.

The following error message can be seen in APM logs:

Email Agent: Message send message send failed.

In tcpdump captured on BIG-IP you can see messages:

SMTP: 421 4.5.0 Bare linefeed (LF) not allowed in slot1

 

Environment

  • BIG-IP APM
  • Access Policy is using an "email" agent, that sends email as per the System >> SMTPD configuration
  • Fortimail v7.6.0

Cause

Fortimail is rejecting the emails from BIG-IP APM because those later are written using "LineFeed [LF]" characters, when they should use both "LineFeed [LF]" and "Carriage Return [CR]" characters, as stressed by RFC5322.

Recommended Actions

Change the configuration of the "Email" agent in the VPE. Please put one and only one line in the agent (you can use session variable, too).

Remove all breaks from the email, including the use of the <br> tag.
