K41570483: Error message - 01070911:3: The requested host (fqdn) is invalid for servers in ntp (/Common/ntp)

Type
Support Solution
Published
2022-08-23
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K41570483

Description

When you try to configure NTP server using FQDN, you will see the similar error message in GUI or /var/log/ltm log:

01070911:3: The requested host (big_ip.f5.com) is invalid for servers in ntp (/Common/ntp)

Environment

  • BIG-IP / BIG-IQ
  • NTP
  • FQDN
     

Cause

Bug ID 758348


Recommended Actions

Use IP address or Change NTP server name without underscore '_'.
 

Additional Information

  • External resource: Wiki Hostname
  • K38121141: Multiple NTP server or domain searches in the DHCP lease can cause missing DNS and NTP configurations
  • K85404955: Underscore (_) in hostname will cause "400 Bad request" when you access GUI with FQDN.
