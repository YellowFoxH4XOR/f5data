K38157961: BIG-IP ASM Bot Defense may fail to block malicious requests when both the Bot Defense profile and DoS profile are associated with a virtual server

Security Advisory Description

The BIG-IP ASM Bot Defense profile may unexpectedly fail to block malicious requests. This issue occurs when the following condition is met:

  • The affected virtual server is associated with the following:
    • A security policy
    • A DoS profile configured with either TPS-based or behavioral detection
    • A Bot Defense profile

Impact

The protected backend server receives malicious requests, which should have been blocked by the BIG-IP ASM Bot Defense profile. However, this issue does not compromise the BIG-IP ASM system’s ability to block denial-of-service (DoS) attacks.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The backend server may receive the malicious requests that should have been blocked by the affected BIG-IP ASM system.

Security Advisory Recommended Actions

Workaround

To work around this issue, you can disable the dosl7.idle_fast_path database variable. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. Disable the dosl7.idle_fast_path database variable by entering the following command: 

    modify sys db dosl7.idle_fast_path value disable
