Description

  • Prometheus Scrape Fails with a Bad Request Error when the declare statement enables the  system_throughputPerformance location.
  • The following error can be seen on restnode log:

    severe: [telemetry.Prometheus.f5telemetry_default::My_Pull_Consumer] Unable to register metric for: system_throughputPerformance_sysPerformanceThroughputManagementBitsIn1_average. Value is not a valid number: NaN

Environment

  • vCMP / Viprion (multi-blade)
  • Telemetry 1.26.0

Cause

Seen behavior is caused by a knonw issue tracked with the Bug ID 1089445.

Recommended Actions

A fix is currently planned for the 1.29.0 release in late May (could be subject to change).
