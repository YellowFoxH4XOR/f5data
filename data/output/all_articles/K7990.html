Issue

Gentoo Linux users may receive the following error message when they attempt to launch a Network Access connection from the FirePass Webtop:

FirePass server closed connection (code 38)

Additionally, if Debug Logging is enabled, an error message similar to the following example will be logged to the /usr/local/lib/F5Networks/SSLVPN/var/log/svpn.dbg file on the Gentoo Linux system:

Fri, 28 Sep 2007 09:16:03 GMT [26700]: +++ main error: "(../src/OpenSSL.scm, line 60) error:00000000:lib(0):func(0):reason(0)" ()

This issue occurs when the /dev/ppp device does not exist on the Gentoo Linux system. To verify whether /dev/ppp exists, run /usr/sbin/pppd from the Linux command line. The output should appear similar to the following example:

# /usr/sbin/pppd
pppd: pppd is unable to open the /dev/ppp device.
You need to create the /dev/ppp device node by
executing the following command as root:

mknod /dev/ppp c 108 0

#

Workaround

You can work around this issue by running the mknod command as instructed by the output of /usr/sbin/pppd. For example:

# mknod /dev/ppp c 108 0
