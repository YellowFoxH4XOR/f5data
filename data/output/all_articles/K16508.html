Known Issue

BIG-IP Edge Client may display an invalid warning message.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a Network Access profile.
  • The access profile is configured with a Maximum Session Timeout set at zero (zero = disabled).
  • You establish a Network Access session using BIG-IP Edge Client.

Impact

BIG-IP Edge Client displays an invalid session timeout warning.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you establish a BIG-IP APM session, BIG-IP Edge Client displays an error message similar to the following example:

    Your session is about to reach maximum session timeout. You will be logged out in about one minute.

  • The BIG-IP Edge Client session timeout value displays all zeros.
  • Your session is not logged out.
