K000154625: F5OS host GUI still shows old version of tenant even after tenant software upgrade

Type
Support Solution
Published
2025-09-06
Updated
2025-09-06
Applies to
  • F5OS
  • F5OS-C: 1.8.0, 1.6.1, 1.8.1, 1.6.2
  • F5OS-A: 1.5.3, 1.8.0, 1.5.1, 1.5.2
Source
https://my.f5.com/manage/s/article/K000154625

Description

F5OS host GUI still shows old version of tenant software under Tenant Management > Tenant Deployments section even after tenant software upgrade.

Environment

  • F5OS-A/C
  • Tenants

Cause

The image under Tenant management > Tenant deployments is the initial image used to deploy tenant.This image is in qcow2 file format, generally used for virtual machines.

However, once deployed and during tenant software upgrade the image used is iso file type.This information should reflect in CLI of the host.

Recommended Actions

Access F5OS CLI using administrator credentials and run command - ' show tenants'

For example: 

Following output shows both initial image used to deploy and current tenant version

R4600-R9-S7# show tenants | include image
 state image            BIGIP-15.1.10.2-0.0.2.T2-F5OS.qcow2.zip.bundle
 state image-version    "BIG-IP 17.5.1 0.0.7"
