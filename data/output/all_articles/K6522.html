Known Issue

This is the result of a known issue. The /etc/sysconfig/coresize file was inadvertently removed from the BIG-IP version 9.0.2 full (clean) installation package. The /etc/sysconfig/coresize file is used to control the size of a core file in the event that a core file is generated. The default entry in the coresize file is unlimited. To prevent the BIG-IP system from generating a core file, you must set the entry to 0 (zero).

If the /etc/sysconfig/coresize file is missing, however, the BIG-IP system uses the default value of unlimited.

Important: For BIG-IP systems that contain only a Compact Flash (CF) card, it is critical to prevent the BIG-IP system from generating a core file, as the size of the core file would most likely render the system inoperable. To prevent the BIG-IP system from generating a core file, the BIG-IP system must contain a coresize file, and the value of the coresize file must be set to 0 (zero). For more information about the CF file system issue, refer to K4805: Known Issue: The Compact Flash (CF) file system is full after a core dump.

F5 Product Development is tracking the issue of the inadvertent removal of the /etc/sysconfig/coresize file from the full installation package as CR47892, and the issue has been partially fixed in BIG-IP version 9.0.3. The /etc/sysconfig/coresize file was reintroduced into BIG-IP version 9.0.3 and subsequent full (clean) installation packages.

However, if you are performing an upgrade rather than a full installation, the /etc/sysconfig/coresize file is not included in the upgrade packages of BIG-IP version 9.0.3 or later. F5 Networks Product Development continued to track the issue of the missing /etc/sysconfig/coresize file from the upgrade packages as CR47892, and this issue was fixed in BIG-IP version 9.1.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

If the /etc/sysconfig/coresize file is missing, upgrading to version 9.0.3 or later will not create a new file.

Workaround

If the file is missing, you can create the file by typing the following command:

echo unlimited > /etc/sysconfig/coresize
