K000159582: Unable to connect to F5OS tenant's management interface via IPv6 for a long time after re-deploying it

Description

After redeploying a BIG-IP tenant on F5OS, the tenant’s IPv6 management interface becomes inaccessible via ping or SSH from the network for several hours.

Tenant was in running state and fully operational when accessed via console.

Environment

  • BIG-IP tenant on F5OS
  • IPv6 management IP

Cause

F5OS tenants receive a new MAC address for the management interface each time they are deployed.

This can be problematic where adjacent devices have a long neighbor cache timeout (for example, 4 hours).

When connections to the tenant management interface are not working, it is typically due to adjacent devices sending packets to the "old", pre re-deployment MAC address.

Recommended Actions

Clear the neighbor cache entry for the IPv6 management address on adjacent devices.

Consider implementing a lower neighbor cache timeout on these devices, where appropriate and feasible.

Additional Information

F5OS tenants send unsolicited neighbor advertisements out of the management interface on startup, but these do not have the override flag set. Some network devices may not update existing cached entries or transition them to a STALE state, on receipt of these NA packets.
