Issue

Description

  • Devices are switching back and forth between active and standby state.
  • Log messages similar to the following are repeatedly logged to /var/log/ltm:
warning sod[8662]: 01140029:4: HA pool_memb_down /Common/pool_gw fails action is failover.

Environment

  • Devices configured in high availability (HA)
  • Gateway failsafe feature is configured

Cause

This issue can occur if the same gateway failsafe gateway is configured on both BIG-IP systems in a HA pair, and there is a connectivity issue to the configured gateway. The connectivity issue can result in a monitor failure for both systems and this can trigger simultaneous gateway failsafe conditions on both BIG-IP devices.

Recommended Actions

Do not configure gateway failsafe to point to the same same gateway on both BIG-IP HA devices.

Investigate connectivity between the BIG-IP and the configured gateway failsafe gateway.

Additional Information

Gateway failsafe is not intended to be used when the HA device group members each point to the same gateway failsafe gateway.
