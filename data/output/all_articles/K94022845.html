Description

F5 BIG-IP iControl REST API can be used to deploy, view, modify, patch .. etc configuration objects on the BIG-IP. this article will explain how to apply ASM security policy to multiple virtual servers.

Environment

  • ASM Security policy
  • Multiple virtual servers configured with HTTP profile

Cause

None

Recommended Actions

Here's an example of assigning a security policy to two virtual servers:

  • To start off, obtain the policy name and its corresponding policy ID value, run the following curl command:
curl -sk -u user:passwd -H "Content-Type: application/json" "https://x.x.x.x/mgmt/tm/asm/policies/" | sed 's/,/\'$'\n/g' | egrep -w "name|id"
Note: update the above command with correct credentials and IP/hostname of the BIG-IP in question.

The output should be similar to:

"name":"sample_policy_1"
"id":"3ABubgpPbPtE7jksigb4DQ"
"name":"sample_policy_2"
"id":"MrLpFzRHNarvj_zuAOD0fw"
  • Using the policy ID value, assign the desired security policy to the virtual servers in question:
curl -sk -u user:passwd -X PATCH -H "Content-Type: application/json" "https://x.x.x.x/mgmt/tm/asm/policies/3ABubgpPbPtE7jksigb4DQ" -d '{ "virtualServers":["/Common/VIP-1", "/Common/VIP-2"] }'
Note: update the above command with correct credentials and IP/hostname of the BIG-IP in question as well as policy ID and desired virtual servers.
