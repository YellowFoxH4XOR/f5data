Description

You want to change the AWS instance type to upgrade the CPU / memory capacity of BIG-IP VE residing in AWS
You are getting "unsupported instance" error

Environment

  • BIG-IP VE located in AWS
  • Using specific instance type like m3.2xlarge and trying to move to another one (m4.4xlarge or m5.4xlarge)

Cause

The instance type is either :

  • Not supported by the current BIG-IP version
  • Not supported by the initial BIG-IP version installed when you first deployed the BIG-IP VE in AWS

Recommended Actions
The instance type you want to install must be supported by both the current and initial BIG-IP software release.

To check if the instance type is supported by a BIG-IP version, refer to the BIG-IP Virtual Edition Supported Platforms matrix

To check the release history dates for EC2 instance types, refer to the EC2 Instance History
Note: BIG-IP support for an EC2 instance type will not be the same time as the initial release date of an EC2 instance type.

If the instance type you want to upgrade to is not supported by any of the above you need to redeploy the AWS BIG-IP VE from a new image. For more information, refer to BIG-IP VE in AWS
