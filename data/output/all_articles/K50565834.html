Description

This article explains how to create an iRule and assign to a virtual server.

Environment

  • iRule
  • Virtual server

Cause

None

Recommended Actions

  • Create an iRule
  • Add an iRule to your virtual server

To watch a video demo of these procedures, go to  Create an iRule and apply it to a virtual server.

Create an iRule

  1. Go to Local Traffic > iRules.

    You can select the plus symbol (+) to go directly to the Create page.

  2. Select Create.
  3. Give the iRule a name, such as my_irule. The full pathname of the iRule cannot exceed 255 characters or contain spaces.
  4. For Definition, enter the syntax for the iRule using Tcl syntax.

    Note: For detailed iRules information, refer to iRules Home on F5 Clouddocs.

  5. Select Finished.

Add an iRule to your virtual server

  1. Go to Local Traffic > Virtual Servers.
  2. Select the virtual server you to which you want to apply the iRule.
  3. Select Resources tab.
  4. Select Manage
  5. Select an iRule from Available list and move it to the Enabled list.
  6. Select Finished.
