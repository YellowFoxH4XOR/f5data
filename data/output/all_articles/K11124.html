Topic

You should consider using this procedure under the following conditions:

  • You are performing troubleshooting to resolve a BIG-IP APM issue and want to increase the BIG-IP APM logging level.
  • You want the BIG-IP APM system to populate session reports.

    For more information, refer to K44555523: BIG-IP APM session reports require access policy log level of Notice or higher

Description

The following procedure is for BIG-IP APM 11.x only. For information about configuring logging profiles in BIG-IP APM 12.0.0 and later, refer to the following articles:

  • K45423041: Enabling APM Policy debug logging
  • K61903673: Additional per-policy BIG-IP APM logging level configuration options available (13.x)


The default log level for the BIG-IP APM access policy log is Notice, which does not log session variables. Setting the access policy log level to Informational or Debug causes the BIG-IP APM system to log session variables and provide more information for troubleshooting, but it also adds more system overhead. If you need to log session variables on a production system, F5 recommends that you temporarily set the access policy log level to Informational while performing troubleshooting or debugging and then return the log level to Notice.

Note: You can alternatively add the Message Box policy item to an access policy to display specific session variables. For more information, refer to K11123: Displaying session variables using a message box event.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility.

Procedures

  • Configuring the BIG-IP APM logging level
  • Viewing BIG-IP APM logs

Configuring the BIG-IP APM logging level

    1. Log in to the Configuration utility.
    2. Navigate to System > Logs > Configuration > Options.
    3. Under Access Policy Logging, for Access Policy, note the current log level and click new log level. For example, Informational.

      Important: Do not click the Debug log level on a production system unless advised to do so by F5 Technical Support. The Debug log level produces large amounts of data, which may negatively impact performance. You should only enable Debug logging while actively troubleshooting and disable it after you have collected the information you need.

    4. Click Update.

    When you are finished troubleshooting, repeat these steps, changing the new log level back to the level you noted in step 3.

    Viewing BIG-IP APM logs

    1. Log in to the Configuration utility.
    2. Navigate to Access Policy > Reports.
    3. Close the Report Parameters pop-up window by clicking Cancel.
    4. In the Reports Browser, under General Reports, click All Messages and click Run Report.
    5. In the new Report Parameters pop-up window, for Restrict by Time, set the values you want to use, for Log Level clear the check boxes of the log levels you do not want to use, and then click Run Report.

    Alternatively, if you have access to the BIG-IP command line, you can view the BIG-IP APM logs in the /var/log/apm file.

    Important: If you have increased the logging threshold, after you finish troubleshooting, change the access policy log level back to its original setting.
