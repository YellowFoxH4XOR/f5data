Issue

If a BIG-IP APM device is downgraded from version 10.2.1, the bigip.conf file may fail to load and generate an error message that appears similar to the following example:

The requested value ({ {) is invalid (<variable assign item list> | none) [add | delete]) for 'variables' in 'agent variable assign'

Important: F5 does not support downgrading the bigip.conf file.

This error message occurs because the configuration file for version 10.2.1 includes default configuration of secure disable that earlier versions do not support. The following example illustrates a section of the configuration file that will generate this error message:

agent variable assign ad-access-policy_act_sso_credential_mapping_ag {
type sso credential mapping
variables {
{
varname "session.sso.token.last.username"
expression "expr {[mcget {session.logon.last.username}]}"
secure disable
}
{
varname "session.sso.token.last.password"
expression "expr {[mcget {session.logon.last.password}]}"
secure disable
}
}
}

To successfully load the bigip.conf file, you must remove or comment out the secure disable lines.
