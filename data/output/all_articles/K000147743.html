K000147743: How to redirect HTTP connections to HTTPS on a load-balancer?

Description

You would like all traffic sent to port 80 (unencrypted) to be redirected to port 443 HTTPS protocol (encrypted).

Environment

  • F5® Distributed Cloud Console
  • HTTP Load Balancer

Cause

  • No web service should be running on HTTP anymore, but only on HTTPS
  • Contemporary browsers use HTTPS by default, search engines take it in account for their ranking, and services like Letsencrypt make it easy to setup.
  • Redirecting HTTP connections to HTTPS has become a standard practice.

Answer/Recommended Actions

To redirect HTTP connections to HTTPS on a LB:

  1. Visit the corresponding load-balancer configuration in <namespace> > Manage > Load Balancers > HTTP Load Balancers
  2. In the top right corner click Edit Configuration
  3. Scroll down to Basic Configuration
  4. Switch from HTTP Load-balancer to HTTPS Load-balancer with Automatic Certificate(optional, you can provide your own)
  5. Tick the box HTTP Redirect to HTTPS
