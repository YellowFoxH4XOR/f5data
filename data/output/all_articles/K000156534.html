K000156534: vCMP guests parallel software installation fails with "Device or Resource busy" and "Audited" boot volume status

Description

When installing a BIG-IP software image on multiple vCMP guests simultaneously, the installation may fail with errors such as:

 

unmount failed Invalid argument 

Fatal error: mount failed: Device or resource busy

 

The GUI may show the image installation as "pending" while the CLI reports it as "complete." Other boot locations may display an "audited" status. The lind process, which manages software installation and volume creation, may restart unexpectedly during this scenario.

 

Environment

  • BIG-IP LTM
  • vCMP enabled
  • Software image installation on vCMP guests

 

Cause

A conflict occurs when attempting to install the same software image on multiple vCMP guests at the same time. The source image file becomes locked by concurrent installation attempts, causing the lind process to fail and restart unexpectedly. This leaves boot volumes in an "audited" state and prevents proper status updates in the GUI.

 

Recommended Actions

Do not install the same software image on multiple vCMP guests simultaneously.

If this issue occurs:

  1. Run bigstart restart lind to restart the lind process; this only affects software management and does not cause device downtime.
  2. Delete the affected boot location (e.g., HD1.2) using this command. tmsh delete sys software volume <volume_name> 
  3. Reinstall the desired software image to that boot volume.
  4. If problems persist, schedule a device reboot during a maintenance window.
