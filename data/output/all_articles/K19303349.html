Description

Your Source address changes unexpectedly when it is passed through a virtual server

Environment

  • BIG-IP LTM
  • Virtual Server
  • SNAT

Cause

The SNAT setting on your virtual server will change the Source IP address of connections being made to the pool

Recommended Actions

If this change is undesirable, set your SNAT setting to None

Additional Information

None
