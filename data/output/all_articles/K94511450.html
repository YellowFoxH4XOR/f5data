Description

When connecting to a remote desktop via APM, the local microphone is not sending the sound to the remote computer.  

Environment

  • BIG-IP APM
  • RDP

Cause

You must enable the sound features in the RDP profile custom parameters to use the local audio devices with the remote computer.  

Recommended Actions

  1. Navigate to the RDP profile and open the one you want to configure.
    Access  ->  Connectivity / VPN ->  VDI / RDP -> Remote Desktops
     
  2. In Custom Parameters, add the following lines:
    audiocapturemode:i:1
    audiomode:i:0
     
  3. Click Update 

Additional Information

audiocapturemode:i:1  
Setting this value to 1 enables audio capture from the local computer  and redirects it to an audio application in the remote computer. The default value is 0, which disables this function.
audiomode:i:0
Setting this value to 0 plays remote sounds on the local computer.
