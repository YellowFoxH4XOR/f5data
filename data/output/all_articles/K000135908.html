K000135908: External monitor type not available in the drop-down list in Local Traffic > Monitor

Published

Updated

Status
Legacy Content
Applies to

  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000135908

Description

When you are trying to create a custom curl monitor, by following the steps included in K31435017, after importing the external monitor script, you need to create the external monitor.

In the GUI you go to  Configuration Utility > Local Traffic > Monitor, Click Create, but the External monitor is not listed in the drop-down box for monitor type.

 

Environment

  • BIG-IP ASM
  • BIG-IP AVR
  • LTM module not licensed

Cause

When you have an ASM or ASM/AVR only, there is only limited LTM functionality available to allow ASM to work properly.

 

 Recommended Actions

To create an external monitor you will need the LTM license.

To be specific, the different scenarios may be listed below.

1) ASM with LTM both provisioned and licensed      ==>  The feature of external monitor is available
2) ASM with LTM not provisioned but licensed         ==>  The feature of external monitor is available
3) ASM with LTM not provisioned and not licensed  ==>  The feature of external monitor is not available

Additional Information

None.
