Known Issue

The Configuration utility may produce an error when attempting to edit a firewall policy.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP AFM system is configured with an Address List that references addresses in a non-default partition.
  • At least two of the addresses are configured in the Address List that have the same first three octets.

    For example:

    rules {
            RULE_VS-FW-EXAMPLE {
                action accept
                ip-protocol tcp
                log yes
                destination {
                    ports {
                        vnc-server { }
                    }
                }
                source {
                    addresses {
                        10.14.5.40%10 { }
                        10.14.5.41%10 { }
                    }
                }
            }
        }
    }

    Note: The first three octets of the addresses are 10.14.5 and are configured in non-default route domains.

  • You attempt to use the Inline Rule Editor.

Impact

The Configuration utility produces an error and the policy rules are not displayed.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to use the Inline Rule Editor, you observe an error message similar to the following example:

    500 (Internal Server Error)

  • You are unable to use the Inline Policy Editor.

Workaround

To work around this issue, you can view and modify the firewall policy rules using the TMOS Shell (tmsh). Additionally, you can enable viewing of the network firewall policy rules with the Configuration utility by disabling the Inline Rule Editor.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Options > Network Firewall.
  3. Clear the Enabled check box for the Inline Rule Editor.
  4. Click Update.
