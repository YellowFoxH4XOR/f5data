K1638: Reasons why all SNATs do not use the global TCP idle timeout for SNATs

Topic

If you change the global TCP idle timeout for SNATs, the new setting only affects new SNAT connections. Any current SNAT connections in the connection table will continue to use the previous value.

To use the new timeout value for existing connections, you must delete the existing connecton entry and recreate the connection.  The new SNAT properties will be applied to the new connection.
