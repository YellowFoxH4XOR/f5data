Description

The Remote Desktop ActiveX client type will only work with Internet Explorer.

Environment

  • Remote Desktop
  • ActiveX

Cause

ActiveX is proprietary to Microsoft and Internet Explorer.  ActiveX plugins will only work with Internet Explorer and not other Browsers.
It may be possible to use an extension for Chrome or Firefox allowing ActiveX plugins to work with these browsers, however this is not the intended use for ActiveX plugins, and the Remote Desktop (RDP) ActiveX plugin is not supported in anything other than Internet Explorer.

Recommended Actions

Microsoft announced the end of support for Internet Explorer on June 15, 2022 and so support for it has also ended on BIG-IP APM.

If you are using other browsers, it is recommended to use the Native Client type.

Additional Information

From Version 14.x, the ActiveX and Java client types are deprecated.

From Version 15.x,  only Native client type is permitted and is implicitly selected.
