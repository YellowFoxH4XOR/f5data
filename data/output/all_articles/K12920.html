Known Issue

The mcpd process may report an incorrect status for a node that you have set to a Disabled status, resulting in the system sending new connections to child pool members of the disabled node.

This issue occurs when all of the following conditions are met:

  • You have manually changed the Node status to Disabled.
  • The system reloads the configuration after you start the Traffic Management Microkernel (TMM) process, run a configuration synchronization (ConfigSync) operation, or type the bigpipe load, bigpipe merge, or tmsh load / sys config commands.

Impact

The BIG-IP system may not process new connections as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H380444 on the Diagnostics > Identified > Low screen.
  • The system still sends new connections to the pool members of the disabled node.

    To determine if the system is sending connections to the pool members of the disabled node, use the following bigpipe or tmsh commands:

    • Use the following syntax for the bigpipe command:

      bigpipe conn ss server <x.x.x.x:xx> show

      Replace <x.x.x.x:xx> with the IP address and port number for the pool member in question.

      For example:

      bigpipe conn ss server 10.3.1.3:80 show
    • Use the following syntax for the tmsh command:

      tmsh show sys connection ss-server-addr <x.x.x.x> ss-server-port <XX>

      Replace <x.x.x.x> with the IP address, and <XX> with the port number for the pool member in question.

      For example:

      tmsh show sys connection ss-server-addr 10.3.1.3 ss-server-port 80

Workaround

To work around this issue, you can set the node status to Forced Offline. To do so, perform one of the following procedures:

Impact of workaround: The system allows only active connections, and does not allow new connections with persistence records for the node.

Using the bigpipe command to set a node to Forced Offline status

  1. Log in to the BIG-IP command line.
  2. Set the node status to Forced Offline by using the following command syntax, where <x.x.x.x> is the IP address of the node you want to force offline:

    bigpipe node <x.x.x.x> down

Using the tmsh command to set a node to Forced Offline status

  1. Log in to the BIG-IP command line.
  2. Set the node status to Forced Offline by using the following command syntax, where <x.x.x.x> is the IP address of the node you want to force offline:

    tmsh modify ltm node <x.x.x.x> down

Using the Configuration utility to set a node to Forced Offline status

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Nodes.
  3. Click the node you want to force offline.
  4. Change the State to Forced Offline.
  5. Click Update.
