Description
When using External Logon Page agent within an APM Access Policy, an HTTP 405 error is returned. 

Environment

  • BIG-IP APM
  • External Logon Page in use 
  • HTTP 405 error is returned

Cause
After the redirection from my.policy in the APM side to the External Logon Page URL, the browser uses a POST method instead of a GET, which is expected

Recommended Actions

Set the External Logon Page server to accept POST coming from the client

None
