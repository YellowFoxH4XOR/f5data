K000138736: Syslog message "default send string" is sent to syslog server from BIG-IP LTM device

Support Solution

Description

When configuring remote logging server, remote logging server (such as Splunk or Qradar) may get "default send string" syslog message from BIG-IP.

 

2024-02-19 192.168.1.1  default send string
2024-02-19 192.168.1.1  default send string
2024-02-19 192.168.1.1  default send string
2024-02-19 192.168.1.1  default send string
2024-02-19 192.168.1.1  default send string
2024-02-19 192.168.1.1  default send string

 

 

Environment

  • Remote Logging
  • Logs sending to a Remote Logging Server
  • UDP monitor applied to remote logging server pool member

Cause

UDP monitor is assigned to configured syslog pool. "default send string" is actually the UDP monitor traffic received by remote logging server.

Recommended Actions

Remove the UDP monitor assigned to the pool . Use the ICMP gateway icmp monitor to syslog pool

Additional Information

None
