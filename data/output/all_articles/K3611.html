Topic

The Mean Time Between Failure (MTBF) values of older platforms in this article were computed using Ericsson (Formerly Telcordia) SR-332 Issue 1. Next generation F5 products will be computed using the SR-332 Issue 3 revision. The Issue 3 revision contains new data and methods for many components. MTBF values calculated with Revision 3 will be indicated in the tables below with a superscript 3 after the hours number. F5 will not recalculate MTBFs for older platforms utilizing Issue 3.

The Reliability Prediction Procedure for Electronic Equipment document (number SR-332, Issue 1 or 3 as applicable) can be ordered directly from Ericsson.

Note: The previous link points to a resource outside of MyF5. The third-party could remove the document without our knowledge.

The MTBF values listed in this article are the calculated MTBF values for F5 platforms. The actual MTBF values typically range higher than the values listed. F5 internally tracks the actual MTBF values targeting a 3x improvement over the calculated values. Actual MTBF values are determined using an F5 proprietary methodology, which takes into account information fed back into F5 iHealth and other systems, as well as the overall Return Materials Authorization (RMA) rate per platform to determine an average MTBF for each deployed platform. Analyzing these numbers allows for additional feedback into the quality process, which can then tie in with supplier reviews, component choice, and improving the overall manufacturing process.

Note: The MTBF values in this article were computed based on an assumed temperature of 25C, ground benign.

Note: Restriction of Hazardous Substances (RoHS)-compliant platforms have the same MTBF values as non-RoHS platforms.
