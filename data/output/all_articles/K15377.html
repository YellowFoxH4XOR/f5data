Topic

You should consider using this procedure under the following condition:

  • You want the BIG-IP Virtual Edition (VE) system to log a notification when the throughput rate exceeds a certain threshold.

Description

Starting in BIG-IP 10.2.4 and 11.2.0, you can configure BIG-IP VE systems to log a notification to the /var/log/ltm file when the system throughput rate exceeds a pre-configured threshold of the maximum allowed throughput rate licensed. This threshold is configurable via the log.alertbwthreshold database variable and is expressed as a percentage of the maximum allowed throughput rate licensed. By default, the log.alertbwthreshold database variable is set at different value, depending on the BIG-IP version:

  • BIG-IP 11.4.0 and later

    The log.alertbwthreshold database variable is preset with the value 75; the BIG-IP system will log a notification when the system exceeds 75 percent of the licensed throughput rate.

  • BIG-IP 11.3.0 and earlier

    The log.alertbwthreshold database variable is preset with the value 0; the BIG-IP system will not log any notification.

    For example, the log.alertbwthreshold database variable setting on a BIG-IP system running 12.0.0 appears similar to the following example:

    sys db log.alertbwthreshold {

    value "75"

    }

    When the database variable is set to a value greater than zero, the system logs a message to the /var/log/ltm file when the throughput rate exceeds the 75 percent threshold:

    01010045:5: Bandwidth utilization is 8 Mbps, exceeded 75% of Licensed 10 Mbps

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the TMOS Shell (tmsh).

Procedures

  • Determining the configured threshold
  • Adjusting the configured threshold
  • Resetting the threshold to its default value

Determining the configured threshold

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To view the currently configured threshold, type the following command:

    list /sys db log.alertbwthreshold

    The command should display output similar to the following example:

    sys db log.alertbwthreshold {
    value "75"
    }

    In this example, the output indicates that the system is configured to log a notification when the throughput rate exceeds 75% of the maximum allowed throughput rate licensed.

Adjusting the configured threshold

Impact of procedure: The notification logging intensity depends on how often the BIG-IP VE system exceeds the configured threshold, hence configuring a low value for the threshold may result in increased logging intensity. You should configure the threshold at a level sufficient for your capacity planning.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To adjust the threshold, type the following command:

    modify /sys db log.alertbwthreshold value <your desired threshold percent>

    For example, you can type the following command to configure the BIG-IP VE system to log a notification when the throughput rate exceeds 80% of the maximum allowable throughput rate licensed:

    modify /sys db log.alertbwthreshold value 80

  3. Save the changes by typing the following command:

    save /sys config

Resetting the threshold to its default value

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To reset the threshold to its default value, type the following command:

    modify /sys db log.alertbwthreshold reset-to-default

  3. Save the changes by typing the following command:

    save /sys config
