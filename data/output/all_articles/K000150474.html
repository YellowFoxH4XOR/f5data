Description

Configuration on a secondary blade on a chassis system may fail to load. This occurs for new blades to the cluster or a cluster member which has had its configuration defaulted. MCPD logs error message in /var/log/ltm indicating error in operation on object not yet loaded.

 

err mcpd[<PID>]: 01070712:3: Caught configuration exception (0), Data operation attempt on object that has not been loaded.

err mcpd[<PID>]: 01070734:3: Configuration error: Configuration from primary failed validation: 01070712:3: Caught configuration exception (0), Data operation attempt on object that has not been loaded.... failed validation with error 17237778.

 

Environment

Any chassis system VIC2200, VIC2400, C4480 or C4800.

New blade added to cluster or cluster member has its configuration defaulted or RMA replacement.

 

Cause

Unknown configuration object making MCPD fail to load configuration.

Issue being tracked as ID1850497 which will log more details indicating missing configuration object.

 

Recommended Actions

ssh into primary cluster member's blade management IP address to avoid being logged out when services are stopped.

Run command to forceload MCPD on all cluster members.

 

clsh touch /service/mcpd/forceload

 

Stop services on all cluster members, you will not be logged out of the primary when connected via primary blade's management IP address.

 

clsh bigstart stop

 

Wait for the primary blade to show all services are down then reboot the primary only. This avoids case where a new cluster member may become primary.

 

reboot

 

Wait for the primary blade to come online.

ssh into into each secondary blade and reboot.

 

reboot
