K63056145: The BIG-IP system may show a warning after a UCS is generated if a file in the configuration filesystem contains spaces.

Type
Support Solution
Published
2021-12-09
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.3
Source
https://my.f5.com/manage/s/article/K63056145

Description

The BIG-IP system may show a warning after a UCS is generated if a file in the configuration filesystem contains spaces, after generating a UCS on the configuration utility, you may see something similar to this message on the output:

/var/local/ucs/test.ucs is saved.
/config/<<Filename with blank spaces>>: Warning, file name has spaces

Environment

  • File with spaces in its name

  • Configuration Filesystem.

  • BIG-IP LTM.

Cause

Filenames should not contain any whitespace.

Recommended Actions

IMPACT: This should not have any negative impact on your system unless the file with spaces contains something that is being used.

  1. - find /config/ -name <<filename with blank spaces>>
  2. - config # mv '<<Filename with blank spaces>>' <<Filename without blank spaces>>

Additional Information

None.
