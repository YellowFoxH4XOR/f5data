K000148970: Unable to create self-signed device certificate in F5OS-A 1.8.0

Type
Support Solution
Published
2025-09-03
Updated
2025-09-03
Applies to

  • F5OS-C: 1.8.X, 1.8.1, 1.8.0
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000148970

Description

When trying to create a self-signed device certificate in F5OS-A 1.8.0, you receive an error as presented in the GUI or the CLI:

"Unable to create CSR for the self-signed certificate. See error log for details."

Environment

  • F5OS-A system
  • Attempting to create or change the self-signed device certificate

Example error text:

error-type : application
error-tag : malformed-message
error-path : /openconfig-system:system/aaa/f5-openconfig-aaa-tls:tls/create-self-signed-cert
error-message : Unable to create CSR for the self-signed certificate. See error log for details.

Cause

Starting in F5OS-A 1.8.0, the SAN parameter is now validated to make sure it is correct.

Recommended Actions

  1. When configuring the self-signed device certificate from the GUI or the CLI, make sure the SAN field contains a valid SAN parameter, example SAN parameters are below:
    1. DNS:r2600-01.company.local
    2. IP:10.10.10.10
    3. email:admin@company.local
