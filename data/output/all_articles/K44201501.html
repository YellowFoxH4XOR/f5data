K44201501: BIG-IP is padding HTTP response with additional whitespaces

Type
Support Solution
Published
2021-04-16
Updated
2023-02-21
Applies to
  • BIG-IP LTM: 15.1.2
Source
https://my.f5.com/manage/s/article/K44201501

Description

When viewing the HTTP response packet, you observe that the actual response has been extended considerably and can sometimes cause applications to break. Looking at packet captures you observe that the payload has been padded by whitespaces (HEX 20).

Environment

  • HTTP/ HTTPS virtual server
  • Analytics profile attached

Cause

The whitespaces are inserted by the analytics profile for Client Side Performance Monitoring (CSPM).

Recommended Actions

This is expected behavior. If there is a requirement for CSPM, then review the related articles for configuration options to get this to work work with your application.

Additional Information

None.
