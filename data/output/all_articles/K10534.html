Topic

Depending on the amount and type of traffic processed by the BIG-IP WebAccelerator, a large volume of messages may be logged in the /var/log/wa/pvac.log file. A large volume of messages in the pvac.log file may reduce an administrator's ability to monitor the log file efficiently. Additionally, a large volume of messages may cause the pvac process to restart.

The <stackTraceSimplified> configuration option in the /config/wa/pvsystem.conf file was introduced to control the growth of the pvac.log file.

Note: For information, refer to K8798: The BIG-IP WebAccelerator logs excessive stack trace information and K10528: Multiple debug messages are logged when an object is proxied by PVAC.

Configuring syslog-ng to filter unwanted pvac log messages

Note: For information about filtering pvac log messages on BIG-IP WebAccelerator version 9.4.x systems, refer to K10218: Filtering BIG-IP  WebAccelerator pvac log messages.

In addition to the stackTraceSimplified option, you can also filter specific messages that you have identified as unwanted. Beginning in BIG-IP WebAccelerator version 10.0.0, the syslog template includes an f_pvac filter that supports filtering of pvac log messages. To configure the syslog template f_pvac filter, perform the following procedure:

Important: The changes detailed in this procedure will prevent messages from being logged that may indicate an issue or failure. These changes should be removed when diagnosing a failure.

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Configure the f_pvac filter using the following command syntax:

    bpsh <<END
    syslog include "
    filter f_pvac {
        facility(kern) and match(\"WA\") and not match(\"string to filter\");
    };"
    END

    Important: When specifying a string to be filtered from the logs, ensure only the messages you want filtered are affected.

  3. Save the configuration by typing the following command:

    bigpipe save

Removing the f_pvac filter 

To remove the f_pvac filter configured in step 2, perform the following procedure:

  1. Remove the f_pvac filter by typing the following command:

    bigpipe syslog include none

  2. Save the configuration by typing the following command:

    bigpipe save
