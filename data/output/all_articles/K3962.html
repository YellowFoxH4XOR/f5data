K3962: The hw_acceleration global variable can no longer be set to full

Type
Knowledge
Published
2006-06-21
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • BIG-IP 4.X: 4.6.4
Source
https://my.f5.com/manage/s/article/K3962

Topic

When the hw_acceleration global variable is set to full, it causes hardware problems in the Packet Velocity ASIC (PVA).

F5 Product Development tracked this issue as CR35400 and CR38714.

Beginning in BIG-IP 4.5.11 and 4.6.3, the full acceleration option was removed and the default for the hw_acceleration global variable and maximum setting is partial. This change has no effect on systems that are not equipped with a PVA.
