Known Issue

The BIG-IP ASM system may incorrectly trigger Modified domain cookie violations. This issue occurs when all of the following conditions are met:

  • On the Application Security > Policy > Blocking > Settings page, the affected security policy is configured to block Modified domain cookie violations.
  • The response from the origin web server (OWS) contains a set-cookie header that has the following attributes:
    • The cookie value is enclosed in double quotes.
    • There is one or more cookie attributes in addition to the cookie name.

    The following example shows a set-cookie header with the described attributes:

    Set-Cookie: TestCookie="example123"; Domain=192.168.20.37; path=/

Impact

The BIG-IP ASM system may report false positive Modified domain cookie violations.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP ASM system triggers the Modified domain cookie violation although the received cookie has not been tempered.

Workaround

There is no workaround for this issue. However, you may be able to mitigate this issue by configuring the OWS to return cookie values without double quotes.
