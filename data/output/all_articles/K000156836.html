K000156836: How do I check if BIG-IP AFM DoS protection profile is configured on a virtual server?

Type
Support Solution
Published
2025-10-06
Updated
2025-10-17
Applies to
  • BIG-IP
  • BIG-IP AFM
Source
https://my.f5.com/manage/s/article/K000156836

Description

You are trying to determine if a BIG-IP AFM DoS protection profile is linked to a virtual server to protect against DoS attacks.

Environment

  • BIG-IP Advanced Firewall Manager (AFM)
  • BIG-IP virtual server configuration
  • DoS protection profile

Cause

None

Recommended Actions

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to the Local Traffic menu and select Virtual Servers.
  3. Locate and select the virtual server you want to review.
  4. In the virtual server properties screen, check under the Security tab.
  5. Look for the DoS Protection Profile field. If a profile is assigned, it will be displayed in this field.

Additional Information

For further details on managing DoS protection profiles, refer to the BIG-IP AFM documentation available on F5 Cloud Docs.
