Description

Disk space full due to log messages on the file /var/log/pi_learning

Environment

  • AFM
  • IPS
  • Disk space full

Cause

ID1250117 (add /var/log/pi_learning to logrotate)

Recommended Actions

to delete the content of the huge log file you can run the command manually

truncate -s 0 /var/log/pi_learning

If the file is growing again the best way is to create a cronjob to flush the file on a daily basis.

You can also automate the flush of /var/log/pi_learning daily automatically with a cron job as indicated here:

 

1.) Create the script file called "flush_pi_learning"

# echo -e '#! /bin/bash\ntruncate -s 0 /var/log/pi_learning' > flush_pi_learning

# cat flush_pi_learning

#! /bin/bash
truncate -s 0 /var/log/pi_learning

2.) Give the file "execute" priviledges:

# chmod +x flush_pi_learning
# ls -l flush*

-rwxr-xr-x. 1 root root 48 Dec 22 21:06 flush_pi_learning

3.) Move file to daily cron so it is automatically executed every day:

# mv flush* /etc/cron.daily/.
# ll /etc/cron.daily
