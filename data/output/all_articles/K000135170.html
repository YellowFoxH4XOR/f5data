Description

You can't save asm changes on Security  >  Application Security : Policy Building : Learning and Blocking Settings as the save button is greyed out.

Environment

  • BIG-IP ASM

Cause

There are invalid value(s) on this page which cause the issue.

 Recommended Actions

You can click the triangle next to 'Policy Building Settings' to list all the entities on this page, then look for lines that have 'Invalid value' in red words and modify the value to a allowed one.

For instance, in the following screenshot, customer tries to define a maximum of 10000 parameters for 'Check maximum number of parameters' under 'HTTP protocol compliance failed', and it's marked as 'Invalid value' as the maximum value allowed is 5000.

Once you change it to a value samller or equal to 5000, save button is resumed again.

If there are other entries that are marked as 'Invalid value', modify them accordingly.
