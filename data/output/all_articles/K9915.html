K9915: When updating attack signatures, BIG-IP ASM reports the most recent file is already installed

Known Issue

This is the result of a known issue. When you update the attack signature to the most recent release, the BIG-IP ASM will erroneously report that the most recent file has already been installed if you have the following configuration:

  • The Update Mode is set to Scheduled
  • The Delivery Mode is set to Automatic

Note: For more information, refer to K8217: Updating the BIG-IP ASM attack signatures.

F5 Product Development tracked this issue as CR112601 and it was fixed in BIG-IP 9.4.7. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can work around this issue by manually installing the new attack singature. To do so, perform the following procedure:

  1. Browse to http://downloads.f5.com.
  2. Manually download the latest signature file to your local work station.
  3. Log in to the Configuration utility.
  4. Click Application Security.
  5. Click Options.
  6. From the Attack Signatures menu, select Attack Signatures Update.
  7. In the Attack Signatures Update section, click Manual for the Update Mode setting.
  8. For the Delivery Mode setting, select Manual.
  9. Click Save Settings.
  10. If you want to update the system-supplied signatures now, click Browse and locate the previously saved signature file, so that the path to the file appears in the Upload File box.
  11. To upload and apply the signature update, click Update Signatures.
