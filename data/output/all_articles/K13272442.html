Known Issue

The Dashboard CPU history file may contain incorrect values.

This issue occurs when the following condition is met:

  • The HTSplit feature is enabled.

    Note: This feature is enabled by default.

Impact

The CPU history in the exported comma-separated values (CSV) file does not match actual CPU usage.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Values such as 33%, 66%, and 99% may appear in the CSV file that the system exports from the dashboard utility.

Workaround

To work around this issue, you can view the CPU history using the System Activity Report (sar) utility. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Type the following command, depending on the BIG-IP version that you are running:

    BIG-IP 12.x and higher:

    sar -f /var/log/sa6/sa

    Or, for older data, type the following command:

    sar -f /var/log/sa6/sa.1

    The oldest data is found compressed in the /var/log/sa6 file, and you must use the gunzip utility to get that data.
     

    BIG-IP 11.x:

    sar -f /var/log/sa/sa

    Or, for older data, type the following command:

    sar -f /var/log/sa/sa.1

    The oldest data is found compressed in the /var/log/sa file, and you must run the gunzip utility to get that data.
