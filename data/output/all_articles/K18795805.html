Description

The Base Registration Key cannot be used to re-activate the license on a device, if it is not retired. A license key is retired for various reasons.
If an invalid or retired key is used to activate the license, an error message will appear as below.

Error message: 51079 - Invalid Base Registration Key / Retired status

Environment

  • License activation
  • BIG-IP/BIG IQ
  • RMA

Cause

  • The Base Registration Key is incomplete or retired.
  • Activating the RMA device with the default RMA Base Registration Key which is RRMAX-XXBIG-IPXXX-V5BXX-SPAREXX

Recommended Actions

  1. Make sure to use the correct Base Registration Key. Base Registration Key contains 27 alphabet. 
  2. For any RMA order processed, an email will be sent that contains the Base Registration Key. See example below:
    Dear Valued Customer:
    This is an automated notification, Please do not reply.
         Service Request: 1-XXXXXXXXXX or C1234567
         RMA Service Order: 1-XXXXXXXXXX
         Internal Ticket #: 
         Shipped: 
         Tracking Number: 
         Defective Serial Number: f5-XXXX-XXXX
         Replacement Serial Number: f5-XXXX-XXXX
         Base Registration Key: ABCDE-FGHIJ-KLMNO-PQRST-UVWXYZA


  3. In case you can not find the email, please contact F5 technical support.
  4. Once you have the correct Base Registration Key, reactivate the license.
    Refer to     K7752: Licensing the BIG-IP system
