Description

After executing the command tmsh modify /sys global-settings gui-setup enabled on a BIG-IP system, the web UI (TMUI) displays the initial Setup Utility wizard instead of the expected configuration dashboard.

Environment

  • BIG-IP LTM version 15.1.x
  • Large configuration with many virtual servers and objects
  • gui-setup set to enabled via tmsh
  • Configuration is still present
  • Non-traffic impacting

Cause

The command tmsh modify /sys global-settings gui-setup enabled re-enables the BIG-IP Setup Utility wizard, causing the TMUI to present the initial setup screen on every login.

Answer/Recommended Actions

Disable the GUI Setup Utility Wizard

Log in to the BIG-IP CLI. Run the following command to disable the Setup Utility:

 tmsh modify /sys global-settings gui-setup disabled

Save the configuration to persist the change across reboots:

tmsh save /sys config
