Description

When renewing a BIG-IP subscription license, base registration keys (BRKs) may be mistakenly mapped with incorrect add-on capacity keys (such as 200 MB instead of the intended 1 GB).


Environment

MyF5

Mapping after subscription renewal


Cause

Incorrect mapping of add-on capacity keys during the license renewal process results in base registration keys being associated with insufficient capacity (e.g., 200 MB instead of 1 GB). Once this mapping is completed, it cannot be reversed. The system will continue to operate with the lower capacity, and attempting to reactivate the license with a different add-on key will not change the assigned capacity unless a new base registration key is used.



Recommended Actions

  • Do not reactivate licenses on affected instances until the mapping issue is resolved to prevent reduced system performance.
  • In MyF5, edit and revoke any incorrectly mapped base registration keys so they can be reused where lower capacity is acceptable.
  • On the BIG-IP device, reactivate the license using a base registration key that has been correctly mapped with the desired add-on (e.g., 1 GB).
  • Perform license reactivation during a maintenance window or on standby devices, as this process reloads configuration and may interrupt traffic or trigger failover in HA environments.
  • If additional help is needed, schedule a remote session with F5 Support.


Additional Information

To avoid similar situation in future please make sure that you are mapping correct base registration key with the corresponding capacity.
