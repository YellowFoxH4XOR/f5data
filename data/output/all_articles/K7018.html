Topic

This article applies to BIG-IP ASM 9.4.0 through 10.2.4. For information about other versions, refer to the following article:

  • K14895: Overview of BIG-IP ASM user role permissions (11.x)

Beginning with BIG-IP ASM 9.4.0, user roles are used to grant access to BIG-IP system objects. Each user role allows a different level of access to BIG-IP system objects.

The following tables outline each user role's level of access to BIG-IP ASM system objects:
