Description

After you create a security policy and begin sending traffic to the application, the system provides learning suggestions concerning additions to the security policy based on the traffic it sees. When navigating to Security  ››  Application Security : Policy Building : Traffic Learning in the Configuration Utility, you will view details about each suggestion, including the actual request/response that triggered the suggestion. 

When the sample requests were correlated with learning suggestions by policy builder, you may find the log messages below in /var/log/messages.

Environment

  • BIG-IP 15.x
  • ASM learning suggestions
  • Sample requests for learning suggestions

Cause

None

Recommended Actions

This log message is by design, and you may safely ignore it.

Additional Information

  • To review requests that are related to learning suggestions, you need to have a security policy that is already handling traffic. If the Learn flag is disabled for a violation, you will not see learning suggestions for that violation. If no violations have occurred, you will only see learning suggestions for adding legitimate entities to the security policy.
  • Before you process a learning suggestion, it is very helpful to examine the details of sample requests that caused the learning suggestion. By viewing the requests, you can determine whether to accept each one, or not. If the suggestion is based on a violation, you can see whether the violation was caused by an attack, or if it is a false positive.
