Topic

To configure BIG-IP to use host names rather than IP addresses, you must enable BIG-IP to perform host name lookups. You can accomplish this by using one, or both, of the following methods:

  • Editing the /etc/hosts files and defining the node's address-name relationship
  • Configuring BIG-IP to perform DNS resolutions

Editing the /etc/hosts files

To edit the /etc/hosts, perform the following steps:

  1. Change to the /etc directory, by typing the following command:

    cd etc

  2. Using a text editor, such as vi or pico, edit the /etc/hosts file and add lines containing the IP addresses and corresponding host names directly the VIPS and NODES line.

    For example:

    #
# VIPS and NODES
#
11.11.11.11 www.domain.com
11.11.11.12 ftp.domain.com
  3. Save the hosts file.

    Note: The BIG-IP Configuration utility will continue to display each node listed in the node list by its IP address, not its host name.

Configuring BIG-IP to perform DNS resolutions

If your DNS server contains the addresses and names for the nodes you are adding to BIG-IP, you can add the name server information to the BIG-IP's /etc/resolv.conf file. The BIG-IP will then use DNS name lookup to resolve host names to their IP addresses.

For specific information about configuring DNS on BIG-IP, refer to K3624: Configuring DNS name resolution on a BIG-IP or 3-DNS Controller.
