Topic

You should consider using this procedure under the following condition:

  • You need the registration key for your LineRate system.

Description

The LineRate system does not have a serial number format that is similar to F5 hardware platforms. You can use the registration key to open a support case if you encounter any issue where you require F5 Technical Support assistance.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have access to the LineRate CLI or the REST API.
  • The license for the LineRate system has been activated.

    Note: If the license on your LineRate system has not yet been activated, you can contact your F5 sales representative for assistance.

Procedures

Displaying the registration key from the CLI (2.4.0 and later)

To display the registration key using the CLI, perform the following steps.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the LineRate system using SSH or the console.
  2. To display the registration key, type the following command:

    show licensing regkey

    The command output appears similar to the following:

    AYWTCR-RHQKE-VXVJF-JLYT-BEDLOHD

Displaying the registration key from the CLI (2.3.x and earlier 2.x versions)

To display the registration key using the CLI, perform the following steps.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the LineRate system using SSH or the console.
  2. Type the following command To display the registration key, type the following command:

    show licensing host-id

    The command output appears similar to the following example:

    0479BE9B-63C9-4B3F-BD73-87E9F36E42C9

Displaying the registration key from the CLI (1.6.x)

To display the registration key using the CLI, perform the following steps.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the LineRate system using SSH or the console.
  2. To display the registration key, type the following command:

    show license-manager host-id

    The command output appears similar to the following example:

    Bios=0479BE9B-63C9-4B3F-BD73-87E9F36E42C9

    Note: The registration key begins after the equal sign "=".

Displaying the registration key using the REST API

To display the registration key using the REST API, perform the following steps.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Authenticate with the LineRate system using the REST API.
  2. Perform a GET operation on the /status/licensing/regKey node.

Requesting license information from F5 using the registration key

To request information about the current status of an F5 registration key, such as on which system a specific registration key has been activated, or what service contracts have been assigned, perform the following steps.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open a browser session, and connect to the following site:

    https://secure.f5.com/validate/validate.jsp

  2. In the Contact Email box, type your email address.
  3. In the box titled F5 Licenses / Serial Numbers, type the base Registration Key.
  4. Click the Submit Info Request button.

    The F5 licensing server sends a license summary for the submitted registration key to the specified email address.
