Organizations rely on a Virtual Private Network (VPN) to provide their employees with continuous, secure, remote access to corporate resources. Use this article to help resolve issues that may arise with your VPN.

BIG-IP APM Network Access is a VPN solution. You must have the following to use BIG-IP APM Network Access:

  • A licensed and provisioned BIG-IP APM module on your BIG-IP system in a virtual or appliance edition.
  • Sufficient access session and User Connectivity Licenses (CCUs).

A successful BIG-IP APM Network Access session consumes:

  • One access session license.
  • One CCU.

Access session license

When users initiate a BIG-IP APM Network Access session, they start a new session on the BIG-IP APM system. The system:

  • Consumes one access session license.
  • Initiates access policy evaluation.
    • Validates user authentication and authorization.
    • Performs client side checks and other security controls defined in the access policy.

Access policy evaluation results in one of following two outcomes:

  •     Success—The access session license remains unavailable for other sessions until the system terminates the current session or the user logs out.
  •     Failure—The system terminates the session and releases the access session license, making it available for a new session.

CCU

The BIG-IP APM system consumes a CCU when the following happens:

  • User connects to a Network Access resource.
  • During access policy evaluation, the system assigns a Network Access resource to a user.

Each session consumes only one CCU regardless of how many resources the system assigns to a user.

The system also consumes a CCU when it connects to any BIG-IP APM tunnel-type resource, including:

  • Per App VPN
  • Application tunnel
  • Portal Access

BIG-IP APM Limited and VPN

All BIG-IP systems include a free perpetual license for the BIG-IP APM Limited module (formerly APM-Lite).

This module includes the same features as a fully licensed BIG-IP APM module, with the following limitations:

  • Licenses for access sessions and CCU are limited to 10 each.
  • Hardware compression is disabled.
  • Software compression is limited to 50 Mbps.
  • Active Directory Federation Services and Proxy Integration Protocol (MS-ADFSPIP / ADFS-PIP ADFS) proxy functionality is not supported.
  • Oracle Access Manager (OAM) integration is not provided.

Provisioning and licensing operations

Verify that BIG-IP APM module is licensed 

To verify that the BIG-IP APM module is licensed on your BIG-IP system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line interface.
  2. Enter the following command:

    tmsh show /sys license

    If BIG-IP APM is licensed for your BIG-IP system, you should see APM listed as an active module in output similar to the following:

    Sys::License
    Licensed Version                       15.0.1
    Registration key                       FXXXX-XXXXX-XXXXX-XXXXX-XXXXXXX
    Licensed On                            2020/03/16
    License Start Date                     2020/03/15
    License End Date                       2020/04/16
    Service Check Date                     2020/03/16
    Platform ID                            Z100
    Daily Renewal Notification Days        5
    Daily Renewal Notification Start Date  2020/04/11

    Active Modules
      APM, Max CCU, VE (R074823-2204805)
        Anti-Virus Checks
        Base Endpoint Security Checks
        Firewall Checks
        Machine Certificate Checks
        Network Access
        Protected Workspace
        Secure Virtual Keyboard
        APM, Web Application
        App Tunnel
        Remote Desktop
      ...

If APM is not licensed, refer to K7752: Licensing the BIG-IP system.

Verify that the BIG-IP APM module is provisioned 

To verify that the BIG-IP APM module is licensed and provisioned on your BIG-IP system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line interface.
  2. Enter the following command:

    tmsh list /sys provision apm

    If the BIG-IP APM module is provisioned on your BIG-IP system, the output is similar to the following:

    sys provision apm {
        level <nominal>
    }

If the BIG-IP APM module is not provisioned, refer to K12111: Provisioning licensed BIG-IP modules

Display the BIG-IP APM global license limit

To display the BIG-IP APM global license limit, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line interface.
  2. Enter the following command:

    tmsh show /apm license

    If the BIG-IP APM module is licensed and provisioned for your BIG-IP system, the output is similar to the following:

    --------------------------------------------
    Global Access License Details:              
    --------------------------------------------
     total access sessions: 10.0M               
     current active sessions: 0                 
     current established sessions: 0            
     access sessions threshold percent: 75      
     total connectivity sessions: 2.5K          
     current connectivity sessions: 0           
     connectivity sessions threshold percent: 75
     total swg sessions: 0                      
     current swg sessions: 0                    
     swg sessions threshold percent: 75         
     total swg limited sessions: 10.0M          
     current swg limited sessions: 0            
     swg limited sessions threshold percent: 75 
     total api protection sub-sessions: 50.0M   

    Note: The total access session and total connectivity session represent respectively the total number of access sessions and CCUs available. 

Display the total access session licenses

To display the total access session licenses, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line interface.
  2. Enter the following command:

    tmsh show /sys license detail | grep apm_access_sessions

    If the BIG-APM module is licensed and provisioned for your BIG-IP system, the output is similar to the following:

    apm_access_sessions [10000000]

Display the total CCUs

To display the total CCUs, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line interface.
  2. Enter the following command:

    tmsh show /sys license detail | grep apm_sessions

    If the BIG-IP APM module is licensed and provisioned for your BIG-IP system, the output is similar to the following:

    apm_sessions [2500]

Determine the total number of active access sessions currently in use

To determine the total number of access sessions currently in use, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line interface.
  2. Enter the following command:

     snmpwalk -v 2c -c public localhost F5-BIGIP-APM-MIB::apmAccessStatCurrentActiveSessions

    If the BIG-IP APM module is licensed and provisioned for your BIG-IP system, the output is similar to the following:

    F5-BIGIP-APM-MIB::apmAccessStatCurrentActiveSessions.0 = Counter64: 104

    In the above output, 104 is the total number of active access sessions currently in use.

    Note: F5-BIGIP-APM-MIB::apmAccessStatCurrentActiveSessions converts to the 1.3.6.1.4.1.3375.2.6.1.4.3.0 OID.

Determine the total number of CCUs currently in use

To determine the total number of CCUs currently in use, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line interface.
  2. Enter the following command

    snmpwalk -v 2c -c public localhost F5-BIGIP-APM-MIB::apmGlobalConnectivityStatCurConns

    If the BIG-IP APM module is licensed and provisioned for your BIG-IP system, the output is similar to the following:

    F5-BIGIP-APM-MIB::apmGlobalConnectivityStatCurConns.0 = Counter64: 100

    In the above output, 100 is the total number of CCUs currently in use.

    Note: F5-BIGIP-APM-MIB::apmGlobalConnectivityStatCurConns converts to the 1.3.6.1.4.1.3375.2.6.1.5.3.0 OID.

Increase VPN license capacity

  • To increase VPN license capacity, you can install a new BIG-IP APM license or an add-on BIG-IP APM license to your BIG-IP system. For more information, refer to K7752: Licensing the BIG-IP system.
