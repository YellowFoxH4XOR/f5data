Description
AS3 PATCH operation fails for “InvalidPatchOperationError: path does not exist SampleTenant1/Application_1/<object_name>”

e.g.
PATCH to https://<bigIP mgmt IP>/mgmt/shared/appsvcs/declare

[{
"path": "SampleTenant1/Application_1/webPoolPatch1",
"op": "add",
"value": {
        "class": "Pool",
            "monitors": [
                "http"
            ],
            "members": [
            {
                "servicePort": 80,
                "serverAddresses": 
                [
                "55.55.55.55"
                ]
            }
            ]
        }
}]

{
    "code": 422,
    "message": "InvalidPatchOperationError: path does not exist SampleTenant1/Application_1/webPoolPatch1"
}

Environment

  • AS3 v3.32.0 and later
  • AS3 Patch operation

Cause
This issue is due to "path" not containing a leading "/".

 

Recommended Actions
Update the "path" definition with the leading "/" and resend the PATCH operation.

 

Additional Information
Previous to AS3 v3.32.0, a PATCH operation without the leading "/" in the "path" definition, would succeed.
