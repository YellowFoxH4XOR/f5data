Topic

When you upgrade a BIG-IP system that includes lights-out processor (LOP) Backplane Micro-Controller Hybrid (LBH) firmware, if the firmware update process is interrupted before it is complete, the serial console output may become garbled.

Description

When performing a BIG-IP software upgrade, the system checks to determine if a firmware update is required and updates the firmware accordingly. A software upgrade combined with firmware update can take between 15 to 25 minutes to complete. If the LOP/LBH firmware update process is interrupted before the firmware update completes, the output on the serial console may become distorted. This problem can present itself whenever the LOP/LBH has stopped working correctly and is most commonly encountered during interrupted software upgrades.

Recommendations

When upgrading a BIG-IP system that includes LOP/LBH firmware, you should consider the following factors:

  • If the BIG-IP software installation is taking longer than expected, do not attempt to interrupt the upgrade process. Instead, F5 recommends that you connect a serial console and monitor the status of the BIG-IP upgrade progress. Doing so lets you  verify when the BIG-IP software and LOP/LBH firmware updates complete.
  • If the firmware process has been interrupted, you can set the serial console baud rate to 115200, as the system reverts to that baud rate while it attempts to load the newer firmware. If the newer firmware fails to load, the system reverts back to the previously installed version of the LOP/LBH firmware. After the reinstall is complete, the system reverts back to the baud rate that was previously configured (The default is 19200).
  • In the event that the serial console output remains distorted after following the aforementioned recommendations, you need to do further troubleshooting to determine whether a return materials authorization (RMA) is needed. Contact F5 Technical Support for assistance with troubleshooting the issue.
