Description

When saving a newly created security policy you may get the following error in the GUI:

Failed to configure created policy
Failed to update policy builder settings

Environment

  • BIG-IP ASM 
  • Saving newly created policy via GUI
     

Cause

This issue occurs when a user is accessing BIG-IP management GUI via a proxy. 
 

Recommended Actions

Accessing GUI without proxy resolves the issue. 
 

Additional Information

None.
