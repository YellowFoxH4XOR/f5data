Issue

Error Message

info bcm56xxd: 012c0012:6: <BCM56XXD_INFO>

In this error message, note the following:

  • <BCM56XXD_INFO> is one of many informational message related to bcm56xxd process initialization

For example:

info bcm56xxd: 012c0012:6: bsx_halmsg_get_system_slot: chassis slot = 0, chassis max slots = 0
info bcm56xxd: 012c0012:6: HAL reported system ID=139, platform family=0xf2000000, chassis slots=0
info bcm56xxd: 012c0012:6: find Higig2 capable HSBe2 device.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The bcm56xxd process starts.

This message code pertains to a group of messages that generate during the initialization sequence for the bcm56xxd process. This message normally occurs when the BIG-IP system boots or restarts.

Impact

None; these messages are informational only.

Recommended Actions

None
