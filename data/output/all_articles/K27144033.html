Description

No GUI access
Cannot ping the management default gateway
Route table on 15.1.5.1 is missing the configured static routes seen in 15.1.5.
Command line prompt "LICENSE INVALID"

Environment

  • AWS 
  • BIG-IP LTM VE 15.1.5.1 

Cause

cloud-init set the dhcp lease. Later it turned down that lease and removed it due to mismatch in statically defined netmask

Recommended Actions

Short term workaround is to boot back to previous version

Workaround for version 15.1.5.1:
  1. Before the upgrade process, change the management IP address subnet mask from /27 to /28 (match the AWS VPC Subnet network mask) 
  2. Delete the failing boot location (ie. HD1.1)
  3. Perform a fresh install of v15.1.5.1-0.0.14 while creating a new boot location
  4. Then save all the config and boot into the new install.
  5. Note that Management routes, access, and netmask are kept.
