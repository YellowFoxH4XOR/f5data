Known Issue

Special characters in iControl REST API object names may be escaped improperly, resulting in inconsistent results during set or verify operations.

This issue occurs when the following condition is met:

  • You use iControl REST object names with characters other than the following:

    • A-Z
    • a-z
    • 0-9
    • _ (underscore)

Impact

iControl REST queries fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Affected iControl REST queries fail and may return error messages similar to the following examples:

    • 404 - Object not found
    • 400 - Unexpected argument

Workaround

To work around this issue, you can avoid using special characters for object names.

For object names, use only the following characters:

  • A-Z
  • a-z
  • 0-9
  • _ (underscore)

Impact of action: None
