Known Issue

This is the result of a known issue. If a user running Windows Vista with Service Pack 1 (SP1) attempts to enter Protected Workspace using Internet Explorer 7, FirePass incorrectly prompts the user to install Microsoft Update KB935855. Prior to SP1, Windows Vista required KB935855 in order to support Protected Workspace. Windows Vista SP1 natively supports Protected Workspace, so users running Windows Vista with SP1 should not be prompted to install KB935855.

FirePass reports an error message similar to the following example:

Some Windows updates are required to run Protected Workspace. Please click on the following link for more details: Windows Update for IE7 and non-default desktop on Vista

OR contact your system administrator for assistance.

OR click here to continue.

If a user clicks the click here to continue link, FirePass performs the action defined in the fallback policy for the Protected Workspace pre-logon inspector. The default fallback policy for the Protected Workspace inspector redirects the user to the Logon Denied page.

F5 Networks Product Development tracked this issue as CR88715 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-601-10 has been issued for FirePass version 6.0.1 and Cumulative Hotfix HF-602-1 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the Cumulative Hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
