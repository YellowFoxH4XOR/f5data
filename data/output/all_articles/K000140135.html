K000140135: DNS - server object got stuck at red (offline) status with "No enabled VS available" message even after manually re-enabled server object.

Environment

  • BIG-IP DNS version 17.1.1 or later.
  • On BIG-IP DNS device, server object was disabled and after then BIG-IP DNS device was rebooted (i.e., software upgrade/maintenance).
  • On BIG-IP DNS device, server object was re-enabled after reboot.

 

Cause

Bug ID1592209.

 

Recommended Actions

Restart gtmd, and affected server object will get back to correct status.

# tmsh restart /sys service gtmd

 

Additional Information

The server object can be enabled after doing the workaround. It doesn't need to be enabled while restarting gtmd
