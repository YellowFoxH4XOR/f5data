Description

After inserting new blade the error message seen on /var/log/ltm

Jun 30 03:44:50 localhost.localdomain err mcpd[48393]: 01071a99:3: The requested bundle state of 'disabled' for interface x/y.0 is invalid.
Jun 30 03:44:51 localhost.localdomain err mcpd[48393]: 01070734:3: Configuration error: Configuration from primary failed validation: 01071a99:3: The requested bundle state of 'disabled' for interface x/y.0 is invalid.... failed validation with error 17242777.
Jun 30 03:44:51 localhost.localdomain err lind[48198]: 013c0004:3: IO error on recv from mcpd - connection lost

Environment

  • VIPRION
  • BIG-IP LTM

Cause

The running config and text configuration did not match. The bigip_base.conf showed the bundle disabled as seen below:

net interface x/y.0 {
    bundle disabled
    bundle-speed 100G
    forward-error-correction enabled
}

Recommended Actions

  • Login to the SSH on the primary blade.
  • Edit the bigip_base.conf file with vi editor.

          vi /config/bigip_base.conf
     
    net interface x/y.0 {
    bundle enabled
    bundle-speed 100G
    forward-error-correction enabled
    }

  • Save the file and exit vi by typing the following command and pressing Enter:

          :wq

  • Reload the configuration by typing the following command:

          tmsh load sys config
