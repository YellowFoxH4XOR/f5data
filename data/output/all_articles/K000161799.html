K000161799: BIG-IQ: Unable to import or overwrite PKCS12 certificate bundle for unmanaged certificate/key object

Type
Support Solution
Published
2026-06-18
Updated
2026-06-18
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.2, 8.4.1
Source
https://my.f5.com/manage/s/article/K000161799

Description

When attempting to import or overwrite a PKCS12 certificate bundle (containing certificate and key) for an unmanaged certificate/key object on BIG-IQ Centralized Management 8.4.1 or 8.4.2, the operation fails with the error:

 

Unable to DELETE SSL Cert object, check provided references.

 

This issue occurs when overwriting an existing certificate/key object, regardless whether the BIG-IP was discovered with or without a silo. Importing the key file alone may succeed, but BIG-IQ then reports that the certificate and key do not match.

 

Environment

  • BIG-IQ Centralized Management
  • Certificate/key objects imported as unmanaged (metadata only) from BIG-IP
  • PKCS12 bundle containing certificate and key

Cause

This issue is caused by a software bug (Bug ID2331109) in BIG-IQ. When attempting to overwrite an unmanaged certificate/key object (imported from BIG-IP) with a PKCS12 bundle, BIG-IQ's certificate management logic incorrectly handles the object name and UUID due to missing file extensions. This results in operations targeting a non-existent object, causing the "Unable to DELETE SSL Cert object" error.

 

Answer/Recommended Actions

Do not attempt to overwrite existing unmanaged certificate/key objects with PKCS12 bundles until a fix is applied. If you encounter this error, contact F5 Support and reference Bug ID2331109 and request for the fix.
