Description

TMSH Command line history file may grow over max history size which default is 10000.

The TMSH Command history file .tmsh-history-<user name> is found under user home directory.

Environment

TMSH Command line

Cause

When TMSH session is terminated abruptly, the TMSH session may remain.
The TMSH Command line history file is rotated at the close of the tmsh session. If the TMSH session is not closed properly, the rotation may not happen when the TMSH Command line history file reached at the max history size.

The issue is tracked by ID969345.

Recommended Actions

Make sure to quit TMSH session by TMSH command quit.
Upgrade to BIG-IP version that resolves ID969345.
