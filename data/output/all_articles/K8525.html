K8525: Support for RADIUS password changes

Topic

FirePass does not currently support password changes for the RADIUS authentication method. If a user attempts to logon to the FirePass controller with an expired RADIUS password, authentication fails. Additionally, FirePass does not display an error message indicating that the password has expired.

FirePass supports password changes for expired passwords for the Active Directory authentication method. If you are running the Windows Internet Authentication Service (IAS), configure Active Directory authentication instead of RADIUS authentication to support password changes for expired passwords.
