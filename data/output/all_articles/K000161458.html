K000161458: How to filter AVR data sent via Telemetry

Type
Support Solution
Published
2026-05-28
Updated
2026-05-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000161458

Description

When AVR is configured for Telemetry Streaming additional unrelated messages may get sent as well. There may be a need to filter these in order to reduce the amount of messages being logged.

Environment

  • BIG-IP
  • AVR configured to log via Telemetry Streaming

Cause

When AVR is configured for Telemetry Streaming additional unrelated messages may get sent as well. There may be a need to filter these in order to reduce the amount of messages being logged.

Answer/Recommended Actions

There is no option to filter out undesired log messages using the Telemetry Streaming declaration. Instead use an iRule.

Example for TCP:

when CLIENT_ACCEPTED { 
    node 127.0.0.1 6514
    TCP::collect
}
 
when CLIENT_DATA {
  switch -glob [TCP::payload] {
     "*errdefs_msgno=\"22327307*" -
     "*errdefs_msgno=\"2232730*" {
#        log local0. "drop"
        drop
     } 
     default {
#        log local0. "release"
        TCP::release
        TCP::close
     }
  }
}

 

Example for UDP:

when CLIENT_ACCEPTED { 
    node 127.0.0.1 6514
}
 
when CLIENT_DATA {
  switch -glob [TCP::payload] {
     "*errdefs_msgno=\"22327307*" -
     "*errdefs_msgno=\"2232730*" {
        drop
     } 
     default {
     }
  }
}
