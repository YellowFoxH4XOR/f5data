Known Issue

This is the result of a known issue. The BIG-IP system generates the following sysctl error message during reboot, where <build_number> is the BIG-IP build number for the system on which the error occurred:

Base<build_number>
....error: 'Base<build_number>.core' must be of the form name=value

The error is benign; it occurs when the rc.sysinit script calls the sed script to search for and print any pattern after the word Build in the /VERSION file.

F5 Product Development tracked this issue as CR89092 and it was fixed in BIG-IP 9.4.4. For information about upgrading, refer to the BIG-IP GTM, LTM, ASM, Link Controller, or WebAccelerator release notes.
