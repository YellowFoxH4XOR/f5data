K92600561: BIGIQ LTM logs show SSL transaction (TPS) rate limit reached

Type
Support Solution
Published
2021-09-22
Updated
2026-08-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K92600561

Description

SSL transaction (TPS) rate limit reached in LTM logs on BIG-IQ.

  • Syslog monitoring of LTM logs on BIG-IQ
  • Log messages seen only, no noted impact
  • Error message similar to  'SSL transaction (TPS) rate limit reached'

Environment

  • Normal operating BIG-IQ with at least 1 DCD
  • BIG-IQ 8.0, 8.1

Cause

Logs indicate that localhost SSL connections to Elastic Search have temporarily reached a high volume.

Recommended Actions

This issue is cosmetic only and the connections will retry and connect. The alerts cannot be turned off, however, if needed they can be filtered out:

K35284961: Filtering BIG-IP log messages

Additional Information
None
