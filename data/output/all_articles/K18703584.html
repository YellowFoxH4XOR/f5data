K18703584: Edge Client diagnostics report not providing full logging

Type
Support Solution
Published
2021-09-27
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K18703584

Description
Newer Edge Clients have the ability to pull a diagnostics report via the Edge Client without the use of the CTU (Client Troubleshooting Utility).  After a recent security fix this results in some logs not being collected in the Diagnostics Report.

Environment

  • BIG-IP APM
  • BIG-IP Edge Client

Cause
ID999317 was fixed to prevent a potential security issue in some instances.

Recommended Actions
To pull the full logging from the Edge Client device

  1. Start the Edge Client with administrator rights
    From the Windows start menu search for BIG-IP Edge Client
    From the listed results right click the BIG-IP Edge Client and click "Run as Administrator"
  2. Run the Diagnostics Report
  3. Completely close the BIG-IP Edge Client
  4. Start the BIG-IP Edge Client with standard (User) rights

Additional Information
K03544414: Running a CTU Diagnostics Report may leave elevated command prompt after report generation

Alternatively, you can collect the logs without running the Diagnostics Report
