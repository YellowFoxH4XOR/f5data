Known Issue

This is the result of a known issue. If a virtual server has the clientssl profile configured to require a client certificate, and the server receives a certificate message without the client certificate, TMM can crash.

F5 Product Development tracked this issue as CR76993 and it was fixed in BIG-IP LTM 9.1.3, 9.3, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
