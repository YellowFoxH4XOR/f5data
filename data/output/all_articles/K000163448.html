K000163448: Edge Client may popup “F5 Networks Component Installer” UAC Prompt After Upgrade to BIG-IP 17.5.1.8

Description

Windows clients running BIG-IP Edge Client 7262 or earlier may display the “F5 Networks Component Installer” UAC prompt when an EPSEC package version 1988 or later is installed on BIG-IP APM. The Edge client will always download and install the EPSEC package when connecting the APM, and maybe popup the prompt below:

 

Environment

  • BIG-IP APM 17.5.1.8
  • OPSWAT EPSEC package version higher than 1.0.0-1988.0
  • APM Network Access VPN
  • Windows clients
  • BIG-IP Edge Client 7262 or earlier
  • Access policy using an EPSEC antivirus check or other agent

Cause

EPSEC version 1988 and later uses a Sectigo signing certificate instead of the Entrust certificate used by earlier EPSEC packages.

Edge Client 7262 and earlier do not include the Sectigo certificate in the Windows F5FirePassRoot certificate store. EPSEC signature validation therefore fails, and Edge Client will downloads and attempts to install the package when connecting. Windows may displays the UAC prompt, but not always.

Recommended Actions

Upgrade BIG-IP Edge Client on Windows to version 7270 or later. Edge Client 7270 and later include the Sectigo certificate in the F5FirePassRoot certificate store.

For Edge Client 7270 or higher version, perform a fresh installation.

For the details, please refer to the artilce K000161279: EPSEC Updates Fail in Windows Clients with Edge Client 7262 or Earlier.
