K000139476: Maximum number of always qualified URLS (asm.cs_qualified_urls)

Type
Support Solution
Published
2024-05-01
Updated
2024-05-01
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000139476

Description

The maximum number of URL'S that are always qualified for JavaScript injection in DB variable asm.cs_qualified_urls is '10'.

Note: Any entry beyond the 10th will be silently disregarded.

Environment

ASM

Cause

There's an existing Request for Enhancement (RFE) with ID 807577 to increase this limit. Currently, specific details regarding availability are not available. Please contact support for any updates on availability.

ID 807577 - RFE: Increase size limit of URLs to be always qualified in DB variable

Recommended Actions

Maintain the number of consistently qualified URLs below the threshold of 10.

Additional Information

The are two DB variables asm.cs_qualified_urls (Brute Force), dosl7.cs_qualified_urls (Bot Defense), that allow configuring URLs which are always qualified for JavaScript injection. These lists are limited to 10 items.

Note: Each URL entry item supports wildcards.
