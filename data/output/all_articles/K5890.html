Topic

Citrix terminated the partnership agreement with F5 Networks, which allowed F5 Networks to distribute the Citrix client software in FirePass. As of January 24, 2006, Citrix client software is no longer included in the FirePass product. Additionally, existing FirePass customers do not have the Citrix client included in FirePass when they upgrade to the most recent FirePass software release.

To address this limitation, F5 Networks has provided a simple mechanism for FirePass customers to upload the Citrix client software to the FirePass controller. For more information, refer to K5891: Downloading and installing the Citrix client.

Note: With this change, FirePass continues to offer clientless access to Citrix Terminal Services for end-users. End-users can download and pre-install the Citrix client software separately without any requirements.

Note: This change does not impact interoperability of FirePass with supporting Citrix Terminal Services. Customers can continue to be able to use all FirePass product functionality and gain secure access to Citrix Terminal Services.
