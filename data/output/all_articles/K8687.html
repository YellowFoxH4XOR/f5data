Known Issue

This is the result of a known issue. The BIG-IP ASM only allows the base OneConnect profile to be associated with a BIG-IP ASM-enabled virtual server. When you attempt to associate a child OneConnect profile with a virtual server referencing a BIG-IP ASM-enabled HTTP class, the BIG-IP Configuration utility displays the following error message:

01070699:3: Only the base oneconnect profile may be used on the same virtual server using a ASM-enabled httpclass profile.

F5 Networks Product Development tracked this issue as CR98843 and it was fixed in BIG-IP ASM version 9.4.5. For information about upgrading, refer to the BIG-IP ASM Release Notes.
