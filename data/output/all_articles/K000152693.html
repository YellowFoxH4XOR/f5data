Description

Microsoft SharePoint CVE-2025-53770 and CVE-2025-53771 vulnerabilities.

Environment

  • CVE-2025-53770 Microsoft SharePoint Deserialization of Untrusted Data Vulnerability
  • CVE-2025-53771 (No name assigned by NIST as of the date of this article).

Cause

This event is generated when an attempt is made to inject Server-side Include code. SSI Injection allows the attacker to send server side code that could be executed locally by the web server.

This is a general attack detection signature (i.e. it is not specific to any web application).

Recommended Actions

  • Ensure the system is using an up to date version of the software and has had all vendor supplied patches applied.
  • Install ASM-AttackSignatures_20250723_072628. It contains attack signature 200204026 SharePoint ToolShell Remote Code Execution
    • K82512024: Managing BIG-IP ASM Live Updates (14.1.x and later)
  • Utilize "Positive Security Model" by accepting only known types of input in web application.

IMPORTANT: you should always test any new OS/EHF/signature update prior to release into any prod environment.
