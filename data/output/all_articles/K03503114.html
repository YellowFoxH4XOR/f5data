Description

For some secure environments, the integration to the commercial endpoints in Microsoft Intune might not fulfill the security requirements that customers are looking for.
Microsoft has some additional endpoints,365 GCC High and DoD, which can fulfill these requirements

Environment

  • BIG-IP APM
  • APM Intune

Cause

Need the use of Microsoft secure endpoints 365 GCC High and DoD

Recommended Actions

Open a service request with the support team and ask for an engineering hotfix for ID1022925.
