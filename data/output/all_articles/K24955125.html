Description

After upgrading the BIG-IP system from 12.x to 14.x, the system may pop up the below error on the Configuration Utility:

This device is not operational because the loaded configuration contained errors or unlicensed objects. Please adjust the configuration and/or the license, and re-license the device.

You may observe the error logs similar as below in /var/log/ltm:

err mcpd[<PID>]: 01071bf3:3: AFM feature not licensed. Logged 12 times.

warning sod[<PID>]: 01140029:4: HA license_exceeded_t mcpd fails action is go offline and down links.

Environment

  • BIG-IP

  • Upgrading from 12.x or earlier to 14.x or newer

Cause

Security HTTP profiles are allowed in older versions (BIG-IP 12.x or earlier). However due to licensing model change, it requires AFM license in new versions (BIG-IP 14.x or newer).

Recommended Actions

You can remove the referenced entry from the bigip.conf file

Impact of procedure: none

  1. Log into the Command Line Utility (CLI)

  2. Make a copy of the bigip.conf file with the following command:

    cp /config/bigip.conf /config/bigip.conf.bak.1

  3. Open the bigip.conf with the vi editor

    vi /config/bigip.conf

  4. Comment out, or remove the offending entry. Here is an example entry:

    security http profile /Common/http_security_migrated_httpsecurity_profile {
    ...
    }

  5. Save the changes made in vi with:

    ESC :wq!

  6. Reload the configuration with the following command:

    tmsh load sys config
