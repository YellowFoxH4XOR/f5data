K000093129: BIG-IQ dashboards are not displaying the iRules traffic statistics data

Type
Support Solution
Published
2022-12-08
Updated
2022-12-08
Source
https://my.f5.com/manage/s/article/K000093129

Description

When trying to check the traffic statistics for iRules, it is discovered that the BIG-IQ dashboard is not displaying them, however, the data is there as it is shown in the BIG-IP GUI.

Environment

  • BIG-IQ 8.0.0, 8.0.0.1, 8.1.0, 8.1.0.1, 8.1.0.2

  • BIG-IQ dashboard

  • iRules statistics

Cause

The issue is caused by bug ID1064777.

Recommended Actions

The solution is to upgrade the BIG-IQ device to an 8.2.0 fixed version.
