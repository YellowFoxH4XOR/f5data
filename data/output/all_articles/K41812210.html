Description

Would like to import the same signed certificates from an CSR that generated from another BIG-IP

Environment

  • BIG-IP
  • Standalone
  • CSR
  • SSL Private key
  • Certificate
  • Import

Cause

None

Recommended Actions

In order to achieve this requirement, we will first need to import the CSR SSL private key from BIG-IP that the CSR generated and import it into the BIG-IP that would want to import the same signed certificates.
Example: CSR were generated in BIG-IP A, and would like to import into BIG-IP B

For steps to export SSL private key via BIG-IP GUI, please refer to KB article K14620 under Export an SSL certificate and private key > SSL Key.

Below are the CLI steps to export the SSL private key from BIG-IP.

  1. SSH into BIG-IP A
  2. Change folder to /config/filestore/files_d/Common_d/certificate_key_d/ with CLI command "# cd /config/filestore/files_d/Common_d/certificate_key_d/"
  3. List folder "# ls" and search for the CSR private key file
  4. View the CSR private key content "# more <:Common:CSR_private_key_filename_#>"
  5. Copy the content which starts with "-----BEGIN PRIVATE KEY-----" and end with "-----END PRIVATE KEY-----"
    Notes: You may save it as a text file for upload, or just copy the content, please follow steps in item 8a/8b.
     
  6. Access to the BIG-IP B GUI and go to System  ››  Certificate Management : Traffic Certificate Management : SSL Certificate List
  7. Click on "Import..." button >> Import type: Key >> Key Name: New: <CSRKeyname>
  8. Key Source:
    a. Upload File >> Choose the CSR private key file        
    Notes: the CSR private key file that you have save earlier in steps item 5.

    b. Paste Text >> paste the content of the CSR private key content
     
  9. Security Type: Normal (unless you have encrypted the CSR with a password, then you may choose "Password")
  10.  Then, click on "Import" button to import the CSR private key
  11.  Once done, you may finally import the signed certificate into this BIG-IP B
    Notes: May further refer to Additional Information on how to manage BIG-IP certificate and how recover lost/deleted private SSL key by using UCS backup file.
