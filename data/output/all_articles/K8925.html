Known Issue

This is the result of a known issue.  When viewing statistics by using a bookmarked link to the statistics page, an error message is logged in the pvac.log file that appears similar to the following example:

n108250b4500m2004 WA ERROR: Performance Monitor did not find match for 25015.5517.octet-stream.50-100K

The error messages are benign and not an indication of a failure, or an impact to system performance. However, the BIG-IP WebAccelerator performance graph for content type specified will be incorrect.

F5 Networks Product Development is tracking this issue as CR98865 and CR117732.
