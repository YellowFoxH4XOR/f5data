Known Issue

The BIG-IP system does not allow the Tag time-to-live (TTL) parameter to be configurable in the message-based load balancing (mblb) profile. This issue occurs when one of the following conditions is met:

  • You attempt to create or modify an mblb profile that has the Tag TTL parameter configuration using the tmsh utility
  • You attempt to manually add a Tag TTL parameter to an mblb profile configuration and load the configuration

The mblb profile is configurable using tmsh utility only. The Tag TTL parameter controls the TTL setting for a message tag.

Impact

You are unable to configure the Tag TTL parameter for an mblb profile.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you attempt to configure the Tag TTL parameter using the tmsh utility, the BIG-IP system fails to create or modify an mblb profile and reports an error message that appears similar to the following example:

    Syntax Error: "tag-ttl" unknown property

  • When you attempt to manually add a Tag TTL parameter to an mblb profile configuration and load the configuration, the BIG-IP system fails to load the configuration and reports an error message.

    For example:

    ltm profile mblb /Common/mymblb {
    defaults-from /Common/mblb
    ingress-high 50
    ingress-low 5
    isolate-abort enabled
    isolate-client disabled
    isolate-expire enabled
    isolate-server enabled
    min-conn 10
    tag-ttl 70
    }

    If you attempt to load a configuration that contains the previous mblb profile configuration snippet, the BIG-IP system fails to load configuration and reports the following error message:

    Syntax Error:(at line: 14) "tag-ttl" unknown property
