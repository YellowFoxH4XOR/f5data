Topic

The BIG-IP APM system is able to use the following HTTP authentication methods using an external authentication server to validate user credentials:

  • HTTP basic authentication

    This option should be configured to use a web server to authenticate users by prompting the users for their credentials and passing them on to the web server configured for AAA authentication.

  • HTTP form based authentication using URL matching

    This option should be used for the following conditions:

    • You want the BIG-IP APM system to use the origin webserver to authenticate each user's credentials using an HTTP form
    • You want the BIG-IP APM system to inspect the response from the origin webserver for a redirect code to a specific URL when authentication is successful
  • HTTP form authentication using string matching

    This option should be used for the following conditions:

    • You want the BIG-IP APM system to use the origin web server (OWS) to authenticate each user's credentials using an HTTP form
    • You want the BIG-IP APM system to inspect the response for the OWS for a specific string in a hidden parameter to determine if the authentication attempt was successful
  • HTTP form base authentication using cookie matching

    This option should be used for the following conditions:

    • You want the BIG-IP APM system to use the origin web server to authenticate each user's credentials using an HTML form
    • You want the BIG-IP APM system to inspect the cookie generated by the origin web server for a specific value
