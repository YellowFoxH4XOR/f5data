Known Issue

This is the result of a known issue. The pvac process will leak memory when proxying oversized HTTP requests, or requests that contain Expect: 100-Continue headers.

An oversized HTTP request includes a request whose body is greater than 64MB. Depending on the number of requests that exceed the 64 MB limit, or contain Expect: 100-Continue headers, the pvac memory leak may take some time before exhausting available memory resources.

Once the memory resources have exhausted, the pvac process will core. As a result, the pvac process will restart and traffic is interrupted.

F5 Networks Product Development tracked this issue as CR133982 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator or Edge Gateway Release Notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
