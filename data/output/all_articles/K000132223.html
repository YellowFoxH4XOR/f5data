K000132223: AFM local-db logging is not working on F5

Type
Support Solution
Published
2023-01-24
Updated
2023-02-15
Applies to
  • BIG-IP
  • BIG-IP AFM: 15.1.6
Source

Description

AFM local-db logging is not working. Nothing is appearing in the Security Event Log

Environment

  • BIG-IP AFM
  • Security Logging
  • local-db

Cause

In rare instances, a race condition between the fslogd and logmysqld processes may prevent the writing of log messages to the local-db

Recommended Actions

Note: Perform the recommended actions either on the standby device or in a maintenance window to avoid traffic disruption. 
  1. Delete /var/run/fslogd.pid and /var/run/logmysqld.pid

    rm /var/run/fslogd.pid

    rm /var/run/logmysqld.pid 

  2. Clear the mcpd database
    touch /service/mcpd/forceload
  3. Reboot the BIG-IP system.
    reboot

Additional Information

The fslogd process formats the logs into mysql format and then logmysqld imports those logs into the mysqld database.
