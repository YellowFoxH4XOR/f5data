Restarting NameSurfer from the command line

To restart NameSurfer from the command line, perform the following procedure.

Note: Before performing this procedure, verify that NameSurfer is not running. For instructions, refer to K1051: Verifying that the NameSurfer process is running.

  1. Log in to the command line.
  2. Change directories to the /usr/local/namesurfer/bin directory by typing the following command:

    cd /usr/local/namesurfer/bin/
  3. Start the NameSurfer daemon with the namesurferd script, by typing the following command:

    ./namesurferd

If you receive error messages, or if NameSurfer is still not running, restart the ns process by performing the following procedure.

Restarting the ns process

If NameSurfer did not successfully restart, you can restart the ns control process. To do so, perform the following procedure:

  1. Start NameSurfer using the root user, by typing the following command:

    ./ns -root

    For 3-DNS versions 4.5 and later, type the following command: 

    bigstart restart namesurfer
  2. Start the Configuration utility for NameSurfer by typing the following command

    /usr/bin/perl /usr/local/namesurfer/webui/webui-main.pl --user $NSUSER &
