Description

After maintenance activity with a Viprion, the WebUI shows with the following warning message:
You are currently logged in to a secondary slot

Environment

  • Multi-blade Viprion 
  • After maintenance activity 
  • Web UI

Cause

Primary slot may change after activity, such as rebooting Blade or Chassis.

Recommended Actions

  1. Confirm connected to the Cluster IP 
    (/S2-green-P:Active)(/Common)(tmos)# show sys cluster all-properties

-----------------------------------------
Sys::Cluster: default
-----------------------------------------
Address                 10.10.66.7/24           <<<
Availability            available
State                   enabled
Reason                  Cluster Enabled
Primary Slot ID         2                       <<<< Primary
Primary Selection Time  09/05/22 05:58:58
  2. Disable primary Slot:
    From Web UI:   
    System > Clusters > Properties
    Via TMOS:
    tmsh modify sys cluster default members {X { disabled}

    Note: By disabling the Primary slot, the system will set a new Primary slot - this should be checked again with:  tmsh show /sys cluster 

  3.  Repeat step #2 until the desired Slot become Primary.

  4. Enable other slots you were disabled previously:
    modify /sys cluster default members {X { enabled}}

Additional Information

None
