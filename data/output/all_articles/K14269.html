Known Issue

A BIG-IP system with an undefined RAID array may log a benign error message after an upgrade. Attempting to modify an undefined RAID array may result in error or an unexpected format of the hard drive.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is a RAID capable platform that was installed with an undefined RAID array.
  • You attempt to perform one or more of the following actions:
    • Upgrade the system running BIG-IP 10.0.0 through 10.2.2 to 10.2.2 HF2 or later.
    • Use a Traffic Management Shell (tmsh) command to attempt to modify an undefined RAID array MD1.

      For example, a tmsh command that adds a target hard drive HD2 to a working RAID array MD1 may appear similar to the following example:

      tmsh modify sys raid array MD1 add HD2

      Important: Do not use this command in a BIG-IP system that does not have a working RAID array.

Impact

After the upgrade and during system initialization, the BIG-IP system will display a benign error message on the console screen. BIG-IP system performance is not affected.

When using tmsh to attempt to modify the undefined RAID array MD1, note the following:

  • Prior to 11.3.0

    This issue is cosmetic. The error occurs because the BIG-IP system assumes a working RAID array is configured.

  • 11.3.0

    This issue may result in formatting of the hard disk, and the system may constantly reboot. In some circumstances, the system may halt at a boot loader prompt that appears similar to the following example:

    grub rescue>

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H384221 on the Diagnostics > Identified > Low page.
  • After the upgrade and during system initialization, the BIG-IP system console screen displays error messages that appear similar to the following examples:

    Setting up initial module provisioning:
    error: Disk_sn called without device
    error: Disk_sn called without device

  • When using tmsh to attempt to modify the undefined RAID array MD1, you encounter one of the following symptoms:
    • Prior to 11.3.0

      After entering the tmsh command, the system will prompt an error message and the system remains functional. The error message appears similar to the following example:

      error: Disk_sn called without device

    • 11.3.0

      The issue results in formatting of the hard disk, and the system constantly reboots. In some circumstances, the system halts at a boot loader prompt that appears similar to the following example:

      grub rescue>

Workaround

There is no workaround for this issue.

In the event that the hard drive is corrupted or formatted, you may restore the BIG-IP system by performing the following procedure that applies to your version:

  • K13117: Performing a clean installation of BIG-IP 11.x - 13.x or Enterprise Manager 3.x
  • K10819: Performing a clean installation of BIG-IP 10.x or Enterprise Manager 2.x
