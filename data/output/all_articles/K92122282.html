Description
tmsh / mcpd shows array status degraded, but Linux host shows the array is ok.

# tmsh show sys raid
-------------------------------------------------------------
Sys::Raid::Bay
Bay  Shelf  Name  Serial Number    Array Member  Array Status
-------------------------------------------------------------
1    1      HD2   WD-<   HD2  serial#  >  no            undefined
2    1      HD1   WD-<   HD1  serial#  > no            undefined

---------------------------------------------------------------------
Sys::Raid::Disk
Name  Serial Number    Array   Array Status  Model
                       Member
---------------------------------------------------------------------
HD1   WD-<   HD1  serial#  >  no      undefined     ATA     WDC WD1000CHTZ-0
HD2   WD-<   HD2  serial#  >  no      undefined     ATA     WDC WD1000CHTZ-0


# array
Bay  name    t/s/r count         state         Serial Number
---  ----    -------------       -----         -------------
1.1  HD2     15/15/0             ok            WD-<   HD2  serial#  > 
1.2  <empty>                                   <none>
2.1  HD1     15/15/0             ok            WD-<   HD1  serial#  > 
2.2  <empty>                                   <none>

(Legend: t = total, s = synchronized, r = replicating)


There are Deny logs in /var/log/auditd/audit.log at the same time as mcpsync logs in /var/log/kern.log

auditd/audit.log
avc:  denied  { getattr } for  pid=12345 comm="mcpsync" path="/var/lib/install/optn.json" dev="md7" ino=12345 scontext=system_u:system_r:mdadm_t:s0 tcontext=system_u:object_r:var_lib_t:s0 tclass=file

kern.log
notice kernel: mcpsync: invoke /bin/disk_publish_mcpsync ...

Environment

  • BIG-IP version 15.1.x
  • Recent upgrade, HDD replacement, or physical or logical rebuild of array

Cause
SELinux permissions error tracked as Bug ID 1039833

Recommended Actions
SELinux relabel and reboot

  # touch /.autorelabel
  # reboot

Additional Information
This command will return 0 if mdadm is running and synchronized as expected. If this output is not 0 then there is an issue with the array not matching the autorelabel solution.
# grep -e "_U" -e "U_" -e "__" /proc/mdstat | wc -l
0
