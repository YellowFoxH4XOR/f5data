Known Issue

This is the result of a known issue. When the BIG-IP system restarts the BIG-IP ASM bd process, the system may report a Tcl error message in the /var/log/ltm file. The error message appears similar to the following example:

tmm tmm[3415]: 01220001:3: TCL error: plugin_rules <HTTP_REQUEST> -      while executing "PLUGIN::disable ASM"

The error message is benign and you can safely ignore it.

When the BIG-IP ASM bd process restarts, all internal connections from bd to TMM are halted. If the system receives an HTTP request on a halted connection, the system's attempt to disable the BIG-IP ASM plugin connection to TMM fails and the system logs the error message.

After restarting the BIG-IP ASM bd process, the system re-establishes all internal connections to TMM to allow the BIG-IP ASM to process traffic.

F5 Product Development tracked this issue as ID 221917 (formerly CR100240). As a result of architectural changes, this issue does not affect BIG-IP 10.0.1 or later.
