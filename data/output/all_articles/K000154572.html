Description

NIC implements a VirtualServer template that sends header Connection: close to HTTP upstream servers by default

Environment

NGINX Ingress Controller (NIC)

VirtualServer/VirtualServerRoute (VS/VSR) resources

Recommended Actions

  • Implement the VirtualServer template within the NIC ConfigMap
  • Within the template, find the following line:
set $default_connection_header {{ if $l.HasKeepalive }}""{{ else }}close{{ end }};
  • Edit this line and replace close with "". For example:
set $default_connection_header {{ if $l.HasKeepalive }}""{{ else }}""{{ end }};
  • Implement a Connection request header in the VS/VSR configuration, for example, action.proxy.requestHeaders.set: {name: Connection, value: keep-alive}
- path: /example
  action:   
    proxy:
      upstream: test
      requestHeaders:
        pass: true
        set:
        - name: Connection
          value: "keep-alive"
