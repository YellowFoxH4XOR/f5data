K11884926: Integrating Grafana with Aspen Mesh Metrics Collector for monitoring mesh metrics

Description

Metrics Collector is a Prometheus instance and it collect metrics from all mesh cluster components. We can visualize metrics using Prometheus graphing interface, but the interface functionality is very limited. We may want to use monitoring solutions like Grafana to create dashboards and explore metrics in a clear and convenient way. In this article we will show how to install and integrate Grafana system with Aspen Mesh Metrics Collector running as a metrics data source.

To open Prometheus graphing interface, we can expose port 9090 using kubernetes external service or by opening kubectl port-forward. For example:

kubectl -n istio-system port-forward aspen-mesh-metrics-collector-<xxx> 9090:9090

Environment

  • Kubernetes
  • Aspen Mesh 
  • Grafana
  • Prometheus

Cause

Aspen Mesh Metrics Collector is an integrated part of Aspen Mesh package and is installed by default with other components of the cluster.

Recommended Actions

Grafana Labs provides kubernetes yaml manifests for the install. Helm charts are also available.

The complete set of configuration files and detailed installation instructions are available here.
Note: The link above takes you to a resource outside of MyF5, and the third party could remove the document without our knowledge. 

We start with installing Grafana on a newly created namespace istio-monitoring:

  1. Create the namespace by running:

    kubectl create namespace istio-monitoring

  2. Paste Grafana yaml manifests to grafana.yaml file. Manifests can be found here.
    Note: The link above takes you to a resource outside of MyF5, and the third party could remove the document without our knowledge. 
  3. Run the following command to deploy Grafana on the cluster:

    kubectl apply -f grafana.yaml -n istio-monitoring

  4. Check the POD is in a Running state by executing the following command:

    kubectl get pods -n istio-monitoring -l app=grafana

  5. Open a port forward to your local shell by running:

    kubectl port-forward service/grafana -n istio-monitoring 3000:3000

  6. Navigate to localhost:3000 in your browser. You should see a Grafana login page.
  7. Use admin for both the username and password to login.

Once logged in to Grafana graphic interface we can add Aspen Mesh Metrics Collector as our data source:

  1. Use your web browser to connect to http://localhost:3000/datasources and go to Configuartion > Data Sources.
  2. Select Add data. Source button.
  3. Select Prometheus from Time series databases section.
  4. Add http://aspen-mesh-metrics-collector.istio-system.svc.cluster.local:19090 as the URL in HTTP section.
    Note: If you cluster is using non-default domain name please replace cluster.local suffix with the correct value.
  5. Leave all other settings in a default values.
  6. Select Save & Test button.
  7. You should see a Data source is working message on a green background.

We are ready now to create a news Dashboard by a plus button in a Dashboards section or by opening http://localhost:3000/dashboard/new in the web browser. We should use a data source Prometheus as a source of our metrics.

As an example, we can use a query to create a graph showing istio_requests_total metric from every POD deployed inside bookinfo namespace:

rate(istio_requests_total{namespace="tdp2"}[1m])
