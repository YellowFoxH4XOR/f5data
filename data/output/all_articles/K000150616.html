K000150616: Can't change the discovery IP Address on BIG-IP devices

Type
Support Solution
Published
2025-03-31
Updated
2025-03-31
Applies to
  • BIG-IQ
  • F5 Distributed Cloud Services
  • BIG-IQ Centralized Management: 8.3.0
Source
https://my.f5.com/manage/s/article/K000150616

Description

When you tried change discovery address on BIG-IQ CM you may encounter problem when after the change, the IP Address reverts to original one. 

Environment

  • BIG-IQ

Cause

Some of devices are still visible for BIG-IQ which prevents change of discovery IP Address. It can be viewed by looking into /var/log/restjavad.0.log:

[ERROR][25 Mar 2025 10:57:49 UTC][/shared/identified-devices/config/discovery DiscoveryConfigWorker] Failed to change discovery address, reverting address to 1.1.1.1.
java.lang.IllegalArgumentException: Before changing the default self-ip, you must first delete/un-manage all devices that you have established communication with: 1.1.1.1, 1.1.1.2

Recommended Actions

To solve this problem, first you need to find the UID of the device. To achieve that please log in to CLI of IP Address mentioned in /var/log/restjavad.0.log then perform:


1. cat /config/f5-rest-device-id

The output should looks like that:

cat /config/f5-rest-device-id
82713cc-16b1-312e-fb19-cd1f318de327

2. Delete the reference from BIG-IQ by:
restcurl /shared/resolver/device-groups/ | jq .items[].selfLink | grep -oP '(?<=/mgmt/)[^"]*' | xargs -I {} restcurl -X DELETE {}/devices/[uid]


3. Restart the restjavad service:
tmsh restart sys service restjavad
