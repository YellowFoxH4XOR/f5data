K98655452: AS3 Declarations can fail after an upgrade of BIG-IP

Type
Support Solution
Published
2022-02-02
Updated
2023-02-21
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K98655452

Description

After upgrading BIG-IP AS3 declarations consistently fail resulting in lack of ability to continue controlling configuration using AS3

Environment

  • BIG-IP
  • AS3

Cause
Bug ID 929213: iAppLX packages not rolled forward after BIG-IP upgrade

Recommended Actions
To restore AS3:

  • Reinstall AS3 package (and any other iRulesLX packages in use) after upgrading
    Downloading and installing the AS3 package
To avoid this issue during future upgrades:
  • Upgrade to a fixed version (at time of writing listed in Bug Tracker as 16.1.2, 15.1.4.1, 14.1.4.4) AND update the DB variable to support a longer RPM build timeout:
tmsh modify sys db iapplxrpm.timeout value 300
tmsh save sys config

Additional Information
Download and Install Cloud Failover Extension
Downloading and installing Telemetry Streaming
