Topic

BIG-IP systems only use SSL certificates and keys that are stored in the Privacy Enhanced Mail (PEM) format with the .crt extension. PEM is the most common format for certificate authority (CA) certificates. PEM certificates are base64-encoded ASCII files that can contain multiple certificates and private keys within a single file. However, some web servers use SSL certificates in a Distinguished Encoding Rules (DER) format.

  • A DER-formated certificate is a binary file that typically has a .der or .cer file extension.
  • A DER-formatted key file is a binary file that typically has a.key file extension.

Description

When exporting an SSL certificate and key from a web server for use on a BIG-IP system, you may not be able to save the files in the required PEM format. In order to use files exported in the DER format, you need to convert the certificate and key files into PEM format for import into the BIG-IP system.

  • Converting a DER certificate file to a PEM certificate file
  • Importing the new PEM certificate and key files to the BIG-IP system

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP command line and Configuration utility.

Converting a DER certificate file to a PEM certificate file
Impact: Converting DER formatted certificate and keys should not negatively impact your BIG-IP system.

  1. Copy the DER file to the /var/tmp directory on the BIG-IP system.

    Note: For more information, refer to K175: Transferring files to or from an F5 system

  2. Log in to the command line of the BIG-IP system.
  3. Use the openssl utility to convert the DER certificate file to a PEM certificate file using the following command syntax:

    openssl x509 -inform der -in <certificate file name>.der -out <certificate file name>.crt

  4. Use the openssl utility to convert the DER key file into a PEM key file using the following command syntax:

    openssl rsa -inform DER -in <certificate file name>.key -out <certificate file name>_pem.key

    Note: In the example syntax, the PEM-formatted key file name includes the suffix pem.key to uniquely identify the file from the original DER-formatted key file.

  5. Copy the PEM-encoded certificate and key files from the BIG-IP system to your local computer.

    Note: For more information, refer to K175: Transferring files to or from an F5 system.

Importing the new PEM certificate and key files to the BIG-IP system

Impact: Converting DER formatted certificate and keys should not negatively impact your BIG-IP system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.

    Note: For BIG-IP 11.x through 12.x, navigate to System > File Management > SSL Certificate List.

  3. Click Import.
  4. For Import Type, click Certificate.
  5. For Certificate Name, type the certificate name.
  6. For Certificate Source, click Choose File.
  7. Locate the certificate file copied to your computer in the previous procedure and choose that file.
  8. Click Import.
  9. For Import Type, click Key.
  10. For Key Name, type the key name.

    Note: F5 recommends that you pair the private key with the certificate by using the same base name.

  11. Click Choose File.
  12. Locate the key file copied to the computer in the previous procedure and choose that file.
  13. Click Import.

    Note: The imported PEM-formatted certificate and key files are available for use in BIG-IP Client SSL profiles.
