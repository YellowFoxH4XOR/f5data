Issue

Error Message

notice chmand[<PID>]: 012a0005:5: <LIBHAL_hardware_event> 

In this error message, note the following:

  • <PID> is the process ID for the chmand process.
  • <LIBHAL_hardware_event> is a message describing a significant but normal hardware event.

For example:

notice chmand[3371]: 012a0005:5: Firmware check finished

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The BIG-IP system performs platform firmware version checks.
  • Platform hardware monitoring in the BIG-IP system detects a process starting or stopping.
  • Delays or timeouts are observed by platform hardware monitoring when attempting to take an action.
  • State changes or unexpected events are observed by platform hardware monitoring.

This message indicates that an event associated with the hardware platform monitoring has been observed and highlighted as important.  

Impact

The impact varies depending on the context in which the message is encountered.  In most cases, the message itself should indicate an unexpected event, state change, or important information.

Recommended Actions

When reviewing these messages, consider the following:

  • If the messages indicate a state change, review the log files to determine if the change is expected based on any changes made to the system at the time.
  • If the messages indicate an error, you can investigate the scope and impact of the problem by reviewing the log files for related messages of similar or higher severity logged at the same time.
