Description

You should use this article in the following conditions:

  • You wish to use a CAPTCHA component as part of your APM policy login process
  • You are attempting to add a CAPTCHA configuration to an existing policy, but you are unable to select a CAPTCHA configuration

Environment

  • APM
  • Visual Policy Editor

Cause

None

Recommended Actions

To add a CAPTCHA configuration, you must first create the CAPTCHA configuration object - and then you can add this to your policy

  1. Open the web interface for your Big IP
  2. Proceed to Access -> Authentication -> CAPTCHA configurations
  3. Select Create
  4. Complete the required information as such:
    1. Name - name your policy.  
    2. Secret, Site Key, Verification URL, Challenge URL, Noscript URL - these are provided by the CAPTCHA service you utilize. 
  5. Click Repeat to create another, or click Finished when done
Next, add the just-created CAPTCHA configuration to your policy:
  1. Proceed to Access -> Profiles / Policies and select the Edit link for the policy you wish to modify.
    1. If necessary, create a new policy.
  2. Either select your logon page object, or create a new object.
    1. Note: the only logon pages that support CAPTCHA are Logon Page and OAuth Logon Page, 
  3. At the top of the configuration guide for the logon page object, look for CAPTCHA Configuration - and on that one, select the desired CAPTCHA configuration.
  4. Configure other items as necessary, and save your work.
Do not forget to select Apply Access Policy after you have completed your changes.

Additional Information

The customization to set the Captcha configuration language to that of the Access Profile in reCaptcha v2.0 is not supported. F5 Product Development tracked this issue as ID 695014.
