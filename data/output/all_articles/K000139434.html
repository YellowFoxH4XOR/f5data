Known Issue

In BIG-IP APM network access, the F5 Access client proxy configuration does not work beginning in MAC OS 10.15.

This issue occurs when all of the following conditions are met:

  • You configure the client proxy setting in BIG-IP APM network access.
  • You use the F5 Access client (currently all supported versions) to establish BIG-IP APM network access, VPN.

To verify if you have client proxy settings enabled on your BIG-IP APM network access, on the BIG-IP Configuration utility, go to your network access object, select the Network Settings tab and verify if Client Proxy Settings is enabled. 
Note: On the Network Settings tab, for Client Settings, enable Advanced to display the Client Proxy Settings parameter.

Impact

The client proxy setting configured is not applied on F5 Access on the client side, and VPN traffic does not flow as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe network access VPN traffic does not flow to the proxy server as intended.
  • When you enter the scutil --proxy command on a MAC client, the output does not indicate that proxy settings are set. For example, when proxy settings are correctly set on the MAC OS client, you may observe an output similar to the following:

    % scutil --proxy
    [...]
      ProxyAutoConfigEnable: 1
      ProxyAutoConfigURLString : http://127.0.0.1:44444/proxy.pac?id=1234567890
    }
