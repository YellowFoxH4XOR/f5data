K000149980: Attack signature 200003534 due to cookie value: _clck=z24a0s|2|ftp|0|1436;

Type
Support Solution
Published
2025-02-26
Updated
2025-03-18
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000149980

Description

Incoming requests are being blocked due to attack signature 200003534 being triggered by the value of cookie _clck. The following part of the cookie value causes the violation.

 _clck=z24a0s|2|ftp|0|1436;

The signatures triggered may be one of the following:

  • ID 200003534 - Windows "ftp" execution attempt (Parameter)
  • ID 200003036 - Unix/Linux "ftp or ncftp" execution attempt (Parameter)

Environment

  • ASM attack signature violation

Cause

The cause of the violation may be that the Microsoft Clarity cookie matches the attack signature pattern.

Recommended Actions

Verify in the event logs that the violation is a false positive and caused by the Microsoft Clarity cookie. To work around this issue a cookie can be created in the security policy and the specific signature can be disabled.

Additional Information

The violation is expected as it matches the attack signature pattern. This is a Microsoft Clarity cookie used to persist the Clarity User ID and preferences, unique to that site is attributed to the same user ID.
