Description
Account root is not accepted by Velos CLI.

Environment

  • F5OS-C
  • Velos
  • Root account

Cause

Password is wrong.
 

Recommended Actions

To reset root account password, log in to Controller as admin, and reset root password on GUI:
User Management >> Users >> select root
