Known Issue

This is the result of a known issue. The BIG-IP Link Controller does not include FTP data channel traffic when determining link statistics. As a result, when the Link Controller configuration contains FTP virtual servers, the link statistics are reported incorrectly.

In addition, TMM attributes traffic (packet and byte) statistics to FTP virtual servers in the wrong direction when an FTP client is in active transfer mode. For example, the system counts inbound traffic for the link as outbound traffic, and outbound traffic for the link as inbound. This can cause further inaccuracies with link statistics.

F5 Product Development is tracking this issue as ID 226028 (formerly CR140656).

This issue has been fixed in Hotfix-BIGIP-9.4.8-407.0-HF4 which has been issued for BIG-IP version 9.4.8, Hotfix-BIGIP-10.2.1-473.0-HF1 which has been issued for BIG-IP version 10.2.1, and BIGIP-10.1.0-3402.0-HF2 which has been issued for BIG-IP version 10.1.0.
