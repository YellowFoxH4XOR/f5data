Known Issue

The BIG-IP APM access policy client-side Endpoint Security (EPSEC) check may fail to detect Kaspersky Internet Security Anti-Virus.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is installed with an EPSEC package prior to 1.0.0-411.0.
  • You have configured an access policy with an EPSEC client-side agent anti-virus software check.
  • The user device is running Mac OS X and Kaspersky Internet Security Anti-Virus 15.0.1.378.
  • A user attempts to establish an access session using the BIG-IP Edge Client for Mac OS X.

Impact

The user may be unable to establish an access session, depending on the access policy configuration.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP APM endpoint security check does not detect the anti-virus software as acceptable.
