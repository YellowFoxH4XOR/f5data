Description

You have noticed that this does not work properly with the PAC file with ASCII format, but fails for UTF-8.

Environment

  • BIG-IP APM Network Access in Full or Split Tunnel mode
  • Client Proxy Settings enabled
  • PAC file in UTF-8 format

Cause

The byte order mark (BOM) at the beginning of the PAC file (3 bytes EF BB BF known as UTF-8 BOM).

Recommended Actions

The easiest option would be use Notepad++.
It will help to save text without a BOM using Encoding → UTF-8 (without BOM).

Additional Information

A byte order mark (BOM) consists of the character code U+FEFF at the beginning of a data stream, where it can be used as a signature defining the byte order and encoding form, primarily of unmarked plaintext files. Under some higher level protocols, use of a BOM may be mandatory (or prohibited) in the Unicode data stream defined in that protocol.
