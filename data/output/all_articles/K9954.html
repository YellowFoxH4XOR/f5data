Issue

In FirePass versions prior to 6.0.3, you could only configure one domain suffix for a Network Access connection. Starting in FirePass 6.0.3 with cumulative hotfix HF-603-2.1, you can now configure six suffixes for a Network Access connection. 

Note: Domain suffixes are configured on the Network Access: Resources page under the DNS tab.
 
F5 Product Development is tracking this enhancement as CR64655.
