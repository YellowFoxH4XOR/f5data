Known Issue

This is the result of a known issue. When the BIG-IP WebAccelerator system is processing compressed content while the memory usage and load are high, the pvac process runs out of memory buffer. As a result, the pvac process may core.

F5 Product Development tracked this issue as ID 335616 (formerly CR132404), and it was fixed in BIG-IP WebAccelerator 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
