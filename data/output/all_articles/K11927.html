Issue

When performing an LDAP query, you may see a log entry that appears similar to the following example in the /var/log/apm file:

LDAP Agent: getLdapUserInput(): invalid user password ciphertext

This error message occurs when an LDAP query is executed with an empty password field. The query will complete successfully, and the error message can safely be ignored.

Note: LDAP query and LDAP Authentication are independent; LDAP query does not require an LDAP Authentication before being executed.
