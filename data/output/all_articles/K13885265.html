Description

N/A

Recommended Actions

system-auth will not show up in tab complete, it creates system-auth from this command and then it will show up in tab complete afterwards:
create /auth radius system-auth servers add { test }

root@(bigiq1)(cfg-sync Standalone)(Active)(/Common)(tmos)# create /auth radius <TAB>
