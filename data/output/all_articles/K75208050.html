Description

A local user(not admin) with the administrator role cannot login into BIG-IP, and matches the following conditions. 

  • The remote authentication is available.
  • The value of the db systemauth.primaryadminuser is 'admin'.

Environment

  • BIG-IP

Cause

It is an expected behavior. 

Recommended Actions

If this local user needs to login into BIG-IP, need to modify db systemauth.primaryadminuser to this local user.
The actions or steps required are as below

  1. tmsh modify sys db systemauth.primaryadminuser value <local_user>
  2. tmsh save sys config 

Additional Information

None.
