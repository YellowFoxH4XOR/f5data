K000147029: Why do I get the error "AutoCertDisabled" on my HTTP Load Balancer?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-19
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147029

Description

  • You created a DNS zone and enabled the options Allow HTTP Load Balancer Managed Records and DNSSEC on it.
  • After creating a HTTP Load Balancer and adding your records, you get the error "AutoCertDisabled"

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Answer/Recommended Actions

This is because of a DNSSEC issue.

To fix the issue you have to

1. Correct the DS record of your zone

2. Go to the HTTP Load Balancer

3. Remove a record

4. Click Save

5. Wait 5 minutes

6. Add the record again

This will trigger the AutoCert process again and fix the issue.
