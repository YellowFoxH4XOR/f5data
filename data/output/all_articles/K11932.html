Known Issue

If static ARP entries are configured in the BIG-IP management network, the BIG-IP configuration may fail to load.

This issue occurs when all of the following conditions are met:

  • You attempt to perform one of the following tasks which attempts to reload the BIG-IP configuration:
    • ConfigSync
    • Manual load of a BIG-IP configuration from the command line
  • Static ARP entries are configured on the BIG-IP management network

Impact

You will be unable to load BIG-IP configurations.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H638394-17 on the Diagnostics > Identified > Low screen.
  • BIG-IP configurations fail to load.
  • An error message is logged to the /var/log/ltm file. The message appears similar to the following example:

    01070712:3: Caught configuration exception (0), Netlink reply from kernel has error: -101 - routing.cpp, line 883

Workaround

To work around this issue, you can remove any static ARP entries configured for the management network before attempting to perform an operation which requires a configuration load. To do so, perform the following procedures:

Impact of workaround: The functionality for which the static ARP entries were originally configured may no longer operate.

BIG-IP 11.x tmsh command

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. Display the list of static ARP entries configured on the BIG-IP system by typing the following command:

    show net arp all
  3. Identify the offending static ARP entry.
  4. Remove the offending entry by typing the following command, where <Name> is the name of the address being deleted:

    delete net arp <Name>

    For example:

    delete net arp /Common/192.168.1.1
  5. Save the change by typing the following command:

    save /sys config

BIG-IP 10.x bigpipe command

  1. Log in to the BIG-IP command line as the root user.
  2. Display the list of static ARP entries configured on the BIG-IP system by typing the following command:

    bigpipe arp static list
  3. Identify the offending static ARP entry.
  4. Remove the offending entry by typing the following command:

    bigpipe arp <IP address> delete
  5. Save the change by typing the following command:

    bigpipe save
