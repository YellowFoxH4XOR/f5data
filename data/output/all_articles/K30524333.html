Known Issue

TCP Round Trip Time (RTT) may reduce the throughput of Bandwidth Control (BWC) policy-enabled virtual servers.

This issue occurs when all of the following conditions are met:

  • You have applied a BWC policy to any of the following virtual server types:
    • FastL4
    • Forwarding IP
    • Forwarding Layer 2
  • Traffic flow RTT increases for the affected virtual server.

Impact

The virtual server processes lower throughput than expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When analyzing the network-level RTT of the TCP flow, you notice the RTT value is increasing.
  • TCP flows with increasing RTT values experience lower throughput than expected.

Workaround

To work around this issue, you can change the virtual server type to Standard. To do so, perform the following procedure:

Important: The Standard virtual server type may not be appropriate for some Forwarding IP and Forwarding Layer 2 configurations.

Impact of workaround: F5 recommends performing the following procedure during a scheduled maintenance window. 

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  3. Select the affected virtual server.
  4. From the Type menu, select Standard.
  5. Click Update.
