Description

A newly deployed Virtual Server (VS) is communicating with the pool via the management IP instead of the self-IP.

SNAT automap is used for this Virtual Server.

For an example of this scenario, the pool member IP is 10.10.8.1/24 and the floating and non-floating self-IP address of the BIG-IP is 10.10.3.1/24 and 10.10.3.2/24 respectively. Instead of using these self-IP to communicate with the pool, the BIG-IP will instead use it's management IP 10.10.1.1/24.

Environment
  • BIG-IP
  • Virtual Server (VIP) is communicating with the pool via it's management IP instead of the self-IP
  • All self-IP addresses are not in the same subnet as the pool IP

Cause

The BIG-IP tmm does not have a route towards the pool's subnet. Because of this, it will use the management IP to communicate with the pool.

Recommended Actions

To resolve the issue, you will need to create a floating and non-floating self-IP address on both Active and Standby BIG-IP devices which are in the same IP subnet of the pool. For example, if the pool IP is 10.10.8.1/24, configure the floating and non-floating self-IP within 10.10.8.0/24 subnet.

  1. Login to the BIG-IP Configuration Terminal.
  2. On the Main tab, click Network > Self IPs.
  3. Click Create. The New Self IP screen opens.
  4. In the Name field, type a unique name for the self IP address.
  5. In the IP Address field, type an IPv4 or IPv6 address. This IP address should represent the address space of the VLAN that you specify with the VLAN/Tunnel setting.
  6. In the Netmask field, type the full network mask for the specified IP address.
  7. From the VLAN/Tunnel list, select the VLAN to associate with this self IP address.
    • On the internal network, select the internal or high availability VLAN that is associated with an internal interface or trunk.
    • On the external network, select the external VLAN that is associated with an external interface or trunk.
  8. From the Port Lockdown list, select Allow Default.
  9. From the Traffic Group list, retain the default value or select a traffic group. This option will determine the IP is a floating or non-floating self-IP.
  10. Click Finished. The screen refreshes, and displays the new self IP address.
  11. Perform the task for all the floating and non-floating self-IP for both Active and Standby BIG-IP devices.
After you perform this task, the BIG-IP system can send and receive traffic through the specified VLAN or VLAN group to the pool.
