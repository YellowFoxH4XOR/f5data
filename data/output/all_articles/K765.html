Known Issue

This is the result of a known issue. The 3dnsmaint utility treats combination systems as separate 3-DNS and BIG-IP units. When you select the Generate and Copy iQuery Encryption Key option from the 3dnsmaint utility, the 3dnsmaint utility will report a remote combination system with the IP address 10.90.100.1, as follows:

BIG-IP 10.90.100.1
3-DNS 10.90.100.1

If you run the 3dnsmaint utility from a combination system, the 3dnsmaint utility will only report the address of that system once, for example:

3-DNS 10.90.100.2

This problem is mostly cosmetic. The new iQuery key is sent to the remote system twice, but this does not cause any issues.

F5 Networks Product Development tracked this issue as CR14294 and CR41884.
