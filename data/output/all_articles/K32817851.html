Description

When trying to delete a VLAN from the Configuration Utility, the next error message appears

01070635:3: The VLAN (<VLAN_name>) is referenced by one or more scrubber-rt-domain.

A similar log to the next one appears on /var/log/ltm:

 err mcpd[<pid>]: 01070635:3: The VLAN (<VLAN_name>) is referenced by one or more scrubber-rt-domain.

Environment

  • BIG-IP AFM
  • Security scrubber profile

Cause

The VLAN can not be deleted since it is referenced in the security scrubber profile.
 

Recommended Actions

Remove the VLAN from the security scrubber profile

  1. Go to Security ›› Options : Network Firewall : External Redirection : Scrubbing Profile.
  2. Select the 'Route Domain' tab
  3. Select the route domain which contains the VLAN referenced in the error message.
  4. Move the VLAN from 'Excluded' to 'Included'.
  5. Click 'Done Editing'  and 'Commit Changes to System'.
  6. Verify that the VLAN is no longer referenced with the next command on CLI:

tmsh list security scrubber profile
