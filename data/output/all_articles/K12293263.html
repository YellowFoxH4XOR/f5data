K12293263: Enter names of user with defined role in F5 when creating new users

Type
Support Solution
Published
2022-06-08
Updated
2026-07-14
Status
Legacy Content
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 16.1.2
  • BIG-IP 5000 Series
  • BIG-IP 5250v
Source
https://my.f5.com/manage/s/article/K12293263

Description

  • When creating new users there are no field to fill in Name and Role to indicate the user itself.
  • This may cause hard to identify the actual user and their role for the username itself form web GUI or Configuration Utilities.

Environment

  • BIG-IP LTM
  • Remote Users
  • TACACS 

Cause

This is a normal for BIG-IP LTM 

Recommended Actions

Consider to create a users with the username easy to identified with role as example below:

jack-admin to identify Jack is an administrator
jane-guest to identify Jane is a Guest

Additional Information

None.
