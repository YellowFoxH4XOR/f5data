Known Issue

Using the Configuration utility to add a peer device to the local trust domain may fail with an 'Unparseable date' error.

This issue occurs when all of the following conditions are met:

  • When you navigate to System > Platform in the Configuration utility, the Time Zone setting is configured for a location within AEST, AEDT, ACDT, ACWST, ACWDT, AWST, or AWDT.
  • You use the Configuration utility to add a peer device to the local trust domain.

Impact

Users cannot add peer devices to a local trust domain with the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If the BIG-IP system uses an AEST, AEDT, ACDT, ACWST, ACWDT, AWST, or AWDT time zone configuration, users cannot add a peer device to the local trust domain from the Configuration utility.
  • When you attempt to add a peer device to the local trust domain from the Configuration utility, the BIG-IP system displays an error message similar to the following example:

    java.text.ParseException: Unparseable date: "Sun Sep 21 22:52:44 AWST 2025"

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to add a peer device. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh on one of the BIG-IP devices by typing the following command:

    tmsh

  2. To add the peer devices to the local trust domain, use the following command syntax:

    modify /cm trust-domain /Common/Root ca-devices add { <mgmt_ip_address> } name <device name> username <admin_username> password <admin_password>

    For example, the following command adds a remote device named BIGIP.remote.net (with the management IP address of 192.168.10.100, and the administrator username and password of admin/admin) to the local system's trust domain:

    modify /cm trust-domain /Common/Root ca-devices add { 192.168.10.100 } name BIGIP.remote.net username admin password admin

  3. To verify that each device has the newly added device in the local trust domain, type the following command:

    list /cm device-group device_trust_group

  4. Save the configuration by typing the following command:

    save /sys config

  5. Repeat steps 2 through 4 for each BIG-IP system that you want to add to the local trust domain.
