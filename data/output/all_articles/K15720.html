Topic

This article applies to BIG-IP 11.x and later. For information about other versions, refer to the following article:

  • K12454: Certain tasks related to the management of SSL certificates do not support encrypted private keys (9.x - 10.x)

Summary

The following tasks, related to the management of SSL certificates, do not support encrypted private keys (private keys protected with a passphrase):

  • SSL certificate renewal using the Configuration utility (11.x - 14.0.x)
  • Key conversion to FIPS using the Configuration utility
Note: Beginning in BIG-IP 14.1.0, the Configuration utility includes a Password field when renewing an SSL certificate with an encrypted private key.

      Description

      When the private key is encrypted, the following tasks will fail and the Configuration utility will report error messages, depending on the BIG-IP version you are running:

      • SSL certificate renewal using the Configuration utility
         
        • BIG-IP 12.0.0 - 14.0.x

          OpenSSL error: Exception caught in Management::urn:iControl:Management/KeyCertificate::certificate_generate() Exception: Common::OperationFailed primary_error_code : -7 (0xFFFFFFF9) secondary_error_code : 0 error_string : error:0906406D:PEM routines:PEM_def_callback:problems getting password

        • BIG-IP 11.4.0 - 11.6.1

          OpenSSL error: error:0906406D:PEM routines:PEM_def_callback:problems getting password

        • BIG-IP 11.0.0 - 11.3.0

          An error has occurred while trying to process your request.

      • Key conversion to FIPS using the Configuration utility
         
        • BIG-IP 12.0.0 and later

          Key management library returned bad status: -99, 01070712:3: Cannot install password-protected key as FIPS key unless the password is provided.

        • BIG-IP 11.0.0 - 11.6.1

          Unsupported key size

      When you want to perform a renewal for an SSL certificate with encrypted private key, you must use the openssl utility in the command line interface. The openssl utility will prompt you for the passphrase of the encrypted private key in order to generate the certificate signing request as well as self signing the certificate.

      When you want to perform a conversion of an encrypted private key to FIPS, you must first use the openssl utility in the command interface to decrypt it and import the decrypted private key before converting it to FIPS in the Configuration utility.

      Recommendations

      • Renewing an SSL certificate with encrypted private key
      • Converting an encrypted private key to FIPS

      Renewing an SSL certificate with encrypted private key

      To renew an SSL certificate with encrypted private key, perform the following procedure:

      Note: Beginning in BIG-IP 14.1.0, the Configuration utility includes a Password field when renewing an SSL certificate with an encrypted private key.

      Impact of procedure: Performing the following procedure should not have a negative impact on your system.

      1. Log in to the BIG-IP system command line.
      2. Create a backup of the configuration by entering the following command:

        tmsh save sys ucs /var/tmp/SOL15720.ucs

      3. Generate a certificate signing request (CSR) file using the following command syntax:

        Note: The command will prompt you to enter the passphrase of the encrypted private key. If you do not know the passphrase to the encrypted private key, you must create a new private key.

        openssl x509 -x509toreq -in <path/to/existing ssl cert file> -signkey <path/to/encrypted private key file> -out <path/to/ssl csr file to be generated>

        For example:

        openssl x509 -x509toreq -in /config/filestore/files_d/Common_d/certificate_d/\:Common\:mysslcert.crt_27388_1 -signkey /config/filestore/files_d/Common_d/certificate_key_d/\:Common\:mysslcert.key_27384_1 -out /config/ssl/ssl.csr/mysslcert.csr

      4. If the certificate is a self-signed certificate, generate the new certificate file using the following command syntax:

        Note: The command will prompt you to enter the passphrase of the encrypted private key.

        openssl x509 -req -in <path/to/generated ssl csr file> -signkey <path/to/encrypted private key file> -days <days of validity> -out <path/to/ssl cert file to be generated>

        For example:

        openssl x509 -req -in /config/ssl/ssl.csr/mysslcert.csr -signkey /config/filestore/files_d/Common_d/certificate_key_d/\:Common\:mysslcert.key_27384_1 -days 10 -out /config/ssl/ssl.crt/mysslcert.crt

      5. If the certificate is not a self-signed certificate, submit the CSR file you generated in the previous step to your certifying authority (CA) to obtain the new certificate file.
      6. Install the renewed certificate using the following command syntax:

        tmsh install /sys crypto cert <certificate name> from-local-file <path/to/renewed ssl cert file>

        For example:

        tmsh install /sys crypto cert myrenewedsslcert.crt from-local-file /config/ssl/ssl.crt/mysslcert.crt

      7. Save the configuration by entering the following command:

        tmsh save /sys config

      Converting an encrypted private key to FIPS

      To convert an encrypted private key to FIPS, perform the following procedure:

      Impact of procedure: Performing the following procedure should not have a negative impact on your system.

      1. Log in to the BIG-IP system command line.
      2. Create a backup of the configuration by entering the following command:

        tmsh save sys ucs /var/tmp/SOL15720.ucs

      3. Create a decrypted version of the private key using the following command syntax:

        Note: The command will prompt you to enter the passphrase. If you do not know the passphrase to the encrypted private key, you must create a new private key.

        openssl rsa -in <path/to/encrypted private key file> -out <path/to/decrypted private key file>

        For example:

        openssl rsa -in /config/filestore/files_d/Common_d/certificate_key_d/\:Common\:mysslcert.key_27384_1 -out /config/ssl/ssl.key/mydecryptedsslcert.key

      4. Install the decrypted SSL private key into the BIG-IP filestore using the following command syntax:

        tmsh install /sys crypto key <key name> from-local-file <path/to/decrypted private key file>

        For example:

        tmsh install /sys crypto key mydecryptedsslcert.key from-local-file /config/ssl/ssl.key/mydecryptedsslcert.key

      5. Log in to the BIG-IP Configuration utility.
      6. Navigate to System > File Management > SSL Certificate List.
      7. Click the SSL key you need to convert to FIPS.
      8. Click the Key tab.
      9. Click Convert to FIPS to convert the decrypted private key to FIPS.
