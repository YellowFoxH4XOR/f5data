Description

AS3 declaration cannot be pushed out due to the following error messages:

[ERROR] invalid character '"' after object key:value pair
[ERROR] [AS3] Error validating AS3 template
[ERROR] [AS3] Error in processing the ConfigMap: kube-system/as3-nginx-ic-passthrough

Environment

  • BIG-IP Controller
  • Kubernetes
  • An AS3 deploy declaration to the BIG-IP system
  • VS deployed with associated iRule

Cause

  • An invalid iRules declaration.
  • iRule is integrated within the BIG-IP.
Example of invalid declaration:

        "serviceMain-Redirect": {
                     "class": "Service_HTTP",
                     "virtualAddresses": [
                         "10.10.10.10"
                     ],
                    "iRules": [
                        "/Common/_sys_https_redirect"   <----- invalid iRule declaration
                     ],
                     "virtualPort": 80,
                     "pool": "Nginx_IC_pool_passthrough"


Recommended Actions

Since an iRule is integrated with the BIG-IP, you need to specify it according to the specific pattern ({"bigip": "irule_reference"}) . The following is how the correct declaration looks like:

 "serviceMain-Redirect": {
                     "class": "Service_HTTP",
                     "virtualAddresses": [
                         "10.10.10.10"
                     ],
                    "iRules": [
                       {"bigip": "/Common/_sys_https_redirect"}   <----- valid iRule declaration
                     ],
                     "virtualPort": 80,
                     "pool": "Nginx_IC_pool_passthrough"
