Description

You would like to find and view SSL (traffic) certificate data/details from the command line of your BIG-IP system.
Note: You can view system certificate information by modifying the commands in Recommended Actions, however the listed commands will search for only "traffic" (used for virtual servers) related certificates.

Environment

  • BIG-IP
  • SSL certificates

Cause
None

Recommended Actions

  1. Log on to the command line of the BIG-IP system with administrative privileges.
  2. To view all SSL certificate details use the following command: 
    find /config/filestore/files_d/*_d/certificate_d -name "*_*"    | egrep -v 'bundle|default|irule' | xargs -i  openssl  x509 -in {} -text  -noout -inform pem 2>&-

  3. To limit the certificate details to only the Issuer and Validity details use the following command: 

    find /config/filestore/files_d/*_d/certificate_d -name "*_*"    | egrep -v 'bundle|default|irule' | xargs -i  openssl  x509 -in {} -text  -noout -inform pem 2>&- | awk '/Issuer:/,/Not After :/ {print $0}'
