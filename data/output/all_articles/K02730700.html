Description

Under CPU or memory pressure conditions, the guestagentd daemon may log the following messages to /var/log/ltm:
Sep 10 06:47:31 slot1/F5device01 info guestagentd[4858]: 01810007:6: Exit flags for PID 30469: 0x500

Environment

  • vCMP Guest

Cause

Bug ID 620374

Recommended Actions

  1. Investigate the memory and CPU conditions of the VCMP host and other guests on the system

  2. Set debug logging for guesta.gentd to get more information:
    tmsh modify sys db log.guestagentd.level value verbose

  3. Once enough logging is capture reset log level
    tmsh modify sys db log.guestagentd.level value Informational

Additional Information

On a VCMP system, guestagentd and hostagentd daemons communicate via an IP tunnel established over a shared memory interface. Please see K71132442: Viewing vCMP guest health and performance information using tmsh for further background.

The information exchanged involves the use of rsync to push information to the VCMP host.

This message with exit status code of 0x500 is reported by rsync (invoked by guestagentd) when it is unable to setup the client-server protocol.
