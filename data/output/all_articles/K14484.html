Known Issue

The TMM process may crash and dump core. This issue occurs when all of the following conditions are met:

  • A virtual server is associated with a DNS profile.
  • The DNS profile is configured with the Use BIND Server on BIG-IP setting set to disabled and a DNS Cache type of either Resolver or Validating Resolver.

Impact

The BIG-IP system may temporarily fail to process traffic, and may fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H422724 on the Diagnostics > Identified > High screen.
  • The TMM process crashes with a SIGFPE.
  • The BIG-IP system generates a TMM core file in the /var/core directory.
  • The BIG-IP system fails over to the peer system in a high-availability configuration.
  • The BIG-IP system logs an error message to the /var/log/tmm file that appears similar to the following example:

    panic: ../modules/hudproxy/ub/ub_proxy.c:329: Assertion "ub_proxy ref valid" failed
