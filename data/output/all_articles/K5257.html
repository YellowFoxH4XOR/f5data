K5257: Changes are not synchronized when a prober statement is reset to its default setting

Known Issue

This is most likely the result of a known issue. By default, 3-DNS uses a prober address of 127.0.0.1, which causes 3-DNS to probe using the appropriate self IP address, according to the routing table.

If you change the prober address to an address other than 127.0.0.1, and then later attempt to set the prober back to the default address, 3-DNS will accept the change on the unit you are configuring, but will not synchronize the changes to other 3-DNS units in the synchronization group.

Workaround

To work around this issue, change the prober address on each 3-DNS unit in the synchronization group.

F5 Networks Product Development tracked this issue as CR43497 and CR43498.
