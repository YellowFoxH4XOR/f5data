Description

When starting ISO upload from the PC via the Import option in the GUI, a temp file is created under /tmp/upload.

 

[root@appliance-1 upload]# ls -lh

total 39M

-rw-------. 1 48 48 39M Mar 2 10:17 im3R6V3x-b8QNZd

 

[root@appliance-1 upload]# pwd

/tmp/upload

 

[root@appliance-1 upload]# ls -lh

total 40M

-rw-------. 1 48 48 40M Mar 2 10:17 im3R6V3x-b8QNZd

 

Once manually refreshing the upload page in the browser, the upload process stops, the file from /tmp/upload disappears, and the upload status in GUI gets changed to "Upload failed" with a yellow triangle on the right side. Hovering the mouse on the triangle shows a window with the message "Size mismatch".

 

Environment

  • ISO upload via GUI
  • F5OS

Cause

Bug ID 1128633

 

 Recommended Actions

Run the below workaround to remove stale entries.

Impact of workaround: Restarting the utils-agent service will briefly interrupt file transfer operations (import/export), but will not impact running tenants or data plane traffic.

[root@appliance-1 ~]# docker exec -it system_manager sh

sh-4.2# confd_cmd -dd -o -c 'delete "/file/upload/meta-data"'

delete "/file/upload/meta-data"

TRACE Connected (cdb) to ConfD

TRACE CDB_NEW_SESSION --> CONFD_OK

TRACE Established new CDB session to ConfD

TRACE CDB_DELETE /file/upload/meta-data --> CONFD_OK

sh-4.2# exit

exit

[root@appliance-1 ~]# docker restart utils-agent

utils-agent

[root@appliance-1 ~]#

 

Additional Information
