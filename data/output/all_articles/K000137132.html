K000137132: After upgrade, load sys config failure 01071bb2:3: The issuer certificate (/Common/issuer.crt) does not match the certificate (/Common/certificate)

Type
Support Solution
Published
2023-10-07
Updated
2023-10-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000137132

Description

The configuration containing the issuer certificate may fail to load.

 

01071bb2:3: The issuer certificate (/Common/issuer.crt) does not match the certificate (/Common/certificate).

Unexpected Error: Validating configuration process failed.

 

Environment

  • BIG-IP LTM
  • sys file ssl-cert object configured with issuer-cert
  • The issuer-cert is not the valid issuer for the ssl-cert
  • May occur after upgrade

Cause

When the config load failure is seen, it means that the issuer.crt is in fact not an issuer of the cert, and the system is unable to find the issuer certificate from the certificate itself or from the chain certificate

Recommended Actions

Check the bigip.conf file, remove the invalid issuer-cert or add proper issuer-cert for the ssl-cert certificate.

 

For example:

bigip.conf: certificate is referring to issuer-cert, that does not contain the proper chain of trust for the certificate
 

sys file ssl-cert /Common/certificate {
cache-path /config/filestore/files_d/Common_d/certificate_d/:Common:certificate_file
issuer-cert /Common/issuer.crt <== the chain doesn't form any relation with the cert certificate_file
revision 1
}

 

Workaround:

  • modify /config/bigip.conf, and replace the invalid chain with another cert file, for example, /Common/valid-issuer.crt, which is a valid issuer of the certificate.

For example:

sys file ssl-cert /Common/certificate {
cache-path /config/filestore/files_d/Common_d/certificate_d/:Common:certificate_file
issuer-cert /Common/valid-issuer.crt <== the valid issuer for the certificate_file, that contain the chain of trust
revision 1
}

 

  • or remove issuer-cert /Common/issuer.crt from the configuration of ssl-cert /Common/certificate

For example:
 

sys file ssl-cert /Common/certificate {
cache-path /config/filestore/files_d/Common_d/certificate_d/:Common:certificate_file
revision 1
}

 

  • reload the configuration with command:

tmsh load sys config
