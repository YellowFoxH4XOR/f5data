Known Issue

This is the result of a known issue. If you move a server object from one data center to another, the BIG-IP GTM system reports incorrect statistics for the data centers. For example, if you move a server object from data center DC1 to data center DC2, DC1 continues to record traffic statistics for the server object even though the server was moved to a different data center. In addition, DC2 does not record statistics for the server object until the gtmd process is restarted.

F5 Product Development tracked this issue as ID 338557 and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the GTM release notes.

Workaround

You can work around this issue by logging in to the command line and restarting the gtmd process by typing the following command:

bigstart restart gtmd
