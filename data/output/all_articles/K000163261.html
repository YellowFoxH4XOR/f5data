K000163261: How to create a new Namespace for a Tenant

Type
Support Solution
Published
2026-09-09
Updated
2026-09-09
Source

Description

  • You want to create a new Tenant Namespace

Environment

  • F5® Distributed Cloud
  • F5 Tenant Owners

Cause

None

Resolution/Answer

To create a new Tenant Namespace follow the next procedure:

1. Login to your F5 Tenant

2. Click on the Administration configuration section

3. Go to Personal Management > My Namespaces and click on Add Namespace

4. In the new Namespace set:

  • Namespace Name which should be the required name for this namespace.
  • Description - if you want to give a short statement about the purpose of the namespace.
  • Users - all user that should have access to your F5 Namespace objects.  
  • Explicit roles - the roles for each namespace user.

 

5. Click Add Namespace to  to save the new Namespace configuration
