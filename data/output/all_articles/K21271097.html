Known Issue

The icrd_child process may occasionally fail to terminate gracefully when you manually restart the restjavad service.

This issue occurs when the following condition is met:

  • You run the bigstart restart or bigstart restart restjavad command on the BIG-IP system.

Impact

The iControl REST API is temporarily unavailable for configuration queries or modifications.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system logs an error message in the /var/log/icrd file that appears similar to the following example:

    err icrd_child: <PID> iControl REST Child Daemon, SEVERE,The parent process is unavailable. Terminating child process with id <ID> and pid <PID>

  • The BIG-IP system logs a message in the /var/log/kern.log file that appears similar to the following example:

    info kernel: icrd_child[PID]: segfault at 9293b50 ip 0000000009293b50 sp 0000000064ce7cac error 15

  • The BIG-IP system generates a core file in the /var/core directory.

Resolution

Workaround

There is no workaround for this issue; however, to recover from the issue, you can restart the restjavad service again.

Impact of workaround: The iControl REST API for making queries or modifications is temporarily unavailable while the restjavad service restarts.
