K000148192: Can I limit file size for uploads via Service Policies?

Published

Description

You want to limit the file size of uploads but you do not know if there is a possibility to do it via Service Policies

Environment

  • F5® Distributed Cloud
  • Service Policy

Resolution/Answer

 You cannot limit file size for uploads via Service Policies.
