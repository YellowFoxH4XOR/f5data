Known Issue

Important: This issue affects only BIG-IP platforms equipped with an AHA compression card.

Important: This issue does not affect the BIG-IP 9.4.x and 10.x software branches.

This is the result of a known issue. In rare cases, the Traffic Management Microkernel (TMM) may crash and produce a core file when an HTTP virtual server is configured to use hardware compression.

F5 Product Development is tracking this issue as ID 334501 (formerly CR130933).
