Description

Creating a new boot location for the upgrade fails with the error: "failed (Disk full (volume group). See SOL#10636."

 

Environment

BIG-IP LTM VE

v16.x

VMware hypervisor

 

Cause

The system wanted 13,826,448 KB to install the boot location, but it only had 12,410,880 KB available.

Working VE:
 
   #show sys software
   --------------------------------------------------------
   Sys::Software Status
   Volume  Product  Version   Build  Active  Status
   --------------------------------------------------------
   HD1.16-1-5-2  BIG-IP 16.1.5.2   0.0.5      no  complete
   HD1.16-1-5  BIG-IP 16.1.5.1   0.0.7     yes  complete
 
   # vgdisplay -vA

  VG Name               vg-db-sda
  VG Size               41.79 GiB
  PE Size               4.00 MiB
  Total PE              10697
  Alloc PE / Size       9924 / 38.77 GiB       # <-- This BIG-IP was provisioned with a 38.7 GB virtual disk. After allocating two boot locations, 3 GB of space remains free.
  Free  PE / Size       773 / 3.02 GiB
 

Non-working VE:
 
   # show sys software
   --------------------------------------------------------
   Sys::Software Status
   Volume  Product  Version   Build  Active  Status
   --------------------------------------------------------
   HD1.16-1-5-2  BIG-IP 16.1.5.2   0.0.5      no  failed (Disk full (volume group). See SOL#10636)
   HD1.16-1-5  BIG-IP 16.1.5.1   0.0.7     yes  complete
 
 
   # vgdisplay -vA
   
 --- Volume group ---
  VG Name               vg-db-sda
  VG Size               46.79 GiB
  PE Size               4.00 MiB
  Total PE              11977
  Alloc PE / Size       8947 / 34.95 GiB       # <-- This BIG-IP was provisioned with a 34.95 GB virtual disk. After allocating one boot location, ~12 GB of space remains free. Not enough for another boot location.
  Free  PE / Size       3030 / 11.84 GiB
 
 

Comparing, we see:

 

****************

Working VE

****************

* Two boot locations

* 38.7 GB VMware disk

* 3 GB of unassigned space

 

****************

Non-working VE

****************

* One boot location

* 34.95 GB VMware disk

* 11.84 GB unused space

There is insufficient space to add a second boot location (requires 12.4 GB).

 

Recommended Actions

1) Shut down the Standby (non-working VE) BIG-IP.

2) In VMware settings, compare the disk size of the working BIG-IP to the Standby BIG-IP.

3) Increase the disk space on the non-working VE by extending the virtual disk by 4 GB (for this scenario).

Note: The amount of disk space you need to add may vary depending on your device.

4) Power the Standby device back on and complete the software installation.
