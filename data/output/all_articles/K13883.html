Known Issue

VIPRION platform status LEDs may not correctly indicate the redundancy state.

This issue occurs when one of the following conditions is met:

  • Two or more VIPRION devices are configured in a sync-failover device group (version 11.x)
  • Two VIPRION devices are configured as an active-standby high availability pair (version 10.x )

Impact

You cannot determine the redundancy state from the LED color.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Blades in a VIPRION chassis that are in the standby state will illuminate with a green status LED instead of amber.

Workaround

While no direct workaround exists for this issue, you can determine the redundancy state by logging in to either the Configuration utility or the command line.

  • In the Configuration utility, the redundancy state indicator is located at the upper-left side of every screen.
  • From the command line, the redundancy state displays in the command line prompt.
