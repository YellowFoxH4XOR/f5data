Known Issue

Microsoft operating system clients with the WebClient service enabled may experience delays connecting to an ARX virtual server. The delay occurs because the ARX system does not respond to the WebClient service's port 80 SYN request to the ARX virtual server.

This issue occurs when all of the following conditions are met:

  • The ARX system is running on a Virtual Machine (VE), or on an ARX 1500 or ARX 2500 platform
  • The WebClient service is enabled on the client that is connecting to an ARX virtual server

Note: The WebClient service is enabled by default on the Microsoft Windows XP operating system.

This issue does not affect other ARX platforms: ARX 500, 1000, 2000, 4000, and 6000. These platforms will immediately reject (RST) the WebClient service's port 80 SYN request.

Impact

Affected clients accessing the ARX virtual server will experience delays.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Delayed access to the ARX virtual server

Workaround

To work around this issue, you can disable the WebClient service on the client system. For information about disabling services, refer to client-specific documentation.

Impact of workaround: The WebClient service enables Windows-based programs to create, access, and modify Internet based files. If this service is stopped, these functions will not be available.
