Description

Failed to upgrade the BIG-IP, found the error message similar to the following

On GUI:
 
failed (Failed to install)

On CLI, found the error message in liveinstall.log:
 
*** Live install end at 2011/01/01 xx:xx:xx: failed (return code 2) ***

Environment

  • BIG-IP software upgrade
  • BIG-IP appliance.
  • Device is not connecting to the internet or unable to reach to NTP server

Cause

Date / Time is not configured on the device. The device time is flipped back to the initial state.

Recommended Actions

  1. Delete the failed boot location.
  2. Configure the local date time on the BIG-IP, referring to K3381.
  3. Try to install the new software again.

None.
