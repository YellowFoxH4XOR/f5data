Topic

This article applies to BIG-IP 11.x. For information about other versions, refer to the following article:

  • K4690: Enabling logging for the WMI performance monitor (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to troubleshoot WMI performance monitor by enabling WMI logging.

Description

When troubleshooting WMI performance monitor issues, it is often useful to view the raw data provided by the DLL. To view this data, you must enable WMI logging using the tmsh utility.

After you enable WMI logging, you can locate the log file named WMIHttpAgent.log in the /var/tmp directory. The system does not remove the WMI log file when you disable WMI logging, nor is the log file log rotated. Hence, at the end of the troubleshooting, you are required to manually manage the WMI log file.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have Traffic Management Shell (tmsh) access to the BIG-IP system.

Procedures

You can enable, disable, or verify the setting of the WMI logging by performing the appropriate, following procedures:

  • Enabling WMI logging
  • Disabling WMI logging
  • Verifying the setting of WMI logging

Enabling WMI logging

Impact of procedure: The WMI log file can grow quickly. When WMI logging is enabled, monitor the size of the log file. Disable WMI logging as soon as you are finished troubleshooting.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To enable WMI logging, type the following command:

    modify /sys db httpagents.wmi.log value true

  3. Save the change by typing the following command:

    save sys config

  4. To exit the tmsh utility, type the following command:

    quit

Disabling WMI logging

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To disable WMI logging, type the following command:

    modify /sys db httpagents.wmi.log value false

  3. Save the change by typing the following command:

    save sys config

  4. To exit the tmsh utility, type the following command:

    quit

Verifying the setting of WMI logging

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To verify the current setting of WMI logging, type the following command:

    list /sys db httpagents.wmi.log

  3. To exit the tmsh utility, type the following command:

    quit
