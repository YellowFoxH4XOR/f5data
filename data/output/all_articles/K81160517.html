Topic

You should consider using this procedure under the following condition:

  • You want to modify the default ConfigSync time threshold.

Description

BIG-IP device group members must be configured to use a Network Time Protocol (NTP) server to set the system time so that the time is synchronized across all devices in the group. In BIG-IP 13.0.0 and later, each device group member sends heartbeat packets containing the device's own time to the peer devices. Each device checks the remote device's time against its own system time, and if the time is not within the configuration synchronization (ConfigSync) time threshold default value of three seconds, the command prompt changes to indicate that the time is out of sync (Peer Time Out of Sync), and ConfigSync operations may fail. In some cases you may want to adjust the ConfigSync time setting to allow for a higher threshold, such as five seconds. In addition, before you consider changing the ConfigSync time threshold, you should check the time delta between device group members.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • The device group members must be configured to use an NTP server.
  • You must have access to the TMOS Shell (tmsh).

Procedures

To check the time delta between device group members or modify the ConfigSync time threshold, perform the following procedures:

  • Checking the time delta between device group member
  • Modifying the ConfigSync time threshold

Checking the time delta between device group members

Before you change the ConfigSync time threshold, you should check the time delta between device group members. If you find that the time difference is greater than 10 seconds, you should verify that NTP is properly configured for all devices and work to resolve the time difference before changing the ConfigSync time threshold setting. If NTP is configured and the time difference between device group members is between three to 10 seconds, you may want to consider modifying the ConfigSync time threshold. To check the time delta between device group members, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To check the time delta between all configured devices, type the following command:

    show /cm device all

    Alternatively, to check the time delta between a list of devices, use the following command syntax:

    show /cm device <devicegroup_member_1> <devicegroup_member_2> etc

    For example, the following command output shows that bigip3.local has a Time Delta to Local Device of five seconds, which may prevent the device from performing ConfigSync operations:

    show /cm device bigip1.local bigip3.local

    -----------------------------------------------------
    CentMgmt::Device: bigip1.local
    -----------------------------------------------------
    Hostname bigip1.local
    Mgmt Ip 172.24.171.234
    Configsync Ip 10.11.16.34
    Mirroring IP ::
    Mirroring Secondary IP ::
    Failover Multicast IP ::
    Failover Unicast IP(s) 10.11.16.34
    Device HA State standby
    Device HA Load Capacity 0
    Device Current Load Factor 0
    Device Next Active Load Factor 1
    Time Delta to Local Device (sec) 0

    -----------------------------------------------------
    CentMgmt::Device: bigip3.local
    -----------------------------------------------------
    Hostname bigip3.local
    Mgmt Ip 172.24.171.233
    Configsync Ip 10.11.16.43
    Mirroring IP ::
    Mirroring Secondary IP ::
    Failover Multicast IP ::
    Failover Unicast IP(s) 10.11.16.43
    Device HA State standby
    Device HA Load Capacity 0
    Device Current Load Factor 0
    Device Next Active Load Factor 0
    Time Delta to Local Device (sec) 5

Modifying the ConfigSync time threshold

After you have checked the time delta between device group members, you may consider modifying the ConfigSync time threshold to account for any time delta between device group members. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To change the ConfigSync time threshold, use the following command syntax:

    modify /sys db configsync.timesyncthreshold value <value between 1-10 seconds>

    For example, to change the ConfigSync time threshold to five seconds, type the following command:

    modify /sys db configsync.timesyncthreshold value 5

  3. Repeat the previous steps for the remaining device group members.
