K65319450: Error Message: 01070029:3: The monitor rule /Common/none was not found

Applies to

Source

Issue

Description

  • ConfigSync operations fail.
  • The following error message is logged to the /var/log/ltm file:

    01070029:3: The monitor rule /Common/none was not found.

  • The Configuration utility may display the following recommended action:

    Recommended action: Review the error message and determine corrective action on the device

Environment

  • High availability (DSC - Device service clustering)

Cause

The configuration object specified in the error message does not have a name.

Recommended Actions

Assign a name to the configuration object.

  1. Log in to the BIG-IP device group member with the latest configuration.
  2. Use the following tmsh command to change the monitor associated with the node to none, so that it matches the configuration:

    tmsh ltm node <node_ip> monitor none

    For example:

    modify ltm node 10.28.11.208 monitor none

  3. Use the following tmsh command to verify the change:

    tmsh list ltm node <node_ip> all-properties

    For example:

    list ltm node 10.28.11.208 all-properties

  4. Save the changes by typing the following command:

    save sys config

  5. Sync from the above device to group.

As a last resort, if the steps above fail to work, then attempt a manual reload of the mcpd process. For more information, refer to by K13030: Forcing the mcpd process to reload the BIG-IP configuration.
