Topic

This article discusses the additional step that the BIG-IP APM administrator must take to allow users access to VMware Horizon 7 through the BIG-IP APM system.

Description

Perform the following procedure to allow users to establish a VMware Horizon 7 session through a BIG-IP APM access session.

Note: BIG-IP APM 11.6.1 HF1 contains a fix for a known issue which prevents the Horizon View client from accessing Horizon 7 resources using BIG-IP APM 11.6.0 and 11.6.1.  For more information, refer to K81314569: VMware View client may fail to establish a session with a VCS BIG-IP APM destination resource.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the affected BIG-IP APM system.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. In the new iRule Name box, type the name for the iRule.
  5. In the Definition box, enter the following text: 
    when HTTP_REQUEST {
    if { [HTTP::header "Origin"] ne "" } {
        HTTP::header remove "Origin"
    }
}
  6. Click Finished.
  7. Navigate to Local Traffic > Virtual Servers.
  8. Click the name of the main virtual server (typically the virtual server listening on port 443).
  9. Click the Resources tab.
  10. In the iRules section, click Manage.
  11. Select the new iRule from the Available column and move it to the Enabled column with the << button.
  12. Click Finished.
