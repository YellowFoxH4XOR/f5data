Description
The apmd process restarts and generates core file.

The core file is located in /shared/core with a file name similar to the following: apmd.bldx.x.x.core.gz. The generation time found in the /var/log/auditd/audit.log is similar to following:

type=ANOM_ABEND msg=audit(YYYY-MM-DDTHH:MM:SSL XXX:42386): auid=########## uid=0 gid=0 ses=########## subj=system_u:system_r:apd_t:s0 pid=5231 comm="apmd" reason="memory violation" sig=6
 

Environment

  • BIG-IP APM
  • ampd
  • BIG-IP version 13.x
     

Cause
Bug ID 1013469

Recommended Actions
To confirm the cause of the issue, gather core file with md5 checksum and qkview and contact F5 Support.
