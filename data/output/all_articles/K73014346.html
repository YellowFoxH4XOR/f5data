K73014346: PreUpgradeCheck NOK on DCD cluster

Applies to

Description

Before doing upgrade from version 6.1 to 7.0 and Running PreUpgradeCheck script, script reported:

DCD cluster: NOK
At least one primary shard (and all of its replicas) are missing.
This means that you are missing data; searches will return partial results,
and indexing into that shard will return an exception.

Environment

  • BIG-IQ Centralized Management
  • BIG-IQ Data Collection Device
  • Upgrade to version 7.0
  • running PreUpgradeCheck script

Cause

Status Of ElasticSearch cluster (System > bigiq-data-collection > bigiq data collection cluster > Summary > Status) reported RED state with error:

At least one primary shard (and all of its replicas) are missing.
This means that you are missing data; searches will return partial results,
and indexing into that shard will return an exception.

Recommended Actions

Check status of elasticsearch cluster from Bash:

curl -s localhost:9200/_cluster/health?pretty

Output example: 

curl -s localhost:9200/_cluster/health?pretty
{
  "cluster_name" : "2eec0cf8-b381-1111-a624-a6d097eee434",
  "status" : "green",
  "timed_out" : false,
  "number_of_nodes" : 5,
  "number_of_data_nodes" : 4,
  "active_primary_shards" : 1460,
  "active_shards" : 2920,
  "relocating_shards" : 0,
  "initializing_shards" : 0,
  "unassigned_shards" : 0,
  "delayed_unassigned_shards" : 0,
  "number_of_pending_tasks" : 0,
  "number_of_in_flight_fetch" : 0,
  "task_max_waiting_in_queue_millis" : 0,
  "active_shards_percent_as_number" : 100.0
}

If status of cluster reports "green" re-run PreupgradeCheck:  ./preUpgradeCheck

If status of cluster reports "red" follow article:
K81715478: Error Message: At least one primary shard (and all of its replicas) are missing. This means that you are missing data; searches will return partial results, and indexing into that shard will return an exception
