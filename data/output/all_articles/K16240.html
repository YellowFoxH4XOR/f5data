Known Issue

The BIG-IP system treats DNS queries containing the EDNS Client subnet option as malformed and drops the queries.

Impact

Client DNS queries that contain the EDNS Client subnet option will fail to resolve.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • DNS queries fail to resolve with an error message that appears similar to the following example:

    dig @192.168.1.100 www.example.net +client=10.10.10.1/32

    ; <<>> DiG 9.9.5 <<>> @192.168.1.100 www.example.net +client=10.10.10.1/32
    ; (1 server found)
    ;; global options: +cmd
    ;; connection timed out; no servers could be reached
