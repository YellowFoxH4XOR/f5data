K83935515: Unable to use Metadata v2 with F5 deployed in AWS

Type
Support Solution
Published
2022-02-24
Updated
2025-02-07
Applies to
  • Public Cloud
  • BIG-IP
  • BIG-IP Cloud Edition
  • Amazon Web Services
Source
https://my.f5.com/manage/s/article/K83935515

Description

  • Unable to license BIG-IP. The following error is observed:  
     01170003:3: halGetDossier returned error (1): Dossier generation failed.
  •  Moving from IMDSv1 to IMDSv2.

Environment

Relevant environmental factors specific to the topic

  • BIG-IP versions higher than 15.1.5.1, but lower than 16.1.2.1
  • Deploying/ reactivating license in Amazon Web Services.
  • Using Metadata version 2.

Cause

  • Change in behavior between IMDSv1 and IMDSv2 wherein the v1 used a request/ response method as opposed to v2 which uses session-based method of access
  • This is tracked as BUG ID968657.

Recommended Actions
Select from the following options:

  • If you can upgrade to v16.1.2.1 or higher, IMDSv2 is supported and will work
  • If you are able to keep using IMDSv1, then disable IMDSv2

Note: If the options above do not suit your needs, raise an F5 support case to see if an Engineering Hotfix is possible for your version.
