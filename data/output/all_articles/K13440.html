Known Issue

Changing the media type setting on a disabled management interface may cause the interface to be enabled.

This issue may occur when all of the following conditions are met:

  • The management interface has been disabled
  • The management interface media type is changed

Impact

The management interface may be unintentionally enabled.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A disabled management interface may be set to enabled. For example, when the management interface is set to disabled, the media value may be set with the following command:

    tmsh modify net interface mgmt media 1000T-FD

    This will result in the interface being automatically enabled, as displayed in the output of the tmsh show net interface mgmt command in the following example:

    Net::Interface
    Name Status Bits Bits Errs Errs Drops Drops Colli
    In Out In Out In Out sions
    -----------------------------------------------------------
    mgmt up 90.6G 21.6G 0 0 0 0 0

Workaround

You can work around this issue by performing one of the following actions:

  • Unplug the network cable from management interface

    Impact of workaround: None.
  • Disable the port on the switch to which the management interface is connected

    Impact of workaround: None.

    Note: For more information about this option, refer to the appropriate documentation for your switch.
