Description

Connection to the virtual server is not working as expected. In the packet capture you can see that it is closed with [F5 RST: ICMP unreachable received] sent by BIG-IP to the back-end server and to the client.

Environment

  • BIG-IP LTM
  • virtual server and pool members listening on different ports

Cause

Port Translation option was disabled for the virtual server. As a result traffic on the server-side is sent by BIG-IP with the destination port of the virtual server, not the pool member.

Recommended Actions

To allow BIG-IP to change the destination port of traffic passing through a virtual server, enable the Port Translation option.

1) Log in to Configuration Utility (GUI).

2) Go to Local Traffic ›› Virtual Servers : Virtual Server List .

3) Select virtual server. 

4) Go to Configuration: Advanced.

5) For Port Translation select "Enabled".

6) Click "Update" to save the config.
