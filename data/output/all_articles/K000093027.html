K000093027: Possible Values of the logging files for DoS Attack Events

Type
Support Solution
Published
2022-12-07
Updated
2022-12-30
Source
https://my.f5.com/manage/s/article/K000093027

Description

Possible Values of the fields that are contained in event messages that might display in AFM logs.

 

Such as: errdefs_msg_name, errdefs_msgno and severity.

 

Environment

  • Required to Set up alerts on selected types of messages

 

Cause

None.

 

Recommended Actions

The possibles values are provided as below.

 

errdefs_msg_name

Network Event

Network DoS Event

IP Intelligence Event

Shun Event

Rtbh Event

Scrubber Event

Netflow Event

Log Throttle Event

Port Misuse Event

Network AutoDoS Event

Firewall NAT

Network DoS nxdomain state

 

errdefs_msgno

NETWORK ACL = 23003137

DOS NETWORK = 23003138

PROTOCOL DNS = 23003139

DOS APPLICATION = 23003140

DOS PROTOCOL DNS = 23003141

IP INTELLIGENCE = 23003142

TRAFFIC FLOW STATS = 23003155

TRAFFIC SYNCOOKIE STATS = 23003156

THROTTLED MESSAGES = 23003154

PROTOCOL SIP = 23003144

DOS PROTOCOL SIP = 23003145

PROTOCOL HTTP = 23003146

PEM LOG = 24182785

 

severity

The number is a value between 0 and 10 where 0 is the minimum value and 10 is the maximum.

 

Additional Information

None.
