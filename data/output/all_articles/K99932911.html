Description

  • CFT, ARM Deployment does not setup HA.
  • CFT, ARM Deployment iapp  does not work.

Environment

  • AWS and Cloud Formation Template (CFT)
  • Azure and Azare Resource Manager (ARM)
  • Any cloud environment deploying from a template.

Cause
Onboarding Script fails.
The hostname must be a fqdn for icontrol to work.

Recommended Actions

  1. Set domain name option in dhcp server and redeploy.

Additional Information

  • The DHCP server must set a domain name.
  • For AWS it logs:
/var/log/cloud/aws/install.log
Onboard failed: 01070903:3: Constraint 'hostname must be a fully qualified DNS name
  • dhcp received is in
/var/lib/dhclient/dhclient.leases
