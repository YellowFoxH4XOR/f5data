Known Issue

This is the result of a known issue. Under rare conditions, the bigd process can run out of memory when an SSL monitor's SSL data structure becomes stale or corrupted.

F5 Product Development tracked this issue as CR63815 and it was fixed in BIG-IP LTM versions 9.1.3 and 9.3.0. For information about upgrading, refer to the BIG-IP LTM release notes.
