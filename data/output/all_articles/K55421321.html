Description
Border Gateway Protocol (BGP) continues functioning when TCP/179 port lockdown is not allowed from self IP address.

Environment
  • ZebOS BGP
  • neighbor passive is not set
  • self IP port lockdown configuration does not allow TCP port 179

Cause
BGP peer initiates ingress connection will be discarded due to port lockdown behavior. BIG-IP egress BGP connection to peer will create a connection to peer and allow any return BGP traffic from peer using the same connection. This effectively establishes the BGP peering. However, not allowing BGP protocol in port lockdown may increase the BGP convergence time. 

Recommended Actions
Allow TCP/179 in port lockdown setting when ZebOS BGP is enabled.
