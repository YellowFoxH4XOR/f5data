K00448761: mcpd and lind processes restarting on secondary blades due to configuration error: AppTemplate (<name>) content does not match the signature

Type
Support Solution
Published
2020-06-02
Updated
2025-02-06
Status
Legacy Content
Applies to
  • VIPRION Platforms
  • BIG-IP
  • BIG-IP LTM: 14.1.2
Source
https://my.f5.com/manage/s/article/K00448761

Description

  • mcpd and lind processes keeps on restarting on secondary blades of vCMP guest
  • the secondary slot logs an error message to the /var/log/ltm file that appears similar to the following example:
    Configuration error: Configuration from primary failed validation: 01071485:3: AppTemplate (<name>) content does not match the signature.... failed validation with error 17241221.

Environment

  • BIG-IP vCMP
  • vCMP Guest system runs on a VIPRION platform configured with one or more secondary blades.
  • You have an existing iApp.
  • You have upgraded the system, rolled back or rebooted the vCMP guest

Cause

Unknown at the time of publication

Recommended Actions
On primary blade,  save and load the configuration by entering the following command:
tmsh save sys config
tmsh load sys config

Additional Information

None.
