Release types

F5 provides the following types of F5 AI Gateway software releases:

  • Major Release: A release with substantial new functions or characteristics. Backward compatibility is not guaranteed.
  • Minor Release: New functionality is added in a backward compatible manner.
  • Patch Release: Backward compatible bug fixes.

Release Frequency

F5 constantly works to enhance and extend its product functionality and provide the customer with the most advanced solution for managing its AI workloads. F5 will release major, minor or patch releases as necessary to satisfy our customer needs.

For release information, see Changelog for AI Gateway Core.

Security Updates

F5 AI Gateway follows F5 standard processes for issuing security patches. Security updates for F5 AI Gateway are issued for the most recent minor release. F5 discloses security vulnerabilities and security exposures for F5 products in Monthly Security Notifications (MSNs).

Please see the following articles:

  • K12201527: Overview of F5 security notifications
  • K67091411: Guidance for Hardened Releases and Security Notifications
  • K4602: Overview of the F5 security vulnerability response policy
  • K000133035: How F5 evaluates vulnerabilities in third-party packages

Impact of Third-Party Components

F5 AI Gateway uses open-source third-party components within the product. For a complete list of these components and their versions, please request an SBOM through your Account Team. Vulnerabilities in these third-party dependencies are addressed as soon as a fix is available in the upstream according to F5 policies.

Support Policy

F5 advises users to run the most recent release of F5 AI Gateway software, because we issue updates to only the most recent release. F5 may, at its discretion, provide updates on previous releases.

F5 provides technical support for the current minor release and releases that are launched within two years of the launch date of the current minor release.

EoSD for all previous releases occur when either a new major or minor release has been issued.

About technical support

When the release has reached EoSD, F5 does not provide security updates or software fixes. During the period between EoSD and EoTS, F5 continues to offer technical support inclusive of technical questions on product, troubleshooting, and problem isolation. Additionally, no product fixes and security fixes are provided during this period. Upgrading to a supported version of code is the best course of action to resolve an issue.

When the release has reached EoTS, F5 does not provide further technical support.
