Recommended Actions

Follow recommendations of K14593: BIG-IQ localhost discovery is required before performing remote device discovery

"Recovering the BIG-IQ system from a failed discovery"

Recovering the BIG-IQ system from a failed discovery

- Log in to the BIG-IQ command line.

- Copy the value that is in the uuid field from the Verify that the BIG-IQ is discovered procedure.

- Remove the Pending or Post_Fail discovery by entering the following command syntax:

curl -X DELETE http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices/<UUID>

Add the BIG-IQ self-IP addresses by entering the following command:

curl -X POST -d '{"address":"127.0.0.1", "userName":"admin", "password":"", "httpsPort":"443"}' http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | json-format

Verify that the BIG-IQ system's self IP address is in the list, in an Active state, by entering the following command to get a list of all the BIG-IQ devices:

curl http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | /usr/bin/json-format

After the BIG-IQ system's self IP address appears in the list, restart the restjavad service using the following command:

bigstart restart restjavad
