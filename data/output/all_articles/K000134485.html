K000134485: F5OS SNMP OID for serial number, type of Hardware and hostname

Type
Support Solution
Published
2023-05-05
Updated
2025-04-01
Applies to
  • F5OS
  • VELOS Platforms
  • rSeries Platforms
Source
https://my.f5.com/manage/s/article/K000134485

Description

What are SNMP OIDs for the below?

  • serial number
  • type of Hardware
  • hostname

Environment

  • F5OS-A / F5OS-C
  • rSeries / Velos
  • SNMP OID
  • serial number
  • type of Hardware
  • hostname

Cause

Starting in 1.8.0, F5OS has OIDs for serial # and platform. These were introduced in ID1251957.

Recommended Actions

These example OIDs were taken from an r5900 running 1.8.3:

.1.3.6.1.4.1.12276.1.2.1.8.1.1.1.8.112.108.97.116.102.111.114.109 =	STRING: "<f5_serial_#>"
.1.3.6.1.4.1.12276.1.2.1.8.1.1.2.8.112.108.97.116.102.111.114.109 =	STRING: "r5900"
.1.3.6.1.2.1.1.5.0                                                =	STRING: <hostname>
