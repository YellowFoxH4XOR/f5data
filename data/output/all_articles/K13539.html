Topic

This article applies to BIG-IP 11.x through 17.x. For information about other versions, refer to the following articles:

  • K9308: Disabling the watchdog process to perform a core dump (9.3.0 - 10.x)
  • K4136: Disabling the watchdog process to perform a core dump (9.0.0 - 9.1.3)

You should consider using this procedure under the following condition:

  • You are forcing the BIG-IP system to produce a core file for diagnostic purposes.

    Note: You only need to produce a core file for diagnostic purposes when directed to do so by F5 Technical Support.

Description

The watchdog process ensures that the BIG-IP system will reboot in the event of a system lock-up, prompting a failover. If you are forcing the BIG-IP system to produce a core file for diagnostic purposes, you must disable the watchdog process to allow the core file to write to disk before the system reboots.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have command line access to the BIG-IP system.

Procedures

Disabling the watchdog process

To disable the watchdog process, perform the following procedure:

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Disable the watchdog process by typing the following command:

    modify sys db watchdog.state value disable

  3. Save the change by typing the following command:

    save sys config

Enabling the watchdog process

To enable the watchdog process, perform the following procedure:

Important: Always enable the watchdog feature once the core dump has completed.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Enable the watchdog process by typing the following command:

    modify sys db watchdog.state value enable

  3. Save the change by typing the following command:

    save sys config
