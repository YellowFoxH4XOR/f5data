K000150145: How do I get the release notes for ASM attack signatures?

Type

Published
2025-02-27
Updated

Source

Description

This article describes how to find the readme files (release notes) for the ASM Attack Signatures.

Environment

  • BIG-IP ASM/AWAF
  • ASM Attack Signatures

Cause

You want to see a list of all the new and modified attack signatures including the ID, name, description, etc. for a particular signature release.

Recommended Actions

  1. Go to the downloads page. From the MyF5 home page select Resources > Downloads.
  2. Select BIG-IP in the Group drop-down menu.
  3. Pick your major branch version in the Product Line menu.
  4. Pick your version in the Product Version menu.
  5. Select the ASM-AttackSignaturesUpdates radio button.
  6. Scroll to the bottom and you'll see the Readme.* files with the signature updates files in the Select a Download File section.

Additional Information

The Readme.txt file contains release notes for every release on a particular BIG-IP version.
