Description

After successfully loading the UCS to the BIG-IP, there are no error messages. The virtual servers and pool configurations are inside the bigip.conf file. But there are no virtual servers and pools in the GUI and when performing 'tmsh list ltm virtual' / 'tmsh list ltm pool'

Environment

  • BIG-IP LTM
  • Successfully loaded UCS without error message
  • There are virtual server and pool configuration inside bigip.conf file
  • There are no virtual servers / pools loaded

Cause

Under certain rare conditions, the binary configuration may become mismatched to the text-file configuration. In cases where the binary image is no longer accurate, you can correct the situation by forcibly reloading the configuration from the text-based configuration files.

Recommended Actions

Perform MCPD forceload, please follow the article:
K13030: Forcing the mcpd process to reload the BIG-IP configuration
