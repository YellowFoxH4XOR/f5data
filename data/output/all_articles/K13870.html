Known Issue

Changes to the filer Windows Remote Management port (WinRM port) are not properly committed when you edit the port settings using the ARX GUI.

This issue occurs when all of the following conditions are met:

  • You are using a Windows filer
  • Snapshots are enabled
  • You are editing an existing filers WinRM port setting

Impact

The ARX system is unable to properly manage the Windows filer snapshots.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Snapshots will fail to run.

Workaround

To work around this issue, you may either edit the WinRM setting using the CLI or edit the filer type and WinRM port settings simultaneously in the ARX GUI. To do so, perform one of the following two procedures:

Impact of workaround: None.

Editing the WinRM port using the ARX CLI

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter global mode by typing the following command:

    global
  4. Enter the filer configuration mode by typing the following command:

    filer [filer name]
  5. Edit the filer WinRM port settings by typing the following command:

    filer-type windows [port winrm-port]

    For example:

    filer-type windows port 65535
  6. Return to privileged mode by typing the following command:

    end

Changing the file server type to a non-windows platform

The ARX GUI will properly commit the WinRM port setting change when the file server type is changed at the same time. To successfully make the filer type and port change, perform the following procedure:

Impact of workaround: None.

  1. Log in to the ARX GUI.
  2. Navigate to File Servers and select File Server Summary.
  3. Select the file server and click Edit.
  4. From File Server Type, change the Windows type to any other type.
  5. Click OK.
  6. After the change is committed, edit the File Server Type and change the type back to Windows.
  7. Select This file server supports snapshots.
  8. Change the WinRM Port value to the desired port.
  9. To commit the changes, click OK.
