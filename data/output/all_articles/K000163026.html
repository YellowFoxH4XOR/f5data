Description

An outbound SCP transfer of a UCS file from a BIG-IP system can fail when the remote destination is the root directory (/), with an error similar to:

scp: /<filename>.ucs: Error opening file: Permission denied.

A zero-byte test file may transfer successfully while the UCS file fails.

Environment

  • BIG-IP LTM
  • UCS file source directory: /var/local/ucs
  • Transfer method: Outbound SCP from BIG-IP to a remote SCP server
  • BIG-IP SCP whitelist: /config/ssh/scp.whitelist
  • Example source path:

    /var/local/ucs/<filename>.ucs

Cause

The remote SCP server cannot create the UCS file in its root directory (/). Possible causes include destination-directory permissions, remote-server restrictions, insufficient disk space, or security policies affecting file creation in /.

The BIG-IP SCP whitelist is not the cause. It controls inbound file transfers to BIG-IP and does not restrict outbound transfers from BIG-IP to a remote server.

Recommended Actions

  1. Confirm that the destination directory exists on the remote SCP server.
  2. Confirm that the remote SCP user can create and write files in the destination directory.
  3. Avoid using the remote server’s root directory (/) unless write access is explicitly permitted.
  4. Transfer the UCS file to a writable directory, such as /var/tmp:
    scp -p /var/local/ucs/<filename>.ucs <remote_user>@<remote_server>:/var/tmp/
  5. If the transfer still fails, verify the following on the remote SCP server:
    • Available disk space
    • Directory ownership and permissions
    • SCP or SSH access restrictions
    • Security policies that prevent file creation in the target directory

Additional Information

  • The BIG-IP SCP whitelist applies to files copied to the BIG-IP system.
  • It does not apply to files copied from the BIG-IP system to a remote SCP server.
  • Successful transfer of a zero-byte test file does not confirm that the remote server can create a larger UCS file in the same directory.
  • Use a destination directory specifically configured for writable file transfers.
