Description

Content-Type header value *json* not detected.

Environment

  • Request payload contains JSON Arrays
  • Header Content-Type configured with *json*
  • JSON profile applied

Cause

ASM handles JSON Arrays differently from JSON Objects.

This has to be demonstrated with an example:

{"container":["123-1,01","123-1,02","123-1,03",

In JSON format >>

{
  "container": [
    "123-1,01",
    "123-1,02",
    "123-1,03",

ASM read this in the following way; the parameter 'container' would be parsed n times, each time with a different value:

container = 123-1,01
container = 123-1,02
container = 123-1,03
...

Therefore, ASM parses each value effectively as a duplicate parameter.

Recommended Actions

Disable 'Parse parameters' in the JSON profile.

Additional Information

None.
