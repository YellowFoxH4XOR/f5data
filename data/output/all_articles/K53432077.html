Description

You want to know what ciphers the BIG-IP will use with a given cipher string

Environment

  • BIG-IP LTM
  • ClientSSL or ServerSSL Profiles

Cause

You are either creating a new cipher string or modifying an existing cipher string for one of your SSL profiles

Recommended Actions

To test your new cipher string you can use tmm --clientciphers or tmm --serverciphers to test what the BIG-IP will allow on the respective ClientSSL and ServerSSL profiles

Syntax:
  • tmm --clientciphers '<cipherstring>'
  • tmm --serverciphers '<cipherstring>'
When run from the command line of your device, you will see an output similar to the following:
