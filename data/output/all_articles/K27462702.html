Description

Attempting to add an iRule to an LTM virtual server fails with a 'No Access' error

  • An error, similar to the following is found within /var/log/webui.log or /var/log/tomcat/catalina.out
    2021-09-08 04:08:14,854 ERROR [-] web.FormHandler:doAllowedCharactersCheck - /tmui/Control/form returning response as, No Access

Environment

  • BIG-IP LTM

Cause

Bug ID 1045421: No Access Error When Policy is applied to the Virtual Server
Bug ID 1049229: No Access Error While trying to create a sub-rule under the Network Firewall rule list

Recommended Actions

An Engineering Hotfix may be available. Contact F5 Support, for more information.
