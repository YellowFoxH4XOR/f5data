Known Issue

This is the result of a known issue. On the Interfaces tab in Device Management: Configuration: Network Configuration, you are able to manually set the Speed/Mode for the individual interfaces by changing the values within the drop-down menu. When you make a change and finalize the new configuration by navigating to the Finalize Section link, the page will still display Auto in the Speed/Mode drop-down menu. The setting that you configured is written to the configuration file on your FirePass device and is being used, but the Administrative Console does not display the new setting.

F5 Product Development tracked this issue as CR122644 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative HF-603-4, which has been issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

For a list of available hotfixes, refer to K10322: FirePass hotfix matrix.
