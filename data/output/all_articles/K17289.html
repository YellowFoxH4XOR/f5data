Known Issue

You cannot log in to the BIG-IP system using the Traffic Management Shell (tmsh) with a user name that contains spaces.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured to use remote authentication.
  • A remote authentication user is configured with a space in the user name.

    For example:

    test user

Impact

Users cannot log in to the BIG-IP system using the tmsh utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H490179 on the Diagnostics > Identified > Low screen.
  • If you attempt to log in using the SSH utility, the system produces an error similar to the following example:

    $ ssh 10.11.12.10 -l 'test user'
    Password:

    Cannot load user credentials for user "test user"
    Current session has been terminated.
    Enter any key to end your session.
  • In the /var/log/ltm file, you observe error messages similar to the following example:

    notice -tmsh[8405]: 01420003:5: Cannot load user credentials for user "test user" Current session has been terminated.
    crit -tmsh[8405]: 01420001:2: boost assertaion failed: "!pthread_mutex_destroy(&m)" file:/usr/include/boost/thread/pthread/recursive_mutex.hpp line:62
