Description
A DNS Listener is not created when a DNS deploy Target is Deploy to Sync Groups

Environment
  • BIG-IP DNS managed by BIG-IQ
Recommended Actions
To deploy a DNS Listener to a managed BIG-IP:
  • In Deployment -> EVALUATE & DEPLOY -> DNS Evaluations, click Create
    • In the Target section select Deploy to Devices 
    • Move the desired target devices from the Available column into the Selected column
    • Click Create
  • After the evaluation has completed deploy any differences that were found
Cause
This is the expected behavior. The DNS Listener creates a traffic-group-local-only virtual-address to handle DNS requests. When a Listener is created you must select a single device to deploy it to. This is because a Listener is usually intended to be specific to a device. If you want to create the same Listener on each device then it will need to be created for and targeted to each device. Then the changes can be deployed to all the target devices in a single deployment.
