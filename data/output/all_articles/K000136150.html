Description

You wanted to know what is the purpose of /config/wa/globalfragment.xml ?

And if these file - /config/wa/globalfragment.xml.x.y.z  with 777 permission can be a vulnerable.
 

Environment

BIG-IP

Cause

None

Recommended Actions

One can safely delete the old version files and can change permission of  /config/wa/globalfragment.xml files to 755.
 

Additional Information

/config/wa/globalfragment.xml contained the configuration for BIG-IP WAM (WebAccelerator) and how it should handle various file types in respect of caching

It is not used by any currently supported product but continues to exist on the file system.

globalgragment.xml.X.Y.Z files are old configuration from earlier versions - i.e. they are created when systems are upgraded

For instance :

15.x test host was originally 15.1.0, then 15.1.6, then 15.1.6.1 and has:

-rwxr-xr-x. 1 tomcat tomcat 22615 Jul 1 2022 globalfragment.xml

-rwxr-xr-x. 1 tomcat tomcat 22615 Nov 21 2019 globalfragment.xml.15.1.0

-rwxr-xr-x. 1 tomcat tomcat 22615 Apr 13 2022 globalfragment.xml.15.1.6
