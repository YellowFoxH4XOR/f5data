Description

  • The Device was rebooted, possibly as part of an upgrade.
  • The Device is not pingable.
     

Environment

  • The Device was Forced Offline

Cause

  • The Address you are attempting to contact is not the Management IP but a Self-IP.
  • You have been using a Self IP without realising it.

Recommended Actions

  1. Log into the Device using the Serial Console or the Hypervisor Console.
  2. run  tmsh list sys management-Ip            to find the correct Address.
  3. Log in to the device using the management IP

Additional Information
Force Offline stops the Dataplane. If the Device is a Viprion or a VCMP guest on a Viprion, the Self-IP's go down immediately.
On an Appliance or a Virtual Edition, the Self-IP's remain up even though the Device does not process traffic.
However in this case when booted and Forced Offline, the Dataplane does not start. The  Self-IP's are not initialised.
