Description

Change HTTP host header from IP address to an FQDN using iRule
 

Environment

  • VIPRION
  • iRules
  • HTTP_REQUEST
     

Cause

Http client can only connect using ip address however the application/web server only accepts http packet using fqdn host header
 

Recommended Actions

1. Login to GUI > Local Traffic > iRules > iRule List > Create > Enter a Name
2. Configure iRule that change http host header from the ip address to and fqdn

when HTTP_REQUEST { 
    if { [HTTP::host] equals "VS_ip_address" } { 
    HTTP::header replace "Host" "FQDN" }
}

Example :

when HTTP_REQUEST { 
    if { [HTTP::host] equals "10.18.10.104" } { 
    HTTP::header replace "Host" "smartfqdn.sevenxxi.net" }
}

3. Click Update

4. Apply the iRule to the Virtual Server > Local Traffic  ››  Virtual Servers : Virtual Server List > Select the Virtual Server > Resources

5. Under iRule > Click Manage > Move the created iRule from Available to Enabled

6. Click Finished and Test the application or run a tcpdump.
