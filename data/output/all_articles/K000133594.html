Description

When using the default configuration of Strict Policy ( /etc/app_protect/conf/NginxStrictPolicy.json ), NAP blocks GET requests that contain the header "Content-Type".

The logs show:

"sub_violations":"HTTP protocol compliance failed:Body in GET or HEAD requests"
<http_sub_violation> Content-Type header in GET request

Environment

  • NGINX App Protect default
  • Default Strict Policy Config

Cause

This is expected behaviour.

By default, the sub-violation "Body in GET or HEAD requests" is enabled.

 

In the default config; /etc/app_protect/conf/NginxStrictPolicy.json

 

The following sections shows the setting:

 

{

          "description": "Body in GET or HEAD requests",

          "enabled": true

        },

 

Recommended Actions

Modify the directive to false.
