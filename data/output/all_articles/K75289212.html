Description

There is no specific limit of IP addresses in IP Address Exceptions in a particular policy.

Environment

  • BIG-IP ASM

  • Configuring IP Address Exceptions 

Cause

It is by design.

Recommended Actions

GUI : Security >> Application Security >> IP Addresses >> IP Address Exceptions

Although there is no limit for configurable IP addresses, these may be some performance impact due to many IP addresses.
So we would recommend the performance test when configuring many IP addresses.
