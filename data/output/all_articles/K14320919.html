Description

  • Unable to sync devices
  • An error message similar to the following can be seen on the GUI on Device Management  >  Overview
    HA (Sync Failed): A validation error occurred while syncing to a remote device
    Sync error on LTM1.example.com: Load failed from /Common/LTM2.example.com 01070734:3: Configuration error: Unknown template (/Common/f5.bigiq-analytics) specified for application

Environment

  • LTM HA pair managed by BIG-IQ
  • BIG-IQ running software version 7.0.0 or 7.0.0.1
  • BIG-IP devices running versions 11.x, 12.x, 13.x, 14.x or v15.x.

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 825301

Recommended Actions

Upgrade BIG-IQ device to a non affected version
