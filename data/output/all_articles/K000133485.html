K000133485: gtm_add failed to sync external monitor

Type
Support Solution
Published
2023-04-12
Updated
2023-04-12
Applies to
  • BIG-IP
  • BIG-IP DNS: 15.1.4
Source
https://my.f5.com/manage/s/article/K000133485

Description

gtm_add command doesn't support external monitor syncing and may fail with the following error :


<DATE> localhost mcpd[4678]: 01070712:3: Caught configuration exception (0), Values (/Common/<external monitor name>) specified for external monitor parameter (/Common/<external monitor name> 2 RUN_I=): foreign key index (to_file) do not point at an item that exists in the database..


Environment

BIG-IP DNS

gtm_add command

Cause

Missing script file for external monitor as gtm_add command can't sync it to the new device.


For example, the following external monitor on existing GTM can't be synced to the new GTM using gtm_add


/config/bigip_gtm.conf 

gtm monitor external /Common/test_ex {

  defaults-from /Common/external

  destination *:*

  interval 4

  probe-timeout 1

  run /Common/test_ex

  timeout 16

}


/config/bigip.conf 

sys file external-monitor /Common/test_ex {

    cache-path /config/filestore/files_d/Common_d/external_monitor_d/:Common:test_ex_xxxxx_x

    revision 1

}


Recommended Actions

Configure LTM device group to sync local files between the two GTMs or remove the external monitor to complete gtm_add.

Additional Information

K63055641: gtm_add script not joining device to sync group or pulling config with external monitor
