K43644521: EPSEC fails to install

Type
Support Solution
Published
2022-09-27
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.X, 16.1.2, 16.1.1, 16.1.3, 16.1.0
Source
https://my.f5.com/manage/s/article/K43644521

Description

You install EPSEC OPSWAT, but when you look in the configuration utility (or CLI: show /apm epsec software-status), it looks like the installation failed.
If you navigate to: System  ››  Software Management : Antivirus Check Updates : Device Status

The "Status" field says: failed <version>

Environment

You have the following applied on your BIG-IP:

  • APM provisioned
  • Attempting to install or update EPSEC OPSWAT

Cause

Although the configuration utility indicates a failure, the installation might actually be successful.
This has been recorded in the bug 1064357.

Recommended Actions

To solve this issue, you can do one of the following:

  • Do a MCP forceload and a full system reboot.

    Note: This is a temporary solution and you might have to perform this after each EPSEC upgrade.
  1. forceload: https://my.f5.com/manage/s/article/K13030
  2. run the command 'reboot' in the CLI
  • Contact F5 technical support, and request a hotfix for this bug.
  • Upgrade to BIG-IP 16.1.3 or 17.0.0 or later
