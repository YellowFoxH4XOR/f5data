K27031493: Change transport address in ElasticsSearch on BIG-IQ CM (BIG-IQ 8.0.0 and later)

Type
Support Solution
Published
2022-04-07
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K27031493

Description

You want to change the IP address BIG-IQ CM uses to communicate with other nodes in the ElasticSearch cluster.

Environment

  • BIG-IQ cluster with Data Collection Device (DCD)

Cause

None

Recommended Actions

Run the following script on BIG-IQ CM CLI as root to modify the the CM transport address:

# /bin/set-cm-es-ip <Primary_cm_es_IP> [Secondary_cm_es_IP]

For example:


If the primary CM transport address will be changed to 192.168.1.11, and the secondary CM transport address will be changed to 192.168.1.12:

# /bin/set-cm-es-ip 192.168.1.11 192.168.1.12


If the primary CM transport address will be changed to 192.168.1.11, and no secondary CM is in use:

# /bin/set-cm-es-ip 192.168.1.11
 

Additional Information

BIG-IQ 8.0.x doesn't come with the script, but you may copy it from another BIG-IQ 8.1.x host or request it from F5 support team.
