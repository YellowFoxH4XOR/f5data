Known Issue

The Traffic Management Microkernel (TMM) may produce a core file and restart on BIG-IP APM systems with Secure Web Gateway (SWG), due to an internal software timing issue.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is licensed and configured for SWG.
  • The BIG-IP APM system is processing access sessions.

Impact

The BIG-IP APM system may temporarily fail to process traffic as it recovers from TMM restarting.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If configured for high availability (HA), the affected BIG-IP APM device fails over to the configured peer device.
  • The BIG-IP APM system generates a TMM core file to the /var/core directory, which includes a time stamp that correlates with the traffic interruption.
  • Log messages similar to the following example are logged to the /var/log/ltm file:
