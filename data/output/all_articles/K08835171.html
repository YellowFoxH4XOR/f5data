Issue

Error Message

notice scriptd[<PID>]: 014f0001:5: started

In this error message, note the following:

  • <PID> is the process ID for the scriptd process

For example:

notice scriptd[5951]: 014f0001:5: started

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The scriptd process is starting.

This message indicates the scriptd process is starting. For example, you restart the scriptd process or the process starts as part of the normal BIG-IP boot process.

Impact

There is no impact; this message is informational.

Recommended Actions

None
