Topic

The Linear White Space (LWS) setting within an HTTP profile is used when headers are inserted using the HTTP::header insert iRule option.

Note: The LWS feature does not work with any other header insert options within the HTTP profile or cookie persistence profile.

The feature consists of the following two attributes:

  • LWS Maximum Columns

    This attribute is used to specify the maximum number of characters allowed per column for a header that is inserted into an HTTP request. The default value is 80 characters per column.
     
  • LWS Separator

    This attribute is used to specify the separator that should be used between HTTP headers when a header exceeds the maximum width specified by the LWS Maximum Columns setting. The available options are: none (default), cr (Carriage Return), lf (Line Feed), or sp (Space).

Note: No separation of the header information occurs with the LWS Separator set to none, even if an LWS Maximum Columns value is specified. Specifying cr (Carriage Return) or lf (Line Feed) will separate the header data into multiple lines.

When the LWS feature is specified, it must be called from with an iRule using the following syntax:

HTTP::header insert lws <Header Name> "Header Value"

For example:

when HTTP_RESPONSE {
HTTP::header insert lws AskF5-Header "abcdefghijklmnopqrstuvwxyz"
}

If you configured an HTTP profile with five LWS Maximum Columns, and sp as the LWS Separator, the output of the header will contain the AskF5-Header data split into five characters per column and separated by a space. For example:

HTTP/1.1 200 OK
Content-Length: 1433
Content-Type: text/html
Content-Location: /
Accept-Ranges: bytes
Connection: close
AskF5-Header: abcde fghij klmno pqrst uvwxy z

Alternatively, if you configured the HTTP profile with five LWS Maximum Columns and cr as the LWS Separator, the output of the header will contain the AskF5-Header data split into groups of five characters per column and separated by a carriage return. For example:

HTTP/1.1 200 OK
Content-Length: 1433
Content-Type: text/html
Content-Location: /
Accept-Ranges: bytes
Connection: close
AskF5-Header: abcde
