Description

To remove BIG-IP Edge Client components you can use the BIG-IP APM Client Troubleshooting Utility (CTU). For information about downloading and installing the , refer to K12444: Overview of the Client Troubleshooting Utility for Windows.

The CTU is a Windows client application that by default is a GUI based application. However, you can also use the CTU from the command line to remove the BIG-IP Edge Client components. For example, if you want to automate removal using management tools like SCCM, you can use the command line option of the CTU.

Environment

  • BIG-IP Edge Client on Windows
  • BIG-IP APM Client Troubleshooting Utility (CTU)

Cause
None

Recommended Actions

  1. Download the BIG-IP APM Client Troubleshooting Utility (CTU) on the affected client system. For information, refer to K12444: Overview of the Client Troubleshooting Utility for Windows.
    Note: An environment with many client systems may choose to use a device management platform to automate the installation of the latest CTU (f5wininfo.exe) onto the client systems.
  1. From the command line of the client system, you can use the following command options to remove the BIG-IP Edge Client components:
    Note: the following command examples use the default /Downloads/ folder as the location of the f5wininfo.exe file. Modify as needed for your client system.
    • To remove all BIG-IP Edge Client components, use the following command:

      /Downloads/f5wininfo.exe /r
       
    • To remove all BIG-IP Edge Client components while excluding a specific client component or group from removal, use the following command:
      Note: Replace <Component Name or Group> with the name of the client component or group as listed in the left navigational pane of the Edge Client CTU graphical user interface (GUI).

      /Downloads/f5wininfo.exe /r /x "<Component Name or Group>”
       
    • To remove all BIG-IP Edge Client components except the Win32 Inspector component and the components listed under the Base Controls group, use the following command:

      /Downloads/f5wininfo.exe /r /x “Win32 Inspector” /x "Base Controls"

  2. Remove the CTU from the client system by deleting it from the file system if no longer required:

    del /Downloads/f5wininfo.exe

Additional Information

Older versions of the BIG-IP Edge Client may have an older version of the CTU installed as f5uninstall.exe in the C:\ProgramData\F5 Networks\ folder. However, the recommended option is to download a new version of the CTU.
