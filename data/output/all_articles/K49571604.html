Description

BIG-IP became INOPERATIVE, with log messages similar to the following:

notice tmm[20450]: 01010019:5: Caught signal 15, exiting
notice overdog[2070]: 01140104:5: Watchdog touch disabled.
info overdog[2070]: 01140101:6: Overdog daemon shutdown.

Environment

  • CLI
  • GUI

Cause

The command pkill -u <user> was issued towards a user with bash access.

Users with advanced shell (bash) access are effectively root. This is expected.

[admin1@ltm:Active:Standalone] ~ # whoami
root

Recommended Actions

Avoid issuing a pkill -u command towards a user with bash access.

Additional Information

The log messages seen in the description of this article are typical during an orderly shutdown of a BIG-IP. They might also be seen on virtual editions when a shutdown is issued from the hypervisor.
