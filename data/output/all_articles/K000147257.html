Description

How to change two default behavior for wingman 

  • Change wingman to use a different port from the default (8070)
    • Why? To resolve port confliction
    • Error message
      • ,"error":"Local server listen 127.0.0.1:8070: +listen tcp 127.0.0.1:8070: bind: address already in use"
    • This mostly will happen if you have multiple application running with hostNetwork 
  • Disable wingman for Kubernetes jobs
    • Why? Some time k8s job only runs as a lightweight job and it does not use any certificates 
    • Note: We do not recommend disabling it unless it causes some issue

What is Wingman?

  • Wingman is a F5® Distributed Cloud Services provided security sidecar that does almost all of the security-related work for the workload from identity bootstrapping, secrets management, external secrets management, certificate rotation, etc.

Environment

  • Your F5® Distributed Cloud Services site and YAML for your application

Procedure

Add the following metadata.annotations of the POD (not the deployment, daemonSet etc..)

  1. Change wingman pod from the default (8070) 
    • apiVersion: apps/v1
      kind: DaemonSet
      metadata:
       annotations:
         app.kubernetes.io/name: my-netbox-client
                                                    ##<---- NOT here
       name: my-netbox-client
       namespace: shali-ns1
      spec:
       selector:
         matchLabels:
           name: my-netbox-client
       template:
         metadata:
           annotations:
             ves.io/wingman-port: "8071" ##<---- Add it here
  2. Disable wingman, this only work in Kubernetes jobs 
    • metadata:
        annotations:
          ves.io/wingman-injection-mode: disable
