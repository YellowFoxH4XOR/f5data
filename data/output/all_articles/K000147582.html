K000147582: How do I enable or disable HTTP2 configuration in the Origin Pool of the HTTP Load-Balancer?

Description

  • I want to enable HTTP2 in the Origin Pool of the HTTP Load Balancer but can't find where I can make the necessary changes.

Environment

  • F5® Distributed Cloud (XC) Console

Cause

  • None

Answer/Recommended Actions

The GUI has been loaded with multiple new features and in the process the HTTP2 field has been moved from the advance fields in origin pool to the below.

To enable or disable your HTTP2 configuration in LB you need to

  1. Navigate to Load-Balancer > Origin Pools
  2. Click  Edit Origin Pool
  3. At the bottom of the page click Edit Configuration
  4. Click Other Settings
  5. Go to Miscellaneous Options
  6. Select HTTP Protocol Configuration from the drop-down list
  7. Select HTTP/2 Configuration
  8. Either check the box next to HTTP2 Enabled to enable them or uncheck the box to disable them
