Description

Client is not able to launch VDI desktop after correct AD authentication.????

Environment

Relevant environmental factors specific to the topic

  • VMware
  • iApp deployment 
  • NO Radius server configured in VPE 
  • APM error message:
    RADIUS agent: No AAA server associated with <access policy agent name>

Cause

Radius 2FA is configured on Vmware Connection Server.
This is not supported by F5. 

Recommended Actions

Disable Radius 2FA on connection server 
Note: If your design require Radius 2FA, you can enable this option in iApp.

None
