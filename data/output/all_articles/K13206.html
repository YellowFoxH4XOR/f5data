Topic

This article applies to BIG-IP 11.x and later. For information about other versions, refer to the following articles:

  • K8439: Configuring local hostname resolution for BIG-IP (9.4.2 - 10.x)
  • K3625: Configuring local hostname resolution for BIG-IP (4.5.x - 9.4.1)

You should consider using these procedures under the following condition:

  • You want to permanently add hosts to your local /etc/hosts file.

Description

Under certain circumstances, you may need to add hosts to your /etc/hosts file. To make the changes, you can use the TMOS Shell (tmsh) command.

Note: The /etc/hosts file is auto-generated at every system reload, including restarts. Do not attempt to add hosts by manually editing the /etc/hosts file. The changes may appear to work, but they will not persist through restarts or configuration reloads.

Note: Beginning in version 11.6.0, the BIG-IP system uses DNS to resolve host names for nodes and pool members that are identified with fully qualified domain names (FQDNs) and does not consult the /etc/hosts file.

Prerequisites

None

Procedures

  • Adding a host to the /etc/hosts file using the Configuration utility
  • Adding a host to the /etc/hosts file using the tmsh command
  • Removing a host from the /etc/hosts file using the tmsh command

Adding a host to the /etc/hosts file using the Configuration utility

Impact of procedure: The following procedure should not have a negative impact on your system.

Note: These changes persist through BIG-IP restarts and configuration reloads. It is not necessary to save this configuration using the tmsh save command.

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to System > Configuration > Device > Hosts.
  3. Enter your chosen host name and corresponding IP address.
  4. Click Add.
  5. Repeat steps 3 and 4 for each additional host you want to add.
  6. Click Update.

Adding a host to the /etc/hosts file using the tmsh command

Impact of procedure: The following procedure should not have a negative impact on your system.

Note: These changes persist through BIG-IP restarts and configuration reloads. It is not necessary to save this configuration using the tmsh save command.

  1. Log in to the BIG-IP host as the root user.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. To enter the global-settings tmsh subsystem, type the following command:

    /sys global-settings

  4. Press Enter.
  5. To add the remote host, use the following command syntax:
    • Replace both instances of <hostname> with the host name you want to add.
    • Replace <host IP address> with the IP address of your host.

    modify remote-host add {<hostname> {hostname <hostname> addr <host IP address>}}

    For example:

    modify remote-host add {test.f5.com {hostname test.f5.com addr 192.168.1.1}}

  6. Repeat step 5 for each additional host you want to add.
  7. Exit tmsh by typing the following command:

    quit

  8. Confirm the change in the /etc/hosts file.
  9. To display the contents of the /etc/hosts file, type the following command:

    less /etc/hosts

Removing a host from the /etc/hosts file using the tmsh command

Impact of procedure: The following procedure should not have a negative impact on your system.

Note: These changes will persist through BIG-IP restarts and configuration reloads. It is not necessary to save this configuration using the tmsh save command.

  1. Log in to the BIG-IP host as the root user.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. To enter the global-settings tmsh subsystem, type the following command:

    /sys global-settings

  4. Press Enter.
  5. To delete the remote host, use the following command syntax, replacing <hostname> with the host name you want to delete:

    modify remote-host delete { <hostname> }

    For example:

    modify remote-host delete { test.f5.com }

  6. Repeat step 5 for each additional host you want to delete.
  7. Exit tmsh by typing the following command:

    quit

  8. Confirm the change in the /etc/hosts file.
  9. To display the contents of the /etc/hosts file, type the following command:

    less /etc/hosts
