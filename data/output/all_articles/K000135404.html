K000135404: Unable to add BIG-IP to Solarwinds SNMP monitoring

Type
Support Solution
Published
2023-07-06
Updated
2026-02-19
Source
https://my.f5.com/manage/s/article/K000135404

Description

Unable to added BIG-IP device on Solarwinds SNMP monitoring tool. It is failing with no error.


Environment

SNMP access configured on BIG-IP


Cause

Misconfiguration


Recommended Actions

In this case, F5 was talking to a firewall IP in between BIG-IP and Solarwidns, which is not allowed in SNMP config on F5.


  1. Check the SNMP agent IPs are added to System > SNMP > Agent > Configuration
  2. Make sure the IP is added to System > SNMP > Agent > Access (V1, V2c) > select source to all or the IP required.


Additional Information

This was confirmed by taking a tcpdump on F5 on SNMP port 161
