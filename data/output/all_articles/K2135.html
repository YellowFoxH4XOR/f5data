Topic

BIG-IP supports failover when SSL accelerator cards or integrated chips fail. By default, this feature is disabled and BIG-IP processes SSL using the main CPU(s). This reduces performance for most sites.

BIG-IP supports failover for the SSL accelerator hardware, as follows:

SSL HardwareFailover Support
Rainbow SSL CardsFully supported
Broadcom SSL CardsUnsupported for failover
BIG-IP Switch AppliancesFully supported
nCipher FIPS cardsFully supported in BIG-IP version 4.5 PTF-04 and later

You can enable support for SSL proxy failover using the Configuration utility or the command line.

Configuration utility

To enable SSL proxy failover using the Configuration utility, perform the following steps:

  1. From Configuration utility, click System.
  2. Click the Advanced Properties tab.
  3. Within the SSL Proxy section, click the sslproxy failover checkbox.
  4. Click Apply.

Command line

To enable SSL proxy failover using the command line, perform the following steps:

  1. From the command line, type the following command:

    bigpipe global sslhardware failover enable

  2. Verify that the feature is enabled, by using one of the following methods:

    • Type the following command:

      bigpipe global sslhardware failover show

    • Edit the /config/bigip.conf file and locate the following line:

      global sslhardware failover enable
