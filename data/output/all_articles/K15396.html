Issue

Old Behavior

In versions prior to BIG-IP 11.4.0, the BIG-IP system does not impose a default limit for Internet Control Message Protocol (ICMP) packet size, other than the maximum size of ICMP packets in networking.

New Behavior

Beginning in BIG-IP 11.4.0, the BIG-IP system drops or does not respond to ICMP packets sent to a self IP address, a virtual server address, or through a NAT or SNAT, which exceed the size specified by two new database variables.

  • IPv4 dos.maxicmpframesize default value 1480 bytes
  • IPv6 dos.maxicmp6framesize default value 1460 bytes

Note: To enable this DOS feature for 11.5.0 and later, the BIG-IP AFM system must be provisioned, but you do not have to configure it in any way.

[Dos.MaxICMPframeSize]
default=1480
type=unsigned_integer
min=0
max=65515
realm=common
scf_config=true
display_name=Dos.MaxICMPframeSize

[Dos.MaxICMP6frameSize]
default=1460
type=unsigned_integer
min=0
max=65495
realm=common
scf_config=true
display_name=Dos.MaxICMP6frameSize

Note: A SNAT, by default, does not pass ICMP traffic. For more information, refer to K7366: Configuring the BIG-IP LTM to pass ICMP traffic.  

Impact

The BIG-IP system does not respond to ICMP packets (such as ping) sent to a self IP address, a virtual server address, or through a NAT or SNAT, that exceeds 1500 bytes.

Network protocol headers, such as Virtual Local Area Network (VLAN) information, are included when calculating the ICMP packet size. As a result, you may reach the maximum ICMP packet size limit with about 50 bytes less ICMP data than the configured limit.

Note: This behavior does not apply to the management IP address.

Recommended Actions

While the maximum configurable ICMP frame size is 65,515 bytes for IPv4 and 65,495 bytes for IPv6, unnecessarily increasing this value may put your BIG-IP system at risk for a denial-of-service (DoS) attack. However, if necessary, you can increase or decrease the limit by configuring the applicable database variable using the TMOS Shell (tmsh).

For example, you can increase the maximum allowed ICMP packet size to 3000 bytes by typing the following command:

tmsh modify /sys db dos.maxicmpframesize value 3000
tmsh modify /sys db dos.maxicmp6framesize value 3000
