Issue

Error Message

warning chmand[<PID>]: 012a0040:4: <PSU_number> Status input lost

In this error message, note the following:

  • <PID> is the process ID of the chmand process.
  • <PSU_number> is the power supply unit slot number.

For example:

warning chmand[8484]: 012a0040:4: PSU1 Status input lost

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The LCD screen

Description

This message occurs when the following condition is met:

  • A power supply unit is insufficiently powered or malfunctioning.

Impact

The power supplied to the PSUs is insufficient to power the system, or the PSU is malfunctioning. Power redundancy for the BIG-IP system may be compromised.

Recommended Actions

To troubleshoot BIG-IP power supply issues and determine the PSU status, refer to K52015891: Troubleshooting BIG-IP power supply issues.
