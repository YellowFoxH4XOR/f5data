Known Issue

This is the result of a known issue. The Configuration utility may crash when displaying production rules, if you have configured five or more production rules.

F5 Networks Product Development tracked this issue as CR47917 and CR47918 and it was fixed in 3-DNS version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the 3-DNS Release Notes.

This problem still exists in the 4.6 software branch.
