Topic

The ARP and routing tables are integrated on BIG-IP. One route entry uses 136 bytes of memory and a small amount of additional memory to maintain the table. There is not a specific limit for the number of entries that can be stored in this table; you can store as many entries as allowed by the amount of memory available on your system.

The routing table competes for memory with other BIG-IP processes. This changes the amount of memory available at any given time; therefore, it is impossible to predict a typical maximum size for the table. Current BIG-IP platforms are typically equipped with at least one Gigabyte of RAM, making it fairly unlikely that you will run out of memory for route or ARP entries.
