Topic

Running the qkview utility and a tcpdump simultaneously from the Configuration utility may cause the Configuration utility to become unresponsive. This behavior is not due to a bug; the Configuration utility opens additional processes to monitor both the qkview and tcpdump process. Both the qkview and tcpdump utilities are capable of capturing a large amount of data that can overwhelm the monitor process of the Configuration utility.

This behavior is more likely to occur when the following two conditions are met:

  • The tcpdump utility is run with no limit or filtering from the Configuration utility
  • The system is handling a large amount of traffic

F5 Technical Support recommends that you run tcpdump and qkview from the command line, if required to capture the information simultaneously.
