To set the timezone on a BIG-IP system:

  1. From the command line, type the following command:

    config

  2. From the menu, select Set Timezone.
  3. Select the entry that best represents your timezone and press Enter.
  4. Press any key to continue.
  5. Quit the config program to return to a prompt.
