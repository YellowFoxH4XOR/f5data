Known Issue

This is the result of a known issue. The BIG-IP system sets hardware acceleration to None for newly created virtual servers. After creating a virtual server with a FastL4 profile and a pool with an assigned monitor, the PVA mode is set to None for the virtual server. If the monitor is removed from the pool configuration, the PVA mode changes to Full.

F5 Product Development tracked this issue as CR75695 and it was fixed in BIG-IP LTM 9.1.3, 9.2, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
