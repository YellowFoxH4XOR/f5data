Topic

For the BIG-IP DNS (formerly known as BIG-IP GTM) system to add a destination BIG-IP device as a server object, the system must first establish an SSH iQuery connection with the device to configure it for use with iQuery. Without initial SSH access to the destination device, the BIG-IP DNS system cannot establish subsequent iQuery communication and the destination device appears unavailable.

For the SSH communication to work, you must configure the BIG-IP destination device SSH IP Allow setting to allow access from the BIG-IP DNS device IP addresses.

After you configure the BIG-IP device to allow SSH access, you can run the BIG-IP DNS device command-line utility bigip_add to exchange iQuery SSL certificates with the destination BIG-IP system. To perform these functions, the bigip_add utility must communicate to destination BIG-IP devices using the SSH protocol.

Description

Configuring SSH access between the destination device and the BIG-IP DNS system

  1. Log in to the Configuration utility of the BIG-IP destination device.
  2. Navigate to Network > Self IPs.

    Note: Steps 3 through 5 are required when communication from the BIG-IP DNS device will connect to a self IP address. You can skip these steps if communication will use the BIG-IP management IP address.

  3. Click the self IP address on which the device will access the BIG-IP DNS system.
  4. For Port Lockdown, click Allow Default or Allow Custom (include Default).

    Note: Alternatively, you can click Allow Custom and, for Custom List, add TCP 22, TCP 4353, UDP 4353, and any other services required for your deployment.

  5. Click Update.
  6. Navigate to System > Platform.
  7. For SSH IP Allow, click Specify Range and enter the IP address(es) or IP address range(s), including the BIG-IP DNS device(s) to which you want to grant SSH access to the BIG-IP device.
  8. Click Update.

Note: For more information about configuring the BIG-IP device allowable IP address ranges for SSH access, refer to K5380: Specifying allowable IP ranges for SSH access.
