K10370: The 'Require the Admin to present a valid certificate to logon' setting is not applied to realm administrators

Known Issue

This is the result of a known issue. If you enable the Require the Admin to present a valid certificate to logon setting on the Device Management : Security : Admin Access Security page, realm administrators are able to logon to the FirePass Administrative Console without presenting a certificate. Currently, FirePass only enforces this setting for the superuser administrator account.

Note: The superuser administrator account is configured on the Device Management : Security : Admin Name and Password page. Realm administrator accounts are configured on the Device Management : Security : Administrative Realms page.

F5 Networks Product Development is tracking this issue as CR125882.
