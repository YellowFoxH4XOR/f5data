Description
FastL4 virtual server on VXLAN on Tenants on F5OS (Velos / rSeriese) does not processing traffic.
3 Way Handshake is failing as last Ack from client does not reach to tenant, even though patition/rSeries receiving it.

Environment

  • F5OS Tenants
  • Velos / rSeries
  • FastL4 virtual server
  • FastL4 profile
  • PVA Acceleration: full

Cause

  •  Bug ID 1117637
     

Recommended Actions

  • Set workaround in Bug ID 1117637
    NOTE: Velos / rSeries are supporting ePVA, but not supported on NVGRE, VXLAN, Ether-IP, and IP-in-IP tunneling.
