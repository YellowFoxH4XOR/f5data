Known Issue

If you put forward slashes in policy rule names, the system cannot correctly display the names. 

This issue occurs when the following condition is met:

  • You create a policy rule name that contains forward slashes.

Impact

When using the Configuration utility, you are unable to view the policy rule that contains forward slashes.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the Configuration utility, the system incorrectly displays policy rule names that contain forward slashes, and generates incorrect links.

Resolution

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to view and edit policy rule names that contain forward slashes. For information regarding tmsh policy commands, type the tmsh help ltm command, or refer to the BIG-IP TMOS: Implementations guide.
