Description

APM SP initiated SAML on BigIP as IdP throws following error

SAML SSO fails with error: Didn't Received Saml Sign URI, err 16

Environment

  • BIG-IP APM

Cause

This logs is seen in /var/log/apm when debug is turned on for SP initiated SAML on BigIP as IdP

Recommended Actions

This message can be ignored, as it doesn't indicate any error, though it looks like an error.  Check on the following logs to identify if the SAML is working.

A typical working logs should like the following

Sep  5 16:54:05 bigip17113.joseph.loc debug tmm5[23385]: 014d0501:7: :::Didn't Received Saml Sign URI, err 16
Sep  5 16:54:05 bigip17113.joseph.loc debug tmm5[23385]: 014d0501:7: /Common/ap_aIdP:Common:3e3f5aed:Client initiated SSO config received in metadata. Meta-data: SAML_RES_LIST=&SAML_SSO=/Common/aIdP
Sep  5 16:54:05 bigip17113.joseph.loc debug tmm5[23385]: 014d0501:7: /Common/ap_aIdP:Common:3e3f5aed:SAML configuration: SAML_RES_LIST=&SAML_SSO=/Common/aIdP
[..]

If you don't see the following logs, verify if the IdP Url configured is correct. It should be:

<fqdn>/saml/idp/profile/redirectorpost/sso
