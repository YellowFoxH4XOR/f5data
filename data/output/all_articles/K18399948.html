Description

'NXDOMAIN' is a DNS response code received by a DNS resolver (i.e. client) when a request to resolve a domain is sent to the DNS server and it cannot be resolved to an IP address. An NXDOMAIN error response means that the domain does not exist.

Some LDNS servers might respond with NXDOMAIN for an AAAA query and BIND on BIG-IP will cache it. This is called "Negative Caching". This Negative Caching will cause BIND to respond with 'NXDOMAIN' for new incoming A-record queries, which might not be expected.

Environment

  • BIG-IP GTM/DNS
  • Listener
  • DNS profile
  • BIND

Cause

According to RFC 2308, this is correct behavior, but we can configure BIND to ignore such Negative response.

Recommended Actions

  1. Login Configuration Utility
  2. Navigate to DNS ›› Zones : ZoneRunner : named Configuration
  3. Add following statement in to the Options field and update:

max-ncache-ttl 0;
