Description

To support VMware Horizon View USB redirection in an APM integration use case the "Secure Tunnel" option needs to be enabled on all Horizon View Connection Servers (VCS) being load balanced. (see doc Manual Chapter : VMware Horizon View Requirements for APM Integration). The "External URL" of the Secure Tunnel feature on each VCS needs to contain FQFN of the VCS that the feature is being configured for.

The BIG-IP APM Access Policy requires a VPE object named "VMware View Policy" with "USB redirection" enabled within. Current View iApp templates will implement this automatically when "Yes, support USB redirection" is selected for question "Do you want to support USB redirection?".

K15041: VMware View and Horizon View iApp template

Note: APM does not support Windows Media Multimedia Redirection (MMR) however since APM does support USB and Client Drive redirection MMR may function. PD has created ID 816525 to track APM support for MMR.

Environment
  • BIG-IP Access Policy Manager (APM)
  • Virtual Policy Editor (VPE)
  • VMWare Horizon View Server (VCS)
  • VMWare Horzon View client.

Cause

The configuration of the APM or VCS server is not correct.

Recommended Actions
 
Verify the configuration of the APM and VCS server.

Verify the configuration on the APM:
  1. Login to the Big-IP Admin GUI
  2. Navigate to Access>Profiles / Policies>Access Profiles (Per-Session Policies).
  3. Click on the "Edit" icon for the VMware Horizon View Access Policy.
  4. Click on the VMware View Policy object.
  5. In the "USB redirection" drop down select "Enabled."
  6. Click Save.

Verify the configuration on the VMware Horizon Connection Server:

  1. Login to the VCS
  2. Navigate to View Configuration>Servers.
  3. Select the Connection Server tab.
  4. Select the Connection Server.
  5. Click on Edit.
  6. Enable "Use Secure Tunnel connection to machine" checkbox.
  7. In the "External URL" field enter the FQDN of the VCS Server.


Additional Information

When connected to a virtual desktop via a View client there is a drop down menu at the top of the connection screen labeled "Connect USB Device". The following options in that drop down menu can help you understand the state of USB redirection functionality:

1. "USB redirection is disabled" - the APM is not configured to implement USB redirection
2. "USB Unavailable" -  APM is configured to implement USB redirection however "Secure Tunnel" is disabled or misconfigured on the VCS
3. "No suitable USB devices available" - USB redirection is implemented and working however there is no USB device on the host client device compatible for USB redirection to the virtual desktop
4. One or more USB devices are listed - USB redirection is implemented and working
