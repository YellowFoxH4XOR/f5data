K08242019: ASM/WAF policies and event logs don't load from the GUI

Type
Support Solution
Published
2022-10-11
Updated
2023-10-17
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
  • BIG-IP ASM: 15.1.6
Source
https://my.f5.com/manage/s/article/K08242019

Description

Suddenly WAF/ASM policies don't show in the GUI. The page keeps loading for a few minutes but doesn't show the policies or event logs.

  • Navigating to Security ›› Application Security : Security Policies : Policies List, takes a very long time.
  • Even after waiting for 2-3 minutes, it doesn't show the list of existing ASM policies.
  • No error message is shown in the GUI.
  • The event logs also doesn't show any entries.

Environment

  • BIG-IP with ASM provisioned
  • Keep getting the following error in catalina logs:
    "Error in HttpJSONClient: java.net.SocketTimeoutException: Read timed out"

Cause

This may be caused due to REST/GUI components not functioning properly.

Recommended Actions

Restarting GUI related daemons should fix this issue. Command below:
# bigstart restart restjavad httpd tomcat restnoded

    Note: Running the above command should not impact traffic. However, the GUI may be inaccessible for a few minutes. If it's a critical device, executing the command in a maintenance window is always recommended.
