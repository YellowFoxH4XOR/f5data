Description

BIG-IP sends a lot of ICMPv6 Neighbor Advertisement packets for link-local addresses when enabling a trunk interface.

Environment

  • Network interface
  • Trunk

Cause

This is normal behavior when a trunk member comes up, so the FDB table on the upstream switch can be refreshed.

Recommended Actions

There is no action required as this is intended behavior.

If IPv6 is not in use, and you would like to prevent these ICMPv6 Neighbor Advertisement packets from being sent, then you may disable IPv6:

tmsh modify /sys db ipv6.enabled value false

Important: There is no way to disable ICMPv6 Neighbor Advertisement for link-local addresses individually, setting ipv6.enabled to false disables all IPv6 functionality.
