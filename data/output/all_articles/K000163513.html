K000163513: BIG-IP DNS returns ICMP unreachable responses for uncached DNS queries when using mixed-address-family pools

Type
Support Solution
Published
2026-10-01
Updated
2026-10-01
Applies to
  • BIG-IP
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K000163513

Description

BIG-IP DNS intermittently returns an ICMP Destination Unreachable (port unreachable) response for uncached DNS queries instead of forwarding them to the backend DNS server.

Environment

  • BIG-IP DNS
  • Listener configured with a SNAT pool
  • The referenced server pool contains a mix of both IPv4 and IPv6 members

Cause

Load balancing fails when a listener configured with a SNAT pool selects a pool member from a mixed-address-family pool that does not match the address-family of the SNAT pool. Consequently, BIG-IP DNS returns an ICMP UDP port-unreachable response (for example, when a listener using an IPv4 SNAT pool selects an IPv6 pool member).

Recommended Actions

Configure separate server pools for each address family when using a SNAT pool:

  1. Assign only IPv4 members and the IPv4 SNAT pool to IPv4 listeners.
  2. Assign only IPv6 members and the IPv6 SNAT pool to IPv6 listeners.
  3. Do not reference a shared mixed-address-family pool on an address-family-specific SNAT pool listener.
