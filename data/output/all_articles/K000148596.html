K000148596: Unassign Self Service license keys in MyF5

Type
Support Solution
Published
2024-12-17
Updated
2026-03-12
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K000148596

Description

You need to move a BIG-IP VE to a new location or use the license key on a different BIG-IP VE and this license key is provided by the MyF5 Self Service for Flex Consumption Program (FCP).

Environment

  • FCP Contract started January 2025 or later
  • BIG-IP Virtual Edition (VE)
  • MyF5 Customer Portal
  • Editor/Admin access to MyF5 Subscriptions

Cause

The MyF5 Self Service for Flex Consumption Program (FCP) offers the ability to manage license keys. This includes unassigning license keys, sometimes referred as performing an "allow move",  which enables some of the following scenarios.

  • Moving a BIG-IP Virtual Edition (VE) and keeping its current license key. 
  • Repurposing an existing license key on another BIG-IP VE.

Important: Unassign allows the key to be reused, but does not stop billing usage. If you no longer want to be billed for usage on this license key, you need to terminate it per Terminate Self Service license keys in MyF5.

Recommended Actions

  1. Logon to MyF5 and open the active FCP Subscription.
  2. Locate the relevant license key. It should have a status of "Active".
  3. Click the "Edit" link to the right.
  4. From the slide out menu, select Unassign from the Actions dropdown list.
  5. Click Submit. Allow 15 minutes to process this request.
  6. When its status reads "Ready to activate" this key is ready for re-use. A screen refresh may be necessary to see this update.
    Note: If this request isn't successful after 30 minutes, please contact F5 Support.
  7. Reassign this key on another BIG-IP VE or reactivate it on the same BIG-IP VE in its new location per Licensing the BIG-IP.

Important: When a license key is unassigned from the BIG-IP Virtual Edition, a new license should be applied to that BIG-IP VE or this BIG-IP VE should be retired altogether, whether it's deleted or its license removed.
