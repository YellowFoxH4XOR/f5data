Description

This article provides a clear, structured framework for compiling and submitting Distributed Cloud (XC) support cases. It emphasizes the key information required to streamline troubleshooting. Supplying complete, well-organized, and accurate details upfront significantly enhances resolution efficiency and leads to faster outcomes.

Environment

  • F5® Distributed Cloud (F5 XC)
  • HTTP Load Balancers
  • WAF
  • Customer Edge

Cause 

To report an issue and engage a support engineer.

Recommended Actions

  1. Gather information

Before contacting the F5 Distributed Cloud (F5 XC) support team, it is recommended to prepare the following that are required to address your issue at the earliest:

 

    1. For General issues
      • What is the namespace?
      • Which Distributed Cloud Service is impacted? (e.g. HTTP Load Balancer, k8s , CE, etc...)
      • What is site name, load balancer or so?
      • Description of problem and symptoms (e.g. screenshot of error message, HAR file, logs, dig output)
      • When did the problem start (date and time zone)?
      • What troubleshooting or testing has been done?
      • Steps to reproduce the issue?
      • Is this a new implementation or was it working before? If so, what has been modified?
      • Is there any workaround in place?
      • What browser are you using?
    1. For troubleshooting intermittent / sporadic connectivity. Example : 5xx Errors or similar
      •  Information from section (a) 
      • Public source IP address of the impacted client/testers.
      •  Scope of impact (all users, some users, users of a specific carrier or region, etc.) 
      •  Traceroutes to HTTP LB, CE or VIP from affected clients, if available.
      •  Packet capture on client, if available.
      •  Testing account/credentials (if necessary).

 

    1. Customer Edge issues
      • How was the CE deployed?
        • Using XC published Terraform.
        • Manually deployed instances using images.
      • Describe the topology in which the CE is deployed.
        • Site type (ingress-egress/ingress only/appstack)
        • Node size (CPU, memory, disk) / instance type if cloud deployment
        • Provider (AWS/Azure/GCP/VMware/KVM/Bare metal/etc.)
        • Gateway type (Internet gateway/ NAT gateway)
        • External FW/ proxy present?
        • Region name if deployed on public cloud
      • What is the site name?
      • Can the CE reach the internet?
      • Are there any DNS resolution issues?
      • Are any of the required endpoints unreachable?
      • Are there any error messages on the CE service status?
      • Provide a screenshot of the secure mesh site dashboard and the message if a software update has failed.

     

    1. Open Support Case via
      1. Customer portal
      2. Email the compiled information to support@cloud.f5.com. or Japan-support@f5.com . It will automatically open a new case support case.
      3. Phone
