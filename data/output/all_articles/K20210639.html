Description

Configuration fails to load, with the following error message:
error:0607907F:digital envelope routines:EVP_PKEY_get1_RSA:expecting an rsa key:p_lib. c:287:

This error message will be displayed in /var/log/ltm log and when running the following command:  tmsh load sys config verify

Environment

BIG-IP system with new SSL certificate (Device Certificate)

Cause

Device Certificate's private key is not an RSA key. DSA and ECC private keys are not currently supported for the Device Certificate.

Recommended Actions

Replace the certificate with one which uses an RSA private key.

None
