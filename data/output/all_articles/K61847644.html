Known Issue

An ePVA-accelerated connection may fail when the destination MAC address changes

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system has an embedded Packet Velocity Acceleration (ePVA) chip. For more information, refer to K12837: Overview of the ePVA feature.
  • Your BIG-IP configuration includes one or more virtual servers with an associated FastL4 profile.
  • A flow is accelerated with a destination MAC address that changes while being accelerated.

Impact

Client connections are prematurely closed.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • ePVA-accelerated connections intermittently fail.
  • When viewing network packet captures, your BIG-IP system sends packets with stale destination MAC addresses.

Workaround

To work around this issue, you can disable the FastL4 profile's ePVA acceleration option. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure may increase CPU use because TCP connections are subsequently processed in software by the Traffic Management Microkernel (TMM).

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To disable ePVA, use the following command syntax:

    modify ltm profile fastl4 <profile_name> pva-acceleration none

    For example, to disable ePVA for a profile named example_fastL4, type the following command:

    modify ltm profile fastl4 example_fastL4 pva-acceleration none

  3. Save the configuration by typing the following command:

    save sys config
