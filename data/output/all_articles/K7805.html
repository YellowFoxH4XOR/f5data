Known Issue

This is the result of a known issue. When a user accesses an Adobe Flash file through a Portal Access Web Application, a memory leak in the Adobe Flash rewrite module for the FirePass reverse proxy engine causes increased memory utilization. If users frequently access Adobe Flash files through Portal Access Web Application Favorites, the resulting high memory utilization may cause the FirePass controller to crash.

F5 Product Development tracked this issue as CR79891 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, cumulative hotfix HF-600-15 has been issued for FirePass version 6.0 and cumulative hotfix HF-601-4 has been issued for FirePass version 6.0.1. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
