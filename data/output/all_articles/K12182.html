Known Issue

This is the result of a known issue. In BIG-IP ASM 9.4.4 through 9.4.8 , when the Auto Apply Policy After Update option is enabled on the Attack Signatures Update screen, BIG-IP ASM does not automatically apply new and updated attack signatures. The BIG-IP system will not enforce new or updated signatures in the security policies to which they should be assigned.

F5 Product Development tracked this issue as ID 221032 (formerly CR91939) and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can enforce the new and updated signatures by reapplying the policy. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. On the Main tab of the Application Security navigation pane, click Policies List.
  3. Click on the name of the security policy of which you want to update the signatures.

    The Security Policy Properties screen opens.
  4. Click Apply Policy.
