K000138935: NGINX default error response page shows version

Type
Support Solution
Published
2024-03-16
Updated
2025-04-02
Applies to
  • NGINX Products
  • NGINX Plus
Source
https://my.f5.com/manage/s/article/K000138935

Description

  • You have your NGINX Plus configured and deployed successfully.
  • You also notice, from to time, an invalid request reaches the NGINX, 
  • NGINX, having received invalid request, it responds with the default response page, where the page consists of NGINX version. 
  • You want to remove reference to NGINX version by modifying the response page.  

Environment

  • NGINX Plus
  • NGINX's default Response page

Cause

  • None

Recommended Actions

  • One can find almost all of the default error pages under directory, "/usr/share/nginx/html/nginx-errors/errors/".
  • However, Nginx recommends you create own custom page as opposed to modifying existing response page.
  • To do so, you would need to use "error_page" directive.
  • With the error_page directive, you can configure NGINX to return a custom page along with an error code.
  • Use of error_page directive, also gives you a better control over the type of information displayed with end users.
  • Additional examples and how-to guide can be found here, Handling Errors
