K000157030: GUI is not accessible after rebooting BIG-IP VE

Type
Support Solution
Published
2025-10-16
Updated
2026-01-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K000157030

Description

  • GUI is not accessible after rebooting BIG-IP VE 
  • BIG-IP host management loose management route after reboot.
  • When the issue occured, the system records the logs similar to the following

   /var/log/ltm

   MM DD HH:MM:SS hostname notice chmand[xxxx]: 012a0005:5: FPGA type requested = 0

   MM DD HH:MM:SS hostname err chmand[4230]: 012a0003:3: Kernel returns error : Network is unreachable

   MM DD HH:MM:SS hostname err chmand[4230]: 012a0003:3: Mgmt Operation:0 Dest:0.0.0.0

   MM DD HH:MM:SS hostname err chmand[4230]: 012a0003:3: Prefix Length:0 Gateway:X.X.X.X mgmt:0

   /var/log/kern.log

   MM DD HH:MM:SS hostname err kernel: kernel: [ 5.115334] piix4_smbus 0000:00:01.3: SMBus base address uninitialized - upgrade BIOS or use force_addr=0xaddr

Environment

  • BIG-IP Virtual Edition
  • BIG-IP Cloud Edition

Cause

F5 tracks this behavior as ID2186789

Recommended Actions

The workaround is to recreate the management route on every boot at F5 templates.

fix: add workaround for BZ 2186789
