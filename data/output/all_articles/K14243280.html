Known Issue

The Configuration utility may fail to display the network interface media settings of a 100 Gbps Quad (4-channel) Small Form-factor Pluggable (QSFP+) module.

This issue occurs when all of the following conditions are met:

  • You have a 100 Gbps QSFP+ module (OPT-0031) configured on your BIG-IP platform.
  • You attempt to view the following network interface media setting of the QSFP+ module using the Configuration utility:
    • Active Media Type
    • Media Speed

Impact

You are unable to determine the network interface media settings of the affected QSFP+ module from the Configuration utility; there should be no impact to the BIG-IP operations due to this issue.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the Configuration utility, when you navigate to Network > Interfaces to view the network interface media settings of the QSFP+ module, you observe the following interface settings:
    • Active Media Type is set to none.
    • Media Speed is set to Not Available.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to determine the network interface media settings of a QSFP+ module. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. Access tmsh by typing the following command:

    tmsh

  3. To determine the media settings of a QSFP+ network interface 2/1.0, type the following command:

    list net interface 2/1.0 media-active

    The output of the command may appear similar to the following example:

    net interface 2/1.0 {
    media-active 100000SR4-FD
    }
