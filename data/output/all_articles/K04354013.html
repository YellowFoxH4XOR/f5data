K04354013: Error Message: INSTALL operation not allowed

Type
Support Solution
Published
2022-06-14
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K04354013

Description
When trying to collect statistics from a BIG-IP device, the following error appears in the UI under the Statistics tab for the device:
Statistics collection error: agentInstaller failed: java.lang.illegalStateException: Installlapp on device <<Device's IP>> failed; java.net.ProtocolException: status 400, body:{"Code":400, "message":"INSTALL operation not allowed","referer": <<CM IP>>", "restOperationId": <<RestID>>","kind":"resterrorresponse"}. Please try again by clicking "Save and Close." below;

In the Big-IQ restjavad log file, you will see the following error:
[ERROR][<<Date Time Stamp>>][/cm/shared/stats-mgmt/agent-install-and-config-task/<<UUID>>/worker AgentInstallAndConfigTaskWorker] agentInstaller failed: java.lang.illegalStateException: Installlapp on device <<Device's IP>> failed; java.net.ProtocolException: status 400, body:{"Code":400, "message":"INSTALL operation not allowed","referer": <<CM IP>>", "restOperationId": <<RestID>>","kind":"resterrorresponse"}

On the corresponding BIG-IP you will see the following message in restjavad-audit log files:
ForwarderPassThroughWorker] {"user":"local/admin","method":"POST","uri":"http://localhost:8100/mgmt/shared/rpm-tasks","status":400,"from":"<<Device IP>>"}
ForwarderPassThroughWorker] {"user":"local/admin","method":"POST","uri":"http://localhost:8100/mgmt/shared/rpm-tasks","status":400,"from":"<<Device IP>>"}

Environment

  • Enable statistics collection in BIQ-IQ.
  • BIG-IP device not running in appliance mode.

Cause
By default restjavad.disablerpmtasks value is true.  This causes iApp RPM installation to be blocked.

Recommended Actions

  1. Set the restjavad.disablerpmtasks db variable to false
tmsh modify sys db restjavad.disablerpmtasks value false
tmsh save sys config

NOTE:  Changing the sys DB variable will cause any manual sync cluster groups to go out of sync.  You will also need to sync these cluster groups after making the change.

  1. After syncing the device cluster as applicable, run the following command on all the BIG-IP devices in the cluster:
tmsh restart sys service restjavad

Once restjavad successfully restarts, the BIG-IQ will be able to install the agent properly.
