K000150606: Errors while connecting SCP to BIG-IP from MAC OS units

Type
Support Solution
Published
2025-03-28
Updated
2026-09-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150606

Description

Customers are unable to SCP to BIG-IP from MAC OS units due non standard command used.

 

Error:

 

scp: Received message too long 1936094320

scp: Ensure the remote shell produces no output for non-interactive sessions.

 

Environment

BIG-IP LTM

MAC OS

SCP

 

Cause

Not standard command Used

 

Recommended Actions

 

Use the following command/syntax to SCP from MAC OS unit to BIG-IP

 

Example:

 

scp -vvvv -O usename@big-iptenant:/var/tmp/pcap.pcap .
