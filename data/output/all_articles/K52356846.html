Issue

Error Message

01071038:5: Loading keys from the file.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions are met:

  • Your BIG-IP/BIG-IQ system configuration is reloading.
  • Your BIG-IP/BIG-IQ system master key has been loaded into memory.

The Secure Vault feature provides security through the use of two cryptographic keys: the unit key and the master key. The unit key is securely stored in the system's (S)EEPROM hardware and is used to encrypt and decrypt the master key. The master key is stored on the file system and is used by the Master Control Program Daemon (MCPD) to encrypt and decrypt passphrases and passwords when loading the system configuration files.

Impact

There is no impact. This message is informational only and will be logged when the log level is set to notice.

Recommended Actions

None
