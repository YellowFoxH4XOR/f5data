Description

On BIG-IP LTM systems, attempts to access High Availability (HA) failover objects (such as traffic groups) or generate QKView files may result in errors such as:

Unable to process request /tm/cm/traffic-group/~Common~traffic-group-1. Service is unavailable

Unable to process request /tm/sys/diags/ihealth-request. Service is unavailable.

Environment

LTM

Cause

This issue occurs due to instability or repeated restarts of the restjavad process. When this process is not running properly, REST API-based services including the GUI for failover objects, and QKView generation become unavailable

Recommended Actions

Restart the restjavad process using the following command:


bigstart restart restjavad


After restarting, try accessing the affected pages or generate Qkview files again.
If the problem recurs, repeat the workaround as needed.
