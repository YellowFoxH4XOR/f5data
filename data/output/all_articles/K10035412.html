Known Issue

Layer 7 (L7) denial-of-service (DoS) remote log entries may contain empty values for the dos_attack_id and dos_mitigation_action fields.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM security policy is configured with a Remote Storage logging profile.
  • The BIG-IP ASM virtual server configuration uses a DoS Protection profile with the proactive bot defense method enabled.

Impact

Remote logs are inaccurate; the system reports empty values for the dos_attack_id and dos_mitigation_action fields.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Remote log entries contain empty values for the dos_attack_id and dos_mitigation_action fields.
