Description

  • Tenant software ISO is uploaded on GUI and image import status shows "File Transfer Initiated" but nothing changes.
  • Can't remove the status.
  • Time column doesn't have an entry.

Environment

  • F5OS
  • Tenant software import/upload
  • Image import status
  • File Transfer Initiated

Cause

  • Bug ID 1128633
  • Bug ID 1132745

Recommended Actions

If upload status stays the same for more than 5 minutes, then the upload likely failed.
The below confd command may display the cause:

show file transfer-operations

You can find the cause by running the curl command below:

curl -k -u 'admin:admin' https://<IP address>:8888/restconf/data/f5-utils-file-transfer:file/f5-file-upload-meta-data:upload

In the previous command note the following:

  • On VELOS the <IP address> is the partition IP address which you can find by running show running-config partitions. Or you can go to CHASSIS PARTITIONS in the GUI.
  • On an rSeries the <IP address> is the management address for the system.

Example output:

<upload xmlns="http://f5.com/yang/file/file-upload"  xmlns:f5-file-upload-meta-data="http://f5.com/yang/file/file-upload"  xmlns:f5-utils-file-transfer="http://f5.com/yang/utils/file-transfer">
  <meta-data>
    <upload-id>4BVT5LOs</upload-id>
    <file-path>images/</file-path>
    <name>BIGIP-15.1.6-0.0.8.ALL-F5OS.qcow2.zip.bundle</name>
    <status>file-size-mismatch-failed</status>
    <size>2096149975</size>
    <percentage-uploaded>0</percentage-uploaded>
  </meta-data>
</upload>

Try to upload/import again.
