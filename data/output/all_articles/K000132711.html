Description

Azure F5Telemetry_system_CL showing not connected
 

Environment

  • Azure Sentinel
  • Telemetry Streaming
     

Cause

Local default admin was disabled
 

Recommended Actions

Enable default admin account. 

1) Go to System > Platform.

2) Under the Admin Account section, uncheck Disable default admin, use alternate box.

3) Enter the password for the admin account.

4) Select Update.

None
