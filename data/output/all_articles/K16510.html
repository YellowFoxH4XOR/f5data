Issue

Old Behavior

In versions prior to 11.2.0, the BIG-IP system does not support SHA-2 signed Secure Sockets Layer (SSL) certificates for server-side SSL processing.

New Behavior

Beginning in BIG-IP 11.2.0, the system can now use SSL certificates that are signed using the SHA-2 hashing algorithm during server-side SSL processing. Server-side SSL processing includes the following:

  • The BIG-IP system sends SHA-2 signed SSL certificates (that are configured on the Server SSL profile) to the pool members
  • The BIG-IP system accepts SHA-2 signed SSL certificates originating from pool members

F5 Product Development tracked this change as ID 374685.

For information about using SHA-2 signed SSL certificates during client-side SSL processing, refer to the following articles:

  • K12139: BIG-IP Client SSL profile support for server SSL certificates signed using the SHA-2 hashing algorithm
  • K16324: The BIG-IP Client SSL profile now accepts Client SSL certificates signed using the SHA-2 hashing algorithm

Impact

The BIG-IP system can support a wider range of SSL certificates for server-side SSL processing by including the SHA-2 hashing algorithm.
