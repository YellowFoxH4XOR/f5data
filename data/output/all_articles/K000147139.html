K000147139: F5OS root user and bash access are local-only

Type
Support Solution
Published
2024-10-23
Updated
2025-02-05
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000147139

Description

The root user is a special user that cannot be remotely authenticated by a service such as LDAP, RADIUS, TACACS+, or. AD. It is the only user than can use the bash shell. The root user only uses local authentication.

The root user has Group ID 0 when looking at show system aaa output on the system but a remote group or user which is assigned GID=0 will have access denied.

ROLENAME        GID   USERS
-----------------------------
admin           9000  -
operator        9001  -
root            0     -
tenant-console  9100  -

Environment

F5OS-A or F5OS-C

Cause

Functions as designed

Recommended Actions

Use local authentication for root user and bash.

Additional Information

root user description from F5 rSeries Systems Administration Configuration manual:

"Created by the system. Used by the system administrator. Provides Bash shell access to the entire system including all components. The root user is the only user that has Bash access. The system root account can be accessed from the management IP address and from a console. The root role can only be accessed by the root user."

 

Securing / Hardening F5OS on rSeries - Remote Authentication excerpt:

"The root role (group ID 0) gives full access to the bash shell, and in some environments this role will be disabled by enabling appliance mode. Note that the root role is valid only for the built-in ‘root’ user account; no other users have access to the bash shell."
