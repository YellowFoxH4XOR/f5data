Description

Enabling Client Certificate Constrained Delegation (C3D) causes TLS 1.3 connections to fail at the Client Hello, or a lower TLS version such as TLS 1.2 will be selected if available.

When the handshake fails, a message similar to the following is printed to /var/log/ltm:

warning tmm[18890]: 01260009:4: 10.10.30.141:36576 -> 10.10.30.143:443: Connection error: ssl_hs_rxhello:10784: alert(70) unsupported version

Environment

  • C3D
  • TLS 1.3

Cause

TLS 1.3 is not supported with C3D prior to BIG-IP 17.1.1. This will result in a handshake failure, or selection of a lower TLS version if offered by the client.

Recommended Actions

Beginning in BIG-IP 17.1.1, the BIG-IP supports the combination of TLS 1.3 and C3D. If you would like to have the support for this combination on your BIG-IP system, you should plan for an upgrade to BIG-IP 17.1.1 and later.
