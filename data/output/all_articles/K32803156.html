Known Issue

When you configure your virtual server with a custom TCP profile, it fails to establish connections.

This issue occurs when one of the following conditions is met:

  • You configured your virtual server with a custom TCP profile, and you selected the following advanced option: Rate Pace.
  • You configured your virtual server with a custom TCP profile, and you selected the following advanced option: Tail Loss Probe.

Impact

The virtual server does not respond to connection requests.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you analyze network-level traffic for the virtual server, the virtual server does not respond to TCP requests.
  • Users are unable to establish a connection to the virtual server.
