Known Issue

The Traffic Management Shell (tmsh) connection table output may be incorrect for the manager user role.

This issue occurs when all of the following conditions are met:

  • You are logged in to the tmsh utility as a user with the manager role.
  • The manager role user does not have access to all configured partitions.
  • You run the tmsh show sys connection command.

The expected connection table output displays as follows:

01070822:3: Access Denied: user (<user>) does not have permission to view connection information

In this output, note the following:

  • <user> is your non-administrative user login.

Impact

This issue is cosmetic and does not affect production traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The tmsh show sys connection command output may appear similar to one of the following three examples:

    • You may view the correct and expected output that appears similar to the following example:

      01070822:3: Access Denied: user (<user>) does not have permission to view connection information

      In this output, note the following:

      • <user> is your manager role user login.
    • You may view incorrect output that appears similar to the following example:

      Data Input Error: ERROR: 'query_view' query reply did not contain a result object.

    • You may view a blank response with no error from the tmsh utility.

Workaround

To work around this issue, you can log in as an administrative user or view the output using the Configuration utility.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
