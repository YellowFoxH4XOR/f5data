Known Issue

The BIG-IP APM aced process may intermittently produce a core file.

This issue occurs when the following condition is met:

  • You shut down or reboot the BIG-IP APM system.

Impact

The aced process generates a core file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you shut down or reboot the BIG-IP APM system intermittently, and the system runs a bigstart stop of the aced process, the aced process generates a core file.
  • After you shut down or reboot the BIG-IP APM system, you notice a core file in the /shared/core file, similar to the following example:

    aced.bld1.62.167.core.gz

  • In the /var/log/ltm file, you observe log messages similar to the following example:

    notice logger: Started writing core file: /var/core/aced.bld1.62.167.core.gz for PID <aced pid>
    alert logger: Bigstart killing service aced
    notice logger: Finished writing <file size> bytes for core file: /var/core/aced.bld<build and version values>.core.gz for PID <aced pid>
