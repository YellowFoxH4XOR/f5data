Description

The Hybrid Flexible Consumption Program (HFCP) contract renewed with MyF5 Self Service for FCP, but the MyF5 customer portal doesn't list the license keys for the hardware. 

Environment

  • HFCP

  • iSeries/rSeries
  • Viprion/VELOS
  • MyF5 Customer Portal

Cause

This is expected. The MyF5 Customer Portal only lists software subscriptions for BIG-IP Virtual Edition on term subscriptions or from the Flexible Consumption Program (FCP).

The hardware already has its license applied from the previous contract. 

  • The license key and any add-on keys don't change. This includes any feature based subscription keys.
  • The entitlement dates automatically extend through the new contract

Reactivating the license is only necessary to update the service check date when preparing to upgrade the BIG-IP or if feature based subscriptions need to be removed or added.

Recommended Actions

No further action is required.
