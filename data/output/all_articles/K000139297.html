Description

While using the configuration utility, the screen for System -> Disk Management is empty, as it shows below. 

Normally there is information on the status of the raid and disks.

Also observed, the 'Select Disk' option shows the HD is Empty from System -> Software Management -> Image List:

Verify RAID status is 'replicating' - run the following command from CLI 'tmsh show sys raid':

tmsh show sys raid
-------------------------------------------------------------
Sys::Raid::Bay
Bay  Shelf  Name  Serial Number    Array Member  Array Status
-------------------------------------------------------------
1    1      HD2   WD-WX52E94DXVXS  yes           ok
2    1      HD1   WD-WXS2EC4HAL5F  yes           replicating

---------------------------------------------------------------------
Sys::Raid::Disk
Name  Serial Number    Array   Array Status  Model
                       Member                 
---------------------------------------------------------------------
HD1   WD-WXS2EC4HAL5F  yes     replicating   ATA     WDC WD2000CHTZ-0
HD2   WD-WX52E94DXVXS  yes     ok            ATA     WDC WD2000CHTZ-0

Although our last command showed RAID in 'replicating' state, to see the correct state of the RAID from a bash shell run the command 'array' .

array
Bay  name    t/s/r count         state         Serial Number
---  ----    -------------       -----         -------------
1.1  HD2     15/15/0             ok            WD-WXQ1EC422222
1.2  <empty>                                   <none>
2.1  HD1     15/15/0             ok            WD-WXQ1EC411111
2.2  <empty>                                   <none>

(Legend: t = total, s = synchronized, r = replicating)

Environment

  • BIG IP
  • RAID

Cause

RAID status show constant 'replicating'. 

Recommended Actions

Use the following steps to fix it:

  1. From CLI run "tmsh show sys raid" to check RAID status
    -------------------------------------------------------------
Sys::Raid::Bay
Bay  Shelf  Name  Serial Number    Array Member  Array Status
-------------------------------------------------------------
1    1      HD2   WD-WX52E94DXVXS  yes           ok
2    1      HD1   WD-WXS2EC4HAL5F  yes           replicating

---------------------------------------------------------------------
Sys::Raid::Disk
Name  Serial Number    Array   Array Status  Model
                       Member                 
---------------------------------------------------------------------
HD1   WD-WXS2EC4HAL5F  yes     replicating   ATA     WDC WD2000CHTZ-0
HD2   WD-WX52E94DXVXS  yes     ok            ATA     WDC WD2000CHTZ-0
  2. Run "tmsh restart /sys service mcpd"
    Important: Traffic impact - F5 recommends using this activity during a maintenance window, to avoid downtime. 
  3. After the service came back up, run again "tmsh show sys raid" to verify 'ok' status:
    tmsh show sys raid
-------------------------------------------------------------
Sys::Raid::Bay
Bay  Shelf  Name  Serial Number    Array Member  Array Status
-------------------------------------------------------------
1    1      HD2   WD-WX52E94DXVXS  yes           ok
2    1      HD1   WD-WXS2EC4HAL5F  yes           ok

---------------------------------------------------------------------
Sys::Raid::Disk
Name  Serial Number    Array   Array Status  Model
                       Member                 
---------------------------------------------------------------------
HD1   WD-WXS2EC4HAL5F  yes     ok            ATA     WDC WD2000CHTZ-0
HD2   WD-WX52E94DXVXS  yes     ok            ATA     WDC WD2000CHTZ-0

Results:

  • RAID's state with status 'OK'
  • Disk Management showing the HD with details
  • Boot location shows 'real' boot location
