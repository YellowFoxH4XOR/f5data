K49993490: APM virtual server resetting connections after upgrade with F5RST: Route domain not reachable (strict mode)

Type
Support Solution
Published
2021-10-07
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.0, 14.1.3, 16.0.1, 16.0.0, 14.1.4, 15.1.4
Source
https://my.f5.com/manage/s/article/K49993490

Description

After an upgrade, APM Virtual Server configured in non-default route domain, starts resetting connections.

If RST cause is enabled, you can see [F5RST: Route domain not reachable (strict mode)] on a packet capture.

Environment

  • APM Virtual Server
  • Route Domain

Cause

Bug ID 1010597: Traffic disruption when virtual server is assigned to a non-default route domain

Recommended Actions

Choose 'Parent Name = 0 (Partition Default Route Domain)' in the route domain that is failing.

Additional Information

None
