Description

It is sometimes necessary to determine how much traffic bandwidth usage an APM Session with a VPN tunnel has consumed. And the follow process can be followed to determine how much traffic bandwidth usage a given APM Session with a VPN tunnel has consumed, be if for a currently active APM Session, or a completed/terminated APM Session. 

Environment

Relevant environmental factors:

  • BIG-IP
  • APM Module provisioned and configured. 
  • Virtual Server with an Access Profile/Policy applied that allocates to the client/user an NA resource to provide VPN Tunnel connectivity.

Cause

N/A

Recommended Actions

To display the traffic bandwidth usage stats for a given currently active APM Session:

  1. In the GUI, navigate to Access > Overview > Active Sessions.
  2. Search the Active Sessions list for the active APM Session of interest. 
  3. Examine the Bytes In & Bytes Out columns to see the amount of inbound and outbound traffic bandwidth usage has occurred so far.

To display the traffic bandwidth usage stats for a given closed/terminated APM Session:

  1. In the GUI, navigate to Access > Overview > Access Reports.
  2. In the Report Parameters pop-up window, specify your search parameters and click Run Report.
  3. Search the All Sessions list for the APM Session-ID of interest. 
  4. Examine the Bytes In & Bytes Out columns to see the amount of inbound and outbound traffic bandwidth usage during that APM Session.
