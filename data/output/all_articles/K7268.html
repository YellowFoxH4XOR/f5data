Topic

Starting in FirePass version 6.0.2, FirePass Portal Access supports Microsoft Outlook Web Access 2007 and Microsoft SharePoint 2007. For information about upgrading, refer to the FirePass Release Notes.

To access Outlook Web Access 2007 and SharePoint 2007 in FirePass version 6.0.1 and earlier versions, use an Application Access Favorite or Network Access Favorite.
