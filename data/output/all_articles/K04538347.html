Description

If you have a CNAME Pool and any pool of AAAA, MX, NAPTR, or SRV type under the same WideIP, running the list gtm, list gtm wideip, or list gtm one-line command in TMSH will not show any pools for the WideIP.

For example, if you assign a CNAME pool cname_pool and an AAAA pool aaaa_pool to an AAAA WideIP www.example.com, then you run the command tmsh list gtm one-line, you will not get any pool configuration from the command:

# tmsh list gtm one-line
gtm wideip aaaa www.example.com { }

However, the expected command output should be like below:

# tmsh list gtm one-line 
gtm wideip aaaa www.example.com { pools { aaaa_pool { order 1 } } pools-cname { cname_pool { order 0 } } }

Environment

  • A WideIP with a CNAME type pool and an AAAA, MX, NAPTR, or SRV type pool.

  • You run the list gtm, list gtm wideip, or list gtm one-line command in TMSH.

Cause

Bug ID 675731: Certain types of GTM Pools not displaying while listing WideIPs

Recommended Actions

To work around the issue, you should follow the below steps one by one:

  1. Delete all the pools in GUI for the WideIPs which are impacted by the issue.

  2. Upgrade to v14.0.0 or above, where the bug ID675731 is fixed.

  3. Add back the WideIP pools that you have deleted in step one.

Note: These steps shall impact the resolution for the WideIPs, you may need to find a maintenance window to do the steps.
