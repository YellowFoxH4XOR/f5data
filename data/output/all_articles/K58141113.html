Description

After upgrading to BIG-IP v15.1.x from BIG-IP v13.x the configuration could not load.

When running command tmsh load sys config verify the following error is seen.
01070710:3: Cannot update_indexes/checkpoint DB object, class:bot_defense_profile_whitelist status:13 - EdbCfgObj.cpp, line 127
Unexpected Error: Validating configuration process failed.

At this moment, BIG-IP is sluggish as all resources is being used to process upgrade.

Environment
  • BIG-IP LTM
  • BIG-IP ASM
  • BIG-IP APM
  • Software upgrade
  • Configuration 
 

Cause

There is a duplicate IP address(es) in the firewall address list during the time of issue which caused the configuration to fail. You will need to remove one of the duplicate address lists.

Below is an example of a duplicate IP address in the firewall address list.
security firewall address-list /Common/ExampleIP {
    addresses {
        10.10.10.10 { }        
        10.10.10.10/32 { }     
    }
}

Recommended Actions

To resolve the issue, you will need to delete the duplicate IP address(es). Only one IP address should remain.

  1. Login to the BIG-IP command line.

  2. Make a backup of the bigip_base.conf file.
    cp /config/bigip_base.conf /config/bigip_base.conf.backup

  3. Edit the bigip_base.conf file.
    vi /config/bigip_base.conf

  4. Find the duplicate IP address and delete it. Leave only 1 IP address.

  5. Save the bigip_base.conf file.
    :wq!

  6. Reload the configuration file.
    tmsh load sys config

  7. Leave the device to load the configuration for several minutes. If needed, reboot the device once again.
