K000092481: Double quote support in "Variables" field of external monitor configuration

Type
Support Solution
Published
2022-10-20
Updated
2023-03-07
Applies to
  • BIG-IP
  • BIG-IP DNS: 15.1.0, 16.1.0, 17.0.0
Source
https://my.f5.com/manage/s/article/K000092481

Description

When a variable value has to contain double quotes there is no way to escape them using e.g. \"value\". 

DNS external monitor will still treat the Variable as '\"value"\' and not 'value'.

 

Environment

  • BIG-IP DNS
  • External Monitors with variables
  • Versions 15.1.0, 16.1.0, 17.0.0.1

Cause

The behavior is identified and is given a bug ID 1181733.
