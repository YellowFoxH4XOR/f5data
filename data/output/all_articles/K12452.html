Known Issue

This is the result of a known issue. Under the following conditions, accessing a website using basic authentication from a mobile device may fail (and cause all subsequent attempts to fail):

  • the user utilizes an i-mode browser
  • the user utilizes a FirePass portal access session
  • the first authentication attempt fails (for example, the user entered the wrong password)

The FirePass Controller interprets line feed characters (0x0A) as space characters (0x20) in a form field when a user utilizes i-mode. The i-mode mobile web browser is a lightweight HTML protocol (also referred to as C-HTML) used primarily in Japan. WAP (also referred to as HDML) is the mobile web browser platform used in the United States and elsewhere. To determine the protocol used by your mobile web browser, refer to your wireless carrier.

F5 Product Development is tracking this issue as ID 344626.

This issue has been fixed in cumulative hotfix HF-610-5, which has been issued for FirePass version 6.1.0.

Workaround

You can work around this issue by closing and re-opening the browser session on the mobile device, which will clear the field and allow logon at the first attempt.
