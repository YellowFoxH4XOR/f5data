Description

NGINX is not caching.

Cache status is MISS in access logs.

Environment

  • nginx version: nginx/1.17.9 (nginx-plus-r21)
  • Built by gcc 4.8.5 20150623 (Red Hat 4.8.5-39) (GCC)

Cause

Upstream server is responding with Cache-Control: Private.

Nginx respects the Cache-Control headers from upstream and does not cache responses with Cache-Control set to "Private" or with Set-Cookie.

A Guide to Caching with NGINX and NGINX Plus

Recommended Actions

Configure nginx to ignore these headers by enabling proxy_ignore_header directive as follows:

location ~* /nowplayinglistener {
proxy_ignore_headers Cache-Control Set-Cookie; #ADD THIS
...
}
