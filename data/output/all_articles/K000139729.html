Description

While generating qkview via GUI, an error message, which indicates "guest" user login was disallowed, may be erroneously generated once.

May  8 16:27:00 slot1/bigip.local info ihealth[4075]: ihealth script started
...
May  8 16:29:11 slot1/bigip.local err mcpd[7937]: 01070827:3: User login disallowed: User (guest) is not an administrator, does not have a UID of zero, and has not been assigned a role on a partition.

 

Environment

  • Multi-blade BIG-IP system (i.e., VIPRION. including vCMP guest)
  • Generate QKView via the GUI.

 

Cause

Bug ID1586453. It is different from Bug ID566980.

 

Recommended Actions

If the error is generated while generating qkview via GUI, the error can be safely ignored.
You can generate the qkview via the CLI ("qkview" command) so as not to generate the error message.
