K000149415: Do I need to upgrade the APM Client when upgrading my BIG-IP APM software?

Type
Support Solution
Published
2025-01-22
Updated
2025-01-22
Applies to
  • BIG-IP
  • BIG-IP APM: 16.0.0, 16.0.X, 16.0.1, 17.X.X, 16.X.X, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0
  • APM Clients
Source
https://my.f5.com/manage/s/article/K000149415

Description

  • You want to upgrade your BIG-IP software version.
  • You need to verify if an upgrade to the APM Client is required following the system software upgrade.

Environment

  • BIG-IP APM
  • APM Clients
  • Upgrade

Cause

None

Recommended Actions

  • When you upgrade the software version of your BIG-IP APM system, a new version of the APM Client is included with the upgrade, and the APM Clients ISO file within the BIG-IP software ISO file becomes the active version upon upgrading the system software.
  • To find out the APM Clients version packaged with the BIG-IP system software version. Refer to K13757: BIG-IP Edge Client version matrix

Important: F5 does not support downgrading the APM Clients software to a lower version than what shipped with the BIG-IP OS. Doing so may cause the automatic Component Update to fail on client systems."   Per K23159056: BIG-IP update and upgrade guide | Chapter 22: Upgrade the BIG-IP Edge Client

Additional Information

None
