K61179363: Unable to access or delete ASM logging profile

Type
Support Solution
Published
2020-12-11
Updated
2023-02-21
Applies to

  • BIG-IP ASM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source

Description

You are unable to edit or delete an ASM logging profile. Error log message displayed in GUI:
Failed to load Logging Profile «/Common/All response»

Environment

  • BIG-IP ASM
  • Logging profile name contains '+' for e.g. 'All+response'
  • bigip.conf was copied from one device to another and loaded
  • When accessed from GUI, it fails to open

Cause
This occurs due to the '+' in the name of the logging profile.

Recommended Actions

Edit the name of the logging profile and load the config to resolve the issue.

  1. Access the BIG-IP via CLI and edit the /config/bigip.conf using preferred text editor.

  2. Change the name of the logging profile and remove the offending character. For example, change to 'All_response'.

  3. Then load the config using following command:
    tmsh load sys config

Additional Information

If a new logging profile is created using any of these characters: +!@# in the name field, the text will change to RED font and the 'Create' button will grey out.

If bigip.conf with the profile 'All+response' is loaded, there are no validation failures, hence the config loads successfully. However, attempt to access the profile from the GUI fails.
