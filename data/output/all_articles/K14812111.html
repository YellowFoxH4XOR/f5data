Description

When you are troubleshooting connectivity on a Big IP, it is generally helpful to see what Big IP is using to route traffic while viewing a packet capture in Wireshark.  

F5's ethernet trailer contains data that can be used in diagnosing a network traffic flow information.  This includes flow metadata, RST causes, and other TMM related information we frequently use for routing traffic.

The information from the F5 ethernet trailer is only ever stored in a capture file when tcpdump is ran on the Big-IP itself. This information is never sent out of the Big-IP to any destination, so there is no risk from the trailer being enabled.  

Environment

  • The latest version of Wireshark on any platform and modern operating system

Recommended Actions

Note: Depending on your current Wireshark version, you may need to update to the latest Wireshark version.

  1. Open Wireshark.  
  2. Go to Edit > Preferences (Ctrl+Shift+P)
  3. Select Protocols and type F5 to locate F5 Ethernet Trailers
  4. Ensure the following options are selected (all others are optional):
    • Populate fields for other dissectors
    • Perform analysis of trailer data
    • Summary display in info column: set to Full
    • Add RST cause string to info
  5. Click OK to close the preferences window
  6. Go to Analyze > Enabled Protocols (Ctrl+Shift+E)
  7. In the search bar, type F5 
  8. Ensure the following are selected: (before Wireshark version 2.6)
    • f5ethtrailer
    • F5 TLS
    • FILEINFO > f5fileinfo
    • Noise
  9. Ensure the following are selected: (Wireshark version 2.6 and later)
    1. F5 Ethernet trailer > f5ethtrailer
    2. FILEINFO > f5fileinfo

Additional information

F5 networks provides no support for third party products, including Wireshark; the intent of this article is strictly to instruct the reader on how to configure Wireshark to read F5's ethernet trailers.
