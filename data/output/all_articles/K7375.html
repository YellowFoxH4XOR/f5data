Known Issue

This is the result of a known issue. The BIG-IP GTM external monitor code does not clean up child process information reliably. As a result, the BIG-IP GTM external monitor can leave child processes in a defunct, or zombie state. If the zombie processes are not reaped from the process table, the system can eventually run out of process ID numbers.

F5 Product Development tracked this issue as CR76978 and it was fixed in BIG-IP GTM 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
