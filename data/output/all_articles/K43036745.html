Known Issue

The apmd process may fail to initialize.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a large number of access policy agents.
  • You are performing an operation that requires the apmd process to start.

    For example, your BIG-IP APM system is reloaded, you install a new image, or you manually restart the apmd process.

Impact

The BIG-IP APM system fails to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP APM system does not reply to requests sent to the /my.policy URL path.
  • In the /var/log/apm file, you observe error messages similar to the following example:

    01490207:3: SAML Agent XML thread specific data creation error: ERR_FAIL.

Workaround

To work around this issue, you can manually restart the apmd process. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM command line.
  2. To restart the apmd process, type the following command:

    bigstart restart apmd
