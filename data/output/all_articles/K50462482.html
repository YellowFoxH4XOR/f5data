Known Issue

TMOS Shell (tmsh) help for the BIG-IP LTM Server/Application State Protocol (SASP) monitor incorrectly lists the default mode as pull.

This issue occurs when the following condition is met:

  • You type the following command on a BIG-IP system with an affected software version:

    tmsh help ltm monitor sasp

Impact

This is a cosmetic issue. The command help information incorrectly displays the default mode as pull instead of the correct value of push.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The description of the mode parameter shown in tmsh help for the BIG-IP LTM SASP monitor incorrectly indicates the default value for the mode parameter as pull. However, the correct parameter, push, displays in the Configuration utility when you create a SASP monitor.
