Known Issue

This is the result of a known issue. The SSL::sessionid iRule command returns the current connection's SSL session ID. When you use the SSL::sessionid iRule command to specify an SSL session ID, and the SSL session ID includes a null byte, the session ID is truncated.

F5 Networks Product Development tracked this issue as CR57247, CR57248, and CR58395 and it was fixed in BIG-IP versions 9.1.2, 9.2.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
