Description

Viprion ISO install stuck at 0%

Environment

BIG-IP LTM v17.1.1

Viprion

Installing new ISO

Cause

Viprion systems replicate all ISO images to all blades, which can take some time. This is especially true for older blades using Hard Disk Drives, instead of new Solid-State Drives.

Recommended Actions

Wait for the system to update, which in some cases can take well over half an hour. Should it take more than an hour it would be best to investigate if the process is successful or not. For instance, the following issue: K95602348: Software installation stuck at 0%

Additional Information

You can use the following command on the primary blade to see the status of the boot volumes on the system:

 tmsh show /sys software status
