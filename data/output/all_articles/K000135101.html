Description

This article describes the steps to check for parent profile of a custom ltm profile


Environment

  • LTM
  • Child profile relates to parent default profiles 
  • CLI
  • tmsh
 

Cause

None
 

Recommended Actions

The following command will display the parent profile of an ltm profile
tmsh list ltm profile <name of the profile> defaults-from

For example, below command will show the output of web-acceleration profile whose default from parent profile "webacceleration".

tmsh list ltm profile web-acceleration defaults-from
ltm profile web-acceleration apm-enduser-if-cache {
    defaults-from webacceleration
}
ltm profile web-acceleration optimized-acceleration {
    defaults-from webacceleration
}
ltm profile web-acceleration optimized-caching {
    defaults-from webacceleration
}
ltm profile web-acceleration p-ramcache-v1 {
    defaults-from webacceleration
}
ltm profile web-acceleration webacceleration {
    defaults-from none  <== parent default profile
}
