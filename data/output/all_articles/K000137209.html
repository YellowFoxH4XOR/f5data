K000137209: VPN F5 agent changing the registry file value

Type
Support Solution
Published
2023-10-11
Updated
2023-10-11
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000137209

Description

  • You might have noticed that F5 VPN client edits registry keys
  • You have a security tool that notifies you that registry keys have been changed

Environment

  • You have an F5 agent installed

Cause

As a fix for the bug 427819, the F5 agent edits the registry key: Computer\HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run when VPN starts and again when it is closed.


 Recommended Actions

None, this is working as expected.

Additional Information

None
