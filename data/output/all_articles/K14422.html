Topic

This article applies to the BIG-IP 1600 and 3600 platforms. For information about other BIG-IP provisioning exceptions, and provisioning exceptions in BIG-IP 11.4.0 and later, refer to the following article:

  • K13988: BIG-IP module provisioning exceptions

Summary

In BIG-IP 11.3.0, the 1600 and 3600 platforms support provisioning a maximum of two software modules.

Description

In earlier versions of the BIG-IP software, the 1600 and 3600 platforms allow you to provision three or more modules.

This change is due to the increased memory footprint of the BIG-IP software in BIG-IP 11.3.0, and the resources available on the 1600 and 3600 platforms. This constraint applies to any combination of three modules. In BIG-IP 11.3.0, F5 does not support the following provisioning examples:

  • All of the items in the Triple Product Combos and Quad Product Combos sections of the BIG-IP software and platform support matrix
  • The addition of the BIG-IP Analytics module to any two module combination, such as LTM/ASM or LTM/GTM
  • The BIG-IP Edge Gateway product, which consists of the following three modules: BIG-IP APM, WebAccelerator, and WOM

Installation Failure

If a 1600 or 3600 platform already has three or more modules provisioned, the BIG-IP 11.3.0 installation process will fail. For example, you will notice the following symptoms when the installation process fails:

  • The BIG-IP Configuration utility System > Software Management > Installed Images page will display the following error message:

    failed (Physical memory (XXXX MiB) insufficient for desired modules. See Solution #13988.)

  • The tmsh show sys software command will display a message that appears similar to the following example:

    ----------------------------------------------------------------------------------------------
    Sys::Software Status
    Volume Product     Version Build Active Status
    ----------------------------------------------------------------------------------------------
    MD1.2     BIG-IP 11.3.0 2702.0.13 no failed (Physical memory insufficient for desired modules. See Solution #13988.)


  • Error messages in the /var/log/liveinstall.log file will appear similar to the following example:

    info: WARNING: There were one or more errors detected during installation.
    info: Check the error messages and take the proper actions if needed.
    info: ERROR: UCS installation failed.
    info: Operation aborted.

Recommendations

To install BIG-IP 11.3.0 to a 1600 or 3600 platform, you must ensure that the device is provisioned with two or fewer modules. If three or more modules are provisioned, you must unprovision some modules.

Unprovisioning a module

  1. Log in to the BIG-IP Configuration utility.
  2. Click System.
  3. Locate the Resource Provisioning menu.
  4. In the Resource Provisioning (Licensed Modules) list, unprovision an active module by selecting None (Disabled) in the menu next to that module.
  5. Click Update.
  6. Click OK.

Once the BIG-IP system has the correct number of modules, you can proceed with any upgrade operations. If an upgrade has previously failed with the error messages detailed above, you can proceed to reinstall the desired version from the System > Software Management > Image List screen.
