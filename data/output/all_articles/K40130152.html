K40130152: HTTP protocol compliance failed: Unparsable request content *** header does not end with CRLF (\r\n)

Type
Support Solution
Published
2022-11-02
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.8, 15.1.7
Source
https://my.f5.com/manage/s/article/K40130152

Description

Violations detected:

  • HTTP protocol compliance failed
  • Unparsable request content
  • *** header does not end with CRLF (\r\n)
  • Requests may be incorrectly blocked or alerted

Environment

The violations may be detected if all conditions are met:

  • Software upgrade completed
  • ASM provisioned
  • ASM security policy applied
  • The client send requests with HTTP headers where there is no space following the header name and the : like in the example below: 
    Content-Type:text/html

Cause

ID1113881 Headers without space after the colon triggering HTTP RFC violation

Recommended Actions

To avoid the violation the preferred solution is to ensure the clients send the correct request with space after ':'
If that is not the viable solution, an iRule can be assigned to the virtual server that removes and re-adds the listed HTTP request headers. In the re-added headers there is the space following : correctly.

Example iRule:

when HTTP_REQUEST {
    set replace_header "Content-Type X-Header1 X-Header2"
        foreach header $replace_header {
            if { [HTTP::header exists $header] } {
            set header_value [HTTP::header value $header]
            HTTP::header remove $header
            HTTP::header insert $header $header_value
        }
    }
}

The list of the HTTP headers to remove and re-add can be customised in set replace_header 

If it is not predictable what HTTP headers are expected to trigger the violation, it possible to remove and re-add all HTTP headers. The impact of removing and re-adding all HTTP headers may be the increased CPU utilisation.

Example iRule:

when HTTP_REQUEST {
    set replace_header [HTTP::header names]
        foreach header $replace_header {
            if { [HTTP::header exists $header] } {
            set header_value [HTTP::header value $header]
            HTTP::header remove $header
            HTTP::header insert $header $header_value
        }
    }
}
