K89845482: Access Summary dashboard not populating with data

Type
Support Solution
Published
2022-02-25
Updated
2025-04-01
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X
Source
https://my.f5.com/manage/s/article/K89845482

Description
The BIG-IQ Configuration utility displays "0" for Monitoring >Access > Access Summary.

Environment

  • BIG-IQ version 7.x
  • BIG-IP APM 14.x

Cause
The BIG-IP APM instances need to be configured for remote logging to the DCDs.

Recommended Actions

  1. Monitoring Tab of BIG-IQ > Dashboards > Access > Remote Logging Configuration
  2. This screen displays each BIG-IP device in the BIG-IQ inventory on which the APM service has been discovered..
  3. For each unit that you wish to report Access Summary / Application Summary information to BIG-IQ, select the checkbox next to the instance HostName.  Then select the "Configure" button at the top.
  4. This configures each BIG-IP APM instance for remote logging to the DCDs.
