K000156867: How Do I Check BIG-IP client-ssl profile is configured on a TCP based virtual server?

Type
Support Solution
Published
2025-10-06
Updated
2025-10-20
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000156867

Description

You want to verify if a BIG-IP Client SSL profile is applied to a virtual server configured with TCP as the protocol. This check ensures SSL termination is set up correctly to handle secure client connections.

Environment

  • BIG-IP system
  • Virtual server configured with TCP
  • SSL termination required
  • Want to know if/which Client SSL profile applied

Cause

None

Recommended Actions

  1. Log into the BIG-IP Configuration Utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  3. Select the virtual server in question.
  4. In the virtual server's Properties, locate the SSL Profile (Client) row.
  5. Check if one or more Client SSL profiles are listed in the Selected box. If none are present, then no Client SSL profile is applied to the virtual server.
  6. If desired, add an appropriate Client SSL profile to enable SSL termination:
    1. Select the desired SSL profile in the Available box
    2. Click << to add the profile to the virtual server
    3. Click Update to save

Note:  If the "SSL Profile (Client)" and "SSL Profile (Server)" are not present, the selected Virtual Server "Type" does not support SSL termination
