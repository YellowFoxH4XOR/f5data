Description

Users who log in using Chrome browser are always getting prompted to open F5 Networks Endpoint Inspector or F5 Networks VPN (for those deployments that have a VPN) every time they connect to the APM.

Environment

  • BIG-IP APM v13 and later versions that uses F5 Helper Apps for endpoint inspection or VPN functionality
  • Chrome v77 and later versions

Cause

This behavior seems to be with the Chrome browser itself. In newer Chrome versions, the Always open these types of links in the associated app checkbox no longer appears. And since this option is gone, the browser has no way of remembering the user's previous choice; hence the user is prompted every time.

Note: The following link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.
"Always open these types of links in the associated app" checkbox is not displayed

Recommended Actions

  1. Use a different browser other than Chrome (such as IE, Firefox) or the BIG-IP Edge Client to connect to the APM
  2. Contact Google for a fix
