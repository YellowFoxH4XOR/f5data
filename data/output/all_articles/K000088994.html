K000088994: Do not run the NGINX Controller command helper using sudo

Type
Support Solution
Published
2021-06-21
Updated
2022-07-17
Source

Description

During Install of Nginx Controller you receive the message: "Do not run the NGINX Controller command helper using sudo"

 Environment

Ubuntu 18.04.5 LTS

 Cause

Running helper.sh as local root user.

 Recommended Actions

Don't run helper.sh as local root user. Run as local user with root privileges.

 Additional Information

root@SYSTEMNAME:/opt/controller-installer# ./helper.sh prereqs
