Known Issue

This is the result of a known issue. The BIG-IP ASM system sets the timestamp incorrectly for remote logging requests sent to an ArcSight server.

Starting in BIG-IP ASM version 10.1.0, you can configure the BIG-IP ASM system to log web application requests to a remote ArcSight server by navigating to the Logging Profiles section in the Configuration utility and selecting the predefined ArcSight entry from the Remote Storage field. When you configure the BIG-IP ASM to send the remote logging requests, the system incorrectly uses the numeric value of the month as the minutes value in the receiptTime (rt) field reported to the ArcSight server.

Log entry example:

rt=Jul 05 2010 17:54:41

The BIG-IP ASM will erroneously send the example log entry as follows:

rt=Jul 05 2010 17:07:41

Note: For more information about ArcSight data fields, refer to K11995: Data field definitions for ArcSight Remote Logging.

F5 Product Development is tracking this issue as ID 336661.

This issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
