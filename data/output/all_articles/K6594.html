Known Issue

This is the result of a known issue. BIG-IP Link Controller link statistics are either not returned or reported incorrectly. In addition, virtual servers will fail to load balance properly if they are configured to load balance based on link statistics, cost segments, and limits.

F5 Product Development tracked this issue as CR69131 and it was fixed in BIG-IP Link Controller 9.2.4. For information about upgrading, refer to the BIG-IP Link Controller Release Notes.
