Known Issue

The iprepd or merged processes may leak memory under certain conditions.

This issue occurs when all of the following conditions are met:

  • The IP Address Intelligence Service is enabled.
  • The BIG-IP ASM system is unable to connect to the IP reputation database server.

Note: This issue is similar to K73325927: The iprepd process may leak memory when using a forward proxy server. While the conditions are slightly different, the root cause for both issues is connectivity to the IP reputation database server.

Impact

A slow memory leak occurs, which may eventually affect other services and overall system performance.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system logs iprepd messages to the /var/log/ltm file that appear similar to the following example:

    err iprepd[1234]: 015c0004:3: Ssl error # 2
    err iprepd[1234]: 015c0004:3: SendReceive returns error -1 (recv error)

  • The BIG-IP ASM system logs merged messages to the /var/log/ltm file that appear similar to the following example:

    merged[2345]: 011b0900:3: TMSTAT error tmstat_merge: Cannot allocate memory.

  • The BIG-IP ASM system is not able to connect to the IP reputation database server using the tmsh show /sys iprep-status command:

    -----------------------------------------------------------------------
    Sys::IP Reputation Database Status
    -----------------------------------------------------------------------
    Last time the server was contacted for updates 10/24/2015 06:55:18
    Last time an update was received N/A
    Total number of IP Addresses in the database 0
    Number of IP Addresses received in the last update 0

Workaround

To work around this issue, you will need to either determine the cause of the connectivity issues between the BIG-IP ASM system and the IP reputation database server or disable the IP Address Intelligence Service.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
