Description

This Article details the steps required for taking the snapshot for the Prometheus database (DB) that comes in your Aspen Mesh Environment.

Environment

All versions of Aspen Mesh have Prometheus DB which is used by our Metrics Collector pod from the control plane. These steps were tested for version 2.23.0 of Prometheus.

Cause

None

Recommended Actions

Here is the procedure for taking the snapshot of the Prometheus DB: 

  1. Edit the metric-collector deployment to add the admin API flag to the configuration.

    k edit deploy aspen-mesh-metrics-collector -n istio-system 
    containers:
          - args:
            - --config.file=/etc/config/prometheus.yml
            - --storage.tsdb.path=/metrics-collector/tsdb
            - --web.console.libraries=/etc/prometheus/console_libraries
            - --web.console.templates=/etc/prometheus/consoles
            - --web.enable-lifecycle
            - --web.enable-admin-api

  2.  We will port forward the metrics collector service to access it locally.

    k port-forward -n istio-system svc/aspen-mesh-metrics-collector 19090

  3. You will take a snapshot of the Prometheus DB using a curl as we have already enabled the admin API.

    curl -XPOST http://localhost:19090/api/v1/admin/tsdb/snapshot {"status":"success","data":{"name":"<name of the snapshot>"}} 

  4. After the snapshot, you would need to copy them to your local machine.

    k cp -n istio-system aspen-mesh-metrics-collector-59b4545bd8-5g6r6:/metrics-collector/tsdb/snapshots/<name of the snapshot> -c metrics-collector . 

    This might take a long time depending on the amount of data/Size of the DB being copied. 

  5. Once you have the snapshot, we would disable the web.enable-admin-api by editing the metric-collector deployment to remove the admin API access. 

    k edit deploy aspen-mesh-metrics-collector -n istio-system
    containers:
          - args:
            - --config.file=/etc/config/prometheus.yml
            - --storage.tsdb.path=/metrics-collector/tsdb
            - --web.console.libraries=/etc/prometheus/console_libraries
            - --web.console.templates=/etc/prometheus/consoles
            - --web.enable-lifecycle 

Note: Be sure to remove the admin access so that not any other container locally can access the DB.

Additional Information

To check the version of Prometheus DB, run the following command:

k exec -it -n istio-system <metrics-collector-pod> -c metrics-collector -- /bin/./prometheus --version
