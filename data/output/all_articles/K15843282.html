Issue

Error Message

01071070:3: Failed to <action> file <filename> with error <errno>

In this error message, note the following:

  • <action> is the operation to be performed on the file.
  • <filename> is the name of the file.
  • <errno> is the error number associated with the failure.

For example:

01071070:3: Failed to change permissions to read-only for file /config/BigDB.dat.tmp with error 30

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The mcpd process fails to change permissions for the /config/BigDB.dat file to read-only.
  • The mcpd process fails to open the /config/BigDB.dat file.

Impact

If the permissions for the BigDB.dat file cannot be changed to read-only, you can still write to the file, which may result in unexpected behavior. If the mcpd process is unable to open the BigDB.dat file, the mcpd process will generate a core file to the /shared/core/ directory and exit, causing a traffic disruption or failover if the system is configured for high availability.

Recommended Actions

If the default permissions for the /config/BigDB.dat file were modified, you may be able to change them back to the default settings using the chmod 444 /config/BigDB.dat command from the command line.  

If the mcpd process generates a core file, you can open a support case with F5 Technical Support and upload the core file for analysis.
