Known Issue

This is the result of a known issue. The Stream profile is used to replace strings within a data stream. When configured for use with a virtual server, the Stream profile will listen to both the client and server sides and attempt to modify both requests and responses unless explicitly disabled using an iRule.

The Stream filter uses TCL to parse and replace data. TCL has a 4MB limit for a single allocation or connection. When this limit is exceeded, TMM will crash.

Virtual servers that are configured to use the Stream filter will cause TMM to crash when certain actions overflow the allocated amount of memory. For example, TMM will crash when the virtual servers are pushing large amounts of data and the expressions specified in the Stream filter utilize unlimited or partial matching capability that cause the 4MB limit to be exceeded. As a result, the BIG-IP LTM system reboots.

F5 Product Development tracked this issue as CR55382 and CR70146 and it was fixed in BIG-IP LTM 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
