Description

BIG IQ system cannot display and collect new logs. The Disk Usage of device partitions is above the threshold (80.0 percent).

To check the threshold of the disk you can navigate to:
BIG IQ > System > BIG IQ Data Collection > Health: folder /var and /var/named/lib are over the threshold.

From the command line the df -h command on BIG-IQ DCD shows that the /var folder is almost full for example:

Environment

BIG-IQ DCD

BIG-IQ CM

Cause

BIG-IQ DCD report that /var is above 80% disk free threshold. For more information please refer to Related Content section below.

Insufficient space in the /var folder on DCD

Old logs and statistics in /var folder on DCD

Recommended Actions

Clear /var folder of old files. You can use following commands to check what uses the most space in the /var folder on DCD:

find /var/ -xdev -type f -exec du {} \; | sort -rn | grep -Ev $(mount | awk '/\/var\// {print $3}' | sed -e :a -e N -e 's/\n/|/' -e ta) | head -20
 

du -a /var | sort -rn | grep -Ev $(mount | awk '/\/var\// {print $3}' | sed -e :a -e N -e 's/\n/|/' -e ta) | head -n 20

Delete or move old files to free the /var space.
