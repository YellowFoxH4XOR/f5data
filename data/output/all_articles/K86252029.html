Security Advisory Description

libpcap before 1.9.1, as used in tcpdump before 4.9.3, has a buffer overflow and/or over-read because of errors in pcapng reading. (CVE-2018-16301)

Impact

A local attacker may be able to corrupt data or execute arbitrary code.

Security Advisory Status

F5 Product Development has assigned IDs 842829 and 844989 (BIG-IP and BIG-IQ) and CPF-25159 (Traffix SDC) to this vulnerability.
