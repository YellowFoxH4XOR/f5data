Known Issue

The net resolver may use an internal IP address as a source address for DNS queries.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system uses a wildcard forwarding virtual server.
  • You create a DNS resolver with a forward zone, and the zone contains a DNS server address that matches the forwarding virtual server network.
  • You create a network firewall policy that restricts traffic based on fully-qualified domain name (FQDN).

Impact

DNS queries fail due to an invalid source IP address.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If you create a net resolver with a forwarding zone that matches an existing wildcard forwarding virtual server, the system uses an incorrect internal IP address as the source. Upon listener lookup for the net resolver, the wildcard virtual server is matched to the forwarding zone, which results in a loopback IP address being used as the source IP address.
