Topic

The Advanced Assembly section of the BIG-IP WebAccelerator policy configuration is a text box for entering special strings that allow you to override system settings for a specific policy node, and enable features for the node that are normally disabled for the system. The features are applied to any requests or responses that match this node. Use a comma ( , ) character to delineate each string, even when each string is on a separate line in the text box.

Note: For information about configuring advanced assembly options, refer to the Specifying advanced assembly options section in the Policy Management Guide for the BIG-IP WebAccelerator System.

Note: Because the system-wide default setting for these features is false, you only need to set these features to false if you are overriding an inherited true setting from parent node. 

The following strings can be specified in the Advanced Assembly text box:

  • authAdapter=<module>
  • followRedirects=true
  • followRedirects=false
  • forceLastMod=true
  • forceLastMod=false
  • disableContentBasedIdentity=true
  • disableContentBasedIdentity=false

The authAdapter=<module> string allows you to specify the authentication adapter module you want the BIG-IP WebAccelerator to load and run for requests and responses that match this node. By default, no module is specified. Replace <module> with the name of the authentication adapter module to be used.

The followRedirects=true and followRedirects=false strings allow you to specify if the BIG-IP WebAccelerator will internally follow redirects for request and responses that match this node. The followRedirects=true string will cause the BIG-IP WebAccelerator to internally follow redirects unless certain conditions, such as protocol or domain changes, are met. The system-wide default setting is false.

The forceLastMod=true and forceLastMod=false strings allow you to specify if the BIG-IP WebAccelerator will attempt to generate a Last-Modified header for a response that matches this node. The forceLastMod=true string will cause the BIG-IP WebAccelerator to attempt to generate a Last-Modified header for the response. The system-wide default setting is false.

The disableContentBasedIdentity=true and disableContentBasedIdentity=false strings allow you to specify if the BIG-IP WebAccelerator will disable the content-based identity feature for this node. The disableContentBasedIdentity=true string will cause the content-based identity feature for this node to be disabled. The system-wide default setting is false.

Note: For more information about disabling content-based identity, refer to the Selectively disabling content-based identity section in the Configuration Guide for the BIG-IP WebAccelerator System.

Note: Disabling content-based identity for a node will also disable RAM Cache for objects matching the node. For more information, refer to K9631: RAM Cache behavior for objects when URL normalization is disabled.
