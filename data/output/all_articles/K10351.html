Known Issue

This is the result of a known issue. When a client sends an HTTP request to the BIG-IP WebAccelerator that contains a Proxy-Connection header, the request completes correctly, but the BIG-IP WebAccelerator logs the following warning message in the /var/log/wa/pvac.log file:

WA Warning: Request processing parsed as forward proxy mode but host manager did not find the information required

This warning message is benign, and may be safely ignored.

F5 Product Development is tracking this issue as ID 327101 (formerly CR119453).

Note: The Proxy-Connection header is not defined in the HTTP specification. The header was intended to provide a mechanism for negotiating a Keep-Alive connection between a given client and a given proxy server. When Keep-Alive connections are desired, you should use the Connection header defined in the HTTP standards specification instead.

Workaround

You can prevent logging of this error message by removing the Proxy-Connection header from the client request. To do so, use an iRule similar to the following:

when HTTP_REQUEST {
   if { [HTTP::header exists Proxy-Connection] } {
      HTTP::header remove Proxy-Connection
   }
}
