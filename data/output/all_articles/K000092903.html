K000092903: GUI intermittently shows "Unable to contact BIG-IP device" when using multiple tabs to manage the BIG-IP, or when multiple simultaneous users are accessing the device via the GUI

Type
Support Solution
Published
2022-12-01
Updated
2022-12-01
Source
https://my.f5.com/manage/s/article/K000092903

Description

Users managing the device using the web configuration utility (GUI) gets disconnected or kicked out of the session with message "Unable to contact BIG-IP device" even if there is good connectivity between the administrator's workstation and the BIG-IP.

 

This normally occurs on a BIG-IP which has considerably large configuration, specially involving partitions and SSL profiles, specially when a users opens multiple tabs for the GUI, or multiple administrators accessing the device simultaneously.

 

The underlying cause is that each browser tab would send a 'coloradvisory' probe towards the BIG-IP every 5 seconds. These probes trigger the BIG-IP to go through the list of partitions and profiles in the configuration, which then loads up mcpd. The result is a delay for mcpd to return the complete response chunk for the probe back to the clients' browser tabs, eventually resulting in the timeout. This is now being tracked as bug ID 1168245.

 

Decrypted packet capture for the management traffic would show that when the response to 'coloradvisory' request probes get delayed for 30 seconds, the browser would render the page with the message "Unable to contact BIG-IP device.".

 

Because there is no fix available at this time, the workaround is to increase the browser's polling interval and to increase the timeout value. See the recommended actions for details of the workaround.

 

Environment

BIG-IP with relatively large configuration (ie. partitions, SSL profiles, etc.)

Multiple users simultaneously accessing the GUI, or a user having multiple browser tabs accessing the same BIG-IP.

 

Cause

Bug ID 1168245

 

Recommended Actions

1. Remount /usr partition as read-write using the command:

mount -o remount,rw /usr

 

2. Edit the file /usr/local/www/xui/framework/scripts/variables.js, and modify the variables: time_updateXui to 8, and timeout_status to 60.


Default values are:

 

var time_updateXui = 5; // Seconds

var timeout_status = 30; //Timeout value for XUI status update

 

Change these values to:

 

var time_updateXui = 8; // Seconds

var timeout_status = 60; //Timeout value for XUI status update

 

3. Remount /usr partition back to read-only.

mount -o remount,ro /usr

 

4. Restart associated daemons:

bigstart restart httpd
bigstart restart tomcat
bigstart restart restjavad

 

 

Additional Information

None.
