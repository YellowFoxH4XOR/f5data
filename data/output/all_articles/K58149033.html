Security Advisory Description

F5 Access is the SSL Virtual Private Network (VPN) client for BIG-IP APM systems. It is available for both desktop and mobile platforms in their respective app stores.

For Android and Apple devices, F5 Access utilizes the operating system’s web browser (WebKit) to allow end users to satisfy authentication prompts and provide maximum flexibility for use with third-party cloud Identity-as-a-Service (IDaaS) providers. This feature is known as Web Logon Mode.

On January 26, 2021, Apple released an iOS security patch that prevents attackers from exploiting a security vulnerability in the operating system and WebKit browser components that allow an attacker to execute code on a vulnerable device. Because the F5 Access VPN client uses the operating system’s WebKit browser for Web Logon Mode, it is by extension also vulnerable.

Impact

An attacker may be able to exploit the vulnerability in iOS to execute code on the vulnerable Apple device.

Security Advisory Status

Because the F5 Access SSL VPN client uses the operating system’s WebKit browser for Web Logon Mode, it is by extension impacted by this Apple iOS vulnerability.

Security Advisory Recommended Actions

To mitigate this threat, F5 strongly recommends installing the Apple iOS security patch on all iOS client devices as soon as possible. For more information, please review the following statement from Apple on this issue:
