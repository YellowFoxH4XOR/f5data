What Happened?

  • I want to know how to setup a redirection rule to a www domain on http load balancers.

Environment

  • F5® Distributed Cloud HTTP load balancers

Resolution/Answer

To create a redirection rule on an HTTP Load Balancer:

  1. Visit the configuration of the corresponding load balancer, and click on Edit Configuration
  2. Scroll down to Routes Configuration and click on Configure
  3. Select Add item
  4. Go through the following steps in the form that appears:
    1. Select Redirect Route for the type of route
    2. Select ANY for the HTTP method
    3. Select Regex for the Path match, and set it to ^(.*)$ 
  5. In the Redirection parameters section select the following:
    1. Select HTTPS for protocol
    2. Set Host to the desired www domain
    3. Set Prefix Rewrite for Redirect Path and leave the Prefix Rewrite value empty
    4. Set the Response code to 302 (or 307 if you find it more appropriate)
    5. Click apply to save the redirect
    6. Click apply to save the route
  6. Scroll down and click on Save and Exit to save changes.

Note: Please test this on a test load-balancer or a throwaway domain before doing this on your production load balancer.
