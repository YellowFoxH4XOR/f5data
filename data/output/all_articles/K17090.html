Known Issue

The BIG-IP APM rewrite process may incorrectly handle HTML form action attribute.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The HTML form action attribute value is an absolute path.
  • The HTML form also contains a tag with value equal to action.
  • Client-side traffic is generated using the Internet Explorer 7, 8, or 9 browser.

In the following example, the form action attribute value is an absolute path and the img tag inside the form has the attribute id="Action":

 <script></script>

  <form id=theForm action="/absolute/path">
    <img id="Action">
  </form>

  <script>
    theForm.submit();
  </script>

The system may not properly rewrite the form action attribute using portal access, and the form is not submitted.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using portal access, HTML forms are not submitted.
  • When using portal access, requested pages fail to display.
  • Web applications malfunction or fail to render properly in Internet Explorer 7, 8, or 9.
