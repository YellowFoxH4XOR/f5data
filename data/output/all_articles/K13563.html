Issue

Old Behavior

In BIG-IP 10.1.0 through 10.2.x, the Configuration utility and Traffic Management Shell (tmsh) both allow you to create new empty software slots without installing a BIG-IP software image. For example, from the Configuration utility System > Software Management > Volume Management page, the Create button allows you to create a volume set without installing a BIG-IP software image.

Also, you can create a new, empty volume set from the tmsh utility by using the following tmsh syntax:

tmsh create sys software volume <new-volume-set-name>

New Behavior

Beginning in BIG-IP 11.0.0, the Configuration utility and the Traffic Management Shell (tmsh) utility no longer support creating a new software volume set on the system without installing a new BIG-IP software image. When you install a BIG-IP software image that has already been imported to the system, you can allocate and name the new volume set using either the Configuration utility or tmsh utility.

Using the Configuration utility to install a BIG-IP software image to a new volume set

  1. Log in to the Configuration utility.
  2. Navigate to System > Software Management.
  3. Under Available Images, select the check box next to the version of Software Image.
  4. Click Install.
  5. Type the desired Volume set name on which to install.

    Note: You can use any combination of 32 lowercase alphanumeric characters and hyphen. If the string you type does not match an existing volume set, the system creates one and installs the software onto it. For example, if the HD1 disk is active, and you type siterequest into Volume set name, the system will create a volume set named HD1.siterequest and install the specified software onto the volume set.

  6. Click Install.

Using the tmsh utility to install a BIG-IP software image to a new volume set

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Use the following tmsh syntax:

    install sys software image <imported-ISO-image> create-volume volume <new-volume-set-name>

    For example, to install BIG-IP 12.0.0 software into a new volume set HD1.siterequest, type the following command:

    install sys software image BIGIP-12.0.0.0.0.606.iso create-volume volume HD1.siterequest
