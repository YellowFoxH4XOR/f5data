Description

Virtual Server with Immediate Action On Service Down enabled resets connections, despite being in an Available state.

F5 reset cause shown in a packet trace or when enabling sys db tm.rstcause.log shows VIP down.

Environment

  • Immediate Action On Service Down enabled

Cause

Bug ID 942217: Virtual server keeps rejecting connections for rstcause 'VIP down' even though virtual status is 'available'

The problematic state will persist even if the rate or connection limit is no longer applied to the pool in question.

Recommended Actions

There is no permanent fix for ID 942217 at the time of this article's publication.

A workaround is to trigger a pool member status change. For example, by removing the health monitor. It can then be re-applied.
