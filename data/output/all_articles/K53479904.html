K53479904: Error message: Server request for 'editActionDialogue' is failed: Request status=500, with BIG-IP APM.

Description
While editing the properties of the "Advanced Resources Assign" agent in the APM Access Policy Visual Policy Editor [VPE], you are prompted with the following error message:
"Server request for 'editActionDialogue' is failed: Request status=500"

Environment

  • BIG-IP APM

Cause
In case the agent is configured with a lot of resources, the VPE PHP application may reach a timeout.

Recommended Actions

The actions below should not have any impact over the traffic as processed by BIG-IP.
It may make the BIG-IP Configuration Utility unavailable for a few seconds, though.

  1. Open an SSH connection to BIG-IP bash
  2. Enter the command: #mount /usr -o rw,remount
  3. Edit - with the help of tools such as "vim" or "nano" the file /usr/local/lib/php.ini.
  4. Locate the record max_execution_time = 30
  5. Replace it with max_execution_time = 90
  6. Save the file
  7. Restart the Configuration Utility engine: #bigstart restart httpd
