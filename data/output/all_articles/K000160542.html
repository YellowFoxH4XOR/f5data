K000160542: "Profile Controller Failed Incorrect External Profile" Error on macOS Edge Client

Type
Support Solution
Published
2026-03-31
Updated
2026-03-31
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000160542

Description

MacOS users attempting to connect to a BIG-IP APM VPN using the BIG-IP Edge Client receive the error "Profile Controller, Failed, Incorrect external profile" in the Edge Client logs. The same configuration works for Android and Windows clients.

Environment

iRule applied for Tunnelcrack mitigation (K000138683)

MacOS

Cause

An iRule is used to modify the XML profile response (e.g., for Tunnelcrack mitigation).

Answer/Recommended Actions

To resolve the "Profile Controller Failed Incorrect External Profile" error on macOS Edge Client, remove the iRule workaround for Tunnelcrack (K000138683) from the affected VS - this was the first way of handling Tunnelcrack, but since then, we introduced another one. On BIG-IP 17.1.x, use the vpn.serveriplist DB variable instead of the iRule for Tunnelcrack mitigation per Users cannot connect to BIG-IP APM virtual servers "The VPN connection has failed because it attempted to connect to an insecure network" with BIG-IP Edge Client 7246 and above.

Additional Information

The iRule workaround for Tunnelcrack is not compatible with macOS Edge Client on 17.1.x; use the DB variable method instead.

The issue may not affect Windows or Android clients due to differences in how the Edge Client parses the profile XML.
