K000161280: BO application report is not rendering

Applies to

Description

Application report fails to render via portal, showing client-side error after receiving unexpected redirect and 404 for .wasm file.

 

 

Environment

BIGIP APM

 

 

Cause

BIG-IP is configured to intercept 404 responses from NGINX and issue a 302 redirect to a static apology message, which breaks the application's expected behavior for .wasm file requests.

 

 

Answer/Recommended Actions

Review and modify BIG-IP configuration to avoid replacing 404 responses with 302 redirects for application resource requests, ensuring .wasm files return the correct status to the client.

 

 

Additional Information

Generic error handling applied to all HTTP responses can cause issues for modern web applications that rely on specific status codes for resource loading and error handling. Redirecting 404s for static resources can result in client-side errors and prevent proper application rendering.
