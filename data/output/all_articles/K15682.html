Topic

F5 has recently discovered and corrected a number of issues that affect customers running BIG-IQ 4.4.0. F5 recommends that all customers currently running BIG-IQ 4.4.0 install the latest cumulative rollup hotfix.

The following table lists the rollup hotfixes released for BIG-IQ 4.4.0. The table lists each hotfix, along with the ID numbers of issues that the corresponding hotfix resolves, and a description of each issue. If an article exists for the issue, the ID number contains a link to a corresponding article.

Note: These rollup hotfixes are cumulative; each hotfix contains all fixes included in the previous hotfixes. For example, HF3 includes all IDs fixed in HF1 and HF2.
