Known Issue

The HISTTIMEFORMAT variable may not be set in the .bash_profile file for the root user.

This issue occurs when all of the following conditions are met:

  • The BIG-IP configuration was originally created on a BIG-IP version prior to 9.4.2 or 9.3.0.
  • The BIG-IP configuration was upgraded to version 9.4.2, 9.3.0, or later.

Beginning in BIG-IP 9.3.0 and 9.4.2, the HISTTIMEFORMAT variable was added to the /root/.bash_profile file. This variable controls the display of time stamps in the output of the history command. A configuration that was originally created prior to 9.3.0 and 9.4.2 and has subsequently been rolled forward to any version affected by this issue may never have had the variable added. New installations of later versions of BIG-IP software include the /root/.bash_profile file in which the HISTTIMEFORMAT variable is set correctly.

Impact

The history command will not display time stamps.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The /root/.bash_profile file does not contain the HISTTIMEFORMAT variable.
  • The commands listed in the output of the history command will be pre-pended by sequential numbers instead of time stamps, as shown in the following example:

    1 b mgmt
    2 config
    3 exit
    4 switchboot -l
    5 whoami
    6 history

Workaround

To work around this issue, you can set the HISTTIMEFORMAT variable. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Type the following command:

    echo -e 'HISTTIMEFORMAT="%Y-%m-%d %T " \n' 'export HISTTIMEFORMAT' | cat >> /root/.bash_profile ; source /root/.bash_profile

After typing the command in step 2, the output of the history command will display time stamps as expected.
