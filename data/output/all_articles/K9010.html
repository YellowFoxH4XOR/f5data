In WebAccelerator version 9.x, the BIG-IP WebAccelerator Keep-Alive timeout is used to manage the lifespan of connection data that is shared between TMM and the BIG-IP WebAccelerator PVAC. The default timeout value is 300 seconds.

To modify the Keep-Alive timeout value in the pvsystem.conf file, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa

  3. Back up the original pvsystem.conf file by typing the following command:

    cp pvsystem.conf pvsystem.conf.sol9010

  4. Open the pvsystem.conf file in a text editor.
  5. Locate and modify the <keepAliveTimeout> setting to the desired value.

    For example:       

    <keepAliveTimeout>300</keepAliveTimeout>

  6. Save the pvsystem.conf file.
  7. Restart the BIG-IP WebAccelerator PVAC process by typing the following command:

    Important: Restarting the pvac daemon briefly disrupts connections and invalidates objects in the BIG-IP LTM RAM Cache. You should schedule the restart of the pvac daemon accordingly. 

    bigstart restart pvac

Note: The BIG-IP WebAccelerator Keep-Alive timeout is no longer used in WebAccelerator version 10.x, due to architecture changes involving the manner in which connection data is managed internally.
