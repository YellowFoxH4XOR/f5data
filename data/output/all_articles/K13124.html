Issue

Error Message

ERROR: Need <EM config archive size> Kbytes for EM backup. Have <available space> Kbytes. Short by <space required> Kbytes

In this error message, note the following:

  • <EM config archive size> refers to the size of the Enterprise Manager configuration archive.
  • <available space> refers to the amount of space available for temporary usage during the backup operation.
  • <space required> refers to the amount of disk space required to successfully complete the em-backup.

For example:

ERROR: Need 6765432 Kbytes for EM backup. Have 3573564 Kbytes. Short by 3191868 Kbytes

Message Location

You may encounter this message in the following location:

  • The em-backup command output

Description

This message occurs when the following condition is met:

  • You attempt to create an Enterprise Manager configuration archive whose size exceeds the available storage in the /var/tmp directory.

The em-backup utility is commonly used to save the configuration of an Enterprise Manager system in an Enterprise Manager configuration archive. This configuration archive includes the software repository as well as configuration archives of all managed devices. You must run the em-backup utility in the following format:

em-backup <EM config archive name>

In the previous command, note the following:

  • <EM config archive name> refers to the name or the full path of the Enterprise Manager configuration archive.

    • Note: By default if you specify the name of the Enterprise Manager configuration archive without any path, the em-backup utility saves the configuration archive to the /var/local/ucs directory.

When you run the em-backup utility, it temporary uses the /var/tmp directory, which is symbolic linked to the /shared/tmp directory. If the disk space utilization of the /shared filesystem is insufficient to house the Enterprise Manager configuration archive, the em-backup utility fails to create the configuration archive and reports the described error message.

Impact

You are unable to create a configuration archive for the affected Enterprise Manager system.

Recommended Actions

F5 recommends that you maintain adequate disk space on the /shared filesystem.
