K75549932: IPSec Event not Displaying in BIG-IQ CM

Description

Even after configuring all necessary data needed to view IPecs Event log in BIG-IQ, Configuration utility (GUI) pane will still not show any data. 
The same is true when you run below on CLI:
      #curl localhost:9200/ipsec* -s   | jq .

Environment

  • BIG-IQ
  • BIG-IP
  • IPSec event logs

Cause

IPSec event logs are normally processed as follows:

1. BIG-IP is configured to send the IPSec logs to DCD (port 9997).
2. DCD formats logs, and store them on ElasticSearch.
3. When user launches BIG-IQ CM GUI (at /ui/monitoring/events/ipsec/events), it queries elastic search for the events
 
The problem is at step 2, BIG-IP data pump via POST is failing to store data into elastic search. The restjavad service on the DCD is getting an incorrect configuration from the CM, and it's trying to store the logs in an index/type that doesn't exist.

This is currently a known issue and is tracked under ID 935941.

Recommended Actions

To address the above mentioned issue, the either of the following is recommended:

1. Change the listener config on every DCD. This will update the listener configuration to store the events in the correct index. To do so, you can run the following commands on every DCD:

ID=$(restcurl /cm/shared/hsl/listener-tasks | jq .items[]  -c | grep ipsec-event-logs | jq .id -r )  ;
restcurl /cm/shared/hsl/listener-tasks/$ID | jq '.|{eventParserConfigs:.eventParserConfigs}' > /var/tmp/eventparser.json ;
cat /var/tmp/eventparser.json | jq . | sed   's/\"esKeyValueIndexName\": \"ipsec-event-logs\"/\"esKeyValueIndexName\": \"ipsec-event-logs_writer\/eventlog\"/g' > /var/tmp/eventparser_final.json ;
curl "localhost:8100/cm/shared/hsl/listener-tasks/$ID" -X PATCH -d @/var/tmp/eventparser_final.json -s | jq .  ;
bigstart restart restjavad  ;

2. Contact support and check if hotfix can be provided for ID 935941.
