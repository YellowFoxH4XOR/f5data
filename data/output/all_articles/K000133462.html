Description

When trying to modify the F5OS trust mode and commit the change, you may see below alert:

R2600-R84-S12(config)# tenants tenant test config trust-mode false

R2600-R84-S12(config-tenant-test)# commit

Aborted: 'tenants tenant test config': Cannot modify test trust-mode. Changes are invalid in current state.

Environment

  • F5OS
  • trust-mode

Cause

The user is trying to modify the trust mode with the tenant in running status

R2600-R84-S12# show tenants tenant full

tenants tenant test

 state name     test

 state unit-key-hash ###############

 state type     BIG-IP

 state image    BIGIP-15.1.6-0.0.8.ALL-F5OS.qcow2.zip.bundle

 state mgmt-ip   10.10.10.10

 state prefix-length 24

 state gateway   10.10.10.1

 state vlans    [ 100 200 300 ]

 state cryptos   enabled

 state vcpu-cores-per-node 4

 state memory    12288

 state running-state deployed

 state trust-mode  true

 state status    Running<========================

 state primary-slot 1

 state image-version "BIG-IP 15.1.6 0.0.8"

NDI   MAC

----------------------------

default 14:a9:d0:07:9f:8d

 Recommended Actions

If it is need to change the tenant trust mode status, the tenant status should be changed to configured firstly. 

# change the tenant state to configured

R2600-R84-S12(config)# tenants tenant test config running-state configured

R2600-R84-S12(config-tenant-test)# commit

 

#change the trust mode

R2600-R84-S12(config)# tenants tenant test config trust-mode true

R2600-R84-S12(config-tenant-test)# commit

 

# change the tenant state to deployed

R2600-R84-S12(config)# tenants tenant test config running-state deployed

R2600-R84-S12(config-tenant-test)# commit
