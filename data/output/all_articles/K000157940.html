Description

Ansible REST API command execution fails with "Expecting value: line 1 column 1 (char 0)" error.

Environment

  • Ansible
  • Variable source IP address used to reach host

Cause

The BIG-IP expects to see a single source IP address being used by the Ansible client while running the playbook.

Recommended Actions

The BIG-IP must be able to see a stable source IP address on all incoming connections from the Ansible client. Ensure that any NAT'ing introduced between the ansible client and the BIG-IP is 1:1 during the lifetime of the running playbook.
