K34275524: Unable to add standby BIG-IQ, getting 400 Bad Request

Type
Support Solution
Published
2020-12-14
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K34275524

Description

When trying to add a secondary BIG-IQ to an HA configuration, it fails and throws an error 400 Bad Request.
  • Error messages similar to these in /var/log/secure:
    Nov 14 22:12:07 bigiq-cmname crit sshd[26809]: fatal: Unable to negotiate a key exchange method

Environment

BIG-IQ HA pair setup

Cause

The BIG-IQ's sshd configuration can be modified to be restrictive of the ciphers that it will use however, the changes do not seem to apply to the 'client' behavior when establishing device trust. When device trust is trying to establish, SSH communication fails due to the 'client' being unable to support what the 'server' supports in terms of ciphers if the sshd cipher suites have been modified or restricted.

Recommended Actions

Revert the sshd include statement to default

# tmsh modify sys sshd include none

Additional Information

None
