K000138942: Need to activate new VE (Virtual Edition)

Type
Support Solution
Published
2024-03-18
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000138942

Description

There are several reasons you may need to activate a new VE:

  1. Expand a license
  2. License got corrupted
  3. VE got corrupted

Environment

Subscription license

or

ELA license

Cause

If you attempt to reuse the license without having already correctly revoked the license it will result in errors.
K36582218: Error 51092: This license has already been activated on a different unit 

Recommended Actions

Allow move needed which will allow the new VE license to be activated with a different UUID and/or MAC address without the licensing server thinking the license is being used on more than instance.

There are two options to accomplish this:

  1. As an owner of the product, you can revoke a license from an operational Virtual Edition in order to allow you to use it elsewhere: K41458656 Reusing a BIG-IP VE license on a different BIG-IP VE system 
  2. F5 Support can manually release the license for you to do so choose any option in: K000135931 : Contact F5 Support  
    Note: If you are needing this done for BIG-IQ you must choose option 2.
