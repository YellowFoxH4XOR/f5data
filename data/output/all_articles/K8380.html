Topic

In certain conditions, you may want to configure BIND on the BIG-IP DNS system to use a hint zone that will override the build root list server. For example, if you want to define a custom root list, or the root server names have changed.

Configuring BIND to use an alternate root server list

To configure BIND to use an alternate root server list, you must perform the following three procedures:

Note: F5 recommends that you perform the following procedures during a maintenance window to prevent disruption to DNS requests.

  • Enabling recursion for named
  • Creating a hint zone using ZoneRunner
  • Copying the list of root servers into the hint zone file

Enabling recursion for named

Note: Recursion is disabled by default for the BIG-IP DNS system. You need to enable recursion for the system to allow named to provide an answer for a zone for which it is not authoritative. When you configure the system for recursion, the system provides recursive replies only to clients with source IP addresses within a self IP address subnet.  For more information, refer to K7055: Enabling DNS recursion in the named configuration on a BIG-IP DNS system.

BIG-IP 11.5.0 and later

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Zones > ZoneRunner > Named Configuration.
  3. Under Options, locate recursion no;
  4. Change the recursion option to recursion yes;.
  5. Click Update.

BIG-IP 11.4.1 and earlier

  1. Log in to the Configuration utility.
  2. Navigate to Global Traffic > ZoneRunner > Named Configuration.
  3. Under Options, locate recursion no;
  4. Change the recursion option recursion yes;
  5. Click Update.

Creating a hint zone using ZoneRunner

To create a hint zone using ZoneRunner, perform the following procedure:

  1. From the ZoneRunner menu, select Zone List.

    The main zones screen displays.

  2. Click Create.

    The new zones screen displays.

  3. For the View Name option, select the view for which the hint zone will apply.

    Note: For most deployments, the external view is the default.

  4. For the Zone Name, enter a period character (.).
  5. For the Zone Type, select Hint.

    The new zone screen will change and display the following:

    Zone File Name: db.external..

  6. Change the Zone File Name to the following:

    db.external.named.root.

    Note: The trailing period is important and must be specified.

  7. Click Finished.

Copying the list of root servers into the hint zone file

To copy the list of root servers into the hint zone file, perform the following procedure:

Note: This section assumes you have already acquired a file that contains the list of root servers, or a custom list if you are creating a specific root list.

Note: A copy of the latest root server list can be found at the following location:

http://www.internic.net/zones/named.cache

  1. Log in to the command line.
  2. To change directories to the /var/named/config/namedb/ directory, type the following command:

    cd /var/named/config/namedb/

  3. Use an editor to open the db.external.named.root. zone file.
  4. Copy the new root server list into the db.external.named.root. zone file.
  5. Save the changes to the file.
  6. To update the time stamp on the /var/named/config/named.conf file, type the following command:

    touch /var/named/config/named.conf

  7. To restart named and zrd, type the following TMOS Shell (tmsh) commands:

    tmsh restart /sys service named

    tmsh restart /sys service zrd

    Note: The hint zone does not display any information when viewed in the ZoneRunner Configuration utility. The information is used by named for the purpose of querying and receiving the most up to date list of root servers. It cannot be updated or modified using the ZoneRunner utility.
