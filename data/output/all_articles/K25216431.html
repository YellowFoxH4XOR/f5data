Issue

Description

The purpose of this article is to guide you in distinguishing between a user-initiated disconnect or an error on the client. This distinction can help troubleshooting a VPN disconnection issue.

Environment

  • BIG-IP APM
  • BIG-IP Edge Client for Windows
  • Browser Network Access Client

Cause

The BIG-IP Edge Client %TEMP%\logterminal.txt file logs several messages when a user initiated disconnect occurs, using the following message syntax:

<date>,<time>, 8972,3500,Standalone, 0,,,, Connection mode changed to ALWAYS_DISCONNECTED
<date>,<time>, 8972,3500,Standalone, 48, , 3395, CStandaloneDoc::CloseSession, Closing session with hangup code: 1, ErrUserInitiated

You observe the corresponding server-side messages in /var/log/apm on the BIG-IP APM in the following message syntax:

<date time> <bigip hostname> notice tmm[1775]: 01490567:5: /Common/NA_full_tunnel:Common:<sessionid>: Session deleted (user_initiated; code - 1).
<date time> <bigip hostname> notice tmm[1775]: 01490505:5: /Common/NA_full_tunnel:Common:<sessionid>: PPP tunnel <tunnelid> (ID: <sessionid>) closed

Recommended Actions

When troubleshooting VPN network access disconnect issues, it is important to identify a disconnect that is initiated by users. By observing the client and server side logs above, you can determine this.

Additional Information

The messages in Windows EdgeClient %TEMP%\logterminal.txt log file are logged in GMT+0. You must convert the times to your local time when matching to the client-side logs to server side on the BIG-IP APM system.
