Description

Beginning from 15.0.0, ASM remote logging format is changed from "" to "N/A" if the value is emptry.
It is because that we introduced a function in our code where all empty values are replaced with "N/A".

If the value of ASM remote logging format is empty;

  • v15 and later version show "N/A"
  • v14 and earlier version show ""

Environment

  • BIG-IP ASM
  • ASM remote logging is configured 
  • The storage format is empty value in the event

Cause

It is by our design.

Recommended Actions

None
