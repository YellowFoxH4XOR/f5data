Description

When renewing a certificate from the Configuration Utility, a comma present in the subject field will cause the value to be truncated.

Example:

F5 Networks, Inc

Will truncate to:

F5 Networks

Environment

  • 14.1.0
  • Configuration Utility
  • CSR Renewal
  • CSR Subject Field

Cause

Bug ID 826437 has been associated to this issue.

Recommended Actions

No workaround is available at this time.
