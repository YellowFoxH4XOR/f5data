K74216253: Can't apply a WMI monitor at the pool level

Type
Support Solution
Published
2021-12-09
Updated
2026-07-16
Status
Legacy Content
Applies to
  • BIG-IP
Source

Description

The WMI  monitor is a node only monitor, so it is by design that this can not be applied at the pool level.

Environment

  • BIG-IP
  • WMI Health Monitor
  • Dynamic Ratio Load balancing
  • Pools
  • Nodes

Cause

N/A

Recommended Actions

  1. Apply the WMI monitor to the individual nodes that require monitoring.
