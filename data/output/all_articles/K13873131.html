Description
This article explains how "max-requests" configuration on HTTP profile impacts the connection. 

Environment

  • BIG-IP system with configuring max-requests value.  
  • HTTP Profile
Cause
When you configure "max-requests 2" in HTTP profile, BIG-IP system inserts "Connection: close" header in HTTP response against 2nd HTTP request and terminates the connection. This is by design.

Recommended Actions
None
