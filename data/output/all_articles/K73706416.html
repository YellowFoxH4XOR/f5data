Issue

Error Message

0107185a:4: Warning generated, for version 14.0.0 or greater  : /<partition>/<profile>, COMPAT, SSLv2, and RC2 keywords and keywords dependent on these in the cipher string have been removed and replaced with NONE because the COMPAT feature has been removed.

In this error message, note the following:

  • <partition> is the name of the partition where the configuration object resides.
  • <profile> is the name of the SSL profile.

For example:

warning mcpd[6240]: 0107185a:4: Warning generated, for version 14.0.0 or greater  : /Common/MySSLProfile, COMPAT, SSLv2, and RC2 keywords and keywords dependent on these in the cipher string have been removed and replaced with NONE because the COMPAT feature has been removed.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You configure an SSL profile in which one or more of the following keywords is specified in the Ciphers setting:
    • COMPAT
    • SSLV2
    • RC2
  • You upgrade your BIG-IP system to 14.0.0 or later.

Starting in BIG-IP 14.0.0, the COMPAT SSL stack and associated SSL ciphers have been removed from the Traffic Management Microkernel (TMM), and are no longer available to use in SSL profiles. If you specified one of the previously listed keywords in the Cipher string field in the SSL profile, the system will reset the keyword during the upgrade process as follows:

  • Any invalid keyword is initially reset to NONE.
  • If the resulting cipher string maps to an empty cipher suite in which the only value is NONE, the system will automatically rewrite the string to DEFAULT.

For more information about how the upgrade script resets the cipher string, refer to the following table.

Cipher string 12.x - 13.xCipher string 14.x
COMPAT+EXPDEFAULT
COMPAT+RC2DEFAULT
COMPAT:AES128SHANONE:AES128SHA
COMPAT:!TLSv1:TLSv12NONE:!TLSv1:TLSv1_2

Impact

Client connections that reply on ciphers that were available only in the COMPAT SSL stack, such as export ciphers, may fail.

Recommended Actions

Review the BIG-IP log files for error messages related to the SSL handshake and look for messages that indicate that the cipher negotiated by the client and server is not supported in one of the SSL profiles. For information about troubleshooting SSL/TLS handshake failures, refer to K15292: Troubleshooting SSL/TLS handshake failures.
