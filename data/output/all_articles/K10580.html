Issue

In BIG-IP 9.0.0 through 10.1.x, the BIG-IP Client SSL and Server SSL profiles support a maximum local Secure Socket Layer (SSL) key size of 2048 bits, regardless of the cipher used. A Server SSL profile using a COMPAT cipher supports a maximum remote SSL key size of 4096 bits.

Note: The term local key refers to a key that is hosted on the BIG-IP system and configured within the SSL profile. The term remote key refers to a key that is hosted on and used by the web server.

Note: For information about a related known issue, refer to K11743: The BIG-IP system allows import and application of unsupported 4096 bit SSL keys.

In BIG-IP 10.2.0, CR124105 was implemented to add support for 4096 bit local SSL keys when NATIVE ciphers are used. As a result of this change, the following configurations are supported:

  • A BIG-IP Client SSL profile using a COMPAT cipher supports a maximum local key size of 2048 bits, and a maximum remote key size of 4096 bits.
  • A BIG-IP Client SSL profile using a NATIVE cipher supports a maximum local key size of 4096 bits, and a maximum remote key size of 4096 bits.
  • A BIG-IP Server SSL profile using a COMPAT cipher supports a maximum local key size of 2048 bits, and a maximum remote key size of 4096 bits.
  • A BIG-IP Server SSL profile using a NATIVE cipher supports a maximum local key size of 4096 bits, and a maximum remote key size of 4096 bits.

    Note: Due to a known issue, the ServerSSL profile does not support the use of 4096 bit keys in BIG-IP 10.2.0. However, an Engineering Hotfix that resolves this issue is available for BIG-IP 10.2.0-HF1. For more information, refer to K12147: SSL handshakes fail when the BIG-IP serverssl profile is configured to use a 4096 bit SSL key.

In BIG-IP 10.2.0, if the server uses a key larger than 2048 bits, you must force the virtual server to use software encryption by configuring the Server SSL profile to use only COMPAT ciphers.

Important: You should implement this recommendation only if absolutely necessary. Using COMPAT ciphers forces the BIG-IP system to use software encryption, which may reduce crypto throughput and increase load on your system.

Note:  For a complete list of both NATIVE and COMPAT ciphers, refer to K11444: SSL ciphers supported on BIG-IP platforms (10.x). For more general information about using ciphers with the SSL profiles, refer to K8802: Using SSL ciphers with BIG-IP Client SSL and Server SSL profiles.
