Known Issue

Local traffic policy controls may not include the BIG-IP ASM control action.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP license contains text for an active module that does not contain additional features.

    For example:

    active module :               CGN, VE (LAB)|<licence string>
    active module :               DNSSEC|<licence string>

    Note: The active module contains a singular Pipe, Broken vertical bar ( | ) character with no additional module features or ( | ) characters listed to the right of the license string.

    For example:

    active module :               GTM, VE (LAB)|<license string>|IPV6 Gateway|Ram Cache|STP|DNS Express

    Note: The unaffected active module contains multiple features separated by Pipe, Broken vertical bar ( | ) characters to the right of the license string.

  • You attempt to create or modify local traffic policy rules using the Configuration utility.

Impact

The user is unable to set the local traffic policy BIG-IP ASM action as part of a rule execution when using the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view local traffic policy action options, the BIG-IP ASM system is not listed.
  • When you use the Traffic Management Shell (tmsh) to create or modify local traffic policies, you can use the BIG-IP ASM control action.
  • When you run the following command on an affected BIG-IP system, active modules that appear similar to the following example are returned:

    grep -E '^active module : [^|]*\|[^|]*$' /config/bigip.license

Workaround

To work around this issue, you can use the tmsh utility to create or modify local traffic policies that require the BIG-IP ASM control action.

Note: For more information, refer to the Introducing Local Traffic Policies chapter of the BIG-IP LTM BIG-IP Getting Started with Policies manual. For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
