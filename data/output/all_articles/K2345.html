K2345: 3-DNS compatibility with AAAA record queries

Topic

3-DNS does not support IPv6 AAAA record queries. When 3-DNS receives an AAAA record query, it passes the query to BIND. If an IPv4 A record exists for the wide IP, BIND responds with a NOERROR reply and the LDNS then sends an IPv4 A record query, to which 3-DNS can respond.

If an A record for the wide IP does not exist, BIND responds with an NXDOMAIN reply. The LDNS caches this response and provides the NXDOMAIN reply to all clients requesting that record, whether the clients use IPv6 AAAA record requests or IPv4 A record requests. As a result, the Wide IP is inaccessible to all users of the affected LDNS.

To avoid this issue, you can configure an A record for each wide IP address.

Note: Beginning with version 4.6.3 of 3-DNS, BIG-IP and BIG-IP Link Controller, the 3dnsd process intercepts AAAA and A6 record requests and sends the NOERROR response. This behavior allows IPv6 name resolution compatibility regardless of whether the named process is running.
 
For more information about BIG-IP GTM compatibility with AAAA and A6 record queries, refer to K7850: Change in Behavior: BIG-IP GTM and Link Controller compatibility with AAAA and A6 record queries.
