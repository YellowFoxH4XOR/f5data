Description

  • Blades on VIPRION chassis failing to load configuration
  • show sys mcp-state shows Running Phase: none but config has successfully loaded
  • Error messages logged in /var/log/ltm:
1070266:3: Dossier error: dossier internal chassis changed

Environment

  • VIPRION chassis with at least one blade

Cause

Migrating configuration from one chassis to another chassis and UCS is restored including license.

This overwrites the correct license leading in failure to load configuration.

Recommended Actions

When migrating or loading UCS back from one Viprion chassis to another chassis exclude the license.

If license from UCS backup gets loaded in error, re-activate the chassis license using the correct Registration Key for that chassis.

Additional Information

None
