Description

The restjavad daemon produces the following log files for iControl REST API:

  • /var/log/restjavad.[0-99].log (0 being the newest)

    This file logs internal activities of the restjavad daemon and how it processes each request. You may review this log file to investigate issues when restjavad does not work properly, such as it frequently times out or it keeps restarting.
     
  • /var/log/restjavad-audit.[0-99].log (0 being the newest)

    This file logs REST API requests received by restjavad, in 1 request-per-line format. This file logs the user, method, uri, status, and source of each request, and is useful if you would like to know the type of REST API requests received and where they originate from.

This article focuses on the latter - /var/log/restjavad-audit.[0-99].log .

Environment

  • BIG-IP
  • v12.0.0 and above
  • You wish to log all REST API requests

Cause

Beginning v12.0.0, GET requests are no longer logged by restjavad by default. Hence, you need to change the log level to log all REST API requests. For more information, refer to K24045323: GET requests are no longer logged by restjavad by default.

Recommended Actions

Increasing log level to log all REST API requests
Impact of procedure: The restjavad service on the BIG-IP system is briefly interrupted during the service restart. F5 recommends performing this procedure during a maintenance window. This procedure increases disk usage for the log files, especially if there are many REST API requests. F5 recommends that you reset the restjavad log level to the default value after troubleshooting.

  1. Login to the command line.
     
  2. Edit /etc/restjavad.log.conf
    vi /etc/restjavad.log.conf
     
  3. Locate the audit.logging.FileHandler.level option, and set it to FINE.
    audit.logging.FileHandler.level=FINE

    The FINE log level is sufficient for logging all externally originated REST API requests. If you wish to also log all internally generated REST API requests, you may use the FINEST log level.
     
  4. Restart restjavad for the change to take effect
    bigstart restart restjavad
     
Reverting to the default log level
Impact of procedure: The restjavad service on the BIG-IP system is briefly interrupted during the service restart. F5 recommends performing this procedure during a maintenance window.
  1. Login to the command line.
     
  2. Edit /etc/restjavad.log.conf
    vi /etc/restjavad.log.conf
     
  3. Locate the audit.logging.FileHandler.level option, and set it to INFO.
    audit.logging.FileHandler.level=INFO
     
  4. Restart restjavad for the change to take effect
    bigstart restart restjavad
