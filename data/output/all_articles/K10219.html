K10219: Routing fails after the IP address of a FirePass network interface is modified

Known Issue

This is the result of a known issue. When you modify the IP address of a FirePass network interface, FirePass does not force a system restart when you finalize the change. However, any routes that previously routed through that network interface, including the default route, will stop passing traffic until the FirePass controller is restarted.

F5 Product Development is tracking this issue as CR119966.

Workaround

You can work around this issue by manually restarting the FirePass controller after modifying a network interface IP address. You can restart FirePass by selecting the Restart Controller link on the Device Management: Maintenance: Restart Services page.
