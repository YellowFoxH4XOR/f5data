K000140440: Is there way to send email notification on Nginx server failover

Description

In an NGINX HA configuration that uses keepalived, is there a way to send an email on a state change ?

 

Environment

NGINX Plus

NGINX Plus HA

Keepalived configuration

 

Cause

None.

 

Recommended Actions

Keepalived can be configured to run scripts whenever there is a state change using the notify directive. Follow these example steps -

 

1.  Create a script to send the mail. In this example we will save this script as /usr/local/bin/notify-email.sh on each of the participating nodes.

Mail Script (make executable) -
#!/bin/bash

# Email settings
recipient="admin@example.com"
subject="Nginx Failover Notification"
body=""

# Check the argument passed by Keepalived
case "$1" in
"MASTER")
body="Failover has occurred. Active Nginx server is down, Passive server is now active."
;;

"BACKUP")
body="Failback has occurred. Previously active Nginx server is now back online as the MASTER."
;;

*)
body="Unknown state change event: $1"
;;

esac

# Send email
echo "$body" | mail -s "$subject" "$recipient"
 
2. Modify the notify directive in each VRRP instance as follows -
notify /usr/local/bin/notify-email.sh
