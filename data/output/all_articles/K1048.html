K1048: Configuring the BIG-IP system to log messages from within rules

Topic

The BIG-IP system does not log which rule, or which line in the rule, was used in each connection; however, starting in version 4.5, you can add a log command to a rule in order to log specific information.

For example:

if (http_uri ends_with "gif" or http_uri ends_with "jpg") {





use pool images





log "image"





}





else {





use pool web





log "non-image"





}

For additional information about BIG-IP rules, refer to the iRules chapter in the BIG-IP Reference Guide.
