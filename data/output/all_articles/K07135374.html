Description

This article explains how to configure Client Initiated Forms SSO when providing access to the BIG-IP Web GUI via Portal Access.

Environment

  • BIG-IP APM 
  • Portal Access configured to provide access to a back-end BIG-IP Web GUI

Cause

  • n/a

Recommended Actions

Create the Forms SSO Profile

  1. In the BIG-IP Web GUI, Navigate to Access > Single Sign-On > Forms - Client Initiated and click Create
  2. Type a profile name in the SSO Configuration Name field and click Form Settings
  3. Click Create
  4. In the Form Name field, type loginForm and click on Request Detection
  5. In the Request URI field, type /tmui/login.jsp and click on Form Parameters
  6. Click Create and in type username in the Form Parameter Name field then type %{session.sso.token.last.username} in the Form Parameter Value field. Click OK
  7. Click Create and in type passwd in the Form Parameter Name field, then type %{session.sso.token.last.password} in the Form Parameter Value field. Set the Secure dropwdown to Yes and Click OK
  8. Click OK, then click OK again to create the profile. 
Apply the Forms SSO Profile to an Access Policy
  1. In the BIG-IP Web GUI, navigate to Access > Profiles / Policies > Access Profiles (Per-Session Policies)
  2. Click on the name of the access profile which you want to apply the SSO Profile to
  3. Click on the SSO / Auth Domains tab 
  4. In the SSO Configuration dropdown menu, select the new profile that was created in the previous procedure. 
  5. Click Update
NOTE: Forms SSO Requires a credential mapping in your Access Policy to work properly. Please refer to K11629  for instructions on how to implement an SSO Credential Mapping in your Access Policy
