Topic

You can use the following sample BIG-IP iRule to block/discard the SQL Slammer Worm. This iRule verifies that:

  • The packet is UDP.
  • The destination port is 1434.
  • The first byte of UDP data contains the hex value of 04 and contains the string: h.dllhel32hkern

Upon verification of all this criteria, the rule discards the packet.

If one of these conditions is not verified, the packet is sent to the sql_servers pool and a log message, along with the source IP address of the offender, is sent to /var/log/bigip.

Note: The following example assumes that you are familiar with basic BIG-IP configuration. This sample iRule may need to be modified to your specific network configuration. For more specific details about BIG-IP configuration and iRules, refer to the iRules chapter in the BIG-IP Reference Guide.

iRule Example

RULE sql_rule {
   if (ip_protocol == 17) {
      if (server_port == 1434) {
         if (substr(udp_content, 0, 1) == <0x04>) {
            if (udp_content contains "h.dllhel32hkern") {
               log "SQL worm detected from ${client_addr}"
               discard
            }
            else {
               log "SQL connection e1 from ${client_addr}"
               use pool sql_servers
            }
         }
         else {
            log "SQL connection e2 from ${client_addr}"
            use pool sql_servers
         }
      }
      else {
         log "SQL connection e3 from ${client_addr}"
         use pool sql_servers
      }
   }
   else {
      log "SQL connection e4 from ${client_addr}"
      use pool sql_servers
   }
}
