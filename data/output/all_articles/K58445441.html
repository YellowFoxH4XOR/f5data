K58445441: Update to SAML Single Logout URLs starting in v16.x

Type
Support Solution
Published
2022-09-01
Updated
2024-11-19
Applies to
  • BIG-IP
  • BIG-IP APM: 17.X.X, 17.0.X, 16.1.X, 16.0.X, 17.0.0, 16.1.3, 16.1.2, 16.X.X, 16.1.0, 16.0.1, 16.0.0, 16.1.1
Source
https://my.f5.com/manage/s/article/K58445441

Description

Starting in BIG-IP v16.x the Single Logout Request URL and Single Logout Response URL have been updated to a single URL rather than the previous 2 different URLs.

Environment

  • BIG-IP APM
  • SAML SP
  • SAML Single Logout (SLO)

Cause

To avoid the confusion of 2 different SLO URLs, This is a change in behavior starting in version 16.x
Note: This change in behavior will not affect users upgrading to 16.x from previous versions of BIG-IP, SLS, SLR and SLO URLs all work for Single Logout

Recommended Actions

Upon reviewing this article, if you are on version v16.x or later and still using the SLS and SLR URLs, it is advised to updated these to the SLO URL as the SLS and SLR may be depreciated in a later version.

Additional Information

You will notice the change from 2 URLs ending in SLS and SLR when exporting the Metadata from the BIG-IP, these were changed to a single ending SLO

Snippet of the SLO portion of SAML-SP metadata – 15.x and prior:

        <SingleLogoutService Binding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-POST" Location="https://example.com/saml/sp/profile/post/sls" ResponseLocation="https://example.com/saml/sp/profile/post/slr">
        </SingleLogoutService>
        <SingleLogoutService Binding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-Redirect" Location="https://example.com/saml/sp/profile/redirect/sls" ResponseLocation="https://example.com/saml/sp/profile/redirect/slr">
        </SingleLogoutService>

Snippet of the SLO portion of SAML-SP metadata – 16.x and later:

        <SingleLogoutService Binding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-POST" Location="https://example.com/saml/sp/profile/post/slo" ResponseLocation="https://example.com/saml/sp/profile/post/slo">
        </SingleLogoutService>
        <SingleLogoutService Binding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-Redirect" Location="https://example.com/saml/sp/profile/redirect/slo" ResponseLocation="https://example.com/saml/sp/profile/redirect/slo">
        </SingleLogoutService>
