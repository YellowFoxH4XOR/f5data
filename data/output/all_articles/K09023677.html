Known Issue

The BIG-IP system may fail to display the time stamp for the history command output.

This issue occurs when all of the following conditions are met:

  • You are assigned the administrator or resource administrator role.
  • You have the Terminal Access option set to tmsh.
  • You log in to the BIG-IP system and switch to the Advanced Shell (bash) to run the history command.

Impact

There are no time stamps associated to the commands that you previously issued on the BIG-IP system. The recorded time stamps may be useful when performing troubleshooting.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the history command, the output consists of only commands without time stamps. The output may appear similar to the following example:

    1  ls
    2  cd
    3  history

    The expected output should appear similar to the following example:

    1  2017-05-25 22:17:11 ls
    2  2017-05-25 22:17:34 cd
    3  2017-05-25 22:17:37 history

Workaround

To work around this issue, you can configure the HISTTIMEFORMAT environment variable before running the history command. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. From the TMOS Shell (tmsh), switch to bash by typing the following command:

    run /util bash

  3. Configure the HISTTIMEFORMAT environmental variable by typing the following command:

    export HISTTIMEFORMAT="%Y-%m-%d %T "

  4. To view the expected output with time stamps, type the following command:

    history
