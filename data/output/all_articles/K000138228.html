K000138228: Message: Virtual Address <virtual-address> monitor status changed from UNCHECKED to UNCHECKED

Type
Support Solution
Published
2024-01-15
Updated
2024-01-15
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.X.X, 17.0.0, 17.0.X, 17.1.0, 17.1.1, 17.1.X
Source
https://my.f5.com/manage/s/article/K000138228

Description

BIG-IP logged one or more virtual addresses' monitor status changed from UNCHECKED to UNCHECKED.

notice mcpd[<pid>]: 010719e8:5: Virtual Address /Common/<virtual-address> monitor status changed from UNCHECKED to UNCHECKED.

Environment

  • tmsh load sys config verify command is executed.

Cause

The command tmsh load sys config verify logs the message ID 010719e8 with a message like "Virtual Address <virtual-adderss> monitor status changed from UNCHECKED to UNCHECKED."

Recommended Actions

The message is cosmetic and can be safely ignored.

Additional Information

None
