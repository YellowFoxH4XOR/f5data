Description

  • LTM is added to BIG-IP DNS
  • Most of the LTM virtual servers are discovered apart from 1
  • No errors logged

Environment

  • DNS and LTM communicating OK
  • No certificate errors on IQDump
  • Missing Virtual Server included in IQuery traffic

Cause

The virtual server in question was using a port list rather than a single TCP port. This is currently unsupported in BIG-IP DNS

Recommended Actions

  1. Change the port from a port list to a single port
  2. If a port list is required, set the auto discovery to no-delete, change the LTM virtual to a port '0', discover the virtual in DNS then change the LTM back to port list.
