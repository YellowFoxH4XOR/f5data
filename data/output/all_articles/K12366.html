Known Issue

When using Internet Explorer to access the Overview screen in the BIG-IP ASM Configuration utility, the browser may report the following error:

'document.getElementById(...)' is null or not an object

Impact

When this issue occurs, the Overview page may not display the expected data.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • JavaScript error messages when using Internet Explorer to navigate the Overview page in BIG-IP ASM Configuration utility

Resolution

Status

F5 Product Development has assigned ID 337531 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release10.2.1K2200: Most recent versions of F5 software
Hotfix10.2.0 HF-2K9502: BIG-IP hotfix matrix

Workaround

To work around this issue, you can restart Internet Explorer. However, the issue may occur again.
