K000134760: Unable to upload/import iFile even when lots of free space available

Type
Support Solution
Published
2023-05-24
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K000134760

Description

  • Unable to upload/import file under System ›› File Management : iFile List.
  • Error messages indicate lack of free space.
  • But "Import" screen shows lots of free space under "Free Space on Disk"
  • Example error messages below:
    • "failed in syscall mkdir(/config/filestore/xxxx/xxx/Common_d) errno=(No space left on device)"
    • "can't write destination file. in out (-1) src (/shared/tmp/upload_xxx)

Environment

  • BIG-IP LTM
  • File being uploaded/imported to iFile List

Cause

The file can fail if there is no free space on /config partition.

Recommended Actions

  • Verify if there is enough free space using df -h command.
  • Check if there is enough free space under /config
  • If there is no or less free space under /config, use the command below to find out which files are occupying space.
  • # find /config/ -xdev -type f -exec du {} \; | sort -rn | head -20
  • Then delete any large unnecessary files.

 

Additional Information

None.
