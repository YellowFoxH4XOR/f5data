K000134881: Device group admin password mismatch owing to HA sync issue

Description

BIG-IP System changes are not synchronized between the HA cluster.
Example: 
modify/delete or created local user are not sync between BIG-IP

For example:

  1. Creating a new user on device A, however, changes are not synced to device B
  2. Changing the local user or default admin password on the device A, however, changes are not synced to device B
  3. Created or Deleted a local user account on device A, however, changes are not synced to device B

 

Environment

  • BIG-IP
  • DNS
  • DSC
  • Sync-Only
  • Local user
  • Synchronization issue
  • Configuration Utility (GUI)

Cause

The Device Group default group "device_trust_group" are defaulted to configuration type "sync-only" mode, and this mode only sync for particular group (example partition), with policies.
 

Recommended Actions

In order to sync the system configuration (none policy type), create a new "Device Group" and configure it to "sync-failover" mode. Steps as below:

  1. Login to BIG-IP Configuration Utility (GUI) > Device Management > Device Groups > Create
  2. Give it a name "e.g sync_failover_group" and choose Group type "sync-failover"
  3. Add Members to this new group and click "Finished" to apply this new group
  4. Device Management > Overview and Sync the "New Sync Failover Group" for the first time
  5. And you should now be able to sync the system configuration which includes the "local users" between HA cluster
