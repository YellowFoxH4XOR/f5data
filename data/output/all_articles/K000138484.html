Description


You may notice that trunk configuration on Tenant cannot be removed directly.

For example :


Environment

・rSeries
・F5OS-A
 

Cause

This is by design because the host (F5OS) layer still have the trunk info meant for the tenant.

Recommended Actions

(1) Locate the vlan that associated to the LAG/trunk on F5OS via GUI : NETWORK SETTINGS >> LAGs

For example :



(2) Locate the tenant in question via GUI : Tenant Deployments and uncheck the vlan that associated to the LAG/trunk

For example :



(3) You can remove the trunk on tenant successfully
