Known Issue

The BIG-IP APM Secure Web Gateway (SWG) URL categorization may cause the /var/lib/mysql file system to become fully utilized.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system has SWG provisioned and is configured to perform URL classification.
  • A large amount of web traffic is proxied by the BIG-IP system.
  • The /var/lib/mysql file system is full or approaching 100 percent utilization; you can observe this by using the df command.

    For example:

    df -h /var/lib/mysql
    Filesystem Size Used Avail Use% Mounted on
    /dev/mapper/vg--db--vda-app.ASWADB.set.1.mysqldb 12G 11G 576M 95% /var/lib/mysql

Impact

The /var hard disk partition becomes fully utilized, and may result in the BIG-IP system becoming unstable.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP APM SWG-related operations dependent on the MySQL database may not be working as expected.
  • The BIG-IP system functions that are dependent on the MySQL database may not be working as expected.
  • The database and index files for SWG URL categorization have grown large, and you can observe the files using the ls command.

    For example:

    ls -alh /var/lib/mysql/AVR/AVR*SWG_URL.MY[DI]
    -rw-rw----. 1 mysql mysql 8.1G 2016-05-23 17:04 /var/lib/mysql/AVR/AVR_DIM_APM_SWG_URL.MYD
    -rw-rw----. 1 mysql mysql 765M 2016-05-23 17:04 /var/lib/mysql/AVR/AVR_DIM_APM_SWG_URL.MYI

Resolution

Status

F5 Product Development has assigned ID 549393 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Hotfix12.0.0 HF1K9502: BIG-IP hotfix matrix

Workaround

To work around this issue, you can reset the Application, Visibility, and Reporting (AVR) statistics. For more information about resetting the AVR statistics, refer to K14956: Resetting BIG-IP AVR statistics.

Impact of workaround: The procedure to reset the AVR statistics removes all of the BIG-IP Analytics data, and resets the MySQL database.
