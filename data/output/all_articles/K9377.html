Known Issue

This is the result of a known issue. If a user installs Swisscom Unlimited Data Manager (UDM) software on a Windows client system, and the FirePass Network Access client-side components were already installed on the client system, Network Access connections may fail to connect with an error message that appears similar to the following example:

The modem (or other connecting device) has reported an error.

This issue occurs because the Swisscom UDM software modifies settings on the client system that are incompatible with the settings required by the FirePass Network Access client-side components.

F5 Product Development is tracking this issue as ID 265489 (formerly CR102045).

In addition, F5 Product Development has opened case number 1-2901293071 with Swisscom. For more information, Swisscom customers should contact Swisscom support and reference case number 1-2901293071.

Workaround

Users can work around this issue by removing and reinstalling the FirePass client-side components. The FirePass controller downloads components to the end users computer at initial logon and whenever a feature or favorite is started. The downloaded client components enable the various features of FirePass controller functionality.

Note: For information about removing FirePass client-side components from Windows systems, refer to K8253: Removing FirePass client components from Windows 2000, 2003, XP, and Vista systems.

For installation instructions, refer to the FirePass Controller Administrator Guide.

In addition, users can avoid this issue by installing the Swisscom UDM software prior to installing the FirePass client-side components.
