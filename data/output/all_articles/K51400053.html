Known Issue

The BIG-IP ASM system may incorrectly classify Illegal HTTP status in response violations.

This issue occurs when the following condition is met:

  • The BIG-IP ASM system detects an Illegal HTTP status in response violation.

The system incorrectly reports the Illegal HTTP status in response violation as an HTTP Parser Attack attack type, instead of an Information Leakage attack type.

Impact

The ASM system reports the incorrect attack type.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP ASM system detects an Illegal HTTP Status in response violation, but incorrectly reports it as an HTTP Parser Attack attack type, instead of an Information Leakage attack type.
