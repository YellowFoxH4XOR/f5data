Known Issue

A configuration with Fully Qualified Domain Name (FQDN) nodes may fail to load.

This issue occurs when all of the following conditions are met:

  • The configuration contains an FQDN node configured in the Common partition.
  • The configuration contains a default-node-monitor.
  • The configuration contains an administrative partition other than Common.

Impact

The BIG-IP system is unable to load the configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The configuration fails to load and the system displays an error message similar to the following example:

    01070726:3: Node /Common/name.of.fqdn.node in partition Common cannot reference monitored object /Common/name.of.fqdn.node /Common/partition1 in partition another_partition.
