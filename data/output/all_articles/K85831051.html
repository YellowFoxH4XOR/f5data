Known Issue

Pool members may not exit the slow ramp when the associated virtual server is configured with a persistence profile.

This issue occurs when all of the following conditions are met:

  • You have configured your pool with a Slow Ramp time value greater than 0 (zero).
  • The virtual server that uses the pool is configured with one of the following persistence profile types:
     
    • Source Address Affinity
    • Destination Address Affinity
    • Hash
  • The persistence profile is configured with the Hash Algorithm set to CARP.

Impact

Newly active pool members stay in the slow ramp state.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Pools configured with priority groups do not select load balance members based on the expected priority configuration.

Workaround

To work around this issue, you can disable Slow Ramp on the affected pool. To do so, perform the following procedure:

Impact of workaround: Newly active pool members will not be brought into the load balancing selection gradually.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Pools > Pool List.
  3. Click the name of the pool you want to modify.
  4. When the Pool Properties screen opens, select Advanced from the Configuration menu.
  5. In the Slow Ramp Time box, change the value to 0 (zero seconds).
  6. To save the change, click Update.
