K404: Performance impacts of large numbers of configuration objects

Topic

BIG-IP uses a hashing algorithm to minimize performance degradation as the number of configuration objects increases. Very large configurations will take longer to load into memory, but should not cause significant increases in latency.

In respect to packet-processing, there is no top or bottom to the table that stores virtual server addresses; therefore, no matter how large the virtual server list is, every packet is processed in the same amount of time.
