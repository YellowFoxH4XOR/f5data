Known Issue

The BIG-IP ASM system may fail to auto apply new signatures when you use the auto apply function of the Attack Signature Update feature.

This issue occurs when the following condition is met:

  • The Attack Signatures Update feature is configured with the following settings:

    • The Update Mode setting is set to Scheduled.
    • The Auto Apply New Signatures Configuration After Update setting is set to Enabled.

Impact

The system does not apply the security policies with the newly downloaded attack signatures, as configured.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After the system automatically downloads the attack signatures, the security policies with the affected attack signatures are in the Modified state waiting for you to manually apply the changes.

Workaround

To recover from this issue, you can manually apply the affected security policies. You can use the manual update mode instead of the scheduled update mode when configuring the Attack Signatures Update feature. To do so, perform the following procedure.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to the Attack Signatures Update page.

    BIG-IP ASM 11.3.0

    Security > Options > Application Security > Attack Signatures > Attack Signatures Update

    BIG-IP ASM 11.2.0 through 11.2.1

    Application Security > Options > Attack Signatures > Attack Signatures Update

  3. For the Update Mode setting, click Manual.
  4. If you have already downloaded the new attack signature update file, for the Delivery Mode setting, select Manual, and browse to the downloaded file.

    Optionally, you can let the system auto-download the file at the end of this procedure by selecting Automatic for the Delivery Mode setting.

  5. Ensure that the Auto Apply New Signatures Configuration After Update setting is set to Enabled.
  6. Select Check for Updates and then select Update Signatures.
