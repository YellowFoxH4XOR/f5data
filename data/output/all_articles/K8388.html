Topic

FirePass does not support command line access through Telnet, SSH, or a serial client connection. This behavior is by design; it ensures that the FirePass controller remains a hardened security device. All FirePass configuration must be performed through the FirePass Administrative and Maintenance Consoles.

The FirePass Maintenance Console offers a set of system administration tools, from basic network tools (such as ping and traceroute) to more complex tools (such as database repair and administrator password resets). The FirePass Administrative Console is the primary console for configuring the FirePass, and offers a wide variety of tools for day-to-day administration and troubleshooting. These include:

  • Reports and logs, which are located on the Reports menu.
  • Device health and monitoring tools, which are located on the Device Management: Monitoring menu.
  • Troubleshooting tools, which are located on the Device Management: Maintenance: Troubleshooting Tools menu.

Note: For information about accessing the FirePass Administrative Console, refer to the FirePass Controller Getting Started Guide.

Note: For information about accessing the FirePass Maintenance Console, refer to K9286: Accessing the FirePass Maintenance Console.
