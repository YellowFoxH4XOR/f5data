Description

The LTM log-file has lots of entries saying ""MR SIP: Failed to create Deny listener."
What does this error mean ? Is it a concern or issue ?

Environment

This happens when

  • Big-IP AFM Source Translation is used or if Big-IP CGNAT module is used
  • A Virtual Server is configured with a Session Initiation Protocol (SIP) application layer gateway (ALG) profile.

Cause

This message is informative only. The deny listeners are created to drop early media packets received before the 200OK from the INVITE is processed. If a client joins two calls at the same time and advertises the same IP and port for receiving media, then a "Failed to create Deny listener" log event will be seen.

Recommended Actions

None, this mesage is considered normal in scenario described above.
