Known Issue

This is the result of a known issue. The BIG-IP LTM system monitors CPU usage and adjusts HTTP compression rates when the CPU usage reaches one of the CPU Saver threshold settings. The BIG-IP LTM CPU saver setting adjusts compression rates incorrectly, resulting in NULL compression for HTTP data.

F5 Product Development tracked this issue as CR75638 and it was fixed in BIG-IP LTM 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

To work around this issue, disable the CPU saver by performing the following procedure:

  1. Log in to the Configuration utility.
  2. Click Local Traffic, then click Profiles.
  3. From the Services menu, select HTTP.
  4. Select the HTTP profile associated with your virtual server.
  5. In the Compression section, clear the CPU saver box.
  6. Click Update.
