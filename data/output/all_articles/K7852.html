Topic

The BIG-IP system will send an NXDOMAIN response for a resource record when a request is received for which the BIG-IP system does not have a wide IP configured, no resource record is configured in the BIND configuration or DNS cache entry. Some caching Local Domain Name System (LDNS) servers have been reported to negatively cache the NXDOMAIN response for an entire domain when receiving an NXDOMAIN response for a single record. As a result, all wide IPs for the domain will be inaccessible to all users of the affected caching LDNS. This undesired behavior is specific to the caching LDNS server and not the BIG-IP system.
