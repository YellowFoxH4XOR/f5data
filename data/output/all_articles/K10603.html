Known Issue

This is the result of a known issue. If you configure a legacy host favorite with a session variable in the Host or Port field, and the user’s master group has the Limit Legacy Hosts Access to Favorites only option enabled, the legacy host favorite fails to connect with the following error message where <host> is the remote host configured in the Host field and <port> is the remote port number configured in the Port field:

Can't connect to <host>:<port> (Security exception)

F5 Product Development tracked this issue as CR128935 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by disabling the Limit Legacy Hosts Access to Favorites only option. To do so, perform the following procedure:

Important: Disabling the Limit Legacy Hosts Access to Favorites only option allows users to configure their own legacy host connections.

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Application Access: Legacy Hosts: Master Group Settings page.
  3. In the Master Group menu, select the name of the master group you want to configure.
  4. Clear the Limit Legacy Hosts Access to Favorites only check box.
