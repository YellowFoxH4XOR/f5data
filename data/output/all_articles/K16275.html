Topic

You should consider using this procedure under the following conditions:

  • You want to modify the passwords for the root or admin users.
  • You want to reset a lost or forgotten root password.

Description

You should always modify the passwords for BIG-IQ system maintenance accounts from their defaults. The procedures in this article provide multiple ways to modify the system maintenance account password to comply with password policies, standards such as PCI compliance, or other security policies appropriate to your organization. If you lose or forget the root password, you can reset it without reinstalling the system software.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • To modify the root or administrator account password, you must have either administrator credential access to the BIG-IQ system interface or root user access to the advance shell command line.
  • To reset a lost root account password, you must have access to the BIG-IQ console screen.

Procedures

  • Modifying the system maintenance account password using the BIG-IQ system interface
  • Modifying the system maintenance account passwords using the tmsh utility
  • Resetting a lost or forgotten root account password

Modifying the system maintenance account password using the BIG-IQ system interface

To modify the system maintenance account password, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system interface.
  2. For BIG-IQ 4.4.0 and later: navigate to System > Access Control.
    For BIG-IQ 4.3.0 and prior: navigate to System > Users.
  3. For BIG-IQ 4.4.0 and later: In the Users panel, double-click the account name for which you want to reset the password.
    For BIG-IQ 4.3.0 and prior: Select the account name for which you want to reset the password, and click the gear symbol.
  4. In the Password box, type the new password.
  5. In the Confirm Password box, type the same password.
  6. Click Save.

Modifying the system maintenance account passwords using the tmsh utility

To modify the system maintenance account password using the Traffic Management Shell utility (tmsh), perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh by typing the following command:

    tmsh

  2. To modify the password for a user account, use the following command syntax:

    modify auth password <username>

    For example, to change the password for the user account admin2, type the following command:

    modify auth password admin2

  3. When prompted, type the new password.
  4. When prompted, retype the new password to confirm.
  5. To save the changes to the configuration files, type the following command:

    save /sys config

  6. To exit the tmsh utility, type quit, and press Enter.

Resetting a lost or forgotten root account password

To reset a lost or forgotten root account password, perform the following procedure:

Impact of procedure: This procedure requires that you restart the BIG-IQ system in Single-User Mode. While in this mode, the device is unable to process any service request.

  1. Start the system in single-user mode.

    Note: For specific instructions, refer to K4178: Restarting the BIG-IP system in single-user mode (GRUB 0.97).

  2. Type the following commands:

    mount -a

    passwd root

  3. When prompted, enter a new password.
  4. When prompted, retype the new password to confirm.
  5. To return to the normal operating mode, type exit or reboot.

    After the system restarts, you should be able to log in using the new password.
