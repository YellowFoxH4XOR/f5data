K2599: Reasons the Internet Weather Map Statistics page may display all zeros

Topic

The Internet Weather Map is a statistical page that displays results for Local Domain Name System (LDNS) probes, but these fields will not populate unless the following criteria are met:
  • You have at least one wide IP configured to use a dynamic load balancing method, such as Quality of Service (QoS) or Round Trip Time (RTT).
  • The wideip.conf file contains the geolocation file.

For information about configuring wide IP load balancing, refer to the 3-DNS Controller Reference Guide.

To verify that the wideip.conf file contains the required geolocation file, perform the following steps:

  1. Using a text editor, such as vi or pico, open the /config/3dns/wideip.conf and search for the globals section.
  2. Verify that the following line is included in the globals section:

    include geoloc 'netIana.inc'
  3. Optional: If the line described in step 2 is not included in the file, add it.
  4. Save the file and exit.
  5. Type the following command:

    3ndc restart

The Internet Weather Map statistical fields should now be populated. If they are not, contact F5 Technical Support for further assistance.
