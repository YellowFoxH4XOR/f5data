The makerand program is used to generate random data. This random data can be used for certificate generation, SSH, or any other program that uses random data. To use the makerand program, use the following syntax:

makerand <bits of randomness> > <filename>

For example:

makerand 4096 > file_of_randomness
makerand 1024 > ~/.rnd
