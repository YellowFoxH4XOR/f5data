Topic

You should consider using this procedure under the following condition:

  • You want to track the client-side load time for every HTTP response on a virtual server.

Description

To track client-side load time, BIG-IP Analytics injects JavaScript into HTTP responses. To minimize the impact on system performance, BIG-IP Analytics injects only the BIG-IP Client Side Performance Monitoring (CSPM) JavaScript into a subset of all responses. If you want to track the load time for every response on the assigned virtual server for troubleshooting or statistics calculation purposes, you can configure BIG-IP Analytics to do so by modifying the BigDB database.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You must have administrative access to the BIG-IP system.
  • You must have a properly configured virtual server and Analytics profile.
  • You have configured the Analytics profile with the Collected Metrics: Page Load Time set to Enabled.

Procedures

Enabling CSPM injection for every response

Impact of procedure: Increased processing overhead per connection may affect BIG-IP system performance, depending on connection volume.

  1. Log in to the BIG-IP command line.
  2. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  3. Configure the BIG-IP system to insert the CSPM JavaScript on every connection by typing the following three commands:

    modify sys db md.maxcspminjectionratio0 value 1
    modify sys db md.maxcspminjectionratio1 value 1
    modify sys db md.maxcspminjectionratio2 value 1

  4. Save the changes to the configuration by typing the following command:

    save sys config

Returning CSPM injection to the default ratio

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. Configure the BIG-IP system to insert the CSPM JavaScript on the default ratio of connections by typing the following three commands:

    modify sys db md.maxcspminjectionratio0 value 20
    modify sys db md.maxcspminjectionratio1 value 17
    modify sys db md.maxcspminjectionratio2 value 14

    Save the changes to the configuration by typing the following command:

    save sys config
