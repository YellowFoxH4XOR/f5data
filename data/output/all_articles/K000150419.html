K000150419: Azure Microsoft Defender for Cloud reports "Insecure Azure storage SAS token"

Type
Support Solution
Published
2025-03-18
Updated
2025-03-18
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000150419

Description

Azure Microsoft Defender for Cloud reports "Insecure Azure storage SAS token" on "/shared/vadc/azure/waagent/Extensions.Config.<num>.xml"

Environment

  • BIG-IP VE
  • Microsoft Azure
  • Microsoft Defender for Cloud

Cause

ID1621417

Recommended Actions

The version of Microsoft waagent that ships with BIG-IP VE places a storage account SAS token onto the filesystem at /shared/vadc/azure/waagent/Extensions.Config.<num>.xml. Later versions of Microsoft waagent do not write SAS tokens to disk. Please do not follow the remediation steps as instructed by Microsoft Defender since modifications or upgrades to the waagent that comes pre-installed on BIG-IP VE are not supported by F5. A future BIG-IP VE release with a fix for ID1621417 will upgrade waagent to a newer version that does not store insecure SAS tokens to disk.
