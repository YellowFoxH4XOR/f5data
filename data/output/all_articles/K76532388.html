K76532388: Generic SNMP network interface OID generates truncating integer value > 32 bits

Type
Support Solution
Published
2021-09-21
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K76532388

Description
When using a generic SNMP network interface OID to scan the F5 you may see the message "truncating integer value > 32 bits" in /var/log/ltm

Environment

  • Generic 32bit counter SNMP network interface OID scanning the F5               

Cause
You are using a generic 32bit counter SNMP OID for network interfaces

Also, there is a know Bug ID 774617: SNMP daemon reports integer truncation error for values greater than 32 bits
Fixed In:
16.0.0, 15.1.0.4, 14.1.4

Recommended Actions

  1. Use the F5 MIB K13322: Overview of BIG-IP MIB files

Additional Information

Note "truncating integer value > 32 bits" is a benign message that can be safely ignored. You can filter this on the remote syslog server or not generate them from the F5 following the below documentation:

K60431538 Debug snmpd[##]: truncating integer value > 32 bits messages appearing in syslog
