Known Issue

Although there are many situations when this issue could occur, it is most likely the result of a known issue. If you have disabled the only prober in a data center, or if BIG-IP is not able to act as a prober for the data center, the Configuration utility does not provide an error when you create the wide IP.

F5 Networks Product Development tracked this issue as CR9888 and CR41927.
