K1811: Recommendations for using Global Availability as a pool load balancing mode

Topic

If you configure the 3-DNS Controller with two pools using Global Availability load balancing, the 3-DNS Controller does not use the second pool, even if all the servers in the first pool are down.

This can happen if the 3-DNS Controller is using Return to DNS as the fallback load balancing method for the preferred (first) pool.

To correct this, change the fallback load balancing method to NONE for all pools except for the pool listed/ranked last.

For specific instructions about configuring the fallback load balancing method, refer to the 3-DNS Controller Reference Guide.
