K000152993: Sending PPP tunnel started/closed logs to remote Syslog or SIEM server

Type
Support Solution
Published

Updated
2025-08-13
Applies to

  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000152993

Description

When integrating F5 BIG-IP APM with a SIEM solution, there may be a requirement to forward only specific VPN session logs—specifically, logs indicating when a user connects ("PPP tunnel Started") and disconnects ("PPP tunnel Closed")—to the SIEM server. The goal is to avoid sending all APM logs and instead filter for only these session start and end events.

Environment

  • Product: F5 BIG-IP APM
  • Logging integration: Syslog forwarding to Remote Syslog or SIEM
  • Use case: VPN session logging (PPP tunnel events)

Cause

By default, BIG-IP APM can generate a large volume of logs, including all session and system events. Without filtering, all logs are sent to the SIEM, which may not be desirable for compliance or storage reasons. The requirement is to filter and forward only VPN session start and end logs.

Recommended Actions

To forward only VPN session start and end logs (PPP tunnel Started/Closed) to a remote SIEM server, configure a syslog filter on the BIG-IP system as follows:

 

  1. Create a syslog filter for PPP tunnel events:

    filter f_apm_ppp_tunnel { match("PPP tunnel.*(started|closed)" value("MESSAGE")); };

  2. Define the SIEM syslog destination:

    destination d_siem { udp("<Hostname or IP of SIEM>" port(514)); };

  3. Configure the log path:

    log { source(s_syslog_pipe); filter(f_apm_ppp_tunnel); destination(d_siem); };

  4. Apply the configuration using tmsh:

    modify sys syslog include "

    filter f_apm_ppp_tunnel { match(\"PPP tunnel.*(started|closed)\" value(\"MESSAGE\")); };

    destination d_siem { udp(\"<Hostname or IP of SIEM>\" port(514)); };

    log { source(s_syslog_pipe); filter(f_apm_ppp_tunnel); destination(d_siem); };

    "

  5. Verify the configuration:
    tmsh list sys syslog all-properties
  6. Test log forwarding:  Initiate VPN connections and disconnections to ensure only the relevant "PPP tunnel Started" and "PPP tunnel Closed" logs are sent to the SIEM.
