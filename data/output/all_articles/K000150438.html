K000150438: "An Error Has Occurred While Trying to Process Your Request" When Adding an Address List to a Virtual Server

Description

When adding an address list to a virtual server, you may encounter the error message: "An error has occurred while trying to process your request." This occurs if the address list is not explicitly selected before proceeding, even when only one list is available.

Environment

BIG-IP 

Cause

When adding an address list in the GUI, users need to manually select and highlight the desired list before proceeding. Unlike other configuration elements that use multiple selection boxes, this interface displays a single list without additional prompts. If no selection is made, even when only one list is available, the system returns the error: "An error has occurred while trying to process your request."
