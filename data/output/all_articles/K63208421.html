Description

After creating a DNS express zone, AXFR request cannot be completed and zone status is red. The following error message might be seen in LTM log file :  

Nov  7 18:09:46 <hostname> err zxfrd[1392]: 0153100e:3: Transfer of zone <zone_file_name> failed with rcode (REFUSED).

Environment
  • BIG-IP DNS
  • Creating a new DNSexpress zone
  • AXFR zone transfer is failing
  • Zone status is red

Cause

The source IP used by BIG-IP DNS system to initiate the AXFR process, is not authorized for zone transfers.
 
Recommended Actions
  1. Determine which IP address is used by the BIG-IP to initiate the AXFR zone transfer request.
  2. Allow this IP address in the external nameserver's configuration (allow-transfer option).

Additional Information

If you want BIG-IP DNS to initiate the IXFR process after receiving a DNS change notification request, specify the external name server's IP address in the "allow notify" section for the DNSexpress zone.
