Description

The BIG-IQ monitoring reports under "BIG-IQ WebUI ›› Monitoring ›› REPORTS ›› Device ›› iHealth ›› Reports"  show an alert for "Heuristics Name: H709036-1" with an incorrect device certificate expiry date.

Example: "Jan 01st 2021" while the actual device certificate expiry date is "Jan 02nd 2022".

Environment

  • BIG-IP
  • BIG-IP Monitoring Report
  • iHealth
  • Device Certificate
  • Wrong Expiry Shown

Cause

iHealth Diagnostic has detected the expired dates on the certificate for PrivateKeyUsage (Certificate Private Key Usage).

Recommended Actions

Either perform 1 of the following options.

  1. Remove this PrivateKeyUsage extension (Certificate Private Key Usage) from the device certificate during renewal
  2. Renew the certs without this PrivateKeyUsage extension (Certificate Private Key Usage)

Additional Information

The PrivateKeyUsage extension has been deprecated in later X.509 RFCs. The following excerpt is from RFC5280 as attached.

* Section 4.2.1.4 in RFC 3280, which specified the
        privateKeyUsagePeriod certificate extension but deprecated its
        use, was removed.  Use of this ISO standard extension is neither
        deprecated nor recommended for use in the Internet PKI.
