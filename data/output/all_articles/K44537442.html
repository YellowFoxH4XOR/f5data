Description

You want to quickly see which of your virtual servers have SYN cookie protection activated.

Environment

  • BIG-IP
  • Virtual Servers
  • Command Line Access

Cause

You need to know which virtual servers have SYN cookie protection activated.

Recommended Actions

The following command can be run via the BIG-IP CLI to list each virtual server and it's SYN cookie status.

tmsh show ltm virtual all-properties | grep -A1 "Virtual Server\|SYN Cookies"

The output of the command will look similar to the following:

[root@bigip1:Active:Standalone] config # tmsh show ltm virtual all-properties | grep -A1 "Virtual Server\|SYN Cookies"
Ltm::Virtual Server: virtual_server_1
------------------------------------------------------------------
--
SYN Cookies
  Status                         not-activated
--
Ltm::Virtual Server: virtual_server_2
------------------------------------------------------------------
--
SYN Cookies
  Status                         not-activated
--
Ltm::Virtual Server: virtual_server_3
------------------------------------------------------------------
--
SYN Cookies
  Status                         not-activated
--
