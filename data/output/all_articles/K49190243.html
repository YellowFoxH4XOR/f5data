Known Issue

The BIG-IP system may not correctly disaggregate uncommon IP protocol traffic.

This issue occurs when the following condition is met:

  • The BIG-IP system is configured to process uncommon IP protocol traffic on a VLAN with the default, Disaggregation (DAG).

For example, certain IP traffic, such as Generic Routing Encapsulation (GRE) or IPsec tunnel traffic, may not load balance evenly across multiple Traffic Management Microkernels (TMMs). As a result, the single TMM quickly becomes overloaded.

Impact

IP protocol traffic is unevenly distributed among multiple TMMs.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you view a tcpdump capture of the IP traffic, you observe that the BIG-IP system forwards the uncommon IP protocols traffic to a single TMM for processing.

Resolution

Status

F5 Product Development has assigned ID 652094 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. After upgrading to the fixed versions, you must enable these database variables. For more information about enabling these database variables, refer to K52184115: Configuring the BIG-IP system to disaggregate uncommon IP protocol traffic.
