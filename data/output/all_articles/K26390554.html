Description

When trying to create a local account, the password field is missing.

  • You can finished creating new local user but you are unable to use it for logging into the BIG-IP as there's no password set
     

Environment

  • BIG-IP
  • Local User Account
  • Remote Authentication is configured
     

Cause

This is expected behavior when you are using a remote authentication method.
 

Recommended Actions

If you encounter this issue, follow the steps below:

  1. Access the BIG-IP Configuration utility.
  2. On the Main tab, go to System > Users > Authentication.
  3. Verify the User Directory that you are using any Remote Authentication method. eg. Remote - LDAP or Remote - TACACS+.
  4. Scroll down. Under External User click "Change".
  5. Tick the "Fallback to Local" to enable it.
  6. Click "Finished".
You should now be able to create a new local user account and the Password field is available.
