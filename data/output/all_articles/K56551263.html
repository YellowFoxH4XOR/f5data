Security Advisory Description

The OSPFv3 parser in tcpdump before 4.9.3 has a buffer over-read in print-ospf6.c:ospf6_print_lshdr(). (CVE-2018-14880)

Impact

An attacker can gain access to sensitive information and can also cause a denial of service (DoS).

Security Advisory Status

F5 Product Development has assigned ID 842829 (BIG-IP), ID 838361 (BIG-IQ), ID 838693 (Enterprise Manager), and ID 838681 (F5 iWorkflow) to this vulnerability.
