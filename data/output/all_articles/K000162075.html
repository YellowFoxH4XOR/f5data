K000162075: Traffic Leakage Between Tenants When Sharing VLANs on F5OS-A (r2000/r4000)

Type
Support Solution
Published
2026-07-04
Updated
2026-07-04
Applies to
  • F5OS Products
  • F5OS-A: 1.8.X, 1.8.4, 1.8.3, 1.8.0
Source
https://my.f5.com/manage/s/article/K000162075

Description

When multiple tenants are configured to use the same VLAN on F5OS-A platforms (r2000 and r4000 series), all tenants receive the traffic intended for other tenants. This is a product limitation and occurs 100% of the time when identical VLANs are assigned to different tenants. This behavior can result in throughput issues and a lack of tenant isolation.

Environment

  • F5OS-A software
  • Platforms: r2000 and r4000 series
  • Multiple tenants configured with the same VLAN

Cause

Product limitation in F5OS-A. RFE ID 1587569

Answer/Recommended Actions

  • Assign a unique VLAN to each tenant to ensure proper traffic isolation and prevent cross-tenant traffic exposure.
  • If configuration changes are not feasible, be aware that all tenants will see each other's traffic and may experience throughput issues.

Additional Information

  • This behavior is by design for the affected platforms.
  • The issue does not affect r5000 platforms.
  • The only way to ensure tenant isolation is to avoid sharing VLANs across tenants.
