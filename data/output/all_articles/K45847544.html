Description

After an upgrade to version 15.1.x, the system stays in offline state and the CLI prompt shows botd down.

The show sys service all command indicates mysqld is failing to start, similar to the following:

asm          down, waiting for mysql to release running semaphore
mysql        down, Failed to initialize MySQL

Additionally, the show sys ha-status command shows bd in a failure state, similar to the following:

--------------------------------------------------------------------------------------------------------------------------
Sys::HA Status
Feature               Key              Action                        Fail  Feature  Take  Client  Proc             Timeout
                                                                           Enabled  Act   Data                     (sec)

--------------------------------------------------------------------------------------------------------------------------
proc-run              bd               go-offline-downlinks          yes   yes      yes   0       sod              10

Environment

  • MySQL
  • Upgrade

Cause

MySQL taking too long to initialize and times out after 2 minutes (bug ID 788949). This is most likely due to the system experiencing some high iowait and having too few CPU resources.

Recommended Actions

Firstly, roll back to a previous working volume.

If the system is a VE, allocate additional CPU cores. Then implement the workaround for bug ID 828937:

tmsh modify /sys db avr.stats.internal.maxentitiespertable value 2148

Reset the AVR stats:

touch /var/avr/init_avrdb

tmsh restart /sys service monpd

Finally, perform the upgrade once more to a new volume. mysqld should initialize.

Additional Information

Even though ID 828937 may be fixed in the target version, AVR tables may have grown to enormous size when the system was running on the previous version and then rolled forward.

You may also observe repeated messages similar to the following in /var/log/mysql.out:

waiting for mysql to set up permissions ...
waiting for mysql to set up permissions ...
MySQL is not yet setup, failed to initialize. Service would go down.
 ERROR! MySQL server PID file could not be found!
 ERROR! MySQL server PID file could not be found!
