K000138290: Declarative Onboarding not working following upgrade

Type
Support Solution
Published
2024-01-19
Updated
2024-01-19
Applies to
  • F5 Automation and Orchestration
  • F5 Declarative Onboarding
Source
https://my.f5.com/manage/s/article/K000138290

Description

Deployments using Declarative Onboarding are no longer working after a BIG-IP or BIG-IQ software upgrade.

 

A similar error may be returned like the one below:

Task Failed: Failed to complete onboarding task. code: 422, message: invalid config - rolled back, error: one or more properties must be specified

 

 

Environment

DO version has been updated after software upgrade

DO deployment was previously working

 

Cause

Defect in DO version

 

Recommended Actions

Upgrade DO to latest Long Term Support (LTS) version on GitHub:

https://github.com/F5Networks/f5-declarative-onboarding/releases

 

Additional Information

If issue persists, try installing the latest DO release and if issue persists you may log an issue on Github or raise an F5 support case for further investigation.
