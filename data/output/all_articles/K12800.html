Topic

Beginning with ARX 6.x, F5 introduces licensing requirements for ARX systems. Before you can configure and use a system running ARX 6.0.0 or later, you must activate a valid license on the system. The new licensing requirements apply to both new systems being shipped with ARX 6.x and with existing/legacy ARX systems being upgraded to ARX 6.x.

Description

To license a newly-purchased ARX platform running 6.x or later, perform the following two procedures:

  • Creating a license dossier
  • Activating the license

If you are upgrading an ARX platform from 5.x or earlier to 6.x or later, perform the following three procedures:

  • Obtaining a base registration key
  • Creating a license dossier
  • Activating the license

If you experience issues during the licensing process, refer to the following section:

  • Troubleshooting ARX licensing

Obtaining a base registration key

Before you can activate the license for the ARX, you must obtain a base registration key, which you need to activate and license ARX platforms. The base registration key is a 29-character string (XXXXXXX-XXXXXX-XXXXX-XXXX-XXXXXXX) that the system uses to create a license dossier, which it delivers to the F5 license server. The license server uses the dossier to produce a license that you can apply to only a specific ARX platform to enable features and enforce limits associated with the purchase of your F5 products.

Newly purchased ARX platforms

If you have purchased new F5 hardware that is shipping with ARX 6.x software, your chassis is pre-programmed with an assigned base registration key. When completing the interview wizard during initial setup, the base registration key appears as the default key when the system prompts you to enter the chassis base registration key.

Important: If you do not have a base registration key, you cannot license your ARX product. Contact your F5 Sales representative or F5 Technical Support.

Creating a license dossier

After you have obtained a base registration key, the system uses the key to create a license dossier. The ARX software generates the license dossier, which is an encrypted list of key characteristics that the system uses to identify the platform. The system generates the license dossier after you choose a license activation method. For additional information, refer to the Activating the license section of this Solution.

Activating the license

You may activate an ARX system license using an automatic or manual method, and both methods can be performed by using either the ARX Manager GUI or the command-line interface (CLI).

The automatic activation method requires that you configure the ARX with a DNS name server, and the ARX must have a routable network to the Internet and have access to the F5 license server (https://activate.f5.com).

The manual activation method is required if you have not configured your ARX system with a DNS name server, or the system does not have a routable network to the Internet that can reach the F5 license server https://activate.f5.com.

Note: F5 recommends that you use the automatic licensing activation method.

Activate the ARX license using the following procedures:

  • Activating automatic licensing using the ARX Manager GUI
  • Activating automatic licensing using the CLI
  • Activating manual licensing using the ARX Manager GUI
  • Activating manual licensing using the CLI

Note: For information about a known issue with automatic licensing not using the out-of-band management network, refer to K12898: Automatic Licensing of ARX products requires in-band management.

Activating automatic licensing using the ARX Manager GUI

  1. Log in to the ARX Manager GUI.

    Note: If this is a new ARX system, open a web browser on a work station attached to the network on which you configured the management interface. Then type the following URL in the browser, where <IP_address> is the address you configured for the management interface: https://<IP address>/

  2. Click Common Operations in the left navigation menu.
  3. If required, click Initial Setup to perform the initial setup wizard to configure proxy IPs, DNS, and so on.
  4. Click Activate License.

    A new License Wizard opens.

  5. For Registration Key, type the base registration key.

    Note: If you are activating an add-on key, select the This key is an add-on key, not a base key check box.

  6. For Activation Method, click Automatic.
  7. Click Next.
  8. Read the End User License Agreement (EULA) and select the I have read and agree to the terms of the EULA check box.

    Note: The EULA acceptance is only required during the initial license activation.

  9. Click Next.
  10. The ARX system now automatically generates a license dossier and communicates with the F5 license server.
  11. The License Wizard indicates that the license activation was successful by displaying the following message:

    The license was successfully activated. Review the license summary then click Finish or Cancel to close the wizard.

  12. Click Finish.

Activating automatic licensing using the CLI

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. To generate a license dossier and communicate with the F5 license server, use the following command syntax:

    license activate base-reg-key <Base_Reg_Key>

    For example:

    license activate base-reg-key GABCDEF-ABCDEF-ABCDE-ABCD-ABCDEFG

    Note: If F5 pre-programmed your ARX system with a base registration key or you entered the base registration key during the initial setup wizard, you can use the license activate command without specifying the base-reg-key <Base_Reg_Key>.

  4. The first-time activation requires acceptance of the 16-page EULA. The EULA begins with text similar to the following example:

    END USER SOFTWARE LICENSE FOR NON-COMMERCIAL USE
    IMPORTANT - READ BEFORE INSTALLING OR OPERATING THIS PRODUCT

  5. To accept the EULA, type yes and click Enter.
  6. After you have accepted the EULA, the ARX system automatically generates a license dossier and submits the dossier to the F5 license server. The F5 license server uses the dossier to validate the license request and automatically generates a license and installs it on the ARX system. The ARX system indicates that the license activation was successful by displaying a message that appears similar to the following example:

    % INFO: The license has been successfully activated.

Activating manual licensing using the ARX Manager GUI

  1. Log in to the ARX Manager GUI.

    Note: If this is a new ARX system, open a web browser on a work station attached to the network on which you configured the management port. Then type the following URL in the browser, where <IP_address> is the address you configured for the management interface: https://<IP address>/.

  2. Click Common Operations in the left navigation menu.
  3. If required, click Initial Setup to perform the initial setup wizard to configure proxy IPs, DNS, and so on.

    Note: If initial setup is required, Initial Setup is active and other buttons are not active. If the initial setup is not required, Initial Setup is not active and the other buttons are active.

  4. Click Activate License.

    A new License Wizard opens.

  5. For Registration Key, type the base registration key.

    Note: If you are activating an add-on key, select the This key is an add-on key, not a base key check box.

  6. For Activation Method, click Manual.
  7. Click Next.
  8. The ARX system generates and displays a license dossier in the under Step 1: Dossier in the License Wizard.
  9. For the manual activation method, click Copy/Paste.
  10. Select and copy the entire dossier.

    Important: Make sure that you select and copy the entire dossier before continuing.

  11. In Step 2: Licensing Server, click Click here to access F5 licensing server

    A new window to the F5 license server opens and displays the F5 Product Licensing / Activate F5 Product page.

  12. Paste the license dossier into the Enter your Dossier box.
  13. Click Next.

    The F5 license server validates the submitted license dossier and produces an ARX license.

  14. Select and copy the entire ARX license.
  15. Return to the License Wizard and paste the ARX license into the Step 3: License box.
  16. Click Next.
  17. The License Wizard indicates that the license activation was successful by displaying a message that appears similar to the following example:

    The license was successfully activated. Review the license summary then click Finish or Cancel to close the wizard.

  18. Click Finish.

Activating manual licensing using the CLI

Note: You should perform the following procedure from a system that can access the ARX CLI and has a routable network to the Internet which has access to the F5 license server.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. Use the license create license-dossier command to generate a license dossier.

    To create a license dossier using a base registration key, use the following command syntax:

    license create license-dossier base-reg-key <Base_Reg_Key>

    To create a license dossier using an add-on registration key, use the following command syntax:

    license create license-dossier add-on-key <Add-on_Reg_Key>

    For example:

    license create license-dossier base-reg-key GABCDEF-ABCDEF-ABCDE-ABCD-ABCDEFG

    Note: If F5 pre-programmed your ARX system with a base registration key, or you entered the base registration key during the initial setup wizard, you can use the license create license-dossier command without specifying the base-reg-key <Base_Reg_Key>.

  4. Display the license dossier by typing the following command:

    show license-dossier

  5. Select and copy the entire dossier.

    Note: The next step requires a routable network to the Internet to access the F5 license server. If the system you are working from cannot access the F5 license server, you must paste the dossier from your copy buffer into a file that you can save onto a system that can access the F5 license server. You can also use the copy command to copy the license arx.dossier file from the ARX system to a location that you can access from the system you will be using to access the F5 license server. For information about the copy command, refer to the ARX CLI Reference Guide. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

  6. From a system with access to the F5 license server, open a browser window to the F5 license server's F5 Product Licensing / Activate F5 Product page.
  7. Paste the license dossier into the Enter your Dossier box.

    Note: Alternatively, you can click Browse and navigate to the arx.dossier file if you previously saved the license dossier to a file.

  8. Click Next.

    The F5 license server validates the submitted license dossier and produces an ARX license.

  9. Click Download license.
  10. Navigate and save the license file to a location or device that you can access using the copy command from your ARX system.

    Note: The default name of the file is License.txt.

  11. From the ARX system, use the copy command to copy the license file to the ARX license area using a command syntax similar to the following:

    copy ftp://[user[:password]@]server/source_license_name license [license_file_name]

    For example:

    copy ftp://guest:asdf@192.168.98.100/tmp/License.txt license arx.license

    The copy command output, which appears similar to the following example, indicates that you have successfully copied the license file to the ARX system:

    % INFO: The copy of source file 'License.txt' to destination file 'arx.license' completed successfully.

    Note: For information about the copy command refer to the ARX CLI Reference Guide. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

  12. Activate the license on the ARX system using the following command syntax:

    license activate file <license_file_name>

    For example:

    license activate file arx.license

  13. The first-time activation requires acceptance of the 16-page EULA. The EULA begins with text similar to the following example:

    END USER SOFTWARE LICENSE FOR NON-COMMERCIAL USE
    IMPORTANT - READ BEFORE INSTALLING OR OPERATING THIS PRODUCT 

  14. To accept the EULA, type yes and click Enter.
  15. After you have accepted the EULA, the ARX system indicates that the license activation was successful by displaying a message that appears similar to the following example:

    % INFO: The license has been successfully activated.

Troubleshooting ARX licensing

  • Verifying connectivity to the F5 License server for automatic activation
  • Displaying the ARX DNS name server configuration
  • Displaying the currently active license

Verifying connectivity to the F5 License server for automatic activation

  1. Log in to the ARX CLI.
  2. Use the ping license-server command to verify connectivity between the ARX system and the F5 license server by typing the following command:

    ping license-server base-reg-key <base_key>

    If the ARX system can connect to the F5 License server, the command output appears similar to the following example:

    % INFO: Activation server response: 'Mon May 02 12:00:00 UTC 2011'

    Note: If the optional base-reg-key <base_key> command option is not used with the ping license-server command, the ARX may attempt to connect to an internal F5 license server. For information, refer to K13058: The 'ping license-server' command may attempt to use an internal F5 license server.

    If this command fails, verify that you have configured a DNS name server in your ARX configuration and that networking is functioning on your ARX. If DNS is configured and networking is functional, you may need to use one of the manual activation methods.

Displaying the ARX DNS name server configuration

  1. Log in to the ARX CLI.
  2. To verify name resolution for the automatic licensing activation method, use the show ip domain command to display the ARX DNS name resolution configuration. The command output should appear similar to the following example:

    DNS Server Configuration
       Domain List:    dsforest1.com
       Name Servers:   172.30.65.50

  3. If you do not have a DNS name server configured, use the ip name-server command in config mode to specify the IP address of the DNS server. For information about the ip name-server command, refer to the ARX CLI Reference Guide.

    Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.
