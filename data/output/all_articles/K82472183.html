K82472183: WARNING: Thermal fault detected in hardware

Type
Support Solution
Published
2023-04-06
Updated
2023-04-06
Source

Description

You may encounter a thermal fault warning in your hardware when running the show system alarms command, displaying the following output:

# show system alarms
ID     RESOURCE   SEVERITY  TEXT                                TIME CREATED
---------------------------------------------------------------------------------------------------
65546  appliance  WARNING   Thermal fault detected in hardware  2022-04-20 13:31:05.693021478 UTC

Environment

This issue may occur on rSeries r5900 devices with F5OS-A version 1.0.1 and BIOS version 1.02.109.1.

Cause

The cause of this issue is a known bug (BUG ID 923609) where the MEMHOT_OUT_L CPU signal is asserted during POST. The alarms are not cleared after each POST, leading to this problem.

Recommended Actions

To resolve this issue, update the BIOS to version 1.02.110.1 or higher.
This fix will also be available as part of the 1.1.0 release.

Additional Information

None.
