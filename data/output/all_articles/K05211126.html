Topic

In November 2015, F5 divided the BIG-IQ product line into two offerings; BIG-IQ Centralized Management, to centrally manage the system, and BIG-IQ Cloud and Orchestration, to manage the system in networks based on Cisco ACI and VMware NSX technology.

The BIG-IQ Cloud and Orchestration functions, including the Cisco APIC and VMware NSX integrations, iControl proxy, and iApp lifecycle management were available with each purchase of the BIG-IQ system as a separate download. However, this product line reached End of Life (EoL) on November 18, 2018. For more information, refer to K15073: BIG-IQ software support policy. The F5 iWorkflow product continues to support Cisco APIC and VMware NSX integrations. For information about compatibility, refer to K11198324: F5 iWorkflow compatibility matrix.

Description

BIG-IQ Centralized Management 4.6.0 was the next version that F5 released after BIG-IQ 4.5.x and is part of the supported upgrade path for the BIG-IQ system. The BIG-IQ Centralized Management 4.6.0 release includes support for managing both physical and virtual BIG-IP devices that run TMOS 12.0. BIG-IQ Centralized Management supports administrative tasks, such as discovery and inventory, TMOS upgrades, configuration file and license management, and monitoring and central management of security policies.

You cannot use the BIG-IQ Centralized Management and F5 iWorkflow systems to manage the same device; you should manage a device with one or the other, but not both products. You should install and operate the two systems on separate devices with separate dedicated licenses.

BIQ-IQ Cloud and Orchestration

The BIG-IQ Cloud and Orchestration system was available as a software appliance. BIG-IQ Cloud and Orchestration 1.0.0 can support both BIG-IP hardware and Virtual Edition (VE) instances; however, it does not provide central management of BIG-IP devices, LTM policies, or security functions. This product delivers production-ready iApp lifecycle management to BIG-IP systems that are integrated into the Cisco APIC and VMware NSX environments. The BIG-IQ Cloud and Orchestration system injects application-specific Layer 4 through 7 intelligence into Cisco ACI and VMware NSX-based networks through the use of F5 iApp technology. The BIG-IQ Cloud and Orchestration system also supports local cloud connections to discovered devices. In June 2016, the BIG-IQ Cloud and Orchestration product name changed to F5 iWorkflow. For more information, refer to K13240900: The BIG-IQ Cloud and Orchestration product name has changed to F5 iWorkflow.

BIG-IQ Centralized Management

The BIG-IQ Centralized Management system manages F5 physical and virtual devices, as well as the following software modules:

  • BIG-IP LTM
  • BIG-IP AFM
  • BIG-IP APM
  • BIG-IP ASM
  • BIG-IP DNS

BIG-IQ Centralized Management is available both as a virtual appliance and on the BIG-IQ 7000 hardware platform. BIG-IQ Centralized Management can support both BIG-IP hardware and BIG-IP VE instances. You can deploy this release onto existing hardware or virtual machines. You can use the BIG-IQ Centralized Management system to centrally administer license management and license usage reporting using the BIG-IQ Centralized Management system. The BIG-IQ Centralized Management system can back up configurations and restore functions and act as a centralized repository for BIG-IP UCS files. The BIG-IQ Centralized Management system is also capable of completing these tasks on a scheduled basis. You can access BIG-IQ Centralized Management functions through a comprehensive set of RESTful APIs. In addition, the BIG-IQ Centralized Management system can proxy API calls to BIG-IP devices.

Recommendations

If you have existing versions of BIG-IQ 4.x or BIG-IQ Cloud and Orchestration, you should deploy the latest version of BIG-IQ Centralized Management or F5 iWorkflow.. If you are using both BIG-IQ Cloud and Centralized Management functionality, contact your account team to discuss options.
