Topic

This article describes the HTTP cache behavior as it relates to the protocol version of server-side requests in different BIG-IP versions.

Description

In BIG-IP 11.x to 14.x, when the HTTP cache is enabled on a virtual server by way of the web acceleration profile, all server-side requests generated by that virtual server will use the HTTP/1.0 protocol. This also applies to server-side requests derived from an HTTP/1.1 client-side request; all HTTP/1.1 requests are rewritten to HTTP/1.0.

A Connection: Keep-Alive header is added dynamically to server connections using HTTP/1.0 only when needed for connection reuse.

This behavior is by design and cannot be changed by a BIG-IP administrator. The HTTP cache will translate all HTTP requests to HTTP/1.0 to simplify the required caching logic. To use the BIG-IP HTTP cache functionality, ensure that your servers are configured to allow HTTP/1.0 requests.

In BIG-IP 15.0.0 and later, HTTP/1.1 is maintained on the server side when HTTP cache is enabled on a virtual server.
