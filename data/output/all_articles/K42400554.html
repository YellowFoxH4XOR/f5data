Known Issue

A non-default Header Table Size setting on an HTTP2 profile may cause issues.

This issue occurs when the following condition is met:

  • You have configured an HTTP2 profile with a header-table-size value that exceeds 4096.

Impact

You experience periodic HTTP2 connection failures to the virtual server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In response to the headers frame, the HTTP2 connection sends an RST_STREAM due to a protocol error.

Workaround

To work around this issue, you can restore the Header Table Size to the default value of 4096. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Services > HTTP/2.
  3. Select the Custom HTTP/2 profile that the system is using.
  4. Set view to Advanced.
  5. Locate the Header Table Size box and type 4096.
  6. Click Update.
