K000130568: Many TCP RST after upgrade from version 12.x.x to later versions

Type
Support Solution
Published
2023-01-19
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 12.1.5
Source
https://my.f5.com/manage/s/article/K000130568

Description

  • A lot of TCP idle timeout Reset Packets in the Packet Capture or external monitoring.

Environment

  • TCP profile
  • BIG-IP

Cause

After the upgrade TCP profile idle timeout returns to default value.


 Recommended Actions

Investigate TCP profile settings and change the idle timeout from 300 (default) to a higher value for example 3600.
