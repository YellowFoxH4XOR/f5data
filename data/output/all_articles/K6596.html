Known Issue

Important: This article applies to the BIG-IP 1000, 2400, 5100, and 5110 platforms.

This is the result of a known issue. TMM does not determine if the BIG-IP system is licensed for the BIG-IP Link Controller module. As a result, TMM takes extra memory from the Linux kernel. This may cause userland processes to crash and push the Linux host near memory capacity.

F5 Product Development tracked this issue as CR69158 and it was fixed in BIG-IP Link Controller 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP Link Controller Release Notes.
