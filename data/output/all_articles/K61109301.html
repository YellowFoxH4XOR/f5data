Description

  • Synopsis of issue: ssh connection to BIG-IP disconnected just after executing any command, GUI is working
  • Symptoms:  root (/) file system is full
  • /var/log/ltm error messages: Can't update command history file (/root/.tmsh-history-d463269), No space left on device : framework/CmdHistoryFile.cpp, line 244

Environment

  • BIG-IP 
  • Out of disk space 

Cause

No free space on the root partition

Recommended Actions

Free some disk space in / partition.

1) Check if the root partition is full:

df -h

2) if "/" partition is full, find the big file which can be deleted to free space: -

find / -xdev -type f -exec du {} \; | sort -rn | head -40

None
