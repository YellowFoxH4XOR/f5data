Description

By default, BIG-IP uses the traditional BSD syslog format (commonly referred to as RFC 3164-style syslog) for local and remote logging. This format is the legacy syslog standard and differs from the newer RFC 5424 structured syslog format.

Environment

Syslog

BIG-IP

Cause

Expected default behavior

Recommended Actions

The BIG-IP uses BSD syslog by default, RFC 3164. So it is not using RFC5424. 

You can use tcpdump to verify the format:

[root@big-ip-Active:Standalone] config # tcpdump -nnvi mgmt host <syslog-server-ip> 

Msg: Feb 10 14:35:02 gallery-big-ip-17-5-1-3.seattle.*****.****.com notice root[6023]: testing\0x0a

If the format shows similar output above, they start with "mm dd hh:mm:ss", it means that it is using BSD format (RFC 3164). On the other hand, if it  RFC5424, would shows something like "2026-02-10T14:31:17Z ". This can be configured by following K000130558: Configure Remote syslog using RFC5424
