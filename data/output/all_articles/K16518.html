Issue

Error Message

Can't find requested disk HD1.

In this error message, note the following:

  • HD1 is the installation disk volume name.

For example:

Terminal error: Can't find requested disk HD1.

Message Location

You may encounter this message in the following locations:

  • The tmsh show sys software command output
  • The /var/log/liveinstall.log file

Description

This message occurs when the following condition is met:

  • You attempt to perform an upgrade by installing BIG-IP 10.2.4 HF9 or HF10 on the BIG-IP system that is using the partitions disk-formatting scheme.

After you attempt to upgrade, you may observe the following:

  • When using the Traffic Management Shell (tmsh) to review the system software status, you may observe the following error message:

    Sys::Software Status
    Volume  Product  Version  Build  Active                                   Status
    --------------------------------------------------------------------------------
    HD1.1    BIG-IP   10.2.4  577.0     yes                                 complete
    HD1.2    BIG-IP   10.2.4  860.0      no  failed (Can't find requested disk HD1.)

  • When reviewing the /var/log/liveinstall.log file, you may observe the following error message:

    sfdisk: ERROR: sector 8338176 does not have an msdos signature
    Terminal error: Can't find requested disk HD1.

Impact

You are unable to complete the BIG-IP 10.2.4 HF9 or HF10 upgrade using the partitions disk-formatting scheme.

Recommended Actions

  • You should consider installing BIG-IP 10.2.4 HF11, which is the latest BIG-IP 10.2.4 hotfix.

    Note: BIG-IP 11.x does not support the use of the partitions disk-formatting scheme. For more information, refer to K15459: BIG-IP systems that use partition disk style cannot be upgraded to versions 11.0.0 or later
