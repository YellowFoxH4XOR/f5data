Topic

F5 discovered and corrected a number of critical issues that affect customers running FirePass 6.1.0. F5 recommends that all customers currently running version 6.1.0 install cumulative HF-610-4, or a later version of the cumulative hotfix, as soon as possible.

The following CRs are fixed in cumulative HF-610-4 for FirePass 6.1.0:
