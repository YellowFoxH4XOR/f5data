Known Issue

An SSL handshake may fail when referencing an SSL certificate/key pair on the Thales Hardware Security Module (HSM).

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured to use the Thales nShield device as an external HSM.
  • The SSL profile references a certificate/key pair stored on the Thales HSM.
  • The certificate/key pair was generated using the Thales generatekey utility on the BIG-IP system.

In a typical Thales HSM deployment, the BIG-IP system is installed with the Thales nShield Connect component, which includes the generatekey utility and the Remote File System (RFS) tools. The BIG-IP system is then configured as an RFS client for enrollment with the Thales RFS server in order to access the encrypted keys from the Thales HSM. The Thales generatekey utility can be used to generate private keys, self-signed certificates, and certificate signing requests on a BIG-IP system as well as import a software-based key to the BIG-IP system.

Impact

SSL connections using the affected certificate/key pair cannot be established.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H419593 on the Diagnostics > Identified > Medium screen.
  • SSL connections cannot be established to a virtual server that is associated with an SSL profile referencing the affected certificate/key pair stored on the Thales HSM.
  • Error messages are logged to the /var/log/ltm file. The error messages appear similar to the following example:

    tmm3[8859]: 01260009:7: Connection error: ssl_hs_cn_vfy_fin:1547: bad verify data (20)
    tmm3[8859]: 01260013:6: SSL Handshake failed for TCP from 10.10.20.38:41960 to 10.10.20.212:443

Workaround

To work around this issue, you can restart the pkcs11d and the TMM processes. To do so, perform the following procedure:

Impact of workaround: Restarting TMM interrupts traffic processing, and you should perform this procedure during a maintenance window.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Restart the pkcs11d process by typing the following command:

    restart /sys service pkcs11d

  3. Restart the TMM process by typing the following command:

    restart /sys service tmm

  4. To exit tmsh, type quit, and press Enter.
