K000134872: "ERR_SSL_VERSION_OR_CIPHER_MISMATCH" error when trying to access through BIG-IP by GUI

Type
Support Solution
Published
2023-06-12
Updated
2023-06-16
Source
https://my.f5.com/manage/s/article/K000134872

Description

The next error is shown in the browser:


This site can't provide a secure connection


IP x.x.x.x uses an unsupported protocol.


ERR_SSL_VERSION_OR_CIPHER_MISMATCH


Environment

  •  BIG-IP LTM
  •  Configuration Utility (GUI)
  •  SSL cipher

Cause

Unknown at the time of publication 

 Recommended Actions

1 - Verify that SSL version 1.2 and 1.3 are not disabled.


config # tmsh list /sys httpd { ssl-ciphersuite ssl-protocol }


sys httpd {

  ssl-ciphersuite ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256

  ssl-protocol TLSv1.1

}


2 - If SSL version 1.2 and 1.3 are disabled, enable them using the next procedure:


3 - Login TMSH


(config) # tmsh 


4 - Modify the SSL protocol:


(tmos)# modify /sys httpd ssl-protocol "all -SSLv2 -SSLv3 -TLSv1"


5 - Save the configuration:


(tmos)# save /sys config


Saving running configuration...

 /config/bigip.conf

 /config/bigip_base.conf

 /config/bigip_user.conf

Saving Ethernet mapping...done


6 -Once the configuration is saved, verify that the SSL protocol 1.2 and 1.3 are enabled:


config # tmsh list /sys httpd { ssl-ciphersuite ssl-protocol }


sys httpd {

  ssl-ciphersuite ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256

  ssl-protocol "all -SSLv2 -SSLv3 -TLSv1"

}
