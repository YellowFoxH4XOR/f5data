K000163466: Selecting Windows APM client services for redeployment after signing certificate rotation

Description

If you need to redeploy Windows APM client components after the signing certificate rotation, include the services your users need. Installing the Component Installer Service alone does not deploy the DNS Relay Proxy Service or Machine Certificate Checker Service. Do not assume it will update either service automatically; verify the installed versions. Have an administrator preinstall required services for users without local administrative privileges.

Environment

  • BIG-IP Access Policy Manager (APM)
  • Windows BIG-IP APM client redeployment after the signing changes in K000157975 and K000160684
  • VPN users and users subject to machine certificate endpoint inspection checks

Cause

The Component Installer Service alone does not deploy every service needed by the client.

Recommended Actions

  1. Follow the applicable redeployment guidance in K000157975 and K000160684.
  2. In Access > Connectivity / VPN > Connectivity, select the connectivity profile and Customize Package. Include:
    • All use cases: Component Installer Service, unless you manage client component updates manually.
    • VPN use cases that need DNS Relay Proxy functionality: DNS Relay Proxy Service. Without it, users with limited privileges may see elevation prompts when DNS settings change (K72735781).
    • Machine certificate endpoint inspection checks: Machine Certificate Checker Service, particularly for users without local administrative privileges (K36326144).
  3. Have an administrator deploy the required services before limited-privilege users connect. Verify their installation and versions on a test endpoint. Do not assume Component Installer Service alone deploys or updates the DNS Relay Proxy Service or Machine Certificate Checker Service.

Additional Information

Machine Certificate Checker Service is not Machine Tunnel Service (K14045). Selecting Machine Tunnel Service in a custom package also installs DNS Relay Proxy Service, even if its separate checkbox is clear (K000092562).
