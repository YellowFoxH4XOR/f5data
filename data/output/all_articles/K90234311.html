Description

  • Declarative onboarding fails if the device is not licensed or a license class is not included
  • An error message similar to the following may occur when requesting the declarative onboarding task ID.
    $ curl -sku $CREDS https://$IP/mgmt/shared/declarative-onboarding/task/2053144b-ad88-49ac-921d-1db4c043548e | jq .
    {
      "id": "2053144b-ad88-49ac-921d-1db4c043548e",
      "selfLink": "https://localhost/mgmt/shared/declarative-onboarding/task/2053144b-ad88-49ac-921d-1db4c043548e",
      "code": 500,
      "status": "ERROR",
      "message": "failed to initialze device",
      "errors": [
        "tryUntil: max tries reached: System is not ready yet"
      ],
      "result": {
        "class": "Result",
        "code": 500,
        "status": "ERROR",
        "message": "failed to initialze device",
        "errors": [
          "tryUntil: max tries reached: System is not ready yet"
        ]
      }
  • You may see the following errors in restnoded logs:
    Thu, 07 Jan 2021 18:18:43 GMT - finest: [f5-declarative-onboarding: restWorker.js] tryUntil: got error {}
    Thu, 07 Jan 2021 18:18:43 GMT - finest: [f5-declarative-onboarding: restWorker.js] typeof err object
    Thu, 07 Jan 2021 18:18:43 GMT - finer: [f5-declarative-onboarding: restWorker.js] tryUntil error: System is not ready yet tries left: 87
    Thu, 07 Jan 2021 18:18:43 GMT - finest: [f5-declarative-onboarding: restWorker.js] tryUntil: retryOrReject: numRemaining: 87 , code: {} , message: System is not ready yet
  • LTM logs will no longer progress.

Environment

  • The target device is not licensed.
  • The declarative onboarding JSON does not contain a license class.

Cause

Declarative onboarding cannot proceed with loading configurations when the associated modules are not licensed.

Recommended Actions

  1. License the device prior to sending the declarative onboarding request.
    or
  2. Include a license class similar to the following in the declarative onboarding request.
            "myLicense": {
                "class": "License",
                "licenseType": "regKey",
                "regKey": "AAAAA-BBBBB-CCCCC-DDDDD-EEEEEEE"
            },

Additional Information

Composing a Declarative Onboarding declaration for a standalone BIG-IP
