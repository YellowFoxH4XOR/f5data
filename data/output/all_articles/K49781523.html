Known Issue

You may be unable to import an access profile with an access policy SecurID agent configuration.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an access profile where the access policy uses the SecurID Auth agent.
  • A user has successfully established an access session using the access profile.
  • You export the access profile.
  • You attempt to import the access profile.

Impact

You are unable to import the access profile.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to import the access profile using the Configuration utility, the access profile does not import and the system does not display an error.
  • When you attempt to import the access profile using the command line utility ng_import, the system displays an error message similar to the following example:
    Unable found BodyObjecct for embedded join aaa securid server /@partition/@name-rsa-secureID_aaa_1

Workaround

To work around this issue, you can modify the access policy before you perform the export. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure temporarily removes authentication from the access policy of the access profile you are exporting.

  1. Log in to the Configuration utility.
  2. Navigate to Access Profiles > Access Profile List.
  3. To open the VPE editor, in the Access Policy column, to the right of the affected access profile, click the Edit link.
  4. Click the RSA SecurID box.
  5. Note the AAA Server setting.
  6. Set the AAA Server to None.
  7. Click Save.
  8. In the upper-left corner of the VPE editor, click the Apply Access Policy link.
  9. To exit the editor, in the upper-right corner of the VPE editor, click Close.
  10. Navigate to Access Profiles > Access Profile List.
  11. To the right of the modified access profile, click Export.
  12. After the access profile export download has completed, click the Edit link to open the VPE editor of the access profile.
  13. Click the RSA SecurID box.
  14. Set the AAA Server to the original server setting from step #5.
  15. Click Save.
  16. In the upper-left corner of the VPE editor, click the Apply Access Policy link.
  17. To exit the editor, in the upper-right corner of the VPE editor, click Close.
