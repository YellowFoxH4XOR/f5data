Known Issue

This is the result of a known issue. An FTP data connection can crash the Traffic Management Microkernel (TMM) on a client-side failure. If an error occurs in the data channel configuration of an FTP connection, the BIG-IP LTM system closes the client-side connection but does not close the server-side connection.

The crash can occur when the BIG-IP LTM system attempts to remove the corresponding client-side connection of the server-side connection, which no longer exists as it was closed when the data channel configuration error first occurred.

F5 Product Development tracked this issue as CR76052, and it was fixed in BIG-IP LTM 9.4.1 and 9.4.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.3-HF4 issued for BIG-IP 9.4.3. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about managing F5 product hotfixes, refer to K6845: Managing BIG-IP product hotfixes (9.x).
