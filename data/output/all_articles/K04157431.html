Known Issue

When a network address translation (NAT) object is created, and its inherit traffic group option is set, this property does not sync to other devices.

This issue occurs when all of the following conditions are met:

  • You are attempting to perform an incremental configuration synchronization (ConfigSync) between systems in a device group.
  • You have a NAT translation object configured with the inherit traffic group option set on the source system.

Impact

The traffic group configuration may be inconsistent across systems in a device group.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you perform a ConfigSync, the inherit traffic group option is not set on other devices in the device group.

Workaround

To work around this issue, you can configure the Full Sync option for ConfigSync. To do so, perform the following procedure:

Impact of workaround: There may be a small performance impact when synchronizations occur.

  1. In the BIG-IP Configuration utility, navigate to Device Management > Device Groups.
  2. Select your sync device group.
  3. Check the Full Sync box.
  4. Click Update.

Note: You cannot select both Automatic Sync and Full Sync. For more information refer to K14809: Auto Sync is possible for Sync-Failover device groups.
