Description

You want to configure automated UCS backups in the BIG-IP and you are wondering about available options.

Environment

  • Automating UCS backups.

Cause

You used to be able to create automated backups through an iApp in version 13.1 or lower but since iApps stopped being supported in newer versions the only officially supported method to create scheduled backups for a BIG-IP is using BIG-IQ. 

Recommended Actions

  • Configure automated backups using the logrotate and crontab utilities. K13418: Archiving UCS files using the logrotate and crontab utilities (11.x - 16.x)
  • Schedule a UCS archive backup with AWX or Ansible Tower. K35454259: Schedule a UCS archive backup with AWX or Ansible Tower
  • Use a BIG-IQ to configure automated backups
  • K000132479: REST API call to BIG-IQ to create BIG-IP UCS Backup
