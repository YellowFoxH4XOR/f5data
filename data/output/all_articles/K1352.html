Topic

To configure the BIG-IP WMI Data Collecting Agent (ISAPI) for use with Windows Media Server and Dynamic Ratio, you must complete the following tasks:

  • Install the Data Gathering Agent (F5lsapi.dll) onto the server.
  • Configure the Monitor to gather statistics for use with Dynamic Ratio.

Installing the Data Gathering Agent (F5Isapi.dll) onto the server

You must have console access to your BIG-IP server to install the Data Gathering Agent. Once you gain console access, perform the following steps:

  1. From /usr/contrib/f5/isapi (the URL is https://<bigip_address>/doc/isapi/f5isapi.dll), download the Data Gathering Agent (F5Isapi.dll) plugin.
  2. Copy the f5isapi.dll file to the C:\Inetpubscripts directory (default IIS configuration) or to your user-defined scripts directory.
  3. Open the Internet Services Manager.
  4. From the left navigation pane of the Internet Services Manager, open the <machine_name>Default Web SiteScript folder, where <machine_name> is the name of the server that you are configuring.

    The Script folder contents open in the right pane.

  5. From the Script folder, right click F5Isapi.dll and select Properties.

    The F5Isapi.dll Properties box opens.

  6. Deselect Logvisits.

    This eliminates the logging of each visit so that the agent does not unnecessarily fill the log file.

  7. Click the File Security tab.

    The File Security options will appear.

  8. In the Anonymous access and authentication control group box, click Edit.

    The Authentication Methods box opens.

    Important: The following step, Step 9, is the cause of most configuration failures. If this step is not performed properly, the agent will not be able to send data. If a failure occurs, perform a tcpdump. The server should return a response that will lead you to the source of the error. Be sure to use -Xs 1500 flags so you can see the text the server sends back.

  9. In the Authentication methods box, clear all check boxes, then select Basic Authentication.

    Click OK to accept the changes.

  10. In the Properties box, click Apply.

    The WMI Data Gathering Agent is now ready to be used.

Configuring the Monitor to gather statistics for use with Dynamic Ratio

Note: When you configure a monitor, you must enter a user name that has the proper NT/IIS permissions in order to access the DLL. Or, you can choose to use anonymous access, in which case it does not matter what user name you enter in the monitor configuration, as opposed to Basic Authentication. Again, you must choose a proper user.

Use the Configuration utility or bigpipe command to create a health check monitor with the WMI monitor template, which is located in the Monitors section of the BIG-IP Configuration Utility. (If you are using a command line interface, refer to the bigpipe man pages.)

Note: For more specific information on the WMI monitor template, refer to the Monitors section of the BIG-IP manual.

The monitor template contains default values for all the attributes. To create a custom monitor from the template, you need only to change the null values for user name and password.

The monitor fields are defined as follows:

Interval
The interval at which the BIG-IP performs a monitor check. The default is 5 seconds. You can change this to any number.

Timeout
The number of seconds in which the node or service must respond to the BIG-IP monitor request. If the target responds within the set time period, it is considered up. If the target does not respond within the set time period, it is considered down. The default is 16 seconds. You can change this number to any number; however, it should be 3 times the interval number of seconds plus 1 second.

User Name
The user name for authentication on the WMI service. Authentication is required for WMI services.

Password
Enter the corresponding password for the user name.

Method
The Method is POST. You cannot edit this attribute.

URL Path
The path to the F5Isapi.dll file. If you installed the Data Gathering Agent to the default directory, you do not need to edit this box. If you installed F5Isapi.dll to a different directory, enter that URL path in this box.

Command
Refer to the table in the BIG-IP Reference Guide for a complete listing of available commands.

Metrics
Refer to the table in the BIG-IP Reference Guide for a complete listing of metrics.
