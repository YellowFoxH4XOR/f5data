Description

When attempting to upgrade NGINX Plus from version R32 (or earlier) to R33 (or later) on AWS Marketplace, standard in-place package upgrades are not supported. It is required to run the instance from a new image containing version R33.

Environment

  • AWS Marketplace;
  • NGINX Plus R32 (or earlier versions);
  • Need to upgrade to NGINX Plus R33 (or later versions).

Cause

Starting with NGINX Plus R33, significant changes were introduced to the NGINX Plus image and licensing model. These changes include:

  • Introduction of JWT (JSON Web Token) based licensing;
  • Fundamental changes to the AMI image structure.

Due to these architectural changes, in-place upgrades from NGINX Plus versions R32 (or earlier) to R33 (or later) are not supported. The upgrade requires running new instances from updated AMI images.

Answer/Recommended Actions

The R33+ images differ significantly from previous ones. This is because they incorporate a new licensing model. Therefore, upgrading from versions R32- is only possible by recreating the instance from a new AMI image with NGINX Plus R33+.

Additional Information

  • This migration requirement applies to all upgrades from R32 and earlier to R33 and later versions;
  • Always maintain current backups of configurations before beginning migration.
