Known Issue

This is the result of a known issue. Restoring a UCS archive file on the BIG-IP ASM system can take 30 minutes or longer when the configuration contains a large number of web applications. This issue affects the following two operations when loading the UCS archive file on the BIG-IP ASM:

  • UCS file loads as the result of running the bigpipe config install command
  • UCS file loads as the result of performing the config sync operation

F5 Product Development tracked this issue as ID220746 (formerly CR85959) and it was fixed in BIG-IP ASM 9.4.4. For information about upgrading, refer to the BIG-IP ASM release notes.
