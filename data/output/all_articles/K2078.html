Topic

You can write a rule that performs SNAT for connections that match any of the following criteria:

  • Client address
  • Server address
  • TCP or UDP port number

Note: The specific codification for this process is based on the traffic routing requirements for your particular site, which must be defined before configuration.

Example Configuration

The following example will forward and secure (using SNAT) all traffic, except traffic that is received from the 10.10.20.0/24 subnet.

snat map default to 192.168.13.103
pool no_trans {
 snat disable
 nat disable
 forward
}
poll trans {
 forward
}
rule forwards {
 if ( client_addr == 10.10.20.0 netmask 255.255.255.0 ) {
  use pool no_trans
 }
 else {
      use pool trans
 }
}
virtual *:* use rule forwards

This preceding example configuration can be expanded to include matching rules statements against a list of IP addresses for clients, servers or even port numbers. For more information on BIG-IP rules, refer to K770: Overview of BIG-IP rules or, for version 4.5, refer to the iRules Chapter in the BIG-IP 4.5 Reference Guide.
