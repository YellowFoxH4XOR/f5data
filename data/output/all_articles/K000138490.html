K000138490: Device Certificate Import Options missing from dropdown in GUI

Type
Support Solution
Published

Updated
2025-05-12
Applies to

Source

Description

Device Certificate Import Options appear to be missing from dropdown in GUI

Environment

BIG-IP

Cause

When httpd has ssl-certchainfile defined the only import option available is certificate under System  ››  Certificate Management : Device Certificate Management : Device Certificate .  This occurs if the chain certificate is pointing to the actual device certificate (server.crt) and not a standalone chain file.  Note when going here you are actually redirected to the Device Certificate Chain and not the Device Certificate.  This why the only option available is certificate.


 

Recommended Actions

You can remove the ssl-certchainfile entry:

tmsh modify sys httpd ssl-certchainfile none
tmsh restart sys service httpd

If the chain certificate is desired you can update the ssl-certchainfile entry to point to a chain file ( chain.crt ) or import one via the GUI.

After removing ssl-certchainfile the full list of import options are available.  Note you are actually located under the Device Certificate and not the Chain.

Additional Information

This is confusing behavior within the GUI.  When you attempt to access the Device Certificate you are silently being redirect to the Chain Certificate if the https ssl-certchainfile directive is pointing to the device certificate instead of a chain file.
