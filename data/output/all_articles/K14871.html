Known Issue

The BIG-IP system may fail to display DNS-Express zone statistics.

This issue occurs when all of the following conditions are met:

  • Your configuration contains a large number of DNS-Express zones (for example, 1800 zones).
  • You attempt to view DNS-Express zone statistics using the Configuration utility.
  • You attempt to view DNS-Express zone statistics using the Traffic Management Shell (tmsh) after first attempting to view them using the Configuration utility.

Impact

You are unable to view DNS-Express zone statistics.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Configuration utility page stops responding and cannot display the DNS Express Zones statistics.
  • After you fail to load the statistics from the Configuration utility, your attempt to view the statistics using the tmsh utility also fails.

Workaround

To work around this issue, you can restart the zxfrd process and use the tmsh utility to display the zone statistics. To do so, perform the following procedure:

Impact of workaround: You should restart the zxfrd process during a maintenance window because the process disrupts the DNS-Express service.

  1. Log in to the BIG-IP command line.
  2. To restart the zxfrd process, type the following command:

    bigstart restart zxfrd

  3. To view the DNS-Express zone statistics using the tmsh utility, use the following command syntax:

    tmsh show ltm dns dns-express zone <Zone-Name>

    For example, to view statistics for a DNS-Express zone named example.org, type the following command:

    tmsh show ltm dns dns-express zone example.org

    Note: To avoid encountering this issue, F5 recommends that you view the statistics by each zone when you have a large number of DNS-Express zones configured (for example 1800 zones).
