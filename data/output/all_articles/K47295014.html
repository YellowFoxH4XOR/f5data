Known Issue

The BIG-IP system may originate oversized TCP segments.

This issue occurs when all of the following conditions are met:

  • You are running BIG-IP 12.0.0 or later.
  • The received TCP maximum segment size (MSS) (plus protocol overhead) from the peer device is smaller than the configured maximum transmission unit (MTU) of the egress BIG-IP interface.
  • Your BIG-IP system sends large TCP segments, such as SNMP GetBulk replies.

Impact

The Traffic Management Microkernel (TMM) may send traffic that exceeds the receiving host's advertised MTU.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You experience performance degradation when transferring data from your BIG-IP system.
  • TMM sends traffic that exceeds the receiving host's advertised MTU.

Workaround

To work around this issue, you can reduce the interface MTU. To do so, perform one of the following procedures:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Reducing the interface MTU from the Configuration utility

Note: When configured, the Ethernet frame size takes effect immediately on the BIG-IP system.

  1. Log in to the Configuration utility.
  2. Click Network.
  3. Click VLANs.
  4. Click VLAN List.
  5. Click the name of the desired Virtual Local Area Network (VLAN).
  6. In the MTU box, type the value of the desired frame size.
  7. Click Update.

Reducing the interface MTU from the Traffic Management Shell

Note: When configured, the Ethernet frame size takes effect immediately on the BIG-IP system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Modify the MTU of a VLAN using the following command syntax:

    modify /net vlan <vlan name> mtu <mtu size>

    For example, to modify the MTU of vlan1158 to 9198, type the following command:

    modify /net vlan vlan1158 mtu 9198

  3. Save the change by typing the following command:

    save sys config
