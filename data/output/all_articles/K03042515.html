Known Issue

The BIG-IP system may fail to allow changes to the Secure Shell Daemon (sshd) configuration.

This issue occurs when all of the following conditions are met:

  • The BIG-IP sshd process is not running.

    For example, you may have configured the sshd login to disabled. The sshd configuration may appear similar to the following example:

    sys sshd {
        allow { ALL }
        banner disabled
        banner-text none
        description none
        inactivity-timeout 0
        include none
        log-level info
        login disabled
    }

    Additionally, the output of the tmsh show /sys service sshd command may appear similar to the following example:

    In BIG-IP 12.0.0 and later:
    sshd is stopped
    In BIG-IP 11.x
    openssh-daemon is stopped

  • You attempt to make changes to the sshd configuration (for example, to enable the sshd banner and sshd login within a single tmsh command).

    The command may appear similar to the following example:

    tmsh modify /sys sshd { banner enabled banner-text test login enabled }

Impact

You may not be able to make changes to the sshd configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to modify the sshd configuration, you notice error messages that appear similar to the following example:

    Jun  9 17:04:31 BIG-IP confpp[3172]: reconfig command FAILURE for unix_config_sshd returned: '/etc/init.d/sshd reload 2>&1'
    Reloading sshd: [FAILED]
    Starting sshd: [  OK  ]
    Jun  9 17:04:31 BIG-IP confpp[3172]: rollback FAILED for 'unix_config_sshd'
    Stopping sshd: [  OK  ]

Workaround

To work around this issue, you can enable the sshd login setting before making other sshd configuration changes. To do so, perform one of the following procedures:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Making sshd configuration changes one at a time

  1. Log in to the BIG-IP system using serial console access.

    For more information, refer to K7683: Connecting a serial terminal to a BIG-IP system.

  2. Run the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  3. Enable the sshd login by typing the following command:

    modify /sys sshd login enabled

  4. Perform other sshd configuration changes. For example to enable sshd banner, type the following command:

    modify /sys sshd { banner enabled banner-text test }

  5. Save the changes by typing the following command:

    save /sys config

Making sshd configuration changes with the correct order within a single tmsh command:

  1. Log in to the BIG-IP system using Console access.

    For more information, refer to K7683: Connecting a serial terminal to a BIG-IP system.

  2. Run the tmsh utility by typing the following command:

    tmsh

  3. Enable the sshd login and make other sshd configuration changes. For example, to enable the sshd banner at the same time, type the following command:

    modify sys sshd { login enabled banner enabled banner-text test }

    Note: The sshd login configuration needs to be placed ahead of all other sshd configuration changes

  4. Save the changes by typing the following command:

    save /sys config
