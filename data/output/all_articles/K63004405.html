You should consider using this procedure under the following condition:

  • You want to change the BIG-IQ device system personality

The role the BIG-IQ system performs is called the system personality, and you choose BIG-IQ Centralized Management or the Data Collection Device during BIG-IQ initial setup.
 

Prerequisite

You must meet the following prerequisites to use this procedure:

  • You have Advanced Shell (bash) access to the BIG-IQ system command line with Administrator role credential.
  • You have a license for all BIG-IQ personalities (CM,DCD and LM)

 

Procedure

Impact of procedure: The following procedure will restores the BIG-IQ system to factory default as well as the BIG-IQ system personality.

  1. Log in to the BIG-IQ GUI.
  2. Go to System > This Device > General Properties
  3. Click on Return to Setup button on the upper right side (Note: Entering Setup Mode will stop all BIG-IQ System services and allow for reconfiguration of the BIG-IQ System Setup. Choosing to continue will log out all users. The system services may take several seconds to stop before restarting the system in Setup Mode. )
  4. Follow the steps as required and choose a different personality for your BIG-IQ during the setup process
