Description

Sometimes you may be required by F5 support to provide the sel decode logs on R2000/R4000.

Environment

  • docker exec
  • platform/sel log
  • F5OS-A
  • R2000/R4000

Cause

To decode the sel logs.

Recommended Actions

If you want to decode the sel logs, please follow the steps below:

  1. Access the device through the Console or SSH, and log in as root.
  2. Then execute the command #docker exec -it platform-hal ipmiutil sel, the ipmiutil tool provides an alternative SEL decoder.
  3. On the console, invoke the AOM command menu with "ESC (", then at the "Enter Command: 'ESC' then 'd' then 'Enter'" to execute the hidden debug/diagnostics command. This will dump a bunch of output to the console and we'll get the baseboard management controller's (BMC) decoding of the SEL.
  4. Collect the output from the above steps, then submit the output file to F5 support.
