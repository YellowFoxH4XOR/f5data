Description

BIG-IQ failed to add BIG-IP and get "x.x.x.x is already trusted"

You see the following error message:-

GetExistingConfigObjectStats: Local object /mgmt/cm/dns/current-config/server/xxxxxxxxxxxxxxxxx/devices/yyyyyyyyyyyyyyyyyyyyyy doesn't exist.

Environment

  • BIG-IQ
  • BIG-IP
  • GUI
  • CLI
  • Re-discover

Cause

None
 

 Recommended Actions

1) Check BIG-IQ and verify if BIG-IP was imported. If so, follow the below action.

2) Check the machineID of the BIG-IP to be deleted with the following command in BIG-IQ CLI. The following command filter with BIG-IP name "bigipve03".

 restcurl -u admin:admin /mgmt/shared/resolver/device-groups/cm-bigip-allDevices/devices | grep bigipve03 -B10 -A10


Sample output:

      \"groupName\": \"cm-bigip-allDevices\",
      \"httpsPort\": 443,
      \"isVirtual\": true,
      \"machineId\": \"70d2bb08-525b-4858-b2e9-cd70737e9068\",
      \"generation\": 2314,
      \"properties\": {
        \"shared:resolver:device-groups:discoverer\": \"ddccd5f6-4053-4763-bcf6-a498d92cb487\"
      },
      \"isClustered\": false,


3) Delete BIG-IP from BIG-IQ cli bash mode using the machineID found from step 1. 

restcurl -s -u admin:admin -X DELETE mgmt/shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices/70d2bb08-525b-4858-b2e9-cd70737e9068

4) Before re-discover BIG-IP from BIG-IQ, run the following commands from BIG-IP command line:

Warning: run below commands from BIGIP

clear-rest-storage
bigstart restart restjavad

5) Proceed to re-add the BIG-IP from BIG-IQ GUI.
