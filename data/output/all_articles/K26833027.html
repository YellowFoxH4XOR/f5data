Description

F5 Access Clients fails to prompt 2FA authentication on Windows 10 

Environment

  • F5 Access Clients
  • Windows 10
  • 2FA

Cause

F5 Access on Windows10 only supports the following for authentication:

 - Username/Password
 - Client certificate authentication
 - Username/Password with client certificate authentication (dual-factor authentication)

2FA type other than certificate auth is not supported.

Recommended Actions

You may use Edge Client or browsers to connect to BIG-IP APM on Windows 10 when 2FA is enabled
