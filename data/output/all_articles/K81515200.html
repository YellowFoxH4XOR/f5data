Description

When sending a REST API request to the BIG-IP with a remote user assigned with an operator role, you get a 401 Authorization failed error.


Environment
  • REST API
  • Remote authentication
  • Operator Role
  • This error is only seen for remote users
  • You get an error message similar to this: 
    "code":401,"message":"Authorization failed

Cause

For remote users, you first need to get a token to send with each iControl REST api call. 
iControl® REST supports external authentication to other providers, such as Active Directory (AD) or RADIUS. Authentication with a provider other than the local authentication provider on a BIG-IP® system requires a token that you can use to access resources in iControl REST. A token consists of 32 random characters, primarily digits and uppercase ASCII characters, valid for a period of time. Until the token expires, a server validates your identity based on the authentication token you submit. When the token expires, you simply acquire a new token from a provider. 

Recommended Actions

  1.  Obtain token with basic auth; example request:
curl -ik -X POST https://<MGMT IP or FQDN>/mgmt/shared/authn/login --data-binary '{"username":"<remote user>", "password":"<pass>", "loginProviderName":"tmos"}' -H "Content-Type: application/json"

Example:

The below examples assume the following:
  • The operator remote user id is 'operator1'
  • The password is 'admin'

curl -ik https://<MGMT IP OR FQDN>/mgmt/tm/ltm/pool/~Common~<POOL NAME>/members/~Common~<IP ADDRESS POOL MEMBER>:<PORT> -H 'X-F5-Auth-Token: <token_fromResponse_inStep1>' -H 'Accept:*/*' -H 'Content-Type':'application/json' -d '{"session":"user-disabled"}'
