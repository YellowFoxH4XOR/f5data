Description

You observe below SSL connection error log message in LTM log. In the example 192.0.2.5 is client or source IP address and 203.0.113.10 is virtual server IP address.
01260009:4: 192.0.2.5:33221 -> 203.0.113.10:443: Connection error: ssl_codec_rx:2299: alert(50) received alert

Environment

  • BIG-IP LTM
  • Virtual server listening on port 443

Cause

By default BIG-IP does not send close notify message to client when TLS connection is being closed. 

Answer/Recommended Actions

Uncheck "Unclean Shutdown" on the relevant Client SSL profile (for the configuration view select "Advanced").

Additional Information

Certain client initiating SSL connection follows strict RFC compliance where it expects a close notify message from the server when SSL/TLS connection is being closed.
