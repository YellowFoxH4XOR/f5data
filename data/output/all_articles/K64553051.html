Issue

Error Message

01570004:3: IO error on recv from mcpd - connection lost

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The Link Layer Discovery Protocol (LLDP) daemon (lldpd) loses its connection to the Master Control Process daemon (mcpd). The mcpd process is either restarting or it is down. 

The lldpd process collects BIG-IP local information from mcpd and sends out the LLDP protocol data unit (PDU) that pertains to the EEE 802.1ab specification on LLDP TX-enabled ports. 

Impact

The LLDP attributes do not advertise while the mcpd process restarts.

Recommended Actions

None
