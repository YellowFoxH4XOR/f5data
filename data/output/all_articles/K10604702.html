Description

You are unable to generate qkview using GUI and getting error message Error generating QKview snapshot and you are getting following message in BIG-IP console:

emerg logger: Re-starting ntlmconnpool

Environment

  • Using the GUI to generate a qkview

Cause

Unknown at the time of creating this article. 

Recommended Actions

Reboot your BIG-IP system. You may perform reboot in maintenance window in order to avoid any down time.

Or 

Run the following command:

# bigstart stop ntlmconnpool
# bigstart start ntlmconnpool

None
