Description

Live Update page is not loading for installing the new attack signatures. When trying to load the page under System >> Software Management: Live Update, below errors are noted in GUI

Could not communicate with the system. Try to reload the page

Environment

  • BIG-IP ASM 
  • ASM Attack signature installation 

Cause

None

Recommended Actions

To work around this issue, restart the tomcat service 

Impact of workaround: The BIG-IP Configuration utility is not accessible while services are restarting.

  1. Log in to the command line.
  2. Type the following command to restart the tomcat daemon:
    bigstart restart tomcat
