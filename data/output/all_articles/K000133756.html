Description

Messages similar to "Debug: Crypto request: Failed to offload to HW accelerator." are being frequently logged in /var/log/ltm or to remote syslog servers

 

Environment

BIG-IP

 

Cause

If you are running a Virtual Edition of BIG-IP this is expected behavior, as this version does not have hardware acceleration.

 

If you are running a BIG-IP hardware platform, the connections causing these events are using an SSL algorithm that is not supported by hardware acceleration on your hardware platform

 

Please see K13213: SSL algorithms that are hardware accelerated (11.x - 16.x) for the list of supported SSL algorithms
 

If you are running BIG-IP rSeries and Crypto/Compression Acceleration is disabled (default enabled), this is expected behavior.
 

Recommended Actions

If you would like to squelch these messages from /var/log/ltm you can reduce the logging level to Notice via the tmsh command:

 

# tmsh modify sys db log.tmm.level value notice
# tmsh save sys config
