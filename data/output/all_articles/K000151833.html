K000151833: The NIM NGINX Usage page does not identify the NGINX instances it's reporting on

Type
Knowledge
Published
2025-06-12
Updated
2025-06-12
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.17.0, 2.17.2, 2.17.1, 2.18.X, 2.19.X, 2.17.X, 2.19.2, 2.19.1, 2.19.0, 2.18.0, 2.17.4, 2.17.3
  • NGINX Plus: R33, R34
Source
https://my.f5.com/manage/s/article/K000151833

Description

The NIM NGINX Usage page reports on NGINX instances that are pointing to the NIM for licensing and usage reporting. The NGINX instances that appear on the NIM NGINX Usage page are identified by a System UID (Unique Identifier). These identifiers are unique to NIM and cannot be traced back to the NGINX instances they represent. The NIM NGINX Usage report page does not contain any other NGINX instance identifiers such as ip address or hostname.

Environment

NGINX Instance Manager

NGINX Plus

Cause

Functions as designed

Additional Information

Configure NGINX Plus to report usage to NGINX Instance Manager
