Known Issue

The support tcpdump file has a qkview file extension.

This issue occurs when the following condition is met:

  • You generate a tcpdump file using the Configuration utility by navigating to System > Support, selecting TCP Dump, and clicking Start.

Impact

The tcpdump file has a qkview file extension. The system functions fine; only the file extension is incorrect.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tcpdump file has a qkview file extension.
