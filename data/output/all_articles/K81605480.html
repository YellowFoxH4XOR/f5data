K81605480: Access Policy returning logout page ''my.logout.php3?errorcode=25'' when set db ipv6.enabled as false

Type
Support Solution
Published
2021-08-25
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 16.X.X, 16.0.X, 14.1.4, 14.1.3, 16.1.3, 16.1.2, 16.1.X, 16.1.0, 16.0.1, 16.0.0, 16.1.1
Source
https://my.f5.com/manage/s/article/K81605480

Description

You are running APM version v16.x
You set ipv6.enabled DB variable as "false"

Example: 
sys db ipv6.enabled {
    default-value "true"
    scf-config "true"
    value "false"   <<-----!!!
    value-range "false true"
}

You observed the Access Policy returning logout page "/my.logout.php3?errorcode=25" when getting the logon page.

Environment

  • BIG-IP version 16.x
  • ipv6.enabled set to "false" by user

Cause
It's related to the fix for Bug ID 470346 and ipv6.enabled set to "false" by user manually.

Recommended Actions
The default value for ipv6.enabled DB variable is "true" as It is mandatory for the renderer to process traffic.

To resolve the problem, change the DB variable to "true" by using the command below: 
tmsh modify sys db ipv6.enabled value true
tmsh save sys config
