K000140983: "Invalid Json" OAuth response when using 'authorization_code' grant type

Type
Support Solution
Published
2024-09-18
Updated
2024-09-18
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000140983

Description

OAuth client on APM fails with error:

 

OAuth Client: failed for server '<OAuth server>' using 'authorization_code' grant type (client_id=<CLIENT_ID>), error: Invalid json

Environment

  • BIG-IP deployed as APM
  • APM configured with an OAuth Client agent

Cause

Response from OAuth AS to the OAuth Token request sent by APM is

 

HTTP/1.0 503 Service Unavailable
Connect failed

 

APM expects that response to include json data like; access token, expires_in, token_type, scope, refresh_token and id_token.  As APM can not parse those attributes from response it considers an invalid json file.

Recommended Actions

Root cause use to be an IP/TCP/TLS issue between APM OAuth client and OAuth AS.
 
It is recommended to configure OAuth server object on APM with 'serverssl-insecure-compatible' or 'serverssl' server ssl profiles.


apm aaa oauth-server  {
  client-serverssl-profile-name  serverssl-insecure-compatible
  resource-serverssl-profile-name  serverssl-insecure-compatible
