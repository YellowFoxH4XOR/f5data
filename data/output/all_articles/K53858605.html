Description

Refer to K6827, you can custom the DNS answer for when user query the BIND version.
This article provide an alternative method to hide the BIND version.

Environment

  • BIG-IP DNS
  • ZoneRunner
  • Listener

Cause

None

Recommended Actions

The following iRule is an example to provide the answer when get the DNS query for the version.bind.

  1. Create the iRule, for example:

when DNS_REQUEST {
    # You can edit the iRule, to match different FQDN of DNS query.
    if {([DNS::question name] eq "version.bind") } {
    # You can custom the DNS answer, at here, the rcode is REFUSED
    DNS::header rcode REFUSED
    DNS::return
    }
}

  1. Apply the iRule to the Virtual Server of the listener.

Additional Information

After apply the iRule, the expected output will be:
