Description

You would like to know if it is possible to disable logging for a specific attack signature ID, but keep blocking requests that trigger the ID.

Environment

  • Attack Signatures
  • Security Policy

Cause

None

Recommended Actions

It is not currently possible to configure attack signatures with their own individual Learn/Alarm/Block flags. Only attack signature sets can be configured in this way.

If you would like F5 Support to add your support for this feature enhancement opportunity, please open a Service Request referencing this article.

To work around this limitation, you may create a Custom Signature Set and add the specific signature to the new Custom Signature Set.

Note: To prevent excessive administrative burden this should be done only when specifically required.
