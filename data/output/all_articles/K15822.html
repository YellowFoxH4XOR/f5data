Topic

You should consider using this procedure under the following conditions:

  • You want to configure a custom eviction policy.
  • You want to configure the BIG-IP system to use a custom eviction policy as the system-wide global eviction policy.
  • You want to associate a default or custom eviction policy with a virtual server.
  • You want to associate a default or custom eviction policy with a route domain.

Description

Beginning in BIG-IP 11.6.0, the configurable options that affect the BIG-IP system adaptive connection reaping behavior are configured in eviction policies. The system-wide adaptive connection reaping behavior is configured by selecting an eviction policy as the system-wide global eviction policy. Additionally, you can associate an eviction policy with a virtual server and/or route domain. By default, the system-wide global setting is configured to use a default eviction policy named default-eviction-policy. F5 recommends that you do not modify the default eviction policy. If you want non-default values, you should create a custom eviction policy.

To create a custom eviction policy, configure the system-wide global eviction policy, or associate an eviction policy with a virtual server or route domain, perform the following procedures:

  • Creating a custom eviction policy
  • Configuring the system-wide global eviction policy
  • Associating an eviction policy with a virtual server
  • Associating an eviction policy with a route domain

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access the Configuration utility.
  • You are familiar with eviction policies (introduced in BIG-IP 11.6.0) and how configurable objects affect the adaptive connection reaping behavior. For more information, refer to K15821: Overview of eviction policies.
  • You are familiar with the adaptive connection reaping feature. For more information, refer to K15740: Overview of adaptive connection reaping (11.6.0 and later).

Procedures

Creating a custom eviction policy

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Local Traffic > Eviction Policy List.
  3. Click Create.
  4. In the Name box, type the policy name you want.
  5. Select the policy configuration values you want.
  6. Click Finished.

Configuring the system-wide global eviction policy

Impact of procedure: Specifying an incorrectly configured eviction policy as the system-wide policy may result in the system not removing connection flows as expected. As a result, the system could experience a memory resource exhaustion condition.

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Local Traffic > General.
  3. From the Eviction Policy list, click the eviction policy you want.
  4. Click Update.

Associating an eviction policy with a virtual server

Impact of procedure: Specifying an incorrectly configured eviction policy as the system-wide global policy may result in the system not removing connection flows as expected. As a result, the system could experience a memory resource exhaustion condition.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Click the name of the virtual server you want.
  4. From the Configuration menu, click Advanced.
  5. From the Eviction Policy list, click the eviction policy you want.
  6. Click Update.

Associating an eviction policy with a route domain

Impact of procedure: Specifying an incorrectly configured eviction policy as the system-wide global policy may result in the system not removing connection flows as expected. As a result, the system could experience a memory resource exhaustion condition.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Route Domains.
  3. Click the name of the route domain you want.
  4. From the Eviction Policy list, click the eviction policy you want.
  5. Click Update.
