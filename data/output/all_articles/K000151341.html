Description

TMM running in Azure cloud may failed to start after reboot. The following logs found in /var/log/ltm may be indicative of the issue:

<13> May 13 04:32:33 <hostname>.azure.com notice sock(1.1)[00:e1.0]: Waiting for tmm1 to reach state 4...
May 13 01:55:26 <hostname>.azure.com crit tmm1[22062]: 01010020:2: MCP bulk Connection aborted, exiting
May 13 01:55:26 <hostname>.cloudapp.azure.com crit tmm1[22062]: 01010020:2: MCP Connection aborted, exiting

Environment

  • Azure Cloud
  • Upgrading the Cloud VE
  • Rebooting the Cloud VE

Cause

ID1292345

Recommended Actions

  1. Shutdown the VE from CLI from bash prompt:
    # shutdown -h now
  2. Stop the BIG-IP Cloud VE via the Azure console.
  3. Wait one minute.
  4. Start the BIG-IP Cloud VE via the Azure console.

None
