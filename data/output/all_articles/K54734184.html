Known Issue

When the ospfd process restarts, the value configured for the Open Shortest Path First (OSPF) distance command is lost.

This issue occurs when all of the following conditions are met:

  • The distance command is configured in the OSPF protocol.
  • The ospfd process restarts.

Impact

The BIG-IP system fails to apply administrative distances on routes.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The OSPF distance command remains in the configuration, but is not applied to the route.
