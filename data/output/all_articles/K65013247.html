Description

Can the IPI Feed List URL use Route Domain notation?

Or can the Feed List use a route in a non-0 Route Domain?

Environment

  • IP Intelligence
  • Feed list

Cause

The IPI Feed List URL does not accept Route Domain notation, and will return an error:

010717a4:3: '<URL with route domain notation>' does not appear to be a well-formed URL.

Additionally, if there is no available route to the URL in Route Domain 0, a message similar to the following will be printed to /var/log/dwbl/dwbld.log:

dwbld| err|Oct 05 07:11:35.247|21034|CURLER|curler|(null)|CURL failed with error Couldn't connect to server

Recommended Actions

Use a Feed List URL that is accessible via Route Domain 0.
