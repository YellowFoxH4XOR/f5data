Description

The AOM (Always-On Management) / BMC (Baseboard Management Controller) is a separate microcontroller that is implemented on standard F5 appliances to facilitate remote management of the host system. The AOM/BMC can be configured to be accessible as a separate IP address from the host management IP while sharing the physical management port.

Environment

i2000, i4000, i5000, i7000, and i10000 series platforms

Cause

None.

Recommended Actions

To access the configuration of the AOM/BMC on these platforms, you can run the ipmiutil config command.

This example shows the IP address and username configured on the AOM:

$ ipmiutil config

ipmiutil ver 2.94

The UserName is in hex format ("61 6f ..."). You can find out the username using this command:

 

echo "61 6f 6d 5f 61 64 6d 69 6e" | xxd -r -p

aom_admin
