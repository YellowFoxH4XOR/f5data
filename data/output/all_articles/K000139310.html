Description

When performing an BIG-IP NEXT installation after the final step of "Would you like to complete configuration with these parameters (Y/n)" the system freezes and logs "[info] Waiting for BIG-IP Next API to be ready. This can takeup to 5 minutes ..."

Environment

BIG-IP NEXT

Cause

This issue can happen if you skip configuring the dataplane external interface after setting DNS and NTP

Recommended Actions

Please configure the external interface after setting DNS and NTP instead of skipping it
