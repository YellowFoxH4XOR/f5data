Topic

You should consider using these procedures under the following condition:

  • You want to find the kernel version for a specific version of BIG-IP software.

Important: F5 has modified its base host operating system and responds to all reported vulnerabilities for that base operating system. You must install only the patches that F5 supplies.

Important: The Linux base host operating system is not involved in processing load-balanced BIG-IP traffic. All BIG-IP TMOS traffic is processed by the Traffic Management Microkernel (TMM) daemon.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have command line access to the BIG-IP system.

Description

You can manually obtain the kernel version information on a running version of BIG-IP software or from a BIG-IP ISO image. To do so, refer to one of the following procedures.

Procedures

  • Manually determine the kernel version for a running system
  • Manually determine the kernel version for a BIG-IP ISO image

Manually determine the kernel version for a running system

You can manually obtain the kernel version information on a running BIG-IP system using the uname command. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Run the uname -a command to display the kernel version information.

    For example:

    uname -a
    Linux bigip-1.lab 3.10.0-862.14.4.el7.ve.x86_64 #1 SMP Tue Apr 12 22:52:03 PDT 2022 x86_64 x86_64 x86_64 GNU/Linux

Manually determine the kernel version for a BIG-IP ISO image

You may need to determine the kernel version for a BIG-IP ISO image. For example, if you are preparing to install a BIG-IP ISO image and you want to determine the kernel version for security reasons. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To change directories to the /shared/images directory, enter the following command:

    cd /shared/images

  3. To display the kernel version of the appropriate image, use the following command syntax:

    isoinfo -i <BIG-IP_ISO_IMAGE> -R -x /metadata.xml | grep -i '/kernel-'

    For example, to display the kernel version for the BIG-IP 17.0.0 ISO image, enter the following command:

    isoinfo -i BIGIP-17.0.0-0.0.22.iso -R -x /metadata.xml | grep -i '/kernel-'

    The output appears similar to the following example:

    <package>x86_64/kernel-3.10.0-862.14.4.el7.0.0.22.x86_64.rpm</package>
    <package>x86_64/kernel-ve-3.10.0-862.14.4.el7.0.0.22.x86_64.rpm</package>
