Known Issue

The netHSM key creations fail when you use the gen-csr TMOS Shell (tmsh) option.

This issue occurs when all of the following conditions are met:

  • The hardware security module (HSM) is licensed and installed on the BIG-IP system.
  • You use the gen-csr tmsh option when you generate the key for netHSM.

    For example:

    tmsh create sys crypto key <key name> gen-csr common-name "FQDN" security-type nethsm

Impact

The tmsh command fails, and the system does not create a Secure Socket Layer (SSL) key or Certificate Signing Request (CSR).

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the gen-csr option within tmsh to create a netHSM key, the operation fails and you observe an error message similar to the following example:

    01070712:3: Failed: name (/Common/example.csr) local/system path expected to be non empty.
