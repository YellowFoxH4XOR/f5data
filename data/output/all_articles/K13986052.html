F5 is deprecated the net-tools package and replaced it with the ip route utility.

BIG-IP 10.x and later software provides the ip route utility as an alternative to the net-tools package.

For a general quick reference guide covering the ip route command, refer to ip Command Cheat Sheet for Red Hat Enterprise Linux.

Note: This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

The table below contains the equivalent versions of the following commands from the net-tools package and ip route utility: arp, ifconfig, netstat, and route.

Net-tools command'Ip route' command
arp -a

Arguments:

  • a = All, or add a [hostname/IP address] for a specific host Address Resolution Protocol (ARP) table entry.
ip neigh

Arguments:

  • neigh = Neighboring devices (ARP table) management.
arp -v

Arguments:

  • v = Verbose output.
ip -s neigh

Arguments:

  • s = Display statistics.
  • neigh = Neighboring devices (ARP table) management.
arp -s 10.0.0.10 00:0c:29:6e:88:4c

Arguments:

  • s = Selected hostname of IP address and interface address (media access control (MAC) address).
ip neigh add 10.0.0.10 lladdr 00:0c:29:6e:88:4c dev eth1

Arguments:

  • add = Add neighboring device ARP information.
  • lladrr = Link layer address of the neighbor.
  • dev = Referenced interface to add the neighbor IP address link layer (MAC) address.
arp -i eth1 -d 10.0.0.10

Arguments:

  • i = Select interface, followed by the selected interface name.
  • d = Delete associated ARP table entry.
ip neigh del 10.0.0.10 dev eth1

Arguments:

  • neigh = Neighboring devices (ARP table) management.
  • del = Delete referenced neighbor ARP table entry.
  • dev = Interface to delete referenced IP address (in this example, eth1).
ifconfig -a

Arguments:

  • a = Display status of all interfaces.
ifconfig eth0

Arguments:

  • eth0 = Display status for the first Ethernet interface (eth0).
ip addr

Arguments:

  • addr = Display status of all interfaces.
ip addr show eth0

Arguments:

  • eth0 = Display IP address and link layer information for eth0.
ifconfig eth0 down

Arguments:

  • down = Disable driver for the referenced interface.
ip link set eth0 down

Arguments:

  • link = Referenced network that is reachable through this device.
  • down = Disable driver for the referenced interface.
ifconfig eth0 up

Arguments:

  • up = Enable driver for referenced interface.
ip link set eth0 up

Arguments:

  • up = Enable driver for referenced interface.
ifconfig eth0 10.0.0.10/24
ifconfig eth0 10.0.0.10 netmask 255.255.255.0

ifconfig eth0:1 0.0.0.10/24

Arguments:

  • eth0:1 = Modify or create the eth0 alias interface, eth0:1.


ifconfig eth0 0.0.0.0
Removes all configured ip addresses from the referenced interface (eth0).		ip addr add 10.0.0.10/24 dev eth0
ip addr add 10.0.0.10/24 dev eth0 label eth0:1

Arguments:

  • addr = IP address.
  • add = Add the IP address.
  • dev = Device interface.
  • label = Interface assigned label, typically a variant of the referenced interface name.
ip addr flush dev eth0
Removes all configured ip addresses from the referenced interface (eth0).
ifconfig eth0 mtu 9000

Arguments:

  • eth0 = Configure the eth0.
  • mtu = Maximum transmission unit (MTU) accepted by the specified interface.
ip link set eth0 mtu 9000

Arguments:

  • link = Referenced network reachable through this device.
  • set = Configure referenced interface to the specified value.
  • eth0 = Referenced interface to which to apply setting(s).
  • mtu = MTU accepted by the specified interface.
ifconfig eth0 10.0.0.10/24

Arguments:

  • eth0 = Configure eth0.
ip addr add 0.0.0.10/24 dev eth0

Arguments:

  • addr = IP address.
  • add = Add associated IP address.
  • dev = Device/interface to add the IP address.
netstat -neopa

Arguments:

  • n =Do not resolve host/service names.
  • e = Display extended information.
  • o = Display networking timers.
  • p = Display program process identifier (PID).
  • a = Display all.
ss -neopa

Arguments:

  • n = Do not resolve host/service names.
  • e = Display extended.
  • o = Show timer information.
  • p = Display process using socket.
  • a = Display all.
netstat -g

Arguments:

  • g = Display multicast group membership information for IPv4 and IPv6.

netstat -r

Arguments:

  • r = Display route table entries.
ip maddr

Arguments:

  • maddr = Display multicast addresses.
ip route show

Arguments:

  • route show = Display route table entries.
route add -net 10.0.0 netmask 255.255.255.0 dev eth0

Arguments:

  • add = Add route to routing table.
  • dev = Specified interface for the route.
ip route add 10.0.0/24 dev eth0

Arguments:

  • add = Add route to routing table
  • dev = Specified interface for the route.
route add default gw 10.0.0.10

Arguments:

  • add = Add route to routing table.
  • default = Set default route of routing table.
  • gw = Route gateway is the specified IP address.
ip route add default via 10.0.0.10

Arguments:

  • add = Add route to routing table.
  • default = Set default route of routing table.
  • via = Route gateway is the specified IP address.

For more information about the ip route utility, type the following commands from the command line of any BIG-IP 10.x or later device:

  • man ip
  • man ss
