Known Issue

This is most likely the result of a known issue. The following error will occur if you attempt to use 3dnsmaint to set up SSH communication before you configure a self IP address for the new system.

ERROR: Can't read remote data via 3dparse.  Make sure 3dnsd is running.

F5 Networks Product Development tracked this issue as CR31946 and CR41912.

Workaround

To resolve this issue, configure a self IP address before you set up SSH communication.
