Topic

Summary

Collecting diagnostics during high system utilization may cause ARX resource exhaustion.

Description

While troubleshooting ARX system issues, it is standard practice to collect diagnostics from the active ARX device by using the collect command or through the ARX Manager GUI diagnostics page. However, if the ARX propkt buffer is experiencing 100 percent usage when the collection is initiated, the TEM STATS daemon's internal communication will fail. As a result, the daemon will exit and the ARX system will failover.

You will see the following message in the ARX traplog when the propkt buffer 100 percent threshold has been reached:

nsmResourceThreshold (415) : resource:propkt threshold:100 slot:2 proc:2

Important: Do not run a collect of any type if the ARX propkt buffer utilization is 100 percent.

Recommendations

When experiencing client performance issues or propkt buffer resource exhaustion, F5 recommends that you run the show fastpath resources command and review the Presto memory (kb) line of the output before collecting diagnostics. To do so, perform the following procedure:

Note: The propkt buffer uses the Presto resources.

  1. Log in to the ARX CLI
  2. Enable privileged mode by typing the following command:

    enable
  3. Show the Presto resources by typing the following command:

    show fastpath resources

    Output will appear similar to the following example:

    Presto Resource                        Current     Maximum     Percent Used
    -----------------------------------------------------------------------------
    Presto temp routing layer (kb)               6           512          1%
    Presto packets (kb)                          2         26343          0%
    Presto memory (kb)                       182267        182267         100%
    Presto TCP TCB Pool (kb)                   117         16384          1%
    Presto UDP Pool (kb)                         3           192          2%
    Presto sockets (kb)                          8          1088          1%
    Presto IP Fragments (kb)                     0           256          0%

If the Presto memory (kb) percent used figure is 100 percent, you may either:

  • Wait for the ARX system to catch up and allow the Presto memory to reach below 90 percent utilization, which may take a considerable amount of time
  • Schedule a failover window and collect diagnostics after the failover is complete
