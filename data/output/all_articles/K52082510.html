Description

You want to create custom ssl profile by adding SSL certificate and key and assign it to virtual server.

Environment

virtual server with ssl offloading and re-encryption. 

Cause

None

Recommended Actions

To create a Client SSL profile, perform the following basic steps.

  1. Import the SSL certificate, key and any necessary intermediate/chain certificates into the BIG-IP using the web management interface by navigating to System > SSL Certificate Management > Traffic Certificate Management > and click Import. 
  2. Create the Client SSL profile by navigating to Local Traffic > Profiles > SSL > Client SSL  and click the Create button. 
  3. In the Name field, enter a friendly name for the profile. 
  4. Locate the Certificate Key Chain setting and check the box on the far right to allow modifications to the setting.
  5. Click the Add button below the Certificate Key Chain multi select box. 
  6. An Add SSL Certificate Key Chain popup will appear.
  7. From the dropdown lists, select the Certificate, Key and Chain/Intermediate certificates and enter a Passphrase for the selected key if the key was generated using a passphrase.
  8. Click Add.
  9. Scroll to the bottom of the page and click Finished.
Next, associate the Client SSL profile to a virtual server.
  1. Navigate to Local Traffic > Virtual Servers > Click on the virtual server that will need to terminate SSL connections using the new Client SSL profile.
  2. On the virtual servers Properties page, locate the SSL Profile (Client) setting and find the new Client SSL profile.
  3. Select the new Client SSL profile in the Available list and move it to the Selected list. 
  4. Scroll to the bottom of the page and click Update.
Once finished virtual server will immediately begin using the certificate(s) and key in the client SSL profile to perform SSL handshakes with clients that connect to the virtual server.


Additional Information

More details about Client SSL profiles can be found in the BIG-IP System: SSL Administration section of the software versions operations manual.
