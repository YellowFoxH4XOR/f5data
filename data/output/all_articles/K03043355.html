Description
If the Last Sync time is compared on GUI and the REST API output for "curl -sku <usr>:<passwd> https://<managementIP>/mgmt/tm/cm/device-group/<deviceGroupName>/stats".
The output might show up different time and this is an expected behavior.

Environment

  • BIG-IP is a part of Device Group

  • BIG-IP's TimeZone is set the non-UTC timezone

Cause
REST API output is in the UTC/GMT time and the GUI time is in the local time of the device.
The command line out also shows similar output as REST API.

Recommended Actions

None 

Additional Information
To view GUI LSS Time

Device Management menu, Select Overview > show Advanced Menu in the Devices view.
Example: GUI LSS Time 12/21/2018 16:36:31 in JST

REST API output show UTC time
