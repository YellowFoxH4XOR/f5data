Description
Customize a Mac client package to specify the client components to install, and to customize settings for BIG-IP Edge Client and Dialup Settings components if you include them.

Environment

  • BIG-IP 12.x and later
  • Connectivity profile

Recommended Actions

To customize and download Windows client package follow below steps:

  1. For BIG-IP v13.x and later
    Go to Access > Connectivity/VPN > Connectivity > Profiles

    For BIG-IP v12.x
    Access Policy > Secure Connectivity
     
  2. Click Add
  3. Fill all needed options for your deployment
  4. Click OK
  5. Click on created Connectivity Profile
  6. Click on black arrow on Customize Package button
  7. Choose Mac option
  8. Decide if you want to leave Auto launch BIG-IP Edge Client after User Log In option
  9. Click Download 
Distribute customized package in your organization. The remote user must have superuser authority, or, must be able to supply an administrative password to successfully install the Network Access client.
