Topic

You should consider using this procedure under the following condition:

  • You want to use the iControl REST API to create or replace the Domain Name System (DNS) servers configured for the BIG-IP system.

Description

The BIG-IP system uses the DNS servers configured in the DNS Lookup Server List to resolve host names for system users. Additionally, you can configure the DNS Search Domain List with local domain names to use for completing a query when no domain suffix is supplied.

You should configure the DNS server settings manually if DHCP is disabled on the BIG-IP system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP iControl REST API.
  • You have command line access to a Linux system (or an alternate BIG-IP system) that has the curl and jq (command-line JSON processor) utilities installed.

Procedures

The following procedure creates DNS entries if they don't exist and replaces the existing DNS settings if they do. To configure the DNS settings using the iControl REST API, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a client system that contains the curl and jq utilities.
  2. Modify the DNS server settings using the following command syntax:

    curl -ksu admin:<password> -H "Content-Type: application/json" -X PATCH https://<bigip_hostname>/mgmt/tm/sys/dns -d '{"nameServers:["<server1>","<server2>","<server3>"],"search":["<domain1>","<domain2>"]}' | jq '.'

    For example, to configure the DNS Lookup Server List with 10.10.10.153 and 10.10.10.154 and configure the DNS Search Domain List with localhost (default) and example.com, enter the following:

    curl -ksu admin:testing -H "Content-Type: application/json" -X PATCH https://ltm1.example.com/mgmt/tm/sys/dns -d '{"nameServers":["10.10.10.153","10.10.10.154"],"search":["localhost","example.com"]}' | jq '.'

    Output appears similar to the following example:

    {
      "kind": "tm:sys:dns:dnsstate",
      "selfLink": "https://localhost/mgmt/tm/sys/dns?ver=15.1.0",
      "nameServers": [
        "10.10.10.153",
        "10.10.10.154"
      ],
      "numberOfDots": 0,
      "search": [
        "localhost",
        "example.com"
      ]
    }
