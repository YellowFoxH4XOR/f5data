K01354451: Unable to select BIG-IQ device to create UCS file

Description

When you try to create UCS via GUI, you may find that there is no device to select.
GUI shows "There are no items to show in this view".

Environment

  • BIG-IQ
  • GUI : System >> BACK UP & RESTORE >> Backup Files, click "Create"

Cause

BIG-IQ failed localhost discovery.

You can check "Validation Failed" by the command.
# curl http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | /usr/bin/json-format

Example
# curl http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | /usr/bin/json-format
    ---snip---
      "slots": [
        {
          "build": "0.0.133",
          "volume": "HD1.1",
          "product": "BIG-IQ",
          "version": "7.1.0.1",
          "isActive": true
        }
      ],
      "state": "VALIDATION_FAILED",      <------------!!!!
      "errors": "Unable to add device to cm-shared-all-big-iqs group. Device does not meet group validation requirements. \n Property name: productName Expected: BIG-IQ Received: ",
      "address": "192.0.2.1",
      "edition": "",
      "product": "",
      "version": "",
      "hostname": "localhost",
    ---snip---


Recommended Actions

Follow K14593 "Recovering the BIG-IQ system from a failed discovery"
