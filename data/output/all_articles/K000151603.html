K000151603: The "ssl" option cannot be used in Common Criteria mode when try to use --f5 ssl flag in TCPdump.

Type
Support Solution
Published
2025-05-30
Updated
2025-05-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151603

Description

While trying to collect the necessary data to solve the problem, you may encounter a situation where when executing tcpdump with the --f5 ssl flag, you may see a warning that prevents the command from running:

tcpdump: WARNING:  The "ssl" option is disabled. The "ssl" option cannot be used in Common Criteria mode. Common Criteria mode is controlled by the DB variable security.commoncriteria.

Environment

  • BIG-IP
  • TCPdump

Cause

Reason of that is because of the value in the security.commoncriteria which is set to true.

Recommended Actions

  1. Check the current value in security.commoncriteria by using:
    # tmsh list sys db security.commoncriteria
  2. If the value is set to true and you want to use the --f5 ssl flag, you need to change it to the false by using: 
    # tmsh modify sys db security.commoncriteria value false
  3. At the end you need to reboot the device.

IMPORTANT: To achieve a working scenario, the device must be restarted after deployment. F5 recommends doing this during the maintenance window to avoid disruption to the production environment.
