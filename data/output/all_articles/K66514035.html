Description

F5 Application Services Templates (FAST) are not working after installing the rpm. Errors similar to the following may appear in the iApp window:

  Error fetching applications: Failed to get data from /mgmt/shared/fast/applications: 400 Bad Request
remoteSender:192.168.2.3, method:GET
 

Environment

  • BIG-IP v13 or newer
  • FAST rpm installed
 

Cause

There is a prerequisite of installing the AS3 rpm separately before FAST will work.
 

Recommended Actions

You can find the latest AS3 RPM here:

  F5Networks / f5-appsvcs-extension

That RPM gets imported the same way as the FAST templates: From the BIG-IP system, install the extension by navigating to iApps > Package Management LX. Click Import and then select the RPM you downloaded.

Once AS3 and FAST are both installed, you should be able to navigate/use the LX templates.
