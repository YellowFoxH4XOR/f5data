Issue

Description

BIG-IP device crashed after loading a new image and fails to boot.

  • Console logs show : C106 during boot

Environment

  • Upgraded BIG-IP 
  • Rebooted Device

Cause

Device failed to hand-off from Always-On-Management (AOM) to Host after upgrade.

Recommended Actions

Contact Support for additional help. If feasible, capture the console output for Support's analysis.
