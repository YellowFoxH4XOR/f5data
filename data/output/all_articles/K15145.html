Topic

Activating a DNS Services license on a BIG-IP software version prior to 11.4.0 generates a provisioning warning message.

Description

When you attempt to activate a DNS Services license on a BIG-IP system running a software version prior to 11.4.0, the system generates the following warnings messages:

  • The upper-left corner of the Configuration utility displays a Provisioning Warning yellow status indicator. If you place your mouse pointer on the warning message, the following message displays:

    Provisioned yet unlicensed: GTM
  • The /var/log/gtm file may log an error message that appears similar to the following example:

    notice gtmd[9360]: 011a000b:5: GTM not licensed

This behavior is by design. BIG-IP 11.4.0 and later support the DNS Services license.

Recommendations

When purchasing the DNS Services license, you should make sure to activate the license on a BIG-IP system running version 11.4.0 or later. In addition, if your platform has an earlier software version installed on an inactive partition, you must upgrade the partition to version 11.4.0 or later prior to booting to the alternate partition and attempting to activate the DNS Services license.
