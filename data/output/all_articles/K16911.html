Known Issue

The BIG-IP system treats, as malformed, DNS queries that contain an unrecognized EDNS0 option code, and drops the queries.

Impact

Client DNS queries that contain an unrecognized EDNS0 option code will fail to resolve.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You notice that some client DNS queries fail to resolve.

Resolution

Workaround

You may be able to work around this issue by creating an iRule that removes EDNS0 options from the DNS query.

Impact of workaround: F5 recommends that you create an iRule that works best for your application environment. Additionally, adding an iRule increases the resources that the associated virtual server uses. Depending on the type and volume of the connections, this processing may introduce noticeable latency. F5 recommends that you test any such changes in an appropriate environment.
