Description

After performing the steps in K49586523 when you attept to perform a bigip_add from a DNS device you will see the below error.

 

Unable to negotiate with <IP_of_BIG-IP> port 22: no matching host key type found. Their offer: ssh-ed25519

 

Environment

If you use DNS and perform the steps in K49586523.

 

Cause

If you perform the steps in K49586523 this causes the ssh client on DNS devices to fail to connect to the LTMs when you use bigip_add.

 

Recommended Actions

Open an SSH session to the bigIP.

Run the following command to make a copy of the current SSH client configuration file:

 cp /config/ssh/ssh_config /config/ssh/ssh_config.bak

 

Check the current configured ciphers by running the following command:

 

 cat /config/ssh/ssh_config

 

The default will look like:

HostKeyAlgorithms ssh-rsa,ecdsa-sha2-nistp256,ecdsa-sha2-nistp384

 

Using a command line text editor such as 'nano' or 'vi', update the HostKeyAlgorithms in "/config/ssh/ssh_config" as shown below and save the change:

 

HostKeyAlgorithms ssh-ed25519

 

Note: The HostKeyAlgorithms need to include at least one in the server list in the error message above.  If your Big-IPs are not all configured the same you may need to include more that one.
