Description

  • Unable to import large ASM configuration into BIG-IQ
  • BIG-IQ crash while importing ASM configuration.
  • BIG-IQ hangs with message "Waiting for BIG-IQ services to become available"

Environment

  • BIG-IQ CM
  • BIG-IP ASM with more than 100 security policies

Cause

BIG-IQ with recommended minimum resources (8 vCPUs, 32GB RAM) only supports import of BIG-IP/ASM with a maximum of 60 security policies.

Recommended Actions

Increase the BIG-IQ CM resources (16 vCPUs, 64GB RAM, increase /var to 100GB)

Additional Information

None.
