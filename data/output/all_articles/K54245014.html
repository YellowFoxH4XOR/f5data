Known Issue

The BIG-IP system may erroneously remove the rule description of a local traffic policy after an update.

This issue occurs when all of the following conditions are met:

  • You have a local traffic policy configured on the BIG-IP system.
  • The local traffic policy has a rule with a description defined.
  • You use the Configuration utility to modify the local traffic policy with the rule description intact and attempt to save the changes.

Impact

There is no impact on traffic processing. The rule description is removed from the local traffic policy.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After making changes to a local traffic policy and saving your changes, you notice that the policy's rule description is missing.

Workaround

There is no workaround. However, you can avoid this issue by using the Traffic Management Shell (tmsh) to perform rule description updates to the local traffic policy rules. To do so, perform the following procedure.

Impact of workaround: Performing the suggested procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To make changes to a published policy, first create a draft policy by typing the following command syntax:

    modify /ltm policy <Policy_Name> create-draft

    For example, to modify a policy named ABCD, type the following command:

    modify /ltm policy ABCD create-draft

    Note: You cannot directly modify a published policy.

  3. To add a rule description to the draft policy, type the following command syntax:

    modify /ltm policy /Common/Drafts/<Policy_Name> rules modify { <Rule_Name> { description "<Description Text Strings>" } }

    For example, to add a rule description named abcd-rule1 to a draft policy named ABCD, type the following command:

    modify /ltm policy /Common/Drafts/ABCD rules modify { abcd-rule1 { description "This applies to abcd-rule1 only" } }

  4. Repeat step 3 for each policy rule that requires an update.
  5. Publish your changes to the draft policy by typing the following command syntax:

    publish /ltm policy /Common/Drafts/<Policy_Name>

    For example:

    publish /ltm policy /Common/Drafts/ABCD

  6. Save the changes by typing the following command:

    save /sys config
