Description

You can manually run an icall script by restarting icall periodic hander.  The commands are similar to the following;

sys icall handler periodic test_script_handler {
    interval 86400
    script test_script
}
sys icall script test_script {
    app-service none
    definition {
        tmsh::modify /ltm virtual test-vir disabled
        tmsh::modify /ltm virtual test-vir enabled
    }
    description none
    events none
}

tmsh stop sys icall handler periodic test_script_handler
tmsh start sys icall handler periodic test_script_handler 
 

Environment

  • BIG-IP system configuring icall script and icall periodic hander.

Cause

This is by design. 

Recommended Actions

None.

None.
