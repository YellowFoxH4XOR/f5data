K000140308: Uneven use of multiple LSN pools attached to a virtual server

Type
Support Solution
Published
2024-07-11
Updated
2024-07-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000140308

Description

When multiple LSN pools in NAPT mode are attached to a virtual server, BIG-IP does not balance use of pools for translation.

Environment

  • CGNAT licensed and provisioned
  • Virtual Server configured with multiple LSN pools
  • LSN pools in NAPT mode

Cause

CGNAT is not designed to balance across multiple pools assigned to a virtual server. In NAPT mode it will generally prefer to use the lowest available addresses first.

Recommended Actions

If you require balancing across LSN pools, this can be accomplished with an iRule. An example can be found on DevCentral, linked below.
