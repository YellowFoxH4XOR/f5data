Description

Observing errors similar to the following when attempting to run commands such as tmsh, lcdwarn, or top:

can't run "/bin/cp -f /etc/man_db.conf /var/system/tmp/tmsh/fruzak/data", No such file or directory
/bin/sed: can't read /var/system/tmp/tmsh/fruzak/data: No such file or directory

Environment

  • Command line
  • bash/tmsh

Cause

These are known indicators of a compromised system that has had destructive commands run.

Recommended Actions

Consider if the system may have been compromised.

Refer to the following article for further guidance:

  • K11438344: Considerations and guidance when you suspect a security compromise on a BIG-IP system
