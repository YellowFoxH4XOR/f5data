Topic

You should consider using this procedure under one of the following conditions:

  • You want to find the F5OS-C software version on the VELOS system controller.
  • You want to find the F5OS-C software version on the VELOS blades.

Description

F5OS-C software includes the Base OS and Service components. The Base OS component on the system controller includes the following software:

  • CentOS Linux
  • Docker
  • Ansible
  • KubeVirt-VELOS

The Service component on the system controller includes the following software:

  • KubeVirt
  • OpenShift
  • Multus
  • F5-produced software, such as the qkview utility, and platform-specific packages

For the blades assigned to a partition, the Base OS component includes the following software:

  • CentOS Linux
  • Docker
  • Ansible
  • Flannel

The Service component at the partition level includes the following software:

  • Partition webUI
  • tcpdump utility
  • F5-produced software, such as the qkview utility for the partition, license service, and FPGA manager

Prerequisites

You must meet the following prerequisites to use this procedure:

  • For the VELOS chassis system controller, you must have access to either of the following:
    • Root or administrator access to the command-line interface (CLI)
    • Administrator access to the webUI
  • For the VELOS blades assigned to a partition, you must have partition administrator access to the CLI.

Procedures

To find the version information for each of these components, perform one of the following procedures:

  • Display the F5OS-C version information on the VELOS system controller using the webUI
  • Display the F5OS-C version information on the VELOS system controller using the CLI
  • Display the F5OS-C version information on the VELOS system controller using the REST API
  • Display the F5OS-C version information on the VELOS blades assigned to a partition using the webUI
  • Display the F5OS-C version information on the VELOS blades assigned to a partition using the CLI
  • Display the F5OS-C version information on the VELOS blades assigned to a partition using the REST API

Display the F5OS-C version information on the VELOS system controller using the webUI

To find the F5OS-C version information using the webUI of the system controller, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the webUI of the VELOS chassis as the chassis administrator.
  2. Perform the following:

    F5OS-C 1.2.x and later

    Go to SYSTEM SETTINGS > General. The Base OS and Service versions display under System Operations & Status.

    F5OS-C 1.1.x and earlier

    Go to General. The Base OS and Service versions display under System Properties.

Display the F5OS-C version information on the VELOS system controller using the CLI

To find the F5OS-C version information using the CLI of the system controller, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the CLI of the VELOS chassis as the chassis administrator.
  2. Display the software version installed on both system controllers by entering the following command:

    F5OS-C 1.6.0 and later

    show system version

    The command returns an output similar to the following example:

    system version os-version 2.0.0-22925
    system version service-version 2.0.0-22925
    system version product F5OS

    All versions of F5OS-C

    show system image state

    The command returns an output similar to the following example:

                         SERVICE      ISO      INSTALL  
    NUMBER  OS VERSION   VERSION      VERSION  STATUS   
    ----------------------------------------------------
    1       2.0.0-22925  2.0.0-22925  -        success  
    2       2.0.0-22925  2.0.0-22925  -        success 

Display the F5OS-C version information on the VELOS system controller using the REST API

To find the F5OS-C version information using the REST API of the system controller, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the CLI of the VELOS chassis as the root user. Alternatively, you can log in to a system with the curl utility installed.
  2. Display the software version installed on both system controllers using the following command syntax:

    F5OS-C 1.6.0 and later

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<ip address>/api/data/openconfig-system:system/f5-system-version:version"

    In the previous syntax, note the following:

    • Replace <username> and <password> with the administrative username and password to access the VELOS chassis.
    • If you are running the command from the chassis CLI, replace <ip address> with localhost.
    • If you are not running the command from the chassis CLI, replace <ip address> with the floating management IP address of the VELOS chassis.

    For example, if you are running it from the VELOS chassis CLI, enter the following command:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://localhost/api/data/openconfig-system:system/f5-system-version:version"

    The command output appears similar to the following example:

    {
      "f5-system-version:version": {
        "os-version": "2.0.0-22925",
        "service-version": "2.0.0-22925",
        "product": "F5OS"
      }
    }

    All versions of F5OS-C

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<ip address>/api/data/openconfig-system:system/f5-system-controller-image:image"

    In the previous syntax, note the following:

    • Replace <username> and <password> with the administrative username and password to access the VELOS chassis.
    • If you are running the command from the chassis CLI, replace <ip address> with localhost.
    • If you are not running the command from the chassis CLI, replace <ip address> with the floating management IP address of the VELOS chassis.

    For example, if you are running it from the VELOS chassis CLI, enter the following command:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://localhost/api/data/openconfig-system:system/f5-system-controller-image:image"

    The command output appears similar to the following example:

    {
      "f5-system-controller-image:image": {
        "state": {
          "controllers": {
            "controller": [
              {
                "number": 1,
                "os-version": "2.0.0-22925",
                "service-version": "2.0.0-22925",
                "install-status": "success"
              },
              {
                "number": 2,
                "os-version": "2.0.0-22925",
                "service-version": "2.0.0-22925",
                "install-status": "success"
              }
            ]
          }
        }
      }
    }

Display the F5OS-C version information on the VELOS blades assigned to a partition using the webUI

To find the F5OS-C version information of the blades assigned to a VELOS partition using the webUI, perform the following procedure:

Note: This procedure applies to blades installed with F5OS-C 1.2.0 and later only.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the webUI of the partition as the partition administrator.
  2. Go to SYSTEM SETTINGS > General. The Base OS and Service versions for each blade are displayed under System Operations & Status.

Display the F5OS-C version information on the VELOS blades assigned to a partition using the CLI

To find the F5OS-C version information of the blades assigned to a VELOS partition using the CLI, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the CLI of the partition as the partition administrator.
  2. Display the software version installed on the blades assigned to a VELOS partition by entering the following command:

    show components component software

    The command returns output similar to the following example:

    NAME     SOFTWARE INDEX      VERSION      
    ------------------------------------------
    blade-1  blade-os            2.0.0-22925 
             partition-services  2.0.0-22925 
    blade-2  blade-os            2.0.0-22925 
             partition-services  2.0.0-22925 

Display the F5OS-C version information on the VELOS blades assigned to a partition using the REST API

To find the F5OS-C version information of the blades assigned to a VELOS partition using the REST API, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to a system with the curl utility installed. Alternatively, you can log in to the CLI of the VELOS chassis as the root user.
  2. Display the software version installed on a blade assigned to a VELOS partition using the following command syntax:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<ip address>/api/data/openconfig-platform:components/component=<blade name>/f5-platform:software"

    In the previous syntax, note the following:

    • Starting in F5OS-C 1.8.1, you must replace <username> and <password> with the administrative username and password of the VELOS partition. Prior to F5OS-C 1.8.1, replace <username> and <password> with the administrative username and password to access the VELOS chassis.
    • Starting in F5OS-C 1.8.1, you must replace <ip address> with the management IP address of the VELOS partition. Prior to F5OS-C 1.8.1, if you are running the command from the chassis CLI, replace <ip address> with localhost; if you are not running the command from the chassis CLI, replace <ip address> with the floating management IP address of the VELOS chassis.
    • Replace <blade name> with the name of one of the blades assigned to the VELOS partition.

    For example, enter the following command to display the F5OS-C version running on blade-1 for partition management IP address 192.168.8.81:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://192.168.8.81/api/data/openconfig-platform:components/component=blade-1/f5-platform:software"

    The command output appears similar to the following example:

    {
      "f5-platform:software": {
        "state": {
          "software-components": {
            "software-component": [
              {
                "software-index": "blade-os",
                "state": {
                  "version": "2.0.0-22925"
                }
              },
              {
                "software-index": "partition-services",
                "state": {
                  "version": "2.0.0-22925"
                }
              }
            ]
          }
        }
      }
    }

  3. Repeat the previous step for the remaining blades assigned to the VELOS partition by replacing <blade name> with the appropriate name of the blade.
