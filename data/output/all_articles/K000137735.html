Description

When you are viewing System  ››  Certificate Management : Device Certificate Management : Device Trust Certificates or DNS  ››  GSLB : Servers : Trusted Server Certificates via the GUI, an error like below prompt and prevent your request.


Environment

  • BIG-IP LTM
  • BIG-IP DNS
  • Device Trust Certificates

Cause

There are the CSR(Certificate Signing Request) files in /config/big3d/ or /config/gtm, refer to ID893093 .

Recommended Actions

Remove the CSR file that has the .crt suffix name from /config/big3d/ or /cofig/gtm. For example, cert.crt is actually a CSR type file, you want to remove this file, use below commands:

#rm -r /config/big3d/cert.crt

#rm -r /config/gtm/cert.crt

Additional Information

Typically, the /config/big3d/ and /cofig/gtm should contain only the CRT files.
