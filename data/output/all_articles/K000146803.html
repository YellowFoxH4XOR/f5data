K000146803: How to allow or block SSH or WebUI port 65500 into CE Devices hosted in Public Cloud

Type
Support Solution
Published
2024-11-08
Updated
2026-09-03
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000146803

Description

You need to SSH or access the WebUI over port 65500 on a CE device to obtain a debug file or troubleshoot. Firewall rules and security groups are not blocking anything however trying to open a connection to any of these ports (22 or 65500) times out.

❯ nc public.ip 22 -v
nc: connectx to public.ip port 22 (tcp) failed: Operation timed out

 

Environment

  • F5® Distributed Cloud
  • Cloud and Edge Sites Service on F5 Distributed Cloud Services Platform
  • Public Cloud e.g. Azure

 

Cause

By default SSH and WebUI are blocked in Advanced Settings.

 

Resolution/Answer

Port 22 and 65500 need to be allowed under the Security Groups or firewall rules in public cloud configuration and after that please navigate to

  • Multi-Cloud Network Connect
  • Site Management
  • Azure VNET Sites (we are using Azure in this example, however select the one that matches your public cloud) 
  • Locate your site
  • Click the three dots under Actions column
  • Click Manage configuration

 

Go to Advanced Configuration and notice the current status of SSH and WebUI services

 

  • Click Edit Configuration
  • And Select the desired option

 

 

Additional Information

CE Sites block these ports by default.
