Known Issue

The security model of the Apple iOS does not accept private keys that are not password protected. As a result, attempting to load a certificate/private key that is not password protected into the BIG-IP Edge Portal application will fail. In addition, the following error message will display:

The password for the certificate "<certificatename>" is incorrect.

F5 Product Development is tracking this issue as ID 344493.

Workaround

You will need to obtain a password-encrypted version of your certificate file.

Note: The BIG-IP Edge Portal application supports only the PKCS#12 (.p12) certificate file format.

Note: For more information about using certificates with the BIG-IP Edge Portal application, refer to K12424: Configuring the BIG-IP Edge Portal application to use a client certificate on Apple iOS devices.
