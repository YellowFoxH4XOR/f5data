Description

BIG-IP is not responding and you are not able to access through GUI or SSH. From the Console, you may see the following display:

[118596.434394] EXT3-fs error (device dm-13): ext3_get_inode_loc: unable to read inode block - inode=116974, block=459022
[118606.599751] Buffer I/O error on dev dm-15, logical block 110594, lost async page write

Environment

  • BIG-IP
  • Hard Disk Drive
     

Cause

This primarily occurs due to corruption of Ext3 file system. The error message does not allows the system to boot and makes the hard drive data inaccessible. The error message consists of various inodes and blocks that are unreadable.
 

Recommended Actions

To resolve corruption in Ext3 file system and to access the data saved in your hard drive, follow the below steps:

  1. Run File System Check by typing the following command:
    fsck -y
  2. After the fsck command completes, restart the device.
    reboot
If FSCK is also not able to repair the file system, then you need to re-install the operating system. Please follow the article below:
K13117: Performing a clean installation of BIG-IP 11.x - 17.x

If the problem still persists, contact F5 support. 
 

Additional Information

You may also want to run EUD to verify Hard Disk Drive condition.
