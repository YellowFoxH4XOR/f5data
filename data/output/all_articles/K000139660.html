Description

You had followed  K15763 : Troubleshooting RADIUS authentication for BIG-IP administrative users

In the pcap file, you have checked "RADIUS Access-Accept" has returned to F5, but F5's secure log still show 

May 15 14:28:07 localhost err httpd[7995]: pam_radius_auth: RADIUS server x.x.x.x failed to respond

 

Environment

RADIUS

Remote authentication to F5 for administrative purpose

Downstream firewall or networking device might still use the old mac table

Cause

One of Common causes is that the BIG-IP receives the return traffic on an old mac-address. The downstream networking device forwards the return traffic to an old mac address.

Not a F5 issue

 

Recommended Actions

Comparing the mac addresses for the egress and ingress packets to F5. Make sure the mac addresses for both destination and source matches so they are in the same conversation.

Once the mac address table has been corrected in the downstream networking device, the problem will be fixed.

Note that this is one of the common causes and might not suitable for other cases.
