K13545534: F5 LTM GUI cannot display APM log more than 90 minutes.

Type
Support Solution
Published
2022-04-27
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.3
Source
https://my.f5.com/manage/s/article/K13545534

Description

There is a limit to the number of logs the configuration utility can display

Environment

  • BIG-IP APM 15.1.3
  • APM logging
  • Configuration Utility

Cause

This is by design.  System -> Logs -> Access Policy only shows the *last* 1 MB of the logs that come from /var/log/apm 

Recommended Actions

None.

Additional Information

None
