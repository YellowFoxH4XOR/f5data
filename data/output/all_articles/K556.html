Note: For information about configuring interfaces, refer to the BIG-IP Reference Guide specific to the version that you are running.

BIG-IP versions 4.0 - 4.6.4

Starting in BIG-IP version 4.0, Source and Destination Processing configurations are no longer required. Every BIG-IP interface is automatically capable of both external and internal functions, so no additional configuration is necessary.
