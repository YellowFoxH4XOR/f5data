Environment

  • BIG-IP ASM
  • BD/CP tables discrepancy

Cause

The job queue of the BD agent is full and the BD and DCC(cp) data are not synchronized. 

Recommended Actions

To fix this error, perform the following steps:

  1. Check the /var has enough space by running the command:
    df -h
     
  2. If full, free up some space by checking for large files in the /var partition. 
    find /var -xdev -type f -exec du {} \; | sort -rn | head -20

    The following command syntax displays the 20 largest files or folders, excluding files or folders that are expected to be large. 
    For more details in maintaining disk space on the BIG-IP System, you may refer (K14403).
     
  3. If /var has enough space, attempt to restart the device:
    bigstart restart
