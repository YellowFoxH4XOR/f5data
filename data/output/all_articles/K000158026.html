K000158026: Issue while Configuring HSL through Management Port

Type
Support Solution
Published
2025-12-12
Updated
2025-12-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000158026

Description

System events and high-speed logs configured to use the management port on BIG-IP LTM were not being received by the remote syslog server.

Environment

  • BIG-IP LTM
  • High-Speed Logging (HSL) configured with a management-port destination

Cause

System events were not reaching the remote syslog server as no log-config filter is configured to direct system event logs to the publisher associated with the management-port destination.

Recommended Actions

  • Verify the HSL has been configured using the management port 
    tmsh list sys log-config destination <destination_name>
  • Verify the publisher includes the management-port destination: 
    tmsh list /sys log-config publisher <publisher_name>
  • Create a log-config filter that matches the desired system event level (e.g., notice) and points to the publisher referencing the management-port destination. 
    tmsh create /sys log-config filter <filter_name> { level notice publisher <publisher_name> }
  • Restart the errdefsd process if changes are made: 
    bigstart restart errdefsd

Additional Information

Check the active connection to syslog server should be from management-ip as source using command:

netstat -pan | grep -E 'syslog-ng|errdefsd'

where IP 1.2.3.4 is the management IP and 192.168.1.1 is syslog server:
