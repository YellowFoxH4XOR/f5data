Known Issue

This is the result of a known issue. The BIG-IP Configuration utility allows you to enable active-active mode without verifying that network failover is enabled. As a result, in BIG-IP version 10.x, the BIG-IP systems will both go offline. In order for a redundant pair of BIG-IP systems to operate in active-active mode, network failover must be enabled. However,

F5 Product Development is tracking this issue as ID 224503.

Workaround

In order to safely enable active-active mode, you must configure and enable network failover.

Note: For more information about configuring network failover, refer to K2397: Comparison of serial failover and network failover features and the Configuring network failover section in the TMOS Management Guide for BIG-IP Systems. For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.
