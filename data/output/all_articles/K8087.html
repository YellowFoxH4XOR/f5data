Known Issue

Note: This Solution only applies to FirePass 4100 and 4300 platforms, which have the Switch Card Control Processor (SCCP).

This is the result of a known issue. A timer wrap within the SCCP kernel occurs after 497 days, and resets the timer to 0 (zero). At the exact instant of the timer wrap, any Inter-Integrated Circuit (I2C) bus driver reads or writes will fail because the I2C is unable to correctly handle the kernel timer wrapping. The System Management Bus (SMBus) then enters a lockup condition, which causes all subsequent I2C reads or writes communications to fail until the SCCP is rebooted. As a result, the SCCP cannot gather data from the host system on fan speeds, temperatures, and power supplies until the SCCP is rebooted (typically done by rebooting the FirePass controller). The status of the system components on the Device Management: Monitoring: System Health page may be inaccurate. Additionally, attempts to license the FirePass controller may fail because the dossier file submitted to obtain the license is created in part by collecting information from the system hardware. If I2C reads fail, this information cannot be retrieved to create the dossier.

This issue is similar to the issue described in K7071: The SCCP kernel driver timer wrap causes an I2C read failure, which applies to these and other hardware platforms when running BIG-IP software. However, this issue affects FirePass software to a much lesser degree. The frequency at which FirePass reads from the SCCP is much lower than that of the BIG-IP. Therefore, the probability of FirePass software encountering this issue is small.

F5 Product Development is tracking this issue as ID 266917 (formerly CR88493).

Note: F5 Product Development is tracking the root cause of this issue, the Linux uptime counter wrap, as CR74550. For details and the current status of this issue, refer to K7036: The Linux uptime counter wraps after 497 days.

Note: The 4300 platform is supported on FirePass software version 6.0.1 and later versions of the 6.0 software branch.
