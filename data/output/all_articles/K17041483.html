Description

How to disable TLS 1.0 on the self IP interface and MGMT interface

Environment

  • self IP
  • MGMT interface
  • TLS 1.0

Cause

An audit scan report has detected that "TLS Version 1.0 Protocol Detection" is enabled on the self IP

Recommended Actions

The way to resolve this is not exactly on the self IP it is on the httpd service, so this will apply to self IP and MGMT IP

Note: This example of removing TLS 1.0 was taken from BIG-IP version 16.1.0. For additional examples, refer to K02321234: Managing the SSL protocols and ciphers allowed by Configuration utility.

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. Review which protocols are currently in use by entering the following command:

    list /sys httpd ssl-protocol

    Example Output:

    sys httpd {
        ssl-protocol "all -SSLv2 -SSLv3"
    }

  3. Apply the modify command according to your requirements. For example:

    modify /sys httpd ssl-protocol "all -SSLv2 -SSLv3 -TLSv1"

  4. Verify the change using the list command again:

    list /sys httpd ssl-protocol

    Example Output:

    sys httpd {
        ssl-protocol "all -SSLv2 -SSLv3 -TLSv1"
    }

  5. Save the configuration change by entering the following command:

    save /sys config
