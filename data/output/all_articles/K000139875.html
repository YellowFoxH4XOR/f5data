Description

When trying to edit any of the values (adding a port for example) in F5 Secure Web Gateway iApp Template you may encounter a problem where the changes do not save and the GUI displays the following message:

01b4002b:3: Client SSL profile (/<partition>/<ssl_profile>): the profile has no RSA cert/key pair that can be modified. To add RSA cert/key, please use [cert-key-chain add].

Environment

  • BIG-IP VE
  • iApp Template (F5 Secure Web Gateway)

Cause

This is because of how the old iApps were written. Most of them cannot be edited because of SSL profile attached to it.

Recommended Actions

To solve this problem, you can re-create the iApp, but first you should check if the profiles are not being used on other virtual servers. In case of situation mentioned before, create a new virtual server with the desired changes for which you are trying to add via iApp and attach the profile of iApp.
