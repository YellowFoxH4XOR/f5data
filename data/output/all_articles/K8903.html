Issue

Starting in FirePass 6.0.2 with cumulative hotfix HF-602-2, the LDAP Group Object mapping method supports LDAP group attributes that contain relative user distinguished names (DNs). For example, the following LDAP schema defines group membership using relative user DNs:

dn: cn=sales,ou=groups,dc=siterequest,dc=com
cn: sales
objectClass: posixGroup
userPassword: {crypt}*
gidNumber: 100
memberUid: jsmith
memberUid: rjones
memberUid: fterry

For information about configuring the LDAP Group Object mapping method, refer to K8258: Configuring dynamic group mapping using the LDAP Group Object mapping method.

Prior to FirePass 6.0.2 with cumulative hotfix HF-602-2, the LDAP Group Object mapping method only supported LDAP group attributes that contained full user DNs. For FirePass versions prior to FirePass version 6.0.2 with Cumulative Hotfix HF-602-2, a workaround is available to support LDAP group mapping using LDAP group objects that contain relative DNs. For information about this workaround, refer to K8238: Configuring dynamic group mapping using the LDAP User Object mapping method with an LDAP group object attribute.

F5 Product Development is tracking this enhancement as CR91992.
