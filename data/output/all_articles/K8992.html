Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator PVAC memory manager does not release or reuse some allocated memory. This issue may cause increased memory usage, and eventually lead to memory exhaustion.

F5 Networks Product Development tracked this issue as CR96975 and it was fixed in BIG-IP WebAccelerator version 9.4.6. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2 issued for BIG-IP WebAccelerator version 9.4.5. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about how to manage F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.
