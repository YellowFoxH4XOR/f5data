Known Issue

When you attempt to delete a custom monitor, the BIG-IP system fails to do so and logs an error message to the Configuration utility or command line and to the /var/log/ltm file.

This issue occurs when all of the following conditions are met:

  • The affected custom monitor is assigned as a member-specific monitor to a pool member
  • The pool member that is assigned the custom monitor is subsequently deleted

Impact

You cannot remove the affected custom monitor from the BIG-IP configuration.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Configuration utility returns a message that appears similar to the following example if you use the Configuration utility to attempt to delete the monitor:

    01070083:3: Monitor <monitor name> is in use.

  • The command line returns a message that appears similar to the following example if you use the bigpipe monitor <monitor name> delete command to attempt to delete the monitor:

    01070083:3: Monitor <monitor name> is in use.

  • The BIG-IP system logs a message that appears similar to the following example to the /var/log/ltm file:

    01070083:3: Monitor <monitor name> is in use.

In the messages, note the following:

  • <monitor name> is the name of the custom monitor you want to delete.

Workaround

To work around this issue, you can save and reload the configuration before attempting to delete the affected custom monitor. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the command line.
  2. Save the running configuration to the configuration files by typing the following command:

    bigpipe save

  3. Load the saved configuration into the running configuration by typing the following command:

    bigpipe load

  4. Proceed to delete the affected custom monitor.
