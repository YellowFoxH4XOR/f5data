Description

Configured port lockdown to "allow none" on self-IP, but user can still access BIG-IP GUI via that self-IP.

Environment

  • Virtual server (Forwarding IP, Performance L4, with FastL4 profile)
  • self IP

Cause

A virtual server (Forwarding IP, Performance L4, with FastL4 profile) is configuring on the same self IP and listening on any ports.
The incoming traffic will match the virtual server and being processed directly, BIG-IP will not refer to the port lockdown configuration to block the unauthorized ports.
This is by design, the matching schema of virtual server matches before self-IP.

Recommended Actions

Do not use the same IP address for a virtual server (with any port) and a self-IP.
