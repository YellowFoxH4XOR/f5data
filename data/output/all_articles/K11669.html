Known Issue

This is the result of a known issue. When the Enterprise Manager discovers a device that has a OneConnect profile configured, or if a OneConnect profile is added to the configuration, the device is marked as impaired. The device status, located on the Configuration utility Device screen, reports an error message that appears similar to the following example:

get change control info: iControl error: 'iControl::OperationFailed - primary code:2(0x2) secondary code: 0(0x0) string:
bigpipe command '/usr/bin/bigpipe shell' with stdin'profile connpool first_test list ' returned unexpected number of instances (0)'

F5 Product Development tracked this issue as CR135906, and it was fixed in version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
