K000131609: GUI not responding or returning 401 on Policy pages or upload actions

Type
Support Solution
Published
2023-01-19
Updated
2023-01-19
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.5, 15.1.5, 15.1.6, 15.1.7, 15.1.8, 16.1.2, 16.1.3, 17.0.0, 13.1.5
Source
https://my.f5.com/manage/s/article/K000131609

Description

GUI is not responding, and returning a 401 (seen in browser developer tools) while performing certain actions:

  • Uploading an ASM policy
  • Creating a new local traffic (LTM) policy
  • Listing LTM or ASM policies

Messages returned may be one or more of:

Loading data...

Unable to upload file

Failed to process transaction, request not processed

Environment

  • GUI
  • 15.1.5.1 or later version
  • Connecting to the system via a proxy

Cause

Bug ID 1110893: Some portions of the BIG-IP GUI do not work when accessed behind an HTTP proxy

Recommended Actions

Apply the workaround for bug ID 1110893:

tmsh mod sys db httpd.matchclient value false

tmsh restart sys service httpd

Note: This DB key, when enabled (default), validates that requests using token auth originate from the same client IP that initially requested the token. Disabling the DB key disables that validation.

ID 1110893 has no permanent fix at the time of this article's publication, but an engineering hotfix may be requested by contacting F5 Support.
