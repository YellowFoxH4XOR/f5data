K000138868: Error log: Bmc Health Self test failed: Device-specific 'internal’ failure

Type
Support Solution
Published
2024-03-10
Updated
2024-10-17
Applies to
  • F5OS
  • F5OS-A: 1.7.X, 1.5.X, 1.7.0, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000138868

Description

The rSeries may at times display and log the following error:

2024-03-03T10:00:00.872254-08:00 appliance-1 alert-service[8]: priority="Notice" version=1.0 msgid=0x2201000000000029 msg="Received event." event="65543 appliance aom-fault EVENT NA "Bmc Health Self test failed: Device-specific 'internal' failure." "2024-03-03 11:00:00.872254 UTC"".

Environment

  • rSeries 2x00
  • rSeries 4x00

Cause

ID 1558797

Recommended Actions

  • Upgrade to a fixed F5OS-A version in ID 1558797
  • If the error is persistent and is not cleared ( usually at the next hourly mark), please open a support case with F5 support.
    If the error is cleared at the next hourly mark, it may be indicative of a false alarm.
