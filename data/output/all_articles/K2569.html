K2569: Configuring BIG-IP to load balance UDP SIP traffic in both directions

Topic

Because UDP is not a connection-oriented protocol, the SIP protocol does not establish a connection. SIP initiates UDP datagrams from both the client and the node.

In this scenario, you should configure two virtual servers; one to load balance the incoming requests and one to pass the outgoing requests.

Configure SIP persistence for the incoming virtual server, but configure no persistence for the outgoing virtual server. If you configure SIP persistence for the outgoing virtual server, it will direct the datagrams back to the node, since the existing SIP persistence entry indicates that the node is the destination.
