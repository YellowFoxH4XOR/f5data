Description

After upgrade, you notice a user with Resource Administrator rights, could not get access to LTM Policy list on the Web GUI.

Other parts of the GUI can also be affected, like Network Map or Analytics View.

Environment

  • After upgrade
  • User Roles
  • GUI access

Cause

Bug ID 718796: IControl REST token issue after upgrade

Recommended Actions

To workaround the issue on affected versions, run the following commands from the command line:

restcurl -X DELETE "shared/storage?key=shared/authz/icontrol-role-migrator"
bigstart restart restjavad
