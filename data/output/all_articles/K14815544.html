Description

  • You create ASM security policy on the BIG-IP
  • Security Policy is set to NOT differentiate HTTP/WS and HTTPs/WSS URLs
  • You then create and export a template of this Security policy
  • You import the template onto the BIG-IQ to be used for future security policy creation 
  • You then create a new security policy of this Template, validate the configuration on the BIG-IQ
  • But when you attempt to deploy/push the policy from BIG-IQ to managed BIG-IP, it fails with error "URL '*' already exists in this policy"

/var/log/restjavad.0.log

[ERROR][12 Aug 2021 09:25:16 CEST][/cm/asm/tasks/distribute-configuration/07a104-0d29-4d6f-a46d-6ebdc414/worker AsmDistributeTaskWorker] Failed pushing added objects to device bigip1.local: URL '*' already exists in this policy.
[ERROR][12 Aug 2021 09:25:17 CEST][/cm/asm/tasks/cluster-distribute-config/9f0be8-fc5a-4470-8fcf-65d0c908b/worker AsmClusterDistributeTaskWorker] Failed pushing added objects to device bigip1.local: URL '*' already exists in this policy.

Environment

  • BIG-IQ deployment 
  • ASM Security policy
  • BIG-IP

Cause

  • Currently the BIG-IQ require us to differentiate HTTP/WS and HTTPs/WSS URLs
  • In other words, the feature to differentiate HTTP and HTTPs on the BIG-IQ does not exist 

Recommended Actions

  • Use Security policy template that differentiate HTTP and HTTPs
