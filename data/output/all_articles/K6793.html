Topic

The BIG-IP DNS system defines a server as a specific system on the network to which requests may be load balanced, and may represent either a single host or a load balancer that hosts multiple virtual servers. The BIG-IP DNS system gathers information from each server to select the most appropriate name resolution responses for each request.

The BIG-IP DNS system supports the following server types:

  • BIG-IP systems
  • Third-party load balancing systems
  • Third-party hosts

The BIG-IP DNS system gathers information from other BIG-IP systems using the iQuery protocol, to communicate with the remote big3d process. The BIG-IP DNS system also gathers information from third-party hosts and load balancing systems by using Simple Network Management Protocol (SNMP) to poll specific object identifiers (OID) on the remote agent. This article describes the SNMP OIDs that are polled for each third-party host or load balancing system that may be defined on the BIG-IP DNS system.

Note: For more information about defining servers for load balancing, refer to the Defining the Physical Network chapter of the BIG-IP DNS Configuration Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Third-party load balancing systems

A third-party load balancing system is any system, other than a BIG-IP system, that supports and manages virtual servers on the network. The following third-party load balancing systems are listed in the Configuration utility:

  • Generic Load Balancer
  • Alteon Ace Director
  • Cisco CSS
  • Cisco LocalDirector v2
  • Cisco LoadDirector v3
  • Cisco SLB
  • Extreme
  • Foundry ServerIron
  • Radware WSD

Third-party host servers

A third-party host server is any server resource on the network that does not support virtual servers. The following third-party load balancing systems are listed in the Configuration utility:

  • Generic Host
  • CacheFlow
  • NetApp
  • Sun Solaris
  • Windows 2000 Server
  • Windows NT 4.0

SNMP OIDs polled by the Product selected

Each entry in the Product menu of the server definition screen refers to a previously defined list of OIDs that the system polls, on that device, to gather the required status information. The system polls the following OIDs based on the server product type chosen:
