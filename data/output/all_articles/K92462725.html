Topic

BIG-IP ASM devices configured for high availability (HA) may continually display the Changes Pending synchronization status.

The Changes Pending status is raised when one or more BIG-IP system contains configuration changes are not synchronized with the other members of the device group. This is likely caused by the device having a security policy with Learning Mode set to Automatic. If automatic synchronization is not enabled for the device group, the automatic updates to the security policy cause the HA pair to become out-of-sync.

Description

In a device group that includes a BIG-IP ASM security policy configured with automatic learning mode, to avoid the Changes Pending synchronization status, you can enable automatic synchronization for the existing sync-failover device group with the following procedures:

Enabling automatic synchronization for the sync-failover device group

  1. Log in to the Configuration utility.
  2. Go to Device Management > Device Groups.
  3. Select the sync-failover group that contains devices with shared security policies.
  4. For Sync Type, select Automatic with Incremental Sync.
  5. Select Update.

Enabling BIG-IP ASM synchronization on the sync-failover group

  1. Log in to the Configuration utility.
  2. Go to Security > Options > Application Security > Synchronization > Application Security Synchronization.
  3. Select the sync-failover group.
  4. Save the changes.

If the device group has an active-active configuration, and policy changes are expected from multiple devices, F5 recommends enabling automatic synchronization for a separated sync-only device group. To do so, perform the following procedures:

Creating a sync-only device group

  1. Log in to the Configuration utility.
  2. Go to Device Management > Device Groups.
  3. Select Create.
  4. Create a Sync-Only device group, and for Sync Type, select Automatic with Incremental Sync.
  5. Make all devices that share security policies members of this newly created group.
  6. Select Update.

Enabling BIG-IP ASM synchronization on the sync-only group

  1. Log in to the Configuration utility.
  2. Go to Security > Options > Application Security > Synchronization > Application Security Synchronization.
  3. Select the newly created sync-only group.
  4. Save the changes.
