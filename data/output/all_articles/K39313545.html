Description
You want to check and verify the version of jQuery installed on your BIG-IP due to Vulnerability Assessment Scan Report.
 

Environment

  • BIG-IP
  • jQuery version


Cause
None
 

Recommended Actions

To check jQuery version on BIG-IP, from bash run the command below:
#rpm -qa | grep jquery

In this example, the version of jQuery installed is 1.10.2
[user] config # rpm -qa | grep jquery
jquery-1.10.2-0.0.19.i686

Additional Information

jQuery version may be updated with each new release of BIG-IP software.

Note: For other BIG-IP third-party software installed on your device, refer to the Related Content section.
