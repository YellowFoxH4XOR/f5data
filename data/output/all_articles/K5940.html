Topic

The following scenarios may apply in situations where a web application accepts requests for HTTP and HTTPS connections:

  • Multiple virtual servers using a single pool with wildcard port members
  • Multiple virtual servers with separate pools for HTTP and HTTPS members
Multiple virtual servers using a single pool with wildcard port members

Creating a pool that contains members with a wildcard port specified

To create a pool that contains members that have a wildcard (*) port specified, perform the following procedure:

  1. Click Local Traffic.

  2. Click Pools.

  3. Click Create.

  4. Type the desired pool name in the Name field.

  5. Select the desired load balancing method from the Load Balancing Method drop-down list.

  6. Type the IP address of the pool member in the Address field.

  7. Select *All Services from the Service Port drop-down list.

  8. Click Add.

  9. Repeat steps 6, 7, and 8 for the remaining pool members.

  10. Click Finished.

Creating an HTTP Class profile with Application Security Enabled

To create an HTTP Class profile with Application Security enabled, perform the following procedure:

  1. Click Application Security.

  2. Click Classes.

  3. Click Create.

  4. Type the desired HTTP Class profile name in the Name field.

  5. Select Enabled from the Application Security drop-down list.

  6. Select the pool created in the Creating a pool that contains members with a wildcard port specified procedure from the Pool drop-down list.

  7. Click Finished.

Creating virtual servers for HTTP and HTTPS

To create virtual servers for HTTP and HTTPS, perform the following procedure:

  1. Click Local Traffic.

  2. Click Virtual Servers.

  3. Click Create.

  4. Type the desired virtual server name in the Name field.

  5. Type the IP address of the virtual server in the Address field.

  6. Select HTTP from the Service Port drop-down list.

  7. Select HTTP from the HTTP Profile drop-down list.

  8. Select the profile created in the Creating an HTTP Class profile with Application Security Enabled procedure from the Available list of HTTP Class Profiles.

  9. Click << to move the selected profile to the Enabled list.

  10. Select None from the Default Pool drop-down list.

  11. Click Finished.

  12. Repeat steps 1 through 5.

  13. Select HTTPS from the Service Port drop-down list.

  14. Repeat steps 7 through 11.

After performing these procedures, traffic is passed to the pool member on the same port as the virtual server the traffic was received on.

For example:

The BIG-IP ASM system will inspect traffic sent to the HTTP virtual server, which is port 80, if the traffic matches the HTTP class profile criteria. The BIG-IP ASM system will then pass the traffic to a pool member on the HTTP port. The BIG-IP ASM system will inspect traffic sent to the HTTPS virtual server, which is port 443, if the traffic matches the HTTP class profile criteria. The BIG-IP ASM system will then pass the traffic to a pool member on the HTTPS port.

Multiple virtual servers with separate pools for HTTP and HTTPS members

Creating a pool that contains HTTP members

To create a pool that contains HTTP members, perform the following procedure:

  1. Click Local Traffic.

  2. Click Pools.

  3. Click Create.

  4. Type the desired pool name in the Name field.

  5. Select the desired load balancing method from the Load Balancing Method drop-down list.

  6. Type the IP address of the pool member in the Address field.

  7. Type the desired Service Port or select HTTP from the Service Port drop-down list.

  8. Click Add.

  9. Repeat steps 6, 7, and 8 for the remaining pool members.

  10. Click Finished.

Creating a pool that contains HTTPS members

To create a pool that contains HTTPS members, perform the following procedure:

  1. Click Local Traffic.

  2. Click Pools.

  3. Click Create.

  4. Type the desired pool name in the Name field.

  5. Select the desired load balancing method from the Load Balancing Method drop-down list.

  6. Type the IP address of the pool member in the Address field.

  7. Type the desired Service Port or select HTTPS from the Service Port drop-down list.

  8. Click Add.

  9. Repeat steps 6, 7, and 8 for the remaining pool members.

  10. Click Finished.

Creating an HTTP Class profile with Application Security enabled

To create an HTTP Class profile with Application Security enabled, perform the following procedure:

  1. Click Application Security.

  2. Click Classes.

  3. Click Create.

  4. Type the desired HTTP Class profile name in the Name field.

  5. Select Enabled from the Application Security drop-down list.

  6. Select None from the Pool drop-down list.

  7. Click Finished.

Create a virtual server for HTTP

To create a virtual server for HTTP, perform the following procedure:

  1. Click Local Traffic.

  2. Click Virtual Servers.

  3. Click Create.

  4. Type the desired virtual server name in the Name field.

  5. Type the IP address of the virtual server in the Address field.

  6. Select HTTP from the Service Port drop-down list.

  7. Select HTTP from the HTTP Profile drop-down list.

  8. Select the HTTP profile created in the Creating an HTTP Class profile with Application Security enabled procedure from the Available list of HTTP Class Profiles.

  9. Click << to move the selected profile to the Enabled list.

  10. Select the pool created in the Creating a pool that contains HTTP members section from the Default Pool drop-down list.

  11. Click Finished.

Creating virtual servers for HTTPS

To create virtual servers for HTTPS, perform the following procedure:

  1. Click Local Traffic.

  2. Click Virtual Servers.

  3. Click Create button.

  4. Type the desired virtual server name in the Name field.

  5. Type the IP address of the virtual server in the Address field.

  6. Select HTTPS from the Service Port drop-down list.

  7. Select HTTP from the HTTP Profile drop-down list.

  8. Select the HTTP profile created in the Creating an HTTP Class profile with Application Security enabled procedure from the Available list of HTTP Class Profiles.

  9. Click << to move the selected profile to the Enabled list.

  10. Select the pool created in the Creating a pool that contains HTTP members section from the Default Pool drop-down list.

  11. Click Finished button.

Once you have performed these procedures, traffic is passed to a member of the pool associated with the virtual server that received the traffic. This method allows you to control the load balancing method and other pool specific settings for each virtual server.

For example:

The BIG-IP ASM system will inspect traffic sent to the HTTP virtual server, which is port 80, if the traffic matches the HTTP class profile criteria. The BIG-IP ASM system will then pass the traffic to a pool member on the HTTP port. The BIG-IP ASM system will inspect traffic sent to the HTTPS virtual server, which is port 443, if the traffic matches the HTTP class profile criteria. The BIG-IP ASM system will then pass the traffic to a pool member on the HTTPS port.
