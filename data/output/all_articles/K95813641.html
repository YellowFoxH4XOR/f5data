K95813641: Resolving BIG-IQ Import Conflicts

Applies to

Description

After discovering or importing the BIG-IP device into the BIG-IQ, you should always manage the BIG-IP device from the BIG-IQ. Changes made locally to the BIG-IP system may result in conflicts being detected by the BIG-IQ.

When conflicts are found, BIG-IQ displays the Resolve Conflicts dialog box, which lists all conflicts found and displays detailed differences for conflicting shared objects, and provides for conflict resolution. 
The Resolve Conflicts dialog box may be displayed two times: once for Network Security objects, and once for Shared Security objects.

Additionally, changes made locally on a managed BIG-IP system may have one or more of the following negative effects:
  • Changes made locally on a managed BIG-IP system will not be reflected on the BIG-IQ unless you re-discover and re-import the BIG-IP system.
  • Changes made locally on a managed BIG-IP system may be overwritten if you perform a deployment from the BIG-IQ system. 

Environment

  • BIG-IP device managed by BIG-IQ
  • Configuration changes made locally on the BIG-IP system

Cause

A managed BIG-IP configuration is updated locally on the BIG-IP system instead of from the BIG-IQ system.

Recommended Actions

If there are any configuration conflicts, the BIG-IQ user interface displays a list of configuration for you to select the conflict resolution methods. Choose one of the following methods appropriate for your environment:
  • BIG-IQ to keep the shared object in the BIG-IQ system's working configuration. The next time the BIG-IQ system deploys a configuration to that BIG-IP device, it updates the shared object to match the one on the BIG-IQ system.
  • BIG-IP to use the shared object from the BIG-IP device's configuration to replace the shared object in the BIG-IQ system's working configuration that is different. If you select this method, the BIG-IQ system replaces that shared object for all of your managed BIG-IP devices the next time it deploys a configuration.
  • Create Version if you want BIG-IQ to create and store a copy of the BIG-IP device's BIG-IP LTM monitor or profile object(s), specific to the software version running on that BIG-IP device. If you select this method, BIG-IQ replaces that object for all the managed BIG-IP devices running that version the next time it deploys a configuration. You can store multiple versions of BIG-IP LTM monitors or profiles. BIG-IQ deploys the appropriate stored version to your managed devices. BIG-IQ automatically resolves conflicts against the appropriate version the next time it imports services that contain BIG-IP LTM monitors or profiles.
Note: Although conflict resolution often results in changes to either the BIG-IP configuration or the BIG-IQ configuration, no changes are applied until they are deployed. You can deploy changes when a deployment task displays the status of READY TO DEPLOY.
