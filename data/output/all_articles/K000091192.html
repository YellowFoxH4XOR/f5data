K000091192: When modifying Gateway, receive Error creating gateway services_uat_api_gateway: API Error (1225): Error upserting gateway: Failed to complete the request due to internal server error

Type
Support Solution
Published
2022-01-03
Updated
2026-08-13
Source
https://my.f5.com/manage/s/article/K000091192

Description

  • You configured API-Gateway and attached APIs and all associated Components 
  • Configured applications are accessible via the gateway
  • You want to modify settings on the Gateway
  • But when navigating to Gateway >> edit >> and attempt to make any change, you end up getting error message 

Error creating gateway <name of gateway>: API Error (1225): Error upserting gateway: Failed to complete the request due to internal server error

Environment

  • Nginx Controller
  • Gateway

Cause

  • APIs are mapped onto the Gateway 

Recommended Actions

  • Create a NEW gateway with the desired settings/value
  • And map all APIs/applications as before onto the Gateway 

Additional Information

None
