Issue

Error Message

Error Message: 01070413:5: Updated existing subscriber <process> with new filter class <filter>

In this error message, note the following:

  • <process> is the process updating a subscription to the Master Control Program Daemon (mcpd).
  • <address> is a pointer address for the filter class.

For example:

01070413:5: Updated existing subscriber tmrouted with new filter class 8004000.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • A system process changes the set of configuration objects for which it requires information and is resubscribing to mcpd.

Impact

There is no impact. This error message is informational.

Recommended Actions

None
