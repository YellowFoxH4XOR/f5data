Known Issue

This is the result of a known issue. The rmeud script included in the BIG-IP 10.2.0 and 10.2.1 ISO images does not function as expected. Running the script does not remove the EUD utility and generates the following error message:

Unknown option: r

Beginning in BIG-IP 10.1.0, ISO images include a bash script named rmeud that is intended to remove the EUD utility. The script is primarily used when an upgrade to BIG-IP 10.1.0 or later fails with a disk full error message; you may be able to reclaim sufficient disk space for the installation by removing the EUD utility. For more information, refer to K10636: Upgrading to BIG-IP version 10.1.0 fails with a 'Disk full' error message.

F5 Product Development tracked this issue as ID 339226 and it was fixed in BIG-IP 10.2.2. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

If you are unable to upgrade, you can work around this issue by using the rmeud script included in the BIG-IP 10.1.0 ISO image.

Note: For more information, refer to K10636: Upgrading to BIG-IP version 10.1.0 fails with a 'Disk full' error message.

Note: If you compare the contents of the two rmeud scripts using the diff utility, you will find no differences. While the actual scripts are identical, other components present in the ISO image have changed in BIG-IP version 10.2.0; it is one of these changes that causes the rmeud script to fail.
