Description

Error when trying to generate a UCS file using TMSH.

Example:

# save sys ucs ucs_name.ucs
Saving active configuration...
Use of uninitialized value $create_sql in substitution (s///) at /usr/local/share/perl5/F5/DbUtils.pm line 498.
Use of uninitialized value $create_sql in print at /usr/local/share/perl5/F5/ConfigSync.pm line 666.
/var/local/ucs/ucs_name.ucs is saved.
 

Environment

  • TMSH
  • Attempt to generate UCS file


Cause

Unknown


???????Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Run the following command on the CLI to confirm the status of the database:

# mysql -t -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'check table PRX.REQUEST_LOG'


If the status is Ok you will see output similar to the example below:

+-----------------+-------+----------+----------+
| Table           | Op    | Msg_type | Msg_text |
+-----------------+-------+----------+----------+
| PRX.REQUEST_LOG | check | status   | OK       |
+-----------------+-------+----------+----------+

If the status does not show as 'OK', you will see errors similar to the following example:

+-----------------+-------+----------+-----------------------------------------------------------+
| Table           | Op    | Msg_type | Msg_text                                                  |
+-----------------+-------+----------+-----------------------------------------------------------+
| PRX.REQUEST_LOG | check | warning  | Table is marked as crashed                                |
| PRX.REQUEST_LOG | check | warning  | 1 client is using or hasn't closed the table properly     |
| PRX.REQUEST_LOG | check | error    | Size of indexfile is: 8883121        Should be: 8922732   |
| PRX.REQUEST_LOG | check | error    | Size of datafile is: 15771212         Should be: 15871212 |
| PRX.REQUEST_LOG | check | error    | Partition p48100001 returned error                        |
| PRX.REQUEST_LOG | check | error    | Corrupt                                                   |
+-----------------+-------+----------+-----------------------------------------------------------+

2. If status comes back OK try generating the UCS file, if not run the following command to repair the database:

# mysql -t -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'repair table PRX.REQUEST_LOG'

3. After the database has been repaired UCS file should be generated without any error message.
