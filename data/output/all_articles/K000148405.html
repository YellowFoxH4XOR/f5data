K000148405: Issue with adding members into existing pool on BIG-IP

Source

Description

After replacing the pool members in the pool on the BIG-IP, the web browser returned an "ERR_EMPTY_RESPONSE" error when trying to connect to the new pool members.

Environment

  • BIG-IP LTM
  • Pool member
  • Authentication

Cause

There is a misconfiguration on the backend server side.

Recommended Actions

Change the behavior on the backend server configuration to match the setting on the server SSL profile on the BIG-IP, as in the example below:

 

Microsoft IIS:

 

Server SSL profile:

ltm profile server-ssl /Common/test_ssl{
   alert-timeout 4294967295
   app-service none
   authenticate once
   authenticate-depth 9
   authenticate-name none
   mode enabled
   options { dont-insert-empty-fragments no-tlsv1.3 }
   partition Common
   passphrase ***scrubbed***
   peer-cert-mode ignore <<<<<==============================
   proxy-ssl disabled
   proxy-ssl-passthrough disabled
}

Additional Information

None.
