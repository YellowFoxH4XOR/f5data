Topic

The FTP profile allows configuring a non-standard data port (a port other than 20). However, if you configure an FTP profile to use a non-standard data port, both the clientside and serverside flows will use that port for the data connection. For example, if the data port is set to 2020, both the clientside and serverside flows will use port 2020 for the data connection.

Currently, the FTP profile does not allow configuring separate clientside/serverside data ports.

Configuring a separate clientside and serverside data port is a common FTP proxy configuration; however, it is not a supported configuration on the BIG-IP system. For example, it is not possible to configure the BIG-IP system as shown below:

Clientside
Client <---- FTP [port 21 (control), port 20 (data)] ----> BIG-IP

Serverside
BIG-IP <---- FTP [port 2021 (control), port 2020 (data)] ----> Pool Member

The example configuration would allow running the backend FTP server as a non-root process on high-order ports while on the clientside the FTP proxy is running the service on the default (and firewall-friendly) ports.

F5 Product Development is tracking a Request For Enhancement (RFE) to allow configuring separate clientside/serverside data ports as ID 248094 (formerly CR57051).
