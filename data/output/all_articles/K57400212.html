Description

When creating an FQDN node that starts with a number, the following error message is observed.

01070088:3: The requested object name (/Common/1.example.com) is invalid.
 

Environment

  • BIG-IP LTM
  • FQDN Node

Cause

Object names cannot begin with a numerical value.

Recommended Actions

Create the FQDN node with the name field to begin with a letter.

  1. Log into the BIG-IP GUI
  2. Navigate to Local Traffic
  3. Navigate to Nodes
  4. Click Create
  5. In the Name field, define a name that begins with a letter
  6. in the Address field, define the address, this can begin with a numerical value.
  7. Click Finished.

Additional Information

FQDN node address can begin with a numerical value, however the object name cannot start with a numerical value. You would need to name the object something that begins with a letter, but the address, can begin with a numerical value.
