K8850: Windows Vista and Windows 7 clients cannot access a Citrix server through a Web Application Tunnel

Topic

FirePass does not support Citrix access through a Web Application Tunnel for Windows Vista and Windows 7 clients. The security model deployed in Windows Vista and Windows 7 differs from previous versions of Microsoft Windows. This new security model prevents the FirePass client-side component from intercepting and forwarding Citrix ICA client traffic through the Web Application Tunnel.

If you need to support Windows Vista and Windows 7 clients, you can configure a Portal Access favorite for access to the Citrix server web interface. For more information, refer to the Deploying Citrix Presentation Server (MetaFrame) with the FirePass Controller Deployment Guide.

For more information about Citrix access through FirePass Portal Access, refer to K8644: Overview of Citrix access through Portal Access.
