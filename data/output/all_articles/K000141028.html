Description

Power BI web application may not work properly when deployed with Portal Access.
There are at least two known limitations which can be identified via specific web developer tools console errors.

First error:

cache-fm-Modern.js:1494 Uncaught TypeError: Cannot read properties of undefined (reading 'document') and this need to be handled.
at get_ (cache-fm-Modern.js:1494:187)
at get_frameElement (cache-fm-Modern.js:1496:8)
at F5_st (cache-fm-Modern.js:1497:9)
at F5_st_set (cache-fm-Modern.js:2234:1387)
at cache-fm-Modern.js:2236:35

Second error:

Uncaught DOMException: DOMException: Failed to read the 'localStorage' property from 'Window': The document is sandboxed and lacks the 'allow-same-origin' flag.
    at F5_st (cache-fm-Modern.js:7:124)
    at F5_st_set (cache-fm-Modern.js:2233:1387)
    at cache-fm-Modern.js:2235:35

Environment

  • Power BI Application
  • Portal Access

Cause

  • First error is due to ID 1617037
  • Second error is due to ID 840257

Recommended Actions

  • For bug ID 1617037, you can use a custom cache-fm-Modern.js which you can download here: cache-fm-Modern_bugID1617037.txt

Note: the fix for bug ID 1552685 mentioned in K000138771 is included in this custom cache-fm-Modern file.

  • For bug ID 840257, an iRule solution can be used if you know in which file the faulty code should be fixed.

Example of iRule:

# START
when HTTP_REQUEST {
  if { [HTTP::has_responded] } { return }
  if { [HTTP::path] ends_with "replacethisfilename.js" } {
     HTTP::header remove "Accept-Encoding"
     if { [HTTP::version] eq "1.1" } {
        if { [HTTP::header is_keepalive] } {
           HTTP::header replace "Connection" "Keep-Alive"
        }
        HTTP::version "1.0"
     }
     set sandbox 1
  }
}
when HTTP_RESPONSE {
  if { [info exists sandbox] } {
     if { [HTTP::header exists "Content-Length"] and [HTTP::header "Content-Length"] <= 6291456 and [HTTP::header "Content-Length"] != 0} {
        HTTP::collect [HTTP::header Content-Length]
     } else {
        HTTP::collect 6291456 ;# 6MB
     }
  }
}
when HTTP_RESPONSE_DATA {
  if { [info exists sandbox] } {
     unset sandbox
     set str_sandbox { sandbox="allow-scripts"}
     set strt_sandbox [string first $str_sandbox [HTTP::payload]]
     if { $strt_sandbox > 0 } {
        HTTP::payload replace $strt_sandbox [string length $str_sandbox] { sandbox="allow-same-origin allow-scripts"}
     }
     HTTP::release
  }
}
# END

Note: Make sure you change replacethisfilename.js referenced in the above iRule with the JavaScript filename containing the sandbox code to change. If you don't know it then it is recommended to open an SR with F5 support.
