Description

After logging in, a session cookie sent by the backend web server is not sent by the browser in subsequent requests. This results in a failed or 404 response.

Environment

  • HTTP
  • Session cookie

Cause

Cookie is set with wrong domain.

In the below example, the Host of the HTTP request is www.ltm1-example.com, and the domain set in the cookie from the HTTP response is .example.com

Host: www.ltm1-example.com
Set-Cookie: AuthCookie=A0jgtze2aTAQ8FbulwRvABQXoaORtaqdXvTvCBCAxFbIQATQ43rD1xRofBxrczUspSulool=; domain=.example.com; path=/\r\n

In this case, an acceptable domain would be:

Set-Cookie: AuthCookie=A0jgtze2aTAQ8FbulwRvABQXoaORtaqdXvTvCBCAxFbIQATQ43rD1xRofBxrczUspSulool=; domain=.ltm1-example.com; path=/\r\n

Recommended Actions

Reconfigure the backend web server to use the correct domain.

Alternatively, an iRule may be used to rewrite the cookie's domain in the HTTP response.
