K000161666: IPsec VPN Tunnel Instability Between F5 Distributed Cloud CE and Cisco ASA via External Connector

Type
Support Solution
Published
2026-06-10
Updated
2026-06-12
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud WAF
Source
https://my.f5.com/manage/s/article/K000161666

Description

IPsec VPN tunnel between F5 Distributed Cloud Customer Edge (CE) deployed on GCP and Cisco ASA firewall fails to stay up when F5 is initiator, with tunnel flapping every ~9 seconds. When Cisco ASA is initiator, tunnel is stable but no traffic flows due to narrowed traffic selectors. Relevant log messages include "IKEv2-PROTO-2: (1288): A supplied parameter is incorrect" and repeated tunnel resets.

Environment

  • Product: F5 Distributed Cloud
  • Feature: Multi-Cloud Network Connect, External Connector (IPsec VPN)
  • CE Deployment: GCP
  • Remote Peer: Cisco ASA firewall
  • VPN Mode: Route-based VPN (VTI interface), IKEv2 with AES-GCM, NAT-T enabled
  • Authentication: Pre-Shared Key (PSK)
  • IKE Proposals: AES-GCM-256, PRF SHA-512, DH Group 21 (ECP_521)
  • ESP Proposals: AES-GCM-256
  • NAT-T: Enabled (UDP 4500)
  • MOBIKE: Advertised as supported by Cisco ASA during IKE_AUTH

Cause

  • Cisco ASA bug (CSCvh14743) in version 9.9 causes tunnel flap due to improper handling of MOBIKE INFORMATIONAL messages with NAT detection payload.
  • When Cisco ASA acts as initiator, it proposes a /32 host route as the local traffic selector, resulting in narrowed selectors and no traffic flow.
  • Traffic selector narrowing is a display issue on F5 CE; actual routing depends on BGP/static routes.

Answer/Recommended Actions

  • Upgrade Cisco ASA to version with fix for MOBIKE compatibility (9.12(1) or later).
  • As interim workaround, configure Cisco ASA as tunnel initiator to achieve tunnel stability, then address traffic flow issue.
  • On Cisco ASA, ensure traffic selector is any-to-any (0.0.0.0/0), not a /32 host route/.
  • Review and correct ASA routing table to remove or adjust any /32 host routes.
  • Configure routing (BGP or static routes) on both sides to direct traffic through the tunnel interface.
  • Verify required protocols and ports are permitted: UDP 500 (IKE), UDP 4500 (NAT-T), IP Protocol 50 (ESP), IP Protocol 51 (AH).

Additional Information

  • Traffic selector display on F5 CE is informational only; actual traffic forwarding is determined by routing.
  • MOBIKE on F5 Distributed Cloud CE cannot be disabled globally.
  • Policy-based VPN is not supported with F5 Distributed Cloud External Connectors; only route-based VPN (VTI) is supported.
  • Lab validation confirmed tunnel stability and successful traffic flow with Cisco ASA version 9.24.
