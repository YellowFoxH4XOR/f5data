K000163470: FQDN Node Resolution Does Not Use DNS Resolver Forward Zones

Type
Support Solution
Published
2026-09-30
Updated
2026-09-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163470

Description

For BIG-IP LTM FQDN nodes, DNS resolution is handled by the dynconfd daemon. dynconfd queries only the DNS servers configured under System > Configuration > Device > DNS.

It does not use the DNS Resolver list or its configured forward zones to resolve FQDN nodes.

Environment

  • BIG-IP LTM
  • DNS servers configured under System > Configuration > Device > DNS
  • A separate DNS Resolver list with a forward zone configured under Network > DNS Resolvers > DNS Resolver List

Cause

The DNS Resolver and device-level DNS resolution are independent mechanisms.

Recommended Actions

Configure the DNS servers under System > Configuration > Device > DNS so they can resolve the FQDN used by the LTM node.

Do not rely on the DNS Resolver list or its forward zones for FQDN node resolution.

Additional Information

The BIG-IP DNS Resolver is an independent mechanism used by specific BIG-IP features and modules, including:

  • BIG-IP HTTP Explicit Proxy
  • BIG-IP APM
  • BIG-IP AFM
  • BIG-IP ASM Bot Defense

Configuring a DNS Resolver forward zone is therefore not required for dynconfd-based resolution of BIG-IP LTM FQDN nodes.
