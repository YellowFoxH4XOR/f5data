Issue

You should consider using this procedure under the following conditions:

  • Your BIG-IP APM system is configured with a Network Access resource.
  • The SNAT Pool setting for the Network Access resource is set to None.
  • Network Access clients are unable to access internal networks when connecting to the BIG-IP APM Network Access resource.

Symptoms

As a result of the SNAT Pool setting being set to None, you may encounter the following symptoms:

  • Network Access clients are unable to access internal networks when connecting to the BIG-IP APM Network Access resource.
  • tcpdump indicates that traffic from the Network Access client, such as Internet Control Message Protocol (ICMP) packets or TCP SYN requests, is not being replied to through the BIG-IP APM system.

Recommended Actions

When your environment requires you to set the SNAT Pool setting to None in order to preserve the source IP address of the network access client on the local network, you must ensure the devices on your internal network are configured with the appropriate routes for the IP addresses used for the Network Access lease pool.

Alternatively, if your environment does not require that the source IP address of the Network Access client to be preserved, you can enable the SNAT Pool feature for the Network Access resource by performing the following procedure:

Configuring a SNAT Pool for a Network Access resource

Impact of procedure: You can't use the affected Network Access resource for Proxy Address Resolution Protocol (ARP), Common Internet File System (CIFS)/Server Message Block (SMB), or VoIP protocols because the Network Access client is translated and not preserved.

Note: The default value for the SNAT Pool setting is Automap. However, you must click None in the SNAT Pool list when you enable the Proxy ARP feature and when you set Preserve Source Port Strict to All. You must also click None when you need to support CIFS/SMB or VoIP protocols with this network resource.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Connectivity / VPN > Network Access (VPN) > Network Access Lists.

    Note: For BIG-IP 11.x - 12.x, navigate to Access Policy > Network Access > Network Access Lists.

  3. Click the Network Access profile.
  4. Click the Network Settings tab.
  5. Under General Settings, click Automap in the SNAT Pool list or click an existing SNAT Pool name.
  6. Click Update.
