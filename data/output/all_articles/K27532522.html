Description

  • You have an Exchange server receiving SMTP traffic. This works correctly.
  • When you insert a Virtual Server to load balance SMTP traffic there are retransmits and timeouts. Mail is delayed.

Environment

  1. A Virtual server deployed for SMTP, possibly through using an iApp.

Cause

  • The Virtual Server is using Snat AutoMap Address translation.
  • The concentrates the traffic to the Exchange server to that one address resulting in this error returned by Exchange.
421 4.3.2 The maximum number of concurrent server connections has exceeded a per-source limit, closing transmission channel



 

Recommended Actions

  • Reconfigure the Exchange Server. (Receive Connector,  MaxInboundConnectionPerSource )
  • Replacing Snat AutoMap with a Snat Pool may help, however the ordering of the Snat addresses is not defined. Thus this may be of limited utility.
