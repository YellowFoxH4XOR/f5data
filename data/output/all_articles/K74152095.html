Published
2023-04-06

2025-02-07
Applies to

Source

Description

Below messages are filling up the log files restjavad.*.log, almost one message every two seconds:

==> /var/log/restjavad.0.log <==
[WARNING]<PID>[RestOperationIdentifier] Failed to validate Authentication failed.
[WARNING]<PID>[RestOperationIdentifier] Failed to validate Authentication failed.
[WARNING]<PID>[RestOperationIdentifier] Failed to validate Authentication failed.

Environment

  • iSeries platforms
  • v15.1.2.1

Cause

Known issue: Bug ID 970829: iSeries LCD incorrectly displays secure mode

There's a single line in each of the restjavad.0.log and restjavad-audit.0.log and touchscreen_lcd:
==> /var/log/restjavad.0.log <==
[WARNING]<PID>[RestOperationIdentifier] Failed to validate Authentication failed.

==> /var/log/restjavad-audit.0.log <==
[I]<PID>[ForwarderPassThroughWorker] {"user":"local/null","method":"GET","uri":"http://localhost:8100/mgmt/tm/sys/alert/lcd","status":401,"from":"IP_address"}

==> /var/log/touchscreen_lcd <==
IP_address err lcdui<PID>: URL: http://IP_address/mgmt/tm/sys/alert/lcd, result: 'Host requires authentication' (204), HTTP method 2, status 401

Recommended Actions

If you require an EHF, contact F5 support to acquire the EHF.  To determine if the issue is resolved, refer to the Fixed In versions of the related BugID 970829.
