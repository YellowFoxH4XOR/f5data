Description

  • Configuration fails to load after upgrade to v14.1.x from v13.x or earlier
  • Following error messages similar to the following appear in /var/log/ltm:
    err mcpd[PID]: 01070920:3: Application error for confpp: AH00526: Syntax error on line 199 of /var/run/config/httpd.conf:
    err tmsh[PID]: 01420006:3: Loading configuration process failed.
    emerg load_config_files[PID]: "/usr/bin/tmsh -n -g -a load sys config partitions all base " - failed. -- Loading schema version: 13.1.2
    err mcpd[PID]: 01070422:3: Base configuration load failed.
    • PID is the daemon's Process ID

Environment

  • BIG-IP upgraded to v14.1.0 or later from v13.x or earlier

Cause

Non-IP address information is present in the HTTPD Allow list

Recommended Actions

Modify the HTTPD Allow list in the bigip_base.conf file:
  1. Access BIG-IP Bash prompt
  2. Open the bigip_base.conf file in a text editor:

    nano bigip_base.conf

  3. Locate the HTTPD Allow list.  It should appear similar to the following:

    sys httpd {
        allow { 192.0.2.0/255.255.255.0 and 198.51.100.0/255.255.255.224 or 203.0.113.245, localhost }
        ...
    }

  4. Remove all occurrences of and, or, "," and localhost from the Allow list
  5. Save the changes made to bigip_base.conf
  6. Exit the text editor
  7. Attempt to load the configuration:

    tmsh load sys config partitions all

Additional Information

Only IP address and Subnet information is permitted in the HTTPD Allow list.  all is also permitted in the HTTPD Allow list.  Any other information will cause an error and prevent the configuration loading.
