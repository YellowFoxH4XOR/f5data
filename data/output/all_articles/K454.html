Topic

You can restrict access to a BIG-IP virtual server by configuring IP filters. IP filters examine each IP packet entering a network interface and apply a set of rules. You can configure an IP filter to examine the source IP address, destination IP address, source port, or destination port.

To create an IP filter that limits access to a virtual server, perform the following steps:

  1. Log in to the Configuration utility.
  2. In the main navigation pane, select IP Filters.
  3. In the Name field, enter a descriptive name for the IP filter.
  4. In the Type menu box, select one of the following filter types:
    • Accept Packet—If the IP filter matches, BIG-IP accepts the packet.
    • Deny Packet—If the IP filter matches, BIG-IP drops the packet.
  5. In the Source IP Address field, enter IP addresses that the IP filter should act on.

    You can enter multiple IP addresses or entire subnetworks, separating each entry with a semicolon.

    For example, 192.38.48.24;www.siteone.com;14.34.53/24 is valid.

    If you leave this field blank, the filter affects all source IP addresses.

    Note: F5 Networks does not recommend using hostnames. If the name cannot be successfully resolved, it is considered a compilation error. You must set up name resolution on the BIG-IP for this to work correctly.

  6. In the Source Service field, enter source ports that the IP filter should act on.

    If you leave this field blank, this filter affects all source services.

  7. In the Destination IP Address field, enter the IP address of the virtual server to which you want to restrict access.
  8. In the Destination Service field, enter the port used by the virtual server to which you want to restrict access.
  9. Click the Done button.
