Topic

Power LED indicators

Each of the three Power LED indicators represents one of the three possible power supplies.

Note: Most FirePass 4100 Controllers are equipped with only one power supply.

LED behaviorDescription
Solid GreenThe power supply has power and working properly.
Solid OrangeThe power supply has power, but is not working properly.
Off (none)The power supply has no power or is not installed.


Status LED indicator

This indicator is not used by FirePass. The condition of the indicator does not provide any information about system status.

Activity LED indicator

This indicator shows activity on the interfaces between the FirePass network interfaces and the main system board.

LED behaviorDescription
Intermittent YellowNetwork activity between the switch interfaces and the main system board.


Alarm LED indicator

This indicator is not used by FirePass. The condition of the indicator does not provide any information about system status.
