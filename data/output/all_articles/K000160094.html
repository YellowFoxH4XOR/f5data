K000160094: BIG-IQ Data Collection Device DCD: LDAP authentication is not working

Description

BIG-IQ Data Collection Device (DCD) CLI LDAP authentication fails when logging in via SSH.

Logs show LDAP/PAM errors such as:

  • pam_ldap(sshd:auth): error reading from nslcd: Connection reset by peer

  • error: PAM: Authentication failure for <username> from <x.x.x.x>

Environment

  • BIG-IQ Data Collection Device (DCD)
  • LDAP/Active Directory configured for system authentication via tmsh

Cause

LDAP referral chasing was disabled (referrals no) in the BIG-IQ DCD LDAP system-auth configuration, but the directory environment required referrals for successful authentication.

Recommended Actions

  1. Verify the current LDAP system-auth settings:
    tmsh list auth ldap /Common/system-auth
  2. Enable LDAP referrals:
    tmsh modify auth ldap /Common/system-auth referrals yes
  3. Save the configuration:
    tmsh save sys config
  4. Re-test LDAP authentication by logging in via SSH using an LDAP user account.
