Topic

In BIG-IP SAM and BIG-IP APM Visual Policy Editor, you can configure custom rules using Tcl expressions. For example, you can configure a rule that checks the time of day or the day of the week, and then configure different actions or endings based on the result.

Note: For more information about the Tcl programming language, refer to the following website. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://www.tcl.tk

The following procedure configures an action with a rule to check the time of day and the day of the week. If the day of the week is Monday through Friday, and the time of day is between the hours of 8 a.m. to 5 p.m., the user is allowed access to the resource. If the day of the week is Saturday or Sunday, or the time of day is outside the hours of 8 a.m. to 5 p.m, the user is denied access to the resource. 

Note: This procedure assumes that you have already configured an access policy with at least one Resource Assign action.

  1. Log in to the BIG-IP Configuration utility.
  2. From the Main tab of the Configuration utility, click Access Control.
  3. Click Access Profiles.
  4. Click the name of the access profile you want to configure.
  5. Click the Access Policy tab.
  6. Click the Edit Access Policy for Profile "<AccessProfileName>" link, where <AccessProfileName> is the name of your access profile.

    The Visual Policy Editor launches in a separate browser window.
  7. To the left of the Resource Assign action you want to restrict, click the plus ( + ) sign.

    Note: This procedure inserts the custom time and date check action immediately prior to the Resource Assign action. In your Access Policy, you may want to insert the time and date check action at different point in the Access Policy. For example, immediately prior to the Logon Page action.
     
  8. Select the Empty option button to select an empty action.
  9. Click the Add Item button.

    The action builder appears.
  10. In the Name field, enter a name for the action.

    For example:

    Check_Day_and_Time
  11. Click the Rules tab.

    Note: For BIG-IP APM, click on the Branch Rules tab.
  12. Click the Add Rule button.

    Note: For BIG-IP APM, click the Add Branch Rule button.
  13. In the Name field, enter a name for the rule.

    For example:

    Deny_Sat_and_Sun
  14. Next to Expression, click the change link.

    The expression builder appears.
  15. Click the Advanced tab.
  16. In the text field, enter the Tcl expression. Using our example to deny access on Saturdays and Sundays, you would enter the following:

    set time [clock format [clock seconds]];
    set access 0;
    if { $time contains "Sun" || $time contains "Sat" } {
         set access 1;
    };
    return $access;
  17. Click the Finished button.
  18. Click the Add Rule button.
  19. In the Name field, enter a name for the rule.

    For example:

    Deny_Nonbusiness_Hours
  20. Next to Expression, click the change link.

    The expression builder appears.
  21. Click the Advanced tab.
  22. In the text field, enter the Tcl expression. Using our example to allow access between 8:00 a.m. and 5:00 p.m, you would enter the following:

    set hour [clock format [clock seconds] -format %H]
    set access 1;
    if { $hour >= 8 && $hour < 17 } {
         set access 0;
    };
    return $access;
  23. Click the Finished button.
  24. Click the Save button to save the action.

    The action appears in your Access Policy, similar to the following example:

     
     
  25. In the top left corner of the page, click the Activate Access Policy link.
