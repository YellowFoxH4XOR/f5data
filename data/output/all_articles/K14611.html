Known Issue

Using the BIG-IP Configuration utility to delete a wide IP may result in an error message.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is licensed and provisioned with the Link Controller module.
  • You use the BIG-IP Configuration utility to attempt to delete a wide IP using the Link Controller > Inbound Wide IPs > Wide IP List menu item.

Impact

Users cannot use the BIG-IP Configuration utility to delete the wide IP.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H426588 on the Diagnostics > Identified > Medium screen.
  • When you use the BIG-IP Configuration utility to attempt to delete a wide IP, you may observe the following error message, where <Wide-IP-Name> is the affected wide IP object name:

    0107070b:7: Wideip pool (/Common/<Wide-IP-Name>) is referenced by one or more wideips

  • You cannot delete the affected wide IP.

Workaround

To work around this issue, you can use the Traffic Management Shell utility (tmsh) to delete the wide IP. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Delete the wide IP using the following command syntax:

    delete /gtm wideip <Wide-IP-Name>

    For example, to delete the wide IP mywip.lab1.local, type the following command:

    delete /gtm wideip mywip.lab1.local

  3. Delete the wide IP resource pool, using the following command syntax:

    delete /gtm pool <Wide-IP-Pool-Name>

    For example, to delete the wide IP resource pool mywip.lab1.local, type the following command:

    delete /gtm pool mywip.lab1.local

  4. To save the changes, type the following command:

    save /sys config

  5. To exit the tmsh utility, type quit and press Enter.
