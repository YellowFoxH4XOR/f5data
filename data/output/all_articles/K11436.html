Known Issue

This is the result of a known issue. When the show nsck command is run, if there is not a namespace configured, the command will fail with a record read error message that appears similar to the following example:

% ERROR: OM_RECORD_READ_FAILED (40239104): A record read from the configuration database failed. Record result code [keyNotFound [3]] Record name [DNASNamespace] Debug string [id=1]

This error message does not indicate a database failure; however, users may erroneously interpret the error message as a database failure. When a namespace is not configured, the show nsck command should clearly indicate that no namespace is configured.

F5 Product Development is tracking this issue as ARX ID 36717.

Note: For information about the nsck metadata utility, refer to the Metadata Utilities section of the ARX CLI Maintenance Guide.
