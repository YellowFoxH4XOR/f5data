Description

  • You implemented offline installation of NGINX Agent
  • You configured NGINX Agent on managed NGINX Plus instance. 
  • However, the status of the Agent service remains "activating" even after several restart and waiting several minutes, it won't turn "Active" 
  • Running command "sudo systemctl status nginx-agent.service", you findthe below output and error message  
                          sudo systemctl status nginx-agent.service
                          ● nginx-agent.service - NGINX Agent
                                 Loaded: loaded (/etc/systemd/system/nginx-agent.service; enabled; vendor preset: enabled)
                                 Active: activating (auto-restart) (Result: exit-code) since Wed 2024-09-04 17:07:43 BST; 1 month 21 days ago
                                   Docs: https://github.com/nginx/agent#readme
                                Process: 1914144 ExecStartPre=/bin/mkdir -P /var/run/nginx-agent (code=exited, status=0/SUCCESS)
                                Process: 1914145 ExecStartPre=/bin/mkdir -P /var/run/nginx-agent (code=exited, status=0/SUCCESS)                                
                                Process: 1914147 ExecStartPre=/usr/bin/nginx-agent (code=exited, status=1/FAILURE)                                
                               Main PID: 1914147 (code=exited, status=1/FAILURE)

Environment

  • NGINX Instance Manager
  • NGINX Agent

Cause

  • The Agent's post install script is unable to create /var/run/nginx-agent

Recommended Actions

  • Delete existing symlink from the same directory the post script trying to create it ( ls -l /var/run/nginx-agent )

Additional Information

  • The Agent's post install script creates a directory "/var/run/nginx-agent", but when it fails to do so, the Agent's status remains "activating",   when there is an already existing symlink
  • You can verify the existence of the same file using command "ls"
                      ls -l /var/run/nginx-agent
                               total 0
                               srw------- 1 root nginx-agent 0 Sep 21 12:12 nginx.sock
