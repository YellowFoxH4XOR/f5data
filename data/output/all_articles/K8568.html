Known Issue

This is the result of a known issue. You can use the Statistics page in the Configuration utility to display persistence records on the BIG-IP system. When the persistence table contains more than 10800 persistence records, and you attempt to display the persistence entries using the Statistics page, the Configuration utility displays an error message.

For BIG-IP 9.x, the error message appears similar to the following example:

General Database Error Retrieving Information

For BIG-IP 10.x, the error message appears similar to the following example:

Too many records to display. Please choose a filter and/or enter search criteria.

F5 Product Development is tracking this issue as CR65405.

Workaround

You can work around this issue in BIG-IP LTM 9.4 and later by using the bigpipe persist show command.

Note: In BIG-IP 9.0 through 9.3.x, the bigpipe persist command does not display more than 10800 persistence entries. For more information, refer to K8473: The bigpipe persist command does not display more than 10800 persistence entries.
