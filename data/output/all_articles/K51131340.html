Issue

Old Behavior

In versions prior to BIG-IP 13.1.0, Secure Sockets Layer (SSL) settings such as Cipher List and Client Certificate are configured directly within an HTTPS monitor.

New Behavior

Beginning in BIG-IP 13.1.0, when you create a custom HTTPS monitor, you specify the SSL settings by configuring the HTTPS monitor to use a Server SSL profile. You configure SSL settings, such as Cipher List and Client Certificate, in the Server SSL profile object.

Note: The BIG-IP system uses bigd process to perform monitoring functions by default. However, BIG-IP 13.1.0 also introduced the option of configuring the Traffic Management Microkernel (TMM) process to perform monitoring. For information about In-TMM monitoring, refer to K11323537: Configuring In-TMM monitoring.

Impact

When you upgrade a BIG-IP system to BIG-IP 13.1.0 or later and roll forward a configuration that contains an HTTPS monitor configured with SSL options, the configured SSL options are converted and saved in a new custom Server SSL profile named <HTTPS_monitor_name>_ssl_profile. Additionally, the new HTTPS monitor is configured to use the new custom Server SSL profile. For example, if the previous, earlier BIG-IP version has an HTTPS monitor named example_https_monitor, the configuration has a new Server SSL profile named example_https_monitor_ssl_profile. This new Server SSL profile is visible with any other configured Server SSL profiles by navigating in the Configuration utility to Local Traffic > Profiles > SSL > Server.

Note: For HTTPS monitors configured with identical SSL options, a single Server SSL profile is created for all HTTPS monitors that use same SSL options.
This enhancement was introduced from BUG ID 659399. The name chosen for each ssl-profile will stem from the first ltm monitor https in the list.

As a result of this change in behavior, the system uses the cipher, certificate, and key settings that are configured within the SSL Profile associated with your monitor for SSL handshake communication.  The monitors no longer make use of the cipherlist configuration and this option is no longer visible under the monitor's Advanced Configuration section in the Configuration utility.  Even if you try to configure it by modifying the configuration file (/config/bigip.conf) or try to modify it using the TMOS shell (tmsh), a warning alerts you:

For example:

root@(LTM1)(cfg-sync Standalone)(/Common)(tmos)# modify ltm monitor https test_https_monitor cipherlist 'DEFAULT'
[api-status-warning] ltm/monitor/https, properties : deprecated : cipherlist

Recommended Actions

None
