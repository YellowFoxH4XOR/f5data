K12320674: Synchronization of SNMP configuration between Primary and Secondary BIGIQ is not working

Type
Support Solution
Published
2020-06-22
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 5.X.X
Source
https://my.f5.com/manage/s/article/K12320674

Description

Synchronization of SNMP configuration between Primary and Secondary BIGIQ is not working. Secondary Device configuration is read-only and does not show SNMP config in SNMP Configuration. SNMP configuration was done only on primary device before creating cluster

Environment

  • BIG-IQ Centralized Management 5.4 cluster
  • SNMP Configuration done from GUI ( >System>This-device>SNMP Configuration)
  • SNMP Configuration done on Primary box not done on Secondary
     

Cause

Configuration of SNMP Configuration is not synchronized

Recommended Actions

  • Configure SNMP via TMSH on Secondary Device:
    example:
    modify sys snmp allowed-addresses add { 10.0.0.1/255.255.255.255}
or
  1. Promote Secondary as Primary device in System > BIG-IQ HA > Settings
  2. Configure SNMP in >System>This-device>SNMP Configuration
  3. Promote Secondary to Primary (previously Primary)

Additional Information
None
