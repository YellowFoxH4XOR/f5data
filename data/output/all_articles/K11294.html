Known Issue

This is the result of a known issue. When the Inject ActiveX/Plugin to clean-up client browser web cache and the Require cache cleanup ActiveX/Plugin to be loaded to allow attachment downloads in Mobile E-Mail and downloads via Web Applications check boxes are selected, Linux and Mac clients will receive the following message when trying to download files from any portal favorite configured on the FirePass controller:

Security exception: Non-HTML data has been blocked for security reasons

Note: For more information about cache cleanup features see K2981: Overview of cache cleanup features.

F5 Product Development tracked this issue as CR135287 and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by clearing the Inject ActiveX/Plugin to cleanup client browser web cache check box on the Users : Endpoint Security : Post-Logon Actions screen.
