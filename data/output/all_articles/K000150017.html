Description

In some cases, when configuring ipfix publisher and log profile, we see errors when iRule tries to send messages to the configured profile in ltm logs.
/var/log/ltm:

TCL error: /Common/<IRULE NAME> <CLIENT_ACCEPTED> - Publisher unavailable: "/Common/ipfix_log_pub". (line 4) invoked from within "IPFIX::destination open -publisher /Common/ipfix_log_pub"

The first thing we need to verify in this situation is that the iRule is referencing correct ipfix log publisher name with valid partition path. If the path is valid and still we encounter this error, then try MCPD forceload by following F5 knowledge article K13030 

 

Environment

  • BIG-IP LTM
  • IPFIX logging profile

Cause

iRule code will accept ipfix logging profile without verifying its existing and if the name is invalid it will throw these TCL errors when running.

Recommended Actions

Always double check the ipfix log profile is valid when associating it with iRules.
