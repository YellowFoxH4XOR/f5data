Description

I need information on how to create blindfolded string for the key to use API. This is useful when using API to upload certificates.

Environment

  • F5® Distributed Cloud (XC)
  • XC console
  • vesctl
  • XC API
  • "private_key":{"blindfold_secret_info":{"location":"string:///'xxx'"}}

Cause

  • None

Answer/Recommended Actions

Following steps are based on available documentation. Please, use the article Blindfold your TLS Certificates for details of each steps.

 

Prepare:

  1. Download vesctl from our vesctl repository on your local machine as it is used to apply Blindfold to the TLS certificate. 
  2. Create a Secret Policy in XC Console.
    Note: You can also use the inbuilt ves-io-allow-volterra policy.
  3. Create an API Certificate - generate certificate in XC Console.
  4. Create config file .vesconfig – use this documentation for details how to create .vesconfig

 

Commands:

  1. Set the environment for P12 password (This is the password you set during API certificate generation in XC Console). 
        export VES_P12_PASSWORD=<p12 password>  
  2. Obtain a public-key using vesctl and store the output to a file.   
             vesctl request secrets get-public-key > demo-api-pubkey 
  3. Obtain a policy-document using vesctl and store the output to a file.
    vesctl request secrets get-policy-document --namespace shared --name ves-io-allow-volterra > demo-api-policy
    (if you get an error, verify the variable 'echo $VES_P12_PASSWORD' if you see the password, if not, set the value again)

  4. Encrypt TLS Key using vesctl and Blindfold.
    vesctl request secrets encrypt --policy-document demo-api-policy --public-key demo-api-pubkey key.pem  > bl-enckey
    Note    : Provide the public key and policy document obtained in step 6 and 7. The key.pem is the TLS key to be encrypted, it is your private key of the certificate to be uploaded.

  5. Blinefolded file 'bl-enckey' contains "Encrypted Secret" line which needs to be removed.
    Remove Encrypted Secret line: Encrypted Secret (Base64 encoded):  
    tail -1 bl-enckey > bl-enckey.blindfold

    After you removed the line form the file: ‘Encrypted Secret (Base64 encoded):’, your 'bl-enckey.blindfold'  is ready to use for the API. 

  6. Now you can use the blindfolded key 'bl-enckey.blindfold' for commands following API documentation to create/replace certificate, for example:
    "private_key":{"blindfold_secret_info":{"location":"string:///'$(cat bl-enckey.blindfold)'"}}
