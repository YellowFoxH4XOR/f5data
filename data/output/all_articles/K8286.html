F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.1.3. F5 recommends that all customers currently running version 9.1.3 install Hotfix-BIG-IP-9.1.3-HF1, or a later version of the cumulative hotfix rollup, as soon as possible.

The following CRs are fixed in HF1 for BIG-IP 9.1.3:

 
CR NumberArticle NumberTitle
CR51599K8277Compression does not work for Internet Explorer 7 when browser workarounds are enabled
CR81826K8068The eventd process may cause memory consumption issues
CR85134K8278iControl portal (through EasySoap) can consume excessive amounts of memory
CR87184K8058The BIG-IP system marks an unsupported internal interface on 1500 platforms as up
CR88223K8282Failed SSL connections using compat ciphers can effect other SSL connections
CR89149K8285An RST packet is sent with an incorrect ACK value when a TCP SYN packet is received for a service that does not exist
 


The hotfix is available for download at the F5 Downloads site. For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about installing a hotfix, refer to K6845: Managing F5 product hotfixes .

For information about F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For a list of the latest hotfixes for each BIG-IP software branch, refer to K9502: BIG-IP hotfix matrix .
