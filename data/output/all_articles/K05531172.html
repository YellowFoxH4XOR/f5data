Topic

This article applies to VELOS systems (chassis). For information about resetting the configuration for a VELOS partition, refer to the following article:

  • K000149614: Reset the configuration of a VELOS partition to factory default settings

For information about resetting the configuration for other F5 systems, refer to the list of articles in the Related Content section at the end of this article.

You should consider using this procedure under the following condition:

  • You want to restore the VELOS system configuration to factory default settings.

Description

You can restore the configuration of the VELOS system to the factory default settings using the system database reset-to-default command. When you run the system database reset-to-default command, you change the reset-default-config flag to true, which loads the default configuration into the running database.

Restoring the default configuration on the VELOS system removes all partitions except the default partition. When the default configuration loads, all chassis blades are assigned to the default partition and the current configuration is removed including the license, network settings, and the management IP addresses.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the VELOS system controller command-line interface (CLI).

Procedures

Restore the VELOS default settings

Before you reset the VELOS system to the default configuration settings, you should back up your current configuration and export the configuration to a remote host. For more information about backing up and exporting the configuration, refer to K50135154: Backing up and restoring F5OS configuration on a VELOS system.

To restore the VELOS system to the default configuration settings, perform the following procedure:

Impact of procedure: Performing the following procedure removes the current configuration from the VELOS system and loads the default configuration.

  1. Log in to the active VELOS system controller CLI as the admin user.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Reset the system to the default settings by entering the following command:

    system database reset-to-default

    The system prompts you to select either yes or no. Setting the reset-default-config flag to true instructs the system to boot to the default settings:

    Removing all user configuration will delete partitions and stop traffic processing. [no,yes] 

  4. Confirm you want the system to load the default settings by entering the following command:

    yes

  5. Commit the change by entering the following command:

    commit

    If you attempt to exit the configuration mode terminal before committing the change, the system presents the following prompt:

    Uncommitted changes found, commit them? [yes/no/CANCEL]

    Selecting yes commits the change and exits the mode. Selecting no aborts the change and exits the mode. If you select CANCEL, the system reverts to the state before attempting to exit the mode.
