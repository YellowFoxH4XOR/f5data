Known Issue

The Configuration utility may stop responding when using the ZoneRunner utility to search for DNS resource records.

This issue occurs when the following condition is met:

  • You search for DNS Resource Records using the ZoneRunner utility. For example, you go to DNS > Zones > ZoneRunner and select Search.

Impact

The Configuration utility stops responding.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Configuration utility stops responding.
  • Apache generates a stack trace and core file.
  • The BIG-IP system generates an error message to the httpd.error log that appears similar to the following example:

    httpd[31072]: [mpm_prefork:error] [pid 31072] AH00161: server reached MaxRequestWorkers setting, consider raising the MaxRequestWorkers setting

Note: This issue differs from the one described in K000139831 which has the same symptoms, but was caused by a different reason.

Workaround

To work around this issue, you can use the BIG-IP DNS command line to view resource records in a zone. To do so, refer to K81024031: Displaying all resource records in a zone from the BIG-IP DNS command line.
