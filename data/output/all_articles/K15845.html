Known Issue

The BIG-IP system fails to disable a Server SSL profile on a virtual server when using a local traffic policy action.

This issue occurs when all of the following conditions are met:

  • You have a virtual server with an associated Server SSL profile.
  • You are using the server-ssl disable local traffic policy action to disable a Server SSL profile on the virtual server.

Impact

Local traffic policies do not behave as expected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Server SSL profiles are not disabled when a policy action is triggered.
