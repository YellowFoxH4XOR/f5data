K000151086: vCMP Guest doesn't come up after expected reboot

Type
Support Solution
Published
2025-04-29
Updated
2025-05-05
Applies to
  • VIPRION Platforms
  • BIG-IP
  • VIPRION 2400
  • VIPRION B2250 Blade
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000151086

Description

vCMP Guest doesn't come up after expected reboot, and repeatedly following logs are seen in /var/log/ltm confirming that the 'chmand' in restart loop.

Apr 29 03:10:05 slot3/localhost.localdomain err chmand[xxxxx]: 012a0003:3: Bad tmm count (0).  : File ProcInfo.cpp Line 378
Apr 29 03:10:05 slot3/localhost.localdomain err chmand[xxxxx]: 012a0003:3: unexpected init failure : std::exception
Apr 29 03:10:05 slot3/localhost.localdomain crit chmand[xxxxx]: 012a0002:2: critical platform initialize failure. exiting...

Environment

  • VIPRION
  • vCMP Guest

Cause

MCPD is unable to load corrupt /config/BigDB.dat file leaving chmand in restart loop. 

Recommended Actions

There are three options to overcome the issue:

  1. Manually copy BigDB.dat file from working slot (SlotY) to the slot with error (SlotX) using scp command:
    1. For example use command 'scp /config/BigDB.dat slotX:/config/BigDB.dat'  to copy the file from slot Y to slot X., 
    2. After this the system should recover automatically,
      1. In case it doesn't solve the issue then ssh to slotX and manually restart the 'mcpd'  by command 'bigstart restart mcpd', or reboot the slot using 'reboot'.
      2. In case the error messages are still showing and vCMP guest still doesn't come up, ssh to slot X and generate log file from the slotX through command tar zcf /var/tmp/slotX.tgz /var/log/ /config/ and share with F5 Support for further investigation.
  2. If possible boot the system from a previously working boot partition. Upgrade the system to desired software version and sync the device with active device in HA.
  3. Delete the Guest and provision it again using a known working UCS. 

Additional Information

Contact F5 technical support center is further support is needed.
