Description

BIG-IQ stops showing statistics after BIG-IP upgrade to 15.1.5.1 or 14.1.5 or 16.1.3

bigip.conf does not show proper analytics config

No IP addresses of DCD nodes  under:

analytics global-settings {
    ecm-port 443
    enable-bigiq-configuration enabled
    offbox-tcp-port 443
}

LTM logs shows logs similar to :

test.local err mcpd[4989]: 01020036:3: The requested application instance (/Common/bigiq-analytics.app/bigiq-analytics) was not found.
test.local err tmsh[698]: 01420006:3: 01020036:3: The requested application instance (/Common/bigiq-analytics.app/bigiq-analytics) was not found.

After importing a BIG-IP system, an error occurs when stats collection is enabled for the device:

Statistics collection error: agentInstaller failed: java.lang.IllegalStateException: installapp on device <ip> failed: java.net.ProtocolException: status:400, body:{"code":400,"message":"INSTALL operation not allowed","referer":"<ip>","restOperationId":14044948,"kind":":resterrorresponse"}. Please try again by clicking "Save and Close," below.

Environment

  • BIG-IQ Centralized Management with Data Collection Devices
  • Stats collection enabled
  • Stats collection not working after upgrade to 15.1.5.1 / 14.1.5 / 16.1.3

Cause

Bug ID 1112777: Statistics collection error after importing a BIG-IP system and enabling stats

Recommended Actions

Enable rpm task to permit installation of BIG-IQ Analytics iApp by executing following commands in CLI (bash):

tmsh modify sys db restjavad.disablerpmtasks value false
tmsh save sys config
restart sys service restjavad

NOTE:  Changing the sys DB variable will cause any manual sync cluster groups to go out of sync.  The customer will also need to sync these cluster groups after making the change.

NOTE:  After restarting services, you may need to disable/enable statistics on the Big-IP from the Big-IQ again.
