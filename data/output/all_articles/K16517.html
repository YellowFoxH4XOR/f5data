Known Issue

The BIG-IP Server/Application State Protocol (SASP) monitor fails and produces a core file.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP SASP monitor to use Push mode.
  • The BIG-IP system receives Send Weights messages from a Group Workload Manager (GWM) server.

Impact

The SASP monitor fails and the pool member status changes to offline.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe that the system erroneously marks pool members offline.
  • You observe an SASP monitor core file in the /shared/core directory.
