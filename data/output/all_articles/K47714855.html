Description

The  Nessus scan tool requires access to the BIG-IP in order to perform scans.

Environment

  • Nessus scan tool (by Tenable)
  • Access to BIG-IP to perform Compliance auditing

Cause
The Nessus tool needs access to perform scans on the BIG-IP system 

Recommended Actions

Configure the Nessus scanner to use a BIG-IP user account that has the Auditor role.  For more information about the Auditor role or other user roles, refer to the User Roles section of the BIG-IP Systems: User Account Administration guide.

F5 recommends testing any such access or scan tools in a lab environment and/or during a maintenance window with consideration to the possible impact on your specific environment.

Important: F5 recommends you permit access to F5 products only over a secure network and restrict command line access to trusted users. For more information, refer to K13092: Overview of securing access to the BIG-IP system.
