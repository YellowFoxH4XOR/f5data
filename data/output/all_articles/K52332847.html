Description

In the /var/log/kern.log you may find similar error messages as follow:
debug kernel: : [7085703.403124] Peer 192.168.2.1:64704/24 unexpectedly shrunk window 4238065460:4238065544 (repaired)

Environment

  • BIG-IP LTM

Cause

This normally occurs when a client decides to reduce its TCP window size, without the server expecting it.
This can be the case when fragmentation is an issue, or when the client is using an embedded device with very little NIC buffer memory.
The messages are informational only, and are used to debug networking issues.
 

Recommended Actions

  • In case of few tenths messages - it is completely normal behave.
  • In case you found thousands appearances per day, please open a new Service Request.
