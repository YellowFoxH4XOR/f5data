Known Issue

Exported request reports do not contain valid source and destination IP address information.

This issue occurs when the following condition is met:

  • You exported a request list with the Binary export of all requests defined by filter option

Impact

The source and destination IP address information for reported requests is unreadable.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In an exported report, the values in the src_ip and dest_ip columns will appear garbled.
