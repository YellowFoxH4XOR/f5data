Description

You want to enable traffic capture in HTTP analytics profile (AVR module) and log the data in remote HSL.

Environment

  • AVR
  • HTTP analytics profile
  • HSL
  • LTM

Cause

None

Recommended Actions

Firstly, you need to have remote HSL configured. To do this follow Configuring Remote High-Speed Logging.

Then follow Troubleshooting Applications by Capturing Traffic on how to enable and configure traffic capture in HTTP analytics profile.

Additional Information

There shouldn't be any negative impact setting up HSL and logging data to remote syslog server. In fact it is recommended to log data into syslog servers than into BIG-IP as BIG-IP is not a logging server.

To associate virtual server in the HTTP analytics profile, you will need to attach HTTP profile to that virtual server. If not the virtual server will not be visible under the HTTP analytics profile.
