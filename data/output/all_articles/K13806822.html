Description

Using Rest API query the IPv6 virtual address, return "HTTP/1.1 404 Not Found".
For example:

curl -isku 'username:password'  https://localhost/mgmt/tm/ltm/al-address/~Common~2001:db8:1:0:0:0:1:1
HTTP/1.1 404 Not Found
...omitted...

Environment

  • BIG-IP

  • IPv6 virtual address

  • Rest API

Cause

The IPv6 address format do not match the RFC 5952.
Refer to the RFC 5952, we should use the IP 2001:db8:1::1:1, instead of 2001:db8:1:0:0:0:1:1.
RFC 5952: A Recommendation for IPv6 Address Text Representation
  > 4.2.1.  Shorten as Much as Possible
  >    The use of the symbol "::" MUST be used to its maximum capability.
  >    For example, 2001:db8:0:0:0:0:2:1 must be shortened to 2001:db8::2:1.
  >    Likewise, 2001:db8::0:1 is not acceptable, because the symbol "::"
  >    could have been used to produce a shorter representation 2001:db8::1.

Recommended Actions

Adjut the command, change to proper IPv6 address format, for example:

curl -isku 'username:password' https://localhost/mgmt/tm/ltm/al-address/~Common~2001:db8:1::1:1
