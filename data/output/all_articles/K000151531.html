K000151531: License assignment might fail when MTU on mgmt interface is modified and network infrastructure does not permit larger MTU than 1500

Description

Unable to license BIG-IP from BIG-IQ

Error in restjavad.log:

Device at 100.0.0.100 is not reachable. Please ensure that you've entered the correct IP address and restjavad services on the device are running.

Pcap is showing large Server Hello, Certificate ( MTU bigger than 1500) sent from BIG-IP to BIG-IQ not visible on BIG-IQ

Environment

  • BIG-IQ CM
  • License Assignment
  • MTU set to larger value than 1500 on MGMT interface
  • Firewall in network infrastructure 

 

Cause

Firewall is blocking bigger frames then standard with MTU 1500.

MTU on MGMT set to Value above 1500 causing that Server Hello, Certificate is not fragmented and dropped by firewall

 

Recommended Actions

Verify and modify MTU value on MGMT interface:

1) Use following command in bash to verify mgmt MTU:

  1. ip -f inet link show
  2. output example:

mgmt: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 2140 qdisc noqueue state UP mode DEFAULT qlen 1000

link/ether fa:16:3e:c8:ba:80 brd ff:ff:ff:ff:ff:ff

2) Modify MTU to values which are permitted on firewalls following: K000133081: Configure BIG-IP management interface (eth0) MTU
