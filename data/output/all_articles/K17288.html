Known Issue

VIPRION systems may continuously log the device group state to the audit log.

This issue occurs when all of the following conditions are met:

  • The VIPRION system is configured with at least one secondary blade.
  • MCP audit logging is enabled.

Impact

The /var/log/audit file continues to expand, due to the system continuously logging device group status messages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Messages similar to the following example are logged continuously to the /var/log/audit file:

    notice mcpd[7211]: 01070417:5: AUDIT - user mcpd-primary - transaction #2945032-4 - object 0 - create_if { devicegroup_device { devicegroup_device_devicegroup "/Common/gtm" devicegroup_device_device "/Common/ltm-1.askf5.local" devicegroup_device_last_sync_time 0 devicegroup_device_last_sync_type 0 devicegroup_device_commit_id { devicegroup_commit_id_id 0 devicegroup_commit_id_timestamp 0 devicegroup_commit_id_originator "" devicegroup_commit_id_device_data_id 0 } } } [Status=Command OK]

    notice mcpd[7211]: 01070417:5: AUDIT - user mcpd-primary - transaction #2945032-5 - object 0 - create_if { devicegroup_device { devicegroup_device_devicegroup "/Common/device_trust_group" devicegroup_device_device "/Common/ltm-1.askf5.local" devicegroup_device_last_sync_time 0 devicegroup_device_last_sync_type 0 devicegroup_device_commit_id { devicegroup_commit_id_id 247 devicegroup_commit_id_timestamp 6192282095678356029 devicegroup_commit_id_originator "/Common/ltm-1.askf5.local" devicegroup_commit_id_device_data_id 0 } } } [Status=Command OK]
