Issue

Prior to BIG-IP 10.1.0, when allocating memory to RAM Cache, the RAM Cache feature did not take into account the Clustered Multi-Processing (CMP) feature. This behavior caused duplicate cache entries to occur across the allocated TMM instances with no sharing between the instances, resulting in inefficient use of RAM Cache memory.

Note: For more information, refer to K8788: The HTTP caching feature does not take the Clustered Multi-Processing feature into account when allocating memory.

Note: For more information about the CMP feature, refer to K7751: Overview of Clustered Multi-Processing.

Beginning in BIG-IP 10.1.0, RAM Cache (also known as distributed RAM Cache) was enhanced to allow cached objects to be copied between TMMs. The RAM Cache feature introduces the new Ramcache.InterStripeCacheMemoryPercent database variable. This variable, set at 25 percent by default, defines what percent of the RAM Cache per TMM is reserved for local versions of cached objects. Adjusting the percentage value will either increase or decrease the size reserved for TMM locally cached objects.

Special cases where setting the variable to 0 or 100 will change the behavior of distributed RAM Cache

  • Ramcache.InterStripeCacheMemoryPercent = 0

    This setting will allow the RAM Cache to be fully distributed and allow for a maximum RAM Cache size, but will result in degraded performance. The degraded performance is a result of a higher percentage in which the cache may miss the owner TMM process of a cached object and need to retrieve the cached object from a different TMM.
  • Ramcache.InterStripeCacheMemoryPercent = 100

    This setting allows the RAM Cache to behave as it did prior to BIG-IP 10.1.0. Each TMM maintains its own cache and does not share information with other TMM processes, resulting in duplication of cached objects and inefficient cache utilization.

Viewing or setting the Ramcache.InterStripeCacheMemoryPercent database variable using the tmsh utility

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To view the current setting value, use the following command syntax:

    list /sys db ramcache.interstripecachememorypercent

    For example:

    list /sys db ramcache.interstripecachememorypercent
    sys db ramcache.interstripecachememorypercent {
    value "25"
    }

  3. To set the variable to a different value, use the following command syntax:

    modify /sys db ramcache.interstripecachememorypercent value <value>

    For example:

    modify /sys db ramcache.interstripecachememorypercent value 30
