Description

Vlans are deleted from /Common/ and recreated in a custom Partition without specifying interface, it stop working.

Do we need to select right interface manually on r2000/r4000 platfrom unlike vCMP guest / Tenant on r5000/r10000 platform and Velos?

 

Environment

  • F5OS-A
  • rSeries 2000/4000
  • VLAN recreation
  • Interface

Cause

  • Yes need to select right interface when you recreate VLANs.
NOTE: This is due to the difference in architectural design.
Tenant on r2000/r4000 series see the VLAN/Interface association on F5OS.

Recommended Actions

The archtecture of the rSeries are described in F5 rSeries Planning Guide: rSeries Performance and Sizing
