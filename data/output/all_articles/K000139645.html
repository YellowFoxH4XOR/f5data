Description

When adding a device to iQuery via bigip_add or gtm_add using "root" you receive the following CLI error message:

ERROR: Can't read remote cert via /usr/bin/ssh -o UserKnownHostsFile=/root/.ssh/known_hosts 

Environment

  • DNS (formally known as GTM)
  • Add a device to iQuery mesh (bigip_add)
  • Perform GTM Sync (gtm_add)

Cause

  • There are old or invalid known_hosts entries in /root/.ssh/known_hosts inside the device which the command is issued.
  • Port lockdown may be blocked SSH communication (22).
  • SSH allowed IP address is configured and it does not have the IP address which the command is issued.

Recommended Actions

  1. Make sure that you have remove all matching IP addresses for the device that you are trying to add into iQuery or perform the GTM Sync.
  2. Make sure that the port lockdown is allowed on SSH (22) for the self address which you are going to use.
  3. Make sure that SSH allowed IP address has been configured with the source address which you are going to run big_add or gtm_add.
