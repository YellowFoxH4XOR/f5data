Description
This document provides the instruction on how to replace multiple slashes found in the HTTP Path to a single slash

For example:changing https://siteA.com//sample//index.html to https://siteA.com/sample/index.html

Environment

  • iRule command
  • Virtual Server

Cause
None

Recommended Actions

Follow the steps below to change the multiple slashes found in the HTTP Path to a single slash using an iRule:
  1. Log in to the Configuration Utility
  2. Navigate to Local Traffic  ››  iRules
  3. Click Create
  4. Provide the name of the iRule
  5. Enter the below iRule. 
    when HTTP_REQUEST {
   # replaces multi / with single / in the HTTP URI
   log local0. "Before rewrite: {[HTTP::path]}"
   set HTTP::path [HTTP::path [regsub -all "\/+" [HTTP::path] "/"]]
   log local0. "After rewrite: {[HTTP::path]}"
}
Note: To remove logging modify the iRule stanza placing the pound sign (#) in front of the lines starting with the word "log".
  6. Click Finish
Assign the newly created iRule to the virtual server.

Note: Please test the iRule before you implement the change in the production system. For complete and detailed information iRules syntax, see the F5 Networks DevCentral website  https://devcentral.f5.com/.
