Description

Creating GSLB Custom Monitor on BIG-IQ


Environment

-BIG-IQ

-GSLB custom monitor

-v7.x.x to latest

Cause

Not Supported at this time

Recommended Actions

Currently BIG-IQ is not supporting creating, modifying custom GSLB Monitors.


These objects are not being imported from BIG-IP DNS to BIG-IQ.


This cause that created by user monitors for servers and pools on BIG-IP DNS are not visible/ selectable under:

Configuration > DNS >GSLB > Servers

Configuration > DNS >GSLB > Pools


-However we already have a Request for Enhancement (RFE) for this feature to be available in BIG-IQ in future versions.
