Known Issue

Adding a pool member by node name may fail.

This issue occurs when all of the following conditions are met:

  • You create a node where the node name contains the colon ( : ) character.
  • You create or modify a pool and attempt to add a member using the node name, using the Traffic Management Shell (tmsh).

Impact

Addition of the pool member fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When creating or modifying a pool and adding the pool member, the system displays an error message that appears similar to one of the following examples:

    0107003a:3: Pool member node (/<partition>/<node ip address>) and existing node (/<partition>/<node name>) cannot use the same IP Address (<node ip address>).

    Syntax Error: A port number or service name is missing for "<node name>:<port>". Please specify a port number or service name using the syntax "<node name>:<port>.<port>".

Resolution

Status

F5 Product Development has assigned ID 633824 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can delete and re-add the node using a node name that does not contain the colon character, prior to adding the node to a pool.

Impact of workaround:  Performing the suggested workaround should not have a negative impact on your system.
