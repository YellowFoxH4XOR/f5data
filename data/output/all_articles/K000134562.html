K000134562: Portal Access when using WebTop

Type
Support Solution
Published
2023-07-18
Updated
2023-07-18
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000134562

Description

When implementing portal Access this config usually will consume an APM CCU license. APM will still patch when portal access resource is removed, given strict adherence to system defaults, an APM CCU is not consumed. Also need of an ability to remove the pop up tool bar when going through APM.

 

Environment

  • BIG-IP APM v15.1.6
  • Portal Access webtop
  • Toolbar
  • APM CCU

Cause

By using defaults from portal access, and then configuring for webtop for type portal access with no resource assigned.

 

Recommended Actions

By using a portal access webtop ONLY, with no portal access resource, you must accept the default values that would appear with a portal access resource. By this, portal webtop should support patching and not consume a CCU.

 

Additional Information

By using defaults and you are wanting to disable the toolbar, the below iRule will be required to remove the pop up toolbar, since there is no longer a portal access resource that grants this ability to customize it.


 

if {[HTTP::header value Content-Type] contains "text/html"}{
# Replace APM Webtop Home Tab variable with blank
STREAM::expression {@var F5_HT_adm_enabled=\'1\';@@}

# Enable the stream filter for this response only
STREAM::enable
}
