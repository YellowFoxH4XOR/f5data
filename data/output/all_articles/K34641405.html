Known Issue

BIG-IP ASM geolocation enforcement may fail following an upgrade of the geolocation database.

This issue occurs when the following condition is met:

  • You update the IP geolocation database and restart the BIG-IP ASM bd process.

Impact

The BIG-IP ASM system is unable to identify the geographic location of a client or web application users.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system is unable to identify the geographic location of a client or web application users.
  • The BIG-IP ASM system logs error messages in the /var/log/ts/bd.log file that appear similar to the following example:

    BD_SSL|ERR |<date>|0973|io_manager_init.c:0425|ERROR: Failed to access GeoIP memory-map BD_SSL|ERR |<date>|0973|io_manager_init.c:0056|ERROR initializing GeoIP database.
