K000136129: Ansible Multi-Line Commands

Type
Support Solution
Published
2023-09-08
Updated
2023-09-08
Source
https://my.f5.com/manage/s/article/K000136129

Description

If an Ansible F5 Command requires multiple lines, such as a tmsh command:

 

sys sshd {

include "

   Ciphers aes128-ctr,aes192-ctr,aes256-ctr

   MACs hmac-sha2-256,hmac-sha2-512

   KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384

"

}

 

 

Environment

  • BIG-IP version 12.x or later
  • Ansible bigip_command

Cause

To achieve this, we start the bigip_command with the pipe character |

 

Recommended Actions

Example command from Ansible YAML file:

tasks:
- name: sshd include config
f5networks.f5_modules.bigip_command:
commands: |
modify sys sshd include "
   Ciphers aes128-ctr,aes192-ctr,aes256-ctr
   MACs hmac-sha2-256,hmac-sha2-512
   KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384
"
