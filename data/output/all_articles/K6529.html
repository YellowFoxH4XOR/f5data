Topic

This article applies to BIG-IP 9.x and 10.x. For information about other versions, refer to the following article:

  • K14127: Enabling and disabling monitor logging for SNMP DCA and SNMP DCA Base monitors (11.x - 12.x)

You can enable and disable monitor logging for SNMP DCA and SNMP DCA Base monitors by performing the following two procedures.

Enabling monitor logging

You can enable monitor logging for SNMP DCA and SNMP DCA Base monitors by performing the following procedure:

  1. Log in to the command line.
  2. Enable monitor logging for SNMP DCA and SNMP DCA Base monitors by typing the following command:

    bigpipe db Snmp.SNMPDCA.Log true

    If you have configured the BIG-IP system to monitor a node using either an SNMP DCA or an SNMP DCA Base monitor, the /var/log/snmpdca.log file (BIG-IP 9.0.0 through 9.3.1) or the /var/tmp/snmpdca.log file (BIG-IP 9.4.0 and later) will contain entries similar to the following example:

Note: For BIG-IP platforms that contain a hard drive, the snmpdca.log file will be recorded in two places. The log locations depend on the version of the BIG-IP system you are running. For BIG-IP 9.0.0 through 9.3.1, the snmpdca.log file is recorded in the /var/log/snmpdca.log file and the /shared/log/snmpdca.log file. For BIG-IP 9.4.0 and later, the snmpdca.log file is recorded in the /var/tmp/snmpdca.log file and the /shared/tmp/snmpdca.log file.

Disabling monitor logging

You can disable monitor logging for SNMP DCA and SNMP DCA Base monitors by typing the following command:

bigpipe db Snmp.SNMPDCA.Log false
