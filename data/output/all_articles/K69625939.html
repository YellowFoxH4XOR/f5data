Description

Wireshark only shows Application Data instead of the decrypted HTTP Traffic as expected when using a PMS file.

Environment

  • TLS traffic packet capture taken from a BIG-IP 
  • PMS file generated to decrypt said TLS packet capture
  • Wireshark tool

Cause

  • By default, Wireshark will only show HTTP decrypted traffic if the TCP Port is 443.
  • If a custom port, such as 4443 or 8443 is used, the default view is to show Application Data.

Recommended Actions

On Wireshark:

  1. Edit -> Preferences -> Protocols -> HTTP -> SSL/TLS Ports
  2. Change it from port 443 to add the custom port number your are using for encrypted traffic
  3. For example: 443, 4443, 8443
