When a user fails to enter a password correctly for a username that is authenticated by LDAP or RADIUS, the error message displayed on the FirePass logon page is slightly different from the error message displayed if a logon was attempted with a username that does not exist in LDAP or RADIUS. As a result, this issue can allow an attacker to learn valid FirePass usernames through repeated logon attempts with guessed usernames.

F5 Product Development tracked this issue as CR66767 for FirePass 5.5.1 and CR68628 for FirePass 6.0.0, and it was fixed in FirePass 5.5.2 and 6.0.1. For information about upgrading, refer to the FirePass release notes.

Additionally, a hotfix has been issued for FirePass 5.5.1. Customers affected by this issue should contact F5 Technical Support to request the hotfix, referencing the CR number and the number of this article. For FirePass 6.0.0, this issue was fixed in cumulative hotfix 600-2. You may download this hotfix or a later version of the cumulative hotfix from the F5 Downloads site.

For instructions about how to obtain a hotfix, refer to K167: Downloading software and firmware from F5. For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
