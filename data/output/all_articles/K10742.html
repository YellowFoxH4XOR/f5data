K10742: A non-multicast address in the multicast network failover address field causes the sod memory to leak

Known Issue

This is the result of a known issue. The Configuration utility incorrectly allows users to specify non-multicast addresses in the multicast network failover address fields. When a non-multicast address is specified, the sod process repeatedly fails to bind the socket, and the memory used by the sod process is not freed. As a result, the system may experience memory exhaustion and dump core.

F5 Networks Product Development tracked this issue as CR124290 and CR124415 and it was fixed in BIG-IP LTM version 10.1.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

You can work around this issue by specifying only link-local multicast addresses in the multicast network failover address fields.
