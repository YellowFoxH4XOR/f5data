Known Issue

The BIG-IP ASM bd process may fail to start.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured with security policy that includes a JSON or XML profile.
  • Your reboot the device or restart the BIG-IP ASM bd service.

Impact

The BIG-IP ASM bd service fails to start.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the BIG-IP ASM bd service fails to start, the system remains in the offline state.
  • The BIG-IP ASM system logs repeating messages to the /var/log/asm file that appear similar to the following example:

    info set_ibdata1_size.pl[<pid>]: Setting ibdata1 size finished successfully, a new size is: 8466M
    info perl[<pid>]: 01310053:6: ASM starting
    info perl[<pid>]: 01310053:6: Going to wait for bd_agent to finish pushing configuration to bd
    info perl[<pid>]: 01310053:6: bd_agent has finished pushing configuration to bd
    info perl[<pid>]: 01310053:6: Going to wait for bd to start all threads
    crit perl[<pid>]: 01310027:2: ASM subsystem error (bd_agent,F5::BdAgent::start): No ack received from BD after 600 seconds -- aborting

  • The BIG-IP ASM system generates a bd core file to the /shared/core/ directory.

Resolution

Status

F5 Product Development has assigned ID 515690 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of fixFixes introduced inRelated articles
Release13.0.0K2200: Most recent versions of F5 software
Hotfix12.0.0 HF3K9502: BIG-IP hotfix matrix

Workaround

To work around this issue, you can remove JSON and XML profiles from all configured security policies.

Impact of workaround:  Performing the suggested workaround will remove JSON and XML protection from the affected security policies.
