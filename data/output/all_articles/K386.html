Topic

BIG-IP 3.0 through 4.6.4

Resetting statistics globally

To reset the statistics globally from the Configuration utility, perform the following steps:

  1. From the left navigation bar, choose Systems.
  2. Click the Reset All Systems Stats button.

    The statistics for all systems are now reset.

Resetting statistics for a specific system

To reset the statistics from a specific VIP, Node, or Pool, perform the following steps:

  1. From the left navigation bar, choose one of the following options:
    • Virtual Servers
    • Node
    • Pool
  2. Choose the Statistics Tab.
  3. Click the Reset All Stats button.

    The statistics for the specific system are now reset.

BIG-IP 2.0 through 2.1.4

To reset the statistics, use one of the following options:

  • Reboot BIG-IP.
  • Reread the configuration file by typing the following command:

    bigpipe -f/etc/bigip.conf
