Description

Unable to set the Ports 5/6 to 1 Gig SFP on rSeries r2000/r4000

 

Environment

rSeries r2000/r4000

Cause

You use an unsupported optics; the right optics for the enabled port should be inserted that supports 1Gb SFP’s. For a list of supported optics for rSeries 2000/4000, refer to Clouddocs.

Recommended Actions

The r2000 and r4000 appliances support the configuration of 3 different port profiles:

8 x 10Gb

4 x 25Gb

2 x 25Gb - 4 x 10Gb

 

Note that port profile doesn’t’ mention every possible speed available, however if you wish to use lower speed follow below procedure:

 

How to set the Ports 5/6 to 1 Gig SFP on rSeries r2000/r4000

As example, if you want all 8 port to be able to support 1Gb set the 8 x 10Gb port profile, then the copper ports should auto-negotiate to 1Gb.

Once this is done you need to put in the right optics for the enabled port that supports 1Gb SFP’s

 

Additional Information

For more details please see following:
