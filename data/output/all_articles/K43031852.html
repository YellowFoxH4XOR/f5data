Description
BIG-IP ASM does not provide volumetric, transactions per second (TPS) DDoS protection of WebSocket traffic however it can rate-limit WebSocket traffic in a manner that appears to provide this protection.

Environment

  • BIG-IP ASM
  • WebSocket traffic
  • L7 DDoS attack protection enabled

Cause
BIG-IP ASM L7 DDoS attack protection does not have visibility into WebSocket frames. Each WebSocket connection starts with a bootstrap which consists of an HTTP request to switch to WebSocket protocol. These HTTP requests, like any other HTTP packets, are visible to L7 DDoS attack protection. If they and another HTTP traffic trigger volumetric protection, rate-limiting of the WebSocket bootstrap/initial handshakes may occur. When the rate of new WebSocket connections is limited, it will have the downstream effect of potentially limiting the amount of WebSocket traffic that can then occur (as there are less total connections able to communicate via WebSocket).

Recommended Actions

If WebSocket traffic appears to be rate-limited, review L7 DDoS attack protection configuration and determine if throttling of HTTP traffic may be impacting WebSocket bootstrap handshakes. Determine if the DDoS protection parameters should be altered to allow this traffic to pass.
