Known Issue

The wamd process may produce a core file and restart.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is provisioned with one of the following modules:

    • AAM
    • WAM
  • The mcpd process is restarted.

Impact

The BIG-IP AAM or WAM system temporarily stops passing traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You notice wamd core files in the /shared/core directory.
  • The BIG-IP system intermittently stops passing traffic.
  • In the /var/log/wamd.log file, you notice messages similar to the following example :

    Dec  6 14:47:06 ltmse-52 WA Debug (17675): [        PvAccelerator.cxx:1478  PvAccelerator_signalHandler ] Caught a signal '11' in thread id '1493904272' with PID '14790' - aborting
    Dec  6 14:47:06 ltmse-52 WA Debug (17675): [             TmPlugin.cxx:1425                 abort ] Aborting!
    Dec  6 14:47:06 ltmse-52 WA Debug (17675): [            PvContext.cxx:511        PvCharStar_Yell ] **********************************************************************
