K000132344: Mini-browser versions used by the BIG-IP Edge Client

Type
Support Solution
Published
2023-01-31
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000132344

Description

The BIG-IP Edge Client for Windows uses an embedded Internet explorer control from Microsoft in order to render the pages (logon page, posture checks, etc). This is sometimes referred to as a mini-browser (because it does not have all the capabilities of a full browser)

 

The IE version that the mini-browser uses depends on the Edge Client version:

  • Edge Client versions < 7.2 used IE9/10 mini browser
  • Edge Client versions >= 7.2 now use IE11 mini-browser

 

Environment

  • BIG-IP Edge Client mini-browser

 

Cause

  • None

 

 Recommended Actions

F5 recommends to update to the latest APM Clients / Edge Client version available, in order to take advantage of the latest features/bug fixes.

You can download the latest APM Clients iso file from the F5 Downloads website

 

Additional Information

We have a plan to support WebView2 and to allow customer to select an alternate browser to perform login page rendering.
