K000132888: APM-VDI RDWeb resource icon not updated

Type
Support Solution
Published
2023-03-07
Updated
2023-03-09
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000132888

Description

When you update the icons for apps on your RDWeb server, they are not reflected correctly on the APM Webtop. It still shows the old icons.

 

Environment

  • BIG-IP APM
  • RemoteDesktop RDWeb

 

Cause

As per design, VDI caches the icons.

 

Recommended Actions

Run on the command line:

bigstart restart vdi

Warning: This command will cause temporary interruption of your vdi related services like RemoteDesktop, Citrix, VmWare View. Probably best to run during a maintenance window.

This will clear the cache and load the new icons for the apps on the APM Webtop.
