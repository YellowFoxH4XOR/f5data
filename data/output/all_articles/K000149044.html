K000149044: Display the current size of the configuration DB

Type
Support Solution
Published
2024-12-19
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000149044

Description

The current size of the configuration DB is only logged in /var/log/ltm when an event to extend it triggered as sample shown below:

Dec 6 15:12:53 bigip16-A.local notice mcpd[xxxx]: 01390002:5: The size of the configuration DB has been extended by 5159040 bytes, now using a total of 46766720 bytes

46766720 bytes is the current of the configuration DB.


However, this log will get deleted/rotated in time.

Environment

BIG-IP

 

Cause

none

 

Recommended Actions

Run the below via the CLI bash to get the current size of the DB when the logs no longer show the value:

perl -e 'open(fd, "<:raw", "/var/db/mcpdb.info"); read(fd, my $x, 4); close(fd); printf "%d\n", unpack("L", $x)'
