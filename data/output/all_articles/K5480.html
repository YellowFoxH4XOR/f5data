Topic

To create a Portal Access favorite that performs automatic form-based authentication, perform the following procedure:

Note: This Solution requires that the user's username and password for the application is the same as the user's username and password for FirePass.

In order to create a Portal Access favorite that automatically logs in to an application, you must first determine the information you need to pass to the authentication form, and then define the Portal Access favorite.

Determining the information required by the authentication form

To create the Portal Access favorite, you must know the URL that is used to submit the username and password, as well as the names of the variables that contain the username and password.

To find this information, perform the following procedure:

Important: Although the following examples are high-level, there may be additional variables that must be passed to the authentication form. Make note of any additional variables and their possible values, in the event you will need them when defining the Portal Access favorite.

  1. Open the HTML source for the main page of the application.

  2. Within the HTML, locate form action. You will see a form tag similar to the following:

    <form action="logon.exe" method="post">

    This form tag renders as a relative link that is used to access the authentication application.

  3. Replace the URI portion of the URL you typically use to access the application with the value of the form action.

    For example, if you usually access the application using the URL http://www.askf5.com/index.html, change the URL, as follows:

    http://www.askf5.com/logon.exe

    This is the authentication URL. Make note of the URL, as you will use it to define the Portal Access favorite in step 9 of the Defining the Portal Access favorite procedure.

  4. Continue to read the HTML source until you find input type. For example:

    <input type="text" size="30" name="askf5username" value="">
    <input type="password" size="30" name="askf5password" value="">

    In each input type line, you will find a name attribute. The value of the name field is the variable name that is used to provide the authentication information.

Make note of the variable names associated with the user name and password. You will use them to define the Portal Access favorite in the Defining the Portal Access favorite procedure.

Defining the Portal Access favorite

To define the Portal Access favorite, perform the following procedure:

  1. Logon to the FirePass Administrative Console.

  2. In the main navigation pane, select Portal Access.

  3. In the upper navigation pane, select Web Applications.

  4. In the sub-menu, select Resources.

  5. Click the Add New Favorite link.

  6. From the Type menu, select Favorite.

  7. Enter a name for the favorite in the Name field.

  8. From the Web Application Type menu, select Generic.

    Note: The Web Application Type menu does not appear in FirePass version 6.0.2 unless you've enabled compatibility mode. Skip this step if the Web Application Type menu does not appear.

  9. Enter the authentication URL for the login page for the application in the Url field.

    For example:

    http://www.askf5.com/logon.exe

  10. If you are running FirePass version 6.x, click the Add to allow list link.

  11. Enter the username and password variable names to the Url variables field, by typing the following syntax:

    <user name variable>=%username%&<password variable>=%password%

    For example:

    askf5username=%username%&askf5password=%password%

    If you need to pass additional variables to the authentication form, type the following syntax:

    <user name variable>=%username%&<password
    variable>=%password%&<variable1>=<value1>&<variable2>=<value2>...

    For example:

    askf5username=%username%&askf5password=%password%&department
    =accounting&domain=askf5domain

  12. Select the Post url variables check box.

    Note: If you are running version 6.x of FirePass software, this check box is named Use POST for URL variables.

  13. Select the Open in new window check box.

  14. Click the Add New button.

The Portal Access favorite is now configured. When the Portal Access favorite is opened, FirePass will automatically log in to the application using the same username and password that was used to log in to FirePass.
