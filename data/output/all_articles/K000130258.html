K000130258: Monitor is not working as expected when pool member is local Virtual Server IP

Type
Support Solution
Published
2022-12-19
Updated
2023-04-05
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.4
Source
https://my.f5.com/manage/s/article/K000130258

Description

Configure a pool and pool member is one of the Virtual Server IP address.

However monitor logging showing error below for that Virtual Server IP address.

 

tmm monitor probe timeout

 

Environment

  • LTM
  • Monitor

Cause

In-TMM monitoring has been enabled.

 

Recommended Actions

Disable In-TMM monitoring and save the configuration.

  • tmsh modify sys db bigd.tmm value disable
  • tmsh save sys config

Additional Information

None
