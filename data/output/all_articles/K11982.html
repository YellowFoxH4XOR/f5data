Topic

The BIG-IP WebAccelerator version 10.x module may not receive sufficient allocation of memory resources. This issue has been addressed in various hotfixes released beginning in version 10.1.0 that introduce custom memory provisioning tables.

The following table specifies the platform, recommended provisioning level, and the related article:

Note: Provisioning information is located in the BIG-IP Configuration utility under System > Resource Provisioning.

Note: Provisioning BIG-IP LTM as None (Disabled) does not disable licensed BIG-IP LTM functionality. This setting disables additional allocations of CPU and memory resources to TMM, but does not disable the BIG-IP LTM.
