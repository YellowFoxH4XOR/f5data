Description
BIG-IQ CM fail to import BIG-IP ASM configuration. When importing was failed, BIG-IQ show the following error at /var/log/restjavad.log or GUI screen.

"Failed to copy configuration to working-config; reason: Failed copying from source subcollections to target subcollections: %s: java.lang.IllegalArgumentException: Invalid country code or country : South Sudan"
 

Environment

  • BIG-IQ CM version 7.x or 8.x
  • BIG-IP ASM version 13.x or 14.x or 15.x or 16.x
  • Geo location enforcement
  • Importing configuration

Cause
BIG-IP ASM does not have an entry of "South Sudan" at internal database Geolocation Enforcement List. F5 track this issue of BIG-IP ASM as ID1057713.
While the entry of "South Sudan" at internal database is missing, ASM's "Geolocation Blacklist" try to inspect missing entry, this inconsistency cause a failure of importing from BIG-IQ. 

Recommended Actions

Revise configuration of ASM and remove the entry of "South Sudan" from "Geolocation Blacklist" from /config/bigip.conf 
Note: Take a backup of the configuration and use vi editor to comment the configuration containing South Sudan and reload the configuration.
