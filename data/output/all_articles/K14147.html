K14147: The BIG-IP system allows you to configure an HA group with pools that are created in partitions other than the Common partition

Issue

Old Behavior

In versions prior to BIG-IP 11.3.0, when creating a high availability (HA) group, it is not possible to select pools created in partitions other than the /Common partition.

New Behavior

Beginning in BIG-IP 11.3.0, when creating an HA group, you can select pools created in partitions other than the /Common partition from the Configuration utility.

This behavior has also changed for the Traffic Management Shell (tmsh) in BIG-IP 11.2.0 HF3 and BIG-IP 11.2.1 HF3.

F5 Product Development tracked this change in behavior as ID 393530 and ID 401405.

Impact

None

Recommended Actions

In BIG-IP 11.2.0 HF3 and later, you can use the tmsh utility to create an HA group and reference a pool in a partition other than the /Common partition. To do so, perform the following procedure:

  1. Log in to the tmsh utility by entering the following command:

    tmsh,/p>

  2. Use the following command syntax:

    create ha-group <group_name> pools add { /<path>/<pool_name> }

    For example:

    create ha-group group1 pools add { /partition1/ftp_pool { attribute percent-up-members weight 70 } }
