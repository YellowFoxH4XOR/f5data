Known Issue

This is the result of a known issue. The UDP monitor fails to mark a node up once it has been marked down.

When the UDP monitor receives an ICMP Destination Unreachable/Destination Port Unreachable message in response to a UDP monitor request, the BIG-IP system will mark the node down. If a UDP packet is sent and any response other than an ICMP Destination Unreachable/Destination Port Unreachable message is received, the node is marked up and BIG-IP is allowed to direct traffic to the node.

When the node returns to service and the port is available, the UDP monitor may fail to mark the node up even after the monitor system stops responding with ICMP Destination Unreachable/Destination Port Unreachable messages.

F5 Product Development tracked this issue as CR102654 and it was fixed in BIG-IP version 9.4.6. For information about upgrading, refer to the BIG-IP LTM or Link Controller Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP version 9.4.5. You may download this hotfix or a later version of the hotfix from the F5 Downloads site.
