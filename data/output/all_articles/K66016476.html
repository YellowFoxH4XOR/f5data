Description

This articles describes how to send auditd or system audit logs under /var/log/auditd directory to a remote syslog server.

Environment

  • BIG-IP
  • Remote syslog server
  • system audit logs

Cause

By default, system audit logs are not sent externally via syslog or remote syslog destinations.

Recommended Actions

The actions or steps required to address the topic covered in the description is following.

  1. SSH into BIG-IP.
  2. To edit /etc/audisp/plugins.d/syslog.conf, run the following command.
    sed -i 's/^active = yes$/active = no/g' /etc/audisp/plugins.d/syslog.conf
  3. From TMSH, restart the auditd service following.
    restart sys service auditd
  4.  For version 17.x and up, the auditd service is handled directly by systemd.  The correct command for 17.x and up is: 
    sudo service auditd restart
  5. From TMSH, edit the syslog properties.

    edit sys syslog all-properties

    Locate the line that says "include none" and replace with the following.

    include "
source s_syslog_pipe {
   pipe(\"/var/run/syslog.pipe\" flags(expect-hostname));
};
filter f_catchall {
   level(debug..emerg);
};
destination d_remote_loghost {
      # replace A.A.A.A and B.B.B.B with the actual IP address of your syslog server.
      udp(\"A.A.A.A\" port(514) );
      udp(\"B.B.B.B\" port(514) );
};
log {
   source(s_syslog_pipe);
   filter(f_catchall);
   destination(d_remote_loghost);
};
"

    Exit the editor and save the changes.

  6. From TMSH, restart syslog with the following command.
    restart sys service syslog-ng
