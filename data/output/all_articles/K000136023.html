Description

You would like to change a BIG-IQ device in an HA-Cluster without resetting both of them to factory defaults.

Environment

  • BIG-IQ in an HA-Cluster
  • New BIG-IQ

Cause

None

Recommended Actions

First identify the Discovery IP address for each BIG-IQ device.
Each HA certificate must contain the Discovery IP address configured on the same BIG-IQ device it is generated on.
The Discovery address can be identified in the BIG-IQ GUI: System > This Device > General Properties

1. Run following command on both BIG-IQ to make them standalone:

ha_reset -f <SELF DISCOVERY ADDRESS>  

2. Run following command on both BIG-IQ to regenerate the SSL certificate:

ha_generate_certs -f <SELF DISCOVERY ADDRESS>

3. Recreate HA group between both devices via the GUI using the discovery IP of the peer. See K36398804 below.
