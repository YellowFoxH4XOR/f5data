Description

The scheduled report email is sent from BIG-IP using TLS even when SMTP is configured with No encryption.

Environment

  • BIG-IP ASM
  • BIG-IP ASM reports
  • The BIG-IP ASM is configured for SMTP
  • The SMTP configuration is set with Encrypted Connection as No encryption.

Cause

 The SMTP client starts the TLS negotiation.

Recommended Actions

  1. Using a text editor such as pico or vim add the following line to the file "/ts/dms/script/avrexport/avrmail.php".

    $mail->SMTPAutoTLS = false;

    Note: This line should be placed just prior the line $mail->SMTPSecure = ... (approximately line number 249).

        2. Your file should look like the following example:
          .......
           // set up mailer
           $mail = new PHPMailer(true);
           $mail->IsSMTP();
           $mail->SMTPDebug = SMTP_DEBUG_LEVEL; $mail->Timeout = 1;
           $mail->Host = $smtp_config['smtp_server_address']; $mail->Port = $smtp_config['smtp_server_port'];
           $mail->SMTPAutoTLS = false; <----------- This is the line you have to add
