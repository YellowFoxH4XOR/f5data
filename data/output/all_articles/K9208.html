Topic

You can use the bigstart utility to manage system services such as starting or stopping services upon boot up, or starting, stopping, and reporting service status from the command line.

Note: For more information about using the bigstart utility to manage system services, refer to K4080: Adding and removing services included in the bigstart process.

When you run the bigstart add --default or bigstart remove --default commands to add or remove a specified service to or from the default group of services, the configuration modification is not included in a UCS archive file.

For example, the following commands configure the postfix service to start at boot time and add the service to the default group of services:

bigstart add postfix

bigstart add --default postfix

F5 Product Development is tracking a request for enhancement to save service startup information in a UCS archive file as ID 273889 (formerly CR85655).

Workaround

You can work around this issue by performing the same service startup modification on the BIG-IP system after restoring the UCS archive.

Additionally, you can modify the /usr/libdata/configsync/cs.dat data file to include the Service startup information located in the /etc/bigstart directory in the UCS archive. To do so, perform the procedure described in the Adding a UCS archive entry section of K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive, and replace the syntax in Step 5 of that procedure with save.<number>.dir = /etc/bigstart.
