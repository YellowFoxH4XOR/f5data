Description

In some situations, you may need to enable Node inspector for some tasks such as debugging node apps. However, if you try to install the Node inspector you will get the following error message:

@BIGIP-A:] node_modules # npm install -g node-inspector
npm WARN deprecated xmldom@0.1.31: Deprecated due to CVE-2021-21366 resolved in 0.5.0

Environment

  • BIG-IP LTM
  • Node Inspector

Cause

Node inspector is already deprecated for security reasons. 

Recommended Actions

Since version 6.3, Node.js provides a built-in DevTools-based debugger which mostly deprecates Node Inspector 

Additional Information

How to use Node.js with Chrome DevTools
