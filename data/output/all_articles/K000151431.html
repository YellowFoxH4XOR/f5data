Security Advisory Description

Protection mechanism failure in firmware for some Intel(R) Ethernet Network Controllers and Adapters E810 Series before version 4.4 may allow an unauthenticated user to potentially enable denial of service via network access. (CVE-2024-24983)

Impact

This vulnerability may allow an unauthenticated attacker to cause a denial-of-service (DoS) through adjacent network access.

All variants of the following rSeries appliances are affected:

  • r2000 series
  • r4000 series
