Description
Client SSL profiles on BIG-IP systems cause relevant virtual servers to close connections directly rather than sending Close Notify alert first.

Environment

  • This occurs when BIG-IP systems have a client SSL profile attached to a virtual server and this client SSL profile doesn't have the Unclean Shutdown setting modified.

Cause
By default, client SSL profile indicates that BIG-IP systems perform unclean shutdown.

Recommended Actions

If clean shutdown is desired, the customer may modify the client SSL profile configuration and have the Unclean Shutdown setting unchecked.
