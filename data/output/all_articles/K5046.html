Topic

If your log files contain identical messages, including messages with the same time stamp, it is likely that there are duplicate or overlapping commands in your syslog configuration file.
 

Syslog facility output

Syslog directs the output of facilities to log files. In the syslog.conf file, there are a number of configuration statements in the following format:

<facility>.<level> /var/log/<logfile>

For example:

local0.* /var/log/bigip

If the same line appears more than once, the same message will be added to the log file more than once. For example, the following two lines would cause all messages in the /var/log/bigip file to be duplicated:

local0.*            /var/log/bigip
local0.*            /var/log/bigip

In addition, overlapping log levels may cause duplicate entries.

Facility log levels

Facilities include several log levels. The facilities are listed in order of the severity of the messages they handle. Generally, higher levels contain all the messages for lower levels. For example, in most cases, the alert level will report all messages from the emerg level, and the debug level will report all messages for all levels. The following levels are available for each facility:

LevelDescriptionVerbosity
emergEmergency system panic messages.Minimum
alertSerious errors that require administrator intervention.Low
critCritical errors, including hardware and filesystem failures.Low
errNon-critical, but possibly very important, error messages.Low
warningWarning messages that should at least be logged for review.Medium
noticeMessages that contain useful information, but may be ignored.Medium
infoMessages that contain useful information, but may be ignored.High
debugMessages that are only necessary for troubleshooting.Maximum
*All log messages at all log levelsEverything

If you use multiple syslog entries for a facility, while using different log levels, all messages at the higher log level will be duplicated.

For example, the following two lines would cause all messages in the /var/log/bigip file at the warning log level or higher to be duplicated:

local0.warning          /var/log/bigip
local0.debug            /var/log/bigip

To eliminate duplication in log files, remove any duplicate configuration statements from the syslog.conf file and consolidate any overlapping entries.
