Known Issue

Some custom monitor attributes may not be configurable if the parent monitor is also a custom monitor. For example, if you create a custom monitor that references another custom monitor as its parent, the following attributes may not be configurable:

  • Manual Resume
  • Reverse
  • Transparent

For instance, if you create custom monitor test2 from custom monitor test1, and the Manual Resume setting is enabled, the test2 monitor will only operate in manual resume mode until the configuration of the BIG-IP system is reloaded.

If you re-enable any of the above attributes using the Configuration utility or bigpipe utility, the monitor will work as intended until the configuration of the BIG-IP system is reloaded. When the BIG-IP system is reloaded, all of the above settings will be disabled (which means they will be set to No). If you attempt to re-enable any of the above attributes using the tmsh command, an error message that appears similar to the following example is returned:

Cannot modify the monitor type (defaults from) for monitor <MONITOR-NAME>

F5 Product Development tracked this issue as ID 338389, and it was fixed in BIG-IP LTM 11.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

When you create a custom monitor that will use the Manual Resume, Reverse, or Transparent setting, F5 recommends that you create the custom monitor from a base monitor. You can then enable those settings as needed.
