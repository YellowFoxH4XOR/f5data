Known Issue

This is the result of a known issue. If you select the Automatically add websites that require client side cookie manipulation setting on the Portal Access: Web Applications: Content Processing page under the Global Settings tab on a primary (master) cluster node, the primary cluster node adds those websites to an internal list without service disruption. However, each time a website is added, that change is pushed to the secondary cluster nodes. Unlike the primary cluster node, the secondary cluster nodes restart their web services each time a new website is added. In a heavily loaded cluster environment where many users are accessing many websites through the Portal Access reverse-proxy engine, the frequent restarting of the web services may cause service degradation on the secondary cluster nodes.

F5 Product Development tracked this issue as CR106540 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

This issue has been fixed in cumulative hotfix HF-603-4 issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

If a hotfix is not available for your version of FirePass software, F5 Networks strongly recommends disabling the the Automatically add websites that require client side cookie manipulation setting for environments using a FirePass cluster configuration. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console of the primary (master) cluster node.
  2. Navigate to the Portal Access: Web Applications: Content Processing page.
  3. Click the Global Settings tab.
  4. Clear the Automatically add websites that require client side cookie manipulation check box.
  5. Optionally, if you want to enable cookie passthrough for all websites, enter an asterisk ( * ) character in the Enter a comma-separated list of patterns to specify URL matches for cookie passthrough text field.
  6. At the top of the page, click the service restart link.
  7. Click the Restart button to restart the FirePass services.
