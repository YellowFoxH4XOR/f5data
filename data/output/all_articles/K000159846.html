K000159846: BIG-IP AVR crashes after DCD removal on BIG-IQ

Applies to

  • BIG-IP Analytics: 17.1.3
Source

Description

You removed DCDs on BIG-IQ. After some time, the AVR crashed on BIG-IP.

 

Environment

BIG-IQ CM/DCD

BIG-IP LTM

 

Cause

ID 1298225


Answer/Recommended Actions

The AVR can generate a core dump when DCD is unavailable. If you remove DCD on BIG-IQ, you need to remove the BIG-IP from BIG-IQ and re-discover it, which removes the invalid offbox-tcp-addresses configuration.

None
