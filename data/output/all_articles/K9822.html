Topic

FirePass provides monitoring of connectivity to an external node's IP address using the ping utility to determine whether it is available. When you use the external IP address monitoring option in the Failover configuration, the FirePass controller pings the node once per second. If no response is received after 60 seconds, the node is considered to be down and FirePass triggers a failover. When this occurs, the active controller becomes the standby controller, and the standby controller becomes active. By default, when external IP address monitoring is enabled, the controller monitors the IP address of the configured default gateway.

The frequency at which this monitoring occurs, and the FirePass controller's behavior in triggering a failover after 60 seconds, are currently not user-definable. 

F5 Networks Product Development is tracking the enhancement request as CR61131.
