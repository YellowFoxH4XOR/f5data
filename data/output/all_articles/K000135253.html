Description

Inbound SIP INVITE messages may be silently dropped in a SIP MRF ALG deployment.

Environment

SIP MRF ALG

Inbound SIP INVITE after internal successfully registers with a REGISTRAR.

Cause

Inbound INVITE has wrong "To:" header value or "Contact:" header has IP address which is not routable.


SIP inbound INVITE MUST match destination UA's SIP registration database entry on the BIGIP. SIP UAC REGISTER message headers which the INVITE will be compared to are "From:" header as well as the translation address IP and port used by the BIGIP for the outbound REGISTER message. The inbound INVITE's "To:" header MUST match either "From:" of the REGISTER or BIGIP translation IP address and port. The UA's "Contact:"/"Subscriber Address:" should be the IP address and port the REGISTER message was received from by the BIGIP else it MUST be routable path to reach the UA.

Recommended Actions

Ensure SIP UAC registers with valid "From:" and "Contact:" header values.

Ensure the REGISTRAR registers correct "From:" or "Contact:" header values as sent by BIGIP in the outbound REGISTER message.
