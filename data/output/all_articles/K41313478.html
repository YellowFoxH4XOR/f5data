Description

When you construct the tcp monitor needed for your remote session host servers there are specific Send and Receive strings needed for each version.

Environment

Relevant environmental factors specific to the topic

  • Pools, TCP monitor, Microsoft Session host servers

Cause

When using the tcp monitor Send and Receive strings in the deployment guide they fail for the Microsoft Remote Desktop Session Host.

Recommended Actions

Use the following Send and Receive strings for the specific Microsoft Server versions.
