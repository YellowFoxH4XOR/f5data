Topic

This article covers BIG-IP native configuration files, which are produced by F5. For information about third-party configuration files that are included in the BIG-IP system, refer to the following article:

  • K14272: Overview of UNIX configuration files (11.x - 17.x)

The BIG-IP configuration is stored in a collection of text files residing on the BIG-IP system. When you configure the BIG-IP system using the TMOS Shell (tmsh) or the Configuration utility, the resulting modifications are written to disk in the BIG-IP configuration files. While not an exhaustive list, the following tables describe the configuration files and other significant files and directories on the BIG-IP system. You should understand the purpose of each file and directory outlined in this article as you will encounter them during ongoing maintenance of your system, and you will also see them referenced in AskF5 articles or F5 product manuals.

Note: Some modules, such as BIG-IP ASM and BIG-IP APM, also store configuration data to a database.

Important: You should not edit BIG-IP files directly unless directed to do so by F5 Technical Support or by an AskF5 article.
