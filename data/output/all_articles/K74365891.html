Description

This article will show you how to use curl to display what ASM/Advanced WAF signature files exist in an environment and what their corresponding ID's are.
Finding out what attack signature packages are available and their corresponding ID's are helpful and can be used when Attack Signature Updates fail.

Environment

  • ASM/Advanced WAF needs to be provisioned in the environment
  • You will need access to bash terminal on the BIG-IP

Cause

None

Recommended Actions

  1. SSH into the BIG-IP with an Administrator level account
  2. Run the following command to status the available packages:

    # curl -sku admin:password https://localhost/mgmt/tm/live-update/asm-attack-signatures/update-files | jq .

    NOTE: You will need to replace admin:password with the administrator username and password.

  • Here you can see the Attack Signature "filename". The attack signature "id" is directly above the file name.
  • Another thing to make note of is the "selfLink". This is the link to the actual file referenced by the ID. This information can be helpful when working with attack signature updates that are failing.
