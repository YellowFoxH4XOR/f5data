Security Advisory Description

Under rare conditions, the BIG-IP APM system appends log details when responding to client requests. Details in the log file can vary; customers running debug mode logging with BIG-IP APM are at highest risk. (CVE-2017-6139)

Impact

A vulnerable BIG-IP APM system may append sensitive logging information when responding to client requests.

Mitigation

To temporarily mitigate this vulnerability, you can restart the apmd process. To do so, perform the following procedure:

Impact of action: The BIG-IP APM system fails to process traffic while the apmd process restarts. The following procedure stops the BIG-IP APM system from actively disclosing sensitive logging information. However, the procedure does not prevent the vulnerability from occurring.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Restart the apmd process by typing the following command:

    restart /sys service apmd
