Known Issue

BIG-IP APM portal access may incorrectly rewrite the submit() method.

This issue occurs when all of the following conditions are met:

  • JavaScript patching is enabled in the portal access configuration.
  • The submit() method is called, within the scope of a with statement, in the server response.
  • The submit() method in the with statement is called without an object.

Impact

HTML form submission fails and causes the web application to malfunction.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using portal access, users cannot submit form data.
  • When using portal access, the web application malfunctions or pages fail to render.
