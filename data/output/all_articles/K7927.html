Known Issue

This is the result of a known issue. If a user enters Protected Workspace using Internet Explorer 7 on a Windows Vista system, and the Vista system has User Account Control (UAC) enabled, two browser windows will launch. The first browser window displays a message similar to the following example:

Resuming Logon Procedure...
The logon procedure should automatically continue in a moment. If this does not occur within 20 seconds, please click the continue button below.

The second browser window opens the FirePass logon page. The correct behavior is for one browser window to launch and open the FirePass logon page.

Note: FirePass version 6.0.1 requires Cumulative Hotfix HF-601-6 or a later version of the Cumulative Hotfix to support Protected Workspace on Microsoft Vista clients. Previous versions of FirePass software do not support Microsoft Vista clients.

UAC is a security component in Windows Vista. For more information about UAC, refer to the following website:

http://technet2.microsoft.com/WindowsVista/en/library/00d04415-2b2f-422c-b70e-b18ff918c2811033.mspx

F5 Networks Product Development tracked this issue as CR85760 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative hotfix HF-601-7 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Important: This workaround is provided for informational purposes, but it is not recommended. Disabling User Account Control may decrease the security of your Windows Vista system. Use this workaround at your own risk.

You can work around this issue by disabling User Account Control on the Windows Vista client. For more information about disabling User Account Control, refer to your Windows Vista documentation.
