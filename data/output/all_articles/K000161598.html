K000161598: vCMP Guest status is not visible on Host GUI/CLI after upgrade

Type
Support Solution
Published
2026-06-05
Updated
2026-08-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.X, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000161598

Description

After upgrading the vCMP host to BIG-IP version 17.5.x, the vCMP host failed to display the correct status of vCMP guests.

Environment

  • BIG-IP LTM, version 17.5.x
  • vCMP enabled with multiple guests deployed

Cause

Bug ID2185097
The guest status JSON file (sys-software.json) is missing from the vCMP host's runtime directory for the affected guest(s) under /run/vcmpd/<guest_name>/json/

Answer/Recommended Actions

Manually restore the missing guest status JSON file from the guest to the vCMP host:

1. Log in to the vCMP host via SSH.

2. Navigate to the missing guest's status folder under /run/vcmpd/. Replace <guest_name> with the actual vCMP guest name:

cd /run/vcmpd/<guest_name>

3. Download the missing JSON status file from the guest to the vCMP host using the guest's management IP address. Replace <guest_mgmt_ip> with the actual guest management IP:

curl -sLku 'admin:<password>' "https://<guest_mgmt_ip>/mgmt/tm/sys/software/status" -o json/sys-software.json

4. After downloading the file, verify that the guest status is now visible on the host:

Note: Repeat steps 2–4 for each affected vCMP guest.

Additional Information

To fix the wrong HA status on the HA Failure list, run the following command in step 3:

curl -sLku 'admin:<password>' "https://<guest_mgmt_ip>/mgmt/tm/sys/ha-status?options=all-properties" -o json/sys-ha-status.json
