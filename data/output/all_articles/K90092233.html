Description
When trying to run an import of cryptographic keys into a FIPS HSM you receive the error:

key management library returned bad status: -18, A vendor error has occurred.

The key returning the error is not imported into the HSM, and is not available for use by the BIG-IP.

Environment

  • This is specifically applicable to BIG-IP running a hardware security module (HSM), not necessarily network HSMs
  • This only impacts HSMs, not FIPS 140-2 licensed software

Cause
This is caused by an a key encryption key (KEK) mismatch between one or more of the imported keys and the FIPS HSM.

Recommended Actions

Delete the offending key and either recreate or re-import the key from a file stored elsewhere. 
Note: Storing keys outside of the HSM may impact your FIPS 140-2 certification.
