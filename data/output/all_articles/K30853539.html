Description

DNS Relay Proxy Service is an important component for vpn users who perform rule-based DNS resolution without the use of the host file. More info in DNS relay proxy
It's common when BIGIP APM administrators require to review the log details related to DNS Relay Proxy Service.

Environment

  • DNS Relay Proxy Service
  • Log
  • APM
  • VPN
  • EdgeClient
  • CTU

Cause

The need in reviewing the logs for DNS Relay Proxy Service

Recommended Actions

Normally, BIGIP APM administrators should review the log from DNS Relay Proxy Service as part of CTU report.
When the report is generated and opened, the administrator should locate: Table Of Contents -> Log Files -> FltRedirSrv.txt

Due to various reasons, it may happen that the FltRedirSrv.txt log file is not included to the CTU report when it is generated.
In that case, the APM administrator can retrieve the log FltRedirSrv.txt file from the testing machine itself by going to: C:\Windows\Temp\ and searching for FltRedirSrv.txt
