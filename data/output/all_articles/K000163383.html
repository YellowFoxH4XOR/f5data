K000163383: Remove SAML Service Provider sp-host warning when configuration is loading

Description

During configuration loading, BIG-IP mcpd may log the following warning for an APM SAML Service Provider configuration:

Warning generated : apm aaa saml (/Common/SP_example) 'sp-host' value is not valid: Hostname sp.example.com/example/page can only contain characters [a-zA-Z0-9-._]

The warning here indicates that the 'sp-host' value contains a URL path. The field accepts only a hostname or fully qualified domain name (FQDN), not a path such as "/example/page".

Environment

  • BIG-IP with APM configured.
  • APM SAML Service Provider configuration with wrong 'sp-host' value format.

Cause

The SAML Service Provider's 'sp-host' value was configured as "sp.example.com/example/page".

The 'sp-host' field is intended to contain only the host or FQDN. The path component "/example/page" is not valid in this field and causes the configuration validation warning.

Answer/Recommended Actions

  • Log in to the BIG-IP Configuration utility.
  • Open "Access >> Federation >> SAML Service Provider >> Local SP Services"
  • Edit the relevant APM SAML Service Provider service.
  • Under General Settings, locate the Host area.
  • Change the Host value so that it contains only the required FQDN. For example:
sp.example.com
  • Save and apply the Access Policy.
  • Confirm that the warning no longer appears when the configuration is loaded.
