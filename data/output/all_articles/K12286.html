Known Issue

The Traffic Summary graph on the Overview screen in the BIG-IP ASM Configuration utility may incorrectly list requests that generate violations but are not blocked as having been blocked or dropped. 

This issue occurs when all of the following conditions are met:

  • The Web Application menu is set to All web applications on the Overview page in the BIG-IP ASM Configuration utility.

Impact

Data displayed in the Traffic Summary graph is inaccurate.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Traffic Summary graph is not consistent with the Traffic Summary data.

Resolution

Status

Workaround

You can work around this issue by viewing statistics for a specific web application rather than for all web applications. In the Web Application menu, select an individual web application, by name. The data for Dropped and Blocked requests is displayed correctly for the selected web application after the screen refreshes.
