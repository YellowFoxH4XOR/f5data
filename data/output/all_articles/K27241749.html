Known Issue

Changing an IPsec tunnel configuration may cause the Traffic Management Microkernel (TMM) process to restart and produce a core file.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility to modify the IKE Peers configuration of an IPsec tunnel.
  • The modifications result in an invalid configuration.

Impact

The BIG-IP system may temporarily fail to process traffic as the system recovers from the TMM restart, and devices configured as a high availability (HA) pair may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you modify the IKE Peers configuration of an IPsec tunnel, your BIG-IP system unexpectedly fails over to another system in the device group.
  • You observe a TMM core file in the /shared/core directory.

Workaround

To work around this issue, you can you can use the Traffic Management Shell (tmsh) to make the desired configuration changes. This issue occurs only when you use the Configuration utility.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
