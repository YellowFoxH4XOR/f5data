K000138601: Is it possible to predict what physical interface in a Trunk or LAG will be used for specific traffic?

Type
Support Solution
Published
2024-02-13
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000138601

Description

You want to know what physical interface in a Trunk or Link Aggregation Group (LAG) will be used for specific traffic.


For example, if BIG-IP sends a packet from 192.0.2.1:80 to 203.0.113.63:53320 which interface will it use?

Environment

  • BIG-IP Classic configured with a Trunk
  • F5OS configured with a LAG

Cause

There is no general way to predict this.

Recommended Actions

None.

Additional Information

The algorithm used for frame distribution varies significantly depending on hardware platform, interfaces used, and other configuration. If you see very uneven distribution across a LAG (called Trunk in BIG-IP Classic), you may open a case with F5 Support for troubleshooting.
