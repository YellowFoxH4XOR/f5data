Known Issue

Excessive memory usage can occur on a standby device when Performance (Layer 4) connection mirroring is enabled.

This issue occurs when all of the following conditions are met:

  • You have two or more BIG-IP systems configured in a High Availability (HA) pair.
  • You have a Performance (Layer 4) virtual server with the connection mirroring feature enabled.

Impact

Clients may experience poor performance after a failover event.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client connections are slow and possibly disconnecting.
  • The following messages may be logged to /var/log/ltm immediately after a failover event:

    warning tmm7[22201]: 011e0002:4: sweeper_update: aggressive mode activated. (2226430/2266368 pages)
    warning tmm7[22201]: 011e0003:4: Aggressive mode sweeper: 22 Connections killed
