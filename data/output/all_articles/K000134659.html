Description

How to run fsck on rSeries F5OS-A

 

Environment

  • rSeries/F5OS-A
 

Cause

None
 

Recommended Actions

1. Reboot F5OS-A

[root@appliance-1(R2600) ~]# reboot


2. Click "e" to edit during the boot sequence.

      CentOS Linux 7 (Core) (ostree:0)
      CentOS Linux 7 (Core) (ostree:1)
 
      Use the ^ and v keys to change the selection.
      Press 'e' to edit the selected item, or 'c' for a command prompt.

3. Add "fsck.mode=force fsck.repair=yes" on the ostree grub entry

linuxefi /ostree/velocity-bcc268a12a5c48591bbf9f58c9632dadd00021cf7fe2fbd65f41\
e0b9a8e544d9/vmlinuz-3.10.0-1160.62.1.F5.1.el7_8.x86_64 intel_iommu=on iommu=p\
t acpi_osi=Linux quiet fsck.mode=force fsck.repair=yes crashkernel=auto rd.lvm\
.lv=velocity/root rd.lvm.lv=velocity/swap console=ttyS0 root=/dev/mapper/veloc\
ity-root ostree=/ostree/boot.1/velocity/bcc268a12a5c48591bbf9f58c9632dadd00021\
cf7fe2fbd65f41e0b9a8e544d9/0
