Description

  • Your BIG-IP system is failing to boot. You may observe errors or prompts, similar to any of the following: 
    Free blocks count wrong for group
Free blocks count wrong
Inode bitmap differences:
Free inodes count wrong for group
Directories count wrong for group
Free inodes count wrong ().

Environment

  • Previously-working BIG-IP system is now failing to boot.

Cause

The filesystem has become corrupted.

Recommended Actions

Force a filesystem check, by running the following commands:

  1. fsck -A -y
  2. reboot
    (note: if the system fails to reboot, after running the 'reboot' command, you may need to power-cycle or reset the BIG-IP system or virtual machine).
