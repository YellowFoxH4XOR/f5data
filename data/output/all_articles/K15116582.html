Known Issue

If you reconfigure pool monitors from within an iApp, you may get an error message.

This issue occurs when the following condition is met:

  • You are attempting to reconfigure a pool member's monitor configuration from within an iApp

Impact

The iApp may fail to process pool reconfiguration commands.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/ltm log file and in the BIG-IP Configuration utility, you may observe an error message similar to the following example:

    01070029:3: The monitor rule was not found.
