Description

BIG-IQ VE deployments of all supported versions are supported in Azure VMware Solution. There are no special considerations or requirements for deploying BIG-IQ VE in Azure's VMware Solution as these requirements are the same as in any ESX environment.

Environment

  • BIG-IQ VE deployment on Azure and VMware

Cause

None

Recommended Actions

None

Additional Information

Azure VMware Solution platform comprises of bare metal VMware ESX servers and deployments as such BIG-IQ VE will be running in native VMware environment. For more details, refer to the VMware and Azure documentation.
