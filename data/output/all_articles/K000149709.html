K000149709: After upgrade to version 17.1.2, the gtm server VSes status is down, Reason: Inherited red from parent link /Common/1.2.3.4

Type
Support Solution
Published
2025-02-07
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000149709

Description

All gtm Virtual Servers are offline for reason "Inherited Red for parent link /Common/x.x.x.x" on the gtm servers where Link Controllers are configured.
Affected Link Controller's status offline, "Reason: no reply from big3d: timed out".
Happens for both 'gateway_icmp' and 'bigip_link' monitors on affected gtm Links.
Ping is working for affected gtm links router-addresses.
iQuery links are in connected state.

For example:

show /gtm server virtual-servers
------------------------------------------------
 | Gtm::Server: GTM.example
 ------------------------------------------------
 | Status         
 |  Availability : offline
 |  State    : enabled
 |  Reason    : No enabled VS available
 ----------------------------------------------------------------------------
   | Gtm::Virtual Server: /Common/GTMVS.example
   ----------------------------------------------------------------------------
   | Status                  
   |  Availability : offline         
   |  State    : enabled         
   |  Reason    : Inherited red from parent link /Common/1.2.3.4

 

show gtm link
------------------------------------------
Gtm::Link: isp1
------------------------------------------
Status        
 Availability : offline
 State    : enabled
 Reason    : Monitor /Common/gateway_icmp : no reply from big3d: timed out


gtmd logs can be found on the system:
Alert HOST gtmd[12345]: 011a6006:1: SNMP_TRAP: VS /Common/GTMVS.example (ip:port=1.1.1.1:123) (Server /Common/GTM.example) state change green --> red ( Inherited red from parent link /Common/1.2.3.4.)

Environment

  • BIG-IP DNS
  • Link Controller configured in affected Datacenter
  • After upgrade to 17.1.2

Cause

Unknown

Recommended Actions

Workaround:
Restart big3d process:
bigstart restart big3d

Additional Information

None
