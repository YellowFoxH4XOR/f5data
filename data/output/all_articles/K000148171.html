K000148171: Does the TCP Load Balancer have the "App Latency" metric?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000148171

Description

You want to know if the TCP Load Balancer has the App Latency just as the HTTP Load Balancer has.

Environment

  • F5® Distributed Cloud TCP Load Balancer

Cause

HTTP (L7) Load Balancers have App Latency metric, however TCP (L4) Load Balancers do not.

Answer/Recommended Actions

No, it does not. It does have other metrics like Proxy Latency and Server Latency
