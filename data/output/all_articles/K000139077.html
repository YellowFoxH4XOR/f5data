K000139077: Kerberos Authentication Failure After Upgrade to 16.1.4 or above

Type
Support Solution
Published
2024-03-28
Updated
2024-06-25
Applies to
  • BIG-IP
  • BIG-IP APM: 17.0.0, 17.1.1, 17.1.0, 17.0.X, 17.X.X, 15.1.10, 15.1.9, 17.1.X, 16.1.4
Source
https://my.f5.com/manage/s/article/K000139077

Description

Following an upgrade to 16.1.4.X, issues have arisen with Kerberos authentication failing within a Single Sign-On (SSO) service configuration. Attempts to access the service post-upgrade result in token validation errors, specifically "Failed to validate kerberos token, Error (-1)". Reverting to the previous partition resolves the issue, indicating the problem is associated with the new version.

Environment

  • Single Sign-On (SSO) service with Kerberos authentication
  • System upgraded to 16.1.4.X

Cause

The authentication failure is due to a new enhancement in the Kerberos library that was introduced in version 16.1.4. This enhancement requires both forward and reverse DNS lookups during the Kerberos token validation process. If the reverse DNS (RDNS) lookup does not find a matching FQDN for the IP address, the Kerberos token cannot be validated, leading to the observed authentication issues.

Recommended Actions

  • Ensure that your DNS is correctly configured to allow both forward and reverse lookups for the FQDNs in question.
  • Alternatively, set the session.server.network.name variable to the Kerberos FQDN in the network settings. This can be done by adding a "Variable Assign" block before the "Kerberos Auth" in your system's configuration. The exact steps are as follows:
    • Add a "Variable Assign" block within the APM VPE policy editor block before the "Kerberos Auth".
    • Configure this block to set the session.server.network.name variable to the correct Kerberos FQDN.
    • Ensure that this block is executed before any Kerberos authentication attempts in the policy flow.
    • Make sure that "Request Based Auth" is set to "Disabled" in the "Kerberos Auth" VPE object
  • Apply the changes and save the configuration.
