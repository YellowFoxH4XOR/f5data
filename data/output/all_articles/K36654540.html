Description

When you upgrade the BIG-IP to version 16.x and you run the command tmsh load sys config verify,  you may see output same as below:

  • There were warnings:
    /Common/<client_ssl_profile_name>, default option no-dtlsv1.2 set.
     

Environment

  • BIG-IP 16.x
  • Upgrading from earlier versions like 14.x or 15.x to 16.x
     

Cause

Beginning in BIG-IP 16.0.0, F5 introduces support for Datagram Transport Layer Security (DTLS) 1.2 as defined in RFC6347.
Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.
 

Recommended Actions

In BIG-IP 16.0.0, DTLSv1.2 is disabled by default in the Client SSL and Server SSL profiles. This log can be ignored if no requirement for DTLSv1.2.
 

Additional Information

If DTLS 1.2 is required, please refer to K52355764: BIG-IP support for DTLS 1.2 to enable it.
