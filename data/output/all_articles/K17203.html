K17203: The sysVlanStatTable OIDs are deprecated and replaced by ifXTable OIDs

Issue

Old Behavior

In BIG-IP versions prior to 11.5.2 HF1 and 11.6.1 for the 11.6.x branch, you can use the F5-BIGIP-SYSTEM-MIB::sysVlanStatTable object identifiers (OIDs) to query VLAN statistics.

New Behavior

Beginning in BIG-IP 11.5.2 HF1 and 11.6.1, the F5-BIGIP-SYSTEM-MIB::sysVlanStatTable OIDs are deprecated and replaced by IF-MIB::ifXTable OIDs.

F5 Product Development tracked this change as ID 382157.

Impact

The IF-MIB::ifXTable OIDs should be used to obtain VLAN statistics.

Recommended Actions

An SNMP management system that is configured to receive VLAN statistics by using the F5-BIGIP-SYSTEM-MIB::sysVlanStatTable OIDs must be updated to use IF-MIB::ifXTable OIDs.
