K000137180: mcpd forceload occurring on each reboot, without creating /service/mcpd/forceload file

Source

Description

The configuration is loaded from the text files on each reboot, and does not appear to be restored from the binary image.

The /var/log/ltm file contains an entry similar to the following on startup:

notice chmand[4588]: 012a0005:5: Hardware/Chassis change detected. Forcing db load from file

In addition, the command line of the mcpd process shows that it was started with the -forceload option:

[root@ltmtenant:Active:Standalone] config # tr '\0' ' ' </proc/$(pidof mcpd)/cmdline
/usr/bin/mcpd -dbmem 512 -listen 127.0.0.1 -forceload -f
                                           ^^^^^^^^^^___ Note

Environment

  • mcpd
  • F5OS tenant (rSeries or VELOS)

Cause

Bug ID 1105021: F5OS BIG-IP tenants perform an MCPD "forceload" operation after a reboot

This issue only affects F5OS tenants.

Recommended Actions

The rebooted device will have the newest commit ID in a device group. Take care to ensure that an outdated configuration is not synced to peer devices.

Additional Information

There is no fix for ID1105021 at the time of this article's publication.
