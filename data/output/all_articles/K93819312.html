Known Issue

Modifying SSL profiles in the Configuration utility may fail when the key is protected by a passphrase.

This issue occurs when one of the following conditions is met:

  • You upgrade a BIG-IP system earlier than 11.5.0 to a BIG-IP 11.5.0 or later system, while having a passphrase-protected key specified in the profile.
  • You create an SSL profile with a custom cert-key-chain name that references a passphrase-protected key.

Impact

You cannot update the Client SSL profile by way of the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When a Client SSL profile has a Certificate Key Chain (CKC) entry with a passphrase-protected key, and you attempt to update the profile using the Configuration utility, the update may fail, and produce an error message similar to the following example:

    01070313:3: Error reading key PEM file <Key_File_Path> for profile <Profile_Name>: error:0906A068:PEM routines:PEM_do_header:bad password read.

    Note: You may encounter this issue even when the passphrase in the SSL profile is correct.

Workaround

To work around this issue, you can make modifications to the affected SSL profile using the TMOS Shell (tmsh), or you can delete the CKC from the affected profile and recreate the profile.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.
