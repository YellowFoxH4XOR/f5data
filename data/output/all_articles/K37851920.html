Description

When loading the configuration, the following messages are logged:

  • Warning message in /var/log/ltm

01071859:4: Warning generated : /Common/myrule:3: warning: [The following errors were not caught before. Please correct the script in order to avoid future disruption. "invalid argument member"1227 38][LB::reselect pool mypool member ${mymember}] /Common/myrule:3

  • Warning message to terminal when loading an offending configuration:

Loading configuration...
There were warnings:
/Common/myrule:3: warning: [The following errors were not caught before. Please correct the script in order to avoid future disruption. "invalid argument member"46 44][LB::reselect pool mypool member ${mymember}]

Environment

  • BIG-IP 12.1.0 or later

  • iRule with LB::reselect parsing pool members as variables with IP tuple syntax

    For Example:

    ltm rule myrule {
    when LB_FAILED {
      set mymember 10.10.10.10
      LB::reselect pool mypool member ${mymember}
    }
    }

Cause

Bug ID 738450

Recommended Actions

As this is only a warning message, there is no action that must be taken. This message is benign so long as the ${mymember} variable is set to a valid IP address.

To suppress the message, you can use a plain value for the IP address instead of a variable.

For Example:

ltm rule myrule {
when LB_FAILED {
  LB::reselect pool mypool member 10.10.10.10
}
}

Additional Information

In the following iRule, all of the LB::reselect commands are valid, however due to ID 738450, the first three will generate a warning:

ltm rule myrule {
  set pmbr 10.10.10.10
  set port 80
  set pmbrport $pmbr:$port
  LB::reselect pool mypool member $pmbr       # << Generates a warning
  LB::reselect pool mypool member $pmbr:$port # << Generates a warning
  LB::reselect pool mypool member $pmbrport   # << Generates a warning
  LB::reselect pool mypool member $pmbr $port # << This line does not generate a warning
}

The following is logged:

warning: [The following errors were not caught before. Please correct the script in order to avoid future disruption. "invalid argument member"1276 38][LB::reselect pool mypool member $pmbr]
warning: [The following errors were not caught before. Please correct the script in order to avoid future disruption. "invalid argument member"1370 44][LB::reselect pool mypool member $pmbr:$port]
