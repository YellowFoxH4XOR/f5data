Description

Guide to setting up BIG-IP Private Offer in Azure (Pay As You Go) PAYG.

Environment

  • Azure (Pay as you go) PAYG
  • BIG-IP

Cause

 

 Recommended Actions

 

  1. Log in to your Azure Portal and navigate to Marketplace 
  2.  In the Marketplace page, enter “big-ip” in the search bar, and Private plan results should appear.  Select “View private plans” 
  3.  In the Private plans page, select the listing associated with the purchased Private Offer 

On the listing page, go to the Plan field and select the BIG-IP product from the dropdown.  Click “Create” to create a VM instance

NOTE: Azure Private Offers are only compatible with these BIG-IP Versions 

13.1.3.2+ 

14.1.2.2+ 

15.0.1.1+  

15.1+, 16.0+, 16.1+, 17.0+, 17.1+ 

  1. Find Your Private Offer with Azure CLI  

  • Download and configure Azure CLI if you do not already have it installed
  • https://docs.microsoft.com/en-us/cli/azure/?view=azure-cli-latest 
  • Open your terminal and enter this command: az vm image list –all – publisher f5-networks
  •  
  • Scroll through the list and find the private offer that you want to deploy.  
  • NOTE: Private needs to be appended to the end of the sku name
