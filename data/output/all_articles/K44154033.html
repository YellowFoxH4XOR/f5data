Description

After upgrade you can see the following in the logs:

logger[<PID>]: Re-starting neurond
neurond[<PID>]: main: Neurond MCP connection established.
neurond[<PID>]: main: Neurond MCP platform state reached.
neurond[<PID>]: parse_dbs: db: ipv4_src: max rules: 0x0000b000
neurond[<PID>]: parse_dbs: db: ipv4_dst: max rules: 0x00009000
neurond[<PID>]: parse_dbs: db: ipv6_src: max rules: 0x00002400

Environment

  • After Upgrade
  • Neurond Process

Cause

Unknown at the time of publication.

Recommended Actions

  1. Run the following commands:

    bigstart remove neurond
    bigstart add --default neurond

If the problem persist after step 1, remove or physically power cycle unit.

 

Note: If a full physical hard-reboot of the system is unavailable, an AOM initialized reboot can suffice, following the steps indicated in the following article: 

K14594: Accessing the AOM Command Menu
