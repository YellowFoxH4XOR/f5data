Topic

The BIG-IP system provides several Ratio load balancing methods that you can select for load balancing traffic to pool members. When you configure a ratio load balancing method, you assign a ratio weight to each pool member.

Description

Ratio methodDescriptionWhen to use
Ratio (member)The Ratio (member) method can be used to load balance most connection types. When you configure the Ratio (member) load balancing method you should assign a ratio weight to each pool member that is proportional to the capacity of the server. The number of connections that each server receives over time is proportionate to the assigned ratio weight. Ratio (member) load balancing calculations are localized to each specific pool (member-based calculation), as opposed to the Ratio (node) method in which calculations are applied to all pools of which the node is a member.You can use the Ratio (member) load balancing method when the server capacity of the pool members is different and you want to assign user-specified ratio weights that are proportional to the resources of each pool member.
Ratio (node)The Ratio (node) method can be used to load balance most connection types. When you configure the Ratio (node) load balancing method, the number of connections that each server receives over time is proportionate to a ratio weight you assign to each node. Ratio (node) load balancing calculations are applied to all pools of which a node is a member. This mode differs from the Ratio (member) load balancing method in which calculations are localized to each pool (member-based calculation).The Ratio (node) method can be used when the server capacity of the pool members is different and you want to assign user-specified ratio weights that are applied to all pools of which each node is a member.
Ratio (session)When you configure the Ratio (session) load balancing method, you assign a ratio weight to each pool member. When you use the Ratio (session) method, the system selects the pool member according to the ratio of the number of sessions each pool member has active; the system counts pending sessions as active sessions. In this context, a session is considered to be a transaction that occurs between the same client and server over an established connection. The Ratio (session) load balancing method requires that you assign Layer 7 and Layer 4 profiles to the virtual server.The Ratio (session) method can be used for message-based load balancing protocols such as RADIUS, DIAMETER, or other protocols that transmit multiple messages over the same connection.
Ratio Least Connections (member)When you use the Ratio Least Connections (member) load balancing method, the system weights connections to each pool member based on the value of the ratio weight defined for each pool member. If a ratio weight is unspecified, it will be treated as a default value of '1'. Load balancing calculations are localized to each specific pool.Use this method when the server capacity of the pool members is different, and you want the system to weight connections to each pool member based on the value of the ratio weight you define.
Ratio Least Connections (node)When you use the Ratio Least Connections (node) load balancing method, the system weights connections to each pool member based on the value of the ratio weight defined for the pool member's node. If a ratio weight is unspecified, it will be treated as a default value of '1'. Load balancing calculations are applied to all pools of which a node is a member.Use this method when the server capacity of the pool members is different, and you want the system to weight connections to each node based on the value of the ratio weight you define. The ratio weights that are applied to all pools of which each node is a member.
Dynamic RatioDynamic Ratio load balancing is a special load balancing mode for which the BIG-IP system actively polls pool members and assigns a weight value to each individual member, based on a set of default or user-defined threshold values.For more information about Dynamic Ratio load balancing, refer to K9125: Overview of Dynamic Ratio load balancing.

Using the tmsh utility to monitor Ratio load balancing statistics

When you configure a pool to use a Ratio load balancing method, you should monitor the load balancing statistics for the pool members or nodes to ensure that you are using the load balancing method that best suits your environment. To do so, perform one or more of the following procedures:

Using the tmsh utility to monitor Ratio load balancing statistics for pool members 

To use the Traffic Management Shell (tmsh) to monitor the statistics for a pool that uses a Ratio load balancing method, perform the following procedure:

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Use the following syntax to monitor the load balancing statistics for the pool:

    show /ltm pool <pool_name> members all-properties

    For example, the following command shows the pool statistics for MyPool:

    show /ltm pool MyPool members all-properties

Using the tmsh utility to monitor Ratio load balancing statistics for nodes

To use the tmsh utility to monitor statistics for a node that uses a Ratio load balancing method, perform the following procedure:

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Use the following syntax to monitor the load balancing statistics for the node:

    show /ltm node <node_name> all-properties

    For example, the following command shows the node statistics for MyNode:

    show /ltm node MyNode all-properties

Using the Configuration utility to monitor ratio load balancing statistics for pool members 

To use the tmsh to monitor the statistics for a pool that uses a Ratio load balancing method, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Pools > Statistics.
  3. In the Search box, type the name of the pool, and click Search.
  4. The system displays the load-balancing statistics for the pool.

Using the Configuration utility to monitor ratio load balancing statistics for nodes 

To use the tmsh utility to monitor the statistics for a node that uses a Ratio load balancing method, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Nodes > Statistics.
  3. In the Search box, type the name of the node, and click Search.
  4. The system displays load-balancing statistics for the node.

Recommendations

When you use Ratio load balancing methods, you should consider the following:

  • F5 recommends that you test different load balancing methods, and select the one that offers the best performance in your particular environment.
