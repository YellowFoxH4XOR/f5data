K62459530: Configuring SSH public key authentication from a remote system to BIG-IQ system

Type
Support Solution
Published
2022-10-07
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K62459530

Description

Without inputting a password, SSH from a remote system to BIG-IQ system.

Environment

  • BIG-IQ GUI & CLI

Cause

None.

Recommended Actions

The following steps are required to address the topic covered in the description.

  1. Create a user <username> in the BIG-IQ GUI
  2. Modify shell to bash for this user with the following tmsh command
    tmsh modify auth user <username> shell bash
  3. Generate key in the /home/<username> in a remote system
    ssh-keygen -t rsa
  4. Copy the public key to BIG-IQ
    scp .ssh/id_rsa.pub <username>@<BIG-IQ IP>:/home/<username>
  5. Generate authorized_keys in the BIG-IQ
    cd /home/<username>; mkdir .ssh; cat id_rsa.pub >.ssh/authorized_keys
  6. Test this function
    ssh <username>@<BIG-IQ IP>
