K000148914: Endpoint Inspection for Trellix Antivirus takes over 2 minutes to complete

Type
Support Solution
Published
2024-12-09
Updated
2024-12-09
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148914

Description

When performing endpoint inspections on client devices with Trellix Antivirus, the process may take more than two minutes to complete. During this time, users may also notice the F5 Edge Client displaying the status "Installing/Downloading," which deviates from the usual "Checking for antivirus software..." message.

Environment

  • APM with AV check
  • Trellix Endpoint Security as the antivirus solution
  • F5 Edge Client

Cause

The delay occurs due to the OPSWAT SDK's GetDefinitionState method, which interacts with Trellix Antivirus to retrieve the definition time. Analysis of log data indicates that this method requires approximately 102 seconds to execute. This unusually high timing results in prolonged inspections and triggers the "Installing/Downloading" status message.

Log snapshot:

"timing": 102250, // 102 seconds

"method_name": "GetDefinitionState"

This is a Trellix-specific behavior and should not be caused by external configurations (e.g., GPOs or third-party applications).

Recommended Actions

There are two possibilities to resolve this:

1. Apply the Hotfix:

F5 has released an engineering hotfix (EHF) that addresses the timing issue. Customers are advised to contact F5 Support by opening a ticket to request the EPSEC hotfix (EPSEC v1777), and apply the hotfix to resolve the extended inspection time.

2. Upgrade to the Latest EPSEC Version:

The fix for this issue will be included in the next official EPSEC build. Ensure that you update your environment to the latest available version when it becomes available on the F5 Downloads site.
