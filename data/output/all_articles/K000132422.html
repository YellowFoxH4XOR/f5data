K000132422: Geolocation dashboard does not show any data.

Description

You are trying to view the dashboard on the BIG-IQ, but it is empty (No Data Available)

Environment

  • BIG-IQ with DCD and BIG-IP configured
  • Managing LTM or other services (APM is included as an example below)

Cause

The data has not been synced with the BIG-IQ yet.

Recommended Actions

  1. Under the Configuration tab, navigate to ACCESS > Access Groups, select the group name to verify the APM configure on BIG-IQ is synced with BIG-IP. If there is any change on the APM side, the APM service should be re-discovered and re-imported on BIG-IQ.

  2. Under Devices > BIG-IP DEVICES, select the APM device and verify that under SERVICES that the LTM and APM services have been discovered and imported. Please do Re-discovery and Re-import if necessary.

  3. Under System tab, navigate to BIG-IQ DATA COLLECTION > BIG-IQ Data Collection Devices. Select the DCD device and under SERVICES verify that Access is activated on the self IP. The discovery and listener address should use an internal network rather than management network. Try to Deactivate/Activate the Access service.

  4. Check that Remote Logging Configuration is enabled for the APM device on the Monitoring > DASHBOARDS > Access > Remote Logging Configuration page.

  5. Is it working? If it is not, run the following command in the BIG-IQ CM CLI:

    bigstart restart restjavad

  6. Still not working? Remove and re-add the DCD.
