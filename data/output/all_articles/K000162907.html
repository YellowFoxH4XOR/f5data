K000162907: FPGA firmware version as deployed to a Velos BX110 or BX520 blade.

Type
Support Solution
Published
2026-08-13
Updated
2026-08-13
Applies to
  • F5OS Products
  • F5OS-C: 1.8.X, 1.8.2, 1.8.1, 1.8.0
  • F5OS: 2.0.X, 2.0.0
Source
https://my.f5.com/manage/s/article/K000162907

Description

You may want to know what is the version of the bitfile code currently loaded to the FPGA we have in the VELOS blades.

Environment

F5 VELOS

Cause

Information

Troubleshooting

Answer/Recommended Actions

We can get the response from the output of the "# show health" command, which can show something like this:

 firmware blade/firmware/fpga/atse0

 state name "FPGA atse0"

 state health ok

 state severity info

                        ATTRIBUTE ATTRIBUTE ATTRIBUTE             

ATTRIBUTE NAME     ATTRIBUTE DESCRIPTION  HEALTH   SEVERITY  VALUE    UPDATED AT       

--------------------------------------------------------------------------------------------------------

firmware:update-status Firmware update status ok     info    complete  2026-08-06T19:02:40Z  

firmware:version    Firmware version    ok     info    75.3.25.00 2026-08-06T19:02:40Z  

 

 firmware blade/firmware/fpga/atse1

 state name "FPGA atse1"

 state health ok

 state severity info

                        ATTRIBUTE ATTRIBUTE ATTRIBUTE             

ATTRIBUTE NAME     ATTRIBUTE DESCRIPTION  HEALTH   SEVERITY  VALUE    UPDATED AT       

--------------------------------------------------------------------------------------------------------

firmware:update-status Firmware update status ok     info    complete  2026-08-06T19:02:54Z  

firmware:version    Firmware version    ok     info    75.3.25.00 2026-08-06T19:02:54Z

 

 

Alternatively, as the "# show health" command can be verbose, we can choose to run the commands below:

  • # show system health components component blade-1 firmware blade/firmware/fpga/atse0
  • # show system health components component blade-1 firmware blade/firmware/fpga/atse1
