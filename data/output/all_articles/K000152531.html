Description

  • You successfully Installed NGINX Instance Manager (NIM). 
  • However, when trying to access NIM User Interface using a browser, you get HTTP error 502
  • When checked NGINX Error log at /var/log/nginx/access.log/error.log
  • When NGINX error/access log, you notice the below permission errors 

NGINX Access Log

		143.202.157.142 - - [07/Jul/2025:21:48:59 +0000] "GET /modules HTTP/2.0" 502 59 "https ://<NIM-fqdn>/ui/" "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/137.0.0.0 Safari/537.36" "-"

NGINX Error Log

		2025/07/07 21:48:59 [crit] 32755#32755: *8 connect() to unix:/var/run/nms/core.sock failed (13: Permission denied) while connecting to upstream, client: 192.168.1.2, server: _, request: "GET /modules HTTP/2.0", upstream: "http : //unix:/var/run/nms/core.sock:/api/platform/v1/modules"
  • You want to know what caused this issue

Environment

  • NGINX Instance Manager
  • NGINX Plus
  • Security-Enhanced Linux (SELinux)
  • User Interface
  • HTTP error 502

Cause

  • Enforced SELinux mandatory access control (policy) preventing NGINX from reading files

Recommended Actions

  • To modify SeLinux

SSH into your the host system where NIM installed

edit SeLinux configuration

sudo vi /etc/selinux/config 

and modify file as below

SELINUX=disabled

save and exit

reboot host system

access NIM UI and confirm

 

  • Alternatively, you can use the optional SELinux policy module provided by NGINX. Please follow the guide provided here Configure SELinux

Additional Information

  • In addition to the above

-- one of the most common cause is not restarting Nginx service

- Please restart NGINX following

 sudo systemctl restart nginx

-- verify NIM, Clickhouse and Nginx service

- Please check the above service status following

sudo systemctl status nms

sudo systemctl status clickhouse-server

sudo systemctl status nginx
