Description

Not able to add BIG-IP to BIG-IQ with the following error message

Error querying 'Virtual Server' from path '/mgmt/tm/ltm/virtual' on device bigip.example.local (10.10.10.10), network communication failed due to protocol error

Environment

The following conditions must be met.

  • Running BIG-IQ 7.0
  • The added BIG-IP has several thousand of virtuals.

Cause

Large amount of virtuals requested via REST causes icrd to timeout.

Recommended Actions

Upgrade BIG-IQ to 7.1
