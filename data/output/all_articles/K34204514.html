Cause

Seen behavior is caused by a known issue tracked with the bug ID 683135

Recommended Actions

  • Upgrade to a software version where bug ID 683135 is fixed.
     
  • As a workaround you can disable the TCP Synflood vector in mitigate mode:
  1. On GUI go to Security > DoS Protection > Device Protection
  2. Click on Network to expand the Attack Vectors list list
  3. Click on TCP SYN Flood 
  4. On the Properties panel locate the State drop-down menu and select Disabled
  5. Click Commit Changes to System
