Recommended Actions

Upload the old version's iso files you removed GUI (SCP to /var/import/staging), then reboot.

If this does not resolve the issue, then please generate host-only-qkview by running the below command on CLI (log in as root)

qkview-collect

Then with the file generated, please escalate to F5 Support.

NOTE: The file generated by this command is not able to process by iHealth as it gather log files only.
