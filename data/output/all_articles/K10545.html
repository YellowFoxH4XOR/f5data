Known Issue

This is the result of a known issue. Users assigned the Application Security Policy Editor user type will receive the following error message with the Configuration utility when attempting view the information for a node object:

General database error retrieving information

The user with the Application Security Policy Editor user type should be able to view the information for the node, but not create or make any changes to the node.

F5 Product Development tracked this issue as CR122645 and it was fixed in BIG-IP ASM 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.
