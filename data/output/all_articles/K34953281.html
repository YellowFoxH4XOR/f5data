Description

Your BIG-IP is configured with an custom iRule that implements the IP Intelligence feature. Virtual Servers on IPv4 are resetting the connection or are no accessible on IPv4, but the Virtual Server on IPv6 are accessible. You see error messages similar to the following logged in /var/log/ltm:
TCL error: /Common/iRule_name <ASM_REQUEST_DONE> - IP Reputation database (/var/IpRep/F5IpRep.dat) not loaded (line 5) invoked from within "IP::reputation $client_ip"

Environment

  • BIG-IP
  • IP Intelligence
  • iRule

Cause
The IP Intelligence feature in not licensed.

Recommended Actions
Remove the iRule from the virtual server configuration. 
Note: IP Intelligence only works with IPv4, so traffic coming/going on IPv6 will not be affected.
