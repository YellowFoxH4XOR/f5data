Known Issue

HTTP responses from the BIG-IP system may contain trailing redundant chunk data, or fail.

This issue occurs when all of the following conditions are met:

  • You have an iRule using the HTTP::respond command associated with a virtual server.
  • The HTML response is modified by the iRule.
  • The BIG-IP Application Visibility and Reporting (AVR) profile is associated with the virtual server.
  • The BIG-IP AVR server-side response event receives a status 200 and no Content-Length: header.

Impact

Affected HTML responses may fail or contain redundant data.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP System responds with trailing chunk header data at the end of the HTML response.
  • The client may display redundant data at the end of the HTML response.
  • The client may receive an HTML error message similar to the following example:

    HTTP/1.0 500 Internal Server Error
