Description

You have added a BIG-IP LTM as a server object on your BIG-IP DNS system, enabled virtual server auto-discovery, and verified that the iQuery connection is connected, but virtual server auto-discovery fails.

Environment

  • BIG-IP DNS
  • Server with bigip monitor
  • Virtual server auto-discovery

Cause

Choosing the management IP of the BIG-IP LTM when adding it as the server causes the auto-discovery failure.

Recommended Actions

Choose the correct non-floating self IP instead of the management IP. For more information refer to Manual Chapter : Integrating BIG-IP DNS Into a Network with BIG-IP LTM Systems

None.
