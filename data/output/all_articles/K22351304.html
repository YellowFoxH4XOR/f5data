Known Issue

Windows 10 device users may not be able to establish an access session.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access profile access policy is configured with the Windows Info agent.
  • You access the BIG-IP APM access profile using the BIG-IP Edge Client.
  • The BIG-IP Edge Client software is configured with the Enforce Access Policy in Custom Dialer setting.
  • The Windows Info agent is configured to deny resource access for devices running Windows 8.
  • You attempt to establish an access session from a device running Windows 10.

Impact

The Virtual Private Network (VPN) fails to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the access session variable for the user device operating system, the detected operating system is Windows 8.

    For example:

    <session id>.session.windows_info_os.last.platform 8 Win8.164

  • Modifying the Windows Info agent settings to allow Windows 8 permits users running Windows 10 to establish an access session.
