K23553401: Failure to install or upgrade BIG-IP on Velos Tenant

Type
Support Solution
Published
2022-07-31
Updated
2023-02-21
Applies to
  • VELOS Platforms
  • F5OS
Source
https://my.f5.com/manage/s/article/K23553401

Description

While trying to install or upgrade BIG-IP tenant on velos, installation fail with error message that version does not support VELOS.

  • Trying to install or upgrade BIG-IP on Velos
  • liveinstall.log:
    *** Live install start at 2022/07/14 14:05:36 ***
    info: Daemon-driven execution indicated by ENV variable.
    info: Repository tm_install version/release is 2.16.0/165.0
    info: System tm_install version/release is 2.14.0/165.0
    info: Updating system tm_install files from /shared/images/BIGIP-16.1.3-0.0.12.iso
    .............................................................................
    7688 blocks
    Terminal error: Failure /shared/images/BIGIP-16.1.3-0.0.12.iso does not support VELOS.
    *** Live install end at 2022/07/14 14:05:37: failed (return code 255) ***

Environment

  • BIG-IP tenant on Velos
  • Installation or upgrade of a tenant fail

Cause

The reason is that the version that you are trying to install or upgrade the tenant is not supported by Velos

Recommended Actions

  • Refer to K9476: The F5 hardware/software compatibility matrix, Compatible BIG-IP tenant software versions, VELOS hardware products

Additional Information

None
