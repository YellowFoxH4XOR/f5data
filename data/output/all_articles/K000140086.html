K000140086: APM Network Access - IOS Clients may take Proxy Port Number even when there is no Proxy Address configured

Type
Support Solution
Published
2024-08-14
Updated
2024-08-15
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.7
Source
https://my.f5.com/manage/s/article/K000140086

Description

You have the following Network Access - Client Proxy Settings configured

You observed that connected Android devices (with No Local Proxy) have "NA" on your Proxy settings.

On connected iOS devices (also with No Local Proxy) showed it has "Blank" Proxy Address with Port 8080.

This resulted to iOS devices having no internet access while the Android devices can access the internet.

 

The Proxy Port is only relevant to the Client Proxy Address configured.

The expected behavior is that this port 8080 should not be relevant since this is the Proxy Port for the Proxy Address (if configured)

 

Environment

  • BIG-IP APM
  • iOS VPN Clients

 

Cause

This typically happens when you previously have Client Proxy Address/Port settings configured on the Network Access Resource. and after some time, you decide you don't need them anymore and remove them from the NA configuration.

 

Apparently, the BIG-IP Configuration utility won't let you leave those settings 'blank'. You will get an error similar to the following after clicking the 'Update' button:

"01071165:3: apm resource network access (/Common/NA_resource) Invalid value for parameter (proxy script and address) when client proxy is set."

 

Recommended Actions

  1. Tick the "Use Local Proxy Settings" checkbox
  2. Set the Client Proxy Port value to the default "0" if No Proxy Address is configured.
