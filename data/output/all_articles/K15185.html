Known Issue

A BIG-IP APM rewrite profile may fail to rewrite specific content.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access profile is configured with a rewrite profile.
  • Users accessing the BIG-IP APM access profile are using an Internet Explorer browser.
  • Web page content retrieved from the destination access profile resource contains the use of the Window.postMessage().

Impact

The web page does not function for the Internet Explorer user.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Internet Explorer browser may produce errors regarding JavaScript.
  • Users may experience a browser pop-up window with no content.
