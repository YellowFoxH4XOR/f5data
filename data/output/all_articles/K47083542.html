Description

BIG-IP DNS TCP monitor marks DOWN with "state: connect failed" when a target object sends reset(RST) packet against SYN. 
Log messages similar to the following will be recorded to /var/log/gtm;

alert gtmd[4209]: 011ae0f2:1: Monitor instance /Common/tcp 192.0.2.1:80 UP --> DOWN from 192.0.2.2 (state: connect failed)
alert gtmd[4209]: 011a4003:1: SNMP_TRAP: Pool /Common/example_pool member Example_Generic_VS (ip:port=192.0.2.1:80) state change green --> red ( Monitor /Common/tcp from 192.0.2.2 : state: connect failed)

 

Environment

  • BIG-IP DNS system with DNS TCP monitor
     

Cause

This is by design. 
 

Recommended Actions

Please make sure that a service of a target object is running.
