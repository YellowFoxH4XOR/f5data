Description

Restjavad logs will show the error :

 

[8100/tm/shared/bigip-failover-state BigipFailoverStateWorker] Failed to discover <HA config sync IP address>: java.lang.IllegalStateException: Could not connect to host <HA config sync IP address>. Please ensure there are no licensing, firewall, port lockdown or network connectivity issues. Error: Connection refused

 

However, the config sync will still in Sync.

 

Environment

  • HA configuration

Cause

ID663754

Recommended Actions

Ensure the HA is correctly configured:

 

1)_ License the same in both HA peers

2)_ Modules provisioned

3)_ NTP is working ok

4)_ Software version must be the same between all the HA peers

5)_ All the ports are having connections , 443, 1026, 4353, 6699

6)_ Self IP port lockdown are set to Default

7)_ Check telemetry (iApp LX) -- this can also generates the log message

Note: Stop using TCP port 443 will generate logs messages. This port is needed as part of Gossip protocol. No workaround is available.
