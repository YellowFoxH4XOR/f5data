K000141012: Pool availability status showing offline (Disable parent)

Type
Support Solution
Published
2024-09-27
Updated
2024-09-27
Source
https://my.f5.com/manage/s/article/K000141012

Description

The pool availability status is shown offline(disabled-by-parent) but the same pool has one or more pool members in the enabled state.

 

Disabled all pool members and the pool status changed to "Available (Disabled Parent)".
Brought down the backend nodes to make the health monitor probes fail and the pool status changed to "Offline (Disabled Parent)".
Enabled one or more pool members. The pool status still shows as "Offline(Disable parent)" instead of "Offline (Enabled)". 

Environment

BIG-IP LTM

Cause

The noticed condition is by design.  The pool member will have the previous status even if we reenable the pool member when health monitor probes are not successful. 

Recommended Actions

The workaround is to force the config load to re-initiate monitor status.

#tmsh load sys config
