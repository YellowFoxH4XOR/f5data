Description

When trying to synchronize FIPS hardware security modules (HSMs) between two BIG-IPs, the following error is found: 

ERROR: Failed to login to the FIPS device as crypto officer

Environment

  • BIG-IP 
  • FIPS hardware security module (HSM)
  • HSM synchronization

Cause

This error means there is a security officer (SO) identities mismatch between the peer unit.

Recommended Actions

The security domain label must be identical on peer FIPs devices in order for HSM synchronization to succeed. To remedy this error, make sure that the SO password used is correct.

In the event the SO password is lost, you will need to re-initialized HSM and reset the SO password. To re-initialize the HSM you can run the following command:

Important: Running the following command erases all keys from the FIPS 140 device. Any configuration objects dependent on FIPS keys will cause the configuration fail to load.

tmsh run util fips-util -f init
