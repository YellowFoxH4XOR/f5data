Description

'AD Auth' agent, inserted in the Access policy after 'Negotiate' branch from a 'HTTP 401 Response' agent, fails.

Environment

Following conditions are met.  

  • BIGIP provisioned with APM
  • 'AD Auth' agent inserted in the Access policy after 'Negotiate' branch from a 'HTTP 401 Response' agent.

Cause

On computers running Windows OS, Microsoft 'Negotiate' security package selects between 'Kerberos' and 'NTLM' authentication, prioritizing 'Kerberos' when possible.


APM can not obtain user's password from neither 'Kerberos' nor 'NTLM' authentication, so 'AD Auth' fails because 'password' is empty.

Recommended Actions

Use another agent that does not require user's password.
