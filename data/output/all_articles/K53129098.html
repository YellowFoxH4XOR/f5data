Known Issue

Advanced customization of access profile files may not function.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with partitions.
  • You create an access profile in a non-default partition and the profile name or the partition name contains a period (.) character.
  • From the Configuration utility, you modify the access profile files by going to Access Policy > Customization > Advanced.

Impact

You cannot access file content.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to edit an access profile file using the Configuration utility, the file content does not display.

Workaround

To work around this issue, you can export and import the access profile using a profile name that does not include a period character. After you import the access profile, you can customize and associate the access profile to the virtual server. To do so, perform the following procedure:

Impact of workaround: F5 recommends performing the following procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility.
  2. Go to Access Policy > Access Profiles > Access Profile List.
  3. In the Export column for the profile, select the Export link.
  4. Save the exported file to your computer. 
  5. Select Import.
  6. Enter a profile name for New Profile Name. Ensure that the new name does not include a period character.
  7. Select Choose File and then go to and select the access profile file you previously exported.
  8. Select Import.
  9. Go to Local Traffic > Virtual Servers > Virtual Server List.
  10. Select the affected virtual server.
  11. Scroll down, and under Access Policy, for Access Profile, select the imported access profile.
  12. Select Update.
