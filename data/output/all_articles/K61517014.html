Description
When you associate a BIG-IP Advanced WAF policy to an HTTP/2 or gRPC virtual server, the BIG-IP terminates the connection, sending a RST to the client.
gRPC support requires HTTP/2 trailers which is now supported beginning in BIG-IP v16.1.0.

Environment

  • BIG-IP
  • HTTP/2
  • gRPC

Cause

Prior to BIG-IP 16.1.0, HTTP parsing on the BIG-IP LTM does not support the HTTP Trailer feature.  Trailers may be silently dropped when rechunking, or in HTTP/1 to HTTP/2 transitions. 

There is support on BIG-IP LTM for gRPC in v16.1+ releases since ID942105 was implemented. However, there's still no support for it with ASM/AWAF. There is an existing enhancement request for it and it is tracked by our Product Engineering as ID2216901.

Recommended Actions

Upgrade to supported software version.
