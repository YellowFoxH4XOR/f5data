Description

You need to import a large amount of MyF5 license keys into a RegKey Pool on the BIG-IQ.

Environment

  • Flexible Consumption Program (FCP)
  • BIG-IP Virtual Edition (VE)
  • MyF5 Self Service license keys
  • BIG-IQ RegKey Pool

Cause

You plan to use BIG-IQ RegKey Pools to manage the license keys from MyF5 and need to import large lists of the license keys.

Important: This process activates all the license keys. This initiates the usage for the FCP, even if the license keys aren't assigned to a BIG-IP VE.

Recommended Actions

  1. Generate the keys from My F5
    • Generate Self Service license keys in MyF5
  2. Build a comma separated value (CSV) file with these keys
    • Plain text document, no header row, one license key per row, saved as .csv
  3. Create a RegKey pool for each type of license key, for example, LTM-1GB, BestBundle-5GB, etc.
    • BIG-IQ > Devices tab > License Management > Licenses > Add RegKey
  4. Import the CSV file into the RegKey Pool
    • Click into the RegKey Pool: BIG-IQ > Devices tab > License Management > Licenses > [RegKey pool name]
    • Click the "Import CSV" button
    • Accept the EULA
