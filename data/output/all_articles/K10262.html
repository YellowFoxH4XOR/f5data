Topic

This article applies to BIG-IP 10.x. For information about other versions, refer to the following article:

  • K13156: SSL ciphers used in the default SSL profiles (11.x - 13.x)

The default Client SSL and Server SSL profiles use a different set of SSL ciphers depending on the software version you are running.

BIG-IP 10.2.3 through 10.2.4

The default Client and Server SSL profiles in BIG-IP LTM 10.2.3 - 10.2.4 allow ciphers from the native SSL stack. The following table lists the ciphers used in the default Client and Server SSL profiles in BIG-IP 10.2.3 - 10.2.4:

Cipher SuitesBitsProtocolsKey ExchangeAuthenticationCipherMAC
RC4-SHA128SSL3, TLS1.0, TLS1.2RSARSARC4SHA
AES128-SHA128SSL3, TLS1.0, TLS1.2, DTLS1RSARSAAESSHA
AES256-SHA256SSL3, TLS1.0, TLS1.2, DTLS1RSARSAAESSHA
DES-CBC3-SHA192SSL3, TLS1.0, TLS1.2, DTLS1RSARSADESSHA
AES128-SHA256128TLS1.2RSARSAAESSHA256
AES256-SHA256256TLS1.2RSARSAAESSHA256

BIG-IP 10.2.0 through 10.2.2

The default Client and Server SSL profiles in BIG-IP LTM 10.2.0 - 10.2.2 allow ciphers from both the native and compat SSL stacks. The following table lists the ciphers used in the default Client and Server SSL profiles in BIG-IP 10.2.0 - 10.2.2:

Note: Starting in BIG-IP 10.2.0, the default BIG-IP SSL profiles no longer include DES-CBC-SHA and ciphers containing the MD5 hash. For more information, refer to K11624: The default BIG-IP SSL profiles no longer include DES-CBC-SHA and ciphers containing the MD5 hash.

Cipher SuitesBitsProtocolsKey ExchangeAuthenticationCipherMAC
RC4-SHA128SSL3, TLS1.0RSARSARC4SHA
AES128-SHA128SSL3, TLS1.0, DTLS1RSARSAAESSHA
AES256-SHA256SSL3, TLS1.0, DTLS1RSARSAAESSHA
DES-CBC3-SHA192SSL3, TLS1.0, DTLS1RSARSADESSHA
