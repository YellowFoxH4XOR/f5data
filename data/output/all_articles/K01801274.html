K01801274: Viewing ASM Security graphs on BIG-IQ not displaying in Monitoring-> Dashboard-> Web Application

Type
Support Solution
Published
2021-06-09
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K01801274

Description

When a BIG-IQ user accesses Monitoring-> Dashboard-> Web Application Security the graphs are empty
The AppIQ log files has the following warning messages when accessing the particular dashboard:

2020-12-24 17:26:09,789 WARN c.f.a.c.c.F5_RESTController [XNIO-2 task-1] msg='TEMPLATE_MALFORMED: Invalid Security Data Query.', code=1, restOperationId=4c4e5e82-8397-45e5-a3af-6cf3dd9227a5, errorStack=[]

This issue is observed when BIG-IQ deployment with at least one DCD and one BIG-IP with LTM and ASM provisioned and imported into the BIG-IQ

Environment

  • BIG-IQ  
  • DCD - Data Collective Device
  • BIG-IP LTM and ASM provisioned 

Cause

AppIQ data is corrupt causing query failure as evident in the log messages in AppIQ

Recommended Actions

Follow the below steps to recover analytics on BIG-IQ:
  1. Clear data on CM
    # clear-appiq-data
     
  2. While this is running, they'll be asked to stop appiqagent on each DCD: on all DCD's stop the agent. 
    # bigstart stop appiqagent
     
  3. After the command on CM finishes, start appiq agent on all DCDs:
    # bigstart start appiqagent

Note: The above command will reset the analytics (statistics collection) settings on BIG-IQ. It doesn't affect ASM request log collection.
