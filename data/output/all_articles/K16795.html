Known Issue

Loading a user configuration set (UCS) with the no-license option may merge the trunk configurations of both the UCS and the currently running configuration.

Note: Prior to BIG-IP 11.x, the no-license option was referred to as the rma option.

This issue occurs when all of the following conditions are met:

  • The BIG-IP configuration that you are currently running contains a trunk with multiple associated interfaces.
  • You load a UCS that has a trunk configuration with the same name as the running configuration, but different associated interfaces.

Impact

Trunk configurations will have associated interfaces from both the UCS and running configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When viewing the current trunk configuration, you notice that the associated interfaces are not correct.

Workaround

To work around this issue, you can either restore the configuration to the factory default settings or force the mcpd process to reload the configuration prior to installing the UCS. To do so, perform one of the following procedures:

Restoring the BIG-IP configuration to factory default settings

Impact of workaround: Restoring the BIG-IP system configuration disrupts traffic processing and should only be performed during a maintenance window.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Restore the BIG-IP configuration to factory default settings by typing the following command:

    load sys config default
  3. To load the UCS file by using the no-license option, use the following command syntax:

    load sys ucs <name> no-license

    For example, to load a UCS named example.ucs, type the following command:

    load sys ucs example.ucs no-license
  4. To save the configuration, type the following command:

    save sys config
  5. To exit the tmsh utility, type the following command:

    quit

Forcing the mcpd process to reload the BIG-IP configuration

Impact of workaround: Rebooting the BIG-IP system disrupts traffic processing and should only be performed during a maintenance window.

  1. Log in to the command line of the BIG-IP system.
  2. Force the mcpd process to reload the configuration by typing the following command:

    touch /service/mcpd/forceload
  3. Reboot the BIG-IP system by typing the following command:

    reboot
  4. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  5. To load the UCS file by using the no-license option, use the following command syntax:

    load sys ucs <name> no-license

    For example, to load a UCS named example.ucs, type the following command:

    load sys ucs example.ucs no-license
  6. To save the configuration, type the following command:

    save sys config
  7. To exit the tmsh utility, type the following command:

    quit
