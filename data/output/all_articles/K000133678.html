K000133678: NJS/JS and other non-NGINX config files do not appear in NIM config views

Type
Support Solution
Published
2023-04-26
Updated
2023-04-26
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.9.1
Source
https://my.f5.com/manage/s/article/K000133678

Description

NJS files deployed on NGINX instances do not appear in Instance Manager: Instances -> Instance Config view.

Environment

NIM

Cause

NMS Agent reports config files specified by the NGINX include directive which does not include NJS/JS files.

Recommended Actions

None

Additional Information

F5 is working to enhance this feature and allow non-config files, such as NJS/JS files, to be maintained via Instance Manager config views
