K000156908: F5OS SSH Key-based auth for non-root accounts with superuser role

Type
Support Solution
Published
2025-10-07
Updated
2026-05-13
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000156908

Description

Enabling SSH key-based authentication for a non-root user account with administrator and superuser roles on an F5OS system to allow this privileged account to use public/private key authentication for SSH access, rather than password-based login.

Environment

User Account Role: Primary role – administrator; Secondary role – superuser (bash-level privileges)

Cause

None.

Recommended Actions

To enable SSH key-based authentication for a non-root user (with administrator/superuser roles) on F5OS:

Login to the CLI and enter the 'config' mode using that command. The prompt will change to (config)#.

Use the following command structure in the F5OS CLI:

system aaa authentication users user <username> config authorized-keys

Add the desired public SSH key(s) within this configuration context.

Save and apply changes as per standard operational procedures.

None.
