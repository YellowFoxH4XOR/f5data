K000132896: Syslog data is not been send to syslog server

Type
Support Solution
Published
2023-08-30
Updated
2023-08-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.4
Source
https://my.f5.com/manage/s/article/K000132896

Description

BIG-IP is sending the logs to the remote server but they are not been seen at the syslog server end.

Environment

  • BIG-IP
  • QRadar Syslog server

Cause

QRadar server was listening for the incorrect IP of BIG-IP.

 Recommended Actions

Verifying that incorrect source address is used

1.When the destination syslog server does not receive log, check the netstat command output carefully for the syslog server IP address in BIG-IP CLI as shown below : 

    • netstat -pan | grep syslog

The incorrect source IP address is being used (management address is used instead of TMM address, and vice versa):
udp   0   0   <incorrect_source_ip>:<random source-port>   <Syslog-server-IP>:514   ESTABLISHED <pid>/syslog-ng

2. We can also find the source IP address by running a packet capture using tcpdump.

  • tcpdump -vvv -s0 -nni 0.0:nnnp -w /var/tmp/syslog.pcap udp port 514 -- will capture the logs in pcap file & need to use Wireshark or similar tool to analyze.
  • tcpdump -ni 0.0 udp port 514 -- will display the traffic live in CLI.

3. Update the correct IP to be monitored in QRadar Syslog server.
