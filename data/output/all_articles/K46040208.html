Description

To install BIG-IP Edge Client on Ubuntu, you will need to download and install the f5fpc installation file on your client device. 

If you are a BIG-IP APM VPN user, you cannot download the f5fpc installation file from the AskF5 site. Your organization's BIG-IP APM system administrator uses the procedure in this article to download the f5fpc installation file from the BIG-IP APM system and distribute it to VPN end users. Please consult your IT department for more information.

For BIG-IP APM administrators, refer to the Recommended Actions section.

Environment

  • Ubuntu
  • Edge Client
  • BIG-IP APM

Cause

None

Recommended Actions

APM supports two command line Linux clients.

Depending on whether you are a VPN administrator of VPN user, refer to the appropriate sections in the following article, using the dpkg command for Debian based distributions:
