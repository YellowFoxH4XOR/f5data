Description

Configuration of AFM profile contains  custom values set up for Detection Threshold % :

  1. On BigIP, navigate to "Security  ››  DoS Protection : Device Protection"
  2. Search for "Single Endpoint Flood" and edit its "Detection Threshold %" properties from the default value of "infinite" to a custom value (say 300).
  3. On BigIQ, rediscover/reimport the AFM config of the affected BigIP, the reported error occurs:

AFM import  to BIG-IQ CM is failing with error

Validation failure: java.lang.IllegalArgumentException: The DoS Device vector Single Endpoint Flood(Single Endpoint) : Detection Threshold Percent (500) must be null, N/A or infinite

Environment

  • BIG-IQ Centralized Management
  • BIG-IP AFM above version 14.1.4.4
  • AFM Configuration import 
  • DoS Protection : Device Protection Detection Threshold % changed from infinite to custom value

Cause

'Detection Threshold %' configuration parameter support for 'Single Endpoint Sweep', 'Single Endpoint Flood' attack Types are newly added on BIG-IP from 14.1.4.4.
BIG-IQ is not supporting this in current releases. ID1070513 is tracking this behaviour.



Recommended Actions

Only Workaround is available to  import  AFM service to BIG-IQ:
  1. On BIG-IP change Detection Threshold % to default
  2. Rediscover and reimport configuration
  3. Set values for  Detection Threshold %  to the one which were previously set up
