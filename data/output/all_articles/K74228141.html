K74228141: Remove configDiff files from UCS when it is causing Big-IQ to fail backups

Type
Support Solution
Published
2023-03-22
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K74228141

Description

BIG-IQ scheduled backups fail with the below message:

Saving active configuration... tar: config/.diffVersions/config/bigip_base.conf/2503.patch: Cannot stat: No such file or directory tar: Exiting with failure status due to previous errors Fatal: executing: tar --no-recursion -rf /var/tmp/im14564/configsync-2.0-1-Linux-3.10.0862.14.4.7.8664.im --no-unquote --files-from=/var/tmp/im.23444/Files Operation aborted. /var/tmp/configsync.spec: Error creating package WARNING:There are error(s) during saving. Not everything was saved. Be very careful when using this saved file! Error creating package Error during config save. Unexpected Error: UCS saving process failed.
 

Environment

  • BIG-IQ attempting backups

Cause

This can be caused by files in either /config/.diffVersions or /config/.config.backup

Recommended Actions

Following the instructions in K4422 add the below lines to the cs.dat file to exclude these directories.

Note: There should be no empty space between the existing lines and the lines below.

save.2007.ignore = (/config/\.diffVersions/*)
save.2008.ignore = (/config/\.config\.backup/*)

None
