K000092484: How to avoid Split Brain when HA link fails

Type
Support Solution
Published
2022-10-22
Updated
2023-01-13
Source
https://my.f5.com/manage/s/article/K000092484

Description

Use this best practice of configuration to avoid split brain or unintended Active-Active state between HA devices.
 

Environment

  • BIG-IP LTM HA pair
  • Network failover configured
  • No hardwired failover
  • Failover cable


Cause

BIG-IP Active/Active state between HA devices due to HA link failure (network failover heartbeat communication failure).


Recommended Actions

  1. Device runs the latest stable version of your current software family.
  2. Setup a VLAN dedicated to carry HA traffic. If possible, connect the HA interfaces in a back-to-back connection type
  3. Configure your config-sync to use the HA VLAN
  4. Configure your "Network Failover" using the HA VLAN IP addresses and also the Management IPs addresses
  5. If using mirroring, use dedicated channels/VLANs for each group used. Use a back-to-back connection when possible.
Note: When split brain happened during HA link failure you may consider to Force Offline one of the BIG-IP and fix the connectivity issue.
