Get started with search

To search Bug Tracker, enter a few descriptive words in the search box and select the Search icon (magnifying glass).

Note: You can use Boolean operators (AND, OR, NOT, and NEAR) to perform advanced searches.

Your search results appear with two icons alongside each result title. The bottom icon (the eye) is a Quick View icon.

Use Quick View

Select the Quick View icon to open the Quick View page for that document. At the top of the Quick View page, your search terms are listed, including a figure indicating the number of times each term appears in the document.

Note: This includes all terms you included in your search, including common words, such as how, in, and to.

To locate the search terms in the article, select the arrows next to the search terms. All of the search terms in the article are highlighted and color-coded.

Filter your search

On the search results page, you can refine your results using the Product Family filter.

Items within the filter are initially sorted by the numbers of results that match your search and filter criteria, which appear next to each product or criteria.

Use the Product Family and Product/Module filters

Start filtering your search with the Product Family filter. You can select only one product at a time in the Product Family filter. Then, you can use the Product/Module filter to narrow your search by selecting specific products, modules, or topics.

Note: For a full list of available product and topic filters for BIG-IP and BIG-IQ searches, refer to K10134038: F5 Bug Tracker filter names and tips.

For example, if you want to view results that apply to only the BIG-IP LTM system, select the BIG-IP LTM check box. Note that the name of the product family, module, or topic you select appears at the top of the results list.

Use the Version filter

After you select your product family, the Version filter appears. You can further filter your search and select only versions you want to include in your search.

The filter displays minor release versions that have results matching your search. Select the down arrow to the left of the minor release version number to expand the list to view relevant, subsequent maintenance, and point release version numbers.

Selecting a minor release number automatically selects all subsequent release numbers. You can also individually select one or more subsequent release numbers when the minor release check box is clear.

After you select your items, a plus sign (+) appears next to the numbers for all unselected items, indicating the number of additional results that will appear if you select that item. Note that the versions you select appear at the top of the results list.

Use the Severity and Vulnerability filters

After you select your product family, the Severity and Vulnerability filters appear. You can further filter your search by selecting specific severity and vulnerability levels to include in your search.

After you select severity or vulnerability levels, a plus sign (+) appears next to the numbers for all unselected items, indicating the number of additional results that will appear if you select that item. Note that the severity or vulnerability levels you select appear at the top of the results list.

Use the Bug State filter

After you select your product family, the Bug State filter appears. You can further filter your search by selecting Fixed or Unresolved. Note that the state you select appears at the top of the results list.

Manage your search filters

Each filter has both a Clear and a Settings icon. To clear selections in the filters, select the X at the top of the filter.

The Settings icon (a row of three dots in a circle) allows you to sort items within each filter by Occurrences or Score.

Use Occurrences

By default, items in each filter are sorted by Occurrences, which refers to the number of results that match that item.

Use Score

Selecting Score sorts the items in each filter by relevance. For example, an item with 10 occurrences appears ahead of an item with 100 occurrences if the item with 10 occurrences is more relevant.

Expand and collapse filter items

You can collapse or expand the items that appear in each filter by selecting the arrow next to Collapse or Expand in Settings.

If you want to see more items than are currently displayed in the filter, select the down arrow at the bottom of each filter. The list further expands each time you select the arrow. To restore the original list, select the up arrow.

Remove filter selections from outside the filter

At the top of the results list, you can remove the products and content types that you have selected by selecting the X next to each name.

At the top of the results list, to clear selections in all filters, select Clear All Filters.

Export your search results

After you have obtained the search results you can export the results, including links to the Bug Tracker bug IDs.

Export search results to Excel

At the top of the search results page, select the ellipsis and select Export to Excel.

General search guidelines

Capitalization

Searches are not case sensitive. All letters, regardless of how you enter them, are processed as lowercase. For example, searches for TCP, Tcp, and tcp return the same results.

Note: Boolean operators (AND, OR, NOT, and NEAR) are exceptions to this rule. You should enter these operators in all caps. 

Phrase searches

You can search for an exact phrase by enclosing the phrase in quotation marks ("). The search engine returns only documents that include the exact phrase you entered.

Note: Make sure you always use quotation marks (“) when performing a phrase search.

For example:

"Error getting auth token from login provider"
