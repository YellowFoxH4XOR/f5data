Description

Linux utilizes two devices: /dev/random and /dev/urandom for the kernel's random number generator. These devices are seeded by an entropy pool that gathers environmental noise from device drivers and other sources. 

One of the many uses of the random number generator is in its use to create cryptographic keys, in the event the entropy pool is depleted, it is not possible to create further keys until entropy pool is refilled.

In situations that might lead to an entropy starved situation in which multiple crypto creation or other processes require use of a random number generator causing a depletion of the entropy pool, the jitterentropy-rngd process can be used to replenish the entropy pool.

The jitterentropy-mgd is an entropy source that directly feeds into the /dev/random device if the entropy pool runs low. 

The jitterentropy-rngd process is started at boot time by the systemd process and does not require any user input.
