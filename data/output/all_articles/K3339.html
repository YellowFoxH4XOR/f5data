K3339: Restoring backup files on a different FirePass unit than they originated on

Topic

FirePass backup files may be restored on a different FirePass controller than was used to create the backup file, with the following limitations and conditions.

FirePass software version limitations and conditions

With one exception, a backup must always be restored on the same version of FirePass software that was used to create the backup. By default, the FirePass controller includes the version number in the name of its backup files so that the version used to take the backup can be easily identified. F5 recommends using the version in any naming nomenclature used by your organization for FirePass controller backup files. However, a backup taken on a FirePass controller running version 4.1.1 may be restored on a system running version 5.0.0 (as long as no hotfixes have been applied to the FirePass controller running version 5.0.0).

Additionally, a backup should be restored to a system with the same hotfixes applied as when the backup was taken. In FirePass software versions prior to version 6.0.1, the restore program prohibited restoring a backup file with different hotfixes from the target system. Attempting this operation would generate an error message in the Administrative Console, and the restore operation would terminate. Beginning in FirePass software version 6.0.1, it is now possible to restore a backup to a target system that has different hotfixes from the system on which the backup was taken. If any hotfixes are required, the FirePass will indicate which hotfix is a prerequisite for performing the restore. However, F5 recommends installing the same hotfixes on the target system, if possible.

FirePass hardware limitations and conditions

With one exception, a full restore of the configuration must always be restored on the same type of FirePass hardware that was used to create the backup. This is because backups would include hardware-specific configuration that could be incompatible with a different hardware platform. However, a backup taken on a FirePass 4100 running version 6.0.2 may be restored to a FirePass 4300 running version 6.0.2 if cumulative hotfix HF-602-3 or a later version of the cumulative hotfix is installed on both systems.

Beginning in FirePass software version 5.2.0, backups can restore only Users and Groups settings, rather than the entire configuration which would include hardware-specific configuration. This allows transfer of user and group settings between different FirePass hardware platforms. When performing the restore, the administrator selects the Restore Users and Groups Settings check box only. If the restore target is a different hardware platform than the system that generated the backup, a warning message will appear in the Administrative Console during the restore, indicating that only Users and Groups can be restored, but not Networking configuration.

If you have restored a backup file that does not conform to these conditions, contact F5 Technical Support immediately for further assistance.
