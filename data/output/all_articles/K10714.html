Known Issue

If you attempt to reboot the BIG-IP WebAccelerator running on the 4500 platform by clicking Reboot in the Properties and Operations section of the System > Configuration > Device screen, the system displays the following message:

"Please wait while this BIG-IP device reboots..."

However, users logged into the command line receive no message indicating a reboot was requested, and the system never reboots.

F5 Product Development tracked this issue as CR123438 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Workaround

You can work around this issue by rebooting the system from the BIG-IP command line. To do so, type the following command:

reboot

The reboot process may take several minutes, and load balanced traffic may be disrupted.
