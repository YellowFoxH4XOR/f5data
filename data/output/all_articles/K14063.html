Known Issue

The snmp_dca monitor does not set the dynamic-ratio weight for nodes.

This issue occurs when all of the following conditions are met:

  • There is a pool with dynamic ratio load balancing.
  • There is a node using the snmp_dca monitor.

While the snmp_dca monitor correctly queries the node for statistics, the monitor does not update the dynamic-ratio weight for the pool members with the information that was returned.

Impact

Traffic is not dynamically load balanced across the pool members.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When viewing the node configuration using the tmsh command, there is no dynamic-ratio value listed for the node:

    # tmsh list /ltm node <node_name>
    ltm node <node_name>{
    address 10.1.1.1
    monitor snmp_dca
    session monitor-enabled
    state up
    }

  • The node name is reported as null in the /var/tmp/snmpdca.log file:

    ========== /usr/share/monitors/SNMPDCA_monitor ==========
    Node Name: (null)

    Note: Monitor logging for the snmp_dca and snmp_dca_base is not enabled by default. To enable monitor logging for the snmp_dca and snmp_dca_base monitors, refer to K6529: Enabling and disabling monitor logging for the snmp_dca and snmp_dca_base monitors.
