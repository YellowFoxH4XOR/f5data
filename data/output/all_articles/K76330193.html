K76330193: BIG-IP ASM violation: Access from disallowed User/Session/IP/Device ID

Applies to

Topic

You can configure the BIG-IP ASM Session Tracking feature to have the system track information about user names, sessions, device IDs, and IP addresses that attempt to access the application and then issue an alert and block requests when it detects a violation.

Description

You can enable Session Tracking for a BIG-IP ASM security policy and specify how the system tracks application user names. You can also configure the system to track violations and perform actions based on the number of violations for a user name, session, or IP address. When you configure violation detection actions, the system logs or blocks the activity causing the violations.

The Session Tracking feature works as follows:

  1. A client attempts to log in to the web application.
  2. The BIG-IP ASM system uses JavaScript to gather information about the client and create a unique device ID.
  3. The BIG-IP ASM system embeds the device ID in a BIG-IP ASM cookie and returns the response to the client.
  4. For subsequent HTTP requests in the session, the BIG-IP ASM system issues a challenge to test the validity of the device ID.
  5. If the system detects that the number of violations from the same user name, session, IP address, or device ID exceeds the configured threshold within a specified time frame, the system issues the following violation to the event logs:

    Access from disallowed User/Session/IP/Device ID
