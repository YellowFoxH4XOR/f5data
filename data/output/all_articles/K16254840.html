K16254840: Traceroute not working via External Interface while working in Management Interface

Type
Support Solution
Published
2020-03-04
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.X, 15.0.1, 15.0.0, 14.1.5, 14.1.4, 15.0.X, 14.1.2, 14.1.0, 14.1.3
Source
https://my.f5.com/manage/s/article/K16254840

Description

Traceroute from the Big-IP using the tmm interface time out or only shows one hop away while sending probing packets from the Big-IP. 
Traceroute using Management works fine. 
Upstream firewall in the Network Topology may not show incoming service as traceroute (UDP) from the Big-IP's self-ip. 

 

Environment

  • Big-IP
  • 14.1.x, 15.0.x. 
     

Cause

Bug 797977
The Egress traffic from TMM has IP TTL set to 255 instead of keeping the TTL from the Linux host. Self-IP traffic does not preserve the TTL from the Linux host.
Note: If you have AFM provisioned, see Related Content below.


Recommended Actions

  1. If using SNAT, the only option is to upgrade to version 15.1.0
  2. If not using SNAT, F5 Support can provide an Engineering Hot Fix upon request.
