Known Issue

A ConfigSync operation will fail if the ConfigSync user's password exceeds 29 characters.

The maximum password length is 32 characters. However, only 29 of the 32 characters are available for a user to set their password. The three additional characters are used as padding by the encryption algorithm. The formula is 29 password characters, plus three additional padding characters inserted when the password is encrypted by the system.

Impact

The configuration will not be synchronized to the peer system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The ConfigSync operation will fail with error messages similar to the following:

    Synchronizing Master Keys...
    Saving active configuration...
    SOAPException: 'Unexpected return code: 401 F5 Authorization Required'

    Authorization failure. Make sure user ID and password are correct.
    Transport and install failed
    Error running config sync all.
    BIGpipe parsing error:
    01110001:3: Error running config sync all

Resolution

Status

Note: The password length limitation was increased to 128 characters for BIG-IP 11.x.

Workaround

To work around this issue, you must limit the ConfigSync user's password to 29 characters or less.

Impact of workaround: None
