Known Issue

Description

If the ARX system is unable to identify the proxy-user credentials when performing a function, the system displays a non-descriptive REPL_CRED_NOT_FOUND error message. The error indicates that config-replication credentials were not found, rather than clearly indicating that proxy-user credentials were not found.

This issue occurs when any of the following conditions are met:

  • A share is enabled for a namespace without a configured proxy user.
  • A non-existent proxy-user name is used for a command that specifies a proxy user.

Impact

The error message does not indicate the actual cause of failure.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When attempting to enable a share for a namespace without a configured proxy-user, the share enable will fail with the following error message:

    % ERROR: REPL_CREDS_NOT_FOUND (40829026):
      Config-replication credentials not found for ''.
  • When specifying a non-existent proxy-user for a command using a specified proxy-user, the command will fail with the following error message, where xxx is replaced with the proxy-user name specified in the command:

    % ERROR: REPL_CREDS_NOT_FOUND (40829026):
      Config-replication credentials not found for 'xxx'.

    For example, the show exports external-filer filer1 proxy-user joe command would fail with the following error message:

    % ERROR: REPL_CREDS_NOT_FOUND (40829026):
      Config-replication credentials not found for 'joe'.

% ERROR: REPL_CREDS_NOT_FOUND (40829027): Proxy-user credentials not found for 'xxx'.
