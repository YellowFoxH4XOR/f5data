Description

HA failover of vCMP guests on Viprion blades 2150 or 2250 

  • Random failover with no known cause
  • Device stops processing traffic and LACP trunks go down
  • CMP state changes for Host and vCMP guests
  • See error messages in /var/log/ltm logs similar to below messages:
info bcm56xxd[14842]: 012c0012:6: Trunk XXXX member mod 1 port 3 slot 0; CMP state changed from 0x5 to 0x1
info bcm56xxd[14842]: 012c0012:6: FFP VHDAG installed for BIG-IP(cmp state 0x1, v-cmp state 0x1)
err bcm56xxd[14842]: 012c0011:3: action Redirect Trunk failed: SDK error Invalid port bs_field.cpp(924)
err bcm56xxd[14842]: 012c0011:3: program SP based dest trunk rule failed: SDK error Invalid port bs_vtrunk.cpp(5328)

Environment

  • Viprion with either 2150 or 2250 blades

Cause 

  • This happens when using 2150 or 2250 blades and an internal FPGA device gets into a bad state under heavy traffic load.

BugID 638089

Recommended Actions

To determine if the issue is resolved, refer to the Fixed In versions of the related BugID 638089.

Additional Information

Please refer to K11333: Using the clsh command to restart or shut down one or more blades in a VIPRION system should the work around of rebooting the blades be necessary.
