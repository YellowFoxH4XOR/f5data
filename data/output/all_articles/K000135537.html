Environment

  • BIG-IQ

Cause

Elasticsearch TLS cluster certificates have expired .

 

Recommended Actions

Use the following command (on the primary CM only) to regenerate the ES certificates for the cluster:

 

# restcurl /cm/shared/esmgmt/cluster-ssl-task -d '{"enable":true,"regenerateCertificates":true}'

 

Additional Information

This task expects that all devices in the ES cluster are communicating normally. It may fail if some devices are missing.
