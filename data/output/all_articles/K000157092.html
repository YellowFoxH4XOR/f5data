K000157092: NTLM Machine Account Password Handling and Security on F5 BIG-IP APM

Type
Support Solution
Published
2025-10-22
Updated
2025-10-22
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000157092

Description

When using NTLM authentication with F5 BIG-IP APM, the system automatically creates a machine account (computer object) in Active Directory using provided administrative credentials. Sometimes, AD management tools or security scans may report that this machine account has a "none" or "null" password, which can raise concerns about its security.


Environment

  • NTLM Authentication
  • On DC, machine account has a "none" or "null" password


Cause

The appearance of a missing password for the NTLM machine account in AD management tools is expected and does not indicate a security risk:

Windows stores computer/machine account passwords in the unicodePwd attribute, which is not visible through standard AD user interfaces.

The password for this account is set by BIG-IP to a strong, random value and stored internally on the BIG-IP device.

If AD tools display "none" or "null" for the password field, it does not mean that the account is unsecured; it simply means that the password is not accessible or displayed here.


Recommended Actions

  • Do not manually set or change the password for this NTLM machine account in Active Directory. Changing the password directly in AD will break communication between BIG-IP and AD, resulting in authentication failures.
  • No further configuration changes are required to secure this machine account; its password is managed securely by BIG-IP and remains hidden from AD users and administrators.
