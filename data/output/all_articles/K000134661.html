K000134661: Problem Enabling App-Protect or App-Protect-DoS as part of Nginx Ingress Controller Deployment

Type
Support Solution
Published
2023-05-18
Updated
2025-09-25
Applies to
  • NGINX Products
  • NGINX Ingress Controller: 3.0.0, 3.0.2, 3.0.1, 3.X.X, 3.1.X, 3.1.0, 3.0.X
Source
https://my.f5.com/manage/s/article/K000134661

Description

  • You provisioned your Kubernetes cluster and are about to install Nginx-Plus Ingress Controller 
  • As part of this deployment, you want to enable Nginx App-Protect[NAP] either by setting Helm configurable parameters -enable-app-protect=true or simply enabling support for App Protect from deployment manifest using command -enable-app-protect
  • However, Nginx ingress controller deployment fails with the below error 
      I0427 09:22:00.921287 1 main.go:380] Using nginx version: nginx/1.23.2 (nginx-plus-r28)
      I0427 09:22:00.948631 1 main.go:776] Pod label updated: ingress-plus-nginx-ingress-controller-c12345679f-jk7qk
      F0427 09:22:00.953186 1 manager.go:467] Failed to set log level for AppProtect: exit status 127

Environment

  • NGINX App-Protect
  • NGINX App Protect DoS
  • Nginx Ingress Controller
  • Kubernetes

Cause

  • Nginx Plus ingress image by iteslf, by default, does not include Nginx App Protect module.
  • And enabling NAP logging while this module missing, results in the above mentioned error along with the failure of the deployment.

Recommended Actions

  • In order to be able to use App Protect along with NGINX Plus Ingress Controller, one needs to use
    • either a pre built image from F5 Container registry
    • or build the image yourself following article "Installation with NGINX App Protect WAF"
  • You can also check this article for further details on how to build Ingress Controller image with NAP by referring article "Building the Ingress Controller Image"
  • With the image built, you can now enable NAP as part of your deployment.

Additional Information

  • There are two separate images that reflect App Protect products 
    • NGINX Ingress Controller with NGINX App Protect WAF  
    • NGINX App Protect DoS 
  • And a third that combines the above two products
    • NGINX Ingress Controller with with NGINX App Protect WAF and DoS
