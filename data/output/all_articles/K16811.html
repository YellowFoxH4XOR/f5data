Known Issue

Secure Sockets Layer (SSL) virtual servers using the Proxy SSL feature may cause the Traffic Management Microkernel (TMM) to produce a core file.

This issue occurs when the following condition is met:

  • Both Proxy SSL and Proxy SSL Passthrough are enabled for the SSL profile.

Impact

The BIG-IP system may temporarily fail to process traffic and fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process restarts and produces a core file in the /var/core directory.
  • The BIG-IP system temporarily fails to process traffic and fails over to the peer device.
  • The BIG-IP system logs errors to the /var/log/ltm file that appear similar to the following example:

    err tmm3[27723]: 01260014:3: Cipher 39:5 negotiated is not configured in profile /Common/serverssl.
