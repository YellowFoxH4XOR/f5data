Known Issue

This is the result of a known issue. The BIG-IP system does not log an error message when the TM.MaxRejectRate threshold is exceeded for TCP or ICMP.

When the TM.MaxRejectRate threshold has been exceeded for TCP, the BIG-IP system should log a message to the /var/log/ltm file that appears similar to the following example:

tmm tmm[1609]: 011e0001:4: Limiting closed port RST response from 299 to 250 packets/sec

In addition, when the TM.MaxRejectRate threshold has been exceeded for ICMP, the BIG-IP system should log a message to the /var/log/ltm file that appears similar to the following example:

tmm tmm[1609]: 011e0001:4: Limiting icmp unreach response from 299 to 250 packets/sec

F5 Product Development tracked this issue as CR129382 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, PSM, WebAccelerator, or WAN Optimization release notes.

Note: For more information about the TM.MaxRejectRate BigDB variable, refer to K9259: Limiting the rate at which the BIG-IP system issues TCP RSTs or ICMP unreachable packets.
