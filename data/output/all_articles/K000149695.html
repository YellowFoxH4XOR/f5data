K000149695: Some SNMP MIBs is not available on F5OS

Type
Support Solution
Published
2025-02-13
Updated
2025-02-21
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000149695

Description

  • You want to use the SNMP to query information from F5OS.
  • However, not all the information is available to retrieve from SNMP. In the F5OS we provide the API to retrieve the system statistics.

Environment

  • F5OS-A
  • F5OS-C
  • SNMP MIBs
  • API on F5OS

Cause

Not all the information is available to retrieve from SNMP. In the F5OS we provide the API to retrieve the system statistics.

Recommended Actions

  • Using API call instead of the SNMP query
  • For example system PSU status, there is no available SNMP MIBs to query from SNMP
  • You can use below command to collect PSU information from API
    • Single query

curl -k https://<ip_address>:8888/restconf/data/openconfig-platform:components/component=psu-1 -u <username>:<password>

    • Multiple query you can use regex

curl -k https://<ip_address>:8888/restconf/data/openconfig-platform:components/component=psu-[1-4] -u <username>:<password>
