Issue

F5 Product Development has discovered a rare DMA engine issue that may occur if the Cavium Nitrox SSL accelerator card has been installed in a PCI slot configured to 133Mhz.

No functional failures are associated with this issue.

Note: The Cavium Nitrox SSL accelerator card running in the 100Mhz will not experience this issue.

BIG-IP systems affected by this issue receive the following error messages:

01010025:2: Device failure: cn0: PCI SERR

01010025:2: Device failure: cn0: PCI write master parity

F5 has determined that some 3400 and 6400 platforms were shipped with a PCI slot set to 133Mhz.

F5 Product Development tracked this issue as CR47310 and it was fixed in manufacturing.
