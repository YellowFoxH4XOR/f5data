Description

Options regarding encrypting Layer 7 (HTTP) traffic for Client and/or Server side connections.

Essentially there are 5 flows involving SSL that can be configured (Note: the below chart is meant to convey where SSL Termination occurs):

          Client-Side(client<-> BIG-IP)                      Server-Side(BIG-IP <-> Server) F5 Term used to describe

  1. HTTPS --> HTTPS                                          HTTPS --> HTTPS               <SSL bridging>
  2. HTTPS -------------------------------------------------> HTTPS                         <SSL passthrough>
  3. HTTPS --> HTTPS                                          HTTP --> HTTP                 <SSL offload>
  4. HTTP  --> HTTP                                           HTTPS --> HTTPS               <no formal name> Note: very rarely used, not recommended
  5. combination of
  • HTTPS --------------------------------------------> HTTPS for authentication only
  • HTTPS --> HTTPS                                     HTTPS --> HTTPS              <Proxy SSL> see K13385: Overview of the Proxy SSL feature>

Environment

BIG-IP Virtual Server

Cause

Design. For a detailed explanation of packet flow in the BIG-IP see K8082: Overview of TCP connection setup for BIG-IP LTM virtual server types and BIG-IP Life of A Packet

Recommended Actions

Configure clientssl and/or serverssl profiles to achieve your desired flow per K65271370: Most Common SSL Methods for LTM: SSL Offload, SSL Pass-Through and Full SSL Proxy and  K14343463: Configuring the BIG-IP system to pass through SSL traffic
or
Configure proxyssl per K13385: Overview of the Proxy SSL feature
