Description

The following article will help recover an ADFS Proxy service that suddenly stopped working with no apparent changes.
ADFS Proxy trust is established successfully but no requests can pass the Virtual Server.
Virtual Server is answering with a 404 response code and no traffic is initiated with the server side.

Environment

Virtual Server with ADFS Proxy enabled.

Cause

The cause is unknown yet.
Please follow recommended actions if you happen to be in such situation.

Recommended Actions

  1. Edit the default-log-setting log profile and switch ADFS Proxy log level from Notice to Debug
  2. Start sending some traffic through the Virtual Server
  3. Start strace command on the BIG-IP command line (and still attempt to send traffic through the VS):

/bin/strace -xf -tt -p `pidof adfs_proxy` -o /var/tmp/strace_adfs_proxy.txt

  1. Wait several minutes then ctrl-c to end strace
  2. core adfs_proxy:

kill -6 `pidof adfs_proxy`

  1. Collect a qkview:

qkview -s0

  1. Edit the default-log-setting log profile and switch ADFS Proxy log level from Debug to Notice
  2. Restart ADFS Proxy service to fix the issue:

tmsh restart sys service adfs_proxy

  1. Create a support case and provide the collected data
