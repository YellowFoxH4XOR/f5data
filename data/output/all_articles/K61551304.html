Description
The Reactivate button is missing from System -> License page of the Configuration utility of the vCMP guest.

Environment

  • BIG-IP
  • vCMP host and guest
  • Licensing

Cause
You are attempting to reactivate the license on a vCMP guest rather than a vCMP host. vCMP guests inherit the license from the vCMP host. The host license must include all BIG-IP modules that you plan to provision on vCMP guest instances.

Recommended Actions

Reactivate the license from the vCMP host and not the vCMP guest. This can be done either via Automatic or Manual method. You can use Automatic method if you have configured the BIG-IP management port to route traffic to the Internet, otherwise use Manual.

Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

Activating the license using the automatic activation method
  1. Log in to the Configuration utility of the vCMP host using an account with the administrator role.
  2. Navigate to System > License and select Reactivate.
  3. Select Automatic and click Next.
  4. The BIG-IP system automatically connects to the F5 License Server and activates the license.
Activating the license using the manual activation method
  1. Log in to the Configuration utility of the vCMP host using an account with the administrator role.
  2. Navigate to System > License and select Reactivate.
  3. Select Manual and click Next.
  4. Copy the dossier and connect to the F5 Product Licensing page at secure.f5.com.
  5. On the F5 Licensing Tools page, select Activate F5 product registration key for BIG-IP 9.x and later.
  6. Paste the dossier into the Enter Your Dossier box, and then select Next.

    The F5 Product Licensing page produces your license.
     
  7. Copy the license and paste it into the License box in the Configuration utility.
  8. Select Next and wait for configuration to reload.
