Description

Running multiple instances of the 'bigtop' command line utility on BIG-IP LTM can cause sustained high CPU utilization on the control plane, including the mcpd process. The 'bigtop' tool provides real-time, interactive statistics for system objects such as virtual servers and nodes, but is intended for short-term use only. If several bigtop sessions are left running, especially by multiple users, CPU resources may become heavily consumed, impacting system performance and management responsiveness. The top command show output similar to:

Environment

  • CPU
  • Multiple concurrent or long-running bigtop processes
  • Users accessing the system via CLI

Cause

The bigtop utility displays real-time statistics and is not designed to run indefinitely or in multiple concurrent sessions. Multiple running bigtop processes continue to consume CPU resources, leading to high utilization on the control plane.

Recommended Actions

  • Use the 'bigtop' utility only for short-term, interactive monitoring sessions.
  • To identify running bigtop processes, use:
    top -cb | grep bigtop
  • For each identified bigtop process, terminate it using:
    kill -9 <PID>
