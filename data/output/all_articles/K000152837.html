Description

On F5OS-A appliances (such as R2600, R4600), the Always-On Management (AOM) LCD panel provides important system information at a glance. However, the information shown on the AOM can vary depending on the version of the LCD UI firmware installed. This article explains how the AOM display changes with different LCD UI versions, and how to check which version is currently running. 

LCD UI Version and F5OS-A Base OS Version Mapping

  • F5OS-A 1.5.x → LCD UI version 1.11.0
  • F5OS-A 1.7.x, 1.8.x → LCD UI version 1.13.12

The information displayed on the AOM LCD panel is determined by the LCD UI firmware version (no matter what the base F5OS version is):

LCD UI version 1.11.0: The default AOM page displays only the model (e.g., "r2600"). To view details such as HOSTNAME, MGMT IP, and OS version, you must touch the screen and navigate to the System Info page.

LCD UI version 1.13.12: The default AOM page displays more comprehensive information, including HOSTNAME, MGMT IP, and OS version, similar to previous iSeries devices.

The LCD UI version could be upgrade from 1.11.0 to 1.13.12 when F5OS upgrade to 1.5.x to 1.7.x or 1.8.x. However, it does not automatically downgrade when the base OS is downgraded, even performing the clean installation. 

Environment

  • rSeries 
  • AOM

Cause

This behavior is by design. 

Recommended Actions

1. Check the LCD UI version

  • Run the following command to verify the current and target LCD UI firmware version:
    docker exec -it platform-fwu psf call GET:firmware/lcd/ui
  • Output example:
      field                     | value
    ----------------------------+----------
      actionRequiredAfterUpdate | none
      componentLocation         |
      componentSubtype          | ui
      componentType             | lcd
      currentVersion            | 1.13.12
      targetVersion             | 1.11.0
      updatePolicy              | newer
      updateRequired            | false

2. Understand the expected display

  • If the LCD UI version is 1.11.0, expect to see only the model on the default AOM page. Touch the screen for more details.
  • If the LCD UI version is 1.13.12, expect to see HOSTNAME, MGMT IP, and OS version on the default AOM page.
