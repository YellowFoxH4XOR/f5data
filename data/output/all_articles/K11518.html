Known Issue

This is the result of a known issue. If you use the HSL::send iRule command to log binary data, the data is modified before being logged.
 
F5 Product Development tracked this issue as ID 225435 (formerly CR139372) and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.
 
Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0, and in Hotfix-BIGIP-10.2.0-1755.1-HF1 for BIG-IP version 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
