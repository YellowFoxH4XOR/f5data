Known Issue

The BIG-IP system may generate persistence cookies with an incorrectly-formatted value. The part of the cookie that identifies a pool member's port may be invalid for IPv6 pool members.

This issue occurs when all of the following conditions are met:

  • You have a virtual server configured to use a cookie persistence profile, and the cookie persistence profile uses the HTTP Cookie Insert method.
  • The pool contains IPv6 pool members.

When you configure a cookie persistence profile to use the HTTP Cookie Insert method, the BIG-IP system inserts a cookie into the HTTP response. Well-behaved clients will include the cookie in subsequent HTTP requests for the hostname. For subsequent requests, the BIG-IP reads the value of the cookie to determine the pool member's IP address and port, and the BIG-IP system persists the request to the identified pool member. However, as a result of this issue, the port section of the cookie is invalid, which prevents the BIG-IP system from identifying the pool member and persisting the connection. The BIG-IP system will load balance the request instead.

Impact

The BIG-IP system may not persist client connections to IPv6 pool members; the BIG-IP system may load balance the client connections to another server.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system does not persist client connections to pool members, as expected.
  • Client connections may fail.
  • An incorrectly-formatted cookie for an IPv6 pool member appears similar to the following example:

    BIGipServer<pool_name>=vi20010112000000000000000000000030.93896575045632

    A cookie with a valid port value should appear similar to the following example:

    BIGipServer<pool_name>=vi20010112000000000000000000000030.20480

    Note:  The value following the period (.) is the portion of the cookie that identifies the port. The proper encoded value for port 80 is 20480. For information, refer to K6917: Overview of BIG-IP persistence cookie encoding.

  • An incorrectly-formatted cookie for an IPv6 pool member on a non-default route domain appears similar to the following example:

      BIGipServer<pool_name>=rd3o20010112000000000000000000000030o94098438488144

    A cookie with a valid port value should appear similar to the following example:

    BIGipServer<pool_name>=rd3o20010112000000000000000000000030o80

    Note: The value following the o separator is the portion of the cookie that identifies the port.
