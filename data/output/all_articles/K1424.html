K1424: Reasons why BIG-IP and 3-DNS may report large numbers of interface input errors but otherwise behave normally

Topic

When using the netstat -si -I exp0 command you may see a high number of Ierrs as shown in the following example:

Name  Index  Address             Ipkts    Ierrs  Opkts  Oerrs  Coll  Drop 

expO 1 00:90:27:fc:9d:0a 117037 36 17552 0 40 0

In BIG-IP version 4.0 and later, the NICs are set in promiscuous mode by default. This means they will see and report on network traffic that is not always destined for BIG-IP. This may cause an increase in Ierrors. Conversely, when BIG-IP is in standby mode, most network traffic is ignored so the Ierror counter does not increase.
