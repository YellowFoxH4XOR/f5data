Known Issue

This is the result of a known issue. RADIUS authentication is used to authenticate user access to the Configuration utility. If an initial login attempt to the Configuration utility fails due to an empty password field, subsequent login attempts with the correct password may slow down the Configuration utility. The subsequent login attempts trigger the BIG-IP system to send multiple RADIUS requests to the RADIUS server for each RADIUS authentication attempt.

Additionally, if RADIUS servers are configured to lock the account after a specific number of failed login attempts, this known issue will cause the RADIUS servers to prevent access to the Configuration utility.

This issue does not affect the following:

  • Users entering invalid passwords
  • CLI (SSH) logins
  • RADIUS authentication profiles on virtual servers

F5 Product Development tracked this issue as CR52340, CR71293 and CR71294 and it was fixed in BIG-IP 9.1.3, 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller Release Notes.

Workaround

After attempting to log in to the Configuration utility with a blank password, close the browser and open a new browser before entering a valid password.
