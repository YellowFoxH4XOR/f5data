K000134546: Activation of AppProtect does not work

Type
Support Solution
Published
2023-05-10
Updated
2025-11-07
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.7.0, 2.9.0, 2.8.0, 2.8.X, 2.9.X, 2.10.X, 2.7.X, 2.10.0, 2.9.1
Source
https://my.f5.com/manage/s/article/K000134546

Description

  • You have successfully installed Nginx Instance Manager
  • You device discovery and management Nginx App protect instances on the Instance Manager is also successfully completed 
  • You load AppProtect module, "modules/ngx_http_app_protect_module.so", on the main context of managed instance from the Instance Manager 
load_module modules/ngx_http_app_protect_module.so;
user  nginx;
worker_processes  auto;
error_log  /var/log/nginx/error.log notice;
pid        /var/run/nginx.pid;
events {
    worker_connections  1024;
}
  • You proceeded to enable/activate the default AppProtect policy on managed Nginx from the Instance Manager
server {
    status_zone default_server;
    app_protect_policy_file /etc/nms/NginxDefaultPolicy.tgz;
    app_protect_security_log_enable on;
    app_protect_security_log "/etc/nms/secops_dashboard.tgz" syslog:server=127.0.0.1:514;

    listen       80 default_server;
    server_name  localhost;
}
  •  But the above attempt to enable policy fails with the below error
        Config failed to publish
        Instance config failed to publish to:

        {"instance:bcc415fd-2c12-3b62-b53a-72b519201469":"no app protect installed"}
        nap: no app protect installed

Environment

  • Nginx Management Suite
  • Nginx Instance Manager
  • Nginx APP Protect

Cause

  • Mismatch between installed AppProtect version on managed instance and installed compiler version on the Instance manager.
  • For example, you may have Nginx instance with AppProtoect version 4.1.0, yet the compiler on NIM may be running nms-nap-compiler-v4.2.0,

Recommended Actions

  • Make sure the instillation and version matching is correct following "WAF Compiler and Supported App Protect Versions "

Additional Information
