Description

  • You attempt to view lsn-pool stats using the lsndb command from a non default route domain.
  • You get the error message below
    Error connecting to memcached, err: Connection refused [111]
     

Environment

  • BIG-IP
  • CGNAT enabled
  • Route Domains in use

Cause

ID777689
The lsndb command must be run from the default Route domain (RD0) only.

Recommended Actions

Use the command 'lsndb list all' from RD0 to view stats for objects in non default route domains.

Additional Information

The BIG-IP CGNAT Implementations manual makes reference to this issue under the Viewing reserved endpoints section.
