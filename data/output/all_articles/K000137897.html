Description

You have connected your F5 rSeries 2600 device to a Cisco Nexus switch using 25G interfaces, but are facing issues with the link not coming up. Despite proper physical connections and receiving light on the Nexus SFP, the link remains inactive.

Environment

  • rSeries 2000/4000
  • Connected to a Cisco switch using 25G port
  • No RS FEC IEEE mode on Cisco side (like in Cisco EX line devices)

Cause

RS FEC IEEE mode is either not supported or not turned on on the Cisco Nexus side of the connection. Some Cisco Nexus models, particularly EX line, do not support the RS FEC IEEE mode required by the F5 device. FEC setting cannot be changed on the F5OS for now.

Recommended Actions

Ensure that the FEC mode on both the F5 device and the adjacent network device is compatible and the same (RS FEC IEEE). For F5 rSeries 2600 devices, the adjacent network device must be configured with RS FEC IEEE mode on 25G interfaces. If you are using Cisco Nexus switches that do not support this mode, consider hardware alternatives that are compatible.
