K000160851: How to configure GRE Tunnel Limiters (Tunnel Max Bandwidth)?

Description

GRE tunnel limiters serve as a method to cap the maximum bandwidth per tunnel. This setting is useful to prevent congestion or instability caused by traffic exceeding the underlying link's capacity.  

Environment

  • Routed DDOS

Cause

None

Answer/Recommended Actions

Things to consider about GRE limiters:

  • The limiter is per tunnel and acts on the traffic entering the tunnel.
  • Only effective on bandwidth (bps) and does not affect or limit the packet rate (pps)
  • This setting is not a mitigation nor a firewall, it's designed to provide customers with greater traffic control.
  • An incorrect limiter configuration can affect legitimate traffic.

Requirements:

  • Capacity of the tunnel's underlying circuit.
  • The number of tunnels terminating in the same circuit. (Customer Endpoint)
  • Clear understanding of the network's traffic delivery needs, traffic routing preferences and primary-backup tunnel setups.

Where is this configured?

  1. On the the Routed DDOS service, under Manage > Tunnels, select the configuration (Actions button) menu for the specific tunnel that will be updated.
  2. On the configuration page, select edit configuration 
  3. Under Bandwidth Speed Configuration, enter the desired limiter in Mbps
    1.  
  4. Save Tunnel

 

A few examples for limiter configuration:

Simple Method

Tunnels terminating in the same circuit will share the same limiter. For example, if circuit 192.168.1.1 has a capacity of 1Gbps, GRE tunnels A,B and C terminating in this IP, will be configured to 900Mbps each, which corresponds to the link's capacity -  X% adjustment (usually 10%) to account for possible traffic spikes. 

Full Method

Takes into consideration the number of tunnels terminating into a single circuit and traffic routing preferences (are communities or prepends being used?). Primary and Backup tunnels should have the same limiters configured.

For example, if circuit 192.168.1.1 has a capacity of 1Gbps, GRE tunnels A,B and C terminating in this IP, will be configured as follows (considering traffic is equally distributed):

(Link Capacity - X%) / #ofTunnels, in this case: (1Gbps - 10%)/3 ≈ 300 Mbps limiter per tunnel.

 

It's always important to review current traffic delivery metrics for the GRE tunnels before making any changes, this information is available inside the Console under Traffic Backbone > Traffic Usage > Outbound Traffic.
