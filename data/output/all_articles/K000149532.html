K000149532: Why are other RE sites doing health checks on an Origin Server advertised on CE

Description

I have an HTTP Load Balancer advertising on a Customer Edge (CE) and you want to know why there are health checks going on the Origin Server.

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer

Cause

  • Check please if Bot Defense is configured in that HTTP Load Balancer.
    • If it is, then we associate the virtual host with two routes. The reference to the first route has a shared cluster responsible for doing Bot Defense.
    • Since the endpoint associated with this cluster has been discovered publicly (on all RE sites) and health checks are being enabled on the cluster, the health check will be done from all RE sites.
    • Health checks happen where the endpoints are discovered which means that the health check is being done on RE sites.

Recommended Actions

None
