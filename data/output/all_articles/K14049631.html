K14049631: Error Message: ''The requested device group device (/Common/[device group name] /Common/[device name]) was not found.''

Type
Support Solution
Published
2020-05-22
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K14049631

Description

  • Syncing device group fails with an error message when using API calls or CLI commands
  • Sync fails.
  • Error Message: "The requested device group device (/Common/[device group name] /Common/[device name]) was not found."

Environment

  • HA Device Group configured

Cause

The device with name [device name] is not in the device group.

Recommended Actions

Note: It's possible to have your global device hostname defined different from the device name at GUI: Device Management  ››  Devices  ››  [device.name] :: Name

  1. Change the API call or CLI command to include a device name listed at Device Management  ››  Devices  ››  [device.name] :: Name
