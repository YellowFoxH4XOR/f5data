Known Issue

The HTTP HEAD method may be incorrectly enabled in an imported security policy.

This issue occurs when all of the following conditions are met:

  • The HTTP HEAD method is removed from the Allowed Methods list.
  • The Security Policy is exported as either binary or XML.
  • The exported policy is re-imported to the BIG-IP ASM system.

Impact

Requests using the HTTP HEAD method are incorrectly allowed.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Requests using the HTTP HEAD method are incorrectly allowed.
  • The HEAD method is listed in the Configuration utility under Application Security > Methods > Allowed Methods (10.2.x).
  • The HEAD method is listed in the Configuration utility under Application Security > Headers > Methods > Allowed Methods (11.0.0).

Workaround

To work around this issue, you can delete the HEAD method after importing the policy. To do so, perform the following procedure:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to the Methods screen:

    • BIG-IP ASM 10.2.x

      Go to Application Security > Methods.

    • BIG-IP ASM 11.0.0

      Go to Application Security > Headers > Methods.

  3. Select the HEAD method.
  4. Click Delete.
  5. Click OK to confirm the operation.
