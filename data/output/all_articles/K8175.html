Known Issue

This is the result of a known issue. A BIG-IP WebAccelerator 4500 platform with 4GB of memory installed, and with more than 2GB of memory provisioned for the host, will report host memory utilization as exabytes instead of megabytes.

For example, the bigpipe memory show command will display output that appears similar to the following example:

b memory show
MEMORY STATISTICS --
| (Host) Total = 15.99EB Used = 15.99EB
| (TMM) Total = 1.252GB Used = 36.77MB

Note: The performance graphs for Memory Used in the Configuration utility will also display exabytes for the host memory used.

Note: This issue is cosmetic and does not affect the BIG-IP WebAccelerator system performance.

F5 Networks Product Development tracked this issue as CR87578 and it was fixed in BIG-IP WebAccelerator version 9.4.4. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.
