Topic

You should consider using these procedures under the following condition:

  • You want to log status change messages for Border Gateway Protocol (BGP) neighbors.

Description

You can log status change messages for BGP neighbors. Doing so is useful to troubleshoot BGP neighbor sessions or adjacency issues without enabling BGP debugging and affecting system performance. Status change messages for BGP neighbors include the following events:

  • BGP notifications
  • Erroneous BGP update received
  • User reset request
  • Peer time-out
  • Peer closing down the session
  • Interface flaps
  • Router ID changed
  • Neighbor deleted
  • Member added to peer group
  • Administrative shutdown
  • Remote AS changed
  • RR client configuration modification
  • Soft reconfiguration modification

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have access to the TMOS Shell (tmsh) or the Advanced Shell (bash).

Procedures

  • Logging status change messages for BGP neighbors
  • Viewing the BGP status change log messages

Logging status change messages for BGP neighbors

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Access the IMI Shell (imish) by using the following syntax:

    run /util imish -r <route_domain>

    For example, the following command accesses imish for route domain 0, the default route domain:

    run /util imish -r 0

  3. Access Enable mode by entering the following command:

    enable

  4. Access Configure mode by entering the following command:

    configure terminal

  5. Access Router mode by using the following syntax:

    router bgp <AS-number>

    For example:

    router bgp 200

  6. To create the log file, enter the following command:

    log file /var/log/zebos.log

  7. Enable log status change messages by entering the following command:

    bgp log-neighbor-changes

    Note: To disable log status change messages, enter the following command from Router mode:

    no bgp log-neighbor-changes

  8. Exit configuration mode by entering the following command:

    end

  9. To write the configuration, enter the following command:

    write

  10. Exit imish by entering the following command:

    exit

Viewing the BGP status change log messages

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to bash.
  2. Go to the /var/log directory by entering the following command:

    cd /var/log

  3. Use a Linux utility such as cat or less to review the BGP status change log messages.

    For example:

    cat zebos.log
