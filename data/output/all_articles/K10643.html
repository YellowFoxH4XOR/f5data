Known Issue

NET-SNMP fails to properly reallocate memory for its ARP cache to handle large ARP tables. As a result, this behavior causes SNMP requests to fail to return all Address Resolution Protocol (ARP) entries when the ARP table exceeds 2,048 entries. The ARP entries up to the boundary will be returned, and any ARP entries after the boundary is reached will not be returned.

Note: It is also possible for this issue to allocate enough space for only 1,024 entries.

This issue occurs when all of the following conditions are met:

  • The ARP table of the system being polled exceeds 2,048 entries.
  • You perform an SNMP query that includes the ARP table.

Impact

Not all ARP entries are returned when performing an SNMP poll.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The following error message is logged to the /var/log/messages file:

    snmpd[1748]: Error allocating more space for arpcache. Cache will continue to be limited to 2048 entries

  • The SNMP query fails to return ARP entries when the ARP table exceeds 2,048 entries.
