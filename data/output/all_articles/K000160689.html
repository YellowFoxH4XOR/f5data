Environment

  • Product: BIG-IP LTM
  • Version: 17.1.0.1 (Point Release 1)
  • Platform: F5 rSeries
  • Management DHCP: Disabled
  • Uptime: 999+ days
  • No abnormal CPU, memory, or traffic spikes observed
  • Management IP unreachable; self IP accessible
  • Log entries showing management IP and hostname changes

Cause

Bug ID 2221585: When tenant renews DHCP lease on eth2, the interface IP address on mgmt also gets modified

Answer/Recommended Actions

  1. Manually restore the correct management IP and hostname if affected.
  2. Save the configuration using 'tmsh save sys config' to ensure changes persist.
  3. If manual restoration resolves the issue, there is no need to reboot or change tenant state (deployed → configured → deployed).

Additional Information

  • The eth2 interface has DHCP automatically enabled for internal tenant-to-host communication. The bug causes the management IP to be overwritten during DHCP lease renewal after long uptime.
  • Manual configuration and disabling DHCP for management IP does not prevent this bug from occurring after the lease renewal period.
  • The workaround of changing tenant state is only needed if management access cannot be restored manually.
