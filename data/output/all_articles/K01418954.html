Known Issue

The Configuration utility may fail to update or delete an SNMPv3 user correctly.

This issue occurs when the following condition is met:

  • You use the Configuration utility to perform any of the following actions from the System > SNMP > Agent > Access (v3) menu:
    • Save an existing SNMPv3 user setting with or without making any changes to it.
    • Delete an existing SNMPv3 user.

Impact

SNMP operations for the modified SNMPv3 user do not function correctly, and the deleted SNMPv3 user receives an error message when attempting to perform an SNMP query.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you use the Configuration utility to update the SNMPv3 user, the SNMP operations for the affected user do not function correctly.
  • The Traffic Management Shell (tmsh) and the Configuration utility do not display the deleted user, and it appears that the user has been deleted. However, the Net-SNMP does not process the user deletion.
