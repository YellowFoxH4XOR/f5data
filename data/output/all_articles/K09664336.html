Description
Creating a custom ASM block page with images

Environment

  • BIG-IP ASM
  • Block Page

Cause
None

Recommended Actions
Note: Before doing any changes/activities, create a fresh UCS of the BIG-IP device in question and copy it to a remote and secure connection as a precautionary measure; see: 
K13132: Backing up and restoring BIG-IP configuration files with a UCS archive

For custom ASM Response with images, they can use a base64 image in their html code or do a Redirect URL.

Note: The maximum limit size of the entire response page is 50k only.

  1. Convert the image file to base64
  2. Go to Security  ››  Application Security : Policy : Response Pages
  3. Select Custom Response
  4. Paste the HTML code as like below
  5. For preview, select the Show button
  6. Apply changes


HTML code:

Note: Replace <base64_image_here> with the base64 string of the image as per step 1 above.

<html>
<head>
<title>Request Rejected</title>
</head>
<body>
<img src="data:image/jpg;base64,<base64_image_here>"/>
<br>
The requested URL was rejected. Please consult with your administrator.<br><br>
Your support ID is: <%TS.request.ID()%>
</body>
</html>
