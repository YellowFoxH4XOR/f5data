Known Issue

The BIG-IP APM access policy client-side Sophos antivirus check may fail.

This issue occurs when all of the following conditions are met:

  • An access policy is configured with an endpoint security client-side agent to check for antivirus software.
  • Users connecting to the BIG-IP APM are running the Mac OS X 10.9 operating system.
  • Mac OS X users connecting to the BIG-IP APM system are running the Sophos 9.4.0 antivirus software.

Impact

Users are denied access to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Mac OS X users attempting to log in to a BIG-IP APM access policy are denied access with an error message similar to the following example:

    Your session could not be established.
    The session reference number: <session id number>
    Access was denied by the access policy. This may be due to a failure to meet access policy requirements.

  • Removing the endpoint security client-side antivirus check agent from the access policy allows Mac OS X users to successfully log in.
