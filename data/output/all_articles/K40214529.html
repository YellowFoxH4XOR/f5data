K40214529: Error Message: The resource doesn't have any tunnels associated with the current OS

Knowledge
Published
2018-04-06

Applies to

Issue

Error Message

The resource doesn't have any tunnels associated with the current OS

Message Location

You may encounter this message in the following location:

  • In the warning tooltip on the webtop.

Description

This message occurs when the following condition is met:

  • You attempt to launch an application tunnel with a client OS that is different than the OS configured in the application tunnel resource. 

Beginning in BIG-IP 13.0.0, F5 introduced native application tunnel support for Linux and Mac. Administrators can now specify the client OS on which the application tunnel resource runs. The resource runs on only the selected OS.    

Impact

The application tunnel resource fails to run from the webtop. 

Recommended Actions

You should configure the application tunnel resource for the appropriate client OS. In environments where the application tunnel resource should be accessed by different client OSs, F5 recommends that you create a separate application tunnel resource for each OS. 

For more information on configuring application tunnels, refer to the Configuring App Tunnel Access chapter of the BIG-IP Access Policy Manager: Application Access manual.
