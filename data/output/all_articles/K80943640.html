K80943640: Disk space compatibility: NOK when running preUpgradeCheck on BIG-IQ

Type
Support Solution
Published
2021-05-10
Updated
2025-02-07
Applies to
  • BIG-IQ
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K80943640

Description
When running preUpgradeCheck on BIG-IQ, following NOK message is displayed.

ActiveVolumeSize: 14893056 KB
RequiredSpace: 67335156 KB
Free space: 43163648 KB
Disk space compatibility: NOK

You may notice the error under the follow conditions too: 

  • It's known to frequently occur on BIG-IQ CM VE that was initially deployed using non-LARGE image
  • It may also occur on BIG-IQ utilizing more disk spaces like when having old software volumes with previous BIG-IQ versions

Environment

  • Running preUpgradeCheck script on BIG-IQ
  • Disk Utilization

Cause
The amount of available disk space is not enough to proceed with the upgrade.
Especially for deployments of BIG-IQ VE versions prior to 7.1.0 using non-LARGE image, several logical volumes including /var will require more disk space on BIG-IQ 7.1 and later. Originally reserved disk space may not be enough for software upgrade.

Recommended Actions

  1. Check if other non-used software volumes exist with following command
    # tmsh show sys software
  2. Delete existing volumes with following command
    # tmsh delete sys software volume HD1.x
  3. If there is only a single volume existing and the preUpgradeCheck gives the NOK message above, its virtual disk needs to be increased on the hypervisor. Follow steps below to extend disk space.
    • Calculate how much disk space is required.
      For example, based on the example output above, 24171508 KB additional disk space is required at least.
      (RequiredSpace) - (Free space) = 67335156 - 43163648 = 24171508 KB
    • Shutdown the BIG-IQ VE
      # shutdown -h now
    • Increase virtual disk size on hypervisor
    • Power on the BIG-IQ VE
    • Check newly available disk space
      # pvs --unit=k
    • Rerun preUpgradeCheck
