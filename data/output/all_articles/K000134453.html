K000134453: Web GUI status with the error message "Failed" in the post install task after upgrade.

Support Solution

2023-05-31

  • BIG-IQ Centralized Management: 8.0.0, 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X
Source
https://my.f5.com/manage/s/article/K000134453

Description

The status of "Regular Upgrade" option in the upgraded version 8.3.0 from 8.0.0 is displayed with the error message, "Failed. Post install task " even though it looks like normal finished after upgrading into 8.3.0.

 

a) BIGIQ > System > Software Management > Upgrade > Select Continue > Select Regular Upgrade.

 

"Failed. Post install task https://localhost/mgmt/cm/shared/esmgmt/post-upgrade/e18a1b99-5700-4960-a54f-cc95f903fa40 failed due to 'Expected number of nodes not found in the elasticsearch cluster.'"

 

 

b) /var/log/restjavad.1.log

 

[WARN][19 Apr 2023 12:50:09 SGT][/cm/shared/esmgmt/post-upgrade/e18a1b99-5700-4960-a54f-cc95f903fa40/worker ESPostUpgradeTaskWorker] Expected number of nodes not found in the elasticsearch cluster.

 

Environment

  • BIG-IQ CM and DCD cluster
  • BIG-IQ CM 8.x
  • BIG-IQ Upgrade status

 

Cause

None.

 

Recommended Actions

We can ignore the error message as cosmetic if there should be no issue or no malfunction in the upgraded version.

 

Additional Information

https://techdocs.f5.com/en-us/bigiq-8-2-0/upgrading-big-iq-with-dcd-cluster-from-versions-6-1-x-and-7-x-to-8-1-0/upgrade-post-upgrade-tasks.html#ch-title-post-upgrade-tasks

Navigate to System -> Big-IQ Data Collection -> Big-IQ Data Collection Devices and a Pop-Up appears indicating that the post upgrade tasks failed and asking if you want to run them again.  

After succesfull finish of post upgrade tasks whe can identify  upgrade task and move it manually to finished state

for this we need to use CLI and do  following check:

Identify most recent  upgrade task with FAILED status:

restcurl -u admin:a /mgmt/cm/shared/esmgmt/upgrade/regular/


change status of task from FAILED to FINISHED

restcurl -u admin:a -X PATCH /mgmt/cm/shared/esmgmt/upgrade/regular/315a3a90-593c-4cee-a47e-fe61aad2ff42 -d '{"status": "FINISHED"}'
