Known Issue

The ARX Manager GUI may not allow you to add a share for a single protocol volume.

This issue occurs when all of the following conditions are met:

  • You attempt to add a share using the Add Share Wizard in the ARX Manager GUI
  • You attempt to add an NFS-only or a CIFS-only share

For example, if you attempt to add a CIFS-only share using the Add Share Wizard in the ARX Manager GUI, the wizard incorrectly requires that both an NFS path and a CIFS share be specified.

Impact

You are unable to add a single protocol share using the ARX Manager GUI.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Add Share Wizard does not progress past the Select the file server and file server share to add to the volume page when you click Next.
     
    • If you attempt to add a CIFS share, an error message similar to the following example appears:

      A value must be supplied for 'NFS Path

    • If you attempti to add an NFS share, an error message similar to the following example appears:

      A value must be supplied for 'CIFS Share

Workaround

To work around this issue, you can add the share from the ARX CLI. To do so, perform one of the following procedures:

  • Add CIFS share
  • Add NFS share

Add CIFS share

Impact of workaround: None.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by entering the following command:

    enable

  3. Enter global configuration mode by entering the following command:

    global

  4. Specify the volume you want to configure by entering the following command, where [NameSpaceName] is the name of the namespace and [VolName] is the name of the volume:

    namespace [NameSpaceName] volume /[VolName]

    For example:

    namespace ns1 volume /vol1

  5. Create the desired share, by entering the following command where [ShareName] is the name of the share:

    share [ShareName]

  6. At the create share confirmation prompt, type the following:

    yes

  7. Specify the source share, by entering the following command where [Filer_Name] is the name of the backend filer and [Share_Name] is the CIFS share name on the backend filer:

    filer [Filer_Name] cifs [Share_Name]

  8. Enable the share by entering the following command:

    enable

  9. Exit the share configuration mode by entering the following command:

    exit

Add NFS share

Impact of workaround: None.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by entering the following command:

    enable

  3. Enter global configuration mode by entering the following command:

    global

  4. Specify the volume you want to configure, by entering the following command where [NameSpaceName] is the name of the namespace and [VolName] is the name of the volume:

    namespace [NameSpaceName] volume /[VolName]

    For example:

    namespace ns1 volume /vol1

  5. Create the desired share by entering the following command, where [ShareName] is the name of the share:

    share [ShareName]

  6. At the create share confirmation prompt, type the following:

    yes

  7. Specify the source export, by entering the following command where [Filer_Name] is the name of the backend filer and [Export_Name] is the NFS export name on the backend filer:

    filer [Filer_Name] nfs [Export_Name]

  8. Enable the share by entering the following command:

    enable

  9. Exit the share configuration mode by entering the following command:

    exit
