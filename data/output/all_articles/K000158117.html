K000158117: Outlook Web Access (OWA) is not working via APM

Type
Support Solution
Published
2025-12-09
Updated
2025-12-09
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000158117

Description

When accessing Outlook Web Access (OWA) through a BIG-IP virtual server, users were able to log in but could not view emails or mailbox content. Attempts to access messages resulted in browser errors such as "Request Rejected" and a support ID. Analysis showed that legitimate OWA traffic was being blocked by the Application Security Manager (ASM) policy attached to the virtual server.

Environment

  • BIG-IP LTM with APM module
  • Virtual server configured for OWA access with:
    • Client SSL and Server SSL profiles
    • NTLM authentication profile
    • Access Policy Manager (APM) policy applied
    • ASM policy attached

Cause

ASM policy attached to the OWA virtual server was blocking valid OWA service requests, resulting in failed mailbox access.

Recommended Actions

  1. Remove the ASM policy from the affected OWA virtual server.
  2. If web application security is required, review and tune ASM signatures and rules specific to Exchange/OWA workflows before re-enabling the policy.
  3. Test OWA access after changes to confirm resolution.

Additional Information

  • Error message observed: "Request Rejected. The requested URL was rejected. Please consult with your administrator."
