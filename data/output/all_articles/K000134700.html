Topic

The BIG-IP Advanced WAF / ASM system verifies HTTP POST data length for all incoming requests. To prevent buffer overflow attacks and denial of service attacks, the system checks that requests containing POST data do not exceed the acceptable POST length specified in the security policy.

Description

When you configure the learning and blocking settings for Illegal POST data length violations and the BIG-IP Advanced WAF / ASM system detects a POST request in which the data length exceeds the acceptable length specified in the policy, the system logs the following violation to the /var/log/asm file and the Requests screen in the Configuration utility:

  • Illegal POST data length

For example, the Illegal POST data length violation may occur if a client sends a very long string in the POST data. Such requests can consume excessive resources on the web server and may be an indication of an attack.

Configure Learning and Blocking settings for Illegal POST data length violations

To configure Learning and Blocking settings for Illegal POST data length violations, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Select File Types.
  4. For Illegal POST data length, select the check boxes for Block, Learn and Alarm, as needed.
  5. Select Save.
  6. Select Apply Policy.

Configure the allowed POST data length for a file type

To configure the allowed POST data length for a file type, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Security > Application Security > Security Policies > Policies List > <Security Policy Name>.
  3. Select HTTP Message Protection.
  4. Select File Types.
  5. Select the name of the relevant file type. For example, *(Wildcard).
  6. Select Length for POST Data Length.
  7. Enter the maximum number of bytes to be allowed for POST data length for the specified file type.
  8. Select Update.
  9. Select Save.
  10. Select Apply Policy.
