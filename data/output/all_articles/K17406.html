Topic

You should consider using this procedure under the following condition:

  • You want to create a new software volume and install a new image or hotfix on the BIG-IQ system.

Description

To perform a new software installation you can either re-use an existing software volume that is non-active, or a new free software volume. Before creating a new software volume, you must ensure that the BIG-IQ system has sufficient volume disk space to create a new software volume. This article explains how to verify whether the BIG-IQ system has sufficient volume disk space, and how to perform the software installation to a new, free software volume using the TMOS Shell (tmsh).

Note: Beginning in BIG-IQ 5.4.0, you can create a new software volume when using the BIG-IQ user interface to perform an upgrade.
Note: You cannot create an empty volume with the BIG-IQ user interface or the command line interface. You must install software if creating a new volume. 

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have Advanced Shell (bash) access with the credential of an administrator role.
  • You are familiar with tmsh.
  • You have already transferred the new software version's image ISO or the desired hotfix ISO file into the /shared/images directory.

    Note: To install a hotfix, you are required to have the final edition image ISO file transferred into the /shared/images directory.

Procedures

Verifying that the system has sufficient volume disk space

To verify that the system has sufficient volume disk space to create a new software volume, you can use the vgs command.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system bash shell as an administrator.
  2. Review the current system's volume disk usage, and enter the following command:

    vgs

  3. Review the output for the amount of free volume disk space.

    Following are two samples of output, one with sufficient volume disk space, and the other with insufficient volume disk space.

    Example output of the sufficient volume disk space:

    A BIG-IQ system with free volume disk space of about 15 GB or more is able to create a new software volume. This BIG-IQ system has 436.43 GB of free volume disk space, so it can create a new software volume.

    VG        #PV #LV #SN Attr   VSize   VFree  
    vg-db-vda   1   8   0 wz--n- 510.75g 436.43g

    Example output of the insufficient volume disk space:

    When reviewing the output, it shows that this BIG-IQ system has 9.35 GB of free volume disk space, which is not sufficient to create a new software volume.

    VG        #PV #LV #SN Attr   VSize   VFree  
    vg-db-vda   1   16   0 wz--n- 510.75g 9.35g

    When you do not have enough volume disk space to create a new software volume, you can still install the new software by re-using an existing software volume that is non-active. Before you re-use an existing software volume that contains an active configuration, F5 recommends that you copy the latest configuration backup to a remote system, as re-using an existing software volume will delete all of the existing configuration on the system.

Installing to a new software volume

To install a software image or hotfix by creating a new free software volume using tmsh, perform the following procedure.

Note: Newly created volumes are created at a default size, not the current volume size. A re-run of the resizevol utility is required for the current extended partitions to be applied to newly created software image volumes.
To display allocated partition sizes assigned to individual image volumes, you can run the following command: lvs

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh as an administrator by entering the following command:

    tmsh

  2. To verify the current BIG-IQ system software status, enter the following command:

    show /sys software

    Example command output:

    ---------------------------------------------------------------------------------
    Sys::Software Status
    Volume  Product  Version    Build  Active                 Status  Allowed Version
    ---------------------------------------------------------------------------------
    HD1.1    BIG-IQ    8.4.0  0.0.139      no               complete              yes

    Note: To view available images on the BIG-IQ system, use the list /sys software command.

  3. To install a new software image or hotfix into a new software volume, use the following command syntax:

    install /sys software <image|hotfix> <ISO> create-volume volume <HDx.y>

    For example, to install the image BIG-IQ 8.4.2 into a new volume named HD1.2, type the following command:

    install /sys software image BIG-IQ-8.4.2-0.0.27.iso create-volume volume HD1.2

  4. To review the status of the software installation, periodically enter the following command:

    show /sys software

    Example command output:

    ---------------------------------------------------------------------------------
    Sys::Software Status
    Volume  Product  Version    Build  Active                 Status  Allowed Version
    ---------------------------------------------------------------------------------
    HD1.1    BIG-IQ    8.4.0  0.0.139      no               complete              yes
    HD1.2    BIG-IQ    8.4.2   0.0.27      no  installing 10.000 pct              yes

  5. Optional: When the installation of the new software has completed, you can restart the system to the new software volume using the following command syntax:

    reboot volume <HDx.y>

    For example, to switch the active software volume to HD1.2, enter the following command:

    reboot volume HD1.2
