Known Issue

NT LAN Manager (NTLM) authentication may not function as expected.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM system with an NTLM Auth configuration.
  • You have configured the NTLM Auth configuration without defining at least one domain controller fully-qualified domain name (FQDN).
  • You configure an access policy that references the NTLM Auth configuration.
  • A user attempts to establish a session with the access profile configured with the access policy.

Impact

User authentication always succeeds.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H513940 on the Diagnostics > Identified > High screen.
  • When attempting to establish an access session, any user and password combination is successfully authenticated.

Workaround

To work around this issue, you can modify the NTLM Auth configuration to specify at least one domain controller in the domain controller FQDN list. To do so, perform the following procedure:

Impact of workaround: Users will be authenticated by NTLM.

  1. Log on to the BIG-IP APM Configuration utility.
  2. Navigate to Access Policy > Access Profiles.
  3. Select the NTLM tab > NTLM Auth Configurations.
  4. Select the name of the affected NTLM Auth configuration.
  5. Enter the FQDN name of a domain controller in the Domain Controller FQDN List.
  6. Click Add.
  7. Repeat steps 5 and 6 for each domain controller FQDN you want to add to the configuration.
  8. Click Finished.
