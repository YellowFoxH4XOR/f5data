Description

APM Client 7.2.7.1 release introduces new and updated icons across the Mac Edge client to provide a refreshed, modern, and consistent visual experience:

  • A new set of icons has been added and existing icons have been updated for improved clarity and alignment with corporate standards.
  • Icons updated include the Application, Dock, Menu bar (Tray icons).
  • No change in functionality—this update affects only the appearance of icons in the User Interface.
  • The new icons are available automatically after updating to BIG-IP MAC Edge client 7271.

Recommended Actions

If the icon is not clearly visible in the menu bar, you can adjust system settings to improve visibility:

Go to System Settings > Accessibility > Display, and toggle Reduce Transparency.

You can also switch between Light and Dark mode under System Settings > Appearance to see which provides better contrast.

Customization of the Application Icon

  1. Get Your Icon Image
    1. Use a square image (at least 512×512 px, .icns, .png, or .jpg).
    2. Open it in Preview.
    3. Press Command + A to select, then Command + C to copy.
  2. Open App Info.
    1. In Finder, go to Applications.
    2. Right-click the app > Get Info.
  3. Paste the Icon
    1. Click the small icon at the top-left of the Info window (it highlights).
    2. Press Command + V to paste.
  4. Restart
    1. Close the Info window and restart the app. The new icon should appear now.

Note: To restore the original icon: open Get Info, select the custom icon, and press Delete.
