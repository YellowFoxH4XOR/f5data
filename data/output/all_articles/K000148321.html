K000148321: Application Connection Reset Issue After Upgrading from 13.x to 15.x

Type
Support Solution
Published
2024-10-29
Updated
2024-11-01
Applies to
  • BIG-IP
  • Public Cloud
  • BIG-IP LTM: 15.1.10
  • Microsoft Azure
Source
https://my.f5.com/manage/s/article/K000148321

Description

After upgrading from version 13.x to 15.x, applications take several minutes to load, and after some time, the connection is reset. However, when bypassing the F5 and connecting directly to the backend server, the connection reset does not occur.

Environment

  • BIG-IP VE hosted in Azure

  • Upgrade from 13.x to 15.1.10.4

  • App connection drops after 4-5 minutes

Cause

BUG ID 1320889

Answer/Recommended Actions

Request and EHF for BUG ID 1320889

Additional Information

Out To determine if you are hitting BUG ID 1320889, you need to take a packet capture to identify if there are indications of packet loss. Then, review if there are drops at the driver level of the interface by running the following command:
tmctl -d blade tmm/ndal_tx_stats -w 300' column 'drop_rej_dd

The output might look like this
iface device tmm drop_rej_dd

----- ------ --- -----------

1.1 sock  0   372767

1.1 sock  1   343236
