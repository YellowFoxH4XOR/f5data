Description
vCMP Guests unstable - HA Connection detected DAG discrepancy errors

Environment

  • BIG-IP version 15.1.2
  • Viprion C2400
  • TMM core files generated. 
  • There is a mismatched DB key 'mhdag.bitshift' configuired between the peers.
  • In the /var/log/ltm file, you may observe error messages that appear similar to the following example:
err tmm[7008]: 01340004:3: HA Connection detected dissimilar peer: local npgs 4, remote npgs 4, local npus 1, remote npus 1, local pg 3, remote pg 2, local pu 0, remote pu 0.  Connection will be aborted.
err tmm[24570]: 01340004:3: HA Connection detected DAG discrepancy: local pg 1, remote pg 2, local pu 0, remote pu 0. Connection will be retried.
err tmm[24502]: 01340002:3: HA Connection with peer 136.253.221.161:1029 for traffic-group /Common/traffic-group-1 lost

Cause

The host <hostname> has a non-default value:

sys db mhdag.bitshift {
      default-value "6"
      value "5"
      value-range "unsigned_integer min:5 max:6"
  }

 

Recommended Actions

  1. Make sure to change the value to the default by running the following commands. 
IMPORTANT: This change should be done during a maintenance window as it will affect disaggregation and might interrupt connections.
 
tmsh modify sys db mhdag.bitshift value 5
tmsh modify sys db mhdag.bitshift reset-to-default 
sys db mhdag.bitshift {
      default-value "6"
      scf-config "true"
      value "6"
      value-range "unsigned_integer min:5 max:6"
  }
  • Reboot the vCMP guest, and then the Host.
