Known Issue

The BIG-IP system may fail to properly migrate an HTTP Class profile to a local traffic policy after an upgrade.

This issue occurs when the following condition is met:

  • An HTTP Class profile that contains the hosts attribute was migrated to a local traffic policy during an upgrade to BIG-IP 11.4.0 or later.
F5 has replaced the HTTP Class profile with the introduction of the Local Traffic Policies feature in BIG-IP 11.4.0. During an upgrade to BIG-IP 11.4.0 or later, if your configuration contains an HTTP Class profile, the BIG-IP system attempts to migrate the HTTP Class profile to an equivalent local traffic policy. As a result of this issue, the new local traffic policy incorrectly uses host instead of all as the Selector property causing the policy to ignore a port if included in the value of the HTTP host header.

Impact

The BIG-IP system does not evaluate the local traffic policy condition as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A local traffic policy condition does not match the port value in an HTTP host header, leading to an unexpected local traffic policy action.
  • A local traffic policy that was migrated from an HTTP Class profile incorrectly uses host instead of all as the Selector property.

Workaround

To work around this issue, you can edit the LTM policy to change the value of the Selector property to all. To do so, perform the following procedure:

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends that you test any such changes during a maintenance window, with consideration to the possible impact on your specific environment.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Policies > Policy List, and click the affected policy.
  3. Under Rules, click the affected rule.
  4. Under Conditions, in the table at the bottom of the section, select the condition that uses the host Selector for the http-host Operand.

    Take note of the values in the table under the Values column for the selected condition, as the system clears these values when you modify the Selector.

    Take note of the setting in the table under the Condition column, as this setting reverts to the default value of equals during editing.

  5. Click Edit.
  6. From the Selector list, select all.
  7. To the Value box under Values, re-add a value from step 4.
  8. Click the small Add button.

    The value should now appear in the List box under Values.

  9. Repeat steps 7 and 8 for all values noted in step 4.
  10. Select the condition noted from step 4, from the Condition list.
  11. Click the large Add button.

    The modified condition should now appear in the table at the bottom of the Conditions section.

  12. To save the changes, click Update Rule.
