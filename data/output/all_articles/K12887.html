Known Issue

The BIG-IP installer reports file or directory removal errors during the installation process.

This issue occurs when all of the following conditions are met:

  • You are using a USB thumb drive or USB DVD/CD drive for the BIG-IP installation or upgrade.

The BIG-IP installer incorrectly acts as though the USB device file system is mounted as a memory file system type instead of a read-only file system and attempts to remove all of the installation files from the affected directories when it is done copying the installation files.

Impact

None. The error message is benign and does not affect the installation.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • An error message that appears similar to the following is reported to the serial console or installation log:

    Can't remove <object type> <file or directory path name> (Read-only file system) at /usr/lib/perl5/site_perl/tm_install/Process.pm line 1167

    In this error message, note the following:

    • <object type> is either a file or directory
    • <file or directory path name> is the path name of the affected file or directory
    For example:

    Can’t remove directory /mnt/thumb/lost+found (Read-only file system) at /usr/lib/perl5/site_perl/tm_install/Process.pm line 1167

    • The error message occurs once for each installation file throughout the installation process; you could potentially see this message appear hundreds of times.
