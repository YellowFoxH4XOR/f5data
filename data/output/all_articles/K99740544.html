Known Issue

The eam process may produce a core file during a graceful system shutdown.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured for authentication, authorization, and accounting (AAA) using Oracle Access Manager (OAM).
  • You shut down your BIG-IP APM system.

Note: Because the issue rarely occurs, further conditions are unknown.

Impact

None. This issue does not affect system operation. 

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system generates an eam core file to the /shared/core directory before the system shuts down.
