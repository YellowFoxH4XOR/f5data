Description

Sometimes there may be a need to change the name of an existing trunk on the BIG-IP. There is currently no supported option to change the name of the existing trunk.

Environment

  • BIG-IP
  • Trunks
  • Interfaces

Cause

This is by design.

Note: Many configuration objects are referenced by name in other locations throughout the configuration. Changing the name could result in objects being orphaned and result in the configuration failing to load.

Recommended Actions

Impact of Procedure: The following actions should not have any negative impact on the system. However it is always recommended that you backup your system and perform these changes during a maintenance window.

To workaround this issue you can create a new trunk and move the interfaces.

  1. Log into the Configuration Utility.
  2. Click Network.
  3. Click Trunks.
  4. Click Create.
  5. Type the new desired name
  6. Click Finished.
Remove the interfaces from the old trunk
  1. Click Network.
  2. Click Trunks.
  3. Click the existing trunk.
  4. Move the interfaces from Members to Available.
  5. Click Update.
Add the interfaces to the new trunk with correct name.
  1. Click Network.
  2. Click Trunks.
  3. Click the new trunk.
  4. Move the interfaces from Available to Members.
  5. Click Update.
Delete the old Trunk
  1. Click Network.
  2. Click Trunks.
  3. Click the check box next to the trunk to delete
  4. Click Delete.
