K000132882: Bottom buttons in F5 Access App on iOS are invisible in dark mode

Type
Support Solution
Published
2023-05-23
Updated
2023-05-23
Applies to
  • BIG-IP
  • F5 Access
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000132882

Description

You are using F5 Access for iOS and would like to use dark mode but you can't see buttons because the font is black and background is dark.

 

Environment

  • BIG-IP APM
  • F5 Access
  • iOS

Cause

You are facing ID 809017 [RFE] Add support for Dark Mode in iOS 13 and later

 

Recommended Actions

To enhance the possible addition of this feature you can open a case with F5 Support (quote ID 809017).

 

Additional Information

None
