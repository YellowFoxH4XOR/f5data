Source

Description

The following ltm logs may be observed:
Critical <device.name> tmm[ID]: 01010025:2: Device error: crypto codec Failed to verify pss padding. OpenSSL error:0906D06C:PEM routines:PEM_read_bio:no start line

Crypto codec queue on the BIG-IP is running on every tmm instance without failures, and is not stuck:

show /sys ha-status all-properties
                              Fail
compression-failsafe tmm0 none no yes no 0 tmm 0
compression-failsafe tmm1 none no yes no 0 tmm1 0
compression-failsafe tmm2 none no yes no 0 tmm2 0
compression-failsafe tmm3 none no yes no 0 tmm3 0

Environment

  • BIG-IP LTM
  • Client SSL profile

Cause

Corrupted client certificate

Recommended Actions

Those errors indicate that BIG-IP wasn't able to verify the client certificate that is signed using the PEM_read_bio signature algorithm because the start line is not properly formatted.

None
