Known Issue

Attempts to rename files using Common Internet File System (CIFS) optimization may fail.

This issue occurs when the following condition is met:

  • The file name or path to the file name is long (for example, more than 100 characters).

Impact

The wocplugin daemon may produce a core file, and traffic processing is temporarily disrupted.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The wocplugin daemon produces a core file similar to the following example:

    wocplugin.bld0.0.221.core.gz
