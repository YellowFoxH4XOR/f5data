Description

Seeing significant CPU utilization spike on the odd numbered CPU cores, on a BIG-IP that was at one time managed by a BIG-IQ.

The spikes are intermittent, occurring once every few days, and lasting for less than 5 minutes.

Environment

  • BIG-IP that was previously managed by a BIG-IQ

Cause

A previously scheduled task related to BIG-IQ's device management is running.

Recommended Actions

Log messages similar to the following are logged to  /var/log/restjavad.0.log:

[WARNING][453182][<date> <time> UTC][8100/cm/autodeploy/software-images SoftwareImageWorker] Failure updating software image list: java.util.concurrent.TimeoutException: remoteSender:http://localhost:8100/cm/autodeploy/software-images, method:PUT

Note: REST logs are in UTC, which may be different to the device time.

When these log messages are present, run the following command from the command line of the affected device:

clear-rest-storage

Important: Do not run this command on devices with SSLO provisioned.

Additional Information

You may additionally be able to identify this by looking at the output of top; Java may be the biggest consumer of CPU time during the spikes
