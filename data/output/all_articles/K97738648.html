Issue

Error Message

01070418:5: connection <address> (user <username>) was closed with active requests

In this error message, note the following:

  • <address> is a pointer address for the internal process connection.
  • <username> is the name of the system user running the process.

For example:

01070418:5: connection 0x59c442c8 (user admin) was closed with active requests

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions are met:

  • A system process has connected to the Master Control Program (mcpd) to begin a transaction, however no data was transferred for five minutes.
  • A system process has connected to mcpd, and the connection closed prematurely.

Impact

These messages typically resolve with no impact.

Recommended Actions

If the error messages continue appearing in the /var/log/ltm file, gather a diagnostic qkview file and open a support case to further troubleshoot the issue. For assistance creating a qkview and opening a support case, refer to the following articles:

  • K12878: Generating BIG-IP diagnostic data using the qkview utility
  • K2633: Instructions for submitting a support case to F5
