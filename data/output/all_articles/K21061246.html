Description
This article may help to add a host to the SNMP allowed-addresses list via curl.

Environment

  • API
  • BIG-IP
  • SNMP allowed address-list

Cause
None.

Recommended Actions

The following command got a successful result:

# curl -sku USER:PASSWORD https://x.x.x.x/mgmt/tm/util/bash -X POST -H "Content-Type: application/json" -d "{\"command\":\"run\",\"utilCmdArgs\":\"-c 'tmsh modify sys snmp allowed-addresses add { z.z.z.z/32 }'\"}"

Note:
The command should work with local authentication, consider the following:
- You may use x.x.x.x or your FQDN host.
- Replace "USER:PASSWORD" with your local credentials.
- Replace "z.z.z.z/32" with the new SNMP host IP address.
