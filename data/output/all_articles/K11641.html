Known Issue

This is the result of a known issue. If you attempt to install BIG-IP version 10.1.0 or later from the System >> Software Management screen to a volume or partition that has BIG-IP version 10.0.0 installed, the Configuration utility reports the following message at the top of the screen even though the installation process is not triggered:

Success
The requested operation completed successfully.

Additionally, an error message that appears similar to the following example is logged to the /var/log/tomcat4/catalina.out file:

ERROR [Thread-19] sw_updates.SoftwareInstallConfirmationHandlerBS3:error - java.util.NoSuchElementException
at java.util.StringTokenizer.nextToken(Unknown Source)
at com.f5.tmui.system.handler.sw_updates.SoftwareInstallConfirmationHandlerBS3.afterOperations(Unknown Source)

F5 Product Development tracked this issue as CR121181 and it was fixed in BIG-IP version 10.0.1. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WAN Optimization release notes.

Important: Since the issue exists in the BIG-IP version 10.0.0 software package and not in the Configuration utility, this issue will still occur on later versions of BIG-IP software if you attempt to install BIG-IP version 10.1.0 or later on a volume or partition that has version 10.0.0 installed.

Workaround

You can work around this issue by upgrading the BIG-IP software using the bigpipe software command. The procedure varies depending on the version of BIG-IP software running on the active partition and whether the BIG-IP system is formatted for volumes or partitions. For installation instructions, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

Note: Although the instructions refer to installing a hotfix, the procedure is the same for upgrading the version of BIG-IP software.
