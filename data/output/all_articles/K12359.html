Known Issue

This is the result of a known issue. Administrators assigned to a user-defined Administrative Realm cannot view failed logon attempts if the logon name is not defined in the local user database.The administrator will view all failed attempts for defined user accounts, but will not view attempted logon attempts of invalid users on FirePass.

F5 Product Development is tracking this issue as ID 327692 (formerly CR141470) 

This issue has been fixed in cumulative hotfix Hotfix-HF-70-1 issued for FirePass version 7.0.0 and in HF-610-4 for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.
