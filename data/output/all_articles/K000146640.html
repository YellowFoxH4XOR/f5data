K000146640: When I enable HTTP2 in my Origin Pool configuration, I get the following error: Error 502 - Bad Gateway

Type
Support Solution
Published
2024-11-08
Updated
2025-02-11
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000146640

Description

You are unable to Enable HTTP2 under HTTP Protocol Configuration in the Origin Pool configuration.
 

Environment

  • F5 Distributed Cloud

Answer/Recommended Actions

  • Your Origin Server (backend server) may not be properly configured for HTTP/2.
  • The best way to verify this is to consult your application team.
  • cURL can be used to gather some clues about HTTP/2 compatibility:
    • The value of the HEAD output below will indicate if your Origin Server is properly configured for HTTP/2
curl -I --http2 www.example.com:443 -v  <- Force cURL to use HTTP/2 to test for compatibility

*   Trying 159.60.x.x:443...
* Connected to www.example.com (159.60.x.x) port 443
> HEAD / HTTP/1.1 <- In this example, the Origin Server does not support HTTP/2
> Host: example.com:443
> User-Agent: curl/8.4.0
> Accept: */*
> Connection: Upgrade, HTTP2-Settings
> Upgrade: h2c
> HTTP2-Settings: xxxxxxxxxx
> 
* Recv failure: Connection reset by peer
* Closing connection
curl: (56) Recv failure: Connection reset by peer
