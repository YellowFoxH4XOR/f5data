Description

BIG-IP VE Deployment and Support in Azure VMware Solution. BIG-IP VE deployments of all supported versions is supported in Azure VMware Solution platform. There are no special considerations or requirements for deploying BIG-IP VE in Azure VMware Solution platform as the requirements are the same as in any ESX environment.

Environment

  • BIG-IP VE deployment on Azure VMware Solution platform

Cause

None

Recommended Actions

None

Additional Information

Azure VMware Solution platform comprises of bare metal VMware ESX servers and deployments as such BIG-IP VE will be running in native VMware environment. For more details, refer to the VMware and Azure documentation.
