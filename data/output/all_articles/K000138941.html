Description

This article has example log messages in /var/log/audit.log when changing a pool member Load Balancing Method and what you should see in the audit log.

Global Availability = gtm_wideip_lbmode_pool 6
Ratio = gtm_wideip_lbmode_pool 3
Round Robin = gtm_wideip_lbmode_pool 2
Topology =  gtm_wideip_lbmode_pool 4

Cofiguration Utility
Local Traffic  ››  Pools : Pool List >> PoolName >> Members >> Load Balancing Method

Environment

GTM / DNS
CLI access
Pool member load balancing method changes

Cause

Working as designed

 

Recommended Actions

You can monitor the /var/log/audit.log when changing a pool member Load Balancing Method

# cat /var/log/audit.log | grep -i <poolMemberName>

Example: 01070417:5: AUDIT - client tmsh, tmsh-pid-13499, user root - transaction #1827544-2 - object 0 - modify { gtm_pool { gtm_pool_name "/Common/ExamplePool" gtm_pool_lb_mode 6 gtm_pool_pool_type 1 } } [Status=Command OK]
Mar 15 16:11:52 <DeviceName> notice tmsh[13499]: 01420002:5: AUDIT - pid=13499 user=root folder=/Common module=(tmos)# status=[Command OK] cmd_data=modify gtm pool a ExamplePool load-balancing-mode global-availability
