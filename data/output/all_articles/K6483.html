Topic

When BIG-IP and 3-DNS systems are configured to communicate using TCP iQuery and the BIG-IP system is configured with a large number of virtual servers, iQuery may run out of buffer space when queuing connections. When this occurs, 3-DNS logs the following error message:

iqBufAdd failed for <address>: Resource temporarily unavailable:tasks:c:1082

This error message does not indicate a problem. The information that would not fit in the current buffer is transmitted in a later connection.

You can prevent this condition by configuring the 3-DNS and BIG-IP systems to use UDP iQuery instead of TCP iQuery. For more information, refer to K344: Configuring iQuery to use TCP or UDP.
