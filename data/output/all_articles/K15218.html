Known Issue

Attempting to open multiple BIG-IP APM sessions may fail.

This issue occurs when all of the following conditions are met:

  • The user's browser is configured to open multiple browser instances (home page tabs) that reference the same BIG-IP APM access profile.
  • The BIG-IP APM access profile is not a Secure Web Gateway (SWG) access profile.
  • The user opens the browser launching all the BIG-IP APM access profile requests simultaneously.

Impact

Establishing multiple BIG-IP APM sessions may fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users may receive an error messages similar to one the following example:

    • Your session could not be established. Invalid Session ID.
      Your session may have expired.
    • Access policy evaluation is already in progress
  • The BIG-IP APM system might reset some or all access profile browser requests.

Workaround

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

To work around this issue, you can establish a single session to the BIG-IP APM system before opening multiple browser instances that reference the same BIG-IP APM access profile.
