Description

  • Merging BIG-IP DNS configuration from a file fails
  • Using 'tmsh load sys config gtm-only file <filename> merge'
  • Error message: Either devices or addresses must be specified

Environment

  • BIG-IP DNS
  • Config file created using 'tmsh list gtm <object>'
  • No syntax issues in the file
  • configuration file looks correct with all relevant data

Cause

You are not able to import gtm server config containing both "devices" and "addresses" definition. 

Recommended Actions

Removing the address section from the config file resolves the issue.
 

Non-working example;

gtm server testserver.net {
    addresses {
        10.10.10.10. {
            device-name /Common/testserver.net
        }
    }
    datacenter test_dc
    devices {
        testserver.net {
            addresses {
                10.10.10.10 { }
            }
        }
    }
    product generic-host
    virtual-servers {
        vs_test_vs_443 {
            destination 10.10.10.20:443
        }
    }
}

working example;
gtm server testserver.net {
    datacenter test_dc
    devices {
        testserver.net {
            addresses {
                10.10.10.10 { }
            }
        }
    }
    product generic-host
    virtual-servers {
        vs_test_vs_443 {
            destination 10.10.10.20:443
        }
    }
}

Additional Information

Extract the configuration from /config/bigip_gtm.conf file and modify this to build the merge file intended for import.
