Description

You have login to the BIG-IP Configuration Terminal (GUI) and when you navigate to several objects you are getting the following error message:
Internal server error while authorizing request

Here are some objects (pages) that you will see this error message:
Local Traffic  ››  Policies : Policy List
Local Traffic  ››  Virtual Servers : Virtual Server List  ››  <VS Name>  ››  Security  ››  Policies
System  ››  Support  ››  Support

This error message can appear at other objects (pages).

Environment

  • BIG-IP Configuration Terminal (GUI)
  • Error "Internal server error while authorizing request"

Cause

Daemons related to the BIG-IP Configuration Terminal (GUI) has stalled.

Recommended Actions

You will need to restart httpd, restjavad and tomcat to resolve the issue.

  1. Login to the command line of the BIG-IP.
     
  2. Run command:
    tmsh restart sys service httpd restjavad tomcat
    Note: When restarting these services, you will lose access to the GUI and you will need to login again. You will also have limited REST access to the control plane during the daemon restart.
     
  3. If the step above does not resolve the issue, you will need to do a MCPD reboot as per article K40134016.

Additional Information

None.
