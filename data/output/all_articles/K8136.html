Topic

This article applies to BIG-IP 9.x - 10.x. For information about other versions, refer to the following article:

  • K13831: Missing or corrupt default SSL certificate and key pair may generate errors (11.x)

When the BIG-IP software is installed, the system generates a default SSL certificate and key pair and associates them with the clientssl profile. The default SSL certificate and key pair are called default.crt and default.key.

The default SSL certificate and key pair are required for system operation and should not be deleted. The BIG-IP system checks the validity of the default certificate and key pair when the system is upgraded or the configuration is loaded.

For example, when the bigpipe load command is issued, the BIG-IP system parses the /config/profile_base.conf file and verifies that the default SSL certificate and key pair exist and make a valid pair. If the default.crt, and default.key files do not exist, or are not a matching SSL certificate and key pair, the BIG-IP configuration fails to load properly and the system generates a bigpipe error message in the console that appears similar to one of the following examples:

  • When the default.key file is missing, the error message appears similar to the following example:

    BIGpipe client SSL profile operation error:
    01070313:3: Error reading key PEM file /config/ssl/ssl.key/default.key for profile clientssl: No such file or directory

  • When the default.key file is corrupt, the error message appears similar to the following example:

    BIGpipe client SSL profile operation error:
    01070313:3: Error reading key PEM file /config/ssl/ssl.key/default.key for profile clientssl: error:0906D064:PEM routines:PEM_read_bio:bad base64 decode

  • When the default.crt file is missing, the error message appears similar to the following example:

    BIGpipe client SSL profile operation error:
    01070313:3: Error reading cert PEM file /config/ssl/ssl.crt/default.crt for profile clientssl: PEM formatting error

  • When the default.crt file is corrupt, the error message appears similar to the following example:

    BIGpipe client SSL profile operation error:
    01070313:3: Error reading cert PEM file /config/ssl/ssl.crt/default.crt for profile clientssl: PEM file contains no certificates

Regenerating the default SSL certificate and key pair

If you have deleted the default SSL certificate and key pair, you can regenerate them by performing the following procedure:

  1. Log in to the command line.
  2. Generate the default SSL private key by typing the following command:

    gencert -n default 1024

  3. Generate the SSL certificate by typing the following command:

    openssl req -new -key /config/ssl/ssl.key/default.key -x509 -out /config/ssl/ssl.crt/default.crt

  4. To load the BIG-IP configuration, type the following command:

    bigpipe load
