K77853033: F5OS-C Tenants do not reflect trunk members changes made on a Partition

Type
Support Solution
Published
2022-09-15
Updated
2023-02-21
Applies to
  • VELOS Platforms
  • F5OS
  • F5OS-C: 1.2.X, 1.1.X, 1.1.1, 1.1.0, 1.3.2, 1.3.1, 1.3.0, 1.3.X, 1.2.1, 1.2.0, 1.1.4, 1.1.3, 1.1.2, 1.2.2
Source
https://my.f5.com/manage/s/article/K77853033

Description
On a partition, LAGs member (port) are changed, but Tenant shows in Trunk old config.

Environment

  • F5OS-C
  • Velos
  • v1.1.x-v1.3.x
  • Tenant: Trunk
  • Partition: LAGs
     

Cause

  • Bug ID 1053113


Recommended Actions

Upgrade to 1.5 or later

If you are not able to upgrade, then
After checking all tenants for Bug ID 950901 as this issue could lead: K45993455: F5OS-C Velos Tenant management port access GUI CLI is intermittent, after upgrade / one of blade is rebooted, follow below
  1. Log in to the partition GUI, and go to SYSTEM SETTINGS >> General
  2. Click "Reboot" for one of the slots
  3. Wait the blade "Role" becomes Ready
  4. Repeat step 2 and 3 and reboot all blades
     

Additional Information

  • K80399720: F5OS-C VELOS Tenant incorrectly reports trunks status.
