Topic

Device Services Clustering (DSC) provides the foundation for centralized management and high-availability features, such as configuration synchronization (ConfigSync), failover, and mirroring. 

Description

DSC components include device trust, device groups, traffic groups, the ConfigSync IP address, the failover and mirroring IP addresses, and the communication channels that make them possible. The BIG-IP objects that make these possible include VLANs, self IP addresses, including one or more floating self IPs, logins for each BIG-IP device, and NTP. When you deploy a BIG-IP device group, it may be helpful to write down the necessary information ahead of time. The following table may be helpful for recording these values for each of the devices in your device group.
 
ObjectDescription / recommendationsValue                                     
BIG-IP hostnameThe FQDN name of the device 
Device numberThe number of the device in the group (such as 1 of 3) 
Peer or subordinateThe trust domain device designation: peer or subordinate. 
Management IP addressThe IP address for the management (administrative) port 
Management default routeThe IP address of the default route for the management port 
NTP server addressThe NTP server address assigned to the device 
DNS server address(es)The DNS server address assigned to the device 
ConfigSync AddressThe local IP address that the system uses for ConfigSync operations
F5 recommends using a self IP address and an internal or dedicated VLAN for ConfigSync traffic.
