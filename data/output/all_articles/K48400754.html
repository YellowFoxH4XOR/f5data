Known Issue

Network access and endpoint inspection fail when using Chrome 64 and later.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is running APM clients 7.1.5 or 7.1.6.
  • Users establish sessions to the BIG-IP APM system using Chrome 64 or later versions on the Windows operating system.
  • The users attempt to launch network access or endpoint inspection from a BIG-IP APM webtop.

Beginning in version 64.0.3282.119, Chrome uses URLEncode when launching network access and endpoint inspection.

Impact

Network access and endpoint security fail when using Chrome 64 and later. 

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using Chrome 64 and later, users cannot establish network access.
  • When using Chrome 64 and later, endpoint inspection fails.
  • BIG-IP APM network components are not updated.

Workaround

There is no workaround for this issue. However, you can use Mozilla Firefox or Microsoft Edge to launch network access and endpoint inspection.
