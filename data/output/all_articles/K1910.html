To enter the SSL Proxy client certificate information into the header of the HTTP session using the Configuration utility, perform the following steps:

  1. From the left navigation pane of the Configuration utility, choose Proxies.

  2. Choose the Proxy Server you want to modify.

  3. Click the Proxy Advanced Properties tab.

  4. Check the box next to Insert Cipher in order to insert the client cipher.

  5. BIG-IP enters the following HTTP header:

    SSLClientCipher: RC4-MD5, version=TLSv1/SSLv3, bits=128

  6. From the Client Certificate drop-down box, you can choose to have BIG-IP SSL proxy Request, Require, or Ignore client certificates. These options are outlined as follows:

    Request
    The proxy requests and verifies the client certificate. In this case, the proxy always grants authentication, regardless of the status of the certificate.

    Require
    The proxy requires a client to present a valid and trusted certificate before granting authentication.

    Ignore
    The proxy ignores any client certificates, and therefore always grants authentication. This is the default.

    After choosing to Request, Require, or Ignore client certificates, you could then configure the BIG-IP to insert into the HTTP header the values you want from the client certificate.

  7. You can choose the information to be inserted into the header by checking the boxes next to Insert Certificate.

    The following examples show actual HTTP headers that are inserted into the connection when you check one of the boxes.

    Note: For a CGI program to parse these headers, you will need to precede the header with HTTP_ then the header name. For example: HTTP_SSLClientCertSubject:.

    Example of header and data inserted by checking the Subject box, which specifies the subject of the certificate:

    SSLClientCertSubject: /Email=j.smith@abc.com/C=US/ST=WA/L=Wellesley/
    O=abc.com/OU=Engineering/CN=john smith

    Example of header and data inserted by checking the Version box, which specifies the version of the certificate:

    SSLClientCertVersion: 3

    Example of header and data inserted by checking the Serial Number box, which specifies the serial number of the certificate:

    SSLClientCertSerialNumber: 61:81:09:15:00:00:00:00:00:0a

    Example of header and data inserted by checking the Signature Algorithm box, which specifies certificate signature algorithm of the certificate:

    SSLClientCertSignatureAlgorithm: sha1WithRSAEncryption

    Example of header and data inserted by checking the Issuer box, which specifies the certificate issuer:

    SSLClientCertIssuer: /C=US/ST=WA/L=Wellesley/O=abc.com/OU=Engineering/CN=abc

    Example of header and data inserted by checking the Validity box, which specifies validation dates of the certificate:

    SSLClientCertNotValidBefore: Feb.11.18:51: 29.2002 GMT

SSLClientCertNotValidAfter: Feb.11 19:01:29 2003 GMT

    Example of header and data inserted by checking the Subject Public Key box, which specifies subject public key type (one of RSA ([size] bit), DSA, or Unknown public key):

    SSLClientCertSubjectPublicKey: RSA (512 bit)

    Example of header and data inserted by checking the Certificate Hash box, which specifies MD5 hash of the client certificate:

    SSLClientCertHash: CE:18:A7:ED:2C:4A:24:AD:C8:52:F2:9C:0E:AD:2B:C0

    Example of header and data inserted by checking the Certificate box, which specifies entire client certificate:

    SSLClientCert: -----BEGIN CERTIFICATE-----........Cert data......-----END CERTIFICATE-----
