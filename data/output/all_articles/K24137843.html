Description

Mitigation of SNMP 'GETBULK' Reflection DDoS vulnerability.

Environment

  • Nessus Scanner used to audit vulnerabilities
  • Vulnerability ID 76474
  • SNMPv2 configuration on the BIG-IP
Cause

None

Recommended Actions

According to the recommendation provided by Nessus: https://www.tenable.com/plugins/nessus/76474, we should disable SNMP service on the remote host (BIG-IP device, in this case) if it's not in use.
Otherwise, restrict and monitor access to this service, and consider changing the default 'public' community string.

We have the following recommendation in place to restrict access to the SNMP system:
K13535: Restricting SNMP access to the BIG-IP system

None
