Topic

iControl SDK (Software Development Kit) versions match the BIG-IP software version with which they are released. Each SDK release maintains full backward compatibility with previous BIG-IP software releases within the same major branch and forward compatibility within the same minor branch. The following table illustrates the BIG-IP software versions supported by each SDK version that is currently available for download on the DevCentral site:

iControl SDK versionCompatible BIG-IP versions
iControl SDK Version 11.1.0BIG-IP 11.0.0 through 11.5.0
iControl SDK Version 10.2.0BIG-IP 10.0.0 through 10.2.4
iControl SDK Version 10.1.0BIG-IP 10.0.0 through 10.1.0
iControl SDK Version 10.0.0BIG-IP 10.0.0 through 10.1.0
iControl SDK Version 9.6.0BIG-IP 9.0.0 through 9.6.1
iControl SDK Version 9.4.0BIG-IP 9.0.0 through 9.4.8
iControl SDK Version 4.6.3BIG-IP 4.1.1-PTF02 through 4.6.4

When using a more recent version of the SDK than your BIG-IP software, the SDK may include new methods that do not exist in the earlier BIG-IP software version. To take advantage of the new methods, you must upgrade your BIG-IP software to at least the same version as the SDK.

The currently available iControl SDK releases may be downloaded from F5 DevCentral site, at the following location:

https://devcentral.f5.com/Wiki/iControl.F5downloads.ashx

Note: A separate DevCentral login is required to access this content.
