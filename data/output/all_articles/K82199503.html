Description

  • You are attempting to duplicate syslog data (UDP port 514) by assigning a clone pool with an additional syslog server as a member.
  • No data is received at the clone pool member.

Environment

  • A Virtual Server receiving syslog packets from external sources.
  • A clone pool assigned to the Virtual Server with an additional syslog server.

Cause

The clone pool member is not an IDS server.

Recommended Actions

  1. This is an invalid configuration. Only IDS servers which listen promiscuously can be member of a clone pool.

Additional Information
The reason is clear when you consider what is happening.

  1. The BIG-IP learns the MAC address of the clone pool member (It must be on a VLAN)
  2. A packet is cloned. Its source address is A, destination address is B and the clone pool member  IP address is C.
  3. The clone feature sends the packet to the MAC Address of C.
  • An IDS system will record this packet.
  • Any normal server will see a packet that is for  B but it's address is C. The packet is dropped in the protocol stack.
BIG-IP software does not have the capability of duplicating a UDP packet to multiple destinations.
