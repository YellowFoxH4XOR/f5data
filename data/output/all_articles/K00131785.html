Topic

The example in this video demonstrates how to create and deploy application services into data centers in Boston and Seattle. The example uses two roles:

  • Administrator—Downloads, clones, customizes, and makes an application template available for an application owner
  • Application owner—Creates an application and application services for two data centers

You should consider using this procedure under the following condition:

  • You want to use the BIG-IQ system and the Application Services 3 extension (AS3) to deploy application services to multiple data centers.

Description

You can also find the video here: Deploy Consistent Application Services with BIG-IQ and AS3.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a BIG-IQ role that enables you to download, clone, and customize AS3 templates on your BIG-IQ.
  • You have a BIG-IQ role that enables you create an application on your BIG-IQ.

Procedures

  • Downloading an AS3 template
  • Creating a new template
  • Making the template available for the application owner
  • Creating an application and adding the first application service
  • Adding the second application service

Downloading an AS3 template

You download AS3 templates from a Git repository maintained by F5. There are instructions in the repository that explain how to download templates to your BIG-IQ. For example, you can:

  • Use a script in SSH to download and import the templates.
  • Use the Postman application to import templates directly to your BIG-IQ.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Applications  > Application Templates.
  2. Click Import Templates.

    The BIG-IQ AS3 Template Library in Git displays

  3. Follow the instructions to download the template you want to your BIG-IQ.

Note: You can share your templates by submitting them to F5 using the Git repository. F5 reviews submissions and posts some for others to use. To submit a template, log in to your Git account, and then on the Code tab, click New pull request.

Creating a new template

Because you cannot edit a published template, to create a new template, clone a default AS3 template on your BIG-IQ and then customize it to meet your needs.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Cloning an existing AS3 template

  1. Go to Applications  > Application Templates.
  2. Under AS3 Templates, select the template you want, and then click Clone.
  3. Type a name for the template and then click Clone.

    Your new template displays at the bottom of the list.

Customizing the template

After you clone the template, you can configure it, including giving the application owner access to the tenant name, customizing classes, and changing the load balancing method.

  1. Click the template name.

    Note: By default, Tenant is blank and editable so that the application owner can see and edit the name. You can change these settings using the corresponding Override and Editable check boxes.

  2. To customize a class, in the left navigation, next to Classes, click Add/Remove.

    Note: For information about each class, in the upper-right, click Help (?).

  3. To change the load balancing method, click Pool, and then under Properties, in the LB mode list, click the method you want.
  4. Click Save.
  5. Click Publish & Close.
  6. Click Publish.

The template is now available to use to create application services.

Making the template available for the application owner

To enable the application owner to create an application, give them the Application Creator AS3 role, and then assign the template you published to them.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to System > Roles > Custom Roles > Application Roles.
  2. Under Custom Application Roles, click Application Creator AS3.
  3. Under General Properties, in the Active Users and Groups box, select the name of the application owner, and then click Move Right (->).
  4. In the AS3 Templates box, select the template you just published, and then click Move Right (->).
  5. Click Save & Close.

Creating an application and adding the first application service

This example uses the following:

  • Two server addresses—The application owner deploys application services into data centers in Boston and Seattle, using two application servers.
  • Tenant name—An AS3 tenant is a collection of AS3 application services that becomes a partition on the BIG-IP system, and you have to name the tenant.
  • A WAF policy that uses OWASP-recommended minimum protection settings.
Impact of procedure: Performing the following procedure should not have a negative impact on your system.
  1. On the BIG-IQ dashboard, click Create.
  2. Under Application Properties, in Application Name, type a name for the application.
  3. Under Select an Application Service Template, on the Template Type list, select the template you created.
  4. Under General Properties, in Application Service Name, type a name for the service.
  5. On the Target List, select the BIG-IP system you want.
  6. In Tenant, type a name for the tenant (the partition on the BIG-IP system).
  7. Under Pool, in Server Addresses, type the address for the first server, and when you have two servers, click Add (+), and then type the address of the second server.
  8. Under Service_HTTPS, in Virtual addresses, type the address for your virtual server.
  9. Under Certificate, in the certificate box, to copy your certificate key into the box, right-click and then click Paste.

    Note: Ensure your certificate key does not contain any escape characters, such as a backslash (\).

  10. In the privateKey box, to copy your private key into the box, right-click and then click Paste.

    Note: Ensure your private key does not contain any escape characters, such as a backslash (\).

  11. Under WAF_Policy, ensure you use a WAF policy that uses OWASP-recommended minimum protection settings.
  12. To see the AS3 declaration JSON, in the upper-right, click View Sample API Request.

    Note that the BIG-IQ adds any necessary escape characters for you.

  13. Click Create.

Adding the second application service

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. On the BIG-IQ dashboard, click the name of the application you just created.
  2. On the dashboard for your application, click Create.
  3. Repeat steps 2–13 in the procedure above.

Notes:

  • The dashboard for your application displays a list of the application services you add.
  • The top section of the dashboard displays an aggregation of data for all the services in the application.
  • To return from the application dashboard to the BIG-IQ dashboard for all applications, click the Back (<-) button.
