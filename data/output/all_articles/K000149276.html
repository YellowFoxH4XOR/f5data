Description

Creating or updating a certificate to NIM through the certs API endpoint fails. One of the following two error code and message responses may occur.

{
 "code": 100,
 "details": [
 {
 "description": "request body has an error: failed to decode request body: invalid character '\\n' in string literal"
 }
 ],
 "message": "Failed to validate Request"
}
{
 "code": 134049,
 "message": "Error creating the certificate: the certificate request body is ill formed. Please check the request and try again."
}

Environment

NGINX Instance Manager

Cause

The certificates within the endpoint request JSON data are not properly formatted.

Recommended Actions

Use the following commands to output your certificate text and key text (and CA text, if used) to a JSON supported string. 

awk 'NF {sub(/\r/, ""); printf "%s\\n",$0;}' <private_key_file>
awk 'NF {sub(/\r/, ""); printf "%s\\n",$0;}' <public_cert_file>
awk 'NF {sub(/\r/, ""); printf "%s\\n",$0;}' <ca_cert_file>
