Known Issue

This is the result of a known issue. The BIG-IP ASM WSDL conversion engine is unable to load a SOAP method element definition when the method and method type are defined in different XML namespaces. When the conversion fails, the creation of the XML profile will fail. In addition, the Configuration utility will display an error message that appears similar to the following example:

An error has occured while processing the schema. (Schema parsing error at: <xsd:element name="myelement" type="tns1:myelemt__method"/>: unknown type for element )

F5 Product Development tracked this issue as ID 342710, and it was fixed in BIG-IP ASM version 10.2.2. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
