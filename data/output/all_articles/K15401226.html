Description

BIG-IP Linux(other) memory is gradually increasing over time.
Linux utilities like "top" show that most memory is allocated to avrd.
Once Linux(other) memory reaches 100% you might observer similar in /var/log/kern.log:

err kernel: Out of memory: Kill process 23647 (avrd) score 9 or sacrifice child
err kernel: Killed process 23647 (avrd) total-vm:4215904kB, anon-rss:499728kB, file-rss:3244kB, shmem-rss:72kB

Environment

  • BIG-IP 13.1.x or 14.x or 15.x
  • Memory is allocated to AVR, whether or not it is provisioned

Cause

Bug ID 828937

Recommended Actions

Recommendations are provided in below article:

  • K45725467: BIG-IP systems may experience long I/O wait times during AVR data aggregation

Additional Information

You may encounter one or more of the following additional symptoms:

  • The BIG-IP system experiences long I/O wait times and high CPU usage peaking at 10 minute, 1 hour, and 24 hour intervals.
  • Processes running on the BIG-IP system experience degraded performance or must be restarted.
  • The BIG-IP system generates a core file to the /shared/core/ directory.
  • High SWAP usage
