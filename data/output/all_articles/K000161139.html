Description

When monitoring DoS (Denial of Service) events in BIG-IQ Centralized Management, behavioral mitigation events for Layer 7 (L7) attacks may be recorded, but logs and the DoS Summary page show "0 drops." However, traffic may be impacted, resulting in timeouts and a decrease in traffic. This article explains why the drop fields remain empty for L7 behavioral mitigation and how to interpret these events.

Environment

  • BIG-IQ Centralized Management
  • BIG-IP devices with DoS L7 protection profiles enabled
  • Logging profiles configured for DoS event forwarding to BIG-IQ Data Collection Devices (DCDs)
  • Unified GUI in BIG-IQ displaying DoS Summary and DDoS HTTP Analysis dashboards

Cause

This behavior is by design. The DoS Summary page in BIG-IQ only populates the drop/incoming packet fields for L3/L4 attacks. For L7 behavioral mitigation events, these fields remain empty, even if mitigation actions impact traffic. 

Answer/Recommended Actions

  • For L7 behavioral mitigation, do not rely on the drop/incoming packet fields in the DoS Summary page; these are only relevant for L3/L4 attacks.
  • To analyze L7 attacks and mitigation actions, use the BIG-IQ dashboard:
    • Navigate to Dashboards > DDoS > HTTP Analysis for detailed information on L7 attacks and mitigation.
    • Review the AVR logs (e.g., /var/log/avr/avrd.log) for event details.
  • Ensure logging profiles are correctly configured to send DoS logs to the appropriate publisher (DoS, not ASM, for DoS events).
