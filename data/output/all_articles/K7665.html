Known Issue

This is a result of a known issue. If a Secure Sockets Layer (SSL) profile is modified while it is in use, it may cause the Traffic Management Microkernel (TMM) to stop responding. This issue is rare, as it requires the SSL profile to be modified during an SSL handshake.

Note: F5 recommends that you make changes to an SSL profile during a maintenance window, or when the virtual server associated with the SSL profile is disabled.

F5 Product Development tracked this issue as CR72320 and it was fixed in BIG-IP LTM 9.1.3. For information about upgrading, refer to the BIG-IP LTM release notes.
