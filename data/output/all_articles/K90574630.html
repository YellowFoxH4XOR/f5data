Description

Cluster has failed to Sync with showing the following error message:

Status Sync Failed
Summary A validation error occurred while syncing to a remote device

In /var/log/ltm you may find the following logs:

err mcpd[<PID>]: 01070821:3: User Restriction Error: Once configured [all] partitions, user cannot have a specific partition
err mcpd[<PID>]: 01071488:3: Remote transaction for device group /Common/<device_group_name> to commit id 2 6978775124636463405 /Common/device_name 0 failed with error 01070821:3: User Restriction Error: Once configured [all] partitions, user cannot have a specific partition.01070821:3: User Restriction Error

Environment

  • HA pair with ConfigSync
  • Unable to Sync
  • Using remote authentication

Cause

Bug ID 544906: Issues when using remote authentication when users have different partition access on different devices

Recommended Actions

It is recommended to upgrade to a fixed version. To workaround the issue on affected version, disable remote authentication, Sync the devices, and enable remote authentication again.

Note: Example below shows with ldap authentication.

  1. tmsh modify auth source { type local }
  2. Sync devices
  3. tmsh modify auth source { type ldap }

None
