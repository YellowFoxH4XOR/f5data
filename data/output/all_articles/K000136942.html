Description

  • The Manage Instances page on BIG-IP Central Manager shows a red "504" banner.  BIG-IP Next instances are not displayed. 
  • API calls to /api/device/v1/inventory return 504 Gateway Timeout.
  • mbiq-proxy-service and mbiq-device-feature are in CrashLoopBackoff.
  • In the mbiq-device-feature log is an entry: stdout P device module installer failed:  unexpected mbiq_device schema version. Expected : 1.63, current: 1.64

Environment

  • BIG-IP Central Manager
  • The configuration was successfully restored from a backup file

Cause

The configuration backup was restored to a newer version of Central Manager. 

Recommended Actions

If you are restoring a backup file on a new Central Manager instance:
  1. Power down the old Central Manager instance if it is not already powered down.
  2. Restore the backup file to a Central Manager instance that is running the same version as the instance where the backup was taken.

Additional Information

You can determine the Central Manager database schema version at the following API endpoint: 
https://{{bigip_next_cm_mgmt_ip}}/v1/version
