Description

While uploading file that is small or equal to long_request_buffer_size (10MB by default) after some time connection on server side is terminated / timeouts.

Environment

  • Uploading file via Virtual Server with ASM policy
  • Uploaded file is less than or equal to long_request_buffer_size long_request_buffer_size (10MB by default)

Cause

When the client sends a request that is greater than the long_request_buffer_size system variable, ASM checks only 10KB of requests for slow POST attacks and forwards it to server side, unless configured to reject long requests. When the client sends a request that is less than or equal to the long_request_buffer_size variable, ASM buffers and examines the whole request before sending it to server. If upload is slow and/or servers' Keep-Alive: timeout is low, this can cause the server-side connection to timeout and the upload will fail.

Recommended Actions

Increase the relevant timeout on the server and/or investigate slow upload speed.
