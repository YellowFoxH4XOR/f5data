K000149142: ASM fails to start after upgrade due to insufficient XML memory

Type
Support Solution
Published
2024-12-30
Updated
2025-02-05
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.X.X, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0
  • BIG-IP ASM: 17.X.X, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000149142

Description

After an upgrade, the ASM may fail to start (stay offline) with messages like the following reported to /var/log/ts/bd.log:

 

BD_XML|ERR |Sep 31 02:33:49.978|30656|xml_validation.cpp:0133|Cannot allocate 24 more bytes for XML parser. current memory size 471859194 (in bytes)

BD_XML|ERR |Sep 31 02:33:49.978|30656|xml_validation.cpp:2593|F5xmlConfigCreate failure. xml_id 2.
BD_XML|ERR |Sep 31 02:33:49.978|30656|xml_validation.cpp:2305|XMLConfigCreate failure. xml_id 2.
ECARD|ERR |Sep 31 02:33:49.978|30656|table.h:0551|KEY_PUT: Failed to PUT data
BD_MISC|ERR |Sep 31 02:33:49.978|30656|temp_func.c:2295|CONFIG_TYPE_PROTOBUF_FILENAMES message had parsing error: could not parse protobuf message
BD_MISC|ERR |Sep 31 02:33:49.978|30656|table_funcs.cpp:2734|CONFIG_TYPE_PROTOBUF_FILENAMES message had errors in block_index: 809. status=-1

Environment

One of the following modules is provisioned:

  • ASM
  • AFM

Cause

Insufficient XML memory available to accommodate the XML (or JSON) enforcement configuration.

Recommend Action

Increase—via the command line, as the ASM GUI will be unavailable—the amount of memory available to the XML engine, then restart ASM.

Additional Information

K10803: Customizing the amount of memory allocated to the BIG-IP ASM XML processing engine
