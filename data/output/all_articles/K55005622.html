Known Issue

When you use the pkcs12_import_from_file_v2() iControl command, the system displays an internal error response.

This issue occurs when one of the following conditions are met:

  • You use the pkcs12_import_from_file_v2 iControl() command immediately after you restart httpd.
  • You use the pkcs12_import_from_file_v2 iControl() command after the session-timeout period.

This issue does not occur if you make any other iControl call before using the pkcs12_import_from_file_v2().

Impact

The pkcs12_import_from_file_v2() command fails to run.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system sends the following SOAP faultstring:

    Exception caught in Management::urn:iControl:Management/KeyCertificate::pkcs12_import_from_file_v2() Internal Error; connection not set and no session from which to get it

  • The http server sends a 500 Internal Server Error.
