K000152664: Switching SSO/Auth Domains in APM leaves invalid configuration

Type
Support Solution
Published
2025-09-29
Updated
2025-10-08
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000152664

Description

When modifying an APM Access Session Policy in BIG-IP, specifically switching from "Multiple Domains" to "Single Domain" configurations in the SSO/Auth Domains tab, residual configuration elements such as domain-groups and primary-auth-service may remain in the configuration after reverting to "Single Domain" mode.

These leftover settings can render the APM policy non-functional. The issue is visible in the configuration file, where lines like domain-groups { ... } and primary-auth-service ... persist even after switching back to "Single Domain." These fields cannot be removed via the Web-GUI.

Environment

  • SSO/Auth Domains configured in the APM policy.
  • Configuration change: APM Access Session Policy with SSO/Auth Domains switching between "Single Domain" and "Multiple Domains"

Cause

the GUI do not remove the domain-groups and primary-auth-service settings from the configuration when reverting from "Multiple Domains" to "Single Domain" mode. Although these settings are ignored functionally in single-domain mode, their presence can cause confusion and operational issues.

Recommended Actions

Important: Before starting this action, make sure to back up the bigip.conf file.

To create a backup of the bigip.conf file, log in to the BIG-IP device via SSH and run the following command:

cp /config/bigip.conf /config/bigip.conf.$(date +%Y%m%d%H%M%S)

This command creates a backup copy of bigip.conf with the current date and time in the filename.

 

  • Workaround:
    1. Log in to the device via SSH.
    2. Enter the following command:
      nano /config/bigip.conf
    3. Make the necessary changes - manually remove the domain-groups and primary-auth-service settings from the configuration file.
    4. To save your changes, press Ctrl+0, then Enter.
    5. To exit the editor, press Ctrl+X.
    6. Reload and save the configuration:
      tmsh load sys config
      tmsh save sys config
    7. Restart the APM service if necessary:
      tmsh restart sys service apm

These fields cannot be removed via the GUI, and manual intervention is required.
