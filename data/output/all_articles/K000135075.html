Description

BIGIP unit with high control plane memory and high control plane CPU can lead to failover when the processes are being killed by Kernel outofmemory (OOM).

You will see following error message in /var/log/kern.log

warning kernel: <process name> invoked oom-killer: gfp_mask=0x201da, order=0, oom_score_adj=0

 

Environment

  • BIG-IP 
  • Multiple Modules Provisioned
  • Management memory set to small under system> Resource provisioning
  • HA Pair

Cause

Insufficient memory provisioned for BIG-IP modules

Recommended Actions

Try increase management memory using provision.extramb DB variable as described in following guide.

K26427018 : Overview of Management provisioning
