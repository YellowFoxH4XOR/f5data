Known Issue

The Configuration utility may erroneously add a carriage return to an Oracle monitor connection string.

This issue occurs when all of the following conditions are met:

  • You attempt to create or modify an Oracle monitor using the Configuration utility.
  • You configure an Oracle monitor with a database string that wraps to the next line of the Send String box in the Configuration utility.

Impact

The BIG-IP system may erroneously mark down pool members.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You observe a carriage return (^M) in the database connection string for an Oracle monitor configuration in the /config/bigip.conf file.
  • When you attempt to list the database connection string using the UNIX cat command, you observe a carriage return (^M) in the connection string. The command and output appear similar to the following example:

    cat -v /config/bigip.conf | grep -A1 '\^M'
    database "(DESCRIPTION =(ADDRESS =(PROTOCOL=TCP)(HOST=%node_ip%)(PORT=%node_port%))(CONNECT_DATA=(SERVICE_NAME=XE)^M
    (SERVER=DEDICATED)))"

    Note: The ^M character pair is the equivalent of a carriage return. Under normal circumstances, the /config/bigip.conf file should not contain a carriage return.

    By comparison, the command and output of a normally functioning configuration appears similar to the following example:

    cat -v /config/bigip.conf | grep database
    database "(DESCRIPTION =(ADDRESS =(PROTOCOL=TCP)(HOST=%node_ip%)(PORT=%node_port%))(CONNECT_DATA=(SERVICE_NAME=XE)(SERVER=DEDICATED)))"

Workaround

To work around this issue, you can edit the /config/bigip.conf file to remove the carriage return from the Oracle monitor configuration and then reload the BIG-IP configuration. To do so, perform the following procedure:

Impact of workaround: In order for the changes to take effect, the device must reload the configuration, which may result in a brief interruption in traffic processing.

  1. Log in to the BIG-IP command line.
  2. To create a backup of the configuration file, type the following command:

    cp /config/bigip.conf /var/tmp/bigip.conf.original

  3. Open the /config/bigip.conf file in a text editor.
  4. Search the file for the affected Oracle monitor's connection string. The configuration appears similar to the following example:

    database "(DESCRIPTION =(ADDRESS =(PROTOCOL=TCP)(HOST=%node_ip%)(PORT=%node_port%))(CONNECT_DATA=(SERVICE_NAME=XE)^M
    (SERVER=DEDICATED)))"

  5. Delete the carriage return (^M) so that the configuration appears similar to the following example:

    database "(DESCRIPTION =(ADDRESS =(PROTOCOL=TCP)(HOST=%node_ip%)(PORT=%node_port%))(CONNECT_DATA=(SERVICE_NAME=XE)(SERVER=DEDICATED)))"

  6. Save the file and exit the text editor.
  7. To re-load the BIG-IP configuration, type the following command:

    tmsh load /sys config
