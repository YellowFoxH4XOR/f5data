Description

This article provides guidance on configuring remote logging for Advanced WAF deployments

Environment

  • BIG-IP ASM

Steps

To monitor and audit security policy activity, you can configure a custom logging profile on the BIG-IP system to Remotely store Application Security events. Once created, this logging profile can be assigned to any Virtual Server where logging is needed.

Advanced WAF Remote Logging Configuration

For optimal performance when running Advanced WAF on vCMP systems, F5 recommends configuring remote logging to store Advanced WAF logs on remote syslog servers rather than locally. This is a performance optimization recommendation, not a requirement.

To configure remote logging for Advanced WAF:

  1. Navigate to Security > Event Logs > Logging Profiles in the BIG-IP GUI
  2. Click Create to create a new logging profile
  3. Enter a unique Profile Name
  4. Enable Application Security and set Configuration to Advanced
  5. Set Storage Destination to Remote Storage
  6. Choose the desired Logging Format:
    • CSV
    • Key-Value Pairs
    • Common Event Format (for ArcSight)
    • BIG-IQ
  7. Select the Protocol for remote logging (TCP, UDP, or TCP-RFC3195)
  8. Enter the Server Address and Port for your remote syslog server
  9. Configure optional settings:
    • Storage Format and Selected Items (for CSV format)
    • Report Detected Anomalies to log attack start/end events
    • Response Logging (Off, For Illegal Requests Only, or For All Requests)
    • Storage Filter to specify which requests are logged (Illegal, Staged, or All)
  10. Click Finished to save the profile
  11. Assign the logging profile to the relevant virtual server:
    • Go to Local Traffic > Virtual Servers
    • Select the virtual server
    • Under Security > Policies, enable Log Profile and select your remote logging profile
    • Click Update
  12. Verify logs are received on the remote server by generating traffic and checking log entries
