Description

Unable to boot the new BIG-IP Virtual Edition setup in VMware ESXi. Error: "No modules have memory, changing to initial boot configuration."

Environment

  • BIG-IP VE

Cause

ESXi VE requires more virtual memory to boot

Recommended Actions

Follow the steps below to add more virtual memory to the BIG-IP Virtual Edition system, through the VMware ESXi console:

  1. Turn Off the VE through the VMware ESXi console
  2. View the installation prerequisites on https://clouddocs.f5.com/cloud/public/v1/vmware/vmware_setup.html 
  3. Navigate to VE settings, increase the amount of virtual memory assigned to it
  4. Save the settings
  5. Turn On the ESXi VE
  6. If the error continues, repeat steps 1 through 4, increasing the assigned memory amount.

Impact of the procedure: As this is a new virtual machine, there will be no negative impact on traffic.
