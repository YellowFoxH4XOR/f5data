Issue

Error Message

info tmm[<PID>]: 01aa0006:6: ICAP (<Client IP Address:Port> -> <Virtual Server IP Address:Port>): Response completed after request completed - connection may be reused by 'oneconnect'

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <Client IP Address:Port> is the client IP address and port where the request originates.
  • <Virtual Server IP Address:Port> is the virtual server IP address and port being used on the BIG-IP

For example:

info tmm[22130]: 01aa0006:6: ICAP (10.0.0.1:65417 -> 172.16.100.17:443): Response completed after request completed - connection may be reused by 'oneconnect'

Message Location

You may encounter this message in the following location:

  • /var/log/ltm

Description

This message occurs when the following condition is met:

  • An Internet Content Adaptation Protocol (ICAP) response completes normally, and not before the ICAP request completes. This behavior indicates an ideal scenario in which the connection may be reused if the internal virtual server has a OneConnect profile; any abnormal or early termination prevents connection reuse.

Impact

There is no impact. You can safely ignore this error message.

Recommended Actions

None
