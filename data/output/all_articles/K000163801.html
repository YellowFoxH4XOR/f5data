Description

Initial management configuration commands may fail during deployment because mcpd is not yet ready, leaving the management IP address and route unconfigured.

Environment

BIG-IP Virtual Edition deployed on Nutanix with Terraform and cloud-init.

Cause

The tmsh commands ran before mcpd was ready to accept configuration changes.

Answer/Recommended Actions

Use F5 BIG-IP Runtime Init to run the management configuration after mcpd becomes available. Enable the bigip_ready_enabled section and use runmd for the management configuration commands.

This sequencing allows the management IP address and gateway configuration to complete successfully.

https://github.com/f5networks/f5-bigip-runtime-init
