Known Issue

Java applets which open network socket connections to a server may experience poor performance through the Portal access reverse-proxy engine. This issue occurs under high load conditions, particularly when numerous Java applets are executed. Additionally, when this issue occurs, the FirePass system memory may be excessively consumed, resulting in poor performance of the FirePass controller.

F5 Product Development tracked this issue as CR82118 and CR85175 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, this issue was fixed in cumulative hotfix HF-601-7 issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Note: For the best performance of Java applets through the Portal Access reverse-proxy engine, your FirePass controller should run FirePass version 6.0.2 or later, or FirePass version 6.0.1 with cumulative hotfix HF-601-8 or a later version of the cumulative hotfix.
