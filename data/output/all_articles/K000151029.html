Description

No Learning suggestions are displayed in the ASM Traffic Learning section, even though violations are visible in the ASM event Log.

 

Environment

  • BIG-IP ASM
  • No Learning suggestion

 

Cause

Misconfiguration in policy Learning and Blocking Settings, which do not match the application traffic.

 

  • When the "Learn only from non-bot traffic" option is enabled in an ASM policy, only requests identified as coming from known browsers are used for generating learning suggestions.
  • If most application traffic is not classified as non-bot (for example, due to custom User-Agent headers, API calls, automation tools, or non-standard browsers), no learning suggestions will be generated despite violations being logged.

 

Recommended Actions

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

 

  1. Go to Security › Application Security: Policy Building: Learning and Blocking Settings: Policy Building Process
  2. Disable the "Learn only from non-bot traffic" setting under Policy Building Process.

Disabling this option allows all incoming requests, regardless of bot classification, to be considered for learning suggestions.
