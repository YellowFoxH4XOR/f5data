K16657: BIG-IP APM support for the native Citrix StoreFront protocol

Issue

Old Behavior

In versions prior to BIG-IP 11.6.0 HF4, deployments that integrate BIG-IP APM with Citrix StoreFront use the legacy/PNAgent protocol for client and server communication.

New Behavior

Beginning in version 11.6.0 HF4, BIG-IP APM supports the native Citrix StoreFront 2.6 protocol when integrating with Citrix StoreFront.

The native StoreFront protocol supports a wider range of features than the legacy protocol, providing capable clients with the ability to access stores of aggregated resources.

Impact

Administrators can now use Citrix StoreFront 2.6 protocol for client and server communication when integrating BIG-IP APM with Citrix StoreFront servers.

Recommended Actions

When deploying the BIG-IP APM system with Citrix StoreFront, you should consider the following factors:

  • For deployments that require using the native StoreFront protocol, you should upgrade the BIG-IP APM systems to 11.6.0 HF4 or later.
  • Existing deployments may have Citrix Receiver accounts configured with the full path to the config.xml file on the server, in order to use PNAgent protocol.

    For example:

    https://<FQDN>/citrix/store/pnagent/config.xml

    To enable the native StoreFront protocol for these clients, you may need to either recreate the accounts or reconfigure the accounts using just the fully-qualified domain name (FQDN) rather than the full path to the server.

    For example:

    https://<FQDN>/
