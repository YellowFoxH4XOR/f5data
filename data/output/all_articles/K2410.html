Topic

Beginning with BIG-IP version 4.0, the manner in which the interfaces are addressed, including shared IP aliases for redundant systems, changed dramatically.

Interfaces are now addressed using a combination of VLAN assignments and self IP addresses, and the shared IP address for a redundant pair of BIG-IPs is now referred to as a floating self IP address. VLANs are configured logically by name, and the actual network interfaces are assigned to a VLAN and/or VLAN group.

For example, you can assign an interface to access your node servers' network to the internal VLAN, and then assign an address on that network to the VLAN as a self IP. You would do this by typing the following commands:

b vlan internal interfaces add 1.1

b self 10.1.1.1 vlan internal netmask 255.255.255.0

To add the shared IP address in a redundant pair for the internal network, type the b self command, with the optional floating argument, as follows:

b self 10.1.1.3 vlan internal netmask 255.255.255.0 floating enable

For more detailed information about creating VLANS, self IP addresses, and floating self IP addresses, refer to the BIG-IP manual.
