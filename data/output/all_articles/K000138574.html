K000138574: HTTP Auth fails with "Curl perform failed: Timeout was reached (28)"

Description

Access Policy logs show timeout errors during the HTTP Authentication step of the access policy. The issue manifests as authentication failures with error messages indicating that the "Curl perform failed: Timeout was reached." This problem has been observed in configurations where HTTP authentication is utilized to connect with external services, such as SMS servers for OTP verification.

 

Environment

BIG-IP APM configurations involving HTTP Auth with external services (e.g., SMS servers)

"Curl perform failed: Timeout was reached." error in logs

Cause

Failure of the external HTTP Auth server to respond to BIG-IP authentication requests, leading to retransmission attempts by the BIG-IP system and resulting in a RST and timeout. This suggests an issue with the server's availability or responsiveness.

Recommended Actions

Ensure that there is proper network connectivity between the BIG-IP system and the HTTP Auth server, and, as needed, contact your server administrator to check why it is not responding to requests from the BIG-IP.
