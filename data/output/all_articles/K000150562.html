Description

The F5OS_INTERNAL trunk is automatically created on the Tenant after upgrading to F5OS-C 1.8.0 and above.

 

Environment

  • F5OS-C
  • Tenant

 

Cause

This is due to an enhancement which would allow users to factor in the tenant's internal connectivity to each of the controllers in a HA-group configuration.

 

Recommended Actions

The F5OS_INTERNAL trunk can be ignored if there is no intention to utilise it.
