Description

Event logs do not have records just for some virtual servers with security log profile enable, but it has for others.
On some random virtual servers with a security log profile applied, event logs information is not displayed, but on some other virtual servers (even with the same profile) there are records on event logs.

Environment

  • BIG-IP ASM
  • Security Log Profile

Cause

During the time of the creation of this article, F5 is still researching the root cause for this, it seems to be due to a huge amount of logging that asm_config_server fails for new instances.
 

Recommended actions

  1. Restart asm_config_server

# pkill -f asm_config_server

  1. It is advice to also restart dcc
# pkill -f dcc
  1. After killing both services you can monitor that these services come back with the following command. (It should take around ~30 secs)

# ps aux | grep "dcc\|asm_config_ser"
