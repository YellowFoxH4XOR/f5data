K65312803: Restricting Enterprise Manager Configuration utility access to clients using high-encryption SSL ciphers

Topic

You should consider using this procedure under the following condition:

  • You want to limit Enterprise Manager Configuration utility access to clients using high-encryption Secure Sockets Layer (SSL) ciphers.

Description

High-encryption SSL ciphers include ciphers with key lengths longer than 128 bits, and some cipher suites with 128-bit keys.

By default, the Enterprise Manager Configuration utility allows a wide range of SSL ciphers for SSL clients to use when connecting to the Configuration utility. If you require a smaller, more secure list of SSL ciphers for Configuration utility access, you can modify the cipher list to only allow access to SSLv3, TLSv1, and keys that are 128 bits or larger.

For example, the following default cipher string for the Enterprise Manager 3.0.0 Configuration utility allows short key lengths that include 56 and 64 bits:

ALL:!ADH:!EXPORT:!eNULL:!MD5:!DES:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2

Note: In Enterprise Manager 3.x, SSLv2 is disabled at the protocol level. It is not necessary to disable the SSLv2 cipher.

The following replacement string allows only long and medium (128 bits or larger) key lengths; this string allows only SSLv3 or TLSv1 cipher suites, and no export or null cipher suites are allowed.

ALL:!SSLv2:!EXPORT40:!EXP:!LOW

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access the Traffic Management Shell (tmsh)

Procedures

Listing the current Configuration utility cipher string

Before you change the Configuration utility SSL cipher string, you should review the existing string for your specific Enterprise Manager version. To list the currently configured cipher string, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. List the currently configured cipher string by typing the following command:

    list /sys httpd ssl-ciphersuite

    For example, the Enterprise Manager 3.0.0 system displays a cipher string similar to the following:

    ALL:!ADH:!EXPORT:!eNULL:!MD5:!DES:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2


Restricting Configuration utility access to clients who use high-encryption SSL ciphers

Impact of procedure: Clients using low-encryption SSL ciphers will not be able to access the Enterprise Manager Configuration utility.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Restrict Configuration utility access to clients using high-encryption ciphers by typing the following command:

    modify /sys httpd ssl-ciphersuite 'ALL:!EXPORT40:!EXP:!LOW'
  3. Save the configuration change by typing the following command:

    save /sys config
