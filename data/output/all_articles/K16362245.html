K16362245: Configuring AFM TCP Half Open vector to provide SYN Cookie Protection for Virtual Servers

Type
Support Solution
Published
2021-12-28
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP AFM: 15.1.4
Source
https://my.f5.com/manage/s/article/K16362245

Description

BIG-IP AFM TCP Half Open Denial of Service (DoS) vector configuration in Device Protection and Network-enabled Protection profile provides SYN Cookie Protection for a Virtual Server under SYN Flood attack. It can be an alternative source of SYN Cookie Protection over Global or Per Virtual Server SYN Check threshold. AFM TCP Half Open vector requires the BIG-IP AFM module to be provisioned.

Environment

Virtual Server under SYN Flood attack
BIG-IP AFM is provisioned

Cause

The BIG-IP has multiple sources of SYN Cookie Protection and different configuration scenarios may provide it to Virtual Server under SYN Flood 

Scenario:
Does SYN Cookie Protection overflow to AFM TCP Half Open vector if Global or Default Per VS SYN check threshold are set and exceeded?

Answer: No, if Default Per Virtual Server SYN Check threshold is exceeded first, it will be the feature that will provide SYN Cookie Protection. Normally, Global SYN check threshold is set at a higher value than Default Per Virtual Server SYN Check threshold and observes half open TCP connections on the BIG-IP System and Virtual Servers. 
AFM TCP Half Open  vector configuration in Device Protection or Network enabled Protection Profile can provide SYN Cookie Protection if these mitigation thresholds are exceeded first. No overflow of SYN Cookie Protection to other BIG-IP features happens once one of these thresholds are exceeded.


Scenario:

Global SYN Check threshold is set

Default Per Virtual Server SYN Check threshold is set lower than AFM TCP Half Open vector

AFM TCP Half Open vector enabled on Device Protection

AFM TCP Half Open vector enabled on Protection Profile applied to a Virtual Server under SYN Flood attack
 

Answer: if Default Per Virtual Server SYN Check threshold value is lower than the AFM TCP Half Open vector mitigation threshold on Protection Profile, the Default Per Virtual Server SYN Check  will trigger and provide the SYN Cookie Protection and take precedence over the other enabled features.

tmsh show ltm virtual <Virtual Server Name under attack> output will also show SYN Cookies Status using either full-hardware or full-software indicating the source of  SYN Cookie Protection.


Scenario:

Global SYN Check threshold is set

Default Per Virtual Server SYN Check threshold is set to 0

AFM TCP Half Open vector enabled on Device Protection

AFM TCP Half Open vector enabled on Protection Profile applied to a Virtual Server under SYN Flood attack
 

Answer: The detection and mitigation threshold configured in AFM TCP Half Open vector configured on Network-enabled AFM Protection Profile takes precedence.

tmsh show ltm virtual <Virtual Server Name under attack> output will also show SYN Cookies Status using either full-hardware or full-software indicating the source of  SYN Cookie Protection

 

Scenario:

Global SYN Check threshold is set

Default Per Virtual Server SYN Check threshold is set to 0

AFM TCP Half Open vector enabled on Device Protection

AFM TCP Half Open vector enabled on Protection Profile in NOT applied to a Virtual Server under SYN Flood attack
 

Answer: The detection and mitigation threshold configured in AFM TCP Half Open vector on Device Protection takes precedence.

tmsh show ltm virtual <Virtual Server Name under attack> output will also show SYN Cookies Status as not-activated and Current SYN Cache value will be temporary filled - up to the Mitigation threshold configured for AFM TCP Half Open vector on Device Protection, then the value clears

 

Scenario:

Global SYN Check threshold is set

Default Per Virtual Server SYN Check threshold is set to 0

AFM TCP Half Open vector is set to Disabled or Detect Only on Device Protection

AFM TCP Half Open vector enabled on Protection Profile in NOT applied to a Virtual Server under SYN Flood attack

Answer: The Global SYN Check threshold will provide the SYN Cookie Protection

tmsh show ltm virtual <Virtual Server Name under attack> output will also show SYN Cookies Status using either full-hardware or full-software indicating the source of  SYN Cookie Protection


Recommended Actions

Use available SYN Cookie Protection to protect Virtual Servers from SYN Flood attacks and still allow legitimate clients to complete the TCP connection by configuring AFM TCP Half Open Vector in either Device Protection or Network-enabled Protection Profile per your needs or as an alternative to Global SYN Check or Default Per Virtual Server SYN Check features.
