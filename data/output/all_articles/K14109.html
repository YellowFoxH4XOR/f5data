Known Issue

When a BIG-IP GTM pool is created using the Traffic Management Shell (tmsh), the IPv4 fallback address field is populated with 0:0:0:0:0:0:0:0.

This issue occurs when all of the following conditions are met:

  • You use the tmsh command to create the BIG-IP GTM pool.
  • The fallback IP is not configured as one of the load balancing methods.

Impact

None

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The fallback IPv4 field address field is populated with 0:0:0:0:0:0:0:0.
  • When you use the Configuration utility to update the pool load balancing method, an error message similar to the following displays:

    Form Error
    One or more fields contain invalid values

Workaround

To work around this issue, you can delete the 0:0:0:0:0:0:0:0 IP address from the fallback IPv4 address field. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Global Traffic > Pools.
  3. Choose the affected pool, and click the Members tab.
  4. Remove the 0:0:0:0:0:0:0:0 IP address from the Fallback IPv4 address field.
  5. Click Update.
