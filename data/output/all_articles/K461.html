Known Issue



This is the result of a known issue. If you add a virtual server to a wide IP using a port other than zero, then change the virtual server to use a different port, the BIG-IP Link Controller will keep both virtual server definitions. As a result, multiple virtual servers will be defined, when only one should be defined.

F5 Networks Product Development is tracking this issue as CR28057 and CR41832. Monitor future BIG-IP Link Controller Release Notes for the status of these CRs.

Workaround

To work around this issue, perform the following steps:

  1. Log in to the command line.

  2. Change directories to /config/3dns/etc, by typing the following command:

    cd /config/3dns/etc

  3. Create a backup of the wideip.conf file, by typing the following command:

    cp wideip.conf wideip.conf.original

  4. Using a text editor, such a vi or pico, edit the wideip.conf file.

  5. Locate the section of the file that defines the virtual server that you want to change.

    You should see two lines that define the virtual server; one that uses the correct port and one that uses the old port.

  6. Delete the virtual server statement that uses the old port.

  7. Save the file and exit the editor.

  8. Load the configuration into memory, by typing the following command:

    3ndc restart
