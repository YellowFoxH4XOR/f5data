Known Issue

BIG-IP APM Multidomain single sign-on (SSO) may not function correctly for virtual servers using non-standard port configurations.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access profile is configured for Multidomain SSO.
  • Initial session access is to a virtual server that is configured to use a port other than 80 or 443.

Impact

Attempts to access the intended resource may fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • A user's initial session access to a virtual server that is configured using a port other than 80 or 443 is subsequently redirected to the configured access policy virtual server on port 443 for authentication.
  • After the user successfully authenticates, the user is redirected by the BIG-IP APM system back to the initial session access virtual server on port 80 or 443.
  • Attempts to access the virtual server resource fail due to a port mismatch between the configured virtual server port and the redirect port used.

Workaround

There is no workaround for this issue; access profiles configured with Multidomain SSO can be assigned only to virtual servers listening on ports 80 or 443.
