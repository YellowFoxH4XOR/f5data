K08283129: Getting the message ''A browser plugin is required to use this site'' opening RDP

Type
Support Solution
Published
2020-09-18
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K08283129

Description

When trying to open an RDP session, your browser shows the message "A browser plugin is required to use this site"

Environment

  • BIG-IP APM
  • RDP resources are ActiveX based.
  • When trying to establish an RDP session it comes up with a plugin prompt
  • Different browsers are affected.
  • This error is not seeing with IE
  • Chrome shows the following error: 
    A browser plugin is required t use this site. This version of Chrome web browser does not support automatic plugin installation

Cause
Bug ID 688651
ActiveX technology is being deprecated/likely not supported by modern browsers except IE. For Chrome and Firefox, you see likely the request to Install plugins.

Recommended Actions
Use Native RDP resources (Client Type - Native) instead.

Additional Information
Bug ID 688651: ActiveX/Java based RDP resources are deprecated
