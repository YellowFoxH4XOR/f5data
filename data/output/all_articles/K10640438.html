Topic

The manual resume feature allows you to control when to resume sending requests to the virtual servers in a BIG-IP DNS (formerly known as BIG-IP GTM) pool after the resources become available.

Description

When the manual resume feature is enabled on a BIG-IP DNS pool, if a member is marked down by a health monitor, the BIG-IP DNS device monitoring the pool member will also mark the pool member as disabled, and requires that the BIG-IP administrator manually re-enable the member once the health monitor marks it back up.

Note: A behaviour change introduced in v13.1.0 means the disabled status is both saved to config and is synchronized to BIGIP DNS sync group members.

If a virtual server defined as a member of a pool goes down, each BIG-IP DNS device in a sync group will learn the status change from a big3d probe response over an iQuery connection and independently mark the pool member down and, when manual resume is configured, each will mark it as disabled. Since each sync group member separately disables a pool member, the status is not synchronized.

The behavior described above will prevent a pool member from being unintentionally disabled on BIG-IP DNS devices that are correctly marking it up. For example, if one BIG-IP DNS loses its iQuery connection to a monitored BIG-IP and thus does not receive status change messages over iQuery, it will mark pool members associated to that BIG-IP down and disabled. The disabled state invoked by manual resume will appropriately not sync to other BIG-IP DNS devices that retain a connection to the BIG-IP system.

In the previous example, when the BIG-IP DNS device that lost the iQuery connection re-establishes it, it will continue to leave pool members disabled on pools with manual resume configured. In this scenario you will need to manually re-enable disabled pool members on the BIG-IP DNS device that lost and re-established iQuery connectivity. This change to the configuration will sync as normal.

Recommendations

When configuring manual resume on a BIG-IP DNS pool, you should consider the following factors:

  • The manual resume feature automatically disables pool members when a health monitor marks them down. You are required to manually re-enable members that have been disabled.
  • You may need to verify the pool member status on all BIG-IP DNS sync group members after a resource has been marked down and back up. In some situations, pool members will be disabled on all sync group members, in other circumstances pool members may only be disabled on a single or a subset of sync group members.
