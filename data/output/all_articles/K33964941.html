Description

BIG-IP is not syncing its time with its NTP server. When running ntpq -pn no NTP servers are seen but returns "No association ID's returned" message.

Example:

ntpq -pn
No association ID's returned

Environment

  • BIG-IP
  • NTP
  • ntpq -pn
  • No association ID's returned
  • NTP servers are configured with its FQDN.

Cause

The issue is with the NTP FQDN is not able to be resolved by your DNS server.
 

Recommended Actions

To resolve the issue, follow one of the options below.

  1. Ensure that your DNS is able to resolve your NTP FQDN. Change to another DNS server if needed. 
    K13205: Configuring the BIG-IP system to resolve DNS hostnames 
  2. Replace the NTP FQDN configuration to IP address.
    K3122: Using the BIG-IP Configuration utility to add an NTP server
    K13380: Configuring the BIG-IP system to use an NTP server from the command line
     

Additional Information

None.
