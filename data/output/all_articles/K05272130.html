Topic

You should consider using this procedure under the following conditions:

  • You want to use the BIG-IP system to provide Remote Desktop Protocol (RDP) access to users.
  • You want to reduce the complexity of RDP resource management.

Description

You can configure the BIG-IP APM system to provide RDP access to multiple users by configuring a separate RDP resource in the BIG-IP APM system for each user. However, the complexity of managing the RDP resources in the BIG-IP APM system increases as the number of users grows.

You can simplify the BIG-IP APM RDP resource configuration by creating a single RDP resource that uses variable substitution to populate the Destination within the BIG-IP APM RDP resource with the user's computer name or IP address. When the user logs in and selects the RDP resource on the BIG-IP APM webtop, the RDP session connects using the information populated by the variable substitution. To do so, perform the following procedures.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • Your AAA service includes customizable attributes in the user profiles.
  • You use the same AAA profile attribute across all employee profiles.
  • You have already entered the name or IP address of the employee's computer into the chosen AAA profile attribute.

Procedures

  • Configuring an access policy to query the AAA server for user attributes
  • Creating an RDP resource to use the attribute containing the user's computer name or IP address
  • Adding the new RDP resource to the access policy 

Configuring an access policy to query the AAA server for user attributes

Note: In the following example, F5 assumes that the AAA server is type AD/LDAP.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Access > Profiles/Policies.

    Note: For BIG-IP APM versions prior to 13.0.0, go to Access Policy > Access Profile List.

  2. Select Edit for the access policy in which you want to provide access to the RDP resource.
  3. In the access policy flow, at some point after the Login Page policy item, but before the Resource Assignment policy item, add an AD or LDAP Query policy item.
  4. Configure the AD or LDAP Query policy item to retrieve the user attributes from the AAA server.  To reduce memory use, use the Require Attributes to specify only the AAA attribute that contains the user's RDP information.
  5. To save the AD or LDAP Query policy item, select Save.
  6. Select Apply.

Creating an RDP resource to use the attribute containing the user's computer name or IP address

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Access > Connectivity/VPN > VDI/RDP > Remote Desktops.

    Note: For BIG-IP APM versions prior to 13.0.0, go to Access Policy > Application Access > Remote Desktops > Remote Desktops List.

  2. Select Create.
  3. Enter a name for the RDP resource.
  4. For Type, select RDP.
  5. For Destination, ensure that Host Name is selected.
  6. For Destination, enter %{session.ad.last.attr.<attribute_name>}, where <attribute_name> is the name of the AAA profile attribute containing the employee's computer name or IP address. If you are using an LDAP AAA server, the APM variable is session.ldap.last.attr.<attribute_name>.

    Note: When configuring using the employee's computer name, DNS in your environment must resolve the employee's computer name to the correct IP address.

  7. Customize the other RDP resource options, then select Finished.

Adding the new RDP resource to the access policy

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Access > Profiles/Policies.

    Note: For BIG-IP APM versions prior to 13.0.0, go to Access Policy > Access Profile List.

  2. Select Edit for the access policy in which you want to provide access to the RDP resource.
  3. Modify the Resource Assignment policy item and add the new RDP resource so it is included on the BIG-IP APM webtop.
  4. To save the change to the Resource Assignment policy item, select Save.
  5. Select Apply.
