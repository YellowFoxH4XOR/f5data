Topic

You should consider using this procedure under the following condition:

  • You want to sync hardware security module (HSM) keys between BIG-IP platforms in separate data centers or device service clusters (DSC).

Description

This article shows you how to sync HSM keys between data centers or DSCs.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Source and destination platforms have the same HSM hardware family.
  • The FIPS Security Officer Domains match.
  • You know the Security Office Password of both HSMs. (These do not need to match.)

Note: BIG-IP peers TMOS versions are not required to match when syncing the keys as per the below procedure. For example, one device can run 16.1.5 while the other can run 17.1.13.

Procedures

FIPS manual HSM sync process

You can sync HSM keys between data centers or DSCs by using the following procedure:

Impact of procedure: Running the fipsutil init command deletes all keys in the HSM and makes any previously exported keys unusable on the destination BIG-IP system. Performing the following procedure should not have a negative impact on your source BIG-IP system.

  1. For the destination BIG-IP system, follow the instructions in the Initializing the HSM in <your_platform> section of the BIG-IP FIPS Platform Setup chapter of the BIG-IP Platform: FIPS Administration manual.

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation. 

  2. To sync the Key Encryption Keys between the BIG-IP platforms in separate data centers or DSCs, use the following command syntax on the source BIG-IP system:

    fipscardsync <IP address>

    For example, for the destination BIG-IP system IP address 192.168.2.2, you would enter the following command:

    fipscardsync 192.168.2.2

  3. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  4.  Optionally, if one is not already created before step 2, create a FIPS key on the source BIG-IP system by using the following syntax:

    create sys crypto key <key_object_name> security-type fips

    For example, to create a FIPS key named fips_01, which is a security-type FIPS, enter the following command:

    create sys crypto key fips_01 security-type fips

    If you want to use the Configuration utility, refer to the Create an SSL CSR and private key section of K14620: Manage SSL certificates for BIG-IP systems using the Configuration utility.

  5. Log in to the BIG-IP Advanced Shell (bash) on your source BIG-IP system by entering the following command:

    bash

  6. Verify that the encrypted version of the FIPS key (.exp) is in the /config/ssl/ssl.cavfips folder on the source BIG-IP system by entering the following command:

    ls -l /config/ssl/ssl.cavfips

    For example, the following output shows that the fips_01.exp file is created when the FIPS keys are created:

    total 4
    -rw-r--r--. 1 root root 1658 2021-11-18 13:04 :Common:fips_01.exp

  7. Copy the FIPS key (.exp) file from the source BIG-IP system to the destination BIG-IP system by using the following command syntax:

    scp -p <local_filename_path> <username>@<server>:<destination_BIG-IP_system_filename_path>

    For example, the following command copies the FIPS key (.exp) file fips_01.exp to the destination BIG-IP system IP address 10.200.69.12:

    scp -p /config/ssl/ssl.cavfips/:Common:fips_01.exp root@10.200.69.12:/config/ssl/ssl.cavfips/:Common:fips_01.exp

  8. Verify that the encrypted version of the FIPS key (.exp) is in the /config/ssl/ssl.cavfips folder on the destination BIG-IP system, by entering the following command:

    ls -l /config/ssl/ssl.cavfips

    For example, the following output shows that the fips_01.exp file is created when the FIPS keys are copied:

    total 4
    -rw-r--r--. 1 root root 1658 2021-11-18 13:13 :Common:fips_01.exp

  9. Log in to tmsh by entering the following command on the destination BIG-IP system:

    tmsh

  10. On the destination BIG-IP system, use the following command syntax to install the key into the HSM:

    install /sys crypto key <from-local-file> security-type fips?

    For example:

    install /sys crypto key fips_01 from-local-file /config/ssl/ssl.cavfips/:Common:fips_01.exp security-type fips
