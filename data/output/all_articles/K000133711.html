K000133711: Forwarding virtual server not functioning

Type
Support Solution
Published
2023-04-28
Updated
2023-04-28
Source
https://my.f5.com/manage/s/article/K000133711

Description

When having a IP Forwarding Virtual Server to forward traffic to other hosts in same network, it does not work.


Environment

  • IP Forwarding Virtual Server
  • Host Destination address. For example: 192.168.1.1
  • BIG-IPs Virtual Server as default gateway in the networks hosts

Cause

Having a host destination address, it will only work if there's another host in the network with same address, using same example, 192.168.1.1. So other network hosts don't receive any traffic destined for them.



 Recommended Actions

Use a network address instead, find more information in K7595: Overview of IP forwarding virtual servers
