Description

Error Message

warning: Global concurrent url limited license limit reached.

For example:

warning tmm1[10186]: 01490508:4: 00000000: Global concurrent url limited license limit reached.

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file

 

Environment

BIG-IP APM configured with SWG

Cause

SWG is licensed for a set number of concurrent user connections by licensing.   When you exceed the maximum number of concurrent users,  you'll receive an error that the limit has been reached.

Recommended Actions

F5 recommends that you monitor traffic volumes so you can proactively manage the license limit. If the rate limit warnings persist, you can perform the following actions:

  • Confirm whether maintenance traffic, such as security scanners, is causing BIG-IP APM-SWG to reach its concurrent connect limit.
  • Contact your F5 sales representative about acquiring an update to the license, allowing a higher threshold.
  • Configure the BIG-IP system to send SNMP traps and email messages to a specified address whenever the system logs a message as a result of the system reaching the global concurrent access session limit. For information about these notifications and email message options, refer to the Related Content section.
