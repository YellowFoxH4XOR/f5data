Description
HTTP2 not working when SSL persistence and Session Ticket enabled.

        }
    }

    profiles {
        A_CLIENT_SSL {
            context clientside
        }
        http { }
        http2 { } --->!!!!
        serverssl {
            context serverside
        }
        tcp { }
    }
    serverssl-use-sni disabled
    source 0.0.0.0/0
    source-address-translation {

Environment

  • LTM
  • HTTP2

Cause
This is caused by ID1133625.

Recommended Actions

  1. Disable either Session Ticket or SSL persistence when using HTTP/2 profile
    • To disable Session Ticket using tmsh command,
      • tmsh modify ltm profile client-ssl A_CLIENT_SSL session-ticket disabled
    • ???????To disale SSL persistence using tmsh command,
      • tmsh modify ltm virtual A_VS persist none
  2. Monitor progress of ID1133625.
