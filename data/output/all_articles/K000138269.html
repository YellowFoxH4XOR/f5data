Description

iControl API GET query to /mgmt/tm/ltm/pool/members/stats endpoint does not show data for partitions other than Common

 

Environment

  • iControl
  • Partitions

Cause

This is due to the BUG ID 703101 [/mgmt/tm/ltm/pool/members/stats endpoint is not showing data for partitions other than Common].

 

Recommended Actions

 

There is no fix at the time of publishing this article for the BUG ID703101, however as a workaround you can use this script to collect all the stats. Make sure you change the password and management IP on the script

 

 

#!/bin/bash

CURL='curl -sku admin: GET https:///mgmt/tm/ltm/pool';

JP='python -m json.tool'

 

list=`$CURL | $JP | egrep 'fullPath'` # Get only 'fullPath' fields

list=`echo $list | tr -d '[":,]'` # Remove " : ,

list=`echo $list | sed 's/fullPath//g'` # Remove 'fullPath'

list=`echo $list | tr '/' '~';` # Convert slash to tilda

 

echo --- `echo $list | wc -w` pools

 

for pool in $list; do

$CURL/$pool/stats | $JP

done

 

 

Create the above script rest-api-stats.sh on the /var/tmp directory with vi editor or any other editor of your choice like nano

 

Change the permissions as below

 

chmod 755 rest-api-stats.sh

 

Then run the script

 

 ./rest-api-stats.sh
