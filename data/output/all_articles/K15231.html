Known Issue

Virtual servers that reference the FastL4 profile may intermittently fail to pass traffic.

This issue occurs when the following condition is met:

  • The Loose Close option is enabled in the associated FastL4 profile.

Impact

The virtual server may fail to pass traffic as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H459763 on the Diagnostics > Identified > Medium|High screen.
  • The virtual server fails to pass traffic as expected.
  • Packet captures indicate intermittent TCP handshake failures.
  • The system appears to activate SYN cookie protection, but the SYN Check Activation threshold has not been exceeded.
  • The system logs error messages to the /var/log/ltm file that appear similar to the following example:

    notice tmm5[18388]: 01010240:5: Syncookie HW mode activated, server = <ip_addr:port>, HSB modId = 1

Workaround

To work around this issue, you can disable the Loose Close option for the associated FastL4 profile.
