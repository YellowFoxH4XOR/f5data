Known Issue

The RPM package manager reports the BIND version incorrectly as 9.6.2.P3. However, named reports the actual version of BIND correctly as 9.6.3.

Impact

Cosmetic

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The RPM package manager will incorrectly report BIND version 9.6.2.P3. The rpm -qi bind command output will appear similar to the following example:

    Name : bind Relocations: (not relocatable)
    Version : 9.6.2.P3 Vendor: F5 Networks, Inc.
    Release : 763.0 Build Date: Fri 20 May 2011 08:05:41PM PDT
    Install Date: Mon 06 Jun 2011 06:57:45 AM PDT Build Host: build10
    Group : System Environment/Daemons Source RPM: bind-9.6.2.P3-763.0.src.rpm
    Size : 2599428 License: BSD-like
    Signature : (none)
    URL : http://www.isc.org/products/BIND/
    Summary : A DNS (Domain Name System) server.
    Description :
    BIND (Berkeley Internet Name Domain) is an implementation of the DNS
    (Domain Name System) protocols. BIND includes a DNS server (named),
    which resolves host names to IP addresses; a resolver library
    (routines for applications to use when interfacing with DNS); and
    tools for verifying that the DNS server is operating properly.

  • named reports BIND version 9.6.3 correctly. The named -v command output appears as follows:

    BIND 9.6.3
