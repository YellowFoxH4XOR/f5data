Description
You may experience TCP resets for POST requests when using an iRule with SSL handshake events and may see similar messages to this in /var/log/ltm:
err tmm[19279]: 011f0007:3: http_process_state_cx_wait - Invalid action:0x100011 clientside

Environment

  • BIG-IP
  • Virtual Server with iRule that uses a client SSL handshake event:
    "CLIENTSSL_HANDSHAKE"

Cause
This may be due to a known bug, ID889165.

Recommended Actions

  1. Upgrade to a non affected version of bigip (14.1.4, 15.1.3, 16.1.0).

Additional Information
Bug ID 889165: "http_process_state_cx_wait" errors in log and connection reset
