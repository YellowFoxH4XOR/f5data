Description

Secure Password Enforcement is not working and able to create simple passwords for local users.

  • Secure Password Enforcement is configured.
  • Able to create local users with passwords like aaaa.

Environment

  • Any remote authentication like AD/LDAP/Radius/TACACS+ is configured.
  • BIG-IP 13.X, 14.X, 15.X, 16.X, 17.X

Cause

This is by design because the BIG-IP doesn't expect users to be created locally when remote authentication is configured.

Recommended Actions

The following workaround may be followed to enforce the Secure Password Enforcement setting.

  1. Disable remote authentication (by selecting Local for User Directory under System  ››  Users : Authentication)
  2. Create all required local users and their password will be enforced for set level of security.
  3. Re-enable remote authentication

Additional Information

None.
