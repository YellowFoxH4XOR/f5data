Known Issue

If an access policy is created in a partition other than the common partition, the Apply Access Policy link which normally appears in the upper left hand corner may not appear.

Note: The policy can still be applied from the Access Profiles List screen by selecting the check box next to the access policy and clicking the Apply Access Policy button.

Note: This issue is similar to the known issue described in K11579: The visual policy editor fails when logged in with an account that is not in the common administrative partition.

F5 Product Development tracked this issue as CR138124, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
