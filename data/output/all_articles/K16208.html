Known Issue

In rare conditions, the wamd process may stop responding if it receives corrupt MCP messages.

This issue occurs when the following condition is met:

  • The mcpd process sends incomplete or malformed information to the wamd process.

Impact

The BIG-IP AAM system may fail to pass traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • At startup, the wamd process produces a core file in the /shared/core directory.

Workaround

To work around this issue, you can force the mcpd process to reload its configuration. To do so, perform the following procedure:

Impact of procedure: Rebooting the BIG-IP system disrupts traffic processing until the system finishes restarting.

  1. Log in to the command line.
  2. Create a null file, with forceload as the file name, in the /service/mcpd directory by typing the following command:

    touch /service/mcpd/forceload

  3. Reboot the BIG-IP system by typing the following command:

    reboot
