Known Issue

SSL client connections may fail. This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured with a virtual server that has an associated Client SSL profile.
  • The BIG-IP system receives a ClientHello message that is greater than 255 bytes from a client using TLS 1.1 or 1.2.

Under these conditions, the client's connection will stall and eventually time out. The time-out duration is determined by the Handshake Timeout setting in the Client SSL profile.

Impact

SSL clients that use TLS 1.1 or 1.2 are unable to establish an SSL connection to the virtual server.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H433613 on the Diagnostics > Identified > High screen.
  • An SSL client connection using TLS 1.1 or 1.2 stalls and eventually times out.
