K14002893: BIG-IQ cannot enable Statistics collection towards some BIG-IP

Support Solution
Published
2022-06-21
Updated
2026-07-15
Status

Applies to

Source
https://my.f5.com/manage/s/article/K14002893

Description
When BIG-IQ CM attempts to enable the statistic collection of imported BIG-IP, it fails with the following error on BIG-IQ CM's GUI log.

/var/log/restjavad.log
Statistics collection error: agentInstaller failed: java.lang.IllegalStateException: installapp on device [IP address of BIG-IP] failed: java.net.ProtocolException: status:400, body:{"code":400,"message":"INSTALL operation not allowed","referer":"[IP address of BIG-IQ CM]","restOperationId":14044948,"kind":":resterrorresponse"}. Please try again by clicking "Save and Close," below.
 

Environment

  • BIG-IQ CM use Statistic Collection 
  • BIG-IP versions 14.1.5 or 15.1.5 or 15.1.6 or 16.1 

Cause
Some rpm-tasks do not allow INSTALL operations from BIG-IQ's statistic collection, F5 tracks this issue as ID1094177

Recommended Actions
You can follow either of the below recommended actions.

  • Disable rpm-tasks on BIG-IP 
    # tmsh modify sys db restjavad.disablerpmtasks value false
    Note: by default the rpm-tasks value is set as true.

    (OR)

  • Upgrade to fixed versions, listed at ID1094177
