Issue

Error Message

01070823:3: Read Access Denied: <message>

In this error message, note the following:

  • <message> is a description of the event

For example:

01070823:3: Read Access Denied: user (testuser) type (script)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • You attempt to query objects or statistics in a partition to which you do not have read access.
  • You attempt to query non-partitioned objects but do not have non-partitioned read access.

Impact

The user is unable to read the objects or statistics.

Recommended Actions

To workaround this issue, you can provide authorization for the user by modifying the partition or role settings. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative effect on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Users.
  3. Select the name of the affected user.
  4. In the Partition Access section, select the current role and partition assignment, then select Edit.
  5. Modify the Role and Partition settings to provide access for the user.
  6. Select Add.
  7. Modify the Terminal Access setting as needed.
  8. Select Update.
