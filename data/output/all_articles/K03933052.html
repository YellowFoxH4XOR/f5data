Issue

Error Message

011f0007:3: <state> - Invalid action: <action> <details>

In this error message, note the following:

  • <state> is the process state of the BIG-IP system when the system is processing the HTTP traffic.
  • <action> is the action that the BIG-IP system is performing.
  • <details> shows affected configuration items and IP addresses.

For example:

011f0007:3: http_process_state_ingress_data - Invalid action EV_PREPEND_HEADERS during ST_HTTP_INGRESS_DATA (Server side: vip=/Common/test_vip profile=http server_ip=10.10.10.100)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The BIG-IP system encounters internal errors related to complex iRules processing or virtual servers with complex profile configurations.
  • Configuration synchronization is lost between BIG-IP devices in a high-availability system.
  • The BIG-IP system processes a request or response that is not RFC compliant.

Impact

The BIG-IP system drops the associated connection.

Recommended Actions

This error describes the action that the BIG-IP system is performing while the system is attempting to process the HTTP traffic. The IP address of the client and server are included in the output when this information is available. This message is typically generated by an unusual sequence of events or unusual traffic patterns. To determine the cause of the error, you may have to perform traffic analysis using packet captures.
