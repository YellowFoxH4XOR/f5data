Known Issue

The BIG-IP 1024-bit key generation script may fail to log error messages to the /var/log/secure file.

This issue occurs when all of the following conditions are met:

  • The 1024-bit key generation script (for example, /etc/cron.hourly/genkeys-1024) runs as scheduled.

    Note: Starting in BIG-IP 11.4.0, the 1024-bit key generation script runs hourly. In earlier versions, the script runs monthly. For more information, refer to K14818: Generation of new ephemeral keys occurs hourly.

  • An error occurs during ephemeral key creation.

Impact

When ephemeral key creation fails, the ephemeral key generation script does not log an error message to the /var/log/secure file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The cron job generates an error message that appears similar to the following example:

    /etc/cron.hourly/genkeys-1024: line 77: -p: command not found

  • The ephemeral key generation script fails to log an error message to the /var/log/secure file when key creation fails.

Workaround

To work around this issue, you can fix the genkeys-1024 script manually to allow key generation error to be logged. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. To create a backup copy of the genkeys-1024 script, type the following command:

    cp -p /etc/cron.hourly/genkeys-1024 /var/tmp/genkeys-1024.backup

    Note: For BIG-IP 11.3.0 and earlier, locate the genkeys-1024 script in the /etc/cron.monthly/ directory.

  3. Use a text editor, such as vi, to edit the genkeys-1024 script.
  4. Locate the following parameter:

    loggcercmd="/usr/bin/logger"

  5. Change the parameter from loggcercmd to loggercmd. The updated parameter appears similar to the following example:

    loggercmd="/usr/bin/logger"

  6. Save the changes and exit the text editor.
