Description

Is it possible to install the DNS Relay Proxy Service component by itself?

Environment

  • BIG-IP
  • APM module

Cause

This is by design.

 Recommended Actions

No, it is not possible, as the DNS Relay Proxy Service is a component of the APM Edge Client.
