Known Issue

The BIG-IP APM SAML service provider (SP) access profile single logout option (SLO) may fail to log users out.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an SAML SP access profile that includes the SLO.
  • A user has an active BIG-IP APM access profile session.
  • The user NameID value contains space characters.

Impact

The affected user's sessions are not terminated.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H487376 on the Diagnostics > Identified > Medium|High screen.
  • When a user attempts to log out using the SLO button, the button does not respond and the user is not logged out.
  • Error messages similar to the following example are logged to the /var/log/apm file:

    err tmm1[10040]: 014d0002:3: 917c49b4: SSOv2 Error creating signed SAML message - failed to find certificate: /Common/F5ProdSAML.key
    err tmm1[10040]: 014d0002:3: 917c49b4: SSOv2 Create signature element for SLO request failed
    err tmm1[10040]: 014d0002:3: 917c49b4: SSOv2 Error (12) sending logout message

Workaround

To work around this issue, you can create a Variable Assign agent to URL-encode spaces in the NameID value. To do so, perform the following procedure:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Profiles > Access Profile List.
  3. To open the VPE editor, click the Edit link to the right of the affected access profile.
  4. To the right of the Authentication box, click the (+) symbol.
  5. Select the Assignment tab.
  6. Click the Variable Assign radio button.
  7. Click Add Item.
  8. In the Variable Assign pop-up display, click Add new entry.
  9. Click the change link of the new entry.
  10. In the Custom Variable box, add the following value:

    session.bigip_saml_sp_information
  11. In the Custom Expression box, add the following value:

    set a1 [mcget session.bigip_saml_sp_information]; set a2 [mcget session.saml.last.nameIDValue]; set a3 [string map {" " %20} $a2]; set a4 [string map [list $a2 $a3] $a1]; return $a4
  12. Click Finished.
  13. Click Save.
  14. In the upper-left corner of the VPE editor, click Apply Access Policy.
  15. To exit the editor, click the green Close button in the upper-right corner of the VPE editor.
