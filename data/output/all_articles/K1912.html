Topic

Because BIG-IP uses the OpenSSL library for many SSL functions, a number of error conditions on BIG-IP simply supply the underlying OpenSSL error message. Any SSL error message that consists entirely of numbers is probably an OpenSSL error.

To find a definition for a particular SSL related error, type the following command, where <err_num> is the specific error number you received:

openssl errstr <err_num>
