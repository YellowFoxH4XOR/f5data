Description

Requests are being blocked due to an "Illegal method" violation, even though they use the default allowed methods (GET and POST). The security policy is already configured to permit these methods, indicating that these blocks are false positives.

Environment

  • BIG-IP ASM
  • Illegal Method Violation for GET/POST 

Cause

This behaviour is likely caused by database inconsistencies, possibly resulting from a partially completed configuration.

Recommended Actions

  1. Export the affected security policy in binary format.

  2. Re-import the policy with a new name.

  3. Assign the newly imported policy to the relevant virtual server.

For instruction on how to perform above steps, refer to K13905104: Overview of importing and exporting BIG-IP ASM security policies

This process effectively resolves any underlying inconsistencies in the original policy.

If the issue persists, or if you observe this behaviour across multiple policies, it is recommended to raise a support case with F5 and provide the latest QKView file for further analysis and troubleshooting. K12878: Generating diagnostic data using the qkview utility
