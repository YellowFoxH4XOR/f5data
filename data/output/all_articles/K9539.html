K9539: Certain Mobile email settings are not configurable when using the Japanese language mode

Known Issue

This is the result of a known issue. If you logon to the FirePass Administrative Console using the Japanese language mode, the following fields are not configurable on the Portal Access : Mobile E-Mail page:

  • IMAP Folders
  • Sent folder
  • Deleted Items
If you configure these fields and then click the Update button, the fields become blank and the values you entered are not saved.
F5 Product Development tracked this issue as CR110749 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-1, which has been issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by logging on to the FirePass Administrative Console using the English language mode to configure the settings on the Portal Access : Mobile E-Mail page.
