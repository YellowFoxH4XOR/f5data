Description

When attempting to save an Access Policy after editing it using the Visual Policy Editor (VPE) in BIG-IP APM, the following error message may appear:

GUI Error: 01070712:3: file (/tmp/cg/Common-access-policy-name-agent-name-ag-123456.xml) expected to exist.

Logs from /var/log/httpd_errors and /var/log/ltm may show log entries similar to:

PHP Warning: DOMDocument::save(/tmp/cg/Common-access-policy-name-agent-name-ag-123456.xml): failed to open stream: Permission denied

Caught configuration exception (0), file (/tmp/cg/Common-access-policy-name-agent-name-ag-123456.xml) expected to exist.

Environment

BIG-IP APM any versions 

Cause

The error occurs because the system temporarily creates a file under the /tmp directory during the process of saving or modifying an access policy. If this temporary file cannot be created due to issues such as insufficient permissions, a full filesystem, or other restrictions on the /tmp directory, the operation fails with the described error.

Answer/Recommended Actions

Verify Permissions for /tmp Directory:

Ensure that the /tmp directory has appropriate write permissions (drwxrwxrwt) so that temporary files can be created by processes.

Use the following command to check and correct permissions if necessary:

  • ls -ld /tmp
  • chmod 1777 /tmp

Check Disk Space:

  • Verify that there is sufficient free space available in the filesystem where /tmp resides.
  • Use df -h to check disk usage and clear unnecessary files if needed.
