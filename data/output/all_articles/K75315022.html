Description

when using the 'supersede-options' to override the "domain-search" value returned by the DHCP server, it is giving an error.

For example: using this command to push "example.local" to the dhclient
 tmsh modify sys management-dhcp sys-mgmt-dhcp-config supersede-options add { domain-search { value add { \"example.local\" } } }

yields this error:
 01071627:3: Management Dhcp resource supersede-option - Invalid dhcp option: domain-search 

Environment

  • DHCP enabled on mgmt interface
  • dhclient

Cause

This is due to bug ID 992813. Fixed in BIG-IP version 17.0.0

Recommended Actions

1. Upgrade to 17.0.0 or later version which contains the fix for the said bug
2. If, for any reason, you are not able to upgrade to version 17.x, contact F5 Technical Support and request for an EHF for ID992813 on top of your current BIG-IP version.
