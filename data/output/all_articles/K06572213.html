Description

After deploy SSLO and Layer2 / layer 3 services, the following issue happened:

  • The bandwidth usage between SSLO and 3rd device is extremely high, near to the full capcity of the interface.
  • Capture the packets on the SSLO and 3rd device, 99% frames are duplicated ACK.

Environment

  • SSLO
  • Topology
  • Layer 2 / Layer 3 service

Cause

Root cause is not addressed. 

Recommended Actions

On the 3rd devices like WAF, enable the ACK probe filter. For the details, please refer to the manual of the 3rd devices.

Additional Information

Root cause maybe SSLO, maybe 3rd device.
