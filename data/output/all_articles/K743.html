Known Issue

This is the result of a known issue. The ECV scan level option, none, is not included in the Configuration utility.

F5 Networks Product Development tracked this issue as CR32729 and CR41843.

Workaround

To work around this issue, perform the following steps:

  1. Create the ECV from the Configuration utility, specifying first as the scan level option.
  2. Log in to the command line.
  3. Change directories to the /config/3dns/etc directory, by typing the following command:

    cd /config/3dns/etc

  4. Back up the wideip.conf file, by typing the following command:

    cp wideip.conf wideip.conf.original

  5. Using a text editor, such as vi or pico, edit the wideip.conf file.
  6. In the ECV configuration statement, locate the following line:

    scan_level first

  7. Change the line to appear as follows:

    scan_level none

  8. Save the file and exit the editor.
  9. Load the new configuration, by typing the following command:

    3ndc restart
