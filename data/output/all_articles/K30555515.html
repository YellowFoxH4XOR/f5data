K30555515: Unable to define an external storage snapshot location for BIG-IQ DCD

Type
Support Solution
Published
2021-06-04
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • Virtual Editions
  • BIG-IQ
  • Vmware ESXI and vCloud Director
Source
https://my.f5.com/manage/s/article/K30555515

Description

You may get following error message when attempting to add external storage device through BIG-IQ CM GUI (System > BIG-IQ DATA COLLECTION > BIG-IQ Data Collection Devices and select Add):

The system returned an unexpected error (400 Bad Request). Mounting external storage failed due to incorrect mount parameters. Please check whether the mount parameters are correct.
This failed on 10.10.10.1.

Environment

  • BIG-IQ CM and DCD
  • Access to the command line of the BIG-IQ Central Manager
  • SMBv1 file server

Cause

This issue can be caused by multiple factors, some of them are listed below:

  • Supported versions of SMB
  • Supported security modes

Recommended Actions

  1. SSH to BIG-IQ CM as root
  2. Create a directory
    mkdir /tmp/xyz
  3. Mount the directory   
    mount -t cifs //<windows server>/<share> /tmp/xyz -o uid=elasticsearch,gid=elasticsearch,rw,iocharset=utf8,noauto,sec=<securitymode>,user=<username>,password='<password>',domain=<domain name>
  4. Unmount the directory when done
    umount /tmp/xyz
Security mode may be an issue. You can cycle through the security modes "none, ntlm, ntlmi, ntlmv2, ntlmv2i, ntlmssp, ntlmsspi, krb5, krb5i" and find the correct working security mode. Mount types can be "SMBv1" or "SMBv3".  Once you are able to find the correct security mode, then, you can try the   below procedure:
  1.   SSH to BIG-IQ CM as root
  2.   Run the following command:
    restcurl -X POST -d '{"username": "<username>", "password": "<password>", "domain": "<domain name>", "externalFS": "//<windows server>/<share>", "security": "<correct security mode>","mountType":"<correct mount type>"}' cm/shared/esmgmt/es-mount-filesystem
