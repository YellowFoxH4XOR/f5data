Known Issue

When you select the access profile Export or Apply options in the BIG-IP APM Configuration utility, the system displays a No Access error. 

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is running a BIG-IP Engineering Hotfix that contains the code fix for Bug IDs 1032405 and 941649.
  • You perform one of the following actions in the BIG-IP APM Configuration utility:
    • Go to Access > Profiles / Policies > Access Profiles (Per-Session Policies) and then select Apply.
    • Go to Access > Profiles / Policies > Access Profiles (Per-Session Policies) and then select Export for an access profile.

The code fix for Bug IDs 1032405 and 941649 provided in engineering hotfixes introduced a regression that results in an error when attempting to save or export an access profile using the Configuration utility.

Note: The code fixes introduced in Bug ID 1045421 and Bug ID 1049229 also contain the fix for Bug ID 1043277 and will resolve this issue.

Impact

You cannot export or apply the BIG-IP APM access profile.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to export or apply an access profile, a No Access error displays in the BIG-IP APM Configuration utility.
