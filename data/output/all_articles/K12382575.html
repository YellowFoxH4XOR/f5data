Description

Users are connecting with F5 Access from an Android device and see the string "function () {[native code]}" in the Logon Page Form 'Username' field.

Environment

  • F5 Access Android
  • BIG-IP APM
  • Logon Page Form in the Username field

Cause

Bug ID 1028081: [F5 Access Android] F5 access in android gets "function () {[native code]}" in logon page

Recommended Actions

You may follow the steps below to modify the main.js file: 
  • Create a copy of the original "main.js" file in /var/sam/www/webtop/public/include/js/modern/, by following the below command:

# cp /var/sam/www/webtop/public/include/js/modern/main.js /var/sam/www/webtop/public/include/js/modern/main.js.origin

  • Edit the file using an editor (e.g., nano)

# nano /var/sam/www/webtop/public/include/js/modern/main.js

  • Locate the string "window.externalAndroidWebHost.getWebLogonUserName" and change it to "window.externalAndroidWebHost.getWebLogonUserName()", then save the file

  • Locate the string "window.externalAndroidWebHost.getWebLogonPassword" and change it to "window.externalAndroidWebHost.getWebLogonPassword()", then save the file

  • Restart your BIG-IP APM
