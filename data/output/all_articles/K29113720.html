Known Issue

The Traffic Management Microkernel (TMM) may leak memory over time when a Client SSL certificate is presented for verification during an SSL handshake.

This issue occurs when the following condition is met:

  • The Client SSL profile is configured to request a client certificate for verification.

Impact

TMM may eventually become unstable, and memory exhaustion may result in a core file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM memory consumption steadily increases over time for the ssl process. You can monitor TMM memory usage by using the tmsh show sys memory command.
  • TMM generates a core file in the /shared/core directory.
