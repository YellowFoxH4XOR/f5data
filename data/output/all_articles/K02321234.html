Topic

You should consider using this procedure under the following condition:

  • You want to list the SSL protocols or ciphers allowed when accessing Configuration utility.
  • You want to change the SSL protocols or ciphers allowed when accessing Configuration utility.

For other methods of managing the SSL protocols and ciphers allowed by BIG-IP Configuration utility, refer to the following:

  • K000140730: Managing the SSL protocols and ciphers allowed by Configuration utility using iControl REST
  • K000140870: Managing the SSL protocols and ciphers allowed by Configuration utility for a managed BIG-IP device using BIG-IQ

Description

SSL protocols and ciphers allowed by Configuration utility are configured independently of local traffic objects, such as SSL profiles.

The default protocol and ciphers vary from version to version. You can list the SSL protocols and ciphers configured and change them to meet your requirements if needed.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access the TMOS Shell (tmsh).

Procedures

  • Listing the SSL protocols allowed by Configuration utility
  • Changing the SSL protocols allowed by Configuration utility
  • Listing the SSL ciphers allowed by Configuration utility
  • Changing the SSL ciphers allowed by Configuration utility

Listing the SSL protocols allowed by Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To list the currently configured SSL protocols, type the following command:

    list /sys httpd ssl-protocol

    For example, the BIG-IP 14.1.0 system displays the following protocols:

    ssl-protocol "All -SSLv2 -SSLv3 -TLSv1"

Changing the SSL protocols allowed by Configuration utility

Impact of procedure: Clients that do not support the specified SSL protocols are not able to access the Configuration utility.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To change the SSL protocols allowed in Configuration utility, type the following command:

    modify /sys httpd ssl-protocol "<allowed protocols>"

    Acceptable values include SSLv2, SSLv3, TLSv1, TLSv1.1, TLSv1.2, ALL, or None.

    For example:

    modify /sys httpd ssl-protocol "all -SSLv2 -SSLv3 -TLSv1 -TLSv1.1"

  3. Save the configuration change by typing the following command:

    save /sys config

Listing the SSL ciphers allowed by Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To list the currently configured SSL ciphers, type the following command:

    list /sys httpd ssl-ciphersuite

    For example, the BIG-IP 14.1.0 system displays the following ciphers:

    ssl-ciphersuite ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256

Changing the SSL ciphers allowed by Configuration utility

Impact of procedure: Clients that do not support the specified SSL ciphers are not able to access the Configuration utility.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To change the SSL ciphers allowed in Configuration utility, type the following command:

    modify /sys httpd ssl-ciphersuite "<allowed ciphers>"

    For example:

    modify /sys httpd ssl-ciphersuite "ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256"

  3. Save the configuration change by typing the following command:

    save /sys config
