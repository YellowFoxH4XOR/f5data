Known Issue

The system does not display node descriptions in the BIG-IP Configuration utility's Nodes: Node List page.

Impact

You are unable to view the description text of a node from the Nodes: Node List page in the BIG-IP Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You do not see the node description text in the Local Traffic > Nodes - Node List page in the Configuration utility, because the system does not display the Description column.

Workaround

To work around this issue, you can view the node description using either the Configuration utility to browse on the node properties, or the tmsh utility to list the node. To do so, perform the following procedure:

Impact of workaround: None

Using the Configuration utility

Log in to the BIG-IP Configuration utility.

  1. Navigate to Local Traffic > Nodes - Node List.
  2. Click the name of the Node you would like to view its description.
  3. You can view the Node Description from the Node's Properties page.

Using the tmsh utility

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.

  2. List the properties of the node using the following command syntax:

    list /ltm node <Node-Name>

    For example to view the properties of a Node named example1, type the following command:

    list /ltm node example1

    You see output that appears similar to the following:

    ltm node example1 {
    address 10.0.0.1
    description "This node is example1"
    }

  3. To exit the tmsh utility, type the following:

    quit
