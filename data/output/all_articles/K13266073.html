Known Issue

A standalone BIG-IP system may go offline momentarily when the host name is changed.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is not part of a high-availability configuration.
  • You use the Configuration utility System > Platform page to change the previously configured host name.

Impact

If the host name is changed on a Virtual Clustered Multiprocessing (vCMP) hypervisor, vCMP guests may experience a momentary interruption of traffic processing. For non-vCMP systems, there is no impact.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H563735 on the Diagnostics > Identified > Low screen.
  • After you change the vCMP hypervisor's host name, traffic processed by vCMP guests is briefly interrupted.
  • On a vCMP guest, in the /var/log/ltm file, you observe an error message similar to the following example:

    warning chmand[1234]: 012a0004:4: hypervisor_offline take action is set
    warning sod[2345]: 01140029:4: HA hypervisor_offline_t chmand fails action is go offline.

  • On typical BIG-IP systems (without vCMP provisioned), in the /var/log/ltm file, you observe an error messages similar to the following example:

    notice sod[6789]: 010c0054:5: Offline for traffic group /Common/traffic-group-1.
    info audit_forwarder: audit_forwarder started.
    notice sod[6789]: 010c006d:5: Leaving Offline for Active for dbvar not redundant.
    notice sod[6789]: 010c0053:5: Active for traffic group /Common/traffic-group-1.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to change the host name. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Change the host name by using the following command syntax:

    modify sys global-settings hostname <hostname>

    For example, to change the system host name to example.com, type the following command:

    modify sys global-settings hostname example.com

  3. To save the configuration, type the following command:

    save sys config
