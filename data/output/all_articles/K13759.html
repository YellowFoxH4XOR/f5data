K13759: Automatically built enhanced security policies no longer include URL objects

Knowledge
Published
2012-08-01

Status
Legacy Content
Applies to

Source

Issue

Old Behavior

Previously, the BIG-IP ASM system automatic policy builder included URL objects when the policy building type was set to Enhanced.

New Behavior

Beginning in BIG-IP ASM 11.2.0, URL objects are no longer included in the Enhanced policy type.

URL objects are included in the Complete policy type. For a detailed list of the properties of each policy type, refer to Table 4.1: Security policy elements for each policy type in the Configuration Guide for BIG-IP Application Security Manager.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

F5 Product Development tracked this change as ID 374002.

Impact

Allowed URL objects will not be created by the automatic policy building process.

Recommended Actions

If Allowed URL objects are required for your specific security policy, you must manually create them.
