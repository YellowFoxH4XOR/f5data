Known Issue

This is the result of a known issue. If you configure a Portal Access favorite for access to a Citrix Server 4.0 through 4.5 web interface, and you configure the favorite to automatically log on to the Citrix Server, automatic logon fails and the user is directed to the Citrix Server logon page. However, if the user closes the favorite and relaunches it, automatic logon succeeds. This issue occurs when client detection is enabled on the Citrix Server.

Note: For information about configuring automatic logon to a Citrix web interface, refer to K5451: Creating a Portal Access favorite that automatically logs in to a Citrix Metaframe or Presentation Server web interface.

Note: For information regarding Citrix Server version 4.6 or later, refer to K9538: Citrix access may fail when Citrix Client Detection is enabled when using Citrix Server version 4.6 or higher.

Citrix uses the client detection mechanism to detect the presence of Citrix client software on the client system. Starting in Citrix version 4.0, the client detection mechanism changed, preventing the FirePass automatic logon functionality from working properly.

F5 Product Development is tracking this issue as ID 269811 (formerly CR99067).

Workaround

You can work around this issue by disabling the client detection feature on the Citrix server. For more information about disabling client detection, refer to your Citrix documentation.
