Topic

3-DNS versions 4.2 through 4.5.14 and 4.6 through 4.6.2, resolves ties between virtual servers by selecting the first configured virtual server when the following load balancing methods are used:

Note: 3-DNS will use the first configured virtual server that was selected, as long as the server is available.

  • hops
  • round trip time
  • hit ratio
  • connection rate
  • virtual server capacity
  • QoS

Beginning with 3-DNS version 4.6.3, 3-DNS randomly chooses the virtual server to use for each connection when a tie occurs.
