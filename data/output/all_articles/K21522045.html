Issue

Error Message

notice mcpd[<PID>]: 0107165d:5: <string_1>:<string_2>

In this error message, note the following:

  • <PID> is the process ID of the mcpd process.
  • <string_1> is an action that the mcpd process is performing.
  • <string_2> provides a status or description of the action.

For example:

notice mcpd[5547]: 0107165d:5: init_system_epsec_software_status: EPSEC:: loading of Epsec software status start
notice mcpd[6286]: 0107165d:5: update_version: EPSEC::In update_version - Version (1.0.0-804.0) OESIS Version (4.3.345.0)
notice mcpd[4332]: 0107165d:5: create_or_update_status_obj: EPSEC::Creating new status with version 1.0.0-804.0

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

Error code 0107165d:5 has multiple message variations that can be grouped by their triggering conditions and impact. The following table lists error messages based on the observed message, condition, impact, and recommended actions.

Message stringConditions metImpactRecommended actions
  • create_or_update_status_obj: EPSEC::Creating new status with version <epsec_version>
  • update_version: EPSEC::In update_version - Version (<epsec_version>) OESIS Version (<oesis_version>)
  • init_system_epsec_software_status: EPSEC:: loading of Epsec software status <loading_status>
    where loading status can be any of start, done or passed.
These messages indicate that the system is loading an EPSEC image. This may happen when you click Upload Package on the Configuration utility to upload EPSEC ISO images.An EPSEC package is loaded to the system.None
  • copy_file: EPSEC in EspecFileObjMgr::copy_file - src (/config/filestore/....<epsec_version>) dst (/shared/apm/images/<epsec_filename>)
This message is a notification that the system is copying the EPSEC package from the config filestore to the /shared/apm/images location. This happens when you click Upload Package on the Configuration utility to upload EPSEC ISO images.NoneNone
  • delete_obsolete_objects: EPSEC::Deleting object '/Common/EPSEC/Images/<epsec_filename>', create time '<creation_time>'
This message indicates that the system is deleting an obsolete EPSEC package with the recorded file name. This may happen when you install an EPSEC package to the system.An EPSEC package is removed from the system.Verify from the message that the deleted EPSEC file name is no longer needed.
  • copy_file: Failed in file copy errno=(No such file or directory) src=(/config/filestore/../:<epsec_version>) dst=(/shared/apm/images/<epsec_filename>).
This message indicates that the EPSEC package cannot be copied to the destination directory. This may happen during installation or upload of a new package. In rare cases, this can happen when you upload or install an EPSEC package on a BIG-IP system with blades that are not in synced.The upload or install operation fails.On BIG-IP systems with blades, upload or install EPSEC packages only after the blades are fully synced.
  • copy_file: Failed in file copy errno=(ENOSPC) src=(/config/filestore/../:<epsec_version>) dst=(/shared/apm/images/<epsec_filename>).
  • copy_file: Failed in file copy, creating destination directory errno=(ENOSPC) src=(/config/filestore/...) dst=(/shared/apm/images/...).
This message indicates that the EPSEC package cannot be copied to the destination directory. This may happen if the BIG-IP system is low on disk space.The upload or install operation fails.Refer to K14403: Maintaining disk space on the BIG-IP system (11.x - 14.x) to identify unwanted files for removal.
  • copy_file: Failed in file copy errno=(Permission denied) src=(/config/filestore/../:<epsec_version>) dst=(/shared/apm/images/<epsec_filename>).
This message indicates that the EPSEC  package cannot be copied to the destination directory. This may happen when the upload process does not have the permissions to the /shared/apm/images directory.The upload or install operation fails.Do not modify the default permissions of the /shared/apm/images directory on the Unix file system. Set the permissions back to default and repeat the operation using the Configuration utility.
  • update_version: EPSEC::Removing invalid package (epsec-1.0.0-134.0.iso) found during config load.
This message indicates that an invalid EPSEC package is detected on a configuration load and will be removed from the configuration. And invalid EPSEC package may be due to a the fact that it is a package from a very old configuration or that it contains invalid version information.NoneRefer to K21175584: Removing unnecessary OPSWAT EPSEC packages from the BIG-IP APM system to periodically remove obsolete EPSEC packages.

Recommended Actions
