Known Issue

Under certain circumstances, the displayed virtual server CPU statistics may be incorrect.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration has a virtual server that is actively processing traffic.
  • You attempt to view statistical information for the virtual server using one of the following methods:
    • TMOS Shell (tmsh) command

      For example, you can type the following command syntax in tmsh to show CPU statistics of a virtual server:

      show /ltm virtual <virtual_server_name>

    • Configuration utility
    • SNMP polling

Impact

The BIG-IP system may report incorrect virtual server CPU usage, with values exceeding 100 percent.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system reports CPU Usage Ratio (%) values exceeding 100 percent. The output appears similar to the following example:

    CPU Usage Ratio (%)
      Last 5 Seconds                           594
      Last 1 Minute                            131
      Last 5 Minutes                            40
