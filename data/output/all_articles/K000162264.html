Description

TMM restarts and enter a continuous crash loop. The following panic message is found in /var/log/tmm: 

 notice panic: ../dev/hsb/if_hsb.c:6129: Assertion "HSB lockup, see ltm and tmm log files" failed. 

TMM core file generation in /var/core/

Environment

  • Product: BIG-IP LTM 
  • HSB

Cause

Bug ID 967769: During reset of high-speed interfaces, TMMs may mistakenly continue hardware watchdog checks, resulting in HSB lockup and TMM crash.

Answer/Recommended Actions

  • Contact F5 Support if you require assistance obtaining or applying the EHF.
