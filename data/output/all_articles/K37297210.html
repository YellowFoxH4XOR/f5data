Description
In BIG-IP ASM 13.1.0.2 and later, Advanced WAF(AWAF) is introduced. 
The BIG-IP system with AWAF-only license does not support HTTP redirect features. 

Environment
  • BIG-IP ASM 13.1.0.2 and later
  • BIG-IP system with AWAF-only license
  • You can not configure "Fallback Host" and "Fallback on Error Codes" in HTTP profile
Cause

This is by design. 

Recommended Actions

None
