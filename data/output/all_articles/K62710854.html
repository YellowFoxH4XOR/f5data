Issue

Error Message

Failure occured:, Failed to parse Network access parameters, <unspecified file>(1): expected

Message Location

You may encounter this message in the following locations on Mac and Linux clients:

  • In logs in the /usr/local/lib/F5Networks/SSLVPN/var/log/ directory on Linux clients.
  • In logs in the ~Library/Logs/F5Networks directory on Mac OS X clients.

Description

This message occurs when the following conditions are met:

  • You attach an HTTP compression file to the BIG-IP APM virtual server.
  • You connect to the virtual server from a Linux or Mac client.
Virtual Private Network (VPN) clients that do not use an HTTP client library with support for compression are unable to connect to the VPN.

Impact

When attempting to establish a VPN session, some VPN clients fail to parse the HTTP response from the BIG-IP system and establish a VPN connection.

Recommended Actions

When you have users who connect to the BIG-IP system using Mac or Linux devices, apply the following iRule to your virtual server, which disables HTTP compression when they attempt to connect.

Note: An alternative to this procedure is to remove the HTTP compression profile attached to the BIG-IP virtual server.

Impact of procedure: The impact of the following procedure depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

Adding the iRule to the BIG-IP system

  1. Log in to the Configuration utility.
  2. Navigate to Local traffic > iRules.
  3. Click Create.
  4. In Name, type a name for the iRule.

  5. In Description, type the following:

    # 707256.tcl
    # Disable http compression profile for VPN Connect request/response. Compression profile attached to VIP must be set to "selective" mode

    when CLIENT_ACCEPTED {
       ACCESS::restrict_irule_events disable
    }

    when HTTP_REQUEST {
       if { [HTTP::uri] contains "connect" } {
          log local0. "Disable compression for VPN connect"
          COMPRESS::disable
       } else {
          COMPRESS::enable
       }
    }
    # Done

  6. Click Finished.

Adding the iRule to your virtual server

  1. Navigate to Local traffic > Virtual Servers > Virtual Servers List.
  2. Click the name of the virtual server to which you want to apply the iRule.
  3. Click the Resources tab.
  4. In the iRules section, click Manage.
  5. In iRule, in the Available list, click the iRule you created, and then click Move Left (<<).
  6. Click Finished.
