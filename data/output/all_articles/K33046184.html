Issue

Error Message

01060111:3: Open SSL error - <reason>

In this error message, note the following:

  • <reason> is the reason for the failed SSL/Transport Layer Security (TLS) connection.

For example:

01060111:3: Open SSL error - error:140790E5:SSL routines:SSL23_WRITE:ssl handshake failure

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to monitor secure web servers using a HTTPS monitor.
  • The monitored pool member cannot successfully negotiate the monitor's SSL/TLS handshake.

Impact

The BIG-IP system marks the pool member down and does not send new client connections until the pool member becomes available.

Recommended Actions

To troubleshoot failing HTTPS monitors, refer to K13768: Identifying which pool members are failing an SSL/TLS handshake.
