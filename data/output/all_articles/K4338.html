K4338: BIG-IP now checks the content of chunk headers for compliance with RFC2616

Topic

Starting in versions 4.5.12 and 4.6.3, BIG-IP checks the content of the chunk headers for compliance with RFC2616. This prevents any potential problems that could occur if BIG-IP receives unexpected content in these headers.

If BIG-IP finds content in the chunk headers that is not compliant with RFC2616, it will pass the packets to the node without parsing it, and log an HTTP parser error. For example:

Jan 01 12:00:01 askf5 kernel: HTTP parser error:
chunk header does not start with hex digit client: 10.90.100.1

Jan 01 12:00:01 askf5 kernel:
HTTP parser error: too large chunk size client: 10.90.100.1

Jan 01 12:00:01 askf5 kernel:
HTTP parser error: no CRLF after chunk data client: 10.90.100.1
