K04309505: Using the iControl REST API to view Virtual Server and Pool configuration

Description

The following procedure outlines the steps required to view virtual server and pool configuration using the iControl REST API (REST).

Environment

  • BIG-IP
  • iControl REST API

Cause

None. 

Recommended Actions

Checking Virtual Server configuration iControl REST API

Impact of procedure: Performing this procedure should not have a negative impact on your system.

1. Log in to a client system that has the cURL utility.

2. To check the virtual server configuration from the remote BIG-IP system, use the following cURL command syntax:

curl -u <user>:<pwd> -sk --request GET 'https://<management_IP>/mgmt/tm/ltm/virtual/<vitual_server>/?options=pool' | jq . 

Replace : <user> with username , <pwd> with password , <management_IP> with management IP of BIG-IP device , <vitual_server> with the vitual server name.

Example:
$ curl -u admin:admin -sk --request GET 'https://10.10.10.10/mgmt/tm/ltm/virtual/VServer_80/?options=pool' | jq .
{

 "kind": "tm:ltm:virtual:virtualstate",
  "name": "VServer_80",

}

Checking pool configuration iControl REST API

Impact of procedure: Performing this procedure should not have a negative impact on your system.

1. Log in to a client system that has the cURL utility.

2. To check the pool configuration from the remote BIG-IP system, use the following cURL command syntax:

curl -u <user>:<pwd> -sk --request GET 'https://<management_IP>/mgmt/tm/ltm/pool/<pool name>/members' | jq .

Replace : <user> with username , <pwd> with password , <management_IP> with management IP of BIG-IP device , <pool name> with the pool name.
