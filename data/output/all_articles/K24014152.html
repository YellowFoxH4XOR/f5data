Description

  • There is a need to import a large number of certificates and keys from a physical appliance to a Virtual one.

Environment

  • Import from Physical Appliance to a Virtual one.
  • Certificates in .cert format.

Cause

None.

Recommended Actions

  1. Login to the command line of the BIG-IP system that you want to import the certificates and keys.
  2. Create a /var/tmp/key directory and upload all the keys here using an SFTP/SCP client.
  3. Create a /var/tmp/crt directory andupload all the keys here using an SFTP/SCP client.
  4. Once all the certs and keys are in place, run the following commands:

    for i in `ls -1 /var/tmp/key`; do tmsh install sys crypto key $i from-local-file /var/tmp/key/$i; done
    for i in `ls -1 /var/tmp/crt`; do tmsh install sys crypto cert $i from-local-file /var/tmp/crt/$i; done

  5. After installing the sys crypto keys and certs, saving configuration is needed:
    tmsh save sys config

Additional Information

Another way to perform this task is to follow K15021.
