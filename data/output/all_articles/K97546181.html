Description
When deploying BIG-IP Virtual Edition on a Nutanix AHV Hypervisor, you may observe that not all services are started and running as expected after the initial boot process. You may observe one or more of the following:

  • No SSH access to device
  • Web Configuration Utility has not fully started
  • Repeating Re-starting mcpd messages in console
  • SELinux errors

Environment

  • New installation of BIG-IP VE
  • Nutanix AHV Hypervisor

Cause
Bug ID 828873

Recommended Actions

  1. Logon to the command line of the BIG-IP.
  2. Using a text editor (vi, pico) open the file /usr/lib/systemd/system/f5-label.service,
  3. Place the pound (#) character in front of the line StandardInput=tty (approximately line 16).
    For example:
    Original line: StandardInput=tty 
    Modified line: #StandardInput=tty
  4. Save the file change.
