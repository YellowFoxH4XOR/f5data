Description

On F5OS, you can enable logs for REST API request and response. You should consider using these procedures under the following condition only:

  • The REST API is behaving in an unexpected manner

Environment

  • F5OS-A (rSeries appliance)
  • F5OS-C (VELOS chassis)
  • REST API

Cause

None

Recommended Actions

The following procedures executed in the F5OS Bash environment will enable traffic logs for the ConfD process.

For F5OS-A (rSeries appliance):

Log REST API traffic for ConfD are configured from a root shell on the appliance.  The changes persist across a system restart, so once debugging is complete, please disable the traffic log.

  1. SSH as root to the rSeries appliance management IP address to access the Bash shell.
  2. To enable/disable traffic logs by running one of the following commands: 
    • To enable the REST API traffic logs:

# docker exec system_manager confd_cmd -c 'mset /confdConfig/logs/webuiAccessLog/trafficLog true'

    • To disable the REST API traffic logs:

# docker exec system_manager confd_cmd -c 'mset /confdConfig/logs/webuiAccessLog/trafficLog false'

  1. The REST API traffic logs will be written to log/webui in this container (system_manager).

For F5OS-C (VELOS) Chassis:

Log REST API traffic for ConfD are configured from a root shell on the appliance.  The changes persist across a system restart, so once debugging is complete, please disable the traffic log.

  1. SSH as root to the rSeries appliance management IP address to access the Bash shell.
  2. To enable/disable traffic logs by running one of the following commands: 
    • To enable the REST API traffic logs:

# docker exec vcc-confd confd_cmd -c 'mset /confdConfig/logs/webuiAccessLog/trafficLog true'

    • To disable the REST API traffic logs:

# docker exec vcc-confd confd_cmd -c 'mset /confdConfig/logs/webuiAccessLog/trafficLog false'

  1. The REST API traffic logs will be written to log/webui in this container (vcc-confd).
  2. Repeat the above command on standby controller if needed.

For F5OS-C Partition:

Log REST API traffic for ConfD are configured from a root shell on the appliance.  The changes persist across a system restart, so once debugging is complete, please disable the traffic log.

  1. SSH as root to the rSeries appliance management IP address to access the Bash shell.
  2. To enable/disable traffic logs by running one of the following commands, replacing X with the partition ID : 
    • To enable the REST API traffic logs:

# docker exec partitionX_cli confd_cmd -c 'mset /confdConfig/logs/webuiAccessLog/trafficLog true'

    • To disable the REST API traffic logs:

# docker exec partitionX_cli confd_cmd -c 'mset /confdConfig/logs/webuiAccessLog/trafficLog false'

  1. The REST API traffic logs will be written to log/webui in this container (partitionX_cli).
