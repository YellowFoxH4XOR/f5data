Topic

Note: This article does not apply to the ARX 500 platform because it has only a single port dedicated for the redundancy link. In addition, this article does not apply to ARX 1500 and ARX 2500 platforms, for which the redundant-pair link is a VLAN. For information, refer to the Configuring Redundancy for ARX-1500 and ARX-2500 section of the ARX CLI Network Management Guide.

Note: For information about configuring the redundancy link for a high availability pair of ARX systems, refer to the ARX CLI Network Management Guide.

When the redundancy link for a high availability pair of ARX systems has been configured to use a single interface on each of the ARX systems, you should change the configuration so the ARX systems use a more redundant multiple interface port channel. To reconfigure the redundancy link of a high availability pair of ARX systems to use a multiple interface port channel, complete the following process:

Note: While this process is non-disruptive to client traffic, F5 recommends that you perform this process during a maintenance window to allow for metalog updates that may be affected.

  • View the current redundancy interface information
  • Verify that the current redundancy configuration is working properly
  • Configure the additional interface on the backup ARX system
  • Configure the additional interface on the active ARX system
  • Configure a port channel on the backup ARX system
  • Configure a port channel on the active ARX system
  • Verify that the new redundancy configuration is working properly

View the current redundancy interface information

To display the current interface (Slot/Port) configured for redundancy, type the show interface summary command from the command line of both ARX systems. The output of the command will appear similar to the following example:

Type   Slot/ Admin    Link   Speed   Duplex  Description
       Port  State    Status
-----  ----  -------  ------ ------- ------- -----------------------------------
mgmt   1/1   Enabled  Up     1  Gb/s Full
gbe    5/1   Ch 1     Up     1  Gb/s Full    Client/Server
gbe    5/2   Ch 1     Up     1  Gb/s Full    Default
gbe    5/3   Disabled Down   1  Gb/s Unknown Default
gbe    5/4   Disabled Down   1  Gb/s Unknown Default
gbe    5/5   Disabled Down   1  Gb/s Unknown Default
gbe    5/6*  Enabled  Up     1  Gb/s Full    HA


* Redundant-Interface

Verify that the current redundancy configuration is working properly

To verify that the current redundancy configuration is working properly, type the show redundancy command from the command line of both ARX systems. The output of the command will appear similar to the following example:

Configure the additional interface on the backup ARX system

  1. Enable privileged mode by typing the following command:

    enable

  2. Enter configuration mode by typing the following command:

    config

  3. Enter the configuration mode for the interface you want to add by using the following command syntax:

    interface gigabit <slot/port>

    For example:

    interface gigabit 5/5

  4. Disable the spanning-tree for the interface by typing the following command:

    spanning-tree shutdown

  5. Configure the interface you will use for redundancy by typing the following command:

    redundancy protocol

  6. Configure the interface port speed by typing the following command:

    speed 1000-full

  7. Enable the interface by typing the following command:

    no shutdown

  8. Exit the interface configuration mode by typing the following command:

    exit

Configure the additional interface on the active ARX system

  1. Enable privileged mode by typing the following command:

    enable

  2. Enter configuration mode by typing the following command:

    config

  3. Enter the configuration mode for the interface you want to add by using the following command syntax:

    interface gigabit <slot/port>

    For example:

    interface gigabit 5/5

  4. Disable the spanning-tree for the interface by typing the following command:

    spanning-tree shutdown

  5. Configure the interface you will use for redundancy by typing the following command:

    redundancy protocol

  6. Configure the interface port speed by typing the following command:

    speed 1000-full

  7. Enable the interface by typing the following command:

    no shutdown

  8. Exit the interface configuration mode by typing the following command:

    exit

Configure a port channel on the backup ARX system

  1. Configure the port channel you will use for redundancy by typing the following command:

    channel <number>

    For example:

    channel 1

  2. Configure the channel you will use for redundancy and specify the interfaces for the channel by using the following command syntax for each interface:

    redundancy protocol <slot/port>

    For example, if 5/6 was the original interface used for redundancy and 5/5 was the additional redundancy interface configured above, you would type the following commands:

    redundancy protocol 5/6
    redundancy protocol 5/5

  3. Specify a description for the channel by using the following command syntax:

    description <Text>

    For example:

    description Interconnect

  4. Enable the channel by typing the following command:

    no shutdown

  5. Exit the channel configuration by typing the following command:

    exit

  6. Exit configuration mode by typing the following command:

    exit

Configure a port channel on the active ARX system

  1. Configure the port channel you will use for redundancy by using the following command syntax:

    channel <number>

    For example:

    channel 1

  2. Configure the channel you will use for redundancy and specify the interfaces for the channel by using the following command syntax for each interface:

    redundancy protocol <slot/port>

    For example, if 5/6 was the original interface used for redundancy and 5/5 was the additional redundancy interface configured above, you would type the following commands:

    redundancy protocol 5/6
    redundancy protocol 5/5

  3. Specify a description for the channel by using the following command syntax:

    description <Text>

    For example:

    description Interconnect

  4. Enable the channel by typing the following command:

    no shutdown

  5. Exit the channel configuration by typing the following command:

    exit

  6. Exit configuration mode by typing the following command:

    exit

Verify that the new redundancy configuration is working properly

To verify that the redundancy connection is functioning for the high availability pair of ARX systems, type the show redundancy command on each ARX system. The output of the show redundancy command should indicate a status of Up for each switch, and will appear similar to the following example:

Node Switch/Quorum Disk   Status     Role    Total Last (UTC)
