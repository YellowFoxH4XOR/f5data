K000141054: TMM Crash after Upgrade to 17.1.1

Type
Support Solution
Published
2024-09-12
Updated
2024-09-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000141054

Description

After upgrading Viprion cluster from 15.1.5.1 to 17.1.1.3. A successful upgrade has taken place on both the hosts in the cluster and 1 of the 2 VCMP guests, Member A has been successfully upgraded on both cluster members, Member B has been upgraded but when made the active device after 5/10 seconds Member B becomes offline and the TMM process crashes causing Member A to again become the active device

You are using an internal data group

Environment

  • Internal data groups
  • v17.1.1

Cause

When an internal data group matches a local traffic policy, tmm crashes.

Bug ID1400317

Recommended Actions

There are 2 options

  • Use an external data group if possible 
  • Contact F5 support to request a hotfix

Additional Information

None
