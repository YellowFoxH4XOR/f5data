Topic

Terraform is a tool for building, changing, and versioning infrastructure safely and efficiently. For more information, refer to F5 Resoures for Terraform. 

F5 Support requests that you provide specific information to open a support case for Terraform. For information about opening a support case with F5 Support for other F5 products, refer to the product table in K2633: Instructions for submitting a Support case to F5.

F5 Support helps you resolve issues more quickly when you provide a full description of the issue and the details of your configuration. To help you gather all the required information, use the following guidelines to prepare for opening a case.

Important: F5 Support cannot walk you through the design or creation of Terraform code. For F5 Support policy on F5 resources for Terraform, refer to K80012344: F5 support for GitHub software.

Description

General Information

Provide the following information when you open a case with F5 Support:

  • A full description of the issue, including the following:
    • The symptoms of the issue, including a brief description of any systems involved
    • The approximate time the issue first occurred
    • The number of times the issue recurred
    • Any error output that the system provided
    • Steps to reproduce the issue
    • Any changes you made to the system before the issue first occurred
    • Any steps you took to attempt to resolve the issue
    • Whether this is a new implementation
    • Whether you have already uploaded a QKView file to the iHealth portal:
      • Ensure that any QKView files uploaded to the iHealth portal are linked to the support case.
      • If you searched AskF5 and did not find a helpful article, inform F5 Support of the search terms you used.
  • A description of the impact the issue has on your site, using the following definitions:
    • Site Down

      The issue caused your network or application to go down or critical business functions to stop.

    • Site at Risk

      The issue severely and negatively impacts your network or application.

    • Performance Severely Degraded

      The issue severely reduces the performance of your network or application.

    • General Assistance Required

      The subject of the case does not currently impact your network or application.

  • The hours that you are available to work on the issue (including your time zone) and any alternative contacts who can work on the issue if you are not available.
  • Remote access information, if possible.

    Note: Remote access to your network environment is important because it is the most effective method for collecting information and troubleshooting technical issues. When you cannot provide remote access, F5 Support works directly with you to resolve the issue over the phone; however, this method is often more time-consuming and may require file transfers, replication, and additional testing.

Product-specific information

The following product information is required when you open a support case:

Terraform

  1. Name of the specific Terraform file that you need help with. For example main.tf.
  2. Names of any other Terraform files that are located in sub directories that the main Terraform file calls.
  3. The output from the terraform plan and terraform apply command.
  4. Use the following command syntax to create a tarball of the directory in which you ran the Terraform commands:

    tar -czvf terrafiles.tgz <name directory>

    Then upload terrafiles.tgz to the F5 Support portal. For example, if your Terraform project is in the /home/root/terraform directory, enter the following command syntax:

    tar -czvf terrafiles.tgz /home/root/terraform

  5. The Terraform version you are running on your control machine. Enter the following command to display the Terraform version: 

     terraform -version

  6. The operating system environment on the control machine. The operating system that Terraform is running on.

  7. Verbose logging. Debug logs can be useful to troubleshoot issues.

    In Terraform, you can set the debug level by setting the TF_LOG environment variable to any one of the following values:

    • TRACE
    • DEBUG
    • INFO
    • WARN
    • ERROR

For more information about how to send the preceding information to F5, refer to K000090853: Exchange files with F5 Support using MyF5.

Managed BIG-IP systems

For managed BIG-IP systems, you must provide a QKView file (a TGZ archive), which contains the configuration files that F5 Support most frequently needs when troubleshooting an issue.

You can use the qkview utility to create and download QKView files from your managed BIG-IP systems. Generate a QKView file from each BIG-IP system that you manage using Terraform and is relevant to the Support case, and provide these files to F5 Support.

For more information about the qkview utility, refer to K12878: Generating diagnostic data using the qkview utility.
