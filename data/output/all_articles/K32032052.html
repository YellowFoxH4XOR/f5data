K32032052: BIG-IQ Cluster (HA) Issue after reboot

Type
Support Solution
Published
2021-05-11
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K32032052

Description

After rebooting BIG-IQ, HA communication is disrupted on tcp port 5432 and HA is no longer working.

The HA pair state may show the status as "In transition" and doesn't change.
 

Environment

  • BIG-IQ HA
  • HA had been working previously
  • Rebooting BIG-IQ

Cause

ID987041

Recommended Actions

Follow the steps to recover the HA:
  1. Allow tcp port 5432 on the BIG-IQ that is refusing connections on port 5432.  Let's call this the Primary BIG-IQ.
    /usr/bin/ha_set_firewall <primary_discovery_IP> <secondary_discovery_IP>
  2. Reset the HA configuration on both BIG-IQ's
    /usr/bin/ha_reset -f <self_discovery_IP>
  3. Add Secondary BIG-IQ to HA configuration via the GUI

Additional Information

Use the following command to verify connectivity (bi-directional) from both Primary and Secondary.

telnet <Discovery IP of peer BIG-IQ> 5432
