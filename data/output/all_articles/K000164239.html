K000164239: Special considerations for engineering hotfixes released on November 18, 2026

Type
Support Solution
Published
2026-11-18
Updated
2026-11-18
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3, 17.5.1, 21.1.0
Source
https://my.f5.com/manage/s/article/K000164239

Description

When upgrading your BIG-IP system to an engineering hotfix (EHF) to mitigate the vulnerabilities disclosed in Out-of-band Security Notification (November 18, 2026), use the guidance below to select the appropriate build for your current version.

Environment

  • BIG-IP TMOS versions: v21.1.x, v17.5.x and v17.1.x

Cause

The appropriate EHF build depends on the BIG-IP version or EHF currently installed.

Answer/Recommended Actions

The recommendation is to go to the following engineering hotfix build from F5 Downloads depending on your current EHF release:

  • BIGIP-17.1.3.6.0.14.20-ENG
    Install this build if you are currently running BIGIP-17.1.3.6.0.9.20-ENG.

  • BIGIP-17.1.3.7.0.21.4-ENG
    Install this build if you are running the 17.1.3.7 base release or an earlier base release.

  • BIGIP-17.5.1.10.0.80.35-ENG
    Install this build if you are currently running either BIGIP-17.5.1.10.0.7.35-ENG or BIG-IP-17.5.1.10.0.37.35-ENG.

  • BIGIP-17.5.1.11.0.61.12-ENG
    Install this build if you are running the 17.5.1.11 base release or an earlier base release.

  • BIGIP-21.1.0.4.0.19.3-ENG
    Install this build if you are running the 21.1.0.4 base release or an earlier base release.

If you are currently running a custom engineering hotfix build, contact F5 Support to request a new engineering hotfix.

Additional Information

None.
