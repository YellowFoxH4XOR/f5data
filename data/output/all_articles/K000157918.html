K000157918: How to upgrade a VELOS or rSeries Tenant from BIG-IQ

Type
Support Solution
Published
2025-11-20
Updated
2025-11-20
Source
https://my.f5.com/manage/s/article/K000157918

Description

You are managing your Velos Tenants on BIG-IQ and want to upgrade them.

Environment

  • BIG-IQ 8.4

  • VELOS Tenant
  • rSeries Tenant
  • Attempting to install on second partition (HD1.2)
  • the tenant was created using "ALL" image **NOT a T1 image

Cause

A tenant when created only has one disk volume / partition. As with any other BIG-IP you will need to create and install into a second partition.

The BIG-IQ does not recognise 2 or 1.2 as valid volumes and will error our:

 

Request for POST on 1.1.1.1 failed: status:400, body:{"code":400,"message":"01070945:3: Invalid volume name (2)","errorStack":[],"apiError":3}

Request for POST on 1.1.1.1 failed: status:400, body:{"code":400,"message":"01070945:3: Invalid volume name (1.2)","errorStack":[],"apiError":3}

 

Answer/Recommended Actions

You need to specify HD1.2 in full and BIG-IQ will initially classify it as unrecognised and then will create the new partition.
