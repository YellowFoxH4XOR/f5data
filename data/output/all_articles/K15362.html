Known Issue

The BIG-IP APM visual policy editor may not function properly when using the Firefox web browser.

This issue occurs when all of the following conditions are met:

  • The user attempts to modify access policy configuration settings with the visual policy editor for one of the following Resource Assign actions:
    • Bandwidth Control Policy (BWC): Assigns bandwidth control policies
    • AD Group Resource Assign: Maps ACLs and resources based on a user's Active Directory group membership

Impact

Users are unable to modify access policy Resource Assign actions.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Clearing the Resource Assign Action check boxes does not work, and the associated items counter increases with each attempt.
  • Clicking on a label or description of the Resource Assign action does not produce any results.
