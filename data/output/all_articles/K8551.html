Topic

Daylight Saving Time (DST) details vary by region and occasionally change. F5 updates time zone files with the release of a new software version. F5 will no longer create hotfixes to patch time zone changes.

Note: For information about setting the time zone on a BIG-IP system, refer to K9098: Setting the time zone on a BIG-IP system.

You can mitigate DST/time zone changes by setting the system time zone to the Coordinated Universal Time (UTC). To set the time zone to UTC on the BIG-IP system, perform one of the following procedures:

Setting the time zone to UTC on the BIG-IP system using the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to System > Platform.
  3. From the Time Zone menu, select UTC.
  4. Click Update.

Setting the time zone to UTC on the BIG-IP system using the command line

To set the time zone to UTC through the Traffic Management Shell (tmsh), complete the following steps:

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Set the updated time zone by typing the following command:

    modify /sys ntp timezone UTC

  3. Save the change by typing the following command:

    save /sys config
