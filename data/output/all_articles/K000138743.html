K000138743: Currently enabled ASM Internal parameters on CLI

Type
Support Solution
Published
2024-02-28
Updated
2024-02-28
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000138743

Description

Which ASM internal parameters are currently configured?


Environment

  • ASM Internal parameter
  • add_del_internal

Cause

None

Recommended Actions

GUI

look for the parameters under Security ›› Options : Application Security : Advanced Configuration : System Variables

(or)

CLI

look for the parameters under /var/ts/files/site_1/config/full/bd.cfg

It would look like below:


<truncated>

long_request_mem_percentage=10

max_raw_request_len=5000

single_page_application=0

restart_upon_config_update_error=0

cookie_httponly_attr=0

max_json_policy_size=1000

policy_history_min_retained_versions=2

policy_history_max_total_size=0

disable_cache_upon_injection=1

<truncated>
