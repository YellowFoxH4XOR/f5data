K000139143: FAST deletes existing configuration in target partition

Type
Support Solution
Published
2024-04-01
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP Link Controller
  • BIG-IP ASM
  • BIG-IP DNS
  • BIG-IP AFM
  • BIG-IP Analytics
  • BIG-IP APM
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000139143

Description

When deploying a service with F5 BIG-IP Application Services Template (FAST), existing configuration in the target partition (Tenant) is deleted.

Environment

  • BIG-IP with FAST

Cause

FAST is a templating system for Application Services 3 Extension (AS3). AS3 is designed to manage all configuration in the specified Tenant, and will delete any configuration which is not specified in the declaration.

Recommended Actions

None.

Additional Information

None.
