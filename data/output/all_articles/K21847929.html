Description
Management module of GUI operation can be slow when many entries of analytics feature used without AVR provision, such as AVR Widget. 
When the problem happened, warning logs similar to the following can be observed.

/var/log/restjavad.log 
[WARNING][PID][DD MMM YYYY HH:MM:SS UTC][8100/tm/analytics/dos-vis-attacks/generate-report AvrDosVisAttacksReportTaskCollectionWorker] thread [25] - posted result for query null : https://localhost/mgmt/tm/analytics/dos-vis-attacks/report-results/****************************

Environment

  • Hundreds of analytics features such as AVR Widget are configured
  • AVR is not provisioned

Cause
Analytics features will face resource shortage and it leads to slowness of management module operation.

Recommended Actions

To workaround the issue, provision AVR. 
  1. On the standby unit of HA, go to System >> Resource Provisioning.
  2. Select the Application Visibility and Reporting (AVR) module.
  3. Check-mark the box under the Provisioning column, Application Visibility and Reporting (AVR) module to set Nominal.
  4. For detail, refer "Task 1 – Provision the AVR module"
