Known Issue

Using the ARX management GUI to enter the proxy IP addresses may cause the system to store the IP order incorrectly in the ARX system configuration.

Impact

This mismatched IP order may prevent the unit from joining into an HA pair.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The show ip proxy-addresses command will present the proxy IPs out of order, compared to how they were entered into the ARX management GUI:

Example proxy IP order as entered into the ARX management GUI:

1) 10.10.100.200/16   
2) 10.10.100.201/16    
3) 10.10.100.202/16    

Example show ip proxy-addresses output:

Proxy Address       VLAN     Mac Address       Owner     In Use By     Proc
------------------  ----  -----------------   -------    -----------   ----
10.10.100.202/16     1    00:0a:49:75:30:01    example     example      1.5  
10.10.100.200/16     1    00:0a:49:75:30:01    example     example      1.4  
10.10.100.201/16     1    00:0a:49:75:30:01    example     example      1.3

Workaround

To work around this issue, you can enter the proxy IPs through the ARX CLI. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter config mode by typing the following command:

    config
  4. Add the proxy IP address using the following command syntax:

    ip proxy-address (address) (subnet mask)

    For example:

    ip proxy-address 10.10.100.200 255.255.255.0
  5. End the configuration mode by typing the following command:

    end
