K000159991: Virtual Server TCP connection behavior based on the pool or the virtual server state.

Type
Support Solution
Published
2026-02-12
Updated
2026-02-12
Source

Description
A Standard virtual server, with a tcp profile, may or may not respond to a TCP request even when it is "Offline (Enabled)" or "Available (Disabled Parent)".

Environment

The connection actions of a virtual server when it is Offline or administratively disabled.

CauseThere are different behaviors based on either the state of the pool or the virtual server:

  • For a virtual server per K9812: Overview of BIG-IP TCP RST behavior when the pool members are not available it is "Offline (Enabled) - The children pool member(s) are down".
    • "If the virtual server references a TCP profile (Standard virtual server type),  the system allows the three-way TCP handshake to complete before sending the TCP RST to the client."
    • "If the virtual server references a FastL4 profile, the system sends a TCP RST packet in response to a connection attempt. The TCP RST packet is sent on the client-side of the connection, and the source IP address of the reset is the relevant virtual server IP address.".
    • This is to allow for some iRule functionality even when the virtual server cannot pass traffic.
  • If all the pool members are "Disabled". then per K86025623: The status of a virtual server with all associated pool members disabled is now reported as Available (Disabled Parent):
    • The virtual server state will be "Available (Disabled Parent) - The children pool member(s) might be disabled".
    • "The connection is immediately reset following the initial Syn, with a reset cause of "VIP disabled (administrative)"".
  • If the virtual server state is set to "Disabled" then per K5773: A disabled virtual server still advertises through ARP
    • "Disabling a virtual server prevents the virtual server from accepting new connections. A disabled virtual (even a deleted virtual) will continue to process existing connections, and the virtual address still advertises through Address Resolution Protocol (ARP)."
    • The virtual server Availability will show "Available (Disabled) - The virtual server is available".

Recommended Actions

The action would depend on what is needed. For example if you are migrating (using a ucs or manually rebuilding the configuration) from an older hardware platform to a new one then the best course of action would be to only connect the management interface until you are ready to bring the new device online.

 

If the issue is due to a pool being unavailable and you need to prevent connections then the steps in K40554304: Stopping virtual server from responding if all pool members are down and the virtual server is offline  will cause an immediate Drop or Reject (Reset) of the connection attempt.
