Description

Qkview generation fails or generated 0KB file.
Tried to follow this solution: K61154426: Troubleshooting QKView diagnostic utility failures

However the situation does not changes.
Generate Qkview with command

qkivew -v
...
Executing Module: [qkavr.so]
        Executing /usr/bin/du -h /var/lib/mysql/AVR/ ...
        Result: [0] Elapsed: 0.011858
        Executing /usr/bin/tmsh -a show analytics report view-by virtual include-total measures { average-page-load-time } range now-1h ...


And numbers of this process stays there and timeout and create another 0KB qkview.
Thus you need to kill qkview process again.
 

Environment

  • BIG-IP
  • any version
     

Cause

AVR database corruption.
 

Recommended Actions

AVR database corrupted and need to reset database.
follow this article and reset the AVR database: K14956: Resetting F5 Application Visibility and Reporting statistics
 

Additional Information

  • K11419837: Troubleshooting qkview process stuck/stalled
