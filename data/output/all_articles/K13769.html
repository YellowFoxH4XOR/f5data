Known Issue

When accessing Outlook Web Access public folders, the users are returned to the login screen.

This issue occurs when all of the following conditions are met:

  • The Outlook Web Access version being accessed is 2003.
  • Outlook Web Access is being accessed through a BIG-IP APM web portal.

Impact

Outlook Web Access users are unable to access public folder items.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are returned to the login screen when accessing public folders.
  • A web application trace shows the 440 Login Timeout status code when a PROPFIND request is made for /public/?Cmd=navbar.

    Front-end request: PROPFIND /public/?Cmd=navbar

    Back-end response:HTTP/1.1 440 Login Timeout
