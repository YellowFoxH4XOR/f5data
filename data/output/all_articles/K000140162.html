K000140162: DNS Prefetch behavior

Type
Support Solution
Published
2024-11-03
Updated
2025-03-31
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.5.X, 17.1.X, 17.1.2, 17.1.0, 17.1.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000140162

Description

In BIG-IP DNS 17.1.0 F5 introduced the Prefetch feature for the DNS Cache. Prefetch is used to allow BIG-IP DNS to fetch for the records in its cache before the TTL expires. When enabling prefetch, common site FQDNs will be cached before expiring its data. The benefits of this technique are low latency and high caching hit rate.

The prefetch functionality is only triggered when there is 10% left of the records TTL. Take note that there should be a query to the record within the last 10% of the TTL for it to be triggered. For example, if TTL is configured to be 3600, a query for that record should be done within the last 360 seconds so the prefetch behavior will be triggered.

Environment

  • BIG-IP DNS
  • DNS Cache

Cause

Prefetch is disabled by default. The configuration displays a value of no for the setting when disabled:

ltm dns cache resolver test-resolver {
<snip>
    serve-expired no
    serve_expired_ttl 0
    serve_expired_reset no
    serve_expired_reply_ttl 30
    serve_expired_client_timeout 0
    prefetch no
<snip>
}

Recommended Actions

You can enable Prefetch by performing the following procedure:

  1. Go to DNS > Caches.
  2. Select the cache where you want to enable the feature.
  3. On the settings page, for Prefetch select the box next to Enabled.
  4. Select Update.
