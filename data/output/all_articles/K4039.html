Topic

3-DNS and BIG-IP version 4.x systems communicate using the iQuery protocol. BIG-IP version 9.0.0 introduced a new version of the iQuery protocol, which uses SSL and TCP.

iQuery communication is fully functional between BIG-IP / 3-DNS versions 4.x and LTM / GTM versions 9.0.0 through 10.0.1.

Important: iQuery communication is not supported between BIG-IP / 3-DNS versions 4.x and BIG-IP LTM / GTM versions 10.1.0 and later systems. For more information, refer to K11106: Change in Behavior: iQuery communication is not supported between BIG-IP / 3-DNS version 4.x and BIG-IP LTM / GTM version 10.1.0 and later systems.

Each device can simultaneously communicate through iQuery with other iQuery-enabled F5 system. For example, you can have a mix of the following systems intercommunicating through iQuery:

  • BIG-IP version 4.5.x
  • 3-DNS version 4.5.x
  • BIG-IP LTM version 10.0.x only
  • BIG-IP GTM version 9.x

The iQuery communications between BIG-IP, 3-DNS, LTM, and GTM systems operate as follows:

3-DNS version 4.x communicating to BIG-IP version 4.x

  • The 3-DNS uses the big3d_install script to install a version appropriate big3d daemon to the BIG-IP 4.x system.
  • Both systems use the big3d daemon to communicate over the original iQuery protocol. This communication can be plain text or encrypted.

3-DNS version 4.x communicating to BIG-IP LTM 9.0.0 through 10.0.1

  • The 3-DNS big3d_install script attempts to install its version of the big3d daemon to the BIG-IP LTM. However, the BIG-IP LTM prevents the installation, and instead continues to use its own big3d daemon.
  • The 3-DNS version 4.x big3d daemon uses the original iQuery protocol. The BIG-IP LTM uses the big3dshim daemon to translate betwen iQuery protocol versions, and passes communications to the BIG-IP LTM big3d daemon.

BIG-IP GTM 9.0.0 through 10.0.1 communicating to BIG-IP version 4.x

  • The BIG-IP GTM uses the big3d_install script to install its big3d daemon and big3dshim daemon to the BIG-IP version 4.x.
  • The GTM big3d daemon allows the BIG-IP version 4.x to communicate with the BIG-IP GTM using the current version of the iQuery protocol.
  • The big3dshim daemon allows the BIG-IP version 4.x to communicate with other 4.x systems using the original version of the iQuery protocol.

BIG-IP GTM communicating to BIG-IP LTM

Both units communicate exclusively using the current version of the iQuery protocol.
