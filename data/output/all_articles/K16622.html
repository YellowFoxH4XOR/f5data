Known Issue

The BIG-IP Edge Client may fail to establish a network access tunnel.

This issue occurs when all of the following conditions are met:

  • You are using the BIG-IP Edge Client for Windows, Mac OS, or Linux to establish a split tunnel network access session.
  • The network access split tunnel configuration is larger than 10240 bytes.

Impact

The system fails to establish a network access tunnel.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you examine the byte length of the network access split tunnel configuration, you see that total bytes are in excess of 10240 (approximately 350 LAN IP addresses).
  • When the network access session fails to establish, the system does not present any warnings to the user, and no messages appear in the BIG-IP APM log regarding the cause of the failure.
  • When you reduce the number of defined LAN addresses of the network split tunnel, where the total bytes are below 10240, users are able to establish network access tunnels with the BIG-IP Edge Client.

Resolution

Status

Workaround

To work around this issue, you can limit the amount of defined LAN address of the network access split tunnel configuration ensuring a total byte size of less than 10240 bytes.
