Description
Always-On Management (AOM) is a separate subsystem that provides lights-out management for the BIG-IP system.
You can configure AOM network - IP address.

When you configure AOM network as the same as the management-ip address, two mac-addresses would be advertised
in the network - base-mac and management-port mac-address.

  ------------------------------------------------------------------
  Sys::MAC Address
  Entry              Component              Object-ID    Property
  ------------------------------------------------------------------
  00:94:a1:c9:2c:00  cm device              bigip.local  base-mac     <--- 
  00:94:a1:c9:2c:00  sys hardware platform  n/a          base-mac     <--- 
  00:94:a1:c9:2c:02  net interface          mgmt         mac-address  <--- mgmt port mac-address
  00:94:a1:c9:2c:04  net interface          1.0          mac-address
  00:94:a1:c9:2c:05  net interface          2.0          mac-address
  00:94:a1:c9:2c:06  net interface          3.0          mac-address
  00:94:a1:c9:2c:07  net interface          4.0          mac-address
  00:94:a1:c9:2c:08  net interface          5.0          mac-address
  00:94:a1:c9:2c:09  net interface          6.0          mac-address

If the peer device learn the base-mac, the device couldn't access the management-port via https and ssh.

Environment

  • BIG-IP All appliances

Cause
AOM network (ip address) is the same as management-ip address.
BIG-IP may advertise two mac-addresses for the management-ip address.

Recommended Actions

Login AOM subsystem and modify or reset AOM network.
