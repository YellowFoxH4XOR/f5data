Description

You see warnings similar to the following on /var/log/ltm when you disable and enable the interface (e.g. 1.1). The number of ethX may vary.

warning mcpd[4817]: 01071859:4: Warning generated : cannot set MTU for eth1. No such device. For legacy VE driver

Environment

  • You are using v13.1.0 and above.
  • You disabled and enabled the interface.
    # tmsh modify net interface 1.1 disabled
    # tmsh modify net interface 1.1 enabled
  • You reboot the BIG-IP.
  • You are not using VMware ESXi 6.7 host Update 2 (or later).

Cause

None. 

Recommended Actions

You can safely ignore the message if the BIG-IP processes traffic without any problem as this is cosmetic.
If you are using VMware ESXi 6.7 host Update 2 (or later), you may also want to refer to K74921042.

None
