Known Issue

Description

Exporting an access policy fails with the following error message:

BIGpipe parsing error: 012e0008:3:The requested command (certificate file) is invalid.

This issue occurs when all of the following conditions are met:

  • The access policy uses the Machine Cert Auth action
  • The Machine Cert Auth action defines a CA Profile that uses a self-signed certificate

Impact

Access policies containing the Machine Cert Auth action cannot be exported.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The following error message is displayed when exporting the access policy, where <ca profile> is the certificate authority profile defined in the machine certificate check action:

    certificate file object <ca profile> list has returned BIGpipe parsing error: 012e0008:3: The requested command (certificate file) is invalid
