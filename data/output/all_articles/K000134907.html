K000134907: What are the methods to authenticate BIG-IP LTM API users

Type
Support Solution
Published
2024-05-23
Updated
2025-09-12
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000134907

Description

Is it possible for the BIG-IP LTM to authenticate API requests using a private key via external TACACS authentication?

Environment

  • LTM
  • REST API
  • User Authentication

Cause

To avoid sharing admin or root passwords with REST API users

Recommended Actions

REST API user authentication using private key via TACACS is not supported.

Currently, there are two methods in BIG-IP LTM to authenticate API users:

  • Basic authentication
  • Token Based authentication

None
