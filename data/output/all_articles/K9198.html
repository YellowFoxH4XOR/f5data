Issue

Previously, when you configured the Windows machine certificate checker in a pre-logon sequence, the only option in the Match Rule menu was the CN matches machine's FQDN option.

Starting in FirePass 6.0.3, when you configure the Windows machine certificate checker, the following additional options are available in the Certificate Match Rule menu (formerly named the Match Rule menu):

Note: The CN matches machine's FQDN option was renamed to Subject's CN match machine's FQDN starting in FirePass 6.0.3.
 
  • SubjectAltName field(regex extraction) match machine's FQDN
  • Any
  • Issuer (regex match)
  • Issuer (regex match) and Serial Number
 
Additionally, starting in FirePass 6.0.3, three optional configuration fields were added to the Windows machine certificate checker for advanced parsing of the SubjectAltName, Issuer, and Serial Number certificate values:

Note: The following three fields are optional and only valid for the rules that match them.
 
  • SubjectAltName(regex, e.g., '.*DNS Name=([^,]+).*')
  • Issuer(regex, e.g., 'CN=.*, O=F5, L=San Jose, S=CA, C=US')
  • Serial Number(hex string, e.g., '05060708090a')
 
The Windows machine certificate checker checks for the presence of a machine certificate on Windows client systems. For more information about configuring the Windows machine certificate checker, click the Help link on the Endpoint Inspector Details page for the Windows machine certificate checker.
 
F5 Product Development tracked this enhancement as CR77650 and it was included starting in FirePass 6.0.3. For information about upgrading, refer to the FirePass Release Notes.
