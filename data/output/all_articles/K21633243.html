Issue

Error Message

01531010:3: Transfer of zone <zone_name> failed b/c there are no records.

In this error message, note the following:

  • <zone_name> is the name of the zone attempting to transfer from a remote DNS nameserver.

For example:

01531010:3: Transfer of zone example.com failed b/c there are no records.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • A zone transfer answer is received from a master nameserver with no records.  

    Note: At minimum, there should be a Start of Authority (SOA) record in the answer, even if there are no zone resource records.

Impact

If this is the initial zone transfer, DNS Express does not host the zone. If the zone was successfully transferred previously, DNS Express does not receive updates to the zone. If the zone transfer continues to fail, and the zone expiration time is exceeded, DNS Express stops hosting the zone until the next successful transfer.

Recommended Actions

  • The configuration on the master DNS nameserver should be investigated to determine why malformed zone transfer responses are being generated.
  • The BIG-IP system will continue to attempt to transfer the zone. After the issue on the master nameserver is resolved, the BIG-IP system can transfer the zone again.
