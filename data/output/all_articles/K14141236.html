Description

SNMP users may fail to connect to the Big-IP when special characters are used in the password.

  • Can't save SNMP user with special characters in the password
  • Error message:  Incomplete Command when trying to add SNMP user with special characters

Environment

Configuring SNMP user

  • SNMP user with special character in password
  • BIG-IP

Cause

Special character in SNMP user password

Recommended Actions

SNMP user passwords containing special characters should be wrapped in double quotes, and any special characters should be escaped with \

For example:
#tmsh modify sys snmp users add { SnmpUser1 { access ro auth-password "p\#assword" auth-protocol sha oid-subset .1 privacy-password "p\#assword" privacy-protocol des security-level auth-privacy username MySnmpUser1 } }
