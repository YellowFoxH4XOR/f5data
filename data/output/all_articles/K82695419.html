Description
When you activate a license on AWS BIG-IP instance, you get the error message.
Unable to grant license key: Error 51133, F5 registration key is not compatible with the detected platform - This platform, "Z100a_pc", cannot be activated with this registration key

Environment

  • BIG-IP VE PAYG instance on AWS

Cause
You applied BIG-IP VE base registration key to PAYG pre-licensed instance.
Platform ID "Z100a_pc" stands for AWS pre-licensed PAYG images.

Recommended Actions

Use BIG-IP VE BYOL image instead of pre-licensed PAYG image.

Additional Information
You can check the instance type on BIG-IP.
 EC2 > Instance > (Click BIG-IP)
 AMI name indicates PAYG or BYOL.
