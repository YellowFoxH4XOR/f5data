Description

NGINX Plus fails to start with the following error:

nginx: [emerg] could not build server_names_hash, you should increase server_names_hash_bucket_size: 64

Cause

The configured server-name hash table is insufficient for the number or length of the configured server names. The required bucket size can also vary according to the host processor’s cache-line size.

Recommended Actions

  1. Update the NGINX configuration within the http block:

    server_names_hash_max_size 128;
    server_names_hash_bucket_size 128;

  2. Validate the configuration:
    nginx -t
  3. Restart NGINX:
    systemctl restart nginx
  4. Confirm that NGINX is running.

Additional Information

  • NGINX uses hash tables to store and look up server names.
  • A large number of server names or unusually long server names may require larger hash-table settings.
  • Different host processor architectures may require different server_names_hash_bucket_size values.
  • If the error persists, increase the hash settings as required by the configured server names.
