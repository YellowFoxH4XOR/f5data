Description

Logs generated with request-logging template attached to virtual-server will be intermittently missing values. As shown below, sometimes Server IP and Server Port values are blank and sometimes it is correctly visible.

Virtual: /Common/Pool: /Common/Repro-Pool  Server IP: 10.10.10.10 Server Port: 80.......
Virtual: /Common/Pool: /Common/Repro-Pool  Server IP: 10.10.10.10 Server Port: 80.......
Virtual: /Common/Pool:  Server IP:  Server Port: .......               -----------> This shows the missing values of server side variables used in request-logging.
Virtual: /Common/Pool:  Server IP:  Server Port: .......               -----------> This shows the missing values of server side variables used in request-logging.
Virtual: /Common/Pool:  Server IP:  Server Port: .......               -----------> This shows the missing values of server side variables used in request-logging.
Virtual: /Common/Pool:  Server IP:  Server Port: .......               -----------> This shows the missing values of server side variables used in request-logging.
Virtual: /Common/Pool: /Common/Repro-Pool  Server IP: 10.10.10.10 Server Port: 80.......
Virtual: /Common/Pool: /Common/Repro-Pool  Server IP: 10.10.10.10 Server Port: 80.......

Environment

  • Request Logging Profile.
  • Request/Response Logging Template.
  • Logs.
  • VS Connection Limit
  • VS Connection rate-limit.

Cause

Virtual-Server configured with connection-limit or connection rate-limit will show this behaviour when server side variables is used in request-logging or client-side variables is used in Response Logging.

Logging Template with Server Side variables in Request Logging:

request-log-template "Virtual: $VIRTUAL_NAME Pool: $VIRTUAL_POOL_NAME Server IP: $SERVER_IP Server Port: $SERVER_PORT"

Logging Template with Client Side variables in Response Logging:

response-log-template "Client-IP: $CLIENT_IP Client-Port: $CLIENT_PORT"

Recommended Actions

  1. This behaviour is expected and functioning as designed. It is recommended to not use server side variables in request-logging-template or client-side variables in response-logging-template if VS is configured with connection rate-limit or connection limit.

  2. If it is required to use server-side variables in request logging or client-side variables in response logging then it is suggested to remove rate-limit or connection-limit from that VS configuration.

Additional Information

This behavior is documented under ID 977609.
