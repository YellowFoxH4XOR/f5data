Topic

BIG-IP interface mirroring, when configured, allows the BIG-IP system to copy the traffic on one or more interfaces to another interface. Typically, you use this configuration to passively monitor network traffic. By default, the interface mirroring feature is disabled.

Description

When an interface is designated for mirrored network traffic, F5 recommends that you avoid attempting to analyze traffic on the mirror interface using the tcpdump utility on the local BIG-IP device. F5 recommends using an external capture device attached to the network interface to analyze (sniff) traffic that is mirrored to the interface. Using the tcpdump utility on the local BIG-IP device on a mirror interface can interrupt the duplication of traffic on the interface.

Note: For more information on configuring the BIG-IP for interface mirroring refer to the Configuring the BIG-IP System for Passive Monitoring chapter of the BIG-IP System: Implementing a Passive Monitoring Configuration manual.
