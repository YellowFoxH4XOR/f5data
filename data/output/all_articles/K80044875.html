K80044875: TCL Error /Common/_sys_APM_Exchange <HTTP_REQUEST> - Illegal argument (line *) invoked from within ''HTTP::username''

Type
Support Solution
Published
2019-12-12
Updated

Applies to

  • BIG-IP APM: 16.X.X, 17.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.0.0
Source

Description

In some cases clients send null Auth headers, this causes an internal iRule to fail when accessing the Virtual Server created by the Exchange iApp.  It also causes the following log message to be generated, which can result in excessive disk usage:

Dec 20 10:11:12 BIGIP1 err tmm[14403]: 01220001:3: TCL error: /Common/_sys_APM_Exchange <HTTP_REQUEST> - Illegal argument (line xxx) invoked from within "HTTP::username"

Environment

  • BIG-IP APM
  • Exchange iApp

Cause

This error is caused by a client sending an improperly formed Auth header, specifically a null value header.

Recommended Actions

  • Ensure that the client devices aren't sending null Auth headers
    OR
  • Create a logging filter to prevent the log from being included:
    sys log-config filter RemoveTCL_Error {
      app-service none
      description RemoveTCLerror_sys_APM_Exchange
      level debug message-id 01220001
      publisher none
      source all
    }
    This can be reached from the Configuration Utility (GUI) from the System > Logs > Configuration > Log Filters menu option
