Issue

Error Message

01071038:5: Unit key read from the hardware.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions are met:

  • Your BIG-IP system configuration is reloading.
  • Your BIG-IP system unit key has been loaded into memory.

The Secure Vault feature provides security through the use of two cryptographic keys: the unit key and the master key. The unit key is securely stored in the BIG-IP system's (S)EEPROM hardware and is used to encrypt and decrypt the master key. The master key is stored on the BIG-IP file system and is used by the Master Control Program Daemon (MCPD) to encrypt and decrypt passphrases and passwords when loading BIG-IP system configuration files.

Impact

None. This message is informational only.

Recommended Actions

None
