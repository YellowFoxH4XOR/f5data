Issue

Error Message

err kernel: Out of memory: Kill process <process ID> (<process name>) score <score value> or sacrifice child

In this error message, note the following:

  • <process ID> is the numeric identifier used by the Linux operating system to uniquely identify an active process.
  • <process name> is the alphanumeric or human readable identifier for an active process.
  • <score value> is based on the percentage of memory being used by the process; processes are killed by higher to lower values during an out-of-memory condition.

For example:

warning kernel: httpd invoked oom-killer: gfp_mask=0x201da, order=0, oom_adj=0, oom_score_adj=0
...
...

err kernel: Out of memory: Kill process 13579 (java) score 90 or sacrifice child

Message Location

You may encounter this message in the following location:

  • The /var/log/kern.log file

Description

This message occurs when the following conditions are met:

  • One or more active processes have consumed an excessive amount of memory, which may be due to:
    • The process failing to release memory appropriately (also referred to as a memory leak).
    • The Linux kernel over-committing memory and allocating more memory to processes than is available.
  • Little available memory remains for use by other system processes (also referred to as memory pressure)

When the BIG-IP system's processes experience memory pressure, the Linux OOM killer scores and kills, or sacrifices, one or more processes while attempting to free memory.

Impact

The BIG-IP system may stop processing traffic, experience a failover event, or become unstable due to one or more processes being killed by the OOM killer.

Recommended Actions

To further investigate and troubleshoot the activation of the OOM killer, generate a qkview file and open a support case. For more information, refer to the following articles:
