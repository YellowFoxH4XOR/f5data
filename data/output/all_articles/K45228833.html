Description

  •  APi tokens are not masked
  • ASM event logs records API retrieved information in plain text

for example 
{"ipAddress":"0.0.0.0","password":"passwd","username":"user1"}

Environment

  • ASM
  • API Calls
  • Event Logs

Cause

  • JSON content profile masking is missing or not configured 

Recommended Actions

  • Configured a JSON content profile following Masking request log data for JSON profiles

  • None
