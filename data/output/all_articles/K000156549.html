Source
https://my.f5.com/manage/s/article/K000156549

Description

Unable to access GUI of BIG-IP, but SSH access works fine.

Browser displays a 404 response similar to the following when attempting to access the login page at /tmui/login.jsp:

(Example from Firefox)

Looks like there’s a problem with this site

https://10.10.10.245/tmui/login.jsp sent back an error.

Error code: 404 Not Found

    Check to make sure you’ve typed the web site address correctly.

Environment

  • BIG-IP GUI access

Cause

This problem is known to occur if files in the /var/cache/tomcat directory have been deleted.

Recommended Actions

To recover from this issue, install a new boot location. It can be the same software version that is running in the active boot location.

To determine whether important files were deleted, examine the bash history for each user.

Additional Information

Care should be taken not to delete important system files when attempting to free disk space.
