Topic

This article covers how you can opt-in and opt-out of an application study based on uploads of a BIG-IP QKView configuration file to F5 iHealth. 

You should consider using this procedure under the following condition:

  • You want to opt-in to the F5 application study.
  • You want to opt-out of the F5 application study.

Description

An application study is the practice of using the qkview utility to produce a QKView diagnostic file from a BIG-IP system in your environment and presenting the data in a way that shows what the BIG-IP system is doing for each application (on a virtual server or collection of virtual servers), how much traffic the system is processing, and what unique services the system is applying to that traffic.

The goal of the study is to help F5 provide better insight, based on your business outcome goals, into how you are leveraging your current investment, the applications F5 is supporting, and areas where improvements, changes, or both can be made. F5 may also use the data to offer additional services for potential areas of improvement. F5 will not use the data derived from this application study for any purposes other than those described in this article, nor will F5 share or disclose it to third parties.

By participating and uploading QKView files for this specific intent, F5 is providing this notice. which explains the details of the data F5 leverages, how long F5 stores the data, and who has access to the data. Your participation in the study is completely optional and F5 performs these analyses only when you perform the opt-in procedure described in this article.

Data collection and retention

To provide a relevant study, F5 asks you to upload a QKView file for each target BIG-IP in your environment. After the QKView files are uploaded, a data parsing tool runs that captures only the relevant data needed for the study, which is stored in a protected F5 database. The data is stored for five years so that F5 can run a second study, with your future permission, and provide you with comparisons. Using existing access control systems within F5, access to your data is limited to only those with responsibility for servicing you. For further information on our data processing policies, refer to the F5 Privacy Notice. If at any time you have questions or concerns about this study or your data, including removal of the data prior to five years, you can notify your account team.

When you upload your QKView files, they contain data which may include personal or sensitive data; F5 uses technical means to ensure that this data is not used in this study and remains in iHealth.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You or your organization have accepted F5’s end user license agreement (upon product download or activation).
  • You have administrative access to the BIG-IP command line.

Procedures

  • Opt-in to the F5 application study
  • Opt-out of the F5 application study

Opt-in to the F5 application study

You can opt-in F5 application study by creating f5_app_study_opt_in file under /etc directory of the BIG-IP device you agree to be part of the F5 application study. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line on the BIG-IP device you agree to be part of the F5 application study.
  2. To create the required opt-in file, enter the following command:

    touch /etc/f5_app_study_opt_in

  3. Create a QKView file of the BIG-IP device and upload it to iHealth. For more information, refer to K12878: Generating diagnostic data using the qkview utility.

Opt-out of the F5 application study

You can opt-out F5 application study by removing f5_app_study_opt_in file from the BIG-IP device you previously agreed to be part of the F5 application study. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line on the BIG-IP device you had agreed to be part of the F5 application study.
  2. To opt-out, enter the following command:

    rm -f /etc/f5_app_study_opt_in
