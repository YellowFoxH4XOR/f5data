Description

LDAP authentication for administrative users fails when the LDAP server certificate is expired.

Logs in /var/log/secure:

Dec 21 13:53:18 hostname err httpd[xxxx]: pam_ldap(httpd:auth): error reading from nslcd: Connection reset by peer
Dec 21 13:53:18 hostname warning httpd[xxxx]: pam_unix(httpd:auth): check pass; user unknown
Dec 21 13:53:18 hostname notice httpd[xxxx]: pam_unix(httpd:auth): authentication failure; logname= uid=48 euid=48 tty= ruser= rhost=aaa.bbb.ccc.ddd
Debug output of nslcd: 
nslcd: [8b4567] <authc="sample_user"> DEBUG: ldap_simple_bind_s("CN=F5, OU=Service-Accounts, DC=my-domain, DC=com","***") (uri="ldaps://ldaphostname:636")
nslcd: [8b4567] <authc="sample_user"> DEBUG: set_socket_timeout(30,500000)
nslcd: [8b4567] <authc="sample_user"> DEBUG: failed to bind to LDAP server ldaps://ldaphostname:636: Can't contact LDAP server: TLS error -8157:Certificate extension not found.: Is a directory
nslcd: [8b4567] <authc="sample_user"> DEBUG: set_socket_timeout(15,0)
nslcd: [8b4567] <authc="sample_user"> DEBUG: ldap_unbind()
nslcd: [8b4567] <authc="sample_user"> DEBUG: "sample_user": user not found: Can't contact LDAP server

The packet capture also says "Alert (Level: Fatal, Description: Bad Certificate)".
 

Environment

  • BIG-IP
  • LDAP configured for management authentication
 

Cause

Expired LDAP Server certificate
 

Recommended Actions

(1) To enable debug logging and have the system post log messages to the SSH/console window, start the nslcd process with -d option, which causes nslcd to run in the foreground until you press control-c to stop it:

  # systemctl stop nslcd
  # nslcd -d

Note: The -d setting does not persist, so you must complete this procedure each time you want to log debug output. You can increase the level of debug output by specifying additional -d options (up to 3), e.g., '-ddd' or '-d -d -d'. When done, stop nslcd with control-c, and then restart it with the default options via the normal systemctl daemon:

  # systemctl start nslcd

(2) To verify the validity of the LDAP certificate, you can use 'openssl s_client -connect ldaphost:636' to display the LDAP certificate, save it to a file (/tmp/certificate.crt) then 'openssl x509 -in /tmp/certificate.crt -text -noout -startdate -enddate'.

(3) Renew the certificate of LDAP server
