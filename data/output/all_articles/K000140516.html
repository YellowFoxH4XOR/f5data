Description

When attempting to deploy an app with Guided Configuration in an HA pair, you may receive the error 'connect EHOSTUNREACH < peer management ip:443>

 

Environment

  • HA configured
  • No Connectivity via Management Interfaces

 

Cause

This error will occur when there is no connectivity established between the management interfaces of the units in an HA configuration, regardless of communication via ConfigSync IPs.

 

Recommended Actions

Units in HA must have communication via the MGMT interfaces.
