Known Issue

The Filter box within the Wide IP List section of the BIG-IP GTM Configuration utility is case sensitive. This behavior may affect searches where the wide IP name has both uppercase and lowercase characters, but you are searching using only lowercase characters.

Note: Beginning in BIG-IP 11.2.0, the Filter box has been renamed the Search box.

Impact

You may need to manually search for the wide IP object you need.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If you use a search term for a wide IP that does not match the case of the wide IP that is configured on the BIG-IP GTM system, you may get an empty search result.

Note: Due to a known issue documented in K13872: The wide IP filter returns no results, you may encounter empty search results on all search terms on BIG-IP 11.0.0 and 11.1.0, regardless of case.

Workaround

To work around this issue, you can select Show All in the page selection menu near the bottom-right side of the screen and use your browser search function to locate the wide IP you need.
