K000151796: XCDOC: HTTP 404s when the HTTP Load Balancer have disabled the "HTTP Redirect to HTTPS" option

Type
Support Solution
Published
2025-11-06
Updated
2025-11-06
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Apps
Source
https://my.f5.com/manage/s/article/K000151796

Description

You have configured an HTTP Load Balancer and you do not want to use the port 80 at all, so you disable the "HTTP Redirect to HTTPS" function but when testing you get the error HTTP 404 "Route not Found"

Environment

  • HTTP Load Balancer

Cause

This is an expected behavior if you are using the same default VIP to expose your WebApp that came with the subscription. 
If you have enabled that option in some other HTTP Load Balancer, it will create a listener in the port 80 and accept HTTP Requests.
So, if other HTTP Load Balancer have the "HTTP Redirect to HTTPS" disabled, it will displays the error HTTP 404: Route_not_found
