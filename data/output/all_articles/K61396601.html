Description

BIG-IP ASM scheduled report emails are sent every hour, despite the configured frequency being different.

Environment
  • BIG-IP ASM
  • scheduled reports configured
Cause

Configured by default timeout is too low (this timeout determines how long to wait for SMTP receipt confirmation)

Bug ID 863069: avrmail timeout is too small

You will see the following messages on /var/log/asm:

crit perl[<PID>]: 01310027:2: ASM subsystem error (run_scheduled_reports.pl,F5::AVReporter::Client::run_monpd_method): Monpd error: Could not send e-mails: SMTP Error: data not accepted.

Recommended Actions

See Workaround given related Bug ID 863069: avrmail timeout is too small.
