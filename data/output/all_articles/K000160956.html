Description

Performance Graphs Throughput Bits shows higher value than actual capacity.

At GUI of BIG-IP, the Performance Graphs Traffic shows spikes in the Throughput, however there is no actual traffic of that amount.

 

Environment

When the BIG-IP frequently receives bursts of traffic for a new flow. Some examples:

 - Several packets arrive for a new UDP flow.

 - Several packets arrive for a non-existent TCP flow

Over time, the traffic counts build up and might all be accounted for at once resulting in a spike in the graphs.

BIG-IP 15.1 , 16.1 , 17.1 , 17.5

 

Cause

F5 tracks this as ID1928437, and fixed in BIG-IP 17.1.3 and 21.0.

 

Recommended Action

In order to confirm the affected condition, we recommend to take CLI records as follow, when the symptom was observed.

# tmsh show sys performance throughput detail historical

For detail of this command, refer K50309321: Viewing BIG-IP system throughput statistics
