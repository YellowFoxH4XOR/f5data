Topic

Beginning in version 9.3.1 for the BIG-IP 9.3.x software branch, and in version 9.4.0 for the BIG-IP 9.4.x software branch, all but the linux* terminal type definitions were removed from the BIG-IP installer to minimize its size. The absence of traditionally supported terminal type definitions, such as the VT100, xterm, and IBM PC terminal types, may cause console usability or readability issues for customers using equipment designed to use those definitions.

F5 Product Development is tracking an enhancement request to restore some of the more traditional terminal types to the BIG-IP installer as CR109694.

Workaround

You may be able to upgrade your KVM software to a version that supports the linux* terminal type definitions included in the installer build.
