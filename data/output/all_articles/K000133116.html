K000133116: How to clear critical alarm: Power supply 1 GPIO status(FND850): Bad (FDIP)

Type
Support Solution
Published
2023-03-26
Updated
2025-03-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0
Source
https://my.f5.com/manage/s/article/K000133116

Description

How to clear critical alarm.

Environment

  • BIG-IP
  • LCD Alarm
  • LCDWARN

Cause

None

Recommended Actions

 1. Run the 'tmsh show /sys alert' command, to find the Priorty level of the alart

[root@bigip1:Standby:In Sync] # tmsh show /sys alert

--------------------------------------------------------------------------------------------------------------------------

Sys::LCDAlerts

Slot   Timestamp Priority  Id                 Description

--------------------------------------------------------------------------------------------------------------------------

0 03/20/23 23:04:02 critical 0x112a0013 Blade 0 hardware sensor critical alarm: Power Supply 2 GPIO status(FND850): Bad (FDIP)


Note : In this example the alert is Critical
 

2. Run 'lcdwarn -c critical', to clear the alarm from the LCD
    (Alternatively, 'lcdwarn -c 4' )

Note: For Emergency, ID is 4

Additional Information

lcdwarn --help

Usage: /bin/lcdwarn [OPTION]... MESSAGE

Send a message to the LCD screen.

 -p, --priority=LEVEL Set priority of message to LEVEL
 -c, --clear=LEVEL   Clears all messages of priority LEVEL
 -h, --help      Display this help and exit
 

LEVEL can be [0|1|2|3|4|5] or [warning|error|alert|critical|emergency|info]
