Known Issue

Attack signature details may not be reported in violation information.

This issue occurs when all of the following conditions are met:

  • The request matches a configured parameter.
  • The Sensitive Parameter setting is enabled for the parameter.
  • A staged or non-staged attack signature is detected in a sensitive parameter.

Impact

Users cannot view or learn about violations in the Configuration utility for attack signatures that match sensitive parameters.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are unable to view the attack signature ID responsible for a blocked request.
  • You are unable to view the attack signature violations list for affected requests.
  • Disabling the Sensitive Parameter setting allows you to view the attack signature details.

Workaround

To work around this issue, you can configure a remote logger to include the violation details and support ID. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system; however, this workaround assumes that you have a functional remote logging configuration.

  1. Log in to the BIG-IP ASM Configuration utility
  2. Navigate to Security > Event Logs > Logging Profiles.
  3. Click the name of the logging profile to edit.
  4. In the Storage Format area, under the Application Security tab, select violation_details and support_id from the Available Items list.
  5. Move the selected items to the Selected Items area by clicking <<.
  6. Click Update.
