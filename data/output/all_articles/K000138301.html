Topic

You should consider using this procedure under the following condition:

  • You want to use the BIG-IQ system to update the protocol inspection signatures on the managed BIG-IP AFM device.

Description

BIG-IP AFM protocol inspection profiles use sets of signatures to detect protocol anomalies in traffic. F5 periodically updates these signatures and releases them on the MyF5 Downloads site. You can download and install protocol inspection updates on the managed BIG-IP AFM device using the BIG-IQ system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IQ system and the managed BIG-IP device.
  • You have have one of the following:
    • A licensed and provisioned the BIG-IP AFM module that is the primary module on your managed BIG-IP device (BIG-IP AFM with BIG-IP LTM and other modules as add-ons).
    • A separate license key enabling the Protocol Inspection Signature Matching and Compliance Engines features.
  • You have internet access to the MyF5 Downloads site either from your local workstation or directly from your BIG-IQ system.

Procedures

There are two ways to download and update the protocol inspection signature depending on whether:

  • BIG-IQ system has direct internet access
  • BIG-IQ system does not have direct internet access

BIG-IQ system has direct internet access

If your BIG-IQ system has direct internet access, you can download the protocol inspection signature from MyF5 Downloads site to your BIG-IQ system directly and then update the protocol inspection signatures on the managed BIG-IP AFM device. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Login to the webUI of your BIG-IQ system as the administrative user.
  2. Navigate to Configuration > SECURITY > Network Security > Protocol Security > Inspection Package Files List.
  3. Select Download. The BIG-IQ webUI displays a pop up for you to choose:
    • if you want to download the latest signature file only and install the file to a sub-group of devices later on, select Download latest files for Download Options. Then select OK to continue.
    • if you want to download the latest signature file and install it on all managed BIG-IP AFM devices immediately, select Download latest files and install on all devices for Download Options. Then select OK to continue.
  4. When the download is completed successfully, the BIG-IQ webUI lists the downloaded signature file on the Inspection Package Files List page as the file Source as F5. If you have selected Download latest files and install on all devices for Download Options, you can skip steps 5 though 9.
  5. Select the filename of the signature file you want to update the managed BIG-IP AFM device.
  6. Under Available Devices column of the Install to Devices setting, select the managed BIG-IP AFM device you want to update and move it to Selected Devices column by selecting ->.
  7. Select Install to initiate the update process. The BIG-IQ webUI displays a pop up for install update confirmation; select Install to proceed.
  8. To monitor the progress, navigate to Configuration > SECURITY > Network Security > Protocol Security > Inspection Update Status and select the latest update installation Start Time.
  9. When the update installation is completed successfully, the Status of the entry should display Finished.

BIG-IQ system does not have direct internet access

If your BIG-IQ system does not have direct internet access, you have to download the protocol inspection signature from MyF5 Downloads site to your local workstation, import it to the BIG-IQ system and then update the protocol inspection signatures on the managed BIG-IP AFM device. To do so, perform the following procedures:

  • Download the protocol inspection signatures to local workstation
  • Manually import and update the protocol inspection signatures

Download the protocol inspection signatures to local workstation

To download the protocol inspection signatures to your local workstation, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. On MyF5, go to Resources > Downloads.
  2. In Account, if you have more than one MyF5 account, select the account you want.
  3. Select the check box to agree with the End User License Agreement and Product Terms.

    Note: The check box displays only when F5 does not yet have a record of you accepting these agreements.

  4. In Group, select BIG-IP.
  5. In Product Line and Product Version, select the product and version you want.
  6. Under Select a product container, select ProtocolInspection-LatestUpdate.

    The files available for download display beneath the product container section after you select a product container.

  7. Under Select a download file, select a file with the filename format pi_updates_<BIG-IP version>-<YYYYMMDD>.<build number>.im that you want to download.

    You can download only one file at a time.

  8. At the bottom of the page, in Download locations, select the location nearest you.
  9. Select Download.
  10. After the system finishes downloading the first file you selected, return to the Select a download file section, and then select the MD5 file for the signature file you downloaded in the previous steps. The MD5 file should have the filename format pi_updates_<BIG-IP version>-<YYYYMMDD>.<build number>.im.md5.
  11. Repeat steps 8 through 9 to download the MD5 file.
  12. After you have downloaded the necessary files, F5 recommends that you perform MD5 checksum verification on the signature file you have downloaded. For instructions on how to perform the MD5 checksum verification, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.

Manually import and update the protocol inspection signatures

To manually import and update the protocol inspection signatures on the managed BIG-IP AFM device using the BIG-IQ system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Login to the webUI of your BIG-IQ system as the administrative user.
  2. Navigate to Configuration > SECURITY > Network Security > Protocol Security > Inspection Package Files List.
  3. Select Import; the BIG-IQ webUI displays a pop up for you to locate the signature file you have downloaded to your local workstation from the previous procedure.
  4. Select Choose File..., locate and select the downloaded signature file from your local workstation and then select Open.
  5. Select Import to upload the signature file to the BIG-IQ system. Once the upload is completed successfully, the BIG-IQ webUI lists the uploaded signature file on the Inspection Package Files List page with the file Source as Import.
  6. Select the filename of the signature file you want to update the managed BIG-IP AFM device.
  7. Under Available Devices column of the Install to Devices setting, select the managed BIG-IP AFM device you want to update and move it to Selected Devices column by selecting ->.
  8. Select Install to initiate the update process. The BIG-IQ webUI displays a pop up for install update confirmation; select Install to proceed.
  9. To monitor the progress, navigate to Configuration > SECURITY > Network Security > Protocol Security > Inspection Update Status and select the latest update installation Start Time.
  10. When the update installation is completed successfully, the Status of the entry should display Finished.
