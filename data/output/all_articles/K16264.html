Known Issue

BIG-IP APM Secure Web Gateway (SWG) appends a slash (/) to URLs when a custom URL category with Prefix Match selected is created using the Configuration utility. This situation can result in no matches for the associated URLs that are configured in the custom URL category.

For example, if you want to match all URLs beginning with http://example-site-, you can enable Prefix Match and add the associated URL http://example-site- to a custom URL category. However, the BIG-IP APM SWG system appends a trailing slash (/) when saving the associated URL in the configuration:

sys url-db url-category /Common/custom_url {
cat-number 1905
display-name custom_url
is-custom true
urls {
http://example-site-/ { <----
type prefix-match
}
}
}

Impact

The BIG-IP APM SWG system is unable to properly match associated URLs, which impairs URL filter enforcement.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the custom URL category in either the Configuration utility or the /config/bigip.conf file, you see a trailing slash appended to associated URLs.
  • URLs configured in custom URL categories are not enforced properly by SWG.

Workaround

To work around this issue, you can manually edit the /config/bigip.conf file and remove the trailing slash (/), or use the Traffic Management Shell (tmsh) to create/add the url-db category URLs. To do so, perform the following procedure:

Impact of workaround: Traffic may be temporarily disrupted while the edited configuration loads.

Using the previous example, remove the trailing slash (/) from the URL:

sys url-db url-category /Common/custom_url {
cat-number 1905
display-name custom_url
is-custom true
urls {
http://example-site- { <----
type prefix-match
}
}
}

  1. Log in to the command line of the BIG-IP APM SWG system.
  2. Change to the /config directory by typing the following command:

    cd /config

  3. Create a backup copy of the bigip.conf file by typing the following command:

    cp bigip.conf bigip.conf.sol16264

  4. Using a text editor, such as vi or pico, open the bigip.conf file for editing.
  5. Locate the stanza with the custom URL category configuration and delete the trailing slash (/) from any affected URLs.
  6. Save the changes and exit the text editor.
  7. Reload the configuration using the tmsh utility by typing the following command:

    tmsh load /sys config
