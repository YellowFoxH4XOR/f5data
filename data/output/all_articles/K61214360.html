Description
An attempt to install an EPSEC image using TMOS Shell (tmos) fails with the following error:

Data Input Error: 01070734:3: Configuration error: Invalid mcpd context, folder not found (/Common/EPSEC/Images)

Environment

  • BIG-IP 14.1.x or greater
  • You attempt to install the EPSEC image using TMOS Shell (tmos)
  • You may encounter this message in the following locations:
    • The /var/log/ltm file
    • Output reported from running a TMOS Shell (tmsh) install /apm epsec epsec-package <EPSEC-IMAGE> command

      For Example:

      (Active)(/Common)(tmos)# install /apm epsec epsec-package epsec-1.0.0-840.0.iso
      Data Input Error: 01070734:3: Configuration error: Invalid mcpd context, folder not found (/Common/EPSEC/Images)

Cause
Bug ID 739570

Recommended Actions

When the system generates this error message, consider performing the following actions:

  • Install EPSEC image via the Web Configuration Utility (TMUI)
  • Create a folder via tmsh
Install EPSEC image via the Web Configuration Utility (TMUI)

See Using the Configuration utility to install an EPSEC update section of K48955220 for details.

Create a folder via tmsh

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP system
  2. Create sys folder Images

    (tmos)# create sys folder Images

  3. Install the EPSEC Image.

    For Example:

    (Active)(/Common)(tmos)# install /apm epsec epsec-package epsec-1.0.0-840.0.iso
