K05302537: Caught runtime exception, Cannot get device index for tmm in rd<#> - create socket failed: No such file or directory

Published
2022-12-27
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K05302537

Description

Configuration load using "tmsh load sys config" or LTM log during device reboot show below errors:

01070711:3: Caught runtime exception, 'Cannot get device index for tmm in rd<#> - create socket failed: No such file or directory' - rolling back...
01070712:3: Caught configuration exception (0), Cannot get device index for tmm in rd<#> - create socket failed: No such file or directory.

Note : Route domain 3 will be rd3 in this error 

Environment

  • BIG-IP LTM

Cause


This issue is caused after you remove route domain configuration however forget to remove a static route associated with it as below :

For example , static route for route domain 3 would look like below in /config/bigip.conf :
net route /Common/static_rd3 {
    gw 10.10.10.1
    mtu 1500
    network 10.0.0.0%3/8
}

Recommended Actions

Follow below steps to fix this issue:

  1. Take a UCS backup of your device and download to your local system - K13132
  2. Edit the /config/bigip.conf file to remove the static route configuration.
  3. Load the configuration using "tmsh load sys config" using command line bash.
