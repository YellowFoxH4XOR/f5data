Description

Guide to creating a bootable USB Flash Drive using the UNetbootin utility (Windows, Mac, Linux) for a clean installation of BIG-IP

Environment

The UNetbootin software can be used under Windows, Mac, or Linux

Cause

None

Recommended Actions

1.  Download the UNetbootin utility for Windows, Mac or Linux at https://unetbootin.github.io

2.  Download the .iso file for the version of BIG-IP you wish to use for a clean installation at https://downloads.f5.com.  For example for BIG-IP version 13.1.3 you would download the file BIGIP-13.1.3-0.0.6.iso

3.  Run the UNetbootin utility and choose the option "Diskimage" (not Distribution).  Browse to the .iso file you downloaded in step 2

4.  Choose Type USB Drive and select the appropriate drive letter and click the OK button

5.  This will generate a bootable USB Flash Drive that you can then use to perform a clean installation

Additional Information

Note: The UNetbootin utility is a 3rd party software that is officially unsupported by F5
