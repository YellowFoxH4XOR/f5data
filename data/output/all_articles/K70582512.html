Issue

Error Message

notice chmand[<PID>]: 012a0019:5: Chassis power module <PSU> is on.

In this error message, note the following:

  • <PID> is the chmand process ID number.
  • <PSU> is the power module number.

For example:

notice chmand[12345]: 012a0019:5: Chassis power module 2 is on.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • A power supply unit is active with sufficient input power.

Impact

None.  This message is purely informational and shows that the power supply is active.

Recommended Actions

None
