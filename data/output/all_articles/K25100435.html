Description

Sometimes it's necessary to confirm the contents of a BIG-IP or BIG-IQ release ISO without installing or even mounting the ISO file itself.

This may be necessary if permissions are not available to mount the ISO as a filesystem, and it's also a good practice to avoid the kernel overhead of the mount itself if only accessing a few files is desired, or in the case where several ISO files need to be inspected in sequence.

The most useful for tool quickly checking a contents is isoinfo, which will scan and print the filenames present on a given ISO file to the output.

The three major flags for this operation are:

  -f  which will show the list of files and directories, each entry on a new line, with the directory name prepended
  -J  which will make sure the Joliet information to store long filenames with accented, and lowercase characters, otherwise the output will show only DOS compatible filenames, with an additional version number appended.
  -R  which will make sure the Rock-Ridge information to store long filenames, which is roughly the same as -J but some (non-BIGIP) ISO images may contain only one of these extensions.
  -i IMAGE must be used to specify which ISO IMAGE file to operate on.

Environment

  • BIG-IP or BIG-IQ ISO

Cause
None

Recommended Actions

  • Listing ISO Image Contents
  • Extracting Files From ISO Images
  • Extracting Several Files

Listing ISO Image Contents

  • For example, to confirm which bash package version BIG-IP 14.1.0.2 contains, we can use the following line:

    isoinfo -f -J -i BIGIP-14.1.0.2-0.0.4.iso|grep bash

    /BIGIP14102/x86_64/bash-4.2.46-29.el7_4.f5.0.0.4.x86_64.rpm

  • In contrast, without the -J option, the file names are truncated, and in an arcane format of the original ISO9660 standard:

    isoinfo -f -i BIGIP-14.1.0.2-0.0.4.iso|grep -i bash

    /BIGIP141/X86_64/BASH_4_2.RPM;1

Extracting Files From ISO Images

It is also possible to extract specific files.

  • If we know the file name, for example checked with the above listed methods, we can extract it to the standard output.
    Note: That we still need the same -J and -i options to parse the correct image with the desired file name format.

    isoinfo  -J -i BIGIP-14.1.0.2-0.0.4.iso -x '/BIGIP14102/x86_64/bash-4.2.46-29.el7_4.f5.0.0.4.x86_64.rpm'|xxd|head -3

    0000000: edab eedb 0300 0000 0001 6261 7368 2d34  ..........bash-4
    0000010: 2e32 2e34 362d 3239 2e65 6c37 5f34 2e66  .2.46-29.el7_4.f
    0000020: 352e 302e 302e 3400 0000 0000 0000 0000  5.0.0.4.........

  • Optionally, the contents can be saved to a file:

    isoinfo -J -i BIGIP-14.1.0.2-0.0.4.iso -x '/BIGIP14102/x86_64/bash-4.2.46-29.el7_4.f5.0.0.4.x86_64.rpm' >bash.rpm

    file bash.rpm

    bash.rpm: RPM v3.0 bin i386/x86_64

Extracting Several Files

isoinfo is not very flexible with regards to multiple files, or filename patterns.

The 7z compression tool which is typically installed on Linux systems (but not on BIGIPs) can be used to test more files:

  • The subcommand can also be used to List the files, T is for Testing, which is not much different in this case, as no compression is involved.

    7z l BIGIP-14.1.0.2-0.0.4.iso|grep -i bash

    2019-02-15 05:07:35 .....       638004       638004  BIGIP14102/x86_64/bash-4.2.46-29.el7_4.f5.0.0.4.x86_64.rpm

    7z t BIGIP-14.1.0.2-0.0.4.iso|grep -i bash

    Testing     BIGIP14102/x86_64/bash-4.2.46-29.el7_4.f5.0.0.4.x86_64.rpm

  • We can also use patterns to select files, but the default output is much more verbose.  Note also the use of a new option, -r to recurse directories, allowing to enter directories to look for matching file names

    7z l BIGIP-14.1.0.2-0.0.4.iso -r '*bash*'

    7z x BIGIP-14.1.0.2-0.0.4.iso -r '*libssh2*'

    7-Zip [64] 9.20  Copyright (c) 1999-2010 Igor Pavlov  2010-11-18
    p7zip Version 9.20 (locale=en_US.UTF-8,Utf16=on,HugeFiles=on,32 CPUs)

  • Both of the files are created in the same hierarchy as they were present on the ISO image

    find BIGIP14102/ -type f

    BIGIP14102/i686/libssh2-1.4.3-10.el7.centos.1.i686.rpm
    BIGIP14102/x86_64/libssh2-1.4.3-10.el7.centos.1.x86_64.rpm
