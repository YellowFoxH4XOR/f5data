Known Issue

Changing the BIG-IP system hostname may cause the system to go offline.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is a standalone VIPRION chassis.
  • Your chassis is populated with multiple blades.
  • You use the Configuration utility to modify the system hostname.

Impact

Non-primary chassis blades momentarily report an offline state.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Virtual Clustered Multiprocessing (vCMP) guests experience unexpected failovers and traffic interruption.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to modify the system hostname. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To modify the system hostname, use the following command syntax:

    modify /sys global-settings hostname <new hostname>

  3. To exit the tmsh utility, type the following command:

    quit
