K09481301: Modifying cli preference display-threshold changes the sync status to Changes Pending

Description

Modifying cli preference display-threshold changes the sync status to Changes Pending

Environment

In order to view more results from the command line, modify the cli preference display-threshold value. Changing this value to 0 allows all results to print to screen.The default value is 100.

  • Adjust the setting for cli preference display-threshold
    tmsh modify cli preference display-threshold <#>
    where <#> equals a number different from its current value. 
     
  • Sync status of the device switches to "changes pending"
    [root@bigip:Standby:In Sync] config # tmsh modify cli preference display-threshold 0
    [root@bigip:Standby:In Sync] config #
    [root@bigip:Standby:Changes Pending] config # tmsh modify cli preference display-threshold 100
    [root@bigip:Standby:Changes Pending] config #
     
  • The default value is 100
    tmsh list cli preference display-threshold
    cli preference {
        display-threshold 100
    }

Cause

Adjusting this value changes the status of the device to "changes pending". This setting is not saved unless tmsh save sys config is run afterwards. The audit logs show similar messages as listed below.

/var/log/audit
notice mcpd[5415]: 01070417:5: AUDIT - client tmsh, tmsh-pid-10264, user root - transaction #3699831-1 - object 0 - create_if { cli_preference { cli_preference_user_name "root" cli_preference_display_threshold 100 } } [Status=Command OK]
notice tmsh[10264]: 01420002:5: AUDIT - pid=10264 user=root folder=/Common module=(tmos)# status=[Command OK] cmd_data=modify cli preference display-threshold 100

Recommended Actions

After the maintenance is complete, sync the devices so the appropriate device's configuration is copied to its peer.
