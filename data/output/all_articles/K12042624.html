Topic

This article applies to BIG-IP 13.x through 16.x. For information about earlier versions, refer to the following articles:

  • K13981: Restricting access to the Configuration utility using client certificates (11.x - 12.x)
  • K7453: Restricting access to the Configuration utility using client certificates (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You require client certificate authentication for access to the Configuration utility.

Description

You can configure the Configuration utility to use client certificate authentication for verifying a client's access by including the Certificate Authority (CA) certificate that signed the client certificates and include the following parameters in the configuration:

  • SSLCACertificateFile
  • SSLVerifyClient
  • SSLVerifyDepth

The parameters are available as the following TMOS Shell (tmsh) commands in the sys httpd component:

Parametertmsh command
SSLCACertificateFiletmsh list /sys httpd ssl-ca-cert-file
SSLVerifyClienttmsh list /sys httpd ssl-verify-client
SSLVerifyDepthtmsh list /sys httpd ssl-verify-depth

If you require the client certificate authentication to use a Certificate Revocation List (CRL), you must include the SSLCARevocationFile parameter in the httpd configuration by using the Configuring the Configuration utility to use a CRL procedure.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have the CA certificate that signed the client certificates for authentication in PEM-encoded format.
  • Optional: You have the CRL file in PEM-encoded format.
  • You have CLI, tmsh, and Configuration utility access.
  • You are familiar with the vi editor.

Procedures

  • Uploading the CA certificate to the BIG-IP system
  • Configuring the Configuration utility to use client certificate authentication
  • Optional: Configuring the Configuration utility to use a CRL

Uploading the CA certificate to the BIG-IP system

Before configuring the Configuration utility, you must upload the CA certificate to the BIG-IP system. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System> Certificate Management > Device Certificate Management > Device CA Certificate List.

    Note: For BIG-IP 13.1.0 and earlier, navigate to System > Device Certificate Management > Device CA Certificate List.

  3. Click Import.
  4. Click Choose File and navigate to the CA certificate file location on your local system. Alternatively, enter the full path to the CA certificate file.
  5. In the Name box, enter a name for the CA certificate.
  6. To upload the CA certificate, click Import.

Configuring the Configuration utility to use client certificate authentication

After you have uploaded the CA certificate to the BIG-IP system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Configure the client certificate authentication by typing the following command:

    modify /sys httpd ssl-ca-cert-file <path/to/cert> ssl-verify-client require ssl-verify-depth <cert depth>

    For example, type the following command to configure client certificate authentication using the /Common/ClientCertCA CA certificate with the certificate depth at 20:

    modify /sys httpd ssl-ca-cert-file /Common/ClientCertCA ssl-verify-client require ssl-verify-depth 20

  3. Save the configuration to the configuration files by typing the following command:

    save /sys config

Optional: Configuring the Configuration utility to use a CRL

If you require the Configuration utility to use a CRL, you must upload the CRL file to the /config/httpd/conf/ssl.crl directory on the BIG-IP system before modifying the httpd configuration. To do so, perform the following procedure:

Impact of procedure: Ensure that you enter the syntax correctly; failing to do so may result in failure to access the Configuration utility.

  1. Upload the CRL file to the /config/httpd/conf/ssl.crl directory on the BIG-IP system by performing the procedure that is appropriate for your environment as described in K175: Transferring files to or from an F5 system.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. Edit the httpd configuration by typing the following command:

    edit /sys httpd

    Note: This command launches a vi editor within tmsh.

  4. Append the following line within the httpd configuration stanza:

    include "SSLCARevocationFile /config/httpd/conf/ssl.crl/<CRL file>"

    Note: If you have existing include statements for the httpd configuration, you must append these after the existing include statements.

    Using the example from the previous procedure, if the CRL file name is ca-crl.pem, the httpd configuration stanza appears similar to the following example:

    sys httpd {
    include "SSLCACertificateFile /config/httpd/conf/ssl.crt/ca-cert.pem
    SSLVerifyClient require
    SSLVerifyDepth 20
    SSLCARevocationFile /config/httpd/conf/ssl.crl/ca-crl.pem"
    }

  5. Save the configuration to memory by exiting the vi editor. To do so, type the following command:

    :wq!

  6. When the vi editor prompts you to save the changes, type y to confirm.

    The httpd process reloads with the new configuration.

  7. Save the configuration to the configuration files by typing the following command:

    save /sys config
