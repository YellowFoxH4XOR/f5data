K000140372: Can not downgrade and delete ampclients-7246 after upgraded to 17.1.1.3, 16.1.4.3, 15.1.10.4 and later,

Type
Support Solution
Published
2024-07-18
Updated
2024-07-18
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM: 17.1.1, 15.1.10, 16.1.4
  • F5 Access
Source
https://my.f5.com/manage/s/article/K000140372

Description

Upgraded to 17.1.1.3, 16.1.4.3, 15.1.10.4 and later (including EngHF).

Apm client;s system default is v7246, and installed older version, however we can not set APM client to older version for default and also can not delete v7246.

 

Environment

  • BIG-IP APM
  • APM client/Edge Client
  • Upgraded to 17.1.1.3, 16.1.4.3, 15.1.10.4 and later (including EngHF).

 

Cause

  • By design.

Due to vulnerability fix, 17.1.1.3, 16.1.4.3, 15.1.10.4 and later (including EngHF) later does not support older APM client.

 

Recommended Actions

If you have any client which should not upgrade (especially old OS), set the connectivity profile's Win/Mac Edge Client 's Component Update = No

 

Additional Information

  • K000138683: Users cannot connect to BIG-IP APM virtual servers "The VPN connection has failed because it attempted to connect to an insecure network" with BIG-IP Edge Client 7246/7247
