Known Issue

This is the result of a known issue. If a load balancing mode does not provide a virtual server to return to the client, it will not work, even if the load balancing mode is designed not to return a response.

If the Explicit IP, Return to DNS, None, or Drop Packet load balancing modes are configured with an alternative or fallback load balancing method that can return a virtual server, BIG-IP will use that method instead.

F5 Networks Product Development tracked this issue as CR38163 and CR41855.

Workaround

To work around this issue when you want to use a specific load balancing method, such as Explicit IP, Return to DNS, None, or Drop Packet, configure all of the load balancing methods (preferred, alternate, and fallback) to use the specific load balancing mode. In doing this, 3-DNS will have to use the load balancing method that you configure.
