Description
 

Overview
Elasticsearch is a search engine technology based on the Lucene library.  It is a distributed, multi-tenant architecture. It runs full-text search engine with an HTTP web interface and JSON documents. It is being used by BIG-IQ CM to collect multiple types of data from managed BIG-IP devices including indices, event logs and statistical information.

Advantages

  • It provides real-time search engine for indexed information.
  • It uses distributed architecture to form a cluster with multiple devices.
  • It provides scalability and flexibility to integrate with other technologies.
  • It is based in a REST API with JSON formatted data, giving users the flexibility to use broad range of programming languages.
  • Able to create full backup of indexed information.


Elasticsearch Terms

Node

  • A single server or device that forms a cluster. BIG-IQ CM and DCDs are used as nodes forming a cluster.
  • It stores data of cluster's search index.


Cluster

  • A collection of one or multiple nodes that hold data of a cluster.
  • Provides indexing and search capabilities across all nodes.

Environment

  • BIG-IQ CM (with Statistics Collection enabled)
  • BIG-IQ DCD
  • BIG-IPs (sending statistics to the BIG-IQ cluster)

Cause
None

     

    Recommended Actions

    When an administrator is not able to view some data within an Elasticsearch cluster, we suggest to review the following files to assess the condition of Elasticsearch.

    1. /var/log/elasticsearch/eslognode.log
      Stores service logs of Elasticsearch, including error and warning messages.
       
    2. /var/tmp/bigiqdiags/bigiq_diagnostics.txt 
      Stores status information. Please refer to K25649710: How to confirm health of Elasticsearch of BIG-IQ.
