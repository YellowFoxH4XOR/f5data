K000149461: MFA Azure integration - Signature element of SAML response is invalid

Type
Support Solution
Published
2025-07-15
Updated
2025-07-15
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149461

Description

You are implementing MFA Azure and policy results denying the access for the user.  You can see the following error in apm logs:

Error_Message=Signature element of SAML response is invalid

Environment

  • BIG-IP APM
  • SAML authentication using Azure AD/ADFS as Identity Provider (IdP)
  • SAML SP and IdP connectors configured on BIG-IP
  • Azure MFA enabled

Cause

The certificate used by the IdP to sign the SAML assertion does not match the certificate configured in the BIG-IP SAML IdP connector. This occurs when different private key/certificate pairs are used for signing assertions versus those exported in metadata and imported into BIG-IP, resulting in signature validation failure by APM.

Recommended Actions

  1. Verify Certificate Consistency:

    • Confirm that the certificate used by your IdP to sign SAML assertions matches exactly with what is configured in your BIG-IP SAML IdP connector.
    • Decode and inspect the certificate embedded within an actual SAML assertion response and compare it against the certificate imported into BIG-IP.

  2. Update or Re-import Metadata:

    • Export fresh metadata from your IdP, ensuring it contains the correct signing certificate currently being used.
    • Import this updated metadata into BIG-IP to create or update your SAML IdP connector.
    • Attach this updated IdP connector object to your relevant SP service configuration on BIG-IP.
