Description

When trying to create new Allowed URL in ASM policy, Create button is not working. Additionally, configuration view remains in Advanced even after switching to Basic.
 


Other web browsers are working correctly.

Environment

  • Creating Allowed URL in ASM policy

Cause

Old and unsupported web browsers may not display Configuration Utility correctly and cause some of the GUI function work properly.

List of supported web browser is available in Software Release Notes New and Installation in BIG-IP Knowledge Center.

Example for software v15.1.x:

https://techdocs.f5.com/kb/en-us/products/big-ip_ltm/releasenotes/product/relnote-bigip-15-1-0.html#rn_browser_support

The BIG-IP Configuration Utility supports these browsers and versions:

    Microsoft Internet Explorer 11.x, or later
    Mozilla Firefox v62.0, or later
    Google Chrome v69.0.3497, or later

Recommended Actions

In order for Configuration Utility (GUI) to work properly, please use supported web browser specified in Software Release Notes.
