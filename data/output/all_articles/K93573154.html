K93573154: Can't delete user Error writing '/etc/passwd.lock': No space left on device

Type
Support Solution
Published
2021-06-08
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K93573154

Description

Unable to delete the local user on BIGIP. We get the following error message :

Can't delete user (Error writing '/etc/passwd.lock'): No space left on device
 

Environment

  • BIGIP
  • Unable to delete local user. System  ››  Users : User List
  • Error message "Can't delete user (Error writing '/etc/passwd.lock.'): No space left on device"

Cause

/ directory is utilizing high space on the BIGIP system(100 percent).
 

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Login to the BIGIP command line 
    ssh@bigip
     
  2. example
    #find / -xdev -type f -exec du {} \; | sort -rn | head -20

    For example:

    [root@LB:Active:Changes Pending] config # find / -xdev -type f -exec du {} \; | sort -rn | head -20

  3. Verify the file using the highest space, Back it up and delete it if it's not useful.
