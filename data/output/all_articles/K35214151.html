Description

How to reboot the BIG-IQ system

Environment

  • BIG-IQ
  • GUI
  • SSH or console access

Cause

None

Recommended Actions

Impact of procedure: This procedure involves restarting the BIG-IQ system, thus F5 recommends that you perform this procedure during a maintenance window.

Use this procedure to reboot the BIG-IQ system using the GUI.

  1. Log in to the BIG-IQ system UI with the administrator user name and password.
  2. Select the System tab.
  3. Expand THIS DEVICE.
  4. Select General Properties.
  5. Select Edit.
  6. Under Localhost Volumes, use the Boot Locations list to select the (Active and default boot location) boot image.
  7. Select the Reboot button. 

Use this procedure to reboot the BIG-IQ system using the command line.

  1. Log in to the BIG-IQ command line (bash).
  2. To restart the BIG-IQ system, enter the following command:
    reboot
