Topic

iRules LX is a feature that allows BIG-IP administrators to extend the capabilities of iRules with JavaScript in the Node.js runtime environment. This article describes the behavior of device group synchronization for iRules LX configuration objects.

Description

The iRules LX feature consists of two configuration objects, LX Workspaces and LX Plugins. The LX Workspace configuration object is a development and staging environment for creating and editing the iRules you want to use with the Node.js and for creating and editing the Node.js code known as an Extension. To implement your code, you load a copy of the content from the LX Workspace into an LX Plugin. During runtime, the iRule calls the LX Plugin, to use the iRules LX capabilities for traffic processing.

To prevent code in an LX Workspace from being overwritten during development, this object is not synchronized between device group members. Also, note that the code in an LX Workspace does not affect traffic processing on the BIG-IP system.

LX Plugins are synchronized to all device group members. To edit an LX Plugin within a device group you must access the device where the associated LX Workspace resides, make your changes, reload the updated code to the LX Plugin, and then synchronize the LX Plugin to the device group.
