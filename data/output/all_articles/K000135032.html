K000135032: On an rSeries platform, system/log/platform.log shows entries mentioning "rasdaemon:mc:uncorrected:event"

Type
Support Solution
Published
2023-06-14
Updated
2024-02-02
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000135032

Description

On an rSeries appliance, entries such as the below are seen in /var/F5/system/log/platform.log :

[date/time] [hostname] diag-agent[8]: priority="Err" msg="Component Attribute Changed" component="appliance/hardware/memory" attribute="rasdaemon:mc:uncorrected:event" severity="Error" value="0x00000001" interface="diag-controller"

 

Environment

BIG-IP rSeries appliance

 

Cause

This message is telling us that rasdaemon detected a one-off hardware memory error which was uncorrectable by the ECC memory's normal operation.

  • rasdaemon records/monitors for memory errors which were detected by the EDAC Linux kernel subsystem, which looks at reports of ECC errors from hardware memory controllers.
  • mc means "machine check", which basically refers to a hardware check. 
  • uncorrected:event refers to an uncorrectable memory error (ie. a memory error which was not automatically correctable using the ECC feature of the Big-IP's installed memory, detected by using parity bits as per ECC normal operation).

 

Recommended Actions

If this message only occurred once then it can be ignored safely, but if it occurs repeatedly (eg. more than once a week) then a case should be raised with F5 Support and the F5 Support engineer should determine whether the message is is due to any known bugs at the time, or if the unit should be RMA'd due to failing memory module(s).

 

Additional Information

rasdaemon is described here: https://github.com/mchehab/rasdaemon

"Rasdaemon is a RAS (Reliability, Availability and Serviceability) logging tool. It records memory errors, using the EDAC tracing events. EDAC is a Linux kernel subsystem with handles detection of ECC errors from memory controllers for most chipsets on i386 and x86_64 architectures. EDAC drivers for other architectures like arm also exists."
