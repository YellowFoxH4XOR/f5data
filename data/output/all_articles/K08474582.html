Description

When you attempt to activate an add-on license using CLI or GUI to a trial license you may get the following error:

The 51113 Error code: Non-Eval Add-on trying to be licensed on an Eval Base License


Time-limited keys incompatibility A non-time-limited Add-on module (YYYYY-YYYYYYY) cannot be used on a time-limited license (XXXXX-XXXXX-XXXXX-XXXXX-XXXXXXX)

Environment

  • Licensing.
  • Trial/Evaluation License.
  • CLI
  • Webgui

Cause

The device is running with Eval license, evaluation or demonstration BIG-IP licenses do expire. This applies to add-on module evaluation licenses for all modules.
 

Recommended Actions

  You are trying to activate a production Add-on module onto an Eval base registration key,  Please change the Eval base registration key with a Production base registration key.
