Description

When you enable "Request Queueing", BIG-IP will queue the connection by the connection limit.
And there are two "Request Queue" stats, "Pool level" and "PoolMember level";

For example, 
  GUI : Statistics >> Module Statistics >> Local Traffic >> Pools
        then you can see "Request Queue" stats of Pool and Pool Members

  CLI : tmsh shw ltm pool <name_of_pool> members
        SNMP traps;
          For Pool : ltmPoolStatConnqXXXXX (Ex. ltmPoolStatConnqAgeHead, etc)
          For Pool Member : ltmPoolMemberStatConnqXXXXX (Ex. ltmPoolMemberStatConnqDepth, etc)

However without the persistence profile, BIG-IP won't display the Pool Member level stats, but only displays Pool level stats.

Environment

  • BIG-IP LTM
  • Enable "Request Queueing"

Cause

It is by design.

Recommended Actions

To display queued stats of Pool Member level, you need to add the persistence profile to Virtual Servers.
If you would like to see the Pool level stats only, you don't have to add persistence profile.

Additional Information

None.
