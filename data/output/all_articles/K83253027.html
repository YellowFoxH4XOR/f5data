Topic

This article discusses the Digital Diagnostic Monitoring (DDM) feature on a BIG-IP hardware product. For information about DDM on the F5 VELOS and rSeries systems, refer to K29709501: Overview of the F5 VELOS and rSeries Digital Diagnostic Monitoring feature.

Description

The DDM feature allows you to check in real time different aspects of an optical connection, such as optical output power, optical input power, and transceiver supply voltage. This feature is implemented with reference to an industry standard known as SFF-8472 that provides the specifications for Diagnostic Monitoring Interface for Optical Transceivers. DDM is available in a number of optics and requires a combination of software and hardware to operate. The hardware (microcontroller) inside the transceiver performs the monitoring and reporting of the operating and diagnostic information, which you can access using a two-wire serial bus known as I2C.

Note: The 2000s/2200s and 4000s/4200v series platforms do not support the DDM feature.

Enabling and disabling the DDM feature

The DDM feature is not enabled by default. To enable the DDM feature, type the following command:

tmsh modify sys db ddm.bcm56xxd.enable value enable

To disable the DDM feature, type the following command:

tmsh modify sys db ddm.bcm56xxd.enable value disable

Viewing the DDM output

After you have enabled the DDM feature, you can view the DDM output for an interface using the following command syntax:

tmsh show net interface-ddm <interface>

For example, to view the DDM output for interface 4/1.1, type the following command:

tmsh show net interface-ddm 4/1.1

Supported optical transceivers with DDM

For a list of F5 branded optical transceivers with DDM that are supported on the BIG-IP platforms, refer to K6097: Specifications of the Fiber Gigabit Ethernet SFP, XFP, SFP+, QSFP+, and QSFP28 module ports on BIG-IP system platforms.

Recommendations

F5 recommends that you use the DDM feature when troubleshooting all optics instead of fiber attenuators. Attenuators may be difficult to use, and if used improperly, they may overpower and damage optic receivers.
