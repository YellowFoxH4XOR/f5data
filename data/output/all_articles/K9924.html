Topic

The BIG-IP ASM Reporting screen allows you to track a user's session based on either the cookie session ID or the parameter session ID. Since the value of a cookie session ID or parameter session ID does not typically change from request to request, it is possible to track a user's activity as they browse the web application protected by the BIG-IP ASM system.

For example, the following HTTP POST request contains a username and jsessionid cookie, both of which you can track using the BIG-IP ASM Reporting page:

POST /login.jsp HTTP/1.1
Accept: image/gif, image/x-xbitmap, image/jpeg
application/vnd.ms-excel, */*
Accept-Language: en-us
Accept-Encoding: gzip, deflate
User-Agent: Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1; SV1)
Host: www.example.com:80
Connection: Keep-Alive
Cookie: pref=style1; jsessionid=12345

user=john&pass=1234

Tracking a user's session using the BIG-IP ASM Reporting page

BIG-IP ASM 10.x

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Web Applications.
  4. On the Main tab of the Application Security page, click Reporting.
  5. Click the Show Filter arrow.
  6. In the Web Applications filter section, click the web application from the drop-down menu for which you will perform the search.
  7. In the Containing String filter section, select Request from the drop-down menu and enter the user's session ID value in the text field.

    For example, in reference to the example HTTP POST request, you could enter the following values:

    user=john
    jsessionid=12345

  8. To perform the search, Go.

BIG-IP ASM 9.4.x

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Web Applications.
  4. On the Main tab of the Application Security page, click Reporting.
  5. Click the Show Filter arrow.
  6. In the Web Applications filter section, click the Only button and select the web application from the drop-down menu for which you will perform the search.
  7. In the Containing String filter section, click the Search In button and enter the user's session ID value in the text field.

    For example, in reference to the example HTTP POST request, you could enter the following values:

    user=john
    jsessionid=12345

  8. To perform the search, Go.
