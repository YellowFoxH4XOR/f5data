K27312387: Modifying the default management sshd and httpd ports for the BIG-IP system hosted on Microsoft Azure

Applies to

Topic

You should consider using this procedure under the following condition:

  • You want to create virtual servers listening on the ports that are in use by the httpd (443) and sshd (22) daemons on a Microsoft Azure instance.

Description

By default, BIG-IP Virtual Edition (VE) deployed on Windows Azure supports only one interface that is assigned with a single IP address using Dynamic Host Configuration Protocol (DHCP). The BIG-IP management port uses port 443 and 22 for the httpd and sshd daemons, respectively. If you need to create virtual servers listening on port 443 or 22 for your application, you must move the default port to an unused port to avoid port conflicts. In addition, you may also need to change your IP security settings within Azure to permit access to the new user interface ports. For more information, refer to your Azure documentation.

To view the current default port setting for httpd or sshd, type one of the following commands:

  • httpd

    tmsh list sys httpd ssl-port

    The command output appears similar to the following example:

    sys httpd {
    ssl-port 443
    }

  • sshd

    tmsh list sys sshd port

    The command output appears similar to the following example:

    sys sshd {
    port 22
    }

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have deployed BIG-IP VE on Azure.
  • You have administrative access to the TMOS Shell (tmsh).

Procedures

  • Modifying httpd default port 443
  • Modifying sshd default port 22

Modifying httpd default port 443

To move default port 443 to a different port, perform the following procedure:

Note: Beginning in BIG-IP 13.0.0, the management interface uses port 8443 for the httpd daemon by default.

Impact of procedure: Management traffic using port 443 is interrupted while you move port 443 to an unused port.

  1. Log in to BIG-IP VE using secure shell (SSH).
  2. To move the default httpd port to a different port, use the following command syntax:

    tmsh modify sys httpd ssl-port <PortNumber>

    For example, to move port 443 to port 8443, type the following command:

    tmsh modify sys httpd ssl-port 8443

  3. To add your new port (8443 in this example) to the default self allow port list, use the following command syntax:

    modify net self-allow defaults add { tcp:8443 }

  4. To save the changes to the system configuration, type the following command:

    tmsh save sys config

  5. After performing the previous steps, you need to modify how you access the BIG-IP system. For example, if you moved port 443 to port 8443, you would type the following content in your browser:

    https://<ip-address>:8443

Modifying sshd default port 22

To move default port 22 to a different port, perform the following procedure:

Impact of procedure: After performing this procedure, SSH no longer works on port 22. You must restart a new session on the new port.

  1. Log in to BIG-IP VE using SSH.
  2. To move the default sshd port to a different port, use the following command syntax:

    tmsh modify sys sshd port <PortNumber>

    For example, to move port 22 to port 8422, you would type the following command:

    tmsh modify sys sshd port 8422

  3. To add your new port (8422 in this example) to the default self allow port list, use the following command syntax:

    modify net self-allow defaults add { tcp:8422 }

    The system automatically saves your changes to the configuration.
