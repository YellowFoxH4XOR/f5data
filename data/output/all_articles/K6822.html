K6822: IP multicast packets received by the BIG-IP system on a VLAN group are not copied to the BIG-IP host subsystem

Known Issue

This is the result of a known issue. IP packets with multicast destination addresses received by the BIG-IP system on a VLAN that is a member of a VLAN group are not copied to the host subsystem. This causes a failure in network communication for local daemons, such as OSPF and RIPv2, which rely on IP multicast.

F5 Networks Product Development tracked this issue as CR57268, CR57426, and CR58570 and it was fixed in BIG-IP LTM versions 9.1.2 and 9.2.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.
