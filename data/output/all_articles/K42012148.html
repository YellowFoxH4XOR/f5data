K42012148: Failed to delete BIG-IQ applications in Configuration Utility

Type
Support Solution
Published
2022-05-31
Updated
2024-02-01
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K42012148

Description


When navigating to BIG-IQ CM GUI >> Applications tab >> APPLICATIONS, and unable to delete an application.
You are attempting to remove services for a managed device and see the following error message:

"errorMsg": "Device in use by application 'example.com'"

Environment

  • BIG-IQ
  • AS3 Deployments via BIG-IQ

Cause

BIG-IQ Applications created as a result of AS3 deployments via BIG-IQ must be manually removed via CLI

Recommended Actions


Follow steps below to delete the application from BIG-IQ.
Note: This does not remove the service from BIG-IP

Replace xxxx with the application name you see in the Configuration Utility

restcurl -X POST /cm/global/tasks/force-delete -d {configSetName:xxxx}

You should see task id field as a response similar to "id": bb089076-ef10-4223-b2e3-75c0897c476b

To get the status of the task, use below command and replace with the correct id you get from aforementioned command output.

restcurl -X GET /cm/global/tasks/force-delete/bb089076-ef10-4223-b2e3-75c0897c476b

The application is deleted when the status is "FINISHED"
