Issue

Error Message

01071913:3: <code> in rule (<irule_name>) under <irule_event> event at <object> (<obj_name>) does not satisfy cmd/event/profile requirement.

In this error message, note the following:

  • <code> is a reference to the problematic code in the iRules.
  • <irule_name> is the name of the iRule being executed.
  • <irule_event> is the name of the iRules event with the problematic code.
  • <object> is the type of configuration object affected.
  • <obj_name> is the name of the affected configuration object.

For example:

01071913:3: HTTP::header command in a proc in rule (/Common/irule_example) under HTTP_REQUEST event at virtual server (/Common/vs1) does not satisfy cmd/event/profile requirement.

Note: The message code for this message in BIG-IP 11.x is 010716bc.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You associate an iRule with a virtual server.
  • The iRule references iRules procedures (procs).
  • You modify the configuration and an incompatibility is detected during iRules validation.

For example, if an iRule referencing procs is configured to return the values of certain HTTP headers based on an event, an HTTP profile needs to be associated with the virtual server. If you attempt to remove the HTTP profile and save the configuration, the missing dependency is detected during validation and this message is generated.

Impact

You cannot save the modified configuration until the requirement for the virtual server or iRule is corrected.

Recommended Actions

When this message is generated, consider the following:

  • When modifying the virtual server configuration, review the associated iRules to ensure all dependencies are being met.
  • Ensure any required profiles for the functionality you want are associated with the virtual server.
  • Review the logic and validity of the events and commands in the iRule.
