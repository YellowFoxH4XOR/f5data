Description

Here are the steps to clean BIG-IP APM PolicySync without rebooting in the case where PolicySync isn't working as expected (Sync Stuck on 'Sync Initiated')

Environment

  • BIG-IP APM with 2 or more trusted devices
  • Policy Sync is enabled and exhibiting signs of being in a "stuck" state.

Cause
None at the time of publication

Recommended Actions

  1. Edit /config/bigip.conf and delete all configuration objects that starts with “apm policy psync-*“
  2. Delete policy_sync_d directory: (bash prompt)
    1. rm –rf /config/filestore/files_d/Common_d/policy_sync_d/
  3. Save the config:
    1. tmsh save sys config partitions all
  4. Verify there's no errors before loading the configuration to memory:
    1. tmsh load sys config verify
  5. Load the config into memory:
    1. tmsh load sys config partitions all
  6. Delete all policy POLICYSYNC_ folders from tmsh:
    1. tmsh delete sys folder POLICYSYNC_policy_name_1
    2. tmsh delete sys folder POLICYSYNC_policy_name_2
    3. tmsh delete sys folder POLICYSYNC_policy_name_...
    4. tmsh delete sys folder POLICYSYNC_policy_name_n
NOTE:
If you get an error during this procedure similar to this (in this example, the apm policy name is f5-test-case):
(/Common)(tmos)# delete sys folder POLICYSYNC_f5-test-case/
010713f9:3: The folder /Common/POLICYSYNC_f5-test-case cannot be deleted because it contains configuration item (Policy Sync Status /Common/POLICYSYNC_f5-test-case/f5-test-case_psd_lab.apm.com /Common/lab.apm.com)

Run the following commands to empty the folder (this should be done on each BIG-IP APM in the trusted domain):
  1. cd into the proper folder, in the example above the policy was called f5-test-case, and delete the missing files:
  2. (/Common)(tmos)# cd POLICYSYNC_f5-test-case
  3. (/Common/POLICYSYNC_f5-test-case)(tmos)# delete apm policy psync-status all (Tab completing this command will not work so please type out the command fully or copy and paste the command)
  4. (/Common/POLICYSYNC_f5-test-case)(tmos)# delete apm policy psync-history all

Additional Information
This procedure should be run anytime after an issue with Policy Sync (such as sync stuck on Sync Initiated) or if directed by support
