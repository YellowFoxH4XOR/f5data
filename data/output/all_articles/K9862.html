Known Issue

This is the result of a known issue. When a Microsoft Windows Vista client with Sun Java JRE installed enters FirePass Protected Workspace and attempts to access Java-based FirePass services, the services may fail to load. For example, attempts to access Java-based Legacy Host sessions, Java applets delivered through FirePass Portal Access, and Java-based Terminal services will fail. This issue is known to affect Sun JRE versions 1.6.0_10, 1.6.0_11 and 1.6.0_12.

Note: FirePass 6.0.3 introduced the ability to deliver Terminal Servers and Static AppTunnels using Java in addition to ActiveX.

F5 Networks Product Development is tracking this issue as CR117731.

This issue has been fixed in cumulative HF-603-3 for FirePass version 6.0.3, and in cumulative HF-602-11 for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
