Source

Description

  • Configuration fails to load after upgrade to 15.1.x
  • You may encounter this error message in /var/log/ltm file that appears similar to the following example:

    err mcpd[mcpd_pid]: 01070734:3: Configuration error: Invalid Devicegroup Reference. The customization_group ([apm policy customization-group ) requires customization_source (/Common/standard) to be syncd to the same devices

Environment

  • Access-policy with advanced customization enabled (sometimes referred to as modern customization) in a device-group sync folder

Cause

  • You are upgrading to 15.1.x
  • Access-policy with advanced (modern) customization in sync folder

Recommended Actions

Use standard customization and not modern customization.

Additional Information

Bug tracker: Bug ID 997313: BIG-IP upgrade fails from 14.1.x to 15.1.2 when modern access profile is configured under a sync folder
