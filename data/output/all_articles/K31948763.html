K31948763: Core with notice panic: ../kern/umem.c:1611: Assertion ''sp->slab_cache == ((umem_cache_t *)(((char *)(&(ccp)[-(UINT64)(ccp)->cc_td]))

Source

Description

TMM restarts and generates a SIGFPE core file. You can find a log similar to the following in /var/log/tmm:

notice panic: ../kern/umem.c:1611: Assertion "sp->slab_cache == ((umem_cache_t *)(((char *)(&(ccp)[-(UINT64)(ccp)->cc_td])) - __builtin_offsetof(umem_cache_t, cache_cpu)))" failed.

Environment

  • APM provisioned 
  • Version 14 or 15
  • SIGFPE core file

Cause

Bug ID 879401: Memory corruption during APM SAML SSO

Recommended Actions

Open a case with F5 Support, upload qkview, core file and md5 for the core file. Engineering Services will confirm if you are hitting this bug or not and provide an EHF if necessary.

None
