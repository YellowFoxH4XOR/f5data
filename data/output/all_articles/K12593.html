Known Issue

This is the result of a known issue. Snapshot operations using RSH may experience a premature timeout. A mgmt_timeout, which should be used for snapshot operations is miscalculated. As a result, snapshot create and/or delete operations taking longer than 80 seconds to complete may fail with the following error message in the syslog file:

:FILER_MGMT_LIB-0-INFO-SNAP_REMOTE_COMMAND:: Remote command 'snap create snapjob acopia_34331_201012261700_ff2be8a8-cd0f-11dd-a7e5-4323cc1f016a' executed on filer '10.10.10.1' using 'rsh' protocol with a command timeout of 80 seconds.
:FILER_MGMT_LIB-0-DBG-MSG7:: RshConnection::sendCommand: FAIL 'Operation timed out after 80 seconds'; error: '-1', cf: 1, errno: '115'.

F5 Product Development tracked this issue as ID 39222 and it was fixed in ARX 5.2.0. For information about upgrading, refer to the ARX release notes.

Workaround

This issue only affects snapshot operations performed using RSH. Snapshot operations performed using SSH are not affected by this issue.

Note: For information about configuring a filer using SSH, refer to the management-protocol option of the filer-type command in the ARX CLI Reference Guide.
