K000150728: Error: "BrowserChallenges_<date>.im failed to upload. An update file with the same file location already exists"

Type
Support Solution
Published
2025-04-04
Updated
2026-10-20
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000150728

Description

Error updating the Browser Challenges signatures, get the error : "BrowserChallenges_<date>.im failed to upload. "

Environment

  • Update WAF signatures

Cause

Duplicated signatures

Recommended Actions

Note: Stopping the tomcat service should not affect production traffic. This is safe to run on a production system.

0)_ stop tomcat:

# bigstart stop tomcat

1)_ Backup the file "BrowserChallenges_20241121_031223.im".

Run this command in bash (delete all the signatues except genesis file):

# mkdir /shared/backup_sign && cd /var/lib/hsqldb/live-update/update-files && cp BrowserChallenges_20241121_031223.im /shared/backup_sign/ && ll /shared/backup_sign/

Example:

# mkdir /shared/backup_sign && cd /var/lib/hsqldb/live-update/update-files && cp BrowserChallenges_20241121_031223.im /shared/backup_sign/ && ll /shared/backup_sign/total 3916
-rwxr--r--. 1 root root 4009984 Apr 3 08:31 BrowserChallenges_20241121_031223.im

2)_ Delete the file "BrowserChallenges_20250211_150541.im".

# cd /var/lib/hsqldb/live-update/update-files && rm BrowserChallenges_20250211_150541.im

3)_ Start tomcat again :

# bigstart start tomcat

4)_ Download fresh Browser signature, import and re-install it again. Today, the last signature available is : BrowserChallenges_20250211_150541.im
