K000138845: IOS Device able to subvert MDM controls

Type
Support Solution
Published
2024-03-06
Updated
2024-03-06
Applies to
  • BIG-IP
  • F5 Access
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000138845

Description

Customer using F5 Access on iOS with InTune MDM. The MDM policy is being respected for per-app VPN functionality, however the F5 Access application is also allowing direct configuration of a standard VPN connection which doesn't respect the MDM restrictions in place

 

Environment

BIG-IP APM

F5 Access

iOS

Cause

Unused key value in InTune config

Recommended Actions

In the InTune control interface:

  1. Go to Apps > App Configuration Policies > “+ Add New” > Managed Devices
    Platform: iOS
    Targeted app: F5 Access (must have been previously added as an app to be selectable)
  2. Click Next
  3. Configuration settings format: Use configuration designer
Configuration KeyValue typeConfiguration Value

ManagedUserConfigurationMode

Booleantrue
ManagedUserConfigurationModeMessage_enString[message to show in banner on top of F5 Access app settings]
