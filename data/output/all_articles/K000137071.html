K000137071: BIG-IP does not forward ICMP to a pool member in a different route domain

Type
Support Solution
Published
2023-10-02
Updated
2023-10-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000137071

Description

BIG-IP does not forward ICMP to a pool member in a different route domain

Environment

  • LTM

Cause

You may need to consider disabling ICMP echo for the Virtual Server and disabling ARP requests for the Virtual Server..

 

Recommended Actions

The condition for ICMP to be forwarded to a pool member (packet forwarded to listener processing) and not being replied to by the Virtual Server is achieved by disabling ICMP echo and ARP requests for the Virtual Server.
