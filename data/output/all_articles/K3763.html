Topic

After you perform a new installation of BIG-IP software, files that exist in the /shared partition, or were linked to the /shared partition, are retained.

If you do not want to retain the files, remove all the files and links from the /shared partition before reinstalling the BIG-IP software. By default, the following directories are linked to the /shared partition.

DirectoryLink name
/var/core/shared/core
/var/log/shared/log
/var/rrd/shared/rrd.1.0
/var/ssh/shared/ssh
/var/tmp/shared/tmp


Note: Starting in BIG-IP version 9.4.0, a new log file system is introduced for BIG-IP systems containing hard drives. On systems with adequate disk space, the log file system is created during the boot process, and mounted as a loopback device to the /var/log directory. For more information, refer to K8479: Overview of the BIG-IP log file system.

Important: The /var/local/ucs file and the /config/bigip.license file are not linked to the /shared partition and will not be retained after you reboot unless you copy them to the /shared partition.
