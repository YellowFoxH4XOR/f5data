K80172339: Network map shows 'One or more profiles are inactive due to unprovisioned modules' in Profiles section

Type
Support Solution
Published
2021-10-07
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K80172339

Description

Network map shows error message: One or more profiles are inactive due to unprovisioned modules.

Environment
  • ASM

Cause

A profile is attached to a virtual server, but the module supporting the profile is not provisioned. This is a known bug as ID 879189

Recommended Actions

Provision the module that supports the profile if any.

Additional Information

If all needed modules have been provisioned, consider this as a cosmetic issue. There is no functionality impact.
