K000162637: Unable to install optics-mgr package F5OS-A 1.8.x

Type
Support Solution
Published
2026-07-29
Updated
2026-08-04
Applies to
  • F5OS Products
  • F5OS: 2.X.X, 2.0.X, 2.0.0
  • F5OS-A: 1.8.X, 1.8.4, 1.8.3, 1.8.0
Source
https://my.f5.com/manage/s/article/K000162637

Description

When installing the optics-mgr package on an F5OS-A system, you observe the following error:
Signature verification failed

Environment

  • F5OS-A 1.8.x
  • optics-mgr package

Cause

Beginning in F5OS-A 1.8.x, the optics-mgr package is installed by default.

Answer/Recommended Actions

You can check by using either one of the following commands:

docker ps | grep optics

Additional Information

None
