Description

You may find the below error log message in the Container Ingress Service container logs:

[ERROR] [VxLAN] Vxlan Manager could not list Kubernetes Pods for ARP entries: Get "https://<IP>:<Port>/api/v1/pods": dial tcp <IP>:<Port>: connect: connection refused

In this error message, note the following:

  • <IP> is the Kubernetes API Server IP, for example, 10.96.0.1
  • <Port> is the Kubernetes API Server service port, for example, 443

Environment

  • F5 Container Ingress Service(CIS, formerly known as Container Connector)

Cause

The connectivity to the Kubernetes API Server is not stable.

Recommended Actions

When the Kubernetes API Server is not stable, your F5 Ingress Container Service might not be working properly as it is required for the instance to watch changes on resources like Pods and Node addresses. If you found the error log message, you may need to check your Kubernetes cluster health status.

To verify the Kubernetes components status, you may start with:

kubectl -n kube-system get all

To verify the cluster node status, you may start with:

kubectl get node -o wide

To verify the connectivity status from your pod, please refer to Accessing the Kubernetes API from a Pod.
