Description

BGP update/withdraw might be delayed after failover

Example configuration:

router bgp 64512
 max-paths ebgp 4
 bgp bestpath as-path multipath-relax
 bgp log-neighbor-changes
 bgp graceful-restart restart-time 120
 redistribute kernel
 neighbor bgp_group1 peer-group
 neighbor bgp_group1 remote-as 64513
 neighbor bgp_group1 password 1 <passwd>
 neighbor bgp_group1 as-origination-interval 1
 neighbor bgp_group1 advertisement-interval 0

Example logs gathered during failover:

Jul 26 16:39:18 bigip.local NSM[6816]: NSM : Operational state change: 3 -> 1 ( Failover time)
Jul 26 16:39:25 bigip.local BGP[6828]: BGP : 1.1.1.1-Outgoing [ENCODE] Update NLRI: Prefix 0.0.0.0/0

Note: 7s delay between device going active and route being updated

Environment

  • BIG-IP
  • BGP
  • Failover

Cause

ID1136921

Recommended Actions

Upgrade to fixed version if available or request EHF
