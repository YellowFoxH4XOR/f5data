Known Issue

Message routing mirroring may trigger the Traffic Management Microkernel (TMM) to produce a core file and restart.

This issue occurs when all of the following conditions are met:

  • You are running an affected release.
  • Your BIG-IP system is configured for connection mirroring.
  • You configure a Diameter message routing router profile with Connection Mirroring enabled.
  • The virtual server configured with the router profile processes traffic.

Impact

The BIG-IP system temporarily fails to process traffic, and the system fails over to a peer system.

Note: Support for the Diameter message routing mirroring feature started with the release of BIG-IP 13.0.0. Configuration options for the feature were erroneously made available in the noted releases.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file in the /shared/core directory.
  • Your BIG-IP system logs a SIGSEGV to the /var/log/tmm file at the same time TMM produces a core file and restarts.
  • In the /var/log/ltm file, the system logs messages similar to the following examples:

    notice sod[<pid>]: 010c007f:5: Receiving status updates from peer device /<partition>/<big-ip peer> (<ip address>) (Offline).
    notice sod[<pid>]: 010c007f:5: Receiving status updates from peer device /<partition>/<big-ip peer> (<ip address>) (Online).
    warning sod[<pid>]: 01140029:4: HA proc_running tmm fails action is go offline and down links.
    notice sod[<pid>]: 010c006d:5: Leaving Standby for Offline for ha table offline_cond.

Workaround

To work around this issue, you can disable Connection Mirroring on the router profile. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Message Routing.
  3. Select the Router Profiles tab.
  4. Click the name of the router profile.
  5. In the Settings section, locate Connection Mirroring.
  6. To disable Connection Mirroring, clear the checkbox.
  7. Click Update.
