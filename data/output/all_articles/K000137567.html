Description

BIG-IP Edge Client for Windows fails to establish VPN tunnel with the error "You do not have access to the Network Access Connections. Please contact your system administrator."

Environment

  • BIG-IP Edge Client running on Windows

Cause

The BIG-IP Edge Client tried to retrieve NA resource details, however, it failed. The client expects NA resource details to be XML formatted, however, it received something that does not look like XML content.

Recommended Actions

A typical reason for such errors is misconfiguration similar to what is described in K15774: Misconfigured DNS load balancing can break client sessions with the BIG-IP APM system where the client's attempt to fetch NA resource config ends up with a load balanced APM that has no idea of the session created on another APM. Review the article to determine if this applies to your environment.

To exactly identify the cause of the client failing to retrieve NA resource details, simultaneous decryptable packet captures will be required on the client and the APM. 

Note: If you are a VPN end user, you must contact your organization's IT department to help you resolve the issue. The aforementioned actions to do not apply to end users.
