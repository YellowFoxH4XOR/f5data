Description

TMM memroy usage is increasing and showing memory leak symptom.
When you run the following command to see what tmm subcomponent is causing increasing more memory, you will see profile component is higher and Max Alloc and Alloc have similar size:

tmsh show /sys memory | sed -n '/Sys::SubSystem Memory/,/^$/ p' | (for i in $(seq 3); do read -r; echo "$REPLY"; done; sort -rhk 3) | head -13

Sys::SubSystem Memory
SubSystem    Alloc (bytes)  Max Alloc (bytes)  Object Size
------------------------------------------------------------
profile              8.0G               8.0G            1
umem               391.4M               1.5G            1
ssl_session          5.6M             298.8M          324 
...
 

Environment

  • BIG-IP
  • v14.1.x-15.0.x
     

Cause

There might be other reasons but one suspect is Bug ID 823921


Recommended Actions

Check if you are using FTP profile, and if the profile has enabled for inherit-parent-profile.

e.g. on CLI:
 
tmsh list /ltm profile ftp
 
ltm profile ftp /Common/MY_FPT_PROFILE {
    ...
    inherit-parent-profile enabled   <<<----- [!]
    ...
}
 
If there are any ftp profiles with inherit-parent-profile enabled,
  • disable it, if it is appropriate for your environment
    or
  • upgrade to fixed versions if you can not disable it.
