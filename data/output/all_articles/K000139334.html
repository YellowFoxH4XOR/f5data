K000139334: Unable to create iRule via API on BIG-IP Next CM

Source

Description

When creating iRule on BIG-IP Next CM using the API it returns an error as below

 

{

"message": "request body has an error: failed to decode request body: multipart: boundary is empty"

}

 

Environment

  • BIG-IP Next CM
  • Create iRule API

Cause

Improper construction of multipart/form-data

Recommended Actions

This is an example of a valid HTTP POST to create an iRule:

 

POST /api/v1/spaces/default/irules HTTP/1.1

Host: 10.1.1.1

Authorization: Bearer {{jwt}}

Content-Length: 397

Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW

 

------WebKitFormBoundary7MA4YWxkTrZu0gW

Content-Disposition: form-data; name="name"

 

new_iRule

------WebKitFormBoundary7MA4YWxkTrZu0gW

Content-Disposition: form-data; name="description"

 

iRule creation

------WebKitFormBoundary7MA4YWxkTrZu0gW

Content-Disposition: form-data; name="content"

 

when HTTP_REQUEST {\n Redirecting client [IP::10.182.10.10] \n}

------WebKitFormBoundary7MA4YWxkTrZu0gW--
