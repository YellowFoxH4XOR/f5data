Description

  • APM Active Directory Authentication fails.
  • Messages similar to the ones below may be observed in /var/log/apm

AD module: authentication with 'auser' failed: KDC has no support for encryption type, principal name: auser@EXAMPLE.COM Please verify Active Directory and DNS configuration. (-1765328370)

Environment

  • APM Policy with Active Directory AAA Object
  • The Domain Controller has been updated with the November 2022 Microsoft security patch.

Cause

  • The Patch is faulty.
  • There is no workaround possible on the BIG-IP.

Recommended Actions

  1. Revert the Patch
  2. Raise a case with Microsoft

Alternatively, the following regkey entries can be added into the DC registry, but may have other unexpected consequences

reg add "HKLM\SYSTEM\CurrentControlSet\services\kdc" /v KrbtgtFullPacSignature /t REG_DWORD /d 0 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\Netlogon\Parameters" /v RequiredSeal /t REG_DWORD /d 0 /f
reg add "HKLM\SYSTEM\CurrentControlSet\services\kdc" /v ApplyDefaultDomainPolicy /t REG_DWORD /d 0 /f
