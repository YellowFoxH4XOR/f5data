Description

Selected prober pool on server or data centre not visible in Configuration Utility (GUI)
 

Environment

You are viewing them in the using Internet Explorer or Edge browser.

Cause

The issue is cause by a Bug ID822393.

Recommended Actions

To fix the issue, upgrade to the version where the bug is fixed.
To workaround the issue, use different browser like Firefox or Chrome or use tmsh CLI to display the configuration

Additional Information

The issue is cosmetic and does not cause any service impact
