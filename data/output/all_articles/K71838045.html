Description

During a migration you are trying to load a .ucs file into to a vCMP guest / BIG-IP VE, using the platform migrate option and an error similar to the one below is being generated.

bigip.lab emerg load_config_files[1069]: "/usr/bin/tmsh -n -g -a load sys config partitions all platform-migrate" - failed. -- 01071bce:3: Device /Common/bigip.lab platform requires network-failover to be enabled for device-group /Common/SyncAndFailoverGroup

Environment

  • UCS
  • vCMP Guest / BIG-IP VE
  • Sync Failover device group

Cause

Starting in 13.x Network Failover cannot be disabled on BIG-IP VE, vCMP guests and VIPRION systems.

Recommended Actions

Enable the network failover on the respective device group on the old unit and then generate again a new ucs file in order to load it into the new system.

  1. Navigate to: Device Management > Device Groups
  2. Select the device group in question
  3. Click Advanced
  4. Select the Network Failover option ( Click on Enabled )

or alternatively you can edit the bigip_base.conf of the ucs manually and remove the network-failover disabled line from the respective device group configuration.

Additional Information

Important: The above does not apply for Sync Only device groups especially Azure active/active deployments where Azure LB is used to load balance requests to all BIG-IPs in the Sync Only device group. See Microsoft Azure: F5 BIG-IP Virtual Edition Single NIC config sync
