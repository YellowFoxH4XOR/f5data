Description

When accessing certain sections of the BIG-IP Configuration Utility (TMUI), such as support or device management overview, users may encounter the interface stuck at "Loading... Receiving configuration data from your device." This issue prevents further interaction with the GUI, requiring alternative methods (such as CLI) to generate diagnostic files like qkview. System logs may show messages related to memory leaks and forcibly unregistered JDBC drivers, as well as threads not being stopped properly.

Environment

  • Product: BIG-IP LTM
  • Log messages indicating memory leaks and thread management issues in TMUI
  • No recent environmental changes explicitly noted

Cause

Insufficient memory allocated to BIG-IP management services (restjavad and tomcat), resulting in the TMUI being unable to retrieve configuration data and complete loading.

Recommended Actions

To resolve the issue, increase the memory allocation for management services and restart the relevant services. Perform these steps during a scheduled maintenance window, as traffic interruption and HA failover may occur.

  1. Increase management service memory allocation:
    tmsh modify sys db provision.extramb value 2048
    tmsh modify sys db provision.restjavad.extramb value 1024
    tmsh modify sys db provision.tomcat.extramb value 256
  2. Restart management services:
    tmsh restart sys service restjavad restnoded httpd tomcat
  3. Save the system configuration:
    tmsh save sys config
  4. If the issue persists, generate a new qkview and submit for further analysis.
    qkview -f /var/tmp/qkview_new.qkview

Impact of workaround: The system may experience temporary traffic interruption and HA failover; perform changes during a scheduled maintenance window.

Note: After increasing memory allocation and restarting services, monitor system stability before making further changes.

Additional Information

  • The following are example log messages that may be observed when this issue occurs:

WARNING [main] org.apache.catalina.loader.WebappClassLoaderBase.clearReferencesThreads The web application [ROOT] appears to have started a thread named [Thread-7] but has failed to stop it...

SEVERE [main] org.apache.catalina.loader.WebappClassLoaderBase.clearReferencesJdbc The web application [ROOT] registered the JDBC driver [org.postgresql.Driver] but failed to unregister it when the web application was stopped...

java.lang.OutOfMemoryError: Java heap space

  • You can use CLI commands above to adjust memory allocation or restart services if GUI is inaccessible.
  • If you cannot access TMUI due to this error, use CLI commands for qkview generation:

qkview -f /var/tmp/qkview_new.qkview

  • If persistent issues remain after recommended actions, contact F5 Support with latest qkview file for deeper analysis.

Note: Increasing extramb values beyond hardware capacity can cause other resource contention issues; consult platform documentation before making large adjustments.

Impact of workaround: The system will not be available while performing multiple restarts.
