Description
Can not update modified ca-bundle cert from GUI.
When uploading that modified CA-bundle certs to a existing device, below error shown up from Configuration Utility,

General error: 01070712:3: Access check failed for (/Common/ca-bundle.crt). in statement [UPDATE certificate_file_object SET local_path = ?, checksum = ? WHERE name = '/Common/ca-bundle.crt']

Environment

  • LTM
  • SSL/TLS certificates

Cause
CA-bundle cert may need to be updated manually.

Recommended Actions

  1. Import new ca-bundle certs to F5, below is scp command to import new ca-bundle certs,
    • scp root@xxxxx:/config/ssl/ssl.crt/ca-bundle.crt ./new_ca-bundle.crt
  2. Install the new ca-bundle certs to F5 then save the config,
    • tmsh install sys crypto cert new_ca-bundle.crt from-local-file /config/ssl/ssl.crt/ca-bundle.crt
    • tmsh save sys config
