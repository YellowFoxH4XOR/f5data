Get started with search

To search for a document, on the MyF5 home page, enter a few descriptive words in the search box and select the Search icon (magnifying glass).

Note: To include archived documents in your search, select the Include archived results check box at the top of the list of results.

Note: You can use Boolean operators (AND, OR, NOT, and NEAR) to perform advanced searches.

Your search results appear with two icons alongside each result title. The top icon indicates the content type of the document, and the bottom icon (the eye) is a Quick View icon.

Use Open preview

Select the Open preview icon () to open the preview page for that document.

Sort results

You can sort by Relevancy (default), Newest, or Oldest.

Relevancy is a calculated score that the search engine uses to find documents that are both important and relevant to your search based on such factors as the following:

  • The number of times your search term occurs within a document
  • How recently the document was modified
  • How close the search terms appear to one another in the document

The accuracy of the Relevancy calculation improves over time as the search engine learns from your search behaviors.

Filter your search

On the search results page, you can refine your results using the Product Version and Content Type filters.

View generative AI answers in search results

When you enter prompts into the search box, F5 uses generative AI to generate an answer based on your instructions and using only the chunks of text that are in the prompt. Generative answers appear under Generated answer(s) for you in a box above the traditional search results, along with citations that reference the content that was used to generate the answer. Selecting a citation opens the corresponding item. If you apply filters to the search results, the answer regenerates in real time, based on the selected filters.

Use the Product Version filter

In Product Version, select the product you want. You can then select the version branch you want (when available) and the version you want (when available).

You can also enter a product name into the Search box. From there, you can select the version branch you want (when available) and the version you want (when available).

Use the Content Type filter

The selections you make in the Product Version filter determine the items that appear in the Content Type filter.

Manage your search filters

To clear applied filters, under Sort by, select Clear All Filters.

Expand and collapse filter items

To expand the filter, select Show more.

To collapse the filter, select Show less."

General search guidelines

This section provides a few helpful search guidelines.

Capitalization

Searches are not case sensitive. All letters, regardless of how you enter them, are handled as lowercase. For example, searches for TCP, Tcp, and tcp return the same results.

Note: Boolean operators (AND, OR, NOT, and NEAR) are exceptions to this rule. You should enter these operators in all caps. For more information, refer to Search Prefixes and Operators. This link takes you to a resource outside of MyF5, and it is possible that the document may be removed without our knowledge.

Phrase searches

You can search for an exact phrase by enclosing the phrase in quotation marks ("). The search engine returns only documents that include the exact phrase you entered.

Note: Make sure you always use quotation marks (“) when performing a phrase search.

For example:

"overview of snat"

Find product documentation

To locate the product manuals for F5 products (for example, BIG-IP version 14.x and newer), refer to K000130285: F5 Product Manuals Index.

To locate the other documentations, you can use the MyF5 search with the following steps for the different types of documentation.

Release Notes

  1. Visit MyF5
  2. Use the search terms "release notes N.N.N", where N.N.N is the release version that you are looking for.
    For example using "15.1.8" or "15.1.x" as version numbers,
    release notes 15.1.8
    release notes 15.1.x
  3. In the Content Type filter, select the Release Notes check box to filter the results.

Security Advisories

  1. Visit MyF5
  2. Use the search terms "CVE-YYYY-", where YYYY is the year of the CVEs that you are looking for.
    For example, CVE-2022-
  3. In the Content Type filter, select the Security Advisory check box to filter the results.

Other documentation for a specific topic

  1. Visit MyF5
  2. Use the search terms on the topic and version number.
    Examples of topic and version number to use as search terms,
    implementations 13.1.0
    attack signatures 16.1.3
  3. In the Content Type filter, select the Manual check box to filter the results.
  4. Optional: Use the Product Version filter to select the F5 product name that you are looking for to filter the results.
