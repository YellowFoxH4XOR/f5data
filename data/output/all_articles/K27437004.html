Description

After configuring the Response Policy Zones per the related manual, if you try to add or remove records in RPZ the changes from BIND zone (zonerunner) are not replicated to the DNS express zone configured in the DNS cache profile, causing the new records not being blocked.

Environment
  • BIG-IP DNS
  • RPZ zone.

Cause

Bind zone is not configured with the option,

also-notify { ::1 port 5353; };

Recommended Actions

In Zone Runner menu, add also-notify statement to ensure BIND notifies DNS Express when the zone is updated:
  1. Log into the BIG-IP GUI
  2. Navigate to DNS > Zones > ZoneRunner > Zone List 
  3. Select the configured RPZ
  4. In the options box add the also-notify { ::1 port 5353; };  statement.

Taking as an example the next default option list,

allow-update {
    localhost;
};
also-notify {
    ::1 port 5353;
};
