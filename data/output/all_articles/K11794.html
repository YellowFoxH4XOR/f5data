Known Issue

Note: Beginning in BIG-IP 10.0.0, F5 can license add-on modules free of charge for a time-limited evaluation period. This feature allows you to try an add-on module on an existing system with a permanent license. When an add-on module evaluation license expires, the Configuration utility displays the All Evaluations Have Ended warning message. For more information, or to request an add-on module evaluation license, contact your F5 Sales Representative.

This is the result of a known issue. You cannot clear the All Evaluations Have Ended warning message once the system has displayed the message. This warning message is benign, and it is safe to operate the BIG-IP system despite the displayed warning message. Reactivating the license of the BIG-IP system will not clear the warning message.

Note: When the Configuration utility displays the All Evaluations Have Ended warning message, the command line prompt status changes to EvalExpired.

F5 Product Development tracked this issue as ID 227189 (formerly CR142891) and it was fixed in BIG-IP 11.4.0. For information about upgrading, refer to the BIG-IP release note for the version you are upgrading to.
