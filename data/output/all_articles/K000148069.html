K000148069: ERROR: "WebSocket connection to 'example.com' failed: Error during WebSocket handshake: Unexpected response code 400"

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000148069

What Happened?

  • You created a new load balancer with HTTPS type
  • The WebSocket option is enabled at Routes configuration
  • You are receiving an error message: "WebSocket connection to 'example.com' failed: Error during WebSocket handshake: Unexpected response code 400"

Environment

  • F5® Distributed Cloud Console

 

Resolution/Answer

  • Change the Http Protocol Configuration in the Origin Pool from Automatic to http 1.1 to resolve the issue.

Cause

  • Sometimes when the Upstream is using HTTP2 WebSocket does not work properly.
