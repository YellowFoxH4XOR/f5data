Known Issue

Differing license tokens on device group members may cause a synchronization failure.

This issue occurs when all of the following conditions are met:

  • You configure a BIG-IP Virtual Edition (VE) device in a device group with other BIG-IP VE devices or with hardware-based BIG-IP systems. 
  • The license token perf_VE_cores is different among licenses within the device group.
  • You sync to or from the device group on any system in the device group.

During the synchronization process, the perf_VE_cores license token causes the BIG-IP system that is receiving the configuration to change the license.maxcores database variable to the number specified by the license token. However, if this value is not allowed by the license, the synchronization failure will occur.

Impact

You cannot sync device group members.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The synchronization status is Sync Failed.
  • After a synchronization, the Summary section of the Device Management > Overview page displays an error message that appears similar to the following example:

    Sync error on <device name>: Load failed from /Common/<device name> 0107178a:3: Modifying license.maxcores to a value other than <integer> is not allowed.

Resolution

Status

F5 Product Development has assigned ID 616059 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

There is no workaround for this issue. To avoid the synchronization failure if you are using BIG-IP VE systems in a device group, ensure that device group member licenses have the same value for the perf_VE_cores license token.
