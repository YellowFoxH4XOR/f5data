K40115984: Modify the retention time for the Prometheus DB in Aspen Mesh

Type
Support Solution
Published
2021-06-30
Updated
2023-07-19
Applies to
  • Aspen Mesh
Source
https://my.f5.com/manage/s/article/K40115984

Description

With Aspen Mesh control plane components installed, you have the aspen-mesh-metrics-collector pod which is running Prometheus DB.  You will be configuring the retention time for this DB.

Environment

  • Aspen Mesh 1.9.3 and higher

Cause

None

Recommended Actions

None

Additional Information

For the Prometheus DB that is used by our metrics collector, you will change the override value file with the following procedure:
  1. Edit your overrides yaml file by adding server.retentionTime as follows::

    Note: The following example indicates 5 days, whereas the default is 15 days.

    # metrics-collector retention time
    aspen-mesh-metrics-collector:
      server:
        retentionTime: "5d"

  2. After adding the above configuration, istiod deployment needs to be upgraded via helm using the override file to set the desired days of retention for aspen-mesh-metrics-collector pod:

    $ helm upgrade istiod ~/manifests/charts/istio-control/istio-discovery -n istio-system --values sample_overrides-aspenmesh.yaml

  3. This will restart the metrics collector pods which had its configuration changed as shown in the following example:

    $ kubectl get pods -n istio-system | grep metric
    aspen-mesh-metrics-collector-7c695fd745-hxlvf         3/3      Running   0         84m

  4. Verify if the above retention time is added to it by checking the arguments for the container as shown in the following example:

    $ kubectl get pod aspen-mesh-metrics-collector-7c695fd745-hxlvf -n istio-system -o yaml | grep -A 5 containers

    containers:
      - args:
        - --config.file=/etc/config/prometheus.yml
        - --storage.tsdb.path=/metrics-collector/tsdb
        - --storage.tsdb.retention.time=5d
        - --web.console.libraries=/etc/prometheus/console_librarie

  5. Wait for the pod to be in running state, displaying its state with the following command:

    $ kubectl get pods -n istio-system | grep metric
    aspen-mesh-metrics-collector-7c695fd745-hxlvf         3/3     Running   0          4h2m

    You can verify the change by querying Prometheus and it should not return anything outside your retention time window.
