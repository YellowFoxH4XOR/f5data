K691: Reasons why the Configuration utility may not immediately display object names

Topic

This issue can occur when a BIG-IP system is configured to perform Domain Name System (DNS) lookups and the Configuration utility attempts to display objects by name rather than numeric address. An offline DNS name server will also cause delays in displaying when the BIG-IP system attempts to resolve the numeric address to a name. To troubleshoot this issue, verify that the name servers listed in the /etc/resolv.conf file are active and responsive.

An alternative to using DNS lookups to map addresses to names, is to use the /etc/hosts file. Since the /etc/hosts file is local to the BIG-IP system, resolutions are instantaneous.

If you choose to use the /etc/hosts file for name resolution, you must enter all object names and addresses into it. Additionally, you must verify that the /etc/irs.conf file contains the following lines to ensure that the BIG-IP system will use the /etc/hosts file to resolve host names before DNS:

hosts local continue
hosts dns
