Description

  • UCS archive restore fails
  • The Traffic Management Shell (TMSH) and/or /var/log/ltm file show following error message:

    01071769:3: Decryption of the field (privatekey) for object (9717) failed. Unexpected Error: Loading configuration process failed.

Environment

  • BIG-IP
  • Restoring UCS Archive

Cause

The BIG-IP does not have the necessary system Master Key required by the UCS Archive

Recommended Actions

The BIG-IP is part of an HA Pair/Cluster
The "shared" configuration can be synchronized onto the BIG-IP by completing the necessary procedures in: K13551: Configuring a replacement BIG-IP device after an RMA when no UCS archive is available

The BIG-IP is

    not part of an HA Pair/Cluster
    The UCS restore on the BIG-IP device can be completed by updating the Master Key on the BIG-IP device with the expected Master Key file. For further information on restoring the Master Key refer to K9420: Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)

    The BIG-IP is
      not part of an HA Pair/Cluster, and restoring the Master Key is
        not an option
        • Making changes to the dynad configuration.
        • Remove all the dynad configuration lines.
        Making changes to the dynad configuration
        The following procedure
          may result in a successful UCS restore:

          Note: After the UCS restore fails, the configuration files should be present in the /config/ folder.

          1. Locate the dynad config in /config/bigip_base.conf file:

            For example, the dynad config will look like:

            sys dynad key {
                key $M$jV$VX7HMp5q346nsTYDYFPnYdJLrBPyQSCrDTJYAz4je7KXJAC38fxtDJL35KtF66bq
            }

          2. Modify the dynad configuration lines to:

            sys dynad key {
                key "test"
            }

          3. Save the updated bigip_base.conf file
          4. Load the configuration with command:  tmsh load sys config
             
          Remove all the dynad lines. There should be 6 lines in total.

          1. Locate the dynad config in /config/bigip_base.conf file:

            For example, the dynad config will look like:

            sys dynad key {
                key $M$jV$VX7HMp5q346nsTYDYFPnYdJLrBPyQSCrDTJYAz4je7KXJAC38fxtDJL35KtF66bq
            }
            sys dynad settings {
                development-mode false
            }

          2. Delete the 6 lines above.
          3. Save the updated bigip_base.conf file
          4. Load the configuration with command:  tmsh load sys config
          5. Save the configuration with command:  tmsh save sys config
