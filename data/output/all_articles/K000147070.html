K000147070: What will the AS-path look like after advertising prefixes through F5® Distributed Cloud?

What Happened?

Customer started advertising prefixes to F5® Distributed Cloud (XC), what ASNs are expected to be visible on the AS path? 

 

Environment

  • F5® Distributed Cloud DDoS

Resolution/Answer

Depending on the type of configuration the customer has, the AS path will look different. 

  • If customer is configured as Always-On:
    The AS path will include AS35280 & AS55002 along with the customer ASN
    AS-path example: 6453 35280 55002 64501

  • If customer is configured as Always-On and using the Route Advertisement Feature:
    The AS path will only include AS35280 along with customer ASN
    AS-path example: 6453 35280 64501

  • If customer is configured as Always-Available and using the Route Advertisement Feature:
    The AS path will only include AS35280 along with customer ASN
    AS-path example: 6453 35280 64501

Cause

  • Even though the peering is made with AS55002 for DDoS protection, if Route Advertisement is used, then the route origination devices will obfuscate AS55002. This helps maintain a shorter path by reducing the AS path length
