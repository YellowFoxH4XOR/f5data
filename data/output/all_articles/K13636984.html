K13636984: Ensuring the BIG-IP system has sufficient volume disk space available for a software upgrade

Type
Support Solution
Published
2020-10-29
Updated
2025-10-22
Applies to

Description

You want to ensure there is sufficient system disk space available before creating a new software volume for a new image or hotfix install on the BIG-IP system. 

Before creating a new software volume, you must first ensure that the BIG-IP system has sufficient volume disk space to create a new software volume for the upgrade. This article explains how to verify whether the BIG-IP system has sufficient volume disk space.

Note: A system with free volume disk space of about 15 GB or more is able to create a new software volume.

Recommended Actions

Display available free disk space using the Configuration management utility 

  1. Log in to the BIG-IP Configuration utility
  2. Navigate to System > Disk Management

Using BIG-IP Advanced Shell (bash) to verify disk space availability

To verify that the system has sufficient volume disk space to create a new software volume, you can use the vgs command.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Advanced Shell (bash) as an administrator.
  2. To review the current system's volume disk usage, enter the following command:

    vgs

  3. Review the output for the amount of free volume disk space.

Following are two samples of output, one with sufficient volume disk space, and the other with insufficient volume disk space.

Note: A system with free volume disk space of about 15 GB or more is able to create a new software volume.

Example output of the sufficient volume disk space:

This BIG-IP system has nearly 415 GB of free volume disk space, so it can handle a new software volume.
VG #PV #LV #SN Attr VSize VFree
vg-db-vda 1 9 0 wz--n- 511.79g 414.92g

Example output of the insufficient volume disk space:

When reviewing the command output, it shows that this BIG-IP system has 9.35 GB of free volume disk space, which is not sufficient to create a new software volume (refer to K33265170).
VG #PV #LV #SN Attr VSize VFree
vg-db-vda 1 9 0 wz--n- 511.79g 9.35g

Using BIG-IP Advanced Shell (bash) to verify logical volume disk usage

To verify logical volume disk usage, you can use the lvs command.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Advanced Shell (bash) as an administrator.
  2. To review the current system's volume disk usage, enter the following command:

    lvs

  3. Review the output. For example volumes in the HD1.1 volume set are prepended with set.1.

If there is insufficient space:

  1. Deleting any unused Installed versions is the safest way to create the needed space.
  2. For ASM it is important have enough disk space. Depending on the type of BIG-IP (the various virtual editions or hardware) extending disk space of /var will be needed.  K000157081: Adv WAF and ASM Upgrade Best Practices
  3. When you don't have enough volume disk space to create a new software volume, you can still install the new software by re-using an existing software volume that is non-active. Before you re-use an existing software volume that contains an active configuration, F5 recommends that you copy the latest configuration backup to a remote system, as re-using an existing software volume will delete all of the existing configuration on that volume.

Additional Information

Note: The bigip_command Ansible module allows execution of the vgs bash command for automated scripting purposes.

tmsh run /util bash -c "vgs"
