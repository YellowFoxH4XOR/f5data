Known Issue

The Border Gateway Protocol (BGP) neighbor <peer-group> local-as <AS> command applies the wrong autonomous system (AS) to peers in a peer group.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system uses BGP with peer groups.
  • You use the neighbor <peer-group> local-as <AS> command syntax, where <peer-group> is the name of the peer group and <AS> is the AS.

Impact

The system sends the local AS of the BGP process to peers instead of the AS specified in the command.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After using the neighbor <peer-group> local-as <AS> command syntax, the system sends the local AS of the BGP process to peers instead of the one specified in the command.

Workaround

To work around this issue, you can apply the local-as setting to each peer in the peer group. To do so, perform the following procedure. 

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Use the following command syntax:

    neighbor <peer_ip_address> local-as <AS>
