Known Issue

The product name may be listed as false in the Configuration utility.

Impact

None

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When viewing the System > Software Management > Image List page in the Configuration utility, the product column displays false, instead of the actual product name.

Resolution

Status

F5 Product Development has assigned ID 385564 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the top right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release11.4.0K2200: Most recent versions of F5 software
HotfixNoneNone

Workaround

To work around this issue, you can view the product name using the tmsh shell. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.

  2. View the list of installed software by typing the following command:

    show sys software
