K19413394: ''Report submission failed: Please provide a valid certificate'' when using non-licensed version of BIG-IQ

Type
Support Solution
Published
2022-07-22
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K19413394

Description

In BIG-IQ 7 and later, you have the option to skip licensing, which gives you access to the “License manager” limited functionality.
However, when submitting “utility Billing Report” for ELA / FCP or other subscription programs, you get an error message like the one below:
[ERROR][01 May 2022 07:00:04 GMT+00:00][BillingReportTask] Report generated but submission failed for XXXXX-YYYYY-ZZZZZ-AAAAA-BBBBBBB (task EEBBHH76-1234-4321-a1b2-XXXZZZSSDDFF): Report submission failed: Please provide a valid certificate
 
Environment
  • BIG-IQ versions 7.X and 8.X (no base registration key / license)
  • Using ELA (Enterprise License Agreement)
  • Sending automated utility report

Cause

When using the automated method of submitting “Utility Billing Report” You need a valid certificate to authenticate to the server “api.f5.com” this certificate is acquired when you activate a base license key and as such is missed when using the non-licensed version of  BIG-IQ

Recommended Actions

Reach out to your Customer Success Manager customersuccess@f5.com or call support.
Quote this solution ID.

You will need a $0 BIG-IQ License manager license key “F5-BIQ-VE-LIC-MGR-LIC”
This will take up to a week to order and process.
If the request is urgent, a 30 day evaluation license can also be used.
