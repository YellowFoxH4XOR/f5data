Topic

The BIG-IP system uses a virtual server precedence to define the order in which it routes a packet to a specific virtual server in the event that the packet matches multiple virtual server definitions.

The order of virtual server precedence (from the highest precedence to the lowest precedence) is as follows:

  • ip:port
  • ip:any
  • network:port
  • any:port
  • network:any
  • vlan:port
  • vlan:any
  • any:any

Once a packet is sent to a specific virtual server, it is added to the connection table for that virtual server. From that point forward, packets that come in from the same connection will always go to the virtual server that contains the connection in its connection table, ignoring virtual server precedence.

The order of precedence has changed in BIG-IP version 9.x. For more information, refer to K6459: Order of precedence for virtual server matching.
