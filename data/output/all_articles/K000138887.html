K000138887: ConfigSync Failure with error Caught configuration exception (0), Failed to sync files

Type
Support Solution
Published
2024-03-12
Updated
2024-04-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.X.X, 15.1.X, 15.1.10, 15.1.9, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.0.X, 15.0.1, 15.0.0
  • BIG-IP APM: 15.X.X, 15.1.X, 15.1.10, 15.1.9, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.0.X, 15.0.1, 15.0.0
Source
https://my.f5.com/manage/s/article/K000138887

Description

  • Unable to sync devices in HA pair
  • An error similar to the following can be seen on GUI after sync:
     Sync_Failover (Sync Failed): A validation error occurred while syncing to a remote device
     - Sync error on bigip2: Load failed from /Common/bigip1 01070712:3: Caught configuration exception (0), Failed to sync files..
     - Recommended action: Review the error message and determine corrective action on the device
  • Logs similar to the following can be seen on /var/log/ltm
info sod[9048]: 010c0096:6: Next active for traffic group traffic-group-1.
err diskmonitor[43133]: 011d0004:3: Disk partition /config has only 0% free
notice mcpd[5258]: 010718ed:5: DATASYNC: requested force sync by user: Unknown
err mcpd[5258]: 0107134b:3: (rsync: write failed on "/config/filestore/.snapshots_d/epsec_package_d/:Common:epsec-1.0.0-1526.0.iso_86308_1": No space left on device (28)
err mcpd[5258]: 0107134b:3: (rsync error: error in file IO (code 11) at receiver.c(322) [receiver=3.0.9]
err mcpd[5258]: 0107134b:3: (rsync: connection unexpectedly closed (113 bytes received so far) [generator]
err mcpd[5258]: 0107134b:3: (syncer /usr/bin/rsync failed! (3072) ()
err mcpd[5258]: 0107134b:3: (rsync process failed.) errno(255) errstr().
err mcpd[5258]: 01070712:3: Caught configuration exception (0), Failed to sync files..

Environment

  • BIG-IP with LTM and APM provisioned
  • HA Pair
  • Sync

Cause

Seen behaviour is the result of low disk space on /config due to EPSEC images.

Recommended Actions

Make sure to remove unnecessary EPSEC images following the procedure described on K21175584

None
