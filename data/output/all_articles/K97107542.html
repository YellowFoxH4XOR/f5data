Source

Description
When attempting to automatically activate or re-activate the BIG-IP license, your firewall is unexpectedly blocking the traffic and causing the connection attempt to fail.

You may see in tmsh that there is no existing configuration for a static management route to the F5 services other than the default route. Use the following command to view management routes:
tmsh list /sys management-route all-properties

The following command example will display the source IP and gateway used to reach the IP address specified:
ip route get 107.162.235.62

Environment

  • BIG-IP system
  • Firewall

Cause
Access to the BIG-IP license activation server, activate.f5.com on port 443 is not allowed and/or the system is unexpectedly using a data plane TMM route from a self IP source instead of a management route from the management interface.

Recommended Actions

  1. Use the following command syntax to add a management route that is more specific than the default route for reaching the BIG-IP license activation IP address. Refer to K15202: IP addresses for F5 hosted services for the most current domains and addresses.
    tmsh create /sys management-route <name> network <network address>/<netmask> gateway <your gateway IP>
    For example:
    tmsh create /sys management-route f5networks network 107.162.235.62/255.255.255.255 gateway 10.1.1.1
  2. To save the changes, type the following command:
    tmsh save /sys config
  3. Update your firewall to allow access to the IP address from K15202 for BIG-IP license activation on port 443 for your management network.
