A keyboard map contains mapping instructions for associating one keystroke or key sequence on the client system to another keystroke or key sequence on the legacy host. You can edit keyboard maps for Java-based legacy hosts on the Application Access : Legacy Hosts : Resources page in the FirePass Administrative Console.

The TN5250 legacy host application is an ActiveX control; you cannot edit its keyboard map. Refer to the table below for the FirePass TN5250 legacy host keyboard map:
