Description

To insert a Virtual IP address in HTTP header when connecting to a server, an irule can be used.

Environment

  • BIG-IP LTM
  • Virtual Server with TCP & HTTP profiles.
  • iRule

Cause

None

 Recommended Actions

To insert the virtual IP address in HTTP header when there's a new HTTP connection, use the following iRule :

  1. To Create the iRule go to Local Traffic > iRules > iRule List
  2. Then click Create
  3. Choose a name for your iRule and paste the following statements into the Definition field & Click Finished :
when HTTP_REQUEST {
HTTP::header insert "Virtual_IP [IP::local_addr clientside]"
}

To apply the iRule to the Virtual Server, follow below steps:

  1. Go to Local Traffic > Virtual Servers > Virtual Server list
  2. Select the Virtual Server
  3. Click the Resources tab
  4. In the iRules section, click Manage
  5. Choose the iRule you just created from the Available section and move it to the Enabled section
  6. Click Finished
