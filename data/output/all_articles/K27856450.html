Description

Configuration Utility (GUI) is restarting frequently and disconnecting me.

Messages observed:

Please wait while the Configuration Utility Starts.
Starting web server
Please do not reboot your device. The device is starting services required for the communication with the configuration utility.
This process takes approximately 1-2 minutes.

 


Unable to contact BIG-IP device
The BIG-IP Configuration utility makes period requests for status information in the background while you work.
Unfortunately, the network connection to your BIG-IP system has been interrupted and the last status request failed.

 

Environment

  • GUI
  • Configuration Utility

Cause

These symptoms have a variety of root causes, but most commonly are caused by:

  • tomcat has reached memory heap limit, or
  • System is low on memory, resulting in OOM Killer activity toward tomcat's java process

The following bug can also cause these issues:

  • Bug ID 472645: Memory issues when there is a lot of data in /var/annotate (annotations for dashboard)

Recommended Actions

To determine if tomcat is running out of memory, look for the following message in /var/log/tomcat/catalina.out:

  • K9719: Error Message: java.lang.OutOfMemoryError

To determine if the Linux host is overall low on memory, refer to Verifying that the system is in a high memory state in K84425073.

If you determine that the system is not low on memory overall, but tomcat is restarting, allocate additional memory to tomcat with the provision.tomcat.extramb database variable:

tmsh modify /sys db provision.tomcat.extramb value 250

tmsh restart /sys service tomcat

Note: These steps are not traffic impacting. An initial value of 250 is recommended, but can be increased as high as 1024, which might be necessary for large configurations.
