K23012013: Software installation failed or missing HD media after install into new volume

Description

You fail to install new software versions on volume HD1.0. The installation appears to fail in the configuration utility. Despite the software eventually installing successfully, the 'hd' is not displayed in the Media column. The liveinstall.log file shows the following error:

error: tm_install::VolumeSet::VolumeSet_add_planned -- internal error; missing required arguments.

Environment

  • Selected HDx.0 to install the OS
  • Software Upgrade

Cause

The issue arises when selecting an HD for installation with a value of '0', which is not allowed.

Recommended Actions

  1. Do not choose '0' when selecting the HD.
  2. Delete the boot volume of the failed installation.
  3. Re-install on HD1.x, where 'x' value cannot be 0. For example, you can choose x=2.
