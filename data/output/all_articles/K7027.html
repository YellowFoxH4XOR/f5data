Topic

This article describes how you can use the stream profile to parse a data stream to perform string search and replace functions.

Description

Note: For more information about the Stream profile, refer to K8115: Overview of the Stream profile.

The Stream profile allows you the ability to search for a string within a data stream and replace that string with another string. You can replace multiple strings within a data stream using a special construction in the Stream profile.

Configuring the Stream profile to replace multiple strings

  1. Go to Local Traffic > Profiles > Other > Stream.
  2. Select Create.
  3. Enter a Name for the new Stream profile.
  4. For Target, select the Custom check box.
  5. Use the following syntax to specify multiple strings to search for and replace, using the at sign (@) as the delimiter:

    @<search string1>@<replacement string1>@ @<search string2>@<replacement string2>@

    Note: The first character defines the delimiter bounding each field for this replacement and must not appear anywhere else in the target string. In certain versions, the delimiter can be a period (.), asterisk (*), forward slash (/), dash (-), colon (:), underscore (_), question mark (?), equals (=), at (@), comma (,), or ampersand (b) character. However, in some versions, only sed-style syntax using the forward slash as the delimiter is supported. The same syntax applies to the STREAM::expression iRules command. For more information, refer to K10192: The Stream profile requires sed syntax when using regular expressions in the Target field.

    Note: A space is required between the end delimiter of one search/replacement set and the start delimiter for the next set.

  6. Select Finished.

Examples

The following section provides the following search and replace examples:

  • Simple search and replace
  • Search and replace within an iRule
  • Search and replace with regular expressions

Simple search and replace

When applied to a virtual server, the following example Stream profile searches all data streams (the data that a virtual server receives on its client and server sides) for the strings 123 and abc. If found, the stream profile replaces the string 123 with 456 and the string abc with xyz when you configure the following:

Name: my_stream
Target: @123@456@ @abc@xyz@

Search and replace within an iRule

You can use the same syntax within an iRule.

Note: You must associate the default Stream profile with the virtual server before an iRule calling the Stream profile can be associated with the virtual server.

For example, the following iRule contains the same syntax:

when HTTP_RESPONSE {
STREAM::expression "@123@456@ @abc@xyz@"
STREAM::enable
}

Note: For BIG-IP LTM 9.3.1, 9.4.2, and later, you must enable the stream filter after the stream expression is specified. For more information, refer to K8207: Stream filter changed to protect against misconfiguration.

An iRule can perform the same function as a custom Stream profile. However, in this example the Stream profile is enabled only when an HTTP response is received from the server. Therefore, the iRule searches only server responses for the strings 123 and abc, and if found, it replaces string 123 with 456, and string abc with xyz.

Search and replace with regular expressions

You can also use regular expressions to search and replace in a Stream profile. The following stream profile searches for patterns matching US social security numbers and removes them:

Name: my_stream
Target: @[0-9]{3}–[0-9]{2}–[0-9]{4}@@
