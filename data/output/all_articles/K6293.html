Topic

This article applies to BIG-IP 9.x and 10.x. For information about other versions, refer to the following article:

  • K14333: Overview of the cache aging rate setting for the Web Acceleration profile (11.x)

The RAM Cache aging rate setting in the HTTP profile specifies how the system calculates the comparative age of each cache entry. Increasing the value of the setting will exponentially increase the comparative age of objects over time. Possible values for the aging rate are from 0 (slowest aging) to 10 (fastest aging). The default setting is 9.

The comparative age of an object is one of several factors including hit rate and priority that together determine which objects are removed from the RAM Cache when space is needed for new objects. The aging rate setting controls how much relative weight is given to age versus these other factors when performing the calculation.

The BIG-IP system uses the following formula to calculate the comparative age of an object:

Comparative age = Age in minutes * 2 ^ Aging rate
