Known Issue

This is the result of a known issue. The gtmd process consumes excessive CPU resources when the mcpd process exits, or if gtmd loses its connection to mcpd. When this issue occurs, the gtmd process may consume more than 90 percent CPU usage, which is displayed in the following top output:

PID USER PRI NI SIZE RSS SHARE STAT %CPU %MEM TIME CPU COMMAND
1800 root 25 0 17680 17M 8080 R 99.4 1.1 167:19 0 gtmd
18684 root 15 0 1076 1076 780 R 0.3 0.0 0:00 0 top
1 root 15 0 544 544 464 S 0.0 0.0 0:13 0 init

F5 Product Development tracked this issue as CR127056 and it was fixed in BIG-IP GTM version 10.1.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-9.4.8-385.0-HF2 which was issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

Workaround

You can work around the issue and stop the gtmd process from spinning by entering the following command:

bigstart restart gtmd
