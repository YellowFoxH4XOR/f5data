Known Issue

The certificate, key, and chain certificate settings used in a Client SSL profile may change after an upgrade.

This issue occurs when all of the following conditions are met:

  • You create a Client SSL profile that does not inherit the certificate, key, and chain certificate settings from the parent profile.
  • You upgrade to BIG-IP 11.5.1 (HF6 or later), 11.5.2, 11.5.3, or 11.6.0.

Impact

The Client SSL profile uses the certificate, key, and chain certificate inherited from the parent profile.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms after upgrading:

  • Client SSL traffic to the affected virtual server fails.
  • The affected Client SSL profile uses the certificate, key, and chain certificate settings inherited from the parent profile.
  • The affected Client SSL profile's inherit-certkeychain option has changed to true.

    For example:

    tmsh show ltm profile client-ssl example_ssl | grep inherit
    inherit-certkeychain true

Workaround

To work around this issue, you can manually modify the /config/bigip.conf configuration file and edit the affected Client SSL profile.

Impact of workaround: F5 recommends performing the following workaround during a maintenance window.

  1. Log in to the command line of the affected BIG-IP system.
  2. To create a backup copy of the /config/bigip.conf file, type the following command:

    cp /config/bigip.conf /config/bigip.conf.507109

  3. Use a text editor to open the /config/bigip.conf file.
  4. Locate the affected Client SSL profile and modify the inherit-certkeychain true line to inherit-certkeychain false.

    Example affected Client SSL profile configuration:

    ltm profile client-ssl /<partition>/<profile name> {
        app-service none
        cert /<partition>/<certificate name>.crt
        cert-key-chain {
            Test {
                cert /<partition>/<certificate name>.crt
                key /<partition>/<key name>.key
            }
        }
        chain none
        defaults-from /<partition>/<parent profile name>
        inherit-certkeychain true     
        key /<partition>/<key name>.key
        passphrase none
    }

    Example updated Client SSL configuration:

    ltm profile client-ssl /<partition>/<profile name> {
        app-service none
        cert /<partition>/<certificate name>.crt
        cert-key-chain {
            Test {
                cert /<partition>/<certificate name>.crt
                key /<partition>/<key name>.key
            }
        }
        chain none
        defaults-from /<partition>/<parent profile name>
        inherit-certkeychain false    
        key /<partition>/<key name>.key
        passphrase none
    }

  5. Save the changes to /config/bigip.conf file.
  6. To load the updated configuration, type the following command:

    tmsh load /sys config

Important: Traffic processing will temporarily be disrupted while the configuration loads.
