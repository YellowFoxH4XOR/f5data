Known Issue

BIG-IP ASM JavaScript injection features (CSRF and CSHUI) may not be injected properly.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is configured for JavaScript injection features such as CSRF or CSHUI.
  • A response page from the origin web server contains an apostrophe or quotations marks.

    For example, an HTTP response containing the following code excerpt is susceptible to this issue:

    <!DOCTYPE html>
    <html><head><TITLE>SAM's PAGE</TITLE></head>
    <body>HTML GOES HERE!<a href="/index.php?bob=12345"> param- reload </a>
    </body>
    <!-- This page contains an apostrophe in the title tag, RESULT: NO CSRF Script Injected-->
    </html>

Impact

This issue may result in irregular rendering or non-rendering of web resources.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • JavaScript in HTTP responses may not function correctly.
  • The web application may malfunction or fail to render properly.
