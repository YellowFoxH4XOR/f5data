Issue

Error Message

err zrd[7256]: Zone <zone_name> in file <zone_file> contains errors: dns_rdata_fromtext: <zone_file>: near <GTM_hostname>: bad name (check-names)..

In this error message, note the following:

  • <zone_name> is the name of the DNS zone with which the error message is associated.
  • <zone_file> is the name of the DNS zone file with which the error message is associated.
  • <GTM_hostname> is the host name of the BIG-IP GTM system that contains the underscore ( _ ) character.

For example:

err zrd[7256]: 01150213:3: Zone 'example.com.' in file 'db.external.example.com.' contains errors: dns_rdata_fromtext: db.external.example.com.:1: near 'GTM_1.example.com.': bad name (check-names). dns_rdata_fromtext: db.external.example.com.:2: near 'GTM_1.example.com.': bad name (check-names). zone example.com/IN: loading from master file db.external.example.com. failed: bad name (check-names). zone example.com/IN: not loaded due to errors..

Message Location

You may encounter this message in the following location:

  • The /var/log/gtm file

Description

This message occurs when the following conditions are met:

  • The host name of the BIG-IP GTM system contains the underscore ( _ ) character.
  • The Domain Validation setting is set to Strict.
  • You create a wide IP object.

 

By default, the BIG-IP GTM system does not allow the use of underscore ( _ ) characters in wide IP names, or in the BIG-IP GTM system's host name. If the BIG-IP GTM system's host name includes an underscore character, the ZoneRunner utility fails to create DNS zones and the BIG-IP GTM system logs an error message.

Impact

The ZoneRunner utility fails to create DNS zones.

Recommended Actions

You can either re-configure the BIG-IP GTM host name without the underscore character, or you can configure the BIG-IP GTM system to accept underscore characters by changing the Domain Validation setting to Allow Underscores. For more information, refer to K14926: Configuring the BIG-IP GTM system to accept underscore characters (11.x).

Note: After setting Domain Validation to Allow Underscores you must manually add DNS zones that were not created (when the Domain Validation setting was set to Strict). Alternatively, you can delete and re-create the wide IP object to trigger the zrd process to automatically create the DNS zone and zone file.
