Known Issue

A network access tunnel configured with split tunneling may not honor the proxy configuration.

This issue occurs when all of the following conditions are met:

  • The network access resource has split tunneling configured
  • The split tunneling configuration does not have a DNS Address Space configured
  • The Network access resource is configured with a client proxy

Impact

Network traffic that should be directed to a proxy is directed through the network access tunnel.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • All network traffic is directed through the network access tunnel

Workaround

To work around this issue, you can populate the DNS address space text box. To do so, perform the following procedure:

Impact of workaround: Inserting a DNS entry in split tunneling may affect system performance due to increased communication with DNS.

  1. Log on to the Configuration utility.
  2. Click Access Policy.
  3. Click Network Access.
  4. Click the name of the network access resource you want to edit.
  5. Click the Network Settings tab.
  6. In the DNS Address Space: DNS text box, enter the following content:

    localhost
  7. Click Add.
  8. Click Update.
  9. Click Apply Access Policy.
  10. Click Apply Access Policy.
