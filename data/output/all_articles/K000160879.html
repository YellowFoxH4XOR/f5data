K000160879: Why is the http/2 default setting for maximum concurrent connections set to 10?

Type
Support Solution
Published
2026-04-17
Updated
2026-04-17
Applies to
  • BIG-IP
  • BIG-IP LTM: 21.0.0, 17.1.3, 17.1.2, 21.0.X, 17.5.0, 17.5.1
Source
https://my.f5.com/manage/s/article/K000160879

Description

F5 has chosen not to default to a high value of concurrent connections in HTTP/2 streams. This is a result of an existing CVE related to "Rapid-Resets" (see: https://my.f5.com/manage/s/article/K000137106)

Environment

BIG-IP LTM

Virtual server using HTTP/2 Profiles.

Cause

Functioning as designed.

Answer/Recommended Actions

Please follow the recommendations in the referenced article:

  1.  Do not use HTTP/2
  2. If required to use HTTP/2:
    1. Follow the mitigation steps in the attached article.

Additional Information

K000137106: HTTP/2 vulnerability CVE-2023-44487
