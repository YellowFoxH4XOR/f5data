K22650515: Updating BIG-IP IP geolocation database using BIG-IQ

Type
Knowledge
Published
2020-04-23
Updated
2025-09-25
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.1.0
Source
https://my.f5.com/manage/s/article/K22650515

Topic

You should consider using this procedure under the following condition:

  • You want to update IP geolocation database on the BIG-IQ managed BIG-IP devices.

Description

The IP geolocation database on the BIG-IP system is used to source data about the origin of an IP address. Beginning in BIG-IQ 7.1.0, you can update and manage the IP geolocation database stored on the managed BIG-IP system using the BIG-IQ GeoIP Database Management utility. Prior to the update, you need to obtain the latest database in the GeoLocationUpdates container on the MyF5 Downloads site.

Note: The IP Geolocation Pulse database requires at least 900 MB of system memory. Ensure you provision sufficient system memory when updating or migrating to the GeoIP Pulse database. For more information, refer to ID 1070841.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IQ system.

Procedures

  • Downloading the latest IP geolocation database
  • Adding IP geolocation database files to the BIG-IQ system
  • Updating IP geolocation database on the managed BIG-IP devices

Downloading the latest IP geolocation database

You can download the latest compatible IP geolocation database for the managed BIG-IP devices from MyF5 Downloads site. To do so, perform the following procedure: 

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Access the MyF5 site.
  2. Go to Resources > Downloads.
  3. In Account, if you have more than one MyF5 account, select the account you want.
  4. Select the check box to agree with the End User License Agreement and Product Terms.

    Note: The check box displays only when F5 does not yet have a record of you accepting these agreements.

  5. In Group, select the product family you want. In this case, you should select BIG-IP.
  6. In Product Line and Product Version, select the product and version you want. For example, BIG-IP v17.x / Virtual Edition with Traffic Management Operation System (TMOS) for Product Line and 17.0.0 for Product Version.
  7. Under Select a product container, select the product container you want. In this case, you should select GeoLocationUpdates_Pulse.
  8. Under Select a download file, select a file that you want to download. In this case, you should select the ip-geolocation file with file extension .zip. For example, ip-geolocation-v2-2.0.0-20230220.27.0.zip.

    Note: You can download only one file at a time.

  9. At the bottom of the page, in Download locations, select the location nearest you.
  10. Select Download.
  11. After the system finishes downloading the first file you selected, return to the Select a download file section, and then select the next file you want to download. In this case, you should select the MD5 file of the ip-geolocation file you have downloaded from previous steps. For example, ip-geolocation-v2-2.0.0-20230220.27.0.zip.md5.
  12. Repeat the steps 9 through 10 to download the MD5 file.

Adding IP geolocation database files to the BIG-IQ system

Once you have the IP geolocation ZIP and MD5 files downloaded, you can add them to the BIG-IQ GeoIP Database Management utility. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ user interface.
  2. Select the Devices tab.
  3. Go to GEO-IP DATABASE MANAGEMENT > DATABASE FILES.
  4. Select Add GeoIP Database.
  5. For .zip File, select Choose File and select the ip-geolocation ZIP file you have downloaded.
  6. Select Upload.
  7. For .md5 File, select Choose File and select the ip-geolocation MD5 file you have downloaded.
  8. Select Upload.
  9. Select Save & Close.

Updating IP geolocation database on the managed BIG-IP devices

You can update the IP geolocation database on the managed BIG-IP devices with the database files on the BIG-IQ system. To do so, perform the following procedure.

Note: In order to have the BIG-IQ system to initiate the update script on target BIG-IP devices running on version 13.0.0 and later, you must enable Advanced Shell Access for the admin user on the target BIG-IP devices. For more information, refer to K12029: Accessing the TMOS Shell.

Impact of procedure: The IP geolocation services on the target BIG-IP device may be briefly interrupted while the database is being updated.

  1. Log in to the BIG-IQ user interface.
  2. Select the Devices tab.
  3. Go to GEO-IP DATABASE MANAGEMENT > DEVICES.
  4. Select the check box in front of the BIG-IP device name you want to update.

    Note: The database update is not a shared object in the BIG-IP device group. To update all members in a device group, you need to select all devices in your device group configuration.

  5. Select Update.
  6. For Database Files, select Latest.
  7. For Devices, review and verify the selected devices.
  8. Select Save & Close.
  9. To verify the update status, go to GEO-IP DATABASE MANAGEMENT > UPDATE HISTORY.
