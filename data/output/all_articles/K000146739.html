Description

  • The process to view a zone's details for the F5 Distributed Cloud (XC) DNS

Environment

  • F5® Distributed Cloud
  • DNS

Answer/Recommended Actions

To view the details for a DNS zone:

  1. To view the details for a DNS zone, click the DNS Management > Domain Management > DNS Management to go to the dashboard
  2. In that dashboard, you can confirm the type of the zone (primary, secondary), the deployment status, and the name servers
  3. In the table, click on the Actions menu (...) for the domain name/zone for which you want to see details and click Manage Configuration.
  4. Click on View Configuration under DNS Zone Configuration
  5. You can view information about the zone, such as its SOA Record Parameters, serial number, and Resource Record Sets
    • You also can change some details about the zone and its records, such as the Record Set, the record name, and the list of IPv4 addresses.
