K000136063: /var/log disk is full due to asm_config_event_dispatcher.log

Type
Support Solution
Published
2023-09-01
Updated
2023-09-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136063

Description

/var/log directory is full with large asm_config_event_dispatcher.log file. After deleting the file from the directory, it is filling up again pretty fast.

Environment

  • ASM
  • asm_config_server.pl
  • disk full

Cause

asm_config_server.pl is constantly crashing, generating excessive logs.
 

 Recommended Actions

1. Use command below to check asm_config_event_dispatcher.log file size.

Example:
# du -a /var/log | sort -rh | head -n 30

 

2889840 /var/log

2664700 /var/log/ts

2645004 /var/log/ts/asm_config_event_dispatcher.log <---

 

2. Check if ASM log is filled with errors like the example below.

Aug 16 16:14:22 test.sa crit perl[22468]: 01310027:2: ASM subsystem error (asm_start,F5::NwdUtils::Nwd::log_failure): Watchdog detected failure for process. Process name: asm_config_server.pl, Failure: Memory Size reached a threshold (detected memory usage: 678674432, threshold: 536870912).

 

3. Make a back-up copy of the /etc/ts/tools/asm_config_server.cfg file and /etc/ts/tools/nwd.cfg file with the following command:

#cp -p /etc/ts/tools/asm_config_server.cfg /var/tmp/asm_config_server.cfg.bak

#cp -p /etc/ts/tools/nwd.cfg /var/tmp/nwd.cfg.bak

 

4. Edit /etc/ts/tools/asm_config_server.cfg file using a text editor (example: vi)
 

5. Search for "MaxMemorySize"

MaxMemorySize=471859200 <<<< (The value could be different from the example here)

 

6. Extend the MaxMemorySize value to something like the following:

MaxMemorySize=1073741824

 

7. Save and return to the CLI
 

8. Repeat step number 4 - 7 for /etc/ts/tools/nwd.cfg file

 

9. Restart the asm_config_server processes with the command below:

#pkill -f asm_config_server

 

Note: The workaround may only work on certain platforms and configurations, please monitor the device for a while after the workaround is performed.
