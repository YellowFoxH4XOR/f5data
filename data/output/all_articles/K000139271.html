Description

When below FIPS card sync is executed either using tmsh or fips utility, sync status shows successful but keys are not restored or shown in remote unit.

tmsh run /util fips-card-sync -v <peer IP> 

fipscardsync -v <peer IP address>

Environment

  • BIG-IP HA
  • FIPS Enabled
  • One HA pair has no keys and trying to restore from peer unit

Cause

Executing fips-card-sync command only sync's master key but doesn't sync or restore all keys.

Recommended Actions

After running fips-card-sync you must perform config-sync to restore the keys.

 

This can be done by performing the following steps :

First reset and re-init FIPS on a unit where there are no Keys and lets call it unit 'B', this will set security domain and SO password

Note : you may need to stop services by running "tmsh stop sys service all"  before executing below commands, which will bring all your services down and should be performed during maintenance window. 

Important : Running this command deletes all keys in the HSM and makes any previously exported keys unusable.

tmsh run util fips-util -v -f reset

tmsh run util fips-util -v -f init 

tmsh restart sys service all

Sync fips from 'A' to the 'B' box

tmsh run /util fips-card-sync -v <peer IP>

check master key in both device, it should be same

tmsh show sys crypto master-key

Then you need to perform config-sync to restore the keys
