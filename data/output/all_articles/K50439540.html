Description

Snmpwalk returns invalid value for ltmPoolMemberAddr (OID:.1.3.6.1.4.1.3375.2.2.5.3.2.1.3)

  • snmpwalk query executed on the localhost (127.0.0.1)
  • snmpwalk output shows invalid output
  • Output shows the format is wrong - it use STRING and not Hex-STRING
    snmp output invalid example: 
    ltmPoolMemberAddr."/Common/tmp443-T2.Site1.com"."/Common/T2.Site1.com".443 = Hex-STRING: 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 
ltmPoolMemberAddr."/Common/tmp443-T2.Site1.com"."/Common/_auto_10.10.0.2".443 = STRING: "¦qi"                    <<<<
ltmPoolMemberAddr."/Common/tmp443-Ser1.site2.com"."/Common/_auto_10.10.0.3".443 = Hex-STRING: B9 71 C5 84
ltmPoolMemberAddr."/Common/tmp443-t5-test5.t-test3.com"."/Common/_auto_10.10.0.4".443 = Hex-STRING: C1 C9 8A BE
ltmPoolMemberAddr."/Common/tmp443-t5-test5-test.t-test3.com"."/Common/_auto_10.10.0.4".443 = STRING: "¦E¦¦"      <<<<

Environment

  • Using SNMP v3 or v2c - i.e.:
    snmpwalk -v2c -Of -c public localhost .1.3.6.1.4.1.3375.2.2.5.3.2.1.3

Cause

Bug ID 1021861: Snmpwalk command returns invalid value for ltmPoolMemberAddr
