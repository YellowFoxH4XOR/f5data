Description

The BIG-IP system fails to authenticate TACACS+ users. When reviewing the log entries for TACACS+ login failures in /var/log/secure, you are observing the error messages similar to the following examples: 

Jan 01 01:02:03 bigip.example.com notice httpd[13231]: pam_tacplus: pam_tacplus: user john_smith successfully authenticated
Jan 01 01:02:03 bigip.example.com err httpd[13231]: tac_author_read: short author body, 2672 of 6875: Operation now in progress
Jan 01 01:02:03 bigip.example.com err httpd[13231]: pam_tacplus: TACACS+ authorisation failed for [john_smith]

Environment

  • BIG-IP 12.X-16.X is configured to use the TACACS authentication
  • TACACS user  is part of a group where the combined length of the Attribute-Value Pairs (AVP) is greater than the largest TCP segment the TACACS server is able to send.

Cause

Bug ID 1032077: TACACS authentication fails with tac_author_read: short author body

Recommended Actions

Reduce the number of attributes of the TACACS group or user on TACACS Server Side, that way the reply is not as big.
