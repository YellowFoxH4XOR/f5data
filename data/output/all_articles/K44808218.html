Description

You are unable to make firewall configuration changes with a user that has the Firewall Administrator role

You may see messages similar to the one below in your logs when changes are attempted: 
Access Denied: user (<username>) does not have modify access to object (fw_uuid_config)

Environment

  • BIG-IP AFM
  • User with Firewall Administrator Role

Cause

This issue is caused by ID 757279

Recommended Actions

Upgrade to a version where this issue has been fixed

Note: See Related Content for more information on versions where this issue has been fixed.
