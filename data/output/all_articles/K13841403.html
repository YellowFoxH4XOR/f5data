Known Issue

The BIG-IP system may respond with an incorrect value for the sysIfxStatHighSpeed SNMP management information base (MIB) object.

This issue occurs when all of the following conditions are met:

  • You have one of the following BIG-IP platforms:

    • BIG-IP 2000 / 4000 Series
    • BIG-IP 10000 Series
    • BIG-IP i2000 / i4000 Series
    • BIG-IP i5000 / i7000/ i10000/i15000 Series
    • VIPRION B4000 Series blade
  • You perform an SNMP query for the sysIfxStatHighSpeed MIB object of a 10G, 40G, or 100G network interface on the BIG-IP system.

Impact

The system does not report the correct active media speed of a 10G, 40G, or 100G network interface.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • An SNMP query on the sysIfxStatHighSpeed MIB object returns an incorrect value. For example, your BIG-IP system may return a value that appears similar to the following output with regards to a 10G network interface, instead of the value of 10000:

    F5-BIGIP-SYSTEM-MIB::sysIfxStatHighSpeed."2.1" = Counter64: 1410

Resolution

Status

F5 Product Development has assigned ID 691491 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table.

Workaround

There is no workaround for this issue. You can query the sysInterfaceMediaActiveSpeed SNMP MIB object instead.

Impact of procedure: Performing the suggested procedure should not have a negative impact on your system.
