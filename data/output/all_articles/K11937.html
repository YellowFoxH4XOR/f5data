Known Issue

This is the result of a known issue. When multiple users employ the same computer to access an F5 VPN device, each user will be prompted to install the F5 VPN installer control. Users with limited rights on the computer may not be able to properly install the VPN installer control. This issue will occur the first time the user accesses the VPN device, or when the VPN installer control is removed from the computer.

F5 Product Development tracked this issue as ID 294510 (formerly CR141364) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

F5 Product Development tracked this issue as ID 317764 (formerly CR141364-1) and it has been fixed in cumulative hotfix HF-610-3-1, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about downloading software from F5, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

F5 Product Development tracked this issue as ID 226381 (formerly CR141364-2) for BIG-IP and it has been fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

Workaround

You can work around this issue by temporarily granting elevated permissions on the user's computer to allow installation of the VPN installer control.
