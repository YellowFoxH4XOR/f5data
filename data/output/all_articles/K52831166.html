K52831166: Error message when assigning an address list or port list to a virtual server: 01071b77:3: The value (inline address) is invalid. Valid domain is set on traffic-matching-criteria.route-domain

Source

Description
When modifying or creating a new virtual server in a non-default route domain, if you try to apply an address list or a port list then you get an error message: 01071b77:3: The value (inline address) is invalid. Valid domain is set on traffic-matching-criteria.route-domain

Environment

  • Virtual server in non-default (non-zero) route domain
  • Address list or port list

Cause
Bug ID 758655: TMC does not allow inline addresses with non-zero Route-domain.

Recommended Actions
Upgrade to a fixed version BIG-IP software

Additional Information
Address and port lists are configured under the Shared Objects tab in BIG-IP LTM version 14 or later.
