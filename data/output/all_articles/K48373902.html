K48373902: [warn] message in error log: an upstream response is buffered to a temporary file while reading upstream

Type
Support Solution
Published
2020-01-15
Updated
2025-04-01
Applies to
  • NGINX Products
  • NGINX Plus
Source
https://my.f5.com/manage/s/article/K48373902

Description

The NGINX Plus error log contains warnings like this:

2020/01/01 11:11:54 [warn] 1234#1234: *123 an upstream response is buffered to a temporary file /var/cache/nginx/proxy_temp/1/00/0000000001 while reading upstream, client: xxx.xxx.xxx.xxx, server: example.com, request: "GET /image.png HTTP/1.1", upstream: "http://127.0.0.1:8080/image.png", host: "example.com", referrer: "http://example.com"

Environment

  • NGINX Plus acting as reverse proxy (proxy_pass, fastcgi_pass)

Cause

The warning message indicates that the response was buffered to disk because it doesn't fit into configured memory buffers.

Recommended Actions

You have three options depending on your use case:

    Option 1: Increase buffers

    You can adjust buffers to fit complete upstream response. If the maximum possible response size is unknown, we recommend to increase both parameters by factor of two until warnings stop appearing.

    proxy_buffers 16 16k;
    proxy_buffer_size 16k;

      Option 2: Disable buffering

      In case the response is too large (for example, 5 GB movie), you can disable buffering of the response completely to stream response directly to client.

      proxy_buffering off;

        Option 3: Ignore these warnings

        These warning are harmless and you can ignore them, unless you observe high disk I/O usage.
