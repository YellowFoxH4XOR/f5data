Description

When you create a virtual server, the default setting for VLAN and Tunnel Traffic is All VLANs and Tunnels which specifies that the virtual server is enabled on all VLANs and tunnels configured on the system. If you changed the default setting when you created the virtual server to enable or disable certain VLAN or tunnel traffic, you can change back to the default setting of All VLANs and Tunnels using the TMOS Shell (tmsh) if desired.

Environment

  • BIG-IP LTM

Cause

None.

Recommended Actions

To reset the Vlans and Tunnels option to All VLANs and Tunnels using tmsh, perform the following steps:

  1. Log in to the tmsh utility by typing the following command:

    tmsh 

  2. Use the following syntax to reset the Vlans and Tunnels option to All VLANs and Tunnels:

    modify ltm virtual <virtual server name> vlans-disabled vlans default

    For example:

    modify ltm virtual MyVirtualServer vlans-disabled vlans default

  3. Save the configuration by typing the following command:

    save /sys config

Note: if you also want to reset the Vlans and Tunnels option to All VLANs and Tunnels on NAT and SNAT, you can refer to K68256422: Using the tmsh utility to enable a SNAT or NAT object on all VLANs or tunnels on the system
