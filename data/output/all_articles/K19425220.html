Description

Connecting to an HTTP/2 virtual server using curl with --http2 option does not work.  

Environment

  • Virtual server listening on port 80
  • HTTP/2 profile
  • Testing with curl --http2

Cause

Connection is failing because the upgrade from HTTP 1.1 is not supported in non-TLS traffic.
BIG-IP support for h2c only includes the direct method, in which clients have prior knowledge of the server's support for h2c.

Recommended Actions

Test the virtual server using curl with --http-prior-knowledge option. It sends HTTP/2 request from the start, without relying on upgrade header.
