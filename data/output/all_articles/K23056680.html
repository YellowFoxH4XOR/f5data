Description

The F5 Big-IP is not able to load the configuration file with the following error message 
010712de:3: Virtual Server (/Common/vs-123) requires serverssl profile (resource /Common/resource/resource) for this assignment
Environment

The following conditions must be met

  • The error message occurs after a new software upgrade.
  • The mentioned error message will be displayed when running the following command
tmsh load sys config verify

Cause

The new software requires to mentioned Virtual Server to have a server ssl profile. Without the server ssl profile, it considers the configuration file to have an error and will not load it.

Recommended Actions

You will need to manually edit the bigip.conf file and add a server ssl profile to the mentioned Virtual Server. Please follow the steps below.

  • SSH to the device.
  • Make a backup of bigip.conf file as below.
/config/bigip.conf
  • Edit bigip.conf file. You can use nano, vim or vi to do this.
  • Find the Virtual Server which is having the issue. In this example, it is "vs-123"
  • Once you have found the impacted Virtual Server, add a serverssl profile below "profiles {". The configuration text should look like this.
    profiles {
        /Common/serverssl {
            context serverside
        }
