K70434315: Connection reset for some POST requests

Description

Clients have reported that some POST requests sent to the BIG-IP virtual server are reset. This issue occurs when the client's requests include blank x-forwarded-for HTTP headers.

Environment

  • Client sending POST request to Virtual Server
  • HTTP profile
  • X-forwarded-for

Cause

The virtual server resets the clients' POST requests with blank x-forwarded-for HTTP headers due to an 'Unknown Reason'. This issue is related to Bug ID 985433.

Recommended Actions

To resolve this issue, disable the X-forwarded-for setting in the HTTP profile and apply the following Tcl iRule:

when HTTP_REQUEST { HTTP::header replace X-Forwarded-For [IP::remote_addr] }


Additional Information

Bug ID 985433 states that the insertion of the X-Forwarded-For HTTP header can fail, causing the client's connection to be reset.
