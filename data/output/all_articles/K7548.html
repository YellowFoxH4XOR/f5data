Known Issue

This is the result of a known issue. If you use the big3d -c option to specify a custom certificate authority (CA) certificate chain depth value, the BIG-IP system does not correctly evaluate the supplied arguments. As a result, the requested certificate depth value is not honored (the default value of 0 (zero) is used) and certificate authentication using non-self-signed SSL certificates will fail.

F5 Product Development tracked this issue as CR80361, and it was fixed in BIG-IP 9.4.2 for the 9.4 software branch. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator Release Notes. This issue still exists in the 9.3 software branch. F5 Product Development is tracking this issue for the 9.3 branch as CR80361-1.

Workaround

To work around this issue, you can modify the big3d startup script to specify the big3d -c option twice. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Change directories to the /etc/bigstart/scripts/big3d directory by typing the following command:

    cd /etc/bigstart/scripts/big3d

  3. Make a copy of the big3d script file by typing the following command:

    cp big3d big3doriginal

  4. Using a text editor, edit the big3d script file.
  5. Locate the following line:

    exec /usr/sbin/big3d

  6. Change the line to appear similar to the following example:

    exec /usr/sbin/big3d -c <certificate_depth> -c <certificate_depth>

    Note: The -c <certificate_depth> option must be specified twice. For more information, refer to K7547: The Big3d.CertificateDepth bigdb variable is not honored.

    The value of <certificate_depth> must be a number from 0 to 9, which represents the maximum depth to be followed in the signing chain when validating certificates.

    Note: For a BIG-IP to verify only self-signed certificates, <certificate_depth> may be set to the default value of zero. For a BIG-IP to verify certificates that are directly signed by a root CA, the value must be at least 1. For BIG-IP to verify certificates signed by a CA whose certificate is signed by a root CA, the value must be at least 2. If you are unsure about the depth of your CA chain, set the value to 9.

  7. Save the changes to the file.
  8. Set the Big3d.CertificateDepth bigdb variable to the same value as you configured in Step 6 by typing the following command:

    b db Big3d.CertificateDepth <value>

  9. Restart the big3d agent by typing the following command:

    bigstart restart big3d
