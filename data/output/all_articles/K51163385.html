Description

When viewing device groups from Device Management  ››  Overview in Configuration Utility,
order of displayed device group sometimes may differ between HA devices.
For example, when you create sync-failover device group named "failover",
"device_trust_group" device group is displayed on the top from active device, while "failover" device group is displayed on the top from standby device.

Environment

  • BIG-IP HA
  • Sync-Failover Device Groups

Cause

This is by design.
The display order of device group depends on mcpd database in each device.

Recommended Actions

No action is required.

None
