K26373642: APM configuration loading failure with error that AD server ''is not a valid IP address or hostname''

Source
https://my.f5.com/manage/s/article/K26373642

Description
After upgrade, configuration can not be loaded with similar error message below,

slot1/LTM1 load_config_files "/usr/bin/tmsh -n -g load sys config partitions all " - failed. -- Loading schema version: 12.1.5.2 Loading schema version: 13.1.3.6 01071d05:3: apm-ad.excample.com is not a valid IP address or hostname. Unexpected Error: Loading configuration process failed.

Environment

  • APM
  • AD Server
  • Software Upgrade

Cause
This is related to ID 742375. 
Prior to BIG-IP APM V13.1.x, there is no enforcement validation is performed on domain-controller hostname or IP address. 

Recommended Actions

Make sure the IP address of AD server of domain-controller is reachable or AD server's FQDN of domain-controller is valid.

apm aaa active-directory /Common/APM_AD_SERVER {
    admin-encrypted-password $M$xxxxxxxxx
    admin-name apm-admin
    domain apm1.example.com
    domain-controller apm-ad.example.com  
    use-pool disabled
}
