K52112750: Users unable to connect to VPN cannot open the logon page

Support Solution
Published
2021-02-01

Applies to

  • BIG-IP APM: 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.0.0, 13.1.0, 13.0.1, 13.X.X, 13.1.X
Source
https://my.f5.com/manage/s/article/K52112750

Description
All users fail to access VPN and can not load the logon page via the browser or the Edge client. 

  • Can ping the IP of the virtual server and the virtual server and APM profile seems fine
  • packet capture shows that the TCP and SSL session have established, however, the virtual server IP (VIP) resets the session after the first client application data with reason: [F5RST: Access encountered an error (Not found)].

Environment

  • BIG-IP APM
  • VPN

Cause
Suspect the running config/the binary configuration has some issue and need to be reloaded. 

Recommended Actions

Force MCPD reload per K13030: Forcing the mcpd process to reload the BIG-IP configuration

None
