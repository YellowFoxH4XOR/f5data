K000138838: Unable to delete old iApps

Type
Support Solution
Published
2024-03-27
Updated
2024-03-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000138838

Description

You would like to delete old iApps but you are unable to due similar errors:

01070283:3: The profile (/public/working/working_iapps_cookie_persistence_profile) is currently associated with one or more virtual servers or transport configs.

01070283:3: The profile (/public/working/working_iapps_source_address_persistence_profile) is currently associated with one or more virtual servers or transport configs

Environment

  • BIG-IP
  • iApps

Cause

The objects created via old iApps are still in use and prevent removal of the old iApps

Recommended Actions

Remove all object with references to the old iApps for example:

  • Virtual Servers
  • Profiles
  • Policies
  • Nodes
  • Pools

Additional Information

None
