Description

  • A login page is not displayed even though it is configured.
  • The session fails.

Environment

  • APM Access policy
  • iRule applied to enable clientless mode

Cause
Clientless mode is enabled. Access policy items requiring user input are ignored. These include Logon Page, End Point Security, Message Box, Decision Box, and others.

Recommended Actions

This is working as intended. If a Logon Page should be displayed, clientless mode has to be disabled.
