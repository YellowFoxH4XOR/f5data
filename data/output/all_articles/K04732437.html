Known Issue

BIG-IP APM may incorrectly log a blank user name.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy is configured with multiple logon pages.
  • The Username field on a subsequent logon page is specified as Read Only.

Impact

BIG-IP APM may fail to log the Username value.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Exported CSV reports contain break (<br/>) tags, and the recorded value for the Username field is blank (Username ' ').
  • The BIG-IP APM system logs messages with blank user names in the /var/log/apm file, similar to the following example:

    notice apd[<pid>]: 01490010:5: f4a3def9: Username '<username_value>'
    notice apd[<pid>]: 01490010:5: f4a3def9: Username ''
