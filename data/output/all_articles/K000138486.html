Description

curl -vk -u admin https://&lt;partition_IP/name&gt;:8888/restconf/data/openconfig-interfaces:interfaces/interface=1%2F1.0/state --header 'Accept: application/yang-data+json'

...

    "oper-status": "UP",
    "counters": {
      "in-octets": "2740670582",
      "in-unicast-pkts": "8639",

Cause
