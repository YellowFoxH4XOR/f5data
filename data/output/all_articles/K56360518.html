K56360518: BIG-IQ having high CPU utilization with high disk space utilization at /var

Type
Support Solution
Published
2021-08-10
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K56360518

Description

Your BIG-IQ system is experiencing high CPU utilization for jre-1.8.0-openjdk.x86_64/bin/java. You will see this when running the top command with the output as below:
PID  UID       PRI  NI    SIZE    RSS  SHARE S %CPU %MEM          TIME CPU    SWAP COMMAND
3198  root       20   0    5.9M   1.7M   1.3M S  0.0  0.0   00:00:00.01   5       0 su elasticsearch -s /bin/bash -c export JAVA_HOME=/usr/lib/jvm/jre-1.8.0-openjdk.x86_64;export ES_JAVA_OPTS='-Xms10000m -Xmx1000
3242  elasticsearch  20   0   43.7G  12.5G   1.5G S 47.5 39.6 1288:12:46.82   5       0 /usr/lib/jvm/jre-1.8.0-openjdk.x86_64/bin/java -Xms10000m -Xmx10000m -Dio.netty.recycler.maxCapacityPerThread=0 -verbose:gc -XX:

Other than the high CPU utilization, disk space is highly utilized in /var. Further check shows that elasticsearch in /var is taking a lot ot space. You can check further on elasticsearch taking up space based on article K15318711.

Environment

  • BIG-IQ
  • BIG-IQ shows high CPU utilization
  • top output shows jre-1.8.0-openjdk.x86_64/bin/java has high utilization
  • elasticsearch in /var is taking up high disk space

Cause

High CPU utilization is caused by UNASSIGNED shards.

Recommended Actions

You will need to delete the UNASSIGNED shards issue to reduce the high CPU utilization. Once the UNASSIGNED shards has been deleted, CPU utilization will be reduced.

  1. Login to the BIG-IQ Command Line.
  2. Download and install the script to clean up UNASSIGNED shards from K92678530.
  3. Once the script has been installed, run the script with the following command:
    python2.7 /shared/scripts/delete_es_indices.py --elastic_ips=localhost:9200 --delete_index --debug
  4. Review the UNASSIGNED shards with the following command:
    curl -s localhost:9200/_cat/shards?v
  5. Restart the retention daemon to clear the shards. Run command:
    tmsh restart sys service appiqconfig
  6. Review the UNASSIGNED shards from step (4).
    Important: Deleting UNASSIGNED shards will take some time. Depending on how many UNASSIGNED shards you have in your BIG-IQ system, it might take from 12 hours to 24 hours to clear the UNASSIGNED shards
Additional Information

None.
