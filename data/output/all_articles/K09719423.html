Description
Currently an SNMP MIB to poll Per-Request Policy statistics, remotely or otherwise, does not exist at this time.

Environment

  • BIG-IP APM
  • Remote monitoring of APM per-Request policy needed.

Cause
None

Recommended Actions

Per-Request Policy statistics can be obtained from the BIG-IP command line tool tmctl:
  1. From SSH command line (bash), type:   tmctl perrequest_policy_stat
The resulting output will provide policy statistics in a table format.
