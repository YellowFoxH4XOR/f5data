Description

This article addresses an issue where LDAPS (LDAP over SSL) traffic fails to pass through a BIG-IP LTM virtual server. Client connections to the LDAPS VS do not complete while direct connections to the backend server (bypassing BIG-IP) work as expected

Environment

  • BIG-IP LTM
  • Virtual Server Type: Standard (SSL Bridge configuration)

Cause

Incorrect configuration: An HTTP profile was applied to a virtual server intended for LDAPS traffic. LDAPS  protocol (LDAP over SSL/TLS) is not HTTP-based. 

Answer/Recommended Actions

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  3. Click the affected LDAPS virtual server.
  4. In the Configuration section, locate the HTTP Profile setting.
  5. Remove the HTTP profile from the virtual server configuration.
  6. Click Update to save the configuration changes.
  7. Test LDAPS connectivity through the VIP to confirm the issue is resolved.
