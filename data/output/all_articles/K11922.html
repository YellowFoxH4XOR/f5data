Known Issue

This is the result of a known issue. Attempting to import an access policy into a BIG-IP APM device that is configured to use an alternate partition with a non-zero ID routing domain will fail. This issue occurs when the leasepool and client traffic classifier associate with the routing domain ID 0, regardless of the routing domain used by the active partition.    

F5 Product Development tracked this issue as ID 226891 (formerly CR142336) and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

In addition, this issue has been fixed for ID 324389 (formerly CR142336-1) in BIG-IP 10.2.0 in Hotfix-BIGIP-10.2.0-1755.1-HF1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
