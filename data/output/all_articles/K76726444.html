Known Issue

Using IP protocol 0 (hopopt) in a BIG-IP AFM firewall rule is not supported for IPv6 packets; however, beginning in BIG-IP AFM 14.0.0, the system supports IP protocol 0 (hopopt) for IPv4 packets in firewall rules.

This issue occurs when the following condition is met:

  • You try to configure a firewall rule with an IPv6 IP protocol 0 (hopopt).

Impact

The BIG-IP AFM system treats the protocol as IP protocol any, not hopopt for IPv6 traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You cannot configure the firewall rule IPv6 IP protocol 0 (hopopt).
