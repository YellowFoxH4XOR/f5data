Known Issue

This is the result of a known issue. When Virtual Server Discovery is set to enabled, no delete, the BIG-IP GTM will discover the virtual servers, but will not set the virtual server name for discovered VIPs.

F5 Product Development tracked this issue as CR69161 and it was fixed in BIG-IP 9.2.4 and 9.3.0. For information about upgrading, refer to the BIG-IP GTM release notes.
