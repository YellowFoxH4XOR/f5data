Description

Unreliable SIP calls.

  • SIP call drops or resets
  • Rapid changing of Source Port on server side connection

Environment

Relevant environmental factors specific to the topic

  • BIG-IP LTM Module
  • SIP configuration setup
  • iRule using a global variable
  • Source port changes

Cause

Using an iRule with TCL global variable results in CMP demotion on the virtual server.

Recommended Actions

Construct an iRule that is CMP compatible  per K13033: Constructing CMP-compatible iRules
 

Additional Information

Snat IP  changing source port consistently for SIP connection.  Virtual Server will be demoted because of iRule causing CMP demotion to use one TMM core so if any communication comes across a different TMM, TMM0 would change the source port because TMM doesn't know about the initial connection from a different TMM core because of the demotion.
