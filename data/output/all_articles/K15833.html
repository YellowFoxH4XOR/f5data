Known Issue

The BIG-IP APM system may be unable to import advanced customizations in an access policy.

This issue occurs when all of the following conditions are met:

  • The access policy is configured with advanced customizations to configuration files.
  • Two or more advanced customizations modify files associated with similar object types.

For example, if two different logon pages are configured in an access policy, and you make a different modification to a file for each logon page, exporting and importing the policy may result in the advanced customizations being lost.

Impact

Some advanced customizations are not saved to disk when you upgrade or import access policies.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After an upgrade, advanced customizations are not rolled forward correctly.
  • Advanced customizations are lost after you import or merge an access policy.
  • Access policy functionality is impaired after you upgrade the system or import an access policy.
