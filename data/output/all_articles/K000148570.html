Description

Answer / Recommended Actions

You cannot create a TCP load balancer on port 80 if other load balancers are already utilizing this port.

  • The system determines the appropriate load balancer for incoming requests on port 80 by examining the HTTP host headers.
    • A standard TCP load balancer lacks the capability to inspect HTTP headers.
    • Given that a tenant is typically assigned only one IP address by default, it becomes impossible to distinguish whether a request should be routed to your TCP load balancer or to one of the other load balancers.
    • Consequently, creating a TCP load balancer on port 80 is not permitted.
  • On the other hand, a TCP load balancer on port 443 can share an IP address and port with the same address, provided that SNI (Server Name Indication) is enabled. SNI offers a mechanism for directing traffic to the appropriate load balancer. Without enabling SNI on the TCP port 443 service, the load balancer will fail to function correctly.
  • Note: Contact your sales team or account manager to purchase additional IP addresses if you must have TCP load balancers on ports already in use.
