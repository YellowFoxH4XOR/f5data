Description

Unexpected or silent reboot of BIG-IP


Environment

BIG-IP


Cause

When observing similar log messages noted below, this issue is being caused by Bug ID 1040277: Syslog-ng issue may cause logging to stop and possible reboot of a system https://cdn.f5.com/product/bugtracker/ID1040277.html


/var/log/messages.*


Apr 16 13:54:59 hostname.example.com notice syslog-ng[2987]: Syslog connection broken; fd='64', server='AF_INET(10.0.0.232:5140)', time_reopen='60'


/var/log/restjavad.*.log


[WARNING][472][16 Apr 2023 13:55:28 UTC][8100/shared/publisher PublicationWorker] submitMessageToSubscribers failed for selfLink : https://localhost/mgmt/forwarder, method: POST. exception: com.f5.rest.common.RestRequestSender$HttpException: java.net.ProtocolException: status:404, body:{"code":404,"message":"","referer":"http://localhost:8100/cm/autodeploy/reboot-device","originalRequestBody":"{\"external\":\"mgmt/cm/autodeploy/reboot-device\",\"internal\":\"cm/autodeploy/reboot-device\",\"odata\":{\"port\":8100,\"internal\":\"cm/autodeploy/reboot-device\",\"adapterLink\":\"http://localhost:8100/mgmt/java-odata-adapter\"},\"port\":8100,\"isExplicit\":false,\"apiStatus\":\"NO_STATUS\"}","errorStack":[]}.


Recommended Actions

Ensure syslog-ng server configuration is valid, and that the server is reachable. If a remote server is not reachable remove it from the BIG-IP syslog configuration.
