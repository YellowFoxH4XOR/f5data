Issue

Old Behavior

BIG-IP 9.x and 10.x include Postfix, a third-party software. Postfix is a Mail Transport Agent (MTA), which delivers locally generated email messages from the BIG-IP system.

New Behavior

Beginning in BIG-IP 11.0.0, Postfix has been removed from BIG-IP software. The BIG-IP system uses ssmtp to perform mail forwarding to a mail host for locally generated email messages from the BIG-IP system.

F5 Product Development tracked this change as ID 367753.

Impact

A BIG-IP system that is upgraded from BIG-IP 9.x or 10.x to 11.0.0 or later, with a configuration that uses the Postfix method to deliver locally generated email messages from the BIG-IP system, no longer works. After the upgrade, the Postfix configuration file included on the customized user configuration set (UCS) archive is available, but the BIG-IP system no longer uses the file.
