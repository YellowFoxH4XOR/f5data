Description

On upgrading to later versions of V15, V16 and V17, ArcSight is not available as Formatted Logging Destination.

 

Existing ArcSight Destinations are visible.

 

Environment

None of Modules

  • AFM
  • ASM
  • SWG

Are installed.

Cause

ArcSight only works with these modules.

If none of these modules are installed, the option will not be visible.

 

Recommended Actions

Review your configuration.

Additional Information

This is by design.
