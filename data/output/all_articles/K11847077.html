Description

You want to configure API Protection with an authorization per-request policy

Environment

  • API Protection
  • Access Policy (per-request policy)
Cause

APM allows administrators to configure the type of authentication to use while creating a new API protection object.
Authorization can be 'HTTP Basic', 'OAuth' or empty.
System adds a gating-criteria when 'HTTP Basic' or 'OAuth' is selected.
But does not include it in case authorization is left empty and the subroutine in the per-request policy is added later.

Recommended Actions

Administrators should configure the subroutine gating-criteria with "expr { [ mcget {request.header.authorization} ] }".
For example:

subroutine-properties {
  /Common/api_prp_auth {
    gating-criteria "expr { [ mcget {request.header.authorization} ] }"
  }
}
