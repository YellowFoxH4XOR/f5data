Description

gzipMemoryLevel and gzipWindowSize are described as using kilobyte units in the Configuration Utility, but when viewing or setting either value from iControl REST, they use bytes.

Environment

  • BIG-IP LTM
  • HTTP Compression Profile
  • iControl REST

Cause

None

Recommended Actions

  • When configuring these values from the GUI, use kilobytes
  • When configuring these values from REST, use bytes; BIG-IP will round these input value to the nearest base-2 number in kilobytes

None
