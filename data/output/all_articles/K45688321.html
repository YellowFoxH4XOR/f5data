Description

  • Deploying an AS3 declaration that returns an error.
  • The error is for a missing resource which obviously exists.

Environment

  • An AS3 deployment.

Cause

  • A preceding syntax error.
  • This may be hidden inside a preceding iRule declaration which is BASE-64 encoded. Thus the root cause error may not be immediately evident and AS3 will not parse it correctly.
     

Recommended Actions

  1. Review preceding Declarations.
