Description

An IP Exception list is used to allow IPs that would otherwise be blocked per the configuration of the security policy. These would be setup for known legitimate traffic (called whitelists). For internal traffic, company uses  internal tools such as penetration tools, manual or automatic scanners, or web scraping tools.

Environment

  • Configuring IP Address Exceptions 

  • Application Security Policies

Cause

By default when an IP Exception list entry is created, it applies to the default Route Domain '0' only.

Recommended Actions

For each Route Domain, you will need to add an entry for the specific address or subnet. Examples for Route Domain 1:

  • Specific address: 192.168.1.1 255.255.255.255, would look like this: 192.168.1.1%1 255.255.255.255
  • Subnet: 192.168.10.0 255.255.255.0, would look like this: 192.168.10.0%1 255.255.255.0
