Description

Antivirus checking fails with the following error in /var/log/apm:

notice apmd[PID]: 01490113:5: /Common/<access policy>:Common:<session id>: session.check_software.last.av.item_1.errors is Failed to get 'last_scan'. code: -11 method: 1004 define: 'WAAPI_ERROR_COMPONENT_METHOD_NOT_SUPPORTED' description: 'Defines an error when a method call was made on a component that does not support it.'

Environment

  • BIG-IP APM
  • Virtual server
  • Access policy
  • Antivirus Check

Cause

Last scan isn't detected on client.

Recommended Actions

Open antivirus software and to do a full disk scan on client.
The operation of different software may be different, you need to refer to manual of antivirus software.

None
