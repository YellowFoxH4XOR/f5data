Known Issue

Server-side TCP connections may remain half-open if the client-side connection closes early.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server to use an iRule with the LB::reselect event.
  • An LB::reselect event is triggered and the BIG-IP system attempts a new connection on the server side.
  • The server closes the client-side connection before the BIG-IP system can complete the new server-side connection.

Impact

The half-open server-side connection will remain in the TMM connection flow table, regardless of timeout length or attempts by the server to close the connection.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Server-side connections remain in the BIG-IP system's connection table indefinitely.
