Topic

Auto-discovery is a process by which the BIG-IP GTM system automatically discovers virtual servers and links that are associated with defined BIG-IP systems. When you first enable virtual server or link discovery for a BIG-IP system, the BIG-IP GTM system searches for the resources on the target BIG-IP system, and adds them to the BIG-IP GTM configuration. When auto-discovery is enabled for a BIG-IP system, the BIG-IP GTM system polls the BIG-IP LTM big3d agent at the Auto-Discovery Request Interval setting. The Auto-Discovery Request Interval setting is 30 seconds by default.

However, the BIG-IP GTM system does not support auto-discovery for BIG-IP systems and virtual servers that use network address translation; if the target BIG-IP system or any of its virtual servers employ network address translation, the BIG-IP GTM system disables auto-discovery for that BIG-IP GTM server object The BIG-IP GTM system does not attempt to automatically discover links or virtual server objects for the target server, even those virtual servers for which address translation is not configured. In addition, the BIG-IP GTM system does not report any messages or alerts that log the change. For example, if the target BIG-IP virtual server IP addresses reside in a private network space, as defined by RFC1918, and are mapped to public IP addresses that are defined on a network device such as a firewall, the BIG-IP GTM system silently disables the auto-discovery for that BIG-IP GTM server object. Virtual server discovery still functions on BIG-IP GTM servers for which no translation address is configured.

If you plan to add BIG-IP systems with translated virtual servers to the BIG-IP GTM configuration, you must manually configure each virtual server on the BIG-IP GTM system. For virtual servers using address translation, you must also configure the translation address. To manually define a virtual server, perform the following procedure:

BIG-IP 11.5.0 and later

  1. Log in to the Configuration utility.
  2. Go to DNS > GSLB > Servers > Server List.
  3. Select the BIG-IP system for which you will define the virtual server.
  4. Select Virtual Servers.
  5. Select Add.
  6. Enter a name for the virtual server.
  7. For Address and Port, enter the IP address and port for the virtual server.
  8. If applicable, for Translation and Translation Service Port, enter the translation IP address and port for the virtual server.
  9. Select Create.

BIG-IP 10.x through 11.4.1

  1. Log in to the Configuration utility.
  2. Go to Global Traffic > Servers > Server List.
  3. Select the BIG-IP system for which you will define the virtual server.
  4. Select Virtual Servers.
  5. Select Add.
  6. Enter a name for the virtual server.
  7. For Address and Port, enter the IP address and port for the virtual server.
  8. If applicable, for Translation and Translation Service Port, enter the translation IP address and port for the virtual server.
  9. Select Create.

BIG-IP 9.2.2 through  9.4.8

  1. Log in to the Configuration utility.
  2. Go to Global Traffic > Servers.
  3. Select the BIG-IP system for which you will define the virtual server.
  4. Select Virtual Servers.
  5. Select Add.
  6. Enter a name for the virtual server.
  7. For Address and Port, enter the IP address and port for the virtual server.
  8. If applicable, for Translation and Translation Service Port, enter the translation IP address and port for the virtual server.
  9. Select Create.
