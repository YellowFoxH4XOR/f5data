Known Issue

Occasional BIG-IP system outages occur when a virtual server handles MultiPath TCP (MPTCP) or Secure Sockets Layer (SSL) traffic.

This issue occurs when one of the following conditions is met:

  • MPTCP is enabled on a TCP profile on a virtual server.
  • An SSL profile is in use on a virtual server.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from the Traffic Management Microkernel (TMM) restart, and devices configured as a high availability (HA) pair may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file in the /shared/core directory.
  • Your BIG-IP system logs a SIGSEGV to the /var/log/tmm file at the same time that TMM produces a core file and restarts.
  • If configured for HA, the affected BIG-IP system fails over to a configured peer device.
