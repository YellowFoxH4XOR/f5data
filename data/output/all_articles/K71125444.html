Description

For BIG-IP DNS system without LTM licence, the Configuration Utility would not display the Local Traffic menu. However, if the system has other module licensed, the Configuration Utility may display the Local Traffic menu as well.

Environment

  • BIG-IP DNS/GTM

  • No LTM provisioned

  • Other module provisioned, for example, AFM provisioned

Cause

If the BIG-IP system has other module provisioned, for example: AFM, the DoS profile may need to be applied under the virtual server's Security tab. So, the Configuration Utility may display the Local Traffic menu to make this configuration possible.

Recommended Actions

This is an expected behavior. No action needed.
