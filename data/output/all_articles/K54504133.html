Description
When using Edge Client to connect to an access policy that has 2 logon pages, the second one being an OTP logon page. The password field will be populated with asterisks, which might be confusing for some users.

Environment

  • BIG-IP APM
  • Edge Client
  • 2 Logon pages, second one used for OTP

Cause

OTP password filed will be prepopulated with asterisks

Recommended Actions

  1. Change the first Logon Page's password variable to password1 (results in session.logon.last.password1), or anything other than session.logon.last.password. 
  2.  Create a variable assign agent with the content :
 session.logon.last.password = expr {[mcget {session.logon.last.password1}]}
