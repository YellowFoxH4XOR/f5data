Description 

When attempting to load a BIG-IP SCF (Single Configuration File) on a BIG-IP AFM system an error message similar to the following is displayed.

: 010715c9:3No source or destination port argument allowed for non-port-based protocol (1) on firewall rule (<rule name>). Unexpected Error: Validating configuration process failed.
Note: <rule name> is the name of the offending BIG-IP AFM firewall policy rule.
 

Environment

  • BIG-IP AFM
  • Load of SCF (Single Configuration File)
Cause

The error message can be misleading as to the cause of the failure to load the SCF.

Recommended Actions 

Check the SCF file for instances of the following with in the BIG-IP AFM firewall rule configurations:

  • Firewall policy rules that are configured with ports for protocols that do not utilize ports.
  • Duplicate firewall policy rules

 

Additional Information 
  • The Configuration Data Management chapter of the BIG-IP System Essentials guide.
