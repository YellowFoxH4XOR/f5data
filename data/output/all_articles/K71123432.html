Issue

Description

When connecting to Citrix environment through BIG-IP APM, you get prompted with a pop-up window, stating: Your logon has expired. Please log on again to continue. 

However, additional attempts to log on result in the same error, and you are unable to connect to the Citrix resources even when using valid credentials.

A packet trace (tcpdump) of the affected traffic indicates the the Citrix server is responding with an expired cookie.

For example, in response to an HTTP request (POST /Citrix/StoreWeb/Resources/List), the Citrix server response contains Set-Cookie headers similar to the following:

  • CitrixWebReceiver-Authenticate: reason="gatewayclaimsinconsistent", location="Authentication/GetAuthMethods"
  • Set-Cookie: CsrfToken=518E8D7081F71CF0DCA3B7F4B70C2F42; expires=Sat, 29-Apr-1989 10:53:33 GMT; path=/Citrix/StoreWeb/; secure [<------- cookies are expired]
  • Set-Cookie: CtxsAuthId=8E9918F3536F8F6B27D77DCE201E4E0D; expires=Sat, 29-Apr-1989 10:53:33 GMT; path=/Citrix/StoreWeb/; secure [<------ cookies are expired]
  • {"unauthorized": true}

Environment

  • BIG-IP APM
  • Deployed a configuration to proxy Citrix authentication and traffic
  • Initial authentication to BIG-IP APM is successful

Cause

An expired Citrix authentication cookie

Recommended Actions

Review the Additional steps if integrating with StoreFront or Web Interface servers section (page 40) of the  F5 Networks Citrix Deployment Guide and ensure the Citrix resources have been deployed with the correct configuration requirements.
