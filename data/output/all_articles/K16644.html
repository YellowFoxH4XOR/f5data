Known Issue

BIG-IP APM Oracle Access Manager (OAM) authentication may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration includes an access profile for OAM.
  • Users accessing the OAM access profile present HTTP requests that contain cookies larger than 4095 bytes.

Impact

Users are temporarily unable to access OAM.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Error messages that appear similar to the following examples are logged to the /var/log/apm file at the time of the occurrence:

    warning eam: 01490000:4: failed to get host identifier through webgate '<webgate profile name>', The Access Management Service is disabled., please make sure admin credential is valid if OAM is 10g

    err eam: 01490000:3: : OAM Exception: OAM Exception: Session token passed to the ObUserSession constructor is null or invalid.

    notice /usr/bin/eam[21876]: 01490000:7: === Initializing EAM Plugin ===
  • The BIG-IP system generates an eam core file to the /shared/core directory with a time stamp that correlates with the time of the occurrence.
