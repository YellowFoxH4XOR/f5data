Policy Information

F5 hereby announces the End of Sale (EoS) for the F5 Application Connector for all BIG-IP platforms. The F5 EoS for the F5 Application Connector is effective October 1, 2018. This applies to all Application Connector licenses and bundles that include the F5 Application Connector. This product notice does not impact any licensed iSeries appliance with BIG-IP 13.x and F5 Application Connector licenses. Future BIG-IP versions, 14.x and higher, will no longer allow F5 Application Connector licenses.

The EoS of the F5 Application Connector features allows F5 to focus on developing and supporting new Multi-Cloud platforms that customers more commonly need.

F5 Application Connector will reach EoS World Wide effective October 1, 2018.
