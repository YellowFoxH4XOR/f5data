K70123206: Disabling SNMP traps for all Virtual Servers

Type
Support Solution
Published
2022-12-09
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K70123206

Description

Disable SNMP traps from being generated and sent for ALL Virtual Server events to avoid 3rd party SNMP monitors from acting on the received alert(generate service request).

Environment

  • Maintenance activity underway 
  • 3rd party SNMP monitors configured to act on SNMP traps from BIGIP

Cause

None

Recommended Actions

  1. Open /etc/alertd/alert.conf and copy the alerts you would like to stop
           For LTM virtual server available and unavailable events
 
alert BIGIP_MCPD_MCPDERR_VIRTUAL_AVAIL {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.135"  <<
}
alert BIGIP_MCPD_MCPDERR_VIRTUAL_UNAVAIL {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.136"  <<
}
 
      2. Backup user alert conf before any modification. 
         cp /config/user_alert.conf /config/user_alert.conf.before_vs_trap_disabled

      3. We are interested in BIGIP_MCPD_MCPDERR_VIRTUAL_AVAIL and BIGIP_MCPD_MCPDERR_VIRTUAL_UNAVAIL events
        open/ modify /config/user_alert.conf and paste the copied lines and comment on them as below:
 
#comment the traps you would like to stop
alert BIGIP_MCPD_MCPDERR_VIRTUAL_AVAIL {
#    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.135" <<<<
}
alert BIGIP_MCPD_MCPDERR_VIRTUAL_UNAVAIL {
#    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.136" <<<<
}
 
           Save and exit the editor

      4. restart alertd daemon

bigstart restart alertd
