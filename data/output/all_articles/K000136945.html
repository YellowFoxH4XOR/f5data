Description

You want to know if the ASM L7 Behavioral DoS baseline is synchronized between peers.

Environment

  • BIG-IP ASM provisioned
  • DoS profile with L7 Behavioral DoS configured
  • Behavioral DoS in use and baseline established

Cause

When using L7 Behavioral DoS, the baseline (all signals baselines and samples of good requests) will sync between peers.

Recommended Actions

None

Additional Information

A bug in certain versions prevented baseline sync. For more information and what versions introduced a fix refer to Bug ID 1408381.
