Description

Brute Force Protection fails to work for Microsoft ActiveSync.

Environment

  • BIG-IP ASM
  • Brute Force Protection Enabled
  • Login URL /Microsoft-Server-ActiveSync
  • Authentication Type: HTTP Basic Authentication
  • Required Access Validation Settings    

Cause

Brute Force Protection for Microsoft ActiveSync fails to work for the following reasons:

  • ASM is designed for Outlook Web Access
  • ActiveSync is an Outlook Client Protocol
  • ASM checks the Access Validation criteria on the response according to the Content-Type of the Login URL
  • /Microsoft-Server-ActiveSync has Content-Type: application/vnd.ms-sync.wbxml
  • ASM currently doesn't support Content-Type: application/vnd.ms-sync.wbxml
Note : Supported content-types are text/*, application/x-javascript, application/sgml, application/xml, application/x-asp, application/x-aspx, application/xhtml+xml, application/json, application/x-shockwave-flash.

Recommended Actions

None.

Additional Information

According to Microsoft, support for HTTP BASIC Authentication will soon be ended. Please check out Microsoft's website for latest updates.
