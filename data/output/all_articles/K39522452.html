Topic

You should consider using this procedure under the following condition:

  • You want to configure the enforcement mode for the security policy. 

Description

The security policy enforcement mode determines how the system processes a request that triggers a violation. You can configure the following enforcement modes for the security policy:

  • Transparent—When you set the enforcement mode to Transparent for a security policy, the system logs violations but doesn’t perform blocking and passes all traffic through to the application. Additionally, the system disables blocking for all individual violations listed on the Learning and Blocking Settings page, and the Block check boxes are unavailable. Transparent mode is often used when deploying a new security policy or testing new policy features because you can review the resulting BIG-IP ASM reporting to find details about each security violation and the specific components of the application under attack, without blocking any traffic.
  • Blocking—When you set the enforcement mode to Blocking for the security policy, the system blocks requests that both cause violations and are designated for blocking. The policy enforcement mode and the blocking actions for each violation, which are listed on the Learning and Blocking Settings page, determine how the system processes requests that trigger a violation.

When you create a security policy using automatic learning mode, the system sets the enforcement mode to Blocking, but it does not block requests until Policy Builder processes sufficient traffic, adds elements to the security policy, and enforces the elements. When you create a security policy manually and the policy is operating in Transparent mode, you must manually change the enforcement mode to Blocking, after monitoring the system’s security violation data and gaining confidence in the accuracy of the policy.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access the Configuration utility.

Procedures

Configuring the security policy enforcement mode

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Versions 15.x and later

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Security Policies > Policies List.
  3. Select the relevant security policy.
  4. In the General Settings area under Learning and Blocking, select one of the following actions for Enforcement Mode:
    • Select Blocking to block traffic that causes violations.
    • Select Transparent to disable blocking and allow all requests to pass through to the application.
  5. Select Save.
  6. Select Apply Policy to activate the security policy changes.

Versions 13.x - 14.x

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. In the General Settings area, on the Enforcement Mode menu, perform one of the following actions:
    • Select Blocking to block traffic that causes violations.
    • Select Transparent to disable blocking and allow all requests to pass through to the application.
  4. Select Save.
  5. Select Apply Policy to activate the security policy changes.
