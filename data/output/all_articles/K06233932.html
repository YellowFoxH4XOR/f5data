Known Issue

The Traffic Management Microkernel (TMM) may exit and produce a core file after you apply an attack signature.

This issue occurs when all of the following conditions are met:

  • In the denial-of-service (DoS) profile, the Block requests from suspicious browsers setting of the Proactive Bot Defense feature is set to enabled.
  • You apply the ASM-SignatureFile_20160627_172326.im attack signature.

Impact

The BIG-IP system may temporarily fail to process traffic while TMM restarts. If configured as a high-availability pair, the device may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system continuously generates a TMM core file to the /shared/core directory.
  • The system generates a SIGSEGV fault to the /var/log/tmm file.

Workaround

To mitigate this issue, you can disable the Block requests from suspicious browsers setting or revert to the previous attack signature update.

To work around this issue, you must install the more recent attack signature update ASM-SignatureFile_20160711_164848 and then disable the Block requests from suspicious browsers setting of the Proactive Bot Defense feature in the DoS profile for 48 hours before you can re-enable this feature. To do so, perform the following procedure:

Impact of procedure: The system does not validate the client browser and blocks detected bots when the Block requests from suspicious browsers setting is disabled.

  1. Download the ASM-SignatureFile_20160711_164848 Attack Signature Update from the F5 Downloads site.
  2. Log in to the Configuration utility.
  3. Navigate to Security > Security Updates > Application Security.
  4. For the Update Mode setting, click Manual.
  5. For the Delivery Mode setting, click Manual and browse to the downloaded Attack Signature Update file.
  6. To begin installation, click Install Updates.
  7. When the installation is complete, click Close on the Security Update Result summary window.
  8. Navigate to Security > DoS Protection > DoS Profiles.
  9. Click on the name of the affected DoS profile.
  10. Click Proactive Bot Defense.
  11. For the Block requests from suspicious browsers setting, click Edit.
  12. Clear the Block Suspicious Browsers option.
  13. Click Close
  14. To save the changes to the DoS profile, click Update.
  15. Repeat steps 9 through 14 for the remaining DoS profiles that are enabled with the Block requests from suspicious browsers setting.
  16. You must wait for 48 hours before re-enabling this setting for the affected DoS profiles.
