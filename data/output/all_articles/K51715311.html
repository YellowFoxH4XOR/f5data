Description

SQL monitor incorrectly marking nodes down.

You may see the following entry in the /var/log/DBDaemon.log or /var/log/ltm:
jdbc:mysql://192.168.1.1:6033/(Thread-7612117): Hung SQL query; abandoning.

Environment

  • BIG-IP
  • SQL Monitor

Cause

Unknown at the time of publication.

Recommended Actions


Important: This will interrupt all health monitoring on the device briefly.
tmsh restart sys service bigd
  1. Restart the bigd daemon
