Known Issue

This is the result of a known issue. The VLAN failsafe feature is designed to trigger an action when no network traffic is detected on the VLAN. If the BIG-IP system does not detect traffic on the VLAN, the BIG-IP will attempt to generate traffic such as ARP requests on the VLAN in order to prevent a false VLAN failsafe action from being triggered.

The BIG-IP LTM does not generate ARP requests for VLANs that are are members of a VLAN group.

F5 Product Development tracked this issue as CR83401 and it was fixed in BIG-IP LTM versions 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.

In addition, this issue has been fixed in Hotfix-BIG-IP-9.3.0-HF3 for BIG-IP version 9.3.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

Note: The BIG-IP LTM generates other kinds of network traffic in addition to ARP requests on the VLAN in order to prevent a false VLAN failsafe action from occurring. For more information, refer to K6045: Change in Behavior: Generating traffic with the VLAN failsafe feature and the available VLAN failsafe actions.
