K85010551: Cannot re-establish HA pair

Type
Support Solution
Published
2020-01-09
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K85010551

Description
In some cases of memory or system file corruption, it has been observed that the internal HA status of the Big-IQ may not get updated as expected and can prevent the creation of a new HA pair.

Environment

  • BIG-IQ
  • Recreate HA fails

Cause
Possible corruption of memory or disk due to hardware failure.

Recommended Actions

After all hardware issues have been resolved and HA cannot be reestablished, the situation can be remedied with the following steps:
  1. Reset both the devices to standalone from the UI or using ha_reset -f <that-device's-discovery-address>
  2. From the console of the primary, do the following:
       # mongo
       bigiq0: PRIMARY> use bigiqDb
       bigiq0:PRIMARY>db.bigiqLiveObjects.update({"_value.selfLink":"https://localhost/mgmt/shared/failover-state"},{$set:{"_value.resetToStandalone":false}})
  3. Exit mongo cli:
    bigiq0:PRIMARY> quit()
  4. Recreate BIG-IQ HA.
