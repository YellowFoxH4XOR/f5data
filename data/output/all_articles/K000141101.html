K000141101: CPU load is not load balanced evenly across all TMMs

Type
Support Solution
Published
2024-09-18
Updated
2026-08-12
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000141101

Description

CPU load is not load-balanced evenly across all TMMs. Using the command tmsh show sys tmm-info, the BIGIP reports CPU usage in % which seems unbalanced.

Environment

  • VIPRION B2250 blades
  • CPU
  • traffic not properly balanced between each TMM

Cause

K11456586

Recommended Actions

1) Change sys db mhdag.pu.table.size.multiplier to value 2

tmsh modify sys db mhdag.pu.table.size.multiplier value 2

2) Restart tmm

bigstart restart tmm

or

clsh bigstart restart tmm (on multibalde systems)

Important: This is service affecting while tmm restarts. On systems with vcmp it needs to be done on guest and hosts.

Additional Information

It is related to https://my.f5.com/manage/s/article/K11456586. However, the affected BIG-IP system has B2250 blades that use mhdag, not dagv2.
