Description

When DNS Validating Resolver configured in DNS profile, DNS NXDOMAIN query attack is not detected.

Environment

  • BIG-IP AFM, DNS
  • Configured DNS profile with DNS Validating Resolver
  • Configured a DoS profile with DNS NXDOMAIN vector

Cause

This is an expected behavior. When DNS cache is enabled, it is up to DNS cache to decide what to respond. In this case, DNS cache not able to respond with correct information and it could not determine whether it is NXDOMAIN, so SERVFAIL is returned.

None.
