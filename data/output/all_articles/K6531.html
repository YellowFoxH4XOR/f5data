Known Issue

Note: This issue only affects the FirePass controller if you are using the Windows XP Microsoft operating systems.

This is the result of a known issue. An Application Tunnel Favorite configured with the MS File Shares type (port 139) will fail on Windows XP clients for users without Administrator privileges. When the Application Tunnel Favorite is activated, you will receive the following error message in the Application Tunnel window:

Couldn't open proxy server

If you have received this error message and are running the XP Microsoft operating system, you can verify you are experiencing this particular known issue by selecting the View logs option and viewing the logterminal.txt file. Messages similar to the following will be logged in the logterminal.txt file:


Tue Jul 25 20:50:36 2006 GMT (TUNNEL:3608)  

code=-1 (The device is not ready.)

Tue Jul 25 20:50:51 2006 GMT (HOST:2312)  

CHostCtrl::OnTimer::Timed out

Tue Jul 25 20:50:51 2006 GMT (HOST:2312)  

CHostCtrl::Failed: Couldn't open proxy server(0)

Tue Jul 25 20:50:51 2006 GMT (HOST:2312)  

CHostCtrl::Failed: Firing event OnError()

F5 Networks Product Development tracked this issue as CR53559 and it was fixed in FirePass versions 6.0.3 and 6.1.0. For information about upgrading, refer to the FirePass Release Notes.
