K9760: Installing a hotfix immediately after installing an OPSWAT hotfix can cause an unexpected system reboot

Known Issue

This is the result of a known issue. Starting in FirePass version 6.0.3, and in FirePass version 6.0.2 with cumulative hotfix HF-602-4, FirePass no longer requires a reboot after installing an OPSWAT hotfix. However, if you install a second hotfix immediately after installing an OPSWAT hotfix, the FirePass controller can unexpectedly reboot while the second hotfix is installing. This issue may cause data corruption or loss of feature functionality.

This issue can occur regardless of the type of the second hotfix (individual, cumulative, or another OPSWAT hotfix), and it occurs due to a timer mechanism, which takes 60 to 90 seconds to clear after the OPSWAT hotfix installation. This timer mechanism does not affect other hotfix installations, since FirePass automatically reboots after installing a non-OPSWAT hotfix. 

Note: This issue only occurs in FirePass version 6.0.2 after installing cumulative hotfix HF-602-4 or later versions of the cumulative hotfix.

F5 Product Development is tracking this issue as ID 266877 (formerly CR117073).

Workaround
You can work around this issue by waiting at least 90 seconds after installing the OPSWAT hotfix before installing the second hotfix.
