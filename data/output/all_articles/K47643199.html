Description

How to enforce local account password change upon first login?

  • When a new BIG-IP user local account login to the BIG-IP (GUI/SSH) to be prompted to change password

Environment

  • BIG-IP
  • Local account
  • First login prompt for password change
  • Prompt user to change password upon login to BIG-IP system

Cause

A security compliance requirements requirement to prompt for password change for the first login to BIG-IP system

Recommended Actions

In BIG-IP we can make use of the shell bash command "chage" to enforce local account password expiry to "0" days, which will ensure password prompt upon login to the BIG-IP system. Steps as listed below

  1. Login to BIG-IP bash shell command line via SSH/Console
  2.   Check default user details
    # chage -l local_user
    Last password change                                    : Apr 29, 2022
    Password expires                                        : never            <<<<<< password expiry "never" expire
    Password inactive                                       : never
    Account expires                                         : never
    Minimum number of days between password change          : 0
    Maximum number of days between password change          : 99999            <<<<<< default "Secure password policy configuration"
    Number of days of warning before password expires       : 7
     
  3. Excute CLI command "chage -M 0" to change the expiry of a local user account expire immediately "0" day
    # chage -M 0 local_user
    # chage -l local_user
    Last password change                                    : Apr 29, 2022
    Password expires                                        : Apr 29, 2022     <<<<<< date of local account password expiry date
    Password inactive                                       : never
    Account expires                                         : never
    Minimum number of days between password change          : 0
    Maximum number of days between password change          : 0                 <<<<<< change to 0, password expire immediately
    Number of days of warning before password expires       : 7
     
  4. BIG-IP will change the local account "e.g local_user" back to BIG-IP default secure password policy after the user login to BIG-IP system and changed the password upon prompted for password change.

    Notes: May refer to F5 KB article link "K15497: Configuring a secure password policy for the BIG-IP system (11.x - 16.x)" for details on BIG-IP what is secure password policy?

  5. Once, the user changed the password, the password expiry and Max number of days between password change will revert back to "secure password policy configuration" default setting:
    # chage -l local_user
    Last password change                                    : Apr 29, 2022
    Password expires                                        : never            <<<<<< revert back to "    secure password policy configuration" default setting
    Password inactive                                       : never
    Account expires                                         : never
    Minimum number of days between password change          : 0
    Maximum number of days between password change          : 99999            <<<<<< revert back to "    secure password policy configuration" default setting
    Number of days of warning before password expires       : 7

Additional Information

May use "chage --help" command for available command to "chage"
# chage --help
Usage: chage [options] LOGIN
Options:
  -d, --lastday LAST_DAY        set date of last password change to LAST_DAY
  -E, --expiredate EXPIRE_DATE  set account expiration date to EXPIRE_DATE
  -h, --help                    display this help message and exit
  -I, --inactive INACTIVE       set password inactive after expiration 
                                to INACTIVE
  -l, --list                    show account aging information
  -m, --mindays MIN_DAYS        set minimum number of days before password
                                change to MIN_DAYS
  -M, --maxdays MAX_DAYS        set maximim number of days before password
                                change to MAX_DAYS
  -R, --root CHROOT_DIR         directory to chroot into
  -W, --warndays WARN_DAYS      set expiration warning days to WARN_DAYS
