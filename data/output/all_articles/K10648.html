Known Issue

This is the result of a known issue. The LCD screen reports more memory than is installed on the 1600, 3600, 3900, 6900, and 8900 platforms. For example, the 3900 platform ships with 8 gigabytes of RAM, but the LCD screen reports that the system contains 11245 megabytes of RAM (11 gigabytes). In addition, the 8900 platform ships with 16 gigabytes of RAM, but the LCD reports 18683 megabytes (18 gigabytes).

F5 Product Development tracked this issue as ID 327772 (formerly CR127168) and it has been fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

Workaround

You can work around this issue by typing the bigpipe memory command to display the correct amount of memory for the platforms.
