Known Issue

This is the result of a known issue. Removing a VLAN from a channel using the no vlan <vlan_name> command while in the cfg-channel mode will completely delete the VLAN from the running configuration.

F5 Product Development tracked this issue as ID 38656 and it was fixed in ARX version 5.2.0. For infomation about upgrading, refer to the ARX Release Notes.
