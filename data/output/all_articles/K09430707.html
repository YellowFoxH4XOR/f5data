Description

After performing some maintenance activity where multiple virtual servers have been manually disabled and re-enabled, one or more virtual servers continue to be shown as offline on BIG-IP DNS, even though the status on BIG-IP LTM is available.

For example: 

BIG-IP DNS: tmsh show gtm server virtual-servers

 -----------------------------------------------------------------------------------------------------------------------
| Gtm::Virtual Server: vs_443
 -----------------------------------------------------------------------------------------------------------------------
| Status
|   Availability : offline
|   State        : enabled
|   Reason       :  Monitor /Common/bigip from /Common/gtm1 : no reply from big3d: timed out
....

BIG-IP LTM: tmsh show ltm virtual
-----------------------------------------------------------
Ltm::Virtual Server: vs_443
-----------------------------------------------------------
Status
  Availability     : available
  State            : enabled
  Reason           : The virtual server is available
....


 

Environment

  • BIG-IP DNS - virtual servers offline
  • BIG-IP LTM - same virtual servers available
  • Virtual servers had been disabled and re-enabled
  • Additional BIG-IP DNS monitor instances added

Cause

Bug ID 1046785

Recommended Actions

At the time of writing, ID1046785 is to be addressed in v13.1.5 and other software trains.  In the meantime an Engineering Hotfix can be made available on request.

Alternatively, the MSMR value can be increased as a workaround, however it is recommended not to exceed the MSMR value of 40 in a production environment.

Important: Altering the MSMR value does not automatically resolve an issue; instead it shifts processing priorities for gtmd and big3d in a way that may be helpful or harmful, depending on the situation. If the number of monitor instances at a polling interval is sufficiently large and the MSMR is configured sufficiently large as well, gtmd should be able to process monitor requests to the exclusion of other tasks like responding to sod heartbeats, which can have negative consequences.
