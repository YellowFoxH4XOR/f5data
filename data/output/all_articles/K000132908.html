Description

How to take tcpdump on F5OS-A on rSeries r2000/r4000 ?

Environment

  • F5OS-A
  • rSeries r2000/r4000
  • tcpdump

Cause

For r2000/r4000, there is currently only one way to run tcpdump: via Linux Bash (root access).
tcpdump was excluded from confd CLI on r2000/r4000 due to difference in architectural design.

Recommended Actions

Since tcpdump in confd is not possible, the interface names to capture on are not straightforward. When Port Group mode is 8x10GbE, the interface mapping is as the following:

  • Interfaces 1.0 - 4.0 are mapped to x557_1 - x557_4 respectively.
  • Interfaces 5.0 - 8.0 are mapped to sfp_5 - sfp_8 respectively.

When Port Group mode is 4x10GbE+2x25GbE, the interface 7.0-8.0 are disabled, the interface mapping is as the following:

  • Interfaces 1.0 - 4.0 are mapped to x557_1 - x557_4 respectively
  • Interfaces 5.0 - 6.0 are mapped to sfp_5 - sfp_6 respectively.

And consequently, for 4x25GB port-profile is configured, the interface 1.0-4.0 are disabled, the interface mapping is as the following:

  • Interfaces 5.0 - 8.0 are mapped to sfp_5 to sfp_8 respectively


To run tcpdump,
1. Log in to F5OS host CLI as root
2. Run the command below specifyig x as appropreate number:

tcpdump -ni sfp_x <add further filter>
tcpdump -ni x557_x <add further filter>

Important: At this time due to platform limitations tcpdump on rSeries r2000/r4000 only captures broadcast traffic.
