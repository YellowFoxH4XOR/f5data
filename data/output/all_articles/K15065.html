Known Issue

The BIG-IP APM system access tunnels may trigger TMM to restart.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a network access profile or application tunnel profile.
  • The BIG-IP APM system is running on a platform that is running more than 16 TMM instances.

Impact

The TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H451358 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system may stop responding and fail over to another system in the device group.
  • TMM may produce core files in the /shared/core directory for each TMM instance.

    For example:

    tmm.1.bld1179.0.core.gz
    tmm.2.bld1179.0.core.gz
    tmm.3.bld1179.0.core.gz
    tmm.4.bld1179.0.core.gz
    ...
    tmm.23.bld1179.0.core.gz

  • The system may log the following error messages to the /var/log/tmm file:

    notice ** SIGFPE **
    notice fault addr: 0x57cb0f

    emerg logger: Re-starting tmm1
    emerg logger: Re-starting tmm2
    emerg logger: Re-starting tmm3
    emerg logger: Re-starting tmm4
    ...
    emerg logger: Re-starting tmm23
