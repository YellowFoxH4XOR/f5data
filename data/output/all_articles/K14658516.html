Description
When using Ansible to deploy virtual servers with an APM profile additional profiles may need to be declared in the Ansible playbook.

Environment

  • BIG-IP APM
  • Ansible control server

Cause
Depending on configuration APM may need additional profiles to allow for functionality.  When configured with the Configuration Utility these may need to be added explicitly or automatically.

Recommended Actions

  1. Identify required profiles for functionality of the expected virtual server. Some of these profiles are:
    • websso
    • rba
    • rdp
    • ntlm
  2. Include the required profiles in the virtual server

Additional Information
 Creating Ansible playbook that defines these profiles is not currently properly supported.

When changing any of the above profiles, the configuration is not updated until the VPE (Virtual Policy Editor) is opened and the changes are saved using VPE, any changes using tmsh (or other automation tool, that uses tmsh rather than VPE) are not effective.

As a workaround, is is necessary to open the Access Policy with the VPE and make a change (add a space then delete the space) and save the configuration before the profile changes above are incorporated.
