Topic

This article applies to BIG-IP 11.x through 16.x. For information about other versions, refer to the following article:

  • K6530: Viewing the dynamic ratio weight of a node (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to view the dynamic ratio weight of a node.

Description

The dynamic ratio weight of a node is used to determine load balancing decisions when a dynamic ratio load balancing algorithm is used. You can view the dynamic ratio weight of a node using the following procedure:

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the TMOS Shell (tmsh).

Procedures

View the dynamic ratio weight of a node

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. View the current dynamic ratio weight for nodes by entering the following command:

    list /ltm node dynamic-ratio

    The output of the command appears similar to the following example:

    ltm node 10.12.10.20 {
        dynamic-ratio 41
    }
    ltm node 10.12.10.30 {
        dynamic-ratio 73
    }

Note: The list /ltm node command also shows, along with other non-default properties, the dynamic-ratio property if it has a value higher than 1.
