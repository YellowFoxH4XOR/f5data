K000150532: Display issue folder APP via VDI Citrix after upgrade

Type
Support Solution
Published
2025-07-08
Updated
2025-07-08
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150532

Description

After upgrading BIG-IP APM from version 13 to versions 15 or 17, users accessing Citrix VDI resources via a Standard Webtop may encounter a display issue: when clicking on an application folder (such as "admin"), the box listing associated applications appears at the bottom of the web window instead of in the center. This UI change can cause users to miss available applications if they do not scroll down. No specific error messages are generated; this is a change in user interface rendering behavior.

Environment

  • BIG-IP APM
  • Standard Policy (Standard Webtop)
  • Citrix VDI integration
  • Citrix version tested: 2405.10 (other versions may also be impacted)

Cause

A compatibility issue exists between the Standard Policy (Standard Webtop) and how application folders are displayed for Citrix VDI resources in BIG-IP APM versions 15.x and 17.x. Changes to UI rendering logic result in application folder contents being shown at the bottom of the page rather than centered.

Recommended Actions

Use a Modern Policy with a Modern Webtop for presenting Citrix VDI resources. The Modern Webtop displays application folders correctly in the center of the web window.

Additional Information

  • There is no automated method to convert an existing Standard Policy to a Modern Policy; manual recreation of both Access Policy and Webtop is required.
  • Ensure that both Access Policy and Webtop are set to the same customization type ("Modern") when configuring.
