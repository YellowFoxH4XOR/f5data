K13422981: BIG-IP Edge Client stuck in ''Loading Cache Cleanup Control''

Type
Support Solution
Published
2021-08-31
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM: 13.1.3
Source
https://my.f5.com/manage/s/article/K13422981

Description

When the BIG-IP Edge Client connects, it passes the Policy, but get stuck displaying "Loading Cache Cleanup Control"

Environment

  • BIG-IP APM
  • BIG-IP Edge Client
  • VPE Policy contains a "Windows Cache and Session Control" object.

Cause

The VPE Policy Object "Windows Cache and Session Control" has become obsolete, and causes the Edge Client to hang.

Recommended Actions

Remove the "Windows Cache and Session Control" VPE Object from your Policy, and the Edge Client will connect as expected.

Additional Information

None
