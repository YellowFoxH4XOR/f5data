Known Issue

This is the result of a known issue. Using SNMP to query pool member and node address statistics consumes excessive system resources.

F5 Product Development is tracking this issue as ID 338480 (formerly CR136629).

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1 for version 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
