K5863: BIG-IP creates a route on the loopback interface for forwarding virtual servers that represent a single IP address

Known Issue

This is the result of a known issue. When you create a forwarding virtual server that represents a single IP address, rather than a network, BIG-IP adds a route for the virtual server on the loopback interface. The route on the loopback interface may prevent BIG-IP from properly routing traffic destined for the forwarding virtual server.

F5 Networks Product Development tracked this issue as CR47540 and CR54467, and it was fixed in BIG-IP version 4.5.14. For information about upgrading, refer to the BIG-IP Release Notes.
