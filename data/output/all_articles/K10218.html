Topic

Depending on the amount and type of traffic processed by the BIG-IP WebAccelerator, a large volume of messages may be logged in the /var/log/wa/pvac.log file. A large volume of messages in the pvac.log file may reduce an administrator's ability to monitor the log file efficiently. Additionally, a large volume of messages may cause the pvac process to restart.

The <stackTraceSimplified> configuration option in the /config/wa/pvsystem.conf file was introduced to control the growth of the pvac.log file.

Note: For information, refer to K8798: The BIG-IP WebAccelerator logs excessive stack trace information.

Configuring syslog-ng to filter unwanted pvac log messages

Note: For information about a simplified method for filtering BIG-IP WebAccelerator pvac log messages on BIG-IP WebAccelerator 10.x versions, refer to K10534: Filtering BIG-IP  WebAccelerator pvac log messages.

You can also filter out specific pvac log messages that you have identified as unwanted by configuring custom syslog filters. To do so, perform the following procedure:

Important: Configuring custom syslog filters may prevent log messages which indicate an issue or failure from logging. F5 Networks recommends removing custom syslog filters when diagnosing a failure.

  1. Log in to the command line.
  2. Enter the following command to configure a syslog include entry:

    Important: Running the command below will overwrite the previous syslog include entry, if configured. If you want to maintain the current syslog include entry, combine the new and old entry into a single syslog include statement. To determine whether a syslog include entry is already configured, run the bigpipe syslog include command.

    bpsh <<END
    syslog {
       include "
    source s_pvac {
        file(\"/dev/null\");
    };
    filter f_pvac {
        not match(\"<filter-string1>\")
        and not match(\"<filter-string2>\")
        and not match(\"<filter-string3>\");
    };
    source s_pvac_new {
        pipe(\"/var/run/pvac.pipe\");
    };
    log {
        source(s_pvac_new);
        destination(d_pvac);
        filter(f_pvac);
    };
    "
    }
    END

    Replace each <filter-string> with a text string you want to filter from the pvac log. When configuring multiple filter strings, the semicolon character ( ; ) should only appear after the last filter string, as shown above.

    Important: Ensure that the filter strings are as specific as possible to avoid matching additional log messages you may not want to filter.
  3. If the new logging configuration is working as expected, issue the following command to save the change:

    bigpipe save

    If the new logging configuration is not working as expected, return to Step 2 and adjust the bpsh command to modify the logging options as necessary. Then proceed to Step 3.

    Note: To remove all syslog include entries, run the following commands:

    bigpipe syslog include none
    bigpipe save

Note: To determine the version of syslog-ng running on your BIG-IP system, refer to K9445: The BIG-IP third party software matrix.
