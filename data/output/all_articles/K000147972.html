K000147972: How to generate API Token for Distributed Cloud

Source

Description

When using Distributed Cloud API, you will need to generate a Credential or a Service Credential for making API calls

Environment

  • F5® Distributed Cloud (XC)
  • Distributed Cloud SaaS
  • Distributed Cloud API

Cause

None

Recommended Actions

There are two types of API tokens that can be generated:

  1. Credential
  2. Service Credential

To generate credential API token:

  1. Navigate to Administration > Personal Management
  2. Click Add Credentials.

  3. Input Credential Name
  4. Select API Token from the Credential Type dropdown
  5. Set an expiry date as per your convenience

  6. Click Generate.
  7. The API Token will be successfully generated for use.

 

To generate service credential API token:

  1. Navigate to Administration > IAM
  2. Click Add Service Credentials

  3. Input Credential Email
  4. Select API Token from the Credential Type dropdown
  5. Set an expiry date as per your convenience
  6. Assign Roles and Namespaces as required

  7. The API Token will be successfully generated for use.

 

Additional Information

  • There are two types of API tokens in F5 Distributed Cloud:
    • Credential: Generated under Administration > Personal Management. Used for personal API access.
    • Service Credential: Generated under Administration > IAM. Used for service accounts, with assignable roles and namespaces.
  • When generating a token, you must select "API Token" as the credential type and set an expiry date.
  • For service credentials, you must also specify the credential email and assign roles/namespaces as needed.
  • The generated API token is required for authenticating API calls to the Distributed Cloud platform.
