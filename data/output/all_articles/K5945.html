Note: For information about adding a static ARP entry in versions 9.x and 10.x, refer to K5946: Adding A Static ARP Entry.

To add a static ARP entry, perform the following steps:

Note: If your BIG-IP system is configured as a redundant pair, perform this procedure on both systems in the pair.

  1. Log in to the BIG-IP command line.
  2. Create a new static ARP entry by typing the following command:

    arp -s hostname link_addr

    For example:

    arp -s 10.10.10.1 f5:90:27:65:d6:b4

  3. Verify that the static ARP entry was created by typing the following command:

    arp -an

  4. To ensure the static ARP entry will be persistent after a reboot of the BIG-IP system, you must add the arp command at the bottom of the /etc/rc.local file by typing the following command:

    echo "arp -s hostname link_addr" >> /etc/rc.local

    For example:

    echo "arp -s 10.10.10.1 f5:90:27:65:d6:b4" >> /etc/rc.local
