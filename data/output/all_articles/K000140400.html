K000140400: Failed to watch ExternalDNS in cluster local: failed to list *v1.ExternalDNS: the server could not find the requested resource

Description

  • You have an OpenShift cluster and a BIG-IP device
  • You want to use F5 Container Ingress Services(CIS) for Kubernetes and OpenShift to leverage BIG-IP capabilities
    • CIS supports Custom Resources such as VirtualServer, TLSProfile, VirtualServer with TLSProfile, TransportServer, ExternalDNS and Policy 
  • To enable customer resource support with CIS, you set --custom-resource-mode argument to true when deploying f5networks/k8s-bigip-ctlr deployment  
  • With the deployment successfully completed and the pod reached running state, when you check pods log, you noticed the below errors 
    • E0719 15:37:00.286569    1 informers.go:1487] [ERROR] Failed to watch ExternalDNS in cluster local: failed to list *v1.ExternalDNS: the server could not find the requested resource (get externaldnses.cis.f5.com)
    • E0719 15:37:08.795360    1 informers.go:1487] [ERROR] Failed to watch CustomPolicy in cluster local: failed to list *v1.Policy: the server could not find the requested resource (get policies.cis.f5.com)

Environment

  • BIG-IP
  • BIG-IP Controller
  • Container Ingress Services(CIS)
  • OpenShift
  • Kubernetes
  • Custom Resource Definition
  • Custom Resource
  • External DNS

Cause

  • Custom--resource-mode argument is set to true without having defined "ExternalDNS" resource in OpenShift/Kubernetes Cluster

Recommended Actions

  • You would need to create a valid ExternalDNS resource as shown in the below sample example or described solution here
    apiVersion: "cis.f5.com/v1"
kind: ExternalDNS
metadata:
  name: exdns
  labels:
    f5cr: "true"
spec:
  domainName: example.com
  dnsRecordType: A
  loadBalanceMethod: round-robin
  pools:
  - name: example.site1.com
    dnsRecordType: A
    loadBalanceMethod: round-robin
    dataServerName: /Common/GSLBServer
    monitor:
      type: https
      send: "GET /"
      recv: ""
      interval: 10
      timeout: 10
