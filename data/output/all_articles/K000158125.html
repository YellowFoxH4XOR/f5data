K000158125: APM Data no longer collected after upgrade to 8.4

Type
Support Solution
Published
2025-12-09
Updated
2026-02-13
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.0
Source
https://my.f5.com/manage/s/article/K000158125

Description

After upgrading BIG-IQ to version 8.4.0, APM session data was no longer being collected, despite the Data Collection Device (DCD) showing as active and healthy.

 

Environment

BIG-IQ VE 8.4.0

BIG-IQ Central Manager and Data Collection Device (DCD)

BIG-IP APM

 

Cause

The root cause was a post-upgrade synchronization issue between BIG-IQ and the BIG-IP APM, which prevented session data collection. Removing the BIG-IP APM device for a sufficient duration allowed the system to reinitialize and resume data collection.

 

Recommended Actions

Removing the BIG-IP APM device from BIG-IQ.

Wait at least 10 minutes before re-adding the BIG-IP APM device.

Verify that session data collection resumes.

If the issue recurs, repeat the removing/re-adding the BIG-IP APM device with an adequate waiting period.
