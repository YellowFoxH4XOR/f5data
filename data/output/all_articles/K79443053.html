Description

Often, address translation and port translation settings of a standard virtual server are sources of confusion.
Both of those settings are related with the pool ( and it's associated pool members ) which is assigned on a virtual server and reflects the way which an ip address / port replacement will take place on the connection between the BIG-IP and the selected pool member.

A connection through the BIG-IP when a standard virtual server is used, along with an assigned pool, contains two parts ( or two connections ):

  • First part, a connection from client towards the BIG-IP
  • BIG-IP will make a load balance decision and it will select a pool member to forward the traffic.
  • Second part, a connection from BIG-IP towards the selected pool member.


Both source address translation and port address translation are referring to the second part of the connection and more specifically to the destination ip address / port of this connection.

Below you will find examples which are explaining the behavior of those two settings in more detail.

CLIENT  IP                     : 203.0.113.100
VIRTUAL SERVER IP    : 203.0.113.200:5555
POOL MEMBER IP        : 192.168.1.152:80

Note: Source address translation on the respective virtual server is set to "None" which is the default value on both of the examples below.

1. Address translation and port translation enabled

Note: This is the default value when creating a standard virtual server.

Client creates a connection with the BIG-IP with the following details:

SRC IP ADDRESS / PORT: 203.0.113.100:49236
DST IP ADDRESS / PORT: 203.0.113.200:5555

BIG-IP will receive this request and after making a load balance decision it will initiate a connection with the pool member with the following details:

SRC IP ADDRESS / PORT: 203.0.113.100:61501
DST IP ADDRESS / PORT: 192.168.1.152:80

The connection table will contain the following information for this connection:

tmsh show /sys connection cs-client-addr 203.0.113.100

Sys::Connections
203.0.113.100:49236  203.0.113.200:5555  203.0.113.100:61501  192.168.1.152:80  tcp  4  (tmm: 0)  none  none
Total records returned: 1

BIG-IP translated the destination ip address / port of the second connection with the selected pool member ip address / port ( 192.168.1.152:80 ).


2. Address translation and port translation disabled

Client creates a connection with the BIG-IP with the following details:

SRC IP ADDRESS / PORT: 203.0.113.100:49238
DST IP ADDRESS / PORT: 203.0.113.200:5555

BIG-IP will receive this request and after making a load balance decision it will initiate a connection with the pool member with the following details:

SRC IP ADDRESS / PORT: 203.0.113.100:61968
DST IP ADDRESS / PORT: 203.0.113.200:5555

The connection table will contain the following information for this connection:

tmsh show /sys connection cs-client-addr 203.0.113.100

Sys::Connections
203.0.113.100:49238  203.0.113.200:5555  203.0.113.100:61968  203.0.113.200:5555  tcp  1  (tmm: 0)  none  none
Total records returned: 1

BIG-IP did not translate the destination ip address / port of the second connection with the selected pool member ip address / port ( 192.168.1.152:80 ).
Instead it used the virtual server ip address / port ( 203.0.113.200:5555 ) as the destination ip address / port for the second connection.

3. Address translation disabled and port translation enabled

Client creates a connection with the BIG-IP with the following details:

SRC IP ADDRESS / PORT: 203.0.113.100:49250
DST IP ADDRESS / PORT: 203.0.113.200:5555

BIG-IP will receive this request and after making a load balance decision it will initiate a connection with the pool member with the following details:

SRC IP ADDRESS / PORT: 203.0.113.100:18981
DST IP ADDRESS / PORT: 203.0.113.200:80

The connection table will contain the following information for this connection:

tmsh show /sys connection cs-client-addr 203.0.113.100

Sys::Connections
203.0.113.100:49250  203.0.113.200:5555  203.0.113.100:18981  203.0.113.200:80  tcp  0  (tmm: 0)  none  none
Total records returned: 1

BIG-IP translated only the destination port of the the second connection with the selected pool member port ( 80 ).
The destination ip address of the second connection was not translated as a result of that the virtual server ip address ( 203.0.113.200 ) was used as a destination ip address.

4. Address translation enabled and port translation disabled

Client creates a connection with the BIG-IP with the following details:

SRC IP ADDRESS / PORT: 203.0.113.100:49446
DST IP ADDRESS / PORT: 203.0.113.200:5555

BIG-IP will receive this request and after making a load balance decision it will initiate a connection with the pool member with the following details:

SRC IP ADDRESS / PORT: 203.0.113.100:49446
DST IP ADDRESS / PORT: 192.168.1.152:5555

The connection table will contain the following information for this connection:

tmsh show /sys connection cs-client-addr 203.0.113.100

Sys::Connections
203.0.113.100:49446  203.0.113.200:5555  203.0.113.100:49446  192.168.1.152:5555  tcp  0  (tmm: 0)  none  none
Total records returned: 1

BIG-IP translated only the destination ip address of the the second connection with the selected pool member ip address ( 192.168.1.152 ).
The destination port of the second connection was not translated, the virtual server port ( 5555 ) was used as a destination port.
