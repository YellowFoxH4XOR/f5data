Known Issue

The System CPU Usage graph may display incorrect CPU statistics. Under normal running conditions, the System CPU Usage graph does not match actual usage, and may report CPU usage as either high or low.

Impact

This is a cosmetic issue.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the Configuration utility, the Statistics > Performance > System CPU Usage page graph displays 40% - 60% usage for an idle system.

Resolution

Workaround

To determine actual CPU usage, you can refer to the per-core CPU statistics. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Statistics > Performance.
  3. In the System CPU Usage table, click View Detailed Graph (right side of the page).

    Note: If this is a multi-bladed chassis, the graph shows a set of statistics for each blade. For systems with multi-core CPUs, the graph reports one line for each core.
