Description

On tablet devices, when launching the F5 Access for Android v3.0.8 app, it repeatedly crashes if used in landscape mode.
It works fine when used in portrait mode.

Environment

  • Android tablets
  • F5 Access 3.0.8 for Android used in landscape mode

Cause

There was an issue found with the current F5 Access 3.0.8 version.
F5 has since published a new F5 Access 3.0.8 app which contains the fix for the said issue, on Google Play store.

Recommended Actions

1. If you are running in to this issue on your Android tablet, please download the latest F5 Access 3.0.8 from Google Play store
