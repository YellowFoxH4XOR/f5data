Topic

To enable or disable verbose logging for the Configuration utility, perform one of the following procedures:

  • Enabling verbose logging for the Configuration utility
  • Disabling verbose logging for the Configuration utility


Enabling verbose logging for the Configuration utility
To enable verbose logging for the Configuration utility, perform the following procedure:

Note: This procedure does not impact traffic flowing across the system. However, you should only enable debug logging while actively troubleshooting issues related to the Configuration utility. You should disable debug logging after you have collected the desired information. F5 recommends that you perform this procedure only during a maintenance window.

  1. Log in to the BIG-IP command line.
  2. To remount the /usr file system in read-write mode, type the following command:

    mount -o remount,rw /usr

  3. To back up the /usr/local/www/tmui/WEB-INF/properties/logger.properties file, type the following command:

    cp /usr/local/www/tmui/WEB-INF/properties/logger.properties /usr/local/www/tmui/WEB-INF/properties/logger.properties.K10622

  4. Open the /usr/local/www/tmui/WEB-INF/properties/logger.properties file in a text editor.
  5. Locate the lines appropriate for your version at the end of the file:

    Example of the files setting prior to modification:
    #log4j.logger.com.f5=DEBUG, console_appender, file_appender
    #log4j.logger.org=DEBUG, console_appender, file_appender
    #log4j.logger.web=DEBUG, console_appender, file_appender
    log4j.logger.org=ERROR, console_appender, file_appender
    log4j.logger.com.f5=ERROR, console_appender, file_appender
    log4j.logger.web=ERROR, console_appender, file_appender

    Note: You will be removing the pound character (#) that is in front of the DEBUG lines, and adding the pound character (#) in front of the ERROR lines.

  6. Uncomment the DEBUG lines, and comment the corresponding ERROR lines below them.

    Note: The modified portion of the file should now appear similar to the following example.

    log4j.logger.com.f5=DEBUG, console_appender, file_appender
    log4j.logger.org=DEBUG, console_appender, file_appender
    log4j.logger.web=DEBUG, console_appender, file_appender
    #log4j.logger.org=ERROR, console_appender, file_appender
    #log4j.logger.com.f5=ERROR, console_appender, file_appender
    #log4j.logger.web=ERROR, console_appender, file_appender

  7. Save the file.
  8. At the command line, restart the tomcat service by typing the following command:

    bigstart restart tomcat

  9. To remount the /usr file system in read-only mode, type the following command:

    mount -o remount,ro /usr

Verbose log messages are logged to the /var/log/webui.log file.

Note: For the additional DEBUG1, DEBUG2, DEBUG3 lines in the same section of the /usr/local/www/tmui/WEB-INF/properties/logger.properties file:

#log4j.logger.com.f5=DEBUG3#com.f5.log.CustomLevel, console_appender, file_appender
#log4j.logger.com.f5=DEBUG2#com.f5.log.CustomLevel, console_appender, file_appender
#log4j.logger.com.f5=DEBUG1#com.f5.log.CustomLevel, console_appender, file_appender

Uncomment these lines only when instructed to do so by F5 Technical Support. The DEBUG1, DEBUG2, DEBUG3 log levels were added to provide debug messages at increasingly verbose and granular levels. These log statements are inactive, by default, since they are commented out, but are included in the file to facilitate troubleshooting complex internal issues.

Disabling verbose logging for the Configuration utility
To disable verbose logging for the Configuration utility, perform the following procedure:

Note: This procedure does not impact traffic flowing across the system; however, F5 recommends that you perform this procedure only during a maintenance window.

  1. Log in to the BIG-IP command line.
  2. To remount the /usr file system in read-write mode, type the following command:

    mount -o remount,rw /usr

  3. To back up the /usr/local/www/tmui/WEB-INF/properties/logger.properties file, type the following command:

    cp /usr/local/www/tmui/WEB-INF/properties/logger.properties /usr/local/www/tmui/WEB-INF/properties/logger.properties.K10622

  4. Open the /usr/local/www/tmui/WEB-INF/properties/logger.properties file in a text editor.
  5. Locate the lines appropriate for your version at the end of the file:

    log4j.logger.com.f5=DEBUG, console_appender, file_appender
    log4j.logger.org=DEBUG, console_appender, file_appender
    log4j.logger.web=DEBUG, console_appender, file_appender
    #log4j.logger.org=ERROR, console_appender, file_appender
    #log4j.logger.com.f5=ERROR, console_appender, file_appender
    #log4j.logger.web=ERROR, console_appender, file_appender

  6. Comment (place the pound symbol "#" at the start of the line) the DEBUG lines, and uncomment (remove the preceding pound "#" symbol) the corresponding ERROR lines below them. The modified portion of the file should appear similar to the following example:

    #log4j.logger.com.f5=DEBUG, console_appender, file_appender
    #log4j.logger.org=DEBUG, console_appender, file_appender
    #log4j.logger.web=DEBUG, console_appender, file_appender
    log4j.logger.org=ERROR, console_appender, file_appender
    log4j.logger.com.f5=ERROR, console_appender, file_appender
    log4j.logger.web=ERROR, console_appender, file_appender

  7. Save the file.
  8. At the command line, restart the tomcat service by typing the following command:

    bigstart restart tomcat

  9. To remount the /usr file system in read-only mode, type the following command:

    mount -o remount,ro /usr

Normal log messages are logged to the /var/log/webui.log file.
