Known Issue

A BIG-IP APM web portal does not rewrite the Citrix ICA configuration file to use the BIG-IP APM system as the proxy.

This issue occurs when the following conditions are met:

  • The BIG-IP APM system is configured to proxy a Citrix Web Interface.
  • The Citrix server responds with an Content-Type application/x-ica entry that does not include lowercase characters.

    For example:

    Content-Type: application/x-icA

Impact

Users cannot access Citrix resources through a BIG-IP APM web portal.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You receive a blank session.
  • You receive a 401 error in the web browser.
  • Performing a web trace shows mixed/uppercase characters for the application/x-ica entry:

    For example:

    Content-Type: application/x-icA

Workaround

To work around this issue, you can edit the response.contentType = "application/x-ica" entry to all lowercase characters in the LaunchAsp.cs file on the Citrix Web Interface server.
