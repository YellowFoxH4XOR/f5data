K04421892: BIG-IP unable send rem_addr field to TACACS+ Server

Type
Support Solution
Published
2023-06-21
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K04421892

Description

You have config TACACS+ authentication for BIG-IP system , and you want BIG-IP send client address field to TACACS+ Server when user login in, but you find not any option can adjust to implemented the purpose.

Environment

  • Authentication
  • Rem_addr
  • TACACS+

Cause

The behavior is by design, because rem_addr is optional in TACACS+ protocol, and BIG-IP haven't implemented the feature.

Recommended Actions

None.

Additional Information

None.
