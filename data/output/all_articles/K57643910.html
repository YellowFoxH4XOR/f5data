Description
Message that /var/lib/mysql is running out of disk space

  • BIG-IP HA pair shows status of Offline
  • mysql process restarting and logging messages similar to the following in the /var/lib/mysql/mysqld.err file:
    • [ERROR] mysqld: Error writing file '/var/lib/mysql/mysqld.pid' (Errcode: 28)
    • [ERROR] Can't start server: can't create PID file: No space left on device
    • ERROR! MySQL server PID file could not be found!
    • ERROR! Jul 18 20:42:23 Unable to launch mysql ...
  • df -h command shows /var/lib/mysql is at 100% disk usage
  • find command shows large multi GB files filling the filesystem such as /var/lib/mysql/AVR/AVR_STAT_RESPONSE_CODE_T#P#LAST.MYD

Environment
  • BIG-IP
  • AVR module provisioned
  • Restarting mysql process

Cause
AVR database corruption as a result of Bug ID 773925.

Recommended Actions

For information about fixed versions and a workaround, refer to Bug ID 773925: Sometimes MariaDB generates multiple error 24 (too many files open) for AVR DB tables files.

Additional Information
To clear and reset the AVR database

touch /var/avr/init_avrdb; bigstart restart monpd

Note: Clearing AVR database will remove all existing statistics data.
