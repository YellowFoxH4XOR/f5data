K000163546: BIG-IP Tenant Deployment Fails with Insufficient Memory on F5OS after upgrade to 2.0.0

Type
Support Solution
Published
2026-10-05
Updated
2026-10-05
Applies to
  • F5OS Products
  • F5OS: 2.0.0
Source
https://my.f5.com/manage/s/article/K000163546

Description

After upgrading F5OS-C from 1.8.2 to 2.0.0, existing production BIG-IP tenants configured with maximum memory could not transition from Configured to Deployed.. The chassis displays:

Insufficient memory on node, retrying tenant deployment

No enough memory available for tenant allocation

Deployment logs may also contain:

Failed to allocate memory

fallocate: failed: No space left on device

Environment

  • Product: F5OS
  • Tenant type: BIG-IP
  • Existing BIG-IP tenants previously deployed successfully on F5OS 1.8.2
  • Tenant configured to use the maximum available memory on the node

Cause

Bug ID 2552457

Recommended Actions

  1. Reduce the tenant’s configured memory allocation by an appropriate amount.
  2. Redeploy the tenant.
  3. Confirm that the tenant reaches the deployed and Running states.

For example, reducing a tenant allocation from 101292 MB to 96292 MB allowed deployment to complete.

Additional Information

This issue affects tenant deployment and does not by itself indicate a failed physical memory module. The error is caused by the memory allocation process failing during deployment when the tenant requests the maximum available memory.
