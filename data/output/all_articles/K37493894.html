Known Issue

The BIG-IP system may erroneously establish an invalid Bidirectional Forwarding Detection (BFD) session.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP device is configured with one of the following dynamic routing protocols:
    • Border Gateway Protocol (BGP)
    • Open Shortest Path First (OSPF)
    • Intermediate System-to-Intermediate System (IS-IS)
  • The dynamic routing configuration uses single IP hop BFD.
  • The BIG-IP system receives a BFD control packet with a time-to-live (TTL) that is not 255.

Impact

The BIG-IP system establishes the BFD session with the nexthop neighbor device.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system can detect a routing protocol failure based on the erroneous BFD session impacting handling of dynamic routing.
