A specially crafted URL may prompt Endpoint Inspector to trigger the BIG-IP Edge Client Component Installer and mislead you into installing a CAB file that is not signed by the F5 Networks certificate. The URI takes the following form:

f5-epi://<URI>

Malicious actors may use the crafted f5-epi URI as a delivery method to trigger the installation or execution of malicious arbitrary code on the Windows client device.

The F5 Endpoint Inspector application, introduced in BIG-IP 13.0 for BIG-IP Edge Client on Windows-based systems, is a browser protocol handler for the f5-epi protocol. Two mechanisms are used to auto-update Edge Client components on Windows: the F5 Component Installer service and InstallerControl. The behavior described in this case makes use of the latter mechanism.

F5 Component Installer Windows service

The Component Installer requires administrative permissions at install time. This component installs and registers a Windows service that installs F5-signed components onto the system. The Component Installer service requires that installation or upgrade packages be signed using the F5 certificate or another trusted certificate in which a chain of trust is established to a root certificate in the F5 root certificate store. The Component Installer service silently installs F5-signed components onto the system. If the package is not F5-signed, it is silently discarded.

User mode installation with InstallerControl component

The InstallerControl component installs the packages signed by the F5 certificate or another trusted certificate installs other signed components onto the system. A trusted certificate may be one that is signed by a third-party certificate that is trusted by Windows and located in one of the certificate stores. For example, the Trusted Root Certification Authorities store. This is known as user-mode component install. InstallerControl silently installs F5-signed components, but User Account Control (UAC) prompts are shown if the package installation requires elevation of privilege. When InstallerControl installs the packages that are signed by another trusted certificate, a confirmation prompt with signer information is shown. You should then review the signer information in the prompt before approving.

If the package installation requires elevation of privilege, UAC prompts are shown. Those with administrative access to the Windows-based system have to accept the UAC prompt for the installation to complete. Those without administrative access need to provide administrator credentials to proceed with the installation. 

Note: This functionality is designed to allow automatic update of BIG-IP Edge Client components when F5 Component Installer service is not installed on the machine. It is also used to install third-party components distributed through BIG-IP system.

For more information on trusted certificates in the Windows installation process, refer to Microsoft PKI Certificate Directory and its related content.

Environment

  • F5 Endpoint Inspector application is installed.
  • F5 Component Installer Windows service is not installed
  • Components are updated by the InstallerControl component.

Cause

A specially crafted URI request using the F5 Endpoint Inspector URI format was sent through a web browser triggering component update via the InstallerControl component.

Recommended Actions

To prevent the InstallerControl component from installing a CAB file that has not been signed by F5 certificates, F5 recommends installing the F5 Component Installer Windows service to assist with installing or upgrading components so that the InstallerControl component is not used. To download the F5 Component Installer, perform one of the two procedures:

Downloading and install the Component Installer Package for Windows

  1. Navigate to Access > Connectivity / VPN > Connectivity > Client Downloads.
  2. Select the link for Component Installer Package for Windows .

Including the Component Installer Package for Windows in the BIG-IP Edge Client download

  1. Navigate to Access  > Connectivity / VPN > Connectivity > Profiles.
  2. Select the appropriate connectivity profile.
  3. Select the Customize Package Profile button and in the Customize Windows Client Package pop-up window, verify that the Component Installer Service check box is selected, then click Download.

After the download completes, install the package and verify that F5 Networks Component Installer is installed in Windows Services.

  • If the Component installer service cannot be installed on Windows client machines and you have to use the InstallerControl, you should review the installation through the User mode installation with InstallerControl component method. Note the following considerations.
    • You should take care when accessing untrusted sites.
    • When InstallerControl installs the packages which are signed by another trusted certificate, a confirmation prompt with signer info is shown, you should then review the signer information in the prompt before approving.
    • When prompted by Windows UAC and application prompts, you should always review the application and signer information and ensure that the signers in the prompts are approved before approving the install.
  • You should take care to ensure that malicious or untrusted certificates are not added to the Windows System’s Certificate Store. You should ensure that only software signed by organizationally trusted certificates can be installed by the InstallerControl component.
