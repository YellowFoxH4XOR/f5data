K10844420: Creating a PDF copy of Aspen Mesh release notes

Type
Support Solution
Published
2022-03-25
Updated
2023-02-21
Applies to
  • Aspen Mesh: 1.X.X
Source
https://my.f5.com/manage/s/article/K10844420

Description

The Aspen Mesh release notes can be found on the Aspen Mesh official site. If a PDF format file of release notes is needed, you can create a PDF copy of the release notes for a particular Aspen Mesh release, or any page of the documentation website, using reader view feature or extension of the web browser.

Environment

Aspen Mesh release note website.

Cause

The Aspen Mesh release note in PDF format is needed.

Recommended Actions

Safari
  1. Go to the page you want to create a PDF file of. For example, Aspen Mesh Carrier-Grade 1.11.7-am1 release notes.
  2. At the left end of Smart Search/Address Bar field, click the Show Reader View icon (Appears like a page).
  3. Select File > Export as PDF.
  4. Specify where to save the file and select Save.

Chrome

  1. If not already installed, install the Reader View extension.
  2. Go to the page you want to create a PDF file of. For example, Aspen Mesh Carrier-Grade 1.11.7-am1 release notes.
  3. Click the Extensions icon (Appears like a blob of paint) in the upper-right corner of the browser.
  4. Click Reader View.
  5. Select File > Print.
  6. In the Destination pop-up menu, select Save as PDF.
  7. Select Save.
  8. Specify where to save the file and select Save.

Note: In the Print menu, Chrome sometimes defaults to one page instead of all pages. You may need to turn Reader View off and then back on to see all pages in the Print menu.
