Description

Configuration needed to expose Nginx Dashboard using VirtualServers and VirtualServerRoutes

Environment

Nginx Ingress Controller 3.x

Cause

None

Recommended Actions

Nginx-Ingress deployment prerequisites:

  • The dashboard is enabled by default. Ensure that the nginx-status argument is not set to false.
  • The dashboard is available on port 8080 by default. It is customizable by the nginx-status-port  command-line argument.
  • Configure the nginx-status-allow-cidrs command-line argument with IP/CIDR blocks for which you want to allow access to the dashboard. By default, access is allowed for 127.0.0.1, ::1
1.- Create a service to target port 8080 from the Nginx-Ingress pods, make sure the selector label matches the ones from your nginx-ingress deployment: 
apiVersion: v1
kind: Service
metadata:
  name: nginx-dash-svc
  namespace: nginx-ingress
spec:
  ports:
  - port: 8080
    targetPort: 8080
    protocol: TCP
    name: http
  selector:
    app: nginx-ingress
2.- Create the following VirtualServer resource with /dashboard.html and /api paths: 
apiVersion: k8s.nginx.org/v1
kind: VirtualServer
metadata:
  name: cafe
  namespace: default
spec:
  host: cafe.example.com
  routes:
  - path: /dashboard.html
    route: nginx-ingress/dash
  - path: ~*^/api
    route: nginx-ingress/api-dash
  tls:
    secret: my-tls-secret
3.- Create the corresponding Virtualserverroutes:
/dashboard.html path: 
apiVersion: k8s.nginx.org/v1
kind: VirtualServerRoute
metadata:
    name: dash
    namespace: nginx-ingress
spec:
    host: cafe.example.com
    subroutes:
    - action:
        pass: dash
      path: /dashboard.html
    upstreams:
    - name: dash
      port: 8080
      service: nginx-dash-svc
/api path: 
apiVersion: k8s.nginx.org/v1
kind: VirtualServerRoute
metadata:
  name: api-dash
  namespace: nginx-ingress
spec:
  host: cafe.example.com
  subroutes:
  - action:
      pass: dash
    path: ~*^/api
  upstreams:
  - name: dash
    port: 8080
    service: nginx-dash-svc
 

Additional Information

After applying the resources above, you should be able to see the dashboard in the specified location, for this demo the url is https://cafe.example.com/dashboard.html:
