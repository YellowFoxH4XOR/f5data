Description

Geolocation database does not show region_name for IP addresses of some Spain provinces.
 

Environment

  • BIG-IP
  • Geolocation version: ip-geolocation-v2-2.0.0-20200713.448.0

Cause

Bug ID 931749
 

Recommended Actions

Please use recent Geolocation Database following:
K11176: Downloading and installing updates to the IP geolocation database

ip-geolocation-v2-2.0.0-20200810.453.0 and later is not affected.
 

Additional Information

To check if you are affected this issue, then run the following commands on CLI, the output does not have region_name output.

geoip_lookup -f /usr/share/GeoIP/v2/F5GeoIP.dat 62.99.79.82
geoip_lookup -f /shared/GeoIP/v2/F5GeoIP.dat 83.213.235.216
