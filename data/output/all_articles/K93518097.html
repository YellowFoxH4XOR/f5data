Description
BIG-IP VE HA pair - HA Connection detected DAG errors. 

Environment

  • BIG-IP Virtual Edition version 14.1.4
  • You have multiple BIG-IP systems in a high availability (HA) configuration.
  • You have enabled connection mirroring on the BIG-IP systems.
  • In the /var/log/ltm file, you may observe error messages that appear similar to the following example:

F501.COM: 
<Date> <Time>  F501.COM  err tmm[10440]: 01340004:3: HA Connection detected DAG discrepancy: local pg 0, remote pg 0, local pu 0, remote pu 2. Connection will be retried.
<Date> <Time>  F501.COM  err tmm3[10440]: 01340001:3: HA Connection with peer <IP_Address>:<Port_Number> for traffic-group /Common/traffic-group-1 established.

F502.COM:
<Date> <Time>  F502.COM notice DAG hash mismatch; discarding mirrored state
<Date> <Time>  F502.COM notice DAG hash mismatch; discarding mirrored state

Cause

The error messages are because there is a DAG mismatch. A different DAG is in use on each BIG-IP VE and that is being caused because F501.COM has ESXi hypervisor accessed via vmxnet3 driver, and F502.COM has KVM hypervisor accessed by virtio driver.
 

[root@F502.COM:Standby:In Sync] config # tmctl -d blade tmm/device_probed
pci_bdf      pseudo_name type      available_drivers    driver_in_use

------------ ----------- --------- -------------------- -------------
0000:00:03.0             F5DEV_PCI xnet, virtio, sock,
0000:00:04.0 1.1         F5DEV_PCI xnet, virtio, sock,  virtio
0000:00:05.0 1.2         F5DEV_PCI xnet, virtio, sock,  virtio                  <<------- KVM hypervisor

[root@F501.COM:Active:In Sync] config # tmctl -d blade tmm/device_probed
pci_bdf      pseudo_name type      available_drivers     driver_in_use

------------ ----------- --------- --------------------- -------------
0000:03:00.0             F5DEV_PCI xnet, vmxnet3, sock,
0000:13:00.0 1.2         F5DEV_PCI xnet, vmxnet3, sock,  vmxnet3
0000:0b:00.0 1.1         F5DEV_PCI xnet, vmxnet3, sock,  vmxnet3
0000:1b:00.0 1.3         F5DEV_PCI xnet, vmxnet3, sock,  vmxnet3                  <<------ ESXi hyperviSOR

The hypervisor of these 2 devices is different:
F501.COM ---> ESXi hypervisor --> tmm.daglib hash_name rss    --> tmm.device_probed driver_in_use vmxnet3
F502.COM ---> KVM hypervisor  --> tmm.daglib hash_name xor_ex --> tmm.device_probed driver_in_use virtio

Recommended Actions

The BIG-IP Virtual Edition hypervisor (host) system must be identical.
