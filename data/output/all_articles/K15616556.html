Software upgrade vs. software update

F5 has two kinds of software upgrades. F5 makes this distinction because upgrades and updates require different considerations before you install. Software updates may not require certification and validation steps because there are no changes in default behavior in the release. An example would be updating from 13.1.3.5 to 13.1.3.6, or 16.0.1 to 16.0.1.1. A point release is the safest course of action as no changes to existing default behaviors are introduced. Maintenance releases may contain changes in default behavior, but this is rare.

  • Upgrade: A version that introduces new features, hardware support, and specific performance improvements.
  • Update: A version that introduces product defect and security fixes.


You can discern upgrades from updates by examining your current and prospective BIG-IP version numbers. Increases in one or both of:

  • The first two numbers of your software version is an upgrade.
  • The last two numbers of your software version is an update.

Why such a significant size for an engineering hotfix file?

The engineering hotfix contains updated packages along with all dependent packages. Due to the difference in size between packages and difference in number of dependent packages, the resulting Engineering hotfix ISO size has the potential to vary greatly in size.
