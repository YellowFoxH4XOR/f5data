Known Issue

This is the result of a known issue. In some cases, the BIG-IP system may fail to release a nexthop pointer reference. As a result, over time the nexthop reference counter may exceed its maximum value of 2,147,483,647 (0x7FFFFFFF) and wrap back to zero. If a subsequent attempt to release a nexthop pointer reference decrements the counter below zero, TMM will crash and dump a core file. When this issue occurs, a message that appears similar to the following example is logged to the /var/log/tmm file:

panic: ../net/nexthop.c:117: Assertion "nexthop ref valid" failed.

F5 Product Development tracked this issue as ID 323759 and ID 330828, and it was fixed in BIG-IP version 10.1.0 as a result of the upgrade to the Linux 2.6 kernel. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WAN Optimization release notes.
