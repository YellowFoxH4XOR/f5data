Description

Zxfrd process is in a restart loop

  • zxfrd process is restarting non stop

  • zxfrd core

  • /var/log/kern.log shows zxfrd segfaulting

  • cat /proc/meminfo

    HugePages_Total                121107
    HugePages_Free                      0  <-
    HugePages_Rsvd                      0
    HugePages_Surp                      0
    Hugepagesize                     2048 kB

Environment       

  • zxfrd
  • zone transfer from external dns 
  • BIG-IP DNS

Cause

ID1030237

  • Available Free Hugepage is insufficient to load entire zone to be transfer
  • In addition, there could be an unknown situation where hugepage is not free up.

Recommended Actions

Workaround

  1. Login to the BIG-IP DNS command line.
  2. Type the following commands in sequence:
bigstart stop zxfrd
rm /dev/mprov/zxfrd/*
rm /shared/zxfrd/*
bigstart start zxfrd


Note: If after performing the above, zxfrd is still restarting due to the lack freehuge space, please open a case with F5 Support for further analysis.
