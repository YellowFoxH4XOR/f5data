K41718605: HSM hardware migration between different hardware platforms

Type

Published

Status
Legacy Content
Applies to

Source
https://my.f5.com/manage/s/article/K41718605

Description

Migrating configuration using SCF or UCS files from one FIPS HSM hardware platform to a different FIPS HSM hardware platform fails with various errors

Environment

  • BIG-IP 
  • FIPS hardware security module (HSM) included in the hardware platform

Cause

The platforms must be the same F5 hardware platform, and the firmware version must also be the same on both machines

Recommended Actions

Manually recreate the whole configuration on the new hardware

Additional Information

None
