Known Issue

This is the result of a known issue. Under rare conditions, a partially-initialized XML variable structure can cause the big3d XML parser to stop processing incoming XML messages. When this issue occurs, the big3d process stops processing LDNS probe paths.

F5 Product Development tracked this issue as CR67747, and it was fixed in BIG-IP LTM version 9.1.3. For information about upgrading, refer to the BIG-IP LTM release notes.
