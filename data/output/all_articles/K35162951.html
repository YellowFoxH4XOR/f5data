Description

  • ZoneRunner(zrd) in restart loop

  • In /var/log/daemon.log:

Re-starting zrd

  • Error message when checking named.conf: 

named-checkconf -t /var/named -z -j /config/named.conf

zone <example.com>/IN: journal rollforward failed: not exact
zone <example.com>/IN: not loaded due to errors.
external/<example.com.>/IN: not exact

Environment

  • BIG-IP DNS

  • ZoneRunner

  • DNS synchronization group

Cause

ZoneRunner(zrd) will be in restart loop if the zone files of BIG-IP DNS synchronization group doesn't match. The domain name (example.com) in the error message exists on one BIG-IP DNS but not on peer device.  

Recommended Actions

You can manually edit the named.conf file to make it same between DNS synchronization group.
Important: F5 recommends that you use the ZoneRunner utility to edit the DNS configuration file. Incorrectly editing the DNS configuration files on a BIG-IP DNS system can cause issues, such as the ZoneRunner utility or BIND failing to start properly.

  1. Login to BIG-IP DNS

  2. To stop the ZoneRunner(zrd) utility on the BIG-IP system, type the following command:

bigstart stop zrd

  1. Use a text editor to remove below zone config in /var/named/config/named.conf

    Note: Please make sure you backup the original /var/named/config/named.conf before modification

zone "example.com." {
    type master;
    file "db.external.domain.com.";
    allow-update {
        localhost; 
        };
};

  1. When you complet the necessary changes to the DNS configuration files, type the following command to verify that the syntax is correct or not:

named-checkconf -t /var/named -z -j /config/named.conf

If there is a syntax error in the DNS configuration file, the output from the named-checkconf command reports the error.

  1. Remove the zone db and journal file in /var/named/config/namedb/

    Note: Please make sure you backup the following files before delete.

rm /var/named/config/namedb/db.external.example.com.

rm /var/named/config/namedb/db.external.example.com..jnl

  1. If no syntax errors were found, restart the named process by typing the following command:

bigstart restart named

  1. To restart the ZoneRunner(zrd) utility, type the following command:

    bigstart start zrd

  2. Check /var/log/daemon.log to make sure the ZoneRunner(zrd) no longer restart.
