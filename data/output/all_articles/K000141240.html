Description

In rare instances, F5 Support may ask to enable additional debugging level for the avrd daemon.

Environment

AVR, or at least one of the modules that leverages AVR (including AFM, ASM, APM, and PEM), is provisioned.

Recommended Actions

Enabling avrd debugging

  1. Make a backup of the avrd logging file:

cp /etc/avr/avrd_logger.cfg /etc/avr/avrd_logger.cfg.bak

 

  1. Edit the /etc/avr/avrd_logger.cfg file

    # sed -i 's/^\(AVRD_GENERAL\|TMM_API\|DOS_VISIBILITY\)\(\s*\)NOTICE/\1\2DEBUG/' /etc/avr/avrd_logger.cfg

    • We're changing the items AVRD_GENERAL, TMM_API and DOS_VISIBILITY from level NOTICE to DEBUG.
    1. Return to the CLI and force AVR to reload its configuration files using these commands:

    tmsh modify sys db md.dologging value 0
    tmsh modify sys db md.dologging value 1

     

    Note: This does not require an avrd restart.  Additional messages will be logged to the /var/log/avr/avrd.log file.

    Disabling avrd debugging

    • To restore the previous avrd logging configuration:

    cp /etc/avr/avrd_logger.cfg.bak /etc/avr/avrd_logger.cfg
    tmsh modify sys db md.dologging value 0
    tmsh modify sys db md.dologging value 1

     

    Note: This does not require an avrd restart.
