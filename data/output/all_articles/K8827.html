Known Issue

This is the result of a known issue. The gateway fail-safe feature monitors traffic between the active BIG-IP system and a pool containing a default gateway device. Configuring gateway fail-safe means designating a load balancing pool as a gateway fail-safe pool, and assigning gateway fail-safe specific settings (such as the unit ID number, and the action that the BIG-IP system should take upon gateway failure).

When you designate a load balancing pool as a gateway fail-safe pool, and then remove the gateway fail-safe designation for the pool, the gateway fail-safe settings remain configured for the pool.

F5 Networks Product Development is tracking this issue as CR93321.
