K000135143: Restricting incoming connection based on source IP and Port in Traffix SDC

Type
Support Solution
Published
2023-06-25
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.0
Source
https://my.f5.com/manage/s/article/K000135143

Description

  • There are instances where you need to restrict incoming connections based on source IP address to the SDC

Environment

  • Traffix SDC 5.x

Cause

By design.

 

 Recommended Actions

  1. You can restrict incoming IP client by going to Topology > Site > Access Control list (turn off \"accept unknown peers\") and add ip address that you want to accept or keep \"accept unknow peers\" but add ip address that you want to reject.
  2. There is no option to set source port.

Additional Information

Refer to Section 3.3.9 Configuring the Access Control List in SDC User Guide.
