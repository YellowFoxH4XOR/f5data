Topic

You can configure the BIG-IP ASM system to block requests based on customized criteria. The table in the following section shows the methods the BIG-IP ASM system uses in response to a request violation that triggers the blocked response for an enforced security-policy configuration.

Description

Request violationMethod
Application securityHTML blocking page (HTTP 200)
TPS-based request blocking, when configured to Block AllTCP reset
AJAXHTTP/1.1 200 OK - XML <soap:Fault>
XMLHTML blocking page (HTTP 200)
JSONHTML blocking page (HTTP 200)
GWTHTML blocking page (HTTP 200)
Brute forceTCP reset
Protocol security for FTP and SMTPTCP reset
DoS protection for behavioral and stress-basedTCP reset
Bot defenseHTML blocking page (HTTP 200)
Geolocation enforcementHTML blocking page (HTTP 200)

Recommendations

When configuring a BIG-IP ASM security policy set in Blocking mode, many of the listed application security configuration options offer non-blocking mitigation settings prior to using blocking on the request. For example, TPS-based, brute force, and DoS protection offer the ability to present a CAPTCHA challenge to the request. Additionally, you can configure these methods to rate limit the request rather than blocking the request.
