K000137865: Can't open command history file (/home/Chkuser/.tmsh-history-<UserName>),Permission denied

Type
Support Solution
Published
2024-06-12
Updated
2024-06-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000137865

Description

When user tries to login via SSH, error messages such as below appears when logging into CLI of the BIG-IP:

Example:

Can't open command history file (/home/Chkuser/.tmsh-history-Example),Permission denied

Environment

  • BIGIP
  • SSH login
  • Bash

Cause

The owner of .tmsh-history-Example is wrong.

# ll /home/Example -a
total 12
drwx------. 2 Example webusers 1024 2023-11-20 21:27 .
drwxr-xr-x. 9 root   root   1024 2023-11-20 21:25 ..
-rw-r--r--. 1 Example webusers  18 2020-12-02 11:59 .bash_
out
-rw-r--r--. 1 Example webusers 176 2020-12-02 11:59 .bash_profile
-rw-r--r--. 1 Example webusers 124 2020-12-02 11:59 .bashrc
-rw-------. 1 root    webusers 147 2023-11-20 21:39 .tmsh-history-Example

Recommended Actions

Change the owner back:

# cd /home/Example
# chown Exmapler ./.tmsh-history-Example

Verify owner of .tmsh-history-Example:

# ll /home/Example -a
total 12
drwx------. 2 Example webusers 1024 2023-11-20 21:27 .
drwxr-xr-x. 9 root   root   1024 2023-11-20 21:25 ..
-rw-r--r--. 1 Example webusers  18 2020-12-02 11:59 .bash_logout
-rw-r--r--. 1 Example webusers 176 2020-12-02 11:59 .bash_profile
-rw-r--r--. 1 Example webusers 124 2020-12-02 11:59 .bashrc
-rw-------. 1 Example webusers 147 2023-11-20 21:39 .tmsh-history-Example
