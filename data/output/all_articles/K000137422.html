K000137422: "JSON data does not comply with JSON schema" violation is not displayed in learning and blocking settings with an ASM license

Type
Support Solution
Published
2023-10-31
Updated
2023-10-31
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.2
Source
https://my.f5.com/manage/s/article/K000137422

Description

"JSON data does not comply with JSON schema" violation is not displayed at

Security  ››  Application Security : Policy Building : Learning and Blocking Settings with an ASM license

 

Environment

  • ASM provisioned
  • ASM policy configured

 

Cause

The violation "JSON data does not comply with JSON schema" is only available with an Advanced WAF license.

 

Recommended Actions

  1. Verify if you have an Advanced WAF license:
    # egrep '(waf_gc|mod_waf|mod_datasafe).+?enabled' /config/bigip.license
    • If this output displays waf_gc, mod_waf, mod_datasafe then the Advanced WAF features are enabled and you have an Advanced WAF license.
    • If the command above does not output anything then you do not have an Advanced WAF license, proceed to step 2 below.
  2. Reactivate your license.
