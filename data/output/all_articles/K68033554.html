K68033554: LDAP / Active Directory administrative login to GUI fails after upgrade to 14.1.x

Type
Support Solution
Published
2020-07-22
Updated
2025-02-06
Applies to

Description

After upgrading to 14.1.x, you may not be able to login to the admin GUI with remote groups, using Active Directory authentication.

  • tcpdump showed user is a member of many groups
  • LDAP server replies with a list of attributes (e.g., list of memberOf) where more than one match existing role.
  • User may get assigned to Guest group, by BIG-IP.
  • err httpd[16648]: [auth_pam:error] [pid 16648] [client x.x.x.x:58993] AUTHCACHE PAM: user 'john.smith  - invalid account: Authentication failure, referer: https://yourbigip.com/tmui/login.jsp

Environment

  • BIG-IP running 14.1 or later.  15.0 or later
  • Remote Active Directory authentication with Remote Role groups

Cause

  • BIG-IP assigns the user to the last attribute in the list that matches a role, potentially yielding a more restrictive set of permissions.

Recommended Actions

  • Ensure "Check Member Attribute in Group" is enabled, in your authentication settings.  If this does not resolve the problem, an Engineering Hotfix may be available from F5 Support.

Additional Information

  • Bug ID 762385: Wrong remote-role assigned using LDAP authentication after upgrade to 14.1.x and later
