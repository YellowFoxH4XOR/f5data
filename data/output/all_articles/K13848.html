Known Issue

The BIG-IP Analytics CSPM feature may inject Javascript into HTTP responses when the injection will not generate any information usable by the Analytics module.

This issue occurs when all of the following conditions are met:

  • A virtual server is configured with a BIG-IP Analytics profile
  • The BIG-IP Analytics profile has the Collected Metrics: Page Load Time option enabled

The CSPM feature injects JavaScript into HTTP responses in order to allow the BIG-IP Analytics module to track the Page Load Time metric. This feature is only supported by certain browsers. However, the JavaScript is injected regardless of whether the client browser type supports the feature, and cannot be disabled for transactions where it offers no benefit.

Impact

Unnecessary JavaScript is added to HTTP responses.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • HTTP responses to unsupported client browsers include the CSPM JavaScript
