Known Issue

A web page accessed through BIG-IP APM portal access may fail to load properly.

This issue occurs when all of the following conditions are met:

  • The web page scripts use MSXML2.
  • The web browser used is Internet Explorer 7 or later.

Impact

The web page may not function as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The web page may fail to load or exhibit incorrect behavior.
  • The web browsers may display an error message that appears similar to the following example:

    Line: 680
    Error: This method cannot be called after the send method has been called.
