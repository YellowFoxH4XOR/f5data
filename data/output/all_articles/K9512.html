K9512: FirePass now stores all RADIUS attributes in session variables

Issue

Starting in FirePass 6.0.3, FirePass stores all RADIUS attributes received in a RADIUS response in the session.radius.auth and session.radius.groupmapping session variables. This behavior allows FirePass to make a single request to the RADIUS server if the same server is used for both master group authentication and dynamic group mapping, which results in increased efficiency and lower overhead. Previously, FirePass would send multiple requests to the RADIUS server.

Note: For more information about RADIUS session variables, refer to K9513: Overview of RADIUS session variables.
 
Note: For more information about using session variables, refer to the FirePass Controller Administrator Guide.
 
F5 Product Development tracked this enhancement as CR78099 and it was included starting in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.
