Issue

Beginning in ARX 5.0.0, CIFS proxy users can use NTLM or Kerberos authentication to access back-end filers. NTLMv2 is not supported for the CIFS proxy users.

ARX versions prior to 5.0.0 only support NTLM authentication for CIFS proxy users to access the back-end filers. Kerberos and NTLMv2 are not supported for CIFS proxy users.

Note: For more information about creating CIFS proxy users, refer to the Preparing for CIFS Authentication chapter in the ARX CLI Storage Guide.
