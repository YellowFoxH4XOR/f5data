K22079615: 01070734:3: Configuration error: Can't associate Policy Sync Status

Type
Support Solution
Published
2021-08-02
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.3, 14.1.4
Source
https://my.f5.com/manage/s/article/K22079615

Description

Attempting to verify configuration using a specific tmsh verify command results in "folder does not exist" error such as:

01070734:3: Configuration error: Can't associate Policy Sync Status (/Common/POLICYSYNC_example/example_psd_f5-example.com /Common/f5-example.com) folder does not exist

Environment

  • BIG-IP APM
  • VCMP Guest
  • Upgrading from 14.1.4 to 15.1.3
  • Configuration contains folder defined in /config/bigip_base.conf
  • Access Policy Sync defined in /config/bigip.conf references above folder

Cause

The tmsh command "tmsh load sys config file /config/bigip.conf verify", only verifies configuration file in bigip.conf. 
Since the above tmsh command limits the verification to just /config/bigip.conf, the folder definition can't be found.

For example:

/config/bigip_base.conf contains:

sys folder /Common/POLICYSYNC_example {
description "example access policy"
device-group /Common/EXAMPLE
hidden false
inherited-devicegroup false
inherited-traffic-group false
traffic-group none
}

and /config/bigip.conf contains:

apm policy psync-status /Common/POLICYSYNC_example/example_psd_f5-example.com {
access-profile /Common/example
source-device /Common/f5-example.com
sync-description "No policy sync activity on Standby"
sync-status success-secondary
target-device /Common/f5-2-example.com
update-time 2021-07-24:10:50:03
}

causing the error:
01070734:3: Configuration error: Can't associate Policy Sync Status (/Common/POLICYSYNC_example/example_psd_f5-example.com /Common/f5-example.com) folder does not exist

Recommended Actions

Use the correct tmsh command without any file names to verify entire configuration, such as below:

tmsh load sys config verify

None.
