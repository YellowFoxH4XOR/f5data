K000141094: BIGIP is not able to ping server whose MAC address has changed

Type
Support Solution
Published
2024-09-17
Updated
2024-09-17
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000141094

Description

When checking with tmsh show net arp command you noticed that the BIGIP device has not updated its ARP table with a new MAC address of the backend server.

Environment

  • MAC address changed
  • ping is not working

Cause

The MAC address for that particular server has been added as a static entry. This is why the new MAC address has not been updated dynamically.

Recommended Actions

When using static ARP you need to update it manually:

1) Log in to the BIG-IP Configuration utility.

2) Click Network >> ARP >> Static List

3) Select the server in question.

4) In the MAC Address box, type the correct MAC address.

5) Click Finished.
