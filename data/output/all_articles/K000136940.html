Description

Scheduled QKView uploads to iHealth have been failing since June 2023.

 

Environment

  • BIG-IQ
  • iHealth

Cause

K000132249: Authentication changes in F5 iHealth

Recommended Actions

In June, the iHealth service was updated and is now using a new authentication method which is no longer compatible with older software versions. You will need to update BIG-IQ to 8.3 to restore this functionality.
