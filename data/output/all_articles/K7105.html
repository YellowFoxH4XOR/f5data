Known Issue

This is the result of a known issue. The BIG-IP GTM system does not honor the prober address specified for a host server for use with an SNMP monitor when probing.

The purpose of the host address is to tell the BIG-IP GTM system which device should perform the probing. However, the BIG-IP GTM system dispatches the monitor request to another BIG-IP LTM or BIG-IP GTM device in the same data center as the host server. As a result, the administrator cannot restrict probing to a particular system.

F5 Product Development tracked this issue as CR74182 and it was fixed in BIG-IP GTM 9.3.0 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
