K000156967: Is there in-built feature to dynamically monitor FQDN?

Type
Support Solution
Published
2025-11-02
Updated
2025-11-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000156967

Description

  • You are load balancing internet traffic on to ISP link and has ICMP transparent monitor verifying Google DNS. The issue with this setup is that when a specific URL fails, it will still mark the pool up as the ISP router and Google DNS is reachable.
  • When you mention the URL in HTTPS or ICMP monitor, an IP address gets resolved and BIG-IP will only monitor that particular IP address. You want BIG-IP to dynamically monitor whatever IP address is resolved at that particular time.

Environment

  • BIG-IP
  • LTM monitor

Cause

None

Recommended Actions

In-built FQDN monitoring feature is not there, where BIG-IP will dynamically monitor the URL. Workaround is specifically mentioning all IP address of the URL to monitor and setting the number of minimum available monitor required to mark the pool up or try to set up an external monitor.

None
