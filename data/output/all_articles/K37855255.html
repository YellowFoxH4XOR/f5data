K37855255: Error Message: 01071031:4: Security setting <SecuritySetting> has been disabled by user <User>

Updated

Applies to

Source

Issue

Error Message

warning mcpd[<PID>]: Security setting <SecuritySetting> has been disabled by user <User>

In this error message, note the following:

  • <PID> is the process ID of the mcpd process.
  • <SecuritySetting> is the security database variable which has been modified.
  • <User> is the BIG-IP user which modified the database variable.

For example:

warning mcpd[12345]: 01071031:4: Security setting systemauth.disablerootlogin has been disabled by user admin
warning mcpd[12345]: 01071031:4: Security setting systemauth.disablebash has been disabled by user admin
warning mcpd[12345]: 01071031:4: Security setting systemauth.primaryadminuser has been modified from admin to newadmin by user admin

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • A user with sufficient privileges modifies one of the following database keys:
    • systemauth.disablerootlogin
    • systemauth.disablebash
    • systemauth.primaryadminuser

 

Impact

None

Recommended Actions

This message is informational, but a system or security administrator may use these messages to detect or audit changes to security settings.
