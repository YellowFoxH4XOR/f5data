K83526544: After upgrade to version 14.1.0 LDAP Remote Authentication fails

Description

Lightweight Directory Access Protocol (LDAP) Authentication may fail if BIND-DN and User-template are both used when setting up LDAP for Remote Authentication.

  • LDAP Remote Authentication fails
  • Error message within /var/log/daemon.log

    <hostname> warning nslcd[pid]: [xxxxx] <authc="user"> <hostname>: lookup failed: Invalid DN syntax

Environment

  • After upgrade to BIG-IP Version 14.1.0
  • LDAP Remote Authentication with both a BIND-DN and User Template are set within the LDAP Configuration.   

    Example:

    auth ldap /Common/system-auth {
        bind-dn CN=XXXXXX,OU=XXXXXXXXX,DC=XXX,DC=XXXX,DC=XXX,DC=XXX   <------------------
        bind-pw ***scrubbed***
        check-roles-group enabled
        login-attribute samaccountName
        search-base-dn OU=XXXXXXX,DC=XXXX,DC=XXXX,DC=XXX,DC=XX
        servers { <server-IP / fqdn> }
        user-template %s@your.domain.com                                <------------------    

Cause

LDAP Configuration Incompatibility

Recommended Actions

  • To resolve this issue, use either a BIND-DN or a User Template. 
    • The Bind and User Template options are mutually exclusive. You should define one setting or the other, but not both
