K29053746: Attaching iRule DOSL7::enable when mitigation is not enabled at dosl7 profile, it is not showing warning in GUI.

Source

Description

While using DOSL7::enable command in iRule, the incoming connections are getting Reset with the following error in LTM log:

01220001:3: TCL error: /Common/dos <HTTP_REQUEST> - Operation not supported (line 1)     invoked from within "DOSL7::enable /Common/dos_test"

Environment

  • BIG-IP ASM
  • dosl7 profile without any mitigation enabled
  • iRule including DOSL7::enable command

Cause

The issue is due to a bug tracked as Bug ID 1067917.

Recommended Actions

There is no fix for this Bug ID at the time of article's publication.
As a workaround, it's suggested to enable the mitigation in DOSL7 profile.

None.
