Known Issue

This is the result of a known issue. When working with the BIG-IP Configuration utility, if a screen includes one or more drop-down boxes, the browser automatically sets focus on the first drop-down box. The affected screens include:

  • Overview >> Traffic Summary
  • Overview >> Performance
  • Overview >> Statistics

As a result, if you use the scroll wheel, the selection of the drop-down box may change and the page may automatically refresh. Using the scroll wheel is quite common, given the large size of some of the affected screens.

Note: While all browsers automatically set focus on the first drop-down box, not all browsers react the same way when you use the scroll wheel. For example, Internet Explorer 6 is known to change the selection of the drop-down box.

F5 Product Development is tracking this issue as ID 285054 (formerly CR67657).
