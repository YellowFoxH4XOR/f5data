Known Issue

This is the result of a known issue. If RAM Cache is configured for a size that exceeds TMM provisioning, the BIG-IP system does not initialize the cache. If the BIG-IP WebAccelerator is provisioned on the system, and attempts to clear the RAM Cache statistics, TMM crashes while accessing the non-existent statistical data.

F5 Product Development tracked this issue as CR116568 and it was fixed in BIG-IP 10.0.1. For information about upgrading, refer to the BIG-IP LTM, ASM, WebAccelerator, or WAN Optimization Module Release Notes.

Additionally, this issue was fixed in BIGIP-10.0.0-5514.0-HF2 for BIG-IP version 10.0.0. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
