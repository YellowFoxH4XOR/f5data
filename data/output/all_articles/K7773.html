Topic

A few 1500 platform systems that shipped in mid-2005 used BIOS version OBJ-0084-00, which allowed the system to power on when reapplying AC power, even if the system's soft power state was set to OFF by the LCD before the AC power was removed. The issue was resolved in BIOS version OBJ-0084-01.

You can display the BIOS version and revision information by performing the following procedure:

  1. Log in to the BIG-IP command line.
  2. Display the BIOS version information, by typing the following command:

    dd bs=65k count=10 skip=15 </dev/mem|strings|grep -e BIOS -e REV

    The command will return an output similar to the following example:

    Phoenix - AwardBIOS v6.00PG
    IBM COMPATIBLE 486 BIOS COPYRIGHT Phoenix Technologies, Ltd
    Phoenix - AwardBIOS v6.00PG
    odTYAN Tomcat I7210 S5112
    2092006 OBJ-0084-01 REV. J
    10+0 records in
    10+0 records out

    In this example, the BIOS version is v6.00, OBJ-0084-01 REV. J.

Workaround

If the desired behavior is for the system to remain powered off after power is applied to 1500 platforms with BIOS version OBJ-0084-00, perform the following procedure:

Note: Console access is required for this procedure.

  1. Power up the 1500 platform.
  2. During system boot up, press the TAB key to access the 1500 platform BIOS settings.

    The Phoenix - AwardBIOS CMOS Setup Utility is displayed.

  3. Use the arrow keys to select the Power Management Setup option.
  4. Press Enter.

    The power management options menu is displayed.

  5. Use the arrow keys to select the Power On Setup option.
  6. Press Enter.

    The power on setup options menu is displayed.

  7. Use the arrow keys to select the PWRON After PWR-Fail option.
  8. Use the +/-/Page Up/Page Down keys to configure the PWRON After PWR-Fail value to be Off.
  9. Press the F10 key to save the CMOS configuration and exit the setup utility.
  10. Press the Y key to confirm.
  11. The system will reboot.

    The system will now remain powered off after power is applied to 1500 platform when the system's soft power state was set to OFF by the LCD before the AC power was removed.
