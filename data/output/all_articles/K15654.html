Known Issue

You are unable to create or modify BIG-IP APM access policy agent properties.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM administrative user is using the Internet Explorer 7 browser.
  • You are using the Configuration utility visual policy editor to create or modify an access policy agent.

Impact

You are unable to create or modify an access policy agent.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you attempt to create or modify an access policy agent using the Configuration utility visual policy editor, the system displays the following browser pop-up error.

    Object doesn't support this property or method

  • You cannot access the access policy agent configuration.

Resolution

Status

F5 Product Development has assigned ID 428671 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release11.5.0K2200: Most recent versions of F5 software
Hotfix11.4.0 HF4K9502: BIG-IP hotfix matrix

Note: BIG-IP APM 11.4.1 is not affected by this issue.

Workaround

To work around this issue, you can use a different browser or newer release of the Internet Explorer browser.
