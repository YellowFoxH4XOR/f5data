Description

When BIG-IP is configured for Remote Authentication of BIG-IP administrative accounts, the "Password" fields are no longer displayed when creating or editing user accounts in the "System > Users" section of the GUI. This is because the user's passwords will be verified by the remote AAA server, not the BIG-IP. So it is the remote AAA server where the user's password must be set, not the BIG-IP. 

If BIG-IP is reconfigured back to Local Authentication, the "Password" fields are restored when creating or editing user accounts in the "System > Users" section of the GUI.

Environment

  • BIG-IP configured for Remote Authentication of BIG-IP administrative accounts.
  • 'Fallback to Local' is set to 'Disabled'

Cause

This is expected behavior when BIG-IP is configured for Remote Authentication.

Recommended Actions

Set new user passwords or reset existing user password on the remote AAA server when using Remote Authentication of BIG-IP administrative logins.
Or enable 'Fallback to Local' under System >> Users >> Authentication.
