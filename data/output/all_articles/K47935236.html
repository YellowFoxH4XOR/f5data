K47935236: DBD::mysql::db do failed: Lock wait timeout exceeded; try restarting transaction at /usr/local/share/perl5/F5/DbUtils.pm

Type
Support Solution
Published
2021-10-29
Updated
2023-02-21
Applies to

  • BIG-IP
  • BIG-IP ASM: 15.1.2
Source

Description
When trying to remove an ASM Policy from a Virtual Server next message appears: 

DBD::mysql::db do failed: Lock wait timeout exceeded; try restarting transaction at /usr/local/share/perl5/F5/DbUtils.pm 

Environment

  • BIG-IP ASM
  • Removing ASM policy from Virtual Server
  • Next logs in var/log/ts/asm_config_server.log:

    asm_config_server.pl|INFO|Oct 27 15:30:30.075|23687|F5::ASMConfig::Handler::spawn_async_handler,,Spawned new async pid 4629
    asm_config_server.pl|INFO|Oct 27 15:30:30.097|4629|F5::ASMConfig::Handler::spawn_async_handler,,Async handler starting
    asm_config_server.pl|INFO|Oct 27 15:30:30.104|4629|F5::LockFactory::Base::lock,,F5::ASMConfig::Handler Line 3690 has locked '/ts/lock/asm_config_server_async_for_23687.lock'. (Lock count: '1', Self count: '1')
    asm_config_server.pl|INFO|Oct 27 15:31:00.161|4629|F5::ASMConfig::Handler::spawn_async_handler,,8 calls handled since async startup (last call handled = update_suggestion)

Cause
A signature update and db locks.

Recommended Actions

One of next: 
  • Wait until update is done
  • Change update time to other time out of administrative actions in the F5
