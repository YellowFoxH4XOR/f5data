Issue

Error Message

011a9007:5: Requesting a dump when one is already happening. Ignoring new request

Message Location

You may encounter this error message in the following location:

  • The /var/log/gtm file

Description

This message occurs when the following condition is met:

  • You have changed the Metrics Caching setting to a lower than recommended value.

When using a dynamic load-balancing algorithm, the BIG-IP GTM system dumps its path and other metrics data to the /config/gtm/ldns.gz file once per hour (3600 seconds, by default). This behavior is controlled by the Metrics Caching setting. Changing the Metrics Caching setting to a value that is too low for your environment may result in overlapping attempts to dump the path and metrics data to the /config/gtm/ldns.gz file. When this occurs, the BIG-IP GTM system generates the error message.

Impact

The system may experience resource issues by attempting to dump the path and metrics data too frequently.

Recommended Actions

Change the Metrics Caching setting to the default value. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration.
  3. From the Global Traffic list, select Metrics Collection.
  4. Change Metrics Caching to 3600.
  5. Click Update.
