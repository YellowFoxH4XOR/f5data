K000135265: Importing a CSV file fails due to invalid IP address

Type
Support Solution
Published
2023-06-28
Updated
2023-06-28
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000135265

Description

When import a CSV file for BIG-IP devices in GUI, get the error message 'invalid IP address'

 

Environment

  • BIG-IQ CM
  • BIG-IP

Cause

When save a CSV file in Microsoft Excel, use CSV UTF-8 format.

 

Recommended Actions

Save this CSV file to 'Comma-separated Values' in the Excel.

 

Additional Information

None.
