Topic

This article applies to BIG-IP 11.x. For information about other versions, refer to the following articles:

  • K12017: The Redundancy State Preference setting should be set to None when the HA group option is configured

The Auto Failback setting is not compatible prior to BIG-IP 13.0.0, and you should not use it  with the HA group feature.

Note: The Auto Failback option is compatible with the HA group feature in BIG-IP 13.0.0 and later.

Description

In BIG-IP 11.0.0 - 11.4.1, the Configuration utility incorrectly allows you to configure the Auto Failback setting when using the HA group feature. The Auto Failback setting is not compatible with the HA group feature. When the BIG-IP systems in a device group are configured with HA group, the sod process decides which device should be active or standby based on the HA scores calculated amongst all the devices in a Sync-Failover device group. If a traffic group is enabled with the Auto Failback setting and a failover occurs, the system will fail back the traffic group to the default device when it becomes available at a later time. However, the sod process will use the calculated HA scores to determine if the default device should be active or standby and proceed to perform another failover if the default device has a lower HA score than the peer device. As a result, the BIG-IP systems may experience multiple failovers during the failback process. Hence enabling both HA group and Auto Failback setting can have unpredictable results. This behavior is by design.

Recommendations

When configuring an HA group, you should consider the following factors:

  • If the devices in the same Sync-Failover device group are configured with HA group, you must disable the Auto Failback setting for the associated traffic groups
  • If you require the traffic group to automatically fail back to the default device, you must disable the HA group on all the devices in the Sync-Failover device group

Procedures

Disabling the Auto Failback setting for the associated traffic groups

Traffic Management Shell (tmsh)

  1. To disable the Auto Failback setting for the associated traffic groups, use the following command syntax:

    tmsh modify /cm traffic-group <traffic group name> auto-failback-enabled false

    For example, you would type the following command to disable the Auto Failback setting for the mytrafficgrp traffic group:

    tmsh modify /cm traffic-group mytrafficgrp auto-failback-enabled false

  2. Save the changes by typing the following command:

    tmsh save /sys config

Configuration utility

  1. Log in to the Configuration utility.
  2. For BIG-IP 11.3.0 and later, go to Device Management > Traffic Groups.

    Note: For BIG-IP 11.0.0 through 11.2.1, go to Network > Traffic Groups.

  3. Select the name of the traffic group.
  4. Clear Auto Failback.
  5. Select Update.
  6. Repeat steps 1 through 5 for any remaining traffic groups.

Disabling the HA group on all devices in the Sync-Failover device group

Traffic Management Shell (tmsh)

  1. To disable the HA group on all devices in the Sync-Failover device group, use the following command syntax:

    tmsh modify /sys ha-group <name of HA group> disabled

    For example, you enter following command to disable the myhagrp HA group:

    tmsh modify sys ha-group myhagrp disabled

  2. Save the changes by entering the following command:

    tmsh save /sys config

Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > High Availability > HA Group.
  3. To disable the HA group, clear the Enable check box.
  4. Select Update.
