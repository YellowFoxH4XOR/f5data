K000139795: VIPRION is INOPERATIVE mode after software upgrade and clusterd restarting

Type
Support Solution
Published
2024-05-28
Updated
2024-05-28
Applies to
  • VIPRION Platforms
  • BIG-IP
  • BIG-IP LTM: 16.0.0, 16.0.X, 16.0.1, 17.X.X, 16.X.X, 15.1.0, 15.1.1, 15.1.2, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K000139795

Description

After upgrade to BIG-IP v15, BIG-IP v16 and BIG-IP v17 in VIPRION, device is not able to boot up and INOPERATIVE via console, and clusterd restarts continuously.

 

Environment

  • Viprion
  • BIG-IP
  • Local mirror address is IPv6

 

Impact

VIPRION is INOPERATIVE mode, and unable to boot up.

 

Condition

In console mode, error messages as below are shown in /var/log/ltm
err clusterd[12497]: 013a0004:3: result {
err clusterd[12497]: 013a0004:3:     result.code 17237767
err clusterd[12497]: 013a0004:3:     result.attribute value
err clusterd[12497]: 013a0004:3:     result.message 01070707:7: The state mirroring address, statemirror.ipaddr, 2001:DB8:: may not be on the same network as the management port
err clusterd[12497]: 013a0004:3: }
notice clusterd[12497]: 013a0006:5: Disconnecting from mcpd.
info clusterd[12497]: 013a0007:6: clusterd stopping...

 

Cause

This is caused by Bug ID 1032001

 

Recommended Actions

Roll back to previous software version.
Before upgrade. remove the IPv6 local mirror address, or change the IPv6 local mirror address to IPv4.

 

Additional Information

Engineering Hotfix is available on request for ID 1032001.
