K000130633: Are ASM signature update files hash checked prior to installation?

Type
Support Solution
Published
2023-01-30
Updated
2023-01-30
Source
https://my.f5.com/manage/s/article/K000130633

Description

Live Update feature does not download ASU's MD5 file, and does not perform MD5 checksum at any point.

 

 

Environment

  • ASM or Advanced WAF
  • Signature files updated automatically via LiveUpdate in Real Time mode.

 

﻿Additional Information

The .im files provided by F5 is signed and encrypted via GPG utility that guarantees its integrity. The integrity check is performed at a couple of steps:

 

- when the file arrives at BigIP (automatically downloaded or manually uploaded)

- when a file is about to be installed.

 

  • Besides GPG, there are two more verifications such as file type (GNU file command) and directory structure check to ensure they meet the necessary standard requirements. This process is visible within /var/log/tomcat/liveupdate.log whenever signature updates are performed.
