Known Issue

This is the result of a known issue. The drop count behavior for unicast packets with matching source and destination MAC addresses not associated with the receiving BIG-IP system differs between some BIG-IP platforms. This behavior occurs due to a difference in the switch chips used in BIG-IP platforms.

Note: On a BIG-IP LTM system, you can view the dropped packet counter for an interface by running the bigpipe interface show all command.

The following BIG-IP platforms increment the dropped packet counter when receiving and discarding unicast packets with matching source and destination MAC addresses not associated with the receiving BIG-IP system:

  • BIG-IP 1500 (C36)
  • BIG-IP 3400 (C62)
  • BIG-IP 6400 (D63)
  • BIG-IP 6800 (D68)
  • BIG-IP 8400 (D84)

The following BIG-IP platforms do not increment the dropped packet counter when receiving and discarding unicast packets with matching source and destination MAC addresses not associated with the receiving BIG-IP system:

Note: The following platforms are not supported under the BIG-IP version 10.x software branch.

  • BIG-IP 1000 (D39)
  • BIG-IP 2400 (D44)
  • BIG-IP 5100 (D51)
  • BIG-IP 5110 (D51)

F5 Product Development is tracking this issue as CR57456.
