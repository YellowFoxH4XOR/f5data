Known Issue

JavaScript content rewrite may rewrite submit functions incorrectly.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP access profile uses a rewrite profile.
  • The rewrite profile processes JavaScript content with an absolute action path that uses an explicit submit() call.

    For example, the HTML/JavaScript may appear as follows:

    <html><body>
    <form id="ExplicitActionPathForm" name="PathForm" action="/JavaServlet" method="post">
    <input type="button" name="submit button" value="Submit Button" onclick="submit();">
    </body></html>
  • Access session users attempt to submit the JavaScript form.

Impact

JavaScript form submission fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When access session users attempt to submit the JavaScript form, the system displays an error message similar to the following example:

    Page can not be displayed
