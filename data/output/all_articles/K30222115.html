Topic

You should consider using this procedure under the following condition:

  • You want to add a DNS TXT resource record for use with DomainKeys Identified Mail (DKIM) using the ZoneRunner utility.

Description

DKIM is one of the internet standards that provides mechanisms to assist in the management of spam and phishing emails. One of its mechanisms is publishing a domain-level public key using the domain name service text (TXT) resource record. This allows the email recipient to query for the public key and validate the domain name identity of the email sender. For more information about DKIM, refer to RFC5585: DomainKeys Identified Mail (DKIM) Service Overview.

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

Organizations are frequently deploying key sizes of 2048-bit or higher. This produces public keys that exceed the limitation of BIND's TXT resource record of 255 characters in a single string. This limitation does not allow a TXT resource record with more than 255 characters in a single string to be created in BIND. However, a TXT resource record can contain multiple strings, which the application querying for it should concatenate without spaces. For more information about this limitation, refer to the Internet Systems Consortium (ISC) documentation: Can I have a TXT or SPF record longer than 255 characters?.

If you are deploying a 2048-bit or higher key size to generate your DKIM public key, break up the resulting public key into chunks of 255 characters or fewer before adding it to the TXT resource record.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have already generated your DKIM public key and have the encoded text block ready to be added to the DNS TXT resource record.
  • You have administrative access to the BIG-IP Configuration utility.
  • The zone in which you want to add the TXT resource record for DKIM usage is already configured on the BIG-IP system. If the zone is not configured, you must configure it before proceeding with the following procedure. For information about creating a zone using the ZoneRunner utility, refer to K02439348: Creating or transferring DNS zone files using the ZoneRunner utility.

Procedures

Configuring a TXT resource record for usage with DKIM

Perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility
  2. Go to DNS > Zones > ZoneRunner > Resource Record List.
  3. Select Create.
  4. For Zone Name, select the zone you want to use.
  5. For Name enter the TXT record name. Typically this would take the form of <selector>._domainkey.<domain>. For example:
    test._domainkey.f5tac.com
  6. For TLL, enter the TTL values you want to use.
  7. For Type select TXT.
  8. For Text, enter the TXT record value.

    Using the example described earlier in this article, you enter both the chunks of the key in one line while preserving the double quotes throughout. The double quotes act as a line delimiter, and any text between a pair of double quotes is considered a single string.

    For example:

    "v=DKIM1;k=rsa;p=MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEAoswne1idmxYknfwVRZjNDebB5RugAlNV7vl8eO4hl/oyx0ahMy22LWH1sAl/L2Ak0/lAo99Dx1OkkaD5mkupf4jON6KXQyVNzUD35318WZyGhGSRAczwENAh/46+vy1T2a9FbsBZ8t96RH7u5pfF""nWn5/wDhhQO1klR33s7oYRpX0B/6LztBhlOWAC9MFmvsZ5mrBGCqkbmAQtQFvR2ausNn/GTu8h76ZtbXDuwmAPDxSaWRZDjClG1l3f4ShULTE21q1J3E+nZ53yCPh8lR2bFJiejpiawBCQPvrC/lz7m58JMfYnxO1fksJXwohwiIpz2SXUwBWo9P7mZTyOdIgwIDAQAB"

  9. Select Finished.

Verifying the configuration

Perform the following procedure on a test client that is installed with the dig utility:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the test client that is installed with the dig utility.
  2. Initiate a TXT request to the listener server using the following dig command syntax:

    dig +tcp @<Server_IP> txt <DKIM TXT name>

    For example,

    dig +tcp @192.168.0.1 txt test._domainkey.f5tac.com

    Output appears similar to the following example:
