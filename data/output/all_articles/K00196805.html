Topic

You should consider using this procedure under the following condition:

  • You want to manage the strict password enforcement setting for local user accounts on the BIG-IQ system.

Description

The BIG-IQ system, by default, does not enforce strict password checking for user accounts. The strict password checking will test passwords in several different ways. The BIG-IQ system performs the following key tests:

  • Try to match patterns in the user name to information in the user's gecos field
  • Check for any simple patterns
  • Attempt to match the password against dictionary words

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have Traffic Management Shell (tmsh) access with Administrator credentials on the BIG-IQ system.

Procedures

  • Displaying the current strict password enforcement setting
  • Enforcing strict password checks on user accounts
  • Disabling strict password checks on user accounts

Displaying the current strict password enforcement setting

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to thetmsh utility by typing the following command:

    tmsh

  2. To display the current strict password enforcement setting, type the following command:

    list /sys db users.strictpasswords

    For example, if strict password enforcement is disabled, output appears similar to the following:

    sys db users.strictpasswords {
    value "disable"
    }

Enforcing strict password checks on user accounts

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh
  2. To enforce strict password checking on user accounts, type the following command:

    modify /sys db users.strictpasswords value enable
  3. To save the system configuration change, type the following command:

    save /sys config

Disabling strict password checks on user accounts

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh
  2. To disable strict password checking on user accounts, type the following command:

    modify /sys db users.strictpasswords value disable
  3. To save the system configuration change, type the following command:

    save /sys config
