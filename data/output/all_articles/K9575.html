K9575: The Firefox 3 profile may become corrupted and cause logon issues

Topic

When using Firefox version 3.0.3 or later to log in to the FirePass device and click to launch a favorite, you may receive a pop-up window that displays the following message:

"Your session is finished. Your session has expired."

This behavior may also occur immediately after logging in. This is the result of a known issue with the corruption of Firefox profiles when Firefox was updated from version 3.0.2 to 3.0.3. New installations of Firefox 3.0.3 have not reported this behavior but it may exist for later versions. If you have updated your Firefox browser from version 3.0.2 to a later version and you are experiencing this issue, you can resolve the issue by creating a new profile.

Note: For more information about how to create a new profile, refer to the Firefox support page.
