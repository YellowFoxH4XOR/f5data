K000141195: Missing real name A records when queried for CNAME/alias records

Description

You configured CNAME pool with a wide-ip member of real name

You configured A record wide-ip for Alias name and attached above CNAME pool to it

When queried for CNAME with A record the responses only have real name but doesn't have real name's A record.

For example :

Win10:~$dig @10.10.126.61 A alias2.example.com +short
www.example.com.

Environment

  • BIG-IP DNS
  • Alias/CNAME

Cause

A minimum response option is enabled on wide-ip setting, which is default.

Recommended Actions

One can disable minimum response option by navigating to DNS ›› GSLB : Wide IPs : Wide IP List , then select the CNAME/alias wide-ip that you wanted to disable this option, then next to general properties, choose advanced from drop down and disable minimum response option

After minimum response option is disabled output includes A record of real name

For example :

Win10:~$ dig @10.10.126.61 A alias2.example.com +short
www.example.com.
10.68.126.68
