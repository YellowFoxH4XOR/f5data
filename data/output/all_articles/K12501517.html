Topic

Summary

Microsoft announced the end of support for the Internet Explorer browser on June 15, 2022.

Description

As of June 15, 2022, Microsoft ended support for Internet Explorer. BIG-IP APM supports the latest operating systems and browser releases as long as they are still supported by the vendor.

As a result, the BIG-IP APM system no longer supports Microsoft Internet Explorer. For more information regarding Microsoft's end of Internet Explorer support, refer to Lifecycle FAQ - Internet Explorer and Microsoft Edge.

Note: This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

You can continue to use Microsoft Edge, Mozilla Firefox, or Google Chrome with BIG-IP APM.

Note: Microsoft Edge browser and all the Universal Windows Platform (UWP) applications are not supported with BIG-IP APM application tunnels and optimized applications.

For more information, refer to BIG-IP APM Client Compatibility Matrix manual
