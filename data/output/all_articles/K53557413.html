Description

This article provides procedure how to manually define the virtual server name via the ltm-name setting on your GSLB Server.

Environment

  • BIG-IP GTM/DNS 
  • GSLB Server configured as "Product: BIG-IP System"

Cause

When configuring GSLB Server (as BIG-IP System) on your GTM/DNS device you define BIG-IP LTM system..

BIG-IP LTM configuration includes virtual servers that can be monitored by BIG-IP GTM/DNS devices.

In some cases virtual server name configured on BIG-IP LTM might be different than virtual server configured on your BIG-IP DNS.

This might lead to incorrect auto-discovery and monitoring issues.

Recommended Actions

Manually define the Virtual Server name(s) via the ltm-name setting.
To do so, perform the following procedure:

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command
    Note: If you are currently logged in to the tmsh shell, you can skip this step.

    tmsh

  2. Modify the ltm-name setting to reflect the full path for each virtual server by using the following command syntax

    modify /gtm server <server name> virtual-servers modify { <virtual server 1> { ltm-name /<partition>/<virtual server 1> } }

    For example, you would enter the following command for virtual server example_vs1 in the Common partition of the BIG-IP server bigip.example.com:

    modify /gtm server bigip.example.com virtual-servers modify { example_vs1 { ltm-name /Common/example_vs1 } }

  3. Save the change by typing the following command

    save /sys config gtm-only
