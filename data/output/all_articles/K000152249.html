Description

You would like to know how to extract a complete list of all URLs (virtual servers) and iRules configured on an F5 BIG-IP LTM system. This process is commonly used for auditing, documentation, or migration activities. No error messages are involved; the goal is to export configuration data for further review or conversion.

Environment

  • BIG-IP
  • iRules
  • Virtual server

Cause

None

Recommended Actions

Steps to Extract iRules and Virtual Servers:

1.Export All iRules

Use the following command in tmsh shell:

tmsh list ltm rule > irules.txt

This creates a file named irules.txt containing all defined iRules.

2.Export All Virtual Servers (URLs)

Use this command in tmsh shell:

tmsh list ltm virtual > virtuals.txt

This creates a file named virtuals.txt with all virtual server configurations.

3.Convert Output Files to XML or Excel (Optional)

# Python script to convert a .txt file containing iRules into XML format

# Input file (your raw .txt file with iRules)
input_file = "irules.txt"  # Replace with your .txt file name (should be in the same folder)
output_file = "irules.xml"  # The name of the resulting .xml file

# Open the .txt file for reading
try:
    with open(input_file, "r") as txt_file:
        lines = txt_file.readlines()  # Reads all lines of the .txt file
    
    # Create a new XML file and write the converted content
    with open(output_file, "w") as xml_file:
        xml_file.write("<iRules>\n")  # Opening XML tag
        for line in lines:
            # Process each line, wrapping it in XML tags
            xml_file.write(f"    <rule>{line.strip()}</rule>\n")
        xml_file.write("</iRules>")  # Closing XML tag

    # Success message
    print(f"Conversion successful! XML file saved as '{output_file}'")

except FileNotFoundError:
    print(f"Error: Input file '{input_file}' not found. Please make sure it exists.")
except Exception as e:
    print(f"An error occurred: {e}")

Save this code as a .py file and run it in the directory where your exported text files are located.

Alternatively, use online converters to transform text files into XML or Excel formats if scripting is not preferred.
