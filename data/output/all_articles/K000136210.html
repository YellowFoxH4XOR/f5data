Description

  • You want to know how to configure or implement NGINX as SFTP proxy

Environment

  • NGINX Plus
  • NGINX Open Source
  • SFTP

Cause

  • None

Recommended Actions

To implement NGINX as a SFTP proxy, you need to proxy port 22 using 'stream' block. Refer to the following configuration example:

stream {
          server {
            listen 22;
            proxy_pass 192.168.10.10:22;  
          }
        }
