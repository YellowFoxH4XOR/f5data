Topic

You should consider using this procedure under the following condition:

  • You want BIG-IP Edge Client on Windows to automatically reuse the Windows logon credentials when you access the BIG-IP APM network access virtual server.

Description

BIG-IP Edge Client Windows users can automatically reuse their Windows logon credentials when they access the BIG-IP APM network access virtual server.

Note: The length of time the Windows credentials remain in cache, and available to BIG-IP Edge Client, is dependent on a specific security policy setting. Please contact Microsoft for assistance locating and changing this setting.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You're accessing the BIG-IP APM network access profile running the Windows operating system.
  • When you access the BIG-IP APM network access profile virtual server, you use BIG-IP Edge Client.
  • The BIG-IP APM access policy is configured to authenticate including the Logon Page policy item.
  • The network access profile uses the same authentication database as Windows access authentication.

Procedures

Configuring the BIG-IP APM access policy to use Windows credentials for Edge Client access

Impact of procedure: BIG-IP Edge Client uses Windows credentials when you access the BIG-IP APM network access profile. Reused Windows credentials that the AAA profile cannot authenticate causes the initial session attempt to fail, requiring you to manually enter your credentials.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Connectivity / VPN > Connectivity.

    Note: For BIG-IP 12.x and earlier, navigate to Access Policy > Secure Connectivity.

  3. Click the secure connectivity profile of the existing network access profile.
  4. Click View.

    Note: for BIG-IP 12.x and earlier, click Edit Profile.

  5. In the Edit Connectivity Profile pop-up window, navigate to Win/Mac Edge Client > Server List.
  6. Click Add.
  7. Optional: For Alias, enter an alias of the virtual server name for the network access profile.
  8. For Host Name, enter the fully qualified DNS name of the destination resource that users access.
  9. Click Win/Mac Edge Client.
  10. Under Edge Client Action Settings, select the check box to enable Reuse Windows Logon Credentials.
  11. Optional: To automatically update BIG-IP Edge Client when you access the BIG-IP APM system, you can enable the Component Update profile setting (this setting is enabled by default). To do so, go to Win/Mac Edge Client and for Component Update, click Yes, then click OK.
  12. Navigate to Access > Connectivity / VPN > Connectivity. 

    Note: For BIG-IP 12.x and earlier, navigate to Access Policy > Secure Connectivity.

  13. Click the name of the connectivity profile.
  14. Click Customize Package > Windows.
  15. Under Available Components, select the check box to enable User Logon Credentials Access Service.
  16. Under BIG-IP Edge Client, select the check box to enable Add virtual server list to trusted sites.
  17. Click Download.
  18. Click Apply Access Policy.
  19. On the Access Profile List page, ensure that the modified access profile check box is selected.
  20. Click Apply Access Policy.
  21. The next time you log in to the BIG-IP APM access profile, the system downloads and installs the updated BIG-IP Edge Client components.

    Note: Auto-update of BIG-IP Edge Client does not occur when the BIG-IP APM  Win/Mac Edge Client configuration setting for Component Update is set to No.
