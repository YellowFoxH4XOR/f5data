Known Issue

Restoring a UCS archive with FIPS keys may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP platform supports the FIPS hardware security module.
  • The UCS file contains a FIPS key with a period (.) in the file name.

Impact

The UCS archive restore process fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The UCS archive restore process fails.
  • You notice messages similar to the following examples when you attempt to load the UCS archive:

    Nov 12 16:49:49 localhost err mcpd[13047]: 010713e4:3: FIPS subsystem reported error while attempting file object operation: import_key_file: failed to open key file /config/ssl/ssl.cavfips/test.exp.
    Nov 12 16:49:49 localhost err mcpd[13047]: 01070712:3: Caught configuration exception (0), unable to import key (/Common/test.fips.key) in FIPS card.
    Nov 12 16:49:49 localhost err tmsh[30152]: 01420006:3: Loading configuration process failed.
    Nov 12 16:49:49 localhost emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all" - failed. -- 01070712:3: unable to import key (/Common/test.fips.key) in FIPS card Unexpected Error: Loading configuration process failed.

  • You notice the following error message in the Configuration utility when you attempt to load the UCS archive:

    The configuration has not yet loaded. If this message persists, it may indicate a configuration problem.
