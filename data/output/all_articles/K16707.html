Security Advisory Description

cURL and libcurl 7.10.6 through 7.41.0 does not properly re-use authenticated Negotiate connections, which allows remote attackers to connect as other users via a request. (CVE-2015-3148)

Impact

Remote attackers may be able to re-use Negotiate connections as other users by way of an unauthenticated request.

Security Advisory Status

F5 Product Development has assigned ID 521025 (BIG-IP), 525349 (BIG-IQ), 525350 (Enterprise Manager), and ID 476510 (ARX), to this vulnerability, and has evaluated the currently supported releases for potential vulnerability. Additionally, BIG-IP iHealth may list Heuristic H16707 on the Diagnostics > Identified > Low screen.
