Description

When you are creating DNS resource record on Zonerunner on GUI, similar to below message displayed and can not create the record:

org.xbill.DNS.TextParseException: '.example.com.': invalid empty label.
 

Environmet

  • BIG-IP DNS / GTM
  • Zonerunner
  • Adding a resource record, and saved
  • Configuration Utility
     

Cause

Invalid name is typed in Name for the record


Recommended Actions

When you get this message, you should have typed a dot(s) in front of the name.

org.xbill.DNS.TextParseException: '.example.com.': invalid empty label.

Must have typed for resource name with a dot as first letter:

.example.com

Remove the first dot and try to save the record: 

 example.com

For resource record, it should not have dots in before the actual record name.
