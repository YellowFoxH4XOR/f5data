Description

In some scenarios you will encounter a single user that cannot connect to the VPN.
When uninstalling and re-installing the Edge Client does not resolve connectivity issues, it is recommended to reset the users network TCP/IP Stack.

Environment

  • BIG-IP APM
  • Windows 10
  • Edge Client

Cause

This is generally due to local network conflicts on the users local machine.

Recommended Actions

Uninstall current client, reset the Network Stack either from the Users Windows GUI or Windows Command Line:

Users Windows GUI :

  1. Download a new Edge Client from the BIG-IP
     
  2. Uninstall all currently installed Edge components using the following article:
    K8253: Removing BIG-IP APM client components from Windows client systems
     
  3. Reset the Windows Network Stack with the following steps:
    1. Open Windows Settings --> Network & Internet
    2. Click on Status in the left panel
    3. Click on Network reset in the right lower panel
    4. Confirm by clicking Reset now
       
  4. Re-install the Edge Client by right clicking and installing as Administrator.
     
  5. Reboot the client machine
Windows Command Line: (Replace Step 3 from from above with the following)
  1. From Windows, In the search box on the taskbar (click Start) type command prompt, right-click the command prompt result and then select Run as administrator and confirm.
    Note: Decline restarting your machine until you have entered the final command

    At the command prompt, enter the following commands:
    1. Type ipconfig /release and press Enter
    2. Type ipconfig /flushdns and press Enter
    3. Type ipconfig /renew and press Enter (This will stall for a moment)
    4. Type netsh int ip reset and press Enter
    5. Type netsh winsock reset and press Enter
