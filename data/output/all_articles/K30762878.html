Issue

Error Message

mcpd[<PID>]: 01070734:3: Configuration error: Can't associate classification overview selection (/[All]/uwid<ID String>) folder does not exist

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <ID String> is the file ID string for the object configuration that you are attempting to load.

For example:

mcpd[4372]: 01070734:3: Configuration error: Can't associate classification overview selection (/[All]/uwid57b2f07e0e364) folder does not exist

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • Output reported from running a TMOS Shell (tmsh) load or verify command

Description

This message occurs when one of the following conditions is met:

  • You load a user configuration set (UCS) file.
  • You migrate a UCS file.
  • You upgrade from a previous version to a later version.

The issue occurs when a UCS file is saved incorrectly, and the system saves the partition information as [All] instead of the correct partition name.

Impact

The configuration fails to load and prevents the system from becoming operational.

Recommended Actions

When the system generates this error message, consider backing up and manually editing the /config/bigip.conf and reloading the configuration using the following procedure:

Impact of procedure: F5 recommends that you perform this procedure during a maintenance window.

  1. Log in to the command line of the affected BIG-IP system
  2. Make a backup of the file /config/bigip.conf using the following command syntax:

    # cp /config/bigip.conf /config/bigip.conf.$(date +%d-%m-%y).bk

  3. Manually edit the /config/bigip.conf file to replace all instances of /ALL with the correct partition name or /Common.
  4. Verify the configuration by typing the following command:

    # tmsh load sys config partitions all verify

    Note: No error should occur during the configuration load verification. If you encounter an error, contact F5 Technical Support.

  5. Load the configuration by typing the following command:

    # tmsh load sys config partitions all
