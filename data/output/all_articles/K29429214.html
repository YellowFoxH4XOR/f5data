Description
Syslog messages being sent via the internal interface (1.1) instead of management interface.
 

Environment

  • Remote syslog destination configured
  • Remote syslog destinaton only reachable via 2 default routes
    • one default route via TMM internal interface (metric 0)
    • one default route via management route (metric 4096)
       

Cause
syslog messages sent via internal interface default route because that route has the lower metric (0)

Note: Even if the metrics were equal, the BIG-IP would prefer the TMM route over the management route.
 

Recommended Actions

  1. Add a specific route to the syslog destination that uses the management interface:

tmsh create /sys management-route <name> network <destination network>/<netmask> gateway <management gateway>

Replace <name> with the name you want to use to identify this route. Replace <destination network>/<netmask> with the IP address and netmask of the network you are routing to. Replace <management gateway> with the IP address of the router used to access the destination network.

For example:

tmsh create /sys management-route syslog_route network 10.10.10.1/32 gateway 172.16.1.254

  1. To save changes to the static routes for the management network, type the following command:

tmsh save /sys config
