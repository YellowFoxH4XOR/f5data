Description
When trying to issue a bigip_add from a BIG-IP DNS system using a remote user account with Administrator access to any remote BIG-IP device, it might fail with the following error:
Syntax Error: command history is only available in shell mode
ERROR: Can't read remote cert via /usr/bin/ssh.

Environment

  • Remotely authenticated user issuing bigip_add from BIG-IP DNS system

Cause
The user account has not been configured on the remote device.

Recommended Actions
In order to workaround this issue and be able to run bigip_add with the remote user account, it can be accomplished by specifying the -a flag with bigip_add to instruct this script to expect a tmsh shell during login. Following this, the script runs successfully without any errors. Either of the following command syntax can be used:

bigip_add -a <BIG-IP_IP_address>
or
bigip_add -a <username>@<existing_DNS_or_LTM_IP_address>

Additional Information
F5 Product Engineering team has a feature request at ID802705 to improve upon this issue in the future, so that the remote user can issue bigip_add without having to specify the -a flag.
