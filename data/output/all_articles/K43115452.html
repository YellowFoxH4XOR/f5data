Description

When navigating the Configuration Utility for statistics, you may observe the below error:

General database error retrieving information.

You may observe the error logs similar as below in /var/log/tomcat/catalina.out and/or /var/log/webui.log:

ERROR util.RequestErrorReporter:errorEvent - common.error.GeneralDatabaseErrorRetrieving java.sql.SQLException: Wrong data type: java.lang.NumberFormatException: For input string: "xxxxxxxxxxx" in statement ......

Important: There are multiple reasons as to why you may see this database error when browsing the GUI. Unless this article fits your case exactly, it is recommended to start with General Database Error Retrieving Information in the BIG-IP Configuration Utility , which helps you discover the right article for you.

Environment

  • BIG-IP
  • Configuration Utility
  • Statistics

Cause

Number "xxxxxxxxxxx" mentioned in the above error log is out of the expected counter range.

Recommended Actions

Log in Advanced shell (bash).

  1. Run the below command to check which virtual server contains statistics number equal to or greater than "xxxxxxxxxxx" in the log.
    tmctl virtual_server_stat

  2. Reset the statistics of this virtual server with the command
    tmsh reset-stats ltm virtual <virtual server name>

  3. Restart the tomcat service
    tmsh restart sys service tomcat
