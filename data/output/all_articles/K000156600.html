K000156600: On MAC OS, the VPN connection will disconnect intermittently and reconnect quickly

Type
Support Solution
Published
2025-09-24
Updated
2025-09-24
Applies to
  • BIG-IP
  • BIG-IP APM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000156600

Description

VPN connections intermittently disconnect and automatically re-establish when using BIG-IP APM with Edge Client (or browser) for macOS. The issue occurs only on macOS clients with Microsoft Defender Network Filter and/or Content Filter enabled via Intune policy. Disabling these filters restores stable VPN connectivity.

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • Network Access
  • MAC OS
  • Edge Client or browser

Cause

Microsoft Defender's Network Filter or Content Filter on macOS interferes with the VPN tunnel, causing repeated disconnects and reconnections.

Recommended Actions

  1. To confirm the issue:

Disable the Microsoft Defender Network Filter and/or Content Filter on an affected macOS client.

Check if VPN stability is restored. Re-enabling the filter should cause the issue to recur. 

  1. For troubleshooting:

Collect edge.log and svpn.log from affected clients, the svpn.log will show the log below when connection close:

<date time>, 6495,11905584,svpn, 1, /USocket.cpp, 309, , EXCEPTION caught: USocketBlocking::send:EXCEPTION!!!

<date time>, 6495,11905584,svpn, 48, /USSLChannel.cpp, 180, , transportWrite closed in one direction

<date time>, 6495,11905584,svpn, 2, /USSLChannel.cpp, 393, USSLChannel::Write, SSL_write failed (result: -1, error: SSL_ERROR_SYSCALL)

<date time>, 6495,11905584,svpn, 2, /interfaces.h, 527, IUChannelImpl::Write(), write to transport failed, mark the channel as closed

<date time>, 6495,11905584,svpn, 1, /svpn.cpp, 89, SSLVpn::RedirectData(), (0x13) EXCEPTION - Cannot write to Channel

<date time>, 6495,11905584,svpn, 1, /svpn.cpp, 2048, , EXCEPTION caught: EXCEPTION!!!

Capture packets (pcap) from both the client’s physical NIC and BIG-IP during a disconnect event, the network connection is normal, and the client will send out FIN tp APM to close the connection graceful.

  1. For resolution/workaround:

Disable the problematic Defender Network Filter and/or Content Filter on affected macOS devices, or adjust the Intune policy to exclude these devices from the filter.

If disabling is not possible, contact Microsoft support to investigate the filter’s impact on VPN traffic.

Additional Information

When the VPN connection close, the client may reset the connection to other server simultaneously.
