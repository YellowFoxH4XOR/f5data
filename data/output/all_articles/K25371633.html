Description

APM will log the message "Halted SSO retry for request" and Kerberos authentication may fail through the APM

Environment

  • Big-IP APM
  • Kerberos SSO

Cause

The backend server used for Kerberos authentication responds to the POST authentication request coming through the APM, with a '401 Unauthorized', similar to:

KRB Error: KRB5KRB_ERR_GENERICContinuation
HTTP/1.1 401 Unauthorized

By design, the APM halts the SSO process and forwards the 401 Unauthorized to the client

Recommended Actions

APM is functioning as designed, as the server is not authenticating the user, so SSO cannot be completed.
  1. Recommend investigating the backend authentication server sending the 401 Unauthorized response, to find the cause.
