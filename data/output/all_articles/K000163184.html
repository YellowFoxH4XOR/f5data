K000163184: After upgrade cluster is stuck in disconnect status

Type
Support Solution
Published
2026-09-03
Updated
2026-09-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3, 21.1.0, 21.0.0, 17.5.1
Source
https://my.f5.com/manage/s/article/K000163184

Description

After upgrading BIG-IP to any of the following versions (17.1.3.4, 17.5.1.8, 21.0.0.3, 21.1.0.1), the HA cluster result in Disconnected status and cannot synchronize between peers anymore. 
Problem with Sync remains even after rolling back to previous working version.

Environment

  • Upgrade to BIG-IP 17.1.3.4, 17.5.1.8, 21.0.0.3, or 21.1.0.1
  • HA cluster with ConfigSync is configured to use the management IP address

Cause

Bug ID 2482505

Answer/Recommended Actions

You may proceed with any of the following actions:

  • Upgrade to a version with a fix for Bug ID 2482505.
  • Before you upgrade to the listed versions, modify ConfigSync from the management IP to a suitable self-IP based configuration.
  • Downgrade to a previously working version and proceed with the following commands on affected devices from the bash CLI:
    Impact of procedure: The system will not process service traffic while executing the following commands.

    bigstart shutdown tmm
    bigstart shutdown mcpd

    cp /sbin/big3d /shared/bin/big3d

    bigstart startup mcpd
    bigstart startup tmm
