K000091224: How to configure URI rewrite on Nginx Controller

Type
Support Solution
Published
2022-01-15
Updated
2022-02-04
Source
https://my.f5.com/manage/s/article/K000091224

Description

  • You successfully configure your Nginx Controller API Gateway 
  • But, you are facing with issue where a client request is being forwarded to the back-end server as original request
  • You would like to rewrite client request to a URI the end server expects/understand it
  • For Example
    •  incoming request would have the form "https://apigateway.example.com"
    •  request forwarded to end/server/Application "https://api.example.com"

 Environment

  • Nginx Controller
  • Rewrite

 Cause

  • None

 Recommended Actions

  • On the Nginx Controller, there is a rewrite feature and can be configured by navigating to Home >> NGINX Controller >> Application Delivery >> Manage Apps & Components >> Programmability
  • On the Create App Component Programmability page:
  • Please note, these settings are applicable only to Web components.
    • (Optional) Select Add URI Redirects and define the desired redirect condition(s).
    • (Optional) Select Add URI Rewrite and define the desired rewrite pattern(s).
    • (Optional) Select Add Request Header Modification and define how to modify the request header.
    • (Optional) Select Add Response Header Modification and define how to modify the response header.
