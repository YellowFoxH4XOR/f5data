Topic

Starting in FirePass version 6.0.2 with cumulative HF-602-2, the Automatically reconnect if link dropped option appears on the Network Access: Resources page under the Client Settings tab. When the Automatically reconnect if link dropped check box is selected, the FirePass Network Access client component automatically reconnects a Network Access connection after receiving a Network Driver Interface Specification (NDIS) media disconnect message. FirePass supports this feature on Windows NT-based client systems prior to Windows Vista. FirePass does not currently support this feature on other client systems such as Linux or Macintosh.

Note: Non-Windows operating systems rarely use the NDIS application programming interface (API) for network interface cards.

An NDIS driver sends a media disconnect message to the F5 VPN driver during certain system events, for example when an NDIS intermediate driver is installed or uninstalled. If the Automatically reconnect if link dropped check box is cleared, or if you are running a version of FirePass prior to 6.0.2 with cumulative HF-602-2, the FirePass Network Access client for Windows terminates the Network Access connection upon receiving an NDIS media disconnect message instead of attempting to reconnect.

Note: For more information about NDIS, refer to the following link. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://www.microsoft.com/whdc/device/network/ndis/default.mspx

F5 Product Development tracked this enhancement as CR86669 and was added starting in FirePass version 6.0.3.

This issue has been fixed in cumulative HF-602-2 issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
