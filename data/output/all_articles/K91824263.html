Description

The output of [DNS::answer] is different between BIG-IP 15.x and BIG-IP 13.x.

For example:
BIG-IP 13.x: {server.f5.com. 23 IN A 12.1.2.1 }
BIG-IP 15.x: {server.f5.com. 23 IN A 12.1.2.1}

Depending on the method you use to extract the IP address, the value may change after upgrading.

Environment

  • BIG-IP DNS

Cause

In BIG-IP 15.x, we remove the space before the ending bracket.

Recommended Actions

To get the IP address in the output of [DNS::answer], please use the following method:

foreach rr [DNS::answer] {
     set response [split $rr]
     set request [ lindex $response 4 ]
     log local0. "4th element is: $request"
}
