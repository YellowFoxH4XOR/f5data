Known Issue

The BIG-IP system fails to create and modify a route domain within a single transaction.

For example, the following tmsh command sequence attempts to create a route domain named test_rd_100 followed by a change in description within the same transaction.

(tmos) # create cli transaction
(tmos) # create net route-domain test_rd_100 id 100
(tmos) # modify net route-domain test_rd_100 description test
(tmos) # submit cli transaction

Impact

The BIG-IP system will fail to process the transaction. As a result, the route domain will not be created.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Route domain creation may fail with an error message similar to the following example:

    transaction failed: 01070734:3: Configuration error: route-domain Name /Common/test_rd_100 is non-numeric, so an ID must be specified.

Workaround

To work around this issue, you can perform create and modify operations in different transactions.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
