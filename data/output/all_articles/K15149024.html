Issue

Error Message

01010239:3: LSN error: <description>

In this error message, note the following:

  • <description> is the string containing a description of the issue.

For example:

01010239:3: LSN error: Inbound reservation failed

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • You have configured a Large Scale NAT (LSN) pool on the BIG-IP system, but you have not licensed and provisioned the carrier-grade network address translation (CGNAT) module.

Impact

The CGNAT configuration will not take effect until you license and provision the CGNAT module on the BIG-IP system.

Recommended Actions

By default the carrier-grade network address translation (CGNAT) module is disabled on the BIG-IP system.  You must license and provision the CGNAT module to enable CGNAT functionality on the BIG-IP system.
