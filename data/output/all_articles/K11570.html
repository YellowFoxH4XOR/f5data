Known Issue

The BIG-IP APM command line may report incorrect access profile statistics on a standby unit in a high-availability pair after the standby unit has become active. For example, the number of active, pending, and established sessions may have a negative value or an extremely high value. The output may appear similar to the following example:

[root@APM:Active] config # b access
GLOBAL ACCESS STATISTICS
<skip>
| current active sessions 18446744073709551591
| current pending sessions 18446744073709551611
| current established sessions 18446744073709551596
--------------------------------------------------

F5 Product Development tracked this issue as CR137257, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
