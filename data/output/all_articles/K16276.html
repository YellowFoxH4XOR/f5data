Known Issue

The F5 Component Installer Service fails to update when accessing a newer version of the BIG-IP APM system.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM configuration includes a connectivity profile with the Component Update setting enabled.
  • The BIG-IP APM system has a newer version of the F5 Component Installer Service than is present on the connecting client system.

Impact

The F5 Component Installer Service version installed on the client will not be updated, even if it is older than the version present on the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client systems connecting to the BIG-IP APM system are not updated with the newer version of the F5 Component Installer Service.
  • Client systems are unable to install updated components when connecting to the BIG-IP APM system.
