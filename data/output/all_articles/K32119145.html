Description

You configure a trunk on the BIG-IP, and the trunk becomes UP. But no GARP is sent from the BIG-IP.

Environment

  • You configure a trunk.
  • You are using one of these platforms.

    BIG-IP i4800
    BIG-IP i4600
    BIG-IP i2800
    BIG-IP i2600
Cause
F5 tracks the issue as ID 967101.
 
ID 967101 No GARP is sent out on switchless i4000 series when trunk goes UP

Recommended Actions

None
