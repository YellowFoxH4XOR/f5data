Known Issue

This is the result of a known issue. If you configure a lengthy Application Tunnel Access Control List (ACL) with Microsoft Internet Explorer 6, and you click the Update button under the Application Tunnel ACL nothing happens. If you configure a lengthy Application Tunnel ACL with Microsoft Internet Explorer 7, you receive the following error message when you click the Update button under the Application Tunnel ACL:
 
Internet Explorer cannot display the webpage
Most likely causes:
You are not connected to the Internet.
The website is encountering problems.
There might be a typing error in the address.

Note: Application Tunnel ACLs are configured on the Application Access : App Tunnels : Master Group Settings page.

This issue occurs because FirePass updates the Application Tunnel ACL through an HTTP GET request, which appends the ACL data to the URL. Microsoft Internet Explorer has a maximum URL length of 2,083 characters. As a result, a lengthy Application Tunnel ACL may exceed that limit.

F5 Networks Product Development tracked this issue as CR78659 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Workaround

You can work around this issue by configuring the Application Tunnel ACL with a different browser, such as Mozilla Firefox.
