Known Issue

The system may incorrectly report the service checking status for a Fully Qualified Domain Name (FQDN) ephemeral node.

This issue occurs when all of the following conditions are met:

  • A pool is configured with FQDN node pool members.
  • The FQDN node pool members are not configured with a node specific or node default monitor.

When an FQDN ephemeral node does not have a node specific monitor or a node default monitor configured, the ephemeral node's service checking availability status is reported incorrectly. Even if the pool has a monitor configured, the ephemeral nodes are reported as availability Unknown (enabled) - Pool member does not have service checking enabled.

Impact

The system does not reflect the actual pool member health status for FQDN ephemeral nodes.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The availability status of a pool with FQDN pool members is reported as unknown (enabled) with a reason of The children pool members either do not have service checking enabled, or service check results are not available yet.
  • The availability status of the FQDN ephemeral pool members is reported as unknown (enabled) with a reason of Pool member does not have service checking enabled.

    For example:

    ---------------------------------------------------------------------

    ---------------------------------------------------------------------
    Status

    State : enabled
    Reason : The children pool member(s) either don't have service checking enabled, or service check results are not available yet
    Monitor : gateway_icmp
    Minimum Active Members : 0
    Current Active Members : 0
    Total Requests : 0
    Current Sessions : 0

    ...

    --------------------------------------------------------------
    | Ltm::Pool Member: host1.test.net:80
    --------------------------------------------------------------
    | Status
    | Availability : unknown
    | State : enabled
    | Reason : Pool member does not have service checking enabled
    | Monitor : gateway_icmp (pool monitor)
    | Monitor Status : unchecked
    | Session Status : enabled
    | Pool Name : http_fqdn
    | IP Address : 10.10.15.1
    ...

    | Ltm::Pool Member: host2.test.net:80
    --------------------------------------------------------------

    | Reason : Pool member does not have service checking enabled

    | Monitor Status : unchecked
