Description
At times you may see a log message similar to this in /var/log/secure:

Oct  9 09:01:32 LTM1.example.com notice root[4803]: Entropy generation check failed.

Environment

  • LTM
  • CC mode

Cause

This is normally seen when there are resource constraints such as high CPU usage on the device. It is merely logging that the system was unable to run the entropy generation script.
Entropy generation script is needed when BIG-IP is operating in CC (Common Criteria) mode. By default, BIG-IP does not operate in CC mode, hence there is no impact from this message.

Recommended Actions

You can determine if BIG-IP is operating in CC mode by checking the system db variable security.commoncriteria.
Important: Do not attempt to modify db variable with tmsh, there could be adverse effects, such as cores or restarts.

  1. Login to BIG-IP CLI
  2. Run the below command
    [root@ LTM1.example.com:Active:Standalone] log # tmsh list sys db security.commoncriteria
    sys db security.commoncriteria {
        value "false"
    }
  3. If CC mode is enabled the value above will be "true". 
    Note: The default value is false.
  4. If BIG-IP is operating in CC mode, investigate why the system resource usage is so high and alleviate that if possible.
  5. If there is any impact seen as a result of these messages while in CC mode then open a case with F5 Support for further assistance.

Additional Information

To disable CCMode you may use this guide: util ccmode
