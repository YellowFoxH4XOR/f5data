Description

When trying to configure virtual servers and applications for nPath or Asymmetric routing, you find the client is unable to establish a connection with the application

Environment

  • BIG-IP LTM
  • IP Forwarding virtual servers

Cause

ID 890229 prevents the BIG-IP from preserving the original source port of the request normally, causing the return traffic from the BIG-IP to contain a source port that doesn't match the original outbound one

Note: See ID 890229 in Related Content for more information

Recommended Actions

Enabling the Preserve-Strict option on the virtual servers' Source Port setting will allow the BIG-IP to return the traffic on the right port
