Description

When you attempt to create a UCS file or SCF file in the command line interface, the file is not created and the following error is thrown on the command line:  

Unexpected Error: cache-path is not in expected ROOTF "/config/filestore/"

Environment

  • BIG-IP
  • UCS or SCF file creation

Cause

Issue is caused by any file in the /filestore directory that contain a space or special character in the name.

For example a certificate with a # in its name:

sys file ssl-cert "/Common/Cert_Test#32685974" {
    cache-path "/config/filestore/files_d/Common_d/certificate_d/:Common:Cert_Test#32685974_62541_1"
    revision 1
}

Recommended Actions

To successfully create UCS or SCF you need to make sure that names of the files in the /filestore directory do not include a space or special characters.

If you need to modify the configuration follow the steps below.

Impact of procedure: F5 recommends that you schedule this procedure during a maintenance window to minimize the impact on production environments. 

       1. Remove the certificate/key with the space or special character in the name from any profiles it is assigned to.
       2. Delete the certificate or key with the space or special character.
       3. Recreate the certificate or key without the space or special character
