Description

Support for ACME or direct integration with Let’s Encrypt with Classic BIG-IP

Environment

  • ACME
  • Lets Encrypt
  • Classic BIG-IP

Cause

None

Recommended Actions

Beginning in BIG-IP version 21.1.0, Classic BIG-IP supports ACMEv2 HTTP-01 validation natively. For versions prior to 21.1.0, Classic BIG-IP does not have native support for ACME or direct integration with Let’s Encrypt. The recommended approach is to use an external ACME client (such as certbot or acme.sh) to obtain and renew certificates. Once the certificates are generated, you can import them into BIG-IP manually or automate the process using scripts or the API.

If you are using BIG-IQ for centralized management, there is a supported workflow for integrating Let’s Encrypt with BIG-IQ, which can automate certificate issuance, renewal, and deployment to managed BIG-IP devices.
