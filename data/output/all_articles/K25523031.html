Description

Vulnerability scanners report the BIG-IP is vulnerable due to the SSH server is configured to use Cipher Block Chaining.
They recommend to disable CBC mode cipher encryption, and enable CTR or GCM cipher mode encryption.
CBC is reported to be affected by several vulnerabilities in SSH such as CVE-2008-5161

Environment

  • SSH
  • SSL/TLS Ciphers

Cause

None

Recommended Actions

To view the current SSHD cipher configuration you can run the following command from the command line of the BIG-IP device:

sshd -T | awk '/ciphers/,/banner/ $2 ~ "[a-z]-[a-z]" { print $2}' | sed s'/,/\n/'g

If you want to remove the CBC ciphers, please, follow below procedure:

  1. Access BIG-IP CLI TMOS prompt:

    tmsh

  2. Begin editing the running configuration:

    load sys config from-terminal merge

  3. Copy the following, and paste into the terminal window:

    sys sshd {
        include "Ciphers aes128-ctr,aes192-ctr,aes256-ctr
            MACs hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com"
    }

  4. Press CTRL-D to submit
  5. Verify the change was made to the running configuration:

    list sys sshd

    The output should look like:

    sys sshd {
        include "Ciphers aes128-ctr,aes192-ctr,aes256-ctr
            MACs hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com"
    }

  6. Save the updated running configuration to disk:

    save sys config

  7. Confirm again the running configuration is using no CBC ciphers:

    list sys sshd

    The output should look like:

    sys sshd {
        include "Ciphers aes128-ctr,aes192-ctr,aes256-ctr
            MACs hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com"
    }

Note: Please, be sure your SSH client supports another ciphers besides CBC. You can type below command in the BIG-IP to check:
sshd -T | awk '/ciphers/,/banner/ $2 ~ "[a-z]-[a-z]" { print $2}' | sed s'/,/\n/'g
