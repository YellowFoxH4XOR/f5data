Issue

Error Message

011b032e:3: Graph <name> is not supported, possibly because it is not licensed, or a license has expired

In this error message, note the following:

  • <name> is the name of the statistical graph.

For example:

011b032e:3: Graph 'SSLTPSGraph' is not supported, possibly because it is not licensed, or a license has expired

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The license for the BIG-IP system has expired.
  • The feature related to the graph is not licensed.

This message is generated by the statsd process, which provides services related to statistical data generation for the BIG-IP system.

Impact

The BIG-IP system is unable to create the graph.

Recommended Actions

For more information about an unlicensed feature related to the graph in the message, you can contact your F5 sales representative.  To reactivate a license that has expired, refer to article K7752: Licensing the BIG-IP system.
