K65757336: How to set up and automate Utility billing in BIG-IQ 8.x for FCP

Type
Support Solution
Published
2019-12-03

Applies to

  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source

Description

As part of the Flexible Consumption Plan (FCP), license utility reporting needs to be configured. These reports can be sent automatically to F5 and other email recipients. 

Environment

  • BIG-IQ 8.x
  • FCP
  • License Utility Reports
  • Access to api.f5.com on port 443

Note: Automated Billing reporting run on monthly intervals.

Cause

On the Flexible Consumption Plan (FCP), license reports need to be submitted monthly to F5. 

Recommended Actions

Configure automatic reports

  1. Log into BIG-IQ, click on Devices tab
  2. Expand License Management > Licenses
  3. In the left side menu under License Management click on Reports > Schedule
  4. Make sure Schedule status is enabled,
  5. Check the Automatically submit report to F5 radio button
  6. Set the day and start time to run the report as requested by the Customer Success Manager (CSM) or Account manager. Note: Due to BugID 1087253, regardless of the stated time zone, the report only runs on Pacific Standard Time (PST) so set the time to run after 00:00:00 PST.
  7. Check the Obfuscate Data radio button, to address any security concerns
  8. Enable Email Notifications to receive a copy of this report.  

Note: To receive a copy of this report an SMTP server must be configured and email notifications enabled.

Configure the SMTP server on the BIG-IQ

  1. Log into the Configuration Utility as an admin user
  2. Select the System tab
  3. Navigate to This Device > SMTP configuration
  4. Click Add.
  5. Enter a name for the SMTP configuration in the Name setting.
  6. Enter the SMTP server in the SMTP Server Host setting.
  7. Enter the SMTP listening port of the SMTP server in the SMTP Server Port setting.
  8. Enter the originating email address in the From Email Address setting.
  9. If your SMTP server requires SSL/TLS encryption, select the appropriate option for the Encryption setting. Otherwise, leave the setting as No Encryption.
  10. If your SMTP server does not require authentication, select No for the Use Auth setting. If your SMTP server requires authentication, select Yes for the Use Auth setting. Then enter the appropriate username and password in the Auth Username and Auth Password settings respectively before clicking Test Connection to verify the SMTP connection.
  11. In the lower-right corner, click Save & Close.

Enable Email notifications

  1. Log into the Configuration Utility as an admin user
  2. Select the Devices tab
  3. Navigate to License Management > Reports
  4. Click Schedule
  5. Enable/check Email Notification
  6. Add email addresses to the email recipient window. Use commas to separate multiple addresses.
  7. In the lower-right corner, click Save & Close.

Additional Information

To confirm internet access to automatically submit reports, from the command line of the BIG-IQ run "telnet api.f5.com 443" without the quotes. It should connect successfully.
