Known Issue

The Traffic Management Microkernel (TMM) process generates a core file and restarts when BIG-IP WebAccelerator receives a 304 NOT MODIFIED response from an origin web server (OWS).

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a WebAccelerator-enabled virtual server.
  • A client makes a conditional request to the BIG-IP WebAccelerator-enabled virtual server.
  • The BIG-IP WebAccelerator-enabled virtual server receives a 304 NOT MODIFIED response from the OWS.
  • The requested content is not found in the BIG-IP WebAccelerator cache.

Impact

The BIG-IP system may temporarily fail to process traffic, as it recovers from TMM restart. If configured as part of a high-availability pair, the device may fail over.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H478783 on the Diagnostics > Identified > High screen.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system fails over to another host in the device group.
