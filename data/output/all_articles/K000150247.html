K000150247: REST API Error, Unable to install SSL cert in Venafi platform

Type
Support Solution
Published
2025-03-06
Updated
2025-03-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150247

Description

When trying to install an SSL certificate using Venafi, the system responds with the next message:

"Error: the remote server returned an error: (401) Unauthorized. Server Response: {"code":401,"message":"Unable to process request /tm/auth/source. Service is unavailable.","referer":"10.102.12.179","restOperationId":227857228,"kind":":resterrorresponse"}"

Environment

  • BIG IP LTM v17.1.1
  • Venafi's Trust Protection Platform

Cause

Authentication error

Recommended Actions

Try restarting the iControl REST framework daemon by running:

tmsh restart sys service restjavad

*Important: The BIG-IP system experiences a temporary traffic interruption as it recovers from the restart of services, and devices configured as a

high-availability (HA) pair may fail over. F5 recommends changing the Management memory size allocation during a scheduled maintenance window.
