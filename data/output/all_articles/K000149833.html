Description

Custom UDP Health Monitor with send and receive string configured is not working as expected.

When you create a Python Script to pass the same send string, there is a correct response from pool member.

ltm monitor udp /Common/MONITOR_UDP_TEST {
    adaptive disabled
    debug no
    defaults-from /Common/udp
    interval 5
    recv 5265636569766564  
    recv-disable none
    send "\x74\x65\x73\x74"
    time-until-up 0
    timeout

Environment

  • BIG-IP LTM
  • udp health monitor

Cause

Response did not match receive regex.

Recommended Actions

Modify receive string and use "\x52\x65\x63\x65\x69\x76\x65\x64" instead of "5265636569766564".
