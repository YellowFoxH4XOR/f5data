Known Issue

Mac OS X devices that use the BIG-IP Edge Gateway client may be unable to maintain a Network Access connection.

This issue occurs when all of the following conditions are met:

  • The Mac OS X device has an established Point-to-Point Tunneling Protocol (PPTP) using the inbuilt client PPTP software.
  • A BIG-IP Edge Gateway client attempts to use the previously-established Mac OS X PPTP tunnel to connect to Network Access.

When the BIG-IP Edge Gateway client attempts to establish a network access tunnel over the existing Mac OS X PPTP tunnel, the two tunnels use common routes. When the BIG-IP Edge Gateway client detects the common routes, it disconnects the tunnel.

Impact

The user is unable to establish a functional BIG-IP Edge Gateway Network Access tunnel.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP Edge Gateway Network Access tunnel temporarily functions, then disconnects, and the user is unable to establish the connection again.
