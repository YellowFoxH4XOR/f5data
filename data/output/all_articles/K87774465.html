Known Issue

Requests including the or string may trigger a false positive match for BIG-IP ASM attack signature ID 200006033.

This issue occurs when all of the following conditions are met:

  • You installed the following attack signature update that released February 27, 2019:

    ASM-SignatureFile_20190226_232307.im

  • The following attack signature is enabled in the security policy:

    200006033 (XPath Injection or 1=1)

  • The request contains the or string as part of the parameter name or value.
  • Attack signature staging is disabled in the security policy.

    Note: Attack signature staging is enabled by default in the security policy. F5 recommends using attack signature staging because the system does not enforce new or updated signatures during the staging period.

Impact

The BIG-IP ASM system generates false positive violations and may block legitimate traffic for some users.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Violations are reported for attack signature ID 200006033.
  • If the security policy is set to block violations for attack signatures, requests matching the affected signature are blocked.

Resolution

Status

F5 Product Development has assigned ID 759976 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To resolve this issue, you can install an updated attack signature file (ASM-SignatureFile_20190228_105942.im or later) that contains a fix for this issue. To do so, perform one of the following procedures:

Important: Make sure to delete any UCS files that contain the affected signature.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Installing the updated ASU signature file (BIG-IP 14.1.0 and later)

To download the updated ASU signature file (ASM-SignatureFile_20190228_105942 or later) for version 14.1.0 and later, refer to the following article:

  • K82512024: Managing BIG-IP ASM Live Updates (14.1.x)

Installing the updated ASU signature file (BIG-IP 11.x through 14.0.0)

To download the updated ASU signature file (ASM-SignatureFile_20190228_105942 or later), perform the following procedure:

  1. Log in to the F5 Downloads site.
  2. Manually download the latest signature file to your local workstation.
  3. Log in to the Configuration utility.
  4. Navigate to the Attack Signature Update page for your version:
    • BIG-IP 12.0.0 through 14.0.0

      Security > Security Updates > Application Security

    • Versions prior to BIG-IP 12.0.0

      Security > Options > Application Security > Attack Signatures > Attack Signatures Update

  5. For Update Mode, click Manual.
  6. For Delivery Mode, click Manual.
  7. Click Save Settings.
  8. Click Choose File and then locate the previously saved signature file.
  9. Install the signatures using one of the following methods for your version:
    • BIG-IP 12.0.0 through 14.0.0

      Click Install Updates.

    • Versions prior to BIG-IP 12.0.0

      Click Update Signatures.
