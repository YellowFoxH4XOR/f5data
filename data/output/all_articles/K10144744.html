Topic

This article provides an overview of the components, files, and configurations of NGINX App Protect WAF. 

Description

When administering NGINX App Protect WAF, it is important to have a good overview of the different processes, components, and files that enable the system to function and protect your applications. For more information, refer to the following sections:

  • NGINX App Protect WAF processes and components
  • NGINX App Protect WAF files

NGINX App Protect WAF processes and components

After successfully installing NGINX App Protect WAF, four different processes are running when you list the NGINX processes using the following command syntax:

ps -ef | grep nginx

You should observe the following four processes:

  • NGINX master: This master NGINX process reads and evaluates configuration files and maintains the NGINX worker processes. The NGINX master process runs as root.
  • NGINX workers: The worker NGINX processes handle and process the actual data or requests. Multiple (default is one) worker processes could be started and by default run as the nginx user. Both values are defined in the /etc/nginx.conf file.
  • BD agent: This Web Application Firewall (WAF) process loads the WAF configurations and passes them to the BD process.

    Beginning in NGINX App Protect WAF 3.5, the BD agent is removed. For more information, refer to the NGINX App Protect WAF 3.5 release notes.

  • BD: The actual process that enforces the WAF configurations received from the BD agent.

BD and BD agent should run as the same user as the worker processes for optimal security and guaranteeing access rights to the sockets connecting them to NGINX. In addition to BD agent and BD, App Protect WAF consists of other WAF processes and components that make up its functionality. NGINX App Protect WAF files

NGINX App Protect WAF files are installed in the /opt/app_protect, /etc/nginx, /etc/app_protect, /var/log/app_protect, /var/log/nginx directories by default.

Runtime environment

The /opt/app_protect directory is the root directory for the App Protect WAF runtime environment that contains installation, executable, database, library files, and more. Administrators generally do not have to modify these files and have read-only access to most of them.

Configuration files

NGINX App Protect WAF configuration files consist of mainly the security policy, the security log file format, and any external file references. For more information about external references, refer to External References in the NGINX documentation.

Since NGINX App Protect WAF allows administrators to specify the directory and file name of their configuration files, the following section lists only the default location of the configuration files. The actual locations may differ depending on the actual deployment. For the exact locations and file names, refer to the specific WAF directives in the nginx.conf file.

For example, the following directive in the nginx.conf file declares a user-defined security policy json file in the user-created /etc/nginx/nap.d directory:

app_protect_policy_file "/etc/nginx/nap.d/example-api-security.json";

Log files

NGINX App Protect WAF log files consist of mainly the following three types of log files: request/security logs, operation logs, and debug logs. These files are installed by default in the /var/log/nginx and /var/log/app_protect directories. For more information, refer to NGINX app Protect WAF Logs Overview in the NGINX documentation.

Since NGINX App Protect WAF allows administrators to specify the directories and file names of their log files, the following section lists only the default location of the log files. The actual locations may differ depending on the actual deployment. For the exact locations and file names, refer to the specific WAF directives in the nginx.conf file.

For example, the following directive in the nginx.conf file declares a user-defined log format in the user-created /etc/nginx/nap.d directory and a user-defined log file in the /var/log/app_protect directory.

app_protect_security_log "/etc/nginx/nap.d/config-illegal-requests.json" /var/log/app_protect/class_illegal_security.log;
