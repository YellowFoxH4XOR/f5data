K63705028: Problem with the accessing login page on BIG-IP APM module

Type
Support Solution
Published
2022-06-10
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K63705028

Description

Since the update, the login page is not displayed anymore and we are redirected to an error page.

Environment

  • APM
  • Route Domain

Cause

Assigning a virtual server to a non-default route domain might cause a traffic disruption.

Recommended Actions

Impact of procedure: Depending on your existing BIG-IP configuration and network environment, performing this procedure may lead to traffic disruption. For example, there could be other virtual servers and resources configured on the affected route domain that depends on the existing configuration. F5 recommends performing this during a scheduled maintenance.

1. Log in to the Configuration utility.
2. Go to Network > Route Domains > affected route domain.
3. In the section Parent Name select '0 (Partition Default Route Domain)'.
4. Select Update.

Additional Information

Bug ID 1010597: Traffic disruption when virtual server is assigned to a non-default route domain
