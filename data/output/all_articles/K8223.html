K8223: Maximum password size set to 512 bytes

Type
Knowledge
Published
2008-10-03
Updated

Status
Legacy Content
Applies to

  • FirePass: 6.0.3
Source
https://my.f5.com/manage/s/article/K8223

Issue

In FirePass software versions prior to 6.0.3, the password supplied to the logon page could be arbitrarily long.

Starting in FirePass 6.0.3, the password is restricted to a maximum of 512 bytes. When using a single-byte character set, the maximum password length is 512 characters. When using a double byte character set such as Shift_JIS, the maximum password length is 256 characters.

F5 Product Development tracked this change as CR88574 and it was included in FirePass 6.0.3. For information about upgrading, refer to the FirePass Release Notes.
