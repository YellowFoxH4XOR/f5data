Description

You may find that a lot of ASM signature update files in /var/ts/var/negsig/ directory.
And it may cause low disk space issue of /var directory.

Environment

  • ASM is provisioned
  • Updating ASM signature many times

Cause

It is by design.
There is no such feature to delete old ASM signature update files automatically so far.

Recommended Actions

You can safely delete the old ASM signature files (ASM-SignatureFile_<date>_XXXXXX*.im) under the path /var/ts/var/negsig/.

Additional Information

ASM system(14.1.x and later) will delete the old files when it reaches the maximum limit. For more details, please refer to K82512024.
