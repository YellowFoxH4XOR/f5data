Description

Replays for hardware SNMP OIDs from BIG-IP VE are:

INTEGER: 0

No Such Instance currently exists at this OID

 

For example, replays from snmpwalk for those hardware OIDs:

CPU TEMP: .1.3.6.1.4.1.3375.2.1.3.2.1.2.1.2

CPU FAN: .1.3.6.1.4.1.3375.2.1.3.2.1.2.1.3

CHASSIS TEMP: .1.3.6.1.4.1.3375.2.1.3.2.3.2.1.2

PSU STATUS: .1.3.6.1.4.1.3375.2.1.3.2.2.2.1.2

CHASSIS FAN: .1.3.6.1.4.1.3375.2.1.3.2.1.2

 

snmpwalk -v 2c -c public 127.0.0.1 .1.3.6.1.4.1.3375.2.1.3.2.1.2.1.2

F5-BIGIP-SYSTEM-MIB::sysChassisFanStatus = No Such Instance currently exists at this OID

 

snmpwalk -v 2c -c public 127.0.0.1 .1.3.6.1.4.1.3375.2.1.3.2.1.2.1.3

F5-BIGIP-SYSTEM-MIB::sysChassisFanSpeed = No Such Instance currently exists at this OID

 

snmpwalk -v 2c -c public 127.0.0.1 .1.3.6.1.4.1.3375.2.1.3.2.3.2.1.2

F5-BIGIP-SYSTEM-MIB::sysChassisTempTemperature = No Such Instance currently exists at this OID

 

snmpwalk -v 2c -c public 127.0.0.1 .1.3.6.1.4.1.3375.2.1.3.2.2.2.1.2

F5-BIGIP-SYSTEM-MIB::sysChassisPowerSupplyStatus = No Such Instance currently exists at this OID

 

snmpwalk -v 2c -c public 127.0.0.1 .1.3.6.1.4.1.3375.2.1.3.2.1.2

F5-BIGIP-SYSTEM-MIB::sysChassisFanTable = No Such Object available on this agent at this OID

 

if we go back to upper OID hardware leaf .1.3.6.1.4.1.3375.2.1.3, we can see the whole replay:

Environment

  • BIG-IP LTM
  • Virtual Edition

Cause

The replay to hardware OID requests from BIG-IP Virtual Edition are expected to be INTEGER: 0, as SNMP on BIG-IP Virtual Edition platform is unable to provide information about hardware components from Hypervisor.

Recommended Actions

F5 recommends that you do not query hardware OIDs on Virtual Edition platforms.
