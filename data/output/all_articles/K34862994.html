K34862994: Exchange Outlook Calender not visible with hybrid setup across on-prem and cloud users

Type
Support Solution
Published
2021-01-19
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 12.1.3
Source
https://my.f5.com/manage/s/article/K34862994
Description

Exchange on-prem and cloud (o365) setup together and cloud and on-prem users not able to view calendar for each other.
on-prem to on-prem user works fine
cloud to cloud user works fine
But on-prem and cloud users cannot access each others calendar.

Environment

  • Exchange both on-prem and cloud users together
  • Out of Office did not work either
Cause

/mapi traffic is sent with Bearer header : APM does not support it currently
The current Exchange hybrid iRule does not handle this scenario too.

Recommended Actions

Use the below modified iRule instead of the one on the Exchange iApp guide (on-prem Exchange VS)

priority 1
when HTTP_REQUEST {
     set is_disabled 0
     switch -glob [string tolower [HTTP::path]] {
         "/ews/mrsproxy.svc" -
         "/ews/exchange.asmx" -
         "/ews/*/exchange.asmx/wssecurity" -
         "/ews/exchange.asmx/wssecurity" {
             set is_disabled 1
             set path [HTTP::path]
             log local0. "Disabling ACCESS for $path"
             ACCESS::disable
             HTTP::path _disable-$path
             pool /Common/<Exchange_iApp_name>.app/<Exchange_Pool_name>     #### Replace with Exchange iApp and "edge" Pool names
         }
          "/mapi*" {
             set is_disabled 1
             set path [HTTP::path]
                         log local0. "Disabling ACCESS for $path"
             ACCESS::disable
             HTTP::path _disable-$path
             pool /Common/<Exchange_iApp_name>.app/<Exchange_Pool_name>     #### Replace with Exchange iApp and "edge" Pool names
         }
         "/autodiscover/autodiscover.svc/wssecurity" -
                 "/autodiscover/autodiscover.xml" -
         "/autodiscover/autodiscover.svc" {
             set is_disabled 1
        set path [HTTP::path]
                         log local0. "Disabling ACCESS for $path"
             ACCESS::disable
             HTTP::path _disable-$path
             pool /Common/<Exchange_iApp_name>.app/<Exchange_Pool_name>     #### Replace with Exchange iApp and "edge" Pool names
         }
     }
}
when HTTP_REQUEST_RELEASE {
    if { [info exists is_disabled] && $is_disabled == 0 } { return }
        if { [info exists path] } {
            HTTP::path $path
            unset is_disabled
            unset path
    }
}
