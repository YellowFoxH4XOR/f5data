K65450462: Adding management route resets management IP to default

Description

When deploying a validated Declarative Onboarding (DO) declaration with management routes, the BIG-IP reverts to the default 192.168.1.245 address

Environment

  • BIG-IP with DO package v1.24.0 installed
  • The BIG-IP has the the management-ip configured like the one below:

sys management-ip 10.168.52.150/24 {
    description configured-statically
}
sys global-settings {
    gui-setup disabled
    mgmt-dhcp disabled
}

Cause

  • The BIG-IP configuration has one global-setting (mgmt-dhcp) that affects both management routes and management ip
  • Adding a management route with the DO setting 'preserveOrigDhcpRoutes' (default is false) enables mgmt-dhcp but resets the management ip to the default 192.168.1.245
  • This issue is tracked in ID 1059717

Recommended Actions

F5Networks/f5-declarative-onboarding Github Issue 169 documents this issue and can be tracked for fixes in upcoming releases
