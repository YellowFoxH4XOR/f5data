Known Issue

When network configuration errors exist, DNS cache resolver connections may remain in memory longer than the configured time-out.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server to reference a DNS profile.
  • Your BIG-IP system's network configuration has one or more errors that significantly degrade the system's connectivity to remote devices.

Impact

Increased memory consumption may cause general traffic processing instability.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system has an excessive number of DNS cache connections that remain in memory for a longer period of time than the configured time-out.
  • The BIG-IP system is processing traffic at a slower rate than expected.

Workaround

To work around this issue, you can ensure that the BIG-IP system network configuration is free from errors, and that the system is able to communicate with remote devices with low latency.

Impact of workaround: Performing the recommended workaround should not have a negative impact on your system.
