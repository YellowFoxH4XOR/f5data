Description

  • You are managing your NGINX Instance using NGINX Instance Manager and to do so, you installed NGINX Agent 
  • Your managed instance/s has a very large spec, like CPU cores exceed 100 core, like 140
  • With the above, however, the Agent log start to record error "Number of NGINX worker processes (140) is greater than queue size (100)
time="2012-12-12T12:12:12+12:12" level=warning msg="Number of NGINX worker processes (140) is greater than queue size (100). Update NGINX Agent config to increase the queue size so that it is greater than the number of NGINX worker processes."

Environment

  • NGINX Instance Manager
  • NGINX Agent
  • Internal queue size Parameter

Cause

  • By default, the NGINX Agent "Internal queue size" is set at "queue_size: 100"

Recommended Actions

  • The recommendation is to set the value for "Internal queue size" to "equal" to or "greater than" twice the number of running NGINX worker_processes.
  • Meaning if you have a worker process equaling 140, then it is appropriate to set the value like"queue_size: 280".
  • To adjust the value, edit "/etc/nginx-agent/nginx-agent.conf" file and update "queue_size" as recommended.
    • ACCESS NGINX Agent configuration file

vi /etc/nginx-agent/nginx-agent.conf

  • Find an entry for "Internal queue size" set at "queue_size: 100"
    • modify this value to "Internal queue size" to "equal" to or "greater than" twice the number of running NGINX worker_processes
