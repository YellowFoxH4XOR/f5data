Topic

Customers with valid Standard or Premium Support contracts can open a proactive service request with F5 Support prior to any software upgrade, hardware migration, data center relocation, or any other activity that requires a dedicated maintenance window. Proactive service requests provide F5 Support advance notice of your maintenance window to save time in case a problem arises that requires F5 Support assistance.

You can also attach data collected prior to the configuration change to define a configuration and network traffic baseline. For more information about how to gather baseline information, refer to K11555: Gathering data in preparation for a traffic-impacting change to the BIG-IP system.

Description

Important points to know before opening a proactive service request

When opening a proactive service request with F5 Support, you should note a few important points about the proactive service request process:

  • Opening a service request does not guarantee that a network support engineer (NSE) will be available to work with you during the maintenance window or help you complete maintenance tasks. The service request is in place in case you require F5 Support assistance due to a failure that occurs during the maintenance window.
  • F5 does not actively monitor proactive service requests for email or F5 Web Support updates. If you need F5 Support assistance, you must call F5 Support using one of the F5 Support phone numbers and mention the proactive service request number.
  • F5 treats requests for assistance on proactive service requests as "high site at risk" or "urgent site down" and prioritizes such requests along with other new high and urgent service requests received at that time.
  • F5 recommends that you create your proactive service request at least two weeks in advance, if possible.
  • F5 recommends that you use Proactive as your selection in the Reason for Contact field when creating a case on MyF5 to help identify the new proactive service request.
  • F5 provides assistance for Standard Support contracts within Standard Support hours only. For more information, see Standard and Premium Support for contract details.
  • Before planning your maintenance window to ensure you get the support in the event of an issue during the maintenance window, you may verify your support entitlement and the contract expiry by referring to K32755669: How to verify support contract end date.

Opening a proactive service request

To open a proactive service request, perform the following steps:

  1. Open a support case with F5 Support.

    For more information about how to create a support case, refer to K2633: Instructions for submitting a support case to F5.

Considerations and best practices when planning a major change

Note: Your company is responsible for designing and implementing configuration changes, software upgrades, hardware migrations, data center relocations, and other related activities that require a dedicated maintenance window and that likely stop production traffic.

  • Thoroughly review F5 release notes for the software version to which you intend to upgrade or any other relevant F5 documentation, such as known issues, two weeks before your scheduled maintenance window.
  • Clarify with F5 Support any questions you have before the maintenance window by using a separate service request. If you prefer to use only the new proactive service request to discuss the upcoming maintenance, you must call F5 Support using one of the F5 Support phone numbers and mention the proactive service request number.
  • Prepare a rollback strategy in case you need to run such a procedure.
  • Create a bootable image with the original software version in case a clean install becomes necessary. For more information, refer to K13117: Performing a clean installation of BIG-IP 11.x - 16.x.
  • Whenever possible, have remote access available for F5 Support.
  • Carefully follow documented F5 release notes and associated upgrade instructions.
  • If issues arise during the maintenance window, make sure that you gather the relevant data while the event is still occurring and before you roll back the installation. For more information, refer to K2633: Instructions for submitting a support case to F5.
  • Important: Because F5 does not actively monitor proactive service requests, to update or append your request you must call F5 Support using one of the F5 Support phone numbers and mention the proactive service request number. F5 prioritizes your call along with other new high and urgent service requests made at the time.
