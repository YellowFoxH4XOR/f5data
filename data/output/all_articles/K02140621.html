K02140621: How to test SSL resumption using OpenSSL s_client

Type
Support Solution
Published
2023-04-28
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K02140621

Description

When testing SSL resumption function, we can use OpenSSL command to send SSL packets to BIG-IP Virtual Server.

Environment

  • BIG-IP
  • Virtual Server
  • Client SSL profile
  • Client with OpenSSL installed

Cause

None

Recommended Actions

  1. You can run the command below on client to simulate client established SSL connection with Virtual Server, then disconnected and reconnect with SSL resumption.

openssl s_client -connect <Virtual IP>:<Port> -no_ticket -reconnect

Additional Information
None
