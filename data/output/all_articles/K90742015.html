Known Issue

The BIG-IP APM eam process may produce a core file and restart.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access policy is configured for authentication, authorization, and accounting (AAA) using Oracle Access Manager (OAM).
  • The OAM application programming interface (API) experiences an exception when processing Access SDK (ASDK) API calls.

Impact

Users cannot authenticate while the eam process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Core files from the eam process appear in the /shared/core directory, similar to the following example:

    eam.bld807.0.core.gz
  • Content accessed through the affected access profile does not render correctly, or is inaccessible.
