Description

Prefix Length set as none by default in Source address persistence profile.

Environment

  • Product: BIG-IP LTM
  • Persistence profile: source address persistence (source-addr)

Cause

 Informational

Answer/Recommended Actions

Default none means /32 subnet mask which means every single client IP will get a separate persistence record. It's not mandatory to configure prefix (if you don't configure it, the mask 'none' will be applied by default).

Mask '/24' for example means that each /24 subnet will get a different persistence record.

Additional Information

For example, if client 10.1.1.1 arrives at the VIP with /24 persistence profile, the VIP will create a persistence record with 10.1.1.0/24 pointing to the chosen pool member. Any other client after this record, which falls into the same /24 subnet, will use the same persistence record to send to same pool member.
