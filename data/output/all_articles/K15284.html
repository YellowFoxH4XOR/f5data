K15284: Removing the 'local/' string from the host name portion of the syslog message sent to your remote syslog server

Topic

You should consider using this procedure under the following condition:

  • You want to remove the local/ string from the host name portion of the syslog message sent to your remote syslog server.

Description

Prior to BIG-IP 11.x, log messages are sent to the remote log server with the local/ string prepended to the host name of the BIG-IP system. In BIG-IP 11.x and later, only the host name is included in the syslog message sent to the remote syslog server. If you would like to emulate the version 11.x behavior in version 10.x, you can use syslog-ng filters to create a custom string.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrator access to the BIG-IP command line.
  • You have a remote syslog-ng server that is accessible from the BIG-IP system.

Procedures

Replace the remote syslog server configuration with a custom syslog include configuration

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP LTM command line.
  2. If you already have your remote syslog server configured on the BIG-IP system, remove that configuration by typing the following command:

    bigpipe syslog remote server none

    Important: This step disables all remote logging. If you have multiple syslog servers configured and want to retain them, refer to K10057: Syntax change for the 'bigpipe syslog remote server' command.
  3. Using a text editor of your choice, create a file with the following name:

    /var/tmp/syslog.inc
  4. Enter the following information, replacing [ip_address] with the IP address of your remote syslog server:

    syslog {

    include "template t_remotetmpl {
    template(\"<$PRI> $DATE $HOST $PRIORITY kernel: $MSG\n\"); template_escape(no); };
    destination remote_server {
    udp(\"[ip_address]\" port (514) template(t_remotetmpl)); };
    log {source(local); filter(f_notLocal6); filter(f_local0); destination(remote_server); };"

    }

    For example:

    syslog {

    include "template t_remotetmpl {
    template(\"<$PRI> $DATE $HOST $PRIORITY kernel: $MSG\n\"); template_escape(no); };
    destination remote_server {
    udp(\"10.0.0.250\" port (514) template(t_remotetmpl)); };
    log {source(local); filter(f_notLocal6); filter(f_local0); destination(remote_server); };"

    }
  5. Load the new configuration by typing the following command:

    bigpipe merge /var/tmp/syslog.inc
  6. Save the new configuration by typing the following command:

    bigpipe save all
