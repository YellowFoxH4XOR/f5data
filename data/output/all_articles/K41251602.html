K41251602: ASM JavaScript behavior when repackaging large HTTP request

Description

By default, ASM JavaScript objects that live in a client browser can repackage an HTTP request with a length up to 6KB. this behavior is controlled by ASM DB key dosl7.max_dynamic_params_injection_length. You should consider the recommendation of this article if you're observing unexpected behavior with ASM JavaScript challenges.

Environment

The virtual server in question is configured with ASM features that use JavaScript.

Cause

ASM JavaScript fails to repackage HTTP requests with a length greater than 6KB.

Recommended Actions

  • Increase the ASM DB key dosl7.max_dynamic_params_injection_length to a value greater than the length of the HTTP request or to the max value "7000":
tmsh modify sys db dosl7.max_dynamic_params_injection_length value 7000
tmsh save sys config
  • Consider other mitigation if the request is larger than 7KB.
