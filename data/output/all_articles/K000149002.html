K000149002: Machine certificate using SAN in multi-language might fail to recognize the extraction pattern.

Type
Support Solution
Published
2024-12-16
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000149002

Description

There will be some scenarios where the SubjectAltName is formatted in a specific language.


In this example the Turkish version of DNS Name=([^]+).* is DNS Adi=([^]+)*

 

2023-10-30,12:28:13:583, 3168,5876,, 48, \certinfo.cpp, 1344, CCertInfo::MatchCertificate, Di?er Ad:As?l Ad=AAA-0000$@example.com, 
DNS Ad?=AAA-0000.example.com doesn't match pattern ".*DNS Name=([^,]+).*"

 

The combination of these patterns using Partial extraction:

(.*DNS Name=([^]+).*, .*DNS Adi=([^]+)* or .*DNS Name=([^]+).*, .*DNS Ad?=([^]+)*,)

Do not work for Match subject Alt Name in Machine Cert Auth configuration.

Environment

  • BIG-IP APM
  • Machine Certificate Autentication


Resolution

In this scenario, Partial extraction will not work.  Therefore, you have to use whole extraction.

Using .* will be recommended because it specifies that the entire SubjectAltName content be extracted for matching.
