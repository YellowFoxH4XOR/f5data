Description

Users are unable to change expired passwords in Citrix StoreFront.

Due to this issue, the expired password has to be changed manually on the Active Directory.

Environment

  • Citrix StoreFront
  • Login with a non-expired password works fine

Cause

Window Authentication port 464 is disabled on Firewall that is between the BIG-IP and the Active Directory.

Hence, the traffic containing requests for password updates does not reach the Active Directory.

Recommended Actions

Allow port 464 on the firewall.

Additional Information

None.
