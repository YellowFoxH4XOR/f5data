Known Issue

Using BIG-IP APM SNMP object identifiers (OIDs) may return incorrect values.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is actively processing user sessions and the configuration includes an access profile.
  • You use the apmGlobalConnectivityStatCurConns SNMP OID (.1.3.6.1.4.1.3375.2.6.1.5.3.0) to view the total current Secure Sockets Layer (SSL) and Virtual Private Network (VPN) connections.

Impact

The values returned from SNMP are incorrect.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The value returned by the apmGlobalConnectivityStatCurConns SNMP OID does not reflect the actual number of current connections.
