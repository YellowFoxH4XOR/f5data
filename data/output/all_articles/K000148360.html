Description

  • You access your services with FireFox
  • After you start your web application it times out and it restarts the same process after 6 minutes
  • FireFox disconnecting after approx 6 minutes due to it no longer exchanging keep alives and the F5 terminates the connection
  • You run the same application but now from a Chrome browser which does not restart the process and it runs to completion in ~10-15 minutes.

 

Environment

  • FireFox
  • Keep-Alive

Cause

Server side TCP profile set to default idle-timeout setting

Recommended Actions

Adjust the server side tcp profile to have a higher idle-timeout value

Additional Information

None
