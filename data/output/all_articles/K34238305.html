K34238305: Unable to backup UCS after upgrade to v15.1.3, getting ''9090>Connection refused'' error message

Type
Support Solution
Published
2021-08-18
Updated
2023-11-22
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 15.1.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0
Source
https://my.f5.com/manage/s/article/K34238305

Description

After upgrading the device to v15.1.3, the BIG-IP is unable to backup the UCS file (either GUI or CLI "tmsh save sys ucs"), getting this error message similar to the following.

info: Thrift: Tue Dec 19 10:53:45 2017 TSocket::open() connect() <Host: localhost Port: 9090>Connection refused
info: Error during config save.
info: Unexpected Error: UCS saving process failed.

Environment

  • BIG-IP LTM
  • The device is upgraded to v15.1.3
  • Scheduled report is configured on the device

Cause

Undetermined at the time of publication.

Recommended Actions

  1. Login to the BIG-IP by using CLI.
  2. Back up the bigip.conf

    cp /config/bigip.conf /config/bigip.conf.bak
     
  3. Modify the bigip.config, remove all analytics scheduled report, similar to the following example.

    analytics cpu scheduled-report <name_of_the_report> {
        frequency every-24-hours
        include-total enabled
        last-run-status success
        module-name tmstat_cpu
        multi-leveled-report {
            measures { cpu_usage_percent io_percent stolen_percent plane_name }
            time-diff last-hour
            view-by tmstat_cpu
        }
        smtp-config /Common/<name_of_the_snmp>
    }
     
  4. Save the file.
  5. Load the configuration.

    tmsh load sys config partitions all
     
  6. Try to backup the UCS (either GUI or CLI command)
Alternatively, you can open a case with F5 support to get assistance with removing the configuration.

Additional Information

None.
