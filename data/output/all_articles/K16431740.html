Description

Similar logs are found when trying to generate a UCS file:
  • Exception: (Can't open temp file fd (/var/system/tmp/tmsh/Nf9y5B/data), No space left on device) (framework/TempFile.cpp, line 46), exiting...

Environment

  • BIG-IP LTM/ASM
  • Version 14.x
  • LiveUpdate

Cause

This issue is related to this Bug ID 907025

Recommended Actions

Please find the files that are consuming space in "var":

find /var -xdev -printf '%h\n' | sort | uniq -c | sort -k 1 -nr | head -25

If you sea a lot of files related to liveUpdate, please delete them with next command:

#rm -rf /var/cache/tomcat/temp/Live-Update*

Restart tomcat:

#tmsh restart sys service tomcat.

Try to generate the UCS file again.
