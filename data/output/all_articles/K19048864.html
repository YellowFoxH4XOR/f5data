Description

  • ASM events are being logged twice
  • On BIG-IQ GUI on Monitoring > EVENTS > Web Application Security > Event Logs > Events you can see duplicated ASM events

Environment

  • BIG-IQ CM
  • Multiple BIG-IQ DCDs (2 or more)
  • ASM security log profile configured to send log to multiple DCDs
  • ASM event logs

Cause
Seen behaviour is expected when the security log profile is configured to send logs to multiple DCDs.

    Recommended Actions

    If you don't have a BIG-IP device to host a virtual server that load balances the logging messages to the pool of DCDs, you will need to configure the logging profile to point to only one DCD.
    Redundancy is already built-in to the Elasticsearch Cluster with replication.
    However, that relies on the ability for the data to reach one DCD in the first place.

    Additional Information

    To optimize data logging from your BIG-IP devices to multiple DCDs, you can configure a BIG-IP system to load balance these messages among the DCDs. This process prevents duplication of information in the consolidated data repository, while also providing high availability for your log messages in the case that one or more DCDs become unavailable.

    To Configuring high availability logging for multiple DCDs you will need the following:

    • Three or more data collection devices (recommended). If you only have one DCD, you can configure data logging directly to the DCD's IP address during the BIG-IQ configuration process.
    • A BIG-IP device that hosts a virtual server that load balances logging messages to the pool of DCDs.
    • A separate BIG-IP device that hosts a virtual server with an ASM policy and an enabled HTTP logging profile.
    For more information about data logging over multiple BIG-IQ DCDs, refer to the following product manuals according to your BIG-IQ versions:
    • BIG-IQ versions 6.x and 7.0, refer to the Deploying a Data Collection Device chapter in the Planning and Implementing a BIG-IQ Deployment manual.
    • BIG-IQ versions 7.1.0 and later, refer to the Connect BIG-IP data logs to a Data Collection Device Cluster chapter in the Setting up and Configuring a BIG-IQ Centralized Management Solution manual.
