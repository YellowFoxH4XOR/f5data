Topic

You should consider using these procedures under the following conditions:

  • You want to view the current number of established concurrent access sessions
  • You want to view the current number of established concurrent connectivity sessions

Description

The BIG-IP APM system is licensed for cumulative user access in two distinct methods. The access session license value represents the total concurrent user sessions for the BIG-IP APM system. The number of VPN/CCUs represents the total concurrent connectivity sessions based on a specific set of user access profiles using SSL VPN, port forwarding, and reverse proxies. For more information, refer to K13267: BIG-IP APM connectivity license use.

To view the concurrent access sessions, you must access BIG-IP APM through an external SNMP tool. Alternatively, you can use the snmpwalk utility on the BIG-IP APM system without having to configure the system for external SNMP polling. To determine the license usage for concurrent access sessions, you can compare the result obtained from SNMP to the BIG-IP APM access sessions license. The following procedures outline how to obtain the required information from the BIG-IP APM command line.

Note: To determine the number of access sessions and VPN/CCUs your BIG-IP APM system is licensed for, refer to K15032: Determining license limits of the BIG-IP APM system.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrative command line access to the BIG-IP APM system.
  • You are familiar with the snmpwalk utility.

Procedures

You can view the number of concurrent access sesstions and connectivity sessions using the snmpwalk utility from the BIG-IP command line. To do so, perform one of the following procedures:

  • Viewing the number of used concurrent access sessions
  • Viewing the number of concurrent connectivity sessions

 

Viewing the number of used concurrent access sessions

Impact of procedure: The following procedure should not have a negative impact on your system.

To view the concurrent access sessions, enter the following command from the BIG-IP APM command line:

snmpwalk -v 2c -c public localhost F5-BIGIP-APM-MIB::apmAccessStatCurrentActiveSessions

Note: F5-BIGIP-APM-MIB::apmAccessStatCurrentActiveSessions converts to the 1.3.6.1.4.1.3375.2.6.1.4.3.0 OID.

The command output appears similar to the following example:

F5-BIGIP-APM-MIB::apmAccessStatCurrentActiveSessions.0 = Counter64: 104

In this command output, note the following:

  • <104> is the total current access sessions on this device

Additionally, you can configure the BIG-IP APM system to allow an external SNMP polling system to gather this and other information.

Viewing the number of concurrent connectivity sessions

Impact of procedure: The following procedure should not have a negative impact on your system.

To view the concurrent connectivity sessions, enter the following command from the BIG-IP APM command line:

snmpwalk -v 2c -c public localhost F5-BIGIP-APM-MIB::apmGlobalConnectivityStatCurConns

Note: F5-BIGIP-APM-MIB::apmGlobalConnectivityStatCurConns is applicable only to BIG-IP 12.1.2 and later. For more information, refer to K17305: Using BIG-IP APM SNMP OIDs may return incorrect values. F5-BIGIP-APM-MIB::apmGlobalConnectivityStatCurConns converts to the 1.3.6.1.4.1.3375.2.6.1.5.3.0 OID.

The command output appears similar to the following example:

F5-BIGIP-APM-MIB::apmGlobalConnectivityStatCurConns.0 = Counter64: 100

In this command output, note the following:

  • <100> is the number of concurrent connectivity sessions (VPN/CCU) in use.

Additionally, you can configure the BIG-IP APM system to allow an external SNMP polling system to gather this and other information.
