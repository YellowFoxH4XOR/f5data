K93541494: Cannot access new existing object in FAST template

Type
Support Solution
Published
2021-02-11
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K93541494

Description

Cannot access new tmsh objects in FAST template

Environment

  • FAST is installed
  • New tmsh object is created, e.g., ssl cert
  • New tmsh object is not available in FAST template

Cause

FAST is not able to see a tmsh object if it is created after FAST is installed.

Recommended Actions

There are a few workarounds:
  1. Uninstall and then reinstall FAST
  2. Reboot the BIG-IP
  3. Restart restjavad and restnoded with this command:
    bigstart restart restjavad restnoded
