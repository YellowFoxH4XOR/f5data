K3063: Both units in a redundant pair may enter standby state when gateway failsafe is enabled

Topic

When BIG-IP has gateway failsafe enabled, the active BIG-IP system continually pings the default gateway. If a ping fails to get a response in the specified amount of time, the active BIG-IP system will failover and enter standby mode. The BIG-IP system will not return to active mode until it can reestablish connectivity to the gateway address.

Therefore, when using gateway failsafe, you must configure a separate gateway address for each system in the redundant pair. If you do not, both systems will enter standby mode if the specified gateway goes down and will not return to an active state until it can connect to the gateway address.

Note: It is possible for the pair to go into a standby-standby state even if you configure a separate gateway address for each system; however, this behavior is rare and will only occur if both gateways are down.
