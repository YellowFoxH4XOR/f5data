K16845113: Automatic FCP usage reports fail to send with error ''Report submission failed: The requested URL was rejected. Please consult with your administrator.''

Type
Support Solution
Published
2020-04-09
Updated
2024-04-02
Applies to
  • Virtual Editions
  • BIG-IQ
  • F5 Cloud Services
  • BIG-IQ Centralized Management: 8.X.X, 6.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K16845113

Description

You are using the automated report option in BIG-IQ to submit your FCP usage reports each month.
Whilst submitting the report you notice a failure message similar to the one below:

Report submission failed: The requested URL was rejected.  Please consult with your administrator.

For example:
 

Environment

  • BIG-IQ
  • FCP reporting
  • Cloud (Azure / Cytech)

Cause

Automated reports are sent from BIG-IQ to the F5 API server for processing, the report is a json formatted text file.
We initially saw this issue occur when the F5 API server was rejecting the report due to the presence of the "tenant" field in the json file.

Recommended Actions

  1. Disable automatic reporting (Expand license management, reports, click on schedule, uncheck schedule status enable)
  2. Periodically generate the reports manually
  3. See "Additional Information" below for code sample.
  4. Run the script on each report to fix the format issue
  5. Submit the json report to F5 vesubscriptions@f5.com

Additional Information

You can create a dos bat file using the code example below:

@echo off
setlocal enabledelayedexpansion

set INPUT_FILE=input.json
set OUTPUT_FILE=output.json

findstr /v /c:"      ""tenant""" "input.json" > "output.json"


rename your json file input.json and send the output.json to vesubscriptions@f5.com

When BIG-IP was deployed in Azure, the field "tenant" was added to the json report file, and this was rejected by F5 API.

This has now been resolved internally.

If you encounter a similar issue please contact your Customer Success Manager or raise a support call.
