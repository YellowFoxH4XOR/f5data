K000137661: Allow TMM to use the BGP learned route for default gateway

Type
Support Solution
Published
2023-11-29
Updated
2025-02-07
Applies to
  • BIG-IP Next
  • BIG-IP Next CNF
Source
https://my.f5.com/manage/s/article/K000137661

Description

Mapres building TMM's initial configuration , where discovering cluster gateway and setup as default. In most BIG-IP Next CNF deployments that connect external BGP router requires TMM to use the BGP learned route for default gateway. To allow configuration, TMM_IGNORE_GATEWAYS environment has to be set to true in helm values.

Environment

  • OpenShift 4.12
  • BIG-IP Next CNF 

Cause

 Removing the default gateway from the TMM routing table

Recommended Actions

1. Check current configuration in TMM container and route via bdt_cli from debug container 
#  oc exec -it deploy/f5-tmm -c f5-tmm -- cat tmm_init.tcl | grep -i gateway
gateway 169.254.1.1
gateway6 fe80::ecee:eeff:feee:eeee
# oc exec -it deploy/f5-tmm -c debug -- bdt_cli -u -s tmm0:8850 route
routeType:1 isIpv6:false destNet:{ip:{addr:10.1.30.0, rd:0} pl:24} gw:{ip:{addr:10.1.10.52, rd:0}} gwType:1 interface:clientside
routeType:0 isIpv6:false destNet:{ip:{addr:<none>, rd:0} pl:0} gw:{ip:{addr:169.254.1.1, rd:0}} gwType:1 interface:eth0 -->> going towards calico defined gw
routeType:1 isIpv6:false destNet:{ip:{addr:10.1.10.0, rd:0} pl:24} gw:{ip:{addr:<none>, rd:0}} gwType:0 interface:clientside
routeType:1 isIpv6:false destNet:{ip:{addr:10.1.20.0, rd:0} pl:24} gw:{ip:{addr:<none>, rd:0}} gwType:0 interface:serverside
routeType:1 isIpv6:false destNet:{ip:{addr:127.20.0.0, rd:0} pl:16} gw:{ip:{addr:<none>, rd:0}} gwType:0 interface:tmm_bp
routeType:0 isIpv6:false destNet:{ip:{addr:169.254.1.1, rd:0} pl:32} gw:{ip:{addr:<none>, rd:0}} gwType:0 interface:eth0
routeType:1 isIpv6:false destNet:{ip:{addr:10.1.215.204, rd:0} pl:32} gw:{ip:{addr:<none>, rd:0}} gwType:0 interface:eth0
2 . Setup TMM_IGNORE_GATEWAYS and TMM_CALICO_ROUTER , which can be done edit TMM deployment or  by redeploy CNF
 
2.1. Edit TMM deployment 
# oc edit deploy/f5-tmm

spec:
  template:
    spec:
        env:
		- name: TMM_CALICO_ROUTER
		  value: default
		- name: TMM_IGNORE_GATEWAYS
		  value: "true"
2.2 . Redeploy CNF via helm using values.yaml, where added such environments - refer to BIG-IP Controller installation   
tmm:
  customEnvVars:
   - name: TMM_CALICO_ROUTER
   value: "default"
   - name: TMM_IGNORE_GATEWAYS
   value: "TRUE"

 

3. Check if TMM configured with BGP default gateway and gateway was removed from tmm_init.tcl in f5-tmm container of TMM pod, 
 

#  oc exec -it deploy/f5-tmm -c f5-tmm -- cat tmm_init.tcl | grep -i gateway 

# oc exec -it deploy/f5-tmm -c debug -- bdt_cli -u -s tmm0:8850 route
routeType:1 isIpv6:false destNet:{ip:{addr:<none>, rd:0} pl:0} gw:{ip:{addr:10.1.20.52, rd:0}} gwType:1 interface:serverside -->> the default BGP route


4. When enabling the BIG-IP Contoller TMM_IGNORE_GATEWAYS Helm parameter or edit TMM deployement, cluster (Pod-to-Pod) traffic may fail. Use the steps below to manually create routes for cluster traffic - static route documentation 

# vi cnf_static_route.yaml
apiVersion: "k8s.f5net.com/v1"
kind: F5BigNetStaticroute
metadata:
 name: "cni-static-route-pod"
 namespace: "cnf-gateway"
spec:
 destination: 10.1.0.0
 dynamic: false
 prefixLen: 16
 type: gateway
 gateway: 169.254.1.1
---
apiVersion: "k8s.f5net.com/v1"
kind: F5BigNetStaticroute
metadata:
 name: "cni-static-route-service"
 namespace: "cnf-gateway"
spec:
 destination: 10.152.183.0
 dynamic: false
 prefixLen: 24
 type: gateway
 gateway: 169.254.1.1

# oc apply -f cnf_static_route.yaml

# oc exec -it deploy/f5-tmm -c debug -- bdt_cli -u -s tmm0:8850 route
routeType:1 isIpv6:false destNet:{ip:{addr:<none>, rd:0} pl:0} gw:{ip:{addr:10.1.20.52, rd:0}} gwType:1 interface:serverside
routeType:0 isIpv6:false destNet:{ip:{addr:10.152.183.0, rd:0} pl:24} gw:{ip:{addr:169.254.1.1, rd:0}} gwType:1 interface:eth0  -->>
routeType:0 isIpv6:false destNet:{ip:{addr:10.1.0.0, rd:0} pl:16} gw:{ip:{addr:169.254.1.1, rd:0}} gwType:1 interface:eth0      -->>
