K95506031: License server has returned an exception. Fault code: 51080

Type
Support Solution
Published
2021-08-26
Updated
2024-04-15
Applies to
  • BIG-IP
  • rSeries Platforms
  • VELOS Platforms
Source
https://my.f5.com/manage/s/article/K95506031

Description

When customer tried to activate the key shipped with the device, below error message was shown in GUI:

Server Error(s)
__________________________________________________
License server has returned an exception
Fault code: 51080
Fault text: Error 51080, invalid Base registration Key - Unknown Key - ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG 
 

Environment

  • Initial activation of license
  • BIG-IP
  • r-Series
  • VELOS  

 

Cause

The Registration Key shipped with the hardware might not be correct.
 

Recommended Actions


Call F5 support to check if the base registration key shipped with the hardware is correct
