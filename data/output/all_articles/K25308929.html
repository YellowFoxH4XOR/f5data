Known Issue

The pendsect process logs informational messages using the warning log level.

The pendsect utility runs daily and checks for pending sector alerts on the BIG-IP system. This utility logs messages to the /var/log/user.log file.

Impact

None. The error messages are cosmetic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the pendsect process runs, and no errors are detected or corrected, the BIG-IP system logs messages that appear similar to the following example to the /var/log/user.log file:

    warning pendsect[21788]: pendsect: /dev/sdb no Pending Sectors detected
