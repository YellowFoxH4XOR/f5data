K000133750: RDP Error on APM: Remote desktop can't find computer <name>. ''VIP disabled (administrative)''

Type
Support Solution
Published
2023-05-01
Updated
2023-05-01
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000133750

Description

Remote Desktop Protocol (RDP) resources not working correctly through a Webtop in the F5 APM policy. The problem manifests as an error message when attempting to connect to RDP after downloading the RDP file from the APM. The error message indicates that the remote computer cannot be found. The message may be similar but not limited to:

 

Remote desktop can't find computer <name>

 

Additionally, in a packet capture the following RST is sent from the client to the VS:

 

 

TCP s1/tmm2 : 48603 → 3389 [RST, ACK] Seq=1 Ack=1 Win=0 Len=0 [F5RST: TCP RST from remote system]

 

Some/all of the following VDI logs are also visible:

 

 

debug vdi 17GetSessionDBValue : error 18

notice vdi Error reported for an outgoing connection

notice vdi Failed to connect to RDG target <name> Connection refused

debug server-side connection was reset, reason: TCP RST from remote system

 

Environment

F5 APM policy with RDP resources configured through a Webtop

Forwarding virtual server present in the configuration

Cause

A disabled/misconfigured forwarding virtual server in the configuration is causing the RDP traffic to be blocked. When present and misconfigured, this virtual server prevents the F5 from sending out RDP traffic.

Recommended Actions

Identify the forwarding virtual server in the configuration that may be causing the issue. Look for any forwarding virtual servers that might be disabled or misconfigured, or on port 3389.

Remove the identified forwarding virtual server from the configuration if no longer needed or adjust the config.
