Known Issue

This is the result of a known issue. In BIG-IP version 10.x, F5 does not fully support the bigpipe software command on devices using the partitions disk-formatting scheme, and you should not use the command to add or delete image locations.

Note: For information about determining if your BIG-IP system is using the partitions disk-formatting scheme, refer to K10817: Determining the disk-formatting scheme used by a BIG-IP version 10.x system.

If your BIG-IP system is using the partitions disk-formatting scheme, and you add or delete image locations with bigpipe software commands, your system may be unable to install any software images without completely reformatting and erasing all configuration data on the device. The following are examples of commands that you should avoid using in this situation:

bigpipe software desired HD1.2 add

bigpipe software desired HD1.2 delete

You can type the bigpipe software status show command, and if your system is in the state mentioned above, the command output appears similar to the following example:

HD1.2 0 BIG-IP 9.4.8 355.0 no failed to create volumeset

You can use the bigpipe software commands on systems that use the partition disk-formatting scheme to perform other functions, including adding software to the software repository, changing the default boot location, installing version 10.x images to existing image locations, and returning information on installed products, versions, and builds with commands similar to the following examples:

bigpipe software desired HD1.2 active enable

bigpipe software images /var/tmp/BIGIP-10.0.1.283.0.iso add

bigpipe software desired HD1.2 product BIG-IP version 10.0.0 build 1234.0

Important: You should never use bigpipe software commands on a platform that has the BIG-IP version 9.x product installed, nor should you use the bigpipe software commands to install a version 9.x product to an alternate image location of an existing 10.x installation. Use the image2disk or im commands, as appropriate, when manipulating 9.x partitions and 9.x images and hotfixes.

F5 Product Development is tracking this issue as ID 291356.

Note: For more information about the bigpipe software command, refer to the bigpipe software help page or the Bigpipe Utility Reference Guide.

Note: For more information about working with version 9.x images and hotfixes, refer to the software help pages for image2disk and im, or the Using the image2disk and diskinit Utilities chapter of the BIG-IP Getting Started Guide, the Installing the Software section of the release notes for the appropriate BIG-IP 9.x software version, and K6845: Managing F5 product hotfixes for BIG-IP version 9.x systems.
