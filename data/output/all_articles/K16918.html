Topic

When used for server authentication of a pool, you can use the BIG-IP Server SSL profile to verify if a Secure Sockets Layer (SSL) server certificate is trusted and check its validity period.

If the Server SSL profile's Untrusted Certificate Response Control option is set to ignore, the BIG-IP system will not check the validity period of the certificate. As a result, the system will not perform the action configured in the Expire Certificate Response Control option. For example, when a Server SSL profile is configured to ignore an untrusted certificate of a pool member, the system will establish a connection to the member, regardless of the value set for the Expire Certificate Response Control option.
