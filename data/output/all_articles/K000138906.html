K000138906: Request for /TSPD/* is not responded by the Big-IP

Type
Support Solution
Published
2024-03-13
Updated
2024-03-13
Source
https://my.f5.com/manage/s/article/K000138906

Description

A BIG-IP will ignore the TSPD URL or forward it to the back end server if an LTM traffic policy disables ASM for these URLs.

As an example:

ltm virtual /test-me { ...

  policies {

    /policy-prod_web_asm_manager { }

  }

ltm policy policy-prod_web_asm_manager {

  controls { asm bot-defense }

  requires { http }

  rules {

    policy-prod-web_asm_manager {

      actions {

        0 {

          asm

          disable

        }

        1 {

          bot-defense

          disable

        }

      }

      conditions {

        0 {

          http-uri

          path

          starts-with

          values { /TSPD/ }

        }

      }

    }

Environment

BIG-IP bot defense or ASM

Cause

configuration

Recommended Actions

Remove the offending traffic policy conditions.
