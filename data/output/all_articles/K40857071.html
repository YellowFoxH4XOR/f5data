K40857071: Transfer certificates from one BIG-IP device to another

Type
Support Solution
Published
2022-03-21
Updated
2022-12-27
Applies to
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K40857071

Description

You can follow this article to transfer certificates and keys during migration between different BIG-IP hardware.

Environment

  • BIG-IP device
  • SSL Certificates 

Cause

Migration

Recommended Actions

Option 1:
1. Select the certificates from below path (checkbox) on your source device and select Archive option to archive all the certificates :
> System  > Certificate Management > Traffic Certificate Management > SSL Certificate List
Note : This will download the archive to your local computer

2. Import this archive to your destination device : 
> System  >  Certificate Management > Traffic Certificate Management > SSL Certificate List > Import > Select import type "Archive"

If for security concerns you do not want to download these certificate/keys to your local system, check out option 2.

Option 2:
1. Copy files directly from source BIG-IP to destination BIG-IP device via SFTP or SCP protocols which would keep these files encrypted during transfer

Certificates are stored in this directory : /config/filestore/files_d/Common_d/certificate_d
Private keys are stored in this directory : /config/filestore/files_d/Common_d/certificate_key_d

For details how to transfer files using command line scp or sftp utilities please refer K175: Transferring files to or from an F5 system

2. Once you copy certificates and keys from one BIGIP to another you need to 'install' them so they appear in the GUI. To do so, run below commands on destination BIG-IP device :

for keys : 
tmsh install /sys crypto key <key_name> from-local-file <key_path_and_name>

for certs :
tmsh install /sys crypto cert <cert_name> from-local-file <cert_path_and_name>

For example, to import the SSL key named testkey2.key, you type the following command:
tmsh install /sys crypto key testkey2.key from-local-file /config/filestore/files_d/Common_d/certificate_key_d/testkey2.key

None.
