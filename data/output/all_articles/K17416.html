Known Issue

The f5wininfo diagnostic report may be incomplete.

This issue occurs when all of the following conditions are met:

  • You have downloaded f5wininfo.exe executable to your Windows device.
  • The version of the f5wininfo build is 7091, 2013, 1211, 1151.

     Note: To view the f5wininfo build information, navigate to Help > About in the diagnostic utility.
  • Your run the Windows f5wininfo diagnostic executable to create a diagnostic f5Report.

Impact

The f5wininfo diagnostic report is incomplete.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the text diagnostic report, the MS Remote Access Diagnostic > Command-Line Utilities section is missing related data.
  • When you view the HTML diagnostic report in the MS Remote Access Diagnostic > Command-Line Utilities section, the links do not reference data.
