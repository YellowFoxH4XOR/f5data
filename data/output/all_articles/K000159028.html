K000159028: TMM goes into restart loop with 'This system does not support "SSSE3"' error on tmm log

Source

Description

TMM keeps restarting in a loop. In /var/log/tmm, you see the error: ‘This system does not support "SSSE3".’

/var/log/tmm:
notice ERROR: This system does not support "SSSE3".
notice Please check that RTE_MACHINE is set correctly.
notice EAL: FATAL: unsupported cpu type.

Environment

BIG-IP VE 17.5.0 or later
xnet-DPDK is being used
Hyper-V

Cause

Starting with BIG-IP version 17.5.0, a change was introduced for BIG-IP Virtual Edition (VE) running on Microsoft Azure and Hyper-V. However, xnet-DPDK driver requires SSSE3 support in the VM.

F5 tracks the issue as ID 1927521.

Recommended Actions

You can switch to 'sock' driver (K10142141) or disable compatibility mode in Hyper-V VM to resolve the issue. See Additional Information section for more detail.

Additional Information

K000153024: xnet-DPDK Driver Default for BIG-IP VE on Azure/Hyper-V from 17.5.0
K10142141: Configure the BIG-IP VE system to use the SOCK network driver
Bug ID 1927521: DPDK has dependency on SSSE3

Configure processor compatibility mode in Hyper-V virtual machines
