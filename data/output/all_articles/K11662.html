Known Issue

Note: This issue does not apply to the ARX 500 because LACP is not supported on the ARX 500 platform.

This is the result of a known issue. There is not a command to manually clear the LACP statistics for a channel.

Running the clear counters channel <#> command will not clear the  LACP statistics.

For example:

# clear counters channel 1

Clear the counters for all of the interfaces associated with channel 1? [yes/no] yes

# show channel 1 lacp stats

LACP Statistics:

S/P       LACP  Packets      Marker Response     Illegal    Unknown

---- ---------- ---------- ---------- ---------- ---------- ----------
2/3  66         65         0          0          0          0
2/4  67         66         0          0          0          0

F5 Product Development is tracking a request to add this functionality as ID 39048.
