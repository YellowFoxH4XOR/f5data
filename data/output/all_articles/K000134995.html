Description

/var directory got full with the following errors:

011d0004:3: Disk partition /var (slot X) has only 0% free

and

Broadcast message from root@BIGIP1.F5LB.com
exception: (Can't create temp directory, /var/system/tmp/tmsh/xxxxx, errno 28] No space left on device) (framework/TempDir.cpp, line 216), exiting...

# df -h

Environment

  • BIG IP
  • /var partition is full

Cause

Bug ID 1045277

Recommended Actions

  1. Check to verify it got multi files (storage*.zip) under /var/config/rest directory:
ls -lstr /var/config/rest
  1. Backup all storage*.zip files to a new temp directory:
# mkdir -v /shared/tmp/rest-storage-backup

# mv /var/config/rest/storage*.zip /shared/tmp/rest-storage-backup
  1. Check again to verify you got free space under /var partition:
df -h

Additional Information

Restart restjavad daemon to make sure it will start fresh:

bigstart restart restjavad
