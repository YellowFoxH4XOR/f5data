Security Advisory Description

The restjavad process may expose a way for attackers to upload arbitrary files on the BIG-IP system, bypassing the authorization system. Resulting error messages may also reveal internal paths of the server. (CVE-2020-5880)

Impact

A remote attacker may be able to fill the disk storage and make the BIG-IP host inoperable.

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by upgrading to a version listed in the Fixes introduced in column. If the table lists only an older version than what you are currently running, or does not list a non-vulnerable version, then no upgrade candidate currently exists.

Mitigation

There is scope for mitigation through employing standard best security practices by limiting access to the Configuration utility to known IP addresses and allowing access to to Configuration utility to trusted users only. For more information, refer to K13092: Overview of securing access to the BIG-IP system.
