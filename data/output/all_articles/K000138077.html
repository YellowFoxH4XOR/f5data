Description

High CPU observed on ASM systems and dosl7 is utilizing the most CPU resources

 

Environment

  • CPU spikes
  • BOT protection profile
  • top output
  • dosl7 
  • control plane

Cause

Device ID is enabled in BOT protection profile.

Recommended Actions

  1. Disable the device ID configuration in BOT protection profile For this, go to the path on configuration utility, SECURITY > Shared Security > Bot Defense > Bot Profiles >Profile > Device ID .
  2. Change it to None to disable Device ID.
  3. Monitor to see if CPU usage goes down

If CPU is still high, please reach out to F5 Support.
