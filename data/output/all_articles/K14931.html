Known Issue

SecurID configuration files fail to synchronize between BIG-IP APM systems.

This issue occurs when all of the following conditions are met:

  • Multiple BIG-IP APM systems are members of a device group.
  • You create a SecurID AAA server on the BIG-IP APM system.
  • You attempt to incrementally synchronize the SecurID configuration files.

Impact

You are unable to synchronize the SecurID configuration files to other devices in the device group.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H442966 on the Diagnostics > Identified > Medium screen.
  • You observe synchronization error messages in the Configuration utility that appear similar to the following example:

    Sync error <target device name>: Load failed from <source device name> 01070712:3: Caught configuration exception (0),
    verify_sync_result:() :Failed to sync files. - sys/validation/FileObject.cpp.
  • You observe error messages in the /var/log/ltm file that appear similar to the following example:

    err mcpd[5507]: 01070712:3: Caught configuration exception (0), verify_sync_result:() :Failed to sync files. - sys/validation/FileObject.cpp, line 6196.

Workaround

To work around this issue, you can perform a full configuration synchronization (ConfigSync) using the Configuration utility. To do so, perform the following procedure:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Overview.
  3. In the Device Groups section, click the name of the device group you want to synchronize.
  4. In the Devices section, click the name of the device from which you want to perform the synchronization action.
  5. From the Sync menu, select the appropriate synchronization action.
  6. To perform a full synchronization, select the Overwrite Configuration check box.
  7. Click Sync.
