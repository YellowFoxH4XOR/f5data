Known Issue

The BIG-IP Virtual Clustered Multiprocessing (vCMP) hypervisor may erroneously log an error message while running the qkview utility. 

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system has vCMP provisioned.
  • The vcmp.installer.use_vdisk_templates system database key is enabled on the BIG-IP platform.
  • The vCMP hypervisor has a virtual disk template present in the system.
  • You attempt to run the qkview utility on the vCMP hypervisor.

Impact

None. This error message can be safely ignored.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/ltm file, you observe an error message with a tag value of 23252 that appears similar to the following example:

    err mcpd[8019]: 0107167d:3: Data publisher not found or not implemented when processing request (unknown request), tag (23252)
