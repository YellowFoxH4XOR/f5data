Known Issue

If a FastHTTP virtual server sends a SYN-ACK packet and the client retransmits the initial SYN packet, the BIG-IP LTM system's retransmission of the SYN-ACK packet will contain the MSS (Maximum Segment Size) in the client's retransmitted SYN, even if the MSS is not supported by FastHTTP. Sending an unsupported MSS results in failure of the TCP handshake to complete.

Note: FastHTTP supports the following MSS values:

  • 1460
  • 1440
  • 1408
  • 1280
  • 1152
  • 1024
  • 896
  • 536

F5 Product Development tracked this issue as CR71597 and CR71762, and it was fixed in BIG-IP LTM 9.1.3, 9.3.0, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM release notes.
