Known Issue

This is the result of a known issue. The BIG-IP self IP address occasionally does not respond to ICMP echo requests. This issue occurs when the BIG-IP self IP address does not receive an ICMP echo request for more than 20 days.

F5 Product Development tracked this issue as CR65177 and CR65178 and it was fixed in BIG-IP 9.3 and 9.4. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller release notes.

Workaround

Important: The following procedure should be run during a maintenance window, as it will cause a system failover if performed on the active unit.

You can work around this issue by restarting all system services. To do so, type the following command from the BIG-IP command line:

bigstart restart
