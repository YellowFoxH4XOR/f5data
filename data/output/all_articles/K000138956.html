K000138956: TCL error: can't read "<variable>": no such variable while executing when variable is created depending on IF statement

Type
Support Solution
Published
2024-03-24
Updated
2024-03-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000138956

Description

After creating iRule which creates variable depending on IF statement, iRule is failing to execute and following error can be seen in var/log/ltm logs:

err tmm[12345]: 01220001:3: TCL error: /Common/<iRule name> <iRule Event> - can't read "<variable name>": no such variable while executing "<my TCL commands>"

 

Environment

  • BIG-IP

  • iRule creating value depending on IF statement

Cause

If variable was not created due to IF statement not being true, for example:

if { [HTTP::header exists X-Forwarded-For ] } {
    set host_forwarded [HTTP::X-Forwarded-For ]
}

and is being referenced later in the iRule without checking if it exists, iRule execution will fail.

Recommended Actions

If value was created under IF statement, make sure to verify if it exists before using it.
