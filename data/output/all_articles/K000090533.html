K000090533: Unable to license NGINX Controller due to ADD license option No present

Type
Support Solution
Published
2021-10-19
Updated
2026-07-30
Source
https://my.f5.com/manage/s/article/K000090533

Description

  • You just installed Nginx controller and accessed the controller from User Interface \[UI\] successfully
  • But upon login onto the UI, you notice the "Upload License" section missing under Controller >> Platform >> License.
  • Nginx Controller is not providing any options to add license from the controller UI

Environment

  • Nginx Controller

Cause

Lack of feature availability usually is a sign of Linux system not meet the minimum resource requirement for Nginx controller

Recommended Actions

Please verify Linux instance where the controller installed has the minimum required resource as stated here, https://docs.nginx.com/nginx-controller/admin-guides/install/nginx-controller-tech-specs/#hardware-specifications..

Additional Information

None
