Description

You are experiencing an issue with OCSP (Online Certificate Status Protocol) Authentication failing. This is indicated by the error message: 'Failure status 'Response Verify Failure'' during the authentication process with a CAC (Common Access Card).

Environment

  • Application Policy Manager (APM)
  • Client Certificate Authentication
  • OCSP Authentication object in use
  • On-Demand Certs Authentication followed by OCSP Authentication

Cause

The error is likely caused by an issue with the OCSP response verification process. This could be due to an incorrect or incomplete certificate bundle configured in the Certificate Authority File of the OCSP Server, which is essential for verifying the OCSP response's signature.

Recommended Actions

Verify the certificate bundle in the OCSP Server configuration. Ensure that the Certificate Authority File is correctly configured and contains all necessary certificates for the OCSP response signature verification. The CA bundle file must contain the complete certificate chain, including the ROOT certificate.

As an alternative, you have the option to disable 'Verify Certificate'. However, this approach is not recommended due to potential security risks.
