K000150779: ARP of virtual address may show different property When Declare Virtual server via AS3

Type
Support Solution
Published
2025-04-29
Updated
2025-04-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150779

Description

When Creating a Wildcard/Subnet-Based virtual server via AS3, the ARP property for the virtual address may behave differently depending on the type of Virtual Server (VS) being configured. 

For Performance Layer 4 VS and Standard VS types, ARP is enabled by default unless explicitly disabled in the declaration. However, for Forwarding IP VS types, ARP is disabled by default even if not explicitly defined in the initial declaration.

Environment

  • BIG-IP
  • AS3

Recommended Actions

To ensure proper configuration of the ARP property when using AS3 for wildcard virtual server. When creating wildcard virtual server with Performance Layer 4 and Standard VS types, ARP must be explicitly declared to disabled for the virtual address.
