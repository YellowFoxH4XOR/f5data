Known Issue

This is the result of a known issue. The BIG-IP system reports that no pool members are available when you use the Traffic Management Shell (tmsh) utility to edit the pool configuration.

Beginning in BIG-IP 10.1.0, you can use the tmsh utility to edit a pool configuration by issuing the edit ltm pool <pool name> command in an interactive tmsh session. This command displays the pool configuration and allows you to edit it in a command line text editor. When you exit the command line text editor, the tmsh utility prompts the following dialog to save changes, regardless of whether any change was made to the configuration:

Save changes? (y/n/e)

If you type y in response to the dialog, and if only the first member in the pool has already been marked down by its assigned node monitor, the BIG-IP system erroneously reports no members are available for the pool by logging a message that appears similar to the following example in the /var/log/ltm file:

local/tmm err tmm[PID]: 01010028:3: No members available for pool <pool name>

For example:

  • Your BIG-IP system contains the following configuration:

    node 10.10.10.43 {}
    node 10.10.10.211 {}
    node 10.10.10.212 {}
    pool myhttp-pool {
    members {
    10.10.10.43:http {}
    10.10.10.211:http {}
    10.10.10.212:http {}
    }
    }
    node * monitor icmp
  • Node 10.10.10.43 has been marked down by node monitor icmp
  • Nodes 10.10.10.211 and 10.10.10.212 are still up
  • The BIG-IP system will log the following message in the /var/log/ltm file:

    local/tmm err tmm[9854]: 01010028:3: No members available for pool myhttp-pool

Additionally, the BIG-IP system generates SNMP traps related to the pool status, and sends them to remote syslog servers, if configured. If sending this trap is an issue, use the Configuration utility to edit the pool.

This issue is cosmetic and does not impact the BIG-IP system traffic processing operations.

F5 Product Development tracked this issue as ID 344650, and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, or WebAccelerator release notes.
