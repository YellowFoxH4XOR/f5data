K000139565: Migrate from Nginx Open Source to Nginx Plus

Type
Support Solution
Published
2024-05-10
Updated
2025-04-02
Applies to
  • NGINX Products
  • NGINX Open Source
  • NGINX Plus
Source
https://my.f5.com/manage/s/article/K000139565

Description

You have an Nginx server with Nginx Open Source installed and want to migrate to Nginx Plus


Environment

  • Nginx Open Source
  • Nginx Plus

Cause

None.


Recommended Actions

1. Check if the platform is supported by Nginx Plus via the Technical Specs

2. Back up the existing Nginx configuration and log files via the commands below

#sudo cp -a /etc/nginx /etc/nginx-plus-backup

#sudo cp -a /var/log/nginx /var/log/nginx-plus-backup

3. Check the Nginx Open Source version via the command below

#nginx -v

Example output:

nginx version: nginx/1.19.0 (Ubuntu)

4. Find the closest corresponding version of the Nginx Plus via the Release Note, as the Nginx Plus is developed based on Nginx Open Source

Example:

NGINX Plus Release 22 (R22)

9 June 2020

Based on NGINX Open Source 1.19.0

5. Uninstall the Nginx Open Source from the platform

6. Install Nginx Plus by following the Installation Guide

7. Check the Nginx Plus status via the command below

#sudo systemctl status nginx

8. Copy/Move all the configuration files to /etc/nginx/conf.d

9. Verify the configuration via the command below

#nginx -t

10. Apply the configuration via the command below

#nginx -s reload


Additional Information

  • Please check for any feature differences between your current version of NGINX and the current NGINX Plus release before migration.
  • NGINX Plus is distributed as a binary with a predetermined set of modules built in (listed in the Technical Specifications), please check if you are using any third‑party modules compiled from the source.
  • Please use Dynamic Modules to load third‑party modules dynamically into NGINX Plus at runtime.
