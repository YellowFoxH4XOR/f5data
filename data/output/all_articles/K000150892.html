K000150892: Microsoft Defender for Cloud reports 'Wacatac' malware detected in BIG-IP VE (APM client ISO)

Type
Support Solution
Published
2025-04-16
Updated
2025-04-16
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000150892

Description

Microsoft Defender for Cloud (agentless scan) could flag apmclients-7221.2022.412.1126-5816.0.iso (or another version of the APM client) located in /usr/apm/images on a BIG-IP VE system as containing Trojan:Linux/Wacatac.A!ml. This detection refers to the APM client ISO used to deliver Edge Client functionality (VPN capability).

Alert Details: 
File Hash (SHA1): d2769c0d08e9c6c0096befd3ee1abf1ba56b013e
File Path: /usr/apm/images

Environment

  • BIG-IP VE running in Microsoft Azure
  • APM provisioned
  • Microsoft Defender for Cloud with agentless malware scanning enabled

Cause

False-positive detection by Microsoft Defender. The apmclients-*.iso files are legitimate system files used to distribute F5 VPN client software. This detection has occurred before in similar environments and was confirmed to be a false alert.

Recommended Actions

To confirm this is a false positive:

1 Download the same ISO file directly from MyF5 Downloads (in this example - apmclients-7221.2022.412.1126-5816.0.iso). Generate a checksum of the downloaded file:

Linux:

md5sum apmclients-7221.2022.412.1126-5816.0.iso

Windows (CMD):

certutil -hashfile apmclients-7221.2022.412.1126-5816.0.iso MD5

2 Compare it with the checksum of the file on the BIG-IP device:

md5sum /usr/apm/images/apmclients-7221.2022.412.1126-5816.0.iso

If the checksums match, this is a legitimate, unmodified ISO. No action is required.

If the checksums do not match, consider following https://my.f5.com/manage/s/article/K11438344 and, if needed, please open a support case and provide both files and checksums for further analysis.
