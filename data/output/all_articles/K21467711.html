Known Issue

Virtual server Datagram Transport Layer Security (DTLS) records may be corrupted.

This issue occurs when all of the following conditions are met:

  • You create a virtual server to process DTLS traffic.
  • You modify the default setting of the system database variable tmm.ssl.dtlsmaxcrs (the default is 1).
  • The virtual server processes the DTLS traffic.

Impact

DTLS connection performance is degraded.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you analyze the DTLS records that the virtual server sends, you notice that the records are corrupted.

Workaround

To work around this issue, you can change the system database variable tmm.ssl.dtlsmaxcrs back to the default value of 1. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To set the system database variable tmm.ssl.dtlsmaxcrs value to 1, type the following command:

    modify /sys db tmm.ssl.dtlsmaxcrs value 1

  3. To exit tmsh, type the following command:

    quit
