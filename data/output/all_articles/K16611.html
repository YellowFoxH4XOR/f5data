K16611: The VMware View logon page for RADIUS does not display all RADIUS challenge messages

Topic

You can configure the BIG-IP APM VMware View logon page to display RADIUS RSA authentication challenge messages on VMware View Clients.
However, when receiving the challenge string to enter the new token code, some versions of VMware View Client fail to correctly parse the challenge string. The message is not properly presented to the authenticating user.

As a result, RADIUS challenges that are sent to users (as with a new token) incorrectly contain three of the same challenge message, instead of three steps with different challenge messages.

Recommendations

As an alternative to RADIUS RSA authentication, you can use the native RSA SecurID authentication method.
