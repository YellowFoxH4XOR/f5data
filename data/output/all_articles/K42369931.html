Description
When checking the contents of a UCS file, you notice that there are some files that are constantly growing. The files have the .fdt extension. You would like to remove the files from the UCS, or, at least reduce their size.

Environment

  • BIG-IP.
  • UCS Backup files.
  • Elastic Search files.

Cause
None, it works as designed.
fdt files store the Elasticsearch indices data.

Recommended Actions

None. The fdt files must not be deleted, otherwise, the Elastic Search processes will present data inconsistencies. 

Additional Information
None.
