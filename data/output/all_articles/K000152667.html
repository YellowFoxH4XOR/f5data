Description

On BIG-IP LTM systems, attempts to restrict REST API access for certificate management to specific non-admin users via TACACS+ role mapping are unsuccessful. Only users with the 'admin' role are able to perform certificate management tasks through the REST API. Assigning roles such as 'certificate-manager' or other non-admin roles does not grant the necessary REST API permissions for these operations.

Environment

  • BIG-IP LTM
  • Features: REST API, TACACS+ remote authentication, role-based access control

Cause

Current product limitation: BIG-IP does not support fine-grained REST API permissions for non-admin users. Only the 'admin' role provides full REST API access, including certificate management. Non-admin roles, such as 'certificate-manager', are limited in their REST API capabilities and cannot perform certificate management tasks via the API.

Recommended Actions

  • To enable REST API access for certificate management, assign the admin role to the user.
  • If REST API access needs to be restricted by source IP address, use management interface firewall rules to control access at the network level. This method restricts access based on IP address rather than user or role.
  • Monitor F5 release notes and product documentation for future enhancements related to fine-grained REST API permissions for non-admin roles.
