K000148603: Multiple attack signatures that are blocking URL

Type
Support Solution
Published
2024-11-18
Updated
2024-11-18
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148603

Description

You are experiencing an issue where a request is being blocked due to something like an attack signature that you disabled for URL. This blockage is preventing legitimate traffic from passing through as expected. Log messages might indicate that a specific request is being blocked by a security policy.

Environment

  • BIG-IP ASM/AWAF

  • Configured Allowed URLs List with Wildcards

  • Specific security policies in place

  • Attack Signature

Cause

The issue is caused by a mis-ordering of the Wildcard URLs List. The current order is causing conflicts that result in legitimate requests being blocked by the security policy.

Recommended Actions

  1. Review the current order of wildcard entries in the Allowed URLs List.
  2. Go to Security >> Application Security > URLs > Wildcards Order > HTTP URLs.
  3. Select the offending Wildcard URL and move it up to be honored first in the pecking order.
  4. Test the changes to confirm that legitimate requests are no longer being blocked.
  5. If the problem persists, consider reviewing the security policy settings for any additional misconfigurations.

Additional Information

Proper ordering of wildcard URLs is crucial in ensuring that the security policies can accurately distinguish between legitimate and illegitimate traffic. Mis-ordering can lead to unexpected blockages and affect normal traffic flow.

Note: explicit URLs do not apply.
