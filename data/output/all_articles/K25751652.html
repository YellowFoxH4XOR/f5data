Description
In order to view the detail wide ip level load balancing decision log on local log directory

By following procedure listed on K14615: Configuring the BIG-IP DNS system to log wide IP request information, you can generate brief logging as below example:
tmm notice tmm[7284]: 011ae024:5: RESOLVED rrtype = A, wip = www.example.org, LDNS(10.11.16.221) to vs(/Common/LTM_VS1) using /Common/GTM_pool1

If you need to generate more detail wide IP decision logging include Pool Member Traversal, Pool Selection, for troubleshooting or reporting purpose. You can configure log publisher profile and assign it to DNS profile of wide IP

Environment

You must have command line and GUI (Configuration Utility) access to the BIG-IP system.

Cause
By default, the BIG-IP DNS system does not log wide IP request information to the system log files. You can  temporarily enable wide IP request logging so that you can determine how the system processes certain requests.

Recommended Actions

  • Enable Load-Balancing Decision Log of wide IP
  • Create custom log publisher
  • Create custom DNS logging profile
  • Create and enable logging on DNS profile
  • Applying the DNS profile to the listener
 

Enable Load-Balancing Decision Log of wide IP

  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Wide IPs. The wide IP List screen opens.
  3. Click the name of the Wide IP you want to modify.
  4. For the Load-Balancing Decision Log setting, select the check boxes of the options that you want to include in the logs.
  5. Click Finished
Create custom log publisher
  1. Log in to the Configuration utility.
  2. Navigate to System > Logs > Configuration > Log Publishers
  3. Click Create
  4. For the Type setting, select local-syslog
  5. Configure the remaining settings, as you want.
  6. Click Finished.
Create custom DNS logging profile
  1. Log in to the Configuration utility.
  2. Navigate to DNS > Delivery > Profiles > Other > DNS Logging
  3. Click Create. The New DNS Logging Profile screen opens.
  4. Name the profile
  5. Select the log publisher from previous step on Log Publisher
  6. Select other Log Fields as you desire
  7. Click finished
Create and enable logging on DNS profile
  1. Log in to the Configuration utility.
  2. Navigate to DNS > Delivery > Profiles > DNS. The DNS profile list screen opens.
  3. Click Create. The New DNS Profile screen opens.
  4. Name the profile
  5. Select the Custom check box.
  6. Check Logging and choose Enabled on dropdown menu
  7. Select the logging profile you created on previous step
  8. Click Finished
Applying the DNS profile to the listener
  1. Log in to the Configuration utility.
  2. Navigate to DNS > Delivery > Listeners > Listener List
  3. Select the Listener you plan to apply the logging
  4. Select the DNS profile you created on previous step on DNS profile
  5. Click finished
Now you should be able to see the detail logging on /var/log/ltm as below
