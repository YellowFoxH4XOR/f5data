K000130629: Can I upgrade to the latest supported software point release for my legacy platform

Type
Support Solution
Published
2023-01-17
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000130629

Description

  • You are wondering if you can install some newer point release like 15.1.2.1 even if the latest supported maintenance release for your hardware platform is for example 15.1.2 like shown in the software compatibilty matrix.

Environment

  • Legacy hardware

Cause

None

 Recommended Actions

You can install point release successfully even if compatibility matrix says that the latest supported software is maintenance release, for example you can use 15.1.2.1 instead of 15.1.2.


Additional Information

None
