Description

How to display a custom HTML page for HTTP 502 response messages.

Environment

  • NGINX Plus core functionality

Cause

None

Recommended Actions

You can instruct NGINX to catch the specific errors and perform an internal redirect into another location block.

The simplest case could look as below:

server {
    ...
    location / {
        error_page 502 504 = /error/5xx.html;
        proxy_pass http://upstream;
    }
    location /error/ {
        internal;
        root /usr/share/nginx/html;
    }
}

Note: The static file /usr/share/nginx/html/5xx.html should exist on the local filesystem.
