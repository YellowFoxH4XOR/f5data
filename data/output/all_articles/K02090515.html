K02090515: Unable to create end point security checks for antivirus or antimalware with BIG-IP APM

Source

Description

While configuring anti-virus or anti-malware agent within an APM AccessPolicy, you may be prompted with an error message, like this one:

An error 'pSource::parseSource: Error while reading source file : (pSourceMapEntry::setDefinitionFromNode: Error while reading class schema (EDOM::load: Unable to find XML file /var/sam/www/admin/vpe2/private/xml/opswat_v4/windows/Windows_ANTIMALWARE_Support_Chart_4.xml))' has occured on server... Dialogue loading has failed

As a consequence, you cannot:
  • Add an AV Check agent to the APM policy;
  • Update the configuration of any existing AV Check agent.

Environment

  • You're using BIG-IP APM;
  • You are performing client-side checks, such as anti-virus or anti-malware checks, by the help of the EPSEC package;
  • You're editing or creating an AV Check agent with the Visual Policy Editor [VPE]
Cause

This may be due to the following bug: ID741222

Recommended Actions

Suggestion #1: fixing permissions over folders
  • Open an SSH connection to the BIG-IP, and be sure you're connected to BASH;
  • Do:  cd /shared/
  • Do:  chmod 755 apm
Once done, please open again the VPE and perform again - creation, modification, ... - the operation to the "AV Check" agent.

Suggestion #2: Re-deploying internal packages
In case the Suggestion #1 above does not help, we can go ahead with the procedure below:
Impact: F5Networks does recommend performing the procedure below during a maintenance window, to avoid any disruption or unexpected behaviour to the "AV Check" operations while the EPSEC packages are being updated.
  • Open an SSH connection to the BIG-IP, and be sure you're connected to BASH;
  • Do:  cd /usr/apm/images/
  • Do:  ll 
    Note:  Please take note of the file whose name should look like epsec-1.0.0-XXX.0.iso
  • Do : rm -rf /shared/apm /shared/lib/rpm
  • Do:  mkdir /mnt/epsec/_
  • Do:  mount /usr/apm/images/epsec-1.0.0-XXX.0.iso /mnt/epsec/_
    Note: please replace XXX with the 3 digits number you have on your BIG-IP.
  • Do:  /opt/bin/rpm --root /shared --dbpath /lib/rpm -U --oldpackage /mnt/epsec/_/.OESIS/*.rpm
  • Do:  umount /mnt/epsec/_
Once done, please open again the VPE and perform again - creation, modification, ... - the operation to the AV Check agent.
