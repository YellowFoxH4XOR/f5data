Issue

Error Message

015e0002:5: [<pg:slot> <pu:cpu>] Acquired lock on new blob: pktclass<1|2>

In this error message, note the following:

  • <pg:slot> is the slot ID for VIPRION platforms. Add 1 to derive the blade ID. Non-VIPRION platforms are 0.
  • <pu:cpu> is the Traffic Management Microkernel (TMM) instance ID. 
  • <pktclass1|2> is the compiled BIG-IP AFM firewall ruleset ID. The ID is either 1 or 2.

For example:

015e0002:5: [pg:0 pu:0] Acquired lock on new blob: pktclass1
015e0002:5: [pg:0 pu:0] Activated blob: pktclass1
015e0002:5: [pg:0 pu:0] Loaded blob: pktclass1

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The /var/log/tmm file
Description

This message occurs when the following conditions are met:

  • One of the following events has occurred:
    • You either create a new or modify an existing BIG-IP AFM security firewall ruleset.
    • Prior to 13.0.0, the availability status of a virtual server with an associated firewall policy changed. 
  • The Packet Correlation Classification Daemon (pccd) compiles a new firewall ruleset and notifies TMM that the new ruleset is ready for use.

For more information about how BIG-IP AFM compiles ruleset binary large objects (BLOBs), refer to K30605514: Error Message: 015d0000:5: Serializing new blob ().

Impact

There is no impact; this message is informational only.
