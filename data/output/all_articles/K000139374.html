K000139374: Error - BIG-IP Next Central Manager application installation failed

2024-04-23

Applies to

Source
https://my.f5.com/manage/s/article/K000139374

Description

At the Central Manager command line, after running the setup command, going through the wizard and beginning the install process for Central Manager, an error occurs:

[ERROR] BIG-IP Next Central Manager application installation failed

Additional errors may be printed to the screen:

  • Memory cgroup out of memory
  • Killed process <id>

Environment

  • BIG-IP Next Central Manager
  • Deploy Virtual Machine from OVA file

Cause

The Virtual Machine was configured with 16 processors and 32GB of RAM.

Recommended Actions

Configure the Virtual Machine using the recommended CPU and memory settings, and run setup again. The recommended combination for Central Manager is 8 CPU/16 GB RAM or 16 CPU/64 GB RAM.

None
