Known Issue

This is the result of a known issue. The MySQL database creates binary log files, which are stored in the /var/lib/mysql partition, that record transaction events. The system does not remove the log files, and each log file can be up to 1 GB in size. During load testing or times when the unit is busy, these log files can accumulate quickly and consume the /var partition. As a result, the system may become unstable or unable to process traffic.

The binary log files appear similar to the following example:

-rw-rw----    1 mysql    mysql    1073742443 Sep 24 04:02 mysqld-bin.000001
-rw-rw----    1 mysql    mysql    1073744167 Sep 28 01:03 mysqld-bin.000002
-rw-rw----    1 mysql    mysql    1073743133 Oct  1 22:02 mysqld-bin.000003
-rw-rw----    1 mysql    mysql    1073747026 Oct  5 18:03 mysqld-bin.000004

F5 Product Development tracked this issue as CR133800 for BIG-IP ASM and as CR133872 for BIG-IP WebAccelerator, and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP ASM or WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
