K000092654: REST API query for /mgmg/shared/appsvcs/info returns 404 after AS3 RPM installation

Type
Support Solution
Published
2022-11-18
Updated
2022-11-28
Source
https://my.f5.com/manage/s/article/K000092654

Description

After installing AS3 appsvcs RPM and trying to verify the installation, querying REST API /mgmt/shared/appsvcs/info returns a 404.

 

Inspecting /var/log/restnoded/restnoded.log would show errors similar to the following after restnoded restarts:

 

info: starting /shared/appsvcs
 

warning: [appsvcs] {"message":"AS3 version: 3.41.0","level":"warning"}

severe: [appsvcs] {"message":"Failed to complete startup. SyntaxError: Unexpected token a in JSON at position 6\n at JSON.parse (<anonymous>)\n at outputToObject (/var/config/rest/iapps/f5-appsvcs/node_modules/@f5devcentral/atg-storage/src/storageDataGroup.js:162:17)\n


severe: [RestWorker] [RestWorker] worker failed to load state: [object Object]:shared/appsvcs


The error occurs when 'list-all-properties' is enabled in the cli preference of the BIG-IP, resulting in unexpected key/value pairs when install script parses ltm data-group appsvcs/settings.

 

Environment

  • BIG-IP
  • AS3

 

Cause

There are unexpected key/value pairs in the output of the command list ltm data-group internal appsvcs/settings. This issue is being tracked by bug ID 1195349.

 

Recommended Actions

 

Workaround is to disable list-all-properties from the cli preference and restart restnoded.

 

tmsh modify cli preference list-all-properties disabled

tmsh save sys config

bigstart restart restnoded
 

Additional Information

None.
