Known Issue

Removing an attack signature may not automatically apply to the active policy.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM security policy is configured with multiple attack signature sets.
  • At least one of the attack signature sets is a manual user-defined signature set.
  • The Auto Apply New Signatures Configuration After Edit option is enabled.
  • You remove an attack signature from the signature list from one of the manual signature sets.

Impact

The signature list change is not applied to the active security policy.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM security policy continues to mark matching content of the removed signature as a violation.
  • Reviewing the Attack Signatures list for the security policy does not list the removed signature.
  • Unassigning and reassigning the manual signature set to the affected policy corrects the enforced policy behavior.

Workaround

To work around this issue, you can remove and reassign the manual signature set to the affected security policy.

Impact of workaround: The attack signature set will not be enforced while unassigned from the security policy.
