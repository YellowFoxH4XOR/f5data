Description

When you are trying to configure an OAuth Client / Resource Server Type ping.

  • You are able to create the Provider Object
  • When you try to create the OAuth Server Object, the Type of Ping is missing, so you can't select the Provider Object that you created

Environment

  • APM Provisioned
  • BIG-IP Versions 16.1.0+, 15.1.3+, 14.1.4+

Cause

This is caused by Bug ID 1022877: Ping missing from list of Types for OAuth Client

Recommended Actions

Use tmsh to create the configuration, e.g.:

tmsh create apm aaa oauth-server <server name> provider-name Ping dns-resolver-name <dns-resolver-name>

Once the OAuth-Server Object has been created, you can then modify it in the GUI.
