Known Issue

The http-explicit profile's Explicit Proxy feature may fail to use the non-default route domain setting.

This issue occurs when all of the following conditions are met:

  • The virtual server uses an http-explicit profile (HTTP profile with the Proxy Mode setting configured to Explicit).
  • The Explicit Proxy section of the http-explicit profile is configured with a non-default route domain and a DNS resolver.
  • A proxy request's target IP address is obtained through a DNS resolution.
  • The target IP address resides in a non-default route domain.

Note: The route domain with an ID of 0 (zero) signifies the default route domain.

Impact

The BIG-IP system fails to forward HTTP Explicit proxy requests to the target IP address.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to forward HTTP proxy requests to the target IP address.
  • The BIG-IP system logs error messages to the /var/log/ltm log file that appear similar to the following example:

    ..
    err tmm1[10779]: 01230140:3: RST sent from 10.10.10.1:8080 to 10.10.10.101:50169, [0x19f607a:12936] no secondary virtual found
    err tmm2[10779]: 01230140:3: RST sent from 10.10.10.1:8080 to 10.10.10.101:50170, [0x19f607a:12936] no secondary virtual found
    ..
