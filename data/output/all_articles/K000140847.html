Description

You are running into the following error when running an Ansible playbook:


Failed to import the required Python library (packaging) on <device_hostname> Python. Please read the module documentation and install it in the appropriate location. If the required library is installed, but Ansible is using the wrong Python interpreter, please consult the documentation on ansible_python_interpreter


Environment

BIG-IP

Ansible

Python

Cause

The Python interpreter has not been properly setup within the environment the Ansible playbook is being tested from.

Recommended Actions

As a workaround, you can manually set the Python interpreter when running the playbook. Example:


ansible-playbook sample-playbook.yml -e 'ansible_python_interpreter=/usr/bin/python3'
