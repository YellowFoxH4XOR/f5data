Known Issue

The BIG-IP system generates host IPv6 traffic even when you set the bigdb variable, ipv6.enabled, to false.

This issue occurs when the following condition is met:

  • You set the system bigdb variable, ipv6.enabled, to false.

Impact

The BIG-IP system produces extraneous IPv6 traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You may observe IPv6 traffic from the BIG-IP system, even when you set ipv6.enabled to false.
