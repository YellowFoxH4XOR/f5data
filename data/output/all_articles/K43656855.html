Description

You may need to retrieve the UUID of a BIG-IP with the REST API or CLI to implement automated operations.

Environment

  • BIG-IP
  • REST API
  • CLI

Cause

None

Recommended Actions

REST API

Use the following REST API call syntax to retrieve the UUID:
curl -sku <username>:<password> https://<BIG-IP Management IP>/mgmt/shared/device-availability | jq .

The output is in JSON format, which will appear similar to the following:
{
  "deviceAvailability": {
    "2527ff8a-9ec4-4b66-ac2d-340e34dd349e": true <====== UUID
  },
  "refreshIntervalMillis": 20000,
  "pingTimeoutMillis": 15000,
  "isAutomaticRefreshEnabled": true,
  "generation": 4,
  "lastUpdateMicros": 1641334344538023,
  "kind": "shared:device-availability:deviceavailabilityrefreshstate",
  "selfLink": "https://localhost/mgmt/shared/device-availability"
}

BIG-IP CLI

Use the following command to retrieve the UUID:
cat /config/f5-rest-device-id
