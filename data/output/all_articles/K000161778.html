K000161778: Higher number of L7 DoS logs in remote syslog server compared to local logs shown in UI for the same time-frame.

Description

BIG-IP L7 DoS logging can show fewer logs in Security ›› Event Logs ›› DoS ›› Application Events than the number of logs received by a remote syslog or SIEM server. The local database summarizes attacks, while HSL sends periodic progress and mitigation messages.

Environment

  • BIG-IP ASM
  • L7 DoS protection profile attached to a virtual server
  • DoS security logging configured for:
    • Local database logging
    • Remote High-Speed Logging (HSL)

Cause

This is expected BIG-IP L7 DoS logging behavior. The local database records summarized DoS activity, such as:

  • Attack started
  • Attack sampled
  • Attack stopped

HSL forwards detailed and periodic attack-progress information. The remote log volume can increase based on:

  • Attack duration
  • Number of participating source IP addresses
  • Attack state changes
  • Mitigation or attack-progress updates

Multiple remote messages can therefore correspond to a single attack ID represented by a summarized event in the local database.

Recommended Actions

  1. Group or correlate remote DoS events by the field, which contains the attack ID.
  2. Count unique attack IDs instead of total syslog messages when comparing remote activity with the BIG-IP local event log.

Additional Information

  • A high number of HSL messages does not necessarily indicate the same number of unique attacks.
  • Local logging provides summarized event visibility, while HSL provides detailed information for external analysis.
  • Correlate remote SIEM events by attack ID before comparing event counts with the BIG-IP local event log.
