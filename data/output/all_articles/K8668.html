Known Issue

The NameSurfer application no longer works after applying the BIND 9.3.4 HF to a 3DNS running version 4.6.4. The upgrade incorrectly changes the directory permissions from named.named to root.wheel. As a result, when using NameSurfer to create a new zone, an error message that appears similar to the following example is reported in the /var/log/messages directory:

named[1302]: zone myzone.com/IN: Transfer started.
named[1302]: transfer of 'myzone.com/IN' from 127.0.0.1#8054: connected using 127.0.0.1#2670
named[1302]: dumping master file: tmp-Yk0oriPH8T: open: permission denied
named[1302]: transfer of 'myzone.com/IN' from 127.0.0.1#8054: failed while receiving responses: permission denied
named[1302]: transfer of 'myzone.com/IN' from 127.0.0.1#8054: end of transfer

You can correct this behavior by performing the following procedure:

  1. Log in to the command line.
  2. Verify the permissions associated with the /var/named/etc directory by typing the following command:

    ls -l /var/named/

    Output will appear similar to the following example:

    Note: If     the permissions are listed as root wheel in the drwxr-x---  3 named  named  512 Apr 17 09:56 etc/ line , proceed to Step 3.

    3.    total 5
       drwxr-xr-x  2 root   named  512 Jun  8  2005 bin/
       drwxr-xr-x  2 root   named  512 Apr 17 09:56 dev/
       drwxr-x---  3 named  named  512 Apr 17 09:56 etc/ 
       drwxr-xr-x  2 root   named  512 Jun  8  2005 sbin/
       drwxrwxrwx  5 named  named  512 Apr 17 09:56 var/

  3. Change the user and group permissions to named for all directories and files under /var/named/etc/, by typing the following command:

    chown -R named:named /var/named/etc

  4. Restart all daemons on the BIG-IP 3-DNS to allow them to restart in order and read the new directory permissions by typing the following command:

    bigstart restart
Once all daemons have restarted, NameSurfer will be able to access the zone files located in the /var/named directory, allowing updates and new zone files to be written.
