Known Issue

This is the result of a known issue. BIG-IP version 10.x hotfix installation files are now ISO archive files and are installed using the bigpipe software command or the image2disk command for partitioned systems.

Note: Managing BIG-IP hotfixes has changed in BIG-IP version 10.x.
If you attempt to install a version 10.x hotfix using the im command, the hotfix installs properly but an error message that appears similar to the following example is displayed:

/var/run/grub.conf.orig.11190 is missing.

F5 Product Development tracked this issue as CR117228 and it was fixed in BIG-IP version 10.0.1. For information about upgrading, refer to the BIG-IP LTM, GTM, Link Controller, ASM, PSM, WebAccelerator, or WOM release notes.

Additionally, this issue has been fixed in hotfix-BIGIP-10.0.0-5460.0-HF1 issued for BIG-IP version 10.0.0, for the 10.x software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about installing version 10.x hotfixes on systems with a partitioned disk-formatting scheme, refer to K9819: Installing a BIG-IP version 10.x hotfix on a partitioned system.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
