Description

VMWare Horizon client cannot access the remote desktop, get the error:

Connection Failed
Error: HTTP error 500

Check the APM log:

debug vdi[<PID>]: 019cffff:7: /Common/vdi_policy:Common:1234abcd: {50.C} Connecting to /Common/vdi_policy-vmware_view_pool_phase2, SSL enabled rtdom 0
debug tmm1[<PID>]: 019cffff:7: /Common/vdi_policy:Common:00000000: RD: [S] 172.31.100.100.443 i 172.30.100.100.12345: server-side connection was reset, reason: TCP retransmit timeout
debug vdi[<PID>]: 019cffff:7: (null)::1234abcd: {50.S} TMEVT_ERROR
notice vdi[<PID>]: 019cffff:5: (null)::1234abcd: {50.S} Operation '' failed, error: 'unspecified'
notice vdi[<PID>]: 019cffff:5: (null)::1234abcd: {50.S} Error reported for an outgoing connection
err vdi[<PID>]: 019cffff:3: (null)::1234abcd: {50.S} Failed to handle View request: system:111: Connection refused

Note: Set the VDI log level to debug, will get the debug log above.

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • vdi profile
  • VMWare View remote desktop
  • VMWare Horizon client

Cause

Network enviroment issue, BIG-IP create the TCP connection from 172.30.100.100.12345 to 172.31.100.100.443, failed.

Recommended Actions

Make sure the BIG-IP can create the TCP connection to the VMWare server. The possible solution:

  • Change the SNAT setting on the virtual server.
  • Fix the route issue between BIG-IP and the VMWare server.
  • On the firewall, allow the connection between BIG-IP and VMWare server

Additional Information

Run tcpdump to capture the packet on BIG-IP, will get the failed TCP connection.
