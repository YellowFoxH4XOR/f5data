K000149635: The zrd process exits upon the ' journal format not recognized. zone example.com/IN: journal rollforward failed' error message

Type
Support Solution
Published
2025-02-12
Updated
2025-02-26
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.1.3, 15.1.9
Source
https://my.f5.com/manage/s/article/K000149635

Description

zrd process repeats restart due to following error in /var/log/daemon.log

named[28030]: 17-Jan-2025 01:26:46.558 general: error: db.external.example.com..jnl: journal format not recognized
named[28030]: 17-Jan-2025 01:26:46.558 general: error: zone example.com/IN/external: journal rollforward failed: unexpected error
named[28030]: 17-Jan-2025 01:26:46.558 general: error: zone examle.com/IN/external: not loaded due to errors.

 

Environment

  • Major version upgrade
    For example, BIG-IP DNS 16.1.3.5 upgrade from DNS 15.1.9
  • ZoneRunner

Cause

BIG-IP DNS upgrade from 15.1.9 to 16.1.3.5 resulted in the BIND version downgrade that caused to the 'jounal format not recognized' error.

 

Recommended Actions

Before upgrade, check if BIND version in the upgrade target BIG-IP version is greater than the version of BIND version on the current BIG-IP version.

Or

After upgrade, delete all zone journal files.

To manually delete the zone journal files from a BIG-IP DNS system, perform the following procedure on each system in the sync group:

Impact of procedure: This procedure restarts the named service which may affect the BIG-IP system's ability to respond to DNS queries. F5 recommends that you perform this procedure during a scheduled maintenance period.

  1. Log in to the affected BIG-IP system command line.
  2. Stop the zrd process by entering the following command:
    tmsh stop /sys service zrd
  3. Stop the named process by entering the following command:
    tmsh stop /sys service named
  4. Delete the journal files corresponding to the affected zones by using the following command syntax:
    rm /var/named/config/namedb/<zone>.jnl
    In this command, note the following:
    <zone> is the name of the affected zone.
    Important: You must remove the affected journal files from all of the BIG-IP DNS systems in the sync group before restarting the zrd and BIND processes on any system in the sync group. Configuring the BIG-IP DNS sync group to synchronize DNS zone files prevents the affected journal files from syncing back after you have deleted the files.
