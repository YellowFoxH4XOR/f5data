Topic

Purpose

You should consider using this procedure under the following condition:

  • You need to generate an HTTP Archive (HAR) file using a browser such as Chrome, Edge, or Firefox to inspect application layer data.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You use one of the following browsers on a Windows or macOS device: Chrome, Edge, Firefox, or Safari (macOS only).

Procedures

To generate a network capture and save it in a HAR file, perform one of the following procedures:

  • Generate a network capture using Chrome
  • Generate a network capture using Edge
  • Generate a network capture using Firefox
  • Generate a network capture using Safari

Generate a network capture using Chrome

  1. In the Chrome address bar, enter the following:

    about:blank

  2. Select the Enter key.
  3. Select Ctrl + Shift + i in Windows or Command + Option + c in macOS to open DevTools.
  4. Select the Network tab.
  5. In the upper-left of DevTools, locate the Record network log icon, which is a red circle. If the icon is not red, select it to initiate recording.
  6. Select the Preserve Log check box to ensure you capture all requests.
  7. Leave DevTools open, enter your URL in the address bar, and then select the Enter key.

    The URL loads.

  8. Reproduce the issue.
  9. In DevTools, select the Stop recording network log icon.
  10. Select Export HAR (sanitized)..., and then save the HAR file to your computer.

Notes:

  • To view the HAR file, drag the file to the Network tab in DevTools (if you have Chrome 62 or later) or use a third-party utility such as HAR Viewer.
  • This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

Generate a network capture using Edge

  1. In the Edge address bar, enter the following:

    about:blank

  2. Select the Enter key.
  3. Select Ctrl-Shift-I in Windows or Command + Option + c in macOS to open DevTools.
  4. Select the Network tab.
  5. In the upper-left of DevTools, locate the Record network log icon, which is a red circle. If the icon is not red, select it to initiate recording.
  6. Select Start Recording.
  7. Select the Preserve Log check box to ensure you capture all requests.
  8. Leave DevTools open, enter your URL in the address bar, and then select the Enter key.
    The URL loads.
  9. Reproduce the issue.
  10. In DevTools, select the Stop recording network log icon.
  11. Select Export HAR (sanitized)..., and then save the HAR file to your computer.

Generate a network capture using Firefox

  1. In the Firefox address bar, enter the following:

    about:blank

  2. Select the Enter key.
  3. Select F12 on Windows or Command + Option + i in macOS to open Firefox Developer Tools.
  4. Select the Network tab.
  5. Select Persist Logs from the Network Settings icon.
  6. Select the stopwatch icon to start the capture.
  7. Leave Firefox Developer Tools open, enter your URL in the address bar, and then select the Enter key.

    The URL loads.

  8. Reproduce the issue.
  9. In Firefox Developer Tools, click Back to pause the capture.
  10. Right-click one of the captured requests, select Save All As HAR, and then save the file to your computer.

Note: The Firefox browser may truncate the body when the request or response is too big. You may need to change the size limit of your browser to save all of content. To do so, perform the following steps:

  1. In the Firefox address bar, enter the following:

about:config

  1. Search for the following settings and change their default values as needed for your application environment:

    • devtools.netmonitor.requestBodyLimit (The default value is 1048576)
    • devtools.netmonitor.response.ui.limit (The default value is 10240)
    • devtools.netmonitor.responseBodyLimit (The default value is 1048576)

Generate a network capture using Safari

  1. In the Safari address bar, enter the following:

    about:blank

  2. Select the Enter key.
  3. Go to Safari > Settings > Advanced.
  4. Select the Show features for web developers check box.
  5. Select Develop > Show Web Inspector.
  6. In the Web Inspector, select the Network tab.
  7. Leave the Web Inspector open, enter your URL in the address bar, and then select the Enter key.

    The URL loads.

  8. Reproduce the issue.
  9. In the Web Inspector, select Export and save the file to your computer.
