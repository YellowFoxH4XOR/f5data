Description

The BIG-IP APM Network Access feature Integrated IP filtering engine can be enabled within the Configuration utility under: 
Access > Connectivity/VPN > Network Access (VPN) > Network Access Lists > [Network Access object] > Network Settings tab. 

This feature implements IPv4 and IPv6 filter rules when BIG-IP APM Network Access tunnels are running. The rules are implemented to a kernel level rule-based ip filtering engine/driver that F5 refers to as Stonewall. The Stonewall driver intercepts data flow between the system's TCP/IP stack and NIC. Stonewall prevents data flows from BIG-IP Network Access tunnels to devices on users' LAN and prevents data flows from devices on users' LAN to BIG-IP Network Access tunnels. Stonewall rules can only be viewed and modified by F5 developers via internal code.

When Integrated IP filtering engine is enabled the following table explains the Stonewall driver rules that get implemented inline with the BIG-IP Network Access settings that get implemented:
 

Network Access SettingsStonewall Driver Rules
AnyAllow IPv4 & IPv6 traffic for the following:
  • The loopback interface on the client system.
  • TCP traffic between any IP address on the client system via its corresponding interface and the BIG-IP APM virtual server IP address and port, e.g. 443.
Use split tunneling for traffic:
  • IPV4/IPV6 LAN Address Space
Allow any traffic to and from the specified LAN address space via the BIG-IP APM Network Access tunnel's PPP interface.
  • IPV4/IPV6 Exclude Address Space
Allow any traffic to and from the specified LAN address space via the corresponding interfaces of the client system.
Allow access to local DHCP serverAllow DHCP requests and responses for each IP address on each of the client system's network adapter that has DHCP enabled.
DTLSAllow IPv4 UDP traffic between any IP address on the client system via its corresponding interface and the BIG-IP APM virtual server. IP address and port, e.g. 4433.
AnyDeny all other traffic based on the following:
  • Deny all traffic to and from the LAN address space specified within IPV4/IPV6 LAN Address Space via anything other than the BIG-IP.
  • Deny all other traffic to and from the PPP IP via the BIG-IP APM Network Access tunnel's PPP interface.
  • Deny all other traffic from PPP IP to broadcast destination IP address for all interfaces on the client system.
 

Environment

  • Microsoft Windows clients
  • BIG-IP APM Network Access with Integrated IP filtering engine enabled

Cause

This is expected behavior.

Recommended Actions

None

Additional Information

  • The BIG-IP Edge Client feature Always connected mode enables a Stonewall service which prevents Internet access when BIG-IP Edge Client is not connected. This is independent of the BIG-IP APM Network Access Integrated IP filtering engine feature, which is implemented when BIG-IP APM Network Access is connected.
    Note: The Stonewall service for Always connected mode only supports IPv4 traffic filtering.
