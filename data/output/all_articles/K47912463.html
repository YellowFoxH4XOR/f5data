K47912463: On BIG-IQ using API to associate or replace expired SSL Certificate on SSL profile

Applies to

Description

On a BIG-IQ, the API REPLACE_CERT call fails while replacing existing SSL certificate.

Environment

  • Replacing expired SSL certificate in an existing SSL profile
  • API POST with "command": "REPLACE_CERT" to https://{{bigiq_host_dev}}/mgmt/cm/adc-core/tasks/certificate-management/

Cause

Using the incorrect self-link to the existing certificate

Recommended Actions

You can use the following procedure to correct this issue. Use the correct self link to identify the existing certificate.
  1. Start with a managed SSL certificate and key on the BIG-IQ
  2.  Use the BIG-IQ to generate an CSR
  3.  Pass the CSR to certificate authority and get a certificate back
  4.  Upload that certificate to /var/config/rest/downloads/
    Note: ADD_CERT works to make it a managed certificate on the BIG-IQ
  5. Use REPLACE_CERT json command

Additional Information

- Following is the command to replace an existing certificate with another.
Note: Use the correct self link to identify the existing certificate.
==============================================================================
# curl -su admin:<admin password> localhost:8100/cm/adc-core/tasks/certificate-management -X POST -d "{'command':'REPLACE_CERT' , 'filePath' : '<file_path_to_new_cert>' , 'certReference' : { 'link' : '<link_to_where_existing_cert_resides>' } } " | jq .
==============================================================================


- Following is an example:
==============================================================================
# curl -su admin:admin localhost:8100/cm/adc-core/tasks/certificate-management -X POST -d "{'command':'REPLACE_CERT' , 'filePath' : '/var/config/rest/downloads/freshcrtkey.crt' , 'certReference' : { 'link' : 'https://localhost/mgmt/cm/adc-core/working-config/sys/file/ssl-cert/a669a5ee-e8dc-3bcb-8c4e-db4a66fe6e79' } } " | jq .

Note: the value of the task’s id in the response to the POST. Send GET requests to confirm that the status of the task has updated to “FINISHED”.
