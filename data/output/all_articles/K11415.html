Topic

Note: This article applies to the BIG-IP 6900 and 8900 platforms only.

Note: This article discusses mirrored volume sets. For more information, refer to K10856: Hard drive mirroring (RAID) for BIG-IP 10.1.0 through 10.2.4.

BIG-IP 6900 and 8900 systems that ship with 10.1.0 or later feature mirrored volume sets exclusively. On these systems, three mirrored volume sets are created by default:

  • MD1.1
  • MD1.2
  • MD1.3

You cannot install a version prior to 10.1.0 on a mirrored volume set. For example, if you attempt to install BIG-IP 10.0.1 on a mirrored volume set, the installation will fail and the BIG-IP system will log an error message to the /var/log/liveinstall.log file that appears similar to the following example:

Terminal error: Selected product is not compatible with the array volume type.

If you want to install a version prior to 10.1.0 on a BIG-IP 6900 or 8900 system that shipped with 10.1.0 or later, perform one of the following procedures:

Note: If you require running BIG-IP 9.4.x, you must perform the third procedure.

  • Creating a new non-mirrored volume set and installing BIG-IP version 10.0.x
  • Reformatting the BIG-IP system to use non-mirrored volume sets exclusively
  • Reformatting the BIG-IP system to use the partitions disk-formatting scheme
Creating a new non-mirrored volume set and installing BIG-IP version 10.0.x

After completing this procedure, the BIG-IP 6900 or 8900 system will feature both mirrored and non-mirrored volume sets. Such systems are known as hybrid systems. This configuration allows you to run version 10.1.0 or later on a mirrored volume set and version 10.0.x on a non-mirrored volume set on the same BIG-IP system.

Important: Due to a known issue, a non-mirrored volume set cannot coexist with more than one mirrored volume set. Before performing this procedure, ensure that no more than one mirrored volume set exists on the BIG-IP 6900 or 8900 system. If necessary, delete the two inactive mirrored volume sets. For more information, refer to K11414: BIG-IP 6900 and 8900 systems experience a kernel panic following a downgrade to version 10.0.x.

  1. Log in to the Configuration utility.
  2. Navigate to System > Software Management > Volume Management.
  3. Click Create.
  4. Ensure that Single Disk is selected in the Volume Type menu.
  5. Enter a name for the new volume.
     
    For example:

    HD1.1
  6. Click Finished.
  7. Once the BIG-IP system has completed creating the new volume, navigate to System > Software Management > Image List.
  8. If needed, import a BIG-IP 10.0.x ISO image by clicking Import.
  9. Once it is available, click the BIG-IP 10.0.x ISO image in the Available Images list.
  10. Select the newly-created non-mirrored volume set.
  11. Click Install.
  12. In the next screen, click Install again to confirm the operation.
  13. In the next screen, select an auto refresh interval from the drop-down menu.
  14. Click Refresh.

    This step ensures that you have correct knowledge of the installation progress.
  15. Once the installation is complete, you can activate the new installation by navigating to System > Software Management > Boot Locations.
Reformatting the BIG-IP system to use non-mirrored volume sets exclusively

If you do not require mirrored volume sets, you can reformat the BIG-IP 6900 or 8900 system to use non-mirrored volume sets exclusively.

  1. Log in to the Configuration utility.
  2. Navigate to System > Software Management > Volume Management.
  3. Click Create.
  4. Ensure that Single Disk is selected in the Volume Type  menu.
  5. Enter a name for the new volume.
     
    For example:

    HD1.1
  6. Click Finished.
  7. Once the BIG-IP system has completed creating the new volume, navigate to System > Software Management > Image List.
  8. If needed, import a BIG-IP 10.0.x ISO image by clicking Import.
  9. Connect to the BIG-IP system command line.
  10. Change directories to the /shared/images/ directory by entering the following command:

    cd /shared/images/
  11. To reformat the BIG-IP system and install version 10.0.x, enter the following command:

    image2disk --instslot=<single disk slot> --format=volumes --nosaveconfig --noarray <BIG-IP ISO image>

    For example:

    image2disk --instslot=HD1.1 --format=volumes --nosaveconfig --noarray BIGIP-10.0.1.283.0.iso

The BIG-IP system will reboot to carry out the reformat and the installation. Once the installation is complete, the BIG-IP system will feature the following non-mirrored volume sets exclusively:

  • HD1.1
  • HD1.2
  • HD1.3
Reformatting the BIG-IP system to use the partitions disk-formatting scheme

To reformat a BIG-IP system to use the partitions disk-formatting scheme, refer to K9745: Reverting BIG-IP version 10.x LVM disk formatting to the partitions disk format .

Refer to the Important note in the Before you start section of the article. Due to a series of known issues, you need to perform a special procedure to revert a BIG-IP 6900 or 8900 system to the partitions disk-formatting scheme. For further assistance, contact F5 Technical Support.
