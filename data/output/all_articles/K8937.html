Issue

Beginning in BIG-IP 9.3.1, and 9.6.0, the switchboot utility no longer uses the -d flag to display the boot configuration of the grub.conf file. If you use the switchboot -d command on a BIG-IP 9.3.1, or 9.6.1 and later system, you receive the following error message:

Unknown option: d (try -h)

In BIG-IP 9.3.1, and 9.6.1 and later, you must use the grub_default -d command to view the boot configuration information. Output appears similar to the following example:

default=0
timeout=5
serial --unit=0 --speed=19200
terminal serial
title BIG-IP 9.3.1 Build 37.1 - drive hda.1
kernel (hd0,4)/boot/vmlinuz ro root=UUID=08af350e-17ce-46f3-b4f7-c4b3e7fc6956 console=ttyS0,19200 panic=1 mem=384M quiet platform=D62
initrd (hd0,4)/boot/initrd
# TIC_IMAGE_INDEX: 1
# TIC_DISK_SN: STI1P13203273123312


title End User Diagnostics
