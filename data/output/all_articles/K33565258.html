Description

When you restart ASM device, you may find the errors below in /var/log/asm;

01310027:2: ASM subsystem error (send_sync.pl,): $VAR1 = bless( {
01310027:2: ASM subsystem error (update_scanner_site_map.pl,): $VAR1 = bless( {
 

Environment

  • BIG-IP ASM
  • Restart ASM service and/or Reboot the device

Cause

send_sync.pl and update_scanner_map.pl are hourly cron job for ASM.
These are scheduled to run in the beginning of an hour.
If these scripts start running when ASM is not fully up, these scripts may fail and the error messages are logged in /var/log/asm.
 

Recommended Actions

If the error messages are logged once, you can ignore it safely.
Because it means that they are cron jobs next run will be successfully once ASM is fully up.
