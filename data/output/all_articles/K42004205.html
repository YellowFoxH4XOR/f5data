Issue

Error Message

mcpd[<PID>]: 01071321:4: Vlan allowed mismatch found: hypervisor (<Hypervisor VLAN>:<VLAN tag>), guest (<Guest VLAN>:<VLAN tag>) and (<Host VLAN>:<VLAN tag>).

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <Hypervisor VLAN> is the name of the hypervisor VLAN being used.
  • <Guest VLAN> is the name of the guest VLAN being used.
  • <Host VLAN> is the name of the host VLAN being used.
  • <VLAN tag> is the VLAN tag in use by the corresponding VLAN.

For example:

warning mcpd[2966]: 01071321:4: Vlan allowed mismatch found: hypervisor (Test_VLAN:903), guest (/Common/Test_VLAN:-1) and (/external_test/Test_VLAN:903).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file on a VCMP guest
Description

This message occurs when one of the following conditions is met:

  • A VLAN in a vCMP guest matches either the name or tag of a vCMP-host published VLAN. This usually happens when a vCMP-published VLAN is modified in the vCMP guest.
  • A VLAN has a name longer than 24 characters, and the name is the same on the host and the guest. The system truncates the name when it sends it from the host to the guest and displays this log message.

Impact

Traffic may be disrupted on reported VLANs.

Recommended Actions

Ensure that your VLAN configuration is as you expect, and consider modifying your VLAN configuration on either your host or your guest to resolve this error. Support usually recommends making VLAN changes on the vCMP host, which are then published to the vCMP guest in this case.
