Known Issue

The HTTPS monitor may erroneously mark resources down.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP systems use a FIPS module to protect Secure Sockets Layer (SSL) keys.
  • The platform with the FIPS hardware security module (HSM) installed is one of the following:

    • BIG-IP 5000 series
    • BIG-IP 7000 series
    • BIG-IP 10000 series
    • BIG-IP 11000 series
  • Your BIG-IP configuration uses an HTTPS monitor to monitor HTTPS server resources.
  • The HTTPS monitor is configured to use a Client SSL certificate.
  • The HTTPS monitor is configured to use an SSL key that is stored in a FIPS module.

Impact

The BIG-IP system incorrectly marks HTTPS pool members down.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice that the BIG-IP system incorrectly marks an HTTPS pool member down.
  • When using the ssldump utility to view a packet capture file, you notice that the BIG-IP system responds to an HTTPS pool member's certificate request with a FIN packet.
