Known Issue

This is the result of a known issue. On Windows Vista under Protected Workspace, Domino Web Access (DWA) ActiveX control will not install successfully. As a result, if the DWA ActiveX control has not already been installed on the system previously, the ActiveX mode client of DWA will not run inside Protected Workspace.

F5 Product Development tracked this issue as CR116269 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.
