Topic

This article applies to BIG-IP 11.x through 12.x. For information about other versions, refer to the following article:

  • K43300744: Adding BIG-IP LTM to a network with BIG-IP DNS (13.x)

You should consider using this procedure under the following condition:

  • You want to integrate a new BIG-IP LTM system into a network with one or more existing BIG-IP DNS (formerly known as BIG-IP GTM) systems.

Description

You can add BIG-IP LTM systems to a network in which BIG-IP DNS systems are already present. To do so, you must enable communications between the BIG-IP LTM and BIG-IP DNS systems by performing the following procedures on one of the BIG-IP DNS sync group members:

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a network with existing BIG-IP DNS systems operating in a synchronization group (sync group).
  • You have defined the following objects on the BIG-IP DNS systems:
    • One or more data centers
    • A server object to represent the BIG-IP DNS system

Procedures

Defining the BIG-IP LTM system

When you define the BIG-IP LTM system as a BIG-IP DNS server object, you configure settings such as those that the BIG-IP DNS systems will use to communicate with the BIG-IP LTM system. For example, when defining the BIG-IP LTM server object you must specify one or more self IP addresses for the BIG-IP LTM system; doing so allows the DNS sync group members to establish an iQuery session with the BIG-IP LTM device. To define the BIG-IP LTM system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of one of the BIG-IP DNS sync group members.
  2. Navigate to DNS > GSLB > Servers.
  3. Click Create.
  4. In the Name box, type a name for the server.
  5. From the Product list, select BIG-IP System.
  6. In the Address List area, add the appropriate self IP addresses of the BIG-IP LTM system.

    Note: You can add more than one self IP address, depending on how you have configured the BIG-IP DNS and BIG-IP LTM systems to communicate on your network.

  7. From the Data Center list, select the data center where the server resides.
  8. In the Health Monitors area, assign the bigip monitor to the server by moving it from the Available list to the Selected list.
  9. From the Virtual Server Discovery list, choose how you want to add the BIG-IP LTM virtual servers to the system.
  10. From the Link Discovery list, choose how you want to add links to the system.
  11. Click Create.

Running the bigip_add script

The bigip_add script exchanges Secure Sockets Layer (SSL) certificates with the remote BIG-IP LTM system. The bigip_add script appends the local BIG-IP DNS system's SSL certificate to the remote BIG-IP LTM system's list of authorized certificates (located in the /config/big3d/client.crt file). The script then appends the remote BIG-IP system's iQuery SSL certificate to the BIG-IP DNS system's local list of authenticated iQuery SSL certificates (located in the /config/gtm/server.crt file).

Note: You should only need to run the bigip_add script on one of the BIG-IP DNS sync group members. The remaining sync group members will then attempt to connect to the big3d agent on BIG-IP LTM system and copy their certificates to the BIG-IP LTM system. If other sync group members cannot connect to the BIG-IP LTM system's big3d agent, the BIG-IP DNS system in which you ran the bigip_add script will relay the certificates from the other BIG-IP DNS sync group members to the newly added BIG-IP LTM system.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP DNS command line as the root user.
  2. Use the following command syntax:

    bigip_add <BIG-IP_LTM_IP_address>

  3. Repeat step 2 for each device group member in the BIG-IP LTM Sync-Failover device group.
After running the bigip_add script, all DNS sync group members should be able to establish iQuery connections to the BIG-IP LTM system.

Verifying iQuery communication

After you have completed the previous procedures, you can verify iQuery communication between a DNS sync group member and the LTM system by performing the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP DNS command line.
  2. To test an iQuery connection, use the following command syntax:

    iqdump <ip address of LTM>

    For example:

    iqdump 10.10.10.20

    If the iQuery channel is established, iqdump returns XML output that appears similar to the following example:

    iqdump 10.10.10.20

    <!-- Local hostname: lc1.example.com -->
    <!-- Connected to big3d at: ::ffff:10.10.10.10:4353 -->
    <!-- Subscribing to syncgroup: default -->
    <!-- Tue May 6 09:55:43 2014 -->
    <xml_connection>
    <version>11.5.1</version>
    <big3d>big3d Version 11.5.1.0.0.110</big3d>
