Description

This article applies to iControl REST. For iControl SOAP, refer to the following article:

  • K26814434: How to determine if a BIG-IP system is using iControl SOAP

You want to know if the device is using iControl REST for monitoring or automation purposes.

Environment

  • BIG-IP system
  • iControl

Cause

None

Recommended Actions

iControl REST is always in-use and enabled by default on the BIG-IP system. There are two scenarios where iControl is used:

  1. Internally: The BIG-IP system uses iControl when navigating around the Configuration utility, dasbhoards, and so on.
  2. Externally: For monitoring purposes and automation tasks, you can use iControl when your device is managed by BIG-IQ.

You can identify the requests, users and source IP addresses sending requests to the iControl Rest API by revieweing the restjavad-audit.x.log file under the /var/log directory. You can also run the following commands to see the following:

  • Top REST API users:

    grep -i user /var/log/restjavad-audit.0.log | awk '{print $6}' | jq .user | sort | uniq -c | sort -rnk1

  • Top REST API source IP addresses:

    grep -i user /var/log/restjavad-audit.0.log | awk '{print $6}' | jq .from | sort | uniq -c | sort -rnk1

  • Top REST API URIs:

    grep -i user /var/log/restjavad-audit.0.log | awk '{print $6}' | jq .uri | sort | uniq -c | sort -rnk1 | head

Additional Information

Access to the iControl REST API can be limited the same way that you can limit https access. For more information, refer to the following article:
