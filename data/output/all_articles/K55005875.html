K55005875: How to turn off password change in AD Auth component

Type
Support Solution
Published
2021-11-30
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K55005875

Description

You would like to remove the option to change a password when the Active Directory password has expired.

Environment

  • BIG-IP APM
  • AD Auth agent in Access Policy

Cause

This is by design and there is no option to turn it off.

Recommended Actions

As a workaround you should be able to use LDAP Auth against AD and it won't prompt for the password change. A must-change password will result in a failed auth.

Additional Information

This is specific to AD Auth. With AD Query, if 'Prompt user to change password before expiration' is set to none, even if the password is expired, it will not prompt them to reset their password.
