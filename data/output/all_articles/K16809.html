Known Issue

Secure Sockets Layer (SSL) virtual servers that use certificate revocation may cause the Traffic Management Microkernel (TMM) to produce a core file.

This issue occurs when the following condition is met:

  • The Certificate Revocation List (CRL) option is enabled for the Client SSL or Server SSL profile.

Impact

The BIG-IP system may temporarily fail to process traffic, and fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM is terminated with a SIGSEGV signal.
  • The TMM process restarts and produces a core file in the /var/core directory.
