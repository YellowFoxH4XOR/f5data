Description

DNS zones can't be found in ZoneRunner after creating Wide-IPs. 

Environment

  • Recursion set to yes in named.conf

  • ZoneRunner

  • BIG-IP DNS

  • Wide-IP pool contains more than 2 pool members

Cause

Bug ID772185: When recursion is enabled in the BIND configuration, Wide-IP zones are not created in ZoneRunner
NOTE: No public-facing article is available for this bug when creating this article.

Recommended Actions

To workaround this issue, please try below methods.

  1. Set recursion to no, if recursion is not necessary. You can go to DNS ›› Zones : ZoneRunner : named Configuration to modify the configuration.

  2. If recursion is needed, please manually modify named.conf to add the missing zones back following procedures in below two articles

K6963: Managing the BIG-IP BIND configuration file
K7032: Freezing zone files to allow manual update to ZoneRunner-managed zone files
