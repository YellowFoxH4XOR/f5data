K3551: Web Engine Trace yields no data

Topic

In order to perform a productive Web Applications engine trace, you must connect to the user’s session after the user logs on to the FirePass webtop, but before the user launches the Web Application favorite. If the user’s master group is configured for an Intranet Webtop, the FirePass webtop is bypassed and the Web Applications engine trace produces no data.

If you need to perform a Web Applications engine trace for a master group which uses an Intranet Webtop, configure a temporary test master group with a single local test account. Configure a resource group with the Web Application favorite you want to test, then assign that resource group to the master group. Perform a Web Applications engine trace after logging on to the webtop with the test user account. When the troubleshooting is complete, remove the test master group and test user account.

Note: For detailed instructions about performing a Web Applications engine trace, refer to K4879: Overview of the Web Applications engine trace feature.

Note: For more information, refer to K10045: Troubleshooting Portal Access Web Application favorites.
