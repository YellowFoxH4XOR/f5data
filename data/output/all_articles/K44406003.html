Known Issue

The BIG-IP system may fail to return WebAcceleration cached objects for a client request.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a functioning HTTP/2 or SPDY-enabled virtual server.
  • You configure the virtual server with a WebAcceleration profile.
  • HTTP/2 or SPDY clients request objects that are stored in cache.

Impact

When the object is cached, the BIG-IP system returns neither the cached objects nor the original objects for HTTP/2 or SPDY client requests.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the HTTP and TCP protocol communication between the client and the BIG-IP virtual server, the BIG-IP virtual server responds to requests for cached objects with an HTTP/2.0 000, and the BIG-IP virtual server closes the TCP connection.
  • The virtual server fulfills non HTTP/2 or SPDY client requests for cached objects from the cache.
