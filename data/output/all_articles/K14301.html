Topic

Summary

As of Microsoft Server 2008 R2 and 2012, the last access timestamp on files is, by default, disabled; in prior versions, the last access timestamp is, by default, enabled.

Description

Each file and folder on an NTFS volume contains an attribute called Last Access Time. Whenever a file is read, the Last Access Time attribute defines when the file or folder was accessed. The ARX system can use the Last Access Time stamp as a method to identify files for policy actions.

Recommendations

If the last access timestamp information is required for an ARX policy, you need to enable the last access timestamps on the Windows filer.

Note: Enabling last access timestamps on the filer may impact the filer's performance, due to the extra file write requirement per client access.

Important: Unless the last access timestamp is required for the ARX policies, F5 recommends that you leave the feature disabled.

For example, use the following command on the Microsoft Server Command Line Interface:

fsutil behavior set disablelastaccess 0

Note: You must start the Windows filer for changes to take effect.
