Known Issue

The HTTP Explicit Proxy and the SOCKS Proxy do not support AAAA address lookups.

This issue occurs when the following condition is met:

  • The destination URI resolves to an IPv6-only address.

Impact

DNS resolution does not occur, and the system is unable to reach the destination.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The HTTP Explicit Proxy and the SOCKS Proxy do not support IPv6 AAAA DNS lookups; these proxies are limited to IPv4 DNS records.
