Description

After the software upgrade the sync status is flapping between Not All Devices Synced and In Sync. After some time the flapping stops without interaction.

Environment

  • HA pair of BIG-IP devices
  • BIG-IP software upgrade
  • ASM provisioned

Cause

This is the expected behaviour. These datasync device group syncs only happen during the first few hours following the software upgrade or provisioning ASM.

The Not All Devices Synced status should last less than a second, because they are being synced right after.

Recommended Actions

No action is required. The sync status flapping must stop after a few hours following the software upgrade or provisioning the ASM module.

The behaviour does not impact system. 

Additional Information

The datasync device groups are used to sync stats related to the datasync framework, such as the number of versions of obfuscated JavaScript available on each device.
