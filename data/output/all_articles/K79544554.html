Topic

You should consider using this procedure under the following condition:

  • You want to configure one or more attack signatures for a specific parameter that is defined in a security policy.

Description

You can configure the system to detect attack signatures for a specific parameter. You can also override security policy settings to change an attack signature state for a specific parameter. For example, you can disable an attack signature for a specific parameter but leave it enabled for the rest of the security policy. Conversely, you can enable an attack signature for a specific parameter but leave it disabled for the rest of the policy.

Note: Prior to BIG-IP ASM 14.0.0, you can configure attack signatures for parameters of the Alpha-Numeric data type. Starting in BIG-IP ASM 14.0.0, you can configure attack signatures for parameters of the File Upload data type, in addition to parameters of the Alpha-Numeric data type.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility.

Procedures

Configure attack signatures for a specific parameter

To change the state of a specific attack signature for a specific parameter, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Parameters.
  3. In the Current edited policy list, select the security policy containing the parameter that has the attack signature you want to change.
  4. In the Parameters list, select the parameter that has the attack signature you want to change.
  5. Select the Attack Signatures tab.
  6. In the Global Security Policy Settings box, select the attack signature whose state you want to change, and then select <<.

    The attack signature now displays as either Disabled or Enabled in the Overridden Security Policy Settings box.

  7. Select Update.
  8. Select Apply Policy.
