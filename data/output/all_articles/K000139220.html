Description

Vulnerability scanners may report the BIG-IP as vulnerable due to Cipher Block Chaining (CBC) and weak Keys.

CBC is reported to be affected by several vulnerabilities such as (but not limited to) CVE-2008-5161

Older Key Exchange Algorithms (KEX) such as diffie-hellman-group1-sha1 and/or diffie-hellman-group-exchange-sha1 have become insecure over time. MACs with SHA1 are considered weak.

Recommended Actions

You can determine the current Cipher and KEX values using the following commands from the BIG-IP CLI:

 1. For KEX (from bash):               

     ssh -Q kex

 2. For SSH Ciphers (from bash):

     sshd -T | awk '/ciphers/,/banner/ $2 ~ "[a-z]-[a-z]" { print $2}' | sed s'/,/\n/'g

You can configure SSH (aka sshd) to use a desired set of Ciphers and KEX algorithms to meet internal security policy requirements with the following commands:

 1. Access BIG-IP CLI TMOS prompt:

     tmsh

     list /sys sshd all-properties

  • Check the line that starts with the include statement. This will show current config. Copy/paste that config into an editor such as Notepad++. Do not use the any Microsoft product for the copy/paste. Microsoft products will often add hidden characters.
    Note: By default, you will see include none as the TMOS sys sshd configuration does not include a specific set of KEX algorithms for BIG-IP systems.

 2. Add to the configuration these lines at the "include" statement. In most cases, be default, it will show "include none".

     include "Ciphers aes128-ctr,aes192-ctr,aes256-ctr

     MACs hmac-sha2-256,hmac-ripemd160,hmac-ripemd160@openssh.com

     KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384"

It should look something like this after the lines have been added:

sys sshd {
    allow { ALL }
    banner disabled
    banner-text none
    description none
    fips-cipher-version 0
    inactivity-timeout 0
    include "Ciphers aes128-ctr,aes192-ctr,aes256-ctr
     MACs hmac-sha2-256,hmac-ripemd160,hmac-ripemd160@openssh.com
     KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384"
    log-level info
    login enabled
    port 22
}

3. Begin editing the running configuration using this command to open up a type of editor:

     load /sys config from-terminal merge

The output will look something like this:

root@(bigip)(cfg-sync Standalone)(Active)(/Common)(tmos)# load /sys config from-terminal merge
Enter configuration. Press CTRL-D to submit or CTRL-C to cancel.

 4. Copy/paste the updated config from notepad on to CLI.

 5. Press CTRL-D to submit.

 6. Verify the change was made to the running configuration.

     list /sys sshd

     Include part should be updated as shown in step2.

 7. Save the updated running configuration to disk.

     save /sys config

 

To see the Cipher and/or KEX, you can connect from a remote device to the BIG-IP Management Interface using the following command:

ssh -vvv root@<BIG-IP management-ip address>
