Description

LDAP authentication to the configuration utility is failing with similar logs in /var/log/secure

hostname.local notice httpd[9546]: pam_bigip_authz: authenticated user user1 with role 900 ([unknown]) in partition

Environment

Relevant environmental factors specific to the topic

  • Conditions
  • Configuration objects and settings
  • Products and features

Cause

This can be caused by a remote role group being disabled.  An example in bigip.conf:

auth remote-role {
    role-info {
        /Common/AppPerm-Proxy-F5SSLO-HelpDsk {
            attribute member <Example domain attributes. Removed for Public consumption >
            deny enabled    <--------------
            line-order 1003
            role guest
            user-partition All
        }

Recommended Actions

To correct this navigate in the web gui to System -> Users -> Remote Role Group -> <groupname> there is a property called "Remote Access" and change this to "Enabled"
