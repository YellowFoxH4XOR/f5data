Description

After upgrading to 14.1.x or higher version, ConfigSync shows Disconnected and configuration cannot be synchronized between HA devices.

  • VLANs, Self-IP address and Port Lockdown settings are all correct
  • Rebuilt device trust but it didn't solve the problem
     

Environment

  • BIG-IP in HA pair
  • ConfigSync
  • VLAN MTU set to jumbo Ethernet frames such as 9100 bytes
  • Switch MTU set its port to 1500 bytes
     

Cause

In 14.0.0 and prior, device group members use TCP MSS of 1448 bytes for sending data across CMI channel.
Starting in 14.1.0 and later, the TCP MSS is based on VLAN MTU less IP and TCP headers.
For example, if VLAN MTU is 9100, then device will advertise TCP MSS as 9060.
 

Recommended Actions

To configure an existing VLAN on the BIG-IP system to use the supported frame sizes, perform the following procedures:

  1. Log in to the Configuration utility.
  2. Navigate to Network > VLANs.
  3. Click VLAN List.
  4. Click the name of the VLAN used for ConfigSync.
  5. In the MTU box, type the value of the frame size. eg 1500.
  6. Click Update
