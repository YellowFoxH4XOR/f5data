Description

  • You are trying to perform ConfigSync operation between your HA peers of BIG-IP system.
  • In the upper left corner of the screen, when you click on the status of the device group (which is RED with status "Sync Failure") and try to sync HA peers you get an error:

"Sync Failed

A validation error occurred while syncing to a remote device

Sync error on LTM1.example.com: Load failed from /Common/LTM1.example.com 01020036:3: The requested parent profile (/Common/<Parent_Profile>) was not found.

Recommended action: Review the error message and determine corrective action on the device"

  • The system logs a message to the /var/log/ltm file that appears similar to the following example:

'01020036:3: The requested parent profile (/Common/<Parent_Profile>) was not found.'

Environment

  • BIG-IP
  • High Availability
  • ConfigSync operation
  • Parent Profile is missing (HTTP, access etc.)

Cause

Default profile has been modified.

A default profile, which is supplied by the system (such as a Access profile), was modified on the device receiving the synchronization (target device), but not modified on the device initiating the synchronization.

Recommended Actions

To avoid this issue, create a custom profile using the default profile as the parent, and do not modify the default profiles.

To work around this issue, you can manually undo the changes to the default profile on the target device, and then re-attempt the ConfigSync operation from the initiating device. To do so, perform the following actions:

1. On the target device, manually remove the modified profile from the /config/bigip.conf file.

Note: Removing the modified profile from the /config/bigip.conf file will not remove the default profile.

2. Load the configuration on the target device (for example, using the tmsh load /sys config command).

3. Re-attempt the ConfigSync operation (from the initiating device) and choose the option to overwrite the configuration.

None.
