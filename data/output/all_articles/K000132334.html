K000132334: F5 is not able to consume issuer attribute in SAML response

Type
Support Solution
Published
2023-01-30
Updated
2023-01-30
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.2
Source
https://my.f5.com/manage/s/article/K000132334

Description

Users are getting below error whenever they are accessing the service protected by SAML IDP(BIG-IP)

Error:

You do not have permission to access this page.

Access to requested SAML resource is denied .Please try again or contact your system administrator for assistance.

﻿
Below logs can be seen on /var/log/apm

err tmm1[22222]: 014d1237:3: /Common/<Access_Policy_name>:Common:<SessionID>:SAML SSO: Authentication request to (/Common/SAML-Builder) is missing mandatory 'Issuer' element

debug tmm1[22222]: 014d0501:7: /Common/<Access_Policy_name>:Common:<SessionID>:IdP configuration/Common/SAML-Builder does not contain SP connector with Issuer:  0

Environment

BIG-IP APM

BIG-IP as SAML IDP

Cause

Issuer element can be seen in the decrypted (using third party website) SAML request coming from SP. However SP didn't use the Base64 format to encrypt the SAML request.

Recommended Actions

Configure SP to use only Base64 to encrypt the SAML request. BIGIP by default uses Base64 for encryption/decryption.

Additional Information

Please note that SAML requests are encoded/decoded differently for different bindings. As per K51854802 ,

>HTTP Redirect Binding, SAML request is to be first URL decoded and then Base 64 Decoded+Inflated

>POST Binding SAML request is just Base 64 Decoded+Inflated
