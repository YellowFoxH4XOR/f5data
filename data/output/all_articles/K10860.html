Known Issue

This is the result of a known issue. If a Windows Vista client attempts to establish a Network Access connection within protected workspace, the connection may fail with the following error message:

Status: The system could not update the phone book file.

This issue occurs when the following two conditions are met:

  • User Account Control (UAC) is enabled in Windows Vista
  • Protected Mode is disabled for the current Web content zone in Internet Explorer (IE)

    Note: By default, Protected Mode is disabled for the Trusted Sites zone. In FirePass versions 6.0.3 and 6.1.0, users must add the URL of the FirePass controller to the IE Trusted Sites zone in order to enter protected workspace.

F5 Networks Product Development tracked this issue as CR132462 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue has been fixed in cumulative hotfix HF-610-1, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can work around this issue by temporarily enabling Protected Mode for the Web content zone (typically the Trusted Sites zone) to which the FirePass URL is assigned. IE displays the current Web content zone and Protected Mode status in the Status Bar. For example:

Trusted sites | Protected Mode: Off

After successfully establishing a Network Access connection, users can change the Protected Mode setting back to its previously disabled state.

Note: For instructions about enabling and disabling Protected Mode, refer to the Configuring Protected Mode section of the following Microsoft article:

http://msdn.microsoft.com/en-us/library/bb250462%28VS.85%29.aspx
