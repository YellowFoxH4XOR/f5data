Known Issue

This is the result of a known issue. When you create more than one view in the ZoneRunner utility, the Configuration utility will return the following error message if you attempt to click on a View Name option in the ZoneRunner View List:

Error trying to access the database.

Note: This issue does not affect the functionality of views in BIG-IP BIND. You can continue to administer BIG-IP BIND views using the command line. For more information, refer to K6963: Managing the BIG-IP BIND configuration file.

F5 Product Development tracked this issue as ID 247971 (formerly CR139925) and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP GTM release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
