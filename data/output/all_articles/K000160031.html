K000160031: DDM alarm message "Lanes: 1 Receiver power low alarm"

Type
Support Solution
Published
2026-02-17
Updated
2026-02-17
Applies to
  • F5OS
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000160031

Description

When disabling an interface on a device A running F5OS-A v1.5.4 or F5OS-A v1.8.3 and it is connected to a peer device B running version 1.8.3, the peer device B generates a DDM (Digital Diagnostics Monitoring) alarm like below:

"Lanes: 1 Receiver power low alarm"

This alarm appears in the system logs and alarm dashboard with messages similar to:

fpgamgr[16]: priority="Err" version=1.0 msgid=0x304000000000034 msg="DDM low alarm set" PORTGROUP="7" ALARMTYPE="receive power" LANE1=-100.000000

Environment

  • F5OS-A
  • Two F5OS devices connected via optical interfaces
  • At least one device is running F5OS-A v1.8.3 e.g. during an upgrade

Cause

This behavior is expected behavior and doesn't indicate a malfunction.

When an interface is disabled on the device, it stops transmitting optical power. The peer device's transceiver detects that the received optical power has dropped significantly below the programmed low-threshold alarm value. This triggers the DDM alarm "Receiver power low alarm" on the peer device.

Answer/Recommended Actions

No corrective action is required if the interface was intentionally disabled.

The alarm will automatically clear when the interface is re-enabled.

Additional Information

DDM check occurs every 30 seconds by default. The alarms may appear up to 30 seconds after an interface state change.
