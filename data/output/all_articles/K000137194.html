Description

The LCD displaying 'Host inaccessible or in diagnostic mode' along with the management IP address changed to 0.0.0.0.  This can occur when booting up an iSeries BIG-IP system.

See below:

 

Environment

  • iSeries device
  • LCD message
  • Management IP

Cause

The behavior is tracked in bug ID1304849.
 

Recommended Actions

Wait for 5 minutes. If the LCD is still displaying the "Host inaccessible or in diagnostic mode" message after the specified time period, reboot the BIG-IP system.

Impact of the workaround: Rebooting the machine will stop the processes, so perform during a scheduled maintenance window.
