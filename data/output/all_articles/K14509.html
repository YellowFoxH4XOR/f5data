Topic

The BIG-IP system FTP monitor has a fixed timeout period of eight seconds, in which the server must respond to the FTP client connection request.

Description

The BIG-IP system FTP monitor has a fixed timeout period of eight seconds, which is hard coded and cannot be modified. When an FTP server fails to respond within eight seconds to the initial FTP client connection request that the FTP monitor sent, the monitor marks the FTP resource as offline or down.

Recommendations

When configuring an FTP monitor, you should consider verifying that the FTP server's response time is within eight seconds to avoid having the FTP monitor falsely mark the resource offline or unavailable.

If the FTP servers in your environment require more than eight seconds to respond, F5 recommends that you use another type of health monitor, for example Internet Control Message Protocol (ICMP) or TCP.
