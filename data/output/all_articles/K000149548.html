Description

Support for Cilium Gateway API (Gateway Class) with CIS

Environment

  • CIS
  • Cilium Gateway API

Cause

Classic BIG-IP does not have support for K8S Gateway API with CIS

Recommended Actions

K8S Gateway API is not supported in CIS for BIG-IP Classic. 
For current alternatives or workarounds for K8S Gateway API support, please contact F5 Support.

None
