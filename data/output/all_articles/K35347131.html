Description

In the log file /var/log/ltm, find the log like:

warning mcpd[PID]: 01071859:4: Warning generated : /Common/<iRule name>:<row number>: warning: [variable reference used where variable name expected][$<variable name>]

Environment

  • BIG-IP
  • iRule

Cause

Extra $ in the iRule set command.

Recommended Actions

Remove the extra $ in the iRule set command.
For example:

when HTTP_REQUEST {
    set S1 1000
    set $S1 1000
}

Both set command can work, but the 2nd set command will cause the log:

warning mcpd[PID]: 01071859:4: Warning generated : /Common/<iRule name>:3: warning: [variable reference used where variable name expected][$S1]

None.
