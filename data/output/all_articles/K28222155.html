Description

BIG-IP APM portal access users may be able to access more resources than the populated list of applications and links present in their access session.

For example:
BIG-IP APM portal access access session user A and user B. User A's access session populates with two resources www.example.com and abc.othersite.com, and user B's access session populates with only www.example.com. The access session URL presented to user A for abc.othersite.com (example: https://<BIG-IP APM virtual server>/f5-w-<a group of numbers>$$/) can be manually copied and given to user B. User B using the copied URL from user A can now access that resource.
 

Environment

  • BIG-IP APM
  • Portal Access
  • Access session presented applications and Links

Cause

The items of Applications and Links are just quick links and therefore are not designed for the specific user's access session.
 

Recommended Actions

You can configure the access policy to use BIG-IP APM Access Control List (ACL) (these can provide Access Control for IP layers 4 through 7).
For more information on Access Control List refer to: Manual Chapter : Configuring Access Control Lists
