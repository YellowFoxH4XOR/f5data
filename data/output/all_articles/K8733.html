Known Issue

This is the result of a known issue. When zone synchronizing is enabled on a BIG-IP GTM and the named.conf file contains the ^M character, the zone synchronization fails and runs repeatedly. As a result, a memory leak occurs.

Note: The ^M character is the equivalent of a carriage return. The addition of the ^M character typically occurs when converting a file from a DOS format to UNIX format or using a DOS or Microsoft Windows based editing tool.

F5 Product Development tracked this issue as CR97575 and it was fixed in BIG-IP GTM 9.4.4. For information about upgrading, refer to the BIG-IP GTM release notes.
