K000160012: Overview of Default Attack Signatures in NGINX App Protect WAF

Published

Applies to

Source

Description

NGINX App Protect or WAF for NGINX includes a comprehensive set of pre-configured attack signatures by default. The specific signatures included in the base policy.

Environment

  • WAF for NGINX
  • NGINX App Protect
  • Attack signatures 

Cause

None

Answer/Recommended Actions

According to the Attack signatures documentation, the following signature sets are included in the default policy:

Signature Sets with Alarm ON (but Block OFF):

  • Command Execution Signatures
  • Cross Site Scripting Signatures
  • Directory Indexing Signatures
  • Information Leakage Signatures
  • OS Command Injection Signatures
  • Path Traversal Signatures
  • Predictable Resource Location Signatures
  • Remote File Include Signatures
  • SQL Injection Signatures
  • Authentication/Authorization Attack Signatures
  • XML External Entities (XXE) Signatures
  • XPath Injection Signatures
  • Buffer Overflow Signatures
  • Denial of Service Signatures
  • Vulnerability Scan Signatures
  • Server Side Code Injection Signatures
  • CVE Signatures

Signature Sets with BOTH Alarm and Block ON:

  • High Accuracy Signatures - These are set to blocked by default
  • Threat Campaigns - Blocks requests when detected (very low false positive rate)
