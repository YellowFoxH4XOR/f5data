Description

When BIG-IP VE is licensed with FIPS, SIP_monitor instances consume a higher amount of CPU cycles compared to a non-FIPS licensed BIG-IP VE.


Environment

  • BIG-IP VE
  • FIPS 140 license

Cause


Unnecessary triggering of self tests when SIP monitor calls libcrypto.


Recommended Actions


For versions affected by this bug, install an Engineering Hotfix containing the fix for ID1395257.


Additional Information

None.
