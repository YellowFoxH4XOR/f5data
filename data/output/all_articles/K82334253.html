Topic

This article applies to BIG-IP 11.x. For information about other versions, refer to the following article:

  • K13044205: Overview of the FTP profile (12.x - 13.x)
  • K08859735: Overview of the FTP profile (14.x)

This article discusses the FTP profile settings. You can find the FTP profile in the Configuration utility by navigating to Local Traffic > Profiles > Services > FTP.

Description

The FTP profile allows an administrator to specify how a BIG-IP virtual server processes File Transfer Protocol (FTP) traffic. To manage FTP traffic, you can tailor FTP profile settings to your specific needs. For those settings that have default values, you can retain those default settings or modify them. You can modify any settings either when you create the profile, or at any time after you have created it.

Settings and definitions in the FTP profile

General Properties

SettingDefault ValueDescription
Name Specifies the name of the FTP profile.
Parent ProfileftpSpecifies the profile from which this profile inherits settings. The default is the system-supplied ftp profile.

Settings

SettingDefault ValueDescription
Translate ExtendedEnabledSpecifies, when selected (enabled), that the system uses ensures compatibility between IP version 4 and IP version 6 clients and servers when using the FTP protocol. The default is selected (enabled).
Inherit Parent Profile1DisabledSpecifies, when selected (enabled), that the FTP data channel inherits the TCP profile used by the control channel. If disabled, the data channel uses FastL4 connections only. The default is cleared (disabled).
Data Port20Allows you to configure the FTP service to run on an alternate port. The default is 20.
Protocol SecurityDisabledSpecifies, when selected (enabled), that the system inspects FTP traffic for security vulnerabilities, by using an FTP security profile. This option is available only on systems licensed for ASM.

1The Inherit Parent Profile setting was introduced in 11.1.0. For versions prior to 11.1.0, the BIG-IP system does not support full proxy connections for the FTP data channel. The ephemeral flows that the BIG-IP system creates for the data channel are always FastL4 connections, and their settings are not configurable. 

Recommendations

The BIG-IP system allows you to modify the default FTP base profile. However, F5 recommends that instead of modifying a default profile, you create a custom profile using the default profile as the parent profile. You can then modify some or all of the values defined in the custom profile, while leaving the parent profile settings at their default value. For information, refer to K14488: Working with profiles.
