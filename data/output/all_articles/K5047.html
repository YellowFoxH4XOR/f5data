Issue

The following error message indicates that you have configured a gateway health check with a timeout value that is shorter than the health check interval. Because the timeout is shorter than the interval, gateway failsafe may trigger even if the gateway is available.

timeout value for gateway pinger less than interval

To resolve this issue, correct the gateway failsafe settings so that the timeout value is longer than the health check interval.

This error message was introduced in BIG-IP versions 4.5.13 and 4.6.3. No warning is provided in prior versions.
