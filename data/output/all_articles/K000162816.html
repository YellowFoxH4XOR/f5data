K000162816: RDP Tunnel Teardown Following AsyncError:1: SuppliedUnexpectedAny VDI requested abort (plugin abort error)

Type
Support Solution
Published
2026-08-06
Updated
2026-08-06
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000162816

Description

Intermittent RDP sessions through BIG-IP APM terminated when the VDI HTTP state machine encountered an invalid server-side HTTP message, generating AsyncError:1: SuppliedUnexpectedAny, server-side connection was reset, reason: Internal error, and VDI requested abort (plugin abort error).

Environment

RDP access

Cause

The RDP server/backend generated a non-compliant HTTP request without a Content-Length header. This caused the BIG-IP APM VDI HTTP state machine to enter an invalid state and report SuppliedUnexpectedAny. Since RDP data is carried inside the HTTP request/response bodies, the existing tunnel could not safely continue after message framing was lost. The VDI plugin therefore terminated the channel and initiated a new connection, which caused the original RDP session to end.

Answer/Recommended Actions

Correct the RDP server/backend or its HTTP-generating component so that requests include a valid Content-Length header or use compliant chunked transfer encoding.

Engage the RDP server vendor or backend team to investigate the malformed HTTP requests.

Additional Information

None.
