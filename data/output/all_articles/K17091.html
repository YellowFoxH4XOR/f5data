Known Issue

The Traffic Management Microkernel (TMM) may restart when you use an Adapt profile and a OneConnect profile on a single virtual server.

The BIG-IP system may prevent users from creating virtual servers with Request Adapt or Response Adapt, and OneConnect profiles, by displaying an error message similar to the following example:

01070095:3: Virtual server /Common/example_virtual lists incompatible profiles.

However, adding a Client SSL or Server SSL profile overrides the warning, and allows the configuration to occur.

This issue occurs when all of the following conditions are met:

  • You create a virtual server by using the Configuration utility or the Traffic Management Shell (tmsh).
  • The profiles applied to the virtual server include all of the following types:

    • Request Adapt and/or Response Adapt
    • Client SSL and/or Server SSL
    • OneConnect
    • HTTP
    • TCP

Impact

TMM restarts and temporarily fails to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.
