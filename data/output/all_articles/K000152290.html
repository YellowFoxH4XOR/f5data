K000152290: After upgrading to 16.1.0 or later, only up to 10 GTM listener objects are displayed on GUI GTM/DNS listener statistics page.

Type
Support Solution
Published
2025-07-01
Updated
2025-07-01
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.1.0, 16.1.2, 16.1.1, 17.1.X, 17.5.X, 16.1.X, 17.5.1, 17.5.0, 17.1.2, 17.1.1, 17.1.0, 16.1.6, 16.1.5, 16.1.4, 16.1.3
Source
https://my.f5.com/manage/s/article/K000152290

Description

If there is more than 10 GTM/DNS listener objects, only 10 listener objects can be displayed at "Statistics >> Module Statistics : DNS : Delivery >> GTM Listeners" GUI Module Statistics page.

On the following example configuration, 15 GTM/DNS listener objects are configured. 

Figure: listener configuration page

 

However, GUI displays only first 10 GTM/DNS listener objects even though "Show All" option is set at bottom right drop-down list. Pagination is not working.

Figure: v17.x listener statistics page

 

This problem does not occur before upgrading from v15.1.x. On v15.1.x, all 15 GTM/DNS listener objects were correctly displayed on GUI.

Figure: v15.x listener statistics page

 

Setting "ui.system.preferences.recordsperscreen" db key to larger value (default 10) does not resolve this problem.

 

Environment

More than 10 GTM/DNS listener objects are configured on BIG-IP DNS.

 

 

Cause

Bug ID 1352293.
