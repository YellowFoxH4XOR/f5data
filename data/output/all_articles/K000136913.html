Description

  • You have a APM system provisioned with Network Access.
  • You wish to determine the VPN Client Type. Is it a browser or Edge Client?


Environment

APM system with Network Access.


If the client starts a Network Access (VPN) session by clicking on the Network Access object on the webtop, then the Session log will contain, for example:


Received client info - Hostname: Type: Mozilla Version: 5 Platform: Win10


Note that the value of "Hostname" is not populated.

If you look in the Configuration Utility for Access  ››  Overview : Access Reports, the Right hand Column is for "Client Host Name".

If that is blank, it is a browser.



If the client is an Edge Client, the log is:


Received client info - Hostname: WIN10-64 Type: Standalone Version: 2.0


Sets the "Hostname" and "Type" is "Standalone". The Hostname is visible on the Access Report as "Client Host Name".

By Design
