Known Issue

When you use the Informational log level, the system logs heartbeat check messages for the clusterd process.

This issue occurs when the following condition is met:

  • You modify the configuration of the clusterd log level from the default level of Notice to the level of Informational.

Impact

You can safely ignore this issue. In the /var/log/ltm log file, the system logs the clusterd heartbeat messages at the Informational level.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system reports clusterd heartbeat check messages at the Informational log level, similar to the following example:

    -- info clusterd[6161]: 013a0007:6: Skipping heartbeat check on peer slot 3: Slot is DOWN.
    -- info clusterd[5705]: 013a0007:6: Checking heartbeat of peer slot: 2 (Last heartbeat 0 seconds ago)
