Known Issue

This is the result of a known issue. The session iRule command uses the persistence table to store user's data under a specified key for a specified persistence mode.

When using the session command in an iRule, the BIG-IP system generates an error message. For example, the following iRule stores the user's data (abc), under a specified key (123) for the specified persistence mode (uie):

when HTTP_REQUEST {
            session add uie 123 abc 600
}

When you configure and load the previous iRule from the Configuration utility or the command line, the system logs an error message to the /var/log/ltm file that appears similar to the following example:

Rule [session] error:  line 2: [undefined procedure: session] [session add uie 123 abc 600]

F5 Product Development tracked this issue as CR88446 and it was fixed in BIG-IP LTM 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue still exists in the BIG-IP LTM 9.6.x software branch.
