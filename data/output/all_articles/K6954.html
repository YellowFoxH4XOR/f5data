Known Issue

This is the result of a known issue. If you attempt to create or delete a group-based packet filter rule on the IP Group Filters tab of the Network Access: Resources page using a netmask in decimal format, the rule will not be created or deleted and you will receive the following error message:

error: Invalid IP mask format

FirePass provides packet filtering capability for Network Access at both the global level and the resource group level. Filter destinations are supplied using an IP network/netmask expression. The netmask can be expressed in either decimal form, or in classless Internet domain routing (CIDR) block form, which is the number of bits (0-32) in the netmask. For example, the 255.255.255.128 decimal netmask corresponds to a 25-bit netmask, expressed in CIDR format as /25. However, when entering a packet filter rule in the IP Group Filters, the rule entry will fail with the above error message if you use the decimal format for the netmask. The CIDR format will work correctly.

Additionally, if you created a rule in the IP Group Filters on an older version of FirePass that did not experience this issue, and then upgraded to one of the affected versions, you will not be able to delete the rule. Clicking on the rule's delete icon will produce the error message.

F5 Product Development tracked this issue as CR71703 and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

Additionally, a hotfix has been issued for certain versions of FirePass. Customers affected by this issue should contact F5 Networks Technical Support to request the hotfix. Include the CR number and the number of this solution in your correspondence. For version 6.0.0, this issue was fixed in cumulative hotfix 600-8.1, and for version 5.5.2, this issue was fixed in cumulative hotfix 552-3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing hotfixes.

Workaround

To enter a filter rule, use the CIDR format of the netmask, instead of the decimal format.

To delete a filter rule with a decimal-format netmask that was created in a previous version of FirePass, delete the resource group containing that Network Access Favorite and recreate it without the filter rule.
