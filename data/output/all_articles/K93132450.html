K93132450: The requested application template (/Common/f5.bigiq-analytics) was not found.

Type
Support Solution
Published
2024-08-18
Updated
2024-08-20
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K93132450

Description

You see the following logs on your big-ip device in restjavad logs:

The requested application template (/Common/f5.bigiq-analytics) was not found.
Tue Aug 2 09:52:11 BST 2022    err    <your_device_hostname>    tmsh[48832]    01420006    3: The requested application instance (/Common/bigiq-analytics.app/bigiq-analytics) was not found.
Tue Aug 2 09:52:11 BST 2022    err    <your_device_hostname>    mcpd[6433]    01020036    The requested application instance (/Common/bigiq-analytics.app/bigiq-analytics) was not found.

or similar to these:

[SEVERE][201552][20 Mar 2022 19:29:05 UTC][8100/shared/rpm-tasks RpmTaskCollectionWorker] rpm -U /var/config/rest/downloads/analytics-iapp2-8.1.0.1-0.0.36.noarch.rpm: RPM returned error code 1. Output= file /var/config/rest/iapps/staging/f5.bigiq-analytics.tmpl from install of analytics-iapp2-8.1.0.1-0.0.36.noarch conflicts with file from package analytics-iapp-7.1.0.0.2-0.0.1520.noarch
[I][201559][20 Mar 2022 19:30:12 UTC][8100/shared/rpm-tasks RpmTaskCollectionWorker] Executing rpm -e analytics-iapp2
[SEVERE][201560][20 Mar 2022 19:30:12 UTC][8100/shared/rpm-tasks RpmTaskCollectionWorker] rpm -e analytics-iapp2: RPM returned error code 1. Output=error: package analytics-iapp2 is not installed
[I][201562][20 Mar 2022 19:30:12 UTC][8100/shared/rpm-tasks RpmTaskCollectionWorker] Executing rpm -e analytics-iapp2

Environment

  • BIG-IQ CM
  • BIG-IQ DCD
  • BIG-IP 
  • Statistic collection enabled

Cause

Unknown, most likely some rpm package corruption on the big-ip device.

Recommended Actions

1) Disable statistic collection on big-iq.
2) Run the below command on problematic big-ip:

rpm -e analytics-iapp

3) Enable statistic collection on big-iq.

Additional Information

None.
