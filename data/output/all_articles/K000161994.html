Description

Migrating BIG-IP system to an rSeries tenant may fail to load due to configuration load errors, like "01070712:3: Cannot set MAC address for < vlan > to '< MAC ADDRESS' in rd< ID other than 0 > - ioctl failed: No such device". The migration tool attempted to associate VLANs to interfaces before creating the required route domains, resulting in partial configuration application and subsequent errors.

Environment

Platform migration to Velos/rSeries tenant.

Migration performed using UCS file and platform-migrate process

Custom route domains and VLANs present in configuration

Cause

The migration failed because the migration tool attempted to associate VLANs to interfaces before the necessary route domains were created on the target rSeries tenant.

Answer/Recommended Actions

1. Ensure all relevant vlans are attached to the destination tenant.

2. If custom route domains are defined then create them on the target tenant before loading the UCS.

3. Rekey the destination tenant before attempting to load the UCS.

4. Remove trunk configuration.
