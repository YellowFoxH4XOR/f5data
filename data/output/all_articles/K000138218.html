K000138218: How to revoke BIG-IP Virtual Edition licenses managed by the BIG-IQ

Type

Published
2024-01-12
Updated
2026-02-05
Applies to

  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.0, 8.4.X, 8.3.0
  • BIG-IP Cloud Edition
Source

Description

A BIG-IP Virtual Edition (VE) isn't needed anymore or is migrating to a new license and its current license is maintained by BIG-IQ.

Environment

  • BIG-IP VE, including unreachable
  • Flex Consumption Plan (FCP)
  • BIG-IQ Centralized Manager or License Manager

Cause

The license for the BIG-IP VE needs to be revoked for any of the following reasons:

  • To keep FCP usage reports accurate
  • To enable the license reactivate option on the BIG-IP VE Configuration Utility

Important: Revoking the license stops traffic on the BIG-IP VE. F5 recommends performing these changes during a maintenance window.

Recommended Actions

Confirm which BIG-IQ owns the license then, from that BIG-IQ, revoke the license for the BIG-IP VE. For unreachable BIG-IP VEs, there is an additional step. The license needs to be manually removed from the unreachable BIG-IP VE for the license reactivate option to become available from its Configuration Utility (WebUI). After the license offering is revoked from the BIG-IQ, run Historical Utilization reports to confirm the status of these CAT license offerings.

On the BIG-IP:

  1. Navigate to System > License 
  2. Scroll to the bottom of this General Properties page
  3. Note the BIG-IQ IP address mentioned in the License Manager row.

On the Unreachable BIG-IP:

  1. Logon to the command line on the BIG-IP VE
  2. Backup the existing license: cp /config/bigip.license /config/bigip.license.orig
  3. Remove the license file: rm /config/bigip.license. Type Y to confirm.
    Important: Revoking the license stops traffic on the BIG-IP VE. F5 recommends performing these changes during a maintenance window.
  4. Reload the license by running this command: reloadlic
  5. After the services restart, the license reactivate option is available from the Configuration Utility.

On the BIG-IQ:

  1. Navigate to Devices Tab > License Management > Assignments
  2. Select the check box for the BIG-IP Device Name
  3. Click Revoke
  4. Enter the username and password of the BIG-IP VE
  5. Click Revoke and OK to confirm.
    Important: Revoking the license stops traffic on the BIG-IP VE. F5 recommends performing these changes during a maintenance window.
  6. Run an Historical report on the BIG-IQ to confirm the revoke status of the BIG-IP VEs so the utilization reports are accurate.
