K6965: Corrupt display of Novell Netware file shares in FirePass Windows Files Favorites

Topic

If you upgrade your FirePass software from version 5.5.x to version 6.0.0, FirePass Windows Files Favorites may display incorrectly for versions of Novell Netware prior to version 6.5 with Service Pack 2 (SP 2).

FirePass Portal Access Windows Files Favorites are implemented using the SAMBA package, the public-domain implementation of the SMB/CIFS protocol used by Windows Networking. All 5.5.x versions of FirePass software use SAMBA version 2. FirePass version 6.0.0 and later minor releases of 6.0.0 use SAMBA version 3.

F5 Networks recommends using Netware 6.5 SP2 or later, if Windows Files Favorites functionality is needed.

Important: While Netware 5.1 and perhaps other older versions of Netware may work with SAMBA 2 clients, it is unlikely that SAMBA 3 clients will work with these versions of Netware. A FirePass controller that is running version 5.x, and is able to correctly display file shares from a Netware 5.1 file server, may fail to display the same file shares when the FirePass is upgraded to version 6.0.0 or later.

When this known issue occurs, FirePass will correctly display the file and folder icons of the file share in the left frame of the Windows Files Favorite, but the names of the files and folders will be left blank or will have names consisting of seemingly random characters. This failure is due to an extra byte, typically zero-value, added to the FIND_FIRST2 data segment of the Trans2 SMB response, sent from the Netware server in response to the FirePass's SMB Trans2 request to list the contents of the top-level directory. If a network packet dump is taken, the extra byte can be seen at the 61st byte (measured from the beginning of the SMB data) in the Trans2 response. Because the erroneous behavior occurs on the Novell Netware server, at this time, F5 Networks does not intend to provide a fix now, or in a later FirePass release.

Workaround

Do not upgrade your FirePass software to the 6.0.x feature release branch. Continue to use the 5.5.x maintenance releases until you can upgrade your Novell Netware server to version 6.5 SP 2 or a later version. Alternatively,you can use a different Favorite type, such as an Application Access Favorite or a Network Access Favorite. Consult your Novell Netware documentation for more information about upgrade options.
