Known Issue

BIG-IP Advanced Routing Module (BIG-IP ARM) using BGP Equal-Cost Multi-Path routing (ECMP) may not correctly update ECMP routing when a disabled path is re-enabled.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is licensed with Advance Routing.
  • Multiple ECMP routes are configured for BGP.
  • An ECMP link is disabled and then re-enabled.

Impact

ECMP routing does not function as expected and all available paths are not used.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Re-enabled links are not used as expected.
  • BGP routing tables do not display expected routes.
