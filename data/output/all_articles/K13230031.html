Description

BIG-IP DNS Wide IP is not resolving the correct IP base on Topology Load Balancing when using a public DNS such as Google DNS

Environment

This article is applicable when the following conditions are met:

  • GSLB Topology and Wide IP has correctly been configured on the BIG-IP DNS.
  • Geolocation database has been updated on the BIG-IP DNS.
  • Local DNS was able to resolve the correct IP when testing using DIG to the BIG-IP DNS listener.

Cause

When using a public DNS such as Google DNS, the public DNS provider will use their LDNS which are located anywhere using variety of IP address thus causing the BIG-IP DNS provide a wrong response.

Recommended Actions

Google has came out with ECS (EDNS Client Subnet) RFC 7871 to address this issue.

  • BIG-IP DNS v14.x and v15.x provides support for ECS. Please follow the DevCentral solution below on how to enable this feature.
    • Using Client Subnet in DNS Requests
       
  • For other software versions, you will need to use iRule to make use of ECS.
    • Implementing Client Subnet in DNS Requests
    • Implementing Client Subnet DNS Requests
