K000160232: Unable to find logs with GUI but able to find those with command line

Type
Support Solution
Published
2026-03-04
Updated
2026-03-04
Applies to

  • BIG-IP LTM: 17.1.0, 17.1.2, 17.1.1, 21.X.X, 17.1.X, 17.5.X, 21.0.X, 21.0.0, 17.5.1, 17.5.0, 17.1.3
Source
https://my.f5.com/manage/s/article/K000160232

Description

While reviewing logs with GUI, while searching for specific logs, you are unable to find those, but you can find matching logs with CLI, for example with grep.

Environment

  • BIG-IP

Cause

GUI only shows logs from files that were not rotated yet, for example, "System >> Logs : Local Traffic" tab in GUI will only show you logs from /var/log/ltm file, it will not search for logs in /var/log/ltm.1 file and older ltm log files.

Answer/Recommended Actions

If you need to review logs that were already rotated, use CLI instead of GUI.
