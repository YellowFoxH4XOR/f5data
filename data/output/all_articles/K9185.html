Known Issue

This is the result of a known issue. When you create the XML profile, you define the validation configuration by importing an XML-based schema file into the profile. The XML profile then protects XML applications by validating whether incoming traffic complies with the predefined schemas or Web Service Definition Language (WSDL) documents.

When attempting to upload a WSDL file into the security profile, the BIG-IP ASM system occasionally does not import the WSDL file, and URLs from the WSDL file are not added as objects into the security policy.

When this behavior occurs, the WSDL file name does not appear in the Configuration Files section of the XML profile. Additionally, the BIG-IP ASM system does not generate any error messages that indicate the WSDL file was not imported into the policy.

F5 Product Development tracked this issue as CR107509 and it was fixed in BIG-IP ASM 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.
