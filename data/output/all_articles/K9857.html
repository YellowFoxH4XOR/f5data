Topic

When the Display Host Names When Possible option is enabled on the System > Preferences page, the BIG-IP system attempts to resolve each IP address displayed as the page loads. Depending on the number of displayed addresses requiring resolution and the availability and response of the DNS servers, the page may not fully load before the Tomcat process five-minute timeout expires. If the timeout expires before the page fully loads, Tomcat resets the connection and the page load stops.

Workaround

You may be able to improve resolution times to within acceptable limits by optimizing the BIG-IP DNS server configuration by referencing the closest, fastest resolver available.

Note: The following workaround also improves the display time of the bigtop utility, which attempts to resolve host names when the Display Host Names When Possible setting is enabled.

You can work around this issue by disabling the Display Host Names When Possible option. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Select System.
  3. Select Preferences.
  4. Under System Settings, clear the Display Host Names When Possible check box.
  5. Select Update.
