Description

Traffic matching criteria and addresses within the address list have different route domain
Config load failed with below Error message:

01b40040:3: TMC(/Test-Partition/Test-TMC) and addresses within the address list(/Test-Partition/Test-Address-List) have different route domain.

Environment

  • Route-domains
  • Address-Lists
  • Config load failure
  • Traffic-Matching-Criteria
  • Non-Zero Route Domain
  • Custom Partition

Cause

Issue is a side effect of ID1000069
Config load failed when traffic-matching-criteria includes route-domain object in the config.
Below is Sample config.

ltm traffic-matching-criteria /Test-Partition/Test-TMC {
    destination-address-inline 0.0.0.0%0
    destination-address-list /Test-Partition/Test-Address-List
    destination-port-inline 80
    protocol tcp
    route-domain /Common/Test-RD       -----> This Route-domain Object causes config load failure.
    source-address-inline 0.0.0.0%0
}

Recommended Actions

Request EHF for ID1000069

K4918: Overview of the F5 critical issue hotfix policy
