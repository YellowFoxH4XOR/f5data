Description

When attempting to import a software image file over 2GB in size via Configuration Utility (GUI), it may not show any progress in "progress bar", and the upload will fail.

Environment

  • BIG-IP 12.1.2 and 12.1.3
  • GUI
  • Importing a software image

Cause

The cause of this is suspected to be the result of known issue ID:614648

Recommended Actions

  1. Connect to the BIG-IP with an SFTP/FTP utility.
  2. Upload the software image into the /shared/images folder.
  3. Refresh the GUI once complete to display the available image.
