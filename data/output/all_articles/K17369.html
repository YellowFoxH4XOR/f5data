Topic

Summary

The FirePass controller does not support Oracle Java SE 8.

Description

The FirePass controller does not support Java SE 8, and F5 has no future plans to add support for Java SE 8.

F5 recommends that FirePass customers migrate to the BIG-IP APM system at their earliest convenience. For more information, refer to K13366: End of Sale announcement for FirePass.

Impact

FirePass controller functionality for Java SE 8 is not supported, and may cause the following issues:

  • The FirePass controller may not function as expected for application tunnels initiated by a client using Java SE 8.
  • The FirePass controller may incorrectly rewrite application content written with Java SE 8.
