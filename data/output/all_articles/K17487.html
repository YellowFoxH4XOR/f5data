Known Issue

Network access resources may be unreachable after establishing an access session.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a network access profile.
  • Users establish their network access session through a proxy server.
  • The user device is configured with a proxy server configuration that references a DNS name that is resolved with DNS round robin.

Impact

Users may be unable to access configured network resources.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After successfully establishing a network access session, access to network resources fail.
  • When the user views their network access session statistics after attempting to access network access resource, the statistics do not increment.
  • Network access session statistics do not increment when users attempt to access the configured access resources.

Workaround

To work around this issue, you can configure the user device proxy configuration replacing the proxy DNS name with the IP address of the proxy server.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
