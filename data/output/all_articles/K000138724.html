Description

After installing or upgrading NMS the GUI becomes inaccessible with error message "502, Upstream Unavailable"

Additionally the following NGINX error.log message (or similar) may occur:

[crit] 30773#30773: *3063678 connect() to unix:/var/run/nms/am.sock failed (13: Permission denied) while connecting to upstream, client: <ip>, server: _, request: "POST /f5.nginx.agent.sdk.Commander/CommandChannel HTTP/2.0", upstream: "grpc://unix:/var/run/nms/am.sock:", host: "<ip>:443"

Environment

NGINX Instance Manager (NIM)

Cause

Sometimes after installing or upgrading NIM the users www-data and nginx are not assigned to the nms group. For example:

$ groups www-data
www-data : www-data nms
$ groups nginx
nginx : nginx

Notice how user www-data is assigned to the nms group however user nginx is not.

Recommended Actions

Add users www-data and nginx to the nms group and restart services

sudo gpasswd -a nginx nms
sudo gpasswd -a www-data nms
sudo service nginx reload
sudo systemctl restart nms
