Description

When BIG-IQ tries to discover a BIG-IP AFM device or deploy a change for firewall rules towards the BIG-IP AFM an error similar to the following occurs:

Failed waiting for discovery task for <device hostname> (<device ip addr>) to finish; reason: Error querying 'Rule List' from path '/mgmt/tm/security/firewall/rule-list' on device <device hostname> (<device ip addr>), network communication failed due to protocol error

Running 'tmsh list security firewall rule-list all-properties' on the BIG-IP AFM hangs and never returns any response.

Environment

  • BIG-IQ
  • BIG-IP AFM

Cause

Memory allocation error occurs in mcpd as it creates a response for the entire firewall rule list with objects in the order of tens of thousands. Note that this is a different issue than that on ID1215161.

F5 has raised ID2083257 for possible enhancements on the BIG-IP code.

Recommended Actions

Remove unnecessary or overlapping firewall objects (eg. policies, rules, rule-lists, address-lists, port-lists) from the BIG-IP AFM until mcpd is able to generate a response when issuing the command 'tmsh list security firewall rule-list all-properties' or when querying iControl REST API endpoint /mgmt/tm/security/firewall/rule-list.
