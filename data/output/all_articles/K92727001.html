Known Issue

The Traffic Management Microkernel (TMM) process on standby system may produce a core file when using the Stream Control Transmission Protocol (SCTP) profile.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system configuration includes a virtual server that uses the SCTP profile.
  • The virtual server has mirroring enabled.
  • The device is in standby mode.

In rare conditions, the TMM process on a standby system may process a duplicate or unexpected COOKIE_ECHO call from an earlier SCTP connection flow association that is still in the process of shutting down.

Impact

A standby unit in the device group temporarily becomes unavailable while the TMM process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H615200 on the Diagnostics > Identified > Medium screen.
  • The standby BIG-IP system temporarily becomes unavailable as it recovers from a TMM restart.
  • The standby BIG-IP system logs a TMM core file to the /shared/core directory.
