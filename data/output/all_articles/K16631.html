Known Issue

The Simple Mail Transfer Protocol (SMTP) monitor may fail to connect, and then incorrectly mark down an available pool member.

This issue occurs when the following condition is met:

  • The SMTP monitor is configured to monitor a pool member on a non-default route domain.

Impact

The SMTP monitor incorrectly marks down available SMTP pool members.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Available SMTP pool members on non-default route domains are incorrectly marked down.
  • If debug logging is enabled for the monitor, the /var/log/debug log file contains messages similar to the following example:

    Notice 'ERROR: failed to connect 10.10.1.100%20:25 error: couldn't open socket: host is unreachable'.

Workaround

To work around this issue, you can configure the affected pool to use an external SMTP monitor that is created from the built-in SMTP_monitor script. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Import a new external monitor file named SMTP_monitor, from the /usr/bin/monitors/builtin/SMTP_monitor source file, by typing the following command:

    create sys file external-monitor SMTP_monitor source-path file:/usr/bin/monitors/builtins/SMTP_monitor
  3. Create a new external monitor named SMTP_monitor that calls the file that you imported in step 2, by typing the following command:

    create ltm monitor external SMTP_monitor run /Common/SMTP_monitor
  4. Update the affected pool to use the new external monitor, which you created in step 3, by using the following command syntax:

    modify ltm pool /Common/<pool_name> monitor /Common/SMTP_monitor

    For example, if the affected pool name was smtp_pool, you would type the following command:

    modify ltm pool /Common/smtp_pool monitor /Common/SMTP_monitor
  5. Save the configuration changes by typing the following command:

    save /sys config
