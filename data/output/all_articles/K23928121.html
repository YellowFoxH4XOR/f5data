Topic

This article provides an overview of command-line options available with the qkview utility.

Description

You can use the qkview utility to create a QKView file, which contains diagnostic information that you can provide to F5 Technical Support using the F5 iHealth tool. In almost all cases, you can generate qkview diagnostic data without using additional command-line options. You can generate this data using the Configuration utility by navigating to System > Support or by typing the qkview command from the command line. For more information, refer to K12878: Generating diagnostic data using the qkview utility.

There are cases in which using the default qkview utility options does not produce a sufficiently detailed QKView file. This article describes command-line options available to address these situations.

The following table lists qkview utility options. Click the link in the Option column to follow a command option to its use-case example .

Note: For more information about qkview utility options not included in this article, refer to the qkview manpage by typing the man qkview command.

OptionDescriptionWhen to use
-s <bytes>Set maximum file size to capture, in bytes. Setting this value to -s 0 is equivalent to the maximum allowed size in the release.
Note: You can use the "man qkview" command to check the maximum allowed size in the release.		BIG-IP system log files are truncated due to size.
-vDisplay verbose output.The qkview command does not complete generating a QKView file.
-f <file name>Provide an alternate file name. If not set, the default file name syntax is <hostname of BIG-IP>.qkview.You want to generate multiple qkview diagnostic files taken at different times.
-t <seconds>Set maximum time for any one module to complete.F5 Technical Support tells you that a module's information is missing from your QKView diagnostic file.
-cCollect complete system information, possibly including sensitive user information.F5 Technical Support requests complete information in the qkview diagnostic file.
--exclude <flag>Exclude specified log files from output.You want to exclude sensitive files when you run the qkview command at the command line.
-hPrint the help message.To view additional qkview options not described in this article.

Using the -s <bytes> option

If BIG-IP log files are too large, the qkview utility may tail-truncate the log files, which may cause a problem if F5 Technical Support needs the entire log files.

Impact of procedure: Overriding the default size limit can result in very large QKView files. You should only use this option when instructed to do so by F5 Technical Support.

To override log file truncation, use the -s <size> option and specify an integer value for the maximum file size, in bytes or enter 0 for maximum allowed size in the release. For example, type the following command:

qkview -s 0

Note: Beginning in BIG-IP 13.1.0, you can set -s 0 in the Configuration utility by selecting the Unlimited snaplen check box.

Using the -v option

Sometimes the qkview command does not complete or takes a long time to complete. You can specify verbose output by using the -v option with the qkview command. When you specify the verbose option, all of the commands that the qkview utility runs to generate the QKView file display, along with the execution time for each of the commands. This may help F5 Technical Support identify which command is slowing or preventing the qkview command from successfully completing.

Impact of procedure: The qkview command may take slightly longer to complete.

To provide verbose output, type the following command:

qkview -v

Using the -f <file name> option

By default, the system saves QKView files with the following file name syntax: <BIG-IP hostname>.tar.qkview. When you create a new QKView file, it overwrites the previous version of that file. If you need to gather diagnostic files before and after an event for troubleshooting purposes, you can use the -f <filename> option to save the QKView files with different names.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To save a diagnostic file a different name use the following command syntax:

qkview -f <filename>.qkview

For example, to save a QKView file named test, type the following command:

qkview -f test.qkview

Note: You can only save QKView files in the /var/tmp/ directory and its subdirectories. The system prepends any file name you provide using the -f option with /var/tmp/, unless the file name already begins with /var/tmp/.

Using the -t <seconds> option

By default, the qkview utility times out after 360 seconds (5 minutes) of waiting for a module to generate its support information. If your configuration is large or if the system is busy, you may need to increase this timeout value. You can use the -t <seconds> option to override the default.

Impact of procedure: Increasing the timeout value may make it more likely that modules can output their full diagnostic information; however this can also cause the qkview command to take significantly longer to complete. You should only use this setting if instructed to do so by F5 Technical Support.

To increase the timeout value to 6 minutes (420 seconds), type the following command:

qkview -t 420

Note: To set the value to the utility's maximum value, type -t 0. For example:

qkview -t 0

Using the -c option

In rare cases, F5 Technical Support may require you to generate a complete QKView file to troubleshoot an issue. You can use the -c option to have the qkview utility perform the following tasks to gather additional information:

  • Execute the /usr/bin/printcertmods command to collects moduli of SSL certificates.
  • Execute the /usr/bin/resolveHosts command, which collects fully qualified domain name (FQDN) resolutions of the servers BIG-IP devices use.
  • Include Traffic Management Microkernel (TMM) session variables if the BIG-IP APM module is installed.

Impact of procedure: The -c option significantly prolongs the time it takes for the qkview command to complete.

Important: When using the -c option with the qkview command:

  • Potentially sensitive information is recorded in the QKView file.

Using the --exclude <flag> option

You can exclude certain sensitive logs files from QKView files by using the --exclude <flag> option. The following table shows the available flags and the log files that they exclude.

FlagExcluded log files
audit/var/log/audit* and /var/log/auditd/*
secure/var/log/secure*
bash_history/root/.bash_history
allEquivalent to excluding audit, secure, and bash_history

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

In order to exclude the /root/bash_history file from the QKView file, type the following command:

qkview --exclude bash_history

You can combine multiple flags in the same command. For example, qkview --exclude all is equivalent to qkview --exclude audit,secure,bash_history.

Note: Beginning in BIG-IP 13.0.0, you can exclude sensitive files using the Configuration utility.
