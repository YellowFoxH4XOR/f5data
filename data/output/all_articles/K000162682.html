Topic

This article applies to BIG-IP 21.x. For information about other versions, refer to the following articles:

  • K000134647: SSL ciphers used in the default SSL profiles (17.x)

Description

When you configure an SSL profile on the BIG-IP system, you have the option to manually specify the ciphers available for SSL connections or use the default cipher list available for the SSL profile. The default cipher string contains ciphers that are suitable for most SSL connections.

Note: For information about all supported ciphers, refer to K000136126: SSL ciphers supported on BIG-IP platforms (16.1.x - 21.x).

To view the current DEFAULT cipher list for the specific version and hotfix level that your system is running, type the following command from the BIG-IP command line:

tmm --clientciphers DEFAULT

The SSL ciphers supported on BIG-IP systems change across versions. The following tables list the SSL ciphers supported by the native stack used on the BIG-IP system for the default Client and Server SSL profiles:

  • Ciphers in BIG-IP 21.1.x
  • Ciphers in BIG-IP 21.0.x
