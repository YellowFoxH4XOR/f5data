K000130263: Error log for icr_eventd of "Recv REST msg error: bad request status 404 with message"

Type
Support Solution
Published
2023-01-12
Updated
2023-01-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.0, 13.1.X, 14.1.3, 14.1.2, 14.1.0, 15.1.2, 15.1.1, 15.1.0, 15.0.X, 16.0.X, 16.0.1, 16.0.0, 15.0.1, 15.0.0, 13.1.5, 13.1.4, 13.1.3, 13.1.1
Source
https://my.f5.com/manage/s/article/K000130263

Description

  • You have observed below log in /var/log/ltm

err icr_eventd[<pid>]: 01a10002:3: Recv REST msg error: bad request status 404 with message: URI path /shared/publisher not registered. Please verify URI is supported and wait for /available suffix to be responsive.: Protocol error

  • You have observed below log in /var/log/restjavad.0.log

[SEVERE][<pid>][<time>][DieOnUncaughtErrorHandler] Restjavad exiting immediately due to an uncaught Error
[SEVERE][<pid>][<time>][DieOnUncaughtErrorHandler] Uncaught Error causing restjavad to exit. Thread id 38, 'Non-Blocking threadPool_16': java.lang.OutOfMemoryError: Java heap space

  • You have observed below log in /var/log/daemon.log which indicates the restjavad process is restarting

<BIG-IP host name> emerg logger[<pid>]: Re-starting restjavad

  • You may find the BIG-IP web GUI sluggish or even no response when you visit it.

Environment

  • BIG-IP system with no extra memory given to restjavad.

  • The configuration contains a large number of configuration objects.

Cause

This issue is caused by ID776393.

 Recommended Actions

Please refer to the Recommended Actions in K12410040: restjavad restarts frequently or the Workaround in ID776393.

Additional Information

During the issue period, you may also note that LTM pool member status up and down.
