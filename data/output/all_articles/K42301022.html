Topic

This article applies to BIG-IP ASM 11.x through 15.x. For information about other versions, refer to the following article:

  • K5979: Configuring the BIG-IP ASM to parse HTTP responses that are larger than 50 MB in length (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP ASM system to parse HTTP responses that are larger than 50 MB in length.

Description

By default, the BIG-IP ASM system does not parse HTTP responses that are longer than 50 megabytes in length. The max_filtered_html_length parameter defines the maximum response size that the BIG-IP ASM system can accumulate when verifying or extracting data from the response. When the response exceeds the 50-megabyte length, the BIG-IP ASM system stops accumulating the response, logs an error message to the /var/log/asm file, and passes the response to the client. If the response header exceeds the value of the max_filtered_html_length parameter, the BIG-IP ASM system will reset the connection. To modify the maximum response size that the BIG-IP ASM system will parse, refer to the following procedures:

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have access to the Configuration utility.

Procedures

Modifying the max_filtered_html_length variable (11.3.0 - 15.x)

To modify the maximum response size that the BIG-IP ASM system will parse in BIG-IP ASM 11.3.0 - 15.x, perform the following procedure:

Impact of procedure: Restarting the BIG-IP ASM service results in a brief traffic disruption.

  1. Log in to the Configuration utility.
  2. Go to Security > Options > Application Security.
  3. Hover on the Advanced Configuration tab and select System Variables.
  4. Select the max_filtered_html_length link.
  5. For Parameter Value, enter the new maximum response size in bytes.
  6. Select Update.
  7. Log in to the command line.
  8. Restart the BIG-IP ASM processes by entering the following command:

    bigstart restart asm

Modifying the max_filtered_html_length variable (11.0.0 - 11.2.1)

To modify the maximum response size that the BIG-IP ASM system will parse in BIG-IP ASM 11.0.0 - 11.2.1, perform the following procedure:

Impact of procedure: Restarting the BIG-IP ASM service results in a brief traffic disruption.

  1. Log in to the Configuration utility.
  2. Go to Application Security > Options.
  3. Select Advanced Configuration.
  4. On the System Variables page, locate the max_filtered_html_length setting.
  5. Enter the new maximum response size, in bytes.
  6. Select Update.
  7. Log in to the command line.
  8. Restart the BIG-IP ASM processes by typing the following command:

    bigstart restart asm
