Description

How to log a client IP address when the client connects to a Virtual Server.

Environment

  • BIG-IP LTM
  • Virtual Server with a TCP profile or FastL4 Profile (Note: Fastl4 profiles cause the client_accepted event to fire on the client syn packet)
  • Connecting client computers making requests to the Virtual Server(s)
  • iRule or Policy

Cause

None

Recommended Actions

This can be accomplished wither either of the below methods. You can use an iRule or a Policy.

Method 1 - iRule

To log the client IP address when there's a new TCP session you can create the following iRule to show a message in /var/ltm every time there's a new TCP session:
  1. To Create the iRule go to Local Traffic > iRules > iRule List
  2. Then click in Create
  3. Choose a name for your iRule and paste the following statements into the Definition field:
    when CLIENT_ACCEPTED {
      log local0. "[virtual] - client ip=[IP::client_addr]:[TCP::client_port]"
        }
  4. Click Finished
To apply the iRule to the Virtual Server you want to log the client's IP address follow these instructions:
  1. Go to Local Traffic > Virtual Servers > Virtual Server list
  2. Select the Virtual Server
  3. Click in the Resources tab
  4. In the iRules section click Manage
  5. Choose the iRule you just created from the Available section and add it to the Enabled section
  6. Click Finished

 

Method 2 - Policy

  1. In the GUI navigate to Local Traffic>> Policies>>Policy List and click create.
  2. Create the Policy as shown in the image below.

3. After the policy is created you will have to click the check next to it in draft and click publish. It should appear like this.

4. Now simply apply the policy to your desired virtual server by clicking on the virtual server and then select the "resources" tab at the top and apply the policy to the virtual server
