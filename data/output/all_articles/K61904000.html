Description

UCS load hangs up while trying to load it on a new platform with platform-migrate and no-license switches. There are no error messages. The last CLI output "Platform migrate loaded successfully. Saving configuration." can be seen, however, the process never ends.

Environment

  • BIG-IP
  • Version 14.x.x
  • UCS load
  • platform-migrate and no-license switches

Cause

When the platform-migrate option is given to 'tmsh load sys ucs <ucs file name> platform-migrate' the command hangs because the platform-migrate option causes 'tmsh save sys config' to be run. A lock file is used to block concurrent UCS loads and saves them from happening. However, the save is done after the UCS has successfully loaded, so it is fine to allow the save to proceed.

Please note that this may also be related to bug ID995629.

Recommended Actions

  1. Use no-platform-check instead of platform-migrate
  2. Use a workaround from the bug ID995629.
