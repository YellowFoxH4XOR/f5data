K22282721: IP Intelligence license for Pay As You Go (PAYG) on Azure

Type
Support Solution
Published
2021-11-06
Updated
2026-02-05
Applies to
  • Public Cloud
  • BIG-IP
  • BIG-IP Cloud Edition
  • Microsoft Azure
Source
https://my.f5.com/manage/s/article/K22282721

Description

You are attempting to purchase an IP Intelligence license for a PAYG instance hosted on Azure, but the base registration key was originally obtained from the AWS Marketplace.

Environment

  • Azure Cloud
  • AWS Marketplace
  • IP Intelligence license

Cause

None

Recommended Actions

 
IP Intelligence and Threat Campaign licenses cannot be activated on AWS Marketplace PAYG instances. This limitation also applies to PAYG instances in any public cloud environment.

 

Additional Information

None
