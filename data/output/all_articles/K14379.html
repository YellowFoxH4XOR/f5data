K14379: The BIG-IP system incorrectly associates a DoS profile to a BIG-IP ASM virtual server after an upgrade to 11.3.0

Known Issue

The BIG-IP system incorrectly associates a denial-of-service (DoS) profile to a BIG-IP ASM virtual server after an upgrade to 11.3.0. This issue occurs when the following condition is met:

  • Prior to the upgrade, the security policy associated with the BIG-IP ASM virtual server was not enabled with the DoS Attack Prevention feature.

Since the security policy was not enabled with the DoS Attack Prevention feature prior to the upgrade, the incorrectly associated DoS profile is also not enabled with DoS protection. Even though the DoS profile is not enabled with DoS protection, the system will collect statistics for the virtual server associated with the DoS profile. This may cause performance to degrade on an overloaded BIG-IP ASM system.

Prior to 11.3.0, the DoS Attack Prevention feature can be disabled by configuring the Operation Mode setting to Off on the Application Security > Anomaly Detection > DoS Attack Prevention page. In 11.3.0, the DoS protection is now configured in a DoS profile on the Security > DoS Protection > DoS Profiles page.

Impact

Performance may degrade on an overloaded BIG-IP ASM system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Performance may degrade on an overloaded BIG-IP ASM system.

Workaround

To work around this issue, you can manually remove the DoS profile from the BIG-IP ASM virtual server. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Virtual Servers.
  4. Click Virtual Server List.
  5. Click the name of the virtual server.
  6. Click the Security tab.
  7. Click Policy.
  8. For the DoS Protection Profile setting, select Disabled.
  9. Click Update.
