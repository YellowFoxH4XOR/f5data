Description

In 14.1.0 and later, the BIG-IP APM system introduced API Protection feature.
You can manage subsessions for API Protection by using the CLI.  

Environment

  • BIG-IP APM 14.1.0 and later
  • API Protection

Cause

This is by design. 

Recommended Actions

  • To list active subsessions: 
    sessiondump -subs

  • To remove a subsession:  
    sessiondump -delete <subsession_ID>

  • To monitor numbers and status of subsessions for API Protection: 
    tmsh show api-protection server
    tmsh show api-protection profile
