Known Issue

Session database variables with long data values may fail arithmetic operation.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system has session database variables with extremely long integer values, namely, padded integers.   
  • The system attempts to perform an arithmetic operation to the session database variables, for example, when using an iRule.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from the Traffic Management Microkernel (TMM) restarting, and systems configured as part of a high availability (HA) group may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The session database variables arithmetic operation may fail, resulting in iRule errors.
  • The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting, and systems configured as part of an HA group may fail over.
  • The BIG-IP system generates a TMM core file with a SIGFPE signal to the /shared/core directory, with a time stamp that correlates to the traffic interruption.

Resolution

Status

F5 Product Development has assigned ID 418943 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can trim the session database variables before using them in the iRule.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
