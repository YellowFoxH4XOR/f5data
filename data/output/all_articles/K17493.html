Known Issue

BIG-IP Analytics (AVR) data in the MySQL database may grow to exceed the capacity of the file system.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured to collect AVR analytics data.
  • A large number of entries in the MySQL DNS table are not evicted as expected when they are no longer needed.

Impact

The MySQL process may stop responding and the system may experience interruption in service.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • AVR analytics data in the MySQL database might grow to exceed the capacity of the file system.
  • The MySQL process may stop responding and the system may experience interruption in service.

Workaround

To work around this issue, you can monitor the file system utilization, and occasionally reset the AVR statistics database, for example, if the file system utilization exceeds 70%. To do so, refer to K14956: Resetting BIG-IP AVR statistics.

Impact of workaround: Resetting the BIG-IP AVR statistics database will remove all Analytics data and reset the MySQL database.
