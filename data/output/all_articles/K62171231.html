Known Issue

The BIG-IP APM system may fail to initialize after an RPM software package installation halts.

This issue occurs when all of the following conditions are met:

  • You attempt to install an RPM software package.
  • The  installation of the RPM software package is halted.
  •  The halted RPM software installation process does not remove RPM database locks.
  • You reboot the BIG-IP APM device.

Impact

The BIG-IP APM system does not initialize.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to log in to the Configuration utility, the system displays the following message:

    Configuration utility is restarting

  • You are unable to access the TMOS Shell (tmsh).
  • In the /var/log/ltm file, you observe that log messages similar to the following example repeat every 15-20 minutes:  

    Error waiting for MCP

  • When you attempt to restart the mcpd service, the restart fails with an error message similar to the following example:

    supervise not running 

  • When you run the command bigstart restart, all BIG-IP services fail to start and the system displays an error message similar to the following example:

    supervise not running 

  • If you produce a /shared/lib/rpm/ directory list, you notice multiple files starting with the __db prefix and ending in a 3-digit numerical value.

    For example:

    -rw-r--r--. 1 root root              0 2017-08-19 05:13 __db.000
    -rw-r--r--. 1 root root     24576 2017-09-04 18:34 __db.001
    -rw-r--r--. 1 root root 1318912 2017-09-04 18:34 __db.002
    -rw-r--r--. 1 root root  450560 2017-09-04 18:34 __db.003

Workaround

To work around this issue, you can manually remove the extraneous RPM files and reboot the device. To do so, perform the following procedure:

Impact of workaround:   Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected device.
  2. To remove extraneous RPM files, type the following command: 

    rm -f /shared/lib/rpm/__db.???

  3. To reboot the device, type the following command:

    shutdown -r now
