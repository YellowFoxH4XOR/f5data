Known Issue

The Application Visibility and Reporting (AVR) TCP analytics Remote Host IP Address Round Trip Time (RTT) average may show incorrect values.

This issue occurs when all of the following conditions are met:

  • The AVR is provisioned with a tcp-analytics profile.
  • A tcp-analytics profile is attached to a virtual server.

Impact

The values reported in the RTT Avg column may be incorrect when you select View By: Remote Host IP Address.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you navigate to Statistics > Analytics > TCP > RTT and select View By: Remote Host IP Address in the table below the graph, the values presented for the RTT Avg (ms) may be incorrect (the values may be even larger than the RTT Max column).
