Description

F5 Telemetry Streaming supports following tables.

  • system
  • syslog
  • LTM request log
  • CGNAT log
  • AFM log
  • ASM log
  • APM log
  • AVR log


This article is a summary about the configurations to send each table in Telemetry reports.


Environment

BIG-IP


Cause

None, this is informational.


Recommended Actions


1.) Telemetry Basic Configuration on BIG-IP

Part 1: Configure an event listener

  1. Create an iRule (localhost forwarder).
  2. Create the virtual server for the local listener 255.255.255.254:6514.
  3. Create the pool with a member 255.255.255.254:6514

Part 2: Configure the logging components, including

  1. Create the Log Destination (Remote HSL):
  2. Create the Log Destination (Format):
  3. Create the Log Publisher: (e.g telemetry_publisher) 

Details can be found

https://clouddocs.f5.com/products/extensions/f5-telemetry-streaming/latest/event-listener.html?highlight=event#standard

3.) Configuration for "SYSTEM" table


"System" Table is configured in the declaration.


"My_System": {

"class": "Telemetry_System",

"systemPoller": { ######. default system poller

"interval": 60

}

You can find example output https://clouddocs.f5.com/products/extensions/f5-telemetry-streaming/latest/output-example.html

You can control what will or will not be included in "SYSTEM" table using data modification.

https://clouddocs.f5.com/products/extensions/f5-telemetry-streaming/latest/data-modification.html


4.) Configuration for "syslog" table

  • System Log

To Send "syslog" table in Telemetry report by adding 127.0.0.1:6514 as a syslog remote server.


#tmsh modify sys syslog remote-servers replace-all-with { server { host 127.0.0.1 remote-port 6514 } }


5.) Configuration for LTM request log Table

  • LTM Request Log profile

To Send "LTM request log" table in Telemetry report by creating a "ltm request-log profile" using created telemetry_publisher and attaching it to a Virtual Server.


6.) Configuration for CGNAT log Table

  • Configuring CGNAT logging

To Send "CGNAT log" table in Telemetry report by attaching " telemetry_publisher" to lsn_pool


7.) Configuration for AFM log Table

  • AFM Request Log profile

To Send "AFM log" table in Telemetry report by creating a "security log profile"using created telemetry_publisher and attaching it to a Virtual Server.


8.) Configuration for ASM log Table

  • ASM Log

To Send "ASM log" table in Telemetry report by creating a "security log profile" and attaching it to a Virtual Server.


9.) Configuration for APM log Table

  • APM Log

To Send "APM log" table in Telemetry report by creating a APM log-setting using created telemetry_publisher and attaching it to a Virtual Server.


10.)Configuration for AVR log table

  • AVR Log

To Send "AVR log" table in Telemetry report by modifying the AVR logging configuration to point to telemetry_publisher.

#tmsh modify analytics global-settings { external-logging-publisher /Common/Shared/telemetry_publisher offbox-protocol hsl use-offbox enabled }
