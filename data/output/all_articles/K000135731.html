K000135731: Cannot deploy VELOS tenant: "kubelet has disk pressure"

Type
Support Solution
Published
2023-08-03
Updated
2023-08-03
Applies to
  • F5OS
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000135731

Description

Unable to deploy a tenant on VELOS.

The show cluster command shows kubelet has disk pressure for one or more of the blades.

Environment

  • VELOS
  • Disk space

Cause

Large file(s) consuming available disk space on a blade's /sysroot filesystem.

Recommended Actions

SSH to the blade in question (from a controller's bash shell) and confirm the available disk space:

df -h -x overlay -x tmpfs

If /sysroot has low available space, execute the following find/du pipeline and examine the output to determine which file(s) are consuming the most disk space:

find /sysroot -xdev -type f -size +5M -exec du -h {} \; | sort -hr

Note: You can optionally pipe the output to less, or redirect to a file.

The VELOS administrator should not delete any large file(s) if they are unsure of their origin or purpose. Engage F5 Support for further assistance if required.
