Known Issue

The LB_FAILED event may fail to trigger if a cookie persistence entry points to a down pool member.

This issue occurs when all of the following conditions are met:

  • The client presents a cookie that matches an existing cookie persistence entry.
  • The cookie persistence entry was created for a pool member that has been marked down by monitoring.
  • There are no pool members available in the virtual server's default pool to accept the client connection.

Impact

iRules associated with the virtual server will be unable to use the LB::reselect command to select another available pool.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Client connections do not load balance to a different pool designated by the LB::reselect command when an LB_FAILED event fails to trigger.
