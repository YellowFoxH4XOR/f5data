Topic

You should consider using this procedure under the following condition:

  • You want to remove an OPSWAT Endpoint Security (EPSEC) package from the BIG-IP APM system.

Description

This article details the process of deleting EPSEC images that are no longer needed. This process helps to free up disk space on the system. The BIG-IP system also includes EPSEC images in the user configuration set (UCS) archives, so deleting EPSEC images will reduce the size of UCS files as well.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have administrative access to the Configuration utility or the TMOS Shell (tmsh).

Important: Do not contact OPSWAT for support requests. OPSWAT works through vendors of security products to address issues with supported products or requests to add support for products. You should direct support requests to F5 for issues regarding the BIG-IP APM implementation of the OPSWAT SDK, and to the vendors of the security software for issues regarding their products' implementation of the SDK.

Note: If you're not sure which packages to remove, please see Determining which EPSEC packages can be removed from the BIG-IP system .

Procedures

Remove an EPSEC package

To remove EPSEC packages that are no longer needed, perform one of the following procedures:

  • Using the Configuration utility to remove an EPSEC package

    To watch a video demo of the Configuration utility procedure, go to  K000160063: Remove OPSWAT Endpoint Security (EPSEC) packages from BIG-IP APM using the Configuration utility.

  • Using tmsh to remove an EPSEC package

Use the Configuration utility to remove an EPSEC package

Impact of procedure: Performing this procedure should not have a negative impact on the system.

  1. Log in to the Configuration utility of the active device.
  2. Go to System > Software Management > Antivirus Check Updates.
  3. Select Package Status.
  4. Select the EPSEC package you want to delete from the system.

    Note: You cannot delete the default EPSEC file included with the BIG-IP APM system. The EPSEC file is labeled True under the System Package column.

  5. Select Delete.
  6. To confirm you want to delete the selected file, select Yes.

    Note: The file should automatically be deleted from the peer device after a configuration synchronization (ConfigSync) if the device is a member of a high availability (HA) group.

    Note: Configuration utility will not provide the Delete option (greyed out) on a Standby device.

The Configuration utility should display that the EPSEC package was successfully removed from the system. Review the uploaded packages under the Antivirus Check Updates > Package Status tab.

Use tmsh to remove an EPSEC package

Impact of procedure: Performing this procedure should not have a negative impact on the system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Delete the epsec-package using the following command syntax:

    delete apm epsec epsec-package <folder name/filename>

    For example:

    delete /apm epsec epsec-package EPSEC/Images/epsec-1.0.0-527.0.iso

    Note: It may take a few minutes for this command to reflect that the package deletion completed.

    Note: If you need to reboot or are having the EPSEC packages automatically copy to a secondary blade on a VIPRION or VIPRION vCMP guest, please save the configuration with:

    save /sys config

    to ensure that the configuration on disk no longer refers to the deleted epsec packages

    Note: If a ConfigSync is performed from the Active device after manual deletion of EPSEC files from the Standby, and the package have NOT been removed from the configuration on the Active, all of those files will be sync'd over (possibly causing out of disk issues, especially on secondary blades)
  1. You can validate the package was deleted by entering the following command:

    list /apm epsec epsec-package recursive
