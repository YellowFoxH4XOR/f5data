K45362529: How to allow NTP traffic on management-IP for BIG-IP 14.1.0 and later

Type
Support Solution
Published
2019-08-30
Updated
2025-10-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.0, 15.0.0
Source
https://my.f5.com/manage/s/article/K45362529

Description

Beginning in BIG-IP 14.1.0, NTP is not allowed on the Management interface. A default policy is enforced for all ports on the management interface are blocked except for the below list of ports. 

  • TCP/22
  • TCP/443 
  • UDP+TCP/161 
  • UDP/1026
  • TCP/4353"

Environment

  • BIG-IP running version 14.1.0-14.1.0.6 and 15.0.0
  • NTP Server configuration
  • Management Interface

Cause

Only on BIG-IP running version 14.1.0-14.1.0.6 and 15.0.0, NTP traffic is not allowed on the management interface.

Recommended Actions

To work around the issue follow either of the below procedure.

Allow NTP from Configuration utility:

  1. Login to BIG-IP GUI
  2. Navigate to 
    Click System  ››  Platform  ››  Security
  3. Create a rule 
    Click Add System  ››  Platform  ››  New Rule

Allow NTP from TMSH

  1. Run the following TMSH command to configure specific access by the BIG-IP to a specific NTP server:

    tmsh modify security firewall management-ip-rules rules add { ntp-rule { action accept destination { addresses add { 192.168.100.100 } ports add { 123 } } ip-protocol udp place-before first source { addresses add { 10.10.10.1 } ports none } status enabled uuid auto-generate } } 

    Note: Replace 192.168.100.100 with IP address of your NTP server, and replace 10.10.10.1 with the BIG-IP management IP address of your BIG-IP system.

    Alternatively you can allow general access to NTP with the following command:

    tmsh modify security firewall management-ip-rules rules add { ntp-udp { action accept destination { ports add { 123 } } ip-protocol udp place-before first } } 


  2. Save the configuration:

    tmsh save /sys config
