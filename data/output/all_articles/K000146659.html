Description

  • You would like to add IP addresses to the DDoS Deny list.
  • You do not want to use the F5 XC console or you have many IP addresses to add.

Environment

  • F5® Distributed Cloud
  • F5 Distributed Cloud DDoS Protection

Answer/Recommended Actions

Infraprotect Deny List Rules API

You can use the F5XC DDoS Deny List Rule API to add individual deny rules to your routed DDoS configuration. You can also use the API in your scripts to add multiple IP addresses.

The corresponding API Documentation is available here:
F5 Distributed Cloud Services API for ves.io.schema.infraprotect_deny_list_rule

 

Prerequisites

  • You'll need an API Token to be able to perform these operations (refer to this page to learn more).
    • Replace the YOURTOKEN string in the examples below with your API Token.
  • You'll also need your XC Tenant shortname (the one found in "https://XXXX.console.ves.volterra.io"
    • Replace TENANT_NAME in the URL with your Tenant name

Curl Example

1. Create a JSON file using the example below or examples from the documentation. Be sure to set the name and the prefix. In this example, the file is name ip_address.json. 

 {
    "metadata": {
        "name": "ip-deny-rule-1",
        "namespace": "system"
    },
    "spec": {
        "expiration_never": {},
        "prefix": "203.0.113.0/24"
    }
}

 

2. Run the curl command below. Do not forget to replace the token and tenant name with your own. 

curl -H 'Content-Type: application/json' -H "Authorization: APIToken YOURTOKEN" -X POST -d @ip_address.json https://TENANT_NAME.console.ves.volterra.io/api/infraprotect/namespaces/system/infraprotect_deny_list_rules

A successful response will look similar to the following (shortened for brevity):

{

"name": "ip-deny-rule-1",
"namespace": "system",

Code Snippet: Automatically add Multiple Addresses

It is not uncommon for customers to have large lists of IP addresses that needed to be added to the DDoS Deny List. Rather than adding each one to the console, you can script out a solution like the following Python script. Note: This is just an example of what you can do with the API. It is not production code and you should use at your own risk.

  • You will need to update the TENANT_NAME and YOURTOKEN in this script. 
  • Your list of IP Addresses should be put in a file called "ip_addresses.txt" in the same directory as this script. One IP per line. It would be a good idea to first try with a small number of IPs. 
  • The script includes a delay of one second for each IP to avoid throttling by the API server. If you have 100 IP addresses then the script will take almost 2 minutes to complete. 

ip_addresses.txt

1.1.2.3/32
4.1.1.1/32
12.12.12.0/24
203.0.113.0/24

 submit_ips.py 

#!/usr/bin/python3
# Use at your own risk
# This has not been tested for production
import requests
from time import sleep
 
# The API endpoint you want to send data to
api_url = 'https://TENANT_NAME.console.ves.volterra.io/api/infraprotect/namespaces/system/infraprotect_deny_list_rules'

# Replace with the path to your file containing the list of IP address prefixes 
file_path = 'ip_addresses.txt'

# Headers for the request
headers = {
    'Content-Type': 'application/json',
    'Authorization': f'APIToken YOURTOKEN'
}

# Function to create the JSON payload from the IP prefix
def create_payload(ip_prefix):
    name = ip_prefix.replace('.', '-').replace('/', '-')
    return {
        "metadata": {
            "name": f"ip-deny-rule-{name}",
            "namespace": "system"
        },
        "spec": {
            "expiration_never": {},
            "prefix": ip_prefix
        }
    }


# Read the file containing the IP address prefixes
with open(file_path, 'r') as file:
    for line in file:
        ip_prefix = line.strip()  # Remove any leading/trailing whitespace
        if ip_prefix:  # Skip empty lines
            # Create the JSON payload
            payload = create_payload(ip_prefix)

            # Make the POST request to the API
            response = requests.post(api_url, headers=headers, json=payload)

            # Check if the request was successful
            sleep(1)
            if response.status_code == 200:
                print(f"Successfully submitted the IP address prefix: {ip_prefix}")
            else:
                print(f"Failed to submit the IP address prefix: {ip_prefix}. Status code: {response.status_code}")
                print("Response:", response.text)

 

Run the script:

$ ./submit_ips.py
Successfully submitted the IP address prefix: 1.1.2.3/32
Successfully submitted the IP address prefix: 4.1.1.1/32
Successfully submitted the IP address prefix: 12.12.12.0/24
Successfully submitted the IP address prefix: 203.0.113.0/24
