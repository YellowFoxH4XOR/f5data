Known Issue

The iControlPortal.cgi process may fail when using iControl to create Client SSL profiles in partitions other than the /Common partition.

This issue occurs when all of the following conditions are met:

  • You attempt to use the iControl portal to create a Client SSL profile.
  • You use either LocalLB::ProfileClientSSL::create or LocalLB::ProfileClientSSL::create_v2 to create the profile.
  • You attempt to create the Client SSL profile in a partition other than the default /Common partition.

Impact

The iControlPortal.cgi process fails and you cannot successfully create the Client SSL profile.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The iControlPortal.cgi process fails and logs messages to the /var/log/httpd/httpd_errors file that appear similar to the following example:

    err httpd[12345]: [error] [client 192.168.1.1] FastCGI: incomplete headers (0 bytes) received from server "/usr/local/www/iControl/iControlPortal.cgi"
    warning fcgi-[12345]: [warn] FastCGI: server "/usr/local/www/iControl/iControlPortal.cgi" (pid 12345) terminated due to uncaught signal '11' (Segmentation fault)
    warning fcgi-[12345]: [warn] FastCGI: server "/usr/local/www/iControl/iControlPortal.cgi" restarted (pid 12345)
  • You cannot create the Client SSL profile.
