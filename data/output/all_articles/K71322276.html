Description

You need to understand the use of below cron jobs configured by default on your BIG-IP system.

# crontab -l
1-59/10 * * * * /usr/bin/diskmonitor
0 */4 * * * /usr/bin/diskwearoutstat
37 15 * * * /usr/bin/updatecheck -a
37 15 17 * * /usr/bin/phonehome_upload
40 * * * * /usr/bin/copy_rrd save

Environment

  • You have some security concern about cronjobs that you are not familiar with.
  • Default configuration of BIG-IP.

Cause

None

Recommended Actions

You may find some cron jobs scheduled in the BIG-IP system.

1-59/10 * * * * /usr/bin/diskmonitor

The diskmonitor utility is a script that runs periodically on the BIG-IP system to monitor disk use. It does the following:

  • Monitors BIG-IP system disk usage limits and disk usage growth rates on selected partitions. 
  • Sends warning and error logs to syslog when partitions are running out of space. 

For more information refer to: K8865: Overview of the diskmonitor utility

0 */4 * * * /usr/bin/diskwearoutstat

Cron task /usr/bin/diskwearoutstat runs for hardisk hardware health check.

37 15 * * * /usr/bin/updatecheck -a

It checks for and recommends the latest software updates for your BIG-IP system.

For more information refer to: K15000: Overview of the Automatic Update Check and Automatic Phone Home features

37 15 17 * * /usr/bin/phonehome_upload

It obtains product versioning, module provisioning, and hardware-related information.

For more information refer to: K15000: Overview of the Automatic Update Check and Automatic Phone Home features

40 * * * * /usr/bin/copy_rrd save

You may find "copy_rrd save" (/usr/bin/copy_rrd save) cron job scheduled in the BIG-IP system. It is because system stores historical performance data in an RRD database. 

RRD stands for Round Robin Database tool. The performance graph generated in Statistics > Performance is generated from RRD file stored in filesystem. The RRD files are constantly updated by the BIG-IP system for the latest performance data. To reduce the I/O overhead to hard drive the RRD files are stored and updated in a on-memory filesystem.

You can verify it by typing the following command:

The script /usr/bin/copy_rrd copies the RRD files from on-memory filesystem to hard drive for non-volatile storage. In the root cron table, the script is executed every hour (at the 48th minutes) to save the RRD files from memory to disk.
