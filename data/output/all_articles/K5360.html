Known Issue

This is the result of a known issue. If you start the Configuration utility in a browser window that is narrower than the minimum width of the menu bar, the full menu bar will not be displayed, even if you scroll horizontally.

F5 Networks Product Development tracked this issue as CR28330 and CR28331.

Workaround

To work around this issue, start your browser at full size and then resize the window to a smaller size after the Configuration utility has loaded.
