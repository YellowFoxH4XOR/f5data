Topic

Begining in ARX version 4.1.0, limited support was added to allow anonymous CIFS access. This support was added to support Kyocera printer and scanner devices. These devices require access to the CIFS IPC$ share. A new cifs anonymous-access CLI command was added to allow anonymous access at the namespace level. An Allow Anonymous Access check box was added to the Edit Namespace page in the GUI.

Note: CIFS anonymous access is disabled by default.

Note: Kerberos-only namespaces must be willing to accept NTLMSSP as there is no anonymous Kerberos authentication.

F5 Networks Product Development tracked this enhancement as ARX ID 31707.

Important: ARX versions prior to 4.1.0 did not support anonymous CIFS logons.

When a client attempts to access an ARX CIFS service anonymously with anonymous access disabled, a message will be logged to the syslog file (at the debug log level) that appears similar to the following example:

SESSNOANON: Anonymous logons are not allowed (client address 10.0.0.1, CIFS service share.ask.f5.com).
