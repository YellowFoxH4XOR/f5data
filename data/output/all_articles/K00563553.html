Description

When VMware View is requested for SSL client cert with 'require', VDI resources cannot be launched.
If SSL client cert has option "request" or "ignore" connection is successful.

Environment

  • BIG-IP v12.x and later
  • Client Certificate option is set to "require" in Client SSL profile
  • Native Horizon View client  is used for launching applications
  • Error is displayed : failed to retrieve SSL certificate

Cause

Native Horizon View client will not work against the backend that has client certificate set to "require".
The reason being, it always sends the very first broker request (get-configuration) over non-authenticated SSL connection.

This is done intentionally.

Recommended Actions

Client certificate over SSL handshake is only used for smart card authentication.
For this to work one has to set it to "request".
