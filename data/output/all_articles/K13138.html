Known Issue

The BIG-IP system does not report an error message when a user creates a SNAT object and a NAT object that share the same origin address.

This issue occurs when the following condition is met:

  • You add a SNAT object and a NAT object that shares the same origin address

Impact

The BIG-IP system may not translate the addresses as expected. As a result, connections using the affected SNAT and NAT object may fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system does not translate the address for traffic destined for the configured NAT
  • Connections using the SNAT or NAT object may fail

Workaround

To work around this issue, you can modify the affected SNAT or NAT object to use different origin address. To do so, perform the following procedure that applies:

  • Modifying the NAT object
  • Modifying the SNAT object

Modifying the NAT object

To modify the affected NAT object to use a different origin address, perform the following procedure:

Impact of workaround: None

  1. Log in to the command line.
  2. To modify the NAT object to use another origin address, use the following command syntax:

    bigpipe nat <IP address> to <NAT IP> {}

    For example:

    bigpipe nat 10.10.10.10 to 20.20.20.20 {}

  3. Save the modifications by entering the following command:

    bigpipe save all

Modifying the SNAT object

To modify the affected SNAT object to use a different origin address, perform one of the following two procedures:

Impact of workaround: None

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic >> SNATs >> SNAT List.
  3. Click on the name of the affected SNAT.
  4. Click on the conflicting origin address in the Address List box.
  5. To remove the highlighted origin address, click on the Delete button.
  6. Optional: Enter a different origin address in the Address List box and click the Add button.
  7. To save the modifications, click the Update button.

Command line

  1. Log in to the command line.
  2. To delete the conflicting origin address from the SNAT object, use the following command syntax:

    bigpipe snat <name> origins <IP address> delete

    For example:

    bigpipe snat MySNAT origins 10.10.10.10 delete

  3. Save the modifications by typing the following command:

    bigpipe save all
