Description

BIG-IP DNS is configured to allow recursion and intermittently is not responding to DNS queries ( on different FQDNs ) from a Symantec Message Gateway ( SMG ) device.

Environment

BIG-IP DNS which allows recursion
Symantec Message Gateway ( SMG ) device

Cause

It has been observed that the requestor's UDP payload size on the initial BIG-IP DNS request from the SMG device towards the BIG-IP is 512 Bytes.

This field is used by the requestor in order to inform how much data can accept.

Due to the previous BIG-IP DNS is truncating the answer, in order to conform to the client request.

Recommended Actions

From the BIG-IP DNS side you can configure a TCP DNS listener in order to manage responses which exceeds the maximum DNS UDP packet size of 512 bytes.
Alternatively  if a TCP DNS listener cannot be used then it should be investigated if f the UDP payload size on the DNS requests on the SMG appliance can be increased.
