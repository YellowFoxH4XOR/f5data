Note: For information about SSL session limits and how the BIG-IP LTM counts the number of SSL connections, refer to K6475: Overview of SSL session licensing limits.

Each BIG-IP 4.x system is licensed to provide a maximum number of SSL transactions per second (TPS). When calculating the number of SSL sessions, the BIG-IP system counts only new connections that have completed the SSL protocol handshake. The BIG-IP system does not count SSL sessions that are being resumed.
