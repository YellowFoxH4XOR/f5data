Topic

This article covers how to download, install, and run the preUpgradeCheck tool for BIG-IQ.

Important: Before you upgrade your BIG-IQ system, you need to perform the procedure in this article to ensure that the system is ready for the upgrade.

Important: If you are upgrading BIG-IQ Virtual Edition (VE) versions prior to 8.0, ensure that the VE instance has at least two NICs configured to avoid upgrade failures. For more information, refer to K54221096: A single NIC configuration is not supported prior to BIG-IQ VE 8.0.

Description

The preUpgradeCheck tool for BIG-IQ is a script that checks various aspects of the system such as CPU, memory, disk space, and data collection device (DCD) cluster health to ensure the BIG-IQ system and DCD cluster are ready for an upgrade.

F5 recommends that you download and install the latest version of the preUpgradeCheck tool before using the following procedure:

Downloading, installing, and running the latest version of the preUpgradeCheck tool

  1. Go to the Downloads on MyF5.
  2. In Account, if you have more than one MyF5 account, select the account you want.
  3. Select the check box to agree with the End User License Agreement and Product Terms.

    Note: The check box displays only when F5 does not yet have a record of you accepting these agreements.

  4. In Group, select BIG-IQ.
  5. In Product Line, select Centralized Management.
  6. In Product Version, select the version you want to upgrade to. For example, 8.4.2.
  7. Under Select a product container, select Utilities. The browser should display a list of files under Select a download file that should include the following:
    • F5_Networks_BIG_IQ_PreUpgradeCheck_Tool_README.txt
    • F5_Networks_BIG_IQ_PreUpgradeCheck_Tool-<version>.tar
    • F5_Networks_BIG_IQ_PreUpgradeCheck_Tool-<version>.tar.md5
    • F5_Networks_BIG_IQ_PreUpgradeCheck_Tool_README.txt.md5
  8. Under Select a download file, select a file that you want to download. You can download only one file at a time.
  9. At the bottom of the page, in Download locations, select the location nearest you.
  10. Select Download.
  11. Repeat steps 8 through 10 for the remaining files.
  12. Follow the latest instructions in the F5_Networks_BIG_IQ_PreUpgradeCheck_Tool_README.txt file (the release date appears at the beginning of the README file) to transfer, install, and run the tool.

    Note: Prior to installing the tool, you can verify the MD5 checksum by transferring the MD5 file to the BIG-IQ system and using the following syntax to perform the verification:

    md5sum --check F5_Networks_BIG_IQ_PreUpgradeCheck_Tool-<version>.tar.md5
