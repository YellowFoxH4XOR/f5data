Known Issue

Virtual servers may buffer ingress HTTP traffic inefficiently.

This issue occurs when the following conditions are met:

  • The virtual server references an HTTP profile.
  • The virtual server processes a series of smaller HTTP requests.
  • The pool members are slow to respond to SYN requests from the BIG-IP system.

Impact

The system may experience memory pressure and produce a core file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H521110 on the Diagnostics > Identified > High screen.
  • The BIG-IP system experiences degraded performance and temporarily fails to process traffic while the Traffic Management Microkernel (TMM) restarts.
  • The BIG-IP system logs messages to the /var/log/tmm file that appear similar to the following example:

    MPI failure due to out-of-memory
