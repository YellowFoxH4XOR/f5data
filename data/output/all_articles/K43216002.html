Environment

Relevant environmental factors specific to the topic

  • Trying to generate a qkview
  • BIG-IP LTM
  • There is rrd corrputed data in the system.

Cause

The rrd corrupted data in the system will cause the qkview process to get stuck.

Recommended Actions

Follow these steps to mitigate the issue:

  1. Log in into the BIG-IP CLI.
  2. Run the following command to verify the related processes to the show sys memory command:
ps |grep "show sys memory"
  1. Kill the processes related to this command with the following command syntax:
ps |grep "show sys memory" | gawk '{print("kill -9 " $1)}'
  1. Stop the stated deamon with the following command syntax:
bigstart stop statsd
  1. Determine the statistics file within statsd containing an Error message with:
grep 'rrd_update' /var/log/ltm | grep -w 'Error'
  1. Erase the statistic files with rm -rf /var/rrd/statistic_filename.
Example:
rm -rf /var/rrd/blade0cpu
rm -rf /var/rrd/access
  1. Start the stated daemon:
bigstart start statsd
  1. Verify its status:
bigstart status statsd
  1. Reboot the BIG-IP system
reboot
