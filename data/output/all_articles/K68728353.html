Description

A UCS backup cannot be generated using either the WEB UI or CLI, in both cases the process seems to never end.

  • Web UI hung with the process never finishing.
  • CLI hung, the process needs to be stopped with Ctrl+C to recover control of the CLI session.
  • There is no error message but sometimes it can show a generic timeout error.

Environment

  • iApp LX

Cause

This behavior is triggered due to a timeout of iApp LX rpm which takes more time to gather all the necessary data for the UCS file, the default value is 60 seconds to save this content as part of a UCS backup.

Recommended Actions

Impact of procedure: There is no negative impact to the device traffic by executing the following procedure.

Increase the system db iapplxrpm.timeout to some higher value so the main UCS process can collect the necessary data from iApp LX without timing out. 
To fix this behavior you will need to execute the following commands:

tmsh modify sys db iapplxrpm.timeout value 300
tmsh save sys config
bigstart restart restjavad
