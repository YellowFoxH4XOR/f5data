Known Issue

The sysInterfaceStatus SNMP OID includes the following incorrect interface states: disabled(2), and loopback(4). The sysInterfaceStatus OID should only return information about observable interface states, such as up/down, and not return information about administrative states, such as disabled.

For example, the incorrect states appear in the sysInterfaceStatus section of the /usr/share/snmp/mibs/F5-BIGIP-SYSTEM-MIB.txt MIB file:

sysInterfaceStatus OBJECT-TYPE
SYNTAX INTEGER {
up(0),
down(1),
disabled(2),
uninitialized(3),
loopback(4),
unpopulated(5)
}
MAX-ACCESS read-only
STATUS current
DESCRIPTION
"The current state of the specified interface.
up - has link and is initialized;
down - has no link and is initialized;
disabled - has been forced down;
uninitialized - has not been initialized;
loopback - in loopback mode
unpopulated - interface not physically populated."
::= { sysInterfaceEntry 17 }

This issue may results in incorrect responses when polling the sysInterfaceStatus OID. For example, the BIG-IP system reports both disabled interfaces and down interfaces as down

F5 Product Development tracked this issue as ID 223296 (formerly CR128678), and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, and Edge Gateway release notes.

Workaround

To differentiate between a disabled interface and a down interface, use the sysInterfaceStatus MIB in conjunction with the sysInterfaceEnabled. If an interface is reported down and enabled, the interface is down; if an interface is reported down and disabled, the interface is disabled.

For example:

Interface 1.4 is down

snmpwalk -v 2c -c public localhost F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus.\"1.4\"
F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.4" = INTEGER: down(1)
snmpwalk -v 2c -c public localhost F5-BIGIP-SYSTEM-MIB::sysInterfaceEnabled.\"1.4\"
F5-BIGIP-SYSTEM-MIB::sysInterfaceEnabled."1.4" = INTEGER: true(1)

Interface 1.5 is disabled

snmpwalk -v 2c -c public localhost F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus.\"1.5\"
F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.5" = INTEGER: down(1)
snmpwalk -v 2c -c public localhost F5-BIGIP-SYSTEM-MIB::sysInterfaceEnabled.\"1.5\"
F5-BIGIP-SYSTEM-MIB::sysInterfaceEnabled."1.5" = INTEGER: false(0)
