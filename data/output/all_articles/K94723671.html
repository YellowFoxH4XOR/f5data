K94723671: After upgrading BIG-IP from 13.1 to 15.1, ASM Application Event Logs are missing

Type
Support Solution
Published
2022-02-23
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.X, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.8, 15.1.1, 15.1.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K94723671

Description

After upgrading the BIG-IP system from version 13.1.x to 15.1.x, there are no local or remote Event Logs for legal or illegal requests for any applications or security policies.

When viewing the Security > Event Logs > Application > Requests page, no logs for violations and blocked requests are seen.


Environment

  • Upgrade to BIG-IP 15.1.x
  • Previously working security logging configuration

Cause

Unknown.


Recommended Actions

The following command can be used to restart the asm services which in many cases has resolved the issue of missing logs both from BIG-IP and remote logging.

Impact: This will disrupt traffic while the ASM services restart.

# tmsh restart sys service asm


Additional Information

None.
