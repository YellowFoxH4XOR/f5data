Known Issue

The Traffic Management Shell (tmsh) output may not display the model name of the BIG-IP system.

This issue occurs when all of the following conditions are met:

  • You deploy a new BIG-IP system or perform a Return Materials Authorization (RMA).
  • You are running an old software release, compatible to the BIG-IP platform that has a revised hardware part number since the official release of the software.

Each BIG-IP software release contains a database used to map platform hardware part numbers to a BIG-IP model name. The hardware part number may be revised after a BIG-IP software release occurs, due to the introduction of a new hardware feature. As a result, the revised hardware part number is missing from the database of the affected software release. Under such circumstances, if your BIG-IP system runs on the affected software release, the tmsh utility output will fail to display the model name of the system.

Impact

This is a cosmetic issue that may affect customers who run custom automation scripts that use the BIG-IP model name as a matching criteria.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tmsh show /sys hardware command output may appear similar to the following example:

    sys hardware platform {
        marketing-name D113
        platform D113

    In this example, the marketing-name field incorrectly displays the platform ID (D113) instead of the model name (for example, BIG-IP 10000) of this hardware platform.

Workaround

There is no workaround for this issue. If you use a custom automation script, you should take into consideration the relevant platform IDs instead of using the model name as the only matching criteria.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
