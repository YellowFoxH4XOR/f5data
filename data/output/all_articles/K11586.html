K11586: Changing the Maximum Cookie Header Length setting to a low value may result in false illegal cookie length violations

Type
Known Issue
Published
2010-07-22
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 10.2.0, 10.1.0
Source
https://my.f5.com/manage/s/article/K11586

Known Issue

This is the result of a known issue. The Maximum Cookie Header Length setting allows you to specify a maximum cookie header length for requests to the BIG-IP ASM virtual server. You can then configure the policy to trigger an alarm when a cookie exceeds the maximum length setting.

If you change the Maximum Cookie Header Length setting to a low value, such as 1, the BIG-IP ASM may trigger false illegal cookie length violations.

For example, if Maximum Cookie Header Length is set to a low value and the following two requests are sent from the client over the same TCP connection, the BIG-IP ASM triggers violations for both requests, although the second request does not contain a cookie header:

GET /document.html HTTP/1.1
Host: askf5.com
Cookie: askf5=1
Connection: keep-alive

GET /another_doc.html HTTP/1.1
Host: askf5.com
were: test
uu: test

This issue occurs because the BIG-IP ASM enables the is_cookie flag for the first transactions and the flag remains enabled for the second transaction.

F5 Product Development is tracking this issue as ID 324347 (formerly CR140984).

This issue has been fixed in BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP version 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for version 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing F5 Networks product hotfixes for BIG-IP version 10.x systems.

Workaround

You can work around this issue by performing one of the following procedures:

Disable the illegal cookie length violation

  1. From the Application Security menu, click Policy.
  2. Select Settings from the Blocking menu.
  3. Disable Alarm for the illegal cookie length violation.
  4. Click Save.
  5. Apply the policy.

Change the maximum cookie length value from 1 to a higher value

  1. From the Application Security menu, click Policy.
  2. Select Advanced from the Configuration drop-down menu.
  3. For the Maximum Cookie Header Length setting, enter a value in bytes.

    Note: The default maximum length is 8192 bytes.

  4. Click Save.
  5. Apply the policy.
