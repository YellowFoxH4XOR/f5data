Description

How to stop running other irules on a virtual server with multiple irules if condition in one irule is already met.

Environment

  • Virtual server 2 or more irules assigned
  • LTM

Cause

None

Recommended Actions

You could use the disable all event command which discontinues evaluating the specified iRule event, or all iRule events, on a particular connection.

event [<name>] [enable|disable] | [enable all|disable all]

Additional Information

Example:

when HTTP_RESPONSE {
  COMPRESS::method prefer gzip
  event disable
}
