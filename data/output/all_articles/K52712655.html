Description

When a new blade is inserted into a VIPRION, the software on the new Secondary blade is synced to be identical in version and location to the existing Primary blade. Successful installation of a new blade into a VIPRION can often require the software version on the new blade to be automatically changed to match the current blades. To ensure this automatic software synchronization is successful, at least two software volumes should be present on the VIPRION before new blades are inserted. More than two software volumes are not necessary. If the Primary blade has only one active volume and that volume is HD1.1/MD1.1, the software on the new blade cannot be upgraded.

Note: The installation of the new blade may succeed if the existing volume on the primary blade is other than HD1.1.

Environment

  • VIPRION
  • At least one blade currently present in chassis as Primary
  • Only software volume on current Primary HD1.1
  • Installation of new blade

Cause

Automatic software synchronization in a VIPRION system requires two volumes (the current active volume and one additional volume) present. F5 ships new blades with software present in volumes HD1.1 and HD1.2 with HD1.1 active. However, an administrator can remove all but the active volume, leaving only one. If the only volume present on the existing Primary is HD1.1, as part of the software sync for the new Secondary it will delete HD1.2 to match the Primary. When the Primary then attempts to change the Secondary's HD1.1 volume to match the Primary's HD1.1 volume, the upgrade action will fail. This is because HD1.1 is the active volume of the Secondary and a BIG-IP system's active volume cannot be upgraded. This will result in an "upgrade needed" message similar to the following:

# tmsh show sys software

Sys::Software Status
Volume  Slot  Product  Version    Build  Active          Status
---------------------------------------------------------------
HD1.1      1   BIG-IP   12.1.2  2.0.276     yes        complete
HD1.1      2   BIG-IP   14.1.0  0.0.116     yes  upgrade needed
 

Recommended Actions

  • Ensure that a VIPRION system has two (or optionally more) volumes are present before inserting any new blades. The software versions of the volumes do not matter, as long as it is version 11.0.x or later. However, the software image files to install the volumes do need to be present.
  • If your upgrade fails due to volume mismatch, a second volume with any software version needs to be installed. The same version as the active volume is recommended for ease of use. After this is installed on the Primary and Secondary, the Secondary will boot into that second volume, upgrade the formerly active volume to the desired version, and then boot back into the originally active volume.

    To create a second volume and install a software image on the new volume, go to System > Software Management > Image List. Select a software image to install, select Install, and specify the Volume set name. For example, HD1.2.
