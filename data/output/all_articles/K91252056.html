Description

The LTM virtual sever is not inserting the HTTP X-Forwarded-For header, despite the HTTP profile being configured to do so.

Environment

  • LTM vrtual server with HTTP profile, configured to insert the X-Forwarded-For header.
  • LTM virtual Server is also configured with ClientSSL and ServerSSL profiles configured for SSL Passthrough.

Cause

SSL Passthrough configuration does not allow the BIG-IP system to be able to modify the data inside the encrypted packets. 

Recommended Actions

If you must modify the data within the encrypted packets, SSL passthrough cannot be used. Reconfigured the SSL profiles to allow the BIG-IP virtual server to either offload or proxy the SSL handshake.
