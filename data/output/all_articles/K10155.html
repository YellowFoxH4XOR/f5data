K10155: The auto-migrate policy takes precedence over file and directory constraints

Topic

An auto-migrate policy configured for a share farm will take precedence over a constrain-files or a constrain-directories rule configured for the share farm. To ensure that file and directory constraints are enforced, a place-rule shoud be used instead of an auto-migrate policy.

Note: For more information about constrain-files, constrain-directories, place-rules, and auto-migrate rules, refer to the ARX CLI Reference Guide.
