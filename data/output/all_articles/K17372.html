Topic

This article provides information about the IP addresses and TCP/User Datagram Protocol (UDP) ports used by BIG-IP Edge Client for Windows client-side components.

Description

BIG-IP Edge Client for Windows utilizes various services to establish Network Access, App Tunnels and Optimized Applications, and Remote Desktops. Individual client-side components work together to provide each service when accessing the BIG-IP APM system. The following table outlines the client-side addresses and ports used by the BIG-IP Edge Client for Windows.

Recommendations

When planning deployments using BIG-IP Edge Client for Windows, you should ensure client-side firewalls do not block addresses or ports needed for BIG-IP Edge Client component communication.
