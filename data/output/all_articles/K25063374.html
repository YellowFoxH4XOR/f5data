Description

When using the F5 BIG-IP APM Dialup Entry/ Windows Logon Integration, user may find that they have to login twice to get to the Windows Desktop. 

Environment

  • BIG-IP APM
  • BIG-IP Edge Client
  • Windows 10 20H2
  • Dialup Entry/ Windows Logon Integration

Cause

By default the Windows Logon Screen has a 30 second time out before 

Recommended Actions

The actions or steps required to address the topic covered in the description.

1. Launch the Windows Registry Editor as an Admin user
2. Browse to HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Authentication\LogonUI
3. Add the DWORD (32-bit) Value, IdleTimeOut
4. Edit the IdleTimeOut registry key
5. Click the Decimal radio button
6. Assign a value of 600000 (this is 10 min in milliseconds)
7. Click OK
8. Log out as the user
9. Attempt to connect using the integrated logon
