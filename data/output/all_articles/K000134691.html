Description

If you are trying to import a certificate authority certificate and receive the following error message:

  • January 1 10:10:10 <BIG-IP hostname> crit tmm2[22992]: 01260027:2: Profile /Common/<Access policy name>- - cannot load Certificate Authority /config/filestore/files_d/Common_d/certificate_d/:Common:<Certificate name>: Unknown error.

Environment

  • BIG-IP

Cause

Unknown

 Recommended Actions

Re-generate the certificate and try uploading it again

None
