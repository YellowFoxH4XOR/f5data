Security Advisory Description

A read-after-free memory flaw was found in the Linux kernel's garbage collection for Unix domain socket file handlers in the way users call close() and fget() simultaneously and can potentially trigger a race condition. This flaw allows a local user to crash the system or escalate their privileges on the system. This flaw affects Linux kernel versions prior to 5.16-rc4. (CVE-2021-4083)

Impact

This flaw allows a local user to cause the system to become unresponsive or to escalate their privileges on the system.

Mitigation

To mitigate this vulnerability, you can allow root access to only trusted users over a trusted network.

For more information about securing access to BIG-IP systems, refer to K13092: Overview of securing access to the BIG-IP system.

To mitigate this vulnerability for F5OS, you should restrict CLI access to the root user.
