Description
In an Access Session report, the "Logon"  column is empty.

Environment

  • Access Policy in use.

Cause

  • The Logon name is stored in the mysql reporting database from the session variable session.logon.last.username. If this is not populated, the field will be blank.
  • The Access policy is set to log at a priority which is too low see   K44555523: BIG-IP APM session reports require access policy log level of Notice or higher


Cause (Alternate)

  • This has occurred after an upgrade to V16.1. session.logon.last.username  was correct. However the access report displayed an empty Logon Column and the logging remained at level "notice" when specified as "informational".

Recommended Actions

  1.  Ensure logging level is correct
  2.  Ensure the Policy is setting session.logon.last.username
  3.  Reboot the device
