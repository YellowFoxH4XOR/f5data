Published

Description

When trying to upload qkviews to iHealth or testing the user credentials from a BIG-IQ the following error is found on GUI:


Failed to authenticate to https://api.f5.com/auth/pub/sso/login/ihealth-api/: Login failed: General SSLEngine problem


Environment

  • BIG-IQ
  • Uploading qkview to iHealth
  • Proxy is configured between BIG-IQ and iHealth which rewrites the SSL Certificates for iHealth server

Cause

The rewritten certificate is not loaded in the Big-IQ Java trusted store.


 Recommended Actions

1) Taking a packet capture using below filter we can check the certificate sent by Proxy to BIG-IQ during Server Hello:


tcpdump -ni eth0 -s0 -vvv -w /shared/tmp/qkview_upload.pcap net 104.219.104.0/21

tcpdump -ni 0.0 -s0 -vvv -w /shared/tmp/qkview_upload2.pcap net 104.219.104.0/21


2) We see below DNS name :


 - api.f5.com

 - ihealth.f5.com


3) dig shows corresponding IPs :


[root@Active:Standalone] config # dig api.f5.com +short

104.219.111.164

[root@Active:Standalone] config # dig ihealth.f5.com +short

104.219.111.140


4) This copies the Certificate Authority file for iHealth into a file on your BIG-IQ:


# openssl s_client -showcerts -connect 104.219.110.164:443 </dev/null 2>/dev/null|openssl x509 -outform PEM > /var/tmp/API_F5_COM.pem

# openssl s_client -showcerts -connect 104.219.111.140:443 </dev/null 2>/dev/null|openssl x509 -outform PEM > /var/tmp/IHEALTH_F5_COM.pem


5) Remount /usr as rw :

# mount -o remount,rw /usr


6) Backup the existing CACert store:


# cd /usr/lib/jvm/java-1.8.0-openjdk-1.8.0.212.b04-0.el6_10.x86_64/bin; cp ../jre/lib/security/cacerts{,.org} ;


7) Load the certificate to the keystore


# ./keytool -keystore ../jre/lib/security/cacerts -storepass changeit -import -trustcacerts -noprompt -alias my_proxy_CA2 -file /var/tmp/API_F5_COM.pem

# ./keytool -keystore ../jre/lib/security/cacerts -storepass changeit -import -trustcacerts -noprompt -alias my_proxy_CA -file /var/tmp/IHEALTH_F5_COM.pem


You will get a return of \"Certificate was added to keystore\" if all went well.


5) Remount /usr and restart restjavad


# mount -o remount,ro /usr ; bigstart restart restjavad
