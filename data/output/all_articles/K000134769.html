Description

A relative addresses not allowed SCP error occurs when you are transferring files to or from the BIG-IP. There are two ways that you can run into this issue:

  • When using the SCP protocol with WinSCP to download a file from the BIG-IP you get the following error:
    SCP Protocol error: Invalid control record (r; elative addresses not allowed)
    Copying files from remote side failed.
  • When using the scp command on the BIG-IP command line to upload or download a file you get the following error:
    relative addresses not allowed

Environment

  • SCP on BIG-IP

Cause

The issue is tracked with two bug IDs. Review the following Bug Tracker articles to determine the affected and fixed BIG-IP versions:
  • Bug ID 1097193
  • Bug ID 1112109
Recommended Actions
To workaround the bug you can use SFTP with WinSCP or use absolute file paths with the scp command.

SFTP on WinSCP
Impact of procedure: Performing the following procedures should not have a negative impact on your system.
  1. From the WinSCP window select New Session.
  2. In the dialog box for File protocol choose SFTP if not already selected.
  3. Enter the hostname or IP address of the BIG-IP for Host name and ensure port 22 is selected in Port number.
  4. Enter your credentials for User name and Password.
  5. Select Login. The protocol in use should appear in the lower right corner of the WinSCP window.
The scp command on BIG-IP CLI
Impact of procedure: Performing the following procedures should not have a negative impact on your system.
  1. Log in to the BIG-IP command line
  2. Specify absolute paths when using the scp command to transfer files. For example:
    scp /config/bigip.conf root@10.1.1.30:/shared/tmp/
