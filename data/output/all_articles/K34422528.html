Description
This article explains why a DNS request to the BIG-IP with no matching Wide-IP might fail and how to correct it.

Environment

  • BIG-IP with DNS/GTM provisioned.
  • DNS zone exists on BIG-IP with no matching Wide-IP.

Cause
By default if a request comes in to the BIG-IP's DNS listener that doesn't match a Wide-IP, BIG-IP will try to send the request to the local BIND server.
If the setting "Use BIND Server on BIG-IP" is disabled in the DNS profile attached to the DNS listener this will not happen and the request may likely fail.

Recommended Actions

  1. Enable Use BIND Server on BIG-IP in the DNS profile attached to the DNS listener object.
    • Note: "Use BIND Server on BIG-IP" is enabled by default.

Additional Information
If BIND cannot be used in this fashion, please see the manual chapter on "Configuring DNS Express".
