Topic

You should consider using this procedure under the following condition:

  • You want to change the baud rate of the rSeries system serial console port.

Description

The default serial console baud rate on the rSeries system is 19200. F5 recommends that you set the baud rate on the connecting serial terminal to match the rSeries system serial console port baud rate, rather than modify the rSeries system serial port configuration. However, if you cannot modify the connecting serial terminal settings, you can set the serial console baud rate on a rSeries system by performing the procedure in this article.

At the point of publishing, the serial console port baud rate can be changed using the following methods:

  • The rSeries system front-panel LCD touchscreen
  • The rSeries system AOM command menu

Prerequisites

You must meet the following prerequisites to use the procedures:

  • If you are planning to use the rSeries system LCD touchscreen, you must have physical access to the rSeries system LCD screen.
  • If you are planning to use the rSeries system AOM command menu, you must have physical access to the rSeries system's serial console port.

Procedures

  • Setting the baud rate of the rSeries system serial console port using the LCD touchscreen
  • Setting the baud rate of the rSeries system serial console port using the AOM command menu

Setting the baud rate of the rSeries system serial console port using the LCD touchscreen

Impact of procedure: Setting the baud rate of the rSeries serial console port that is different from the connecting serial terminal may result in garbled console output. Ensure you have set the baud rate of the rSeries serial console port and the connecting serial terminal to match each other.

  1. Touch the LCD screen to activate the LCD menus.
  2. Select Setup. The screen displays Management, AOM Management and Baud Rate options.
  3. Select Baud Rate. The screen displays a list of baud rate options for you to select.
  4. Select the baud rate you want.
  5. Select Back to return to the previous screen.
  6. Ensure that you change the baud rate on your serial terminal to match the newly configured baud rate before attempting to connect via the rSeries serial console port.

Setting the baud rate of the rSeries system serial console port using the AOM command menu

Impact of procedure: Setting the baud rate of the rSeries serial console port that is different from the connecting serial terminal may result in garbled console output. Ensure you have set the baud rate of the rSeries serial console port and the connecting serial terminal to match each other.

  1. Connect to the serial console port of the rSeries system using a serial terminal and a null modem cable.
  2. Access the AOM command menu by simultaneously pressing the ESC+SHIFT+9 keys. The system displays a command menu similar to the following:

    AOM Command Menu:
    A --- Reset AOM
    B --- Set baud rate
    I --- Display platform information
    N --- Configure AOM network
    P --- Power on/off host subsystem
    R --- Reset host subsystem
    S --- Configure SSH server
    U --- Front panel USB port
    Q --- Quit menu and return to console
     
    Enter Command:

  3. Press B to select the Set baud rate option from the AOM menu. The system displays a list of baud rate options for you to select; similar to the following:

    Set console baud rate:
     
    1 -- 9600
    2 -- 19200 *
    3 -- 38400
    4 -- 57600
    5 -- 115200
     
    Select baud rate:

  4. Press the number representing your selection. The system prompts the following:

    Baud rate being set to 19200. Be sure to change the serial device baud rate to 19200 and press <Enter>, or garbled characters may appear.

    Press ENTER/RETURN to continue.

  5. At this time, the current console connection via the connecting serial terminal drops. You have to change the baud rate on your serial terminal to match the newly configured baud rate.
  6. Re-establish the serial connection to the controller.
  7. To exit the AOM command menu, press Q.
