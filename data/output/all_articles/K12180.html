Known Issue

This is the result of a known issue. When you use the ARX Manager GUI to specify a filer-type for an external-filer that you created using the command line, and you had not configured the external-filer to manage snapshots, the system does not retain the filer-type setting after you save the file server configuration. As a result, the external-filer configuration indicates that the filer-type is unknown.

Note: This issue occurs when you press the OK button to save the file server configuration, even if you did not make any changes to the file server configuration.

F5 Product Development tracked this issue as ID 339599 and it was fixed in ARX 5.2.0. For information about upgrading, refer to the ARX release notes.

Workaround

To ensure that the system maintains the filer-type setting when you edit the file server using the ARX Manager GUI, you must configure the external-filer to support snapshots using either the ARX Manager GUI or the command line. To do this, perform one of the following procedures:

Configuring the external-filer to support snapshots using the ARX Manager GUI

  1. Log in to the ARX Manager GUI.
  2. Click Filer Servers in the left navigation menu.
  3. Click the file server to be edited.
  4. Click Edit.
  5. Select the Supports Snapshots check box.
  6. Type the file server's management IP address in the Management IP Address field.
  7. Click OK.

Configuring the external-filer to support snapshots using the command line

  1. Log in to the ARX command line.
  2. Enable privileged mode by typing the following command:

    enable

  3. Enter global mode by typing the following command:

    global

  4. Enter the external-filer configuration mode by typing the following command syntax:

    external-filer <file server name>

  5. Specify the file server support snapshots by typing the following command:

    manage snapshots

  6. Configure the file server's management IP address using the following command syntax:

    ip address <IP_Address> management

  7. Exit the external-filer configuration mode and return to privileged mode by typing the following command:

    end
