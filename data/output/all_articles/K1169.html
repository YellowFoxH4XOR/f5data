K1169: Enabling iControl communications through VLANs in which port lockdown is enabled

External interfaces/VLANs are usually configured with port_lockdown enabled. If you choose to allow iControl to communicate with a port lockdown interface between the BIG-IP system and a remote iControl client, the global parameter, open_corba_ports, must be set to enable.

To set the open_corba_ports to enable, perform the following steps:

  1. From the BIG-IP local console, log in as root.
  2. Type the following bigpipe commands:

    bigpipe global open_corba_ports enable

    bigpipe save

Note: This parameter affects the ports only when port_lockdown is enabled on the VLAN, it does not affect the ports when port_lockdown is disabled on the VLAN. This parameter is set to enable by default in BIG-IP versions 4.0 and later. For security reasons, you may choose to disable this feature using the bigpipe global open_corba_ports disable command.

Corba ports 683 and 684 are used in iControl communication. For more information about these ports, refer to the iControl SDK documentation.
