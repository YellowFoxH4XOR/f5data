Known Issue

iControl calls issued from the BIG-IP system (localhost) may fail.

This issue occurs when the following condition is met:

  • The iControl call performs an action on a file object.

    For example, the DataGroupFile iControl interface can perform a specified action on an external data group configuration file.

Impact

The iControl call fails and generates an error message.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • iControl calls fail.
  • The iControl debug log file reports an error message similar to the following example:

    debug iControlPortal.cgi[13146]: LocalLB:DataGroupFile::create called by user "root"

    Note: You can enable/disable iControl debug logging using the following syntax:

    tmsh modify /sys db icontrol.loglevel value [debug/none]
