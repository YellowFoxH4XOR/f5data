Known Issue

The Simple Mail Transfer Protocol (SMTP) monitor may incorrectly mark nodes down.

This issue occurs when the following condition is met:

  • The SMTP server is configured with a multi-line greeting banner.

Impact

Pool members are marked down, and are unavailable to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Messages similar to the following example are logged to the /var/log/ltm file:

    notice mcpd[1234]: 01070638:5: Pool /Common/pool_smtp member /Common/10.22.12.1:25 monitor status down. [ /Common/monitor_smtp: down ]  [ was up for 0hr:1min:36sec ]
    err tmm1[12345]: 01010028:3: No members available for pool /Common/pool_smtp
  • If the debug option is enabled in the SMTP monitor configuration, messages similar to the following example are logged to the /var/log/monitors/<monitor_type>_<IP_address>.<port>.log file:

    tail /var/log/monitors/Common_monitor_smtp-Common_10.22.12.1-25.log

    (_Tcl /Common/monitor_smtp): Initial connection output 220-smtp-server.askf5.local ESMTP Multi-line test
    (_Tcl /Common/monitor_smtp): ERROR: failed to complete the transfer, Failed to connect mail server

Resolution

Status

F5 Product Development has assigned ID 503384 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can configure a single-line greeting banner in the SMTP server.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. Ensure that any modifications to your SMTP server are compatible with your environment.
