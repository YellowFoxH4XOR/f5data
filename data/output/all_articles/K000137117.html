K000137117: 'Check for Updates' button stuck spinning after upgrade to v17.1.x

Type
Support Solution
Published
2023-10-04
Updated
2023-11-02
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000137117

Description:

After upgrade to v17.1.x you might encounter different issues related to Live Updates:

  • 'Check for Updates' button stuck spinning and action not complete
  • Live Update configuration and list of update files reverts to default
  • List of update files will include only "Genesis" file

Environment:

  • ASM
  • Advanced WAF provisioned
  • Upgrade to v17.1.x

Cause:

All above symptoms are due to ID1076825.

Recommended Actions:

Restart tomcat after an upgrade to make a 'Check for Updates' button functional again

# bigstart restart tomcat

All other configuration related to Live Update which was set to default after an upgrade needs to be restored manually

Additional Information:

Although after an upgrade you will see only default "Genesis" file in the list of update files, the signatures fare stored in BIG-IP database and those installed in previous software version will preserve.
