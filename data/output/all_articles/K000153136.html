K000153136: BIG-IP LTM Compatibility with OpenSSL 3.x

Published
2025-08-22
Updated

Applies to

Source

Description

You are seeking information about whether any F5 BIG-IP LTM operating system version supports OpenSSL 3.x. This article explains the current state of OpenSSL support on BIG-IP platforms

Environment

  • Product: BIG-IP LTM

  • Platforms: All supported hardware and virtual editions

  • Software Versions: TMOS/BIG-IP 16.x, 17.x, and later

Cause

No BIG-IP software version supports OpenSSL 3.x. at the time of this article publication.

Answer/Recommended Actions

  • Monitor F5 release notes and the third-party software matrix for future updates regarding OpenSSL 3.x support.

  • No changes or upgrades are required on existing BIG-IP systems regarding OpenSSL 3.x at this time.

Additional Information

 The F5 third-party software matrix (K11398383) provides details on software versions and bundled third-party components.
