Description

When upgrading to version 14.x or later  and a virtual server is configured with SMTPS and Server SSL profiles, loading the configuration may fail to get the following error message:

01b40003:3: Virtual Server /Common/smtps_vs starttls-profile /Common/smtps_vs configuration error: SSL forward-proxy must be enabled
Unexpected Error: Validating configuration process failed

 

Environment

  • Upgrade to 14.x or later.
  • Server SSL profile.
  • SMTPS profile.

Cause

Since SMTPS profile enables StartTLS on serverside and upgrades the plaintext connection to the server to a secure one. Having both server SSL and StartTLS creates a conflict and will require SSL forward proxy enabled.

Versions earlier than 14.x BIG-IP doesn't check if SMTPS and Server SSL profiles are both configured, therefore a virtual server may use both. 

Recommended Actions

Remove Server SSL profile from the virtual server.

None.
