Description

When you create a new tenant on the F5OS platforms, the system sets the default state for the tenant to Configured and does not allocate any hardware resources (vCPU, memory, or storage) to the tenant. When you change the state of the tenant to Provisioned, the status indicates Provisioning while the system allocates the requested hardware resources to the tenant. It then changes to Provisioned when the allocation completes.

When you attempt to change the state of the tenant to Deployed, the system checks if the allocated resources are available for the tenant. If there are not enough resources for the system to start and run the tenant, the status of the tenant remains Pending until sufficient resources are available to meet the request. When sufficient resources are made available to meet the tenant's request, the status of the tenant indicates Running and the system starts the tenant. This behavior is by design.

You can view the status of a tenant using any of the following methods:

  • Use the webUI
  • Use the command line
  • Use the REST API

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

Use the webUI

  1. Log in to the partition webUI as the partition administrator for a VELOS system, or the webUI as the admin user for an F5 rSeries system.
  2. Go to TENANT MANAGEMENT > Tenant Details.
  3. For Tenant Name, select the tenant name.
  4. You can view the status of the tenant from Status.

Use the command line

  1. Log in to the partition command line as the partition administrator for a VELOS system or the CLI as the admin user for an rSeries system.
  2. To view the current state of the tenant, enter the following command syntax:

    show tenants tenant <name of the tenant>

    For example, you enter the following command to view the current state of the my-example-bigip-tenant tenant:

    show tenants tenant my-example-bigip-tenant

    Observe the status of the tenant from the command output. In the following example, the tenant is in the Deployed state but its status is Pending due to insufficient resources:

      ready-time    ""

Use the REST API

  1. Log in to a system with the curl and jq utilities installed. Alternatively, you can log in to the command line as the root user for the VELOS chassis or the rSeries system.
  2. To view the current state of the tenant, enter the following REST API command syntax:

    curl -X GET -H “Content-Type: application/yang-data+json” -sku <username>:<password> "https://<ip address>/api/data/f5-tenants:tenants/tenant=<tenant>"

    Note: Replace <username> and <password> with the administrative username and password to access the VELOS partition or the rSeries system and replace <ip address> with the management IP address of the VELOS partition or the rSeries system.

    For example, you enter the following REST API command to view the current state of the my-example-bigip-tenant tenant:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://192.168.85.36/api/data/f5-tenants:tenants/tenant=my-example-bigip-tenant"
