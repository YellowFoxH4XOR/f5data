Description

OIDC authentication may fail when two or more simultaneous auth attempts occur within the same web browser. The following error may occur:

OIDC ID Token validation error: nonce from token (xxx) does not match client (yyy)

Environment

NGINX Ingress Controller

OIDC authentication

Cause

Nonce authentication cookie value is overwritten

Recommended Actions

This is expected behavior by a web browser

To mitigate, avoid simultaneous OIDC authentication sessions within the same web browser

Additional Information

An authentication nonce is a randomly generated, unique value that gets assigned to every OIDC authentication request

The purpose of a nonce is to maintain authentication session integrity

When multiple, simultaneous OIDC authentication requests occur within the same web browser, the web browser will overwrite the value of the authentication nonce cookie received from the last authentication request

This means previous OIDC authentication request sessions will continue with an invalid nonce value, resulting in authentication failure
