Description

How do I determine if my BIG-IP system is using DNS:: based iRules command? You can do so by performing the procedure described in Recommended Actions section via CLI or the tmsh utility.

Environment

  • BIG-IP system
  • The root user access to CLI or an administrative user access to the tmsh utility.

Cause

Not applicable.

Recommended Actions

You can check if your BIG-IP system is using DNS:: based iRules command by performing the following steps:
  1. Login to your BIG-IP system as the root user.
  2. Check if there are any DNS:: based iRules command defined in an iRule by entering the following command:

    tmsh list ltm rule | grep "DNS::"

  3. If the command does not return anything, then it is safe to say there are no DNS:: based iRules command defined on your BIG-IP system and you can stop here.
  4. If the command returns an output that has DNS::, for example:

    set q "[DNS::question name]"
    DNS::return

    Then the next step is to find out which iRule contains these DNS:: based iRules command.

  5. Before you can find out which iRule contains these commands, you need to find out how many iRules you have on your BIG-IP system by entering the following command:

    tmsh list ltm rule | grep "ltm rule" | grep -v "ltm rule _sys"

    The output should list "ltm rule" followed by the iRule name and end with a parenthesis {. For example:

    ltm rule dns_server {
    ltm rule httprespbasedonURI {

  6. With the list of iRules, you can now proceed to find out which iRule contains these DNS:: based iRules command by entering the following command syntax:

    tmsh list ltm rule <iRule name> | grep "DNS::"

    You will repeat this command for each iRule. Using the example from the previous step, you will enter the following command:

    tmsh list ltm rule dns_server | grep "DNS::"
    tmsh list ltm rule httprespbasedonURI | grep "DNS::"

    The command that returns an output similar to step 4 is the iRule that contains the DNS:: based iRules command.

  7. Now that you have determined which iRule contains the command, you should find out if the iRule is in used by any Virtual Server. To do so, enter the following command syntax:

    tmsh list ltm virtual rules | grep "<iRule name>" -A 2 -B 2

    Using the previous examples and assuming that the dns_server iRule is the one containing the DNS:: based iRules command, you would enter the following command:

    tmsh list ltm virtual rules | grep "dns_server" -A 2 -B 2

  8. If the command does not return an output, then it is safe to say that the iRule is not in use and you can stop here.
  9. If the command returns an output that starts with "ltm virtual" followed by the Virtual Server name, then that Virtual Server is using DNS:: based iRules command. For example, the following example output shows that the dns-vs and dns-vs-vlan188 Virtual Servers are using DNS:: based iRules command in the dns_server iRule:

    ltm virtual dns-vs {
        rules {
            dns_server
        }
    }
    ltm virtual dns-vs-vlan188 {
        rules {
            dns_server
        }
    }

If you do not have the root user access but you have an administrative user (with administrator role) access to the tmsh utility, you can perform the same steps described previously except that you need to remove tmsh from each command since you will be in the tmsh utility. For example, instead of tmsh list ltm rule | grep "DNS::" , you should enter list ltm rule | grep "DNS::" as the administrative user in the tmsh utility.
