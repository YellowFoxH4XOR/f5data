K000150491: No Users or Groups Showing in XC UI After SCIM Provisioning

Type
Support Solution
Published
2025-03-20
Updated
2025-03-20
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000150491

Description

Customers using SCIM provisioning with Azure SSO observe that provisioned users and groups do not appear in the F5 Distributed Cloud (XC) UI, even after a successful SCIM synchronization.

Environment

  • F5 Distributed Cloud (XC)
  • Azure Single Sign-On (SSO)
  • SCIM (System for Cross-domain Identity Management) Integration

Cause

Provisioned users must log in at least once for their information to populate the XC interface.

Answer/Recommended Actions

For Users

  1. Ensure the user attempts to log in to the XC portal.
    1. This action will add the user to the UI if they have been provisioned via SCIM.

For Groups

  1. Confirm the user is assigned to a Group in Entra ID.
    1. In EntraID, assign the target user to a synchronized group.
  2. Ensure the Group’s Azure Object ID is added to XC:
    1. Navigate to User Management in the XC console.
    2. Add the group’s Azure Object ID under the appropriate SCIM configuration.

Additional Information

Users will not immediately appear in the F5 XC UI after SCIM provisioning until their first login.

Groups require explicit mapping in XC via their Azure Object ID to be listed.
