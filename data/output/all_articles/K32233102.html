Description
After upgrade to 14.1.0 or higher release, config-sync is not working as expected and configuration cannot be synchronized between device group members. Packet captures of TCP connection between device group members show large TCP segment sends from Device A is not received by Device B.
 

Environment

  • Device group members are inter-connected via Layer 2 switches.
  • BIG-IP devices set VLAN MTU to Jumbo frame size such as 9000 bytes
  • Switch has set its port MTU to 1500 bytes

Cause
As BIG-IP device sends TCP segment larger than Switch MTU limit, Switch discards the frame and config-sync action fails.
In 14.0.0 and prior, device group members use TCP MSS of 1448 bytes for sending data across CMI channel.
Starting in 14.1.0 and later, the TCP MSS is based on VLAN MTU less IP and TCP headers. For example, if VLAN MTU is 9000, then device will advertise TCP MSS as 8960.

Recommended Actions

Use a consistent MTU setting across the CMI communication path to avoid fragmentation and the need for Path MTU discovery mechanism.
