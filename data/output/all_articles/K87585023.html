Known Issue

When you create or modify an access policy resource assignment, the BIG-IP APM Configuration utility's visual policy editor may produce an error message. 

This issue occurs when the following condition is met:

  • You attempt to create or modify an access policy's Full Resource Assign agent.

Impact

You are unable to create or modify the Full Resource Assign agent.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to create or modify a Full Resource Assign agent, the following error message displays:

    Error While creating agent class (pCustomRAMapping_class is not defined)

Workaround

To work around this issue, if you are familiar with the bigip.conf file access policy definitions, you can manually modify the agent in the bigip.conf file.

Impact of workaround: You should perform the following procedure only during a maintenance window.

  1. Log on to the affected device.
  2. Using a text editor, open the /config/bigip.conf file.
  3. Locate the affected access policy.
  4. Locate the agents line of the access policy.
  5. Modify the agents configuration.
  6. Save the configuration changes to the /config/bigip.conf file.
  7. Load the configuration changes by typing the following command:

    tmsh load /sys config
