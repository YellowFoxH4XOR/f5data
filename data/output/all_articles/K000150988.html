K000150988: SIP monitor is failing

Type
Support Solution
Published
2025-04-23
Updated
2025-04-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000150988

Description

SIP monitor marking nodes down when getting 200 OK, but up when getting 404 from a different node.


Environment

SIP monitor

Multiple SIP servers


Cause

The monitor is configured to accept any response as valid, so the 404 response is marked up.

The 200 response code is valid, but that server is modifying the "From" header. The F5 expects SIP responses to have the same headers, and there is no built-in way to bypass this expectation.


Recommended Actions

Review the SIP server that is modifying the header and configure it to reply with headers that match the incoming packets.

Review the expected/desired status codes and update the monitor accordingly.
