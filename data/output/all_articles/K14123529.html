Description

BIG-IP will not allow an administrator to change a Self IP address or it's subnet configurations while they are in use within the BIG-IP's High Availability (HA) configuration (ConfigSync, Network Failover, and/or Mirroring). To make such configuration changes, the new self IP must first be added to the BIG-IP and its HA configuration. Only after the new self IP is added to the HA configuration can the original Self IP be removed from use within the HA config. To prevent a failover during this process, set the Standby device to Forced Offline when making these changes.

Note: If the original HA Self IP is removed from the HA Config before the new one is applied, the BIG-IP's statuses will change to disconnected and can only be recovered by rebuilding the HA pair.

Environment

  • BIG-IP configured for High Availability (HA).
  • Self IP is configured as a network failover address.
  • The new Self IP is already configured on the BIG-IP. Note: See "Creating a self IP address" in Manual Chapter: Self IP Addresses.

Cause

Self-IP address and subnet configuration cannot be changed while the Self-IP is still in use within the HA configuration. 

Recommended Actions

Impact of procedure: This should not have negative impact on your system. However, it is recommended that you create a backup and perform these action during a maintenance window.

In order to make the changes to the Self IP address you will need to first "Force Offline" the Standby unit per K15122: Overview of the Force Offline option. Then add the new HA Self-IP to the High Availability configuration (ConfigSync, Network Failover, & Mirroring) of the device. Afterwards, remove the original Self-IP.

  1. Log in to the Configuration utility of the device that requires the Self IP address change.
  2. Click on Device Management.  
  3. Click on Devices.
  4. Select Device name (self).
  5. Scroll to the bottom of the page and select Force Offline.
  6. Click the ConfigSync tab and change the address to the new self-IP.
  7. Click the Failover tab.
  8. Check the new Self-IP and select Add.
  9. Select the original Self IP address you are removing and click Delete.
  10. Click the Mirroring Tab and change the address to the new self-IP.

Once the original Self IP address is no longer used within the HA configuration it can be removed from the Big-IP's Network configuration.

  1. Navigate to Network > Self IPs > Check the original Self IP and click Delete.

Afterwards, bring this BIG-IP back online.

  1. Log in to the Configuration utility of the device that requires the Self IP address change.
  2. Click on Device Management.  
  3. Click on Devices.
  4. Select Device name (self).
  5. Scroll to the bottom of the page and select Release Offline.

Then repeat all the steps above on its peer to update its Self-IP.
