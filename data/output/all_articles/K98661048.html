Description

When an FQDN node returns multiple A records (multiple nodes for one DNS entry), the nodes are entered in MCPD as "_auto_"<ip address>.  After deleting the parent FQDN node, the "auto" generated nodes may remain listed on the BIG-IP.  This prevents the customer from manually using the IP address later as a node.

Environment

  • BIG-IP with FQDN node
  • FQDN node returns multiple A records

Cause

The child nodes remain after the parent FQDN node is removed.  

Recommended Actions

The child nodes can be removed manually.

  1. Log into the BIG-IP command line, tmsh shell.
    # tmsh
  2. Take note of the full name of the child node that is desired to be removed.
  3. Remove the node manually with the following command:
    # delete ltm node _auto_192.168.1.1
    (fill in the appropriate title here, starting with _auto_ and the correct IP address.  192.168.1.1 is simply an example).
  4. Save the configuration with the following command:
    # save sys config

None.
