Description

Seeing the error logs in ltm and gtm, and zrd restarting in loop

  • zrd restarting in loop

  • Error messages

in /var/log/ltm
err named[<PID>]: 27-Sep-2019 13:38:07.291 general: error: zone example.net/IN/external: NS 'a01.example.net' has no address records (A or AAAA)
in /var/log/gtm
err zrd[<pid>]: 0115020b:3: Errors in config file zone example.net/IN: loaded serial 22. zone example.net/IN: NS 'a01.example.net' has no address records (A or AAAA). 

Environment

  • BIG-IP DNS module
  • Having a domain name like example.net
  • BIG-IP hostname looks like a01.example.net in this domain
  • Without A records for  a01.example.net in BIND

Cause

Without A records for  a01.example.net

Recommended Actions

Adding A records for  a01.example.net in ZoneRunner through Configuration Utility .
