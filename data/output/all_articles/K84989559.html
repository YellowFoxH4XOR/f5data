Source
https://my.f5.com/manage/s/article/K84989559

Description

It was found that /var/ directory fills up due to autodosd.out file with a size in Gigabytes.

The following is a sample output:

-rw-r--r--. 1 root root 42G Jan 4 16:15 tmp/autodosd.out
-rw-r--r--. 1 root root 39G Jan 4 00:03 tmp/autodosd.out.1


Environment

  • After deleting autodosd.out it returns sometime later
  • Rebooting the device does not help

Cause

This is due to Bug ID 1069321: High iowait and pgstat wait every hour on the hour, due to excessive logging in autodosd.out


Recommended Actions

At the time of this article's publishing, no release is fixed.

Therefore, please open a Service Request and request for an Engineering Hot Fix.
 

Additional Information

None.
