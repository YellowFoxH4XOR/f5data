Description

When the httpd.conf config file for the httpd daemon is configured with non-default include settings, the BIG-IP Configuration Utility (webUI) can throw the error message below when accessing the Dashboard:

"The dashboard is disabled because the BIG-IP system's license has expired. To re-enable the dashboard, log into the BIG-IP Configuration Utility and confirm that the BIG-IP system is licensed. then reopen the dashboard"

Additionally, the BIG-IP Configuration Utility can fail to show any Performance Graphs, when the httpd.conf config file's include statements are non-default.

Environment

Relevant environmental factors:

  • BIG-IP
  • httpd.conf file containing a non-default include section
  • Dashboard throwing the above cited error
  • Performance Graphs failing to show any data

Cause

This issue with the Dashboard & Performance Graphs not working is caused by the httpd.conf config file's include section being configured to non-default values.

Recommended Actions

Restore the default include settings in the httpd.conf config file, as indicated below.

1. Log in to the BIG-IP via SSH/CLI and enter the TMOS shell using:
tmsh

2. Edit the httpd configuration by typing the following command, which will open the httpd config file in a VI editor where the file's contents can then be edited (tutorials on VI available online as needed):
edit /sys httpd

3. Modify contents of the "httpd" config file as shown below to restore the default config:
sys httpd {
      include "
              <Location />
              RewriteEngine On
              RewriteCond %{REQUEST_METHOD} ^(OPTIONS)
              Rewrite .* - [F]
              </Location>
              <Directory /usr/local/www/rrdstats>
                  Options +SymLinksIfOwnerMatch
              </Directory>
              <Directory /usr/local/www/mcpq>
                  Options +SymLinksIfOwnerMatch
              </Directory>
              <Directory /usr/local/www/rtstats>
                  Options +SymLinksIfOwnerMatch
              </Directory>
              <Directory /var/www/tmui/tmui/system/stats/images>
                  Options +SymLinksIfOwnerMatch
              </Directory>
              "
}

4. Restart httpd by issuing the command below at the BASH shell:
bigstart restart httpd

5. Then test the Dashboard & Performance Graphs to see if they start working normally, which they should.

None.
