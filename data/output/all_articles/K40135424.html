Known Issue

Network access split tunnel routes may be omitted on the client device.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM network access profile is configured to use split tunneling and DNS Exclude Address Space.
  • The client device established an access session using the BIG-IP Edge Client.
  • The installed BIG-IP Edge Client package includes the DNS Relay Proxy Service.
  • The client device accesses destinations defined in the DNS Exclude Address Space.
  • The client device terminates the access session.
  • The client device establishes a new access session in less than one minute from the previous session's termination. 
  • The client device attempts to access destinations defined in the DNS Exclude Address Space.

Impact

The client device is unable to access destinations specified in the DNS Exclude Address Space.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view traffic specified by the DNS Exclude Address Space, you notice that the traffic is sent through the network access tunnel.
  • When you view the route table of the client device, you notice there are no specific IP routes for the destinations specified in the DNS Exclude Address Space.
  • When you terminate the access session and wait at least one minute before you initiate a new access session, split tunnel routing functions as expected.

Resolution

Status

F5 Product Development has assigned ID 671151 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table.

Workaround

To work around this issue, you can delay initiating a new access session by at least one minute after the previous access session terminates. 

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
