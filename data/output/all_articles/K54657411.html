K54657411: Microsoft Defender Smartscan displays warning when installing a Edge Client or Components package

Published

Applies to

Source

Description

This solution will explain this warning message and how to resolve the issue.

  • F5 APM components package fails to install without a warning message from Microsoft Defender Smartscan.
  • Microsoft Defender Smartscan with display the following warning message:
"Microsoft Defender Smartscan prevented unrecognized app from starting. Running this app might put your PC at risk."

Environment

  • Windows OS version 10 or 11.
  • Microsoft Defender
  • APM client components package.
  • APM

Cause

The F5 client components are signed individually, but the installation package itself (.exe) is not.

Recommended Actions

Sign the F5 client components package using an internally generated Certificate or with a 3rd party Certificate.

How to sign an app package using SignTool

None.
