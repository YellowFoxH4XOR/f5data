Topic

When you configure the cookie hash persistence method, the hash consistently maps a cookie value to a specific pool member. When the client obtains the cookie and returns to the site, the BIG-IP system uses the cookie information to return the client to the given pool member. With this cookie persistence method, the web server must generate the cookie.

Note: For more information about the cookie hash persistence method, refer to K6586: Overview of cookie hash persistence.

Configuring cookie hash persistence

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Persistence > Create.
  3. Specify a name for the new Persistence profile.

    For example:

    my_hashCookie

  4. For Persistence Type, select Cookie.
  5. For Cookie Method, select the Custom check box.
  6. From the Cookie Method menu, select Cookie Hash.
  7. Under Custom, select the following check boxes:
    • Cookie Name
    • Hash Offset
    • Hash Length
    • Timeout

    Additionally, you can select the following optional items after the cookie persistence profile has been created:

    • Match Across Services
    • Match Across Virtual Servers
    • Match Across Pools
8. Specify the Cookie Name, which is the name of the existing cookie set by the server.
9. Specify the Hash Offset, which is the number of characters in the cookie to skip before calculating the hash value. The ASCII value of each character is a byte in length. The default value is 0 (zero).
10. Specify the Hash Length, which is the number of characters to use when calculating the hash value. The default value is 0 (zero).

Note: The following behavior occurs if the Hash Offset and Hash Length are given specific values:

Hash Offset = 0
Hash Length = 0
Result: The entire cookie value is used.

Hash Offset = <Any value other than 0>
Hash Length = 0
Result: The value of the cookie beginning with the offset character until the end of the cookie is used.

Hash Offset = 0
Hash Length = <Any value other than 0>
Result: The value from the start of the cookie until the length, as specified by the Hash Length value is reached, is used.

11. Specify the Timeout in seconds or choose Indefinite. If you select Indefinite for the Timeout value, the persistence entry never times out.

Important: The Timeout value must be greater than zero for cookie hash persistence to work properly.

12. Click Finished.

The new cookie hash persistence profile is now available.
