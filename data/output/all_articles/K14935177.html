Description

After the HTTP analytics profile is created and associated with the virtual servers, the information in analytics does not appear.

Environment

  • HTTP analytics profile.
  • BIG-IP LTM/AVR

Cause

Unknown

Recommended Actions

Restart the avrd service from the command line of the device:

tmsh restart /sys service avrd

There should be no impact on traffic on running this command.

None
