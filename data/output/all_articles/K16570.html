Known Issue

A BIG-IP AAM or BIG-IP WebAccelerator enabled virtual server connection may be reset for a request with an If-Match header.

This issue occurs when all of the following conditions are met:

  • The acceleration policy node that matches the request is configured with No-Proxy.
  • The acceleration policy node that matches the response is configured with Always Proxy.

Impact

Affected accelerated connections are reset.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • An initial matching request (not in cache) is successful, but subsequent requests are reset.
