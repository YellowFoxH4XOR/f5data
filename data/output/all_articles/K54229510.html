K54229510: 01310012:6: ASM bad request: event code I4040 Request has an unknown HTTP selector:

Type
Support Solution
Published
2021-12-10
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.X, 14.1.4, 14.1.3, 14.1.2, 14.1.5, 14.1.0
Source
https://my.f5.com/manage/s/article/K54229510

Description

 The issue occurs after the update of all the security policies using automated deployment with Ansible

Environment

  • BIG-IP ASM
  • ASM synchronization 

Cause

Unknown at the time of publication  
 

Recommended Actions

Please, run the following command on both devices.

pkill -f asm_config_server

Impact: this will restart asm_config_server on the units in the device group. Impact of workaround: Performing the following procedure should not have a negative impact on your system.
