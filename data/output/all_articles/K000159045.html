K000159045: BIG-IP VE unresponsive, VMware console displays "login incorrect"

Type
Support Solution
Published
2026-03-06
Updated
2026-03-06
Source

Description 

BIG-IP VE in a cluster fails to boot and is inaccessible.

VMware console displays a persistent "login incorrect" message without presenting a login prompt.

The VE BIG-IP cannot be accessed through management interfaces and only console access was responsive but inaccessible.

 

Environment 

  • BIG-IP LTM Virtual Edition
  • VMware Hypervisor host

 

Cause 

Extremely high latency on the hypervisor host interfering with the boot process, causing the VE BIG IP to become unresponsive, both GUI and CLI access.

 

Recommended actions

  • Power cycle affected BIG-IP LTM VMs via VM console to restore functionality.
  • Migrate BIG-IP LTM VMs to dedicated, low-latency storage to prevent future boot and performance issues.
  • Monitor storage latency and VM performance to ensure continued stability.
