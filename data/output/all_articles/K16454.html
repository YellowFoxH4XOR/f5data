Known Issue

The BIG-IP system may experience a kernel panic when using the telnet utility.

This issue occurs when the following condition is met:

  • You use the telnet client utility on the BIG-IP system.

    For example, this condition exists in configurations that use an external monitor to call the telnet client.

Note: The BIG-IP system does not include telnet server software.

Impact

The BIG-IP system temporarily fails to process traffic, while it recovers from rebooting, as a result of Linux kernel panic. Systems configured as part of a high availability (HA) group may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to the standby system if configured for HA.
  • Messages similar to the following example are logged to the /var/log/kern.log file:

    crit kernel: kernel BUG at drivers/char/n_tty.c:1713!
