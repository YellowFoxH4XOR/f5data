K3000: The bigpipe pool command cannot be used to define a fallback host with a URI

Known Issue

The BIG-IP system reports a syntax error if you attempt to define a fallback host with a URI.

For example, the following command syntax reports an error:

bigpipe pool <poolname> modify { fallback http://192.1.1.1/index.html }

If you specify only a host and no URI path, the command works correctly.

For example, the following command syntax specifies a host, but does not contain a URI path:

bigpipe pool <poolname> modify { fallback http://192.1.1.1 }

F5 Product Development tracked this issue as CR30505 and CR30506. This issue will most likely not be fixed in future releases of the product. For more information about this CR, refer to the BIG-IP Release Notes.

Workaround

To work around this issue using the Configuration utility, configure the fallback options for the pools.

To work around this issue from the command line, use one of the following enclosed modify statement examples:

  • bigpipe pool <poolname> modify { fallback \"http://192.1.1.1/index.html\" }
  • bigpipe pool <poolname> modify '{ fallback "http://192.1.1.1/index.html" }'
