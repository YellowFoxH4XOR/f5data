K000138597: Recover a revoked license

Type
Support Solution
Published
2024-02-14
Updated
2024-02-14
Source
https://my.f5.com/manage/s/article/K000138597
Description

The Re-activate button for your license sits next to the Revoke button. This very close proximity may bring about a situation where the wrong button is clicked.

Environment

If that happens the BIG-IP will lose the configuration stored in RAM to run the BIG-IP and cannot re-load it until the situation with the license is rectified.

Cause

Without a valid license the BIG-IP will not be able to access/load the configuration files in RAM and will thus not be able to process your traffic.

Recommended Actions

The situation can be rectified because while the various .conf files are no longer accessible due to the revocation of the license all the files needed are still in the 'config' directory. To access the license file and re-activate the license follow these steps...
  1. Establish access to the BIG-IP via ssh. This will need to be done with the default root account.
  2. When the session starts it should default into the bash shell in the config directory. If for some reason it does not then:
    1. If it opens up in tmsh then you will need to enter the bash shell. Depending on the emulator you are using for access use either the command quit or bash to enter the bash shell. The quit command is the preferred method, but for some emulators that will close it.
    2. If it opens in another directory or you find yourself in another one then cd into the config directory...cd /config
  3. There are 2 ways to retrieve the base registration key that is in the license file in that directory...
    1. The first way is to try this command...grep Registration /config/bigip.license
    2. The second is to open the license file and review it for the Registration key. The safest way to do that is to simply 'cat' the file and look for the section titled "Registration Key:"... cat bigip.license
  4. Once you have the key you can return to the GUI and enter it in at System >> License in the section titled "Base Registration Key". You may have to click the 'Edit' button if it is greyed out to do so. Once that has been done you can choose the Activation Method.
    1. If the BIG-IP has internet connectivity and the traffic to the F5 licensing server is not blocked you can choose Automatic and click 'Next'. It will likely take a few minutes.
    2. If the BIG-IP does not have access to the internet and/or the F5 licensing server choose 'Manual' and click 'Next'.
      1. Copy the Dossier.
      2. Click the link in the section titled "Step 2: Licensing Server" and it will open a tab. Paste the Dossier into the box, accept the EULA (if it asks for it) and click 'Next'.
      3. Copy the license and go back to the BIG-IP GUI and enter it into the section titled "Step 3: License" and click 'Next'.
      4. The license should now load and your configuration.
