Description

  • You received the error - Replace not allowed since there is a newer version of resource while trying to save a new configuration
  • Below is the attached error -

Environment

  • F5® Distributed Cloud (XC) Console

Answer/Recommended Actions

  • This error means the Load Balancer object that you were editing has expired, because someone else edited the configuration at the same time.

  • When you open LB config from UI, the config loads via API. If someone else edited the LB before you save, you will get this error that current LB config is old.

Cause

  • Two customers tried to edit console configuration at the same time.

 

Additional Information

 

  • It also might happen when user created a new Load Balancer, LB will try to fetch the Certs, CNAME etc.

  • During this time system may renew the config as well.
