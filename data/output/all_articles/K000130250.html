K000130250: Virtual server is showing up however pool is down

Type
Support Solution
Published
2022-12-16
Updated
2022-12-16
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000130250

Description

Virtual Server is marked up however pool assigned is marked down.

 

Environment

BIG-IP

Pool iRule

 

Cause

Basically if you use Pool pool_name then it will contribute to status but if you do my_pool=pool_name and then pool $my_pool it won't affect the pool status. More information

K73440174: How referenced pools in iRules affect VIP status

 

Recommended Actions

  • You can modify your iRule, i.e. If you initially has this iRule:

 

when HTTP_REQUEST {

if { [HTTP::host] starts_with "server1" } {

pool server1

}

else if { [HTTP::host] starts_with "server2" } {

pool server2

}

}

 

You can change like this:

 

when HTTP_REQUEST {

if { [HTTP::host] starts_with "server1" } {

set new_pool1 server1

pool "$new_pool1"

}

else if { [HTTP::host] starts_with "server2" } {

set new_pool2 server2

pool "$new_pool2"

}

}
