Issue

Error Message

012a0013:2: Blade <blade_number> hardware sensor critical alarm: <message>

In this error message, note the following:

  • The <blade_number> is the number of the blade.
  • The <message> is the alarm message.

For example:

012a0013:2: Blade 1 hardware sensor critical alarm: Power supply 1 GPIO status: Bad

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • A sensor gets an excessively high temperature reading.
  • A sensor gets an excessively high or excessively low voltage reading.
  • External power is disrupted to a power supply on the BIG-IP system.

Impact

This message indicates that a hardware sensor reported a potentially critical condition that could indicate a loss of power or a faulty hardware component.

Recommended Actions

If the error message occurs only once and cannot be explained by a known external power event, you can review the log files for any signs of daemon restarts or other transitory events that may have caused the system to log the message. If the error message is logged repeatedly, you should perform an End-User Diagnostic (EUD) to identify any related hardware issues. For more information about performing an EUD, refer to the End-User Diagnostics Release Notes.
