Description

After installing FAST (1.23.0-1) and AS3 (3.42.0-5)

Navigate to iApps ›› Application Services : Applications LX shows "F5 Application Services Templates" link.

Click the "F5 Application Services Templates" link throws the below error:

Error fetching templates: Failed to get data from /mgmt/shared/fast/templatesets?userAgent=FASTGUI/NA: 404 Not Found Public URI path not registered: /shared/fast/templatesets

 

Environment

  • AS3
  • BIG-IP FAST
  • BIG-IP version 15.x

Cause

Installing BIG-IP FAST RPM first and then installing AS3 RPM causes the error:
"Failed to get data from /mgmt/shared/fast/templatesets?showDisabled=true&userAgent=FASTGUI/NA: 404 Not Found"

 

Recommended Actions

When installing F5 BIG-IP FAST on the BIG-IP you should first install the AS3 RPM and then install the F5 BIG-IP FAST RPM. If the installation is not in this order then you will get an error

To recover from the error uninstall AS3 and BIG-IP FAST RPM and then install it in correct order.

Note: You must use the built-in 'admin' user , other user won't work.
