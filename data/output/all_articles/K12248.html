Known Issue

This is the result of a known issue. When a client SSL profile is configured to use compat ciphers, or if the BIG-IP system selects a compat cipher during the SSL handshake, the ServerHello message sent by the BIG-IP system incorrectly indicates that TLS session tickets are supported. As a result, the client may attempt to resume the SSL session at a later time by presenting a TLS session ticket, causing the BIG-IP system to silently discard the request. When this issue occurs, the client observes intermittent connectivity issues when contacting the virtual server.

Note: For more information about compat ciphers, refer to K11444: SSL ciphers supported on BIG-IP platforms in version 10.x.

F5 Product Development tracked this issue as ID 337378 and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the the BIG-IP LTM, ASM, PSM, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
