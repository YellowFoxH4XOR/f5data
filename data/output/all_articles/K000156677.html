Description

The F5 BIG-IP Advanced WAF Bot Defense Microservice Automated Threat Detection feature may not block requests immediately after the configured threshold is exceeded.

Environment

Adv.WAF

Cause

DOSL7D_BOT will push entries to dosl7d_bot_anomaly_engine every 2 seconds. Therefore, the system may appear to allow a higher number of requests than expected, which can create the perception that the Automated Threat Detection settings are being bypassed.

Recommended Actions

It is important to clarify that this behavior is not a configuration or tuning issue, but rather an architectural limitation of the current system design. At this time, no direct recommendation can be made to eliminate the mismatch.

Additional Information

In a multi-blade cluster, the primary slot plays a central role by enforcing the counter logic within the microservice. This ensures that traffic limits and thresholds are consistently monitored and applied across the cluster.

The secondary slot supports this operation by transmitting records at a fixed interval of every two seconds. These records contain request counts that are synchronized with the primary slot through the DOSL7D_DB_SYNC mechanism.

The primary slot is responsible for evaluating whether the defined thresholds have been exceeded. These thresholds are calculated based on two inputs: (1) the requests directly handled by the primary slot, and (2) the request counts relayed from the secondary slot. Once the aggregate counters surpass the configured thresholds, the primary slot initiates a process that sends publisher records to the secondary slots, enabling enforcement across the cluster.

However, due to the inherent synchronization delay between the slots, a temporary mismatch may occur. Specifically, there can be a lag in (a) syncing all request records from the secondary slot to the primary slot, and (b) propagating the enforcement actions from the primary back to the secondary slot. During this short window, the system may appear to allow a higher number of requests than expected, which can create the perception that the Automated Threat Detection settings are being bypassed.
