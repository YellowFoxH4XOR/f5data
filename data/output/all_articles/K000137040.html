K000137040: BIGIP LTM Management-Ip is not compatible as a BIGIP DNS/GTM Server

Type
Support Solution
Published
2023-09-28
Updated
2023-12-20
Source
https://my.f5.com/manage/s/article/K000137040

Description

When adding LTM devices to the DNS/GTM Server list using the management-ip address, virtual server status is not reported correctly.


Environment

Adding BIGIP LTM to BIGIP DNS/GTM to the server list


Cause

When management-ip addresses are used to import BIGIP LTM devices into BIGIP GTM/DNS, they will discover fine, however will not participate in iquery updates and virtual server status will not be correct.

Recommended Actions

Must use self-ip addresses for server ip addresses in GTM
