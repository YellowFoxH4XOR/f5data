Description

User see different interpretation of Edge Client version on Windows and Edge Client itself.

 Environment

  • BIG-IP APM
  • Windows

 Cause

"Version number" from (Control Panel >> Uninstall) is property "ProductVersion" obtained by Windows Installer from the installation file. It use to be encoded as "major.minor.build". Following string depends on how companies encode the product version of the software in the installation file. 

 Recommended Actions

K13757: BIG-IP Edge Client version matrix  indicates the right ways to locate the version number of BIG-IP Edge Client on Windows:

1) Using Windows Explorer

  • Log in to the Windows client system.

  • Open Windows Explorer.

  • Go to the F5 VPN directory; the default installation is in "c:\program files\"

  • Right-click the f5fpclientW.exe file.

  • Select Properties.

  • Select the Details tab.

  • The version is shown in the Product version field.

2) Using Edge Client Application

  • Log in to the Windows client system.

  • Launch the BIG-IP Edge Client application.

  • Select View Details.

  • Select the Miscellaneous tab.
