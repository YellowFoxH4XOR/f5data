Description

The following error is displayed in the Configuration utility, when trying to view or edit TXT record via ZoneRunner:
"Error trying to access database"

Environment

  • BIG-IP DNS
  • Zonerunner
  • TXT Records

Cause

Some TMOS versions contain a bug which prevents ZoneRunner from displaying records with the '%' character in them.

Recommended Actions

Avoid using % in TXT records or update to 15.1.0+

Additional Information

Only the following special characters are allowed: period, asterisk, forward slash, dash, colon, underscore, question mark, equals, at sign, comma, ampersand and double quote (.*/-:_?=@,&")"
