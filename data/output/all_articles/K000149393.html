K000149393: Auto-populate option for the FQDN pool member is not working as expected

Type
Support Solution
Published
2025-02-04
Updated
2025-02-04
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.X, 15.1.9, 15.1.10, 16.1.4, 16.1.5, 17.1.2, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000149393

Description

After creating a pool with FQDN pool member having auto-populate enabled, there is only auto-created member, despite DNS server resolves FQDN with 2 IP addresses.

Environment

  • BIG-IP LTM
  • FQDN pool member

Cause

The pool is configured with autopopulate enabled, but autopopulate option is disabled on ltm node level.

ltm pool /Common/test_FQDN {
    members {
        /Common/example.com:80 {
            fqdn {
                autopopulate enabled  <-------
                name example.com
            }
        }
    }
    monitor /Common/http
}

ltm node /Common/example.com {
    address ::
    app-service none
    connection-limit 0
    description none
    dynamic-ratio 1
    ephemeral false
    fqdn {
        address-family ipv4
        autopopulate disabled  <------
        down-interval 5
        interval 0
        name example.com
    }
    logging disabled
    metadata none
    monitor none
    partition Common
    rate-limit disabled
    ratio 1
    session user-enabled
    state fqdn-up
}

With this configuration, the system resolves a DNS query for the FQDN of the node with the single IP address associated with the FQDN.

Recommended Actions

To solve the issue follow the below steps:

  1. Remove the node from the configuration of the pool/pools and remove the node from BIG-IP.
  2. Recreate the node and make sure it has auto-populate enabled.
  3. Add a pool member choosing FQDN Node from FQDN Node List. 
  4. Use Auto Populate Enabled option for the pool member.

OR 

  1. Remove the node from the configuration of the pool/pools and remove the node from BIG-IP.
  2. Add a pool member using New FQDN Node option. 
  3. Use Auto Populate Enabled option. This setting will be inherited by the newly created node.

Additional Information

In versions affected by Bug ID 1077405 FQDN ephemeral pool members are not created if pool member autopopulate enabled, but node autopopulate disabled.
