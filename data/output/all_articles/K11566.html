Known Issue

This is the result of a known issue. In an iRule, the argument for the TCL catch command should be surrounded by curly braces ( { } ). If the argument is incorrectly surrounded by square brackets ( [ ] ), the command is interpreted as a command object and passed to catch. As a result, TMM may crash and dump core.

For example, the following line is incorrect because it does not follow TCL specifications:

if { [catch [session lookup uie $sessionkey]] } {

The line should appear with curly braces, similar to the following example:

if { [catch {session lookup uie $sessionkey}] } {

Note: The TCL catch command is used to handle unexpected or unallowable conditions that may develop during a program's run time. The command attempts to perform a certain operation and traps any unexpected errors, preventing the program from crashing and allowing it to continue running. For more information, refer to the following location. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://www.tcl.tk/man/tcl8.5/TclCmd/catch.htm

Note: This issue does not affect BIG-IP version 9.x, where the TCL catch command accepts arguments between both curly braces and square brackets.

F5 Product Development is tracking this issue as ID 248009 (formerly CR141080).

Workaround

You can avoid this issue by ensuring that you surround the argument for the TCL catch command with curly braces.
