K000136921: Brute Force detected failed login attempts exceed set threshold value

Type
Support Solution
Published
2023-09-20
Updated
2024-07-10
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000136921

Description

The number of failed login attempts for the Brute Force Attack Prevention security feature has gone beyond the detected failed logins / threshold value limit set.

Environment

  • ASM 
  • Brute Force Attack Prevention

Cause

Brute Force Detected Failed Logins / Threshold Event Log violation counters are reporting / working as intended.

Recommended Actions

You can lower the threshold value a bit from the initial value you want. However, be aware that the mitigation action you set might be activated by the lower value.

Additional Information

A Distributed Brute Force attack is detected if the number of failed login attempts for the specified login page is above the configured threshold. For example, if the threshold is set to (7), the first mitigation occurs after the threshold number has been reached which may be (8) or (9). This is expected behavior.
