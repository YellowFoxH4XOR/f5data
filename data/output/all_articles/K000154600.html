K000154600: VELOS - Console on Velos Arrow key not working as expected on GRUB

Type
Support Solution
Published
2025-09-04
Updated
2025-09-04
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.6.X, 1.8.X, 1.8.1, 1.8.0, 1.6.2, 1.6.1, 1.6.0, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000154600

Description

When navigating the GRUB menu on F5 VELOS systems, using the arrow keys (particularly the down arrow) may not work as expected. Pressing the down arrow can cause “[B” characters to appear instead of moving the selection, and the display may revert to showing only the boot line.

Environment

  • Product: F5OS - Chassis
  • Software Version: 1.6.x, 1.7.x, 1.8.x
  • Affected Component: VELOS console (serial console)
  • Scenario: Interacting with GRUB menu (e.g., for password recovery)

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1813721

Recommended Actions

Use SSH to connect to the console for more reliable navigation.

  • In GRUB, use these keyboard shortcuts:
    • Ctrl-n: Move down
    • Ctrl-p: Move up
    • Ctrl-f: Move right
    • Ctrl-b: Move left
    • Ctrl-h: Delete character left of cursor (if backspace does not function)

In addition, the grub.cfg file can be modified to make the arrow keys work.

  1. Connect to the controller CLI as root
  2. Edit boot/efi/EFI/BOOT/grub.cfg

    vi boot/efi/EFI/BOOT/grub.cfg

  3. Remove these lines:

    serial --speed=115200
    terminal_input serial console
    terminal_output serial console

  4. and replace them with:

    terminal_input console
    terminal_output console

  5. Save the changes
