K000135755: Tenant not starting and pods report "failed to pull image" from port 2000 registry

Source

Description

Tenant is not starting on rSeries platform, stuck on:

Allocating resources to tenant is in progress

Reviewing the output of kubectl get pods --all-namespaces and kubectl describe pods --all-namespaces reveals that images cannot be pulled from the port 2000 Docker registry:

Failed to create pod sandbox: rpc error: code = NotFound desc = failed to get sandbox image "localhost:2000/rancher/pause:3.1": failed to pull image "localhost:2000/rancher/pause:3.1": failed to pull and unpack image "localhost:2000/rancher/pause:3.1": failed to resolve reference "localhost:2000/rancher/pause:3.1": localhost:2000/rancher/pause:3.1: not found

Environment

  • rSeries
  • Versions up to and including F5OS-A v1.3.2

Cause

Bug ID 1187189: Tenants fail to start after bare metal install

This happens when the F5OS ISO is not present on the system after initial install, and the system is rebooted.

# show system image
% No entries found.

Recommended Actions

Import the F5OS ISO on to the system, and reboot the system once it shows as available in show system image.

ID1187189 is fixed in F5OS-A v1.5.0 and later.

Additional Information

At the time of this article's publication, the F5OS ISO is only copied onto the system with USB clean install, and not when using other methods such as DVD or PXE:

Bug ID 1213185: ISO file not copied during clean install from USB DVD/CD-ROM device
