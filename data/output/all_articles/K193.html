Topic

An FTP session failure may indicate that the FTP server requires passive mode, or that the server is attempting to perform a reverse-name lookup.

Passive mode FTP

Many FTP clients will automatically enable passive mode when required. Some FTP clients require that you manually enable passive mode by typing the following command:

pass

Note: You can also use the pasv command to manually enable passive mode.

Some FTP clients, such as the Windows FTP client, do not support passive mode.

When you attempt to retrieve data from an FTP server that requires passive mode, but you have not enabled passive mode, the session may appear to hang. Eventually, you may receive one of the following error messages:

  • Service Not Available, Remote Server Has Closed Connection
  • Can't build data connection: Operation timed out
  • 500 Illegal Port Command

Reverse-name lookup

Some FTP servers attempt to perform a reverse-name lookup on the client from which you have connected. The FTP server will not allow you to log in when it cannot resolve the name.

To resolve this issue, use one of the following two options:

  • Disable the reverse-name lookup performed by the FTP server software.
  • Make it possible for the FTP server to resolve the name for the client IP address by adding the client IP address to DNS or the hosts file on the FTP server.
