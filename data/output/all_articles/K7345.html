Known Issue

This is the result of a known issue. If you launch the Windows Standalone Client from the command line interface (CLI), and use the /config parameter to read a profile of other parameters from a file, the Standalone Client fails to launch, but produces no error messages.

The Windows-based Standalone Client can be launched through a CLI, using the f5fpc.exe utility.

The /config parameter (alias /c) can be used with the f5fpc.exe utility to read a profile of other parameters from a file. When the /config parameter references a file that does not exist, the command will execute but not return a session ID or other output on the command line, and not display the Standalone Client's user interface.

For example, the following command would fail if the myprofile.f5c file does not exist in the current working directory:

f5fpc.exe -start /h fp.foo.com /u johndoe /p p@ssW0RD /c myprofile.f5c

F5 Networks Product Development tracked this issue as CR72688 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.
