Description

When enable AVR functionality of BIG-IP, they may observe that the Round trip time from BIG-IP to web server is greater than round trip time from client to BIG-IP.

 

Environment

  • BIG-IP LTM
  • Virtual Server
  • Pool member

Cause

This is expected behavior.

RTT is Round Trip Time and is only the TCP round trip time - measuring the latency to and from the other side of the TCP connection (client or server) and the BIG-IP in each case.

RTT is purely dependent on the TCP connection(SYN,SYN+ACK & ACK) between the client and BIG-IP for the clientside. BIG-IP and the server for the server side. There is no correlation here at all between the Client & Server side RTT.
