Known Issue

The BIG-IP system removes the local IP address specified in the remote logging configuration after a ConfigSync operation.

This issue occurs when all of the following conditions are met:

  • You add a remote syslog server object to the remote logging configuration on a primary BIG-IP device
  • The remote syslog server object specified in the remote syslog server list includes a local IP address
  • You synchronize the configuration to a peer BIG-IP device
  • The local IP address of the remote syslog server object updates on the peer BIG-IP device
  • The updated configuration synchronizes back to the primary BIG-IP device

After the subsequent ConfigSync operation, the local IP address of the remote syslog server object specified in the remote syslog server list is removed from the BIG-IP device on which the configuration was synchronized. In order to prevent the system from overwriting the local IP address, you can use the tmsh utility to add or update remote syslog server objects.

Impact

You cannot use the Configuration utility to add or update remote syslog server objects.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After adding a local IP address to a remote syslog server object using the Configuration utility, you observe that the sync status displays Changes Pending
  • After a ConfigSync operation, you observe that the local IP address specified in the remote logging configuration is removed from the BIG-IP device on which the configuration was synchronized
  • You notice that the IP address that the BIG-IP syslog process binds to when sending logs to the remote syslog server does not match the local IP address that was added using the Configuration utility

Workaround

To work around this issue, you can use the tmsh utility to add the local IP address to the remote syslog server object. To do so, perform the following procedure:

Impact of workaround: You cannot use the Configuration utility to add or update the local IP address on remote syslog server objects.

  1. Log in to the command line of the affected BIG-IP device that no longer has the local IP address listed in the remote syslog server object.
  2. To determine the name of the syslog server object, type the following command:

    tmsh list sys syslog

    The command output displays similar to the following example:

    sys syslog {
    remote-servers {
    remotesyslog1 {
    host 10.10.10.1
    }
    }
    }

    In the previous example, only one remote syslog server object is defined, which is remotesyslog1.
  3. To add the local IP address to the remote syslog server object, use the following command syntax:

    tmsh modify sys syslog remote-servers modify { <name> { local-ip <ip.addr>} }

    In this command syntax, note the following:
    • <name> is the identifier of the remote syslog server object
    • <local-ip> is the IP address of the BIG-IP device

    For example, to add the local IP address 192.168.1.1 to the remotesyslog1 instance, you would type the following command:

    tmsh modify sys syslog remote-servers modify { remotesyslog1 { local-ip 192.168.1.1} }
  4. For any additional remote syslog server objects, repeat Step 3.
  5. Save your changes by typing the following command:

    tmsh save sys config
  6. Repeat this procedure on any other affected BIG-IP devices.
