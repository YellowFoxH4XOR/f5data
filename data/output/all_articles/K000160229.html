K000160229: CPU usage on VELOS platform exceed 100%

Published

2026-03-04
Applies to

Source

Description

On the F5 VELOS platform, blade-level CPU usage can exceed 100% while tenant-level CPU usage remains below 100%. This occurs because blade-level metrics include both tenant-allocated vCPUs and F5OS platform/data-mover reserved vCPUs, whereas tenant metrics only reflect allocated vCPUs.

Environment

  • F5 VELOS platform
  • F5OS version 1.8.1
  • BIG-IP tenants
  • VELOS blades (e.g., BX110)
  • Commands used:
    • Blade level: show cluster
    • Tenant level: tmsh show sys performance all-stats raw detail

Cause

This is a cosmetic display issue tracked under Bug ID 2227701. The blade-level CPU calculation includes reserved system vCPUs in addition to tenant vCPUs, which can result in reported usage exceeding 100%.

Answer/Recommended Actions

Understanding the CPU Architecture:

Each VELOS BX110 blade has 28 vCPUs total:
- 22 vCPUs are available for tenant allocation
- 6 vCPUs are reserved for F5OS platform and data-mover operations

Why Blade CPU Can Exceed 100%:

The blade-level CPU usage calculation includes all 28 vCPUs. When all 22 tenant vCPUs run at 100% utilization and the 6 reserved vCPUs are also busy, the blade-level reporting can show CPU usage exceeding 100%.

Recommended Action:

No action is required. This is expected behavior and a cosmetic reporting issue only. The blade-level CPU usage exceeding 100% does not indicate a functional problem, performance degradation, or any impact on system operation. You can safely ignore blade CPU readings above 100% during high load scenarios.

Additional Information

  • This behavior is expected due to the architectural design and the way CPU usage is calculated at different system levels
  • There is no impact on system performance or tenant operation
  • The display issue may be improved in future F5OS releases
