Description

Case-insensitive configuration fails to detect uppercase JSON elements on a login page. This may cause, for example, brute force protection to not trigger.

Environment

  • ASM security policy is configured case-insensitive.
  • Login Page Authentication Type is JSON/AJAX Request.
  • Brute Force attack protection.

Cause

This behavior is due to ID995889; Username/Password JSON elements of login page detected as case sensitive when the policy is configured as case insensitive

Recommended Actions

Assign below iRule to the impacted virtual server to make sure that both username and password parameters will be presented in lowercase before ASM start inspection:

Note: Adjust the iRule as needed and test it before applying it to production to avoid any traffic impact. Remove the comments before the lines log local0. to debug the iRule.
when HTTP_REQUEST {
   if {[HTTP::method] eq "POST" && [HTTP::header value Content-Type] contains "json"}{
       if {[HTTP::header "Content-Length"] ne "" && [HTTP::header "Content-Length"] <= 1048576}{
         set content_length [HTTP::header "Content-Length"]
       } else {
         set content_length 1048576
      }
      # Check if $content_length is not set to 0
      if { $content_length > 0} {
        HTTP::collect $content_length
      }
   }
}
when HTTP_REQUEST_DATA {
       #log local0. "===== Matched iRule K37362145 ======"
       #log local0. "Content length is [HTTP::header Content-Length]"
       set json_orig [HTTP::payload]
       #log local0. "json body is $json_orig"
       set orig_length [HTTP::payload length]
       #log local0. "Payload length is $orig_length"
       set json_replaced [string map -nocase [list username username password password] $json_orig]
       #log local0. "After replacing the strings: $json_replaced"
       set new_length [string length $json_replaced]
       #log local0. "New length = $new_length"
       #log local0. "old data = $json_orig"
       #log local0. "new data = $json_replaced"
       HTTP::payload replace 0 $orig_length $json_replaced
       HTTP::header replace Content-Length $new_length
       #log local0. "==================================="
}
