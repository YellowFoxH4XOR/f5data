Security Advisory Description

A flaw was found in QEMU's virtio-blk device. The issue arises because the device does not properly validate the size of input descriptors before writing data. A malicious guest with high privileges could exploit this vulnerability by submitting a malformed virtio-blk SCSI request, leading to an out-of-bounds write in the host heap memory and a potential denial-of-service (DoS) for the QEMU process. (CVE-2026-48914)

Impact

A local attacker with a BIG-IP Administrator role that has Terminal Access set to Advanced shell (bash) may be able to cause a DoS on the system.

If the Fixes introduced in column does not list a version for your branch, then no update candidate currently exists for that branch and F5 recommends that you upgrade to a version with the fix (refer to the tables).

Mitigation

To mitigate this vulnerability, update all BIG-IP user accounts with the Administrator role on the tenant so that Terminal Access is not configured to use bash. To do so, perform the following procedure:

Impact of action: Performing the following procedure removes access to the bash for users with an Administrator role on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Go to System > Users.
  3. Select the name of the user.
  4. For the Terminal Access setting, ensure the Advanced shell option is not selected.
  5. Select Update.
  6. Repeat steps 2 - 5 for the remaining accounts with Administrator role.
