Description

When you imported bash script written on Windows workstation, you may get following runtime error.

-bash: ./install.sh: /bin/bash^M: bad interpreter: No such file or directory

Environment

BIG-IP All version

Cause

The imported script include Windows CRLF return code that is incompatible to linux LF return code, that result in the runtime error.

Recommended Actions

To run a script on BIG-IP, You need to convert Windows CRLF return code to linux LF return code.

To convert, run following command at BIG-IP

# tr -d '\r' < source_file_name > output_file_name

Following example convert source file "install_windows.sh" to output file name "install_linux.sh"

# tr -d '\r' < install_windows.sh > install_unix.sh
