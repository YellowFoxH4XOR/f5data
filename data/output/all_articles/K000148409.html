K000148409: vcc-lacpd is restarting in a loop after resetting Velos controllers to factory default

Type
Support Solution
Published
2024-11-06
Updated
2024-11-06
Source
https://my.f5.com/manage/s/article/K000148409

Description

After running 'system database config reset-default-config' on Velos controllers, vcc-lacpd (the chassis lacpd daemon responsible for managing the management aggregation) becomes unhealthy, and is restarting in a loop.

The following error message can be found in velos.log:

controller-1 vcc-lacpd[XXXXX]: priority="Crit" version=1.0 msgid=0x3301000000000051 msg="Fatal error, application exit" fatal_str="Failed to get System Mac, exit to restart".

Environment

  • Velos
  • vcc-lacpd restarting in a loop after factory reset

Cause

ID1341993.

Recommended Actions

1) Reboot the non-affected controller, failover to it, then reboot the other controller.

2) Upgrade to F5OS-C 1.8.0 where ID1341993 is fixed.

Additional Information

None.
