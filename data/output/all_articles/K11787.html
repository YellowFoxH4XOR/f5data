Topic

Maintenance mode enables you to prepare the BIG-IP system for maintenance. When enabled, the BIG-IP system stops accepting new connections and slowly completes the processing of existing connections. Because maintenance mode impacts production traffic, only enable it when you perform maintenance on a BIG-IP system.

Note: If you are enabling maintenance mode for BIG-IP DNS or BIG-IP GTM systems, and you do not want the system to perform metrics collection and monitoring functions, you can stop the big3d process during maintenance mode and restart the process after disabling maintenance mode. To do so, use the following procedures that use the TMOS Shell (tmsh).

Description

Enabling maintenance mode

Enabling maintenance mode using the tmsh command

  1. Log in to the command line.
  2. Type the following command:

    tmsh modify /ltm global-settings general maintenance-mode enabled

  3. For BIG-IP DNS or BIG-IP GTM systems, to prevent the system from performing metrics collection and monitoring functions, type the following command:

    bigstart stop big3d

Enabling maintenance mode using the Configuration utility

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click Configuration or General Properties, depending on your version of the BIG-IP system.
  4. On the Local Traffic menu, click General.
  5. Under Properties, select the Maintenance Mode check box.
  6. Click Update.

Disabling maintenance mode

Disabling maintenance mode using the tmsh command

  1. Log in to the command line.
  2. Type the following command:

    tmsh modify /ltm global-settings general maintenance-mode disabled

  3. For the BIG-IP DNS or BIG-IP GTM systems, type the following command to re-enable metrics collection and monitoring functions:

    bigstart restart big3d

Disabling maintenance mode using the Configuration utility

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click Configuration or General Properties, depending on your version of the BIG-IP system.
  4. On the Local Traffic menu, click General.
  5. Under Properties, clear the Maintenance Mode check box.
  6. Click Update.
