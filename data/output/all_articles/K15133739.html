Description

Requests module can not be imported
Unable to perform certain iControl REST calls which requires python's requests module
You may receive the following error in the python shell: 

ImportError: No module named requests

Environment

  • BIG-IP appliance or vCMP guest 
  • Python version 2.6.6
  • iControl REST
  • Automation/orchestration

Cause

BIG-IP TMOS version(s) shipped with python 2.6.6 do not have requests module included

Recommended Actions

Upgrade to BIG-IP 14.1 and later which ships with python 2.7.5

Additional Information

Import the requests module in the BIG-IP CLI python shell

>>> import requests
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ImportError: No module named requests
