K000138078: TCL error was invoked from within "HTTP::path" while attempting to process an invalid HTTP request

Type
Support Solution
Published
2023-12-29
Updated
2023-12-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.0, 15.1.2, 15.1.1, 15.1.X, 15.1.10, 15.1.9, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3
Source
https://my.f5.com/manage/s/article/K000138078

Description

You may notice that after upgrading to the v15.x software version, you are receiving TCL errors related to HTTP::path, similar to the following:

<HTTP_REQUEST> - ERR_VAL (line 2) invoked from within "HTTP::path"

 

Environment

  • iRule

Cause

ID1407885

Recommended Actions

You could consider either of the following:

  • Using the -normalized option with the HTTP::path command.
  • Using the catch command in the iRule to log errors to the ltm log.
