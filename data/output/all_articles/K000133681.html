Description

Installers for MacOS clients to use with BIG-IP APM are distributed as standard Apple "Installer Packages" with a filename suffix of .pkg
They can be installed from the MacOS graphical interface or from the Terminal (command line)

Environment

  • BIG-IP APM deployment with Mac clients
  • MacOS devices with version 10 onward

Cause


Article K44328534 Describes how administrators can download the installer packages
Article K05816648 :  Describes a way of hosting these .pkg files to be available to your enterprise

This article describes how to install them manually or provides information for installing with a MDM scripting solution.

Recommended Actions

To use the command line to download a package from the APM and install it, F5 recommends using curl to download the pkg. This will prevent the pkg from being marked as an 'unsafe' download as occurs when using Safari.

Packages are installed by using the built in MacOS installer binary % /usr/sbin/installer

MyPKG="mac_f5epi.pkg"
MyAPM="seattle.vpn.example.net"
curl -O https://${MyAPM}/public/download/${MyPKG}


You can check the md5 hash matches the source to confirm the download was not corrupted

openssl md5 ${MyPKG}


The packages can then be installed with

sudo installer -pkg ${MyPKG} -target /

adding the options -dumplog, -verbose and -verboseR will produce more verbose screen messages about the install, and will be useful if something is not working. 
 

For MDM deployments, most management tools allow the above installer command to be packaged as a script and deployed as a bundle. Refer to your MDM documentation for details.

% /usr/sbin/installer
Usage: installer [-help] [-dominfo] [-volinfo] [-pkginfo] [-allowUntrusted] [-dumplog]
