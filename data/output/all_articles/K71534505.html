Description

APM 'Client Cert Inspection' always fails with a native VMware Horizon View client.

Environment

  • BIG-IP APM.
  • Native VMware Horizon View client.
  • 'Client Cert Inspection' on the VPE.

Cause
Horizon View client doesn't work for the SSL Client Certificate Authentication.

Recommended Actions
Use a web browser to use the SSL certificate authentication and 'Client Cert Inspection'.
