K000137710: Unable to login as admin to the Central Manager GUI

Description

When you try to log into the BIG-IP Next Central Manager GUI as the admin user on a new Central Manager deployment, login fails.

Environment

  • BIG-IP Next Central Manager
  • You configured the admin password at the command-line

Cause

The CLI password for admin and the GUI password are not the same. The default GUI password is admin/admin.  If you set the CLI password for admin, it does not change the GUI password.
 

Recommended Actions

Try to log in as admin/admin.

  • K000135998: Login failed on central manager logon page
