K72585084: Incorrect Username Displayed in Audit Log

Type
Support Solution
Published
2020-09-24
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K72585084

Description
The User listed in Audit Logs for Re-Discover/Re-Import will be incorrect for most of the Delete and Finish log entries of the Re-Discover and Re-Import sub tasks.

Environment

  • BIG-IQ 6.1+
  • One or more managed BIG-IPs

Cause
The user listed in the Audit Logs for most of the sub task Delete and Finish log entries will be the user which performed those initial tasks rather than the current user doing the current iteration of them.

Recommended Actions

The log entries for the parent task (Re-Discover or Re-Import) do correctly show the current user executing those tasks. Therefore the log entries for the parent task can continue to be used to authoritatively determine which user executed the tasks.

For reference, the Re-Discover task's initial log entry is for "ADC Discover Config Task" with an action of Start and the Re-Discover task's initial log entry is for "ADC Declare Management Authority Task" also with an action of Start.
