K000161606: WatchGuard Endpoint Security 360 failing to be detected during client inspection

Type
Support Solution
Published
2026-06-05
Updated
2026-06-05
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000161606

Description

BIG-IP APM endpoint inspection fails to detect WatchGuard Endpoint Security 360 as a valid antivirus product during client inspection checks. Users with WatchGuard Endpoint Security 360 installed, enabled, and up to date are denied access due to failed antivirus checks. Session logs show only other antivirus products (such as Windows Defender) being detected, with WatchGuard Endpoint Security 360 absent from scan results:

session.check_software.last.av.count is 1

session.check_software.last.av.item_1.name is Windows Defender

→ Following rule 'fallback' from item 'AV Logging' to terminalout 'AV failure'

→ Following rule 'AV failure' from item 'AV check' to terminalout 'AV Failure'

→ Following rule 'AV Failure' from item 'Pre-logon checks' to ending 'Deny'

Environment

  • BIG-IP APM with OPSWAT EPSEC endpoint inspection enabled
  • Access policy configured with antivirus software check (AV check agent)
  • EPSEC build prior to the fix
  • Client endpoints running WatchGuard Endpoint Security 360 (rebranded from WatchGuard EPDR)
  • Client OS: Windows 10 / Windows 11

Cause

WatchGuard Endpoint Security 360 is a rebranded product (formerly WatchGuard EPDR) with a new product name and signature ID that was not present in the OPSWAT OESIS SDK in EPSEC builds prior to the fix. OPSWAT determined that the differences between the old and new products required a new signature.

Answer/Recommended Actions

  1. Download and install the EPSEC build containing the fix on all BIG-IP APM systems. This build includes the updated OESIS SDK, which adds signatures for:
    • WatchGuard Endpoint Security 360
    • WatchGuard Endpoint Security Basic
  2. Refer to the relevant KB article for instructions on installing an OPSWAT Endpoint Security update on BIG-IP APM systems.
  3. After installing the updated EPSEC package, use the OPSWAT OESIS Diagnose (WaDiagnose) tool on an affected client endpoint to confirm that WatchGuard Endpoint Security 360 is now detected correctly.
  4. Verify the following key detection results in the WaDiagnose output:
    • sig_name: WatchGuard Endpoint Security 360
    • GetRealTimeProtectionState: enabled: true
    • GetDefinitionState: is_recent: true
  5. Review the AV check configuration in the access policy. If a Last Scan Time requirement is configured, it must be disabled (set to 0) for WatchGuard Endpoint Security 360, as the GetLastScanTime method is not supported for this product.

Additional Information

  • GetLastScanTime is NOT SUPPORTED for WatchGuard Endpoint Security 360. If the APM AV check policy includes a "Last Scan Time Not Older Than" requirement, this will cause check failures for WatchGuard Endpoint Security 360 users. Disable this requirement for WatchGuard products.
  • The TerminateProcesses method is also NOT_SUPPORTED for WatchGuard Endpoint Security 360, as the product does not allow termination of its main service.
  • If an EPSEC build containing the fix is not yet available as a standard release, contact F5 Support to request the EHF (hotfix) build.
  • To confirm which antivirus products are supported by the currently installed EPSEC version, refer to the OPSWAT support chart.
