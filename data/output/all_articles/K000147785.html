Description

Logs are not appearing in your AWS S3 bucket after configuring a Global Log Receiver.

Environment

  • F5 Distributed Cloud Global Log Receiver

Resolution/Answer

  • Ensure the AWS credentials used have write permissions for the target S3 bucket.
