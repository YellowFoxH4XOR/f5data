Known Issue

This is the result of a known issue. ARP broadcast traffic may not be sent to all interfaces configured for a VLAN. When the VLAN is configured with multiple interfaces, the Traffic Management Microkernel (TMM) will send ARP broadcast traffic out to each interface configured for the VLAN in a loop. However, if an interface is not connected, the interface will return a link down error message, and TMM will stop sending the ARP broadcast traffic to the remaining interfaces.

F5 Product Development tracked this issue as CR100657 and it was fixed in BIG-IP version 9.4.6. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, PSM, or WebAccelerator release notes.

This issue was also fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP version 9.4.5. You may download this hotfix or a later version of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.

Workaround

To ensure ARP broadcast traffic is sent to all interfaces that are configured for a VLAN, all configured interfaces must be connected, and unconnected interfaces must be removed from the VLAN configuration. For information about configuring VLAN interfaces, refer to the BIG-IP Network and System Management Guide.
