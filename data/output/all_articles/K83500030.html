Description

BIG-IP DNS / GTM is not sending health monitor to servers.
  • GSLB pool member marked down for reason: no route

Environment

  • BIG-IP GTM or DNS
  • BIG-IP Server Object
  • GSLB Servers
  • GSLB Monitors
  • Management Route for affected GSLB Server 

Cause

A management route to a server object that is more specific than TMM available routes will prevent big3d from sending monitors to that server object. The BIG-IP GTM or BIG-IP Server Object system will not probe objects through the management interface, because the management interface is specified for management traffic to the BIG-IP GTM system, and is not supported for production traffic.

Recommended Actions

  • Ensure that the BIG-IP Server Object system does not have any objects configured on the management network address space.
  • Ensure that the BIG-IP Server Object is not sending monitors out of the management subnet. 
  • Ensure that the default route for the BIG-IP Server Object system is not on the management subnet.
