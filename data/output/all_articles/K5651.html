Topic

FirePass version 5.4.0 introduced a new failover subsystem in addition to the original subsystem used in FirePass versions prior to 5.4.0. By default, the original subsystem is configured on versions up to and including 5.4.2. The new subsystem is configured by default on FirePass versions 5.5.0 and later. An administrator may configure a version 5.4.0, 5.4.1, or 5.4.2 FirePass unit to use the newer subsystem from the maintenance menu on the serial console.

However, neither the maintenance menu, nor the Administrative Console displays which subsystem is in use. You can verify which subsystem is in use by performing a network packet trace, then either comparing the time difference between heartbeat packets or examining the content of heartbeat packets. Heartbeat packets are UDP subnet-directed broadcasts sent to port 694 (by default) from the network interface configured for heartbeat.

Using a network packet trace to determine which failover subsystem is in use

To run a network packet trace, perform the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Configuration.
  4. Click Network Configuration.
  5. Click the Failover tab.

    The Failover Configuration information is displayed.

  6. Note the Network interface and UDP port used for the failover heartbeat.
  7. Click Device Management.
  8. Click Maintenance.
  9. Click Troubleshooting Tools.

    The available Troubleshooting Tools are displayed.

  10. Under the Network packet dump section, select the following options:
    • In the Packet type menu, select UDP.
    • Clear the Ignore Broadcasts check box.
    • In the Interface menu, select the interface you noted in Step 5.
    • In the Max Packet Count menu, select 100.
  11. Click the Start Sniffing the Network Traffic link.

    The packet capture will stop after a few seconds. You can also click the Click here to stop the capture and view the results link to stop the packet capture and view data.

  12. Examine the trace for packets sent from the unit's non-virtual IP address to the broadcast IP address and port configured for heartbeat noted in Step 5. Note that both FirePass units send heartbeat packets to each other, so be sure to select packets sent from the FirePass unit that was used to perform the trace.

Once the heartbeat packets have been identified, use one of the following two methods to identify the failover subsystem.

Time difference between heartbeat packets

FirePass units using the old subsystem send heartbeat packets once per second, and FirePass units using the new subsystem send heartbeat packets 10 times per second. Using two consecutive packets, determine the time difference between their Arrival Time: fields. If the difference is approximately 1 second, then the unit is using the old failover subsystem. If the time difference is approximately 0.1 second, the unit is using the new subsystem.

For example:


Frame 2 (178 on wire, 178 captured)

Arrival Time: Mar 10, 2006 21:37:05.287624000

Frame 4 (178 on wire, 178 captured)

Arrival Time: Mar 10, 2006 21:37:05.387669000

The difference of .1 second indicates this FirePass unit uses the new failover subsystem.

Note: The packets are the second and fourth frames in the trace. Frame #3 was a heartbeat packet sent by the other FirePass unit in the failover pair.

Content of heartbeat packets
