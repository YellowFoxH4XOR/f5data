K000147642: How to find out who your tenant owner is

Applies to

Source

Description

  • I need to find out who my tenant owner is because:
    • some F5® Distributed Cloud Console pages are not visible for me (For example)
    • I have a permission issue to create an object, for example
      • 403 error when creating a namespace
      • 403 access denied error message when using Kubectl command

Environment

  • Access to F5® Distributed Cloud Console

Answer/Recommended Actions

To find out who your tenant owner is:

  1. Access Distributed Cloud Console
  2. Go to Administration -> IAM -> Users
  3. Search for "Tenant Owner"

If the above page is not visible to you, please raise a support ticket or contact the person who gave you access to this tenant
