K7660: Virtual servers that have Application Security enabled do not currently support Fallback Persistence Profiles

Topic

A Fallback Persistence Profile specifies the persistence profile that you want the BIG-IP system to use if the system cannot use the specified default persistence profile. Virtual servers that have Application Security enabled do not currently support Fallback Persistence Profiles.
