K35800290: The BIG-IP system now redistributes routes with a prefix length of zero

Issue

Old Behavior

In versions prior to BIG-IP 12.0.0, the BIG-IP system does not redistribute routes with a prefix length of zero in the protocol routing table. For example, output from the show ip bgp command does not show the route (0.0.0.0/0) in the Border Gateway Protocol (BGP) routing table when the system configures and redistributes the Traffic Management Microkernel (TMM) route using the redistribute kernel command in the BGP protocol.

For example, review the following TMM routing table display:

BGP table version is 1, local router ID is 10.30.1.6
Status codes: s suppressed, d damped, h history, * valid, > best, i - internal, l - labeled
              S Stale
Origin codes: i - IGP, e - EGP, ? - incomplete

   Network          Next Hop            Metric     LocPrf     Weight Path
*> 8.8.8.8/32       10.20.1.200                                32768 ?

Total number of prefixes 1

The TMM routing table still displays the route of 0.0.0.0/0 when the system redistributes kernel routes into the routing protocols.

New Behavior

Beginning in BIG-IP 12.0.0, the BIG-IP system redistributes routes with a prefix length of zero in the protocol routing table. For example, show ip bgp command output shows the route (0.0.0.0/0) in the BGP routing table when the system configures and redistributes the TMM route using the redistribute kernel command in the BGP protocol.

For example, review the following TMM routing table display:

BGP table version is 1, local router ID is 10.20.1.5
Status codes: s suppressed, d damped, h history, * valid, > best, i - internal, l - labeled
              S Stale
Origin codes: i - IGP, e - EGP, ? - incomplete

   Network          Next Hop            Metric     LocPrf     Weight Path
*> 0.0.0.0/0        10.20.1.11                                 32768 ?
*> 8.8.8.8/32       10.20.1.200                                32768 ?

Total number of prefixes 2

Impact

You experience a change in the route redistribution behavior after you upgrade from BIG-IP 11.x to BIG-IP 12.x or later.

Recommended Actions

Review the BIG-IP routing configuration before you upgrade to BIG-IP 12.x or later. In addition, you can configure route-map to avoid unexpected routes in your routing table.
