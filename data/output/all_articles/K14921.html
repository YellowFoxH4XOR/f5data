Known Issue

BIG-IP APM access profiles that reference external logon pages may impact BIG-IP Edge Client alert notifications.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM profile references an external logon page for user authentication.
  • Users accessing the BIG-IP APM profile are using the BIG-IP Edge Client in the minimized state to initialize a network access session.
  • The BIG-IP Edge Client attempts to alert the user that they need to perform an action regarding their session.

Impact

Users are not aware that the BIG-IP Edge Client is awaiting user interaction in order to continue with the network access session.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The minimized BIG-IP Edge Client network access session initialization appears to fail.
  • To view the BIG-IP Edge Client alert, the user must double-click the BIG-IP Edge Client tray icon.
  • Users who initialize a network access session using a Webtop link are not impacted by this issue.

Workaround

To work around this issue, you can modify the JavaScript code on the external server logon page to ensure the Action required alert is displayed. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Using a web page editor, locate the JavaScript Onload section of the existing logon web page of the external server.

    For example:

    <script language="javascript"> function OnLoad()

  2. At the end of the OnLoad section (before the closing </script> statement) insert the following JavaScript code:

    {
    try{
    if ( "undefined" != typeof(window.external) && "unknown" != typeof(window.external)
    && "undefined" != typeof(window.external.WebLogonNotifyUser) && "unknown" != typeof(window.external.WebLogonNotifyUser) ){
    window.external.WebLogonNotifyUser();
    }
    }catch(e){alert(e)};
    }

  3. Save the modifications of the updated external logon web page code.
