Topic

BIG-IP Edge Client support for Mac OS X 10.12 (Sierra) is available in BIG-IP APM 11.5.1 and later (BIG-IP Edge Client 7101 and later). For more information about supported features and versions, refer to the Client Compatibility Matrix for your version.

Note: For information about how to locate F5 product documentation, refer to K12453464: Finding product documentation on AskF5.

Description

F5 has completed compatibility testing of the BIG-IP Edge Client-related features on the Apple Mac OS X beta 6 pre-release (Sierra). The testing did not identify any serious problems that require immediate software fixes to the F5 BIG-IP Edge Client and components. F5 will also test on the Mac OS X 10.12 final release build to ensure that no additional compatibility issues are encountered.

F5 identified the following compatibility issues through testing the Mac OS X beta 6 pre-release (Sierra).

  • Edge Client distribution customizations are not applied when you run the BIG-IP Edge Client on the Mac OS X 10.12 device.

    Refer to: K05301831 Mac Edge Client customizations are not applied when run on end user device

  • Mac OS X 10.12 devices may display a system Internal Error message when the system establishes an app tunnel and the resource is utilized using the Safari 10 browser.

    Refer to: K35559723 Utilizing an established app tunnel may display an operating system error message

  • The Mac OS X 10.12 device may display a system Internal Error message, or stop responding, when you establish a Java Client-enabled remote desktop access session, and you use the Caps Lock, Alt, Shift, or Ctrl keys in the desktop session.

    Refer to: K14407631 Using modifier keys within a remote desktop may display a Java exception error message

F5 Product Development will provide regular updates to this article when additional issues are identified.

Note: F5 may issue Engineering Hotfixes on a per-customer request to address known issues on various BIG-IP APM versions that are still under active software development.

Recommendations

F5 recommends that you upgrade to a BIG-IP APM software version that includes Mac OS X 10.12 support according to its corresponding Client Compatibility Matrix.
