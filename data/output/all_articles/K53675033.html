Known Issue

In rare conditions, some BIG-IP DNS (formerly known as BIG-IP GTM) monitored resources are marked as Unknown when the actual status is Offline.

This issue occurs when either of the following conditions is met:

  • Many monitor timeout periods elapse at the same time and you receive no response.
  • You received a response indicating that the resource is down, and the monitor is configured to ignore down responses.

This issue is more likely to occur when the monitor timeout value is evenly divisible by the monitor's monitor interval.

Impact

You can safely ignore this issue; it does not materially affect the operation of the system, as the system does not use resources marked as Unknown or Offline.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system incorrectly displays the status of the monitored resource as Unknown.
