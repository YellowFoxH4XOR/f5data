K000135592: The interface activity LED off or blink with a big interval

Type
Support Solution
Published
2023-12-22
Updated
2023-12-22
Applies to
  • VIPRION Platforms
  • VIPRION B2250 Blade
Source
https://my.f5.com/manage/s/article/K000135592

Description

Unbundled 40G interface, for example, 40G interface 2.1 is unbundled, split to 4 10G interface(1.1, 1.2, 1.3, 1.4). 
One or more of interfaces (1.1, 1.2, 1.3, 1.4) activity LED do not blink or with a big interval. 
For example: 

Environment

  • Unbundled 40GbE ports

Cause

There are too little or no traffic going through this interface

Recommended Actions

It is expected when a little traffic go through this interface.
If there are lots of traffic sending over this interface, it will be solid green.

Additional Information

None.
