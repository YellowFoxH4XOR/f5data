K10329: The Java console reports a 'load: class com.citrix.JICA not found' error when attempting to connect to a Java-based Citrix MetaFrame Terminal Server favorite

Topic

If you select the Java client check box when configuring a Citrix MetaFrame Terminal Server favorite, you should also install the Citrix Java ICA (JICA) client on the Application Access : Terminal Servers : Global Settings page. Installing the Citrix JICA client ensures that clients who do not have the JICA client pre-installed can connect to the Java-based favorite.

Note: You can download the JICA client on the Citrix website.

If the client system does not have the JICA client installed, and you do not install it on the FirePass controller, the user receives an error message that appears similar to the following example when launching a Java-based Citrix MetaFrame Terminal Server favorite:

ERROR

Java applet cannot be started. Please make sure that a required version of Java is installed
