Description
The Big-IP only supports load balancing the  AJP protocol based on TCP.
Load balancing AJP protocol traffic with an HTTP profile applied on the virtual server, will cause these connections to fail and is currently not supported on the Big-IP.

Environment

  • BIG-IP LTM
  • HTTP Profile
  • TCP Profile

Cause
The BIG-IP system is not able to convert HTTPS to AJP protocol on the server-side as BIG-IP does not support this as a service profile (layer 5-7).
It is only possible to load balance AJP packets based on TCP connections.

Recommended Actions

  1. When configuring the Big-IP to load balance AJP traffic, ensure the Big-IP virtual server is configured only with TCP layer profiles. HTTP profiles are not supported.
