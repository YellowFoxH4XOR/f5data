Known Issue

Virtual servers with a SPDY profile may erroneously use SNAT automap.

This issue occurs when the following condition is met:

  • A BIG-IP virtual server uses the following configuration:
     
    • An associated SPDY profile
    • The Source Address Translation option set to None (the default setting)

Impact

Virtual servers with a SPDY profile determine the server-side source address using secure network address translation (SNAT) automap, which may result in an incorrect server-side source address.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Unexpected server-side source addresses are observed by pool members, which can affect processes such as web server logging by the pool member. You can observe this behavior by using the tcpdump packet tracing utility. For more information, refer to K1893: Packet trace analysis.
