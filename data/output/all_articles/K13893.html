Issue

Error Message

local/B6800-R39-S4 warning logger: WARNING: The <vlan_name> vlan on the redundant peer <ip_addr> is setup with a different vlan tag id <vlan_id>. Connection mirroring requires that the vlan tags be identical. Please correct the vlan tag ids on your redundant system

In this error message, note the following:

  • <vlan_name> is the name of the VLAN used for connection mirroring.
  • <ip_addr> is the self IP address of the peer BIG-IP system.
  • <vlan_id> is the specified tag configured for the VLAN.

For example:

local/B6800-R39-S4 warning logger: WARNING: The mirror-vlan vlan on the redundant peer 10.12.16.235 is setup with a different vlan tag id (2012). Connection mirroring requires that the vlan tags be identical. Please correct the vlan tag ids on your redundant system.

Message Location

You may encounter this message in the following location:

  • /var/log/ltm

Description

This message occurs when all of the following conditions are met:

  • You have configured a redundant pair of BIG-IP systems with connection mirroring.
  • The VLAN tag or VLAN name do not match on across BIG-IP systems for the VLAN used for mirroring.

Note: The error message always indicates a mismatch with the VLAN tag id. However, the error message happens when either the VLAN name or VLAN tag are different.

If there is a mismatch with the VLAN tag or VLAN name for the mirroring VLAN, the error message is logged when a configsyc is performed. However, the configsync will work as expected.

Impact

If the mismatch is with the VLAN tag, there is no impact other than the error message; connection mirroring will work as expected. However, if the mismatch is with the VLAN name, connection mirroring will fail.

Recommended Actions

Ensure the redundant BIG-IP systems use matching VLAN names and VLAN tags on the VLAN used for mirroring.
