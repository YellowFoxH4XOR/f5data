K000133155: BigIP tenant config load fails after rSeries reboot

Type
Support Solution
Published
2023-05-23
Updated
2023-05-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000133155

Description

You are trying to restore the UCS which is password encrypted and you modified the master key following the directions in:

K9420: Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)

BIG_IP was deployed with a master key and the UCS restore failed:

You can see errors:

failed while loading configuration that is encrypted with a different master key

Loading configuration process failed.

Configuration loading error: base-config-load-failed

 

Environment

UCS

master key f5mku

configuration load

 

Cause

Undetermined

Recommended Actions

1. Modify the master key and load sys config -> load process complete, device Active and operational.

2. update syslog server config via GUI ->  Youcan see in logs: Saving the new version of Master key file.

3. reboot device -> no issue, device loads config with the new key, device Active and operational.
