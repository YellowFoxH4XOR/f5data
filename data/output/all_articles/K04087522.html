Environment

  • BIG-IQ Centralized Management
  • BIG-IP APM configuration import
  • Api Response protection object in partition

Cause

header  name doesn't contain / before  partition name
headers {
        DMZ/Basic_GCO_API-Protec_auto_response1_header1

APM config validation is not reporting syntax issue when doing 'load sys config verify'

Recommended Actions

  1.  Manually modify bigip.conf file by adding missing character using text editor  ( VI, nano etc.)
    headers {
            DMZ/Basic_GCO_API-Protec_auto_response1_header1
    Replace with:
    should be :
    headers {
            /DMZ/Basic_GCO_API-Protec_auto_response1_header1
  2. Verify and save configuration using:
    tmsh load sys config verify
    tmsh save sys config
