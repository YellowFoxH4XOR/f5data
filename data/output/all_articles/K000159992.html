Description

Security scanning tools (such as Rubrik) may report that the file /usr/lib/libirdetector.so on BIG-IP systems is associated with the VOIDLINK C2 framework malware. The detection is driven by YARA rules that target specific string patterns within the binary, rather than relying on file hash matching. This file is flagged as a potential indicator of compromise (IOC) related to VOIDLINK malware.

The file /usr/lib/libirdetector.so is a legitimate BIG-IP system library used to determine if the appliance is installed in a cloud environment.

Environment

  • Product: BIG-IP (all modules), BIG-IQ
  • Affected BIG-IP versions: 16.1.x, 17.1.x, 17.5.x, 21.0.x, BIG-IQ versions: 8.x
  • File in question:  /usr/lib/libirdetector.so
  • Security scanners: Rubrik, or other tools using YARA-based malware detection
  • Detection method: File hash matching against VOIDLINK malware signatures

Cause

The YARA rule G_APT_Framework_VOIDLINK_1 (MD5: a009491dec480d013abec15650fb1f1a) is incorrectly identifying the legitimate BIG-IP library /usr/lib/libirdetector.so as VOIDLINK malware. This is a false positive detection.

Answer/Recommended Actions

The file /usr/lib/libirdetector.so is a legitimate BIG-IP system component and does not indicate a security compromise. F5 has confirmed this is a false positive detection.

To further validate the integrity of the BIG-IP system, run the F5 system Scanner. For more information, refer to F5 System Scanner 

Additional Information

  • F5 has verified that multiple YARA rules designed to detect VOIDLINK malware, including rules from Google Mandiant, do not identify the presence of VOIDLINK malware in the legitimate file.
  • The file /usr/lib/libirdetector.so is a dynamic library used by BIG-IP to determine if the appliance is running in a cloud environment.
