Description

When performing a BIG-IP software upgrade on a vCMP guest, the following error may occur during signature verification:

Terminal error: Repository must be a file for signature validation; /tmp/lind_util.4WDt2S.\r ***

Live install end: failed (return code 2)

This error prevents the upgrade from proceeding when signature verification is enabled.

Environment

  • Product: BIG-IP LTM
  • Version: 17.x 
  • Platform: Viprion chassis
  • Configuration: vCMP guest with signature verification enabled during software installation

Cause

The issue is caused by Bug ID 492369, which results in vCMP guests failing the image verification check if the image verification database variable is enabled. The .iso and .sig files used for installation must reside on the guest system rather than on the host for successful signature validation.

Recommended Actions

  1. Move .iso and .sig files to the guest:
    Ensure both the BIG-IP software .iso and .sig files are present on the vCMP guest, not on the host system. Use scp or winscp to transfer them if needed.
  2. Disable signature verification (if required):
    Temporarily disable automatic signature verification:
    tmsh modify /sys db liveinstall.checksig value "disable"
  3. Manually verify signatures:
    Perform manual signature verification of the .iso file on the guest using instructions from K24341140: Verifying BIG-IP software images using digital signatures and checksums.
  4. Restart lind process:
    On the guest, restart lind to apply changes:
    bigstart restart lind
  5. Retry software installation:
    Initiate software installation again from within the vCMP guest.

For additional details and troubleshooting steps, refer to K33135278: Troubleshooting BIG-IP software image installation failures in vCMP guests with signature validation enabled.
