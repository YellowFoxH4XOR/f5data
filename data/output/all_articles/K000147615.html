Description

After migrating my application to the F5® Distributed Cloud platform you get the error:

Cross-Origin Read Blocking (CORB) blocked cross-origin response.

Environment

  • F5® Distributed Cloud (XC)
  • HTTP Load Balancer

Answer/Recommended Actions

You need to enable and configure a CORS policy adding the domain that is getting blocked.

  • If you have a list of similar domains or just subdomains and you don't want to manually configure the domains as they appear, the solution is to use regex pattern with Allow Origin Regex.

  • If your website uses cross origin with authentication (eg: cookie header) then you have to check the Allow Credentials checkbox then F5 XC will send "access-control-allow-credentials" header in the response and the browsers won't raise CORB error.
