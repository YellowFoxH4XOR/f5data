K03541352: Unable to generate Qkview. The process gests stuck at line : Executing /bin/rpm -qa ...

Type
Support Solution
Published
2022-04-01
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K03541352

Description
When attempting to generate a QKview file from the command line, the qkview process hangs while executing rpm -qa.

Example:
Executing /bin/rpm -qa ...

Environment

  • BIG-IP
  • Qkview
  • Command line

Cause
The RPM database gets corrupted under unknown circumstances.

Recommended Actions

  1. Log on to the BIG-IP command line.
  2. Change directories to t/var/lib/rpm: 
    cd /var/lib/rpm
     
  3. View the files of the directory:
    ls -l *db.*
     
  4. Move the existing RPM db files to a backed up copy.
    For example the ls -l *db.* command returns the a list of db files similar to:
    -rw-r--r--. 1 root root  311296 Mar 26 19:11 __db.001
    -rw-r--r--. 1 root root   90112 Mar 26 19:11 __db.002
    -rw-r--r--. 1 root root 1318912 Mar 26 19:11 __db.003
     
  5. Move (rename) these files to a backup copy of those files.

    Example:
    mv __db.001 __db.001.bak
    mv  __db.002 __db.002.bak
    mv __db.003 __db.003.bak
     
  6. Rebuild the RPM database files with the following command:
    rpm --rebuilddb
     
  7. You can now test that reading of the RPM database files with the following command: 
    /bin/rpm -qa
     
  8. After a successful test attempt to run the qkview utility again.
