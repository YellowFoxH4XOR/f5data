K000149278: Getting error "Passwd.bin: Authentication token manipulation error" when attempting to change root password

Description

Getting error "Passwd.bin: Authentication token manipulation error" when attempting to recover root password from single-user mode.

Environment

  • BIG-IP

Cause

Root partition disk space full

Recommended Actions

1. Boot into bash environment by keying 'init=/bin/bash' in GRUB

Refer to either of these articles depending on your version. Replace 'rd.break' with 'init=/bin/bash' to boot into bash environment.

  • K4178: Restarting the BIG-IP system in single-user mode (GRUB 0.97)
  • K14662: Restarting the BIG-IP system in single-user mode (GRUB2)

For example:

kernel /boot/1/vmlinuz ro root=UUID=7237fa64-e347-4bb7-a755-6e2617bd7c0e console=ttyS0 panic=1 platform=D113 <default_cpu_order quiet> init=/bin/bash

Once in bash environment, you should see bash prompt similar to:

2. Remounting root partition with read/write permission

mount -o remount,rw /

3. Remove unused file in root partition to clear disk space

You may refer to K11176458: 011d0004:3: Disk partition / (slot #) has only 0% free space for reference.

4. Type 'exit' in the bash prompt to exit from bash environment and proceed to change root password
