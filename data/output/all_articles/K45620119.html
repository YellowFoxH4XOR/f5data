K45620119: Getting Authentication error and failure while login in into the VDI infrastructure.

Description
While connecting to a VMWare UAG system through BIG-IP LTM, you get prompted with authentication failures messages.

Environment

  • BIG-IP LTM
  • VMWare UAG deployment and infrastructure

Cause
This may be due to some difficulty with the connection persistence setup on BigIP.
Typical VMWare deployments are made out of several Virtual Servers.
And all those Virtual Servers are assigned a persistence profile (usually: a source_addr persistence profile).
If one of the Virtual Server is not marked as "available", the persistence profile records may get deleted, leading the authentication requests to get load-balanced to all UAG servers.

Recommended Actions

  1. Review the status of each Virtual Servers involved in the VMWare deployment;
  2. Ensure each of them is marked as "available";
  3. For each Virtual Server not marked as "available", perform each necessary step (such as updating the configuration of the monitors) to fix the status.
