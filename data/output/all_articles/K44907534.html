Known Issue

The BIG-IP system might drop fast forwarded User Datagram Protocol (UDP) packets if Datagram load balancing is enabled.

This issue occurs when all of the following conditions are met:

  • The Traffic Management Microkernel (TMM) is overloaded.
  • UDP Datagram load balancing is enabled in a UDP profile.

Impact

The system drops UDP packets.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • If Datagram load balancing is enabled in the UDP profile, the system may drop fast forwarded UDP packets.

Workaround

To work around this issue, you can disable Datagram load balancing in the affected UDP profile using the TMOS Shell (tmsh). To do so, perform the following procedure:

Impact of workaround: Disabling Datagram load balancing in a UDP profile affects virtual server traffic processing. F5 recommends that you perform this procedure during a scheduled maintenance period.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Disable Datagram load balancing by typing the following command:

    modify ltm profile udp <profile_name> datagram-load-balancing disabled

    For example:

    modify ltm profile udp exampleUdpProfile datagram-load-balancing disabled

  3. Save the configuration by typing the following command:

    save /sys config
