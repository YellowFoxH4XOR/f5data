Issue

Error Message

Error Message: 01900025 : SCTP <%s> association (<%F>) primary path changed to <%F>.

In this error message, note the following:

  • <%s> is the Stream Control Transmission Protocol (SCTP) connection.
  • <%F> is the path used for the SCTP connection.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions is met:

  • The SCTP connection association old primary path is not working, and the primary path association is changed to a new primary path. 

For more information about SCTP and path selection, refer to Internet Engineering Task Force (RFC 4960).

Note: This link takes you to a resource outside of AskF5, and the third party could remove the document without our knowledge.

Impact

There is no impact. You can safely ignore this error message.

Recommended Actions

None
