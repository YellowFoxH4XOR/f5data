Known Issue

This is the result of a known issue. Escaped double quotes are incorrectly parsed during a configuration load.

An example escaped quote \" in a class file is as follows:

class test_ext extern {
type string
filename ext_class.txt
mode read
}

The ext_class.txt file contains the following entry:

"\"_test_\""

After the updated configuration loads, the BIG-IP LTM reports a message similar to the following example:

# bigpipe load
....
Reading configuration from /config/bigip.conf.
....
Loading the configuration ...
BIGpipe: class modification error:
01070627:3: The string class external file (/config/ext_class.txt) has an invalid format.

F5 Product Development tracked this issue as CR84373 and it was fixed in BIG LTM 9.3.1 and 9.4.4. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You can work around this issue by replacing the escaped double quote, which will allow the system to properly parse and load the configuration. To do so, replace \” with \x22, which is the HEX equivalent of \”.

For example:

"\"_test_\""

To replace the escaped double quote in the example, you would use the following syntax:

"\x22_test_\x22"
