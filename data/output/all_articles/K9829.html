Known Issue

This is the result of a known issue. The following files are not synchronized between members of a FirePass cluster or failover pair:

  • Resigned client, components uploaded on the Device Management: Customization page under the Code Signing tab
  • Citrix ICA client, uploaded on the Application Access: Terminal Servers: Global Settings page
  • Citrix JICA client, uploaded on the Application Access: Terminal Servers: Global Settings page

    Note: Support for the Citrix JICA client was introduced in FirePass version 6.0.3.

F5 Product Development is tracking this issue as ID 341055.

This issue has been fixed in cumulative hotfix HF-70-3, which has been issued for FirePass version 7.0.0 and cumulative hotfix HF-610-5 for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
