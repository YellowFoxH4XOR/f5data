Description

Geo locations are added or deleted automatically in the ASM policy under Security  ››  Application Security : Security Policies : Policies List  ›› ASM policy >> Advanced Settings >> Geolocation Enforcement

Following logs are noted in  /var/log/asm

Jul 12 16:57:23 LTM1 info perl[18810]: 01310053:6: ASMConfig change: Disallowed Geolocation XXX [delete] { audit: policy = /Common/ASM policy component = Policy Builder }

In above logs  configured geolocation enforcement is deleted

Environment

  • BIG-IP ASM 
  • Geolocation is enabled in the ASM policy
     

Cause

If "Learn" from Access from disallowed Geolocation is enabled, the Policy Builder will add/delete the  locations automatically to the ASM policy. This is expected behaviour
 

Recommendations

1. Disable "Learn" from "Access from disallowed Geolocation" in the Security  ››  Application Security : Policy Building : Learning and Blocking Settings of ASM policy




2. Save and Apply the ASM policy
