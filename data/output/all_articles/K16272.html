Known Issue

The BIG-IP system displays no available memory for certain Traffic Management Microkernel (TMM) threads.

This issue occurs when the following condition is met:

  • You use either of the tmsh show sys memory or tmsh show sys tmm-info commands.

Beginning in BIG-IP 11.3.0, TMM supports a multi-threaded architecture. Each TMM instance is a separate thread, and the allocated TMM memory is shared between all TMM threads. For more information, refer to K14358: Overview of Clustered Multiprocessing (11.3.0 and later) and K15468: Overview of BIG-IP TMM CPU and memory usage (10.x - 11.x).

Impact

The amount of memory allocated to each TMM thread is not directly available.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The show sys memory command incorrectly displays Available memory as zero for all TMM threads, except for TMM 0.0.

    For example:

    -----------------------
    Sys::TMM Memory (bytes)
    -----------------------
    TMM: 0.0
    Available 28.6G
    Used 603.8M

    -----------------------
    Sys::TMM Memory (bytes)
    -----------------------
    TMM: 0.1
    Available 0
    Used 3.7M

    Note: This example has been truncated for clarity.
  • The show sys tmm-info command incorrectly displays Available memory as zero for all TMM threads, except for TMM 0.0.

    For example:

    ---------------------------
    Sys::TMM: 0.0
    ---------------------------
    Global
    TMM Process Id 10987
    Running TMM Id 0
    TMM Count 1
    CPU Id 0

    Memory (bytes)
    Available 28.6G
    Used 603.8M

    CPU Usage Ratio (%)
    Last 5 Seconds 3
    Last 1 Minute 3
    Last 5 Minutes 3

    --------------------------
    Sys::TMM: 0.1
    --------------------------
    Global
    TMM Process Id 10987
    Running TMM Id 1
    TMM Count 1
    CPU Id 1

    Memory (bytes)
    Available 0
    Used 3.7M

    CPU Usage Ratio (%)
    Last 5 Seconds 1
    Last 1 Minute 1
    Last 5 Minutes 1

    Note: This example has been truncated for clarity.
