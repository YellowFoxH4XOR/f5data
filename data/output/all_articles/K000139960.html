Description

There are cases, when the security assessment team, sends a report contains a SSH-RSA vulnerability, which required to delete SSH-RSA from Host key.

Verified the issue is not with sshd's keys.

Environment

  • BIG IP
  • Security assessment report

Cause

Security test team asked to remove 'ssh-rsa' from BIG IP to overcome vulnerability

Recommended Actions

Use the following steps to get with the 'ssh-rsa' and how to remove it:

From CLI run - "ssh -Q key" to find if you have ssh-rsa keys in your cached ssh:

Look for users which set Linux environment to use ssh-rsa i.e.: root - From CLI:

  1. To make sure we will have another connection open while we running the procedure, please open two ssh connections to the BIG IP through CLI.
  2. To find which user got the ssh-rsa key, use the following from CLI:
    1. cat /root/.ssh/known_hosts | grep -i 'ssh-rsa'
  3. To remove the relevant line, use a vi editor or any other editor:
    1. vi /root/.ssh/known_hostsand
    2. remove the relevant line/s contain the "ssh-rsa"

Note: This procedure should not interrupt the traffic.
