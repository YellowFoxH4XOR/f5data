Description

While doing configuration for DNS virtual server using iApp f5.dns template  below error is seen
 

Environment

  • f5.dns template
  • /shared partition
  • Disk Space
  • iApps

Cause

/shared is 100% utilized

Recommended Actions

  1. Login to BIG-IP CLI (bash mode)
  2. Check the disk space using command:  df -h
  3. To locate the 20 largest files (measured in KB) on the system, use the following command syntax:
    find /shared -xdev -type f -exec du {} \; | sort -rn | head -20
  4. Remove unwanted files under /shared partition.
