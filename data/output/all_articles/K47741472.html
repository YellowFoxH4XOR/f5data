Known Issue

The Configuration utility does not process Secure Sockets Layer (SSL) keys and certificates with names that include special characters.

This issue occurs when the following condition is met:

  • In the Configuration utility, you import an SSL key or certificate that has a name containing one of the following characters:
    • Question mark (?)
    • Colon (:)
    • At sign (@)
    • Exclamation mark (!)
    • Ampersand (&)
    • Number sign (#)

Impact

You cannot use the Configuration utility to manage SSL keys or certificates that have names containing special characters.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You cannot use the Configuration utility to manage affected keys or certificates that were created using the Traffic Management Shell (tmsh).
  • After importing an affected certificate, you cannot display the certificate.
  • The Configuration utility displays an error message similar to the following example:

    An error has occurred while trying to process your request.

  • You cannot delete affected certificates using the Configuration utility or tmsh utility.

Workaround

To work around this issue, you can avoid importing certificates with names that contain the affected characters.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
