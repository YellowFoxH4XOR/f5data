Description

When configuration is large (~100 bot profiles) applying Bot Defense profile changes may fail due to configured timeout.

In F5 GUI error like this can be seen:

Could not save Bot Profile
AsyncContext timeout

In the logs you can see messages like these:

/var/log/restjavad.0.log

Environment

  • BIG-IP ASM
  • Bot Defense profile

Cause

Timeout occurs before configuration is loaded fully.

Recommended Actions

1. Increase timeout values for icrd, restjavad and restnoded processes.

# tmsh modify sys db icrd.timeout value 240
# tmsh modify sys db restjavad.timeout value 240
# tmsh modify sys db restnoded.timeout value 240

2. Restart REST services.

# tmsh restart sys service restjavad restnoded
Impact: There is no impact on traffic. Limited REST access to the control plane occurs.
