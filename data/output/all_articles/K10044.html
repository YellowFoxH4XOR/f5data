Known Issue

This is the result of a known issue. The EUD utility version 12.0.0 reports a kernel panic message when rebooting the system.

Note: The EUD utility version 12.0.0 only supports the BIG-IP 1600, 3600, and 6900 platforms.

When exiting the EUD utility, the system must reboot to load the BIG-IP software because the EUD utility and the BIG-IP software use different kernel versions. Due to the difference in kernel versions, when the BIG-IP system reboots after exiting the EUD, the following message is reported to the console:

Note:The BIG-IP system uses Linux kernel version 2.4, and the EUD uses Linux kernel version 2.6.

Kernel panic: IO-APIC + timer doesn't work! pester mingo@redhat.com
Rebooting in 1 second.

This message is benign; the BIG-IP system will reboot. The message occurs when the system switches from Linux kernel version 2.6 back to Linux kernel version 2.4.

F5 Networks Product Development tracked this issue as CR116786/ITEM 679 and it was fixed in EUD version 12.4.

Note: EUD version 12.4 is included with BIG-IP version 9.4.8. If you are running an earlier version of the EUD software, you can download EUD version 12.4 from the F5 Networks Downloads site. For more information, refer to the End-User Diagnostics Release Notes.
