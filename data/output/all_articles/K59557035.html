Description


When activating a Registration Key from the BIG-IQ Centralized Manager License Management tab, an error similar to the one below can be observed from /var/log/restjavad.#.log

Error parsing license text:<>: The supplied license does not have the feature flag perf_VE_cores when activating RegKeyl in BIG-IQ

Environment

  • BIG-IQ CM
  • License Manager
  • License reactivation

Cause

Older versions of licenses do not have the necessary feature flags that BIG-IQ now checks for before it can manage the license.

Recommended Actions

  • Run the command below on the BIG-IP where the key is being used:

# tmsh show sys license detail | egrep 'perf_VE|license_manager'

  • If there is no result for 'perf_VE_core' then your license version is outdated and you need to contact your F5 accounts representative to request a newer license key version.
