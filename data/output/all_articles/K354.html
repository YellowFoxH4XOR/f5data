Note: This Solution assumes that you have a basic familiarity with DNS and its processes. For more specific information about DNS and recursion, refer to DNS & BIND 4th edition by O'Reilly.

Recursion is a DNS term that refers to how Name Server handles DNS queries.

If a DNS server that allows recursion receives a name resolution request, the DNS server will query (following the steps of DNS delegation) all the necessary Name Servers in an attempt to obtain the answer.

Conversely, if a DNS server that does not allow recursion receives a resolution request, it will respond with a message similar to the following example:

best known answer

The requestor will then be required to use the information supplied to find the correct answer.

As a server, 3-DNS supports both modes of operation. The following instructions explain how to restrict recursion users and disable recursion.

      Restricting Recursion Users for 3-DNS versions 4.5 through 4.6.1

    Disabling recursion will create issues for users who are using the 3-DNS as their local DNS. In this situation, rather than disabling recursion, you may simply want to restrict its use only to authorized users. To do so, perform the following procedure:

    1. Edit the /etc/named.conf file.
    2. Add the following line to the options section:

      Note: 192.168.24.24/16 is the network IP range within your network from which you will allow recursive queries.

      allow-recursion { 192.168.24.24/16; };
    3. To load the new configuration, type the following command:

      ndc reload

    Disabling Recursion on 3-DNS for 3-DNS versions 4.5 through 4.6.1

    By default, recursion is enabled. To disable recursion, perform the following procedure:

    1. Edit the /etc/named.conf file.
    2. Add the following line to the options section:

      recursion no;
    3. To load the new configuration, type the following command:

      ndc reload

    Restricting Recursion Users for 3-DNS versions 4.6.2 through 4.6.4

    Disabling recursion will create issues for users who are using the 3-DNS as their local DNS. In this situation, rather than disabling recursion, you may simply want to restrict its use only to authorized users. To do so, perform the following procedure:

    1. Edit the /var/named/etc/named.conf file.
    2. Add the following line to the options section:

      Note: 192.168.24.24/16 is the network IP range within your network from which you will allow recursive queries.

      allow-recursion { 192.168.24.24/16; };
    3. To load the new configuration, type the following command:

      rndc reload

    Disabling Recursion on 3-DNS for 3-DNS versions 4.6.2 through 4.6.4

    By default, recursion is enabled. To disable recursion, perform the following procedure:

    1. Edit the /var/named/etc/named.conf file.
    2. Add the following line to the options section:

      recursion no;
    3. To load the new configuration, type the following command:

      rndc reload
