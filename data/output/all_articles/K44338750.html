K44338750: Upgrading Edge Client from 12.1.2 to 13.1.x may require removing the Client ''_Common_*'' VPN interfaces

Type
Support Solution
Published
2019-10-01
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.X, 13.1.4, 13.1.3, 13.1.1, 13.1.5, 13.1.0
  • APM Clients
Source
https://my.f5.com/manage/s/article/K44338750

Description
If you upgrade the Edge client from 12.1.2.x to 13.1.x, without removing the previous instance of the Edge client, you may run into connection problems accessing the VPN tunnel because the old 'VPN interface' is being reused.

Environment

  • Upgrade from BIG-IP 12.1.2.x to 13.1.x
  • APM Network Access configured
  • Upgraded Edge Client without removing previous instance.
  • Windows 10 Edge Client users.

Cause
The New Edge client instance uses the old VPN interface  (_Common_<Network access name>) on the PC, instead of creating a new VPN interface with the updated functionality of the new version.

Recommended Actions

  Delete all of the VPN interfaces that start with "_Common_"  
  1. Goto Network and Sharing center
  2. Goto Change Adapter settiongs
  3. Under network settings,  remove all the _Common_* interfaces.
    NOTE: do not remove "APM Network Access" adapter.
  4. If the delete option is greyed out, either delete the following RegKey or rename it to include .old at the end.
    %USERPROFILE%\AppData\Roaming\Microsoft\Network\Connections\Pbk\rasphone.pbk
  5.  Attempt a new connection to the VPN Tunnel 
A new connection to the VPN will create a new VPN adapter "_Common_<Network access name>".
