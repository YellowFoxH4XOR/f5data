Known Issue

Using the BIG-IP Configuration utility to configure Device Trust between peer devices may result in an error message.

This issue occurs when the following condition is met:

  • You configure peer devices for an intended Device Trust group to use different time zones.

Impact

You cannot create Device Trust groups.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H435093 on the Diagnostics > Identified > Medium screen.
  • An error message, similar to the following example, displays in the Configuration utility and in the /var/log/ltm file:

    err devmgmtd[6216]: 015a0000:3: checkDeviceTrustSupported failed: [CheckHandlers.cpp:83 checkDevic] System time on <peer-ip-address> off by <numeric-value> seconds

Workaround

To work around this issue, you can configure the devices to use the same time zone (F5 recommends UTC). To do so, perform one of the following procedures:

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Using the Configuration utility to configure all devices in the device trust group to use the UTC time zone

  1. Log in to the BIG-IP Configuration utility.
  2. Click System.
  3. Click Platform.
  4. Select UTC.
  5. Click Update.

Using the tmsh utility to configure all devices in the device trust group to use the UTC time zone

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Configure the device to use the UTC time zone by typing the following command:

    modify /sys ntp timezone UTC
  3. Save the change by typing the following command:

    save /sys config

Note: Time zone abbreviations must be capitalized.
