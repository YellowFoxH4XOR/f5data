Known Issue

This is the result of a known issue. In BIG-IP 9.3.x through 9.4.8, it is possible to run a hotfix uninstall package on a system that is running a different BIG-IP version than intended for the uninstaller. Running the wrong version of an uninstaller may cause packages from multiple versions of the BIG-IP software to install concurrently on a system. F5 does not recommend or support such a configuration, as it may lead to system instability and unknown configuration issues. The BIG-IP hotfix uninstall software currently does not warn against performing this procedure.

For example, after upgrading BIG-IP 9.4.8 build (355) to cumulative hotfix Hotfix-BIGIP-9.4.8-407.0-HF4.im, all appropriate packages will be either from the base BIG-IP 9.4.8 build (355) or from the Hotfix-BIGIP-9.4.8-407.0-HF4 build (407).
