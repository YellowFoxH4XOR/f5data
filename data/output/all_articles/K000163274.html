K000163274: BIG-IQ: Unable to open Registration Key Pool with error "result.replaceAll is not a function"

Type
Support Solution
Published
2026-09-09
Updated
2026-09-09
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0
Source
https://my.f5.com/manage/s/article/K000163274

Description

Opening a RegKey license pool in BIG-IQ Centralized Management can fail with the following messages:

  • result.replaceAll is not a function

Environment

  • BIG-IQ Centralized Management
  • Browser with outdated JavaScript support or a browser plugin or policy that restricts JavaScript functionality

Cause

The "result.replaceAll is not a function" error is associated with browser-side JavaScript compatibility. The JavaScript "String.prototype.replaceAll()" method is not supported by older browser versions, including Chrome versions older than Chrome 85.

Answer/Recommended Actions

Update the browser used to access BIG-IQ Centralized Management to a current, supported version.
