Description

Single network interface card (NIC) is supported beginning in BIQ-IQ 8.0.0. For more information, refer to K54221096: A single NIC configuration is not supported prior to BIG-IQ VE 8.0.

If you are upgrading a BIG-IQ device with prior single NIC configuration from a version earlier than 8.0.0 to any version greater than or equal to 8.0.0, then you will be operating in an unsupported configuration. For more information, refer to K71442235: BIG-IQ upgrade of single NIC to version 8.0 results in network communication failures.

If you are setting up BIG-IQ 8.0.0/8.1.0 starting from a clean installation, there are still issues that require workarounds to be applied. For more information, refer to K95712472: Workaround for single NIC configuration on BIG-IQ 8.0.0/8.1.0.

This article will cover any information not covered in above articles.

Environment

  • You are setting up a BIG-IQ device in single NIC configuration. Depending on the version of BIG-IQ you are installing, please use the solution article specific to that release.

    Note: For more information, refer to K95712472: Workaround for single NIC configuration on BIG-IQ 8.0.0/8.1.0.

Cause

None.

Recommended Actions

To setup a BIG-IQ device in single NIC configuration on BIG-IQ 8.0.0/8.1.0, please follow steps outlined in K95712472: Workaround for single NIC configuration on BIG-IQ 8.0.0/8.1.0.

About DHCP based auto-configuration

If you utilize DHCP service in your network, you will observe that the management interface object is automatically initialized for you. You will observe a single interface named mgmt in the output of the tmsh show net interface command. After you boot up your BIG-IQ device, you can logon to the BIG-IQ user interface to complete the setup wizard. Your BIG-IQ device will then be ready for operation in single NIC configuration. See the Additional Information section in this article to configure your BIG-IQ device as you normally would.

Note that the mgmt interface is for management traffic and not accessible for network configuration via the BIG-IQ user interface. If you need traffic objects, like VLAN/Self-IP objects, then you can still create them using the tmsh utility, but without referencing an interface object. If you need to perform a more exhaustive network configuration using a traffic interface via the BIG-IQ user interface, then please add an additional NIC card. Please note that in such a case it would no longer be a single NIC configuration.

In the absence of DHCP based auto-configuration

This section pertains to the scenario where you do not utilize DHCP service in your network. You may observe that some network objects are not automatically initialized after installation. After you first boot into your BIG-IQ device, please use the F5 Management Port Setup Utility (type config on the command line) to set an IP address and mask. To do so, perform the following steps:

  1. Log in to the command line/console of the BIG-IQ device as the root user.
  2. Type default at the password prompt.
  3. Enter the F5 Management Port Setup utility by entering the following command:

    config

  4. To configure the management port, enter the appropriate IP address, netmask, and management route in the screens that follow.

You can use the following commands to validate your settings:

  • To view the management port DHCP settings, enter the following command:

    tmsh list sys global-settings mgmt-dhcp

    The command should return an output similar to the following example:

    sys global-settings {
        mgmt-dhcp disabled
    }

  • To view the management IP address and netmask, enter the following command:

    tmsh list sys management-ip

    The command should return an output similar to the following example:

    sys management-ip 192.168.1.139/24 {
        description configured-statically
    }

  • To view the management route, enter the following command:

    tmsh list sys management-route

    The command should return an output similar to the following example:

    sys management-route default {
        description configured-statically
        gateway 192.168.1.254
        network default
    }

After this you can logon to the BIG-IQ user interface to complete the setup wizard. Once done, your BIG-IQ device should be ready for any additional configuration you normally need. See the Additional Information section in this article for more resources to configure the BIG-IQ device.
