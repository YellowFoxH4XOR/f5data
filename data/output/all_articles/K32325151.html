Issue

Error Message

notice tmm[<PID>]: 01340007:5: HA Connection with peer <IP>:<port> for traffic-group <name> closing.

In this error message, note the following:

  • <PID> is the process ID for the tmm process
  • <IP> is the IP address used by the peer device
  • <port> is the port number used by the peer device
  • <name> is the partition and name of the traffic group

For example:

notice tmm[8567]: 01340007:5: HA Connection with peer 10.10.10.10:1031 for traffic-group /Common/traffic-group-3 closing.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The connection used for high availability (HA) features between peer members of a device group, such as persistence and connection mirroring, closes.

This error message typically occurs when the peer system changes to an inactive state or reboots.

Impact

Connection and persistence records are no longer mirrored to the peer systems. As a result, connections may not continue or persist as expected in the event of a failover.

Recommended Actions

If the loss of mirroring communication is unexpected, verify the availability of the members in the device group and check to make sure the members are able to communicate using the mirroring IP addresses. For more information about configuring mirroring, refer to K13478: Overview of connection and persistence mirroring (11.x - 12.x).
