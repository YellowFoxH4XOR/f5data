Known Issue

This is the result of a known issue. If a user enters Protected Workspace using Internet Explorer 8, and then tries to copy a file larger than 153 KB, the file copy fails. In addition, an error message that appears similar to the following example will display, where <filename> is the name of the file the user attempted to copy:

Cannot copy <filename>: The filename, directory name, or volume label syntax is incorrect.

F5 Networks Product Development tracked this issue as CR125353 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

This issue has been fixed in cumulative HF-603-5.1-1, which has been issued for FirePass version 6.0.3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can work around this issue by connecting to FirePass using an alternate browser, such as Firefox.
