Description

High memory and CPU usage occurs on BIG-IP systems when activating, managing Application Security Manager (ASM) policies through the GUI. Symptoms include service disruptions, failovers in active/active clusters, and Out Of Memory (OOM) killer events that terminate critical processes such as java and tmm. Log messages may show repeated "invoked oom-killer" and "Killed process" entries, and the system may generate core files for affected processes.

Environment

  • Product: BIG-IP ASM (Application Security Manager)
  • Version: 17.5.1
  • ASM policies actively managed via GUI

Cause

Insufficient memory allocation for the VM and BIG-IP daemon that leads to memory exhaustion, triggering the OOM killer, which terminates essential processes and causes failovers.

Answer/Recommended Actions

Increase resources for the BIG-IP system as well increase the provision.extramb parameter based on K26427018: Overview of Management provisioning

If problem still remains after above tunning please open a case to the F5 support with the fresh qkview generated.
