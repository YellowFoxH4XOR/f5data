K41983050: The HA group score displayed with tmsh shows that the sys ha-group command no longer includes the active bonus

Applies to

Issue

Old Behavior

In versions prior to BIG-IP 11.5.0, the Score value displayed by the tmsh show sys ha-group command includes the active bonus score when you view it on an active system.

For example, the following output from the tmsh show sys ha-group command indicates a Score of 110 on the active system, and a Score of 100 on the standby system:

Active system:
----------------------------------------------------------------------
Sys::HA Group: HA_Fail-safe
----------------------------------------------------------------------
State enabled
Active Bonus 10
Score 110


Standby system:
----------------------------------------------------------------------
Sys::HA Group: HA_Fail-safe
----------------------------------------------------------------------
State enabled
Active Bonus 10
Score 100

However, the tmsh show sys ha-group command is not the appropriate context for viewing an HA group score that includes the active bonus, and can lead to confusion. The active bonus is relevant only for the active device of a traffic group, as the system requires an active traffic group association before considering the active bonus.

New Behavior

Beginning in BIG-IP 11.5.0, the HA group score no longer includes the active bonus in the output provided by the tmsh show sys ha-group command.

F5 Product Development tracked this change as ID 427579.

Impact

This change is only in how the scores are displayed, and does not affect how the scores are calculated or applied.

Recommended Actions

To view the HA group score that includes the active bonus per traffic group, you should use the tmsh show sys ha-status all-properties command.

Note: When run on a system with an active traffic group, the score includes the active bonus and is listed for each traffic group.

The output of the command appears similar to the following example:

-------------------------------------------------------------------------------------------------------------------
Sys::HA Status
Feature Key Action Fail Feature Take Client Proc Timeout
Enabled Act Data (sec)
-------------------------------------------------------------------------------------------------------------------
---(output truncated to only display relevant line)---
ha-group-score traffic-group-1 failover no yes no 110 mcpd 0
---(output truncated to only display relevant line)---


While the tmsh show sys ha-group command on the same system no longer includes the active bonus in the score value:

---------------------------
Sys::HA Group: HA_Fail-safe
---------------------------
State enabled
Active Bonus 10
Score 100
