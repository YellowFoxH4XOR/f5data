K000148300: Unable to lower default timeout from 20m to 10m without getting Error Message : Error getting auth token from login provider

Type
Support Solution
Published
2024-10-29
Updated
2024-10-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148300

Description

GUI pages fail to load with error message "Error getting auth token from login provider" if the auth-pam-idle-timeout value is configured to be less than 20 minutes.

Environment

  • BIG-IP GUI.
  • auth-pam-idle-timeout value is not 20 min (1200 sec).

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1353957

Recommended Actions

Upgrade to an unaffected version or apply the workaround described in Bug ID 1353957

Additional Information

None
