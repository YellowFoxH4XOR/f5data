Description

Declarative Onboarding does not support sha512 SNMPv3 authentication

 

Environment

Cause

RFE: Add sha512 as a supported SNMPv3 authentication protocol option in the Declarative Onboarding schema for SnmpTrapDestination, tracked under PE ID2297433.
