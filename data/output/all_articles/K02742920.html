Description

After applying a bandwidth controller policy on a virtual server, any changes to the virtual server disassociates the BWC policy

  • All Bandwidth Controller (BWC) stats are 0 (zero) even though traffic is passing.
  • The virtual server allows more bandwidth than allotted by the BWC policy, therefore allowing maximum license throughput which can cause other virtual servers to fail processing.
  • Traffic is no longer throttled according to the policy rules.

Environment

  • A BWC policy is attached to a virtual server.
  • The virtual server with the attached BWC policy is modified.
  • Basically, any changes to the virtual server disassociates the BWC policy.
Cause

Bug ID 921149: After applying static bandwidth controller on a virtual server, any changes to the virtual server disassociates the BWC policy

Recommended Actions

To re-enable the policy, detach the Bandwidth Controller policy from the virtual server, save the config, then reapply it and save the config again.
