K14649400: Clicking Web Application under Acceleration menu shows 'Not Found'

Type
Support Solution
Published
2021-12-15
Updated
2026-07-15
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP AAM: 15.1.4
Source
https://my.f5.com/manage/s/article/K14649400

Description

When clicking Web Application under Acceleration menu in the GUI, the web page will display 'Not Found'.

Environment

  • BIG-IP AAM
  • Upgrade to v15.1.4

Cause

This is due to the fix for Apache security issues in ID944513.

Recommended Actions

The following is a temporary workaround. If your BIG-IP is rebooted, some of the changes will be lost.
Note: After your BIG-IP is rebooted, you have to re-edit /etc/rc.d/init.d/httpd (step 1) and /config/httpd/conf/httpd.conf (step 2). /config/httpd/conf.d/proxy_ajp.conf (step 3) does not need to be re-applied.

  1. Go to bottom in /etc/rc.d/init.d/httpd, and add the following content
    # Check if WA package is installed (by checking the existence of
    # /usr/local/www/waui/WEB-INF/web.xml
    [ -f /usr/local/www/waui/WEB-INF/web.xml ] && OPTIONS="${OPTIONS} -DWebAccelerator"
     
  2. In /config/httpd/conf/httpd.conf
    After
    <Directory "/var/run/config/htdocs">
        Options None
        AllowOverride None
    </Directory>
    Add
    <IfDefine WebAccelerator>
        <Location /waui>
          <RequireAll>
          AuthType Basic
          AuthName "BIG-IP"
          AuthPAM_Enabled on
          AuthPAM_IdleTimeout 1200
          require valid-user
          </RequireAll>
        </Location>

        <Location "/waui/WEB-INF">
          Require all denied
        </Location>
    </IfDefine>
     
  3. Go to bottom in /config/httpd/conf.d/proxy_ajp.conf, and add the following content
    <IfDefine WebAccelerator>
      ProxyPassMatch ^/waui/(.*)$ ajp://localhost:8009/waui/$1 retry=5
    </IfDefine>
     
  4. Run the command below:
    bigstart restart httpd
