Issue

Old Behavior

In versions prior to 12.1.0, the BIG-IP DNS system did not allow the use of underscore ( _ ) characters in wide IP names. To accept underscore characters in wide IP names, the ZoneRunner utility's domain validation option had to be changed from Strict to Allow Underscores. 

Following are possible ZoneRunner domain validation options prior to BIG-IP 12.1.0:

  • Strict: Specifies that the system allows only the most narrow interpretation of DNS names; that is, alphanumeric characters and the dash ( - ) character.
  • Allow Underscores: Specifies that the system follows the Strict validation rules, and also allows the underscore ( _ ) character.

New Behavior

Beginning in BIG-IP 12.1.0, the BIG-IP DNS system allows the use of underscore characters in wide IP names, by default.

Following are possible ZoneRunner domain validation options in BIG-IP 12.1.0 and later:

  • None: Specifies that the system does not restrict the use of any characters in domain names.
  • Allow Underscores: Specifies that the system follows the Strict validation rules (see Old Behavior), and also allows the underscore ( _ ) character.

Note: The Strict option has been deprecated in BIG-IP 12.1.0 and later.

F5 Product Development tracked this change as ID 561333.

Impact

The requirement for wide IP name validation has been relaxed.

Recommended Actions

For information about changing the ZoneRunner utility's domain validation option, refer to K14926: Configuring the BIG-IP DNS system to accept underscore characters (11.0.0 - 12.0.0).
