Description

Duplicate iRule logging on mirrored connections

 

Environment

  • LTM
  • Virtual Server
  • connection mirroring
  • iRule logging

 

Cause

N/A

Recommended Actions

It's possible to mitigate this (i.e. ensure that only iRule on Active unit is logging) by enclosing all logging commands in your iRule with if block checking the HA::status

 

when HTTP_REQUEST {

if { [HA::status active]} {

log local0. "[IP::client_addr]"

}

}
