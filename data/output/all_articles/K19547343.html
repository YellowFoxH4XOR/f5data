Description
BIG-IQ Centralized Management configuration fails to load with PostgreSQL database error

Environment

  • BIG-IQ Centralized Management

Cause

Postgres Role already exists.
A failure in the config load caused the memory provisioning to not be honored.

Recommended Actions

  • In this example we use the role "fctest"
  • Fix the error and reboot. Please follow these steps in the BIG-IQ CM console:
  1. # Enter Postgres CLI
    psql -U postgres
     
  2. # Connect to tmdb database
    \connect tmdb
     
  3. # Show all users.
    Select * from auth_user;
     
  4. # Verify user 'fctest' is in the list. Delete the related user/role:
    drop role fctest;
     
  5. # Quit session
    \q
     
  6. # Reboot unit
    tmsh reboot

After the boot, please check to see if any other role is still throwing the error.  
If so, please repeat this with that role in place of "fctest"
