Description

Inquiry regarding the installation and running of SentinelOne Endpoint Detection and Response (EDR) agent on F5 BIG-IP appliances (both physical and virtual instances), including support status, recommended approaches, limitations, performance impact, and alternative security mechanisms.

Environment

  • EDR agent
  • CVE

Cause

None

Recommended Actions

The SentinelOne EDR agent is not supported for installation on F5 BIG-IP appliances (both physical and virtual) please refer to the K93238294: Support for 3rd party software installation  

As alternative option for EDR protection on BIG-IP platforms please check CrowdStrike Falcon sensor, which is officially supported.

To deploy CrowdStrike Falcon on BIG-IP:

1.For getting access for the Falcon sensor for BIG-IP please follow K000157015: Getting started with Falcon sensor for F5 BIG-IP .

2. For installation instructions on BIG-IP systems please follow K000156881: Install Falcon sensor for F5 BIG-IP on the BIG-IP system or F5 hardware platforms.
