Known Issue

The Traffic Management Microkernel (TMM) may leak memory when processing multicast packets.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system processes multicast packets.
  • The egress interface for the multicast traffic is disabled.

Impact

Memory exhaustion may cause TMM to become unstable and possibly produce a core file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to another host in the device group.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system temporarily fails to process traffic.

Workaround

To temporarily work around this issue, you can restart the TMM process. To do so, perform the following procedure:

Impact of workaround: Restarting TMM interrupts traffic processing; you should perform this task in a maintenance window. In addition, restarting TMM temporarily mitigates the issue.

  1. Log in to the BIG-IP command line.
  2. Type the following command:

    bigstart restart tmm
