K95324441: modsec_audit.log dramatically increasing

Type
Support Solution
Published
2020-01-14
Updated
2025-02-07
Applies to
  • NGINX Products
  • NGINX ModSecurity WAF
Source
https://my.f5.com/manage/s/article/K95324441

Description

When enabled, the ModSecurity module produces an extraordinary volume of data in its modsec_audit.log file.

Environment

  • NGINX WAF

Cause

There was an issue in ModSecurity. For more information, refer to https://github.com/SpiderLabs/ModSecurity/issues/2196.

Recommended Actions

To resolve this issue, perform one of the following actions:

Disable the ModSecurity audit log

  1. Using a text editor, modify the /etc/nginx/modsec/modsecurity.conf file, and add the following: 

    SecAuditEngine Off

  2. Save and close the file.
  3. Reload the nginx process by running the following command:

    sudo service nginx reload

Update the ModSecurity module

Upgrade the ModSecurity module to at least the 1.0.0-10 version using the system package manager.
