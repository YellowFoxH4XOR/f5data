Description

Immediately following an upgrade of an HA pair/cluster BIG-IP, it is expected behavior to see the ConfigSync state show Changes Pending, Not all devices in sync, or Disconnected. This is because the upgrade process includes a Reboot in order to Activate the new Boot Location containing the new version of BIG-IP code that the BIG-IP is being upgraded to. And a Reboot causes the BIG-IP to Reload it's config from the saved-config in it's file-system.

Further, when upgrading an HA pair or cluster of BIG-IP's, ConfigSync functions are not supported between HA peer BIG-IP's running different versions of code. This is because the config file's Config Schema's are BIG-IP version specific. So you cannot perform a ConfigSync between HA peer BIG-IP's while the upgraded BIG-IP is running the new version of code and the not yet upgraded BIG-IP is still running the old version of code. 

Once both HA peer BIG-IP's are upgraded and running the same version of BIG-IP, ConfigSync functionality between the HA peers should be restored. But if they are configured to use Manual Sync, their respective ConfigSync states will still show Changes Pending, Not all devices in sync, or Awaiting initial sync, since there has not yet been a successful Manual ConfigSync operation since their configs were Reloaded following their Upgrades. And once a Manual ConfigSync has been successfully completed, both HA peer BIG-IP's ConfigSync states should show "InSync". If they are configured for Auto Sync, then the HA peer BIG-IP's should automatically perform a ConfigSync operation once the second HA peer BIG-IP has completed it's Upgrade process.

Environment

Relevant environmental factors:

  • BIG-IP's in an HA pair/cluster arrangement that are being Upgraded.

Cause

The ConfigSync state becoming Changes Pending, Not all devices in sync, or Disconnected following an Upgrade of one or more of the HA peer BIG-IP's in an HA pair or cluster.

Recommended Actions

Once all HA peers in an HA pair of cluster of BIG-IP's have been successfully upgraded, and a Manual ConfigSync is needed to bring them back to an InSync state:

  1. Select the HA peer BIG-IP from which you want to perform a Manual ConfigSync to all the other HA peer BIG-IP's.
  2. Navigate to Device Management  ››  Overview and select the (Self) device.
  3. Then click the Sync Device to Group option, and click OK when prompted to see if you're sure you want to proceed.
