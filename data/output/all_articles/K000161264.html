K000161264: SCIM-Provisioned Users Display "0 Namespaces" in F5 Distributed Cloud UI Despite Correct Group-Based Access

Type
Support Solution
Published
2026-05-13
Updated
2026-06-12
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud WAF
Source
https://my.f5.com/manage/s/article/K000161264

Description

In F5 Distributed Cloud (XC), users provisioned via SCIM and assigned to groups with namespace roles may show "0 namespaces" in their user profile within the XC UI. Despite this display, users retain full access to resources and permissions as defined by their group assignments. The issue is limited to the UI display and does not affect functional access.

Relevant error messages/logs:

  • User profile in XC UI shows "0 namespaces" for SCIM-provisioned users.
  • Group assignments contain multiple namespace roles.
  • Users can access and perform actions in all assigned namespaces.
  • Azure SCIM provisioning logs show successful provisioning with no errors.

Environment

  • F5 Distributed Cloud (XC) platform
  • SCIM and SSO integration with Azure Entra ID
  • Users provisioned via SCIM and assigned to groups with namespace roles
  • Group configuration includes multiple namespace roles

Cause

The "0 namespaces" display for SCIM-provisioned users in the XC UI is functioning as designed. Namespace access is inherited from the group, and the UI does not reflect these assignments at the individual user level. This is a platform limitation and does not impact user permissions or access.

Answer/Recommended Actions

  • No action required if users have functional access to resources.
  • Namespace assignments for group-based access are visible under Administration > IAM > Groups in the XC UI, not at the individual user level.
  • To request that namespace assignments be displayed at the user level in the UI, submit a Request for Enhancement (RFE).
  • Monitor for any functional access issues and report if observed.

Additional Information

  • This behavior applies to all users who derive namespace access from group assignments, regardless of provisioning method.
  • The display of "0 namespaces" at the user level is a UI limitation and does not affect actual permissions or access.
  • If users are unable to access resources or perform actions as expected, further investigation may be required.
