Known Issue

The Configuration utility displays special characters incorrectly.

This issue occurs when the following condition is met:

  • The Input field value contains a special character

Impact

The Manage Sessions (Access Policy > Manage Session) page and reports (Access Policy > Event Logs) display special characters as non-readable content.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Manage Sessions page and reports display special characters as non-readable content.

Status
