Known Issue

This is the result of a known issue. When the BIG-IP PSM security profile is configured to block requests that violate the policy, the BIG-IP PSM should display a blocking response page on the clients screen indicating that the request was rejected. However, the BIG-IP PSM may fail to a display blocking page when a request is blocked by the PSM HTTP security profile.

F5 Product Development is tracking this issue as CR125179.

This issue has been fixed in BIGIP-9.4.8-396.1-HF3 BIG-IP 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
