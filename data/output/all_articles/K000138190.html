Description

  • Steps to export SAML metadata (BIG-IP as SP or IdP)

Environment

  • BIG-IP with APM and SAML

Cause

Exporting the metadata for a local SP or IdP Service requires several steps.

Recommended Actions

  1. List the SP services
curl -kv -u admin https://localhost/mgmt/tm/apm/aaa/saml/ | jq .
  1. Use the "selfLink" property from step 1 to export the metadata of the SP object to /shared/tmp/meta.xml on the BIG-IP
curl -kv -u admin -X PATCH 'https://localhost/mgmt/tm/apm/aaa/saml/~<partition>~<SP_name>?ver=<version>' -H 'Content-Type: application/json' -d '{ "exportMetadata": "no-signing", "metadataFile": "/shared/tmp/meta.xml" }' | jq .
  1. Download the metadata
curl -kv -u admin 'https://localhost/mgmt/tm/util/bash' -H 'Content-Type: application/json' -X POST -d "{\"command\":\"run\",\"utilCmdArgs\":\" -c 'cat /shared/tmp/meta.xml'\"}" | jq -r .commandResult

To export IdP metadata start by listing the IdP services using the URL https://localhost/mgmt/tm/apm/sso/saml/ .
