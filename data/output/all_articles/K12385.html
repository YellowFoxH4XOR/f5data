Topic

The BIG-IP APM system uses software libraries from OPSWAT's Software Development Kit (SDK) to obtain information about third-party security software, such as antivirus and firewall, located on remote access client systems. This information is used in pre-logon sequences, protected configurations, and access policies to ensure that endpoint security policies are properly enforced.

You can find support charts for antivirus applications in Online Help, and the charts are updated when you apply OPSWAT hotfixes. For information about navigating to the OPSWAT support chart or to view the currently installed EPSEC software version for the BIG-IP APM system, perform the following procedures:

  • Navigating to the OPSWAT support chart on a BIG-IP APM system
  • Viewing the installed EPSEC software version

Navigating to the OPSWAT support chart on a BIG-IP APM system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility.
  2. On the Welcome page, click the OPSWAT Application Security integration support charts link.
  3. Select integration type and operating system type from the drop-down menus.
  4. Click Show.

Viewing the installed EPSEC software version

To view the installed EPSEC version from the Configuration utility or the TMOS Shell (tmsh), perform one of the following procedures:

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

Viewing the installed EPSEC software version from the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to System > Software Management.
  3. Click the Antivirus Check Updates tab.
  4. To view the installed version, click Device EPSEC Status.

Viewing the installed EPSEC software version from tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To view the current EPSEC software version, type the following command:

    show /apm epsec software-status

  3. To exit tmsh, type the following command:

    quit
