Topic

You can synchronize the configuration between BIG-IP systems in a redundant pair using the Configuration utility or the command line.
 

Configuration utility

To synchronize the configuration using the Configuration utility, perform the following steps:

  1. From the navigation pane, click System.
  2. Click the Redundant Properties tab.
  3. Click Synchronize Configuration.

Command line

Type the following command to synchronize only the bigip.conf file:

bigpipe configsync

Type the following command to synchronize all shared files:

bigpipe configsync all
