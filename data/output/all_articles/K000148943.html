K000148943: Firefox for Android doesn't pass traffic to the Proxy Server when a VPN tunnel is connected via the F5 Access app

Description

 Firefox for Android doesn't pass traffic to the Proxy server when F5 Access connected

Environment

  • F5 Access app version 3.0.9 and higher
  • Firefox for Android
  • Client Proxy Settings and Client Proxy Autoconfig Script settings in a network access resource enabled with non-default (TCP 80) port.

Cause

The main issue arises because Firefox does not automatically fetch the custom proxy settings obtained during the VPN connection using the F5 Access app.

By default, Firefox tries to connect using TCP port 80, which leads to connectivity problems when a custom TCP port is required.

    Recommended Actions

    Note: Firefox for Android Beta and Nightly versions only allow editing proxy configuration. The workaround doesn't refer to regular Firefox for Android

    To ensure Firefox correctly uses the custom TCP port specified in the Client Proxy Autoconfig Script, manual configuration is required in Firefox:

    1. Open Firefox and type about:config into the address bar.
    2. In the search box, type proxy to list all options related to proxy settings.
    3. Change the value of network.proxy.type to 2 and set network.proxy.autoconfig_url to the URL of the PAC file. To edit these options tap on the edit box below the configuration option twice to start editing.
    4. Provide the link to the locally stored .pac file, for example, file:///storage/emulated/0/Download/proxy.pac, or specify the location where the file is stored.
    5. Close the about:config page. Now, Firefox should use the PAC file for proxy settings with custom TCP port.
