K24225343: iControl SOAP calls intermittently timeout and fail to respond

Type
Support Solution
Published
2023-10-12
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K24225343

Description


Automation iControl SOAP calls fail, resulting in retries every minute until the iControl SOAP call succeeds. This can cause a pause for up to 20 minutes, impacting the operator's ability to move to their next task. You may see the following logs in /var/log/secure.

err httpd[22683]: [error] [client < IP > ] FastCGI: comm with server "/usr/local/www/iControl/iControlPortal.cgi" aborted: idle timeout (300 sec)
err httpd[22683]: [error] [client < IP >] FastCGI: incomplete headers (0 bytes) received from server "/usr/local/www/iControl/iControlPortal.cgi"

Environment

  • iControl
  • BIG-IP LTM

Cause

Unknown

 

Recommended Actions

  •  bigstart restart restjavad
  •  bigstart restart restnoded

Additional Information

None
