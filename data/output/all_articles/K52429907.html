Known Issue

The resizevol script may fail to run on the BIG-IQ system and report an error.

This issue occurs when all of the following conditions are met:

  • You downloaded the F5_Networks_Disk_Size_Tools.zip file from F5 Downloads page and uploaded it to the BIG-IQ system.
  • You extracted the resizevol script from the downloaded file and attempt to run the script on the BIG-IQ system.

The resizevol script included in the F5_Networks_Disk_Size_Tools.zip file was incorrectly saved in a DOS/Windows format. As a result, the script contains Carriage Return Line Feed (CRLF) characters that prevent it from running correctly on the BIG-IQ system.

Impact

The resizevol script fails to run on the BIG-IQ system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to run the resizevol script, the script fails and report an error similar to the following example:

    -bash: ./resizevol: /bin/sh^M: bad interpreter: No such file or directory

Workaround

To work around this issue, you can remove the CRLF characters from the resizevol script by using the vim command. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IQ system.
  2. Remove the CRLF characters from the resizevol script by entering the following command syntax:

    vim <path/to/the/downloaded/resizevol/script> -c 'set fileformat=unix'

    For example, you would enter the following command to remove the CRLF characters from the /var/tmp/resizevol script:

    vim /var/tmp/resizevol -c 'set fileformat=unix'

  3. Save the change and exit the vim editor by entering the following key sequences:

    :wq
