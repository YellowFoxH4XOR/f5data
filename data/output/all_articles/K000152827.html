K000152827: Tenant deployments stuck in pending state with error message: "Tenant deployment will be processed when the crypto devices are available"

Type
Support Solution
Published
2025-07-30
Updated
2025-07-30
Applies to
  • F5OS
  • F5 Distributed Cloud Services
  • F5OS-C: 1.6.0, 1.6.X, 1.8.X, 1.8.1, 1.8.0, 1.6.2, 1.6.1
Source
https://my.f5.com/manage/s/article/K000152827

Description

Tenant deployment remains in pending state with error:

Resource allocation failed - Node is up but Platform services not responding  Tenant deployment will be processed when the crypto devices are available. 

The velos.log located on the Partition shows an error similar to the following:

2025-07-28T19:50:07.160515+00:00 <hostname> orchestration-agent[7]: nodename=controller-1(p2) priority="Err" version=1.0 msgid=0x505000000000049 msg="Qat Devices are not available on node. ," TENANT="xxxxx" node=x.

Environment

  • VELOS-C Controller (1.6.2)
  • VELOS-C Partition (1.8.1)

Cause

Software Version mismatch between the Controller and Partition.

Recommended Actions

Ensure that both the Controller and Partition are running the same software version, in accordance with article K86001294.

Additional Information

Running mismatched software versions between the Controller and Partition is not officially supported. The standard upgrade process for VELOS systems involves upgrading the Controller first, followed by the Partitions, ensuring that both ultimately run the same software version.
