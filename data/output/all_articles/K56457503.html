Topic

You should consider using this procedure under the following conditions:

  • You want to estimate the number of Data Collection Devices (DCD) deployed in a given setup.
  • You want to set custom retention time for the managed BIG-IP modules.

The result produced by the sizing scripts in this article is calculated based on statistic load only. You may need additional resources if you plan to enable listeners on the DCD. For the required tool and information, refer to the DCD Sizing Guidelines chapter of the BIG-IQ: Sizing Guidelines manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

The following steps briefly describe the process:

  1. Download and install the DCD sizing script.
  2. Estimate the number of DCDs with the dcds-sizing.py script; by the end of this step, you should have sufficient information to estimate the number of DCDs you need for your environment.
  3. Deploy the DCDs as recommended in step 2.
  4. Configure deployment with selected attributes. This step is necessary if your DCD deployment needs to function based on earlier selected attributes.

Description

This article describes the procedures for estimating the number of DCDs recommended in your particular setup with the provided sizing scripts, as well as setting the custom data retention time for the managed BIG-IP modules. There are two scripts included in this tool:

dcds-sizing.py

This script interacts with the user and collects necessary data including the data retention time for the following modules:

  • SSLO (SSL Orchestrator)
  • SIP (Session Initiation Protocol)
  • LTM (Virtual servers and pool members)
  • AFM (IP reputation, AFM enforced/staged)
  • ASM (Alerts stats, transaction, ASM memory, bot defense, ASM violations)
  • DNS (DNS profiles)
  • Advanced DNS (DNS cache, DNS zones, WideIP)
  • Network DoS
  • DoS (Other type of DoS)
  • Access (APM, SWG)
  • TCP (AVR TCP profile)
  • HTTP (AVR HTTP profile)

The retention time is required for calculating the necessary resource, as well as the number of DCDs. If the retention time is specified other than the default value (10 hours), a custom command output will be provided for later use.

retention_per_module_settings.py

The retention script is used to set the custom retention values to the specific modules. The exact command is provided by the dcds-sizing.py script output.

Note: You should only run the retention script on a BIG-IQ system with DCD cluster already configured.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IQ system.

Procedures

  • Download the DCD sizing script
  • Install the DCD sizing scripts
  • Estimate the number of DCDs with the dcds-sizing.py script
  • Deploy the DCDs
  • Configure your deployment with the selected attributes using the retention_per_module_settings.py script

Download the DCD sizing script

You can find and download the DCD sizing script file on the F5 Downloads site. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to the F5 Downloads site.
  2. Select Find a Download.
  3. Select Centralized Management.
  4. Select the version you are currently running.
  5. Select BIG-IQ_Sizing_Tools.
  6. Download all of the following files to your workstation. You need to review and accept the EULA and choose a location from which to download.
    • dcd_sizing.tar.gz
    • dcd_sizing.tar.gz.md5

Note: Before extracting the downloaded TAR file, you can verify the MD5 checksum by transferring the MD5 file to the BIG-IQ system and using the following command to perform the verification:

md5sum --check dcd_sizing.tar.gz.md5

Install the DCD sizing scripts

You can install the sizing script by extracting the downloaded tarball on the ElasticSearch node. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Use an SCP client to copy the downloaded TAR file to the target ElasticSearch node (BIG-IQ Centralized Management or DCD).

    Note: For information about uploading files to an F5 system, refer to K175: Transferring files to or from an F5 system.

  2. Log in to the BIG-IQ command line.
  3. To extract the scripts, go to the directory where the tarball is located and enter the following command:

    tar xvfz dcd_sizing.tar.gz -C /

    The outputs appear similar to the following example:

    shared/
    shared/scripts/
    shared/scripts/dcds-sizing.py
    shared/scripts/retention_per_module_settings.py

  4. Verity that the following files are extracted to the corresponding directories:

    dcd-sizing.py under /shared/scripts/ directory
    retention_per_module_settings.py under /shared/scripts/ directory

Estimate the number of DCDs with the dcds-sizing.py script

You can estimate the number of DCDs recommended in your environment using the dcds-sizing.py script. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ command line.
  2. To change to the directory where the script is located, enter the following command:

    cd /shared/scripts

  3. To run the sizing script, enter the following command:

    ./dcds-sizing.py

Deploy the DCDs

To deploy the DCDs in your environment, as recommended in the Estimate the number of DCDs with the dcds-sizing.py script procedure, perform the steps in the following sections of the Setting up and Configuring a BIG-IQ Centralized Management Solution guide:

  • Install BIG-IQ Data Collection Devices
  • Build the Data Collection Cluster
  • Configure Data Collection Devices

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Configure your deployment with the selected attributes using the retention_per_module_settings.py script

To configure your deployment with the selected attributes for each managed BIG-IP module with the retention command retrieved from the DCD sizing script, perform the following procedure:

Important: This procedure is necessary if you want your DCD deployment to function based on earlier selected attributes.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ command line.
  2. To change to the directory where the script is located, enter the following command:

    cd /shared/scripts

  3. To set the retention time, enter the command output copied previously from running the dcd-sizing.py script. For example:

    ./retention_per_module_settings.py --module_info="sslo-group 10 120 20 12" --module_info="sip-group 11 130 21 11" --module_info="ltm-group 12 135 22 12" --module_info="afm-group 13 140 20 11"

    Retention values changed successfully
