Description

Unable to Establish High Availability between two DDoS Hybrid Defenders. 

Environment

  • BIG-IP Version 13.1.3
  • DDoS Hybrid Defender Version 13.1.0-3.1.334
  • The failover status remains at 'Standalone'

Cause

Due to the incompatibility of BIG-IP software with the DDoS Hybrid Defender version, the high availability between devices is not established. 
K73914526: F5 DDoS Hybrid Defender compatibility matrix

Recommended Actions

To establish high availability between two DDoS Hybrid Defenders, downgrade the BIG-IP software to 13.1.0.x.  
K14568: Downgrading BIG-IP software (10.x - 15.x)

Important: When you downgrade from version 13.1.3 to version 13.1.0, configuration will not be copied to the new boot location.

The latest point release in 13.1.0 can be found in Downloads site.

Please refer to the manual to configure the High Availability again:  Manual Chapter : Installing DDoS Hybrid Defender for High Availability
