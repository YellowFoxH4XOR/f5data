Known Issue

This is the result of a known issue. Under rare conditions, it is possible for the BIG-IP ASM to incorrectly interpret some HTTPS requests as HTTP.  When this occurs, the BIG-IP ASM learns HTTP type objects and flows for the HTTPS application. This is a result of an issue that has been known to occur if multiple HTTPS requests are present on the same TCP stream.

F5 Networks Product Development tracked this issue as CR111331 and it was fixed in BIG-IP ASM version 10.0.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, Hotfix-BIGIP-9.4.6-403.0-HF1 has been issued for BIG-IP ASM version 9.4.6. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
