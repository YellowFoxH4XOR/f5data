Description

In the BIG-IP GUI, if you navigate to Statistics > Performance Reports > Active Connections and click View Detailed Graph. You will see a graph named Active SSL Connections.

Even though many client SSL connections were received by SSL virtual servers, you still see the SSL Client curve in the graph always displaying 0.

Environment

  • Version 15.1.x and later
  • BIG-IP LTM
  • Actvie SSL connections stats graph

Cause

ID 1189909

 Recommended Actions

You can use the alternate method mentioned in this article K76898322 to see the Active client-side SSL connections.
