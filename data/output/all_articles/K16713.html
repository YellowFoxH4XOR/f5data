Known Issue

The BIG-IP system may not update the Sync Status information when devices are added or removed from the device trust domain.

Impact

The BIG-IP system displays incorrect Sync Status information.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the standby device is removed from the active BIG-IP system trust domain, output from the tmsh show cm sync-status command displays an incorrect In Sync status for the standby BIG-IP system.

    For example:

    ------------------------------------------------------------------------------------------
    CM::Sync Status
    ------------------------------------------------------------------------------------------
    Color green
    Status In Sync
    Summary All devices in the device group are in sync
    Details
    /Common/bigip5-askf5.com: connected (for 333 seconds)
    /Common/device_trust_group (In Sync): All devices in the device group are in sync
  • The BIG-IP system logs error messages to the /var/log/ltm file that appear similar to the following example:

    notice mcpd[6016]: 01071431:5: Attempting to connect to CMI peer 10.11.19.25 port 6699
    notice mcpd[6016]: 0107143a:5: CMI reconnect timer: disabled, all peers are connected
    err mcpd[6016]: 0107142f:3: Can't connect to CMI peer 10.11.19.25, port:6699, Transport endpoint is not connected
    notice mcpd[6016]: 0107143a:5: CMI reconnect timer: enabled
