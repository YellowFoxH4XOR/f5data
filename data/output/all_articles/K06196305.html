Description

The BIG-IP did not forward packets to the backend pool member, despite receiving multiple retransmissions, resulting in a reset and broken application flow.

Environment

  • Fastl4 / Performance Layer 4
  • Virtual Server load balancing HTTPS
  • HTTP profile applied

Cause

Virtual server is load balancing SSL/TLS passthrough traffic, with a HTTP profile. This is an incompatible configuration.

The limitations of HTTP profiles and Performance Layer 4 virtual servers are described in:

  • K16446: The BIG-IP system now allows a Performance (Layer 4) virtual server to have an associated HTTP profile

Recommended Actions

Remove the HTTP profile from the virtual server.
