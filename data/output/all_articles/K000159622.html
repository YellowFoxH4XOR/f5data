Description

  • You created self IP address and VLAN for a newly created route domain on one of the BIG-IP in HA.
  • When you try to sync the configuration, you get below error message:

Sync Failed
A validation error occurred while syncing to a remote device
Sync error on BIG-IP-02.f5.com: Load failed from /Common/BIG-IP-01.f5.com 01070973:3: The specified route domain (<Route Domain>) does not exist for address (<IP address>%<Route Domain>).
Recommended action: Review the error message and determine corrective action on the device

Environment

  • BIG-IP LTM
  • Config Sync

Cause

Non-floating self IP addresses, VLANs, Route domain, etc. configuration does not sync between devices in HA. For reference K21259300: BIG-IP items that are not synchronized between device group members during a ConfigSync operation.

Answer/Recommended Actions

Create VLAN, self IP addresses and route domain on the peer device.

None
