Known Issue

A large number of Secure Sockets Layer (SSL) certificates or keys may cause the Configuration utility to fail with an internal server error.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a large number of SSL certificates or keys (approximately 3000).
  • You attempt to view or edit SSL certificates or keys using the Configuration utility.

Impact

You are unable to view or edit SSL certificates or keys using the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H664206 on the Diagnostics > Identified > Medium screen.
  • The Configuration utility displays the following example error message:

    (500) Internal Server Error

  • You experience slow responses from the Configuration utility.

Resolution

Status

F5 Product Development has assigned ID 600052 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, use the Traffic Management Shell (tmsh), instead of the Configuration utility, to view or edit SSL certificates or keys.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
