Topic

When configuring a Security Domain, a password is required for the Security Operator (SO).

Note: For more information, refer to the Configuring and Maintaining a FIPS Security section of the BIG-IP LTM Platform Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Once the SO password is set, it cannot be changed without reinitializing the FIPs card. It is important to choose a strong security password, in order to prevent having to reconfigure and reinitialize a Security Domain.
