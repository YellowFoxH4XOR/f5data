Known Issue

When multicast traffic, such as RIPv2 or EIGRP packets, cross Virtual Local Area Network (VLAN) groups in a failover configuration, a bridge loop or packet storm can occur after failover.

The BIG-IP LTM system tracks multicast packets forwarded between L2 VLAN group members as active connections. When the BIG-IP LTM system fails over, the standby units will still forward packets for these active connections between the L2 VLAN group members. This creates a situation where both BIG-IP systems are forwarding L2 traffic, and a multicast traffic loop is created in the L2 network. The faster the switch, the faster the network will be flooded with the multicast packets, affecting network performance.

F5 Product Development tracked this issue as CR49812 and it was fixed in BIG-IP LTM 9.1.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
