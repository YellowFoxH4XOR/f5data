K000090842: NGINX Controller Installation fails with the message "error: timed out waiting for the condition"

Type
Support Solution
Published
2021-10-25
Updated
2026-07-30
Source
https://my.f5.com/manage/s/article/K000090842

Description

NGINX Controller installation script may fail with the following messages:

 

"Waiting up to 120s for coredns deployment to be ready...

Waiting for deployment "coredns" rollout to finish: 0 of 2 updated replicas are available...

error: timed out waiting for the condition"

 

Environment

  • You are trying to install NGINX Controller
  • coredns pods are crashing continuously and unable to reach a "running" state

Cause

Routing configuration issue, coredns tries to reach an internal IP address and a static route for the same subnet that points to external gateway exists

Recommended Actions

  • Check the output of the command "kubectl describe pod <COREDNS_POD_NAME> -n kube-system"
  • Check the routing table to verify if you have any entries that points to an external gateway for affected subnet in question.
