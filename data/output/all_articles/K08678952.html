K08678952: BIG-IQ TLS v1.0 for iQuery port 4353

Published
2022-03-17
Updated

Applies to

Source

Description

You are receiving BIG-IQ TLS v1.0 vulnerability report for iQuery port 4353

Environment

  • BIG-IQ Central Management
  • BIG-IQ v8.x
  • iQuery port 4353
  • TLS 1.0

Cause
Big3d is enabled by default on BIG-IQ v8.x and is using TLS1.0, as seen on the example below:

Example:
[root@BIG-IQ-1:Active:Standalone] ~ # tmsh list sys db big3d.minimum.tls.version all-properties
sys db big3d.minimum.tls.version {
    default-value "TLSv1"
    scf-config "true"
    value "TLSv1"
    value-range "string"
}
[root@BIG-IQ-1:Active:Standalone] config # netstat -tulpn | grep 4353
tcp6       0      0 :::4353                 :::*                    LISTEN      5561/big3d

Recommended Actions

  1. It's not functioning on BIG-IQ.
  2. Big3d can be safely disabled on BIG-IQ.
  3. Log in to tmsh by typing the following command:
    # tmsh
  4. Disable the big3d component which will stop the service and prevent it from starting on subsequent reboots by typing the following command:
    # modify /sys service big3d disable

Additional Information

There is no impact of disabling big3d on BIG-IQ on licensing functionality
