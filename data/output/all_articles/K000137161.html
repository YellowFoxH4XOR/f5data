Description

After upgrading AS3 from 3.40 to 3.44, the AS3 deployment is failing due to SNAT pool configuration

 

 ...
       "Common": {
            "class": "Tenant",
            "Shared": {
                "class": "Application",
                "template": "shared",
                "snat": {
                    "class": "SNAT_Pool",
                    "snatAddresses": [
                        "192.168.1.100"
                    ]
                },
...


Error message in /var/log/restnoded/restnoded.log:

severe: [appsvcs] {"message":"Declaration failed: 01020066:3: The requested SNAT Translation (/Common/192.168.1.100) already exists in partition Common.","level":"error"}
 

Environment

  • BIG-IP
  • SNAT object
  • AS3 version 3.44-3.45

 

Cause

ID1349025
Github issue:  AS3 SNATpool declaration: error happening after the first deployment #727 

Recommended Actions

Update to AS3 v3.46+

The procedure to update AS3 on BIG-IQ is in the following article:
