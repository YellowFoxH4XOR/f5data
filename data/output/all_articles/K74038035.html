Issue

Error Message

tmrouted[<PID>] 01910602 : Failed to suppress route <%s> matching admin network

In this error message, note the following:

  • <%s> is the route that matches the BIG-IP management network
  • <PID> is the process ID for the tmrouted process

For example:

tmrouted[50702] 01910602 : Failed to suppress route 10.15.42.0/24 matching admin network

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file.

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP system is running an advanced routing protocol, such as Open Shortest Path First (OSPF).
  • The BIG-IP system failed to prevent an advertised route that matched the management network route from being added to the Linux kernel routing table.

The BIG-IP system may log the above error message when an adjacent router advertises a route that matches the BIG-IP management network, and the system is unable to suppress the advertised route.

Impact

Access to the management interface may fail.

Recommended Actions

Verify whether the BIG-IP management network route exists in the Linux kernel routing table and was not overwritten by the advertised route. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. To view existing routes in the Linux kernel routing table, including the management route, type the following command:

    netstat -rn

    For example, the following output indicates that the 10.15.42.0/24 network is assigned to the management interface:

    Kernel IP routing table
