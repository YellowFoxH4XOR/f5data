K000157191: Customer Edge (CE) - errors: HTTP 502 - ext_authz_cluster

Description

You are running a CE cluster on XC and you start getting HTTP 502 errors "ext_authz_cluster". 

Environment

  • Customer Edge (CE)

Cause

The issue was caused by the expiry of an in-memory security certificate used by our proxy service to securely connect to your backend systems. When these certificates expire, the proxy is unable to establish a secure connection, resulting in temporary service disruptions.

Recommended Actions

To resolve the issue a restart of the service or cluster is needed so it will renew the certificate.

Additional Information

Remember to keep the SW version of the CE updated because if the SW version of the CE is older than 6 months it may start to malfunction so it is better to plan a maintenance window to upgrade your CE.
