Known Issue

The BIG-IP system may log erroneous "blade powered down" and "blade powered up" messages.

This issue occurs when all of the following conditions are met:

  • The platform is a VIPRION 2400 chassis with B2100 blade(s) installed.
  • The lights-out processor (LOP) restarts as a result of a watchdog timeout.

If the lopd process loses connectivity with the LOP subsystem, a watchdog timeout may restart the LOP. When the LOP restarts, the lopd process sends an incorrect power state message to the BIG-IP system. The BIG-IP system interprets the message to indicate that the blade has been powered off. After LOP restarts, the BIG-IP system detects the blade as powered up.

Impact

Users may inaccurately interpret "blade powered down" and "blade powered up" messages as a hardware failure.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H435234 on the Diagnostics > Identified > Medium screen.
  • The /var/log/ltm file contains error messages that appear similar to the following examples:

    • err clusterd[<pid>]: 013a0009:3: Blade 2: blade1 powered DOWN
    • notice clusterd[<pid>]: 013a0010:5: Blade 2: blade 1 powered up
