Topic

You can configure an XML profile within the BIG-IP ASM security policy to protect XML-based web traffic. When you create the XML profile, you define the validation configuration by importing an XML-based schema file into the profile. The XML profile then protects XML applications by validating whether the incoming traffic complies with the predefined schemas or WSDL documents.

When the Allow Attachments in SOAP Messages setting in the XML profile is enabled, it specifies that the security policy allows attachments in SOAP messages. If the Allow Attachments in SOAP Messages setting is disabled, and the security policy processes a request that contains a multi-part SOAP message, the following violation will be logged to the /var/log/asm file and to the Reporting screen in the Configuration utility:

Illegal attachment in SOAP message
