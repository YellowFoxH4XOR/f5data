Issue

Previously, FirePass did not support Terminal Servers favorites for Linux client systems.

Starting in FirePass 6.0.3, FirePass supports Microsoft Terminal Server and Citrix MetaFrame Java Terminal Servers favorites for Linux client systems. You can configure Java Terminal Servers favorites on the Application Access > Terminal Servers > Resources page in the FirePass Administrative Console. When configuring a Terminal Servers favorite, select the Java client check box to support Linux clients. 

For information about which versions of Linux are supported, refer to the FirePass Controller Client Compatibility Matrix for your version of FirePass software.
 
Note: Some features are not available in the Java Terminal Servers clients. For more information, select the Help link in the top right corner of the Application Access > Terminal Servers > Resources page.
 
F5 Product Development tracked this enhancement as CR28772 and it was included starting in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.
