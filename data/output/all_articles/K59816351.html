K59816351: High CPU Utilization on control plane cores

Type
Support Solution
Published
2022-04-13
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 14.1.4
  • BIG-IP i7000 Series
  • BIG-IP i10000 Series
  • BIG-IP i5000 Series
Source
https://my.f5.com/manage/s/article/K59816351

Description

  • CPU usage constantly high on control plane cores (1, 3, 5, ...,etc)
  • The top output shows the kipmi0 process using a high CPU percentage such as in the example below:
      PID   USER    PR  NI    VIRT    RES   SHR    S   %CPU    %MEM     TIME+      COMMAND
     1441  root      39  19     0      0     0     R    94.1    0.0      10818:51     kipmi0
     21248 root     1   -19  87.5g 145688 122896   S    41.2    0.1      143665:31    tmm.0
     
  • Messages similar to below are logged in the /var/log/ltm file
    warning chmand[7445]: 012a0004:4: Unable to get sensor reading for sens num 2
    warning chmand[7445]: 012a0004:4: Error writing SEL records, BmcDev: Unable to get SEL Info
    warning chmand[7445]: 012a0004:4: AomSelLogger: unable to process SEL logs

Environment

  • BIG-IP LTM
  • Running on i5600, i5800, i7600, i7800, i10600, i10800 platforms

Cause

Undetermined
 

Recommended Actions

  • Run an EUD test to confirm or rule out a hardware issue with the unit.
    NB: There is a chance the issue may be resolved during the reboot as part of running the eud process.

Additional Information

K7172: Overview of the End User Diagnostics software
