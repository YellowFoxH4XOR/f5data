K000150866: Unable to add new API definitions. Getting a 403 Forbidden error

Type
Support Solution
Published
2025-04-15
Updated
2025-04-15
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud Web App & API Protection
Source
https://my.f5.com/manage/s/article/K000150866

Description

I'm getting the following error when attempting to add new API definition in my tenant:

 

"Http failure response: 403 Forbidden 

Server returned forbidden, you are probably not allowed to do this operation."

 

 

Environment

WAAP

Distributed Cloud Services API

 

Cause

WAAP Advanced Add-on Service is not enabled on the tenant.

*Advanced WAAP services (like the add-on) may require a subscription.

 

Recommended Actions

Reach your F5 Sales representative & Account Manager to ensure the WAAP Advanced Add-on Service is properly activated in your subscription.

Contact F5XC Support or your account manager to enable specific services.

 

Additional Information
