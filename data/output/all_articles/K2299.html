Note: For information about BIG-IP versions 9.x and later, refer to K7577: BIG-IP spanning tree protocol (STP) compatibility with tagged VLANs.

Spanning Tree Protocol (STP) domains allow loop resolution in configurations where one or more external switches are connected in parallel with an IP Application Switch.

BIG-IP does not currently support the use of STP in conjunction with VLAN tagging. BIG-IP can, however, transport STP through VLANs, passively participating in STP.

For specific information about configuring STP for BIG-IP, refer to the BIG-IP Reference Guide. For more information about Spanning Tree Protocol, refer to the IEEE 802.1D standard.
