Known Issue

When Lightweight Directory Access Protocol (LDAP) remote-auth is configured with user-template and remote-user, remote users cannot log in.

This issue occurs when all of the following conditions are met:

  • You have configured LDAP remote-auth with user-template.
  • Remote-user is configured to permit login.

Impact

Remote users cannot log in.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/secure log file, you notice error messages similar to the following example:

    info httpd(pam_audit)[20453]: User=<user> tty=(unknown) host=192.168.1.1 failed to login after 1 attempts (start="Fri Mar 8 17:24:46 2019" end="Fri Mar 8 17:25:47 2019").

    info httpd(pam_audit)[20453]: 01070417:6: AUDIT - user <user> - RAW: httpd(pam_audit): User=<user> tty=(unknown) host=192.168.1.1 failed to login after 1 attempts (start="Fri Mar 8 17:24:46 2019" end="Fri Mar 8 17:25:47 2019").

Workaround

To work around this issue, you can use bind-dn or a user template for authentication; however, you cannot use both.

Impact of workaround: Performing this action should not have a negative impact on your system.
