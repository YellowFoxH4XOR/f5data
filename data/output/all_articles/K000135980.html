Description

Endless HTTP 302 redirection loop after Jenkins HTTP 403 respond.

 

Environment

LTM

Jenkins

HTTP Header: GET /securityRealm/commenceLogin?from=%2f HTTP/1.1


Cause

This response is sent from the server back to the BIG-IP:

 

HTTP/1.1 403 Forbidden

Date: Sun, 20 Aug 2022 17:01:28 GMT

X-Content-Type-Options: nosniff

Set-Cookie: JSESSIONID.=node.node0; Path=/; HttpOnly

Expires: Thu, 01 Jan 1970 00:00:00 GMT

Content-Type: text/html;charset=utf-8

X-Hudson: 1.395

X-Jenkins: 2.401.1.3

X-Jenkins-Session: 04982363

Content-Length: 585

Server: Jetty(10.0.13)

 

Authentication required

 

Recommended Actions

Change the auth method in the Jenkins app to LDAP.
