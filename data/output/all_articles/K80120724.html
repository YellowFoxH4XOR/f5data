Description
When booting the BIG-IP unit to the software upgraded volume, the BIG-IP is stuck in INOPERATIVE status with the following LTM log error: 

Apr 5 06:05:54 slot1/bigip01.localhost err mcpd[7899]: 01070668:3: WAM must be provisioned when a Virtual Server is using a Web Acceleration profile (/Common/my_aam_profile) with attached applications.


Environment

  • BIG-IP AAM/WAM
  • Web Acceleration

Cause
This can be related to K70113407: End of Software Development for BIG-IP AAM.

Recommended Actions

  1. Before upgrading the software of the BIG-IP unit, remove the AAM profile from the respective Virtual Servers.
  2. Optional, delete the custom AAM profile(s) 
Note: F5 recommends that before making any changes to your systems, you back up each system and store the backup in a remote and secure location. For information, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.
