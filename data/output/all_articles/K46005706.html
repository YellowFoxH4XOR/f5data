Description
logmysqld is in restart loop and you observer the below error message repeadedly in /var/log/messages and /var/log/user.log

errno[error_ID] strerror[Can't find file: 'log_data_current' (errno: 2)]
 

Environment

  • BIG-IP AVR
  • logmysqld

Cause

Due to a missing database file (specifically /var/lib/mysql/logdb/log_data_0.MYI).
 

Recommended Actions

Run below command on CLI
mysql -uroot -p`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` -e 'DROP DATABASE logdb;'
Once lodmysqld restarted, it should stop the loop and logging.
If not, please follow : K05755225: Checking and repairing MySQL databases on the BIG-IP system
