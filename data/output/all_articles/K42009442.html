Description

Exporting ASM Policy audit logs manually

Environment

  • ASM Policy audit logs
  • GUI (Configuration Utility)
  • REST API
  • MySQL

Cause

None

Recommended Actions

To export policy audit logs from the GUI (Configuration Utility) perform one of the following actions:

Export via the GUI
Export using REST
Export directly from the local mysql database

Export via the GUI

  1. Navigate to Security  ››  Application Security : Policy : Audit : Log
  2. Modify the Filter as desired
  3. Click Export
  4. Click OK
    There is a export limitation of 1500 records.Note:
Export using REST
  1. Obtain the REST Policy ID for each policy using the following command where <mgmt ip> is the BIG-IP management IP.

    curl -skuadmin:admin https://<mgmt ip>/mgmt/tm/asm/policies?\$select=name,id\&\$top=10 | jq -c '.items[]|[(.name,.id)]'

    For example this device has two policies:

    curl -skuadmin:admin https://192.168.0.1/mgmt/tm/asm/policies?\$select=name,id\&\$top=10 | jq -c '.items[]|[(.name,.id)]'
    ["mypolicy","NuBmLiEtxAcQxWvuqP-LnA"]
    ["myotherpolicy","Ct3t5hLE3vwYJipDrQoz5Q"]

  2. Export the policy audit logs to CSV for each required policy using the following command, where <mgmt ip> is the BIG-IP management IP and <rest ID> is the ID of the policy as per step 1:

    curl -skuadmin:admin https://<mgmt IP>/mgmt/tm/asm/policies/<rest ID>/audit-logs?\$ | jq '.items[]|[(.eventType, .entityKind, .lastUpdateMicros, .description, .deviceName, .username, .component, .entityName)]|@csv' >> /var/tmp/filename.csv

    For example:

    curl -skuadmin:admin https://162.168.0.1/mgmt/tm/asm/policies/NuBmLiEtxAcQxWvuqP-LnA/audit-logs?\$ | jq '.items[]|[(.eventType, .entityKind, .lastUpdateMicros, .description, .deviceName, .username, .component, .entityName)]|@csv' >> /var/tmp/filename.csv

  3. Check the filename.txt file for the audit logs

Export directly from the local mysql database

  1. Get the list of policies:

    mysql -Bs -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "select id,name from PLC.PL_POLICIES"

    For example:

    mysql -Bs -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "select id,name from PLC.PL_POLICIES"
    104     /Common/mypolicy
    105     /Common/myotherpolicy

  2. Use the policy ID to dump the policy audit logs from the database table to a file, where XX is the ID of the policy.

    mysql -Bs -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "select * from PLC.PL_CONFIG_LOG where policy_id = XX"  >> /var/tmp/filename.txt

    For example:

    mysql -Bs -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "select * from PLC.PL_CONFIG_LOG where policy_id = 104"  >> /var/tmp/filename.txt

  3. Check the filename.txt file for the audit logs
    Note: Some manual formatting may be required
