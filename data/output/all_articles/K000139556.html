K000139556: Edge client is stuck in intializing state.

Type
Support Solution
Published
2024-05-08
Updated
2024-05-08
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K000139556

Description

Edge Client stays in initializing state. Tunnel gets started and closed and new IP addresses are assigned to client.
Edge Client Logs has similar to below entry

CURDialer::OnRasCallback, WAN Miniport maybe disabled. Please make sure that it is enabled before connecting to VPN

 

Environment

  • BIG-IP APM
  • Edge Client
  • Windows
  • Wan Miniport

 

Cause

  • Windows's WAN miniport having some issue. Make sure if it is not diabled.

 

Recommended Actions

It is always recommended to update WAN miniport driver in Windows.
