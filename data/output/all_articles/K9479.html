Known Issue

This is the result of a known issue. The flashver command displays the Always-On Management (AOM) kernel version for the following BIG-IP platforms:

  • 1600 (C102)
  • 3600 (C103)

The flashver command takes more than 35 seconds to display the AOM kernel information. This behavior may cause diagnostic utilities, such as qkview, to appear to hang when executing the flashver command.

F5 Product Development tracked this issue as CR111245, and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.
