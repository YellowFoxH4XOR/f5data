Known Issue

Form-based client-initiated single sign-on (SSO) may cause the Traffic Management Microkernel (TMM) to exit and restart.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured to use form-based client-initiated SSO authentication.
  • Memory corruption occurs due to a decryption failure on the BIG-IP APM system during SSO processing.

Impact

The BIG-IP APM system may temporarily fail to process traffic, and fail over if you have configured it as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are unable to authenticate with the BIG-IP APM system using form-based client-initiated SSO authentication.
  • The TMM process exits and generates a core file to the /shared/core directory.
  • Users may view messages in the /var/log/apm file that appear similar to the following example:

    err tmm3[21577]: 014d0002:3: e6abc892: SSOv2 Decryption of form parameter
