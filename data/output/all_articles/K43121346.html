Known Issue

The BIG-IP system does not add existing routing protocols to route domain 0 when upgrading from 10.x to 11.2.0 or later.

This issue occurs when all of the following conditions are met:

  • You have configured a routing protocol in the default route domain (RD0) without any customization.
  • You have upgraded the system from 10.x to 11.2.0 or later.

Impact

Routing protocol information is missing from route domain 0 following the upgrade. Dynamic routing does not run, even though it is configured.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H523663 on the Diagnostics > Identified > Medium screen.
  • Your BIG-IP system may not correctly route system and/or virtual server traffic that relies on dynamic routing information.

Workaround

To work around this issue, you can add a comment to the configuration, prior to performing the upgrade, perform an incremental upgrade, or re-add the routing configuration following the upgrade. To do so, perform one of the following procedures:

  • If you have not yet upgraded to 11.2.0 or later, perform one of the following two procedures:

    Adding a comment to the description field before upgrading

    Performing an incremental upgrade

  • If you have already upgraded to 11.2.0 or later, perform the following procedure:

    Re-adding the routing protocol to route domain 0 following the upgrade

Adding a comment to the description field before upgrading

If you have not yet applied the upgrade, you can add a comment to the Route Domain description field. This action will cause the system to create an entry in the configuration file and allow the upgrade script to correctly update and apply routing information to route domain 0. To do so, perform the following procedure from the Configuration utility.

Impact of workaround: Performing the following procedures should not have a negative impact on your system. However, you should perform this procedure during a maintenance window.

  1. Choose Network > Route Domains.
  2. Select the 0 route domain.
  3. In the Description section, add a comment.
  4. Click Update.

Performing an incremental upgrade

If you have not yet applied the upgrade, you can perform an incremental upgrade from 10.x to 11.0.0 or 11.1.0, and then from 11.0.0/11.1.0 to your final version. Since the issue occurs when upgrading from 10.x to 11.2.0 or later, performing an incremental upgrade will ensure information being properly updated when moving from 10.x to 11.x. For information about performing an upgrade, refer to the release notes for the versions for which you will be upgrading.

Impact of workaround: You should perform upgrades during a maintenance window.

Re-adding the routing protocol to route domain 0 following the upgrade

If you have already upgraded to 11.2.0 or later, you can re-add the routing protocol to route domain 0. To do so, perform the following from the Configuration utility:

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

  1. Choose Network > Route Domains.
  2. Select route domain 0, listed as just 0.
  3. Select the appropriate dynamic routing protocols from Available and move them to the Enabled box using the << button.
  4. Select Update.
