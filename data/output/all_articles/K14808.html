Known Issue

The BIG-IP Edge Client for the OS X operating system does not properly support BIG-IP APM policy redirection.

This issue occurs when all of the following conditions are met:

  • Users connecting to the BIG-IP APM policy are using the BIG-IP Edge Client on devices running the OS X operating system.
  • The BIG-IP APM policy ending is set to Redirect.

Impact

Users receive an error message when BIG-IP Edge Client mishandles the redirect and sends them back to the BIG-IP APM system after BIG-IP APM has closed the user's session.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Users who are running BIG-IP Edge Client for the OS X operating system with a policy ending set to Redirect receive an error message similar to one of the following examples:

    • Your session could not be established
    • The certificate of this server is invalid
    • HTTP 404 Not Found
