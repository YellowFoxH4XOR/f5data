Known Issue

SNMP may return an incorrect value for the F5-BIGIP-SYSTEM-MIB::sysInterfaceMediaActiveSpeed object identifier (OID).

This issue occurs when all of the following conditions are met:

  • Your BIG-IP platform uses the 100 Gbps QSFP28 SR4 transceiver.
  • You view the interface media active speed using the following SNMP OID:

    F5-BIGIP-SYSTEM-MIB::sysInterfaceMediaActiveSpeed
    .1.3.6.1.4.1.3375.2.1.2.4.1.2.1.4

Impact

The BIG-IP platform returns an incorrect active speed value.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the returned media active speed for the .1.3.6.1.4.1.3375.2.1.2.4.1.2.1.4 OID, the value appears similar to the following:

    F5-BIGIP-SYSTEM-MIB::sysInterfaceMediaActiveSpeed."<interface>" = Gauge32: 80

    Note: The returned media active speed displays incorrectly as 80.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to view the media active speed of the interface. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. View the active media speed of the platform interfaces by typing the following command:

    show /net interface

    Note: To limit the displayed interfaces, you can append the interface to the tmsh command. For example: show /net interface 1.1.

  3. Exit the tmsh utility by typing the following command:

    quit
