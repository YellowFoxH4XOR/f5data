K10750: A VLAN is not configurable when using a failover-only node license until after synchronization occurs

Known Issue

This is the result of a known issue. On a FirePass controller with a failover-only node license installed, the VLAN tab on the Device Management: Configuration: Network Configuration page does not appear until after a successful synchronization with the active controller. Therefore, you do not have the option to configure a network interface with VLAN tagging for the initial synchronization.

F5 Product Development is tracking this issue as CR91143.
 
Workaround
 
You can work around this issue by configuring a non-tagged network interface for initial synchronization. After synchronization completes, you can enable and configure VLAN tagging for subsequent synchronizations.
 
Note: For information about configuring network interfaces and VLANs on the FirePass controller, refer to the FirePass Controller Administrator Guide.
