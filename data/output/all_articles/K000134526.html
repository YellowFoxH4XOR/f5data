K000134526: API request to retrieve the license details

Type
Support Solution
Published
2023-05-09
Updated
2023-06-07
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000134526

Description

You can use the F5OS API request to retrieve the license details in either JSON or XML format.

Environment

  • F5OS-A / F5OS-C
  • rSeries / Velos
  • API
  • license

Cause

  • None

Recommended Actions

For JSON format response, use the following example:

curl -X GET -H 'Accept: application/yang-data+json' -sku admin:admin https://localhost:8888/restconf/data/openconfig-system:system/f5-system-licensing:licensing

For XML format response, use the following example:

curl -X GET -H 'Accept: application/yang-data+xml' -sku admin:admin https://localhost:8888/restconf/data/openconfig-system:system/f5-system-licensing:licensing

Additional Information

  • F5OS-A/F5 rSeries - API
  • F5OS-C/VELOS - API
