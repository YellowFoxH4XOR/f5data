K5849: Remaining rules may be duplicated when a rule is deleted from the command line

Known Issue

This is the result of a known issue. If multiple rules are configured, and you use the bigpipe rule <name> delete command to remove any rule other than the last listed rule in the configuration, BIG-IP will delete the rule you selected, and will replace it with the next rule in the configuration. As a result, the same number of rules remains, but one of the rules has been duplicated.

If you attempt to delete the last listed rule in the configuration, it will be deleted properly.

F5 Networks Product Development tracked this issue as CR42720 and CR42721, and it was fixed in BIG-IP version 4.5.14. For information about upgrading, refer to the BIG-IP Release Notes.

Workaround

To work around this issue, you can delete the rule by using the Configuration utility, or by editing the bigip.conf file.
