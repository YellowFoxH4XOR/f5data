K07353559: Deleting configuration snapshots from BIG-IQ using the REST API

Description

Over time, configuration snapshots may accumulate on the BIG-IQ. The number of snapshots present may grow the size of the database, causing disk size growth as well as larger UCS and qkview files. The administrator of the BIG-IQ system may want to automate this task using the REST API.

Environment

  • BIG-IQ

Cause

BIG-IQ will retain these configuration snapshots indefinitely unless they are manually deleted as there is not an automatic deletion policy for older snapshots at this time.

Recommended Actions

Configuration snapshots are contained within separate modules within BIG-IQ (such as Shared Security, Access, etc.) and the endpoints reflect this separation. The following command lists the Configuration Snapshot modules:

restcurl -u admin:<password> /cm/ | grep snapshot-config

 "link": "https://localhost/mgmt/cm/security-shared/tasks/snapshot-config" [Shared Security]
 "link": "https://localhost/mgmt/cm/firewall/tasks/snapshot-config"        [Security > Network Security (AFM)]
 "link": "https://localhost/mgmt/cm/global/tasks/snapshot-config"          [Global]
 "link": "https://localhost/mgmt/cm/asm/tasks/snapshot-config"             [Security > Web Application Security (ASM)]
 "link": "https://localhost/mgmt/cm/websafe/tasks/snapshot-config"         [Security > Fraud Protection (WebSafe)]
 "link": "https://localhost/mgmt/cm/dns/tasks/snapshot-config"             [DNS (GTM)]
 "link": "https://localhost/mgmt/cm/access/tasks/snapshot-config"          [Access (APM)]
 "link": "https://localhost/mgmt/cm/adc-core/tasks/snapshot-config"        [Local Traffic & Network (LTM)]
 "link": "https://localhost/mgmt/cm/sslo/tasks/snapshot-config"            [SSL Orchestrator (SSLO)]

Gather list of snapshots of a module

MethodEndpoint
GET/mgmt/cm/<module>/tasks/snapshot-config/

Note: Since most administrators will want to find older snapshots to mark for deletion, compare the value of each snapshot's endDateTime to a value of your choosing and gather the IDs of the snapshots older than this value. 

restcurl -u admin:<password> /cm/asm/tasks/snapshot-config/?\$select=endDateTime,id

or

restcurl -u admin:<password> /cm/asm/tasks/snapshot-config/ | jq '.items[]|{endDateTime,id}' -c

Removing a list of IDs

Method

Endpoint

Payload

DELETE

/mgmt/cm/<module>/tasks/snapshot-config/

'{ "items":[{"id":"<UUID>"}, {"id":"<UUID>"}, ... ] }'
