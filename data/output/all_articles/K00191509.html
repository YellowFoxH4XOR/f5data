Known Issue

BIG-IP Edge Client may terminate network access sessions and restart continually after being connected for a period of time.

This issue occurs when all of the following conditions are met:

  • You are running Windows 10 Enterprise LTSC build 17763 (version 1809).
  • You use BIG-IP Edge Client 7.1.7.2 or later to establish a network access session with the BIG-IP APM system.

Impact

Users running Windows 10 Enterprise LTSC cannot maintain network access sessions to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After establishing a network access session, the BIG-IP Edge Client terminates the network access session and restarts.
