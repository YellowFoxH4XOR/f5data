K000159009: Tenant shows the interface DOWN not the UNINITIALIZED, when the interface was removed from the F5OS

Description

Tenant shows the interface DOWN not the UNINITIALIZED, when the interface was removed from the F5OS.

Environment

  • F5OS
  • LAG

Cause

This is a known existing issue with Pantera and Static LAG configurations in F5OS. When an UP interface is removed from the host (Pantera), the tenant interface state does not automatically update to reflect the change and remains in its previous state instead of transitioning to UNINITIALIZED. The interface status persists until a manual refresh is performed on the tenant.

https://cdn.f5.com/product/bugtracker/ID1322157.html

Recommended Actions

Apply the following workaround from the tenant to refresh the interface state:

Execute: bigstart restart mcpd

Execute: tmsh save sys config

This should force the tenant to re-evaluate interface states and display the correct status.
