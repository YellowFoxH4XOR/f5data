K000147245: How to Enable Additional Services in your XC Tenant (Self-Service Enablement Pattern)

Type
Support Solution
Published
2024-11-08
Updated
2025-02-20
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud Billing
Source
https://my.f5.com/manage/s/article/K000147245

Description

  • You attempted to navigate to a particular service in XC Console, but were not able to.
  • You attempted to create resources within that service, but were not able to.
  • You may have received a 403 response code in XC Console when trying to do the aforementioned.

 

Environment

  • F5® Distributed Cloud (XC)
  • XC Console

 

Resolution/Answer

  1. Navigate to your tenant in XC Console.
  2. Navigate to the service of interest (e.g. DNS Management).
  3. On the left pane, click About under Workspace Info.
  4. Click Explore, then Enable Service as per below screenshots.

Cause

  • If you purchased Console Package instead of Base Package, many XC services will not be enabled by default since Console Package provides the bare minimum amount of XC features to sustain the existence and fundamental operations of a tenant.
  • These additional services have to be enabled as instructed earlier in this article.
