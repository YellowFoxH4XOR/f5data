Topic

The number of DNS zones that can be loaded on a BIG-IP GTM system is only limited by the configuration and the amount of RAM and disk space installed on the BIG-IP GTM system.

Note: While the BIG-IP GTM system is able to perform with thousands of DNS zones, BIG-IP GTM configurations containing a large number of records within each DNS zone, and/or a large number of GTM objects, such as wide IPs, iRules, and topology records, will utilize more system resources and impact system performance.
