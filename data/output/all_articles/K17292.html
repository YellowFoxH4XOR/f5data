Known Issue

The BIG-IP system may produce a Traffic Management Microkernel (TMM) core file when IPSec traffic is configured.

This issue occurs when all of the following conditions are met:

  • You are running BIG-IP 11.2.1 with HF2 or HF4 and later.
  • You are running IPSec tunnels through the BIG-IP system.

Impact

The BIG-IP system is unable to process traffic while the TMM process restarts, and the system fails over if it is configured for high availability (HA).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process restarts, and the BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system sends a SIGSEGV signal to TMM, resulting in a stack trace and core file.
  • The system logs the stack trace to the /var/log/tmm file.
