K000135383: How DNS servers are selected to resolve FQDN nodes?

Type
Support Solution
Published
2023-07-06
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.5
Source
https://my.f5.com/manage/s/article/K000135383

Description

How a DNS name server is selected from the list of configured DNS Name Server to resolve FQDN nodes and FQDN node address changes when a different name-server is used.

Environment

  • BIG-IP LTM
  • More than 1 DNS Name Server configured.
  • FQDN nodes

Cause

There are more than one DNS Name Server configured and their configured DNS Zones are not in sync.

Recommended Actions

Make sure that DNS Name Servers used by BIG-IP are synchronised in their DNS Zone files.

Additional Information

How DNS Name Servers are selected in BIG-IP.

Example configuration

sys dns {
  description configured-by-dhcp
  name-servers { 192.16.100.87 192.16.100.88 192.16.100.89}
  search none
}

The resolver will query the first name server (192.16.100.87); if it is not able to respond, all subsequent queries will be sent to  the next name-server in the list (192.16.100.88).  If that also fails to respond then it will continue to the next name server in the list (192.16.100.89).  It will continue to use whichever name server did not timeout and cycle through the name-servers when timeouts do occur.
