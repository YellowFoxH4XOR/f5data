K000150930: handle_generic_grpc errors after restoring UCS from a different Tenant on F5OS

Type
Support Solution
Published
2025-04-18
Updated
2025-04-18
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150930

Description

You restored a UCS on a newly created BIG-IP running as a tenant on F5OS. You notice that the BIG-IP service doesn't boot properly and find errors similar to the following on /var/log/ltm.

err platform_agent[XXXX]: 01e10004:3: handle_generic_grpc: Bad return code from gRPC call to platform: X Client not registered for VlanSetStatsRequest request. [message type]:15

err platform_agent[XXXX]: 01e10004:3: handle_generic_grpc: Bad return code from gRPC call to platform: X Client not registered for VlanConfig request. [message type]:5

Environment

F5OS Tenant

Restoring UCS on a new Tenant

 

Cause

If a UCS is loaded on a F5OS tenant and the name of the tenant from where the UCS was saved doesn't match the tenant's name where it is restored, the tenant will not become operational. F5 tracks this issue as ID 1678105.

 

Recommended Actions

 

Reboot the BIG-IP tenant or see a workaround section on ID 1678105.
