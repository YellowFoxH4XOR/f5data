Description

This article describes how to reset the variable asm.cs_qualified_urls to default.

Environment

  • Reset to default 

Cause

None.

Recommended Actions

To reset the variable asm.cs_qualified_urls to default, refer to the following steps.

  1. Log in to the BIG-IP via CLI
     
  2. Run the following command from the BASH:

     tmsh mod sys db asm.cs_qualified_urls reset-to-default
