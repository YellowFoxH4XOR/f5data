Topic

BIG-IP WebAccelerator does not apply the Intelligent Browser Referencing (IBR) or Multiconnect features to embedded objects. For example, if IBR is enabled for image objects, images embedded in a CSS file, form, or JavaScript do not have IBR applied to those objects. This behavior is by design in current BIG-IP WebAccelerator versions.
