Issue

Error Message

Device trust software validation error: Unexpected Error: Could not add ca-device (error from devmgmtd): 01070276:3: The requested device <device_name> has a non-matching software version, <software_version>.

or

Unable to add peer. This device version does not match the remote one. Update the software version for this device

In this error message, note the following:

  • <device_name> is the host name of the BIG-IP device to which you are attempting to add to the trust domain.
  • <software_version> is the software version of the BIG-IP device to which you are attempting to add to the trust domain.

For example:

Device trust software validation error:
Unexpected Error: Could not add ca-device (error from devmgmtd): 01070276:3: The requested device (/Common/BIGIP-3.localdomain) has a non-matching software version, 11.5.3.

or

Unable to add peer. This device version does not match the remote one. Update the software version for this device

Message Location

You may encounter this message in the following locations:

  • The TMOS Shell (tmsh) or command line terminal screen
  • The Configuration utility

Description

This message occurs when the following condition is met:

  • You attempt to add a BIG-IP device to the trust domain and the device is not running the same BIG-IP software version as other members in the trust domain.

BIG-IP devices must run the same software version before you can add the systems to the same trust domain. This includes the major, minor, and maintenance software version numbers. By default, the hotfix version numbers are not required to match among device group members.

Impact

The BIG-IP device is not added to the trust domain and high availability (HA) features may not work as expected.

Recommended Actions

Make sure the BIG-IP systems are running the same software version before attempting to add the systems to the same trust domain.
