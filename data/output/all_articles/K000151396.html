Description

On the low-end rSeries platforms, configuring Spanning Tree Protocol (STP), Rapid STP (RSTP), or Multiple Spanning Tree Protocol (MSTP) is not supported. Attempts to enable these protocols result in the error:

01070686:3: Spanning Tree Protocol (STP) is not supported on this platform.

BPDU (Bridge Protocol Data Unit) packet forwarding is also not supported; no BPDU frames are observed on interfaces, even when "passthru" mode is configured.

Environment

  • Product: F5 BIG-IP LTM
  • Platform: low-end rSeries (r2000 and r4000) 
  • Software Version: 17.1.1
  • Network configuration: STP/MSTP/RSTP attempted at global and tenant levels

Cause

The r2000 and r4000 rSeries models do not provide support for STP, RSTP, or MSTP protocols. While configuration options may appear available in the interface, enabling these features is not possible and results in an error message. BPDU forwarding functionality is also absent from this platform.

 

Recommended Actions

  • Do not attempt to configure STP, RSTP, or MSTP on the r2000 and r4000; these protocols are unsupported.
  • The "passthru" mode does not forward BPDUs on this platform.

 

Additional Information

Spanning tree protocols are supported only on F5 r5000/r10000/r12000 platforms.
