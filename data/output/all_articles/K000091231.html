K000091231: NGINX Controller AppSec - RBAC Security Strategies issues

SYMPTOM
In UI, when going to https://<nginx_controller_fqdn>/services/security/strategies, error "Error Fetching Strategies API Error (403): unauthorized" is raised when READ access only is set for /services/security/strategies.

CAUSE
API path to strategies is /api/v1/security/strategies

RESOLUTION
Create user_role with READ access to /security/strategies
