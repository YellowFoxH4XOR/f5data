Description

F5 uses Microsoft MSSQL drivers as part of the SQL Health Checks used by BIG-IP to check the health or status of a  MSSQL Pool member.   Depending on what Version of BIG-IP software you are running, the version may be different.  

Environment
  • BIG-IP LTM
  • configured to perform a health monitor on a MSSQL pool member

Cause

None

Recommended Actions
  • If your deployment requires a certain version of code,  you may need to upgrade to match the driver version. 

Additional Information

The following versions of code, and later releases, using Microsoft's JDBC driver version 6.4.0:

    12.1.5.3
    13.1.3.6
    14.1.2.7
    15.1.0
    16.0.0

Versions prior to these using Microsoft's JDBC driver version 6.0, unless you have an engineering hotfix version of code that includes RFE ID608952.
