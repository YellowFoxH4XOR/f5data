K000159997: Existing Address List object is not displayed while clicking Address List object on AFM Firewall Rule List page.

Type
Support Solution
Published
2026-02-13
Updated
2026-02-13
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.5.1, 17.1.3
Source
https://my.f5.com/manage/s/article/K000159997

Description

Under "Security >> Network Firewall : Rule Lists >> [rule-list-name]", Firewall Rule is shown with hyperlink to "Address List" object page if Firewall Rule uses "Address List" at Source and/or Destination settings.  If user clicks "Address List" object, "Address List" property page should be displayed, as shown below.

Figure: expected behavior

 

However, due to Bug ID2163321, when user clicks "Address List" object, user is redirected to "New Address List" creation page, instead of redirected to existing "Address List" object page.

Figure: actual behavior

 

Environment

  • AFM Firewall Rule List uses Address Lists object at Source/Destination Address/Region.

 

Cause

Bug ID2163321.

 

Answer/Recommended Actions

User can see Address Lists objects by navigating to "Shared Objects >> Address Lists" although it is not possible to directly goes to existing "Address Lists" object page from AFM Firewall Rule List page.

 

Additional Information

Bug ID2163321 is fixed in TMOS v17.5.1.4 (at the time of article publication).
