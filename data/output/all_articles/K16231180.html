Description

BIG-IP failover occurs intermittently after applying new iRule with "SSL::extensions insert".
The following messages are logged in /var/log/ltm:

notice sod[12799]: 01140045:5: HA reports tmm NOT ready.
notice sod[12799]: 010c0050:5: Sod requests links down.
err bcm56xxd[7740]: 012c0010:3: Failover event detected.  Marking external interfaces down. bsx.c(4751)
...
notice sod[12799]: 01140041:5: Killing tmm.0 pid 1037.
warning sod[12799]: 01140029:4: HA daemon_heartbeat tmm fails action is go offline down links and restart.

A core file is generated in /var/core/

Environment

  • BIG-IP
  • iRule with "SSL::extensions insert"
  • Non-SSL traffic
  • Intermittent failover
  • TMM core file generated

Cause

Bug ID 864897

Recommended Actions

This issue is triggered when an iRule with "SSL::extensions insert" processes non-SSL traffic.
Issue can be avoided by updating the iRule logic so that "SSL::extensions insert" is only applied to SSL traffic.

Additional Information

The tmm core file may be analysed by F5 Engineering to verify the root cause if this bug ID does not match the conditions.
Please remember to generate the md5sum of the core file when uploading to F5 Support to verify the file integrity.

K41022796: Generation of md5sum for transmission to F5 Support
