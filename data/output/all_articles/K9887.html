Known Issue

This is the result of a known issue. When an acceleration policy is configured with the Cache only if the document contains matching begin and end tags option from the Responses Cached tab of the policies Acceleration Rules menu, BIG-IP WebAccelerator will still cache improperly formatted HTML documents that are missing start HTML tags.

F5 Product Development tracked this issue as ID 222293 (formerly CR116645).
