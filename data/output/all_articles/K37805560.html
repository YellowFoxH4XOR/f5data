Description

When you SSH into an F5, you get the following message "bash: /root/.bash_profile: Input/output error "

Environment

  • BIG-IP
  • Error Message: -bash: /root/.bash_profile: Input/output error 
  • Error Message: -bash-4.1# cat /root/.bashrc

Cause

Possible file system corruption or changes made to configuration for /root/.bash_profile profile

Recommended Actions

Copy the known good "/root/.bash_profile" and "/root/.bashrc" files from another system to the trouble device by running the following commands substituting the known good BIG-IP management address and the trouble BIG-IP management IP address.

# scp root@<IP_Known_Good_F5>:/root/.bash_profile root@<IP_Trouble_Device>:/root/
# scp root@<IP_Known_Good_F5>:/root/.bashrc root@<IP_Trouble_Device>:/root/

For example: 
# scp root@10.10.10.10:/root/.bash_profile root@11.11.11.11:/root/
# scp root@10.10.10.10:/root/.bashrc root@11.11.11.11:/root/
