K35112305: AS3 fails with 422, ''Failed! exit_code (22)''

Type
Support Solution
Published
2022-01-25
Updated
2023-02-21
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K35112305

Description

POSTing an AS3 declaration to BIG-IP results in the following response:

{
"code": 422,
"message": "declaration failed",
"response": "Failed! exit_code (22).\n",
"host": "localhost",
"tenant": "Common",
"runTime": 70770
}

Environment

  • BIG-IP
  • AS3 declaration
  • "Failed! exit_code (22).\n"

Cause

"Failed! exit_code (22).\n"," is caused by cURL failing to download one of the URLs provided in the AS3 declaration.
These are error codes passed by cURL: https://curl.se/libcurl/c/libcurl-errors.html

Github issue: https://github.com/F5Networks/f5-appsvcs-extension/issues/553

Recommended Actions

Validate URL links in the AS3 declaration

Additional Information

Log messages in /var/log/restnoded/restnoded.log on BIG-IP can be used to troubleshoot AS3 deployments
