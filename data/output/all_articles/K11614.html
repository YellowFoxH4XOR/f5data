Known Issue

This is the result of a known issue. If an Active Directory or LDAP user attribute contains one or more non-printable characters, the attribute is not encoded correctly and the BIG-IP APM access policy may be unable to authenticate the user.

F5 Product Development tracked this issue as CR137015 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP APM, LTM, ASM, PSM, WebAccelerator, or Edge Gateway release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
