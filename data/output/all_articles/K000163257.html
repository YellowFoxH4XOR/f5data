Work Instructions or Explanation

Either TCP or HTTP Load Balancer deployment will increase the counter of the following quotas:

  • virtual_host - A virtual host is the main anchor configuration for a proxy. The primary application for a virtual host configuration is a reverse proxy. The virtual host object is used to create a loadbalancer, virtual service or an API gateway. It can also be viewed as a base object to define application routing.
  • virtual_host.public - The number of virtual hosts being advertised on the public internet.
  • endpoint - An endpoint object represents the actual service provider, such as an origin server. A single endpoint object might dynamically resolve into multiple actual endpoints, allowing for flexibility and scalability.
  • route - A route object is a configuration element that determines the processing of incoming traffic. It involves defining match conditions, specifying actions to be performed when a match occurs, and enabling custom JavaScript processing for advanced customization (optional).
  • cluster - A cluster object represents a group of endpoints that can serve a specific route for a virtual host. The cluster shares common properties such as health checks, load balancing algorithms, circuit breaker settings, and connection and timeout parameters. Each endpoint within the cluster is referenced, and can be configured with specific TLS parameters and protocol timeouts.
