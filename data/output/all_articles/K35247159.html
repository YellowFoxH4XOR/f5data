K35247159: Upgrade from 14.1.3.1 to 15.1.5.1 fails due to SecurID issue

Type
Support Solution
Published
2022-07-22
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 14.1.3
Source
https://my.f5.com/manage/s/article/K35247159

Description
RSA SecurID functionality could be impacted due to corrupted/changed node secret during the upgrade process, causing securidtest to fail.

The following output of securidtest will be seen:

[root@example:Standby:In Sync] # securidtest -p /config/aaa/ace/Common/Application -s 10.10.10.10 -u example -w 12345678
Test done: total tests: 1, success=0, failure=1

Environment

  • BIG-IP
  • RSA SecurID configured
  • TMOS Upgrade

Cause
Unknown at this time.

Recommended Actions
Follow the steps in K11402 to reset the node secret between the BIG-IP and RSA server(s).

Additional Information
None
