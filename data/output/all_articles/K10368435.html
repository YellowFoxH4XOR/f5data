Description

When using the BIG-IP APM Guided Configuration (Access >> Guided Configuration) an error similar to the following is displayed:

Object not found!
The requested URL was not found on this server. If you entered the URL manually please check your spelling and try again. Error 404

Environment

  • BIG-IP APM licensed
  • Guided Configuration
  • BIG-IP HA or standalone
  • Standby

Cause

Guided Configuration is not synchronized properly.

This issue could also happen when restnoded could not fetch the list of files to load from the respective iAppsLX directory from the following logs in  in /var/log/restnoded/restnoded.log.

Mon, 01 Nov 2021 04:54:17 GMT - config: [RestWorker] /odata-registry/register has started. Name:RegistryWorker
Mon, 01 Nov 2021 04:54:17 GMT - warning: [LoaderWorker] Could not get list of files to load from directory: /var/config/rest/iapps/f5-iappslx-access-adfs/nodejs
[...]
Mon, 01 Nov 2021 04:54:17 GMT - warning: [LoaderWorker] Could not get list of files to load from directory: /var/config/rest/iapps/f5-iappslx-access-saml-idp/nodejs

Recommended Actions

BIG-IP 14.x and later

Perform the following procedure when your system is running BIG-IP 14.x and later.

  1. Go to iApps >> Package Management LX 
  2. Select all the rpms
  3. Select Uninstall to uninstall all of the rpms. 
  4. Return to AGC so that all the rpms will be reinstalled (with the default AGC version of the BIG-IP version the system is running). 
  5. Verify that the error and issue are resolved and deployments are be visible. 

BIG-IP 13.x

Perform the following procedure when your system is running BIG-IP 13.x

  1. Log in to the BIG-IP APM command line.
  2. Stop the restjavad and restnoded on the standby device (affected device) with the following commands:

    bigstart stop restjavad 
    bigstart stop restnoded 

  3. Run the following command on the standby unit:

    rm -f /var/config/rest/storage/*; clear-rest-storage 

    Important: If you have deployments, those will disappear but all the objects created by the deployment process will remain active. In addition, if you have SSO configuration, this will remove them from the device. Also if device is managed by BIG-IQ, BIG-IP device might have to be rediscovered on BIG-IQ systems.

  4. Copy the /var/config/rest/storage directory from active unit (working device) to standby.
  5. Start the restjavad and restnoded daemons in the standby unit by running the following commands:

    bigstart start restjavad 
    bigstart start restnoded

  6. Go to Access >> Guided Configuration to verify if the error message is no longer seen.
