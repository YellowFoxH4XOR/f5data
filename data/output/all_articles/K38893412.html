K38893412: Since 13.0 TCPDUMP Utility Now Can Dump Into a Single File Over 2 GB In Size

Type
Support Solution
Published
2021-08-10
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K38893412

Description
Before 13.0, tcpdump command can only capture traffic and write to a single file no larger than 2 GB. Since 13.0, this limitation has been lifted.

Environment

  • A tcpdump command is being used to capture traffic.

Cause
This change is caused by the utility is now a 32-bit program.

Recommended Actions

On BIG-IP systems running 12.1.x and earlier, use -c parameter to limit file size of each packet capture file.

Additional Information

None
