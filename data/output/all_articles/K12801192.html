Description

  • you want to restrict multiple concurrent user logins to the BIG-IP GUI and SSH
  • when a BIG-IP user is already logged in and another log in is attempted using the same user without terminating the previous session, the new log in session must be denied

Environment

  • BIG-IP management access

Cause

NA

Recommended Actions

  • at the moment, there is no method to limit concurrent logins for the BIG-IP GUI and SSH.
  • a feature enhancement request is currently in place internally
