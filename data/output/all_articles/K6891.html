K6891: The BIG-IP GTM object-type references are not cleared from the persistence table when the object types are deleted from the GTM configuration

Known Issue

This is the result of a known issue. The BIG-IP GTM persistence records may refer to various types of objects such as wide IPs, pool members, datacenters, servers, and links. When these objects are deleted from the BIG-IP GTM configuration, the corresponding object-type references are not cleared from the persistence table. This can cause gtmd to crash when synchronizing persistence information between BIG-IP GTM systems.

F5 Product Development tracked this issue as CR69509, CR69561, and CR70253 and it was fixed in BIG-IP GTM 9.2.4, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP GTM Release Notes.

Workaround

To work around this issue, restart gtmd by typing the following command from the command line:

bigstart restart gtmd
