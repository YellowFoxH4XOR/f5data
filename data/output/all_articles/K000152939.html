Environment

  • F5OS-A all version

Cause

The uploaded F5OS-A ISO image is corrupted.

Recommended Actions

Delete the corrupted F5OS-A iso image manually, and check the iso image is not corrupted, then upload again.

To delete the corrupted iso, and re-upload F5OS-A iso image, do following steps.

  1. SSH login to the system as root user
  2. Delete the F5OS ISO image.
    The iso image is located under /var/export/chassis/import/iso/
    Following example delete F5OS-A-1.8.0-16036.R5R10.iso
    rm /var/export/chassis/import/iso/F5OS-A-1.8.0-16036.R5R10.iso
  3. Download F5OS-A ISO image from F5 download site.
  4. Upload F5OS-A ISO image.
  5. If the upload still fails,
    kill -HUP <pid of sw-mgmt process>
    docker restart system_image_agent
    or
    rebooting the system.
