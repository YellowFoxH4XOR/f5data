Known Issue

The websso daemon experiences high CPU usage with Kerberos single sign-on (SSO) due to an inefficient data structure for credential cache in the Kerberos krb5 library.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM access profile with Kerberos SSO.
  • Many users log in to the BIG-IP APM system using Kerberos SSO.

Impact

The performance of the BIG-IP APM system handling HTTP requests decreases, and users experience increased latency when accessing applications.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The output from the top or ps commands shows high CPU usage for the websso daemon.
  • The performance of the BIG-IP APM virtual server configured with Kerberos SSO decreases as more users log in.
  • You observe messages in the /var/log/apm file that appear similar to the following example:

    err websso.0[<pid>]: 014d0048:3: /<Folder>/<Access Profile>:<Folder>:<sessionID>: failure occurred when processing the work item

Workaround

To work around this issue, you can reduce the number of cached Kerberos user tickets by lowering the default ticket lifetime from 600 minutes. For example, to modify the ticket lifetime to 120 minutes, perform one of the following procedures:

BIG-IP 13.x

Impact of workaround: When you reduce the ticket lifetime, the frequency of Kerberos ticket requests increases and may result in a higher number of DNS and Kerberos requests in the network. F5 recommends that you perform this procedure during a scheduled maintenance window for the affected BIG-IP system.

  1. Log in to the Configuration utility on the first BIG-IP system.
  2. Navigate to Access > Single Sign-On > Kerberos.
  3. Click the name of the affected Kerberos SSO object.
  4. Under SSO Method Configuration, in the Ticket Lifetime box, type 120.
  5. Click Update.

BIG-IP 11.x – 12.x

Impact of workaround: When you reduce the ticket lifetime, the frequency of Kerberos ticket requests increases and may result in a higher number of DNS and Kerberos requests in the network. F5 recommends that you perform this procedure during a scheduled maintenance window for the affected BIG-IP system.

  1. Log in to the Configuration utility on the first BIG-IP system.
  2. Navigate to Access Policy > SSO Configurations > Kerberos.
  3. Under SSO Method Configuration, in the Ticket Lifetime box, type 120.
  4. Click Update.
