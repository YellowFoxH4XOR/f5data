Topic

You should consider using this procedure under the following condition:

  • You want to configure link aggregation groups (LAGs) with Link Aggregation Control Protocol (LACP) on the VELOS system using a Cisco Nexus 9000 series switch as a peer.

Description

The IEEE 802.3ad link specification defines a standards-based method for aggregating multiple physical Ethernet links into a single logical link. The logical link, known as a link aggregation group (LAG), is comprised of multiple members (individual pairs of physical interfaces on each switch). LAGs may be defined statically or dynamically, the latter using the Link Aggregation Control Protocol (LACP). With LACP enabled, 802.3ad compliant switches can dynamically add or remove one or more members to a LAG. Especially when used with LACP, link aggregation adds redundancy to network connections. Depending on the number of flows and the hashing technique used, link aggregation may also boost available bandwidth.

In this example, a Cisco Nexus 9000 series switch uses a two-member LAG to exchange traffic with two BX110 blades in a VELOS CX410 chassis.  For the sake of redundancy, two physical interfaces on each VELOS blade connect to separate ports on the switch using two separate port channels.  Switch ports in port channel 10 connect to the first physical interface on each VELOS blade, and switch ports in port channel 20 connect to the second physical interface on each blade.

LAG member interfaces can reside on different blades in the VELOS chassis. In the following example, interfaces 1/1.0 and 2/1.0 on the VELOS chassis are members of LAG1, and interfaces 1/2.0 and 2/2.0 on the VELOS chassis are members of LAG2. On the Cisco switch, interfaces Ethernet1/1 and Ethernet1/3 are members of LAG1 and Ethernet1/2 and Ethernet1/4 are members of LAG2. LACP is enabled on all LAG members.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have a configured partition up and running on the VELOS system.
  • Have partition administrative access to the partition command-line interface (CLI) or the partition webUI.

Procedures

  • Configure a LAG with LACP on the VELOS system
  • Configure the Cisco Nexus 9000 series switch

Configure a LAG with LACP on the VELOS system

  • Use the partition CLI
  • Use the partition webUI

Use the partition CLI

When creating LACP-enabled LAGs on the VELOS system using the partition CLI, you need to create an LACP interface and assign interfaces and VLANs to the LAG. To do so using the CLI, perform the following procedure:

Note: Assigning interfaces to the LAG is performed at the F5OS partition layer. Once the partition is up and running, a user can create the LAG and assign interfaces to the LAG interface. For more information about configuring partitions, refer to the Manual : VELOS Systems: Administration and Configuration.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Create a LAG interface

Create the LAG interface and enable LACP so the member link state will be updated dynamically.

  1. Log in to the VELOS partition CLI as the partition administrator using the partition’s floating management IP address.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Create the LAG interface for LAG1 (external) using the following syntax:

    interfaces interface <name> config type <type>

    For example:

    interfaces interface external config type ieee8023adLag

  4. You should now be in configuration mode for the interface. Enable LACP on the new LAG interface by entering the following command:

    aggregation config lag-type LACP

  5. Commit the change by entering the following command:

    commit

    The system confirms the commit with the following message:

    Commit complete.

  6. Enter the exit command twice to leave the configuration mode.
  7. View the new LAG interface and confirm that the lag-type is now LACP by entering the following command:

    show interfaces interface external

    Output should appear similar to the following example:

    interfaces interface external
     aggregation state lag-type LACP
     aggregation state lag-speed 0
     aggregation state mac-address 00:94:a1:8d:18:0a

Create a LACP interface

For LACP to manage the interface, you should create an LACP interface to reference the LAG interface.

  1. Enter the configuration mode terminal by entering the following command:

    config

  2. To create the LACP interface referencing the LAG interface, enter the following command:

    lacp interfaces interface external config name external

  3. Commit the change by entering the following command:

    commit

    The system confirms the commit with the following message:

    Commit complete.

  4. Enter the exit command twice to leave the configuration mode terminal.
  5. View the new LACP interface by entering the following command:

    show lacp interfaces interface external

    Output should appear similar to the following example:

    lacp interfaces interface external
     state name external
     state interval SLOW
     state lacp-mode ACTIVE

Add interface LAG members

LAG interfaces can have multiple interface members. The LAG interface state is up as long as at least one member is active.

  1. Enter the configuration mode terminal by entering the following command:

    config

  2. To add interface members to the LAG interface, use the following syntax:

    interfaces interface <<interface>> ethernet config aggregate-id <lag_name>

    For example, to add interface 1.0 on blade 1 as a member of LAG interface external, enter the following command:

    interfaces interface <1/1.0> ethernet config aggregate-id external

    To add interface 1.0 on blade 2 as a member, enter the following command:

    interfaces interface <2/1.0> ethernet config aggregate-id external

  3. Commit the change by entering the following command:

    commit

    The system confirms the commit with the following message:

    Commit complete.

  4. Enter the exit command to leave configuration mode.

Attach VLANs to the LAG interface

You must attach valid VLANs to the LAG interface to pass application traffic. Make sure the VLAN exists before attaching it to the LAG interface.

  1. Enter the configuration mode terminal by entering the following command:

    config

  2. To attach VLANs to the LAG interface, use the following syntax:

    interfaces interface <lag_name> aggregation switched-vlan config trunk-vlans [ <vlan1_name> <vlan2_name> ]

    For example, to add VLANs vlan_id1 and vlan_id2 to LAG interface external, enter the following command:

    interfaces interface external aggregation switched-vlan config trunk-vlans [ vlan_id1 vlan_id2 ]

  3. Commit the change by entering the following command:

    commit

    The system confirms the commit with the following message:

    Commit complete.

  4. Enter the exit command to leave configuration mode.

View the LACP state

  1. To view the LACP state, enter one of the following commands, depending on the level of information to be shown. Output varies by command:

    show lacp
    show lacp interfaces
    show lacp interfaces interface external

  2. You can also check the LACP state for each member interface by entering the following command:

    show interfaces interface state lacp_state

    For example:

           LACP
    NAME   STATE
    ------------------
    1/1.0  LACP_DOWN
    1/2.0  LACP_UP

    The LACP state can be one of the following values:

    • LACP_DEFAULTED indicates the initial lacp_state value which is synonymous to LACP_DOWN.
    • LACP_UP indicates that LACPD has determined this interface is a working member of an LACP LAG and may pass application traffic.
    • LACP_DOWN indicates LACPD has determined this interface is not a working member. If this interface is also a configured member of an LACP LAG, it cannot receive or transmit user traffic. Otherwise, the interface behaves as normal.

This completes the configuration for LAG1 (external) on the VELOS system. To perform the configuration of LAG2 (internal) in the example, repeat the previous steps and add blade interfaces 1/2.0 and 2/2.0 as members of the second LAG. 

Use the partition webUI

You can configure LACP enabled LAGs on the VELOS system using the VELOS partition webUI. To do so, perform the following procedure:

Note: LAG configuration is performed at the F5OS partition layer. Once the partition is up and running, a user can create the LAG and assign interfaces to the LAG interface. For more information about configuring partitions, refer to the VELOS Systems: Administration and Configuration guide.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the VELOS partition webUI as the partition administrator.
  2. Go to Network Settings > LAGs.
  3. Select Add.
  4. For Name, enter a name for the LAG.
  5. For LAG Type, select LACP.
  6. Set the LACP Interval as you want, and for LACP Mode, select ACTIVE.
  7. For Configured Members, select the interfaces to be members of this LAG.
  8. In Trunk VLAN, select the VLANs for the LAG.
  9. Select Save.

    In Figure 2, you can see an example configuration.

Configure the Cisco Nexus 9000 series switch

Note: Refer to your Cisco Nexus 9000 series switch documentation for more information about configuring port channels.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Cisco switch and enter the following command to enter configuration mode:

    configure terminal

  2. Enable LACP by entering the following command:

    feature lacp

  3. To leave configuration mode, enter exit.
  4. You can create a port channel before you create a channel group; the software automatically creates the associated channel group.

    Make sure the VLAN exists before attaching it to the LAG interface by entering the following command:

    show vlan brief

    VLAN Name                             Status    Ports
    ---- -------------------------------- --------- -------------------------------
    2001 external                         active    Po5, Po10, Po20, Eth1/1, Eth1/2
                                                    Eth1/3, Eth1/4, Eth1/5, Eth1/6
                                                    Eth1/36
    3001 internal                         active    Po5, Po10, Po20, Eth1/1, Eth1/2
                                                    Eth1/3, Eth1/4, Eth1/5, Eth1/6
                                                    Eth1/36
     

  5. To enter configuration mode, enter the following command:

    configure terminal

  6. Configure the port channel for LAG1 by entering the following commands in the following order:

    interface port-channel 10
    switchport mode trunk
    switchport trunk allowed vlan [ vlan_id1 vlan_id2 ]

  7. Enter the exit command.
  8. You can add a Layer 2 port to a new channel group or to a channel group that already contains Layer 2 ports. The software creates the port channel associated with this channel group if the port channel does not already exist. To do so, enter the following commands in the following order:

    interface ethernet 1/1
    switchport
    channel-group 10 mode active
    exit
    interface ethernet 1/3
    channel-group 10 mode active
    exit

  9. You can verify the port channel configuration using the following commands:
    CommandDescription
    show interface port-channel channel-numberDisplays the status of a port-channel interface.
    show feature | grep lacp Displays the state of the LACP.
    show port-channel summaryDisplays a summary for the port-channel interfaces.
    show port-channel trafficDisplays the traffic statistics for port channels.
    show port-channel usageDisplays the range of used and unused channel numbers.
    show running-config interface port-channel channel-numberDisplays information about the running configuration of the port-channel.
  10. Repeat the steps to create port channel 20, making sure to attach interface ethernet 1/2 and ethernet 1/4 to create the new port channel with LACP.
