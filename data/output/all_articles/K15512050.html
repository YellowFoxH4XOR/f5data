K15512050: Configuration load fails with ''0107161f:3: Log publisher '/Common/<security log profile>' used by Application DoS Security log profile can have only ArcSight, Splunk or Syslog destinations.''

Type
Support Solution
Published
2022-08-30
Updated
2023-10-17
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP AFM: 15.1.5
  • BIG-IP ASM: 15.1.5
Source
https://my.f5.com/manage/s/article/K15512050

Description

After upgrading the configuration may not load correctly because of the below error.

0107161f:3: Log publisher '/Common/<security log profile>' used by Application DoS Security log profile can have only ArcSight, Splunk or Syslog destinations.
Unexpected Error: Loading configuration process failed.
Environment
  • ASM or AFM module provisioned
  • Security log profile of type remote

Cause
The bigip.conf file got corrupted when a security log profile was deleted.

Recommended Actions

  1. Get a backup of the bigip.conf file with the below command
         cp /config/bigip.conf/ <name of the backup file>
  1. Check the bigip.conf file with desired text modifier
  2. Look for the profile referenced in the error  <security log profile>
  3. The line below line should be in the configuration security profile
      logger-type remote
  1. Proceed to comment the line mentioned before and the line will look as below:
            #logger-type remote
  1. Save the changes in bigip.conf file
  2. Proceed to load the configuration again and confirm that the process was successful
