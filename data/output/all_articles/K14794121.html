Issue

Error Message

 01940022:3: errdefs: error adding management port destination <port number>; check the configuration for missing elements.

In this error message, note the following:

  • <port number> is the port number of the remote logging server.

For example:

error 01940022:3: errdefs: error adding management port destination 100001; check the configuration for missing elements.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The system is out of memory.

Possible causes of out-of-memory conditions include:

  • One or more processes running on the system are using an excessive amount of memory.
  • The logging configuration is excessively large (for example, containing several hundred publishers, destinations, and filters).
  • A validation issue in the mcpd process is allowing the creation of an incomplete logging configuration.

Impact

The errdefsd process never publishes an incomplete logging configuration; therefore, all daemons continue to use the previous logging configuration. If the previous logging configuration is the default configuration, then the configuration may only include local syslog logging.

Recommended Actions

  • Check the configuration and reduce your remote logging configuration if possible.
  • Capture a QKView file and upload it to the F5 iHealth diagnostics tool. If F5 iHealth is unable to identify any issues, contact F5 Technical Support to open a support case.
