Topic

You should consider using this procedure under the following condition:

  • You want to modify DHCPv6 settings for the BIG-IP Virtual Edition (VE) management interface.

Description

Starting in 14.1.0, the BIG-IP VE system supports the Dynamic Host Configuration Protocol with IPv6 (DHCPv6) for the management interface, in addition to DHCPv4. The mgmt-dhcp system variable controls the DHCP settings for the management interface with the following values.

ValueDescription
enabledEnables both DHCPv4 and DHCPv6
disabledDisables both DHCPv4 and DHCPv6
dhcpv4Only enables DHCPv4 (DHCPv6 disabled)
dhcpv6Only enables DHCPv6 (DHCPv4 disabled)

The mgmt-dhcp default value is enabled on a BIG-IP VE system and dual stack DHCP is supported on the management interface. You can change the DHCPv4/DHCPv6 support settings independently by modifying the mgmt-dhcp value. 

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the TMOS Shell (tmsh).

Procedures

Modify DHCP settings for the BIG-IP VE management interface

Impact of procedure: Modifying DHCP settings on a management interface may disconnect you from the BIG-IP system, depending on how your network supports DHCP. The impact of the procedure depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To modify the DHCP settings, use the following command syntax:

    modify /sys global-settings mgmt-dhcp <value>

    Replace <value> with the available variable value as listed in the previous table. For example, to enable DHCPv6 only and disable DHCPv4 on the management interface, enter the following command:

    modify /sys global-settings mgmt-dhcp dhcpv6

  3. Save the change by entering the following command:

    save /sys config

  4. To verify the modified DHCP settings, enter the following command:

    list /sys global-settings mgmt-dhcp
