Description

Client-side checks such as AV check, Firewall check, Disc Encryption take a long time.

Environment

  • APM
  • Edge Client
  • APM Client

Cause

Various.

Recommended Actions

  1. Clearing the client components on the local machine and re-installing the client with admin privileges. Preferably, the components should be removed following the instruction in the articles below:
    K12444: Overview of the Client Troubleshooting Utility for Windows
    K64744125: Manually Uninstalling BIG IP EDGE CLIENT on macOS
     
  2. Update EPSEC package to the most recent:
    K48955220: Installing an OPSWAT Endpoint Security update on BIG-IP APM systems
     
  3. Updating the APM client package:
    K81649656: Overview of APM Clients update on BIG-IP APM
    K13757: BIG-IP Edge Client version matrix
