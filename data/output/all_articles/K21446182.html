Known Issue

The BIG-IP system may not mirror connections on a virtual server.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server on the BIG-IP system with the Clustered Multiprocessing (CMP) feature disabled.

    Note: The VIPRION platform requires you to enable the CMP feature. The VIPRION platform does not support disabling the CMP feature.

  • The connection mirroring feature on the virtual server is enabled.

Impact

Connection mirroring may not work as expected. As a result, the client connections to a virtual server may drop after a failover event.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The connection mirror table on the standby system has missing entries. You can view the table by typing the following command:

    tmsh show /sys connection type mirror

  • Your BIG-IP system does not maintain client connections to a virtual server after a failover event.
