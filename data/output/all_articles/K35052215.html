Known Issue

BIG-IP APM portal access may fail to process JAR files.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access with Java patching.
  • The header size of the application JAR file is larger than 72 bytes.

Impact

The Java applet fails to render correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Java applet fails to render correctly.
  • The java console logs an error message similar to the following example:

    java.io.IOException: line too long
