K000154680: Unable to Pull NGINX Plus Ingress Controller Image Resulting in Error 401

Description

  • A 401 authorization error occurs when attempting to pull the NGINX Ingress Controller image from private-registry.nginx.com.
  • This error prevents successful deployment or upgrade of the NGINX Ingress Controller in a Kubernetes environment.

Environment

  • Product: NGINX Ingress Controller
  • Version: 5.1.0
  • Kubernetes cluster with NGINX Ingress Controller deployment
  • Image pulled from private-registry.nginx.com
  • JWT-based authentication used for registry access

Cause

  • The issue is caused by using a Kubernetes secret of type "generic" containing a JWT token for image pulling.
  • The correct method requires a secret of type "docker-registry" with the appropriate credentials. Using an incorrect secret type results in a 401 authorization error from the registry.

Recommended Actions

  • Create the correct image pull secret:
    Use this command to create a docker-registry type secret:
    kubectl create secret docker-registry <secret-name> \
  --docker-server=private-registry.nginx.com \
  --docker-username=<JWT> \
  --docker-password=none \
  -n <namespace>
    Replace <secret-name>, <JWT>, and <namespace> with your actual values.
  • Create the license secret for usage reporting (if required):
    kubectl create secret generic license-token \
  --from-file=license.jwt=license.jwt \
  --type=nginx.com/license \
  -n <namespace>
  • Reference secrets correctly in your deployment:
    Ensure that your deployment manifests or Helm values reference both the image pull secret and license secret as specified in the NGINX Ingress Controller documentation.
  • Licensing Considerations:
    Licensing is typically per deployment; consult your account manager for details on your entitlements.
