Description

Management interface does not allow VLAN ID 0 or tagged VLANs

Environment

  • BIG-IP - All modules
  • TAG vs UNTAG VLANs

Cause

Informational only

Recommended Actions

By design, the management port can only support an untagged VLAN, if tagged VLANs are necessary then the management needs to be done in a tmm interface (self ip).
VLAN 0 is a reserved VLAN for different purposes and can not be used in the management port.
