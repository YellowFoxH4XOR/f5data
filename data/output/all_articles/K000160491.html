Description

This article covers how to verify file integrity on the BIG-IP system products by comparing files against a known good source. You can also install and run the F5 System Scanner described in K000160515: F5 System Scanner.

Procedures

  • Gather file information from a known good source BIG-IP system
  • Gather file information from the target BIG-IP system
  • Perform the comparison of the file information you gathered
  • Act on the results of the file integrity verification

Gather file information from a known good source BIG-IP system

  1. Identify a known good source that contains the verified file or files such as a BIG-IP running a clean install. For more information about completing a clean install on a BIG-IP, refer to K13117: Performing a clean installation of BIG-IP.
  2. Gather the following information for each file from the known good source:
    • The file creation/modification timestamp.
    • Use a hashing algorithm tool such as sha256sum or md5sum to compute the checksum of the file.
    • Record the checksum and file name.

Gather file information from the target BIG-IP system

  1. Identify the target system containing the file or files you wish to validate.
  2. Gather the following information for each file on the target system:
    • The file creation/modification timestamp on the target system.
    • Use the same hashing algorithm you used on the known good source to compute the target file checksum.
    • Record the checksum and file name.

Perform the comparison of the file information you gathered

  1. Use a third-party system that is known to be trusted and secure to conduct the comparison of the file information you gathered. For each file:
    • Compare the file checksum from the known good source and the target system to ensure the files are identical.
    • Compare the timestamps of the files. Verify whether the creation or modification times are identical.
    • Document any mismatches or failures during this process for troubleshooting and remediation.

Act on the results of the file integrity verification

  1. If all files are identical (timestamp and checksum match), then the files on the target system are verified.
  2. If there are mismatches, then investigate the source of discrepancies (e.g., file corruption, unauthorized modifications, etc.) and take appropriate corrective actions. If you suspect a security compromise on your BIG-IP system, review the following article: K11438344: Considerations and guidance when you suspect a security compromise on a BIG-IP system.
