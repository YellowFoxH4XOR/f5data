Known Issue

The BIG-IP system reports being managed by the BIG-IQ system after you remove the BIG-IP system from the BIG-IQ system's device inventory.

This issue occurs when all of the following conditions are met:

  • You use the BIG-IQ Centralized Management system to manage remote BIG-IP systems.
  • You remove a BIG-IP system from the BIG-IQ Centralized Management device inventory.
  • Your BIG-IP system continues to display Managed by BIG-IQ in the status area next to the F5 logo.

Note: Ensure that your BIG-IP system is not currently being managed by a high availability (HA) peer BIG-IQ system.

Impact

The BIG-IP system mistakenly reports being Managed by BIG-IQ.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system continues to report being Managed by BIG-IQ after the BIG-IP system was removed from the BIG-IQ Centralized Management device inventory.

Workaround

To work around this issue, you can remove the BIG-IQ reference from the REST database on the BIG-IP system. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP system's Advanced Shell (bash).
  2. Determine the machineId of the BIG-IQ reference from the BIG-IP system's REST database by entering the following command:

    restcurl shared/resolver/device-groups/cm-bigip-allDevices/devices | jq '.items[] | select(.product == "BIG-IQ") | {product,machineId}'

    The command returns an output similar to the following example:

    {
      "product": "BIG-IQ",
      "machineId": "81397691-98ef-4b64-9df9-0b5de69591d9"
    }

  3. Remove the BIG-IQ reference from the REST database on the BIG-IP system by entering the following command syntax:

    restcurl -X DELETE shared/resolver/device-groups/cm-bigip-allDevices/devices/<BIG-IQ reference machineId>

    Using the example from previous steps, you would enter the following command:

    restcurl -X DELETE shared/resolver/device-groups/cm-bigip-allDevices/devices/81397691-98ef-4b64-9df9-0b5de69591d9

  4. Verify that the BIG-IQ reference ("product": "BIG-IQ") no longer exists in the REST database on the BIG-IP system by entering the following command:

    restcurl shared/resolver/device-groups/cm-bigip-allDevices/devices
