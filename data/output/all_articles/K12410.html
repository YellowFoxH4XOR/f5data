Known Issue

This is the result of a known issue. Mac OS X users that have Japanese set as their first preferred language may be unable to resolve DNS after connecting to Network Access. This issue occurs because the Mac OS X system is unable to properly create a service ID when it connects to either FirePass or BIG-IP APM. The service ID is used to configure network settings, such as DNS. While Japanese is the only language reported to have this issue, other languages may also be affected.

F5 Product Development tracked this issue as ID 339469 and it was fixed in BIG-IP APM 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1789.0-HF2, which has been issued for BIG-IP APM 10.2.0, and in cumulative hotfix HF-610-4, which has been issued for FirePass 6.1.0.
