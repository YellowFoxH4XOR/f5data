Description

BIG-IQ VE unable to setup HA after upgrade to 7.1.0 with error "Unable to connect to Postgres. Error code: 2'

  • After upgrade BIG-IQ CM from 7.0.0.1 to 7.1.0 the BIG-IQ cannot join HA together
  • Secondary is not able to access GUI
  • Tried to rebooting and rejoin secondary to HA but problem still occurs.

Environment

  • BIG-IQ VE
  • Upgrade to 7.1.0
  • Services like elasticsearch, guiserver, restjavad and tokumond having status as "down, waiting for setupd configuration to complete"

Cause

During HA setup, the Secondary BIG-IQ needs to connect to the Primary BIG-IQ on port 5432 to replicate the Postgresql database. If the network connectivity is broken, the Postgres service will stay offline and GUI will never come up.

Recommended Actions
Note : Enabling port 5432 is required for BIG-IQ version 7.1.0.

  1. Enable/allow 5432 on the firewall.
  2. Reboot secondary BIG-IQ.
  3. Run HA setup again.
Note : If above steps 2-3 does not resolve the issue, try below steps. 
  1. Enable/allow 5432 on the firewall.
  2. Boot into previous volume. 
  3. Delete latest volume that has the issue.
  4. Reinstall Upgrade.

Additional Information

ha_pg_basebackup is used for replicate database from primary and set itself as a slave Postgres database on the secondary CM:

/var/log/ha_pg_basebackup.log
