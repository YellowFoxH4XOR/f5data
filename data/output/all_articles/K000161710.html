Description

In BIG-IP v21.1.0, a new system DB variable was introduced.

To check the current value of this DB variable, run the following command from the BIG-IP CLI:

#tmsh list sys db tmm.http2.enablestreampriority

sys db tmm.http2.enablestreampriority {

value "true"

}

This DB variable controls whether HTTP/2 stream priority processing is enabled, specifically in accordance with RFC 9218 ("Extensible Prioritization Scheme for HTTP").

Environment

  • BIG-IP v21.1.0
  • HTTP/2 traffic

Answer/Recommended Actions

The tmm.http2.enablestreampriority DB variable controls whether RFC 9218 HTTP/2 stream priority processing is enabled on the BIG-IP system.

  • When set to true (default), the BIG-IP will process HTTP/2 stream priorities in accordance with RFC 9218 – Extensible Prioritization Scheme for HTTP.
  • When set to false, RFC 9218 functionality is disabled and default (non-RFC 9218) priority handling is used instead.

Additional Information

This DB variable was newly introduced in BIG-IP version 21.1.0. It is not present in earlier versions.
