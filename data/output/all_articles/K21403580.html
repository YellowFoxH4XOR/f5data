Known Issue

The BIG-IP system may fail to install an existing Secure Sockets Layer (SSL) key to the FIPS hardware security module (HSM).

This issue occurs when all of the following conditions are met:

  • Your existing SSL key security-type is normal and the key has no (.key) extension.

    For example, the following SSL key test does not have a (.key) extension with security-type normal. The SSL key should be test.key instead of test.

        sys crypto key test {
            key-size 2048
            key-type rsa-private
            security-type normal
        }

  • You attempt to install the existing key to the FIPS security-type using the tmsh install /sys crypto key command.
  • Your BIG-IP system is configured for FIPS HSM.

Impact

The BIG-IP system is unable to install an existing SSL key to the FIPS security-type.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system displays an error message similar to the following example:

    Syntax Error: must specify at least one of from-editor, from-local-file, or from-url

  • The BIG-IP system fails to install an SSL key to the FIPS HSM module

Workaround

To work around this issue, you can remove the existing SSL key/certificate pair, re-import the key/certificate pair with the proper extensions to the BIG-IP system, and then install the newly imported key/certificate pair to the FIPS HSM. To do so, perform the following tasks:

Impact of workaround:  Removing the affected configuration may disrupt services that are already in use. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  • Remove the existing SSL key/cert pair.
  • Import the SSL key/cert pair with the proper (.key/.crt) extensions to the BIG-IP system.
  • Install the SSL key/cert pair to the FIPS HSM.

Note: For more information about removing and installing SSL keys and certificates, refer to K15462: Managing SSL certificates for BIG-IP systems using the tmsh utility.
