Description

Users logging out from an application receive a TCP/RST when SAML SP sends the SAML SLO request to APM SAML IdP

Environment

  • APM deployed as SAML IdP

Cause

After users logout from an application on back-end server, they receive a 200 OK with http header 'Clear-Site-Data'.

This makes cookies to be cleared on the browser, so when it sends the SAML SLO req to APM it does not include an access cookie and connection is closed sending a TCP/RST.

Recommended Actions

Add this irule to APM VS:

when HTTP_RESPONSE {
   HTTP::header remove Clear-Site-Data
}
