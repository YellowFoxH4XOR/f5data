Known Issue

This is the result of a known issue. BIG-IP 8400/8800 outgoing traffic on a trunk is limited to a single link when PVA is demoted to wire mode. This issue may occur when the configuration is too large for the PVA. As a result, all objects that exceed the maximum objects allowed for the PVA are demoted to wired mode.

When this issue occurs, an error message similar to the following is reported in the /var/log/ltm file:

pvad[2059]: 01130003:6: Config too big for PVA. Going to wire mode.

This message indicates that objects such as virtual servers that would qualify for PVA acceleration will not be accelerated. If trunks are configured, these objects are not accelerated (PVA wired mode). All egress traffic for these objects is limited to a single link within the trunk.

F5 Product Development tracked this issue as ID 223959.

Support for the affected BIG-IP8400 and 8800 platforms ended in BIG-IP 11.1.0. For more information about software support for the BIG-IP 8400 and 8800 platforms, refer to K13520: Updated End of New Software Support announcement for the 6400 FIPS/NEBS, 6800 FIPS, 8400/8400 FIPS/NEBS, and 8800 platforms.

Workaround

You can work around this issue by attempting to reduce the number of configured objects.
