Issue

If you use Enterprise Manager to install a new software version or hotfix on a managed device and the installation fails or encounters issues, Enterprise Manager may report a Job has failed, installation is looping error message. To help identify and recover from the issue, you can perform the following procedures:

  1. Connect to the terminal port on the affected managed device.
  2. Check the console output for possible hints as to why the installation failed.
  3. If you do not see any errors that report a hardware failure, wait for the GRUB boot image selection to appear. Select any available boot location to stop the installation attempts.

    Important: Do not allow GRUB to use the default remote-install location, as this will continue the installation attempts.

    If the managed device will not boot successfully from any available boot location, exit this procedure and perform a clean installation on the managed device. For information, refer to one of the following articles:

    • K13117: Performing a clean installation of BIG-IP 11.x - 13.x or Enterprise Manager 3.x
    • K10819: Performing a clean installation of BIG-IP 10.x or Enterprise Manager 2.x
  4. Log in to the managed device after it boots, remove all files and sub-directories under the /shared/repository directory.
  5. Import a new image of the software into Enterprise Manager and attempt the installation again.

    If the install fails again, run the install_log command from the command line of the affected device. The install_log command will provide a record of the changes made to the device. These records will help you to determine whether Enterprise Manager completed all the necessary installation steps and may help identify the issue. Correct any identified issues and perform the procedure again.

Verifying the installation was successful

When the install job completes without an error, you can verify that the installation was successful by performing the following tasks:

  • Connect to the Configuration utility and refresh the affected managed device. If Enterprise Manager successfully refreshes the device and the device reports that the correct software version is installed, the installation was successful.
  • Connect to the managed device and check the software version and running configuration. If the software version and the running configuration of the managed device are both correct, the installation was successful.
