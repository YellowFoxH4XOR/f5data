Description

Engineering Hotfixes do not get transferred to new software after installing a new software version.
 

Environment

  • Engineering Hotfix
  • Software Upgrade

Cause

None
 

Recommended Actions

If you are considering changing your software version with Engineering Hotfix currently installed on your device, you can check if bugs that were fixed in Engineering Hotfix are already resolved in the version that you are upgrading to on bug tracker: https://my.f5.com/manage/s/bug-tracker.

If bugs that were fixed with Engineering Hotfix are not fixed in the version that you are upgrading to, you can open a new case and request for Engineering Hotfix, but please remember that Engineering Hotfix can be provided only on top of the latest release.
