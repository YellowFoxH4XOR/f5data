K000154632: Access policy with Edge browser does not work

Type
Support Solution
Published
2025-09-26
Updated
2025-09-26
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000154632

Description

Access policy works fine with Chrome or Firefox browsers but fails with Edge browsers.

You notice in a tcpdump that there are requests from client to APM with IE UA instead of Edge UA.

Environment

BIGIP provisioned with APM.

One of these conditions applies

  • Access policy includes an agent that does not allow IE browsers.
  • There is an irule that drops requests with IE UA.

Cause

Edge browser is configured by default with IE mode for backward compatibility, so some or all websites can be redirected from Edge mode to IE mode.

Recommended Actions

That feature is not needed nowadays so you can disable IE mode compatibility for all sites in Edge browser's settings.

  1. Open Edge browser's Settings
  2. Click "Default browser",
  3.  In "Internet Explorer compatibility", Select "Don't allow" from "Allow sites to be reloaded in Internet Explorer mode (IE mode)" dropdown menu, Once changed, a "Restart" button comes up.
  4. Click it to apply the changes.
