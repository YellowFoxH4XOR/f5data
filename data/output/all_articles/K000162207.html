K000162207: Security policy in Transparent, with microservice in blocking... not blocking the request

Description

You have configured an application security policy as transparent, and the microservice as blocking, yet the request you want blocked is passing through the Advanced WAF.

Environment

ASM

Cause

As per design

Answer/Recommended Actions

The microservice feature has the ability to set overrides on two violations:

  • Evasion Techniques
  • HTTP Protocol Compliance

That means...

  • If a request matches a violation that is Evasion Technique, OR HTTP Protocol Compliance, and no other violations, then it will not be blocked.
  • But if a request matches any other violations, and those violations are set to Block (even if Block is greyed out on the microservice), then the request will be blocked.
