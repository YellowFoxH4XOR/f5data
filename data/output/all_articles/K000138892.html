K000138892: iRule causing site to hang

Published
2024-03-12
Updated

Applies to
  • BIG-IP

Source

Description

TCL error like the one below is generated when STREAM::disable is used against BIG-APM virtual server when access session state is set to not allowed.

TCL error: /Common/<iRule_name> - Operation not supported (line 1) invoked from within "STREAM::disable"

Where <iRule_name> is the name of the iRule that generated the log message.

Using following iRule: 

 when HTTP_REQUEST {
  STREAM::disable
 }

with Policy: Logon page / AD auth

Environment

BIG-IP APM 17.1.0.3

Cause

Bug alias 451045

Recommended Actions

The work around is: set the iRule STREAM:Disable with condition only when access session state is allowed

when HTTP_REQUEST {
 set apm_cookie [HTTP::cookie value MRHSession]
 if { $apm_cookie != "" && [ACCESS::session exists -state_allow $apm_cookie] } {
 STREAM::disable
 }
}
