Topic

You can determine the type of mobile device connecting to the BIG-IP APM system by analyzing the session.user.agent variable and assigning resources based on the value returned.

The following example procedures explain how to gather the device information from the session.user.agent variable and assign resources based on the data returned:

  • Creating the user agent action
  • Assigning a resource

Important: These procedures serve only as an example of how to assign resources; they are not intended to define how to integrate the procedure into your environment.

Prerequisites

  • The BIG-IP APM system configured with an existing access policy and web resource
  • An understanding of the visual policy editor and writing access policies

Creating the user agent action

The following demonstrates how to create the user agent action and assign branches for iPhone and Android devices:

  1. Click Access Policy in the navigation pane.
  2. Click Access Profiles.
  3. Click Edit... in the Access Policy column in the same row as the name of the access policy to which you chose to add the user agent check.

    The Visual Policy Editor opens in a new window.
  4. Click the plus (+) icon located on the fallback branch exiting the Start box.  

    A pop-up window appears.
  5. In the General Purpose section, click Empty.
  6. Click Add Item.
  7. In the Name: text box, type the following content:

    User Age

  8. Click the Add Branch button.
  9. In the Name text box, delete any existing text and type the following content:

    iPhone

  10. In the Expression: row, click the change link. 

    A pop-up window opens.
  11. Click the Advanced tab
  12. Enter the following text in the text box:

    expr { [mcget {session.user.agent}] contains "iPhone" or [mcget {session.user.agent}] contains "iPad" or [mcget {session.user.agent}] contains "iPod" }

  13. Click Finished.

    The pop-up window closes.
  14. Click Add Branch.
  15. In the newly-added Name text box, delete any existing text and type the following content:

    Android

  16. In the Expression: row, click the change link.

    A pop-up window opens.
  17. Click the Advanced tab.
  18. Enter the following text in the text box:

    expr { [mcget {session.user.agent}] contains "Android" }

  19. Click Finished.

    The pop-up window closes.
  20. Click Save.

You now see the newly-created User Agent Check action with iPhone, Android, and fallback branches.

Assigning a resource

The following procedure demonstrates how to assign a resource to the iPhone branch of the User Agent Check action:

  1. Click the plus (+) icon located on the iPhone branch of the User Agent Check action.  

    A pop-up window appears.
  2. In the General Purpose section, click the Resource Assign option button.
  3. Click Add Item.
  4. Click Add new entry.
  5. Click the Add/Delete Web Application Web Resources link.

    A pop-up window opens.
  6. Select the check box next to the web application you want to assign to the iPhone profile.
  7. Click Update.
  8. Click Save.

Note: For more information about access policies and the visual policy editor, refer to the Configuration Guide for BIG-IP Access Policy Manager.
