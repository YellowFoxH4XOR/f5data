Description

After creating an IPI TTL record with command like tmsh run security ip-intelligence category name /Common/phishing ip-ttl add { 192.168.1.245,120,allow-advertisement } , you noticed on the device-pair IPI TTL record cannot be shown with command tmsh show security ip-intelligence info address 192.168.1.245 .

Environment

  • IP Intelligence setup across device-pair

Cause

None. This is by design.

Answer/Recommended Actions

IPI TTL records and status is only visible and effective in active device of traffic-group-1.

In the backend of the configuration synced device-group, the IPI TTL records are always immediately in synced but not shown in standby devices. (So in user perspective it looks like the records are shifted)
