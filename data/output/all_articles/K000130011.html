K000130011: Functionality similar to "Reuse Windows Logon Credentials" on macOS

Type
Support Solution
Published
2022-12-14
Updated
2026-04-28
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.3
Source
https://my.f5.com/manage/s/article/K000130011

Description

On Windows it is possible to setup a connectivity profile and Edge Client to reuse logon credentials, so the Edge Client auto logs in.

Edge Clients on macOS do not have such functionality.

Environment

  • any macOS
  • any Edge Client

Cause

Due to macOS not providing similar APIs like Windows to extract the credentials when user logs into the client, this is not supported.

 Recommended Actions

None.

Additional Information

None.
