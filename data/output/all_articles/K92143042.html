Description
Tmrouted is restarting every few minutes on your device.

You see the following logs in /var/log/daemon:

Nov 15 15:04:32 bigip1 emerg logger: Re-starting tmrouted
Nov 15 15:05:17 bigip1 emerg logger: Re-starting tmrouted
Nov 15 15:05:38 bigip1 emerg logger: Re-starting tmrouted

Environment

  • BIG-IP

Cause
Issue is caused by ID 730852. Note: See Related Content for more information

Recommended Actions

If you believe you have run into this issue, collect the following debug data and contact F5 Networks Support
  1. Enable debug logging on mcpd, tmrouted, and ZebOS:
    • Refer to K5532 below for steps to enable/disable mcpd debug logging
    • Refer to K10168 below for steps to enable/disable ZebOS debug logging
    • To enable/disable debug logging for tmrouted
      • Enable debug logging
        echo 5 > /var/service/tmrouted/debug
        bigstart restart tmrouted
      • Disable debug logging 
        rm /service/tmrouted/debug
        bigstart restart tmrouted
      • Verify service is up  
        bigstart status tmrouted
      • Note: logs will be sent to /var/tmp/tmrouted.out
  2. Attempt a reproduction of the issue. If you are able to reproduce the issue, collect a qkview
  3. Once you are done with the reproduction attempt, disable debug logging on mcpd, tmrouted, and ZebOS
