Description

VPN users can access resources that are not granted to them by modifying static routes on the client

With no other modification to the network access, or adding ACL to the resources, clients can gain access to non granted resources

VPN users connected through APM split tunneling, and have granted access to specific resources, can create static routes on the client machines to allow them access to other resources

For example:
Network access has split tunneling and it is configured to have just specific resources in the IPV4 LAN Address Space

apm resource network-access /Common/Network-Access {
      address-space-include-subnet {
        {
            subnet 10.128.20.11/32
        }
    }


User that is connected can access that resource.

The lease ip assigned to test user is 1.1.1.1

Environment

  • APM Edge client configured to connect through Access profile
  • Split tunneling

Cause

Client machine is external to F5, and if the user has admin privilege, he can create static routes on his machine.
 

Recommended Actions

The work around for this behavior:

1) Use Access control list (ACL)to prevent the client from accessing non allowed resources
2) Check the option of "Prohibit routing table changes during Network Access connection" in the Network Settings part.
