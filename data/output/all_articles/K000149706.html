Description

Connection hangs when HTTP response with a large header section is processed in the HTTP_RESPONSE_RELEASE iRule event.

Environment

  • iRule HTTP_RESPONSE_RELEASE event
  • suspending commands (K12962)
  • large HTTP headers section
  • connection hangs

Cause

ID1538241: HTTP may not forward POST with large headers and parking HTTP_REQUEST_RELEASE iRule

 

Existing bug ID1538241 refers to POST with large headers and HTTP_REQUEST_RELEASE event.

But this bug can also manifest itself for the traffic going in the other direction. I.e. when there's an HTTP response with a large headers portion and HTTP_RESPONSE_RELEASE event.

Based on the bug description, the condition for this bug is also using a command that suspends the connection. In the example iRule, they're using the after command but there is a list of other commands that suspend the connection (K12962).

Recommended Actions

Upgrade to a version where ID1538241 is fixed

Additional Information
