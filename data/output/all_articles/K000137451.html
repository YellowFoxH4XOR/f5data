Description

The security advisory article says the engineering hotfix is available from Downloads but for BIG-IP 16.1.4.1 it's not listed.

This article helps you locate the following hotfixes to address CVE-2023-46747 and CVE-2023-46748:

  • Hotfix-BIGIP-17.1.1.0.2.6-ENG
  • Hotfix-BIGIP-17.1.0.3.0.75.4-ENG
  • Hotfix-BIGIP-16.1.4.1.0.50.5-ENG
  • Hotfix-BIGIP-15.1.10.2.0.44.2-ENG
  • Hotfix-BIGIP-14.1.5.6.0.10.6-ENG
  • Hotfix-BIGIP-13.1.5.1.0.20.2-ENG

Note: For general information about installing engineering hotfixes (not specific to the above CVEs), refer to: K13123: Managing BIG-IP product hotfixes (11.x - 17.x).

Environment

  • MyF5 Downloads

Cause

F5 released engineering hotfixes for CVE-2023-46747 and CVE-2023-46748. 

Recommended Actions

If the security advisory indicates your version is vulnerable to a CVE and lists an engineering hotfix as the patch for the CVE, you must start by downloading the hotfix for your version.

  1. Follow the Download F5 products that are not NGINX products procedure in K000090258: Download F5 products from MyF5.

    Note: To locate an engineering hotfix, you must first select the appropriate point release in the Product Container section. For example, when you select the 17.1.0.3 product container, you can then scroll down to the Select a download file section, where you can download files as needed. In the case of 17.1.0.3, you would download the following file:

    Hotfix-BIGIP-17.1.0.3.0.75.4-ENG.iso    OOBSN 10/27/23 - ISO for EngHF 75 for ID1117229 ID1240121 ID1381357

  2. After downloading the ISO file, you must download the corresponding MD5 file. For the example in step 1, you would go back the point release container and select following MD5 file:

    Hotfix-BIGIP-17.1.0.3.0.75.4-ENG.iso.md5    OOBSN 10/27/23 - MD5 file for ISO for EngHF 75 for ID1117229 ID1240121 ID13

  3. Verify the MD5 and install the ISO as explained in K13123: Managing BIG-IP product hotfixes (11.x - 17.x).
