K32200302: Change color of portion of APM Logon Page

Type
Support Solution
Published
2022-09-02
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM: 16.0.X, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K32200302

Description
Change color configuration of APM standard logon page is desired

Environment

  • BIG-IP APM
  • Standard logon page 

Cause
None

Recommended Actions

1. Log in to the Configuration utility.
2. Navigate to the Quick Start/Basic page:
13.0.0 and later

Access > Profiles / Policies > Customization > Quick Start/Basic

11.x - 12.x

Access Policy > Customization > Quick Start/Basic

3. Under Access Profiles, in the Available Profiles list, click the access profile that you want to have a custom logo image.
4. In the Select Language list, click the language preference of the access profile.
5. There you will see "Page Background Color", "Header Background Color" and "Table Background Color"
6. Change color of the section you need to change
 

Additional Information
None
