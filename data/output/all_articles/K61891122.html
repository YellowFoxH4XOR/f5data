Published
2022-08-04
Updated
2025-02-06
Applies to

Source

Description

BIG-IQ GUI: Monitoring tab >> Alerts & Notifications >> Settings >> Directory Usage Alert Conditions

This section applies to BIG-IQ only, not the BIG-IP managed devices.
 

Environment

  • BIG-IQ
  • Monitor disk usage on managed devices

Cause

None

Recommended Actions

To monitor disk usage for managed BIG-IP devices configure the following:

Monitoring tab >> Alerts & Notifications >> Settings >> Disk Usage Alert Conditions: Used disk space is above threshold for a device

Note: Alerts are not triggered immediately after updating the configuration and may take several hours to be triggered.

Additional Information

Alerts are logged in /var/log/restjavad.0.log

Use the following command to list all alerts:
grep alerts /var/log/restjavad.*.log
