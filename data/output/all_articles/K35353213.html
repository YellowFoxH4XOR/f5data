Known Issue

If you disable a single pool member, the system removes all BIG-IP DNS persistence records.

This issue occurs when all of the following conditions are met:

  • You have configured a wide IP with persistence enabled.
  • You have disabled Drain Persistent Requests. To access this Configuration utility setting, navigate to DNS > Settings > GSLB > General (the Drain Persistent Requests default setting is Enabled).
  • You have toggled a wide IP pool member from Enabled to Disabled.

Impact

The system clears all DNS persistence records.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you disable a single pool member, the system removes all DNS persistence records.
