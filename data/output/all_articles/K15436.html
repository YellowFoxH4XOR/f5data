Topic

You should consider using these procedures under the following condition:

  • You want to increase restjavad log verbosity.

Description

The restjavad service implements all of the iControl REST API functionalities on a BIG-IP system. The restjavad logging configuration is set in the /etc/restjavad.log.conf file.

When troubleshooting with restjavad, you may need to increase the verbosity of the events and details saved in the log file. As a result, the log files may fill up quickly. Therefore, you need a larger file handler count to capture all of the events you require during troubleshooting.

Important: Increasing restjavad logging verbosity results in higher disk usage. F5 recommends that you reset the restjavad logging configuration back to the default value after troubleshooting.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have command line access.
  • You are familiar with a text editor in the Linux environment.

Procedures

  • Increase the verbosity of restjavad logging
  • Reset the verbosity to the default setting

Increase the verbosity of restjavad logging

You can increase restjavad logging verbosity to assist with troubleshooting REST API-related issues by performing the following procedure:

Impact of procedure: The restjavad service on the BIG-IP system is briefly interrupted during the restart. F5 recommends performing this procedure during a maintenance window. This procedure increases disk usage for the log files. F5 recommends that you reset the restjavad logging configuration to the default value after troubleshooting.

  1. Log in to the command line.
  2. Before you edit the current restjavad log file, create a backup copy by entering the following command:

    cp -a /etc/restjavad.log.conf /var/tmp/SOL15436-backup-restjavad.log.conf

  3. Using a text editor of your choice, edit the /etc/restjavad.log.conf file.
  4. To increase logging verbosity, modify the line with the .level parameter.

    For example:

    .level=INFO

    In this example, note the following:

    • .level refers to the variable for the restjavad log level
    • INFO is the level for basic information logging

    Changing the value from INFO to FINE will increase the verbosity of logging.

    For example:

    .level=FINE

    For even higher verbosity of logging, you can use the FINEST value.

    Important: When using the FINEST value, restjavad greatly increases the events and details captured in the log files, creating more disk usage.

  5. Increase the number of restjavad.*log files that you want to create before they are overwritten by modifying the line with the java.util.logging.FileHandler.count parameter.

    For example:

    java.util.logging.FileHandler.count=2

    Change this value to 30.

  6. Save the changes and exit the text editor.
  7. To use the new verbosity logging level set, restart restjavad by entering the following command:

    tmsh restart /sys service restjavad

  8. When restjavad resumes service, you can verify the increased verbosity by reviewing the /var/log/restjavad.0.log log file.

Reset the verbosity to the default setting

If you have previously increased the logging verbosity for the restjavad service and you want to reset it back to the default level of logging, perform the following procedure:

Impact of procedure: The restjavad service on a BIG-IP system is briefly interrupted during the restart. F5 recommends performing this procedure during a maintenance window.

  1. Log in to the command line.
  2. Copy the original  restjavad.log.conf file over the modified version of the file by entering the following command:

    cp -a /var/tmp/SOL15436-backup-restjavad.log.conf /etc/restjavad.log.conf

  3. To use the new default verbosity logging set, restart restjavad by entering the following command:

    tmsh restart /sys service restjavad

  4. When restjavad resumes service, you can verify the reduced verbosity by reviewing the /var/log/restjavad.0.log log file.
