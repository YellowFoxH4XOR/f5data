Description

After applying a profile to a virtual server that is configured with many profiles you observe an LTM error log and all connections to the virtual server are reset and an error message similar to the following is logged to /var/log/ltm:

01010008:3: Proxy initialization failed for /<partition>/<virtual server name>. Defaulting to DENY.
01010008:3: Listener config update failed for /<partition>/<virtual server name>: ERR:ERR_MEM
[F5RST: Port denied]

Environment

  • BIG-IP
  • Virtual server
  • Profiles

Cause

Currently there is a maximum of 23 hud chain elements that can be attached to a virtual server. Hud chain elements are created by adding profiles and enabling various settings on a virtual server, and some profiles add more than one element.  For more information about how to determine how many hud elements are attached to a virtual server, refer to the link below.

Bug ID 1075045: Proxy initialization failed, Defaulting to DENY, after applying additional profile to a virtual server

Recommended Actions

  • Reduce the number of hud chain elements on the virtual server below 24.
