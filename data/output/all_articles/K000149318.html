K000149318: Traffic Intelligence Signature Update: "Error: Non OK return code (400) received from API call"

Type
Support Solution
Published
2025-02-07
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149318

Description

The following error message is logged on /var/log/hitless_upgrade.log

Error: Non OK return code (400) received from API call

Environment

  • BIG-IP without PEM, AFM or ASM provisioned
  • Automatic signature update enabled

Cause

Seen behaviour is expected. The device is not licensed and configured with the PEM, AFM or ASM modules which provides an option for updating the classification signatures and engine. The BIG-IP system sends a hardware manifest using an SSL connection to the F5 API server at api.f5.com. and since none of the above modules are licensed the update fails.

Recommended Actions

Disable the daily automatic signature update

  1. Connect to CLI
  2. Run

    tmsh modify ltm classification signature-update-schedule auto-update-disabled
