K67549140: Audit log search tool in GUI start and end date limits

Description

In the GUI, the audit log search properties shows pre-filled dates for start and end dates, usually just for the current day, this dates can be changed, but only within the boundaries presented, otherwise, it won't have an effect in the search.
Selecting dates outside this boundaries will be accepted, but those dates will be ignored, only logs from the current day will be searched for

Environment

  • GUI, audit search tool

Cause

This is by design, the BIG-IP has limited resources, logs are rotated and compressed every day, the current day is the only log not compressed
The BIG-IP won't look for logs in compressed files, if this were the case,  mcpd  would have to un-compress and then compress the log files every time a search is performed
This would have a negative impact on the BIG-IP performance

Recommended Actions

Linux tools like zcat and grep can be used in the CLI
