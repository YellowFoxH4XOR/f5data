Issue

When you configure a link on a BIG-IP GTM or BIG-IP Link Controller system, you are defining an object that represents a physical connection to the Internet. A link is associated with a router on the network that provides a path to the Internet.

Note: Before creating the link objects on the BIG-IP GTM or BIG-IP Link Controller system, you should create a default gateway pool that contains the link addresses. Then you should use that pool to define the system's default gateway. For more information, refer to the BIG-IP Global Traffic Manager and Link Controller: Implementations guide.

Note: For information about how to locate F5 product guides, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Health monitors are used to ensure that the BIG-IP GTM or BIG-IP Link Controller links are available. Many monitor options exist, although transparent monitors are recommended for checking the status of links. Transparent monitors allow the system to monitor a destination on the other side of the link, ensuring that the link is available and able to pass traffic. For example, you can configure a transparent monitor to ping www.f5.com through the link instead of just monitoring the link.

The best practice for monitoring the BIG-IP GTM or BIG-IP Link Controller link objects, and the BIG-IP LTM gateway pool, is to monitor the link objects with the bigip_link monitor, and monitor the BIG-IP LTM gateway pool using one or more transparent monitors.

Note: For BIG-IP Link Controller systems, F5 recommends that you configure two or more transparent monitors with an availability requirement of 1 for monitoring the status of the gateway pool.

  • Configure the bigip_link monitor
  • Create the transparent monitors
  • Create a default gateway pool
  • Configure the BIG-IP LTM gateway pool to be monitored
  • Assign the gateway pool as the default gateway

Configure the bigip_link monitor

To configure a custom bigip_link monitor, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Global Traffic > Links or Link Controller > Links.

    Note: In BIG-IP GTM 11.5.0 and later, navigate to DNS > GSLB > Links.

  3. Select the link to be monitored.

    Note: In BIG-IP 11.x, if no monitor is specified, the system will automatically assign the bigip_link monitor.

  4. From the Health Monitors section, select bigip_link from the Available column.
  5. Click << to move the bigip_link monitor to the Enabled column.
  6. Click Update.
  7. Repeat these steps for each link object that you want to configure.

Create the transparent monitors

To create a transparent monitor for monitoring the default gateway pool member(s), perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: The type of monitor created is optional. However, in this example, a Gateway ICMP monitor is created.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Monitors.
  3. Click Create.
  4. Type the name for the monitor.
  5. From the Type menu, select Gateway ICMP.
  6. From the Configuration menu, select Advanced.
  7. Select Yes for the Transparent section.
  8. In the Alias Address field, type the IP address of the upstream destination to be monitored.
  9. Click Finished.

Note: For BIG-IP Link Controller systems, F5 recommends that you configure a second transparent monitor and choose a different upstream destination IP address to be monitored. If one of the upstream devices being monitored becomes unavailable and the link is still up, the link will not be marked down by the BIG-IP Link Controller system.

Create a default gateway pool

To configure the default gateway pool that contains the IP addresses of the routers that the BIG-IP system will use as gateways, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Pools.
  3. Select Create.
  4. Enter a name for the pool, such as Default_GW_Pool.
  5. For Health Monitors, select the transparent gateway ICMP monitor you created in the previous steps and move it to the Active box.
  6. For Load Balancing Method, select a load balancing method for the pool.
  7. For Address, enter the IP address of at least one of default network gateway.
  8. For Service Port, select * All Services.
  9. To add the default gateway to the New Members table, select Add.
  10. Repeat steps 7 through 9 for each default gateway address.
  11. Select Finished.

You can cannot create a BIG-IP LTM pool for to use standalone BIG-IP DNS/GTM systems as a gateway pool cannot using the Configuration utility.

To create the pool, you can use the Traffic Management Shell (tmsh) with the following command syntax.

  1. Log in to tmsh by entering the following command:

    create /ltm pool <pool_name> members add { <pool_ip>:any <gw_ip>:any <gw_ip>:any }

    For example:

    create /ltm pool gw_pool members add { 192.168.1.1:any 192.168.1.2:any }

  2. Assign a monitor to the gateway pool by entering the following command:

    modify /ltm pool <pool_name> monitor <monitor_name>

    For example:

    modify /ltm pool gw_pool monitor gateway_icmp

  3. Save the configuration by entering the following command:

    save /sys config partitions all

Configure the BIG-IP LTM gateway pool to be monitored

To configure the default gateway pool to use the custom monitor created in the previous procedure, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Pools.
  3. Select the BIG-IP LTM gateway pool to be monitored.
  4. From the Configuration menu, select Advanced.
  5. In the Health Monitors section, select the transparent gateway ICMP monitors created in the previous steps, and then click << to move the monitors to the Active window.
  6. For BIG-IP Link Controller systems, select At Least from the Availability Requirement menu, and enter 1 in the Health Monitor(s) box.

Assign the gateway pool as the default gateway

To assign the gateway pool as the default gateway of the BIG-IP DNS/GTM or Link Controller system, perform the following procedure:

Impact of procedure: Performing the following procedure should will route all non-local network traffic to the members assigned in the default gateway pool created in a previous procedure.

  1. Log in to the Configuration utility.
  2. Go to Network > Routes.
  3. Select Add.
  4. Enter a name for the route, such as Default_GW.
  5. Enter 0.0.0.0 for the Destination.
  6. Enter 0.0.0.0 for the Netmask.
  7. For Resource, select Use Pool.
  8. Select the default gateway pool you created in the previous procedure (Example: Default_GW_Pool).
  9. Select Finished.
