K13617: Upgrading an Enterprise Manager that uses an external database

Published
2014-01-15
Updated

Applies to

  • Enterprise Manager: 3.1.1, 3.1.0, 3.0.0

Topic

You should consider using this procedure under the following conditions:

  • You want to upgrade an Enterprise Manager system or install a hotfix
  • The Enterprise Manager system is configured to use an external database for statistics data collection

Description

The Enterprise Manager system supports the use of an external database for storing statistics data collected from the devices it is monitoring. During an upgrade of the Enterprise Manager system, if the Enterprise Manager system is configured to use an external database, you may encounter known issues such as the one described in K12702: The Enterprise Manager system may not recognize an external database. You can prevent the Enterprise Manager from encountering the issue by configuring the Enterprise Manager to switch to internal database before an upgrade and reverting back to the external database when the upgrade is completed.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You must ensure the Enterprise Manager system has adequate storage space
  • You must have command line access to the Enterprise Manager system

Procedures

  • Performing a backup of the Enterprise Manager
  • Configuring the Enterprise Manager to switch from external to local database
  • Performing an upgrade of the Enterprise Manager
  • Configuring the Enterprise Manager to switch from local to external database

Performing a backup of the Enterprise Manager

Before you proceed with any configuration change, F5 recommends that you perform a backup of the Enterprise Manager system. To do so, perform the following procedure:

Impact of procedure: None.

  1. Log in to the command line
  2. Perform a backup by entering the following command:

    em-backup <path/to/filename>

    For example, to save a UCS archive of the Enterprise Manager system as myembackup.ucs in the /var/tmp directory, you would enter the following command:

    em-backup /var/tmp/myembackup.ucs

  3. Copy the UCS archive created in step 2 to a remote location. For example, you can secure copy to the /root/backup directory on a remote server with IP address 10.10.10.10 using the remote user root by entering the following command:

    scp /var/tmp/myembackup.ucs root@10.10.10.10:/root/backup

Configuring the Enterprise Manager to switch from external to local database

Before proceeding with an upgrade, you can configure the Enterprise Manager system to stop collecting statistics data from the devices and switch the external database to the local database. To do so, perform the following procedure:

Impact of procedure: The Enterprise Manager will temporarily cease to collect statistics data from the managed devices until the final procedure.

  1. Log in to the Configuration utility.
  2. Navigate to the Data Collection page.
    • For 3.0.0 and later, navigate to:

      Statistics > Managed Devices > Options > Data Collection
    • For 2.3.0, navigate to:

      Enterprise Management > Options > Statistics > Data Collection
    • For 2.2.0, navigate to:

      Enterprise Management > Statistics > Options > Data Collection
  3. From the Collect Statistics Data drop-down menu, select Disable.
  4. Click Save Changes.
  5. Navigate to the Data Storage page.
    • For 3.0.0 and later, navigate to:

      Statistics > Managed Devices > Options > Data Storage
    • For 2.3.0, navigate to:

      Enterprise Management > Options > Statistics > Data Storage
    • For 2.2.0, navigate to:

      Enterprise Management > Statistics > Options > Data Storage
  6. Select Local for Statistics Data Location.
  7. Click Save Changes.

Performing an upgrade of the Enterprise Manager

Proceed to perform the upgrade of the Enterprise Manager or install a hotfix to another slot.

Impact of procedure: The Enterprise Manager will not be able to manage devices temporary until the upgrade is completed successfully.

  • To upgrade the Enterprise Manager from version 2.2.0 to 2.3.0, refer to the To import and install the upgrade using the Software Upgrade wizard section of the Enterprise Manager version 2.3.0 release notes.
  • To install a hotfix, refer to the Copying and installing software to managed devices chapter of the Enterprise Manager Administrator Guide appropriate for your version.

Configuring the Enterprise Manager to switch from local to external database

When the upgrade or hotfix installation is completed successfully, you can configure the Enterprise Manager system to switch the local database to the external database and start collecting statistics data from the devices. To do so, perform the following procedure:

Impact of procedure: None.

  1. Log in to the Configuration utility.
  2. Navigate to the Data Storage page.
    • For 3.0.0 and later, navigate to:

      Statistics > Managed Devices > Options > Data Storage
    • For 2.3.0, navigate to:

      Enterprise Management > Options > Statistics > Data Storage
    • For 2.2.0, navigate to:

      Enterprise Management > Statistics > Options > Data Storage
  3. Select External for Statistics Data Location.
  4. Enter the connectivity details of the external database appropriate for your setup.
  5. Click Save Changes.
  6. Navigate to the Data Storage page.
    • For 3.0.0 and later, navigate to:

      Statistics > Managed Devices > Options > Data Storage
    • For 2.3.0, navigate to:

      Enterprise Management > Options > Statistics > Data Storage
    • For 2.2.0, navigate to:

      Enterprise Management > Statistics > Options > Data Storage
  7. From the Collect Statistics Data drop-down box, select Enable.
  8. Click Save Changes.
