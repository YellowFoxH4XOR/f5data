Known Issue

This is the result of a known issue. When the FirePass controller's internal intrusion detection features detect a possible attack from a logged-in user account, information about the attempt is sent to the System log. The information will also be emailed to the FirePass administrator if the Admin E-Mail feature and the FirePass's SMTP Server are both configured, under the Device Management menu.

If email is sent to the administrator, the text of the message omits the FirePass username and user's master group information. The following example email displays two spaces between the words account and from, where the username and master group information, in the form of user@group, should be included:

Possible intrusion attempt detected against account  from source IP address 192.168.162.86 for URI=[/vdesk/index.php3?Z=0%2C6](USER-AGENT changed.[Mozilla/5.0 (Windows; U; Windows NT 5.1; en-GB; rv:1.8.0.12) Gecko/20070508 Firefox/1.5.0.12->Mozilla/4.0 (compatible; MSIE 4.01; Windows CE; SHARP/WS003SH; PPC; 480x640)].

F5 Product Development tracked this issue as CR85478, and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Workaround

Locate the event on the Report: Systems Logs page for the user and group information.
