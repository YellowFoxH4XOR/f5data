Description

Environment

  • FIPS Platform
  • Standalone (non-HA)
  • RMA

Cause

  • UCS file with references to FIPS keys can only be restored by the same FIPS device that created it.
  • The UCS master key is unknown and can't be recovered. There is no backup for the certificate and keys.

Recommended Actions

A manual rebuild of the devices configuration and import of cert/keys would be required. 

Additional Information

During initialization of the FIPS card a unique SIM masterkey is generated which is different for every FIPS card / initialization. The SIM master key is the key to the kingdom when combined with a .ucs file providing access to ALL .ucs encrypted data as well as to FIPS key(s) residing within the .ucs backup file. In order to restore FIPS key(s) from a .exp file or UCS backup file, the original unique SIM masterkey used to create the FIPS .ucs file is required.
