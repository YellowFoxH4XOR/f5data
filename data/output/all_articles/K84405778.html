K84405778: 014d0056:3: <>:<sessionID>:Disabled the SSO for this request: oauth token is expired/revoked

Type
Support Solution
Published
2022-04-01
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM: 15.1.4
Source
https://my.f5.com/manage/s/article/K84405778

Description

This error message is seen when :

  • Oauth SSO is turned ON
  • BIG-IP receives a 401 or 407 response 
  • BIG-IP has sent a token
  • Oauth is set to "send token always"

Environment

  • BIG-IP APM
  • OAuth
  • SSO

Cause

The destination server got the token from the BIG-IP but sends a 401 or 407 response code.
This concludes that the server did not accept the token so BIG-IP will not use that anymore.

Recommended Actions

NA

Additional Information
There might be some situations when this log message will be seen in a per-session and not a per-request policy, which might lead to some confussion.
There is a request to get this log message fixed.
