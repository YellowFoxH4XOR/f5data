Description

  • You successfully configured and deployed Nginx Ingress Controller NGINXPLUS solution
  • You also configured cert manager to manage your certificates/secretes for your Kubernetes Cluster
  • Your Nginx ingress resource also is configured to reference secretes managed by Cert-manager
  • While all seems to be in working state, when checking for counter metrics in Grafana such: zone_requests, zone_recived, you noticed regular interval Nginx worker process reload as shown below
2022/01/25 08:31:00 [notice] 9363#9363: exiting
2022/01/25 08:31:00 [notice] 9363#9363: exit
2022/01/25 08:31:00 [notice] 16#16: signal 17 (SIGCHLD) received from 9363
2022/01/25 08:31:00 [notice] 16#16: worker process 9363 exited with code 0
2022/01/25 08:31:00 [notice] 16#16: signal 29 (SIGIO) received
  • In addition to the above logs, you also correlating reload of Nginx when checking metric: "nginx_ingress_controller_nginx_reloads_total"
  • When checking the event output for the specific namespace, you would also note there is corresponding certificate request and the issuing of new certificate, with equal frequency

kubectl get events -n <namespace>

default       31m     Normal  cert-manager.io   certificaterequest/demo-request-vgp7c              Certificate request has been approved by cert-manager.io
default       31m     Normal  CertificateIssued  certificaterequest/demo-request-vgp7c             Certificate fetched from issuer successfully
default       28m     Normal  cert-manager.io   certificaterequest/demo-request-vgp7c              Certificate request has been approved by cert-manager.io
default       28m     Normal  CertificateIssued  certificaterequest/demo-request-vgp7c             Certificate fetched from issuer successfully
default       22m     Normal  cert-manager.io   certificaterequest/demo-request-vgp7c              Certificate request has been approved by cert-manager.io
default       22m     Normal  CertificateIssued  certificaterequest/demo-request-vgp7c             Certificate fetched from issuer successfully

 Environment

  • Nginx Ingress controller
  • Cert-Manager
  • Ingress-resource

 Cause

  • Cert-manager is configured to renew certificate every five minutes

 Recommended Actions

  • increase the interval in which certificate is renewed for the given ingress resource

 Additional Information

  • Cert manager with Vault PKI was enabled for ingress resources and was set to generate new cert for every new ingress resource in Kubernetes cluster
  • Certificate rotation time set to 3 mins – so every time the secret/cert has changed the Nginx made a reload
