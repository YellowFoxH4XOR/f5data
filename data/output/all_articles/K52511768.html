Description

While going to Shared Objects  ››  Address Lists/Port Lists tab, using the Search, it does not provide you any results.

Environment
  • BIG-IP
  • Address Lists/Port Lists configured in Shared Objects
Cause

This issue is being tracked as ID 857897.

Recommended Actions
  • At this moment there is no fix for the issue. 
  • As a workaround, you can expand objects on the list before using Search - then the results will be accurate. 
Additional Information

This will happen only if you put in the Search IP address/Port number while not expanding the Object first.
