Description

A vCMP guest does not have a physical serial port from which to access its console. The vconsole utility is a telnet-based console access utility for the vCMP host to connect to its vCMP guest instance. To connect to a vCMP guest using the vconsole utility, you must first log in to the vCMP host's TMOS Shell (tmsh) or BIG-IP command prompt to run the vconsole command. After you connect, and if you manually resize the screen window, you may notice screen output will display unmatched file length and does not display the full resolution if you maximize the window size.

Environment

  • VIPRION system with vCMP guest provisioned

Cause

This is expected behavior because serial connections does not have a mechanism to transfer SIGWINCH. SIGWINCH is a signal sent upon the resizing of a window: when the number of columns or rows changes. 

Some screens (SSH, GNU) output have SIGWINCH enabled, when the signal arrives, it fetch the new screen size and reformat its display accordingly. However, serial connection by default does not have it.

Recommended Actions

You can workaround this behavior by following method.
  1. use vi to edit /root/.bashrc
  2. add a line before "# User specific aliases and functions"
    stty -F /dev/ttyS0 rows 1000 cols 1000
