Issue

Error Message

pvad[<pid>]: 01130003:6: No.3 regWait on STATUS bit 8 failed.
pvad[<pid>]: 01130003:6: PVA2 incoherency detected; synchronization required.
pvad[<pid>]: 01130003:6: three FE_TEST read result: 0x100, 0x7c0005c4, 0x4fc
pvad[<pid>]: 01130003:6: PVA2 synchronization complete

In this error message, note the following:

  • <pid> is the process ID of pvad on your host

For example:

pvad[2064]: 01130003:6: No.3 regWait on STATUS bit 8 failed.
pvad[2064]: 01130003:6: PVA2 incoherency detected; synchronization required.
pvad[2064]: 01130003:6: three FE_TEST read result: 0x100, 0x7c0005c4, 0x4fc
pvad[2064]: 01130003:6: PVA2 synchronization complete

Message Location

You may encounter this message in the following location:

  • /var/log/ltm

Description

These messages indicate that the PVA2 has detected an incoherency and corrected for it.  These messages may occur when both of the following conditions are met:

  • The device is a BIGIP 3400, 6400, or 6800
  • The BIG-IP system is under heavy traffic load

Impact

These error messages may be indicative of a PVA2 chip synchronization condition and the impact to the system should be minimal.

Recommended Actions

None
