Known Issue

This is the result of a known issue. Custom source address and destination address persistence profiles are supported on a standalone BIG-IP Link Controller system, and the system allows their creation without error. However, if you attempt to delete a custom source address or custom destination address persistence profile on a stand-alone BIG-IP Link Controller system, the profile is not deleted. As a result, the system logs an error message in the /var/log/ltm file that appears similar to the following example:

01070356:3: MSRDP persistence feature not licensed.

Note: Although the error message refers to the Microsoft Remote Desktop Protocol (MSRDP) persistence feature, the MSRDP persistence feature is not implemented in stand-alone BIG-IP Link Controller systems.

F5 Networks Product Development is tracking this issue as ID 337384.

Workaround

You can work around this issue by manually editing the bigip.conf configuration file to remove the custom profile. To do so, perform the following procedure:

Note: Before you begin, ensure the persistence profile you want to delete is not applied to any virtual server or referenced in an iRule.

  1. Log in to the BIG-IP Link Controller command line.
  2. Back up the configuration file by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.sol11928
  3. Open the /config/bigip.conf file for editing in a text editor.
  4. Locate the stanza defining the persistence profile you want to delete, and delete then entire stanza.
  5. Save the file and exit the editor.
  6. Reload the modified configuration by typing the following command:

    bigpipe load
