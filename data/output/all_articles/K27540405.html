Issue

Old Behavior

In versions prior to BIG-IP 13.0.0, the TMOS Shell (tmsh) does not have the ability to configure the RewriteDomain and FromLineOverride settings in the Secure Simple Mail Transfer Protocol (SSMTP) configuration. To do so, you can configure these two settings on the /etc/ssmtp/ssmtp.conf file directly. Additionally, the changes that are configured manually on the ssmtp.conf file is lost after the BIG-IP system restarts for the system running BIG-IP 11.5.0 through 12.x.

New Behavior

Beginning in BIG-IP 13.0.0, you can configure the RewriteDomain and FromLineOverride settings using tmsh. After you save the changes, they persist across restarts.

  • To configure the RewriteDomain setting, use the following command syntax:

    tmsh modify /sys outbound-smtp rewrite-domain <domain_name>

  • To configure the FromLineOverride setting, use the following command syntax:

    tmsh modify /sys outbound-smtp from-line-override <enabled|disabled>

F5 Product Development tracked this change as ID 465700.

Impact

None

Recommended Actions

  • In BIG-IP 13.0.0, the RewriteDomain setting is set to none by default. Due to a separate issue, you should not leave this setting in the default configuration. For more information, refer to K15188934: Emails generated by the BIG-IP system may fail after upgrading to 13.0.0.
  • The FromLineOverride setting is set to disabled by default. You can leave this setting in the default configuration, unless you have custom alerts configured in the /config/user_alert.conf file to send the email notifications using a non-default fromaddress parameter. The fromaddress parameter uses root as the default user.
