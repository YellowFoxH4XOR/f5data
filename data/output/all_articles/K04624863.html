K04624863: Force deleting BIG-IQ managed applications with AS3 will fail with pinned objects

Type

Published
2022-01-24
Updated
2026-08-10
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K04624863

Description

Attempting to delete a managed application on BIG-IQ may fail

  • AS3 is used to delete a managed application
  • Error code similar to /tenant/app-service/some_app_object is pinned to device managed_device_here

Environment

Relevant environmental factors specific to the topic

  • Using AS3 commands to make changes to managed applications
  • BIG-IQ CM 

Cause

An application cannot be deleted when they have objects that are pinned to certain devices.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. In the BIG-IQ GUI, go to    Configuration >>>>> Pinning Policies >>>>>>> Select the device in the error
  2. Check the box next to the object (from the error) in resource types and click on the "remove" box to remove the pinning.
