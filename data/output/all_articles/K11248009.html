K11248009: Using BIG-IP products and features to mitigate CVE-2022-22536

Type
Support Solution
Published
2022-02-21
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K11248009

Description

CVE-2022-22536 can be mitigated by BIG-IP products and features. Per CVE details, the delivery of the attack is thru HTTP request smuggling and would appear as a non RFC compliant HTTP request to the BIG-IP.

Environment

ASM is provisioned
LTM is provisioned

Cause

Security researchers released a tool to scan if a system is vulnerable to CVE-2022-22536

Recommended Actions

LTM:

Using a HTTP Profile on a Virtual Server fronting the application enforces HTTP protocol RFC compliance.
For BIG-IP SW versions beginning from 14.1.2.3, 13.1.3.4, 12.1.5.1, set the db variable tmm.http.rfc.enforcement value to "enable"  (reboot required, enforces HTTP RFC compliance for the whole BIG-IP system).
For 15.1.0 and later BIG-IP SW versions, Enable "Enforce RFC Compliance" in the HTTP profile
For information about these options, refer to K40413116

ASM:

A specific BIG-IP ASM/Adv WAF attack signature was released for CVE-2022-22536. Update your ASM/Adv WAF security policy and ensure attack signature 200020213 is included and enforced.

Attack Signature ID:
200020213		SAP NetWeaver request smugglingHTTP Parser AttackCVE-2022-22536
SAP NetWeaver and other SAP web products are vulnerable to request smuggling using concatenation

BIG-IP ASM security policy also have "HTTP protocol compliance failed" violations options which could detect non RFC compliant HTTP requests.
