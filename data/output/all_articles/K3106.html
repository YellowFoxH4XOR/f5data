Topic

The FirePass controller allows an administrator to configure time limits on user sessions. FirePass provides the following two types of session time limits, which are tracked by the FirePass controller with server-side components:
 
  • Inactivity Timeouts

    An Inactivity Timeout specifies the amount of time a user session can remain idle before FirePass displays a pop-up message. If the user does not respond to the pop-up message, FirePass logs the user out. Idleness is measured by the amount of network traffic received from the client by the FirePass controller.
     
  • Reauthentication Timeouts

    A Reauthentication Timeout specifies the maximum amount of time FirePass allows a user session to exist, regardless of user activity. When the Reauthentication Timeout expires, FirePass displays a pop-up message, prompting the user to save any unsaved work. FirePass then logs the user out.  The time at which a user is logged out is kept by the FirePass controller.

You can configure both types of session time limits globally and for specific groups.

Configuring Global inactivity and reauthentication timeouts

To configure global inactivity and reauthentication timeouts, perform the following procedure: 

  1. Log on to the FirePass Administrative Console.
  2. In the main navigation pane, select Device Management. In versions prior to 5.0, select Server.
  3. In the upper navigation pane, select Security.
  4. In the sub-menu, select Timeouts.
  5. Set the inactivity timeout to a value between three minutes and 72 hours, using the Global inactivity timeout drop-down menu.
  6. Set the reauthentication timeout to a value between 10 minutes and 72 hours, using the Global reauthentication timeout drop-down menu.

    Note: If you want to disable the Global reauthentication timeout, select do not use.

  7. Click the Update button.

Configuring group-specific inactivity and reauthentication timeouts

To configure group-specific inactivity and reauthentication timeouts, use the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. In the main navigation pane, select Device Management. In versions prior to 5.0, select Server.
  3. In the upper navigation pane, select Security.
  4. In the sub-menu, select Timeouts.
  5. In the For the group drop-down menu, select the group you want to configure.
  6. Set the inactivity timeout to a value between three minutes and 72 hours, using the Separate inactivity timeout drop-down menu.

    Note: If you want to disable the Separate inactivity timeout, select do not use.

  7. Set the reauthentication timeout to a value between 10 minutes and 72 hours, using the Separate reauthentication timeout drop-down menu.

    Note: If you want to disable the Separate reauthentication timeout, select do not use.

  8. Click the Update button.
