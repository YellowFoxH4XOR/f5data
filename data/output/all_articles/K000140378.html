K000140378: 502 httpd Proxy Error while deleting an F5OS-C ISO image via the REST API

Type
Support Solution
Published
2024-07-18
Updated
2024-07-19
Applies to

  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000140378

Description

When trying to delete an ISO image through a REST API request, if the command to delete the ISO image exceeds 1 minute to respond, the client will encounter a 502 Proxy Error from the VELOS REST interface.

$ curl -X POST -H "Content-Type: application/yang-data+json" -sku <user>:<passwd> https://x.x.x.x/api/data/f5-system-image:image/controller/remove -d '{ "f5-system-image:iso": "1.5.1-14085"}'

Environment

  • VELOS (F5OS-C 1.6.2)
  • REST API

Cause

This occurs because the default httpd timeout of 60 seconds has been reached, causing the VELOS internal proxy connection to time out. 

Recommended Actions

Ensure there is a strong network connection between the client initiating the connection and the VELOS system.
