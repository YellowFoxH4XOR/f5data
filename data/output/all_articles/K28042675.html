K28042675: BIG-IQ stopped showing device statistics and ASM events

Support Solution
Published
2022-01-18

Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0, 8.0.X, 8.1.0, 8.1.X, 8.2.0, 8.2.X, 8.3.0, 8.3.X, 8.X.X
Source
https://my.f5.com/manage/s/article/K28042675

Description

  • BIG-IQ CM stopped showing BIG-IP device statistics
  • No new ASM event logs are being logged or visible on BIG-IQ CM
  • An error message similar to the following can be seen on /var/log/appiq/configserver.log

    ERROR c.f.a.b.s.e.ElasticSearchBookKeeperService [scheduling-1] ElasticSearch bulk delete error. Checking cluster state.
    org.elasticsearch.ElasticsearchStatusException: Elasticsearch exception [type=cluster_block_exception, reason=blocked by: [FORBIDDEN/12/index read-only / allow delete (api)];]
    ...
        Suppressed: org.elasticsearch.client.ResponseException: method [DELETE], host [https://127.0.0.1:9200], URI [/book-keeper-end/meta-data/default_2488b74e-4505-4092-a79b-f1e660f2a3cf_10.227.252.159_tl0_http?timeout=1m], status line [HTTP/1.1 403 Forbidden]
    {"error":{"root_cause":[{"type":"cluster_block_exception","reason":"blocked by: [FORBIDDEN/12/index read-only / allow delete (api)];"}],"type":"cluster_block_exception","reason":"blocked by: [FORBIDDEN/12/index read-only / allow delete (api)];"},"status":403}

Environment

  • BIG-IQ CM
  • BIGIQ DCD
  • AVR analytics
  • BIG-IP device statistics
  • ASM event logs

Cause

K53943550: Setting log events retention on BIG-IQ
Bug ID 1055153

Recommended Actions

You may first need to stop any processes that is utilizing space in /var to prevent it from increasing whilst running the following steps.

  1. Free up disk space on /var or add more free space.
  2. Run the following command on the BIG-IQ CM or any BIG-IQ DCD (only needs to be run on one):

    for idx in $(curl -ks -u admin:admin https://localhost:9200/_cat/indices | awk '{print $3}'); do if [ $idx != ".opendistro_security" ]; then curl -k -u admin:admin -X PUT "https://localhost:9200/$(echo $(echo $idx | cut -d\+ -f1)*)/_settings?pretty" -H 'Content-Type: application/json' -d'{"index.blocks.read_only_allow_delete": false}'; fi; done

Note: The command may take 10 to 20 minutes to complete and will print a series of '"acknowledged" : true"' to the screen.
