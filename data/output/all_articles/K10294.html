K10294: Auto-launch now occurs when a user is assigned multiple Network Access favorites with auto-launch enabled

Type
Knowledge
Published
2009-07-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.0.3
Source
https://my.f5.com/manage/s/article/K10294

Topic

In FirePass versions 6.0.2 and earlier, when a user logged on to the webtop, FirePass would not automatically launch a Network Access favorite if the user was assigned multiple Network Access favorites with auto-launch enabled.

Starting in FirePass version 6.0.3 with cumulative HF-603-3, when a user logs on to the FirePass webtop, FirePass automatically launches the first Network Access favorite listed on the webtop that has auto-launch enabled.

Note: Auto-launch is enabled by selecting the Autolaunch based on endpoint protection check box on the Network Access: Resources page.
