Source
https://my.f5.com/manage/s/article/K55830000

Description

Users may not be able to access the graphical user interface(GUI) of the BIG-IP system after selecting Zone Runner.
httpd errros will be noticed under /var/log/httpd/httpd_errors showing following messages

err httpd[8585]: [error] ajp_read_header: ajp_ilink_receive failed
err httpd[8585]: [error] (120006)APR does not understand this error code:proxy: dialog to (null) (*) failed
err httpd[8184]: [error] ajp_read_header: ajp_ilink_receive failed
err httpd[8184]: [error] (120006)APR does not understand this error code:proxy: read response failed from (null)(*)
err httpd[8583]: [error] ajp_read_header: ajp_ilink_receive failed
 

Environment

  • BIG-IP GTM
  • BIG-IP DNS
  • 11.6.x, 12.x

Cause

Unknown at time of publication

Recommended Actions

Stop the following daemons and restart
  1. Stop zrd
    # tmsh stop /sys service zrd
  2. Stop named 
    # tmsh stop /sys service named
  3. Find the named process id and kill the process. 
    # ps -A | grep named 
    # kill -9 <process ID of named>
  4. Start the named
    # tmsh start /sys service named
  5. Start the 3rd 
    # tmsh start /sys service zrd

Additional Information
Restarting httpd and tomcat may restore GUI, however, this is a temporary fix.
