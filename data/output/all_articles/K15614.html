Known Issue

The policy_sync_d directory can grow to consume all available space on the /config file system.

This issue occurs when all of the following conditions are met:

  • BIG-IP APM systems are configured to synchronize access policies.
  • The access policies are synchronized multiple times.

After performing access policy synchronization, policy synchronization history files are generated to the /config/filestore/files_d/Common_d/policy_sync_d directory. The history files are not purged by the system and over time can accumulate and eventually consume all available space on the /config file system. This issue is exacerbated when hosted content files are associated with the access policy that is being synchronized.

Impact

System functionality is impaired and the system can no longer perform qkview and configsync operations due to lack of space on the /config file system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Access policy synchronization fails to complete.
  • Attempts to generate diagnostic data using the qkview utility fail to complete.
  • The ConfigSync process fails to complete.
  • The BIG-IP APM system becomes unstable or experiences impaired functionality.
  • Output from the df command shows the /config file system at or near 100 percent usage.

Workaround

While there is no workaround for this issue, you can restore system functionality by deleting psync-history objects and related data files to create more space in the /config file system. To do so, perform the following procedure:

Impact of workaround: The following procedure will remove all psync-history and related file objects from your local BIG-IP APM system. You will no longer have entries within the Sync History tab of your Access Policy Sync page of the BIG-IP APM Configuration utility.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Change to the PolicySyncHistory directory by typing the following command:

    cd /Common/PolicySyncHistory/

  3. Delete the psync-history and related objects by typing the following command:

    delete apm policy psync-history all

  4. Save the configuration changes to remove the psync references from the bigip.conf file by typing the following command:

    save /sys config partitions all
