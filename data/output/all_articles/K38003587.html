Description

On the GUI, Cluster Synchronization Status Displays "Error" for secondary slot(s).


Environment

  • LTM Configuration is synced between all slots
  • ASM configuration is synced between primary slot of the affect vCMP and the peer guest
  • Restarted 'asm_config_server', issue persists


Cause

Bug ID 912149


Recommended Actions

As in the case of vCMP guests running on multiple blade, the asm_config_server is required to be run on all slots.
if it is single blade or platfrom, then run
pkill -f asm_config_server
 
To restart asm_config_server on multiple blades (viprion), run the following command:
 
clsh pkill -f asm_config_server
