Description

VIPRION displays the following error message in the ltm logs.

goodbye from slot "x"

The slot number "x" represents which slot is having the issue.

Environment

  • BIG-IP VIPRION platforms.

Cause

This message is generated by the clusterd daemon on the remaining/observing blade(s) when a peer blade's clusterd process disconnects from the cluster. It indicates that slot "x" has left the cluster membership either gracefully (e.g., reboot, shutdown) or abruptly (e.g., crash, hardware failure, loss of backplane communication). It is the counterpart to Hello from slot "x", which is logged when a blade joins the cluster.

Recommended Actions

In a specific case, the message can be due to license expiration. When this happens, you can re-activate the license to resolve the issue.

Important: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.
