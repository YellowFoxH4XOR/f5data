K12482090: AS3 declaration failed with status of 422 Invalid data property

Type

Published

Updated
2025-04-01
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K12482090

Description

After modifying class properties for an AS3 template on a BIG-IQ system and publishing the changes, deploying an application using this template fails with the error message below:

AS3 declaration failed with status of 422 Invalid data property

Environment

  • BIG-IQ
  • AS3 templates
  • AS3 application deployment

Cause

After removing or adding a class from an AS3 template, the resulting JSON template gets a "Properties": {} field inserted into it, causing this error at runtime. This issue is being tracked as Bug ID 1003669.

Recommended Actions

To workaround the error, after making the changes to a template, before clicking Publish and Close navigate to the other properties of the template by selecting one of the buttons in the menu such as Properties.
