K2725: Reasons why 3-DNS may not provide path metrics for all objects in a data center

Topic

Starting in version 4.5, the 3-DNS Controller allows router objects in data centers, which means that the data center can have multiple links defined with separate metrics for each link.

Note: This feature was added to incorporate the Link Controller features into the 3-DNS Controller product.

Two common reasons that the 3-DNS Controller does not probe all of the hosts in the data center include the following:

  • If a host server is not in the same IP subnet as the router, then the 3-DNS Controller does not probe the hosts for metrics.
  • When BIG-IP Controllers are auto-configured in a data center, routers are added automatically.

To resolve this issue, remove the data center's router object and then disable auto-configuration for the BIG-IP systems.

Removing the router object from the data center

  1. From the navigation pane of the Configuration utility, click Data Centers.
  2. Select the data center.
  3. Locate the Router within the list and then click Remove next to it.

Disabling auto-configuration for all BIG-IP Controllers

  1. From the navigation pane of the Configuration utility, expand the Servers menu.
  2. Click BIG-IP.
  3. Select the BIG-IP name.
  4. From the Discovery menu, select OFF.
  5. Click Update.
  6. Repeat steps 3 through 5 for each BIG-IP system.

    The 3-DNS Controller should now probe all the hosts in the data centers.
