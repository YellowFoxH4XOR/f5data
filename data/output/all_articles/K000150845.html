Description

This article describes what determines the frequency of zone transfer for DNS Express Zone.


Environment

  • BIGIP DNS
  • DNS Express Zone

Cause

None


Recommended Actions

Zone transfer will occur based on 3 individual conditions:

  1. The refresh timer expiry for Zone is reached.
  2. Master DNS server sends Notify to DNS Express after zone update.
  3. DNS Express zone is disabled and re-enabled(*Trigger AXFR)

Additional Information

::Zone Configuration Example::


example.com.  IN  SOA  ns.example.com. hostmaster.example.com. (

               2003080800 ; sn = serial number

               172800   ; ref = refresh = 2d <-- refresh timer

               900    ; ret = update retry = 15m

               1209600  ; ex = expiry = 2w

               3600    ; nx = nxdomain ttl = 1h
