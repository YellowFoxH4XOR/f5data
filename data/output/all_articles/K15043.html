Topic

You can use this F5 supported iApp template to configure availability, encryption, security, proxy authentication, and remote access for Microsoft SharePoint 2010 and 2013 deployments. This template will help configure BIG-IP LTM, APM, AAM, ASM, and AFM for SharePoint deployments.

For instructions about using this template and configuring your SharePoint Server 2010 or 2013 environment, refer to the Deploying the BIG-IP System with Microsoft SharePoint Server 2010 and 2013 Deployment Guide.

To download and install the iApp template, perform the following procedures:

Downloading the iApp template

Installing the iApp template

Downloading the iApp template

Important: You must download the file; do not copy and paste the contents.

  1. Go to the F5 Downloads site.
  2. From the Downloads Overview page, click Find a Download.
  3. From the Product Line column, select iApp-Templates.
  4. Read the End User Software License Agreement and either accept the license by clicking I Accept, or cancel the process by clicking Cancel.

    If you accept the End User Software License Agreement, the Select a Download page appears, which shows a table with the file name, product description, and file size details.

    Note: After you accept the End User Software License Agreement, the system will not present the agreement again for subsequent downloads that you perform during the same browser session.

  5. From the Filename column of the table, select the file named iapps-x.x.x.x.x.zip. For example, the file for the July 2017 iApp release is named iapps-1.0.0.468.0.zip.
  6. F5 supports the FTP, HTTP, and HTTPS protocols for downloading files from F5. Select one of the three supported protocols listed by clicking the down arrow button.

    A pop-up window appears, prompting you to either open or save the file.

    Note: Some browsers save the file to a default location. You can review your specific browser's documentation to change the default location of where you want to save files.

  7. Select the option to save the file.

Installing the iApp template

  1. Unzip the zip file to a location accessible from your BIG-IP system.
  2. Log in to the BIG-IP Configuration utility.
  3. From the iApp tab, select Templates.
  4. Click Import.
  5. Select the Overwrite Existing Templates box.
  6. Click Browse.
  7. Browse to the location where you saved the iApp file.
  8. Select the file named f5.microsoft_sharepoint_2010_2013.vx.x.x that corresponds to the iApp version you want to install. For example, the file for the July 2017 release of this iApp is named f5.microsoft_sharepoint_2010_2013.v1.2.2.

    Note: Refer to the previously-listed Support Matrix to select the most current supported template for your BIG-IP software version.

  9. Click Upload.

When the upload completes, the iApp is available for use.

Revision History

f5.microsoft_sharepoint_2010_2013.v1.2.2

Features added

  • Added the ability to select custom BIG-IP ASM policies.

Issues resolved

  • Fixed an issue that would result in an error state when you try to deploy the iApp for BIG-IP ASM 12.1.0 and later.
  • Fixed an issue where the rechunk iRule was not created when the requirements were met in basic mode for SharePoint 2010.
  • Corrected an issue where a BIG-IP APM policy would not be applied after reconfiguring the iApp.
  • Corrected an issue where an error state would occur if you selected an AFM HTTP protocol security profile and also selected SSL pass-through.

Known issues

  • None at this time.

f5.microsoft_sharepoint_2010_2013.v1.2.1

Features added

  • Added the option of using an existing AAA server object when deploying BIG-IP APM.
  • Add the option of using an existing Access Profile when deploying BIG-IP APM.

Issues resolved

  • Removed the question in the iApp template for using a single Active Directory server. Now there is just a single question asking for the IP addresses and FQDNs of your Active Directory implementation.

Known issues

  • None at this time.

f5.microsoft_sharepoint_2010_2013.v1.1.0

Features added

  • The iApp template now supports the BIG-IP AFM system.
  • The iApp template allows you to select pre-existing Network Firewall policies and logging profiles.
  • The iApp template now supports the F5 IP Intelligence feature.
  • The iApp allows you to select pre-existing Application Security logging profiles.

Issues resolved

  • Streamlined the HTTP compression profile content-include list for better performance.

Known issues

  • None at this time.

f5.microsoft_sharepoint_2010_2013.v1.0.0

Features added

  • The iApp template now fully supports SharePoint 2013.
  • The iApp template now allows you to select pre-existing objects such as HTTP, compression, acceleration, SSL, persistence profiles, server pools, and health monitors.
  • The iApp template now allows you to add pre-existing iRules to the virtual server.
  • You can now choose authentication for HTTP/HTTPS monitors.
  • VLANs question now more closely matches BIG-IP conventions.
  • You can now use intermediate certificates.
  • Added the following new features specific to the BIG-IP APM system:
    • Built-in support for the BIG-IP APM system.
    • Logout URI is now configured for SharePoint 2010 and 2013.
    • Persistent cookies are enabled in the BIG-IP APM Access Profile.
    • Added monitor options for the AAA server pool.
    • You can now use smart card authentication.

Issues resolved

  • NTLM profile is now assigned to the SharePoint virtual server.
  • Removed the option to deploy the BIG-IP APM system with unencrypted traffic.
  • iApp template now automatically converts Kerberos realm name to uppercase.
  • Added iRule to rechunk compressed HTTP responses and OneConnect, and NTLM profiles are configured.
  • Added warning when the BIG-IP ASM module is not provisioned.
  • You can now use multiple host FQDNs.

Known issues

  • None
