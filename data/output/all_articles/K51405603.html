K51405603: BIG-IP VE logs on VMware messages of Bandwidth utilization exceeded on Active and Standby

Type
Support Solution
Published
2021-04-26
Updated
2025-04-01
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM: 13.1.1
Source
https://my.f5.com/manage/s/article/K51405603

Description

Bandwidth utilization is xxx, exceeded  xxx of Licensed 10000 Mbps 

  • Getting Bandwidth Utilization Exceeded Alarms on Active and Stand by
  • Getting Errors as "Bandwidth utilization is 8018 Mbps, exceeded 75% of Licensed 10000 Mbps"

Environment

Relevant environmental factors specific to the topic

  • BIG-IP v12.1.x and 13.1.x
  • BIG IP Virtual Edition on VMware
  • CPU is Normal 

Cause

When using VMware hypervisor, when promiscuous mode is turned ON on the VMWARE virtual switch, LTM logs/pegs all the packets (not destined for tmm VS's) against Bandwidth utilization on the License.)

Recommended Actions

If you are not using VLAN group and MAC masquerade, disable promiscuous mode on the BIG-IP and the VMWARE virtual Switch.

On the VMWARE Virtual Switch, configure a portgroup or virtual switch to  disable promiscuous mode:

  1. Log into the ESXi/ESX host or vCenter Server using the vSphere Client.
  2. Select the ESXi/ESX host in the inventory.
  3. Click the Configuration tab.
  4. In the Hardware section, click Networking.
  5. Click Properties of the virtual switch for which you want to enable promiscuous mode.
  6. Select the virtual switch or portgroup you wish to modify and click Edit.
  7. Click Security tab.
  8. From the Promiscuous Mode dropdown menu, click Disable
On the BIG-IP Disable as follows:
  1. Log into the Advanced Shell (bash) of the BIG-IP
  2. Disable promisc mode for all VLANs and NICs
    Note: Change vlanxxx and ethx to the VLAN name and NIC name you are modifying.
    # ip link set vlanxxx promisc off
    # ip link set ethx promisc off
    Note: May see no change in "ifconfig -a" output for it shows as disabled already.

Additional Information

To check if the promiscuous mode is turned ON or OFF

# ifconfig -a

 eth0             Link encap:Ethernet HWaddr 00:50:56:86:45:96
                     inet6 addr: fe80::250:56ff:fe86:4596/64 Scope:Link
                     UP BROADCAST RUNNING ALLMULTI MULTICAST MTU:1500 Metric:1 <<<<<<<<<<<<< OFF

# ip link set eth0 promisc on 
# ifconfig -a
