K31205156: Invalid command 'AuthPAM_ExpiredPasswordsSupport'

Type
Support Solution
Published
2020-04-15
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.1
Source
https://my.f5.com/manage/s/article/K31205156

Description
Configuration Utility is not accessible and when the httpd is restarted, a syntax error is shown.
# bigstart start httpd
   Syntax error on line 451 of /etc/httpd/conf/httpd.conf:
   Invalid command 'AuthPAM_ExpiredPasswordsSupport', perhaps misspelled or defined by a module not included in the server
   configuration
   Starting httpd: [FAILED]

Environment

  • HTTPD
  • mod_auth_pam
  • Configuration Utility (GUI) 


Cause
This is due to the incompatible mod_auth_pam package in iWorkflow.


Recommended Actions

Workaround: Reinstall the original package that came with the BIG-IP software.
  1. Mount the BIGIP image 
    # mount -o ro,loop /shared/images/BIGIP-13.1.1.4-0.0.4.iso /mnt
  2. Install the mod_auth_pam pakage
    # rpm -U --force /mnt/BIGIP*/i686/mod_auth_pam*
  3. Unmount the BIGIP image
    # umount /mnt
  4. Restart the HTTPD 
    # bigstart start httpd
