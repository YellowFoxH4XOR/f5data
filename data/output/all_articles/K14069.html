Known Issue

Description

Collecting capture diagnostic information using the ARX Manager GUI may fail to collect all capture files.

Impact

The ARX system will not gather all of the capture files that exist in the ARX system capture directory.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The diagnostic collect file will not contain all capture files on the ARX system.

Status

Workaround

To work around this issue, you can gather the capture files using the ARX CLI. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Create a configuration and diagnostics file and upload the file to the F5 Support FTP server using the following command syntax:

    collect capture ftp://<ftpid>:<ftppassword>@arxftp.f5.com/<File_Name>.tgz

    In this command, note the following:

    • Replace <ftpid> with the username you were issued for accessing the FTP server.

      Note: This is not the username used for accessing AskF5 or downloads resources.

    • Replace <ftppassword> with the password used for accessing the FTP server.

      Note: This is not the password used for accessing AskF5 or downloads resources.

    • Replace <File_Name> with the desired file name for your diagnostics file.

      Note: F5 Technical Support requests that you name the file with the ARX hostname, date, and description or case number.

    For example:

    collect capture ftp://johndoe:secret@arxftp.f5.com/ARXname_01222008_c123456.tgz

    The Collect diagnostic information? [yes/no] prompt displays.
  4. Type yes.

    Status messages that appear similar to the following example display until the command completes:

    Note: The diagnostics information file is actually transferred, even though the status messages indicate 0 MB transferred.

    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: Transferred 0 megabytes; still copying . . .
    % INFO: The copy command completed successfully.
