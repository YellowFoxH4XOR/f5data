Issue

Error Message

01531023:5: Scheduling zone transfer in <time> for <domain name>.com from <IP address>

In this error message, note the following:

  • <time> is the time, in seconds, until the next scheduled zone transfer.
  • <domain name> is the name of your domain.
  • <IP address> is the IP address of the remote master DNS nameserver.

For example:

01531023:5: Scheduling zone transfer in 1800s for example.com from 192.168.10.100.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You have configured a DNS Express zone on the BIG-IP system.

Note: Beginning in BIG-IP 11.3.0, the logging level for this message has changed from NOTICE to DEBUG.

Impact

None. The message is informational.

Recommended Actions

None
