Known Issue

SSL stream throughput may be slower when hardware SSL offloading is in use.

This issue occurs when all of the following conditions are met:

  • You have a virtual server configured to do hardware-based SSL offloading.
  • You are transferring very large files, greater than 100MB in size.

Impact

SSL clients will experience very slow transfer speeds.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You will notice a speed reduction of between 30% and 50% on large file transfers.

Workaround

To work around this issue, you can modify the High-Speed Bridge (HSB) scheduler. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Modifying the scheduler.hsbpollmode.ltm db key

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To set the db key value to always, type the following command:

    modify /sys db scheduler.hsbpollmode.ltm value always

  3. Save the changes by typing the following command:

    save /sys config
