Description

ASM events not visible in monitoring section

  • tcpdump on DCD devices and BIG-IP confirms traffic coming to DCDs
  • restjavad.logs reports incorrect formatting.

Environment

  • BIG-IQ Cluster
  • BIG-IP ASM
  • ASM Event Logging

Cause

Wrong configuration of security log profile

Wrong Logging format, it should be set as BIG-IQ

Recommended Actions

Change Logging Format in Security Log profile as in example

 

Additional Information

Configure Web Application Security logging
