Description

Failover occurred, and you can see similar to below log in /var/log/ltm: 

notice mcpd[<pid>]: 010719fb:5: HA Group <ha-pool-name> score updated from 40 to 30.
notice sod[<pid>]: 010c0045:5: Leaving active, group score 36 peer group score 40.
notice sod[<pid>]: 010c0052:5: Standby for traffic group /Common/<traffic_group_name>


Environment

  • BIG-IP
  • Failover
     

Cause

This indicates the HA Group feature is triggered due to score changed by the monitor object failures.
 

Recommended Actions

Please read for further details about HA group features: K16947: F5 recommended practices for the HA group feature


Additional Information

    HA groups
        With an HA group, the BIG-IP system monitors trunk, pool, or cluster health to create an HA health score for a device. You can configure the system to initiate failover whenever the health score falls below configurable levels.

    When this is configured, the following commands will show similar to below

     tmsh show sys ha-group
    ----------------------------
    Sys::HA Group: <ha_group_name>
    ----------------------------
    State         enabled   <<-----
    Active Bonus       20
    Score              10

    tmsh list sys ha-group all-properties
    sys ha-group <ha_group_name> {
        active-bonus 20
        app-service none
        clusters none
        description none
        enabled   <<-----
        pools {
            <pool_name> {
                app-service none
                attribute percent-up-members
                minimum-threshold 1
                percent-up 100
                sufficient-threshold all
                weight 10
            }
        }
        trunks none
    }
