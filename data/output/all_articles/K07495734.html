Issue

Error Message

err tmm[<PID>]: 01670019:3: DNAT configuration: <various state information>

In this error message, note the following:

  • <PID> is the process ID for the tmm process
  • <various state information> is the various state information used by the dnatutil utility to reverse map Large Scale NAT (LSN) translations.

For example:

err tmm[13678]: 01670019:3: DNAT configuration: cfg: dver=18 dname=p8dag dhsbs=2 dhash=6 dfold=0 dseed=0

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A carrier-grade network address translation (CGNAT) Deterministic NAT (DNAT) LSN Pool is configured and attached to an active virtual server. This log entry records the state information used by the dnatutil utility to reverse map LSN translations.

Impact

Log entries are for information only.

Recommended Actions

None
