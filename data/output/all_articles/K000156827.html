K000156827: How do I know if DNS cache is configured?

Type
Support Solution
Published
2025-10-06
Updated
2025-10-17
Applies to
  • BIG-IP
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K000156827

Description

You want to verify if DNS caching is configured on your system. DNS cache improves query response times by storing previously resolved records, but misconfiguration can lead to unexpected behavior.

Environment

  • BIG-IP systems configured for DNS services
  • Utilizing DNS profiles or caching settings
  • Recent modifications to DNS-related configuration

Cause

Not Applicable

Answer/Recommended Actions

  1. On the GUI, go to DNS >> Delivery >> Profiles  >> DNS Feature and locate if DNS Cache is enabled.

Additional Information

None
