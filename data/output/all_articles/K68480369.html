Description

You want to connect 2 Viprions directly (without passing from a switch/patch panel/ODF) using an OPT-0045-01 SFP.

Environment

  • HA Link
  • Direct link
  • Viprion
  • F5-UPG-QSFP+PSM4 (OPT-0045-01) - 40GBase-LR-PSM4 QSFP+ 4x10LR PSM4 40G Transceiver with DDM Support

Cause

OPT-0045-01 is 40GBase-LR-PSM4 QSFP+ 4x10LR PSM4 40G Transceiver with DDM Support. From K6097 we know the basic specifications, but the connector type could be misleading and could lead us to use the wrong cable and the interface never will turn UP

  • Laser emitter: 1310nm
  • Connector type: QSFP+
  • Operating distances and cable specification/requirements:
    • up to 10km

  • Supported platforms:

    • BIG-IP 10250, 10200, 10050, 10055, 10000, and 12250
    • VIPRION B2250
    • VIPRION B4450, B4450N
    • BIG-IP i5x00, i7x00, i10x00, i11x00, and i15x00 platforms
    • VELOS BX110 blades
    • F5 r5600, r5800, r5900, r10600, r10800, and r10900 platforms
When we use MTP/MPO connectors we should be aware of the type of cable that we need to use. There are 3 types of cable, A,B and C.

MTP Trunk Cable Type A: Type A cable, also known as straight cable, is a straight-through cable with a key-up MTP connector on one end and a key-down MTP connector on the opposite end. This makes the fibers at each end of the cable to have the same fiber position. For example, the fiber located at position 1 (P1) of the connector on one side will arrive at P1 at the other connector.

MTP Trunk Cable Type B: Type B cable (reversed cable) uses key-up connectors on both ends of the cable. This type of array mating results in an inversion, which means the fiber positions are reversed at each end. The fiber at P1 at one end is mated with fiber at P12 at the opposing end.

MTP Trunk Cable Type C: Type C cable (pairs flipped cable) looks like Type A cable with one key-up connector and one key-down connector on each side. However, in Type C each adjacent pair of fibers at one end are flipped at the other end. For example, the fiber at position 1 on one end is shifted to position 2 at the other end of the cable. The fiber at position 2 at one end is shifted to position 1 at the opposite end etc

Recommended Actions

When using a MTP/MPO connector, please use a type B  cable(reverse cable).
