Known Issue

This is the result of a known issue. The BIG-IP ASM Traffic Learning page allows you to click any violation type to open a screen where you can view details of the violation. When you use the BIG-IP ASM Traffic Learning page to view details of the modified domain cookie violation, the cookie value is missing.

The BIG-IP ASM Reporting page properly displays the cookie values for modified domain cookie violations.

F5 Product Development tracked this issue as CR91593 and it was fixed in BIG-IP ASM 10.0.0.  For information about upgrading, refer to the BIG-IP ASM Release Notes.
