Known Issue

This is the result of a known issue. The BIG-IP LTM system is inoperative and does not pass traffic if the syslog-ng utility fails to start. For example, if there are typographical errors in the syslog-ng.conf file and the BIG-IP LTM system is restarted, or the BIG-IP LTM services are restarted, the TMM process fails to start and the BIG-IP LTM system is inoperative.

F5 Product Development tracked this issue as CR76385 and it was fixed in BIG-IP LTM 9.1.3, 9.2.3, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

Important: This procedure must be performed from the command line, through the console (accessed through the serial terminal), or using SSH connected through the management interface.

Note: A typographical error in the syslog-ng.conf file is one reason that the syslog-ng utility may fail to start. There may be other reasons not covered in this solution.

To work around this issue, perform the following procedure:

  1. Log in to the BIG-IP LTM command line.
  2. Determine why the syslog-ng utility will not start, and correct the issue. For example, make sure there are no typographical errors or extra carriage returns in the file.
  3. Reboot the BIG-IP LTM system by typing the following command:

    reboot
