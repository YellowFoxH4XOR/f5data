K23044620: Not able to migrate managed BIG-IP on BIG-IQ device to Nutanix

Type
Support Solution
Published
2025-01-03
Updated
2025-04-01
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K23044620

Description

  • Trying to migrate existing managed devices(BIG-IP) on BIG-IQ to Nutanix. 
  • You may have successfully migrated several already; however, one or more device(s) is giving problems.
  • BIG-IP: GUI: shows "This BIG-IP system has encountered a configuration problem that may prevent the Configuration utility from functioning properly."
  • BIG-IP: CLI: prompt shows "NO LICENSE"
  • BIG-IP: tmsh load sys config verify    Result:  Loading configuration failed with below error.
  • 01070712:3: Failed: name (/Common/dtca-bundle.crt) Cache path (/config/filestore/files_d/Common_d/trust_certificate_d/:Common:dtca-bundle.crt_63010_4) does not exist and there is no copy in trash-bin to restore from.
    Unexpected Error: Loading configuration process failed

Environment

  • BIG-IQ on vmware with managed devices(BIG-IP) using Licensing pool on BIG-IQ
  • Migrating managed devices(BIG-IP) to Nutanix

Cause

  • BIG-IP: tmsh load sys config verify    Result:  Loading configuration failed with below error.
  • 01070712:3: Failed: name (/Common/dtca-bundle.crt) Cache path (/config/filestore/files_d/Common_d/trust_certificate_d/:Common:dtca-bundle.crt_63010_4) does not exist and there is no copy in trash-bin to restore from.
    Unexpected Error: Loading configuration process failed

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. K02091043: Error Message: The configuration has not yet loaded. If this message persists, it may indicate a configuration problem.
    https://my.f5.com/manage/s/article/K02091043
  2. K23934354: Cache path (/config/filestore/files_d/<Partition>_d/ifile_d/:<Partition>:<Filename>_<revision number>) does not exist and there is no copy in trash-bin to restore from.
    https://my.f5.com/manage/s/article/K23934354
  3. After correction is made on BIG-IP, add BIG-IP to the new BIG-IQ on Nutanix and license the BIG-IP. 

Additional Information

May encounter error when adding device on BIG-IQ:  The device 1.1.1.1 (null) is not a BIG-IP device

If so, use article:

K91302639: Error Message - Trust establishment failed; reason: The device <ip address>> (null) is not a BIG-IP device
https://my.f5.com/manage/s/article/K91302639
