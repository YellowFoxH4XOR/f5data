Known Issue

Under rare circumstances, the rewrite process may exit and produce a core file.

This issue occurs when the following condition is met:

  • The BIG-IP APM system is configured for portal access.

Impact

The BIG-IP APM system stops rewriting content temporarily while the rewrite process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system generates a rewrite process core file to the /shared/core directory.
  • Links in web application content are not rewritten before they are sent to the client.
  • Web applications that are accessed using portal access fail to render.
