K92230680: HTTP header names that include the ''_'' (ascii 95) character

Issue

Old Behavior

In BIG-IP ASM 11.4.1 – 11.5.3, the BIG-IP ASM system converts HTTP header names that contain the underscore character "_" (ascii 95) to the dash character "-" (ascii 45) in the response headers for the request logging profile and the blocking response page.

New Behavior

Beginning in BIG-IP ASM 11.5.4 and later, when the HTTP header names contain the underscore character “_” (ascii 95), the system retains the character in the unmodified state in the response headers for the request logging profile and the blocking response page.

Impact

When the system is performing external monitoring of the HTTP blocking response page, this may affect response headers, due to the fact that the HTTP header name "_" (ascii 95) character is no longer converted.

Recommended Actions

None
