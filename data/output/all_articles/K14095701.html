Known Issue

Single sign-on (SSO) fails with Citrix StoreFront integration.

This issue occurs when all of the following conditions are met:

  • Citrix StoreFront is configured in passthrough gateway authentication mode.
  • The user password contains the plus sign ( + ) character.

Impact

SSO authentication fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SSO authentication fails when the password contains the plus sign character.
