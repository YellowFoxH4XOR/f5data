K80487062: BIG-IP Azure failover CFE routes working from one system in a pair

Type
Support Solution
Published
2020-06-05
Updated
2025-02-07
Applies to
  • Public Cloud
  • BIG-IP
  • Microsoft Azure
Source
https://my.f5.com/manage/s/article/K80487062

Description
BIG-IP in Azure failover, but only one of the pair has functioning routes.

User Defined Routes (UDR) only working when one of the devices in the pair is Active.
/var/log/restnoded.log on failing device shows [f5-cloud-failover] No route operations to run.
 

Environment

  • Azure
  • BIG-IP VE
  • CFE

Cause
This is due to the BIG-IP not being able to reach the Azure API over the data plane interfaces. 

If you have a default route on an F5 BIG-IP in Microsoft's Azure cloud platform, management traffic will use that route. In some configurations, the data plane interfaces may not have access to the Azure API public IP addresses, which will break the F5 Cloud Failover Extension.
 

Recommended Actions

  • Configure the management route to reach the Azure API address. Here is an example of adding a route on the TMSH (tmos) shell:
    1. create sys management-route MSFT_<Azure IP address>_<netmask> gateway <gateway_IP> network <Azure IP Address>/<netmask>
      create sys management-route MSFT_x_x_x_x_28 gateway y.y.y.y network x.x.x.x/28

    2. save sys config
