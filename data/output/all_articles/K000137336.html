K000137336: Dashboard displays i2800 when device is an i2600

Type
Support Solution
Published
2024-01-22
Updated
2024-01-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000137336

Description

Dashboard of a BIG-IP i2600 is showing as i2800 even though the physical device is an i2600 and has an i2600 license.

Environment

  • BIG-IP i2600 platform

Cause

None

Recommended Actions

  • Switchboot to another other boot location. For more information refer to K93414734: How to set the default boot volume location.
  • If the issue still persists, perform a clean installation. For more information refer to K13117: Performing a clean installation of BIG-IP 11.x - 17.x.

Additional Information

None
