K000147593: How Do I Shorten/Mask a URI?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-22
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147593

Description

  • You need to have a shortened URI accessible and visible to a longer URI for your HTTP Load Balancer
  • Your application has a Long URI (/this/is/long/uri) and you want clients to access a shortened URI (/long) for this URI all while showing the shortened URI in the client's browser

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer

Answer/Recommended Actions

  1. Create a Simple Route on your HTTP Load Balancer
  2. Configure the Path Matching with the Short URI (/long in this example)
     
  3. On the Simple Route, go to Advanced Options, and select Edit Configuration
  4. Under the Request/Response Manipulation Section, Enable Prefix Rewrite and configure your Long URI (/this/is/long/uri in this example)
     
  5. Configure any other settings on the Simple Route your application requires (origin pool, etc)
  6. Apply the changes to the Route and Save your Load Balancer
  7. Now that the Simple Route has been configured, when you make a request to /long the Simple Route will send your request to the /this/is/long/uri on the Origin side all while displaying the short URI to the client's browser
