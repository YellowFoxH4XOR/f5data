K000141079: ASM adds trailing semicolon, making TS cookies non-RFC compliant

Type
Support Solution
Published
2024-09-16
Updated
2024-09-30
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.1.X, 17.1.1
Source
https://my.f5.com/manage/s/article/K000141079

Description

When ASM adds TS cookies on version 15.1.x or 16.1.x, the resulting cookie value is RFC compliant. For example:
Set-Cookie: TS01635345=01b5c01fa1b0b187ee7e5bb56678753045bdaca0b1eb754f17b2e19e66298e4a0a75a9dd37993b30ad855bd4bf07e57211860cb52d; Path=/

When ASM adds TS cookies on version 17.1.x, the resulting cookie value is NOT RFC compliant. For example:
Set-Cookie: TS01635345=013c0db32fddd42989047a0b6965b0f69c538c45cfeff1da7847b8eb4812f2e1426e4ab1c60d11c488867fc7b622206a38ee91f671; Path=/;

 

The addition of this trailing semicolon is not compliant with RFC6265 and it can lead to traffic disruption.

Environment

  • ASM provisioned
  • Virtual server has ASM policy applied that inserts TS cookie

Cause

Upon escalating to Product Engineering and reviewing the data, we can confirm that this is a product defect and opened a new bug ID1633133 to track this issue.

Recommended Actions

A potential workaround is to utilize an iRule such as the following:

when HTTP_RESPONSE_RELEASE {
    # Check if the response has a Set-Cookie header
    if {[HTTP::header exists "Set-Cookie"]} {
    
        set header_list [HTTP::header values "Set-Cookie"]
        
        HTTP::header remove "Set-Cookie"
        
        foreach cookie_header $header_list {
        
            # Use regex to remove the trailing semicolon
            set modified_cookie_header [regsub -all {;[\s]*$} $cookie_header ""]
        
            # Replace the Set-Cookie header with the modified one
            HTTP::header insert "Set-Cookie" $modified_cookie_header
            unset modified_cookie_header
        }
    }
}

Additional Information

The regsub tcl command: https://www.tcl.tk/man/tcl8.4/TclCmd/regsub.htm performs substitution based on regex pattern matching.
