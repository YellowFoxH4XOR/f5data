Description

You may see similar messages in the audit log:

device_name notice mcpd[5277]: 01070417:5: AUDIT - client Unknown, user Unknown - transaction #406958812-1 - object 0 - obj_delete_if { analytics_realtime_external_report { analytics_realtime_external_report_ext_publishing_id 647007320 } } [Status=Command OK]\\"
 

Environment

  • BIG-IP
  • AVR provisioned
  • accessing Dashboard in the GUI
 

Cause

Issue is caused by bug ID915473.
 

Recommended Actions

Log messages can be ignored, there is no negative impact and logging is the only inconvenience caused by this bug.
 

Additional Information

None.
