Description

You has created a new iRule on BIG-IP with the RULE_INIT event. After save it the iRule affects distribution of virtual servers the BIG-IP.

Environment

  • BIG-IP
  • iRule

Cause

RULE_INIT event included in iRule

Recommended Actions

The RULE_INIT event is global in scope and is triggered without the context of a virtual server or client to virtual server connection. So please read the official document RULE_INIT Event before using this event as its may affect configuration on the BIG-IP,
