K000139308: F5 Viprion FIPS System validation failed message shows up in console.

Type
Support Solution
Published

Updated
2025-04-09
Applies to

  • BIG-IP LTM: 17.1.0
Source

Description

F5 Viprion FIPS System validation failed message shows up in console.

The following message appears in /var/log/secure

BIG-IP Integrity Check: [ FAIL ] -- THE SYSTEM WILL HALT UPON REBOOT, CONTACT F5 NETWORKS FOR TECHNICAL SUPPORT

Environment

Big-IP with FIPS enabled.

Cause

FIPS validation failed

Recommended Actions

Because there are several issues which can lead to a FIPS validation error, please run the sys-eicheck utility on each blade to determine why the validation has failed.  Further information on this utility can be found here: 

K00029945: Using the sys-eicheck (FIPS) utility

If you need assistance determining how to resolve this, please contact support.

Additional Information

Important: If the sys-eicheck utility displays a fail status, the system does not boot to the current volume the next time it restarts. Therefore, you must resolve any fail issues before you restart the BIG-IP system. For troubleshooting information, refer to K11402545: Troubleshooting FIPS self-test failure
