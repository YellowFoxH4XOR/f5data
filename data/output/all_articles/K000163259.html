K000163259: BIG-IP HA Software Installation Job Permanently Stuck in DRAFT

Type
Support Solution
Published
2026-09-09
Updated
2026-09-09
Applies to
  • BIG-IP
  • F5 Insight: 1.2.1
Source
https://my.f5.com/manage/s/article/K000163259

Description

In F5 Insight 1.2.1, a BIG-IP HA Software Installation Job cannot be executed even though the readiness check passes.

Synopsis: The BIG-IP HA Software Installation Job readiness check passes, but the job fails to start and cannot proceed with the software installation or upgrade.

Symptoms:

The job remains in DRAFT status instead of transitioning to READY

Software installation / upgrade cannot start

Error messages:

job must be in READY status to activate (current: DRAFT)

 

Environment

F5 Insight version 1.2.1

BIG-IP HA devices managed through F5 Insight

BIG-IP onboarded using an FQDN endpoint or a Self IP

 

Cause

This is ID2452569, which is fixed in v1.2.2

 

Answer/Recommended Actions

Add the BIG-IP using its Management IP

 

Additional Information

None.
