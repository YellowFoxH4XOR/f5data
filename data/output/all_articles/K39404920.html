Description

The guest status changes to "waiting" with the banner (hovering the mouse over the guest status icon) when set to deploy after host's reboot. For example:

"Slot Id X: waiting for HotFix ISO image to become available- BIGIP-12.1.1.0.0.184.iso"

The guest Software release is actually 14.1.3.1-0.0.8 and not 12.1.1.0.0.184

Environment

  • vCMP Guest
  • Adding another blade to the Guest's existing configuration (expanding the Guest resources), or host has been upgraded and original Guests' OS version has been removed and the required images don't exist anymore in Host's /shared/images directory.

Cause

"Initial Image" was set to a different software version than the current one, in this case BIGIP-12.1.1.0.0.184.iso, "Initial Hotfix" was also set to Hotfix-BIGIP-12.1.1.1.14.196-HF1-ENG.iso in the Host's configuration of Guest.

Recommended Actions

The best way to fix this is to upload the iso that it is looking for in the initial image setting to the vCMP host under the /shared/images folder via the command line or upload it to the images section of the GUI.

If not possible (original ISO file is no longer available), follow this procedure:

  1. Bring the affected Guest(s) to the configured state
  2. In the setting "initial image" in the bigip.conf, replace "BIGIP-12.1.1.0.0.184.iso" with "BIGIP-14.1.3.1-0.0.8.iso" and remove the image listed in the "Initial Hotfix" setting
  3. Same procedure can be done via vCMP Guest configuration in host's GUI.
  4. Deploy the modified vCMP guests
  5. Correct any possible configuration error if necessary, due to OS versions' code changes. For example, upgrades from version 12.x or 13.x to 14.x.

Additional Information

You cannot upgrade directly from software versions that are more than two major versions behind the planned target version. For example, to upgrade from BIG-IP 14.x to 17.x, you would have to first upgrade from 14.x to at least 15.x, and then perform another upgrade from 15.x to 17.x. For more information about supported upgrade paths, refer to K13845: Overview of supported BIG-IP upgrade paths and an upgrade planning reference
