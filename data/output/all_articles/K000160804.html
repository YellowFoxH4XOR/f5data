K000160804: Virtual Server or Virtual Address not responding to ping

Type
Support Solution
Published
2026-04-15
Updated
2026-04-15
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000160804

Description

When trying to ping a virtual server from a NETWORK that is not defined in the VLAN assigned to the Virtual Server, ICMP fails. Traffic might come from the gateway that is actually assigned to the VLAN in the Virtual Server, but if the network is different it will fail.


 

Environment

Virtual Address

Existent Virtual Server with previous Virtual Address

ICMP ping


 

Cause

Expected


 

Answer/Recommended Actions

If a VLAN in that network segment doesn't exist, create it and assign it to the Virtual Server (Note: If the option to add all vlans and tunnels is already in place, just create the vlan)

If the VLAN exist, assign it to the VLAN

None
