K000148813: Active Mode FTP downloads through FTP-enabled virtual server stall for 1 hour

Type
Support Solution
Published
2026-08-26
Updated
2026-08-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148813

Description

Active Mode FTP downloads through the FTP-enabled virtual server appear to hang for 1 hour before finally completing. (The actual transfer of the file-related data packets finished within 2-3 seconds, however).


Environment

BIG-IP LTM

FTP profile


Cause

Bug ID 1620897: Flow will abruptly get dropped if &quot;PVA Offload Initial Priority&quot; is set to High/Low


Recommended Actions

Enable the "Inherit Parent Profile" option in your FTP profile


Additional Information

none
