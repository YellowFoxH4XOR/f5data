Known Issue

The Configuration utility may not display the persistence profile for BIG-IP iSeries platforms and Virtual Edition (VE).

This issue occurs when the following condition is met:

  • Your BIG-IP system is one of the following:
    • BIG-IP APM Standalone iSeries i2600/i2800
    • BIG-IP APM Standalone iSeries i4600/i4800
    • BIG-IP APM Standalone iSeries i5600/i5800
    • BIG-IP APM Standalone iSeries i7600/i7800
    • BIG-IP APM Standalone iSeries i10600/i10800
    • BIG-IP APM Standalone iSeries i11600/i11800
    • BIG-IP APM Standalone iSeries i15600/i15800
    • BIG-IP APM Standalone VE

Impact

Users cannot configure the persistence profile from the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The persistence profile is missing from the Configuration utility’s Profiles page.
  • The license file does not contain the ltm_persist keyword, and the tmsh show sys license detail | grep ltm_persist command fails to return information.

Resolution

Status

F5 Product Development has assigned ID 707007 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can reactivate the system license. To do so, perform the following procedure:

Impact of workaround: The license reactivation process may reload the configuration and temporarily interrupt traffic processing.

Note: You must log in with the administrator account to relicense the system. For more information, refer to K9965: The admin user account must be used to license the system.

  1. Log in to the Configuration utility.
  2. Navigate to System > License > Reactivate.
  3. Select Automatic or Manual as the activation method.

    Note: If your system does not have Internet access, you must select Manual.

  4. Click Next and follow the on-screen instructions. For more information about automatic or manual license activation, refer to K7752: Licensing the BIG-IP system.
