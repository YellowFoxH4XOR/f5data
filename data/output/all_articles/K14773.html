Known Issue

FirePass Network Access tunnels may fail to start.

This issue occurs when all of the following conditions are met:

  • The user is accessing the FirePass controller from a device that is running the Mac OS X operating system.
  • The user's Mac OS X operating system uses a default language other than English.
  • The FirePass controller has been configured with a Network Access resource.
  • The Network Access resource Launch Application feature is configured.

Impact

The Network Access tunnel fails to start.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users are unable to successfully start a Network Access tunnel.
  • Users encounter the following message when the Network Access resource (tunnel) fails to start:

    Connection dropped
