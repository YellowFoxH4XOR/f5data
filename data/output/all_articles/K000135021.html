K000135021: ssmtp Does Not Work from crontab

Type
Support Solution
Published
2023-06-13
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135021

Description

  • ssmtp used in a bash script and run from cron does not send expected mail

Environment

  • BIG-IP version 15.x or above

Cause

ssmtp not in environment path of cron

 Recommended Actions

  1. Type 'crontab -e' at the bash command prompt.
  2. Add the path to ssmtp command in cron environment. This line must be at the top of the crontab file.
PATH=/sbin:/bin:/usr/sbin:/usr/bin

 

Additional Information

None.
