K15043439: BIG-IQ License Manager pool license held by BIG-IP that has been deleted

Type
Support Solution
Published
2022-11-04
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K15043439

Description
When a license from a BIG-IQ license manager has been given to a BIG-IP, and that device has been deleted, the BIG-IQ cannot recover the license from the BIG-IP system
Attempting to remove services and deleting from the CM GUI does not work.

Environment

  • BIG-IQ License Manager
  • BIG-IP with a utility/pool license that has been deleted

Cause
BIG-IP VE systems were deleted before the ELA license had been revoked and now the reactivate button on BIG-IQ is greyed out when the device is selected

Recommended Actions

  1. The steps to revoke the license : K84120003: Remove license from BIG-IQ using restcurl
The command will be similar to 
# restcurl /cm/device/licensing/pool/utility/licenses/7aeae407-0b11-4f48-be84-153d1fadb7a5/members/474566bf-cffe-45f4-a016-84720050d448 -X DELETE -d '{"username":"admin","password":"adminpassword","id":"474566bf-cffe-45f4-a016-84720050d448"}'
  1. If that fails, recreate the missing BIG-IP using the same hostname and management IP address, along with default username and password.
Then perform the restcurl command above. This workaround may resolve issues where the username and password for the deleted BIG-IP are no longer known.
