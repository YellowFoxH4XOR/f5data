Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator leaks memory if the <base> tag appears in an HTML document. When the BIG-IP WebAccelerator parses the <base> tag, the PezParser does not properly release a memory location, resulting in a memory leak of 776 bytes.

F5 Product Development tracked this issue as CR132610 and it was fixed in BIG-IP WebAccelerator version 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-378.0-HF3 issued for BIG-IP WebAccelerator version 10.0.1, in Hotfix-BIGIP-9.4.8-379.3-HF1 issued for version 9.4.8, and in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0.  You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
