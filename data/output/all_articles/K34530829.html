Description

You want to convert your pool from using IP addresses to identify pool members to using Fully Qualified Domain Names.

Environment

  • BIG-IP LTM
  • Local Traffic Pools
  • FQDN Nodes

Cause

You want to automatically populate node and pool member lists by using a fully qualified domain name (FQDN).

Recommended Actions

  1. Create a new pool 
    • Note that the address family may only be picked when creating a pool. To mitigate DNS issues for critical pools, one or more pool members should be of the traditional IP address format.
  2. In the Address setting, select FQDN, and then type the host name in the field
  3. Add a monitor
  4. Once you verify the pool is marked Available, modify your virtual server to point to this new pool
    Impact: The process of creating a new pool and selecting it minimizes the risk of traffic disruption and should not interfere with existing connections.
