Description

When modifying pool members, you may see the following error message:

0107003a:3: Pool member node (/Common/<IP_address>) and existing node (/Common/<Node>) cannot use the same IP Address (<IP_address>)

In this error message, note the following:
<IP_address> is the IP address of the node.
<Node> is the name of the existing node.

For example:

0107003a:3: Pool member node (/Common/10.0.0.1) and existing node (/Common/node_001) cannot use the same IP Address (10.0.0.1)

Environment

  • BIG-IP
  • iApp
  • Nodes 
  • Pools

Cause

This error occurs when the BIG-IP system attempts to add a pool member node object for an IP address that is already defined as a pool member.
This issue is often encountered when deploying an iApp that does not provide a node selection option to specify pool members.


Recommended Actions


When creating a new pool member select the "Node List" option in the "New Members" section and select the existing node.
