K000136004: Ad Query Fails "generic failure: GSSAPI Error: Unspecified GSS failure. Minor code may provide more information (Message stream modified) (-2)"

Type
Support Solution
Published
2023-08-29
Updated
2023-08-29
Source
https://my.f5.com/manage/s/article/K000136004

Description

AD Query failed sometimes and End user could not login

apm logs shows 

Ad Query Fails "generic failure: GSSAPI Error: Unspecified GSS failure. Minor code may provide more information (Message stream modified) (-2)"
 

Environment

AD Auth
 

Cause

AD Auth configuration did not have Admin credentials set on it

 

 

Recommended Actions

Enter the Administrator username and password (required for AD Query)

 

Additional Information

 

/var/log/apm

 

you see below errors

 

AD module: query with '(sAMAccountName=jon)' failed: Local error, SASL(-1): generic failure: GSSAPI Error: Unspecified GSS failure. Minor code may provide more information (Message stream modified) (-2)
