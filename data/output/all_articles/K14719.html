Known Issue

You may be unable to provision the BIG-IP AAM system on the Amazon Web Services (AWS) platform.

This issue occurs when all of the following conditions are met:

  • You are using the AWS hypervisor with an instance of BIG-IP Virtual Edition.
  • Your license includes the BIG-IP AAM system.
  • The string mod_am does not appear in the /config/bigip.license file.

Impact

You are unable to provision the BIG-IP AAM system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP AAM system does not appear in the Provisioning page of the BIG-IP Configuration utility.

Workaround

To work around this issue, re-activate your license. To do so, perform the following procedure:

Impact of workaround: The BIG-IP System is temporarily unable to pass traffic.

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to System > License.
  3. Click the Re-activate button.
  4. Select the method of activation, then click Next.
  5. When the re-licensing is complete, click Continue.

For more information on the re-licensing process, refer to K7752: Licensing the BIG-IP system.
