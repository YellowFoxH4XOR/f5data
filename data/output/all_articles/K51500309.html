Description

There currently is no configured limit to the number of virtual servers that can be created or configured on the BIG-IP. 

Environment

  • BIP-IP
  • Virtual Server

Cause

The number of Virtual Servers is not limited at a configuration level, however, it is limited to the amount of memory of the device or VE. The Virtual Server limitations will also vary depending on the type of virtual server they are, iRule, other objects configured on the unit and amount of connection/traffic.

Recommended Actions

None. 

Note: F5 Support does not design or configure iRules, external monitors, deployment, optimization.  If you are in need of any assistance configuring an iRule to best work for your environment, F5 Professional Services can assist.

Additional Information

Depending on the hardware, or the resources assigned to a virtual edition, you could potentially experience performance degradation with an extremely large number of virtual servers.
