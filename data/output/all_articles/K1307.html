Topic

You can disable web aggregation to troubleshoot or work around specific issues.

F5 does not recommend disabling web aggregation, as it results in unnecessary traffic between BIG-IP and its nodes. If you must disable web aggregation, it is important that you re-enable it as soon as you resolve your issue.

To disable web aggregation, perform the following procedure:

  1. Log in to the command line.
  2. Type the following command:

    bigpipe global web aggregate none

  3. Configure the timeout for web aggregation, by typing the following command:

    bigpipe global web aggregate timeout <value>

    For example:

    bigpipe global web aggregate timeout 1005

    Note: This step is required, because BIG-IP still uses the web aggregate timeout for all delayed binding connections, even though they are not aggregated.

  4. Save the configuration, by typing the following command:

    bigpipe save
