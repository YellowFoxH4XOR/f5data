K000134465: Hard disk numbering changes when HD1 is removed from array

Type
Support Solution
Published
2023-05-04
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000134465

Description

When we have multiple disks in array and HD1 is removed physically the HD2 disk changes to HD1 instead.


Environment

  • BIG-IP
  • RAID array
  • Disk replacement

Cause

Expected Behavior.


 Recommended Actions

Below are the events that occur when HD1 is removed and added back:


1) Running "tmsh show sys raid" shows WD-WXB1E92YJF81 is HD2


[root@B10200-R67-S14:Active:Standalone] config # tmsh show sys raid

---------------------

Sys::Raid::Array: MD1

---------------------

Size (MB) 931.5K

---------------------------------------------------------

Sys::Raid::ArrayMembers

Bay ID Serial Number  Name Array Member Array Status

---------------------------------------------------------

1    WD-WXB1E92YJF81 HD2  yes      ok

2    WD-WXB1E92LEX33 HD1  yes      ok


2) After removing HD1 physically , WD-WXB1E92YJF81 becomes HD1


[root@B10200-R67-S14:Active:Standalone] config # tmsh show sys raid

---------------------

Sys::Raid::Array: MD1

---------------------

Size (MB) 931.5K

---------------------------------------------------------

Sys::Raid::ArrayMembers

Bay ID Serial Number   Name Array Member Array Status

---------------------------------------------------------

1      WD-WXB1E92YJF81 HD1  yes          ok

 

3) Put back the original HD1 in the rack


[root@B10200-R67-S14:Active:Standalone] config # tmsh show sys raid

---------------------

Sys::Raid::Array: MD1

---------------------

Size (MB) 931.5K

---------------------------------------------------------

Sys::Raid::ArrayMembers

Bay ID Serial Number   Name Array Member Array Status

---------------------------------------------------------

2      WD-WXB1E92LEX33 HD2  yes          testing    --> originally HD1 becomes HD2 initially !

1      WD-WXB1E92YJF81 HD1  yes          ok


4) Original HD1 stays HD2 after reseating


[root@B10200-R67-S14:Active:Standalone] config # tmsh show sys raid

---------------------

Sys::Raid::Array: MD1

---------------------

Size (MB) 931.5K

---------------------------------------------------------

Sys::Raid::ArrayMembers

Bay ID Serial Number   Name Array Member Array Status

---------------------------------------------------------

2      WD-WXB1E92LEX33 HD2  yes          ok

1      WD-WXB1E92YJF81 HD1  yes          ok


5) After reboot , it goes back to original disk numbering :


[root@B10200-R67-S14:Active:Standalone] config # tmsh show sys raid

---------------------

Sys::Raid::Array: MD1

---------------------

Size (MB) 931.5K 

---------------------------------------------------------

Sys::Raid::ArrayMembers

Bay ID Serial Number   Name Array Member Array Status

---------------------------------------------------------

1      WD-WXB1E92YJF81 HD2  yes          ok

2      WD-WXB1E92LEX33 HD1  yes          ok
