K000138376: Using ADFS Proxy against ADFS 2022 backend shows eventid 276 regularly

Type
Support Solution
Published
2026-03-05
Updated
2026-03-05
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000138376

Description

The AD FS 2022 server has a error 276 in the server logs when accessed via APM.

 

Environment

BIGIP APM

ADFS 2022

Cause

ADFS 2022 does not like TLS 1.3

Recommended Actions

Enable "No TLS1.3" in the server side SSL profile.

Additional Information

None.
