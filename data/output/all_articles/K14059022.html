Description

Some LSAs might be dropped with the log message similar to:

"LSA[%s]: LSA is received recently"

This happens even when OSPF timers are tuned. 

Environment

  • BIG-IP 13.x, 14.x, 15.x, 16.x
  • ZebOS
  • OSPF

Cause
OSPF min LSA arrival is hardcoded in some places. Timer value change does not affect the operations.
This is Bug ID 1064753: OSPF LSAs are dropped/rate limited incorrectly

Recommended Actions

Open Support ticket for requesting EHF:
K2633: Instructions for submitting a support case to F5
