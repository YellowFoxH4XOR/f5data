Description

You want to setup a scheduled task to mark a node down for a few hours and up.
 

Environment

  • BIG-IP
  • any version
  • Scheduled task
     

Cause

n/a

Recommended Actions

There is no build-in function.
You can use script or cron utility: K03108954: Overview of the cron utility on the BIG-IP system


To mark administratively down:
Node: tmsh modify ltm node <nodename> state user-down
Pool member:  tmsh modify ltm pool <pool_name> modify { <node_name>:<port> { state user-down } }

To mark administratively up  :
Node: tmsh modify ltm node <nodename> state user-up
Pool member:  tmsh modify ltm pool <pool_name> modify { <node_name>:<port> { state user-up } }
