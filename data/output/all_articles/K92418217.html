K92418217: DNS Express not responding to zone transfer requests correctly

Type
Support Solution
Published
2020-10-09
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP DNS: 15.1.X, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.8, 15.1.1, 15.1.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K92418217

Description
DNS Express is configured to answer zone transfer requests from specified clients, but when a zone transfer request is initiated DNS Express is not returning a copy of the requested zone file. It may return a copy of DNS root top-level-domains servers instead.
 

$ dig AXFR mydomain.com. @10.1.1.53
; <<>> DiG 9.11.4-P2-RedHat-9.11.4-16.P2.el7_8.6 <<>> AXFR mydomain.com. @10.1.1.53
;; global options: +cmd
com.                    163128  IN      NS      l.gtld-servers.net.
com.                    163128  IN      NS      c.gtld-servers.net.
com.                    163128  IN      NS      j.gtld-servers.net.
[snipped]

Environment

  • BIG-IP DNS
  • DNS Express

Cause
DNS profile in the Listener needs to have option "Zone Transfer" enabled. It is disabled by default.

Recommended Actions

Modify existing DNS profile to allow zone transfers.

  1. On the Main tab, click DNS > Delivery > Profiles > DNS select DNS profile

  2. From the DNS Traffic section, go to Zone Transfer option and select Enabled

  3. Click Update.
