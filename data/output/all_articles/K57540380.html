Known Issue

The mcpd process may exit and restart when performing an incremental ConfigSync on the BIG-IP APM system.

This issue occurs when all of the following conditions are met:

  • You manually edit the /config/bigip.conf file by removing an access policy item that calls a macro and adding the item to another access policy.
  • You then load the modified configuration into the running configuration.
  • You delete the original access policy before attempting to perform an incremental ConfigSync manually.

Impact

During the ConfigSync operation, the destination BIG-IP APM system may temporarily fail to process traffic while the mcpd process restarts and fails over if configured as part of a high availability (HA) system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates an mcpd core file to the /shared/core directory.
  • A failover event may occur if you configure the system for HA.

Workaround

To mitigate this issue, after editing and saving the changes to the /config/bigip.conf file, complete the ConfigSync operation before attempting to delete the original access policy.
