Topic

Beginning in BIG-IP WebAccelerator version 10.2.0, the BIG-IP WebAccelerator allows you to specify external hosts that serve Edge Side Includes (ESI) content and forward ESI content from the external host to the client, when requested.

Prior to WebAccelerator version 10.2.0, all ESI content must be served from the default BIG-IP WebAccelerator pool when the base page is requested through the BIG-IP WebAccelerator. If the base page is requested through the BIG-IP WebAccelerator and ESI includes information to obtain dynamic content from an external host, the BIG-IP WebAccelerator will respond with an HTTP 404 error in the section of the page in which content resides on an external host since the WebAccelerator always constructs the inline proxy request using the default pool member's IP address as the host.

F5 Product Development tracked this enhancement request to include the ability of specifying external hosts for use with ESI content as ID 242544 (formerly CR134226) and the feature was added in BIG-IP WebAccelerator version 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release note.

In addition to upgrading to BIG-IP WebAccelerator version 10.2.0, you must configure the BIG-IP WebAccelerator Application to include the external host as a Requested Host and ensure the external host is reachable from the BIG-IP WebAccelerator. To configure the BIG-IP WebAccelerator application to include the external host, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to WebAccelerator >> Applications.
  3. Click the name of the Application associated with the effected WebAccelerator Virtual Server.
  4. Click the Add Host button under the Hosts section.
  5. Type in the IP address or the Fully Qualified Domain Name (FQDN) of the external host in the blank text box under the Requested Host section.

    Note: If you use FQDN for the external host, you must configure DNS name resolution on the BIG-IP WebAccelerator. For information on configuring DNS name resolution on BIG-IP WebAccelerator version 9.4.0 through 9.4.1, refer to K3624: Configuring DNS name resolution. For information on configuring DNS name resolution on BIG-IP WebAccelerator version 9.4.2 and later, refer to K8437: Configuring DNS name resolution for BIG-IP version 9.4.2 and later

  6. Click the Save button to save and make the modification.
