Known Issue

The BIG-IP APM system may incorrectly rewrite JavaScript that contains assignment operators.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access with JavaScript patching enabled.
  • One of the following JavaScript assignment operators is used:

    "-=", "*=", "/=", "%="

  • The result of the operation is assigned to an index expression ("a[i]") or a dot expression ("a.value")
  • The JavaScript assignment operators appear within an eval statement or are generated by the write() or writeln() functions.

For example, the BIG-IP APM system may not properly evaluate the following statement:

eval ( "a[i] -= b; o.value-=b;" );

Impact

JavaScript code containing the listed assignment operators may not function properly.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Applications that rely on JavaScript assignment operators malfunction when they use portal access.
  • Portions of the web application fail to load when they use portal access, but load successfully when they access the application directly.

Workaround

To work around this issue, you can replace the problematic arithmetic assignment operators in your JavaScript code with pairs of simple operators. For example, you can replace the expression "a[i] -= b" with the following expression: "a[i] = a[i] - b".
