K9570: Users are prompted to add the FirePass controller as a trusted site during the pre-logon sequence

Issue

Due to the security level and security settings configured on a Windows client system, some applications may not work properly through the FirePass controller unless the FirePass URL is added as a trusted site.

Starting in FirePass 6.0.3, when a user accesses a pre-logon sequence, FirePass consults the Internet Explorer (IE) Trusted Sites list to determine whether the FirePass URL is a trusted site. If it is not a trusted site, FirePass displays a pop-up window with the following three options:

  • Add this site to your Trusted Sites list, and always allow inspection from this site
  • Allow this site to inspect your system for this session only
  • Do not allow this site to inspect your system, and do not connect to this site

If a user selects the first option, the URL of the FirePass controller is permanently added to the IE Trusted Sites list, and the user will not receive the Trusted Sites pop-up window during future connections to the FirePass controller.

Note: The Trusted Sites pop-up window only displays when you enable a pre-logon sequence on the FirePass controller. You cannot disable this pop-up window in the FirePass configuration. However, you can prevent users from receiving this pop-up window by pre-configuring your Windows client systems with the FirePass URL added to the IE Trusted Sites zone.

Security zones, including the Trusted Sites zone, is a security feature of IE. The FirePass Trusted Sites implementation consults IE’s Trusted Sites list through a FirePass client component. This component allows all browsers, not just IE, to access the IE Trusted Sites list.

Note: For more information about IE Trusted Sites security zones, refer to the following Microsoft document. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge: 

http://support.microsoft.com/kb/174360

F5 Product Development tracked this enhancement as CR87356 and it was included in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.
