K000151117: Unable to upgrade BIGIP-VE instance on Azure

Type
Support Solution
Published
2025-05-01
Updated
2025-05-01
Applies to
  • Public Cloud
  • BIG-IP
  • BIG-IP Cloud Edition
  • Microsoft Azure
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000151117

Description

When deploying BIG-IP LTM VE on Microsoft Azure using the "AllOneBootLocation" image, upgrading to a newer version (such as from 17.1.1 to 17.5) requires redeployment due to the limitations of the "AllOneBootLocation" configuration.

Environment

  • Product: BIG-IP LTM VE
  • Platform: Microsoft Azure
  • Image Types: AllOneBootLocation, AllTwoBootLocations
  • Upgrade
  • Deployment Method: Azure Resource Manager (ARM) template with parameters for imageName and diskSizeGB

Cause

The "AllOneBootLocation" image restricts deployment to a single boot location, which prevents in-place upgrades to newer BIG-IP versions that require multi-volume support.

Recommended Actions

Redeploy the BIG-IP VE instance in Azure using the "AllTwoBootLocations" image.

  1. Update your ARM template parameters:

    1. Set imageName from "AllOneBootLocation" to "AllTwoBootLocations".
    2. Adjust diskSizeGB as needed (for example, increase from 55 GB to 100 GB).

  2. Deploy the new VM instance.
  3. Activate your BIG-IP license (BYOL or Eval).
  4. Restore configuration from a previously saved UCS file if required.
  5. Proceed with software upgrade by installing the desired ISO (e.g., BIGIP-17.5.0-0.0.15.iso) onto a new volume such as HD1.2.
