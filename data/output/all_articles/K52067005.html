Description
Some users need to continue using applications running in legacy backend servers prepared to work just with Internet Explorer only. Since Microsoft stated it will deprecate Internet Explorer soon, Microsoft created the "Internet Explorer mode" that is an extension that clients must install in their machines. You may see that if client points directly to the backend server the application works, but if you direct the request through a LTM Virtual Server it doesn't work. 
 

Environment

  • Edge Browser
  • Internet Explorer mode
  • Legacy applications that work with Internet Explorer

Cause
Internet Explorer mode needs to be configured, the IP of the Virtual Server should be added to this configuration if Internet Explorer mode is needed to reach a backend server which is Internet Explorer only. 

Recommended Actions
To install the extension you should change a setting in your Edge application

  1. Open MS Edge
  2. Click the Settings and More (ellipsis) button on the top-right corner
  3. Select the Settings option
  4. Click on Default Browser
  5. Under the "internet Explorer compatibility" section, turn on the "Allow sites to be reloaded in the Internet Explorer mode" toggle switch.
  6. Click the Restart button. The changes in the system (the installation) will occurred here.
Once installed the extension it is ready to be used, in the Default mode.

In the default mode, the Edge will identify in the navigation history of IE which sites are/were visited using IE, Edge will prompt the user the possibility to reload the sites identified.

If the customer requires something more than the Default mode (using Edge from other computer, not required to reload but directly load the content in IE mode) additional configuration needs to be done:
  1. Click the setting and more (ellipsis) button on the top-right corner
  2. Select the Settings option
  3. Click on Default browser
  4. Under the “Internet Explorer compatibility” section, use the “Allow sites to be reloaded in Internet Explorer mode” drop-down menu and select the option to handle browsing when using Internet Explorer, including:
    • Don't allow– IE will never switch to Edge to load the site.
    • Default – Websites will load in Edge, but if the sites were loaded previously in IE, the user will be prompted to be able to reload in IE mode 
    • Always – Edge will always load the sites in the whitelist in IE mode.
  5. You can configure the list of the sites to be loaded in IE mode in the section Internet Explorer mode pages.

Additional Information
For more information about "Internet Explorer mode" refer to the documentation from Microsoft.
