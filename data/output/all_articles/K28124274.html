Description

You see response traffic from a pool or pool member is being slowed when going through the BIG-IP
In packet captures, you see the pool member sending a large amount of retransmits to the BIG-IP

Environment

  • BIG-IP LTM
  • TCP Virtual Server

Cause

The Delayed ACKs feature in the TCP profile may be in conflict with the pool member's TCP retransmit timer

Recommended Actions

Creating a custom TCP profile and applying it to the server-side of the effected virtual server may allow you to correct this behavior
  1. Navigate to Local Traffic > Profiles > Protocol > TCP
  2. Create a new TCP profile and give it a name
  3. Under Data Transfer, customize and disable Delayed ACKs
  4. Save the new profile
  5. Navigate to the virtual server
  6. Under Protocol Profile (Server), apply your new TCP profile
  7. Apply your changes and test the application
